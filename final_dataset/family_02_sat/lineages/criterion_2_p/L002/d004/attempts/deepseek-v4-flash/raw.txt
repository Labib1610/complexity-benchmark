We can model each machine as a boolean variable, and each interlock as a clause that must not have both literals true.  
That is equivalent to a **2-SAT** problem where we need to avoid certain combinations.

For each interlock `(c1, c2)`, the forbidden situation is:

- If `c1 > 0`, then machine `c1` must not be 0 when the other is high → we add implication: `(c1 == 1) OR (c2 == 0)` etc.

More systematically, for each clause `(A OR B)` we add implications `(!A → B)` and `(!B → A)`.

Here, each literal is:
- Positive `x` means machine `x` is 0.
- Negative `-x` means machine `x` is 1.

We want to avoid `(A AND B)` being true, so we require `(!A OR !B)`.  
That is a 2-SAT clause.

We can solve 2-SAT with SCC (Tarjan or Kosaraju) in O(n + m).

```python
import sys
sys.setrecursionlimit(1 << 20)
input = sys.stdin.readline

n, m = map(int, input().split())
N = 2 * n  # variables: 0..n-1 for x_i, n..2n-1 for not x_i

def node(var):
    # var > 0: machine var is 0
    # var < 0: machine -var is 1
    if var > 0:
        return (var - 1) * 2      # even index for x_i
    else:
        return (-var - 1) * 2 + 1 # odd index for not x_i

def neg_node(u):
    return u ^ 1

g = [[] for _ in range(N)]
gr = [[] for _ in range(N)]

for _ in range(m):
    a, b = map(int, input().split())
    u = node(a)
    v = node(b)
    # clause: (not u) OR (not v)
    # implications: u -> not v, v -> not u
    g[u].append(neg_node(v))
    g[neg_node(v)].append(u)
    g[v].append(neg_node(u))
    g[neg_node(u)].append(v)
    # reverse graph
    gr[neg_node(v)].append(u)
    gr[u].append(neg_node(v))
    gr[neg_node(u)].append(v)
    gr[v].append(neg_node(u))

# Kosaraju SCC
visited = [False] * N
order = []

def dfs1(u):
    visited[u] = True
    for w in g[u]:
        if not visited[w]:
            dfs1(w)
    order.append(u)

for i in range(N):
    if not visited[i]:
        dfs1(i)

comp = [-1] * N
def dfs2(u, cid):
    comp[u] = cid
    for w in gr[u]:
        if comp[w] == -1:
            dfs2(w, cid)

cid = 0
for u in reversed(order):
    if comp[u] == -1:
        dfs2(u, cid)
        cid += 1

# Check satisfiability
for i in range(n):
    if comp[2*i] == comp[2*i+1]:
        print("NO")
        sys.exit()

print("YES")
res = []
for i in range(n):
    # comp[2*i] > comp[2*i+1] means x_i is true (machine i+1 in mode 0)
    if comp[2*i] > comp[2*i+1]:
        res.append("0")
    else:
        res.append("1")
print(" ".join(res))
```
