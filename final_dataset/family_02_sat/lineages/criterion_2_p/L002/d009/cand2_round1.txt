<STATEMENT>
# Problem B — Sparse Vector Projection

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given the dimensions of a computational system: an integer $n$ representing the number of basis dimensions, and $m$ representing the number of projection tests.
You must construct an $n$-dimensional column vector $\mathbf{x} = [x_1, x_2, \dots, x_n]^T$ where every component $x_i \in \{0, 1\}$.

Each of the $m$ projection tests provides two non-zero integers $c_1$ and $c_2$.
For each test, consider a $2 \times n$ matrix $M$ and a $2 \times 1$ threshold vector $\mathbf{t}$ defined as follows:
- The first row of $M$ has the value $\frac{c_1}{|c_1|}$ (i.e., $+1$ if $c_1 > 0$, and $-1$ if $c_1 < 0$) at column $|c_1|$, and $0$ everywhere else.
- The second row of $M$ has the value $\frac{c_2}{|c_2|}$ at column $|c_2|$, and $0$ everywhere else.
- The first component of $\mathbf{t}$ is defined as $\min\left(0, \frac{c_1}{|c_1|}\right)$.
- The second component of $\mathbf{t}$ is defined as $\min\left(0, \frac{c_2}{|c_2|}\right)$.

A projection test is considered **successful** if the sum of the components of the resulting $2 \times 1$ vector $M\mathbf{x} - \mathbf{t}$ is strictly greater than $0$.

Determine if there exists a vector $\mathbf{x}$ such that all $m$ projection tests are successful. If so, output the components of $\mathbf{x}$.

## Input
The first line of the input provides two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of basis dimensions and the number of tests, respectively.

The next $m$ lines each contain two non-zero integers $c_1$ and $c_2$ ($|c_i| \le n$), detailing the parameters for that specific projection test.

## Output
If it is impossible to construct a valid vector $\mathbf{x}$ that passes all tests, output a single line with the word `NO`.

If a valid vector is possible, print `YES` on the first line. On the second line, print $n$ space-separated integers $x_1, x_2, \dots, x_n$ (where each $x_i \in \{0, 1\}$) representing the chosen components of the vector.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
There might be several valid vectors; outputting any one that passes all tests is correct. The same index can be referenced multiple times across different tests.
</STATEMENT>
<RATIONALE>
The problem was completely reframed from a mechanical locking system to a linear algebra problem involving sparse matrices and threshold vectors. This forces the model to algebraically evaluate the expression `Mx - t` and deduce that its sum evaluates to a boolean OR clause, preventing shallow pattern matching on DIMACS-like forbidden states.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic sum of the components of `Mx - t` evaluates to exactly `x_i` (if c > 0) or `1 - x_i` (if c < 0), meaning the sum is strictly greater than 0 if and only if at least one of the conditions avoids its forbidden state, exactly matching the seed's logic.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, solvable in O(N+M) time by reducing the matrix inequalities back to boolean implications and finding strongly connected components.
</PRESERVED_CLASS>
