**Solution Explanation**

For every machine `i` we denote  

```
Xi = 1   – the machine works in mode 1
Xi = 0   – the machine works in mode 0
```

For a literal written in the input

* `l > 0`  reference = machine `l` in mode **1**  
  the interlock is triggered when the machine is **not** in mode 1, i.e. when `Xi = 0`.  
  The forbidden assignment is therefore `¬Xi` (or `¬Li` where `Li` means “Xi = 1”).

* `l < 0`  reference = machine `|l|` in mode **0**  
  the interlock is triggered when the machine is **not** in mode 0, i.e. when `Xi = 1`.  
  The forbidden assignment is `Xi` (or `Li`).

An interlock contains two literals `l1 , l2`.  
It shuts down the plant **iff** both forbidden assignments happen together.
Hence we have to avoid the conjunction

```
(forbidden assignment of l1)  AND  (forbidden assignment of l2)
```

which is equivalent to the clause

```
(not forbidden of l1)  OR  (not forbidden of l2)
```

Thus every interlock gives a **2‑CNF clause**.  
The whole problem is exactly the classic *2‑SAT* problem.

--------------------------------------------------------------------

#### 1.   2‑SAT encoding

For each machine `i` we create a Boolean variable `Li` meaning “machine `i` works in mode 1”.
A literal in a clause is either `Li` or `¬Li` :

```
input l > 0   →   literal = ¬Li
input l < 0   →   literal =  Li
```

A clause `(A ∨ B)` is transformed to two implications

```
¬A → B
¬B → A
```

We build a directed graph with `2·n` vertices:

```
vertex 2·(i-1)   :  ¬Li   (Li = false)
vertex 2·(i-1)+1 :  Li   (Li = true)
```

For every clause we add the two edges described above.

--------------------------------------------------------------------

#### 2.   Solving 2‑SAT

The implication graph is solved by **strongly connected components** (SCC).

* If a variable and its negation belong to the same SCC, the formula is unsatisfiable.
* Otherwise the SCCs form a DAG.  
  In any topological order, the component that appears later is “more true”.  
  We assign  

```
Li = true   if   comp(Li) > comp(¬Li)
Li = false  otherwise
```

The assignment of `Li` directly gives the required mode of the machine
(`1` for true, `0` for false).

We use Kosaraju’s algorithm – linear time and memory.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct calibration
iff such a calibration exists.

---

##### Lemma 1  
For each interlock the clause constructed by the algorithm is satisfied
exactly when the interlock does **not** trigger.

**Proof.**  
Consider an input literal `l`.

* `l > 0` : the interlock forbids `Xi = 0`.  
  The clause contains `¬Li`.  
  `¬Li` is true ⇔ `Li = 0` ⇔ `Xi = 0` is **not** the forbidden assignment.  
  Hence `¬Li` being true means the interlock’s condition on this machine is satisfied.

* `l < 0` : the interlock forbids `Xi = 1`.  
  The clause contains `Li`.  
  `Li` true ⇔ `Xi = 1` is **not** the forbidden assignment.

Thus for each literal, the clause literal is true exactly when the
corresponding machine does **not** take the forbidden value.
The clause `(A ∨ B)` is true ⇔ at least one machine avoids its forbidden value,
which is precisely the condition that the interlock does **not** trigger. ∎



##### Lemma 2  
If the algorithm finds a satisfying assignment of the 2‑SAT instance,
the produced calibration satisfies **all** interlocks.

**Proof.**  
A satisfying assignment makes every clause true.
By Lemma&nbsp;1 each clause being true means the corresponding interlock does not trigger.
Therefore no interlock triggers. ∎



##### Lemma 3  
If the algorithm reports “NO”, no safe calibration exists.

**Proof.**  
The algorithm reports “NO” only when for some variable `i`,
`Li` and `¬Li` belong to the same SCC.
In any assignment respecting all implications, vertices inside one SCC must have
the same truth value (reachability both ways).  
Thus `Li` and `¬Li` would have to be simultaneously true, which is impossible.
Consequently the 2‑SAT formula is unsatisfiable, i.e. there is no assignment that
makes all clauses true.
By Lemma&nbsp;1 this means no calibration avoids all interlocks. ∎



##### Lemma 4  
If the algorithm reports “YES”, the assignment it outputs satisfies all implications
and therefore all clauses.

**Proof.**  
Kosaraju’s algorithm yields SCCs in reverse topological order.
The rule `Li = true` iff `comp(Li) > comp(¬Li)` assigns `true` to a vertex only
if its component appears later than the component of its negation.
Hence there is no edge from a later component to an earlier one,
so no implication `A → B` is violated:
if `A` is true, `A`'s component is later, therefore `B`'s component is also later,
making `B` true as well.
Thus all implications hold, consequently all clauses hold. ∎



##### Lemma 5  
The calibration printed by the algorithm (when “YES”) is safe.

**Proof.**  
From Lemma&nbsp;4 the assignment satisfies all clauses.
By Lemma&nbsp;2 this implies that no interlock triggers. ∎



##### Theorem  
The algorithm outputs  

* “NO” **iff** no safe calibration exists,  
* otherwise “YES” and a calibration that keeps all interlocks inactive.

**Proof.**  

*If the algorithm outputs “YES”* – by Lemma&nbsp;5 the printed calibration is safe,
so a safe calibration exists.

*If a safe calibration exists* – the corresponding assignment satisfies every
clause (Lemma&nbsp;1), therefore the 2‑SAT instance is satisfiable.
A satisfiable 2‑SAT instance never has a variable and its negation in the same SCC,
so the algorithm will not output “NO”.  
Consequently it outputs “YES” and, by Lemma&nbsp;5, a safe calibration.

Thus the statements are equivalent. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Vertices* : `2·n`  
*Edges*    : `2·m` (two per clause)

Kosaraju’s algorithm runs in `O(V + E) = O(n + m)` time and the same memory.

Both limits satisfy the constraints (`n ≤ 10⁵`, `m ≤ 2·10⁵`).

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    N = 2 * n                     # total vertices
    g = [[] for _ in range(N)]   # forward graph
    rg = [[] for _ in range(N)]  # reverse graph

    def var_node(i: int, is_true: bool) -> int:
        """return vertex number for Li (is_true) or ¬Li (not is_true)"""
        base = 2 * (i - 1)
        return base + (1 if is_true else 0)

    for _ in range(m):
        l1 = int(next(it))
        l2 = int(next(it))

        # translate input literal to (var, is_true) where literal = (is_true ? Li : ¬Li)
        if l1 > 0:
            a_var, a_true = l1, False   # ¬Li
        else:
            a_var, a_true = -l1, True   # Li

        if l2 > 0:
            b_var, b_true = l2, False
        else:
            b_var, b_true = -l2, True

        a = var_node(a_var, a_true)
        nota = var_node(a_var, not a_true)
        b = var_node(b_var, b_true)
        notb = var_node(b_var, not b_true)

        # add implications ¬A → B , ¬B → A
        g[nota].append(b)
        rg[b].append(nota)

        g[notb].append(a)
        rg[a].append(notb)

    # Kosaraju
    visited = [False] * N
    order = []

    def dfs(v: int):
        visited[v] = True
        for to in g[v]:
            if not visited[to]:
                dfs(to)
        order.append(v)

    for v in range(N):
        if not visited[v]:
            dfs(v)

    comp = [-1] * N
    cur = 0

    def rdfs(v: int, label: int):
        comp[v] = label
        for to in rg[v]:
            if comp[to] == -1:
                rdfs(to, label)

    for v in reversed(order):
        if comp[v] == -1:
            rdfs(v, cur)
            cur += 1

    # check satisfiability
    assignment = [0] * n
    for i in range(1, n + 1):
        false_node = var_node(i, False)
        true_node = var_node(i, True)
        if comp[false_node] == comp[true_node]:
            print("NO")
            return
        # component with larger number appears earlier in topological order of reversed graph
        assignment[i - 1] = 1 if comp[true_node] > comp[false_node] else 0

    print("YES")
    print(' '.join(map(str, assignment)))


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
