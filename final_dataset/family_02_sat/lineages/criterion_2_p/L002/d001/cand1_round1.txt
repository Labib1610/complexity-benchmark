<STATEMENT>
# Problem B — Production Line Configuration

Time limit: 1 s   Memory limit: 256 MB

## Description

A manufacturing plant contains $n$ distinct machines. Each machine must be calibrated to one of two operational modes: mode 1 or mode 0. The plant managers have compiled a list of $m$ critical safety tolerances. Each tolerance identifies a specific pair of machine states that interact dangerously. A tolerance is violated if both of the identified states are present in the plant's actual calibration at the same time. The plant is considered safe only if no tolerances are violated.

Determine if there is a way to calibrate all $n$ machines such that the plant is safe. If such a plant-wide calibration is possible, provide one. Otherwise, indicate that a safe configuration is impossible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the following $m$ lines contains two non-zero integers $l_1$ and $l_2$, where $|l_i| \le n$. These represent the two interacting states for a tolerance. A positive integer $x$ means a trigger occurs if machine $x$ operates in mode 0. A negative integer $x$ means a trigger occurs if machine $|x|$ operates in mode 1. For each tolerance, the plant is safe as long as it avoids having both of its triggers active simultaneously.

## Output
If there is no valid way to calibrate the machines to make the plant safe, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) representing the chosen mode for each machine from 1 to $n$.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid calibrations may exist; any one is accepted. The same machine may appear in multiple tolerances.
</STATEMENT>
<RATIONALE>
I replaced the standard 2-SAT disjunction framing ("at least one of two desired states") with a negated conjunction framing ("avoid having both triggers active simultaneously"). I also inverted the mapping of positive/negative integers to account for this change. This removes the surface-level affordance, forcing the model to apply De Morgan's laws to deduce the correct implications rather than blindly using a stock 2-SAT template.
</RATIONALE>
<PRESERVED_ANSWER>
By De Morgan's laws, forbidding the simultaneous occurrence of the inverted states is logically identical to requiring at least one of the original states, so the exact same truth assignments remain valid for every input.
</PRESERVED_ANSWER>
