<STATEMENT>
# Problem B — Production Line Configuration

Time limit: 1 s   Memory limit: 256 MB

## Description

A manufacturing plant operates $n$ distinct machines, each requiring calibration into one of two operational modes: mode 1 or mode 0. To guarantee plant stability, managers have deployed $m$ safety interlocks. Rather than checking single machines, each interlock dictates a fallback relationship between a specific pair of machines to prevent system failure.

You must determine whether it is feasible to calibrate all $n$ machines in a way that respects every interlock's requirements. If a safe plant-wide configuration exists, you must output one such configuration. If no such configuration can be achieved, you must report that it is impossible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the following $m$ lines contains two non-zero integers $l_1$ and $l_2$, where $|l_i| \le n$. These values specify the reference conditions for a single interlock. For any given $l_i$, if $l_i > 0$, the reference condition is that machine $l_i$ operates in mode 1. If $l_i < 0$, the reference condition is that machine $|l_i|$ operates in mode 0.

An interlock prevents a shutdown by enforcing a strict operational rule between its two reference conditions. Specifically, whenever the actual calibration of the machine for $l_1$ fails to match its reference condition, the safety protocol mandates that the machine for $l_2$ must match its reference condition. Due to symmetric wiring, this equivalently dictates that whenever the machine for $l_2$ fails to match its reference condition, the machine for $l_1$ must match its reference condition.

## Output
If there is no valid way to calibrate the machines without triggering a shutdown, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) representing the chosen mode for each machine from 1 to $n$.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid calibrations may exist; any one is accepted. The same machine may be monitored by multiple interlocks.
</STATEMENT>
<RATIONALE>
Replaced the direct statement of the forbidden state (which easily mapped to a 2-SAT OR-clause via De Morgan's laws) with an operational fallback rule framed purely as an implication. This forces the model to either recognize the logical equivalence of the implication to a disjunction or to construct the implication graph directly from the text, preventing it from relying on surface-level keyword matching for a standard CNF clause definition.
</RATIONALE>
<PRESERVED_ANSWER>
The logical constraint "if A fails, B must match" is strictly equivalent to "A and B cannot both fail", meaning the exact same set of valid configurations is preserved for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, solvable in linear time using Kosaraju's algorithm on the implication graph, as the constraints are just pairwise boolean implications.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "if A fails, B must match" as an exclusive-OR or strict implication rather than a standard material implication (where A matching and B matching simultaneously is also perfectly valid), though the symmetry clarification helps mitigate this.
</RISK>
