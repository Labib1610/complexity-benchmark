<STATEMENT>
# Problem B — Production Line Configuration

Time limit: 1 s   Memory limit: 256 MB

## Description

A manufacturing facility runs $n$ distinct machines. Each machine must be securely locked into one of two modes: mode 0 or mode 1. 

The facility's power grid is safeguarded by $m$ safety interlocks. Each interlock receives two signal feeds from the machines. A signal feed is defined by a non-zero integer $c$. The absolute value $|c|$ specifies the source machine for the feed. The sign of $c$ determines the feed's phase: a positive $c$ indicates a positive-phase feed, and a negative $c$ indicates a negative-phase feed.

A feed operates in *alignment* if it is a positive-phase feed ($c > 0$) and its source machine is in mode 1, or if it is a negative-phase feed ($c < 0$) and its source machine is in mode 0. Otherwise, the feed operates in *anti-alignment*.

Each feed delivers power to its interlock based on its operational state: it delivers $|c|$ watts if it operates in alignment, and $-|c|$ watts if it operates in anti-alignment.

An interlock calculates its total received power by summing the watts delivered by its two feeds. For an interlock with feeds $c_1$ and $c_2$, the critical threshold is defined as $-(|c_1| + |c_2|)$ watts. An interlock remains stable if and only if its total received power is strictly greater than this critical threshold. If the total received power drops to or below this threshold, a catastrophic shutdown is triggered.

To keep the facility running, you must determine a facility-wide configuration (assigning mode 0 or mode 1 to each machine) such that all $m$ interlocks remain stable.

Determine if a safe configuration exists, and if so, output the required mode for each machine.

## Input
The first line of the input provides two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of machines and the number of safety interlocks, respectively.

The next $m$ lines each contain two non-zero integers $c_1$ and $c_2$ ($|c_i| \le n$), detailing the two signal feeds for that interlock. 

## Output
If it is impossible to configure all $n$ machines without causing a shutdown, output a single line with the word `NO`.

If a safe configuration is possible, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{0, 1\}$) to specify the chosen mode for each machine from 1 to $n$.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
There might be several safe configurations; outputting any valid one is correct. A single machine can provide signal feeds to multiple interlocks.
