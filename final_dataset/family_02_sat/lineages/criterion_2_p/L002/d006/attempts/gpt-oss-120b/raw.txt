**Solution Explanation**

For every machine `i` we have a Boolean variable `s[i] ∈ {0,1}`.
For a linkage value `c`

```
u = |c|                     # machine index
b(c) = 1  if c > 0
b(c) = 0  if c < 0
```

The strain of this linkage is `0` iff `s[u] = b(c)`, otherwise `1`.

An interlock has two linkages `c1 , c2`.  
It stays intact **iff not both linkages have strain = 1**, i.e.

```
(s[|c1|] = b(c1))  OR  (s[|c2|] = b(c2))
```

Thus each interlock gives a 2‑SAT clause  
`L1 ∨ L2` where a literal `L` is either `s[i] = 1` or `s[i] = 0`.

The whole problem is exactly the classic *2‑SAT* problem:
find a truth assignment satisfying all clauses, or report that none exists.



--------------------------------------------------------------------

#### 1.   2‑SAT encoding

For every variable `i` we create two nodes

```
node 2*i     :  s[i] = 0   (false)
node 2*i + 1 :  s[i] = 1   (true)
```

`neg(x)` – the opposite literal – is `x ^ 1`.

A clause `(A ∨ B)` is transformed to two implications

```
¬A → B
¬B → A
```

and we add the corresponding directed edges to the implication graph.



--------------------------------------------------------------------

#### 2.   Solving 2‑SAT

A 2‑SAT instance is satisfiable **iff** in the implication graph no variable
and its negation belong to the same strongly connected component (SCC).

We compute SCCs with Kosaraju’s algorithm (two DFS passes) – linear time.

After SCCs are known we order them topologically (by decreasing finishing time
in the second pass).  
For each variable `i` we set

```
s[i] = 1   if   comp[true]  > comp[false]
s[i] = 0   otherwise
```

(the component with larger topological order is assigned `false`).

If any variable and its negation share a component we output `NO`.



--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct assignment
iff such an assignment exists.

---

##### Lemma 1  
For every interlock the clause `L1 ∨ L2` (as constructed) is satisfied
exactly when the interlock does not break.

**Proof.**  
`Lk` is the statement “the linkage `ck` matches its bias”, i.e.
`s[|ck|] = b(ck)`.  
The interlock breaks only when *both* linkages mismatch, i.e. when
`¬L1 ∧ ¬L2` holds.  
Thus the interlock is safe ⇔ `¬(¬L1 ∧ ¬L2)` ⇔ `L1 ∨ L2`. ∎



##### Lemma 2  
An assignment of the variables satisfies all interlock constraints
iff it satisfies all 2‑SAT clauses built from them.

**Proof.** Directly from Lemma&nbsp;1, each interlock constraint is equivalent to
its clause. ∎



##### Lemma 3  
If the algorithm outputs `YES` and a vector `s`,
then `s` satisfies every clause.

**Proof.**  
The algorithm outputs `YES` only when for every variable `i`,
`comp[true] ≠ comp[false]`.  
In Kosaraju’s ordering, for any edge `u → v` we have `comp[u] ≥ comp[v]`.
Consider a clause `(A ∨ B)`. The algorithm added edges `¬A → B` and `¬B → A`.
If both `A` and `B` were false under `s`, then `¬A` and `¬B` would be true,
hence edges `¬A → B` and `¬B → A` would go from a true literal to a false
literal, contradicting the topological order (a true literal cannot reach a
false one). Therefore at least one of `A, B` is true, i.e. the clause holds. ∎



##### Lemma 4  
If a satisfying assignment exists, the algorithm never declares `NO`.

**Proof.**  
Assume a satisfying assignment exists.
Take any variable `i`. In the implication graph, if `true` and `false`
were in the same SCC, then there would be a path `true → false` and also
`false → true`. From the first path we get implication `true ⇒ false`,
i.e. `s[i]=1` forces `s[i]=0`; from the second, `false ⇒ true`.
Thus any assignment would have to set both values equal, impossible.
Hence a satisfiable instance cannot contain such a component pair,
so the algorithm will not output `NO`. ∎



##### Lemma 5  
If the algorithm outputs `YES`, the produced assignment `s`
satisfies all clauses.

**Proof.** Follows from Lemma&nbsp;3. ∎



##### Theorem  
The algorithm prints `YES` and a valid configuration exactly when such a
configuration exists; otherwise it prints `NO`.

**Proof.**  
*If* the algorithm prints `YES`, by Lemma&nbsp;5 the assignment satisfies all
clauses, and by Lemma&nbsp;2 all interlock constraints – a valid configuration.

*Only if* a valid configuration exists, by Lemma&nbsp;4 the algorithm will not
output `NO`; consequently it outputs `YES` and, by Lemma&nbsp;5, a (possibly
different) valid configuration. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis

* `2n` nodes, `2m` edges.
* Kosaraju: two DFS traversals → `O(n + m)` time.
* Memory: adjacency lists for forward and reverse graph → `O(n + m)`.

Both limits satisfy the problem constraints (`n ≤ 10⁵`, `m ≤ 2·10⁵`).

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    N = 2 * n                     # total literals
    g = [[] for _ in range(N)]
    rg = [[] for _ in range(N)]

    def var_node(idx, val):
        """return node number for s[idx]=val (val 0/1)"""
        return 2 * (idx - 1) + val

    for _ in range(m):
        c1 = int(next(it)); c2 = int(next(it))
        u1 = abs(c1); u2 = abs(c2)
        b1 = 1 if c1 > 0 else 0
        b2 = 1 if c2 > 0 else 0
        a = var_node(u1, b1)          # literal A
        b = var_node(u2, b2)          # literal B
        na = a ^ 1                     # ¬A
        nb = b ^ 1                     # ¬B
        # ¬A -> B
        g[na].append(b); rg[b].append(na)
        # ¬B -> A
        g[nb].append(a); rg[a].append(nb)

    visited = [False] * N
    order = []

    def dfs(v):
        visited[v] = True
        for to in g[v]:
            if not visited[to]:
                dfs(to)
        order.append(v)

    for v in range(N):
        if not visited[v]:
            dfs(v)

    comp = [-1] * N
    cur = 0

    def rdfs(v, k):
        comp[v] = k
        for to in rg[v]:
            if comp[to] == -1:
                rdfs(to, k)

    for v in reversed(order):
        if comp[v] == -1:
            rdfs(v, cur)
            cur += 1

    # check satisfiability
    for i in range(n):
        if comp[2*i] == comp[2*i+1]:
            print("NO")
            return

    # assignment: component with larger number = false
    ans = [0] * n
    for i in range(n):
        ans[i] = 1 if comp[2*i+1] > comp[2*i] else 0

    print("YES")
    print(' '.join(map(str, ans)))

if __name__ == "__main__":
    solve()
```

and conforms to the required input‑output format.
