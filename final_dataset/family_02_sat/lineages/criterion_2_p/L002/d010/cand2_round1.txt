<STATEMENT>
# Problem B — Spectral Alignment Constraints

Time limit: 1 s   Memory limit: 256 MB

## Description

A research facility operates $n$ quantum emitters. Each emitter $i$ must be calibrated with a binary state $s_i \in \{0, 1\}$. Depending on its state, an emitter produces one of two baseline transformation matrices:
- If $s_i = 0$, its matrix is $M = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}$.
- If $s_i = 1$, its matrix is $M = \begin{pmatrix} 1 & 0 \\ 1 & 1 \end{pmatrix}$.

The facility's containment grid is maintained by $m$ interference monitors. Each monitor receives signals from exactly two channels, defined in the system by two non-zero integers $c_1$ and $c_2$. 

A channel specified by a value $c$ retrieves a transformation matrix from emitter $|c|$. The channel's polarity determines which matrix is retrieved:
- If $c > 0$, the channel retrieves the exact matrix currently produced by emitter $|c|$.
- If $c < 0$, the channel retrieves the *complementary* matrix. (If the emitter currently produces $\begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}$, the channel retrieves $\begin{pmatrix} 1 & 0 \\ 1 & 1 \end{pmatrix}$, and vice versa).

Inside the monitor, the two retrieved matrices, $A$ (from channel $c_1$) and $B$ (from channel $c_2$), undergo non-linear mixing. The resulting resonance matrix $R$ is computed via standard matrix multiplication: $R = A \times B$.

A critical instability occurs if the trace of the resonance matrix $R$ (the sum of its main diagonal elements) is exactly equal to 0. If this happens in any of the $m$ monitors, the containment grid collapses.

You must determine if there is a calibration sequence $s_1, \dots, s_n$ for the $n$ emitters such that every monitor remains stable (i.e., the trace of $R$ is strictly greater than 0 for all monitors). If such a sequence exists, output the required states.

## Input
The first line of the input provides two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of emitters and the number of monitors, respectively.

The next $m$ lines each contain two non-zero integers $c_1$ and $c_2$ ($|c_i| \le n$), representing the two channels for that monitor. 

## Output
If it is impossible to configure all $n$ emitters without collapsing the grid, output a single line with the word `NO`.

If a stable configuration is possible, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{0, 1\}$) to specify the chosen state for each emitter from 1 to $n$.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
There might be several stable configurations; outputting any valid one is correct. A single emitter can connect channels to multiple monitors.

Replaced the direct scalar inequality $R = v_1 + v_2 + v_1 v_2 \le 0$ with a matrix multiplication trace condition. The matrices are specifically chosen so that their pairwise product traces map perfectly to the truth table of the original boolean constraint. This forces models to manually evaluate the 4 possible matrix products to discover the underlying 2-SAT structure, rather than instantly pattern-matching a familiar scalar equation.
</RATIONALE>
<PRESERVED_ANSWER>
The trace of the matrix product evaluates to 0 if and only if both channels retrieve the matrix for state 0, perfectly mirroring the original condition where $R > 0$ if and only if both channels received $v=1$.
</PRESERVED_ANSWER>
