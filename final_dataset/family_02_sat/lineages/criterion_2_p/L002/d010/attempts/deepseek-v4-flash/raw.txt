We can simplify the condition first.  

For a monitor with channels \( c_1, c_2 \), the parameters are:

- If \( c > 0 \): \( v = s_{|c|} \)  
- If \( c < 0 \): \( v = 1 - s_{|c|} \)

The functions are:
\[
f_1(x) = x + 2v_1 - 1
\]
\[
f_2(x) = x + 2v_2 - 1
\]

The integral:
\[
I = \int_0^1 (x + 2v_1 - 1)(x + 2v_2 - 1)\, dx
\]

Let’s compute it:

Let \( a = 2v_1 - 1 \), \( b = 2v_2 - 1 \).  
Then:
\[
I = \int_0^1 (x+a)(x+b)\, dx
= \int_0^1 (x^2 + (a+b)x + ab)\, dx
\]
\[
= \frac{1}{3} + \frac{a+b}{2} + ab
\]

We require \( I \neq \frac{1}{3} \), so:
\[
\frac{a+b}{2} + ab \neq 0
\]

Now note:  
If \( v \in \{0,1\} \), then \( 2v - 1 \in \{-1, 1\} \).  
So \( a, b \in \{-1, 1\} \).

Check cases:

- \( a = 1, b = 1 \): \( \frac{2}{2} + 1 = 1 + 1 = 2 \neq 0 \) → stable  
- \( a = 1, b = -1 \): \( \frac{0}{2} - 1 = -1 \neq 0 \) → stable  
- \( a = -1, b = 1 \): same as above → stable  
- \( a = -1, b = -1 \): \( \frac{-2}{2} + 1 = -1 + 1 = 0 \) → unstable  

So instability occurs **only when** \( a = b = -1 \), i.e., \( v_1 = v_2 = 0 \).

Thus, a monitor is unstable if both parameters are 0.

Now, parameter \( v = 0 \) means:
- If \( c > 0 \): \( s_{|c|} = 0 \)
- If \( c < 0 \): \( 1 - s_{|c|} = 0 \) → \( s_{|c|} = 1 \)

So each monitor gives a constraint:  
We cannot have both channels yield 0 simultaneously.

This is a **2-SAT** problem:  
For each monitor with channels \( c_1, c_2 \), we must avoid the assignment that makes both 0.  
That means:  
At least one of the two must be 1.

Let’s define for each emitter \( i \):
- \( x_i \) = True if \( s_i = 1 \), False if \( s_i = 0 \).

For a channel \( c \):
- If \( c > 0 \): parameter is 1 when \( x_{|c|} \) is True.
- If \( c < 0 \): parameter is 1 when \( x_{|c|} \) is False.

So the condition “not both 0” means:  
At least one of the two parameters is 1.

That is a clause:  
(parameter1 == 1) OR (parameter2 == 1)

Which translates to a 2-SAT clause.

We can solve with implication graph and SCC.

Let’s implement.

```python
import sys
sys.setrecursionlimit(1 << 20)

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    clauses = []
    for _ in range(m):
        c1, c2 = map(int, input().split())
        # parameter is 1 if:
        # c>0: x[|c|] is True
        # c<0: x[|c|] is False
        # So literal for "param is 1":
        lit1 = c1 > 0
        lit2 = c2 > 0
        var1 = abs(c1) - 1
        var2 = abs(c2) - 1
        # clause: (lit1 ? x_var1 : ~x_var1) OR (lit2 ? x_var2 : ~x_var2)
        # In 2-SAT: (a OR b) => (~a -> b) and (~b -> a)
        # a is True if lit1 is True and var1 is True, or lit1 False and var1 False.
        # So a = (lit1 == x_var1)
        # ~a = (lit1 != x_var1)
        # We'll encode node for each literal: 2*var for False, 2*var+1 for True
        # a_lit = 2*var1 + (1 if lit1 else 0)
        # b_lit = 2*var2 + (1 if lit2 else 0)
        a_lit = 2 * var1 + (1 if lit1 else 0)
        b_lit = 2 * var2 + (1 if lit2 else 0)
        # ~a_lit = a_lit ^ 1
        # ~b_lit = b_lit ^ 1
        clauses.append((a_lit, b_lit))
    
    N = 2 * n
    g = [[] for _ in range(N)]
    gr = [[] for _ in range(N)]
    for a, b in clauses:
        # ~a -> b
        g[a ^ 1].append(b)
        gr[b].append(a ^ 1)
        # ~b -> a
        g[b ^ 1].append(a)
        gr[a].append(b ^ 1)
    
    # Kosaraju SCC
    visited = [False] * N
    order = []
    def dfs1(u):
        visited[u] = True
        for v in g[u]:
            if not visited[v]:
                dfs1(v)
        order.append(u)
    
    for i in range(N):
        if not visited[i]:
            dfs1(i)
    
    comp = [-1] * N
    def dfs2(u, cid):
        comp[u] = cid
        for v in gr[u]:
            if comp[v] == -1:
                dfs2(v, cid)
    
    cid = 0
    for u in reversed(order):
        if comp[u] == -1:
            dfs2(u, cid)
            cid += 1
    
    for i in range(n):
        if comp[2*i] == comp[2*i+1]:
            print("NO")
            return
    
    print("YES")
    res = []
    for i in range(n):
        # If comp[2*i] > comp[2*i+1] means False literal is later in topological order => assign True
        # Standard: if comp[2*i] > comp[2*i+1] then x_i = True
        if comp[2*i] > comp[2*i+1]:
            res.append('1')
        else:
            res.append('0')
    print(' '.join(res))

if __name__ == "__main__":
    solve()
```
