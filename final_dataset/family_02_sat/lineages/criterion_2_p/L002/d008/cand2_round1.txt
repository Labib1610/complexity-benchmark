# Problem B — Production Line Configuration

Time limit: 1 s   Memory limit: 256 MB

## Description

A manufacturing facility operates $n$ distinct machines. Each machine must be securely configured into one of two operational modes: `0` or `1`. 

The facility is safeguarded by $m$ safety interlocks. Each interlock monitors exactly two mechanical feeds coming from the machines. A feed is defined by a non-zero integer $c$. The absolute value $|c|$ identifies which machine the feed connects to.

Every feed has an intrinsic phase, determined by its sign:
- A positive feed ($c > 0$) has an intrinsic phase of `1`.
- A negative feed ($c < 0$) has an intrinsic phase of `0`.

When machine $|c|$ is configured to mode $s \in \{0, 1\}$, the feed interacts with the machine's mode. If the machine's mode exactly matches the feed's intrinsic phase, the feed transmits a "stabilizing" resonance to the interlock. If the machine's mode differs from the feed's intrinsic phase, it transmits a "destructive" resonance.

An interlock is robust enough to handle destructive resonance from one of its feeds. However, if *both* of its connected feeds transmit destructive resonance simultaneously, the interlock shatters and triggers a catastrophic facility-wide shutdown.

To keep the facility operational, you must determine a facility-wide configuration (assigning mode `0` or `1` to each machine) such that all $m$ interlocks remain intact. Determine if a safe configuration exists, and if so, output the required mode for each machine. 

The factory floor consists of a $100 \times 1000$ grid of installation slots. There is at least one machine, and the number of machines $n$ will not exceed the total number of slots. The safety interlocks are housed in a dedicated room containing $200$ racks, each capable of holding exactly $1000$ interlocks, meaning the total number of interlocks $m$ can range from zero up to the maximum rack capacity. Each feed's identifier $|c|$ always corresponds to a valid installed machine.

## Input
The first line of the input provides the two integers $n$ and $m$, representing the number of machines and the number of safety interlocks. The values of $n$ and $m$ respect the facility capacities described above.

The next $m$ lines each contain two non-zero integers $c_1$ and $c_2$, detailing the two feeds connected to that specific interlock.

## Output
If it is impossible to configure all $n$ machines without causing a shutdown, output a single line with the word `NO`.

If a safe configuration is possible, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{0, 1\}$) to specify the chosen mode for each machine from 1 to $n$.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
There might be several safe configurations; outputting any valid one is correct. A single machine can connect feeds to multiple interlocks.

I replaced it with a logical matching rule where a feed's "intrinsic phase" (derived from its sign) must equal the machine's mode to be "stabilizing". This forces the model to logically deduce the truth table of the failure condition rather than pattern-matching an algebraic inequality. Additionally, I encoded the numeric bounds as physical capacities (grid and racks) to satisfy S07.
