# Problem B — Production Line Configuration

Time limit: 1 s   Memory limit: 256 MB

## Description

A manufacturing facility runs $n$ distinct machines. Each machine must be securely locked into one of two operational phases: $s_i \in \{0, 1\}$.

The facility's power grid is safeguarded by $m$ safety interlocks. Each interlock receives two mechanical feeds from the machines. A feed is defined by a non-zero integer $c$. The feed's connected machine is given by its absolute value, $|c|$.

Each feed has a preferred phase dictated by its sign. If $c > 0$, the feed's preferred phase is 1. If $c < 0$, the feed's preferred phase is 0. 
When machine $|c|$ is configured to the feed's preferred phase, the feed provides *stabilizing* resonance. When the machine is configured to the opposite phase, the feed provides *destructive* resonance.

An interlock stays intact if and only if at least one of its two feeds is stabilizing; it shatters only when both feeds are destructive. If an interlock shatters, it triggers a catastrophic facility-wide shutdown.

To keep the facility operational, you must determine a facility-wide configuration (assigning phase 0 or 1 to each machine) such that all $m$ interlocks remain intact. Determine if a safe configuration exists, and if so, output the required phase for each machine.

Note that a single machine can connect feeds to multiple interlocks. Furthermore, the two feeds of a single interlock may refer to the same machine, potentially with the same or opposite signs.

## Input
The first line of the input provides two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of machines and the number of safety interlocks, respectively.

The next $m$ lines each contain two non-zero integers $c_1$ and $c_2$, detailing the two feeds for that interlock. Each feed satisfies $1 \le |c_i| \le n$.

## Output
If it is impossible to configure all $n$ machines without causing a shutdown, output a single line with the word `NO`.

If a safe configuration is possible, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{0, 1\}$) to specify the chosen phase for each machine from 1 to $n$. Any valid configuration is accepted.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

I removed the algebraic formula for torque which directly produced the 2-SAT literals for the models. Instead, I established a semantic rule where the sign of the input integer dictates a "preferred phase", and failure occurs only if both feeds are "destructive". This explicitly preserves the logic while preventing simple pattern-matching on the formula. I also restored the exact numeric bounds to satisfy the gate requirements.
</RATIONALE>

The condition for an interlock shattering (both feeds destructive) is mathematically identical to both torques being negative in the seed, ensuring the exact same valid configurations.
