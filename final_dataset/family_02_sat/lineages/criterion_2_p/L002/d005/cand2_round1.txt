<METHOD_NAME>Algebraic Constraint Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit boolean NAND condition ("both feeds carry a high voltage") with a mathematically equivalent linear inequality over {-1, 1}. By requiring a cross-multiplied sum to be <= 0, models must algebraically simplify the expression to deduce that it prevents exactly one out of four state combinations, which maps to a 2-SAT clause. This prevents direct pattern matching on boolean descriptions.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Production Line Configuration

Time limit: 1 s   Memory limit: 256 MB

## Description

A manufacturing facility runs distinct machines. Each machine $i$ (from $1$ to $n$) must be assigned a configuration state $s_i \in \{0, 1\}$. This state determines the machine's operational scaling factor, defined as $f_i = 1 - 2s_i$. Note that $f_i$ will always be either $1$ or $-1$.

The facility's power grid is safeguarded by safety interlocks. Each interlock receives two signal feeds from the machines. A signal feed is defined by a non-zero integer $c$. The absolute value $|c|$ specifies which machine provides the feed, and the sign of $c$ influences the stability calculation.

For an interlock receiving feeds $c_1$ and $c_2$, the system evaluates the following stability criterion:
$$f_{|c_1|} \cdot c_1 \cdot |c_2| + f_{|c_2|} \cdot c_2 \cdot |c_1| \le 0$$

A catastrophic shutdown is triggered if this inequality is violated (i.e., if the evaluated sum is strictly greater than zero). To keep the facility running, you must determine a facility-wide configuration (assigning $0$ or $1$ to each $s_i$) such that all $m$ interlocks satisfy the stability criterion.

Determine if a safe configuration exists, and if so, output the required state $s_i$ for each machine.

## Input
The first line of the input provides two integers $n$ and $m$, representing the number of machines and the number of safety interlocks, respectively. The facility has physical space for up to $100,000$ machines, and there is always at least one installed. The safety grid can support a maximum of $200,000$ interlocks, though it can also operate with none at all.

The next $m$ lines each contain two non-zero integers $c_1$ and $c_2$. These represent the two signal feeds for that interlock. The absolute value of any feed will never exceed the number of installed machines $n$.

## Output
If it is impossible to configure all $n$ machines without causing a shutdown, output a single line with the word `NO`.

If a safe configuration is possible, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{0, 1\}$) to specify the chosen state for each machine from 1 to $n$.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
There might be several safe configurations; outputting any valid one is correct. A single machine can provide signal feeds to multiple interlocks.
</STATEMENT>
<RATIONALE>
Removed the explicit boolean logic ("both feeds carry a high voltage") that models were directly translating into 2-SAT NAND clauses. Replaced it with an algebraic inequality over {-1, 1} that is mathematically identical but requires algebraic simplification (dividing by $|c_1 c_2|$ and analyzing the sign) to reveal the excluded state combination. Also applied S07 by expressing the numeric bounds of $n$ and $m$ as physical capacities in the facility description.
</RATIONALE>
<PRESERVED_ANSWER>
Dividing the inequality by $|c_1 c_2|$ yields $f_{|c_1|}\text{sgn}(c_1) + f_{|c_2|}\text{sgn}(c_2) \le 0$, which is violated if and only if both terms are $+1$; this perfectly matches the original condition where shutdown occurs if and only if both specific states are simultaneously active.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem remains identical to 2-SAT (each interlock still forbids exactly one pair of states out of four), meaning it is still solvable in O(n+m) via strongly connected components on the implication graph.
</PRESERVED_CLASS>
<RISK>
The most likely way this could be judged ambiguous is if a reader assumes the formula must be evaluated strictly using 32-bit integers (which would overflow for $10^5 \times 10^5$), but this is a mathematical criterion describing the system, not a strict data type requirement.
</RISK>
