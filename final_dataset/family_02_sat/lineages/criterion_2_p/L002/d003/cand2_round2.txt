<STATEMENT>
# Problem B — Production Line Configuration

Time limit: 1 s   Memory limit: 256 MB

## Description

A manufacturing plant operates $n$ distinct machines, each requiring calibration to either mode 1 or mode 0. To guarantee operational stability, the plant uses $m$ safety interlocks. Each interlock monitors a pair of reference conditions.

An interlock triggers a plant shutdown if and only if both of its monitored reference conditions are simultaneously violated by the current machine calibrations. Safe operation requires configuring the plant such that no interlock triggers a shutdown.

Determine if there is a way to calibrate all $n$ machines to prevent any shutdowns. If such a plant-wide calibration is possible, provide one. Otherwise, indicate that a safe configuration is impossible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the following $m$ lines contains two non-zero integers $l_1$ and $l_2$, where $|l_i| \le n$. These describe the reference conditions for an interlock. 
For a given $l_i$, if $l_i > 0$, the reference condition is that machine $l_i$ is in mode 1. If $l_i < 0$, the reference condition is that machine $|l_i|$ is in mode 0. 

## Output
If there is no valid way to calibrate the machines without triggering a shutdown, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) representing the chosen mode for each machine from 1 to $n$. Any valid configuration is accepted.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid calibrations may exist; any one is accepted. The same machine may be monitored by multiple interlocks. An interlock's two conditions may even monitor the same machine, potentially in the same or opposite modes.
</STATEMENT>
<RATIONALE>
The explicit implication wording ("whenever A fails, B is required") was removed, as it allowed models to directly write directed edges `~A -> B` and `~B -> A` without recognizing the boolean logic. Instead, the constraint is framed as prohibiting the joint violation of both reference conditions. This forces models to independently deduce that `not (fail A and fail B)` is equivalent to the 2-SAT clause `A or B`, requiring genuine algorithmic modeling rather than surface translation. The numeric bounds were restored exactly as they appeared in the seed.
</RATIONALE>
<PRESERVED_ANSWER>
The logical requirement that an interlock must not have both conditions violated is De Morgan's equivalent to requiring at least one condition to be satisfied, which exactly matches the seed's implication rules.
</PRESERVED_ANSWER>
