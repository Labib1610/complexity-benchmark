This is the classic 2-SAT problem. Each interlock gives a clause: we must avoid the situation where both conditions are violated. So the clause is: (condition 1 satisfied) OR (condition 2 satisfied).

Let me formalize. A literal $c_i$: if $c_i > 0$, it means "machine $c_i$ is in mode 1". If $c_i < 0$, it means "machine $|c_i|$ is in mode 0".

A condition is violated if the machine is not in the specified mode. So for $c_i > 0$, violation means machine $c_i$ is in mode 0. For $c_i < 0$, violation means machine $|c_i|$ is in mode 1.

The interlock trips if both conditions are violated. So we need: NOT(violation of c1 AND violation of c2) = (satisfaction of c1) OR (satisfaction of c2).

So each interlock is a clause (l1 ∨ l2) where l1 is the literal for c1 and l2 is the literal for c2.

def main():

        if c1 > 0:
