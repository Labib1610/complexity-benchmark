We can model each microservice as a boolean variable:  
- `True` (or `1`) means Route 1  
- `False` (or `0`) means Route 0  

Each rule is a clause of the form:  
`(l1 == target1) OR (l2 == target2)`  

This is a **2-SAT** problem. We can solve it using implication graph and SCC (Strongly Connected Components).  

For each variable `x` (microservice), we create two nodes:  
- `2*i` for `x = True`  
- `2*i+1` for `x = False`  

A clause `(a OR b)` becomes:  
`(not a -> b)` and `(not b -> a)`  

Then we check if any variable and its negation are in the same SCC. If so, it's unsatisfiable. Otherwise, we assign values based on topological order of SCCs.

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(1 << 20)
input = sys.stdin.readline

n, m = map(int, input().split())
N = 2 * n
g = [[] for _ in range(N)]
gr = [[] for _ in range(N)]

def node(var):
    # var is int, positive means True, negative means False
    if var > 0:
        return 2 * (var - 1)      # True node
    else:
        return 2 * (-var - 1) + 1 # False node

def add_imp(u, v):
    g[u].append(v)
    gr[v].append(u)

for _ in range(m):
    a, b = map(int, input().split())
    # (a OR b) => (!a -> b) and (!b -> a)
    na = -a
    nb = -b
    add_imp(node(na), node(b))
    add_imp(node(nb), node(a))

# Kosaraju's SCC
visited = [False] * N
order = []

def dfs1(u):
    visited[u] = True
    for v in g[u]:
        if not visited[v]:
            dfs1(v)
    order.append(u)

for i in range(N):
    if not visited[i]:
        dfs1(i)

comp = [-1] * N

def dfs2(u, cid):
    comp[u] = cid
    for v in gr[u]:
        if comp[v] == -1:
            dfs2(v, cid)

cid = 0
for u in reversed(order):
    if comp[u] == -1:
        dfs2(u, cid)
        cid += 1

# Check satisfiability
for i in range(n):
    if comp[2*i] == comp[2*i+1]:
        print("NO")
        sys.exit()

print("YES")
# Assign values: if comp[True] > comp[False] then True, else False
res = []
for i in range(n):
    if comp[2*i] > comp[2*i+1]:
        res.append('1')
    else:
        res.append('0')
print(' '.join(res))
```
