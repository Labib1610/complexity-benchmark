<METHOD_NAME>linear_inequality_obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit conditional implication logic ("if not A then B") with a mathematically equivalent linear inequality constraint ($L_1 + L_2 \le 1$) over binary variables. This mimics a load-balancing or ILP problem, forcing the model to algebraically deduce the 2-SAT structure rather than pattern-matching the implication edges from the text.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Phase 3: Deployment Planner

Time limit: 1 s   Memory limit: 256 MB

## Description
You are managing the deployment of $n$ microservices. Each microservice $i$ (from $1$ to $n$) must be deployed to exactly one of two environments: the Primary Environment (represented by $s_i = 1$) or the Secondary Environment (represented by $s_i = 0$).

The architecture includes $m$ redundancy protocols to ensure reliability. Each protocol specifies two non-zero integer parameters, $l_1$ and $l_2$. The absolute value of a parameter identifies the microservice it monitors.

A parameter $v$ generates a network load $L(v)$ depending on the environment of microservice $|v|$:
- If $v > 0$, the load is $L(v) = 1 - s_{|v|}$.
- If $v < 0$, the load is $L(v) = s_{|v|}$.

To prevent a bottleneck, every redundancy protocol must be satisfied. A protocol with parameters $l_1$ and $l_2$ is satisfied if and only if the total network load generated by its two parameters does not exceed 1:
$$ L(l_1) + L(l_2) \le 1 $$

Your task is to determine whether there exists a global deployment assignment $s_1, s_2, \dots, s_n$ such that absolutely all $m$ redundancy protocols are satisfied.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of microservices and the number of redundancy protocols.

Each of the following $m$ lines provides a protocol as two non-zero integers $l_1$ and $l_2$ ($1 \le |l_i| \le n$).

## Output
If no valid global assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ separated by spaces. Print $s_i = 1$ if microservice $i$ is allocated to the Primary Environment, and $s_i = 0$ if it is allocated to the Secondary Environment. Any valid assignment is accepted.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid assignments may exist; any one is accepted. The same microservice ID may appear in multiple protocols, and even within the same protocol. If $m = 0$, any assignment is valid.
</STATEMENT>
<RATIONALE>
The previous version used a conditional failover rule ("if allocation contradicts the first parameter, it is forced to comply with the second"), which directly handed the models the directed implication edges ($ \neg A \implies B $) needed to build the 2-SAT graph. This rewrite replaces that affordance with an algebraically equivalent linear inequality over binary variables ($L_1 + L_2 \le 1$). To solve it efficiently, models must now deduce that this inequality encodes a boolean OR constraint, bridging the gap from a load-balancing representation to a 2-SAT formulation.
</RATIONALE>
<PRESERVED_ANSWER>
The linear inequality $L(l_1) + L(l_2) \le 1$ restricts the load variables (which evaluate to 0 or 1) from both being 1, which is logically equivalent to the original requirement that at least one parameter matches its target environment, preserving all valid assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT because the problem constraint mathematically simplifies to a conjunction of two-literal disjunctions, solvable in $O(n+m)$ time using the implication graph and Kosaraju's algorithm.
</PRESERVED_CLASS>
