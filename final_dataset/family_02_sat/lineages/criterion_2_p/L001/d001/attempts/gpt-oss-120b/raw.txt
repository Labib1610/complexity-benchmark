**Solution Explanation**

For every hub `i` we have a Boolean variable  

```
xi = 1   – hub i is ACTIVE
xi = 0   – hub i is DORMANT
```

A routing protocol gives two literals, e.g. `3` (hub 3 must be ACTIVE) or `‑5`
(hub 5 must be DORMANT).  
The protocol is satisfied iff at least one of its literals is true, i.e. the
clause  

```
(l1  OR  l2)
```

The whole task is exactly the classic **2‑SAT** problem.

--------------------------------------------------------------------

#### 1.   Implication graph

For a clause `(a OR b)` we add the two implications  

```
¬a → b
¬b → a
```

If all implications can be satisfied simultaneously, a global assignment exists.

We build a directed graph with `2·n` vertices:

```
vertex 2*i     – literal  xi   (xi = 1)
vertex 2*i + 1 – literal ¬xi   (xi = 0)
```

`neg(v) = v ^ 1` (toggle the last bit).

For a literal `l`

```
if l > 0 :   var = l-1 , vertex = 2*var          (xi)
else       : var = -l-1, vertex = 2*var + 1      (¬xi)
```

For each protocol we add the two edges described above.

--------------------------------------------------------------------

#### 2.   Strongly connected components

In the implication graph a 2‑SAT instance is **unsatisfiable** iff a variable
and its negation belong to the same strongly connected component (SCC).

We compute SCCs with Kosaraju’s algorithm (two depth‑first passes).  
`order` – vertices in order of finishing times of the first DFS.  
Second DFS on the reversed graph processes vertices in reverse `order`,
assigning a component id `comp[v]`.

--------------------------------------------------------------------

#### 3.   Constructing a solution

The SCC‑graph is a DAG. In Kosaraju’s order, components are obtained in
*reverse topological order*: a component discovered later cannot reach an
earlier one.

Therefore for each variable `i`

```
if comp[ true(i) ] > comp[ false(i) ] : xi = 1
else                                   : xi = 0
```

(The component with larger id appears later in the topological order and
must be set to false, the opposite literal to true.)

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct assignment iff one
exists, otherwise prints “NO”.

---

##### Lemma 1  
For every clause `(a OR b)` the added edges `¬a → b` and `¬b → a` are
logically equivalent to the clause.

**Proof.**  
If `a` is true, the clause is satisfied regardless of `b`.  
If `a` is false (`¬a` true) the edge forces `b` to be true, satisfying the
clause. Symmetrically for `b`. ∎



##### Lemma 2  
If some variable `xi` and its negation belong to the same SCC, the instance
has no satisfying assignment.

**Proof.**  
Inside an SCC each vertex reaches every other, therefore `xi → ¬xi` and
`¬xi → xi`. Any assignment that makes `xi = 1` forces `¬xi = 1`, contradiction,
and similarly for `xi = 0`. Hence unsatisfiable. ∎



##### Lemma 3  
If for every `i` the two literals are in different SCCs, the assignment defined
by  

```
xi = 1  iff  comp[xi] > comp[¬xi]
```

satisfies all implications, thus all clauses.

**Proof.**  
Consider any edge `u → v`. In the SCC‑DAG there is a directed edge from
`comp[u]` to `comp[v]`. Topological order guarantees `comp[u] ≤ comp[v]`.  
If `comp[u] > comp[v]` the edge would go backward, impossible.  
Hence `comp[u] ≤ comp[v]`.  

If `u` is assigned true, then `comp[u] > comp[¬u]`. Because `comp[u] ≤ comp[v]`,
we also have `comp[v] > comp[¬u]`. Since `comp[v]` and `comp[¬v]` are different,
`comp[v] > comp[¬v]` holds, i.e. `v` is true. Thus every true premise forces a
true conclusion, satisfying all implications. By Lemma&nbsp;1 the original
clauses are satisfied. ∎



##### Lemma 4  
If the algorithm outputs “YES”, the printed assignment satisfies all routing
protocols.

**Proof.**  
“YES” is printed only when for every `i` the two literals lie in different SCCs.
The algorithm then uses the assignment of Lemma&nbsp;3, which satisfies all
implications and therefore all clauses. ∎



##### Lemma 5  
If the algorithm outputs “NO”, no satisfying assignment exists.

**Proof.**  
“NO” is printed exactly when some variable and its negation share an SCC.
By Lemma&nbsp;2 any assignment would violate an implication, hence the original
instance is unsatisfiable. ∎



##### Theorem  
The algorithm is correct.

**Proof.**  
*Soundness*: By Lemma&nbsp;4, whenever “YES” is printed the produced assignment
is valid.  
*Completeness*: If a valid assignment exists, the implication graph cannot
contain a variable together with its negation in the same SCC (otherwise the
assignment would be impossible). Hence the algorithm will not output “NO”.
It will output “YES” and, by Lemma&nbsp;3, the constructed assignment is also
valid. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Building the graph*: `O(m)` edges, `O(n + m)` memory.  
*Kosaraju*: two DFS traversals – `O(n + m)` time, `O(n + m)` memory.  
*Assignment*: `O(n)`.

Overall  

```
Time   : O(n + m)   ≤ 3·10^5
Memory : O(n + m)   ≤ 3·10^5  integers  (well below limits)
```

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    N = 2 * n
    g = [[] for _ in range(N)]
    rg = [[] for _ in range(N)]

    def lit_to_node(l: int) -> int:
        if l > 0:
            v = l - 1
            return 2 * v          # xi
        else:
            v = -l - 1
            return 2 * v + 1      # ¬xi

    for _ in range(m):
        a = int(next(it))
        b = int(next(it))
        u = lit_to_node(a)
        v = lit_to_node(b)
        nu = u ^ 1
        nv = v ^ 1
        # ¬a -> b
        g[nu].append(v)
        rg[v].append(nu)
        # ¬b -> a
        g[nv].append(u)
        rg[u].append(nv)

    sys.setrecursionlimit(1 << 25)
    visited = [False] * N
    order = []

    def dfs(v: int):
        stack = [(v, 0)]
        while stack:
            node, state = stack.pop()
            if state == 0:
                if visited[node]:
                    continue
                visited[node] = True
                stack.append((node, 1))
                for to in g[node]:
                    if not visited[to]:
                        stack.append((to, 0))
            else:
                order.append(node)

    for v in range(N):
        if not visited[v]:
            dfs(v)

    comp = [-1] * N
    cid = 0
    for v in reversed(order):
        if comp[v] != -1:
            continue
        stack = [v]
        comp[v] = cid
        while stack:
            node = stack.pop()
            for to in rg[node]:
                if comp[to] == -1:
                    comp[to] = cid
                    stack.append(to)
        cid += 1

    assignment = [0] * n
    for i in range(n):
        if comp[2 * i] == comp[2 * i + 1]:
            print("NO")
            return
        assignment[i] = 1 if comp[2 * i] > comp[2 * i + 1] else 0

    print("YES")
    print(' '.join(map(str, assignment)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
