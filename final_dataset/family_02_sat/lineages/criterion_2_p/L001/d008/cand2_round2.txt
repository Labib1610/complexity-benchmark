<STATEMENT>
# Problem B — Logistics Safeguards

Time limit: 1 s   Memory limit: 256 MB

## Description

Management of a logistics network must finalize the operational schedule for its $n$ transit hubs. Every hub $i$ must be assigned a phase state $s_i \in \{0, 1\}$.

Safety inspectors have completed $m$ vulnerability assessments. Each assessment provides two non-zero integer parameters $l_1$ and $l_2$. 

To evaluate an assessment under a given schedule, a diagnostic probe is initialized in the **Active** state. The probe then sequentially processes parameter $l_1$, followed by parameter $l_2$. For any parameter $v$, the probe updates its state according to the phase state $s_{|v|}$ of the hub designated by its absolute value $|v|$. The transition rules are applied as follows:

- If $v > 0$:
  - When $s_{|v|} = 1$, an **Active** probe remains **Active**, and a **Degraded** probe becomes **Active**.
  - When $s_{|v|} = 0$, an **Active** probe becomes **Degraded**, and a **Degraded** probe becomes **Failed**.
- If $v < 0$:
  - When $s_{|v|} = 0$, an **Active** probe remains **Active**, and a **Degraded** probe becomes **Active**.
  - When $s_{|v|} = 1$, an **Active** probe becomes **Degraded**, and a **Degraded** probe becomes **Failed**.

A schedule is considered safe if, for every assessment, the probe does not end in the **Failed** state after processing both $l_1$ and $l_2$. Your task is to determine whether it is possible to assign a phase state $s_i \in \{0, 1\}$ to every hub such that a safe schedule is achieved. If such a schedule can be formed, you must provide one.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$). For clarity, $n$ is up to 100000 and $m$ is up to 200000.

Each of the following $m$ lines provides two non-zero integers $l_1$ and $l_2$ ($1 \le |l_i| \le n$), representing the two parameters of a vulnerability assessment. 

Note that $l_1$ and $l_2$ in an assessment may refer to the same hub, with the same or opposite signs. A hub may appear in any number of assessments, and identical assessments may repeat.

## Output
If no safe schedule is possible, print a single line NO.

Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each being 0 or 1, representing the phase state $s_i$ for hub $i$) that form a valid schedule. Multiple valid schedules may exist; any one is accepted.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

<RATIONALE>
The direct algebraic formula `C(l1) + C(l2) > -(|l1| + |l2|)` was replaced with a 3-state finite automaton processing the two parameters sequentially. This removes the easily parsed linear equation that directly mapped to a 2-SAT boolean disjunction, forcing the model to trace the state transitions to deduce that the "Failed" state is only reached if both parameters fail their respective phase conditions.
</RATIONALE>
<PRESERVED_ANSWER>
The state machine perfectly encodes the original logic: a parameter $v$ fails its condition if $v > 0$ and $s = 0$ or $v < 0$ and $s = 1$, which is exactly when $C(v) = -|v|$; the probe reaches the Failed state if and only if both $l_1$ and $l_2$ fail their conditions, maintaining the exact same valid schedules.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, as each assessment still enforces that at least one of two literal conditions must be met, solvable in linear time using strongly connected components on an implication graph.
</PRESERVED_CLASS>
