# Problem B — Logistics Safeguards

Time limit: 1 s   Memory limit: 256 MB

## Description

Management of a logistics network must finalize the operational schedule for its $n$ transit hubs. Every hub $i$ must be assigned a phase state $s_i \in \{0, 1\}$.

Safety inspectors have completed $m$ vulnerability assessments. Each assessment provides two non-zero integer parameters $l_1$ and $l_2$. 

For each assessment, a diagnostic sequence is executed to compute a final integer code $Z$. The code $Z$ starts at $0$. The sequence processes the first parameter $l_1$, then the second parameter $l_2$.

When processing a parameter $v$, the code $Z$ is updated based on the current phase $s_{|v|}$ of its designated hub $|v|$. The update rule is:
- If $v > 0$ and $s_{|v|} = 0$, the new code is $2Z + 1$.
- If $v > 0$ and $s_{|v|} = 1$, the code remains $Z$.
- If $v < 0$ and $s_{|v|} = 1$, the new code is $2Z + 1$.
- If $v < 0$ and $s_{|v|} = 0$, the code remains $Z$.

An assessment is considered *stable* if its final diagnostic code $Z$ after processing both parameters is strictly less than $3$. A critical failure occurs if there is at least one assessment that is not stable. 

Your task is to determine whether it is possible to assign a phase state $s_i \in \{0, 1\}$ to every hub such that zero critical failures occur (i.e., all $m$ assessments are stable). If such a schedule can be formed, you must provide one.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$). For clarity, $n$ is up to 100000 and $m$ is up to 200000.

Each of the following $m$ lines provides two non-zero integers $l_1$ and $l_2$ ($1 \le |l_i| \le n$), representing the two parameters of a vulnerability assessment. 

Note that $l_1$ and $l_2$ in an assessment may refer to the same hub, with the same or opposite signs. A hub may appear in any number of assessments, and identical assessments may repeat.

## Output
If no safe schedule is possible, print a single line NO.

Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each being 0 or 1, representing the phase state $s_i$ for hub $i$) that form a valid schedule. Multiple valid schedules may exist; any one is accepted.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

<METHOD_DESCRIPTION>I replaced the clean algebraic inequality C(v) = v(2s-1) with an asymmetric multi-step state machine. The state Z updates via Z = 2Z + 1 when a parameter's condition is violated, and remains unchanged otherwise. While mathematically equivalent to checking if both literals are false (which yields Z=3), the sequential recurrence hides the boolean disjunction and prevents models from trivially factoring the problem into 2-SAT clauses via surface-level algebraic pattern matching.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<RATIONALE>
The models previously bypassed genuine reasoning by directly pattern-matching the algebraic inequality `C(l1) + C(l2) > -(|l1| + |l2|)` into a 2-SAT boolean disjunction. I removed the equation entirely and replaced it with a multi-step state machine recurrence (`Z = 2Z + 1`). This forces the models to trace the state space, evaluate the final values for all four truth assignments, and independently deduce the logical constraint, preventing surface-level shortcuts.
</RATIONALE>
<PRESERVED_ANSWER>
The state machine yields Z=3 only when both parameters trigger the `2Z+1` update (the "false" condition), and yields Z < 3 in all other cases, which is logically identical to the original disjunction requirement.
</PRESERVED_ANSWER>
