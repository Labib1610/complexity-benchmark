# Problem B — Logistics Safeguards

Time limit: 1 s
Memory limit: 256 MB

## Description

Management of a logistics network must finalize the operational schedule for its $n$ transit hubs. Every hub $i$ must be assigned a phase state $s_i \in \{0, 1\}$.

Safety inspectors have completed $m$ vulnerability assessments. Each assessment involves a diagnostic probe that sequentially tests two non-zero integer parameters, $l_1$ and then $l_2$. 

The probe begins each assessment in the **Active** state. It first processes parameter $l_1$, updating its state according to the rules below. Then, starting from that updated state, it processes parameter $l_2$ using the same rules. For any parameter $v$, the state transition depends on the phase $s_{|v|}$ of the target hub $|v|$ and whether $v$ is positive or negative:

- If $v > 0$:
  - When $s_{|v|} = 1$, an **Active** probe remains **Active**, a **Degraded** probe recovers to **Active**, and a **Failed** probe remains **Failed**.
  - When $s_{|v|} = 0$, an **Active** probe drops to **Degraded**, a **Degraded** probe drops to **Failed**, and a **Failed** probe remains **Failed**.
- If $v < 0$:
  - When $s_{|v|} = 1$, an **Active** probe drops to **Degraded**, a **Degraded** probe drops to **Failed**, and a **Failed** probe remains **Failed**.
  - When $s_{|v|} = 0$, an **Active** probe remains **Active**, a **Degraded** probe recovers to **Active**, and a **Failed** probe remains **Failed**.

An assessment is considered *stable* as long as the probe does not end in the **Failed** state after processing both $l_1$ and $l_2$. A critical failure occurs if there is at least one assessment that ends with a **Failed** probe. 

Your task is to determine whether it is possible to assign a phase state $s_i \in \{0, 1\}$ to every hub such that zero critical failures occur (i.e., all $m$ assessments are stable). If such a schedule can be formed, you must provide one.

## Input

The first line contains two integers $n$ and $m$. The number of transit hubs $n$ is at most the number of centimeters in one kilometer. The number of completed vulnerability assessments $m$ is at most twice this limit. You are guaranteed $1 \le n$ and $0 \le m$.

Each of the following $m$ lines provides two non-zero integers $l_1$ and $l_2$ ($1 \le |l_i| \le n$), representing the two parameters of a vulnerability assessment. 

Note that $l_1$ and $l_2$ in an assessment may refer to the same hub, with the same or opposite signs. A hub may appear in any number of assessments, and identical assessments may repeat.

## Output

If no safe schedule is possible, print a single line NO.

Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each being 0 or 1, representing the phase state $s_i$ for hub $i$) that form a valid schedule. Multiple valid schedules may exist; any one is accepted.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```
