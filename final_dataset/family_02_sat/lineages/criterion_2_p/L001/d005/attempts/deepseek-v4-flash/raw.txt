We can model each hub as a boolean variable, and each assessment as a constraint.  
The condition:

\[
I(l_1) + I(l_2) \ge 0
\]

can be rewritten depending on the signs of \(l_1\) and \(l_2\).

Let’s define \(x_i = s_i\) (0 or 1).  
Then \(q_i = 2s_i - 1\) is \(+1\) if \(s_i=1\), \(-1\) if \(s_i=0\).

For a parameter \(v\):

- If \(v > 0\), \(I(v) = q_{|v|}\)
- If \(v < 0\), \(I(v) = -q_{|v|}\)

So the constraint becomes:

- If both positive: \(q_a + q_b \ge 0\) → at least one is \(+1\) → \(s_a \lor s_b\)
- If both negative: \(-q_a - q_b \ge 0\) → \(q_a + q_b \le 0\) → at least one is \(-1\) → \(\neg s_a \lor \neg s_b\)
- If one positive, one negative: \(q_a - q_b \ge 0\) → \(q_a \ge q_b\) → if \(s_b=1\) then \(s_a=1\) → \(\neg s_b \lor s_a\)

These are all 2-SAT clauses.  
We can solve with implication graph and SCC.

```python
import sys
sys.setrecursionlimit(1 << 20)

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    N = 2 * n  # nodes: 2*i = false, 2*i+1 = true

    g = [[] for _ in range(N)]
    gr = [[] for _ in range(N)]

    def add_imp(u, v):
        g[u].append(v)
        gr[v].append(u)

    # variable i: 0..n-1
    # node for x_i true: 2*i+1
    # node for x_i false: 2*i

    for _ in range(m):
        l1, l2 = map(int, input().split())
        a = abs(l1) - 1
        b = abs(l2) - 1
        sign1 = 1 if l1 > 0 else 0
        sign2 = 1 if l2 > 0 else 0

        # Clause: (x_a == sign1) OR (x_b == sign2)
        # Equivalent implications:
        # (x_a != sign1) -> (x_b == sign2)
        # (x_b != sign2) -> (x_a == sign1)

        # node for (x == val): 2*var + val
        # node for (x != val): 2*var + (1-val)

        na = 2*a + sign1
        nb = 2*b + sign2
        not_na = 2*a + (1 - sign1)
        not_nb = 2*b + (1 - sign2)

        add_imp(not_na, nb)
        add_imp(not_nb, na)

    # Kosaraju SCC
    visited = [False] * N
    order = []

    def dfs1(u):
        visited[u] = True
        for v in g[u]:
            if not visited[v]:
                dfs1(v)
        order.append(u)

    for i in range(N):
        if not visited[i]:
            dfs1(i)

    comp = [-1] * N
    def dfs2(u, cid):
        comp[u] = cid
        for v in gr[u]:
            if comp[v] == -1:
                dfs2(v, cid)

    cid = 0
    for u in reversed(order):
        if comp[u] == -1:
            dfs2(u, cid)
            cid += 1

    for i in range(n):
        if comp[2*i] == comp[2*i+1]:
            print("NO")
            return

    print("YES")
    res = []
    for i in range(n):
        # If false node has higher comp id, assign true (standard 2-SAT assignment)
        if comp[2*i] > comp[2*i+1]:
            res.append('1')
        else:
            res.append('0')
    print(' '.join(res))

if __name__ == "__main__":
    solve()
```
