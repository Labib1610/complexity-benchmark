# Problem B — Broadcast Band Allocation

Time limit: 1 s   Memory limit: 256 MB

## Description

A regional communications network operates $n$ broadcast towers. For the upcoming season, each tower must be permanently assigned to exactly one of two frequencies: the High-Frequency (HF) band or the Low-Frequency (LF) band.

The network is responsible for providing coverage to $m$ remote communities. Because of mountainous terrain, each community is capable of receiving signals from two specific tower-band configurations. 
These configurations are provided as non-zero signed integers. A positive integer $x$ means tower $x$ operating on the HF band. A negative integer $x$ means tower $|x|$ operating on the LF band.

A community will experience a complete service blackout if and only if the network implements neither of its two receivable configurations in the final allocation. Your objective is to find a system-wide band allocation for all $n$ towers such that zero communities experience a blackout.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of towers and the number of communities.
Each of the following $m$ lines provides two non-zero signed integers $c_1$ and $c_2$ ($|c_i| \le n$), representing the two configurations that the respective community can receive. A positive integer denotes the HF band; a negative integer denotes the LF band.

## Output
If it is impossible to prevent all blackouts, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $b_1, b_2, \dots, b_n$ (each being 0 or 1), representing a valid allocation. Print `1` if tower $i$ is assigned to the HF band, and `0` if it is assigned to the LF band.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid allocations may exist; any one is accepted. The same tower may be part of the configurations for multiple communities.
