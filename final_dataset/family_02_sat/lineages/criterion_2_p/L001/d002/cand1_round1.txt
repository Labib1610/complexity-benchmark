# Problem B — Contingency Safeguards

Time limit: 1 s   Memory limit: 256 MB

## Description

A logistics network operates `n` transit hubs. For the upcoming shift, each hub must be locked into one of two operational states: ACTIVE or DORMANT. 

The network's safety is monitored through `m` contingency plans. Each plan is built around a pair of safeguards. A safeguard is a specific state assigned to a specific hub. A contingency plan breaks down if and only if the network configuration rejects its first safeguard and simultaneously rejects its second safeguard. 

You need to find out if there is a single global configuration for all `n` hubs that prevents all `m` contingency plans from breaking down. If it is possible, provide the configuration; otherwise, declare that the plans are unworkable.

## Input
The first line provides the integers `n` and `m`. The transit authority's hardware registry requires at least one hub and caps the network size `n` at exactly the fifth power of ten. The number of contingency plans `m` can be as low as zero and is limited by the database to double the hardware registry's maximum hub capacity.

Following this are `m` lines, each detailing a contingency plan via two non-zero signed integers `l1` and `l2`. The magnitude of each integer corresponds to a hub index (meaning it is between 1 and `n` inclusive). A positive value means the safeguard requires the hub to be ACTIVE; a negative value means the safeguard requires the hub to be DORMANT.

## Output
If the plans are unworkable, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, output `n` space-separated integers `s1 s2 … sn` to describe your configuration, where `0` means DORMANT and `1` means ACTIVE.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple safe configurations may exist; any one of them will be accepted. A hub index can be referenced in multiple contingency plans.
</STATEMENT>
<RATIONALE>
The explicit disjunctive phrasing "at least one of its two specified conditions is met" has been replaced with its De Morgan equivalent: "breaks down if and only if the network configuration rejects its first safeguard and simultaneously rejects its second safeguard". This forces the model to logically deduce the (A OR B) boolean requirement rather than pattern-matching standard 2-SAT wording. Additionally, the explicit numeric bounds have been replaced with scenario-derived text (e.g., "fifth power of ten") to satisfy the strategy requirements.
</RATIONALE>
<PRESERVED_ANSWER>
The condition for a plan failing is exactly the negation of a disjunction, meaning the configuration must still satisfy at least one of the two safeguards, preserving the exact same valid configurations.
</PRESERVED_ANSWER>

The problem remains exactly 2-SAT, which is solvable in O(n+m) time using strongly connected components on an implication graph.
</PRESERVED_CLASS>
