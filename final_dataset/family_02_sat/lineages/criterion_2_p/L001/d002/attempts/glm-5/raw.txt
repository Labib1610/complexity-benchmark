This is the classic 2-SAT problem. We have $n$ variables (hubs), each with two possible states (ACTIVE = 1, DORMANT = 0). Each contingency plan is a clause of two literals: $(l_1 \lor l_2)$. We need to find a satisfying assignment.

Standard 2-SAT solution:
1. Build the implication graph. For each variable $x_i$, we have two nodes: $x_i$ (true/ACTIVE) and $\neg x_i$ (false/DORMANT). Conventionally, node $2i$ represents $x_i$ and node $2i+1$ represents $\neg x_i$ (or some similar mapping).

2. For each clause $(a \lor b)$, add implications $\neg a \to b$ and $\neg b \to a$.

3. Compute strongly connected components (SCC) using Tarjan's algorithm or Kosaraju's. If $x_i$ and $\neg x_i$ are in the same SCC, output NO.

4. Otherwise, assign each variable: $x_i$ = true if the SCC of $x_i$ comes after the SCC of $\neg x_i$ in topological order (in Tarjan's, components are numbered in reverse topological order, so $x_i$ is true if comp[$x_i$] < comp[$\neg x_i$]).
