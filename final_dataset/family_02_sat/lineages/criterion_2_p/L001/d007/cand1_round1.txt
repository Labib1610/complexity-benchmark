<METHOD_NAME>
Continuous-Domain Clearance Threshold
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the explicit boolean error metric with an algebraic "clearance" function C(v) = v * (2s_{|v|} - 1) that mixes the variable ID, its sign, and its state into a single integer. The stability condition is then defined as a strict inequality where the sum of clearances must exceed the negative sum of their absolute values. This mathematically perfectly encodes a 2-SAT clause (since the minimum possible sum equals the threshold, which happens only when both variables take their "wrong" boolean assignments), but visually resembles a weighted integer linear programming constraint, preventing models from relying on DIMACS pattern matching.
</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Logistics Safeguards

Time limit: 1 s   Memory limit: 256 MB

## Description

Management of a logistics network must finalize the operational schedule for its $n$ transit hubs. Every hub $i$ must be assigned a phase state $s_i \in \{0, 1\}$.

Safety inspectors have completed $m$ vulnerability assessments. Each assessment provides two non-zero integer parameters $l_1$ and $l_2$. 

For any parameter $v$, its operational clearance under a given schedule is determined by the phase state of the hub designated by its absolute value $|v|$. The clearance is calculated as:
$$C(v) = v \cdot (2 s_{|v|} - 1)$$

An assessment with parameters $l_1$ and $l_2$ is considered *stable* if the sum of their operational clearances strictly exceeds the negative sum of their absolute values:
$$C(l_1) + C(l_2) > - (|l_1| + |l_2|)$$

A critical failure occurs if there is at least one assessment that is not stable. Your task is to determine whether it is possible to assign a phase state $s_i \in \{0, 1\}$ to every hub such that zero critical failures occur (i.e., all $m$ assessments are stable). If such a schedule can be formed, you must provide one.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$). For clarity, $n$ is up to 100000 and $m$ is up to 200000.

Each of the following $m$ lines provides two non-zero integers $l_1$ and $l_2$ ($1 \le |l_i| \le n$), representing the two parameters of a vulnerability assessment. 

Note that $l_1$ and $l_2$ in an assessment may refer to the same hub, with the same or opposite signs. A hub may appear in any number of assessments, and identical assessments may repeat.

## Output
If no safe schedule is possible, print a single line NO.

Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each being 0 or 1, representing the phase state $s_i$ for hub $i$) that form a valid schedule. Multiple valid schedules may exist; any one is accepted.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

<RATIONALE>
Removed the explicit boolean error metric and the explicit mapping of positive/negative integers to target states (1/0). Introduced a continuous-looking algebraic function $C(v)$ that evaluates to either $|v|$ or $-|v|$ depending on whether the state aligns with the sign of $v$. The strict inequality check forces models to deduce algebraically that the only way to fail the condition is if both parameters evaluate to their negative extremes, which requires recognizing the underlying 2-SAT structure without explicit boolean keywords.
</RATIONALE>
<PRESERVED_ANSWER>
The function $C(v) = v \cdot (2 s_{|v|} - 1)$ evaluates to $|v|$ if the state $s_{|v|}$ matches the sign of $v$, and $-|v|$ otherwise; the strict inequality $C(l_1) + C(l_2) > -(|l_1| + |l_2|)$ is violated if and only if both $C(l_1) = -|l_1|$ and $C(l_2) = -|l_2|$, making it logically identical to the original "at most one error" clause.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT because the new inequality evaluates to a standard boolean disjunction for each pair of parameters, solvable in $O(n+m)$ time using strongly connected components on the implication graph.
</PRESERVED_CLASS>
