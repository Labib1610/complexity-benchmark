We can model each hub as a boolean variable, and each assessment as a constraint.  
Let’s analyze the stability condition.

We have:

\[
C(v) = v \cdot (2s_{|v|} - 1)
\]

If \(v > 0\), then \(C(v) = 2s_v - 1\) (which is either -1 or +1).  
If \(v < 0\), then \(C(v) = - (2s_{|v|} - 1) = 1 - 2s_{|v|}\).

The condition:

\[
C(l_1) + C(l_2) > -(|l_1| + |l_2|)
\]

Let’s denote \(x = |l_1|\), \(y = |l_2|\).  
We can check the four sign combinations:

- Both positive: \(C(l_1) = 2s_x - 1\), \(C(l_2) = 2s_y - 1\)  
  Sum = \(2s_x + 2s_y - 2\).  
  Condition: \(2s_x + 2s_y - 2 > -(x+y)\) → always true since LHS ≥ -2 and RHS ≤ -2? Actually if x+y ≥ 2, RHS ≤ -2, so always true. If x=y=1, RHS = -2, LHS = -2,0,2 → always ≥ -2, so always true. So both positive always stable.

- Both negative: \(C(l_1) = 1 - 2s_x\), \(C(l_2) = 1 - 2s_y\)  
  Sum = \(2 - 2s_x - 2s_y\).  
  Condition: \(2 - 2s_x - 2s_y > -(x+y)\) → always true similarly.

- One positive, one negative:  
  Suppose \(l_1 > 0\), \(l_2 < 0\).  
  \(C(l_1) = 2s_x - 1\), \(C(l_2) = 1 - 2s_y\).  
  Sum = \(2s_x - 2s_y\).  
  Condition: \(2s_x - 2s_y > -(x+y)\).  
  Since \(x,y \ge 1\), RHS ≤ -2.  
  LHS can be -2, 0, 2.  
  If LHS = -2, condition is \(-2 > -(x+y)\) → \(x+y > 2\).  
  If \(x+y = 2\) (i.e., x=y=1), then \(-2 > -2\) is false.  
  So the only unstable case is when one is positive, one is negative, and both refer to the same hub (x=y=1).  
  That means: \(l_1 = 1, l_2 = -1\) or \(l_1 = -1, l_2 = 1\) for the same hub.

Thus, the only constraints that matter are of the form:  
\((a, -a)\) or \((-a, a)\) for some hub \(a\).  
These require \(s_a\) such that \(2s_a - 2(1-s_a) > -2\)? Let’s check:

For \(l_1 = a, l_2 = -a\):  
Sum = \(2s_a - 2(1-s_a) = 4s_a - 2\).  
Condition: \(4s_a - 2 > -2a\)? Wait, careful:  
Actually \(x = a, y = a\), so RHS = \(-2a\).  
Condition: \(4s_a - 2 > -2a\).  
If \(a=1\): \(4s_a - 2 > -2\) → \(4s_a > 0\) → \(s_a = 1\).  
If \(a>1\): always true because LHS ≥ -2, RHS ≤ -4.

So the only real constraints are for assessments of the form \((1, -1)\) or \((-1, 1)\) for the same hub.  
That means: for each hub, if there is an assessment \((1, -1)\) or \((-1, 1)\), we must set \(s=1\).  
If there is also an assessment \((-1, 1)\)? That’s the same constraint.  
But what about \((1,1)\) and \((-1,-1)\)? Those are always stable, so no constraint.

Thus the problem reduces to:  
For each hub, if it appears in any assessment of type \((1, -1)\) or \((-1, 1)\), set \(s=1\).  
If a hub has both \((1, -1)\) and \((-1, 1)\)? That’s still just \(s=1\).  
No conflict possible, so answer is always YES unless there is a contradiction?  
Wait, is there any case where we must set \(s=0\)?  
From the analysis, only \((1,-1)\) forces \(s=1\).  
There is no constraint forcing \(s=0\).  
So answer is always YES, with all such hubs set to 1, others arbitrary (say 0).

Let’s verify with examples:  
Example 1:  
(1,2) → both positive → always stable.  
(-1,-2) → both negative → always stable.  
So no constraints → YES, any assignment works. Output 1 0 works.

Example 2:  
(1,1) → both positive → always stable.  
(-1,-1) → both negative → always stable.  
So no constraints → YES? But output says NO.  
Wait, let’s re-check:  
For (1,1): \(C(1)+C(1) = (2s_1-1)+(2s_1-1) = 4s_1-2\).  
Condition: \(4s_1-2 > -2\) → \(4s_1 > 0\) → \(s_1=1\).  
Ah! I missed that: both positive with same hub and value 1 gives a constraint!  
Let’s redo carefully.

We must check all cases where \(x+y\) is small.

General condition:  
\(C(l_1)+C(l_2) > -(x+y)\).

Let’s enumerate all sign combos:

1. Both positive:  
Sum = \(2s_x - 1 + 2s_y - 1 = 2s_x + 2s_y - 2\).  
Condition: \(2s_x + 2s_y - 2 > -(x+y)\).  
If \(x+y \ge 3\), RHS ≤ -3, LHS ≥ -2 → always true.  
If \(x+y = 2\) (x=y=1): condition: \(2s_1+2s_1-2 > -2\) → \(4s_1 - 2 > -2\) → \(4s_1 > 0\) → \(s_1=1\).  
So (1,1) forces \(s_1=1\).

2. Both negative:  
Sum = \(1-2s_x + 1-2s_y = 2 - 2s_x - 2s_y\).  
Condition: \(2 - 2s_x - 2s_y > -(x+y)\).  
If \(x+y \ge 3\), RHS ≤ -3, LHS ≥ -2 → always true.  
If \(x+y=2\): condition: \(2 - 4s_1 > -2\) → \(4 - 4s_1 > 0\) → \(s_1 < 1\) → \(s_1=0\).  
So (-1,-1) forces \(s_1=0\).

3. One positive, one negative:  
Sum = \(2s_x - 1 + 1 - 2s_y = 2s_x - 2s_y\).  
Condition: \(2s_x - 2s_y > -(x+y)\).  
If \(x+y \ge 3\), RHS ≤ -3, LHS ≥ -2 → always true.  
If \(x+y=2\) (x=y=1): condition: \(2s_1 - 2s_1 = 0 > -2\) → always true.  
So no constraint from (1,-1) or (-1,1) when same hub? Wait, that contradicts earlier. Let’s check:  
For (1,-1): \(C(1)=2s_1-1\), \(C(-1)=1-2s_1\), sum = 0. Condition: \(0 > -2\) → true. So indeed no constraint.  
So my earlier analysis was wrong: (1,-1) is always stable.

Thus the only constraints are:
- (1,1) forces \(s_1=1\)
- (-1,-1) forces \(s_1=0\)

If both appear for the same hub, contradiction → NO.

So the problem reduces to:  
For each hub, check if it has (1,1) and (-1,-1) assessments.  
If both appear → NO.  
Otherwise, set \(s=1\) if (1,1) appears, \(s=0\) if (-1,-1) appears, else arbitrary.

Let’s verify with example 2:  
Hub 1 has (1,1) and (-1,-1) → contradiction → NO. Correct.

Example 1:  
Hub 1: (1,2) → not (1,1) or (-1,-1). Hub 2: (1,2) and (-1,-2) → not those. So no constraints → YES.

Thus solution is simple.

Implementation:  
- Read n, m.  
- For each assessment, if l1 == l2 == 1 → mark hub 1 as must be 1.  
- If l1 == l2 == -1 → mark hub 1 as must be 0.  
- If both marks for same hub → NO.  
- Else output YES and assign accordingly.

But wait: what about assessments like (1, -1) with different hubs?  
Example: (1, -2): x=1, y=2, sum = 2s_1 - 2s_2, RHS = -3, always true.  
So no constraint.

What about (2,2)? x+y=4, always true.  
(2,-2)? sum = 2s_2 - 2s_2 = 0 > -4 → true.

So indeed only (1,1) and (-1,-1) matter.

Let’s code it.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    must1 = [False] * (n + 1)
    must0 = [False] * (n + 1)
    for _ in range(m):
        a, b = map(int, input().split())
        if a == 1 and b == 1:
            must1[1] = True
        elif a == -1 and b == -1:
            must0[1] = True
    for i in range(1, n + 1):
        if must1[i] and must0[i]:
            print("NO")
            return
    print("YES")
    res = []
    for i in range(1, n + 1):
        if must1[i]:
            res.append("1")
        elif must0[i]:
            res.append("0")
        else:
            res.append("0")
    print(" ".join(res))

if __name__ == "__main__":
    main()
```
