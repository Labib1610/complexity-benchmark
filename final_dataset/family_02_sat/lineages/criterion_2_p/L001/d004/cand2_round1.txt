<STATEMENT>
# Problem B — Sparse Hyperplane Classifier

Time limit: 1 s   Memory limit: 256 MB

## Description

A data science team is training a linear classifier with binary weights. The model has $n$ features, and the learned weight vector must be $X \in \{-1, 1\}^n$.

The training dataset consists of $m$ critical data points. To achieve zero classification error on this critical set, the weight vector must satisfy the condition:
$C X \ge 0$
where $C$ is an $m \times n$ matrix representing the dataset, and the inequality applies element-wise to the resulting $m$-dimensional column vector (i.e., every element of the product vector must be non-negative).

Because the dataset is extremely sparse, each row of $C$ is generated from exactly two non-zero feature indices, provided in the input as $l_1$ and $l_2$.
For the $i$-th row of $C$ (where $1 \le i \le m$):
- Initially, all elements in the row are 0.
- If $l_1 > 0$, we add 1 to the $|l_1|$-th column of the row.
- If $l_1 < 0$, we subtract 1 from the $|l_1|$-th column of the row.
- We then repeat this exact update for $l_2$: if $l_2 > 0$, we add 1 to the $|l_2|$-th column; if $l_2 < 0$, we subtract 1 from the $|l_2|$-th column.

Note that $l_1$ and $l_2$ may refer to the same feature index, which can result in a matrix element being exactly 2, -2, or 0.

Your task is to determine whether there exists a valid binary weight vector $X \in \{-1, 1\}^n$ that correctly classifies all $m$ data points. If it exists, you must output one such vector.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$).

Each of the following $m$ lines provides two non-zero integers $l_1$ and $l_2$ ($1 \le |l_i| \le n$), representing the feature updates for that row. 

## Output
If no such vector $X$ exists, print a single line NO.

Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ representing the components of $X$. To conform to the team's legacy format, print 1 if $X_k = 1$, and print 0 if $X_k = -1$. Multiple valid vectors may exist; any one is accepted.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was completely reframed from a boolean logic/scheduling scenario into a linear algebra and machine learning scenario. By representing the 2-SAT clauses as a sparse system of linear inequalities over $\{-1, 1\}$, models relying on pattern matching will likely misidentify the problem as an Integer Linear Programming (ILP) or Perceptron training task, leading to inefficient algorithms like backtracking or gradient descent. To succeed, a model must algebraically analyze the sparse rows and deduce the isomorphism to 2-SAT.
</RATIONALE>
<PRESERVED_ANSWER>
The linear inequality $C_i X \ge 0$ over $\{-1, 1\}$ with at most two non-zero coefficients of $\pm 1$ is mathematically identical to a boolean OR clause, mapping $X_k=1$ to True and $X_k=-1$ to False, preserving all valid assignments exactly.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT in disguise, meaning it can still be solved in $O(n+m)$ time using Tarjan's or Kosaraju's strongly connected components algorithm on the derived implication graph.
</PRESERVED_CLASS>
