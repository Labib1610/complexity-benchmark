<STATEMENT>
# Problem B — Logistics Safeguards

Time limit: 1 s   Memory limit: 256 MB

## Description

Management of a logistics network must finalize the operational schedule for its $n$ transit hubs. For the upcoming shift, every hub must be calibrated to a specific operational phase, which is represented by either 1 or 0.

Safety inspectors have completed $m$ vulnerability assessments. Each assessment provides two non-zero integers, $l_1$ and $l_2$. 
For any non-zero integer $v$, define its phase requirement $R(v)$ as follows: $R(v) = 1$ if $v > 0$, and $R(v) = 0$ if $v < 0$.
Let $P(x)$ be the finalized phase assigned to hub $x$. 
An individual assessment $(l_1, l_2)$ is considered *exposed* if and only if both of the following conditions are met simultaneously:
- $P(|l_1|) \neq R(l_1)$
- $P(|l_2|) \neq R(l_2)$

A critical failure will occur if even a single assessment is exposed.

Your task is to determine whether it is possible to assign a phase (0 or 1) to every hub such that zero critical failures occur across the network. If such a schedule can be formed, you must provide one.

## Input
The first line contains two integers $n$ and $m$. The number of hubs $n$ ranges from a single hub up to a maximum network size of one hundred thousand. The number of assessments $m$ starts from zero and is capped at two hundred thousand.

Each of the following $m$ lines provides two non-zero integers $l_1$ and $l_2$. The absolute value of any such integer is guaranteed to be between $1$ and $n$ inclusive. 

Note that $l_1$ and $l_2$ in an assessment may refer to the same hub, and may have the same or opposite signs.

## Output
If no safe schedule is possible, print a single line NO.

Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each being 0 or 1) representing the phases $P(1), P(2), \dots, P(n)$ that form a valid schedule. Multiple valid schedules may exist; any one is accepted.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

<RATIONALE>
I replaced the standard 2-SAT boolean vocabulary ("ACTIVE/DORMANT", "rejects both conditions") with an algebraic evaluation rule using an indicator function $R(v)$ and absolute values. This forces the model to algebraically trace the inequality conditions to realize they map directly to boolean disjunctions, defeating models that rely on surface-level keyword pattern matching to identify 2-SAT.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that $P(|l_i|) \neq R(l_i)$ is strictly equivalent to rejecting a required state, so simultaneous violation of both constraints triggers exactly the same failure logic as the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem remains a set of binary variables constrained by a list of pairwise disjunctions, which is exactly 2-SAT and solvable in linear time via strongly connected components.
</PRESERVED_CLASS>
<RISK>
None. The algebraic definitions of $R(v)$ and the exposure condition are mathematically precise and leave no room for alternative interpretations.
</RISK>
