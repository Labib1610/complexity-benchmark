**Solution Explanation**

For a hub `i` we have a binary variable  

```
s_i = 0 or 1
```

For a parameter `v`

```
target(v) = 1   if v > 0
target(v) = 0   if v < 0
```

The calibration error is  

```
E(v) = | s_|v| – target(v) |
```

`E(v) = 0`  ⇔  the statement *“s_|v| equals target(v)”* is true,  
`E(v) = 1`  ⇔  the statement is false.

For an assessment `(l1 , l2)` we need  

```
E(l1) + E(l2) ≤ 1
```

i.e. **at least one of the two statements must be true**.  
That is exactly a 2‑SAT clause:

```
(l1 is true)  OR  (l2 is true)
```

So the whole problem is a classic 2‑SAT instance with `n` variables and `m`
clauses.

--------------------------------------------------------------------

#### 1.   2‑SAT encoding

*Variable* `i` (1‑based) → two literals  

```
i_true   : s_i = 1
i_false  : s_i = 0
```

Indexing (0‑based)  

```
idx(i, true)  = 2*(i-1)
idx(i, false) = 2*(i-1) + 1
```

Negation:

```
neg(idx) = idx ^ 1          # flips the last bit
```

For a parameter `v`

```
if v > 0 : literal = idx(|v|, true)
else      : literal = idx(|v|, false)
```

Clause `(a OR b)` is transformed to two implications

```
¬a → b
¬b → a
```

Both edges are added to the implication graph (size `2n`).

--------------------------------------------------------------------

#### 2.   Solving 2‑SAT

We use Kosaraju’s algorithm (two DFS passes) to obtain strongly connected
components (SCCs).

* If a variable and its negation belong to the same SCC → unsatisfiable.
* Otherwise the SCCs form a DAG.  
  In Kosaraju the second pass processes vertices in *reverse* topological
  order, therefore the component number (`comp`) is a reverse topological
  order: larger `comp` means “earlier” in the DAG.

Assignment rule:

```
s_i = 1   if comp[idx(i, true)]  > comp[idx(i, false)]
s_i = 0   otherwise
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints “YES” and a schedule exactly when one
exists.

---

##### Lemma 1  
For every assessment `(l1,l2)` the clause `(l1 is true) OR (l2 is true)` is
satisfied **iff** the assessment is stable (`E(l1)+E(l2) ≤ 1`).

**Proof.**  
`E(v)=0` ⇔ the statement “s_|v| = target(v)” is true.  
Thus `E(l1)+E(l2) ≤ 1` means at least one of the two statements is true,
which is precisely the logical OR. ∎



##### Lemma 2  
The implication graph built from all assessments is exactly the standard
implication graph of the corresponding 2‑SAT formula.

**Proof.**  
For each clause `(a OR b)` we add edges `¬a → b` and `¬b → a`.  
These are exactly the edges required by the definition of the 2‑SAT
implication graph. ∎



##### Lemma 3  
If Kosaraju finds a variable `i` with `comp(true) = comp(false)` then the
2‑SAT formula is unsatisfiable.

**Proof.**  
In any assignment a literal and its negation cannot both be true.
If they lie in the same SCC, there is a directed cycle containing both,
hence each implies the other, forcing them to have the same truth value –
impossible. ∎



##### Lemma 4  
If for every variable `i` the two literals belong to different SCCs, the
assignment defined by  

```
s_i = 1  iff  comp(true) > comp(false)
```

satisfies all clauses.

**Proof.**  
Consider any edge `u → v` in the implication graph.
Because SCCs are processed in reverse topological order,
`comp(u) > comp(v)` cannot happen (otherwise there would be an edge from a
later component to an earlier one, contradicting topological order).
Thus `comp(u) ≤ comp(v)`.

If `u` is assigned **true**, then `comp(u) > comp(¬u)`.  
Since `comp(u) ≤ comp(v)`, we have `comp(v) > comp(¬u)`.  
If `v` were false, then `comp(v) < comp(¬v)`. But `¬v` is reachable from `u`
through the edge `u→v` and then the edge `v→¬v` (by definition of a literal
and its negation), which would give `comp(u) > comp(¬v)`, a contradiction.
Hence `v` must be true. Therefore every implication is respected, and a
clause `(a OR b)` is violated only when both `a` and `b` are false, i.e.
when `¬a` and `¬b` are true, which would create edges `¬a→b` and `¬b→a`
forcing `b` and `a` true – impossible. So all clauses are satisfied. ∎



##### Lemma 5  
If the algorithm outputs “YES” and the produced schedule, the schedule is
stable for every assessment.

**Proof.**  
“YES” is printed only when no variable collides with its negation, therefore
by Lemma&nbsp;4 the assignment satisfies all 2‑SAT clauses.
By Lemma&nbsp;1 each clause corresponds exactly to stability of the
assessment. ∎



##### Lemma 6  
If a stable schedule exists, the algorithm never prints “NO”.

**Proof.**  
A stable schedule gives a satisfying assignment of the 2‑SAT formula
(Lemma&nbsp;1). Hence the formula is satisfiable, which implies that no
variable and its negation can be in the same SCC (otherwise unsatisfiable,
Lemma&nbsp;3). The algorithm therefore reaches the assignment step and
prints “YES”. ∎



##### Theorem  
The algorithm prints “YES” and a valid schedule **iff** such a schedule
exists; otherwise it prints “NO”.

**Proof.**  
*If* part: by Lemma&nbsp;5.  
*Only‑if* part: by Lemma&nbsp;6. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Vertices*: `2n`  
*Edges*: `2` per clause → `2m`  

Kosaraju:

```
first DFS  : O(V+E) = O(n + m)
second DFS : O(V+E) = O(n + m)
```

Overall time `O(n + m)` ≤ `3·10⁵`.  
Memory: adjacency lists for `2n` vertices, each edge stored once → `O(n+m)`.

Both limits satisfy the problem constraints.

#### 5.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    N = 2 * n                     # number of literals
    g = [[] for _ in range(N)]
    rg = [[] for _ in range(N)]

    def lit(v: int) -> int:
        """return index of literal representing (s_|v| == target(v))"""
        var = abs(v) - 1
        if v > 0:
            return 2 * var          # true literal
        else:
            return 2 * var + 1      # false literal

    for _ in range(m):
        a = int(next(it))
        b = int(next(it))
        la = lit(a)
        lb = lit(b)
        na = la ^ 1
        nb = lb ^ 1
        # ¬a -> b
        g[na].append(lb)
        rg[lb].append(na)
        # ¬b -> a
        g[nb].append(la)
        rg[la].append(nb)

    visited = [False] * N
    order = []

    def dfs(v: int):
        stack = [(v, 0)]
        while stack:
            v, state = stack.pop()
            if state == 0:
                if visited[v]:
                    continue
                visited[v] = True
                stack.append((v, 1))
                for to in g[v]:
                    if not visited[to]:
                        stack.append((to, 0))
            else:
                order.append(v)

    for v in range(N):
        if not visited[v]:
            dfs(v)

    comp = [-1] * N
    cur = 0

    def rdfs(v: int, label: int):
        stack = [v]
        while stack:
            x = stack.pop()
            if comp[x] != -1:
                continue
            comp[x] = label
            for to in rg[x]:
                if comp[to] == -1:
                    stack.append(to)

    for v in reversed(order):
        if comp[v] == -1:
            rdfs(v, cur)
            cur += 1

    assignment = [0] * n
    for i in range(n):
        t = 2 * i
        f = t ^ 1
        if comp[t] == comp[f]:
            print("NO")
            return
        assignment[i] = 1 if comp[t] > comp[f] else 0

    print("YES")
    print(' '.join(map(str, assignment)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
