<METHOD_NAME>Permutation Router Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the algebraic sum inequality (which cleanly isolates literals and mimics standard 2-SAT) with a deterministic 3-element array routing sequence. The target condition (OR gate) is encoded as the final position of an element after two conditional swaps, forcing models to symbolically evaluate the 4 discrete states of the router to discover the underlying boolean satisfiability structure.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem B — Acoustic Levitation Arrays

Time limit: 1 s   Memory limit: 256 MB

## Description
An acoustic levitation chamber contains $n$ transducer arrays. Each array $i$ ($1 \le i \le n$) must be assigned a phase state $s_i \in \{0, 1\}$. 
This state defines the array's phase vector $V_i = [1 - s_i, s_i]$. Note that $V_i$ is 0-indexed, so $V_i[0] = 1 - s_i$ and $V_i[1] = s_i$.

The chamber is subject to $m$ harmonic constraints. Each constraint is defined by two non-zero integers $l_1$ and $l_2$. 
For any non-zero integer $l$, we define its *channel index* $c(l)$:
$c(l) = 1$ if $l > 0$
$c(l) = 0$ if $l < 0$

The *activation level* of a parameter $l$ is obtained by reading the channel index from its corresponding array's phase vector:
$A(l) = V_{|l|}[c(l)]$

Each constraint $(l_1, l_2)$ processes a signal through a 3-port router. The router's ports are represented by a 0-indexed array $P$ initialized to $P = [1, 2, 3]$ (meaning $P[0]=1, P[1]=2, P[2]=3$). 
The routing sequence for the constraint consists of exactly two steps, performed in order:
1. Swap the element at index $0$ with the element at index $A(l_1)$.
2. Swap the element at index $0$ with the element at index $2 \times A(l_2)$.

To prevent destructive interference, a valid global assignment of phase states must ensure that for every harmonic constraint, after applying its routing sequence, the value $1$ is no longer at index $0$ (i.e., $P[0] \neq 1$).

Determine whether there exists a global assignment of phase states for all $n$ arrays that satisfies all $m$ harmonic constraints.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of transducer arrays and the number of harmonic constraints.
Each of the next $m$ lines contains two non-zero integers $l_1$ and $l_2$ ($1 \le |l_1|, |l_2| \le n$), representing the parameters for a single constraint.

## Output
If no valid global assignment exists, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) forming any valid assignment.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid assignments may exist; any one is accepted. The same array index may appear in multiple constraints, and it is possible that $l_1 = l_2$ or $|l_1| = |l_2|$ within a single constraint.
</STATEMENT>
<RATIONALE>
The explicit mathematical inequality `I(l1) + I(l2) > 0` (which cleanly mirrors DIMACS 2-SAT) has been removed. In its place, the problem uses a deterministic 3-element array permutation where the activation of each parameter dictates a swap. Models can no longer pattern-match the sum condition; they must symbolically evaluate the 4 possible states of the router to deduce that `P[0] != 1` acts as a logical OR gate between the two activations.
</RATIONALE>
<PRESERVED_ANSWER>
The router logic dictates that `P[0] != 1` if and only if `A(l1) == 1` or `A(l2) == 1`, which precisely matches the original requirement that at least one literal in the constraint must evaluate to true, preserving all valid assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains exactly 2-SAT (each constraint is a disjunction of two boolean literals), which is solvable in O(n+m) time using standard implication graph and SCC algorithms.
</PRESERVED_CLASS>
