<METHOD_DESCRIPTION>Replaces the algebraic formula $I(v)$ and the sum inequality with a physical model of test rays and deflection angles ($0^\circ$ or $90^\circ$). The sum of angles being strictly less than $180^\circ$ logically enforces that at least one ray must not be deflected, exactly preserving the 2-SAT OR-clause structure while completely hiding the standard boolean satisfiability framing from pattern-matching models.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Acoustic Levitation Arrays

Time limit: 1 s   Memory limit: 256 MB

## Description
An acoustic levitation chamber contains $n$ transducer arrays. Each array $i$ ($1 \le i \le n$) must be assigned a phase state $s_i \in \{0, 1\}$.

The chamber is subject to $m$ harmonic constraints. Each constraint is defined by two non-zero integers $l_1$ and $l_2$, representing two test rays.

A test ray is specified by a non-zero integer $v$. It interacts with the array at index $|v|$, resulting in a deflection angle $\theta(v)$ that depends on both the ray's polarity (the sign of $v$) and the array's phase state $s_{|v|}$:
- If $v > 0$, the ray passes straight ($\theta(v) = 0^\circ$) when $s_{|v|} = 1$, but is deflected ($\theta(v) = 90^\circ$) when $s_{|v|} = 0$.
- If $v < 0$, the ray passes straight ($\theta(v) = 0^\circ$) when $s_{|v|} = 0$, but is deflected ($\theta(v) = 90^\circ$) when $s_{|v|} = 1$.

To maintain stable levitation, a valid global assignment of phase states must ensure that for every constraint $(l_1, l_2)$, the sum of the deflection angles of its two rays is strictly less than $180^\circ$:

$\theta(l_1) + \theta(l_2) < 180^\circ$

Determine whether there exists a global assignment of phase states for all $n$ arrays that satisfies all $m$ harmonic constraints.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of transducer arrays and the number of harmonic constraints.
Each of the next $m$ lines contains two non-zero integers $l_1$ and $l_2$ ($1 \le |l_1|, |l_2| \le n$), representing the parameters for a single constraint.

## Output
If no valid global assignment exists, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) forming any valid assignment.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid assignments may exist; any one is accepted. The same array index may appear in multiple constraints, and it is possible that $l_1 = l_2$ or $|l_1| = |l_2|$ within a single constraint.
</STATEMENT>
<RATIONALE>
The algebraic formula $I(v)$ easily mapped to boolean satisfiability because its structure mirrored literal assignments and its sum inequality mapped to standard CNF clauses. By reframing the constraints as physical rays with deflection angles of $0^\circ$ or $90^\circ$, the models must work through the angle cases to deduce that $\theta < 180^\circ$ effectively means at least one ray is undeflected, breaking the superficial resemblance to 2-SAT.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $\theta(l_1) + \theta(l_2) < 180^\circ$ is mathematically equivalent to $I(l_1) + I(l_2) > 0$, as both require at least one of the conditions (a positive literal being 1, or a negative literal being 0) to be true, preserving all valid assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains identically reducible to 2-SAT, as each constraint still acts as a disjunction of exactly two variables (or their negations), solvable in $O(n+m)$ time.
</PRESERVED_CLASS>
