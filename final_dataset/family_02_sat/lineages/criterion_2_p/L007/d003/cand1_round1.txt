<STATEMENT>
# Problem B — Warehouse Zone Configurations

Time limit: 1 s   Memory limit: 256 MB

## Description
An automated warehouse manages $n$ storage zones. Each zone must be configured to operate in either state 1 (high-density) or state 0 (rapid-retrieval).

The facility must comply with $m$ load-balancing protocols. Each protocol is defined by a pair of non-zero integers $l_1$ and $l_2$. 

For any non-zero integer $v$, we define its *operational yield* based on the configuration of zone $|v|$:
- If zone $|v|$ is configured to state 1, the yield of $v$ is exactly $v$.
- If zone $|v|$ is configured to state 0, the yield of $v$ is exactly $-v$.

A protocol $(l_1, l_2)$ indicates a shared resource bottleneck. To prevent a system fault, a valid global configuration must ensure that for every protocol $(l_1, l_2)$, it is never the case that the yield of $l_1$ and the yield of $l_2$ are both strictly negative. (It is perfectly acceptable if only one parameter evaluates to a negative yield, or if neither does).

Determine whether a global configuration for all $n$ zones exists that safely resolves all $m$ protocols.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of zones and load-balancing protocols.
Each of the next $m$ lines contains two non-zero integers $l_1$ and $l_2$ ($|l_i| \le n$), representing the parameters for a single protocol.

## Output
If no valid global configuration exists, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) forming any valid configuration.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any one is accepted. The same constraint parameters may appear in multiple protocols.
</STATEMENT>
<RATIONALE>
The previous version explicitly defined the boolean literal mapping using piecewise conditions based on the sign of $v$ (e.g., "$v > 0$ and state is 0"), which models pattern-matched directly to standard DIMACS 2-SAT parsers. I replaced this with an algebraic "operational yield" where state 1 gives yield $v$ and state 0 gives yield $-v$, and the failure condition is both yields being strictly negative. This forces the model to algebraically deduce the boolean literal mapping rather than relying on standard template recognition.
</RATIONALE>
<PRESERVED_ANSWER>
The yield of $v$ is strictly negative if and only if either ($v > 0$ and state is 0) or ($v < 0$ and state is 1), which is mathematically identical to the original "strain" condition, preserving all valid assignments exactly.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, returning a boolean assignment that satisfies a set of 2-variable disjunctions, solvable in $O(n+m)$ time via strongly connected components.
</PRESERVED_CLASS>
