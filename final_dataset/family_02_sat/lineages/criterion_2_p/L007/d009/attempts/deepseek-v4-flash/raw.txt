We can model each constraint as a logical condition on the variables.  

For a constraint with `(l1, l2)`, the target point is determined by the signs of `l1` and `l2`:

- If `l1 > 0`, target coordinate is `1`, else `0`.
- If `l2 > 0`, target coordinate is `1`, else `0`.

The squared distance condition `< 2` means the projection must be **exactly equal** to the target point, because the only possible coordinates are 0 or 1, and any mismatch gives distance at least 1, and two mismatches give distance 2 (not allowed).  

So each constraint becomes:

- If `l1 > 0`, then `x[|l1|] = 1`, else `x[|l1|] = 0`.
- If `l2 > 0`, then `x[|l2|] = 1`, else `x[|l2|] = 0`.

This is a 2-SAT problem: each constraint forces two literals to be true.  
We can solve it with union-find on variables and their negations.

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(1 << 20)

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    parent = list(range(2 * n + 2))
    
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    
    def union(a, b):
        ra, rb = find(a), find(b)
        if ra != rb:
            parent[ra] = rb
    
    # variable i: 0..n-1 for x_i = 0, n..2n-1 for x_i = 1
    # We'll use index i for x_i = 1, i+n for x_i = 0
    
    for _ in range(m):
        l1, l2 = map(int, input().split())
        a = abs(l1) - 1
        b = abs(l2) - 1
        val1 = 1 if l1 > 0 else 0
        val2 = 1 if l2 > 0 else 0
        # force x_a = val1
        if val1 == 1:
            union(a, a)  # no-op, but keep structure
            # x_a = 1 means x_a != 0
            union(a, a)  # placeholder
            # Actually: force x_a = 1 => union(a, a) and union(a+n, a)?? 
            # Better: force x_a = 1 means x_a must be 1, so we union a with a (true) and a+n with a (false impossible)
            # In 2-SAT with union-find, forcing x_a = 1 means union(a, a) and union(a+n, a)?? 
            # Actually we can just set: union(a, a) and union(a+n, a) to make a+n and a same => contradiction if a != a+n
            # Simpler: force x_a = 1 => union(a, a) and union(a+n, a) => a and a+n same => impossible if both forced differently
            # But we can just do: union(a, a) and union(a+n, a) => a and a+n same => forces a true
            union(a, a)  # no effect
            union(a + n, a)  # a+n and a same => a true
        else:
            union(a + n, a + n)
            union(a, a + n)  # a and a+n same => a false
        
        if val2 == 1:
            union(b, b)
            union(b + n, b)
        else:
            union(b + n, b + n)
            union(b, b + n)
    
    # Check consistency
    for i in range(n):
        if find(i) == find(i + n):
            print("NO")
            return
    
    # Build assignment
    res = [0] * n
    for i in range(n):
        if find(i) == find(i):
            # choose value
            # If i and i+n are in different sets, pick one
            # We'll pick 1 if find(i) < find(i+n) else 0
            if find(i) < find(i + n):
                res[i] = 1
            else:
                res[i] = 0
    
    print("YES")
    print(" ".join(map(str, res)))

if __name__ == "__main__":
    solve()
```
