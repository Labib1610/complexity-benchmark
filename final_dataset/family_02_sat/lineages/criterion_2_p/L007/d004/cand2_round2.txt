<METHOD_NAME>Algebraic Indicator Formulation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the pairwise boolean-like negative yield condition with an algebraic function $I(v) = v(2s_{|v|} - 1) + |v|$ that maps true literals to positive numbers and false literals to zero. The constraint is framed as a sum $I(l_1) + I(l_2) > 0$. This hides the boolean OR logic and the direct 2-SAT structure behind integer arithmetic, forcing models to algebraically derive the boolean equivalence rather than pattern-matching DIMACS-style text.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem B — Acoustic Levitation Arrays

Time limit: 1 s   Memory limit: 256 MB

## Description
An acoustic levitation chamber contains $n$ transducer arrays. Each array $i$ ($1 \le i \le n$) must be assigned a phase state $s_i \in \{0, 1\}$.

The chamber is subject to $m$ harmonic constraints. Each constraint is defined by two non-zero integers $l_1$ and $l_2$. 

For any non-zero integer $v$ such that $1 \le |v| \le n$, we define its *resonance index* $I(v)$ based on the phase state of array $|v|$:

$I(v) = v \cdot (2s_{|v|} - 1) + |v|$

To prevent destructive interference, a valid global assignment of phase states must ensure that for every harmonic constraint $(l_1, l_2)$, the sum of their resonance indices is strictly positive:

$I(l_1) + I(l_2) > 0$

Determine whether there exists a global assignment of phase states for all $n$ arrays that satisfies all $m$ harmonic constraints.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of transducer arrays and the number of harmonic constraints.
Each of the next $m$ lines contains two non-zero integers $l_1$ and $l_2$ ($1 \le |l_1|, |l_2| \le n$), representing the parameters for a single constraint.

## Output
If no valid global assignment exists, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) forming any valid assignment.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid assignments may exist; any one is accepted. The same array index may appear in multiple constraints, and it is possible that $l_1 = l_2$ or $|l_1| = |l_2|$ within a single constraint.
</STATEMENT>
<RATIONALE>
The seed problem explicitly described picking states to avoid two negative yields, which maps directly to the standard 2-SAT OR-clause (not A or not B). To defeat models that rely on this textual mapping, the rewrite introduces an algebraic indicator function $I(v)$ where the boolean logic is obfuscated behind integer arithmetic. The condition $I(l_1) + I(l_2) > 0$ forces models to algebraically analyze the function to discover that it evaluates to $>0$ if and only if the corresponding literal is satisfied.
</RATIONALE>
<PRESERVED_ANSWER>
The function $I(v)$ evaluates to $2|v| > 0$ if the literal is true and $0$ if it is false; since $I(v) \ge 0$ always, $I(l_1) + I(l_2) > 0$ holds if and only if at least one of the two literals is true, which is exactly the seed's constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, which is solvable in $O(n+m)$ time using an implication graph and strongly connected components (or any standard 2-SAT algorithm).
</PRESERVED_CLASS>
