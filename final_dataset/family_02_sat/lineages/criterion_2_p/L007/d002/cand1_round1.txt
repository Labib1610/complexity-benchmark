<STATEMENT>
# Problem B — Warehouse Zone Configurations

Time limit: 1 s   Memory limit: 256 MB

## Description
An automated warehouse manages $n$ storage zones. Each zone must be configured to operate in either state 1 (high-density) or state 0 (rapid-retrieval).

The facility must comply with $m$ load-balancing protocols. Each protocol is defined by a pair of non-zero integers $l_1$ and $l_2$. 

For any non-zero integer $v$, the system is considered to be under *strain* with respect to parameter $v$ if either:
- $v > 0$ and zone $|v|$ is configured to state 0.
- $v < 0$ and zone $|v|$ is configured to state 1.

A protocol $(l_1, l_2)$ indicates a shared resource bottleneck between these two parameters. To prevent a system fault, a valid global configuration must ensure that the system is never simultaneously under strain with respect to $l_1$ and under strain with respect to $l_2$. (It is acceptable to be under strain for just one of the parameters, or neither).

Determine whether a global configuration for all $n$ zones exists that safely resolves all $m$ protocols.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of zones and load-balancing protocols.
Each of the next $m$ lines contains two non-zero integers $l_1$ and $l_2$ ($|l_i| \le n$), representing the parameters for a single protocol.

## Output
If no valid global configuration exists, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) forming any valid configuration.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any one is accepted. The same constraint parameters may appear in multiple protocols.
</STATEMENT>
<RATIONALE>
I removed the "designated state" and "opposite state" framing, which directly mimicked the definition of DIMACS CNF literals and clauses. Instead, I introduced a "strain" condition that models the exact same logical requirements without using explicit boolean satisfiability terminology. This forces the model to construct the implication logic from the operational rules rather than pattern-matching a standard 2-SAT definition.
</RATIONALE>
<PRESERVED_ANSWER>
The "strain" conditions for $v > 0$ and $v < 0$ exactly correspond to the negation of the literal $v$, meaning forbidding simultaneous strain on $l_1$ and $l_2$ is logically identical to the clause $(l_1 \lor l_2)$, preserving all valid configurations.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, as each of the $m$ protocols still dictates a binary disjunction between two state assignments, solvable in $O(n+m)$ time.
</PRESERVED_CLASS>
<RISK>
Models might find the phrasing "simultaneously under strain with respect to $l_1$ and under strain with respect to $l_2$" slightly unusual when $l_1 = l_2$, though logically it cleanly resolves to a strict prohibition of that single strain condition.
</RISK>
