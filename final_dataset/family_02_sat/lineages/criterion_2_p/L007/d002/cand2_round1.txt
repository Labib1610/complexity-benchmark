<STATEMENT>
# Problem B — Warehouse Zone Configurations

Time limit: 1 s   Memory limit: 256 MB

## Description
An automated warehouse manages $n$ storage zones. Each zone must be configured to operate in either state 1 (high-density) or state 0 (rapid-retrieval).

To evaluate the stability of the warehouse, we assign each zone $i$ an operational multiplier $q_i$:
- $q_i = 1$ if zone $i$ is in state 1.
- $q_i = -1$ if zone $i$ is in state 0.

The facility must comply with $m$ contingency plans. Each plan is defined by two non-zero integers $l_1$ and $l_2$. A plan establishes a safety threshold based on the zones $|l_1|$ and $|l_2|$. Specifically, a global configuration satisfies the plan if and only if at least one of the following two conditions holds:
- $q_{|l_1|} \cdot l_1 > 0$
- $q_{|l_2|} \cdot l_2 > 0$

Determine whether a global configuration for all $n$ zones exists that satisfies every contingency plan.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of zones and contingency plans.
Each of the next $m$ lines contains two non-zero integers $l_1$ and $l_2$ ($|l_i| \le n$), representing the parameters for a single contingency plan.

## Output
If no valid global configuration exists, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) forming any valid configuration.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any one is accepted. The same constraint parameters may appear in multiple contingency plans.
</STATEMENT>
<RATIONALE>
I replaced the explicit boolean-logic phrasing ("designated state", "opposite state", "forbids exactly one combination") with an algebraic condition involving an operational multiplier $q_i \in \{1, -1\}$. This forces models to algebraically deduce that $q_{|l|} \cdot l > 0$ is equivalent to assigning a specific boolean state, requiring them to reconstruct the 2-SAT reduction rather than triggering on standard DIMACS CNF vocabulary.
</RATIONALE>

</PRESERVED_ANSWER>
