We can model each interlock as a constraint on the boolean variables \( s_i \).  
Let’s define \( x_i = 2s_i - 1 \), so \( x_i \in \{-1, 1\} \).  

The condition \( E > C \) becomes:

\[
l_1 x_{|l_1|} + l_2 x_{|l_2|} > -(|l_1| + |l_2|)
\]

We can rewrite this as:

\[
l_1 x_{|l_1|} + l_2 x_{|l_2|} + |l_1| + |l_2| > 0
\]

Now, note that \( l_i \) can be positive or negative.  
If \( l_i > 0 \), then \( l_i x_i + |l_i| = l_i(x_i + 1) \), which is \( 0 \) if \( x_i = -1 \) and \( 2l_i \) if \( x_i = 1 \).  
If \( l_i < 0 \), then \( l_i x_i + |l_i| = |l_i|(1 - x_i) \), which is \( 0 \) if \( x_i = 1 \) and \( 2|l_i| \) if \( x_i = -1 \).

So each term is either \( 0 \) or positive. The sum is strictly positive iff at least one term is positive.  
That means: for each interlock, at least one of the two arrays must be in the “positive” state for that term.

This is exactly a **2-SAT** problem:  
- If \( l_1 > 0 \), then \( x_{|l_1|} = 1 \) means \( s_{|l_1|} = 1 \).  
- If \( l_1 < 0 \), then \( x_{|l_1|} = -1 \) means \( s_{|l_1|} = 0 \).  

We need at least one of the two required states to hold.  
That’s a clause: \( (A \lor B) \), where \( A \) and \( B \) are literals.

We can solve 2-SAT with implication graph and SCC.

```python
import sys
sys.setrecursionlimit(1 << 20)

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    N = 2 * n
    g = [[] for _ in range(N)]
    rg = [[] for _ in range(N)]

    def node(var, val):
        # var: 0-based index, val: 0 or 1
        return 2 * var + val

    def add_imp(u, v):
        g[u].append(v)
        rg[v].append(u)

    for _ in range(m):
        l1, l2 = map(int, input().split())
        a = abs(l1) - 1
        b = abs(l2) - 1
        # literal for l1: if l1>0 then s_a=1, else s_a=0
        lit1 = node(a, 1 if l1 > 0 else 0)
        lit2 = node(b, 1 if l2 > 0 else 0)
        # clause (lit1 OR lit2)
        # implications: !lit1 -> lit2, !lit2 -> lit1
        add_imp(lit1 ^ 1, lit2)
        add_imp(lit2 ^ 1, lit1)

    # Kosaraju SCC
    visited = [False] * N
    order = []
    def dfs(u):
        visited[u] = True
        for v in g[u]:
            if not visited[v]:
                dfs(v)
        order.append(u)

    for i in range(N):
        if not visited[i]:
            dfs(i)

    comp = [-1] * N
    def rdfs(u, cid):
        comp[u] = cid
        for v in rg[u]:
            if comp[v] == -1:
                rdfs(v, cid)

    cid = 0
    for u in reversed(order):
        if comp[u] == -1:
            rdfs(u, cid)
            cid += 1

    for i in range(n):
        if comp[2*i] == comp[2*i+1]:
            print("NO")
            return

    print("YES")
    ans = []
    for i in range(n):
        # if comp[2*i] > comp[2*i+1], then s_i = 1 else 0
        if comp[2*i] > comp[2*i+1]:
            ans.append('1')
        else:
            ans.append('0')
    print(' '.join(ans))

if __name__ == "__main__":
    solve()
```
