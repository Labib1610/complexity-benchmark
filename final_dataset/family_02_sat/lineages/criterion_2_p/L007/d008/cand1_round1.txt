<STATEMENT>
# Problem B — Acoustic Levitation Arrays

Time limit: 1 s
Memory limit: 256 MB

## Description
An acoustic levitation chamber contains $n$ transducer arrays. Each array $i$ ($1 \le i \le n$) must be assigned a phase state $s_i \in \{0, 1\}$. The physical phase angle generated by array $i$ is $\theta_i = \pi s_i$.

To prevent destructive interference, the chamber is equipped with $m$ acoustic interlocks. Each interlock monitors two arrays, specified by two non-zero integers $l_1$ and $l_2$. 

For the $k$-th parameter of an interlock ($k \in \{1, 2\}$), the expected phase offset $\delta_k$ depends on the sign of $l_k$:
* $\delta_k = \pi$ if $l_k > 0$
* $\delta_k = 0$ if $l_k < 0$

The acoustic modulation factor $M_k$ for this parameter is determined by its alignment with the expected offset:
$$M_k = \cos(\theta_{|l_k|} - \delta_k)$$

The interlock computes a joint resonance coefficient $R$ based on the magnitudes $|l_1|$ and $|l_2|$:
$$R = \left( |l_1| M_1 - \frac{|l_1|}{2} \right) \left( |l_2| M_2 - \frac{|l_2|}{2} \right)$$

An interlock will trigger a system halt if the resonance coefficient $R$ reaches or exceeds a critical threshold $C$, defined as:
$$C = 2 |l_1| |l_2|$$

Therefore, a valid global configuration must ensure that for every interlock, the strict inequality $R < C$ holds.

Determine whether there exists a global assignment of phase states for all $n$ arrays that prevents any of the $m$ interlocks from triggering a halt.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of transducer arrays and the number of safety interlocks.
Each of the next $m$ lines contains two non-zero integers $l_1$ and $l_2$ ($1 \le |l_1|, |l_2| \le n$), representing the parameters for a single interlock.

## Output
If no valid global assignment exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) forming any valid assignment.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid assignments may exist; any one is accepted. The same array index may appear in multiple interlocks, and it is possible that $l_1 = l_2$ or $|l_1| = |l_2|$ within a single interlock.
</STATEMENT>
<RATIONALE>
Replaced the direct linear inequality with a trigonometric phase modulation and a product-based resonance coefficient. This forces the model to evaluate the four discrete states of the modulation factors algebraically to discover the threshold condition, breaking direct syntactic mapping to 2-SAT clauses.
</RATIONALE>
<PRESERVED_ANSWER>
Since the phase angles are multiples of pi, the modulation factors are strictly +/- 1; the condition R < C fails if and only if both factors are -1, matching the original requirement that not both literals can be unsatisfied.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a satisfying assignment for a set of boolean disjunctions, keeping it exactly in 2-SAT.
</PRESERVED_CLASS>
<RISK>

</RISK>
