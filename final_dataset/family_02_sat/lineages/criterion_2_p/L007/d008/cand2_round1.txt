<STATEMENT>
# Phase-Modulated Acoustic Interlocks

Time limit: 1 s
Memory limit: 256 MB

## Description
An acoustic levitation chamber contains $n$ transducer arrays. Each array $i$ must be assigned a phase state $s_i \in \{0, 1\}$.

To prevent destructive resonance, the chamber is equipped with $m$ acoustic interlocks. Each interlock monitors a specific pair of array connections, specified by two non-zero integers $l_1$ and $l_2$.

The acoustic pressure $P$ at an interlock is the sum of the wave contributions from its two connections. For a connection parameterized by a non-zero integer $l$, its amplitude is $A = |l|$ and its intrinsic phase shift is $\phi = 0$ if $l > 0$, or $\phi = \pi$ if $l < 0$. 

When the monitored array $|l|$ is in phase state $s_{|l|}$, it introduces an operational phase of $\pi \cdot s_{|l|}$. The wave contribution $W$ of this connection is modeled using the cosine of the total phase:
$$W = A \cos(\pi \cdot s_{|l|} + \phi)$$

The combined pressure at the interlock is simply $P = W_1 + W_2$, where $W_1$ and $W_2$ are the contributions from the connections $l_1$ and $l_2$.

An interlock will trigger a system halt if the combined pressure $P$ reaches the theoretical maximum capacity of the interlock, which is exactly $A_1 + A_2$. Therefore, a valid global configuration must ensure that for every interlock, the strict inequality $P < A_1 + A_2$ holds.

Determine whether there exists a global assignment of phase states for all $n$ arrays that prevents any of the $m$ interlocks from triggering a halt.

## Input
The first line contains two integers $n$ and $m$, representing the number of transducer arrays and the number of safety interlocks. The installation requires at least one array and is limited by a physical capacity of one hundred thousand arrays. The safety system can accommodate anywhere from zero up to two hundred thousand interlocks.

Each of the next $m$ lines contains two non-zero integers $l_1$ and $l_2$, representing the parameters for a single interlock. The absolute values of $l_1$ and $l_2$ represent valid array indices (ranging from $1$ up to $n$).

## Output
If no valid global assignment exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) forming any valid assignment.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid assignments may exist; any one is accepted. The same array index may appear in multiple interlocks, and it is possible that $l_1 = l_2$ or $|l_1| = |l_2|$ within a single interlock.
