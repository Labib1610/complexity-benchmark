<METHOD_NAME>
Trigonometric Phase Encoding
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the explicit linear inequality with a trigonometric wave interference model. It forces models to reason about cosine phase shifts to deduce the underlying boolean satisfiability conditions, disrupting straightforward pattern matching to 2-SAT algebraic forms.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<STATEMENT>
# Problem B — Acoustic Levitation Arrays

Time limit: 1 s
Memory limit: 256 MB

## Description
An acoustic levitation chamber contains $n$ transducer arrays. Each array $k$ ($1 \le k \le n$) must be assigned a binary phase state $s_k \in \{0, 1\}$.

To prevent destructive interference, the chamber is equipped with $m$ acoustic interlocks. Each interlock monitors two wave connections, specified by two non-zero integers $l_1$ and $l_2$. 

For a given connection parameter $l$, the corresponding wave amplitude is $A = |l|$. Because $l \neq 0$, the amplitude is always at least 1 ($A \ge 1$). The base phase shift is determined by the sign of $l$: $\phi = 0$ if $l > 0$, and $\phi = \pi$ if $l < 0$. The wave contribution $W$ from this connection depends on the phase state of array $A$ and is given by the trigonometric function:
$$W = A \cos(\pi s_{A} + \phi)$$

The total peak pressure $P$ measured by an interlock is the sum of the wave contributions from its two connections:
$$P = W_1 + W_2$$
where $W_1$ and $W_2$ are derived from $l_1$ and $l_2$ respectively.

An interlock will trigger a system halt if the peak pressure $P$ reaches its theoretical maximum capacity. This capacity is exactly the sum of the two amplitudes, $A_1 + A_2$. Therefore, a valid global configuration must ensure that for every interlock, the strict inequality $P < A_1 + A_2$ holds.

Determine whether there exists a global assignment of phase states for all $n$ arrays that prevents any of the $m$ interlocks from triggering a halt.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of transducer arrays and the number of safety interlocks.
Each of the next $m$ lines contains two non-zero integers $l_1$ and $l_2$ ($1 \le |l_1|, |l_2| \le n$), representing the parameters for a single interlock.

## Output
If no valid global assignment exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) forming any valid assignment.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid assignments may exist; any one is accepted. For a single interlock, the two parameters $l_1$ and $l_2$ may refer to the same array, with the same or opposite sign. An array may also appear in multiple different interlocks.
</STATEMENT>
<RATIONALE>
The explicit algebraic inequality $E > C$ that maps directly to boolean clauses was replaced with a trigonometric interference model. Models must now symbolically evaluate the cosine function for $s \in \{0, 1\}$ and $\phi \in \{0, \pi\}$ to deduce that $P < A_1 + A_2$ strictly requires at least one wave contribution to be $-A_i$, structurally hiding the 2-SAT disjunction.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $W_i = A_i \cos(\pi s_{A_i} + \phi)$ evaluates to $A_i$ when the literal is false and $-A_i$ when true; the strict inequality $P < A_1 + A_2$ thus requires at least one literal to be true exactly as the seed's $E > C$ did.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, solvable in $O(n+m)$ time by finding Strongly Connected Components in the implication graph.
</PRESERVED_CLASS>
<RISK>
Models might struggle with floating point approximations if they attempt to physically simulate the waves rather than symbolically reducing the math, though the domain $\{0, 1\}$ makes symbolic reduction highly accessible to careful reading.
</RISK>
