<STATEMENT>
# Problem B — Warehouse Zone Configurations

Time limit: 1 s   Memory limit: 256 MB

## Description
An automated warehouse manages $n$ storage zones. Each zone must be configured for either high-density storage (represented as 1) or rapid-retrieval storage (represented as 0).

The facility must comply with $m$ contingency plans. Each plan provides two reference directives, represented as non-zero integers. The absolute value of a directive identifies a specific zone. The sign of the directive establishes a baseline state for that zone: a positive integer establishes a baseline state of 1, while a negative integer establishes a baseline state of 0.

A zone is considered to "deviate" if its assigned configuration is the exact opposite of the baseline state established by a directive. Each contingency plan identifies a critical instability: the warehouse will fail if, under a given global configuration, the zone from the first directive deviates from its baseline state and the zone from the second directive also deviates from its baseline state. To fulfill a plan, you must ensure this combined deviation never occurs.

Determine whether a global configuration for all $n$ zones exists that fulfills every contingency plan simultaneously.

The physical footprint accommodates up to exactly one hundred thousand storage zones. The number of active zones $n$ is at least one and cannot exceed this footprint. The compliance registry has a maximum capacity of exactly double the maximum zone footprint, meaning the number of plans $m$ ranges from zero up to that registry capacity. Every reference directive strictly points to an installed zone, meaning the absolute value of any directive will never be less than one nor exceed the number of active zones $n$.

## Input
The first line contains two integers $n$ and $m$, representing the number of zones and the number of contingency plans.
Each of the next $m$ lines contains two non-zero integers $l_1$ and $l_2$, representing the two reference directives for a single contingency plan.

## Output
If no valid global configuration exists, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) forming any valid configuration.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any one is accepted. The same configuration directive may appear in multiple contingency plans.
</STATEMENT>
<RATIONALE>
The explicit "first, second, or both" wording that mapped directly to boolean OR clauses was removed. Instead, the constraints are presented using De Morgan's laws: defining a "deviation" from a baseline state and forbidding the simultaneous deviation of both directives in a plan. The numeric bounds were also translated into scenario constraints (e.g., maximum footprint and registry capacity) to force the model to parse the physical limits rather than relying on standard inequality notation.
</RATIONALE>
<PRESERVED_ANSWER>
Forbidding the simultaneous deviation of two variables from their baseline states is logically equivalent to requiring that at least one variable matches its baseline state, perfectly preserving the original boolean satisfiability constraints.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, as every constraint still enforces a disjunction between two literals, keeping it solvable in O(n+m) time via an implication graph and strongly connected components.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "combined deviation never occurs" if they fail to recognize it applies strictly per-plan, though the phrasing "Each contingency plan identifies... To fulfill a plan, you must ensure..." makes the scope explicit.
</RISK>
