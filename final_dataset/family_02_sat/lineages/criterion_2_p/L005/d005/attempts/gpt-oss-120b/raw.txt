**Solution Explanation**

For each qubit `i` we choose a spin `x_i ∈ {‑1, 1}`.
For a route `(l1 , l2)` the resonance score is  

```
R = l1 * x|l1| + l2 * x|l2|
```

The route is *critical* exactly when  

```
R = -( |l1| + |l2| )
```

Because `x_i` can only be `‑1` or `1`, the equality holds **iff**

```
x|l1| = -sign(l1)   and   x|l2| = -sign(l2)
```

(`sign(l) = 1` for `l>0`, `‑1` for `l<0`).

So for every route we are **forbidden** to assign the two
variables simultaneously to those two values.
All other assignments are allowed.

--------------------------------------------------------------------

### 1.   From spins to Boolean variables  

Define a Boolean variable  

```
v_i = 1   ⇔   x_i = 1
v_i = 0   ⇔   x_i = -1
```

For a literal `l` (one of the two numbers of a route)

```
sign = 1  if l>0 else -1
forbidden value of v_|l|  = 1   if sign = -1
                               0   if sign =  1
```

Let  

```
f = 1  if sign = -1
    0  otherwise
```

The forbidden assignment for this literal is `v = f`.
The route is critical exactly when **both** literals take their
forbidden values.

Therefore the condition *“the route must NOT be critical”* is

```
(v_a != f_a)  OR  (v_b != f_b)
```

which is a 2‑CNF clause.

--------------------------------------------------------------------

### 2.   2‑SAT formulation  

For each variable `i` we have two literals in the implication graph  

```
L(i, true)  = node 2*i
L(i, false) = node 2*i+1
negation:   node ^ 1
```

The clause `(A OR B)` is transformed to the two implications  

```
¬A → B
¬B → A
```

For a route we compute the two literals `A , B` :

```
if f == 0 :   A = L(i, true)      # we need v_i != 0  → v_i = true
else          A = L(i, false)    # we need v_i != 1  → v_i = false
```

Add the two edges described above.  
Number of nodes = `2·n` ( ≤ 2·10⁵ ), number of edges = `2·m` ( ≤ 4·10⁵).

--------------------------------------------------------------------

### 3.   Solving 2‑SAT  

We run Kosaraju’s algorithm (two DFS passes) to obtain strongly
connected components (SCC).  
If a variable and its negation belong to the same SCC the instance is
unsatisfiable → answer `NO`.

Otherwise the SCCs give a topological order.  
A standard assignment rule:

```
v_i = 1   if comp[ L(i,true) ]  > comp[ L(i,false) ]
v_i = 0   otherwise
```

(The component with larger finishing order comes earlier in the
reverse topological order.)

The required output bits are exactly `v_i` (because `s_i = (x_i+1)/2`
and `x_i = 2·v_i-1`).

--------------------------------------------------------------------

### 4.   Correctness Proof  

We prove that the algorithm outputs `YES` and a valid calibration
iff such a calibration exists.

---

#### Lemma 1  
For a route `(l1,l2)` let `A` be the literal “`v_a != f_a`” and `B`
the literal “`v_b != f_b`”.  
The route is non‑critical **iff** the Boolean assignment satisfies the
clause `A ∨ B`.

*Proof.*  
The route is critical exactly when both variables take their forbidden
values, i.e. `v_a = f_a` **and** `v_b = f_b`.  
Negating this condition gives `v_a ≠ f_a` **or** `v_b ≠ f_b`,
which is precisely `A ∨ B`. ∎



#### Lemma 2  
The implication graph built by the algorithm is exactly the standard
graph for the 2‑CNF formula consisting of all clauses `A ∨ B` from
Lemma&nbsp;1.

*Proof.*  
For each clause `A ∨ B` the algorithm adds edges `¬A → B` and `¬B → A`,
which is the textbook translation from a 2‑CNF clause to an
implication graph. ∎



#### Lemma 3  
If the algorithm reports *unsatisfiable* (some variable and its
negation lie in the same SCC) then no calibration avoids all critical
routes.

*Proof.*  
By Lemma&nbsp;2 the SCC condition is exactly the standard unsatisfiability
criterion for a 2‑SAT instance. If a variable and its negation are in the
same SCC, any truth assignment would have to give the variable both
`true` and `false`, impossible. Hence the original set of clauses,
and therefore the set of route constraints (Lemma&nbsp;1), cannot be
simultaneously satisfied. ∎



#### Lemma 4  
If the algorithm produces an assignment `v_i` then every route is
non‑critical.

*Proof.*  
The assignment is obtained from a topological order of SCCs, which is a
known satisfying assignment for the 2‑SAT formula represented by the
implication graph (standard property of Kosaraju‑based 2‑SAT solving).
Thus all clauses `A ∨ B` are true. By Lemma&nbsp;1 each clause being true
means the corresponding route is non‑critical. ∎



#### Lemma 5  
If a calibration avoiding all critical routes exists, the algorithm
does not report unsatisfiable.

*Proof.*  
From such a calibration we obtain Boolean values `v_i`. By Lemma&nbsp;1
all clauses `A ∨ B` are satisfied, therefore the 2‑SAT instance is
satisfiable. A satisfiable 2‑SAT instance never has a variable and its
negation in the same SCC (otherwise no assignment could satisfy it).
Hence the algorithm will not detect a conflict. ∎



#### Theorem  
The algorithm outputs  

* `NO` **iff** no stable calibration exists;  
* `YES` and a binary array `s_i` **iff** a stable calibration exists,
  and the printed array corresponds to a stable calibration.

*Proof.*  
- If the algorithm prints `NO`, by Lemma&nbsp;3 no calibration can avoid
  all critical routes, so none exists.
- If a stable calibration exists, Lemma&nbsp;5 guarantees the algorithm
  does not output `NO`. It therefore produces an assignment; by
  Lemma&nbsp;4 this assignment makes every route non‑critical, i.e. it is
  a stable calibration. The printed bits are exactly `v_i = s_i`. ∎



--------------------------------------------------------------------

### 5.   Complexity Analysis  

- Building the graph: `O(m)` edges, `O(n)` nodes.
- Kosaraju DFS passes: `O(n + m)`.
- Memory: adjacency lists store `2·m` integers → `O(n + m)`.

Both limits satisfy the required constraints (`n ≤ 10⁵`, `m ≤ 2·10⁵`).

--------------------------------------------------------------------

### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    N = 2 * n                     # number of nodes in implication graph
    g = [[] for _ in range(N)]
    rg = [[] for _ in range(N)]

    def add_imp(u, v):
        g[u].append(v)
        rg[v].append(u)

    for _ in range(m):
        l1 = int(next(it))
        l2 = int(next(it))
        # first literal
        i1 = abs(l1) - 1
        sign1 = 1 if l1 > 0 else -1
        f1 = 1 if sign1 == -1 else 0          # forbidden value of v_i
        # we need (v_i != f) -> literal A
        litA = 2 * i1 + (0 if f1 == 0 else 1)  # true if f==0 else false
        # second literal
        i2 = abs(l2) - 1
        sign2 = 1 if l2 > 0 else -1
        f2 = 1 if sign2 == -1 else 0
        litB = 2 * i2 + (0 if f2 == 0 else 1)

        # clause (litA OR litB)
        notA = litA ^ 1
        notB = litB ^ 1
        add_imp(notA, litB)
        add_imp(notB, litA)

    # Kosaraju
    visited = [False] * N
    order = []

    def dfs(v):
        stack = [v]
        while stack:
            node = stack[-1]
            if visited[node]:
                stack.pop()
                continue
            visited[node] = True
            for to in g[node]:
                if not visited[to]:
                    stack.append(to)
            # after exploring children, record order
            if stack[-1] == node:
                stack.pop()
                order.append(node)

    for v in range(N):
        if not visited[v]:
            dfs(v)

    comp = [-1] * N
    label = 0
    for v in reversed(order):
        if comp[v] == -1:
            stack = [v]
            comp[v] = label
            while stack:
                node = stack.pop()
                for to in rg[node]:
                    if comp[to] == -1:
                        comp[to] = label
                        stack.append(to)
            label += 1

    assignment = [0] * n
    for i in range(n):
        if comp[2*i] == comp[2*i+1]:
            print("NO")
            return
        assignment[i] = 1 if comp[2*i] > comp[2*i+1] else 0

    print("YES")
    print(' '.join(map(str, assignment)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
