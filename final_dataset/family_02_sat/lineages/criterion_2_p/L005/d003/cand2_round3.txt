# Problem B — Quantum Array Calibration

Time limit: 1 s   Memory limit: 256 MB

## Description

You are tasked with finding a valid operating state for a quantum computing array consisting of $n$ qubits. Each qubit must be calibrated into one of two basis states: 1 or 0. The configuration space contains $2^n$ possible global calibrations.

The system's error-correction protocol monitors a set of $m$ hardware dependencies. Each dependency links two qubits through a conditional reaction. The reaction is defined by two non-zero integers, $l_1$ and $l_2$. 

For any integer $v$:
- If $v > 0$, the *trigger state* of qubit $|v|$ is 0.
- If $v < 0$, the *trigger state* of qubit $|v|$ is 1.

A dependency between $l_1$ and $l_2$ dictates that if qubit $|l_1|$ enters its trigger state (as defined by $l_1$), it forces qubit $|l_2|$ to take the opposite of its own trigger state (as defined by $l_2$). Because the hardware routing is bidirectional, the reverse is also true: if qubit $|l_2|$ enters its trigger state, it forces qubit $|l_1|$ to take the opposite of its trigger state.

The array is considered stable if and only if all conditional reactions are satisfied simultaneously across the entire array. Write a program to determine if a stable global calibration exists for the $n$ qubits, and if so, output one. 

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines describes a dependency using two non-zero integers $l_1$ and $l_2$ ($|l_1|, |l_2| \le n$). 

## Output
If no valid calibration exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \ldots, s_n$ (each either 0 or 1) representing the state of each qubit in a valid calibration. Any valid calibration will be accepted.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
The same qubit may appear in multiple dependencies, or multiple times in the same dependency.
</STATEMENT>
<RATIONALE>
The problem was reframed to replace the static "hazardous pair" phrasing (which models easily pattern-match to a NAND clause) with a dynamic "conditional reaction" (which explicitly describes an implication). This forces the model to trace the conditional logic and recognize that bidirectional forcing between opposite trigger states is logically identical to the original mutual exclusion constraint, shifting the burden from surface pattern matching to structural reasoning.
</RATIONALE>
<PRESERVED_ANSWER>
The bidirectional implication "if A is in trigger state then B must be opposite to its trigger state" is logically equivalent to the original constraint "A and B cannot both be in their trigger states simultaneously", preserving all valid configurations.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, solvable in linear time using an implication graph and strongly connected components.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "take the opposite of its own trigger state" if they fail to recognize that the basis states are strictly binary (0 or 1), though the first paragraph explicitly restricts the states to 1 or 0.
</RISK>
