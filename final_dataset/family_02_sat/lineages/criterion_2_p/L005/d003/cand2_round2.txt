# Problem B — Quantum Array Calibration

Time limit: 1 s   Memory limit: 256 MB

## Description

You are tasked with finding a valid operating state for a quantum computing array consisting of $n$ qubits. Each qubit must be calibrated into one of two basis states: state 1 or state 0.

The system's error-correction protocol enforces structural rules based on entanglement routing. There are $m$ hardware dependencies. Each dependency dictates an asymmetric conditional reaction between two specific qubit states.

For any non-zero integer $v$, we define its "activation state":
- If $v$ is positive, the activation state for qubit $v$ is state 0.
- If $v$ is negative, the activation state for qubit $|v|$ is state 1.

A dependency is specified by two non-zero integers $l_1$ and $l_2$. The entanglement routing dictates that:
- If qubit $|l_1|$ is placed in its activation state, a reaction is triggered that forces qubit $|l_2|$ to strictly avoid its own activation state.
- Symmetrically, if qubit $|l_2|$ is placed in its activation state, a reaction is triggered that forces qubit $|l_1|$ to strictly avoid its own activation state.

The array is considered stable if and only if all conditional reactions are satisfied simultaneously across all dependencies. (Note that a dependency might reference the same qubit twice, and the same qubit may appear in multiple dependencies).

Write a program to determine if a stable global calibration exists, and if so, output one.

## Input
The first line contains two integers $n$ and $m$. The array's physical chassis accommodates a minimum of $1$ and a maximum of $10^5$ qubits. The diagnostic buffer can store from $0$ up to $2 \cdot 10^5$ routing dependencies.

Each of the next $m$ lines describes a dependency using two non-zero signed integers $l_1$ and $l_2$. The absolute values $|l_1|$ and $|l_2|$ will never exceed the number of active qubits $n$.

## Output
If no valid calibration exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \ldots, s_n$ (each either 0 or 1) representing the state of each qubit in a valid calibration. Any valid calibration will be accepted.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```
