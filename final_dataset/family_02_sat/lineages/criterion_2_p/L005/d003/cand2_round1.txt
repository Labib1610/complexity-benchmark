<STATEMENT>
# Problem B — Quantum Array Calibration

Time limit: 1 s   Memory limit: 256 MB

## Description

You are tasked with finding a valid operating state for a quantum computing array. The array has a design capacity of $n$ qubits. The facility mandates at least one qubit for operation, and can support an architectural maximum of one hundred thousand qubits. Each qubit must be calibrated into exactly one of two basis states: state 1 or state 0.

The system's error-correction protocol processes a sequence of $m$ hardware dependencies. This sequence can be completely empty, but is limited by the protocol's memory buffer which holds at most two hundred thousand dependencies. 

Each dependency provides two non-zero integers $l_1$ and $l_2$. These represent conditional triggers based on individual qubit states:
- A positive integer $x$ acts as a trigger if qubit $x$ is calibrated to state 0.
- A negative integer $-x$ acts as a trigger if qubit $x$ is calibrated to state 1.

(The absolute values of any given $l_1$ or $l_2$ will never exceed the array's installed qubit count $n$.)

Every dependency establishes a mandatory reaction to maintain array stability: if the condition for $l_1$ is met, it actively forces the specific qubit monitored by $l_2$ to adopt the state *opposite* to the one that would act as a trigger for $l_2$. Because the physical coupling is symmetric, if the condition for $l_2$ is met, it equally forces the specific qubit monitored by $l_1$ to adopt the state opposite to the one that would act as a trigger for $l_1$. 

Write a program to evaluate the configuration space to determine if a stable global calibration exists where all mandatory reactions are satisfied without contradiction, and if so, output one.

## Input
The first line contains two integers $n$ and $m$, representing the installed qubit count and the number of dependencies.
Each of the next $m$ lines describes a dependency using two non-zero signed integers $l_1$ and $l_2$. 

## Output
If no valid calibration exists in the state space, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \ldots, s_n$ (each either 0 or 1) representing the state of each qubit in a valid calibration.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid calibrations may exist; any one is accepted. The same qubit may appear in multiple dependencies.
</STATEMENT>
<RATIONALE>
Removed the explicit "hazardous pair" and "cannot simultaneously exhibit" phrasing, which models reliably pattern-matched to NAND clauses in 2-SAT. Instead, the constraints are presented as a physical forcing mechanism where triggering one condition actively forces the other monitored qubit into its opposite state, requiring the model to deduce the logical equivalence. Additionally, numeric constraints were removed from the Input section and embedded into the narrative as physical capacities to satisfy strategy S07.
</RATIONALE>
<PRESERVED_ANSWER>
The forcing mechanism ($l_1 \implies \neg l_2$) is logically identical to the original mutual exclusion ($\neg (l_1 \land l_2)$), ensuring all valid configurations remain exactly the same.
</PRESERVED_ANSWER>

The problem remains standard 2-SAT because the constraints still strictly map to pairwise boolean disjunctions.
</PRESERVED_CLASS>
