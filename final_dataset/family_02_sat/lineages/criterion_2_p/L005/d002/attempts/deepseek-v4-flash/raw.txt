We can model each qubit as a boolean variable, and each dependency as a clause that forbids a certain combination.  
This is essentially a **2-SAT** problem.

- A positive literal `x` means `x = 0` (or `not x` in boolean terms if we map 0 → True, 1 → False).  
- A negative literal `-x` means `x = 1` (or `x` in boolean terms).

A dependency `(a, b)` forbids both being true at the same time, so we add implications:  
`a → ¬b` and `b → ¬a`.

We can solve 2-SAT using implication graph + SCC (Tarjan or Kosaraju).  
If a variable and its negation are in the same SCC, it's unsatisfiable.

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(1 << 20)

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    
    # 2-SAT: variable i (0-based) -> 2*i for False, 2*i+1 for True
    # We'll map: literal x (positive) means qubit x = 0 -> variable False
    #            literal -x means qubit x = 1 -> variable True
    # So for literal l:
    #   if l > 0: var = 2*(l-1)   (False)
    #   if l < 0: var = 2*(-l-1)+1 (True)
    
    N = 2 * n
    g = [[] for _ in range(N)]
    gr = [[] for _ in range(N)]
    
    def add_imp(u, v):
        g[u].append(v)
        gr[v].append(u)
    
    def lit_to_node(l):
        if l > 0:
            return 2 * (l - 1)      # False
        else:
            return 2 * (-l - 1) + 1 # True
    
    for _ in range(m):
        a, b = map(int, input().split())
        u = lit_to_node(a)
        v = lit_to_node(b)
        # a -> not b
        add_imp(u, v ^ 1)
        # b -> not a
        add_imp(v, u ^ 1)
    
    # Kosaraju SCC
    visited = [False] * N
    order = []
    
    def dfs1(u):
        visited[u] = True
        for w in g[u]:
            if not visited[w]:
                dfs1(w)
        order.append(u)
    
    for i in range(N):
        if not visited[i]:
            dfs1(i)
    
    comp = [-1] * N
    def dfs2(u, cid):
        comp[u] = cid
        for w in gr[u]:
            if comp[w] == -1:
                dfs2(w, cid)
    
    cid = 0
    for u in reversed(order):
        if comp[u] == -1:
            dfs2(u, cid)
            cid += 1
    
    # Check satisfiability
    for i in range(n):
        if comp[2*i] == comp[2*i+1]:
            print("NO")
            return
    
    # Assign values: choose False if comp[2*i] > comp[2*i+1] (typical)
    res = []
    for i in range(n):
        # comp[2*i] is False node, comp[2*i+1] is True node
        if comp[2*i] > comp[2*i+1]:
            res.append(0)  # False
        else:
            res.append(1)  # True
    
    print("YES")
    print(" ".join(map(str, res)))

if __name__ == "__main__":
    main()
```
