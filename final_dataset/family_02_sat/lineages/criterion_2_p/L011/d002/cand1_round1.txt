# Problem B — Paired Window Constraints

Time limit: 1 s   Memory limit: 256 MB

## Description

Before a manufacturing run can commence, an industrial control panel with **n** toggle switches must be configured. Every switch must be locked into either an UP or DOWN position. The safety system monitors the panel using **m** fault mitigation procedures.

Each procedure specifies two preferred switch states (for example, demanding that a particular switch is UP, or demanding that a particular switch is DOWN). A critical failure occurs if a procedure's fallback chain breaks. Specifically, for every procedure, if the configuration lacks the first preferred state, it triggers a hardware override that strictly requires the second preferred state to be present. Because these overrides act symmetrically, lacking the second preferred state similarly mandates that the first preferred state is present.

Your task is to determine whether it is possible to find one overarching UP/DOWN configuration for all **n** switches that safely navigates all **m** mitigation procedures without triggering an unresolvable hardware failure. If such a configuration exists, you must provide one. If the procedures contradict each other such that no valid configuration is possible, you must report this failure.

## Input
The first line provides two integers, n and m. The number of switches n is at least 1 and at most the exact number of seconds in 27 hours, 46 minutes, and 40 seconds. The number of procedures m is at least 0 and at most twice the upper limit of n.

The subsequent m lines each contain two non-zero signed integers, l1 and l2, where the absolute value of each integer is at most n. A positive value designates a preference for the specified switch to be UP, while a negative value designates a preference for it to be DOWN. Each line defines one mitigation procedure's two preferred states.

## Output
If there is no valid configuration, output a single line containing NO.
If a valid configuration is possible, output YES on the first line. On the second line, output n space-separated integers s1 s2 … sn (each being 0 or 1) that represent a valid configuration. Here, 1 indicates UP and 0 indicates DOWN.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any valid one will be accepted. The same switch index can be referenced in multiple procedures.
</STATEMENT>
<RATIONALE>
I removed the explicit "at least one must match" phrase that gave away the standard OR-clause formulation of 2-SAT, replacing it with a description of symmetric hardware overrides (if one state is lacking, the other is mandated). I also encoded the maximum limits for $n$ and $m$ indirectly as a time calculation to force the model to derive the bounds rather than reading them from a standard inequality.
</RATIONALE>
<PRESERVED_ANSWER>
The hardware override rules (if not P1 then P2, and if not P2 then P1) are logically equivalent to requiring at least one of P1 or P2 to be true, meaning the exact same switch configurations are valid.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
This is still exactly the 2-SAT problem, which can be solved in linear time by finding strongly connected components in the implication graph.
</PRESERVED_CLASS>
<RISK>
The indirect bounds calculation (27 hours, 46 minutes, 40 seconds) could be misinterpreted if a model fails to convert it to exactly 100,000 seconds, though the arithmetic is standard.
</RISK>
