# Problem B — Pathway Viability

Time limit: 1 s   Memory limit: 256 MB

## Description

A synthetic organism has a genome consisting of **n** engineered genes. For the organism to survive in a given environment, each gene must be chemically locked into one of two states: Expressed or Suppressed.

The organism's metabolism relies on **m** critical biochemical pathways. Because of built-in biological redundancy, each pathway is triggered by two independent regulatory conditions. A regulatory condition specifies a required state (Expressed or Suppressed) for a particular gene. For a pathway to function properly, the organism's overall genetic state must satisfy at least one of its two regulatory conditions. This dual-trigger mechanism ensures that if a gene must be kept in a specific state for one pathway, another pathway can still operate using its alternative trigger.

Your task is to determine whether it is possible to find a single, comprehensive genetic state for all **n** genes that simultaneously allows all **m** metabolic pathways to function. If such a state exists, you must provide it. If the biological requirements contradict each other such that no viable organism can be synthesized, you must report this failure.

## Input
The first line provides two integers, n and m (1 ≤ n ≤ 10^5, 0 ≤ m ≤ 2·10^5).
The subsequent m lines each contain two non-zero signed integers, l1 and l2, where |li| ≤ n. A positive value indicates a regulatory condition requiring the specified gene to be Expressed, while a negative value indicates a condition requiring the gene to be Suppressed. For each line, the final genetic state must satisfy at least one of the two conditions.

## Output
If there is no viable genetic state, output a single line containing NO.
If a viable state is possible, output YES on the first line. On the second line, output n space-separated integers s1 s2 … sn (each being 0 or 1) that represent a valid state. Here, 1 indicates Expressed and 0 indicates Suppressed.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple viable states may exist; any valid one will be accepted. The same gene index can be referenced in multiple pathways.
