<STATEMENT>
# Problem B — Power Grid Feed Interlocks

Time limit: 1 s   Memory limit: 256 MB

## Description

A power grid operates **n** independent feed lines. Before commissioning, each feed line $i$ must be locked into one of two operational modes, represented by a multiplier $x_i \in \{1, -1\}$. A multiplier of $1$ corresponds to the ENERGIZED mode, while $-1$ corresponds to the ISOLATED mode.

The grid's safety is managed by **m** mutual interlocks. Each interlock balances the operational multipliers of exactly two specific feed lines. You are given the configuration of each interlock as a pair of non-zero integers $c_1$ and $c_2$. For each integer, its absolute value indicates the index of a monitored feed line, and its sign indicates the polarity of the connection. 

An interlock operates securely if and only if the sum of the polarity-adjusted multipliers of its two monitored lines is non-negative. Specifically, the grid must satisfy the following condition for every interlock:
$$ \text{sgn}(c_1) x_{|c_1|} + \text{sgn}(c_2) x_{|c_2|} \ge 0 $$
where $\text{sgn}(c)$ is $1$ if $c > 0$ and $-1$ if $c < 0$.

Determine whether a single global configuration of all $n$ feed lines can secure every interlock simultaneously. If such a configuration exists, report one; otherwise, report that the safety requirements are irreconcilable.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two non-zero signed integers $c_1$ and $c_2$, with $|c_i| \le n$. These integers define the monitored feed lines and connection polarities for one interlock.

## Output
If no secure configuration exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \ s_2 \ \dots \ s_n$ (each in $\{0, 1\}$) forming any secure configuration, where $1$ denotes the ENERGIZED mode ($x_i = 1$) and $0$ denotes the ISOLATED mode ($x_i = -1$).

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple secure configurations may exist; any one is accepted. The same feed line index may appear in multiple interlocks, including within the same interlock.
</STATEMENT>
<RATIONALE>
Replaced explicit logical disjunctions ("at least one of these two monitored states must be present") with an algebraic inequality over $\{-1, 1\}$ variables. This forces models to algebraically deduce that the condition $a + b \ge 0$ for $a, b \in \{-1, 1\}$ implies $\neg(a = -1 \land b = -1)$, requiring a genuine step of structural recognition to uncover the underlying 2-SAT implication graph rather than relying on textbook keyword matching.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical condition $\text{sgn}(c_1) x_{|c_1|} + \text{sgn}(c_2) x_{|c_2|} \ge 0$ strictly prohibits both terms from evaluating to $-1$, which is logically identical to the original requirement that at least one of the two specified feed states must be realized.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, solvable in $O(n+m)$ time by constructing an implication graph and finding strongly connected components, as the algebraic constraints map 1:1 to standard boolean clauses.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the output format if they fail to map the $\{-1, 1\}$ multipliers back to the requested $\{0, 1\}$ integers, though the wording explicitly defines this mapping.
</RISK>
