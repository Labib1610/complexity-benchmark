Looking at this problem, I need to understand the relay constraint:

- If config adopts opposite of mode 1, then config must adopt mode 2
- If config adopts opposite of mode 2, then config must adopt mode 1

Let me denote mode `l` being adopted as variable `x_l = true`. The opposite of mode `l` is `¬l` (flip sign).

The constraint says: if `¬l1` is adopted, then `l2` must be adopted. That is: `x_{¬l1} → x_{l2}`.

Note that `x_{¬l1}` means "feed line |l1| has the opposite mode of l1", which is equivalent to "NOT x_{l1}".

So the constraint is: `¬x_{l1} → x_{l2}`, which is equivalent to `x_{l1} ∨ x_{l2}`.

Similarly the symmetric part: `¬x_{l2} → x_{l1}`, also `x_{l1} ∨ x_{l2}`.

So each relay enforces: `x_{l1} ∨ x_{l2}` (at least one of the two monitored modes must be adopted).

This is a 2-SAT problem. Each clause is `(l1 ∨ l2)`.

For 2-SAT, I'll use the implication graph: clause `(a ∨ b)` gives implications `¬a → b` and `¬b → a`.

Let me encode: variable `i` (1-indexed), value `true` = ENERGIZED. A literal `l` where `l > 0` means `x_l = true`, `l < 0` means `x_{|l|} = false`.

The negation of literal `l` is `-l`.

For clause `(l1 ∨ l2)`: add edges `-l1 → l2` and `-l2 → l1`.

Then find SCCs and check satisfiability.

    # Actually simpler: map literal l to node id

    radj = [[] for _ in range(size)]

        if l > 0:
            return 2 * (l - 1)
        else:
            return 2 * (-l - 1) + 1

        u = node(-l2)
        v = node(l1)

        radj[v].append(u)

    visited = [False] * size
    order = []

    for start in range(size):

- First pass: DFS on original graph, record finish order
- Second pass: process vertices in reverse finish order on transpose graph
- SCCs are found in reverse topological order (of the condensation DAG)

So the first SCC found (smallest comp2 id) is a sink in the condensation, i.e., last in topological order.
