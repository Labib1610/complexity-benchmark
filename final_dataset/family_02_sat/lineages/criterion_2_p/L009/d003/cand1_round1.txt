# Problem B — Power Grid Feed Interlocks

Time limit: 1 s   Memory limit: 256 MB

## Description

A power grid consists of **n** independent feed lines. Prior to commissioning, every feed line must be assigned exactly one of two operational modes: ENERGIZED or ISOLATED.

The grid is safeguarded by **m** fault-prevention relays. Each relay monitors two specific target modes across the network. To ensure stability, each relay enforces an activation guard between its two monitored modes: if the grid configuration adopts the exact opposite of the first monitored mode, the relay triggers a fault unless the grid also adopts the second monitored mode. Symmetrically, if the configuration adopts the opposite of the second monitored mode, the relay triggers a fault unless the grid adopts the first monitored mode. (The opposite of ENERGIZED is ISOLATED, and vice versa). A full grid configuration is deemed secure if zero relays trigger a fault.

Determine whether there exists a global configuration of all $n$ feed lines that is secure, and if so, report one; otherwise, report that the safety requirements are irreconcilable.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two non-zero signed integers $l_1$ and $l_2$, with $|l_i| \le n$. A positive integer $x$ denotes the mode where feed line $x$ is ENERGIZED, while a negative integer $-x$ denotes the mode where feed line $x$ is ISOLATED. Each line defines the two monitored modes $l_1$ and $l_2$ for a single relay, enforcing the activation guard described above.

## Output
If no secure configuration exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \ s_2 \ \dots \ s_n$ (each in $\{0, 1\}$) representing any secure configuration, where 1 denotes ENERGIZED and 0 denotes ISOLATED.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple secure configurations may exist; any one is accepted. The same feed line index may appear in multiple relays.
</STATEMENT>
<RATIONALE>
Removed the "omits both" phrasing that allowed models to trivially apply De Morgan's laws to get a standard `(l1 OR l2)` CNF clause. Replaced it with an activation guard framed as symmetrical implications (`~l1 -> l2` and `~l2 -> l1`), forcing the models to explicitly parse the condition and construct the directed edges rather than relying on standard 2-SAT boilerplate.
</RATIONALE>
<PRESERVED_ANSWER>
The logical condition `(not l1 implies l2) and (not l2 implies l1)` is strictly equivalent to the original `l1 OR l2` requirement, meaning all valid and invalid configurations remain exactly the same.
</PRESERVED_ANSWER>

The problem remains exactly boolean satisfiability with two literals per clause (2-SAT), solvable in linear time using strongly connected components on the implication graph.
</PRESERVED_CLASS>
