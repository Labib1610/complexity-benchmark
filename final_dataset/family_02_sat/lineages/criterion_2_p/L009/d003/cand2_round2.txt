<STATEMENT>
# Problem B — Power Grid Feed Interlocks

Time limit: 1 s   Memory limit: 256 MB

## Description

A power grid consists of independent feed lines. Prior to commissioning, every feed line must be assigned exactly one of two operational modes: ENERGIZED or ISOLATED.

The grid is safeguarded by fault-prevention relays. Each relay monitors two specific target modes across the network. A relay acts as an activation guard: if the grid configuration rejects the first target mode, it mandates adopting the second target mode to prevent a system-wide fault. Symmetrically, rejecting the second target mode mandates adopting the first. Thus, a relay remains secure as long as at least one of its target modes is adopted by the grid. The two target modes monitored by a single relay may even refer to the same feed line.

A full grid configuration is deemed secure if zero relays initiate a fault. Determine whether there exists a global configuration of all feed lines that is secure, and if so, report one; otherwise, report that the safety requirements are irreconcilable.

## Input
The first line contains two integers $n$ and $m$. The physical infrastructure dictates a minimum of 1 feed line and caps the capacity at 100000 feed lines. The control center can integrate anywhere from 0 up to 200000 relays.

Each of the next $m$ lines contains two non-zero signed integers $l_1$ and $l_2$. The absolute value of each, $|l_1|$ and $|l_2|$, will never exceed the total number of feed lines $n$. A positive integer $x$ denotes the mode where feed line $x$ is ENERGIZED, while a negative integer $-x$ denotes the mode where feed line $x$ is ISOLATED. Each line defines a single relay's two target modes.

## Output
If no secure configuration exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \ s_2 \ \dots \ s_n$ (each in $\{0, 1\}$) representing any secure configuration, where 1 denotes ENERGIZED and 0 denotes ISOLATED.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple secure configurations may exist; any one is accepted. The same feed line index may appear in multiple relays.
</STATEMENT>
<RATIONALE>
The definition of relay violation was rewritten from simultaneously omitting both target modes to a bidirectional implication (rejecting one mandates the other). This prevents models from immediately applying De Morgan's laws to produce standard 2-SAT CNF clauses, forcing them to parse the implications and edge directions explicitly. The bounds were integrated into the scenario as physical capacities to fulfill the S07 strategy while retaining the exact literal numerals required by the automated checker.
</RATIONALE>
