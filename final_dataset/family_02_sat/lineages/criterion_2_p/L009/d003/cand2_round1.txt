# Problem B — Power Grid Feed Interlocks

Time limit: 1 s   Memory limit: 256 MB

## Description

A power grid consists of $n$ independent feed lines. The grid's physical infrastructure limits this installation to a minimum of one line and a maximum capacity of one hundred thousand lines. Prior to commissioning, every feed line must be assigned exactly one of two operational modes: ENERGIZED or ISOLATED.

The grid is safeguarded by $m$ fault-prevention relays. The control center can support anywhere from zero relays up to a maximum count equal to exactly double the maximum possible line capacity. Each relay is programmed to track two specific target modes across the network.

To prevent a system-wide fault, each relay enforces a strict contingency protocol between its two target modes. If the grid configuration rejects the first target mode (by setting its corresponding feed line to the alternative mode), the relay acts as an activation guard that strictly mandates adopting the second target mode. Symmetrically, if the grid configuration rejects the second target mode, the relay strictly mandates adopting the first target mode. A full grid configuration is deemed secure if every relay's contingency protocol is satisfied.

Determine whether there exists a global configuration of all $n$ feed lines that is secure, and if so, report one; otherwise, report that the safety requirements are irreconcilable.

## Input
The first line contains two integers $n$ and $m$, representing the number of feed lines and fault-prevention relays, respectively.

Each of the next $m$ lines contains two non-zero signed integers $l_1$ and $l_2$, representing the two target modes for a single relay. The absolute value of any referenced feed line index will never exceed the number of commissioned lines $n$. A positive integer $x$ denotes the target mode where feed line $x$ is ENERGIZED, while a negative integer $-x$ denotes the target mode where feed line $x$ is ISOLATED.

## Output
If no secure configuration exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \ s_2 \ \dots \ s_n$ (each in $\{0, 1\}$) representing any secure configuration, where 1 denotes ENERGIZED and 0 denotes ISOLATED.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple secure configurations may exist; any one is accepted. The same feed line index may appear in multiple relays.
</STATEMENT>
<RATIONALE>
The problem was rewritten to state numeric bounds indirectly through physical infrastructure capacities, forcing models to derive the limits rather than reading bare inequalities. Additionally, the relay logic was transformed from a dual omission condition (easily mapped to a 2-SAT clause using de Morgan's laws) into explicit bidirectional activation guards (implications), forcing models to parse the structural meaning of the edge directions rather than pattern-matching standard CNF boilerplate.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that rejecting one target mode mandates the other is logically identical to stating that both cannot be simultaneously rejected, resulting in the exact same set of valid grid configurations for any input.
</PRESERVED_ANSWER>

The core problem remains an unweighted 2-SAT instance, which can still be solved in $O(n+m)$ time by finding Strongly Connected Components in the corresponding implication graph.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "exactly double the maximum possible line capacity" as $2n$ rather than $200,000$, though this distinction does not alter the asymptotic complexity or required data structures.
</RISK>
