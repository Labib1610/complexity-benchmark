# Problem B — Quantum Routing Configurations

Time limit: 1 s   Memory limit: 256 MB

## Description

A quantum facility contains **n** qubits. Each qubit must be initialized to a spin state of either 0 or 1. 
To ensure coherence, the system undergoes **m** calibration checks. Each check monitors two qubits, specified by two non-zero integers $l_1$ and $l_2$. 

The absolute value $|l_i|$ identifies the qubit being monitored. The sign of $l_i$ establishes the target spin for that connection: a positive sign indicates a target spin of 1, while a negative sign indicates a target spin of 0.

Each check operates a microscopic routing sequence on a separate test array of three particles, initially placed in positions 1, 2, and 3 (so position 1 holds particle 1, position 2 holds particle 2, and position 3 holds particle 3).
The routing sequence consists of two potential position swaps on the test array, executed in order:
1. First, the check examines the first connection ($l_1$). If the actual spin of qubit $|l_1|$ does **not** match its target spin, the particles currently located at position 1 and position 2 are swapped with each other. If it matches, no swap occurs.
2. Next, the check examines the second connection ($l_2$). If the actual spin of qubit $|l_2|$ does **not** match its target spin, the particles currently located at position 2 and position 3 are swapped with each other. If it matches, no swap occurs.

A calibration check is considered *stable* if, after both steps are completed, at least one of the three test particles is located in its original starting position (i.e., position 1 contains particle 1, position 2 contains particle 2, or position 3 contains particle 3). If all three particles have been displaced from their initial positions, the check fails and triggers a decoherence fault.

You must determine whether there exists a single global initialization of all **n** qubits (each set to 0 or 1) such that all **m** calibration checks are stable simultaneously. If such an initialization exists, report one; otherwise, report that the calibration requirements are mutually contradictory.

## Input
The first line contains two integers **n** and **m**. The facility's maximum hardware capacity limits the number of qubits to $100,000$, while the calibration protocol accommodates up to $200,000$ checks. The system requires at least $1$ qubit, but it is possible to have $0$ checks.
Each of the next **m** lines contains two non-zero signed integers $l_1$ and $l_2$. The magnitude of each integer guarantees it refers to a valid qubit (from $1$ up to **n**). The two integers in a check may have the same absolute value.

## Output
If no valid initialization exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print **n** integers $f_1 \ f_2 \dots f_n$ (each in {0, 1}) forming any valid initialization, where the $i$-th integer represents the spin of qubit $i$.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```
