**Solution Explanation**

For every transmitter `i` we have a Boolean variable  

```
xi = 0   (frequency 0 MHz)
xi = 1   (frequency 1 MHz)
```

For a filter we are given two signed integers `l1 , l2`.

```
|l|  – index of the transmitter
sign(l) = +1  →  si =  1
sign(l) = -1  →  si = -1
```

The filter is stable iff  

```
s1·x_a + s2·x_b  ≥  (s1+s2)/2                (1)
```

`x_a , x_b` are the two variables of the filter (they may be the same).

--------------------------------------------------------------------

#### 1.   Translating (1) to a 2‑SAT clause  

All possibilities of the pair `(s1 , s2)` are examined.

| `s1` | `s2` | condition (1)                              | allowed assignments of `(xa,xb)` | 2‑SAT form |
|------|------|--------------------------------------------|-----------------------------------|------------|
|  1   |  1   | `xa + xb ≥ 1`                               | not both `0`                      | `xa ∨ xb` |
| -1   | -1   | `-xa - xb ≥ -1  ⇔  xa + xb ≤ 1`             | not both `1`                      | `¬xa ∨ ¬xb` |
|  1   | -1   | `xa - xb ≥ 0  ⇔  xa ≥ xb`                  | disallow `(0,1)`                  | `xb → xa` |
| -1   |  1   | `-xa + xb ≥ 0  ⇔  xb ≥ xa`                  | disallow `(1,0)`                  | `xa → xb` |

If the two literals refer to the **same** variable (`a == b`) we obtain a
*unit* constraint:

* `s1 = s2 =  1` → `xa = 1`
* `s1 = s2 = -1` → `xa = 0`
* opposite signs → always true, no constraint.

All obtained constraints are classic 2‑SAT clauses (implications or
disjunctions).  
Therefore the whole problem is a 2‑SAT instance.

--------------------------------------------------------------------

#### 2.   2‑SAT encoding  

For each variable `xi` we create two nodes

```
i          – literal  xi   (true)
i + n      – literal ¬xi   (false)
```

Implication `A → B` is stored as a directed edge `A → B`.

Encoding of each clause:

* `xa ∨ xb`                →  (¬xa → xb) , (¬xb → xa)
* `¬xa ∨ ¬xb`             →  (xa → ¬xb) , (xb → ¬xa)
* `xb → xa`               →  (xb → xa) , (¬xa → ¬xb)   (contrapositive)
* `xa → xb`               →  (xa → xb) , (¬xb → ¬xa)
* unit `xa = 1`           →  (¬xa → xa)
* unit `xa = 0`           →  (xa → ¬xa)

The total number of edges is at most `4·m` ( ≤ 8·10⁵ ), well inside limits.

--------------------------------------------------------------------

#### 3.   Solving 2‑SAT  

We run Kosaraju’s algorithm (two DFS passes) on the implication graph
with `2·n` vertices.

*If a variable and its negation belong to the same strongly connected
component, the instance is unsatisfiable.*

Otherwise, the SCCs give a topological order.
The usual rule:

```
xi = true   if   comp(xi) > comp(¬xi)   (processed in reverse topological order)
```

gives a concrete assignment, i.e. the required frequencies.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct tuning
iff such a tuning exists.

---

##### Lemma 1  
For every filter the translation in the table yields a clause that is
satisfied exactly by the assignments fulfilling the original inequality
(1).

**Proof.** Exhaustive case analysis was performed above.
For each pair of signs the set of allowed `(xa,xb)` pairs coincides with
the truth table of the corresponding clause. ∎



##### Lemma 2  
The set of all clauses produced from the input is equivalent to the
original system of filter constraints.

**Proof.** By Lemma&nbsp;1 each individual filter is replaced by a clause
with the same set of satisfying assignments.
The conjunction of all filters is therefore equivalent to the conjunction
of all clauses. ∎



##### Lemma 3  
If the 2‑SAT instance is unsatisfiable, then no global tuning satisfies
all filters.

**Proof.** Unsatisfiability means that for every assignment of the Boolean
variables at least one clause is false.
By Lemma&nbsp;2 a false clause corresponds to a violated filter,
hence no assignment can satisfy all filters. ∎



##### Lemma 4  
If the 2‑SAT instance is satisfiable, the assignment obtained from the
SCC order satisfies every clause.

**Proof.** Standard property of 2‑SAT solved by SCCs:
for each variable `xi` the algorithm never puts `xi` and `¬xi` in the same
SCC, and the chosen truth value respects all implications.
Therefore every clause (which is a pair of implications) is satisfied. ∎



##### Lemma 5  
The assignment produced by the algorithm satisfies all original filters.

**Proof.** By Lemma&nbsp;4 it satisfies all clauses.
By Lemma&nbsp;2 the clauses are equivalent to the filter constraints,
hence the assignment also satisfies every filter. ∎



##### Theorem  
The algorithm outputs  

* “NO” iff no tuning of the `n` transmitters makes all `m` filters stable;
* otherwise “YES” and a tuning that makes all filters stable.

**Proof.**  

*If the algorithm prints “NO”.*  
That happens only when some variable and its negation lie in the same SCC,
i.e. the 2‑SAT instance is unsatisfiable.
By Lemma&nbsp;3 no tuning can satisfy all filters.

*If a valid tuning exists.*  
Then the corresponding Boolean assignment satisfies all clauses
(Lemma&nbsp;2), therefore the 2‑SAT instance is satisfiable.
Kosaraju will not find a contradictory SCC, the algorithm proceeds to
construct an assignment, which by Lemma&nbsp;5 satisfies all filters,
and prints it with “YES”. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Vertices* : `2·n`  
*Edges*    : at most `4·m`  

Kosaraju:

```
first DFS  : O(V + E)
second DFS : O(V + E)
```

Overall  

```
Time   O(n + m)      ≤ 3·10⁵
Memory O(n + m)      ≤ a few MB
```

Both respect the limits.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    N = 2 * n
    g = [[] for _ in range(N)]
    rg = [[] for _ in range(N)]

    def add_imp(u, v):
        g[u].append(v)
        rg[v].append(u)

    def var(i):          # literal xi (true)
        return i
    def neg(i):          # literal ¬xi
        return i + n

    for _ in range(m):
        l1 = int(next(it))
        l2 = int(next(it))
        a = abs(l1) - 1
        b = abs(l2) - 1
        s1 = 1 if l1 > 0 else -1
        s2 = 1 if l2 > 0 else -1

        if a == b:
            # same variable
            if s1 == s2:
                if s1 == 1:
                    # xa = 1
                    add_imp(neg(var(a)), var(a))
                else:
                    # xa = 0
                    add_imp(var(a), neg(var(a)))
            # opposite signs give no restriction
            continue

        # different variables
        if s1 == 1 and s2 == 1:
            # xa ∨ xb
            add_imp(neg(var(a)), var(b))
            add_imp(neg(var(b)), var(a))
        elif s1 == -1 and s2 == -1:
            # ¬xa ∨ ¬xb
            add_imp(var(a), neg(var(b)))
            add_imp(var(b), neg(var(a)))
        elif s1 == 1 and s2 == -1:
            # xb -> xa
            add_imp(var(b), var(a))
            add_imp(neg(var(a)), neg(var(b)))
        elif s1 == -1 and s2 == 1:
            # xa -> xb
            add_imp(var(a), var(b))
            add_imp(neg(var(b)), neg(var(a)))

    # Kosaraju
    visited = [False] * N
    order = []

    def dfs(v):
        visited[v] = True
        for to in g[v]:
            if not visited[to]:
                dfs(to)
        order.append(v)

    for v in range(N):
        if not visited[v]:
            dfs(v)

    comp = [-1] * N
    cid = 0

    def rdfs(v, k):
        comp[v] = k
        for to in rg[v]:
            if comp[to] == -1:
                rdfs(to, k)

    for v in reversed(order):
        if comp[v] == -1:
            rdfs(v, cid)
            cid += 1

    assignment = [0] * n
    for i in range(n):
        if comp[var(i)] == comp[neg(var(i))]:
            print("NO")
            return
        assignment[i] = 1 if comp[var(i)] > comp[neg(var(i))] else 0

    print("YES")
    print(' '.join(map(str, assignment)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
