<STATEMENT>
# Problem B — Thruster Stabilization

Time limit: 1 s   Memory limit: 256 MB

## Description

A robotics facility contains **n** directional thrusters. Each thruster must be locked into one of two orientations, which determines its 3D thrust vector $\vec{v}_k$:
- Orientation 1: $\vec{v}_k = (1, 1, 1)$
- Orientation 0: $\vec{v}_k = (-1, -1, -1)$

The facility has **m** stabilization monitors. Each monitor samples the thrust from two thrusters, specified by two non-zero integers $l_1$ and $l_2$. 
The absolute value $|l_j|$ identifies which thruster is sampled. 
The sign of $l_j$ determines the mounting polarity:
- A positive sign means the thrust is applied directly, contributing a vector $\vec{u}_j = \vec{v}_{|l_j|}$.
- A negative sign means the thrust is mechanically inverted, contributing a vector $\vec{u}_j = -\vec{v}_{|l_j|}$.

Each monitor calculates a net force vector by summing its two sampled vectors and a constant bias vector $\vec{B} = (2, 2, 2)$. The net force is $\vec{F} = \vec{u}_1 + \vec{u}_2 + \vec{B}$.

A monitor is considered stable if and only if the net force vector $\vec{F}$ is strictly non-zero (i.e., its magnitude is greater than 0). If $\vec{F} = (0, 0, 0)$, a deadzone fault occurs.

You must determine whether there exists a single global configuration of all **n** thrusters (each set to orientation $0$ or $1$) such that all **m** monitors are stable simultaneously. If such a configuration exists, report one; otherwise, report that the requirements are mutually contradictory.

## Input
The first line contains two integers **n** and **m** (1 ≤ n ≤ 10^5, 0 ≤ m ≤ 2·10^5).
Each of the next **m** lines contains two non-zero signed integers $l_1$ and $l_2$. For each integer, $1 \le |l_i| \le n$. 
The two integers in a monitor may have the same absolute value (meaning the monitor samples the same thruster twice, potentially with the same or opposite polarities).

## Output
If no valid configuration exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print **n** integers $s_1 \ s_2 \dots s_n$ (each in {0, 1}) forming any valid configuration, where the $i$-th integer represents the orientation of thruster $i$.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any one is accepted. The same thruster may appear in multiple monitors, and even twice within the same monitor.

<RATIONALE>
Changed the explicit scalar boolean condition into a 3D vector sum $\vec{F} = \vec{u}_1 + \vec{u}_2 + (2, 2, 2) \neq (0, 0, 0)$. This forces models to algebraically deduce that failure uniquely occurs when both sampled vectors are $(-1, -1, -1)$, breaking their reliance on recognizing "sum of deviations < 2" as a trivial 2-SAT clause.
</RATIONALE>
<PRESERVED_ANSWER>
The vector sum equals $(0, 0, 0)$ if and only if both sampled vectors evaluate to $(-1, -1, -1)$, which perfectly matches the original boolean condition where a fault occurs if and only if both connections simultaneously miss their targets.
</PRESERVED_ANSWER>

The problem remains exactly 2-SAT, as the vector condition trivially reduces to a pairwise boolean implication constraint, solvable in O(n+m) time using standard strongly connected component algorithms.
</PRESERVED_CLASS>
