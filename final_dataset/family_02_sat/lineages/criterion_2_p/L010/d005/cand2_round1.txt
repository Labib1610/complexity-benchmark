<STATEMENT>
# Problem B — Harmonic Filter Tuning

Time limit: 1 s   Memory limit: 256 MB

## Description

A communications array consists of **n** transmitters. Each transmitter must be tuned to a carrier frequency of either 0 MHz or 1 MHz.

To prevent interference, the array is equipped with **m** harmonic filters. Each filter processes two transmitter signals and specifies a *suppression target* for each. 
The suppression target for a transmitter is 1 MHz if its corresponding integer in the filter's configuration is positive, and 0 MHz if the integer is negative.

For each of its two signals, the filter generates a beat signal equal to the absolute difference between the transmitter's actual carrier frequency and its suppression target. 
The filter is considered stable if the sum of its two beat signals is strictly less than 2 MHz. If the sum reaches 2 MHz, the filter overloads and causes a system fault.

You need to determine if there is a global frequency assignment for all **n** transmitters that keeps all **m** filters stable simultaneously. If such an assignment exists, report one; otherwise, report that the filters are mutually contradictory.

## Input
The first line contains two integers **n** and **m**. The number of transmitters **n** is between 1 and the number of millimeters in 100 meters (inclusive). The number of filters **m** is between 0 and double that maximum amount (inclusive).
Each of the next **m** lines contains two non-zero signed integers $l_1$ and $l_2$. The absolute value $|l_i|$ identifies a transmitter index (from 1 to **n**). The sign of $l_i$ provides the suppression target for that transmitter in the filter.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise print `YES` on the first line. On the second line print **n** integers $s_1 \ s_2 \dots s_n$ (each in {0, 1}) forming any valid assignment, where 1 represents 1 MHz and 0 represents 0 MHz.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid assignments may exist; any one is accepted. The same transmitter may appear in multiple filters.
</STATEMENT>
<METHOD_NAME>Continuous Threshold Encoding</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit boolean logic and algebraic sign-product inequality with a continuous-looking threshold condition (sum of absolute differences strictly less than a maximum). This forces the model to deduce the discrete state space and evaluate the threshold to discover it is logically equivalent to a standard 2-SAT disjunction.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<RATIONALE>
Removed the explicit algebraic inequality `V(|l_1|) * sgn(l_1) + V(|l_2|) * sgn(l_2) >= 0` that models were using to immediately recognize the 2-SAT clause structure. Replaced it with a physical narrative about beat frequencies where the sum of absolute differences must be strictly less than 2, alongside converting explicit bounds to an indirect metric deduction. This forces the model to evaluate the possible absolute difference combinations (0+0, 1+0, 0+1, 1+1) to deduce that the condition means the two transmitters cannot both mismatch their targets.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the sum of absolute differences is strictly less than 2 is mathematically identical to forbidding the state where both transmitters mismatch their targets, preserving the exact same valid boolean assignments as the original problem for every input.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT because each filter still enforces a strict disjunction (OR) between two boolean conditions, solvable in linear time via an implication graph.
</PRESERVED_CLASS>
<RISK>
Models might struggle to correctly translate "number of millimeters in 100 meters" to 100,000, though this is a standard metric conversion with no ambiguity.
</RISK>
