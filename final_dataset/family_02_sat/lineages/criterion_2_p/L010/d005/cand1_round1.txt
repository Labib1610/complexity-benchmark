<STATEMENT>
# Problem B — Configuration State Search

Time limit: 1 s   Memory limit: 256 MB

## Description

A control panel has **n** binary switches, each of which can be set to ON or OFF. Commissioning supplies **m** hardware interlocks that enforce dependency rules between switches to prevent system faults. 

Each interlock connects two switches and is defined by two non-zero integers $l_1$ and $l_2$. The absolute value $|l_i|$ identifies the switch index. The sign of $l_i$ specifies the required state for that switch: a positive sign requires the switch to be ON, and a negative sign requires it to be OFF.

To determine if an interlock is satisfied, a diagnostic test is performed using a virtual directional pointer:
1. Initially, the pointer faces East.
2. If the current state of switch $|l_1|$ contradicts its required state (i.e., it is OFF when $l_1 > 0$, or ON when $l_1 < 0$), the pointer is rotated 90 degrees counter-clockwise. Otherwise, its direction remains unchanged.
3. Next, if the current state of switch $|l_2|$ contradicts its required state, the pointer is rotated an additional 90 degrees counter-clockwise from its current orientation. Otherwise, it remains unchanged.

An interlock is satisfied if and only if, after these two steps, the pointer is NOT facing West.

A system fault occurs if any of the **m** interlocks is not satisfied. Given the vast number of possible global states, engineers need to know if a valid state exists without an exhaustive search. 

Decide whether a single global ON/OFF setting of all **n** switches avoids all system faults simultaneously. If such a configuration exists, report one; otherwise, report that the interlocks are mutually contradictory.

## Input
The first line contains two integers **n** and **m** (1 ≤ n ≤ 10^5, 0 ≤ m ≤ 2·10^5).
Each of the next **m** lines contains two non-zero signed integers $l_1$ and $l_2$, with $|l_i| \le n$. 

The absolute value $|l_i|$ identifies a switch. The sign of $l_i$ indicates its required state for the diagnostic test (positive for ON, negative for OFF).

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise print `YES` on the first line. On the second line print **n** integers $s_1 \ s_2 \dots s_n$ (each in {0, 1}) forming any valid assignment, where 1 represents ON and 0 represents OFF.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid assignments may exist; any one is accepted. The same switch may appear in multiple interlocks.

<METHOD_NAME>
Geometric State Machine Encoding
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces an explicit algebraic boolean inequality with a small sequential state machine (a pointer rotating through cardinal directions) that evaluates to the same truth table. Models relying on pattern-matching inequalities to CNF clauses will fail to recognize the 2-SAT structure without symbolically executing the state machine to deduce the forbidden configuration.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<RATIONALE>
The previous version used an explicit algebraic inequality over {-1, 1} states that transparently encoded a 2-SAT clause, allowing models to bypass reasoning and immediately map it to standard logic. I removed the inequality and replaced it with a geometric state machine where contradictions trigger 90-degree rotations. To succeed, models must now symbolically execute the rotations to deduce that "NOT facing West" strictly forbids the double-contradiction state, requiring genuine logical deduction to recover the structural OR condition.
</RATIONALE>
<PRESERVED_ANSWER>
The pointer faces West (180 degrees from East) if and only if both switches contradict their required states, meaning the condition "NOT facing West" is logically identical to the original requirement that at least one switch matches its sign.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, solvable in O(n+m) time by constructing an implication graph and finding strongly connected components.
</PRESERVED_CLASS>
