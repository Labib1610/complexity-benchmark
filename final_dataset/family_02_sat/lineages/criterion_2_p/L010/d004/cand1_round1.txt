<STATEMENT>
# Problem B — Configuration State Search

Time limit: 1 s   Memory limit: 256 MB

## Description

A control panel has **n** binary switches, whose states are represented by variables $s_1, s_2, \dots, s_n \in \{0, 1\}$. Commissioning supplies **m** hardware interlocks that enforce dependency rules between switches to prevent system faults. 

For any non-zero integer $l$, we define its alignment mismatch $E(l)$ as follows:
- $E(l) = 1 - s_{l}$ if $l > 0$
- $E(l) = s_{-l}$ if $l < 0$

Each of the **m** interlocks is specified by two non-zero integers $l_1$ and $l_2$. The interference generated by a single interlock is the product of their alignment mismatches: $E(l_1) \times E(l_2)$.

The system's total interference is the sum of the interference terms from all **m** interlocks. Given the vast number of possible global states, engineers need to know if a valid state exists without an exhaustive search. 

Decide whether a single global setting of all **n** switches results in a total interference of exactly 0. If such a configuration exists, report one; otherwise, report that the interlocks are mutually contradictory.

## Input
The first line contains two integers **n** and **m** (1 ≤ n ≤ 10^5, 0 ≤ m ≤ 2·10^5).
Each of the next **m** lines contains two non-zero signed integers $l_1$ and $l_2$, with $|l_i| \le n$. 

These integers represent the two parameters for that specific interlock's interference term, as defined in the description. The absolute value $|l_i|$ identifies the switch index, and the sign determines which alignment mismatch formula applies.

## Output
If no configuration results in a total interference of 0, print a single line `NO`.
Otherwise print `YES` on the first line. On the second line print **n** integers $s_1 \ s_2 \dots s_n$ (each in {0, 1}) forming any valid assignment, where 1 represents ON and 0 represents OFF.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid assignments may exist; any one is accepted. The same switch may appear in multiple interlocks.

<RATIONALE>
The previous wording explicitly stated that a fault occurs when both switches are simultaneously set opposite to their targets, which models pattern-matched instantly to the boolean logic `~(~A and ~B) = (A or B)`. This rewrite replaces the boolean framing entirely with an algebraic one. Models must now deduce mathematically that because the variables are binary, the sum of products being exactly zero implies every individual product must be zero, which in turn implies a set of logical OR clauses, before they can recognize the standard 2-SAT structure.
</RATIONALE>
<PRESERVED_ANSWER>
Because $s_i \in \{0, 1\}$, every mismatch $E(l)$ is either 0 or 1, making all interference products non-negative; thus the sum is 0 if and only if every product is 0, which is mathematically identical to the original requirement that no two forbidden opposite states occur simultaneously.
</PRESERVED_ANSWER>
