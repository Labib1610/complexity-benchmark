**Solution Explanation**

For every switch `i`

* `ON`  → value `V(i) = 1`
* `OFF` → value `V(i) = -1`

For a clause (interlock) we are given two signed numbers `l1 , l2`.

```
a = |l1| ,  s1 = sign(l1)   ( +1 or -1 )
b = |l2| ,  s2 = sign(l2)
```

The clause is satisfied iff  

```
s1 * V(a) + s2 * V(b)  ≥ 0
```

Because each term is `±1`, the sum can be `-2 , 0 , 2`.  
The inequality forbids only the case `-2`, i.e. **both terms are -1**.
So the clause is equivalent to

```
(s1 * V(a) = +1)  OR  (s2 * V(b) = +1)
```

Define a Boolean variable  

```
x_i = 1   ⇔   V(i) = +1   (switch i is ON)
x_i = 0   ⇔   V(i) = -1   (switch i is OFF)
```

Then

```
s1 * V(a) = +1   ⇔   (s1 = +1  →  x_a = 1)   or   (s1 = -1  →  x_a = 0)
```

Thus each clause becomes a **2‑SAT clause** of the form  

```
(literal A)  OR  (literal B)
```

where a literal is either a variable `x_i` or its negation `¬x_i`.

The whole problem is exactly the classic 2‑SAT problem.

--------------------------------------------------------------------

#### 2‑SAT via implication graph

For `n` Boolean variables we create `2·n` vertices

```
vertex 2*i     :  ¬x_i   (x_i = false)
vertex 2*i + 1 :   x_i   (x_i = true)
```

For a clause `(A ∨ B)` we add two directed edges

```
¬A → B
¬B → A
```

The formula is satisfiable **iff** no variable and its negation belong to the
same strongly connected component (SCC) of this graph.

We compute SCCs with Kosaraju’s algorithm (two DFS passes).  
If for some `i` the two vertices of `x_i` are in the same SCC → `NO`.

Otherwise we obtain a topological order of the SCC‑condensation graph.
A standard way to get a satisfying assignment is:

```
x_i = true   if   comp[vertex of x_i]  >  comp[vertex of ¬x_i]
          else false
```

(`comp` is the order in which SCCs are discovered in the second pass;
larger numbers are earlier in topological order.)

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct assignment
iff such an assignment exists.

---

##### Lemma 1  
For any clause `(l1 , l2)` the condition  

```
sgn(l1)·V(|l1|) + sgn(l2)·V(|l2|) ≥ 0
```

holds **iff** the Boolean clause  

```
(l1 > 0 ? x_|l1| : ¬x_|l1|)  ∨  (l2 > 0 ? x_|l2| : ¬x_|l2|)
```

holds.

**Proof.**  
`sgn(l)·V(|l|) = +1` exactly when `V(|l|) = sgn(l)`.  
If `sgn(l)=+1` this means `V=+1` → `x=1`.  
If `sgn(l)=-1` this means `V=-1` → `x=0` → `¬x` is true.  
Thus the term is `+1` iff the corresponding literal is true.
The sum can be `-2` only when *both* terms are `-1`, i.e. when *both*
literals are false. Therefore the sum is non‑negative exactly when at
least one literal is true, i.e. the Boolean clause is satisfied. ∎



##### Lemma 2  
The implication graph built by the algorithm is exactly the standard
implication graph of the Boolean formula consisting of all clauses from
Lemma&nbsp;1.

**Proof.**  
For a clause `(A ∨ B)` the standard construction adds edges `¬A → B`
and `¬B → A`. The algorithm does the same for every input clause,
using the mapping described in Lemma&nbsp;1. ∎



##### Lemma 3  
If the algorithm outputs `NO` then the original set of interlocks is
unsatisfiable.

**Proof.**  
`NO` is printed only when for some variable `i` the two vertices
`x_i` and `¬x_i` belong to the same SCC.
In any assignment all vertices inside one SCC must have the same truth
value (reachability in both directions). Hence `x_i` and `¬x_i` would
have to be simultaneously true, impossible. By Lemma&nbsp;2 the SCC
condition is necessary for satisfiability of the Boolean formula, and by
Lemma&nbsp;1 for the original interlocks. ∎



##### Lemma 4  
If the algorithm outputs `YES` and the assignment `A` it constructs,
then every clause of the Boolean formula (hence every interlock) is
satisfied.

**Proof.**  
When `YES` is printed, for every `i` the two vertices lie in different
SCCs. The algorithm sets `x_i = true` exactly when the SCC of `x_i`
appears **before** the SCC of `¬x_i` in the topological order
(`comp[x_i] > comp[¬x_i]`).  
Consider any edge `u → v` of the implication graph.
If `u` is true under this rule, then `comp[u] > comp[¬u]`.  
Because `u → v` implies `comp[u] ≥ comp[v]` (edges go from later to
earlier SCCs), we have `comp[v] ≤ comp[u]`.  
If `v` were false, then `comp[v] < comp[¬v]`. Combining the inequalities
gives `comp[u] > comp[¬v]`. But `¬v` is the negation of `v`, and there is
an edge `¬v → u` (the other implication of the same clause). This would
contradict the topological order. Hence `v` must be true.  
Thus every implication is respected, which is equivalent to the
satisfaction of all clauses. By Lemma&nbsp;1 the original interlocks are
satisfied. ∎



##### Lemma 5  
If the original interlocks are satisfiable, the algorithm never prints
`NO`.

**Proof.**  
Assume a satisfying assignment exists. By Lemma&nbsp;1 it satisfies the
Boolean formula, therefore the Boolean formula is satisfiable.
For a satisfiable 2‑SAT instance the implication graph never contains a
variable and its negation in the same SCC (standard 2‑SAT theory). Hence
the algorithm will not encounter such a pair and will not output `NO`. ∎



##### Theorem  
The algorithm prints `YES` and a correct configuration exactly when such
a configuration exists; otherwise it prints `NO`.

**Proof.**  
*If* the algorithm prints `YES`, Lemma&nbsp;4 guarantees the printed
configuration satisfies all interlocks.  
*Only if* a satisfying configuration exists, Lemma&nbsp;5 shows the
algorithm cannot output `NO`; consequently it outputs `YES`.  
If the algorithm outputs `NO`, Lemma&nbsp;3 shows no configuration can
satisfy all interlocks. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Vertices*: `2·n ≤ 2·10⁵`  
*Edges*: two per clause → `2·m ≤ 4·10⁵`

Kosaraju:

* first DFS – `O(V+E)`
* second DFS – `O(V+E)`

Overall time `O(n + m)` ≤ `3·10⁵` operations, well inside the 1 s limit.  
Memory: adjacency lists for both directions, each storing `E` integers,
plus a few auxiliary arrays → `O(V + E)` ≤ a few MB, far below 256 MB.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    n = next(it)
    m = next(it)

    N = 2 * n                     # total vertices
    g = [[] for _ in range(N)]    # forward graph
    rg = [[] for _ in range(N)]   # reversed graph

    def lit_index(var, is_true):
        """return vertex index for literal (x_var) if is_true else (¬x_var)"""
        return 2 * var + (1 if is_true else 0)

    for _ in range(m):
        l1 = next(it)
        l2 = next(it)
        a = abs(l1) - 1
        b = abs(l2) - 1
        # literal A
        if l1 > 0:
            A = lit_index(a, True)      # x_a
        else:
            A = lit_index(a, False)     # ¬x_a
        # literal B
        if l2 > 0:
            B = lit_index(b, True)
        else:
            B = lit_index(b, False)

        notA = A ^ 1
        notB = B ^ 1
        # ¬A → B
        g[notA].append(B)
        rg[B].append(notA)
        # ¬B → A
        g[notB].append(A)
        rg[A].append(notB)

    sys.setrecursionlimit(1 << 25)

    visited = [False] * N
    order = []

    # first pass: fill order by finish time
    def dfs(v):
        stack = [(v, 0)]
        while stack:
            node, state = stack.pop()
            if state == 0:
                if visited[node]:
                    continue
                visited[node] = True
                stack.append((node, 1))
                for to in g[node]:
                    if not visited[to]:
                        stack.append((to, 0))
            else:
                order.append(node)

    for v in range(N):
        if not visited[v]:
            dfs(v)

    comp = [-1] * N
    cur = 0

    # second pass: assign components on reversed graph
    def rdfs(v, label):
        stack = [v]
        comp[v] = label
        while stack:
            node = stack.pop()
            for to in rg[node]:
                if comp[to] == -1:
                    comp[to] = label
                    stack.append(to)

    for v in reversed(order):
        if comp[v] == -1:
            rdfs(v, cur)
            cur += 1

    # check for contradictions
    for i in range(n):
        if comp[2*i] == comp[2*i + 1]:
            print("NO")
            return

    # build assignment
    assignment = [0] * n
    for i in range(n):
        # true component must be "earlier" (higher number) in topological order
        assignment[i] = 1 if comp[2*i + 1] > comp[2*i] else 0

    print("YES")
    print(' '.join(map(str, assignment)))

if __name__ == "__main__":
    solve()
```

and conforms to the required input‑output format.
