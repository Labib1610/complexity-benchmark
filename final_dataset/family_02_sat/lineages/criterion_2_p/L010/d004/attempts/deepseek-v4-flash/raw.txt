We can model each switch as a boolean variable and each interlock as a 2-SAT clause.

For an interlock with values \(l_1, l_2\):

- If \(l_i > 0\), it means the literal is \(x_{|l_i|}\) (switch ON).
- If \(l_i < 0\), it means the literal is \(\neg x_{|l_i|}\) (switch OFF).

The condition:
\[
V(|l_1|) \cdot sgn(l_1) + V(|l_2|) \cdot sgn(l_2) \ge 0
\]
translates to:  
At least one of the two literals must be true.  
That is exactly a 2-SAT clause: \((lit_1 \lor lit_2)\).

So the problem reduces to:  
Given \(m\) clauses of 2 literals over \(n\) variables, find a satisfying assignment or report unsatisfiable.

We can solve 2-SAT in \(O(n+m)\) using implication graph and SCC (Kosaraju or Tarjan).

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(1 << 20)
input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    N = 2 * n  # nodes: 2*i for false, 2*i+1 for true
    g = [[] for _ in range(N)]
    gr = [[] for _ in range(N)]

    def add_imp(u, v):
        g[u].append(v)
        gr[v].append(u)

    for _ in range(m):
        a, b = map(int, input().split())
        # literal index: for variable x (1-based), true = 2*(x-1)+1, false = 2*(x-1)
        def lit(l):
            var = abs(l) - 1
            return 2 * var + (1 if l > 0 else 0)
        l1 = lit(a)
        l2 = lit(b)
        # (l1 or l2) => (!l1 -> l2) and (!l2 -> l1)
        add_imp(l1 ^ 1, l2)
        add_imp(l2 ^ 1, l1)

    # Kosaraju SCC
    visited = [False] * N
    order = []
    def dfs1(u):
        visited[u] = True
        for v in g[u]:
            if not visited[v]:
                dfs1(v)
        order.append(u)

    for i in range(N):
        if not visited[i]:
            dfs1(i)

    comp = [-1] * N
    def dfs2(u, cid):
        comp[u] = cid
        for v in gr[u]:
            if comp[v] == -1:
                dfs2(v, cid)

    cid = 0
    for u in reversed(order):
        if comp[u] == -1:
            dfs2(u, cid)
            cid += 1

    for i in range(n):
        if comp[2*i] == comp[2*i+1]:
            print("NO")
            return

    print("YES")
    # assignment: if comp[true] > comp[false] then true
    res = []
    for i in range(n):
        if comp[2*i+1] > comp[2*i]:
            res.append('1')
        else:
            res.append('0')
    print(' '.join(res))

if __name__ == "__main__":
    solve()
```
