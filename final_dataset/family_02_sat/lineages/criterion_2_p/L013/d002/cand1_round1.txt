<STATEMENT>
# Problem B — Paired Window Constraints

Time limit: 1 s   Memory limit: 256 MB

## Description
A control panel features $n$ binary switches that must be configured prior to a system test. The commissioning team has provided $m$ operational requirements to prevent hardware resonance. 

Each requirement defines two primary states, where a state refers to a particular switch being set to a specific polarity (either ON or OFF). The *inverse* of a state means that the underlying switch is instead set to the opposite polarity. Due to the electrical wiring, if a system is configured such that it simultaneously adopts the inverse of the first primary state AND the inverse of the second primary state, a critical short circuit will occur. Therefore, a valid configuration must never activate the inverse of both primary states listed in any single requirement.

Your task is to determine whether it is possible to configure all $n$ switches simultaneously such that no short circuits occur across all $m$ requirements. If such a configuration exists, you must provide it. If no global configuration can avoid all short circuits simultaneously, you must report that the system is unconfigurable.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of switches and the number of requirements, respectively.
Each of the following $m$ lines contains two non-zero signed integers $l_1$ and $l_2$ ($1 \le |l_i| \le n$). For each requirement, the absolute value indicates the switch index, and the sign indicates its primary polarity (positive for ON, negative for OFF). The final switch configuration must avoid the simultaneous assignment of the inverse of $l_1$'s primary state and the inverse of $l_2$'s primary state.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{0, 1\}$) representing a valid assignment, where $1$ denotes ON and $0$ denotes OFF.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any one of them is accepted. The same switch may be referenced in multiple requirements.
</STATEMENT>
<RATIONALE>
I replaced the explicit disjunction ("at least one state must be active") with a negated conjunction ("never simultaneously activate the inverse of both primary states"). This removes the textbook 2-CNF phrasing and forces the models to apply De Morgan's laws or implication logic to the narrative constraints to build their graph.
</RATIONALE>
<PRESERVED_ANSWER>
By De Morgan's laws, avoiding the simultaneous occurrence of the inverses of two states is logically identical to satisfying at least one of the original states, leaving all valid configurations exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains identically 2-SAT, which is solvable in $O(n+m)$ time using Tarjan's or Kosaraju's algorithm on the implication graph.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "simultaneous assignment" when $l_1$ and $l_2$ refer to the exact same switch, though standard boolean logic gracefully simplifies "A and A" to "A".
</RISK>
