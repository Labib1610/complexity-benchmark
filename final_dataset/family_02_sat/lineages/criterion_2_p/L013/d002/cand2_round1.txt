<STATEMENT>
# Problem B — Paired Window Constraints

Time limit: 1 s   Memory limit: 256 MB

## Description
A control panel features $n$ binary switches that must be configured prior to a system test. The system architecture imposes a physical limit of at least 1 and at most 100,000 switches on the panel. The commissioning team has provided $m$ safety interlock rules; the safety controller's memory capacity allows it to store anywhere from 0 up to 200,000 such rules.

Each interlock rule is programmed with two target switch polarities (where a polarity means a switch is either ON or OFF). The rule will trigger a critical system fault if and only if both of the monitored switches are simultaneously set to the exact opposite of their target polarities. 

Your task is to determine whether it is possible to configure all $n$ switches simultaneously such that zero system faults are triggered by any of the $m$ rules. If such a configuration exists, you must provide it. If no global configuration can satisfy the safety controller without triggering a fault, you must report that the system is unconfigurable.

## Input
The first line contains two integers $n$ and $m$, representing the number of switches and the number of interlock rules, respectively.
Each of the following $m$ lines contains two non-zero signed integers $l_1$ and $l_2$, describing the two target polarities for a rule. The absolute value of each integer corresponds to a valid switch index (1 through $n$), and the sign indicates the target polarity (positive for ON, negative for OFF).

## Output
If no valid assignment exists without triggering a fault, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers (each either 0 or 1) representing a valid assignment, where 1 denotes ON and 0 denotes OFF.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any one of them is accepted. The same switch may be referenced in multiple interlock rules.
</STATEMENT>
<RATIONALE>
The problem was rewritten to describe the constraints as avoiding a conjunction of opposite events ("fault if both are exactly opposite") rather than satisfying a disjunction ("at least one must be active"). Numeric bounds were moved from the Input section into the narrative description as physical and memory limits. This forces the model to construct the 2-SAT logic internally via De Morgan's laws rather than pattern-matching standard CNF clause definitions, and to parse constraints from natural language.
</RATIONALE>
<PRESERVED_ANSWER>
By De Morgan's laws, avoiding the condition where both switches are the opposite of their targets is logically identical to satisfying at least one target, preserving all valid assignments exactly.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is mathematically identical to 2-SAT, which remains solvable in linear time using an implication graph and strongly connected components.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "both of the monitored switches" when a rule references the same switch twice, though logically treating it as two independent checks of the same switch yields the correct result.
</RISK>
