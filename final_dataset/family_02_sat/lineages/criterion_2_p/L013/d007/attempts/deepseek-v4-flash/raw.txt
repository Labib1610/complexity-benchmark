We can model each detector as a constraint on the toggle variables.  
Let’s analyze the condition.

For a manifold \( l \):

- If \( l > 0 \), then \(\delta(l) = 0\), so  
  \( P(l) = (-1)^{s_{|l|}} \).  
  This is \(+1\) if \(s_{|l|}=0\), and \(-1\) if \(s_{|l|}=1\).

- If \( l < 0 \), then \(\delta(l) = 1\), so  
  \( P(l) = (-1)^{s_{|l|} + 1} = -(-1)^{s_{|l|}} \).  
  This is \(-1\) if \(s_{|l|}=0\), and \(+1\) if \(s_{|l|}=1\).

So effectively, the sign of \(l\) flips the phase.

A detector is dormant if \(P(l_1) + P(l_2) \le 0\).  
Since each \(P\) is \(\pm 1\), the sum can be:

- \(2\) (both +1) → triggers
- \(0\) (one +1, one -1) → dormant
- \(-2\) (both -1) → dormant

So the only forbidden case is both phases being \(+1\).

Thus, for each detector, we must **not** have both phases equal to \(+1\).

---

Let’s define a variable \(x_i = s_i\) (0 or 1).  
For a manifold \(l\):

- If \(l > 0\): phase is \(+1\) when \(x_{|l|} = 0\).
- If \(l < 0\): phase is \(+1\) when \(x_{|l|} = 1\).

So each detector forbids a specific combination of two variables.

We can encode each detector as a 2-SAT clause:  
We need at least one of the two phases to be \(-1\).  
That is:  
- If \(l_1 > 0\), phase1 = +1 when \(x_{a}=0\), so to avoid +1 we need \(x_a=1\).  
- If \(l_1 < 0\), phase1 = +1 when \(x_a=1\), so to avoid +1 we need \(x_a=0\).

So for each detector, we get a clause:  
\((x_a = \text{val1}) \lor (x_b = \text{val2})\)  
where val is 1 if \(l>0\), 0 if \(l<0\).

This is a standard 2-SAT problem.

---

We can solve 2-SAT with implication graph and SCC.

Let’s implement:

```python
import sys
sys.setrecursionlimit(1 << 20)

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    # 2-SAT: variable i (0-index) -> node 2*i (false), 2*i+1 (true)
    N = 2 * n
    g = [[] for _ in range(N)]
    gr = [[] for _ in range(N)]

    def add_imp(u, v):
        g[u].append(v)
        gr[v].append(u)

    def add_clause(a, va, b, vb):
        # (a == va) OR (b == vb)
        # equivalent to (a != va) -> (b == vb) and (b != vb) -> (a == va)
        # node for x is 2*x + (1 if true else 0)
        na = 2 * a + (1 if va else 0)
        nb = 2 * b + (1 if vb else 0)
        # not a -> b
        add_imp(na ^ 1, nb)
        # not b -> a
        add_imp(nb ^ 1, na)

    for _ in range(m):
        l1, l2 = map(int, input().split())
        a = abs(l1) - 1
        b = abs(l2) - 1
        va = 1 if l1 > 0 else 0
        vb = 1 if l2 > 0 else 0
        add_clause(a, va, b, vb)

    # Kosaraju SCC
    visited = [False] * N
    order = []
    def dfs1(u):
        visited[u] = True
        for v in g[u]:
            if not visited[v]:
                dfs1(v)
        order.append(u)

    for i in range(N):
        if not visited[i]:
            dfs1(i)

    comp = [-1] * N
    def dfs2(u, cid):
        comp[u] = cid
        for v in gr[u]:
            if comp[v] == -1:
                dfs2(v, cid)

    cid = 0
    for u in reversed(order):
        if comp[u] == -1:
            dfs2(u, cid)
            cid += 1

    for i in range(n):
        if comp[2*i] == comp[2*i+1]:
            print("NO")
            return

    # Assign values: if comp[2*i] > comp[2*i+1] then true
    res = []
    for i in range(n):
        if comp[2*i] > comp[2*i+1]:
            res.append(1)
        else:
            res.append(0)

    print("YES")
    print(" ".join(map(str, res)))

if __name__ == "__main__":
    solve()
```
