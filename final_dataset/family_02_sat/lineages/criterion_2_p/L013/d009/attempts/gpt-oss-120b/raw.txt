**Solution Explanation**

For a connection `l`

* `|l| = i` – it is attached to strut `i`
* `l > 0` – *standard* mount  
  displacement = `+1`  iff `s_i = 1` , otherwise `-1`
* `l < 0` – *inverted* mount  
  displacement = `+1`  iff `s_i = 0` , otherwise `-1`

For a brace we add the two displacements.
The brace **breaks** only when the sum is `-2`, i.e. **both**
displacements are `-1`.

So for every brace we must forbid the situation  

```
disp(connection 1) = -1   AND   disp(connection 2) = -1
```

which is equivalent to the logical clause  

```
disp(connection 1) = +1   OR   disp(connection 2) = +1
```

--------------------------------------------------------------------

### 1.   From displacements to Boolean literals
For a connection `l` (`i = |l|`)

```
l > 0   →   disp = +1  ⇔  s_i = 1          (literal  s_i )
l < 0   →   disp = +1  ⇔  s_i = 0          (literal ¬s_i)
```

Thus each brace gives a **2‑SAT clause** `(L1 ∨ L2)` where each
`Lk` is either a variable `s_i` or its negation `¬s_i`.

--------------------------------------------------------------------

### 2.   2‑SAT formulation
*Variables* – `s_1 … s_n` (boolean, `True` means `1`).

*Clause* – for a brace with connections `l1 , l2`

```
(L1 ∨ L2)          where
    L =  s_i   if l > 0
    L = ¬s_i   if l < 0
```

Standard reduction to implication graph:

```
(L1 ∨ L2)   ⇔   (¬L1 → L2)  and  (¬L2 → L1)
```

The graph has `2·n` vertices (`s_i` true / false).  
We run SCC (Kosaraju) :

* if a variable and its negation belong to the same SCC → unsatisfiable.
* otherwise, the SCC topological order gives a satisfying assignment
  (the component that appears later gets value `True`).

--------------------------------------------------------------------

### 3.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct configuration
iff such a configuration exists.

---

#### Lemma 1  
For any connection `l` the statement “its displacement is `+1`”
is equivalent to the Boolean literal  

```
s_i          if l > 0
¬s_i         if l < 0
```

*Proof.* Directly from the definition of the mounts (see table above). ∎



#### Lemma 2  
A brace does **not** break exactly when the clause
`(L1 ∨ L2)` (defined from its two connections) is satisfied.

*Proof.*  
Brace breaks ⇔ both displacements are `-1`.  
Using Lemma&nbsp;1, “displacement = -1” is the negation of the literal
that makes it `+1`. Therefore “both are -1” ⇔ “¬L1 ∧ ¬L2”.  
Negating gives “not (¬L1 ∧ ¬L2)” ⇔ “L1 ∨ L2”. ∎



#### Lemma 3  
A truth assignment to the variables satisfies **all** clauses
iff it keeps **all** braces intact.

*Proof.* Immediate from Lemma&nbsp;2 applied to every brace. ∎



#### Lemma 4  
The implication graph built by the algorithm is exactly the standard
graph for the 2‑SAT instance consisting of all clauses.

*Proof.* For each clause `(L1 ∨ L2)` the algorithm adds edges
`(¬L1 → L2)` and `(¬L2 → L1)`, which is the textbook reduction. ∎



#### Lemma 5  
If the algorithm outputs “NO”, the original problem has no solution.

*Proof.* “NO” is printed only when some variable and its negation lie in
the same SCC. By properties of 2‑SAT, this makes the formula unsatisfiable.
By Lemma&nbsp;3 the original problem is unsatisfiable as well. ∎



#### Lemma 6  
If the algorithm outputs “YES” and a configuration `s`,
then `s` keeps all braces intact.

*Proof.* When “YES” is printed, the SCCs are acyclic and no variable
conflicts with its negation, so the standard SCC‑ordering assignment
produces a satisfying assignment of the 2‑SAT formula.
By Lemma&nbsp;3 this assignment satisfies every brace. ∎



#### Lemma 7  
If a configuration keeping all braces intact exists,
the algorithm outputs “YES”.

*Proof.* Existence of a configuration means the 2‑SAT formula is
satisfiable (Lemma&nbsp;3). A satisfiable 2‑SAT instance never has a
variable and its negation in the same SCC, therefore the algorithm will
not output “NO”. It will compute a satisfying assignment and print “YES”. ∎



#### Theorem  
The algorithm prints “YES” and a correct configuration
iff such a configuration exists; otherwise it prints “NO”.

*Proof.*  
*If* part – Lemma&nbsp;6.  
*Only‑if* part – Lemma&nbsp;5 together with Lemma&nbsp;7. ∎



--------------------------------------------------------------------

### 4.   Complexity Analysis
*Vertices* : `2·n`  
*Edges*    : `2·m` (two per clause)

Kosaraju runs in `O(V + E) = O(n + m)` time and memory.

Both limits satisfy the problem constraints (`n ≤ 10⁵`, `m ≤ 2·10⁵`).

--------------------------------------------------------------------

### 5.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    N = 2 * n                     # 0..2n-1, even = false, odd = true
    g = [[] for _ in range(N)]
    rg = [[] for _ in range(N)]

    def lit(l):
        """return node id of literal that is true when displacement = +1"""
        idx = abs(l) - 1
        if l > 0:                 # need s_i = 1  -> true literal
            return 2 * idx + 1
        else:                     # need s_i = 0  -> false literal
            return 2 * idx

    for _ in range(m):
        l1 = int(next(it))
        l2 = int(next(it))
        a = lit(l1)
        b = lit(l2)
        na = a ^ 1          # negation
        nb = b ^ 1
        # (a ∨ b)  => (¬a → b) , (¬b → a)
        g[na].append(b)
        rg[b].append(na)
        g[nb].append(a)
        rg[a].append(nb)

    visited = [False] * N
    order = []

    def dfs(v):
        visited[v] = True
        for to in g[v]:
            if not visited[to]:
                dfs(to)
        order.append(v)

    for v in range(N):
        if not visited[v]:
            dfs(v)

    comp = [-1] * N
    cur = 0

    def rdfs(v, k):
        comp[v] = k
        for to in rg[v]:
            if comp[to] == -1:
                rdfs(to, k)

    for v in reversed(order):
        if comp[v] == -1:
            rdfs(v, cur)
            cur += 1

    assignment = [0] * n
    for i in range(n):
        if comp[2 * i] == comp[2 * i + 1]:
            print("NO")
            return
        # component with larger number appears earlier in topological order
        assignment[i] = 1 if comp[2 * i + 1] > comp[2 * i] else 0

    print("YES")
    print(' '.join(map(str, assignment)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
