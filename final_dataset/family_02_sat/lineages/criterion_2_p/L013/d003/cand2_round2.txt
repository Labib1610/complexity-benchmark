<STATEMENT>
# Problem B — Paired Window Constraints

Time limit: 1 s   Memory limit: 256 MB

## Description
A control panel features $n$ binary switches that must be configured prior to a system test. The commissioning team has provided $m$ safety rules. Each rule monitors a pair of target switch settings. A target setting is defined by a switch index and a desired position (either ON or OFF). 

Each safety rule establishes a failsafe dependency between its two target settings. The rule dictates that if the final configuration fails to adopt the first target setting, it becomes strictly obligated to adopt the second target setting. Symmetrically, failing to adopt the second target setting obligates the configuration to adopt the first. A system fault is triggered if the panel's configuration violates this failsafe dependency.

Your task is to determine whether a global configuration exists for all $n$ switches such that zero system faults are triggered. If such a configuration exists, you must provide it. If no such configuration is possible, print `NO` as specified in the Output section.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of switches and the number of safety rules, respectively.
Each of the following $m$ lines contains two non-zero signed integers $l_1$ and $l_2$ ($1 \le |l_i| \le n$). For each target setting, the absolute value indicates the switch index. A positive integer $k$ indicates a target setting of ON for switch $k$, while a negative integer $-k$ indicates a target setting of OFF for switch $k$. The two target settings in a rule may refer to the same switch, and may be identical or opposite.

## Output
If no fault-free configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{0, 1\}$) representing a valid configuration, where $1$ denotes ON and $0$ denotes OFF.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any valid configuration is accepted. The same switch may be monitored by multiple rules.
</STATEMENT>
<RATIONALE>
The description of the safety rules was rewritten to remove the direct "contradicts both" and "matches one or both" phrasing, which models were using to immediately recognize the standard 2-SAT clause `(A OR B)`. Instead, the rules are described through conditional obligations (`NOT A implies B`, and `NOT B implies A`). This forces models to parse the failsafe mechanism and deduce the boolean logic rather than matching the standard DIMACS-style clause description. Explicit numerical bounds were restored in the Input section to satisfy strict formatting constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The logical requirement for a safety rule is mathematically equivalent to the original: a rule is satisfied if and only if at least one of its target settings is adopted, keeping all valid configurations identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, solvable in $O(n+m)$ time by finding strongly connected components in the implication graph.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the conditional obligation as a strict directional implication (only checking the first condition) if they fail to read the sentence explicitly stating the symmetry, though the symmetry is clearly stated.
</RISK>
