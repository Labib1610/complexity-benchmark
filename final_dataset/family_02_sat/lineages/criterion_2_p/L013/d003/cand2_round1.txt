<STATEMENT>
# Problem B — Paired Window Constraints

Time limit: 1 s   Memory limit: 256 MB

## Description
A control panel features $n$ binary switches that must be configured prior to a system test. The panel hardware supports up to one hundred thousand switches, and the diagnostic module can track up to two hundred thousand safety rules. The commissioning team has provided $m$ such rules for the current test.

Each safety rule links two specific switch states. A state is defined by a switch index and a position (either ON or OFF). The rule enforces a fallback condition: any configuration that fails to exhibit the first specified state is strictly required to exhibit the second specified state. (Because the rule is symmetric, failing to exhibit the second state similarly requires exhibiting the first). A system fault occurs if the configuration violates any rule's fallback condition.

Your task is to determine whether a global configuration exists for all $n$ switches such that zero system faults are triggered. If such a configuration exists, you must provide it. If no such configuration is possible, you must report that the system is unconfigurable.

## Input
The first line contains two integers $n$ and $m$, representing the number of switches (at least one) and the number of safety rules (which can be zero), respectively. These values will not exceed the hardware and diagnostic capacities described above.
Each of the following $m$ lines contains two non-zero signed integers $l_1$ and $l_2$. The absolute value of each integer corresponds to a valid switch index (from $1$ to $n$). A positive integer indicates the ON state, while a negative integer indicates the OFF state. The two states in a rule may refer to the same switch, and may be identical or opposite.

## Output
If no fault-free configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{0, 1\}$) representing a valid configuration, where $1$ denotes ON and $0$ denotes OFF.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any one of them is accepted. The same switch may be monitored by multiple rules.
</STATEMENT>
<RATIONALE>
The problem was rewritten to use conditional implication framing ("failing to exhibit the first specified state strictly requires exhibiting the second") instead of a negated conjunction ("contradicts both"). This removes the direct translation to standard DIMACS 2-SAT OR clauses, forcing models to reason through the implication logic to construct the equivalent clauses or graph edges. Additionally, per Strategy S07, all bare inequalities for the numeric bounds were replaced with textual descriptions of physical capacities and valid ranges.
</RATIONALE>
<PRESERVED_ANSWER>
The logical requirement that failing one state necessitates the other is strictly equivalent to the original requirement that the configuration cannot contradict both states simultaneously, leaving all valid configurations unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, solvable in linear time by finding strongly connected components on the implication graph.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "fails to exhibit" if they do not correctly map a state to a specific switch index and its ON/OFF position, but the definition of a state is explicitly provided in the text to prevent this.
</RISK>
