# Orbital Synchronization Framework

Time limit: 1 s   Memory limit: 256 MB

## Description
A satellite orbital framework contains $n$ synchronization nodes. Each node $i$ ($1 \le i \le n$) is controlled by a binary mode $s_i \in \{0, 1\}$.
- Setting $s_i = 1$ configures the node to broadcast a prograde phase shift, represented by the permutation cycle $(A \to B \to C \to A)$ on three orbital sectors.
- Setting $s_i = 0$ configures the node to broadcast a retrograde phase shift, represented by the permutation cycle $(A \to C \to B \to A)$.

The framework is reinforced by $m$ interference channels. Each channel spans exactly two terminals across the network. A channel's terminals are specified by two non-zero integers $l_1$ and $l_2$. For any terminal $l$:
- The absolute value $|l|$ identifies the node index it attaches to.
- The sign of $l$ dictates its signal processing relative to the channel:
  - If $l > 0$, it is a direct feed. The terminal broadcasts the node's phase shift exactly as configured.
  - If $l < 0$, it is an inverted feed. The terminal reverses the direction of the node's phase shift (a prograde shift becomes retrograde, and a retrograde shift becomes prograde).

Inside each channel, the phase shifts from its two terminals are applied sequentially (the shift from $l_1$ is applied first, followed by the shift from $l_2$).
A channel will experience catastrophic desynchronization if and only if the combined effect of its two phase shifts is exactly the prograde cycle $(A \to B \to C \to A)$. If the combined effect is the identity (no net change) or the retrograde cycle $(A \to C \to B \to A)$, the channel safely absorbs the interference and remains stable.

Your task is to determine whether there is a configuration of modes $s_1, s_2, \dots, s_n$ such that all $m$ channels remain stable. If it is possible, you must provide the configuration. If no such configuration exists, print a single line containing `NO`.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of nodes and the number of channels, respectively.

Each of the following $m$ lines contains two non-zero integers $l_1$ and $l_2$ ($1 \le |l_i| \le n$), detailing the two terminals for a single channel. The two terminals for a channel may attach to the same node, may be the exact same terminal ($l_1 = l_2$), or may be the same node with opposite signs ($l_1 = -l_2$). The same pair of terminals may also appear on multiple channels. 

## Output
If no valid configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{0, 1\}$) representing a valid configuration.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any one of them is accepted. If $m = 0$, there are no channels to desynchronize, so any combination of $n$ valid modes is acceptable.
