**Solution Explanation**

For a brace we are given two connections `l1 , l2`.

```
t(l) = 1 - s[|l|]   if l > 0          (direct coupling)
t(l) = s[|l|]       if l < 0          (inverted coupling)
```

Inside the brace the forces `x , y` must satisfy  

```
x + t(l1)·y = 0
t(l2)·x + y = 0
```

The only safe situation is that the linear system has the unique solution `x = y = 0`.
The coefficient matrix is  

```
| 1   t(l1) |
| t(l2)  1 |
```

Its determinant is `1 - t(l1)·t(l2)`.  
The system is non‑trivial **iff** the determinant is `0`, i.e. `t(l1)=t(l2)=1`.

Therefore a brace is safe **iff** it is **not** the case that both
` t(l1) = 1 ` **and** ` t(l2) = 1 `.

--------------------------------------------------------------------

#### 1.   From braces to Boolean constraints

For a connection `l`

```
t(l) = 1   ⇔   ( l > 0  and  s[|l|] = 0 )
            or ( l < 0  and  s[|l|] = 1 )
```

Define a *literal*  

```
L(l) :  s[|l|] = val(l)          where   val(l) = 0 if l>0 else 1
```

`L(l)` is true exactly when `t(l)=1`.

The safety condition of a brace becomes

```
¬L(l1)  ∨  ¬L(l2)                (at most one of the two literals may be true)
```

That is a 2‑SAT clause.  
For each brace we add the two implications

```
L(l1) → ¬L(l2)          L(l2) → ¬L(l1)
```

--------------------------------------------------------------------

#### 2.   2‑SAT formulation

We have `n` Boolean variables `s1 … sn`.  
For each variable we create two nodes:

* `i`   – literal `s_i = 1` (true)
* `i^`  – literal `s_i = 0` (false)

A literal `L(l)` is either `i` or `i^` depending on the sign of `l`.

For a clause `¬A ∨ ¬B` we add edges  

```
A → ¬B
B → ¬A
```

All edges are stored in an adjacency list ( ≤ 2·m edges).

--------------------------------------------------------------------

#### 3.   Solving 2‑SAT

Standard Kosaraju / Tarjan SCC algorithm (iterative to avoid recursion limit).

*If a variable and its negation belong to the same SCC → unsatisfiable.*

Otherwise, the SCCs give a topological order.  
If `comp(i) > comp(i^)` we set `s_i = 0`, else `s_i = 1`
(the component with larger topological number comes earlier in the reverse order).

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm outputs “YES” and a correct assignment
iff such an assignment exists.

---

##### Lemma 1  
For any brace with connections `l1 , l2` the brace is safe
iff the Boolean clause `¬L(l1) ∨ ¬L(l2)` holds.

**Proof.**  
`L(l)` is true exactly when `t(l)=1`.  
Brace unsafe ⇔ `t(l1)=t(l2)=1` ⇔ `L(l1)` and `L(l2)` are both true ⇔
`¬L(l1) ∨ ¬L(l2)` is false. ∎



##### Lemma 2  
For every brace the two implications added by the algorithm are
logically equivalent to the clause `¬L(l1) ∨ ¬L(l2)`.

**Proof.**  
A clause `¬A ∨ ¬B` is equivalent to `(A → ¬B) ∧ (B → ¬A)`.  
The algorithm adds exactly these two directed edges, i.e. the two
implications. ∎



##### Lemma 3  
An assignment of the variables satisfies all added implications
iff it satisfies all brace safety conditions.

**Proof.**  
By Lemma&nbsp;2 each brace contributes exactly the implications of its
clause. An assignment satisfies all implications ⇔ it satisfies all
clauses ⇔ (by Lemma&nbsp;1) it satisfies all safety conditions. ∎



##### Lemma 4  
If the SCC algorithm declares the instance unsatisfiable
(i.e. some variable and its negation lie in the same SCC),
then no assignment can satisfy all braces.

**Proof.**  
In any implication graph, if a variable `v` reaches `¬v` and `¬v` reaches
`v`, then any truth assignment would force `v` to be both true and false.
Thus no assignment can satisfy all implications, and by Lemma&nbsp;3
cannot satisfy all braces. ∎



##### Lemma 5  
If the SCC algorithm finds no such conflict, the assignment constructed
from the SCC topological order satisfies all implications.

**Proof.**  
Standard property of 2‑SAT: ordering SCCs in reverse topological order,
assign a variable false when its SCC appears later than that of its
negation guarantees that every implication edge goes from a true literal
to a true literal, never from true to false. Hence all implications hold. ∎



##### Lemma 6  
The assignment produced by the algorithm satisfies all braces.

**Proof.**  
By Lemma&nbsp;5 it satisfies all implications, therefore all clauses,
therefore (Lemma&nbsp;1) all brace safety conditions. ∎



##### Theorem  
The algorithm outputs

* “NO” iff no configuration of `s_i` keeps all braces safe,
* otherwise “YES” and a configuration that keeps all braces safe.

**Proof.**  

*If algorithm outputs “NO”.*  
That happens only when a variable and its negation share an SCC.
By Lemma&nbsp;4 no satisfying assignment exists.

*If a satisfying configuration exists.*  
Then the implication graph is satisfiable, so no variable conflicts with
its negation; the SCC step will not detect a conflict.
The algorithm will output “YES” and the assignment from Lemma&nbsp;5,
which by Lemma&nbsp;6 is a satisfying configuration.

Thus the output is correct in both directions. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis

*Vertices*: `2·n`  
*Edges*: at most `2·m` (two per brace)

*Building the graph*: `O(n + m)`  
*Kosaraju (two DFS passes)*: `O(n + m)`  
*Assignment*: `O(n)`

Memory: adjacency lists store `O(n + m)` integers → ≤ ~3·10⁵ entries,
well inside the limits.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    N = 2 * n                     # node count
    g = [[] for _ in range(N)]
    rg = [[] for _ in range(N)]

    def lit(idx, val):
        """return node number for literal s_idx == val (val 0/1)"""
        # node for true (s=1) is 2*idx, false (s=0) is 2*idx+1
        # we map: true -> 2*idx, false -> 2*idx+1
        return 2 * idx + (0 if val else 1)

    def add_imp(u, v):
        g[u].append(v)
        rg[v].append(u)

    for _ in range(m):
        l1 = int(next(it))
        l2 = int(next(it))
        i1 = abs(l1) - 1
        i2 = abs(l2) - 1
        val1 = 0 if l1 > 0 else 1   # L(l) true when s_i == val
        val2 = 0 if l2 > 0 else 1
        a = lit(i1, val1)           # literal L(l1)
        b = lit(i2, val2)           # literal L(l2)
        na = a ^ 1                  # negation node (toggle last bit)
        nb = b ^ 1
        # clause ¬a ∨ ¬b  => a -> ¬b , b -> ¬a
        add_imp(a, nb)
        add_imp(b, na)

    # Kosaraju
    visited = [False] * N
    order = []

    def dfs(v):
        stack = [(v, 0)]
        while stack:
            v, state = stack.pop()
            if state == 0:
                if visited[v]:
                    continue
                visited[v] = True
                stack.append((v, 1))
                for to in g[v]:
                    if not visited[to]:
                        stack.append((to, 0))
            else:
                order.append(v)

    for v in range(N):
        if not visited[v]:
            dfs(v)

    comp = [-1] * N
    cid = 0
    for v in reversed(order):
        if comp[v] != -1:
            continue
        stack = [v]
        comp[v] = cid
        while stack:
            x = stack.pop()
            for to in rg[x]:
                if comp[to] == -1:
                    comp[to] = cid
                    stack.append(to)
        cid += 1

    assignment = [0] * n
    for i in range(n):
        if comp[2*i] == comp[2*i+1]:
            print("NO")
            return
        # component with larger number appears earlier in topological order
        assignment[i] = 0 if comp[2*i] > comp[2*i+1] else 1

    print("YES")
    print(' '.join(map(str, assignment)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
