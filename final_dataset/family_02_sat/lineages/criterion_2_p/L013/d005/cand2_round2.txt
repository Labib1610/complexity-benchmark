<STATEMENT>
# Problem B — Paired Window Constraints

Time limit: 1 s   Memory limit: 256 MB

## Description
A control panel features $n$ binary switches, each taking a state $s_i \in \{0, 1\}$. The commissioning team has provided $m$ hardware safety relays. Each relay monitors a pair of expected switch positions to ensure redundancy.

An expected position is specified by a non-zero integer $l$. The absolute value $|l|$ identifies the switch index ($1 \le |l| \le n$). A positive integer means the expected position is ON ($1$), while a negative integer means the expected position is OFF ($0$).

Each of the $m$ relays is wired to two such expected positions, $l_1$ and $l_2$. A relay will trip and trigger a system shutdown if and only if both of its monitored positions are simultaneously violated—that is, when the actual state of the switch for $l_1$ is the opposite of its expected state, and the actual state of the switch for $l_2$ is also the opposite of its expected state. As long as a relay has at least one of its monitored expected positions matching the actual switch configuration, it remains stable.

Your task is to determine whether a global configuration $s_1, s_2, \dots, s_n$ exists such that no relay trips. If such a configuration is possible, you must provide it. If no such configuration exists, you must report that the system is unconfigurable.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of switches and the number of relays, respectively.

Each of the following $m$ lines contains two non-zero signed integers $l_1$ and $l_2$ ($1 \le |l_i| \le n$). For each expected position, the absolute value indicates the switch index. A positive integer defines an expected position of ON, while a negative integer defines an expected position of OFF. The two expected positions monitored by a relay may refer to the same switch, and they may be identical or opposite.

## Output
If no valid configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{0, 1\}$) representing a valid configuration, where $1$ denotes ON and $0$ denotes OFF.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any one of them is accepted. The same switch may be monitored by multiple relays.
</STATEMENT>
<RATIONALE>
I completely removed the factored zero-product equation `(A)(B)=0`, which the surviving models trivially parsed as an algebraic definition of an OR-clause. Instead, I described the constraint through a physical scenario (a safety relay that trips only when both expected positions are simultaneously violated). This forces the model to independently deduce the boolean logic and construct the implication graph from text rather than pattern-matching an equation.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that a relay trips if and only if both expected positions fail is logically identical to the original requirement that at least one position must be satisfied, meaning all valid configurations remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT because each relay enforces a logical OR between two boolean literals, which is solvable in linear time using an implication graph and strongly connected components.
</PRESERVED_CLASS>
