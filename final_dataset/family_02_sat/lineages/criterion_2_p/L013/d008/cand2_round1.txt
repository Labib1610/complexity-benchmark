<STATEMENT>
# Dual-Manifold Chemical Routing

Time limit: 1 s   Memory limit: 256 MB

## Description
A chemical processing plant contains $n$ flow distributors. Each distributor $i$ ($1 \le i \le n$) is controlled by a binary toggle $s_i \in \{0, 1\}$.

The plant's safety system includes $m$ reaction detectors. Each detector samples exactly two manifolds across the plant. A detector's connection is specified by two non-zero integers $l_1$ and $l_2$. The absolute value of each integer identifies the distributor index from which the manifold samples.

Each detector evaluates the compatibility of the toggle states of its two sampled distributors. Due to the physical routing, each detector has exactly one *critical blind spot*—a specific combination of states that it cannot regulate. If the toggle states of the two sampled distributors exactly match this blind spot simultaneously, the detector will trigger a catastrophic shutdown. As long as the states do not match the blind spot, the detector safely dissipates the reaction and remains dormant.

The critical blind spot for a detector is determined entirely by the signs of its connection integers $l_1$ and $l_2$:
- For the first manifold $l_1$, the critical state for distributor $|l_1|$ is $0$ if $l_1 > 0$, and $1$ if $l_1 < 0$.
- For the second manifold $l_2$, the critical state for distributor $|l_2|$ is $0$ if $l_2 > 0$, and $1$ if $l_2 < 0$.

For example, if a detector samples $l_1 = 3$ and $l_2 = -5$, its blind spot is triggered if and only if $s_3 = 0$ and $s_5 = 1$ simultaneously.

Your task is to determine whether there is a configuration of toggles $s_1, s_2, \dots, s_n$ such that all $m$ detectors remain dormant. If it is possible, you must provide the configuration. If no such configuration exists, report that the plant is unconfigurable.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of distributors and the number of detectors, respectively.

Each of the following $m$ lines contains two non-zero integers $l_1$ and $l_2$ ($1 \le |l_i| \le n$), detailing the two manifolds sampled by a single detector. The two manifolds sampled by a detector may belong to the same distributor, and may even be the exact same manifold.

## Output
If no valid configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{0, 1\}$) representing a valid configuration.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any one of them is accepted. The same distributor may be sampled by multiple detectors.
