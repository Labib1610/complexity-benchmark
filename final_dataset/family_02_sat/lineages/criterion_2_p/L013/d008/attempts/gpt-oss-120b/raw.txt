**Solution Explanation**

For a distributor `i`

* `s[i] = 1` – it produces isotope 1  
* `s[i] = 0` – it produces isotope 0  

A manifold is described by a signed integer `l`

* `|l| = i` – it is connected to distributor `i`
* `l > 0` – the isotope is transmitted unchanged
* `l < 0` – the isotope is flipped (0↔1)

Therefore the isotope that reaches a detector through `l` is  

```
value(l) = s[|l|] xor (l < 0)          (1)
```

A detector samples two manifolds `l1 , l2`.  
It **fails** only when *both* isotopes are `0` :

```
value(l1) = 0  AND  value(l2) = 0
```

The detector must stay dormant, i.e. the above situation must be impossible.
Negating it we obtain the required condition

```
value(l1) = 1  OR  value(l2) = 1                (2)
```

--------------------------------------------------------------------

#### 1.   From the plant to a 2‑SAT instance
Using (1) in (2)

```
(s[a] xor f1) = 1   OR   (s[b] xor f2) = 1
```

where  

```
a = |l1| ,   f1 = (l1 < 0) ? 1 : 0
b = |l2| ,   f2 = (l2 < 0) ? 1 : 0
```

`x xor 1 = 1`  ⇔  `x = 0`  
`x xor 0 = 1`  ⇔  `x = 1`

Thus (2) is equivalent to the **2‑SAT clause**

```
(s[a] = ¬f1)  OR  (s[b] = ¬f2)                (3)
```

A clause of the form  
`(variable i is value vi) OR (variable j is value vj)`  
is a standard 2‑SAT clause.

--------------------------------------------------------------------

#### 2.   Implication graph
For every variable `i` we have two literals  

* `i = 0`  → node `2*i`
* `i = 1`  → node `2*i+1`

The negation of a literal is the opposite value, i.e. `node ^ 1`.

Clause `(i = vi) OR (j = vj)` is transformed into two implications

```
(i = ¬vi) → (j = vj)
(j = ¬vj) → (i = vi)
```

and the corresponding directed edges are added to the graph.

The graph contains at most `2*m` edges (two per clause), i.e. ≤ 4·10⁵.

--------------------------------------------------------------------

#### 3.   Solving 2‑SAT
We run Kosaraju’s algorithm (or Tarjan) to obtain strongly connected
components (SCCs).

*If a variable and its negation belong to the same SCC the instance is
unsatisfiable.*

Otherwise the SCCs form a DAG.  
Processing them in reverse topological order gives a satisfying assignment:

```
s[i] = 1   if   comp[ node(i,1) ] > comp[ node(i,0) ]
s[i] = 0   otherwise
```

(The component numbers produced by Kosaraju already respect the reverse
topological order.)

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct configuration
iff such a configuration exists.

---

##### Lemma 1  
For every detector the clause (3) is satisfied **iff** the detector does
not trigger.

**Proof.**  
From the definition of `value(l)` (1) the detector triggers exactly when
`value(l1)=0` and `value(l2)=0`.  
Negating gives condition (2). Substituting `value(l)=s xor f` yields (3).
∎



##### Lemma 2  
The implication graph built from all detectors is exactly the implication
graph of the 2‑SAT formula consisting of all clauses (3).

**Proof.**  
Each clause (3) is transformed by the standard rule into the two
implications used when adding edges. No other edges are added.
∎



##### Lemma 3  
If the algorithm reports “NO”, the plant is unconfigurable.

**Proof.**  
“NO” is printed only when some variable `i` and its negation belong to the
same SCC. By properties of 2‑SAT, a formula containing such a pair is
unsatisfiable. By Lemma&nbsp;2 the formula is equivalent to the set of
detector constraints, and by Lemma&nbsp;1 each clause is exactly the
requirement that the corresponding detector stays dormant. Hence no
assignment of the toggles can keep all detectors dormant. ∎



##### Lemma 4  
If the algorithm prints an assignment `s[1…n]`, every detector stays
dormant.

**Proof.**  
When the algorithm finishes, for each variable `i` the assignment respects
the SCC order, i.e. a literal is set to `true` only if its SCC is **after**
the SCC of its negation. This is the standard construction of a satisfying
assignment for a 2‑SAT instance, therefore all clauses (3) are true.
By Lemma&nbsp;1 each clause being true means the corresponding detector
does not trigger. ∎



##### Lemma 5  
If a configuration keeping all detectors dormant exists, the algorithm
outputs “YES”.

**Proof.**  
Assume a satisfying toggle assignment exists. By Lemma&nbsp;1 it satisfies
all clauses (3), therefore the 2‑SAT formula is satisfiable.
A satisfiable 2‑SAT instance never has a variable and its negation in the
same SCC, so the algorithm will not output “NO”. Consequently it proceeds
to construct an assignment, which by Lemma&nbsp;4 is also satisfying, and
prints “YES”. ∎



##### Theorem  
The algorithm outputs

* “NO” **iff** no toggle configuration keeps all detectors dormant,
* otherwise “YES” and a configuration that keeps all detectors dormant.

**Proof.**  
*If* part: Lemma&nbsp;3.  
*Only‑if* part: Lemma&nbsp;5 together with Lemma&nbsp;4. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis
*Building the graph* – `O(m)` edges, `O(n+m)` time.  
*Kosaraju* – linear in vertices + edges: `O(n + m)`.  
*Assignment* – `O(n)`.

Memory: adjacency lists for at most `2*m ≤ 4·10⁵` edges and `2*n ≤ 2·10⁵`
nodes → `O(n+m)` ≤ ~6·10⁵ integers, well inside the limit.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    N = 2 * n                     # node count
    g = [[] for _ in range(N)]
    rg = [[] for _ in range(N)]

    def node(var: int, val: int) -> int:
        """literal node: var in [0..n-1], val in {0,1}"""
        return var * 2 + val

    for _ in range(m):
        l1 = int(next(it))
        l2 = int(next(it))
        a = abs(l1) - 1
        b = abs(l2) - 1
        f1 = 1 if l1 < 0 else 0
        f2 = 1 if l2 < 0 else 0
        # clause: (s[a] = not f1) OR (s[b] = not f2)
        va = 1 - f1
        vb = 1 - f2

        # (a = not va) -> (b = vb)
        u = node(a, 1 - va)
        v = node(b, vb)
        g[u].append(v)
        rg[v].append(u)

        # (b = not vb) -> (a = va)
        u = node(b, 1 - vb)
        v = node(a, va)
        g[u].append(v)
        rg[v].append(u)

    # Kosaraju
    visited = [False] * N
    order = []

    def dfs(v: int):
        visited[v] = True
        for to in g[v]:
            if not visited[to]:
                dfs(to)
        order.append(v)

    for v in range(N):
        if not visited[v]:
            dfs(v)

    comp = [-1] * N
    cur = 0

    def rdfs(v: int, k: int):
        comp[v] = k
        for to in rg[v]:
            if comp[to] == -1:
                rdfs(to, k)

    for v in reversed(order):
        if comp[v] == -1:
            rdfs(v, cur)
            cur += 1

    assignment = [0] * n
    for i in range(n):
        if comp[node(i, 0)] == comp[node(i, 1)]:
            print("NO")
            return
        assignment[i] = 1 if comp[node(i, 1)] > comp[node(i, 0)] else 0

    print("YES")
    print(' '.join(map(str, assignment)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input‑output format.
