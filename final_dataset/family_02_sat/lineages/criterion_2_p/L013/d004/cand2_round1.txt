<METHOD_DESCRIPTION>Replaces the boolean logic / implication rules with a purely algebraic formulation (sum of polarity-adjusted voltages >= 0). This forces the model to realize that a sum of two values in {-1, 1} being non-negative is mathematically equivalent to a boolean OR clause, preventing pattern-matching on standard 2-SAT phrasings.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Paired Window Constraints

Time limit: 1 s   Memory limit: 256 MB

## Description
A control panel features $n$ binary switches that must be configured prior to a system test. Each switch $k$ is assigned a state $s_k \in \{0, 1\}$. 

The system's internal logic operates on bipolar voltages. The voltage of switch $k$ is determined by its state as $V_k = 2s_k - 1$.

The commissioning team has provided $m$ hardware interlocks. Each interlock monitors two switch connections (which may refer to the same switch). An interlock is defined by two non-zero integers $l_1$ and $l_2$. For each connection $l_i$:
- The absolute value $|l_i|$ indicates the index of the monitored switch.
- The sign of $l_i$ defines the polarity multiplier $p_i = l_i / |l_i|$ (which is $1$ if $l_i > 0$, and $-1$ if $l_i < 0$).

An interlock calculates a combined measurement $M$ by adding the polarity-adjusted voltages of its two connections:
$$M = V_{|l_1|} \cdot p_1 + V_{|l_2|} \cdot p_2$$

To ensure a safe system test, every interlock must measure a non-negative total voltage (i.e., $M \ge 0$). 

Your task is to determine whether a global configuration exists for all $n$ switches such that no interlock evaluates to a negative measurement. If such a configuration exists, you must provide it. If no such configuration is possible, you must report that the system is unconfigurable.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of switches and the number of interlocks, respectively.

Each of the following $m$ lines contains two non-zero signed integers $l_1$ and $l_2$ ($1 \le |l_i| \le n$), representing the two connections of an interlock. The two connections in an interlock may refer to the same switch, and may be identical or opposite.

## Output
If no valid configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{0, 1\}$) representing a valid configuration.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any one of them is accepted. The same switch may be monitored by multiple interlocks.
</STATEMENT>
<RATIONALE>
Removed the explicit implication logic ("if opposite, requires expected") and replaced it with a purely algebraic inequality over bipolar variables. To solve the problem efficiently, models must now deduce that $V \cdot p \in \{-1, 1\}$, and thus $M \ge 0$ is mathematically equivalent to the boolean disjunction of the two expected states, requiring them to independently reconstruct the 2-SAT reduction.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $M \ge 0$ holds if and only if at least one connection matches its expected polarity, perfectly preserving the exact same satisfying assignments as the original 2-SAT problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT (solvable in O(N+M) time via strongly connected components), simply expressed through algebraic constraints equivalent to boolean clauses.
</PRESERVED_CLASS>
