<STATEMENT>
# Problem B — Paired Window Constraints

Time limit: 1 s   Memory limit: 256 MB

## Description

The system configuration pipeline operates in three stages. First, a parser analyzes complex user requirements for $n$ modules. Each module must be assigned exactly one operational mode: Mode 1 or Mode 0. This parser outputs a list of $m$ critical safety constraints.

In the second stage—which your program must implement—you evaluate these constraints. Each constraint specifies a potential point of failure involving two target settings. A target setting is represented by a non-zero signed integer: a positive value $x$ targets module $x$ operating in Mode 1, and a negative value $-x$ targets module $x$ operating in Mode 0. 

A constraint consisting of settings $l_1$ and $l_2$ guarantees a system failure if and only if the global configuration contradicts both target settings simultaneously. That is, the failure occurs exactly when the module for $l_1$ is placed in the mode opposite to $l_1$'s target, and the module for $l_2$ is placed in the mode opposite to $l_2$'s target. Your task is to determine whether a single global assignment of modes for all $n$ modules exists that avoids triggering any of the $m$ failures. If a safe configuration exists, report one. Otherwise, report that the constraints are mutually contradictory.

Finally, in the third stage, a downstream controller will read your output and physically actuate the modules.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two non-zero signed integers $l_1$ and $l_2$, with $|l_i| \le n$. These represent the two target settings for a constraint. A positive integer $x$ targets module $x$ in Mode 1, and a negative integer $-x$ targets module $x$ in Mode 0. A constraint triggers a failure if and only if both target settings are contradicted by the chosen configuration.

## Output
If no safe configuration exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) forming any safe configuration, where $1$ denotes Mode 1 and $0$ denotes Mode 0.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple safe configurations may exist; any one is accepted. The same target setting may appear in multiple constraints.
</STATEMENT>
<RATIONALE>
The explicit boolean OR clauses were replaced with their De Morgan equivalent, framing the constraints as combinations of settings that trigger a failure when *both* are contradicted. This removes the explicit 2-SAT clause notation that models were pattern-matching, forcing them to logically deduce the implications (if one target is contradicted, the other must be satisfied) to build the graph.
</RATIONALE>
<PRESERVED_ANSWER>
By De Morgan's laws, avoiding a state where both $l_1$ and $l_2$ are contradicted is logically identical to satisfying at least one of $l_1$ or $l_2$, preserving the exact same valid configurations.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, solvable in $O(n+m)$ time by constructing an implication graph and finding strongly connected components.
</PRESERVED_CLASS>
