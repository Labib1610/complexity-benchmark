# Problem A — Quantum State Synchronization

Time limit: 2 s   Memory limit: 256 MB

You are calibrating a quantum computing cluster consisting of $n$ processors. To maintain coherence, each processor must be initialized into exactly one of 3 available quantum states. The states are identified by the integers 1, 2, and 3. Each state is defined by a specific 3-dimensional state vector:
- State 1 corresponds to the vector $(1, -1, 0)$.
- State 2 corresponds to the vector $(0, 1, -1)$.
- State 3 corresponds to the vector $(-1, 0, 1)$.

The cluster's architecture imposes $m$ synchronization constraints. Each constraint specifies two distinct processors, $u$ and $v$, that share an entanglement channel. 

To prevent decoherence, the quantum interference between any two entangled processors must be strictly negative. Specifically, for every constraint involving processors $u$ and $v$, the dot product of their assigned state vectors must evaluate to exactly $-1$. 

You must assign a state (1, 2, or 3) to each of the $n$ processors such that all $m$ synchronization constraints are simultaneously satisfied. 

## Input
The first line contains two integers $n$ and $m$ — the number of processors and the number of synchronization constraints ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$, representing a pair of processors involved in a synchronization constraint. Processors are indexed from 1 to $n$.

## Output
If no valid state assignment is possible, output NO on a single line.
Otherwise, output YES on the first line. On the second line, output $n$ integers $c_1 \ c_2 \dots c_n$ (each being 1, 2, or 3), where $c_i$ is the state assigned to processor $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I completely replaced the "shard routing" and "subset cardinality" scenario with a quantum physics domain involving 3D state vectors and dot products. The discrete inequality constraint (c_u != c_v) is now masked as a geometric requirement where the dot product of two assigned vectors must equal -1. This breaks the model's structural recognition of the problem as graph 3-coloring, forcing it to implement a generic backtracking solver rather than applying graph-specific heuristics like degree-based vertex sorting, which is necessary to pass the time limit on N=40.
</RATIONALE>
<PRESERVED_ANSWER>
The dot product of any two distinct vectors from the given set is exactly -1, while the dot product of any vector with itself is 2; thus, the dot product constraint is mathematically identical to requiring that entangled processors are assigned different states, preserving all answers exactly.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Graph 3-Coloring, as it asks to assign one of 3 labels to each node such that no two connected nodes share the same label, keeping it NP-complete.
</PRESERVED_CLASS>
