<METHOD_NAME>Asymmetric Relation Masking</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the symmetric "different packages" constraint with an asymmetric "unidirectional read-write overlap" constraint between hardware memory blocks. While mathematically equivalent to 3-coloring, it tricks the model into perceiving a directed network flow or edge-orientation problem, defeating simple graph-coloring pattern matching.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Distributed Sensor Network

Time limit: 2 s   Memory limit: 256 MB

You are deploying a network of $n$ sensor buoys. Each buoy must be configured with exactly one of 3 available firmware packages, identified by the integers 1, 2, and 3.

The buoys share data through a limited set of memory blocks: Block A, Block B, and Block C. Each firmware package is hardcoded to interact with exactly two of these blocks—writing to one, and reading from another:
- **Package 1** writes to Block A and reads from Block B.
- **Package 2** writes to Block B and reads from Block C.
- **Package 3** writes to Block C and reads from Block A.

You are given a list of $m$ critical adjacent pairs of buoys. Each pair involves two specific buoys $(u, v)$ that monitor a highly volatile sector. 
To ensure data flows correctly without causing feedback loops, every given adjacent pair must form a unidirectional data link. A unidirectional data link is successfully formed between buoy $u$ and buoy $v$ if and only if exactly one of the following two conditions is true:
- Buoy $u$ reads from the memory block that buoy $v$ writes to.
- Buoy $v$ reads from the memory block that buoy $u$ writes to.

You must assign a firmware package (1, 2, or 3) to each of the $n$ buoys such that all $m$ critical adjacent pairs successfully form a unidirectional data link.

## Input
The first line contains two integers $n$ and $m$ — the number of buoys and the number of critical adjacent pairs ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing a critical adjacent pair of buoys. Buoys are indexed from 1 to $n$.

## Output
If no such assignment is possible, output NO on a single line.
Otherwise, output YES on the first line. On the second line, output $n$ integers $c_1 \ c_2 \dots c_n$ (each being 1, 2, or 3), where $c_i$ is the firmware package assigned to buoy $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The previous symmetric constraint ("track all 4 metrics") allowed the model to easily recognize the problem as 3-coloring and apply specialized templates like degree-ordered backtracking. By replacing it with an asymmetric "unidirectional read-write overlap" condition, the problem now appears to involve directed data flows or edge-orientation decisions. This forces the model to either manually evaluate the logic and realize it simplifies to $c_u \neq c_v$, or attempt to solve it as a complex directed CSP, breaking its reliance on standard undirected graph-coloring shortcuts.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that exactly one buoy reads from the block the other writes to is mathematically true if and only if the two buoys are assigned different packages, ensuring the set of valid assignments remains exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains isomorphic to the NP-complete 3-coloring problem, as the new condition is a direct mapping of the requirement that adjacent vertices have different colors.
</PRESERVED_CLASS>
