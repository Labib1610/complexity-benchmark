# Problem A — Atmospheric Preservation

Time limit: 2 s   Memory limit: 256 MB

An archive is preparing to indefinitely store $n$ historical manuscripts. During preliminary screening, archivists discovered $m$ specific pairs of manuscripts that exhibit dangerous chemical reactivity when exposed to one another. Such pairs will rapidly deteriorate if housed within the same atmospheric conditions.

The storage complex contains exactly three climate-controlled chambers, designated by the identifiers 1, 2, and 3. To prevent deterioration, the following safety regulations are enforced:
- Every manuscript must be allocated to exactly one of the three chambers.
- If two manuscripts are known to be chemically reactive with each other, they must be allocated to completely different chambers.

You must evaluate the reactivity reports and determine if there is a way to safely distribute all the manuscripts among the three chambers. If a safe distribution is possible, you need to provide a working allocation. Should there be more than one way to safely distribute the manuscripts, any valid allocation will be considered correct.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le \frac{n(n-1)}{2}$), representing the total number of manuscripts and the number of reactive pairs.
The subsequent $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that manuscript $u$ and manuscript $v$ are chemically reactive with each other.

## Output
If it is impossible to safely allocate all manuscripts according to the regulations, output a single line containing `NO`.
If a safe allocation exists, output `YES` on the first line. On the second line, output $n$ space-separated integers, where the $i$-th integer (which must be 1, 2, or 3) represents the chamber assigned to the $i$-th manuscript. Any valid allocation is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
