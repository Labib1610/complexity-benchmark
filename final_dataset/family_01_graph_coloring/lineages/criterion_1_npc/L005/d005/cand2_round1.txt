<METHOD_NAME>LCM-GCD Ratio Substitution</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit quadratic modular arithmetic with an LCM/GCD ratio rule. This hides the proper coloring reduction behind number-theoretic functions, increasing the chance models will implement a generic backtracking search rather than a degree-ordered graph coloring heuristic, leading to a Time Limit Exceeded on hard instances.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Museum Curation

Time limit: 2 s   Memory limit: 256 MB

You are organizing a highly anticipated exhibition featuring $n$ interactive installations. The venue supports exactly three distinct frequency multipliers for the installations' audio elements, designated as 1, 2, and 3.

Every installation $i$ must be assigned exactly one frequency multiplier $c_i \in \{1, 2, 3\}$. However, certain pairs of installations interact. You have compiled a list of $m$ interacting pairs. 

For any such interacting pair $(u, v)$, their combined acoustic profile is evaluated by taking the least common multiple (LCM) of their assigned multipliers $c_u$ and $c_v$, and dividing it by their greatest common divisor (GCD). 

To ensure no acoustic interference occurs, the assignment must guarantee that for every interacting pair, this resulting quotient is strictly greater than 1.

You must determine whether it is possible to assign a frequency multiplier to all $n$ installations such that this interference condition is strictly avoided for all given pairs.

## Input
The first line contains two integers $n$ and $m$ — the number of installations and the number of interacting pairs ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$, representing an interacting pair of installations. Installations are indexed from 1 to $n$.

## Output
If no such assignment is possible, output NO on a single line.
Otherwise, output YES on the first line. On the second line, output $n$ integers $c_1 \ c_2 \dots c_n$ (each being 1, 2, or 3), where $c_i$ is the frequency multiplier assigned to installation $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit quadratic modular equation was replaced with a condition based on the ratio of the least common multiple to the greatest common divisor. By obscuring the disequality constraint behind number-theoretic operations, the model is forced to either mathematically deduce that the quotient is 1 if and only if the multipliers are equal, or blindly implement the LCM/GCD check in a naive backtracking solver, which will fail to use the degree-ordering heuristics necessary to avoid a Time Limit Exceeded on hard instances.
</RATIONALE>
<PRESERVED_ANSWER>
For any two values chosen from {1, 2, 3}, their LCM divided by their GCD is strictly greater than 1 if and only if the two values are distinct, making the condition perfectly equivalent to the original requirement that interacting pairs have different multipliers.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to proper 3-coloring on a given graph, which is NP-complete.
</PRESERVED_CLASS>
