We can model this as a graph coloring problem.  

The key observation:  
- Product of two numbers from {1,2,3} is a perfect square only for (1,1), (2,2), (3,3), and (2,3)/(3,2) because 2×3=6 is not a square, but 2×2=4 and 3×3=9 are squares.  
- So the forbidden pairs are: same number, or (2,3) and (3,2).  
- That means:  
  - 1 can only be paired with 2 or 3.  
  - 2 can only be paired with 1.  
  - 3 can only be paired with 1.  

So the graph must be bipartite between {2,3} and {1}, and also 2 and 3 cannot be adjacent.  

Thus:  
- If there is an edge between two nodes both assigned 2 or both assigned 3 → invalid.  
- If there is an edge between 2 and 3 → invalid.  
- So the only valid assignment is:  
  - Color some nodes as 1.  
  - The rest must be split into two independent sets: one for 2, one for 3, with no edges between them.  

This is equivalent to:  
- The graph induced by nodes not colored 1 must be bipartite, and we can color one side 2 and the other 3.  
- Nodes colored 1 can connect to anyone.  

We can brute force because n ≤ 40.  
We can try all subsets for color 1 (2^40 is too big), but we can do smarter:  
- Try all possibilities for which nodes are 1 (2^n is too big).  
- Instead, we can try all 3-colorings via backtracking with pruning, since n ≤ 40 but m can be large.  

Better:  
- We can try all assignments of 1/2/3 via backtracking with constraint checking.  
- Since n ≤ 40, worst-case 3^40 is too big, but we can prune heavily.  

But we can also reduce:  
- If we fix which nodes are 1, the rest must be bipartite.  
- We can iterate over all subsets for 1 (2^40 too big).  

However, we can use the fact that the graph is small enough for a backtracking with bitmask and pruning.  

Let’s implement a backtracking that assigns colors 1,2,3 and checks constraints on the fly.  

We’ll use adjacency list and try to assign colors in order.  

We can also use the fact that if a node is 1, it has no restrictions with others.  
So we can try to assign 1 to some nodes, and for the rest, solve 2-coloring.  

We can do:  
- Try all subsets for color 1 (2^40 too big).  
- But we can do backtracking: for each node, try color 1,2,3.  

Given n ≤ 40, backtracking with pruning should be fine because constraints are strong.  

Let’s implement.  

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n  # 0 = unassigned, 1,2,3
    
    def is_valid(u, c):
        for v in adj[u]:
            if color[v] == 0:
                continue
            if c == color[v]:
                return False
            if (c == 2 and color[v] == 3) or (c == 3 and color[v] == 2):
                return False
        return True
    
    def dfs(idx):
        if idx == n:
            return True
        # try colors 1,2,3
        for c in (1,2,3):
            if is_valid(idx, c):
                color[idx] = c
                if dfs(idx+1):
                    return True
                color[idx] = 0
        return False
    
    if dfs(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
