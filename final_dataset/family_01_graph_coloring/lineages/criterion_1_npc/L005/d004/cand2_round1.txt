<STATEMENT>
# Problem A — Quantum Sensor Calibration

Time limit: 2 s   Memory limit: 256 MB

You are calibrating a network of $n$ quantum sensors. Each sensor must be configured to one of three possible energy states, represented by the integers 1, 2, or 3.

You have identified $m$ pairs of sensors that are quantum entangled. To maintain the stability of the network, the entanglement imposes a strict mathematical condition: for every entangled pair of sensors $(u, v)$, the product of their assigned energy states ($c_u \times c_v$) must not be a perfect square.

You must determine whether it is possible to assign an energy state to each of the $n$ sensors such that this stability condition is satisfied for all $m$ entangled pairs.

## Input
The first line contains two integers $n$ and $m$ — the number of sensors and the number of entangled pairs ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$, representing an entangled pair of sensors. Sensors are indexed from 1 to $n$.

## Output
If no such valid configuration is possible, output NO on a single line.
Otherwise, output YES on the first line. On the second line, output $n$ integers $c_1 \ c_2 \dots c_n$ (each being 1, 2, or 3), where $c_i$ is the energy state assigned to sensor $i$. If multiple valid configurations exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

This perfectly encodes that the values must be different while completely masking the graph-coloring nature of the problem, preventing models from triggering graph heuristics like degree-based vertex ordering.
</RATIONALE>
<PRESERVED_ANSWER>
The assigned values must be 1, 2, or 3, and the product of any two such values is a perfect square if and only if the two values are identical, maintaining the exact same valid configurations as the original problem.
</PRESERVED_ANSWER>

The problem remains exactly equivalent to 3-Coloring, preserving its NP-complete status.
