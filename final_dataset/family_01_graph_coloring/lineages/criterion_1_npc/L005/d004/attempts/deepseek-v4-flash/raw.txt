 We need to check if we can assign values from {1, 2, 3} to each node such that for every edge (u, v),  
P(u, v) = c_u² + c_u·c_v + c_v² is not divisible by 3.

First, let’s analyze the condition modulo 3.  
Possible values for c are 1, 2, 3. Mod 3, these are 1, 2, 0.

Let’s compute P mod 3 for each combination:

- (0,0): 0+0+0 = 0 → bad  
- (0,1): 0+0+1 = 1 → ok  
- (0,2): 0+0+4 ≡ 0+0+1 = 1 → ok  
- (1,0): 1+0+0 = 1 → ok  
- (1,1): 1+1+1 = 3 ≡ 0 → bad  
- (1,2): 1+2+4 ≡ 1+2+1 = 4 ≡ 1 → ok  
- (2,0): 4+0+0 ≡ 1 → ok  
- (2,1): 4+2+1 ≡ 1+2+1 = 4 ≡ 1 → ok  
- (2,2): 4+4+4 ≡ 1+1+1 = 3 ≡ 0 → bad  

So the only forbidden pairs (mod 3) are:  
(0,0), (1,1), (2,2).  
That means: two connected nodes cannot have the same value modulo 3.

Thus, the problem reduces to: can we 3-color the graph such that adjacent nodes have different colors (where colors are 0,1,2 mod 3)?  
This is exactly the 3-coloring problem, which is NP-hard in general.  
But n ≤ 40, so we can use backtracking with pruning.

We can try assigning colors 0,1,2 to each node, ensuring no conflict with already assigned neighbors. If we find a valid assignment, we output it (mapping 0→3, 1→1, 2→2 for example). If not, output NO.

Let’s implement backtracking.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    
    def dfs(node):
        if node == n:
            return True
        # Try colors 0,1,2
        for c in range(3):
            ok = True
            for nb in adj[node]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[node] = c
                if dfs(node + 1):
                    return True
                color[node] = -1
        return False
    
    if dfs(0):
        print("YES")
        # Map 0->3, 1->1, 2->2
        mapping = {0: 3, 1: 1, 2: 2}
        print(" ".join(str(mapping[color[i]]) for i in range(n)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
