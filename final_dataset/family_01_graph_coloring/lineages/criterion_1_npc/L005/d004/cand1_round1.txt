# Problem A — Museum Curation

Time limit: 2 s   Memory limit: 256 MB

You are organizing a highly anticipated exhibition featuring interactive installations. The venue has a strict spatial capacity allowing a maximum of 40 installations, and there is always at least one installation present. 

Each installation must be configured with a specific frequency multiplier. To ensure compatibility with the venue's power grid, this multiplier must be chosen as exactly 1, 2, or 3.

During testing, you have compiled a list of pairs of installations that interact with each other. The number of such interacting pairs ranges from zero up to the theoretical maximum of all possible unique pairs among the present installations.

If two interacting installations, $u$ and $v$, are assigned frequency multipliers $c_u$ and $c_v$ respectively, their combined electromagnetic footprint is calculated as $c_u^2 + c_u c_v + c_v^2$. If this footprint is an exact multiple of 3, it causes a harmonic resonance that trips the venue's circuit breakers.

You must determine whether it is possible to assign a frequency multiplier to every installation such that no interacting pair trips the circuit breakers.

## Input
The first line contains two integers $n$ and $m$ — the number of installations and the number of interacting pairs.
Each of the subsequent $m$ lines contains two integers $u$ and $v$, representing a pair of installations that interact. Installations are indexed from 1 to $n$.

## Output
If no valid configuration is possible, output NO on a single line.
Otherwise, output YES on the first line. On the second line, output $n$ integers $c_1 \ c_2 \dots c_n$ (each being 1, 2, or 3), where $c_i$ is the frequency multiplier assigned to installation $i$. If multiple valid configurations exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
