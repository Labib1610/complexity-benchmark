# Problem A — Museum Curation

Time limit: 2 s   Memory limit: 256 MB

You are organizing a highly anticipated exhibition featuring $n$ interactive installations. The venue supports exactly three distinct power levels for the installations' audio elements, designated as 1, 2, and 3.

Every installation $i$ must be assigned exactly one power level $c_i \in \{1, 2, 3\}$. However, certain pairs of installations interact. You have compiled a list of $m$ interacting pairs. 

For any such pair $(u, v)$, you must evaluate their combined acoustic profile. Consider the four interaction harmonics generated by their indices and power levels: $c_u \cdot u$, $c_v \cdot v$, $c_u \cdot v$, and $c_v \cdot u$. 

To ensure no acoustic interference occurs, the difference between the largest and the smallest of these four values must be strictly greater than $|u - v| \cdot \min(c_u, c_v)$. If this condition is not met, it creates an unstable resonance loop and the assignment is invalid.

You must determine whether it is possible to assign a power level to all $n$ installations such that this interference condition is strictly avoided for all given pairs.

## Input
The first line contains two integers $n$ and $m$ — the number of installations and the number of interacting pairs. The venue can host up to 40 installations ($1 \le n \le 40$), and $m$ can range from 0 up to the maximum possible number of distinct pairs ($0 \le m \le n \cdot (n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$, representing an interacting pair of installations. Installations are indexed from 1 to $n$.

## Output
If no such assignment is possible, output NO on a single line.
Otherwise, output YES on the first line. On the second line, output $n$ integers $c_1 \ c_2 \dots c_n$ (each being 1, 2, or 3), where $c_i$ is the power level assigned to installation $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I replaced the simple "product is not a perfect square" constraint with a tautological pair-dependent algebraic inequality. The new constraint evaluates exactly to $c_u \neq c_v$ but incorporates the vertex indices $u$ and $v$ using maximum and minimum operations over a set of products. This breaks the model's ability to pattern-match the problem to standard 3-coloring, thereby preventing it from applying the crucial degree-ordered vertex sorting heuristic necessary to pass within the time limit.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic inequality for the four harmonics mathematically simplifies step-by-step to $\max(c_u, c_v) > \min(c_u, c_v)$, which is strictly equivalent to $c_u \neq c_v$ for all positive inputs, ensuring identical validity for all assignments.
</PRESERVED_ANSWER>

The problem remains strictly equivalent to graph 3-coloring, preserving its NP-complete complexity class.
