<METHOD_NAME>Algebraic Root Masking</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the direct inequality or perfect-square check with a condition on the number of distinct real roots of a characteristic polynomial P(x) = x^3 - (c_u + c_v)x^2 + (c_u c_v)x. This forces the model to algebraically factor the polynomial to discover the underlying c_u != c_v constraint. Models that fail to recognize this equivalence will not trigger their optimized graph-coloring templates (like degree-ordered backtracking) and will likely TLE on dense graphs.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Museum Curation

Time limit: 2 s
Memory limit: 256 MB

You are organizing a highly anticipated exhibition featuring $n$ interactive installations. The venue supports exactly three distinct frequency multipliers for the installations' audio elements, designated as 1, 2, and 3.

Every installation $i$ must be assigned exactly one frequency multiplier $c_i \in \{1, 2, 3\}$. However, certain pairs of installations interact. You have compiled a list of $m$ interacting pairs. 

For each listed pair $(u, v)$, their assigned multipliers $c_u$ and $c_v$ generate a characteristic acoustic polynomial, defined as:
$P(x) = x^3 - (c_u + c_v)x^2 + (c_u c_v)x$

To ensure no acoustic interference occurs, this polynomial must have exactly three distinct real roots. If the polynomial has a repeated root, it creates an unstable resonance loop and the assignment is invalid.

You must determine whether it is possible to assign a frequency multiplier to all $n$ installations such that this interference condition is strictly avoided for all given pairs.

## Input
The first line contains two integers $n$ and $m$ — the number of installations and the number of interacting pairs ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$, representing an interacting pair of installations. Installations are indexed from 1 to $n$.

## Output
If no such assignment is possible, output NO on a single line.
Otherwise, output YES on the first line. On the second line, output $n$ integers $c_1 \ c_2 \dots c_n$ (each being 1, 2, or 3), where $c_i$ is the frequency multiplier assigned to installation $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The explicit bounds from the seed have been fully restored to the Input section to strictly satisfy the I/O contract constraints. The core modification replaces the "product is not a perfect square" constraint with a polynomial root condition: $P(x) = x^3 - (c_u + c_v)x^2 + (c_u c_v)x$ must have three distinct real roots. Factoring this yields $P(x) = x(x - c_u)(x - c_v)$, meaning the roots are $0$, $c_u$, and $c_v$. Since $c_u, c_v \ge 1$, the roots are distinct if and only if $c_u \neq c_v$. This algebraically masks the 3-coloring constraint, preventing models from relying on surface pattern matching to trigger degree-ordered backtracking optimizations.
</RATIONALE>

The roots of the polynomial are 0, c_u, and c_v; these are exactly three distinct real numbers if and only if c_u != c_v, which perfectly matches the seed's requirement that the product of multipliers from {1, 2, 3} is not a perfect square.
</PRESERVED_ANSWER>
