<METHOD_NAME>Global Dot-Product Summation</METHOD_NAME>
<METHOD_DESCRIPTION>Maps each shard to a 3D vector such that the dot product is 2 for identical shards and -1 for distinct shards. The requirement that the sum of dot products across all m edges equals -m algebraically forces the number of monochromatic edges to be exactly 0. This masks the local inequality constraint behind a global summation.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Distributed Shard Routing

Time limit: 2 s   Memory limit: 256 MB

You are configuring a distributed database with $n$ storage nodes. To ensure stable load distribution, each node must be assigned to exactly one of 3 available data shards. The shards are identified by the integer IDs 1, 2, and 3.

To model the load distribution, each shard ID is associated with a specific 3-dimensional load vector:
- Shard 1: $V_1 = (1, -1, 0)$
- Shard 2: $V_2 = (0, 1, -1)$
- Shard 3: $V_3 = (-1, 0, 1)$

You are given a list of $m$ high-frequency query patterns. Each pattern involves a specific pair of nodes $(u, v)$ that are frequently accessed together.

When nodes $u$ and $v$ are assigned to shards with load vectors $W_u$ and $W_v$ respectively, the cross-node interference for that query pattern is defined as the standard dot product $W_u \cdot W_v$. 

To maintain system stability, you must assign a shard ID (1, 2, or 3) to each of the $n$ nodes such that the total cross-node interference, summed over all $m$ given query patterns, is exactly $-m$.

## Input
The first line contains two integers $n$ and $m$ — the number of storage nodes and the number of high-frequency query patterns ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing a pair of nodes involved in a high-frequency query pattern. Nodes are indexed from 1 to $n$.

## Output
If no such assignment is possible, output NO on a single line.
Otherwise, output YES on the first line. On the second line, output $n$ integers $c_1 \ c_2 \dots c_n$ (each being 1, 2, or 3), where $c_i$ is the shard ID assigned to node $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the local equality check with a global sum over dot products of 3D vectors. Because the dot product is 2 for identical vectors and -1 for distinct ones, a sum of $-m$ over $m$ pairs is algebraically only possible if every pair evaluates to -1, which strictly requires assigning distinct vectors to all connected nodes. This forces the model to deduce the local inequality via mathematical bounds rather than pattern-matching a direct collision rule.
</RATIONALE>
<PRESERVED_ANSWER>
The dot product of the assigned vectors is 2 if they are identical and -1 if they are distinct; thus, a total sum of $-m$ over $m$ patterns is uniquely achieved when strictly zero patterns have identical vectors, matching the seed's exact requirement.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
