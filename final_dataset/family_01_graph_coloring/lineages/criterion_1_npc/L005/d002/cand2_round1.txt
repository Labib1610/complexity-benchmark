# Problem A — Atmospheric Preservation

Time limit: 2 s   Memory limit: 256 MB

You are tasked with organizing historical documents for long-term storage. Extensive testing has uncovered pairs of documents with incompatible material compositions, meaning they will suffer degradation if stored in the same environment.

The storage facility operates a primary vault (designated as vault 1), a secondary vault (designated as vault 2), and a tertiary vault (designated as vault 3). To prevent damage, the following protocols apply:
- Every document must be securely placed into exactly one of these three designated vaults.
- If two documents are incompatible, they must not be placed into the same vault.

Determine whether there is a storage assignment that strictly follows these protocols. If such an assignment is possible, provide one.

## Input
The first line contains the document count $n$ and the pair count $m$. The facility's quarantine space limits the collection size: there is always at least a single document, and the total count $n$ never exceeds forty. The number of recorded incompatible pairs $m$ can be anything from zero up to the theoretical limit where every document is incompatible with all other documents in the collection.
Each of the following $m$ lines contains two integers $u$ and $v$, representing a pair of incompatible documents.

## Output
If no valid assignment exists, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $c_1 \ c_2 \dots c_n$ (each being 1, 2, or 3), where $c_i$ is the vault assigned to document $i$. Providing one valid assignment is sufficient if several exist.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
