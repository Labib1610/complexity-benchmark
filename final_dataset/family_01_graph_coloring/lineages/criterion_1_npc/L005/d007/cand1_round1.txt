# Problem A — Distributed Shard Routing

Time limit: 2 s   Memory limit: 256 MB

You are configuring a distributed database with $n$ storage nodes, indexed from 1 to $n$. To ensure optimal load distribution, each node must be assigned to exactly one of 3 available data shards. The shards are identified by the integer IDs 1, 2, and 3.

You are given a list of $m$ high-frequency query patterns. Each pattern involves a specific pair of nodes $(u, v)$ that are frequently accessed together.

The router evaluates the assignment by constructing an $n \times n$ routing interference matrix $R$. The rows and columns of $R$ correspond to the $n$ nodes. The entries of $R$ are defined as follows:
- $R_{i, j} = 1$ if $i \neq j$, nodes $i$ and $j$ are involved together in at least one high-frequency query pattern, and they are assigned the SAME shard ID ($c_i = c_j$).
- $R_{i, j} = 0$ otherwise (this includes when $i = j$, when $i$ and $j$ do not share a pattern, or when they are assigned different shard IDs).

Note that since the query patterns are unordered pairs, $R$ is always a symmetric matrix ($R_{i, j} = R_{j, i}$).

To maintain system stability, you must assign a shard ID (1, 2, or 3) to each of the $n$ nodes such that the matrix product $R^2$ (that is, $R$ multiplied by itself using standard integer matrix multiplication) results in the $n \times n$ zero matrix (a matrix where every single entry is exactly 0).

## Input
The first line contains two integers $n$ and $m$ — the number of storage nodes and the number of high-frequency query patterns ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing a pair of nodes involved in a high-frequency query pattern. 

## Output
If no such assignment is possible, output NO on a single line.
Otherwise, output YES on the first line. On the second line, output $n$ integers $c_1 \ c_2 \dots c_n$ (each being 1, 2, or 3), where $c_i$ is the shard ID assigned to node $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
