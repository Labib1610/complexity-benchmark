# Problem A — Trichrome Shifts

Time limit: 2 s   Memory limit: 256 MB

A manufacturing plant operates three distinct scheduling blocks, labeled 1, 2, and 3. The facility employs $n$ personnel. Due to interpersonal disputes, certain pairs of personnel cannot be assigned to the same scheduling block.

The provided data will include tightly constrained dispute configurations, as well as configurations where almost all personnel can be safely allocated but the final few cannot. Your method must process all such valid configurations within the time limit.

You must allocate each person to exactly one of the three scheduling blocks such that no two individuals with a dispute share the same block, or state if no such allocation exists.

## Input
The first line provides two integers $n$ and $m$ — the total number of personnel and the number of disputes ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
The following $m$ lines each contain two integers $u$ and $v$ — indicating that person $u$ and person $v$ have a dispute.

## Output
If no valid scheduling block allocation is possible, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2, 3\}$), representing the scheduling block for person $i$. Any valid allocation will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
