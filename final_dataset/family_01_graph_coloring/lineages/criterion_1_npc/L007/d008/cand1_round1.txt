# Problem A — Thermal Resonance Tuning

Time limit: 2 s   Memory limit: 256 MB

A reactor core contains $n$ thermal modules. To maintain stability, each module must be assigned a resonance state $s_i \in \{1, 2, 3\}$.

The diagnostic system has identified $m$ critical interactions between specific pairs of modules. The stability of the core is determined by the balance between its total coupling energy $W$ and its network potential $V$.

For each critical interaction between module $u$ and module $v$, their coupling energy is given by the following polynomial formula:
$C_{u,v} = s_u^4 - 4 s_u^3 s_v + 6 s_u^2 s_v^2 - 4 s_u s_v^3 + s_v^4 - 5 s_u^2 + 10 s_u s_v - 5 s_v^2 + s_u + s_v + 4$

The total coupling energy $W$ is the sum of all coupling energies for the critical interactions:
$W = \sum_{j=1}^m C_{u_j, v_j}$

The network potential $V$ of the core is determined by the states of the modules weighted by their interaction frequency. Let $d_i$ be the number of critical interactions that include module $i$. The network potential is:
$V = \sum_{i=1}^n d_i s_i$

To prevent core failure, the configuration must achieve a state of perfect resonance, which requires the total coupling energy to exactly match the network potential. (That is, $W = V$).

Your task is to determine whether there exists a valid state assignment for all modules $1 \dots n$ such that $W = V$. If such an assignment exists, you must provide one.

## Input
The first line contains two integers $n$ and $m$ — the number of thermal modules and the number of critical interactions ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating a critical interaction between module $u$ and module $v$. Each interaction is listed at most once.

## Output
If it is impossible to calibrate the modules to the required energy state, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2, 3\}$), with $s_i$ representing the resonance state assigned to module $i$. Any valid assignment is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```
*Explanation for Example 1:*
The interactions for each module are counted to find $d_i$:
$d_1 = 3$, $d_2 = 3$, $d_3 = 2$, $d_4 = 2$.
Assigning states 1, 2, 3, 3 yields the network potential:
$V = 3(1) + 3(2) + 2(3) + 2(3) = 3 + 6 + 6 + 6 = 21$.

The coupling energies for the interactions are:
- Interaction (1, 2) with states 1 and 2: $C_{1,2} = 1 - 8 + 24 - 32 + 16 - 5 + 20 - 20 + 1 + 2 + 4 = 3$.
- Interaction (1, 3) with states 1 and 3: $C_{1,3} = 1 - 12 + 54 - 108 + 81 - 5 + 30 - 45 + 1 + 3 + 4 = 4$.
- Interaction (2, 3) with states 2 and 3: $C_{2,3} = 16 - 96 + 216 - 216 + 81 - 20 + 60 - 45 + 2 + 3 + 4 = 5$.
- Interaction (1, 4) with states 1 and 3: $C_{1,4} = 4$.
- Interaction (2, 4) with states 2 and 3: $C_{2,4} = 5$.

The total coupling energy $W$ is $3 + 4 + 5 + 4 + 5 = 21$.
Since $W = V$, the configuration is stable.
