# Problem A — Thermal Resonance Tuning

Time limit: 2 s   Memory limit: 256 MB

A reactor core contains $n$ thermal modules. To maintain stability, each module must be assigned a resonance state $s_i \in \{1, 2, 3\}$.

The diagnostic system has identified $m$ critical interactions between specific pairs of modules. To prevent core failure, every critical interaction must be stabilized.

A critical interaction between module $u$ and module $v$ is stable if and only if at least one of their assigned states does not evenly divide the sum of their states. Formally, the interaction is stable if $(s_u + s_v) \bmod s_u \neq 0$ or $(s_u + s_v) \bmod s_v \neq 0$.

Your task is to determine whether there exists a valid state assignment for all modules $1 \dots n$ such that all $m$ critical interactions are stable. If such an assignment exists, you must provide one.

## Input
The first line contains two integers $n$ and $m$ — the number of thermal modules and the number of critical interactions ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating a critical interaction between module $u$ and module $v$. Each interaction is listed at most once.

## Output
If it is impossible to calibrate the modules so that all critical interactions are stable, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2, 3\}$), with $s_i$ representing the resonance state assigned to module $i$. Any valid assignment is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```
*Explanation for Example 1:*
Assigning states 1, 2, 3, 3 yields the following:
- Interaction (1, 2) with states 1 and 2: The sum is 3. Since $3 \bmod 2 \neq 0$, state 2 does not evenly divide the sum. The interaction is stable.
- Interaction (1, 3) with states 1 and 3: The sum is 4. Since $4 \bmod 3 \neq 0$, state 3 does not evenly divide the sum. The interaction is stable.
- Interaction (2, 3) with states 2 and 3: The sum is 5. Since $5 \bmod 2 \neq 0$ and $5 \bmod 3 \neq 0$, neither state evenly divides the sum. The interaction is stable.
- Interaction (1, 4) with states 1 and 3: The sum is 4. Since $4 \bmod 3 \neq 0$, state 3 does not evenly divide the sum. The interaction is stable.
- Interaction (2, 4) with states 2 and 3: The sum is 5. Since $5 \bmod 2 \neq 0$ and $5 \bmod 3 \neq 0$, neither state evenly divides the sum. The interaction is stable.

All critical interactions are stable. The configuration is valid.
