# Problem A — Thermal Resonance Tuning

Time limit: 2 s   Memory limit: 256 MB

A reactor core contains $n$ thermal modules. To maintain stability, each module must be assigned a resonance state $s_i \in \{1, 2, 3\}$.

The diagnostic system has identified $m$ critical interactions between specific pairs of modules. The stability of the core is determined by its total system energy $W$, which consists solely of coupling energies between interacting modules.

For each critical interaction between module $u$ and module $v$, their coupling energy is given by the following resonance formula:
$C_{u,v} = 3 s_u^5 + 3 s_v^5 - 9 s_u^4 s_v - 9 s_u s_v^4 + 6 s_u^3 s_v^2 + 6 s_u^2 s_v^3 - 15 s_u^3 - 15 s_v^3 + 15 s_u^2 s_v + 15 s_u s_v^2 + 12 s_u + 12 s_v + u^2 + v^2$

The total system energy $W$ is the sum of all coupling energies for the critical interactions:
$W = \sum_{j=1}^m C_{u_j, v_j}$

To prevent core failure, the configuration must achieve a state of baseline resonance, which requires the total system energy to be exactly the sum of the squares of the interacting module IDs. That is, the target energy is $E = \sum_{j=1}^m (u_j^2 + v_j^2)$. The core is stable if and only if $W = E$.

Your task is to determine whether there exists a valid state assignment for all modules $1 \dots n$ such that the total system energy $W$ is exactly equal to $E$. If such an assignment exists, you must provide one.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of thermal modules and the number of critical interactions.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating a critical interaction between module $u$ and module $v$. Each interaction is listed at most once.

## Output
If it is impossible to calibrate the modules to the required energy state, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2, 3\}$), with $s_i$ representing the resonance state assigned to module $i$. Any valid assignment is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```
*Explanation for Example 1:*
The target baseline energy is $E = (1^2+2^2) + (1^2+3^2) + (2^2+3^2) + (1^2+4^2) + (2^2+4^2) = 5 + 10 + 13 + 17 + 20 = 65$.
Assigning states 1, 2, 3, 3 yields the following coupling energies:
- Interaction (1, 2) with states $s_1=1$ and $s_2=2$: $C_{1,2} = 5$.
- Interaction (1, 3) with states $s_1=1$ and $s_3=3$: $C_{1,3} = 10$.
- Interaction (2, 3) with states $s_2=2$ and $s_3=3$: $C_{2,3} = 13$.
- Interaction (1, 4) with states $s_1=1$ and $s_4=3$: $C_{1,4} = 17$.
- Interaction (2, 4) with states $s_2=2$ and $s_4=3$: $C_{2,4} = 20$.

The total system energy $W$ is $5 + 10 + 13 + 17 + 20 = 65$. Since $W = E$, the configuration is stable.

<RATIONALE>
I modified the coupling energy formula by scaling the original state-dependent polynomial by 3 and adding a topology-dependent offset `u^2 + v^2`. The target total energy is correspondingly changed from 0 to the sum of `u^2 + v^2` over all edges. This eliminates the obvious `W=0` zero-sum pattern that models use to instantly recognize the graph coloring reduction, forcing them to analytically evaluate the state-dependent portion of the polynomial to discover it evaluates to exactly zero only when endpoints have distinct states.
</RATIONALE>
