<STATEMENT>
# Problem A — Thermal Resonance Tuning

Time limit: 2 s   Memory limit: 256 MB

A reactor core contains thermal modules. The core's testing facility has exactly 40 bays, meaning the number of modules $n$ cannot exceed this amount, though a test may involve as few as a single module. To maintain stability, each module must be assigned a resonance state $s_i$. These states are strictly positive integers. Due to the phase constraints of the cooling system, a state of four or higher would trigger an immediate cascade failure, so such values are strictly prohibited.

The diagnostic system has identified $m$ critical interactions between specific pairs of modules. This number can range from zero up to the theoretical maximum where every unique pair of modules interacts exactly once. The stability of the core is determined by its total system energy $W$, which consists solely of coupling energies between interacting modules.

For each critical interaction between module $u$ and module $v$, their coupling energy is given by the following resonance formula:
$C_{u,v} = 3s_u^4 + 3s_v^4 - 12s_u^3 s_v - 12s_u s_v^3 + 2s_u^3 + 2s_v^3 + 18s_u^2 s_v^2 - 27s_u^2 - 27s_v^2 + 30s_u s_v + 22s_u + 22s_v - 14$

The total system energy $W$ is the sum of all coupling energies for the critical interactions:
$W = \sum_{j=1}^m C_{u_j, v_j}$

To prevent core failure, the configuration must achieve a state of baseline resonance, which requires the total system energy to be exactly $-2m$ (negative two times the number of critical interactions).

Your task is to determine whether there exists a valid state assignment for all modules such that the total system energy is exactly $-2m$. If such an assignment exists, you must provide one.

## Input
The first line contains two integers $n$ and $m$ — the number of thermal modules and the number of critical interactions. As detailed above, the facility's physical limits dictate the allowed ranges for these parameters.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a critical interaction between module $u$ and module $v$. A module cannot interact with itself, and each pair's interaction is listed at most once.

## Output
If it is impossible to calibrate the modules to the required energy state, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$, with $s_i$ representing the resonance state assigned to module $i$. Any valid assignment is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```
*Explanation for Example 1:*
Assigning states 1, 2, 3, 3 yields the following coupling energies:
- Interaction (1, 2) with states 1 and 2: $C_{1,2} = 3(1) + 3(16) - 12(2) - 12(8) + 2(1) + 2(8) + 18(4) - 27(1) - 27(4) + 30(2) + 22(1) + 22(2) - 14 = 3 + 48 - 24 - 96 + 2 + 16 + 72 - 27 - 108 + 60 + 22 + 44 - 14 = -2$.
- Interaction (1, 3) with states 1 and 3: $C_{1,3} = 3(1) + 3(81) - 12(3) - 12(27) + 2(1) + 2(27) + 18(9) - 27(1) - 27(9) + 30(3) + 22(1) + 22(3) - 14 = 3 + 243 - 36 - 324 + 2 + 54 + 162 - 27 - 243 + 90 + 22 + 66 - 14 = -2$.
- Interaction (2, 3) with states 2 and 3: $C_{2,3} = 3(16) + 3(81) - 12(24) - 12(54) + 2(8) + 2(27) + 18(36) - 27(4) - 27(9) + 30(6) + 22(2) + 22(3) - 14 = 48 + 243 - 288 - 648 + 16 + 54 + 648 - 108 - 243 + 180 + 44 + 66 - 14 = -2$.
- Interaction (1, 4) with states 1 and 3: evaluates similarly to $C_{1,4} = -2$.
- Interaction (2, 4) with states 2 and 3: evaluates similarly to $C_{2,4} = -2$.

The total system energy $W$ is $(-2) + (-2) + (-2) + (-2) + (-2) = -10$.
The required target energy is $-2m = -2(5) = -10$. The configuration achieves the target exactly, so it is valid.

<RATIONALE>
I replaced explicit numeric bounds with physical constraints detailed in the scenario text (Strategy S07), requiring the model to deduce $1 \le n \le 40$ and $s_i \in \{1, 2, 3\}$. To eliminate the zero-sum graph-coloring shortcut, I completely rewrote the resonance polynomial so that it evaluates to -2 for unequal states and 10 for equal states, and shifted the target energy to $-2m$. This breaks the trivial $W=0 \implies C=0$ heuristic and forces models to algebraically analyze the polynomial to find its global minimum over the discrete domain.
</RATIONALE>
<PRESERVED_ANSWER>
The new polynomial evaluates to exactly -2 if and only if the assigned states are different, and 10 if they are identical; because the target sum for $m$ edges is exactly $-2m$, every single edge must evaluate to -2, preserving the exact same set of valid proper 3-colorings as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains mathematically equivalent to finding a proper 3-coloring of a graph, keeping it firmly NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the phrasing "negative two times the number of critical interactions" if they try to evaluate it per module instead of globally, but the mathematical notation $-2m$ alongside it makes the target unambiguous.
</RISK>
