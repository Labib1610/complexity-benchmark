Let's analyze the problem.

We have:

- Each vertex has a state \( s_i \in \{1,2,3\} \).
- Intrinsic energy for vertex \( i \):
  \[
  E_i = d_i (s_i^4 - 5s_i^2)
  \]
- Coupling energy for edge \( (u,v) \):
  \[
  C_{u,v} = 2 s_u s_v (3 s_u s_v + 5 - 2s_u^2 - 2s_v^2)
  \]

We need total energy \( W = -4m \).

Let's compute the possible values.

For \( s \in \{1,2,3\} \):

- \( s=1 \): \( s^4 - 5s^2 = 1 - 5 = -4 \)
- \( s=2 \): \( 16 - 20 = -4 \)
- \( s=3 \): \( 81 - 45 = 36 \)

So intrinsic energy:
\[
E_i = d_i \cdot f(s_i), \quad f(1)=f(2)=-4,\ f(3)=36
\]

Now coupling energy for states \( a,b \):

Compute \( C(a,b) = 2ab(3ab + 5 - 2a^2 - 2b^2) \).

Let's compute for all pairs:

- (1,1): \( 2\cdot1\cdot1(3+5-2-2) = 2(4) = 8 \)
- (1,2): \( 2\cdot1\cdot2(6+5-2-8) = 4(1) = 4 \)
- (1,3): \( 2\cdot1\cdot3(9+5-2-18) = 6(-6) = -36 \)
- (2,2): \( 2\cdot2\cdot2(12+5-8-8) = 8(1) = 8 \)
- (2,3): \( 2\cdot2\cdot3(18+5-8-18) = 12(-3) = -36 \)
- (3,3): \( 2\cdot3\cdot3(27+5-18-18) = 18(-4) = -72 \)

So coupling energy matrix:

\[
C = \begin{pmatrix}
8 & 4 & -36 \\
4 & 8 & -36 \\
-36 & -36 & -72
\end{pmatrix}
\]

Now total energy:
\[
W = \sum_i d_i f(s_i) + \sum_{(u,v) \in E} C(s_u,s_v)
\]

We want \( W = -4m \).

Observe that \( f(1)=f(2)=-4 \), \( f(3)=36 \). Also \( C(1,1)=8, C(1,2)=4, C(2,2)=8, C(1,3)=C(2,3)=-36, C(3,3)=-72 \).

Let's try to simplify. Let's define for each vertex a variable \( x_i \in \{0,1,2\} \) where \( s_i = x_i+1 \). But maybe there's a pattern.

Total energy:

W = \sum_i d_i \cdot 36 + \sum_{e} (-72) = 36 \sum_i d_i - 72m

But \(\sum_i d_i = 2m\), so:

W = 36(2m) - 72m = 72m - 72m = 0
\]
Not -4m.

If all \( s_i = 1 \):

W = -4\sum_i d_i + 8m = -8m + 8m = 0

Not -4m.

If all \( s_i = 2 \):

W = -8m + 8m = 0

Again 0.

So constant assignments give 0.

We need -4m. Let's check if there's a transformation.

So \( f(s) = 40 \cdot \mathbf{1}_{s=3} - 4 \).

Similarly, compute \( C(a,b) + 4 \):

Let's try to express \( C(a,b) \) in terms of \( f(a), f(b) \). Since \( f \) only depends on whether \( s=3 \) or not, let's define \( y_i = 1 \) if \( s_i=3 \), else 0.

Then:

- For coupling, we need \( C(a,b) \). Let's compute in terms of \( y_a, y_b \):

So we need a different approach.

Let's compute total energy directly.

Let \( n_1, n_2, n_3 \) be number of vertices with state 1,2,3.

Let \( m_{ij} \) be number of edges between state i and state j (i≤j).

Then:
\[
W = \sum_{i=1}^3 \sum_{v: s_v=i} d_v f(i) + \sum_{i \le j} m_{ij} C(i,j)
\]

But \(\sum_{v: s_v=i} d_v = 2m_{ii} + \sum_{j \ne i} m_{ij}\).

Let's compute \( W \):

\[
W = \sum_{i=1}^3 f(i) \left( 2m_{ii} + \sum_{j \ne i} m_{ij} \right) + \sum_{i \le j} m_{ij} C(i,j)
\]

We know \( f(1)=f(2)=-4, f(3)=36 \).

Let's write \( W \) in terms of \( m_{ij} \):

\[
W = -4(2m_{11} + m_{12} + m_{13}) -4(2m_{22} + m_{12} + m_{23}) + 36(2m_{33} + m_{13} + m_{23}) + 8m_{11} + 4m_{12} -36m_{13} + 8m_{22} -36m_{23} -72m_{33}
\]

Simplify term by term:

- From \( f(1) \): \(-8m_{11} -4m_{12} -4m_{13}\)
- From \( f(2) \): \(-8m_{22} -4m_{12} -4m_{23}\)
- From \( f(3) \): \(72m_{33} + 36m_{13} + 36m_{23}\)
- From coupling: \(8m_{11} + 4m_{12} -36m_{13} + 8m_{22} -36m_{23} -72m_{33}\)

Now sum:

Coefficient of \( m_{11} \): \(-8 + 8 = 0\)
\( m_{12} \): \(-4 -4 + 4 = -4\)
\( m_{13} \): \(-4 + 36 -36 = -4\)
\( m_{22} \): \(-8 + 8 = 0\)
\( m_{23} \): \(-4 + 36 -36 = -4\)
\( m_{33} \): \(72 - 72 = 0\)

So:
\[
W = -4(m_{12} + m_{13} + m_{23})
\]

But \( m_{12} + m_{13} + m_{23} \) is the number of edges with endpoints of different states (i.e., not monochromatic edges). Let's call this \( m_{\text{cross}} \).

So:
\[
W = -4 m_{\text{cross}}
\]

We need \( W = -4m \), so:
\[
-4 m_{\text{cross}} = -4m \implies m_{\text{cross}} = m
\]

But \( m_{\text{cross}} \le m \) always, with equality iff every edge has endpoints of different states, i.e., the graph is properly colored with 3 colors (not necessarily proper in the usual sense, but no edge has same color on both ends).

So the condition is: there exists an assignment of states 1,2,3 to vertices such that no edge has both endpoints with the same state. That is, the graph is 3-colorable.

So the problem reduces to: Is the graph 3-colorable? If yes, output any proper 3-coloring. Otherwise, output NO.

Check example 1: Graph is K4 minus an edge? Actually n=4, edges: (1,2),(1,3),(2,3),(1,4),(2,4). This is K4 minus edge (3,4). Is it 3-colorable? Yes, color 1,2,3,3 works (as given). So YES.

Example 2: K4, which is not 3-colorable (needs 4 colors). So NO.

Thus the problem is exactly 3-coloring, which is NP-complete in general, but n ≤ 40, so we can use backtracking with pruning.

We need to output any proper 3-coloring.

So the solution is: check if graph is 3-colorable using backtracking with bitmask for available colors.

Since n ≤ 40, we can do backtracking with pruning: for each vertex, maintain a bitmask of available colors (initially 7). When we assign a color to a vertex, remove that color from its neighbors. If any vertex has 0 available colors, backtrack.

We can also use a greedy ordering (e.g., most constrained first).

Let's implement.

We'll use recursion with index of vertex to color. We'll keep an array `color` of size n, initially -1. We'll also keep an array `avail` of size n, where `avail[i]` is a bitmask of colors that can be assigned to vertex i given current partial assignment. Initially all 7.

At each step, pick an uncolored vertex with minimum number of available colors (MRV heuristic). If none, we're done.

For each color in its available set, try assigning, update neighbors' availability, recurse.

If no color works, backtrack.

Since n ≤ 40, worst-case exponential but with MRV and pruning it should be fine for typical test cases. However, 3-coloring is NP-complete, so in worst case it's exponential. But given constraints, it's likely intended.

Let's implement.

We'll read graph, build adjacency list.

Then backtrack.

Edge cases: m=0, then any assignment works, e.g., all 1.

Let's code.

```python
import sys
sys.setrecursionlimit(1000000)

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    # avail[i] bitmask of available colors (bits 0,1,2)
    avail = [7] * n
    
    def backtrack(count):
        if count == n:
            return True
        # find uncolored vertex with min available colors
        best = -1
        best_mask = 0
        best_bits = 10
        for i in range(n):
            if color[i] == -1:
                bits = bin(avail[i]).count('1')
                if bits == 0:
                    return False
                if bits < best_bits:
                    best_bits = bits
                    best = i
                    best_mask = avail[i]
                    if bits == 1:
                        break
        # try colors
        for c in range(3):
            if (best_mask >> c) & 1:
                # assign
                color[best] = c
                # save old avail for neighbors
                old = []
                for nb in adj[best]:
                    if color[nb] == -1:
                        old.append((nb, avail[nb]))
                        avail[nb] &= ~(1 << c)
                if backtrack(count + 1):
                    return True
                # backtrack
                for nb, old_mask in old:
                    avail[nb] = old_mask
                color[best] = -1
        return False
    
    if backtrack(0):
        print("YES")
        print(' '.join(str(c+1) for c in color))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
