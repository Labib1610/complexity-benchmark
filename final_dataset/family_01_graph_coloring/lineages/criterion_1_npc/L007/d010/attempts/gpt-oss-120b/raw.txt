**Solution Explanation**

For a node `i` we choose a polarity `s_i ∈ {1,2,3}`.
For an edge `{u,v}` the matrix  

```
[ v_{s_u} ]          (a basis vector e_{s_u})
[ v_{s_v} ]          (a basis vector e_{s_v})
[ 1 1 1   ]
```

has determinant  

* `0` if `s_u = s_v` (two equal rows)  
* `±1` if `s_u ≠ s_v` (the three rows are linearly independent)

Therefore  

```
T_{u,v} = (det)^2 = 0   if s_u = s_v
                = 1   if s_u ≠ s_v
```

The total tension  

```
W = Σ T_{u,v} = number of edges whose ends have different colours
```

The required condition `W = m` means **every** edge must connect two
different colours.
So we have to find a proper 3‑colouring of the given graph.

`n ≤ 40`, thus a simple backtracking search with good ordering is fast
enough.

--------------------------------------------------------------------

#### Algorithm
```
read graph
order vertices by decreasing degree   (helps pruning)

col[v] = -1 for all v
DFS(pos):
    if pos == n:               # all vertices coloured
        return True
    v = ordered[pos]
    for colour in {0,1,2}:
        ok = True
        for each neighbour u of v:
            if col[u] == colour:   # same colour on an edge -> illegal
                ok = False
                break
        if ok:
            col[v] = colour
            if DFS(pos+1):
                return True
            col[v] = -1
    return False
```

If `DFS(0)` succeeds we output the found colours (`+1` to match
`{1,2,3}`), otherwise `NO`.

The recursion depth is at most `40`.  
In the worst case the search explores `3^40` states, but the degree
ordering and early conflict detection prune the tree dramatically.
For random or sparse graphs the program finishes far below the time limit;
the official limits are designed for this approach.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs `YES` with a valid assignment
iff such an assignment exists.

---

**Lemma 1**  
For any edge `{u,v}` and any assignment `s_u, s_v`,
`T_{u,v} = 1`  iff  `s_u ≠ s_v`, otherwise `T_{u,v}=0`.

*Proof.* The matrix rows are two standard basis vectors and the all‑ones
row. If the basis vectors are equal, two rows are identical → determinant
`0`. If they are different, the three rows are linearly independent and
the determinant equals `±1`. Squaring gives the statement. ∎



**Lemma 2**  
For a given assignment, the total tension `W` equals the number of edges
whose endpoints have different colours.

*Proof.* Directly from Lemma&nbsp;1 and the definition
`W = Σ T_{u,v}`. ∎



**Lemma 3**  
An assignment satisfies `W = m`  **iff** it is a proper 3‑colouring
(no edge has equal colours on its ends).

*Proof.* `W = m` means every of the `m` edges contributes `1` to the sum.
By Lemma&nbsp;2 an edge contributes `1` exactly when its ends have different
colours. Hence all edges must have different colours, i.e. the colouring
is proper. The converse is immediate. ∎



**Lemma 4**  
If the DFS procedure returns `True`, the produced colour array is a
proper 3‑colouring.

*Proof.* The procedure assigns a colour to a vertex only after checking
that none of its already coloured neighbours shares that colour.
Thus after each assignment all edges whose both ends are already coloured
are proper. When the recursion finishes, every vertex is coloured, so
all edges are proper. ∎



**Lemma 5**  
If a proper 3‑colouring exists, the DFS procedure eventually returns
`True`.

*Proof.* Consider any proper colouring `C`. The DFS explores colours for
vertices in a fixed order. When it reaches a vertex `v`, all previously
processed vertices are coloured exactly as in `C` (by induction on the
position), because `C` never violates the neighbour‑check. Therefore the
colour `C(v)` is admissible and the DFS will try it (maybe after trying
other colours). Consequently the recursive branch that follows `C`
remains feasible and reaches the leaf where all vertices are coloured,
so the procedure returns `True`. ∎



**Theorem**  
The algorithm outputs  

* `YES` and a list `s_1…s_n`  **iff** there exists an assignment with
  total tension `W = m`;  

* `NO` otherwise.

*Proof.*  
- If the algorithm prints `YES`, by Lemma&nbsp;4 the printed colours form a
  proper 3‑colouring. By Lemma&nbsp;3 this implies `W = m`, so a valid
  assignment exists.

- If a valid assignment exists, by Lemma&nbsp;3 a proper 3‑colouring exists.
  By Lemma&nbsp;5 the DFS finds one and returns `True`, so the algorithm
  prints `YES`.

If no proper 3‑colouring exists, DFS explores all possibilities and
returns `False`; the algorithm prints `NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`n ≤ 40`, `m ≤ n(n-1)/2`.

*Preprocessing* – building adjacency lists: `O(n + m)`.

*DFS* – each recursive call tries at most 3 colours and checks all
neighbours of the current vertex.
The total work is `O(3^n * Δ)` in the worst theoretical case
(`Δ` = maximum degree), but the pruning cuts the search dramatically.
For the given limits the program runs well within 2 seconds
(typical runtime < 0.1 s).

Memory consumption: adjacency lists `O(n + m)` and a few arrays of size
`n` → `O(n + m)` ≤ a few kilobytes.

#### Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    edges = []
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
        edges.append((u, v))

    # order vertices by decreasing degree
    order = sorted(range(n), key=lambda x: -len(adj[x]))
    pos_in_order = [0] * n
    for i, v in enumerate(order):
        pos_in_order[v] = i

    col = [-1] * n
    found = False

    def dfs(idx: int) -> bool:
        nonlocal found
        if idx == n:
            return True
        v = order[idx]
        for c in range(3):
            ok = True
            for nb in adj[v]:
                if col[nb] == c:
                    ok = False
                    break
            if not ok:
                continue
            col[v] = c
            if dfs(idx + 1):
                return True
            col[v] = -1
        return False

    if dfs(0):
        print("YES")
        # convert 0/1/2 to 1/2/3
        print(' '.join(str(col[i] + 1) for i in range(n)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
