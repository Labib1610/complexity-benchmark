# Problem A — Trichrome Shifts

Time limit: 2 s
Memory limit: 256 MB

A manufacturing facility operates continuously across three distinct shifts, designated as 1, 2, and 3. The facility employs a given number of personnel. Certain pairs of personnel have interpersonal conflicts and cannot be scheduled during the same shift. 

The conflict relationships can be intricately structured. The scheduling procedure must resolve every possible scenario within the time limits, including densely interconnected groups, nearly-resolvable arrangements, and cases where a valid assignment is ultimately impossible. Your task is to allocate each person to exactly one of the three shifts such that no two conflicting individuals are assigned to the same shift, or to determine that no such allocation exists.

## Input
The first line provides two integers $n$ and $m$ — the total number of personnel and the number of documented conflicts. 
Due to strict occupancy regulations requiring dedicated emergency lockers for each worker, the facility's workforce $n$ requires a minimum of 1 person and is capped at a strict physical limit of 40 people. The count of conflict records $m$ starts from a minimum of 0 and can reach up to $n(n-1)/2$ (the scenario where everyone conflicts with everyone else).
Each of the subsequent $m$ lines provides two integers $u$ and $v$, representing a pair of personnel who must not share a shift.

## Output
If there is no valid shift allocation, output a single line containing NO.
Otherwise, output YES on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2, 3\}$), with $s_i$ representing the shift assigned to person $i$. Any valid allocation is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
