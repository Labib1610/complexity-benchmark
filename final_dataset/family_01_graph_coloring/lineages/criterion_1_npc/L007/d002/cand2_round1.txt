# Problem A — Production Roster Alignment

Time limit: 2 s   Memory limit: 256 MB

A round-the-clock production plant divides its daily operations into three distinct working periods, labeled 1, 2, and 3. The plant is staffed by $n$ workers, identified by integers from 1 to $n$. Due to interpersonal friction, specific pairs of workers refuse to work together and cannot be active during the same working period.

The plant's infrastructure strictly limits the workforce size. There are exactly 40 safety harnesses available, and since every worker requires their own harness, the total workforce $n$ is capped at this quantity (the plant is never completely empty, so $n$ is at least 1). The number of friction reports, $m$, can be as low as zero or as high as the total number of distinct pairs that can be formed from the $n$ workers. Each report involves two different workers.

Management needs a robust system to process these friction reports. The system must reliably find a valid assignment of every worker to exactly one of the three periods, ensuring no two workers in a friction report share a period. If the reports create a situation where no such assignment is possible, the system must detect this. Any valid assignment is acceptable.

## Input
The first line contains the workforce size $n$ and the number of friction reports $m$.
The following $m$ lines each contain two integers $u$ and $v$, identifying a pair of workers who must be placed in different working periods.

## Output
If no valid arrangement of workers into the three periods exists, print a single line containing NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ separated by spaces, where each $s_i \in \{1, 2, 3\}$ indicates the working period assigned to worker $i$. If multiple valid arrangements exist, any one of them will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
