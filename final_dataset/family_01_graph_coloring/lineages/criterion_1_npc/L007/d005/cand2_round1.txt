# Problem A — Thermal Resonance Tuning

Time limit: 2 s   Memory limit: 256 MB

A reactor core contains $n$ thermal modules. To maintain stability, each module $i$ must be assigned a frequency multiplier $s_i \in \{1, 2, 3\}$.

The diagnostic system has identified $m$ bilateral constraints. Each constraint specifies two modules, $u$ and $v$. 

When modules $u$ and $v$ operate simultaneously, their combined thermal footprint along an axis $x$ can be modeled by the function $f(x) = (x - s_u)^2 + (x - s_v)^2$. To prevent catastrophic feedback, the thermal equilibrium—defined as the $x$-coordinate where $f(x)$ reaches its absolute minimum—must fall strictly inside the open interval $(\min(s_u, s_v), \max(s_u, s_v))$.

Your task is to determine whether there exists a valid multiplier assignment for all modules $1 \dots n$ such that every bilateral constraint is mitigated. If such an assignment exists, you must provide one.

## Input
The first line contains two integers $n$ and $m$. The number of modules $n$ is at least 1. The maximum capacity of any reactor of this class is such that if every possible pair of modules had a constraint, there would be exactly 780 constraints; $n$ is guaranteed to not exceed this capacity. The number of active constraints $m$ is non-negative and does not exceed the total number of possible pairs for the actual $n$.

Each of the following $m$ lines contains two integers $u$ and $v$, indicating a bilateral constraint involving module $u$ and module $v$.

## Output
If it is impossible to satisfy all constraints, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2, 3\}$), with $s_i$ representing the frequency multiplier assigned to module $i$. Any valid assignment is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The explicit condition "strictly different states" was replaced with a continuous algebraic property: the minimum of the quadratic function $f(x) = (x - s_u)^2 + (x - s_v)^2$ must fall strictly between $\min(s_u, s_v)$ and $\max(s_u, s_v)$. Mathematically, the minimum is at $x = (s_u + s_v)/2$, which is strictly between the two values if and only if $s_u \neq s_v$. This prevents the model from recognizing the problem as Graph 3-Coloring, forcing it to omit degree-based vertex ordering and rely on generic backtracking, which will TLE on dense graphs at $N=40$. S07 was also applied to the bounds, encoding $N \le 40$ as a maximum pair count of 780.
</RATIONALE>
<PRESERVED_ANSWER>
The absolute minimum of $f(x)$ occurs at the midpoint of $s_u$ and $s_v$; this midpoint lies strictly inside the open interval between them if and only if $s_u \neq s_v$, perfectly preserving the original conflict logic.
</PRESERVED_ANSWER>
