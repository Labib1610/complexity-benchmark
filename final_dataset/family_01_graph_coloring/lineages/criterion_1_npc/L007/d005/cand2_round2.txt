# Problem A — Quantum Phase Calibration

Time limit: 2 s   Memory limit: 256 MB

A quantum array contains $n$ flux nodes. To stabilize the array, each node $i$ (for $1 \le i \le n$) must be calibrated to a phase state $s_i$, which must be exactly 1, 2, or 3.

The diagnostic system has identified $m$ entanglement links. Each link specifies two nodes, $u$ and $v$, which are physically positioned such that they will cause catastrophic interference if their phase states are harmonically aligned. Specifically, for every recorded entanglement link between node $u$ and node $v$, the phase states must be assigned such that the value $s_u + 2s_v$ is not a multiple of 3.

Your task is to determine whether there exists a valid phase state assignment for all nodes $1 \dots n$ such that every entanglement link is mitigated. If such an assignment exists, you must provide one.

## Input
The first line contains two integers $n$ and $m$ — the number of flux nodes and the number of entanglement links ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the following $m$ lines contains two integers $u$ and $v$, indicating an entanglement link between node $u$ and node $v$.

## Output
If it is impossible to calibrate the nodes safely, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2, 3\}$), with $s_i$ representing the phase state assigned to node $i$. Any valid assignment is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The problem was rewritten to hide the "strictly different" constraint that triggers graph 3-coloring heuristics. I replaced the inequality $s_u \neq s_v$ with the mathematically equivalent modular arithmetic condition $s_u + 2s_v \not\equiv 0 \pmod 3$ for $s_i \in \{1, 2, 3\}$, forcing the model to either deduce the equivalence or process the constraint algebraically rather than relying on standard graph coloring templates. The explicit bounds were restored exactly as requested.
</RATIONALE>
<PRESERVED_ANSWER>
For any $x, y \in \{1, 2, 3\}$, the expression $x + 2y$ is a multiple of 3 if and only if $x = y$, meaning the modular constraint perfectly enforces the original requirement that linked nodes have different states.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains identically equivalent to graph 3-colorability, preserving its NP-completeness and required search space.
</PRESERVED_CLASS>
