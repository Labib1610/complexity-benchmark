<STATEMENT>
# Problem A — Orbital Resonance Alignment

Time limit: 2 s   Memory limit: 256 MB

A space station has $n$ stabilizing gyroscopes. To maintain operational equilibrium, each gyroscope must be tuned to a frequency band $s_i \in \{1, 2, 3\}$.

The station's structural integrity depends on $m$ critical load-bearing struts, each connecting a specific pair of gyroscopes. The interaction between connected gyroscopes generates a resonance drift.

For a strut connecting gyroscope $u$ and gyroscope $v$, let $S = s_u + s_v$ and $P = s_u \times s_v$.
The thermal drift $T_{u,v}$ is calculated as:
$T_{u,v} = P^2 - 11P + 6S + 7$

The resonance variance $R_{u,v}$ is calculated as:
$R_{u,v} = P - S^2 + 6S - 11$

The combined strut drift $D_{u,v}$ is given by:
$D_{u,v} = T_{u,v} + 5 \times (R_{u,v})^2$

The total system drift $W$ is the sum of the combined drifts across all $m$ struts:
$W = \sum_{j=1}^m D_{u_j, v_j}$

To maintain perfect structural stability, the total system drift must be exactly $7m$. 

Your task is to determine whether there exists a valid frequency assignment for all gyroscopes $1 \dots n$ such that the total system drift $W$ is exactly $7m$. If such an assignment exists, you must provide one.

## Input
The first line contains two integers $n$ and $m$ — the number of gyroscopes and the number of struts ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating a strut connecting gyroscope $u$ and gyroscope $v$. Each strut is listed at most once.

## Output
If it is impossible to align the gyroscopes to the required drift state, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2, 3\}$), with $s_i$ representing the frequency band assigned to gyroscope $i$. Any valid assignment is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```
*Explanation for Example 1:*
Assigning frequency bands 1, 2, 3, 3 yields the following calculations:
- Strut (1, 2) with bands 1 and 2: $S = 1+2=3, P = 1 \times 2=2$.
  $T_{1,2} = 2^2 - 11(2) + 6(3) + 7 = 4 - 22 + 18 + 7 = 7$.
  $R_{1,2} = 2 - 3^2 + 6(3) - 11 = 2 - 9 + 18 - 11 = 0$.
  $D_{1,2} = 7 + 5(0)^2 = 7$.
- Strut (1, 3) with bands 1 and 3: $S = 1+3=4, P = 1 \times 3=3$.
  $T_{1,3} = 3^2 - 11(3) + 6(4) + 7 = 9 - 33 + 24 + 7 = 7$.
  $R_{1,3} = 3 - 4^2 + 6(4) - 11 = 3 - 16 + 24 - 11 = 0$.
  $D_{1,3} = 7 + 5(0)^2 = 7$.
- Strut (2, 3) with bands 2 and 3: $S = 2+3=5, P = 2 \times 3=6$.
  $T_{2,3} = 6^2 - 11(6) + 6(5) + 7 = 36 - 66 + 30 + 7 = 7$.
  $R_{2,3} = 6 - 5^2 + 6(5) - 11 = 6 - 25 + 30 - 11 = 0$.
  $D_{2,3} = 7 + 5(0)^2 = 7$.
- Strut (1, 4) with bands 1 and 3: identical to (1, 3), $D_{1,4} = 7$.
- Strut (2, 4) with bands 2 and 3: identical to (2, 3), $D_{2,4} = 7$.

The total system drift $W$ is $7 + 7 + 7 + 7 + 7 = 35$. Since $m = 5$, the target is $7 \times 5 = 35$. The configuration achieves the target exactly.

<RATIONALE>
The modular arithmetic formula was replaced with a custom 2-variable polynomial system that evaluates to exactly 7 for all unequal frequency pairs, and strictly greater than 7 for equal ones. Because all possible drift values are $\ge 7$, achieving a total sum of exactly $7m$ over $m$ struts mathematically forces every single strut to evaluate to exactly 7, which means no two connected gyroscopes can share the same frequency. This forces the model to either mathematically prove this minimum to unlock a standard 3-coloring reduction, or attempt to evaluate the polynomial globally inside a naive backtracking loop (which will Time Out).
</RATIONALE>

The polynomial evaluates to 7 for all unequal pairs and to 29, 8, or 45 for equal pairs; since the minimum possible value is 7, a sum of 7m over m edges is achieved if and only if every edge is unequal, making it perfectly equivalent to proper 3-coloring.
</PRESERVED_ANSWER>
