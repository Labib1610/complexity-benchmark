<STATEMENT>
# Quantum Resonance Synthesis

Time limit: 2 s   Memory limit: 256 MB

You are configuring a network of $n$ quantum resonance emitters. Each emitter $i$ (where $1 \le i \le n$) must be assigned an excitation state $e_i$, chosen from the discrete energy levels $\{1, 2, 3\}$.

The network's stability is constrained by $m$ proximity conditions. Each condition specifies two emitters, identified by their indices $u$ and $v$, which share a quantum entanglement channel. To avoid destructive interference, their assigned states must not form a resonant loop.

Specifically, for each condition specifying emitters $u$ and $v$, you must evaluate the channel's phase sum:
$$S = e_u + 2 e_v$$
For the entanglement channel to remain stable, this phase sum $S$ must not be a multiple of 3. You must ensure this requirement holds for all $m$ conditions.

Your task is to determine whether there exists a global assignment of excitation states for all $n$ emitters such that all $m$ proximity conditions are satisfied simultaneously. If such an assignment exists, you must provide one. Providing any single valid assignment is sufficient, even if multiple exist.

## Input
The first line contains two integers $n$ and $m$ — the total number of emitters and the number of proximity conditions ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$, indicating a condition that the emitters $u$ and $v$ must satisfy the phase sum requirement.

## Output
If it is impossible to assign excitation states to all emitters such that every condition is satisfied, print a single line containing `NO`.
If it is possible, print `YES` on the first line. On the second line, print $n$ integers $e_1, e_2, \dots, e_n$ separated by spaces, where each $e_i \in \{1, 2, 3\}$ indicates the excitation state assigned to emitter $i$. You only need to supply one valid assignment, even if multiple are possible.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The matrix determinant condition in the seed trivially simplified to $e_u \neq e_v$, which models recognized to map the problem directly to graph 3-coloring and apply degree-ordered backtracking. By changing the condition to $(e_u + 2 e_v)$ not being a multiple of 3, the equivalence to $e_u \neq e_v$ is preserved for values in $\{1, 2, 3\}$, but models are forced to either algebraically derive this equivalence or use naive backtracking without coloring heuristics, which will time out on $N=40$.
</RATIONALE>
<PRESERVED_ANSWER>
For $e_u, e_v \in \{1, 2, 3\}$, the phase sum $e_u + 2 e_v = 3 e_v + (e_u - e_v)$ is a multiple of 3 if and only if $e_u = e_v$, meaning the new condition is mathematically identical to the original matrix invertibility requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains identical to graph 3-coloring, keeping it NP-complete.
</PRESERVED_CLASS>
