# Personnel Scheduling

Time limit: 2 s   Memory limit: 256 MB

A production plant employs $n$ staff members. Over time, management has logged $m$ specific pairs of workers who exhibit severe friction. Workplace policies strictly mandate that no two workers in a logged pair can be assigned to the same shift.

The plant operates around the clock using exactly three shifts: shift 1, shift 2, and shift 3. 

You must determine if there is a valid way to assign every staff member to exactly one of the three shifts without violating the friction policy. When such an arrangement is possible, you must provide it.

## Input
The first line contains two integers $n$ and $m$ — the number of staff members and the number of friction pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the following $m$ lines contains two integers $u$ and $v$, meaning staff member $u$ and staff member $v$ cannot share a shift.

## Output
If it is impossible to assign all staff members safely, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each being 1, 2, or 3), where $s_i$ is the shift assigned to staff member $i$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The suggestion to add a canonical requirement (like lexicographically smallest) would violate Constraint 2 by introducing a tie-break rule where none existed in the seed. Instead, I removed the explicit trigger sentence ("If multiple valid assignments exist, any of them will be accepted") that the model relied on to justify its greedy shortcut. This removes the affordance without altering the I/O contract.
</RATIONALE>
<PRESERVED_ANSWER>
The conditions for a valid schedule are identical to the seed, and the problem still accepts any valid assignment.
</PRESERVED_ANSWER>

The problem remains equivalent to finding a valid 3-coloring for a graph with $n$ vertices and $m$ edges, which is NP-complete.
</PRESERVED_CLASS>
