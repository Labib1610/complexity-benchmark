<STATEMENT>
# Discrete Parameter Synthesis

Time limit: 2 s   Memory limit: 256 MB

You are given a system of $n$ discrete parameters. Each parameter $e_i$ (where $1 \le i \le n$) must be configured with an integer value from the domain $\{1, 2, 3\}$.

The system's stability is governed by $m$ algebraic conditions. Each condition specifies two parameters, $u$ and $v$, which must satisfy the quadratic inequality:
$(e_u - e_v)^2 \ge 1$

Your task is to evaluate whether there exists a global configuration for all $n$ parameters such that all $m$ conditions are satisfied simultaneously. If a valid configuration is possible, you must provide one. Providing any single valid configuration is sufficient, even if multiple solutions exist.

## Input
The first line contains two integers $n$ and $m$ — the total number of parameters and the number of conditions ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$, indicating a condition that the parameters $e_u$ and $e_v$ must satisfy $(e_u - e_v)^2 \ge 1$.

## Output
If it is impossible to assign values to all parameters such that every condition is satisfied, print a single line containing `NO`.
If it is possible, print `YES` on the first line. On the second line, print $n$ integers $e_1, e_2, \dots, e_n$ separated by spaces, where each $e_i \in \{1, 2, 3\}$ indicates the value assigned to parameter $i$. You only need to supply one valid assignment, even if multiple are possible.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I changed the framing from isolated modules to an algebraic system of discrete parameters. The absolute value inequality was replaced with a mathematically equivalent squared difference inequality to obscure the graph coloring nature of the problem, forcing models to reason about the algebraic constraints directly rather than applying degree-based graph heuristics.
</RATIONALE>
<PRESERVED_ANSWER>
The domain of each parameter is exactly {1, 2, 3} and the condition (e_u - e_v)^2 >= 1 is mathematically equivalent to |e_u - e_v| >= 1 for integers, so the valid configurations remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to 3-coloring a graph with n vertices and m edges, keeping it NP-complete.
</PRESERVED_CLASS>
