# Workforce Shift Harmonization

Time limit: 2 s   Memory limit: 256 MB

A manufacturing facility relies on a workforce of $n$ personnel. The human resources department has cataloged $m$ specific pairs of employees who exhibit severe friction when working side-by-side. To ensure smooth operations, company policy strictly dictates that any two employees identified in a friction pair cannot be assigned to the same working period.

The facility operates on a daily cycle split into exactly three non-overlapping working periods: period 1, period 2, and period 3.

The friction pairs are systematically arranged to form deeply interlocking dependencies. The input data is structurally balanced such that sorting or prioritizing individuals by their total number of conflicts provides no advantage; the constraints are distributed to ensure that all schedule combinations remain highly interdependent. The provided scenarios include both cases where a valid schedule can be formed and cases where the constraints perfectly block all valid schedules.

Your task is to determine if there is a valid way to assign every employee to exactly one of the three working periods such that no friction rules are violated. If such an assignment exists, you must provide one. You only need to output a single valid assignment, even if multiple options are available.

## Input
The first line contains two integers $n$ and $m$ — the total number of personnel and the number of friction pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the following $m$ lines contains two integers $u$ and $v$, indicating that employee $u$ and employee $v$ must be scheduled in different working periods.

## Output
If it is impossible to assign all personnel to the working periods without breaking the friction rules, output a single line containing `NO`.
If a valid assignment is possible, output `YES` on the first line. On the second line, output $n$ space-separated integers $s_1, s_2, \dots, s_n$, where each $s_i \in \{1, 2, 3\}$ represents the working period assigned to employee $i$. You only need to supply one valid assignment, even if several are possible.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
