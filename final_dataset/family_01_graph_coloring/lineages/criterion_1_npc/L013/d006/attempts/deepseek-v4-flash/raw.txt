 We need to assign each vertex a value from {1, 2, 3} such that for every edge (u, v), the determinant  
\[
\begin{vmatrix}
u & v \\
u \cdot e_u & v \cdot e_v
\end{vmatrix}
= u \cdot v \cdot e_v - v \cdot u \cdot e_u = uv(e_v - e_u) \neq 0
\]  
Since \(u\) and \(v\) are distinct positive integers, \(uv \neq 0\), so the condition reduces to:  
\[
e_u \neq e_v
\]  
for every edge.  

Thus, the problem is simply: can we 3-color the graph?  
If yes, output the coloring; otherwise, output "NO".  

We can solve this with backtracking or BFS-based 3-coloring. Since \(n \leq 40\), backtracking with pruning works fine.

Here’s the implementation:

```python
n, m = map(int, input().split())
edges = [tuple(map(int, input().split())) for _ in range(m)]

adj = [[] for _ in range(n)]
for u, v in edges:
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def dfs(node):
    for c in range(3):
        ok = True
        for nei in adj[node]:
            if color[nei] == c:
                ok = False
                break
        if ok:
            color[node] = c
            for nei in adj[node]:
                if color[nei] == -1:
                    if not dfs(nei):
                        ok = False
                        break
            if ok:
                return True
            color[node] = -1
    return False

possible = True
for i in range(n):
    if color[i] == -1:
        if not dfs(i):
            possible = False
            break

if not possible:
    print("NO")
else:
    print("YES")
    print(" ".join(str(c + 1) for c in color))
```
