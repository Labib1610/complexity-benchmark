We can first compute the possible energy contributions for each pair of states:

- (1,1), (2,2), (3,3): difference = 0 → energy = 7  
- (1,2) or (2,1): difference = 1 → energy = 1 - 5 + 7 = 3  
- (2,3) or (3,2): difference = 1 → energy = 3  
- (1,3) or (3,1): difference = 2 → energy = 16 - 20 + 7 = 3  

So the only possible energies are 3 (for different states) and 7 (for same states).  
We need total = 3m, so every edge must contribute exactly 3.  
That means no edge can connect two emitters with the same state.  

Thus the problem reduces to: can we 3-color the graph such that adjacent vertices have different colors?  
Since n ≤ 40, we can use backtracking with pruning.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    
    def backtrack(idx):
        if idx == n:
            return True
        # Try colors 0,1,2 (representing 1,2,3)
        for c in range(3):
            ok = True
            for nb in adj[idx]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[idx] = c
                if backtrack(idx + 1):
                    return True
                color[idx] = -1
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(str(c + 1) for c in color))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
