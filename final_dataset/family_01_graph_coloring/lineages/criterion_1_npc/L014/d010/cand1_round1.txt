<METHOD_DESCRIPTION>
Replaces the polynomial resonance test with a discrete dynamical system (iterated function S -> S^2+c mod 17). The node speeds x and y dictate the number of iterations applied to an edge-dependent initial state. Because the iteration count is the variable, it cannot be factored algebraically. The chosen constants c guarantee no cycles of length <= 3, meaning equality holds if and only if x=y, but proving this requires quadratic residue analysis that LLMs won't perform. The edge-dependent parameters act as a psychological trap to make the model think the forbidden pairs vary by edge.

# Problem A — Grid Harmonic Resonance

Time limit: 2 s
Memory limit: 256 MB

You are deploying a computational grid consisting of $n$ processing nodes, labeled 1 through $n$. Your task is to configure the clock speed for each node. The available clock speed options for any node are 1, 2, and 3 GHz.

Certain pairs of nodes share a direct synchronization link. For any two linked nodes $u$ and $w$ assigned clock speeds $x$ and $y$ respectively (where $x$ is the speed of $u$ and $y$ is the speed of $w$), the synchronization controller runs a signal reflection diagnostic to ensure stability.

The diagnostic process is as follows:
1. It determines a link-specific interference constant $c$ from the array $C = [1, 2, 6, 7]$. Specifically, $c = C[(u + w) \bmod 4]$, where the array is 0-indexed.
2. It initializes a signal intensity $I_0 = (u \cdot w) \bmod 17$.
3. It simulates signal reflection for node $u$ by applying a non-linear transformation exactly $x$ times. That is, it computes $I_k = (I_{k-1}^2 + c) \bmod 17$ for $k = 1, 2, \dots, x$. The final diagnostic value for node $u$ is $V_u = I_x$.
4. It independently simulates signal reflection for node $w$ by applying the same transformation exactly $y$ times, starting from the same initial intensity. That is, it computes $J_k = (J_{k-1}^2 + c) \bmod 17$ for $k = 1, 2, \dots, y$, with $J_0 = I_0$. The final diagnostic value for node $w$ is $V_w = J_y$.

Due to hardware limitations, if the final diagnostic values are exactly equal ($V_u = V_w$), the nodes will experience harmonic resonance and the link will fail. To ensure the grid is fully operational, every synchronization link must connect two nodes that do not experience harmonic resonance.

You are provided with the number of nodes and the exact pairs that share a synchronization link. You must output a fully functional clock speed assignment for the grid, or indicate if it is impossible.

## Input
The first line contains two integers $n$ and $m$ — the number of processing nodes and the number of synchronization links ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
Each of the following $m$ lines contains two distinct integers $u$ and $w$ ($1 \le u, w \le n$, $u \neq w$), representing a pair of nodes connected by a synchronization link. It is guaranteed that each unordered pair of nodes appears at most once in the input.

## Output
If no valid clock speed assignment can be found, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $a_1, a_2, \dots, a_n$ (where each $a_i \in \{1, 2, 3\}$), representing the clock speed assigned to node $i$. Any valid assignment will be accepted.

## Example 1
Input:

1 3

1 4
2 4
```
Output:
```
YES
1 2 3 3
```

```

<RATIONALE>
The previous version used a polynomial expression for the diagnostic values, which the surviving model algebraically factored to deduce that resonance only occurs when the speeds are equal. To defeat this, the resonance test is replaced with a discrete dynamical system (a non-linear state machine modulo 17) where the node speeds determine the number of iterations rather than acting as algebraic variables. The constants are carefully chosen so that the sequence has no short cycles, perfectly preserving the $x \neq y$ logic, but the model cannot algebraically simplify it and will likely fail to deduce the uniform rule due to the edge-dependent parameters.
</RATIONALE>
<PRESERVED_ANSWER>
By selecting constants $c \in \{1, 2, 6, 7\}$, the quadratic recurrence $S_{k+1} \equiv S_k^2 + c \pmod{17}$ mathematically has no 1-cycles and no 2-cycles, ensuring that the sequence values at steps 1, 2, and 3 are always pairwise distinct; thus, $V_u = V_w$ if and only if $x = y$, keeping the valid assignments exactly identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The condition $V_u = V_w$ simplifies strictly to $x = y$ for all valid inputs, meaning the problem remains exact Graph 3-Coloring, which is NP-complete.
</PRESERVED_CLASS>
