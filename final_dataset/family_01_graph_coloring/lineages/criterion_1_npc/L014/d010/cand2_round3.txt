# Problem A — Grid Harmonic Resonance

Time limit: 2 s
Memory limit: 256 MB

You are deploying a computational grid. The grid consists of processing nodes, labeled sequentially starting from 1. Your task is to configure the clock speed for each node. The available clock speed options for any node are 1, 2, and 3 GHz.

Certain pairs of nodes share a direct bidirectional synchronization link. The grid operates on a universal 5-tick phase cycle. When a node running at speed $x$ transmits to a linked node running at speed $y$, the receiving node processes the mixed signal. The phase interference sum of this transmission is calculated as 4 times the sender's speed plus the receiver's speed. 

If this sum is an exact multiple of 5, the mixed signal hits the cycle boundary exactly and causes a harmonic resonance failure. Because the synchronization links are bidirectional, communication flows both ways. Thus, a link connecting a node with speed $x$ and a node with speed $y$ will fail if either $4x + y$ or $4y + x$ is a multiple of 5. 

To ensure the grid is fully operational, every synchronization link must connect two nodes that do not cause a resonance failure.

You are provided with the number of nodes and the exact pairs that share a synchronization link. You must output a fully functional clock speed assignment for the grid, or indicate if it is impossible.

## Input
The first line contains two integers $n$ and $m$. The integer $n$ represents the number of processing nodes in the grid, which is constrained by a 40-slot hardware chassis. The integer $m$ represents the number of synchronization links, which can be any count from zero up to a fully connected network topology (one link per unique pair of nodes).
Each of the following $m$ lines contains two distinct integers $u$ and $w$ (both being valid node labels from 1 to $n$), representing a pair of nodes connected by a synchronization link. It is guaranteed that no two links connect the same unordered pair of nodes.

## Output
If no valid clock speed assignment can be found, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $a_1, a_2, \dots, a_n$ (where each $a_i \in \{1, 2, 3\}$), representing the clock speed assigned to node $i$. Any valid assignment will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

I replaced the explicit algebraic equality check with a modular arithmetic condition ($4x+y \pmod 5 \neq 0$). This forces the model to evaluate the condition for the domain $\{1, 2, 3\}$ to realize it strictly enforces $x \neq y$, breaking its ability to use symbolic cancellation as a shortcut to graph coloring. I also applied S07 by describing the input bounds via physical constraints like a "40-slot hardware chassis" rather than bare inequalities.
</RATIONALE>
<PRESERVED_ANSWER>
For $x, y \in \{1, 2, 3\}$, the condition $4x+y \equiv 0 \pmod 5$ is true if and only if $x = y$, meaning the set of valid assignments remains exactly identical to the original problem.
</PRESERVED_ANSWER>

The problem is still isomorphic to graph 3-coloring, which is NP-complete, as the modular constraint perfectly maps to the requirement that adjacent nodes have different colors.
</PRESERVED_CLASS>
