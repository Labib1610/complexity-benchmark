# Problem A — Circuit Voltage Levels

Time limit: 2 s
Memory limit: 256 MB

You are configuring a custom integrated circuit consisting of multiple logic components. The components are numbered sequentially starting from 1. Each component must be supplied with a discrete operating voltage level of 1, 2, or 3.

The circuit contains various data links between specific pairs of components. For a data link to function correctly, there must be a non-zero potential difference between the two components it connects. Therefore, the two components sharing a link cannot be supplied with the identical voltage level.

The circuit designs provided for certification will include highly irregular, worst-case connection topologies. Your configuration tool must be robust enough to handle these adversarial layouts without relying on simple structural assumptions or assignment strategies that just prioritize the most heavily connected components.

You are given the total number of components and the specific pairs that are connected by data links. Determine a valid voltage assignment for all components that ensures every data link is functional, or report that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$ — the number of logic components and the number of data links. The value of $n$ is at least 1 and at most the number of thieves in the classic tale of Ali Baba. The value of $m$ ranges from 0 up to the maximum possible number of unique unordered pairs among the $n$ components. 

Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing a pair of components connected by a data link. No pair of components is connected by more than one link (unordered pairs are unique in the input).

## Output
If no valid voltage assignment can be found, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $v_1, v_2, \dots, v_n$ (where each $v_i \in \{1, 2, 3\}$), representing the voltage level assigned to component $i$. Any valid assignment will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
