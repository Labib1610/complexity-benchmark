# Problem A — Circuit Voltage Levels

Time limit: 2 s
Memory limit: 256 MB

You are tasked with tuning an integrated circuit made up of $n$ distinct processing components, indexed from 1 up to $n$. To ensure stable operation, every component must be assigned exactly one of three available discrete voltage levels: 1, 2, or 3.

The circuit architecture includes several communication pathways, each bridging a specific pair of components. A pathway can only transmit signals if there is a strict potential difference across it. This means that any two components joined by a pathway must operate at different voltage levels.

Given the total component count and the layout of the communication pathways, your goal is to find a valid voltage configuration for all $n$ components such that every pathway is active. If it is impossible to satisfy all pathway constraints simultaneously, you must report that no solution exists.

*Performance note: The official test suite includes adversarial configurations chosen to defeat solvers that rely on simple heuristics, such as processing components based on their connection count. Ensure your approach can handle worst-case topologies within the time limit.*

## Input
The first line contains two integers $n$ and $m$ — the number of processing components and the number of communication pathways. The component count $n$ is restricted by the packaging standard, being at least 1 and at most the number of hours in a standard full-time work week (40). The pathway count $m$ is at least 0 and at most the maximum possible number of component pairs ($n \cdot (n-1)/2$).
Each of the following $m$ lines contains two integers $u$ and $v$ (where $1 \le u, v \le n$), representing a pair of components bridged by a communication pathway.

## Output
If no valid voltage assignment can be found, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $v_1, v_2, \dots, v_n$ (where each $v_i \in \{1, 2, 3\}$), representing the voltage level assigned to component $i$. Any valid assignment will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
