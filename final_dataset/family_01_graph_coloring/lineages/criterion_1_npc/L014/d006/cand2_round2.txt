<STATEMENT>
# Problem A — Grid Harmonic Resonance

Time limit: 2 s
Memory limit: 256 MB

You are deploying a computational grid consisting of $n$ processing nodes, labeled 1 through $n$. Your task is to configure the clock speed for each node. The available clock speed options for any node are 1, 2, and 3 GHz.

Each clock speed option $k \in \{1, 2, 3\}$ corresponds to a specific phase vector $v_k$ in 3D space:
- 1 GHz corresponds to $v_1 = (2, -1, -1)$
- 2 GHz corresponds to $v_2 = (-1, 2, -1)$
- 3 GHz corresponds to $v_3 = (-1, -1, 2)$

Certain pairs of nodes share a direct synchronization link. Due to hardware limitations, if the dot product of the phase vectors of two linked nodes is 6, they will experience harmonic resonance and the link will fail. To ensure the grid is fully operational, every synchronization link must connect two nodes whose phase vectors have a dot product of exactly -3. (Note that any pair of available clock speeds will result in a dot product of either 6 or -3).

You are provided with the number of nodes and the exact pairs that share a synchronization link. You must output a fully functional clock speed assignment for the grid, or indicate if it is impossible.

## Input
The first line contains two integers $n$ and $m$ — the number of processing nodes and the number of synchronization links ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
Each of the following $m$ lines contains two distinct integers $u$ and $w$ ($1 \le u, w \le n$, $u \neq w$), representing a pair of nodes connected by a synchronization link. It is guaranteed that each unordered pair of nodes appears at most once in the input.

## Output
If no valid clock speed assignment can be found, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $a_1, a_2, \dots, a_n$ (where each $a_i \in \{1, 2, 3\}$), representing the clock speed assigned to node $i$. Any valid assignment will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The seed problem used a "perfect square" product constraint to forbid identical assignments across links. Models easily recognized this as an equality check and deployed specialized graph 3-coloring algorithms with degree-ordered heuristics. I replaced this with an algebraic vector embedding, assigning a 3D phase vector to each clock speed. The equality check is now a dot product condition (6 for identical, -3 for distinct). This forces models to either formally prove the equivalence to graph coloring or fall back to generic CSP backtracking, which will TLE without graph-specific heuristics.
</RATIONALE>
<PRESERVED_ANSWER>
The dot product of any two identical vectors from the set is 6, and any two distinct vectors is -3, meaning the new constraint is strictly equivalent to forbidding equal assignments on linked nodes, perfectly preserving all valid configurations.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to general graph 3-coloring, which is NP-complete, because the pairwise constraint still strictly evaluates to $a_u \neq a_w$.
</PRESERVED_CLASS>
