<METHOD_NAME>Explicit Allowed Set Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the algebraic inequality constraint with an exhaustive list of allowed unordered pairs, forcing models to interpret the rule as a generic constraint rather than immediately mapping it to the inequality operator and graph coloring. This aims to prevent the activation of graph-coloring-specific heuristics like DSATUR or MRV, causing generic backtracking solutions to fail the time limit on challenging test cases.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Circuit Voltage Levels

Time limit: 2 s
Memory limit: 256 MB

An integrated circuit contains $n$ logic components, identified by integers from 1 to $n$. You must configure the circuit by assigning an operating voltage to each component. The only permitted voltage levels for any component are 1, 2, and 3.

The components are connected by a network of bidirectional data links. For any data link to function properly, the two components at its ends must be assigned a valid voltage combination. The exclusively permitted combinations for the two linked components (regardless of order) are:
- Voltage 1 and Voltage 2
- Voltage 1 and Voltage 3
- Voltage 2 and Voltage 3

If a link's endpoints are assigned any combination of voltages not explicitly listed above, the link will fail. You must find a voltage assignment for all $n$ components such that every data link functions properly.

The test cases are heavily constrained. Basic search algorithms that process components in ascending numerical order, or that statically order them by their total number of links, will exceed the time limit due to the vast number of combinations.

## Input
The first line provides two integers $n$ and $m$ — the number of logic components and the number of data links ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
The next $m$ lines each contain two distinct integers $u$ and $w$ ($1 \le u, w \le n$, $u \neq w$), specifying that a bidirectional data link connects component $u$ and component $w$. Each connected pair is listed at most once.

## Output
If there is no valid configuration, output a single line with `NO`.
If a configuration exists, print `YES` on the first line. On the second line, print $n$ space-separated integers $a_1, a_2, \dots, a_n$, where $a_i \in \{1, 2, 3\}$ is the voltage for component $i$. Any valid assignment will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The algebraic rule in the seed ($a+b \neq 2a$ and $a+b \neq 2b$) trivially simplifies to $a \neq b$, which models immediately recognize as graph coloring. By replacing this with an explicit list of allowed unordered pairs, the problem appears as a generic constraint satisfaction problem. Models that fail to recognize the equivalence to graph coloring will likely omit crucial heuristics like DSATUR or MRV, leading to a Time Limit Exceeded on the heavily constrained test cases.
</RATIONALE>
<PRESERVED_ANSWER>
The explicit list of allowed combinations ({1,2}, {1,3}, {2,3}) perfectly matches the set of pairs where the two assigned voltages are distinct, which is exactly the same logical constraint as the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains identical to graph 3-coloring, which is NP-complete, as the constraint still enforces that no two connected components share the same voltage.
</PRESERVED_CLASS>
