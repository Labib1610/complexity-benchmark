We need to assign voltages 1, 2, or 3 to each node such that every edge connects nodes with different voltages (since each allowed set consists of two distinct numbers from {1,2,3}).

This is equivalent to a **3-coloring** problem, but note that not just any 3-coloring works — we must also have that the two voltages on an edge are *different*, which is automatically satisfied by a proper 3-coloring.

So the problem reduces to: Given a graph with up to 40 nodes, is it 3-colorable? If yes, output one such coloring.

Since n ≤ 40, we can use **backtracking with pruning** or **DSATUR**. We'll implement backtracking for simplicity, ensuring efficiency by always choosing the vertex with the most constraints (DSATUR-style ordering heuristic).

Let's write the solution:

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    colors = [0] * n
    # available colors for each node: 1,2,3
    
    # Sort vertices by degree descending for better backtracking order
    order = sorted(range(n), key=lambda x: len(adj[x]), reverse=True)
    
    # Simple backtracking with MRV heuristic
    
    def dfs(pos):
        if pos == n:
            return True
        v = order[pos]
        # Try colors 1,2,3
        for c in (1,2,3):
            ok = True
            for nb in adj[v]:
                if colors[nb] == c:
                    ok = False
                    break
            if ok:
                colors[v] = c
                if dfs(pos + 1):
                    return True
                colors[v] = 0
        return False
    
    if dfs(0):
        print("YES")
        print(" ".join(str(colors[i]) for i in range(n)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
