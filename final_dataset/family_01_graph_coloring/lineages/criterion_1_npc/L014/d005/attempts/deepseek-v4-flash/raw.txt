 We need to assign each node a value from {1, 2, 3} such that for every edge (u, v), the product of their values is **not** a perfect square.

Let’s analyze the condition:

- 1×1 = 1 (perfect square) → invalid  
- 1×2 = 2 (not square) → valid  
- 1×3 = 3 (not square) → valid  
- 2×2 = 4 (perfect square) → invalid  
- 2×3 = 6 (not square) → valid  
- 3×3 = 9 (perfect square) → invalid  

So the only invalid pairs are:  
(1,1), (2,2), (3,3).  
That means: **No two connected nodes can have the same value.**

So the problem reduces to:  
Can we 3-color the given graph?  
If yes, output any valid coloring. If not, output `NO`.

Since n ≤ 40, we can use backtracking or a simple greedy with backtracking.

We'll implement a backtracking 3-coloring.

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n

def is_safe(node, c):
    for nei in adj[node]:
        if color[nei] == c:
            return False
    return True

def solve(node):
    if node == n:
        return True
    for c in range(1, 4):
        if is_safe(node, c):
            color[node] = c
            if solve(node + 1):
                return True
            color[node] = 0
    return False

if solve(0):
    print("YES")
    print(" ".join(str(c) for c in color))
else:
    print("NO")
```
