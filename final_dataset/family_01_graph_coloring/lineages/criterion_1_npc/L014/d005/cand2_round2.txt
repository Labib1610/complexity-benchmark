<METHOD_NAME>
GCD-LCM-Inequality-Obfuscation
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the explicit subset enumeration of valid pairs ({1,2}, {1,3}, {2,3}) with an equivalent number-theoretic inequality: GCD(x,y) + LCM(x,y) > 2*min(x,y). For x,y in {1,2,3}, this perfectly filters out x=y (where it evaluates to 2x > 2x, false) and allows x!=y (e.g., 1+6 > 4, true). This prevents LLMs from recognizing the standard 3-coloring edge constraint via pattern matching, thereby disabling their degree-ordering heuristics.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<STATEMENT>
# Problem A — Circuit Voltage Levels

Time limit: 2 s
Memory limit: 256 MB

An integrated circuit is being designed with $n$ logic components, labeled 1 through $n$. Your task is to assign each component a discrete operating voltage. The available voltage options for any component are 1, 2, and 3.

Certain pairs of components communicate via bidirectional data links. In order for communication to be successful across a link, the voltages assigned to the two connected components must satisfy a specific synchronization constraint: the greatest common divisor (GCD) of the two voltages, plus their least common multiple (LCM), must be strictly greater than twice the minimum of the two voltages.

You are provided with the number of components and the exact pairs that share a data link. You must output a fully functional voltage assignment for the circuit, or indicate if it is impossible.

## Input
The first line contains two integers $n$ and $m$ — the number of logic components and the number of data links ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
Each of the following $m$ lines contains two distinct integers $u$ and $w$ ($1 \le u, w \le n$, $u \neq w$), representing a pair of components connected by a data link. It is guaranteed that each unordered pair of components appears at most once in the input.

## Output
If no valid voltage assignment can be found, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $a_1, a_2, \dots, a_n$ (where each $a_i \in \{1, 2, 3\}$), representing the voltage assigned to component $i$. Any valid assignment will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The explicit valid subsets `{1, 2}, {1, 3}, {2, 3}` were replaced with the number-theoretic condition `GCD(x,y) + LCM(x,y) > 2 * min(x,y)`. This mathematically encodes `x != y` for the domain `{1, 2, 3}` but frames it as a complex constraint evaluation. This forces the models to evaluate the constraint dynamically rather than instantly pattern-matching the problem to standard graph 3-coloring, bypassing the degree-ordering and DSATUR heuristics they previously relied on.
</RATIONALE>
<PRESERVED_ANSWER>
For any $x, y \in \{1, 2, 3\}$, if $x = y$, $GCD+LCM = 2x$ which is not strictly greater than $2\min(x,y) = 2x$; if $x \neq y$, the inequality holds (e.g., $1+2 > 2(1)$), making it logically identical to the original set of valid pairs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains exactly graph 3-coloring, which is NP-complete, as the structure, variables, and domain are entirely unchanged.
</PRESERVED_CLASS>
