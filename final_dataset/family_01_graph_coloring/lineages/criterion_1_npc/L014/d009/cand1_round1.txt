# Problem A — Grid Harmonic Resonance

Time limit: 2 s
Memory limit: 256 MB

You are deploying a computational grid consisting of $n$ processing nodes, labeled 1 through $n$. Your task is to configure the clock speed for each node. The available clock speed options for any node are 1, 2, and 3 GHz.

Certain pairs of nodes share a direct synchronization link. For any two linked nodes $u$ and $w$ assigned clock speeds $x$ and $y$ respectively (where $x$ is the speed of $u$ and $y$ is the speed of $w$), the synchronization controller calculates two integer diagnostic values for the link:
$V_u = x^2 \cdot (w \cdot x + u \cdot y) + y^2 \cdot (x^2 + y)$
$V_w = y^2 \cdot (u \cdot y + w \cdot x) + x^2 \cdot (y^2 + x)$

Due to hardware limitations, if $V_u$ and $V_w$ are exactly equal, the nodes will experience harmonic resonance and the link will fail. To ensure the grid is fully operational, every synchronization link must connect two nodes that do not experience harmonic resonance.

You are provided with the number of nodes and the exact pairs that share a synchronization link. You must output a fully functional clock speed assignment for the grid, or indicate if it is impossible.

## Input
The first line contains two integers $n$ and $m$ — the number of processing nodes and the number of synchronization links ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
Each of the following $m$ lines contains two distinct integers $u$ and $w$ ($1 \le u, w \le n$, $u \neq w$), representing a pair of nodes connected by a synchronization link. It is guaranteed that each unordered pair of nodes appears at most once in the input.

## Output
If no valid clock speed assignment can be found, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $a_1, a_2, \dots, a_n$ (where each $a_i \in \{1, 2, 3\}$), representing the clock speed assigned to node $i$. Any valid assignment will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

I replaced it with a cubic polynomial equality $V_u = V_w$ that perfectly reduces to $x = y$ for all positive integers $u, w$ and $x, y \in \{1, 2, 3\}$, but intertwines the node IDs and speeds so that $x$ does not divide away its own squared term. The mathematical difference $V_u - V_w$ factors to $(x-y)[wx(x+y) + uy(x+y) - (x^2+xy+y^2)]$, and since $u, w \ge 1$, the bracketed term is strictly positive for all $x, y \ge 1$, meaning $V_u = V_w$ if and only if $x = y$, keeping all valid assignments identical.
