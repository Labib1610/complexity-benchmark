We can brute-force all assignments since \( n \le 40 \) but \( 3^{40} \) is too large.  
However, we can use backtracking with pruning: assign speeds one by one and check constraints with already assigned neighbors.  

Let’s first simplify the resonance condition.  

Given:
\[
V_u = x^2 (w x + u y) + y^2 (x^2 + y)
\]
\[
V_w = y^2 (u y + w x) + x^2 (y^2 + x)
\]

We need \( V_u \neq V_w \).  
Let’s compute the difference:

\[
V_u - V_w = x^2 w x + x^2 u y + y^2 x^2 + y^3 - (y^2 u y + y^2 w x + x^2 y^2 + x^3)
\]
Simplify:
\[
= w x^3 + u x^2 y + x^2 y^2 + y^3 - u y^3 - w x y^2 - x^2 y^2 - x^3
\]
Cancel \( x^2 y^2 \):
\[
= w x^3 + u x^2 y + y^3 - u y^3 - w x y^2 - x^3
\]
Group:
\[
= (w x^3 - x^3) + (u x^2 y - w x y^2) + (y^3 - u y^3)
\]
\[
= x^3(w-1) + xy(ux - wy) + y^3(1-u)
\]

We need this ≠ 0.

Since \( x, y \in \{1,2,3\} \), we can precompute for each ordered pair \((x,y)\) whether it’s allowed for a given \((u,w)\).  
But \(u,w\) are node labels, so the condition depends on the labels.

We can precompute a boolean `ok[u][w][x][y]` for all \(u,w,x,y\) (n ≤ 40, so 40×40×3×3 is small).

Then backtracking with pruning works.

Let’s implement:

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    edges = []
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        w = int(next(it)) - 1
        edges.append((u, w))
        adj[u].append(w)
        adj[w].append(u)

    # Precompute allowed pairs
    # ok[u][w][x][y] = True if assigning x to u and y to w is fine
    ok = [[[[False]*3 for _ in range(3)] for _ in range(n)] for _ in range(n)]
    for u in range(n):
        for w in range(n):
            for x in range(1,4):
                for y in range(1,4):
                    diff = (x**3)*(w+1-1) + x*y*(u*x - w*y) + (y**3)*(1-u-1)  # wait, careful
                    # Actually use formula:
                    diff = (x**3)*(w-1) + x*y*(u*x - w*y) + (y**3)*(1-u)
                    ok[u][w][x-1][y-1] = (diff != 0)

    # Backtracking
    assign = [0]*n
    used = [False]*n

    def backtrack(idx):
        if idx == n:
            return True
        # Try speeds 1,2,3
        for sp in [1,2,3]:
            assign[idx] = sp
            good = True
            for nb in adj[idx]:
                if assign[nb] != 0:
                    if not ok[idx][nb][sp-1][assign[nb]-1]:
                        good = False
                        break
            if good:
                if backtrack(idx+1):
                    return True
        assign[idx] = 0
        return False

    if backtrack(0):
        print("YES")
        print(" ".join(str(x) for x in assign))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
