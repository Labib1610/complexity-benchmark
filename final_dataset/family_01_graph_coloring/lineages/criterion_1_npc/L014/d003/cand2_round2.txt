# Problem A — Circuit Power Rails

Time limit: 2 s
Memory limit: 256 MB

You are configuring a custom integrated circuit consisting of $n$ logic components, numbered 1 through $n$. You must assign each component to a power rail. There are exactly three power rails available, designated as 1, 2, and 3. 

The circuit contains data links between certain pairs of components. To prevent signal interference, any two components connected by a data link must draw from distinct power rails. 

Note that the test data includes configurations specifically structured such that evaluation approaches which process components in numerical order, or sort them solely by their number of connections, will explore too many invalid states.

You are given the total number of components and the specific pairs that are connected by data links. Determine a valid assignment for all $n$ components that ensures no interference occurs across any data link, or report that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$ — the number of logic components and the number of data links. The hardware chassis supports a maximum of 40 components, so $n$ is bounded between 1 and 40 inclusive. The layout may have no links at all (minimum 0), up to a fully saturated layout where every component links to every other component, capping $m$ at exactly $n \cdot (n-1)/2$.

Each of the following $m$ lines contains two integers $u$ and $w$, representing a pair of components connected by a data link. Since they represent valid components, both values are between 1 and $n$ inclusive, and they are always distinct ($u \neq w$). It is guaranteed that each unordered pair of components appears at most once in the input.

## Output
If no valid assignment can be found, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $a_1, a_2, \dots, a_n$ (where each $a_i \in \{1, 2, 3\}$), representing the power rail assigned to component $i$. Any valid assignment will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
