# Problem A — Grid Harmonic Resonance

Time limit: 2 s
Memory limit: 256 MB

You are configuring the operating frequencies for a computational grid. The grid contains $n$ processing units, sequentially identified by integers from 1 up to $n$. Each processing unit must be assigned a fixed operating frequency. The supported frequency levels for any unit are 1, 2, and 3 GHz.

The grid framework relies on direct synchronization channels established between specific pairs of units. When a channel connects unit $u$ (running at frequency $x$) and unit $w$ (running at frequency $y$), the system's diagnostic monitor evaluates their interference potential by computing two directional metrics:
$V_u = x \cdot ( u \cdot (x^2 + y^2) - 2 \cdot w \cdot y^2 )$
$V_w = y \cdot ( w \cdot (x^2 + y^2) - 2 \cdot u \cdot x^2 )$

A critical hardware constraint dictates that if the combined metric $V_u + V_w$ evaluates to exactly $0$, the channel will suffer from harmonic resonance, leading to an immediate connection drop. A stable grid requires that absolutely no synchronization channel experiences this resonance.

Given the total number of processing units and the layout of the synchronization channels, determine a safe frequency configuration for the entire grid, or report if no such configuration is possible.

## Input
The first line provides two integers $n$ and $m$ — the total number of processing units and the number of synchronization channels ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
Each of the subsequent $m$ lines contains two distinct integers $u$ and $w$ ($1 \le u, w \le n$, $u \neq w$), indicating that a synchronization channel exists between unit $u$ and unit $w$. Every unordered pair of connected units is listed at most once.

## Output
If it is impossible to assign frequencies without causing resonance, output a single line with `NO`.
Otherwise, output `YES` on the first line. On the next line, output $n$ space-separated integers $a_1, a_2, \dots, a_n$, where $a_i \in \{1, 2, 3\}$ represents the frequency assigned to unit $i$. Any valid configuration will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

</PRESERVED_ANSWER>
