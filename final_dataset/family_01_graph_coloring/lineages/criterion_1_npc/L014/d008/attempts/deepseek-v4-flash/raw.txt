We can brute-force all assignments since \( n \leq 40 \) and each node has only 3 possible speeds, but \( 3^{40} \) is too large.  
However, we can use backtracking with pruning, or reduce the problem to a 3-coloring-like constraint satisfaction.

Let’s first analyze the condition:

For an edge \((u, w)\) with speeds \(x\) and \(y\):

\[
V_u = (w \cdot x^2 + y) \bmod x
\]
\[
V_w = (u \cdot y^2 + x) \bmod y
\]

We need \(V_u \neq V_w\).

We can precompute for each possible speed pair \((x, y)\) whether it is allowed for a given edge \((u, w)\).  
Then we can do backtracking with forward checking.

Since \(n \leq 40\), backtracking with pruning should be fast enough.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    edges = []
    for _ in range(m):
        u, w = map(int, input().split())
        edges.append((u-1, w-1))
    
    # Precompute allowed speed pairs for each edge
    allowed = []
    for u, w in edges:
        ok = []
        for x in (1,2,3):
            for y in (1,2,3):
                vu = (w * x * x + y) % x
                vw = (u * y * y + x) % y
                if vu != vw:
                    ok.append((x,y))
        allowed.append(ok)
    
    # Backtracking
    assign = [0]*n
    # adjacency list
    adj = [[] for _ in range(n)]
    for idx, (u,w) in enumerate(edges):
        adj[u].append((w, idx))
        adj[w].append((u, idx))
    
    # order nodes by degree
    order = sorted(range(n), key=lambda i: -len(adj[i]))
    
    def backtrack(pos):
        if pos == n:
            return True
        node = order[pos]
        for speed in (1,2,3):
            assign[node] = speed
            valid = True
            for nb, eidx in adj[node]:
                if assign[nb] != 0:
                    # check edge constraint
                    u, w = edges[eidx]
                    if u == node:
                        x = speed
                        y = assign[nb]
                    else:
                        x = assign[nb]
                        y = speed
                    vu = (w * x * x + y) % x
                    vw = (u * y * y + x) % y
                    if vu == vw:
                        valid = False
                        break
            if valid:
                if backtrack(pos+1):
                    return True
            assign[node] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, assign)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
