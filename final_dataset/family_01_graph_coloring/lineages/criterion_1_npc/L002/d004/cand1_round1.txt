<STATEMENT>
# Quantum Oscillator Configuration

Time limit: 2 s   Memory limit: 256 MB

You are designing the configuration for a system of $n$ quantum oscillators. Each oscillator $i$ (for $1 \le i \le n$) must be assigned an energy state $E_i$ chosen from the set $\{1, 2, 3\}$.

The system must satisfy $m$ directional resonance conditions to remain stable. Each condition specifies a primary oscillator $u$ and a secondary oscillator $v$. To prevent signal reflection from $u$ to $v$, the characteristic transmission polynomial $P(x) = A x^2 + B x + C$ must have a strictly positive discriminant, where the coefficients are defined as:
- $A = E_u$
- $B = -(E_u^2 + E_v^2)$
- $C = E_u E_v^2$

Your task is to determine whether there exists at least one valid assignment of energy states to all $n$ oscillators that satisfies all $m$ resonance conditions simultaneously. The test suites include highly restrictive condition sets, meaning an unoptimized search may fail to complete within the time limit.

## Input
The first line contains two integers $n$ and $m$. The value of $n$ is at least 1 and at most the total number of slots in a standard $4 \times 10$ containment grid. The value of $m$ is at least 0 and at most the maximum possible number of distinct unordered pairs among the $n$ oscillators. 
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating a resonance condition where $u$ is the primary oscillator and $v$ is the secondary oscillator. 

## Output
If no such configuration is possible, output `NO` on a single line.
If a valid configuration exists, output `YES` on the first line. On the second line, output $n$ integers representing the sequence of energy states $E_1, E_2, \dots, E_n$. If there are multiple valid configurations, any of them will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The problem was reframed from a sequence validation task into a quantum oscillator configuration task to obscure its graph-coloring nature. The symmetric inequality constraint ($u \neq v$) was replaced with a mathematically equivalent but highly asymmetric algebraic condition: requiring a strictly positive discriminant for a specific quadratic polynomial. Models must now either algebraically simplify the discriminant to discover the hidden symmetry or implement it literally. In either case, the asymmetric presentation strongly discourages mapping the problem to an undirected graph, which is necessary to apply the total-degree vertex ordering heuristic that prevents Time Limit Exceeded (TLE) during backtracking. The bounds were also restated indirectly using physical dimensions ($4 \times 10$) following Strategy S07.
</RATIONALE>
