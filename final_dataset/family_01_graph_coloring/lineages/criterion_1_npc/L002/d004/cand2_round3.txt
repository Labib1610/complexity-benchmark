<METHOD_NAME>Algebraic Constraint Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Transforms the pairwise inequality constraint into a requirement that a quadratic equation formed by the two variables has distinct real roots, preventing models from easily recognizing it as a graph coloring problem.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Emitter Stability Verification

Time limit: 2 s   Memory limit: 256 MB

You are configuring a system of $n$ signal generators. Each generator must be assigned an integer power level $P[i]$ chosen from the set $\{1, 2, 3\}$.

The system contains $m$ interference constraints. Each constraint involves two generators $u$ and $v$ (1-based indices). For the constraint to remain stable, the combined signal of the two generators must satisfy a specific mathematical condition. 

Specifically, the combined signal forms the following quadratic equation:
$x^2 - (P[u] + P[v])x + P[u]P[v] = 0$

For the constraint to be stable, this equation must yield two strictly distinct real solutions for $x$. If the equation has a single repeated solution, the constraint destabilizes.

Your task is to determine whether there exists at least one assignment of power levels to all $n$ generators such that every interference constraint in the system is stable. The test suites include highly restrictive configuration sets, meaning naive left-to-right generation may fail to complete within the time limit.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). 
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating an interference constraint between the generator at index $u$ and the generator at index $v$. 

## Output
If no such configuration can be constructed, output `NO` on a single line.
If a valid configuration exists, output `YES` on the first line. On the second line, output $n$ integers representing the valid power levels $P[1], P[2], \dots, P[n]$. If there are multiple valid configurations, any of them will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the inequality constraint between two elements into an algebraic condition where a quadratic equation formed by their values must have two distinct real roots. This forces the model to algebraically deduce that $P[u] \neq P[v]$, breaking simple graph-coloring pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The distinct real roots condition for the quadratic equation $x^2 - (P[u]+P[v])x + P[u]P[v] = 0$ is exactly $(P[u]+P[v])^2 - 4P[u]P[v] > 0$, which simplifies to $(P[u]-P[v])^2 > 0$, meaning $P[u] \neq P[v]$, matching the exact original constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is mathematically identical to 3-coloring a graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might get confused by the phrasing "yield two strictly distinct real solutions for x", but it is a standard algebraic term.
</RISK>
