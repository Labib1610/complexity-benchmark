<STATEMENT>
# Sequence Configuration

Time limit: 2 s   Memory limit: 256 MB

You are tasked with generating an integer sequence $C$ of length $n$. Each element $C[i]$ in the sequence must be a strictly positive integer chosen such that the number of distinct ways to express it as the sum of two strictly positive integers (ignoring the order of the addends) is strictly less than 2. 

The sequence must satisfy $m$ conditions. Each condition is defined by a pair of 1-based indices $u$ and $v$. For the sequence to satisfy a given condition, the absolute difference between the elements at these two indices, $|C[u] - C[v]|$, must be an exact integer power of 2 (i.e., $2^p$ for some non-negative integer $p$).

Your objective is to determine if at least one such sequence $C$ can be constructed that satisfies all $m$ conditions simultaneously.

## Input
The first line contains two integers $n$ and $m$. It is guaranteed that $1 \le n \le K$, where $K$ is the smallest positive integer such that $K!$ ends in exactly 9 trailing zeros in base 10. The number of conditions $m$ satisfies $0 \le m \le n(n-1)/2$. 
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating a condition applied to the elements at index $u$ and index $v$. 

## Output
If no such sequence can be constructed, output `NO` on a single line.
If a valid sequence exists, output `YES` on the first line. On the second line, output $n$ integers representing the valid sequence $C[1], C[2], \dots, C[n]$. If there are multiple valid sequences, any of them will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The explicit domain `{1, 2, 3}` was replaced with a mathematical definition based on integer partitions, as only 1, 2, and 3 can be written as the sum of two positive integers in fewer than 2 ways. The constraint `gcd(C[u]!, C[v]!) < max(C[u], C[v])` was replaced with the condition that their absolute difference is a power of 2, which evaluating over the domain `{1, 2, 3}` exactly enforces `C[u] != C[v]`. The bound `n <= 40` was hidden behind a factorial trailing-zeros property (40! is the smallest factorial with 9 trailing zeros). This forces the model to genuinely evaluate the mathematical properties to recover the bounds and constraints rather than pattern-matching to graph coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The domain evaluates exactly to {1, 2, 3} and the absolute difference between any two distinct values in this set is either 1 or 2 (both powers of 2), while the difference between identical values is 0 (not a power of 2), meaning the conditions mathematically reduce to the exact same inequality as the seed problem.
</PRESERVED_ANSWER>
