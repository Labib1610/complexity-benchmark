# Problem A — Key Isolation

Time limit: 2 s   Memory limit: 256 MB

A secure distributed database holds $n$ sensitive data shards. To protect the system against partial breaches, every shard must be encrypted using exactly one of three available master keys. These keys are identified by the integers 1, 2, and 3.

A security audit has identified $m$ critical shard pairs. A critical pair consists of a shard $u$ and a shard $v$ which, if decrypted together, would expose personally identifiable information. The security policy mandates a strict separation of risk: if a single master key is compromised, no critical pair should be fully exposed. Consequently, for every identified critical pair involving shard $u$ and shard $v$, the two shards must be encrypted using strictly different master keys.

Determine if there is a valid key assignment for all $n$ data shards that satisfies every separation policy. If such an assignment is possible, output one valid configuration.

## Input
The first line contains two integers $n$ and $m$ — the number of data shards and the number of critical pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the following $m$ lines contains two integers $u$ and $v$ — the identifiers of two data shards that form a critical pair.

## Output
If no valid key assignment exists, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $k_1, k_2, \dots, k_n$ (each in $\{1, 2, 3\}$), where $k_i$ is the master key assigned to shard $i$. Any valid key assignment is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
