# Harmonic Containment

Time limit: 2 s   Memory limit: 256 MB

An engineering team is finalizing the setup of $n$ experimental energy cores. To function correctly, every core has to be tuned to exactly one of the available frequency bands. There is one band for each of the three primary colors of light, identified by the integers 1, 2, and 3.

The team has a log of $m$ hazardous resonance events from earlier trials. Each event specifies a pair of distinct cores, $u$ and $v$, that interfere with each other. If any two cores listed in an event are tuned to the identical frequency band, their resonance will cause a system failure. Therefore, to achieve a stable setup, any two cores that share a logged interference event must be assigned strictly different frequency bands.

The resonance logs are drawn from a comprehensive suite of stress tests. You should assume that the inputs include densely entangled worst-case scenarios specifically designed so that assigning bands by prioritizing cores with the highest number of interference events, or trying to evaluate states using bit-level operations, will result in an overwhelming number of dead ends. Your solution must be robust enough to handle these cases within the time limit.

Your task is to figure out whether all $n$ cores can be safely tuned. If a stable configuration is achievable, you must also output one valid assignment of bands to the cores.

## Input
The first line contains two integers $n$ and $m$. The number of cores $n$ is at least 1, and will not exceed the facility's maximum capacity of 8 storage racks that each hold exactly 5 cores. The number of events $m$ is at least 0, and is bounded above by the total number of unique pairs of cores. 
The following $m$ lines each contain two integers $u$ and $v$, representing the IDs of the two distinct interacting cores. Core IDs are integers starting from 1 up to $n$.

## Output
If it is impossible to safely tune all the cores, output a single line containing `NO`.
If a stable configuration exists, output `YES` on the first line. On the second line, output $n$ integers $p_1, p_2, \dots, p_n$, where $p_i \in \{1, 2, 3\}$ is the frequency band assigned to the $i$-th core. If there are multiple safe configurations, any of them will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
