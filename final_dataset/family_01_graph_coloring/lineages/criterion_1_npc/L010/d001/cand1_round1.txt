# Problem A — Tri-Phase Scheduling

Time limit: 2 s   Memory limit: 256 MB

A manufacturing plant needs to allocate its machinists into exactly three distinct maintenance phases, designated by the numbers 1, 2, and 3. Each machinist must be assigned to exactly one of these phases.

However, certain pairs of machinists have filed formal grievances against each other. To maintain a safe working environment, any two machinists who share a grievance must be placed in different maintenance phases.

The plant employs $n$ machinists, identified by integers from 1 to $n$. The facility requires at least one machinist on site, but has exactly 40 safety harnesses, capping the maximum number of machinists at 40. The HR department tracks $m$ grievance reports, which can range from a minimum of zero up to the theoretical maximum where every distinct pair of these $n$ machinists has filed a report.

Determine if it is possible to allocate every machinist to a maintenance phase without violating the safety rule. If it is possible, provide a valid allocation.

## Input
The first line contains two integers $n$ and $m$ — the number of machinists and the number of grievance reports. These values will always fall within the facility's limits described above.
Each of the next $m$ lines contains two integers $u$ and $v$ — representing a pair of machinists who have a grievance against each other.

## Output
If no valid allocation exists, print a single line NO.
Otherwise print YES on the first line. On the second line print $n$ integers $s_1, s_2, \ldots, s_n$ (each in $\{1, 2, 3\}$), where $s_i$ is the maintenance phase of machinist $i$. Any valid allocation is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
