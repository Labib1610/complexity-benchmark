# Problem A — Non-Zero Congruences

Time limit: 2 s   Memory limit: 256 MB

You are analyzing a system of $n$ variables, $x_1, x_2, \ldots, x_n$. Your task is to assign each variable an integer value from the set $\{1, 2, 3\}$.

The system is defined by $m$ constraints. Each constraint is provided as a pair of indices $u$ and $v$. For the assignment to be valid, every given pair must satisfy the condition that $x_u + 2x_v$ is not divisible by 3. 

Determine if there exists an assignment for all $n$ variables that satisfies all $m$ constraints simultaneously. 

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$) — the number of variables and the number of constraints.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing a constraint between the variables $x_u$ and $x_v$.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $v_1, v_2, \ldots, v_n$ (each in $\{1, 2, 3\}$), where $v_i$ is the value assigned to $x_i$. Any valid assignment is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
