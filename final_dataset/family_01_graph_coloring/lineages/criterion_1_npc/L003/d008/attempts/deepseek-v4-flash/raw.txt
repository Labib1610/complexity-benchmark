We need to check if we can assign values from {1, 2, 3} to vertices such that for every edge (u, v), the product of assigned values is not a perfect square.

First, note:
- 1×1 = 1 (perfect square) → forbidden
- 1×2 = 2 (not square) → allowed
- 1×3 = 3 (not square) → allowed
- 2×2 = 4 (perfect square) → forbidden
- 2×3 = 6 (not square) → allowed
- 3×3 = 9 (perfect square) → forbidden

So the only forbidden pairs are (1,1), (2,2), (3,3).  
That means: **No edge can have both endpoints with the same value.**

Thus the problem reduces to: Can we color the graph with 3 colors such that no two adjacent vertices share the same color?  
That’s exactly the 3-coloring problem.

Since n ≤ 40, we can use backtracking with pruning.

We'll implement a backtracking search:
- Assign colors 1, 2, 3 to vertices one by one.
- At each step, check that the color doesn't conflict with already colored neighbors.
- If we color all vertices, we output YES and the assignment.

If no assignment found, output NO.

Let's write the code.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n
    
    def backtrack(idx):
        if idx == n:
            return True
        # Try colors 1,2,3
        for c in (1, 2, 3):
            ok = True
            for nb in adj[idx]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[idx] = c
                if backtrack(idx + 1):
                    return True
                color[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
