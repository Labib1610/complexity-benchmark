# Acoustic Levitation Arrays

Time limit: 2 s   Memory limit: 256 MB

You are tasked with tuning an acoustic levitation array consisting of $n$ wave emitters. The acoustic chamber is equipped with a maximum of 40 mounting slots, so the number of emitters will never exceed this capacity. For the system to function, every emitter must be assigned an amplitude mode. The hardware allows exactly three distinct amplitude modes, identified by the numeric codes 1, 2, and 3.

Due to the geometry of the system, certain pairs of emitters project sound waves that converge at shared focal points. In total, there are $m$ such pairs. When a pair of emitters targets the same focal point, their acoustic waves create a thermal differential. 

For any two interacting emitters with assigned amplitude codes $c_u$ and $c_v$, the local heating factor at their shared focal point is calculated as the remainder when $c_u^3 + c_v^3$ is divided by 97. The local cooling factor is calculated as the remainder when $c_u^2 c_v + c_u c_v^2$ is divided by 97. The hardware safety threshold requires that the heating factor must strictly exceed the cooling factor. If this threshold is not met, the focal point undergoes sudden condensation, causing a localized pressure drop that destroys the levitated specimen. 

You must determine whether it is possible to assign a safe amplitude code to all $n$ emitters given the list of interacting pairs, such that the thermal threshold is satisfied for every shared focal point.

## Input
The first line contains two integers $n$ and $m$ — the number of emitters and the number of interacting emitter pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). Emitters are indexed from $1$ to $n$.
Each of the subsequent $m$ lines provides two integers $u$ and $v$ ($1 \le u, v \le n$), specifying that emitter $u$ and emitter $v$ share a focal point.

## Output
If a safe tuning is impossible, output a single line containing `NO`.
If a valid tuning exists, output `YES` on the first line. On the second line, output $n$ space-separated integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the amplitude code assigned to emitter $i$. Any valid array configuration will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
