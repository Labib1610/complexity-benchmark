# Acoustic Levitation Arrays

Time limit: 2 s   Memory limit: 256 MB

You are tasked with tuning an acoustic levitation array consisting of $n$ wave emitters. The acoustic chamber is equipped with a maximum of 40 mounting slots, so the number of emitters will never exceed this capacity. For the system to function, every emitter must be assigned a phase offset mode. The hardware allows exactly three distinct offset modes, identified by the numeric codes 1, 2, and 3.

Due to the geometry of the system, certain pairs of emitters project sound waves that converge at shared focal points. In total, there are $m$ such pairs. When a pair of emitters targets the same focal point, their projected waves superimpose. 

The wave equation for an emitter $u$ assigned offset code $p_u$ is given by:
$$W_u(t) = \sqrt{2} \cos\left(\omega t - p_u \frac{2\pi}{3}\right)$$
where $\omega > 0$ is the system's base frequency and $t$ represents time.

The acoustic power at a shared focal point between interacting emitters $u$ and $v$ is the time-averaged squared superposition of their waves:
$$P(u, v) = \lim_{T \to \infty} \frac{1}{T} \int_0^T \left(W_u(t) + W_v(t)\right)^2 dt$$

The hardware safety threshold dictates that the total acoustic power across all $m$ shared focal points must be exactly $m$. If the total power exceeds this value, localized pressure spikes will destroy the levitated specimen. 

You must determine whether it is possible to assign a safe phase offset code to all $n$ emitters given the list of interacting pairs, such that the total acoustic power satisfies the safety threshold.

## Input
The first line contains two integers $n$ and $m$ — the number of emitters and the number of interacting emitter pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). Emitters are indexed from $1$ to $n$.
Each of the subsequent $m$ lines provides two integers $u$ and $v$ ($1 \le u, v \le n$), specifying that emitter $u$ and emitter $v$ share a focal point.

## Output
If a safe tuning is impossible, output a single line containing NO.
If a valid tuning exists, output YES on the first line. On the second line, output $n$ space-separated integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the offset code assigned to emitter $i$. Any valid array configuration will be accepted.
