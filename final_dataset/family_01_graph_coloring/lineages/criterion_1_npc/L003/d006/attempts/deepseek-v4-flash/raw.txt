 We need to assign each emitter one of three values (1, 2, 3) such that for every edge (u, v), the 2×2 matrix  

\[
\begin{pmatrix}
x & y \\
y & x
\end{pmatrix}
\]  

has a non-zero determinant.  

The determinant is \(x^2 - y^2 = (x-y)(x+y)\).  
For it to be non-zero, we need \(x \neq y\) and \(x \neq -y\).  
Since values are 1, 2, 3, the only way \(x = -y\) is impossible (no negative values), so the condition reduces to \(x \neq y\).  

Thus, the problem is simply: can we 3-color the graph such that no two adjacent vertices have the same color?  
That’s always possible for any graph with 3 colors (since 3-coloring is always possible for any graph? Actually no, 3-coloring is NP-hard in general, but here we just need to check if it's possible; for n ≤ 40, we can use backtracking).  

We can implement a simple backtracking search.  

```python
n, m = map(int, input().split())
edges = [tuple(map(int, input().split())) for _ in range(m)]

adj = [[] for _ in range(n)]
for u, v in edges:
    adj[u-1].append(v-1)
    adj[v-1].append(u-1)

colors = [0] * n

def is_safe(node, c):
    for nb in adj[node]:
        if colors[nb] == c:
            return False
    return True

def solve(node):
    if node == n:
        return True
    for c in range(1, 4):
        if is_safe(node, c):
            colors[node] = c
            if solve(node + 1):
                return True
            colors[node] = 0
    return False

if solve(0):
    print("YES")
    print(" ".join(map(str, colors)))
else:
    print("NO")
```
