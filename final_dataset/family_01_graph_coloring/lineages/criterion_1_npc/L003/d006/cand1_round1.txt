# Acoustic Levitation Arrays

Time limit: 2 s   Memory limit: 256 MB

You are tasked with tuning an acoustic levitation array consisting of $n$ wave emitters. The acoustic chamber is equipped with a maximum of 40 mounting slots, so the number of emitters will never exceed this capacity. For the system to function, every emitter must be assigned a phase offset mode. The hardware allows exactly three distinct offset modes, identified by the numeric codes 1, 2, and 3.

Due to the geometry of the system, certain pairs of emitters project sound waves that converge at shared focal points. In total, there are $m$ such pairs. When a pair of emitters targets the same focal point, their acoustic outputs interact.

The hardware safety threshold requires that for any two emitters sharing a focal point, the interference pattern must not create resonant feedback. Specifically, if the two interacting emitters are assigned offset modes $x$ and $y$, their acoustic interference is modeled by the localized resonance matrix:

$$ R = \begin{pmatrix} x & y \\ y & x \end{pmatrix} $$

To maintain stability, the matrix $R$ must have full rank (meaning its determinant must be strictly non-zero). If this condition is not met, the focal point experiences a localized pressure spike that destroys the levitated specimen.

You must determine whether it is possible to assign a safe phase offset mode to all $n$ emitters given the list of interacting pairs, such that the resonant feedback condition is satisfied for every shared focal point.

## Input
The first line contains two integers $n$ and $m$ — the number of emitters and the number of interacting emitter pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). Emitters are indexed from $1$ to $n$.
Each of the subsequent $m$ lines provides two integers $u$ and $v$ ($1 \le u, v \le n$), specifying that emitter $u$ and emitter $v$ share a focal point. Every listed pair represents a strict interference constraint.

## Output
If a safe tuning is impossible, output a single line containing NO.
If a valid tuning exists, output YES on the first line. On the second line, output $n$ space-separated integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the offset mode assigned to emitter $i$. Any valid array configuration will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I removed the coprimality affordance that models used to trivially map the problem to graph 3-coloring. Instead, I introduced a matrix determinant condition that mathematically evaluates to the same inequality constraint but requires algebraic reasoning to simplify, disrupting surface-level pattern matching. (The prompt's suggestion to require all 3 modes was rejected because it would change the valid outputs for 2-colorable graphs, violating the hard constraint of identical answers).
</RATIONALE>
<PRESERVED_ANSWER>
The determinant of the resonance matrix is mathematically $x^2 - y^2$, which is non-zero if and only if $x \neq y$ (since the modes are strictly positive integers), making the valid configurations exactly identical to the seed problem.
</PRESERVED_ANSWER>

The core logic remains equivalent to assigning one of three values to nodes such that no adjacent nodes share the same value, preserving the NP-complete 3-coloring structure.
</PRESERVED_CLASS>
