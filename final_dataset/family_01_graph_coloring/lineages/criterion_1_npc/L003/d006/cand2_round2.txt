# Acoustic Levitation Arrays

Time limit: 2 s   Memory limit: 256 MB

You are tasked with tuning an acoustic levitation array consisting of $n$ wave emitters. The acoustic chamber is equipped with a maximum of 40 mounting slots, so the number of emitters will never exceed this capacity. For the system to function, every emitter must be assigned a phase offset mode. The hardware allows exactly three distinct offset modes, identified by the numeric codes 1, 2, and 3.

Due to the geometry of the system, certain pairs of emitters project sound waves that converge at shared focal points. In total, there are $m$ such interacting pairs. When a pair of emitters targets the same focal point, their acoustic outputs interact.

The hardware safety threshold requires that for any two emitters sharing a focal point, the interference pattern must not create resonant feedback. To maintain stability, the interaction requires a strict phase differential. Specifically, for every listed pair of interacting emitters, their assigned offset modes must be such that one mode is strictly greater than the other. If this condition is not met, the focal point experiences a localized pressure spike that destabilizes the system.

You must determine whether it is possible to assign a safe phase offset mode to all $n$ emitters given the list of interacting pairs, such that the strict phase differential condition is satisfied for every shared focal point.

## Input
The first line contains two integers $n$ and $m$ — the number of emitters and the number of interacting emitter pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). Emitters are indexed from $1$ to $n$.
Each of the subsequent $m$ lines provides two distinct integers $u$ and $v$ ($1 \le u, v \le n$), specifying that emitter $u$ and emitter $v$ share a focal point. Every listed line represents exactly one strict interference constraint, and no interacting pair is listed more than once.

## Output
If a safe tuning is impossible, output a single line containing NO.
If a valid tuning exists, output YES on the first line. On the second line, output $n$ space-separated integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the offset mode assigned to emitter $i$. Any valid array configuration will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I replaced the complex coprimality formula with a direct rule, as requested by the expert critique. However, to maintain difficulty, I framed the "not equal" constraint as requiring "one mode to be strictly greater than the other". This mathematically perfectly enforces $x \neq y$ for undirected pairs, but uses vocabulary that often triggers LLMs to overcomplicate the state space with edge directions or partial orders, disrupting their standard graph 3-coloring templates.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that "one mode is strictly greater than the other" for two integers is mathematically identical to requiring that the two integers are not equal, which perfectly matches the seed's coprimality condition for modes 1, 2, and 3.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Graph 3-Coloring, which is NP-complete, because assigning 3 values such that endpoints of every edge are distinct is the definition of 3-coloring.
</PRESERVED_CLASS>
<RISK>
Models might interpret "one mode is strictly greater than the other" as requiring a specific emitter (e.g., the first one listed) to be greater, though the phrasing "one mode" rather than "the first mode" is standard English for an undirected property.
</RISK>
