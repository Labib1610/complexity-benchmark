We need to assign each emitter one of three codes (1, 2, 3) such that for every edge (u, v), the 2×2 matrix  

```
[ code_u  code_v ]
[   1       1    ]
```

has a nonzero determinant.  

The determinant is:  
`code_u * 1 - code_v * 1 = code_u - code_v`.  

So the condition is simply:  
**For every edge (u, v), code_u ≠ code_v.**  

That means we need to 3-color the graph. Since n ≤ 40, we can use backtracking with pruning.  

We can also check if the graph is bipartite — if it is, 2 colors suffice, but 3 colors always work if the graph is 3-colorable.  

We’ll implement a backtracking search with constraint propagation.  

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    colors = [0] * n  # 0 = uncolored, 1,2,3 = colors
    
    # Sort vertices by degree for better pruning
    order = sorted(range(n), key=lambda x: len(adj[x]), reverse=True)
    
    def backtrack(idx):
        if idx == n:
            return True
        v = order[idx]
        used = [False] * 4
        for nb in adj[v]:
            if colors[nb] != 0:
                used[colors[nb]] = True
        for c in range(1, 4):
            if not used[c]:
                colors[v] = c
                if backtrack(idx + 1):
                    return True
                colors[v] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(str(colors[i]) for i in range(n)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
