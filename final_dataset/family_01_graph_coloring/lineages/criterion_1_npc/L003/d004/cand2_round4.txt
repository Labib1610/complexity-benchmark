<METHOD_NAME>Floor Ratio Asymmetry</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the determinant-based inequality check with a non-linear algebraic condition involving floor division ($\lfloor p_u / p_v \rfloor \neq \lfloor p_v / p_u \rfloor$). This obscures the simple $p_u \neq p_v$ logic. While mathematically equivalent over the domain {1,2,3}, it prevents pattern-matching models from immediately identifying the problem as Graph 3-Coloring, forcing them to deduce the equivalence or evaluate the condition dynamically, which can disrupt standard graph-heuristic applications like degree-sorting.</METHOD_DESCRIPTION>

<STATEMENT>
# Acoustic Levitation Arrays

Time limit: 2 s   Memory limit: 256 MB

You are tasked with tuning an acoustic levitation array consisting of $n$ wave emitters. The acoustic chamber is equipped with a maximum of 40 mounting slots, so the number of emitters will never exceed this capacity. For the system to function, every emitter must be assigned a phase offset. The hardware allows exactly three distinct offset modes, identified by the numeric codes 1, 2, and 3.

Due to the geometry of the system, certain pairs of emitters project sound waves that converge at shared focal points. In total, there are $m$ such pairs. When a pair of emitters targets the same focal point, their acoustic outputs interact. 

To prevent a destructive resonance cascade at a shared focal point, the offset codes $p_u$ and $p_v$ assigned to the two interacting emitters must satisfy the following algebraic asymmetry condition:

$$ \lfloor p_u / p_v \rfloor \neq \lfloor p_v / p_u \rfloor $$

where $\lfloor x \rfloor$ denotes the greatest integer less than or equal to $x$. If this condition is violated for any pair of emitters sharing a focal point, the waves resonate perfectly, causing a localized pressure spike that destroys the levitated specimen.

You must determine whether it is possible to assign a safe phase offset code to all $n$ emitters given the list of interacting pairs.

## Input
The first line contains two integers $n$ and $m$ — the number of emitters and the number of interacting emitter pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). Emitters are indexed from $1$ to $n$.
Each of the subsequent $m$ lines provides two distinct integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), specifying that emitter $u$ and emitter $v$ share a focal point. Each interacting pair of distinct emitters is listed at most once, and the order of the emitters in a pair does not matter.

## Output
If a safe tuning is impossible, output a single line containing NO.
If a valid tuning exists, output YES on the first line. On the second line, output $n$ space-separated integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the offset code assigned to emitter $i$. Any valid array configuration will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The problem replaces the explicit matrix determinant condition (which trivially evaluated to $p_u \neq p_v$) with an algebraically obfuscated floor division condition. Over the domain $\{1, 2, 3\}$, $\lfloor p_u / p_v \rfloor \neq \lfloor p_v / p_u \rfloor$ is strictly equivalent to $p_u \neq p_v$. This forces models to either symbolically deduce the equivalence or dynamically evaluate the constraint during search. This obscures the underlying Graph 3-Coloring structure, making models less likely to apply critical heuristics like degree-ordered backtracking. Additionally, the input contract has been tightened to explicitly enforce simple graph semantics (distinct endpoints, no duplicate pairs), addressing previous ambiguity.
</RATIONALE>
<PRESERVED_ANSWER>
For any two codes chosen from {1, 2, 3}, the floor ratio condition is false if the codes are identical and true if they are distinct, preserving the exact same valid configurations as the original matrix determinant rule.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Graph 3-Coloring, as the core constraint still requires assigning one of three available states to each node such that no two adjacent nodes share the same state.
</PRESERVED_CLASS>
