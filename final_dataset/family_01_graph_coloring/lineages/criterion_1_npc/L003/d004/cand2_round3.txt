# Acoustic Levitation Arrays

Time limit: 2 s   Memory limit: 256 MB

You are tasked with tuning an acoustic levitation array consisting of $n$ wave emitters. The acoustic chamber is equipped with a maximum of 40 mounting slots, so the number of emitters will never exceed this capacity. For the system to function, every emitter must be assigned a phase offset. The hardware allows exactly three distinct offset modes, identified by the numeric codes 1, 2, and 3.

Due to the spatial configuration of the chamber, specific pairs of emitters form interference links. You are provided with a list of $m$ such links. 

For each interference link between emitter $u$ and emitter $v$, their acoustic outputs interact. The safety of this interaction is evaluated by the hardware's asymmetric scaling logic. Specifically, the system calculates $q_1 = \lfloor p_u / p_v \rfloor$ and $q_2 = \lfloor p_v / p_u \rfloor$, where $p_u$ and $p_v$ are the numeric offset codes assigned to the two emitters, and $\lfloor x \rfloor$ denotes the greatest integer less than or equal to $x$.

If $q_1$ and $q_2$ are exactly equal, the waves resonate symmetrically and the interference becomes perfectly constructive. This causes a localized pressure spike that destroys the levitated specimen. Therefore, for the system to operate safely, it is required that $q_1 \neq q_2$ for the codes assigned to any two emitters connected by an interference link.

You must determine whether it is possible to assign a safe phase offset code to all $n$ emitters given the list of interference links.

## Input
The first line contains two integers $n$ and $m$ — the number of emitters and the number of interference links ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). Emitters are indexed from $1$ to $n$.
Each of the subsequent $m$ lines provides two integers $u$ and $v$ ($1 \le u, v \le n$), specifying an interference link between emitter $u$ and emitter $v$.

## Output
If a safe tuning is impossible, output a single line containing NO.
If a valid tuning exists, output YES on the first line. On the second line, output $n$ space-separated integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the offset code assigned to emitter $i$. Any valid array configuration will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I changed the interference condition from a matrix determinant to an asymmetric integer division check. This mathematically encodes the exact same distinctness requirement but masks the standard graph 3-coloring formulation. By removing the linear algebra hint, models are forced to process the constraint literally, which makes them less likely to recognize the problem as a graph and apply the degree-ordered backtracking heuristic necessary to pass within the time limit.
</RATIONALE>
<PRESERVED_ANSWER>
For any two codes from {1, 2, 3}, the condition ⌊pu / pv⌋ ≠ ⌊pv / pu⌋ is satisfied if and only if pu ≠ pv, which is exactly the same requirement as the original determinant condition, ensuring all valid and invalid configurations remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Graph 3-Coloring, which is NP-complete, as the variables, domain size, and pairwise inequality constraints are mathematically unchanged.
</PRESERVED_CLASS>
