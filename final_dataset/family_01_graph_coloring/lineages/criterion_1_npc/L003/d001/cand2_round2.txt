# Signal Interference Avoidance

Time limit: 2 s   Memory limit: 256 MB

You are configuring a network of $n$ autonomous sensor modules. Each module must be assigned a transmission signature vector to broadcast its telemetry. The hardware supports exactly three signature vectors, which are specified by the configuration codes 1, 2, and 3:
- Code 1 corresponds to vector $(1, 0, 0)$
- Code 2 corresponds to vector $(0, 1, 0)$
- Code 3 corresponds to vector $(0, 0, 1)$

The physical environment dictates that $m$ specific pairs of modules share a localized communication channel. When two modules share a channel, their signals interact. If the dot product of their assigned signature vectors is strictly greater than zero, the resulting cross-talk will corrupt the channel. To ensure reliable communication, for any two modules that share a channel, the dot product of their signature vectors must evaluate to exactly zero.

Given the list of module pairs that share a channel, determine if there is a valid signature configuration for all $n$ modules.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of modules and the number of shared channels.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that module $u$ and module $v$ share a channel.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES on the first line. On the second line print $n$ integers $p_1, p_2, \dots, p_n$ (each in $\{1, 2, 3\}$), where $p_i$ is the configuration code for module $i$. If there are multiple valid configurations, any of them is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The problem was rewritten to disguise the graph coloring structure by mapping "distinct colors" to "orthogonal vectors". By requiring the dot product of assigned signature vectors to be exactly zero, models must deduce that adjacent modules require different configuration codes, preventing simple keyword-based recognition of 3-coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The dot product of any two standard basis vectors is zero if and only if they are distinct, meaning the condition exactly enforces that connected modules have different configuration codes, keeping all valid assignments identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to 3-coloring on an undirected graph with up to 40 vertices, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the dot product condition if they fail to map the configuration codes to their corresponding vectors, though the definition of each vector is explicitly provided.
</RISK>
