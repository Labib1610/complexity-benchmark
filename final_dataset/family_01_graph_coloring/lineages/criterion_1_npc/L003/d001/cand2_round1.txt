<STATEMENT>
# Harmonic Interference Mitigation

Time limit: 2 s   Memory limit: 256 MB

You are calibrating a set of $n$ acoustic levitation emitters inside a testing chamber. Each emitter requires a dedicated cooling channel. The chamber's thermal manifold provides exactly 40 such channels, which physically limits the maximum number of emitters present. At least one emitter is always tested.

Each emitter must be programmed with a specific phase configuration code. The system uses a standard 2-bit unsigned register for this configuration, but the value 0 is strictly reserved for hardware diagnostics. Therefore, the available operational codes are the remaining integer values representable in this register.

Due to the internal geometry of the chamber, $m$ specific pairs of emitters have overlapping focal points. The total number of overlapping pairs, $m$, can be anywhere from zero up to the maximum possible number of distinct pairs among the $n$ emitters. When two emitters share a focal point, their acoustic fields interact. If both are programmed with the exact same phase configuration code, their waves will perfectly synchronize, causing a localized pressure spike that shatters the levitated sample. To maintain safe and stable levitation, any two emitters that share a focal point must operate using different configuration codes.

Given the pairs of emitters that share a focal point, determine if there is a valid configuration for all $n$ emitters.

## Input
The first line contains two integers $n$ and $m$ — the number of emitters and the number of overlapping focal point pairs. The bounds on $n$ and $m$ are as dictated by the physical limits described above.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that emitter $u$ and emitter $v$ share a focal point.

## Output
If no safe configuration exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $p_1, p_2, \dots, p_n$, where $p_i$ is the phase configuration code for emitter $i$. If there are multiple valid configurations, any of them is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
