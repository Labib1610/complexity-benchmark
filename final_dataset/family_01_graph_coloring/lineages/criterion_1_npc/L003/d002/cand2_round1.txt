<STATEMENT>
# Gravity-Fed Irrigation Network

Time limit: 2 s   Memory limit: 256 MB

You are designing a gravity-fed irrigation network for a terraced hillside. The network consists of $n$ distribution basins. Each basin must be installed at one of three specific elevation tiers, represented by the codes 1, 2, and 3.

The basins are connected by $m$ aqueducts. An aqueduct allows water to flow between the two basins it connects, provided there is an elevation drop. To prevent water from stagnating, every aqueduct must have an elevation drop across it. This means that for any aqueduct connecting two basins, one of those basins must be assigned to a strictly higher elevation tier than the other. The overall direction of flow throughout the network does not matter; the only requirement is that no individual aqueduct is stagnant.

Given the list of basin pairs connected by aqueducts, determine if there is a valid elevation tier assignment for all $n$ basins.

## Input
The first line contains two integers $n$ and $m$ — the number of distribution basins and the number of aqueducts ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that basin $u$ and basin $v$ are connected by an aqueduct.

## Output
If no valid elevation assignment exists, print a single line NO.
Otherwise print YES on the first line. On the second line print $n$ integers $t_1, t_2, \dots, t_n$ (each in $\{1, 2, 3\}$), where $t_i$ is the elevation tier code for basin $i$. If there are multiple valid assignments, any of them is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was completely reframed from an acoustic levitation scenario with an algebraic constraint (product is not a perfect square) to a gravity-fed irrigation network with an ordinal constraint (strictly higher elevation tier). This removes the algebraic and coloring keywords that models previously used to pattern-match the problem. To succeed, the model must now deduce that the requirement for one basin to be "strictly higher" than an adjacent basin, when restricted to a set of 3 possible values, is logically identical to requiring the values to be unequal, which is exactly graph 3-coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that one basin's tier is strictly higher than the other's ensures the two connected basins have unequal values, exactly matching the seed problem's constraint that the product of values in {1, 2, 3} is not a perfect square (which also evaluates to true if and only if the values are unequal).
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains a direct formulation of Graph 3-Coloring, preserving its NP-complete status.
</PRESERVED_CLASS>
<RISK>
A model might incorrectly assume that the water must flow in a valid global direction (e.g., from basin 1 to basin $n$), but the statement explicitly clarifies that "The overall direction of flow throughout the network does not matter," mitigating this risk.
</RISK>
