<METHOD_DESCRIPTION>Replaces the easily recognizable "product is a perfect square" rule with a mathematically equivalent modular arithmetic condition: $(p^2+q^2) \equiv 2pq \pmod 3$. This evaluates to $p=q$ for $p,q \in \{1,2,3\}$, but obscures the 3-coloring reduction by requiring algebraic simplification or truth-table generation, breaking the surface-level pattern match.</METHOD_DESCRIPTION>

<STATEMENT>
# Antenna Alignment

Time limit: 2 s   Memory limit: 256 MB

You are tasked with configuring a network of $n$ communication antennas. Every antenna in the network requires exactly one operational mode, which must be selected from the numeric codes 1, 2, and 3.

The terrain contains $m$ direct line-of-sight links between specific pairs of antennas. When two antennas share a line-of-sight link, their transmitted signals interact. The network's safety controller evaluates two diagnostic metrics for each link based on the modes assigned to its two endpoints:
1. The sum of the squares of the two modes.
2. Twice the product of the two modes.

If these two metrics leave the exact same remainder when divided by 3, the interaction produces a destructive standing wave that destabilizes the network. To guarantee reliable communication, you must ensure that for every line-of-sight link, the two antennas' operational codes do not trigger this destructive condition.

Your objective is to determine if there exists a complete assignment of operational modes to all $n$ antennas that avoids creating any destructive standing waves across the $m$ specified links.

## Input
The first line contains two integers $n$ and $m$ — the number of antennas and the number of line-of-sight links ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). The antennas are indexed from $1$ to $n$.
Each of the subsequent $m$ lines provides two distinct integers $u$ and $v$ ($1 \le u, v \le n$), indicating that antenna $u$ and antenna $v$ share a direct line-of-sight link. Each pair represents a strict standing wave constraint.

## Output
If a safe configuration is impossible, output a single line containing `NO`.
If a valid configuration exists, output `YES` on the first line. On the second line, output $n$ space-separated integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the operational mode assigned to antenna $i$. Any valid configuration will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I replaced the "product is a perfect square" condition with a modular arithmetic condition checking if $(p^2+q^2)$ and $2pq$ leave the same remainder modulo 3. This removes the explicit phrasing that models previously mapped directly to graph 3-coloring, forcing them to either perform algebraic deduction or evaluate the constraint dynamically to discover the underlying structure.
</RATIONALE>
<PRESERVED_ANSWER>
The new condition $(p^2+q^2) \equiv 2pq \pmod 3$ simplifies algebraically to $(p-q)^2 \equiv 0 \pmod 3$, which for $p, q \in \{1, 2, 3\}$ holds if and only if $p=q$; thus the forbidden mode pairs are still exactly the identical pairs, keeping all valid configurations unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains perfectly isomorphic to Graph 3-Coloring, as it still requires assigning one of 3 states to each vertex such that no two adjacent vertices share the same state, maintaining its NP-complete status.
</PRESERVED_CLASS>
