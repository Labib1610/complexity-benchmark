**Solution Explanation**

For every edge `(u,v)`

```
interference = 6   if colour[u] == colour[v]
interference = -3  otherwise
```

The required total interference is `-3·m`.  
If `k` edges have equal colours, the total interference equals  

```
k·6 + (m‑k)·(-3) = -3·m + 9·k .
```

Only `k = 0` gives `-3·m`, therefore **all edges must join vertices
with different colours**.
So we have to colour the given undirected graph with three colours
such that adjacent vertices obtain different colours – the classical
*3‑colourability* problem.

`n ≤ 40`, therefore a back‑tracking search with good heuristics is fast
enough.



--------------------------------------------------------------------

#### 1.  Data structures
* `adj[v]` – list of neighbours of vertex `v` (0‑based indices)
* `colour[v]` – `0` = not coloured yet, otherwise `1…3`

--------------------------------------------------------------------

#### 2.  Search order – MRV heuristic  

During the depth‑first search we always colour the *uncoloured* vertex
with the **fewest currently possible colours** (minimum remaining
values).  
For a vertex `v` the forbidden colours are the colours already used by
its coloured neighbours.  
If a vertex has no possible colour the current partial assignment is
invalid and we backtrack immediately.

The heuristic dramatically cuts the search tree.

--------------------------------------------------------------------

#### 3.  Symmetry breaking  

The three colours are interchangeable.
We fix colour `1` for vertex `0` before the search starts – this removes
the factor `3!` of equivalent solutions and does not affect existence.

--------------------------------------------------------------------

#### 4.  Recursive routine  

```
dfs(coloured_cnt):
        if coloured_cnt == n            -> success
        choose uncoloured vertex v with the smallest number of possible colours
        for each possible colour c of v:
                colour[v] = c
                if dfs(coloured_cnt+1)  -> success
                colour[v] = 0           # backtrack
        return failure
```

The recursion depth is at most `n (=40)`.

--------------------------------------------------------------------

#### 5.  Correctness Proof  

We prove that the algorithm prints `"YES"` and a correct colouring
iff such a colouring exists.

---

##### Lemma 1  
During the search, a vertex is coloured only with a colour that differs
from all already coloured neighbours.

**Proof.**  
Before assigning a colour to a vertex `v` we compute the set of colours
used by its coloured neighbours and *exclude* them.
Only the remaining colours are tried. ∎



##### Lemma 2  
If the algorithm reaches the line `if coloured_cnt == n` then the current
assignment is a proper 3‑colouring of the whole graph.

**Proof.**  
All `n` vertices are coloured. By Lemma&nbsp;1 every coloured vertex differs
from each of its coloured neighbours.
Since at that moment *all* neighbours are coloured, every edge connects
vertices of different colours. ∎



##### Lemma 3  
If the algorithm returns *failure* for a recursive call,
then **no** proper 3‑colouring exists that extends the current partial
assignment.

**Proof.**  
The call fails only after having tried **all** possible colours for the
chosen vertex `v` and each trial led to a recursive failure.
For each tried colour `c` the recursive call attempted to complete the
colouring under the invariant that `v` has colour `c` and all previously
coloured vertices keep their colours.
By the induction hypothesis (recursion depth is smaller) each of those
calls fails exactly when no completion exists with that fixed colour.
Consequently no colour of `v` can be extended to a full colouring, i.e.
no proper colouring extends the current partial assignment. ∎



##### Lemma 4  
If a proper 3‑colouring of the whole graph exists, the algorithm eventually
finds it and returns success.

**Proof.**  
Consider any correct colouring `C`.  
The algorithm fixes colour `1` for vertex `0`, which is also possible in
`C` after a suitable permutation of the colour names (the colours are
symmetrical).  
Induction on the number of coloured vertices:

*Base.* Zero coloured vertices – trivially true.  

*Induction step.*  
Assume the algorithm has already coloured a set `S` exactly as in `C`.
Let `v` be the next vertex the algorithm chooses.
All colours of already coloured neighbours of `v` are the same in the
algorithm and in `C`; therefore the colour `C(v)` is still allowed for
`v`.  
When the algorithm tries colours, it will eventually try `C(v)`.
The recursive call then has a partial colouring identical to `C` on
`S ∪ {v}` and the induction hypothesis applies.
Thus the branch following colour `C(v)` reaches success. ∎



##### Lemma 5  
If the algorithm prints `"YES"` and a colour array, the array satisfies
the required interference condition `-3·m`.

**Proof.**  
By Lemma&nbsp;2 the printed array is a proper 3‑colouring,
hence every edge connects vertices of different colours.
Each edge contributes `-3`, so the total contribution is `-3·m`. ∎



##### Lemma 6  
If the algorithm prints `"NO"` then no proper 3‑colouring of the graph
exists.

**Proof.**  
The algorithm prints `"NO"` only after the initial call to `dfs`
fails.  
The initial call started with vertex 0 coloured `1`; any proper colouring
can be renumbered so that vertex 0 receives colour 1.
Hence, by Lemma&nbsp;3, the failure of this call means that no proper
colouring extends this fixed colour, i.e. no proper colouring exists at
all. ∎



---

##### Theorem  
The program outputs  

* `"YES"` and a suitable assignment *iff* such an assignment exists,  

* otherwise `"NO"`.

**Proof.**  
*If* part: existence ⇒ algorithm finds it (Lemma 4) ⇒ prints `"YES"` and
the assignment satisfies the condition (Lemma 5).  

*Only‑if* part: algorithm prints `"YES"` ⇒ assignment is proper ⇒ satisfies
the condition, so a suitable assignment exists.  

If algorithm prints `"NO"` ⇒ by Lemma 6 no proper 3‑colouring exists,
hence no assignment with total interference `-3·m` exists. ∎



--------------------------------------------------------------------

#### 6.  Complexity Analysis  

`n ≤ 40`.

*Choosing a vertex* scans all vertices → `O(n)` .  
*Computing possible colours* scans its adjacency list – at most `n-1`.  

One recursion step therefore costs `O(n²)` in the worst case,
but `n` is only 40, so the constant work is tiny.

The algorithm explores only a tiny fraction of the `3ⁿ` possibilities
thanks to MRV and early dead‑end detection.
For all inputs fitting the limits it runs well within the 2 seconds
time limit.

Memory consumption: adjacency lists (`O(n+m) ≤ 800` integers) and a few
arrays of size `n` – well below the 256 MB limit.



--------------------------------------------------------------------

#### 7.  Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    colour = [0] * n

    if n > 0:
        colour[0] = 1                       # symmetry breaking

    # depth‑first search with MRV heuristic
    def dfs(coloured_cnt: int) -> bool:
        if coloured_cnt == n:
            return True

        best_v = -1
        best_opts = None

        # select vertex with minimum number of allowed colours
        for v in range(n):
            if colour[v] != 0:
                continue
            used = 0
            for nb in adj[v]:
                c = colour[nb]
                if c:
                    used |= 1 << c
            opts = []
            for col in (1, 2, 3):
                if not (used >> col) & 1:
                    opts.append(col)
            if not opts:          # dead end
                return False
            if best_v == -1 or len(opts) < len(best_opts):
                best_v = v
                best_opts = opts
                if len(opts) == 1:
                    break

        for col in best_opts:
            colour[best_v] = col
            if dfs(coloured_cnt + 1):
                return True
            colour[best_v] = 0
        return False

    possible = dfs(1 if n > 0 else 0)

    out = []
    if possible:
        out.append("YES")
        out.append(" ".join(str(colour[i]) for i in range(n)))
    else:
        out.append("NO")
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
