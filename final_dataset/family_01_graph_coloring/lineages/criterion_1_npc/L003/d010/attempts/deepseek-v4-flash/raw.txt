 We need to assign each antenna a mode (1, 2, or 3) such that the sum over all edges of the interference values equals exactly \(-3m\).

The interference table is:

- Same mode: \(6\)
- Different modes: \(-3\)

So for each edge:
- If the two endpoints have the same mode, contribution is \(+6\).
- If different, contribution is \(-3\).

Let’s denote:
- \(s\) = number of edges with same mode
- \(d\) = number of edges with different modes

We have \(s + d = m\).

Total interference = \(6s - 3d = 6s - 3(m - s) = 6s - 3m + 3s = 9s - 3m\).

We want this to equal \(-3m\):

\[
9s - 3m = -3m \implies 9s = 0 \implies s = 0
\]

So we need **no edge** to have the same mode on both endpoints. That means the graph must be 3-colorable (proper coloring with 3 colors).

Thus the problem reduces to:  
Check if the graph is 3-colorable. If yes, output a valid 3-coloring. If not, output "NO".

We can solve this with backtracking since \(n \leq 40\), but 3-coloring is NP-hard in general. However, with \(n=40\) and 3 colors, backtracking with pruning is feasible for typical cases, but worst-case could be heavy. Still, we can implement a simple backtracking with forward checking.

Let's implement:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    
    def is_safe(node, c):
        for nb in adj[node]:
            if color[nb] == c:
                return False
        return True
    
    def backtrack(node):
        if node == n:
            return True
        # Try colors 0,1,2
        for c in range(3):
            if is_safe(node, c):
                color[node] = c
                if backtrack(node + 1):
                    return True
                color[node] = -1
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(str(c + 1) for c in color))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
