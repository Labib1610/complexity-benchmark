# Problem A — Cycle Scheduling

Time limit: 2 s
Memory limit: 256 MB

A facility coordinates a roster of $n$ personnel. Every person on the roster must be allocated exactly one operational cycle from the options $\{1, 2, 3\}$. However, certain pairs of personnel are incompatible and cannot be allocated the same operational cycle. 

You must determine an allocation for all personnel such that no two incompatible individuals share the same cycle. If no such allocation can be made, you must report that it is impossible. 

The documented conflicts can form any arbitrary arrangement. The test data includes configurations specifically structured so that many partial allocations remain valid until the very last personnel are evaluated.

## Input
The first line contains two integers $n$ and $m$, representing the headcount of personnel and the tally of incompatible pairs. The headcount $n$ is constrained by a minimum of 1 and a facility capacity of 40. The tally $m$ ranges from a minimum of 0 up to a maximum of $n(n-1)/2$, which represents the scenario where every individual is incompatible with everyone else.
Each of the following $m$ lines contains two integers $u$ and $v$ — indicating that person $u$ and person $v$ are incompatible.

## Output
If no valid allocation exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (each in $\{1, 2, 3\}$), where $c_i$ is the operational cycle allocated to person $i$. Any valid allocation is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
