We can model this as a graph coloring problem with 3 colors, but with constraints based on the product of the states.

First, let’s decode the classification string `XOOXCOCCX`:

Index: 1 2 3 4 5 6 7 8 9  
Char:  X O O X C O C C X  

So:
- Product 1 → 'X' → forbidden
- Product 2 → 'O' → allowed
- Product 3 → 'O' → allowed
- Product 4 → 'X' → forbidden
- Product 5 → 'C' → allowed
- Product 6 → 'O' → allowed
- Product 7 → 'C' → allowed
- Product 8 → 'C' → allowed
- Product 9 → 'X' → forbidden

Forbidden products: 1, 4, 9.  
Allowed products: 2, 3, 5, 6, 7, 8.

Now, states are 1, 2, 3.  
Forbidden pairs (u,v) mean:
- s_u * s_v ≠ 1 → cannot both be 1
- s_u * s_v ≠ 4 → cannot be (2,2)
- s_u * s_v ≠ 9 → cannot be (3,3)

So the only forbidden combinations are:
- (1,1)
- (2,2)
- (3,3)

That means: **No two connected nodes can have the same state.**

So the problem reduces to: Can we 3-color the graph such that adjacent nodes have different colors?  
That’s exactly the 3-coloring problem, which is NP-complete in general, but n ≤ 40, so we can use backtracking with pruning.

We’ll implement a backtracking search with constraint propagation.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    
    # Check if we can color with backtracking
    def dfs(node):
        if node == n:
            return True
        # Try colors 1,2,3
        for c in (1,2,3):
            ok = True
            for nb in adj[node]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[node] = c
                if dfs(node + 1):
                    return True
                color[node] = -1
        return False
    
    if dfs(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
