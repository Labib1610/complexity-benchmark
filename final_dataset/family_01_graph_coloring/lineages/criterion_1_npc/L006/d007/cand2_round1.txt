<STATEMENT>
# Problem A — Quantum Interference

Time limit: 2 s
Memory limit: 256 MB

You are tuning a network of $n$ quantum resonators. Each resonator must be assigned a discrete energy state, which must be exactly 1, 2, or 3.

The network is tested under $m$ coupling conditions. Each condition involves a specific pair of resonators. When a pair of resonators $u$ and $v$ are coupled, they generate an interference pattern based on the product of their assigned states, $p = s_u \cdot s_v$.

The specific pattern generated is determined by looking up the $p$-th character of the classification string `XOOXCOCCX` (1-indexed, so the 1st character is 'X' and the 2nd is 'O'). 

To avoid destructive feedback and achieve stable network resonance, absolutely no coupled pair in the network may produce an 'X' pattern. 

Your task is to determine whether it is possible to assign an energy state $s_i \in \{1, 2, 3\}$ to every resonator $i$ (from $1$ to $n$) such that the network achieves stable resonance. If it is possible, provide a valid assignment.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of resonators and the number of coupled pairs.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing that resonator $u$ and resonator $v$ are coupled. It is guaranteed that each unordered pair $\{u, v\}$ appears at most once in the input.

## Output
If there is no valid assignment, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$, where each $s_i \in \{1, 2, 3\}$ is the energy state assigned to resonator $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the algebraic energy formula and the global target sum with a discrete string-index classification based on the product of the two states. This removes the "formula-target cancellation" affordance where models minimized a polynomial to deduce the inequality constraint. Models must now genuinely trace the string lookups for the possible state products to discover that the 'X' pattern corresponds exactly to equal states, thereby recognizing the graph coloring structure.
</RATIONALE>
<PRESERVED_ANSWER>
The string 'XOOXCOCCX' has 'X' exactly at indices 1, 4, and 9, meaning a coupled pair produces an 'X' if and only if their states are equal, so a valid assignment is identical to the seed's requirement of no equal adjacent states.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to graph 3-coloring, which is NP-complete.
</PRESERVED_CLASS>
