<STATEMENT>
# Problem A — Frequency Allocation

Time limit: 2 s   Memory limit: 256 MB

A secure facility is evaluating a batch of $n$ encrypted data shards. The facility's containment grid consists of 8 rows of 5 isolation bays each. The number of shards $n$ will never exceed the total number of these bays, and there is always at least a single shard to evaluate.

To successfully process the data, each shard must be configured to operate on a designated frequency band. The hardware supports a primary, secondary, and tertiary frequency band, identified respectively by the integers 1, 2, and 3. 

During preliminary analysis, the facility identified $m$ pairs of shards that exhibit harmonic interference. The number of such pairs $m$ can be as low as zero, and cannot exceed the total number of unique two-shard combinations that can be formed from the batch. If both shards in any interfering pair are configured to operate on the identical frequency band, the system will trigger a security fault and halt.

Your task is to determine whether it is possible to configure a frequency band for each of the $n$ shards such that no security faults are triggered. If it is possible, provide a valid configuration for all shards.

## Input
The first line contains two integers $n$ and $m$ — the number of data shards and the number of interfering pairs. The limits for $n$ and $m$ are dictated by the containment grid capacity and the maximum possible number of unique pairs, as described above.
Each of the following $m$ lines contains two integers $u$ and $v$, representing that shard $u$ and shard $v$ exhibit harmonic interference. Shards are identified by integers starting from $1$ up to $n$. An interference pair always consists of two distinct shards.

## Output
If there is no way to configure the frequency bands without triggering a security fault, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $p_1, p_2, \dots, p_n$, where each $p_i$ is the frequency band (1, 2, or 3) configured for shard $i$. If multiple valid configurations exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
