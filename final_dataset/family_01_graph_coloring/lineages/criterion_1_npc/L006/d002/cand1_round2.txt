# Problem A — Frequency Separation

Time limit: 2 s
Memory limit: 256 MB

A communications array consists of $n$ transmitters. Each transmitter must be configured to operate on exactly one frequency channel. The available channels are designated by the integers 1, 2, and 3.

The array is subject to $m$ interference constraints. Each constraint specifies a pair of transmitters that are in close physical proximity. To prevent signal degradation, the absolute difference between the channel numbers assigned to the two transmitters in any proximity pair must be at least 1.

Your task is to determine whether it is possible to configure the channels for all $n$ transmitters such that all interference constraints are satisfied. If it is possible, provide a valid channel configuration.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of transmitters and the number of proximity pairs.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing that transmitter $u$ and transmitter $v$ form a proximity pair. It is guaranteed that each unordered pair $\{u, v\}$ appears at most once in the input.

## Output
If there is no valid channel configuration, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $c_1, c_2, \dots, c_n$, where each $c_i \in \{1, 2, 3\}$ is the channel assigned to transmitter $i$. If multiple valid configurations exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
