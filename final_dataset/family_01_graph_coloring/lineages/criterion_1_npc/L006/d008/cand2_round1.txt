<METHOD_NAME>Matrix Transformation Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit inequality/forbidden product list with a 2D rotation-scaling matrix transformation. The condition requires that the 4th power of the matrix applied to a basis vector does not lie on the x-axis. Mathematically, this evaluates to the imaginary part of (s_u + i s_v)^4 being non-zero, which simplifies to s_u != s_v. This prevents LLMs from immediately recognizing the problem as Graph 3-Coloring, thereby bypassing their optimized DSATUR/degree-sorting heuristics and forcing naive backtracking to time out.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Quantum Interference

Time limit: 2 s
Memory limit: 256 MB

You are tuning a network of $n$ quantum resonators. Each resonator must be assigned a discrete energy state, which must be exactly 1, 2, or 3.

The network is tested under $m$ coupling conditions. Each condition involves a specific pair of resonators. When a pair of resonators $u$ and $v$ are coupled, their assigned states induce a local phase transformation. This transformation is represented by the $2 \times 2$ matrix:
$$M_{u,v} = \begin{pmatrix} s_u & -s_v \\ s_v & s_u \end{pmatrix}$$

To ensure the network achieves stable resonance and avoids destructive feedback, the phase shift must not collapse into a purely real state after four iterations. Specifically, if you apply the transformation matrix $M_{u,v}$ exactly 4 times to the basis vector $\begin{pmatrix} 1 \\ 0 \end{pmatrix}$, the resulting vector must not lie on the horizontal axis. In other words, the second coordinate (the y-component) of the vector $M_{u,v}^4 \begin{pmatrix} 1 \\ 0 \end{pmatrix}$ must be strictly non-zero.

Your task is to determine whether it is possible to assign an energy state $s_i \in \{1, 2, 3\}$ to every resonator $i$ (from $1$ to $n$) such that all $m$ coupling conditions result in stable resonance. If it is possible, provide a valid assignment.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of resonators and the number of coupled pairs.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing that resonator $u$ and resonator $v$ are coupled. It is guaranteed that each unordered pair $\{u, v\}$ appears at most once in the input.

## Output
If there is no valid assignment, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$, where each $s_i \in \{1, 2, 3\}$ is the energy state assigned to resonator $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I changed the explicit forbidden product mapping (which LLMs easily simplified to a graph coloring inequality) into a matrix transformation condition. The requirement that the y-component of $M^4 \begin{pmatrix} 1 \\ 0 \end{pmatrix}$ is non-zero mathematically evaluates to $4s_u s_v (s_u^2 - s_v^2) \neq 0$, which simplifies to $s_u \neq s_v$. This forces the model to either blindly implement the matrix math and time out using naive backtracking, or perform a deep algebraic/geometric deduction to recognize the graph coloring structure required to trigger its optimized DSATUR heuristics.
</RATIONALE>
<PRESERVED_ANSWER>
The matrix condition is mathematically equivalent to $s_u \neq s_v$ for strictly positive integers, meaning the set of valid assignments is exactly the same as in the original 3-coloring problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Graph 3-Coloring on a graph of up to 40 vertices, which is NP-complete.
</PRESERVED_CLASS>
