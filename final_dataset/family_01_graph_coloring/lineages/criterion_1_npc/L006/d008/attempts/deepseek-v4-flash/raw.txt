We can first check which pairs of states are forbidden.  
The condition is:

\[
s_u^3 + s_v^3 \equiv s_u^2 s_v + s_u s_v^2 \pmod 7
\]

Let’s test all pairs from {1,2,3}:

- (1,1): 1+1=2, 1+1=2 → allowed  
- (1,2): 1+8=9≡2, 1*2+1*4=2+4=6 → 2≠6 → allowed  
- (1,3): 1+27=28≡0, 1*3+1*9=3+9=12≡5 → allowed  
- (2,2): 8+8=16≡2, 4*2+4*2=8+8=16≡2 → forbidden  
- (2,3): 8+27=35≡0, 4*3+8*3=12+24=36≡1 → allowed  
- (3,3): 27+27=54≡5, 9*3+9*3=27+27=54≡5 → forbidden  

So forbidden pairs are (2,2) and (3,3).  
That means:  
- State 2 cannot be adjacent to state 2.  
- State 3 cannot be adjacent to state 3.  
State 1 can be adjacent to anything.

Thus the problem reduces to:  
We have a graph, assign each vertex a value in {1,2,3} such that no edge connects two vertices both with value 2, and no edge connects two vertices both with value 3.

This is equivalent to:  
- Vertices with value 2 form an independent set.  
- Vertices with value 3 form an independent set.  
- Vertices with value 1 can be anywhere.

We can solve by trying all assignments of 1/2/3 for n ≤ 40? That’s 3^40 too large.  
But we can use backtracking with pruning, or reduce to 2-coloring after fixing which vertices are 1.

Better:  
We can try all subsets for value 2 (independent set), then the rest must be colored with 1 or 3 such that no two 3’s are adjacent. That’s equivalent to: the remaining graph must be bipartite (2-colorable with colors 1 and 3).  

So algorithm:  
- Enumerate all independent sets for value 2 (max 2^40 too large).  
But n ≤ 40, we can use meet-in-the-middle or backtracking with pruning.

Given constraints, a simple backtracking with pruning works:  
- Assign states one by one, check constraints with already assigned neighbors.  
- Use symmetry: state 1 is “neutral”, so we can try to assign 1 first for unassigned nodes if possible.

We can also do:  
- Try all possibilities for nodes with degree > 0? Still large.

Better:  
We can use a SAT-like backtracking:  
- For each node, try 1, 2, 3, but prune if conflict.  
- With n=40, worst-case might be large, but constraints are small enough for backtracking with ordering (most constrained first).

Let’s implement backtracking with MRV (minimum remaining values) heuristic.

```python
import sys

sys.setrecursionlimit(10000)

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    # forbidden pairs: (2,2) and (3,3)
    # state 1 is compatible with all
    
    assignment = [0] * n  # 0 = unassigned
    
    # Precompute degree for ordering
    degree = [len(adj[i]) for i in range(n)]
    
    def is_valid(node, val):
        for nb in adj[node]:
            if assignment[nb] != 0:
                if assignment[nb] == val and val in (2,3):
                    return False
        return True
    
    # MRV: pick unassigned with fewest possible values
    def select_unassigned():
        best = -1
        best_count = 4
        for i in range(n):
            if assignment[i] == 0:
                cnt = 0
                for v in (1,2,3):
                    if is_valid(i, v):
                        cnt += 1
                if cnt < best_count:
                    best_count = cnt
                    best = i
                    if cnt == 0:
                        break
        return best
    
    def backtrack():
        node = select_unassigned()
        if node == -1:
            return True
        # try values in order 1,2,3
        for val in (1,2,3):
            if is_valid(node, val):
                assignment[node] = val
                if backtrack():
                    return True
                assignment[node] = 0
        return False
    
    if backtrack():
        print("YES")
        print(" ".join(str(x) for x in assignment))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
