We can simplify the energy formula first.  
For states in {1,2,3}, the possible differences are -2,-1,0,1,2.  
Compute E for each difference:

- d=0: 5(0)^4 - 25(0)^2 + 13 =  ​13
- d=±1: 5(1)^4 - 25(1)^2 + 13 =  ​5 - 25 + 13 = -7
- d=±2: 5(16) - 25(4) +  ​13 =  ​80 - 100 +  ​13 = -7

So E = 13 if states equal, and -7 if states differ.  
Total energy = 13 * (#equal edges) + (-7) * (#different edges).  
Let m = total edges. If k = #equal edges, then #different = m - k.  
Total = 13k - 7(m - k) =  ​20k - 7m.  
We need total = -7m → 20k - 7m = -7m → 20k =  ​0 → k =  ​0.  

So we need **no edge** with equal states. That means every coupled pair must have different states.  
Thus the problem reduces to: can we 3-color the graph such that adjacent vertices have different colors, using colors {1,2,3}?  
n ≤ 40, m up to complete. This is graph 3-coloring, which is NP-hard in general, but n=40 small enough for backtracking with pruning.

We can implement a recursive backtracking with degree ordering and constraint propagation.  
Since n ≤ 40, worst-case complete graph is easy (impossible quickly), but sparse graphs may need search. We'll use DSATUR-style heuristic: choose uncolored vertex with most colored neighbors (ties by degree), assign smallest possible color, backtrack if none.

Implementation plan:
- Build adjacency list.

- colors array: 0 = uncolored, else 1..3.
- Recursive function: find vertex with max number of colored neighbors (and max degree as tiebreaker). If all colored → success.
- For each color 1..3 not used by any colored neighbor, assign and recurse. If success return true.
- Backtrack.

This should handle n=40 within time for typical cases.  
We also need to output assignment if found.

import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -=  ​1
        v -=  ​1
        adj[u].append(v)
        adj[v].append(u)

    color = [0] * n

    # Precompute degrees for tie-breaking
    deg = [len(adj[i]) for i in range(n)]

    def backtrack():
        # Find uncolored vertex with most colored neighbors
        best = -1
        best_score = -1
        best_deg = -1
        for i in range(n):
            if color[i] == 0:
                cnt =  ​0
                for nb in adj[i]:

                        cnt +=  ​1
                if cnt > best_score or (cnt == best_score and deg[i] > best_deg):

                    best_deg = deg[i]
                    best = i

            return True

            if color[nb] != 0:
                used[color[nb]] = True

        for c in range(1, 4):
            if not used[c]:
                color[best] = c
                if backtrack():
                    return True
                color[best] =  ​0
        return False

    if backtrack():

if __name__ == "__main__":
