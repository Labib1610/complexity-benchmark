<STATEMENT>
# Problem A — Harmonic Resonance

Time limit: 2 s
Memory limit: 256 MB

You are configuring a network of $n$ signal emitters. Each emitter must be tuned to a phase state $s_i$, which must be exactly 1, 2, or 3.

The network is tested under $m$ interference conditions. Each condition involves a specific pair of emitters. When a pair of emitters $u$ and $v$ interact, their assigned phase states determine the formation of directed transmission channels. 

Specifically, for each interacting pair $u$ and $v$:
- A directed channel forms from $u$ to $v$ if $s_u^3 + s_v \le s_v s_u^2 + s_u$.
- A directed channel forms from $v$ to $u$ if $s_v^3 + s_u \le s_u s_v^2 + s_v$.
(If both inequalities hold, channels form in both directions simultaneously).

To avoid destructive structural feedback, the resulting network of transmission channels must never form any directed cycles (a path of one or more channels that starts and ends at the same emitter, following the direction of the channels).

Your task is to determine whether it is possible to assign a phase state $s_i \in \{1, 2, 3\}$ to every emitter $i$ (from $1$ to $n$) such that the network contains no directed cycles among the $m$ specified interacting pairs. If it is possible, provide a valid assignment.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of emitters and the number of interacting pairs.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing that emitter $u$ and emitter $v$ interact. It is guaranteed that each unordered pair $\{u, v\}$ appears at most once in the input.

## Output
If there is no valid assignment, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$, where each $s_i \in \{1, 2, 3\}$ is the phase state assigned to emitter $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The divisibility rule in the seed problem trivially revealed that equal values form 2-cycles (since any number divides itself), allowing models to easily map the problem to undirected 3-coloring and apply powerful heuristics like DSATUR. By replacing the edge formation rule with a mathematically equivalent polynomial inequality, the underlying undirected graph structure is completely obfuscated, forcing models to treat it as a directed cycle-detection problem which will likely TLE.
</RATIONALE>
<PRESERVED_ANSWER>
The polynomial inequality evaluates to exactly $s_u \le s_v$ for $s_u, s_v \in \{1, 2, 3\}$, which forms 2-cycles for equal values and a strict DAG for unequal values; thus, directed cycles exist if and only if two interacting emitters share the same state, exactly matching the valid assignments of the seed.
</PRESERVED_ANSWER>

The problem remains exactly equivalent to proper 3-coloring on the interaction graph, maintaining its NP-complete complexity.
