<METHOD_NAME>Polynomial Energy Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the discrete "not equal" conflict rule with a continuous-looking global polynomial energy minimization. The expanded polynomial mathematically evaluates to 0 when states differ and 4 when they match, perfectly encoding graph coloring without using any discrete logic. Framing it as a global sum prevents the LLM from triggering its graph-coloring templates (like DSATUR), forcing it to either use naive backtracking (which will TLE) or perform complex algebraic factorization to rediscover the underlying structure.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Grid Synchronization Energy

Time limit: 2 s
Memory limit: 256 MB

An energy system consists of $n$ components. Each component must be assigned a phase state, which is an integer $c_i \in \{1, 2, 3\}$.

The system is subject to $m$ pairwise interactions. Each interaction couples a specific pair of components. For any assignment of phase states, the *interaction energy* between a coupled pair of components $u$ and $v$ is governed by the polynomial:
$$E(u, v) = c_u^4 + c_v^4 - 4c_u^3 c_v - 4c_u c_v^3 + 6c_u^2 c_v^2 - 5c_u^2 - 5c_v^2 + 10c_u c_v + 4$$

The *total system energy* is the sum of the interaction energies across all $m$ interactions. To achieve a stable resonance, the total system energy must be exactly $0$.

Your task is to determine whether it is possible to assign a phase state to all $n$ components such that the total system energy is exactly $0$. If it is possible, provide a valid phase state assignment.

## Input
The first line contains two integers $n$ and $m$. The number of components $n$ is a positive integer; its maximum possible value is determined by the chassis capacity, which is designed such that a fully connected network at maximum capacity would contain exactly $780$ unique interactions. The number of interactions $m$ is a non-negative integer, bounded above by the maximum number of unique pairs possible for the given $n$ components.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing an interaction between component $u$ and component $v$. It is guaranteed that each unordered pair $\{u, v\}$ appears at most once in the input.

## Output
If there is no valid phase state assignment, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $c_1, c_2, \dots, c_n$, where each $c_i \in \{1, 2, 3\}$ is the phase state assigned to component $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the direct "different proposals" rule with a global polynomial energy sum. The polynomial is the expansion of `(c_u - c_v)^4 - 5(c_u - c_v)^2 + 4`, which evaluates to 0 if the states differ and 4 if they are the same. This forces the model to either algebraically factor the polynomial to rediscover the graph coloring structure, or implement naive backtracking which will time out without DSATUR optimizations.
</RATIONALE>
<PRESERVED_ANSWER>
For values in {1, 2, 3}, the polynomial yields exactly 0 when the values differ and 4 when they match, meaning a total energy of 0 requires all coupled components to have different states, perfectly matching the original conflict rules.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to deciding 3-coloring on a given graph, preserving its NP-complete status.
</PRESERVED_CLASS>
<RISK>
A reader might incorrectly assume that negative interaction energies could cancel out positive ones to reach exactly 0, though mathematically the polynomial's minimum value over the discrete domain {1, 2, 3} is exactly 0.
</RISK>
