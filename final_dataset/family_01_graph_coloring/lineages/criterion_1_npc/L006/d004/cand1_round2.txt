<STATEMENT>
# Problem A — Culture Incubation

Time limit: 2 s
Memory limit: 256 MB

A biological research facility is cultivating $n$ bacterial strains. Each strain must be placed into exactly one of three incubation environments, identified by the integers 1, 2, and 3.

The researchers have documented $m$ cross-contamination risks. Each risk involves a specific pair of strains that produce hostile enzymes when metabolizing similar nutrients. To ensure culture viability, any two strains involved in a documented risk must be placed such that one strain is assigned an environment with a strictly higher identifier than the other. 

Your task is to determine whether it is possible to assign environments to all $n$ strains such that all cross-contamination risks are mitigated. If it is possible, provide a valid environment assignment.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of strains and the number of cross-contamination risks.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing that strain $u$ and strain $v$ form a documented risk pair. It is guaranteed that each unordered pair $\{u, v\}$ appears at most once in the input.

## Output
If there is no valid environment assignment, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $c_1, c_2, \dots, c_n$, where each $c_i \in \{1, 2, 3\}$ is the environment assigned to strain $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
Replaced the explicit "different proposals" condition with the mathematically equivalent but structurally deceptive requirement that "one strain is assigned an environment with a strictly higher identifier than the other." This forces the model to deduce that an undirected strict inequality between two variables is simply a non-equality constraint, preventing surface-level pattern matching to graph 3-coloring templates.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that one identifier must be strictly higher than the other is mathematically identical to stating the two identifiers cannot be equal, preserving all valid assignments exactly as in the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Graph 3-Coloring, as it asks to assign each vertex one of three values such that no two adjacent vertices share the same value.
</PRESERVED_CLASS>
<RISK>
A reader might overthink the phrase "one strain" and wonder if the input order dictates which strain must be higher, though the phrase "unordered pair" in the input description clarifies that the relationship is symmetric.
</RISK>
