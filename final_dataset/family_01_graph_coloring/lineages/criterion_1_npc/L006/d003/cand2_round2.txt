# Problem A — Protocol Separation

Time limit: 2 s
Memory limit: 256 MB

A chemical processing plant consists of $n$ reaction tanks. Each tank must be configured to operate under exactly one safety protocol. The available protocols are designated by the integers 1, 2, and 3.

The plant is subject to $m$ thermal proximity constraints. Each constraint specifies a pair of tanks that share a heat exchange valve. To prevent a resonant thermal loop, the protocols assigned to the two tanks in any proximity pair must be strictly incompatible with each other. Two assigned protocols are considered incompatible if and only if the absolute difference between their designated integers is at least 1.

Your task is to determine whether it is possible to configure the safety protocols for all $n$ tanks such that all thermal proximity constraints are satisfied. If it is possible, provide a valid protocol configuration.

## Input
The first line contains two integers $n$ and $m$. The plant's containment building has a strict physical limit of 40 tank slots, meaning the total number of tanks $n$ is between 1 and 40 inclusive. The number of constraints $m$ can be as low as 0 and as high as the scenario where every tank shares a valve with every other tank, which corresponds to exactly $n(n-1)/2$ constraints.

Each of the following $m$ lines contains two integers $u$ and $v$. These represent that tank $u$ and tank $v$ form a proximity pair. Given the physical layout, $u$ and $v$ are valid tank IDs between 1 and $n$ inclusive, a tank never shares a valve with itself ($u \neq v$), and it is guaranteed that each unordered pair $\{u, v\}$ appears at most once in the input.

## Output
If there is no valid protocol configuration, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $c_1, c_2, \dots, c_n$, where each $c_i \in \{1, 2, 3\}$ is the protocol assigned to tank $i$. If multiple valid configurations exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
