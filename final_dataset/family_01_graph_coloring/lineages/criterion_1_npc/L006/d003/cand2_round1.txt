# Problem A — Frequency Separation

Time limit: 2 s
Memory limit: 256 MB

A communications array is installed on a hardware rack that contains exactly 40 mounting slots. The array consists of a positive number of transmitters, $n$, which cannot exceed the rack's total slot capacity. 

Each transmitter must be configured to operate in a specific polarization mode. The available modes are designated by the integers 1, 2, and 3.

The array is subject to $m$ interference constraints. The number of constraints $m$ can range from zero up to the theoretical maximum where every possible unordered pair among the $n$ transmitters forms a proximity pair. Each constraint specifies two transmitters that are in close physical proximity. 

To prevent signal degradation, the two transmitters in any proximity pair must not establish a standing wave. A standing wave forms if and only if both transmitters are configured with the exact same polarization mode. Therefore, to ensure safe operation, the mode integer assigned to one transmitter in a proximity pair must always be different from the mode integer assigned to the other.

Your task is to determine whether it is possible to configure the polarization modes for all $n$ transmitters such that no standing waves form. If it is possible, provide a valid configuration.

## Input
The first line contains two integers $n$ and $m$ — the number of transmitters and the number of proximity pairs.
Each of the following $m$ lines contains two integers $u$ and $v$. These represent the 1-based indices of the transmitters forming a proximity pair. A transmitter cannot be paired with itself, and it is guaranteed that each unordered pair $\{u, v\}$ appears at most once in the input.

## Output
If there is no valid configuration that avoids all standing waves, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $c_1, c_2, \dots, c_n$, where each $c_i$ is the polarization mode (1, 2, or 3) assigned to transmitter $i$. If multiple valid configurations exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
