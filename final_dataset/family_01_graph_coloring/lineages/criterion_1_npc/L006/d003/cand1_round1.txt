# Problem A — Frequency Separation

Time limit: 2 s
Memory limit: 256 MB

An installation of $n$ radio transmitters requires configuration. Every transmitter must be tuned to a single operational frequency band. The allowed bands are identified by the numeric codes 1, 2, and 3.

The installation has $m$ spatial restrictions. Each restriction lists two transmitters situated close to each other. To avoid mutual interference, the tuning must ensure that for any restricted pair, the product of their two frequency codes is never a perfect square.

Determine if a tuning arrangement exists for all $n$ transmitters that respects every spatial restriction. If such an arrangement is possible, produce one valid assignment.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$), indicating the total number of transmitters and the number of restricted pairs.
The next $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), showing that transmitter $u$ and transmitter $v$ are subject to a spatial restriction. Every unordered pair $\{u, v\}$ is listed at most once.

## Output
If no valid tuning arrangement can be found, print `NO` on a single line.
If a valid tuning is possible, print `YES` on the first line. On the following line, print $n$ integers $c_1, c_2, \dots, c_n$, where $c_i \in \{1, 2, 3\}$ is the frequency code for transmitter $i$. Any valid arrangement is acceptable if more than one exists.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The affordance triggering standard graph-coloring heuristics (like DSATUR) was the explicit "absolute difference must be at least 1" condition, which easily maps to inequality. I replaced this with the mathematically equivalent condition that "the product of their two frequency codes is never a perfect square." Models relying on surface pattern matching will fail to recognize the exact 3-coloring equivalence and thus fail to retrieve their specialized coloring templates, forcing them to reason through the constraint manually.
</RATIONALE>
<PRESERVED_ANSWER>
For values restricted to {1, 2, 3}, the product of two values is a perfect square (1, 4, or 9) if and only if the two values are identical, making the new constraint logically identical to the original inequality constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to graph 3-coloring, keeping it firmly in NP-Complete.
</PRESERVED_CLASS>
