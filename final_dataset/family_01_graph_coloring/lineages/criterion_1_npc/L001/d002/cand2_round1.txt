# Problem A — Artifact Exhibition

Time limit: 2 s   Memory limit: 256 MB

A museum is preparing an exhibition featuring $n$ historical artifacts. The exhibition space is divided into three distinct display areas, numbered 1, 2, and 3.

Due to conflicting historical narratives, specific pairs of artifacts cannot be shown in the same display area. Every artifact must be assigned to exactly one of the three areas such that no conflicting pair ends up in the same area. The museum is permitted to leave areas completely empty, as long as all $n$ artifacts are placed and no conflicts are violated. If no such arrangement exists, it must be reported.

## Input
The first line specifies two integers $n$ and $m$ — the number of artifacts and the number of conflicting pairs, respectively ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the subsequent $m$ lines provides two integers $u$ and $v$, indicating a pair of artifacts that share a historical conflict.

## Output
If there is no way to arrange the artifacts without conflicts, output a single line containing NO.
Otherwise, output YES on the first line. On the second line, output $n$ integers $z_1, z_2, \dots, z_n$ (where each $z_i \in \{1, 2, 3\}$), with $z_i$ denoting the display area for artifact $i$. If multiple valid arrangements exist, you must output the one that produces the lexicographically smallest sequence of area numbers.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the explicit permission to output any valid allocation with a requirement to output the lexicographically smallest valid allocation. This prevents models from using a heuristic bitmask backtracking search that terminates upon finding the first valid arrangement (often using a descending-degree artifact ordering), forcing them to systematically search for the lexicographically smallest assignment.
</RATIONALE>
<PRESERVED_ANSWER>
The reference solution already implements lexicographically-smallest backtracking, so it will continue to produce exactly the same outputs under this explicitly stated requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Determining whether a valid 3-coloring exists is NP-complete, and finding the lexicographically smallest one is equally NP-hard, preserving the fundamental complexity class.
</PRESERVED_CLASS>
