# Problem A — Reactive Storage

Time limit: 2 s   Memory limit: 256 MB

A chemical plant operates three distinct containment units, designated as 1, 2, and 3. You are tasked with processing $n$ different chemical substances. Due to safety regulations, certain pairs of these substances are highly volatile when mixed and must be strictly kept apart in different containment units.

Your objective is to allocate each of the $n$ substances to exactly one of the three available containment units. The allocation is considered safe if no two volatile substances are placed in the same unit. Note that it is not mandatory to use all three units; some units may remain completely empty if no substances are allocated to them. Determine if a safe allocation is achievable, and if so, provide one.

## Input
The first line contains two integers $n$ and $m$ — the number of chemical substances and the number of volatile pairs ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
Each of the following $m$ lines contains two integers $u$ and $v$, indicating that substance $u$ and substance $v$ are volatile when mixed and cannot share a containment unit.

## Output
If a safe allocation is unachievable, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \ldots, s_n$ (each in $\{1, 2, 3\}$), where $s_i$ is the containment unit chosen for substance $i$. Any valid allocation is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
