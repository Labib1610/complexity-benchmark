 We need to check if we can assign each node a value from {1, 2, 3} such that the sum over all edges of  
\( 5(b_u - b_v)^2 - (b_u - b_v)^4 \) equals \( 4m \).

Let’s analyze the possible differences:

- If \( b_u = b_v \), difference = 0 → contribution = 0.
- If \( |b_u - b_v| = 1 \), then \( 5(1)^2 - (1)^4 = 5 - 1 = 4 \).
- If \( |b_u - b_v| = 2 \), then \( 5(4) - 16 = 20 - 16 = 4 \).

So every edge contributes exactly 4, regardless of whether the difference is 1 or 2.  
Thus the total sum is always \( 4m \) for **any** assignment where no edge connects equal values.  
If any edge connects equal values, that edge contributes 0, making the total less than \( 4m \).

So the problem reduces to:  
Can we assign each node 1, 2, or 3 such that no edge connects two nodes with the same value?  
That’s exactly a graph coloring problem with 3 colors.

Since \( n \leq 40 \), we can use backtracking with pruning.

Here’s the solution:

```python
n, m = map(int, input().split())
edges = [tuple(map(int, input().split())) for _ in range(m)]

adj = [[] for _ in range(n)]
for u, v in edges:
    adj[u-1].append(v-1)
    adj[v-1].append(u-1)

color = [-1] * n

def dfs(node):
    if node == n:
        return True
    used = set()
    for nei in adj[node]:
        if color[nei] != -1:
            used.add(color[nei])
    for c in range(1, 4):
        if c not in used:
            color[node] = c
            if dfs(node + 1):
                return True
            color[node] = -1
    return False

if dfs(0):
    print("YES")
    print(" ".join(str(c) for c in color))
else:
    print("NO")
```
