# Chemical Extraction Sequencing

Time limit: 2 s   Memory limit: 256 MB

You are configuring a three-stage filtration system for a chemical plant. The extraction cycle consists of exactly three sequential phases (labeled 1, 2, and 3, in chronological order). 

There are $n$ chemical compounds that need to be targeted for extraction. You must assign each compound to exactly one of the three phases. 

The central control panel has exactly 8 rows of 5 switches. Each compound requires its own dedicated switch, meaning the number of compounds cannot exceed the total number of switches. There is always at least one compound to process.

Certain pairs of compounds are highly reactive. If they are processed simultaneously, they will form a precipitate and clog the filters. You are provided with a list of $m$ reactive pairs. To ensure safe operation, the two compounds in any reactive pair must be separated temporally. Specifically, for every reactive pair, one compound must be assigned to a strictly earlier phase than the other. The number of reactive pairs can range from zero up to the theoretical maximum where every compound reacts with every other compound.

Your objective is to determine if all $n$ compounds can be assigned to the three phases without violating any reactivity constraints. If a valid configuration exists, output it.

## Input
The first line contains two integers $n$ and $m$ — the number of chemical compounds and the number of reactive pairs. The bounds for $n$ and $m$ are dictated by the physical limits described above (at least one compound, up to the total number of switches; and from zero up to the maximum number of distinct pairs).
Each of the next $m$ lines contains two distinct integers $u$ and $v$ (both between 1 and $n$), representing a pair of compounds that are reactive.

## Output
If there is no valid way to assign the compounds to the phases, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $p_1, p_2, \dots, p_n$ (each in {1, 2, 3}), where $p_i$ is the phase assigned to compound $i$. If there are multiple valid assignments, any valid assignment is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
