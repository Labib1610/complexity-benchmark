We can’t solve this by brute force for n up to 40, but the key is that the allowed values are only 1, 2, and 3.  
We can check which pairs of values are allowed together.

Allowed pairs (x, y) such that (x² + y²) is **not** divisible by (x·y):

- (1,1): (1+1)=2, divisible by 1 → not allowed  
- (1,2): (1+4)=5, not divisible by 2 → allowed  
- (1,3): (1+9)=10, not divisible by 3 → allowed  
- (2,2): (4+4)=8, divisible by 4 → not allowed  
- (2,3): (4+9)=13, not divisible by 6 → allowed  
- (3,3): (9+9)=18, divisible by 9 → not allowed  

So the only forbidden edges are between nodes with the same value (1-1, 2-2, 3-3).  
That means each connected component must be 3-colorable with colors 1, 2, 3 such that adjacent nodes have different colors.  
Since the graph may not be bipartite, we can try all 3! = 6 permutations of assigning colors to the three independent sets.

We can solve by trying all 6 permutations of (1,2,3) and checking if the graph is 3-colorable with those colors in a BFS/DFS manner.

```python
import sys
from collections import deque

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)

    # Try all 6 permutations of colors
    import itertools
    for perm in itertools.permutations([1, 2, 3]):
        color = [0] * n
        possible = True
        for start in range(n):
            if color[start] == 0:
                color[start] = perm[0]
                q = deque([start])
                while q:
                    u = q.popleft()
                    for v in adj[u]:
                        if color[v] == 0:
                            # assign a color different from color[u]
                            for c in perm:
                                if c != color[u]:
                                    color[v] = c
                                    break
                            q.append(v)
                        elif color[v] == color[u]:
                            possible = False
                            break
                    if not possible:
                        break
            if not possible:
                break
        if possible:
            print("YES")
            print(' '.join(map(str, color)))
            return

    print("NO")

if __name__ == "__main__":
    solve()
```
