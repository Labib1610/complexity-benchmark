# Phase 2: Frequency Multiplexing

Time limit: 2 s   Memory limit: 256 MB

You are developing a module for a satellite communications pipeline. The pipeline operates in three sequential phases:

**Phase 1: Telemetry Ingestion**
The system receives raw data streams from distinct monitoring satellites. An interference analysis is performed to determine which pairs of data streams have overlapping harmonics.

**Phase 2: Frequency Multiplexing (Your Task)**
The data streams must be configured for the downlink transmission. Your module receives the number of satellites and the list of interfering stream pairs identified in Phase 1. There are three available frequency bands, designated by the identifiers 1, 2, and 3. You must configure each data stream to transmit on exactly one of these three bands. To ensure data integrity, any two streams that exhibit overlapping harmonics will destructively interfere if they share the same band; therefore, they must be configured to use different bands. If no such configuration is possible, the batch must be rejected.

**Phase 3: Downlink and Decoding**
The ground station receives the multiplexed signals, demodulates them using your assigned bands, and archives the telemetry.

Your task is to implement the logic for Phase 2. Given the output from Phase 1, determine a valid band configuration for all streams, or report that the batch cannot be processed.

## Input
The first line provides $n$, the total count of data streams (ranging from a minimum payload of 1 up to a hardware maximum of 40), and $m$, the number of overlapping pairs (from a minimum log size of 0 up to $n(n-1)/2$, the maximum possible number of distinct pairs).
The subsequent $m$ lines each contain two integers $u$ and $v$, identifying a pair of streams that exhibit overlapping harmonics. Streams are numbered from 1 to $n$.

## Output
If there is no configuration that avoids destructive interference, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $f_1, f_2, \dots, f_n$ (each in {1, 2, 3}), where $f_i$ is the frequency band assigned to data stream $i$. If multiple valid configurations exist, any valid configuration is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
