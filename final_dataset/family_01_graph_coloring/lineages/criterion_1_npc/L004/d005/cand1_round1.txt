# Protocol Synchronization

Time limit: 2 s   Memory limit: 256 MB

You are configuring the synchronization protocols for a distributed network of $n$ server nodes. Each node $i$ must be assigned a protocol version $b_i$, which must be an integer chosen from the set $\{1, 2, 3\}$.

You are given a list of $m$ communication links between pairs of nodes. For each link $(u, v)$, the protocol versions assigned to node $u$ and node $v$ must be cryptographically compatible to establish a secure connection. 

The compatibility check uses a modular checksum. Specifically, the assigned versions $b_u$ and $b_v$ are compatible if and only if the sum of their squares, $b_u^2 + b_v^2$, leaves a remainder of 3, 5, or 6 when divided by 7. If the remainder is anything else, the signals interfere and the connection fails.

Your objective is to determine if there exists an assignment of protocol versions for all $n$ nodes such that every communication link successfully operates. If a valid assignment exists, output it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of server nodes and the number of communication links.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), representing a communication link between node $u$ and node $v$.

## Output
If there is no valid protocol assignment, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $b_1, b_2, \dots, b_n$ (each in $\{1, 2, 3\}$), where $b_i$ is the protocol version assigned to node $i$. If there are multiple valid assignments, any valid assignment is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The previous version used a set-intersection mechanic ("share exactly one active channel") which models easily pattern-matched to the requirement that adjacent nodes must have different assignments (graph 3-coloring). To prevent this shortcut, I replaced the channel mechanic with a purely algebraic condition using quadratic residues modulo 7. For variables in {1, 2, 3}, the sum of their squares modulo 7 uniquely partitions into {3, 5, 6} for distinct pairs and {1, 2, 4} for identical pairs. This forces the model to either deduce the partition logically or fall back to an unoptimized search, breaking the semantic trigger for graph-coloring heuristics like degree ordering.
</RATIONALE>

</PRESERVED_ANSWER>
