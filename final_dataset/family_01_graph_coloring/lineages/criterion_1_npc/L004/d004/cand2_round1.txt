# Protocol Synchronization

Time limit: 2 s   Memory limit: 256 MB

You are configuring the synchronization protocols for a distributed network of $n$ server nodes.
Each node $i$ must be assigned a protocol version $b_i$, which must be an integer chosen from the set $\{1, 2, 3\}$.

For each protocol version $x \in \{1, 2, 3\}$, its state vector is defined as the 4-dimensional column vector:
$$V(x) = \begin{bmatrix} x^3 + 2x + 1 \\ x^2 + x + 2 \\ x^3 + 2x^2 + x \\ 2x^3 + x^2 + 1 \end{bmatrix}$$
Additionally, the network configuration uses two fixed reference vectors, $R_1 = [73, 22, 100, 145]^T$ and $R_2 = [136, 32, 180, 276]^T$.

You are given a list of $m$ communication links between pairs of nodes. For each link $(u, v)$, the two nodes exchange data. To ensure the entire network operates without packet loss, the protocol assignment must satisfy a specific global stability condition. 
For each communication link $(u, v)$, the synchronization matrix $M_{u,v}$ is the $4 \times 4$ matrix whose first, second, third, and fourth columns are $V(b_u)$, $V(b_v)$, $R_1$, and $R_2$, respectively. The synchronization energy of a link $(u, v)$ is defined as the rank (the maximum number of linearly independent columns) of the matrix $M_{u,v}$.

A configuration is considered stable if and only if the sum of the synchronization energies over all $m$ communication links equals exactly $4m$. 
Your objective is to determine if there exists a stable protocol assignment for all $n$ nodes. If a stable assignment exists, output it.

## Input
The first line contains two integers $n$ and $m$ ($n \ge 1$) — the number of server nodes and the number of communication links. The hardware limits the maximum number of nodes such that a fully connected topology of that maximum size would contain exactly 780 links. The number of links $m$ is non-negative and does not exceed the theoretical maximum for the given $n$.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), representing a communication link between node $u$ and node $v$.

## Output
If there is no stable protocol assignment, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $b_1, b_2, \dots, b_n$ (each in $\{1, 2, 3\}$), where $b_i$ is the protocol version assigned to node $i$. If there are multiple valid assignments, any valid assignment is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

Replaced the explicit polynomial energy function with the algebraic rank of a $4 \times 4$ matrix constructed from protocol state vectors. The state vectors are secretly the product of a Vandermonde matrix and a constant invertible matrix. This forces the model to either symbolically prove the rank is 4 iff $b_u \neq b_v$ or computationally probe the matrix, preventing immediate recognition of the 3-coloring reduction. Additionally, the constraints on $n$ and $m$ were rewritten using Strategy S07 to require deriving the bounds from a physical capacity limit.
</RATIONALE>
<PRESERVED_ANSWER>
The rank of the synchronization matrix is 4 if the protocol versions are distinct and 3 if they are identical, meaning the total energy of $4m$ is achieved if and only if every linked pair has distinct versions, which is mathematically identical to the original stability condition.
</PRESERVED_ANSWER>
