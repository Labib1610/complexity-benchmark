<STATEMENT>
# Protocol Synchronization

Time limit: 2 s   Memory limit: 256 MB

You are configuring the synchronization protocols for a distributed network of $n$ server nodes. The network is built around a standard 40-port master switch, restricting the number of nodes $n$ to be at most 40 (with at least one node present). 

Each node $i$ must be assigned a protocol version $b_i$, which must be an integer chosen from the set $\{1, 2, 3\}$.

You are given a list of $m$ communication links between pairs of nodes. The number of links $m$ can be any value from zero up to the maximum possible number of distinct pairwise direct connections. For each link $(u, v)$, the two nodes exchange data. To ensure the entire network operates continuously, the protocol assignment must satisfy a specific global stability condition. A configuration is considered stable if and only if the network's total synchronization energy equals exactly $4m$. 

The total synchronization energy is calculated as the sum over all $m$ communication links $(u, v)$ of the following expression:
$17(b_u - b_v)^6 - 86(b_u - b_v)^4 + 73(b_u - b_v)^2$

Your objective is to determine if there exists a stable protocol assignment for all $n$ nodes. If a stable assignment exists, output it.

## Input
The first line contains two integers $n$ and $m$ (where $n$ is between $1$ and the $40$-port switch capacity, and $m$ is between $0$ and the maximum number of distinct node pairs) — the number of server nodes and the number of communication links.
Each of the next $m$ lines contains two integers $u$ and $v$ (where $u$ and $v$ are distinct node identifiers from $1$ to $n$), representing a communication link between node $u$ and node $v$.

## Output
If there is no stable protocol assignment, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $b_1, b_2, \dots, b_n$ (each in $\{1, 2, 3\}$), where $b_i$ is the protocol version assigned to node $i$. If there are multiple valid assignments, any valid assignment is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The edge energy formula was replaced with a more complex 6th-degree expression that yields identical values (0 for difference 0, and 4 for differences 1 and 2). The input bounds were rewritten as textual descriptions of physical limits (e.g., a 40-port switch) to force the model to derive the bounds from context rather than pattern-matching bare inequalities.
</RATIONALE>
<PRESERVED_ANSWER>
The new energy expression evaluates to 0 when endpoints share a protocol and exactly 4 when they differ, meaning the total energy of 4m is only achievable if every pair of connected nodes has different protocols, precisely matching the seed's constraints.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to graph 3-coloring, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the textual bounds for $n$ and $m$ if they fail to parse "40-port switch capacity" or "maximum number of distinct node pairs", but the wording is standard and unambiguous.
</RISK>
