# Problem B — Workspace Modes

Time limit: 1 s   Memory limit: 256 MB

A manufacturing plant operates $n$ robotic assembly arms, numbered 1 through $n$. The facility's main floor has space to house exactly 200 blocks, each capable of holding 1,000 arms, meaning $n$ is at least one and cannot exceed this maximum capacity. 

Each arm must be configured with an operating mode, which is either 1 or 2. 

The system logs $m$ pairs of arms that share a physical workspace. The safety monitoring module allocates exactly 800,000 bytes of memory for overlap records. Each record requires exactly 4 bytes, so $m$ ranges from an empty log up to the module's maximum storage limit. 

To prevent collisions, any pair of arms that shares a workspace must operate in compatible modes. Specifically, the product of their operating modes must be exactly 2. 

Assign a mode to each assembly arm such that all workspace constraints are satisfied, or report that this is impossible. 

## Input
The first line contains two integers $n$ and $m$, representing the number of assembly arms and the number of logged pairs, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of arms that share a workspace.

## Output
If no valid mode assignment exists, print a single line `NO`.
Otherwise print `YES`, followed by a second line containing $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$), representing the mode assigned to each arm. If multiple valid assignments exist, output the sequence $s_1 \dots s_n$ that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit bounds for $n$ and $m$ were replaced with physical capacities (200 blocks of 1,000 arms) and memory limits (800,000 bytes divided by 4 bytes per record), forcing the reader to derive $200,000$. The requirement for overlapping arms to receive "different grids" was replaced with a mathematical constraint: they must receive modes from $\{1, 2\}$ such that their product is exactly 2. This forces the model to deduce that the assignments must be strictly alternating (i.e., one is 1 and the other is 2) rather than matching on standard graph-coloring phrasing.
</RATIONALE>
<PRESERVED_ANSWER>
The possible operating modes are 1 and 2, and the only way their product can be exactly 2 is if one arm is assigned mode 1 and the other mode 2, which is mathematically identical to the original requirement of assigning distinct grids.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to 2-coloring an undirected graph, which is bipartite checking solvable in O(n+m) time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
None. The derived bounds use simple multiplication and division, and the product constraint over the domain {1, 2} uniquely implies distinct values without ambiguity.
</RISK>
