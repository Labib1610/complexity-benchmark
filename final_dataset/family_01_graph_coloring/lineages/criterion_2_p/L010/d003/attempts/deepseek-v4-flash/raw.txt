We need to assign each node a value of 1 or 2 such that for every edge (u, v), the two-digit number formed by concatenating the two values is divisible by 3.

Let’s analyze the condition:

- If both are 1: "11" → 11 % 3 = 2 → fails  
- If both are 2: "22" → 22 % 3 = 1 → fails  
- If one is 1 and the other is 2: "12" or "21" → 12 % 3 = 0, 21 % 3 = 0 → passes  

So the condition is: **Every connected edge must connect nodes with different values (1 and 2)**.  
That means the graph must be bipartite, with the two parts assigned values 1 and 2.

We need the lexicographically smallest assignment.  
We can do a BFS/DFS coloring, starting with 1 for the smallest index possible, and if a conflict occurs, output NO.

```python
import sys
from collections import deque

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    possible = True
    
    for i in range(n):
        if color[i] == -1:
            color[i] = 1
            q = deque([i])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = 3 - color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        possible = False
                        break
                if not possible:
                    break
        if not possible:
            break
    
    if not possible:
        print("NO")
    else:
        print("YES")
        print(" ".join(str(c) for c in color))

if __name__ == "__main__":
    solve()
```
