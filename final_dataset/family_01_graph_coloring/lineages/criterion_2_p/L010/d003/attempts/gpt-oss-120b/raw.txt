**Solution Explanation**

For every arm we have to choose a mode `s_i ∈ {1,2}`.
For each given pair `(u , v)` the two‑digit number `s_u s_v` must be a multiple
of `3`.

```
11 % 3 = 2        12 % 3 = 0
21 % 3 = 0        22 % 3 = 1
```

Only `12` and `21` are divisible by `3`, therefore for every edge the
endpoints must have *different* values.
So we have to 2‑colour the whole graph, i.e. the graph must be **bipartite**.
If it is not bipartite the answer is `NO`.

If it is bipartite we have to output the lexicographically smallest
assignment `s_1 … s_n` (with `1 < 2`).

--------------------------------------------------------------------

#### 1.   Observations

* In a bipartite component there are exactly two possible colourings:
  the two colour classes may be swapped.
* The first index of the whole array belonging to a component decides the
  lexicographic order for this component – later indices are never compared
  before that.
* Consequently the lexicographically smallest global assignment is obtained by  
  **giving colour `1` to the smallest‑index vertex of every component**.
  (If we gave it `2`, the whole array would be larger, no matter what the
  other vertices receive.)

--------------------------------------------------------------------

#### 2.   Algorithm
```
read graph
colour[1…n] = -1                         // -1 = not visited yet
answer[1…n] = 0

for every vertex v (1 … n)
    if colour[v] == -1                     // new component
        run BFS starting from v
            assign temporary colours 0 / 1
            if a conflict is found -> graph not bipartite -> print NO
            store all vertices of this component in a list comp
        min_vertex = smallest index in comp
        flip = colour[min_vertex]           // 0 → keep, 1 → swap the two sides
        for each x in comp
            answer[x] = (colour[x] XOR flip) + 1   // 0→1 , 1→2

print YES and the array answer
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise it prints the lexicographically smallest valid assignment.

---

##### Lemma 1  
During BFS a vertex is coloured `0` or `1`.  
If the algorithm ever discovers an edge whose two endpoints already have the
same colour, the original graph is not bipartite.

**Proof.**  
In a bipartite graph every edge connects the two different colour classes.
BFS always colours neighbours with the opposite colour,
so equal colours on an edge mean that a 2‑colouring is impossible. ∎



##### Lemma 2  
If the algorithm finishes BFS for a component without conflict,
the temporary colours `0/1` form a proper 2‑colouring of this component.

**Proof.**  
Induction over the BFS order.
The start vertex receives colour `0`.  
Whenever we pop a vertex `u`, all already visited neighbours have colour
different from `colour[u]` (by construction).  
All still unvisited neighbours are coloured with the opposite value.
Thus after processing the whole component every edge connects vertices of
different temporary colours. ∎



##### Lemma 3  
For a component `C` let `c_min` be the smallest index inside `C`.
The algorithm assigns `answer[c_min] = 1`.

**Proof.**  
`c_min` belongs to `comp`.  
If its temporary colour is `0`, `flip = 0` and the final colour is `0+1 = 1`.  
If its temporary colour is `1`, `flip = 1`; after xor we obtain `0`,
again `0+1 = 1`. ∎



##### Lemma 4  
The array `answer` produced by the algorithm satisfies the condition for
every edge.

**Proof.**  
Consider an edge `{u,v}`.
Both endpoints lie in the same connected component, therefore they received
temporary colours `c_u , c_v` with `c_u ≠ c_v` (Lemma&nbsp;2).  
Both are transformed by the *same* `flip` (the flip of their component),
hence `(c_u XOR flip) ≠ (c_v XOR flip)`.  
After adding `1` the two final values are `1` and `2` in some order,
which is exactly a permitted pair (`12` or `21`). ∎



##### Lemma 5  
Among all valid assignments the algorithm’s assignment is lexicographically
minimal.

**Proof.**  
Consider the vertices in increasing order.
Let `i` be the first index where the algorithm’s assignment differs from any
other valid assignment `B`.  
`i` belongs to some component `C`.  
All vertices with index `< i` are in components processed earlier,
hence both assignments coincide on them.

By Lemma&nbsp;3 the algorithm gives vertex `i` colour `1`.  
Any other valid assignment must also respect the bipartition of `C`,
so inside `C` the two colour classes are either kept or swapped.
If it swapped them, vertex `i` (the smallest index of `C`) would receive colour
`2`.  
Thus `B[i] = 2 > 1 = answer[i]`, contradicting the assumption that `B` is
lexicographically smaller. ∎



##### Lemma 6  
If the algorithm prints `NO` then no valid assignment exists.

**Proof.**  
`NO` is printed only when a conflict described in Lemma&nbsp;1 is found.
That conflict proves the graph is not bipartite,
hence no 2‑colouring (and therefore no assignment with only `{1,2}`) exists. ∎



##### Theorem  
The algorithm outputs  

* `NO` **iff** the required configuration does not exist;  
* otherwise `YES` and the lexicographically smallest feasible sequence
  `s_1 … s_n`.

**Proof.**  

*If the algorithm prints `NO`* – by Lemma&nbsp;6 no configuration exists.

*If the algorithm prints `YES`* – Lemma&nbsp;2 guarantees each component is
bipartite, Lemma&nbsp;4 shows all edges satisfy the divisibility condition,
so the printed sequence is feasible.
Lemma&nbsp;5 states that among all feasible sequences it is the lexicographically
smallest. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*BFS* visits each vertex once and each edge twice.

```
Time   :  O(n + m)   ≤ 4·10⁵
Memory :  O(n + m)   adjacency lists + a few arrays
```

Both limits satisfy the problem constraints.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    n = next(it)
    m = next(it)

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = next(it); v = next(it)
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # temporary 0 / 1
    answer = [0] * (n + 1)

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS of one component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        while q:
            u = q.popleft()
            cu = colour[u]
            for v in adj[u]:
                if colour[v] == -1:
                    colour[v] = cu ^ 1
                    q.append(v)
                    comp.append(v)
                elif colour[v] == cu:
                    # not bipartite
                    sys.stdout.write("NO")
                    return
        # choose orientation: smallest index gets final colour 1
        min_vertex = min(comp)
        flip = colour[min_vertex]          # 0 -> keep, 1 -> swap
        for v in comp:
            answer[v] = (colour[v] ^ flip) + 1

    # all components processed successfully
    out = ["YES", " ".join(str(answer[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
