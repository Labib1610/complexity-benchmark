<STATEMENT>
# Problem B — Harmonized Frequencies

Time limit: 1 s
Memory limit: 256 MB

A manufacturing plant operates $n$ robotic assembly arms. Each arm must be configured to a positive integer operational frequency multiplier $s_i$. 

Due to hardware constraints, the multiplier assigned to each individual arm must satisfy the property that its factorial equals itself ($s_i! = s_i$).

The facility has identified $m$ specific pairs of arms that share physical workspace. When two arms with multipliers $a$ and $b$ share a workspace, their combined movement generates a spatial interaction matrix $M$:
$$ M = \begin{pmatrix} a & b & 1 \\ b & a & 1 \\ 1 & 1 & 1 \end{pmatrix} $$

To avoid resonant vibrations that lead to collisions, this interaction matrix must be non-singular (i.e., its determinant must not be zero).

Determine a valid frequency multiplier for each assembly arm so that all shared workspace constraints are satisfied. If no such configuration exists, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of assembly arms and the number of shared workspace pairs, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of arms that share physical workspace.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES on the first line, followed by a second line containing $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$), representing the frequency multiplier assigned to each arm. If multiple valid configurations exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit $\{1, 2\}$ domain and the $a^b + b^a = 3$ interference condition with a factorial property ($s_i! = s_i$) and a matrix non-singularity condition. Models must now compute the determinant of the $3 \times 3$ matrix and deduce that for the allowed values, it evaluates to non-zero if and only if $a \neq b$, forcing them to reconstruct the graph coloring logic rather than relying on pattern-matching the arithmetic.
</RATIONALE>
<PRESERVED_ANSWER>
The constraint $s_i! = s_i$ for positive integers restricts multipliers to $\{1, 2\}$, and the non-singular matrix determinant evaluates to $(a-b)(a+b-2) \neq 0$, which exactly enforces $a \neq b$ on all shared workspace pairs, preserving all valid assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring of an undirected graph (or determining none exists) and selecting the lexicographically smallest, which is solvable in $O(n+m)$ using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might fail to correctly evaluate the determinant symbolically or miss that $s_i! = s_i$ restricts the domain to $\{1, 2\}$, though the explicit $\{1, 2\}$ constraint preserved in the Output section mitigates this risk.
</RISK>
