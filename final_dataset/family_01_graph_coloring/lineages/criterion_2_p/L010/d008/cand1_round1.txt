<STATEMENT>
# Problem B — Harmonized Frequencies

Time limit: 1 s
Memory limit: 256 MB

A manufacturing plant operates $n$ robotic assembly arms, indexed from $1$ to $n$. Each arm must be configured to an integer operational mode $s_i$, chosen from the set $\{1, 2\}$.

The facility has identified $m$ pairs of arms with overlapping workspaces. To prevent collisions, every overlapping pair must pass a safety diagnostic. For any two overlapping arms $u$ and $v$, the diagnostic is successful if and only if their assigned modes satisfy the following resonance condition:

$s_u^3 + s_v^3 = 9$

Determine a valid operational mode for each assembly arm so that all $m$ safety diagnostics are successful. If no such configuration exists, you must report it.

The plant's power grid requires the total energy footprint $E$ to be as small as possible. The energy footprint is measured by simulating signal propagation through a diagnostic network.
The diagnostic network consists of a primary source $S$ and sequential relay nodes numbered $1$ to $n$. 
For each index $i$ from $1$ to $n-1$:
- A bundle of exactly 3 distinct directed links connects relay $i$ to relay $i+1$.
For each index $i$ from $1$ to $n$:
- A bundle of exactly $s_i$ distinct directed links connects the source $S$ directly to relay $i$.

The energy footprint $E$ is defined as the total number of distinct directed paths from the source $S$ to the final relay $n$. (A valid path starts at $S$, traverses a direct link to some relay $i$, and then sequentially follows the links from $i$ to $i+1$, $i+1$ to $i+2$, and so on, until reaching relay $n$).

If multiple valid mode configurations exist, you must output the specific configuration that yields the strictly minimum possible mathematical value for $E$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of assembly arms and the number of overlapping pairs, respectively.
Each of the following $m$ lines contains two integers $u$ and $v$ — indicating that the workspace of arm $u$ overlaps with the workspace of arm $v$.

## Output
If no valid mode configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$), representing the operational mode assigned to each arm. If there are multiple valid configurations, output the one that minimizes the total number of paths $E$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```
**Explanation:** For the configuration `1 2 1 2`, the number of paths from $S$ to relay $4$ is calculated as follows:
- $1$ link to relay $1$, followed by $3 \times 3 \times 3 = 27$ path continuations to relay $4$ ($27$ paths)
- $2$ links to relay $2$, followed by $3 \times 3 = 9$ path continuations to relay $4$ ($18$ paths)
- $1$ link to relay $3$, followed by $3$ path continuations to relay $4$ ($3$ paths)
- $2$ links to relay $4$, which is already the destination ($2$ paths)

Total paths $E = 27 + 18 + 3 + 2 = 50$. This is the minimum possible total path count among all valid configurations.

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit base-3 polynomial sum $E = \sum s_i 3^{n-i}$ immediately triggers lexicographical shortcuts in pattern-matching models. I replaced it with an identical combinatorial objective: counting directed paths in a specific multigraph DAG. A model that genuinely reasons will analyze the DAG, derive the mathematical sum, and deduce the lexicographical property required to solve the problem efficiently. A model relying on surface patterns will attempt to optimize a global DAG path-counting metric and fail to map it to the local component orientations of the 2-coloring subproblem.
</RATIONALE>
<PRESERVED_ANSWER>
The total number of paths from $S$ to $n$ in the defined network is exactly mathematically equal to $\sum_{i=1}^n s_i 3^{n-i}$, meaning the function that maps any valid configuration to $E$ is identical to the seed problem, preserving all optimal configurations.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest valid 2-coloring of a graph, which is solvable in $O(n+m)$ time, keeping it firmly in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "distinct directed paths" if they do not realize that choosing a different parallel link between the same two nodes constitutes a distinct path, but the explicit step-by-step calculation in Example 1 completely resolves this potential ambiguity.
</RISK>
