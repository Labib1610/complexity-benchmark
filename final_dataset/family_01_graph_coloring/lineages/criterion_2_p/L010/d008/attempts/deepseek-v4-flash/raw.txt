We can solve this by noticing that the resonance condition  
\( s_u^3 + s_v^3 = 9 \)  
only holds when one mode is 1 and the other is 2, because:

- \(1^3 + 1^3 = 2\)
- \(2^3 + 2^3 = 16\)
- \(1^3 + 2^3 = 9\)

So each edge requires its two endpoints to have different modes.  
This becomes a bipartite graph coloring problem.

We need to:
1. Build the graph.
2. Try to 2-color it (modes 1 and 2).
3. If impossible → print `NO`.
4. If possible → among all valid colorings, pick the lexicographically smallest sequence.

For lexicographically smallest, we assign mode 1 whenever possible, starting from node 1.  
We can do BFS/DFS and assign greedily: if a node is uncolored, set it to 1, then propagate.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
