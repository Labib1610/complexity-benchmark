# Problem B — Harmonized Frequencies

Time limit: 1 s
Memory limit: 256 MB

A manufacturing plant operates $n$ robotic assembly arms. Each arm must be configured to an integer operational mode $s_i$, which must be chosen from the set of positive integer divisors of $2$. 

The facility has identified $m$ instances of workspace overlap. To avoid collisions, every overlap must pass a safety check. The diagnostic system evaluates the resonance between any two overlapping arms $u$ and $v$. An overlap is considered safe if and only if the assigned modes satisfy the resonance condition:

$s_u^5 + s_v^5 - 3 s_u^2 s_v^2 = 21$

Determine a valid operational mode for each assembly arm so that all $m$ safety checks are passed. If no such configuration exists, you must report it.

The plant requires the operational modes to be standardized. If multiple valid configurations exist, you must output the lexicographically smallest sequence $s_1, \dots, s_n$.

## Input
The first line contains two integers $n$ and $m$. The number of assembly arms $n$ is at least $1$ and at most the total number of square millimeters in $0.2$ square meters. The number of overlaps $m$ is at least $0$ and shares the exact same upper limit as $n$.

Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — indicating that the workspace of arm $u$ overlaps with the workspace of arm $v$.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, followed by a second line containing $n$ integers $s_1 \dots s_n$ representing the operational mode assigned to each arm. If multiple valid configurations exist, output the lexicographically smallest sequence $s_1 \dots s_n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Replaced the explicit $\{1, 2\}$ domain with "positive integer divisors of 2" and the simple $s_u^3 + s_v^3 = 9$ equation with the expanded polynomial $s_u^5 + s_v^5 - 3 s_u^2 s_v^2 = 21$. This forces the model to mathematically evaluate the polynomial to discover that it only holds when $s_u \neq s_v$, severing the immediate pattern-matching to graph bipartiteness. The upper bounds are also derived indirectly via physical area conversions.
</RATIONALE>
<PRESERVED_ANSWER>
The valid operational modes remain strictly $\{1, 2\}$, and the new polynomial evaluates to 21 if and only if one mode is 1 and the other is 2, perfectly preserving the underlying requirement that overlapping arms must have opposite modes.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to 2-coloring (bipartiteness) on an undirected graph, which is solvable in linear time using BFS or DFS, keeping it firmly in P.
</PRESERVED_CLASS>
<RISK>
Models might theoretically fail to correctly convert $0.2$ square meters to $200,000$ square millimeters, though this relies entirely on standard unit conversion.
</RISK>
