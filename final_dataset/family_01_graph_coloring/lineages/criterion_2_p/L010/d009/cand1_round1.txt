# Problem B — Harmonized Frequencies

Time limit: 1 s
Memory limit: 256 MB

A manufacturing plant operates $n$ robotic assembly arms. Each arm must be configured to a strictly positive integer operational mode $s_i$. 

The facility has identified $m$ instances of workspace overlap. To avoid collisions, every overlap must pass a safety check. The diagnostic system evaluates the resonance between any two overlapping arms $u$ and $v$ using a geometric resonance model. An overlap is considered safe if and only if a triangle can be formed with side lengths $s_u$, $s_v$, and $\sqrt{5}$, and the area of this triangle is exactly $1$.

Determine a valid operational mode for each assembly arm so that all $m$ safety checks are passed. If no such configuration exists, you must report it.

The plant requires the operational modes to be standardized. If multiple valid configurations exist, you must output the lexicographically smallest sequence $s_1, \dots, s_n$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of assembly arms and the number of overlaps, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — indicating that the workspace of arm $u$ overlaps with the workspace of arm $v$.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, followed by a second line containing $n$ integers $s_1 \dots s_n$, representing the operational mode assigned to each arm. If multiple valid configurations exist, output the lexicographically smallest sequence $s_1 \dots s_n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Removed the explicit `{1, 2}` domain and the easily recognizable polynomial condition. Replaced them with an unbounded domain (positive integers) and a geometric condition (triangle area). To solve this, models must formalize the area using Heron's formula and solve the resulting Diophantine equation to discover that the only valid positive integer pairs are `(1, 2)` and `(2, 1)`. This forces genuine deduction of the bipartite graph structure rather than pattern-matching on a small discrete set.
</RATIONALE>
<PRESERVED_ANSWER>
The only positive integer solutions to the triangle area condition are `{1, 2}`, making the valid edge assignments mathematically identical to the original problem; isolated arms will be assigned `1` (the smallest positive integer), perfectly preserving the lexicographically smallest tie-break.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing), which is in P.
</PRESERVED_CLASS>
<RISK>
Models might struggle to parse the geometric condition as an exact integer equation due to the presence of `\sqrt{5}`, but mathematically it unambiguously simplifies to a standard Diophantine equation.
</RISK>
