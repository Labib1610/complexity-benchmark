We can solve this by noticing that the resonance condition:

\[
s_u^2 s_v + s_u s_v^2 + s_u^2 + s_v^2 = 11
\]

only has solutions for \(s_u, s_v \in \{1, 2\}\).  
Let’s check:

- If \(s_u = 1, s_v = 1\):  
  \(1 + 1 + 1 + 1 = 4\) → no  
- If \(s_u = 1, s_v = 2\):  
  \(1\cdot2 + 1\cdot4 + 1 + 4 = 2 + 4 + 1 + 4 = 11\) → yes  
- If \(s_u = 2, s_v = 1\):  
  same as above → yes  
- If \(s_u = 2, s_v = 2\):  
  \(4\cdot2 + 2\cdot4 + 4 + 4 = 8 + 8 + 8 = 24\) → no  

So the condition is:  
**Every edge must connect a 1 and a 2.**  
That means the graph must be bipartite, and we assign 1 to one side and 2 to the other.

We need the lexicographically smallest assignment.  
We can do BFS/DFS coloring, starting from node 1 with color 1, and if conflict → NO.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
