# Problem B — Harmonized Frequencies

Time limit: 1 s
Memory limit: 256 MB

A manufacturing plant operates $n$ robotic assembly arms. Each arm must be configured to an integer operational mode $s_i$, which must be chosen from the set $\{1, 2\}$. 

The facility has identified $m$ instances of workspace overlap. To avoid collisions, every overlap must pass a safety check. The diagnostic system evaluates the resonance between any two overlapping arms $u$ and $v$ by computing the following improper integral over time $t$:

$$ R(u, v) = \int_0^\infty e^{-3t} \left(e^{s_u t} + e^{s_v t}\right) dt $$

An overlap is considered safe if and only if $R(u, v) = \frac{3}{2}$. 

Determine a valid operational mode for each assembly arm so that all $m$ safety checks are passed. If no such configuration exists, you must report it.

If multiple valid configurations exist, you must output the one that minimizes the system's weighted operational footprint, defined as:

$$ W = \sum_{i=1}^n s_i \cdot 2^{n-i} $$

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of assembly arms and the number of overlaps, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ — indicating that the workspace of arm $u$ overlaps with the workspace of arm $v$.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, followed by a second line containing $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$), representing the operational mode assigned to each arm.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

Replaced the linear equation system with an improper integral that evaluates to exactly 3/2 if and only if the two variables are different, forcing models to bridge continuous calculus with discrete graph coloring. Replaced the "lexicographically smallest" tie-breaker with a global weighted sum minimization to mask the fact that disconnected components can be optimized independently, attacking the shortcut where models blindly applied independent component greedy choices without proving they were valid under the objective.
</RATIONALE>
<PRESERVED_ANSWER>
The improper integral evaluates to 3/2 exclusively when one mode is 1 and the other is 2, perfectly matching the original bipartite constraint; the weighted sum minimization mathematically equates to finding the lexicographically smallest sequence due to the base-2 exponential dominance.
</PRESERVED_ANSWER>
