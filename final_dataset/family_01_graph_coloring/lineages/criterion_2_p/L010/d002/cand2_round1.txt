<STATEMENT>
# Problem B — Harmonized Frequencies

Time limit: 1 s
Memory limit: 256 MB

A manufacturing plant operates $n$ robotic assembly arms. Each arm must be configured to an integer operational frequency multiplier $s_i$, which must be chosen from the set $\{1, 2\}$. 

The facility has identified $m$ specific pairs of arms that share physical workspace. To avoid resonant vibrations that lead to collisions, the interference index between any two arms that share a workspace must be exactly $3$. The interference index between an arm with multiplier $a$ and an arm with multiplier $b$ is calculated as $a^b + b^a$.

Determine a valid frequency multiplier for each assembly arm so that all shared workspace constraints are satisfied. If no such configuration exists, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of assembly arms and the number of shared workspace pairs, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of arms that share physical workspace.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, followed by a second line containing $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$), representing the frequency multiplier assigned to each arm. If multiple valid configurations exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the direct "product of their frequency multipliers is exactly 2" condition with an indirect interference index formula ($a^b + b^a = 3$). This forces the model to evaluate the possible combinations of the set {1, 2} to deduce that adjacent nodes must have distinct values, preventing it from immediately pattern-matching the problem to graph bipartiteness based on the word "product".
</RATIONALE>
<PRESERVED_ANSWER>
The equation $a^b + b^a = 3$ for $a, b \in \{1, 2\}$ is satisfied if and only if one value is 1 and the other is 2, which is mathematically identical to the original product constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring of an undirected graph, which is solvable in linear time using BFS/DFS and thus remains in P.
</PRESERVED_CLASS>
