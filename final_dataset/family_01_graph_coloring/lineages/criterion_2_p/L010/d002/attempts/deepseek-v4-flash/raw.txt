 We need to assign each arm either 1 or 2 such that for every edge (u, v),  
the value of \(1^2 + 2^1 = 3\) is achieved.  

Let’s check the possible pairs:  
- (1,1): \(1^1 + 1^1 = 2\) → not 3  
- (1,2): \(1^2 + 2^1 = 1 + 2 = 3\) → OK  
- (2,1): \(2^1 + 1^2 = 2 + 1 = 3\) → OK  
- (2,2): \(2^2 + 2^2 = 4 + 4 = 8\) → not 3  

So the only valid assignment is that every edge must connect a 1 and a 2.  
That means the graph must be bipartite.  

We can solve by BFS/DFS coloring:  
- Color one node 1, its neighbors 2, and so on.  
- If conflict occurs, print NO.  
- Otherwise, print YES and the coloring.  

We also need lexicographically smallest assignment, so we start with 1 for the first uncolored node in BFS order.  

Here’s the implementation:  

```python
from collections import deque

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]  # 1 -> 2, 2 -> 1
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
