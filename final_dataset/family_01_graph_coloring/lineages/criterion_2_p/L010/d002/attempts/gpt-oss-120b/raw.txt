**Solution Explanation**

For every arm we have to choose a value `s_i ∈ {1,2}`.
For a pair `(u,v)` the required interference index is  

```
s_u ^ s_v + s_v ^ s_u = 3
```

(`^` is exponent, not xor).

--------------------------------------------------------------------

#### 1.   Which pairs of values satisfy the equation ?

```
(1,1) : 1^1 + 1^1 = 2
(1,2) : 1^2 + 2^1 = 1 + 2 = 3   ← ok
(2,1) : 2^1 + 1^2 = 2 + 1 = 3   ← ok
(2,2) : 2^2 + 2^2 = 8
```

Only the mixed pairs `(1,2)` and `(2,1)` are allowed.
Therefore **every given edge must connect two different values**.
The whole problem becomes:

*Is the graph bipartite?*  
If yes, output a 2‑colouring with colours `1` and `2`.

--------------------------------------------------------------------

#### 2.   Lexicographically smallest colouring

A bipartite connected component has exactly two possible colourings
(the two sides can be swapped).
Let `c(v) ∈ {0,1}` be the colour obtained by a standard BFS/DFS
(`0` for the start vertex, neighbours get the opposite colour, …).

For a component let  

```
first = smallest vertex index inside the component
```

If we give colour `0` the value `1` and colour `1` the value `2`,
`first` receives `1` **iff** `c(first) = 0`.
Otherwise we have to swap the mapping, otherwise `first` would become `2`
which is lexicographically larger.

Thus for each component we choose the orientation that makes the smallest
vertex of this component equal to `1`.  
All components are independent, so this yields the globally smallest
sequence `s_1 … s_n`.

--------------------------------------------------------------------

#### 3.   Algorithm
```
read n,m
build adjacency list
colour = array of -1 (unvisited)

for v = 1 … n
    if colour[v] == -1
        run BFS from v
            assign colour 0/1, detect conflict (edge with same colour)
            store all vertices of this component in list comp
        if conflict → print "NO" and exit
        first = min(comp)
        if colour[first] == 0
            mapping = {0:1, 1:2}
        else
            mapping = {0:2, 1:1}
        for x in comp
            answer[x] = mapping[colour[x]]

print "YES"
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `"NO"` iff no assignment exists,
otherwise prints `"YES"` and the lexicographically smallest valid assignment.

---

##### Lemma 1  
For any edge `(u,v)` the interference condition is satisfied **iff**
` s_u ≠ s_v`.

*Proof.* Directly from the table in section&nbsp;1. ∎



##### Lemma 2  
During BFS, if a conflict (an edge whose ends already have the same colour)
is found, then no assignment satisfying the condition exists.

*Proof.* By Lemma&nbsp;1 the two ends must receive different values.
BFS colours vertices exactly according to the parity of the length of a
path from the start vertex. If an edge connects two vertices of the same
BFS colour, every 2‑colouring would give them the same value, contradicting
Lemma&nbsp;1. Hence the instance is unsatisfiable. ∎



##### Lemma 3  
If BFS finishes a component without conflict, the obtained colour
`c(v) ∈ {0,1}` yields a valid assignment for this component
(by mapping the two colours to `{1,2}`).

*Proof.* All edges of the component connect vertices of opposite BFS
colours, therefore after any mapping `0→a, 1→b` with `a≠b` the edge endpoints
receive different values, satisfying Lemma&nbsp;1. ∎



##### Lemma 4  
For a conflict‑free component the algorithm chooses the mapping that gives
the smallest possible value to the smallest vertex of the component.

*Proof.* Let `first` be that vertex.
If `c(first)=0` the algorithm maps colour 0 to `1`, so `first` gets `1`.
Any other mapping would give `first` the value `2` (since colours must be
different), which is larger.  
If `c(first)=1` the algorithm maps colour 1 to `1`, again giving `first`
value `1`. The opposite mapping would give `2`. ∎



##### Lemma 5  
The whole sequence produced by the algorithm is lexicographically minimal
among all valid assignments.

*Proof.* Consider the vertices in increasing order.
Take the first index `i` where the algorithm’s assignment differs from any
other valid assignment.
Vertex `i` belongs to some component `C`. All vertices `< i` are equal in
both assignments, therefore for component `C` the other assignment must give
the same values to all vertices `< i`. In particular the smallest vertex of
`C` (call it `first`) is `< i` and already has value `1` in both assignments
(because otherwise the other assignment would be larger at `first`).  
By Lemma&nbsp;4 the algorithm gives value `1` to `first` and consequently
to every vertex whose colour equals `c(first)`. Vertex `i` has the same
colour as `first` (otherwise it would already differ earlier). Hence the
algorithm also gives `1` to `i`, while the other assignment gives `2`.  
Thus the algorithm’s sequence is lexicographically smaller. ∎



##### Lemma 6  
If the algorithm prints `"YES"` the produced sequence satisfies all
constraints.

*Proof.* Every component was conflict‑free, therefore by Lemma&nbsp;3 the
mapping of its two colours to `{1,2}` yields a valid assignment inside the
component. Different components have no edges between them, so all edges of
the whole graph satisfy Lemma&nbsp;1. ∎



##### Theorem  
The algorithm outputs  

* `"NO"` **iff** no assignment of `{1,2}` to the vertices satisfies the
  interference condition;
* otherwise `"YES"` and the lexicographically smallest such assignment.

*Proof.*  
- If the algorithm prints `"NO"` it discovered a conflict, and by
  Lemma&nbsp;2 the instance is unsatisfiable.
- If the instance is unsatisfiable, any component must contain a conflict,
  otherwise Lemma&nbsp;3 would give a valid assignment. Hence the algorithm
  would encounter a conflict and print `"NO"`.
- If the algorithm prints `"YES"`, by Lemma&nbsp;6 the assignment is valid.
  By Lemma&nbsp;5 it is lexicographically minimal among all valid
  assignments. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

`BFS` visits each vertex once and each edge twice.

```
Time   :  O(n + m)   ≤ 4·10^5
Memory :  O(n + m)   adjacency list + arrays
```

Both fit easily into the limits.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 unvisited, 0/1 bipartite colour
    answer = [0] * (n + 1)

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS for this component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        ok = True
        while q:
            v = q.popleft()
            cv = colour[v]
            for to in adj[v]:
                if colour[to] == -1:
                    colour[to] = cv ^ 1
                    q.append(to)
                    comp.append(to)
                elif colour[to] == cv:
                    # conflict -> not bipartite
                    print("NO")
                    return
        # choose orientation for lexicographically smallest result
        first = min(comp)
        if colour[first] == 0:
            map0, map1 = 1, 2
        else:
            map0, map1 = 2, 1
        for v in comp:
            answer[v] = map0 if colour[v] == 0 else map1

    # all components processed without conflict
    print("YES")
    sys.stdout.write(' '.join(str(answer[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
