# Problem B — Harmonized Frequencies

Time limit: 1 s
Memory limit: 256 MB

A manufacturing plant operates $n$ robotic assembly arms. Each arm must be configured to an integer operational phase state, which must be chosen from the set $\{1, 2\}$. 

The facility has identified $m$ specific pairs of arms that share physical workspace. When two arms share a workspace, their combined operation generates an acoustic resonance proportional to the sum of the cubes of their phase states. To avoid vibrations that lead to collisions, any pair of arms that share workspace must be configured such that the sum of the cubes of their phase states is exactly $9$. 

Determine a valid phase state for each assembly arm so that all shared workspace constraints are satisfied. If no such configuration exists, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of assembly arms and the number of shared workspace pairs, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of arms that share physical workspace.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, followed by a second line containing $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$), representing the phase state assigned to each arm. If multiple valid configurations exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the edge constraint from a direct product condition ($s_u \cdot s_v = 2$) to an indirect polynomial predicate (the sum of the cubes of their phase states must be exactly 9). This forces the model to evaluate the predicate over the domain $\{1, 2\}$ to discover that adjacent nodes must have distinct values, preventing surface-level pattern matching to graph 2-coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The domain for each state remains $\{1, 2\}$, and the new condition $s_u^3 + s_v^3 = 9$ is mathematically satisfied if and only if one state is 1 and the other is 2, perfectly matching the original $s_u \cdot s_v = 2$ constraint so all valid assignments and the lexicographical tie-breaker are identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring (bipartiteness check) of an undirected graph, which is solvable in $O(n+m)$ time using BFS or DFS, keeping it in the complexity class P.
</PRESERVED_CLASS>
