<STATEMENT>
# Problem B — Harmonized Frequencies

Time limit: 1 s
Memory limit: 256 MB

A manufacturing plant operates $n$ robotic assembly arms. Each arm must be configured to an integer operational mode $s_i$, which must be chosen from the set $\{1, 2\}$. 

The facility has identified $m$ calibration dependencies. To ensure stability, every dependency must pass a safety check. For a dependency where arm $v$ is calibrated against arm $u$, the diagnostic system requires that the operational mode of arm $v$ must be exactly equal to the remainder when $5$ is divided by $(s_u + 2)$.

Determine a valid operational mode for each assembly arm so that all $m$ safety checks are passed. If no such configuration exists, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of assembly arms and the number of dependencies, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ — indicating a calibration dependency where arm $v$ is calibrated against arm $u$.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, followed by a second line containing $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$), representing the operational mode assigned to each arm. If multiple valid configurations exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The symmetric constraint ($s_u^2 + s_v^2 = 5$) was replaced with a mathematically identical but asymmetric modulo operation ($s_v = 5 \bmod (s_u + 2)$), and the input pairs were reframed as directed dependencies. This tricks the models into building a directed graph instead of an undirected one, causing their BFS to fail on weakly connected components that lack directed paths from the starting nodes.
</RATIONALE>
<PRESERVED_ANSWER>
For $s_i \in \{1, 2\}$, the condition $s_v = 5 \bmod (s_u + 2)$ evaluates to true if and only if $s_u \neq s_v$, maintaining the exact same valid configurations (and thus the same lexicographically smallest sequence) as the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) on an undirected graph, which is solvable in O(n + m) time using BFS or DFS, keeping it in the P complexity class.
</PRESERVED_CLASS>
