<STATEMENT>
# Problem B — Harmonized Frequencies

Time limit: 1 s
Memory limit: 256 MB

A manufacturing plant operates $n$ robotic assembly arms. Each arm must be configured to an integer operational mode $s_i$, which must be chosen from the set $\{1, 2\}$. 

The facility has identified $m$ instances of workspace overlap. Each overlap involves two arms. To avoid collisions, the entire configuration must pass a facility-wide safety diagnostic. 

The diagnostic system calculates two global metrics:
1. The **Total Stress**: For each of the $m$ overlaps, the system multiplies the operational modes of the two overlapping arms. The Total Stress is the sum of these $m$ products.
2. The **Total Load**: For each arm $i$ from $1$ to $n$, the system multiplies its operational mode $s_i$ by its overlap frequency $d_i$. The overlap frequency $d_i$ is defined as the total number of times arm $i$ is listed in the $m$ overlap pairs. The Total Load is the sum of these $n$ values (i.e., $\sum_{i=1}^n d_i s_i$).

The entire configuration is considered safe if and only if the Total Stress is exactly $2m$ and the Total Load is exactly $3m$.

Determine a valid operational mode for each assembly arm so that the configuration is safe. If no such configuration exists, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of assembly arms and the number of overlaps, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ — indicating that the workspace of arm $u$ overlaps with the workspace of arm $v$.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES on the first line, followed by a second line containing $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$), representing the operational mode assigned to each arm. If multiple valid configurations exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<METHOD_NAME>Global System of Invariants</METHOD_NAME>
<METHOD_DESCRIPTION>Replaced the local per-edge constraints with two global sum constraints (Total Stress and Total Load) that form a system of equations whose unique solution algebraically forces the original local constraint. This hides the bipartite graph coloring nature behind what appears to be a global QUBO/optimization problem, defeating models that rely on surface pattern matching.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<RATIONALE>
I removed the local per-overlap condition that explicitly forced `s_u != s_v` and replaced it with two global facility-wide sum metrics. This forces the model to mathematically prove that the only way to satisfy both global sums simultaneously is if every individual overlap assigns different modes, requiring deep structural reasoning before the standard BFS can be applied.
</RATIONALE>
<PRESERVED_ANSWER>
Because `s_i` is restricted to {1, 2}, the system of equations formed by the two global metrics has a unique solution where the count of same-mode overlaps is strictly zero, making the valid assignments mathematically identical to the seed's local conflict rules.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding a valid 2-coloring of a graph and choosing the lexicographically smallest one, which is solvable in O(n+m) time using BFS, so it remains in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the `Total Load` definition if they fail to understand that `d_i` is simply the degree of the vertex in the multigraph, but the explicit definition "total number of times arm i is listed in the m overlap pairs" prevents ambiguity.
</RISK>
