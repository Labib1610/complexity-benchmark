<STATEMENT>
# Problem B — Harmonized Frequencies

Time limit: 1 s
Memory limit: 256 MB

A manufacturing plant operates $n$ robotic assembly arms. Each arm must be configured to an integer operational mode $s_i$, which must be chosen from the set $\{1, 2\}$. 

The facility has identified $m$ instances of workspace overlap. To avoid collisions, every overlap must pass a safety check. The diagnostic system calculates the combined energy profile of an overlap between arm $u$ and arm $v$, which is determined by the sum of the squares of their operational modes ($s_u^2 + s_v^2$). An overlap is considered safe if and only if this combined energy profile is exactly 5.

Determine a valid operational mode for each assembly arm so that all $m$ safety checks are passed. If no such configuration exists, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of assembly arms and the number of overlaps, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ — indicating that the workspace of arm $u$ overlaps with the workspace of arm $v$.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, followed by a second line containing $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$), representing the operational mode assigned to each arm. If multiple valid configurations exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the artificial concatenation and divisibility rule with a combined energy profile rule ($s_u^2 + s_v^2 = 5$). This forces models to evaluate the condition for the domain $\{1, 2\}$ and deduce that it requires $s_u \neq s_v$, effectively masking the bipartite 2-coloring structure under a natural physical constraint. I also removed the directional wording to prevent semantic drift, while restoring the exact formal bounds in the Input section to satisfy the strict I/O contract.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $s_u^2 + s_v^2 = 5$ for $s_i \in \{1, 2\}$ is satisfied if and only if one mode is 1 and the other is 2, which is exactly equivalent to the seed's requirement that their concatenation is a multiple of 3 (12 or 21), leaving all valid assignments identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartite checking) on an undirected graph, solvable in $O(n+m)$ time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
None. The arithmetic constraint is explicitly defined and trivial to evaluate for the allowed domain.
</RISK>
