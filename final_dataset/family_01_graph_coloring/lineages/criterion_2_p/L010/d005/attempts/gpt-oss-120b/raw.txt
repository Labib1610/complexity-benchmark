**Solution Explanation**

For every arm we have to choose a mode `s_i ∈ {1,2}`.
For an overlap (edge) `{u,v}` the safety condition is  

```
s_u² + s_v² = 5
```

`1² = 1 , 2² = 4` → the sum is `5` **iff** one endpoint is `1` and the other
is `2`.  
So every edge must connect two different values – the required assignment is
exactly a *proper 2‑colouring* of the given graph.

The problem therefore reduces to

* check whether the graph is bipartite,
* if it is, output a 2‑colouring with colours `{1,2}`,
* among all possible colourings output the lexicographically smallest one.

--------------------------------------------------------------------

#### 1.   Bipartite check and component collection  

We run a BFS/DFS from every still unvisited vertex.

During the search we store  

* `col[v] ∈ {0,1}` – the side of the bipartition,
* `comp` – list of vertices of the current connected component.

If we ever see an edge `(v,w)` with `col[v] == col[w]` the graph is **not**
bipartite → answer `NO`.

The total work is `O(n+m)`.

--------------------------------------------------------------------

#### 2.   Lexicographically smallest colouring  

Components are independent – we may flip the two sides inside a component
without breaking any edge condition.

Consider one component, its vertices are `comp = [v1, v2, …]`.
Let `v_min = min(comp)` – the smallest index belonging to this component.
If we colour the side `col = 0` with value `1` and side `col = 1` with `2`,
`v_min` receives  

```
value = 1   if col[v_min] == 0
value = 2   otherwise
```

If we flip the colours, `v_min` receives the opposite value.
To obtain the smallest possible overall sequence we **must give `v_min` the
value `1`** (because any earlier index in the whole answer is smaller than all
later ones).  
Thus the orientation of the component is uniquely determined:

```
if col[v_min] == 0 :   side 0 → 1 , side 1 → 2
else                 :   side 0 → 2 , side 1 → 1
```

For an isolated vertex (`comp` size = 1, no edges) the rule also gives value
`1`.

Processing components in any order and applying the rule yields the globally
lexicographically smallest assignment.

--------------------------------------------------------------------

#### 3.   Algorithm
```
read n,m
build adjacency list
col = [-1]* (n+1)          # -1 = unvisited, else 0/1
answer = [0]*(n+1)

for v = 1 .. n:
    if col[v] == -1:
        bfs from v
        collect vertices of this component in list comp
        during bfs check bipartite, fill col[]

        if conflict -> print "NO" and exit

        v_min = min(comp)
        # decide orientation so that v_min gets value 1
        if col[v_min] == 0:
            side_one = 0          # colour 0 → value 1
        else:
            side_one = 1          # colour 1 → value 1

        for x in comp:
            if col[x] == side_one:
                answer[x] = 1
            else:
                answer[x] = 2

print "YES"
print answer[1] … answer[n] separated by spaces
```

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise prints `YES` and the lexicographically smallest valid assignment.

---

##### Lemma 1  
During BFS, if an edge `(u,v)` with `col[u] == col[v]` is found, the graph is
not bipartite, hence no assignment satisfying all edges exists.

**Proof.** In any assignment each edge must connect different values (`1` and
`2`). Translating values to colours (`1 → 0`, `2 → 1`) gives a proper
2‑colouring. If an edge has equal colours, such a 2‑colouring cannot exist.
∎



##### Lemma 2  
If the algorithm finishes all BFS traversals without conflict, the graph is
bipartite and the produced `answer` satisfies every edge.

**Proof.** BFS assigns a colour `0/1` to each vertex, and the conflict test
ensures that every edge connects vertices of different colours.
The final step maps one colour to value `1` and the other to `2`; therefore
each edge connects `1` and `2`, i.e. `s_u² + s_v² = 1 + 4 = 5`. ∎



##### Lemma 3  
For a single connected component, among all valid assignments the algorithm
chooses the lexicographically smallest one restricted to the vertices of this
component.

**Proof.** Let `v_min` be the smallest index in the component.
Any valid assignment must give `v_min` either `1` or `2`.  
If it gives `2`, flipping the whole component (exchanging the two sides)
produces another valid assignment where `v_min` becomes `1` and all other
vertices keep the same relative order. Since `1 < 2`, the assignment with
`v_min = 1` is lexicographically smaller. The algorithm exactly selects this
orientation, therefore no other valid assignment of the component is
lexicographically smaller. ∎



##### Lemma 4  
The concatenation of the component‑wise choices made by the algorithm is the
lexicographically smallest assignment for the whole graph.

**Proof.** Consider the global vertex order `1,2,…,n`. Let `c` be the first
component that contains the smallest index where two different global
assignments differ. By Lemma&nbsp;3 the algorithm gives the smallest possible
value to that index inside component `c`. All earlier indices belong to
components already fixed identically in every feasible assignment (otherwise
they would be the first differing index). Hence no other global assignment can
be lexicographically smaller. ∎



##### Lemma 5  
If the algorithm outputs `YES` and a sequence, that sequence is a valid
assignment.

**Proof.** By Lemma&nbsp;2 each component is bipartite and the mapping to
`1/2` respects every edge, therefore the whole sequence satisfies all edges. ∎



##### Theorem  
The algorithm

* prints `NO` **iff** no assignment of `{1,2}` satisfying all edges exists,
* otherwise prints `YES` followed by the lexicographically smallest such
  assignment.

**Proof.**  
*If the algorithm prints `NO`*: this happens only when a conflict is found,
by Lemma&nbsp;1 the graph is not bipartite, thus no assignment exists.

*If a valid assignment exists*: the graph is bipartite, so no conflict occurs,
the algorithm finishes and prints `YES`. By Lemma&nbsp;5 the printed sequence
is valid. By Lemma&nbsp;4 it is the lexicographically smallest among all
valid sequences.

Conversely, if the algorithm prints `YES`, a valid assignment exists
(Lemma&nbsp;5). ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge processed once → `O(n + m)`  
*Additional work* (finding minima, filling answer) is linear in component
size, overall `O(n)`.

Total time `O(n + m)` ≤ `4·10⁵`, well inside the 1 s limit.  
Memory consumption `O(n + m)` ≤ `~4·10⁵` integers → < 10 MB.

#### 6.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    col = [-1] * (n + 1)          # -1 unvisited, else 0/1
    ans = [0] * (n + 1)

    for start in range(1, n + 1):
        if col[start] != -1:
            continue
        # BFS for this component
        q = deque([start])
        col[start] = 0
        comp = [start]
        ok = True
        while q:
            v = q.popleft()
            for nb in adj[v]:
                if col[nb] == -1:
                    col[nb] = col[v] ^ 1
                    q.append(nb)
                    comp.append(nb)
                elif col[nb] == col[v]:
                    ok = False
                    break
            if not ok:
                break
        if not ok:
            print("NO")
            return

        # decide orientation: smallest index gets value 1
        v_min = min(comp)
        side_one = col[v_min]          # colour that will become 1
        for v in comp:
            ans[v] = 1 if col[v] == side_one else 2

    # all components processed
    print("YES")
    print(' '.join(str(ans[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
