<STATEMENT>
# Problem B — Harmonized Frequencies

Time limit: 1 s
Memory limit: 256 MB

A manufacturing plant operates $n$ robotic assembly arms. Each arm must be configured to an integer operational mode $s_i$, which must be chosen from the set $\{1, 2\}$. 

The facility has identified $m$ instances of directional workspace overlap. To avoid collisions, every overlap must pass a one-way diagnostic check. The diagnostic system evaluates an overlap from arm $u$ into the operating zone of arm $v$ using an asymmetric optical verification protocol.

The system tracks a single test pulse through a 4-channel waveguide, with channels labeled A, B, C, and D. For each directional overlap from $u$ to $v$:
1. A test pulse is injected exactly into channel A.
2. The pulse passes through arm $u$. Depending on its mode $s_u$, the arm routes the pulse to a new channel:
   - Mode 1: If the pulse is in A, it moves to B; if in B, it moves to A; if in C, it moves to D; if in D, it moves to C.
   - Mode 2: If the pulse is in A, it moves to C; if in C, it moves to A; if in B, it moves to D; if in D, it moves to B.
3. The pulse then immediately passes through arm $v$, which applies the exact same routing rules based on its mode $s_v$.

The overlap is considered safe if and only if, after passing through both arms in that strict order, the test pulse emerges from channel D.

Determine a valid operational mode for each assembly arm so that all $m$ directional diagnostic checks are passed. If no such configuration exists, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of assembly arms and the number of directional overlaps, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ — indicating that the workspace of arm $u$ overlaps into the zone of arm $v$.

## Output
If no valid configuration exists, print a single line `NO`.
Otherwise print `YES`, followed by a second line containing $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$), representing the operational mode assigned to each arm. If multiple valid configurations exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The arithmetic divisibility rule was removed and replaced with a sequential channel-routing simulation equivalent to the Klein four-group. This forces the model to either correctly trace the state machine to deduce that the rule simplifies to the symmetric undirected constraint $s_u \neq s_v$, or fall into the trap of modeling it as a complex directed 2-SAT problem, which will time out or fail when attempting to find the lexicographically smallest assignment.
</RATIONALE>
<PRESERVED_ANSWER>
Tracing the routing: if modes are (1,1) the pulse goes A->B->A; if (1,2) it goes A->B->D; if (2,1) it goes A->C->D; if (2,2) it goes A->C->A. The pulse emerges from D if and only if $s_u \neq s_v$, which is the exact same condition as the seed's divisibility by 3.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying constraint remains $s_u \neq s_v$ on the domain $\{1, 2\}$, which is exactly the 2-coloring (bipartiteness) problem solvable in $O(n+m)$ using Breadth-First Search.
</PRESERVED_CLASS>
