We can model this as a graph problem.  
Each index in the phase array is a node.  
A conflict cell `(u, v)` means `p[u] != p[v]`.  

So we build an undirected graph where an edge between `u` and `v` means they must have different phases.  
This is a bipartite check: if the graph is not bipartite, answer is `NO`.  
If it is bipartite, we assign phases 1 and 2, and to get the lexicographically smallest array, we try to assign 1 whenever possible during BFS/DFS.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n + 1)]

for _ in range(m):
    u, v = map(int, input().split())
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * (n + 1)
possible = True

for i in range(1, n + 1):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    print(' '.join(str(color[i]) for i in range(1, n + 1)))
```
