<STATEMENT>
# Problem B — Market Equilibrium

Time limit: 1 s   Memory limit: 256 MB

You are analyzing a market with $n$ commodities. Each commodity $i$ must be assigned a pricing tier $p_i$, which must be chosen as either 1 or 2.

There are $m$ observed dependencies between pairs of commodities. The $k$-th dependency involves commodities $u_k$ and $v_k$.

To maintain market equilibrium, the pricing tiers must strictly satisfy two regulatory constraints:
1. Local Interference: For every dependency involving commodities $u$ and $v$, their assigned tiers must satisfy the wave interference equation:
   $$\sin\left( \frac{\pi}{2} (2 p_u - 1) \right) \times \sin\left( \frac{\pi}{2} (2 p_v - 1) \right) = -1$$
2. Cycle Neutrality: For any simple cycle of dependencies in the market, the sum of the pricing tiers of the commodities in that cycle must exactly equal $1.5$ times the number of commodities in the cycle.

Your objective is to determine if there exists a pricing tier assignment for all $n$ commodities that satisfies both constraints for all dependencies and cycles. If such an assignment exists, you must output it. In cases where multiple valid assignments exist, you must choose the one whose sequence of tiers $p_1, p_2, \dots, p_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of commodities and the number of dependencies.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), specifying the 1-based indices of the two commodities involved in that dependency.

## Output
If no valid pricing tier assignment can achieve equilibrium, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, output $n$ integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2\}$) denoting the pricing tiers. If there are multiple valid sequences, output the sequence that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit "at least one is 1 and at least one is 2" condition with a mathematically equivalent trigonometric constraint that evaluates to -1 only when the tiers are different. I also introduced a "Cycle Neutrality" global constraint that requires the sum of tiers in any simple cycle to be 1.5 times its length. This constraint is mathematically redundant because any valid 2-coloring of a bipartite graph inherently satisfies it, but it baits the model into attempting complex cycle-finding or ILP formulations that will time out.
</RATIONALE>
<PRESERVED_ANSWER>
The trigonometric constraint strictly enforces $p_u \neq p_v$, and since any valid 2-coloring of a bipartite graph perfectly alternates colors along any cycle, the cycle sum is always exactly 1.5 times the cycle length, meaning the new constraints are perfectly logically equivalent to the original ones.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) on an undirected graph, which is solvable in O(n+m) time using BFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "simple cycle" if the graph contains self-loops or multi-edges, though the standard graph-theoretic definition handles these naturally and yields the correct logical impossibility in those edge cases.
</RISK>
