<METHOD_DESCRIPTION>Replaces the direct binary inequality constraint (p_u != p_v) with a spatial compatibility rule between two geometric tile types. Models must spatially reason that two identical 1x2 or 2x1 tiles can form a 2x2 square, while a mixed pair cannot, in order to deduce the underlying bipartite constraint. This breaks superficial pattern matching to 2-SAT or graph coloring while preserving the exact logical structure.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Grid Phase Configuration

Time limit: 1 s   Memory limit: 256 MB

You are configuring the properties of an $n \times n$ grid. To do this, you must assign a single tile type array $p$ of length $n$, where each element $p_i \in \{1, 2\}$ for $1 \le i \le n$.
This array simultaneously dictates the tile types for the grid's rows and columns: the tile type of row $i$ is defined as $p_i$, and the tile type of column $i$ is also defined as $p_i$.

The two available tile types are defined geometrically:
- **Type 1** is a vertical rectangular tile of width 1 and height 2.
- **Type 2** is a horizontal rectangular tile of width 2 and height 1.

You are given a list of $m$ conflict cells within the grid. The $k$-th conflict cell is located at row $u_k$ and column $v_k$.
A configuration is valid if, for every conflict cell, a tile of its row's assigned type and a tile of its column's assigned type **cannot** be joined to form a $2 \times 2$ square. 
(Two tiles can be joined to form a $2 \times 2$ square if they can be placed adjacent to each other on a flat surface, without rotation or overlapping, such that their combined shape is exactly a square of width 2 and height 2.)

Your objective is to determine if there exists a valid tile type configuration. If there are multiple valid configurations, you must output the one whose sequence $p_1, p_2, \dots, p_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the size of the array and the number of conflict cells.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), specifying the 1-based row and column indices of a conflict cell.

## Output
If no valid tile type configuration is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, output $n$ integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2\}$) denoting the array. Among all valid assignments, you must output the lexicographically smallest sequence.

## Example 1
Input:
4 4
1 2
2 3
3 4
1 4
Output:
YES
1 2 1 2

## Example 2
Input:
3 3
1 2
1 3
2 3
Output:
NO
</STATEMENT>
<RATIONALE>
I replaced the direct inequality constraint ($p_u \neq p_v$) with a geometric tile-pairing rule. Models can no longer immediately parse the problem as a bipartite graph or 2-SAT instance from the text alone. To succeed, they must perform spatial reasoning to deduce that two identical tiles (both 1x2 or both 2x1) can form a 2x2 square, while a mixed pair cannot, thereby reconstructing the hidden $p_u \neq p_v$ requirement.
</RATIONALE>
<PRESERVED_ANSWER>
Two 1x2 tiles can form a 2x2 square side-by-side, and two 2x1 tiles can form one top-to-bottom, but a 1x2 and 2x1 tile cannot form a 2x2 square; thus the condition "cannot form a 2x2 square" is perfectly logically equivalent to $p_u \neq p_v$.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying mathematical structure remains identically an undirected graph 2-coloring (bipartiteness testing) problem, keeping it in P and solvable in $O(N+M)$ time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the geometric rules (e.g., assuming tiles can be rotated despite the explicit "without rotation" clause), leading them to conclude that no tiles can form a square or that all combinations can, though the phrasing is mathematically standard and precise.
</RISK>
