We can model this as a graph problem. Each gear is a node, and each meshing pair is an edge. The condition \( p_u \times p_v = 2 \) means that if one gear has ratio 1, the other must have ratio 2, and vice versa. So the graph must be bipartite, and the two parts correspond to ratio 1 and ratio 2.

We need the lexicographically smallest assignment, so we try to assign 1 as early as possible. This can be done by BFS/DFS with a greedy coloring: when we start a new component, we try assigning 1 to the smallest-index node in that component, then propagate.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        # Try to assign 1 to i
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]  # 1 -> 2, 2 -> 1
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    print(" ".join(str(c) for c in color))
```
