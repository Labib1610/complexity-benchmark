<METHOD_NAME>Trigonometric Inequality Projection</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit binary inequality p_u != p_v with a trigonometric product condition cos(pi * p_u) * cos(pi * p_v) < 0. Since p_i is in {1, 2}, this evaluates to (-1) * 1 < 0, exactly enforcing opposite assignments. Models relying on explicit inequality checks or standard graph text patterns will fail to recognize the bipartite structure.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem B — Flux Node Polarity

Time limit: 1 s   Memory limit: 256 MB

You are tuning a system of $n$ flux nodes. To do this, you must assign a single state array $p$ of length $n$, where each element $p_i \in \{1, 2\}$ for $1 \le i \le n$. 
The polarity of the $i$-th node is given by the function $f(p_i) = \cos(\pi \cdot p_i)$.

You are given a list of $m$ flux linkages between the nodes. The $k$-th linkage connects the node at index $u_k$ and the node at index $v_k$.
A state configuration is valid if, for every linkage $k$, the product of the polarities of the two connected nodes is strictly negative. That is, $f(p_{u_k}) \cdot f(p_{v_k}) < 0$.

Your objective is to determine if there exists a valid state configuration. If there are multiple valid configurations, you must output the one whose sequence $p_1, p_2, \dots, p_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of nodes and the number of linkages.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), specifying the 1-based indices of the nodes connected by a flux linkage.

## Output
If no valid state configuration is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, output $n$ integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2\}$) denoting the state array. Among all valid assignments, you must output the lexicographically smallest sequence.

## Example 1
Input:
4 4
1 2
2 3
3 4
1 4
Output:
YES
1 2 1 2

## Example 2
Input:
3 3
1 2
1 3
2 3
Output:
NO
</STATEMENT>
<RATIONALE>
The problem replaces the explicit "row phase != column phase" condition with a mathematically equivalent trigonometric product condition. Because `cos(π) = -1` and `cos(2π) = 1`, the condition `f(p_u) * f(p_v) < 0` exactly requires `p_u` and `p_v` to be distinct elements of `{1, 2}`. This forces the model to evaluate the trigonometric function's range over the discrete domain to discover the binary inequality.
</RATIONALE>
<PRESERVED_ANSWER>
The condition `cos(π * p_u) * cos(π * p_v) < 0` for `p_i` in `{1, 2}` is satisfied if and only if one value is 1 and the other is 2, which is identical to the original `p_u != p_v` requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring a graph (bipartiteness checking) with lexicographical tie-breaking, keeping it firmly in P.
</PRESERVED_CLASS>
