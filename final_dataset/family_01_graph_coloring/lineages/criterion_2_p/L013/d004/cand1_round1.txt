# Problem B — Asset Hedging

Time limit: 1 s   Memory limit: 256 MB

A financial institution is allocating a portfolio of $n$ assets. Each asset must be assigned exactly one configuration factor, which must be either $1$ or $2$.

Due to extreme market correlation, risk analysts have identified $m$ specific pairs of assets that require careful handling. To comply with the institution's hedging policy, every flagged pair $(u, v)$ must be assigned configuration factors $s_u$ and $s_v$ such that the remainder when $s_u$ is divided by $s_v$, plus the remainder when $s_v$ is divided by $s_u$, is exactly $1$.

Your objective is to find a complete assignment of configuration factors for the $n$ assets that strictly respects all $m$ hedging policies. If such an assignment is possible, you must output it. In cases where multiple valid assignments exist, you must choose the one that yields the lexicographically smallest sequence of $n$ configuration factors (using 1s and 2s).

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), indicating the total number of assets and the number of flagged asset pairs. The assets are indexed from 1 to $n$.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), specifying a pair of assets that falls under the hedging policy.

## Output
If no assignment can satisfy all hedging policies, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$) denoting the assigned configuration factors for assets 1 through $n$. If there are multiple valid assignments, output the sequence that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit "must be in different vehicles" / "must be split" condition with an arithmetic constraint on the assigned values. The condition (sum of cross-modulos equals 1) is mathematically equivalent to the variables being different over the domain {1, 2}, but it forces models to analyze the domain and evaluate the arithmetic rather than just pattern-matching keywords to a bipartite graph 2-coloring template.
</RATIONALE>
<PRESERVED_ANSWER>
Since the variables are restricted to {1, 2}, the condition (s_u mod s_v) + (s_v mod s_u) = 1 is true if and only if s_u != s_v, making the valid assignments identical to the seed's requirement that the pair be split.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring on a graph (checking bipartiteness), which is solvable in O(n + m) time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the modulo condition if they fail to read the restriction that the factors must be exactly 1 or 2, though this is explicitly stated in the first paragraph.
</RISK>
