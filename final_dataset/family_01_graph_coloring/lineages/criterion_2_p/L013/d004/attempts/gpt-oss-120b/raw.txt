**Solution Explanation**

For every row of the matrix we know the two columns that contain `1`.
If the chosen values of the vector `S` are `s_u , s_v` then the row value is  

```
s_u + s_v
```

The required row value is `3`, therefore for every given pair `(u , v)`

```
s_u + s_v = 3                (1)
```

`S` may contain only `1` or `2`.  
Equation (1) is satisfied **iff** the two numbers are different:

```
s_u = 1  →  s_v = 2
s_u = 2  →  s_v = 1
```

So the columns are the vertices of a graph, each row is an (undirected) edge,
and the condition is:

*adjacent vertices must obtain different values*.

That is exactly the definition of a **bipartite** graph with the two
colours `1` and `2`.

--------------------------------------------------------------------

#### 1.   Detect bipartiteness and obtain a 2‑colouring  

Depth‑first (or breadth‑first) search is performed.
During the search each vertex receives colour `0` or `1`.
When an already coloured neighbour has the same colour, the graph contains an
odd cycle → it is **not bipartite** → answer `NO`.

The search also collects all vertices of the current connected component.

Complexities  

```
time   :  O(n + m)
memory :  O(n + m)
```

--------------------------------------------------------------------

#### 2.   Lexicographically smallest solution  

Inside one connected component the whole colouring can be flipped
(`0 ↔ 1`) and still satisfies all edges.
The lexicographically smallest whole vector is obtained by the following
rule:

*In each component make the vertex with the smallest index receive the
value `1`.*

Why?  
Lexicographic order compares the first position where two vectors differ.
The first position belonging to a component is exactly the smallest index
inside this component. Giving it the smallest possible value (`1`) is
mandatory for a globally minimal vector; later positions cannot compensate
for a larger value at this earlier position.

Implementation  

* after the DFS of a component we know its vertices and the smallest index
  `min_v`.
* if `colour[min_v] == 1` we flip the whole component (`colour ^= 1`);
  otherwise we keep it.
* finally `s_i = 1` for colour `0`, `s_i = 2` for colour `1`.

Isolated vertices (no incident edge) form a component of size `1`,
receive colour `0` → value `1`, which is also optimal.

--------------------------------------------------------------------

#### 3.   Algorithm
```
read n , m
build adjacency list of n vertices from the m edges
colour[1..n] = -1          # -1 = unvisited
answer[1..n] = 0

for v = 1 .. n
    if colour[v] == -1
        start DFS from v, colour[v] = 0
        component = []          # vertices of this component
        min_v = v
        while stack not empty
            x = pop()
            component.append(x)
            min_v = min(min_v, x)
            for each neighbour y of x
                if colour[y] == -1
                    colour[y] = colour[x] ^ 1
                    push y
                elif colour[y] == colour[x]
                    print "NO" and exit
        flip = colour[min_v]          # 0 → keep, 1 → invert
        for each x in component
            final = colour[x] ^ flip
            answer[x] = 1 if final == 0 else 2

print "YES"
print answer[1] … answer[n] separated by blanks
```

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `NO` iff no suitable vector exists,
otherwise prints `YES` and the lexicographically smallest valid vector.

---

##### Lemma 1  
During DFS, if an edge connects two vertices with the same colour,
the system of equations (1) has no solution.

**Proof.**  
Same colour means the algorithm would assign the same value (`1` or `2`) to
both endpoints. Equation (1) would then require `1+1=3` or `2+2=3`,
both impossible. ∎



##### Lemma 2  
If the algorithm finishes DFS without detecting a conflict,
the obtained colouring satisfies (1) for every edge.

**Proof.**  
Every explored edge connects vertices of opposite colours
(because a conflict would have been reported).  
We later map colour `0 → 1` and colour `1 → 2` (possibly after a global flip
inside the component). Hence each edge connects a `1` and a `2`,
their sum is `3`. ∎



##### Lemma 3  
For a connected component, among all assignments satisfying (1) the
algorithm’s choice (smallest index vertex gets value `1`) is lexicographically
minimal restricted to the indices of this component.

**Proof.**  
Inside a component any valid assignment is either the algorithm’s colouring
or its global flip (the only other possibility, because all edges force
adjacent vertices to be different).  
If the smallest index vertex receives `2` in an assignment, flipping the
component makes it receive `1` and does not change any earlier index
(because there is none). Therefore the assignment with `1` at the smallest
index is strictly smaller lexicographically. ∎



##### Lemma 4  
The vector produced by the algorithm is the lexicographically smallest
among **all** vectors satisfying (1).

**Proof.**  
Consider the components ordered by their smallest vertex index.
The algorithm forces the first component (the one containing vertex `1` if it
exists, otherwise the component whose smallest index is the smallest overall)
to have value `1` at its smallest index, which is the smallest possible value
at that position (Lemma&nbsp;3).  
All later components involve only indices larger than any index already
fixed, therefore their choices cannot affect the already optimal prefix.
Applying Lemma&nbsp;3 to each component sequentially yields a globally minimal
lexicographic vector. ∎



##### Lemma 5  
If the algorithm outputs `NO`, no vector `S` with entries in `{1,2}`
satisfying `A S = 3` exists.

**Proof.**  
`NO` is printed only when a conflict (same colour on an edge) is found.
By Lemma&nbsp;1 such a conflict makes the system unsatisfiable, hence no
vector exists. ∎



##### Lemma 6  
If the algorithm outputs `YES`, the printed vector satisfies `A S = 3`.

**Proof.**  
`YES` is printed only after all components have been processed without
conflict, therefore the colouring is proper. By Lemma&nbsp;2 each edge sums to
`3`. Consequently every row of `A` multiplied by `S` equals `3`. ∎



##### Theorem  
The algorithm is correct.

**Proof.**  

*Soundness* – If the algorithm prints `YES`, by Lemma&nbsp;6 the printed
vector satisfies the required equation, and by Lemma&nbsp;4 it is the
lexicographically smallest such vector.

*Completeness* – If a suitable vector exists, the underlying graph must be
bipartite; otherwise some edge would have equal values, contradicting the
row sum `3`. A bipartite graph never produces a conflict during DFS, so the
algorithm never prints `NO`. Hence it prints `YES` and a valid vector.

Thus the algorithm outputs `NO` exactly when the problem has no solution,
and otherwise outputs the required optimal vector. ∎

#### 5.   Complexity Analysis  

```
building adjacency list : O(m)
DFS over all vertices   : O(n + m)
memory                  : O(n + m)   (adjacency list, colour, answer)
```

Both limits satisfy the given constraints (`n,m ≤ 2·10⁵`).

#### 6.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    n, m = data[0], data[1]
    adj = [[] for _ in range(n + 1)]
    it = 2
    for _ in range(m):
        u = data[it]; v = data[it + 1]; it += 2
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 = unvisited, 0/1 = two colours
    ans = [0] * (n + 1)             # final values 1 or 2

    stack = []
    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # new component
        component = []
        min_v = start
        colour[start] = 0
        stack.append(start)

        while stack:
            v = stack.pop()
            component.append(v)
            if v < min_v:
                min_v = v
            cv = colour[v]
            for nb in adj[v]:
                if colour[nb] == -1:
                    colour[nb] = cv ^ 1
                    stack.append(nb)
                elif colour[nb] == cv:
                    sys.stdout.write("NO")
                    return

        flip = colour[min_v]          # 0 -> keep, 1 -> invert
        for v in component:
            final = colour[v] ^ flip
            ans[v] = 1 if final == 0 else 2

    # all vertices processed without conflict
    out = ["YES", " ".join(str(ans[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
