**Solution Explanation**

For every asset we have to choose a vehicle `1` or `2`.
For each given pair `{u , v}` the two assets must be placed in **different**
vehicles.

So the assets together with the pairs form an undirected graph.
The condition *“endpoints of every edge have different vehicles”* is exactly the
definition of a **bipartite** graph.
If the graph is not bipartite the answer is `NO`.

If the graph is bipartite, each connected component has two possible
colourings – we may exchange the two colour classes.
Among all global colourings we have to output the lexicographically smallest
string of `1`/`2`.

--------------------------------------------------------------------

#### 1.   Observations

* In one component the vertices are ordered by their indices.
  The first (smallest) index of the component is the first position where this
  component influences the final string.
* All earlier positions are already fixed, therefore to obtain the smallest
  possible whole string we only have to make the **smallest index of the current
  component equal to `1` if it is possible**.
* Inside a component the two colour classes are fixed up to a global swap,
  therefore we can always achieve `1` on the smallest vertex:
  just choose the orientation that puts its colour to `1`.

Consequences  

* We can process the components independently, in any order.
* For each component we run a BFS/DFS, colour the vertices `0/1`.
  If a conflict appears → graph not bipartite.
* Let `v0` be the smallest vertex of the component.
  If `colour[v0] == 0` we map colour `0 → 1 , 1 → 2`,
  otherwise we map `0 → 2 , 1 → 1`.
  This gives the lexicographically smallest possible assignment.

The whole algorithm is linear `O(n+m)`.

--------------------------------------------------------------------

#### 2.   Algorithm
```
read n, m
build adjacency list G

colour[1..n] = -1          # -1 = unvisited, 0/1 = temporary colours
answer[1..n] = 0

for each vertex start = 1 .. n
    if colour[start] != -1: continue
    # new component
    queue = [start]
    colour[start] = 0
    component_vertices = [start]
    while queue not empty
        v = pop queue
        for each to in G[v]
            if colour[to] == -1
                colour[to] = colour[v] ^ 1
                push to into queue
                component_vertices.append(to)
            elif colour[to] == colour[v]
                print "NO" and exit
    # component is bipartite
    v0 = min(component_vertices)          # smallest index in this component
    if colour[v0] == 0:
        # orientation A : 0 → 1 , 1 → 2
        for x in component_vertices:
            answer[x] = 1 if colour[x] == 0 else 2
    else:
        # orientation B : 0 → 2 , 1 → 1
        for x in component_vertices:
            answer[x] = 2 if colour[x] == 0 else 1

print "YES"
print answer[1] … answer[n] separated by spaces
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `NO` iff no feasible allocation exists,
otherwise prints the lexicographically smallest feasible allocation.

---

##### Lemma 1  
During the BFS of a component, if a conflict `colour[u] == colour[v]` for an
edge `{u,v}` is found, the whole graph is not bipartite.

**Proof.**  
BFS assigns colours exactly as in a standard 2‑colouring algorithm.
If an edge connects two vertices of the same colour, any 2‑colouring would give
them the same colour (because colours are forced by parity of path length).
Thus the component, and consequently the whole graph, is not bipartite. ∎



##### Lemma 2  
If the algorithm finishes a component without conflict, the component is
bipartite and the array `colour` is a proper 2‑colouring of it.

**Proof.**  
BFS starts with an arbitrary vertex coloured `0` and always colours a neighbour
with the opposite colour. By induction on the BFS order every processed edge
has endpoints of different colours, therefore the obtained colouring is proper.
∎



##### Lemma 3  
For a bipartite component let `v0` be its smallest vertex.
The algorithm chooses an orientation that assigns vehicle `1` to `v0`.

**Proof.**  
If `colour[v0] == 0` the algorithm maps colour `0 → 1`, hence `v0` gets `1`.  
If `colour[v0] == 1` the algorithm maps colour `1 → 1`, again `v0` gets `1`. ∎



##### Lemma 4  
Among all feasible allocations, any allocation that gives vehicle `1` to the
smallest vertex of a component is lexicographically not larger than any
allocation that gives vehicle `2` to that vertex, while keeping the assignments
of earlier vertices unchanged.

**Proof.**  
Lexicographic order compares the first position where two strings differ.
All positions before `v0` are equal (they belong to earlier components).
If one allocation has `1` at position `v0` and the other has `2`,
the former is strictly smaller. ∎



##### Lemma 5  
The allocation produced by the algorithm is lexicographically minimal among
all feasible allocations.

**Proof.**  
Consider the components ordered by their smallest vertex.
We prove by induction over this order.

*Base.* For the first component the algorithm (Lemma&nbsp;3) assigns `1` to its
smallest vertex, which is optimal by Lemma&nbsp;4.

*Induction step.* Assume the algorithm is optimal for the first `k‑1`
components, i.e. the prefix up to the smallest vertex of component `k` is
lexicographically minimal among all feasible allocations.
For component `k` the algorithm again gives `1` to its smallest vertex
(Lemma&nbsp;3). Any feasible allocation that coincides with the algorithm on the
first `k‑1` components but gives `2` to this vertex would be larger
(Lemma&nbsp;4). Changing earlier components would break the induction hypothesis.
Thus after processing component `k` the prefix up to its smallest vertex is
still minimal. ∎



##### Lemma 6  
If the algorithm outputs `YES` and the assignment `answer`,
`answer` satisfies all hedging policies.

**Proof.**  
By Lemma&nbsp;2 each component is bipartite, and the final mapping only swaps the
two colour classes. Hence every edge connects vertices of different vehicles.
All vertices belong to exactly one component, therefore all edges are satisfied. ∎



##### Theorem  
The algorithm prints `NO` iff no feasible allocation exists.
Otherwise it prints `YES` and the lexicographically smallest feasible allocation.

**Proof.**  

*If part.*  
If the algorithm prints `NO`, it must have detected a conflict (Lemma&nbsp;1),
so the graph is not bipartite, thus no allocation exists.

*Only‑if part.*  
If a conflict never occurs, every component is bipartite (Lemma&nbsp;2) and the
constructed assignment satisfies all edges (Lemma&nbsp;6), therefore a feasible
allocation exists and the algorithm prints `YES`.

Finally, by Lemma&nbsp;5 the printed allocation is the lexicographically smallest
among all feasible ones. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once → `O(n + m)`.

Total time `O(n + m)` ≤ `4·10⁵`, well inside the limits.  
Memory: adjacency list (`2m` integers) + a few arrays → `O(n + m)` ≤
~`5·10⁵` integers ≈ a few MB.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    g = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        g[u].append(v)
        g[v].append(u)

    colour = [-1] * (n + 1)          # temporary 0/1 colours
    ans = [0] * (n + 1)             # final 1/2 assignment

    from collections import deque

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # new component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        while q:
            v = q.popleft()
            cv = colour[v]
            for to in g[v]:
                if colour[to] == -1:
                    colour[to] = cv ^ 1
                    q.append(to)
                    comp.append(to)
                elif colour[to] == cv:
                    print("NO")
                    return
        # component is bipartite
        v0 = min(comp)
        if colour[v0] == 0:
            # 0 -> 1, 1 -> 2
            for x in comp:
                ans[x] = 1 if colour[x] == 0 else 2
        else:
            # 0 -> 2, 1 -> 1
            for x in comp:
                ans[x] = 2 if colour[x] == 0 else 1

    out = ['YES', ' '.join(str(ans[i]) for i in range(1, n + 1))]
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```

to the required input‑output format.
