**Solution Explanation**

For every commodity `i`

* `p_i` – its price tier, `p_i ∈ {1,2}`
* `d_i` – how many times `i` appears in the `m` dependencies  
  (`d_i` is the degree of vertex `i` in the given undirected graph)

The two global numbers are  

```
W = Σ d_i · p_i
U = Σ p_u · p_v          (over all edges (u,v))
```

The market is in perfect equilibrium iff  

```
3·W – 2·U = 5·m                                    (1)
```

--------------------------------------------------------------------

#### 1.   Transform the equation

Write `p_i = 1 + x_i` with `x_i ∈ {0,1}`.

```
W = Σ d_i (1 + x_i) = Σ d_i + Σ d_i x_i                (2)
U = Σ (1+x_u)(1+x_v)
  = Σ (1 + x_u + x_v + x_u x_v)
  = m + Σ (x_u + x_v) + Σ x_u x_v
  = m + Σ d_i x_i + Σ x_u x_v                         (3)
```

Insert (2) and (3) into (1):

```
3( Σ d_i + Σ d_i x_i ) – 2( m + Σ d_i x_i + Σ x_u x_v ) = 5m
```

Because `Σ d_i = 2m` (hand‑shaking lemma) we obtain after simplification

```
Σ d_i x_i – 2 Σ x_u x_v = m                              (4)
```

--------------------------------------------------------------------

#### 2.   Edge classification

For an edge `(u,v)` three cases are possible

| x_u | x_v | contribution to Σ d_i x_i | contribution to Σ x_u x_v |
|-----|-----|---------------------------|---------------------------|
| 0   | 0   | 0                         | 0                         |
| 1   | 1   | 2                         | 1                         |
| 0   | 1   | 1                         | 0                         |
| 1   | 0   | 1                         | 0                         |

Define  

* `S2 = Σ x_u x_v` – number of edges whose both ends are `1`
* `T` – number of edges with **exactly one** endpoint equal to `1`

From the table  

```
Σ d_i x_i = 2·S2 + T
```

Plug into (4):

```
(2·S2 + T) – 2·S2 = T = m
```

Therefore **every edge must belong to `T`**, i.e. its ends must be different.
Consequences

* the graph must be *bipartite* (2‑colourable with colours `0` and `1`);
* any bipartition satisfies the equation, because then `T = m`.

If the graph is not bipartite, no assignment exists.

--------------------------------------------------------------------

#### 3.   Lexicographically smallest assignment

All feasible assignments are exactly the two colourings of each connected
component.  
To obtain the lexicographically smallest sequence `p_1 … p_n`
(`p_i = 1 + x_i`) we proceed component by component in increasing order of
their smallest vertex index:

* start a BFS/DFS from the smallest not yet visited vertex `s`;
* colour `s` with `0` (so `p_s = 1`);
* propagate the colours (standard bipartite check).

Choosing `0` for the smallest vertex of the component is optimal:
any other orientation would make `p_s = 2`, which is larger at the first
different position of the whole sequence.

Thus the greedy rule “the first vertex of each component gets colour 0”
produces the globally lexicographically minimal solution.

--------------------------------------------------------------------

#### 4.   Algorithm
```
read n, m
build adjacency list
colour[1…n] = -1   // -1 = unvisited, 0 or 1 otherwise
for v = 1 … n:
    if colour[v] == -1:
        colour[v] = 0
        queue = [v]
        while queue not empty:
            u = pop
            for each neighbour w of u:
                if colour[w] == -1:
                    colour[w] = colour[u] ^ 1
                    push w
                else if colour[w] == colour[u]:
                    print "NO" and exit   // not bipartite
print "YES"
output p_i = colour[i] + 1 for i = 1 … n
```

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct lexicographically
smallest assignment iff such an assignment exists.

---

##### Lemma 1  
For any assignment `p_i ∈ {1,2}` the equality `3W‑2U = 5m` holds
iff every edge connects vertices with different values of `x_i = p_i‑1`.

**Proof.** The derivation in Sections&nbsp;1‑2 shows that the equality is
equivalent to `T = m`, i.e. the number of edges with exactly one endpoint
having `x = 1` equals the total number of edges. Hence no edge may have
both ends `0` or both ends `1`. ∎



##### Lemma 2  
An assignment satisfying the equality exists **iff** the input graph is
bipartite.

**Proof.**  
*If* the graph is bipartite, colour its vertices with `0/1`. By Lemma&nbsp;1
the condition holds, therefore a valid assignment exists (`p = 1+colour`).  

*Only‑if*: if a valid assignment exists, by Lemma&nbsp;1 its `x`‑values give a
2‑colouring of the graph, thus the graph is bipartite. ∎



##### Lemma 3  
During the algorithm, when a new component is started at its smallest
vertex `s`, setting `colour[s]=0` yields the lexicographically smallest
possible values for all vertices of that component among all feasible
colourings of the component.

**Proof.** The component has exactly two feasible colourings: the one
produced by the BFS and its global complement (swap `0↔1`). In the first
colouring `s` has colour `0`, in the second `s` has colour `1`. Since the
overall sequence is compared from left to right, any sequence where `p_s=2`
is larger than the one with `p_s=1`, regardless of later positions.
Thus the orientation with `colour[s]=0` is lexicographically minimal. ∎



##### Lemma 4  
If the algorithm finishes without detecting a conflict, the produced
array `p_i = colour[i]+1` satisfies `3W‑2U = 5m`.

**Proof.** The BFS never assigns the same colour to adjacent vertices,
hence every edge connects vertices of different colours, i.e. different
`x`. By Lemma&nbsp;1 the equality holds. ∎



##### Lemma 5  
If the algorithm prints “NO”, no valid assignment exists.

**Proof.** “NO” is printed only when an edge `(u,v)` with `colour[u]==colour[v]`
is found. At that moment the already coloured part of the component forces
both ends to have the same `x`. Any extension of this partial colouring would
keep this edge monochromatic, contradicting Lemma&nbsp;1. Hence the graph is
not bipartite, and by Lemma&nbsp;2 no assignment exists. ∎



##### Theorem  
The algorithm outputs  

* “NO” iff the market cannot be in perfect equilibrium;  
* otherwise “YES” and the lexicographically smallest price tier sequence
  achieving perfect equilibrium.

**Proof.**  

*If the algorithm outputs “YES”*: by Lemma&nbsp;4 the produced sequence
satisfies the required equation, so a perfect equilibrium exists.
By Lemma&nbsp;3 each component is coloured minimally, therefore the whole
sequence is lexicographically minimal among all feasible sequences.

*If a perfect equilibrium exists*: by Lemma&nbsp;2 the graph is bipartite,
so the BFS never meets a conflict; the algorithm therefore reaches the end
and prints “YES”.  

*If the algorithm outputs “NO”*: by Lemma&nbsp;5 no equilibrium is possible.

Thus the statements hold in all cases. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge processed once → `O(n + m)` time.  

Total: **Time `O(n + m)`**, **Memory `O(n + m)`**, well within the limits.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * n          # -1 = unvisited, 0 or 1 otherwise
    for start in range(n):
        if colour[start] != -1:
            continue
        colour[start] = 0      # smallest vertex of component gets 0
        q = deque([start])
        while q:
            u = q.popleft()
            cu = colour[u]
            for w in adj[u]:
                if colour[w] == -1:
                    colour[w] = cu ^ 1
                    q.append(w)
                elif colour[w] == cu:
                    print("NO")
                    return

    # all good
    print("YES")
    out = [str(c + 1) for c in colour]
    print(' '.join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
