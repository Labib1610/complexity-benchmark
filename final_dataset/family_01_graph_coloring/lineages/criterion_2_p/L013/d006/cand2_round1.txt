Algebraically, expanding this sum produces complex path-of-length-2 cross terms that prevent models from decomposing it into independent edge constraints. <STATEMENT>
# Problem B — Market Equilibrium

Time limit: 1 s
Memory limit: 256 MB

You are analyzing a market with $n$ commodities. Each commodity $i$ must be assigned a pricing tier $p_i$, which must be chosen as either 1 or 2.

There are $m$ observed dependencies between pairs of commodities. 

For each commodity $i$, let $d_i$ denote the total number of dependencies it is involved in. We define two local metrics for commodity $i$:
1. The **Base Valuation**, $V_i = d_i p_i$.
2. The **Network Valuation**, $N_i$. For each of the $d_i$ dependencies involving commodity $i$, consider the pricing tier of the other commodity in that dependency. $N_i$ is the sum of these $d_i$ pricing tiers. (If $d_i = 0$, then $N_i = 0$).

The overall volatility of the market is measured by the **Market Divergence**, defined as:
$D = \sum_{i=1}^n (V_i - N_i)^2$

A market is considered to be in *perfect equilibrium* if and only if the Market Divergence exactly equals the sum of the squares of the dependency counts:
$D = \sum_{i=1}^n d_i^2$

Your objective is to determine if there exists a pricing tier assignment for all $n$ commodities that achieves perfect equilibrium. If such an assignment exists, you must output it. In cases where multiple valid assignments exist, you must choose the one whose sequence of tiers $p_1, p_2, \dots, p_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of commodities and the number of dependencies.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), specifying the 1-based indices of the two commodities involved in that dependency.

## Output
If no valid pricing tier assignment can achieve perfect equilibrium, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, output $n$ integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2\}$) denoting the pricing tiers. If there are multiple valid sequences, output the sequence that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the global edge-sum condition with a global sum of squared local vertex differences. Algebraically, expanding this expression introduces complex path-of-length-2 terms (due to the squared neighborhood sum) that prevent models from simplifying it into independent edge constraints. This forces the model to step away from global algebraic manipulation and discover the local upper bound $(V_i - N_i)^2 \le d_i^2$ for each vertex independently to realize it's just bipartiteness.
</RATIONALE>
<PRESERVED_ANSWER>
Since $(V_i - N_i)^2 \le d_i^2$ is strictly true for all valid assignments of 1s and 2s, the global equality holds if and only if every local bound is tight, which occurs exactly when every dependency connects different tiers, preserving the exact set of valid assignments and the lexicographical tie-breaker.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The condition $D = \sum d_i^2$ is mathematically equivalent to requiring $p_u \neq p_v$ for all edges, meaning the problem remains exactly bipartite 2-coloring, solvable with BFS in O(n+m) time.
</PRESERVED_CLASS>
<RISK>
The most likely way this could be judged ambiguous is if the definition of Network Valuation for multigraphs is misunderstood, but the phrasing "For each of the $d_i$ dependencies... consider the pricing tier of the other commodity" explicitly clarifies that multiple dependencies to the same commodity are counted multiple times.
</RISK>
