# Problem B — System Cohesion

Time limit: 1 s   Memory limit: 256 MB

You are analyzing a complex system with $n$ components. Each component $i$ must be assigned a configuration state $c_i$, which must be chosen as either 1 or 2.

There are $m$ observed linkages between pairs of components. The $k$-th linkage connects components $u_k$ and $v_k$.

The system's overall stability is summarized by two global metrics:
1. The **Aggregate Volume Metric (AVM)**, defined as $V = \sum_{i=1}^n d_i c_i$, where $d_i$ is the total number of times component $i$ appears across all $m$ linkages.
2. The **Synergy Metric (SM)**, defined as $S = \sum_{k=1}^m c_{u_k} c_{v_k}$.

The system is considered to be in *perfect cohesion* if and only if these metrics satisfy the non-linear equation:
$V^2 - 4mS = m^2$

Your objective is to determine if there exists a configuration state assignment for all $n$ components that achieves perfect cohesion. If such an assignment exists, you must output it. In cases where multiple valid assignments exist, you must choose the one whose sequence of states $c_1, c_2, \dots, c_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of components and the number of linkages.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), specifying the 1-based indices of the two components involved in that linkage.

## Output
If no valid configuration state assignment can achieve perfect cohesion, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, output $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2\}$) denoting the assigned states. If there are multiple valid sequences, output the sequence that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
