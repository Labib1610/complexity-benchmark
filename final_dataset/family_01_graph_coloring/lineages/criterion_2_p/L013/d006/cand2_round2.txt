<STATEMENT>
# Market Equilibrium

Time limit: 1 s   Memory limit: 256 MB

You are analyzing a market with $n$ commodities. Each commodity $i$ must be assigned a pricing tier $p_i$, which must be chosen as either 1 or 2.

There are $m$ observed dependencies between pairs of commodities. The $k$-th dependency involves commodities $u_k$ and $v_k$. 

A market is considered to be in *perfect equilibrium* if and only if for every observed dependency between commodities $u$ and $v$, their assigned pricing tiers satisfy the following modular congruence:
$7^{p_u} + 7^{p_v} \equiv 6 \pmod{10}$

Your objective is to determine if there exists a pricing tier assignment for all $n$ commodities that achieves perfect equilibrium. If such an assignment exists, you must output it. In cases where multiple valid assignments exist, you must choose the one whose sequence of tiers $p_1, p_2, \dots, p_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$. The market registry assigns a unique 1-based index to each commodity, and the infrastructure's maximum capacity dictates that the number of commodities will not exceed two hundred thousand, with at least one commodity always present. Similarly, the monitoring system is limited to tracking a maximum of two hundred thousand dependencies, though it is possible for zero dependencies to be observed.
The following $m$ lines each contain two integers $u$ and $v$, specifying the indices of the two commodities involved in that dependency. The indices are guaranteed to be valid commodity identifiers.

## Output
If no valid pricing tier assignment can achieve perfect equilibrium, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, output $n$ integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2\}$) denoting the pricing tiers. If there are multiple valid sequences, output the sequence that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
