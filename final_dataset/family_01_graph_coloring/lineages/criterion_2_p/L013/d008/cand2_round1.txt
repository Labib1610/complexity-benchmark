<STATEMENT>
# Problem B — Signal Synchronization

Time limit: 1 s   Memory limit: 256 MB

You are deploying a network of $n$ signal processors. Each processor $i$ must be configured with a gain multiplier $g_i$, which must be chosen as either 1 or 2.

There are $m$ synchronization links between pairs of processors. The $k$-th link connects processors $u_k$ and $v_k$.

To prevent signal drift, the configuration must satisfy a strict interference condition for every link. Specifically, for any link between processors $u$ and $v$, the quadratic function 
$$ f(x) = x^2 - (g_u + g_v)x + 2 $$
must achieve a minimum value of exactly $-0.25$.

Your objective is to determine if there exists a valid gain configuration for all $n$ processors that satisfies this condition for all $m$ links. If such a configuration exists, you must output it.

If there are multiple valid configurations, you must choose the one that maximizes the system stability metric, defined as:
$$ \sum_{i=1}^n \frac{2 - g_i}{\Gamma(i+1)} $$
where $\Gamma$ denotes the Gamma function (recall that $\Gamma(k) = (k-1)!$ for positive integers).

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of processors and the number of links.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), specifying the 1-based indices of the two processors connected by that link.

## Output
If no valid configuration can achieve synchronization, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, output $n$ integers $g_1, g_2, \dots, g_n$ (where each $g_i \in \{1, 2\}$) denoting the gain multipliers. If there are multiple valid sequences, output the sequence that maximizes the stability metric.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The previous versions failed because models recognized the explicit "average exactly 1.5" constraint as a bipartite coloring condition. By encoding this condition as the minimum of a quadratic function, models must now perform algebraic deduction before they can recognize the underlying graph structure. Furthermore, the tie-breaker is rewritten using an algebraic indicator function and the Gamma function, removing the explicit set construction that models previously pattern-matched to lexicographical ordering.
</RATIONALE>
<PRESERVED_ANSWER>
The minimum of $f(x)$ occurs at $x = (g_u+g_v)/2$ with a value of $2 - (g_u+g_v)^2/4$; setting this to $-0.25$ algebraically forces $g_u + g_v = 3$, identical to the original average constraint, and the stability metric algebraically simplifies to exactly the original factorial sum since $(2-g_i)$ is 1 when $g_i=1$ and 0 when $g_i=2$.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring of a graph and choosing the lexicographically optimal valid coloring per connected component, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might struggle with the algebraic deduction step and mistakenly conclude the condition is unsatisfiable, though the algebra is standard and unambiguous.
</RISK>
