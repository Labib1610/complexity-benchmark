# Problem B — Asset Hedging

Time limit: 1 s
Memory limit: 256 MB

A financial institution is reorganizing its investments by distributing exactly $n$ unique financial instruments across two separate funds, designated as Fund 1 and Fund 2. Your task is to determine the exact fund assignment for each of the $n$ instruments. Each instrument must go to exactly one of the two funds.

Risk analysts have flagged $m$ specific pairs of instruments that are highly correlated. To ensure market neutrality, a strict separation policy applies to each of these flagged pairs: the two instruments in any flagged pair are strictly prohibited from being assigned to the same fund. 

You need to figure out if there is a way to distribute all $n$ instruments between the two funds without violating any of the separation policies. If it can be done, output a valid distribution. If there is more than one valid way to distribute the instruments, you must output the distribution that produces the lexicographically smallest sequence of $n$ fund identifiers (where each identifier is either 1 or 2).

## Input
The first line contains two integers $n$ and $m$. The institution's portfolio system requires at least $1$ instrument and has a maximum capacity of $2\cdot 10^5$ instruments. The risk analysts can flag anywhere from $0$ up to $2\cdot 10^5$ pairs. Instruments are numbered from 1 to $n$.
Each of the following $m$ lines contains two integers $u$ and $v$, representing a pair of instruments that fall under the separation policy.

## Output
If there is no valid fund assignment that satisfies all separation policies, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print exactly $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$) representing the assigned funds for instruments 1 through $n$. If there are multiple valid assignments, output the sequence that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
