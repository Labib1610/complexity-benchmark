<STATEMENT>
# Problem B — Asset Hedging

Time limit: 1 s
Memory limit: 256 MB

A wealth management firm is restructuring its holdings. The firm offers two investment vehicles, identified by the values $1$ and $2$. You must determine an investment value for each of the $n$ assets, where each asset receives exactly one of these two values.

To ensure market neutrality, the risk department has flagged $m$ combinations of two assets. For each flagged combination, a strict hedging mandate is enforced: the sum of the assigned investment value for the first asset in the combination and the assigned investment value for the second asset in the combination must equal exactly $3$.

Determine whether it is possible to assign the values $1$ and $2$ to all $n$ assets such that every mandate is perfectly satisfied. If a valid assignment exists, you must provide it. In the event that multiple valid assignments are possible, you must select the one that is lexicographically smallest when expressed as a sequence of $n$ investment values. A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first position where they differ, sequence $A$ has a smaller value than sequence $B$.

The firm's asset database allocates exactly $5$ bytes of storage for each asset record, out of a total capacity pool of $1,000,000$ bytes, establishing the maximum limit for $n$. The number of assets $n$ will be between $1$ and this limit. Similarly, the risk engine's memory allows it to process a number of flagged combinations $m$ ranging from $0$ up to the same limit. Assets are numbered from $1$ to $n$.

## Input
The first line contains two integers $n$ and $m$, representing the number of assets and the number of flagged combinations, respectively.
Each of the next $m$ lines contains two integers, representing a flagged combination of two assets subject to the hedging mandate.

## Output
If no valid assignment exists that satisfies all mandates, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$) representing the assigned investment values for assets $1$ through $n$. If there are multiple valid assignments, output the sequence that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The graph-coloring terminology ("if one asset is allocated to Portfolio 1, the other must be placed in Portfolio 2") has been replaced with an arithmetic constraint: the assigned values (1 and 2) must sum to exactly 3. This forces models to logically deduce that the two values must be different, rather than relying on surface-level keyword matching for bipartite graphs or 2-coloring. Numeric bounds were also made indirect via a storage capacity calculation.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that two values from the set {1, 2} sum to exactly 3 is mathematically identical to requiring that the two values be different, exactly preserving the bipartite coloring constraints (including failing correctly on self-loops) and the lexicographical tie-breaking rule.
</PRESERVED_ANSWER>

The problem remains equivalent to checking if a graph is bipartite (2-colorable) and assigning colors via BFS to find the lexicographically first valid coloring, keeping it firmly in P.
</PRESERVED_CLASS>

Models might misinterpret the indirect bounds calculation (1,000,000 / 5 = 200,000), but the arithmetic is straightforward and clearly mapped to the variables $n$ and $m$.
