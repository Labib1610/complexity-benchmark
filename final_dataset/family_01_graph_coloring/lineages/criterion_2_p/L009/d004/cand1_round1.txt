# Problem B — Factory Tuning

Time limit: 1 s   Memory limit: 256 MB

The factory requires each of its $n$ machines (numbered $1$ to $n$) to be set to a power mode $s_i \in \{1, 2\}$. There are $m$ links between specific pairs of machines.

Each machine $i$ demands a baseline energy $E_i = d_i \cdot s_i^2$, where $d_i$ is the total number of links connected to machine $i$. The factory's total energy demand is the sum of $E_i$ over all $n$ machines.

The interference across the network is denoted by $I = \sum_{(u,v)} s_u s_v$, where the sum contains exactly one term for each of the $m$ links.

A legacy controller will only accept the overall power configuration if the total energy demand is exactly equal to $2I + m$. You must assign a power mode to every machine such that the controller accepts the configuration.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a linked pair of machines.

## Output
If no valid assignment of modes exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
