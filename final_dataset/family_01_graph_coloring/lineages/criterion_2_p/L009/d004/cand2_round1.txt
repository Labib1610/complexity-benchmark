<STATEMENT>
# Problem B — Factory Tuning

Time limit: 1 s   Memory limit: 256 MB

The factory requires each of its $n$ machines to be set to a power mode of either 1 or 2. There are $m$ interference links between specific pairs of machines. 

A legacy controller evaluates the entire network's configuration at once. For each machine that is connected to at least one link, the controller calculates the sum of the power modes of all machines directly linked to it. The controller accepts the configuration if and only if, for every such machine, this sum is exactly twice the number of links connected to it when the machine itself is set to mode 1, and exactly equal to the number of links connected to it when the machine itself is set to mode 2.

You must assign a power mode to every machine such that the overall configuration is accepted by the controller.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a linked pair of machines.

## Output
If no valid assignment of modes exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I removed the edge-local matrix inverse condition and replaced it with a vertex-centric aggregation rule. By defining the acceptance criteria based on the sum of a machine's entire neighborhood, models can no longer bypass the reasoning by simply evaluating a 2x2 local state space; they must logically deduce that reaching the maximum/minimum possible sum forces all neighbors to take the opposite mode.
</RATIONALE>
<PRESERVED_ANSWER>
The condition requires a machine's neighbors to sum to 2d if its mode is 1, forcing all neighbors to be 2; and to d if its mode is 2, forcing all neighbors to be 1, which is mathematically identical to requiring every edge to connect opposite modes.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing), solvable in O(n+m) via BFS/DFS, with the same independent lexicographical choices for each connected component.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "sum of the power modes of all machines directly linked to it" if there are multiple edges between the same pair, though the mathematical deduction holds regardless of graph simplicity.
</RISK>
