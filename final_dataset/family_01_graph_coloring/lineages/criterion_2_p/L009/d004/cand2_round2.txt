<METHOD_DESCRIPTION>Replaces the easily-recognized matrix invertibility condition with a modular arithmetic condition ($3^{x+y} \equiv 7 \pmod{10}$) that mathematically evaluates to exactly the same bipartite constraint ($x \neq y$) but defeats semantic pattern matching on 2x2 matrix determinants.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Factory Tuning

Time limit: 1 s   Memory limit: 256 MB

The factory requires each of its $n$ machines to be set to a power mode of either 1 or 2. There are $m$ interference links between specific pairs of machines. A legacy controller accepts a link between a machine with mode $x$ and a machine with mode $y$ if and only if the base-10 representation of the integer $3^{x+y}$ ends with the digit 7.

You must assign a power mode to every machine such that all $m$ links are accepted by the controller.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a linked pair of machines.

## Output
If no valid assignment of modes exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment. (An assignment $s$ is lexicographically smaller than $t$ if at the first index $i$ where they differ, $s_i < t_i$.)

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the 2x2 matrix invertibility condition with a modular arithmetic property ($3^{x+y}$ ends in 7) that is mathematically equivalent for $x, y \in \{1, 2\}$. This removes the direct pattern-matching affordance of the inverse matrix constraint while forcing models to evaluate the condition and independently discover the $x \neq y$ bipartite constraint. Added a rigorous definition of lexicographical comparison to prevent solver divergence.
</RATIONALE>
<PRESERVED_ANSWER>
For $x, y \in \{1, 2\}$, the sum $x+y$ is 2, 3, or 4; $3^{x+y}$ is 9, 27, or 81, so it ends in 7 if and only if $x+y=3$, meaning $x \neq y$, exactly matching the seed's bipartite constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) on an undirected graph, solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "ends with the digit 7" if they attempt to compute it in a different base, but "base-10 representation" explicitly prevents this.
</RISK>
