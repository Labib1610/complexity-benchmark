We can model this as a graph coloring problem.  

The condition says:  
A link between machines with modes \( x \) and \( y \) is accepted if \( 3^{x+y} \) ends with digit 7.  

Let’s check possible sums:  
- If \( x=1, y=1 \): \( 3^2 = 9 \) → ends with 9 → not accepted.  
- If \( x=1, y=2 \): \( 3^3 = 27 \) → ends with 7 → accepted.  
- If \( x=2, y=1 \): same as above → accepted.  
- If \( x=2, y=2 \): \( 3^4 = 81 \) → ends with 1 → not accepted.  

So the only accepted link is between machines with **different modes**.  

Thus, the problem reduces to:  
We have an undirected graph, and we must assign each vertex a value 1 or 2 such that every edge connects vertices of different values.  
That’s exactly **bipartite graph checking** and coloring.  

We need the lexicographically smallest assignment, so we try to assign 1 whenever possible during BFS/DFS.  

Here’s the implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]  # 1 -> 2, 2 -> 1
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(map(str, color)))
```
