<METHOD_NAME>Global Sum Bound Reduction</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces a local edge-wise constraint with a global sum of pairwise bitwise XORs that must equal its theoretical maximum. Models must deduce that the maximum can only be achieved if every single edge contributes its maximum (3), which requires opposite modes, before they can recognize the underlying graph coloring structure. Superficial pattern matchers may misinterpret the global sum as a Max-Cut or DP optimization problem.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem B — Factory Tuning

Time limit: 1 s   Memory limit: 256 MB

The factory requires each of its $n$ machines to be assigned a power mode of either 1 or 2. There are $m$ interference links between specific pairs of machines. A legacy controller computes the system's total flux by taking the bitwise XOR of the assigned modes for each linked pair of machines, and then summing these $m$ values together. The controller accepts the assignment if and only if this total flux is exactly $3m$.

You must assign a power mode to every machine such that the assignment is accepted by the controller.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a linked pair of machines.

## Output
If no valid assignment of modes exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment. (An assignment $s$ is lexicographically smaller than $t$ if at the first index $i$ where they differ, $s_i < t_i$.)

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The seed's local acceptance condition ($3^{x+y}$ ending in 7) was easily evaluated truth-table style by the models, which then trivially recognized the $x \neq y$ requirement. By reformulating this as a global sum of bitwise XORs that must equal exactly $3m$, the model is forced to reason about the bounds of the sum. It must deduce that since the maximum possible XOR for values in $\{1, 2\}$ is 3, a sum of $m$ terms can only equal $3m$ if every single pair independently achieves the maximum. This prevents immediate pattern-matching to 2-coloring while remaining mathematically equivalent.
</RATIONALE>
<PRESERVED_ANSWER>
The bitwise XOR of two modes in {1, 2} is 3 if they are different, and 0 if they are the same; thus the sum of $m$ such values equals $3m$ if and only if every linked pair has different modes, which perfectly preserves the original valid assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still reduces exactly to finding the lexicographically smallest 2-coloring of the graph components, keeping it safely in P and solvable in O(n+m) time.
</PRESERVED_CLASS>
