**Solution Explanation**

For every edge `{u , v}` we have  

```
node potential of u   = deg(u) * s_u²
node potential of v   = deg(v) * s_v²
edge potential        = 2 * s_u * s_v
```

The *total harmonic potential* is  

```
 Σ_i deg(i) * s_i²  –  Σ_{(u,v)} 2 s_u s_v
```

--------------------------------------------------------------------

#### 1.   Reformulation

```
Σ_i deg(i) * s_i² = Σ_{(u,v)} (s_u² + s_v²)          (each edge counted twice)
total = Σ_{(u,v)} (s_u² + s_v² – 2 s_u s_v)
      = Σ_{(u,v)} (s_u – s_v)²
```

` s_i ∈ {1,2}`  ⇒  `s_u – s_v` is `0` or `±1`.  
Therefore every summand is `0` or `1`.

```
total = number of edges whose ends have different values
```

The controller accepts a configuration **iff** the total equals `m`,
i.e. **every edge must connect vertices with different values**.
So we only have to colour the graph with two colours `1` and `2`
such that adjacent vertices obtain different colours – a classic *bipartite
graph* problem.

--------------------------------------------------------------------

#### 2.   When is it possible?

The graph is colourable **iff** it is bipartite.
While checking bipartiteness we also obtain a 2‑colouring
(`0` / `1`) for each connected component.

If any edge joins two vertices having the same colour → **NO**.

--------------------------------------------------------------------

#### 3.   Lexicographically smallest colour assignment

Different components are independent: for each component we may flip the
two colours (`0↔1`) and still obtain a valid global colouring.
The whole sequence `s₁ … sₙ` is compared lexicographically,
so we treat components in increasing order of their smallest vertex index.

*Observation*  
In a component we can always give the vertex with the smallest index the
value `1` – just choose the orientation that maps its colour to `1`.
All later vertices of the same component are then forced.

Consequences  

* For every component we run a BFS/DFS, receive colours `c(v) ∈ {0,1}`.
* Let `r` be the smallest index in this component (the vertex that started the search).
  If `c(r) = 0` we keep the mapping `0 → 1 , 1 → 2`.  
  If `c(r) = 1` we swap: `1 → 1 , 0 → 2`.

This makes the whole sequence lexicographically minimal.

Isolated vertices are single‑vertex components, they obtain colour `1`.

--------------------------------------------------------------------

#### 4.   Algorithm
```
read n, m
build adjacency list
colour[1…n] = -1               # -1 = unvisited, else 0 / 1
answer[1…n] = 0

for v = 1 … n:
    if colour[v] == -1:
        # start new component, BFS
        queue = [v]; colour[v] = 0
        component = [v]
        while queue not empty:
            x = pop queue
            for each neighbour y of x:
                if colour[y] == -1:
                    colour[y] = colour[x] ^ 1
                    push y
                    component.append(y)
                elif colour[y] == colour[x]:
                    print "NO" and exit   # not bipartite
        # component finished, decide orientation
        root = v                # smallest index of the component
        if colour[root] == 0:   # keep
            for u in component:
                answer[u] = 1 if colour[u]==0 else 2
        else:                   # swap
            for u in component:
                answer[u] = 1 if colour[u]==1 else 2

print "YES"
print answer[1] … answer[n] separated by spaces
```

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints `YES` and a lexicographically smallest
valid assignment exactly when such an assignment exists.

---

##### Lemma 1  
For any assignment `s` with `s_i ∈ {1,2}`,  

```
total harmonic potential = Σ_{edges (u,v)} (s_u – s_v)²
```

**Proof.** As shown in the reformulation part. ∎



##### Lemma 2  
An assignment satisfies the controller (`total = m`) **iff**
for every edge `{u,v}` we have `s_u ≠ s_v`.

**Proof.**  
By Lemma&nbsp;1 each edge contributes `0` if its ends are equal,
`1` otherwise.
The sum equals `m` exactly when every edge contributes `1`,
i.e. its ends are different. ∎



##### Lemma 3  
The algorithm prints `NO` iff the input graph is not bipartite.

**Proof.**  
During BFS every traversed edge connects vertices of opposite
temporary colours `0`/`1`.  
If an edge is found whose ends already have the same colour,
the graph contains an odd cycle ⇒ not bipartite,
and the algorithm prints `NO`.  
Conversely, if the algorithm never meets such a conflict,
the temporary colours give a proper 2‑colouring, so the graph
is bipartite. ∎



##### Lemma 4  
If the algorithm finishes without printing `NO`,
the produced sequence `answer` satisfies `s_u ≠ s_v` for every edge.

**Proof.**  
The BFS guarantees that for every edge `{u,v}` the temporary colours
fulfil `colour[u] ≠ colour[v]`.  
Both possible orientations (keeping or swapping) keep the relation
`answer[u] ≠ answer[v]` because they only replace `0` by `1` and `1` by `2`
(or vice‑versa) uniformly inside the component. ∎



##### Lemma 5  
For each connected component the algorithm chooses the lexicographically
smallest colour assignment among the two feasible ones.

**Proof.**  
Inside a component the only freedom is swapping the two colour classes.
The vertex with smallest index in the component is the first position of
the whole global sequence belonging to this component.
The algorithm forces this vertex to value `1`; the alternative orientation
would give it value `2`, which is larger.
Thus the chosen orientation is lexicographically smaller than the other
one, and no other feasible assignment exists. ∎



##### Lemma 6  
The whole sequence `answer` is the lexicographically smallest feasible
assignment for the whole graph.

**Proof.**  
Consider the components ordered by their smallest vertex index.
By Lemma&nbsp;5 the algorithm makes the first differing position *inside*
the current component as small as possible, while all earlier positions
(belonging to earlier components) are already fixed to their minima.
Therefore after processing all components no other feasible global assignment
can be lexicographically smaller. ∎



##### Theorem  
The algorithm outputs  

* `NO`  iff no assignment of `{1,2}` values makes the controller accept,
* otherwise `YES` followed by the lexicographically smallest such
  assignment.

**Proof.**  

*If the algorithm prints `NO`.*  
By Lemma&nbsp;3 the graph is not bipartite, i.e. there is no
2‑colouring with different colours on each edge.
By Lemma&nbsp;2 any acceptable assignment must be such a 2‑colouring,
hence none exists.

*If the algorithm prints `YES`.*  
The graph is bipartite (Lemma&nbsp;3).  
Lemma&nbsp;4 shows the produced assignment satisfies the edge condition,
hence by Lemma&nbsp;2 the total harmonic potential equals `m`.  
Finally Lemma&nbsp;6 guarantees this assignment is the lexicographically
smallest among all valid ones.

Thus the theorem holds. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all vertices*: each vertex and edge processed once → `O(n + m)`.  
*Additional arrays*: `O(n)`.

Total time `O(n + m)`, memory `O(n + m)`, well inside the limits
(`n, m ≤ 2·10⁵`).

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # temporary 0 / 1
    ans = [0] * (n + 1)              # final 1 / 2

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # new component, BFS
        q = deque([start])
        colour[start] = 0
        comp = [start]

        while q:
            v = q.popleft()
            cv = colour[v]
            for nb in adj[v]:
                if colour[nb] == -1:
                    colour[nb] = cv ^ 1
                    q.append(nb)
                    comp.append(nb)
                elif colour[nb] == cv:
                    sys.stdout.write("NO")
                    return

        # decide orientation: smallest index = start
        if colour[start] == 0:      # keep mapping 0->1, 1->2
            for v in comp:
                ans[v] = 1 if colour[v] == 0 else 2
        else:                       # swap
            for v in comp:
                ans[v] = 1 if colour[v] == 1 else 2

    out = ["YES\n"]
    out.append(' '.join(str(ans[i]) for i in range(1, n + 1)))
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```

and conforms to the required input‑output format.
