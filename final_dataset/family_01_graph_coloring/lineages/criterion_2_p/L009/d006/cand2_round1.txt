<STATEMENT>
# Problem B — Factory Tuning

Time limit: 1 s   Memory limit: 256 MB

The factory requires each of its $n$ machines to be set to a power mode of either 1 or 2. There are $m$ interference links between specific pairs of machines. 

For a link between a machine with mode $x$ and a machine with mode $y$, the raw link stress is defined as the integer $x^2 + y^2$. The link's adjusted diagnostic value is calculated by taking the bitwise XOR (commonly denoted as $\oplus$ or `^`) of its raw link stress and the integer 7.

The factory's overall stability score is the sum of these adjusted diagnostic values across all $m$ links. A legacy controller accepts the configuration if and only if this overall stability score is exactly equal to $2m$. (If $m=0$, the score is 0, which is accepted).

You must assign a power mode to every machine such that the configuration is accepted by the controller.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a linked pair of machines.

## Output
If no valid assignment of modes exists, print a single line `NO`.
Otherwise print `YES`, then a second line with $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment. (An assignment $s$ is lexicographically smaller than $t$ if at the first index $i$ where they differ, $s_i < t_i$.)

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The seed problem used a product of positive integers equal to $5^m$, which trivially forces every term to be 5 because 5 is prime. I replaced this with a sum of a bitwise XOR function over the raw values. This removes the prime factorization affordance, forcing models to manually evaluate the small finite domain of possible raw values to deduce that the minimum possible adjusted value is 2, thereby proving that every edge must have an adjusted value of 2 (and thus a raw value of 5).
</RATIONALE>
<PRESERVED_ANSWER>
The possible raw link stresses are 2, 5, and 8; their bitwise XORs with 7 are 5, 2, and 15 respectively, so a sum of $2m$ over $m$ links is only mathematically possible if every link evaluates to 2, which requires a raw stress of 5 (modes 1 and 2), perfectly matching the original acceptance condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core logical requirement remains identical (every link must connect nodes of different modes), so the problem is still solvable in $O(n+m)$ time via BFS/DFS bipartite coloring.
</PRESERVED_CLASS>
<RISK>
None. The bitwise XOR operation and the sum condition are unambiguously defined using standard mathematical terminology and notation.
</RISK>
