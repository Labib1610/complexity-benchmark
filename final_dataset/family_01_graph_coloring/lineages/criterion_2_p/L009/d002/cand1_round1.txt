# Problem B — Factory Tuning

Time limit: 1 s   Memory limit: 256 MB

The factory requires each of its $n$ machines to be set to a power mode, which can be either 1 or 2. With $n$ machines, there are $2^n$ possible mode configurations to consider. 

Given $m$ interference links, search this space to assign each machine a power mode such that for every linked pair of machines, their modes $x$ and $y$ maintain stability. Stability is achieved if and only if three times their combined production (the product of their modes, $x \cdot y$) perfectly matches twice their combined draw (the sum of their modes, $x + y$). 

If no valid assignment exists in the configuration space, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a linked pair of machines.

## Output
If no valid assignment exists in the configuration space, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the explicit bitwise XOR condition with a mathematically equivalent requirement ($3xy = 2(x+y)$) framed as a factory production-versus-draw rule. This forces the model to evaluate the condition over the domain $\{1,2\}$ to discover that it strictly requires $x \neq y$, preventing immediate pattern matching to bipartite graph coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The equation $3xy = 2(x+y)$ for variables $x,y \in \{1,2\}$ is satisfied only by the pairs $(1,2)$ and $(2,1)$, which is exactly identical to the original $x \oplus y = 3$ requirement, keeping all valid assignments identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding a valid 2-coloring of a graph (or determining if it is bipartite) and selecting the lexicographically first valid coloring, which is solvable in $O(n+m)$ time using Breadth-First Search.
</PRESERVED_CLASS>
