# Problem B — Factory Tuning

Time limit: 1 s   Memory limit: 256 MB

The factory requires each of its $n$ machines to be set to a power mode, which can be either 1 or 2. With $n$ machines, there are $2^n$ possible mode configurations to consider. Given $m$ interference links, search this space to assign each machine a power mode such that for every linked pair of machines, the bitwise XOR of their power modes evaluates to exactly 3. If no valid assignment exists in the configuration space, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a linked pair of machines.

## Output
If no valid assignment exists in the configuration space, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit inequality constraint ("no conflicting pair shares a shift") with a mathematically equivalent bitwise operation ($s_u \oplus s_v = 3$). This forces the models to algebraically deduce that the constraint still strictly enforces $s_u \neq s_v$ for values in $\{1,2\}$, preventing them from immediately pattern-matching the problem to bipartite graph 2-coloring. I ignored the automated suggestion to add a global condition ("must use both shifts") because doing so would change the correct output for edgeless graphs, which violates the IDENTICAL ANSWERS constraint.
</RATIONALE>
<PRESERVED_ANSWER>
Every valid assignment remains exactly the same because for $s_u, s_v \in \{1,2\}$, the condition $s_u \oplus s_v = 3$ is strictly logically equivalent to $s_u \neq s_v$.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to 2-coloring (or 2-SAT) on a graph, as the core constraint between connected nodes is still a simple pairwise inequality, keeping it in P and solvable in linear time via BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the bitwise XOR requirement as implying a more complex multi-variable boolean satisfiability problem or GF(2) system rather than recognizing it as a simple pairwise inequality constraint.
</RISK>
