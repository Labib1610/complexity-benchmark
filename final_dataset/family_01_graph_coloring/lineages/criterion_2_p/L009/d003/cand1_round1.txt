<STATEMENT>
# Problem B — Factory Tuning

Time limit: 1 s   Memory limit: 256 MB

The factory requires each of its $n$ machines to be assigned a power mode of either 1 or 2. There are $m$ interference links, each connecting a pair of machines.

For each machine $i$, let $s_i \in \{1, 2\}$ be its assigned power mode. Let $L_i$ be the collection of links connected to machine $i$, and let $d_i$ be the number of links in $L_i$. (A link connecting a machine to itself counts as exactly one link in $L_i$). 

Let $P_i$ be the sum of the power modes of the machines at the other end of each link in $L_i$. Specifically, if multiple links connect the same two machines, the connected machine's mode is added once for each link. For a self-loop on machine $i$, the machine at the other end is $i$ itself, so $s_i$ is added to $P_i$.

The factory's legacy controller evaluates the system by checking a stability equation for each machine. It will only accept the overall configuration if, for every machine $i$, the following holds:
$P_i + d_i \cdot s_i = 3 d_i$

You must assign a power mode to every machine such that the controller accepts the configuration.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — a linked pair of machines.

## Output
If no valid assignment of modes exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Removed the local pairwise equation `3xy = 2(x + y)` which models easily brute-forced over `{1, 2}` to discover the `x != y` (bipartite) constraint. Replaced it with a mathematically equivalent neighborhood sum equation `P_i + d_i * s_i = 3 d_i`. This forces models to genuinely reason about the bounds of `P_i` to deduce that all neighbors must have the opposite mode, blocking the shortcut of evaluating a static condition on four possible pairs.
</RATIONALE>
<PRESERVED_ANSWER>
The equation P_i + d_i * s_i = 3 d_i for s_i in {1,2} can only be satisfied if every neighbor has mode 3 - s_i, making it strictly equivalent to the original requirement that linked machines have different modes.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) on an undirected graph, solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret how self-loops contribute to P_i, though explicit parentheticals were added to define that a self-loop adds s_i to P_i exactly once.
</RISK>
