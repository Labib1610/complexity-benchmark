We need to analyze the condition for a link to be accepted.

The matrix is:

\[
\begin{pmatrix}
x & 1 \\
1 & y
\end{pmatrix}
\]

Its determinant is:

\[
xy - 1
\]

For the matrix to be invertible with integer inverse, we need:

1. \(\det = xy - 1 \neq 0\)
2. The inverse must have integer entries.

The inverse is:

\[
\frac{1}{xy-1}
\begin{pmatrix}
y & -1 \\
-1 & x
\end{pmatrix}
\]

For integer entries, we need \(xy - 1\) to divide both \(y\) and \(x\).  
Since \(x, y \in \{1, 2\}\), we check:

- If \(x=1, y=1\): det = 0 → not invertible.
- If \(x=1, y=2\): det = 1 → inverse integer.
- If \(x=2, y=1\): det = 1 → inverse integer.
- If \(x=2, y=2\): det = 3 → inverse has fractions (since 3 doesn't divide 2).

So the only valid pairs are \((1,2)\) and \((2,1)\).  
That means every edge must connect two machines with **different** modes.

Thus the problem reduces to:  
Can we 2-color the graph (bipartite check)?  
If yes, output the lexicographically smallest assignment (with 1 and 2).

Lexicographically smallest means we try to assign 1 as much as possible, but if the graph is bipartite, we can choose the coloring that gives 1 to the first node, then propagate.

We can do BFS/DFS, assign 1 to unvisited nodes, and if conflict → NO.

Let's implement.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
