**Solution Explanation**

For a link between machines `u , v` let their modes be `x , y ∈ {1,2}`.
The controller accepts the link iff the matrix  

```
| x  1 |
| 1  y |
```

is invertible **and** its inverse consists only of integers.

The determinant is `det = x·y – 1`.  
The inverse is  

```
1/det * |  y  -1 |
        | -1   x |
```

All four entries must be integers, therefore `det` must divide `1`,
hence `det = ±1`.

```
x·y – 1 = ±1   →   x·y = 0 or 2
```

With `x , y ∈ {1,2}` the only possibilities are

* `x = 1 , y = 2`   (det = 1)
* `x = 2 , y = 1`   (det = 1)

All other pairs give `det = 0` or `3`, which are not ±1.

So **every link must connect a machine of mode 1 with a machine of mode 2**.
The whole problem is exactly the classic *graph bipartition* problem.

--------------------------------------------------------------------

#### 1.   Graph model
* vertices – machines `1 … n`
* edges – the `m` interference links

We have to 2‑colour the graph with colours `{1,2}`.
If the graph is not bipartite → answer `NO`.

--------------------------------------------------------------------

#### 2.   Lexicographically smallest colouring
A connected component can be coloured in two ways (swap the two colour
classes).  
When we process vertices in increasing order `1 … n`,
the first still uncoloured vertex `v` belongs to some component `C`.
To obtain the lexicographically smallest overall sequence we must give
`v` colour `1` (if possible).  
Exactly one of the two orientations of `C` gives colour `1` to `v`,
the other gives colour `2`.  
Choosing the former is optimal, because any later vertex is less
significant in lexicographic order.

Therefore the algorithm is:

```
for v = 1 … n
    if v not coloured yet
        BFS/DFS the whole component,
        store temporary colours 0/1,
        if temporary colour of v == 0:
                map 0 → 1 , 1 → 2
        else:
                map 0 → 2 , 1 → 1
        write the final colours of all vertices of the component
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `YES` and the lexicographically
smallest valid assignment iff such an assignment exists.

---

##### Lemma 1  
A colouring satisfies all links **iff** it is a proper 2‑colouring of the
graph (adjacent vertices have different colours).

**Proof.** From the analysis of the matrix we saw that a link is accepted
iff its endpoints have modes `{1,2}` in any order, i.e. they are different.
∎



##### Lemma 2  
During the processing of a component `C` the algorithm always produces a
proper 2‑colouring of `C`.

**Proof.** The BFS assigns temporary colours `0/1` exactly as a standard
bipartite check: each edge forces opposite temporary colours.
If a conflict is found, the graph is not bipartite and the algorithm
terminates with `NO`.  
Otherwise the temporary colours are a proper 2‑colouring.
The final mapping (`0→1,1→2` or the swapped one) keeps the property
“different temporary colours → different final colours”. ∎



##### Lemma 3  
For the component `C` containing the smallest uncoloured vertex `v`,
the algorithm chooses the orientation that gives `v` colour `1`.

**Proof.** By construction we look at the temporary colour of `v`.
If it is `0` we map `0→1`; otherwise we map `0→2`. In both cases the
final colour of `v` becomes `1`. ∎



##### Lemma 4  
Let `S` be the sequence produced by the algorithm and `T` any other
valid sequence. Then `S` is lexicographically not larger than `T`.

**Proof.** Consider the first index `i` where `S` and `T` differ.
All vertices `< i` belong to components already processed, therefore
`S` and `T` coincide on them.
Vertex `i` is the smallest vertex of its component `C`.  
By Lemma&nbsp;3 the algorithm gave `i` colour `1`.  
Any valid sequence must give `i` either `1` or `2`.  
If `T_i = 2` then `S_i = 1 < 2` and `S` is lexicographically smaller.
If `T_i = 1` then `S_i = T_i`. This contradicts the choice of `i` as the
first differing position. Hence the case cannot happen.
Thus `S` is not larger than any other valid sequence. ∎



##### Lemma 5  
If the graph is bipartite, the algorithm outputs a valid assignment.

**Proof.** By Lemma&nbsp;2 each component is coloured properly, therefore
all edges connect vertices of different final colours.
By Lemma&nbsp;1 this satisfies every link. ∎



##### Theorem  
The program prints  

* `NO` iff no assignment of modes exists,  
* otherwise `YES` and the lexicographically smallest assignment.

**Proof.**  
*If the program prints `NO`.* This happens only when a conflict is found
during BFS, i.e. the graph contains an odd cycle and is not bipartite.
By Lemma&nbsp;1 no assignment can satisfy all links, so indeed none
exists.

*If the program prints `YES`.* Then no conflict occurred, the graph is
bipartite. By Lemma&nbsp;5 the produced assignment is valid.
By Lemma&nbsp;4 it is lexicographically minimal among all valid
assignments.

Conversely, if a valid assignment exists, the graph is bipartite,
so the program never meets a conflict and prints `YES`. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis
*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge visited once → `O(n + m)` time.  
Overall: **`O(n + m)` time**, **`O(n + m)` memory**, well within limits
(`n, m ≤ 2·10⁵`).

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [0] * (n + 1)          # final answer, 0 = unassigned, else 1 or 2
    temp = [ -1 ] * (n + 1)         # temporary 0/1 during BFS
    from collections import deque

    for start in range(1, n + 1):
        if colour[start]:
            continue
        # BFS this component
        q = deque([start])
        temp[start] = 0
        comp = [start]
        ok = True
        while q:
            v = q.popleft()
            for to in adj[v]:
                if temp[to] == -1:
                    temp[to] = temp[v] ^ 1
                    q.append(to)
                    comp.append(to)
                elif temp[to] == temp[v]:
                    print("NO")
                    return
        # decide orientation so that start gets colour 1
        if temp[start] == 0:
            map0, map1 = 1, 2
        else:
            map0, map1 = 2, 1
        for v in comp:
            colour[v] = map0 if temp[v] == 0 else map1
            temp[v] = -1          # reset for possible future use (not needed)

    # all done
    print("YES")
    print(' '.join(str(colour[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
