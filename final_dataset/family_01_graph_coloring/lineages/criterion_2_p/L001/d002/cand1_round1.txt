# Problem B — Power Bus Redundancy

Time limit: 1 s   Memory limit: 256 MB

An orbital station contains $n$ life-support modules. The automated diagnostic system must configure the backup network by assigning a redundancy tier to each module. The assigned tier for any module must be a positive integer that evenly divides $2$.

The safety protocol includes $m$ critical links. Each link identifies two modules that serve as mutual backups. To guarantee operational stability, the configuration must satisfy a strict numerical condition: for any two modules $u$ and $v$ connected by a critical link, the bitwise XOR of their assigned tier values must equal exactly $3$.

You must determine whether a valid tier assignment exists for all modules. When multiple valid assignments are possible, the diagnostic system mandates selecting the configuration that produces the lexicographically smallest sequence of tier values, ordered by module number from $1$ to $n$.

## Input
The first line of the input contains two integers $n$ and $m$. The station's engineering specifications guarantee at least one module, while its maximum structural limit is two hundred thousand modules. The number of critical links $m$ ranges from zero up to exactly the station's maximum structural limit for modules.
Each of the next $m$ lines contains two integers $u$ and $v$ — a redundancy link between module $u$ and module $v$.

## Output
If there is no way to assign the tier values without violating the safety protocol, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers separated by spaces, where the $i$-th integer is the tier value assigned to the $i$-th module, representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
