# Problem B — Quantum Resonance Network

Time limit: 1 s   Memory limit: 256 MB

A research facility is testing a new quantum communication network consisting of $n$ nodes. Each node must be calibrated into one of two quantum states, represented by an integer value $s_i \in \{1, 2\}$.

The network contains $m$ entanglement links, each connecting two nodes. For the network to remain stable, every pair of linked nodes $u$ and $v$ must satisfy a specific resonance condition: the sum of the cubes of their assigned state values must be a multiple of 9. That is, $(s_u^3 + s_v^3)$ must be evenly divisible by 9.

You must determine whether a stable calibration exists for all nodes. If multiple stable calibrations are possible, the system mandates selecting the one that minimizes the network's total energy footprint. The energy footprint $E$ is highly sensitive to the node indices and is calculated using the formula:
$$E = \sum_{i=1}^{n} s_i \cdot 2^{n-i}$$

Your task is to find a valid state assignment that minimizes this energy footprint, or report that no such assignment exists.

## Input
The first line of the input contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — an entanglement link between node $u$ and node $v$.

## Output
If there is no way to assign the states without violating the resonance condition, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers separated by spaces, where the $i$-th integer is the state ($1$ or $2$) assigned to the $i$-th node, representing the valid configuration that minimizes the energy footprint.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was completely reframed into a quantum network scenario to remove all vocabulary associated with graph coloring or bipartiteness. The explicit constraint $x \cdot y = 2$ was replaced with the mathematically equivalent but structurally opaque $(s_u^3 + s_v^3) \pmod 9 = 0$. The explicit tie-breaker "lexicographically smallest" was replaced with the algebraic equivalent of minimizing a base-2 polynomial, forcing the model to deduce that this strictly prioritizes smaller values at lower indices.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $(s_u^3 + s_v^3) \pmod 9 = 0$ for $s_i \in \{1, 2\}$ is only satisfied by $(1, 2)$ and $(2, 1)$, strictly enforcing $s_u \neq s_v$ just like the original product constraint; minimizing the given base-2 polynomial is mathematically identical to finding the lexicographically smallest sequence, ensuring identical outputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) on an undirected graph, which is solvable in linear $O(n+m)$ time using Breadth-First Search.
</PRESERVED_CLASS>
