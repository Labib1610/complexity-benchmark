We can model this as a graph problem.  
Each module’s tier is either 1 or 2, and for each edge (u, v), we need:

```
tier[u] XOR tier[v] = 3
```

Since the only possible values are 1 and 2, and  
`1 XOR 2 = 3`, this means connected modules must have **different** tiers.

So the problem reduces to checking if the graph is bipartite, and if so, output the lexicographically smallest assignment.

We can do a BFS/DFS, assigning tier 1 to the first node, then alternating.  
To get lexicographically smallest, we process nodes in order and assign the smallest possible value that doesn’t conflict.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
# Convert 0 -> 1, 1 -> 2
print(' '.join(str(c + 1) for c in color))
```
