# Problem B — Phase Isolation Protocol

Time limit: 1 s   Memory limit: 256 MB

An orbital station is equipped with $n$ life-support modules. The engineering bay allocates exactly one processing unit per module from a total inventory of $200,000$ processing units. The station requires at least one module to remain operational.

Each module must be assigned a discrete phase state, restricted to the integer values $1$ or $2$. 

The station's safety protocol defines $m$ interference links. The system's memory buffer can store a maximum of $200,000$ such links, though a scenario with zero links is possible. Each link specifies a pair of modules. To prevent destructive resonance, the protocol mandates that for every interference link, the sum of the phase states of the two connected modules must equal exactly $3$.

Determine if it is possible to assign a phase state to each module such that all interference links are safe. If multiple valid configurations exist, the system requires the one that is lexicographically smallest when the phase states are listed in order of the module numbers from $1$ to $n$.

## Input
The first line contains two integers $n$ and $m$, bounded by the physical hardware and memory limits described in the station specifications.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ — denoting an interference link between module $u$ and module $v$.

## Output
If there is no valid phase state assignment that satisfies the protocol, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers separated by spaces, where the $i$-th integer is the phase state ($1$ or $2$) assigned to the $i$-th module, representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit bounds in the input section were removed and replaced with physical capacity limits in the description text, forcing the reader to extract $1 \ge n \ge 200,000$ and $0 \ge m \ge 200,000$ from the scenario. Additionally, the direct instruction to assign modules to "different buses" was replaced with an algebraic constraint where the sum of their phase states (restricted to 1 or 2) must equal exactly 3. This forces the model to deduce the inequality constraint (and thus the graph 2-coloring structure) rather than pattern-match on standard phrasing.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that values from {1, 2} sum to 3 is mathematically identical to requiring that the two values be different, meaning the exact same assignments are valid and the lexicographical tie-breaker yields the same unique result.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) on an undirected graph, which is solvable in O(V+E) time using Breadth-First Search or Depth-First Search, keeping it firmly in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the indirect bounds if they fail to link the inventory and memory limits to $n$ and $m$, though the text makes this mapping very direct.
</RISK>
