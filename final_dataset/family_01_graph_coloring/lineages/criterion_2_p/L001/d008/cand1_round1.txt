<STATEMENT>
# Problem B — Network Transceivers

Time limit: 1 s   Memory limit: 256 MB

You are configuring a communication network comprising $n$ servers and $m$ communication links. Each link connects a specific pair of servers.

Every communication link between a server $u$ and a server $v$ must be tuned to a continuous phase angle. Let $\theta_{u,v}$ be the phase angle (in radians) of the link evaluated from $u$ to $v$. When evaluated in the reverse direction, the phase angle is inherently shifted by a half-cycle, meaning $\theta_{v,u} = \theta_{u,v} + \pi$.

Each server must be assigned a hardware type $T \in \{1, 2\}$.

A configuration is valid if it is possible to assign a phase angle to every link such that for every server $i$, its assigned type $T_i$ satisfies the following equation for every link connecting server $i$ to a server $j$:
$$T_i = 1.5 + 0.5 \cos(\theta_{i,j})$$
where $\theta_{i,j}$ is the phase angle of that specific link evaluated from $i$ to $j$.

If a server has no links connected to it, the tuning equation is vacuously satisfied for both types, but it must still be assigned exactly one type.

You must determine if a valid configuration is possible. If there are multiple valid assignments of hardware types, you must output the assignment that produces the lexicographically smallest sequence of types when listed in order from server $1$ to server $n$.

## Input
The first line of the input contains two integers $n$ and $m$. The hardware budget provisions for up to $200,000$ servers and up to $200,000$ links, establishing the maximum capacity for $n$ and $m$. There is always at least one server, and there can be as few as zero links.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ — representing a communication link between server $u$ and server $v$.

## Output
If no such valid configuration is possible, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers, where the $i$-th integer is the hardware type ($1$ or $2$) assigned to server $i$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit discrete polarity constraint ($D \in \{1, -1\}$) and its corresponding type equation with a continuous phase angle ($\theta$) and a trigonometric equation ($T_i = 1.5 + 0.5 \cos(\theta_{i,j})$). This mathematically enforces the exact same 2-coloring requirement (since $\cos(\theta) = \pm 1$ and $\cos(\theta + \pi) = -\cos(\theta)$), but entirely conceals the discrete bipartite nature from surface pattern matching. I also applied Strategy S07 to express the numeric bounds as hardware budget capacities rather than bare inequalities.
</RATIONALE>
<PRESERVED_ANSWER>
The trigonometric equation forces every connected pair of servers to have distinct types from $\{1, 2\}$, which is mathematically identical to the original polarity constraint, thus preserving all valid configurations and the lexicographically smallest tie-breaker constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains logically equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in linear time using BFS, keeping it firmly in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the continuous phase angle as requiring floating-point arithmetic or complex numbers, though the strict $T \in \{1, 2\}$ requirement fundamentally restricts the valid cosine values to exactly $1$ and $-1$.
</RISK>
