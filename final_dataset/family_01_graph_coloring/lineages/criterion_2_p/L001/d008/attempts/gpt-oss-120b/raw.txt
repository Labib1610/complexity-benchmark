**Solution Explanation**

For every filter we have to choose one of the two modes  

* mode `1`  →  transformation `f(x)= x`   (sign `+1`)  
* mode `2`  →  transformation `f(x)= -x`  (sign `-1`)

For a synchronization pair `{u,v}` we need  

```
f_u ( f_v (x) ) = -x      for all x
```

`f_u` and `f_v` are only `+x` or `-x`, therefore  

```
sign_u * sign_v = -1          (sign = +1 for mode 1, -1 for mode 2)
```

So the two filters must have **different signs**.  
The whole set of pairs is a graph, the condition is exactly that the graph is
* bipartite* (its vertices can be coloured with two colours such that every edge
joins vertices of different colours).

If the graph is not bipartite there is no valid configuration.

--------------------------------------------------------------------

#### Lexicographically smallest assignment  

If the graph is bipartite, each connected component has **two** possible
colourings – they are each other’s colour swap.
The components are independent, therefore we may decide for every component
which of the two colourings to use.

Lexicographic order compares the sequence `mode[1] , mode[2] , …`.
The first position where two global assignments differ decides which one is
smaller.  
Consequently, for each component we only have to look at the **smallest vertex
index inside this component**:

*If we can give this vertex mode `1`, we must do it – otherwise the whole
assignment would be larger.*

Hence for a component we

1. run BFS/DFS, colour vertices `0 / 1` arbitrarily (starting vertex colour `0`);
2. remember all vertices of the component;
3. let `v0 = min(component)`.  
   If `colour[v0] == 0` we map colour `0 → mode 1` and colour `1 → mode 2`;  
   otherwise we swap the mapping.

All other vertices of the component receive their modes according to this
mapping. This yields the lexicographically smallest global assignment.

Isolated vertices (no incident edges) are components of size 1; the rule above
gives them mode 1, which is optimal.

--------------------------------------------------------------------

#### Algorithm
```
read n, m
build adjacency list
colour[1..n] = -1   // -1 = unvisited
answer[1..n] = 0

for each vertex v = 1 .. n
    if colour[v] == -1
        // new component
        queue ← [v]
        colour[v] = 0
        comp = []                // vertices of this component
        while queue not empty
            x = pop queue
            comp.append(x)
            for each neighbour y of x
                if colour[y] == -1
                    colour[y] = colour[x] ^ 1
                    push y
                else if colour[y] == colour[x]
                    print "NO" and exit   // not bipartite
        // component finished, decide orientation
        v0 = min(comp)
        if colour[v0] == 0
            map0 = 1; map1 = 2
        else
            map0 = 2; map1 = 1
        for each vertex u in comp
            answer[u] = map0 if colour[u]==0 else map1

print "YES"
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise prints `YES` and the lexicographically smallest valid assignment.

---

##### Lemma 1  
During BFS, if the algorithm discovers an edge whose endpoints have the same
colour, the graph is not bipartite and no assignment satisfies all pairs.

**Proof.**  
Having the same colour means the algorithm forced both endpoints to have the
same sign (`+1` or `-1`). The edge requires opposite signs, contradiction.
Thus the graph contains an odd cycle and is not bipartite, so the required
condition cannot be fulfilled. ∎



##### Lemma 2  
If the algorithm finishes BFS of a component without contradiction, the
obtained colouring (`0/1`) is a proper bipartition of that component.

**Proof.**  
BFS starts with colour `0` for the first vertex and always assigns the opposite
colour to every neighbour. By induction on the BFS order, every processed edge
joins vertices of different colours. Since all vertices of the component are
reached, the whole component is properly coloured. ∎



##### Lemma 3  
For a component `C` let `v0 = min(C)`.  
The algorithm chooses the orientation (mapping colours to modes) that gives
`mode[v0] = 1`. This orientation yields the smallest possible prefix
`mode[1..v0]` among all valid assignments for the whole graph.

**Proof.**  
All vertices with index `< v0` belong to earlier components, already fixed.
Any valid global assignment must respect the bipartition of `C`; the only
freedom is swapping the two colour classes.  
If we assign `mode[v0]=2`, the prefix up to `v0` is larger than the prefix
obtained by assigning `mode[v0]=1`, because the first differing position is
`v0` and `1 < 2`. Therefore the orientation with `mode[v0]=1` is strictly
lexicographically smaller than the opposite orientation, and no other
orientation exists. ∎



##### Lemma 4  
After processing all components, the array `answer` produced by the algorithm
is a valid assignment (all edges satisfy the condition).

**Proof.**  
By Lemma&nbsp;2 each component is bipartite with colours `0/1`. The algorithm
maps the two colours to the two modes (maybe swapped). Hence any edge inside
the component connects vertices of different modes, i.e. opposite signs, so
`sign_u * sign_v = -1`. Edges never connect different components, therefore all
edges satisfy the requirement. ∎



##### Lemma 5  
The assignment `answer` is lexicographically minimal among all valid
assignments.

**Proof.**  
Consider the components in increasing order of their minimal vertex index.
By Lemma&nbsp;3, for the first component the algorithm chooses the orientation
that gives the smallest possible prefix. For the second component, the prefix
up to the smallest vertex of that component is already fixed (by earlier
components); again Lemma&nbsp;3 guarantees the smallest continuation, and so on.
Induction over the components shows that no other valid assignment can be
lexicographically smaller. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no assignment of modes satisfying all synchronization pairs exists;  
* otherwise `YES` and the lexicographically smallest such assignment.

**Proof.**  

*If the algorithm prints `NO`*: this happens only when Lemma&nbsp;1 detects a
same‑colour edge, i.e. the graph is not bipartite. A non‑bipartite graph cannot
be coloured with opposite signs on every edge, so no assignment exists.

*If a valid assignment exists*: the graph is bipartite, therefore BFS never
fails (Lemma&nbsp;1 never triggers). By Lemma&nbsp;4 the produced `answer`
satisfies all edges. By Lemma&nbsp;5 it is the lexicographically smallest
among all such assignments. Hence the algorithm prints `YES` and this
assignment. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all vertices*: each vertex and each edge is processed once →  
`O(n + m)` time, `O(n)` additional memory for colour and queue.  

Overall: **Time `O(n + m)`**, **Memory `O(n + m)`**, well within the limits
(`n, m ≤ 2·10⁵`).

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 = unvisited, 0/1 = bipartite colour
    answer = [0] * (n + 1)

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp = []
        while q:
            x = q.popleft()
            comp.append(x)
            for y in adj[x]:
                if colour[y] == -1:
                    colour[y] = colour[x] ^ 1
                    q.append(y)
                elif colour[y] == colour[x]:
                    print("NO")
                    return
        # decide orientation for lexicographically smallest result
        v0 = min(comp)
        if colour[v0] == 0:
            map0, map1 = 1, 2
        else:
            map0, map1 = 2, 1
        for v in comp:
            answer[v] = map0 if colour[v] == 0 else map1

    # all components processed successfully
    print("YES")
    print(' '.join(str(answer[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
