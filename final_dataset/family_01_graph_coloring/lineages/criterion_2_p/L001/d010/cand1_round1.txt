<STATEMENT>
# Problem B — Resonant Pipeline Calibration

Time limit: 1 s   Memory limit: 256 MB

You are configuring a fluid processing pipeline consisting of $n$ control valves. Each valve $i$ must be set to a specific pressure multiplier, denoted by $m_i$. You must configure each valve into exactly one of two operational modes:
* **Mode 1**: $m_i = 1$
* **Mode 2**: $m_i = 2$

The pipeline design includes $m$ synchronization links. Each link specifies two valves $u$ and $v$ that share a pressure-balancing chamber. To prevent chamber rupture, any two valves connected by a synchronization link must be capable of achieving a stable harmonic state.

A stable harmonic state is achieved if and only if there exists a pair of **positive integers** $(P, Q)$ that satisfy both of the following calibration equations simultaneously:
1. $P \cdot m_u = Q \cdot m_v$
2. $P \cdot Q = 2$

If a valve is not part of any synchronization link, the harmonic condition is vacuously satisfied for that valve, but it must still be assigned a mode of exactly 1 or 2.

You must determine if there is a valid configuration of modes for all $n$ valves. If there are multiple valid configurations, you must choose the one that yields the lexicographically smallest sequence of modes (where each mode is represented as $1$ or $2$) when listed in order from valve $1$ to valve $n$.

## Input
The first line of the input contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — indicating a synchronization link between valve $u$ and valve $v$.

## Output
If there is no valid configuration, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers separated by spaces, where the $i$-th integer is the mode ($1$ or $2$) assigned to the $i$-th valve, representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Removed the explicit matrix multiplication and the semantic cues about "identity", "exchange", and "opposite modes". Replaced the edge constraint with a local system of Diophantine equations ($P \cdot m_u = Q \cdot m_v$ and $P \cdot Q = 2$ for positive integers $P, Q$). This forces the models to algebraically solve the system to deduce that $m_u \neq m_v$, preventing pattern-matching on graph coloring vocabulary while keeping the underlying mathematical constraint identical.
</RATIONALE>
<PRESERVED_ANSWER>
The Diophantine system $P \cdot m_u = Q \cdot m_v$ and $P \cdot Q = 2$ over positive integers requires $\{P, Q\} = \{1, 2\}$, which exactly enforces $m_u \neq m_v$ for $m_i \in \{1, 2\}$, preserving the exact same valid configurations and lexicographical tie-breaking rule as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem remains finding a valid 2-coloring of the graph and choosing the lexicographically smallest one per connected component, which is solvable in $O(n+m)$ time using standard BFS traversal.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the existence of $(P, Q)$ as a global property rather than a per-link property, though the phrasing "any two valves connected by a synchronization link must be capable..." strongly implies it is evaluated locally per link.
</RISK>
