<METHOD_NAME>
Edge-Role Consistency Shift
</METHOD_NAME>
<METHOD_DESCRIPTION>
Instead of asking the model to assign global states (transmitter/receiver) to vertices which implies a directed edge, this rewrite asks the model to assign asymmetric roles (provider/consumer) to the endpoints of each individual edge. The bipartite restriction is then enforced indirectly via a "uniformity rule" that requires each vertex to have the same role across all its incident edges. This breaks the direct pattern-match to vertex 2-coloring.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<STATEMENT>
# Problem B — Network Transceivers

Time limit: 1 s   Memory limit: 256 MB

You are configuring a communication network consisting of $n$ servers and $m$ communication links. Each link connects a specific pair of servers.

For each link, you must designate one of its two endpoints to act as the *provider* for that link, and the other endpoint to act as the *consumer* for that link. 

To prevent hardware conflicts, the network must satisfy a strict uniformity rule: no server is allowed to act as a provider for some of its links and a consumer for others. If a server is connected to one or more links, it must either act as the provider for all of them, or act as the consumer for all of them.

Once the per-link roles are established, each server is assigned a configuration code based on its operation:
- Code $1$: The server acts as a provider for its links.
- Code $2$: The server acts as a consumer for its links.
- Isolated servers (those with no links) do not participate in any link roles, and can independently be assigned either code $1$ or code $2$.

You must determine if there is a valid way to designate the roles for all links without violating the uniformity rule. If there are multiple valid role designations, and consequently multiple valid ways to assign the configuration codes, you must choose the assignment that yields the lexicographically smallest sequence of configuration codes when listed in order from server $1$ to server $n$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a communication link between server $u$ and server $v$.

## Output
If there is no way to designate the link roles without violating the uniformity rule, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers separated by spaces, where the $i$-th integer is the configuration code ($1$ or $2$) assigned to the $i$-th server, representing the lexicographically smallest valid code sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was rewritten to shift the primary decision variables from the vertices (servers) to the edges (links). Instead of assigning a mode to a server which forces edge directions, the model must now assign roles to the endpoints of each individual edge, and then satisfy a uniformity constraint on the vertices. This obscures the standard vertex coloring / bipartiteness formulation by framing it as local edge-role consistency.
</RATIONALE>
<PRESERVED_ANSWER>
The uniformity rule forces every non-isolated server to be exclusively a provider (code 1) or a consumer (code 2), and since each link requires exactly one provider and one consumer, every link must connect a code 1 server to a code 2 server, which perfectly matches the original bipartite constraints and lexicographical tie-breaking.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
