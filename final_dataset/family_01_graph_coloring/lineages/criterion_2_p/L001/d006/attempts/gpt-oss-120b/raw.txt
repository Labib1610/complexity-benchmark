**Solution Explanation**

For every server we have to choose a mode  

* mode 1 – all incident links are directed **out of** the server  
* mode 2 – all incident links are directed **into** the server  

If a link connects servers `u , v` and we decide that `u` is mode 1 and `v`
is mode 2, the link must be directed `u → v`.  
If both ends had the same mode the link could not be directed
according to the rules.

Therefore a feasible assignment exists **iff** the undirected graph is
* bipartite*: we can colour its vertices with two colours such that every
edge connects vertices of different colours.
The colour class “0” will become mode 1 and colour class “1” will become
mode 2 (or the opposite).

--------------------------------------------------------------------

#### Lexicographically smallest assignment  

Among the two possible colour‑to‑mode mappings of a bipartite component we
choose the one that makes the smallest indexed vertex of this component
receive mode 1 (the smaller value).  
Processing the vertices in increasing order guarantees that this greedy
choice yields the globally lexicographically smallest sequence:
the first position where two valid assignments differ is the smallest
vertex of some component, and we have forced it to be `1`.

--------------------------------------------------------------------

#### Algorithm
```
read n, m
build adjacency list
answer[1…n] = 0
visited[1…n] = false
for each vertex v = 1 … n
    if not visited[v]:
        run BFS/DFS from v
        during the search assign colour 0/1
        if a conflict (edge inside same colour) → print NO and exit
        collect all vertices of this component in list comp
        let min_v = minimum vertex id in comp
        if colour[min_v] == 0:
            # colour 0 → mode 1, colour 1 → mode 2
            for x in comp:
                answer[x] = 1 if colour[x]==0 else 2
        else:
            # swap the mapping
            for x in comp:
                answer[x] = 2 if colour[x]==0 else 1
print YES
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` iff no valid configuration exists,
otherwise prints `YES` and the lexicographically smallest valid mode
sequence.

---

##### Lemma 1  
If the algorithm detects a colour conflict inside a component, no valid
configuration exists.

**Proof.** A conflict means an edge `u‑v` with `colour[u] = colour[v]`.
In any orientation every edge must go from a mode 1 vertex to a mode 2
vertex, therefore its ends must have different modes, i.e. different
colours in any bipartition. Hence such an edge makes a bipartition
impossible, so no configuration exists. ∎



##### Lemma 2  
If the algorithm finishes a component without conflict, the graph is
bipartite and the two assignments it builds (original mapping or swapped)
are both feasible.

**Proof.** The BFS colours every edge with opposite colours, therefore the
component is 2‑coloured – a bipartition.  
Choosing mode 1 for colour 0 and mode 2 for colour 1 directs every edge
from colour 0 to colour 1, satisfying the rules. Swapping the two modes
does the same with opposite direction, also feasible. ∎



##### Lemma 3  
For a component `C` the algorithm assigns mode 1 to the smallest indexed
vertex of `C`.

**Proof.** Let `p = min(C)`. If `colour[p]=0` we keep the original mapping,
so `p` gets mode 1. If `colour[p]=1` we swap the mapping, turning colour 1
into mode 1, again giving `p` mode 1. ∎



##### Lemma 4  
The sequence produced by the algorithm is lexicographically minimal among
all feasible sequences.

**Proof.** Consider the vertices in increasing order.
Let `i` be the first index where the algorithm’s sequence `A` differs from
any other feasible sequence `B`.  
Vertex `i` belongs to some component `C`. By Lemma&nbsp;3, `A[i]=1`.  
If `B[i]=2`, then `B` gives mode 2 to the smallest vertex of `C`,
contradicting feasibility because we could swap the two modes inside `C`
and obtain another feasible sequence with a smaller value at position `i`.
Thus any feasible sequence must have `B[i]=1`. Hence no feasible sequence
is lexicographically smaller than `A`. ∎



##### Lemma 5  
If the algorithm outputs `YES`, the printed sequence is feasible.

**Proof.** By Lemma&nbsp;2 each component is bipartite and the chosen
mapping respects the direction rule for all its edges. Combining all
components gives a global orientation and mode assignment satisfying the
requirements. ∎



##### Theorem  
The algorithm outputs `NO` iff no valid configuration exists; otherwise it
outputs `YES` and the lexicographically smallest valid mode assignment.

**Proof.**  
*If* the algorithm prints `NO`, it must have found a colour conflict
(Lemma&nbsp;1), therefore no configuration exists.  

*If* a configuration exists, the graph is bipartite, so no conflict is
found; the algorithm finishes and prints `YES`. By Lemma&nbsp;5 the
produced assignment is feasible, and by Lemma&nbsp;4 it is the
lexicographically smallest one. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`BFS` visits each vertex once and each edge twice.

```
Time   :  O(n + m)
Memory :  O(n + m)   (adjacency list, colour, visited, answer)
```

Both satisfy the limits (`n,m ≤ 2·10⁵`).

--------------------------------------------------------------------

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # 0 or 1
    ans = [0] * (n + 1)
    from collections import deque

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        ok = True
        while q:
            u = q.popleft()
            cu = colour[u]
            for v in adj[u]:
                if colour[v] == -1:
                    colour[v] = cu ^ 1
                    q.append(v)
                    comp.append(v)
                elif colour[v] == cu:
                    print("NO")
                    return
        # decide orientation: smallest vertex gets mode 1
        min_v = min(comp)
        if colour[min_v] == 0:
            for v in comp:
                ans[v] = 1 if colour[v] == 0 else 2
        else:
            for v in comp:
                ans[v] = 2 if colour[v] == 0 else 1

    print("YES")
    print(' '.join(str(ans[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
