**Solution Explanation**

For every module we have to choose one of the two buses.
For each critical link `(u , v)` the two modules must be on *different*
buses.  
Exactly the same condition appears in a *bipartite graph* :

* vertices = modules  
* edges    = critical links  

The graph is bipartite **iff** a feasible assignment exists.
If it is bipartite, each connected component has two possible colourings
(the two colour classes can be swapped).  
Among all feasible assignments we need the lexicographically smallest
sequence  

```
bus[1] bus[2] … bus[n]      (bus[i] ∈ {1,2})
```

--------------------------------------------------------------------

#### 1.   Observations

* In one component the two colourings differ only by swapping the two
  colour classes.
* The lexicographically smallest whole sequence is obtained by the
  following greedy rule:

  > In every component make the **smallest numbered vertex of this
  > component receive bus 1**.

  Proof sketch:  
  Look at the first index `k` where two feasible assignments differ.
  `k` belongs to a certain component `C`.  
  Inside `C` the two assignments are exactly the two possible colourings,
  i.e. they are each other's swap.  
  The assignment that gives `bus[k]=1` is lexicographically smaller,
  because all earlier positions are equal.  
  Therefore for each component we must choose the orientation that puts
  its smallest vertex on bus 1.  
  The choices for different components are independent, so applying the rule
  to every component yields the global optimum.

--------------------------------------------------------------------

#### 2.   Algorithm
```
read n , m
build adjacency list

colour[1…n] = -1          # -1 = not visited, 0/1 = temporary colours
answer[1…n] = 0

for v = 1 … n:
    if colour[v] != -1: continue
    # start a new component, BFS
    queue ← [v]; colour[v] = 0
    component = []                # vertices of this component
    while queue not empty:
        x = pop queue
        component.append(x)
        for each neighbour y of x:
            if colour[y] == -1:
                colour[y] = colour[x] ^ 1
                push y
            elif colour[y] == colour[x]:
                print "NO" and exit   # not bipartite

    # component is bipartite, decide orientation
    min_vertex = min(component)
    # we want colour[min_vertex] to become 0 (bus 1)
    flip = colour[min_vertex]          # 0 → no flip, 1 → flip
    for each vertex u in component:
        final_colour = colour[u] ^ flip
        answer[u] = 1 if final_colour == 0 else 2

print "YES"
print answer[1] … answer[n] separated by spaces
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `NO` iff no feasible assignment exists,
otherwise prints `YES` and the lexicographically smallest feasible
assignment.

---

##### Lemma 1  
During BFS, if an edge `(x, y)` is found with `colour[x] == colour[y]`,
the graph is not bipartite.

**Proof.** In a bipartite graph every edge connects vertices of opposite
colour classes. The BFS colours vertices exactly according to the parity
of the path length from the start vertex, therefore equal colours on an
edge contradict bipartiteness. ∎



##### Lemma 2  
If the algorithm finishes all BFS traversals without triggering Lemma 1,
the whole graph is bipartite.

**Proof.** Each connected component is processed independently.
BFS succeeds for a component ⇔ that component is bipartite
(Lemma 1). All components being bipartite means the whole graph is
bipartite. ∎



##### Lemma 3  
For a processed component `C` let `c_min` be its smallest vertex.
The algorithm assigns bus 1 to `c_min`.

**Proof.** After BFS we have temporary colours `0/1`.  
If `colour[c_min] == 0` we set `flip = 0`, i.e. keep the colours,
so `c_min` gets final colour `0 → bus 1`.  
If `colour[c_min] == 1` we set `flip = 1`, swapping the two colour
classes, thus `c_min` receives final colour `0 → bus 1`. ∎



##### Lemma 4  
For every component the algorithm produces the lexicographically
smallest assignment among the two possible colourings of this component.

**Proof.** By Lemma 3 the smallest vertex of the component gets bus 1.
Any other feasible assignment for the same component must give this
vertex either bus 1 (identical) or bus 2 (the swapped colouring).
If it gives bus 2, the whole sequence becomes larger at the position of
that vertex, therefore the algorithm’s choice is the smaller one. ∎



##### Lemma 5  
Let `A` be the assignment output by the algorithm and `B` any feasible
assignment. Then `A` is lexicographically not larger than `B`.

**Proof.** Scan vertices from `1` to `n`.  
Consider the first index `k` where `A` and `B` differ.
`k` belongs to some component `C`.  
Both assignments respect the bipartition, therefore inside `C` they are
exactly the two possible colourings (they differ only by a global swap).
By Lemma 4 the algorithm chose the colouring that gives bus 1 to the
smallest vertex of `C`.  
Since `k` is the smallest index where the two assignments differ,
`k` is the smallest vertex of `C`. Consequently `A[k] = 1` and `B[k] = 2`,
so `A` is lexicographically smaller. ∎



##### Lemma 6  
If the algorithm prints `NO`, no feasible assignment exists.

**Proof.** `NO` is printed only when Lemma 1 detects an edge whose
endpoints have equal temporary colours, i.e. an odd cycle.
A graph containing an odd cycle is not bipartite, thus no assignment can
satisfy the “different buses” condition. ∎



##### Theorem  
The algorithm

* prints `NO` **iff** the required assignment does not exist,
* otherwise prints `YES` and the lexicographically smallest feasible
  assignment.

**Proof.**  
*If* the algorithm prints `NO`, by Lemma 6 no assignment exists.  
*Only if* an assignment exists, the graph is bipartite, so Lemma 2 shows
the algorithm never triggers `NO`. It finishes, outputs `YES` and a
feasible assignment (by construction each edge connects different buses).
By Lemma 5 this assignment is lexicographically minimal among all feasible
ones. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency list* : `O(n + m)` memory and time.  
*BFS over all components*   : each vertex and edge processed once →  
`O(n + m)` time, `O(n)` additional memory for colour / answer arrays.  

Overall  

```
Time   : O(n + m)   ≤ 4·10⁵ operations
Memory : O(n + m)   ≤ 4·10⁵ integers  (well below limits)
```

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # temporary 0/1
    answer = [0] * (n + 1)           # final 1/2

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS of a new component
        q = deque([start])
        colour[start] = 0
        comp = []
        while q:
            x = q.popleft()
            comp.append(x)
            cx = colour[x]
            for y in adj[x]:
                if colour[y] == -1:
                    colour[y] = cx ^ 1
                    q.append(y)
                elif colour[y] == cx:
                    sys.stdout.write("NO")
                    return

        # decide orientation: smallest vertex gets bus 1
        min_v = min(comp)
        flip = colour[min_v]          # 0 -> no flip, 1 -> flip
        for v in comp:
            final = colour[v] ^ flip
            answer[v] = 1 if final == 0 else 2

    out = ["YES", " ".join(str(answer[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
