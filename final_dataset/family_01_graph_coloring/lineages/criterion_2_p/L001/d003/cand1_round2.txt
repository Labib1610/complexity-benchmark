<STATEMENT>
# Problem B — Power Bus Redundancy

Time limit: 1 s
Memory limit: 256 MB

An orbital station contains $n$ life-support modules. The automated diagnostic system must configure the backup network by assigning a redundancy tier to each module. Each module's tier must be an integer $t$ such that $1 \le t \le 2$.

The safety protocol includes $m$ critical links. Each link identifies two modules that serve as mutual backups. To guarantee operational stability, the configuration must satisfy a strict numerical condition: for any two modules $u$ and $v$ connected by a critical link, the sum of the cubes of their assigned tier values must evaluate to exactly $9$.

You must determine whether a valid tier assignment exists for all modules. When multiple valid assignments are possible, the diagnostic system mandates selecting the configuration that produces the lexicographically smallest sequence of tier values, ordered by module number from $1$ to $n$.

## Input
The first line of the input contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a redundancy link between module $u$ and module $v$.

## Output
If there is no way to assign the tier values without violating the safety protocol, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers separated by spaces, where the $i$-th integer is the tier value ($1$ or $2$) assigned to the $i$-th module, representing the lexicographically smallest valid assignment ordered by indices from $1$ to $n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The bitwise XOR condition and the "evenly divides 2" phrasing in the seed problem acted as strong triggers for models to recognize bipartiteness and 2-coloring. I replaced these with mathematically equivalent algebraic conditions: tiers are restricted to the range `[1, 2]`, and the edge condition requires the sum of their cubes to be exactly 9. Because $1^3 + 2^3 = 9$, this forces adjacent modules to have different tiers, demanding the exact same structural reasoning without the obvious bitwise flags.
</RATIONALE>
<PRESERVED_ANSWER>
The domain of allowed tiers remains exactly {1, 2}, and the cubic equation $t_u^3 + t_v^3 = 9$ is satisfied if and only if one tier is 1 and the other is 2, making the set of valid assignments and the lexicographical tie-breaker identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring of an undirected graph, which is solvable in polynomial time O(n+m) using Breadth-First Search.
</PRESERVED_CLASS>
