This forces the endpoints to take distinct values (2-coloring) but presents it as a numerical power requirement, bypassing heuristics that trigger on graph coloring or orientation keywords.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Network Transceivers

Time limit: 1 s   Memory limit: 256 MB

You are configuring a communication network consisting of $n$ servers and $m$ communication links. Each link connects a specific pair of servers.

You must assign each server to an operation tier: either Tier 1 or Tier 2.
- A server assigned to Tier 1 provides exactly 1 unit of signal power to each individual link connected to it.
- A server assigned to Tier 2 provides exactly 2 units of signal power to each individual link connected to it.

For a communication link to be stable, the sum of the signal power provided by its two endpoints must be exactly 3 units. 
A configuration is valid if every link in the network is stable. If a server has no links connected to it, it must still be assigned exactly one tier.

You must determine if there is a valid configuration. If there are multiple valid tier assignments, you must choose the assignment that yields the lexicographically smallest sequence of tiers when listed in order from server $1$ to server $n$.

## Input
The first line of the input contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a communication link between server $u$ and server $v$.

## Output
If there is no valid configuration, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers separated by spaces, where the $i$-th integer is the tier ($1$ or $2$) assigned to the $i$-th server, representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit rules about directing links and making endpoints Origins or Destinations were removed. They were replaced with an algebraic constraint where the tiers of connected servers must sum to 3. Because the domain is restricted to {1, 2}, this mathematically forces adjacent servers to have different tiers, requiring models to independently deduce the 2-coloring structure without graph-theoretic hints.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that connected servers provide power summing to 3 from a domain of {1, 2} is mathematically identical to requiring them to have distinct states, preserving exactly the same valid assignments and lexicographical tie-breaking outcomes.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring of a graph and choosing the lexicographically smallest assignment, which is solvable in linear time using Breadth-First Search.
</PRESERVED_CLASS>
