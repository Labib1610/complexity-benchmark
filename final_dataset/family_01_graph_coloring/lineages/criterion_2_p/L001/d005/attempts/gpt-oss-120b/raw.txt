**Solution Explanation**

For every server we have to choose a mode

* `1` – transmitter : all incident edges are directed **out of** the vertex  
* `2` – receiver    : all incident edges are directed **into** the vertex  

For an edge `{u,v}` the direction must satisfy both ends, therefore the
two ends must have opposite modes :

```
u   mode 1   →   edge   ←   mode 2   v
```

If both ends had the same mode the edge could not be directed.
Consequently

* the graph must be **bipartite**
* inside a connected component the two colour classes are forced:
  one class gets mode `1`, the other class gets mode `2`.
* which class receives `1` is free – we may swap the two modes.

The task is

1. check bipartiteness,
2. choose the swapping in every component so that the whole
   sequence `a[1] … a[n]` is lexicographically minimal.

--------------------------------------------------------------------

#### 1.   Bipartite check and colouring  

Depth‑first or breadth‑first search supplies a `color[v] ∈ {0,1}`.
During the search:

```
for each edge (v , to):
        if color[to] is unassigned:   color[to] = 1 - color[v]
        else if color[to] == color[v]:   NOT BIPARTITE → answer NO
```

If a vertex has degree `0` it is isolated; it may take any colour
(because it has no edges).

--------------------------------------------------------------------

#### 2.   Lexicographically smallest assignment  

We process vertices in increasing order `1 … n`.
When we first meet a *still unvisited* vertex `v`
all vertices with a smaller index are already completely processed.
Therefore `v` is the **smallest index of its connected component**.

Inside the component we already know the two colour classes.
To obtain the smallest possible value at position `v`
we simply give mode `1` to the colour class that contains `v`
(and mode `2` to the other class).  
All later vertices of this component are forced by this choice.
No other decision can improve an earlier position – the greedy rule is optimal.

Isolated vertices are a special case of a component of size `1`,
the rule also makes them mode `1`.

--------------------------------------------------------------------

#### 3.   Algorithm
```
read n, m
build adjacency list
color[1…n] = -1          # -1 = unvisited
answer[1…n] = 0

for v = 1 … n:
        if color[v] != -1: continue
        if degree(v) == 0:            # isolated
                answer[v] = 1
                color[v] = 0
                continue

        # new non‑trivial component, v is its smallest vertex
        BFS queue ← v
        color[v] = 0
        component_vertices = [v]

        while queue not empty:
                x = pop
                for each neighbour y of x:
                        if color[y] == -1:
                                color[y] = 1 - color[x]
                                push y
                                component_vertices.append(y)
                        elif color[y] == color[x]:
                                print "NO" and exit

        # assign modes, give 1 to the colour of the smallest vertex (v)
        for each vertex u in component_vertices:
                answer[u] = 1 if color[u] == color[v] else 2

print "YES"
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `"NO"` iff no valid assignment exists,
otherwise prints `"YES"` and the lexicographically smallest feasible
mode sequence.

---

##### Lemma 1  
If the algorithm prints `"NO"` then no assignment satisfying the rules
exists.

**Proof.** `"NO"` is printed only when during BFS an edge `(x,y)` is found
with `color[x] == color[y]`. All previously coloured vertices respect the
rule *adjacent vertices have opposite colours*. Adding the edge forces the
two endpoints to have opposite colours, a contradiction. Hence any
2‑colouring of the graph is impossible, consequently no orientation with
the required transmitter/receiver property exists. ∎



##### Lemma 2  
If the algorithm finishes without `"NO"`, the produced `answer`
satisfies all constraints.

**Proof.** For every edge `{u,v}` the BFS coloured `u` and `v` with opposite
colours, because otherwise the algorithm would have stopped earlier.
The algorithm assigns mode `1` to exactly one colour class of the component
(the class containing the smallest vertex) and mode `2` to the other.
Thus the endpoints obtain different modes, and the edge can be directed
from the `1`‑endpoint to the `2`‑endpoint, satisfying the problem statement.
Isolated vertices obtain mode `1` and have no incident edges, also valid. ∎



##### Lemma 3  
For each connected component the algorithm assigns mode `1` to the colour
class that contains the smallest numbered vertex of the component.

**Proof.** By construction the outer loop visits vertices in increasing order.
When it first reaches a vertex `v` that is still uncoloured,
all vertices with smaller indices belong to already finished components,
hence `v` is the smallest index inside its component.
The BFS colours the whole component, and afterwards the algorithm sets
`answer[u]=1` exactly when `color[u]==color[v]`. ∎



##### Lemma 4  
Among all feasible assignments, the one produced by the algorithm is
lexicographically minimal.

**Proof.** Consider the vertices from `1` to `n` sequentially.

*If vertex `i` belongs to a component already processed*,
its mode is already fixed by the algorithm, identical to every other
assignment that agrees on earlier vertices (otherwise a previous vertex
would differ, contradicting minimality).

*If vertex `i` is the first (smallest) vertex of its component*, the
algorithm gives it mode `1` (Lemma&nbsp;3). Any feasible assignment must give
either mode `1` or mode `2` to this vertex, because the two colour classes
can be swapped arbitrarily.
Choosing mode `2` would make the whole sequence larger at position `i`
while keeping all earlier positions unchanged, contradicting lexicographic
minimality. Therefore every lexicographically minimal feasible assignment
must also give mode `1` to this vertex, and consequently the same
assignment to the whole component. ∎



##### Lemma 5  
If a feasible assignment exists, the algorithm never prints `"NO"`.

**Proof.** Suppose a feasible assignment exists.
Take any edge `{u,v}`. In a feasible assignment the two endpoints have
different modes, therefore they belong to opposite colour classes in any
proper 2‑colouring of the graph.
Thus the graph is bipartite. While the algorithm performs BFS,
it colours vertices exactly as a 2‑colouring; because the graph is bipartite,
no edge connects vertices of the same colour, so the conflict triggering
`"NO"` never occurs. ∎



##### Theorem  
The algorithm outputs  

* `"NO"` iff the required configuration does not exist,  
* otherwise `"YES"` followed by the lexicographically smallest valid
  sequence of modes.

**Proof.**  

*If the algorithm outputs `"NO"`*: by Lemma&nbsp;1 no feasible configuration
exists.

*If the algorithm outputs `"YES"`*: by Lemma&nbsp;5 a feasible configuration
must exist. Lemma&nbsp;2 shows the produced sequence is feasible.
Lemma&nbsp;4 proves it is the lexicographically smallest among all feasible
sequences.

Thus the statements hold in both directions. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once →  
`O(n + m)` time, `O(n)` additional memory for colour / answer arrays and
queue.

Overall  

* **Time** `O(n + m)` ( ≤ 4·10⁵ operations, well inside 1 s limit)  
* **Memory** `O(n + m)` ( ≤ 4·10⁵ integers, well under 256 MB)

#### 6.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * (n + 1)          # -1 = unvisited, else 0/1
    ans = [0] * (n + 1)

    for v in range(1, n + 1):
        if color[v] != -1:
            continue
        if not adj[v]:                     # isolated vertex
            ans[v] = 1
            color[v] = 0
            continue

        # new component, v is its smallest vertex
        q = deque([v])
        color[v] = 0
        comp = [v]
        ok = True
        while q:
            x = q.popleft()
            cx = color[x]
            for nb in adj[x]:
                if color[nb] == -1:
                    color[nb] = 1 - cx
                    q.append(nb)
                    comp.append(nb)
                elif color[nb] == cx:
                    print("NO")
                    return
        # assign modes: colour of v gets 1
        col_one = color[v]
        for u in comp:
            ans[u] = 1 if color[u] == col_one else 2

    # all components processed without conflict
    print("YES")
    sys.stdout.write(' '.join(str(ans[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
