# Acoustic Resonance Tuning

Time limit: 1 s
Memory limit: 256 MB

An acoustic laboratory manages a grid of $n$ sonic emitters. For operational stability, each emitter must be assigned a phase duration of exactly 1 or 2 microseconds.

The physical layout of the laboratory imposes $m$ resonance dependencies, each connecting a specific pair of emitters. A system calibration is deemed stable only if it adheres to a precise synchronization rule: for every dependency, the mathematical product of the phase durations of the two connected emitters must be exactly 2.

You must determine if a stable calibration exists for the entire grid. In cases where multiple valid configurations exist, the protocol dictates selecting the one whose sequence of $n$ phase durations is lexicographically smallest. Thus, when comparing two stable configurations, the one with the shorter duration (1 rather than 2) at the earliest index where they differ is chosen.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), denoting the total number of emitters and the number of resonance dependencies.
Each of the subsequent $m$ lines provides two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a dependency exists between emitter $u$ and emitter $v$.

## Output
If it is impossible to calibrate the network safely, print `NO` on a single line.
If a safe calibration exists, print `YES` on the first line. On the second line, print $n$ space-separated integers (each either 1 or 2) representing the phase duration for each emitter from 1 to $n$. This sequence must be the lexicographically smallest valid calibration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The direct statement that "one emitter's phase duration must be exactly twice the phase duration of the other" was removed. It was replaced with the mathematically equivalent condition that the product of the two durations must be exactly 2 (since the only allowed values are 1 and 2). This forces the model to deduce that the endpoints of every dependency must have different values, breaking the immediate pattern-match to 2-coloring.
</RATIONALE>
<PRESERVED_ANSWER>
Because the allowed phase durations are strictly 1 and 2, the condition that their product equals 2 uniquely requires one to be 1 and the other to be 2, which is identical to the original requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring of a graph (or determining if it is bipartite) and can still be solved in O(n + m) time using BFS or DFS.
</PRESERVED_CLASS>
