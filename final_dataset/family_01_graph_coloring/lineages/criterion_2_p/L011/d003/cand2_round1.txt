# Acoustic Resonance Tuning

Time limit: 1 s
Memory limit: 256 MB

A research facility operates a network of sonic emitters. To maintain stability, every emitter must be calibrated with a phase duration of either 1 or 2 microseconds.

The facility's architecture creates resonance dependencies. Each dependency links a specific pair of emitters. A calibration is only considered safe if it satisfies a strict relative timing condition: for every pair of emitters linked by a dependency, the resonance product of their two phase durations must be exactly 2.

Your task is to determine whether a safe calibration can be applied to the entire network. If multiple safe configurations are possible, the control system defaults to the one whose sequence of phase durations is lexicographically smallest. This means that when comparing two valid configurations, the preferred one has the smaller duration (1 instead of 2) at the earliest emitter index where they differ.

System specifications dictate that the network contains $n$ emitters, where $n$ ranges from a minimum of a single unit up to a maximum structural capacity of two hundred thousand. The number of resonance dependencies $m$ can be zero, and is bounded by the same maximum structural capacity.

## Input
The first line contains two integers $n$ and $m$, representing the total number of emitters and the number of resonance dependencies, bounded as described in the system specifications.
Each of the subsequent $m$ lines provides two integers $u$ and $v$ (ranging from 1 to $n$), indicating that a dependency exists between emitter $u$ and emitter $v$.

## Output
If it is impossible to calibrate the network safely, print `NO` on a single line.
If a safe calibration exists, print `YES` on the first line. On the second line, print $n$ space-separated integers (each either 1 or 2) representing the phase duration for each emitter from 1 to $n$. This sequence must be the lexicographically smallest valid calibration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit condition that one phase duration must be exactly twice the other was replaced with the condition that their product must be exactly 2. Because the only allowed values are 1 and 2, this enforces the exact same constraint while removing the overt opposite-color wording that models used to immediately trigger bipartite graph recognition. Additionally, numeric bounds were moved out of bare inequalities into scenario-based capacity descriptions.
</RATIONALE>
<PRESERVED_ANSWER>
The allowed phase durations are strictly 1 and 2, so the only way their product can be exactly 2 is if one emitter is assigned 1 and the other is assigned 2, perfectly preserving the exact same valid configurations and lexicographical preference as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring (testing bipartiteness) and selecting the lexicographically smallest valid assignment per connected component, which is solvable in O(n+m) time.
</PRESERVED_CLASS>
