<METHOD_DESCRIPTION>
Replaces graph terminology and inequality constraints with an algebraic equation over a restricted integer domain. This masks the bipartite coloring structure, forcing models away from standard graph-traversal templates and towards algebraic or SAT solvers that often fail to run in linear time.
</METHOD_DESCRIPTION>

<STATEMENT>
# Harmonic Interference Resolution

Time limit: 1 s
Memory limit: 256 MB

A research facility operates an array of acoustic projectors. To maintain operational stability, you must configure a pulse cycle sequence $C = (c_1, c_2, \dots, c_n)$ for the deployed projectors, where each $c_i$ is strictly chosen from the set $\{1, 2\}$.

The facility's diagnostic system has logged a series of harmonic constraints. Each constraint specifies two sequence indices, $u$ and $v$. For the sequence $C$ to be viable, every logged constraint must satisfy the equation $c_u + c_v = 3$. A configuration is only valid if this equation holds true for all constraints simultaneously.

Your objective is to determine if a viable sequence $C$ exists. If multiple valid sequences are possible, you must output the lexicographically smallest sequence $C$. This means strictly prioritizing the value 1 for lower-indexed variables: $c_1$ must be 1 if any valid sequence allows it, and subject to that, $c_2$ must be 1 if possible, continuing this sequential prioritization up to $c_n$. This prioritization applies globally across the entire sequence.

The facility's main grid has a hard capacity limit of $200,000$ deployed projectors, and its memory buffer can store up to $200,000$ harmonic constraints. The grid requires a minimum of $1$ active projector to boot, though it can operate with $0$ constraints.

## Input
The first line contains two integers $n$ and $m$, representing the number of deployed projectors and the number of constraints, respectively.

Each of the subsequent $m$ lines provides two integers $u$ and $v$, indicating that the equation $c_u + c_v = 3$ applies to the sequence elements at indices $u$ and $v$. Sequence indices are positive integers that never exceed the total number of deployed projectors.

## Output
If it is impossible to find a viable sequence $C$, output `NO` on a single line.
If a viable sequence exists, output `YES` on the first line. On the second line, output $n$ space-separated integers (each being either 1 or 2) representing the sequence $C$. This sequence must be the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I eliminated the graph-coloring framing by replacing the requirement that connected nodes have "different" states with an algebraic constraint $c_u + c_v = 3$. I also applied strategy S07 to replace the explicit numeric bounds with capacity limits in the scenario description. This forces the model to algebraically deduce the mutually exclusive binary states rather than pattern-matching a standard bipartite graph traversal.
</RATIONALE>
<PRESERVED_ANSWER>
The domain is restricted to {1, 2}, so the equation $c_u + c_v = 3$ is mathematically identical to requiring $c_u \neq c_v$, ensuring every valid sequence is exactly the same as the valid assignments in the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically first 2-coloring of an undirected graph, which is solvable in linear time using Breadth-First Search on each connected component.
</PRESERVED_CLASS>
