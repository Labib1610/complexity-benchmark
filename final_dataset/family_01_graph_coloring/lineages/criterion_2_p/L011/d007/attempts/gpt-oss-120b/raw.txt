**Solution Explanation**

For every edge `(u , v)` we need  

```
p[u] * p[v] = 2 ,   p[i] ∈ {1 , 2}
```

Therefore the two endpoints must receive *different* values.
The whole graph has to be **bipartite** – vertices can be coloured with two
colours `0` and `1` such that every edge connects vertices of different colour.
If the graph is not bipartite the answer is impossible.

If the graph is bipartite, each connected component has exactly two feasible
assignments:

* colour `0` → `1` , colour `1` → `2`
* colour `0` → `2` , colour `1` → `1`

We have to output the lexicographically smallest feasible whole sequence.
Consider the components in the order of their smallest vertex index.
When we first meet a component (the first vertex of it is the smallest index of
the component) we can freely decide which of the two assignments to use.
Choosing the assignment that gives `p[first] = 1` makes the whole sequence
lexicographically minimal, because any later decision cannot affect earlier
positions.

Thus the algorithm is:

```
for i = 1 .. n
    if i not visited
        BFS/DFS from i, colour vertices 0/1
        if a conflict appears -> NO
        # i is the smallest vertex of this component
        if colour[i] == 0:
            map colour 0 -> 1 , colour 1 -> 2
        else:
            map colour 1 -> 1 , colour 0 -> 2
        write the values to the answer array
output YES and the array
```

`n, m ≤ 2·10⁵`, the BFS visits each vertex and edge once – `O(n+m)` time,
`O(n+m)` memory.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs **NO** iff no feasible assignment exists,
otherwise it outputs the lexicographically smallest feasible assignment.

---

##### Lemma 1  
If the algorithm reports a conflict while colouring a component, the graph is
not bipartite, therefore no assignment satisfying all edges exists.

**Proof.**  
During BFS we assign opposite colours to the two ends of every processed edge.
A conflict means an edge connects two vertices that already have the same colour,
which is exactly the definition of a non‑bipartite graph.  
If a graph is not bipartite, any 2‑colouring (hence any assignment of `{1,2}`
with opposite values on edges) is impossible. ∎



##### Lemma 2  
If the algorithm finishes without conflict, the produced values satisfy
`p[u]·p[v]=2` for every edge.

**Proof.**  
For each component we have a proper 2‑colouring (`colour[u] ≠ colour[v]` for every edge).
We map the two colours to `{1,2}` bijectively, therefore endpoints of any edge
receive different numbers, i.e. one is `1` and the other `2`. Their product is `2`. ∎



##### Lemma 3  
For a component whose smallest vertex is `s`, the algorithm chooses the
assignment with `p[s]=1`.

**Proof.**  
When the component is first discovered, `s` is the current vertex `i`.
If `colour[s]=0` we map colour `0 → 1`; otherwise we map colour `1 → 1`. In both
cases `p[s]=1`. ∎



##### Lemma 4  
Among all feasible assignments, the one constructed by the algorithm is
lexicographically minimal.

**Proof.**  
Consider the vertices in increasing order.
Let `c` be the first component whose assignment differs between the algorithm’s
solution `A` and any other feasible solution `B`.  
By definition, the smallest vertex of `c` is `s`, and all vertices `< s` belong
to earlier components where `A` and `B` coincide.

By Lemma&nbsp;3, `A` has `p[s]=1`.  
If `B` also has `p[s]=1` then the two assignments of component `c` are identical,
contradicting the choice of `c`.  
Hence `B` must have `p[s]=2`. Therefore at position `s` we have `A_s = 1 <
2 = B_s`, so `A` is lexicographically smaller than `B`. ∎



##### Lemma 5  
If a feasible assignment exists, the algorithm never reports a conflict.

**Proof.**  
A feasible assignment gives a proper 2‑colouring of every component (vertices with
value `1` one colour, value `2` the other). Hence each component is bipartite.
BFS on a bipartite graph cannot encounter a conflict. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no feasible assignment exists;
* otherwise `YES` and the lexicographically smallest feasible assignment.

**Proof.**  

*If the algorithm outputs `NO`.*  
It happened because a conflict was found. By Lemma&nbsp;1 the graph is not
bipartite, thus by Lemma&nbsp;2 no assignment can satisfy all edges. Hence no
feasible assignment exists.

*If a feasible assignment exists.*  
By Lemma&nbsp;5 the algorithm finds no conflict, therefore it outputs `YES` and
a concrete assignment. Lemma&nbsp;2 guarantees this assignment satisfies all
edges. Lemma&nbsp;4 shows it is the lexicographically smallest among all feasible
assignments.

Thus the statement holds in both directions. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(n+m)` memory.  
*BFS over all components*: each vertex and edge processed once → `O(n+m)` time.  
*Total*: `O(n+m)` time, `O(n+m)` memory, well within limits (`n,m ≤ 2·10⁵`).

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # 0 / 1
    answer = [0] * (n + 1)
    from collections import deque

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp_vertices = [start]
        ok = True
        while q:
            u = q.popleft()
            cu = colour[u]
            for v in adj[u]:
                if colour[v] == -1:
                    colour[v] = cu ^ 1
                    q.append(v)
                    comp_vertices.append(v)
                elif colour[v] == cu:
                    ok = False
                    break
            if not ok:
                break
        if not ok:
            print("NO")
            return

        # decide orientation: make start (the smallest vertex) have value 1
        if colour[start] == 0:
            # colour 0 -> 1, colour 1 -> 2
            for v in comp_vertices:
                answer[v] = 1 if colour[v] == 0 else 2
        else:
            # colour 1 -> 1, colour 0 -> 2
            for v in comp_vertices:
                answer[v] = 1 if colour[v] == 1 else 2

    print("YES")
    print(' '.join(str(answer[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
