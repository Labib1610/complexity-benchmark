# Acoustic Resonance Tuning

Time limit: 1 s   Memory limit: 256 MB

A research installation manages a network of $n$ acoustic projectors. Every projector needs to be tuned to one of two operational frequencies, which are identified by the integers 1 and 2.

Throughout the installation, there are $m$ overlapping regions where acoustic waves cross. Each of these regions is formed by the signals of two specific projectors. To avoid catastrophic wave amplification, you must enforce a rigorous tuning rule: whenever two projectors project into the same overlapping region, the sum of the squares of their tuned frequency identifiers must be exactly 5.

Your task is to find out whether it is possible to tune all the projectors safely. If there is more than one valid way to tune the entire network, the automated control grid demands the lexicographically smallest sequence of $n$ frequency identifiers. This means that when comparing two distinct safe tuning sequences from projector 1 to $n$, the correct one will have the smaller identifier at the earliest projector index where the two sequences do not match.

## Input
The first line of input provides two integers $n$ and $m$, representing the total count of projectors and the number of overlapping regions. The installation always runs at least one projector, with a maximum architectural limit of two hundred thousand projectors. The count of overlapping regions can be anywhere from zero up to the exact maximum limit of projectors.
Following this, there are $m$ lines. Each line contains two integers $u$ and $v$, indicating that projector $u$ and projector $v$ share an overlapping region. The projectors are indexed sequentially from one up to $n$.

## Output
If no safe tuning sequence exists, output a single line with the word `NO`.
If a safe tuning sequence can be achieved, output `YES` on the first line. On the second line, output $n$ space-separated integers, where the $i$-th integer (either 1 or 2) is the frequency identifier for projector $i$. This sequence must be the lexicographically smallest valid tuning.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The problem was rewritten to use indirect bounds as required by strategy S07, expressing the numeric limits of $n$ and $m$ through the physical constraints of the facility. Additionally, the affordance `sum ... must equal exactly 3` was replaced with `the sum of the squares ... must be exactly 5`. Because $1^2 + 2^2 = 5$, this enforces the exact same bipartite condition but prevents simple text-matching models from immediately recognizing the 2-coloring reduction.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the sum of the squares of two variables from the set {1, 2} equals 5 is mathematically identical to requiring their sum to be 3; both enforce that one variable is 1 and the other is 2.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem remains identical: determining if a graph is bipartite and finding the lexicographically smallest 2-coloring, which is solvable in O(n+m) time using Breadth-First Search.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "the exact maximum limit of projectors" as referring to $n$ rather than the global constant $200,000$, though in practice this distinction does not affect the algorithm's correctness.
</RISK>
