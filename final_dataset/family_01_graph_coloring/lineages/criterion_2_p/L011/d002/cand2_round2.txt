# Holographic Projection Alignment

Time limit: 1 s   Memory limit: 256 MB

A holographic exhibition employs $n$ projectors. Each projector must be calibrated to a power level of either 1 or 2.

The exhibition space contains $m$ overlapping projection regions. Each overlapping region is formed by exactly two specific projectors. To prevent visual interference, the calibration must satisfy a strict optical condition: for any two projectors that share an overlapping region, the sum of the squares of their assigned power levels must equal exactly 5.

You must determine if a valid calibration exists for all projectors. When multiple valid calibrations exist, the central control system requires the sequence of $n$ power level assignments to be lexicographically smallest. That is, if two valid sequences differ, the preferred sequence is the one with the smaller value at the first position where they differ.

## Input
The first line of input provides two integers $n$ and $m$, representing the number of projectors and the number of overlapping regions. The facility's architectural specifications dictate a minimum of $1$ and a maximum capacity of $2 \cdot 10^5$ projectors. The number of overlapping regions can range from a minimum of $0$ up to a structural limit of $2 \cdot 10^5$.
The following $m$ lines each contain two integers $u$ and $v$ (valid projector identifiers between $1$ and $n$ inclusive), representing an overlapping region formed by projector $u$ and projector $v$.

## Output
If no valid calibration can be found, output a single line containing `NO`.
If a valid calibration is possible, output `YES` on the first line. On the second line, output $n$ space-separated integers, where the $i$-th integer (either 1 or 2) represents the power level assigned to projector $i$. This sequence must be the lexicographically smallest valid calibration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
