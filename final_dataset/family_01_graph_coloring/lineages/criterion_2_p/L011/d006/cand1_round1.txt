<STATEMENT>
# Phase Alignment Calibration

Time limit: 1 s
Memory limit: 256 MB

A research facility operates a network of acoustic projectors. To maintain operational stability, every projector in the network must be assigned a fixed pulse cycle of either 1 microsecond or 2 microseconds.

The facility's layout contains multiple interference thresholds, each connecting a specific pair of projectors. A cycle assignment is only viable if it resolves the interference across the entire network. 

The diagnostic system evaluates a single threshold connecting projector $u$ and projector $v$ by calculating a stability score based on their assigned pulse cycles, $p_u$ and $p_v$. The score is determined by taking the sum of their squares ($p_u^2 + p_v^2$), representing this sum as a standard base-2 binary integer, and counting the total number of '1' bits (the Hamming weight).

For the network assignment to be viable, the total sum of the stability scores across all $m$ thresholds must equal exactly $2m$.

Your objective is to determine if a viable cycle assignment exists for the entire network. If multiple valid assignments are possible, the diagnostic system requires a single deterministic configuration. Among all valid assignments, output the lexicographically smallest sequence of $n$ pulse cycles (ordered from projector 1 to projector $n$). This means selecting the sequence that features the shorter pulse cycle (1 instead of 2) at the earliest projector index where the assignments differ.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 200,000$, $0 \le m \le 200,000$), representing the number of projectors and the number of thresholds, respectively.

Each of the subsequent $m$ lines provides two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that an interference threshold connects the projector indexed $u$ and the projector indexed $v$.

## Output
If it is impossible to find a viable cycle assignment, output `NO` on a single line.
If a viable assignment exists, output `YES` on the first line. On the second line, output $n$ space-separated integers (each being either 1 or 2) representing the pulse cycle assigned to each projector from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Removed the continuous algebraic polynomial formula that enabled models to algebraically deduce the exact maximum value and map it to a simple inequality. Replaced it with a discrete bit-counting operation (Hamming weight of the sum of squares). This forces the models to trace the algorithmic logic for the discrete domain {1, 2} to realize that the maximum possible score is 2, which is only achieved when the assignments are different, thereby forcing them to genuinely reason about the structure rather than matching an algebraic pattern.
</RATIONALE>
<PRESERVED_ANSWER>
For the allowed domain {1, 2}, the stability score is 1 for identical assignments (1^2+1^2=2="10"->1; 2^2+2^2=8="1000"->1) and 2 for differing assignments (1^2+2^2=5="101"->2), meaning a sum of 2m strictly requires every connected pair to differ, which is mathematically identical to the original problem's constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still reduces strictly to lexicographically smallest 2-coloring (bipartiteness testing) on an undirected graph, which is solvable via Breadth-First Search in O(V + E) time, keeping it in P.
</PRESERVED_CLASS>
