<STATEMENT>
# Harmonic Interference Resolution

Time limit: 1 s
Memory limit: 256 MB

A research facility operates a network of $n$ acoustic projectors. To maintain operational stability, every projector $i$ ($1 \le i \le n$) must be assigned a fixed power multiplier $p_i$, which must be chosen from the set $\{1, 2\}$.

The facility's layout dictates $m$ harmonic balance requirements. Each requirement specifies two projectors $u$ and $v$. To prevent interference, the power multipliers assigned to these two projectors must satisfy the following resonance equation:
$p_u^3 + p_v^3 - p_u p_v = 7$

A configuration is only valid if this condition holds for all $m$ requirements simultaneously.

Your objective is to determine if a viable sequence of power multipliers $(p_1, p_2, \dots, p_n)$ exists. 

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 200,000$, $0 \le m \le 200,000$), representing the number of projectors and the number of requirements, respectively.

Each of the next $m$ lines provides two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that the resonance equation $p_u^3 + p_v^3 - p_u p_v = 7$ must hold for projectors $u$ and $v$.

## Output
If it is impossible to find a viable assignment of power multipliers, output `NO` on a single line.
If a viable assignment exists, output `YES` on the first line. On the second line, output $n$ space-separated integers representing the sequence $p_1, p_2, \dots, p_n$. This sequence must be the lexicographically smallest valid assignment. (A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index where they differ, $A$ has a smaller value than $B$.)

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The direct `p_u * p_v = 2` condition was replaced with a cubic polynomial `p_u^3 + p_v^3 - p_u p_v = 7`. This forces models to algebraically evaluate the condition over the domain {1, 2} rather than immediately pattern-matching "product exactly 2" to a bipartite graph coloring problem. The tie-break rule was explicitly restored to the Output section to ensure strict compliance with the original I/O contract.
</RATIONALE>
<PRESERVED_ANSWER>
For variables in {1, 2}, the equation evaluates to 7 if and only if one variable is 1 and the other is 2, making the constraint mathematically identical to the original problem for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains exactly 2-coloring (bipartiteness testing), keeping the problem in P with an O(n+m) complexity.
</PRESERVED_CLASS>
