Looking at this problem, I need to figure out when a valid assignment exists.

The stability formula is `6(p_u + p_v) - (p_u + p_v)^2`. Let me compute this for all combinations:
- Both 1: `6(2) - 4 = 8`
- One 1, one 2: `6(3) - 9 = 9`  
- Both 2: `6(4) - 16 = 8`

The total must equal `9m`, so the average per edge must be 9. This means **every edge must have exactly one projector with cycle 1 and one with cycle 2**.

This is exactly a **2-coloring problem** (bipartite check). If the graph is bipartite, a valid assignment exists.

For the lexicographically smallest assignment: I want to assign 1 to the smallest indices when possible. Using BFS, when I assign a color to an unvisited node, I should try to assign it the value that makes it 1 if possible. Since the graph is bipartite, each connected component has exactly 2 valid colorings (swap 1s and 2s). I process nodes in index order; for each unvisited node, I assign it 1, then BFS to assign the rest of its component.

```python
import sys
from collections import deque

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * (n + 1)  # 0 = unvisited, 1 or 2 = assigned value
    
    for start in range(1, n + 1):
        if color[start] != 0:
            continue
        color[start] = 1
        queue = deque([start])
        while queue:
            u = queue.popleft()
            cu = color[u]
            for v in adj[u]:
                if color[v] == 0:
                    color[v] = 3 - cu  # opposite: 1->2, 2->1
                    queue.append(v)
                elif color[v] == cu:
                    print("NO")
                    return
    
    print("YES")
    print(' '.join(str(color[i]) for i in range(1, n + 1)))

solve()
```
