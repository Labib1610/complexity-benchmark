<STATEMENT>
# Magnetic Flux Stabilization

Time limit: 1 s
Memory limit: 256 MB

A research facility operates a network of acoustic projectors. To maintain operational stability, every projector in the network must be assigned a fixed pulse cycle of either 1 microsecond or 2 microseconds.

The facility is divided into 400 sectors, each capable of housing exactly 500 acoustic projectors. The total number of deployed projectors $n$ can be anywhere from a single unit up to a fully populated facility.
The monitoring system allocates exactly 8 bytes of memory per interference threshold. With a dedicated memory bank of 1,600,000 bytes, the number of tracked thresholds $m$ starts from zero up to the maximum capacity dictated by this memory.

For a threshold connecting projector $u$ and projector $v$, the localized magnetic flux is determined by their assigned pulse cycles, $p_u$ and $p_v$. The flux is calculated using the formula:
$\Phi_{u,v} = 5(p_u + p_v) - 3 p_u p_v$

The total magnetic flux of the network is the sum of $\Phi_{u,v}$ across all $m$ thresholds.
To achieve absolute stability, the total magnetic flux must equal exactly $9m$. A cycle assignment is viable if and only if it satisfies this global condition.

Your objective is to determine if a viable cycle assignment exists for the entire network. If multiple valid assignments are possible, the diagnostic system requires a single deterministic configuration. It converts each valid sequence of $n$ pulse cycles (ordered from projector 1 to projector $n$) into a string of $n$ characters (for example, "1212"). It then selects the valid assignment whose string appears first in standard alphabetical (dictionary) order.

## Input
The first line of the input provides two integers $n$ and $m$, representing the actual number of projectors and the actual number of thresholds.
Each of the subsequent $m$ lines provides two integers $u$ and $v$, indicating that an interference threshold connects the projector indexed $u$ and the projector indexed $v$. Projector indices are valid integers between 1 and $n$, inclusive.

## Output
If it is impossible to find a viable cycle assignment, output `NO` on a single line.
If a viable assignment exists, output `YES` on the first line. On the second line, output $n$ space-separated integers (each being either 1 or 2) representing the pulse cycle assigned to each projector from 1 to $n$. This sequence must be the one that satisfies the tie-breaking string rule described above.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem forces models to deduce that the global sum $9m$ can only be achieved if every single threshold evaluates to 9, because 9 is the absolute maximum of the polynomial over the domain {1, 2}. Evaluating to 9 requires $p_u \neq p_v$, naturally encoding the bipartite coloring constraint without presenting it as a local rule. The tie-breaker was rewritten to use string lexicographical comparison to eliminate the "earliest index" wording that models use as a shortcut to identify BFS orientation rules. The bounds are stated indirectly via facility sectors and memory bytes (S07).
</RATIONALE>
<PRESERVED_ANSWER>
The polynomial returns 9 for (1,2) and (2,1), 7 for (1,1), and 8 for (2,2); since the target sum is exactly $9m$, no compensation is mathematically possible, strictly enforcing $p_u \neq p_v$ on every threshold just like the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing), solvable in $O(n+m)$ time using BFS/DFS.
</PRESERVED_CLASS>
