<STATEMENT>
# Quantum Sensor Array

Time limit: 1 s
Memory limit: 256 MB

A research facility operates a network of $n$ quantum sensors. To maintain operational stability, every sensor $i$ ($1 \le i \le n$) must be assigned a fixed energy state $X_i$. This state must be chosen from the set of two integers: $\{1, 2\}$.

The facility's layout dictates $m$ entanglement requirements. Each requirement specifies a pair of sensors that interact. We define an $n \times n$ symmetric interaction matrix $A$, initially filled with zeros. For each of the $m$ requirements specifying sensors $u$ and $v$, the values of $A_{u,v}$ and $A_{v,u}$ are each increased by 1.

To prevent resonant decoherence, the global configuration vector $X = \begin{pmatrix} X_1 \\ X_2 \\ \vdots \\ X_n \end{pmatrix}$ must satisfy the following matrix equation:

$$ X^T A X - 3 X^T A \mathbf{1} + 5m = 0 $$

where $\mathbf{1}$ is the $n \times 1$ all-ones vector, and $X^T$ is the transpose of $X$. A configuration is only valid if this global equation holds exactly.

Your objective is to determine if a viable sequence of energy states $(X_1, X_2, \dots, X_n)$ exists. If multiple valid sequences are possible, you must output the sequence that yields the lexicographically smallest sequence of states. 

(A sequence $Y$ is lexicographically smaller than sequence $Z$ if, at the first index where they differ, $Y$ has a smaller value than $Z$. This prioritization applies globally across the entire sequence of $n$ sensors.)

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 200,000$, $0 \le m \le 200,000$), representing the number of sensors and the number of requirements, respectively.

Each of the next $m$ lines provides two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a requirement between sensors $u$ and $v$.

## Output
If it is impossible to find a viable assignment of energy states, output `NO` on a single line.
If a viable assignment exists, output `YES` on the first line. On the second line, output $n$ space-separated integers representing the sequence of states $X_1, X_2, \dots, X_n$. This sequence must be the lexicographically smallest valid sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
<METHOD_NAME>Global Quadratic Form Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Converts the local pairwise inequality constraint ($X_u \neq X_v$) into a global matrix equation ($X^T A X - 3 X^T A \mathbf{1} + 5m = 0$). Because the equation is evaluated globally over the adjacency matrix, models that rely on pattern-matching will fail to recognize the independent pairwise nature of the constraints and will likely attempt intractable global optimization or backtracking, while models that perform genuine algebraic deduction will recover the 2-coloring structure.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
The original problem asks for a 2-coloring of a graph, presented as choosing intervals that union to a length of 2. I replaced this with a mathematically equivalent global quadratic form over the adjacency matrix. Expanding the matrix equation yields a sum over edges where each term is $2X_uX_v - 3(X_u+X_v) + 5$. For $X_i \in \{1, 2\}$, this term is exactly 0 if $X_u \neq X_v$, and 1 if $X_u = X_v$. Since the sum must be 0, all terms must be 0, forcing a valid 2-coloring. This forces the model to perform multi-step algebraic deduction rather than matching a local truth-table directly to XOR.
</RATIONALE>
<PRESERVED_ANSWER>
The matrix equation holds if and only if $X_u \neq X_v$ for every edge, which is mathematically identical to the original requirement that the intervals union to a length of 2 (forcing one to be [0,1] and the other [1,2]).
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains exactly 2-coloring (bipartite graph checking), solvable in $O(n+m)$ using Breadth-First Search.
</PRESERVED_CLASS>
