# Acoustic Resonance Tuning

Time limit: 1 s
Memory limit: 256 MB

A research facility operates an array of $n$ acoustic projectors. To ensure structural integrity, the continuous operation protocol dictates that every projector must be assigned a pulse cycle of either 1 or 2 microseconds.

The facility's layout introduces $m$ interference thresholds. Each threshold connects a specific pair of projectors. A cycle assignment is only viable if it maintains strict harmony across these connections: for any two projectors $u$ and $v$ joined by a threshold, the greatest common divisor of $(c_u + 1)$ and $(c_v + 1)$ must evaluate to exactly 1, where $c_u$ and $c_v$ are their assigned pulse cycles.

Your objective is to determine if a viable cycle assignment exists for the complete array. Since multiple viable assignments might be possible, the diagnostic system evaluates the global resonance footprint of the array. The footprint is defined mathematically as $F = \sum_{i=1}^{n} c_i \cdot 10^{n - i}$. The system is strictly required to adopt the viable assignment that minimizes this global resonance footprint $F$.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of acoustic projectors and the number of interference thresholds.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a threshold connects projector $u$ and projector $v$.

## Output
If it is impossible to find a viable cycle assignment, print `NO` on a single line.
If a viable assignment can be found, print `YES` on the first line. On the second line, print $n$ space-separated integers (each either 1 or 2) indicating the pulse cycle for each projector from 1 to $n$. This sequence must be the unique valid assignment that minimizes the footprint $F$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The direct "product equals 2" affordance was replaced with a GCD condition that evaluates to the exact same truth table on the domain {1, 2}, preventing simple keyword-based mapping to bipartite graphs. Meanwhile, the explicit "lexicographically smallest" tie-breaker was replaced with a mathematically equivalent global base-10 sum minimization. This forces models to genuinely reason that minimizing a positional number system allows for independent greedy choices per component, trapping models that blindly attempt to compute the massive sum or use inappropriate global optimization algorithms.
</RATIONALE>
<PRESERVED_ANSWER>
For values in {1, 2}, gcd(x+1, y+1) = 1 if and only if x ≠ y, which perfectly preserves the original constraint; furthermore, minimizing a sequence evaluated as a base-10 integer is mathematically identical to finding the lexicographically smallest sequence.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) with a greedy tie-breaker, solvable in O(n+m) time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
Models might attempt to literally compute the sum $F$ and fail due to integer overflow, but this is a failure of algorithmic reasoning rather than an ambiguity in the problem text, as the output only asks for the sequence itself.
</RISK>
