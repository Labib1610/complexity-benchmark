# Harmonic Interference Resolution

Time limit: 1 s
Memory limit: 256 MB

A research facility operates a network of acoustic projectors. To maintain operational stability, every projector in the network must be assigned a fixed pulse cycle of either 1 microsecond or 2 microseconds.

The facility's layout contains multiple interference thresholds, each connecting a specific pair of projectors. A cycle assignment is only viable if it resolves the interference at every threshold. The interference generated by a threshold connecting projector $u$ and projector $v$ is calculated using their assigned pulse cycles, $p_u$ and $p_v$. Specifically, the interference value is the sum of the squares of their pulse cycles, plus the product of their pulse cycles ($p_u^2 + p_v^2 + p_u p_v$). For the assignment to be viable, this interference value must equal exactly 7 for every single threshold in the network.

Your objective is to determine if a viable cycle assignment exists for the entire network. If multiple valid assignments are possible, the diagnostic system requires a single deterministic configuration. It will compare the sequences of $n$ pulse cycles (ordered from projector 1 to projector $n$) and select the sequence that features the shorter pulse cycle (1 instead of 2) at the earliest projector index where the assignments differ.

## Input
The facility's power grid can support up to 200,000 acoustic projectors, and its monitoring system can track up to 200,000 interference thresholds.

The first line of the input provides two integers $n$ and $m$, representing the actual number of projectors and the actual number of thresholds. The number of projectors $n$ is at least 1, and the number of thresholds $m$ is at least 0. Neither will exceed their respective maximum system capacities of 200,000.

Each of the subsequent $m$ lines provides two integers $u$ and $v$, indicating that an interference threshold connects the projector indexed $u$ and the projector indexed $v$. Projector indices are valid integers between 1 and $n$, inclusive.

## Output
If it is impossible to find a viable cycle assignment, output `NO` on a single line.
If a viable assignment exists, output `YES` on the first line. On the second line, output $n$ space-separated integers (each being either 1 or 2) representing the pulse cycle assigned to each projector from 1 to $n$. This sequence must be the one that satisfies the tie-breaking rule described above.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
