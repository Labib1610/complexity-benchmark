# Polarization Frequency

Time limit: 1 s   Memory limit: 256 MB

A manufacturing plant operates continuously. The plant's main floor is composed of 200,000 installation bays. The number of active machines $n$ is at least 1 and can be at most the number of bays. Each machine is assigned a unique ID from 1 to $n$.

The machines must be configured to use either polarization frequency 1 or polarization frequency 2. The safety system logs $m$ proximity warnings, each linking a pair of machines. The system's memory can store anywhere from no warnings up to a maximum exactly equal to the total number of installation bays. If two machines linked by a warning are configured to the same polarization frequency, they will cause destructive interference. Consequently, they require distinct frequencies.

You must determine whether it is possible to configure all machines without causing interference. If a safe configuration is possible, the plant's automated control system requires a standardized output. Specifically, the resulting sequence of $n$ frequencies must be the lexicographically smallest valid sequence, meaning that the system prefers frequency 1 over frequency 2, prioritizing the machine with the lowest ID, then the second lowest, and so forth.

## Input
The first line contains two integers $n$ and $m$, representing the number of active machines and the number of proximity warnings. The bounds for these values are defined by the plant's physical capacities described above.
The following $m$ lines each contain two integers $u$ and $v$ (representing valid machine IDs), indicating that machine $u$ and machine $v$ are linked by a proximity warning.

## Output
If there is no way to configure the frequencies without interference, output a single line containing `NO`.
If a safe configuration exists, output `YES` on the first line. On the second line, output $n$ space-separated integers, where the $i$-th integer (either 1 or 2) represents the frequency assigned to machine $i$. This sequence must be the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I applied strategy S07 by removing the bare inequalities from the Input section and instead embedding the exact limits within the physical description of the facility (e.g., 200,000 installation bays). This forces the model to read and comprehend the scenario text to establish the constraints, rather than relying on standard formatted bounds. The core pairwise distinctness constraint was also reworded as proximity warnings requiring distinct frequencies to obscure the graph coloring framing.
</RATIONALE>
<PRESERVED_ANSWER>
The problem still requires finding a valid assignment of exactly two states (frequencies) to machines such that no two linked machines share a state, and returning the lexicographically smallest assignment or reporting failure, which identically preserves the output for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The task remains mathematically equivalent to finding the lexicographically first valid 2-coloring of an undirected graph, which is solvable in linear time using Breadth-First Search, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might struggle to parse the indirect bounds if they expect a strict mathematical notation, though the phrasing "at most the number of bays" and "up to a maximum exactly equal" is designed to be completely unambiguous.
</RISK>
