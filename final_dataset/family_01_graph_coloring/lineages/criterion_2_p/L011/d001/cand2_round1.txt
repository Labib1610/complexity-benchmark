# Transmission Calibration

Time limit: 1 s   Memory limit: 256 MB

A mechanical engineering team is designing a custom transmission featuring $n$ rotary shafts. Each shaft must be fitted with a gear. The available gears come in two specific sizes, which provide a speed multiplier of either 1 or 2.

The transmission design includes $m$ critical mesh points. Each mesh point directly engages a specific pair of shafts. To ensure the transmission operates smoothly and meets the engine's design specifications, the mechanical requirements dictate that for every engaged pair of shafts, the combined gear ratio—calculated as the product of their individual gear multipliers—must be exactly 2.

You must determine whether it is possible to assign a gear multiplier of either 1 or 2 to each of the $n$ shafts such that all $m$ mesh point requirements are satisfied simultaneously.

If a valid configuration is possible, the automated manufacturing system requires a standardized output format. Specifically, the resulting sequence of $n$ gear multipliers must be lexicographically smallest. This means the system prefers assigning a multiplier of 1 over 2, prioritizing the choice for shaft 1, then shaft 2, and so forth.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of shafts and the number of mesh points.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that shaft $u$ and shaft $v$ are engaged at a mesh point.

## Output
If there is no way to assign the gear multipliers to satisfy all mesh points, output a single line containing `NO`.
If a valid assignment exists, output `YES` on the first line. On the second line, output $n$ space-separated integers, where the $i$-th integer (either 1 or 2) represents the gear multiplier assigned to shaft $i$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

This forces models to algebraically deduce the inequality constraint and subsequently recognize the bipartite structure, rather than relying on standard graph-coloring keywords.
