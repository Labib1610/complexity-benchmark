# Problem B — Linkage Configuration

Time limit: 1 s   Memory limit: 256 MB

You are designing a mechanical linkage with $n$ vertical sliders, identified by integers from 1 to $n$. Your task is to lock each slider $i$ at a vertical height $h_i$, which must be exactly 1 or 2.

The linkage contains $m$ rigid struts. Each strut connects slider $u$ and slider $v$. To prevent the mechanism from binding under dynamic loads, each strut undergoes a stress test. The stress tensor for a strut connecting $u$ and $v$ is modeled as the $2 \times 2$ matrix:

$$ S = \begin{pmatrix} h_u + h_v & h_u - h_v \\ h_u - h_v & h_u + h_v \end{pmatrix} $$

For the assembly to pass inspection, the determinant of the stress tensor for every strut must be exactly 8. (If a slider is not connected to any struts, its height does not affect the stress tensors of any struts).

Your task is to determine whether all sliders can be locked at valid heights such that every strut's stress tensor meets the determinant requirement. If a valid configuration exists, you must provide the sequence of heights $h_1, h_2, \dots, h_n$ (where each $h_i \in \{1, 2\}$). If multiple valid sequences exist, you must output the one that produces the smallest possible value when the sequence of digits $h_1 h_2 \dots h_n$ is read as a single $n$-digit number in base 3.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a strut connecting slider $u$ and slider $v$.

## Output
If there is no way to assign the heights without violating the stress tensor requirement, print a single line containing NO.
Otherwise, print YES on the first line. On the second line, print $n$ space-separated integers $h_1, h_2, \dots, h_n$ (each either 1 or 2), representing the valid configuration sequence that minimizes the required base-3 value.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
