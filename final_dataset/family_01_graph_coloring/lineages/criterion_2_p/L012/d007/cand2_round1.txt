<METHOD_NAME>Singular Matrix Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replace the explicit geometric distance equation with a linear algebra constraint. The edge condition is enforced by requiring a 2x2 synchronization matrix constructed from the endpoint states to be singular. The determinant of this matrix evaluates to h_u * h_v - 2, which equals 0 if and only if one state is 1 and the other is 2. This hides the bipartite nature of the problem, forcing the model to solve the singularity condition to discover the h_u != h_v constraint before it can recognize the underlying graph coloring structure.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Linkage Configuration

Time limit: 1 s   Memory limit: 256 MB

You are designing a mechanical linkage with $n$ vertical sliders, identified by integers from 1 to $n$. Your task is to lock each slider at a configuration state $h_i$, which must be exactly 1 or 2.

The linkage contains $m$ rigid struts. Each strut connects slider $u$ and slider $v$. For the mechanism to assemble correctly without binding, the structural parameters of the two connected sliders must perfectly synchronize. Specifically, for every strut connecting $u$ and $v$, the connection defines a $2 \times 2$ synchronization matrix:
$$M_{u,v} = \begin{pmatrix} h_u & 2 \\ 1 & h_v \end{pmatrix}$$
For the mechanism to operate safely, this matrix must be singular (i.e., its determinant must be exactly zero). (If a slider is not connected to any struts, its state does not affect the assembly of other components).

Your task is to determine whether all sliders can be locked at valid states such that every strut perfectly synchronizes. If a valid configuration exists, you must provide the sequence of states $h_1, h_2, \dots, h_n$ (where each $h_i \in \{1, 2\}$). If multiple valid sequences exist, you must output the one that produces the smallest possible value when evaluated as the sum $\sum_{i=1}^n h_i \cdot 3^{n-i}$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a strut connecting slider $u$ and slider $v$.

## Output
If there is no way to assign the states without violating the matrix singularity requirement, print a single line containing NO.
Otherwise, print YES on the first line. On the second line, print $n$ space-separated integers $h_1, h_2, \dots, h_n$ (each either 1 or 2), representing the valid configuration sequence that minimizes the required sum.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit geometric formula $\sqrt{(u-v)^2+1}$ was removed because models easily simplified it to $(h_u - h_v)^2 = 1$, instantly revealing the bipartite coloring structure. It is replaced with a requirement that a specific $2 \times 2$ matrix must be singular. The determinant of this matrix is $h_u h_v - 2$, meaning it is singular if and only if $h_u h_v = 2$. Given the domain $\{1, 2\}$, this forces the endpoints to take opposite values. Models must now independently evaluate the linear algebra condition to uncover the graph structure.
</RATIONALE>
<PRESERVED_ANSWER>
The domain for $h_i$ remains $\{1, 2\}$, and the matrix singularity condition ($h_u h_v = 2$) is mathematically equivalent to the original Euclidean distance condition ($h_u \neq h_v$), so the set of valid configurations and the tie-breaking sum are exactly identical for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in linear time using Breadth-First Search, keeping it in the P complexity class.
</PRESERVED_CLASS>
