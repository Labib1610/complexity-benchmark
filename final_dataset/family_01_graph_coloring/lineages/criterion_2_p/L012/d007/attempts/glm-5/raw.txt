The perimeter requirement for a strut between sliders $u$ and $v$ (with $u < v$) is $2(v - u) + 2$.
The actual perimeter of the bounding box is $2(v - u) + 2|h_u - h_v|$.
For these to be equal, we must have $2|h_u - h_v| = 2$, which means $|h_u - h_v| = 1$.
Since the heights can only be 1 or 2, this implies that for every strut, the two connected sliders must have different heights.
This reduces the problem to a graph bipartiteness check. We can model the sliders as nodes and the struts as edges, and we need to assign each node a color (1 or 2) such that adjacent nodes have different colors.

To minimize the base-3 value of the sequence of heights, we should greedily assign the smallest possible height (which is 1) to the nodes. We can process the nodes from 1 to $n$. For each unvisited node $i$, we assign it height 1, and then perform a Depth-First Search (DFS) or Breadth-First Search (BFS) to assign the opposite height to all its neighbors. If at any point we find an edge connecting two nodes of the same height, the graph is not bipartite, and we output "NO". Otherwise, we output "YES" and the sequence of heights.

```python
import sys

def solve():
    input = sys.stdin.read
    data = input().split()
    if not data:
        return
    
    n = int(data[0])
    m = int(data[1])
    
    adj = [[] for _ in range(n + 1)]
    for i in range(m):
        u = int(data[2 + 2 * i])
        v = int(data[3 + 2 * i])
        adj[u].append(v)
        adj[v].append(u)
        
    h = [0] * (n + 1)
    
    for i in range(1, n + 1):
        if h[i] == 0:
            h[i] = 1
            stack = [i]
            while stack:
                u = stack.pop()
                for v in adj[u]:
                    if h[v] == 0:
                        h[v] = 3 - h[u]
                        stack.append(v)
                    elif h[v] == h[u]:
                        sys.stdout.write("NO\n")
                        return
                        
    sys.stdout.write("YES\n")
    sys.stdout.write(" ".join(map(str, h[1:])) + "\n")

if __name__ == '__main__':
    solve()
```
