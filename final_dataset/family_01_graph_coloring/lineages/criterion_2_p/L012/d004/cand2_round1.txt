# Problem B — Power Scaling

Time limit: 1 s   Memory limit: 256 MB

A manufacturing facility employs $n$ robotic welders, which are identified by integers from 1 to $n$. The facility requires each welder to be configured with a calibration mode of exactly 1 or 2.

Over time, management has installed $m$ shared power buses. Each bus connects two specific welders. A strict operational rule dictates that to prevent electrical overload, any two welders $u$ and $v$ connected by a shared bus must create a stable potential field. A field is considered stable if and only if the following system of linear equations (in real variables $x$ and $y$) has a unique solution:

$$s_u x + s_v y = s_u s_v$$
$$s_u^2 x + s_v^2 y = s_u^2 s_v^2$$

Here, $s_u$ and $s_v$ are the calibration modes assigned to welders $u$ and $v$, respectively.

Your task is to determine whether the entire set of welders can be configured in complete compliance with this operational rule. If a compliant configuration exists, you must provide the specific configuration sequence $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$ is the calibration mode assigned to welder $i$) that is lexicographically smallest. 

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — representing the two welders connected by a shared power bus.

## Output
If there is no way to assign the calibration modes without violating the operational rule, print a single line containing NO.
Otherwise, print YES on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (each either 1 or 2), representing the lexicographically smallest valid configuration sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Replaced the explicit "product of modes is 2" rule with a condition requiring a system of linear equations to have a unique solution. This forces the model to either compute the determinant of the coefficient matrix or test the four possible state combinations to discover that the rule simply enforces $s_u \neq s_v$, breaking surface-level pattern matching to graph bipartiteness.
</RATIONALE>
<PRESERVED_ANSWER>
The system of equations has a unique solution if and only if its determinant $s_u s_v(s_v - s_u)$ is non-zero, which for $s_i \in \{1, 2\}$ strictly means $s_u \neq s_v$; this is logically identical to the original "product is 2" rule, so the set of valid configurations and the lexicographical tie-breaker remain unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure is still exactly 2-coloring a graph and returning the lexicographically smallest valid assignment, which remains solvable in $O(n+m)$ time using BFS/DFS, keeping it in P.
</PRESERVED_CLASS>
