<STATEMENT>
# Problem B — Power Scaling

Time limit: 1 s   Memory limit: 256 MB

A manufacturing facility employs $n$ robotic welders, which are identified by integers from 1 to $n$. The facility requires each welder to be configured with a phase gear of exactly 1 or 2. 

Over time, management has installed $m$ shared power buses. Each bus connects two specific welders. A strict operational rule dictates that to prevent electrical overload, the resonance of any two welders connected by a shared bus must be perfectly asymmetric. Specifically, the product of the phase gears of the two welders connected by any bus must evaluate to exactly 2.

Your task is to determine whether the entire set of welders can be configured in complete compliance with this operational rule. If a compliant configuration exists, you must provide the specific configuration sequence $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$ is the phase gear assigned to welder $i$) that is lexicographically smallest. If no such configuration is possible, you must report that it cannot be done.

## Input
The first line contains two integers $n$ and $m$. The factory floor guarantees the headcount $n$ is between $1$ and $2 \cdot 10^5$ inclusive. The maintenance limits dictate the bus count $m$ is between $0$ and $2 \cdot 10^5$ inclusive.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — representing the two welders connected by a shared power bus.

## Output
If there is no way to assign the phase gears without violating the operational rule, print a single line containing NO.
Otherwise, print YES on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (each either 1 or 2), representing the lexicographically smallest valid configuration sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the explicit XOR constraint with a mathematically equivalent product constraint (the product must be 2 for values restricted to 1 and 2). This forces the model to independently deduce that connected components must have alternating values, rather than relying on the common 'XOR 3' pattern matching to identify graph bipartiteness. The bounds were also integrated into the narrative as physical limits to satisfy the indirect bounds strategy while keeping exact numeric constraints present.
</RATIONALE>
<PRESERVED_ANSWER>
Since the allowed phase gear values are exactly 1 and 2, the only way their product can evaluate to exactly 2 is if one value is 1 and the other is 2, which is logically identical to the original requirement where their XOR evaluates to 3.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core task remains exactly equivalent to finding a valid 2-coloring of an undirected graph (bipartiteness check) and selecting the lexicographically first valid assignment, which is solvable in O(n + m) time using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the product constraint if they fail to link it strictly to the {1, 2} domain, though the domain is explicitly stated twice in the text.
</RISK>
