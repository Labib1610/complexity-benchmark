**Solution Explanation**

For every edge `{u,v}` we need  

```
s[u] * s[v] = 2 ,   s[i] ∈ {1,2}
```

The only possibilities are `(1,2)` or `(2,1)`.  
Thus the two endpoints must receive *different* values – the graph has to be
**bipartite**.  
If the graph is not bipartite the answer is `NO`.

If it is bipartite we have to output the lexicographically smallest
assignment `s1 … sn`.  
Inside one connected component the two colour classes can be swapped
(`class A → 1 , class B → 2` or the opposite).  
Components are independent, therefore the global lexicographic order is
determined by the first vertex of each component (the smallest index inside
the component).  
When we process vertices in increasing order, the first unvisited vertex `i`
is exactly the smallest index of its component.  
To obtain the smallest possible value at position `i` we must give it `1`.
Consequently the whole colour class of `i` gets value `1` and the opposite
class gets `2`.

So the algorithm is:

```
for i = 1 .. n
    if i not visited
        BFS/DFS from i, colour vertices 0/1, collect component
        if a conflict appears -> NOT bipartite -> NO
        let col_i = colour[i]          # colour of the smallest vertex
        for each vertex v in component
            if colour[v] == col_i:  answer[v] = 1
            else:                   answer[v] = 2
```

All isolated vertices are handled as components of size 1 and receive `1`.

The algorithm runs in `O(n+m)` time and `O(n+m)` memory, well inside the limits.



**Correctness Proof**

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise prints `YES` and the lexicographically smallest valid assignment.

---

*Lemma 1*  
A labeling satisfying the edge condition exists **iff** the graph is bipartite.

*Proof.*  
If a labeling exists, every edge connects vertices with different values
(1 vs 2), therefore the graph can be coloured with two colours (value 1 and
value 2) – it is bipartite.  
Conversely, if the graph is bipartite, colour the two parts with 1 and 2;
every edge joins different colours, product is 2. ∎



*Lemma 2*  
During processing of a component, assigning value 1 to the colour class of
its smallest indexed vertex yields the smallest possible value at that
position among all valid labelings of the component.

*Proof.*  
The smallest vertex `i` belongs to exactly one colour class `C`.  
Any valid labeling must give the two colour classes opposite values
(1 and 2). Hence `i` receives either 1 or 2. Choosing 1 is strictly better
lexicographically, and it is feasible by giving class `C` value 1. ∎



*Lemma 3*  
For a fixed component, after fixing the value of its smallest vertex to 1,
the resulting labeling is the unique lexicographically smallest labeling of
that component.

*Proof.*  
With `i` forced to 1, the opposite class must be 2 (otherwise edge condition
fails). This determines the value of every vertex in the component uniquely.
Any other valid labeling would have `i` = 2, which is lexicographically larger.
∎



*Lemma 4*  
The algorithm’s assignment is lexicographically smallest among all global
valid assignments.

*Proof.*  
Components are processed in increasing order of their smallest vertex.
Consider the first index where two global assignments differ.
It belongs to some component `C` and is the smallest vertex of `C`.
By Lemma 2 the algorithm gives this vertex value 1, which is the minimum
possible. Hence no other global assignment can be lexicographically smaller.
∎



*Theorem*  
The algorithm outputs  

* `NO` iff no assignment satisfying all edges exists;  
* otherwise `YES` and the lexicographically smallest assignment.

*Proof.*  
If the algorithm detects a colour conflict, the graph is not bipartite,
so by Lemma 1 no assignment exists → output `NO`.  
If no conflict occurs, the graph is bipartite, thus a valid assignment exists.
The algorithm constructs an assignment as described; by Lemma 3 each
component’s part is the smallest possible, and by Lemma 4 the whole vector is
lexicographically minimal. Hence it outputs a correct `YES` answer. ∎



**Complexity Analysis**

* Building adjacency lists: `O(n+m)` time, `O(n+m)` memory.  
* One BFS/DFS over all vertices and edges: `O(n+m)` time, `O(n)` extra memory
  for queues/stack and colour array.  
* Final output: `O(n)`.

Total: `O(n+m)` time, `O(n+m)` memory.



**Reference Implementation (Python 3)**

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # 0 / 1
    ans = [0] * (n + 1)
    from collections import deque

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # new component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        ok = True
        while q:
            u = q.popleft()
            for v in adj[u]:
                if colour[v] == -1:
                    colour[v] = colour[u] ^ 1
                    q.append(v)
                    comp.append(v)
                elif colour[v] == colour[u]:
                    print("NO")
                    return
        # assign values: colour of start gets 1
        col_start = colour[start]
        for v in comp:
            ans[v] = 1 if colour[v] == col_start else 2

    # all done
    print("YES")
    print(' '.join(str(ans[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
