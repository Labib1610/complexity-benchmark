# Problem B — Orbital Relays

Time limit: 1 s   Memory limit: 256 MB

A communications network consists of $n$ satellite relays, numbered 1 to $n$. Each relay must be assigned an operational tier of exactly 1 or 2.

The network relies on $m$ laser uplinks. Each uplink maintains a continuous data connection between two specific relays. To prevent signal desynchronization, the communication protocol requires a precise impedance mismatch between any two linked relays. The mismatch score for an uplink connecting a relay at tier $t_u$ and a relay at tier $t_v$ is calculated as the ratio of their tiers plus its reciprocal:
$$ \frac{t_u}{t_v} + \frac{t_v}{t_u} $$
For the uplink to remain stable, this mismatch score must evaluate to exactly 2.5.

Your task is to determine whether all $n$ relays can be assigned a tier (1 or 2) such that every uplink in the network is stable. If a valid configuration exists, you must provide the sequence of tier assignments $t_1, t_2, \dots, t_n$ that is lexicographically smallest. If no such configuration is possible, you must report that it cannot be done.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — representing two relays connected by an uplink.

## Output
If there is no way to assign the tiers without destabilizing at least one uplink, print a single line containing NO.
Otherwise, print YES on the first line. On the second line, print $n$ space-separated integers $t_1, t_2, \dots, t_n$ (each either 1 or 2), representing the lexicographically smallest valid assignment sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the "bitwise XOR to 3" operational rule with a rational equation modeling an impedance mismatch ratio. This removes the explicit boolean toggle affordance, forcing the model to algebraically evaluate the constraint over the domain {1, 2} to discover that it strictly enforces opposite assignments.
</RATIONALE>
<PRESERVED_ANSWER>
The equation $t_u/t_v + t_v/t_u = 2.5$ for $t \in \{1, 2\}$ is satisfied if and only if one tier is 1 and the other is 2, identically mirroring the original $t_u \oplus t_v = 3$ constraint, so all valid configurations and the lexicographically smallest tie-break remain unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem requires assigning two possible states to nodes such that no two connected nodes share the same state, which maps perfectly to 2-coloring and bipartiteness testing (solvable in O(n+m) via BFS).
</PRESERVED_CLASS>
<RISK>
Models might overthink the phrase "evaluate to exactly 2.5" and worry about floating-point precision, but since the input domain is strictly the integers 1 and 2, the evaluation is discrete and exact, minimizing real ambiguity.
</RISK>
