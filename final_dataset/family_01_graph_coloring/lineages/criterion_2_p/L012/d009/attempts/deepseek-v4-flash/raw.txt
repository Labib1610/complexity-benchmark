We can model each constraint as requiring that the two variables have opposite truth values.  

The clauses are:  
- \( x_u \lor x_v \)  
- \( \neg x_u \lor \neg x_v \)  

Together, these force \( x_u \neq x_v \).  

So the problem becomes:  
- Build a graph where each edge means “these two variables must be different.”  
- Check if the graph is bipartite.  
- If not, output `NO`.  
- If yes, assign values to minimize lexicographic order, where `1` < `2`.  

We can do a BFS/DFS coloring, trying to assign `1` whenever possible.  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    # color 0 -> 1, color 1 -> 2
    ans = [1 if c == 0 else 2 for c in color]
    print("YES")
    print(" ".join(map(str, ans)))
```
