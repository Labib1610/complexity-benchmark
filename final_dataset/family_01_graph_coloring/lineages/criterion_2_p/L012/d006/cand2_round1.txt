<METHOD_DESCRIPTION>
Replaces the direct scalar relationship between connected nodes with a 3D vector sum collinearity condition. By mapping the binary states to non-parallel 3D vectors and requiring the neighborhood sum to be collinear with a target vector, it perfectly encodes bipartite coloring while looking like a continuous linear algebra problem, defeating models that rely on recognizing simple arithmetic graph conditions.
</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Power Scaling

Time limit: 1 s   Memory limit: 256 MB

A manufacturing facility employs $n$ robotic welders, identified by integers from 1 to $n$. The facility requires each welder to be configured with a calibration mode of exactly 1 or 2.

This mode defines the welder's operational vector in a 3D control space. Specifically, if welder $i$ is assigned mode $s_i \in \{1, 2\}$, its operational vector is defined as $\mathbf{p}_i = (s_i, 3-s_i, 1)$.

Over time, management has installed $m$ shared power buses. Each bus connects two specific welders. A strict operational rule dictates that to prevent electrical overload, the system must maintain local equilibrium. Specifically, for every welder $i$, let $\mathbf{V}_i$ be the vector sum of the operational vectors of all welders connected to it via a bus. (If a welder is not connected to any buses, $\mathbf{V}_i = (0,0,0)$).

The equilibrium rule requires that for every welder $i$, its neighbor-sum vector $\mathbf{V}_i$ must be perfectly collinear with its own target vector $\mathbf{t}_i = (3-s_i, s_i, 1)$. (Note: the zero vector $(0,0,0)$ is considered collinear with any vector).

Your task is to determine whether the entire set of welders can be configured in complete compliance with this operational rule. If a compliant configuration exists, you must provide the specific configuration sequence $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$). If multiple such compliant sequences exist, you must output the one that produces the smallest possible value when evaluated as the sum $\sum_{i=1}^n s_i \cdot 3^{n-i}$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a power bus connecting welder $u$ and welder $v$.

## Output
If there is no way to assign the calibration modes without violating the operational rule, print a single line containing NO.
Otherwise, print YES on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (each either 1 or 2), representing the valid configuration sequence that minimizes the required sum.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the scalar neighborhood sum condition with a 3D vector sum collinearity condition. This completely hides the simple "s_j = 3 - s_i" scalar relationship from pattern-matching LLMs, forcing them to algebraically solve the vector cross-product to discover that the rule strictly requires all neighbors to have the opposite state.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the sum of neighbor vectors $a(3-s_i, s_i, 1) + b(s_i, 3-s_i, 1)$ is collinear with $(3-s_i, s_i, 1)$ mathematically simplifies to $b(2s_i - 3) = 0$, meaning $b=0$; thus every adjacent welder must have a different mode, which exactly matches the valid configurations of the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in linear time using BFS, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might struggle with the definition of collinearity if they assume it requires non-zero vectors, but this is mitigated by explicitly stating that the zero vector is considered collinear with any vector.
</RISK>
