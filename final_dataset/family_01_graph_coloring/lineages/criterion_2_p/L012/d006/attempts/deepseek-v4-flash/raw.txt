 We need to assign each slider a height of 1 or 2 such that for every strut between u and v, the distance condition holds:

\[
\sqrt{(u-v)^2 + (h_u - h_v)^2} = \sqrt{(u-v)^2 + 1}
\]

This simplifies to:

\[
(h_u - h_v)^2 = 1
\]

So the heights must differ by exactly 1. Since heights are only 1 or 2, this means:

- If \( h_u = 1 \), then \( h_v = 2 \)
- If \( h_u = 2 \), then \( h_v = 1 \)

Thus, each strut forces its two endpoints to have opposite heights. This is exactly a bipartite constraint: we can model it as a graph where each edge requires opposite colors.

If the graph is not bipartite, it's impossible → output "NO".  
If it is bipartite, we can color it. To get the lexicographically smallest sequence (since the sum with powers of 3 is minimized by smallest possible values from left to right), we should assign height 1 to the first node if possible, and propagate.

We can do BFS/DFS, trying to assign 1 to node 1 first, and if conflict occurs, try assigning 2 to node 1.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

def try_color(start_color):
    color = [-1] * n
    color[0] = start_color
    q = deque([0])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                return None
    # If some nodes are unvisited (disconnected), color them with 0
    for i in range(n):
        if color[i] == -1:
            color[i] = 0
            q = deque([i])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = 1 - color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        return None
    return color

# Try starting with 0 (height 1)
res = try_color(0)
if res is None:
    res = try_color(1)
if res is None:
    print("NO")
else:
    print("YES")
    print(" ".join(str(c + 1) for c in res))
```
