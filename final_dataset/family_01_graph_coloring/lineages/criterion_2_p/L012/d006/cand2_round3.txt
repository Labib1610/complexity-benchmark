<METHOD_NAME>Bitwise XOR equivalent constraint</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit 'opposite modes' or 'averaging' constraint with a bitwise XOR condition (s_u XOR s_v == 3) that is logically identical over the domain {1, 2}, obfuscating the graph bipartiteness property.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Power Scaling

Time limit: 1 s   Memory limit: 256 MB

A manufacturing facility employs $n$ robotic welders, identified by integers from 1 to $n$. The facility requires each welder to be configured with a calibration mode of exactly 1 or 2.

Over time, management has installed $m$ shared power buses. Each bus connects two specific welders. A strict operational rule dictates that to prevent electrical overload, the system must maintain local equilibrium across all connections. Specifically, for every power bus connecting a welder $u$ and a welder $v$, the bitwise XOR of their assigned calibration modes ($s_u \oplus s_v$) must evaluate to exactly 3. 

Your task is to determine whether the entire set of welders can be configured in complete compliance with this operational rule. If a compliant configuration exists, you must provide the specific configuration sequence $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$). If multiple such compliant sequences exist, you must output the one that produces the smallest possible value when evaluated as the sum $\sum_{i=1}^n s_i \cdot 3^{n-i}$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a power bus connecting welder $u$ and welder $v$.

## Output
If there is no way to assign the calibration modes without violating the operational rule, print a single line containing NO.
Otherwise, print YES on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (each either 1 or 2), representing the valid configuration sequence that minimizes the required sum.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was simplified back to its core pairwise constraint to avoid the task drift (H5) caused by the previous averaging formulation. To prevent models from instantly recognizing the bipartite graph coloring structure, the requirement that connected welders must have different modes is now expressed as a bitwise XOR condition ($s_u \oplus s_v = 3$). Because the domain is strictly restricted to $\{1, 2\}$, this bitwise equation is mathematically identical to $s_u \neq s_v$, forcing models to reason about the domain rather than pattern-matching standard graph terminology.
</RATIONALE>
<PRESERVED_ANSWER>
Because the only valid calibration modes are 1 and 2, the condition $s_u \oplus s_v = 3$ is satisfied if and only if one mode is 1 (binary 01) and the other is 2 (binary 10); thus, the set of valid configurations and the tie-breaking sum are exactly identical to the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to checking whether a graph is bipartite (2-colorable) and assigning colors to minimize a lexicographical objective, which is solvable in linear time O(n + m) using BFS or DFS.
</PRESERVED_CLASS>
