# Problem B — Power Scaling

Time limit: 1 s   Memory limit: 256 MB

A manufacturing facility employs $n$ robotic welders, identified by integers from 1 to $n$. The facility requires each welder to be configured with a calibration mode of exactly 1 or 2.

Over time, management has installed $m$ shared power buses. Each bus connects two specific welders. A strict operational rule dictates that to prevent electrical overload, the system must maintain local equilibrium at every node. To assess the equilibrium for any specific welder that is connected to at least one bus, the system calculates the arithmetic mean of the calibration modes found at the opposite end of each of its connected buses. For the system to remain stable, this calculated mean must evaluate to exactly three minus that welder's own assigned calibration mode. (Welders with zero bus connections trivially satisfy the equilibrium rule).

Your task is to determine whether the entire set of welders can be configured in complete compliance with this operational rule. If a compliant configuration exists, you must provide the specific configuration sequence $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$). If multiple valid assignments exist, you must output the lexicographically smallest sequence $s_1, s_2, \dots, s_n$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a power bus connecting welder $u$ and welder $v$.

## Output
If there is no way to assign the calibration modes without violating the operational rule, print a single line containing NO.
Otherwise, print YES on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (each either 1 or 2), representing the lexicographically smallest valid configuration sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<METHOD_DESCRIPTION>
Replaced the explicit summation equation with a prose requirement that the arithmetic mean of the neighbors' modes equals `3 - own_mode`. This preserves the exact mathematical constraint while removing the recognizable symbolic pattern `sum = k_i * (3 - s_i)` that models use to trigger bipartite graph templates. It forces the solver to logically deduce that since modes are bounded in {1, 2}, an average of `3 - s_i` strictly requires all adjacent modes to be identical to each other and opposite to `s_i`.
</METHOD_DESCRIPTION>
