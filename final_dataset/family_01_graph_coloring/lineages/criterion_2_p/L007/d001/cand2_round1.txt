# Problem B — Tuning Multipliers

Time limit: 1 s   Memory limit: 256 MB

A communication network consists of $n$ radio towers. Each tower must be configured with a tuning multiplier chosen from the set $\{1, 2\}$. 

The network also contains $m$ coupled pairs of towers. To maintain signal stability, every coupled pair must satisfy a specific condition: the product of the tuning multipliers assigned to the two towers in the pair must be exactly $2$. 

Determine a valid assignment of tuning multipliers for all $n$ towers, or report that it is impossible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a coupled pair of towers.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $t_1 \dots t_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment of tuning multipliers.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>

The models were pattern-matching the phrase "no interfering pair shares a frequency" directly to bipartite graph 2-coloring and parity checks. By replacing the "different frequency" constraint with the algebraic requirement that the product of the two multipliers (from the set {1, 2}) must be exactly 2, models are forced to logically deduce that the values must be distinct before they can apply the bipartite coloring algorithm. The flawed prompt suggestion to require both frequencies globally was ignored because it would violate the strict identical answers constraint for edgeless instances.
</RATIONALE>
<PRESERVED_ANSWER>
Since the domain is strictly {1, 2}, the condition that their product is exactly 2 is mathematically equivalent to requiring that the two values are distinct, exactly preserving all valid assignments, impossibility conditions, and the lexicographical tie-breaker.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure is still perfectly equivalent to checking if an undirected graph is bipartite and finding the lexicographically first valid 2-coloring, which is solvable in O(n+m) time using BFS or DFS.
</PRESERVED_CLASS>
