We can model each tower as a variable that can be either 1 or 2.  

For an edge (u, v), the condition is:  
primary(u) == backup(v) and primary(v) == backup(u).  

Since backup(x) = 3 - primary(x), the edge condition becomes:
- primary(u) = 3 - primary(v)  
- primary(v) = 3 - primary(u)  

This means f[u] and f[v] must be **different**.  
So we need a valid 2-coloring of the graph using colors {1, 2}.

If the graph is not bipartite → NO.  
Otherwise, we need the lexicographically smallest coloring.

This can be solved with DFS/BFS:  
- Assign component starting at lowest-index node color 1 (to minimize lexicographic order).  
- Propagate alternating colors within each connected component.

Here's the implementation:

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    g = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)

    color = [-1] * n

    def bfs(start):
        from collections import deque
        q = deque([start])
        color[start] = 0
        while q:
            u = q.popleft()
            for v in g[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    return False
        return True

    for i in range(n):
        if color[i] == -1:
            if not bfs(i):
                print("NO")
                return

    print("YES")
    # The coloring: color 0 => protocol 1, color 1 => protocol 2
    # But to get lexicographically smallest, for each component we start
    # with 0 for the smallest node in that component. Already satisfied.

    ans = [c + 1 for c in color]
    print(" ".join(map(str, ans)))

if __name__ == "__main__":
    solve()
```
