<STATEMENT>
# Problem B — Network Configurations

Time limit: 1 s
Memory limit: 256 MB

A communication grid consists of $n$ radio towers. You need to assign each tower $k$ a protocol flag $f_k$, which must be chosen from the set $\{1, 2\}$. 

There are $m$ critical links between specific pairs of towers. 

To prevent catastrophic interference and signal dropping, the configuration must adhere to a strict network-wide phase regulation.
- For any tower $k$, its phase factor is defined as the complex number $c_k = i^{f_k}$, where $i$ is the imaginary unit ($i = \sqrt{-1}$).
- For a critical link connecting tower $u$ and tower $v$, the interference generated by the link is the magnitude (absolute value) of the sum of their phase factors, $|c_u + c_v|$.

The total interference generated by all $m$ critical links combined must not exceed $m \sqrt{2}$.

Determine if a valid assignment of protocol flags exists for all towers such that the network-wide phase regulation is satisfied. If no such assignment is possible, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of towers connected by a critical link.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $f_1 \dots f_n$ (each in $\{1,2\}$). 
If multiple valid assignments exist, you must resolve ties by choosing the assignment that assigns the smallest possible flag to tower 1. If ties remain, among those, choose the one that assigns the smallest possible flag to tower 2, and continue this sequential preference for smaller flags up to tower $n$ (this is equivalent to the lexicographically smallest valid assignment).

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit mutual exclusion rules with a global continuous-looking constraint using complex numbers. By defining the phase as $i^{f_k}$, the interference of a link is exactly 2 if the flags are identical, and $\sqrt{2}$ if they differ. The global bound of $m\sqrt{2}$ mathematically forces every link to take the minimum possible value, requiring the model to deduce that $f_u \neq f_v$ for all links before it can recognize the underlying graph structure.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical minimum interference for any single link is $\sqrt{2}$ (achieved only when endpoints have different flags), so a total interference of at most $m\sqrt{2}$ across $m$ links is only achievable if every single link has different flags, which is exactly the same per-edge validity condition as the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still reduces entirely to finding a valid 2-coloring (bipartite check) of the graph and outputting the lexicographically smallest one, which remains solvable in $O(N+M)$ time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
Models might attempt to use floating-point arithmetic to check the condition dynamically during a search instead of deducing the exact discrete property, which could theoretically lead to precision issues, though the strict mathematical deduction $N_{same} = 0$ makes this unlikely to cause ambiguity for a competent reader.
</RISK>
