<STATEMENT>
# Problem B — Quantum Sensor Calibration

Time limit: 1 s
Memory limit: 256 MB

You are calibrating a network of $n$ quantum sensors. Each sensor $i$ must be configured with a measurement basis $b_i \in \{1, 2\}$. 

There are $m$ entanglement links between specific pairs of sensors. Let $E$ be the collection of these $m$ links, and let $d_i$ be the degree of sensor $i$ (the total number of link endpoints attached to sensor $i$). 

For the network to function successfully, the assigned bases must satisfy the following global calibration equation:
$$ 2 \sum_{(u,v) \in E} b_u b_v + 5m = 3 \sum_{i=1}^n d_i b_i $$

Determine if a valid assignment of measurement bases exists for all sensors such that this equation is satisfied. If no such assignment is possible, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of sensors connected by an entanglement link.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $b_1 \dots b_n$ (each in $\{1,2\}$). 
If multiple valid assignments exist, you must resolve ties by choosing the assignment that assigns the smallest possible basis to sensor 1. If ties remain, among those, choose the one that assigns the smallest possible basis to sensor 2, and continue this sequential preference for smaller bases up to sensor $n$ (this is equivalent to the lexicographically smallest valid assignment).

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit pairwise anti-commutation condition (which models easily recognized as a bipartite/2-SAT constraint) was replaced with a single global Diophantine-style equation. By equating a weighted sum of edge products with a weighted sum of vertex degrees, the equation algebraically factors into a sum of non-negative local terms that equals zero if and only if $b_u \neq b_v$ for all edges. This forces models to perform a non-trivial algebraic factorization to discover the underlying 2-coloring structure, defeating pattern-matching on local constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The global equation algebraically simplifies to $\sum_{(u,v) \in E} (2b_u b_v - 3b_u - 3b_v + 5) = 0$, and since the inner term evaluates to 1 when $b_u = b_v \in \{1,2\}$ and 0 when $b_u \neq b_v$, the equation holds if and only if every edge connects different bases, which is exactly the original condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks whether the graph is 2-colorable and to find the lexicographically smallest valid coloring, which remains solvable in $O(N+M)$ time using Breadth-First Search.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret $d_i$ if the graph contains parallel edges or self-loops, but the explicit definition of degree as "the total number of link endpoints attached to sensor $i$" eliminates this ambiguity.
</RISK>
