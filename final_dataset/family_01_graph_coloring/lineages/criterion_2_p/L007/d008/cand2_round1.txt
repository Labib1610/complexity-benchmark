# Problem B — Quantum Sensor Calibration

Time limit: 1 s
Memory limit: 256 MB

You are calibrating a network of $n$ quantum sensors. Each sensor $i$ must be configured with a measurement basis $b_i \in \{1, 2\}$. 
The basis chosen dictates the tuning vector applied by the sensor:
- Choosing basis 1 configures the sensor with the vector $V = (5, 2, -1, 3)$.
- Choosing basis 2 configures the sensor with the vector $V = (-4, -3, -1, 3)$.

There are $m$ entanglement links between specific pairs of sensors. 
For a successful joint measurement across an entanglement link between sensor $u$ and sensor $v$, their configured tuning vectors, denoted $V_u$ and $V_v$, must have a strictly negative dot product. That is, they must satisfy $V_u \cdot V_v < 0$.

Determine if a valid assignment of measurement bases exists for all sensors such that the joint measurement condition is satisfied for all entanglement links. If no such assignment is possible, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of sensors connected by an entanglement link.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $b_1 \dots b_n$ (each in $\{1,2\}$). 
If multiple valid assignments exist, you must resolve ties by choosing the assignment that assigns the smallest possible basis to sensor 1. If ties remain, among those, choose the one that assigns the smallest possible basis to sensor 2, and continue this sequential preference for smaller bases up to sensor $n$ (this is equivalent to the lexicographically smallest valid assignment).

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit Pauli matrices and anti-commutation equation were replaced with an asymmetric algebraic condition (a dot product of seemingly unrelated vectors). Because $V_1 \cdot V_1 = 39$, $V_2 \cdot V_2 = 35$, and $V_1 \cdot V_2 = -16$, the condition $V_u \cdot V_v < 0$ still perfectly enforces $b_u \neq b_v$. This defeats models that blindly pattern-match symmetric structures to 2-coloring/2-SAT, forcing them to manually evaluate the condition to discover the bipartiteness.
</RATIONALE>
<PRESERVED_ANSWER>
The dot product condition evaluates to true if and only if the connected sensors have different bases, making the valid configurations identical to the original anti-commuting requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring of a graph, which is solvable in O(n + m) time using BFS or DFS, keeping it in P.
</PRESERVED_CLASS>
