We can model this as a graph coloring problem.  

For each edge \((u, v)\), the condition is that the sum of their matrices must be invertible.  

- If both use basis 1:  
  \(C_1 + C_1 = \begin{pmatrix}2 & 2 \\ 2 & 2\end{pmatrix}\) → determinant 0 → invalid.  
- If both use basis 2:  
  \(C_2 + C_2 = \begin{pmatrix}2 & -2 \\ -2 & 2\end{pmatrix}\) → determinant 0 → invalid.  
- If one uses basis 1 and the other basis 2:  
  \(C_1 + C_2 = \begin{pmatrix}2 & 0 \\ 0 & 2\end{pmatrix}\) → determinant 4 → valid.  

So each edge must connect sensors with **different** bases.  
This is exactly a bipartite graph check.  

We need to assign 1 or 2 to each node such that adjacent nodes differ, and the assignment is lexicographically smallest (prefer 1 for lower indices).  

We can do BFS/DFS coloring, starting with 1 for each unvisited node, and if a conflict occurs, output NO.  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 0  # 0 means basis 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
