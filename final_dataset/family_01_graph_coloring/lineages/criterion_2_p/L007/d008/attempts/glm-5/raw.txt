We need to determine when C_u + C_v is invertible.

C1 = [[1,1],[1,1]], C2 = [[1,-1],[-1,1]].

C1+C1 = [[2,2],[2,2]], det = 0.
C2+C2 = [[2,-2],[-2,2]], det = 0.
C1+C2 = [[2,0],[0,2]], det = 4 ≠ 0.
C2+C1 = same, det ≠ 0.

So the condition is: for every edge, the two endpoints must have different bases. This is exactly 2-coloring (bipartiteness check).

We need the lexicographically smallest valid assignment, preferring basis 1. For a connected component, once we fix the color of the smallest-indexed node to 1, the rest are determined. If the component is bipartite, this gives a unique assignment per component. We need the lexicographically smallest overall, which is achieved by always assigning the smallest unvisited node basis 1 and BFS/DFS coloring.

```python
import sys
from collections import deque

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * (n+1)
    for start in range(1, n+1):
        if color[start] != 0:
            continue
        color[start] = 1
        dq = deque([start])
        while dq:
            u = dq.popleft()
            for v in adj[u]:
                if color[v] == 0:
                    color[v] = 3 - color[u]
                    dq.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    return
    
    print("YES")
    print(' '.join(str(color[i]) for i in range(1, n+1)))

solve()
```
