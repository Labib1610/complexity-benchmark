We can model this as a bipartite graph problem:  
Each tower is a node, and each critical link is an edge.  
The condition “exactly one high and one low” means the two endpoints must have different configurations.  
So we need to check if the graph is bipartite, and if so, assign values 1 and 2 accordingly.  

To get the lexicographically smallest assignment, we can run BFS/DFS from each unvisited node, assigning 1 to the starting node and alternating.  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    # color 0 -> config 1, color 1 -> config 2
    print(' '.join(str(c + 1) for c in color))
```
