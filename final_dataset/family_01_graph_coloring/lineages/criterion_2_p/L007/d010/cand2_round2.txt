# Problem B — Network Topology Design

Time limit: 1 s
Memory limit: 256 MB

You are designing a distributed computing network consisting of $n$ clusters. Each cluster $i$ must be configured with a specific internal topology $b_i \in \{1, 2\}$. 

Choosing topology 1 configures the cluster as a 2-node linear graph (a single edge connecting two vertices).
Choosing topology 2 configures the cluster as a 3-node ring graph (a triangle consisting of three vertices and three edges).

There are $m$ high-speed synchronization links between specific pairs of clusters. For a synchronization link between cluster $u$ and cluster $v$ to be robust, the Cartesian product of their chosen internal topologies must **not** contain an Eulerian circuit. 

(Recall that the Cartesian product $G \square H$ of two graphs $G$ and $H$ has the vertex set $V(G) \times V(H)$. Two vertices $(u_1, v_1)$ and $(u_2, v_2)$ are adjacent in $G \square H$ if and only if either $u_1 = u_2$ and $v_1$ is adjacent to $v_2$ in $H$, or $v_1 = v_2$ and $u_1$ is adjacent to $u_2$ in $G$. An Eulerian circuit is a trail that visits every edge of the graph exactly once and starts and ends on the same vertex.)

Determine if a valid assignment of topologies exists for all $n$ clusters such that this robustness condition is satisfied for all $m$ synchronization links. If no such assignment is possible, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of clusters connected by a synchronization link.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $b_1 \dots b_n$ (each in $\{1,2\}$). 
If multiple valid assignments exist, you must output the assignment that minimizes the sequence $b_1, b_2, \dots, b_n$ when it is interpreted as an $n$-digit base-3 integer (where $b_1$ is the most significant digit and $b_n$ is the least significant digit).

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
