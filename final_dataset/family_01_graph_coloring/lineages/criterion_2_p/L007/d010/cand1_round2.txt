<STATEMENT>
# Problem B — Quantum Sensor Calibration

Time limit: 1 s
Memory limit: 256 MB

You are calibrating a network of $n$ quantum sensors. Each sensor $i$ must be configured with a measurement basis $b_i \in \{1, 2\}$.

There are $m$ interference links between specific pairs of sensors. For each sensor $i$, let $d_i$ be the number of interference links incident to it. 

For the network to be properly calibrated, the assigned bases must satisfy the following condition for every sensor $i$: the product of the assigned bases of the sensors at the other ends of its $d_i$ incident links must evaluate to exactly $2^{d_i}$ if $b_i = 1$, and must evaluate to exactly $1$ if $b_i = 2$. 

When calculating this product, it ranges over the $d_i$ incident links. That is, there is exactly one factor per incident link occurrence, so if multiple links were to connect the same pair of sensors, the neighbor's basis would be included as a factor once for each connecting link. For $d_i = 0$, the empty product is defined as 1.

Determine if a valid assignment of measurement bases exists for all sensors such that this condition is satisfied for every sensor. If no such assignment is possible, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of sensors connected by an interference link.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $b_1 \dots b_n$ (each in $\{1,2\}$). 
If multiple valid assignments exist, you must output the assignment that minimizes the sequence $b_1, b_2, \dots, b_n$ when it is interpreted as an $n$-digit base-3 integer (where $b_1$ is the most significant digit and $b_n$ is the least significant digit).

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit pairwise affine transformations (which models easily recognized as mutual inverses) with a vertex-centric multiplicative constraint. By requiring the product of a sensor's neighbors to be $2^{d_i}$ when its state is 1, and $1$ when its state is 2, it mathematically forces all neighbors to have the opposite state. This forces models to logically deduce that the multiplicative constraint is equivalent to strict alternation (2-coloring), while breaking the known shortcut of spotting inverse functions. The tie-breaker and I/O format were restored exactly to the seed to prevent task drift.
</RATIONALE>
<PRESERVED_ANSWER>
Because each $b_v \in \{1, 2\}$, the product of $d_i$ neighbors equals $2^{d_i}$ if and only if all neighbors are 2, and equals $1$ if and only if all neighbors are 1; this restricts valid assignments to exactly those where every edge connects a 1 and a 2, keeping the solution set and tie-breaker completely identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains strictly equivalent to finding the lexicographically smallest 2-coloring of a graph, which is still solvable in linear time O(n+m) using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the empty product convention for isolated vertices, though the explicit statement "For $d_i = 0$, the empty product is defined as 1" directly mitigates this.
</RISK>
<METHOD_NAME>
Multiplicative Vertex-Neighborhood Condition
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the pairwise affine transformation constraint with a mathematically equivalent product constraint over each vertex's neighborhood. A vertex assigned 1 requires the product of its neighbors to be 2^d, meaning all neighbors must be 2. A vertex assigned 2 requires the product to be 1, meaning all neighbors must be 1. This obfuscates the bipartite coloring requirement by framing it as a local multiplicative property rather than a mutual inverse function or explicit edge inequality.
</METHOD_DESCRIPTION>
