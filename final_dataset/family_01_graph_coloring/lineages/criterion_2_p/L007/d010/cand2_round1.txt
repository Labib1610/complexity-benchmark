# Problem B — Quantum Sensor Calibration

Time limit: 1 s
Memory limit: 256 MB

You are calibrating a network of quantum sensors. Each sensor $i$ must be configured with a measurement basis $b_i \in \{1, 2\}$. 

There are interference links between specific pairs of sensors. For a successful joint measurement across an interference link between sensor $u$ and sensor $v$, their combined configuration must support a valid quantum resonance. Specifically, a resonance is physically possible if and only if the Diophantine equation 
$$X^2 - (b_u + b_v + 2)Y^2 = -1$$ 
has at least one solution where $X$ and $Y$ are integers.

Determine if a valid assignment of measurement bases exists for all sensors such that this resonance condition is satisfied for all interference links. If no such assignment is possible, report impossibility.

## Input
The first line provides the exact number of sensors $n$ and links $m$ for the current calibration run. The facility can support a maximum capacity where the sum of the number of sensors and the number of links does not exceed $400,000$, and neither the sensor count nor the link count will ever exceed half of this total capacity. There is always at least one sensor, though there might be zero links.

Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of sensors connected by an interference link.

## Output
If no valid assignment exists, print a single line containing `NO`.

Otherwise, print `YES` on the first line. On the second line, print $n$ integers $b_1 \dots b_n$ (each in $\{1,2\}$). 
If multiple valid assignments exist, you must output the assignment that minimizes the sequence $b_1, b_2, \dots, b_n$ when it is interpreted as an $n$-digit base-3 integer (where $b_1$ is the most significant digit and $b_n$ is the least significant digit).

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

This forces the model to mathematically evaluate the equation's solvability for different sums of $b_u + b_v$ to discover that only differing bases yield a valid resonance, demanding genuine algorithmic reasoning over surface-level recognition. Additionally, I applied S07 to restate the input bounds indirectly as a facility capacity limit.
</RATIONALE>
<PRESERVED_ANSWER>
The Diophantine equation $X^2 - (b_u + b_v + 2)Y^2 = -1$ has integer solutions only when $b_u + b_v + 2 = 5$ (which yields $X=2, Y=1$), meaning $b_u \neq b_v$, which perfectly preserves the exact same bipartite requirement as the original seed.
</PRESERVED_ANSWER>
