**Solution Explanation**

For the two given matrices  

```
S1 = |0 1 0|
     |0 0 1|
     |1 0 0|

S2 = |0 0 1|
     |1 0 0|
     |0 1 0|
```

* `S1` is the permutation `(1 2 3)`.
* `S2` is its square, the permutation `(1 3 2)`.

Both are permutation matrices, therefore the product of two of them is again a
permutation matrix and its trace equals the number of fixed points of the
corresponding permutation.

```
S1·S1 = S2   (no fixed point) → trace = 0
S2·S2 = S1   (no fixed point) → trace = 0
S1·S2 = I    (all three points fixed) → trace = 3
S2·S1 = I    (all three points fixed) → trace = 3
```

Hence  

```
Tr(Mu·Mv) = 3   ⇔   Mu·Mv = I   ⇔   Mv = Mu⁻¹
```

`S1` and `S2` are inverses of each other, and **none of them is its own inverse**.
Consequences for the required assignment `b[i] ∈ {1,2}` :

* an edge `(u,v)` forces `b[u] ≠ b[v]` (the two bases must be opposite);
* a self‑loop `(u,u)` would need `b[u] = b[u]` **and** `S_{b[u]}·S_{b[u]} = I`,
  which is impossible – therefore any self‑loop makes the whole instance
  unsatisfiable.

Thus the problem is exactly:  

> Is the given (undirected) graph bipartite and contains no self‑loops?
> If yes, output a 2‑coloring with colors `1` and `2`.  
> Among all possible colorings output the lexicographically smallest
> (interpreted as a base‑3 number).

--------------------------------------------------------------------

#### Minimal lexicographic coloring

Components are independent.  
Consider a connected component whose smallest vertex index is `s`.
If we colour `s` with `1`, the whole component’s coloring is uniquely
determined (the opposite colour is forced for all neighbours, etc.).
If we colour `s` with `2` we obtain the same pattern but all `1`/`2` are swapped,
and the first differing position (`s`) is larger.  
Therefore the globally minimal assignment is obtained by

* processing vertices `1 … n` in order,
* when an unvisited vertex `i` is found, start a BFS/DFS,
  **force its colour to be `1`**,
* propagate the forced opposite colour to all neighbours,
* if a conflict appears → the graph is not bipartite → answer `NO`.

This greedy rule automatically yields the minimal base‑3 number.

--------------------------------------------------------------------

#### Algorithm
```
read n, m
build adjacency list
if any edge has u == v: print NO and exit

visited[1…n] = false
colour[1…n]   = 0/1   (0 → will become 1, 1 → will become 2)

for i = 1 … n
    if not visited[i]
        queue ← [i]
        visited[i] = true
        colour[i] = 0          # force 1 for the smallest vertex of the component
        while queue not empty
            v = pop queue
            for each neighbour to in adj[v]
                if not visited[to]
                    visited[to] = true
                    colour[to] = colour[v] ^ 1   # opposite colour
                    push to
                else
                    if colour[to] == colour[v]:
                        print NO and exit

print YES
output for i=1..n : (1 if colour[i]==0 else 2)
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct minimal assignment
iff such an assignment exists.

---

##### Lemma 1  
For any edge `(u,v)` the condition `Tr(M_u M_v)=3` holds **iff**
`b[u] ≠ b[v]`.

**Proof.**  
From the matrix analysis above `Tr(M_u M_v)=3 ⇔ M_u M_v = I ⇔ M_v = M_u⁻¹`.  
`S1⁻¹ = S2` and `S2⁻¹ = S1`, therefore the bases must be different. ∎



##### Lemma 2  
If the input graph contains a self‑loop, no assignment satisfies all edges.

**Proof.**  
A self‑loop requires `Tr(M_u M_u)=3`.  
But `S1·S1 = S2` and `S2·S2 = S1`, both have trace `0`. Contradiction. ∎



##### Lemma 3  
If the algorithm finishes without conflict, the produced assignment satisfies
all edges.

**Proof.**  
During BFS we assign opposite colours to the two ends of every traversed edge.
Thus for every edge `(u,v)` we have `colour[u] ≠ colour[v]`,
hence by Lemma&nbsp;1 the trace condition holds. ∎



##### Lemma 4  
If the algorithm reports a conflict, the graph is not bipartite, therefore
no valid assignment exists.

**Proof.**  
A conflict appears exactly when an edge connects two vertices already coloured
identically. That means the graph contains an odd cycle (standard property of
BFS 2‑colouring). Any assignment would give the same colour to the two ends of
that edge, violating Lemma&nbsp;1. Hence impossible. ∎



##### Lemma 5  
Assume the graph is bipartite and has no self‑loops.
The algorithm outputs the lexicographically smallest valid assignment.

**Proof.**  
Consider a connected component `C` and let `s` be its smallest vertex.
The algorithm forces `b[s]=1`. Any valid assignment must colour `C` with one of
the two possible bipartitions; the other possibility colours `s` with `2`.
Since `1 < 2`, the algorithm’s choice is strictly smaller at the first
position where the two assignments differ, i.e. at `s`.  
Components are processed in increasing order of their smallest vertex,
so decisions for earlier components cannot be altered by later ones.
Therefore the whole sequence is minimal. ∎



##### Theorem  
The algorithm prints  

* `NO` iff no assignment of bases satisfies all interference links,  
* otherwise `YES` followed by the minimal assignment.

**Proof.**  

*If the algorithm prints `NO`.*  
Either a self‑loop existed (Lemma 2) or a conflict was found (Lemma 4);
both imply impossibility.

*If a valid assignment exists.*  
The graph is bipartite and has no self‑loops. BFS never meets a conflict,
so the algorithm finishes and, by Lemma 3, the produced assignment is valid.
By Lemma 5 it is the minimal one. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once → `O(n + m)`.  

Total time `O(n + m)` ≤ `4·10⁵`, well inside the limits.  
Memory `O(n + m)` ≤ `~4·10⁵` integers, also within the limit.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        if u == v:
            print("NO")
            return
        adj[u].append(v)
        adj[v].append(u)

    visited = [False] * (n + 1)
    col = [0] * (n + 1)          # 0 -> output 1, 1 -> output 2

    for i in range(1, n + 1):
        if not visited[i]:
            dq = deque([i])
            visited[i] = True
            col[i] = 0            # force smallest vertex to be 1
            while dq:
                v = dq.popleft()
                cv = col[v]
                for to in adj[v]:
                    if not visited[to]:
                        visited[to] = True
                        col[to] = cv ^ 1
                        dq.append(to)
                    elif col[to] == cv:
                        print("NO")
                        return

    # all good
    print("YES")
    out = ['1' if col[i] == 0 else '2' for i in range(1, n + 1)]
    print(' '.join(out))

if __name__ == "__main__":
    solve()
```
