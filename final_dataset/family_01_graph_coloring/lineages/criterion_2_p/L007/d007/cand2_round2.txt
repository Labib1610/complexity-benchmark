<STATEMENT>
# Problem B — 1D Constrained Point Layout

Time limit: 1 s
Memory limit: 256 MB

You are designing a one-dimensional layout for $n$ structural anchor points, numbered 1 through $n$. Each anchor point $i$ must be assigned a fixed coordinate $c_i$. Due to physical track limitations, the coordinate for each anchor point must be chosen from the set $\{1, 2\}$.

You are provided with $m$ rigid spacing struts. Each strut specifies a pair of anchor points $u$ and $v$ that must be placed at an exact distance of 1 from each other. In other words, the absolute difference between their coordinates must be exactly 1 ($|c_u - c_v| = 1$). Because the only available coordinates are 1 and 2, a strut connecting $u$ and $v$ is valid if and only if $c_u \neq c_v$.

Determine if there exists a valid coordinate assignment for all $n$ anchor points such that all $m$ spacing struts are simultaneously satisfied. If no such layout is possible, report impossibility.

Among all valid layouts, output the lexicographically smallest layout sequence $c_1, c_2, \dots, c_n$. (A sequence $A$ is lexicographically smaller than $B$ if, at the first index $k$ where they differ, $A_k < B_k$).

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of anchor points connected by a spacing strut.

## Output
If no valid layout exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $c_1 \dots c_n$ (each in $\{1,2\}$). 

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
