**Solution Explanation**

For every sensor we have to choose a basis  

* `1` → matrix `X`  
* `2` → matrix `Z`

For an edge `{u,v}` the two matrices must **anti‑commute** :

```
Ou Ov + Ov Ou = 0
```

`X·X = I ,   Z·Z = I` → the same basis does **not** anti‑commute.  
`X·Z + Z·X = 0` → different bases **do** anti‑commute.

Therefore the condition for every edge is simply  

```
bu ≠ bv
```

The whole problem becomes:

*Is the given undirected graph bipartite?*  
If it is, output a 2‑colouring (`1` / `2`) that is lexicographically smallest.



--------------------------------------------------------------------

#### 1.   Lexicographically smallest bipartite colouring  

In a bipartite component there are exactly two colourings – they are
each other’s complement.
The global lexicographic order is decided at the first vertex where the
two colourings differ.
That vertex is the **smallest numbered vertex of its connected component**.
If we colour this vertex with `1`, the whole assignment is already the
smallest possible, because any other valid assignment would have `2` at
that position and would be larger lexicographically.

Consequences  

* Process vertices in increasing order `1 … n`.  
* When we meet an unvisited vertex `v` it is the smallest vertex of its
  component – start a BFS/DFS from `v` and give it colour `1`.  
* All other vertices of the component receive the forced opposite colour.
* No later decision can change the colour of `v`, therefore the obtained
  colouring is the lexicographically smallest one.

--------------------------------------------------------------------

#### 2.   Algorithm
```
read n, m
build adjacency list

visited[1…n] = false
col[1…n]    = 0          # 0 → basis 1, 1 → basis 2

for v = 1 … n
    if not visited[v]
        start BFS from v
        visited[v] = true
        col[v] = 0                     # basis 1 for the smallest vertex
        queue = [v]
        while queue not empty
            x = pop queue
            for each neighbour y of x
                if not visited[y]
                    visited[y] = true
                    col[y] = col[x] xor 1
                    push y into queue
                else
                    if col[y] == col[x]          # same colour on an edge
                        print "NO" and exit

print "YES"
print col[1]+1 … col[n]+1   (convert 0/1 → 1/2)
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `"NO"` iff no valid assignment exists,
otherwise it prints `"YES"` and the lexicographically smallest valid
assignment.

---

##### Lemma 1  
During BFS, if an edge `{a,b}` is examined and both ends are already
visited, then `col[a] = col[b]` **iff** the graph contains an odd cycle.

**Proof.**  
BFS always assigns opposite colours to the two ends of a traversed edge,
so for every tree edge the invariant `col[a] ≠ col[b]` holds.
If later a non‑tree edge `{a,b}` is examined, both ends already have a
colour.  
*If* they are equal, the unique path in the BFS tree between `a` and `b`
has even length (alternating colours), adding the edge creates an odd
cycle.  
*If* they are different, the path length is odd, the added edge makes an
even cycle. ∎



##### Lemma 2  
If the algorithm finishes without printing `"NO"`, the produced colours
satisfy `bu ≠ bv` for every edge `{u,v}`.

**Proof.**  
All edges are examined exactly once.
* Tree edges* are coloured opposite by construction.
* Non‑tree edges* are examined after both ends are visited.
The algorithm would have printed `"NO"` if the colours were equal
(Lemma&nbsp;1). Since it did not, the colours are different. ∎



##### Lemma 3  
If the algorithm prints `"NO"` then no valid assignment exists.

**Proof.**  
`"NO"` is printed only when an edge `{a,b}` with `col[a] = col[b]` is
found while both vertices are already visited.
By Lemma&nbsp;1 this means the graph contains an odd cycle.
A graph with an odd cycle is not bipartite, therefore it is impossible
to colour its vertices with two colours such that adjacent vertices differ.
Consequently no assignment of bases satisfies the anti‑commutation
condition. ∎



##### Lemma 4  
Assume the graph is bipartite.  
For every connected component the algorithm assigns colour `1` to its
smallest numbered vertex.

**Proof.**  
The outer loop visits vertices in increasing order.
When the first vertex `s` of a component is encountered, it is the
component’s smallest vertex and is still unvisited.
The algorithm starts BFS from `s` and sets `col[s]=0`, i.e. basis `1`. ∎



##### Lemma 5  
Assume the graph is bipartite.  
The colouring output by the algorithm is the lexicographically smallest
among all valid colourings.

**Proof.**  
Consider the first index `i` where two valid colourings differ.
Vertex `i` belongs to some component `C`.  
By Lemma&nbsp;4 the algorithm gives vertex `i` colour `1`.  
Any other valid colouring must give vertex `i` colour `2` (otherwise the
two colourings would be identical up to `i`).  
Since `1 < 2`, the algorithm’s colouring is lexicographically smaller
than any other valid colouring. ∎



##### Theorem  
The algorithm

* prints `"NO"` **iff** no assignment of bases satisfying all links
  exists;
* otherwise prints `"YES"` followed by the lexicographically smallest
  valid assignment.

**Proof.**  

*If* the algorithm prints `"NO"` – by Lemma&nbsp;3 no assignment exists.  

*If* the algorithm finishes without `"NO"` – by Lemma&nbsp;2 the
produced colours satisfy the required condition, therefore a valid
assignment exists.  
By Lemma&nbsp;5 this assignment is the lexicographically smallest one. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency list* : `O(n + m)` memory and time.  
*BFS over all components* : each vertex and edge is processed once →  
`O(n + m)` time, `O(n)` additional memory for queues and arrays.

Overall  

```
Time   : O(n + m)   ≤ 4·10⁵ operations
Memory : O(n + m)   ≤ 4·10⁵ integers
```

Both fit easily into the limits.

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    visited = [False] * (n + 1)
    col = [0] * (n + 1)          # 0 -> basis 1, 1 -> basis 2

    for start in range(1, n + 1):
        if visited[start]:
            continue
        # start BFS from the smallest vertex of this component
        dq = deque([start])
        visited[start] = True
        col[start] = 0            # basis 1 for the smallest vertex
        while dq:
            u = dq.popleft()
            cu = col[u]
            for v in adj[u]:
                if not visited[v]:
                    visited[v] = True
                    col[v] = cu ^ 1
                    dq.append(v)
                elif col[v] == cu:
                    # same colour on an edge -> not bipartite
                    sys.stdout.write("NO")
                    return

    # all edges satisfied, output lexicographically smallest colouring
    out = ["YES\n"]
    out.append(' '.join(str(col[i] + 1) for i in range(1, n + 1)))
    sys.stdout.write(''.join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
