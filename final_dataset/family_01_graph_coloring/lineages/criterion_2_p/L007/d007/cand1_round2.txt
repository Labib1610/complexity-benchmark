<STATEMENT>
# Problem B — Network Configurations

Time limit: 1 s
Memory limit: 256 MB

A communication grid consists of $n$ radio towers. 
You need to assign each tower $i$ an operational state $f_i \in \{1, 2\}$. 
- State 1 equips the tower with the spatial reversal operator, denoted as $R$.
- State 2 equips the tower with the polarity inversion operator, denoted as $I$.

These operators act on the signals passing through the towers. They commute with each other ($R \circ I = I \circ R$) and each is its own inverse ($R \circ R = \text{Id}$ and $I \circ I = \text{Id}$, where $\text{Id}$ is the identity operator).

There are $m$ critical links between specific pairs of towers. 
To establish a successful bidirectional handshake across a critical link between tower $u$ and tower $v$, the hardware requires that the combined transformation applied by the two towers is exactly the composition of one reversal and one inversion. Specifically, applying tower $u$'s operator followed by tower $v$'s operator must yield the exact combined operator $R \circ I$.

Determine if a valid assignment of states exists for all towers such that all critical links successfully establish their handshakes. If no such assignment is possible, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of towers connected by a critical link.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $f_1 \dots f_n$ (each in $\{1,2\}$). 
If multiple valid assignments exist, you must resolve ties by choosing the assignment that assigns the smallest possible state index to tower 1. If ties remain, among those, choose the one that assigns the smallest possible state index to tower 2, and continue this sequential preference for smaller state indices up to tower $n$ (this is equivalent to the lexicographically smallest valid assignment).

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem has been reframed using operators from the Klein four-group. The binary choices are mapped to two involutions, $R$ and $I$. The edge constraint requires their composition to be $R \circ I$. Since applying the same operator twice yields the identity, the only way to achieve $R \circ I$ is by assigning distinct operators to the endpoints. This forces the model to deduce the $f_u \neq f_v$ inequality constraint through algebraic reasoning rather than pattern-matching a standard graph coloring scenario. The numeric bounds and I/O format have been perfectly restored to exactly match the seed.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic condition $f_u \circ f_v = R \circ I$ evaluates to true if and only if one tower is assigned state 1 ($R$) and the other is assigned state 2 ($I$), which is exactly the original condition $f_u \neq f_v$.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying mechanism is still strictly assigning one of two states to each node such that no two connected nodes share the same state, keeping it exactly isomorphic to bipartite testing / 2-coloring (class P).
</PRESERVED_CLASS>
