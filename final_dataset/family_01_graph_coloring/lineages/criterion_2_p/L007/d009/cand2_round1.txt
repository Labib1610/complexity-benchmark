# Problem B — Quantum Sensor Calibration

Time limit: 1 s
Memory limit: 256 MB

You are calibrating a network of quantum sensors in a facility. The facility is built as a rectangular grid of $400$ rows and $500$ columns of sensor slots. The total number of deployed sensors $n$ can be up to the total number of slots, and there is always at least one sensor deployed. The diagnostic logging system allocates a fixed memory block capable of storing exactly $200,000$ interference link records. The number of active interference links $m$ can be anything from zero up to this maximum capacity.

Each sensor $i$ must be configured with a measurement basis $b_i \in \{1, 2\}$. 
Choosing basis 1 configures the sensor with the response profile $P_1(x) = x^2 - 1$.
Choosing basis 2 configures the sensor with the response profile $P_2(x) = -x^2 + x + 1$.

When a joint measurement is performed across an interference link between sensor $u$ and sensor $v$, their profiles are superimposed to form $S_{u,v}(x) = P_u(x) + P_v(x)$.
For the measurement to be stable, the equation $S_{u,v}(x) = 0$ must have exactly one real solution.

Determine if a valid assignment of measurement bases exists for all sensors such that the stability condition is satisfied for all interference links. If no such assignment is possible, report impossibility.

## Input
The first line contains two integers $n$ and $m$, representing the actual number of deployed sensors and active interference links, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of sensors connected by an interference link.

## Output
If no valid configuration exists, print a single line `NO`.
Otherwise print `YES`, then a second line with $n$ integers $b_1 \dots b_n$ (each in $\{1,2\}$). 
If multiple valid configurations are possible, output the one that is lexicographically smallest. This means you should prioritize assigning basis 1 to sensor 1. If there's still a tie, prioritize basis 1 for sensor 2, and so forth.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
