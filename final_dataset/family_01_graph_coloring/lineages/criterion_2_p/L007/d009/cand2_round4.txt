<METHOD_DESCRIPTION>Replaces the matrix algebra condition with a continuous function integral that evaluates to negative only when the two functions are different. This masks the bipartite matching requirement behind calculus operations.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Continuous Signal Calibration

Time limit: 1 s
Memory limit: 256 MB

You are calibrating a network of $n$ quantum sensors. Each sensor $i$ must be configured with a measurement basis $b_i \in \{1, 2\}$. 
Depending on the chosen basis, the sensor emits a continuous signal profile $S_i(x)$ defined over the domain $x \in [-1, 1]$:

Choosing basis 1 configures the sensor with the profile: 
$S_i(x) = x + 1$

Choosing basis 2 configures the sensor with the profile: 
$S_i(x) = x - 1$

There are $m$ interference links between specific pairs of sensors. 
For a successful joint measurement across an interference link between sensor $u$ and sensor $v$, their configured profiles, denoted $S_u(x)$ and $S_v(x)$, must exhibit negative cross-correlation. Specifically, the definite integral of their product over the domain $[-1, 1]$ must be strictly negative:

$$ \int_{-1}^{1} S_u(x) S_v(x) \, dx < 0 $$

Determine if a valid assignment of measurement bases exists for all sensors such that this cross-correlation condition is satisfied for all interference links. If no such assignment is possible, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of sensors connected by an interference link.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $b_1 \dots b_n$ (each in $\{1,2\}$). 
If multiple valid assignments exist, you must output the lexicographically smallest valid assignment (i.e., resolve ties by preferring basis 1 over basis 2 for sensor 1, then for sensor 2, and so on).

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The matrix condition was removed and replaced with an integral of a product of signal functions. Evaluating the integral analytically shows it is negative if and only if the two functions are different. This requires the model to correctly integrate the expressions before it can deduce the graph bipartite structure.
</RATIONALE>
<PRESERVED_ANSWER>
The definite integral of (x+1)^2 or (x-1)^2 from -1 to 1 is positive (8/3), while for (x+1)(x-1) it is negative (-4/3); this forces connected sensors to have different bases, exactly matching the original matrix invertibility condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying constraint is identical (adjacent pairs must take opposite values), so it remains equivalent to 2-coloring (checking bipartiteness), which is solvable in O(n+m) time.
</PRESERVED_CLASS>
