<STATEMENT>
# Problem B — Quantum Sensor Calibration

Time limit: 1 s
Memory limit: 256 MB

You are calibrating a network of $n$ quantum sensors. Each sensor $i$ (for $1 \le i \le n$) must be configured with a measurement basis $b_i \in \{1, 2\}$. 

There are $m$ interference links between specific pairs of sensors. We define the network's structural matrix $L$ (an $n \times n$ matrix) as follows:
- The diagonal entry $L_{i,i}$ is exactly the number of interference links connected to sensor $i$.
- The off-diagonal entry $L_{i,j} = -1$ if there is an interference link between sensor $i$ and sensor $j$.
- All other entries are $0$.

Let $B$ be an $n \times 1$ column vector where the $i$-th element is the assigned basis $b_i$. For the network to be perfectly calibrated and achieve stable joint measurements, the configuration must satisfy the following global energy equation:
$$B^T L B = m$$

Determine if a valid assignment of measurement bases exists for all sensors such that this global energy equation is satisfied. If no such assignment is possible, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$) — a pair of sensors connected by an interference link.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise print `YES`, then a second line with $n$ integers $b_1 \dots b_n$ (each in $\{1,2\}$). 
If multiple valid assignments exist, you must output the lexicographically smallest valid assignment (i.e., resolve ties by preferring basis 1 over basis 2 for sensor 1, then for sensor 2, and so on).

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<METHOD_NAME>Laplacian Quadratic Form Equivalence</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the edge-local constraint with a single global matrix equation $B^T L B = m$ using the graph's Laplacian. This defeats models that rely on simulating the local truth table for all possible value pairs, as they must now analytically expand the quadratic form to discover the bipartite requirement.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<RATIONALE>
The previous attempts failed because models could easily extract the local condition and evaluate its truth table for the pairs (1,1), (2,2), and (1,2), immediately revealing the bipartite reduction. I replaced the local condition with a global matrix equation involving the graph's Laplacian matrix. This forces models to analytically expand the quadratic form to deduce that the maximum possible value is $m$, which is achieved if and only if $b_u \neq b_v$ for every edge.
</RATIONALE>
<PRESERVED_ANSWER>
The quadratic form $B^T L B$ mathematically expands to the sum over all edges of $(b_u - b_v)^2$; since $b_i \in \{1, 2\}$, this sum can only reach $m$ if every single edge contributes $1$, which requires $b_u \neq b_v$ for all edges exactly as in the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying requirement is still strictly $b_u \neq b_v$ across all edges, which is standard bipartiteness testing (2-coloring) solvable in $O(n+m)$ time.
</PRESERVED_CLASS>
<RISK>
Some readers might be unfamiliar with the properties of the Laplacian matrix, but its exact construction and the matrix equation are explicitly defined, making the problem fully self-contained and unambiguous to anyone capable of basic matrix multiplication.
</RISK>
