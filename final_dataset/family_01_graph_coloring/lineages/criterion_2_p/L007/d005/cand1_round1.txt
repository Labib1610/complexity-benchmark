<STATEMENT>
# Problem B — Network Configurations

Time limit: 1 s
Memory limit: 256 MB

A communication grid consists of $n$ radio towers. You need to assign each tower $i$ a protocol flag $f_i$, which must be chosen from the set $\{1, 2\}$. 

There are $m$ critical links between specific pairs of towers. 

During operation, the network runs in synchronized discrete time steps $t \ge 1$ (where $t$ is an integer). Each tower generates a diagnostic sequence $D_i(t)$. At time step $t$, a tower's diagnostic value is calculated based on its assigned protocol flag:
$D_i(t) = (t \cdot f_i) \bmod 998244353$

To prevent interference, the two towers connected by any critical link must remain conflict-free. A critical link between tower $u$ and tower $v$ is conflict-free if and only if:
- It is never the case that both towers simultaneously produce the resonance value $998244352$. That is, there is no integer time step $t \ge 1$ where both $D_u(t) = 998244352$ and $D_v(t) = 998244352$.

Determine if a valid assignment of protocol flags exists for all towers such that all critical links are conflict-free. If no such assignment is possible, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of towers connected by a critical link.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $f_1 \dots f_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

The conflict condition is hitting a specific large resonance value (998244352) simultaneously. This forces the model to algebraically solve $t \cdot f_i \equiv 998244352$ and deduce that the collision times for flags 1 and 2 are disjoint, mathematically reducing the problem to $f_u \neq f_v$ (bipartiteness) without triggering any graph-coloring or state-machine pattern matching.
</RATIONALE>
