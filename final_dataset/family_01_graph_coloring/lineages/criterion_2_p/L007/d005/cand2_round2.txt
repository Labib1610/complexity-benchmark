<METHOD_NAME>
Temporal Sequence Arithmetic
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces explicit state machine transition rules and explicit endpoint state conflicts with an arithmetic evaluation of generated sequences. Endpoints are conflict-free if the sum of their sequence values at every step avoids a specific integer, which mathematically requires the assigned flags to be distinct, forcing bipartiteness while requiring algebraic deduction.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<STATEMENT>
# Problem B — Network Configurations

Time limit: 1 s
Memory limit: 256 MB

A communication grid consists of $n$ radio towers. You need to assign each tower $i$ a protocol flag $f_i$, which must be chosen from the set $\{1, 2\}$. 

There are $m$ critical links between specific pairs of towers. 

During operation, the network runs in synchronized discrete time steps $t \ge 1$. At each time step $t$, every tower $i$ transmits a pulse with an energy level $E_i(t) \in \{0, 1, 2\}$ given by the formula:
$E_i(t) = (t \cdot f_i) \bmod 3$

To prevent interference, the two towers connected by any critical link must not create a resonant wave. A critical link between tower $u$ and tower $v$ is conflict-free if and only if, at every time step $t \ge 1$, the standard integer sum of their pulse energies is never exactly 2. Formally, for all $t \ge 1$:
$E_u(t) + E_v(t) \neq 2$

Determine if a valid assignment of protocol flags exists for all towers such that all critical links are conflict-free. If no such assignment is possible, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — a pair of towers connected by a critical link.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise print `YES`, then a second line with $n$ integers $f_1 \dots f_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The seed problem explicitly listed the state transitions (Sync -> Ping -> Ack) and explicitly forbade simultaneous states (Ping-Ping, Ack-Ack). Models easily mapped this to the XOR constraint `f_u != f_v` and recognized bipartiteness. I replaced the explicit state machine and collision rules with an arithmetic sequence generated by each flag: $E_i(t) = (t \cdot f_i) \bmod 3$. The conflict condition is now that the integer sum of two endpoints' sequences must never equal 2. To solve this, models must mathematically evaluate the sequence sums for all combinations of $\{1, 2\}$ to deduce that only distinct flags avoid a sum of 2, thus discovering the bipartiteness constraint through algebraic reasoning rather than pattern matching on XOR/collision terminology.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $E_u(t) + E_v(t) \neq 2$ is violated at $t=1$ if $f_u = f_v = 1$, and at $t=2$ if $f_u = f_v = 2$, but is never violated if $f_u \neq f_v$ (where sums are always 0 or 3), making it logically identical to the seed's requirement that connected nodes have distinct flags.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding a lexicographically smallest 2-coloring of an undirected graph (or determining if it is bipartite), which is solvable in $O(n + m)$ time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the modulo operation applying to the sum itself rather than the individual energies, though the phrasing "standard integer sum" and the explicit formula for $E_i(t)$ strongly guard against this.
</RISK>
