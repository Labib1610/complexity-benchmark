<STATEMENT>
# Problem B — Network Configurations

Time limit: 1 s
Memory limit: 256 MB

A communication grid consists of $n$ radio towers. You need to assign each tower $i$ a configuration value $f_i$, which must be chosen from the set $\{1, 2\}$. 

There are $m$ critical links between specific pairs of towers. To prevent data corruption, the two towers connected by any critical link must satisfy an unconditional stability predicate.

When data is transmitted across a critical link between tower $u$ and tower $v$, it is packaged as a sequence of three arbitrary elements $(x_1, x_2, x_3)$. During transmission, the sequence is transformed by both towers. A tower with configuration value $k$ applies a cyclic right-shift of $k$ steps to the sequence.
- A 1-step cyclic right-shift changes $(x_1, x_2, x_3)$ to $(x_3, x_1, x_2)$.
- A 2-step cyclic right-shift changes $(x_1, x_2, x_3)$ to $(x_2, x_3, x_1)$.

A critical link between tower $u$ and tower $v$ is unconditionally stable if and only if, for *every* possible sequence $(x_1, x_2, x_3)$, the combined effect of tower $u$'s shift and tower $v$'s shift restores the sequence to its exact original order $(x_1, x_2, x_3)$.

Determine if a valid assignment exists for all towers such that all critical links are unconditionally stable. If no such assignment is possible, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of towers connected by a critical link.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $f_1 \dots f_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Removed the explicit high/low complementary signal wording that directly translated to a binary inequality. Instead, the problem requires the composition of two cyclic shifts on a length-3 sequence to be the identity transformation for all possible sequences. Since the shifts are chosen from {1, 2}, this forces the two endpoints of an edge to have shifts summing to exactly 3, which indirectly enforces the exact same opposite-configuration constraint.
</RATIONALE>
<PRESERVED_ANSWER>
The total shift on a length 3 sequence is (f_u + f_v). For this to restore every arbitrary sequence, (f_u + f_v) must be a multiple of 3, which given f_i in {1, 2} means f_u + f_v = 3 (i.e. f_u != f_v), making the valid assignments perfectly identical to the seed's 2-coloring requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying constraint remains f_u != f_v for every edge, which is exactly graph 2-coloring (bipartiteness testing), keeping the problem in P.
</PRESERVED_CLASS>
