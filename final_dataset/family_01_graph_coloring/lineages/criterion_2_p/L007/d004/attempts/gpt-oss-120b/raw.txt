**Solution Explanation**

For a tower `i`

* flag `1` : `Sync → Ping → Ack → Sync …`
* flag `2` : `Sync → Ack → Ping → Sync …`

Both cycles have length `3`.  
Let  

```
state_f(t) =   t            (mod 3)   if f = 1
               -t ≡ 2·t    (mod 3)   if f = 2
```

(`0 = Sync , 1 = Ping , 2 = Ack`)

For an edge `{u,v}` we need for **every** `t ≥ 1`

```
not (state_f(u)(t) = state_f(v)(t) = 1)   and
not (state_f(u)(t) = state_f(v)(t) = 2)
```

The two towers may be equal only when the common state is `0` (Sync).

--------------------------------------------------------------------

#### 1.   When are two towers allowed to be connected ?

```
state_f(u)(t) = state_f(v)(t)
⇔ (a_u – a_v)·t ≡ 0 (mod 3)          a_f = 1 (flag 1) , a_f = 2 (flag 2)
```

*If the flags are equal* (`a_u = a_v`) the left side is always `0`,
so the towers are equal for **all** `t`.  
In particular they are both `Ping` at `t = 1` – forbidden.

*If the flags are different* (`a_u – a_v ≡ ±1 (mod 3)`) the equality holds
iff `t ≡ 0 (mod 3)`.  
Exactly those moments the state is `0` (Sync), which is allowed.

```
=>  an edge is conflict‑free  ⇔  its two endpoints have different flags
```

So the whole problem is exactly **2‑colouring** the graph
(colour `1` ↔ flag `1`, colour `2` ↔ flag `2`).

--------------------------------------------------------------------

#### 2.   Lexicographically smallest assignment

If the graph is bipartite, each connected component has two possible
colourings (they are each other's colour swap).
The lexicographically smallest global list is obtained by the following
greedy rule:

*process vertices `1 … n`*  
When we meet the first vertex of a still uncoloured component,
colour it with `1`.  
All other vertices of this component are forced by the bipartite
constraints.

Thus we simply run a BFS/DFS, always start a new component with colour
`0` (meaning flag `1`). This gives the smallest possible flag for the
smallest index of the component, and consequently the smallest overall
sequence.

--------------------------------------------------------------------

#### 3.   Algorithm
```
read n, m
build adjacency list
colour[1…n] = -1          # -1 = unvisited, 0 = flag 1, 1 = flag 2
for v = 1 … n
    if colour[v] == -1
        colour[v] = 0
        queue ← v
        while queue not empty
            x ← pop
            for each neighbour y of x
                if colour[y] == -1
                    colour[y] = colour[x] xor 1
                    push y
                else if colour[y] == colour[x]
                    print "NO" and exit
# bipartite
print "YES"
for i = 1 … n
    output (colour[i] + 1)   # 0→1 , 1→2
```

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints **YES** and a lexicographically
smallest valid assignment iff such an assignment exists.

---

##### Lemma 1  
For any edge `{u,v}` the conflict‑free condition holds
iff `f_u ≠ f_v`.

*Proof.*  
From the analysis in section&nbsp;1 we derived that equality of states
occurs for all `t` when the flags are equal, producing a forbidden
`Ping`/`Ack` coincidence, while for different flags equality happens
only at multiples of `3`, i.e. when the state is `Sync`. ∎



##### Lemma 2  
If the algorithm finishes without printing `NO`, the produced flags
satisfy Lemma&nbsp;1 for every edge.

*Proof.*  
During BFS we assign opposite colours (`0`/`1`) to the two ends of every
traversed edge. Therefore for each edge the final flags are different,
hence by Lemma&nbsp;1 the edge is conflict‑free. ∎



##### Lemma 3  
If the algorithm prints `NO`, the input graph is not bipartite,
hence no valid assignment exists.

*Proof.*  
`NO` is printed exactly when an edge connects two vertices already
coloured identically. That means the graph contains an odd cycle,
i.e. it is not 2‑colourable. By Lemma&nbsp;1 any valid assignment would be
a proper 2‑colouring, contradiction. ∎



##### Lemma 4  
Assume the graph is bipartite. The flags output by the algorithm are
lexicographically smallest among all valid assignments.

*Proof.*  
Consider the vertices in increasing order.
When the algorithm meets the first vertex `s` of a component,
it forces `f_s = 1` (colour `0`).  
Any valid assignment must give opposite flags to neighbours of `s`,
so the whole component is uniquely determined up to swapping the two
flags. The only alternative would give `f_s = 2`, which is larger.
Thus any assignment that is lexicographically ≤ the algorithm’s one
must coincide on `s`. By induction over the ordered vertices the whole
sequence must be identical. Hence the algorithm’s sequence is the
lexicographically smallest possible. ∎



##### Lemma 5  
If the graph is bipartite, the algorithm never prints `NO`.

*Proof.*  
A bipartite graph admits a proper 2‑colouring. The BFS colours exactly
such a colouring, never encountering an edge whose ends already have
the same colour. ∎



##### Theorem  
The algorithm outputs  

* `NO` **iff** no assignment of flags satisfies the problem constraints;  

* otherwise `YES` and the lexicographically smallest assignment.

*Proof.*  

*If part:*  
If the algorithm prints `NO`, by Lemma&nbsp;3 the graph is not bipartite,
hence by Lemma&nbsp;1 no assignment can satisfy all edges.

*Only‑if part:*  
If a satisfying assignment exists, by Lemma&nbsp;1 the graph must be
bipartite. By Lemma&nbsp;5 the algorithm does not print `NO`.  
It outputs a flag assignment; Lemma&nbsp;2 shows it satisfies all edges,
and Lemma&nbsp;4 shows it is the lexicographically smallest one.

Thus the theorem holds. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Building adjacency list* : `O(n + m)`  
*BFS over all components* : each vertex and edge processed once → `O(n + m)`  

Memory: adjacency list `O(n + m)`, colour array `O(n)`.

Both limits satisfy the given constraints (`n, m ≤ 2·10⁵`).

#### 6.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 = unvisited, 0 = flag 1, 1 = flag 2
    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # start new component, give smallest vertex flag 1 (colour 0)
        colour[start] = 0
        q = deque([start])
        while q:
            v = q.popleft()
            cv = colour[v]
            for to in adj[v]:
                if colour[to] == -1:
                    colour[to] = cv ^ 1
                    q.append(to)
                elif colour[to] == cv:
                    sys.stdout.write("NO")
                    return

    # bipartite, construct answer
    out = ['YES\n']
    flags = [str(colour[i] + 1) for i in range(1, n + 1)]
    out.append(' '.join(flags))
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```

and conforms to the required input‑output format.
