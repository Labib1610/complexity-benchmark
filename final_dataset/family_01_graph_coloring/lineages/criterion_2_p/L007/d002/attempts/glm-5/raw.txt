Looking at this problem, I need to analyze the stability condition $f_u^{f_v} + f_v^{f_u} = 3$ where $f_u, f_v \in \{1, 2\}$.

Let me check all combinations:
- $f_u=1, f_v=1$: $1^1 + 1^1 = 2 \neq 3$ ✗
- $f_u=1, f_v=2$: $1^2 + 2^1 = 1 + 2 = 3$ ✓
- $f_u=2, f_v=1$: $2^1 + 1^2 = 2 + 1 = 3$ ✓
- $f_u=2, f_v=2$: $2^2 + 2^2 = 4 + 4 = 8 \neq 3$ ✗

So the condition requires $f_u \neq f_v$ for every edge. This is a bipartite graph problem.

For the lexicographically smallest assignment, I need to assign values greedily. The key insight is:
- For each connected component, I can try both orientations (start with 1 or start with 2)
- To get lexicographically smallest, I should process components in order of their minimum vertex, and for each component, try to assign the minimum vertex value 1 if possible.

I'll use a greedy approach: process vertices 1 to n, and when I find an unassigned vertex, try assigning it value 1, then BFS/DFS to assign the rest. If this creates a conflict, try value 2. If both fail, output NO.

```python
import sys
from collections import deque

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * (n+1)
    
    for start in range(1, n+1):
        if color[start] != 0:
            continue
        
        # Try assigning start = 1
        color[start] = 1
        queue = deque([start])
        component = [start]
        ok = True
        
        while queue and ok:
            u = queue.popleft()
            for v in adj[u]:
                if color[v] == 0:
                    color[v] = 3 - color[u]
                    queue.append(v)
                    component.append(v)
                elif color[v] == color[u]:
                    ok = False
                    break
        
        if ok:
            continue
        
        # Try assigning start = 2
        for v in component:
            color[v] = 0
        color[start] = 2
        queue = deque([start])
        ok = True
        
        while queue and ok:
            u = queue.popleft()
            for v in adj[u]:
                if color[v] == 0:
                    color[v] = 3 - color[u]
                    queue.append(v)
                elif color[v] == color[u]:
                    ok = False
                    break
        
        if not ok:
            print("NO")
            return
    
    print("YES")
    print(' '.join(str(color[i]) for i in range(1, n+1)))

solve()
```
