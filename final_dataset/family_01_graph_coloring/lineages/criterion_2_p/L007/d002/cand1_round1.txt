# Problem B — Network Configurations

Time limit: 1 s
Memory limit: 256 MB

A communication grid consists of $n$ radio towers. You need to assign each tower $i$ a configuration value $f_i$, which must be chosen from the set $\{1, 2\}$. 

There are $m$ critical links between specific pairs of towers. To prevent signal degradation, the configuration values $f_u$ and $f_v$ of the two towers connected by any critical link must satisfy the stability condition:
$$f_u^{f_v} + f_v^{f_u} = 3$$

Determine if a valid assignment exists for all towers. If no such assignment is possible, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of towers connected by a critical link.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $f_1 \dots f_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit "sum to exactly 3" constraint was replaced with the symmetric non-linear equation $f_u^{f_v} + f_v^{f_u} = 3$. Because the domain is restricted to $\{1, 2\}$, this equation is satisfied if and only if $f_u \neq f_v$. This forces the model to actually evaluate the condition over the domain to deduce the bipartiteness constraint, rather than relying on surface pattern matching of the word "sum" to immediately trigger graph coloring heuristics.
</RATIONALE>
<PRESERVED_ANSWER>
The equation $f_u^{f_v} + f_v^{f_u} = 3$ evaluates to true for $\{1, 2\}$ and false for $\{1, 1\}$ and $\{2, 2\}$, exactly mirroring the original requirement that the values sum to 3, leaving all valid assignments and the lexicographical tie-breaking identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying mathematical structure remains finding a valid 2-coloring of an undirected graph (bipartiteness testing), which is solvable in O(n + m) time using BFS or DFS.
</PRESERVED_CLASS>
