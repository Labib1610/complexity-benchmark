<STATEMENT>
# Problem B — Phase Synchronization

Time limit: 1 s   Memory limit: 256 MB

A cloud provider must schedule phase configurations for $n$ database instances. The configuration process requires assigning each instance an integer phase state, which must be either 1 or 2.

Certain pairs of instances are linked by a synchronous replication channel. To maintain data integrity across a channel, the product of the phase states of the two linked instances must evaluate to exactly 2.

You must assign a phase state to each instance to satisfy all channel requirements, or determine that no such configuration exists. If multiple valid configurations exist, the automated deployment system requires the configuration whose sequence of phase states $s_1 \dots s_n$ (where $s_i$ is the state assigned to instance $i$) is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$, representing the number of database instances and the number of replication channels. The data center has a minimum of one instance and a maximum capacity of two hundred thousand instances. The network switch supports up to two hundred thousand channels (and there may be none). 

Each of the next $m$ lines contains two integers $u$ and $v$, indicating that instances $u$ and $v$ are linked by a replication channel.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Changed the pairwise incompatibility ("cannot undergo maintenance during the same window") to a multiplicative constraint ("product of phase states must be exactly 2") over the domain {1, 2}. This forces models to algebraically deduce the mutual exclusion rather than triggering on standard graph-coloring keywords. Expressed the numeric bounds as physical capacities in the text rather than mathematical inequalities, fulfilling the S07 strategy.
</RATIONALE>
<PRESERVED_ANSWER>
The domain of states is {1, 2}, and the only way two such states can multiply to 2 is if one is 1 and the other is 2, which is mathematically identical to the original requirement that they take different values.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding a valid 2-coloring of an undirected graph (and choosing the lexicographically first valid assignment), which is solvable in linear time using Breadth-First Search.
</PRESERVED_CLASS>
