<STATEMENT>
# Problem B — System Configuration

Time limit: 1 s   Memory limit: 256 MB

A cloud provider must configure the operation mode for $n$ database instances. The configuration requires assigning each instance $i$ an operation mode $s_i$, which must be chosen from the set $\{1, 2\}$.

The system includes $m$ shared backup storage arrays, each connecting two specific database instances. 
Let $s \in \{1, 2\}^n$ be the column vector of the assigned operation modes.
Let $A$ be the $n \times n$ adjacency matrix representing the backup arrays, where $A_{u,v} = 1$ if there is a backup array connecting instances $u$ and $v$, and $0$ otherwise.
Let $D$ be the $n \times n$ diagonal degree matrix, where $D_{i,i}$ is the number of backup arrays connected to instance $i$.
Let $\mathbf{1}$ be the all-ones column vector of length $n$.

To prevent data collision, the configuration must satisfy the global stability equation:
$$s^T A s + s^T D s - 6 \cdot \mathbf{1}^T D s = -9m$$

You must assign a mode to each instance to satisfy this global stability equation, or determine that no such configuration exists. 

If multiple valid configurations exist, the automated deployment system requires the configuration that minimizes the total network energy score $E$, defined as:
$$E = \sum_{i=1}^n s_i \cdot 2^{n-i}$$

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of database instances and the number of shared backup arrays.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that instances $u$ and $v$ share a backup array.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the valid configuration with the minimum energy score.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<METHOD_NAME>Signless Laplacian Completing the Square</METHOD_NAME>
<METHOD_DESCRIPTION>The edge-local difference condition is mathematically transformed into a single global quadratic equation using the adjacency and degree matrices. By expanding and completing the square, the global equation $s^T A s + s^T D s - 6 \mathbf{1}^T D s = -9m$ is strictly equivalent to $\sum_{(u,v)} (s_u + s_v - 3)^2 = 0$. This forces the model to perform non-trivial algebraic manipulation to recover the 2-coloring structure, defeating pattern matchers that look for local edge constraints.</METHOD_DESCRIPTION>
