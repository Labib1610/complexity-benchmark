# Problem B — System Configuration

Time limit: 1 s   Memory limit: 256 MB

A cloud provider must configure the operation mode for $n$ database instances. The configuration requires assigning each instance $i$ an operation mode $s_i$, which must be chosen from the set $\{1, 2\}$.

The system includes $m$ shared backup storage arrays, each connecting two specific database instances. A backup array continuously monitors the joint state of its two connected instances. To prevent data collision, the configuration must guarantee that for every backup array connecting instances $u$ and $v$, the $2 \times 2$ state transition matrix 
$$M_{u,v} = \begin{pmatrix} s_u & 2 \\ 1 & s_v \end{pmatrix}$$
has the property that both of its eigenvalues are rational numbers. 

You must assign a mode to each instance to satisfy this eigenvalue constraint across all backup arrays, or determine that no such configuration exists. 

If multiple valid configurations exist, the automated deployment system requires the configuration that minimizes the total network interference score $I$, defined as:
$$I = \sum_{i=1}^n \frac{s_i}{3^i}$$

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of database instances and the number of shared backup arrays.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that instances $u$ and $v$ share a backup array.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the valid configuration with the minimum interference score.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit determinant condition was replaced with a requirement that a specific matrix has rational eigenvalues. For $s_u, s_v \in \{1, 2\}$, the characteristic polynomial's discriminant is $(s_u - s_v)^2 + 8$, which is a perfect square (yielding rational roots) if and only if $s_u \neq s_v$. The tie-breaker was converted from an integer polynomial base-2 to a convergent series base-3, which mathematically preserves the exact same lexicographical order preference while breaking hardcoded binary-string heuristics.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the matrix has rational eigenvalues evaluates to true if and only if $s_u \neq s_v$, perfectly preserving the bipartite constraint, and the base-3 series tie-breaker is strictly monotonic with respect to lexicographical order exactly like the original base-2 formula.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding a valid 2-coloring of a graph and then orienting each connected component to minimize the lexicographical assignment, which operates in $O(n+m)$ time.
</PRESERVED_CLASS>
