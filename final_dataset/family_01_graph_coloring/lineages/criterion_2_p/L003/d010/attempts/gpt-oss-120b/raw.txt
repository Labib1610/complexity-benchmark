**Solution Explanation**

For every backup array we need its two endpoints to be in different tiers.
So the graph formed by the `n` instances and the `m` edges must be *bipartite*.
If it is not bipartite there is no feasible configuration.

If the graph is bipartite, each connected component has exactly two possible
assignments – we may exchange the two colour classes.
We have to choose the exchange that makes the whole sequence  
` s1 , s2 , … , sn ` lexicographically smallest.

--------------------------------------------------------------------

#### Lemma  
In a bipartite connected component the lexicographically smallest assignment
is obtained by giving tier **1** to the colour class that contains the smallest
vertex index of this component.

*Proof.*  
Consider the first vertex `v` (smallest index) belonging to the component.
Both colourings are feasible, one gives `v` tier 1, the other tier 2.
All earlier vertices belong to other components and are already fixed,
therefore the lexicographically smallest whole sequence must give `v` tier 1.
All other vertices of the component are forced then (the opposite colour class
gets tier 2). ∎



--------------------------------------------------------------------

#### Algorithm
```
read n, m
build adjacency list
colour[1…n] = -1          # -1 = unvisited, 0/1 = bipartite colour
answer[1…n] = 0

for each vertex v = 1 … n
    if colour[v] == -1
        # start a new component
        bfs from v, colour start with 0
        store all vertices of this component in list comp
        during bfs, if we find a conflict → graph not bipartite → print NO

        # find the smallest index in this component
        min_v = min(comp)
        colour_of_min = colour[min_v]

        # decide mapping: colour == colour_of_min  → tier 1, else tier 2
        for u in comp
            if colour[u] == colour_of_min:
                answer[u] = 1
            else:
                answer[u] = 2

print YES and the answer array
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints **NO** iff no feasible configuration
exists, otherwise prints **YES** and the lexicographically smallest one.

---

##### Lemma 1  
If the algorithm detects a conflict during BFS, the input graph is not
bipartite, therefore no feasible configuration exists.

*Proof.*  
A conflict means an edge connects two vertices that received the same
bipartite colour. Any 2‑colouring of a graph must give opposite colours to
adjacent vertices, so such a graph cannot be bipartite. ∎



##### Lemma 2  
If the algorithm finishes without conflict, the produced `answer`
satisfies the requirement (every edge connects different tiers).

*Proof.*  
For each component BFS assigned a proper bipartite 2‑colouring
(`colour` 0/1). Afterwards we map one colour class to tier 1 and the other to
tier 2 (maybe swapping). Hence adjacent vertices, belonging to opposite
colour classes, receive opposite tiers. ∎



##### Lemma 3  
For each component the algorithm gives tier 1 to the colour class that
contains the smallest vertex index of this component.

*Proof.*  
`min_v` is exactly that smallest vertex. The algorithm maps the colour
`colour[min_v]` to tier 1, all vertices with the same colour receive tier 1,
all others tier 2. ∎



##### Lemma 4  
The whole sequence `answer[1…n]` is lexicographically minimal among all feasible
assignments.

*Proof.*  
Consider the first position `i` where some feasible assignment `B`
differs from `answer`. Vertex `i` belongs to a certain component `C`.
By Lemma&nbsp;3 `answer` gives tier 1 to the colour class that contains the
smallest vertex of `C`. Since `i` is the smallest index of `C` (otherwise an
earlier vertex would already differ), `i` itself is that smallest vertex.
Thus `answer[i] = 1`. Any feasible assignment must give either 1 or 2 to `i`,
and giving 2 would make it lexicographically larger.
Therefore `B[i]` cannot be 2, so `B[i]=1 = answer[i]`. Contradiction.
Hence no feasible assignment is lexicographically smaller than `answer`. ∎



##### Theorem  
The algorithm outputs  

* “NO” iff no assignment satisfying all edges exists;  

* otherwise “YES” and the lexicographically smallest assignment.

*Proof.*  

- If a conflict is found, by Lemma&nbsp;1 the graph is not bipartite, thus no
  assignment exists, and the algorithm correctly prints “NO”.

- If no conflict is found, the graph is bipartite.
  By Lemma&nbsp;2 the produced `answer` is a feasible assignment.
  By Lemma&nbsp;4 it is lexicographically minimal.
  Hence the algorithm prints the required output. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`BFS` visits each vertex once and each edge twice.

```
Time   :  O(n + m)
Memory :  O(n + m)   (adjacency list, colour, answer)
```

Both satisfy the limits (`n,m ≤ 2·10⁵`).

--------------------------------------------------------------------

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 unvisited, 0/1 bipartite colour
    answer = [0] * (n + 1)

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        ok = True
        while q:
            v = q.popleft()
            cv = colour[v]
            for to in adj[v]:
                if colour[to] == -1:
                    colour[to] = cv ^ 1
                    q.append(to)
                    comp.append(to)
                elif colour[to] == cv:
                    # not bipartite
                    print("NO")
                    return
        # choose orientation: smallest vertex gets tier 1
        min_v = min(comp)
        col_min = colour[min_v]
        for v in comp:
            answer[v] = 1 if colour[v] == col_min else 2

    # all components processed
    print("YES")
    print(' '.join(str(answer[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
