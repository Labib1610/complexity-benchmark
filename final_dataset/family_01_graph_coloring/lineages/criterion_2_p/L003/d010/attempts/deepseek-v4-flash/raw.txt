We can model this as a bipartite graph problem.  
Each instance is a node, and each backup array is an edge.  
We need to assign tier 1 or 2 such that every edge connects nodes of different tiers — that’s exactly a 2-coloring problem.

We also need the lexicographically smallest assignment.  
We can do a BFS/DFS over each connected component, always trying to assign the smallest possible value (1) to the current node if it’s uncolored, and propagate the opposite color to neighbors.  
If a conflict occurs, output `NO`.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]  # 1 -> 2, 2 -> 1
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
