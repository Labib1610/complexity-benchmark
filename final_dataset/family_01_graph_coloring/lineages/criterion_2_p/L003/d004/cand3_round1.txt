# Problem B — Beamforming Configuration

Time limit: 1 s   Memory limit: 256 MB

A telecommunications company must configure the spatial multiplexing mode for $n$ MIMO transmission antennas. The configuration requires assigning each antenna $i$ a mode $s_i$, which must be chosen from the set $\{1, 2\}$.

The mode determines the antenna's base beamforming vector. If $s_i = 1$, the antenna's beamforming vector is set to $v_i = (1, 1)$. If $s_i = 2$, the beamforming vector is set to $v_i = (1, -1)$.

Certain pairs of antennas have overlapping coverage cells. When two antennas $u$ and $v$ have overlapping cells, their signals mix in the air. To ensure that user devices can separate the mixed signals, the beamforming vectors $v_u$ and $v_v$ must be linearly independent. That is, they must span the full 2D real signal space $\mathbb{R}^2$. If their vectors are linearly dependent, the mixed signal collapses into a single dimension and the connection will drop.

You must assign a mode to each antenna to satisfy all independence constraints, or determine that no such configuration exists. If multiple valid configurations exist, the automated deployment system requires the configuration whose sequence of mode assignments $s_1 \dots s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of antennas and the number of overlapping coverage pairs.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that antennas $u$ and $v$ have overlapping coverage cells.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The constraint mechanism was completely rewritten from a string-splitting parity check to a linear independence check in $\mathbb{R}^2$. This forces the model to evaluate the mathematical property of the two possible vectors to realize they are only independent if they are different, which logically recovers the 2-coloring requirement while evading models that just pattern-match on sequence splitting.
</RATIONALE>
<PRESERVED_ANSWER>
The vectors $(1, 1)$ and $(1, -1)$ are linearly independent of each other, but any vector is linearly dependent with itself; therefore, overlapping antennas must simply be assigned different modes, which is the exact same $s_u \neq s_v$ constraint as the seed problem.
</PRESERVED_ANSWER>
