<METHOD_DESCRIPTION>Replaces the parity-based "cannot be split into two identical halves" condition with a GCD requirement on shifted values (s_i + 1). Since values are 1 and 2, the shifted values are 2 and 3, and their GCD is 1 if and only if they are different. This obscures the bipartite graph structure and trivial 2-coloring reduction.</METHOD_DESCRIPTION>

# Problem B — System Configuration

Time limit: 1 s   Memory limit: 256 MB

A cloud provider must configure the operation mode for $n$ database instances. The configuration requires assigning each instance $i$ an operation mode $s_i$, which must be chosen from the set $\{1, 2\}$.

Certain pairs of instances share a dedicated backup storage array. When two instances $u$ and $v$ share a backup array, the array establishes a synchronization window based on their operation modes. Specifically, the array calculates a cycle length for each instance by adding $1$ to its operation mode (i.e., $s_u + 1$ and $s_v + 1$). 

To maintain system stability, the array's payload inspector requires that the greatest common divisor of these two cycle lengths must be exactly $1$. If the greatest common divisor is strictly greater than $1$, the array's synchronization will fail due to harmonic resonance.

You must assign a mode to each instance to satisfy all stability constraints, or determine that no such configuration exists. If multiple valid configurations exist, the automated deployment system requires the configuration whose sequence of mode assignments $s_1 \dots s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of database instances and the number of shared backup arrays.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that instances $u$ and $v$ share a backup array.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit string concatenation and "two identical consecutive halves" rule was easily identified by models as an odd-length requirement, cleanly reducing to $s_u \neq s_v$. I replaced this with a GCD condition on shifted values $(s_i + 1)$. Because the base values are $1$ and $2$, the shifted values are $2$ and $3$. The only way their GCD is $1$ is if they are different ($2$ and $3$). This forces models to deduce the inequality constraint mathematically rather than triggering a bipartite matching heuristic.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $\gcd(s_u+1, s_v+1)=1$ is algebraically identical to $s_u \neq s_v$ when $s_i \in \{1, 2\}$, so the set of valid configurations for any input graph remains exactly the same.
</PRESERVED_ANSWER>
