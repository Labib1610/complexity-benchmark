# Problem B — System Configuration

Time limit: 1 s   Memory limit: 256 MB

A cloud provider must configure the operation mode for $n$ database instances. The system allocates a 32-bit integer for each instance's metadata, supporting a maximum total allocation of 800,000 bytes across all instances. Each instance $i$ must be assigned an operation mode $s_i$, chosen from the set $\{1, 2\}$.

Certain pairs of instances share a dedicated backup storage array. The routing table records these connections; each connection requires 16 bytes, and the table's total size cannot exceed 3,200,000 bytes.

When two instances $u$ and $v$ share a backup array, the array's payload inspector continuously monitors their combined signal. The inspector calculates a diagnostic resonance coefficient $R$, defined as:
$R = \frac{s_u}{s_v} + \frac{s_v}{s_u}$

To maintain system stability, the inspector requires that $R$ must NOT be an integer. If $R$ evaluates to an integer, the array's synchronization will fail. 

You must assign a mode to each instance to satisfy all stability constraints, or determine that no such configuration exists. If multiple valid configurations exist, the automated deployment system requires the configuration whose sequence of mode assignments $s_1 \dots s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$, representing the number of database instances and the number of shared backup arrays. The values of $n$ and $m$ respect the memory limits described above, with $n \ge 1$ and $m \ge 0$.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that instances $u$ and $v$ share a backup array.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Removed the "identical halves" string parity condition which models easily map to bipartite coloring. Replaced it with a mathematical formula $R = s_u/s_v + s_v/s_u$ that must not be an integer. Models must evaluate this over the domain $\{1, 2\}$ to deduce that $s_u \neq s_v$ is required, requiring an extra step of logical deduction before the graph structure becomes visible. Numeric bounds were also hidden behind system byte allocations (S07).
</RATIONALE>
<PRESERVED_ANSWER>
The condition $s_u/s_v + s_v/s_u$ evaluates to 2 (an integer) when $s_u = s_v$, and 2.5 (not an integer) when $s_u \neq s_v$ for $s_i \in \{1, 2\}$, perfectly preserving the strict inequality constraint $s_u \neq s_v$ for every shared array.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains exact 2-coloring (bipartiteness testing) to find a lexicographically smallest valid assignment, keeping it solvable in $O(n+m)$ time using BFS.
</PRESERVED_CLASS>
<RISK>
Models might struggle with floating point logic if they attempt to simulate the formula directly instead of mathematically reducing it, though the small domain of {1, 2} limits this risk.
</RISK>
