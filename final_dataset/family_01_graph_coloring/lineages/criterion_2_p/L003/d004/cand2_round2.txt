<STATEMENT>
# Problem B — System Configuration

Time limit: 1 s   Memory limit: 256 MB

A cloud provider must configure the operation mode for $n$ database instances. The configuration requires assigning each instance $i$ an operation mode $s_i$, which must be chosen from the set $\{1, 2\}$.

Each mode is represented by a 2-phase transmission signature. Mode 1 transmits the signature `(1, 0)`, and Mode 2 transmits the signature `(0, 1)`.

Certain pairs of instances share a dedicated backup storage array. When an array is shared between two instances, it merges their signatures by concatenating them into a single 4-phase sequence. (The order in which the two instances' signatures are concatenated does not matter for the stability check.)

To maintain system stability, the array's payload inspector counts the number of inversions in this 4-phase sequence. An inversion is defined as a pair of indices $(i, j)$ such that $1 \le i < j \le 4$ and the value at phase $i$ is strictly greater than the value at phase $j$. 

The array's synchronization will fail unless this 4-phase sequence contains exactly 2 inversions.

You must assign a mode to each instance to satisfy all stability constraints, or determine that no such configuration exists. If multiple valid configurations exist, the automated deployment system requires the configuration whose sequence of mode assignments $s_1 \dots s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of database instances and the number of shared backup arrays.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that instances $u$ and $v$ share a backup array.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I changed the underlying conflict condition from a string concatenation parity rule (cannot be split into two identical halves) to an inversion counting rule on a concatenated 2-phase signature. This forces the model to carefully evaluate the inversion count for all four possible mode combinations to deduce the underlying $s_u \neq s_v$ requirement, hiding the immediate reduction to inequality constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The 4-phase sequence inversion count is exactly 2 if and only if the two instances are assigned different modes, which perfectly preserves the original constraint that sharing instances must be assigned different states.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains a bipartite checking (2-coloring) problem with a lexicographical tie-break, solvable in $O(n+m)$ time using BFS or DFS.
</PRESERVED_CLASS>
