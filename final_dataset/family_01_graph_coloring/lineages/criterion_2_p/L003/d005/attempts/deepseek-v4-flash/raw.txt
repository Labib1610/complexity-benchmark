We can model this as a graph problem.  

First, note that  

\[
M_i = \begin{pmatrix} 3 & -4 \\ 2 & -3 \end{pmatrix}^{s_i}
\]

For \(s_i = 1\):

\[
M = \begin{pmatrix} 3 & -4 \\ 2 & -3 \end{pmatrix}
\]

For \(s_i = 2\):

\[
M^2 = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix} = I
\]

So if \(s_i = 2\), \(M_i = I\).  
If \(s_i = 1\), \(M_i\) is not \(I\).

Now, for an edge \((u, v)\), we require:

\[
M_u \times M_v \neq I
\]

Cases:

- If both are 2: \(I \times I = I\) → invalid.
- If one is 1 and the other is 2: \(M \times I = M \neq I\) → valid.
- If both are 1: \(M \times M = M^2 = I\) → invalid.

So the constraint is: **adjacent nodes cannot have the same mode**.  
This is exactly a bipartite graph coloring problem with modes 1 and 2.

We need to check if the graph is bipartite. If not, output `NO`.  
If yes, we need the lexicographically smallest assignment.  
We can do BFS/DFS, assigning 1 to the first node in each component, then alternate.  
Since we want lexicographically smallest, we process nodes in increasing index order, and when we start a new component, assign 1.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 0  # mode 1
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
