# Problem B — System Configuration

Time limit: 1 s   Memory limit: 256 MB

A cloud provider must configure the operation mode for $n$ database instances. The configuration requires assigning each instance $i$ an operation mode $s_i$, which must be chosen from the set $\{1, 2\}$.

Certain pairs of instances share a dedicated backup storage array. When instances $u$ and $v$ share a backup array, the array undergoes a diagnostic test before it can synchronize them. 

The test simulates a signal pulse traveling inside a two-dimensional rectangular bounding box of width $s_u$ and height $s_v$. 
The pulse originates at the bottom-left corner $(0,0)$ and initially travels in the $(+1, +1)$ direction. 
Whenever the pulse hits a boundary of the box, it reflects perfectly (hitting a vertical wall reverses its X velocity, and hitting a horizontal wall reverses its Y velocity). 
The pulse continues traveling bouncing off the walls until it strikes any of the four corners of the box, at which point it safely dissipates.

However, the array's synchronization sensor is located exactly at the top-right corner $(s_u, s_v)$. 
To maintain system stability, the pulse must never strike this sensor. It must eventually dissipate at one of the other three corners. 
If the pulse strikes the top-right corner, the test fails, and synchronization is aborted.

You must assign a mode to each instance to satisfy all stability constraints, or determine that no such configuration exists. If multiple valid configurations exist, the automated deployment system requires the configuration whose sequence of mode assignments $s_1 \dots s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of database instances and the number of shared backup arrays.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that instances $u$ and $v$ share a backup array.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the transparent arithmetic constraint (Cartesian product size being a perfect square) with a small physical simulation (ray tracing in a grid). This removes the obvious mathematical keywords that models use to pattern-match the bipartiteness condition. To succeed, the model must now mentally simulate or mathematically evaluate the bouncing pulse for the small domain of possible modes ({1, 2}), deduce that the constraint is equivalent to $s_u \neq s_v$, and then apply graph 2-coloring.
</RATIONALE>
<PRESERVED_ANSWER>
A bouncing pulse in an $a \times b$ grid starting at (0,0) hits the top-right corner if and only if $a/\gcd(a,b)$ and $b/\gcd(a,b)$ are both odd; for $a,b \in \{1,2\}$, this only occurs when $a=b$, making the new constraint perfectly equivalent to $s_u \neq s_v$, thus preserving all valid configurations and the lexicographically smallest tie-breaker.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in O(N + M) time using Breadth-First Search (BFS), keeping it in the P complexity class.
</PRESERVED_CLASS>

Models might overthink the physics of the bouncing pulse and attempt to simulate it for large bounds, but since the problem explicitly states $s_i \in \{1, 2\}$, the state space is trivially small and unambiguous.
</RISK>
