**Solution Explanation**

For every edge `{u,v}` we need  

```
|s_u – s_v| = min(s_u , s_v) ,   s_i ∈ {1,2}
```

The only possible pairs are `(1,2)` or `(2,1)` because  

* `1,1` → `|0| = 0 ≠ 1`  
* `2,2` → `|0| = 0 ≠ 2`  

Hence every edge must connect vertices with **different** values.
The whole graph has to be *bipartite* and we have to output the
lexicographically smallest 1‑2‑string among all bipartite colourings.

--------------------------------------------------------------------

#### 1.   Lexicographically smallest colouring

Consider one connected component.
All its vertices are forced to be coloured with two colours, say `0` and `1`
(the usual bipartite colours).  
We may exchange the meaning of the two colours:
* colour `0` → value `1`, colour `1` → value `2`
* or the opposite.

The lexicographically smallest whole assignment is obtained by the
following greedy rule:

*look at the smallest index vertex of the component*.
Give it value `1`.  
All other vertices of the component are then forced.

Why is this optimal?  
If the smallest index vertex received `2`, any other feasible assignment
would have `1` there and would be lexicographically smaller.
Thus the rule is necessary and also sufficient.

Implementation: during BFS we store the list of vertices of the component
and the colour (`0/1`) of the first visited vertex `root = i`.
After the BFS finishes we set

```
if colour[root] == 0:   map 0→1 , 1→2
else:                    map 0→2 , 1→1
```

and write the final values for all vertices of the component.

--------------------------------------------------------------------

#### 2.   Algorithm
```
read n,m
build adjacency list
visited[1..n] = false
answer[1..n]   = 0

for i = 1 .. n:
    if not visited[i]:
        BFS starting from i
            assign temporary colour 0/1
            detect conflict (edge joining same colour) → NOT BIPARTITE
            store all vertices of this component in list comp
        if conflict: print "NO" and exit
        # orientation for lexicographically smallest result
        if colour[i] == 0:
            for v in comp: answer[v] = 1 if colour[v]==0 else 2
        else:
            for v in comp: answer[v] = 2 if colour[v]==0 else 1

print "YES"
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints **NO** iff no valid configuration exists,
otherwise prints the lexicographically smallest valid configuration.

---

##### Lemma 1  
For any edge `{u,v}` a pair `(s_u,s_v)` satisfies the required equation
iff `{s_u,s_v} = {1,2}`.

*Proof.* Direct check of the four possibilities, as shown in the
introduction. ∎



##### Lemma 2  
A configuration exists **iff** the input graph is bipartite.

*Proof.*  
*If* the graph is bipartite, colour its vertices with two colours `0,1`
so that adjacent vertices have different colours.
Assign value `1` to colour `0` and value `2` to colour `1`.  
By Lemma&nbsp;1 every edge connects `1` and `2`, therefore the condition holds.

*Only‑if*: suppose a configuration exists.
By Lemma&nbsp;1 every edge connects vertices with different values,
hence with different values `1`/`2`. Interpreting value `1` as colour `0`
and value `2` as colour `1` gives a proper 2‑colouring, i.e. the graph is
bipartite. ∎



##### Lemma 3  
For a fixed connected component, among the two possible assignments
(the two colour‑to‑value mappings) the one that gives value `1` to the
smallest‑index vertex of the component is lexicographically smallest
among all assignments of this component.

*Proof.*  
All assignments of the component coincide on every vertex except possibly
the two colour‑to‑value mappings. The smallest index where they can differ
is exactly the smallest index vertex of the component.
If it receives `2` in some assignment, the other assignment gives it `1`,
which is smaller, therefore the former cannot be lexicographically minimal.
Conversely, giving `1` to that vertex yields the smallest possible first
difference, so the assignment is minimal. ∎



##### Lemma 4  
When the algorithm processes a component whose smallest index vertex is `i`,
the values written to `answer` for this component are the lexicographically
smallest possible among all valid global configurations.

*Proof.*  
The algorithm colours the component arbitrarily, then applies the rule of
Lemma&nbsp;3, i.e. it gives value `1` to vertex `i`.  
Any global valid configuration must respect the bipartite constraints,
hence on this component it can only use one of the two mappings.
All those configurations give the same prefix up to position `i-1`
(because earlier components are already fixed) and differ first at `i`.
By Lemma&nbsp;3 the algorithm’s choice is the smallest among them. ∎



##### Lemma 5  
If the algorithm finishes without detecting a conflict, the produced
array `answer` satisfies all constraints.

*Proof.*  
During each BFS we ensured that adjacent vertices receive opposite temporary
colours; a conflict would have been reported otherwise.
The final mapping only swaps the two colour names, therefore still assigns
different values to the ends of every edge.
By Lemma&nbsp;1 the condition holds for every edge. ∎



##### Theorem  
The algorithm outputs  

* “NO” **iff** no valid configuration exists;  
* otherwise “YES” and the lexicographically smallest valid configuration.

*Proof.*  

*If part*:  
If the algorithm prints “NO”, it found a conflict, i.e. an edge whose ends
received the same temporary colour. Hence the graph is not bipartite,
so by Lemma&nbsp;2 no configuration exists.

*Only‑if part*:  
If the graph is not bipartite, any 2‑colouring attempt must encounter a
conflict, therefore the algorithm will print “NO”.

Assume the graph is bipartite. The algorithm never meets a conflict,
so by Lemma&nbsp;5 the produced `answer` is a valid configuration.
Consider the order of processing components: they are handled in increasing
order of their smallest vertex index.
By Lemma&nbsp;4 each component is coloured lexicographically minimally
given the already fixed earlier components.
Induction over the components shows that after processing the first `k`
components the prefix `answer[1..p]` (where `p` is the largest vertex index
among those components) is the smallest possible among all valid
configurations.
After the last component the whole array is minimal. ∎

#### 4.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is visited once → `O(n + m)` time.  
*Additional work* (building component lists, writing answers) is linear.

Total  

```
Time   : O(n + m)   ≤ 4·10^5 operations
Memory : O(n + m)   ≤ 4·10^5 integers
```

Both fit easily into the limits.

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    visited = [False] * (n + 1)
    colour = [0] * (n + 1)          # temporary 0/1
    answer = [0] * (n + 1)

    for start in range(1, n + 1):
        if visited[start]:
            continue
        # BFS this component
        q = deque([start])
        visited[start] = True
        colour[start] = 0
        comp = [start]
        ok = True
        while q:
            u = q.popleft()
            cu = colour[u]
            for v in adj[u]:
                if not visited[v]:
                    visited[v] = True
                    colour[v] = cu ^ 1
                    q.append(v)
                    comp.append(v)
                elif colour[v] == cu:
                    # not bipartite
                    print("NO")
                    return
        # orient to make smallest index vertex get value 1
        if colour[start] == 0:
            for v in comp:
                answer[v] = 1 if colour[v] == 0 else 2
        else:
            for v in comp:
                answer[v] = 2 if colour[v] == 0 else 1

    # all components processed
    print("YES")
    sys.stdout.write(' '.join(str(answer[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
