We can model this as a graph problem.  

The condition says: for any edge (u, v),  
`|s_u - s_v| = min(s_u, s_v)`.  

Since modes are only 1 or 2, let’s check possibilities:  
- If both are 1: |1-1| = 0, min = 1 → 0 ≠ 1 → invalid.  
- If both are 2: |2-2| = 0, min = 2 → invalid.  
- If one is 1 and the other is 2: |1-2| = 1, min = 1 → valid.  

So the only valid assignment is that every edge connects nodes of different modes.  
That means the graph must be bipartite.  

We need the lexicographically smallest assignment, so we try to assign 1 as much as possible, but if a node is forced to be 2 due to constraints, we do that.  

We can do BFS/DFS with coloring, starting from each unvisited node with color 1, and if conflict occurs → NO.  

Here’s the implementation:  

```python
import sys
from collections import deque

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    for i in range(n):
        if color[i] == -1:
            color[i] = 1
            q = deque([i])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = 3 - color[u]  # 1 -> 2, 2 -> 1
                        q.append(v)
                    elif color[v] == color[u]:
                        print("NO")
                        return
    
    print("YES")
    print(" ".join(str(c) for c in color))

if __name__ == "__main__":
    solve()
```
