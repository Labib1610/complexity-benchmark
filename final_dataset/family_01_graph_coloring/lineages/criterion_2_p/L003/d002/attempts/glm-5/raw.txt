Let me analyze the constraint: for instances u and v sharing a backup array, |s_u - s_v| = min(s_u, s_v).

If both are 1: |1-1| = 0, min = 1. 0 ≠ 1. Invalid.
If both are 2: |2-2| = 0, min = 2. 0 ≠ 2. Invalid.
If one is 1, other is 2: |1-2| = 1, min = 1. 1 = 1. Valid.

So every edge requires the two endpoints to have different values. This is exactly 2-coloring (bipartite check).

For lexicographically smallest: assign 1 to the smallest-indexed uncolored node, then BFS/DFS assigning opposite colors.

```python
import sys
from collections import deque

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * (n+1)
    
    for start in range(1, n+1):
        if color[start] != 0:
            continue
        color[start] = 1
        q = deque([start])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == 0:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    return
    
    print("YES")
    print(' '.join(str(color[i]) for i in range(1, n+1)))

solve()
```
