# Problem B — System Configuration

Time limit: 1 s   Memory limit: 256 MB

A cloud provider must configure the operation mode for $n$ database instances, indexed from 1 to $n$. The configuration requires assigning each instance $i$ an operation mode $s_i$, which must be chosen from the set $\{1, 2\}$.

Certain pairs of instances share a dedicated backup storage array. To maintain system stability, the load generated by any two instances $u$ and $v$ sharing a backup array must be asymmetric relative to their indices. Specifically, you must assign their operation modes $s_u$ and $s_v$ such that the quantity $s_u \cdot u + s_v \cdot v$ is NOT a multiple of $(u + v)$.

You must assign a mode to each instance to satisfy all stability constraints, or determine that no such configuration exists. If multiple valid configurations exist, the automated deployment system requires the configuration whose sequence of mode assignments $s_1 \dots s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of database instances and the number of shared backup arrays.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that instances $u$ and $v$ share a backup array.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Removed the uniform equation $s_u + s_v = 3$ and replaced it with the condition that $s_u \cdot u + s_v \cdot v$ is not a multiple of $u + v$. This forces the model to algebraically evaluate the index-dependent condition over the domain $\{1, 2\}$ to discover that it is uniformly equivalent to $s_u \neq s_v$, defeating pattern-matching on simple opposite-coloring definitions.
</RATIONALE>
<PRESERVED_ANSWER>
For any $u, v \ge 1$ and $s_u, s_v \in \{1, 2\}$, the quantity $s_u u + s_v v$ is a multiple of $u+v$ if and only if $s_u = s_v$, so the new condition is strictly logically equivalent to $s_u \neq s_v$ for every possible edge.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of a graph, keeping it solvable in linear time (P) using component-wise traversal.
</PRESERVED_CLASS>
