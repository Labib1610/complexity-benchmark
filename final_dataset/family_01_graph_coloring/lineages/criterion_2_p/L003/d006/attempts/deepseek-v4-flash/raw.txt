We can model this problem as a **graph coloring problem** with two colors (modes 1 and 2).  

Let’s analyze the matrix multiplication:

- Mode 1:  
  \( M_1 = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix} \)  
- Mode 2:  
  \( M_2 = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix} \)  

If we compute \( M_1 \times M_1 \):  
\[
\begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}
\begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}
=
\begin{pmatrix} 0 & 0 \\ 0 & 0 \end{pmatrix}
\]
So mode 1 with mode 1 gives zero matrix → invalid.

If we compute \( M_2 \times M_2 \):  
\[
\begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}
\begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}
=
\begin{pmatrix} 0 & 0 \\ 0 & 0 \end{pmatrix}
\]
So mode 2 with mode 2 also gives zero matrix → invalid.

If we compute \( M_1 \times M_2 \):  
\[
\begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}
\begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}
=
\begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}
\]
Non-zero → valid.

If we compute \( M_2 \times M_1 \):  
\[
\begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}
\begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}
=
\begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix}
\]
Non-zero → valid.

So **valid pairs** are exactly (1,2) or (2,1).  
That means: every edge in the graph must connect nodes of **different** modes.  

This is exactly a **bipartite graph** check.  
If the graph is bipartite, we can color it with 1 and 2.  
For lexicographically smallest assignment, we try to assign mode 1 whenever possible during BFS/DFS.

---

Here’s the Python solution:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]  # switch 1 <-> 2
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
