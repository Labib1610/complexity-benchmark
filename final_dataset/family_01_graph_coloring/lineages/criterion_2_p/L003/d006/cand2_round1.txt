# Problem B — System Configuration

Time limit: 1 s   Memory limit: 256 MB

A cloud provider must configure the operation mode for $n$ database instances. The configuration requires assigning each instance $i$ an operation mode $s_i$, which must be chosen from the set $\{1, 2\}$.

Each instance $i$ maintains a $2 \times 2$ state transformation matrix $M_i$. The matrix depends on the assigned operation mode $s_i$:
- If $s_i = 1$, $M_i = \begin{pmatrix} 1 & 2 \\ 3 & -1 \end{pmatrix}$
- If $s_i = 2$, $M_i = \begin{pmatrix} 1 & 0 \\ -1 & -1 \end{pmatrix}$

Certain pairs of instances share a dedicated backup storage array. When two instances $u$ and $v$ share a backup array, the array synchronizes them by computing their combined transformation matrix $C_{u,v} = M_u \times M_v$.

To maintain system stability, the backup array's resonance detector requires that the trace of this combined matrix $C_{u,v}$ (the sum of the elements on its main diagonal) must be exactly $0$. If the trace is non-zero, the array will experience a feedback loop and synchronization will fail. 

You must assign a mode to each instance to satisfy all stability constraints, or determine that no such configuration exists. If multiple valid configurations exist, the automated deployment system requires the configuration whose sequence of mode assignments $s_1 \dots s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of database instances and the number of shared backup arrays.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that instances $u$ and $v$ share a backup array.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I removed the obvious algebraic shortcut ($M_i = A^{s_i}$ where $A^2=I$) that allowed models to trivially deduce $s_u = s_v$ via pattern matching. Instead, I substituted two specific anti-commuting matrices whose product has a trace of 0, whereas their squares have non-zero traces. This forces the models to manually evaluate the matrix products to discover that adjacent instances must have different modes.
</RATIONALE>
<PRESERVED_ANSWER>
The trace of the combined matrix is exactly 0 if and only if the two assigned modes are different, which exactly preserves the original requirement that adjacent instances must have distinct modes.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of an undirected graph, which is in P and solvable in linear time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the matrix multiplication order for $C_{u,v}$, though this is mathematically mitigated because the trace of $M_u M_v$ equals the trace of $M_v M_u$, meaning the constraint evaluates identically either way.
</RISK>
