**Solution Explanation**

For every instance `i` we have to choose a mode `s_i ∈ {1,2}`.
For an edge `(u,v)` the backup array receives a concatenation of

```
s_u copies of the same pulse
followed by
s_v copies of the same pulse
```

All pulses are identical, therefore the whole concatenated string is just a
run of length `L = s_u + s_v`.

The string can be split into two equal consecutive halves **iff** `L` is even.
The stability condition of the problem is that this must **not** happen, i.e.

```
s_u + s_v   is odd          (1)
```

--------------------------------------------------------------------

#### 1.   Reformulation as a graph problem
`1` is odd, `2` is even.  
Condition (1) means that on every edge the two endpoints must have **different
parities**.  
Thus we have to 2‑colour the given undirected graph:

* colour `0`  →  mode `1`
* colour `1`  →  mode `2`

The graph must be **bipartite**; otherwise no assignment exists.

--------------------------------------------------------------------

#### 2.   Lexicographically smallest assignment
If the graph is bipartite, each connected component has exactly two possible
colourings – they are each other’s colour swap.

Lexicographic order compares vertices from `1` to `n`.  
Inside a component the first (smallest index) vertex decides which of the two
colourings is better:

* give it mode `1` (colour `0`) → the whole component becomes smaller,
* give it mode `2` → larger.

Therefore for every component we:

* run BFS/DFS, obtain colours `0/1`,
* find the smallest vertex `v_min` in this component,
* if `colour[v_min] == 0` keep the colours as they are,
  otherwise flip all colours of the component.

After processing all components we have the lexicographically smallest feasible
sequence.

--------------------------------------------------------------------

#### 3.   Algorithm
```
read n, m
build adjacency list
colour[1..n] = -1   // -1 = unvisited

for each vertex i = 1 .. n
    if colour[i] == -1
        start BFS from i, colour[i] = 0
        store all vertices of this component in list comp
        while queue not empty
            pop v
            for each neighbour to
                if colour[to] == -1
                    colour[to] = colour[v] ^ 1
                    push to, add to comp
                else if colour[to] == colour[v]
                    print "NO" and exit   // not bipartite
        // component finished
        v_min = min(comp)
        if colour[v_min] == 1          // need to flip
            for each x in comp
                colour[x] ^= 1

// build answer: mode = 1 if colour == 0 else 2
print "YES"
print the modes
```

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `NO` iff no valid configuration exists,
otherwise prints the lexicographically smallest valid configuration.

---

##### Lemma 1  
For any edge `(u,v)` the stability condition holds **iff** `s_u` and `s_v`
have different parity.

*Proof.* The concatenated string length is `s_u + s_v`.  
It can be split into two equal halves exactly when the length is even.
Thus the condition “cannot be split” ⇔ length is odd ⇔ parities differ. ∎



##### Lemma 2  
A configuration satisfying all stability constraints exists **iff** the graph
is bipartite.

*Proof.* By Lemma&nbsp;1 we need opposite parities on every edge, i.e. a proper
2‑colouring of the graph. Such a colouring exists exactly for bipartite graphs. ∎



##### Lemma 3  
For a bipartite connected component the two possible colourings are
exactly the original BFS colouring and its global colour swap.

*Proof.* In a connected bipartite graph the colour of any vertex determines
uniquely the colour of all others (alternating along edges). Starting BFS with
colour `0` for the start vertex yields one of the two colourings; swapping all
colours yields the other. No other colouring exists. ∎



##### Lemma 4  
For a component, among its two feasible colourings the one that gives mode `1`
to the smallest‑indexed vertex of the component is lexicographically smaller
than the other.

*Proof.* All vertices with index smaller than that vertex belong to earlier
components, whose values are already fixed and equal in both global
assignments. At the first differing position (the smallest vertex of the
component) the assignment with `1` is smaller because `1 < 2`. ∎



##### Lemma 5  
After processing a component the algorithm assigns to it the lexicographically
smallest feasible colouring.

*Proof.* The algorithm obtains a BFS colouring, computes the smallest vertex
`v_min`. If `v_min` currently has colour `1` (mode `2`), it flips the whole
component, otherwise it keeps it. By Lemma&nbsp;4 this yields exactly the
colouring that gives mode `1` to `v_min`, i.e. the smallest feasible one. ∎



##### Lemma 6  
If the algorithm finishes without printing `NO`, the produced sequence satisfies
all stability constraints.

*Proof.* The algorithm only aborts when it discovers an edge whose endpoints
already have the same colour, which would violate bipartiteness.
If it finishes, every edge connects vertices of opposite colours, i.e. opposite
parities, therefore by Lemma&nbsp;1 all constraints hold. ∎



##### Lemma 7  
If a valid configuration exists, the algorithm never prints `NO`.

*Proof.* Existence of a valid configuration implies, by Lemma&nbsp;2, that the
graph is bipartite. In a bipartite graph a BFS never meets an edge with equal
colours, so the algorithm never triggers the conflict test. ∎



##### Theorem  
The algorithm outputs  

* `NO` **iff** no valid configuration exists;  
* otherwise `YES` and the lexicographically smallest valid configuration.

*Proof.*  
- (**Only‑if**) If the algorithm prints `NO`, it found a same‑colour edge,
  meaning the graph is not bipartite, thus by Lemma&nbsp;2 no configuration
  exists.
- (**If**) If a configuration exists, the graph is bipartite, so by Lemma&nbsp;7
  the algorithm does not print `NO`. By Lemma&nbsp;6 the produced sequence is
  valid. By Lemma&nbsp;5 each component is coloured minimally, and components are
  independent, therefore the whole sequence is the lexicographically smallest
  among all valid ones. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis
*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge processed once → `O(n + m)` time.  
*Flipping colours*: total work proportional to number of vertices → `O(n)`.  

Overall  

```
Time   : O(n + m)   ≤ 4·10^5
Memory : O(n + m)
```

Both fit easily into the limits.

#### 6.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 unvisited, 0 -> mode 1, 1 -> mode 2
    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        while q:
            v = q.popleft()
            cv = colour[v]
            for to in adj[v]:
                if colour[to] == -1:
                    colour[to] = cv ^ 1
                    q.append(to)
                    comp.append(to)
                elif colour[to] == cv:
                    print("NO")
                    return
        # decide orientation for lexicographic minimality
        v_min = min(comp)
        if colour[v_min] == 1:          # need to flip
            for x in comp:
                colour[x] ^= 1

    # build answer
    ans = ['1' if colour[i] == 0 else '2' for i in range(1, n + 1)]
    print("YES")
    print(' '.join(ans))

if __name__ == "__main__":
    solve()
```
