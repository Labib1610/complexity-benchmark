# Problem B — System Configuration

Time limit: 1 s   Memory limit: 256 MB

A cloud provider manages $n$ database instances and must assign each instance $i$ an operation mode $s_i$ from the available set $\{1, 2\}$.

The infrastructure includes dedicated backup storage arrays, each shared by a specific pair of instances. System stability dictates that two instances $u$ and $v$ sharing a backup array cannot operate symmetrically. Instead, their assigned modes must be strictly asymmetrical, meaning one instance must operate at a strictly higher mode than the other instance.

Your task is to determine an assignment of operation modes for all instances that satisfies the stability requirements for every shared backup array. If it is impossible to stabilize the system, you must report this. In cases where multiple valid assignments are possible, the automated deployment system requires the configuration whose sequence of mode assignments $s_1 \dots s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of database instances and the number of shared backup arrays.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that instances $u$ and $v$ share a backup array.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit absolute-difference and minimum equation was removed because it transparently signaled a bipartite coloring constraint (where endpoints must have different colors). It was replaced with an operational requirement that one instance must operate at a strictly higher mode than the other. This forces the model to reason about the implications of the `{1, 2}` domain and asymmetrical assignments rather than pattern-matching a standard inequality to graph coloring. Explicit numeric bounds were retained in the Input section to strictly satisfy H2 based on gate feedback.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that one instance must operate at a strictly higher mode than the other over the domain {1, 2} is logically identical to requiring the two instances to have different modes, which perfectly matches the original absolute-difference equation constraint.
</PRESERVED_ANSWER>

The problem remains equivalent to determining whether a graph is bipartite (2-colorable) and finding the lexicographically smallest valid coloring per connected component, which is solvable in O(n+m) time using BFS or DFS.
</PRESERVED_CLASS>
