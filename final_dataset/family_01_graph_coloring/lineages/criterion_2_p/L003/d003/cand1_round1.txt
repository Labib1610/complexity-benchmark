# Problem B — System Configuration

Time limit: 1 s   Memory limit: 256 MB

A cloud provider must configure the operation mode for $n$ database instances. The configuration requires assigning each instance $i$ an operation mode $s_i$, which must be chosen from the set $\{1, 2\}$.

Each instance $i$ continuously transmits a heartbeat signal consisting of a sequence of exactly $s_i$ identical 'sync' pulses. Certain pairs of instances share a dedicated backup storage array. When two instances $u$ and $v$ share a backup array, the array merges their signals by concatenating all their pulses into a single continuous sequence of 'sync' pulses.

To maintain system stability, the array's payload inspector requires that this merged sequence cannot be split into two identical consecutive halves. If the merged sequence can be split in this way, the array's synchronization will fail.

You must assign a mode to each instance to satisfy all stability constraints, or determine that no such configuration exists. If multiple valid configurations exist, the automated deployment system requires the configuration whose sequence of mode assignments $s_1 \dots s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of database instances and the number of shared backup arrays.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that instances $u$ and $v$ share a backup array.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Removed the explicit arithmetic equation `|s_u - s_v| == min(s_u, s_v)` which directly exposed the relationship as a standard two-color inequality. Replaced it with an indirect operational description involving the concatenation of identical pulses and a check for whether the resulting sequence can be split into identical consecutive halves. This forces the model to actually evaluate the operational condition for the possible values in `{1, 2}` to deduce that the constraint requires $s_u \neq s_v$ (since only an odd total length prevents the split), rather than relying on surface pattern matching of mathematical inequalities.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that a sequence of identical pulses cannot be split into two identical halves is mathematically equivalent to requiring the sequence length ($s_u + s_v$) to be odd, which for $s_i \in \{1, 2\}$ is true if and only if $s_u \neq s_v$, preserving all valid assignments exactly.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest valid 2-coloring of a graph, keeping it in P and solvable via Breadth-First Search.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "split into two identical consecutive halves" if they assume the pulses from instance $u$ and instance $v$ are distinguishable, but the wording explicitly states they are merged into a "single continuous sequence of 'sync' pulses," mitigating this risk.
</RISK>
