We can model this as a bipartite graph problem: each instance is a node, and each backup array is an edge requiring the two endpoints to have different modes (1 or 2).  

If the graph is not bipartite, no valid configuration exists.  
If it is bipartite, we can color it with two colors.  
Among all valid colorings, we need the one that minimizes:

\[
E = \sum_{i=1}^n s_i \cdot 2^{n-i}
\]

Since \(2^{n-i}\) is huge for small \(i\), the most significant bit is \(s_1\), then \(s_2\), etc.  
So we want the lexicographically smallest sequence \(s_1, s_2, \dots, s_n\) (with 1 < 2) among all valid bipartite colorings.

We can achieve this by a BFS/DFS that assigns colors greedily:  
- Start with node 1, assign it mode 1.  
- For each connected component, assign the first uncolored node mode 1, then propagate.  
- If a conflict occurs, output NO.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 0  # mode 1
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
