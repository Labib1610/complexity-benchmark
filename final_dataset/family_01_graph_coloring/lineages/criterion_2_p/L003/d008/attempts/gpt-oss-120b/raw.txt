**Solution Explanation**

For every backup array `(u , v)` the two instances must obtain different
modes, i.e. the graph formed by the `n` instances and the `m` edges has to be
*bipartite*.  
If it is not bipartite there is no feasible configuration.

If it is bipartite, each connected component has exactly two possible
assignments:

* colour `0` → mode `1`, colour `1` → mode `2`
* colour `0` → mode `2`, colour `1` → mode `1`

The energy  

```
E = Σ s_i · 2^(n-i)
```

is a binary number where the most significant bit corresponds to `s_1`,
the next to `s_2`, … .
Because `1 < 2`, minimizing `E` is exactly the same as making the sequence
`(s_1,…,s_n)` lexicographically smallest.

--------------------------------------------------------------------

#### Lemma  
For a connected component the lexicographically smallest feasible assignment
is obtained by forcing the **smallest indexed vertex of the component** to
receive mode `1`.

*Proof.*  
Inside a component the two feasible assignments are opposite to each other.
All vertices except the smallest indexed one have larger indices, therefore
their values are less significant for the lexicographic order.
Choosing the assignment that gives the smallest indexed vertex the smaller
value (`1`) makes the whole sequence lexicographically smaller, and no other
choice can improve the prefix before that vertex. ∎



--------------------------------------------------------------------

#### Algorithm
```
read n, m
build adjacency list
colour[1…n] = -1          # -1 = unvisited, 0/1 = bipartite colour
answer[1…n] = 0

for each vertex v = 1 … n
    if colour[v] == -1
        # start a new component
        queue ← [v]; colour[v] = 0
        component_vertices = []
        while queue not empty
            x = pop queue
            component_vertices.append(x)
            for each neighbour y of x
                if colour[y] == -1
                    colour[y] = colour[x] ^ 1
                    push y into queue
                else if colour[y] == colour[x]
                    print "NO" and exit   # not bipartite

        # decide orientation of this component
        min_vertex = min(component_vertices)
        if colour[min_vertex] == 0
            # keep mapping 0→1, 1→2
            for u in component_vertices
                answer[u] = 1 if colour[u]==0 else 2
        else
            # flip mapping
            for u in component_vertices
                answer[u] = 1 if colour[u]==1 else 2

print "YES"
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `"NO"` iff no feasible configuration exists,
otherwise prints a feasible configuration with minimum energy.

---

##### Lemma 1  
If the algorithm prints `"NO"` then the graph is not bipartite.

*Proof.*  
`"NO"` is printed only when during BFS an edge `(x,y)` with `colour[x]==colour[y]`
is found. This is exactly a violation of the bipartite condition, therefore the
graph cannot be coloured with two colours, i.e. no feasible configuration
exists. ∎



##### Lemma 2  
If the graph is bipartite the algorithm outputs a feasible configuration.

*Proof.*  
For each component BFS assigns a proper 2‑colouring (`colour` values differ on
every edge). Afterwards we map the two colours to the two modes (`1` and `2`);
the mapping is applied uniformly inside the component, so adjacent vertices
receive different modes. All components are processed, therefore every edge
satisfies the requirement. ∎



##### Lemma 3  
For a bipartite component the algorithm chooses the lexicographically smallest
assignment among the two possible ones.

*Proof.*  
By construction the algorithm checks the smallest indexed vertex `p` of the
component. If `colour[p]==0` it keeps the mapping `0→1`; otherwise it flips,
so that `p` receives mode `1` in both cases. By Lemma from the *Solution
Explanation* this yields the smallest possible prefix for the whole sequence,
hence the smallest assignment for the component. ∎



##### Lemma 4  
The concatenation of the component‑wise optimal assignments is globally
lexicographically minimal.

*Proof.*  
Consider the vertices in increasing order `1 … n`. The first vertex belonging
to a component `C` is exactly the smallest indexed vertex of `C`. By Lemma 3 the
algorithm gives this vertex mode `1`. No other feasible global assignment can
give a smaller value at this position, because any feasible assignment must
respect the bipartite constraints inside `C` and therefore can only give `1` or
`2`. Hence the prefix up to that vertex is optimal. The same argument repeats
for the next not‑yet‑fixed vertex, which is the smallest index of the next
component, and so on. By induction the whole sequence is lexicographically
minimal. ∎



##### Theorem  
The algorithm outputs  

* `"NO"` iff no configuration satisfying all constraints exists;  
* otherwise `"YES"` and a configuration with minimum possible energy `E`.

*Proof.*  

*If part*: By Lemma 1, `"NO"` implies impossibility.

*Only‑if part*: If a feasible configuration exists, the graph is bipartite.
The algorithm never prints `"NO"` (no colour conflict appears) and by
Lemma 2 outputs a feasible configuration. By Lemma 4 this configuration is
lexicographically smallest, which is equivalent to minimal `E`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all vertices*: each vertex and edge is processed once → `O(n + m)`.  
*Additional work* (finding minima, filling answer) is linear in the size of
components, overall `O(n)`.  

Total time `O(n + m)` ≤ `4·10⁵`, well inside the 1 s limit.  
Memory consumption `O(n + m)` ≤ `~4·10⁵` integers, far below 256 MB.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 unvisited, 0/1 bipartite colour
    ans = [0] * (n + 1)

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp = []
        while q:
            x = q.popleft()
            comp.append(x)
            for y in adj[x]:
                if colour[y] == -1:
                    colour[y] = colour[x] ^ 1
                    q.append(y)
                elif colour[y] == colour[x]:
                    sys.stdout.write("NO")
                    return
        # decide orientation: smallest index gets mode 1
        min_v = min(comp)
        flip = colour[min_v]  # 0 -> no flip, 1 -> flip
        if flip == 0:
            for v in comp:
                ans[v] = 1 if colour[v] == 0 else 2
        else:
            for v in comp:
                ans[v] = 1 if colour[v] == 1 else 2

    out = ["YES", " ".join(str(ans[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
