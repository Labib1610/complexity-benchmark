<METHOD_NAME>Instance-Dependent Scalar Scaling</METHOD_NAME>
<METHOD_DESCRIPTION>Multiplies the base matrix for each instance by an index-dependent scalar. This forces models that rely on precomputing the four possible products of two globally fixed matrices to instead handle instance-specific matrices, breaking their hardcoded shortcut while preserving the underlying bipartite structure (since non-zero scalars do not affect whether a product is the zero matrix).</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Signal Processor Calibration

Time limit: 1 s   Memory limit: 256 MB

A communications array contains $n$ signal processors. You must assign each processor $i$ a frequency band $f_i$ from the set $\{1, 2\}$.

Each processor $i$ operates using a $4 \times 4$ signal transformation matrix $M_i$. This matrix is derived from a base template that depends on the assigned band, scaled by a calibration constant $c_i$. To maintain standard reference levels, processors 1 through 4 share a normalized calibration constant of $c_i = 1$. For all subsequent processors ($i > 4$), the calibration constant scales with the index, so $c_i = i$.

The base templates for the two frequency bands are:

Band 1 template $A^{(1)}$:
$\begin{pmatrix} -8 & -5 & 4 & 5 \\ -10 & -6 & 5 & 6 \\ -16 & -10 & 8 & 10 \\ -10 & -6 & 5 & 6 \end{pmatrix}$

Band 2 template $A^{(2)}$:
$\begin{pmatrix} 6 & 1 & -2 & -2 \\ 10 & -4 & -2 & 0 \\ 10 & 13 & -6 & -10 \\ 13 & -12 & -1 & 4 \end{pmatrix}$

The transformation matrix for processor $i$ is exactly $M_i = c_i A^{(f_i)}$.

The array features $m$ bidirectional data links, each connecting a specific pair of processors $u$ and $v$. A data link is valid only if the combined signal transformation does not result in complete signal loss (represented by $Z$, the $4 \times 4$ matrix of all zeros). Because data flows in both directions, the pair is valid only if both multiplication orders are non-zero:
- $M_u \times M_v \neq Z$
- $M_v \times M_u \neq Z$

Thus, every connected pair must be assigned frequency bands that avoid degenerate interaction.

You must assign a frequency band to each processor to satisfy all data link constraints across the array, or determine that no such assignment exists. Among all feasible assignments, output the one whose sequence $f_1 \dots f_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of signal processors and the number of data links.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that processors $u$ and $v$ share a data link.

## Output
If no valid assignment exists, print a single line NO.
Otherwise, print YES on the first line, followed by a second line containing $n$ integers $f_1 \dots f_n$ (each either 1 or 2), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The seed problem allowed models to precompute the products of two globally fixed matrices and reduce the problem to simple graph coloring. By introducing an index-dependent scaling factor $c_i$, the matrices are now instance-specific. Models attempting to hardcode the combinations will fail, forcing them to either recognize that scalar multiples do not affect the zero-product property or dynamically compute the products for each edge.
</RATIONALE>
<PRESERVED_ANSWER>
Because $c_i \ge 1$, the scalar multiples are strictly positive, and $c_u c_v A^{(x)} A^{(y)} = Z$ if and only if $A^{(x)} A^{(y)} = Z$, meaning the underlying compatibility between any two assigned bands remains exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still reduces to finding a valid 2-coloring of a graph (or determining none exists) and picking the lexicographically smallest valid assignment, which is solvable in $O(n+m)$ time using BFS, keeping it in P.
</PRESERVED_CLASS>
