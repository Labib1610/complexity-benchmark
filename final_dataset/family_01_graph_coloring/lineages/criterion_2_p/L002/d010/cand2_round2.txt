Since the variables are strictly 1 or 2, this equation forces exactly one variable to be 1 and the other to be 2, preserving the bipartite structure while obfuscating it behind non-linear arithmetic. I expect this to defeat the survivors because it doesn't use graph terminology or logical operators, forcing them to logically evaluate the algebraic equation over the restricted domain rather than pattern-matching a known graph algorithm.

<STATEMENT>
# System Calibration

Time limit: 1 s   Memory limit: 256 MB

A technical installation consists of $n$ modules. Each module $i$ must be assigned a power state $p_i$, which is restricted to either `1` or `2`.

The installation has $m$ structural links between specific pairs of modules. For any two modules $u$ and $v$ connected by a link, their assigned power states must satisfy a strict resonance condition to avoid failure. Specifically, the resonance equation $p_u^{p_v} + p_v^{p_u} = 3$ must hold true for their assigned states. 

If there is no way to assign power states to all $n$ modules such that the resonance condition is satisfied for every link, the installation cannot be stabilized. When multiple valid state assignments are possible, you must select the sequence of states (ordered from module 1 to $n$) that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$) — the number of modules and the number of structural links.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — a pair of modules that share a link.

## Output
If no valid state assignment can be found, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $p_1 \dots p_n$ (each either `1` or `2`), denoting the power states for modules 1 through $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit prohibition against assigning the same value to constrained pairs was replaced with the non-linear symmetric equation $p_u^{p_v} + p_v^{p_u} = 3$. This forces models to algebraically evaluate the constraint over the domain $\{1, 2\}$ to discover that it strictly requires $p_u \neq p_v$, thereby hiding the bipartite graph coloring nature of the problem.
</RATIONALE>
<PRESERVED_ANSWER>
Over the domain $\{1, 2\}$, the equation $p_u^{p_v} + p_v^{p_u} = 3$ is only satisfied when one variable is 1 and the other is 2 ($1^2 + 2^1 = 3$), and fails otherwise ($1^1 + 1^1 = 2$, $2^2 + 2^2 = 8$), which is exactly equivalent to the seed's rule that constrained pairs must receive different phases.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains mathematically identical to finding the lexicographically smallest 2-coloring of a graph, which is solvable in O(n+m) time using BFS or DFS, keeping it in the P complexity class.
</PRESERVED_CLASS>
