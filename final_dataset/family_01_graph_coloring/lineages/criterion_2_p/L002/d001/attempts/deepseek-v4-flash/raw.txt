We can model this as a bipartite graph problem.  
Each person gets clearance `1` or `2`.  
For an edge `(u, v)`, the product must be exactly `2`, so one must be `1` and the other `2`.  
That means the graph must be bipartite, and we assign `1` to one side and `2` to the other.

To get the lexicographically smallest assignment, we try to assign `1` to as many low-index nodes as possible.  
We can do a BFS/DFS coloring, but when we start a new component, we try starting with `1` if possible; if that leads to a conflict, we try starting with `2`.

```python
from collections import deque
import sys

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start, first_color):
    q = deque([start])
    color[start] = first_color
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        # try starting with 1
        temp_color = color[:]
        if bfs(i, 0):
            continue
        # if failed, reset and try starting with 2
        color = temp_color
        if not bfs(i, 1):
            print("NO")
            sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
