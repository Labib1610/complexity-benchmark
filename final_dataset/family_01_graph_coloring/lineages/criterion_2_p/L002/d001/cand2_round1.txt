# Module 2: Roster Allocation

Time limit: 1 s   Memory limit: 256 MB

The annual company review process consists of three distinct modules executed in sequence. First, the HR analytics engine scans past incident reports to compile a list of interpersonal conflicts. 

Your task is to implement the second module: the roster allocation processor. This processor receives the list of conflicts and must divide the $n$ personnel into exactly two operational schedules, designated Schedule 1 and Schedule 2. To mitigate risks, for every conflict logged between two individuals, one must be assigned to Schedule 1 and the other must be assigned to Schedule 2.

If it is impossible to divide the personnel in this manner, the processor must abort the workflow. Furthermore, whenever multiple valid scheduling configurations exist, the compliance protocol requires the processor to output the one that yields the lexicographically smallest sequence of schedule assignments (where the sequence is formed by the schedule numbers assigned to personnel 1 through $n$).

Finally, the output of your module is fed into the third module, the payroll system, which uses these schedule designations to apply shift differentials and finalize the weekly pay schedule.

The company allocates a strict registration budget of \$1,000,000, and assigning an employee ID costs exactly \$5. This budget dictates the absolute maximum for the headcount $n$ (calculated as the budget divided by the cost per ID). The analytics engine can process up to 400,000 kilobytes of log data, where each conflict report requires exactly 2 kilobytes of storage, dictating the absolute maximum for the number of conflicts $m$ (calculated as the log capacity divided by the storage per report).

## Input
The first line contains two integers $n$ and $m$, representing the actual number of personnel and the actual number of conflicts for the current workflow. (Their maximum possible values are bounded by the system limits described above, with $n \ge 1$ and $m \ge 0$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — a pair of personnel involved in a conflict.

## Output
If the roster allocation processor cannot find any valid division, output a single line with `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1 \dots s_n$ (each either `1` or `2`), representing the schedule assigned to each person from $1$ to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
