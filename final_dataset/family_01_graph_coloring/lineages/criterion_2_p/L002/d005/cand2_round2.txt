# Tiered Settlement Obligations

Time limit: 1 s   Memory limit: 256 MB

A financial clearinghouse is migrating $n$ institutional accounts to a new regulatory framework. Under this framework, each account must be assigned a compliance tier, strictly designated as either `1` or `2`.

The clearinghouse has identified $m$ reciprocal obligations between specific pairs of accounts. To satisfy risk-margin requirements, any two accounts $u$ and $v$ involved in a reciprocal obligation must be assigned tiers $t_u$ and $t_v$ such that the absolute difference of their cubed tier values is exactly 7 (that is, $|t_u^3 - t_v^3| = 7$). 

If there is no way to assign tiers to all $n$ accounts such that every reciprocal obligation satisfies this margin rule, the migration must be halted. When multiple valid tier assignments are possible, the compliance protocol mandates selecting the sequence of tier designations (ordered from account 1 to $n$) that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of accounts and the number of reciprocal obligations.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — a pair of accounts that share a reciprocal obligation.

## Output
If no valid tier assignment can be found, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (each either `1` or `2`), denoting the compliance tier for accounts 1 through $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Replaced the original quadratic equation (which trivially factored to roots 1 and 2, signaling bipartiteness to LLMs) with the condition $|t_u^3 - t_v^3| = 7$. Because $t_u, t_v \in \{1, 2\}$, this condition is satisfied if and only if one tier is 1 and the other is 2, effectively maintaining the exact same constraint without revealing the underlying graph-coloring structure. The explicit lexicographical tie-break rule was restored to satisfy the I/O contract.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $|t_u^3 - t_v^3| = 7$ for $t_u, t_v \in \{1, 2\}$ is true if and only if one variable is 1 and the other is 2 (since $|1 - 8| = 7$), preserving the exact same valid assignments and outputs as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in O(n + m) time using Breadth-First Search.
</PRESERVED_CLASS>
