**Solution Explanation**

For an edge `{u , v}` we need  

```
C(tu + tv , tu)   is odd
```

`tu , tv` are only `1` or `2`.

--------------------------------------------------------------------

#### 1.   When is a binomial coefficient odd ?

For non‑negative integers `a , b`

```
C(a , b) is odd   ⇔   (a & b) = 0                (Lucas theorem, base 2)
```

`tu + tv` is either `2` (`1+1`) , `3` (`1+2`) or `4` (`2+2`).

```
tu = 1 (01₂) , tv = 1 (01₂)   → 1 & 1 = 1 ≠ 0   → even
tu = 2 (10₂) , tv = 2 (10₂)   → 2 & 2 = 2 ≠ 0   → even
tu = 1 (01₂) , tv = 2 (10₂)   → 1 & 2 = 0       → odd
```

So the edge is **valid iff its ends have different tiers**.
The whole graph must be *bipartite* and the two colour classes are exactly the
tiers `1` and `2`.

--------------------------------------------------------------------

#### 2.   Lexicographically smallest assignment

The graph may consist of several connected components.
Inside one component the two colour classes can be swapped.
To obtain the smallest possible sequence `s1 … sn` we decide the orientation
*independently for each component*:

* look at the smallest vertex index inside the component,
* give this vertex tier `1`,
* consequently the whole component is fixed.

Why is this optimal?  
Consider the first index `i` where two different feasible assignments differ.
`i` belongs to some component `C`.  
If we give `i` tier `1` we obtain a smaller prefix, therefore any optimal
assignment must do exactly that. The rule above does it for every component,
hence the whole sequence is lexicographically minimal.

--------------------------------------------------------------------

#### 3.   Algorithm
```
read n , m
build adjacency list
colour[1…n] = -1          # -1 = unvisited, 0/1 = bipartite colour
answer[1…n] = 0

for each vertex v = 1 … n
    if colour[v] == -1
        BFS/DFS from v, colour the component with 0/1
        if a conflict appears → graph not bipartite → print NO
        collect all vertices of this component in list comp
        find the smallest vertex min_v in comp
        if colour[min_v] == 0
            map colour 0 → tier 1 , colour 1 → tier 2
        else
            map colour 1 → tier 1 , colour 0 → tier 2
        fill answer[vertex] accordingly
print YES and the answer
```

`n , m ≤ 2·10⁵`, BFS/DFS is `O(n+m)` and fits easily into limits.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `NO` iff no feasible assignment exists,
otherwise prints `YES` and the lexicographically smallest feasible assignment.

---

##### Lemma 1  
For an edge `{u,v}` the condition “the number of ways to choose a committee is odd”
holds **iff** `tu ≠ tv`.

*Proof.*  
From Lucas theorem `C(tu+tv,tu)` is odd ⇔ `(tu & tv) = 0`.  
Binary representations: `1 = 01₂`, `2 = 10₂`.  
`1 & 1 = 1 ≠ 0`, `2 & 2 = 2 ≠ 0`, `1 & 2 = 0`. ∎



##### Lemma 2  
A tier assignment satisfying all edges exists **iff** the graph is bipartite.

*Proof.*  
By Lemma&nbsp;1 each edge must connect vertices of different tiers,
i.e. a proper 2‑colouring of the graph.
Conversely any proper 2‑colouring gives a tier assignment (choose which colour
represents tier 1). ∎



##### Lemma 3  
For a connected component `C` let `v_min` be its smallest vertex.
Among all feasible assignments restricted to `C` the lexicographically smallest
one is the one where `v_min` receives tier 1.

*Proof.*  
Inside `C` there are exactly two feasible assignments (the two possible swaps).
They are identical except that the tiers of all vertices are exchanged.
If `v_min` gets tier 2 in an assignment, swapping yields another feasible
assignment where `v_min` gets tier 1 and every earlier vertex (none) is unchanged,
so the swapped assignment is lexicographically smaller.
Thus the optimal one must give tier 1 to `v_min`. ∎



##### Lemma 4  
The algorithm outputs a feasible assignment whenever the graph is bipartite.

*Proof.*  
During BFS each visited edge connects vertices of opposite BFS colours,
otherwise a conflict is detected and the algorithm stops with `NO`.
Hence the BFS colours form a proper 2‑colouring of the component.
The algorithm maps the two colours to tiers `1` and `2` (maybe swapped),
so every edge connects different tiers – by Lemma&nbsp;1 all edges satisfy the
required oddness condition. ∎



##### Lemma 5  
The assignment produced by the algorithm is lexicographically minimal among all
feasible assignments.

*Proof.*  
Consider the vertices in increasing order.
When the algorithm first meets a component `C`, it has not assigned any vertex of
`C` yet. By construction it gives tier 1 to the smallest vertex of `C`
(Lemma&nbsp;3), therefore the prefix up to that vertex is the smallest possible.
All later vertices belong either to already fixed components (identical in every
feasible assignment) or to new components, for which the same argument applies.
Thus no other feasible assignment can be lexicographically smaller. ∎



##### Lemma 6  
If the algorithm prints `NO` then no feasible assignment exists.

*Proof.*  
`NO` is printed only when a conflict is found during BFS, i.e. an edge whose
endpoints already have the same BFS colour. Any 2‑colouring must give opposite
colours to the ends of every edge, therefore the graph is not bipartite.
By Lemma&nbsp;2 no feasible assignment exists. ∎



##### Theorem  
The program

* prints `NO` iff the required tier assignment does not exist,
* otherwise prints `YES` and the lexicographically smallest valid assignment.

*Proof.*  
If the program prints `NO`, by Lemma&nbsp;6 no assignment exists.
If it prints `YES`, the graph was bipartite, Lemma&nbsp;4 guarantees the
produced assignment is feasible, and Lemma&nbsp;5 guarantees it is the
lexicographically smallest one. ∎

#### 5.   Complexity Analysis

*Building adjacency list*: `O(n + m)` memory `O(n + m)`  
*BFS over all components*: each vertex and edge processed once → `O(n + m)` time.  
*Overall*:  

```
Time   :  O(n + m)   ≤ 4·10⁵ operations
Memory :  O(n + m)
```

Both satisfy the limits.

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # 0 / 1 bipartite colour
    answer = [0] * (n + 1)

    from collections import deque

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        while q:
            v = q.popleft()
            cv = colour[v]
            for to in adj[v]:
                if colour[to] == -1:
                    colour[to] = cv ^ 1
                    q.append(to)
                    comp.append(to)
                elif colour[to] == cv:
                    print("NO")
                    return
        # decide orientation: smallest vertex gets tier 1
        min_v = min(comp)
        if colour[min_v] == 0:
            # colour 0 -> tier 1
            for v in comp:
                answer[v] = 1 if colour[v] == 0 else 2
        else:
            # colour 1 -> tier 1
            for v in comp:
                answer[v] = 1 if colour[v] == 1 else 2

    print("YES")
    print(' '.join(str(answer[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
