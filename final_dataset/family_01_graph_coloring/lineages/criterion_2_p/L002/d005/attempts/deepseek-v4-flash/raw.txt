 We need to assign each account a tier (1 or 2) such that for every edge (u, v), the number of ways to choose t_u members from t_u + t_v is odd.  

The combinatorial condition:  
C(t_u + t_v, t_u) is odd.  
By Lucas' theorem, C(a, b) is odd iff (b & (a - b)) == 0.  
Here a = t_u + t_v, b = t_u, so a - b = t_v.  
Thus condition: (t_u & t_v) == 0.  

So the problem reduces to:  
Assign each vertex a value 1 or 2 such that for every edge (u, v), (t_u & t_v) == 0.  
Since t_u, t_v ∈ {1, 2}:  
- 1 & 1 = 1 → invalid  
- 1 & 2 = 0 → valid  
- 2 & 1 = 0 → valid  
- 2 & 2 = 2 → invalid  

So edges must connect vertices of different tiers. This is exactly a bipartite graph condition.  

Thus:  
- If the graph is not bipartite → output NO.  
- If bipartite, we need the lexicographically smallest assignment.  
  We can BFS/DFS color with 1 and 2, but to get lexicographically smallest, we try to assign 1 whenever possible.  
  This means: for each connected component, try starting with 1; if that leads to a conflict, try starting with 2.  

Implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start, c):
    q = deque([start])
    color[start] = c
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

# Try to color each component with starting color 1 if possible
for i in range(n):
    if color[i] == -1:
        # try starting with 1
        temp_color = color[:]
        temp_color[i] = 1
        q = deque([i])
        ok = True
        while q:
            u = q.popleft()
            for v in adj[u]:
                if temp_color[v] == -1:
                    temp_color[v] = 1 - temp_color[u]
                    q.append(v)
                elif temp_color[v] == temp_color[u]:
                    ok = False
                    break
            if not ok:
                break
        if ok:
            color = temp_color
        else:
            # try starting with 2
            color[i] = 2
            q = deque([i])
            ok = True
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = 1 - color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        ok = False
                        break
                if not ok:
                    break
            if not ok:
                print("NO")
                sys.exit()

print("YES")
print(' '.join(str(c + 1) for c in color))
```
