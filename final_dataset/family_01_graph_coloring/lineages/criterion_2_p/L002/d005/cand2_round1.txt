# Tiered Settlement Obligations

Time limit: 1 s   Memory limit: 256 MB

A financial clearinghouse is migrating $n$ institutional accounts to a new regulatory framework. Under this framework, each account must be permanently assigned a compliance tier, strictly designated as either `1` or `2`.

The clearinghouse has identified $m$ reciprocal obligations between specific pairs of accounts. To satisfy risk-margin requirements, any two accounts $u$ and $v$ involved in a reciprocal obligation must be assigned tiers $t_u$ and $t_v$ such that the bitwise XOR of $(3 \times t_u)$ and $(3 \times t_v)$ evaluates to exactly $5$.

Because the migration must be deterministic and perfectly reproducible, the clearinghouse mandates the following sequential state-machine protocol to assign the tiers:
1. The protocol maintains a sequence of assigned tiers, initially empty.
2. It processes the accounts strictly in order from $1$ to $n$.
3. For the current account $i$, the protocol proposes tier `1`.
4. It then performs a full hypothetical validation: "Given the permanent assignments made so far and the proposed tier `1` for account $i$, does there exist at least one way to assign tiers (either `1` or `2`) to all remaining unassigned accounts such that EVERY reciprocal obligation in the entire network satisfies the margin rule?"
5. If the validation returns True, account $i$ is permanently assigned tier `1`.
6. If the validation returns False, account $i$ is permanently assigned tier `2`. 
7. If tier `2` is assigned, but it also cannot lead to a complete valid assignment for the network, the migration is immediately halted.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of accounts and the number of reciprocal obligations.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — a pair of accounts that share a reciprocal obligation.

## Output
If the migration halts because no valid tier assignment can be found, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers (each either `1` or `2`), denoting the finalized compliance tier for accounts 1 through $n$ as produced by the protocol.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

The lexicographical tie-breaker has been rewritten as an explicit sequential state-machine protocol that mathematically computes the exact same result, but strongly encourages a literal $O(N^2)$ simulation which will Time Limit Exceeded. The local edge condition was replaced with a bitwise XOR operation (`(3*tu) ^ (3*tv) == 5`) that evaluates to true only for the pair {1,2}, removing the recognizable quadratic equation and forcing the model to deduce the bipartiteness independently.
</RATIONALE>
