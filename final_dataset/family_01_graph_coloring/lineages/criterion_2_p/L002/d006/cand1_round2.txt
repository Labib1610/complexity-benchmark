<METHOD_NAME>Combinatorial Sequence Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the original binomial parity condition with a sequence arrangement counting problem. Models must analyze the valid permutations of a multiset (of size 2, 3, or 4) to discover that the condition is only satisfied when the two tiers are different. This prevents surface-level pattern matching to bipartiteness without using arithmetic modulo or division that could cause solver drift.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Tiered Settlement Obligations

Time limit: 1 s   Memory limit: 256 MB

A financial clearinghouse is migrating $n$ institutional accounts to a new regulatory framework. Under this framework, each account $i$ must be assigned a compliance tier $t_i$, strictly designated as either `1` or `2`.

The clearinghouse has identified $m$ reciprocal obligations between specific pairs of accounts. To satisfy risk-margin requirements, any two accounts $u$ and $v$ involved in a reciprocal obligation must be assigned tiers $t_u$ and $t_v$ such that they can form a valid joint supervisory committee. 

The rule for the committee is as follows: it must process a sequence consisting of exactly $t_u$ primary audits and $t_v$ secondary audits. To ensure definitive accountability, the total number of distinct ways to arrange these $t_u + t_v$ audits in a sequence such that no two audits of the same type are adjacent must be exactly 1. (Note that audits of the same type are indistinguishable, and the rule is symmetric with respect to $u$ and $v$).

If there is no way to assign tiers to all $n$ accounts such that every reciprocal obligation satisfies this committee rule, the migration must be halted. When multiple valid tier assignments are possible, the compliance protocol mandates selecting the sequence of tier designations (ordered from account 1 to $n$) that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of accounts and the number of reciprocal obligations.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — a pair of accounts that share a reciprocal obligation.

## Output
If no valid tier assignment can be found, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $t_1 \dots t_n$ (each either `1` or `2`), denoting the compliance tier for accounts 1 through $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The binomial parity rule from the seed was replaced with a multiset permutation rule. For $t_u, t_v \in \{1, 2\}$, the number of valid arrangements is 2 when $t_u = t_v$, and 1 when $t_u \neq t_v$. This forces models to manually evaluate the permutations of small multisets to discover the underlying $t_u \neq t_v$ constraint, preventing them from instantly mapping the problem to graph bipartiteness based on surface-level parity keywords.
</RATIONALE>
<PRESERVED_ANSWER>
The new combinatorial rule is satisfied (evaluates to exactly 1) if and only if $t_u \neq t_v$, which is mathematically identical to the seed's binomial parity rule, ensuring all valid assignments and the lexicographically smallest tie-break remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying constraint is still $t_u \neq t_v$ for every edge in a graph with domain $\{1, 2\}$, which is exactly the 2-coloring (bipartiteness) problem, solvable in $O(n+m)$ time using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might struggle to correctly evaluate the multiset permutations for the four possible $(t_u, t_v)$ pairs, leading them to falsely conclude that all pairs are valid or invalid, though the permutations are simple enough that standard reasoning should succeed.
</RISK>
