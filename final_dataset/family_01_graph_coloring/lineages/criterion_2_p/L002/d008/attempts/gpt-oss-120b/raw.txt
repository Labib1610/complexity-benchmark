**Solution Explanation**

For every constraint `(u , v)` we need  

```
p_u * p_v = 2   ,   p_i ∈ {1 , 2}
```

The only possibilities are `(1,2)` or `(2,1)`.  
Therefore the two processes of a constraint must receive **different**
phases.  
The whole system is exactly a *bipartite* graph problem:

* vertices – processes  
* edges    – constraints  

A feasible assignment exists **iff** the graph is bipartite.
If it is bipartite, each connected component has two possible colourings
(the two colour classes can be swapped).

--------------------------------------------------------------------

#### Lexicographically smallest assignment  

The required output is the lexicographically smallest sequence  
`p1 , p2 , … , pn` ( `1 < 2` ).

Consider a connected component.
Let `c` be the smallest index belonging to this component.
If we colour the component so that `c` receives phase `1`,
any other valid colouring would give `c` phase `2` and would be
lexicographically larger, no matter what the later vertices receive.
Hence **the optimal rule is**:

*for every component give its smallest‑index vertex phase `1`.*

If we start a BFS/DFS from that smallest vertex and colour it `0`,
all other vertices obtain colours `0/1` automatically.
Finally we output `colour + 1`, i.e. `0 → 1`, `1 → 2`.  
Thus the smallest vertex of each component gets phase `1` and the whole
sequence is lexicographically minimal.

--------------------------------------------------------------------

#### Algorithm
```
read n , m
build adjacency list

colour[1..n] = -1   // -1 = unvisited
for v = 1 .. n
    if colour[v] == -1
        colour[v] = 0                     // smallest vertex of this component → 0
        queue ← {v}
        while queue not empty
            x ← pop queue
            for each neighbour y of x
                if colour[y] == -1
                    colour[y] = colour[x] xor 1
                    push y
                else if colour[y] == colour[x]
                    print "NO" and exit   // not bipartite
print "YES"
output (colour[i] + 1) for i = 1 .. n
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` exactly when no assignment exists,
otherwise prints the lexicographically smallest valid assignment.

---

##### Lemma 1  
During BFS, if an edge `(x , y)` is processed and `colour[y]` is already
assigned, then `colour[y] = colour[x] xor 1`.

**Proof.**  
When `y` is first discovered, we set its colour to the opposite of its
predecessor, i.e. `colour[y] = colour[parent] xor 1`.  
Later we may encounter the same edge from the other side, but the colour
does not change. ∎



##### Lemma 2  
If the algorithm ever finds an edge whose two ends have the same colour,
the graph is not bipartite, i.e. no feasible phase assignment exists.

**Proof.**  
A bipartite graph admits a 2‑colouring where adjacent vertices have different
colours. The algorithm builds a 2‑colouring respecting this rule
(Lemma&nbsp;1). Encountering an edge with equal colours contradicts the
definition of bipartiteness, therefore such a colouring cannot exist. ∎



##### Lemma 3  
If the algorithm finishes without contradiction, the produced colours
form a proper 2‑colouring of the whole graph.

**Proof.**  
All vertices are visited (the outer loop iterates over all `v`).  
For every processed edge the two ends received opposite colours
(Lemma&nbsp;1) and no conflict was detected, so the invariant holds for
all edges. ∎



##### Lemma 4  
For each connected component the vertex with the smallest index receives
phase `1` in the output.

**Proof.**  
When the outer loop reaches the smallest index `c` of a component,
`colour[c]` is set to `0`. All other vertices of the component receive
colours `0/1` relative to `c`. The final output is `colour + 1`,
hence `c` gets `0+1 = 1`. ∎



##### Lemma 5  
Among all feasible assignments, the one output by the algorithm is
lexicographically smallest.

**Proof.**  
Consider the first position `i` where two feasible assignments differ.
Both assignments must respect the bipartite constraints, therefore `i`
belongs to some component `C`.  
By Lemma&nbsp;4 the algorithm gives the smallest index of `C` phase `1`.
If `i` is that smallest index, the algorithm’s value is `1`, any other
feasible assignment can only give `2` (otherwise it would be the same
assignment). Hence the algorithm is smaller at the first differing
position.  
If `i` is not the smallest index of its component, then the smallest
index of `C` is `< i` and both assignments already coincide on all earlier
positions (they both must give it phase `1`). Therefore the first
difference cannot appear before the smallest index, contradicting the
choice of `i`.  
Thus no other feasible assignment is lexicographically smaller. ∎



##### Theorem  
The algorithm

* prints `NO` iff no assignment of phases satisfying all constraints exists;
* otherwise prints `YES` followed by the lexicographically smallest
  valid assignment.

**Proof.**  

*If the algorithm prints `NO`*: this happens only when a same‑colour edge is
found. By Lemma&nbsp;2 the graph is not bipartite, hence no assignment
exists.

*If a feasible assignment exists*: the graph is bipartite, therefore a
proper 2‑colouring exists. The BFS never encounters a conflict, so the
algorithm reaches the end and, by Lemma&nbsp;3, outputs a proper colouring.
By Lemma&nbsp;5 this colouring is the lexicographically smallest among all
feasible ones.

Thus the statement holds in both directions. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once →  
`O(n + m)` time, `O(n)` additional memory for colour array and queue.

Overall: **Time `O(n + m)`**, **Memory `O(n + m)`**, well within limits.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 = unvisited, 0/1 = two colours

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # start is the smallest index of its component
        colour[start] = 0
        q = deque([start])
        while q:
            x = q.popleft()
            cx = colour[x]
            for y in adj[x]:
                if colour[y] == -1:
                    colour[y] = cx ^ 1
                    q.append(y)
                elif colour[y] == cx:
                    sys.stdout.write("NO")
                    return

    # successful colouring
    out = ['YES\n']
    phases = [str(colour[i] + 1) for i in range(1, n + 1)]
    out.append(' '.join(phases))
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```

and conforms to the required input‑output format.
