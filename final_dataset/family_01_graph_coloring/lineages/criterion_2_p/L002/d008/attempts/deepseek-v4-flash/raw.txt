 We need to assign each process a phase of either 1 or 2 such that for every edge (u, v), the product of their phases is exactly 2.  
That means:  
- If one is 1, the other must be 2.  
- If one is 2, the other must be 1.  

So this is exactly a **bipartite graph** problem:  
- Color one node 1, its neighbors 2, their neighbors 1, etc.  
- If a conflict occurs (a node would need both colors), it’s impossible → print `NO`.  
- Otherwise, we need the lexicographically smallest assignment.  

To get lexicographically smallest, we should try to assign 1 to as many low-index nodes as possible.  
We can do this by running BFS/DFS from each unvisited node in increasing index order, and always try to assign 1 to the starting node if possible.  

Here’s the implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n  # -1 = uncolored, 0 = phase 1, 1 = phase 2

def bfs(start):
    q = deque([start])
    color[start] = 0  # try phase 1
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        if not bfs(i):
            print("NO")
            sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
