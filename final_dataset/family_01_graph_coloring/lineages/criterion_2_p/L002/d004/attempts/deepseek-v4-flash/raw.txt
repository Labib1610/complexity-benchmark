We need to check the condition for the quadratic equation to have integer roots.  

The equation is:  
\[
x^2 - (t_u + t_v)x + 2 = 0
\]  
For integer roots, the discriminant must be a perfect square:  
\[
D = (t_u + t_v)^2 - 8
\]  
Since \(t_u, t_v \in \{1, 2\}\), possible sums are 2, 3, 4.  

- If sum = 2: \(D = 4 - 8 = -4\) → not possible.  
- If sum = 3: \(D = 9 - 8 = 1\) → perfect square, possible.  
- If sum = 4: \(D = 16 - 8 = 8\) → not a perfect square.  

So the only valid case is when \(t_u + t_v = 3\), meaning one is 1 and the other is 2.  
Thus, the graph must be bipartite, with edges connecting nodes of different tiers.

We need to find the lexicographically smallest bipartition (tier assignment) with labels 1 and 2.  
We can do a BFS/DFS, assigning 1 to the first node if possible, and propagate.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 1
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 3 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
