# Tiered Settlement Obligations

Time limit: 1 s   Memory limit: 256 MB

A financial clearinghouse is migrating $n$ institutional accounts to a new regulatory framework. Under this framework, each account must be assigned a compliance tier, strictly designated as either `1` or `2`. The clearinghouse infrastructure supports up to two hundred thousand accounts, and can process up to two hundred thousand reciprocal obligations.

The clearinghouse has identified $m$ reciprocal obligations between specific pairs of accounts. To satisfy risk-margin requirements, any two accounts $u$ and $v$ involved in a reciprocal obligation must be placed in tiers such that the quadratic equation $x^2 - (t_u + t_v)x + 2 = 0$ (where $t_u$ and $t_v$ are their respective tier designations) has integer solutions for $x$.

If there is no way to assign tiers to all $n$ accounts such that every reciprocal obligation satisfies this margin rule, the migration must be halted. When multiple valid tier assignments are possible, the compliance protocol mandates selecting the sequence of tier designations (ordered from account 1 to $n$) that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$, representing the number of accounts and the number of reciprocal obligations. 
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of accounts that share a reciprocal obligation.

It is guaranteed that $n$ is at least one, $m$ is at least zero, neither exceeds the stated infrastructure limits, and all account identifiers are valid positive integers up to $n$.

## Output
If no valid tier assignment can be found, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (each either `1` or `2`), denoting the compliance tier for accounts 1 through $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit difference-of-squares condition was replaced with a mathematically equivalent requirement that the quadratic equation $x^2 - (t_u + t_v)x + 2 = 0$ has integer solutions. This forces the model to algebraically deduce that $t_u + t_v = 3$ (and thus $t_u \neq t_v$), hiding the graph bipartiteness property. Additionally, numeric bounds were moved into the narrative to prevent simple parsing.
</RATIONALE>
<PRESERVED_ANSWER>
Since the only allowed tier values are 1 and 2, the quadratic equation $x^2 - (t_u + t_v)x + 2 = 0$ has integer solutions if and only if $t_u + t_v = 3$, which exactly preserves the constraint that connected accounts must have different tiers.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in linear time using Breadth-First Search, keeping it in the P complexity class.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "has integer solutions" as requiring a specific number of solutions, though any valid quadratic here with one integer solution necessarily has two.
</RISK>
