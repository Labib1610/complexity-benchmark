<STATEMENT>
# Quantum Resonance Initialization

Time limit: 1 s   Memory limit: 256 MB

A quantum computing grid consists of $n$ programmable qubits. To prepare the system for computation, each qubit $i$ must be initialized to a strictly positive integer energy level $s_i$ (where $s_i \ge 1$). 

The grid's architecture includes $m$ entanglement links between specific pairs of qubits. For any two qubits $u$ and $v$ connected by a link, their energy levels must satisfy a strict resonance condition to prevent decoherence. Specifically, if you construct the $3 \times 3$ interaction matrix $M_{u,v}$:

$$ M_{u,v} = \begin{pmatrix} s_u & s_v & 1 \\ s_v & s_u & 1 \\ 1 & 1 & 1 \end{pmatrix} $$

The resonance condition requires that the absolute value of the determinant of $M_{u,v}$ must be exactly 1. 

If there is no way to assign valid energy levels to all $n$ qubits such that every entanglement link satisfies this condition, the initialization must be aborted. When multiple valid energy level assignments are possible, the system's firmware automatically selects the assignment that minimizes the grid's characteristic footprint, defined as $F = \sum_{i=1}^n s_i \cdot 10^{n-i}$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of qubits and the number of entanglement links.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — a pair of qubits connected by an entanglement link.

## Output
If no valid initialization can be found, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$, denoting the energy levels for qubits 1 through $n$. (By the algebraic limits of the resonance condition, these target states will always resolve to either 1 or 2, which perfectly matches standard output protocols).

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was rewritten to disguise the 2-coloring bipartite graph structure. The binary domain $\{1, 2\}$ and the inequality constraint were replaced with an unbounded positive integer domain and a matrix determinant constraint. Evaluating the determinant yields $|(s_u - s_v)(s_u + s_v - 2)| = 1$, which for positive integers strictly limits the only valid solutions to $\{1, 2\}$ and forces $s_u \neq s_v$. The "lexicographically smallest" tie-breaker was rephrased as minimizing a base-10 polynomial, which mathematically forces exactly the same greedy selection. This forces the model to symbolically solve a Diophantine equation and recognize the base-10 minimization as a lexicographical sequence before it can apply the required BFS algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The determinant condition is satisfied by positive integers if and only if one value is 1 and the other is 2, preserving the exact same valid states and inequality constraints as the seed; minimizing the base-10 polynomial $F$ is mathematically identical to selecting the lexicographically smallest sequence of digits.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) on an undirected graph, which is solvable in $O(n+m)$ time using BFS/DFS.
</PRESERVED_CLASS>
