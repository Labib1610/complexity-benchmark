<STATEMENT>
# Sensor Network Frequencies

Time limit: 1 s
Memory limit: 256 MB

A city is deploying a network of $n$ traffic sensors. Each sensor must be assigned an operating frequency band, which is strictly restricted to either band `1` or band `2`.

There are $m$ pairs of sensors located close enough to each other that their signals overlap. To prevent interference, the frequency bands $s_u$ and $s_v$ assigned to any overlapping pair of sensors $u$ and $v$ must satisfy a specific signal separation property. Specifically, the configuration matrix $M = \begin{pmatrix} s_u & 1 \\ 1 & s_v \end{pmatrix}$ formed by their assigned bands must have a determinant of exactly 1.

If there is no way to assign the restricted frequency bands to all $n$ sensors such that every overlapping pair satisfies this separation rule, the deployment must be aborted. When multiple valid assignments are possible, the configuration protocol requires selecting the sequence of band assignments (ordered from sensor 1 to $n$) that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of sensors and the number of overlapping pairs.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — a pair of sensors that have overlapping signals.

## Output
If no valid band assignment can be found, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (each either `1` or `2`), denoting the frequency band for sensors 1 through $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The problem was reframed into a sensor frequency assignment task. The explicit "absolute difference between the squares" constraint was replaced by a 2x2 matrix determinant condition. For variables strictly in {1, 2}, the condition det(M) = 1 algebraically forces the variables to be distinct, requiring the model to deduce the bipartite structural constraint from a novel mathematical presentation.
</RATIONALE>
<PRESERVED_ANSWER>
The determinant condition $s_u s_v - 1 = 1$ simplifies to $s_u s_v = 2$, which for $s_u, s_v \in \{1, 2\}$ is true if and only if one is 1 and the other is 2, perfectly matching the original constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains exactly 2-coloring / bipartiteness testing on an undirected graph, solvable in O(n+m) time using BFS or DFS.
</PRESERVED_CLASS>
