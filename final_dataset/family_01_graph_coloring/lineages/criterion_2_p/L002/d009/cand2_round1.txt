# Process Synchronization

Time limit: 1 s   Memory limit: 256 MB

A distributed system consists of $n$ processes that need to be synchronized. Each process $i$ must be assigned a phase $p_i$, which must be strictly designated as either `1` or `2`.

The system allocates $500$ bytes of memory per process, with the total process allocation capping at exactly $100,000,000$ bytes. There is at least one process. Each constraint record requires $16$ bytes of memory, and the system reserves a maximum of $3,200,000$ bytes for them (there may be zero constraints).

The system has $m$ synchronization constraints between specific pairs of processes. For any two processes $u$ and $v$ that share a constraint, their assigned phases must satisfy the following condition to avoid data collisions:
The greatest common divisor of their phases must be strictly less than their arithmetic mean (i.e., $\gcd(p_u, p_v) < \frac{p_u + p_v}{2}$).

If there is no way to assign phases to all $n$ processes such that every constraint is satisfied, the system cannot be synchronized. When multiple valid phase assignments are possible, the scheduler mandates selecting the valid assignment that minimizes the formal mathematical value of the algebraic expression $\sum_{i=1}^n p_i \cdot 3^{n-i}$.

## Input
The first line contains two integers $n$ and $m$ (bounded by the system memory limits described above) — the number of processes and the number of synchronization constraints.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — a pair of processes that share a synchronization constraint.

## Output
If no valid phase assignment can be found, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $p_1 \dots p_n$ (each either `1` or `2`), denoting the phases for processes 1 through $n$. This sequence must be the one that minimizes the expression defined above.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit product constraint ($p_u \cdot p_v = 2$) was replaced with a number-theoretic inequality ($\gcd(p_u, p_v) < \frac{p_u + p_v}{2}$) which, over the domain $\{1, 2\}$, is only satisfied when $p_u \neq p_v$. The tie-breaking rule "lexicographically smallest" was replaced with minimizing the formal value of $\sum_{i=1}^n p_i \cdot 3^{n-i}$. Because the base (3) is strictly greater than the maximum possible phase value (2), minimizing this polynomial is mathematically identical to finding the lexicographically smallest sequence, forcing models to deduce the greedy equivalence rather than relying on keyword triggers. Bounds were concealed using physical memory limits (S07).
</RATIONALE>

</PRESERVED_ANSWER>
