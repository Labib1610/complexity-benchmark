# Tiered Settlement Obligations

Time limit: 1 s   Memory limit: 256 MB

A financial clearinghouse is migrating $n$ institutional accounts to a new regulatory framework. Under this framework, each account $i$ must be assigned a compliance tier $t_i$, strictly designated as either `1` or `2`.

The clearinghouse has identified $m$ reciprocal obligations between specific pairs of accounts. To satisfy risk-margin requirements, any two accounts $u$ and $v$ involved in a reciprocal obligation must be assigned tiers $t_u$ and $t_v$ such that one account receives a tier that is strictly greater than the other's tier. 

If there is no way to assign tiers to all $n$ accounts such that every reciprocal obligation satisfies this requirement, the migration must be halted. When multiple valid tier assignments are possible, the compliance protocol mandates selecting the sequence of tier designations (ordered from account 1 to $n$) that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of accounts and the number of reciprocal obligations.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — a pair of accounts that share a reciprocal obligation.

## Output
If no valid tier assignment can be found, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $t_1 \dots t_n$ (each either `1` or `2`), denoting the compliance tier for accounts 1 through $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Changed the complex recurrence rule to a plain inequality condition: "one account receives a tier strictly greater than the other's". This forces the model to deduce that for a domain of {1, 2}, this symmetric inequality is exactly equivalent to the undirected constraint t_u != t_v, bypassing surface-level triggers for DAGs or directed graphs.
</RATIONALE>
<PRESERVED_ANSWER>
Since the only allowed tiers are 1 and 2, one tier being strictly greater than the other means they must be {1, 2}, which is logically identical to the original requirement that t_u != t_v.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem remains checking if the graph is bipartite and finding the lexicographically smallest 2-coloring, which is solvable in O(n + m) time using BFS, keeping it in P.
</PRESERVED_CLASS>
