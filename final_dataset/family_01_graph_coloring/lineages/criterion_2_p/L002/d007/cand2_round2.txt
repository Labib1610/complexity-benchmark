<STATEMENT>
# Tiered Settlement Obligations

Time limit: 1 s   Memory limit: 256 MB

A financial clearinghouse is migrating $n$ institutional accounts to a new regulatory framework. Under this framework, each account $i$ must be assigned a compliance tier $t_i$, strictly designated as either `1` or `2`.

The clearinghouse has identified $m$ reciprocal obligations between specific pairs of accounts. To satisfy risk-margin requirements, any two accounts $u$ and $v$ involved in a reciprocal obligation must be assigned tiers $t_u$ and $t_v$ such that they can form a valid joint supervisory committee. 

A committee is validated through a step-by-step review process consisting of $t_u$ primary audits and $t_v$ secondary audits. This process can be visualized as tracing a path on a grid from $(0,0)$ to $(t_u, t_v)$, where each primary audit is a step of length 1 in the positive $x$-direction and each secondary audit is a step of length 1 in the positive $y$-direction. A review path is considered *strictly alternating* if every step (except the first) is in a different direction than the immediately preceding step. The regulatory rule mandates that there must be exactly one strictly alternating path from $(0,0)$ to $(t_u, t_v)$.

If there is no way to assign tiers to all $n$ accounts such that every reciprocal obligation satisfies this committee rule, the migration must be halted. When multiple valid tier assignments are possible, the compliance protocol mandates selecting the sequence of tier designations (ordered from account 1 to $n$) that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of accounts and the number of reciprocal obligations.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — a pair of accounts that share a reciprocal obligation.

## Output
If no valid tier assignment can be found, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $t_1 \dots t_n$ (each either `1` or `2`), denoting the compliance tier for accounts 1 through $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I changed the 1D sequence arrangement constraint to a 2D grid path counting constraint. Models can no longer rely on the "no two adjacent are the same" phrasing (which strongly triggers parity/bipartite coloring templates) and must instead reason geometrically to discover that exactly one strictly alternating path exists if and only if the dimensions are different (t_u != t_v).
</RATIONALE>
<PRESERVED_ANSWER>
The number of strictly alternating paths on a t_u by t_v grid is exactly 1 if and only if t_u != t_v; since tiers are restricted to 1 and 2, this enforces exactly the same opposite-tier constraint as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains strictly equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solveable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
