We need to assign each employee a value of either `1` or `2`.  
The condition for each flagged pair `(u, v)` is:

```
(u % v) + (v % u) == 1
```

Let’s check the possible cases:

- If both are `1`: `(1 % 1) + (1 % 1) = 0 + 0 = 0` → not valid.
- If both are `2`: `(2 % 2) + (2 % 2) = 0 + 0 = 0` → not valid.
- If `u=1, v=2`: `(1 % 2) + (2 % 1) = 1 + 0 = 1` → valid.
- If `u=2, v=1`: `(2 % 1) + (1 % 2) = 0 + 1 = 1` → valid.

So the only valid pairs are those where one is `1` and the other is `2`.  
This means the graph must be bipartite: employees with designation `1` on one side, `2` on the other.

Thus the problem reduces to:  
- Check if the graph is bipartite.
- If not, output `NO`.
- If yes, output the lexicographically smallest assignment.

For lexicographically smallest, we want employee 1 to be `1` if possible.  
We can do BFS/DFS coloring, starting with `1` for the first uncolored node, and try to assign `1` to as many early-index nodes as possible.

We can do this by:
- Iterate nodes from 1 to n.
- If uncolored, color it `1` and BFS/DFS to color neighbors with opposite color.
- If conflict → `NO`.

This gives the lexicographically smallest because we always try `1` first for each new component.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]  # 1 -> 2, 2 -> 1
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
