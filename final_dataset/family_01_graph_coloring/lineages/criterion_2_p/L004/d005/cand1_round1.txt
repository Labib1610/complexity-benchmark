<STATEMENT>
# Orbital Resonance

Time limit: 1 s
Memory limit: 256 MB

A deep space communications network consists of $n$ relay satellites, numbered 1 through $n$. Within this network, there are $m$ known proximity hazards. Each hazard involves a specific pair of satellites that are physically too close to one another.

To stabilize the network, each satellite $i$ must be assigned a tuning parameter $s_i \in \{1, 2\}$.

Let $d_i$ be the total number of hazards involving satellite $i$. When the network is active, each satellite experiences a calibration load from its hazards. Specifically, for each of the $d_i$ hazards involving satellite $i$, we take the tuning parameter of the other satellite involved in that hazard. The incoming load $L_i$ is the sum of these $d_i$ values.

A system-wide failure will occur unless every satellite $i$ achieves absolute calibration resonance. Resonance is achieved when a satellite's incoming load perfectly balances its own emitted tuning frequency, defined by the equation:
$L_i + d_i s_i = 3 d_i$

Isolated satellites (those with $d_i = 0$) trivially satisfy this equation, but must be explicitly assigned $s_i = 1$ to maintain baseline network power.

Your task is to determine if there is a valid assignment of tuning parameters for all satellites that prevents any system-wide failures. If such a configuration is possible, you must output it. If there are multiple valid ways to assign the parameters, you must choose the one whose sequence of assignments $s_1, s_2, \dots, s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a proximity hazard between satellite $u$ and satellite $v$.

## Output
If no safe configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being either 1 or 2), representing the tuning parameter assigned to each satellite from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Removed the $+1/-1$ edge orientations and the extremal balance condition $|C_i| = d_i$, which models easily mapped to "all edges point in/out" and thus bipartiteness. Replaced it with a discrete algebraic equation $L_i + d_i s_i = 3 d_i$. Models must now formally analyze the bounds of this equation (since $s_j \in \{1, 2\}$, $L_i$ must equal $2d_i$ if $s_i=1$ and $d_i$ if $s_i=2$) to deduce that it strictly enforces $s_j \neq s_i$ for all neighbors.
</RATIONALE>
<PRESERVED_ANSWER>
The equation $L_i + d_i s_i = 3 d_i$ is mathematically satisfied if and only if every neighbor of $i$ has the state $3 - s_i$, which perfectly mirrors the original problem's requirement that endpoints of every hazard must have opposite states.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of a graph, which is achievable via Breadth-First Search in $O(n+m)$ time, keeping it in P.
</PRESERVED_CLASS>
