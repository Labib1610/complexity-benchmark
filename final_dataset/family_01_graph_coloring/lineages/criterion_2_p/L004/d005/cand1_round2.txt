<STATEMENT>
# Orbital Resonance

Time limit: 1 s
Memory limit: 256 MB

A deep space communications network consists of $n$ relay satellites, numbered 1 through $n$. Within this network, there are $m$ known proximity hazards. Each hazard involves a specific pair of satellites that are physically too close to one another.

To stabilize the network, every satellite $i$ must be assigned a tuning parameter $s_i \in \{1, 2\}$. 

The safety of the network depends on the local resonance at each satellite. For any satellite $i$, let $d_i$ be the total number of hazards involving it. Let $L_i$ be the sum of the tuning parameters of the opposing satellites across all hazards involving satellite $i$. Specifically, for every hazard involving satellite $i$ and some satellite $j$, the value $s_j$ is added to $L_i$.

A system-wide failure will occur unless every satellite $i$ satisfies the following resonance equation:
$$d_i \cdot s_i + L_i = 3 \cdot d_i$$

Notice that when a satellite is not involved in any hazards ($d_i = 0$), the equation evaluates to $0 = 0$, which imposes no restriction on its tuning parameter $s_i$ for the purpose of network safety.

Your task is to determine if there is a valid configuration of tuning parameters for all $n$ satellites that prevents system-wide failure. If such a safe configuration is possible, you must output it. If there are multiple valid ways to assign the parameters, you must choose the one whose sequence of assignments $s_1, s_2, \dots, s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a proximity hazard between satellite $u$ and satellite $v$.

## Output
If no safe configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being either 1 or 2), representing the tuning parameter assigned to each satellite from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The rewrite removes the affordance of `|C_i| = d_i` which models easily mapped to bipartite two-coloring. Instead, it introduces an algebraic constraint `d_i * s_i + L_i = 3 * d_i`. To solve the problem, models must now deduce that because `s_j` is restricted to `{1, 2}`, this equation strictly forces all adjacent values to be the opposite of `s_i`, thereby reconstructing the bipartite requirement through algebraic reasoning rather than pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic condition mathematically forces `s_j = 2` for all neighbors if `s_i = 1`, and `s_j = 1` for all neighbors if `s_i = 2`, exactly reproducing the two-coloring constraints of the seed; isolated vertices are unconstrained by the equation and thus correctly receive `s_i = 1` from the lexicographically smallest tie-breaker.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains bipartite graph checking (2-coloring) with a lexicographical preference per connected component, which is solvable in O(N + M) time using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret how `L_i` is calculated for multiple edges between the same pair, though the phrase "for every hazard involving satellite i" clarifies that each hazard contributes individually.
</RISK>
