<STATEMENT>
# Quantum Annealing Calibration

Time limit: 1 s
Memory limit: 256 MB

A quantum computer consists of $n$ qubits, numbered 1 through $n$. The system's architecture includes $m$ coupling links, where each link connects a specific pair of qubits. 

To calibrate the system for a computation, every qubit $i$ must be assigned a state parameter $s_i \in \{1, 2\}$.

The stability of the quantum system is determined by its total energy $E$, which is calculated in three parts:
1. **Node Energy:** For each qubit $i$, let $D_i$ be the number of times qubit $i$ appears as an endpoint in the $m$ coupling links. The node energy contributed by qubit $i$ is $D_i (s_i^2 - 6s_i)$.
2. **Link Energy:** For each of the $m$ coupling links, let $u$ and $v$ be the two qubits it connects. The link energy contributed by this connection is $2 s_u s_v$.
3. **Vacuum Energy:** A constant baseline energy of $9m$ is added to the system.

The total energy $E$ is the sum of all $n$ node energies, plus the sum of all $m$ link energies, plus the vacuum energy.

For the system to be perfectly stable and ready for computation, the total energy $E$ must be exactly $0$. (If there are no coupling links, meaning $m=0$, $E$ evaluates to $0$ regardless of the state parameters, making any assignment stable).

Your task is to determine if there is a valid configuration of state parameters for all $n$ qubits that achieves exactly $E = 0$. If such a configuration is possible, you must output it. 

Among all valid assignments $s_1, s_2, \dots, s_n$, output the lexicographically smallest sequence. (A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index $i$ where they differ, $A_i < B_i$).

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — indicating a coupling link between qubit $u$ and qubit $v$.

## Output
If no stable configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being either 1 or 2), representing the state parameter assigned to each qubit from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

## Example 3
Input:
```
3 2
1 2
2 3
```
Output:
```
YES
1 2 1
```

<RATIONALE>
The problem has been entirely reframed from a local pairwise product to a global energy function based on the signless Laplacian of the graph. By grouping the quadratic and linear terms by node degree rather than by edge, the condition $s_u \neq s_v$ is completely disguised as a Quadratic Unconstrained Binary Optimization (QUBO) problem. This forces the model to either perform deep algebraic manipulation to realize $E = \sum (s_u + s_v - 3)^2$ or fail by treating it as an intractable global optimization problem.
</RATIONALE>
<PRESERVED_ANSWER>
Algebraically, the total energy $E$ simplifies exactly to $\sum_{(u,v)} (s_u + s_v - 3)^2$, which evaluates to $0$ if and only if $s_u \neq s_v$ for every edge, meaning the set of valid assignments is perfectly identical to the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring (testing bipartiteness) of the graph, which is solvable in $O(n+m)$ time using Breadth-First Search, keeping it in the P complexity class.
</PRESERVED_CLASS>
