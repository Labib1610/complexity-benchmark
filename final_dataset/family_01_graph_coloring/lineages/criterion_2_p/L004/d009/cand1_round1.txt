<STATEMENT>
# Orbital Resonance

Time limit: 1 s
Memory limit: 256 MB

A deep space communications network consists of $n$ relay satellites. Within this network, there are $m$ known proximity hazards. Each hazard involves a specific pair of satellites that are physically too close to one another.

To stabilize the network, every satellite $i$ must be assigned a tuning parameter $s_i \in \{1, 2\}$. 

The tuning parameter defines a signal phase shift function for that satellite. The base phase shift function is defined for a signal $x$ as:
$$g(x) = \frac{2x - 3}{x - 1}$$

For a satellite $i$ with tuning parameter $s_i$, its individual phase shift is the function $g$ applied $s_i$ times sequentially. We denote this as $g^{(s_i)}(x)$. Thus, if $s_i = 1$, the shift is $g^{(1)}(x) = g(x)$. If $s_i = 2$, the shift is $g^{(2)}(x) = g(g(x))$.

When a signal passes between two satellites $u$ and $v$ involved in a proximity hazard, their phase shifts combine sequentially to produce a hazard transformation $H_{u,v}(x) = g^{(s_u)}(g^{(s_v)}(x))$. 

For the network to be safe, every single proximity hazard must perfectly neutralize the signal phase. This means that for all $m$ hazards, the combined transformation must act as the identity transformation, simplifying algebraically to exactly $H_{u,v}(x) = x$. (If $m=0$, there are no hazards and the network is inherently safe).

Your task is to determine if there is a valid configuration of tuning parameters for all $n$ satellites that makes the network safe. If such a configuration is possible, you must output it. 

Among all valid assignments $s_1, s_2, \dots, s_n$, output the lexicographically smallest sequence. (A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index $i$ where they differ, $A_i < B_i$).

## Input
The first line contains two integers $n$ and $m$. The network always contains at least one satellite. To ensure memory safety, the system limits the satellite index array to exactly 1,600,000 bytes (at 8 bytes per satellite ID), which dictates the maximum possible value for $n$. Similarly, the hazard list can be empty, but is constrained by a strict buffer of 3,200,000 bytes (at 16 bytes per hazard), dictating the maximum possible value for $m$.
Each of the next $m$ lines contains two integers $u$ and $v$ — indicating a proximity hazard between satellite $u$ and satellite $v$ ($1 \le u, v \le n$, $u \neq v$).

## Output
If no safe configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being either 1 or 2), representing the tuning parameter assigned to each satellite from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

Models can no longer immediately pattern-match the bipartite nature from a quadratic form; they must either correctly execute symbolic algebra for sequential function compositions or write an accurate script to evaluate the periodic behavior of the Mobius transformation to deduce that $s_u \neq s_v$. <PRESERVED_ANSWER>
The function $g(x) = (2x-3)/(x-1)$ has a strict period of 3, meaning $g^{(k)}(x) = x$ if and only if $k$ is a multiple of 3; since $s_u, s_v \in \{1, 2\}$, their sum is in $\{2, 3, 4\}$, so the condition $H_{u,v}(x) = x$ is satisfied exactly when $s_u + s_v = 3$, enforcing $s_u \neq s_v$ identically to the seed's $R_{u,v} = 7$.
</PRESERVED_ANSWER>

The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of a graph (or detecting an odd cycle), keeping it firmly in P.
</PRESERVED_CLASS>
