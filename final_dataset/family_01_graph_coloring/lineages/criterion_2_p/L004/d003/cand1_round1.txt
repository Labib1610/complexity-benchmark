# Orbital Resonance

Time limit: 1 s
Memory limit: 256 MB

A deep space communications network consists of $n$ relay satellites, numbered 1 through $n$. Within this network, there are $m$ known proximity hazards. Each hazard involves a specific pair of satellites that are physically too close to one another.

Every satellite must be assigned a frequency multiplier, which must be either a base unit of 1 or a doubled unit of 2. Whenever two satellites share a proximity hazard, they must maintain a balanced resonance. To check this balance, take each satellite's multiplier in the pair, cube it, and multiply it by the other satellite's multiplier. The sum of these two resulting values must be exactly 10. If this calculation yields any other value, their resonance will cause a system-wide failure.

Your task is to determine if there is a valid configuration of multipliers for all $n$ satellites that prevents any system-wide failures. If such a configuration is possible, you must output it. If there are multiple valid ways to assign the multipliers, you must choose the one whose sequence of assignments $s_1, s_2, \dots, s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$. The deep space administration divides the network into 200 zones, each capable of hosting up to 1,000 satellites. Thus, the total number of satellites $n$ is at least 1 and at most the maximum theoretical capacity of all zones combined. The hazard database allocates memory for a maximum number of records equal to this same combined capacity, meaning $m$ can be anywhere from 0 up to this limit.
Each of the next $m$ lines contains two integers $u$ and $v$ — indicating a proximity hazard between satellite $u$ and satellite $v$.

## Output
If no safe configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being either 1 or 2), representing the multiplier assigned to each satellite from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The direct inequality condition `|x^3 - y^3| = 7` is a common pattern-matching trigger for "x must not equal y". This was replaced with a verbal description of the equation `x^3 * y + y^3 * x = 10`, which achieves the exact same truth table for domain {1, 2} but forces the model to translate the text into math and evaluate the pairs rather than rely on memorized CP tropes. Additionally, the constraints on `n` and `m` were stated indirectly via a multiplication puzzle (200 zones * 1000 satellites) as requested by the strategy.
</RATIONALE>
<PRESERVED_ANSWER>
The condition `1^3*2 + 2^3*1 = 2 + 8 = 10` holds for unequal values, while `1^3*1 + 1^3*1 = 2` and `2^3*2 + 2^3*2 = 32` fail for equal values; thus the constraint remains strictly that adjacent nodes must have different values, leaving all valid assignments identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest valid 2-coloring of a graph, which is solvable in O(V + E) using BFS or DFS.
</PRESERVED_CLASS>
