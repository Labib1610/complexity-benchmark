**Solution Explanation**

For every edge `{u , v}` the tuning parameters must satisfy  

```
s_u³ + s_v³ + (s_u·s_v)² = 13 ,   s_u , s_v ∈ {1 , 2}
```

The four possible pairs are

| s_u | s_v | value |
|-----|-----|-------|
| 1   | 1   | 3     |
| 1   | 2   | 13    |
| 2   | 1   | 13    |
| 2   | 2   | 32    |

Only the mixed pairs `(1,2)` and `(2,1)` give `13`.  
Therefore every hazardous pair must consist of **different** parameters.
The whole problem is exactly the classic *graph bipartition* problem:

* assign each vertex colour `0` or `1` (the two sides of a bipartition);
* every edge must join vertices of different colours.

If the graph is not bipartite – i.e. some edge connects two vertices of the
same colour – the answer is `NO`.

If it is bipartite we still have a freedom: for each connected component we
may swap the two colour classes.
We have to output the **lexicographically smallest** sequence
`(s₁,…,s_n)` (`1 < 2`).  
Greedy works:

*process vertices in increasing order*.
When we first meet a vertex `v` of a still‑unoriented component,
we choose the orientation that gives `s_v = 1`.  
All earlier positions are already fixed, and giving the smallest possible
value to the current earliest unfixed position is optimal for the whole
lexicographic order.

Thus the algorithm is:

```
for i = 1 … n
    if i not visited
        BFS/DFS from i, colour the whole component (0/1)
        if a conflict appears → NOT BIPARTITE → NO
        orientation = (colour[i] == 0) ? (0→1,1→2) : (0→2,1→1)
        set answer for every vertex of the component accordingly
```

Isolated vertices are handled the same way – they receive `1`.

The whole work is linear `O(n+m)` and fits easily into the limits.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise prints `YES` and the lexicographically smallest valid assignment.

---

##### Lemma 1  
For any edge `{u,v}` the equation is satisfied **iff** `s_u ≠ s_v`.

*Proof.* Direct evaluation of the four possible pairs (shown above). ∎



##### Lemma 2  
If the algorithm reports `NO` then the graph is not bipartite, therefore no
assignment exists.

*Proof.* The algorithm reports `NO` only when during the BFS a neighbour already
coloured with the same colour as the current vertex is found.
That is exactly a violation of bipartiteness.
By Lemma&nbsp;1 any valid assignment would be a proper 2‑colouring,
hence cannot exist. ∎



##### Lemma 3  
If the algorithm finishes without conflict, the produced assignment satisfies
the equation for every edge.

*Proof.* The BFS colours each edge with opposite colours (`0` vs `1`),
otherwise a conflict would have been detected.
The final step maps the two colour classes of each component to the values
`1` and `2`. Consequently every edge connects vertices with different values,
and by Lemma&nbsp;1 the equation holds. ∎



##### Lemma 4  
For a fixed connected component, among the two possible assignments
(the two possible swaps) the algorithm chooses the one that is lexicographically
smaller for the whole sequence.

*Proof.* Let `c` be the smallest vertex index belonging to this component.
The algorithm orients the component so that `s_c = 1`.  
The alternative orientation would give `s_c = 2`.  
Since `1 < 2`, any sequence beginning with `s_c = 1` is lexicographically
smaller than any sequence with `s_c = 2`, regardless of later positions.
Thus the chosen orientation is optimal for this component. ∎



##### Lemma 5  
The whole sequence output by the algorithm is the lexicographically smallest
among all valid assignments.

*Proof.* Process vertices in increasing order.
When the algorithm first meets a vertex `v` of a component, all earlier
vertices belong to already processed components and their values are already
fixed to the smallest possible ones (induction hypothesis).
By Lemma&nbsp;4 the algorithm picks the orientation that gives `s_v = 1`,
the smallest feasible value for this earliest unfixed position.
Therefore after fixing `v` the prefix up to `v` is lexicographically minimal.
Proceeding inductively over all vertices yields a globally minimal sequence. ∎



##### Theorem  
The algorithm outputs  

* `NO` **iff** no assignment of `{1,2}` to all satellites satisfies the
  equation for every hazardous pair;
* otherwise `YES` and the lexicographically smallest such assignment.

*Proof.*  
- If the algorithm prints `NO`, by Lemma&nbsp;2 no assignment exists.  
- If it prints `YES`, Lemma&nbsp;3 guarantees the assignment is valid,
  and Lemma&nbsp;5 guarantees it is the lexicographically smallest one.  

Conversely, if a valid assignment exists, the graph must be bipartite
(Lemma&nbsp;1), so the algorithm never meets a conflict and therefore prints
`YES`. ∎

#### Complexity Analysis  

*Building adjacency lists*: `O(n+m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once → `O(n+m)` time.  
*Total*: `O(n+m)` time, `O(n+m)` memory, well within the limits (`n,m ≤ 2·10⁵`).

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # 0 / 1 during BFS
    answer = [0] * (n + 1)           # final s_i (1 or 2)

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        ok = True
        while q:
            v = q.popleft()
            cv = colour[v]
            for to in adj[v]:
                if colour[to] == -1:
                    colour[to] = cv ^ 1
                    q.append(to)
                    comp.append(to)
                elif colour[to] == cv:
                    # not bipartite
                    print("NO")
                    return
        # decide orientation: make start vertex have value 1
        if colour[start] == 0:
            # 0 -> 1, 1 -> 2
            for v in comp:
                answer[v] = 1 if colour[v] == 0 else 2
        else:
            # 1 -> 1, 0 -> 2
            for v in comp:
                answer[v] = 1 if colour[v] == 1 else 2

    # all done
    print("YES")
    sys.stdout.write(' '.join(str(answer[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
