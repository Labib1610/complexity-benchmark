# Replica Synchronization

Time limit: 1 s
Memory limit: 256 MB

You are configuring a distributed database consisting of $n$ replica servers, numbered 1 through $n$. Each replica server must be assigned a protocol version, which is an integer chosen strictly from $\{1, 2\}$.

The database relies on $m$ synchronization channels to maintain consistency. Each channel connects a specific pair of replica servers. For a channel to operate without data corruption, the protocol versions of the two connected servers must pass a strict binary checksum constraint. Specifically, for a channel connecting server $u$ and server $v$, you must calculate the bitwise XOR of their product and their sum: $(s_u \times s_v) \oplus (s_u + s_v)$, where $s_u$ and $s_v$ are the protocol versions of the two servers. The channel operates correctly if and only if this checksum evaluates to exactly 1. If the checksum evaluates to any other value, the channel will drop all packets and trigger a cluster-wide failure.

Your task is to determine if there is a valid configuration of protocol versions for all $n$ replica servers that prevents any cluster-wide failures. If such a configuration is possible, you must output it. If there are multiple valid ways to assign the versions, you must choose the one whose sequence of assignments $s_1, s_2, \dots, s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — indicating a synchronization channel between replica server $u$ and replica server $v$.

## Output
If no safe configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being either 1 or 2), representing the protocol version assigned to each replica server from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
