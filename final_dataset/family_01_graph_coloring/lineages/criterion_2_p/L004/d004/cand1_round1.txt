<STATEMENT>
# Orbital Resonance

Time limit: 1 s
Memory limit: 256 MB

A deep space communications network consists of $n$ relay satellites, numbered 1 through $n$. Within this network, there are $m$ known proximity hazards. Each hazard involves a specific pair of satellites that are physically too close to one another. Let $d_i$ denote the number of hazards involving satellite $i$.

Every satellite in the network must be assigned a tuning parameter $s_i$, which is an integer chosen from $\{1, 2\}$. The network generates a total resonance $R$, which is determined by the individual parameters and their interactions across all hazards. Specifically, the total resonance is given by:

$R = 3 \sum_{i=1}^n d_i s_i - 2 \sum_{j=1}^m s_{u_j} s_{v_j}$

where the second sum is over all $m$ hazards, and $u_j, v_j$ are the two satellites involved in the $j$-th hazard.

To maintain orbital equilibrium, the total resonance must exactly equal $5m$. If $R$ evaluates to any other value, the resonance will cause a system-wide failure.

Your task is to determine if there is a valid configuration of tuning parameters for all $n$ satellites that prevents any system-wide failures. If such a configuration is possible, you must output it. If there are multiple valid ways to assign the parameters, you must choose the one whose sequence of assignments $s_1, s_2, \dots, s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a proximity hazard between satellite $u$ and satellite $v$.

## Output
If no safe configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being either 1 or 2), representing the tuning parameter assigned to each satellite from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The local edge constraint was replaced with a global sum over all vertices and edges. To realize this is a 2-coloring problem, the model must algebraically factorize the vertex degree sum into an edge sum, evaluate the combinations over the domain {1, 2}, and deduce that the global maximum of 5m is only achievable when every single edge independently evaluates to 5 (which strictly requires opposite parameters). This defeats pattern-matching models that rely on explicitly evaluating isolated edge constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The global sum factorizes over edges to exactly $5m$ if and only if every edge has endpoints with different values from {1, 2}, making the valid configurations identical to the seed's bipartite colorings.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a lexicographically smallest 2-coloring of a graph, which is solvable in O(N+M) time using BFS, keeping it in P.
</PRESERVED_CLASS>
