**Solution Explanation**

For a satellite `i`

* state `1`  → vector `A = (1,2,3,4)`
* state `2`  → vector `B = (4,-3,-2,1)`

For a hazard (edge) `{u,v}` the penalty is the dot product of the two
vectors.

```
A·A = 1+4+9+16 = 30
B·B = 16+9+4+1 = 30
A·B = 1·4 + 2·(-3) + 3·(-2) + 4·1 = -4
```

So for an edge

* both ends have the same state → penalty `30`
* different states                → penalty `-4`

Let  

* `x` – number of edges whose ends have the same state  
* `m-x` – edges with different states  

Total penalty  

```
30·x + (-4)·(m-x) = 34·x - 4·m
```

The required total penalty is `-4·m`.  
Hence we need `34·x = 0` → `x = 0`.  
**Every edge must connect satellites of different states.**

That is exactly the definition of a *bipartite* graph.
So the problem reduces to:

*Is the given graph bipartite?*  
If yes, output a 2‑coloring (`1` / `2`) that is lexicographically smallest.

--------------------------------------------------------------------

#### Lexicographically smallest coloring

Each connected component can be colored in two ways (swap the two colors).
Components are independent, therefore we can decide the orientation of every
component separately.

Consider one component, let `v` be the smallest numbered vertex inside it.
If we give `v` state `1`, the whole component’s orientation is fixed;
otherwise `v` would be `2` and the whole component would be the opposite
coloring, which is lexicographically larger because the first differing
position is `v`.

Thus for each component we:

1. BFS/DFS, assign temporary colors `0` / `1` and check bipartiteness.
2. Find the smallest vertex `v` of the component.
3. If its temporary color is `1`, flip all colors of the component
   (`0 ↔ 1`).  
   Afterwards `v` gets state `1`.

Finally state = `color + 1`.

Isolated vertices (no edges) are single‑vertex components; they receive
state `1`, which is optimal.

--------------------------------------------------------------------

#### Algorithm
```
read n, m
build adjacency list
state[1..n] = 0          # 0 = unvisited, otherwise 1 or 2
color[1..n] = -1         # temporary 0/1 during BFS

for each vertex i = 1 .. n
    if state[i] == 0
        BFS from i
            assign color 0 to i
            collect all vertices of this component in list comp
            if a conflict (neighbor already colored with same color) → NOT bipartite
        min_v = minimum vertex in comp
        if color[min_v] == 1          # need to flip
            for each v in comp: color[v] ^= 1
        for each v in comp: state[v] = color[v] + 1   # 1 or 2

if any conflict happened → print "NO"
else
    print "YES"
    print state[1] … state[n]
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise prints the lexicographically smallest valid assignment.

---

##### Lemma 1  
For any assignment of states, the total penalty equals `34·x - 4·m`,
where `x` is the number of edges whose ends have the same state.

*Proof.* Direct calculation using the three possible dot products
(30,30,-4) as shown above. ∎



##### Lemma 2  
A state assignment satisfies the required total penalty `-4·m`
iff every edge connects vertices of different states
(i.e. the graph is bipartite with the two states as the two parts).

*Proof.* By Lemma&nbsp;1 the required equality `34·x - 4·m = -4·m`
implies `34·x = 0`, therefore `x = 0`. Conversely, if `x = 0` the total
penalty is `-4·m`. ∎



##### Lemma 3  
During BFS the algorithm detects a conflict exactly when the component
is not bipartite.

*Proof.* BFS colors a graph with two colors, assigning opposite colors to
adjacent vertices. If an edge is found whose ends already have the same
color, the component contains an odd cycle and is not bipartite.
If BFS finishes without conflict, a proper 2‑coloring exists, i.e. the
component is bipartite. ∎



##### Lemma 4  
If the algorithm finishes without reporting a conflict, the produced
`state[ ]` assignment makes every edge connect different states.

*Proof.* For each component the algorithm either keeps the BFS colors
or flips all of them. In both cases adjacent vertices have opposite
temporary colors, therefore opposite final states (`color+1`). ∎



##### Lemma 5  
For a bipartite component, the algorithm chooses the orientation that
gives the smallest possible state sequence restricted to the vertices of
that component.

*Proof.* Let `v` be the smallest vertex of the component.
If we assign `v` state `1`, the whole component’s orientation is forced
(the opposite orientation would give `v` state `2`). Any valid assignment
must give either `v` state `1` or `2`. Since `1 < 2`, the orientation with
`v` = `1` is lexicographically smaller on the first position belonging to
the component. The algorithm exactly selects this orientation. ∎



##### Lemma 6  
The concatenation of the component‑wise optimal orientations is the
lexicographically smallest global assignment.

*Proof.* Consider the vertices in increasing order.
The first vertex belonging to a component `C` is exactly the minimal
vertex of `C`. By Lemma&nbsp;5 the algorithm gives this vertex state `1`,
which is the smallest possible value for that position among all
valid global assignments. All earlier positions belong to earlier
components and are already fixed to their minimal possible values.
Thus no other valid assignment can be lexicographically smaller. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no assignment with total penalty `-4·m` exists;  
* otherwise `YES` and the lexicographically smallest assignment satisfying
  the requirement.

*Proof.*  
- If the algorithm prints `NO`, a conflict was found, i.e. some component
  is not bipartite (Lemma&nbsp;3). By Lemma&nbsp;2 any valid assignment would
  require the graph to be bipartite, contradiction. Hence no assignment
  exists.

- If the algorithm prints `YES`, all components are bipartite
  (no conflict). By Lemma&nbsp;4 the produced assignment makes every edge
  connect different states, therefore satisfies the total penalty
  condition (Lemma&nbsp;2). By Lemma&nbsp;6 this assignment is the
  lexicographically smallest among all such assignments.

Thus the theorem holds. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(n + m)`  
*BFS over all components*: each vertex and edge processed once → `O(n + m)`  
*Memory*: adjacency list `O(n + m)`, plus a few `O(n)` arrays.

Both limits satisfy the constraints (`n, m ≤ 2·10⁵`).

--------------------------------------------------------------------

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    state = [0] * (n + 1)          # final answer: 1 or 2, 0 = unvisited
    color = [-1] * (n + 1)         # temporary 0/1 during BFS
    ok = True

    for start in range(1, n + 1):
        if state[start]:
            continue
        # BFS this component
        q = deque([start])
        color[start] = 0
        comp = [start]
        while q:
            u = q.popleft()
            cu = color[u]
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = cu ^ 1
                    q.append(v)
                    comp.append(v)
                elif color[v] == cu:
                    ok = False
                    break
            if not ok:
                break
        if not ok:
            break

        # choose orientation: smallest vertex gets state 1
        min_v = min(comp)
        if color[min_v] == 1:          # need to flip
            for v in comp:
                color[v] ^= 1
        for v in comp:
            state[v] = color[v] + 1     # 1 or 2

    out = sys.stdout
    if not ok:
        out.write("NO")
    else:
        out.write("YES\n")
        out.write(' '.join(str(state[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```

conforms to the required input‑output format.
