<STATEMENT>
# Orbital Resonance

Time limit: 1 s
Memory limit: 256 MB

A deep space communications network consists of $n$ relay satellites, numbered 1 through $n$. Within this network, there are $m$ known proximity hazards. Each hazard involves a specific pair of satellites that are physically too close to one another.

To stabilize the network, every satellite $i$ must be assigned a phase state $s_i \in \{1, 2\}$. 

When a signal passes between two satellites $u$ and $v$ involved in a proximity hazard, their phase states interact to produce a resonance factor $R_{u,v}$ for that hazard. 

First, each satellite's phase state is converted into an augmented state $A_i$ using the formula:
$A_i = 5s_i - 1$

The resonance factor $R_{u,v}$ between the two satellites is then calculated as the greatest common divisor (GCD) of their augmented states:
$R_{u,v} = \gcd(A_u, A_v)$

The global resonance of the network is defined as the product of the resonance factors of all $m$ listed hazards. (If there are no hazards, meaning $m=0$, this product is defined to be 1).

For the network to be safe, the global resonance must be exactly 1.

Your task is to determine if there is a valid configuration of phase states for all $n$ satellites that achieves this exact global resonance. If such a configuration is possible, you must output it. 

Among all valid assignments $s_1, s_2, \dots, s_n$, output the lexicographically smallest sequence. (A sequence $X$ is lexicographically smaller than sequence $Y$ if, at the first index $i$ where they differ, $X_i < Y_i$).

## Input
The first line contains two integers $n$ and $m$. The theoretical maximums for these values can be derived from the network's hardware specifications: an 18-bit addressing space (yielding 262,144 total addresses) with 62,144 addresses reserved for diagnostics establishes the upper limit for $n$, while a 1,600,000-byte hazard database where each record occupies exactly 8 bytes establishes the upper limit for $m$. The minimums are 1 for $n$ and 0 for $m$.

Each of the next $m$ lines contains two integers $u$ and $v$ — a proximity hazard between satellite $u$ and satellite $v$.

## Output
If no safe configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being either 1 or 2), representing the phase state assigned to each satellite from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Replaced the bitwise OR condition with a greatest common divisor (GCD) constraint on augmented states. By mapping states 1 and 2 to 4 and 9 respectively, identical states yield a GCD of 4 or 9, while different states yield a GCD of 1. Setting the target product to 1 forces every hazard to connect different states, preserving the exact bipartiteness condition while completely masking the typical graph coloring markers.
</RATIONALE>
<PRESERVED_ANSWER>
The target product of 1 is achieved if and only if every hazard has a resonance factor of 1, which strictly requires $s_u \neq s_v$ for all hazards, perfectly matching the original problem's valid assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in linear time using BFS/DFS.
</PRESERVED_CLASS>
