**Solution Explanation**

For an edge `(u , v)` the interference function is  

```
I(x) = (x – s_u)(x – s_v) = x² – (s_u+s_v)·x + s_u·s_v
```

It is a parabola opening upwards, therefore its global minimum is attained at the
vertex  

```
x* = (s_u + s_v) / 2
```

The requirement *“minimum exactly at x = 1.5”* is equivalent to  

```
(s_u + s_v) / 2 = 1.5   →   s_u + s_v = 3
```

`s_u , s_v` may only be `1` or `2`, thus the only possibilities are  

```
(s_u , s_v) = (1,2) or (2,1)
```

So every listed pair of satellites must receive **different** values.
The whole problem becomes:

*Is the given graph bipartite?*  
If yes, output the lexicographically smallest 2‑coloring with colors `1` and `2`.

--------------------------------------------------------------------

#### 1.   Bipartite check and component handling  

We run a BFS/DFS over all vertices.

* `col[v] = 0/1` – temporary two‑coloring used only for the check.
* While exploring a component we store all its vertices in a list `comp`.

If we ever meet an already coloured neighbour with the same colour,
the graph is not bipartite → answer `NO`.

--------------------------------------------------------------------

#### 2.   Lexicographically smallest coloring  

Inside one connected component we may flip the two colour classes
(`0 ↔ 1`) without breaking bipartiteness.
The whole answer is lexicographically compared vertex by vertex,
therefore the **first** vertex (smallest index) of the component decides
which orientation is better:

* let `first = min(comp)`  
* let `c = col[first]` – its temporary colour (`0` or `1`)

We want `s_first = 1` (the smallest possible value).  
Hence we map

```
temporary colour c → 1
temporary colour 1‑c → 2
```

All other vertices of the component receive their values accordingly.
Isolated vertices are single‑vertex components; the rule above gives them `1`.

Processing components in increasing order of their first vertex guarantees
the global lexicographically smallest sequence.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `NO` iff no assignment exists,
otherwise prints the lexicographically smallest valid assignment.

---

##### Lemma 1  
For an edge `(u,v)` the condition “the quadratic attains its minimum at `x=1.5`”
holds **iff** `s_u ≠ s_v`.

**Proof.**  
From the derivation above the minimum is at `x = (s_u+s_v)/2`.  
Equality with `1.5` gives `s_u+s_v = 3`.  
With `s_u , s_v ∈ {1,2}` this is equivalent to `{s_u,s_v} = {1,2}`,
i.e. the two values are different. ∎



##### Lemma 2  
A labeling `s_1…s_n` satisfying the requirement exists **iff** the graph is
bipartite.

**Proof.**  
*If* the graph is bipartite, colour its vertices with two colours `0,1`
so that adjacent vertices differ. Set `s_i = 1` for colour `0`,
`s_i = 2` for colour `1`. By Lemma&nbsp;1 every edge connects different
values, therefore the requirement holds.

*Only‑if*: suppose a labeling satisfying Lemma&nbsp;1 exists.
Then every edge connects vertices with different values, i.e. with
different labels `1`/`2`. Interpreting `1` as colour `0` and `2` as colour `1`
gives a proper 2‑colouring, hence the graph is bipartite. ∎



##### Lemma 3  
For a fixed connected component, among the two possible assignments
(`colour0→1, colour1→2` or the opposite) the one that gives `s_first = 1`
is lexicographically smaller than the other.

**Proof.**  
Both assignments are identical on all vertices except that they swap the
values `1` and `2`. The first vertex where they differ is exactly `first`,
the smallest index of the component. The assignment with `s_first = 1`
has a smaller value at this position, therefore it is lexicographically
smaller. ∎



##### Lemma 4  
The algorithm outputs the lexicographically smallest valid labeling
(if one exists).

**Proof.**  
Components are processed independently.
Consider the component whose smallest index is `i`. All vertices with index
`< i` belong to earlier components, whose values are already fixed.
By Lemma&nbsp;3 the algorithm chooses, for this component, the orientation
that makes `s_i = 1`. Any other valid labeling must either give the same
value at `i` (identical orientation) or give `s_i = 2`, which is larger.
Thus no other valid overall labeling can be lexicographically smaller.
Proceeding inductively over increasing `i` proves the claim. ∎



##### Lemma 5  
If the algorithm prints `NO` then no valid assignment exists.

**Proof.**  
`NO` is printed only when during BFS an edge connects two vertices with the
same temporary colour. This means the graph contains an odd cycle, i.e.
is not bipartite. By Lemma&nbsp;2 a valid assignment would imply bipartiteness,
contradiction. ∎



##### Theorem  
The program prints `NO` exactly when the required assignment does not exist;
otherwise it prints `YES` followed by the lexicographically smallest
assignment satisfying the condition.

**Proof.**  
*If* the program prints `YES`, the BFS never detected a conflict, therefore
the graph is bipartite. The constructed labeling respects the bipartition,
hence by Lemma&nbsp;1 all edges satisfy the interference rule – a valid
assignment is produced. By Lemma&nbsp;4 it is the lexicographically smallest.

*If* the program prints `NO`, by Lemma&nbsp;5 the graph is not bipartite,
so by Lemma&nbsp;2 no assignment exists.

Thus the output is correct in all cases. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all vertices*: each vertex and edge examined once → `O(n + m)` time.  
*Additional work* (storing component vertices, finding minima) is linear in the
size of the component, overall `O(n + m)`.

Memory consumption: adjacency list `2m` integers, arrays `col`, `ans`,
and a queue → `O(n + m)` ≤ 2·10⁵ + 2·10⁵ ≈ 4·10⁵ integers → well below 256 MB.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    col = [-1] * (n + 1)          # temporary 0/1 colours
    ans = [0] * (n + 1)           # final 1/2 values
    q = deque()

    for start in range(1, n + 1):
        if col[start] != -1:
            continue
        # new component
        comp = []
        col[start] = 0
        q.append(start)
        while q:
            v = q.popleft()
            comp.append(v)
            for to in adj[v]:
                if col[to] == -1:
                    col[to] = col[v] ^ 1
                    q.append(to)
                elif col[to] == col[v]:
                    print("NO")
                    return
        # decide orientation: smallest index gets value 1
        first = min(comp)
        wanted = col[first]          # colour that must become 1
        for v in comp:
            ans[v] = 1 if col[v] == wanted else 2

    # all done
    print("YES")
    print(' '.join(str(ans[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```

to the required input‑output format.
