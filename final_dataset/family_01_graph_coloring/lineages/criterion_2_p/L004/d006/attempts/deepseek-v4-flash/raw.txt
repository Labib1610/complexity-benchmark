We can model this as a graph coloring problem with two colors (1 and 2).  
The condition that the minimum of  
\[
I(x) = (x - s_u)(x - s_v)
\]  
is at \(x = 1.5\) means that \(s_u\) and \(s_v\) must be different.  
So each hazard edge requires its endpoints to have different values.

Thus, the problem reduces to checking if the graph is bipartite, and if so, finding the lexicographically smallest 2-coloring.

We can do this with BFS/DFS, assigning colors greedily starting from node 1, always trying color 1 first.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 0  # 0 means value 1, 1 means value 2
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
