<STATEMENT>
# Orbital Resonance

Time limit: 1 s
Memory limit: 256 MB

A deep space communications network consists of $n$ relay satellites, numbered 1 through $n$. Within this network, there are $m$ known proximity hazards. Each hazard involves a specific pair of satellites that are physically too close to one another.

To stabilize the network, every satellite $i$ must be assigned a tuning parameter $s_i \in \{1, 2\}$. 

This parameter determines the satellite's spatial orientation vector $V_i \in \mathbb{R}^3$:
- If $s_i = 1$, its orientation is $V_i = (1, 2, 2)$.
- If $s_i = 2$, its orientation is $V_i = (2, 1, 2)$.

When a signal passes between two satellites $u$ and $v$ involved in a proximity hazard, it generates an interference vector $W_{u,v}$ defined by the cross product of their orientations:
$W_{u,v} = V_u \times V_v$

The scalar interference of this specific hazard is given by the squared Euclidean norm of the interference vector, $\|W_{u,v}\|^2$.

For the network to be safe, the total scalar interference across all $m$ listed hazards must be exactly $17m$.

Your task is to determine if there is a valid configuration of tuning parameters for all $n$ satellites that achieves this exact total interference. If such a configuration is possible, you must output it. 

Among all valid assignments $s_1, s_2, \dots, s_n$, output the lexicographically smallest sequence. (A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index $i$ where they differ, $A_i < B_i$).

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a proximity hazard between satellite $u$ and satellite $v$.

## Output
If no safe configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being either 1 or 2), representing the tuning parameter assigned to each satellite from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The original problem explicitly gave a local constraint that trivially simplified to $s_u + s_v = 3$, immediately revealing the 2-coloring structure. The rewrite replaces this with a global sum constraint over the squared norms of cross products of 3D vectors. Because the maximum possible squared norm for any individual pair is 17, achieving a total sum of $17m$ forces every local pair to achieve exactly 17. This requires the model to perform a global-to-local extremum deduction before it can recognize the underlying graph coloring structure.
</RATIONALE>
<PRESERVED_ANSWER>
The cross product of the assigned vectors has a squared norm of 17 if $s_u \neq s_v$ and 0 if $s_u = s_v$; thus, a total sum of $17m$ over $m$ hazards is achievable if and only if $s_u \neq s_v$ for all hazards, preserving the exact same valid assignments as the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically first valid 2-coloring of a graph, which is solvable in linear time using Breadth-First Search, keeping it in the polynomial time complexity class (P).
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the cross product order (though the squared norm is invariant) or fail to understand that the global sum is over the $m$ given hazard pairs, but the explicit wording "across all $m$ listed hazards" minimizes this risk.
</RISK>
<METHOD_NAME>Discrete Global Extremum of Vector Cross Products</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the local polynomial constraint with a global sum of squared Euclidean norms of cross products. The vectors are chosen such that the squared norm is 17 if the parameters differ, and 0 if they are the same. By requiring the total sum over m hazards to be exactly 17m, the model must deduce that every single hazard must achieve the maximum possible value of 17, which locally enforces s_u != s_v. This defeats pattern matching by requiring a global-to-local deduction step before the bipartite graph structure is revealed.</METHOD_DESCRIPTION>
