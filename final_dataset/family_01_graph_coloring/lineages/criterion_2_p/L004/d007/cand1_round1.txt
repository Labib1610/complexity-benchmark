<STATEMENT>
# Orbital Resonance

Time limit: 1 s
Memory limit: 256 MB

A deep space communications network consists of $n$ relay satellites, numbered 1 through $n$. Within this network, there are $m$ known proximity hazards. Each hazard involves a specific pair of satellites that are physically too close to one another.

To stabilize the network, every satellite $i$ must be assigned a tuning parameter $s_i \in \{1, 2\}$. 

When a signal passes between two satellites $u$ and $v$ involved in a proximity hazard, it undergoes a 2D phase transformation. If the signal's phase is represented by a geometric vector $(x, y)$, the hazard distorts it into a new transformed vector $(x', y')$ given by the equations:
$x' = (s_u + s_v)x + y$
$y' = 8x + (6 - s_u - s_v)y$

For the network to be safe, the assignments must satisfy a strict interference rule: for every listed hazard pair, this phase transformation must perfectly preserve the area of any 2D region it acts upon (meaning the area of any shape before and after the transformation remains identical, with a scaling factor of exactly 1).

Your task is to determine if there is a valid configuration of tuning parameters for all $n$ satellites that prevents any system-wide failures. If such a configuration is possible, you must output it. 

Among all valid assignments $s_1, s_2, \dots, s_n$, output the lexicographically smallest sequence. (A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index $i$ where they differ, $A_i < B_i$).

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a proximity hazard between satellite $u$ and satellite $v$.

## Output
If no safe configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being either 1 or 2), representing the tuning parameter assigned to each satellite from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
<METHOD_NAME>Area-Preserving Transformation Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit quadratic minimum with a requirement that a 2D linear transformation (whose matrix depends on the tuning parameters) preserves area. This forces the model to compute the determinant and solve for the sum of the parameters, hiding the bipartite constraint behind linear algebra.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
The explicit quadratic minimum `I(x)` allowed models to instantly solve `s_u + s_v = 3`. By replacing it with a 2D area-preservation condition, models must now recognize that area scaling corresponds to the absolute value of the transformation matrix's determinant, compute `(s_u + s_v)(6 - s_u - s_v) - 8`, and solve for it equaling 1. This prevents simple pattern matching on the bipartite structure without executing the linear algebra step.
</RATIONALE>
<PRESERVED_ANSWER>
The determinant of the transformation matrix is `(s_u + s_v)(6 - s_u - s_v) - 8`. For `s_i \in \{1, 2\}`, the sum `s_u + s_v` can be 2, 3, or 4, yielding determinants of 0, 1, and 0 respectively. The area is preserved (determinant magnitude 1) if and only if `s_u + s_v = 3`, which requires `s_u \neq s_v`, identical to the seed problem's logic.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of a graph, keeping it in P and solvable in O(n + m) time using BFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "scaling factor of exactly 1" as requiring the transformation to be the identity matrix, though the clarification "area of any shape... remains identical" strongly points to the determinant.
</RISK>
