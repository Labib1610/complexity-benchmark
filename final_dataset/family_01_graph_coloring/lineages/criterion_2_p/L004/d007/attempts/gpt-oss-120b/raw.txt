**Solution Explanation**

For a satellite `i`

* `s_i = 1`  →  orientation `V_i = (1,2,2)`
* `s_i = 2`  →  orientation `V_i = (2,1,2)`

For a hazard edge `{u,v}` the interference vector is the cross product  

`W_{u,v}=V_u × V_v`.  
Its squared length is

```
‖W_{u,v}‖² = 0   if s_u = s_v
‖W_{u,v}‖² = 17  if s_u ≠ s_v                (1)
```

(The two possible orientations give the vectors `(2,2,-3)` and `(-2,-2,3)`,
both of length √17.)

The required total interference is `17·m`.  
Therefore **every** listed edge must satisfy `s_u ≠ s_v`.  
The problem becomes:

*Is the given graph bipartite?*  
If yes, output the lexicographically smallest 2‑coloring with colors `1` and `2`.

--------------------------------------------------------------------

#### 1.   Bipartite check and component handling
We run a BFS/DFS over all vertices.

* `col[v] = 0` or `1` – provisional colour inside the current component.
* While traversing an edge `(u,v)`  
  * if `col[v]` is unset → set `col[v] = col[u] xor 1`
  * else if `col[v] == col[u]` → odd cycle → **NO**.

All vertices of the current component are stored in a list `comp`.

--------------------------------------------------------------------

#### 2.   Lexicographically smallest colouring
Inside one component we may swap the two colour classes.
Let `x = min(comp)` – the smallest index in this component.

*If `col[x] == 0`* we keep the mapping `0 → 1 , 1 → 2`.  
*Otherwise* we swap: `0 → 2 , 1 → 1`.

Thus the smallest index of the component receives colour `1`.  
Processing components in increasing order of their first vertex guarantees the
overall sequence is lexicographically minimal.

--------------------------------------------------------------------

#### 3.   Algorithm
```
read n,m
build adjacency list
col = [-1]* (n+1)
answer = [0]* (n+1)

for v = 1 .. n:
    if col[v] == -1:
        start BFS from v
        store visited vertices in comp
        if conflict → print NO and exit
        smallest = min(comp)
        if col[smallest] == 0:
            map0, map1 = 1, 2
        else:
            map0, map1 = 2, 1
        for u in comp:
            answer[u] = map0 if col[u]==0 else map1

print YES
print answer[1..n]
```

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise prints the lexicographically smallest valid assignment.

---

##### Lemma 1  
For any edge `{u,v}` the interference contribution equals `17` iff `s_u ≠ s_v`,
and `0` otherwise.

*Proof.* Direct computation of the two possible cross products gives vectors
`(2,2,-3)` and `(-2,-2,3)`, both of squared length `4+4+9 = 17`.  
If the two orientations are equal, the cross product is zero. ∎



##### Lemma 2  
A configuration satisfying the total interference `17·m` exists **iff**
the graph is bipartite.

*Proof.* By Lemma&nbsp;1 each edge contributes `17` exactly when its endpoints have
different `s`. The required total forces *every* edge to contribute `17`,
hence all edges must connect vertices with different `s`. This is precisely a
proper 2‑colouring, i.e. the graph being bipartite. Conversely, a bipartite
graph admits a 2‑colouring, which yields the required total. ∎



##### Lemma 3  
During BFS the algorithm assigns provisional colours `0/1` that are consistent
iff the processed component is bipartite.

*Proof.* BFS colours a tree alternatingly, which is always possible.
If an edge connects two vertices already coloured equally, an odd cycle exists,
so the component is not bipartite. The algorithm detects this and reports
conflict. If no conflict appears, the obtained `col` is a proper 2‑colouring. ∎



##### Lemma 4  
For a bipartite component the algorithm chooses the mapping of provisional
colours to final colours (`1`/`2`) that makes the smallest indexed vertex of the
component receive colour `1`.

*Proof.* Let `x` be the smallest index. If `col[x]=0` we map `0→1`. Otherwise we
swap, mapping `0→2` and `1→1`. In both cases `x` gets colour `1`. ∎



##### Lemma 5  
The whole sequence produced by the algorithm is the lexicographically smallest
among all valid assignments.

*Proof.* Consider the components ordered by their smallest vertex.
By Lemma&nbsp;4 each component’s smallest vertex receives colour `1`.  
All vertices with index smaller than the first vertex of a component belong to
previous components whose colours are already fixed and cannot be changed
without breaking validity (they are independent components).  
Thus at the first position where any valid assignment can differ from ours,
our assignment has colour `1`, the smallest possible value. By induction over
components the whole sequence is lexicographically minimal. ∎



##### Lemma 6  
If the algorithm prints `YES` and a sequence, that sequence is a valid
assignment.

*Proof.* For every component BFS succeeded, so by Lemma&nbsp;3 the provisional
colours form a proper bipartition. The final mapping only swaps the two colour
classes, preserving the property that adjacent vertices have different final
colours. Hence every edge connects vertices with different `s`, and by
Lemma&nbsp;1 each contributes `17`. The total is `17·m`. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no assignment satisfying the statement exists;  
* otherwise `YES` and the lexicographically smallest such assignment.

*Proof.*  
*If* the algorithm outputs `NO`, it found a component with a conflict, i.e.
the component is not bipartite. By Lemma&nbsp;2 no assignment exists.

*If* a valid assignment exists, the graph is bipartite (Lemma&nbsp;2).  
All components are bipartite, so BFS never reports conflict; the algorithm
outputs `YES`. By Lemma&nbsp;6 the produced assignment is valid, and by
Lemma&nbsp;5 it is lexicographically minimal.

Thus the theorem holds. ∎

#### 5.   Complexity Analysis
*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all vertices*: each edge examined twice → `O(n + m)` time.  
*Overall*: `O(n + m)` time, `O(n + m)` memory, well within limits (`n,m ≤ 2·10⁵`).

#### 6.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    col = [-1] * (n + 1)          # provisional 0/1
    ans = [0] * (n + 1)

    for start in range(1, n + 1):
        if col[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        col[start] = 0
        comp = [start]
        ok = True
        while q and ok:
            u = q.popleft()
            cu = col[u]
            for v in adj[u]:
                if col[v] == -1:
                    col[v] = cu ^ 1
                    q.append(v)
                    comp.append(v)
                elif col[v] == cu:
                    ok = False
                    break
        if not ok:
            print("NO")
            return
        # decide mapping to 1/2
        smallest = min(comp)
        if col[smallest] == 0:
            map0, map1 = 1, 2
        else:
            map0, map1 = 2, 1
        for v in comp:
            ans[v] = map0 if col[v] == 0 else map1

    print("YES")
    print(' '.join(str(ans[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
