<STATEMENT>
# Orbital Resonance

Time limit: 1 s
Memory limit: 256 MB

A deep space communications network consists of $n$ relay satellites, numbered 1 through $n$. Within this network, there are $m$ known proximity hazards. Each hazard involves a specific pair of satellites that are physically too close to one another.

To stabilize the network, every satellite $i$ must be assigned a tuning parameter $s_i \in \{1, 2\}$. 

When a signal passes between two satellites $u$ and $v$ involved in a proximity hazard, their tuning parameters interact to produce a scalar resonance factor $R_{u,v}$ for that hazard, defined by the formula:
$R_{u,v} = s_u^2 + s_u s_v + s_v^2$

The overall network resonance is defined as the product of the resonance factors of all $m$ listed hazards. (If there are no hazards, meaning $m=0$, this product is defined to be 1).

For the network to be safe, the overall network resonance must be exactly $7^m$.

Your task is to determine if there is a valid configuration of tuning parameters for all $n$ satellites that achieves this exact overall network resonance. If such a configuration is possible, you must output it. 

Among all valid assignments $s_1, s_2, \dots, s_n$, output the lexicographically smallest sequence. (A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index $i$ where they differ, $A_i < B_i$).

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a proximity hazard between satellite $u$ and satellite $v$.

## Output
If no safe configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being either 1 or 2), representing the tuning parameter assigned to each satellite from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the global sum constraint (which evaluated to an extremum, allowing models to bypass reasoning via max/min logic) with a global product constraint targeting a specific prime power ($7^m$). Since the possible edge contributions are 3, 7, and 12, the target 7 is strictly between the extremes. This forces the model to use unique prime factorization to deduce that every edge must independently contribute exactly 7.
</RATIONALE>
<PRESERVED_ANSWER>
The equation $s_u^2 + s_u s_v + s_v^2$ yields 7 if and only if $s_u \neq s_v$, and since 7 is prime and cannot be formed by products of the other possible values (3 and 12), the target $7^m$ is achievable if and only if $s_u \neq s_v$ for all edges, which is exactly the bipartite condition of the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a lexicographically smallest valid 2-coloring (bipartite partition) of the graph, which is solvable in $O(n+m)$ using BFS, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models could attempt to directly compute $7^m$ and fail due to integer overflow or Time Limit Exceeded, but this is a failure of algorithmic reasoning rather than ambiguity in the text.
</RISK>
