<METHOD_NAME>Modular Wrap of Bounded Sum</METHOD_NAME>
<METHOD_DESCRIPTION>The global condition is rewritten as a modular equation `Sum ≡ m mod (m+1)`. Because the sum is bounded between `m` and `2m`, the only valid solution is exactly `m`, which forces every local contribution to its minimum. This defeats the "maximum possible total" shortcut by hiding the extremum behind a modular equivalence that lacks obvious monotonicity.</METHOD_DESCRIPTION>

<STATEMENT>
# Orbital Resonance

Time limit: 1 s
Memory limit: 256 MB

A deep space communications network consists of $n$ relay satellites, numbered 1 through $n$. Within this network, there are $m$ known proximity hazards. Each hazard involves a specific pair of satellites that are physically too close to one another. 

The network's central registry allocates memory for up to $200,000$ satellite records and up to $200,000$ hazard records. The registry will always contain at least one satellite, though it may contain zero hazards.

To stabilize the network, every satellite $i$ must be assigned a tuning parameter $s_i \in \{1, 2\}$. 

When a signal passes between two satellites $u$ and $v$ involved in a proximity hazard, it generates a scalar interference $W_{u,v}$ based on their tuning parameters, defined by the formula:
$W_{u,v} = 2 - (s_u - s_v)^2$

The total network interference is the sum of the scalar interferences $W_{u,v}$ across all $m$ listed hazards. 

For the network to be safe, the total network interference modulo $(m + 1)$ must be exactly $m$.

Your task is to determine if there is a valid configuration of tuning parameters for all $n$ satellites that achieves this safe state. If such a configuration is possible, you must output it. 

Among all valid assignments $s_1, s_2, \dots, s_n$, output the lexicographically smallest sequence. (A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index $i$ where they differ, $A_i < B_i$).

## Input
The first line contains two integers $n$ and $m$, representing the number of satellites and the number of hazards, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ — indicating a proximity hazard between satellite $u$ and satellite $v$.

## Output
If no safe configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being either 1 or 2), representing the tuning parameter assigned to each satellite from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the global condition from an explicit extremum target (17m) to a modular equivalence `Sum ≡ m mod (m+1)`. Because the sum of the new interference formula is strictly bounded between `m` and `2m`, the only valid solution is exactly `m`, which forces every hazard to evaluate to 1 (different parameters). This forces the model to formally solve the bounded modular equation rather than relying on the "target is the maximum possible total" heuristic shortcut.
</RATIONALE>
<PRESERVED_ANSWER>
The modular equation `Sum ≡ m mod (m+1)` for a sum bounded between `m` and `2m` has the unique solution `Sum = m`, which requires every hazard to have `s_u ≠ s_v`, strictly preserving the exact same valid assignments as the original problem.
</PRESERVED_ANSWER>

The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of a graph, keeping it in P.
</PRESERVED_CLASS>
