**Solution Explanation**

For every satellite we have to choose a value `1` or `2`.
For a hazard edge `{u,v}` the condition  

```
|u³ – v³| = 7
```

must hold.
The cubes are `1³ = 1` and `2³ = 8`, their absolute difference is `7`.
Therefore **the two endpoints of every edge must receive different values**.

So the whole problem is exactly:

*Is the given graph bipartite?*  
If it is, output a 2‑colouring (`1` / `2`) that is lexicographically smallest.

--------------------------------------------------------------------

#### 1.   Bipartite test and component collection  

We run a BFS/DFS over all vertices.

* `col[v] = 0` or `1` – the usual bipartite colour.
* While traversing a component we store all its vertices in a list `comp`.

If we ever see an edge joining two vertices with the same `col`,
the graph is not bipartite → answer `NO`.

--------------------------------------------------------------------

#### 2.   Lexicographically smallest colouring  

Inside one connected component we are free to **swap** the two colours,
because the whole component can be recoloured (`0↔1`) and all edges stay
properly coloured.

To obtain the smallest possible overall sequence `s₁ … sₙ` we act greedily:

*process vertices in increasing order*.
When we first meet a new component, the current vertex `v` is the smallest
index of this component.
We simply decide to give `v` the value `1`.  
That uniquely determines the mapping for the whole component:

```
if col[v] == 0 :   colour 0 → 1 , colour 1 → 2
else               colour 1 → 1 , colour 0 → 2
```

All earlier positions are already fixed, and the current one is the
minimum possible (`1`). Hence the whole assignment is lexicographically
minimal.

Isolated vertices are components of size 1, they also receive `1`.

--------------------------------------------------------------------

#### 3.   Algorithm
```
read n,m
build adjacency list
col[1..n] = -1
ans[1..n] = 0

for v = 1 .. n:
    if col[v] == -1:
        BFS starting from v
        during BFS:
            set col[start] = 0
            collect vertices of this component in list comp
            detect non‑bipartite → print NO and exit
        # component finished, decide mapping
        if col[v] == 0:
            for x in comp: ans[x] = 1 if col[x]==0 else 2
        else:
            for x in comp: ans[x] = 1 if col[x]==1 else 2

print YES
print ans[1] … ans[n]
```

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise prints the lexicographically smallest valid assignment.

---

##### Lemma 1  
If the algorithm prints `NO`, the graph is not bipartite.

**Proof.** `NO` is printed only when during BFS an edge `(a,b)` with
`col[a] == col[b]` is found. This is exactly the definition of a graph
that is not bipartite. ∎



##### Lemma 2  
If the graph is not bipartite, the algorithm prints `NO`.

**Proof.** In a non‑bipartite graph every 2‑colouring attempt must encounter
an odd cycle, i.e. an edge whose endpoints already have the same colour.
Our BFS colours vertices exactly as any 2‑colouring would, therefore it
will encounter such an edge and output `NO`. ∎



##### Lemma 3  
Assume the graph is bipartite. For each connected component the algorithm
outputs a colouring that satisfies all its edges.

**Proof.** Inside a component BFS assigns a proper bipartite colour
`col` (by construction, no conflict occurs). Afterwards we either keep
`col` as is (`0→1,1→2`) or swap the two colours. Both possibilities map
different `col` values to different output values (`1` and `2`), therefore
every edge still connects vertices with different output values. ∎



##### Lemma 4  
For a bipartite graph the assignment produced by the algorithm is
lexicographically minimal among all valid assignments.

**Proof.** Consider the vertices in order `1 … n`.  
When the algorithm first reaches a vertex `v` that belongs to a not yet
processed component `C`, `v` is the smallest index of `C`.  
The algorithm forces `s_v = 1`. Any valid assignment must give either `1`
or `2` to `v`. If it gave `2`, the whole sequence would be lexicographically
larger, because all earlier positions are identical and at position `v`
`2 > 1`.  
If it gives `1`, the rest of component `C` is forced (up to a global swap)
to be exactly the same as the algorithm’s choice, because the two
possible colour‑to‑value mappings are the only ones that keep all edges
properly coloured. Hence any lexicographically minimal valid assignment
must coincide with the algorithm on `v` and consequently on the whole
component. Repeating the argument for every component proves the whole
sequence is minimal. ∎



##### Lemma 5  
If the graph is bipartite, the algorithm outputs a valid assignment.

**Proof.** By Lemma&nbsp;3 each component is coloured correctly, therefore
all edges of the whole graph satisfy the required condition. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no assignment satisfying the problem statement exists;  
* otherwise `YES` and the lexicographically smallest such assignment.

**Proof.**  
*If* the algorithm prints `NO`, by Lemma&nbsp;1 the graph is not bipartite,
hence no assignment exists (edges would need different values).  

*If* the graph is not bipartite, Lemma&nbsp;2 shows the algorithm prints
`NO`.  

If the graph is bipartite, Lemma&nbsp;5 guarantees the algorithm outputs a
valid assignment, and Lemma&nbsp;4 guarantees it is the lexicographically
smallest one. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all vertices*: each vertex and edge is processed once → `O(n + m)`.  
*Overall*:  

- Time `O(n + m)` ≤ `4·10⁵` operations, well inside 1 s.  
- Memory `O(n + m)` ≤ about 3 MB for edges plus arrays, far below 256 MB.

#### 6.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    col = [-1] * (n + 1)          # -1 unvisited, 0/1 bipartite colour
    ans = [0] * (n + 1)

    for start in range(1, n + 1):
        if col[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        col[start] = 0
        comp = [start]
        while q:
            v = q.popleft()
            for to in adj[v]:
                if col[to] == -1:
                    col[to] = col[v] ^ 1
                    q.append(to)
                    comp.append(to)
                elif col[to] == col[v]:
                    print("NO")
                    return
        # decide mapping so that start gets value 1
        if col[start] == 0:
            for v in comp:
                ans[v] = 1 if col[v] == 0 else 2
        else:
            for v in comp:
                ans[v] = 1 if col[v] == 1 else 2

    # all components processed
    print("YES")
    print(' '.join(str(ans[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```

conforms to the required input‑output format.
