# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

The factory operates continuously. There are $n$ workers. The factory features $m$ workstations. For each workstation, exactly two specific workers are trained to use it.

Each worker must be assigned a rotation code, which is either 1 or 2. To ensure proper operation, for every workstation, the two workers trained to use it must be assigned rotation codes that sum to exactly 3.

Determine a valid assignment of rotation codes to all $n$ workers such that every workstation's condition is satisfied, or report if it is impossible.

## Input
The first line contains two integers $n$ and $m$. The number of workers $n$ is at least $1$ and limited by the factory's maximum capacity of $2\cdot 10^5$ personnel. The number of workstations $m$ ranges from a minimum of $0$ up to a maximum of $2\cdot 10^5$ installations.
Each of the next $m$ lines contains two integers $u$ and $v$ — the two workers trained to use that workstation.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit opposite-shift constraint with a mathematically equivalent algebraic constraint (the rotation codes must sum to exactly 3). Since the codes must be 1 or 2, this forces the two workers to have different codes, requiring the model to deduce the bipartite coloring structure rather than pattern-matching the shift assignment. I also applied S07 by expressing the bounds in prose using the exact numeric values to satisfy the H2 constraint.
</RATIONALE>
<PRESERVED_ANSWER>
Every valid assignment still requires each pair of workers sharing a workstation to have different codes (since 1+2=3), so the set of valid assignments and the lexicographically smallest one remains exactly the same.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
