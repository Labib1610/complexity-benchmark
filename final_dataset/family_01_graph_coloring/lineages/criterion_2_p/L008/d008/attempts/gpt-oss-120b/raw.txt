**Solution Explanation**

For every lens `i`

* `d_i` – number of tube ends incident to `i`
* `c_i` – its polarization ( `1` or `2` )
* each incident tube end injects  

  * `3` if the end is an **anode**
  * `8` if the end is a **cathode**

The required total injected into lens `i` is  

```
d_i · (5·c_i – 2) =                     (1)
    3·d_i   when c_i = 1
    8·d_i   when c_i = 2
```

--------------------------------------------------------------------

#### 1.   What does an orientation have to look like ?

For a fixed lens `i` all its incident tube ends must sum to `3·d_i`
or to `8·d_i`.  
That is possible **only if every incident end gives the same amount**,
otherwise the sum would be a mixture of `3`s and `8`s and could never be
exactly `3·d_i` or `8·d_i`.

* `c_i = 1`  → every incident end of `i` is an **anode** (`3`)
* `c_i = 2`  → every incident end of `i` is a **cathode** (`8`)

Consequences  

* an edge always joins a vertex that is an anode on this edge
  with a vertex that is a cathode on this edge
* two vertices with the same `c` can **never** be joined by an edge

So the graph must be **bipartite** :

```
left part   – vertices with c = 1 (always anode)
right part  – vertices with c = 2 (always cathode)
edges are directed from left to right
```

A self‑loop gives one anode *and* one cathode to the same vertex,
producing `11` instead of `6` or `16`.  
Hence **any self‑loop makes the whole instance impossible**.

--------------------------------------------------------------------

#### 2.   Decision problem reduced to bipartiteness

*If the graph has a self‑loop → answer `NO`.*
*Otherwise the instance is solvable **iff** the (loop‑free) graph is bipartite.*

--------------------------------------------------------------------

#### 3.   Lexicographically smallest polarization vector

The graph may consist of many connected components.
Inside one component the two colour classes can be swapped:
`c = 1` can be assigned to the left or to the right side.
All components are independent, therefore the global lexicographically
smallest vector is obtained by the following rule:

*In each component set the vertex with the smallest index to `c = 1`.*

Proof sketch  
The two possible vectors differ exactly on the vertices of this component,
and on each of them the values are opposite (`1` ↔ `2`).
The earliest index belonging to the component decides which whole vector is
lexicographically smaller. Making that vertex `1` is optimal, and components
do not interfere with each other.

Isolated vertices (degree `0`) have no restriction; we set them to `1`
as well – it is the smallest possible value.

--------------------------------------------------------------------

#### 4.   Algorithm
```
read n, m
build adjacency list
if any edge u == v :               # self‑loop
        print NO and exit

color[1…n] = -1                    # -1 = unvisited, 0/1 = bipartite colour
answer[1…n] = 1                    # default 1 for isolated vertices

for every vertex v with colour -1 and degree > 0:
        BFS/DFS from v, colour the component
        if a conflict (neighbour with same colour) appears:
                print NO and exit
        collect all vertices of this component
        let s = smallest index in the component
        flip = color[s]             # 0 → keep, 1 → swap the two sides
        for each vertex x in component:
                answer[x] = (color[x] XOR flip) + 1   # 0→1, 1→2 after optional flip

print YES
print answer[1] … answer[n]
```

`n, m ≤ 2·10⁵`, BFS/DFS is `O(n+m)`.  
Memory consumption `O(n+m)`.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints `YES` and a lexicographically smallest
valid polarization vector exactly when it exists, otherwise prints `NO`.

---

##### Lemma 1  
If a vertex has both an anode and a cathode incident to it, the required
total (1) cannot be satisfied.

**Proof.**  
The total is a sum of `3`s (anodes) and `8`s (cathodes).  
If at least one `3` and at least one `8` appear, the sum is
`3·a + 8·b` with `a,b ≥ 1`.  
Both possibilities in (1) are `3·d` or `8·d`, i.e. all terms are equal.
Impossible. ∎



##### Lemma 2  
A self‑loop makes the instance unsolvable.

**Proof.**  
A loop contributes one anode (`3`) and one cathode (`8`) to the same vertex,
so that vertex has both kinds of contributions.
By Lemma&nbsp;1 the required total cannot be achieved. ∎



##### Lemma 3  
If the loop‑free graph is bipartite, there exists a feasible orientation and
polarization assignment.

**Proof.**  
Take any bipartition `L`/`R`.  
Orient every edge from its endpoint in `L` to the endpoint in `R`.  
All vertices of `L` are anodes on all incident edges → each receives `3·d`
units, therefore `c = 1`.  
All vertices of `R` are cathodes → each receives `8·d`, therefore `c = 2`.
All requirements (1) are met. ∎



##### Lemma 4  
If the loop‑free graph is **not** bipartite, the instance is unsolvable.

**Proof.**  
Assume a feasible orientation exists.
From Lemma&nbsp;1 each vertex is either always anode or always cathode.
Thus every edge connects a vertex of the first kind with a vertex of the
second kind, i.e. the vertices can be divided into two sets with no internal
edges – a bipartition. Contradiction. ∎



##### Lemma 5  
For a connected component without loops the algorithm assigns
`c = 1` to the smallest indexed vertex and produces a feasible polarization.

**Proof.**  
The BFS colours the component properly (otherwise the algorithm would have
already terminated with `NO`).  
Therefore the component is bipartite.
Let `s` be its smallest vertex, `flip = colour[s]`.  
If `flip = 0`, the algorithm keeps the colours; `s` gets colour `0`
→ `c = 1`.  
If `flip = 1`, the algorithm flips the two colour classes; now `s` gets
colour `0` after the xor, again `c = 1`.  
All other vertices obtain the opposite value (`2`) when they belong to the
other colour class.  
Thus the resulting assignment coincides with one side of a bipartition,
hence by Lemma&nbsp;3 it is feasible. ∎



##### Lemma 6  
The vector produced by the algorithm is lexicographically minimal among all
feasible vectors.

**Proof.**  
Consider any component `C`.  
Its two possible feasible assignments are exact opposites (`1`↔`2`) on the
vertices of `C`.  
Let `s` be the smallest index in `C`.  
All indices smaller than `s` belong to other components, whose assignments
are independent of the choice inside `C`.  
Consequently, the first position where two global vectors can differ inside
`C` is `s`.  
Choosing `c_s = 1` (the algorithm’s rule) makes the vector smaller at this
position than the alternative choice `c_s = 2`.  
Since this argument holds for every component, no other feasible vector can
be lexicographically smaller. ∎



##### Lemma 7  
If the algorithm prints `NO`, the instance is unsolvable.

**Proof.**  
`NO` is printed only in two cases  

* a self‑loop exists – by Lemma&nbsp;2 impossible;
* during BFS a colour conflict is found – the component is not bipartite,
  therefore by Lemma&nbsp;4 impossible. ∎



##### Theorem  
The algorithm outputs  

* `NO` **iff** no polarization assignment satisfying the statement exists;
* otherwise `YES` and the lexicographically smallest valid assignment.

**Proof.**  

*If the algorithm prints `NO`* – Lemma&nbsp;7 ⇒ no solution.

*If the algorithm prints `YES`* – all components are bipartite and have no
loops, thus by Lemma&nbsp;5 the produced assignment is feasible.
Lemma&nbsp;6 guarantees its lexicographic minimality.

Conversely, if a solution exists, the graph cannot contain a loop
(Lemma&nbsp;2) and must be bipartite (Lemma&nbsp;4), therefore the algorithm
never aborts with `NO` and reaches the `YES` branch. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Building adjacency list* `O(n + m)` time, `O(n + m)` memory  
*BFS over all components* `O(n + m)` time, `O(n)` extra memory for colour array  
*Final output* `O(n)` time  

Total: **`O(n + m)`** time, **`O(n + m)`** memory.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        if u == v:                     # self‑loop → impossible
            print("NO")
            return
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * n          # -1 = unvisited, 0/1 = bipartite colour
    answer = [1] * n           # default 1 (isolated vertices stay 1)

    for start in range(n):
        if colour[start] != -1 or not adj[start]:
            continue            # already processed or isolated
        q = deque([start])
        colour[start] = 0
        component = [start]

        while q:
            v = q.popleft()
            cv = colour[v]
            for nb in adj[v]:
                if colour[nb] == -1:
                    colour[nb] = cv ^ 1
                    q.append(nb)
                    component.append(nb)
                elif colour[nb] == cv:
                    print("NO")
                    return

        # make the smallest index of the component have c = 1
        min_vertex = min(component)
        flip = colour[min_vertex]          # 0 → keep, 1 → swap sides
        for v in component:
            answer[v] = (colour[v] ^ flip) + 1   # 0→1, 1→2 after possible flip

    print("YES")
    sys.stdout.write(' '.join(map(str, answer)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
