# Problem B — Anti-Glare Arrays

Time limit: 1 s
Memory limit: 256 MB

An optical instrument contains $n$ crystal lenses. Each lens must be assigned a polarization mode, which must be an integer value of either $1$ or $2$.

The instrument is equipped with $m$ calibration tubes, each routing data between a pair of lenses. The instrument's diagnostic system validates the configuration by checking the local resonance at each lens.

First, every calibration tube must be assigned a single direction of data flow, designating one of its endpoints as the primary and the other as the secondary. A tube delivers a resonance weight of $8$ to the lens at its primary endpoint, and a resonance weight of $3$ to the lens at its secondary endpoint. (A self-loop thus provides one primary and one secondary endpoint to the same lens, contributing a total resonance weight of $11$).

For each lens $i$, let $d_i$ be the total number of tube endpoints connected to it. (If a tube connects a lens to itself, it provides two endpoints to that lens). The total resonance weight accumulated at lens $i$ is the sum of the weights delivered to it by all its connected tube endpoints.

To successfully filter out glare, there must exist some valid assignment of directions to all $m$ tubes such that for every lens $i$ (from $1$ to $n$), its total accumulated resonance weight is exactly:
$d_i \cdot (5 c_i - 2)$
where $c_i$ is the assigned polarization mode of lens $i$.

Determine an assignment of polarization modes for all $n$ lenses that makes such a resonance configuration possible, or report that the hardware configuration is flawed.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the two lenses connected by that calibration tube.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES`, followed by a second line with $n$ integers $c_1 \dots c_n$ (each in $\{1,2\}$). This sequence must represent the valid calibration assignment. If multiple valid assignments exist, output the lexicographically smallest sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The previous solutions relied on pattern-matching the bounds `0` and `d_i` to immediately deduce that every vertex must be a pure source or pure sink, skipping the deduction step. By changing the edge contributions to asymmetric weights (8 and 3) and updating the target formula to `d_i * (5 c_i - 2)`, models are forced to algebraically solve `8k + 3(d_i - k) = d_i(5c_i - 2)` to rediscover that $k$ must be either $0$ or $d_i$, which restores the necessity of genuine structural reasoning.
</RATIONALE>
<PRESERVED_ANSWER>
Solving the new balance equation `8k + 3(d_i - k) = d_i(5c_i - 2)` yields exactly `k = d_i(c_i - 1)`, which is mathematically identical to the original requirement that a vertex has either all outgoing or all incoming edges depending on its mode, so the set of valid configurations and the lexicographically smallest sequence remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still reduces to checking whether the graph is bipartite and assigning alternating modes to connected components, which remains solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
