# Problem B — Anti-Glare Arrays

Time limit: 1 s
Memory limit: 256 MB

An optical instrument contains $n$ crystal lenses. Each lens $i$ must be assigned a polarization mode $c_i$, which must be an integer value of either $1$ or $2$.

The instrument is equipped with $m$ calibration tubes, each routing data between a pair of lenses. The instrument's diagnostic system validates the configuration by checking the local flow metrics at each lens.

First, every calibration tube must be configured by assigning it a single continuous flow direction. This designates exactly one of the two lenses it connects as the 'source' for that tube, and the other as the 'sink' for that tube.

For each lens $i$, let $d_i$ be the total number of tube connections to it. (If a tube connects a lens to itself, it provides two connections to that lens: one as a source and one as a sink). Let $S_i$ be the total number of times lens $i$ acts as a source, and $K_i$ be the total number of times it acts as a sink. Note that $S_i + K_i = d_i$.

To successfully filter out glare, there must exist some valid configuration of flow directions for all $m$ tubes such that for every lens $i$ (from $1$ to $n$), the flow metrics satisfy the following two conditions simultaneously:
1. $S_i^3 + K_i^3 = d_i^3$
2. The value $S_i - d_i(2 - c_i)$ is an integer multiple of $(d_i + 1)$

Determine an assignment of polarization modes for all $n$ lenses that makes such a configuration possible, or report that the hardware configuration is flawed.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the two lenses connected by that calibration tube.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES`, followed by a second line with $n$ integers $c_1 \dots c_n$ (each in $\{1,2\}$). This sequence must represent the valid calibration assignment. If multiple valid assignments exist, output the lexicographically smallest sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the linear sum of endpoint constants (3 and 8) with a non-linear algebraic system ($S_i^3 + K_i^3 = d_i^3$) and a modulo condition on the flow counts. This forces the model to genuinely solve the algebraic system to deduce that all incident edges must have uniform direction, rather than relying on the heuristic that maximum/minimum possible sums imply uniformity.
</RATIONALE>
<PRESERVED_ANSWER>
The non-linear system algebraically forces every vertex to be a pure source or pure sink, and the modulo condition perfectly maps pure sources to mode 1 and pure sinks to mode 2, which is logically identical to the original bipartite 2-coloring requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) on the connected components of the graph, which is solvable in O(N+M) time using BFS or DFS, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might struggle with the phrase "integer multiple of (d_i + 1)" if they fail to consider 0 as a valid multiple, though 0 is mathematically a multiple of every integer.
</RISK>
