<STATEMENT>
# Problem B — Anti-Glare Arrays

Time limit: 1 s
Memory limit: 256 MB

An optical instrument contains $n$ crystal lenses. Each lens must be assigned a polarization mode, which must be an integer value of either $1$ or $2$.

The instrument is equipped with $m$ calibration tubes, each routing data between a pair of lenses. The instrument's diagnostic system validates the configuration by checking the local resonance at each tube.

For a calibration tube connecting lens $u$ and lens $v$, its baseline frequency is calculated as the least common multiple ($\text{lcm}$) of the focal values of lens $u$ and lens $v$. The focal value of a lens $i$ is defined as $3 c_i + 1$, where $c_i$ is its assigned polarization mode.

To successfully filter out glare, there must exist some valid assignment of polarization modes to all $n$ lenses such that for every calibration tube, its baseline frequency is exactly $28$.

Determine an assignment of polarization modes for all $n$ lenses that makes such a configuration possible, or report that the hardware configuration is flawed.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the two lenses connected by that calibration tube.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES`, followed by a second line with $n$ integers $c_1 \dots c_n$ (each in $\{1,2\}$). This sequence must represent the valid assignment. If multiple valid assignments exist, output the lexicographically smallest sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<METHOD_NAME>
Edge-Centric Algebraic Camouflage
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaced the vertex-centric resonance sum (which models easily matched to the min/max possible degree sum bounds to deduce bipartiteness) with an edge-centric least common multiple condition on mapped values. Models can no longer rely on degree-sum heuristics and must independently evaluate the LCM condition to discover it enforces mutual exclusion.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<RATIONALE>
The seed problem used a vertex-centric sum that equaled the absolute minimum or maximum possible sum of incident endpoints, allowing models to shortcut the logic by realizing all endpoints must uniformly be anodes or cathodes. I removed this affordance by replacing it with a direct edge-centric condition: the LCM of $3c+1$ for the endpoints must be 28. This forces the model to evaluate the condition manually (LCM of 4 and 7 is 28, while LCM of 4 and 4 is 4) to deduce that adjacent vertices must have different states, breaking the pattern-matching shortcut.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $\text{lcm}(3c_u+1, 3c_v+1) = 28$ for $c_i \in \{1, 2\}$ is mathematically satisfied if and only if one lens is mode 1 and the other is mode 2, perfectly preserving the exact bipartite coloring constraints (including failing on self-loops) of the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains exactly Graph 2-Coloring (Bipartiteness Checking), which is solvable in O(n+m) time using BFS or DFS, keeping it firmly in P.
</PRESERVED_CLASS>

none
