We can model this as a graph coloring problem.  

Each lens has a polarization mode `1` or `2`, and the focal value is `3*c + 1`, so:

- If `c = 1`, focal value = `4`
- If `c = 2`, focal value = `7`

The lcm of two focal values must be `28`.  
`lcm(4, 7) = 28`, so any edge must connect a `1` and a `2`.  
Thus, the graph must be bipartite, with `1` on one side and `2` on the other.

We need the lexicographically smallest assignment, so we try to assign `1` as much as possible, using BFS/DFS with backtracking if needed.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 0  # 0 means mode 1, 1 means mode 2
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

# Now we have a valid bipartite coloring, but we want lexicographically smallest.
# We can flip entire components if it makes earlier positions smaller.
# Since each component is independent, we can choose orientation per component.

visited = [False] * n
for i in range(n):
    if not visited[i]:
        # BFS to collect component
        comp = []
        q = deque([i])
        visited[i] = True
        while q:
            u = q.popleft()
            comp.append(u)
            for v in adj[u]:
                if not visited[v]:
                    visited[v] = True
                    q.append(v)
        # Check if flipping this component gives lexicographically smaller
        # We compare current vs flipped for the smallest index in comp
        # If flipped is smaller at the first differing position, flip.
        flip = False
        for u in comp:
            if color[u] == 0:
                # current has 1, flipped has 2
                if not flip:
                    # flipped would be larger here, so don't flip
                    break
            else:
                # current has 2, flipped has 1
                flip = True
                break
        if flip:
            for u in comp:
                color[u] = 1 - color[u]

print("YES")
print(' '.join(str(c + 1) for c in color))
```
