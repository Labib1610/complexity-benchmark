**Solution Explanation**

For an edge `{u,v}` let the assigned polarizations be `c_u , c_v ∈ {1,2}`.
The contribution of this edge to the total stability is  

```
3·c_u + 3·c_v – 2·c_u·c_v
```

All four possibilities:

| c_u | c_v | contribution |
|-----|-----|--------------|
| 1   | 1   | 4 |
| 1   | 2   | 5 |
| 2   | 1   | 5 |
| 2   | 2   | 4 |

The required total is `5·m`.  
Therefore **every edge must contribute 5**, i.e. its ends must have *different*
polarizations.  
So we need a 2‑coloring of the given graph – the graph must be *bipartite*.
If it is not bipartite the answer is `NO`.

When the graph is bipartite many colorings exist (swap the two sides of any
connected component).  
We have to output the **lexicographically smallest** sequence
`c_1 … c_n` (`1 < 2`).  
Consider one connected component.  
Let `S0` be the vertices with parity `0` in a BFS/DFS, `S1` the vertices with
parity `1`.  
If we decide to give color `1` to `S0` and `2` to `S1` we obtain one valid
assignment, swapping the two sides gives the only other one.

The lexicographically smallest global assignment is obtained greedily:

*process vertices in increasing order*.
When we meet the first vertex of a component we are free to choose the
orientation of this component.  
Choosing the orientation that gives this vertex color `1` makes the whole
sequence as small as possible, because all earlier positions are already fixed
and later positions cannot influence them.

Thus for each component we:

1. BFS, store all its vertices and their parity (`0/1`). Detect a conflict → `NO`.
2. Let `first = min(component_vertices)`.  
   If `parity[first] == 0` we set `parity 0 → color 1`, else `parity 1 → color 1`.
3. Fill the answer array accordingly.

If there are no edges (`m = 0`) the graph is trivially bipartite; the smallest
sequence is all `1`s.

The algorithm runs in `O(n + m)` time and `O(n + m)` memory.

---

#### Correctness Proof  

We prove that the algorithm outputs `YES` and a lexicographically smallest
valid assignment iff such an assignment exists.

---

##### Lemma 1  
For any edge `{u,v}` the contribution equals `5` **iff** `c_u ≠ c_v`.

*Proof.* Direct computation of the four cases shown in the table above. ∎



##### Lemma 2  
A polarization assignment yields total stability `5·m` **iff** it is a proper
2‑coloring of the graph (adjacent vertices have different colors).

*Proof.* By Lemma&nbsp;1 each edge contributes `5` exactly when its ends differ,
otherwise `4`. The total is `5·m` exactly when every edge contributes `5`,
i.e. when all edges have different‑colored ends. ∎



##### Lemma 3  
If the algorithm reports `NO` then no valid assignment exists.

*Proof.* The algorithm reports `NO` only when during BFS a vertex is reached
with two different required parities, i.e. the graph contains an odd cycle.
Such a graph is not bipartite, therefore by Lemma&nbsp;2 no assignment can make
all edges have different colors, hence no assignment reaches total `5·m`. ∎



##### Lemma 4  
If the algorithm finishes without conflict, the produced sequence is a
valid assignment.

*Proof.* For each component the BFS assigns a parity `0/1` to every vertex,
and edges always connect vertices of opposite parity (property of BFS on a
bipartite graph). The algorithm then maps the two parity classes to the two
colors `1` and `2`. Consequently every edge connects vertices of different
colors, and by Lemma&nbsp;2 the total stability equals `5·m`. ∎



##### Lemma 5  
For a fixed component, among the two possible colorings the algorithm chooses
the one that is lexicographically smallest for the whole sequence.

*Proof.* Let `first` be the smallest index in the component.
The algorithm gives `first` color `1`. Any other valid coloring of this
component must give `first` color `2` (the opposite orientation). Since the
global sequence is compared lexicographically from left to right, any sequence
that gives `first` color `2` is larger, regardless of later positions. ∎



##### Lemma 6  
The whole sequence output by the algorithm is the lexicographically smallest
valid assignment.

*Proof.* Process vertices `1 … n`.  
When the first vertex of a component is encountered, all earlier vertices belong
to already processed components and are already fixed to the smallest possible
values (by induction on the processing order). By Lemma&nbsp;5 the algorithm
chooses the smallest possible value for this first vertex, and this choice does
not affect earlier positions. Hence after handling all components the resulting
sequence is minimal among all valid assignments. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no assignment with total stability `5·m` exists;  
* otherwise `YES` and the lexicographically smallest assignment achieving that
  total.

*Proof.*  
- If the algorithm outputs `NO`, by Lemma&nbsp;3 no assignment exists.  
- If it outputs an assignment, Lemma&nbsp;4 guarantees it is valid, and
  Lemma&nbsp;6 guarantees it is the lexicographically smallest among all
  valid ones.  
Conversely, if a valid assignment exists, the graph is bipartite, so BFS never
finds a conflict and the algorithm reaches the output step. ∎



---

#### Complexity Analysis  

*Building adjacency lists*: `O(n + m)` memory.  
*BFS over all components*: each vertex and edge is processed once → `O(n + m)`
time.  
*Additional work* (finding minima, filling answer) is linear in the component
size, overall `O(n)`.  

Total: **Time `O(n + m)`, Memory `O(n + m)`**, well within limits.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    parity = [-1] * n          # -1 unvisited, else 0/1
    answer = [0] * n
    for start in range(n):
        if parity[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        parity[start] = 0
        comp = [start]
        ok = True
        while q:
            v = q.popleft()
            for to in adj[v]:
                if parity[to] == -1:
                    parity[to] = parity[v] ^ 1
                    q.append(to)
                    comp.append(to)
                elif parity[to] == parity[v]:
                    print("NO")
                    return
        # choose orientation to make smallest index get color 1
        first = min(comp)
        if parity[first] == 0:
            # parity 0 -> color 1, parity 1 -> color 2
            for v in comp:
                answer[v] = 1 if parity[v] == 0 else 2
        else:
            # parity 1 -> color 1
            for v in comp:
                answer[v] = 1 if parity[v] == 1 else 2

    # all components processed, graph is bipartite
    print("YES")
    print(' '.join(map(str, answer)))

if __name__ == "__main__":
    solve()
```
