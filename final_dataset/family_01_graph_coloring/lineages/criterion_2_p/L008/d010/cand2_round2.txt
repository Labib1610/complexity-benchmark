# Problem B — Anti-Glare Arrays

Time limit: 1 s
Memory limit: 256 MB

An optical instrument contains $n$ crystal lenses. Each lens must be assigned a polarization mode, which must be an integer value of either $1$ or $2$.

The instrument is equipped with $m$ calibration tubes, each routing data between a pair of lenses. The instrument's diagnostic system validates the configuration by calculating the total optical tension.

For a calibration tube connecting lens $u$ and lens $v$, its local tension is defined as the square of the difference between the polarization modes of lens $u$ and lens $v$. The total optical tension of the instrument is the sum of the local tensions across all $m$ calibration tubes.

To successfully filter out glare, there must exist some valid assignment of polarization modes to all $n$ lenses such that the total optical tension is exactly $m$.

Determine an assignment of polarization modes for all $n$ lenses that satisfies this condition, or report that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the two lenses connected by that calibration tube.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES`, followed by a second line with $n$ integers $c_1 \dots c_n$ (each in $\{1,2\}$). This sequence must represent the valid assignment. If multiple valid assignments exist, output the lexicographically smallest sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

I changed the edge validation condition from a local LCM check to a global sum of squared differences that must equal $m$. This forces the model to deduce that since the maximum possible squared difference for values in $\{1, 2\}$ is 1, a sum of $m$ terms can only equal $m$ if every term is exactly 1, meaning every connected pair must have different values.
</RATIONALE>
<PRESERVED_ANSWER>
Since each variable is restricted to 1 or 2, the squared difference between any pair is at most 1, so the global sum over $m$ pairs equals $m$ if and only if every pair has a squared difference of 1, which is mathematically identical to the original requirement that every connected pair must have different values.
</PRESERVED_ANSWER>
