<STATEMENT>
# Problem B — Anti-Glare Arrays

Time limit: 1 s
Memory limit: 256 MB

An optical instrument contains $n$ crystal lenses. Each lens must be assigned a polarization axis, which must be an integer value of either $1$ or $2$.

The instrument is equipped with $m$ calibration tubes, each routing light directly between a pair of lenses. The instrument's diagnostic system validates the configuration by checking the local neighborhood of each lens. 

For each lens $i$, the system compiles a list of all tube connections to it. Specifically, each of the $m$ tubes connecting lenses $u$ and $v$ provides one connection to $u$ (originating from $v$) and one connection to $v$ (originating from $u$). If a tube connects a lens to itself, it provides two connections to that lens (both originating from itself). Let $d_i$ be the total number of connections to lens $i$. 

For each connection to lens $i$ originating from lens $j$, the system determines its *interference rating* based on the assigned axes of the two lenses:
- The rating is $2$ if both lenses are assigned axis $1$.
- The rating is $4$ if both lenses are assigned axis $2$.
- The rating is $3$ if one lens is assigned axis $1$ and the other is assigned axis $2$.

To successfully filter out glare, every lens $i$ with at least one connection ($d_i > 0$) must achieve an arithmetic mean of exactly $3$ across all of its $d_i$ interference ratings. Lenses with no connections ($d_i = 0$) automatically pass the diagnostic.

Determine an assignment of polarization axes for all $n$ lenses that satisfies this requirement, or report that the hardware configuration is flawed.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the two lenses connected by that calibration tube.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES`, followed by a second line with $n$ integers $c_1 \dots c_n$ (each in $\{1,2\}$). This sequence must represent the valid calibration assignment. If multiple valid assignments exist, output the lexicographically smallest sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the algebraic equation with a tabular definition of "interference ratings" and required their arithmetic mean to be exactly 3. To average 3, a lens with axis 1 (which only generates ratings of 2 or 3) must only connect to lenses yielding 3, meaning axis 2. This forces the model to deduce the local extremum bounds of the table to discover the 2-coloring reduction, rather than algebraically simplifying an equation.
</RATIONALE>
<PRESERVED_ANSWER>
The tabular interference ratings are exactly equivalent to $c_i + c_j$, and requiring their arithmetic mean to be 3 is algebraically identical to $S_i + d_i c_i = 3 d_i$, preserving all valid assignments.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
