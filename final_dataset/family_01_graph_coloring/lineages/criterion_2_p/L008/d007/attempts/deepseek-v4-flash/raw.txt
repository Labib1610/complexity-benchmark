We need to determine if we can assign each lens a mode (1 or 2) such that there exists an orientation of edges where each vertex’s in-degree equals  
`d_i * (c_i - 1)`.  

If `c_i = 1`, required in-degree = 0.  
If `c_i = 2`, required in-degree = `d_i`.  

So:

- Mode 1 means all incident edges must be outgoing.
- Mode 2 means all incident edges must be incoming.

This means:

- If a vertex has mode 1, all its neighbors must have mode 2 (because edges are directed from mode 1 to mode 2).
- If a vertex has mode 2, all its neighbors must have mode 1.

Thus, the graph must be bipartite, with the two parts being mode 1 and mode 2.  
Self-loops are impossible because a vertex would need to be both source and target for the same edge, which would require both modes simultaneously — so if any self-loop exists, answer is NO.

We need the lexicographically smallest assignment.  
We can do BFS/DFS coloring, trying to assign mode 1 to the smallest index vertex first, and propagate.

Let’s implement:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
has_self_loop = False

for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    if u == v:
        has_self_loop = True
    adj[u].append(v)
    adj[v].append(u)

if has_self_loop:
    print("NO")
    sys.exit()

color = [-1] * n  # 0 = mode 1, 1 = mode 2

for start in range(n):
    if color[start] != -1:
        continue
    # try to assign mode 1 (0) to start
    color[start] = 0
    q = deque([start])
    ok = True
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                ok = False
                break
        if not ok:
            break
    if not ok:
        print("NO")
        sys.exit()

# If we reach here, graph is bipartite.
# But we need lexicographically smallest: we may need to flip components.
# We'll try to make as many early vertices as possible mode 1.
# We can do BFS from each uncolored vertex, but we already colored.
# To get lexicographically smallest, we can re-run with a greedy BFS:
# For each vertex in order, if uncolored, set to 0 and BFS.

color = [-1] * n
for i in range(n):
    if color[i] != -1:
        continue
    color[i] = 0
    q = deque([i])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)

# Output
print("YES")
print(' '.join(str(c + 1) for c in color))
```
