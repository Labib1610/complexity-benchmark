**Solution Explanation**

For a lens `i`

* `d_i` – number of incident edge‑endpoints  
* `c_i` – its polarization, either `1` or `2`

The required indegree of `i` is  

```
indeg(i) = d_i · (c_i – 1)
```

* `c_i = 1` → `indeg(i) = 0` – every incident edge must leave `i`
* `c_i = 2` → `indeg(i) = d_i` – every incident edge must enter `i`

A self‑loop contributes **one** incoming and **one** outgoing endpoint
independently of its direction, therefore a vertex incident to a self‑loop
can never have indegree `0` nor indegree `d_i`.  
Consequences

* if any self‑loop exists → answer `NO`
* otherwise each vertex is either **source of all its edges** (`c=1`) or
  **sink of all its edges** (`c=2`)

Hence every edge must be oriented from a source vertex to a sink vertex.
If we colour every vertex

```
colour = 0  → source (c = 1)
colour = 1  → sink   (c = 2)
```

the condition is exactly that the graph is **bipartite**.
If the graph is bipartite we can orient every edge from colour 0 to colour 1,
and the required `c_i` are obtained.

--------------------------------------------------------------------

#### Lexicographically smallest assignment
In a bipartite connected component we may swap the two colours.
To obtain the smallest possible sequence `c_1 … c_n` we do the following
for each component:

* let `v` be the smallest vertex index inside the component
* force `c_v = 1` (i.e. make `v` a source)
* the rest of the component follows uniquely.

Thus the whole sequence is lexicographically minimal.

--------------------------------------------------------------------

#### Algorithm
```
read n, m
build adjacency list, detect self‑loops
if a self‑loop exists: print NO and exit

colour[1…n] = -1   // -1 = unvisited, 0/1 = bipartite colour
answer[1…n] = 0

for each vertex i = 1 … n
    if colour[i] == -1
        BFS/DFS from i, colour the component (0/1)
        if a conflict appears → print NO and exit
        collect all vertices of this component in list comp
        v_min = minimum vertex in comp
        // decide which colour becomes 1
        if colour[v_min] == 0:
            map0 = 1 , map1 = 2
        else:
            map0 = 2 , map1 = 1
        for each vertex x in comp
            answer[x] = map0 if colour[x]==0 else map1

print YES
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a lexicographically smallest
valid assignment iff such an assignment exists.

---

##### Lemma 1  
If the input contains a self‑loop, no assignment of directions and
polarizations satisfies the requirement.

**Proof.**  
A self‑loop contributes exactly one incoming and one outgoing endpoint to its
vertex, no matter how it is oriented.  
For `c = 1` we need indegree `0`; for `c = 2` we need indegree `d_i` (which
counts the two endpoints of the loop). Neither `0` nor `2` equals `1`. ∎



##### Lemma 2  
Assume the graph has no self‑loops.
A polarization assignment `c_i ∈ {1,2}` is feasible **iff**
the underlying undirected graph is bipartite.

**Proof.**  

*If* the graph is bipartite, colour it with colours `0,1`.  
Direct every edge from colour 0 to colour 1.  
All vertices of colour 0 have indegree `0` → set `c=1`.  
All vertices of colour 1 have indegree equal to their degree → set `c=2`.  
Thus a feasible assignment exists.

*Only‑if*: suppose a feasible assignment exists.
Vertices with `c=1` have indegree `0`, therefore every incident edge is
oriented **outwards**; vertices with `c=2` have all incident edges oriented
**inwards**. Consequently every edge is oriented from a `c=1` vertex to a
`c=2` vertex, i.e. the vertex set can be partitioned into the two groups,
which is exactly a bipartition. ∎



##### Lemma 3  
For a bipartite connected component, fixing the colour of its smallest
indexed vertex uniquely determines a feasible polarization assignment for the
whole component.

**Proof.**  
The bipartition of the component is unique up to swapping the two colour
classes. Once we decide which class receives `c=1` (source) and which receives
`c=2` (sink), every vertex’s polarization is forced. ∎



##### Lemma 4  
The algorithm outputs a feasible assignment whenever the graph is bipartite
(and has no self‑loops).

**Proof.**  
The BFS colours each component consistently; a conflict would mean the
component is not bipartite, in which case the algorithm aborts with `NO`.  
If no conflict occurs, the component is bipartite.  
By Lemma&nbsp;3 the algorithm chooses the colour of the smallest vertex to be
`c=1` and assigns the other colour `c=2`. This respects the orientation
from colour 0 to colour 1, therefore satisfies Lemma&nbsp;2. ∎



##### Lemma 5  
The assignment produced by the algorithm is lexicographically smallest among
all feasible assignments.

**Proof.**  
Consider the first index `i` where two feasible assignments differ.
`i` belongs to some component `C`.  
Both assignments must respect the bipartition of `C`; they can only differ by
which colour class is mapped to `c=1`.  
Our algorithm forces the smallest vertex of `C` (which is `i` because all
smaller indices are equal) to have `c=1`. Any other feasible assignment would
give `c_i = 2`, which is larger. Hence no other feasible assignment can be
lexicographically smaller. ∎



##### Theorem  
The program prints  

* `NO` iff no feasible polarization assignment exists,  
* otherwise `YES` followed by the lexicographically smallest feasible
  assignment.

**Proof.**  

*If* the program prints `NO`:
  - either a self‑loop was found → by Lemma 1 impossible,
  - or a colour conflict was detected → the graph is not bipartite,
    and by Lemma 2 no assignment exists.

*If* a feasible assignment exists:
  - there is no self‑loop (Lemma 1) and the graph is bipartite (Lemma 2),
    so the program never aborts early.
  - By Lemma 4 it outputs a feasible assignment.
  - By Lemma 5 this assignment is lexicographically minimal.

Thus the theorem holds. ∎

#### Complexity Analysis
*Building adjacency list*: `O(n + m)`  
*BFS over all vertices*: each edge examined once → `O(n + m)`  
*Memory*: adjacency list `O(n + m)`, colour & answer arrays `O(n)`.

Both limits satisfy the constraints (`n, m ≤ 2·10⁵`).

--------------------------------------------------------------------

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        if u == v:          # self‑loop -> impossible
            print("NO")
            return
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 unvisited, 0/1 bipartite colour
    ans = [0] * (n + 1)

    from collections import deque

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        while q:
            v = q.popleft()
            for to in adj[v]:
                if colour[to] == -1:
                    colour[to] = colour[v] ^ 1
                    q.append(to)
                    comp.append(to)
                elif colour[to] == colour[v]:
                    print("NO")
                    return
        # decide mapping to 1/2
        v_min = min(comp)
        if colour[v_min] == 0:
            map0, map1 = 1, 2
        else:
            map0, map1 = 2, 1
        for v in comp:
            ans[v] = map0 if colour[v] == 0 else map1

    print("YES")
    print(' '.join(str(ans[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
