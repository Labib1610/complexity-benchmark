# Problem B — Anti-Glare Arrays

Time limit: 1 s   Memory limit: 256 MB

An optical instrument contains $n$ ($n \ge 1$) crystal lenses. Each lens must be assigned a polarization axis, which must be an integer value of either $1$ or $2$. 

The instrument's control unit limits the architecture to a maximum of $200,000$ lenses, and its routing chassis can house up to $200,000$ calibration tubes. Currently, there are $m$ ($m \ge 0$) calibration tubes installed, each routing light directly between a pair of lenses.

The instrument's diagnostic system validates the configuration by computing a global calibration product. For each tube connecting a pair of lenses, let $x$ and $y$ be the polarization axes assigned to those two lenses. The system calculates an interference factor for this tube equal to $x^2 + y^2 - x \cdot y$. It then multiplies these interference factors together across all $m$ tubes. 

To successfully filter out glare, this final calibration product must evaluate to exactly $3^m$.

Determine an assignment of polarization axes for all $n$ lenses that satisfies this requirement, or report that the hardware configuration is flawed.

## Input
The first line contains two integers $n$ and $m$ — the number of lenses and the number of calibration tubes. (The values are guaranteed to respect the hardware limits described above).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — indicating a calibration tube connecting lens $u$ and lens $v$.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES`, followed by a second line with $n$ integers $c_1 \dots c_n$ (each in $\{1,2\}$). This sequence must represent the valid calibration assignment. If multiple valid assignments exist, output the lexicographically smallest sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I changed the edge validation function from $(x+y)$ to $(x^2+y^2-xy)$. The original sum evaluated to 2, 3, or 4, making it trivial for models to deduce that a global product of $3^m$ requires every sum to be 3. The new polynomial evaluates to 1, 3, or 4. This forces the model to mathematically prove that the target product can only be achieved if every single edge evaluates to 3 (since 4 introduces a prime factor of 2), requiring a deeper algebraic reasoning step before the bipartite graph structure can be recognized.
</RATIONALE>
<PRESERVED_ANSWER>
For $x, y \in \{1, 2\}$, the expression $x^2+y^2-xy$ evaluates to 3 if $x \neq y$, 1 if $x=y=1$, and 4 if $x=y=2$; since 4 is not a power of 3, a product of $3^m$ over $m$ terms is uniquely achieved when every term is 3, which is mathematically identical to requiring $x \neq y$ for all connected lenses, preserving all valid assignments exactly.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core constraint still strictly enforces that adjacent nodes must have different values from the set {1, 2}, maintaining its identity as 2-coloring (bipartiteness testing) solvable in $O(n+m)$ time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the phrasing if they read too quickly, but explicitly defining the variables $x$ and $y$ and providing the algebraic formula $x^2 + y^2 - x \cdot y$ removes any genuine ambiguity.
</RISK>
