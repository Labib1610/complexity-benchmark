# Problem B — Anti-Glare Arrays

Time limit: 1 s   Memory limit: 256 MB

An optical instrument contains $n$ crystal lenses. Each lens must be assigned a polarization axis, which must be an integer value of either 1 or 2.

The instrument is equipped with $m$ calibration tubes. Each tube routes light directly from one lens to another. The instrument's diagnostic system validates the configuration by testing each tube individually. 

For each tube routing light from a lens with assigned axis $x$ to a lens with assigned axis $y$, the system computes the interference metric $x^2 + 3y^2$. The tube successfully filters glare if and only if this computed metric is a prime number. 

The instrument is fully calibrated if and only if every one of its $m$ tubes successfully filters glare.

Determine an assignment of polarization axes for all $n$ lenses that satisfies this requirement, or report that the hardware configuration is flawed.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — indicating a calibration tube routing light from lens $u$ to lens $v$.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES`, followed by a second line with $n$ integers $c_1 \dots c_n$ (each in $\{1,2\}$). This sequence must represent the valid calibration assignment. If multiple valid assignments exist, output the lexicographically smallest sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Replaced the symmetric polynomial and global product with an asymmetric local algebraic constraint (`x^2 + 3y^2` must be prime). This directly addresses the gate's feedback by keeping the condition strictly edge-wise, while the apparent asymmetry acts as a decoy to prevent models from instantly recognizing the undirected bipartiteness pattern.
</RATIONALE>
<PRESERVED_ANSWER>
For x,y in {1,2}, the expression x^2 + 3y^2 evaluates to 4, 13, 7, 16; since 7 and 13 are prime while 4 and 16 are not, the condition is exactly equivalent to requiring x != y for every edge, identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) on the given graph, which is solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
