# Problem B — Anti-Glare Arrays

Time limit: 1 s   Memory limit: 256 MB

An optical instrument contains $n$ crystal lenses. Each lens must be assigned a polarization axis, which must be an integer value of either 1 or 2.

The instrument is equipped with $m$ calibration tubes, each routing light directly between a pair of lenses. The instrument's diagnostic system validates the configuration by computing a net calibration score for the entire network. 

First, the system calculates a *polarization potential* for each lens. For a lens with assigned axis $c$ that is connected to $d$ tubes, its potential is defined as $3 \cdot d \cdot c$. The instrument sums these potentials across all $n$ lenses.

Second, the system accounts for *transmission loss*. For each of the $m$ tubes connecting a pair of lenses with assigned axes $x$ and $y$, the loss is $2 \cdot x \cdot y$. The instrument sums these losses across all $m$ tubes.

The net calibration score is the total polarization potential minus the total transmission loss. (If $m=0$, the score is 0).

To successfully filter out glare, this net calibration score must evaluate to exactly $5m$.

Determine an assignment of polarization axes for all $n$ lenses that satisfies this requirement, or report that the hardware configuration is flawed.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the two lenses connected by that calibration tube.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES`, followed by a second line with $n$ integers $c_1 \dots c_n$ (each in $\{1,2\}$). This sequence must represent the valid calibration assignment. If multiple valid assignments exist, output the lexicographically smallest sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicitly per-edge product condition with a global sum condition that conceptually separates into a vertex-degree term (polarization potential) and an edge term (transmission loss). Models that rely on surface pattern matching will fail to recognize that this global sum mathematically factors back into independent edge contributions where the maximum possible sum of $5m$ is only achievable if every edge connects distinct axes. This forces genuine mathematical reasoning to uncover the underlying bipartiteness.
</RATIONALE>
<PRESERVED_ANSWER>
The net calibration score evaluates to exactly $5m$ if and only if every tube connects lenses with different axes, maintaining exact equivalence with the original $3^m$ product condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring (bipartite checking) and choosing the lexicographically smallest assignment, keeping it firmly in P.
</PRESERVED_CLASS>

</RISK>
