# Problem B — Anti-Glare Arrays

Time limit: 1 s   Memory limit: 256 MB

An optical instrument contains $n$ crystal lenses. Each lens must be assigned a polarization axis, which must be an integer value of either 1 or 2.

The instrument is equipped with $m$ calibration tubes, each routing light directly between a pair of lenses. The instrument's diagnostic system validates the configuration by computing the bitwise XOR of the polarization axes assigned to the two lenses connected by each tube. To successfully filter out glare, this bitwise XOR must evaluate to exactly 3 for every tube.

Determine an assignment of polarization axes for all $n$ lenses that satisfies this requirement for all $m$ tubes, or report that the hardware configuration is flawed.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the two lenses connected by that calibration tube.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES`, followed by a second line with $n$ integers $c_1 \dots c_n$ (each in $\{1,2\}$). This sequence must represent the valid calibration assignment. If multiple valid assignments exist, output the lexicographically smallest sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit instruction "one is set to axis 1 and the other is set to axis 2" with a mathematical requirement: "the bitwise XOR of the polarization axes... must evaluate to exactly 3". This forces the model to evaluate the truth table for the allowed values (1 and 2) to realize this is just a distinct-value constraint, preventing an immediate pattern-match to bipartite graph coloring.
</RATIONALE>
<PRESERVED_ANSWER>
Since the only allowed axis values are 1 and 2, and $1 \oplus 2 = 3$ while $1 \oplus 1 = 0$ and $2 \oplus 2 = 0$, the XOR condition is logically identical to requiring distinct axes for connected lenses, leaving the set of valid assignments exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains fundamentally identical to finding the lexicographically smallest 2-coloring of an undirected graph, which is solvable in $O(n + m)$ time using Breadth-First Search.
</PRESERVED_CLASS>
