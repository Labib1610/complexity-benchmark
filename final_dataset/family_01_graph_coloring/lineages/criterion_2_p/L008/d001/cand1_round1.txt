<STATEMENT>
# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

The factory operates continuously using exactly two shifts, labeled 1 and 2. There are $n$ workers and $m$ pairs of workers. Each worker must be assigned to exactly one shift. For each given pair, the two workers in that pair must collectively provide coverage across all available shifts. Assign each worker a shift so that all pair restrictions are satisfied, or report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of workers.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the explicit inequality ("must be assigned to different shifts") with a set-coverage requirement ("collectively provide coverage across all available shifts"). This removes the direct trigger for bipartite coloring templates, forcing the model to deduce that covering two shifts with two workers requires opposite assignments.
</RATIONALE>
<PRESERVED_ANSWER>
Because there are exactly two available shifts and each worker receives exactly one, a pair of workers can only cover all available shifts if they are assigned to different shifts, keeping the logical constraints mathematically identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still reduces to finding a valid 2-coloring of a graph (or testing for bipartiteness) and selecting the lexicographically smallest assignment, which remains solvable in O(n+m) time using BFS.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret "collectively provide coverage" as a global requirement rather than a pair-specific one, though the phrasing "for each given pair, the two workers in that pair must..." strongly scopes the condition.
</RISK>
