We can model this as a graph problem: each worker is a node, and each workstation is an edge between its two trained workers.  
The condition “one worker on shift 1, the other on shift 2” means the graph must be bipartite.  
We also need the lexicographically smallest assignment, so we try to assign shift 1 to the smallest possible worker IDs first.

We can solve it with BFS/DFS coloring, trying to assign color 1 to the smallest index in each component, and if a conflict occurs, output NO.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    q.clear()
                    break
        if not possible:
            break

if not possible:
    print("NO")
else:
    print("YES")
    # color 0 -> shift 1, color 1 -> shift 2
    print(' '.join(str(c + 1) for c in color))
```
