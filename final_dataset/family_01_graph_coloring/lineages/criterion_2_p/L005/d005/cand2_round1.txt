<STATEMENT>
# Problem B — Quantum Entanglement Protocol

Time limit: 1 s
Memory limit: 256 MB

An industrial facility manages a network of $n$ quantum sensors. Each sensor must be configured with a transformation operator. There are two available operators, represented by $2 \times 2$ matrices:

$T_1 = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}$ and $T_2 = \begin{pmatrix} 1 & 0 \\ 1 & 1 \end{pmatrix}$

A configuration of the network is defined by an array of $n$ integers $s_1 \dots s_n$, where each $s_i \in \{1, 2\}$ indicates the operator chosen for sensor $i$.

The facility's monitoring system has flagged $m$ entanglement pairs. Each pair indicates two sensors that share a quantum state.
To avoid decoherence, the combined transformation of any flagged pair must be perfectly reversible in the spatial basis. In this system, this condition is met if and only if the matrix product of their two assigned operators is a symmetric matrix. 
(Because the entanglement is undirected, the order of multiplication does not matter; for these specific matrices, $T_A T_B$ is a symmetric matrix if and only if $T_B T_A$ is a symmetric matrix).

Your task is to determine a configuration $s_1 \dots s_n$ that satisfies this spatial reversibility protocol for every flagged pair, or determine that no such configuration is possible.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$ — a pair of sensors listed as an entanglement pair. Sensors are numbered from $1$ to $n$.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I completely replaced the numerical constraint (product is exactly 2) with a linear algebra constraint (matrix product is a symmetric matrix). By carefully choosing the matrices, the product $T_u T_v$ is symmetric if and only if $s_u \neq s_v$. This forces the model to mathematically evaluate the matrix products to discover the bipartite nature of the graph, rather than relying on standard keyword associations or simple integer inequalities.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the matrix product $T_A T_B$ is symmetric holds exactly when $A \neq B$ (since $T_1 T_2$ and $T_2 T_1$ are symmetric, while $T_1 T_1$ and $T_2 T_2$ are not), which is logically identical to the seed's requirement that the values must be different to multiply to 2.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) on an undirected graph, which is solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
