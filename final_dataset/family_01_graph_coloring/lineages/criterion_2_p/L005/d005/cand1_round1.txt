<STATEMENT>
# Problem B — Spectral Calibration

Time limit: 1 s
Memory limit: 256 MB

An industrial facility manages a network of $n$ automated machines. Each machine must be configured to a power setting of either 1 or 2.

The facility's monitoring system has flagged $m$ adjacency pairs. Each pair indicates two machines that are physically close enough to risk signal overlap. To guarantee safe operation, the system enforces a strict spectral interference protocol.

For every flagged pair of machines $(u, v)$, we construct an interference matrix $M$ defined as:
$$M = \begin{pmatrix} s_u & \sqrt{2} \\ \sqrt{2} & s_v \end{pmatrix}$$
where $s_u$ and $s_v$ are the power settings of the two machines.
To avoid chaotic resonance, the protocol dictates that both eigenvalues of this matrix must be rational numbers.

Your task is to determine a power setting configuration for all $n$ machines that satisfies this protocol for every flagged pair, or determine that no such configuration is possible.

If multiple valid configurations exist, imagine concatenating the settings $s_1, s_2, \dots, s_n$ to form a single $n$-digit number in base-3 (where $s_1$ is the most significant digit). You must output the configuration that yields the strictly smallest possible numerical value for this base-3 number.

The number of machines $n$ and the number of flagged pairs $m$ provided in the input will never exceed the total number of seconds in 55 hours, 33 minutes, and 20 seconds.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n$, $0 \le m$).
The following $m$ lines each contain two integers $u$ and $v$ — a pair of machines listed in an adjacency pair. Machines are numbered from $1$ to $n$.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the valid configuration that minimizes the base-3 value described above.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
