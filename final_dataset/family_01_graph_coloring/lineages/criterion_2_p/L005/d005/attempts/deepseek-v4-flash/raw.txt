We need to analyze the condition for each flagged pair.

Given:

\[
M = \begin{pmatrix} x & y \\ y & x \end{pmatrix}
\]

Eigenvalues of this matrix are:

\[
\lambda_1 = x + y, \quad \lambda_2 = x - y
\]

The condition says: exactly one eigenvalue equals 3.

Since \(x, y \in \{1, 2\}\), possible sums/differences:

- If \(x = y\): eigenvalues are \(2x\) and \(0\).  
  - If \(x=1\): eigenvalues 2 and 0 → no 3.  
  - If \(x=2\): eigenvalues 4 and 0 → no 3.  
  So equal values never satisfy.

- If \(x \neq y\): one is 1, the other is 2.  
  Then \(x+y = 3\) and \(x-y = \pm 1\).  
  Exactly one eigenvalue is 3.  

So the condition is: **for every flagged pair, the two machines must have different power settings**.

Thus the problem reduces to:  
Given a graph, can we 2-color it (bipartite check) with colors 1 and 2?  
If yes, output the lexicographically smallest coloring (assign 1 to node 1, then BFS/DFS assigning alternating colors, with smallest possible values).

If the graph is not bipartite → NO.

Implementation plan:
- Build adjacency list.
- BFS/DFS coloring with 1 and 2.
- If conflict → NO.
- Else output YES and the colors.

We must ensure lexicographically smallest:  
We can start BFS from node 1 with color 1, and for each unvisited node, start with color 1 (since we want smallest lexicographic). This works because any connected component can be flipped, but starting with 1 gives smallest.

Let's code it.

```python
import sys
from collections import deque

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    for i in range(n):
        if color[i] == -1:
            color[i] = 1
            q = deque([i])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = 3 - color[u]  # 1 -> 2, 2 -> 1
                        q.append(v)
                    elif color[v] == color[u]:
                        print("NO")
                        return
    
    print("YES")
    print(" ".join(str(c) for c in color))

if __name__ == "__main__":
    solve()
```
