<STATEMENT>
# Problem B — Power Calibration

Time limit: 1 s
Memory limit: 256 MB

An industrial facility operates a network of $n$ automated machines. Each machine must be calibrated to a power mode of either 1 or 2.

The facility's safety system has identified $m$ critical pairs of machines. These pairs share a power bus. To prevent surges, the two machines in any critical pair must always be calibrated to different power modes.

Your task is to find a calibration for all $n$ machines that safely balances all $m$ critical pairs, or determine that no such calibration exists. 

Because multiple safe calibrations might be possible, the facility requires a specific deterministic sequence of modes. If at least one valid overall calibration exists, the required sequence is defined by the following sequential procedure:
1. Evaluate the machines in index order from $1$ to $n$.
2. For the current machine $i$, tentatively assign it to power mode 1.
3. Check if there exists ANY valid mode assignment for the remaining machines ($i+1$ to $n$) which, together with the assignments for machines $1$ to $i$, satisfies all $m$ critical pair constraints.
4. If such a completion exists, machine $i$ is permanently set to mode 1.
5. Otherwise, machine $i$ is permanently set to mode 2.

You must output the exact sequence of modes that this procedure produces.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of machines and the number of critical pairs, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a critical pair of machines. Machines are numbered from $1$ to $n$.

## Output
If it is impossible to safely calibrate the machines, print NO on a single line.
Otherwise, print YES on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2\}$) representing the required calibration sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Removed the artificial matrix eigenvalue constraint and replaced it with a natural operational rule ("must be different"). To prevent models from trivially solving it via standard bipartite templates, the "lexicographically smallest" tie-break is rephrased as an explicit sequential procedure. This forces models to realize that the $O(n^2)$ naive simulation is structurally equivalent to the optimal $O(n+m)$ greedy component-wise coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement for adjacent machines to have different modes from $\{1, 2\}$ is exactly equivalent to the original matrix eigenvalue condition, and the sequential procedure perfectly defines the lexicographically smallest valid sequence, ensuring identical outputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing), which can be solved in $O(n+m)$ time by assigning the lowest available color to the unvisited nodes during a BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the sequential procedure as requiring an online algorithm, but the "If at least one valid overall calibration exists" clause makes it clear it's a static tie-breaking rule.
</RISK>
