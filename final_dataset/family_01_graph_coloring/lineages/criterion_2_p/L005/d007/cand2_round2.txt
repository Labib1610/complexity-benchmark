# Problem B — Power Calibration

Time limit: 1 s
Memory limit: 256 MB

An industrial facility operates a network of $n$ automated machines. Each machine must be calibrated to a power mode of either 1 or 2.

The facility's safety system has identified $m$ critical pairs of machines. These pairs share a power bus, and their modes must be carefully balanced to prevent surges. 

For any critical pair with assigned modes $x$ and $y$, the system's stability is modeled using the following $2 \times 2$ state matrix:
$$S = \begin{pmatrix} x^2 & x+y \\ x+y & y^2 \end{pmatrix}$$
To comply with the safety protocol, the determinant of the matrix $S$ must be exactly $-5$ for every critical pair.

Your task is to find a calibration for all $n$ machines that satisfies this requirement for all $m$ pairs, or determine that no such calibration exists.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of machines and the number of critical pairs, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a critical pair of machines. Machines are numbered from $1$ to $n$.

## Output
If it is impossible to safely calibrate the machines, print NO on a single line.
Otherwise, print YES on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2\}$) representing the lexicographically smallest valid calibration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<METHOD_DESCRIPTION>
Replaced the seed's 3x3 sparse matrix and its max-eigenvalue condition with a 2x2 dense matrix and a determinant condition. The new condition $\det(S) = -5$ evaluates to true if and only if the modes are different, preserving the exact same bipartiteness logic while destroying the specific surface patterns (like $\sqrt{5}$ and the star matrix structure) that models rely on to skip reasoning.
</METHOD_DESCRIPTION>

yes
</METHOD_NOVEL>
<RATIONALE>
The surviving models succeeded by recognizing the specific $3 \times 3$ matrix and the $\sqrt{5}$ eigenvalue as a known pattern equivalent to $x^2+y^2=5$, bypassing the need to deduce the relationship. By introducing a $2 \times 2$ matrix whose determinant $x^2 y^2 - (x+y)^2$ equals $-5$ only when $x \neq y$, models are forced to genuinely evaluate the mathematical condition for the domain $\{1, 2\}$ rather than pattern-matching.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $\det(S) = x^2 y^2 - (x+y)^2 = -5$ holds for $x, y \in \{1, 2\}$ if and only if one mode is 1 and the other is 2, which is exactly the same constraint as the seed.
</PRESERVED_ANSWER>
