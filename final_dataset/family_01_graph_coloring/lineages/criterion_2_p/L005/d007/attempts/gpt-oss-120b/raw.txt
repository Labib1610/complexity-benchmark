**Solution Explanation**

For a machine we choose a mode `c[i] ∈ {1,2}`.
For a critical pair `{u,v}` the resonance factor is  

```
c[u]^3 + c[v]^3
```

```
1^3 = 1 ,   2^3 = 8
possible sums : 1+1 = 2 , 1+8 = 9 , 8+8 = 16
```

The required total product is `9^m`.  
Therefore **every** edge must contribute the factor `9`, i.e. its sum must be `9`.
Consequently each edge must connect a machine with mode `1` and a machine with mode `2`.

So we have to colour the vertices with two colours `{1,2}` such that
every edge connects vertices of different colours – exactly the definition of a
*bipartite* graph.

If the graph is not bipartite the answer is `NO`.
Otherwise a bipartite colouring exists; each connected component has two
possibilities (swap the two colour classes).  
We need the **lexicographically smallest** sequence `c[1] … c[n]`.

Observation  
For a component let `vmin` be its smallest vertex index.
If we colour the component so that `c[vmin] = 1`, then all vertices with index
smaller than any vertex of another component are already fixed to the smallest
possible values. Hence the globally lexicographically smallest solution is
obtained by, for every component, choosing the orientation that gives
`c[vmin] = 1`.

Thus the algorithm is:

```
if m == 0:
    output all 1s
else
    build adjacency list
    colour array col[i] = -1 (unvisited), values 0/1 for the two sides
    answer array ans[i]

    for i = 1 .. n:
        if col[i] == -1:
            BFS/DFS from i, colour the component (0/1)
            if a conflict appears -> NOT BIPARTITE -> NO
            let vmin = smallest vertex of this component (it is i because we iterate increasing)
            if col[i] == 0:          # colour 0 will become mode 1
                for each vertex x in component:
                    ans[x] = 1 if col[x]==0 else 2
            else:                    # swap
                for each vertex x in component:
                    ans[x] = 2 if col[x]==0 else 1
```

Complexities  
`O(n+m)` time, `O(n+m)` memory – fits the limits.

#### Correctness Proof  

We prove that the algorithm prints `YES` and a lexicographically smallest
valid calibration iff such a calibration exists.

---

**Lemma 1**  
For any edge `{u,v}` the condition `c[u]^3 + c[v]^3 = 9` holds **iff**
`c[u] ≠ c[v]`.

*Proof.*  
The only possible sums of two numbers from `{1,8}` are `2,9,16`.  
`9` occurs exactly for the pair `{1,8}` i.e. the modes are different. ∎



**Lemma 2**  
A calibration satisfying the requirement exists **iff** the graph is bipartite.

*Proof.*  
By Lemma&nbsp;1 each edge must connect vertices of different modes, which is
exactly a proper 2‑colouring of the graph. Such a colouring exists precisely
when the graph is bipartite. ∎



**Lemma 3**  
For a bipartite connected component, among the two possible colourings,
the one with the smallest indexed vertex coloured `1` yields a lexicographically
not larger (and strictly smaller unless both are equal) overall sequence
than the opposite colouring, assuming all earlier vertices (outside the
component) are already fixed.

*Proof.*  
All vertices with index smaller than the component’s minimum are already fixed,
so the first position where the two colourings can differ is that minimum
vertex. Giving it colour `1` makes the sequence smaller (since `1 < 2`). ∎



**Lemma 4**  
The algorithm outputs a valid calibration whenever it prints `YES`.

*Proof.*  
During BFS each visited edge connects vertices with opposite temporary colours
`0` and `1`; a conflict would abort with `NO`. Hence the temporary colours form a
proper bipartition. Afterwards the algorithm maps the two temporary colours to
`1` and `2` (possibly swapping) – this preserves the property that adjacent
vertices receive different final modes. By Lemma&nbsp;1 every edge contributes
`9`, therefore the total product is `9^m`. ∎



**Lemma 5**  
If a valid calibration exists, the algorithm never prints `NO`.

*Proof.*  
Existence of a valid calibration implies the graph is bipartite (Lemma&nbsp;2).
A bipartite graph has no odd cycle, therefore the BFS never encounters a
conflict, so the algorithm finishes all components and prints `YES`. ∎



**Lemma 6**  
The calibration produced by the algorithm is lexicographically smallest among
all valid calibrations.

*Proof.*  
Consider the components in increasing order of their smallest vertex.
When the algorithm processes a component, all vertices with smaller indices
belong to earlier components and are already fixed to the smallest possible
values (induction hypothesis). By Lemma&nbsp;3 the algorithm chooses the
orientation that makes the current component’s smallest vertex `1`, which is
the minimal possible value at the first still‑free position. Hence after
processing this component the prefix up to its largest vertex is lexicographically
minimal. By induction over components the whole sequence is minimal. ∎



**Theorem**  
The program prints  

* `NO` iff no calibration satisfying the condition exists;  

* otherwise `YES` followed by the lexicographically smallest valid calibration.

*Proof.*  
If the program prints `NO`, it must have detected a conflict, i.e. the graph is
not bipartite, so by Lemma&nbsp;2 no calibration exists.  
If a calibration exists, Lemma&nbsp;5 guarantees the program does not print
`NO`. By Lemma&nbsp;4 the printed assignment is valid, and by Lemma&nbsp;6 it
is the lexicographically smallest one. ∎

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    if m == 0:
        print("YES")
        print(" ".join(["1"] * n))
        return

    col = [-1] * (n + 1)          # temporary colours 0/1
    ans = [0] * (n + 1)

    from collections import deque

    for start in range(1, n + 1):
        if col[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        col[start] = 0
        comp = [start]
        ok = True
        while q:
            v = q.popleft()
            for to in adj[v]:
                if col[to] == -1:
                    col[to] = col[v] ^ 1
                    q.append(to)
                    comp.append(to)
                elif col[to] == col[v]:
                    print("NO")
                    return
        # decide orientation: make start (the smallest vertex of this component) colour 1
        if col[start] == 0:
            for v in comp:
                ans[v] = 1 if col[v] == 0 else 2
        else:
            for v in comp:
                ans[v] = 2 if col[v] == 0 else 1

    print("YES")
    print(" ".join(str(ans[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
