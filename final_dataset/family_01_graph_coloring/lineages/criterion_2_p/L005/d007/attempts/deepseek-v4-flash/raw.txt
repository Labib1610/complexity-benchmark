We need to assign each machine a value of 1 or 2 such that for every critical pair (u, v), the product over all pairs of (x³ + y³) equals 9^m.

Since x, y ∈ {1, 2}, the possible values of x³ + y³ are:

- 1³ + 1³ = 2  
- 1³ + 2³ = 1 + 8 = 9  
- 2³ + 1³ = 9  
- 2³ + 2³ = 8 + 8 = 16  

We need the product over all edges to be 9^m.  
That means every edge must have resonance factor 9.  
So for every edge, one endpoint must be 1 and the other must be 2.

Thus, the graph must be bipartite, with machines in one part assigned 1 and the other part assigned 2.

If the graph is not bipartite, output NO.  
If it is bipartite, we need the lexicographically smallest assignment.  
We can do BFS/DFS coloring, starting with 1 for the smallest index, and whenever possible assign 1 to smaller-index nodes.

Let’s implement:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
