<STATEMENT>
# Problem B — Power Calibration

Time limit: 1 s
Memory limit: 256 MB

An industrial facility operates a network of automated machines. Each machine must be calibrated to a power mode of either 1 or 2.

The facility's safety system has identified critical pairs of machines. These pairs share a power bus, and their modes must be carefully balanced to prevent surges. 

For any critical pair with assigned modes $x$ and $y$, the system's stability is modeled using the following $4 \times 4$ state matrix $S$:
$$S = \frac{1}{2} \begin{pmatrix} x+y & x & y & 0 \\ x & x-y & 0 & -y \\ y & 0 & -x+y & -x \\ 0 & -y & -x & -x-y \end{pmatrix}$$

To comply with the safety protocol, the largest eigenvalue of the matrix $S$ must be exactly $\sqrt{5}$ for every critical pair.

Your task is to find a calibration for all machines that satisfies this requirement for all pairs, or determine that no such calibration exists.

## Input
The first line contains two integers $n$ and $m$ (where $1 \le n \le 200\,000$ and $0 \le m \le 200\,000$), representing the number of machines and the number of critical pairs, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a critical pair of machines. Machines are numbered from $1$ to $n$.

## Output
If it is impossible to safely calibrate the machines, print NO on a single line.
Otherwise, print YES on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2\}$) representing the valid calibration that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The sparse star-shaped matrix from the seed problem was replaced with a dense 4x4 orthogonal conjugate matrix that possesses the exact same non-zero eigenvalues. This removes the obvious visual cue of `x^2 + y^2` in the characteristic polynomial, forcing the model to genuinely compute the eigenvalues of the new matrix for the possible `(x,y)` pairs in `{1,2}` to discover the `x != y` bipartiteness constraint.
</RATIONALE>
<PRESERVED_ANSWER>
The largest eigenvalue of the new matrix is exactly sqrt(x^2 + y^2), which equals sqrt(5) if and only if one machine is set to 1 and the other to 2, preserving the exact same valid configurations and lexicographical tie-breaking as the seed problem.
</PRESERVED_ANSWER>
