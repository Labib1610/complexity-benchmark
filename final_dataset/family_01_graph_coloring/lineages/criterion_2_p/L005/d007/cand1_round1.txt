<STATEMENT>
# Problem B — Power Calibration

Time limit: 1 s
Memory limit: 256 MB

An industrial facility operates a network of $n$ automated machines. Each machine must be calibrated to a power mode of either 1 or 2.

The facility's safety system has identified $m$ critical pairs of machines. These pairs share a power bus, and their modes must be carefully balanced to prevent surges. 

For any critical pair with assigned modes $x$ and $y$, the system's stability is modeled using the following $4 \times 4$ state matrix $W$:
$$W = \frac{1}{2} \begin{pmatrix} x+y & x & y & 0 \\ x & x-y & 0 & -y \\ y & 0 & -x+y & -x \\ 0 & -y & -x & -x-y \end{pmatrix}$$

To comply with the safety protocol, the largest eigenvalue of the matrix $W$ must be exactly $\sqrt{5}$ for every critical pair.

Your task is to find a calibration for all $n$ machines that satisfies this requirement for all $m$ pairs, or determine that no such calibration exists.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of machines and the number of critical pairs, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a critical pair of machines. Machines are numbered from $1$ to $n$.

## Output
If it is impossible to safely calibrate the machines, print NO on a single line.
Otherwise, print YES on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2\}$) representing the lexicographically smallest valid calibration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The previous sparse $3 \times 3$ star-shaped matrix allowed models to easily compute the characteristic polynomial analytically and recognize the $x^2+y^2=5$ condition. I padded the matrix with a zero eigenvalue and conjugated it with a $4 \times 4$ Hadamard matrix to produce a dense, symmetric $4 \times 4$ matrix. This preserves the exact same non-zero eigenvalues but completely obfuscates the algebraic structure, forcing models to either correctly perform a very difficult symbolic $4 \times 4$ determinant expansion or accurately compute eigenvalues for numerical test cases without a code interpreter.
</RATIONALE>
<PRESERVED_ANSWER>
The new matrix $W$ is orthogonally similar to the original matrix padded with a zero, so its eigenvalues are identically $0, 0, \sqrt{x^2+y^2}, -\sqrt{x^2+y^2}$; thus the largest eigenvalue is $\sqrt{5}$ if and only if $x^2+y^2=5$, perfectly preserving the requirement that $x \neq y$.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The condition still reduces exactly to assigning distinct values from $\{1, 2\}$ to every connected pair, which is identically Graph Bipartiteness (2-coloring) solvable in $O(n+m)$ time.
</PRESERVED_CLASS>
