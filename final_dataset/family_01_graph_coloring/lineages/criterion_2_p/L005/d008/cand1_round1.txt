# Problem B — Power Calibration

Time limit: 1 s
Memory limit: 256 MB

An industrial facility operates a network of $n$ automated machines. Each machine must be calibrated to a power mode of either 1 or 2.

The facility's safety system has identified $m$ critical pairs of machines. These pairs share a power bus, and their modes must be carefully balanced. 

For each machine $i$, let $k_i$ be the total number of critical pairs that include machine $i$. To comply with the safety protocol and prevent dangerous harmonic cascades, the configuration must satisfy a strict neighborhood balance: for every machine $i$, the sum of the power modes of the machines paired with machine $i$ across all $k_i$ of its critical pairs, plus $k_i$ times the power mode of machine $i$ itself, must equal exactly $3k_i$. 

Your task is to find a calibration for all $n$ machines that satisfies this requirement, or determine that no such calibration exists.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of machines and the number of critical pairs, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a critical pair of machines. Machines are numbered from $1$ to $n$.

## Output
If it is impossible to safely calibrate the machines, print NO on a single line.
Otherwise, print YES on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2\}$) representing the lexicographically smallest valid calibration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

Replaced the explicit pairwise arithmetic constraint ($x^3+y^3=9$) with an equivalent vertex-centric neighborhood sum constraint. This breaks the pattern matching of independent edge evaluations. To solve it, the model must perform algebraic bounds analysis on the sum to deduce that the condition strictly forces every adjacent machine to have the opposite mode, thereby recovering the 2-coloring requirement.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $\sum c_j + k_i c_i = 3k_i$ simplifies to $\sum c_j = k_i(3 - c_i)$; since $c \in \{1, 2\}$, this sum equals its theoretical maximum $2k_i$ when $c_i=1$ (forcing all neighbors to 2) and its theoretical minimum $k_i$ when $c_i=2$ (forcing all neighbors to 1), making it mathematically identical to strict proper 2-coloring.
</PRESERVED_ANSWER>

The underlying problem remains exactly proper 2-coloring of a graph (bipartiteness testing), which is solvable in $O(n+m)$ time using BFS or DFS.
</PRESERVED_CLASS>
