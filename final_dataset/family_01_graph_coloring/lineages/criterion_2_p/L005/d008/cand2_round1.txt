<STATEMENT>
# Problem B — Power Calibration

Time limit: 1 s
Memory limit: 256 MB

An industrial facility operates a network of $n$ automated machines. Each machine must be calibrated to a power mode of either 1 or 2.

The facility's safety system has identified $m$ critical pairs of machines. These pairs share a power bus, and their modes must be carefully balanced. 

For any machine $i$, let $d_i$ be the number of critical pairs that include machine $i$. The total grid load $L$ is calculated as:
$L = \sum_{i=1}^n d_i c_i$
where $c_i \in \{1, 2\}$ is the power mode of machine $i$.

The grid stability $S$ is calculated as:
$S = \sum_{j=1}^m c_{u_j} c_{v_j}$
where $u_j$ and $v_j$ are the two machines in the $j$-th critical pair.

To comply with the safety protocol and prevent dangerous harmonic cascades, the calibration must satisfy the global condition:
$3L - 2S = 5m$

Your task is to find a calibration for all $n$ machines that satisfies this requirement, or determine that no such calibration exists.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of machines and the number of critical pairs, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a critical pair of machines. Machines are numbered from $1$ to $n$.

## Output
If it is impossible to safely calibrate the machines, print NO on a single line.
Otherwise, print YES on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2\}$) representing the lexicographically smallest valid calibration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I changed the resonance condition from an explicit edge-by-edge arithmetic check to a global algebraic equality involving a node-wise degree-weighted sum and an edge-wise product sum. This forces models to algebraically manipulate the global sums into an edge-wise maximum to discover that the condition uniquely requires $c_u \neq c_v$ for all pairs, completely breaking surface-level pattern matching to 2-coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The global condition $3L - 2S = 5m$ mathematically simplifies to $\sum (3(c_u + c_v) - 2 c_u c_v) = 5m$, which is uniquely satisfied when every edge contributes exactly 5, meaning $c_u \neq c_v$ for all critical pairs, exactly matching the valid calibrations of the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The valid assignments and their lexicographical ordering are identical to the seed problem, meaning the problem remains exactly 2-coloring (bipartiteness testing) solvable in $O(n+m)$ time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret $d_i$ if a machine is part of multiple identical critical pairs (multigraphs), though standard graph problem conventions and the definition "number of critical pairs that include machine $i$" unambiguously dictate counting with multiplicity.
</RISK>
