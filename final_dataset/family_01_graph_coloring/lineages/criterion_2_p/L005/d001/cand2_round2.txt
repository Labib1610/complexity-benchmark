<STATEMENT>
# Problem B — Frequency Calibration

Time limit: 1 s
Memory limit: 256 MB

An industrial plant operates a system of $n$ robotic units. Each unit must be calibrated to operate on one of two available frequency bands, labeled 1 and 2.

The plant's safety system contains $m$ proximity records. Each record identifies two units that operate close to one another. To prevent signal interference, the calibration must satisfy a strict safety rule: for any pair of units listed in a proximity record, the sum of their assigned frequency bands must evaluate to exactly 3.

You must assign a frequency band to each of the $n$ units such that every proximity record satisfies this safety rule, or determine that no such assignment is possible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of units listed in a proximity record.

## Output
If no valid calibration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid calibration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the direct "different phases" phrasing with an algebraic constraint where the sum of the assigned frequency bands must be exactly 3. This forces the model to deduce that the endpoints of each proximity record must have opposite assignments (since the only available bands are 1 and 2), removing the surface-level bipartite terminology.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that two variables from the set {1, 2} sum to 3 is mathematically identical to requiring them to be distinct, so the set of valid assignments and the lexicographical tie-breaker remain identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core structure remains equivalent to finding a 2-coloring of a graph (or determining bipartiteness), which is solvable in O(n+m) time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the sum condition if they fail to recognize that the only available bands are strictly 1 and 2, though this limitation is explicitly stated in the first paragraph.
</RISK>
