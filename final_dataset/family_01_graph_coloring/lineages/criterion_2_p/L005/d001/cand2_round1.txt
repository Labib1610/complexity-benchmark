# Problem B — Resonance Configuration

Time limit: 1 s   Memory limit: 256 MB

An automated manufacturing facility operates using a set of $n$ assembly technicians, numbered 1 to $n$. The personnel database allocates exactly $2 \cdot 10^5$ memory slots for technician profiles. The active headcount $n$ is always at least 1 and will never exceed this allocated capacity. 

Certain technicians share specialized pneumatic tools; there are $m$ such sharing links. The system log for these links can be entirely empty, or it can contain up to the same number of entries as the maximum possible technician capacity.

To prevent resonance failure in the shared tools, every technician must be configured to operate on exactly one of two calibration frequencies, designated as frequency 1 and frequency 2. Whenever a tool is shared between two technicians, its internal pressure valve requires their assigned operating frequencies to sum to exactly 3 in order to reset correctly between uses.

You need to determine a frequency configuration for all $n$ technicians that safely resets all shared tools, or determine that no such configuration is possible.

## Input
The first line contains the headcount $n$ and the number of tool-sharing links $m$.
The next $m$ lines each contain two integers $u$ and $v$ — identifying a pair of technicians who share a tool.

## Output
If the system cannot be configured safely, print a single line containing NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1, 2\}$) representing the assigned frequencies. If there are multiple valid configurations, you must print the one whose sequence of frequencies is the lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The direct mention of scheduling into different phases was replaced with assigning numeric frequencies (1 or 2) that must sum to 3 across shared tools. This algebraically forces the same inequality condition ($x \neq y$) while obscuring the obvious graph-coloring terminology. Additionally, following Strategy S07, the numeric bounds were removed from the Input section and embedded in the description as physical database limits, forcing the model to infer the constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that frequencies 1 and 2 must sum to 3 exactly mimics the requirement that shared-tool technicians be assigned to different phases, preserving all valid schedules and the lexicographical tie-breaker.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is in P and heavily relies on breadth-first search and connected components.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "sum to exactly 3" as allowing values outside of {1, 2}, though the text explicitly states technicians must operate on "exactly one of two calibration frequencies, designated as frequency 1 and frequency 2."
</RISK>
