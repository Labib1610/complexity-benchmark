# Problem B — Phase Scheduling

Time limit: 1 s   Memory limit: 256 MB

A manufacturing facility employs $n$ technicians, and there are $m$ pairs of technicians whose workstations are physically linked. You must assign each technician exactly one phase factor $s_i \in \{1, 2\}$. Due to resonance constraints, for every pair of technicians whose workstations are linked, the product of their assigned phase factors must be exactly 2. You must find an assignment of phase factors that satisfies this requirement, or report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of technicians whose workstations are linked.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit "not scheduled for the same phase" conflict condition with a mathematical equivalence: the product of their phase factors (which must be chosen from {1, 2}) must be exactly 2. This forces the model to deduce that $s_u \neq s_v$ instead of relying on keyword matching to standard graph coloring descriptions.
</RATIONALE>
<PRESERVED_ANSWER>
Because the phase factors are restricted to {1, 2}, the only way their product can be exactly 2 is if one factor is 1 and the other is 2, which is mathematically identical to requiring them to be different.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to 2-coloring (bipartiteness testing), which is in P and solvable in O(n+m) time using Breadth-First Search.
</PRESERVED_CLASS>
