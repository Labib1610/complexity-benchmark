<STATEMENT>
# Problem B — Frequency Calibration

Time limit: 1 s
Memory limit: 256 MB

An industrial facility manages a network of $n$ automated machines, each assigned a unique ID from 1 to $n$. Each machine must be configured to use one of two specific operational modes, which are designated by the values 1 and 2.

The facility's monitoring system has flagged $m$ adjacency pairs. Each pair indicates two machines that are physically close enough to risk signal overlap. To guarantee safe operation, the system enforces a strict interference protocol: for any two machines in an adjacency pair with IDs $u$ and $v$, if their configured modes are $x$ and $y$, the resulting cross-talk metric, calculated as $x^3 + y^3 + x y (u + v)$, must evaluate to exactly $9 + 2(u + v)$.

Your task is to determine a mode configuration for all $n$ machines that satisfies this protocol for every adjacency pair, or determine that no such configuration is possible.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$ — the IDs of a pair of machines listed in an adjacency pair.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The models bypassed the intended reasoning by evaluating the static global polynomial $x^2 + 3xy + y^2 = 11$ for the fixed domain $\{1, 2\}$, immediately revealing it acts as a simple $x \neq y$ check. To remove this affordance without violating the hard constraint of identical answers across all possible inputs (which adding a non-implied condition like "$u+v$ is odd" would violate for valid bipartite graphs with even-sum edges), the static polynomial was replaced with an edge-dependent equation $x^3 + y^3 + xy(u+v) = 9 + 2(u+v)$. This forces the solver to handle the constraint parametrically or per-edge, disrupting simple global static evaluation while remaining mathematically equivalent to bipartiteness for all valid machine IDs.
</RATIONALE>
<PRESERVED_ANSWER>
The equation $x^3 + y^3 + xy(u+v) = 9 + 2(u+v)$ for $x,y \in \{1,2\}$ and $u,v \ge 1$ is satisfied if and only if $x \neq y$, keeping the valid configurations exactly identical to the original problem for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest valid 2-coloring of a graph, which is solvable in $O(n+m)$ time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
Models might still evaluate the new equation on the first given edge, test the four mode combinations, and correctly generalize that the condition always simplifies to $x \neq y$.
</RISK>
