<STATEMENT>
# Problem B — Frequency Calibration

Time limit: 1 s
Memory limit: 256 MB

An industrial facility manages a network of $n$ automated machines. Each machine must be configured to use one of two specific operational modes, which are designated by the values 1 and 2.

The facility's monitoring system has flagged $m$ adjacency pairs. Each pair indicates two machines that are physically close enough to risk signal overlap. To guarantee safe operation, the system enforces a strict neighborhood interference protocol.

For any given machine, let $k$ be the number of adjacency pairs that include it. The protocol requires that the sum of the configured modes of its partner machines in these $k$ pairs must perfectly balance the given machine's own mode:
- If the given machine is configured to mode 1, the sum of the modes of its partner machines must be exactly $2k$.
- If the given machine is configured to mode 2, the sum of the modes of its partner machines must be exactly $k$.

Your task is to determine a mode configuration for all $n$ machines that satisfies this protocol for every machine, or determine that no such configuration is possible.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$ — a pair of machines listed in an adjacency pair.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The previous surviving models bypassed the algorithmic reasoning by extracting the local polynomial condition (x^2 + 3xy + y^2 = 11) and computationally evaluating the 4 possible (x, y) combinations, immediately mapping the valid (1, 2) and (2, 1) pairs to graph bipartiteness. 
To remove this affordance, the per-edge constraint has been replaced with a per-neighborhood aggregation rule. Because the condition is now defined over the sum of an arbitrary number of neighbors $k$, models can no longer brute-force a 2x2 local truth table. They are forced to genuinely deduce that a sum of $k$ mode values (each 1 or 2) can only equal $2k$ if all partners are 2, and can only equal $k$ if all partners are 1, meaning all neighbors must have the opposite mode.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the sum of $k$ variables from {1, 2} equals $2k$ (or $k$) uniquely forces all those variables to be 2 (or 1), meaning every adjacency pair must contain exactly one machine in mode 1 and one in mode 2, which is mathematically identical to the original polynomial requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) on an undirected graph, keeping it in P.
</PRESERVED_CLASS>
<RISK>
A reader might wonder how the protocol applies to isolated machines ($k=0$); however, the standard mathematical convention that an empty sum is 0 perfectly resolves this ($0 = 2 \times 0$ and $0 = 1 \times 0$), leaving the machine unconstrained, which correctly defaults to mode 1 due to the lexicographical tie-breaker.
</RISK>
