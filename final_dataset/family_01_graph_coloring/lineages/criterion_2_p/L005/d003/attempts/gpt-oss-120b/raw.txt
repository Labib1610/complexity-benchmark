**Solution Explanation**

For every machine `i`

* `deg[i]` – number of adjacency pairs containing `i`
* `x[i] ∈ {1,2}` – the mode we have to choose

The statement requires  

```
if x[i] = 1 :   sum of neighbours' modes = 2·deg[i]
if x[i] = 2 :   sum of neighbours' modes =   deg[i]
```

--------------------------------------------------------------------

#### 1.   Reformulation

For a fixed `i`

```
sum_{j neighbour of i} x[j] = deg[i]·(3 – x[i])          (1)
```

because  

* `x[i]=1`  → right side `deg·2`  
* `x[i]=2`  → right side `deg·1`

Move the term containing `x[i]` to the left:

```
sum_{j neighbour of i} x[j] + deg[i]·x[i] = 3·deg[i]    (2)
```

Equation (2) tells us that **all neighbours of `i` must have the same
value, opposite to the value of `i`** :

* if `x[i]=1` then every neighbour must contribute `2`,
  therefore every neighbour must be `2`;
* if `x[i]=2` then every neighbour must contribute `1`,
  therefore every neighbour must be `1`.

Consequently the whole graph has to be *bipartite* and the two parts
must receive the two different modes `1` and `2`.

--------------------------------------------------------------------

#### 2.   Bipartite check and construction

We run a BFS/DFS over every connected component.

* `col[v] = 0/1` – the parity inside the component (the usual bipartite
  colouring).
* If we ever see an edge joining two vertices with the same parity,
  the graph is **not bipartite** → answer `NO`.

Otherwise the component is bipartite.
There are exactly two possible assignments of modes:

```
parity 0 → 1 , parity 1 → 2          (A)
parity 0 → 2 , parity 1 → 1          (B)
```

To obtain the **lexicographically smallest** whole sequence we decide
independently for each component:

* let `v0` be the smallest vertex index inside the component,
* look at its parity `p = col[v0]`,
* choose the orientation that gives `x[v0] = 1`
  (i.e. map parity `p` to mode `1`).

Because components are disjoint, fixing the smallest index of a
component to the smallest possible value makes the global sequence
lexicographically minimal.

--------------------------------------------------------------------

#### 3.   Algorithm
```
read n, m
build adjacency list
col[1..n] = -1
answer[1..n] = 0

for each vertex v = 1 .. n
    if col[v] == -1
        BFS from v
        store all visited vertices of this component in list comp
        during BFS detect non‑bipartite → print NO and exit
        v0 = minimum vertex in comp
        p  = col[v0]
        for each u in comp
            if col[u] == p: answer[u] = 1
            else           : answer[u] = 2

print YES
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `NO` iff no valid configuration exists,
otherwise prints `YES` and the lexicographically smallest valid
configuration.

---

##### Lemma 1  
If a configuration satisfying the statement exists, the graph is
bipartite.

**Proof.**  
Take any edge `(i,j)`. From (1) for vertex `i` we have
`x[j] = 3 – x[i]`. Since `x[i] ∈ {1,2}`, `x[j]` is the opposite value.
Thus every edge connects vertices with different values, i.e. the
graph is 2‑colourable → bipartite. ∎



##### Lemma 2  
If the graph is bipartite and we assign mode `1` to one part and mode `2`
to the other part, all vertices satisfy the required equalities.

**Proof.**  
Consider a vertex `i` belonging to part `P`. All its neighbours belong to
the opposite part `Q`. All neighbours therefore have the same mode,
call it `y`. Because the two parts receive different modes, `y = 3 –
x[i]`. The sum of neighbour modes equals `deg[i]·y = deg[i]·(3‑x[i])`,
which is exactly the right hand side of (1). ∎



##### Lemma 3  
For a bipartite component the algorithm produces a configuration that
satisfies the statement.

**Proof.**  
The BFS colours the component with two parities, which is a proper
bipartition. The algorithm maps one parity to mode `1` and the other to
mode `2`. By Lemma&nbsp;2 this mapping satisfies all vertices of the
component. ∎



##### Lemma 4  
If the algorithm prints `NO`, no valid configuration exists.

**Proof.**  
`NO` is printed only when during BFS an edge connects two vertices with
the same colour, i.e. the component is not bipartite. By Lemma&nbsp;1 any
valid configuration would make the graph bipartite, contradiction. ∎



##### Lemma 5  
Assume the graph is bipartite. The configuration output by the algorithm
is lexicographically smallest among all valid configurations.

**Proof.**  
Consider one component `C`. Let `v0` be its smallest index.
The algorithm forces `x[v0]=1`. Any valid configuration must assign the
two modes to the two colour classes of `C`; therefore either `v0` gets
`1` or `2`. If it gets `2`, the whole sequence is lexicographically larger
at position `v0`. Hence any lexicographically minimal global solution
must also give `v0` value `1`. With this forced choice the remaining
vertices of `C` are uniquely determined (the opposite colour gets `2`).
Thus the algorithm’s assignment is the unique minimal one for this
component. Since components are independent and we minimise each
earliest index, the concatenation over all components is globally
lexicographically minimal. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff the required configuration does not exist;
* otherwise `YES` and the lexicographically smallest configuration that
  satisfies all constraints.

**Proof.**  

*If the algorithm prints `NO`* – by Lemma&nbsp;4 no configuration exists.  

*If the algorithm prints `YES`* – all components were bipartite, so by
Lemma&nbsp;3 the produced assignment satisfies every vertex.
By Lemma&nbsp;5 it is the lexicographically smallest among all such
assignments. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Building adjacency list*: `O(n + m)`  
*BFS over all components*: each vertex and edge processed once → `O(n + m)`  
*Memory*: adjacency list `O(n + m)`, arrays `O(n)`.

Both limits satisfy the given constraints (`n,m ≤ 2·10⁵`).

#### 6.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    g = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        g[u].append(v)
        g[v].append(u)

    col = [-1] * (n + 1)          # -1 = unvisited, 0/1 = parity
    ans = [0] * (n + 1)

    for start in range(1, n + 1):
        if col[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        col[start] = 0
        comp = [start]
        ok = True
        while q:
            v = q.popleft()
            for to in g[v]:
                if col[to] == -1:
                    col[to] = col[v] ^ 1
                    q.append(to)
                    comp.append(to)
                elif col[to] == col[v]:
                    print("NO")
                    return
        # decide orientation: smallest vertex gets mode 1
        v0 = min(comp)
        p = col[v0]
        for v in comp:
            ans[v] = 1 if col[v] == p else 2

    # output
    out = ["YES", " ".join(str(ans[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
