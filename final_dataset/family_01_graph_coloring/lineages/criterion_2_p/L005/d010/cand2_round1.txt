<STATEMENT>
# Problem B — Power Calibration

Time limit: 1 s
Memory limit: 256 MB

An industrial facility operates a network of $n$ automated machines. Each machine must be calibrated to a power mode of either 1 or 2.

The facility's safety system has identified $m$ critical pairs of machines. These pairs share a power bus, and their modes must be carefully balanced. 

To comply with the safety protocol and prevent dangerous harmonic cascades, the configuration must satisfy a strict network-wide condition. For each of the $m$ critical pairs $(u, v)$, the system generates a synchronization token by computing the sum of the cubes of the power modes of machines $u$ and $v$, and taking the remainder when this sum is divided by 9. The overall calibration is deemed safe if and only if the sum of all $m$ synchronization tokens equals exactly 0.

Your task is to find a calibration for all $n$ machines that satisfies this requirement, or determine that no such calibration exists.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of machines and the number of critical pairs, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a critical pair of machines. Machines are numbered from $1$ to $n$.

## Output
If it is impossible to safely calibrate the machines, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2\}$) representing the lexicographically smallest valid calibration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Replaced the conspicuous bitwise OR condition and its maximum sum with a modular polynomial evaluation ($c_u^3 + c_v^3 \bmod 9$). This removes the surface-level affordances that triggered the models' pattern matching. To succeed, a model must now genuinely evaluate the polynomial over the domain $\{1, 2\}$ to discover that the only roots occur when $c_u \neq c_v$.
</RATIONALE>
<PRESERVED_ANSWER>
The modular condition evaluates to 0 if and only if $c_u \neq c_v$ (since $1^3+1^3=2$, $2^3+2^3=16 \equiv 7$, and $1^3+2^3=9 \equiv 0$), which is the exact same constraint as the original bitwise OR summing to $3m$, ensuring every valid assignment remains perfectly identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains identical to finding the lexicographically smallest 2-coloring of a graph, which is solvable in $O(n+m)$ time using BFS or DFS, keeping the problem in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret 'remainder when this sum is divided by 9' if they assume some non-standard modulo behavior, but since the sum of cubes is always positive (2, 9, or 16), the standard mathematical remainder is universally non-negative and unambiguous.
</RISK>
