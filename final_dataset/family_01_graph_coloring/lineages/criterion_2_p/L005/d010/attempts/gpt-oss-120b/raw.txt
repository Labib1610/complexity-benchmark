**Solution Explanation**

For every machine `i`

* `d_i` – number of critical pairs containing `i`
* `x_i` – its power mode (`1` or `2`)

The safety system requires  

```
   sum of neighbours' modes  +  d_i * x_i   =   3 * d_i          (1)
```

--------------------------------------------------------------------

#### 1.   Reformulating the condition  

```
S_i = Σ_{j neighbour of i} x_j
```

From (1)

```
S_i = 3 d_i – d_i * x_i = d_i * (3 – x_i)
```

`x_i` can be only `1` or `2`

```
x_i = 1  →  S_i = 2 d_i
x_i = 2  →  S_i = 1 d_i
```

`S_i` is the sum of `d_i` numbers, each `1` or `2`.

*If `x_i = 1`* the only way to obtain `2 d_i` is that **all neighbours are `2`**.  
*If `x_i = 2`* the only way to obtain `1 d_i` is that **all neighbours are `1`**.

Therefore for every edge `{u,v}` the two ends must have opposite values:

```
x_u = 1  ⇔  x_v = 2
```

The whole graph has to be *bipartite* (2‑colourable).  
If a component contains an odd cycle the requirement is impossible.



--------------------------------------------------------------------

#### 2.   What has to be output  

*If the graph is not bipartite* → `NO`.

*Otherwise* we have a proper 2‑colouring.  
In each connected component we may exchange the two colours.
For the lexicographically smallest sequence `c_1 … c_n` we must give
value `1` to the **smallest numbered vertex of the component**,
because any other choice would make the first differing position larger.

Consequences  

* Process vertices in increasing order `1 … n`.
* When we meet an unvisited vertex `v` it is the smallest vertex of its
  component – start a BFS/DFS from `v` and colour it with colour `0`.
* During the search check bipartiteness (neighbour already coloured with
  the same colour → impossible).
* After the component is explored, output  

```
c_i = 1   if colour[i] == 0
c_i = 2   if colour[i] == 1
```

Thus the smallest vertex of the component receives `1` and the whole
assignment is lexicographically minimal.



--------------------------------------------------------------------

#### 3.   Algorithm
```
read n, m
build adjacency list
colour[1…n] = -1          // -1 = unvisited, 0/1 = two colours
answer[1…n]

for v = 1 … n
    if colour[v] == -1
        colour[v] = 0
        queue ← {v}
        while queue not empty
            u ← pop
            for each w in adj[u]
                if colour[w] == -1
                    colour[w] = colour[u] xor 1
                    push w
                else if colour[w] == colour[u]
                    print "NO" and exit
        // component finished, assign final values
        for each vertex x visited in this component
            answer[x] = 1 if colour[x] == 0 else 2

print "YES"
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `NO` iff no valid calibration exists,
otherwise prints `YES` and the lexicographically smallest valid calibration.

---

##### Lemma 1  
In any valid calibration, for every edge `{u,v}` the values satisfy
`x_u ≠ x_v`.

**Proof.**  
From the reformulation above, if `x_u = 1` all neighbours of `u` (including
`v`) must be `2`. If `x_u = 2` all neighbours must be `1`. In both cases
`x_v` is forced to be the opposite value. ∎



##### Lemma 2  
A calibration exists **iff** the graph is bipartite.

**Proof.**  

*If* the graph is bipartite, colour the two parts with `1` and `2`.  
Every edge connects different colours, therefore Lemma&nbsp;1 holds,
and the condition (1) is satisfied (each vertex sees only neighbours of the
other colour, giving the required sum).

*Only if* a calibration exists, by Lemma&nbsp;1 every edge connects vertices
with different values, i.e. a proper 2‑colouring of the graph. Hence the
graph is bipartite. ∎



##### Lemma 3  
During the BFS of a component the algorithm detects a conflict
(colour[w] == colour[u]) **iff** the component is not bipartite.

**Proof.**  
BFS colours vertices exactly as a standard 2‑colouring algorithm.
If an odd cycle exists, two adjacent vertices of the cycle receive the same
colour, producing a conflict. Conversely, if a conflict appears, there is an
edge whose ends have equal colour, which is impossible in a bipartite graph.
∎



##### Lemma 4  
If the algorithm finishes without printing `NO`, the produced assignment
satisfies the safety condition for every vertex.

**Proof.**  
By Lemma&nbsp;3 the graph is bipartite, therefore the assignment is a proper
2‑colouring. By Lemma&nbsp;1 this implies the condition (1) holds for every
vertex, i.e. the calibration is valid. ∎



##### Lemma 5  
For each connected component the algorithm assigns value `1` to its smallest
indexed vertex.

**Proof.**  
Components are processed in increasing order of their smallest vertex `v`.
When `v` is first encountered it is uncoloured, we start BFS from `v` and set
`colour[v]=0`. After the BFS we output `1` for colour `0`. Hence `v` receives
value `1`. ∎



##### Lemma 6  
Among all valid calibrations, the one output by the algorithm is
lexicographically smallest.

**Proof.**  
Consider the first index `i` where two valid calibrations differ.
Let `C` be the component containing `i`. All vertices with index `< i`
belong to components already processed, and by Lemma&nbsp;5 they all have
value `1` in our output, which is the minimum possible.
Inside component `C` the two possible colourings are exact opposites.
The smallest index of `C` is `v ≤ i`. By Lemma&nbsp;5 our calibration gives
`c_v = 1`. Any other valid calibration must give `c_v = 2` (otherwise it would
coincide with ours on `v`). Hence at position `v` (and therefore at the first
position where they differ) our value is smaller. Consequently the whole
sequence is lexicographically minimal. ∎



##### Theorem  
The algorithm prints  

* `NO` **iff** no calibration satisfying the safety condition exists;
* otherwise `YES` and the lexicographically smallest calibration.

**Proof.**  

*If* the algorithm prints `NO`, by Lemma&nbsp;3 a component is not bipartite,
hence by Lemma&nbsp;2 no calibration exists.

*If* a calibration does not exist, the graph is not bipartite (Lemma&nbsp;2),
so some component is non‑bipartite and the algorithm will encounter a conflict
and print `NO`.

If the algorithm prints `YES`, Lemma&nbsp;4 guarantees the produced assignment
is a valid calibration. Lemma&nbsp;6 shows it is the lexicographically
smallest among all valid calibrations. ∎

#### 5.   Complexity Analysis  

*Building adjacency list* : `O(n + m)` memory and time.  
*BFS over all components* : each vertex and edge processed once → `O(n + m)` time.  

Total  

```
Time   :  O(n + m)   ≤ 4·10⁵ operations
Memory :  O(n + m)   ≤ 4·10⁵ integers
```

Both satisfy the limits.

#### 6.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 = unvisited, 0/1 = two sides
    answer = [0] * (n + 1)

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # start is the smallest vertex of its component
        colour[start] = 0
        q = deque([start])
        component = [start]
        while q:
            u = q.popleft()
            cu = colour[u]
            for w in adj[u]:
                if colour[w] == -1:
                    colour[w] = cu ^ 1
                    q.append(w)
                    component.append(w)
                elif colour[w] == cu:
                    sys.stdout.write("NO")
                    return
        # assign final values: colour 0 -> 1, colour 1 -> 2
        for v in component:
            answer[v] = 1 if colour[v] == 0 else 2

    # all vertices processed, graph is bipartite
    out = ["YES", " ".join(str(answer[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
