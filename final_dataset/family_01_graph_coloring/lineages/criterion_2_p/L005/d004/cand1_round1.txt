<STATEMENT>
# Problem B — Frequency Calibration

Time limit: 1 s
Memory limit: 256 MB

An industrial facility manages a network of $n$ automated machines. The network is designed to support at least a single machine and up to a maximum capacity of two hundred thousand machines. Each machine must be configured to use one of two specific operational frequencies, which are designated by the values 1 and 2.

The facility's monitoring system has flagged $m$ adjacency pairs (where $m$ can range from zero up to the same maximum capacity as the machines). Each pair indicates two machines that are physically close enough to risk signal overlap. To guarantee safe operation, the system enforces a strict neighborhood interference protocol.

For any given machine, let $k$ be the number of adjacency pairs that include it. The protocol requires that the operational frequencies of its partner machines perfectly balance the given machine's own frequency. Specifically, the facility calculates a "harmonic stress" for each machine, defined as the sum of the cubes of the frequencies of all its partner machines. 

The configuration is deemed safe if and only if, for every machine in the network, its harmonic stress is exactly equal to $15k$ minus the product of $7k$ and its own frequency.

Your task is to determine a frequency configuration for all $n$ machines that satisfies this protocol for every machine, or determine that no such configuration is possible.

## Input
The first line provides two integers $n$ and $m$, representing the number of machines and the number of adjacency pairs, respectively.
The following $m$ lines each contain two integers $u$ and $v$ — a pair of machines listed in an adjacency pair.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit sum requirements from the seed problem ("sum is 2k" and "sum is k") have been replaced with a single unified polynomial equation involving the sum of cubes. Because $(15k - 7k \cdot 1) = 8k$ (forcing all neighbors to be 2) and $(15k - 7k \cdot 2) = k$ (forcing all neighbors to be 1), the mathematical requirement is identical, but models can no longer trigger their 2-coloring heuristics via surface-level text matching. They must algebraically evaluate the equation to deduce the bipartite structure. Bounds were also converted to text (Strategy S07).
</RATIONALE>
<PRESERVED_ANSWER>
The equation algebraically forces all adjacent machines to have the opposite frequency, which is exactly the same structural requirement as the seed problem, meaning the set of valid configurations (and the lexicographically smallest tie-break) is identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph (or detecting an odd cycle), which is solved using Breadth-First Search in O(n+m) time, keeping it in class P.
</PRESERVED_CLASS>
