Let me analyze the eigenvalue condition.

The matrix is:
$$S = \begin{pmatrix} 0 & x & y \\ x & 0 & 0 \\ y & 0 & 0 \end{pmatrix}$$

The characteristic polynomial is $\lambda(\lambda^2 - x^2 - y^2) = 0$, so eigenvalues are $0, \pm\sqrt{x^2+y^2}$.

The largest eigenvalue is $\sqrt{x^2+y^2}$, which must equal $\sqrt{5}$, so $x^2+y^2=5$.

With $x,y \in \{1,2\}$: $1+4=5$ ✓, $4+1=5$ ✓, $1+1=2$ ✗, $4+4=8$ ✗.

So each critical pair must have one machine with mode 1 and the other with mode 2 — this is a bipartite graph 2-coloring problem.

For lexicographically smallest: assign greedily, trying mode 1 first for each uncolored node, then BFS/DFS to propagate.

```python
import sys
from collections import deque

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * (n+1)
    
    for start in range(1, n+1):
        if color[start] != 0:
            continue
        color[start] = 1
        queue = deque([start])
        while queue:
            u = queue.popleft()
            for v in adj[u]:
                if color[v] == 0:
                    color[v] = 3 - color[u]
                    queue.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    return
    
    print("YES")
    print(' '.join(str(color[i]) for i in range(1, n+1)))

solve()
```
