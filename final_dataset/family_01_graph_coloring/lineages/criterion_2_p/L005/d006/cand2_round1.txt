<STATEMENT>
# Problem B — Power Calibration

Time limit: 1 s
Memory limit: 256 MB

An industrial facility manages a network of automated machines distributed along a $200$\,km pipeline. With exactly $1,000$ machine bays per kilometer, the total number of machines, $n$, is at least $1$ and at most the total number of bays. 

Each machine must be configured to a power setting of either 1 or 2.

The monitoring system has flagged $m$ interference pairs (where $m$ is between zero and the total number of bays). Each pair indicates two machines that are physically close enough to risk signal overlap. To guarantee safe operation, the system enforces a strict neighborhood interference protocol. 

For every flagged pair of machines, let their assigned settings be $x$ and $y$. The system evaluates their compatibility by constructing two virtual interference cylinders: the first cylinder has a radius of $x$ units and a height of $y$ units, while the second cylinder has a radius of $y$ units and a height of $x$ units. The protocol requires that for every flagged pair, the sum of the volumes of their two corresponding cylinders must be exactly $6\pi$ cubic units.

Your task is to determine a power setting configuration for all $n$ machines that satisfies this protocol for every pair, or determine that no such configuration is possible.

## Input
The first line provides two integers $n$ and $m$.
The following $m$ lines each contain two integers $u$ and $v$ — the IDs of a pair of machines listed as an interference pair. Machines are numbered from $1$ to $n$.

## Output
If no valid configuration exists, print a single line `NO`.
Otherwise print `YES`, then a second line with $n$ integers $s_1 \dots s_n$ (each in \{1,2\}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit matrix eigenvalue constraint with a geometric volume identity ($V_1 + V_2 = 6\pi$). This evaluates to exactly the same truth table for $\{1,2\}$, preserving the $x \neq y$ requirement, but prevents models from pattern-matching the standard "eigenvalue of a swapped matrix" to bipartite graph checking. I also applied S07 by bounding $n$ and $m$ using the capacity of a $200$\,km pipeline with $1,000$ bays per kilometer, securely encoding $2\cdot 10^5$.
</RATIONALE>
<PRESERVED_ANSWER>
The cylinder volume equation $\pi x^2 y + \pi y^2 x = 6\pi$ simplifies to $xy(x+y)=6$, which for $x,y \in \{1,2\}$ is true if and only if $x \neq y$, exactly matching the original matrix eigenvalue condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core requirement remains that every flagged pair must have distinct settings, so the problem is still bipartite 2-coloring, solvable in $O(n+m)$ using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
Models could theoretically misremember the standard formula for the volume of a cylinder, though the explicit provision of "radius" and "height" makes this highly unlikely.
</RISK>
