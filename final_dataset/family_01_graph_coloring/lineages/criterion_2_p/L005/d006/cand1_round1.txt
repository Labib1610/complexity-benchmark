<STATEMENT>
# Problem B — Power Calibration

Time limit: 1 s
Memory limit: 256 MB

An industrial facility manages a network of $n$ automated machines. Each machine must be configured to a power setting of either 1 or 2.

The facility's monitoring system has flagged $m$ adjacency pairs. Each pair indicates two machines that are physically close enough to risk signal overlap. To guarantee safe operation, the system enforces a strict neighborhood interference protocol. 

For every flagged pair of machines, let their assigned settings be $x$ and $y$. The system evaluates their compatibility by analyzing their combined continuous waveform over a standard calibration interval. Specifically, their interference score is calculated as the definite integral:
$$S = \int_{0}^{\pi} \left( \cos((x - y)\theta) - \cos((x + y)\theta) \right) d\theta$$
The protocol requires that for every flagged pair, their interference score $S$ must be exactly 0.

Your task is to determine a power setting configuration for all $n$ machines that satisfies this protocol for every pair, or determine that no such configuration is possible.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$ — a pair of machines listed in an adjacency pair. Machines are numbered from $1$ to $n$.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The affordance of a $2 \times 2$ matrix and its eigenvalues immediately triggered memorized pattern-matching for $x+y$ and $x-y$, allowing models to bypass reasoning about the constraint's origin. By replacing the matrix with a definite integral of trigonometric functions, models must now genuinely evaluate the calculus (or recognize Fourier orthogonality) to deduce that $S=0$ strictly enforces $x \neq y$. This breaks the direct lexical association with eigenvalues while preserving the exact mathematical constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The definite integral evaluates to 0 when $x \neq y$ (since both cosine terms integrate to 0) and evaluates to $\pi$ when $x = y$ (since $\cos(0) = 1$ integrates to $\pi$), so the valid configurations remain exactly those where no two flagged machines share the same setting.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The condition still algebraically reduces to requiring opposite settings across every given edge, meaning the problem remains identical to bipartite 2-coloring, which is solvable in linear time using Breadth-First Search.
</PRESERVED_CLASS>
