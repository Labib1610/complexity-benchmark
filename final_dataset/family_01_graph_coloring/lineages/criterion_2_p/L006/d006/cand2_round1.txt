<STATEMENT>
# Problem B — System Equilibrium

Time limit: 1 s   Memory limit: 256 MB

You are tasked with finding a state vector $S = (s_1, s_2, \dots, s_n)$ such that $s_i \in \{1, 2\}$ for all $1 \le i \le n$, which puts a simulated system into equilibrium.

The system consists of $n$ particles and a log of $m$ interactions.
Each particle $i$ must be assigned a state $s_i \in \{1, 2\}$. Depending on its state, it emits a $2 \times 2$ signature matrix $M_i$:
- If $s_i = 1$, $M_i = \begin{pmatrix} 5 & 12 \\ 12 & -5 \end{pmatrix}$.
- If $s_i = 2$, $M_i = \begin{pmatrix} 12 & -5 \\ -5 & -12 \end{pmatrix}$.

Each of the $m$ logged interactions involves two particles, denoted as $u_j$ and $v_j$ for the $j$-th interaction. The interference generated by this interaction is given by the matrix anti-commutator of their signature matrices:
$C_j = M_{u_j} M_{v_j} + M_{v_j} M_{u_j}$

The overall system is in equilibrium if and only if the global interference matrix, defined as the sum of $C_j$ over all $m$ logged interactions, is exactly the $2 \times 2$ zero matrix:
$\sum_{j=1}^m C_j = \begin{pmatrix} 0 & 0 \\ 0 & 0 \end{pmatrix}$

If there are multiple valid state vectors $S$ that satisfy the equilibrium condition, you must output the sequence $s_1 \dots s_n$ that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the indices of the two particles involved in the $j$-th interaction. The interactions are given in order for $j = 1, 2, \dots, m$.

## Output
If no such vector $S$ exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$) representing the elements of the lexicographically smallest valid vector $S$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

</PRESERVED_ANSWER>
