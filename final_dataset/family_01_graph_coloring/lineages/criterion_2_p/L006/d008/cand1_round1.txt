<STATEMENT>
# Problem B — Quantum Equilibrium

Time limit: 1 s   Memory limit: 256 MB

You are simulating a system of $n$ quantum particles to find a stable configuration. For the system to reach equilibrium, each particle $i$ must be assigned an energy level $c_i \in \{1, 2\}$.

The system log contains $m$ elementary entanglements. Each entanglement involves two particles $u$ and $v$. 
The local amplitude of a single entanglement between particle $u$ and particle $v$ is defined mathematically as the sum of their cubed energy levels: $c_u^3 + c_v^3$.

The interaction amplitude of the entire system is the product of the local amplitudes of all $m$ logged entanglements. 
To achieve equilibrium, this total interaction amplitude must be exactly $9^m$.

If there are multiple valid energy level assignments that satisfy this equilibrium requirement, you must output the sequence $c_1 \dots c_n$ that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the indices of the two particles involved in the $j$-th logged entanglement. The entanglements are given in order for $j = 1, 2, \dots, m$.

## Output
If no such assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1 \dots c_n$ (where each $c_i \in \{1,2\}$) representing the elements of the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit $c_u \times c_v = 2$ local constraint was removed and replaced with a global product condition over $m$ terms. To realize this is still a bipartite graph coloring problem, the model must deduce via unique prime factorization that a product of terms from $\{2, 9, 16\}$ can only equal $9^m$ if every single term is exactly 9, which then forces $c_u \neq c_v$.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $c_u^3 + c_v^3 = 9$ holds if and only if one energy level is 1 and the other is 2, making it mathematically identical to the original $c_u \times c_v = 2$ requirement for every pair.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) on an undirected graph, keeping it firmly in P and solvable in O(N+M) time.
</PRESERVED_CLASS>

A model might interpret "total interaction amplitude must be exactly $9^m$" as requiring literal arbitrary-precision arithmetic evaluation in code rather than treating it as a mathematical constraint to be simplified, though standard competitive programming models usually recognize this phrasing as a theoretical condition.
</RISK>
