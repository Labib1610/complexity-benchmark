# Problem B — Quantum Decoherence

Time limit: 1 s   Memory limit: 256 MB

You are configuring a quantum computing cluster to find a stable phase configuration. For the cluster to reach stability, each processor $i$ must be assigned a phase state $s_i \in \{1, 2\}$.

The calibration log contains $m$ elementary entanglements. Each entanglement involves a pair of processors, given as $u$ and $v$.
According to the resonance principles of the cluster, an entanglement between $u$ and $v$ is stable if and only if the resonance signature $4s_u - s_v$ evaluates to either 2 or 7.

To achieve a stable cluster, every logged entanglement must satisfy this condition.
(Note: If a logged entanglement involves the same processor twice, meaning $u = v$, its resonance signature would be $3s_u$, which can only evaluate to 3 or 6. This immediately violates the stability requirement and causes decoherence).

If there are multiple valid phase state assignments that satisfy all logged entanglements, you must output the sequence $s_1 \dots s_n$ that is lexicographically smallest.

## Input
The quantum cluster is built on a mainframe with exactly $200,000$ hardware slots, establishing the strict upper limit for the number of processors $n$. The telemetry buffer is similarly constrained to exactly $200,000$ rows, capping the number of logged entanglements $m$. There is always at least one processor installed, while the entanglement count can be zero. Processors are identified by integers from 1 up to $n$.

The first line contains two integers $n$ and $m$.
Each of the following $m$ lines contains two integers $u$ and $v$ — the indices of the two processors involved in the $j$-th logged entanglement. The entanglements are given in order for $j = 1, 2, \dots, m$.

## Output
If no such assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$) representing the elements of the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The direct product constraint `c_u * c_v = 2` was replaced with the asymmetric linear combination `4s_u - s_v in {2, 7}`. This evaluates to true if and only if the two variables take opposite values from `{1, 2}`. This perfectly preserves the undirected bipartite constraint while mimicking a directed, complex algebraic condition, defeating pattern-matching on bipartite coloring. Numeric bounds were also rewritten as physical hardware limits (S07).
</RATIONALE>
<PRESERVED_ANSWER>
The condition `4s_u - s_v in {2, 7}` for `s_i in {1, 2}` is mathematically identical to `s_u != s_v`, so exactly the same assignments are valid and the lexicographical tie-breaker produces the exact same sequence.
</PRESERVED_ANSWER>
