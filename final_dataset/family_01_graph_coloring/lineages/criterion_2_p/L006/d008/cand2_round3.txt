This breaks LLMs that rely on pattern-matching the multiplication condition to bipartite coloring.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Phase Balancing

Time limit: 1 s   Memory limit: 256 MB

You are calibrating a network of $n$ oscillators to find a stable configuration. For the network to reach stability, each oscillator $i$ must be tuned to a phase state $p_i \in \{1, 2\}$.

The system log contains $m$ interference links. Each link connects two oscillators $u$ and $v$.
To prevent destructive interference, the phase states of the two oscillators on each link must satisfy the following non-linear phase condition:
$3p_u + 3p_v - 2p_u p_v = 5$

To achieve stability, every logged link must satisfy this condition.
(Note: If a logged link connects an oscillator to itself, meaning $u = v$, the expression evaluates to $6p_u - 2p_u^2$, which can only equal 4 for $p_u \in \{1,2\}$. This immediately violates the stability requirement and makes calibration impossible).

If there are multiple valid phase assignments that satisfy all logged links, you must output the sequence $p_1 \dots p_n$ that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the indices of the two oscillators connected by the $j$-th link. The links are given in order for $j = 1, 2, \dots, m$.

## Output
If no such assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $p_1 \dots p_n$ (where each $p_i \in \{1,2\}$) representing the elements of the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The mass-action rate condition `c_u * c_v = 2` was a dead giveaway for bipartite coloring, as 1 and 2 multiply to 2 only if they are distinct. This rewrite substitutes the multiplication with a symmetric algebraic condition `3x + 3y - 2xy = 5` which evaluates to exactly the same truth table over `{1,2}` but requires algebraic simplification or case-testing to realize it forces inequality. The explicit numeric bounds from the seed have been fully restored to the Input section to satisfy the strict I/O contract check.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic condition `3x + 3y - 2xy = 5` over the domain `{1, 2}` is satisfied if and only if `x != y`, which is identically equivalent to `x * y = 2`, preserving the exact same valid assignments and lexicographical order.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) on an undirected graph, solvable in O(n + m) time using BFS or DFS.
</PRESERVED_CLASS>
