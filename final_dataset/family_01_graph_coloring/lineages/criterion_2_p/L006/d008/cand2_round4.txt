# Problem B — Sensor Network Calibration

Time limit: 1 s   Memory limit: 256 MB

You are calibrating a network of $n$ sensors. Each sensor $i$ must be configured with a discrete power setting $p_i \in \{1, 2\}$.

The system has $m$ critical interference channels. Each channel connects a pair of sensors $u$ and $v$. 
To ensure signal integrity, the power settings for any two sensors sharing a channel must satisfy the condition:
$p_u^3 + p_v^3 = 9$

If there are multiple valid configurations that satisfy this condition for all $m$ channels, you must output the sequence $p_1 \dots p_n$ that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ — the indices of the two sensors sharing a critical channel.

## Output
If no such configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $p_1 \dots p_n$ (where each $p_i \in \{1,2\}$) representing the elements of the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Replaced the explicit product constraint with a cubic polynomial sum ($p_u^3 + p_v^3 = 9$). This forces the model to algebraically deduce that the only valid pairs from $\{1, 2\}$ are $(1, 2)$ and $(2, 1)$, before it can recognize the underlying bipartite graph structure. I also removed extraneous explanations about self-loops to prevent the model from deriving graph-theoretic rules directly from the text.
</RATIONALE>
<PRESERVED_ANSWER>
Since the domain is strictly restricted to {1, 2}, the sum of cubes can only be 9 if one variable is 1 and the other is 2; this perfectly preserves the mutual exclusion constraint originally enforced by the product equaling 2.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
