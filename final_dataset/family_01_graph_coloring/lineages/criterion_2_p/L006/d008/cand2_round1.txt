<STATEMENT>
# Problem B — Orbital Resonance

Time limit: 1 s
Memory limit: 256 MB

You are designing a 1D orbital configuration for $n$ satellites. Each satellite $i$ ($1 \le i \le n$) must be assigned an integer position $c_i$ along the X-axis, placing it at the spatial coordinates $(c_i, 0, 0)$.

The system is governed by $m$ resonance constraints. Each constraint involves two satellites $u$ and $v$. For the system to be stable, their positions must satisfy a specific geometric condition: the surface of the sphere having the line segment between $(c_u, 0, 0)$ and $(c_v, 0, 0)$ as a diameter must contain the exact point $(1.5, 0.4, 0.3)$ in 3D space. 
*(Note: if $c_u = c_v$, the diameter is zero, and the sphere degenerates to a single point. This point must still exactly match the anomaly's coordinates to satisfy the constraint).*

If there are multiple valid assignments of integer positions $c_1 \dots c_n$ that satisfy all $m$ constraints, you must output the sequence $c_1 \dots c_n$ that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the indices of the two satellites involved in the $j$-th resonance constraint. The constraints are given in order for $j = 1, 2, \dots, m$.

## Output
If no such assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1 \dots c_n$ representing the positions of the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit `{1, 2}` domain and the `c_u × c_v = 2` constraint with a 3D geometric condition: a sphere with diameter endpoints at `(c_u, 0, 0)` and `(c_v, 0, 0)` must contain the point `(1.5, 0.4, 0.3)`. This expands algebraically to `(1.5-c_u)(1.5-c_v) + 0.25 = 0`, which simplifies to the Diophantine equation `(2c_u-3)(2c_v-3)=-1`. The only integer solutions are `{1, 2}`, which perfectly encodes the bipartite 2-coloring constraint while hiding it behind continuous-looking geometry. Models must now algebraically reduce the 3D geometry to discover the discrete graph coloring structure.
</RATIONALE>
<PRESERVED_ANSWER>
The geometric condition perfectly reduces to the integer Diophantine equation `(2c_u-3)(2c_v-3)=-1`, whose only integer solutions are exactly `c_u, c_v ∈ {1, 2}` with `c_u ≠ c_v`, making the valid assignments and their lexicographical order identical to the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding a valid 2-coloring of an undirected graph (or determining none exists), which is solvable in O(n+m) time using BFS/DFS, keeping it in P.
</PRESERVED_CLASS>
