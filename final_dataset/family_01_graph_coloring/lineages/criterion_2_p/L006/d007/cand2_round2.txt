<STATEMENT>
# Problem B — Cluster Anti-Affinity

Time limit: 1 s   Memory limit: 256 MB

You are configuring a network of $n$ servers. Each server must be assigned to exactly one of two available clusters, designated as Cluster 1 and Cluster 2. Let $s_i \in \{1, 2\}$ represent the cluster assigned to server $i$.

You are provided with a log of $m$ anti-affinity rules. Each rule specifies two servers, $u$ and $v$, which share a critical resource. To ensure fault tolerance, the cluster assignments for these two servers must satisfy the following balancing equation:
$s_u + s_v = 3$

This equation must hold for every rule in the log. Note that if a rule specifies the same server twice (i.e., $u = v$), the equation becomes $2s_u = 3$. Since cluster assignments must be integers, this has no valid solution and the configuration is impossible.

Your task is to find a valid cluster assignment for all $n$ servers. If there are multiple valid assignments that satisfy all $m$ rules, you must output the sequence $s_1 \dots s_n$ that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the indices of the two servers involved in the $j$-th anti-affinity rule. The rules are given in order for $j = 1, 2, \dots, m$.

## Output
If no such sequence $S$ exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$) representing the elements of the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
