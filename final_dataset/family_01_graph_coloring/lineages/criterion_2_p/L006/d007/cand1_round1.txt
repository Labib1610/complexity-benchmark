# Problem B — System Equilibrium

Time limit: 1 s   Memory limit: 256 MB

You are tasked with finding a state vector $S = \begin{pmatrix} s_1 \\ s_2 \\ \vdots \\ s_n \end{pmatrix}$ such that $s_i \in \{1, 2\}$ for all $1 \le i \le n$, which puts a simulated system into equilibrium.

The system consists of $n$ particles. A log contains $m$ interactions, where each interaction involves two particles $u$ and $v$.
The equilibrium of the system requires that the actual assigned state vector $S$ satisfies a strict stability condition for every logged interaction. 

For every logged interaction between particle $u$ and particle $v$, the following two hypothetical conditions must both hold true:
- If we were to hypothetically assign a value of 1 to the state(s) of the specific particle(s) involved in this interaction (leaving the states of all other particles unchanged), the sum of all $n$ particles' states in the system must become strictly less than its actual sum.
- If we were to hypothetically assign a value of 2 to the state(s) of the specific particle(s) involved in this interaction (leaving the states of all other particles unchanged), the sum of all $n$ particles' states in the system must become strictly greater than its actual sum.

If these conditions are violated for any interaction in the log, the system fails to reach equilibrium. Note that if an interaction logs the same particle twice (i.e., $u = v$), the hypothetical assignment applies to that single particle, which may immediately destabilize the system.

If there are multiple valid state vectors $S$ that satisfy the stability conditions for all interactions, you must output the sequence $s_1 \dots s_n$ that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the indices of the two particles involved in the $j$-th interaction. The interactions are given in order for $j = 1, 2, \dots, m$.

## Output
If no such vector $S$ exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$) representing the elements of the lexicographically smallest valid vector $S$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

I replaced the four explicit implication rules (which trivially mapped to $s_u \neq s_v$) with a global perturbation constraint. The model must now algebraically deduce that hypothetically overriding the states to 1 or 2 and checking the global sum strictly decreasing/increasing mathematically simplifies to $s_u + s_v = 3$, forcing the model to discover the bipartite nature itself.
</RATIONALE>
<PRESERVED_ANSWER>
The perturbation conditions mathematically simplify to exactly $s_u \neq s_v$ for all $u \neq v$, and inherently fail for $u=v$, which is precisely the same constraint as the original implication rules.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring a graph and choosing the lexicographically smallest valid assignment (solvable in O(n+m) via BFS), keeping it in P.
</PRESERVED_CLASS>

Models might misinterpret "leaving the states of all other particles unchanged" if they fail to realize the hypothetical override applies to both $u$ and $v$ simultaneously, but "particle(s) involved" and the singular/plural notation makes it sufficiently clear.
</RISK>
