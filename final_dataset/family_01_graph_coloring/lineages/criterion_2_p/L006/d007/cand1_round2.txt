# Problem B — System Equilibrium

Time limit: 1 s   Memory limit: 256 MB

You are tasked with finding a state vector $S = \begin{pmatrix} s_1 \\ s_2 \\ \vdots \\ s_n \end{pmatrix}$ such that $s_i \in \{1, 2\}$ for all $1 \le i \le n$, which puts a simulated system into equilibrium.

The system consists of $n$ particles and a log of $m$ interactions. Each interaction involves two particles $u$ and $v$.
The equilibrium of the system is governed by a strict local rule applied to every logged interaction.

For each logged interaction between particle $u$ and particle $v$, we define the $3 \times 3$ interaction matrix $M_{u,v}$ as follows:
$$M_{u,v} = \begin{pmatrix} s_u & 1 & 0 \\ 0 & s_v & 1 \\ 2 & 0 & 1 \end{pmatrix}$$

To maintain equilibrium, the determinant of this matrix must be exactly 4. That is, $\det(M_{u,v}) = 4$.

If this determinant condition is violated for any interaction in the log, the system fails to reach equilibrium. Furthermore, if any logged interaction involves the same particle twice (i.e., $u = v$), the exact same determinant rule applies, meaning $\det(M_{u,u})$ must equal 4. Since $s_u \in \{1, 2\}$, this is mathematically impossible, and such an interaction will immediately prevent equilibrium.

If there are multiple valid state vectors $S$ that satisfy this condition for all interactions, you must output the sequence $s_1 \dots s_n$ that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the indices of the two particles involved in the $j$-th interaction. The interactions are given in order for $j = 1, 2, \dots, m$.

## Output
If no such vector $S$ exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$) representing the elements of the lexicographically smallest valid vector $S$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
