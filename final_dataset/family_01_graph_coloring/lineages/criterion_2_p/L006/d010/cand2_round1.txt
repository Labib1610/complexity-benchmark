<METHOD_NAME>Linear Transformation Involutions</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the discrete permutation constraint (which trivially reduces to inequality) with continuous linear transformations over R^2. The two states are assigned matrices A and B such that A^2 = I, B^2 = I, but AB and BA have no eigenvalues equal to 1. This preserves the bipartite 2-coloring structure exactly, but requires the model to perform matrix algebra or symbolic evaluation to discover the inequality constraint, defeating models that rely on recognizing the permutation derangement pattern.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Network Configuration

Time limit: 1 s   Memory limit: 256 MB

You are configuring a network of $n$ modules. Each module $i$ must be assigned a configuration state $s_i \in \{1, 2\}$.

These configurations apply a linear transformation to a 2-dimensional continuous signal vector $X = (x, y) \in \mathbb{R}^2$.
- State $s_i = 1$ configures the module to apply the transformation $T_1(x, y) = (2x + y, -3x - 2y)$.
- State $s_i = 2$ configures the module to apply the transformation $T_2(x, y) = (7x + 12y, -4x - 7y)$.

The system log contains $m$ active connections. Each connection involves two modules $u$ and $v$. 
When a connection is active, a signal passes through module $u$'s transformation and then immediately through module $v$'s transformation, resulting in the combined transformation $T_v(T_u(x, y))$. 

To ensure safe data transfer without resonance, the combined effect of these two transformations must not have any non-zero fixed points. That is, there must be no signal $X = (x, y) \neq (0, 0)$ such that $T_v(T_u(X)) = X$.

(Note: If a logged connection involves the same module twice, meaning $u = v$, the signal passes through the identical transformation twice. For both state 1 and state 2, applying the exact same transformation twice restores the signal exactly to its original state. This means every signal $X$ becomes a fixed point, immediately violating the requirement and destabilizing the network).

If there are multiple valid state assignments that satisfy all logged connections, you must output the sequence $s_1 \dots s_n$ that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the indices of the two modules involved in the $j$-th logged connection. The connections are given in order for $j = 1, 2, \dots, m$.

## Output
If no such assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$) representing the elements of the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The seed problem's permutation logic trivially reduced to $s_u \neq s_v$ because the composition of the two derangements was obvious. I replaced the discrete permutations with linear transformations over $\mathbb{R}^2$. The matrices for $T_1$ and $T_2$ are involutions ($T^2 = I$), so $s_u = s_v$ yields the identity matrix (which has infinite fixed points, violating the condition). However, $T_1 \circ T_2$ and $T_2 \circ T_1$ are matrices with no eigenvalue equal to 1, meaning their only fixed point is the zero vector, which satisfies the condition. This forces models to algebraically evaluate the compositions to discover the underlying $s_u \neq s_v$ bipartite constraint.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the combined transformation has no non-zero fixed points is mathematically equivalent to $s_u \neq s_v$, so the valid assignments and tie-breaking remain exactly identical for every input.
</PRESERVED_ANSWER>
