We can model this as a bipartite graph problem: each worker is a node, and incompatible pairs are edges. We need to assign each node to one of two schedules (colors 1 or 2) such that no edge connects two nodes of the same color. This is exactly checking if the graph is bipartite, and if so, finding the lexicographically smallest coloring.

We can do a BFS/DFS over each connected component, assigning colors alternately. To get the lexicographically smallest arrangement, we should try to assign color 1 to the smallest-index node in each component when possible, and propagate.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 0  # 0 means schedule 1, 1 means schedule 2
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = color[u] ^ 1
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
