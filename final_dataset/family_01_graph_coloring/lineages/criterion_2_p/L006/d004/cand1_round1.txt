<METHOD_DESCRIPTION>
Transforms the 2-coloring graph problem into an Integer Linear Programming (ILP) format. The pairwise constraint is rewritten as a linear equation $s_u + s_v = 3$, and the "lexicographically smallest" tie-breaker is replaced by a mathematically equivalent continuous objective function $\sum s_i 2^{-i}$. This defeats models that rely on keyword matching for graph algorithms, forcing them to either use slow generic solvers (which TLE) or fail to handle the precision of the objective function if they don't deduce its equivalence to lexicographical order.
</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — State Optimization

Time limit: 1 s   Memory limit: 256 MB

A fluid control facility contains $n$ automated valves, labeled 1 through $n$. Every valve must be assigned an operational integer state $s_i \in \{1, 2\}$.

The network is supervised by $m$ pressure monitors. Each monitor is linked to a specific pair of valves. For the network to achieve equilibrium, every monitor must verify that the sum of the operational states of its two linked valves is exactly 3.

You must determine whether a valid configuration $s = (s_1, \dots, s_n)$ exists that satisfies all $m$ monitors. If there are several valid configurations, you must output the one that minimizes the objective function:
$f(s) = \sum_{i=1}^n s_i \cdot 2^{-i}$

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$) — the labels of the two valves linked to a single monitor.

## Output
If no such configuration is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$) representing the valid configuration that minimizes $f(s)$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I changed the pairwise relation to a linear equation ($s_u + s_v = 3$) and the lexicographical tie-breaker to a mathematically equivalent exponential sum objective. This forces the model to deduce that this ILP formulation is actually a 2-coloring problem on independent graph components, and that the objective function strictly enforces lexicographical order, preventing them from using the independent-orientation logic without this deduction.
</RATIONALE>
<PRESERVED_ANSWER>
The constraint $s_u + s_v = 3$ for $s_i \in \{1, 2\}$ is exactly equivalent to one state being 1 and the other 2, and the objective function $\sum s_i 2^{-i}$ is strictly minimized by the lexicographically smallest sequence, ensuring all valid configurations and the chosen optimal configuration remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains solvable in $O(n+m)$ using the exact same greedy BFS 2-coloring algorithm, as the underlying graph structure and component-wise optimal choices are mathematically unchanged.
</PRESERVED_CLASS>
<RISK>
Models might attempt to evaluate the objective function using standard floating-point arithmetic and fail due to precision limits for large $n$, though mathematically the specification is exact and unambiguous.
</RISK>
