# Problem B — System Equilibrium

Time limit: 1 s   Memory limit: 256 MB

A fluid control facility contains $n$ automated valves, labeled 1 through $n$. The system's protocol dictates that every valve must be assigned an operational state $s_i \in \{1, 2\}$.

The network is supervised by $m$ pressure monitors. Each monitor is linked to a specific pair of valves, $u$ and $v$. For the network to achieve equilibrium, every monitor must verify that the $2 \times 2$ state matrix 
$$ M = \begin{pmatrix} s_u & 1 \\ 2 & s_v \end{pmatrix} $$
is singular (its determinant must be exactly zero). Note that the order of $u$ and $v$ in this matrix does not affect its determinant.

You must determine whether a configuration exists that satisfies all monitors. If there are several valid configurations for the $n$ valves, you must output the sequence of states $s_1 \dots s_n$ that minimizes the system's total harmonic resonance. The resonance is defined exactly as the value of the sum:
$$ \sum_{i=1}^n s_i \cdot 3^{n-i} $$

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ — the labels of the two valves linked to a single monitor.

## Output
If no such configuration is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$) representing the valid configuration that minimizes the harmonic resonance.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

I replaced the explicit "one is twice the other" constraint with a mathematically equivalent condition requiring a 2x2 state matrix to have a determinant of zero. I also replaced the "lexicographically smallest" tie-breaker with the mathematically equivalent objective of minimizing a base-3 polynomial. This obfuscates both the bipartite nature of the constraints and the independence of the components, forcing models to algebraically deduce that the problem is still bipartite 2-coloring with lexicographical tie-breaking.
</RATIONALE>
<PRESERVED_ANSWER>
The singular matrix condition exactly forces $\{s_u, s_v\} = \{1, 2\}$ just like the original problem, and minimizing the base-3 polynomial is mathematically identical to finding the lexicographically smallest valid sequence.
</PRESERVED_ANSWER>
