**Solution Explanation**

For every given pair `(u , v)` the corresponding row of the matrix `M` contains  

```
M[j][u] = 1 ,  M[j][v] = 1          (if u != v)
M[j][u] = 2                         (if u == v)
```

The equation `M·S = 3` for this row becomes  

```
s_u + s_v = 3          (if u != v)
2·s_u = 3              (if u == v)
```

` s_i ` may only be `1` or `2`.

* `2·s_u = 3` has no integer solution → any pair with `u = v` makes the whole
  system impossible.

* For `u != v` we need `s_u + s_v = 3`.  
  The only possibilities are `(s_u , s_v) = (1,2)` or `(2,1)`.  
  Thus the two vertices must obtain **different** values.

Consequently the whole problem is exactly a *2‑colouring* (bipartite
checking) of the undirected graph whose vertices are `1 … n` and whose
edges are the given pairs.

--------------------------------------------------------------------

#### 1.   Graph model
* vertices `1 … n`
* for each input pair `(u , v)` (`u != v`) add an undirected edge `u – v`
* if any pair has `u = v` → answer `NO`

--------------------------------------------------------------------

#### 2.   Bipartite check & colour assignment
Depth‑first (or breadth‑first) search over each connected component.

* store temporary colour `c[v] ∈ {0,1}` (`0` will later become value `1`,
  `1` will become value `2`)
* while traversing, if we meet an already coloured neighbour with the same
  colour → the component is not bipartite → answer `NO`.

All vertices of a component are collected in a list `comp`.

--------------------------------------------------------------------

#### 3.   Lexicographically smallest solution
Inside one component we may flip all colours (`0 ↔ 1`) and still satisfy
all equations.  
To obtain the globally lexicographically smallest vector we act greedily:

* let `p = min(comp)` – the smallest index belonging to this component
* if `c[p] == 1` we flip the whole component (i.e. replace `c[v]` by `1-c[v]`)
  otherwise we keep it.

Why is this optimal?  
All positions `< p` belong to earlier components and are already fixed.
Choosing the colour of `p` as `1` (the smallest possible value) makes the
overall sequence as small as possible, and later positions cannot influence
the earlier ones. Repeating this for every component yields the minimal
lexicographic vector.

Finally set  

```
answer[i] = 1  if c[i] == 0 else 2
```

Isolated vertices (components of size 1 without edges) are handled the same
way – their minimum is themselves, we keep colour `0` → value `1`.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `NO` iff no suitable vector exists,
otherwise prints `YES` and the lexicographically smallest valid vector.

---

##### Lemma 1  
If any input pair has `u = v` the system has no solution.

**Proof.** The corresponding equation is `2·s_u = 3`.  
Since `s_u ∈ {1,2}`, the left side is `2` or `4`, never `3`. ∎



##### Lemma 2  
For a component without self‑loops, a vector `S` satisfies all its equations
iff the vertices can be coloured with two colours such that adjacent vertices
receive different colours, and the values are obtained by mapping colour 0 →
`1`, colour 1 → `2`.

**Proof.**  
*If* the colouring exists, every edge `{u,v}` has opposite colours, i.e.
`c[u] ≠ c[v]`. Hence `{s_u , s_v}` = `{1,2}` and `s_u + s_v = 3`.  
*Only‑if*: suppose a vector `S` satisfies all equations of the component.
For each edge `{u,v}` we have `s_u + s_v = 3`, therefore `{s_u , s_v}` = `{1,2}`
and the two vertices are different. Define `c[x]=0` when `s_x=1`,
`c[x]=1` when `s_x=2`. Adjacent vertices obtain different colours. ∎



##### Lemma 3  
A component admits a solution **iff** it is bipartite.

**Proof.** By Lemma&nbsp;2 a solution ⇔ a 2‑colouring exists ⇔ the component is
bipartite. ∎



##### Lemma 4  
For a bipartite component, among the two possible colourings the one that
assigns colour 0 to the smallest indexed vertex of the component yields the
lexicographically smallest values for all vertices of this component,
independently of other components.

**Proof.** The two colourings are exact complements.
All vertices with index larger than the minimum keep the same relative order
in both colourings; only the minimum vertex changes between `1` and `2`.
Choosing `1` (colour 0) makes the first differing position as small as possible,
hence the whole component’s contribution to the global sequence is minimal.
Since components are disjoint, later components cannot affect earlier indices. ∎



##### Lemma 5  
The algorithm outputs a vector that satisfies all equations whenever a
solution exists.

**Proof.**  
* If a self‑loop exists, by Lemma 1 no solution exists and the algorithm
  prints `NO`.  
* Otherwise the algorithm checks each component for bipartiteness.
  By Lemma 3 a solution exists ⇔ every component is bipartite.
  The algorithm aborts with `NO` exactly when a component is not bipartite.
* For a bipartite component it builds a 2‑colouring (standard BFS) that
  respects all edges, then possibly flips it. Flipping does not break the
  property that adjacent vertices have opposite colours.
  Mapping colours to `{1,2}` therefore satisfies every equation
  (Lemma 2). ∎



##### Lemma 6  
If a solution exists, the vector produced by the algorithm is the
lexicographically smallest among all solutions.

**Proof.** Consider components ordered by their minimal vertex index.
Processing proceeds in that order.  
When the algorithm handles a component, all earlier vertices are already set
to the smallest possible values (induction hypothesis).  
By Lemma 4 the algorithm chooses the colouring that makes the smallest
vertex of the current component equal to `1`. Any other feasible solution
must have the same prefix (earlier components) and at the current minimal
vertex cannot be smaller than `1`. Hence after fixing this component the
prefix up to its largest vertex is also minimal. Induction finishes with the
entire vector minimal. ∎



##### Theorem  
The algorithm prints  

* `NO` iff the system has no solution,  
* otherwise `YES` and the lexicographically smallest vector `S` with
  `s_i ∈ {1,2}` satisfying `M·S = 3`.

**Proof.**  
*If* the algorithm prints `NO`, either a self‑loop existed (Lemma 1) or a
non‑bipartite component was found. Both cases make a solution impossible
(Lemmas 1 and 3).  
*If* a solution exists, the algorithm never aborts (Lemma 3) and by
Lemma 5 outputs a valid vector. By Lemma 6 this vector is the lexicographically
smallest one. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis
*Building the graph* – `O(m)` time, `O(n+m)` memory.  
*BFS over all components* – each vertex and edge visited once: `O(n+m)` time,
`O(n)` extra memory for colour array and queues.  

Overall: **`O(n + m)` time**, **`O(n + m)` memory**, well within the limits.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        if u == v:          # self‑loop -> impossible
            print("NO")
            return
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 = unvisited, 0 or 1 otherwise
    answer = [0] * (n + 1)

    from collections import deque

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # start a new component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        bip = True
        while q:
            v = q.popleft()
            for to in adj[v]:
                if colour[to] == -1:
                    colour[to] = colour[v] ^ 1
                    q.append(to)
                    comp.append(to)
                elif colour[to] == colour[v]:
                    bip = False
        if not bip:
            print("NO")
            return

        # make the smallest index vertex have colour 0
        min_v = min(comp)
        if colour[min_v] == 1:
            for v in comp:
                colour[v] ^= 1

    for i in range(1, n + 1):
        answer[i] = 1 if colour[i] == 0 else 2

    print("YES")
    print(' '.join(str(answer[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
