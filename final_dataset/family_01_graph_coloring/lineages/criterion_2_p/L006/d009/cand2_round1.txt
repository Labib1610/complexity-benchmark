<STATEMENT>
# Problem B — Network Configuration

Time limit: 1 s
Memory limit: 256 MB

You are configuring a network of $n$ structural modules. Each module $i$ must be assigned a material phase $s_i \in \{1, 2\}$.

This phase determines the module's $2 \times 2$ compliance matrix $C_i$:
- If $s_i = 1$, $C_i = \begin{pmatrix} 1 & 1 \\ 1 & 1 \end{pmatrix}$.
- If $s_i = 2$, $C_i = \begin{pmatrix} 1 & -1 \\ -1 & 1 \end{pmatrix}$.

The system log contains $m$ load-bearing connections. Each connection involves two modules $u$ and $v$. 
When two modules are connected, their matrices combine to form the connection's joint compliance $J = C_u + C_v$.
To avoid structural collapse under load, the joint compliance matrix of every logged connection must be strictly positive definite (meaning all of its eigenvalues must be strictly greater than zero).

(Note: If a logged connection involves the same module twice, meaning $u = v$, the joint matrix is $2 C_u$. Since $C_u$ always has an eigenvalue of exactly 0, $2 C_u$ also has an eigenvalue of 0, which immediately violates the requirement and collapses the network).

If there are multiple valid phase assignments that satisfy the requirement for all logged connections, you must output the sequence $s_1 \dots s_n$ that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the indices of the two modules involved in the $j$-th logged connection. The connections are given in order for $j = 1, 2, \dots, m$.

## Output
If no such assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$) representing the elements of the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
