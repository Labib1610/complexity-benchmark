We can rewrite the equilibrium condition.

Let’s define:

- \( d_i \) = degree count (with self-loops counted twice).
- Interaction energy: \( 2 \sum_{j=1}^m s_{u_j} s_{v_j} \)
- Base energy: \( 3 \sum_{i=1}^n d_i s_i - 5m \)

Equilibrium means:

\[
2 \sum_{j=1}^m s_{u_j} s_{v_j} = 3 \sum_{i=1}^n d_i s_i - 5m
\]

We can rearrange:

\[
3 \sum_{i=1}^n d_i s_i - 2 \sum_{j=1}^m s_{u_j} s_{v_j} = 5m
\]

Now, note that:

\[
\sum_{i=1}^n d_i s_i = \sum_{j=1}^m (s_{u_j} + s_{v_j})
\]

So the left side becomes:

\[
3 \sum_{j=1}^m (s_{u_j} + s_{v_j}) - 2 \sum_{j=1}^m s_{u_j} s_{v_j}
= \sum_{j=1}^m \left[ 3(s_{u_j} + s_{v_j}) - 2 s_{u_j} s_{v_j} \right]
\]

For each interaction, let \( a = s_u, b = s_v \), each in {1,2}.  
Compute \( 3(a+b) - 2ab \):

- If (1,1): \( 3(2) - 2(1) = 6 - 2 = 4 \)
- If (1,2) or (2,1): \( 3(3) - 2(2) = 9 - 4 = 5 \)
- If (2,2): \( 3(4) - 2(4) = 12 - 8 = 4 \)

So each interaction contributes either 4 or 5.  
The total must equal \( 5m \).  
Thus, every interaction must contribute exactly 5.  
That means for every edge, the two endpoints must have different values (one 1, one 2).

So the problem reduces to:  
Can we assign each vertex a value 1 or 2 such that every edge connects vertices of different values?  
That’s exactly checking if the graph is bipartite.  
If yes, output the lexicographically smallest assignment (with 1 before 2).

We can do BFS/DFS coloring, and to get lexicographically smallest, we try to assign 1 to as many early vertices as possible.  
We can do this by starting from vertex 1, assigning 1, and propagating. If a conflict occurs, it's impossible.

Implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 0  # 0 means value 1, 1 means value 2
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
