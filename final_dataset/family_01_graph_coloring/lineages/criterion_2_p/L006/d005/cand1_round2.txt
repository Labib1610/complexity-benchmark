<STATEMENT>
# Problem B — System Equilibrium

Time limit: 1 s   Memory limit: 256 MB

You are tasked with finding a sequence of system states $s_1, s_2, \dots, s_n$ such that each $s_i \in \{1, 2\}$.

The system is constrained by a sequence of $m$ interacting index pairs. For the $j$-th pair $(u, v)$, we define a function $F_j(x)$ by the definite integral:

$$ F_j(x) = \int_0^x (t - s_u)(t - s_v) \, dt $$

The system is considered to be in perfect equilibrium if, for every $j$ from $1$ to $m$, the function $F_j(x)$ has a point of inflection at exactly $x = 1.5$. 

If there are multiple valid state sequences $s_1 \dots s_n$ that satisfy this equilibrium condition for all $m$ pairs, you must output the sequence that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — an interacting pair of indices.

## Output
If no such sequence of states exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$) representing the lexicographically smallest valid state sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the matrix construction constraint into a calculus condition where a function defined by an integral must have an inflection point at a specific coordinate. This removes the overt pair-sum structure and forces models to symbolically differentiate the integral to discover the hidden bipartite constraint $s_u + s_v = 3$, bypassing the banned complexity-class vocabulary while keeping the difficulty high.
</RATIONALE>
<PRESERVED_ANSWER>
The inflection point at $x = 1.5$ requires the second derivative $2x - s_u - s_v$ to be zero at that point, which simplifies exactly to $s_u + s_v = 3$, identical to the original matrix equation.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains equivalent to finding a valid 2-coloring of a graph, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the inflection point requirement if they struggle with basic calculus, though the math is standard and unambiguous.
</RISK>
