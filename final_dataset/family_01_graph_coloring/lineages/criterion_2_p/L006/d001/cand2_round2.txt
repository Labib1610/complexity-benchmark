# Problem B — Factory Schedules

Time limit: 1 s   Memory limit: 256 MB

The manufacturing facility manages $n$ employees and must assign each of them a shift code, $s_i$, which must be either 1 or 2. The facility operates with at least $1$ employee, up to a maximum capacity of $2\cdot 10^5$ employees.

To maintain continuous operation, a regulatory database stores $m$ joint-task contracts. The database can contain as few as $0$ contracts, up to a limit of $2\cdot 10^5$. 

Each joint-task contract binds two specific employees. To satisfy a contract, the two bound employees must have their shift codes sum to exactly 3. This ensures that one employee is present during shift 1 while the other is present during shift 2, providing seamless coverage.

Your task is to determine if there is a valid assignment of shift codes for all $n$ employees such that every joint-task contract is satisfied. If multiple valid assignments exist, you must find the one where the resulting sequence of shift codes $s_1, s_2, \dots, s_n$ is lexicographically smallest (i.e., comparing two valid sequences from left to right, the one with the smaller code at the first position they differ is preferred).

## Input
The first line contains two integers $n$ and $m$, representing the active headcount and the number of contracts.
Each of the next $m$ lines contains two integers $u$ and $v$ — a joint-task contract between these two employees.

## Output
If no valid assignment of shift codes exists, print a single line containing NO.
Otherwise, print YES on the first line, followed by a second line containing $n$ integers $s_1 \dots s_n$ (each either 1 or 2), representing the lexicographically smallest valid sequence of shift codes.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was reframed to hide the direct "incompatible pairs" graph-coloring interpretation. Instead of stating that conflicting workers must not share a schedule, the relationship is defined algebraically: their shift codes (which are restricted to 1 and 2) must sum to 3. The explicit mathematical inequalities for the bounds were removed from the Input section and integrated into the scenario as physical system capacities, fulfilling the S07 strategy while preserving the exact numerical values to satisfy the automated gate.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that two variables in {1,2} sum to 3 is mathematically identical to requiring them to be different, preserving the exact same valid assignments and lexicographical tie-breaking as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT / 2-coloring (bipartiteness testing), which is solvable in O(n+m) time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "sum to exactly 3" if they forget the domain is restricted to {1,2}, though the text explicitly states "each of them a shift code, $s_i$, which must be either 1 or 2".
</RISK>
