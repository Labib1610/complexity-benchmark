# Problem B — Factory Schedules

Time limit: 1 s   Memory limit: 256 MB

A factory requires each of its $n$ personnel to be assigned a security code from the set $\{1, 2\}$.
The factory operations are governed by $m$ bilateral contracts. Each contract is a strict agreement between two specific personnel.
To comply with regulations, any two personnel bound by a contract must be assigned codes that sum to exactly 3.
Determine if there is a valid code arrangement for all personnel. If no valid arrangement can be found, report the impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a contract between personnel $u$ and $v$.

## Output
If no valid arrangement exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), the lexicographically smallest valid arrangement.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Replaced explicit graph-coloring terminology ("incompatible pair", "shares a schedule") with a scenario involving "contracts" and "security codes". The constraint that conflicting nodes must receive different labels is now expressed algebraically: the two codes must sum to exactly 3. This forces the model to recognize that $x + y = 3$ for $x, y \in \{1, 2\}$ implies $x \neq y$, breaking surface-level pattern matching for bipartiteness checks.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that two values from the set {1, 2} sum to exactly 3 is mathematically equivalent to requiring that the two values are distinct, preserving all valid assignments exactly as in the seed.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
