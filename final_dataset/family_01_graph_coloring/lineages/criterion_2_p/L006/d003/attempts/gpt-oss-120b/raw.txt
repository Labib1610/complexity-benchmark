**Solution Explanation**

For every monitor we are given a pair of valves `(u , v)`.
The monitor is satisfied **iff** the states of the two valves are different,
because the only possible states are `1` and `2` and the condition
“one state is exactly twice the other” means `{1,2}`.

So the whole system is a graph whose vertices are the valves and whose edges
are the monitors.
We have to colour the vertices with two colours `1` and `2` such that
adjacent vertices have different colours – i.e. the graph must be **bipartite**.

If the graph is bipartite there are exactly two colourings for each connected
component (they are each other’s colour swap).  
Among all global colourings we need the lexicographically smallest
sequence `s1 … sn` (`1 < 2`).  
Consider one connected component `C`.  
Let `vmin` be the smallest index vertex belonging to `C`.
If we colour `vmin` with `2`, the whole sequence becomes larger at position
`vmin` no matter how the rest is coloured.
Therefore in a lexicographically minimal solution **the smallest index vertex
of every component must receive colour `1`**.
The rest of the component is forced by bipartiteness.

Hence the algorithm is:

```
for every not visited vertex:
        run BFS/DFS, assign temporary parity 0/1
        if a conflict appears → graph not bipartite → answer NO
        collect all vertices of this component
        let vmin = min(vertex list)
        if parity[vmin] == 0:
                colour parity 0 → 1 , parity 1 → 2
        else:
                colour parity 0 → 2 , parity 1 → 1
        write the chosen colours into the answer array
```

If all components are processed without conflict we output `YES` and the
answer array.

`n, m ≤ 2·10⁵`, BFS/DFS runs in `O(n+m)` time and `O(n+m)` memory,
well inside the limits.

---

#### Correctness Proof  

We prove that the algorithm prints `YES` and the lexicographically smallest
valid assignment iff such an assignment exists.

---

##### Lemma 1  
If the algorithm reports a conflict while processing a component, the graph
is not bipartite, therefore no assignment satisfying all monitors exists.

**Proof.**  
During BFS we assign temporary parity `0/1` to vertices and require that
adjacent vertices have opposite parity. A conflict means an edge connects two
vertices that already have the same parity, which is exactly the definition of
a non‑bipartite graph. Any assignment of `1/2` must respect opposite colours on
edges, impossible in a non‑bipartite graph. ∎



##### Lemma 2  
If the algorithm finishes without conflict, the produced assignment satisfies
all monitors.

**Proof.**  
For each component we first obtained a proper 2‑colouring in terms of parity,
so every edge connects vertices of opposite parity.
We then possibly swap the two colours, but swapping keeps the property that
adjacent vertices receive different final states (`1` vs `2`). Hence every
monitor sees two different states, i.e. the required relation holds. ∎



##### Lemma 3  
For a fixed component `C`, among all assignments that satisfy the monitors,
the algorithm chooses the lexicographically smallest restriction to the
vertices of `C`.

**Proof.**  
All valid assignments on `C` are exactly the two colourings obtained from the
parity colouring, one being the swap of the other.
Let `vmin` be the smallest index in `C`.  
If `vmin` receives colour `2` in an assignment, the whole global sequence is
larger at position `vmin` than any assignment where `vmin` receives `1`,
independently of later positions.  
The algorithm forces `vmin` to colour `1` (by possibly swapping the two
colourings). Therefore its restriction to `C` is lexicographically minimal
among the two possibilities. ∎



##### Lemma 4  
The whole sequence output by the algorithm is lexicographically minimal among
all globally valid assignments.

**Proof.**  
Consider the first index `i` where the algorithm’s sequence `A` differs from
any other valid sequence `B`.  
Vertex `i` belongs to some component `C`.  
Both `A` and `B` must respect the parity colouring of `C`; they can only differ
by a possible swap of the two colours inside `C`.  
By Lemma&nbsp;3 the algorithm chooses the variant where the smallest vertex of
`C` (which is ≤ `i`) gets colour `1`. Since `i` is the first differing position,
the smallest vertex of `C` is exactly `i`. Hence `A[i]=1` and any other valid
assignment must have `B[i]=2`. Therefore `A` is lexicographically smaller.
∎



##### Theorem  
The algorithm outputs  

* `NO` iff no assignment satisfying all monitors exists;  

* otherwise `YES` and the lexicographically smallest satisfying assignment.

**Proof.**  

*If the algorithm prints `NO`*: this happens only when a conflict is found.
By Lemma&nbsp;1 the graph is not bipartite, thus no assignment exists.

*If the algorithm prints `YES`*: it finished without conflict, so by
Lemma&nbsp;2 the produced assignment satisfies all monitors.
By Lemma&nbsp;4 it is the lexicographically smallest among all such
assignments.

Conversely, if a satisfying assignment exists, the graph is bipartite,
so no conflict occurs and the algorithm prints `YES`. ∎

#### Complexity Analysis  

*Building adjacency lists*: `O(n+m)` memory.  
*BFS over all components*: each vertex and edge processed once → `O(n+m)` time.  
*Additional arrays*: `O(n)`.

Overall: **Time `O(n+m)`, Memory `O(n+m)`**.

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    color = [0] * (n + 1)          # final answer 1/2, 0 = unassigned
    parity = [-1] * (n + 1)        # temporary 0/1 during BFS
    from collections import deque

    for start in range(1, n + 1):
        if parity[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        parity[start] = 0
        comp = [start]
        ok = True
        while q:
            u = q.popleft()
            pu = parity[u]
            for v in adj[u]:
                if parity[v] == -1:
                    parity[v] = pu ^ 1
                    q.append(v)
                    comp.append(v)
                elif parity[v] == pu:
                    print("NO")
                    return
        # decide orientation: smallest vertex gets colour 1
        vmin = min(comp)
        if parity[vmin] == 0:
            # parity 0 -> 1, parity 1 -> 2
            for v in comp:
                color[v] = 1 if parity[v] == 0 else 2
        else:
            # swap
            for v in comp:
                color[v] = 1 if parity[v] == 1 else 2

    # all vertices assigned
    print("YES")
    print(' '.join(str(color[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
