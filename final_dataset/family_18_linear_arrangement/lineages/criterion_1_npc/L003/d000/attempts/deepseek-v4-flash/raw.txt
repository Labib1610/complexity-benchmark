We need to assign crops to zones to minimize the sum of pipe lengths for given edges.  
This is equivalent to finding a linear arrangement of the graph that minimizes the sum of edge lengths, which is the **Minimum Linear Arrangement (MinLA)** problem.  

Since the problem is NP-hard in general, but here we only need to check if we can get ≤ B, we can try a greedy or heuristic approach.  
For small n, we can try all permutations, but n can be large.  

A practical approach:  
- Place crops that are connected close together.  
- Use a greedy algorithm: start with the most connected crop, place it in the center, then place neighbors nearby.  

We’ll implement a simple greedy BFS/DFS-based placement.  

```python
import sys
from collections import deque

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    B = int(next(it))
    
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    # Greedy: place nodes with high degree first, then neighbors nearby
    degree = [len(adj[i]) for i in range(n)]
    order = sorted(range(n), key=lambda x: -degree[x])
    
    pos = [-1] * n
    used = [False] * n
    
    # Place first node in the middle
    start = order[0]
    mid = n // 2
    pos[start] = mid
    used[mid] = True
    
    # BFS-like placement
    queue = deque([start])
    placed_count = 1
    
    while placed_count < n:
        # Try to place neighbors of already placed nodes
        new_queue = deque()
        for u in queue:
            for v in adj[u]:
                if pos[v] == -1:
                    # Find nearest free slot to u's position
                    best = None
                    best_dist = float('inf')
                    for slot in range(n):
                        if not used[slot]:
                            d = abs(slot - pos[u])
                            if d < best_dist:
                                best_dist = d
                                best = slot
                    pos[v] = best
                    used[best] = True
                    placed_count += 1
                    new_queue.append(v)
        queue = new_queue
        
        # If no new placements, place any unplaced node
        if placed_count < n and not queue:
            for i in range(n):
                if pos[i] == -1:
                    for slot in range(n):
                        if not used[slot]:
                            pos[i] = slot
                            used[slot] = True
                            placed_count += 1
                            queue.append(i)
                            break
                    break
    
    # Compute total length
    total = 0
    for u in range(n):
        for v in adj[u]:
            if u < v:
                total += abs(pos[u] - pos[v])
    
    if total <= B:
        print("YES")
        print(" ".join(str(pos[i] + 1) for i in range(n)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
