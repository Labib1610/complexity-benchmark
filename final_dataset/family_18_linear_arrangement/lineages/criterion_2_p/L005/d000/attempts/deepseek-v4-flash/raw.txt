We need to place the units on a line of positions 1..n such that the sum of distances along edges of the tree is ≤ B.  
This is a known problem: given a tree, find a linear arrangement minimizing the sum of edge lengths (also called the *minimum linear arrangement* problem), but here we just need ≤ B, not necessarily minimum.

We can solve it with a greedy DFS approach:  
- Root the tree at any node (say 1).  
- For each node, we decide the order of its children in the line.  
- The key observation: For each edge, the number of edges crossing it equals the size of the smaller side of the cut.  
- The total length = sum over edges of (size of subtree) * (n - size of subtree).  
- We can try to arrange the tree so that each subtree is placed contiguously, minimizing the sum.

We can do a DFS that returns the interval [l, r] occupied by the subtree in the final permutation.  
We assign positions greedily:  
- Start with position 1 for root.  
- For each child, we place its whole subtree immediately after the previous child's subtree.  
- This ensures each edge contributes exactly (subtree size) * (n - subtree size) to the total length.

So the algorithm:
1. Build adjacency list.
2. Root the tree at 1.
3. Compute subtree sizes.
4. Compute total length = sum over all edges (subtree_size * (n - subtree_size)).
5. If total length > B, print NO.
6. Else, do a DFS to assign positions:  
   - pos[node] = current position, then increment.  
   - Recurse into children in any order (order doesn't matter for total length, only for output).

Let's implement.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    B = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    parent = [-1] * n
    order = []
    stack = [0]
    parent[0] = -2
    while stack:
        u = stack.pop()
        order.append(u)
        for v in adj[u]:
            if v == parent[u]:
                continue
            parent[v] = u
            stack.append(v)
    
    size = [1] * n
    for u in reversed(order):
        for v in adj[u]:
            if v == parent[u]:
                continue
            size[u] += size[v]
    
    total = 0
    for u in range(1, n):
        s = size[u]
        total += s * (n - s)
    
    if total > B:
        print("NO")
        return
    
    pos = [0] * n
    cur = 1
    def dfs(u):
        nonlocal cur
        pos[u] = cur
        cur += 1
        for v in adj[u]:
            if v == parent[u]:
                continue
            dfs(v)
    
    dfs(0)
    
    print("YES")
    print(" ".join(str(pos[i]) for i in range(n)))

if __name__ == "__main__":
    solve()
```
