We can model the modules and belts as a tree (since there are exactly n−1 edges and it’s connected).  
The problem is to assign numbers 1..n to the tree nodes (bijectively) so that the sum of |pos[u] − pos[v]| over all edges is ≤ B.

A known fact: For a tree, the sum of edge lengths in a linear arrangement is minimized by placing nodes according to a DFS order (or any order that keeps subtrees contiguous).  
The minimal possible sum is achieved by a **DFS ordering** of the tree, and it equals the sum over all edges of the size of the smaller side when the edge is cut.

So the algorithm:
1. Build adjacency list.
2. Root the tree at node 1.
3. Compute subtree sizes.
4. Compute minimal possible total length = sum over edges of min(subtree_size, n − subtree_size).
5. If this minimal sum > B → output NO.
6. Otherwise, we can output any DFS order (preorder) as the assignment.  
   That gives the minimal sum, which is ≤ B.

We must output the bay number for each module (1-indexed).

Let’s implement.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, B = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    parent = [-1] * n
    order = []
    stack = [0]
    parent[0] = 0
    while stack:
        u = stack.pop()
        order.append(u)
        for v in adj[u]:
            if v == parent[u]:
                continue
            parent[v] = u
            stack.append(v)
    
    size = [1] * n
    for u in reversed(order):
        for v in adj[u]:
            if v != parent[u]:
                size[u] += size[v]
    
    min_cost = 0
    for u in range(1, n):
        s = size[u]
        min_cost += min(s, n - s)
    
    if min_cost > B:
        print("NO")
        return
    
    # Assign positions via DFS preorder
    pos = [0] * n
    idx = 1
    stack = [0]
    visited = [False] * n
    visited[0] = True
    while stack:
        u = stack.pop()
        pos[u] = idx
        idx += 1
        for v in adj[u]:
            if not visited[v]:
                visited[v] = True
                stack.append(v)
    
    print("YES")
    print(" ".join(str(p) for p in pos))

if __name__ == "__main__":
    solve()
```
