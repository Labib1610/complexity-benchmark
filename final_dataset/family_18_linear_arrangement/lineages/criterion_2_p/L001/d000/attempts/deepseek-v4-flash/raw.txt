We can model the hierarchy as a tree. The problem is to assign distinct positions 1..n to nodes so that the sum of absolute differences along edges is ≤ B.

A known approach:  
- Root the tree at the top-level unit (the one with no parent).  
- Use a DFS to compute subtree sizes.  
- Place nodes in a contiguous segment of positions for each subtree.  
- The optimal placement for minimizing total edge length in a tree on a line is to place nodes in DFS order (preorder), which yields a total length equal to the sum over edges of (subtree size of child) * (n - subtree size of child) if we place them in a certain way — but here we just need any placement ≤ B.

We can use a greedy DFS placement:  
- Assign positions in preorder.  
- The total length will be the sum over edges of the distance between parent and child positions.  
- This is not necessarily minimal, but we can check if it’s ≤ B. If not, we can try other orderings (like postorder) or use a known optimal arrangement.

Actually, the minimal possible total length for a tree on a line is achieved by placing nodes in DFS order (preorder) with the root at position 1, and children placed consecutively. The total length is:

sum over edges (subtree_size[child]) * (n - subtree_size[child])

This is the minimal possible sum of distances for a tree embedded on a line with distinct integer positions.  
So we can compute this minimal value. If it’s > B, answer NO. Otherwise, we can output the preorder assignment.

Let’s implement that.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    B = int(next(it))
    
    adj = [[] for _ in range(n+1)]
    indeg = [0]*(n+1)
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)
        indeg[v] += 1
    
    # find root (indegree 0)
    root = 1
    for i in range(1, n+1):
        if indeg[i] == 0:
            root = i
            break
    
    parent = [0]*(n+1)
    order = []
    stack = [root]
    parent[root] = -1
    while stack:
        u = stack.pop()
        order.append(u)
        for v in adj[u]:
            if v != parent[u]:
                parent[v] = u
                stack.append(v)
    
    # compute subtree sizes
    size = [1]*(n+1)
    for u in reversed(order):
        for v in adj[u]:
            if v != parent[u]:
                size[u] += size[v]
    
    # minimal total length
    min_len = 0
    for u in range(1, n+1):
        if parent[u] != -1:
            s = size[u]
            min_len += s * (n - s)
    
    if min_len > B:
        print("NO")
        return
    
    # assign positions in preorder
    pos = [0]*(n+1)
    cur = 1
    stack = [root]
    while stack:
        u = stack.pop()
        pos[u] = cur
        cur += 1
        # push children in reverse order to get natural order
        for v in reversed(adj[u]):
            if v != parent[u]:
                stack.append(v)
    
    print("YES")
    print(" ".join(str(pos[i]) for i in range(1, n+1)))

if __name__ == "__main__":
    solve()
```
