We can model the modules and cables as a tree.  
The problem asks for a permutation of bay numbers (1 to n) assigned to the tree nodes such that the sum of absolute differences along edges is ≤ B.

A known approach:  
- Root the tree at any node.  
- Use a DFS to assign positions in a way that minimizes total edge length.  
- A good heuristic is to assign positions in DFS order (preorder), which often gives small total length.  
- If the total length exceeds B, we can try other rootings or orders, but for this problem, a simple DFS order from a chosen root usually works if B is feasible.

We’ll implement:
1. Build adjacency list.
2. DFS from node 1, assign bay numbers in preorder.
3. Compute total cable length.
4. If ≤ B, print YES and the assignment; else NO.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    B = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    pos = [0] * n
    order = []
    visited = [False] * n
    
    def dfs(u):
        visited[u] = True
        order.append(u)
        for w in adj[u]:
            if not visited[w]:
                dfs(w)
    
    dfs(0)
    
    # assign bay numbers in order
    for i, node in enumerate(order):
        pos[node] = i + 1
    
    total = 0
    for u in range(n):
        for v in adj[u]:
            if u < v:
                total += abs(pos[u] - pos[v])
    
    if total <= B:
        print("YES")
        print(" ".join(str(pos[i]) for i in range(n)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
