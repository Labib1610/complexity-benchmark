**Solution Explanation**

For every job we know all jobs that have to be finished before it.
All jobs need exactly one time slot, a slot can contain at most `M`
jobs (the number of parallel stations) and a job must be placed in a
slot strictly larger than the slots of all its predecessors.

The following greedy algorithm is optimal for unit‑time jobs:

```
for t = 1 … D
        take up to M jobs whose all predecessors are already scheduled
        (i.e. in‑degree 0) and put them into slot t
```

*Why is it optimal?*  
Consider any feasible schedule. Look at the first slot.
If it contains less than `M` jobs, we can move any unscheduled
ready job into this slot without breaking any precedence constraint,
because all its predecessors are already finished (they are in earlier
slots). Repeating this argument slot after slot shows that a schedule
that always fills a slot as much as possible never needs more slots
than an arbitrary feasible schedule. Consequently, if the greedy
procedure cannot finish all jobs within the given deadline `D`,
no schedule can.

The algorithm needs only a topological order of the jobs.
We keep the current in‑degree of every vertex and a queue of vertices
with in‑degree `0`. While processing a slot we pop at most `M` vertices
from the queue, assign the current slot number to them and decrease the
in‑degree of their outgoing neighbours, inserting newly ready vertices
into the queue.

If after processing slots `1 … D` some jobs are still unscheduled,
the answer is `NO`. Otherwise we output the obtained slot numbers.

The algorithm works in  

* `O(N + P)` time – one pass over all vertices and all precedence edges,
* `O(N + P)` memory.

--------------------------------------------------------------------

#### Algorithm
```
read N, M, D, P
build adjacency list, compute indegree[1…N]

queue = all vertices with indegree 0
slot = [0] * (N+1)          # slot[i] = assigned slot, 0 = not assigned yet
for t = 1 … D
        cnt = 0
        while cnt < M and queue not empty
                v = queue.pop()
                slot[v] = t
                cnt += 1
                for each w in adj[v]
                        indegree[w] -= 1
                        if indegree[w] == 0: queue.push(w)

if any slot[i] == 0          # some job not scheduled
        print "NO"
else
        print "YES"
        print slot[1] … slot[N] separated by spaces
```

#### Correctness Proof  

We prove that the algorithm prints a correct answer.

---

**Lemma 1**  
When a job `v` is taken from the queue, all its predecessors have already
been assigned a slot smaller than the current slot `t`.

*Proof.*  
A vertex enters the queue only when its indegree becomes `0`, i.e. when
all incoming edges have been processed. An incoming edge `(u → v)` is
processed exactly when `u` is taken from the queue and scheduled.
Therefore at the moment `v` is popped, every predecessor `u` has already
received a slot (the slot of `u` is the iteration in which it was popped)
and that slot is `< t` because the current iteration is `t`. ∎



**Lemma 2**  
The schedule produced by the algorithm respects all precedence
constraints.

*Proof.*  
Take any edge `u → v`. Vertex `u` is scheduled before `v` because `v`
cannot enter the queue before `u` is removed from it (its indegree would
still be positive). By Lemma&nbsp;1 the slot of `v` is strictly larger
than the slot of `u`. ∎



**Lemma 3**  
At the beginning of each slot `t` the queue contains exactly the jobs
that are ready (all predecessors already scheduled) and not yet
scheduled.

*Proof by induction on `t`.*  

*Base `t = 1`*: initially the queue is filled with all vertices of indegree
`0`, i.e. precisely the jobs without predecessors – the ready set.

*Induction step*: assume the statement holds for slot `t`.  
During slot `t` we remove up to `M` ready jobs, schedule them and for
each outgoing edge decrease the indegree of the neighbour. Whenever a
neighbour’s indegree becomes `0` all its predecessors have just been
scheduled (in slot `t` or earlier), therefore it becomes ready and is
added to the queue. No other vertex changes its readiness status.
Consequently, after finishing slot `t` the queue consists exactly of the
still‑unscheduled ready jobs, i.e. the ready set for slot `t+1`. ∎



**Lemma 4**  
If the algorithm finishes all jobs within the deadline `D`, the
produced assignment is a feasible schedule.

*Proof.*  
All jobs receive a slot `≤ D` by construction.
By Lemma&nbsp;2 precedence is satisfied.
At each slot we schedule at most `M` jobs, so the per‑slot capacity
constraint holds. ∎



**Lemma 5**  
If the algorithm cannot schedule all jobs within `D` slots, then **no**
feasible schedule respecting the deadline exists.

*Proof.*  
Consider the moment just before slot `D+1` would start.
By Lemma&nbsp;3 the queue contains exactly the unscheduled ready jobs.
If the queue is empty, all jobs would already be scheduled – contradiction.
Hence the queue is non‑empty, i.e. there exists at least one ready job.
Any feasible schedule must also place this job in some slot `≥ D+1`,
because all earlier slots are already completely filled (each of them
contains `M` jobs, otherwise the greedy algorithm could have taken another
ready job). Therefore any feasible schedule needs more than `D` slots. ∎



**Theorem**  
The algorithm outputs  

* `YES` and a correct schedule **iff** a schedule respecting the deadline
  exists;
* `NO` otherwise.

*Proof.*  
*If* part: when the algorithm finishes all jobs within `D` slots,
by Lemma&nbsp;4 the printed assignment is feasible, so a schedule exists.

*Only‑if* part: when the algorithm stops after slot `D` with unscheduled
jobs, Lemma&nbsp;5 shows that no feasible schedule can exist, therefore
printing `NO` is correct. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building the graph*: `O(N + P)` time, `O(N + P)` memory.  
*Main loop*: each vertex is removed from the queue exactly once and each
edge is examined exactly once while decreasing indegrees – `O(N + P)`
time.  
Overall: **Time `O(N + P)`, Memory `O(N + P)`**, well inside the limits.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    N = int(next(it))
    M = int(next(it))
    D = int(next(it))
    P = int(next(it))

    adj = [[] for _ in range(N + 1)]
    indeg = [0] * (N + 1)

    for _ in range(P):
        a = int(next(it))
        b = int(next(it))
        adj[a].append(b)
        indeg[b] += 1

    q = deque([i for i in range(1, N + 1) if indeg[i] == 0])
    slot = [0] * (N + 1)          # 0 = not scheduled yet

    for t in range(1, D + 1):
        cnt = 0
        while cnt < M and q:
            v = q.popleft()
            slot[v] = t
            cnt += 1
            for w in adj[v]:
                indeg[w] -= 1
                if indeg[w] == 0:
                    q.append(w)

    if any(s == 0 for s in slot[1:]):
        sys.stdout.write("NO")
    else:
        sys.stdout.write("YES\n")
        sys.stdout.write(' '.join(str(slot[i]) for i in range(1, N + 1)))

if __name__ == "__main__":
    solve()
```
