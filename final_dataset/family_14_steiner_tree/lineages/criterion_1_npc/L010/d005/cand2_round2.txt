<METHOD_NAME>Logical Implication Framing</METHOD_NAME>
<METHOD_DESCRIPTION>Transforms the graph connectivity problem into a logical implication problem over a system of equality constraints. By framing it as "choosing constraints such that any satisfying assignment forces a subset of variables to be equal", models that rely on "graph", "path", or "connectivity" keywords will fail to recognize the Steiner Tree structure, while the underlying mathematical structure remains identical.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Variable Unification System

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing a theoretical system of **n** unknown variables, $x_1, x_2, \dots, x_n$. Initially, these variables can take on independently arbitrary values. 

You have a list of **m** available constraints that you can choose to activate. Each constraint takes the form $x_u = x_v$ and costs **w** units to activate. When a constraint is activated, it restricts the possible values of the variables such that $x_u$ and $x_v$ must evaluate to the exact same value. 

By the fundamental properties of equality, these constraints combine logically: if a set of active constraints mathematically requires $x_A = x_B$ and $x_B = x_C$, then any valid assignment to the variables will also satisfy $x_A = x_C$, without needing to activate the specific constraint $x_A = x_C$ directly.

There is a specific set of **t** priority variables. Your goal is to choose a set of constraints to activate such that, for any valid assignment of values to the variables that satisfies all activated constraints, all **t** priority variables are absolutely guaranteed to hold the exact same value. You may activate constraints involving any of the **n** variables, using non-priority variables as stepping stones if it results in a lower total cost.

Find the absolute minimum total cost required to logically enforce that all **t** priority variables are equal.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers representing the indices of the priority variables.
The next **m** lines each provide three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that the constraint $x_u = x_v$ is available to activate for a cost of **w**.
It is guaranteed that it is possible to enforce the equality of all **t** priority variables using the available constraints.

## Output

Output a single integer representing the minimum total cost required to ensure all priority variables evaluate to the same value.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, activating $x_1 = x_4$, $x_2 = x_4$, and $x_3 = x_4$ costs 1 + 1 + 1 = 3. By the rules of equality, any assignment satisfying these constraints will also satisfy $x_1 = x_2 = x_3$, meeting the requirement for the priority variables. This is cheaper than activating $x_1 = x_2$ and $x_2 = x_3$ directly, which costs 2 + 2 = 4. 

In Example 3, with only one priority variable, no constraints need to be activated, so the minimum cost is 0.
</STATEMENT>
<RATIONALE>
The problem is reframed from graph connectivity (Steiner Tree) to logical implication over a system of equations. By asking the solver to enforce that a set of variables must be equal under any satisfying assignment, the mathematical structure is preserved while removing standard graph terminology (nodes, edges, connectivity). This forces the model to deduce the equivalence to finding a minimum-cost subgraph that connects the priority variables.
</RATIONALE>
<PRESERVED_ANSWER>
The logical requirement that variables are forced to evaluate to the same value is mathematically identical to finding a connected component containing all priority variables, so the minimum cost subset of constraints is exactly the minimum Steiner tree.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Steiner Tree problem on a weighted graph, which is NP-complete, with the priority variables acting as the terminal nodes.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "any valid assignment" as requiring a SAT solver, but the explicit explanation of equality transitivity makes the connectivity requirement unambiguous.
</RISK>
