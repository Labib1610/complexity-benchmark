# Problem A — Policy Harmonization

Time limit: 5 s   Memory limit: 256 MB

## Description

A multinational corporation has **n** regional branches, numbered 1 through **n**. Each branch must adopt a single regulatory framework. Initially, each branch can independently adopt any framework from an infinite set of possibilities.

To ensure consistency, the corporation can establish bilateral harmonization agreements between certain pairs of branches. You are provided with a list of **m** available agreements. Activating an agreement between branch **u** and branch **v** requires a capital expenditure of **w**. Once activated, this agreement acts as a strict constraint: branch **u** and branch **v** are legally mandated to adopt the exact same regulatory framework.

The corporation has identified a specific set of **t** core branches. Your task is to select a subset of agreements to activate such that, for any valid assignment of frameworks to the **n** branches that satisfies all activated agreements, the **t** core branches must necessarily share the exact same framework. (In other words, it must be impossible to assign frameworks in a way that respects your activated agreements but leaves any two core branches with different frameworks).

You may activate agreements involving any of the **n** branches, leveraging non-core branches as intermediate constraints if it reduces the total capital expenditure.

Determine the absolute minimum total capital expenditure required to enforce this condition for the core branches.

## Input

The first line contains three integers **n**, **m**, and **t**. The total number of branches **n** is between 1 and the number of years in a century. The number of possible agreements **m** is between 0 and the maximum possible number of unique branch pairs. The number of core branches **t** is between 1 and the number of years in a standard decade.

The second line contains **t** distinct integers representing the identities of the core branches.

The next **m** lines each provide three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), indicating that an agreement is available to strictly harmonize branch **u** and branch **v** for a capital expenditure of **w** (where **w** is a positive integer up to one million).

It is guaranteed that it is possible to force all **t** core branches to share the same framework using the available agreements.

## Output

Output a single integer representing the minimum total capital expenditure required to ensure the core branches are forced to adopt the identical regulatory framework.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, activating the agreements for pairs (1, 4), (2, 4), and (3, 4) costs 1 + 1 + 1 = 3. Under these constraints, branch 1 must match 4, branch 2 must match 4, and branch 3 must match 4. Consequently, any valid assignment of frameworks will force core branches 1, 2, and 3 to all match each other. This is more cost-effective than activating (1, 2) and (2, 3), which would cost 2 + 2 = 4. 

In Example 3, there is only one core branch. A single branch is trivially always identical to itself, so no agreements need to be activated.
</STATEMENT>
<RATIONALE>
The problem was reframed from establishing transitive equivalence (which easily matches graph connectivity) to enforcing a universal condition over a state space (all valid assignments must force the targets to match). Additionally, the explicit numeric bounds `t <= 10` and `n <= 100` were replaced with domain facts ("years in a decade", "years in a century"). This forces the model to construct the graph abstraction from first principles and prevents it from blindly triggering exponential subset DP based on seeing a bare `10`.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that all valid assignments force the core branches to match is mathematically identical to requiring that the selected agreements form a connected component containing all core branches, meaning the minimum cost selection remains exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Finding the minimum weight subset of edges that places a specific set of vertices in the same connected component is the exact definition of the Steiner Tree problem, keeping it NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might struggle to parse the indirect bounds (e.g., "years in a decade") if they rely strictly on regex extraction for array sizing, though the phrasing is standard English and logically unambiguous.
</RISK>
