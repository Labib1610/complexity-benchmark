<METHOD_NAME>Algebraic Matroid Framing</METHOD_NAME>
<METHOD_DESCRIPTION>Translates the graph connectivity problem into an equivalent linear algebra problem over a graphic matroid. Finding a minimum-cost subset of edges to connect a set of terminals is exactly finding a minimum-cost subset of difference vectors $e_u - e_v$ whose linear span contains all target difference vectors $e_a - e_b$. This completely removes all graph and path-finding affordances, forcing the model to mathematically deduce the equivalence to Steiner Tree rather than pattern-matching.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Subspace Basis Projection

Time limit: 5 s   Memory limit: 256 MB

## Description

You are operating in an **n**-dimensional vector space defined by the standard orthogonal basis vectors $e_1, e_2, \dots, e_n$.

You are provided with a catalog of **m** available difference vectors. The **i**-th available vector is of the form $e_u - e_v$. To add the **i**-th vector to your active set, you must pay a one-time acquisition cost of **w**. Once acquired, a vector can be scaled by any real number (including negative scalars) and linearly combined with other vectors in your active set. Because vectors can be scaled by $-1$, the distinction between acquiring $e_u - e_v$ and $e_v - e_u$ is irrelevant.

You are given a list of **t** target dimensions. Your objective is to acquire a subset of available vectors such that your active set has the following property: for every possible pair of target dimensions **a** and **b**, the difference vector $e_a - e_b$ lies completely within the linear span of your active set. You may acquire vectors involving any of the **n** dimensions to serve as intermediate components in these linear combinations.

Determine the absolute minimum total acquisition cost required to form such an active set.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers representing the indices of the target dimensions.
The next **m** lines each provide three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that the difference vector $e_u - e_v$ is available for an acquisition cost of **w**.
It is guaranteed that acquiring all available vectors would allow all target difference vectors to be spanned.

## Output

Output a single integer representing the minimum total cost required.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, acquiring the difference vectors $e_1 - e_4$, $e_2 - e_4$, and $e_3 - e_4$ costs 1 + 1 + 1 = 3. 
To form the target difference vector $e_1 - e_2$, you can take the linear combination $1 \cdot (e_1 - e_4) - 1 \cdot (e_2 - e_4) = e_1 - e_2$. 
Similarly, any difference vector between the target dimensions {1, 2, 3} can be expressed as a linear combination of these three acquired vectors. This is cheaper than acquiring the direct difference vectors among 1, 2, and 3 (which would cost 2 + 2 = 4).

In Example 3, with only one target dimension, there are no pairs of target dimensions that need to be spanned. The condition is vacuously met with an empty active set, so the minimum cost is 0.
</STATEMENT>
<RATIONALE>
The problem was rewritten to use the language of linear algebra and vector spaces. By framing the task as ensuring $e_a - e_b$ is in the linear span of a chosen subset of difference vectors $e_u - e_v$, all mentions of "connectivity", "graphs", or "equivalences" are removed. Models must now mathematically deduce that the linear span of difference vectors corresponds exactly to connected components in a graphic matroid, forcing genuine reasoning over pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The linear span of a set of difference vectors $e_u - e_v$ contains $e_a - e_b$ if and only if $a$ and $b$ are in the same connected component of the graph formed by those vectors; thus, the minimum cost to span all target differences is exactly the minimum weight Steiner Tree.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Steiner Tree problem in graphs, which is NP-complete.
</PRESERVED_CLASS>
