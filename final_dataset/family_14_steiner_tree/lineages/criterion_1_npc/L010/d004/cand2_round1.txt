<STATEMENT>
# Problem A — Ledger Synchronization Mandate

Time limit: 5 s   Memory limit: 256 MB

## Description

You are an auditor verifying a financial database. The database contains **n** distinct regional ledgers, labeled from 1 to **n**.

You have a catalog of **m** bidirectional synchronization scripts. Each script can continuously mirror the entries between two specific ledgers, enforcing that their balances remain exactly identical. Deploying a script between ledger **u** and ledger **v** incurs a one-time licensing fee of **w**.

Synchronization relationships are transitive. If ledger A is mirrored with ledger B, and ledger B is mirrored with ledger C, then ledger A and ledger C are indirectly mirrored and will maintain identical balances.

A regulatory mandate requires that a specific group of **t** core ledgers must be mutually synchronized—meaning the system must guarantee that all **t** of these ledgers share the exact same balance. You may deploy scripts between any combination of ledgers in the database, including non-core ones, if using them as intermediate mirrors achieves the mandate at a lower total licensing fee.

Your task is to determine the absolute minimum total licensing fee required to ensure all **t** core ledgers are mutually synchronized.

## Input

The first line contains three integers **n**, **m**, and **t**. 
The limits are defined by the system's physical and administrative constraints:
- The regulatory committee has exactly 10 members, and each member may designate at most one core ledger (with at least one designated overall).
- The database is hosted on a server rack with exactly 100 hardware slots, supporting a maximum of one ledger per slot (with at least one ledger existing).
- The number of available scripts **m** can be as low as zero, up to the theoretical maximum where every unique pair of the **n** ledgers has a script.

The second line contains **t** distinct integers identifying the core ledgers.
The next **m** lines each provide three integers **u**, **v**, and **w**, indicating that a script can mirror ledger **u** and ledger **v** for a fee of **w**. The ledgers **u** and **v** are distinct valid ledger labels. A statutory cap ensures that the fee **w** for any single script is strictly positive and will not exceed one million.
It is guaranteed that it is possible to mutually synchronize all core ledgers using the provided scripts.

## Output

Output a single integer representing the minimum total licensing fee to ensure all core ledgers are mutually synchronized.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, deploying scripts to mirror ledgers 1 and 4, 2 and 4, and 3 and 4 (which costs 1+1+1 = 3) is more cost-effective than mirroring the three core ledgers directly among themselves (which would cost 4). In Example 3, there is only one core ledger, so no scripts need to be deployed.

<RATIONALE>
The problem was reframed from a spatial networking task (connecting hubs with fiber links) to an algebraic one (enforcing transitive equivalence between variables). This hides the graph structure entirely, forcing the model to recognize that establishing transitive equivalence among a subset of variables using pairwise constraints is structurally identical to finding a minimum-weight Steiner tree. Numeric bounds were also embedded into the scenario's physical and administrative limits (Strategy S07) rather than presented as bare inequalities, preventing superficial pattern-matching on the input format.
</RATIONALE>
<PRESERVED_ANSWER>
The cost to ensure a subset of variables are equal via pairwise equalities is exactly the minimum weight of a subgraph connecting those variables, preserving the exact Steiner Tree optimization objective and all answers.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Steiner Tree problem on graphs, which is NP-complete, as the underlying mathematical structure of transitive pairwise equivalence is identical to graph connectivity.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "mutually synchronized" as requiring a complete clique of scripts directly between the core ledgers, though the text explicitly clarifies that indirect mirroring via transitivity satisfies the requirement.
</RISK>
