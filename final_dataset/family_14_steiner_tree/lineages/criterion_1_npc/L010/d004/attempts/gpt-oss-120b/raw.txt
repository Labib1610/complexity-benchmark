**Solution Explanation**

For every expression we have a vertex.
A sub‑routine `u v w` is an undirected edge with weight `w`.
Running a set of sub‑routines means taking a set of edges.
Because equality is transitive, the taken edges only have to **connect**
all *target* vertices – intermediate (non‑target) vertices may also be used.

The problem is therefore:

*Given an undirected weighted graph ( `n ≤ 100` ) and a set `T`
(`|T| = t ≤ 10`) of terminal vertices,
find a minimum‑weight set of edges whose union connects all terminals.*

That is the **Steiner Tree** problem.
For general graphs it is NP‑hard, but with `t ≤ 10` the classic
dynamic programming over subsets solves it easily.

--------------------------------------------------------------------

#### 1.   DP state  

```
dp[mask][v] = minimum total weight of a tree
              that connects exactly the terminals whose bits are set in mask
              and whose *root* (any vertex of the tree) is v
```

`mask` – bitmask of size `t` ( `0 … 2^t-1` ),  
`v` – vertex `0 … n-1`.

The answer will be  

```
min_v dp[fullMask][v]          (fullMask = (1<<t)-1)
```

--------------------------------------------------------------------

#### 2.   Initialisation  

For every terminal `Ti` (its index in the terminal list is `i`)

```
dp[1<<i][Ti] = 0          # no edge needed, tree consists of the single vertex
```

All other entries are `+∞`.

--------------------------------------------------------------------

#### 3.   Merging two already built sub‑trees  

Assume we already know optimal trees for two *disjoint* terminal sets
`sub` and `mask-sub` that both end in the **same** vertex `v`.
Joining the two trees at `v` gives a tree for `mask` whose cost is the sum.

```
for every proper non‑empty sub ⊂ mask
        other = mask ^ sub
        for every vertex v
                dp[mask][v] = min(dp[mask][v],
                                  dp[sub][v] + dp[other][v])
```

The loop over all sub‑masks runs in `O(3^t)` total, which is tiny
(`t ≤ 10  →  3^t = 59049`).

--------------------------------------------------------------------

#### 4.   Spreading the root through the graph  

After the merging step `dp[mask][v]` is known **only** for the vertices
that are already roots of optimal sub‑trees.
From any such vertex we can walk along graph edges,
paying their weight, and obtain a tree for the same terminal set whose
root moves to a neighbour.  
Consequently we have to compute *all‑pairs shortest paths* with the
current distances as sources – exactly a Dijkstra run per mask.

```
run Dijkstra with initial distance of vertex x = dp[mask][x] (if finite)
        relaxation:   dp[mask][to] = min(dp[mask][to], dp[mask][v] + w(v,to))
```

`n ≤ 100`, `m ≤ n·(n-1)/2`, therefore `O( (2^t)·(m log n) )` is far below the limits.

--------------------------------------------------------------------

#### 5.   Whole algorithm  

```
full = (1<<t) - 1
for mask = 1 … full
        # 1) merge smaller masks
        for sub = (mask-1) & mask ; sub > 0 ; sub = (sub-1) & mask
                other = mask ^ sub
                for v = 0 … n-1
                        dp[mask][v] = min(dp[mask][v],
                                          dp[sub][v] + dp[other][v])

        # 2) run Dijkstra to propagate through edges
        Dijkstra( dp[mask] )
answer = min_v dp[full][v]
```

The algorithm respects the required limits easily.

--------------------------------------------------------------------

#### 6.   Correctness Proof  

We prove that the algorithm outputs the minimum possible total cost.

---

##### Lemma 1  
For any mask and vertex `v`, after the Dijkstra step
`dp[mask][v]` equals the minimum weight of a tree that

* connects exactly the terminals of `mask`,
* contains `v`,
* and whose other edges form a (possibly empty) simple path from `v`
  to the original root used before the Dijkstra step.

**Proof.**  
Before Dijkstra, `dp[mask][v]` is the optimum among trees whose root is **exactly**
`v`. Dijkstra treats every vertex with that current finite distance as a source
and relaxes edges with their weights, which is precisely the classic single‑source
shortest‑path relaxation. Because edge weights are non‑negative, Dijkstra
produces the shortest possible additional path from any source to any other
vertex. Adding such a path to the tree keeps all terminals connected and adds
only `w(e)` for each traversed edge, therefore the new value is the optimum among
all trees containing `v`. ∎



##### Lemma 2  
After processing a mask, `dp[mask][v]` equals the minimum possible weight of
*any* tree that connects exactly the terminals of `mask` and contains vertex `v`.

**Proof.**  
Induction over increasing `mask`.

*Base* – `mask` is a power of two, i.e. a single terminal `Ti`.  
Initially `dp[mask][Ti]=0`, all other vertices are `+∞`.  
Running Dijkstra computes the shortest path distances from `Ti` to every vertex,
which are exactly the cheapest ways to connect `Ti` and the vertex `v`
(the tree is just that path). Hence the statement holds.

*Induction step.*  
Assume the statement true for all proper non‑empty sub‑masks of `mask`.  
Consider any optimal tree `S` for `mask` that contains vertex `v`.  
If `v` is a **branch point** where two sub‑trees meet, remove `v` and split `S`
into two trees `S1` and `S2` whose terminal sets are `sub` and `mask-sub`
(the two parts of the tree). Both still contain `v`. By induction,
their costs are `dp[sub][v]` and `dp[mask-sub][v]`. Adding yields
`dp[sub][v] + dp[mask-sub][v]`. The merging loop therefore sets  
`dp[mask][v]` to at most this value.

If `v` lies on a **path** from the root of the optimal tree to some branch
point, then after the merging step the root of the tree coincides with `v`.
The later Dijkstra step can extend a tree whose root is at any vertex to a
tree whose root is any other vertex by exactly the needed path cost.
Consequently Dijkstra can obtain the exact cost of `S`.  

Thus after both steps `dp[mask][v]` is no larger than the optimum.
Conversely, every value created by the algorithm is a sum of costs of
feasible trees (by induction hypothesis) plus possibly additional edge
costs (by Dijkstra), therefore it cannot be smaller than the true optimum.
Hence equality holds. ∎



##### Lemma 3  
For the full mask `F` (all terminals)  
`answer = min_v dp[F][v]` equals the weight of a minimum Steiner tree
connecting all terminals.

**Proof.**  
By Lemma&nbsp;2, for each vertex `v` the value `dp[F][v]` is the cheapest
tree that connects all terminals **and** contains `v`.  
Any Steiner tree necessarily contains at least one vertex, so its weight is
≥ `min_v dp[F][v]`.  
Conversely, the tree realising `min_v dp[F][v]` connects all terminals,
hence is a feasible Steiner tree with that exact weight. ∎



##### Theorem  
The algorithm outputs the minimum total computing power needed to make all
target expressions equivalent.

**Proof.**  
The needed sub‑routines correspond to edges of a Steiner tree for the target
vertices. By Lemma&nbsp;3 the algorithm returns the weight of a minimum such tree,
which is exactly the smallest possible sum of edge costs that achieves the
required equivalence. ∎

#### 7.   Complexity Analysis  

```
states:   (2^t) * n   ≤ 1024 * 100 = 1.0·10^5
merge loops:   O(3^t * n)   ≤ 5.9·10^6
Dijkstra per mask:   O( (2^t) * (m log n) )
                     ≤ 1024 * (4950 * log 100)   < 5·10^6
total time < 0.1 s in Python
memory:   dp array ≈ 1·10^5 integers  →   < 1 MB
```

Both limits are far below the given constraints.

#### 8.   Reference Implementation  (Python 3)

```python
import sys
import heapq

INF = 10 ** 18

def solve() -> None:
    data = list(map(int, sys.stdin.read().strip().split()))
    if not data:
        return
    it = iter(data)
    n = next(it)
    m = next(it)
    t = next(it)

    terminals = [next(it) - 1 for _ in range(t)]          # 0‑based
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = next(it) - 1
        v = next(it) - 1
        w = next(it)
        adj[u].append((v, w))
        adj[v].append((u, w))

    full = (1 << t) - 1
    dp = [[INF] * n for _ in range(full + 1)]

    # singletons
    for i, node in enumerate(terminals):
        dp[1 << i][node] = 0

    # main DP over masks
    for mask in range(1, full + 1):
        # merge two smaller subsets
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            # both sub and other are non‑empty
            for v in range(n):
                cand = dp[sub][v] + dp[other][v]
                if cand < dp[mask][v]:
                    dp[mask][v] = cand
            sub = (sub - 1) & mask

        # Dijkstra to propagate through edges
        pq = [(dp[mask][v], v) for v in range(n) if dp[mask][v] < INF]
        heapq.heapify(pq)
        while pq:
            d, v = heapq.heappop(pq)
            if d != dp[mask][v]:
                continue
            for to, w in adj[v]:
                nd = d + w
                if nd < dp[mask][to]:
                    dp[mask][to] = nd
                    heapq.heappush(pq, (nd, to))

    ans = min(dp[full])
    print(ans)


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input / output format.
