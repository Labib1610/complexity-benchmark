# Problem A — System of Equalities

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing a mathematical model consisting of **n** unknown variables, labeled from 1 to **n**. You are provided with a catalog of potential equality constraints that can be enforced between specific pairs of variables. Each constraint has an associated implementation cost.

An external specification demands that a specific group of **t** variables, designated as the target variables, must be mathematically unified. This means that, through the transitive property of equality, all **t** target variables must be forced to take the exact same value. To achieve this, you may enforce constraints involving any of the **n** variables. Non-target variables can be freely utilized as intermediate links to chain the equalities together.

Your task is to determine the absolute minimum total implementation cost required to enforce a subset of constraints such that all **t** target variables are definitively unified.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers identifying the target variables.
The next **m** lines each provide three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that an equality constraint between variable **u** and variable **v** can be enforced for a cost of **w**.
It is guaranteed that it is possible to unify all target variables using the provided options.

## Output

Output a single integer representing the minimum total implementation cost to ensure all target variables are unified.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, enforcing constraints between variable 4 and each of the target variables (which costs 1+1+1 = 3) forces variables 1, 2, and 3 to equal variable 4. By transitivity, the three target variables are unified. This is more cost-effective than enforcing direct equalities among the target variables (which would cost at least 4). In Example 3, there is only one target variable, so no constraints need to be enforced.
