<STATEMENT>
# Problem A — Subspace Dependencies

Time limit: 5 s   Memory limit: 256 MB

## Description

An algebraic system involves **n** independent variables, denoted $x_1$ through $x_n$.

A vendor offers a collection of **m** optional linear binomials. Each binomial is of the form $x_u - x_v$ for a specific pair of variables $x_u$ and $x_v$, and requires a licensing fee of **w** to acquire. 

You are provided a list of **t** target variables. Your objective is to acquire a subset of these binomials such that, for every pair of target variables $x_a$ and $x_b$, their difference $x_a - x_b$ can be expressed as a linear combination (with real coefficients) of the acquired binomials. You may acquire binomials involving any of the **n** variables to serve as intermediate terms in these linear combinations.

Determine the absolute minimum total licensing fee required to acquire such a subset of binomials.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers representing the indices of the target variables.
The next **m** lines each provide three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that the binomial $x_u - x_v$ is available for a licensing fee of **w**.
It is guaranteed that acquiring all available binomials would allow forming the difference between any pair of target variables.

## Output

Output a single integer representing the minimum total licensing fee required.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, acquiring the binomials $x_1 - x_4$, $x_2 - x_4$, and $x_3 - x_4$ costs 1 + 1 + 1 = 3. From these, we can algebraically form the difference between any pair of target variables (for instance, $x_1 - x_2 = (x_1 - x_4) - (x_2 - x_4)$). This is cheaper than acquiring binomials directly among the target variables, such as $x_1 - x_2$ and $x_2 - x_3$, which would cost 2 + 2 = 4.

In Example 3, with only one target variable, no differences need to be formed, resulting in a minimum fee of 0.

<RATIONALE>
The problem was reframed from equality mandates to linear algebra, specifically finding a minimum-cost set of binomials (vector differences) whose span contains all pairwise differences of a target set of variables. To apply the exact Steiner tree algorithm with shortest-path preprocessing, models must now analytically prove that spanning a difference of basis vectors is mathematically equivalent to forming a connected component in the graph whose edges are the acquired binomials.
</RATIONALE>
<PRESERVED_ANSWER>
The incidence vectors of a graph span the difference $e_a - e_b$ if and only if vertices $a$ and $b$ are in the same connected component, meaning the valid subsets of binomials are exactly the valid connected subgraphs from the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is mathematically isomorphic to the Minimum Weight Steiner Tree problem on a graph, keeping it in NP-complete.
</PRESERVED_CLASS>
