<STATEMENT>
# Problem A — Pressure Equalization

Time limit: 5 s   Memory limit: 256 MB

## Description

A facility houses $n$ sealed gas tanks, numbered 1 to $n$. 

A contractor offers $m$ pipe installation blueprints. Each blueprint connects a specific pair of tanks, $u$ and $v$, and costs $w$ to install. Once a pipe is installed between two tanks, their internal gas pressures become permanently equalized. Because equalization is a transitive property, chains of connected pipes will equalize all tanks within the chain.

You are given a list of $t$ critical tanks. You must select a subset of blueprints to install such that the $t$ critical tanks are guaranteed to stabilize at the exact same pressure, regardless of their initial states. This requires them to be mutually equalized through the installed pipes. The sequence of equalizations may route through any tank in the facility, not just the critical ones.

Find the absolute minimum total installation cost required to achieve this.

The physical limits of the facility dictate the following parameter bounds:
- The number of critical tanks is at least one, and its maximum is exactly the number of years in a decade.
- The total number of tanks is at least one, and its maximum is exactly the square of the maximum number of critical tanks.
- The cost of any single pipe blueprint is a positive integer that never exceeds the cube of the maximum total number of tanks.
- The number of available blueprints is a non-negative integer up to the number of unordered pairs of tanks.

## Input

The first line contains three integers $n$, $m$, and $t$. 
The second line contains $t$ distinct integers representing the identifiers of the critical tanks.
The next $m$ lines each provide three integers $u$, $v$, and $w$, indicating that a pipe between tank $u$ and tank $v$ can be installed for a cost of $w$ ($1 \le u, v \le n$, $u \neq v$).
It is guaranteed that installing all $m$ blueprints would successfully equalize all critical tanks.

## Output

Output a single integer representing the minimum total installation cost required.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, installing the pipes between tank 4 and tanks 1, 2, and 3 costs 1 + 1 + 1 = 3. Under these three pipes, tanks 1, 2, and 3 will all equalize to the same pressure (because they all equalize with tank 4). This costs less than installing the pipes directly among 1, 2, and 3 (which would cost 2 + 2 = 4).

In Example 3, with only one critical tank, no pipe is needed to ensure it equalizes with itself, so the minimum cost is 0.

<RATIONALE>
The problem was reframed into a physical system of gas tanks and pressure equalization, preserving the exact Steiner Tree mechanics. More importantly, all explicit numeric digits bounding the parameters were removed from the Input section and replaced with derived relationships (e.g., "years in a decade" for $t \le 10$, "square of the maximum" for $n \le 100$). This forces the model to logically derive the bounds before it can accurately assess the time complexity. If a model fails to realize $t \le 10$, it will assume $t$ scales with $n$ and incorrectly reject the required $O(3^t n)$ dynamic programming solution as intractable, falling back to an approximation heuristic that yields incorrect answers.
</RATIONALE>
