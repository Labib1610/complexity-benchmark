</METHOD_NAME>
<METHOD_DESCRIPTION>
Transforms the Steiner Tree problem into a logic synthesis scenario. Nodes become boolean propositions, edges become biconditional axioms ($u \leftrightarrow v$), and the Steiner tree requirement becomes a condition that every valid truth assignment must assign the same truth value to all $t$ core propositions. This prevents models from immediately recognizing the graph structure and shortest-path/tree properties.
</METHOD_DESCRIPTION>

yes

<STATEMENT>
# Problem A — Axiomatic Equivalence Enforcement

Time limit: 5 s   Memory limit: 256 MB

## Description

You are designing a logical framework over a universe of **n** distinct propositions, numbered 1 to **n**.

You have a catalog of **m** available biconditional axioms. Each axiom asserts a strict logical equivalence between proposition **u** and proposition **v** (meaning proposition **u** is true if and only if proposition **v** is true). Adopting the axiom that binds **u** and **v** adds a complexity penalty of **w** to your framework.

A truth assignment to the **n** propositions is considered a *valid theory* if it satisfies all the axioms you have chosen to adopt.

You are given a strict requirement involving a set of **t** core propositions. You must adopt a subset of the available axioms such that, in *every* valid theory, if at least one core proposition is true, then all **t** core propositions must be true.

Determine the absolute minimum total complexity penalty required to adopt a subset of axioms that guarantees this condition.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers representing the indices of the core propositions.
The next **m** lines each provide three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that a biconditional axiom between proposition **u** and proposition **v** is available with a complexity penalty of **w**.
It is guaranteed that adopting all available axioms would satisfy the requirement for the core propositions.

## Output

Output a single integer representing the minimum total complexity penalty required.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, adopting the axioms between proposition 4 and propositions 1, 2, and 3 incurs a penalty of 1 + 1 + 1 = 3. Any valid theory satisfying these three axioms must assign the same truth value to propositions 1, 2, 3, and 4. Thus, if any of the core propositions (1, 2, or 3) is true, all of them must be true. This is more efficient than adopting the axioms directly among 1, 2, and 3 (which would incur a penalty of 2 + 2 = 4).

In Example 3, there is only one core proposition. The condition "if at least one core proposition is true, then all 1 core propositions must be true" is vacuously satisfied in every theory without adopting any axioms, so the minimum penalty is 0.
</STATEMENT>
<RATIONALE>
The previous versions failed because models mapped "transpositions" and "orbit-equivalent" directly to graph connectivity, triggering their Steiner Tree templates. This rewrite completely changes the domain to propositional logic and frames the connectivity requirement as a condition on the space of valid truth assignments. To solve it, the model must deduce that the logical condition is mathematically equivalent to requiring all core propositions to be in the same connected component of biconditional axioms, forcing deep structural reasoning rather than surface-level pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The logical condition is satisfied if and only if all core propositions are forced into the same equivalence class by the adopted axioms, which perfectly maps to the original requirement of making them mutually orbit-equivalent, preserving all optimal subset costs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Steiner Tree problem on a graph, with propositions acting as vertices, axioms as edges, penalties as weights, and core propositions as terminal nodes.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "a valid theory" as asking to find just one satisfying assignment rather than quantifying over all possible valid assignments, though the phrasing "in *every* valid theory" is explicitly written to prevent this.
</RISK>
