<METHOD_DESCRIPTION>Replaces the commutative boolean toggle operations (GF(2) addition) with non-commutative permutation swaps (symmetric group transpositions). The reachability condition (generating a specific transposition) still perfectly maps to graph connected components, preserving the Steiner Tree structure and all answers. However, the non-abelian nature and the 2k-1 sequence length required for paths strongly obscures the underlying graph connectivity, leading models to misclassify it as a permutation routing or sorting problem instead of recognizing the Steiner Tree DP.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Warehouse Crate Relocation

Time limit: 5 s   Memory limit: 256 MB

## Description

You are managing a warehouse with **n** storage bays, numbered 1 to $n$. Initially, each bay $k$ contains a unique crate, which we will also refer to as crate $k$.

You can purchase automated swap mechanisms to manipulate the positions of these crates. Each mechanism is hardwired to exactly two distinct bays, $u$ and $v$. When executed, the mechanism simultaneously exchanges the crate currently in bay $u$ with the crate currently in bay $v$.

Once a mechanism is purchased, it is permanently unlocked. You may execute your purchased mechanisms in any order, and you may execute the same mechanism multiple times. 

A specific subset of **t** bays are designated as *critical*. Your task is to purchase a subset of available mechanisms such that the following condition is satisfied: 
For *every* pair of distinct critical bays $i$ and $j$, there must exist some sequence of executions of your purchased mechanisms that transitions the warehouse from its initial state (every crate in its matching bay) to a target state where exactly crate $i$ is in bay $j$, crate $j$ is in bay $i$, and all other $n-2$ crates are in their original starting bays.

The specific sequence of executions may be different for each pair of critical bays, but every sequence may only use mechanisms from the subset you purchased.

You are given a list of **m** available mechanisms, each with a one-time purchase cost **w**. Determine the minimum total cost of a subset of mechanisms that satisfies this requirement.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line lists **t** distinct integers representing the indices of the critical bays (1-indexed).
The following **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1,000,000). These represent an available mechanism wired to bays **u** and **v** that can be purchased for a cost of **w**. (Note that the order of $u$ and $v$ does not matter, as the mechanism swaps them simultaneously).
It is guaranteed that it is possible to satisfy the requirement using the available mechanisms.

## Output

Output a single integer representing the minimum total cost of a subset of mechanisms that allows reaching the required target states for all pairs of critical bays.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```

2 3 1

```

**Output**
```

```

### Example 3

**Input**


**Output**
```
0
```

## Note

In Example 1, the critical bays are 1, 2, and 3. We must be able to reach three target states from the initial arrangement:
- Exactly crates 1 and 2 are swapped.
- Exactly crates 2 and 3 are swapped.
- Exactly crates 1 and 3 are swapped.

By purchasing the three mechanisms wired to (1, 4), (2, 4), and (3, 4) for a total cost of 1+1+1 = 3, we can satisfy the requirement. For instance, to reach the state where exactly crates 1 and 2 are swapped, we can execute the mechanism (1, 4), then (2, 4), and then (1, 4) again. Crate 4 is temporarily moved but returns to bay 4, while crates 1 and 2 end up swapped. This is cheaper than purchasing the mechanisms (1, 2) and (2, 3) directly, which would cost 2+2=4.

In Example 3, there is only one critical bay. Because there are no pairs of distinct critical bays, the requirement is vacuously satisfied. No mechanisms need to be purchased, resulting in a cost of 0.

<RATIONALE>
Changed the boolean toggle framing to a permutation swap framing. The core requirement (generating specific transpositions) remains mathematically isomorphic to graph connectivity (and thus Steiner Tree) because a set of transpositions generates a specific swap if and only if the two elements are in the same connected component. This preserves the operational structure of the seed while obscuring the graph-theoretic nature behind non-abelian symmetric group mechanics.
</RATIONALE>
<PRESERVED_ANSWER>
A set of swap mechanisms (transpositions) can generate a swap between two specific items if and only if those items' starting bays belong to the same connected component in the mechanism graph, making the valid subsets of mechanisms identical to the valid subsets of scripts in the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a minimum-cost subgraph that connects all critical vertices, which is the exact definition of the NP-complete Steiner Tree problem.
</PRESERVED_CLASS>
