<STATEMENT>
# Problem A — Submatrix Positivity

Time limit: 5 s   Memory limit: 256 MB

## Description

You are working with an $n \times n$ matrix $A$. Initially, $A$ is the $n \times n$ identity matrix (that is, $A_{i,i} = 1$ for all $1 \le i \le n$, and $A_{i,j} = 0$ for all $i \ne j$).

You are given a target set of $t$ distinct indices $S = \{k_1, k_2, \ldots, k_t\}$.

You have a list of $m$ available operations. Each operation is defined by two indices $u$ and $v$ and a cost $w$. If you apply this operation, you set both $A_{u,v} = 1$ and $A_{v,u} = 1$.

You may choose to apply any subset of the available operations. You pay the sum of the costs of the operations in your chosen subset. 

Your goal is to ensure that in the resulting matrix $A$, the condition $(A^n)_{i,j} > 0$ holds for all $i \in S$ and $j \in S$. Here, $A^n$ denotes the matrix $A$ raised to the $n$-th power (i.e., the product of $n$ copies of $A$ using standard matrix multiplication).

Determine the minimum total cost of a subset of operations that satisfies this condition.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers representing the indices in the set $S$.
The following **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000). These represent an available operation that sets $A_{u,v} = 1$ and $A_{v,u} = 1$ for a cost of **w**.
It is guaranteed that it is possible to satisfy the condition using the available operations.

## Output

Output a single integer representing the minimum total cost to satisfy the condition.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, choosing the three operations (1, 4), (2, 4), and (3, 4) costs 1+1+1 = 3. This modifies $A$ such that $A_{1,4}=A_{4,1}=A_{2,4}=A_{4,2}=A_{3,4}=A_{4,3}=1$. When this resulting matrix $A$ is raised to the 4th power, $(A^4)_{i,j} > 0$ for all $i,j \in \{1, 2, 3\}$. This is cheaper than choosing operations directly between the target indices (which would cost 2+2=4). 
In Example 3, there is only one target index, 1. Since $A_{1,1} = 1$ initially, $(A^3)_{1,1} \ge 1 > 0$ without applying any operations, so the minimum cost is 0.
</STATEMENT>
<RATIONALE>
I removed all graph-theoretic and equivalence-relation framing by casting the problem as achieving strict positivity in a principal submatrix of the $n$-th power of an adjacency matrix with self-loops. This forces the model to deduce that $(A^n)_{i,j} > 0$ is algebraically equivalent to reachability in an undirected graph, and therefore recognize the problem as finding a minimum-cost subgraph connecting a subset of vertices (Minimum Steiner Tree).
</RATIONALE>
<PRESERVED_ANSWER>
The condition $(A^n)_{i,j} > 0$ for a matrix with 1s on the diagonal holds if and only if there is a path of length at most $n$ between $i$ and $j$ using the chosen off-diagonal entries, which is functionally identical to the original requirement of logically entailing equality between the variables.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Steiner Tree problem on an undirected graph, which is NP-complete, because the matrix operations directly correspond to adding edges to a graph to connect a set of terminal vertices.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret $A^n$ as an element-wise power rather than a matrix product, although the phrase "using standard matrix multiplication" explicitly guards against this.
</RISK>
<METHOD_NAME>
Matrix Power Reachability Disguise
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the concept of "equality constraints" and "logical entailment" with the algebraic property of the n-th power of a binary matrix with 1s on the diagonal. The condition (A^n)_{i,j} > 0 forces the chosen subset of symmetric off-diagonal entries to form a connected component containing the focal indices. Models relying on graph-theoretic keywords or explicit equivalence relations will fail to map this matrix condition to the minimum Steiner tree problem.
</METHOD_DESCRIPTION>
