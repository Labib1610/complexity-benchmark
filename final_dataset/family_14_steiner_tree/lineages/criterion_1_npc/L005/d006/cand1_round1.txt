<METHOD_NAME>Algebraic Incidence Framing</METHOD_NAME>
<METHOD_DESCRIPTION>Transforms a graph connectivity problem into an equivalent linear algebra problem by replacing vertices with basis vectors and edges with difference vectors ($e_u - e_v$). The requirement to connect a subset of vertices becomes a requirement to include specific target vectors in the linear span of the chosen subset. This forces models to bridge the gap between abstract vector spaces and graph components, defeating pattern matching on "equality constraints" or "graphs".</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Basis Span Optimization

Time limit: 5 s   Memory limit: 256 MB

## Description

You are working in an **n**-dimensional real vector space with a standard basis $e_1, e_2, \ldots, e_n$.

You are given a target set of **t** specific dimensions, which are referred to as the *focal dimensions*. Your objective is to construct a subspace $W$ that contains the difference vector $e_i - e_j$ for every pair of focal dimensions $i$ and $j$.

To build this subspace, you can select from a provided list of **m** available *generator vectors*. Each available generator vector is of the form $e_u - e_v$ and has an associated cost of **w**. 

You may choose any subset of the available generator vectors to purchase, paying the sum of their costs. The subspace $W$ is then defined exactly as the linear span of your chosen subset of generator vectors. 

You are permitted to purchase generator vectors that involve non-focal dimensions, as long as the resulting linear span $W$ contains the required $e_i - e_j$ vectors for all focal dimensions $i$ and $j$.

Determine the minimum total cost of a subset of generator vectors whose linear span satisfies this requirement.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line lists **t** distinct integers representing the indices of the focal dimensions.
The following **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000). These represent an available generator vector $e_u - e_v$ that can be purchased for a cost of **w**. (Note that the linear span is independent of the sign of the vector, so $e_u - e_v$ and $e_v - e_u$ are equivalent).
It is guaranteed that it is possible to form a valid subspace using the available generator vectors.

## Output

Output a single integer representing the minimum total cost of a subset of generator vectors whose linear span contains $e_i - e_j$ for all focal dimensions $i$ and $j$.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the focal dimensions are 1, 2, and 3. We require the subspace $W$ to contain $e_1 - e_2$, $e_2 - e_3$, and $e_1 - e_3$. By purchasing the three generator vectors $e_1 - e_4$, $e_2 - e_4$, and $e_3 - e_4$ (total cost 1+1+1 = 3), their linear span contains the required vectors. For instance, $(e_1 - e_4) - (e_2 - e_4) = e_1 - e_2$. This is cheaper than purchasing the vectors $e_1 - e_2$ and $e_2 - e_3$ directly (which would cost 2+2=4). 

In Example 3, there is only one focal dimension. The requirement is vacuously satisfied because $e_1 - e_1$ is the zero vector, which is contained in every subspace. Thus, 0 generator vectors need to be purchased.
</STATEMENT>
<RATIONALE>
I changed the framing from logical equality constraints to constructing a subspace in a real vector space using difference vectors ($e_u - e_v$). This forces models to recognize that the linear span of these specific difference vectors corresponds exactly to the connected components of a graph (via the incidence matrix), a mathematical equivalence that demands genuine reasoning and defeats simple keyword-based pattern matching for the Steiner Tree problem.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical property that $e_i - e_j$ is in the linear span of a set of difference vectors if and only if $i$ and $j$ are in the same connected component ensures every valid subset of vectors exactly matches a valid subset of equality constraints.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains identically the minimum-weight Steiner Tree problem on a graph (or equivalently on a graphic matroid), which is NP-complete, and the identical Dreyfus-Wagner subset DP algorithm still solves it.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "linear span" as allowing fractional purchases of vectors, though the text explicitly restricts choices to a discrete "subset of the available generator vectors to purchase".
</RISK>
