# Problem A — Synchronization Links

Time limit: 5 s   Memory limit: 256 MB

## Description

An industrial facility operates **n** automated workstations (numbered 1 through **n**). A specific subset of **t** primary workstations must be able to synchronize their operations together.

Synchronization is achieved by establishing dedicated bidirectional data links between pairs of workstations. The facility has a set of potential links that can be activated, each requiring a known continuous energy draw. 

A synchronization signal can pass between two workstations if there is an active link between them. The synchronization routing cascades: if workstation A can exchange signals with B, and B can exchange signals with C, then A and C are synchronized.

Your task is to determine the minimum total continuous energy draw required to activate a combination of links such that every primary workstation can synchronize with every other primary workstation.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the identifiers of the primary workstations.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), representing a potential bidirectional data link between workstation **u** and workstation **v** that requires **w** units of energy to activate.
It is guaranteed that there exists at least one combination of links that allows all primary workstations to synchronize.

## Output

Print a single integer: the minimum total energy draw required to ensure all primary workstations are synchronized.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the optimal configuration activates the links between (1, 4), (2, 4), and (3, 4) for a total energy draw of 1 + 1 + 1 = 3. In Example 3, there is only one primary workstation, requiring a total energy draw of 0.
