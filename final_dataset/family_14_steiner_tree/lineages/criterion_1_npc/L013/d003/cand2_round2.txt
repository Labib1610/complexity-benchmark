# Problem A — Aggregator Interconnects

Time limit: 5 s   Memory limit: 256 MB

## Description

A distributed computing cluster consists of **n** processing nodes, numbered 1 through **n**. Within this cluster, a specific group of **t** nodes are designated as *primary aggregators*.

For the cluster to function correctly, all primary aggregators must participate in a unified state-sharing protocol. This requires establishing a continuous communication framework where every primary aggregator can route messages to every other primary aggregator. Messages can be routed through any number of intermediate nodes.

The cluster has a physical topology of **m** potential bidirectional interconnects. Each interconnect bridges two specific nodes and requires a fixed continuous power allocation to be powered on. Once powered on, an interconnect provides unlimited bidirectional routing capacity and can be utilized simultaneously by multiple message routes between different primary aggregators without requiring additional power.

Your task is to determine the minimum total power allocation required to power on a set of interconnects such that every primary aggregator can successfully route messages to all other primary aggregators.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the identifiers of the primary aggregators.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), representing a potential bidirectional interconnect between node **u** and node **v** that requires **w** units of power to power on.
It is guaranteed that there exists at least one set of interconnects that allows all primary aggregators to be mutually connected.

## Output

Print a single integer: the minimum total power allocation required to ensure all primary aggregators are mutually connected.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the optimal configuration powers on the interconnects between (1, 4), (2, 4), and (3, 4) for a total power allocation of 1 + 1 + 1 = 3. In Example 3, there is only one primary aggregator, requiring a total power allocation of 0.
