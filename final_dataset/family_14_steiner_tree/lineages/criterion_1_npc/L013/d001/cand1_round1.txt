# Problem A — Core Synchronization

Time limit: 5 s   Memory limit: 256 MB

## Description

An industrial complex operates **n** distinct processing units. A specific subset of these units are designated as core controllers. For the complex to function safely, all core controllers must be able to exchange heartbeat signals with one another.

You have the option to power on bidirectional fiber-optic connections between certain pairs of units. Each connection has a known continuous power consumption when activated.

Heartbeat signals can route through any sequence of powered-on connections. The routing is fully transitive: if a signal can travel from unit A to unit B, and from unit B to unit C, then unit A and unit C can successfully communicate.

Your task is to identify a viable configuration of powered connections that allows full communication among the core controllers, while minimizing the total power draw of those connections. You are free to power on connections that route through ordinary, non-core units if doing so results in a lower overall power consumption.

## Input

The first line contains three integers **n**, **m**, and **t**. The total number of processing units **n** is between 1 and 100, and the number of available connections **m** is between 0 and **n**·(**n**−1)/2. The architecture of the complex designates **t** of these units (where 1 ≤ **t** ≤ 10) as core controllers.

The second line contains **t** distinct integers between 1 and **n**: the identifiers of the core controllers.

The next **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000), representing an available connection between unit **u** and unit **v** that consumes **w** units of power.

It is guaranteed that it is possible to connect all core controllers.

## Output

Print a single integer: the minimum total power consumption required to ensure all core controllers can exchange heartbeat signals.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, routing the heartbeat signals through the ordinary unit 4 (consuming 1+1+1 = 3 power) is more efficient than linking the three core controllers directly (which would consume 2+2 = 4 power). In Example 3, there is only one core controller, so no connections need to be powered on (0 power).
