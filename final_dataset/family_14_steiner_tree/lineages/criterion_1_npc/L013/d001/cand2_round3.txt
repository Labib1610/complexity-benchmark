<STATEMENT>
# Problem A — Signal Integration

Time limit: 5 s   Memory limit: 256 MB

## Description

A facility operates **n** hardware units (identified by integers from 1 to **n**). Within this facility, a specific group of **t** primary units must be integrated so they can freely exchange signals.

You have the option to activate bidirectional signal channels between specific pairs of units. Activating a channel comes with a continuous energy cost.

Signal exchange is transitive: if a channel is active between unit A and unit B, and another between unit B and unit C, then signals can travel between unit A and unit C.

Your objective is to activate a collection of channels that allows every primary unit to exchange signals with every other primary unit. You may activate channels that route through non-primary units if doing so results in a lower total energy cost than connecting the primary units exclusively among themselves.

Determine the minimum total energy required to activate a valid configuration of channels.

## Input

The first line contains three integers **n**, **m**, and **t**. The facility's specifications dictate that the unit count **n** is between 1 and 100. The primary unit count **t** is constrained between 1 and 10 by the available slots on the main control board. The number of potential channels **m** is between 0 and **n**·(**n**−1)/2.

The second line contains **t** distinct integers: the identifiers of the primary units.

Each of the next **m** lines contains three integers **u**, **v**, and **w**. These represent a potential bidirectional channel between unit **u** and unit **v** (where **u** and **v** are distinct integers between 1 and **n**, and **u** ≠ **v**). The energy requirement **w** is between 1 and 1000000.

It is guaranteed that the available potential channels are sufficient to integrate all primary units.

## Output

Print a single integer: the minimum total energy required to activate a set of channels such that all primary units can exchange signals with each other.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, routing the signals through the non-primary unit 4 (requiring 1+1+1 = 3 energy) is more efficient than linking the three primary units directly (which would require 2+2 = 4 energy). In Example 3, there is only one primary unit, so no channels need to be activated (0 energy).
