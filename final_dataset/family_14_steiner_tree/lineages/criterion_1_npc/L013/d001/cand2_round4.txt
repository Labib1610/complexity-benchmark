<STATEMENT>
# Problem A — Network Integration

Time limit: 5 s   Memory limit: 256 MB

## Description

An infrastructure project involves **N** sites (identified by integers from 1 to **N**). A specific group of **P** mandatory sites must be fully integrated so they can communicate with one another.

You have the option to build bidirectional communication channels between certain pairs of sites. Each potential channel has an associated integer construction cost.

Communication can route through any sequence of built channels. If a path of built channels connects two sites, they can communicate. This means if site A can communicate with site B, and site B with site C, then site A can communicate with site C.

Your objective is to choose a set of channels to build such that every mandatory site can communicate with every other mandatory site. You are permitted to build channels that connect to or pass through non-mandatory sites, if utilizing them as intermediate routing points results in a lower total construction cost.

Determine the minimum total cost required to build a valid set of channels.

## Input

The first line contains three integers **N**, **M**, and **P**. The total number of sites **N** is at least 1 and capped at 100. The number of mandatory sites **P** is at least 1 and cannot exceed the 10 available priority slots. The number of potential channels **M** is between 0 and **N**·(**N**−1)/2.

The second line contains **P** distinct integers: the identifiers of the mandatory sites.

Each of the next **M** lines contains three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **N**, **u** ≠ **v**), representing a potential bidirectional channel between site **u** and site **v**. The construction cost **w** is an integer from 1 to 1000000.

It is guaranteed that there is at least one way to build channels such that all mandatory sites can communicate.

## Output

Print a single integer: the minimum total cost required to build channels so that all mandatory sites can communicate with each other.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, building channels through the non-mandatory site 4 (costing 1+1+1 = 3) is more cost-effective than connecting the three mandatory sites directly (which would cost 2+2 = 4). In Example 3, there is only one mandatory site, so no channels need to be built (cost 0).
