# Problem A — Telemetry Synchronization

Time limit: 5 s   Memory limit: 256 MB

## Description

An industrial complex is managed by a network of processing units. The facility is composed of 10 identical server racks, each capable of holding 10 processing units, which dictates the maximum possible value for the total number of processing units, **n**. These units are identified by integers from 1 to **n**, and there is always at least one unit present in the network.

Within this network, a specific group of **t** units acts as primary terminals. A unit is designated as a primary terminal if it is wired directly to the external sensor array. This array features exactly 10 interface ports, which establishes the strict upper limit on the number of primary terminals **t** in any given configuration. There will always be at least one primary terminal. It is strictly required that all primary terminals can exchange telemetry with one another.

You have the option to open bidirectional telemetry channels between certain pairs of processing units. The number of available potential channels, **m**, can be zero, or it can be as large as the theoretical maximum number of unique pairs among the **n** units. Opening a channel requires a continuous energy overhead. The energy overhead for any single channel is always a positive integer, bounded from above by the one-million unit capacity of a standard micro-reactor.

Telemetry exchange is transitive across open channels: if unit A can communicate with unit B, and unit B can communicate with unit C, then unit A can communicate with unit C. 

Your objective is to determine the most energy-efficient way to open a subset of the available channels so that every primary terminal can exchange telemetry with every other primary terminal. You are permitted to route telemetry through standard, non-primary units if using them as intermediaries reduces the total energy overhead.

Find the minimum total energy overhead required to achieve full synchronization among the primary terminals.

## Input

The first line of input provides three integers: **n**, **m**, and **t**.
The second line provides **t** distinct integers representing the identifiers of the primary terminals.
The subsequent **m** lines each describe a potential telemetry channel using three integers **u**, **v**, and **w**. This indicates that a bidirectional channel can be opened between unit **u** and unit **v** (**u** ≠ **v**) at an energy overhead of **w**.
It is guaranteed that the available channels are sufficient to allow all primary terminals to be interconnected.

## Output

Output a single integer representing the minimum total energy overhead required to open a valid configuration of channels.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, routing telemetry through the standard unit 4 (costing 1+1+1 = 3 energy overhead) is more efficient than linking the three primary terminals directly (which would cost 2+2 = 4 energy overhead). In Example 3, there is only one primary terminal, meaning synchronization is already trivially achieved without opening any channels (0 energy overhead).
