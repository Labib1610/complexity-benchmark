We can model this as finding the minimum cost to connect all critical formats, where we can choose any node as the root (native format).  
This is equivalent to finding the **minimum Steiner tree** for the set of critical nodes, but since \( t \le 10 \), we can use a **bitmask DP** over subsets of critical nodes.

We can:
1. Compute all-pairs shortest paths (Floyd–Warshall) on the given graph.
2. Use DP over subsets of critical nodes:
   - `dp[mask][v]` = minimum cost to connect the critical nodes in `mask` with `v` as the root of the connected subgraph.
   - Initialize `dp[1<<i][c_i] = 0`.
   - Combine subsets: `dp[mask][v] = min(dp[mask][v], dp[sub][v] + dp[mask^sub][v])`.
   - Relax with shortest paths: `dp[mask][v] = min(dp[mask][v], dp[mask][u] + dist[u][v])`.
3. Answer is `min_v dp[(1<<t)-1][v]`.

Here’s the implementation:

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    n, m, t = map(int, input_data[:3])
    critical = list(map(int, input_data[3:3+t]))
    edges = []
    idx = 3 + t
    for _ in range(m):
        u = int(input_data[idx])
        v = int(input_data[idx+1])
        w = int(input_data[idx+2])
        idx += 3
        edges.append((u-1, v-1, w))
    
    INF = 10**18
    dist = [[INF]*n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0
    for u, v, w in edges:
        if w < dist[u][v]:
            dist[u][v] = w
            dist[v][u] = w
    
    # Floyd-Warshall
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]
    
    # Map critical nodes to indices 0..t-1
    crit_idx = [c-1 for c in critical]
    
    full_mask = (1 << t) - 1
    dp = [[INF]*n for _ in range(1 << t)]
    
    for i, c in enumerate(crit_idx):
        dp[1 << i][c] = 0
    
    for mask in range(1 << t):
        # Combine subsets
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if sub < other:  # avoid double work
                for v in range(n):
                    if dp[sub][v] + dp[other][v] < dp[mask][v]:
                        dp[mask][v] = dp[sub][v] + dp[other][v]
            sub = (sub - 1) & mask
        
        # Relax with shortest paths
        for v in range(n):
            for u in range(n):
                if dp[mask][u] + dist[u][v] < dp[mask][v]:
                    dp[mask][v] = dp[mask][u] + dist[u][v]
    
    ans = min(dp[full_mask])
    print(ans)

if __name__ == "__main__":
    solve()
```
