# Problem A — Superpixel Segmentation

Time limit: 5 s   Memory limit: 256 MB

## Description

You are processing an image abstracted as **n** distinct regions, indexed 1 through **n**.
An object recognition module has identified **t** key regions that belong to the same foreground object. Your task is to merge regions until all **t** key regions are fused into a single continuous superpixel.

You have a list of **m** valid boundary dissolutions. Dissolving the boundary between region `u` and region `v` costs **w** processing cycles. When a boundary is dissolved, the two regions fuse completely.
Fusing is an ongoing process: if region A fuses with region B, and B fuses with C, they all become part of one massive superpixel.

You may dissolve boundaries involving non-key regions; these can act as spatial bridges to fuse the key regions if it results in fewer total processing cycles.

Determine the minimum total processing cycles required to dissolve a set of boundaries such that all **t** key regions are fused into the exact same superpixel. (If **t**=1, no boundaries need to be dissolved and the minimum cost is 0).

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2), representing the total number of regions, the number of valid boundary dissolutions, and the number of key regions.
The second line contains **t** distinct integers $c_1, c_2, \dots, c_t$: the indices of the key regions.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that the boundary between region `u` and region `v` can be dissolved at a cost of **w** cycles.
It is guaranteed that the available dissolutions are sufficient to fuse all key regions.

## Output

Print a single integer: the minimum total processing cycles to dissolve a set of boundaries that satisfies the requirement.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the key regions are 1, 2, and 3. You can dissolve the boundaries between (1,4), (2,4), and (3,4) for a total cost of 1+1+1 = 3 cycles. Because region 1 fuses with 4, and 2 fuses with 4, they become one superpixel. Similarly, 3 fuses with 4, so all three key regions are fused into the same superpixel. Alternatively, dissolving boundaries for (1,2) and (2,3) directly would cost 2+2 = 4 cycles. The minimum cost is 3. 

In Example 3, there is only one key region ($t=1$), so no boundaries need to be dissolved and the minimum cost is 0.
