# Problem A — Cryptographic State Alignment

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing a system of $n$ cryptographic state registers. Your objective is to publicly establish that a specific critical subset of $t$ target registers all contain the identical underlying value.

To achieve this without revealing the actual values, you can publish pairwise zero-knowledge equality proofs. You are provided with a list of $m$ available proofs that can be generated. Each available proof asserts the exact equality of two specific registers, $u$ and $v$. Generating and publishing this proof consumes a specific computational cost $w$. 

When a set of proofs is published, the equality of other registers can be deduced through logical transitivity (if $u=v$ and $v=k$ are proven, $u=k$ is implicitly proven). Your task is to select a subset of the available proofs to publish such that it becomes logically indisputable that all $t$ target registers are equal to one another. 

Determine the minimum total computational cost required to publish a valid subset of proofs. (If the number of target registers is exactly one, no proofs are required, and the minimum cost is 0).

## Input

The first line contains three integers **n**, **m**, and **t**. The bounds are defined as follows: the number of target registers, **t**, is at least one and at most the number of distinct digits in the standard base-10 numeral system. The total number of registers, **n**, is at least one and at most the square of the absolute maximum possible value of **t**. The number of available proofs, **m**, is non-negative and at most the number of unique two-element subsets that can be chosen from a set of **n** items.
The second line contains **t** distinct integers $c_1, c_2, \dots, c_t$: the indices of the target registers.
Each of the next **m** lines contains three integers **u**, **v**, and **w**. This indicates that an equality proof between register **u** and register **v** can be published for a cost of **w**. The indices **u** and **v** are distinct and between 1 and **n** inclusive. The cost **w** is a positive integer no greater than one million.
It is guaranteed that it is always possible to prove all target registers equal using the available proofs.

## Output

Print a single integer: the minimum total computational cost.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```

1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the target registers are 1, 2, and 3. You can publish the proofs for 1=4, 2=4, and 3=4 for a total cost of 1+1+1 = 3. 
By publishing these proofs, it is established that registers 1, 2, and 3 are all equal to register 4, and therefore logically equal to each other. 
Alternatively, you could publish the proofs for 1=2 and 2=3 for a total cost of 2+2 = 4 to establish that 1=2=3. The minimum cost is 3.

In Example 3, there is only one target register, so no proofs are needed. The minimum cost is 0.
