# Problem A — Permutation Group Orbits

Time limit: 5 s   Memory limit: 256 MB

## Description

You are studying the symmetric group $S_n$ acting on the set $X = \{1, 2, \dots, n\}$. 
Your objective is to enforce an algebraic condition on a critical subset of $t$ target elements, identified by $c_1, c_2, \dots, c_t$.

To do this, you are provided with a list of $m$ available transpositions. Each transposition is specified by two distinct elements, $u$ and $v$, and an acquisition cost $w$. Acquiring this transposition gives you the permutation $(u, v)$ which swaps $u$ and $v$ while leaving all other elements fixed.

You must select a subset of these available transpositions to acquire. Let $H$ be the subgroup of $S_n$ generated by your selected transpositions. 
The action of $H$ partitions the set $X$ into disjoint orbits. Two elements $x, y \in X$ belong to the same orbit if there exists some permutation $h \in H$ such that $h(x) = y$.

Determine the minimum total acquisition cost for a subset of transpositions such that the $t$ target elements $c_1, c_2, \dots, c_t$ all belong to the exact same orbit under $H$. (If $t=1$, the condition is trivially satisfied with an empty subset and a cost of 0).

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2), representing the size of the set $X$, the number of available transpositions, and the number of target elements.
The second line contains **t** distinct integers $c_1, c_2, \dots, c_t$: the target elements.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that the transposition $(u, v)$ is available for an acquisition cost of w.
It is guaranteed that acquiring all available transpositions would place all target elements in the same orbit.

## Output

Print a single integer: the minimum total acquisition cost.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the target elements are 1, 2, and 3. You can acquire the transpositions (1, 4), (2, 4), and (3, 4) for a total cost of 1+1+1 = 3. 
The subgroup $H$ generated by these three transpositions acts transitively on the entire set $\{1, 2, 3, 4\}$, meaning there is only one orbit. Thus, the target elements 1, 2, and 3 belong to the same orbit. 
Alternatively, you could acquire the transpositions (1, 2) and (2, 3) for a total cost of 2+2 = 4. The subgroup $H$ generated by these two transpositions has orbits $\{1, 2, 3\}$ and $\{4\}$. The target elements are in the same orbit, but the cost is 4. The minimum cost is 3.

In Example 3, there is only one target element ($t=1$), so no transpositions need to be acquired. The minimum cost is 0.

<RATIONALE>
I recast the problem into abstract algebra, asking for the minimum cost to select transpositions such that a target set falls into a single orbit under the generated subgroup. Crucially, I completely removed the explicit sentence permitting the use of non-target elements, which models were using as a direct hint to build a Steiner Tree. By relying strictly on the mathematical definition of selecting a subset from the available operations, the affordance is eliminated without changing the problem's underlying reality.
</RATIONALE>

The orbits of a subgroup generated by transpositions correspond exactly to the connected components of the graph where those transpositions are edges, meaning the minimum cost to unify the targets remains exactly the minimum Steiner Tree cost.
