# Problem A — Register Synchronization

Time limit: 5 s   Memory limit: 256 MB

## Description

You are configuring the clock domains of a processor containing **n** hardware registers (numbered 1 to n). Initially, each register operates on its own independent clock. 

You can fuse the clock domains of certain pairs of registers by installing a phase-locker between them. Installing a phase-locker incurs a known hardware cost and merges the two registers' domains. Consequently, they—along with any other registers that have already been merged into either's domain—will permanently share a single, unified clock.

The processor relies on a specific group of **t** critical registers. Your objective is to purchase a set of phase-lockers so that these **t** registers all end up operating within the exact same clock domain. The other registers in the processor do not have this requirement, but you are free to incorporate them into the unified domain if doing so yields a lower overall installation cost.

Determine the minimum total cost of the phase-lockers needed to place all critical registers into a single clock domain.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2), representing the total number of registers, the number of available phase-locker connections, and the number of critical registers.
The second line contains **t** distinct integers: the identifiers of the critical registers.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): indicating that a phase-locker can be installed between register u and register v at a cost of w.
It is guaranteed that the available phase-lockers are sufficient to place all critical registers into a single domain.

## Output

Print a single integer: the minimum total cost to place all critical registers into a single clock domain.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, placing the three critical registers into a single domain by installing phase-lockers that include register 4 (costs 1+1+1 = 3) is cheaper than installing phase-lockers directly between the critical registers (which would cost 4). In Example 3, there is only one critical register, so no phase-lockers are needed.
