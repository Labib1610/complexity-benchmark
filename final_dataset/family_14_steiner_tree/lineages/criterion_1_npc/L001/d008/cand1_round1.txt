<METHOD_NAME>Linear Algebraic Isomorphism</METHOD_NAME>
<METHOD_DESCRIPTION>Transforms the graph-theoretic Minimum Weight Steiner Tree problem into an equivalent linear algebra problem. Vertices become standard basis vectors, edges become difference vectors, and connected components become linear spans. This completely removes all graph vocabulary and structural hints, baiting models into attempting greedy matroid algorithms or Gaussian elimination, while preserving the exact mathematical constraints.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Subspace Spanning

Time limit: 5 s   Memory limit: 256 MB

## Description

You are working in an **n**-dimensional vector space over the real numbers, which has a standard basis $b_1, b_2, \dots, b_n$. 
You are given a list of **t** critical indices: $c_1, c_2, \dots, c_t$.
Your objective is to construct a set of vectors $S$ such that, for every pair of critical indices $c_i$ and $c_j$ ($1 \le i < j \le t$), the difference vector $b_{c_i} - b_{c_j}$ lies within the linear span of $S$.

You must construct $S$ by purchasing vectors from a provided catalog of **m** available vectors. 
Each available vector in the catalog is specified by two indices $u$ and $v$, representing the vector $b_u - b_v$, and has an associated cost $w$. 
You may purchase any subset of the vectors from the catalog. You only pay the cost $w$ once for each vector you include in $S$. 
(Since you are forming a linear span, you can use any real coefficients when combining the vectors in $S$. For example, if you purchase $b_u - b_v$, you can multiply it by $-1$ to obtain $b_v - b_u$ in the span).

Determine the minimum total cost required to purchase a set $S$ that satisfies the condition for all critical indices. (If $t=1$, no difference vectors need to be spanned, and the minimum cost is 0).

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2), representing the dimension of the space, the number of available vectors in the catalog, and the number of critical indices.
The second line contains **t** distinct integers $c_1, c_2, \dots, c_t$: the critical indices.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that the vector $b_u - b_v$ is available in the catalog for a cost of w.
It is guaranteed that it is possible to span the required difference vectors using the available vectors.

## Output

Print a single integer: the minimum total cost.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the critical indices are 1, 2, and 3. You need to span $b_1 - b_2$, $b_1 - b_3$, and $b_2 - b_3$. You can purchase the vectors $b_1 - b_4$, $b_2 - b_4$, and $b_3 - b_4$ for a total cost of 1+1+1 = 3. 
Because $(b_1 - b_4) - (b_2 - b_4) = b_1 - b_2$, the vector $b_1 - b_2$ is in the span. The other required vectors can be formed similarly. 
Alternatively, you could purchase $b_1 - b_2$ and $b_2 - b_3$ for a total cost of 2+2 = 4. The minimum cost is 3.

In Example 3, there is only one critical index ($t=1$), so there are no pairs of critical indices, and no difference vectors need to be spanned. The minimum cost is 0.
</STATEMENT>
<RATIONALE>
The problem was completely reframed from a graph-theoretic network design task into a linear algebra problem about spanning a subspace. The underlying mathematical structure is identical (the incidence matrix of a graph is totally unimodular, and spanning a difference of basis vectors is exactly equivalent to connecting two vertices), but all graph vocabulary and structural hints have been removed to prevent pattern-matching to Steiner Tree.
</RATIONALE>
<PRESERVED_ANSWER>
The linear span of a set of difference vectors $b_u - b_v$ contains $b_x - b_y$ if and only if $x$ and $y$ are in the same connected component of the graph formed by the chosen vectors, making the minimum cost required identical to the original Steiner Tree problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Minimum Weight Steiner Tree in an undirected graph, which is NP-complete, simply represented through its exact linear algebra isomorphism.
</PRESERVED_CLASS>
<RISK>
Models could theoretically attempt to solve it using Gaussian elimination or matroid intersection over the real numbers, but this is a natural consequence of the linear algebra framing and not an ambiguity in the wording.
</RISK>
