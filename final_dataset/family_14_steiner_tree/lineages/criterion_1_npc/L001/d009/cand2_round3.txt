<METHOD_NAME>Universal Zero-Sum Routing Formulation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit requirement to "merge into a unified group" with the mathematically equivalent condition that the selected edges must support any arbitrary zero-sum routing demand among the mandatory nodes. This removes connectivity and clustering keywords while preserving the exact requirement (which implies the mandatory nodes must all lie in the same connected component).</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Universal Resource Routing

Time limit: 5 s   Memory limit: 256 MB

## Description

You are designing a routing infrastructure for a network of **n** sites, numbered 1 through **n**. 
Your objective is to ensure that a designated set of **t** mandatory sites, identified as $c_1, c_2, \dots, c_t$, can freely exchange resources.

Specifically, you must select a subset of **m** available bidirectional links to construct. Each link connects two sites, $u$ and $v$, and requires a one-time construction cost of $w$. Once constructed, a link has unlimited capacity to transfer resources in either direction.

The selected links must satisfy the universal routing condition for the mandatory sites: for any assignment of supply and demand to the **t** mandatory sites such that the total supply equals the total demand (a zero-sum distribution), it must be possible to route the resources from the suppliers to the demanders using only the constructed links. You may route resources through any of the **n** sites, whether they are mandatory or not, to achieve this.

Determine the minimum total construction cost required to select a subset of links that satisfies this universal routing condition. (If $t=1$, no exchanges are necessary, so the minimum cost is 0).

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2), representing the total number of sites, the number of available links, and the number of mandatory sites.
The second line contains **t** distinct integers $c_1, c_2, \dots, c_t$: the identifiers of the mandatory sites.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that a bidirectional link between site u and site v can be constructed for a cost of w.
It is guaranteed that the available links are sufficient to satisfy the routing condition.

## Output

Print a single integer: the minimum total construction cost.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the mandatory sites are 1, 2, and 3. You can construct the links (1,4), (2,4), and (3,4) for a total cost of 1+1+1 = 3. This allows any zero-sum resource exchange among sites 1, 2, and 3 by routing through site 4. Alternatively, you could construct links (1,2) and (2,3) for a total cost of 2+2 = 4. The minimum cost is 3.

In Example 3, there is only one mandatory site ($t=1$), so no exchanges are necessary. The minimum cost is 0.
</STATEMENT>
<RATIONALE>
The problem was rewritten to use a universal zero-sum routing condition instead of explicitly asking to unify clusters into a single group. Because a set of nodes can support any arbitrary zero-sum flow if and only if they are all in the same connected component, the structural requirement remains identical. This forces models to logically deduce that the problem is asking for a connected subgraph spanning the mandatory sites, bypassing models that rely on "merge" or "unify" keywords to trigger Steiner tree algorithms.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the selected links can route any zero-sum distribution among the mandatory sites is mathematically equivalent to requiring that all mandatory sites belong to the same connected component, so the set of valid edge subsets and their costs remain identically constrained.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Weight Steiner Tree problem on graphs, which is NP-complete, because the task is still to find a minimum-cost subset of edges that connects a given subset of terminal nodes.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret the routing condition as requiring distinct paths for different flows simultaneously, but the phrase "for any assignment... it must be possible to route" implies a static evaluation of connectivity rather than a multi-commodity flow over time.
</RISK>
