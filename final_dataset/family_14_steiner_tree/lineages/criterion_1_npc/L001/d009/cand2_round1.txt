# Problem A — Zero-Sum Liquid Routing

Time limit: 5 s   Memory limit: 256 MB

## Description

You are managing a fluid distribution network with **n** reservoirs, numbered 1 through **n**. 
Your specific objective is to ensure that a critical subset of **t** reservoirs, identified as $c_1, c_2, \dots, c_t$, can freely exchange fluid among themselves without any bottlenecks.

You are provided with a list of **m** potential bidirectional pipelines. Each pipeline connects two distinct reservoirs, $u$ and $v$, and requires a one-time construction cost of $w$. Once constructed, a pipeline has infinite flow capacity in both directions.

You must choose one specific subset of these pipelines to construct. This single chosen subset must be capable of successfully routing **any** hypothetical fluid transfer scenario among the critical reservoirs. 
A hypothetical transfer scenario assigns a demand $D_i$ (which can be any real number: positive, negative, or zero) to each critical reservoir $c_i$, such that the sum of all demands is exactly 0 ($\sum_{i=1}^t D_i = 0$). 
To successfully route a scenario, there must exist a valid flow through your constructed pipelines where:
- The net flow leaving critical reservoir $c_i$ is exactly $D_i$.
- The net flow leaving any non-critical reservoir is exactly 0 (strict flow conservation).

Determine the minimum total construction cost required to build a single subset of pipelines that can satisfy every possible valid transfer scenario. (If $t=1$, the only valid scenario trivially has $D_1=0$, requiring no pipelines, so the minimum cost is 0).

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2), representing the total number of reservoirs, the number of potential pipelines, and the number of critical reservoirs.
The second line contains **t** distinct integers $c_1, c_2, \dots, c_t$: the identifiers of the critical reservoirs.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that a pipeline between reservoir u and reservoir v can be constructed for a cost of w.
It is guaranteed that the available pipelines are sufficient to satisfy the requirement.

## Output

Print a single integer: the minimum total construction cost.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the critical reservoirs are 1, 2, and 3. You can construct pipelines (1,4), (2,4), and (3,4) for a total cost of 1+1+1 = 3. 
With these pipelines, any zero-sum demand on reservoirs 1, 2, and 3 can be routed through reservoir 4. For instance, if a scenario requires $D_1 = 5$, $D_2 = -3$, and $D_3 = -2$, you can route 5 units from 1 to 4, then 3 units from 4 to 2, and 2 units from 4 to 3. All non-critical reservoirs (reservoir 4) will correctly have a net flow of 0. 
Alternatively, constructing pipelines (1,2) and (2,3) costs 2+2=4 and also allows routing any scenario. The minimum cost is 3.

In Example 3, there is only one critical reservoir ($t=1$), so the only valid scenario is $D_1=0$. No pipelines are needed, and the minimum cost is 0.

<RATIONALE>
I changed the problem from "unifying clusters using merge procedures" to "designing a fluid network capable of routing any zero-sum flow demand among critical reservoirs". This forces the model to mathematically deduce that "capable of routing any zero-sum flow demand on infinite-capacity edges" is exactly equivalent to "the critical reservoirs are in the same connected component". Models relying on surface pattern-matching will likely misclassify this as a multi-commodity flow or robust network design problem.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that any zero-sum flow demand can be routed on infinite-capacity edges is mathematically equivalent to requiring all critical nodes to be in the same connected component of the chosen subgraph, ensuring the exact same valid subgraphs and minimum cost.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the Minimum Steiner Tree problem (NP-complete) because the structural requirement (connecting a subset of terminals) and the objective (minimizing edge weights) are identical to the seed.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret the flow requirement as needing strong connectivity or 2-edge connectivity, though the specification of "infinite flow capacity in both directions" on undirected edges makes 1-edge connectivity logically sufficient.
</RISK>
