<METHOD_NAME>
Universal Flow Routing
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the concept of a connected subgraph (Steiner Tree) with a universal flow routing requirement. The problem asks for a minimum-cost subset of edges capable of routing any zero-sum demand vector over the terminals. This is mathematically equivalent to connectivity but obscures the graph-theoretic nature of the objective, preventing models from pattern-matching to Steiner tree algorithms.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<STATEMENT>
# Problem A — Cluster Unification

Time limit: 5 s   Memory limit: 256 MB

## Description

You are designing a routing infrastructure for a network of **n** sites, numbered 1 through **n**. Among these, a specific subset of **t** sites, identified as $c_1, c_2, \dots, c_t$, are designated as primary distribution hubs.

You are provided with a list of **m** potential bidirectional pipelines. Each pipeline connects two sites, $u$ and $v$, and requires a one-time construction cost of $w$. Once constructed, a pipeline has unlimited capacity to transfer material in either direction.

You must select a subset of these pipelines to construct. The selected subset must be robust enough to handle *any* zero-sum demand scenario among the primary hubs. Specifically, for every possible assignment of real-valued demands $(D_1, D_2, \dots, D_t)$ to the primary hubs such that $\sum_{i=1}^t D_i = 0$, there must exist a valid routing of these demands using only the constructed pipelines. 

A valid routing means assigning a real-valued flow to each constructed pipeline such that:
- The net flow out of each primary hub $c_i$ is exactly $D_i$.
- The net flow out of every other site (non-primary hubs) is exactly 0.

You may route flows through any site, provided the flow conservation constraints are met. Determine the minimum total construction cost required to build a subset of pipelines that satisfies this universal routing requirement. (If $t=1$, the minimum total cost is 0).

## Input

The first line contains three integers **n**, **m**, and **t**, representing the total number of sites, the number of potential pipelines, and the number of primary hubs. The total number of sites **n** is a positive integer bounded by the 100 available regional zoning permits. The number of primary hubs **t** is a positive integer restricted by the 10 available federal hub licenses. The number of potential pipelines **m** can be from zero up to the number of unique pairs of sites.

The second line contains **t** distinct integers $c_1, c_2, \dots, c_t$: the identifiers of the primary hubs.

Each of the next **m** lines contains three integers **u**, **v**, and **w** ($u \neq v$), indicating that a pipeline between site **u** and site **v** can be constructed for a cost of **w**. The construction cost **w** of any pipeline is a positive integer bounded by the maximum subsidy limit of 1000000. All site identifiers are between 1 and **n**.

It is guaranteed that a valid subset of pipelines exists that can satisfy the routing requirement.

## Output

Print a single integer: the minimum total construction cost.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the primary hubs are 1, 2, and 3. By constructing the pipelines (1,4), (2,4), and (3,4), the total cost is 1+1+1 = 3. This set of pipelines allows any zero-sum demand scenario to be successfully routed. Alternatively, constructing (1,2) and (2,3) costs 4 and is also valid. The minimum cost is 3.

In Example 3, there is only one primary hub, so no pipelines are needed. The minimum cost is 0.
</STATEMENT>
<RATIONALE>
The problem was rewritten to use a universal flow routing requirement instead of explicit graph connectivity. By requiring that the selected edges can route any zero-sum demand vector among the terminals, the problem mathematically demands that all terminals lie in the same connected component. This forces the model to realize that the universal flow condition is equivalent to finding a Steiner Tree, breaking surface-level pattern matching to flow algorithms. Additionally, numeric bounds were expressed through scenario constraints (zoning permits, federal licenses, subsidy limits) per Strategy S07.
</RATIONALE>
<PRESERVED_ANSWER>
The universal flow routing condition with unlimited capacity is satisfied if and only if all primary hubs are in the same connected component of the chosen subset of pipelines; thus, the minimum cost to satisfy this is exactly the minimum cost Steiner Tree connecting the primary hubs, leaving all answers identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Steiner Tree problem in graphs, which is NP-complete, because the set of valid solutions (subgraphs connecting all terminals) and the objective function (sum of edge weights) are unchanged.
</PRESERVED_CLASS>
<RISK>
A reader might incorrectly assume that flows can be routed over time or that capacities must be assigned, but the statement explicitly defines "valid routing" as a single assignment of real-valued flows to the constructed pipelines for each demand scenario, which unambiguously maps to standard network flow conservation.
</RISK>
