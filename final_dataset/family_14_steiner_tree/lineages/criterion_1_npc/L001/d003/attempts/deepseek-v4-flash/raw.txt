We need to find the minimum cost to connect consecutive core banks in a given sequence, where we can share links between multiple paths.

This is essentially a **Steiner tree** problem on a graph, but with a special structure: the terminals are given in a sequence, and we only need to connect consecutive terminals (not all pairs).  
That means we need to find the minimum cost subgraph that connects \( c_1 \) to \( c_2 \), \( c_2 \) to \( c_3 \), ..., \( c_{t-1} \) to \( c_t \).

This can be solved using **dynamic programming over subsets of terminals** (Steiner tree DP), but since \( t \leq 10 \), we can do a DP over subsets of the core banks.

We can:
1. Compute all-pairs shortest paths between all nodes (Floyd–Warshall or Dijkstra from each node).
2. Use a DP where `dp[mask][v]` = minimum cost to connect the terminals in `mask` and end at node `v`.
3. Initialize for each terminal `c_i`: `dp[1<<i][c_i] = 0`.
4. Combine subsets: for each mask, for each submask, combine two DPs.
5. Also relax using shortest paths: `dp[mask][v] = min(dp[mask][v], dp[mask][u] + dist[u][v])`.
6. The answer is `min_v dp[(1<<t)-1][v]`.

But here we don’t need to connect all terminals together — only consecutive ones.  
However, the Steiner tree DP still works because connecting all terminals in the sequence will also connect consecutive ones, and the optimal solution for consecutive connections is a subset of the full Steiner tree.  
Actually, we can reduce the problem: we only need to connect pairs \((c_1,c_2), (c_2,c_3), \dots\).  
This is equivalent to finding a minimum cost subgraph that connects all terminals in the sequence, because if all are connected, consecutive ones are connected.  
But the optimal might not connect all terminals — it might connect only the needed pairs.  
However, since the sequence is a path, connecting all terminals is necessary and sufficient: if you connect \(c_1\) to \(c_2\) and \(c_2\) to \(c_3\), then \(c_1\) and \(c_3\) are also connected, but that’s fine.  
The minimal cost to connect all terminals in the sequence is exactly the minimal cost to satisfy the consecutive requirements, because any solution that satisfies consecutive requirements also connects all terminals (by transitivity).  
So we can solve the Steiner tree problem on the set of core banks.

Thus, the DP approach works.

Implementation steps:
- Read input.
- Build adjacency list.
- Compute all-pairs shortest paths (Floyd–Warshall, n ≤ 100).
- Run Steiner tree DP.

Let's write the code.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))
    cores = [int(next(it)) - 1 for _ in range(t)]
    
    INF = 10**15
    dist = [[INF]*n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0
    
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        if w < dist[u][v]:
            dist[u][v] = w
            dist[v][u] = w
    
    # Floyd-Warshall
    for k in range(n):
        for i in range(n):
            if dist[i][k] == INF:
                continue
            for j in range(n):
                if dist[k][j] == INF:
                    continue
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]
    
    if t == 1:
        print(0)
        return
    
    # Steiner tree DP
    full_mask = (1 << t) - 1
    dp = [[INF]*n for _ in range(1 << t)]
    for i, c in enumerate(cores):
        dp[1 << i][c] = 0
    
    for mask in range(1 << t):
        # Combine subsets
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if sub < other:  # avoid double work
                for v in range(n):
                    if dp[sub][v] + dp[other][v] < dp[mask][v]:
                        dp[mask][v] = dp[sub][v] + dp[other][v]
            sub = (sub - 1) & mask
        
        # Relax via shortest paths
        for v in range(n):
            if dp[mask][v] == INF:
                continue
            for u in range(n):
                if dist[v][u] < INF:
                    nd = dp[mask][v] + dist[v][u]
                    if nd < dp[mask][u]:
                        dp[mask][u] = nd
    
    ans = min(dp[full_mask])
    print(ans)

if __name__ == "__main__":
    solve()
```
