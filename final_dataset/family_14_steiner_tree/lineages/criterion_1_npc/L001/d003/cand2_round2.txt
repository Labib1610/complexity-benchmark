# Problem A — Storage Synchronization

Time limit: 5 s   Memory limit: 256 MB

## Description

You are tasked with calibrating a computing architecture consisting of **n** storage silos (indexed from 1 to n). The architecture allows you to establish two-way data-bridges between certain pairs of silos. Activating a bridge between two silos requires a specific hardware expenditure and permanently synchronizes their contents, forcing them to continuously reflect the identical data state. Because this synchronization is transitive, any chain of bridges linking two silos guarantees they will hold the same data.

The architecture depends on **t** critical silos. Your objective is to choose a combination of bridges to activate so that all **t** critical silos are strictly guaranteed to maintain the exact same data state. You are permitted to activate any combination of the provided bridges, including those connecting non-critical silos, as long as the critical silos are synchronized.

Calculate the minimum possible total hardware expenditure of the activated bridges needed to fulfill this requirement.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2). These represent the total number of storage silos, the number of possible data-bridges, and the number of critical silos, respectively.
The second line contains **t** distinct integers from 1 to n, representing the identifiers of the critical silos.
Each of the subsequent **m** lines provides three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000). This indicates that a data-bridge can be activated between silo u and silo v for a hardware expenditure of w.
It is guaranteed that the provided bridges are sufficient to synchronize all critical silos.

## Output

Output a single integer representing the minimum total hardware expenditure required to ensure all critical silos share the identical data state.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the requirement can be satisfied by activating bridges between (1,4), (2,4), and (3,4), incurring a total expenditure of 1+1+1 = 3. This ensures silos 1, 2, and 3 reflect the same data (along with silo 4). Alternatively, establishing bridges (1,2) and (2,3) would incur an expenditure of 4. The minimum expenditure is 3. In Example 3, there is only a single critical silo, thus no bridges need to be activated.
