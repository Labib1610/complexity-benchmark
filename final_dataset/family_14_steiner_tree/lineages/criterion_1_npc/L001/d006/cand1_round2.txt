# Problem A — Equality Entailment

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing a formal system containing **n** variables, indexed 1 through **n**. Initially, no relationships between these variables are known.

You are provided with a list of **m** available equality axioms. An equality axiom between variable $u$ and variable $v$ asserts that their values are identical. Activating a specific axiom so that it can be used in your deductions incurs a one-time cost of $w$ compute cycles. Equality is transitive; if $u = v$ and $v = z$ are both activated axioms, then $u = z$ is logically entailed.

You are given a query containing a subset of **t** target variables: $c_1, c_2, \dots, c_t$. 
Your objective is to select a subset of the available equality axioms to activate such that, based on the activated axioms, it is logically entailed that all **t** target variables share the exact same value. 

You may activate equality axioms involving non-target variables; these can bridge deductions between target variables if it results in a lower total compute cost. 

Determine the minimum total compute cost required to ensure that the mutual equality of all **t** target variables is entailed. (If $t=1$, no activation is needed and the minimum cost is 0).

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2), representing the total number of variables, the number of available equality axioms, and the number of target variables.
The second line contains **t** distinct integers $c_1, c_2, \dots, c_t$: the indices of the target variables.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that an equality axiom can be activated between variable u and variable v at a cost of w.
It is guaranteed that the available axioms are sufficient to entail the mutual equality of all target variables.

## Output

Print a single integer: the minimum total compute cost to activate a set of axioms that satisfies the requirement.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the target variables are 1, 2, and 3. You can activate axioms between (1,4), (2,4), and (3,4) for a total cost of 1+1+1 = 3 compute cycles. Because variable 1 is equal to 4, and 2 is equal to 4, their equality is entailed. Similarly, 3 is equal to 4, so the mutual equality of all three target variables is entailed. Alternatively, activating axioms for (1,2) and (2,3) directly would cost 2+2 = 4 cycles. The minimum cost is 3. 

In Example 3, there is only one target variable ($t=1$), so no activation is needed and the minimum cost is 0.

<RATIONALE>
The problem was rewritten using the "Equality Entailment Framework", mapping the graph's vertices to variables and its edges to equality axioms. This removes the spatial/network terminology of "groups" and "merging" and replaces it with logic and transitivity, forcing the model to infer that finding a minimum-cost subset of axioms to prove mutual equality is mathematically identical to finding a minimum-weight Steiner tree connecting the target components. The flagged word "trivially" was removed to comply with H3.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical structure is strictly isomorphic: selecting an axiom corresponds perfectly to adding an edge, and transitivity of equality precisely mirrors connected components, so the minimum cost for any input remains identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem is exactly the Steiner Tree Problem on a weighted graph, which is NP-complete, and the identical inputs, bounds, and output requirement preserve this class perfectly.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the transitivity rule as requiring a complete clique of activated axioms rather than just a connected tree, though the explanation in Example 1 clarifies that indirect entailment is sufficient.
</RISK>
