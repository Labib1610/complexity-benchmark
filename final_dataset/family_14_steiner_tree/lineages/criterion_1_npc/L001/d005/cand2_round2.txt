# Problem A — Translation Lexicons

Time limit: 5 s   Memory limit: 256 MB

## Description

You are studying **n** ancient dialects, numbered 1 through **n**. You have the option to hire translators who are bilingual in specific pairs of dialects. Hiring a translator for a specific pair incurs a known salary cost.

A chosen set of hired translators groups the dialects into mutually intelligible families. Two dialects belong to the same family if a message can be translated between them through a sequence of hired translators, either directly or via other intermediate dialects.

You are given a focus group of **t** vital dialects: $c_1, c_2, \dots, c_t$. Your objective is to select a single set of translators to hire such that all **t** vital dialects belong to the exact same mutually intelligible family.

You may hire translators for non-vital dialects; these can serve as linguistic bridges to connect vital dialects. Once a set of translators is hired, all resulting translations are possible simultaneously.

Determine the minimum total salary cost you must pay to hire a set of translators that satisfies the requirement. (If $t=1$, no translators are needed and the minimum cost is 0).

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2), representing the total number of dialects, the number of available translators, and the number of vital dialects.
The second line contains **t** distinct integers $c_1, c_2, \dots, c_t$: the identifiers of the vital dialects. The order of these identifiers does not matter.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that a translator can be hired for dialect u and dialect v at a salary cost of w.
It is guaranteed that the available translators are sufficient to place all vital dialects into the same family.

## Output

Print a single integer: the minimum total salary cost to hire a set of translators that satisfies the requirement.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the vital dialects are 1, 2, and 3. You can hire translators for pairs (1,4), (2,4), and (3,4) for a total salary cost of 1+1+1 = 3. Because dialect 1 is mutually intelligible with 4, and 2 is mutually intelligible with 4, a message can be translated between 1 and 2. Similarly, dialect 3 is mutually intelligible with 4, so all three vital dialects belong to the same family. Alternatively, hiring translators for (1,2) and (2,3) directly would cost 2+2 = 4. The minimum cost is 3. 

In Example 3, there is only one vital dialect ($t=1$), so no translators are needed and the minimum cost is 0.
