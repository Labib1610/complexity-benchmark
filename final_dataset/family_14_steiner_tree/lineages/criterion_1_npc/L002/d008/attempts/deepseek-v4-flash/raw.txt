We can model this as a graph problem.  
The condition says: for every subset \( Y \) that splits \( T \), \( Y \) must split at least one chosen edge.  
Equivalently, if we choose edges \( S \), then any subset \( Y \) that is *consistent* with all edges in \( S \) (i.e., for each edge, either both endpoints are in \( Y \) or both are out) must not split \( T \).  

That means: the connected components of the graph formed by chosen edges must be such that each component is either fully inside \( T \) or fully outside \( T \).  
So we need to connect elements so that no component contains both a target and a non-target element.  

Thus, the problem reduces to:  
We have \( t \) target elements and \( n-t \) non-target elements.  
We must choose edges so that no connected component mixes target and non-target.  
We can achieve this by ensuring all target elements are connected together (or isolated) and all non-target elements are connected together (or isolated), but never mixed.  

The cheapest way is to connect all target elements into one component (if \( t>1 \)) and all non-target elements into one component (if \( n-t>1 \)), using the given edges.  
If \( t=1 \) or \( n-t=1 \), that side needs no edges.  

So we compute:
- Minimum cost to connect all target elements (MST on target nodes using given edges).
- Minimum cost to connect all non-target elements (MST on non-target nodes).
- Sum them.

If either group has size ≤ 1, its MST cost is 0.

Let’s implement this.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))
    
    target = set()
    for _ in range(t):
        target.add(int(next(it)))
    
    edges = []
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        w = int(next(it))
        edges.append((w, u, v))
    
    # If t == 1 or n-t == 1, that side needs no edges
    # We need MST for target set and non-target set separately.
    
    # Helper: MST cost for a given set of nodes
    def mst_cost(nodes):
        nodes = list(nodes)
        if len(nodes) <= 1:
            return 0
        node_set = set(nodes)
        # Kruskal
        parent = {x: x for x in nodes}
        rank = {x: 0 for x in nodes}
        
        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x
        
        def union(a, b):
            ra = find(a)
            rb = find(b)
            if ra == rb:
                return False
            if rank[ra] < rank[rb]:
                parent[ra] = rb
            elif rank[ra] > rank[rb]:
                parent[rb] = ra
            else:
                parent[rb] = ra
                rank[ra] += 1
            return True
        
        cost = 0
        used = 0
        for w, u, v in sorted(edges):
            if u in node_set and v in node_set:
                if union(u, v):
                    cost += w
                    used += 1
                    if used == len(nodes) - 1:
                        break
        if used != len(nodes) - 1:
            return float('inf')
        return cost
    
    target_nodes = list(target)
    non_target_nodes = [x for x in range(1, n+1) if x not in target]
    
    cost1 = mst_cost(target_nodes)
    cost2 = mst_cost(non_target_nodes)
    
    print(cost1 + cost2)

if __name__ == "__main__":
    solve()
```
