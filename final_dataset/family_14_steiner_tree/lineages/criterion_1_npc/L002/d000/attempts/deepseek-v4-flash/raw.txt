 We can solve this by treating it as a **Steiner tree** problem, but since the number of terminals \( t \leq 10 \), we can use a **bitmask DP** approach.

Here’s the plan:

1. Run **Floyd–Warshall** to get the shortest path distances between all pairs of nodes.
2. Use DP over subsets of terminals:
   - `dp[mask][v]` = minimum cost to connect the terminals in `mask` with the tree rooted at node `v`.
3. Initialize `dp[1 << i][terminal[i]] = 0` for each terminal.
4. Combine subsets:  
   `dp[mask][v] = min(dp[mask][v], dp[sub][v] + dp[mask ^ sub][v])`
5. Relax using shortest paths:  
   `dp[mask][v] = min(dp[mask][v], dp[mask][u] + dist[u][v])`
6. Answer is `min(dp[(1<<t)-1][v])` over all `v`.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    terminals = list(map(int, input().split()))
    terminals = [x - 1 for x in terminals]  # 0-based

    INF = 10**18
    dist = [[INF] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0

    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        if w < dist[u][v]:
            dist[u][v] = w
            dist[v][u] = w

    # Floyd-Warshall
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]

    full_mask = (1 << t) - 1
    dp = [[INF] * n for _ in range(1 << t)]

    for i in range(t):
        dp[1 << i][terminals[i]] = 0

    for mask in range(1 << t):
        # Combine subsets
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if sub < other:  # avoid duplicate work
                for v in range(n):
                    dp[mask][v] = min(dp[mask][v], dp[sub][v] + dp[other][v])
            sub = (sub - 1) & mask

        # Relax via shortest paths
        for u in range(n):
            if dp[mask][u] < INF:
                for v in range(n):
                    if dist[u][v] < INF:
                        nd = dp[mask][u] + dist[u][v]
                        if nd < dp[mask][v]:
                            dp[mask][v] = nd

    ans = min(dp[full_mask][v] for v in range(n))
    print(ans)

if __name__ == "__main__":
    solve()
```
