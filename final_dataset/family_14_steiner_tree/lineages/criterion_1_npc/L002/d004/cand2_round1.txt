<STATEMENT>
# Problem A — Vector Span Acquisition

Time limit: 5 s
Memory limit: 256 MB

## Description
You are working in an $n$-dimensional vector space over the real numbers, with standard basis vectors denoted as $e_1, e_2, \dots, e_n$.

There are $m$ available difference vectors that you can acquire. Each available vector is of the form $e_u - e_v$, and acquiring it incurs a one-time cost of $w$. 
When you acquire a subset of these vectors, they generate a linear subspace (their linear span).

A specific subset of $t$ dimensions have been designated as targets. 
Your objective is to acquire a subset of the available difference vectors such that, for any two target dimensions $a$ and $b$, the vector $e_a - e_b$ lies completely within the linear span of your acquired subset. 

You are permitted to acquire difference vectors that involve non-target dimensions; if utilizing them as intermediate steps in linear combinations reduces the overall acquisition cost, it is a valid strategy.

Write a program to calculate the minimum total cost necessary to acquire a subset of vectors whose linear span contains $e_a - e_b$ for all target dimensions $a$ and $b$.

## Input
The first line contains three integers $n$, $m$, and $t$.
The number of dimensions $n$ is at most 100, with a minimum of 1. The number of available difference vectors $m$ ranges from a minimum of 0 up to $n(n-1)/2$. The number of target dimensions $t$ is at most 10, and there is always at least 1.

The second line contains $t$ distinct integers: the indices of the target dimensions.

Each of the next $m$ lines contains three integers $u$, $v$, and $w$, representing an available difference vector $e_u - e_v$ that requires an acquisition cost of $w$. Each vector involves two distinct dimensions (identified by integers from 1 to $n$, where $u \neq v$). The acquisition cost $w$ is at least 1 and is capped at 1000000. Note that since the span of $\{e_u - e_v\}$ is the same as the span of $\{e_v - e_u\}$, the order of $u$ and $v$ does not matter.

It is guaranteed that the available vectors are sufficient to ensure the target span condition can be met.

## Output
Print a single integer: the minimum total cost to ensure $e_a - e_b$ is in the span of the acquired vectors for all target dimensions $a$ and $b$.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note
In Example 1, acquiring the vectors $e_1 - e_4$, $e_2 - e_4$, and $e_3 - e_4$ costs 1+1+1 = 3. 
The vector $e_1 - e_2$ is in their linear span because $(e_1 - e_4) - (e_2 - e_4) = e_1 - e_2$. Similarly, $e_2 - e_3$ and $e_1 - e_3$ can be formed through linear combinations of the acquired vectors. This is more cost-effective than acquiring the direct difference vectors involving only the targets 1, 2, and 3, which would require a cost of 4. 
In Example 3, there is only one target dimension, so no vectors need to be acquired (the condition is trivially satisfied since $e_1 - e_1$ is the zero vector, which is in every span).
</STATEMENT>
<RATIONALE>
The problem was reframed from network connectivity to acquiring vectors to span a subspace. To solve it, models must deduce that spanning a difference vector $e_a - e_b$ using a subset of $\{e_u - e_v\}$ is mathematically equivalent to finding a path between $a$ and $b$ in a graph. This forces the model to bridge linear algebra and graph theory to recognize the Steiner Tree structure, bypassing keyword-based retrieval of the subset DP algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The linear span of a set of difference vectors contains $e_a - e_b$ if and only if $a$ and $b$ are in the same connected component of the graph formed by those vectors, meaning the minimum cost to satisfy the span condition is exactly the minimum cost Steiner Tree.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying mathematical structure is perfectly isomorphic to the Minimum Steiner Tree problem, preserving its NP-complete complexity class.
</PRESERVED_CLASS>
