# Problem A — Grid Management Upgrade

Time limit: 5 s
Memory limit: 256 MB

## Description
A regional energy provider is overhauling its grid management infrastructure. The project is divided into three stages:

**Stage 1: Topographical Survey.** Field teams have evaluated $n$ energy facilities (numbered 1 through $n$). They have discovered $m$ potential underground conduits capable of housing new telemetry channels. For each potential conduit, the teams have determined the precise installation cost.

**Stage 2: Network Synthesis.** Your role is to plan the network architecture. Out of the $n$ facilities, exactly $t$ are critical synchronization hubs. You must establish a continuous communication backbone so that all $t$ synchronization hubs are fully interconnected (they must all be able to communicate with one another within a single connected network). Data can pass through any chain of installed telemetry channels. If it lowers the total installation cost, you are free to route the network through any of the other facilities to act as passive relays. Your objective is to determine the absolute minimum total cost required to link all the synchronization hubs together.

**Stage 3: Physical Deployment.** The minimum cost you calculate will be presented to the board. Following budget approval, installation crews will lay the telemetry channels in the selected conduits.

Your task is to implement Stage 2: process the survey data from Stage 1 and output the final budget required for Stage 3.

## Input
The first line contains three integers $n$, $m$, and $t$. The grid comprises a number of facilities $n$ (from 1 to 100). The legacy telemetry hardware limits the count of synchronization hubs $t$ to be from 1 up to a maximum of 10. The engineers might identify anywhere from 0 up to $n(n-1)/2$ viable conduits $m$.
The second line contains $t$ distinct integers: the IDs of the synchronization hubs.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$, representing a viable conduit between facility $u$ and facility $v$ (where $u$ and $v$ are valid distinct facility IDs from 1 to $n$) with an installation expense $w$. The budget cap restricts any single conduit's expense $w$ to be between 1 and 1000000.
It is guaranteed that the surveyed conduits are sufficient to connect all synchronization hubs.

## Output
Print a single integer: the minimum total cost to ensure all synchronization hubs are connected.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note
In Example 1, routing the telemetry channels through the passive relay facility 4 (which costs 1+1+1 = 3) is cheaper than linking the three synchronization hubs directly to each other (which would cost 4). 
In Example 3, there is only one synchronization hub, so no telemetry channels need to be installed.
