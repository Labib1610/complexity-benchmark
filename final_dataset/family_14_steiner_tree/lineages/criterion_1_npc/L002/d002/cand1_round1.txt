<STATEMENT>
# Problem A — Grid Management Upgrade

Time limit: 5 s
Memory limit: 256 MB

## Description
A regional energy provider is modernizing its grid management software. The new system must process telemetry from legacy equipment that operates across $n$ distinct data schemas (numbered 1 to $n$). The system's registry requires at least one schema and has a hard architectural capacity limit of exactly one century of schemas (100).

To facilitate data exchange, third-party vendors offer $m$ bidirectional translation modules. Each module enables direct, two-way conversion between a specific pair of schemas and requires a one-time licensing fee. This fee is strictly positive and capped at the standard corporate micro-transaction limit of one million. The number of modules $m$ can be anything from zero up to the maximum possible number where every unique pair of schemas has exactly one dedicated module.

The provider has identified $t$ specific schemas that correspond to top-tier substations. The number of top-tier substations is at least one and will never exceed the exact number of years in a decade (10). 

Your objective is to determine the most cost-effective combination of translation modules to license so that an alert generated in any top-tier substation's schema can be successfully propagated to every other top-tier substation's schema. You may chain multiple modules together to achieve this. You are fully permitted to license modules that convert to or from schemas not associated with top-tier substations, provided that using them as intermediate steps lowers the overall licensing fee.

Write a program to calculate the minimum total licensing fee required to establish this universal alert propagation network among all top-tier substations.

## Input
The first line provides three integers $n$, $m$, and $t$.
The second line provides $t$ distinct integers: the schema IDs of the top-tier substations.
Each of the next $m$ lines provides three integers $u$, $v$, and $w$, representing an available translation module between distinct schemas $u$ and $v$ that has a licensing fee of $w$.
It is guaranteed that licensing all available modules would successfully allow alert propagation among all top-tier substations.

## Output
Print a single integer: the minimum total licensing fee to ensure all top-tier substations can exchange alerts.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note
In Example 1, chaining conversions through schema 4 (which is not top-tier and costs 1+1+1 = 3) is cheaper than licensing the modules that directly convert between the three top-tier schemas (which would cost 4). 
In Example 3, there is only one top-tier schema, so no modules need to be licensed.
