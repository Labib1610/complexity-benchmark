# Problem A — Grid Management Upgrade

Time limit: 5 s
Memory limit: 256 MB

## Description
A regional energy provider is modernizing its grid telemetry network. The legacy equipment outputs data across $n$ distinct semantic formats, indexed 1 through $n$.

To achieve interoperability, vendors offer $m$ bidirectional format adapters. Each adapter is associated with a flat licensing fee. When an adapter is licensed, it merges the capabilities of its two endpoint formats, meaning data can be seamlessly mapped back and forth between them.

A chosen subset of licensed adapters partitions the $n$ formats into equivalence classes. Two formats are in the same equivalence class if and only if they can be mutually translated, either directly or through a chain of licensed adapters.

The provider has designated $t$ specific formats as essential. Your task is to select a subset of adapters to license such that all $t$ essential formats belong to the exact same equivalence class. It is fully permissible to include non-essential formats in this equivalence class if licensing their adapters yields a lower total cost.

Calculate the minimum total licensing fee required to ensure all essential formats fall into a single equivalence class.

## Input
The system's architectural limits support a maximum of 100 distinct formats ($1 \le n \le 100$) and up to 10 essential formats ($1 \le t \le 10$). The number of available adapters is $m$ ($0 \le m \le n(n-1)/2$).
The first line contains the three integers $n$, $m$, and $t$.
The second line contains $t$ distinct integers: the indices of the essential formats.
Each of the next $m$ lines describes an available adapter with three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$). This indicates an adapter that maps between format $u$ and format $v$ for a fee of $w$.
It is guaranteed that licensing all available adapters would successfully place all essential formats into the same equivalence class.

## Output
Print a single integer: the minimum total licensing fee to ensure all essential formats are in the same equivalence class.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note
In Example 1, chaining translations through the non-essential format 4 (which costs 1+1+1 = 3) is cheaper than licensing the adapters that directly map between the three essential formats (which would cost 4). 
In Example 3, there is only one essential format, which trivially forms its own equivalence class, so no adapters need to be licensed.
