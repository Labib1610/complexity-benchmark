<STATEMENT>
# Problem A — Quantum Fidelity Certification

Time limit: 5 s
Memory limit: 256 MB

## Description
You are analyzing a physical system described by $n$ unknown quantum states. Each state is represented by a normalized vector $|\psi_i\rangle$ in a complex Hilbert space of arbitrarily large dimension.

You have access to a pool of $m$ pairwise fidelity tests. Each test is defined by a pair of state indices $(u, v)$. Activating a test incurs a one-time equipment cost of $w$. Once activated, the test certifies that the transition probability between the two states is exactly $1$; mathematically, it imposes the rigid constraint $|\langle \psi_u | \psi_v \rangle|^2 = 1$. 

A specific subset of $t$ indices have been designated as critical states. Your objective is to choose a subset of the tests to activate, such that their combined constraints logically guarantee that $|\langle \psi_a | \psi_b \rangle|^2 = 1$ for every pair of critical indices $a$ and $b$. The guarantee must hold for any configuration of the $n$ state vectors that satisfies all activated constraints.

Write a program to calculate the minimum total cost necessary to ensure this certification condition is met.

## Input
The first line contains three integers $n$, $m$, and $t$.
The number of states $n$ satisfies $1 \le n \le 100$. The number of available tests $m$ satisfies $0 \le m \le n(n-1)/2$. The number of critical states $t$ satisfies $1 \le t \le 10$.

The second line contains $t$ distinct integers: the indices of the critical states.

Each of the next $m$ lines contains three integers $u$, $v$, and $w$, representing an available fidelity test between state $u$ and state $v$ that requires a cost of $w$. The integers $u$ and $v$ identify the two distinct states involved ($1 \le u \le n$, $1 \le v \le n$, $u \neq v$). The cost $w$ satisfies $1 \le w \le 1000000$.

It is guaranteed that the available pool of tests is sufficient to ensure the condition can be met.

## Output
Print a single integer: the minimum total cost to ensure the target condition is logically guaranteed.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note
In Example 1, activating the tests for $(1, 4)$, $(2, 4)$, and $(3, 4)$ incurs a cost of $1+1+1=3$. These tests certify that the transition probabilities between state 4 and each of the states 1, 2, and 3 are perfectly 1. In any complex Hilbert space, this mutual perfect fidelity with state 4 logically forces the transition probability between any two of the states 1, 2, and 3 to also be 1. Thus, the target condition is guaranteed for the critical states 1, 2, and 3. This approach is more cost-effective than activating tests directly between the critical states, which would cost at least 4.

In Example 3, with only one critical state, there are no pairs of distinct critical states. The condition is vacuously satisfied without activating any tests, resulting in a minimum cost of 0.

<RATIONALE>
I completely changed the domain from linear functionals and joint kernels to quantum state tomography and transition probabilities. The linear equality constraint $x_u - x_v = 0$ was replaced by the perfect fidelity constraint $|\langle \psi_u | \psi_v \rangle|^2 = 1$. This forces the model to first use the Cauchy-Schwarz equality condition to deduce that the states must be identical up to a global phase, recognize this as an equivalence relation, and finally map the requirement of logically guaranteeing perfect fidelity between critical states to finding a minimum-cost connected structure (Steiner tree).
</RATIONALE>

Any set of tests guarantees the target condition if and only if all critical states fall into the same equivalence class of perfect fidelity, which maps exactly to the same minimum-cost connected components as the seed problem.
</PRESERVED_ANSWER>
