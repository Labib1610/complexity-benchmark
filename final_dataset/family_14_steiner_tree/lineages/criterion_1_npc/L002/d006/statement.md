# Problem A — Covector Span

Time limit: 5 s
Memory limit: 256 MB

## Description
Consider the dual space $(\mathbb{R}^n)^*$ with the standard dual basis $\varepsilon_1, \varepsilon_2, \dots, \varepsilon_n$.
You are provided with a pool of $m$ candidate covectors. Each candidate covector is defined by a pair of indices $(u, v)$ and is equal to $\varepsilon_u - \varepsilon_v$. Activating a specific candidate covector incurs a one-time cost $w$.

A specific subset of $t$ indices have been designated as essential indices. Let $W$ be the subspace of $(\mathbb{R}^n)^*$ spanned by the set of covectors $\varepsilon_a - \varepsilon_b$ for every pair of essential indices $a$ and $b$.

Your objective is to activate a subset of the candidate covectors such that their linear span contains the subspace $W$.

Write a program to calculate the minimum total cost necessary to ensure this span condition is met.

## Input
The first line contains three integers $n$, $m$, and $t$.
The dimension $n$ satisfies $1 \le n \le 100$. The number of candidate covectors $m$ satisfies $0 \le m \le n(n-1)/2$. The number of essential indices $t$ satisfies $1 \le t \le 10$.

The second line contains $t$ distinct integers: the essential indices.

Each of the next $m$ lines contains three integers $u$, $v$, and $w$, representing a candidate covector $\varepsilon_u - \varepsilon_v$ that requires a cost of $w$. The integers $u$ and $v$ identify the two distinct dimensions involved ($1 \le u \le n$, $1 \le v \le n$, $u \neq v$). The cost $w$ satisfies $1 \le w \le 1000000$.

It is guaranteed that the available candidate covectors are sufficient to ensure the condition can be met.

## Output
Print a single integer: the minimum total cost to ensure the target span condition is met.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note
In Example 1, activating the covectors for $(1, 4)$, $(2, 4)$, and $(3, 4)$ incurs a cost of $1+1+1=3$. Their linear span contains $\varepsilon_1 - \varepsilon_4$, $\varepsilon_2 - \varepsilon_4$, and $\varepsilon_3 - \varepsilon_4$. By taking linear combinations, we can form $\varepsilon_1 - \varepsilon_2 = (\varepsilon_1 - \varepsilon_4) - (\varepsilon_2 - \varepsilon_4)$, as well as $\varepsilon_2 - \varepsilon_3$ and $\varepsilon_1 - \varepsilon_3$. Thus, the span contains the subspace $W$ generated by all pairs of the essential indices $1, 2$, and $3$. This is more cost-effective than activating the covectors defined solely on the essential indices, which would cost at least 4.

In Example 3, with only one essential index, there are no pairs of distinct essential indices. The target subspace $W$ is the trivial zero-dimensional subspace. The condition is vacuously satisfied without activating any covectors, resulting in a minimum cost of 0.
