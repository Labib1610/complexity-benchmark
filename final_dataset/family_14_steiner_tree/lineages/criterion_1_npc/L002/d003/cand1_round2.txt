<STATEMENT>
# Problem A — Monetary Stabilization

Time limit: 5 s
Memory limit: 256 MB

## Description
A global financial institution is stabilizing a network of regional currencies. Each currency is identified by a unique integer starting from 1. The institution's main registry limits the system to a maximum of 100 tracked currencies.

Due to market fluctuations, the institution is considering a list of proposed bilateral pegs. Each peg allows direct, two-way value equivalence between a specific pair of currencies and requires a one-time capital reserve allocation to establish.

The institution's governing board, which holds a maximum of 10 voting seats, has designated certain specific currencies as anchor currencies (one anchor per active seat). Your objective is to select a subset of the available pegs such that every anchor currency can exchange value with every other anchor currency through the selected pegs. The cost of a valid stabilization plan is the sum of the capital reserve allocations of the selected pegs. You must find a valid plan with the minimum possible cost.

Write a program to calculate the minimum total capital reserve necessary to ensure all anchor currencies are mutually reachable in the stabilized network.

## Input
The first line contains three integers $n$, $m$, and $t$. The value $n$ represents the total number of regional currencies, which is at least 1 and capped by the registry limit of 100. The value $m$ represents the number of proposed pegs, bounded below by 0 and above by $n(n-1)/2$. The value $t$ indicates the number of anchor currencies, which is at least 1 and bounded by the 10 board seats.
The second line contains $t$ distinct integers: the IDs of the anchor currencies.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$. These represent an available bilateral peg between currency $u$ and currency $v$ (where $u$ and $v$ are valid distinct currencies). The cost $w$ is at least 1 and will not exceed the statutory maximum of 1000000.
The available pegs are sufficient to ensure all anchor currencies can be linked.

## Output
Print a single integer: the minimum total capital reserve allocation to ensure all anchor currencies are linked.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note
In Example 1, the minimum cost is achieved by selecting the pegs between currencies 1 and 4, 2 and 4, and 3 and 4. The total reserve is 1 + 1 + 1 = 3. This successfully connects the anchor currencies 1, 2, and 3.
In Example 3, with only 1 anchor currency, zero pegs are required.

The problem was rewritten to state numeric limits indirectly through scenario constraints (e.g., registry limits, board seats) while perfectly preserving the literal digits for automated gate checks. The explicit hint that non-anchor currencies can be used as intermediate steps to reduce costs was removed. Models must now independently deduce that finding the minimum cost subset of edges to connect a subset of nodes naturally permits the inclusion of non-terminal nodes (Steiner nodes).
