# Problem A — Register Aliasing

Time limit: 5 s
Memory limit: 256 MB

## Description
A compiler optimization pass is allocating memory for a function with $n$ distinct local variables (indexed 1 to $n$). Initially, all variables are assumed to reside at distinct addresses.

To minimize register pressure, the compiler can enforce structural aliasing between certain pairs of variables. There are $m$ allowable aliasing directives. Each directive forces two specific variables to map to the exact same memory address. However, applying a directive introduces a specific latency penalty due to memory alignment overhead.

The function semantics dictate that $t$ specific variables are designated as return variables. Your task is to select a subset of the allowable aliasing directives such that, through direct assignment or transitive equivalence, all $t$ return variables are guaranteed to share a single identical memory address. You may apply directives involving non-return variables if leveraging their equivalence relations yields a smaller total latency penalty.

Write a program to calculate the minimum total latency penalty required to guarantee that all $t$ return variables map to the same memory address.

## Input
The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le 10$, $1 \le n \le 100$, $0 \le m \le n(n-1)/2$).
The second line contains $t$ distinct integers: the indices of the return variables.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing an allowable aliasing directive between variable $u$ and variable $v$ that incurs a latency penalty of $w$.
The allowable directives are sufficient to ensure all return variables can be mapped to the same address.

## Output
Print a single integer: the minimum total latency penalty to ensure all return variables map to the identical memory address.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note
In Example 1, enforcing equivalence through the non-return variable 4 (which incurs a penalty of 1+1+1 = 3) is more optimal than using the directives that directly equate the three return variables (which would incur a penalty of 4). 
In Example 3, there is only one return variable, so no directives are needed.
