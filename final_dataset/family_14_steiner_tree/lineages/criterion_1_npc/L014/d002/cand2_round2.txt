<STATEMENT>
# Problem A — Secure Facility Integration

Time limit: 5 s   Memory limit: 256 MB

## Description

A corporate archive manages an ecosystem of **n** distinct data vaults, labeled uniquely from 1 to **n**. The facility's physical footprint limits the total number of vaults, meaning **n** is between 1 and 100. Among these, a specific subset of **t** vaults (where the mandate restricts **t** to between 1 and 10) are designated as master vaults, while the rest are standard vaults.

There are **m** proposed bidirectional fiber bridges that can be installed. The number of proposals **m** ranges from 0 up to the maximum possible for a simple network, **n**·(**n**−1)/2. Each proposed bridge allows data to be mirrored between a specific pair of vaults and carries a known installation cost **w** (a value between 1 and 1000000). Any vault, master or standard, will automatically relay data between any installed bridges it connects to.

The organization must guarantee that all master vaults are fully integrated. This requires that every master vault can exchange data with every other master vault, either through a direct bridge or via some chain of installed bridges. You must select a subset of the **m** proposed bridges to install such that this integration requirement for all master vaults is satisfied. You may only select from the **m** proposed bridges listed; selected bridges may route through standard vaults. Your goal is to keep the sum of the installation costs as low as possible. Determine this minimum total cost.

## Input

The first line contains three integers **n**, **m**, and **t**. The total vault count **n** is limited by the 100 physical slots in the facility (so **n** is between 1 and 100). The proposed bridge count **m** ranges from 0 up to the theoretical maximum of **n**·(**n**−1)/2. The master vault count **t** is restricted by the 10 available authorization keys (so **t** is between 1 and 10).
The second line contains **t** distinct integers: the labels of the master vaults.
Each of the next **m** lines contains three integers **u**, **v**, and **w**: indicating a proposed bridge between vault **u** and vault **v** with an installation cost of **w**. The vault identifiers **u** and **v** are distinct and range from 1 to **n**. The cost **w** is at least 1 and capped by a per-bridge budget limit of 1000000.
It is guaranteed that the listed proposed bridges are sufficient to integrate all master vaults.

## Output

Print a single integer: the minimum total installation cost required to integrate all master vaults.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, installing bridges through standard vault 4 (cost 1+1+1 = 3) is cheaper than directly connecting the three master vaults (which would cost 2+2 = 4). In Example 3, there is only one master vault, so no bridges need to be installed.
