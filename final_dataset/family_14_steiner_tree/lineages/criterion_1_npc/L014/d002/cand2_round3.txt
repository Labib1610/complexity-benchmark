# Problem A — Secure Communication Grid

Time limit: 5 s   Memory limit: 256 MB

## Description

A corporate conglomerate operates **n** secure installations, each assigned a unique ID from 1 to **n**. The conglomerate is considering **m** potential bidirectional fiber-optic links to establish communication between these installations. Each link connects two distinct installations and has a specific installation cost.

Within this conglomerate, a core group of **t** installations are designated as executive headquarters. The rest are standard facilities. Any installation, whether an executive headquarters or a standard facility, seamlessly routes data between any active fiber-optic links connected to it.

The conglomerate's board requires that a unified communication network is formed among all executive headquarters. This means that a message originating at any executive headquarters must be able to reach every other executive headquarters, either directly or by being routed through a sequence of activated links (which may pass through intermediate standard facilities). You are tasked with selecting a subset of the **m** potential links to activate such that this connectivity mandate for the executive headquarters is met. Your objective is to minimize the total installation cost of the activated links. Determine this minimum total cost.

## Input

The first line provides three integers **n**, **m**, and **t**. The total number of installations **n** is at least 1 and limited by the 100 available zoning permits. The number of potential links **m** can be 0 or any integer up to n·(n−1)/2. The number of executive headquarters **t** is at least 1 and limited by the 10 seats on the board of directors.
The second line contains **t** distinct integers: the IDs of the executive headquarters.
Each of the subsequent **m** lines contains three integers **u**, **v**, and **w**. These specify a potential link between distinct installations **u** and **v** (both are valid IDs from 1 to **n**, with **u** ≠ **v**). The installation cost **w** is at least 1 and capped by a maximum budget of 1000000 credits per link.
It is guaranteed that the provided potential links are sufficient to interconnect all executive headquarters.

## Output

Output a single integer: the minimum total installation cost required to interconnect all executive headquarters.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, activating links through the standard facility 4 (cost 1+1+1 = 3) is cheaper than directly connecting the three executive headquarters (which would cost 2+2 = 4). In Example 3, there is only one executive headquarters, so no links need to be activated.
