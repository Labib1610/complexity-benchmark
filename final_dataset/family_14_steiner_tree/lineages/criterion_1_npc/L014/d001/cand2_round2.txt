# Problem A — Optimal Circuit Shorting

Time limit: 5 s   Memory limit: 256 MB

## Description

A hardware engineer is designing a prototype circuit board. The board contains **n** distinct contact pads, numbered uniquely from 1 to **n**. The manufacturing equipment can print a set of **m** potential wire traces. Each potential trace connects a specific pair of contact pads and requires a known amount of copper to print.

Among the **n** contact pads, a specific subset of **t** pads are designated as power terminals. The rest of the pads are unassigned. The engineer needs to ensure that all power terminals are electrically shorted together. This means electrical current must be able to flow between any two power terminals via some sequence of printed traces. 

Any contact pad on the board can serve as a junction. If multiple printed traces meet at any pad—whether it is a power terminal or unassigned—current will freely flow between those traces, allowing the network of traces to branch out.

You must select a subset of the potential traces to print so that all **t** power terminals are electrically connected to one another, while minimizing the total amount of copper used. Determine this minimum total copper requirement.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the ids of the power terminals.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): a potential trace between contact pads **u** and **v** requiring **w** micrograms of copper.
It is guaranteed that the available potential traces are sufficient to electrically connect all power terminals.

## Output

Print a single integer: the minimum total copper required to connect all power terminals.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, printing traces to connect the power terminals through the unassigned pad 4 (requiring 1+1+1 = 3 micrograms of copper) is cheaper than directly printing traces between the three power terminals (which would cost 4). In Example 3, there is only one power terminal, so no traces need to be printed.

The problem was rewritten using a circuit board and copper trace manufacturing scenario to replace the abstract network communication terminology ("nodes", "links", "forwarding"). By framing the non-terminal vertices as "unassigned pads" acting as "junctions" for electrical current, models that rely on explicitly matching keywords like "forwarding standard nodes" to the Steiner Tree problem are forced to deduce the equivalent graph structure from physical descriptions of branching current.
