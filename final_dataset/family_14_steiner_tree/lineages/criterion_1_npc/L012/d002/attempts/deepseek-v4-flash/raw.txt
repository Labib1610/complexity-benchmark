We can model this as selecting a connected subgraph that includes at least one starting language and all priority languages.  
The key trick is: since we can start anywhere, we just need to connect all priority languages with minimum cost, possibly using some intermediate languages.

A full Minimum Steiner Tree in general graphs is hard, but here \(n \leq 100\), \(t \leq 10\), so we can do **bitmask DP over subsets of terminals**.

We can model as:
1. First compute all-pairs shortest paths (Floyd–Warshall) since edge weights are positive.
2. Then solve Steiner tree using DP:
   - Treat the priority languages as terminals.
   - DP[mask][v] = minimum cost to connect the terminals in `mask` with the tree rooted at `v`.
   - Initialize: DP[1<<i][terminal_i] = 0.
   - For each node `v`, combine two disjoint masks: DP[mask][v] = min over submasks.
   - Also relax using shortest paths: DP[mask][v] → DP[mask][u] + dist[v][u].

Since \(n\) ≤ 100 and \(t\) ≤ 10, total states: \(2^t \times n\) ≤ 1024×100 ≈ 102,400.  
Each state merging over submasks is fine.

The final answer is min over all nodes v: DP[full_mask][v].

Let's write the solution.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    terminals = list(map(int, input().split()))
    terminals = [x-1 for x in terminals]  # zero-index
    
    INF = 10**15
    dist = [[INF]*n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0
    
    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        if w < dist[u][v]:
            dist[u][v] = w
        if w < dist[v][u]:
            dist[v][u] = w
    
    # Floyd-Warshall
    for k in range(n):
        dk = dist[k]
        for i in range(n):
            dik = dist[i][k]
            if dik == INF:
                continue
            di = dist[i]
            for j in range(n):
                nd = dik + dk[j]
                if nd < di[j]:
                    di[j] = nd
    
    # If t == 1, answer is 0 (start at that terminal)
    if t == 1:
        print(0)
        return
    
    full_mask = 1 << t
    # dp[mask][v]
    dp = [[INF]*n for _ in range(full_mask)]
    
    # Initialize single terminal states
    for i in range(t):
        dp[1 << i][terminals[i]] = 0
    
    # Combine submasks
    for mask in range(1, full_mask):
        # First combine smaller masks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if sub < other:  # only process once per pair
                for v in range(n):
                    if dp[sub][v] < INF and dp[other][v] < INF:
                        val = dp[sub][v] + dp[other][v]
                        if val < dp[mask][v]:
                            dp[mask][v] = val
            sub = (sub - 1) & mask
        
        # Relax using shortest paths
        # Run Dijkstra-like relaxation? Since n is small, just do Floyd-like relaxation
        for k in range(n):
            if dp[mask][k] == INF:
                continue
            dk = dist[k]
            dpm = dp[mask]
            for j in range(n):
                nd = dpm[k] + dk[j]
                if nd < dpm[j]:
                    dpm[j] = nd
    
    ans = INF
    for v in range(n):
        ans = min(ans, dp[full_mask-1][v])
    
    print(ans)

if __name__ == "__main__":
    solve()
```
