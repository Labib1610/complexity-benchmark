**Solution Explanation**

For every language we have a vertex.
A translator for languages `u , v` with fee `w` is an undirected edge
`u – v` with weight `w`.

If we keep a set of translators, the broadcast spreads exactly through the
connected component that contains the language we originally wrote in.
Therefore we have to choose a *connected* subgraph that contains **all**
target languages.  
The cheapest possible cost of such a subgraph is the classic **Steiner
tree** problem with the target set `T` (size `t ≤ 10`).  
The starting language can be any vertex of the tree, so no extra cost is
necessary – we only have to connect the targets.

`n ≤ 100`, `t ≤ 10` → we can solve Steiner tree by the standard DP over
subsets of terminals.

--------------------------------------------------------------------

#### 1.   DP definition  

```
mask … bitmask of a subset of the t target languages (0 … (1<<t)-1)
v    … a vertex (0 … n-1)

dp[mask][v] = minimum total fee of a connected subgraph
              that contains exactly the terminals of ‘mask’
              and whose *rightmost* vertex is v
```

“rightmost” means that the subgraph is a tree and `v` is one of its vertices.
The value is the sum of edge weights of that tree.

--------------------------------------------------------------------

#### 2.   Initialization  

For each single terminal `Ti` (index `i`)

```
dp[1<<i][Ti] = 0          # no edge needed, the tree consists of the single vertex
dp[1<<i][v] = INF for v ≠ Ti
```

--------------------------------------------------------------------

#### 3.   Merging two already built subsets  

For a mask with at least two bits we can split it into two non‑empty
disjoint sub‑masks `sub` and `mask ^ sub`.  
If both parts already end in the same vertex `v`, we can unite the two
trees (they already share `v`) without adding any edge:

```
dp[mask][v] = min over sub ⊂ mask ( dp[sub][v] + dp[mask^sub][v] )
```

All proper sub‑masks are enumerated by the classic loop

```
sub = (mask-1) & mask
while sub:
        …
        sub = (sub-1) & mask
```

Complexity of this step: `O(3^t * n)` – fine for `t ≤ 10`.

--------------------------------------------------------------------

#### 4.   Propagation through graph edges  

After the merging step `dp[mask][v]` is the best cost of a tree that ends
in `v`, but the tree may be improved by adding extra edges and moving the
rightmost vertex to a neighbour.  
That is exactly a **multi‑source Dijkstra**:

* start the priority queue with all vertices `v` whose current distance
  `dp[mask][v]` is finite,
* relax edges `u – w – v` as usual.

After Dijkstra finishes, `dp[mask][*]` contains the optimal values for
this mask.

Complexity per mask: `O(m log n)`.  
Overall: `O( 2^t * m log n )` – well inside limits.

--------------------------------------------------------------------

#### 5.   Result  

`full = (1<<t) - 1` – all terminals.  
The answer is the cheapest tree that connects them, i.e.

```
answer = min_v dp[full][v]
```

If `t == 1` the initialization already gives `0`.

--------------------------------------------------------------------

#### 6.   Correctness Proof  

We prove that the algorithm returns the minimum possible total fee.

---

##### Lemma 1  
For any mask and vertex `v`, after the Dijkstra step
`dp[mask][v]` equals the minimum cost of a connected subgraph that

* contains all terminals of `mask`,
* contains vertex `v`,
* and whose total edge weight is minimal.

**Proof.**  
The Dijkstra step starts from all vertices with their current best
costs (which already represent some trees ending at those vertices).
Running Dijkstra on a graph with non‑negative weights computes the
shortest paths from this multi‑source set, i.e. the cheapest way to
extend any of those trees by a path to any other vertex.
Consequently after the algorithm finishes, for each vertex `v` we have
the cheapest possible cost of a tree that contains the required terminals
and ends at `v`. ∎



##### Lemma 2  
For any mask and vertex `v`, after the *merge* step
(`dp[mask][v] = min_{sub} dp[sub][v] + dp[mask^sub][v]`)
the value equals the minimum cost of a tree that

* contains exactly the terminals of `mask`,
* contains vertex `v`,
* and can be split into two edge‑disjoint sub‑trees whose terminal sets are
  `sub` and `mask^sub` respectively (both also contain `v`).

**Proof.**  
Any tree that satisfies the description can be cut at vertex `v`,
producing two sub‑trees with the required properties; their costs add up,
hence the right hand side is an upper bound.
Conversely, taking optimal sub‑trees for `sub` and `mask^sub` (both ending
in `v`) and uniting them yields a tree for `mask` ending in `v` with exactly
that total cost. ∎



##### Lemma 3  
After processing a mask (merge + Dijkstra) `dp[mask][v]` is the minimum
cost of **any** tree that contains all terminals of `mask` and vertex `v`.

**Proof by induction on the number of bits in `mask`.**

*Base*: |mask| = 1 – initialization gives cost `0` for the terminal itself,
which is clearly optimal.

*Induction step*: assume the statement true for all proper sub‑masks.
For current `mask` we first consider any optimal tree `T` for `mask` ending
in `v`. Remove `v`; the remaining forest consists of at least two connected
components, each containing a non‑empty subset of terminals.
Pick any component, its terminal set is `sub`. The other components together
form `mask^sub`. Both are trees ending in `v`. By induction their costs are
`dp[sub][v]` and `dp[mask^sub][v]`. Hence `cost(T) ≥ dp[sub][v]+dp[mask^sub][v]`
and after taking the minimum over all `sub` we have
`cost(T) ≥ dp_after_merge[mask][v]`.

Now run Dijkstra: it can only *decrease* the values, never increase them,
and by Lemma&nbsp;1 the resulting value is achievable by some tree.
Thus after Dijkstra `dp[mask][v]` equals the optimum. ∎



##### Lemma 4  
`min_v dp[full][v]` equals the minimum total fee of a set of translators
that makes all target languages reachable from some starting language.

**Proof.**  
A feasible set of translators corresponds to a connected subgraph containing
all target vertices. Choose any vertex `r` of this subgraph as the starting
language; the subgraph is a tree (or can be reduced to a tree without
increasing cost). Its cost is at least `dp[full][r]` by Lemma&nbsp;3, therefore
`min_v dp[full][v]` is a lower bound for any feasible solution.

Conversely, let `v*` be the vertex attaining the minimum.
Lemma&nbsp;3 guarantees a tree of that exact cost containing all targets and
`v*`. Starting the broadcast in `v*` spreads it to the whole tree, so the
cost is feasible. Hence the minimum is also an upper bound. ∎



##### Theorem  
The algorithm outputs the minimum possible total retainer fee required to
reach all priority languages.

**Proof.**  
By Lemma&nbsp;3 the DP values are optimal for every mask after processing.
Applying Lemma&nbsp;4 to the full mask gives that the reported value is both
a lower and an upper bound on the optimum, therefore equal to it. ∎



--------------------------------------------------------------------

#### 7.   Complexity Analysis  

*Number of masks*: `2^t ≤ 1024`  
*Merge step*: `O(3^t * n) ≤ 59049 * 100 ≈ 6·10^6`  
*Dijkstra per mask*: `O(m log n)` → at most `1024 * 4950 * log 100`
≈ `5·10^6` operations.  

Total well below the 5 seconds limit, memory `O(2^t * n) ≤ 1024 * 100`
≈ 100 KB.

--------------------------------------------------------------------

#### 8.   Reference Implementation  (Python 3)

```python
import sys
import heapq

INF = 10**18

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))
    targets = [int(next(it)) - 1 for _ in range(t)]

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        adj[u].append((v, w))
        adj[v].append((u, w))

    if t == 1:
        print(0)
        return

    full = (1 << t) - 1
    dp = [[INF] * n for _ in range(1 << t)]

    # initialization
    for i, v in enumerate(targets):
        dp[1 << i][v] = 0

    # process masks in increasing order
    for mask in range(1, full + 1):
        # skip singletons (already optimal)
        if mask & (mask - 1):
            # merge submasks
            sub = (mask - 1) & mask
            while sub:
                other = mask ^ sub
                # both non‑empty
                if other:
                    dps = dp[sub]
                    dpo = dp[other]
                    dp_mask = dp[mask]
                    for v in range(n):
                        val = dps[v] + dpo[v]
                        if val < dp_mask[v]:
                            dp_mask[v] = val
                sub = (sub - 1) & mask

        # multi‑source Dijkstra for this mask
        dist = dp[mask]
        pq = [(dist[v], v) for v in range(n) if dist[v] < INF]
        heapq.heapify(pq)
        visited = [False] * n
        while pq:
            d, u = heapq.heappop(pq)
            if visited[u]:
                continue
            visited[u] = True
            for v, w in adj[u]:
                nd = d + w
                if nd < dist[v]:
                    dist[v] = nd
                    heapq.heappush(pq, (nd, v))

    ans = min(dp[full])
    print(ans)


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
