# Universal Translation

Time limit: 5 s   Memory limit: 256 MB

## Description

A galactic federation has $n$ known languages, each assigned a unique ID from 1 to $n$. The federation's linguistic database has a strict physical capacity of 100 language slots, and currently contains at least one known language. You are organizing an interstellar summit and must distribute a critical unified broadcast to populations that speak a specific subset of $t$ priority languages. The summit's broadcast array features exactly 10 output channels reserved for priority languages; therefore, the number of priority languages will never exceed this hardware limit, though there will always be at least one.

You will draft the original broadcast in exactly one language. You may choose any of the $n$ known languages to be this original source.

To ensure the broadcast reaches the priority populations, there are $m$ freelance bilingual translators available for hire. The total number of available translators can range from zero up to one for every possible pair of languages in the database. Each translator is proficient in two specific languages and charges a one-time retainer fee. A banking regulation limits any single retainer fee transaction to a maximum of 1,000,000 credits, and requires it to be at least 1 credit.

Once hired, a translator acts as a bidirectional linguistic bridge. The broadcast propagates through these hired bridges: if the broadcast becomes available in a certain language, any hired translator proficient in that language will immediately and automatically render it into their other known language. This propagation continues indefinitely across the entire network of hired translators. 

Your objective is to find the minimum total retainer fee you must pay to hire a group of translators such that, when you optimally choose the original source language, the automatic propagation process successfully renders the broadcast into all $t$ priority languages. (If the chosen original source language is itself a priority language, it occupies one of the channels directly).

## Input

The first line contains three integers $n$, $m$, and $t$.
The second line contains $t$ distinct integers: the IDs of the priority languages.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$, representing a translator proficient in languages $u$ and $v$ ($u \neq v$) who charges a retainer fee of $w$.
The available translators are sufficient to ensure all priority languages can be reached.

## Output

Print a single integer: the minimum total retainer fee required to ensure the broadcast reaches all priority languages.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, you can choose language 4 as the original source. By hiring translators for 1-4, 2-4, and 3-4 (at a total cost of 1+1+1 = 3), the broadcast propagates from language 4 into the priority languages 1, 2, and 3. This is cheaper than hiring translators to directly connect the priority languages (which would cost 4). 
In Example 3, there is only one priority language. You can choose it as the original source, requiring no translators to be hired.
