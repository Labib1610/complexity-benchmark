<STATEMENT>
# Universal Translation

Time limit: 5 s   Memory limit: 256 MB

## Description

A galactic federation has $n$ known languages (numbered 1 to $n$). You are organizing an interstellar summit and must distribute a critical unified broadcast to populations that speak a specific subset of $t$ priority languages.

You will draft the original broadcast in exactly one language. You may choose any of the $n$ known languages to be this original source.

To ensure the broadcast reaches the priority populations, there are $m$ freelance bilingual translators available for hire. Each translator is proficient in two specific languages and charges a one-time retainer fee. Once hired, a translator can perform unlimited translations back and forth between their two languages. 

You may hire translators for languages outside the $t$ priority ones, using those additional languages as intermediate stepping stones. As long as there is a valid chain of hired translators from your chosen original source language to a priority language, the population speaking that priority language will receive the broadcast. (If the chosen original source language is itself a priority language, that population receives it directly without needing a translation).

Find the minimum total retainer fee you must pay to hire a group of translators such that, for some optimally chosen original source language, the broadcast can be successfully translated into all $t$ priority languages.

## Input

The first line contains three integers $n$, $m$, and $t$ (1 ≤ $n$ ≤ 100, 0 ≤ $m$ ≤ $n$·($n$−1)/2, 1 ≤ $t$ ≤ 10).
The second line contains $t$ distinct integers: the IDs of the priority languages.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ (1 ≤ $u$, $v$ ≤ $n$, $u \neq v$, 1 ≤ $w$ ≤ 1000000): a translator proficient in languages $u$ and $v$ who charges a retainer fee of $w$.
The available translators are sufficient to ensure all priority languages can be reached.

## Output

Print a single integer: the minimum total retainer fee required to ensure the broadcast reaches all priority languages.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, you can choose language 4 as the original source. By hiring translators for 1-4, 2-4, and 3-4 (at a total cost of 1+1+1 = 3), the broadcast can be translated from language 4 into the priority languages 1, 2, and 3. This is cheaper than hiring translators to directly connect the priority languages (which would cost 4). 
In Example 3, there is only one priority language. You can choose it as the original source, requiring no translators to be hired.
</STATEMENT>
<RATIONALE>
I reframed the problem from "mutually connect $t$ delegates" to "broadcast from a single optimally chosen source language to $t$ priority languages". This forces the model to recognize that since the translation edges are undirected, choosing a source and connecting it to all targets is mathematically identical to finding a minimum connected subgraph containing just the targets. Models relying on surface pattern matching will likely write an outer loop to iterate over all $N$ possible source nodes and compute a subset DP for each, which increases the time complexity by a factor of $N$ and will Time Limit Exceed. Models that genuinely reason will recognize the source choice is a red herring and solve it with the standard $O(3^t N)$ subset DP.
</RATIONALE>
<PRESERVED_ANSWER>
Because the translation edges are bidirectional, any valid subgraph connecting an arbitrary source to all $t$ priority languages must contain a connected component covering all $t$ priority languages, meaning the minimum cost is exactly the undirected Steiner Tree cost over the $t$ priority languages, identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the undirected Steiner Tree problem on graphs, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret "convert the broadcast ... in either direction" as meaning the hired translator can only be used as a directed edge once chosen, but the explicit phrasing "perform unlimited translations back and forth" eliminates this ambiguity.
</RISK>
