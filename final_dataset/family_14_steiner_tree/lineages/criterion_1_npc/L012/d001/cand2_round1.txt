<STATEMENT>
# Galactic Summit Interpreters

Time limit: 5 s   Memory limit: 256 MB

## Description

You are organizing an interstellar summit for a galactic federation. The summit takes place in a facility equipped with exactly one hundred audio channels. This physical capacity establishes the upper bound for **n**, the number of known languages in the federation (there is always at least one language present). You must ensure that the inner circle of delegates can all understand each other. The inner circle is seated at a table with exactly ten translation earpieces. This sets the upper bound for **t**, the number of primary languages you must support (there is always at least one primary language).

There are **m** freelance bilingual interpreters available for hire. The number of available interpreters, **m**, can be zero, up to a maximum of the total number of unique non-directional pairs among the **n** languages. Each interpreter is proficient in two distinct languages and charges a one-time retainer fee **w** to join your summit staff. Federation minimum wage laws guarantee a fee of at least one credit, while an anti-gouging statute caps the fee at one million credits. Once hired, an interpreter can perform unlimited translations back and forth between their two languages.

You may also hire interpreters for languages outside the **t** primary ones, using those additional languages as intermediate stepping stones. For example, if you hire an interpreter between Primary Language A and Secondary Language X, and another between Secondary Language X and Primary Language B, delegates speaking A and B can communicate via X.

Find the minimum total retainer fee you must pay to hire a group of interpreters such that a message originating in any primary language can be interpreted (directly or through a chain of interpreters) into all other primary languages.

## Input

The first line contains three integers **n**, **m**, and **t**. The bounds on these values are determined strictly by the physical and legal limits described above.
The second line contains **t** distinct integers: the IDs of the primary languages (each between 1 and **n**).
Each of the next **m** lines contains three integers **u**, **v**, and **w**: an interpreter proficient in languages **u** and **v** who charges a retainer fee of **w**.
The available interpreters are always sufficient to ensure all primary languages can be connected.

## Output

Print a single integer: the minimum total retainer fee required to ensure all primary languages are mutually intelligible.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, using language 4 as an intermediate pivot (hiring interpreters for 1-4, 2-4, and 3-4 at a total cost of 1+1+1 = 3) is cheaper than hiring interpreters to directly connect the three primary languages (which would cost 4). In Example 3, there is only one primary language, so no interpreters need to be hired.
</STATEMENT>
<RATIONALE>
I removed the explicit mathematical inequalities for the input bounds (e.g., `1 <= t <= 10`) and instead encoded these limits as physical constraints within the scenario description (e.g., "exactly ten translation earpieces"). This prevents models from pattern-matching the small terminal set size `t <= 10` from the input specification, forcing them to comprehend the scenario text to deduce that an exponential-time subset dynamic programming approach (like Dreyfus-Wagner) is required.
</RATIONALE>
<PRESERVED_ANSWER>
The core problem remains identical: finding the minimum cost to connect a specific subset of nodes in a weighted graph, meaning the optimal cost for any given input is exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is still the Minimum Weight Steiner Tree problem on a general graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "sets the upper bound for **t**" as meaning **t** is always 10, though the phrasing "upper bound" and the input format specifying **t** as a variable should clarify that **t** can vary up to that limit.
</RISK>
