<STATEMENT>
# Problem A — Grid Integration

Time limit: 5 s   Memory limit: 256 MB

## Description

An offshore wind farm consists of **n** platforms, numbered 1 through **n**. A survey has identified **m** potential submarine cable routes, each capable of linking a specific pair of platforms. 

A subset of **t** platforms houses the primary turbines. The central control facility is equipped with a hardware panel containing exactly ten physical slots for primary turbine monitoring modules. The farm is guaranteed to have at least one primary turbine, and the total count will never exceed the panel's slot capacity. Furthermore, the total number of platforms in the entire farm, **n**, is a positive integer limited to the square of the panel's maximum slot capacity. The number of surveyed cable routes, **m**, is a non-negative integer that can be up to the theoretical maximum where every distinct pair of platforms shares a route.

Your task is to select a subset of the surveyed cable routes to install. The installed cables must form an interconnected grid such that energy can flow between any two primary turbines. This flow may pass through any number of installed cables, and platforms without primary turbines can be utilized as intermediate routing junctions. Each cable route has a specific material cost, which is a positive integer capped at one million.

Determine the minimum possible total material cost to establish this required connectivity.

## Input

The first line provides three integers: **n**, **m**, and **t**.
The second line lists **t** distinct integers representing the identifiers of the platforms that contain primary turbines.
The following **m** lines each contain three integers **u**, **v**, and **w**, detailing a potential submarine cable route between distinct platforms **u** and **v** with a material cost of **w**.
It is guaranteed that a valid configuration of cables exists.
(All variables strictly adhere to the limits defined by the facility's physical constraints described above.)

## Output

Print a single integer representing the minimum total material cost required to connect all primary turbines.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, purchasing the cables joining platform 4 to platforms 1, 2, and 3 (total cost 1+1+1 = 3) allows energy to flow between the three primary turbines. This is cheaper than installing cables strictly between the primary turbine platforms themselves (which would cost 4). In Example 3 there is only one primary turbine, so no cabling is needed.
