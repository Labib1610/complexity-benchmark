<STATEMENT>
# Problem A — Grid Integration

Time limit: 5 s   Memory limit: 256 MB

## Description

An offshore wind farm is planned in a maritime sector divided into a coordinate grid with 10 rows and 10 columns. Each cell in the grid can host at most one platform, meaning the total number of platforms $n$ is between 1 and the total number of grid cells. The platforms are identified by integers from 1 to $n$.

Among these, a certain headcount $t$ of platforms are equipped with primary turbines. To comply with environmental acoustic limits, $t$ is at least 1 and strictly capped at the number of columns in the grid.

Certain pairs of platforms can be linked by a submarine cable. A contractor has provided $m$ possible cable options, each with a specific material cost $w$. The cost $w$ of any single cable is a positive integer no greater than one million. The number of options $m$ can range from zero up to an option for every possible pair of platforms.

Initially, each platform operates its own isolated energy grid. Building a submarine cable between two platforms physically merges their respective grids into a single unified grid.

You must select a subset of the available cable options to build such that, after all selected cables are installed, every primary turbine ends up in the exact same unified energy grid. Platforms without primary turbines may also be included in this grid if they help reduce the total cost.

Determine the minimum total material cost required to satisfy this requirement.

## Input

The first line contains three integers **n**, **m**, and **t**.
The second line contains **t** distinct integers: the identifiers of the platforms that contain primary turbines.
Each of the next **m** lines contains three integers **u**, **v**, and **w**, describing a cable option between platform **u** and platform **v** with material cost **w** (**u** $\neq$ **v**). 
All bounds on these values follow strictly from the physical limits described above.
It is guaranteed that the available cable options are sufficient to allow all primary turbines to end up in the same energy grid.

## Output

Print a single integer: the minimum total material cost of the built cables.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, building the cables between platform 4 and platforms 1, 2, and 3 (total cost 1+1+1 = 3) merges their grids such that the three primary turbine platforms end up in the same energy grid. This is cheaper than building cables strictly between the primary turbine platforms themselves (which would cost 4). 
In Example 3 there is only one primary turbine platform, so it is already in its own energy grid and no cabling is needed.

I replaced the explicit numeric bounds in the Input section with indirect bounds embedded in the scenario description (a 10x10 grid for platforms, capped by column count for turbines). This forces the model to read and comprehend the physical constraints of the text to deduce the state space dimensions (like $t \le 10$ and $n \le 100$), rather than relying on standard bare inequalities to quickly recognize the small-terminal Steiner tree DP pattern.
</RATIONALE>
