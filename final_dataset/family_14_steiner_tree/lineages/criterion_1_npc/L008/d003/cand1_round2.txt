<STATEMENT>
# Problem A — Fluid Integration

Time limit: 5 s   Memory limit: 256 MB

## Description

A chemical plant layout consists of **n** reaction chambers (numbered 1 to n). Certain pairs of chambers can be linked by a bidirectional transfer pipe. Each potential pipe has a specific installation expense.

Among the chambers, **t** are equipped with **catalyst injectors**. 

Initially, all chambers are completely isolated from one another. Installing a transfer pipe between chamber *u* and chamber *v* combines their contents, merging them—along with any other chambers they are already linked to—into a single continuous fluid system.

Your objective is to authorize a subset of pipes to be installed so that, once completed, all **t** catalyst injectors belong to the exact same continuous fluid system. This allows the catalyst to circulate among all of them. (Chambers without catalyst injectors can also be included in this system to serve as routing junctions).

Calculate the minimum total installation expense required to link all catalyst injectors into a single system.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the ids of the chambers equipped with catalyst injectors.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): a viable transfer pipe linking chamber u and chamber v at an installation expense of w.
The available pipe options are always sufficient to successfully integrate all catalyst injectors into the same fluid system.

## Output

Print a single integer: the minimum total installation expense of the authorized pipes.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, installing pipes between chamber 4 and chambers 1, 2, and 3 (total expense 1+1+1 = 3) merges them such that the three catalyst injectors end up in the same continuous fluid system. This is more cost-effective than installing pipes strictly between the catalyst injectors themselves (which would incur an expense of 4). In Example 3, there is only one catalyst injector, so it already constitutes a valid system on its own and no pipes need to be installed.
