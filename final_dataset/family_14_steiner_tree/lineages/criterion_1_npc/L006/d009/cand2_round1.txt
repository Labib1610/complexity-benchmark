<METHOD_NAME>Graphic Matroid Span Isomorphism</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the graph connectivity / power-series positivity condition with an equivalent linear algebraic condition: synthesizing target vectors (e_i - e_j) from a basis of chosen transaction vectors (e_u - e_v). By the properties of the graphic matroid, the target vectors are in the span of the chosen vectors if and only if the corresponding edges contain a path between the critical vertices. This forces the model to recognize the equivalence between the column space of an incidence matrix and graph connectivity, completely removing graph-theoretic affordances while maintaining the exact same underlying mathematical structure.</METHOD_DESCRIPTION>

<STATEMENT>
# Basis Vector Synthesis Configuration

Time limit: 5 s   Memory limit: 256 MB

## Description

A data engineering team is configuring a system of $n$ continuous variables, indexed 1 through $n$. The team is focused on a specific subset of $t$ critical variables.

The team can select from $m$ available transition vectors. Each available transition vector acts on a specific pair of variables $u$ and $v$. It is defined as a vector in $\mathbb{R}^n$ with a value of $+1$ at index $u$, a value of $-1$ at index $v$, and $0$ at all other indices. Each vector has a one-time activation cost $w$.

The team's objective is to select a single portfolio of these transition vectors. From this shared portfolio, they must be able to synthesize a specific target vector $R_{i,j}$ for every pair of critical variables $i$ and $j$ (including when $i = j$). 
The target vector $R_{i,j}$ is defined as having a value of $+1$ at index $i$, a value of $-1$ at index $j$, and $0$ at all other indices (if $i=j$, $R_{i,j}$ is the zero vector). 
A target vector can be synthesized if it can be expressed as a linear combination of the transition vectors included in the team's selected portfolio.

The team is permitted to activate transition vectors involving non-critical variables, provided their inclusion expands the linear span to help synthesize the required targets. Each available transition vector is either selected for activation or not selected. If selected, its activation cost is paid exactly once. The total cost is the sum of the activation costs of the distinct vectors the team chooses to activate.

Determine the minimum total activation cost required to select a portfolio of transition vectors such that $R_{i,j}$ can be synthesized for all possible pairs of critical variables $i$ and $j$.

## Input

The first line provides three integers $n$, $m$, and $t$.
The integer $n$ represents the number of variables. It is at least 1, and its maximum limit is the number of years in a century.
The integer $m$ represents the number of available transition vectors. It is at least 0, and its maximum limit is exactly the number of distinct unordered pairs that can be formed from $n$ items.
The integer $t$ represents the number of critical variables. It is at least 1, and its maximum limit is exactly the number of pins in a standard ten-pin bowling rack.

The second line lists $t$ distinct integers representing the indices of the critical variables.

Each of the subsequent $m$ lines specifies an available transition vector using three integers $u$, $v$, and $w$.
The values $u$ and $v$ are distinct valid variable indices, specifying where the vector has $+1$ and $-1$ respectively (their order does not restrict linear combinations).
The value $w$ is the one-time activation cost. It is at least 1, and its maximum limit is exactly the square of one thousand.

It is guaranteed that the set of all $m$ available transition vectors is sufficient to synthesize the targets for all critical variables.

## Output

Print a single integer: the minimum total activation cost required to select a portfolio of transition vectors such that $R_{i,j}$ can be synthesized for all pairs of critical variables $i$ and $j$.

### Example 1

**Input**
```
4 6 3

3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**


**Output**
```
2
```

### Example 3

**Input**
```

1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, activating the transition vectors that involve the non-critical variable 4 (which require costs of 1, 1, and 1; total cost = 3) is more efficient than activating the vectors directly involving only the three critical variables (which would result in a total cost of 4). Let $T_{u,v}$ denote the vector with $+1$ at $u$ and $-1$ at $v$. The selected vectors $T_{1,4}$ and $T_{2,4}$ can be linearly combined ($T_{1,4} - T_{2,4}$) to synthesize the target $R_{1,2}$. Including $T_{3,4}$ ensures the target vectors can be synthesized for all pairs among the critical variables 1, 2, and 3. Thus, variable 4 acts as an effective intermediary basis dimension. 

In Example 3, there is only a single critical variable. The requirement to synthesize $R_{1,1}$ (which is the zero vector) is inherently satisfied by an empty portfolio, requiring no vectors to be selected and resulting in a total cost of 0.

<RATIONALE>
The problem's connectivity requirement was previously exposed through a power-series positivity condition that models easily matched to graph reachability. This rewrite completely replaces the graph-theoretic framing with an equivalent linear algebraic one: synthesizing target vectors $e_i - e_j$ from a chosen basis of transaction vectors $e_u - e_v$. By the properties of the graphic matroid (or the column space of an incidence matrix), the targets are in the span of the basis if and only if the chosen edges form a connected path between the critical vertices. This forces the model to genuinely reason about the algebraic structure to discover the Steiner Tree isomorphism, defeating surface-level pattern matching. Numeric bounds have been replaced with indirect physical/scenario limits (e.g., "years in a century" for 100) to satisfy the S07 strategy.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the target vector $e_i - e_j$ is in the linear span of a set of vectors $e_u - e_v$ is mathematically identical to the condition that vertices $i$ and $j$ are in the same connected component of the graph formed by the edges $(u,v)$; thus, the minimum cost to satisfy this for all critical pairs is exactly the Minimum Steiner Tree cost.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Weight Steiner Tree problem on a weighted undirected graph, keeping it NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret whether the target vectors must be synthesized using the same shared portfolio or if a separate portfolio can be chosen for each pair. The phrase "select a single portfolio... From this shared portfolio, they must be able to synthesize..." was added to strongly prevent this ambiguity.
</RISK>
