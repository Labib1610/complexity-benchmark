<STATEMENT>
# Topological Indistinguishability Configuration

Time limit: 5 s   Memory limit: 256 MB

## Description

A data engineering team is configuring a topological space on a finite set of $n$ variables, indexed 1 through $n$. The team is focused on a specific subset of $t$ critical variables.

The team can activate a selection from $m$ available bidirectional constraints. Each available constraint acts on a specific pair of variables $u$ and $v$, and has a one-time activation cost $w$.

If the team selects a subset of these constraints, they define a topology $\tau$ on the set of $n$ variables. To ensure structural integrity, $\tau$ is defined as the finest topology (the topology containing the maximum possible number of open sets) such that for every activated constraint between variables $u$ and $v$, the following condition holds: every open set in $\tau$ that contains $u$ must also contain $v$, and every open set in $\tau$ that contains $v$ must also contain $u$. 

The team's objective is to select a subset of constraints such that in the resulting topology $\tau$, for every pair of critical variables $i$ and $j$ (including when $i = j$), any open set containing $i$ necessarily contains $j$.

The team is permitted to activate constraints involving non-critical variables, provided their inclusion helps establish the required topological condition among the critical variables. Each available constraint is either selected for activation or not selected. If selected, its activation cost is paid exactly once. The total cost is the sum of the activation costs of the distinct constraints the team chooses to activate.

Determine the minimum total activation cost required to select a set of constraints such that the topological condition is satisfied for all pairs of critical variables $i$ and $j$.

## Input

The first line provides three integers $n$, $m$, and $t$ (1 ≤ $t$ ≤ 10, 1 ≤ $n$ ≤ 100, 0 ≤ $m$ ≤ $n$·($n$−1)/2).
The second line lists $t$ distinct integers representing the indices of the critical variables.
Each of the subsequent $m$ lines specifies an available constraint using three integers $u$, $v$, and $w$ (1 ≤ $u$, $v$ ≤ $n$, $u$ ≠ $v$, 1 ≤ $w$ ≤ 1000000). This indicates a constraint between variables $u$ and $v$ with a one-time activation cost of $w$.
It is guaranteed that the set of all $m$ available constraints is sufficient to satisfy the requirement for all critical variables.

## Output

Print a single integer: the minimum total activation cost required to ensure that for all pairs of critical variables $i$ and $j$, any open set in $\tau$ containing $i$ also contains $j$.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, activating the constraints that involve the non-critical variable 4 (which require costs of 1, 1, and 1; total cost = 3) is more efficient than activating the constraints directly involving only the three critical variables (which would result in a total cost of 4). The constraints between (1, 4) and (2, 4) ensure that any open set containing 1 must contain 4, and thus must contain 2. Including (3, 4) ensures the topological condition holds for all pairs among the critical variables 1, 2, and 3. Thus, variable 4 acts as an effective intermediary. 
In Example 3, there is only a single critical variable. The requirement that any open set containing 1 must contain 1 is inherently satisfied by the definition of a set, regardless of which constraints are selected. Therefore, no constraints need to be activated, resulting in a total cost of 0.
</STATEMENT>
<RATIONALE>
The power-series mathematical condition was replaced with a topological indistinguishability condition. The target models previously mapped the non-zero entries of the matrix exponential directly to walks in a graph. This rewrite forces the model to deduce that the finest topology satisfying the mutual inclusion constraints is the partition topology of the graph's connected components, making the condition equivalent to graph connectivity without using any graph terminology.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that any open set containing $i$ must contain $j$ in the finest topology is mathematically identical to $i$ and $j$ belonging to the same connected component of the activated constraints, preserving the exact same valid subsets and their costs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Steiner Tree problem on an undirected graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models or humans with no background in point-set topology might struggle to parse "finest topology" and "open set", though the explicit transitivity explained in the note mitigates this by demonstrating the mechanical effect of the rules.
</RISK>
