<METHOD_NAME>Polynomial Ideal Isomorphism</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the permutation group orbit condition with an equivalent algebraic geometry condition: requiring that the difference between any two core variables belongs to the polynomial ideal generated by a selected set of binomial differences. This masks the graph connectivity structure while preserving exact mathematical equivalence.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Ideal Generators

Time limit: 5 s   Memory limit: 256 MB

## Description

A computational algebra system is working with a polynomial ring $R = \mathbb{R}[z_1, z_2, \dots, z_n]$ over the real numbers, which has $n$ indeterminates. The system identifies a specific subset of $t$ core indeterminates that are of particular interest.

The system's goal is to construct a polynomial ideal $I \subseteq R$ such that for every pair of core indeterminates $z_a$ and $z_b$, their difference $z_a - z_b$ belongs to the ideal $I$.

To construct this ideal, the system can choose to include generators from a provided list of $m$ available binomials. Each available binomial is of the form $z_u - z_v$. 
If a set of binomials $S$ is selected, the generated ideal $I$ is defined as the standard polynomial ideal generated by $S$:
$I = \langle S \rangle = \left\{ \sum_{k=1}^{|S|} p_k g_k \;\middle|\; p_k \in R, g_k \in S \right\}$.

The system is allowed to include binomials that involve non-core indeterminates, as long as their inclusion helps satisfy the condition for the core indeterminates. Each available binomial is either selected for inclusion or not. If selected, its inclusion cost $w$ is paid exactly once. The total cost is the sum of the inclusion costs of the distinct binomials the system chooses to add to the generating set $S$.

Determine the minimum total inclusion cost required to select a generating set $S$ such that $z_a - z_b \in \langle S \rangle$ for all pairs of core indeterminates $z_a, z_b$.

## Input

The first line provides three integers $n$, $m$, and $t$ (1 ≤ $t$ ≤ 10, 1 ≤ $n$ ≤ 100, 0 ≤ $m$ ≤ $n \cdot (n−1)/2$).
The second line lists $t$ distinct integers representing the indices of the core indeterminates.
Each of the subsequent $m$ lines specifies an available binomial generator using three integers $u$, $v$, and $w$ (1 ≤ $u$, $v$ ≤ $n$, $u \neq v$, 1 ≤ $w$ ≤ 1000000). This indicates a binomial $z_u - z_v$ (or equivalently $z_v - z_u$) with a one-time inclusion cost of $w$.
It is guaranteed that the set of all $m$ available binomials is sufficient to satisfy the condition for all core indeterminates.

## Output

Print a single integer: the minimum total inclusion cost required to select a set of generators $S$ such that $z_a - z_b \in \langle S \rangle$ for all core indeterminates $z_a, z_b$.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, including the binomials $z_1 - z_4$, $z_2 - z_4$, and $z_3 - z_4$ (which require costs of 1, 1, and 1; total cost = 3) is more efficient than including the binomials directly involving only the three core indeterminates (which would result in a total cost of 4). If $S = \{z_1 - z_4, z_2 - z_4, z_3 - z_4\}$, the generated ideal $\langle S \rangle$ contains $z_1 - z_2$ because $z_1 - z_2 = (z_1 - z_4) - (z_2 - z_4)$. Similarly, it contains $z_2 - z_3$ and $z_1 - z_3$, satisfying the requirement for the core indeterminates $z_1, z_2, z_3$. Thus, the indeterminate $z_4$ acts as an effective intermediary. 
In Example 3, there is only a single core indeterminate. The condition is vacuously satisfied, so no binomials need to be included, resulting in a total cost of 0.
</STATEMENT>
<RATIONALE>
The surviving model successfully identified the Steiner tree structure by mapping "sequence of selected operators" directly to graph connectivity. To remove this affordance, the problem was translated into an isomorphic algebraic geometry framing: constructing a polynomial ideal from binomial differences. This forces models to deduce that a difference of variables belongs to a binomial ideal if and only if the variables are connected in the underlying graph of generators.
</RATIONALE>
<PRESERVED_ANSWER>
The difference $z_a - z_b$ belongs to the ideal generated by a set of differences $S$ if and only if $a$ and $b$ are in the same connected component of the graph formed by $S$, meaning the mathematical condition and minimal costs are identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the Minimum Steiner Tree problem on a weighted graph, which is NP-complete.
</PRESERVED_CLASS>
