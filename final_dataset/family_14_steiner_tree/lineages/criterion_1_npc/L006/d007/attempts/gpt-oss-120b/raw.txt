**Solution Explanation**

For every constraint we have an (undirected) edge  

```
u ──w── v          cost = w
```

Choosing a set of constraints means choosing a set of edges.
All *critical* vertices have to become equal – in graph terms they have to be
contained in one connected component.
Thus we have to find a minimum‑cost set of edges that connects the given
`t ≤ 10` special vertices (terminals).  
That is exactly the **Steiner Tree** problem in an undirected weighted graph.

`n ≤ 100`, therefore a classic DP over subsets of terminals is easily fast
enough.



--------------------------------------------------------------------

#### 1.   DP definition  

```
mask … bitmask of terminals, 0 … (1<<t)-1
v    … graph vertex, 0 … n-1

dp[mask][v] = minimum total cost of a subgraph
              that
              • connects all terminals whose bits are set in mask,
              • and whose *root* (any vertex of the subgraph) is v
                (v belongs to the subgraph).
```

The answer is  

```
min_v dp[fullMask][v]          (fullMask = (1<<t)-1)
```

--------------------------------------------------------------------

#### 2.   Initialisation  

For every terminal `i` (its vertex is `term[i]`)  

```
dp[1<<i][ term[i] ] = 0                # nothing has to be bought
all other entries = INF
```

--------------------------------------------------------------------

#### 3.   Building larger masks  

All masks are processed in increasing order of the number of set bits.
For a fixed mask we first try to **merge two already known smaller masks**,
then we improve the distances by travelling through ordinary graph edges.

*Merge*  

```
for every non‑empty proper submask sub of mask
        other = mask ^ sub
        for every vertex v
                dp[mask][v] = min( dp[mask][v],
                                   dp[sub][v] + dp[other][v] )
```

Both parts already end in the same vertex `v`, therefore their union is a
valid subgraph for the whole `mask`.

*Shortest paths*  

After the merge step `dp[mask][v]` is known for every `v`, but the subgraph
might be improved by adding ordinary edges (e.g. moving the root to a neighbour).
We run Dijkstra with the current `dp[mask][·]` as the start distances:

```
priority queue Q
push (dp[mask][v], v) for all v with finite distance

while Q not empty
        (d,u) = pop
        if d != dp[mask][u] : continue
        for (v,w) in adj[u]
                if dp[mask][v] > d + w
                        dp[mask][v] = d + w
                        push (dp[mask][v], v)
```

Now `dp[mask][·]` contains the cheapest possible cost for that mask.

Both steps are standard; the whole algorithm is well‑known as
*Dreyfus‑Wagner* DP for Steiner trees.

--------------------------------------------------------------------

#### 4.   Complexity analysis  

```
number of masks            : 2^t   ≤ 1024
submask loops per mask     : ≤ 2^{k-1}   (k = bits of mask)
total merges                : O(3^t * n)  ≤ 6·10^4 * 100  ≈ 6·10^6
Dijkstra per mask           : O((n+m) log n)  ≤ (5·10^3)·log100
overall                     : 2^t * (n+m) log n  ≤ 5·10^6 operations
memory                      : (2^t)·n  ≤ 1024·100  = 1·10^5 integers
```

All far below the limits (5 s, 256 MiB).

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm outputs the minimum possible total activation cost.

---

##### Lemma 1  
For every mask and vertex `v` the value `dp[mask][v]` after the algorithm
finishes processing this mask equals the minimum cost of **any** subgraph
that

* connects exactly the terminals of `mask`,
* contains `v`,
* and whose edges are a subset of the given edges.

**Proof.** By induction over the number of bits in `mask`.

*Base* `|mask| = 1`.  
Only the single terminal `t` belongs to `mask`.  
The unique subgraph connecting it and containing vertex `v` is possible
iff `v = t`; its cost is `0`.  
The initialization sets exactly these values, therefore the statement holds.

*Induction step.* Assume the statement true for all masks with fewer bits.
Take a mask `M` with at least two bits.
During processing of `M` the algorithm first executes the merge loop.
Consider any optimal subgraph `S` for `(M, v)`.  
Remove vertex `v` from `S`; the remaining edges still connect all terminals.
In `S` there exists a partition of the terminals into two non‑empty sets
`A` and `B` such that the edges incident to `v` can be split into two
subgraphs `S_A` (connecting `A` and `v`) and `S_B` (connecting `B` and `v`),
and `S = S_A ∪ S_B`.  
Corresponding masks are `sub = mask(A)` and `other = mask(B)` (both proper).
By induction hypothesis
`cost(S_A) ≥ dp[sub][v]` and `cost(S_B) ≥ dp[other][v]`.  
Therefore `cost(S) ≥ dp[sub][v] + dp[other][v]`.  
The merge step stores the minimum of exactly those sums, consequently after
the merge
`dp[M][v] ≤ cost(S)` for **every** feasible `S`.  
Thus `dp[M][v]` is a lower bound on the optimum.

Conversely, let `sub` be the submask that realises the minimum in the merge
step. The algorithm knows optimal subgraphs for `(sub, v)` and `(other, v)`.
Their union is a feasible subgraph for `(M, v)` with cost exactly the stored
value, so the lower bound is attainable.  
Hence after the merge step `dp[M][v]` equals the optimum **restricted to
subgraphs whose root is already `v`** (i.e. where `v` belongs to the subgraph,
but edges may still be missing).

Running Dijkstra adds any number of ordinary edges to move the root from a
vertex to a neighbour, exactly modelling the possibility to extend the
subgraph by additional edges. Dijkstra computes the cheapest way to reach
every vertex, therefore after it terminates the distance to every `v`
is the minimum possible cost of any subgraph for mask `M` that contains `v`. ∎



##### Lemma 2  
After all masks have been processed,
`ans = min_v dp[fullMask][v]` equals the minimum possible cost of a subgraph
that connects **all** terminals (order does not matter).

**Proof.** By Lemma&nbsp;1, for each vertex `v` the value `dp[fullMask][v]`
is the cheapest cost of a subgraph that contains `v` and connects all
terminals. The cheapest among them therefore is the overall optimum. ∎



##### Lemma 3  
Any set of selected constraints that makes all terminals equal corresponds
to a subgraph that connects all terminals, and its total activation cost
equals the sum of edge weights of that subgraph.

**Proof.** Selecting a constraint means taking the corresponding edge.
Equality propagates along paths, therefore two terminals become forced equal
iff they lie in the same connected component of the chosen edges.
Hence the chosen edges must connect all terminals. The cost definition is
exactly the sum of the chosen edge weights. ∎



##### Theorem  
The algorithm outputs the minimum possible total activation cost that guarantees
all critical variables to be equal.

**Proof.**  
*Soundness*: the algorithm outputs `ans`. By Lemma&nbsp;2 there exists a
subgraph of total weight `ans` that connects all terminals.
Choosing exactly the edges of this subgraph is a feasible set of constraints,
so a cost of `ans` can be achieved.

*Optimality*: let `C*` be an optimal feasible set of constraints,
with total weight `opt`. By Lemma&nbsp;3 the edges of `C*` form a
subgraph connecting all terminals of weight `opt`. Lemma&nbsp;2 tells us that
`ans` is **no larger** than the weight of any such subgraph, therefore
`ans ≤ opt`. Together with soundness we have `ans = opt`. ∎

#### 6.   Reference Implementation  (Python 3)

```python
import sys
import heapq

INF = 10 ** 18

def solve() -> None:
    data = list(map(int, sys.stdin.read().strip().split()))
    if not data:
        return
    it = iter(data)
    n = next(it)
    m = next(it)
    t = next(it)

    terminals = [next(it) - 1 for _ in range(t)]

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = next(it) - 1
        v = next(it) - 1
        w = next(it)
        adj[u].append((v, w))
        adj[v].append((u, w))

    full = 1 << t
    dp = [[INF] * n for _ in range(full)]

    # initial masks: single terminals
    for i, v in enumerate(terminals):
        dp[1 << i][v] = 0

    # process masks in increasing order of bits
    for mask in range(1, full):
        # merge submasks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if other:
                dps = dp[sub]
                dpo = dp[other]
                dp_mask = dp[mask]
                # try to improve via meeting at same vertex
                for v in range(n):
                    val = dps[v] + dpo[v]
                    if val < dp_mask[v]:
                        dp_mask[v] = val
            sub = (sub - 1) & mask

        # Dijkstra to propagate through graph edges
        dist = dp[mask]
        heap = [(dist[v], v) for v in range(n) if dist[v] < INF]
        heapq.heapify(heap)
        while heap:
            d, u = heapq.heappop(heap)
            if d != dist[u]:
                continue
            for v, w in adj[u]:
                nd = d + w
                if nd < dist[v]:
                    dist[v] = nd
                    heapq.heappush(heap, (nd, v))

    ans = min(dp[full - 1])
    print(ans)


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input / output format.
