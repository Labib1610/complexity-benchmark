<STATEMENT>
# Problem A — Secure Facility Integration

Time limit: 5 s   Memory limit: 256 MB

## Description

A corporate campus consists of several buildings. Certain pairs of buildings can be linked by a fiber conduit for a specific installation fee. The administration has designated a subset of these buildings as critical facilities. These critical facilities must all be integrated into a single unified communication network. This integration is achieved if any critical facility can transmit data to any other critical facility, possibly by routing the signal through intermediate buildings via the installed fiber conduits. Intermediate buildings that are not critical facilities are strictly optional; you may route conduits through them if it reduces the overall installation fee, or ignore them completely.

Find the minimum total installation fee required to ensure all critical facilities are successfully integrated.

## Input

The first line contains three integers **n**, **m**, and **t**.
- **n** is the total number of buildings (numbered 1 to **n**).
- **m** is the number of available fiber conduit options.
- **t** is the number of critical facilities.

The security clearance system assigns a unique single decimal digit (0 through 9) to each critical facility. Therefore, **t** is at least 1 and is bounded by the total number of possible decimal digits.
The total number of buildings **n** is a positive integer that will not exceed the square of the maximum possible number of critical facilities.
The number of available conduits **m** is non-negative and will not exceed the total number of distinct pairs of buildings.

The second line contains **t** distinct integers: the ids of the critical facilities.

Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**): a fiber conduit option linking building **u** and building **v** at an installation fee of **w**.
The installation fee **w** is a positive integer that will never exceed the cube of the maximum possible number of buildings.

The provided fiber conduit options are always sufficient to integrate all critical facilities.

## Output

Print a single integer: the minimum total installation fee to integrate all critical facilities.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, routing the network through the optional relay building 4 (which costs 1+1+1 = 3) is cheaper than linking the three critical facilities directly (which would cost 4). In Example 3, there is only one critical facility, so no fiber conduits are needed.
