# Secure Communications Network

Time limit: 5 s   Memory limit: 256 MB

## Description

A city contains **n** facilities, identified by integers from 1 to n. Certain pairs of facilities can be linked with a secure fiber-optic conduit, with each potential link having a specific installation cost. A specific subset of **t** facilities are designated as critical. Your objective is to ensure that all critical facilities are fully interconnected. They are considered interconnected if secure data can be transmitted between any two critical facilities, possibly by routing through other linked facilities. The facilities that are not critical can be used as intermediate routing points if linking them provides a more cost-effective overall network, or they can be left unlinked.

Determine the minimum total installation cost for a set of conduits that successfully interconnects all critical facilities.

## Input

The first line contains three integers **n**, **m**, and **t**. The number of critical facilities is strictly limited by the security protocol (1 ≤ t ≤ 10), the total number of facilities is bounded by the city district size (1 ≤ n ≤ 100), and the number of potential conduits ranges from none to all possible pairs (0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers representing the identifiers of the critical facilities.
Each of the following **m** lines contains three integers **u**, **v**, and **w**, representing a potential conduit between distinct facilities (1 ≤ u, v ≤ n, u ≠ v) with a positive installation cost bounded by the budget limit (1 ≤ w ≤ 1000000).
It is guaranteed that the available potential conduits are sufficient to interconnect all critical facilities.

## Output

Output a single integer representing the minimum total cost to interconnect all critical facilities.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, routing data through the non-critical facility 4 (which costs 1+1+1 = 3) is more cost-effective than linking the three critical facilities directly (which would cost 4). In Example 3, there is only one critical facility, so no conduits need to be installed.
