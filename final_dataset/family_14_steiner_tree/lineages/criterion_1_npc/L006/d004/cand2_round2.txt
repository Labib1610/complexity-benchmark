<METHOD_NAME>Equivalence Relation Synthesis</METHOD_NAME>
<METHOD_DESCRIPTION>Recasts the graph connectivity problem as selecting symmetric binary axioms to generate an equivalence relation that unifies a specific subset of elements. This completely removes graph terminology (nodes, edges, pools, merging) and replaces it with algebraic structure, defeating models that rely on explicit graph wording to recognize the Steiner Tree problem and trigger subset DP templates.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Axiomatic Synthesis

Time limit: 5 s   Memory limit: 256 MB

## Description

A formal system operates over a domain of $n$ distinct elements (identified by integers 1 through $n$). A specific subset of $t$ elements, denoted as the critical set $C$, must be mathematically unified.

Initially, no two distinct elements are equivalent. However, you have access to a library of $m$ candidate axioms. Each axiom asserts a symmetric equivalence between two elements, $u$ and $v$. 

When you select a set of axioms, they generate an equivalence relation over the domain. Specifically, two elements are considered equivalent if their equivalence can be deduced from the selected axioms using the standard properties of equivalence relations (reflexivity, symmetry, and transitivity). 

You may select axioms that involve elements outside the critical set $C$, as long as their inclusion helps establish the required equivalences among the critical elements.

Each candidate axiom has an associated conceptual complexity, denoted by $w$. The total complexity of your chosen system is the sum of the conceptual complexities of the distinct axioms you select for inclusion.

Determine the minimum total complexity required to select a combination of axioms such that all $t$ elements in the critical set $C$ are equivalent to one another under the generated equivalence relation.

## Input

The first line provides three integers $n$, $m$, and $t$ (1 ≤ $t$ ≤ 10, 1 ≤ $n$ ≤ 100, 0 ≤ $m$ ≤ $n$·($n$−1)/2).
The second line lists $t$ distinct integers representing the identifiers of the elements in the critical set $C$.
Each of the subsequent $m$ lines specifies a candidate axiom using three integers $u$, $v$, and $w$ (1 ≤ $u$, $v$ ≤ $n$, $u$ ≠ $v$, 1 ≤ $w$ ≤ 1000000). This indicates an axiom asserting the equivalence of element $u$ and element $v$ with a conceptual complexity of $w$.
It is guaranteed that the available axioms are sufficient to make all elements of $C$ equivalent.

## Output

Print a single integer: the minimum total complexity required to ensure all elements in the critical set $C$ are equivalent to one another.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the axioms that involve the non-critical element 4 (which require complexities of 1, 1, and 1; total complexity = 3) is more efficient than selecting the axioms directly between the three critical elements (which would result in a total complexity of 4). 
In Example 3, there is only a single critical element, so the requirement is already satisfied. No axioms need to be selected, resulting in a total complexity of 0.
</STATEMENT>
<RATIONALE>
The problem was translated from a graph/network connectivity scenario into an algebraic one (generating an equivalence relation via axioms). This forces the model to recognize that deducing equivalence via symmetry and transitivity is isomorphic to finding connected components in a graph, and that minimizing the sum of weights to connect a specific subset is the Steiner Tree problem, without relying on standard graph keywords.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical structure is identical: elements are nodes, axioms are edges with weights, and equivalence is path connectivity; thus the minimum cost to unify the critical set is exactly the minimum Steiner Tree cost.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the exact same instance of the NP-complete Steiner Tree problem on graphs, just described using the language of binary relations and equivalence classes.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "deduced from the selected axioms" as allowing multiple identical axioms to somehow stack or reduce cost, but the phrase "sum of the conceptual complexities of the distinct axioms you select" unambiguously defines the cost function as the sum of weights of the chosen subset.
</RISK>
