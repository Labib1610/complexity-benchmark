<STATEMENT>
# Problem A — Axiomatic Equivalence

Time limit: 5 s   Memory limit: 256 MB

## Description

You are tasked with defining an equivalence relation $\equiv$ on a universal set of integers $E = \{1, 2, \dots, n\}$. 

Initially, the relation is strictly the identity: for any $x, y \in E$, $x \equiv y$ if and only if $x = y$. 

You are given a subset $C \subseteq E$ consisting of $t$ specific critical integers. 

You can expand the equivalence relation by adopting *axioms* from a provided catalog of size $m$. Each axiom in the catalog is specified as a pair $(u, v)$ with an associated validation cost $w$. Adopting this axiom explicitly enforces the rule that $u \equiv v$. 

Because $\equiv$ must remain a mathematically valid equivalence relation, adopting any axiom automatically implies the reflexive, symmetric, and transitive closures over all adopted axioms. For instance, if you adopt axioms that enforce $A \equiv B$ and $B \equiv C$, the relation $A \equiv C$ implicitly becomes true without requiring an additional axiom.

You may choose to adopt any combination of the available axioms. The total validation cost incurred is the sum of the $w$ values of the distinct axioms you adopt. 

Your objective is to ensure that for every pair of integers $a, b \in C$, the relation $a \equiv b$ holds true. You are permitted to adopt axioms involving elements outside of $C$ if they help achieve this goal more efficiently.

Determine the minimum total validation cost required to select and adopt a combination of axioms such that all $t$ elements in the subset $C$ belong to the same equivalence class. 

The size of the universal set $n$ is at least one and bounded by the number of years in a century. The number of critical integers $t$ is at least one and at most the base of the decimal numeral system. The number of available axioms $m$ can be zero and will not exceed the number of unique two-element subsets of $E$. The cost $w$ of any single axiom is strictly positive and at most the cube of one hundred. Elements are indexed from 1 to $n$, and any axiom relates two distinct elements.

## Input

The first line contains three integers $n$, $m$, and $t$.
The second line contains $t$ distinct integers representing the elements of the subset $C$.
Each of the subsequent $m$ lines specifies a cataloged axiom using three integers $u$, $v$, and $w$, indicating that an axiom enforcing $u \equiv v$ is available for a validation cost of $w$. 
It is guaranteed that it is always possible to make all elements in $C$ equivalent using some combination of the available axioms.

## Output

Print a single integer: the minimum total validation cost required to ensure all elements in $C$ are equivalent.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, adopting the axioms that relate to the non-critical element 4 (which incur costs of 1, 1, and 1; total cost = 3) is more cost-effective than adopting the axioms directly between the three critical elements (which would incur a total cost of 4). 
In Example 3, there is only a single critical element, so it is trivially equivalent to itself. No axioms need to be adopted, resulting in a total cost of 0.
</STATEMENT>
<RATIONALE>
The problem was completely reframed from merging "liquidity pools" to constructing an "equivalence relation" using "axioms". This requires the model to independently deduce that adopting pairs to form an equivalence class is mathematically identical to selecting edges to form a connected component. Furthermore, the critical bounds (especially $t \le 10$, which triggers the Steiner Tree subset DP template) were removed from the Input section and replaced with indirect textual bounds (e.g., "base of the decimal numeral system").
</RATIONALE>
<PRESERVED_ANSWER>
The answers remain completely unchanged because substituting the cost of edges to connect a subset of nodes in a graph is mathematically identical to summing the cost of axioms to place a subset of elements in the same equivalence class.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class is unchanged as the problem remains exactly the minimum weight Steiner Tree problem on a graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might struggle to correctly parse the indirect bounds (like "cube of one hundred" for $10^6$), but the wording is strictly unambiguous and relies only on universally known constants.
</RISK>
