<METHOD_NAME>Vector Space Span Isomorphism</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces graph connectivity with the mathematically equivalent condition of expressing differences of basis vectors as linear combinations of selected difference vectors. This breaks graph-based pattern matching (Steiner Tree, shortest paths) while preserving the exact combinatorial structure.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Subspace Generator Selection

Time limit: 5 s   Memory limit: 256 MB

## Description

A computational system operates on an $n$-dimensional vector space. The space is spanned by $n$ standard basis vectors, denoted as $e_1, e_2, \dots, e_n$.

The system has a set of $t$ mandatory dimensions.

You are provided with $m$ available difference vectors. Each available difference vector is defined by a pair of distinct indices $u$ and $v$, and takes the form $e_u - e_v$. Each available vector has an associated one-time selection cost $w$. Each unordered pair of indices $\{u, v\}$ corresponds to at most one available vector.

You may select any subset of these available vectors. If a vector is selected, its cost $w$ is added to your total cost exactly once.

Your objective is to select a subset of the available vectors such that for every pair of mandatory dimensions $x$ and $y$, the target vector $e_x - e_y$ can be expressed as a linear combination of the selected vectors. 

You are allowed to select difference vectors that involve non-mandatory dimensions, provided their inclusion helps satisfy the requirement for the mandatory dimensions. The total cost is the sum of the selection costs of the distinct vectors you choose to select.

Determine the minimum total cost required to select a subset of vectors that fulfills this condition.

## Input

The first line provides three integers $n$, $m$, and $t$ (1 ≤ $t$ ≤ 10, 1 ≤ $n$ ≤ 100, 0 ≤ $m$ ≤ $n$·($n$−1)/2).
The second line lists $t$ distinct integers representing the indices of the mandatory dimensions.
Each of the subsequent $m$ lines specifies an available difference vector using three integers $u$, $v$, and $w$ (1 ≤ $u$, $v$ ≤ $n$, $u$ ≠ $v$, 1 ≤ $w$ ≤ 1000000). This indicates that the vector $e_u - e_v$ is available for selection with a cost of $w$.
It is guaranteed that each unordered pair $\{u, v\}$ appears at most once in the input.
It is guaranteed that the set of all $m$ available vectors is sufficient to satisfy the requirement for all pairs of mandatory dimensions.

## Output

Print a single integer: the minimum total cost required to ensure that for every pair of mandatory dimensions $x$ and $y$, the vector $e_x - e_y$ is a linear combination of the selected subset.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the vectors $e_1 - e_4$, $e_2 - e_4$, and $e_3 - e_4$ (which have costs of 1, 1, and 1; total cost = 3) is more efficient than selecting the vectors directly involving only the three mandatory dimensions (which would result in a total cost of 4). By selecting $e_1 - e_4$ and $e_2 - e_4$, the vector $e_1 - e_2$ can be expressed as $(e_1 - e_4) - (e_2 - e_4)$. Including $e_3 - e_4$ ensures that $e_1 - e_3$ and $e_2 - e_3$ can also be expressed as linear combinations. Thus, the dimension 4 acts as an effective intermediate. 
In Example 3, there is only a single mandatory dimension. The requirement is that for every pair of mandatory dimensions $x$ and $y$, $e_x - e_y$ can be expressed. Since there is only one mandatory dimension, the only pair is $x=1, y=1$, and $e_1 - e_1$ is the zero vector, which requires no vectors to be selected. Therefore, the minimum cost is 0.
</STATEMENT>
<RATIONALE>
I replaced the graph connectivity framing with a mathematically equivalent linear algebra formulation: expressing differences of basis vectors as linear combinations of selected difference vectors. This breaks structural pattern matching for Steiner Tree and shortest-path DP, forcing models to recognize that spanning a difference vector is isomorphic to connecting two components in a graph.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that $e_x - e_y$ is in the linear span of a subset of difference vectors $e_u - e_v$ is absolutely equivalent to $x$ and $y$ belonging to the same connected component in the graph formed by those pairs, leaving the optimization problem and all answers unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Steiner Tree problem on a graph, which is NP-complete, disguised through the column space of the incidence matrix.
</PRESERVED_CLASS>
<RISK>
Models might mistakenly assume the coefficients for the linear combination imply fractional costs or that partial vectors can be bought, though the prompt explicitly states "If a vector is selected, its cost $w$ is added to your total cost exactly once", which clearly defines a discrete subset selection.
</RISK>
