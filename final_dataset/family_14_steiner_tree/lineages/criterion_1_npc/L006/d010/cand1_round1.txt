<STATEMENT>
# Matrix Configuration

Time limit: 5 s   Memory limit: 256 MB

## Description

You are configuring an $n \times n$ matrix $M$. Initially, $M$ is the $n \times n$ identity matrix (ones on the main diagonal, zeros elsewhere).

There is a menu of $m$ available modifications. Each modification is specified by a pair of distinct row and column indices $(u, v)$ and an associated cost $w$. If you choose to purchase a modification, you add $1$ to both $M_{u,v}$ and $M_{v,u}$. Each modification may be purchased at most once.

You may purchase any combination of modifications. The total cost is the sum of the costs of the purchased modifications.

Let $A$ be the final matrix after all purchased modifications have been applied. We define the matrix $B = A^n$, which is the matrix $A$ raised to the $n$-th power using standard matrix multiplication.

You are given a specific set of $t$ target indices. Your objective is to select a set of modifications such that in the resulting matrix $B$, the entry $B_{x,y}$ is strictly greater than $0$ for every pair of target indices $x$ and $y$ (including when $x = y$).

Determine the minimum total cost required to purchase a set of modifications that satisfies this condition.

## Input

The first line provides three integers $n$, $m$, and $t$ (1 ≤ $t$ ≤ 10, 1 ≤ $n$ ≤ 100, 0 ≤ $m$ ≤ $n$·($n$−1)/2).
The second line lists $t$ distinct integers representing the target indices.
Each of the subsequent $m$ lines specifies an available modification using three integers $u$, $v$, and $w$ (1 ≤ $u$, $v$ ≤ $n$, $u$ ≠ $v$, 1 ≤ $w$ ≤ 1000000). This indicates a modification that adds $1$ to both $M_{u,v}$ and $M_{v,u}$, with a cost of $w$.
It is guaranteed that purchasing all $m$ available modifications is sufficient to satisfy the condition for the target indices.

## Output

Print a single integer: the minimum total cost required to ensure $B_{x,y} > 0$ for all pairs of target indices $x$ and $y$.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, purchasing the modifications for (1, 4), (2, 4), and (3, 4) costs 1 + 1 + 1 = 3. 
The resulting matrix $A$ has $A_{1,1}=A_{2,2}=A_{3,3}=A_{4,4}=1$, and $A_{1,4}=A_{4,1}=A_{2,4}=A_{4,2}=A_{3,4}=A_{4,3}=1$, with all other entries being 0.
When computing $B = A^4$, the entries $B_{1,2}$, $B_{1,3}$, and $B_{2,3}$ (as well as $B_{1,1}$, $B_{2,2}$, $B_{3,3}$, etc.) are all strictly positive. Since the target indices are 1, 2, and 3, the condition $B_{x,y} > 0$ is satisfied for all pairs of these indices. This configuration is cheaper than purchasing the modifications directly between the target indices (which would cost 4).

In Example 3, there is only a single target index (1). The condition requires $B_{1,1} > 0$. If no modifications are purchased, $A$ remains the identity matrix. The 3rd power of the identity matrix is still the identity matrix, meaning $B_{1,1} = 1 > 0$. The condition is inherently satisfied without purchasing any modifications, resulting in a total cost of 0.
