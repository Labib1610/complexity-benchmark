State-Invariance Functional Framing
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the explicit "equality/system of equations" and implicit graph connectivity with a functional property over arbitrary assignments. The requirement that terminals belong to the same connected component is reformulated as a requirement that in any assignment where connected endpoints share the same state, all terminals must also share the same state. This obscures the graph structure and Steiner Tree objective, preventing models from mapping the problem to shortest paths or tree DP. Combined with S07 (Indirect Bounds) to hide the small terminal count.
</METHOD_DESCRIPTION>

yes

<STATEMENT>
# Stability Enforcement Optimization

Time limit: 5 s   Memory limit: 256 MB

## Description

A regulatory agency is analyzing a system of $n$ interacting entities, numbered 1 through $n$. Within this system, a specific subset of $t$ entities are designated as "critical".

The agency's goal is to enforce a systemic property regarding how states can be assigned to these entities. Consider any hypothetical assignment of integer states to the $n$ entities. An assignment is defined as "stable" under a given set of active regulations if, for every active regulation connecting two entities, those two entities are assigned the exact same state.

The agency requires that in *every* possible stable assignment, all $t$ critical entities are mathematically forced to have the exact same state as one another. 

To achieve this, the agency can activate any number of regulations from a provided list of $m$ available regulations. Each available regulation applies to a specific pair of entities $u$ and $v$. If activated, it requires that $u$ and $v$ share the same state in any stable assignment. Activating a regulation incurs a one-time implementation cost $w$. 

Regulations involving non-critical entities may be activated, and they are often necessary to indirectly constrain the critical entities. 

Determine the minimum total implementation cost required to activate a set of regulations such that the stability condition is met.

The agency's monitoring equipment imposes strict capacity limits. The number of critical entities $t$ is limited such that the number of possible distinct subsets of critical entities is at most 1,024. The total entity capacity $n$ cannot exceed the square of the maximum possible critical entity count. The number of proposed regulations $m$ is at most the total number of distinct pairs that can be formed from the $n$ entities.

## Input

The first line provides three integers $n$, $m$, and $t$. The values are strictly bounded by the system capacities described above (with $t \ge 1$, $n \ge 1$, and $m \ge 0$).
The second line lists $t$ distinct integers representing the indices of the critical entities.
Each of the subsequent $m$ lines specifies an available regulation using three integers $u$, $v$, and $w$ (1 ≤ $u, v$ ≤ $n$, $u \neq v$, 1 ≤ $w$ ≤ 1,000,000). This indicates a regulation between entities $u$ and $v$ with a one-time activation cost of $w$.
It is guaranteed that activating all $m$ available regulations is sufficient to satisfy the agency's requirement.

## Output

Print a single integer: the minimum total implementation cost required to ensure all critical entities are forced to share the same state in every stable assignment.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, activating the regulations that involve the non-critical entity 4 (which require costs of 1, 1, and 1; total cost = 3) is more efficient than activating regulations directly between the three critical entities (total cost = 4). The regulations between (1, 4) and (2, 4) ensure that in any stable assignment, entities 1, 2, and 4 must share the same state. Adding the regulation between (3, 4) forces entity 3 to share this state as well. Thus, entity 4 acts as an effective intermediary. 
In Example 3, there is only a single critical entity. The requirement that "all critical entities share the same state" is inherently satisfied for a set of one, so no regulations need to be activated, resulting in a total cost of 0.

<RATIONALE>
I completely removed the "system of equations" framing and replaced it with a functional property over arbitrary state assignments, hiding the inherent Steiner Tree connectivity requirement behind logic that defines connected components without naming them. Additionally, I applied strategy S07 to express the crucial parameter bounds indirectly (e.g., $2^t \le 1024 \implies t \le 10$), forcing models to proactively deduce the small terminal count necessary to trigger subset dynamic programming.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that all critical entities share the same state in every stable assignment is mathematically identical to requiring that all critical entities belong to the same connected component of activated regulations, maintaining the exact same optimization objective and minimum costs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the Minimum-Weight Steiner Tree problem on a graph, which is NP-complete, as the functional stability condition simplifies exactly to standard graph connectivity among the target terminals.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the phrasing "in every possible stable assignment" as requiring them to compute, simulate, or count assignments, rather than recognizing it as a rigorous definition of structural connectivity.
</RISK>
