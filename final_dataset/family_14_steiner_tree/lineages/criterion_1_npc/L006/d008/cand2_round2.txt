<STATEMENT>
# Basis Subspace Synthesis

Time limit: 5 s   Memory limit: 256 MB

## Description

A research team is designing a symmetric linear operator $M$, represented as an $n \times n$ matrix. Initially, $M$ is the $n \times n$ zero matrix. 

The team is focused on a specific subset of $t$ critical dimensions, given by their indices. 
Their objective is to ensure that for any two critical indices $i$ and $j$, the difference vector $e_i - e_j$ is in the column space of $M$. Here, $e_k$ denotes the $k$-th standard basis vector of $\mathbb{R}^n$ (a column vector with a 1 in the $k$-th position and 0s elsewhere).

To construct $M$, the team can select from $m$ available matrix additions. Each available addition is defined by a pair of distinct indices $u$ and $v$. If selected, it allows the team to add the symmetric matrix $(e_u - e_v)(e_u - e_v)^T$ to $M$. 

The team may select any subset of the $m$ available additions. Each addition can be selected at most once. The final matrix $M$ is the sum of $(e_u - e_v)(e_u - e_v)^T$ over all selected additions. Additions involving non-critical indices may be selected if they help expand the column space of $M$ to satisfy the requirement for the critical indices.

Each available addition has a fixed cost, $w$. The total cost is the sum of the costs of the chosen additions.

Determine the minimum total cost required to select a set of additions such that for every pair of critical indices $i$ and $j$, the vector $e_i - e_j$ is in the column space of the resulting matrix $M$.

## Input

The first line provides three integers $n$, $m$, and $t$ (1 ≤ $t$ ≤ 10, 1 ≤ $n$ ≤ 100, 0 ≤ $m$ ≤ $n$·($n$−1)/2).
The second line lists $t$ distinct integers representing the critical indices.
Each of the subsequent $m$ lines specifies an available matrix addition using three integers $u$, $v$, and $w$ (1 ≤ $u$, $v$ ≤ $n$, $u$ ≠ $v$, 1 ≤ $w$ ≤ 1000000). This indicates an available addition defined by indices $u$ and $v$ with a selection cost of $w$.
It is guaranteed that selecting all $m$ available additions is sufficient to satisfy the column space requirement for all critical indices.

## Output

Print a single integer: the minimum total cost required to select a set of additions such that the resulting matrix $M$ satisfies the column space requirement.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the additions involving the non-critical index 4 (which require costs of 1, 1, and 1; total cost = 3) is more efficient than selecting the additions directly involving only the three critical indices (which would result in a total cost of 4). The additions $(e_1 - e_4)(e_1 - e_4)^T$ and $(e_2 - e_4)(e_2 - e_4)^T$ expand the column space of $M$ such that $e_1 - e_2$ is in the column space. Including $(e_3 - e_4)(e_3 - e_4)^T$ further expands it so that $e_1 - e_3$ and $e_2 - e_3$ are also in the column space, satisfying the requirement for critical indices 1, 2, and 3. Thus, index 4 acts as an effective intermediary. 
In Example 3, there is only a single critical index. The requirement that $e_i - e_j$ is in the column space for any two critical indices is vacuously satisfied, so no additions need to be selected, resulting in a total cost of 0.
</STATEMENT>
<RATIONALE>
The problem has been reframed from enforcing equality constraints to synthesizing a linear operator whose column space contains specific difference vectors. Mathematically, the sum of the symmetric outer products `(e_u - e_v)(e_u - e_v)^T` forms the Laplacian matrix of the graph defined by the chosen additions. A vector `e_i - e_j` is in the column space of a graph Laplacian if and only if vertices `i` and `j` are in the same connected component. This requires the model to independently recognize the isomorphism between this linear algebra condition and graph connectivity, completely bypassing any standard Steiner Tree keywords or graph terminology.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that `e_i - e_j` is in the column space of the sum of the chosen outer products is mathematically identical to requiring that nodes `i` and `j` are connected in the graph formed by the chosen edges, meaning the minimum cost to satisfy this for all critical indices is exactly the cost of the Minimum Steiner Tree.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Steiner Tree problem on an undirected graph, preserving its NP-complete complexity class.
</PRESERVED_CLASS>
<RISK>
Models or humans might struggle to prove the equivalence between the column space of the Laplacian and graph connectivity, but the mathematical statement is perfectly unambiguous and standard in algebraic graph theory.
</RISK>
