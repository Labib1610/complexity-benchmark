<METHOD_DESCRIPTION>Replaces the graph connectivity and measurement concepts with the algebraic linear span of algebraic differences between symbolic states. This frames the task as a basis selection problem in a vector space, which typically suggests matroid or continuous linear algebra approaches. Because the linear span of incidence vectors exactly matches graph connectivity, the problem remains identical, but models relying on recognizing graph properties will fail to map it to a Steiner tree.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Relative Observability

Time limit: 5 s   Memory limit: 256 MB

## Description

A formal verification tool is analyzing a system of $n$ symbolic states, indexed 1 through $n$. The tool must prove the equivalence of relative offsets between all pairs of states in a critical subset of $t$ core states.

The engine can evaluate a set of $m$ available transition rules. Evaluating a rule between state $u$ and state $v$ yields the exact algebraic difference $S_u - S_v$ (which inherently provides $S_v - S_u$). These differences are linearly composable: if $S_A - S_B$ and $S_B - S_C$ are evaluated, their sum yields $S_A - S_C$.

The tool may evaluate rules involving non-core states, as long as the linear span of the evaluated differences includes the differences between all pairs of core states.

Each rule has an evaluation complexity $w$. The total complexity is the sum of the complexities of the distinct rules evaluated.

Determine the minimum total evaluation complexity required to select a subset of rules such that the differences between all $t$ core states are within their linear span.

## Input

The first line provides three integers $n$, $m$, and $t$ (1 ≤ $t$ ≤ 10, 1 ≤ $n$ ≤ 100, 0 ≤ $m$ ≤ $n$·($n$−1)/2).
The second line lists $t$ distinct integers representing the indices of the core states.
Each of the subsequent $m$ lines specifies an available transition rule using three integers $u$, $v$, and $w$ (1 ≤ $u$, $v$ ≤ $n$, $u$ ≠ $v$, 1 ≤ $w$ ≤ 1000000). This indicates a rule between state $u$ and state $v$ with an evaluation complexity of $w$.
It is guaranteed that the available rules are sufficient so that all pairwise differences among the core states can be spanned.

## Output

Print a single integer: the minimum total evaluation complexity required to ensure all pairwise differences between the core states are in the linear span of the selected rules.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, evaluating the rules that involve the non-core state 4 (complexities of 1, 1, and 1; total = 3) is more optimal than evaluating the rules directly between the three core states (which would cost 4). State 4 acts as an intermediate operand in the linear combination. 
In Example 3, there is only a single core state, so there are no pairwise differences that need to be evaluated. The zero vector is in the span of the empty set. No rules need to be evaluated, resulting in a total complexity of 0.

<RATIONALE>
The problem was rewritten to use the language of linear algebra and symbolic states rather than graph connectivity. By describing the objective as ensuring that target differences are within the "linear span" of selected rules, the prompt obscures the fact that this is a Steiner tree problem, forcing the model to deduce that algebraic linear span of differences is equivalent to graph connectivity.
</RATIONALE>
<PRESERVED_ANSWER>
The linear span of a set of difference vectors $S_u - S_v$ contains $S_x - S_y$ if and only if $x$ and $y$ are in the same connected component of the graph formed by the selected edges, meaning the exact same subsets of rules are valid and have the same costs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is still asking for the minimum weight subgraph that connects a specific subset of vertices, which is the NP-complete Steiner Tree problem.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "linear span" as allowing fractional edges or continuous optimization, though mathematically the incidence matrix column space exactly matches discrete connectivity, so the optimal answer remains identical.
</RISK>
