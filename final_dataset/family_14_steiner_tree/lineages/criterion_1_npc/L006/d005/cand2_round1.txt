<METHOD_NAME>Incidence Matrix Subspace Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the graph connectivity requirement (Steiner tree) with a linear algebra subspace spanning requirement. Instead of finding a minimum cost subgraph to connect target vertices, it asks for a minimum cost subset of difference vectors $v_u - v_v$ such that all target differences $v_a - v_b$ are in their linear span. Because the difference vectors form the incidence matrix of the graph, linear span is mathematically identical to graph connectivity. This defeats models by making the problem look like a matroid or matrix optimization task, obscuring the graph structure and preventing the retrieval of the Dreyfus-Wagner Steiner tree algorithm.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Core Vector Span

Time limit: 5 s   Memory limit: 256 MB

## Description

A quantitative analysis team is evaluating a vector space spanned by $n$ linearly independent abstract basis vectors, denoted $v_1, v_2, \dots, v_n$. 

The team is particularly focused on a subset of $t$ core vectors. To analyze the relationships between these core vectors, the team must be able to express the difference $v_a - v_b$ for every pair of core vectors $a, b$ as a linear combination of a selected set of "difference vectors".

Initially, they have no difference vectors. However, they can purchase access to $m$ available difference vectors. Each available difference vector is of the form $v_u - v_v$ for some $u$ and $v$. Purchasing the difference vector $v_u - v_v$ incurs a specific acquisition cost $w$. Because linear combinations allow scalar multiplication by $-1$, purchasing $v_u - v_v$ inherently also provides $v_v - v_u$ at no additional cost.

The team may purchase difference vectors involving non-core vectors, provided they are useful in forming the required linear combinations. The total cost incurred by the team is the sum of the acquisition costs of the distinct difference vectors they choose to purchase. 

Determine the minimum total acquisition cost required to select a subset of the available difference vectors such that for every pair of core vectors $v_a$ and $v_b$, the target vector $v_a - v_b$ is in the linear span of the selected subset.

## Input

The first line provides three integers $n$, $m$, and $t$.
- $t$: The number of core vectors. It is at least 1, and strictly capped at the number of decimal digits (10) due to the dashboard's display grid.
- $n$: The total number of basis vectors. It is at least 1, and cannot exceed the square of the maximum possible number of core vectors.
- $m$: The number of available difference vectors. It is non-negative and bounded by the number of unique unordered pairs of the $n$ basis vectors.

The second line lists $t$ distinct integers representing the 1-based indices of the core vectors.
Each of the subsequent $m$ lines specifies an available difference vector using three integers $u$, $v$, and $w$. This indicates that the vector $v_u - v_v$ can be purchased for an acquisition cost of $w$. It is guaranteed that $u \neq v$. The cost $w$ is a positive integer bounded by one million.
It is guaranteed that purchasing all $m$ available vectors would successfully span all required differences among the core vectors.

## Output

Print a single integer: the minimum total acquisition cost required to select a subset of difference vectors such that all pairwise differences between the core vectors are in their linear span.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, purchasing the difference vectors that involve the non-core vector 4 (which require costs of 1, 1, and 1; total cost = 3) is more efficient than purchasing the difference vectors directly between the three core vectors (which would result in a total cost of 4). The basis vector $v_4$ acts as an intermediate component in the linear combinations. 
In Example 3, there is only a single core vector, so there are no strictly non-zero differences that need to be spanned (the difference between the core vector and itself is the zero vector, which is trivially in the span of the empty set). No difference vectors need to be purchased, resulting in a total cost of 0.
</STATEMENT>
<RATIONALE>
The problem has been completely reframed from deducing scalar differences to finding a minimum-cost subset of vectors that span a target subspace. By using the incidence matrix equivalence (where a set of difference vectors spans a target difference if and only if the corresponding vertices are in the same connected component), the graph structure is mathematically preserved but semantically hidden. The numeric bounds have also been replaced with indirect physical or mathematical limits, forcing the model to actively parse the text rather than matching integer patterns to known complexity bounds.
</RATIONALE>
<PRESERVED_ANSWER>
The linear span of a set of difference vectors $v_u - v_v$ includes a target difference $v_a - v_b$ if and only if $a$ and $b$ are in the same connected component of the graph formed by the purchased vectors; thus, minimizing the cost to span all core differences is mathematically identical to finding the minimum weight Steiner tree connecting the core vertices.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Weight Steiner Tree problem on a graph, which is NP-complete, requiring the same Dreyfus-Wagner dynamic programming approach for optimal solution.
</PRESERVED_CLASS>
<RISK>
Models might incorrectly assume that fractional combinations of vectors could bypass the connectivity requirement, though mathematically the incidence matrix properties guarantee this is impossible; this is a failure of the model's mathematical reasoning, not an ambiguity in the statement.
</RISK>
