# Problem A — Legacy Compatibility

Time limit: 5 s   Memory limit: 256 MB

## Description

A digital ecosystem consists of **n** distinct data formats (numbered 1 to **n**). There are **m** available translation modules. A translation module allows direct, two-way conversion between format **u** and format **v**, and requires a licensing fee **w** to activate.

A user holds documents in a specific subset of **t** target formats. The user needs to ensure universal compatibility among these target formats.

Universal compatibility is achieved if data in any target format can be converted into any other target format, possibly by passing through a chain of activated translation modules. The user is allowed to activate modules involving non-target formats if they are used as intermediate steps in a conversion chain.

The total financial overhead of the chosen set of modules is simply the sum of the licensing fees of all activated modules.

Determine the minimum total financial overhead required to activate a set of translation modules that provides universal compatibility among all target formats.

## Input

The first line contains three integers **n**, **m**, and **t**.
By system design, the total number of formats **n** is at least 1 and is capped at a maximum of exactly 100.
The module count **m** ranges from a minimum of 0 up to the maximum possible number of unique pairs among the **n** formats (which mathematically evaluates to **n**·(**n**−1)/2).
The target count **t** requires at least 1 format and is limited by a dashboard capacity of exactly 10 slots.
The second line contains **t** distinct integers: the identifiers of the target formats.
Each of the next **m** lines contains three integers **u**, **v**, and **w**, describing a translation module. The identifiers **u** and **v** are distinct valid formats (between 1 and **n**). The licensing fee **w** is at least 1 and cannot exceed a gateway limit of exactly 1000000.
It is guaranteed that the provided modules are sufficient to achieve universal compatibility.

## Output

Print a single integer: the minimum total financial overhead to achieve universal compatibility among all target formats.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, activating the translation modules that pass through the non-target format 4 (fees 1, 1, 1; sum = 3) is cheaper than activating modules between the three target formats directly (which would have a sum of 4). In Example 3, there is only one target format, so no modules need to be activated (sum = 0).
