<METHOD_NAME>
Linear Algebra Orthogonality Frame
</METHOD_NAME>
<METHOD_DESCRIPTION>
Transforms the equality/connectivity requirement into an algebraic condition about the orthogonal complement of selected basis-difference vectors. By framing it as a property of all vectors y orthogonal to S, models must infer that this algebraic constraint is isomorphic to graph connectivity, breaking surface pattern matching to Steiner Tree.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<STATEMENT>
# Problem A — Subspace Orthogonality Minimization

Time limit: 5 s   Memory limit: 256 MB

## Description

Consider the vector space $\mathbb{R}^n$. Let $e_k$ denote the $k$-th standard basis vector. You are given a target subset of **t** coordinate indices.

You have access to a pool of **m** candidate vectors. The $i$-th candidate vector is of the form $e_u - e_v$ and has an associated selection cost $w$.

You may select any combination of candidate vectors. Let $S$ be your selected set of vectors. Your goal is to find a set $S$ with the minimum possible total selection cost such that the following condition holds:

For every vector $y \in \mathbb{R}^n$, if $y$ is orthogonal to all vectors in $S$ (that is, the dot product $y \cdot v = 0$ for all $v \in S$), then $y$ must have identical components at all indices in the target subset. In other words, any such $y$ must satisfy $y_a = y_b$ for all $a, b$ in the target subset.

Determine the minimum total selection cost of a valid set $S$.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the target coordinate indices.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), representing a candidate vector $e_u - e_v$ with selection cost $w$.
The pool of candidate vectors is sufficient to achieve the condition.

## Output

Print a single integer: the minimum total selection cost of a valid set $S$.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the candidate vectors $e_1 - e_4$, $e_2 - e_4$, and $e_3 - e_4$ costs 1+1+1 = 3. Any vector $y \in \mathbb{R}^4$ orthogonal to these three vectors must satisfy $y_1 = y_4$, $y_2 = y_4$, and $y_3 = y_4$. This guarantees $y_1 = y_2 = y_3$, satisfying the requirement for the target coordinates 1, 2, and 3. This is cheaper than selecting vectors directly between the target coordinates. 

In Example 3, there is only one target coordinate. The requirement places no additional restrictions, so choosing no vectors is optimal (cost 0).
</STATEMENT>
<RATIONALE>
The problem was reframed from equality constraints to linear algebra (orthogonal complements of basis-difference vectors). This forces the model to deduce that $y \cdot (e_u - e_v) = 0$ implies $y_u = y_v$, and that requiring this to enforce $y_a = y_b$ for all targets is mathematically identical to finding a connected subgraph containing the targets. All banned phrasing like "trivially" was removed.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $y \cdot (e_u - e_v) = 0$ is strictly equivalent to $y_u = y_v$, so finding a minimum-cost set of vectors to enforce target equality is exactly the same as finding a minimum-cost set of equality constraints.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains Minimum Steiner Tree on graphs, as the algebraic requirement maps 1:1 to graph connectivity among a subset of terminals, meaning it is still NP-complete.
</PRESERVED_CLASS>
