# Problem A — Equality Constraint Minimization

Time limit: 5 s   Memory limit: 256 MB

## Description

You are configuring a system of **n** data registers, numbered 1 to $n$. You are given a designated subset of **t** priority registers.

You can select from **m** available bidirectional synchronization links. The $i$-th link, if selected, continuously enforces that register $u$ and register $v$ hold the same value, and requires an implementation cost of $w$.

A global assignment of values to all **n** registers is considered valid if, for every selected link, its two corresponding registers hold the same value. 

Determine the minimum total implementation cost to select a subset of links such that, in every valid global assignment, all **t** priority registers are guaranteed to hold the exact same value. 

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the indices of the priority registers.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), representing an available synchronization link between register $u$ and register $v$ at an implementation cost of $w$.
The available links are sufficient to ensure all priority registers hold the exact same value.

## Output

Print a single integer: the minimum total implementation cost to ensure all priority registers hold the same value.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the synchronization links between registers (1, 4), (2, 4), and (3, 4) requires a total cost of 1 + 1 + 1 = 3. Under these selected links, any valid global assignment must assign the same value to registers 1, 2, 3, and 4, which fulfills the requirement for the priority registers 1, 2, and 3. 

In Example 3, there is only one priority register. No links need to be selected, resulting in a minimum cost of 0.

<RATIONALE>
Removed explicit explanations of equality transitivity and the explicit hint that non-target variables can be used as cheaper intermediates. The problem now relies purely on the formal property of a valid assignment, forcing the model to independently deduce that this condition is mathematically equivalent to finding a minimum-weight connected subgraph spanning the priority nodes (Steiner tree).
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical condition—that the target nodes must be forced to take the same value—is identical to the seed, meaning the exact same subset of links satisfies the condition for the exact same cost.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains Minimum Steiner Tree on a graph, which is NP-complete, because the only way to guarantee the priority registers share a value in every valid assignment is to form a connected component containing all of them.
</PRESERVED_CLASS>
