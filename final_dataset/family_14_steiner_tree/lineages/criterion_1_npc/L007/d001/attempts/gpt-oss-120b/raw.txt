**Solution Explanation**

For the given undirected weighted graph we have to buy a set of edges whose total
price is minimal, while all *t* *priority* vertices become mutually reachable.
The bought edges may contain also vertices that are **not** priority – they can
be used as intermediate relays.

The problem is exactly the **Steiner Tree** problem for a terminal set of size  
`t ≤ 10`.  
For such a small terminal set the classic DP over subsets solves it fast enough.

--------------------------------------------------------------------

#### 1.   DP definition  

```
dp[mask][v] = minimal price of a sub‑graph
               that connects all terminals whose bits are set in mask
               and that contains vertex v
```

`mask` is a bitmask of length `t` ( `0 … (1<<t)-1` ), `v` is a vertex
`0 … n-1`.  
The answer will be `min_v dp[ALL][v]` where `ALL = (1<<t)-1`.

--------------------------------------------------------------------

#### 2.   Initialisation  

For every terminal `i` (its vertex number is `term[i]`)

```
dp[ 1<<i ][ term[i] ] = 0          # nothing has to be bought to reach itself
all other entries = INF
```

--------------------------------------------------------------------

#### 3.   Subset merging  

If a mask can be split into two non‑empty disjoint parts `p` and `q`,
the optimal tree for `mask` can be obtained by joining optimal trees for
`p` and `q` **in the same vertex** `v`.

```
dp[mask][v] = min( dp[p][v] + dp[q][v] )   over all proper sub‑masks p of mask
```

The loop over the sub‑masks is `O(3^t)` ( `t ≤ 10` → far below one million).

--------------------------------------------------------------------

#### 4.   Propagation through edges – Dijkstra  

After the merging step `dp[mask][v]` is the cheapest cost of a tree that
*already* ends in `v`.  
From this tree we can extend to any neighbour `to` by buying the edge
`(v,to,w)`.  
Consequently the values have to be relaxed along the graph – exactly a
single‑source shortest path problem with many sources (all vertices with a
finite current value).

We run a normal Dijkstra where the initial distance of each vertex `v` is
`dp[mask][v]`.  
After the Dijkstra finishes, `dp[mask][v]` equals the cheapest possible price
of a Steiner tree for `mask` that contains `v`.

Complexities per mask: `O( m log n )`.  
Number of masks: `2^t ≤ 1024`. With `n ≤ 100` this easily fits into the limits.

--------------------------------------------------------------------

#### 5.   Whole algorithm  

```
for mask = 1 … ALL:
        # 1) combine smaller masks
        for every proper submask p of mask (p < mask):
                q = mask ^ p
                for every vertex v:
                        dp[mask][v] = min(dp[mask][v],
                                          dp[p][v] + dp[q][v])

        # 2) run multi‑source Dijkstra
        run Dijkstra with initial distances dp[mask][*]
        (updates are written back into dp[mask][*])
answer = min_v dp[ALL][v]
```

The DP of a mask uses only results of *strictly smaller* masks, therefore the
order `mask = 1 … ALL` is correct.

--------------------------------------------------------------------

#### 6.   Correctness Proof  

We prove that the algorithm outputs the minimal possible total price.

---

##### Lemma 1  
For any mask and any vertex `v`, after the Dijkstra of that mask finishes,
`dp[mask][v]` equals the minimum price of a Steiner tree for `mask` that
*contains* vertex `v`.

**Proof.**  
Before Dijkstra, `dp[mask][v]` is the cheapest price of a tree for `mask`
that already contains `v` (by induction on the processing order of masks,
see Lemma&nbsp;2).  
Running Dijkstra with these values as initial distances repeatedly applies
the relaxation  

```
price(tree ∪ {edge (v,to)}) = price(tree) + w
```

which is exactly the operation of extending a tree by one edge.
Dijkstra computes the cheapest possible total price to reach each vertex,
hence after termination the stored value is the cheapest price of *any*
tree for `mask` that contains `v`. ∎



##### Lemma 2  
Assume that for every proper sub‑mask `p` of `mask` and every vertex `v`
the invariant of Lemma&nbsp;1 already holds.
After the *subset merging* step (before Dijkstra) we have

```
dp[mask][v] = min over all partitions (p,q) of mask
              ( cheapest price of a tree for p containing v )
            + ( cheapest price of a tree for q containing v )
```

**Proof.**  
The merging step enumerates every non‑empty proper sub‑mask `p`;
`q = mask \ p` is the complementary part.
For each vertex `v` we try `dp[p][v] + dp[q][v]` and keep the smallest
value.  
By the induction hypothesis `dp[p][v]` (resp. `dp[q][v]`) already equals the
cheapest price of a tree for `p` (resp. `q`) containing `v`.  
Thus the minimum taken is exactly the expression stated. ∎



##### Lemma 3  
After both steps (merging **and** Dijkstra) for a mask, `dp[mask][v]`
is the cheapest price of a Steiner tree for `mask` that contains `v`.

**Proof.**  
Consider an optimal Steiner tree `T` for `mask` that contains `v`.  
If `T` uses at least two edges incident to `v`, remove `v` and split `T`
into two sub‑trees `T₁, T₂` whose terminal sets are a partition `(p,q)` of
`mask`. Both sub‑trees still contain `v`.  
Their prices are at least `dp[p][v]` and `dp[q][v]` (Lemma&nbsp;1 for
smaller masks). Hence `price(T) ≥ dp[p][v] + dp[q][v]`.
Taking the minimum over all partitions gives a lower bound that is exactly
the value after the merging step (Lemma&nbsp;2).

If `T` does **not** split at `v` (i.e. all edges of `T` lie on a single path
from `v` outward), then `T` can be obtained from a tree for some proper
sub‑mask `p` (the terminals already connected inside `T` except maybe some
still missing) by extending along edges.  
Running Dijkstra from the values obtained after merging therefore reaches
the price of `T` (Lemma&nbsp;1).  

Consequently the Dijkstra cannot produce a value larger than the optimum,
and because it only relaxes by adding edges, it cannot become smaller.
Thus after Dijkstra the stored value equals the optimum. ∎



##### Lemma 4  
For every mask the algorithm finishes with correct `dp[mask][*]`.

**Proof.** By induction over the number of bits in `mask`.

*Base* – masks with a single bit (`|mask| = 1`).  
The only terminal vertex `s` has `dp[mask][s]=0`, all other vertices are
∞. Running Dijkstra computes the shortest path distances from `s`,
exactly the cheapest tree containing any vertex – Lemma&nbsp;1 holds.

*Induction step* – assume correctness for all proper sub‑masks.
When processing `mask` the algorithm first merges (Lemma&nbsp;2) using
already correct values, then runs Dijkstra.  
Lemma&nbsp;3 shows that after Dijkstra the values are correct. ∎



##### Lemma 5  
`answer = min_v dp[ALL][v]` equals the minimum total price of a set of edges
that connects all priority vertices.

**Proof.**  
`dp[ALL][v]` is the cheapest price of a Steiner tree that contains *all*
terminals and also vertex `v` (Lemma&nbsp;4).  
Any feasible solution is a Steiner tree for `ALL`; it contains some vertex
`v` (any vertex of the tree). Its price is therefore at least
`dp[ALL][v]`. Taking the minimum over `v` gives a lower bound on any feasible
solution.

Conversely, a tree that realises `dp[ALL][v*]` for the minimizing vertex `v*`
is a feasible solution of exactly that price. Hence the minimum equals the
optimum. ∎



##### Theorem  
The algorithm outputs the minimum possible total price required to make all
priority locations mutually reachable.

**Proof.** Directly from Lemma&nbsp;5. ∎



--------------------------------------------------------------------

#### 7.   Complexity Analysis  

```
Number of masks          : 2^t  ≤ 1024
Merging step per mask    : O( n * 2^{|mask|} )   → total O( 3^t * n ) ≤ 6·10^4
Dijkstra per mask        : O( m log n )
Total Dijkstra work      : 2^t * m log n ≤ 1024 * 4950 * log 100  < 5·10^6
Memory used              : (2^t) * n  ≤ 1024 * 100  = 1.0·10^5  integers
```

Both time (**< 5 seconds**) and memory (**≈ 1 MB**) satisfy the limits easily.

--------------------------------------------------------------------

#### 8.   Reference Implementation  (Python 3)

```python
import sys
import heapq

INF = 10 ** 18

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    n = next(it)
    m = next(it)
    t = next(it)

    terminals = [next(it) - 1 for _ in range(t)]          # 0‑based
    graph = [[] for _ in range(n)]
    for _ in range(m):
        u = next(it) - 1
        v = next(it) - 1
        w = next(it)
        graph[u].append((v, w))
        graph[v].append((u, w))

    full = (1 << t) - 1
    dp = [[INF] * n for _ in range(full + 1)]

    # initial masks – single terminals
    for i, node in enumerate(terminals):
        dp[1 << i][node] = 0

    # process all masks
    for mask in range(1, full + 1):
        # ----- subset merging -----
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            # to avoid doing both (sub,other) and (other,sub) we enforce sub < other
            if sub < other:
                dps = dp[sub]
                dpo = dp[other]
                dpm = dp[mask]
                for v in range(n):
                    val = dps[v] + dpo[v]
                    if val < dpm[v]:
                        dpm[v] = val
            sub = (sub - 1) & mask

        # ----- multi‑source Dijkstra -----
        dist = dp[mask]
        heap = [(dist[v], v) for v in range(n) if dist[v] < INF]
        heapq.heapify(heap)

        while heap:
            d, u = heapq.heappop(heap)
            if d != dist[u]:
                continue
            for v, w in graph[u]:
                nd = d + w
                if nd < dist[v]:
                    dist[v] = nd
                    heapq.heappush(heap, (nd, v))

    ans = min(dp[full])
    print(ans)


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input / output format.
