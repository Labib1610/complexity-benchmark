<STATEMENT>
# Subspace Generation Price

Time limit: 5 s   Memory limit: 256 MB

## Description

You are working in an $n$-dimensional vector space over the real numbers, with the standard basis vectors denoted as $e_1, e_2, \dots, e_n$. 

You are given a set of $t$ critical dimensions, identified by their indices. Your goal is to span a specific target subspace. This target subspace is defined as the linear span of all vectors of the form $e_x - e_y$, where both $x$ and $y$ are among the $t$ critical dimensions.

To build your subspace, you can purchase vectors from a provided catalog of $m$ options. The $i$-th catalog option provides the vector $e_{u} - e_{v}$ (which intrinsically also provides $e_{v} - e_{u}$ via scalar multiplication) and costs a specified price $w$. 

You may select any subset of the $m$ catalog vectors. The vectors you purchase will collectively generate a linear span. Your objective is to choose a subset of catalog vectors such that their linear span completely contains the target subspace. 

Determine the minimum total price (the sum of the prices of the purchased vectors) required to achieve this.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the indices of the critical dimensions.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), representing a catalog option that provides the vector $e_u - e_v$ for a price of $w$.
The provided catalog of vectors is guaranteed to be sufficient to span the target subspace if all options are purchased.

## Output

Print a single integer: the minimum total price of a subset of vectors whose span contains the target subspace.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the critical dimensions are 1, 2, and 3, meaning the target subspace is the span of $\{e_1 - e_2, e_2 - e_3, e_1 - e_3\}$. By purchasing the vectors $e_1 - e_4$, $e_2 - e_4$, and $e_3 - e_4$ at a price of 1+1+1 = 3, their span contains the target subspace. For instance, $(e_1 - e_4) - (e_2 - e_4) = e_1 - e_2$. This incurs a lower price than purchasing the vectors $e_1 - e_2$ and $e_2 - e_3$ directly.
In Example 3, there is only one critical dimension, so the target subspace is merely the zero vector. No vectors need to be purchased, resulting in a minimum price of 0.

<RATIONALE>
The problem was completely reframed using a mathematically isomorphic linear algebra domain. Because the incidence matrix of a graph defines a cycle space, spanning $e_x - e_y$ using basis-difference vectors $e_u - e_v$ is mathematically identical to connecting nodes $x$ and $y$ in a graph. This forces models to genuinely reason about the properties of the linear span to discover the underlying Steiner Tree structure, defeating models that rely on graph-theoretic pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The linear span of a set of vectors $e_u - e_v$ contains $e_x - e_y$ if and only if $x$ and $y$ are in the same connected component of the graph formed by the edges $(u, v)$, ensuring the exact same subsets are valid and optimal.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the Minimum Weight Steiner Tree problem on an undirected graph, which is NP-complete, as the linear algebra framing is a strict isomorphism of the graph connectivity requirement.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the target subspace as requiring a full basis of the entire $n$-dimensional space, though the text explicitly defines the target subspace as only the span of $e_x - e_y$ for the critical dimensions.
</RISK>
