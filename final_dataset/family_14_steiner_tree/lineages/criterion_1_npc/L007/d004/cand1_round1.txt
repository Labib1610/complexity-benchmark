<STATEMENT>
# Problem A — Automated Theorem Prover

Time limit: 5 s   Memory limit: 256 MB

## Description

A formal verification system tracks **n** distinct variables, denoted $X_1$ to $X_n$. You are assigned a proof obligation: you must formally deduce that a specific group of **t** target variables all share the exact same value.

To build this proof, you can query an axiom database containing **m** specific pairwise equations. Each equation asserts that $X_u = X_v$, and querying it consumes **w** units of processing power.

Because equality is an equivalence relation, the system automatically applies the transitive property. If your queried equations establish a chain of equalities between any two variables, the system successfully infers they are equal. You are permitted to query equations involving non-target variables if they serve as useful intermediate steps to complete the proof more efficiently.

Determine the minimum total processing power required to query a set of equations that rigorously proves all **t** target variables are equal to each other.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the subscripts of the target variables.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): an available equation $X_u = X_v$ that consumes **w** units of power to query.
The database contains enough equations to satisfy the proof obligation.

## Output

Print a single integer: the minimum total processing power required to prove all target variables are equal.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, querying the equations $X_1 = X_4$, $X_2 = X_4$, and $X_3 = X_4$ (power 1+1+1 = 3) proves all four variables are equal. This is more efficient than querying the equations between the three target variables directly (which would consume 4 units). In Example 3, there is only one target variable, so the proof obligation is trivially satisfied without querying any equations.

<RATIONALE>
The problem was completely re-contextualized from a physical network routing problem into a formal logic and abstract algebra problem. Vertices became variables, edges became equations, and connectivity was replaced by the transitive property of equality. This forces the model to independently recognize that establishing an equivalence class among a subset of variables using pairwise relations is structurally identical to the Steiner Tree problem, bypassing superficial pattern matching on words like "bridge", "access point", or "network".
</RATIONALE>
