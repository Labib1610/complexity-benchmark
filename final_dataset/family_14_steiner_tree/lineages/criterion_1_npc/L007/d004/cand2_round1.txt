<STATEMENT>
# Problem A — Constraint Activation

Time limit: 5 s   Memory limit: 256 MB

## Description

You are configuring a system of **n** integer variables, $x_1, x_2, \ldots, x_n$.

There are **m** optional equality constraints available. Each constraint enforces that two specific variables must be equal ($x_u = x_v$) and comes with a known activation cost **w**.

You may activate any subset of these constraints. Your goal is to ensure that a specific subset of **t** target variables are strictly guaranteed to hold the exact same value. Formally, you must choose a subset of constraints such that every valid integer assignment to $x_1, \ldots, x_n$ that satisfies your chosen constraints also satisfies $x_{c_1} = x_{c_2} = \ldots = x_{c_t}$ (where $c_1, \ldots, c_t$ are the indices of the target variables).

You can include constraints involving non-target variables if they help logically deduce the required equality at a lower total cost.

Determine the minimum total activation cost of the constraints that must be chosen to guarantee the target variables are all equal.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the indices of the target variables.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), representing an available constraint $x_u = x_v$ with an activation cost of **w**.
It is guaranteed that activating all **m** constraints is sufficient to satisfy the condition for the target variables.

## Output

Print a single integer: the minimum total activation cost.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, activating the constraints $x_1 = x_4$, $x_2 = x_4$, and $x_3 = x_4$ (total cost 1+1+1 = 3) ensures that for any valid assignment, $x_1$, $x_2$, and $x_3$ must equal $x_4$, and therefore must equal each other. This is cheaper than activating constraints directly between the target variables (e.g., $x_1 = x_2$ and $x_2 = x_3$, which would cost 2+2 = 4). In Example 3, there is only one target variable, so the condition $x_1 = x_1$ is trivially guaranteed without activating any constraints.
</STATEMENT>
<RATIONALE>
The problem was completely reframed from network synchronization (which strongly implies graph connectivity) to a system of logical implications over equality constraints. This forces the model to independently deduce that "guaranteeing variables take the same value across all valid assignments" is mathematically equivalent to finding a minimum-weight connected subgraph (Steiner Tree) among those variables.
</RATIONALE>
<PRESERVED_ANSWER>
The logical implication that a subset of variables must be equal holds if and only if those variables are in the same connected component in the graph of activated equality constraints, making the minimum cost mathematically identical to the minimum Steiner Tree cost.
</PRESERVED_ANSWER>

The problem still asks for the minimum cost subset of edges required to mutually connect a specific subset of vertices, preserving its NP-complete Steiner Tree classification.
</PRESERVED_CLASS>
