# Problem A — Automated Equality Prover

Time limit: 5 s   Memory limit: 256 MB

## Description

An automated theorem prover is analyzing a system with **n** integer variables (numbered 1 to n). You are given a set of **t** target variables. The prover must establish that all **t** target variables are equal to one another.

To do this, the prover can query a database of known equalities. There are **m** available equalities, each asserting that a specific pair of variables are equal. However, querying an equality consumes a certain amount of computational resources, known as its query cost.

The prover's deduction engine applies transitivity automatically: if it queries equations that establish equality between a chain of variables, it deduces that all variables in that chain are equal. You are allowed to query equations involving auxiliary (non-target) variables if routing the logical deductions through them reduces the overall query cost.

Determine the minimum total query cost required to prove that all target variables share the same value.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the ids of the target variables.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): an available equality stating variable u equals variable v, with a query cost of w.
The available equalities are sufficient to prove that all target variables are equal.

## Output

Print a single integer: the minimum total query cost to ensure all target variables are proven equal.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, querying the equalities between variable 4 and each of 1, 2, and 3 (costs 1+1+1 = 3) is sufficient to prove the three target variables are equal, which is cheaper than querying the equalities between the three target variables directly (which would cost 4). In Example 3 there is only one target variable, so the proof obligation is already satisfied without querying any equations.
