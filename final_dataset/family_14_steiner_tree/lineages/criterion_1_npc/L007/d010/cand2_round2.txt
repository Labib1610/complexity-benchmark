<METHOD_NAME>Continuous Metric Framing</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces discrete equivalence relations and transpositions with the continuous concept of a pseudo-metric space. Forcing distances to 0 under the triangle inequality is mathematically identical to finding connected components, but the continuous terminology (non-negative reals, triangle inequality) obscures the discrete Steiner Tree structure from LLMs relying on pattern matching.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Pseudo-Metric Forcing

Time limit: 5 s   Memory limit: 256 MB

## Description

You are studying the properties of a pseudo-metric function $d(x, y)$ defined over a space of **n** points, numbered 1 through **n**.
A pseudo-metric assigns a non-negative real distance between any two points and must satisfy $d(x, x) = 0$, symmetry ($d(x, y) = d(y, x)$), and the triangle inequality ($d(x, z) \le d(x, y) + d(y, z)$ for all $x, y, z$). Unlike a standard metric, a pseudo-metric allows $d(x, y) = 0$ even when $x \neq y$.

There are **m** available constraints you can enforce. The $i$-th constraint applies to points **u** and **v** and costs **w** to enforce.
If you enforce this constraint, you require that the pseudo-metric satisfies $d(u, v) = 0$.

You are given a collection of **t** priority points.
Your goal is to select a subset of the available constraints to enforce such that, as a logical consequence of your chosen constraints and the foundational rules of a pseudo-metric, the distance between any two priority points is strictly forced to be 0. (That is, no valid pseudo-metric could satisfy your chosen constraints while assigning a strictly positive distance between any two priority points).

Determine the minimum total cost required to enforce a subset of constraints that achieves this guarantee.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ **t** ≤ 10, 1 ≤ **n** ≤ 100, 0 ≤ **m** ≤ **n**·(**n**−1)/2).
The second line contains **t** distinct integers: the priority points.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000): an available constraint applying to points **u** and **v**, and its cost **w**.
The provided set of available constraints is always sufficient to satisfy the required condition.

## Output

Print a single integer: the minimum total cost required to enforce a subset of constraints that achieves the condition.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 3, with only one priority point, the distance from that point to itself is already 0 by definition, so choosing no constraints satisfies the condition vacuously with a total cost of 0.
</STATEMENT>
<RATIONALE>
The problem was reframed from invariant functions under transpositions to enforcing zero-distances in a pseudo-metric space. Because a pseudo-metric requires the triangle inequality and symmetry, enforcing $d(u, v) = 0$ is mathematically identical to placing $u$ and $v$ in the same equivalence class (or connected component). This forces the model to realize that continuous distance constraints under a pseudo-metric map exactly to discrete graph connectivity, removing the obvious structural hints of the seed.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the distance between all priority points is forced to 0 holds if and only if they are in the same connected component of the chosen zero-distance constraints, which is exactly the same mathematical requirement as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Steiner Tree problem on a graph where points are vertices and constraints are edges, keeping it in NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the continuous framing as requiring a shortest-path continuous optimization (like Floyd-Warshall or linear programming) rather than recognizing the discrete Steiner Tree subset-DP structure, though the problem statement is mathematically unambiguous.
</RISK>
