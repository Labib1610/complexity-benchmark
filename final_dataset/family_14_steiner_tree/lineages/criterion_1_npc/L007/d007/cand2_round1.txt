# Equilibrium Displacement Alignment

Time limit: 5 s   Memory limit: 256 MB

## Description

You are engineering a mechanical framework consisting of **n** nodes. The total number of nodes **n** is at most the number of years in a century. The framework's equilibrium states are governed by its stiffness matrix $L$, which is initially an $n \times n$ matrix entirely filled with zeros.

You have a set of **m** available spring connections that can be installed between nodes. The number of available connections **m** does not exceed the maximum possible number of unique node pairs. 
Installing the $i$-th available connection between node **u** and node **v** modifies the stiffness matrix $L$ by subtracting 1 from the entries $L_{u,v}$ and $L_{v,u}$, and adding 1 to the entries $L_{u,u}$ and $L_{v,v}$. Applying this connection incurs a financial cost of **w**, which is a positive integer bounded by the number of millimeters in a kilometer. Because the modifications are additive, installing multiple connections accumulates their effects on the matrix $L$.

A state of the framework is defined by a displacement vector $\mathbf{x} \in \mathbb{R}^n$. A state is considered a *zero-force equilibrium* if it satisfies the equation $L\mathbf{x} = \mathbf{0}$ (i.e., $\mathbf{x}$ is in the nullspace of $L$).

You are given a specific set of **t** priority nodes. This set contains at least one node, and its size is at most the total number of single-digit non-negative integers. 
Your goal is to select a subset of connections to install such that in EVERY zero-force equilibrium state of the resulting framework, the displacements of all **t** priority nodes are strictly identical to each other. In other words, you must ensure that for any vector $\mathbf{x}$ satisfying $L\mathbf{x} = \mathbf{0}$, it is guaranteed that $x_{c_1} = x_{c_2} = \dots = x_{c_t}$.

Determine the minimum total financial cost incurred by selecting a subset of connections that achieves this strict displacement requirement. The provided set of available connections is guaranteed to be sufficient to achieve this.

## Input

The first line contains three integers **n**, **m**, and **t**.
The second line contains **t** distinct integers: the indices of the priority nodes.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (u ≠ v): an available connection between node $u$ and node $v$, and its financial cost $w$.

## Output

Print a single integer: the minimum total financial cost to ensure the displacement requirement is met for the priority nodes.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, installing the connections involving node 4 (between 1 and 4, 2 and 4, 3 and 4 at a cost of 1+1+1 = 3) modifies the stiffness matrix $L$ such that any zero-force equilibrium state $\mathbf{x}$ satisfying $L\mathbf{x} = \mathbf{0}$ must have $x_1 = x_2 = x_3 = x_4$. Consequently, the displacements of the priority nodes (1, 2, and 3) will always be identical ($x_1 = x_2 = x_3$). This incurs a lower cost than installing the connections directly between the priority nodes.

In Example 3, there is only one priority node. The condition that all priority nodes share the same displacement is vacuously true for any displacement vector. Thus, no connections need to be installed, and the minimum cost is 0.
