<METHOD_NAME>Linear Algebra Isomorphism</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the graph connectivity requirement (Steiner tree) with its exact linear algebraic equivalent: selecting a set of difference vectors e_u - e_v such that their linear span contains the difference vectors e_a - e_b for all target pairs. This transforms the surface appearance from a network/clustering task into a vector space basis problem, disabling pattern-matching to graph algorithms while preserving identical mathematical structure.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Vector Span Penalty

Time limit: 5 s   Memory limit: 256 MB

## Description

You are working in the $n$-dimensional real vector space $\mathbb{R}^n$. Let $e_1, e_2, \dots, e_n$ denote the standard basis vectors of this space, corresponding to indices $1$ through $n$.

You are given a set of $m$ available difference vectors. The $i$-th available vector is defined as $e_u - e_v$ for some given indices $u$ and $v$. Selecting this vector to be part of your working set incurs a fixed penalty of $w$.

You are also given a list of $t$ target indices. Your goal is to select a subset of the available difference vectors such that, for every pair of target indices $a$ and $b$ from the list, the difference vector $e_a - e_b$ is contained within the linear span of the selected subset. 

Determine the minimum total penalty incurred by selecting a subset of vectors that achieves this spanning requirement.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers between 1 and **n**: the target indices.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): representing an available vector $e_u - e_v$ and its penalty $w$. Each available vector listed may be selected at most once.
The provided set of available vectors is sufficient to satisfy the spanning requirement.

## Output

Print a single integer: the minimum total penalty to achieve the spanning requirement.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the vectors $e_1 - e_4$, $e_2 - e_4$, and $e_3 - e_4$ incurs a total penalty of 1 + 1 + 1 = 3.
The required difference vector for targets 1 and 2 is $e_1 - e_2$. This is in the linear span of the selected subset because $e_1 - e_2 = (e_1 - e_4) - (e_2 - e_4)$.
Similarly, for targets 2 and 3, $e_2 - e_3 = (e_2 - e_4) - (e_3 - e_4)$, and for targets 1 and 3, $e_1 - e_3 = (e_1 - e_4) - (e_3 - e_4)$.
Thus, all pairs of target indices (1, 2, and 3) have their difference vectors in the span of the selected subset. This achieves the requirement with a lower penalty than selecting the vectors directly between the targets.

In Example 3, there is only one target index. There are no distinct pairs of target indices, so the spanning requirement is trivially fulfilled by selecting an empty set of vectors. The minimum penalty is 0.
</STATEMENT>
<RATIONALE>
The problem is mathematically isomorphic to the Steiner Tree problem, as the vector $e_a - e_b$ is in the linear span of a set of edge-difference vectors if and only if nodes $a$ and $b$ are in the same connected component. By framing the connectivity requirement strictly in terms of linear algebra and vector spans, we disable surface-level heuristics that trigger graph DP algorithms, forcing the model to independently deduce that this basis-selection task is structurally a subset-merging graph problem.
</RATIONALE>
<PRESERVED_ANSWER>
The linear span of difference vectors $e_u - e_v$ contains $e_a - e_b$ if and only if $a$ and $b$ are connected in the graph formed by the selected edges, meaning the exact same subsets are valid and optimal.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains NP-complete as it is an exact isomorphism of the Steiner Tree problem on graphs.
</PRESERVED_CLASS>
