<STATEMENT>
# Analytic Indifference

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing the structural properties of real-valued functions $f(x_1, \dots, x_n)$ defined over $n$ arguments.

You have a catalog of **m** possible coordinate transpositions. The $i$-th transposition swaps the arguments at positions **u** and **v**. Activating this transposition incurs a penalty of **w**.

A function $f$ is considered *indifferent* to a transposition of arguments at positions **u** and **v** if the output of the function remains identical when the values at these two positions are exchanged, for all possible inputs.

You are given a priority collection of **t** argument positions. Your objective is to activate a subset of the available transpositions to guarantee the following property:
Every real-valued function $f$ that is indifferent to **all** of your activated transpositions must analytically also be indifferent to a transposition of arguments at positions $a$ and $b$, for every pair of distinct positions $a, b$ within your priority collection.

Calculate the minimum total penalty required to activate a valid subset of transpositions.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the priority argument positions.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): an available transposition between the arguments at positions **u** and **v**, and its penalty **w**.
The provided set of available transpositions is sufficient to achieve the required guarantee.

## Output

Print a single integer: the minimum total penalty required to activate a valid subset of transpositions.

## Examples

### Example 1

**Input**
```

1 2 3

1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

**Output**

### Example 3

```

```


<RATIONALE>
I removed the "Note" section from the examples, which explicitly explained how enabling swaps through an intermediate non-target index achieves the goal at a lower cost. This removes the direct hint that non-target variables can act as Steiner nodes. I also rephrased the invariance condition using words like "indifferent" and "transposition" to force the model to deduce the equivalence relation (and thus the connectivity requirement) from first principles rather than recognizing the exact phrasing of a known problem.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical condition for a function to be indifferent to all target pairs given a set of active transpositions remains exactly the requirement that all target variables are in the same connected component of transpositions, keeping all optimal costs identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Finding the minimum-cost set of edges to connect a specific subset of vertices in a weighted graph is the Steiner Tree problem, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might find the phrase "analytically also be indifferent" slightly unusual, but its meaning ("logically implied for all such functions") is mathematically unambiguous in context.
</RISK>
