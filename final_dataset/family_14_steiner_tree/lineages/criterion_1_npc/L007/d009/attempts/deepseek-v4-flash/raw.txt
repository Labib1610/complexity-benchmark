 We can model the problem as a graph problem.  
The available transpositions are edges with weights.  
We need to ensure that for every pair of priority coordinates, they are in the same connected component after selecting edges.  
This is because if two priority coordinates are connected via transpositions, then any function indifferent to all activated transpositions must be indifferent to swapping those two coordinates (by composing transpositions along the path).  

Thus, the problem reduces to:  
Given a graph with weighted edges, find the minimum total weight to connect all priority vertices into one component.  
This is exactly the **Steiner tree** problem on a small set of terminals (t ≤ 10).  

We can solve it using **DP over subsets** of terminals, with Floyd-Warshall for all-pairs shortest paths first.  

Here’s the implementation:  

```python
import sys
input = sys.stdin.readline

n, m, t = map(int, input().split())
priority = list(map(int, input().split()))
priority = [x-1 for x in priority]

INF = 10**18
dist = [[INF]*n for _ in range(n)]
for i in range(n):
    dist[i][i] = 0

for _ in range(m):
    u, v, w = map(int, input().split())
    u -= 1
    v -= 1
    if w < dist[u][v]:
        dist[u][v] = w
        dist[v][u] = w

# Floyd-Warshall
for k in range(n):
    dk = dist[k]
    for i in range(n):
        dik = dist[i][k]
        if dik == INF:
            continue
        di = dist[i]
        for j in range(n):
            nd = dik + dk[j]
            if nd < di[j]:
                di[j] = nd

# DP over subsets of terminals
# dp[mask][i] = min cost to connect terminals in mask, ending at node i
full_mask = 1 << t
dp = [[INF]*n for _ in range(full_mask)]

for i in range(t):
    dp[1<<i][priority[i]] = 0

for mask in range(full_mask):
    # combine two submasks
    sub = (mask-1) & mask
    while sub:
        other = mask ^ sub
        if sub < other:  # avoid duplicate work
            for i in range(n):
                if dp[sub][i] < INF:
                    for j in range(n):
                        if dp[other][j] < INF:
                            nd = dp[sub][i] + dp[other][j] + dist[i][j]
                            if nd < dp[mask][i]:
                                dp[mask][i] = nd
        sub = (sub-1) & mask
    # relax via shortest paths
    for i in range(n):
        if dp[mask][i] < INF:
            for j in range(n):
                nd = dp[mask][i] + dist[i][j]
                if nd < dp[mask][j]:
                    dp[mask][j] = nd

ans = min(dp[full_mask-1][i] for i in range(n))
print(ans)
```
