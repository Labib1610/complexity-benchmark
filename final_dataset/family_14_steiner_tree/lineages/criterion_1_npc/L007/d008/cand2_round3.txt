<STATEMENT>
# Constraint Subspace

Time limit: 5 s   Memory limit: 256 MB

## Description

You are configuring an algebraic solver for a system of formal variables, $x_1, \dots, x_n$. 

You can select a subset of difference expressions from a provided catalog. The catalog contains $m$ available expressions. The $i$-th available expression is of the form $x_u - x_v$, and adding it to your selected subset requires an allocation of $w$ compute credits.

When you select a subset of these expressions, the solver generates a linear subspace consisting of all possible linear combinations (using real coefficients) of your selected expressions.

You are given a specific set of $t$ target variables. Your objective is to select a subset of the available difference expressions such that for any two variables $x_a$ and $x_b$ in the target set, their difference $x_a - x_b$ is contained within the generated linear subspace.

Determine the minimum total compute credits required to select a subset of expressions that satisfies this condition.

## Input

The first line contains three integers $n$, $m$, and $t$ (The number of target variables $t$ is at least 1 and at most the number of fast registers, which is 10; the total variables $n$ is at most the square of the maximum possible $t$; $m$ is between 0 and the number of unique unordered pairs of $n$ variables).
The second line contains $t$ distinct integers: the indices of the target variables.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$. This represents an available difference expression $x_u - x_v$ (where $1 \le u, v \le n$ and $u \ne v$) that requires $w$ compute credits (where $w$ is a positive integer up to one million).
The provided catalog of expressions is sufficient to satisfy the condition for the target variables.

## Output

Print a single integer: the minimum total compute credits required to ensure that all differences between target variables are in the generated linear subspace.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the expressions involving variable 4 (that is, $x_1 - x_4$, $x_2 - x_4$, and $x_3 - x_4$, for a total of $1 + 1 + 1 = 3$ credits) allows the solver to form any difference between the target variables 1, 2, and 3 via linear combinations of the selected expressions. This requires fewer credits than selecting expressions directly among the target variables.

In Example 3, there is only 1 target variable. The condition that any two target variables have their difference in the subspace is vacuously true, so no expressions need to be selected. The minimum cost is 0.
