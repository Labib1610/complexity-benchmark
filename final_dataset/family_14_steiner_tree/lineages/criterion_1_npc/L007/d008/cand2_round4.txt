<METHOD_DESCRIPTION>
Reframes the Steiner tree problem as selecting a minimum-cost subset of linear equations of the form x_u - x_v = 0. The goal is to restrict the solution space enough to force a target subset of variables to take the same value. This obscures the graph-theoretic nature of the problem, forcing models to independently deduce the equivalence between algebraic connectivity and graph components.
</METHOD_DESCRIPTION>

<STATEMENT>
# Equivalent Variables

Time limit: 5 s   Memory limit: 256 MB

## Description

You are designing a system of linear equations over $n$ variables, $x_1, x_2, \dots, x_n$.

You can include equations from a set of $m$ candidate equations. The $i$-th candidate equation is of the form $x_u - x_v = 0$. Including this equation in your system requires a computational cost of $w$. 

When a subset of these equations is included, the solution space consists of all assignments to $x_1, \dots, x_n$ that satisfy all the included equations simultaneously.

You have a set of $t$ target variables. Your objective is to include a subset of the candidate equations such that, for every solution in the resulting solution space, the $t$ target variables must all equal each other.

Determine the minimum total computational cost required to include a subset of equations that achieves this objective.

## Input

The first line contains three integers $n$, $m$, and $t$ (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains $t$ distinct integers: the indices of the target variables (each between 1 and $n$).
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): a candidate equation $x_u - x_v = 0$, and its computational cost $w$.
The provided set of candidate equations is sufficient to guarantee the target variables equal each other.

## Output

Print a single integer: the minimum total computational cost required to guarantee that the target variables take the exact same value in every solution.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, including the equations involving variable 4 ($x_1 - x_4 = 0$, $x_2 - x_4 = 0$, and $x_3 - x_4 = 0$ at a cost of 1 + 1 + 1 = 3) restricts the solution space such that $x_1 = x_2 = x_3 = x_4$. Consequently, any solution will have the target variables ($x_1, x_2$, and $x_3$) taking identical values. This incurs a lower cost than including equations directly relating the target variables.

In Example 3, there is only one target variable. A single variable always equals itself, so no equations need to be included. The minimum cost is therefore 0.
</STATEMENT>
<RATIONALE>
The problem was reframed from graph connectivity (or voting pacts) into an algebraic constraint system where variables must be forced to equal each other through selected equations. This forces the model to realize that a system of $x_u - x_v = 0$ equations partitions variables into equivalence classes (connected components), mapping the algebraic goal back to a Steiner Tree problem on a graph. The explicit numeric bounds from the seed were fully restored exactly as requested.
</RATIONALE>
<PRESERVED_ANSWER>
The answers are identical because forcing a set of variables to be equal in all valid assignments of $x_u = x_v$ constraints requires exactly the same minimum-weight connecting edges (Steiner Tree) as the original voting pact formulation.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class remains NP-complete, as the problem is a direct mathematical isomorphism of the Steiner Tree problem on graphs.
</PRESERVED_CLASS>
