<STATEMENT>
# Transposition Invariants

Time limit: 5 s   Memory limit: 256 MB

## Description

Let $X = \{x_1, x_2, \dots, x_n\}$ be a set of $n$ formal variables. We consider the ring of polynomials with real coefficients, $\mathbb{R}[x_1, \dots, x_n]$.

You are given $m$ available variable transpositions. The $i$-th available transposition, if selected, exchanges the variables $x_u$ and $x_v$. Selecting this transposition incurs a weight of $w$.

A polynomial $P \in \mathbb{R}[x_1, \dots, x_n]$ is said to be *invariant* under a transposition $\tau$ if applying $\tau$ to the variables does not change the polynomial. That is, $P(x_1, \dots, x_n) = P(\tau(x_1, \dots, x_n))$. 
For a chosen subset of transpositions $S$, let $\text{Inv}(S)$ denote the set of all polynomials that are invariant under every transposition in $S$.

You are given a target subset $T \subseteq \{1, 2, \dots, n\}$ consisting of $t$ variable indices.
Your objective is to choose a subset of the available transpositions $S$ such that for EVERY polynomial $P \in \text{Inv}(S)$, $P$ is also invariant under the transposition that exchanges $x_a$ and $x_b$, for all pairs of indices $a, b \in T$.

Determine the minimum total weight of a subset $S$ that satisfies this algebraic condition.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the indices in the target subset $T$.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): an available transposition between $x_u$ and $x_v$, and its weight **w**.
The provided set of available transpositions is sufficient to satisfy the condition.

## Output

Print a single integer: the minimum total weight of a chosen subset $S$ that achieves the invariant guarantee.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the transpositions involving variable 4 (between 1 and 4, 2 and 4, and 3 and 4, with a total weight of 1 + 1 + 1 = 3) ensures that any polynomial invariant under these three transpositions must be symmetric with respect to the variables $x_1, x_2, x_3, x_4$. Consequently, any such polynomial is inherently invariant under the transposition of any two variables in the target subset $\{1, 2, 3\}$. This incurs a lower weight than selecting transpositions directly among the target indices.

In Example 3, there is only one target index. The condition holds vacuously for any polynomial (exchanging a variable with itself changes nothing), so the empty set of transpositions can be selected, incurring a weight of 0.
</STATEMENT>
<RATIONALE>
The problem was completely reframed using Invariant Theory and formal polynomials. The models previously relied on the surface-level "identical voting outcomes" directly matching the "connected component" concept. By shifting to polynomial invariants, the model is forced to perform a multi-step algebraic deduction (invariants of transpositions $\rightarrow$ symmetric functions on orbits $\rightarrow$ orbits equal connected components) to realize the underlying structure is still Steiner Tree.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that all polynomials invariant under the selected transpositions are also invariant under transposing any two target variables is mathematically identical to requiring that all target variables belong to the same orbit (connected component) of the generated group, preserving all valid edge subsets and their costs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains identically the Steiner Tree problem on graphs, preserving its NP-complete complexity class.
</PRESERVED_CLASS>
<RISK>
Models might struggle to correctly interpret $\text{Inv}(S)$ as the invariant ring of the group generated by $S$ rather than just the individual transpositions, though mathematically they are equivalent. The formalism is rigorous and standard in invariant theory, so ambiguity is minimal.
</RISK>
