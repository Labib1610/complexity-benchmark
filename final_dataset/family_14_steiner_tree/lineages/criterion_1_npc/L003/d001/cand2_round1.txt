# Problem A — Establishing Equivalence

Time limit: 5 s   Memory limit: 256 MB

## Description

A mathematical theory contains **n** unproven propositions (numbered 1 to **n**). A mathematician wishes to establish that a specific set of **t** target propositions are all logically equivalent to one another.

There are **m** possible bidirectional lemmas that can be proven. Proving a lemma establishes that proposition **u** is logically equivalent to proposition **v**, and requires writing a proof of length **w** pages. 

By the transitive property of equivalence, if proposition A is equivalent to B, and B is equivalent to C, then A is equivalent to C. The mathematician will choose a subset of the **m** possible lemmas to prove. Each chosen lemma is proven exactly once, contributing its length **w** to the total pages written. The chosen subset must collectively guarantee that all **t** target propositions are equivalent to each other.

What is the minimum total number of pages the mathematician must write?

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the ids of the target propositions.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): a possible lemma establishing equivalence between proposition u and proposition v requiring w pages of proof.
The available lemmas are sufficient to establish the equivalence of all target propositions.

## Output

Print a single integer: the minimum total pages of proof required to ensure all target propositions are equivalent.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, proving the lemmas for (1,4), (2,4), and (3,4) requires 1+1+1 = 3 pages. This establishes that propositions 1, 2, and 3 are all equivalent to proposition 4, and therefore equivalent to each other. Attempting to establish this using only lemmas that directly link propositions 1, 2, and 3 would require at least 4 pages. 

In Example 3, there is only one target proposition, which is trivially equivalent to itself, requiring 0 pages.

<RATIONALE>
Replaced the network synchronization scenario with proving logical equivalences between mathematical propositions. This removes graph-theoretic affordances like "relays", "spanning", and "connections", forcing the model to independently recognize that establishing a transitive equivalence relation among a subset of items is structurally identical to the Steiner Tree problem.
</RATIONALE>
<PRESERVED_ANSWER>
The allowed pairwise equivalences and their costs form an identical weighted graph, and satisfying the transitive equivalence of the target propositions requires finding the exact same minimum-weight connected subgraph.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the classic Steiner Tree problem on a general graph where propositions are vertices, lemmas are edges, and target propositions are the terminal nodes.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "equivalent to each other" as requiring a clique of direct lemmas rather than a single connected component, although the explicit explanation of the "transitive property" heavily mitigates this.
</RISK>
