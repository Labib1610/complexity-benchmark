<METHOD_NAME>Dual-to-Primal Cut Condition</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the primal description of graph connectivity (paths, transitivity, components) with its dual definition: the non-existence of a cut separating any two terminals. This forces the model to mathematically deduce that the absence of such a cut is equivalent to all terminals belonging to the same connected component, hiding the Steiner Tree structure from superficial pattern matching while remaining formally identical.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Cohesive Structure

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing a system of **n** distinct modules, numbered 1 to n. There are **m** potential bidirectional interfaces you can build between specific pairs of modules. Building the interface between module u and module v has a construction cost of **w**.

A specific subset of **t** modules are designated as *core modules*.

Your task is to select a subset of interfaces to build such that the resulting system is *core-cohesive*. A set of built interfaces is defined as core-cohesive if it is strictly impossible to partition the **n** modules into two disjoint sets, A and B, that satisfy all of the following three conditions simultaneously:
1. Set A contains at least one core module.
2. Set B contains at least one core module.
3. No built interface has one of its two modules in set A and its other module in set B.

(Note: A valid partition must place every single module from 1 to n into exactly one of the two sets A or B).

Determine the minimum possible total construction cost of a set of interfaces that is core-cohesive. You may include interfaces between any modules, whether they are core modules or not, as long as the final system meets the cohesiveness requirement.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the identifiers of the core modules.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): a potential interface between modules u and v that requires **w** cost to build.
The potential interfaces are sufficient to allow a core-cohesive system to be formed.

## Output

Print a single integer: the minimum total cost of the built interfaces required to ensure the system is core-cohesive.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, building the interfaces between module 4 and each of the three core modules (costs 1+1+1 = 3) makes the system core-cohesive. This is more efficient than only building interfaces directly between the core modules (which would require at least 4 cost). In Example 3, there is only one core module, so it is impossible to place a core module in set A and a core module in set B. Thus, the empty set of interfaces is already core-cohesive, requiring 0 cost.
</STATEMENT>
<RATIONALE>
The explicit description of transitivity, synchronization, and connected components was removed. Instead, the problem defines the validity of the chosen edges using the dual cut condition (no partition can separate any two core modules without an edge crossing the cut). This forces models to mathematically deduce that the absence of such a cut is equivalent to all core modules belonging to the same connected component, breaking the surface-level pattern matching to Steiner Tree.
</RATIONALE>
<PRESERVED_ANSWER>
By Menger's theorem, the impossibility of finding a cut separating any two core modules is mathematically identical to all core modules being in the same connected component, meaning the exact same subset of edges is required.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding the minimum weight set of edges that connects a specific subset of $t$ terminals, which is the exact definition of the Minimum Steiner Tree problem, keeping it NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the partition definition as requiring the algorithm to output the partition, but the phrasing "strictly impossible to partition" and the requirement to output the "minimum total construction cost" clearly define it as a property the selected edges must fulfill.
</RISK>
