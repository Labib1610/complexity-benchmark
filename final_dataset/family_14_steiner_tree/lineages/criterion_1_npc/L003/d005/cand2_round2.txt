<METHOD_NAME>Cut-based Connectivity Definition</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the standard path-based or transitive-equality definition of connectivity with a global cut-based constraint (no valid partition separating the targets with zero crossing edges). This forces the model to deduce that the absence of such a cut is equivalent to the targets being in a single connected component, obscuring the Steiner Tree nature of the problem.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Corporate Integration

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing a market of **n** corporations, indexed from 1 to n. You have the option to establish strategic partnerships between pairs of corporations. Establishing a specific partnership between two corporations requires a known financial investment.

Among all the corporations, a specific subset of **t** corporations are designated as target corporations.

Your objective is to select a set of partnerships to establish such that the market becomes fully integrated with respect to the target corporations. The market is considered fully integrated if and only if it is impossible to divide the **n** corporations into two disjoint groups, Group A and Group B, such that all three of the following conditions hold simultaneously:
1. Every corporation is assigned to exactly one of the two groups.
2. Group A contains at least one target corporation, and Group B contains at least one target corporation.
3. No established partnership exists between any corporation in Group A and any corporation in Group B.

You are free to establish partnerships involving non-target corporations. Calculate the minimum possible total investment required to establish a valid set of partnerships that achieves this integration condition.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the identifiers of the target corporations.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): a potential partnership between corporations u and v that requires w investment to establish.
The potential partnerships are sufficient to allow the market to be fully integrated.

## Output

Print a single integer: the minimum total investment required to ensure the market is fully integrated with respect to the target corporations.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, establishing partnerships between corporation 4 and each of the three target corporations (investments 1+1+1 = 3) successfully integrates the market. Any attempt to divide the corporations such that targets are separated into Group A and Group B would require separating at least one target from corporation 4, but since we established partnerships between corporation 4 and all targets, an established partnership will always bridge the two groups. This is more efficient than only establishing partnerships directly among the target corporations (which would cost 4). In Example 3, with only one target corporation, you cannot place targets in both Group A and Group B, so the requirement is already satisfied with 0 investment.
</STATEMENT>
<RATIONALE>
The problem of connecting a set of target nodes with minimum edge weight (Steiner Tree) is standardly described using paths or transitive relations. By replacing this with a cut-based definition—requiring that no partition separates the targets without a crossing edge—we describe exactly the same topological requirement. Models that pattern-match on "paths" or "equality" will need to reason through the equivalence between the non-existence of a separating cut and the existence of a connected component.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that no cut separates the target corporations is mathematically equivalent to requiring that all target corporations belong to the same connected component, preserving the Steiner Tree objective identically.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the minimum-weight connected subgraph containing a subset of vertices, which is exactly the NP-complete Steiner Tree problem.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the cut condition as applying only to the target corporations rather than a partition of all n corporations, though the rules explicitly state "Every corporation is assigned to exactly one of the two groups."
</RISK>
