<STATEMENT>
# Problem A — Subspace Spanning Optimization

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing an **n**-dimensional vector space $V$ over the real numbers, defined by a standard basis $e_1, e_2, \dots, e_n$.

You are provided with a set of **m** available difference vectors. Each available difference vector is defined by a pair of basis elements $(u, v)$ and takes the form $d = e_u - e_v$. Including a specific difference vector in your generating set requires a known selection cost $w$.

You may select any subset of these available difference vectors. Let $S$ be the subset you select, and let $W = \text{span}(S)$ be the linear subspace of $V$ spanned by the vectors in $S$.

Among the **n** basis vectors, a specific subset of **t** basis vectors are designated as the *target basis vectors*.

Your objective is to select a subset of available difference vectors such that for any two target basis vectors $e_x$ and $e_y$, their difference $e_x - e_y$ is contained entirely within the subspace $W$. In other words, the projections of all **t** target basis vectors onto the quotient space $V/W$ must be identical.

Calculate the minimum possible total selection cost of a subset $S$ that achieves this condition.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the indices of the target basis vectors.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000). This represents an available difference vector $e_u - e_v$ with a selection cost of **w**. (Note that $\text{span}(e_u - e_v)$ is identical to $\text{span}(e_v - e_u)$, so the order of **u** and **v** does not matter).
It is guaranteed that selecting all **m** available difference vectors would satisfy the condition for the target basis vectors.

## Output

Print a single integer: the minimum total selection cost of the subset $S$ required to ensure $e_x - e_y \in W$ for all target basis vectors $e_x, e_y$.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the available difference vectors between basis vector 4 and each of the three target basis vectors (costs 1+1+1 = 3) allows any difference between the target basis vectors to be formed via linear combination (e.g., $e_1 - e_2 = (e_1 - e_4) - (e_2 - e_4)$). This is more efficient than only selecting difference vectors directly among the target basis vectors (which would cost 4). In Example 3, with only one target basis vector, there are no pairs to evaluate, so the requirement is trivially satisfied with a cost of 0.
