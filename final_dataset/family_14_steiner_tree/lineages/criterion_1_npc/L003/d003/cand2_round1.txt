# Problem A — Establishing the Protocols

Time limit: 5 s   Memory limit: 256 MB

## Description

You are managing a network of **n** communication towers, indexed from 1 to n. There are **m** potential direct radio links you can choose to activate. Activating a specific link between two towers requires a known amount of energy. 

When a link is active, the two connected towers continuously synchronize their local databases. This synchronization is fully transitive: any group of towers connected together by a sequence of active links will merge their data into a single, identical shared database.

Among all the towers, a specific subset of **t** towers are designated as priority outposts. Before any links are activated, each priority outpost's database contains a unique, localized telemetry log. Towers that are not priority outposts start with empty databases.

Your objective is to ensure that the database of every priority outpost ends up containing the complete set of telemetry logs from all **t** priority outposts. You are free to activate links involving non-priority towers; while they do not originate any logs, they will successfully synchronize and pool any data they receive.

Calculate the minimum possible total energy required to activate a valid set of links that achieves this complete synchronization among the priority outposts.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the identifiers of the priority outposts.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): a potential radio link between towers u and v that requires w energy to activate.
The potential links are sufficient to allow all priority outposts to fully synchronize.

## Output

Print a single integer: the minimum total energy of the active links required to ensure the databases of all priority outposts contain all **t** telemetry logs.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, activating the links between tower 4 and each of the three priority outposts (energies 1+1+1 = 3) successfully synchronizes all priority outposts. This is more efficient than only activating links directly between the priority outposts (which would require at least 4 energy). In Example 3, there is only one priority outpost, which already contains its own log, so no links need to be activated.
