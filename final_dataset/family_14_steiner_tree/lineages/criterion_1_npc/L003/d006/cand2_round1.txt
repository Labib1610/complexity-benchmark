<STATEMENT>
# Problem A — Logical Entailment Optimization

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing a system of $n$ boolean variables, $V_1, V_2, \ldots, V_n$. 

You are given a target set of $t$ distinct variable indices from $\{1, \dots, n\}$. Your goal is to select a system of constraints $S$ such that in every boolean assignment satisfying $S$, all variables in the target set are forced to evaluate to the exact same truth value.

To construct $S$, you may select from a provided list of $m$ candidate constraints. Each candidate constraint enforces the logical equivalence $V_u \iff V_v$ (meaning $V_u$ and $V_v$ must take the same boolean value) for some $u \neq v$. Selecting a candidate constraint adds it to your chosen set $S$. Each candidate constraint has an associated activation cost. 

Determine the minimum possible total activation cost of a selected set $S$ such that its logical consequences satisfy the target condition. 

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le 10$, $1 \le n \le 100$, $0 \le m \le n(n-1)/2$).
The second line contains $t$ distinct integers: the indices of the variables in the target set.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$): a candidate constraint $V_u \iff V_v$ available for selection, which has an activation cost of $w$.
It is guaranteed that selecting all $m$ candidate constraints generates a system that satisfies the condition for the target set.

## Output

Print a single integer: the minimum total activation cost of a selected set of candidate constraints whose logical consequences satisfy the condition.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the candidate constraints $V_1 \iff V_4$, $V_2 \iff V_4$, and $V_3 \iff V_4$ (total cost $1+1+1 = 3$) forms a system $S$. In any boolean assignment satisfying $S$, the variables $V_1, V_2,$ and $V_3$ must all share the same truth value as $V_4$, and therefore share the same truth value with each other. This selection is more cost-effective than selecting the equivalences directly between the target variables (which would cost 4). 

In Example 3, with only one index in the target set, the condition that "all variables in the target set evaluate to the exact same truth value" is trivially satisfied for any assignment. Thus, no constraints need to be activated, and the minimum cost is 0.
</STATEMENT>
<RATIONALE>
The problem has been completely recontextualized from a vector space span to a logical entailment task over boolean variables. The core requirement (graph connectivity) is now disguised as forcing a set of variables to share the same truth value via bi-implications. This forces models to parse the logical constraint implications and recognize that it is mathematically isomorphic to finding a minimum-weight connected subgraph (Steiner Tree), bypassing pattern matching on standard graph or vector formulations.
</RATIONALE>
<PRESERVED_ANSWER>
The only way to logically force a set of boolean variables to always share the same truth value using purely bi-implications is to ensure they are all within the same connected component of activated equivalences, making the optimal cost identical to the original minimum Steiner Tree cost.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
