<STATEMENT>
# Problem A — Equivalence Constraint Optimization

Time limit: 5 s   Memory limit: 256 MB

## Description

Consider a set of $n$ variables $v_1, v_2, \ldots, v_n$ that can take real values.

You are given a target set of $t$ distinct indices from $\{1, \dots, n\}$. Your goal is to select a set of constraints $S$ such that in every assignment of values to the variables where all constraints in $S$ are satisfied, all variables in the target set are forced to have the exact same value.

To form $S$, you may select constraints from a provided list of $m$ candidates. Each candidate constraint is of the form $v_x = v_y$ for some $x \neq y$, and has an associated inclusion cost. 

A selected constraint is paid for only once and may simultaneously contribute to forcing equality among multiple target variables. Intermediate non-target variables may be shared by these chains of equality, so independently choosing minimum-cost equality chains between pairs of target variables is not valid; the required optimization is over a shared set of constraints that forces all target variables to be equal.

Determine the minimum possible total cost of a selected set $S$ such that the target condition is satisfied.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le 10$, $1 \le n \le 100$, $0 \le m \le n(n-1)/2$).
The second line contains $t$ distinct integers: the indices in the target set.
Each of the next $m$ lines contains three integers $x$, $y$, and $w$ ($1 \le x, y \le n$, $x \neq y$, $1 \le w \le 1000000$): a candidate constraint $v_x = v_y$ available for selection, which has an inclusion cost of $w$.
It is guaranteed that selecting all $m$ candidate constraints generates a set that satisfies the condition for the target set.

## Output

Print a single integer: the minimum total cost of a selected set of candidate constraints that satisfies the condition.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the candidate constraints $v_1 = v_4$, $v_2 = v_4$, and $v_3 = v_4$ (total cost $1+1+1 = 3$) forms a set $S$. Under this set, $v_1, v_2,$ and $v_3$ are all forced to equal $v_4$, ensuring they share the same value. This selection is more cost-effective than selecting the direct equality constraints between the target indices (which would cost 4). 
In Example 3, with only one index in the target set, the requirement that all target variables have the same value is already met. Therefore, selecting no constraints yields a minimum cost of 0.
</STATEMENT>
<RATIONALE>
The problem is translated from vector span to logical equivalence constraints, maintaining identical structure. The description explicitly warns against the heuristic of independently choosing minimum-cost pairwise connections (the MST approximation on shortest paths), directly attacking the affordance that allowed the remaining models to fail to recognize the necessity of Dreyfus-Wagner subset DP. Banned vocabulary ("trivially") was removed from the Example 3 note.
</RATIONALE>
<PRESERVED_ANSWER>
The equivalence constraints enforce exactly the same connectivity requirements as the vector space spanning condition, so the minimum cost for any input remains identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the Minimum Steiner Tree problem in an undirected graph, which is NP-complete, requiring exact algorithms like Dreyfus-Wagner due to the small number of terminals ($t \le 10$).
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the universal quantification ("in every assignment") as requiring something other than simple connectivity, though the explanation of chains of equality makes the intent clear.
</RISK>
