# Problem A — Establishing the Protocols

Time limit: 5 s   Memory limit: 256 MB

## Description

You are managing a network of **n** communication towers, indexed from 1 to n. While no towers are initially connected, there are **m** potential direct radio links you can choose to activate. Activating a specific link between two towers requires a known amount of energy. Once active, a link allows bidirectional signal transmission between its two endpoints. Furthermore, signals can be relayed automatically through any sequence of active links, allowing distant towers to communicate as long as a path of active links connects them.

Among all the towers, a specific subset of **t** towers are designated as priority outposts. You must ensure that every priority outpost can successfully transmit signals to every other priority outpost. You are free to route these signals through any of the other non-priority towers in the network if it helps reduce the overall energy footprint. 

Your objective is to find the most energy-efficient way to connect the priority outposts. Calculate the minimum possible total energy required to activate a valid set of links.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the identifiers of the priority outposts.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): a potential radio link between towers u and v that requires w energy to activate.
The potential links are sufficient to allow all priority outposts to exchange signals.

## Output

Print a single integer: the minimum total energy of the active links required to allow all priority outposts to exchange signals with one another.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, activating links involving tower 4 (energies 1+1+1 = 3) is more efficient than using links that only involve the priority outposts (which would require 4 energy). In Example 3 there is only one priority outpost, so no links need to be activated.
