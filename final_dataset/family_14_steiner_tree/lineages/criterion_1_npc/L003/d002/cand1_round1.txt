# Problem A — Integration Architecture

Time limit: 5 s   Memory limit: 256 MB

## Description

An enterprise software environment contains **n** microservices (numbered 1 to **n**). You have the option to deploy bidirectional data bridges between specific pairs of microservices. Each available bridge requires a specific deployment fee to activate. Once activated, information can stream directly between the two connected microservices, or it can be relayed through any sequence of microservices that are linked by active bridges.

The architecture designates **t** specific microservices as primary endpoints. Your objective is to choose a collection of bridges to activate such that information can be successfully routed between every pair of primary endpoints. Any microservice in the environment, whether primary or not, can act as a relay. Calculate the minimum possible sum of deployment fees for the bridges you activate.

## Input

The first line provides three integers **n**, **m**, and **t**. The number of primary endpoints **t** is at least 1 and at most the total count of single decimal digits (0 through 9). The total number of microservices **n** is at least 1 and at most the square of the maximum possible value for **t**. The number of available bridges **m** is at least 0 and at most the number of unique pairs among the **n** microservices.
The second line provides **t** distinct integers: the identifiers of the primary endpoints.
Each of the subsequent **m** lines provides three integers **u**, **v**, and **w**, where **u** and **v** are distinct microservices (from 1 to **n**) and **w** is a positive integer deployment fee that does not exceed one million.
It is guaranteed that activating all available bridges would allow all primary endpoints to communicate with one another.

## Output

Output a single integer: the minimum total deployment fee required to ensure all primary endpoints can exchange information with one another.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, activating the bridges that connect to microservice 4 (fees 1+1+1 = 3) is more cost-effective than exclusively activating bridges between the primary endpoints (which would incur a total fee of 4). In Example 3, there is only a single primary endpoint, so no bridges need to be activated.
