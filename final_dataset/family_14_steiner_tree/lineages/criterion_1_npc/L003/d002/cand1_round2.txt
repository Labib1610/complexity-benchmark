<STATEMENT>
# Problem A — Architecture Integration

Time limit: 5 s   Memory limit: 256 MB

## Description

A software architecture consists of **n** routines (identified from 1 to n). You can deploy bidirectional communication bridges between specific pairs of routines. Each potential bridge requires a certain deployment fee. Information can be exchanged between any two routines that are connected by a deployed bridge, and can be relayed through any sequence of routines linked by deployed bridges.

You are provided with a list of **t** primary services. Your objective is to choose a collection of bridges to deploy so that information can be routed between any two of these **t** primary services. You may use any of the **n** routines in the architecture as intermediaries to relay the information. Find the lowest possible sum of deployment fees for the bridges you choose to deploy.

## Input

The first line contains three integers **n**, **m**, and **t**. The architecture has at least 1 routine, and its system capacity limits **n** to a maximum of 100. The number of potential bridges **m** ranges from 0 up to the maximum possible pairs, n·(n−1)/2. There is at least 1 primary service, and the dashboard limit restricts **t** to a maximum of 10.
The second line contains **t** distinct integers representing the identifiers of the primary services.
Each of the next **m** lines contains three integers **u**, **v**, and **w**. These specify a potential bridge between distinct routines **u** and **v** (valid routine identifiers from 1 to **n**). The deployment fee **w** is at least 1, and the transaction cap limits it to a maximum of 1000000.
The available bridges are guaranteed to be sufficient to allow all primary services to communicate.

## Output

Print a single integer: the lowest possible total deployment fee for a collection of bridges that allows all primary services to exchange information with one another.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, deploying bridges that involve routine 4 (fees 1+1+1 = 3) is cheaper than using bridges that only involve the primary services (which would incur a total fee of 4). In Example 3, there is only one primary service, so no bridges need to be deployed.
