**Solution Explanation**

For every candidate vector `b_u – b_v` we draw an undirected edge `u – v`
with weight `w`.
A set `C` of vectors is valid **iff** the edges of `C`

* connect all indices of the target set `T`,
* contain exactly `|S|-1` edges where `S` is the set of vertices incident to
  the chosen edges together with `T`,
* are linearly independent – in a graph this means the edges contain no
  cycle.

Therefore `C` must be a **tree** whose vertex set is `S` and whose leaf
vertices are allowed only among the required vertices `T`.  
A vertex that is not a leaf has degree at least `2`.  
Consequently a valid `C` is exactly a **Steiner tree** of the graph with
terminal set `T` (Steiner vertices are allowed, they automatically have
degree ≥ 2 in a tree).

So the problem reduces to:

> *Find a minimum‑weight tree that connects all terminals `T`.*

`|T| ≤ 10`, `n ≤ 100`.  
The classic DP for Steiner tree (Dreyfus‑Wagner) works in  
`O( 3^t·n + 2^t·m·log n )`, easily fast enough.



--------------------------------------------------------------------

#### 1.   DP definition  

`mask` – bitmask of terminals already connected (`0 … (1<<t)-1`)  
`v`   – a vertex of the graph (`0 … n-1`)

`dp[mask][v]` = minimum total weight of a tree

* that connects exactly the terminals whose bits are set in `mask`,
* and whose **root** (any chosen vertex of the tree) is `v`.

The answer is `min_v dp[fullMask][v]` where `fullMask` has all `t` bits set.



--------------------------------------------------------------------

#### 2.   Initialization  

For each terminal `i` (its vertex is `term[i]`)

```
dp[1<<i][ term[i] ] = 0          # a tree consisting of a single terminal
dp[1<<i][other vertices] = INF
```



--------------------------------------------------------------------

#### 3.   DP transition – merging two sub‑trees  

For a non‑empty mask we try to split it into two non‑empty disjoint parts
`sub` and `mask ^ sub`.  
If both parts already have optimal trees rooted at the same vertex `v`,
they can be merged (their roots coincide) without adding any edge:

```
dp[mask][v] = min( dp[sub][v] + dp[mask^sub][v] )
```

All proper sub‑masks are enumerated; the total work over all masks is
`O(3^t·n)`.



--------------------------------------------------------------------

#### 4.   DP transition – extending the tree through edges  

After the merging step `dp[mask][*]` contains the best costs for trees
**ending** at each vertex, but the root may be moved along graph edges.
We run a Dijkstra (or any shortest‑path) algorithm with the current
`dp[mask]` as the source distances:

```
dist = dp[mask]                     # copy
run Dijkstra on the whole graph,
   starting with all vertices whose dist < INF
   (multi‑source Dijkstra)
dp[mask] = dist
```

Now `dp[mask][v]` is the optimum for a tree connecting the terminals of
`mask` and whose root is `v`, possibly after adding extra edges.

Complexity per mask: `O( m log n )`.  
Overall: `O( 2^t·m·log n )`.



--------------------------------------------------------------------

#### 5.   Result  

`full = (1<<t) - 1`  

`answer = min( dp[full][v] for v in range(n) )`  

The problem guarantees at least one feasible solution, therefore the
minimum is finite.



--------------------------------------------------------------------

#### 6.   Correctness Proof  

We prove that the algorithm returns the minimum possible total cost.

---

##### Lemma 1  
For any mask and vertex `v`, after the Dijkstra step
`dp[mask][v]` equals the minimum weight of a tree that

* connects exactly the terminals of `mask`,
* contains `v` (as a vertex of the tree).

**Proof.**  
Induction over the DP order.

*Base.* For a single terminal mask `{i}` the only tree connecting it and
containing vertex `v` is possible iff `v` is that terminal, with weight `0`.
The initialization sets exactly this value.

*Induction step.* Assume the statement holds for all proper sub‑masks of
`mask`.  
Consider any optimal tree `T` for `mask` that contains `v`.  
If `v` is a leaf of `T`, remove the leaf edge; the remaining tree connects
the same terminals and still contains `v`. Its weight is smaller, contradicting
optimality. Hence `v` is not a leaf; there exists a vertex `x` of `T`
such that the unique path from `x` to `v` consists only of edges of `T`.
Remove that path; the remaining forest splits into two trees whose terminal
sets are a partition `sub` and `mask^sub`, both containing `x`. Their
weights are exactly `dp[sub][x]` and `dp[mask^sub][x]` by the induction
hypothesis, and the removed path contributes its total edge weight.
Running Dijkstra from all vertices with current `dp[mask][*]` adds precisely
the cheapest possible path to any other vertex, therefore after Dijkstra
the distance to `v` equals the weight of `T`. ∎



##### Lemma 2  
After processing a mask, `dp[mask][v]` is the minimum possible weight of a
**tree** (acyclic connected subgraph) that connects the terminals of `mask`
and contains `v`.

**Proof.**  
The merging step only combines two trees that share the same root `v`,
producing a tree (union of two edge‑disjoint trees) whose weight is the sum.
All possibilities of partitioning the terminal set are examined, therefore
the minimum over all such unions is stored.  
The subsequent Dijkstra step can only add a shortest path from the root to
another vertex, which keeps the structure a tree (adding a path to a new
vertex cannot create a cycle). By Lemma&nbsp;1 the resulting distances are
exactly the optimum among all trees containing the vertex. ∎



##### Lemma 3  
For the full mask `fullMask`, `min_v dp[fullMask][v]` equals the minimum
weight of any Steiner tree connecting all terminals `T`.

**Proof.**  
Any Steiner tree `S` connects all terminals, thus its terminal set is
`fullMask`. Choose any vertex `r` of `S` as root; by Lemma&nbsp;2
`dp[fullMask][r]` is at most the weight of `S`. Consequently the minimum
over all vertices is ≤ optimal Steiner tree weight.

Conversely, let `v*` be a vertex attaining the minimum.
Lemma&nbsp;2 guarantees a tree `S*` of that weight connecting all terminals.
`S*` is a feasible Steiner tree, therefore the optimum cannot be smaller.
Thus the minimum equals the optimum. ∎



##### Theorem  
The algorithm outputs the minimum possible total cost of a valid selection
`C`.

**Proof.**  
By the reduction explained at the beginning, valid selections are exactly
Steiner trees of the graph with terminal set `T`.  
By Lemma&nbsp;3 the algorithm computes the minimum weight of such a tree,
hence the printed value is the optimal cost. ∎



--------------------------------------------------------------------

#### 7.   Complexity Analysis  

```
t ≤ 10,  n ≤ 100,  m ≤ n·(n-1)/2 ≤ 4950
```

* Merging sub‑masks: `O(3^t·n)   ≤ 3^10·100 ≈ 5.9·10^5`
* Dijkstra for each mask: `2^t` times `O(m log n)`  
  `2^10·4950·log 100  < 5·10^6`
* Memory: `dp` array `2^t × n` → at most `1024·100 = 102400` integers.

Both time (well below 5 s) and memory limits are satisfied.

#### 8.   Reference Implementation  (Python 3)

```python
import sys
import heapq

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))
    terminals = [int(next(it)) - 1 for _ in range(t)]

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        adj[u].append((v, w))
        adj[v].append((u, w))

    INF = 10**18
    full = (1 << t) - 1
    dp = [[INF] * n for _ in range(1 << t)]

    for i, v in enumerate(terminals):
        dp[1 << i][v] = 0

    # iterate masks in increasing order
    for mask in range(1, full + 1):
        # combine submasks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            # to avoid doing both (sub, other) and (other, sub) we can enforce sub < other
            if sub < other:
                dps = dp[sub]
                dpo = dp[other]
                dpm = dp[mask]
                for v in range(n):
                    val = dps[v] + dpo[v]
                    if val < dpm[v]:
                        dpm[v] = val
            sub = (sub - 1) & mask

        # Dijkstra (multi-source)
        dist = dp[mask][:]
        heap = [(dist[v], v) for v in range(n) if dist[v] < INF]
        heapq.heapify(heap)
        while heap:
            d, v = heapq.heappop(heap)
            if d != dist[v]:
                continue
            for to, w in adj[v]:
                nd = d + w
                if nd < dist[to]:
                    dist[to] = nd
                    heapq.heappush(heap, (nd, to))
        dp[mask] = dist

    ans = min(dp[full])
    print(ans)

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
