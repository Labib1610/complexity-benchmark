<METHOD_NAME>Geometric Coordinate Linkage</METHOD_NAME>
<METHOD_DESCRIPTION>Recasts graph components and edges as coordinate equality constraints on a vector space. Vertices become vector coordinates, edges become pairwise equality constraints (hyperplanes). Finding the minimum Steiner tree becomes finding the minimum cost set of constraints that force a designated subset of coordinates to be equal. This hides the graph structure and Steiner tree nature behind linear algebra / constraint satisfaction terminology.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Coordinate Equalization

Time limit: 5 s
Memory limit: 256 MB

## Description

Consider an **n**-dimensional system. The coordinates of any state in this system are indexed from 1 to **n**. You are provided a menu of **m** possible coordinate restrictions. Each restriction forces the value at coordinate **u** to be exactly equal to the value at coordinate **v**. Enforcing this specific restriction incurs a structural cost of **w**.

A system requirement dictates that a specific subset of **t** coordinates—designated as *critical indices*—must be forced to share the exact same value. Two coordinates are guaranteed to have the same value if a restriction is directly applied between them, or if their equality is logically forced through a chain of other coordinate restrictions.

You may select any combination of the available restrictions. You are not limited to restrictions involving only the critical indices; you may enforce equalities involving any of the non-critical coordinates if using them as intermediate links results in a lower total structural cost.

Your task is to select a subset of the **m** restrictions to enforce such that the chosen equalities logically force all **t** critical indices to have the identical value, while keeping the total structural cost of the selected restrictions to the absolute minimum.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **t** ≤ 10, 1 ≤ **n** ≤ 100, 0 ≤ **m** ≤ **n**·(**n**−1)/2).  
The second line lists **t** distinct integers representing the critical indices.  
Following this, there are **m** lines. Each line provides three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000), indicating that a coordinate restriction can be enforced between coordinate **u** and coordinate **v** for a structural cost of **w**.  
It is guaranteed that the available restrictions are sufficient to force equality among all critical indices.

## Output

Output a single integer representing the minimum possible total structural cost required to satisfy the system requirement.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, enforcing the restrictions that equalise coordinate 4 with coordinates 1, 2, and 3 requires a total cost of 1 + 1 + 1 = 3. This successfully ensures the critical indices (1, 2, and 3) share the same value. Utilising coordinate 4 as a transitive intermediate link is more cost-effective than applying restrictions solely among the critical indices, which would incur a cost of at least 4. 

In Example 3, with only one critical index, the requirement is already satisfied without selecting any restriction, resulting in a cost of 0.

<RATIONALE>
The problem was rewritten using the "Geometric Coordinate Linkage" method to disguise the graph-theoretic Steiner Tree structure. Vertices are recast as geometric coordinates, and edges are recast as equality constraints between coordinates. This forces the model to deduce that "transitive equality forcing" is mathematically identical to finding a connected subgraph, preventing purely pattern-matching LLMs from recognizing the standard Steiner Tree setup. Previous H3 flags ("reduction" and "trivially") and vague phrasing were removed per expert feedback.
</RATIONALE>
