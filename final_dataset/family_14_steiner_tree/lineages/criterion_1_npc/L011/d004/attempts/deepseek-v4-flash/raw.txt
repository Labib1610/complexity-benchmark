We can model this as finding the minimum spanning tree (MST) that connects all the invariant variables, but we may use any other variables as intermediate nodes.  

Since the number of invariant variables is at most 10, we can use a **Steiner tree** approach:  
- Compute shortest paths between all pairs of nodes (Floyd–Warshall).  
- Then use dynamic programming over subsets of the invariant variables to find the minimum cost to connect them.  

Here’s the implementation:  

```python
import sys

def main():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    terminals = list(map(int, input().split()))
    terminals = [x-1 for x in terminals]  # 0-indexed

    INF = 10**15
    dist = [[INF]*n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0

    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        if w < dist[u][v]:
            dist[u][v] = w
            dist[v][u] = w

    # Floyd-Warshall
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]

    # DP over subsets of terminals
    # dp[mask][v] = min cost to connect terminals in mask, ending at node v
    full_mask = 1 << t
    dp = [[INF]*n for _ in range(full_mask)]

    for i in range(t):
        dp[1 << i][terminals[i]] = 0

    for mask in range(full_mask):
        # combine two submasks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if sub < other:  # avoid double work
                for v in range(n):
                    dp[mask][v] = min(dp[mask][v], dp[sub][v] + dp[other][v])
            sub = (sub - 1) & mask

        # relax via shortest paths
        for v in range(n):
            if dp[mask][v] < INF:
                for u in range(n):
                    if dist[v][u] < INF:
                        nd = dp[mask][v] + dist[v][u]
                        if nd < dp[mask][u]:
                            dp[mask][u] = nd

    ans = min(dp[full_mask-1][v] for v in range(n))
    print(ans)

if __name__ == "__main__":
    main()
```
