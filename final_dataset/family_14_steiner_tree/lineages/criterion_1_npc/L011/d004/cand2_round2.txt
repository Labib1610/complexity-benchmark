# Problem A — Axiomatic Foundations

Time limit: 5 s
Memory limit: 256 MB

## Description

A formal verification system operates on a collection of **n** distinct logical propositions, identified by integers from 1 to **n**. To demonstrate that these propositions are mathematically equivalent, you can establish bidirectional implications (proofs) between specific pairs of propositions. The computational effort required to establish each proposed bidirectional proof is known in advance.

A strict theoretical framework requires that a specific subset of **t** propositions—designated as *core axioms*—must be proven to be mutually equivalent. Specifically, there must exist a continuous chain of established bidirectional proofs such that logical equivalence can be traced from any core axiom to any other core axiom.

When constructing this chain of proofs, you are not restricted to only proving direct implications between the core axioms themselves. Any of the remaining auxiliary propositions may be utilized as intermediate logical steps; routing equivalence through these auxiliary propositions is entirely optional but may be advantageous if it reduces the overall computational effort.

Your task is to select a subset of the proposed bidirectional proofs to establish such that all core axioms are mutually equivalent, while keeping the total computational effort of the established proofs to the absolute minimum.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **t** ≤ 10, 1 ≤ **n** ≤ 100, 0 ≤ **m** ≤ **n**·(**n**−1)/2).  
The second line lists **t** distinct integers representing the identifiers of the core axioms.  
Following this, there are **m** lines. Each line provides three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000), indicating that a bidirectional proof can be established between proposition **u** and proposition **v** for a computational effort of **w**.  
It is guaranteed that the proposed proofs provide at least one valid way to demonstrate the mutual equivalence of all core axioms.

## Output

Output a single integer representing the minimum possible total computational effort required to satisfy the theoretical framework.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, establishing the proofs that link proposition 4 to propositions 1, 2, and 3 requires a total effort of 1 + 1 + 1 = 3. This successfully demonstrates the mutual equivalence of the core axioms (1, 2, and 3). Utilizing proposition 4 as an intermediate logical step is more efficient than forcing direct proofs solely between the core axioms, which would incur an effort of at least 4. 

In Example 3, only one proposition is flagged as a core axiom. Since only one core axiom is specified, no biconditionals need to be established, resulting in an effort of 0.
