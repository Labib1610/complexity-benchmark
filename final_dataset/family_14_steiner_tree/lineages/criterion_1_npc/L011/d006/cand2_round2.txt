<METHOD_NAME>Algebraic Rank Equivalent of Connectivity</METHOD_NAME>
<METHOD_DESCRIPTION>Translates the topological requirement of a connected subgraph spanning a set of terminals into an algebraic requirement: the system of equations formed by the selected edges (each representing $x_u - x_v = 0$) on a subset $S$ must have a rank of exactly $|S| - 1$. This perfectly preserves the Steiner Tree problem while completely removing all graph terminology and forcing models to deduce that rank $|S|-1$ implies a single connected component.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Subspace Anchors

Time limit: 5 s
Memory limit: 256 MB

## Description

You are designing a system of **n** continuous variables, identified by integers from 1 to **n**. You can enforce relative constraints between specific pairs of variables. There are **m** possible constraints available. Enforcing a constraint between variable **u** and variable **v** incurs a one-time cost of **w**, and forces the algebraic condition $x_u - x_v = 0$. Constraints operate symmetrically.

A subset of variables **S** is defined as *rigidly coupled* if the enforced constraints that exclusively involve variables in **S** form a system of equations with a rank of exactly $|S| - 1$. In other words, the maximum number of linearly independent equations that can be selected from the enforced constraints within **S** must be exactly $|S| - 1$.

A new structural framework requires that a designated group of **t** *anchor* variables must all reside within the same rigidly coupled subset.

You may include any number of other variables in this subset if enforcing constraints involving them helps reduce the overall cost. Your task is to select a set of constraints to enforce such that there exists at least one rigidly coupled subset containing all **t** anchor variables, while keeping the total cost of the enforced constraints to the absolute minimum.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **t** ≤ 10, 1 ≤ **n** ≤ 100, 0 ≤ **m** ≤ **n**·(**n**−1)/2).  
The second line lists **t** distinct integers representing the identifiers of the anchor variables.  
Following this, there are **m** lines. Each line provides three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000), indicating that a constraint can be enforced between variable **u** and variable **v** for a cost of **w**.  
It is guaranteed that the available constraints are sufficient to form at least one rigidly coupled subset containing all anchor variables.

## Output

Output a single integer representing the minimum possible total cost required to satisfy the structural framework.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, enforcing the constraints between variable 4 and variables 1, 2, and 3 incurs a total cost of 1 + 1 + 1 = 3. The subset **S** = {1, 2, 3, 4} is rigidly coupled. The enforced constraints exclusively within **S** are $x_1 - x_4 = 0$, $x_2 - x_4 = 0$, and $x_3 - x_4 = 0$. These form a system from which we can select exactly $|S| - 1 = 3$ linearly independent equations. This subset successfully contains the anchor variables 1, 2, and 3. Utilizing variable 4 in the subset is more cost-effective than enforcing constraints exclusively among the anchor variables, which would incur a cost of at least 4.

In Example 3, only one variable is designated as an anchor. A subset consisting of just this single variable (**S** = {1}) requires exactly $|S| - 1 = 0$ independent equations. Thus, zero constraints need to be enforced, resulting in a cost of 0.
</STATEMENT>
<RATIONALE>
I replaced the graph-cut definition of a "cohesive enclave" with a strictly algebraic condition: the enforced constraints on a subset $S$ must form a system of equations with a rank of exactly $|S| - 1$. This eliminates all topological and graph terminology (cuts, partitions, edges) and forces the model to realize that a system of difference equations having rank $|S| - 1$ is mathematically equivalent to the variables forming a single connected component.
</RATIONALE>
<PRESERVED_ANSWER>
The rank of a system of difference equations $x_u - x_v = 0$ on a set of variables $S$ is always $|S| - c$, where $c$ is the number of connected components; thus, a rank of exactly $|S| - 1$ means the subset $S$ forms exactly one connected component, perfectly matching the seed's connectivity requirement and yielding identical minimal costs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Steiner Tree problem on a graph where variables are vertices, constraints are edges, and anchor variables are the terminals, preserving its NP-completeness.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "rank of exactly $|S| - 1$" if they lack standard linear algebraic knowledge, though the parenthetical explanation clarifying "maximum number of linearly independent equations" removes structural ambiguity.
</RISK>
