# Problem A — Control System Synchronization

Time limit: 5 s
Memory limit: 256 MB

## Description

An industrial control network consists of **n** processing units, numbered 1 through **n**. Certain pairs of units can be synchronized by installing a dedicated communication interface, which carries a specific setup cost.

Among the **n** units, a specific group of **t** units are classified as *core* units. For the system to function correctly, every core unit must be able to exchange data with every other core unit. Data exchange between any two units is possible as long as there is a contiguous chain of installed communication interfaces connecting them.

You must choose a subset of the available communication interfaces to install so that every pair of core units is connected by a contiguous chain of installed interfaces. Determine the minimum total setup cost required to achieve this.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the identifiers of the core units.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), representing a potential communication interface between unit **u** and unit **v** with a setup cost of **w**.
It is guaranteed that the available potential interfaces are sufficient to allow all core units to communicate.

## Output

Print a single integer: the minimum total setup cost to install the interfaces.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the optimal subset of interfaces to install connects unit 1 to 4, unit 2 to 4, and unit 3 to 4, for a total cost of 1 + 1 + 1 = 3. In Example 3, there is only one core unit, requiring no installed interfaces.
