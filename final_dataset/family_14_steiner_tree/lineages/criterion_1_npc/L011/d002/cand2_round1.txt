# Problem A — Facility Fiber Integration

Time limit: 5 s   Memory limit: 256 MB

## Description

A campus council manages **n** facilities, which are assigned unique integer identifiers starting from 1. The council's zoning rules restrict the campus to a maximum of 100 facilities. You have a list of **m** potential bidirectional fiber links that can be installed between certain pairs of facilities. The number of potential links **m** can be any non-negative integer up to the scenario where every facility is directly connected to all other facilities. Each link has a specific installation expense **w**. The installation expense for each link is a strictly positive integer that will not exceed the regional grant cap of 1,000,000.

A specific subset of **t** facilities are designated as *primary*. These primary locations require specialized synchronization hardware to function as the core of the network. This hardware uses a single base-10 digit (0 through 9) to identify the synchronization channel, meaning the system can support at most 10 primary facilities. There is always at least one primary facility designated.

The goal is to establish a communication network so that every primary facility can transmit data to every other primary facility. Data can flow between any two facilities as long as there is a contiguous sequence of installed fiber links connecting them.

You may select any combination of the available fiber links to achieve this goal. Determine the minimum possible total expense required to ensure all primary facilities can communicate with one another.

## Input

The first line contains three integers **n**, **m**, and **t**.
The second line contains **t** distinct integers: the identifiers of the primary facilities.
Each of the next **m** lines contains three integers **u**, **v**, and **w**, representing a potential fiber link between facility **u** and facility **v** (where **u** and **v** are distinct valid facility identifiers) with an installation expense of **w**.
It is guaranteed that the available potential links are sufficient to allow all primary facilities to communicate.

## Output

Print a single integer: the minimum total expense to install the links.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the fiber links connecting facility 4 to facilities 1, 2, and 3 incurs a total expense of 1 + 1 + 1 = 3. This successfully allows the primary facilities (1, 2, and 3) to communicate and is more economical than linking them exclusively using direct connections between each other, which would require an expense of at least 4. In Example 3, there is only one primary facility, so no fiber links need to be installed.
