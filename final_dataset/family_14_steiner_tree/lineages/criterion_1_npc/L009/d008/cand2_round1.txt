<STATEMENT>
# Problem A — Logical State Entanglement

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing a formal logic system defined by $n$ boolean variables, $x_1, x_2, \ldots, x_n$. Each variable can independently be assigned the value True or False. Within this system, a specific subset of $t$ variables are designated as the *critical indicators*.

You have access to a catalog of $m$ potential equivalence axioms. Each axiom in the catalog specifies a strict logical biconditional between two variables, $(x_u \iff x_v)$, and comes with an associated implementation cost $w$. When an axiom is implemented, it restricts the valid states of the system: any valid state (truth assignment) must assign the exact same truth value to $x_u$ and $x_v$.

Your objective is to select a subset of these axioms to implement such that the total cost is minimized, and the implemented axioms strictly enforce indicator uniformity. Indicator uniformity is achieved if, in absolutely every valid state of the system that satisfies all implemented axioms, all $t$ critical indicators share the exact same truth value.

If no axioms are implemented, all $2^n$ states are valid, and indicator uniformity is generally not satisfied (unless $t \le 1$).

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ t ≤ 10). The integer **t** is the number of critical indicators.
The second line provides **t** distinct integers representing the indices of these critical indicators.
The subsequent **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), describing an axiom catalog entry that provides the biconditional $(x_u \iff x_v)$ for an implementation cost of **w**.
It is guaranteed that implementing all available axioms would be sufficient to satisfy the condition for all critical indicators.

## Output

Print a single integer: the minimum total cost to implement a subset of axioms that satisfies the condition for all critical indicators.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, implementing the axioms $(x_1 \iff x_4)$, $(x_2 \iff x_4)$, and $(x_3 \iff x_4)$ incurs a total cost of 1+1+1 = 3. Any valid state of the system must satisfy $x_1 = x_4$, $x_2 = x_4$, and $x_3 = x_4$. This logically implies $x_1 = x_2 = x_3$. Consequently, in every valid state, the critical indicators 1, 2, and 3 all share the same truth value. This is more economical than selecting a subset of axioms that do not involve variable 4 (which would cost at least 4).

In Example 3, there is only a single critical indicator. The condition that all critical indicators must share the same truth value is vacuously satisfied by an empty subset of axioms, resulting in a cost of 0.

<RATIONALE>
The previous framing used group theory and orbits, which models successfully mapped to undirected graph connectivity and Steiner Tree. This rewrite shifts the domain entirely to formal logic and Boolean Satisfiability, requiring the model to deduce that forcing equivalence across all valid states is mathematically identical to forming a connected component of biconditional clauses.
</RATIONALE>
<PRESERVED_ANSWER>
The logical condition that a subset of variables must share the same truth value in every valid assignment is exactly equivalent to the structural condition that those variables belong to the same connected component of implemented biconditional clauses, keeping the minimum cost identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the minimum weight Steiner Tree problem on an undirected graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "valid state" or attempt to solve it using actual SAT solvers rather than recognizing the underlying graph structure, though the definition of a valid state is mathematically precise.
</RISK>
