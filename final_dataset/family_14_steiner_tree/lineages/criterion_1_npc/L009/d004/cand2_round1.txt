# Problem A — Guaranteeing Logical Equivalence

Time limit: 5 s   Memory limit: 256 MB

## Description

You are optimizing a formal verification engine that analyzes a system of $n$ boolean variables, numbered 1 through $n$. Within this system, exactly $t$ variables are designated as critical watchpoints. 

The engine has access to a database of $m$ potential biconditional rules. Each rule can enforce a logical equivalence ($u \leftrightarrow v$) between a specific pair of variables $u$ and $v$. However, loading a rule into the active verification context consumes a specific amount of processing time $w$.

Your task is to select a subset of these rules to load into the active context. The selection must satisfy the following strict guarantee: **For any possible assignment of True/False values to the $n$ variables, if every loaded rule evaluates to True, then all $t$ critical watchpoint variables must share the exact same boolean value.** 

Variables that are not watchpoints do not have this requirement; they can take any value, provided the loaded rules are satisfied. You may load rules involving non-watchpoint variables if they help establish the required guarantee for the watchpoints more efficiently.

Calculate the minimum total processing time required to load a valid subset of rules that successfully guarantees all critical watchpoints are logically equivalent.

## Input

The first line contains three integers $n$, $m$, and $t$. The number of variables $n$ is at least 1 and capped by the engine's architectural limit of 100. The number of available rules $m$ is non-negative and bounded by the maximum possible number of unique pairs among the $n$ variables. The number of critical watchpoints $t$ is at least 1 and capped by the debugger's hardware limit of 10.

The second line provides $t$ distinct integers representing the identifiers of the critical watchpoint variables.

The subsequent $m$ lines each contain three integers $u$, $v$, and $w$. Each line describes a potential rule that enforces $u \leftrightarrow v$ and requires a processing time of $w$. The processing time $w$ is a positive integer not exceeding the maximum latency of 1,000,000 microseconds. It is guaranteed that $u \neq v$.

It is guaranteed that the database contains a sufficient set of rules to satisfy the condition.

## Output

Print a single integer: the minimum total processing time required to load a subset of rules that guarantees the critical watchpoints share the same value.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, loading the rules between the optional variable 4 and each of the three watchpoints (costing 1+1+1 = 3) is more efficient than loading the rules that directly relate the three watchpoints (which would cost 4). If variables 1, 2, and 3 are all equivalent to variable 4, they are logically guaranteed to be equivalent to each other.

In Example 3, there is only a single critical watchpoint. The condition that it shares the same value with all other watchpoints is trivially satisfied for any assignment, meaning no rules need to be loaded.

<RATIONALE>
I changed the framing from a spatial network connecting facilities to a logical system where rules enforce boolean equivalence between variables. This forces the model to reason structurally: it must deduce that guaranteeing equivalence across all valid assignments is mathematically identical to forming a connected component in a graph, breaking superficial pattern matching to routing or network-design algorithms.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that a subset of biconditional rules guarantees equivalence among targets across all valid assignments is strictly equivalent to requiring the targets to be in the same connected component of the rule subgraph, keeping the optimal subset and cost identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Steiner Tree problem on a graph where variables are nodes and rules are edges, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
A reader might mistakenly believe they need to evaluate specific boolean assignments or construct a SAT formula, rather than recognizing it as a structural property, though the bolded guarantee mathematically defines connectivity without ambiguity.
