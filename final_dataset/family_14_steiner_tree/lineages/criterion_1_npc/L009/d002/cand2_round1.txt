<STATEMENT>
# Problem A — Essential Facilities Integration

Time limit: 5 s   Memory limit: 256 MB

## Description

A regional development initiative spans a set of $n$ designated zones (numbered 1 through $n$). A subset of these zones, numbering $t$, have been earmarked as essential facilities.

Your objective is to establish a unified communication grid. You are provided with a catalogue of potential communication links, each bridging two distinct zones and requiring a specific installation expense.

You must choose a collection of these links such that all essential facilities can exchange data with one another. Two facilities can exchange data if there is an unbroken chain of installed links bridging them, which may traverse any number of intermediary zones. Using the non-essential zones is entirely at your discretion; you may route the grid through them if it decreases the overall expenditure, or bypass them completely.

Determine the absolute minimum installation expense for a collection of links that guarantees all essential facilities are integrated.

## Input

The first line provides three integers $n$, $m$, and $t$. 
The physical and administrative limits of the project dictate the ranges of these values:
- The total number of zones $n$ is at least one, and the district charter strictly caps the number of zones at one hundred.
- The number of potential links $m$ can be as low as zero, and can go up to the theoretical maximum where every single zone shares a potential link with every other zone.
- The number of essential facilities $t$ is at least one. Each essential facility must dispatch exactly one delegate to the project's oversight committee. Because this committee meets in a boardroom that strictly accommodates a maximum of ten delegates, the number of essential facilities will never exceed ten.

The second line contains $t$ distinct integers: the identifiers of the essential facilities.

The subsequent $m$ lines each contain three integers $u$, $v$, and $w$. This indicates a potential link between zone $u$ and zone $v$ (where $u$ and $v$ are distinct valid zone identifiers). The installation expense $w$ is at least 1, and is capped by the regional per-link budget limit of exactly one million.

The provided catalogue of links is guaranteed to be sufficient to integrate all essential facilities.

## Output

Print a single integer: the minimum overall expense required to integrate all essential facilities.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, routing the grid through the optional zone 4 (expense 1+1+1 = 3) is more economical than integrating the three essential facilities directly (which would incur an expense of 4). In Example 3 there is only one essential facility, so no links are required.
</STATEMENT>
<RATIONALE>
I replaced the explicit mathematical inequalities for the bounds with scenario-based descriptions, such as a boardroom capacity of ten delegates implying t ≤ 10. This forces the model to read and comprehend the text to deduce the constraints, rather than pattern-matching on bare inequalities to instantly know a 2^t dynamic programming approach is viable.
</RATIONALE>

The core logic of finding the minimum cost to connect a subset of nodes remains exactly the same, and the examples are unchanged, so identical inputs will yield identical outputs.
</PRESERVED_ANSWER>
