<STATEMENT>
# Problem A — Basis Alignment Procurement

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing an $n$-dimensional vector space $V$ over the real numbers, equipped with a fixed standard basis $\mathbf{e}_1, \mathbf{e}_2, \ldots, \mathbf{e}_n$. Within this space, a specific set of $t$ standard basis vectors are designated as objective targets.

You are tasked with procuring a collection of vectors to generate a subspace $W \subseteq V$. You can select from a provided catalog of available options. Each catalog entry allows you to add the specific vector $\mathbf{e}_u - \mathbf{e}_v$ to your generating set for a specified procurement expense.

Your goal is to select a subset of the catalog entries such that the resulting subspace $W$ (the linear span of your selected vectors) satisfies a specific algebraic property: in the quotient space $V / W$, the images of all objective target basis vectors under the canonical projection map $\pi: V \to V / W$ must be identical. That is, for any two objective targets $\mathbf{e}_a$ and $\mathbf{e}_b$, you must ensure that $\pi(\mathbf{e}_a) = \pi(\mathbf{e}_b)$.

Calculate the minimum total expense required to procure a subset of catalog entries that satisfies this quotient space condition for all objective targets.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ t ≤ 10). The integer **t** is the number of objective targets.
The second line provides **t** distinct integers representing the indices of the objective target basis vectors.
The subsequent **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), describing a catalog entry that provides the vector $\mathbf{e}_u - \mathbf{e}_v$ for a procurement expense of **w**.
It is guaranteed that the available catalog entries are sufficient to satisfy the condition for all objective targets.

## Output

Print a single integer: the minimum total expense to satisfy the quotient space condition for all objective targets.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the catalog entries for $\mathbf{e}_1 - \mathbf{e}_4$, $\mathbf{e}_2 - \mathbf{e}_4$, and $\mathbf{e}_3 - \mathbf{e}_4$ (costing 1+1+1 = 3) generates a subspace $W$. Because these vectors are in $W$, their images under the canonical projection $\pi$ to $V / W$ are zero. Thus, $\pi(\mathbf{e}_1) = \pi(\mathbf{e}_4)$, $\pi(\mathbf{e}_2) = \pi(\mathbf{e}_4)$, and $\pi(\mathbf{e}_3) = \pi(\mathbf{e}_4)$, which guarantees $\pi(\mathbf{e}_1) = \pi(\mathbf{e}_2) = \pi(\mathbf{e}_3)$. This is more economical than satisfying the condition among the three objective targets using vectors that do not involve $\mathbf{e}_4$ (which would cost 4). In Example 3, there is only a single objective target, so the condition is vacuously satisfied with an empty subset, resulting in a cost of 0.
