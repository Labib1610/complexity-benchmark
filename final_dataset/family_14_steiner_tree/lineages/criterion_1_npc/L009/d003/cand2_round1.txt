# Problem A — Linking the Priority Facilities

Time limit: 5 s   Memory limit: 256 MB

## Description

A regional development project encompasses **n** distinct districts (numbered 1 to **n**). You must establish a unified data grid. You are provided with a catalogue of potential optical links, each capable of joining two different districts at a given cost.

Certain districts are designated as priority facilities. By law, every priority facility must be audited by a unique inspector from the regional oversight committee. The committee is permanently staffed with exactly ten inspectors, which acts as a strict hard limit on the concurrent number of priority facilities. The current plan includes **t** such facilities.

Your objective is to select a collection of these optical links so that every priority facility can exchange data with all other priority facilities. Data exchange between any two priority facilities is possible if they are directly or indirectly linked by the chosen optical links. The sequence of links can traverse any number of intermediate districts. The districts without priority status are strictly optional; you may route the grid through them if it achieves a lower total cost, or you may bypass them entirely.

Determine the minimum total cost of a collection of optical links that successfully interconnects all priority facilities.

## Input

The first line contains three integers **n**, **m**, and **t**.
The number of districts **n** is a positive integer. The district registration system limits the region to a maximum of one hundred distinct district IDs.
The integer **m** is the count of available links, which can be zero, up to the maximum possible count of unique district pairs.
The integer **t** is the count of priority facilities. It is at least one, and its upper limit is strictly dictated by the available oversight committee headcount described above.
The second line contains **t** distinct integers: the ids of the priority facilities.
Each of the next **m** lines contains three integers **u**, **v**, and **w** detailing an optical link between distinct valid districts **u** and **v**. The cost **w** is a positive integer bounded by a grant limit of one million.
The provided optical links are guaranteed to be sufficient to interconnect all priority facilities.

## Output

Print a single integer: the minimum total cost to interconnect all priority facilities.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, routing the grid through the optional district 4 (costs 1+1+1 = 3) is cheaper than joining the three priority facilities directly (which would cost 4). In Example 3 there is only one priority facility, so no optical links are needed.

The explicit bounds `1 <= t <= 10` and `1 <= n <= 100` were removed from the input section. Instead, these bounds are now expressed indirectly through the scenario narrative (a committee of ten inspectors limiting `t`, and a registration system limiting `n` to one hundred). This forces the model to synthesize narrative constraints into algorithmic bounds to realize that exponential state-space algorithms over `t` are feasible.
</RATIONALE>
