<STATEMENT>
# Problem A — Subgroup Orbit Procurement

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing the symmetric group acting on a set of $n$ distinct elements $\{1, 2, \ldots, n\}$. Within this domain, a specific set of $t$ elements are designated as priority targets.

You are tasked with procuring a subset of transpositions from a provided catalog. Each catalog entry allows you to add a specific transposition $(u, v)$ to your chosen subset for a specified procurement expense. A transposition $(u, v)$ is a permutation that swaps elements $u$ and $v$ while leaving all other elements unchanged.

Your goal is to select a subset of the available transpositions to act as a generating set for a subgroup. You must ensure that in the subgroup generated by your selected transpositions, all $t$ priority targets belong to the exact same orbit. Two elements $a$ and $b$ are in the same orbit if there exists at least one permutation in the generated subgroup that maps $a$ to $b$.

Calculate the minimum total expense required to procure a subset of transpositions that satisfies this condition.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ t ≤ 10). The integer **t** is the number of priority targets.
The second line provides **t** distinct integers representing the identities of these priority targets.
The subsequent **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), describing a catalog entry that provides the transposition $(u, v)$ for a procurement expense of **w**.
It is guaranteed that the available options are sufficient to satisfy the condition for all priority targets.

## Output

Print a single integer: the minimum total expense to satisfy the condition for all priority targets.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, procuring the transpositions $(1, 4)$, $(2, 4)$, and $(3, 4)$ incurs a total expense of 1+1+1 = 3. The subgroup generated by these three transpositions allows any element in the set $\{1, 2, 3, 4\}$ to be mapped to any other element in the set. Consequently, the priority targets 1, 2, and 3 all belong to the same orbit. This is more economical than selecting a subset of transpositions that do not involve element 4 (which would cost at least 4).

In Example 3, there is only a single priority target. The condition that all priority targets must belong to the same orbit is vacuously satisfied by an empty subset of transpositions, resulting in a cost of 0.

<RATIONALE>
The problem was reformulated from finding a linear functional over basis vectors to selecting transpositions to generate a subgroup where specific elements share an orbit. This forces the model to recognize the equivalence between group-theoretic orbits under transpositions and graph connectivity, completely removing the implicit graph/tree structure that the surviving models previously exploited.
</RATIONALE>
<PRESERVED_ANSWER>
The orbits of a subgroup generated by a set of transpositions correspond exactly to the connected components of a graph whose edges are those transpositions, making the minimum cost to place targets in the same orbit identical to the minimum cost to connect them.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Steiner Tree problem on graphs, which is NP-complete.
</PRESERVED_CLASS>
