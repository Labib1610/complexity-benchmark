**Solution Explanation**

For every pair `u , v` we may buy the vector  

```
x u – x v      (cost w)
```

and also its opposite `x v – x u`.  
If we buy several vectors, we may add them with any real coefficients.
For a set `S` of *target* basis vectors we need that for every `a , b ∈ S`

```
x a – x b               (1)
```

belongs to the linear span of the bought vectors.

--------------------------------------------------------------------

#### 1.   Graph interpretation  

`x u – x v` is the **oriented edge** `u → v`.  
If we have a (undirected) path  

```
a = p0 – p1 – … – pk = b
```

then  

```
x a – x b = (x p0 – x p1) + (x p1 – x p2) + … + (x pk‑1 – x pk)
```

i.e. the sum of the edge vectors of the path, therefore (1) is satisfied.

Conversely, any linear combination of edge vectors that yields `x a – x b`
uses only vertices from the connected component that contains `a` and `b`,
hence `a` and `b` must lie in the same component.

*Conclusion*  
A set of bought edges fulfills the requirement **iff** all target vertices are
connected in the undirected graph formed by these edges.

So we have to buy a cheapest set of edges that connects the given `t` terminals.
That is the **Steiner Tree Problem** in an undirected graph with `n ≤ 100`,
`|T| = t ≤ 10`.

--------------------------------------------------------------------

#### 2.   Steiner‑DP (classical DP over subsets of terminals)

For every subset `M` of terminals (`M` is a bitmask, `0 … 2^t‑1`) and every
vertex `v` we store  

```
dp[M][v] = minimum cost of a subgraph
           that connects all terminals of M
           and whose “root” (any vertex of the subgraph) is v
```

The answer is  

```
min_v dp[ALL][v]       where ALL = (1<<t)‑1
```

--------------------------------------------------------------------
**Initialisation**

For a single terminal `Ti` (`mask = 1<<i`) the cheapest way to have `v` as root
is the shortest path from `Ti` to `v` (maybe `v = Ti` itself).
Instead of pre‑computing all‑pairs shortest paths we simply put  

```
dp[1<<i][Ti] = 0          (all other entries stay INF)
```

and later run Dijkstra to spread the distances.

--------------------------------------------------------------------
**Transition – merging two disjoint subsets**

If `M = A ∪ B` with `A ∩ B = ∅` then a tree for `M` with root `v`
can be obtained by taking a tree for `A` rooted at `v`
and a tree for `B` also rooted at `v` and joining them at `v`.

```
dp[M][v] = min over A⊂M  ( dp[A][v] + dp[M\A][v] )
```

The loop iterates over all proper non‑empty sub‑masks `A` of `M`.  
Total number of sub‑mask pairs over all masks is `O(3^t)` ( ≤ 59049 ),
trivial for `t ≤ 10`.

--------------------------------------------------------------------
**Transition – using an edge**

After the merging step we know the cheapest cost of a *tree* for `M`
that ends at each vertex.  
From such a tree we may walk along an edge `(u, v, w)` and obtain a tree
rooted at `v` with additional cost `w`.  
Thus we have to compute **shortest paths** in the original graph with the
current `dp[M][*]` as starting distances.

That is exactly Dijkstra with many sources: push all vertices whose current
distance is finite into a priority queue.

Running Dijkstra for every mask costs  

```
O( 2^t · ( n log n + m log n ) )    ≤   1024 · ( 5000 log 100 )
```

which is easily inside the limits.

--------------------------------------------------------------------
**Algorithm**

```
read input, build adjacency list
terminals[]  (0‑based indices)
FULL = (1<<t) - 1
INF = 10^18
dp[mask][v] = INF
for i = 0 .. t-1:
        dp[1<<i][ terminals[i] ] = 0

for mask = 1 .. FULL:
        # 1) combine two smaller subsets
        sub = (mask-1) & mask
        while sub:
                other = mask ^ sub
                for v in 0..n-1:
                        cand = dp[sub][v] + dp[other][v]
                        if cand < dp[mask][v]:  dp[mask][v] = cand
                sub = (sub-1) & mask          # next proper sub‑mask

        # 2) propagate through graph edges (multi‑source Dijkstra)
        run Dijkstra with initial distances dp[mask][*]

answer = min_v dp[FULL][v]
print answer
```

Complexities  

*Time*   `O( 3^t · n + 2^t · (n+m) log n )`  
          ≤ `5·10^7` elementary operations – well below 5 s.  

*Memory* `O( 2^t · n )`  ≤ 102 400 integers.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs the minimum possible total cost.

---

##### Lemma 1  
For any set of bought edges `E'` the following statements are equivalent  

1. For every two terminals `a, b` the vector `x a – x b` is in the span of
   `{ x u – x v | (u,v) ∈ E' }`.
2. In the undirected graph `(V, E')` all terminals belong to the same
   connected component.

**Proof.**  

*1 ⇒ 2* : Take terminals `a, b`. By 1 there exists a linear combination of
edge vectors equal to `x a – x b`. Replace each edge vector by its
undirected edge; the combination can be rewritten as a sum of edges along
some walk from `a` to `b`. Hence a walk (and therefore a path) exists,
so `a` and `b` are connected.

*2 ⇒ 1* : If a path `a = p0 – p1 – … – pk = b` exists using edges from `E'`,
the sum of its edge vectors equals `x a – x b`. ∎



##### Lemma 2  
For every mask `M` and vertex `v` after the Dijkstra step of the algorithm

```
dp[M][v] = minimum possible cost of a subgraph that
           (i) connects all terminals of M,
           (ii) contains vertex v,
           (iii) v may be any vertex of the subgraph (not necessarily a leaf).
```

**Proof by induction over the order of processing masks.**

*Base (`|M| = 1`).*  
`dp[1<<i][Ti] = 0`. Dijkstra spreads the distance from `Ti` to every vertex,
thereby setting `dp[1<<i][v]` to the length of the cheapest `Ti‑v` path,
which is precisely the cheapest subgraph connecting the single terminal
and containing `v`.

*Induction step.*  
Assume the statement holds for all proper non‑empty sub‑masks of `M`.  
During the merging loop we consider a split `M = A ∪ B` (`A,B` non‑empty,
disjoint) and compute for each `v`

```
candidate = dp[A][v] + dp[B][v]
```

By the induction hypothesis each term is the cheapest cost of a subgraph
connecting the respective terminals and containing `v`. Their union is a
subgraph that connects all terminals of `M` and contains `v`; its cost is
the sum, therefore the minimum over all splits yields the cheapest such
subgraph **that is already rooted at `v`**.

Afterwards Dijkstra relaxes along edges, i.e. it may extend the subgraph
by an arbitrary path starting at `v`. Consequently the final value
`dp[M][v]` equals the cheapest possible cost of *any* subgraph that
contains `v` and connects all terminals of `M`. ∎



##### Lemma 3  
For the full mask `ALL` we have  

```
min_v dp[ALL][v] = minimum cost of a Steiner tree that connects all terminals.
```

**Proof.**  
By Lemma&nbsp;2 each `dp[ALL][v]` is the cheapest cost of a subgraph that
connects all terminals **and** contains vertex `v`.  
Removing vertices and edges that are not needed while keeping connectivity
cannot increase the cost, therefore an optimal subgraph may be assumed to be
a tree (a Steiner tree). The minimum over all possible root vertices `v`
is exactly the optimum Steiner tree cost. ∎



##### Lemma 4  
The algorithm never assigns to any `dp[mask][v]` a value larger than the
optimal one for that pair.

**Proof.**  
Both operations used to improve `dp` (splitting a mask and Dijkstra)
are *relaxations*: they only replace a value by a smaller feasible cost.
Since the initial values are feasible (0 for a terminal alone) and every
relaxation keeps feasibility, the invariant “`dp[mask][v]` is never larger
than the optimum” holds throughout the execution. ∎



##### Lemma 5  
When the algorithm finishes, for every mask and vertex the entry
`dp[mask][v]` equals the optimum value described in Lemma&nbsp;2.

**Proof.**  
Consider any mask `M`. After the merging loop all possibilities of
splitting `M` into two non‑empty sub‑masks have been examined,
so the best tree that is already rooted at `v` is known.
Running Dijkstra on this exact set of source distances computes **all**
shortest paths from any vertex of such a tree to any other vertex,
therefore none of the feasible subgraphs is missed and the distance becomes
optimal.  
Processing masks in increasing order guarantees that when a mask is handled,
all its proper sub‑masks already store optimal values, which is required for
the merging step. Hence optimality holds for every mask. ∎



##### Theorem  
The algorithm outputs the minimum total procurement cost satisfying the
requirement of the problem.

**Proof.**  
By Lemma&nbsp;1 the problem is equivalent to finding a minimum‑cost edge set
that connects all terminals – a Steiner tree.  
Lemma&nbsp;3 states that `min_v dp[ALL][v]` equals the optimal Steiner tree
cost. Lemma&nbsp;5 guarantees that after the algorithm finishes each
`dp[ALL][v]` indeed holds that optimum value. Consequently the printed number
is exactly the minimum possible total cost. ∎

#### 4.   Reference Implementation  (Python 3)

```python
import sys
import heapq

INF = 10 ** 18

def dijkstra(dist, adj):
    """multi‑source Dijkstra, updates dist in place"""
    n = len(dist)
    heap = [(dist[v], v) for v in range(n) if dist[v] < INF]
    heapq.heapify(heap)
    while heap:
        d, u = heapq.heappop(heap)
        if d != dist[u]:
            continue
        for v, w in adj[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(heap, (nd, v))

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))

    terminals = [int(next(it)) - 1 for _ in range(t)]

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        adj[u].append((v, w))
        adj[v].append((u, w))

    FULL = (1 << t) - 1
    dp = [[INF] * n for _ in range(FULL + 1)]

    for i, node in enumerate(terminals):
        dp[1 << i][node] = 0

    # process all masks
    for mask in range(1, FULL + 1):
        # combine two proper sub‑masks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            # both sub and other are non‑empty
            for v in range(n):
                cand = dp[sub][v] + dp[other][v]
                if cand < dp[mask][v]:
                    dp[mask][v] = cand
            sub = (sub - 1) & mask

        # shortest‑path relaxation
        dijkstra(dp[mask], adj)

    ans = min(dp[FULL])
    print(ans)

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input / output format.
