<STATEMENT>
# Problem A — Boolean Matrix Closure

Time limit: 5 s
Memory limit: 256 MB

## Description

You are tasked with designing a sparse $n \times n$ symmetric boolean matrix $M$. Initially, $M$ is the $n \times n$ identity matrix (all diagonal entries $M_{i,i}$ are 1, and all off-diagonal entries are 0).

You are provided a catalog of $m$ available modifications. Each modification, which can be purchased for a specified cost $w$, sets both off-diagonal entries $M_{u,v}$ and $M_{v,u}$ to 1. 

Let $M^*$ denote the transitive closure of $M$. Formally, $M^*$ is the boolean matrix $M^n$ (the product of $n$ copies of $M$), computed using standard matrix multiplication rules where scalar addition is replaced by logical OR, and scalar multiplication is replaced by logical AND.

You are given a specific set of $t$ target indices. Your objective is to select a subset of the available modifications such that in the resulting closure matrix $M^*$, every entry $M^*_{i,j}$ where both $i$ and $j$ are target indices evaluates to 1. 

Modifications involving indices outside the target set may be purchased if they help achieve this objective at a lower total cost. Calculate the minimum sum of costs for the selected subset of modifications required to satisfy the condition.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ t ≤ 10). The integer **t** is the number of target indices.
The second line provides **t** distinct integers representing the target indices.
The subsequent **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), describing a modification that sets $M_{u,v} = 1$ and $M_{v,u} = 1$ for a cost of **w**.
It is guaranteed that a valid selection of modifications exists to satisfy the condition.

## Output

Print a single integer: the minimum total cost to satisfy the condition.

<RATIONALE>
The problem has been completely stripped of graph and network terminology (nodes, edges, connections, synchronization, paths) and recast into the domain of linear algebra and boolean matrices. The operations and the goal condition (transitive closure $M^n$ evaluating to 1 for all pairs in a target set) are mathematically identical to finding a Steiner Tree. This forces the model to independently recognize that boolean matrix closure is equivalent to graph reachability before it can deploy the necessary subset dynamic programming algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The boolean matrix logic exactly mirrors graph connectivity, where each modification acts as an undirected edge; thus, the minimum cost to ensure $M^*_{i,j}=1$ for all target pairs is identical to finding the minimum weight connected subgraph containing all targets.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the Minimum Steiner Tree problem on graphs, preserving its NP-complete complexity class (solvable via Dreyfus-Wagner DP in this bounded instance).
</PRESERVED_CLASS>
<RISK>
A model might misinterpret "the product of $n$ copies of $M$" as requiring exactly paths of length $n$, but the explicit inclusion of the identity matrix ($M_{i,i}=1$) mathematically guarantees that $M^n$ correctly represents paths of length *up to* $n$, safely avoiding this ambiguity.
</RISK>
