# Problem A — Algebraic Variable Entanglement

Time limit: 5 s   Memory limit: 256 MB

## Description

You are designing a system of homogeneous linear equations over the finite field GF(2) involving $n$ variables, $z_1, z_2, \ldots, z_n$. Within this system, a specific set of $t$ variables are designated as priority variables.

You are provided with a catalog of $m$ available equation constraints. Each catalog entry allows you to enforce a specific constraint of the form $z_u + z_v = 0$ (which, over GF(2), is equivalent to $z_u = z_v$), and comes with a specified procurement expense.

Your objective is to select a subset of these constraints to form a linear system. Let $M z = 0$ be the system formed by your selected constraints. You must ensure that in *every* valid solution vector $z \in \text{GF}(2)^n$ to this system, all priority variables are perfectly entangled—meaning $z_x = z_y$ for every pair of priority variables $x$ and $y$. 

You may select constraints that involve non-priority variables; these impose auxiliary restrictions on the system's null space, which can indirectly force the priority variables to match.

Calculate the minimum total expense required to procure a subset of constraints that restricts the solution space in this required manner.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ t ≤ 10). The integer **t** is the number of priority variables.
The second line provides **t** distinct integers representing the indices of these priority variables.
The subsequent **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), describing a catalog entry that provides the constraint $z_u + z_v = 0$ for a procurement expense of **w**.
It is guaranteed that the available catalog options are sufficient to enforce the required entanglement of the priority variables.

## Output

Print a single integer: the minimum total expense to satisfy the condition for all priority variables.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, procuring the constraints $z_1 + z_4 = 0$, $z_2 + z_4 = 0$, and $z_3 + z_4 = 0$ incurs a total expense of 1+1+1 = 3. In any solution $z$ satisfying these three equations, we have $z_1 = z_4$, $z_2 = z_4$, and $z_3 = z_4$, which implies $z_1 = z_2 = z_3$. Consequently, the condition is fulfilled for the priority variables 1, 2, and 3. This is more economical than selecting a subset of constraints that do not involve variable 4 (which would cost at least 4).

In Example 3, there is only a single priority variable. The requirement that $z_x = z_y$ for every pair of priority variables is vacuously satisfied by an empty subset of constraints, resulting in a cost of 0.

<RATIONALE>
I transformed the problem from a vector spanning condition to a constraint satisfaction problem over the null space of a GF(2) matrix. Instead of asking to span vectors using intermediate components, it asks to select homogeneous equations $z_u + z_v = 0$ such that in all valid solutions, the priority variables are forced to be equal. This completely removes the affordance of graph connectivity and path-finding terminology, forcing the model to independently deduce that transitive equivalence constraints form a graph and the goal is to connect all priority variables in a single component.
</RATIONALE>
<PRESERVED_ANSWER>
The constraint that $z_x = z_y$ in all solutions to the selected equations holds if and only if all priority variables are in the same transitive equivalence class (i.e., the same connected component of the graph formed by the chosen equations), making the required optimal subset exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the minimum-weight Steiner Tree problem on a graph, which is NP-complete, with the exact same variables acting as terminals and the same equations acting as edges.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "every valid solution vector $z \in \text{GF}(2)^n$" as requiring the system to have exactly one unique solution, although the phrase clearly specifies "every valid solution", implying the null space can have multiple vectors.
</RISK>
