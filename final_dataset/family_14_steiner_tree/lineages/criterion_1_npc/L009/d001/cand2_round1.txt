# Problem A — Cabling the Required Sites

Time limit: 5 s   Memory limit: 256 MB

## Description

A university is overhauling its network infrastructure. The process involves surveying the grounds, designing the layout, and finally deploying the hardware.

In the surveying phase, engineers identified **n** distinct sites across the campus, labeled with integers starting from 1. They also evaluated various potential cabling connections between specific pairs of sites, each carrying a specific installation cost.

Your responsibility is to handle the design phase. A specific subset of **t** sites are designated as critical facilities. Your objective is to ensure that all critical facilities are linked together within a single network. You may achieve this by connecting them directly, or by routing the network through any of the remaining non-critical sites, which act as optional relays. You are not required to connect relay sites unless they are useful for reducing the overall expense.

You must select a combination of cabling connections that successfully links all critical facilities while keeping the total cost as low as possible. Calculate and report this minimum total cost, which the installation crew will subsequently use to request funding and lay down the physical wires.

## Input

The first line contains three integers **n**, **m**, and **t**.
The number of sites **n** is strictly positive. As the campus sites map onto a 10 by 10 coordinate grid with at most one site per cell, **n** is naturally bounded.
The number of critical sites **t** is at least one. Each critical site must be assigned its own dedicated security supervisor from a roster of exactly 10 available supervisors, which limits the maximum value of **t**.
The integer **m** represents the number of available cabling connections, ranging from zero up to the maximum possible number of unique pairs of sites.
The second line contains **t** distinct integers: the IDs of the critical sites (which are numbered from 1 to **n**).
Each of the next **m** lines contains three integers **u**, **v**, and **w**, representing a cabling connection joining site **u** and site **v** (where **u** and **v** are distinct valid site IDs). The connection cost **w** is a strictly positive integer; because the maximum grant for any single connection is one million, **w** is capped at exactly that amount.
The provided cabling connections are sufficient to link all critical sites.

## Output

Print a single integer: the minimum total cost to connect all critical facilities.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, routing the network through the optional relay site 4 (which costs 1+1+1 = 3) is cheaper than joining the three critical sites directly (which would cost 4). In Example 3, there is only one critical site, so no cabling is needed.
