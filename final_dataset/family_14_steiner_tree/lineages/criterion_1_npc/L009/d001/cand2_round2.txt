# Problem A — Upgrading the Campus Network

Time limit: 5 s   Memory limit: 256 MB

## Description

The university is upgrading its campus network infrastructure, a process divided into surveying, planning, and installation. 

During the surveying stage, engineers mapped out the campus and identified **n** locations. They also determined that certain pairs of these locations can be linked by a fiber-optic cable, with each potential connection having a specific installation cost. 

Your responsibility is the planning stage. A specific subset of **t** locations are designated as **critical** and must be integrated into a single unified continuous network. You can achieve this by selecting a combination of the available cable connections. The other locations on campus are optional relays; you can choose to route your network through them if it results in a cheaper overall design, or you can bypass them entirely. Your goal is to select a collection of cable connections that minimizes the total installation cost while ensuring every critical location is connected to the others. 

Finally, during the installation stage, technicians will secure the budget based on your calculated minimum cost and physically deploy the cables along your selected routes.

## Input

The first line contains three integers **n**, **m**, and **t**.
The number of surveyed locations **n** is between 1 and the port capacity of the central switch (which is 100).
The number of proposed cable connections **m** is between 0 and the maximum possible number of distinct pairs, evaluated as n·(n−1)/2.
The number of critical locations **t** is between 1 and the number of available high-priority transceivers (which is 10).

The second line contains **t** distinct integers: the ids of the critical locations.

Each of the next **m** lines contains three integers **u**, **v**, and **w**: a cable connection option joining locations **u** and **v** at cost **w**.
Each proposed connection joins two distinct locations (u ≠ v, with IDs ranging from 1 to n) and has an installation cost **w** between 1 and the university's maximum budget per link of 1000000.

The provided cable connections are enough to connect all critical locations.

## Output

Print a single integer: the minimum total cost to connect all critical locations.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, routing cables through the optional relay location 4 (costs 1+1+1 = 3) is cheaper than joining the three critical locations directly (which would cost 4). In Example 3 there is only one critical location, so no cables are needed.
