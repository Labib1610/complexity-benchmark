<STATEMENT>
# Frequency Synchronization

Time limit: 2 s   Memory limit: 256 MB

## Description

An array of $n$ independent signal generators is deployed. A subset of $t$ of these generators are designated as **Primary Emitters**.

To coordinate the emitters, you can install phase-lock modules. There are $m$ potential phase-lock modules available. Each module forces two specific generators to operate at the exact same frequency, and consumes a certain amount of power to maintain. The available modules were designed such that if all were installed, every generator in the array would be synchronized to the same frequency. Furthermore, the design is strictly non-redundant: exactly $m = n - 1$ modules are available, meaning there are no overlapping synchronization dependencies between any pair of generators.

You must choose a subset of these phase-lock modules to activate. In the configuration containing only your activated modules, all $t$ Primary Emitters must be forced to operate at the same frequency (meaning any Primary Emitter is synchronized with any other Primary Emitter, possibly through a sequence of other intermediate synchronized generators). Modules that are not activated consume no power and provide no synchronization.

Your objective is to determine the minimum total power consumption required to activate a valid subset of modules that synchronizes all Primary Emitters.

## Input

The first line contains three integers: $n$, $m$, and $t$.
- $n$ is the total number of signal generators. The array requires at least one generator, and is controlled by a registry that limits the maximum possible number of generators to exactly 200000.
- $m$ is the number of available modules, which is fixed by the non-redundant design to be exactly one less than the number of generators.
- $t$ is the number of Primary Emitters. The system requires at least one Primary Emitter, and at most, every generator in the array can be designated as one.

The second line contains $t$ distinct integers: the identifiers of the Primary Emitters (from 1 to $n$).

Each of the next $m$ lines details an available phase-lock module with three integers: $u$, $v$, and $w$.
- $u$ and $v$ are distinct generator identifiers (from 1 to $n$) coupled by the module.
- $w$ is the power consumption required to keep this module active. This is a positive integer, restricted by a hardware safety limit to not exceed 1000000.

These $m$ lines form the exact design described above, ensuring a single sequence of dependencies between any two generators.

## Output

Print a single integer: the minimum total power consumption required to synchronize all Primary Emitters using only the activated modules.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the Primary Emitters 1 and 4 can only be synchronized with each other by coupling through generators 2 and 3, so all three modules (5 + 1 + 2 = 8) must be activated. In Example 2, there is only one Primary Emitter. With one required generator, an empty set of modules is valid, so the minimum power consumption is 0.

<RATIONALE>
To bypass the models' reliance on tree-traversal templates, the problem domain was entirely shifted from network routing to physical frequency synchronization. All explicit graph terminology (reachable, route, path, undirected) was removed, and bounds were expressed indirectly through registry and hardware limits according to strategy S07. Models must now deduce that the non-redundant synchronization dependencies form a tree structure mathematically, rather than having the concept handed to them via standard graph keywords.
</RATIONALE>
<PRESERVED_ANSWER>
The structural constraints (m = n - 1, full synchronizability) perfectly preserve the mathematical properties of a tree, meaning the minimal valid subset of modules corresponds exactly to the unique Steiner tree connecting the required nodes, yielding identical costs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains finding the minimum Steiner tree on a given tree, which is solvable in O(n) time and remains firmly in P.
</PRESERVED_CLASS>
<RISK>
A reader might misinterpret "sequence of dependencies" as requiring a linear chain rather than a branching structure, though the phrase "possibly through a sequence of other intermediate synchronized generators" accurately describes paths in a tree without implying the global structure is a single line.
</RISK>
