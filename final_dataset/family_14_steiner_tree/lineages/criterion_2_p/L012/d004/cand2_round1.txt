<STATEMENT>
# Equivalence Deduction

Time limit: 2 s   Memory limit: 256 MB

## Description

An automated reasoning engine is analyzing a system of $n$ integer variables. 

You are provided with a knowledge base of $m$ potential equivalence assertions. An assertion between variable $u$ and variable $v$ requires $w$ computational resources to process. When processed, it introduces the strict axiom that $u = v$ into the reasoning engine.

The knowledge base contains exactly $m = n - 1$ such assertions. It is guaranteed that these assertions are logically independent (no assertion can be deduced from any combination of the others) and globally complete (processing all $m$ assertions would successfully prove that all $n$ variables share the exact same value).

You are given a specific query involving $t$ target variables. You must select a subset of the available assertions to process such that the engine can formally deduce that all $t$ target variables are equal to each other. The deduction must hold true strictly based on the selected assertions, using the transitive property of equality.

Your objective is to determine the minimum total computational resource cost required to process a valid subset of assertions that satisfies this query.

## Input

The first line contains three integers: $n$, $m$, and $t$.
- $n$ is the total number of variables in the system. The system contains at least 1 variable and at most 200000.
- $m$ is the number of available assertions, which is exactly $n - 1$.
- $t$ is the number of target variables in the query, which is at least 1 and at most $n$.

The second line contains $t$ distinct integers: the identifiers of the target variables (from 1 to $n$).

Each of the next $m$ lines details an available assertion with three integers: $u$, $v$, and $w$.
- $u$ and $v$ are the distinct variable identifiers (from 1 to $n$) equated by the assertion.
- $w$ is the computational resource cost to process this assertion. This cost is a positive integer not exceeding 1000000.

These $m$ lines form the exact logical structure described above, guaranteeing a single valid deduction chain between any two variables.

## Output

Print a single integer: the minimum total computational resource cost required to process a subset of assertions that successfully proves all $t$ target variables are equal.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the query requires proving variable 1 equals variable 4. The only way to deduce this is by chaining the available assertions $1 = 2$, $2 = 3$, and $3 = 4$. Therefore, all three assertions must be processed, requiring a total cost of 5 + 1 + 2 = 8.

In Example 2, there is only one target variable. A single variable is trivially equal to itself, requiring no axioms to be processed, so the minimum cost is 0.
