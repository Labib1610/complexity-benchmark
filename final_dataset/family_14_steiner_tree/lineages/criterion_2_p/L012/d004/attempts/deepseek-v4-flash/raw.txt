We are given a tree (since \( m = n-1 \) and there’s exactly one path between any two nodes).  
We need to connect all target nodes in this tree using a subset of edges with minimum total cost.  

This is equivalent to finding the **minimum Steiner tree** for the set of target nodes in a tree, which is simply the union of all edges on paths between target nodes.  

The minimal cost is the sum of weights of all edges that lie on the path between any two target nodes.  

We can compute this by:  
1. Root the tree at any node.  
2. For each edge, if removing it splits the tree such that both sides contain at least one target node, then that edge must be included.  
3. Sum the weights of such edges.  

We can do this with a DFS to count target nodes in each subtree.  

Here’s the implementation:  

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    targets = set(map(int, input().split()))
    
    adj = [[] for _ in range(n+1)]
    edges = []
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
        edges.append((u, v, w))
    
    # DFS to count targets in subtree
    parent = [0]*(n+1)
    parent_edge_weight = [0]*(n+1)
    order = []
    stack = [1]
    parent[1] = -1
    while stack:
        u = stack.pop()
        order.append(u)
        for v, w in adj[u]:
            if v != parent[u]:
                parent[v] = u
                parent_edge_weight[v] = w
                stack.append(v)
    
    target_count = [0]*(n+1)
    for node in targets:
        target_count[node] = 1
    
    total_cost = 0
    for u in reversed(order):
        if u != 1:
            if target_count[u] > 0 and (t - target_count[u]) > 0:
                total_cost += parent_edge_weight[u]
            if parent[u] != -1:
                target_count[parent[u]] += target_count[u]
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
