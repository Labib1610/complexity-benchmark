<STATEMENT>
# Corporate Pneumatic Network

Time limit: 2 s   Memory limit: 256 MB

## Description

A massive corporate headquarters consists of $n$ departments. Certain pairs of departments are connected by direct pneumatic tube lines. Each tube line requires a specific financial cost to upgrade to a high-speed secure standard. 

Among the $n$ departments, exactly $t$ of them are designated as **Auditing Offices**. 

The given tube lines connect all departments, there are exactly $n - 1$ lines in total, and between any two departments there is exactly one simple route of tube lines. 

Your objective is to choose a subset of tube lines to upgrade such that all $t$ Auditing Offices are interconnected using only the chosen lines. This means for any two Auditing Offices, there must exist a route between them consisting exclusively of upgraded lines. These routes may pass through other departments that are not Auditing Offices, but non-upgraded lines do not count toward connectivity.

Find the minimum total upgrade cost required to achieve this. If there is only one Auditing Office ($t = 1$), no lines need to be upgraded, and the cost is 0.

## Input

The first line contains three integers: $n$, $m$, and $t$.
- $n$ ($1 \le n \le 200000$) is the total number of departments.
- $m$ is the number of tube lines, which is always exactly $n - 1$.
- $t$ ($1 \le t \le n$) is the number of Auditing Offices.

The second line contains $t$ distinct integers: the identifiers of the Auditing Offices (each between 1 and $n$).

Each of the next $m$ lines details a tube line with three integers: $u$, $v$, and $w$.
- $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$) are the two distinct departments connected by the tube line.
- $w$ ($1 \le w \le 1000000$) is the financial cost to upgrade this tube line.

## Output

Print a single integer: the minimum total upgrade cost required to ensure all Auditing Offices are interconnected via upgraded lines.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the Auditing Offices 1 and 4 can only communicate by routing through departments 2 and 3, so all three tube lines (5 + 1 + 2 = 8) must be upgraded. In Example 2, there is only one Auditing Office, so no tube lines need to be upgraded.
