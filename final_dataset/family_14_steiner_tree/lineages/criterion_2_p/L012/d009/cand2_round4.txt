<STATEMENT>
# Commodity Exchange Regulations

Time limit: 2 s   Memory limit: 256 MB

## Description

There are $n$ distinct commodities, indexed from $1$ to $n$. A specific subset of $t$ commodities are designated as benchmark commodities.

You are provided with a set of $m$ bilateral exchange regulations. Each regulation permits direct exchange between two distinct commodities $u$ and $v$, and requires a specific activation cost $w$ to be included in your active set. 

The complete set of available regulations is connected and contains exactly $m = n - 1$ regulations, meaning there is exactly one valid sequence of exchanges (route) between any two commodities.

You must select a subset of these regulations to activate. Your selection must satisfy the following condition: any benchmark commodity must be exchangeable for any other benchmark commodity using only a sequence of activated regulations. (When $t=1$, this condition imposes no restrictions, as no pairs exist).

Your objective is to determine the minimum total cost required to activate a valid subset of regulations meeting this condition.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le n \le 200,000$, $m = n - 1$, $1 \le t \le n$).
- $n$ is the total number of commodities.
- $m$ is the number of available exchange regulations.
- $t$ is the number of benchmark commodities.

The second line contains $t$ distinct integers: the indices of the benchmark commodities (from $1$ to $n$).

Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u \le n$, $1 \le v \le n$, $u \ne v$, $1 \le w \le 1,000,000$).
- $u$ and $v$ are the distinct commodities connected by the regulation.
- $w$ is the cost to activate this regulation.

## Output

Print a single integer: the minimum total cost required to activate a subset of regulations that ensures all benchmark commodities can be mutually exchanged.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the benchmark commodities are 1 and 4. The required exchange between 1 and 4 can only be achieved by activating all three regulations, since the sequence of exchanges is (1,2), (2,3), and (3,4). The minimum cost is therefore 5 + 1 + 2 = 8. 

In Example 2, there is only one benchmark commodity. Since no pairs of benchmark commodities exist, no regulations need to be activated, resulting in a minimum cost of 0.
</STATEMENT>
<RATIONALE>
The problem was reframed from linear algebra subspace spanning to a network of commodity exchange regulations. By mapping the zero-sum subspace basis vectors to edges in a tree and describing the linear combination requirement as mutual exchangeability, models must independently deduce that the optimal solution is a Steiner tree on the given tree topology. The numeric bounds were explicitly restored in inequality format to meet strict parser requirements.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that target vectors must be spanned is mathematically equivalent to requiring that the target commodities are in the same connected component of the chosen subgraph, so the minimum cost subset of edges is identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying graph is still a tree (connected with n-1 edges) and the task remains finding the unique minimal subtree connecting a set of target nodes, keeping it solvable in linear time.
</PRESERVED_CLASS>
