<METHOD_NAME>Dual Constraint Equivalence Network</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the linear algebra "difference vector spanning" framing with its dual: a system of equality constraints x_u = x_v. By framing the spanning condition as logical necessity of equalities and explicitly describing the network as a connected set of m=n-1 links, it preserves the tree property perfectly without using the word "tree" or vector subspaces. This defeats solvers that pattern-match on "difference vector" or "subspace spanning" to instantly trigger tree algorithms, forcing them to genuinely recognize that m=n-1 connected links forms a unique-path topology.</METHOD_DESCRIPTION>

<STATEMENT>
# Variable Equivalence Network

Time limit: 2 s   Memory limit: 256 MB

## Description

You are working with a system of $n$ real variables $x_1, x_2, \dots, x_n$. A specific subset of $t$ indices from $1$ to $n$ are designated as **Target Variables**.

You are provided with a collection of $m$ candidate equivalence constraints. Each candidate constraint is defined by two distinct indices $u$ and $v$, and enforces the equality $x_u = x_v$. Including a candidate constraint in your active set incurs a specific scalar cost.

Each candidate constraint can be viewed as an undirected link between the variables $u$ and $v$. The complete collection of $m$ available candidate constraints is sufficient to link all $n$ variables into a single fully connected network. Furthermore, this collection contains exactly $m = n - 1$ constraints.

You must select a subset of these candidate constraints. Your selection must satisfy the following condition: for any pair of Target Variables $a$ and $b$, the equality $x_a = x_b$ must be a logical necessity of your selected constraints. This is equivalent to requiring that all Target Variables are structurally linked together within the same connected component of your selected subset. (When $t=1$, this condition is always satisfied automatically, as no distinct pairs exist).

Your objective is to determine the minimum total cost required to select a valid subset of candidate constraints meeting this condition.

## Input

The first line contains three integers: $n$, $m$, and $t$.
- $n$ is the number of variables in the system. There is at least 1 variable and at most 200,000.
- $m$ is the number of available candidate constraints, which is exactly $n - 1$.
- $t$ is the number of Target Variables, which is at least 1 and at most $n$.

The second line contains $t$ distinct integers: the indices of the Target Variables (from 1 to $n$).

Each of the next $m$ lines details an available candidate constraint with three integers: $u$, $v$, and $w$.
- $u$ and $v$ are the distinct indices (from 1 to $n$) defining the constraint $x_u = x_v$.
- $w$ is the cost to include this constraint. This cost is a positive integer not exceeding 1,000,000.

These $m$ lines form the exact structure described above, guaranteeing the full collection of links forms a single fully connected network.

## Output

Print a single integer: the minimum total cost required to ensure all required equalities between Target Variables are logically enforced by the selected subset.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the Target Variables are 1 and 4. The required equality $x_1 = x_4$ can only be logically enforced by including all three candidate constraints, since $x_1 = x_2$, $x_2 = x_3$, and $x_3 = x_4$ together imply $x_1 = x_4$. The minimum cost is therefore 5 + 1 + 2 = 8. 

In Example 2, there is only one Target Variable. With one Target Variable, no connectivity between distinct targets is required, so selecting no constraints yields a minimum cost of 0.
</STATEMENT>
<RATIONALE>
The linear algebraic framing ("difference vector spanning") has been replaced with its exact dual: a system of equality constraints $x_u = x_v$. By defining the requirement as the logical necessity of equalities and explicitly noting the equivalence to connected components, the problem's task remains unambiguous and operationally identical. This removes the "difference vector" and "subspace spanning" terminology that models used to instantly pattern-match the problem to a tree topology, forcing them to genuinely deduce that $m=n-1$ connected links forms a unique-path network without relying on surface-level keywords.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that $x_a = x_b$ is logically enforced by the subset is mathematically identical to $e_a - e_b$ being in the span of the selected difference vectors, so the minimum cost subset to achieve this is exactly the same for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure is still finding a minimum cost subset of edges to connect a set of terminals in a graph that is guaranteed to be a tree, which remains solvable in $O(n)$ time and is thus still in P.
</PRESERVED_CLASS>
