<STATEMENT>
# Logistical Path Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

A supply chain network consists of $n$ distribution hubs. Exactly $t$ of these hubs are designated as **Primary Hubs**.

The network designers have proposed $m$ potential transit corridors. Each corridor directly links two specific hubs. The proposed corridors are structured such that if all were activated, goods could be routed between any two hubs in the network. To minimize maintenance overhead, exactly $m = n - 1$ corridors have been proposed. This exact configuration ensures that there is exactly one valid sequence of corridors routing goods between any two hubs.

Activating a corridor requires an annual maintenance budget of $w$. You must select a subset of these corridors to activate. Your selection must satisfy the following condition: for every possible pair of Primary Hubs, the unique sequence of corridors that routes goods between them in the full proposed network must be entirely included in your activated subset.

Your objective is to determine the minimum total maintenance budget required to activate a valid subset of corridors that satisfies this pairwise routing condition.

## Input

The first line contains three integers: $n$, $m$, and $t$.
- $n$ is the total number of hubs. The network contains at least 1 hub and at most 200000.
- $m$ is the number of proposed corridors, which is exactly $n - 1$.
- $t$ is the number of Primary Hubs, which is at least 1 and at most $n$.

The second line contains $t$ distinct integers: the identifiers of the Primary Hubs (from 1 to $n$).

Each of the next $m$ lines details a proposed corridor with three integers: $u$, $v$, and $w$.
- $u$ and $v$ are distinct hub identifiers (from 1 to $n$) linked by the corridor.
- $w$ is the annual maintenance budget required to activate this corridor. This budget is a positive integer not exceeding 1000000.

These $m$ lines form the exact structural configuration described above, guaranteeing a single routing sequence between any two hubs.

## Output

Print a single integer: the minimum total maintenance budget required to activate a valid subset of corridors that satisfies the pairwise routing condition.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the Primary Hubs 1 and 4 have exactly one routing sequence between them in the full network, which passes through hubs 2 and 3. Therefore, all three corridors in this sequence (costs 5, 1, and 2, summing to 8) must be entirely included in the activated subset. 

In Example 2, there is only one Primary Hub. With only one required hub, there are no pairs of distinct Primary Hubs that need to be routed between each other, so the pairwise condition is vacuously satisfied without activating any corridors. The minimum cost is 0.

To defeat the remaining models, the objective has been reframed: instead of asking to "connect all targets" (which models reliably solve in $O(n)$ by finding the Steiner tree), it asks to include the specific, unique path between every possible pair of targets. A model that translates this literally will write an $O(t^2 \cdot n)$ pairwise path-finding loop and Time Out. To pass, the model must deduce that the union of all pairwise paths in a tree is equivalent to the minimal spanning subtree, and substitute the $O(n)$ algorithm.
