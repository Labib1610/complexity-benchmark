<METHOD_DESCRIPTION>Replaces the logical deduction tree with an algebraic system of squared differences. The model must recognize that forcing a sum of squares F(x) to be zero requires the selected terms to form a connected component spanning the critical indicators.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Quadratic Penalty Selection

Time limit: 2 s   Memory limit: 256 MB

## Description

A system state is defined by $n$ real variables $x_1, x_2, \dots, x_n$. Exactly $t$ of these variables are designated as **Critical Indicators**.

You are provided with a set of $m$ available penalty terms. Each term enforces equality between two specific variables and has the form $(x_u - x_v)^2$. Activating a penalty term incurs a specific computational cost. The complete set of $m$ available terms is sufficient to guarantee that if their sum is zero, then all $n$ variables must be equal. Furthermore, this set contains exactly $m = n - 1$ terms, the minimum number required to enforce this global state synchronization.

You must select a subset of these penalty terms to activate. Let $F(x)$ be the sum of your selected penalty terms. Your selection must satisfy the following condition: for any state vector $x$ such that $F(x) = 0$, all $t$ Critical Indicators must hold identical values. (If $t=1$, this condition is automatically satisfied).

Your objective is to determine the minimum total activation cost required to select a valid subset of penalty terms meeting this condition.

## Input

The first line contains three integers: $n$, $m$, and $t$.
- $n$ is the total number of variables. The system contains at least 1 variable and at most 200000.
- $m$ is the number of available penalty terms, which is exactly $n - 1$.
- $t$ is the number of Critical Indicators, which is at least 1 and at most $n$.

The second line contains $t$ distinct integers: the indices of the Critical Indicators (from 1 to $n$).

Each of the next $m$ lines details an available penalty term with three integers: $u$, $v$, and $w$.
- $u$ and $v$ are distinct variable indices (from 1 to $n$) linked by the term $(x_u - x_v)^2$.
- $w$ is the cost to activate this term. This cost is a positive integer not exceeding 1000000.

These $m$ lines form the exact structure described above, guaranteeing global synchronization when all terms are active.

## Output

Print a single integer: the minimum total activation cost required to ensure all Critical Indicators are equal whenever the sum of the selected penalty terms is zero.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the Critical Indicators 1 and 4 can only be forced to take identical values when $F(x)=0$ by activating all three penalty terms (costs 5 + 1 + 2 = 8). In Example 2, there is only one Critical Indicator. Since a single variable always equals itself, no penalty terms need to be activated, resulting in a minimum cost of 0.
</STATEMENT>
<RATIONALE>
I transformed the logical equivalence problem into an algebraic penalty minimization problem. The tree structure is implicitly encoded by stating that $n-1$ terms are sufficient to synchronize $n$ variables. The models must deduce that enforcing $F(x)=0$ over the critical indicators requires selecting a subset of terms corresponding to a connected subtree spanning those indicators.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that $F(x)=0$ forces the critical indicators to be equal is mathematically identical to requiring the selected assertions to form a deduction chain between the target variables, so the identical optimal subset is chosen.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains a tree with required vertices to be connected, meaning the problem is still solvable in $O(n)$ time using a tree traversal and subtree counts.
</PRESERVED_CLASS>
<RISK>
Models might fail to realize that $F(x)=0$ for a sum of squares implies each individual term is zero, causing them to doubt whether the problem maps exactly to connectivity.
</RISK>
