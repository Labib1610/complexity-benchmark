This shifts the domain from graph theory to linear algebra, forcing the model to recognize that the constraints form the incidence matrix of a tree.

<STATEMENT>
# Linear Subspace Restriction

Time limit: 2 s   Memory limit: 256 MB

## Description

A system state is represented as a vector $x = (x_1, x_2, \dots, x_n) \in \mathbb{R}^n$. Exactly $t$ of these dimensional indices are designated as **Critical Indicators**.

You are provided with a set of $m$ available linear constraints. Each constraint enforces an equality between two dimensions, $x_u = x_v$, and requires a specific activation cost. The coefficient vector for such a constraint has a $1$ at index $u$, a $-1$ at index $v$, and $0$ elsewhere.

The complete set consists of exactly $m = n - 1$ constraints. It is mathematically guaranteed that the $m$ coefficient vectors of these equations are linearly independent, and that the only vectors $x$ satisfying all $m$ equations simultaneously are those in the span of the all-ones vector (i.e., vectors where all $n$ components are identical).

You must select a subset of these constraints to activate. Let $V$ be the subspace of $\mathbb{R}^n$ consisting of all vectors $x$ that satisfy your selected constraints. Your selection must ensure that for every vector $x \in V$, the $t$ Critical Indicators all share the same value. (If $t=1$, this condition is trivially satisfied for any selection).

Your objective is to determine the minimum total activation cost required to select a valid subset of constraints that restricts the subspace $V$ in this manner.

## Input

The first line contains three integers: $n$, $m$, and $t$.
- $n$ is the dimension of the state vector. The system contains at least 1 dimension and at most 200000.
- $m$ is the number of available linear constraints, which is exactly $n - 1$.
- $t$ is the number of Critical Indicators, which is at least 1 and at most $n$.

The second line contains $t$ distinct integers: the indices of the Critical Indicators (from 1 to $n$).

Each of the next $m$ lines details an available constraint with three integers: $u$, $v$, and $w$.
- $u$ and $v$ are distinct indices (from 1 to $n$) linked by the constraint $x_u = x_v$.
- $w$ is the cost to activate this constraint. This cost is a positive integer not exceeding 1000000.

These $m$ lines form the exact algebraic structure described above, guaranteeing linear independence and a one-dimensional common nullspace.

## Output

Print a single integer: the minimum total activation cost required to ensure all Critical Indicators are equal for any vector in the resulting subspace $V$.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the Critical Indicators 1 and 4 are guaranteed to be equal for all vectors in $V$ only if all three constraints are activated (costs 5 + 1 + 2 = 8). In Example 2, there is only one Critical Indicator. Since a single dimension always equals itself, no constraints need to be activated, resulting in a minimum cost of 0.
</STATEMENT>
<RATIONALE>
The problem was translated from a network/graph framing to a linear algebra framing. The constraint $x_u = x_v$ and the guarantee of linear independence with a 1D nullspace mathematically define the incidence matrix of a spanning tree. This forces the model to bridge linear algebra and graph theory to realize it can solve the problem in $O(N)$ using a tree traversal, rather than attempting computationally heavy matrix operations.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that variables must be equal under the selected constraints is identical to the original requirement that variables are equal when the penalty function evaluates to zero, preserving all answers.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains exactly a tree, meaning the optimal solution is still the unique minimal subtree spanning the critical indicators, which is solvable in $O(N)$.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the linear algebra terminology and attempt to implement Gaussian elimination or matrix rank algorithms, which would lead to Time Limit Exceeded on $N=200000$.
</RISK>
