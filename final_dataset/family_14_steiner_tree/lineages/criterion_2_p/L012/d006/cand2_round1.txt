<STATEMENT>
# Quadratic Penalty Selection

Time limit: 2 s   Memory limit: 256 MB

## Description

A system state is represented by a vector $x \in \mathbb{R}^n$. Exactly $t$ coordinates of this vector are designated as **Critical Indicators**.

You are provided with a pool of $m$ available constraint vectors. Each constraint vector $q$ is defined by two indices $u$ and $v$, and takes the form $q = e_u - e_v$, where $e_i$ is the $i$-th standard basis vector of $\mathbb{R}^n$. Activating a constraint vector incurs a specific computational cost. 

The complete pool of $m$ available constraint vectors spans a subspace of dimension $n - 1$. This is the exact rank required so that if a vector $x$ is orthogonal to all $m$ constraint vectors, then all $n$ components of $x$ must be identical. The number of available constraint vectors is exactly $m = n - 1$.

You must select a subset of these constraint vectors to activate. Let $S$ be your selected subset, and define the quadratic form $F(x) = \sum_{q \in S} (q^T x)^2$. Your selection must satisfy the following condition: for any state vector $x$ such that $F(x) = 0$, the $t$ Critical Indicator coordinates of $x$ must all hold identical values. (If $t=1$, this condition is trivially satisfied).

Your objective is to determine the minimum total activation cost required to select a valid subset of constraint vectors meeting this condition.

## Input

The first line contains three integers: $n$, $m$, and $t$.
- $n$ is the dimension of the state vector (and the number of components). The dimension is at least 1 and at most 200000.
- $m$ is the number of available constraint vectors, which is exactly $n - 1$.
- $t$ is the number of Critical Indicators, which is at least 1 and at most $n$.

The second line contains $t$ distinct integers: the indices of the Critical Indicators (from 1 to $n$).

Each of the next $m$ lines details an available constraint vector with three integers: $u$, $v$, and $w$.
- $u$ and $v$ are distinct coordinate indices (from 1 to $n$) defining the vector $e_u - e_v$.
- $w$ is the cost to activate this constraint vector. This cost is a positive integer not exceeding 1000000.

These $m$ lines form the exact structure described above, guaranteeing a rank of $n - 1$ when all are active.

## Output

Print a single integer: the minimum total activation cost required to ensure all Critical Indicators are equal whenever the quadratic form $F(x)$ evaluates to zero.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the Critical Indicators are coordinates 1 and 4. We want $x_1 = x_4$ whenever $F(x) = 0$. This condition can only be forced by activating all three constraint vectors, which means $S$ contains $e_1 - e_2$, $e_2 - e_3$, and $e_3 - e_4$. The total cost is $5 + 1 + 2 = 8$. 
In Example 2, there is only one Critical Indicator. Since a single coordinate always equals itself, no constraint vectors need to be activated, resulting in a minimum cost of 0.

<RATIONALE>
I replaced the explicit variable-equality and graph-theoretic phrasing with linear algebra terminology (standard basis vectors, orthogonality, quadratic forms, and matrix rank). This forces the model to mathematically deduce that $F(x)=0 \iff q^T x = 0 \iff x_u = x_v$, and that a rank of $n-1$ for $n-1$ vectors implies a tree structure, preventing it from relying on surface-level keywords to trigger a tree traversal template.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $F(x) = 0$ evaluates to $\sum (x_u - x_v)^2 = 0$, which is mathematically equivalent to $x_u = x_v$ for all selected pairs; thus the selected subset must still form a connected component containing all critical indicators.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure is still a tree (since $m=n-1$ vectors spanning an $(n-1)$-dimensional subspace correspond to an acyclic connected graph), meaning the minimal valid subset is the unique minimal spanning subtree, keeping the $O(n)$ time complexity unchanged.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the quadratic form $F(x)$ as requiring a continuous numerical optimization or matrix factorization approach rather than a discrete combinatorial one, though the logical equivalence $F(x)=0 \iff x_u=x_v$ is mathematically unambiguous.
</RISK>
