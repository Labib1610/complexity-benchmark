<STATEMENT>
# Document Routing Consolidation

Time limit: 2 s   Memory limit: 256 MB

## Description

A corporate headquarters consists of $n$ departments. Exactly $t$ of these departments are designated as **Auditing Offices**.

The headquarters has a legacy network of $m$ undirected pneumatic tube lines, each connecting a pair of departments. The layout of these available lines is constrained: there are exactly $m = n - 1$ lines in total. The network might be fragmented into disconnected components, and some of these components could contain cycles. However, it is guaranteed that all $t$ Auditing Offices are located within a single connected component, and to ensure predictable routing, this specific component contains no cycles (meaning there is exactly one simple path of lines between any two departments within it).

Each line requires a specific maintenance budget to remain operational. You must select a subset of these lines to keep active. In the network containing only your selected lines, all $t$ Auditing Offices must be interconnected (meaning any Auditing Office can route documents to any other Auditing Office, possibly passing through other intermediate departments). Lines that are not selected are decommissioned and provide no connectivity.

Your objective is to determine the minimum total maintenance budget required to select a valid subset of lines.

## Input

The first line of the document contains three integers: $n$, $m$, and $t$.
- $n$ is the total number of departments. The headquarters contains at least 1 department and at most 200000.
- $m$ is the number of available lines, which is exactly $n - 1$.
- $t$ is the number of Auditing Offices, which is at least 1 and at most $n$.

The second line contains $t$ distinct integers: the identifiers of the Auditing Offices (from 1 to $n$).

Each of the next $m$ lines details an available undirected line with three integers: $u$, $v$, and $w$.
- $u$ and $v$ are distinct department identifiers (from 1 to $n$) connected by the line.
- $w$ is the maintenance budget required to keep this line active. This cost is a positive integer not exceeding 1000000.

The available lines strictly follow the structural properties described above.

## Output

Print a single integer: the minimum total maintenance budget required to interconnect all Auditing Offices using only the selected lines.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the Auditing Offices 1 and 4 can only route documents to each other by passing through departments 2 and 3, so all three lines (5 + 1 + 2 = 8) must be selected. In Example 2, there is only one Auditing Office. With one required department, an empty set of lines is valid, so the minimum cost is 0.
</STATEMENT>
<RATIONALE>
The suggested strategy was to remove the global unique-path guarantee and allow disconnected components with cycles, intending to force a general Steiner tree computation. However, allowing cycles in the component containing the target vertices would make the problem NP-hard (since any arbitrary graph can be embedded as a component in an $m=n-1$ graph by adding isolated vertices), which violates the strict constraint against changing the complexity class. To resolve this, the rewrite implements the strategy by removing the global guarantee and introducing the possibility of disconnected components and cycles, but carefully restricts the specific component containing the Auditing Offices to have no cycles. This forces models to identify the correct component and prevents blind application of a global tree traversal, while preserving the P complexity class.
</RATIONALE>
<PRESERVED_ANSWER>
The objective remains to find the minimum weight subgraph connecting the designated vertices, and since the specific component containing them is still guaranteed to have unique paths, the optimal subgraph calculation is identical to the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
By guaranteeing that the single connected component containing all Auditing Offices has no cycles, the relevant portion of the graph remains a simple branching structure, ensuring the problem can still be solved in polynomial time (O(n)) by finding that component and computing the subtree weight.
</PRESERVED_CLASS>
<RISK>
Models might overreact to the mention of cycles and disconnected components and attempt to use a general Steiner tree algorithm, which could lead to Time Limit Exceeded on large inputs, although this is the intended penalty for failing to reason about the local structure.
</RISK>
