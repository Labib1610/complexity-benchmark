**Solution Explanation**

For a tree the unique cheapest way to connect a given set of vertices is the
*minimal subtree* that contains all of them – the union of all pairwise
paths.  
An edge belongs to this subtree **iff** after removing the edge the set of
required vertices (the *auditing offices*) is split into two non‑empty parts.

So we only have to know, for every edge, how many required vertices are in the
subtree of one of its ends.  
If this number is `0` or `t` (all required vertices) the edge is unnecessary,
otherwise it is necessary and its weight contributes to the answer.



--------------------------------------------------------------------

#### Algorithm
```
read n , m (= n‑1) , t
read list S of the t special vertices
mark special[v] = True

build adjacency list of the tree, each entry (neighbor , weight)

root the tree at vertex 1
DFS (iterative) → parent[v] , weight_to_parent[v] , order[] (pre‑order)

cnt[v] = 1 if v is special else 0
process vertices in reverse order (post‑order)
        p = parent[v]
        if p != 0:          # 0 means “no parent”, i.e. the root
                cnt[p] += cnt[v]          # propagate number of specials upward

answer = Σ weight_to_parent[v]   over all v ≠ root
          with 0 < cnt[v] < t
print answer
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs the minimum possible total maintenance
budget.

---

##### Lemma 1  
For any edge `e = (parent, child)` let `sub = cnt[child]` be the number of
special vertices in the subtree of `child`.  
Edge `e` is contained in the minimal connecting subtree **iff**
`0 < sub < t`.

**Proof.**  
Removing `e` separates the tree into two components:

* component A – the subtree of `child` (contains `sub` specials)
* component B – the rest of the tree (contains `t‑sub` specials)

If `sub = 0` or `sub = t` all specials stay in a single component, therefore a
connected subgraph containing all specials can be built without `e`.  
If `0 < sub < t` each component contains at least one special vertex, so any
connected subgraph that contains all specials must contain a path between the
two components, and the only such path is `e`. ∎



##### Lemma 2  
The set of edges selected by the algorithm (those with `0 < cnt < t`) is
exactly the minimal subtree spanning all special vertices.

**Proof.**  
By Lemma&nbsp;1 an edge is selected **iff** it is necessary for connectivity of
the specials, i.e. it belongs to *every* connected subgraph that contains all
specials.  
All selected edges together form a connected subgraph (they are exactly the
edges of the original tree that are not removed by cutting away whole
subtrees without specials).  
Therefore the selected edges are precisely the edges of the unique minimal
subtree. ∎



##### Lemma 3  
The total weight computed by the algorithm equals the total weight of the
minimal subtree.

**Proof.**  
The algorithm sums the weight of each selected edge once, and by Lemma&nbsp;2
the selected edges are exactly the edges of the minimal subtree. ∎



##### Theorem  
The algorithm outputs the minimum possible total maintenance budget that makes
all auditing offices mutually reachable.

**Proof.**  
Any feasible set of edges must contain the minimal subtree (otherwise the
special vertices would be disconnected). Hence its total weight is at least
the weight of the minimal subtree.  
By Lemma&nbsp;3 the algorithm outputs exactly that weight, therefore no cheaper
feasible set exists and the algorithm is optimal. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list* – `O(n)` time, `O(n)` memory.  
*Iterative DFS* – visits each vertex and edge once: `O(n)` time, `O(n)` memory
for the stack and arrays.  
*Post‑order propagation* – `O(n)` time.  

Overall  

* **Time** `O(n)` ( ≤ 2·10⁵, well inside the limit)  
* **Memory** `O(n)` ( adjacency list + a few integer arrays )

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)

    n = next(it)
    m = next(it)          # = n-1, not used separately
    t = next(it)

    specials = [next(it) for _ in range(t)]
    is_special = [False] * (n + 1)
    for v in specials:
        is_special[v] = True

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = next(it)
        v = next(it)
        w = next(it)
        adj[u].append((v, w))
        adj[v].append((u, w))

    # ---------- root the tree ----------
    parent = [0] * (n + 1)          # 0 = no parent (root)
    pw = [0] * (n + 1)              # weight to parent
    order = []                      # preorder list

    stack = [1]
    parent[1] = -1                  # mark root
    while stack:
        u = stack.pop()
        order.append(u)
        for v, w in adj[u]:
            if v != parent[u]:
                parent[v] = u
                pw[v] = w
                stack.append(v)

    # ---------- count specials in subtrees ----------
    cnt = [0] * (n + 1)
    for v in specials:
        cnt[v] = 1

    for u in reversed(order):
        p = parent[u]
        if p > 0:                   # ignore the root (parent = -1)
            cnt[p] += cnt[u]

    # ---------- sum needed edges ----------
    total = 0
    for v in range(2, n + 1):       # all vertices except the root
        if 0 < cnt[v] < t:
            total += pw[v]

    print(total)


if __name__ == "__main__":
    solve()
```
