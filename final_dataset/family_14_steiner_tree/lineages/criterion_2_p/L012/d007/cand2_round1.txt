<METHOD_DESCRIPTION>Replaces explicit structural guarantees (like "exact rank required") with the formal algebraic properties of the constraints (null space dimension and logical independence of evaluations). This forces the model to deduce the tree structure from first principles rather than pattern-matching the $m=n-1$ rank guarantee.</METHOD_DESCRIPTION>

<STATEMENT>
# Quadratic Penalty Selection

Time limit: 2 s   Memory limit: 256 MB

## Description

A system state is represented by a vector $x = (x_1, x_2, \dots, x_n) \in \mathbb{R}^n$. Exactly $t$ of these coordinates are designated as **Target Dimensions**.

You are provided with a collection of $m$ available quadratic penalty operators. Each operator $P(x)$ enforces a penalty between two specific coordinates and takes the form $(x_u - x_v)^2$. Activating an operator incurs a specific scalar cost. 

The complete collection of $m$ operators possesses two structural properties:
1. The set of state vectors $x$ for which the sum of all $m$ operators evaluates to zero is exactly the one-dimensional subspace where all $n$ coordinates are equal.
2. The operators are independent: for any single operator in the collection, its evaluation to zero cannot be logically deduced even if all other $m-1$ operators evaluate to zero.

You must select a subset of these operators to activate. Let $F(x)$ be the sum of your selected operators. Your selection must satisfy the following condition: for any state vector $x$ such that $F(x) = 0$, the values of $x$ at all $t$ Target Dimensions must be identical. (When $t=1$, this condition imposes no additional restriction on the selected subset).

Your objective is to determine the minimum total activation cost required to select a valid subset of operators meeting this condition.

## Input

The first line contains three integers: $n$, $m$, and $t$.
- $n$ is the total number of coordinates in the state vector. This dimension is at least a single coordinate and is bounded by the system's maximum architectural capacity of two hundred thousand coordinates.
- $m$ is the number of available operators. To maintain exactly the necessary degrees of constraint without redundancy, the facility provides exactly one operator fewer than the total number of coordinates.
- $t$ is the number of Target Dimensions. This is at least a single dimension and cannot exceed the total number of coordinates.

The second line contains $t$ distinct integers: the indices of the Target Dimensions (from 1 to $n$).

Each of the next $m$ lines details an available operator with three integers: $u$, $v$, and $w$.
- $u$ and $v$ are distinct coordinate indices (from 1 to $n$) linked by the operator $(x_u - x_v)^2$.
- $w$ is the cost to activate this operator. This cost is a positive integer strictly bounded by a maximum budget cap of one million units.

These $m$ lines form the exact algebraic structure described above.

## Output

Print a single integer: the minimum total activation cost required to ensure all Target Dimensions are equal whenever the sum of the selected operators is zero.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the Target Dimensions 1 and 4 can only be forced to take identical values when $F(x)=0$ by activating all three operators (costs 5 + 1 + 2 = 8). In Example 2, there is only one Target Dimension. Since a single coordinate always equals itself, no operators need to be activated, resulting in a minimum cost of 0.
</STATEMENT>
<RATIONALE>
The explicit affordance describing the constraints as having the "exact rank required to enforce this one-dimensional solution space" was replaced with two rigorous algebraic properties: null space dimension and logical independence. To succeed, a model must now deduce that these properties mathematically define a tree (connected and acyclic equivalence relations) instead of relying on the semantic cues of rank and $n-1$ dimensions. Numeric bounds were also translated into scenario-appropriate physical constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the sum of non-negative quadratic terms equals zero still means every selected pairwise difference must be zero, which is identical to selecting edges in a graph; the minimal required subset remains the Steiner tree over the targets.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding the minimum weight subtree spanning $t$ nodes in an $n$-node tree, which is solvable in $O(n)$ time using a single traversal.
</PRESERVED_CLASS>
