# Subgroup Orbit Selection

Time limit: 2 s   Memory limit: 256 MB

## Description

You are investigating a permutation group acting on a set of $n$ elements, indexed $1$ to $n$. A specific subset of $t$ elements are designated as **Primary Elements**.

You are provided with a collection of $m$ basic transpositions. Each transposition swaps exactly two elements $u$ and $v$. Including a transposition in your active generator set incurs a specific scalar cost. The complete collection of $m$ available transpositions generates the symmetric group $S_n$ on all $n$ elements. Furthermore, this collection contains exactly $m = n - 1$ transpositions.

You must select a subset of these transpositions to form an active generator set. Your selection must satisfy the following condition: under the action of the subgroup generated by your selected transpositions, all $t$ Primary Elements must belong to the same orbit. (When $t=1$, this condition imposes no additional restrictions on the selected subset).

Your objective is to determine the minimum total cost required to select a valid subset of transpositions meeting this condition.

## Input

The first line contains three integers: $n$, $m$, and $t$.
- $n$ is the total number of elements. There is at least 1 element and at most 200000.
- $m$ is the number of available transpositions, which is exactly $n - 1$.
- $t$ is the number of Primary Elements, which is at least 1 and at most $n$.

The second line contains $t$ distinct integers: the indices of the Primary Elements (from 1 to $n$).

Each of the next $m$ lines details an available transposition with three integers: $u$, $v$, and $w$.
- $u$ and $v$ are distinct element indices (from 1 to $n$) swapped by the transposition.
- $w$ is the cost to include this transposition. This cost is a positive integer not exceeding 1000000.

These $m$ lines form the exact structure described above, guaranteeing the full collection generates $S_n$.

## Output

Print a single integer: the minimum total cost required to ensure all Primary Elements are in the same orbit under the generated subgroup.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the Primary Elements 1 and 4 can only be placed in the same orbit by including all three transpositions (costs 5 + 1 + 2 = 8). In Example 2, there is only one Primary Element. Since a single element always forms an orbit with itself under any subgroup, no transpositions need to be included, resulting in a minimum cost of 0.
