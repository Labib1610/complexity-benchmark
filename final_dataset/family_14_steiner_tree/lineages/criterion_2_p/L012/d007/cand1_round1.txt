<STATEMENT>
# Symmetric Group Orbit Synthesis

Time limit: 2 s   Memory limit: 256 MB

## Description

Consider the symmetric group $S_n$ acting on the set of elements $X = \{1, 2, \dots, n\}$. You are provided with a specific subset $T \subseteq X$ containing exactly $t$ elements.

You are also given a collection of $m$ available transpositions. Each transposition swaps two specific elements $u$ and $v$ in $X$ (leaving all other elements fixed) and incurs a specific scalar activation cost when selected. 

The complete collection of $m$ available transpositions is sufficient to generate the full symmetric group $S_n$. Furthermore, this collection contains exactly $m = n - 1$ transpositions, which is the theoretical minimum number of transpositions required to generate $S_n$. 

You must select a subset of these available transpositions to activate. Let $H$ be the subgroup of $S_n$ generated by your selected subset of transpositions. Your selection must satisfy the following condition: under the natural action of $H$ on $X$, all $t$ elements of the subset $T$ must belong to the exact same orbit. In other words, for any two elements $a, b \in T$, there must exist at least one permutation $\pi \in H$ such that $\pi(a) = b$. (When $t=1$, this condition imposes no additional restriction, as any element is trivially in its own orbit under any subgroup).

Your objective is to determine the minimum total activation cost required to select a valid subset of transpositions meeting this condition.

## Input

The first line contains three integers: $n$, $m$, and $t$.
- $n$ is the total number of elements in $X$. There is at least 1 element and at most 200000.
- $m$ is the number of available transpositions, which is exactly $n - 1$.
- $t$ is the number of elements in the subset $T$, which is at least 1 and at most $n$.

The second line contains $t$ distinct integers: the elements of the subset $T$ (from 1 to $n$).

Each of the next $m$ lines details an available transposition with three integers: $u$, $v$, and $w$.
- $u$ and $v$ are distinct elements (from 1 to $n$) swapped by the transposition.
- $w$ is the cost to activate this transposition. This cost is a positive integer not exceeding 1000000.

These $m$ lines form the exact structure described above, guaranteeing that the full set of transpositions generates $S_n$.

## Output

Print a single integer: the minimum total activation cost required to ensure all elements of $T$ are in the same orbit of the subgroup generated by the selected transpositions.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the elements 1 and 4 can only be placed in the same orbit by activating all three transpositions (costs 5 + 1 + 2 = 8). In Example 2, there is only one element in $T$. Since a single element is always in its own orbit under any subgroup, no transpositions need to be activated, resulting in a minimum cost of 0.

The previous linear-algebraic and logical-equivalence framings failed because models easily map equations like $x_u = x_v$ directly to graph connected components. To break this surface pattern matching, I transformed the problem into an abstract algebra domain. The tree of operators is re-cast as a minimal generating set of transpositions for the symmetric group $S_n$, and the connected components requirement is re-cast as requiring the target elements to fall within a single orbit of the generated subgroup. This forces the model to deduce the structural isomorphism between group orbits and graph connectivity.
</RATIONALE>
<PRESERVED_ANSWER>

</PRESERVED_ANSWER>
