We need to treat this properly: the target condition is that the chosen edges must span all differences between the given target vertices.  

One way to handle that is to consider the graph whose vertices are the given indices, and we need their complete graph to be in the span. A known trick: if we take any spanning tree over the target vertices, then all differences between those vertices can be generated.  
So the minimal cost is the minimum weight of a connected subgraph that contains all target vertices.

Thus, the problem becomes: Given a graph with n vertices and n-1 edges, which is connected (since it spans the whole (n-1)-dim space), find the minimum cost connected subgraph that includes all target vertices.

This is the **Steiner tree** problem, but here because the graph is a tree (n vertices, n-1 edges), it's simpler: we can contract all non-target leaves recursively, and sum the edges in the minimal subtree that spans the targets.

Since it's a tree, the minimal subtree connecting a set of terminals is unique: it's the union of all paths between terminals. Its cost is found by removing leaves not in the target set repeatedly.

In Python, with n up to 200k, we can use adjacency list and BFS / queue to strip non-target leaves.

**Steps**:
1. Read input.
2. Build adjacency list for edges, keeping cost info.
3. Mark targets as a set.
4. Perform a "leaf peeling" process:
   - Compute degree of each vertex.
   - Initialize queue with all leaves (degree==1) that are not targets.
   - While queue: pop leaf, remove it from graph (decrease neighbor degree and add edge cost to a total variable representing all edges not in the minimal target subtree). For popped leaf, subtract its cost from total cost (we initially total sum all edges) or directly sum costs of removed edges.
5. At the end, total cost = sum of all edge costs - sum of removed edge costs. That remaining is the cost of the minimal subtree.

This works because in a tree, any edge not on the minimal connecting subtree is precisely those branch edges leading to non-target leaves.

Implementation notes:
- The graph may be of size up to 200k vertices, so adjacency list fine.
- Use deque for queue.

Let's code.

```python
import sys
from collections import deque

def main():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    targets = set(map(int, input().split()))
    adj = [[] for _ in range(n+1)]
    total_cost = 0
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
        total_cost += w
    if t <= 1:
        print(0)
        return
    degree = [0]*(n+1)
    for i in range(1,n+1):
        degree[i] = len(adj[i])
    removed_cost = 0
    q = deque()
    visited = [False]*(n+1)
    for i in range(1,n+1):
        if degree[i] == 1 and i not in targets:
            q.append(i)
            visited[i] = True
    while q:
        v = q.popleft()
        for to, w in adj[v]:
            if not visited[to]:
                degree[to] -= 1
                removed_cost += w
                if degree[to] == 1 and to not in targets:
                    q.append(to)
                    visited[to] = True
    print(total_cost - removed_cost)

if __name__ == "__main__":
    main()
```
