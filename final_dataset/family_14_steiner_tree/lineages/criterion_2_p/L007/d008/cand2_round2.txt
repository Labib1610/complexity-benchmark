# Hardware Matrix Accelerator

Time limit: 2 s   Memory limit: 256 MB

## Description

You are designing a hardware accelerator that processes an $n \times n$ matrix. The rows of the matrix are indexed from $1$ to $n$.

You need to support arbitrary permutations of a specific subset of $t$ rows, called the target subset $T$. 

To achieve this, you can purchase "row-swap modules". Each module swaps exactly two specific rows $u$ and $v$ of the matrix and has a licensing cost $w$. 

You are provided with a catalog of $m = n - 1$ distinct modules. It is guaranteed that if you purchase all $m$ modules, you can compose them in various sequences to achieve any possible permutation of the $n$ rows.

Your objective is to purchase a subset of these modules with the minimum total licensing cost, such that by composing the purchased modules, for every pair of distinct rows $a, b \in T$, you can construct an operation sequence that swaps $a$ and $b$ while ultimately leaving all other rows in their original positions. Note that intermediate steps in the composition may affect rows outside of $T$, which is permissible and often necessary to establish the required swapping operations.

Determine the minimum total licensing cost of a subset of modules that must be purchased to satisfy this requirement. Any module not strictly needed can be omitted.

## Input

The first line provides three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$).
The second line provides $t$ distinct integers, representing the row indices in the target subset $T$.
The next $m$ lines each contain three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), indicating an available module that swaps rows $u$ and $v$, with a licensing cost of $w$.

## Output

Output a single integer: the minimum total licensing cost of the purchased subset of modules.

**Input**

```

```

**Output**


<RATIONALE>
The problem was rewritten from group theory (transpositions) to matrix transformations (row-swaps). This retains the exact mathematical properties (a generated subgroup of permutations) without using keywords like "subgroup", "transposition", or "generator" which trigger standard graph theoretical templates in LLMs. The exact bounds from the seed were explicitly restored to ensure verifier compliance.
</RATIONALE>
<PRESERVED_ANSWER>
The set of permutations generated by row swaps is mathematically identical to the subgroup generated by transpositions, yielding the exact same required minimum-weight subtree.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the minimum-cost connected subgraph containing all target vertices on a tree, which is uniquely solved in linear time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "ultimately leaving all other rows in their original positions" as meaning intermediate steps cannot alter other rows, but this is mitigated by explicitly stating that intermediate steps affecting other rows are permissible.
</RISK>
