<METHOD_NAME>Null Space Projection</METHOD_NAME>
<METHOD_DESCRIPTION>Frame the problem as finding a minimum-weight subset of difference equations such that the null space of the subset, when projected onto the target variables, yields exactly the 1-dimensional space spanned by the all-ones vector. This mathematically requires the subset to form a connected component spanning the target variables (a Steiner tree), but disguises it as a linear algebra problem to prevent tree-based pattern matching.</METHOD_DESCRIPTION>

<STATEMENT>
# Subspace Projection

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a homogeneous system of linear equations involving $n$ unknown real variables, $x_1, x_2, \dots, x_n$. You are provided with a set of $m$ potential difference equations. Each equation is of the form $x_u - x_v = 0$ and has a specific verification cost $w$ to include in your system.

The set of potential equations is minimally complete: if you were to include all $m$ equations, the null space of the overall system would be exactly 1-dimensional (the space where $x_1 = x_2 = \dots = x_n$). The set contains no redundancies; removing any equation from the full set would strictly increase the dimension of the null space.

A client has specified a target list of $t$ variables. Your objective is to select a subset of the potential equations to include such that, in the null space of your selected subset, the projection onto the $t$ target variables is exactly a 1-dimensional space spanned by the all-ones vector. (In other words, any vector in the null space must have identical components at all $t$ of the specified indices). Variables not in the target list may also end up being constrained to this value, which is permissible.

Determine the minimum total verification cost of a subset of equations that satisfies this requirement. Any equation not needed to enforce this condition can be omitted.

## Input

The first line provides three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$).
The second line provides $t$ distinct integers, representing the indices of the target variables.
The next $m$ lines each contain three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), indicating a potential equation $x_u - x_v = 0$ with a verification cost of $w$.

## Output

Output a single integer: the minimum total verification cost of the included equations that guarantee the projection of the null space onto the $t$ target variables is exactly 1-dimensional.

## Examples

### Example 1

**Input**
```

```

**Output**
```
8
```

```

```

**Output**
```

```
</STATEMENT>
<RATIONALE>
I changed the framing from logical equivalence deduction (which models mapped directly to graph connectivity and trees) to a linear algebra problem involving the null space of a system of difference equations. This forces models to genuinely reason about the properties of the null space to deduce that the equations form a tree and the requirement is equivalent to finding a minimal subtree spanning the target variables, defeating models that rely on surface pattern matching and might attempt matrix operations.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that the projection of the null space onto the target variables is 1-dimensional is mathematically identical to requiring that the selected equations (edges) force all target variables to be equal, which means they must be in the same connected component, preserving the exact same valid subsets and costs as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains finding the minimum cost Steiner tree on a given tree, which is solvable in O(N) time, keeping the complexity class exactly the same (P).
</PRESERVED_CLASS>
<RISK>
The phrase "projection onto the $t$ target variables is exactly a 1-dimensional space" could be misinterpreted if the reader does not realize the all-ones vector is always in the null space, but the parenthetical explicitly clarifies that this simply means all target variables must take the same value.
</RISK>
