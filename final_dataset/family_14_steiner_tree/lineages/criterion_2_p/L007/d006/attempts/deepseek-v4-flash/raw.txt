We are given a tree (since \( m = n-1 \) transpositions that generate \( S_n \) must form a tree on \( n \) vertices).  
We need to select a subset of edges (transpositions) with minimum total cost such that the generated subgroup contains all transpositions \((a,b)\) for \(a,b \in T\).

**Key insight:**  
In a tree, the transpositions corresponding to edges generate the full symmetric group on the vertices of the tree.  
To generate a transposition \((a,b)\), we need to include all edges on the unique path between \(a\) and \(b\) in the tree.  
Thus, to generate all transpositions among the target set \(T\), we must include all edges that lie on the union of paths between every pair of vertices in \(T\).

That union of paths is exactly the minimal subtree connecting all vertices in \(T\) (the Steiner tree of \(T\) in the given tree).  
So the problem reduces to: find the minimum-cost subtree that connects all vertices in \(T\).  
Since the tree is given with edge costs, this is simply the sum of costs of edges in the minimal connected subgraph containing all \(T\) vertices.

**Algorithm:**
1. Build adjacency list of the tree.
2. Mark target vertices.
3. Perform DFS from any target vertex, count how many target vertices are in each subtree.
4. An edge is needed if both sides contain at least one target vertex.
5. Sum the costs of needed edges.

If \( t = 1 \), answer is 0.

Let's implement.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    targets = set(map(int, input().split()))
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    if t <= 1:
        print(0)
        return
    
    # DFS to count targets in subtree
    visited = [False] * (n+1)
    total_cost = 0
    
    def dfs(u, parent):
        nonlocal total_cost
        visited[u] = True
        cnt = 1 if u in targets else 0
        for v, w in adj[u]:
            if v == parent:
                continue
            child_cnt = dfs(v, u)
            if child_cnt > 0 and (t - child_cnt) > 0:
                total_cost += w
            cnt += child_cnt
        return cnt
    
    # start from any target
    start = next(iter(targets))
    dfs(start, -1)
    print(total_cost)

if __name__ == "__main__":
    solve()
```
