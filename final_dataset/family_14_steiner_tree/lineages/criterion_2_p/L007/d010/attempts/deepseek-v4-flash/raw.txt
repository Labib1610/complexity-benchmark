We are given a graph with \( n \) vertices and \( m = n-1 \) edges, each edge representing a difference vector \( e_u - e_v \) with a cost. The target set \( T \) has \( t \) vertices, and we need to span all differences \( e_a - e_b \) for \( a, b \in T \).

This is equivalent to: we need to connect all vertices in \( T \) in the graph (in terms of reachability via edges, since spanning \( e_a - e_b \) means there is a path between \( a \) and \( b \) in the selected edges). Since the graph is a tree (because \( m = n-1 \) and it's connected), the minimal cost to connect all target vertices is the **minimum Steiner tree** on the tree, restricted to the target set \( T \).

For a tree, the minimum Steiner tree for a set of terminals is simply the union of all edges on the minimal subtree that connects all terminals. The cost is the sum of edge weights in that subtree.

We can compute this by:
1. Root the tree at any node.
2. Mark all nodes in \( T \).
3. Do a DFS from the root. For each node, if its subtree contains at least one terminal, then the edge from its parent to it must be included in the Steiner tree.
4. Sum the weights of included edges.

If \( t = 1 \), the cost is 0.

Let's implement this efficiently for \( n \) up to 200,000.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    targets = set(map(int, input().split()))
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    if t <= 1:
        print(0)
        return
    
    # Root the tree at 1
    parent = [0]*(n+1)
    weight = [0]*(n+1)
    order = [1]
    parent[1] = -1
    for node in order:
        for nei, w in adj[node]:
            if nei != parent[node]:
                parent[nei] = node
                weight[nei] = w
                order.append(nei)
    
    # Post-order processing
    has_target = [False]*(n+1)
    for node in targets:
        has_target[node] = True
    
    total_cost = 0
    # Process in reverse order (children before parents)
    for node in reversed(order):
        if node == 1:
            continue
        if has_target[node]:
            total_cost += weight[node]
            # propagate up
            p = parent[node]
            if p != -1:
                has_target[p] = True
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
