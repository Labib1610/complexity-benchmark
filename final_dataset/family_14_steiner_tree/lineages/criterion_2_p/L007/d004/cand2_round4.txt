<STATEMENT>
# Equivalence Verification

Time limit: 2 s   Memory limit: 256 MB

## Description

A formal system contains **n** variables, indexed from 1 to **n**. You are provided with a set of **m** potential equivalence identities, where **m = n − 1**. The set of **m** identities is comprehensive enough that, if all were verified, it would establish that all **n** variables are equivalent to one another. Furthermore, because **m = n − 1**, there is exactly one non-redundant chain of identities linking any given pair of variables.

A client requires a guarantee that a specific subset of **t** target variables are all equivalent to each other. You must select a subset of the available identities to verify such that the equivalence of all **t** target variables is logically proven. You may verify identities involving non-target variables to complete the proof chains.

The total cost of your verification is calculated by summing two components:
1. The individual verification costs of all selected identities.
2. A processing fee for every non-target variable that appears in the selected identities.

Currently, the processing fee is fixed at 0 per non-target variable. Calculate the minimum total verification cost necessary to prove the mutual equivalence of the **t** target variables, ensuring you incorporate both the identity costs and the processing fees into your final calculation.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line provides **t** distinct integers, which are the indices of the target variables.
The next **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000). This indicates a potential equivalence identity between variable **u** and variable **v** that costs **w** to verify. The given set of **m** identities connects all **n** variables such that exactly one valid chain of identities exists between any two variables.

## Output

Output a single integer: the minimum total verification cost to prove the target variables are equivalent.

<RATIONALE>
The problem has been reframed from a datacenter networking scenario to a logical equivalence verification task. The explicit guarantee that the input forms a connected tree spanning all variables is preserved through the mechanics of "chains of identities" that connect all variables. This forces the model to recognize the underlying tree structure from logical descriptions rather than relying on standard networking keywords.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical task remains identical: find the minimum-weight subgraph that connects the specified subset of nodes, which on a tree is exactly the unique subtree spanning those nodes.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class remains P, as the input structure is still guaranteed to be a tree, allowing the optimal subset to be found in linear time using tree traversals.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "logically proven" if they assume transitive closure is free, but the statement explicitly requires selecting identities and defines the cost based on the selected identities.
</RISK>
