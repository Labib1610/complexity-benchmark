# Conglomerate Formation

Time limit: 2 s   Memory limit: 256 MB

## Description

A global market consists of **n** distinct corporations, indexed from 1 to **n**. Financial regulators have pre-approved exactly **m** bilateral merger agreements. The structure of these pre-approved agreements guarantees that, if all were executed, there would be exactly one unique chain of corporate combinations linking any given pair of corporations. Executing each merger agreement requires a specific legal expenditure.

An activist investor has acquired significant shares in a specific portfolio of **t** corporations. Your objective is to execute a selection of the pre-approved mergers so that every corporation in the portfolio is absorbed into the exact same unified conglomerate. The conglomerate may also absorb corporations that are not in the investor's portfolio.

The total expenditure for your restructuring is calculated by summing two components:
1. The individual legal expenditures of all executed merger agreements.
2. A regulatory integration fine for every non-portfolio corporation that is absorbed into the unified conglomerate containing the portfolio corporations.

Currently, the regulatory integration fine is fixed at 0 per non-portfolio corporation. Calculate the minimum total expenditure necessary to merge all the portfolio corporations together, ensuring you incorporate both the merger expenditures and the regulatory fines into your final calculation.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line provides **t** distinct integers, which are the indices of the portfolio corporations.
The next **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000). This indicates a pre-approved merger agreement between corporation **u** and corporation **v** that costs **w** to execute. The provided framework of **m** agreements guarantees that exactly one valid sequence of mergers exists to link any two corporations when all are executed.

## Output

Output a single integer: the minimum total expenditure to execute the required mergers and cover any fines.

<RATIONALE>
The problem was completely reframed from networking to corporate mergers. The terms "merger" and "conglomerate" strongly trigger surface-level associations with Disjoint Set Union (DSU) and Minimum Spanning Tree algorithms like Kruskal's. Models relying on these associations will apply a greedy edge-sorting approach, which incorrectly adds cheap but irrelevant edges outside the required minimal subtree. To succeed, the model must logically deduce that the input is already a tree and that the task requires pruning unnecessary branches rather than greedy edge selection.
</RATIONALE>
<PRESERVED_ANSWER>
The required output remains the sum of edge weights in the minimal connected subgraph containing the target nodes, yielding the exact same integer for every input.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure is still finding the Steiner tree on a graph that is already a tree, which can be solved in O(n) time via topological pruning or post-order traversal, keeping it in the polynomial complexity class.
</PRESERVED_CLASS>
