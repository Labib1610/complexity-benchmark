# Datacenter Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

A computing facility houses **n** server racks, indexed from 1 to **n**. The building is pre-wired with exactly **m** fiber-optic links. The infrastructure guarantees that, when all links are powered on, the entire facility is fully interconnected (a communication route exists between any two racks). Powering on each link incurs a specific activation expense.

A customer has rented a specific group of **t** racks. To minimize power consumption while satisfying the customer's requirements, the facility manager performs the following strict shutdown procedure:
1. Initially, all **m** links are powered on.
2. Identify all links that can be powered off *without* breaking the communication routes between any given pair of the **t** rented racks. (If **t** = 1, there are no pairs to disconnect, so every link is considered safely removable. When evaluating communication routes, data can always be routed through any racks, including unrented ones).
3. If no such links exist, the procedure terminates.
4. Otherwise, among all such safely removable links, pick the one with the highest activation expense. If there is a tie, pick the link that appeared first in the input list.
5. Power off the chosen link permanently.
6. Repeat the process from step 2 until the procedure terminates.

The total activation expense for your network is calculated by summing two components at the end of the procedure:
1. The individual activation expenses of all fiber-optic links that remain powered on.
2. A relay activation fee for every unrented rack that is still included in the active communication routes.

Currently, the relay activation fee is fixed at 0 per unrented rack. Calculate the final total activation expense of the network after the shutdown procedure terminates, ensuring you incorporate both the remaining link expenses and the relay activation fees into your calculation.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line provides **t** distinct integers, which are the indices of the rented racks.
The next **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000). This indicates a pre-wired fiber-optic link between rack **u** and rack **v** that has an activation expense of **w**.

## Output

Output a single integer: the final total activation expense after the shutdown procedure terminates.

<RATIONALE>
I removed the explicit "unique communication route" guarantee and replaced the Steiner Tree optimization objective with a deterministic, iterative link-shutdown procedure. The procedure asks to repeatedly remove the most expensive non-essential link. For a tree (which the input mathematically is, given m=n-1 and full connectivity), this process always leaves exactly the minimal valid subtree, making the answer identical. This forces models to either genuinely recognize the tree properties to use the O(N) approach, or fall for the trap of simulating the O(N^2) procedure and timing out.
</RATIONALE>
<PRESERVED_ANSWER>
In a connected graph with n-1 edges (a tree), the set of links whose removal does not disconnect the required terminals is exactly the set of links outside the minimal Steiner subtree, so any valid sequence of removals will always terminate with exactly the minimal subtree remaining.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The final state of the described process is mathematically identical to the minimal Steiner subtree on a tree, which can still be found in O(N) time using standard tree traversal and pruning.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the tie-breaking rule as implying the final answer depends on the order of removals, though mathematically it does not.
</RISK>
