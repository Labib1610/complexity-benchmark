# Datacenter Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

A computing facility houses **n** server racks, indexed from 1 to **n**. The building is pre-wired with **m** fiber-optic links. Powering on each link incurs a specific activation expense.

A customer has rented a specific group of **t** racks. Your objective is to power on a selection of the fiber-optic links so that every rented rack can exchange data with every other rented rack. Data can be routed through racks that the customer has not rented.

The total activation expense for your network is calculated by summing two components:
1. The individual activation expenses of all powered-on fiber-optic links.
2. A relay activation fee for every unrented rack that is included in the active communication routes.

Currently, the relay activation fee is fixed at 0 per unrented rack. Calculate the minimum total activation expense necessary to tie all the rented racks together, ensuring you incorporate both the link expenses and the relay activation fees into your final calculation.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line provides **t** distinct integers, which are the indices of the rented racks.
The next **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000). This indicates a pre-wired fiber-optic link between rack **u** and rack **v** that costs **w** to power on. The given infrastructure of **m** links may form an arbitrary network configuration, though it is guaranteed that a valid selection of links exists to mutually connect all rented racks.

## Output

Output a single integer: the minimum total activation expense to power on the required links and racks.

<RATIONALE>
Removed the explicit guarantee that there is "exactly one unique communication route between any given pair of racks". Instead, the statement notes that the `m = n - 1` links may form an arbitrary network, guaranteeing only that the rented racks can be connected. This forces the model to deduce the structural properties (that any connected component must be a tree) rather than relying on a direct "unique path" keyword to trigger tree-specific templates.
</RATIONALE>
<PRESERVED_ANSWER>
The hidden test cases and requirements are identical; the minimal subgraph connecting the required nodes simply uses the same edges.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying graph in all valid inputs is a tree (or forest where required nodes are in one tree component), keeping the problem solvable in linear time using the same approach.
</PRESERVED_CLASS>
<RISK>
Models might assume the graph can contain cycles and attempt NP-hard Steiner tree algorithms, but this is a deliberate trap for models that fail to deduce the topological constraints from `m = n - 1`.
</RISK>
