We are given a tree (since \( m = n - 1 \)) with weighted edges. We need to select a subset of edges such that all target vertices are in the same connected component, minimizing the total weight of selected edges.

This is equivalent to finding the **minimum Steiner tree** for the set of target vertices in a tree. In a tree, the minimum Steiner tree is simply the minimal subtree that connects all target vertices. Its cost is the sum of weights of edges in that minimal subtree.

We can solve this by:

1. Marking target vertices.
2. Doing a DFS/BFS from any target vertex to find the minimal subtree that connects all targets.
3. The cost is the sum of edges in that subtree.

A common efficient method:
- Root the tree at any target vertex.
- For each node, compute if its subtree contains any target vertex.
- If a node's subtree contains at least one target, then the edge from its parent to this node is part of the Steiner tree (except for the root).
- Sum the weights of such edges.

Let's implement this.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    targets = set(map(int, input().split()))
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    # pick any target as root
    root = next(iter(targets))
    
    parent = [0]*(n+1)
    weight = [0]*(n+1)
    order = []
    stack = [root]
    parent[root] = -1
    while stack:
        u = stack.pop()
        order.append(u)
        for v, w in adj[u]:
            if v != parent[u]:
                parent[v] = u
                weight[v] = w
                stack.append(v)
    
    has_target = [False]*(n+1)
    for v in targets:
        has_target[v] = True
    
    total_cost = 0
    # process in reverse order (post-order)
    for u in reversed(order):
        if u == root:
            continue
        if has_target[u]:
            total_cost += weight[u]
            # propagate up
            p = parent[u]
            if p != -1:
                has_target[p] = True
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
