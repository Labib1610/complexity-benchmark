# Variable Exchange Mechanism

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a memory controller managing $n$ variables, denoted by indices from $1$ to $n$.

You are provided with a pool of $m$ hardware exchange instructions. Each instruction is defined by a pair of indices $u$ and $v$ and has an activation cost $w$. When executed, the instruction simultaneously swaps the current values of the variables at $u$ and $v$, leaving all other variables unchanged.

It is guaranteed that if all $m$ instructions are activated, they can be sequenced to rearrange the values of the $n$ variables into any arbitrary permutation.

A subset of $t$ variables is designated as the target set $T$. Your task is to activate a subset of the $m$ instructions such that the following condition is satisfied:
For every pair of distinct variables $a, b \in T$, there must exist a finite sequence of activated instructions whose net effect is exactly the exchange of the values of $a$ and $b$. This means the sequence must swap the values of $a$ and $b$ while ensuring that the final value of every other variable (whether in $T$ or not) is exactly equal to its initial value before the sequence began. Note that intermediate steps in the sequence may temporarily modify other variables.

Determine the minimum total activation cost of a subset of instructions that must be selected to fulfill this condition. Any instruction not strictly needed to enable the required exact exchanges can be omitted.

## Input

The first line provides three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$).
The second line provides $t$ distinct integers, representing the indices of the variables in the target set $T$.
The next $m$ lines each contain three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), indicating an available exchange instruction between variables $u$ and $v$, with an activation cost of $w$.

## Output

Output a single integer: the minimum total activation cost of the selected subset of instructions.

## Examples

```

```

**Output**
```
9
```

<METHOD_NAME>Domain Shift with Implicit Structure Induction</METHOD_NAME>
<METHOD_DESCRIPTION>Removed all group-theoretic terminology (symmetric group, transposition, subgroup) and deleted the explicit statement that the generating set is minimal. Reframed the problem using hardware variable exchange instructions. This removes the direct "it's a tree" affordance, forcing the model to deduce from the $m=n-1$ constraint and the universal permutation guarantee that the instruction graph is a spanning tree, and that isolating a swap requires every edge on the unique path between the variables.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<RATIONALE>
The previous wording explicitly stated that the generating set was minimal and mapped directly to symmetric group transpositions, which immediately handed the models the "this is a tree" deduction. By shifting to a hardware instruction domain and removing the minimality explanation, the model must independently deduce that $n-1$ instructions capable of generating all permutations form a spanning tree, and that achieving an isolated swap requires the path between the variables.
</RATIONALE>
<PRESERVED_ANSWER>
The condition of isolating the swap of two variables exactly defines a transposition in the symmetric group; since the available swaps form a tree, the required set of instructions is identical to the required subtree of transpositions in the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains finding the minimum weight subtree connecting all target vertices in a tree, keeping it in polynomial time (solvable in O(n) via tree traversal).
</PRESERVED_CLASS>
