# Swap Sequence Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

You are investigating a permutation system of $n$ distinct elements, which are identified by integers from $1$ to $n$.

You are provided with a pool of $m$ distinct swap operations. Each operation exchanges exactly two elements $u$ and $v$ (leaving all other elements unchanged) and has a specific activation cost $w$.

It is guaranteed that the full pool of operations can be composed to form any possible permutation of the $n$ elements.

A researcher has specified a target subset of $t$ elements, denoted as $T$. Your objective is to activate a subset of the available operations such that, for any chosen pair of distinct elements $a, b \in T$, it is possible to form a sequence (allowing repeated use of any activated operation) that swaps $a$ and $b$ while leaving all other elements in their original positions at the end of the sequence. Note that intermediate steps in your sequence may temporarily displace elements outside of $T$, which is permissible and often necessary.

Determine the minimum total activation cost of a subset of operations that must be selected to satisfy the researcher's requirement. Any operation not strictly needed to form the required target swaps can be omitted.

System limits are bounded by the following physical constants:
- The maximum number of elements $n$ corresponds to the number of meters in $200$ kilometers.
- The size of the operation pool $m$ is always exactly one less than $n$.
- The number of target elements $t$ ranges from a single element up to the full set of $n$.
- The elements $u$ and $v$ in any operation are distinct valid identifiers between $1$ and $n$.
- The strictly positive activation cost $w$ for any single operation will not exceed the number of grams in one metric tonne.

## Input

The first line provides three integers $n$, $m$, and $t$.
The second line provides $t$ distinct integers, representing the elements in the target subset $T$.
The next $m$ lines each contain three integers $u$, $v$, and $w$, indicating an available operation that swaps elements $u$ and $v$ with an activation cost of $w$.

## Output

Output a single integer: the minimum total activation cost of the selected subset of operations.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

<RATIONALE>
Removed the explicit minimality explanation that directly hinted at the tree structure, and replaced group-theoretic terminology with functional swap sequences. Used S07 to obfuscate numerical bounds via physical constants (meters in 200km, grams in a tonne). Models must now deduce the tree topology from the fact that $n-1$ swaps generate all permutations, rather than relying on surface-level keywords.
</RATIONALE>
<PRESERVED_ANSWER>
The problem still asks for the minimum cost subset of $n-1$ operations that allows swapping any pair of target elements, which remains equivalent to finding the unique Steiner tree of the target set.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class is unchanged because the underlying structure is still a tree (since $m=n-1$ and the operations generate all permutations), making the problem solvable in linear time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "form a sequence" as requiring a single sequence to swap all pairs simultaneously, though the phrasing "for any chosen pair... form a sequence" is specifically designed to clarify that each pair gets its own sequence.
</RISK>
