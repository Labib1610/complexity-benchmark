# Datacenter Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

A datacenter contains **n** server racks, numbered 1 to **n**. The facility's physical layout includes exactly **n − 1** fiber conduits. These conduits are laid out such that, if every single one were activated, they would successfully link all **n** racks together into a single connected network. Each conduit has an associated activation cost.

A client has leased a specific subset of **t** racks. You are tasked with activating a subset of the available conduits. The activated conduits must ensure that all of the client's leased racks can communicate with one another. When routing data between leased racks, you may route through unleased racks, which will act as pass-through switches at no additional cost beyond the activation of the conduits themselves.

Determine the minimum total activation cost required to interconnect all of the client's leased racks.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers representing the identifiers of the leased racks.
Each of the following **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that there is a fiber conduit available between rack **u** and rack **v** with an activation cost of **w**. It is guaranteed that the full set of **m** conduits connects all **n** racks.

## Output

Print a single integer representing the minimum total activation cost to connect all leased racks.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

```

```

**Output**
```
9
```

<RATIONALE>
Removed the explicit statement that "data can travel between any two racks via exactly one sequence of conduits" and the phrase "non-redundant network topology". Instead, the problem now states there are exactly $n-1$ conduits which, if all activated, fully connect all $n$ racks. This forces the model to deduce the unique-path (tree) property from the mathematical definition of a connected graph with $n-1$ edges, rather than relying on surface-level descriptions of unique sequences.
</RATIONALE>
<PRESERVED_ANSWER>
The underlying graph is identical, and the objective of finding the minimum cost to connect the leased racks remains exactly the same, ensuring all outputs correspond perfectly to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The network is still a tree (guaranteed by $n$ nodes, $n-1$ edges, and full connectivity), so the minimal connecting subgraph is unique and can be found in O(n) time, keeping the problem in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "interconnect all of the client's leased racks" as requiring a direct clique rather than a single connected component, though "route through unleased racks" clarifies this.
</RISK>
