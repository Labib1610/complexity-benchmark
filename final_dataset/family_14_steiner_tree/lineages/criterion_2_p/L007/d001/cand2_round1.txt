# Datacenter Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

A datacenter contains **n** server racks, numbered 1 to **n**. A telecom provider has laid out **m** potential fiber links between various pairs of racks, ensuring that the entire datacenter is fully interconnected. Each link has a specific activation cost.

A client has leased a specific subset of **t** racks. You must activate a subset of the available fiber links so that all leased racks can communicate with each other, either directly or by routing through unleased racks. Unleased racks on the active routes will act as pass-through switches.

Determine the minimum total activation cost required to establish this communication network for the client.

## Input

The first line contains three integers **n**, **m**, and **t**.
The total number of racks **n** is at least 1 and at most the capacity of a 200-kilowatt power grid, assuming each rack requires exactly one watt of baseline power (1 kilowatt = 1,000 watts). The number of available links **m** is exactly one less than the number of racks. The number of leased racks **t** ranges from 1 up to **n**.

The second line contains **t** distinct integers representing the identifiers of the leased racks.

Each of the following **m** lines contains three integers **u**, **v**, and **w**, indicating a potential fiber link between rack **u** and rack **v** with an activation cost of **w**. Racks **u** and **v** are distinct positive integers up to **n**. The activation cost **w** is a positive integer bounded by the number of milliwatts in one kilowatt.

## Output

Print a single integer representing the minimum total activation cost to connect all leased racks.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```
