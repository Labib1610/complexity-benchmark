 We can solve this by building a **minimum Steiner tree** for the leased racks.  
Since the graph is a tree, the optimal solution is the minimal subtree that connects all leased nodes.

Here’s the approach:

1. Mark the leased racks.
2. Perform a DFS to compute, for each node, whether its subtree contains any leased rack.
3. The minimal cost is the sum of weights of all edges that lie on paths between leased racks — equivalently, edges whose both sides contain at least one leased rack.

We can do this with a single DFS from any node.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    leased = set(map(int, input().split()))
    
    adj = [[] for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
        edges.append((u, v, w))
    
    # DFS to count leased nodes in subtree
    visited = [False] * (n + 1)
    has_leased = [False] * (n + 1)
    
    def dfs(u):
        visited[u] = True
        if u in leased:
            has_leased[u] = True
        for v, w in adj[u]:
            if not visited[v]:
                dfs(v)
                if has_leased[v]:
                    has_leased[u] = True
    
    # Start from any leased node
    start = next(iter(leased))
    dfs(start)
    
    total_cost = 0
    for u, v, w in edges:
        # Edge is needed if both sides contain at least one leased node
        if has_leased[u] and has_leased[v]:
            total_cost += w
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
