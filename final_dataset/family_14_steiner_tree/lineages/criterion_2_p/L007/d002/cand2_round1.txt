<STATEMENT>
# Datacenter Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

A technology firm operates a datacenter housing **n** server racks, which are assigned unique identifiers starting from 1 up to **n**. The physical infrastructure provides a total of **m** fiber-optic conduits between these racks. The topology of these conduits guarantees that if all of them were brought online, every single rack would be part of a unified communication grid, and this grid is designed minimally such that no alternative routes exist between any two racks. Bringing a conduit online requires paying a specific activation expense.

A corporate customer has rented a specific collection of **t** racks. Your objective is to select and activate a subset of the existing conduits so that the customer's rented racks can all exchange data with each other. When data travels between rented racks, it is permitted to pass through unrented racks. These unrented racks function as intermediate relays at no extra charge beyond the initial conduit activation expenses.

Calculate the lowest possible total activation expense needed to establish full connectivity among the customer's rented racks.

## Input

The first line provides three integers: **n**, **m**, and **t**. The datacenter contains at least one and up to two hundred thousand racks. The customer rents at least one rack, up to the total number of racks present. The conduit count **m** exactly matches the minimum number of connections required to form a fully connected grid of **n** racks.
The second line lists **t** distinct integers, specifying the identifiers of the rented racks.
The subsequent **m** lines each contain three integers **u**, **v**, and **w**. These specify a conduit linking distinct racks **u** and **v**, with an activation expense **w**. The minimum possible expense is one, and the billing system supports a maximum expense of one million per conduit. The complete infrastructure is guaranteed to connect the entire datacenter.

## Output

Output a single integer giving the lowest total expense to link the rented racks.

<RATIONALE>
Replaced the explicit `m = n - 1` and all other bare inequalities with scenario-based bounds. By stating that `m` is the "minimum number of connections required to form a fully connected grid" and that there are "no alternative routes", models must logically deduce that the graph is a tree rather than relying on the common `n - 1` pattern-matching trigger.
</RATIONALE>
<PRESERVED_ANSWER>
The required subset of edges to connect the specified nodes remains identical, as the underlying graph topology, edge weights, and required nodes are unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The graph is still a tree (guaranteed connected with unique paths) where we must find the minimum connected subgraph spanning a set of terminals, which is solvable in polynomial time (O(n)).
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "minimum number of connections required to form a fully connected grid" if they fail to realize it mathematically evaluates to exactly `n - 1`, though it is a fundamental property.
</RISK>
