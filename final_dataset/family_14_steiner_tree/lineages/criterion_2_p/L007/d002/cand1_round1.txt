# Datacenter Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

A large-scale datacenter operates **n** server racks, identified by integers from 1 to **n**. The racks are wired together by a topology of **m** fiber-optic conduits. Each conduit has a known activation cost.

A corporate client has secured leases for a specific group of **t** racks. Your objective is to bring a subset of the conduits online so that the client's leased racks are all mutually able to exchange data. The data packets can freely transit through any unleased racks along the way; these unleased racks function as cost-free relays once the underlying conduits are brought online. 

Find the absolute minimum total activation cost to establish a fully functional communication infrastructure for the client's leased racks.

## Input

The first line provides three integers: **n**, **m**, and **t** (1 ≤ **t** ≤ **n**, 1 ≤ **n** ≤ 200000, **m** = **n** − 1).
The second line contains **t** distinct integers representing the identifiers of the leased racks.
Each of the subsequent **m** lines contains three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000), meaning a conduit can be activated between rack **u** and rack **v** for a cost of **w**. The given infrastructure of **m** conduits guarantees that a path exists between any two racks when fully activated.

## Output

Print a single integer representing the minimum total activation cost to connect all leased racks.
