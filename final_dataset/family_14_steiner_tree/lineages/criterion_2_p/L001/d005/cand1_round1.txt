<STATEMENT>
# Problem B — Core Factions

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of $n$ binary variables, $X_1, X_2, \dots, X_n \in \{0, 1\}$. 
The system features $m$ quadratic terms. Each term $k$ is defined by a pair of variables $(X_u, X_v)$ and an associated coefficient $W_k$.

A specific set of $t$ variables are designated as **fixed**. Your objective is to assign a binary value to each of the $n$ variables to minimize the objective function:
$$ Z = \sum_{k=1}^m W_k \cdot X_{u_k} \cdot X_{v_k} $$

Your assignment must satisfy the following algebraic rules:
1. For every fixed variable $c$, you must assign $X_c = 1$.
2. The assigned values must satisfy the structural balance equation:
   $$ \sum_{i=1}^n X_i - \sum_{k=1}^m (X_{u_k} \cdot X_{v_k}) = 1 $$

The pairs $(u_k, v_k)$ are structured such that they form a minimal complete basis: there is exactly one sequence of overlapping pairs relating any two variables in the system.

You must determine the absolute minimum value of $Z$ required to yield a valid assignment.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers: the indices of the fixed variables.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000) representing a quadratic term between variable u and variable v with a coefficient of w.

## Output

Print a single integer: the minimum value of $Z$ required for a valid assignment.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the fixed variables are 1 and 4, so $X_1 = 1$ and $X_4 = 1$. If we only assign 1 to these two ($\sum X_i = 2$), all products $X_u \cdot X_v$ would be 0, which violates $2 - 0 = 1$. To satisfy the structural balance equation, we must also set $X_2 = 1$ and $X_3 = 1$. This yields $\sum X_i = 4$. The terms (1,2), (2,3), and (3,4) evaluate to 1, giving $\sum X_u \cdot X_v = 3$. Since $4 - 3 = 1$, the assignment is valid. The objective function $Z$ evaluates to 5 + 1 + 2 = 8.

In Example 2, there is only one fixed variable ($X_3 = 1$). By setting all other variables to 0, we have $\sum X_i = 1$ and $\sum X_u \cdot X_v = 0$. The equation $1 - 0 = 1$ is satisfied. The minimum value of $Z$ is 0.

In Example 3, fixed variables 1, 2, and 3 must all be assigned 1. Thus $\sum X_i = 3$. The terms (1,2) and (2,3) evaluate to 1, yielding $\sum X_u \cdot X_v = 2$. The equation $3 - 2 = 1$ is satisfied. The value of $Z$ is 4 + 5 = 9.
