Let's analyze the algebraic condition. Let $S$ be the set of activated modules, so $|S| = X^T X = k$. The term $X^T A X$ counts each energized channel twice (since $A$ is symmetric), so $X^T A X = 2e$, where $e$ is the number of energized channels (edges with both endpoints in $S$). The condition $X^T A X = 2 X^T X - 2$ simplifies to $2e = 2k - 2$, or $e = k - 1$. This means the subgraph induced by the activated modules $S$ must be a tree (or forest, but since $e = k - 1$ exactly, it must be connected and acyclic, hence a tree). We are given a tree $T$ of all modules, and we must find a connected subtree of $T$ that contains all $t$ primary modules, minimizing the sum of edge weights. This is the classic Minimum Steiner Tree problem on a tree, which can be solved by finding the union of paths between all pairs of primary modules in the tree, or equivalently, by taking the minimal subtree that spans all primary modules.

```python
import sys

def solve():
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    n = int(input_data[0])
    m = int(input_data[1])
    t = int(input_data[2])
    
    primary = [int(input_data[3 + i]) for i in range(t)]
    
    adj = [[] for _ in range(n + 1)]
    idx = 3 + t
    for _ in range(m):
        u = int(input_data[idx])
        v = int(input_data[idx+1])
        w = int(input_data[idx+2])
        adj[u].append((v, w))
        adj[v].append((u, w))
        idx += 3
        
    parent = [0] * (n + 1)
    parent_weight = [0] * (n + 1)
    depth = [0] * (n + 1)
    order = [1]
    parent[1] = 0
    
    for u in order:
        for v, w in adj[u]:
            if v != parent[u]:
                parent[v] = u
                parent_weight[v] = w
                depth[v] = depth[u] + 1
                order.append(v)
                
    is_primary = [False] * (n + 1)
    for c in primary:
        is_primary[c] = True
        
    in_steiner = [False] * (n + 1)
    for c in primary:
        in_steiner[c] = True
        
    for u in reversed(order):
        if in_steiner[u] and parent[u] != 0:
            in_steiner[parent[u]] = True
            
    total_penalty = 0
    for u in range(2, n + 1):
        if in_steiner[u]:
            total_penalty += parent_weight[u]
            
    print(total_penalty)

if __name__ == "__main__":
    solve()
```
