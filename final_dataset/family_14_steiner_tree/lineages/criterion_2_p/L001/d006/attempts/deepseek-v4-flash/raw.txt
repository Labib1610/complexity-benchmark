 We are given a tree (since there’s exactly one path between any two nodes), and we must choose a subset of nodes containing all primary nodes such that:

\[
\sum_{u \in S} (2 - c(u)) = 2
\]

Where \( c(u) \) is the number of activated neighbors of \( u \) in the chosen subset.

---

### Step 1 – Understanding the condition

Let \( |S| = k \), and let \( e \) be the number of edges inside the induced subgraph on \( S \).

For each node \( u \in S \), \( c(u) \) is its degree inside \( S \).  
Summing over all \( u \in S \):

\[
\sum_{u \in S} c(u) = 2e
\]

So the condition becomes:

\[
\sum_{u \in S} (2 - c(u)) = 2k - 2e = 2
\]

Thus:

\[
2k - 2e = 2 \quad \Rightarrow \quad k - e = 1
\]

---

### Step 2 – Interpreting \( k - e = 1 \)

In a tree, if we take a connected subset of nodes, then \( e = k - 1 \), so \( k - e = 1 \) automatically holds.  
If the subset is disconnected, then \( e < k - 1 \), so \( k - e > 1 \), which is invalid.

Therefore, the activated set must be **connected** and contain all primary nodes.

---

### Step 3 – Problem reduction

We need to find the minimum total edge weight of a connected subgraph that contains all primary nodes.

This is exactly the **Steiner tree** problem on a tree, which is easy:  
The minimal connected subgraph containing a set of required nodes is the union of all paths between them.  
In a tree, this is simply the minimal subtree that spans all required nodes.

---

### Step 4 – Algorithm

1. Mark all primary nodes as required.
2. Root the tree arbitrarily (say at node 1).
3. Do a DFS to compute for each node whether its subtree contains any required node.
4. The minimal subtree is the set of edges where both endpoints have required nodes in their subtrees (or one endpoint is required itself).
5. Sum the weights of those edges.

---

### Step 5 – Implementation details

We can do a DFS from any root, and for each edge (parent–child), if the child’s subtree contains at least one required node, then that edge must be included.

---

### Step 6 – Complexity

O(n) time and memory.

---

Here’s the Python solution:

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    required = set(map(int, input().split()))
    
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    visited = [False] * (n + 1)
    
    def dfs(u):
        visited[u] = True
        has_required = u in required
        total_cost = 0
        for v, w in adj[u]:
            if not visited[v]:
                child_has, cost = dfs(v)
                if child_has:
                    total_cost += cost + w
                    has_required = True
        return has_required, total_cost
    
    _, ans = dfs(1)
    print(ans)

if __name__ == "__main__":
    solve()
```
