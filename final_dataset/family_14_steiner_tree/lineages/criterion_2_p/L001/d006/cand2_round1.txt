# Problem B — Core Factions

Time limit: 2 s   Memory limit: 256 MB

## Description

You are configuring a system of $n$ modules (indexed 1 to $n$) and $m$ bidirectional channels. The channels are structured such that between any two modules, there is exactly one non-repeating sequence of channels linking them.

You must choose a configuration vector $X \in \{0, 1\}^n$, where $X_i = 1$ means module $i$ is activated, and $X_i = 0$ means it is dormant. A specific set of $t$ primary modules must be activated, meaning you must set $X_c = 1$ for every primary module $c$.

Each channel between a pair of modules has a specific positive maintenance penalty $w$. A channel connecting module $u$ and module $v$ is considered *energized* if and only if both its endpoints are activated ($X_u = 1$ and $X_v = 1$). For every energized channel, you must pay its maintenance penalty exactly once. Channels that are not energized incur no penalty.

To ensure system stability, your configuration vector $X$ must satisfy the following routing condition:
It must be possible to assign a direction to each individual energized channel (making it point from one of its activated endpoints to the other) such that:
- Exactly one activated module has exactly $0$ outgoing energized channels.
- Every other activated module has exactly $1$ outgoing energized channel.

(Dormant modules are fully ignored and do not participate in energized channels.)

You must determine the absolute minimum total maintenance penalty required to yield a valid configuration vector $X$.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$).
The second line contains $t$ distinct integers: the indices of the primary modules.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a channel connecting module $u$ and module $v$ with a maintenance penalty of $w$.
These $m$ channels are guaranteed to form the structure described above (exactly one non-repeating sequence of channels linking any two modules).

## Output

Print a single integer: the minimum total maintenance penalty required for a valid configuration.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the primary modules are 1 and 4, so $X_1 = 1$ and $X_4 = 1$. If we only activate these two, there are no energized channels. Module 1 and module 4 would both have 0 outgoing energized channels, which violates the rule that exactly one activated module has 0 outgoing channels. To satisfy the condition, we must also activate modules 2 and 3. The channels (1,2), (2,3), and (3,4) become energized. We can direct them as $1 \to 2$, $2 \to 3$, and $4 \to 3$. Then modules 1, 2, and 4 each have exactly 1 outgoing energized channel, and module 3 has exactly 0. This configuration is valid. The total penalty is 5 + 1 + 2 = 8.

In Example 2, there is only one primary module ($X_3 = 1$). By keeping all other modules dormant, there are no energized channels. Module 3 is the only activated module, and it has 0 outgoing energized channels. The condition is perfectly satisfied. The minimum total penalty is 0.

In Example 3, primary modules 1, 2, and 3 must all be activated. The channels (1,2) and (2,3) are energized. We can direct them as $1 \to 2$ and $3 \to 2$. Modules 1 and 3 have 1 outgoing channel each, while module 2 has 0. The condition is satisfied. The total penalty is 4 + 5 = 9.
</STATEMENT>
<RATIONALE>
The surviving model recognized that the algebraic equation $X^T A X = 2 X^T X - 2$ simplified to $E = V - 1$, which on a tree graph forces the activated vertices to form a connected subtree. To break this recognition, the equation was replaced with an orientation condition: requiring energized edges to be directable such that exactly one vertex has out-degree 0 and the rest have out-degree 1. Because the underlying graph is a forest, the number of out-degree 0 vertices under such an orientation exactly equals the number of connected components, meaning this condition covertly forces the induced subgraph to be connected. This forces the model to independently deduce the topological equivalence rather than relying on algebraic pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
Any subgraph of a tree is a forest; in a directed forest where maximum out-degree is 1, the number of vertices with out-degree 0 equals the number of connected components, so requiring exactly 1 such vertex is mathematically identical to requiring the activated modules to form a connected subgraph containing the primary modules, leaving the minimum penalty unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks for the minimum weight connected subgraph spanning a set of terminal vertices on a tree (the Steiner tree on a tree), which remains solvable in O(n) time.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret "assign a direction" as requiring the output to include the orientations, though the Output section explicitly asks for a single integer penalty and the text says "It must be possible to assign".
</RISK>
