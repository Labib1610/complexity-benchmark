# Problem B — Activating the Primary Network

Time limit: 2 s   Memory limit: 256 MB

## Description

A large colony consists of **n** outposts (numbered 1 to **n**). You are provided with a list of **m** potential bidirectional transmission lines that can be activated between specific pairs of outposts. Each line has a known activation power draw. 

The provided lines form a complete and unique-routing network for the colony: all outposts are connected, and there is exactly one valid sequence of lines between any two outposts. 

A specific group of **t** outposts are designated as **command** outposts. Your objective is to choose a subset of the potential transmission lines to activate such that every command outpost can communicate with every other command outpost (signals can be routed through any activated intermediate outposts). Determine the minimum total activation power draw required to accomplish this.

## Input

The first line contains three integers **n**, **m**, and **t**. The number of outposts **n** is a positive integer capped by the colony's maximum capacity of 200000. The number of command outposts **t** is between 1 and **n** inclusive. The number of lines **m** is exactly **n** minus 1.
The second line contains **t** distinct integers representing the ids of the command outposts.
Each of the next **m** lines contains three integers **u**, **v**, and **w**. These denote a potential transmission line between distinct outposts **u** and **v** (both between 1 and **n**) with an activation power draw **w**. The power draw **w** is at least 1 and cannot exceed the hardware's peak rating of 1000000.

## Output

Print a single integer: the minimum total activation power draw to fully connect all command outposts.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the command outposts 1 and 4 can only communicate if the lines between (1,2), (2,3), and (3,4) are all activated. The total power draw is 5 + 1 + 2 = 8.
In Example 2, there is only one command outpost, so no lines need to be activated.
In Example 3, command outposts 1, 2, and 3 must all be connected. Activating line (1,2) with power draw 4 and line (2,3) with power draw 5 achieves this for a total power draw of 9.

<RATIONALE>
I replaced the explicit "minimally sufficient" and "removing any single link" wording with the equivalent structural guarantee that "all outposts are connected, and there is exactly one valid sequence of lines between any two outposts." This removes the specific phrasing affordances that models were using to trigger their tree-reduction algorithms, while maintaining the exact same graph properties. I also applied strategy S07 by expressing the numeric bounds through physical limits (e.g., "colony's maximum capacity of 200000") rather than bare inequalities, forcing models to parse the constraints from the scenario prose.
</RATIONALE>

The graph is still a tree and the goal is still to find the minimum weight subtree spanning a specified set of vertices, meaning the optimal subset of edges and its total cost remains identical for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a Steiner tree on a graph that is guaranteed to be a tree, which has a unique solution and can be solved in O(n) time, keeping it in the polynomial complexity class.
</PRESERVED_CLASS>
