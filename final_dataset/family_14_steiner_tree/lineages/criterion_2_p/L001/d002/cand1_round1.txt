<STATEMENT>
# Problem B — Activating the Primary Network

Time limit: 2 s   Memory limit: 256 MB

## Description

A large facility consists of **n** locations (numbered 1 to n). You are provided with a list of **m** potential bidirectional data links that can be activated between specific pairs of locations. Each link has a known activation cost. 

A specific group of **t** locations are designated as **primary**. You must establish a secure communication sub-network. To do this, you will first select a subset of the locations to form a "secure zone". This zone MUST include all **t** primary locations (and may include any number of non-primary locations). 

Additionally, you must activate a subset of the potential links such that both of the following conditions are met:
1. Every activated link connects two locations that are BOTH inside the secure zone.
2. All locations in the secure zone must be able to communicate with every other location in the secure zone, using ONLY the activated links.

Your objective is to find a valid secure zone and a corresponding set of activated links that minimizes the total activation cost of the links. Determine this absolute minimum total activation cost.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers: the ids of the primary locations.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): a potential link between location u and location v with an activation cost of w.

## Output

Print a single integer: the minimum total activation cost of the links required to form a valid secure zone.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the primary locations 1 and 4 must be in the secure zone. To connect them, locations 2 and 3 must also be included in the secure zone. The links (1,2), (2,3), and (3,4) must all be activated. The total cost is 5 + 1 + 2 = 8.
In Example 2, there is only one primary location (3). The secure zone can consist solely of location 3 with no links activated, resulting in a valid configuration with a cost of 0.
In Example 3, primary locations 1, 2, and 3 must all be in the secure zone. Activating link (1,2) with cost 4 and link (2,3) with cost 5 connects all locations in the zone for a total minimum cost of 9.
</STATEMENT>
<RATIONALE>
Removed the explicit guarantee that the provided links form a "minimally sufficient" connected network, replacing it with a neutral description. Introduced a dual-optimization framing where the solver must explicitly select a subset of vertices (the "secure zone") and a subset of edges connecting them. This forces models to either see through the vertex-selection framing to realize it is mathematically identical to a standard Steiner tree (edge selection only), or get bogged down in a complex and error-prone vertex-inclusion dynamic programming state.
</RATIONALE>
<PRESERVED_ANSWER>
Any valid secure zone and its activated links form a connected subgraph containing the primary locations; since the actual inputs are trees, the unique minimal cost subgraph is the Steiner tree, making the optimal cost identical to the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is mathematically identical to finding the minimum weight connected subgraph containing a subset of vertices on a tree, which remains solvable in O(n) time via a simple post-order traversal.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the t=1 case, thinking a single-node secure zone requires at least one link to "communicate", but the standard mathematical interpretation of "every other location" for a set of size 1 vacuously holds and Example 2 explicitly clarifies this edge case.
</RISK>
