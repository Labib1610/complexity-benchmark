# Problem B — Activating the Primary Network

Time limit: 2 s   Memory limit: 256 MB

## Description

A large facility consists of **n** locations (numbered 1 to n). You are provided with a list of **m** bidirectional data links that are currently active between specific pairs of locations. Each link has a known maintenance cost. The network of available links connects all **n** locations. Furthermore, there is exactly one valid sequence of links connecting any two locations in the facility, meaning the network contains no redundant routes.

A specific group of **t** locations are designated as **primary** operations centers. To reduce maintenance expenses, your objective is to deactivate unnecessary links. You may deactivate a link as long as, after its removal, every primary location can still communicate with every other primary location (data can be routed through any remaining active links, including those at non-primary locations). You must continue deactivating links until no additional link can be removed without isolating at least one primary location from the others.

Determine the total maintenance cost of the links that will remain active after all possible safe deactivations have been made.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers: the ids of the primary locations.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): an available link between location u and location v with a maintenance cost of w.

## Output

Print a single integer: the total maintenance cost of the links that remain active.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the primary locations 1 and 4 must remain able to communicate. The sequence of links (1,2), (2,3), and (3,4) forms the only route between them. None of these links can be deactivated. The total maintenance cost of the remaining links is 5 + 1 + 2 = 8.
In Example 2, there is only one primary location. It trivially can communicate with itself, so all links can be safely deactivated. The total cost of remaining links is 0.
In Example 3, primary locations 1, 2, and 3 must all remain connected. Removing either link (1,2) or (2,3) would isolate at least one primary location. Both must remain active, for a total cost of 4 + 5 = 9.
