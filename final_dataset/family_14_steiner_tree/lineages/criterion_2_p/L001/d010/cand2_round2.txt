<STATEMENT>
# Problem B — Secure Deployment

Time limit: 2 s   Memory limit: 256 MB

## Description

You are planning a secure deployment across $n$ outposts and $m$ potential bidirectional communication links. 

You must assign a deployment state $x_i \in \{0, 1\}$ to each outpost $i$ ($1 \le i \le n$). An outpost is 'active' if $x_i = 1$, and 'dormant' if $x_i = 0$. A specific subset of $t$ critical outposts must be active (that is, $x_i = 1$ for these outposts).

When a configuration is chosen, all potential links that connect two active outposts are established. Links where at least one outpost is dormant are not established.

Each active outpost is allocated a baseline budget of 2 security tokens. However, establishing a secure link between two active outposts requires a synchronization fee: 1 token is deducted from the budget of *each* of those two connected outposts. 
The *net token surplus* of a configuration is calculated by summing the remaining tokens across all active outposts (note that an individual outpost's remaining tokens will be negative if it has more than two established links). 
A configuration is considered **valid** if its net token surplus evaluates to exactly 2.

Each potential link $j$ has a positive operation cost $w_j$. The *deployment cost* of a configuration is the sum of the operation costs for all of its established links.

Your task is to determine the absolute minimum deployment cost among all valid configurations.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, and $m$ is exactly the theoretical minimum number of links required to connect $n$ outposts into a single network).
The second line contains $t$ distinct integers: the IDs of the critical outposts.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a potential link between outpost $u$ and outpost $v$ with an operation cost of $w$.
It is guaranteed that a message can be relayed between any two outposts using the provided links.

## Output

Print a single integer: the minimum deployment cost of a valid configuration.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the critical outposts are 1 and 4. 
If we only activate these two outposts ($x = [1, 0, 0, 1]$):
- Outpost 1 is allocated 2 tokens and consumes 0 (no established links).
- Outpost 4 is allocated 2 tokens and consumes 0.
The net token surplus is $2 + 2 = 4$. This configuration is invalid.
If we activate all four outposts ($x = [1, 1, 1, 1]$):
- Outpost 1 is allocated 2 tokens, consumes 1 (shared with 2). Surplus: 1.
- Outpost 2 is allocated 2 tokens, consumes 2 (shared with 1 and 3). Surplus: 0.
- Outpost 3 is allocated 2 tokens, consumes 2 (shared with 2 and 4). Surplus: 0.
- Outpost 4 is allocated 2 tokens, consumes 1 (shared with 3). Surplus: 1.
The net token surplus is $1 + 0 + 0 + 1 = 2$.
This configuration is valid. The deployment cost is $5 + 1 + 2 = 8$.

In Example 2, the only critical outpost is 3. By activating only outpost 3 ($x = [0, 0, 1, 0, 0]$):
- Outpost 3 is allocated 2 tokens and consumes 0.
The net token surplus is 2.
This configuration is valid, and the deployment cost is 0.

In Example 3, critical outposts 1, 2, and 3 must all be active ($x = [1, 1, 1]$).
- Outpost 1 is allocated 2 tokens, consumes 1. Surplus: 1.
- Outpost 2 is allocated 2 tokens, consumes 2. Surplus: 0.
- Outpost 3 is allocated 2 tokens, consumes 1. Surplus: 1.
The net token surplus is $1 + 0 + 1 = 2$.
This configuration is valid, and the deployment cost is $4 + 5 = 9$.
</STATEMENT>

I replaced the explicit structural indicators "m = n - 1" and "connected grid" with indirect descriptive bounds ("theoretical minimum number of links to connect n outposts"). I also rephrased the validity equation using a security token budget while strictly maintaining the original 2V - 2E = 2 math. This forces the model to independently deduce that the graph is a tree and that the token balance equation is functionally equivalent to requiring a connected induced subgraph, rather than relying on shallow pattern matching of explicit tree indicators.
