**Solution Explanation**

For every vertex `i` we have a binary variable `X_i ∈ {0,1}`.
For an edge `e = (u,v)`  

```
(X_u – X_v)² = X_u + X_v – 2·X_u·X_v                (1)
```

because `X_u , X_v` are `0/1`.

--------------------------------------------------------------------

### 1.   Reformulating the given equation  

```
∑ (X_u – X_v)²  +  ∑ (2 – D_i)·X_i = 2
```

`D_i` – degree of vertex `i`.

Using (1)

```
∑ (X_u + X_v) – 2·∑ X_u·X_v  +  ∑ (2 – D_i)·X_i = 2
```

`∑ (X_u + X_v)` counts each vertex `i` exactly `D_i` times, therefore

```
∑ D_i·X_i  – 2·∑ X_u·X_v  +  ∑ (2 – D_i)·X_i = 2
```

The `D_i` terms cancel:

```
2·∑ X_i  – 2·∑ X_u·X_v = 2
```

Dividing by `2`

```
∑ X_i  –  ∑ X_u·X_v = 1                              (2)
```

Define  

* `S = ∑ X_i` – number of vertices with value `1`  
* `P = ∑ X_u·X_v` – number of edges whose both ends are `1`

(2) becomes `S – P = 1`.

--------------------------------------------------------------------

### 2.   What does `S – P = 1` mean on a tree?

The vertices with `X_i = 1` form a subgraph of the tree.
Because the original graph is a tree, this subgraph is a **forest**.
For a forest with `k` connected components

```
#edges  =  #vertices – k          →   P = S – k
```

Insert into `S – P = 1` :

```
S – (S – k) = k = 1
```

Hence the subgraph must have **exactly one connected component**,
i.e. the set `{ i | X_i = 1 }` must be a **connected non‑empty** set of vertices.

--------------------------------------------------------------------

### 3.   The optimisation problem

*All critical vertices must belong to the set* (they are forced to `1`).

The cost to minimise is  

```
∑ W_e · X_u·X_v   =   sum of weights of edges whose both ends are 1
```

Therefore we have to choose a **connected vertex set containing all
critical vertices** with minimum total weight of its internal edges.

On a tree the unique cheapest connected set that contains a given
terminal set is the **minimal Steiner tree**:
the union of all simple paths between the terminals.
An edge belongs to this tree **iff** after removing the edge both sides
contain at least one terminal.

Consequently the answer is simply the sum of weights of all edges
that separate the terminal set.

--------------------------------------------------------------------

### 4.   Computing the answer

Root the tree arbitrarily (vertex `1`).  
For every vertex `v` let `cnt[v]` be the number of critical vertices in the
subtree of `v`.

* `cnt[v]` can be computed by a single DFS (post‑order).
* For the edge `(parent[v] , v)` with weight `w` :

```
if 0 < cnt[v] < t          // terminals on both sides
        answer += w
```

The algorithm is linear `O(n)` and uses `O(n)` memory.

--------------------------------------------------------------------

### 5.   Correctness Proof  

We prove that the algorithm outputs the minimum possible evaluation cost.

---

#### Lemma 1  
For any binary assignment `X` satisfying the original equation,
the set `A = { i | X_i = 1 }` is a non‑empty connected subgraph.

*Proof.*  
From Section&nbsp;2 we derived `S – P = 1`.  
In a tree the induced subgraph of `A` is a forest with `k` components,
so `P = S – k`.  
Thus `S – (S – k) = k = 1`.  
Hence `k = 1` and `A` is connected and non‑empty. ∎



#### Lemma 2  
For any connected vertex set `A` the equality `S – P = 1` holds.

*Proof.*  
If `A` is connected, the induced subgraph is a tree with `|A|` vertices
and `|A|‑1` edges, i.e. `P = S – 1`.  
Therefore `S – P = 1`. ∎



#### Lemma 3  
Let `T` be the minimal Steiner tree of the critical vertices
(the union of all paths between them).  
For every feasible assignment `X` the set `A = { i | X_i = 1 }`
contains `T` as a subgraph.

*Proof.*  
`A` is connected and contains all critical vertices (they are forced to `1`).
The unique minimal connected subgraph containing those vertices is `T`,
hence `T ⊆ A`. ∎



#### Lemma 4  
The total weight of edges inside `T` equals the sum of weights of all
edges whose removal leaves at least one critical vertex on each side.

*Proof.*  
An edge `e` belongs to `T` iff the two sides of `e` each contain a terminal,
otherwise the terminals are all on one side and `e` is unnecessary.
∎



#### Lemma 5  
The algorithm returns exactly the total weight of `T`.

*Proof.*  
During the DFS we compute `cnt[v]` = number of terminals in the subtree
of `v`.  
For the edge `(parent[v], v)` the side of `v` contains `cnt[v]` terminals,
the other side contains `t‑cnt[v]`.  
The algorithm adds the edge weight precisely when `0 < cnt[v] < t`,
i.e. when both sides contain a terminal.
By Lemma&nbsp;4 these are exactly the edges of `T`. ∎



#### Lemma 6  
For any feasible assignment `X` the evaluation cost is at least the
algorithm’s answer.

*Proof.*  
By Lemma&nbsp;3 the edge set of `A` contains all edges of `T`.  
All those edges contribute their weights to the cost
`∑ W_e·X_u·X_v`.  
Thus the cost of `X` is ≥ total weight of `T`, which equals the algorithm’s
output by Lemma&nbsp;5. ∎



#### Lemma 7  
There exists a feasible assignment whose cost equals the algorithm’s
answer.

*Proof.*  
Take `A =` vertex set of `T`.  
`A` is connected, contains all critical vertices, therefore by Lemma&nbsp;2
the corresponding `X` satisfies the original equation.
Its cost is exactly the sum of weights of edges of `T`,
i.e. the algorithm’s answer (Lemma&nbsp;5). ∎



#### Theorem  
The algorithm outputs the minimum possible evaluation cost among all
valid state vectors.

*Proof.*  
Lemma&nbsp;6 shows no feasible solution can have cost smaller than the
algorithm’s output.  
Lemma&nbsp;7 provides a feasible solution attaining exactly that cost.
Hence the output is optimal. ∎



--------------------------------------------------------------------

### 6.   Complexity Analysis  

* `O(n)` time: one DFS traversal and a linear post‑order pass.  
* `O(n)` memory: adjacency list, several integer arrays.

Both limits satisfy the constraints (`n ≤ 200 000`).

--------------------------------------------------------------------

### 7.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    n = int(next(it))
    m = int(next(it))          # = n-1, not used separately
    t = int(next(it))

    is_term = [False] * (n + 1)
    for _ in range(t):
        v = int(next(it))
        is_term[v] = True

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        w = int(next(it))
        adj[u].append((v, w))
        adj[v].append((u, w))

    parent = [0] * (n + 1)
    pw = [0] * (n + 1)          # weight to parent
    order = []

    # iterative DFS to avoid recursion depth problems
    stack = [1]
    parent[1] = -1
    while stack:
        v = stack.pop()
        order.append(v)
        for to, w in adj[v]:
            if to != parent[v]:
                parent[to] = v
                pw[to] = w
                stack.append(to)

    cnt = [0] * (n + 1)
    ans = 0
    # process in reverse order (post‑order)
    for v in reversed(order):
        c = 1 if is_term[v] else 0
        for to, _ in adj[v]:
            if parent[to] == v:          # child
                c += cnt[to]
        cnt[v] = c
        if v != 1:                       # has a parent edge
            if 0 < c < t:
                ans += pw[v]

    print(ans)


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
