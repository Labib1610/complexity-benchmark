We can model this as a tree problem.  
The validity condition simplifies to:  

- If a node has degree 1 (leaf), then setting it to 1 contributes `(2 - 1) = 1` to the second sum.  
- If a node has degree 2, it contributes 0.  
- If a node has degree > 2, it contributes negative, which is not possible here since it's a tree and max degree can be large, but the equation must hold.

Let’s analyze:

The equation is:

\[
\sum_{(u,v)} (X_u - X_v)^2 + \sum_i (2 - D_i) X_i = 2
\]

For a tree, \(D_i\) is the degree of node \(i\).  
The first sum counts the number of edges where the two endpoints differ.  
The second sum:  
- For leaves (\(D_i=1\)): contributes \(+1\) if \(X_i=1\).  
- For internal nodes (\(D_i=2\)): contributes \(0\).  
- For nodes with \(D_i>2\): contributes negative if \(X_i=1\), but that would require more careful handling.

But since \(m = n-1\), the sum of degrees is \(2(n-1)\).  
The sum of \((2 - D_i)\) over all nodes is:

\[
\sum (2 - D_i) = 2n - 2(n-1) = 2
\]

So the second sum is always 2 if all \(X_i=1\).  
If some \(X_i=0\), the second sum decreases by \((2 - D_i)\) for each zero.

The first sum counts edges with different endpoints.

We need total = 2.

Let’s denote:
- \(S_1\) = number of edges with different endpoints.
- \(S_2 = \sum (2 - D_i) X_i\).

We need \(S_1 + S_2 = 2\).

If all \(X_i=1\), then \(S_1=0\), \(S_2=2\), works.  
If we set some to 0, we must adjust.

Let’s think:  
If we set a leaf to 0, \(S_2\) decreases by 1 (since leaf contributes 1 when 1).  
If we set an internal node (degree 2) to 0, \(S_2\) unchanged.  
If we set a node with degree >2 to 0, \(S_2\) increases (because it was negative contribution).

Also, setting a node to 0 may change \(S_1\) depending on neighbors.

We need to find minimal cost among valid assignments.

Observation:  
The only way to get \(S_1 + S_2 = 2\) with some zeros is to have exactly the right combination.  
Since \(S_2\) can be at most 2 (when all 1), and can be less if leaves are 0.

If we set a leaf to 0, \(S_2\) drops by 1, so we need \(S_1\) to increase by 1 to compensate.  
That means exactly one edge incident to that leaf must have different endpoints.  
If we set two leaves to 0, \(S_2\) drops by 2, so we need \(S_1=2\), etc.

But also internal nodes with degree >2: setting them to 0 increases \(S_2\), so we’d need \(S_1\) negative, impossible. So they must be 1.

Thus:  
- All nodes with degree > 2 must be 1.  
- Nodes with degree 2 can be 0 or 1 freely (they don’t affect \(S_2\)).  
- Leaves can be 0 or 1, but each leaf set to 0 requires one incident edge to be different.

Also, critical variables must be 1.

So the problem reduces to:  
We have a tree. Some nodes are forced 1 (critical).  
We can choose 0/1 for others, but:
- Degree >2 nodes must be 1.
- Leaves can be 0, but then exactly one of their incident edges must be different (so neighbor must be 1).
- Degree 2 nodes can be 0 or 1 freely.

We want to minimize sum of \(W_j\) over edges where both endpoints are 1.

This is a tree DP problem.

Let’s root the tree arbitrarily.  
For each node, we consider two states: 0 or 1.  
But constraints:
- If node is critical or degree>2 → must be 1.
- If node is leaf and set to 0 → its parent must be 1 (if parent exists) to make the edge different.

We can do DP with states:
- dp[node][0] = min cost in subtree if node is 0.
- dp[node][1] = min cost in subtree if node is 1.

Transitions:
For each child:
- If node is 0:
  - Child can be 0 or 1, but if child is leaf and child=0, then edge must be different → but node=0, so child must be 1. Actually if node=0 and child=0, edge same, not different. So if child is leaf and child=0, that would require edge different → impossible if node=0. So for leaf child, if node=0, child must be 1.
  - For non-leaf child, child can be 0 or 1 freely.
- If node is 1:
  - Child can be 0 or 1 freely, but if child=0 and child is leaf, that’s fine because edge different.
  - If child=1, add edge weight.

We also must ensure that for any leaf set to 0, its parent is 1. That’s handled in transitions.

Let’s implement.

We’ll root at 1 (or any).  
We’ll precompute degrees.

DP:

```
def dfs(u, parent):
    dp0 = 0  # cost if u=0
    dp1 = 0  # cost if u=1
    for v, w in adj[u]:
        if v == parent: continue
        child0, child1 = dfs(v, u)
        if u == 0:
            # if v is leaf, v must be 1
            if deg[v] == 1:
                dp0 += child1
            else:
                dp0 += min(child0, child1)
        else: # u == 1
            # v can be 0 or 1
            # if v=1, add w
            dp1 += min(child0, child1 + w)
    # enforce constraints
    if critical[u] or deg[u] > 2:
        dp0 = INF
    return dp0, dp1
```

But careful: if u is leaf and u=0, that’s allowed only if parent is 1. That’s handled in parent’s transition.

Also, if u is root and leaf? Then if root=0, no parent to make edge different → invalid. So root leaf must be 1. We can handle by setting dp0=INF for root if deg[root]==1.

Let’s test with examples.

Example 1:  
n=4, edges: 1-2(5), 2-3(1), 3-4(2).  
Degrees: 1:1, 2:2, 3:2, 4:1.  
Critical: 1,4.  
Root at 1.  
Node 1: critical, deg=1 → must be 1.  
Node 4: critical, deg=1 → must be 1.  
So all must be 1? Let’s see:  
If all 1, cost = 5+1+2=8.  
Can we do better?  
If node 2=0, node3=0? Then edges: 1-2 diff, 2-3 same, 3-4 diff → S1=2, S2: leaves 1 and 4 are 1 → S2=2, total=4 ≠2.  
If node2=0, node3=1: edges: 1-2 diff, 2-3 diff, 3-4 same → S1=2, S2=2 → total=4.  
If node2=1, node3=0: edges: 1-2 same, 2-3 diff, 3-4 diff → S1=2, S2=2 → total=4.  
So only all 1 works. Cost=8. Matches.

Example 2:  
n=5, path 1-2-3-4-5, critical: 3.  
Degrees: 1:1,2:2,3:2,4:2,5:1.  
Root at 3.  
We can set 1=0,2=0,3=1,4=0,5=0.  
Check: edges: 1-2 same(0), 2-3 diff, 3-4 diff, 4-5 same → S1=2. S2: only node3=1, deg=2 → contributes 0. Total=2. Valid. Cost=0. Matches.

Example 3:  
n=3, edges: 1-2(4),2-3(5). Critical: 1,2,3.  
All must be 1 → cost=9. Matches.

So DP works.

We need to be careful with large n (200k) → recursion depth. Use iterative DFS or set recursion limit high.

Let’s implement.

```python
import sys
sys.setrecursionlimit(300000)
INF = 10**18

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    critical = [False]*(n+1)
    for x in map(int, input().split()):
        critical[x] = True
    adj = [[] for _ in range(n+1)]
    deg = [0]*(n+1)
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
        deg[u] += 1
        deg[v] += 1
    
    parent = [0]*(n+1)
    order = [1]
    parent[1] = -1
    for u in order:
        for v, w in adj[u]:
            if v != parent[u]:
                parent[v] = u
                order.append(v)
    
    dp0 = [0]*(n+1)
    dp1 = [0]*(n+1)
    
    for u in reversed(order):
        c0 = 0
        c1 = 0
        for v, w in adj[u]:
            if v == parent[u]:
                continue
            if u == 0:  # not possible here, we compute later
                pass
            # We'll compute based on u's state
        # Actually we need to compute both states
        # Let's compute dp0[u], dp1[u]
        sum0 = 0
        sum1 = 0
        for v, w in adj[u]:
            if v == parent[u]:
                continue
            # child's dp
            child0 = dp0[v]
            child1 = dp1[v]
            # if u=0
            if deg[v] == 1:
                # leaf child must be 1
                sum0 += child1
            else:
                sum0 += min(child0, child1)
            # if u=1
            sum1 += min(child0, child1 + w)
        # enforce constraints
        if critical[u] or deg[u] > 2:
            dp0[u] = INF
        else:
            dp0[u] = sum0
        dp1[u] = sum1
    
    # root is 1
    ans = min(dp0[1], dp1[1])
    # But if root is leaf and dp0 chosen, invalid because no parent to make edge different
    if deg[1] == 1:
        ans = dp1[1]
    print(ans)

if __name__ == "__main__":
    solve()
```
