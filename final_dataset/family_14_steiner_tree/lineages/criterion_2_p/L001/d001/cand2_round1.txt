<STATEMENT>
# Problem B — Cabling the Mandatory Sites (Constrained Layout)

Time limit: 2 s   Memory limit: 256 MB

## Description

A campus master plan contains a collection of sites. The campus has at least one site, and its zoning permit restricts the maximum expansion to two hundred thousand sites. Certain pairs of sites can be joined by a cabling option at a given cost. The cost of any individual option is a positive integer that cannot exceed the single-link budget cap of one million.

Among all sites, a specific subset are designated as mandatory. There is always at least one mandatory site, and the subset could include up to the total number of sites on campus. These mandatory sites must all end up linked to each other through the cabling you install, either directly or through intermediate relay sites.

The available cabling options provide full connectivity across the campus. However, the network architecture is strictly non-redundant: every site can communicate with every other site, but the failure of any single option would sever connectivity between some sites.

Install a set of cabling options of minimum total cost so that all mandatory sites are linked. Report that minimum total cost.

## Input

The first line provides three integers: the total number of sites **n**, the number of available cabling options **m**, and the number of mandatory sites **t**. The constraints on these values are dictated by the physical limits and network architecture described above (specifically, the strict non-redundancy dictates that **m** is exactly one less than **n**).
The second line contains **t** distinct integers: the ids of the mandatory sites (which are numbered starting from 1 up to **n**).
Each of the next **m** lines contains three integers **u**, **v**, and **w** (**u** ≠ **v**): a cabling option joining sites **u** and **v** at cost **w**.

## Output

Print a single integer: the minimum total cost to connect all mandatory sites.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1 the mandatory sites 1 and 4 are linked only through 2 and 3, so all three options (5+1+2 = 8) are needed. In Example 2 there is one mandatory site, so no cabling is needed.
</STATEMENT>
<RATIONALE>
The explicit mention of "exactly one possible cabling route" has been removed, as this strongly hinted at unique paths and a tree structure. Instead, the problem now describes the network as fully connected but where every edge is a bridge ("failure of any single option would sever connectivity"). Additionally, all direct numeric bounds (like `1 <= n <= 200000`) were replaced with indirect physical limits ("at least one site", "maximum expansion to two hundred thousand sites"), forcing the model to deduce the constraints from the text.
</RATIONALE>
<PRESERVED_ANSWER>
The graph is still a tree (a connected graph where every edge is a bridge), and the task remains to find the minimum weight subtree that spans the mandatory sites, so the exact same edges are selected and the cost is identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the Steiner tree on a tree, which is solvable in polynomial time (O(n)) by pruning leaves that are not mandatory sites.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "sever connectivity between some sites" as implying the graph could have cycles as long as there is at least one bridge, but the phrase "failure of *any* single option" ensures that *every* edge is a bridge, uniquely defining a tree.
</RISK>
