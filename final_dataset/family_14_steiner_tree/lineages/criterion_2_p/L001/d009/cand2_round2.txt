<STATEMENT>
# Problem B — Network Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

You are managing a communication network consisting of $n$ stations and $m$ bidirectional channels. The channels form a connected network.

You must assign an operational state to each station: either active or inactive. 
A specific set of $t$ mandatory stations must be active.

A channel is considered *active* if and only if both of its endpoint stations are active. 
To ensure proper synchronization, an assignment of states is considered **valid** if the total number of active stations is exactly one greater than the total number of active channels.

Each channel $j$ has a positive maintenance penalty $w_j$. The *activation cost* of an assignment is the sum of the maintenance penalties of all active channels.

Your task is to determine the absolute minimum activation cost among all valid assignments.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$).
The second line contains $t$ distinct integers: the IDs of the mandatory stations.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a bidirectional channel between station $u$ and station $v$ with a maintenance penalty of $w$.
The channels are guaranteed to form a connected network.

## Output

Print a single integer: the minimum activation cost of a valid assignment.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the mandatory stations are 1 and 4. 
If we only activate these two stations:
- Active stations: 1, 4 (total 2).
- Active channels: none (total 0).
The number of active stations minus the number of active channels is $2 - 0 = 2 \neq 1$. This assignment is invalid.
If we activate all four stations:
- Active stations: 1, 2, 3, 4 (total 4).
- Active channels: the channel between 1 and 2, between 2 and 3, and between 3 and 4 (total 3).
The difference is $4 - 3 = 1$. This assignment is valid. The activation cost is $5 + 1 + 2 = 8$.

In Example 2, there is only one mandatory station (3). By activating only station 3:
- Active stations: 3 (total 1).
- Active channels: none (total 0).
The difference is $1 - 0 = 1$. This assignment is valid, and the activation cost is 0.

In Example 3, mandatory stations 1, 2, and 3 must all be active.
- Active stations: 1, 2, 3 (total 3).
- Active channels: the channel between 1 and 2, and between 2 and 3 (total 2).
The difference is $3 - 2 = 1$. This assignment is valid, and the activation cost is $4 + 5 = 9$.
</STATEMENT>
<RATIONALE>
The explicit tree construction description was removed and replaced with a connected network where $m = n - 1$. The local degree sum condition $B(x) = 2$ was replaced with the mathematically equivalent global Euler characteristic condition (active stations - active channels = 1). This forces the model to independently deduce that the network is a tree and that the Euler condition implies the active stations must form a single connected component, defeating models that rely on explicit tree keywords to trigger tree-pruning algorithms.
</RATIONALE>
<PRESERVED_ANSWER>
On a tree, any induced subgraph is a forest, and the number of vertices minus the number of edges equals the number of connected components; thus, requiring this difference to be 1 is exactly equivalent to requiring the active stations to form a single connected component, preserving all valid assignments and their costs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains finding the minimum weight connected subgraph containing a specified set of vertices on a tree (the Steiner tree on a tree), which is solvable in polynomial time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "active stations - active channels = 1" as allowing disconnected components if they fail to realize the underlying graph is a tree and thus cannot contain cycles, but the statement itself is mathematically unambiguous.
</RISK>
