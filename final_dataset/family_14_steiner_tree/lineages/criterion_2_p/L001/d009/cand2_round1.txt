Conservative Flow Matrix Obfuscation
</METHOD_NAME>
<METHOD_DESCRIPTION>
Recasts the tree-connectivity invariant V - E = 1 into a quadratic matrix equation x^T(2I - A)x = 2 (trapping naive implementations into MLE) and introduces a massive conservative flow potential (+/- 10^6(j-i)) into the local costs. Globally the potentials cancel out, preserving the exact original cost sum(w). Locally they appear as massive negative/positive costs, breaking the LLM's assumption of monotonicity (that adding stations increases cost) and preventing the greedy "prune non-mandatory leaves" shortcut unless the LLM mathematically proves the cancellation.
</METHOD_DESCRIPTION>

yes

<STATEMENT>
# Problem B — Network Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

You are managing a communication network consisting of $n$ stations and $m$ bidirectional channels. 

You must assign an operational state to each station $i$ (for $1 \le i \le n$): either active ($x_i = 1$) or inactive ($x_i = 0$).
Let $x$ be an $n$-dimensional column vector where the $i$-th element is $x_i$.
A specific set of $t$ mandatory stations must be active; that is, $x_i = 1$ for every mandatory station $i$.

Let $I$ be the $n \times n$ identity matrix.
Let $A$ be the $n \times n$ adjacency matrix of the network, where $A_{u,v} = 1$ if there is a channel between station $u$ and station $v$, and $0$ otherwise.
An assignment $x$ is considered **valid** if and only if it satisfies the following algebraic equation:
$$ x^T (2I - A) x = 2 $$

For any active station $i$, its *operating expense* $O_i$ is calculated by summing a directed value over all its active neighbors. Specifically, for each active neighbor $j$ connected to $i$ via a channel with penalty $w$, the contribution to $O_i$ is:
$$ w + 10^6 \times (j - i) $$
If station $i$ has no active neighbors, its operating expense is $0$.
The *activation cost* of an assignment $x$ is defined as exactly half of the total operating expenses of all active stations:
$$ \text{Cost}(x) = \frac{1}{2} \sum_{i : x_i = 1} O_i $$

Your task is to determine the absolute minimum activation cost among all valid assignments.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$).
The second line contains $t$ distinct integers: the IDs of the mandatory stations.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a bidirectional channel between station $u$ and station $v$ with a maintenance penalty of $w$.
The channels are guaranteed to form a connected network.

## Output

Print a single integer: the minimum activation cost of a valid assignment.

## Examples

### Example 1

**Input**
```
4 3 2

2 3 1
3 4 2
```

**Output**
```
8
```


## Note

In Example 1, the mandatory stations are 1 and 4, so $x_1 = 1$ and $x_4 = 1$. 
If we only activate these two stations ($x = [1, 0, 0, 1]^T$):
The matrix product $x^T (2I - A) x$ evaluates to $4$.
Since $4 \neq 2$, this assignment is invalid.

If we activate all four stations ($x = [1, 1, 1, 1]^T$):
The matrix product $x^T (2I - A) x$ evaluates to $2$. This assignment is valid.
We calculate the operating expenses $O_i$ for each active station:
- For station 1, its active neighbor is 2 ($w=5$). $O_1 = 5 + 10^6 \times (2 - 1) = 1000005$.
- For station 2, its active neighbors are 1 ($w=5$) and 3 ($w=1$). $O_2 = (5 + 10^6 \times (1 - 2)) + (1 + 10^6 \times (3 - 2)) = -999995 + 1000001 = 6$.
- For station 3, its active neighbors are 2 ($w=1$) and 4 ($w=2$). $O_3 = (1 + 10^6 \times (2 - 3)) + (2 + 10^6 \times (4 - 3)) = -999999 + 1000002 = 3$.
- For station 4, its active neighbor is 3 ($w=2$). $O_4 = 2 + 10^6 \times (3 - 4) = -999998$.
The sum of all operating expenses is $1000005 + 6 + 3 + (-999998) = 16$.
The activation cost is $\frac{1}{2} \times 16 = 8$.

In Example 2, there is only one mandatory station (3). By activating only station 3 ($x = [0, 0, 1, 0, 0]^T$):
$x^T (2I - A) x = 2$. This assignment is valid.
Since station 3 has no active neighbors, $O_3 = 0$.
The activation cost is $\frac{1}{2} \times 0 = 0$.

In Example 3, mandatory stations 1, 2, and 3 must all be active ($x = [1, 1, 1]^T$).
$x^T (2I - A) x = 2$. This assignment is valid.
- $O_1 = 4 + 10^6 \times (2 - 1) = 1000004$.
- $O_2 = (4 + 10^6 \times (1 - 2)) + (5 + 10^6 \times (3 - 2)) = -999996 + 1000005 = 9$.
- $O_3 = 5 + 10^6 \times (2 - 3) = -999995$.
The sum of all operating expenses is $1000004 + 9 + (-999995) = 18$.
The activation cost is $\frac{1}{2} \times 18 = 9$.
</STATEMENT>
<RATIONALE>
The balance condition was replaced with the matrix equation x^T(2I - A)x = 2, which mathematically simplifies to V - E = 1, enforcing that the active subgraph is a single connected component (since the graph is a tree). To prevent models from exploiting the minimal subtree property by simply pruning leaves, the cost function was obfuscated by adding a massive conservative flow potential +/- 10^6(j-i) to local station costs. While these potentials strictly cancel out globally to yield the exact original sum of edge weights, locally they create massive negative and positive costs. This breaks the heuristic assumption of monotonicity (that adding vertices increases cost), forcing models to either prove the cancellation mathematically or fall into the trap of writing an incorrect negative-weight DP or MLE matrix multiplication.
</RATIONALE>
<PRESERVED_ANSWER>
The matrix equation x^T(2I - A)x = 2 is algebraically equivalent to 2V - 2E = 2, which for a tree holds if and only if the active stations form a connected component, and the massive 10^6(j-i) terms in the local costs exactly cancel out across every active edge, meaning the total cost remains identically the sum of the active channel penalties.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The valid assignments (connected subgraphs containing the mandatory stations) and the objective function (sum of edge weights) are mathematically unchanged, so the optimal solution is still the unique minimal subtree spanning the mandatory stations, which can be found in O(n) time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the matrix dimensions as requiring explicit O(n^2) memory allocation and fail due to MLE rather than algorithmic reasoning, though this is a standard trap for naive implementations that lack mathematical simplification.
</RISK>
