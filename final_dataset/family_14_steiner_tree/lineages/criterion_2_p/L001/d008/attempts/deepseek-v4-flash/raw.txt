We can model the network as a tree (since \( m = n-1 \) and it’s incrementally built).  
The balance condition can be rewritten:

\[
B(x) = \sum_{i: x_i=1} (2 - k_i) = 2
\]

Let \( S \) be the set of active stations, and let \( e(S) \) be the number of edges with both endpoints in \( S \).  
Then:

\[
\sum_{i \in S} k_i = 2 e(S)
\]

So:

\[
B(x) = 2|S| - 2e(S) = 2
\]

Thus:

\[
|S| - e(S) = 1
\]

This means the active subgraph must be a tree (connected and acyclic) containing all mandatory stations.

So the problem reduces to:  
Find the minimum-cost connected subgraph (tree) that contains all mandatory stations.

This is the **Steiner tree** problem on a tree, which can be solved by pruning unnecessary leaves.

---

**Approach:**

1. Build the tree.
2. Mark mandatory nodes.
3. Remove all leaves that are not mandatory repeatedly (since they can’t be part of the minimal tree).
4. The remaining tree is the minimal subtree connecting all mandatory nodes.
5. Sum the weights of edges in this remaining tree.

---

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m, t = map(int, input().split())
mandatory = set(map(int, input().split()))

adj = [[] for _ in range(n + 1)]
for _ in range(m):
    u, v, w = map(int, input().split())
    adj[u].append((v, w))
    adj[v].append((u, w))

degree = [0] * (n + 1)
for i in range(1, n + 1):
    degree[i] = len(adj[i])

# Remove non-mandatory leaves
q = deque()
for i in range(1, n + 1):
    if degree[i] == 1 and i not in mandatory:
        q.append(i)

removed = [False] * (n + 1)
while q:
    u = q.popleft()
    removed[u] = True
    for v, w in adj[u]:
        if not removed[v]:
            degree[v] -= 1
            if degree[v] == 1 and v not in mandatory:
                q.append(v)

# Sum weights of edges between remaining nodes
total_cost = 0
for u in range(1, n + 1):
    if not removed[u]:
        for v, w in adj[u]:
            if v > u and not removed[v]:
                total_cost += w

print(total_cost)
```
