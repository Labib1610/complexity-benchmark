# Problem B — Network Synchronization

Time limit: 2 s
Memory limit: 256 MB

## Description

You are configuring a network of $n$ communication relays. There are $m$ bidirectional channels, each connecting a pair of relays. The channels are arranged such that the entire network could be constructed by starting with a single relay, and iteratively introducing each of the other relays by establishing exactly one channel with an already-introduced relay.

You must assign a state to each relay: either active (1) or inactive (0). A specific set of $t$ mandatory relays must be active.

For each active relay $i$, its *isolation score* is defined as $3 - d_i$, where $d_i$ is the number of other active relays that are directly connected to relay $i$ by a channel. 
A configuration is considered **valid** if and only if the sum of the isolation scores of all active relays is exactly equal to the total number of active relays plus two.

Each channel has a maintenance penalty $w$. The *operational cost* of a configuration is the sum of the maintenance penalties of all channels for which both connected relays are active.

Your task is to determine the absolute minimum operational cost among all valid configurations.

The relays are shipped in modular crates of 1,000 units each. The maximum deployment consists of 200 crates, establishing the upper limit for the total number of relays $n$ at 200,000. The number of channels $m$ is always exactly one less than the number of relays. The number of mandatory relays $t$ ranges from a single relay up to the full set of $n$ relays. The maintenance penalty $w$ of any channel is a positive integer that is capped by a strict hardware limit of 1,000,000.

## Input

The first line contains three integers $n$, $m$, and $t$.
The second line contains $t$ distinct integers: the identifiers of the mandatory relays.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$, representing a channel between relay $u$ and relay $v$ with a maintenance penalty of $w$. 
The relay identifiers $u$ and $v$ are distinct integers between 1 and $n$.

## Output

Print a single integer: the minimum operational cost of a valid configuration.

## Examples

**Input**


**Output**


**Output**
```

```

### Example 3

**Input**


**Output**
```

```

## Note

In Example 1, the mandatory relays are 1 and 4.
If we only activate these two, there are 2 active relays. Relay 1 is connected to relay 2 (which is inactive), so $d_1 = 0$. Relay 4 is connected to relay 3 (which is inactive), so $d_4 = 0$.
The sum of isolation scores is $(3 - 0) + (3 - 0) = 6$. The required target is the number of active relays plus two, which is $2 + 2 = 4$. Since $6 \neq 4$, this configuration is invalid.
If we activate all four relays, there are 4 active relays.
- Relay 1 is connected to active relay 2, so $d_1 = 1$. Score: $3 - 1 = 2$.
- Relay 2 is connected to active relays 1 and 3, so $d_2 = 2$. Score: $3 - 2 = 1$.
- Relay 3 is connected to active relays 2 and 4, so $d_3 = 2$. Score: $3 - 2 = 1$.
- Relay 4 is connected to active relay 3, so $d_4 = 1$. Score: $3 - 1 = 2$.
The sum of scores is $2 + 1 + 1 + 2 = 6$. The required target is $4 + 2 = 6$. Since $6 = 6$, this configuration is valid.
The channels between active relays are (1,2), (2,3), and (3,4). The operational cost is $5 + 1 + 2 = 8$.

In Example 2, the only mandatory relay is 3. By activating only relay 3, we have 1 active relay. Relay 3 is connected to relays 2 and 4 (both inactive), so $d_3 = 0$.
The sum of scores is $3 - 0 = 3$. The required target is $1 + 2 = 3$. This configuration is valid.
Since there are no channels where both endpoints are active, the operational cost is 0.

In Example 3, mandatory relays 1, 2, and 3 must all be active. There are 3 active relays.
- Relay 1: $d_1 = 1$ (score 2).
- Relay 2: $d_2 = 2$ (score 1).
- Relay 3: $d_3 = 1$ (score 2).
The sum of scores is $2 + 1 + 2 = 5$. The target is $3 + 2 = 5$. This is valid.
The operational cost is $4 + 5 = 9$.
