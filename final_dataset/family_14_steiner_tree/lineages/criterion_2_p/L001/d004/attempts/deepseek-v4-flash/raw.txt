We can model the system as a tree (since \( m = n-1 \) and it’s connected).  
The condition:

\[
\sum E_{u,v} = \sum V_i - 1
\]

means the activated edges form a connected subgraph containing all variables with \( V_i = 1 \), and that subgraph must be a tree (since edges = vertices − 1).  

So the problem becomes:  
We must choose a connected subgraph (a tree) that contains all core variables, and minimize the sum of edge weights in that subgraph.

That’s exactly the **Steiner tree** problem on a tree, which has a simple solution:  
The minimal subtree connecting all core nodes is the union of all paths between core nodes.  
Its cost is the sum of all edges that lie on paths between any two core nodes.

We can find this by:
1. Root the tree arbitrarily.
2. Mark nodes that are in the minimal subtree (i.e., nodes that are on a path between two core nodes).
3. Sum the weights of edges that connect two marked nodes.

Implementation approach:
- Do a DFS from any core node to compute parent and depth.
- Mark all core nodes.
- For each node, if it has a core node in its subtree, then the edge from its parent to it is included in the Steiner tree.
- Sum those edge weights.

Let’s write the code.  

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    core = set(map(int, input().split()))
    
    g = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        g[u].append((v, w))
        g[v].append((u, w))
    
    parent = [0]*(n+1)
    weight = [0]*(n+1)
    depth = [0]*(n+1)
    
    # DFS to set parent and depth
    stack = [(next(iter(core)), 0, 0)]  # (node, parent, weight)
    visited = [False]*(n+1)
    visited[stack[0][0]] = True
    while stack:
        u, p, w = stack.pop()
        parent[u] = p
        weight[u] = w
        for v, wgt in g[u]:
            if not visited[v]:
                visited[v] = True
                depth[v] = depth[u] + 1
                stack.append((v, u, wgt))
    
    # Mark nodes that are in the minimal subtree
    has_core = [False]*(n+1)
    # We'll do a post-order traversal
    order = []
    stack = [next(iter(core))]
    visited = [False]*(n+1)
    visited[stack[0]] = True
    while stack:
        u = stack.pop()
        order.append(u)
        for v, _ in g[u]:
            if not visited[v]:
                visited[v] = True
                stack.append(v)
    
    for u in reversed(order):
        if u in core:
            has_core[u] = True
        for v, _ in g[u]:
            if parent[v] == u and has_core[v]:
                has_core[u] = True
    
    ans = 0
    for u in range(1, n+1):
        if has_core[u] and parent[u] != 0 and has_core[parent[u]]:
            ans += weight[u]
    
    print(ans)

if __name__ == "__main__":
    solve()
```
