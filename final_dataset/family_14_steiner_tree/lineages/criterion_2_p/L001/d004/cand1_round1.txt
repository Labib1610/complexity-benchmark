<METHOD_NAME>Algebraic Subgraph Constraint</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit graph-connectivity requirement ("connect all core factions") with an equivalent algebraic constraint on binary vertex variables ($E = V - 1$). On a tree, this equation holds if and only if the chosen vertices form a single connected component. Models relying on surface patterns will fail to recognize the Steiner tree problem and will likely attempt an intractable state-space DP, while models that can reason about graph properties will deduce the connectivity requirement and succeed.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Core Factions

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of **n** variables (numbered 1 to n) and **m** bilateral relations. The relations are structured such that there is exactly one simple sequence of relations linking any two variables.

A specific group of **t** variables are designated as **core**. Your objective is to assign a binary state, $V_i \in \{0, 1\}$, to each variable $i$ from 1 to $n$. 

Your assignment must satisfy the following rules:
1. For every core variable $c$, you must assign $V_c = 1$.
2. For every bilateral relation between variables $u$ and $v$, we define the relation's activation state as $E_{u,v} = V_u \times V_v$.
3. The total number of activated relations must be exactly one less than the total number of variables assigned a value of 1. Mathematically:
   $$ \sum_{\text{all relations } (u,v)} E_{u,v} = \left( \sum_{i=1}^n V_i \right) - 1 $$

Each bilateral relation has a specific maintenance cost $w$. When a relation is activated (i.e., $E_{u,v} = 1$), you must pay this cost. Relations that are not activated cost nothing.

You must determine the absolute minimum total maintenance cost required to yield a valid assignment.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers: the ids of the core variables.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000) representing a bilateral relation between variable u and variable v with a maintenance cost of w.

## Output

Print a single integer: the minimum total maintenance cost required for a valid assignment.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the core variables are 1 and 4, so $V_1 = 1$ and $V_4 = 1$. If we only assign 1 to these two ($\sum V_i = 2$), all $E_{u,v}$ would be 0, which violates $0 = 2 - 1$. To satisfy the equation, we must also set $V_2 = 1$ and $V_3 = 1$. This yields $\sum V_i = 4$. The relations (1,2), (2,3), and (3,4) are activated, giving $\sum E_{u,v} = 3$. Since $3 = 4 - 1$, the assignment is valid. The total cost is 5 + 1 + 2 = 8.

In Example 2, there is only one core variable ($V_3 = 1$). By setting all other variables to 0, we have $\sum V_i = 1$ and $\sum E_{u,v} = 0$. The equation $0 = 1 - 1$ is satisfied. The minimum total cost is 0.

In Example 3, core variables 1, 2, and 3 must all be assigned 1. Thus $\sum V_i = 3$. The relations (1,2) and (2,3) are activated, yielding $\sum E_{u,v} = 2$. The equation $2 = 3 - 1$ is satisfied. The total cost is 4 + 5 = 9.
</STATEMENT>
<RATIONALE>
The explicit requirement to "connect" the core factions has been replaced with an algebraic constraint on the vertices and edges of the induced subgraph. Because the base graph is a tree, the condition that the number of active edges equals the number of active vertices minus one is mathematically identical to requiring that the active vertices form a single connected component. Models that only match the text against known problem templates will fail to recognize the Steiner tree structure and will likely attempt an intractable state-space DP, while models that reason about the properties of trees will deduce the connectivity requirement and succeed.
</RATIONALE>
<PRESERVED_ANSWER>
On a tree, any subset of vertices induces a forest; the algebraic condition $E = V - 1$ holds if and only if this forest is a single connected tree containing all core variables, which exactly maps to the original Steiner tree cost.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains solvable in $O(N)$ time by finding the minimal subtree spanning the required nodes, preserving the polynomial complexity class.
</PRESERVED_CLASS>
