We can model the network as a tree.  
The condition \( I(x) = 1 \) can be rewritten as:

\[
\sum_{i=1}^n x_i - \sum_{(u,v) \in E} x_u x_v = 1
\]

For a tree, this has a known interpretation:  
If we consider the active nodes as forming connected components, then:

\[
I(x) = \text{number of active nodes} - \text{number of active edges}
\]

In a forest, this equals the number of connected components consisting of active nodes.  
So \( I(x) = 1 \) means the active nodes must form exactly one connected component.

Thus, the problem reduces to:  
Choose a connected subtree that contains all critical nodes, minimizing the sum of edge weights inside it.

This is the **Steiner tree** problem on a tree, which can be solved by:

1. Compress the tree to only the critical nodes and their pairwise paths.
2. The minimal connected subgraph containing all critical nodes is the union of paths between them.
3. The cost is the sum of edge weights in that union.

We can compute this efficiently:

- Root the tree at any critical node.
- Mark all nodes that are in the minimal subtree connecting all critical nodes.
- Sum the weights of edges in that subtree.

Implementation steps:

1. Read input.
2. Build adjacency list.
3. Mark critical nodes.
4. Do a DFS from any critical node to compute which edges are needed:
   - A node is “needed” if it is critical or has a needed child.
5. Sum weights of edges where both endpoints are needed.

Let’s write the code.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    critical = set(map(int, input().split()))
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    # Root at any critical node
    root = next(iter(critical))
    
    parent = [0]*(n+1)
    parent_edge_weight = [0]*(n+1)
    order = []
    stack = [root]
    parent[root] = -1
    while stack:
        u = stack.pop()
        order.append(u)
        for v, w in adj[u]:
            if v == parent[u]:
                continue
            parent[v] = u
            parent_edge_weight[v] = w
            stack.append(v)
    
    needed = [False]*(n+1)
    for c in critical:
        needed[c] = True
    
    # Process in reverse order (post-order)
    for u in reversed(order):
        if u == root:
            continue
        if needed[u]:
            needed[parent[u]] = True
    
    total_cost = 0
    for u in range(1, n+1):
        if u == root:
            continue
        if needed[u] and needed[parent[u]]:
            total_cost += parent_edge_weight[u]
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
