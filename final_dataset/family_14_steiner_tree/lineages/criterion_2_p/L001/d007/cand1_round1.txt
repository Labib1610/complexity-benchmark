# Problem B — Core Factions

Time limit: 2 s   Memory limit: 256 MB

## Description

You are configuring a network of $n$ modules (indexed 1 to $n$) and $m$ bidirectional channels. The channels are structured such that between any two modules, there is exactly one non-repeating sequence of channels linking them.

You must choose a subset of modules to *activate*. A specific set of $t$ primary modules is mandatory and must be included in your activated subset.

A channel is considered *energized* if and only if both of its endpoint modules are activated. Each channel has a specific positive maintenance penalty $w$. For every energized channel, its maintenance penalty is added to the total cost of the configuration. Channels that are not energized incur no cost.

To ensure the activated modules form a cohesive system, they must pass a diagnostic test:
1. An activated module is considered *exposed* if it is an endpoint of exactly one energized channel.
2. If there are no exposed modules, the diagnostic test concludes.
3. Otherwise, select any exposed module and *suspend* it. Suspending a module means it is no longer considered activated for the remainder of the test (which causes any channel connected to it to no longer be energized).
4. Repeat steps 1-3 until the test concludes.

Your chosen subset of activated modules is considered valid if and only if, regardless of the order in which exposed modules are suspended, the diagnostic test concludes with exactly one activated module remaining. (Note: this test is purely a hypothetical condition for determining validity; the total cost is evaluated based on your initially chosen subset of activated modules).

You must determine the absolute minimum total cost required to yield a valid subset of activated modules.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$).
The second line contains $t$ distinct integers: the indices of the primary modules.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a channel connecting module $u$ and module $v$ with a maintenance penalty of $w$.
These $m$ channels are guaranteed to form the structure described above (exactly one non-repeating sequence of channels linking any two modules).

## Output

Print a single integer: the minimum total cost required for a valid configuration.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

```
1 2 4
2 3 6

```

**Output**
```
0
```

### Example 3

**Input**


**Output**


## Note

In Example 1, the primary modules are 1 and 4. If we only activate these two, there are no energized channels. Neither module is exposed (both are endpoints of 0 energized channels). The test concludes immediately with 2 modules remaining, which is invalid. 
If we activate modules 1, 2, 3, and 4, the energized channels are (1,2), (2,3), and (3,4). Modules 1 and 4 are exposed. If we suspend module 1, the remaining activated modules are 2, 3, 4, and the energized channels are (2,3) and (3,4). Now modules 2 and 4 are exposed. Suspending 4 leaves modules 2 and 3 with channel (2,3). Both are exposed. Suspending 2 leaves only module 3, which has 0 energized channels and is not exposed. The test concludes with exactly 1 module remaining, meaning this configuration is valid. The cost is 5 + 1 + 2 = 8.

In Example 2, there is only one primary module (3). By activating only module 3, there are no energized channels. Module 3 is not exposed, so the test concludes with exactly 1 module remaining. The configuration is valid and costs 0.

In Example 3, primary modules 1, 2, and 3 must all be activated. The energized channels are (1,2) and (2,3). Modules 1 and 3 are exposed. Suspending 1 leaves 2 and 3 with channel (2,3). Suspending 3 leaves only module 2. The test concludes with 1 module remaining. The total cost is 4 + 5 = 9.

<RATIONALE>
The surviving model relied on recognizing the algebraic identity `sum(2 - c(u)) = 2|V| - 2|E| = 2`, which trivially simplifies to Euler's formula for a single tree component (`|V| - |E| = 1`). To remove this shortcut, the validity condition has been rewritten as an operational filtration test (repeatedly removing degree-1 nodes). The model must now topologically reason about this process to deduce that it inherently leaves exactly one node per connected component in a forest, forcing it to genuinely understand the connectivity requirement rather than parsing an equation.
</RATIONALE>
<PRESERVED_ANSWER>
Because any induced subgraph of a tree is a forest, repeatedly removing nodes of degree 1 will always reduce each connected component to exactly one node; therefore, the test leaves exactly one node if and only if the chosen subset is a single connected component, preserving the exact same valid configurations and costs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the minimum-cost connected subgraph containing all mandatory vertices in a tree (Steiner tree on a tree), which is solvable in O(N) by rooting the tree and taking the union of paths between mandatory vertices.
</PRESERVED_CLASS>
