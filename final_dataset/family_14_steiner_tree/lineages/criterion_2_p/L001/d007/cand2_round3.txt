<METHOD_NAME>Sequential Path Validation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the algebraic stability sum condition with a sequential path-connectivity condition. A subset is valid if its elements can be arranged in a sequence where the path between consecutive elements is fully energized. This masks the simple "connected subgraph" property behind a seemingly complex sequence requirement, forcing structural deduction.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem B — Core Factions

Time limit: 2 s   Memory limit: 256 MB

## Description

You are configuring a system of $n$ modules (indexed 1 to $n$) and $m$ bidirectional channels. The channels are structured such that between any two modules, there is exactly one non-repeating sequence of channels linking them.

You must choose a subset of modules to activate. A specific set of $t$ primary modules is mandatory and must be included in your activated subset.

Each channel has a specific positive maintenance penalty $w$. A channel is considered *energized* if and only if both of its endpoint modules are activated. For every energized channel, its maintenance penalty is added to the total cost of the configuration. Channels that are not energized incur no cost.

Your chosen subset of activated modules is considered valid if and only if the activated modules can be arranged into a sequence $v_1, v_2, \dots, v_k$ (where $k$ is the total number of activated modules, and each activated module appears exactly once in the sequence) such that for every index $i$ from 1 to $k-1$, the unique sequence of channels linking $v_i$ to $v_{i+1}$ consists entirely of energized channels.

You must determine the absolute minimum total cost required to yield a valid configuration of activated modules.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$).
The second line contains $t$ distinct integers: the indices of the primary modules.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a channel connecting module $u$ and module $v$ with a maintenance penalty of $w$.
These $m$ channels are guaranteed to form the structure described above.

## Output

Print a single integer: the minimum total cost required for a valid configuration.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the primary modules are 1 and 4, so they must be activated. If we only activate these two, the channels linking them are not energized (since modules 2 and 3 are not activated), making the configuration invalid. By activating modules 1, 2, 3, and 4, the condition can be satisfied. The energized channels are (1,2), (2,3), and (3,4), giving a total cost of 5 + 1 + 2 = 8.

In Example 2, there is only one primary module (3). By activating only module 3, there is only one activated module. Since $k=1$, there is no index $i$ from 1 to $k-1$, so the condition is satisfied. No channels are energized, yielding a total cost of 0.

In Example 3, primary modules 1, 2, and 3 must all be activated. The condition is satisfied with these three modules activated. The energized channels are (1,2) and (2,3), yielding a total cost of 4 + 5 = 9.
</STATEMENT>
<RATIONALE>
The problem was modified by replacing the algebraic local stability sum invariant with a sequential path-connectivity constraint. Instead of calculating $2 - c(u)$ to check for a tree topology, the model must deduce that a set of vertices can be sequenced with fully energized paths between consecutive elements if and only if they form a single connected component. This removes the surface-level affordance that allowed models to pattern-match the algebraic sum to Euler's formula for trees.
</RATIONALE>
<PRESERVED_ANSWER>
The sequence condition is mathematically equivalent to requiring the activated modules to form a connected subgraph, which matches the original stability sum condition, meaning the exact same subsets are valid and their costs remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains finding the minimum-weight connected subgraph (Steiner tree) spanning a set of mandatory vertices on a tree, which is solvable in linear time using a bottom-up traversal.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the sequence condition as requiring a specific path traversal (like a Hamiltonian path) rather than realizing that any sequence works as long as the subset is connected, potentially leading to confusion about the problem's feasibility.
</RISK>
