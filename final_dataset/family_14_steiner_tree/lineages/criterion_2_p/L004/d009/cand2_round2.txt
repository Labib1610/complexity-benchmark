<STATEMENT>
# Subsystem State Entanglement

Time limit: 2 s
Memory limit: 256 MB

## Description

You are configuring a composite system of $n$ quantum subsystems, indexed $1$ through $n$.

You have a catalog of $m$ optional symmetric pairwise entanglement operations. Each operation couples two specific subsystems $u$ and $v$ (without affecting any other subsystems) and requires an energy cost $w$.

The catalog of available operations provides complete state integration: there are exactly $m = n - 1$ operations available, and if all were applied, the entire collection of subsystems would form a single fully entangled composite state (meaning any subsystem can influence any other via a sequence of operations).

Your objective is to apply a subset of these operations to establish a targeted correlation. You must ensure that a specific list of $t$ critical subsystems are all mutually entangled with each other using only the applied operations. (That is, for any two critical subsystems $a$ and $b$, influence must be able to propagate between them via a sequence of applied operations). The entanglement status of the remaining non-critical subsystems does not matter.

What is the minimum total energy cost of the operations you must apply to satisfy this condition?

## Input

The first line contains three integers **n**, **m**, and **t**. The number of subsystems is **n** (1 ≤ **n** ≤ 200000). The number of available operations **m** is always exactly **n** − 1. The number of critical subsystems is **t** (1 ≤ **t** ≤ **n**).
The second line contains **t** distinct integers: the identifiers of the critical subsystems.
Each of the next **m** lines contains three integers **u**, **v**, and **w**. These denote an optional operation coupling subsystems **u** and **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), which costs **w** to apply (1 ≤ **w** ≤ 1000000).

## Output

Print a single integer: the minimum total energy cost required.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

<RATIONALE>
The explicit mention of a "unique communication route" was removed, as it directly signaled a tree structure. Instead, the problem relies on the combination of complete integration and $m = n - 1$ to imply the tree. The framing was shifted to quantum entanglement to obscure graph-theoretic patterns.
</RATIONALE>
<PRESERVED_ANSWER>
The structural requirement remains finding the minimum-weight subgraph that connects the critical nodes, which on a connected graph with $n-1$ edges is uniquely the minimal spanning subtree.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding a Steiner tree on a tree graph, which is solvable in polynomial (linear) time using a simple traversal.
</PRESERVED_CLASS>
<RISK>
The phrase "mutually entangled" could be misinterpreted as requiring a clique, though the parenthetical "(That is, for any two... via a sequence of applied operations)" explicitly clarifies it means transitive connectivity.
</RISK>
