<STATEMENT>
# Sparse Matrix Synthesis

Time limit: 2 s
Memory limit: 256 MB

## Description

You are configuring a symmetric integer matrix $A$ of size $n \times n$. Initially, $A$ is the identity matrix ($A_{i,i} = 1$ for all $1 \le i \le n$, and $0$ elsewhere).

You are provided with a catalog of $m$ optional symmetric rank-2 updates. Each update allows you to add $1$ to both $A_{u,v}$ and $A_{v,u}$ for a specific pair of distinct indices $(u, v)$, and incurs a cost of $w$. 

The catalog provides a complete minimal set: there are exactly $m = n - 1$ updates available. It is guaranteed that if all of them were applied, the resulting matrix $A$ would have the property that every entry of its $n$-th power is strictly positive. That is, $(A^n)_{i,j} > 0$ for all $1 \le i, j \le n$ (where $A^n$ denotes the $n$-th power of $A$ under standard matrix multiplication).

Your objective is to select a subset of these available updates to apply, such that for a specific set of $t$ target indices, the resulting matrix $A$ satisfies $(A^n)_{a,b} > 0$ for any two target indices $a$ and $b$. The values in the matrix for non-target indices do not matter, as long as this condition holds for all pairs of target indices. 

What is the minimum total cost of the updates you must select?

## Input

The first line contains three integers **n**, **m**, and **t**. The matrix size is **n** (1 ≤ **n** ≤ 200000). The number of available updates **m** is always exactly **n** − 1. The number of target indices is **t** (1 ≤ **t** ≤ **n**).
The second line contains **t** distinct integers: the target indices.
Each of the next **m** lines contains three integers **u**, **v**, and **w**. These denote an optional update modifying $A_{u,v}$ and $A_{v,u}$ (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), which costs **w** to apply (1 ≤ **w** ≤ 1000000).

## Output

Print a single integer: the minimum total cost required.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

<METHOD_NAME>Matrix Exponentiation Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Translates graph connectivity into the strict positivity of the n-th power of a symmetric matrix with a non-zero diagonal. This shifts the vocabulary from graph theory to linear algebra, masking the tree structure and the Steiner tree objective behind matrix exponentiation conditions.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<RATIONALE>
The problem was reframed from network connectivity to matrix exponentiation. By defining the state as a symmetric matrix $A$ with $1$s on the diagonal, the condition $(A^n)_{a,b} > 0$ mathematically encodes that $a$ and $b$ are in the same connected component. This forces models to bridge the gap between linear algebra and graph theory to recognize the underlying tree structure.
</RATIONALE>
<PRESERVED_ANSWER>
Because $A$ has $1$s on the diagonal, $(A^n)_{a,b} > 0$ if and only if there is a path of length at most $n$ between $a$ and $b$ in the graph of applied updates, which is perfectly equivalent to $a$ and $b$ being in the same connected component.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains finding the minimum cost to connect a subset of vertices in a tree (Steiner tree on a tree), which is solvable in $O(n)$ time by pruning leaves.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "any two target indices $a$ and $b$" as requiring $a \ne b$, but since $(A^n)_{a,a} > 0$ is always true, this distinction does not change the required updates or the answer.
</RISK>
