<STATEMENT>
# Quantum Entanglement Grid

Time limit: 2 s
Memory limit: 256 MB

## Description

You are calibrating a quantum processor consisting of a register of $n$ qubits, indexed $1$ through $n$.

You are provided with a catalog of $m$ optional pairwise entanglement operators. Each operator links two specific qubits $u$ and $v$ (without affecting any other qubits directly) and requires a tuning cost $w$ to apply.

The catalog of $m$ operators is comprehensive enough that, if every single operator were applied, the entire register would form a fully entangled state where any qubit can interact with any other qubit. The total number of available operators $m$ is strictly equal to the number of qubits minus one.

Your objective is to apply a subset of these operators to establish a synchronized subsystem. You must ensure that a specific list of $t$ target qubits are all mutually interactive using only the applied operators. (That is, for any two target qubits $a$ and $b$, interaction must be possible via a chain of applied operators). The interaction capabilities of the remaining non-target qubits do not matter.

What is the minimum total tuning cost of the operators you must apply to satisfy this condition?

## Input

The first line contains three integers **n**, **m**, and **t**. 
The size of the qubit register **n** is at least one, and is bounded by the processor's maximum capacity of two hundred thousand qubits. 
The number of available operators **m** is exactly **n** − 1. 
The number of target qubits **t** is at least one, and cannot exceed the register size **n**.
The second line contains **t** distinct integers: the identifiers of the target qubits.
Each of the next **m** lines contains three integers **u**, **v**, and **w**. These denote an optional operator linking qubits **u** and **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), which requires a tuning cost **w**. The tuning cost is a positive integer capped at one million.

## Output

Print a single integer: the minimum total tuning cost required.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

<RATIONALE>
Removed the explicit mention of "exactly one valid communication route" and "minimal connectivity". Replaced it with the mathematically equivalent but less explicit guarantee that $m=n-1$ edges provide full connectivity. This forces the model to deduce the tree structure and the uniqueness of paths rather than pattern-matching on explicit textual hints. The numeric bounds were also rewritten to be derived from the physical scenario (S07).
</RATIONALE>
<PRESERVED_ANSWER>
The graph remains a tree and the required subset of edges is still the minimal subtree spanning the target nodes, so the minimum cost is identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains finding the Steiner tree on a graph that is guaranteed to be a tree, which is solvable in linear time ($O(n)$) using a single traversal.
</PRESERVED_CLASS>
<RISK>
The phrase "interaction must be possible via a chain of applied operators" could potentially be misinterpreted if a reader fails to understand it implies standard transitive connectivity, though "chain" is standard terminology for a path.
</RISK>
