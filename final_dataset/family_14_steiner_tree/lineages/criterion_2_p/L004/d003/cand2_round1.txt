# Synchronization Energy

Time limit: 2 s
Memory limit: 256 MB

## Description

In a large-scale manufacturing facility, a material transport system connects $n$ workstations using $m$ two-way conveyor belts. The system is designed so that material can be routed between any two workstations. The facility's layout was mathematically optimized to use the absolute minimum number of conveyor belts such that every single workstation can be reached from any other.

A quality control system has identified exactly $t$ specific workstations that require synchronization via the conveyor control lines. To synchronize them, you must power on a subset of the conveyor belts to form a single continuous communication link containing all $t$ identified workstations. The powered network must allow data to be routed between any two identified workstations. Unidentified workstations may be part of this powered network if they are needed to bridge the links.

Powering on a conveyor belt consumes a specific amount of electrical power. Your task is to select a subset of belts that connects all $t$ identified workstations while minimizing the total electrical power consumed.

## Input

The first line contains three integers $n$, $m$, and $t$. The facility's floor plan consists of exactly 400 zones, each with a strict maximum of 500 workstations, meaning the total number of workstations $n$ can be anywhere from 1 up to the maximum possible capacity of all zones combined. The number of belts $m$ is strictly determined by the full reachability optimization mentioned above. The number of identified workstations $t$ is at least 1 and at most the total number of workstations $n$.
The second line contains $t$ distinct integers: the identifiers of the identified workstations.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$. These denote a two-way conveyor belt between distinct workstations $u$ and $v$. Workstation identifiers are positive integers starting from 1 up to $n$. The electrical power $w$ required to power this belt is at least 1 and capped at exactly the square of one thousand.

## Output

Print a single integer: the minimum total electrical power required to form a continuous network connecting all identified workstations.

## Examples


**Output**

```

```

I removed explicit mentions of "no closed circuits" and the formula "m = n - 1", replacing them with the indirect condition that the network uses the "absolute minimum number of conveyor belts" to ensure full reachability. I also restated the variable bounds using physical capacities (e.g., 400 zones of 500 workstations) to force the model to derive the actual limits. This requires the model to independently deduce that the graph is a tree.
</RATIONALE>

</PRESERVED_ANSWER>

</PRESERVED_CLASS>
