# Sparse Matrix Exponentiation Control

Time limit: 2 s
Memory limit: 256 MB

## Description

You are configuring the sparsity pattern of an $n \times n$ symmetric matrix $A$. Initially, every entry of $A$ is $0$.

You have a list of $m$ allowed structural modifications. Each modification specifies two distinct indices $u$ and $v$. If you activate this modification, you set $A_{u, v} = 1$ and $A_{v, u} = 1$. Activating this modification consumes $w$ units of power.

The list of $m$ available modifications has a special property: if you were to activate all of them, the resulting matrix $A$ would be such that $(I + A)^{n-1}$ has strictly positive entries everywhere (where $I$ is the $n \times n$ identity matrix). 

You are given a target set of $t$ specific indices. Your objective is to activate a subset of the structural modifications such that, for the resulting matrix $A$, if we define $M = I + A$, the entry $M^{n-1}_{i, j}$ is strictly greater than zero for every pair of indices $i$ and $j$ that both belong to the target set. (The matrix operations use standard arithmetic). 

To conserve energy, you must find the minimum total power required to activate a valid subset of modifications.

## Input

The first line contains three integers **n**, **m**, and **t**. 
- **n** is the matrix dimension. Its minimum is 1, and its maximum is the number of endpoints in a $400 \times 500$ grid.
- **m** is the number of allowed modifications. It is always exactly one less than **n**.
- **t** is the number of target indices. It ranges from 1 up to **n**.

The second line contains **t** distinct integers: the specific target indices.

Each of the next **m** lines contains three integers **u**, **v**, and **w**. 
- **u** and **v** specify the indices for an allowed modification. They are valid distinct row/column numbers from 1 to **n**.
- **w** is the power consumed to activate it. It is at least 1, and at most the output of a one-megawatt generator expressed in watts (1,000,000).

## Output

Print a single integer: the minimum total power required.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3

```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

<RATIONALE>
I completely removed the graph-theoretic framing (networks, corridors, routing) and replaced it with an equivalent algebraic condition on the adjacency matrix. The requirement that $(I+A)^{n-1}_{i,j} > 0$ is mathematically identical to requiring that nodes $i$ and $j$ are in the same connected component. This forces the model to independently deduce the equivalence between matrix exponentiation and graph connectivity, and subsequently recognize that $m=n-1$ implies a tree structure, without relying on graph-theoretic keywords. Numeric bounds were updated to follow the S07 strategy, using physical grid dimensions and power outputs.
</RATIONALE>
<PRESERVED_ANSWER>
The entry $(I+A)^{n-1}_{i,j}$ is strictly positive if and only if there is a path between $i$ and $j$ in the graph represented by $A$, meaning the exact same subsets of edges (modifications) are valid, and thus the minimum cost subset remains identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains a tree with $n$ vertices and $n-1$ edges, so the minimal valid subset is still uniquely determined by the paths connecting the target indices, keeping the problem solvable in $O(n)$ time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the matrix multiplication as requiring boolean arithmetic instead of standard arithmetic, though the statement explicitly clarifies that standard arithmetic is used.
</RISK>
