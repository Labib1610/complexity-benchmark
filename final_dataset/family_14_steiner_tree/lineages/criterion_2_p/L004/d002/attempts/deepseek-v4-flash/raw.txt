 We are given a tree (since m = n - 1 and it's connected), and we need to connect all flagged nodes with minimal total edge weight.  
This is the **Steiner tree** problem on a tree, which can be solved by:

1. Removing all unnecessary leaves (pruning) until only flagged nodes and necessary paths remain.
2. Summing the weights of the remaining edges.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m, t = map(int, input().split())
flagged = set(map(int, input().split()))

adj = [[] for _ in range(n + 1)]
for _ in range(m):
    u, v, w = map(int, input().split())
    adj[u].append((v, w))
    adj[v].append((u, w))

# If only one flagged node, no edges needed
if t == 1:
    print(0)
    sys.exit()

degree = [len(adj[i]) for i in range(n + 1)]
in_queue = [False] * (n + 1)
q = deque()

# Start with leaves that are not flagged
for i in range(1, n + 1):
    if degree[i] == 1 and i not in flagged:
        q.append(i)
        in_queue[i] = True

removed = [False] * (n + 1)
total_weight = 0

# Prune non-flagged leaves
while q:
    u = q.popleft()
    removed[u] = True
    for v, w in adj[u]:
        if not removed[v]:
            if v not in flagged:
                degree[v] -= 1
                if degree[v] == 1 and not in_queue[v]:
                    q.append(v)
                    in_queue[v] = True
            else:
                # If neighbor is flagged, this edge is part of the Steiner tree
                total_weight += w

# Now sum all edges that connect remaining nodes (the minimal subtree)
# We can do a DFS from any flagged node over non-removed nodes
visited = [False] * (n + 1)
start = next(iter(flagged))
stack = [(start, -1)]
while stack:
    u, parent = stack.pop()
    if visited[u]:
        continue
    visited[u] = True
    for v, w in adj[u]:
        if v != parent and not removed[v] and not visited[v]:
            total_weight += w
            stack.append((v, u))

print(total_weight)
```
