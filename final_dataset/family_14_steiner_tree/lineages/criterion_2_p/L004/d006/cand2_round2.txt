<METHOD_NAME>Logical Transitivity Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces graph-theoretic tree terminology (like "exactly two valid truth assignments") with logical transitivity ("structurally complete and irredundant", "unique sequence of available axioms"). This prevents models from pattern-matching the characteristic phrasing to a spanning tree, forcing them to deduce that the unique sequence property defines a tree and that transitive equivalence of a subset requires a connected subgraph. It also applies S07 to move all numeric bounds into the descriptive text.</METHOD_DESCRIPTION>

<STATEMENT>
# Axiom Selection

Time limit: 2 s
Memory limit: 256 MB

## Description

You are analyzing a formal logical system containing **n** propositions, numbered 1 to **n**. The system requires at least one proposition and its memory architecture can register a maximum of two hundred thousand propositions. Each proposition evaluates to either True or False.

You are given a pool of **m** optional axioms. Each axiom asserts a bidirectional logical equivalence between a specific pair of propositions **u** and **v** (meaning they must both be True or both be False). Adopting an axiom incurs a computational cost of **w**, which is at least one and capped at one million processing cycles. 

The pool of axioms is structurally complete and irredundant: for any two propositions in the system, there is exactly one sequence of available axioms that chain together to transitively establish their equivalence. Because of this unique-sequence property, the number of available axioms **m** is always exactly one less than the number of propositions.

Your objective is to adopt a subset of these optional axioms so that a specific list of **t** critical propositions are unconditionally synchronized. The number of critical propositions **t** ranges from a single proposition up to the entire set of **n** propositions. Synchronization means that, using *only* your adopted subset of axioms, every critical proposition must be proven to share the exact same truth value as every other critical proposition through transitive equivalence. You do not care about the truth values of the remaining non-critical propositions, nor do you require them to be synchronized with the critical ones.

What is the minimum total cost of axioms you must adopt to guarantee this synchronization for the **t** critical propositions?

## Input

The first line contains three integers **n**, **m**, and **t**. The integer **n** represents the number of propositions. The integer **m** is the number of available axioms. The integer **t** is the number of critical propositions.
The second line contains **t** distinct integers: the identifiers of the critical propositions.
Each of the next **m** lines contains three integers **u**, **v**, and **w**. These denote an optional axiom establishing the equivalence of proposition **u** and proposition **v** (**u** ≠ **v**), which costs **w** to adopt. The **m** axioms are guaranteed to satisfy the unique-sequence property described above.

## Output

Print a single integer: the minimum total cost of axioms required to synchronize the critical propositions.

<RATIONALE>
I removed the explicit "exactly two valid truth assignments" phrase that models used to immediately identify the graph as a tree. Instead, I established the tree structure using the logical equivalent of a unique path property ("exactly one sequence of available axioms that chain together"). I also applied strategy S07, moving all numeric bounds into the descriptive text as system limits, forcing models to parse the scenario to understand the constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The problem still requires finding the minimum-cost subset of edges (axioms) that connects (transitively synchronizes) a specific subset of vertices (critical propositions) in a graph guaranteed to be a tree, so the optimal cost is identically the sum of edges in the minimal spanning subtree.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the minimal Steiner tree on a tree, which is solvable in polynomial time $O(n)$ by pruning unneeded branches.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "sequence of available axioms" as implying order matters, though "chain together" and "bidirectional logical equivalence" should clarify it functions as an undirected path.
</RISK>
