<STATEMENT>
# Axiom Selection

Time limit: 2 s
Memory limit: 256 MB

## Description

You are analyzing a formal logical system containing **n** propositions, numbered 1 to **n**. Each proposition can evaluate to either True or False.

You are given a pool of optional axioms. Each axiom establishes a logical equivalence between two propositions **u** and **v** (meaning they must both be True or both be False). Adopting an axiom into your system incurs a computational cost of **w**. 
The pool contains exactly **m** = **n** − 1 available axioms. Note that this collection of pairwise axioms may form an arbitrary structure; it could be disconnected or contain cyclic redundancies.

Your objective is to adopt a subset of these axioms such that a specific list of **t** critical propositions are unconditionally synchronized. That is, in any valid truth assignment that satisfies all axioms in your adopted subset, the **t** critical propositions must all hold the exact same truth value as each other. You do not care about the truth values of the remaining propositions, as long as the adopted axioms are satisfied. It is guaranteed that it is possible to achieve this synchronization for the critical propositions using the available axioms.

What is the minimum total cost of axioms you must adopt to ensure this property for the **t** critical propositions?

## Input

The first line contains three integers **n**, **m**, and **t**. The system's architecture limits the number of propositions **n** to a maximum of 200,000 (and at least 1). The number of available axioms **m** is always exactly **n** − 1. The number of critical propositions **t** ranges from 1 up to all **n** propositions.
The second line contains **t** distinct integers: the identifiers of the critical propositions.
Each of the next **m** lines contains three integers **u**, **v**, and **w**. These denote an optional axiom establishing the equivalence of proposition **u** and proposition **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**). The computational cost **w** to adopt an axiom is a positive integer capped at 1,000,000.

## Output

Print a single integer: the minimum total cost required.

## Examples

### Example 1

**Input**
```

2 3 1
3 4 2
```

**Output**
```
8
```

**Output**
```
0
```

**Input**
```

```

**Output**
```
9
```

<RATIONALE>
Following the suggested removal, I eliminated the guarantee that the axioms form a minimally complete system (a tree) and explicitly stated that the structure may contain cycles or be disconnected. I also applied S07 to express the numeric bounds indirectly as architectural limits. This forces models to view the problem as a general graph synchronization (Steiner tree) problem, abandoning the simple tree-based DFS algorithms.
</RATIONALE>

The actual test cases remain unchanged (they are all trees), so the O(N) tree solution remains correct for all inputs that will actually be evaluated, and the minimum cost subsets are identical.
</PRESERVED_ANSWER>
