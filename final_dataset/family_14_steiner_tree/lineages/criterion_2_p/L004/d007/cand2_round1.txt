<METHOD_NAME>
Null-Space Partitioning
</METHOD_NAME>
<METHOD_DESCRIPTION>
Translates the structural removal of edges in a tree into the algebraic operation of computing the left null space of an incidence matrix with one column removed. The resulting binary indicator vectors mathematically correspond to the connected components. The Steiner tree edge requirement is restated as the indicator vector not being constant on the target indices. This completely obscures the graph structure and the $O(n)$ subtree-counting algorithm, forcing models to either independently discover the graph isomorphism or write $O(n^2)/O(n^4)$ algebraic simulations that will Time Out.
</METHOD_DESCRIPTION>

yes

<STATEMENT>
# Null-Space Splitting

Time limit: 2 s
Memory limit: 256 MB

## Description

You are analyzing the algebraic properties of an $n \times m$ sparse matrix $A$, where $m = n - 1$. The matrix has $n$ rows (indexed 1 to $n$) and $m$ columns (indexed 1 to $m$).

Each column $i$ is defined by two row indices $u$ and $v$ and a scalar weight $w$. In the matrix $A$, column $i$ has a value of $1$ at row $u$, a value of $-1$ at row $v$, and a value of $0$ in all other rows. 

It is a guaranteed property of the provided columns that the matrix $A$ has a rank of exactly $n-1$.

For any specific column $i$, let $A_{-i}$ denote the $n \times (n-2)$ submatrix formed by deleting column $i$ from $A$. Because the rank of $A_{-i}$ is $n-2$, its left null space—the set of all row vectors $y^T \in \mathbb{R}^n$ such that $y^T A_{-i} = \mathbf{0}^T$—is exactly 2-dimensional.

Notice that the all-ones vector $\mathbf{1} = [1, 1, \dots, 1]^T$ is always in the left null space of $A_{-i}$ because the sum of the elements in any column of $A$ is exactly zero. It can be shown that the left null space of $A_{-i}$ is spanned by $\mathbf{1}$ and a binary indicator vector $z^{(i)} \in \{0, 1\}^n$. This binary vector $z^{(i)}$ is uniquely determined up to inversion (i.e., replacing $z^{(i)}$ with $\mathbf{1} - z^{(i)}$).

You are given a list of $t$ target row indices. 
We classify column $i$ as *target-splitting* if the vector $z^{(i)}$ is not constant across the $t$ target indices. In other words, column $i$ is target-splitting if there exist target indices $a$ and $b$ such that $z^{(i)}_a \neq z^{(i)}_b$.

What is the sum of the weights $w$ of all target-splitting columns?

## Input

The first line contains three integers **n**, **m**, and **t**. The number of rows is **n** (1 ≤ **n** ≤ 200000). The number of columns **m** is always exactly **n** − 1. The number of target indices is **t** (1 ≤ **t** ≤ **n**).
The second line contains **t** distinct integers: the identifiers of the target row indices.
Each of the next **m** lines contains three integers **u**, **v**, and **w**. These define a column with $1$ at row **u**, $-1$ at row **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), and an associated weight **w** (1 ≤ **w** ≤ 1000000).

## Output

Print a single integer: the sum of the weights of all target-splitting columns.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

<RATIONALE>
Changed the problem from selecting a minimum-cost subset of mechanisms to directly identifying columns whose removal algebraically splits the target indices in the left null space. This forces models to recognize that the matrix represents a tree and that the target-splitting condition is equivalent to an edge being in the minimal Steiner tree spanning the targets; otherwise, they will attempt a naive $O(n^2)$ or $O(n^4)$ algebraic simulation and Time Out.
</RATIONALE>
<PRESERVED_ANSWER>
The target-splitting columns exactly correspond to the edges in the unique minimal Steiner tree spanning the target indices, meaning the sum of their weights is mathematically identical to the minimum coupling cost.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The optimal solution remains an $O(n)$ tree traversal that counts target indices in subtrees, keeping the problem in P.
</PRESERVED_CLASS>
