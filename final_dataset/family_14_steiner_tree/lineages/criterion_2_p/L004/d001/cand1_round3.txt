# Synchronization Energy

Time limit: 2 s
Memory limit: 256 MB

## Description

In an industrial plant, **n** processing units (numbered 1 to n) are connected by **m** bidirectional transfer pipes. The piping layout is strictly designed such that **m = n − 1**, and there is exactly one valid sequence of pipes connecting any given pair of units.

A sensor array has flagged exactly **t** units that must be synchronized. To achieve this, you must open a subset of the transfer pipes to form a single continuous fluid network that connects all **t** flagged units together. This continuous network is permitted to route through unflagged units if necessary.

Opening a pipe requires a certain amount of mechanical energy, and the total energy is the sum of the energy requirements for all opened pipes. You must select a subset of pipes that successfully links all **t** flagged units such that the total energy expended is minimized.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers: the identifiers of the flagged units.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): a bidirectional transfer pipe connecting unit u to unit v requiring w units of energy to open. 

## Output

Print a single integer: the minimum total energy required to connect all flagged units.

## Examples

### Example 1

**Input**
```
4 3 2

```

**Output**
```
8
```

```

```
