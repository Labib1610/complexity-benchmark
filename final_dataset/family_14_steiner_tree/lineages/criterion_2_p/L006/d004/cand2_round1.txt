# Problem B — Priority Reconciliation

Time limit: 2 s
Memory limit: 256 MB

## Description

A biochemical laboratory is analyzing a collection of protein variants. The laboratory's storage capacity limits the total number of variants to 200,000. Each variant is labeled with a distinct integer from 1 up to the total number of variants.

The researchers have compiled a catalog of potential reactions. Each reaction bridges two specific variants. Simulating a reaction once unlocks the transformation between those two variants in both directions, and requires a certain amount of computational credits to perform (up to 1,000,000 credits per reaction).

The team's current grant focuses on a designated priority subset of these variants. They must select a subset of reactions to simulate such that all priority variants are mutually reconciled. Mutual reconciliation is achieved if, for any two priority variants, there exists a continuous chain of simulated reactions that can transform one into the other. Reactions involving non-priority variants may be simulated if they serve as necessary intermediate steps in these chains.

The catalog of reactions is comprehensive yet strictly lean: it is guaranteed that simulating the entire catalog would reconcile all variants in the collection, and the total number of available reactions is always exactly one less than the number of variants.

Determine the minimum total computational credits required to simulate a valid subset of reactions that achieves mutual reconciliation for the priority group.

## Input

The first line provides three integers **n**, **m**, and **t**. The laboratory capacity ensures that the number of variants **n** is at most 200,000. The priority group size **t** is at least 1 and at most **n**. The number of available reactions **m** is always exactly **n** - 1.
The second line lists **t** distinct integers representing the labels of the priority variants.
Following this are **m** lines, each containing three integers **u**, **v**, and **w**. These values indicate a reaction bridging variant **u** and variant **v** that requires **w** computational credits to simulate. The cost **w** is at least 1 and at most 1,000,000. The labels **u** and **v** are distinct and between 1 and **n**.

## Output

Output a single integer representing the minimum possible total computational credits required to simulate the necessary reactions to achieve mutual reconciliation among all priority variants.

<RATIONALE>
I completely removed the explicit explanation that omitting any operation would leave the system unresolvable (the "minimal basis" affordance). Instead, the problem now only states that the full set of reactions connects all variants and that `m = n - 1`. This forces the model to genuinely reason about the graph's structure (deducing it is a tree from the edge count and connectivity) rather than pattern-matching on the explicit description of a minimal connected component. I also shifted the domain to biochemical variant reconciliation to prevent surface-level matching with known calibration problems.
</RATIONALE>
<PRESERVED_ANSWER>
The problem still requires finding the minimum cost subgraph that connects a specific subset of nodes in a given tree, which means the required edges are exactly those in the unique minimal spanning subtree for the priority nodes, leaving the mathematical answer identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying graph is still a tree, so the optimal solution is uniquely determined by pruning paths that do not lead to priority nodes, which remains solvable in O(n) time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "simulating a reaction once unlocks the transformation... in both directions" as requiring two separate costs, but the phrasing explicitly says "simulating a reaction once... requires a certain amount" which implies a single cost.
</RISK>
