We can model the synchronizers as edges of a graph, and the critical indices as special nodes.  
The condition says: for any cut that separates at least two critical nodes, we must have at least one selected edge crossing that cut.  
This is equivalent to saying that all critical nodes must be in the same connected component after selecting edges.  

Since we have exactly `n-1` edges and the full set connects all nodes, the graph is a tree.  
We need to connect all critical nodes in this tree with minimum total edge weight.  

That’s exactly the **Steiner tree** problem on a tree, which can be solved by taking the minimal subtree that spans all critical nodes.  
We can do this by:

1. Mark critical nodes.
2. Do a DFS from any critical node, and keep only edges that lead to at least one critical node in their subtree.
3. Sum the weights of those kept edges.

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    critical = set(map(int, input().split()))
    
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    if t <= 1:
        print(0)
        return
    
    visited = [False] * (n + 1)
    
    def dfs(u, parent):
        visited[u] = True
        has_critical = u in critical
        total = 0
        for v, w in adj[u]:
            if v == parent:
                continue
            if not visited[v]:
                sub_has, sub_cost = dfs(v, u)
                if sub_has:
                    total += sub_cost + w
                    has_critical = True
        return has_critical, total
    
    # start from any critical node
    start = next(iter(critical))
    _, ans = dfs(start, -1)
    print(ans)

if __name__ == "__main__":
    solve()
```
