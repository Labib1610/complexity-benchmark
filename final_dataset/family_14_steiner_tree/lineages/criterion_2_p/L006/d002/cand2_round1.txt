# Problem B — Relative Calibration

Time limit: 2 s
Memory limit: 256 MB

## Description

A network of **n** sensors (numbered starting from 1 up to **n**) is undergoing a relative calibration phase. The diagnostic system's memory is designed to track a maximum of 200,000 sensors. Absolute readings cannot be measured directly. Instead, the system relies on **m** available pairwise calibration procedures. Each procedure compares two distinct valid sensor identifiers, determining the exact numerical difference between their readings. To prevent redundant measurements, the exact number of available procedures is always one less than the total number of sensors. These procedures are comprehensive: if all were executed, the relative difference between any two sensors in the network could be mathematically deduced.

A priority group of **t** target sensors is identified (this group can range from a single sensor up to the entire array). Your task is to select a subset of the available procedures to perform such that the relative difference between every pair of these **t** target sensors can be deduced. You may use other non-target sensors as intermediaries in these calculations.

Each procedure has a known financial cost to execute, requiring a budget allocation of at least 1, up to a maximum grant of 1,000,000. You must find a valid selection of procedures that minimizes the total execution cost, and report this minimum total cost.

## Input

The first line contains three integers **n**, **m**, and **t**. The limits and exact relationships for these values are governed by the system capacities and protocols detailed in the description.
The second line contains **t** distinct integers: the identifiers of the target sensors.
Each of the following **m** lines contains three integers **u**, **v**, and **w**, representing an available calibration procedure between sensor **u** and sensor **v** that costs **w** to execute.

## Output

Print a single integer: the minimum total execution cost of the procedures required to deduce the relative differences among all target sensors.

## Examples

### Example 1

**Input**
```

1 4

```

**Output**
```
8
```

```

```

**Output**
```

```
