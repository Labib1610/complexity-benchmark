We have a tree with n nodes and n-1 edges, each with a cost. We need to connect all t priority nodes with the minimum total cost. This is the **Steiner tree** problem on a tree, which can be solved by taking the minimal subtree that connects all terminals.

The minimal subtree connecting a set of terminals in a tree is the union of all paths between terminals. Its cost is the sum of edges in that union.

We can find it by:
1. Marking all priority nodes.
2. Doing a DFS from any node, and for each edge, if both sides contain at least one priority node, the edge is needed.

We can compute this with a single DFS, counting priority nodes in each subtree.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    priority = set(map(int, input().split()))
    adj = [[] for _ in range(n+1)]
    edges = []
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
        edges.append((u, v, w))
    
    # We'll root at 1
    parent = [0]*(n+1)
    parent_cost = [0]*(n+1)
    order = [1]
    parent[1] = -1
    for u in order:
        for v, w in adj[u]:
            if v != parent[u]:
                parent[v] = u
                parent_cost[v] = w
                order.append(v)
    
    # Count priority nodes in each subtree
    cnt = [0]*(n+1)
    for node in priority:
        cnt[node] = 1
    
    total_cost = 0
    # Process in reverse order (post-order)
    for u in reversed(order):
        if u == 1:
            continue
        p = parent[u]
        cnt[p] += cnt[u]
        if cnt[u] > 0 and cnt[u] < t:
            total_cost += parent_cost[u]
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
