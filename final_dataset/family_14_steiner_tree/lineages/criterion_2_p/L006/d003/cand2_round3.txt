# Problem B — Relative Calibration

Time limit: 2 s
Memory limit: 256 MB

## Description

A facility contains **n** sensors, labeled from 1 to **n**. The facility's calibration grid is organized into 400 zones, each capable of monitoring exactly 500 sensors, which establishes the maximum possible number of sensors. Because their absolute baseline readings are unobservable, their calibration must rely entirely on pairwise comparisons. You are given a roster of **m** potential testing operations. A single operation evaluates a specific pair of distinct sensors and yields the precise numerical offset between them.

The roster of operations provides full coverage of the facility: executing all of them would allow you to calculate the relative offset between any two sensors in the system. To avoid redundant testing, the roster is minimally connected: the number of potential operations is exactly one fewer than the total number of sensors.

Your objective focuses on a designated priority group of **t** sensors. The priority group contains at least one sensor, and could include all active sensors in the facility. You need to choose a subset of the testing operations so that the relative offset between every pair of these **t** priority sensors can be calculated. You are allowed to include tests involving non-priority sensors if they help bridge the calculations between the priority ones.

Each testing operation carries a specific monetary cost, determined by the required equipment time in microseconds. This cost spans at least 1 microsecond and is capped at exactly one full second (one million microseconds). Determine the minimum total cost required to fund a valid subset of operations that fully integrates the priority sensors.

## Input

The first line provides three integers **n**, **m**, and **t**. The values conform to the physical and operational limits described above.
The second line lists **t** distinct integers representing the labels of the priority sensors.
Following this are **m** lines, each containing three integers **u**, **v**, and **w**. These values indicate a potential testing operation that evaluates sensor **u** and sensor **v** at a cost of **w**. It is guaranteed that the given **m** operations can relate all **n** sensors, forming the structure described above.

## Output

Output a single integer representing the minimum possible total cost to execute the necessary operations to deduce the offsets among all priority sensors.
