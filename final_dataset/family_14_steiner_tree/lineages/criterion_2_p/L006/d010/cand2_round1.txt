<STATEMENT>
# Problem B — Linear Span Optimization

Time limit: 2 s
Memory limit: 256 MB

## Description

You are working in an $n$-dimensional vector space $V$ over the real numbers, with a fixed basis $B = \{b_1, b_2, \dots, b_n\}$. 
You are given a target subset $T$ consisting of $t$ distinct basis indices.

You have a catalog of $m$ available vectors in $V$. The $i$-th vector is defined as $v_i = b_{u_i} - b_{v_i}$, and selecting it incurs a cost of $w_i$.

When you select a subset $C$ of the $m$ available vectors, they generate a linear subspace $\text{Span}(C)$. 
Your goal is to select a subset $C$ such that for any two indices $j, k \in T$, the difference vector $b_j - b_k$ belongs to $\text{Span}(C)$.

You are given that $m = n - 1$. Furthermore, it is mathematically guaranteed that if you were to select all $m$ available vectors, their linear span would have a dimension of exactly $n - 1$.

Determine the minimum total cost (the sum of $w_i$ for the vectors in $C$) required to select a valid subset $C$ that satisfies the span requirement for all pairs of indices in $T$.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **t** ≤ **n**, 1 ≤ **n** ≤ 200000, **m** = **n** − 1). The basis vectors are indexed from 1 to **n**.
The second line lists **t** distinct integers representing the indices of the target subset $T$.
Following this are **m** lines, each containing three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000). These values define an available vector $b_u - b_v$ that can be selected at a cost of **w**.

## Output

Output a single integer representing the minimum possible total cost to select a subset of vectors that satisfies the span requirement for $T$.

## Examples

### Example 1

**Input**
```
4 3 2

1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

```

```


**Output**
```
9
```

<RATIONALE>
I changed the framing from invariant subspaces of swap operations to the linear span of difference vectors ($b_u - b_v$). This forces the models to recognize that the linear algebra problem over an $(n-1)$-dimensional span of $n-1$ difference vectors is structurally identical to finding a minimal subtree in a tree, preventing them from blindly applying graph algorithms without understanding the algebraic equivalence.
</RATIONALE>
<PRESERVED_ANSWER>
Because the $m=n-1$ difference vectors span an $(n-1)$-dimensional space, they are linearly independent, meaning any target difference $b_j - b_k$ has a unique linear combination of vectors; thus the required subset of vectors is exactly the path in the corresponding tree, making the minimum cost identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the minimal subtree connecting a set of target nodes in a given tree, which is solvable in $O(n)$ time, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might interpret "linear span" as requiring a real-valued matrix representation, leading to MLE/TLE if they attempt to construct dense matrices for $N=200,000$, though mathematically the problem is unambiguous.
</RISK>
