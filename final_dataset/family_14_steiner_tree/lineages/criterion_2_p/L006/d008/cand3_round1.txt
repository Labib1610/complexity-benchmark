<METHOD_NAME>Implicit Tree Deduction via Bridge Property</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit connectivity guarantee ("forces all x_i to be equal") with the property that removing any edge strictly reduces the number of connected pairs. This logically implies the graph is a forest, and combined with M = N - 1, implies a single tree, preserving the P complexity. Models that fail to deduce this will likely attempt general graph algorithms and fail.</METHOD_DESCRIPTION>

<STATEMENT>
# Information State Synchronization

Time limit: 2 s
Memory limit: 256 MB

## Description

You are configuring a distributed network consisting of $N$ data nodes. A functioning network requires at least $1$ node, and hardware constraints limit $N$ to a maximum of $200,000$. The nodes are assigned sequential IDs from $1$ to $N$.

A subset of these nodes, containing $T$ nodes, are designated as critical. $T$ is at least $1$ and can be up to $N$. Your task is to ensure that all critical nodes maintain the exact same information state.

You have access to a catalog of $M$ bidirectional synchronization channels. The network architecture strictly dictates that $M$ is exactly $N - 1$. 
Activating a channel between two distinct nodes forces their information states to be identical and requires a specific activation energy. The energy for any channel is a positive integer, bounded by a maximum capacity of $1,000,000$.

Your objective is to select a subset of these channels to activate, such that the critical nodes are mathematically guaranteed to share the same information state through the transitive property of equality. 
Equivalently, for any possible partition of the network's nodes into two non-empty disjoint sets $A$ and $B$, if both $A$ and $B$ contain at least one critical node, your selected subset of activated channels must contain at least one channel that bridges $A$ and $B$.

You may activate channels connecting to non-critical nodes if they are useful for propagating the state between critical nodes.

To assist with your configuration, the network topology guarantees that every channel in the catalog is strictly necessary for maximum connectivity: permanently removing any single channel from the full catalog would strictly reduce the total number of node pairs that can potentially share an information state. 

Determine the minimum total activation energy required to activate a valid subset of channels.

## Input

The first line provides the three integers $N$, $M$, and $T$.
The second line lists $T$ distinct integers representing the IDs of the critical nodes.
Following this are $M$ lines, each describing an available channel with three integers: the IDs of the two nodes it connects, and its activation energy.

## Output

Output a single integer representing the minimum possible total activation energy to satisfy the synchronization requirement for the critical nodes.

## Examples


**Output**
```
8
```

```

```

**Output**
```
9
```
</STATEMENT>
<RATIONALE>
The explicit guarantee that the full edge set connects all variables has been removed. It is replaced with the property that every edge is a bridge (removing it reduces connected pairs), which combined with $M = N - 1$ mathematically guarantees the graph is a single tree. Models must now deduce the tree structure rather than relying on explicit connectivity keywords; failure to do so will likely result in attempting a general Steiner tree algorithm, which will fail on the large bounds. Numeric bounds are also integrated into the scenario text.
</RATIONALE>
<PRESERVED_ANSWER>
The required output remains the minimum cost to connect the critical nodes, and since the inputs are identical (and logically constrained to be trees by the new description), the minimum spanning subtree cost is unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains in P because a graph with $N$ vertices, $N-1$ edges, and where every edge is a bridge is mathematically guaranteed to be a single tree, making the minimum Steiner tree solvable in linear time.
</PRESERVED_CLASS>
<RISK>
Models might find the bridge property wording slightly abstract, but it is a rigorous graph-theoretic condition (every edge is a cut edge) that unambiguously defines a forest, avoiding any contradiction.
</RISK>
