<STATEMENT>
# Problem B — Equivalence System Activation

Time limit: 2 s
Memory limit: 256 MB

## Description

You are tasked with enforcing a set of constraints on an array of $n$ continuous variables $X = [x_1, x_2, \dots, x_n]$. You have a critical subset $T$ containing $t$ indices that require synchronization.

You are given a catalog of $m$ available bidirectional synchronizers. Each synchronizer can enforce the equality constraint $x_u = x_v$ and requires an activation energy $w$.

Your goal is to select a subset of synchronizers $C$ from the catalog such that for any two indices $i, j \in T$, the equation $x_i = x_j$ is mathematically guaranteed by the synchronizers in $C$ (using the standard transitive, symmetric, and reflexive properties of equality). 

You may activate synchronizers that do not involve any indices from $T$ if they are needed to propagate the equality constraints between critical variables.

You are given that $m = n - 1$. Furthermore, it is mathematically guaranteed that if you were to activate all $m$ available synchronizers, the equality $x_i = x_j$ would be guaranteed for all $i, j \in T$. Note that variables outside the critical subset might not be fully constrained to the others by the full catalog of synchronizers.

Determine the minimum total activation energy required to choose a valid collection $C$ that synchronizes the critical subset $T$. If $t=1$, the minimum total energy is 0.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **t** ≤ **n**, 1 ≤ **n** ≤ 200000, **m** = **n** − 1). The variables are indexed from 1 to **n**.
The second line lists **t** distinct integers representing the indices of the critical subset $T$.
Following this are **m** lines, each containing three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000). These values indicate an available synchronizer that enforces $x_u = x_v$ and can be activated at an energy cost of **w**.

## Output

Output a single integer representing the minimum possible total energy to activate a collection of synchronizers that satisfies the required property for $T$.

</STATEMENT>
<RATIONALE>
Removed the explicit guarantee that all $n$ variables are connected by the full edge set, which previously allowed models to immediately assume a global tree structure and use a simple DFS shortcut. The problem now only guarantees that the critical subset $T$ is connected, forcing models to handle the possibility of disconnected components and cycles outside $T$, while the actual test cases (which are indeed trees) remain perfectly valid.
</RATIONALE>
<PRESERVED_ANSWER>
The test cases are unchanged and still consist of global trees; since the unique minimal subset of edges connecting $T$ remains identical, any valid approach to satisfy the connectivity constraint will yield the exact same minimum energy.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains finding a Steiner tree on a graph that is structurally a tree (since $m=n-1$ and the test cases are connected), which is solvable in polynomial time O(n).
</PRESERVED_CLASS>
<RISK>
Models might perceive the problem as NP-hard because finding a Steiner tree in a general graph (or a disconnected graph with cycles) is NP-hard, which could cause them to fail to write an optimal polynomial-time algorithm, though this is the intended effect of removing the global tree affordance.
</RISK>
