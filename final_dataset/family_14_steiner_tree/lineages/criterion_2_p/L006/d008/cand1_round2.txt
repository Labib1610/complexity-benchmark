# Problem B — Isotopic Equilibration

Time limit: 2 s
Memory limit: 256 MB

## Description

You are analyzing a system of $n$ distinct isotopes, indexed 1 through $n$. A specific subset of $t$ isotopes are designated as *target isotopes*.

You have a catalog of $m$ reversible catalytic reactions available. Each reaction bridges isotope $u$ and isotope $v$, and requires a thermal activation energy $w$ to sustain. 

Your goal is to sustain a subset of these reactions, $C$, that satisfies the following structural cut-property: For every possible division of the $n$ isotopes into two disjoint, non-empty partitions $A$ and $B$, if partition $A$ contains at least one target isotope and partition $B$ contains at least one target isotope, then there must be at least one reaction sustained in $C$ that bridges an isotope in $A$ with an isotope in $B$.

You may include reactions in $C$ that involve non-target isotopes if they are needed to satisfy this cut-property. (Equivalently, this property logically ensures that all $t$ target isotopes are merged into the exact same equilibrated pool via sequences of sustained reactions).

You are given that $m = n - 1$. Furthermore, the full catalog of $m$ available reactions is comprehensive, meaning it satisfies the cut-property for the entire system: for *any* division of the $n$ isotopes into two disjoint, non-empty partitions (regardless of target isotopes), there is always at least one reaction in the full catalog that bridges the two partitions. 

Determine the minimum total thermal activation energy required to sustain a valid subset of reactions $C$ that fulfills the cut-property for the target isotopes.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **t** ≤ **n**, 1 ≤ **n** ≤ 200000, **m** = **n** − 1). The isotopes are indexed from 1 to **n**.
The second line lists **t** distinct integers representing the indices of the target isotopes.
Following this are **m** lines, each containing three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000). These values indicate an available reaction between isotope $u$ and isotope $v$ that requires an activation energy of **w**.

## Output

Output a single integer representing the minimum possible total activation energy to sustain a subset of reactions that satisfies the requirement for the target isotopes.

**Output**

8
```

```

<RATIONALE>
I changed the problem description to define both the objective and the full-graph connectivity strictly through the mathematical cut-property rather than path-based or explicit tree language. This forces the model to deduce that a graph with $m=n-1$ satisfying the global cut-property is a tree, and that the cut-property for target nodes in a tree is satisfied by the unique minimal subtree connecting them, while baiting pattern-matchers into thinking it is a Min-Cut problem.
</RATIONALE>
<PRESERVED_ANSWER>
The cut-property for target nodes is mathematically identical to requiring all target nodes to be in the same connected component, so the valid subsets and their minimum costs remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The full catalog is still given as $m=n-1$ and satisfies the global cut-property (meaning it is connected), which guarantees the input graph is a tree, keeping the problem solvable in $O(n)$ time.
</PRESERVED_CLASS>
<RISK>
Models or readers might initially misunderstand the cut-property as an edge-cut removal game rather than a subset selection requirement, though the text explicitly asks to "sustain a subset of these reactions".
</RISK>
