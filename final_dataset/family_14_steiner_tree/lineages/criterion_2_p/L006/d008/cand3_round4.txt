# Problem B — Equivalence System Activation

Time limit: 2 s
Memory limit: 256 MB

## Description

You are tasked with enforcing a set of constraints on an array of $n$ continuous variables $X = [x_1, x_2, \dots, x_n]$. You have a critical subset $T$ containing $t$ indices that require synchronization.

You are given a catalog of $m$ available bidirectional synchronizers. Each synchronizer can enforce the equality constraint $x_u = x_v$ and requires an activation energy $w$.

Your goal is to select a subset of synchronizers $C$ such that for any two indices $i, j \in T$, the equation $x_i = x_j$ is mathematically guaranteed by the synchronizers in $C$ (using the standard transitive, symmetric, and reflexive properties of equality). 

Equivalently, the collection $C$ must satisfy the following structural property: For every possible partition of the $n$ indices into two disjoint non-empty sets $A$ and $B$, if both $A$ and $B$ contain at least one index from $T$, then there must exist at least one synchronizer in $C$ that bridges the partition (i.e., enforces $x_u = x_v$ where $u \in A$ and $v \in B$).

You may activate synchronizers that do not involve any indices from $T$ if they are needed to propagate the equality constraints between critical variables.

You are given that $m = n - 1$. Furthermore, it is mathematically guaranteed that if you were to activate all $m$ available synchronizers, all variables in the critical subset $T$ would be successfully synchronized. Note that variables outside the synchronized critical component may be disconnected from it.

Determine the minimum total activation energy required to choose a valid collection $C$ that synchronizes the critical subset $T$.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **t** ≤ **n**, 1 ≤ **n** ≤ 200000, **m** = **n** − 1). The variables are indexed from 1 to **n**.
The second line lists **t** distinct integers representing the indices of the critical subset $T$.
Following this are **m** lines, each containing three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000). These values indicate an available synchronizer that enforces $x_u = x_v$ and can be activated at an energy cost of **w**.

## Output

Output a single integer representing the minimum possible total energy to activate a collection of synchronizers that satisfies the required property for $T$.

<RATIONALE>
I replaced the guarantee that the full set of synchronizers equates all variables with a weaker guarantee that it only synchronizes the critical subset T, explicitly noting that other variables may be disconnected. This forces models to handle the possibility of disconnected components and cycles, breaking their assumption that the input forms a single spanning tree that can be trivially rooted and traversed.
</RATIONALE>
<PRESERVED_ANSWER>
The hidden test cases remain identical (they are still spanning trees), so the optimal subset of synchronizers and its minimum cost are unchanged for every input.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem solved by the reference solution is unchanged, and since the actual inputs remain trees, finding the minimal connecting subset remains solvable in O(n) polynomial time.
</PRESERVED_CLASS>
<RISK>
Models might deduce that allowing disconnected components when m = n - 1 implies the presence of cycles within the critical component, which would make the general problem NP-hard and could cause them to output overly complex or exponential algorithms that fail on time limits.
</RISK>
