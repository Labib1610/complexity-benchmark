<METHOD_DESCRIPTION>
This method translates the graph connectivity problem into the language of algebraic topology, specifically 1-chains and boundaries over the field GF(2). By defining a "1-chain" as a subset of 1-simplices and its "boundary" as the elements appearing an odd number of times, the requirement that a path exists between two nodes is reformulated as requiring the existence of a 1-chain whose boundary is exactly those two nodes. This entirely removes graph terminology (nodes, edges, trees, paths) and forces the model to either mathematically prove the equivalence to a tree minimal-subtree problem or attempt to solve it using linear algebra over GF(2) (which will TLE or fail).
</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Boundary Chain Activation

Time limit: 2 s
Memory limit: 256 MB

## Description

You are analyzing a discrete algebraic structure defined on $n$ basis elements, indexed from 1 to $n$. You have a designated critical subset $T$ containing $t$ basis elements.

You are given a catalog of $m$ available 1-simplices. Each 1-simplex is defined by a pair of basis elements $(u, v)$ and has an associated activation cost $w$.

We define a **1-chain** as any subset of the activated 1-simplices. 
The **boundary** of a 1-chain is defined as the set of basis elements that appear an *odd* number of times across the 1-simplices in that 1-chain. (This is mathematically equivalent to the boundary operator over the field $\mathbb{Z}_2$).

Your goal is to select a subset of 1-simplices $C$ to activate, such that for any two distinct critical basis elements $i, j \in T$, the two-element set $\{i, j\}$ is exactly the boundary of at least one 1-chain $L \subseteq C$.

You may activate 1-simplices that do not involve any elements from $T$ if they are needed to form the required 1-chains.

You are given that $m = n - 1$. Furthermore, it is mathematically guaranteed that if you were to activate all $m$ available 1-simplices, the required property would hold for any pair of basis elements in the entire structure (meaning the full set of $m$ simplices contains a 1-chain that forms the boundary $\{x, y\}$ for any $x \neq y$).

Determine the minimum total activation cost required to choose a valid collection $C$.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **t** ≤ **n**, 1 ≤ **n** ≤ 200000, **m** = **n** − 1). The basis elements are indexed from 1 to **n**.
The second line lists **t** distinct integers representing the indices of the critical subset $T$.
Following this are **m** lines, each containing three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000). These values indicate an available 1-simplex between basis element **u** and basis element **v** that can be activated at a cost of **w**.

## Output

Output a single integer representing the minimum possible total cost to activate a collection of 1-simplices that satisfies the boundary condition for all pairs in the critical subset $T$.

<RATIONALE>
Removed all references to variables, equality constraints, and synchronization, replacing them with concepts from algebraic topology (1-simplices, 1-chains, and boundaries over Z_2). The requirement that two nodes are connected by a path is mathematically exactly equivalent to requiring that the two nodes form the boundary of some 1-chain. This forces the model to either deduce that a 1-chain with a two-element boundary in a tree is simply a unique path, or fail by attempting a matrix-based GF(2) null-space algorithm which would TLE.
</RATIONALE>
<PRESERVED_ANSWER>
The boundary of a 1-chain in a graph without cycles (since m = n - 1 and it spans all nodes) is exactly the endpoints of a path; therefore, finding a subset of 1-simplices that contains a path between all pairs in T is identical to finding the minimal subtree connecting T, preserving the optimal cost.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying graph is still a tree and the problem still asks for the weight of the minimal subtree spanning a set of terminal nodes, which remains solvable in O(n) time using DFS or topological sorting.
</PRESERVED_CLASS>
<RISK>
A model might misunderstand "appear an odd number of times across the 1-simplices" if it fails to realize this simply means the degree of the vertex in the chosen subgraph, but the definition is mathematically precise and standard.
</RISK>
