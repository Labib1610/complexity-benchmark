<METHOD_NAME>Boolean Constraint Satisfaction Framing</METHOD_NAME>
<METHOD_DESCRIPTION>Translates the vector space basis and spanning condition into a boolean constraint satisfaction problem. Vertices become boolean variables, and edges become equality constraints ($x_u = x_v$). The requirement to span priority vectors is reframed as forcing all priority variables to hold identical truth values across all valid assignments. This masks the underlying graph connectivity and tree structure as logical deduction, heavily confusing models that rely on standard graph DP templates.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Subspace Acquisition

Time limit: 2 s
Memory limit: 256 MB

## Description

You are analyzing a system of $n$ boolean variables, $x_1, x_2, \dots, x_n$. 

You are provided with a catalog of $m$ available logical constraints. Each available constraint is defined by a pair of variable indices $(u, v)$ and enforces the condition that $x_u$ and $x_v$ must have the same truth value. 

The complete catalog of $m$ constraints is minimally restrictive enough to leave exactly two globally valid assignments for the entire system (the assignment where all variables are True, and the assignment where all are False). This means that if you activate all $m$ constraints, every variable is forced to hold the same truth value as every other variable, but omitting even one constraint from the catalog would strictly increase the number of valid assignments for the system.

Your objective focuses on a designated priority set of $t$ variables. You must purchase a subset of the available constraints such that, in every possible boolean assignment that satisfies your purchased subset, all variables in the priority set are forced to share the same truth value. You may purchase constraints involving non-priority variables if they are useful for propagating the logical restrictions.

Each constraint in the catalog has a specific activation cost. Determine the minimum total cost required to acquire a valid subset of constraints that satisfies the uniform truth-value condition for all variables in the priority set.

## Input

The first line provides three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, and $m$ is always exactly $n - 1$).
The second line lists $t$ distinct integers representing the indices in the priority set.
Following this are $m$ lines, each containing three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$). These values indicate an available constraint between $x_u$ and $x_v$ that can be purchased at a cost of $w$. It is guaranteed that the full catalog of $m$ constraints satisfies the minimal restrictiveness property described above.

## Output

Output a single integer representing the minimum possible total cost to purchase a subset of constraints that guarantees $x_i = x_j$ for all priority indices $i$ and $j$ across all satisfying assignments.

</STATEMENT>
<RATIONALE>
The problem was reframed from a vector space span to a boolean constraint satisfaction scenario. This forces the model to deduce that "forcing variables to share the same truth value" is mathematically equivalent to finding a connected subgraph containing those variables, bypassing explicit graph terminology that triggers DP templates.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that variables share a truth value in all valid assignments holds if and only if they are in the same connected component of the enforced equivalence relations, which is isomorphic to spanning the difference vectors in the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains finding the minimum weight subtree connecting a subset of vertices in a tree, which is solvable in linear time using dynamic programming or a post-order traversal, keeping the problem in P.
</PRESERVED_CLASS>
