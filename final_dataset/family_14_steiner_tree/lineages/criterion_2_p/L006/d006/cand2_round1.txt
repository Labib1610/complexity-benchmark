<METHOD_NAME>Permutation Group Generators</METHOD_NAME>
<METHOD_DESCRIPTION>Transforms the problem of finding a minimal connected subgraph into finding a minimum-cost set of transpositions that generate a subgroup containing specific target transpositions. Since transpositions generate the full symmetric group if and only if their underlying graph is connected, and $m=n-1$ implies the available transpositions form a tree, this requires finding the unique Steiner tree spanning the target elements. Models relying on surface patterns will likely attempt group-theoretic algorithms instead of tree pruning, leading to failure.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Subgroup Generation

Time limit: 2 s
Memory limit: 256 MB

## Description

You are working with the symmetric group $S_n$, which consists of all permutations of the set of elements $\{1, 2, \dots, n\}$.

You are provided with a catalog of $m$ optional group generators. Each available generator is a transposition $(u, v)$ that swaps the elements $u$ and $v$ while leaving all other elements fixed. Each generator has a specific acquisition cost.

Your objective focuses on a designated target set of $t$ elements. You must acquire a subset of the available generators such that the subgroup they generate contains the transposition $(i, j)$ for every pair of distinct elements $i$ and $j$ in the target set. You may acquire generators involving non-target elements if they are useful for building the required permutations.

Determine the minimum total cost required to acquire a valid subset of generators that satisfies this condition for the target set.

## Input

The first line provides three integers $n$, $m$, and $t$. The degree of the symmetric group, $n$, is at most 200,000. The number of available generators, $m$, is exactly $n - 1$. The number of target elements, $t$, ranges from 1 up to $n$.
The second line lists $t$ distinct integers from $1$ to $n$, representing the elements in the target set.
Following this are $m$ lines, each containing three integers $u$, $v$, and $w$. These values indicate an available transposition $(u, v)$ with $u \neq v$. The acquisition cost $w$ is a positive integer bounded by 1,000,000. It is guaranteed that if you were to acquire all $m$ generators, the subgroup they generate would be the entire symmetric group $S_n$.

## Output

Output a single integer representing the minimum possible total cost to acquire a subset of generators that satisfies the requirement.

## Examples

### Example 1

**Input**
```

```

**Output**
```
8
```


<RATIONALE>
I changed the framing from satisfying equality constraints to selecting transpositions that generate a specific subgroup of the symmetric group. This forces the model to mathematically deduce that transpositions generate a subgroup containing $(i, j)$ if and only if $i$ and $j$ are in the same connected component of the generator graph, thereby recovering the concealed tree structure.
</RATIONALE>
<PRESERVED_ANSWER>
The answers are perfectly identical because the subgroup generated by a forest of transpositions contains a transposition $(i, j)$ if and only if $i$ and $j$ are connected by the chosen transpositions, making the valid subsets exactly the subtrees spanning the target set.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class remains polynomial time (solvable in O(n)) because the underlying mathematical structure is still finding the unique minimal Steiner tree on a given unrooted tree.
</PRESERVED_CLASS>
