# Problem B — Hub Connectivity

Time limit: 2 s
Memory limit: 256 MB

## Description

A government is upgrading the transit network connecting a number of towns, **n** (numbered 1 to **n**). The national geographic registry limits the total number of towns **n** to at most two hundred thousand, and there is always at least one town.
There are **m** available transit segments. To ensure a lean infrastructure, the number of available segments **m** is exactly one less than **n**. These available segments connect all **n** towns in such a way that between any two towns there is exactly one route using these segments.

The government has designated **t** of these towns as critical hubs. The number of critical hubs is at least one, and cannot exceed the total number of towns **n**.
Your task is to select a subset of the available transit segments to refurbish. You must choose the segments such that for every pair of critical hubs, there is a path between them using only the refurbished segments (this path may pass through other towns which are not critical hubs).

Each available segment connects two distinct towns and requires a refurbishment cost **w**. The cost **w** represents the required labor, which ranges from a minimum of 1 worker-day up to a maximum of one million worker-days per segment.

You must find a valid selection of transit segments that keeps the total refurbishment cost as low as possible, and report this minimum total cost.

## Input

The first line contains three integers **n**, **m**, and **t**. The values conform to the registry and capacity limits described above: **n** is between 1 and 200,000, **m** is exactly one less than **n**, and **t** is between 1 and **n**.
The second line contains **t** distinct integers: the identifiers of the critical hubs.
Each of the next **m** lines contains three integers **u**, **v**, and **w**. These represent an available transit segment between distinct towns **u** and **v** requiring **w** worker-days to refurbish (**u** and **v** are valid town identifiers between 1 and **n**, and **w** is between 1 and 1,000,000). It is guaranteed that the full set of **m** segments forms the exact network structure described above.

## Output

Print a single integer: the minimum total refurbishment cost (in worker-days) required to ensure all critical hubs are connected to one another via the chosen segments.
