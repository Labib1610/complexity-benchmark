# Problem B — Priority Infrastructure

Time limit: 2 s
Memory limit: 256 MB

## Description

A university is upgrading the communication hardware across **n** facilities, numbered 1 through **n**. The planners have evaluated **m** potential conduit installations. Each installation spans between two specific facilities and carries a known activation cost. When all **m** potential installations are considered together, they provide full connectivity, meaning data could theoretically pass between any two facilities in the system.

A specific group of **t** facilities has been designated as mission-critical. You need to determine the absolute minimum total activation cost required to purchase a subset of the potential installations such that information can be successfully exchanged among all mission-critical facilities. Data may be relayed through any number of intermediate facilities (which may or may not be mission-critical themselves) as long as the purchased installations provide a valid sequence of connections between the critical ones.

## Input

The first line provides the integers **n**, **m**, and **t** (1 ≤ **t** ≤ **n**, 1 ≤ **n** ≤ 200000, **m** = **n** − 1).
The second line lists **t** distinct integers representing the labels of the mission-critical facilities.
Following this are **m** lines, each containing three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000). These signify a potential conduit installation between facility **u** and facility **v** with an activation cost of **w**. It is guaranteed that the complete collection of **m** installations provides full connectivity among all **n** facilities.

## Output

Output a single integer representing the minimum total cost of conduit installations needed to fully interconnect the mission-critical facilities.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```
