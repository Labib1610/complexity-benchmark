The problem asks for the minimum cost to connect all target sensors in a tree. Since the graph is a tree (m = n-1 and connected), the minimum cost to connect a subset of vertices (the targets) is the cost of the minimal Steiner tree. For a tree, the minimal Steiner tree is the minimal subtree spanning all target vertices. This subtree can be found by taking the union of all paths between target vertices. A standard way to compute the cost of this subtree is to perform a post-order traversal (or use union-find with edge processing) to find edges that lie on paths between target vertices.

An efficient approach for a tree is to use a union-find structure. We process edges in a way that identifies which edges are part of the minimal subtree connecting the targets. However, a simpler and robust method for trees is to root the tree and use a DFS to compute the number of target vertices in each subtree. An edge is part of the minimal Steiner tree if and only if the subtree below it contains at least one target vertex and at least one target vertex is outside that subtree (i.e., the count is strictly between 0 and t). This works because the graph is a tree, so the minimal subtree is unique.

Given n up to 200,000, we need an iterative DFS to avoid recursion depth issues.

```python
import sys

def solve():
    input_data = sys.stdin.buffer.read().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))
    
    targets = [int(next(it)) for _ in range(t)]
    is_target = [False] * (n + 1)
    for x in targets:
        is_target[x] = True
    
    adj = [[] for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        w = int(next(it))
        adj[u].append((v, w))
        adj[v].append((u, w))
        edges.append((u, v, w))
    
    if t <= 1:
        print(0)
        return
    
    # Iterative DFS to compute subtree target counts and identify edges in the Steiner tree
    # We root the tree at 1 (or any node)
    parent = [0] * (n + 1)
    parent_edge_weight = [0] * (n + 1)
    order = []
    stack = [1]
    parent[1] = -1
    while stack:
        u = stack.pop()
        order.append(u)
        for v, w in adj[u]:
            if parent[v] == 0 and v != parent[1]:
                # Actually need to be careful with root
                pass
    # Let's redo the iterative DFS properly
    parent = [0] * (n + 1)
    parent_edge_weight = [0] * (n + 1)
    order = []
    stack = [1]
    parent[1] = -1
    visited = [False] * (n + 1)
    visited[1] = True
    while stack:
        u = stack.pop()
        order.append(u)
        for v, w in adj[u]:
            if not visited[v]:
                visited[v] = True
                parent[v] = u
                parent_edge_weight[v] = w
                stack.append(v)
    
    count = [0] * (n + 1)
    for i in range(1, n + 1):
        if is_target[i]:
            count[i] = 1
    
    # Process in reverse order (post-order)
    for u in reversed(order):
        p = parent[u]
        if p != -1:
            count[p] += count[u]
    
    total_cost = 0
    for u in range(2, n + 1):
        c = count[u]
        if 0 < c < t:
            total_cost += parent_edge_weight[u]
    
    print(total_cost)

solve()
```
