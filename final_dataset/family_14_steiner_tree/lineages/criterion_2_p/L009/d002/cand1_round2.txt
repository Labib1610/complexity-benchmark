# Freight Hub Upgrades

Time limit: 2 s   Memory limit: 256 MB

## Description

A regional railway network is composed of **N** stations and **E** track segments. The segments are laid out such that there is exactly one unique route between any two stations. 

The transport authority has selected **F** stations to serve as priority freight hubs. They need to reinforce a subset of the track segments to handle heavy industrial trains. The chosen subset of segments must allow cargo to be routed between any pair of priority freight hubs using only reinforced segments. Each track segment has a specific reinforcement cost. 

Calculate the minimum total cost to reinforce a valid subset of track segments.

## Input

The first line contains three integers **N**, **E**, and **F**. The region can support a maximum of 200000 stations, so **N** is at least 1 and up to this capacity limit. The number of priority hubs **F** is at least 1 and at most **N**. Because of the unique routing topology, the number of track segments **E** is always exactly **N** - 1.
The second line contains **F** distinct integers: the identifiers of the freight hubs.
Each of the following **E** lines contains three integers **u**, **v**, and **w**. These represent a track segment between station **u** and station **v** (where **u** and **v** are distinct station identifiers ranging from 1 to **N**). The reinforcement cost **w** for any segment is at least 1 and will never exceed the municipal budget cap of 1000000.

## Output

Print a single integer: the minimum total cost to reinforce track segments such that all freight hubs are connected to each other via reinforced tracks.
