<STATEMENT>
# Permutation Orbit Optimization

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of states numbered from 1 to **N**.

You are provided with a catalog of **E** available operations. Each operation is a transposition that swaps the states **u** and **v**, leaving all other states fixed. Purchasing an operation incurs a cost of **w**. 

It is guaranteed that if the **E** available transpositions are viewed as undirected links between the states, they form a connected network with exactly one unique sequence of links between any two states. 

A specific subset of **F** states are designated as *critical*. Your task is to select a subset of the available transpositions to purchase such that all critical states belong to the same orbit under the subgroup generated by your purchased transpositions. In other words, for any two critical states $x$ and $y$, it must be possible to transform $x$ into $y$ using a sequence of the purchased transpositions.

Determine the minimum total cost required to purchase a valid subset of transpositions. (If **F** = 1, selecting no transpositions already satisfies the condition, so the minimum total cost is 0.)

## Input

The first line contains three integers **N**, **E**, and **F** (1 ≤ F ≤ N, 1 ≤ N ≤ 200000, E = N − 1).
The second line contains **F** distinct integers: the indices of the critical states.
Each of the following **E** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ N, u ≠ v, 1 ≤ w ≤ 1000000), representing an available transposition that swaps states **u** and **v**, and a purchase cost of **w**.

## Output

Print a single integer: the minimum total cost required to purchase a subset of transpositions whose generated subgroup places all critical states in the same orbit.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

```

```

**Output**
```
9
```

<RATIONALE>
The problem is reframed from linear algebra (spanning vectors) to abstract algebra (transpositions generating a subgroup). The required condition is that all critical states lie in the same orbit. This forces the model to recognize that the subgroup's orbits correspond to connected components, making it a Steiner tree problem on a network, without using graph-theory or linear-algebra keywords. The forbidden word "trivially" has been removed to comply with H3 constraints, and the structural uniqueness of paths is stated explicitly in neutral terms.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that critical states are in the same orbit under the generated subgroup is mathematically identical to them being in the same connected component of the selected edges, preserving the exact minimum cost.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure is still finding the minimum weight subgraph connecting a set of vertices in a connected structure with N-1 edges, which is solvable in linear time, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might struggle with the group theory terminology ("orbit", "subgroup generated by"), but the explanation ("transform $x$ into $y$ using a sequence of the purchased transpositions") resolves any ambiguity.
</RISK>
