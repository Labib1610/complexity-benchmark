<STATEMENT>
# Subspace Span Optimization

Time limit: 2 s   Memory limit: 256 MB

## Description

You are working in the polynomial ring $R = \mathbb{R}[z_1, z_2, \dots, z_N]$ over the real numbers.

You are given a catalog of **E** available binomials. Each binomial is of the form $z_u - z_v$. Purchasing the $i$-th binomial incurs a cost of **w**. (Multiplying a binomial by $-1$ does not change the ideal it generates, so the order of $u$ and $v$ is interchangeable.)

It is guaranteed that the ideal generated by the entire catalog of **E** binomials contains the polynomial $z_j - z_k$ for all $1 \le j, k \le N$.

A specific subset of **F** variables are designated as *critical*. Your task is to select a subset of the available binomials to purchase such that, if $I$ is the ideal in $R$ generated by your purchased subset, then for any two critical variables $z_x$ and $z_y$, the polynomial $z_x - z_y$ belongs to $I$.

Determine the minimum total cost required to purchase a valid subset of binomials. (If **F** = 1, the empty set of binomials generates the zero ideal, which is sufficient since there are no pairs of critical variables, so the minimum total cost is 0.)

## Input

The first line contains three integers **N**, **E**, and **F** (1 ≤ F ≤ N, 1 ≤ N ≤ 200000, E = N − 1).
The second line contains **F** distinct integers: the indices of the critical variables.
Each of the following **E** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ N, u ≠ v, 1 ≤ w ≤ 1000000), representing an available binomial $z_u - z_v$ and its purchase cost of **w**.

## Output

Print a single integer: the minimum total cost required to purchase a subset of binomials whose generated ideal satisfies the condition for all critical variables.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

<RATIONALE>
The surviving model recognized that vectors with exactly one 1 and one -1 represent incidence edges of a graph, and reduced the span condition to finding a spanning subtree. To remove this affordance, the linear algebra framing has been entirely replaced with algebraic geometry (polynomial rings and ideals). The mathematical condition remains strictly identical, since a degree-1 binomial $z_x - z_y$ is in the ideal generated by a set of degree-1 binomials if and only if it is in their linear span, which in turn means $x$ and $y$ are connected in the equivalent graph. This forces the model to independently deduce the equivalence between ideal membership and graph connectivity, breaking the surface-level pattern match.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $z_x - z_y \in I$ is mathematically equivalent to $x$ and $y$ being in the same connected component of the graph formed by the purchased binomials, so the optimal subset and its cost remain identical for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem is still finding the minimum weight subtree connecting a set of critical nodes in a given tree, which is solvable in O(N) time and remains in P.
</PRESERVED_CLASS>
<RISK>
Models might attempt to use symbolic algebra or Gröbner basis algorithms due to the "ideal" terminology and Time Limit Exceed, but the phrasing is mathematically unambiguous.
</RISK>
