# Network Valve Upgrade

Time limit: 2 s   Memory limit: 256 MB

## Description

A regional water network is assembled from **N** stations and **E** pipelines. Each pipeline joins exactly two stations. The pipelines unite all the stations into a single continuous network.

The water authority has identified **F** stations that are designated as primary hubs. To maintain the network's core functionality, a subset of the pipelines must be upgraded with reinforced valves. The chosen subset of pipelines must link all the primary hubs together. Specifically, it must be possible to pass from any primary hub to any other primary hub by crossing exclusively upgraded pipelines. (Non-primary stations may be passed through if they are joined by these upgraded pipelines).

Each pipeline requires a specific maintenance cost for the upgrade. Calculate the minimum total maintenance cost needed to upgrade a valid subset of pipelines.

## Input

The first line contains three integers **N**, **E**, and **F**. The regional controller supports up to 200,000 stations, so **N** is a positive integer bounded by this maximum capacity. The number of primary stations **F** is a positive integer that cannot exceed the total number of stations. To ensure no redundant loops exist, the network is designed such that the pipeline count **E** is exactly the station count minus one.

The second line contains **F** distinct integers: the identifiers of the primary stations.

Each of the following **E** lines contains three integers **u**, **v**, and **w**, representing a pipeline between station **u** and station **v** (where **u** and **v** are distinct positive integers no greater than the station count) requiring an upgrade cost of **w**. The cost **w** is a positive integer capped by the maximum municipal budget of 1,000,000 per pipeline.

## Output

Print a single integer: the minimum total maintenance cost required such that all primary hubs are linked exclusively via upgraded pipelines.

## Examples

```

```

