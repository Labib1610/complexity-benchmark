<STATEMENT>
# Secure Communications Network

Time limit: 2 s   Memory limit: 256 MB

## Description

A secure communications network consists of **N** outposts and **E** bidirectional transmission links. The links are arranged such that the entire network is fully integrated, meaning messages can route between any two outposts, and the total number of transmission links is exactly one less than the total number of outposts.

A security audit has flagged **F** specific outposts that handle highly classified intelligence. To ensure the integrity of their communications, a subset of the transmission links must be upgraded with quantum encryption hardware. 

The chosen subset of upgraded links must support a sequential synchronization protocol. This protocol is considered perfectly supported if there exists at least one permutation $(P_1, P_2, \dots, P_F)$ of all **F** classified outposts such that, for every $1 \le i < F$, the unique simple route in the network between outpost $P_i$ and outpost $P_{i+1}$ consists exclusively of upgraded links. 

Each link requires a certain financial allocation to be upgraded. Determine the minimum total financial allocation required to upgrade a valid subset of links that supports this protocol. (A link's upgrade cost is paid at most once, even if it is traversed multiple times by the protocol's routes).

## Input

The first line contains three integers **N**, **E**, and **F** (1 ≤ F ≤ N, 1 ≤ N ≤ 200000, E = N − 1).
The second line contains **F** distinct integers: the identifiers of the classified outposts.
Each of the following **E** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ N, u ≠ v, 1 ≤ w ≤ 1000000), representing a transmission link between outpost **u** and outpost **v** requiring a financial allocation of **w** to upgrade.

## Output

Print a single integer: the minimum total financial allocation required such that the upgraded links can support the sequential synchronization protocol for the classified outposts.

<RATIONALE>
I introduced a fictitious optimization dimension by requiring the upgraded links to support a path between consecutive nodes in *at least one* permutation of the classified outposts. Models that rely on surface pattern matching will perceive this as a sequence optimization problem (such as the Traveling Salesperson Problem) and attempt to search for an optimal permutation, leading to TLE or incorrect heuristics. Models that genuinely reason about the tree structure will deduce that the union of paths for *any* permutation of a set of nodes in a tree is identically their minimal spanning subtree, reducing the problem back to a simple bottom-up tree traversal.
</RATIONALE>
<PRESERVED_ANSWER>
In a tree topology, the union of simple paths between consecutive nodes in any permutation of a set of target nodes is exactly the unique minimal spanning subtree connecting those nodes, meaning the minimum cost to support any permutation is identical to the original cost of connecting all target nodes.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class remains P because the mathematically optimal set of edges is invariant to the permutation and is always the minimal spanning subtree, which can still be found in O(N) time using a single bottom-up traversal.
</PRESERVED_CLASS>
