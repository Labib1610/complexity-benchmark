<STATEMENT>
# Linear Operator Projection

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a linear operator defined by a set of linear functionals.
The input space $\mathbb{R}^N$ has coordinates $z_1, z_2, \dots, z_N$.
You are given a catalog of **E** available functionals. Each functional is of the form $f(z) = z_u - z_v$ for some pair of coordinate indices $u$ and $v$. Activating this functional for your system incurs a cost of **w**. (Note that $z_u - z_v$ and $z_v - z_u$ have the same kernel, so the order of $u$ and $v$ does not matter).

It is guaranteed that if you were to activate all **E** available functionals, forming a full operator $T_{full}: \mathbb{R}^N \to \mathbb{R}^E$, its kernel (null space) would consist exactly of the one-dimensional subspace of constant vectors (i.e., those vectors where $z_1 = z_2 = \dots = z_N$).

A specific subset of **F** coordinate indices are designated as *target* indices. Your task is to select a subset of the available functionals to activate. These selected functionals define a reduced operator $T_{red}$ (where $T_{red}(z)$ is the vector of the selected functionals' outputs). You must ensure that every vector $z$ in the kernel of $T_{red}$ satisfies $z_x = z_y$ for every pair of target indices $x$ and $y$.

Determine the minimum total cost required to activate a valid subset of functionals. (If **F** = 1, the condition is vacuously satisfied by any vector $z$, so no functionals need to be activated and the minimum total cost is 0.)

## Input

The first line contains three integers **N**, **E**, and **F** (1 ≤ F ≤ N, 1 ≤ N ≤ 200000, E = N − 1).
The second line contains **F** distinct integers: the target coordinate indices.
Each of the following **E** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ N, u ≠ v, 1 ≤ w ≤ 1000000), representing an available functional $z_u - z_v$ with an activation cost of **w**.

## Output

Print a single integer: the minimum total cost required to activate a subset of functionals whose reduced operator's kernel satisfies the condition for all target indices.

</STATEMENT>
<RATIONALE>
Changed the problem from vector subspace spanning to linear operator kernel constraints. The model must now deduce that enforcing $z_x = z_y$ for all vectors in the kernel is equivalent to connecting $x$ and $y$ in the graph of activated functionals. The explicit guarantee that the full kernel is 1-dimensional, combined with E=N-1, preserves the tree structure without using any graph terminology.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic condition that $z_x = z_y$ for all $z$ in the kernel of the selected functionals is mathematically equivalent to $x$ and $y$ being in the same connected component of the corresponding edge set, meaning the exact same minimum-weight subtree is required.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains exactly finding the minimum-cost subtree connecting a set of terminals in a weighted tree, which is uniquely solvable in O(N) time.
</PRESERVED_CLASS>
<RISK>
The model might misinterpret "kernel of $T_{red}$" if it lacks strong linear algebra grounding, but the definition is standard and unambiguous in mathematics.
</RISK>
