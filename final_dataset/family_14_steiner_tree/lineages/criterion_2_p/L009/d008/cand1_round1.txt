# Fluid Routing Optimization

Time limit: 2 s   Memory limit: 256 MB

## Description

You are managing a fluid distribution network consisting of **N** reservoirs, numbered 1 through **N**.

The network contains **E** bidirectional pipes. Each pipe connects reservoir **u** to reservoir **v** and contains a standing volume of **w** liters of fluid. The network is currently fully unified, meaning fluid can route between any two reservoirs. Furthermore, the system is strictly non-redundant: sealing even a single pipe would permanently divide the network into isolated zones.

A specific set of **F** reservoirs are designated as *injection sites*. To minimize maintenance overhead, you have been instructed to seal off a subset of the pipes. However, operational safety requires that fluid must still be able to flow freely between any pair of *injection sites* using the pipes that remain open (fluid may route through non-injection reservoirs if necessary).

Your goal is to seal pipes optimally to leave behind the smallest possible footprint. Determine the minimum possible total standing volume (the sum of **w**) of the pipes that **remain open** such that all injection sites stay mutually connected. (If **F** = 1, all pipes can be sealed, so the minimum remaining volume is 0.)

## Input

The first line contains three integers **N**, **E**, and **F** (1 ≤ F ≤ N, 1 ≤ N ≤ 200000, E = N − 1).
The second line contains **F** distinct integers: the labels of the injection sites.
Each of the following **E** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ N, u ≠ v, 1 ≤ w ≤ 1000000), representing a pipe between reservoir **u** and reservoir **v** with a standing volume of **w**.

## Output

Print a single integer: the minimum total standing volume of the pipes that remain open.
