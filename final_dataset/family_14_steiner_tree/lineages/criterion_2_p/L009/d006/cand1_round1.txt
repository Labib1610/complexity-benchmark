<METHOD_NAME>
Operational Routing Disguise
</METHOD_NAME>
<METHOD_DESCRIPTION>
Transforms a static subgraph selection problem (Steiner Tree) into an operational routing problem. By asking for the minimum cost of a walk that visits all targets from an arbitrary starting node, the model is baited into writing a complex DP to evaluate all possible starting locations, failing to realize that the optimal walk always traces the minimal subtree and any node within it is an optimal start.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<STATEMENT>
# Facility Inspection Route

Time limit: 2 s   Memory limit: 256 MB

## Description

A facility contains **N** rooms, labeled 1 through **N**.

There are **E** corridors available in the facility. Each corridor connects a specific pair of rooms, **u** and **v**, and requires a one-time cost of **w** to permanently illuminate.

The full set of corridors provides complete access: if all **E** corridors were illuminated, it would be possible to walk between any two rooms in the facility.

A specific subset of **F** rooms are designated as *critical*. You must plan an inspection route by choosing a single starting room (which can be any room in the facility). An inspector will begin at this starting room and must travel to each of the **F** critical rooms by walking along the corridors. The inspector may visit the critical rooms in any order, and may pass through any non-critical rooms along the way.

Any corridor that the inspector traverses (even just once) incurs its illumination cost of **w**. Because the illumination is permanent, traversing the same corridor multiple times during the inspection does not incur any additional cost.

Determine the minimum total illumination cost required to complete an inspection of all critical rooms. (If **F** = 1, the inspector can simply start in that critical room and traverse 0 corridors, so the minimum total cost is 0.)

## Input

The first line contains three integers **N**, **E**, and **F** (1 ≤ F ≤ N, 1 ≤ N ≤ 200000, E = N − 1).
The second line contains **F** distinct integers: the labels of the critical rooms.
Each of the following **E** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ N, u ≠ v, 1 ≤ w ≤ 1000000), representing a corridor between room **u** and room **v** with an illumination cost of **w**.

## Output

Print a single integer: the minimum total illumination cost required to complete the inspection.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**


**Output**
```

```

### Example 3

**Input**
```

1 2 3

```

**Output**
```
9
```
</STATEMENT>
<RATIONALE>
The problem was reframed from "selecting a subset of edges to connect targets" to "finding an optimal starting node and walk to visit targets". This masks the Steiner Tree objective, baiting models into attempting a complex DP to evaluate all N possible starting locations instead of realizing the minimum cost is always exactly the weight of the unique minimal subtree connecting the targets.
</RATIONALE>
<PRESERVED_ANSWER>
Because the set of traversed edges in any valid walk must form a connected subgraph containing the start node and all targets, the minimum cost is achieved by choosing a start node within the targets' minimal subtree and traversing exactly that subtree, yielding the identical Steiner Tree weight.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying mathematical objective is unchanged (computing the weight of the minimal subtree spanning the targets in a given tree), which remains solvable in O(N) by rooting the tree and summing edges with targets in both resulting components.
</PRESERVED_CLASS>
