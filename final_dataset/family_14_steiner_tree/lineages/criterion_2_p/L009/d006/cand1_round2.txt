<STATEMENT>
# Subterranean Ventilation System

Time limit: 2 s   Memory limit: 256 MB

## Description

A subterranean facility contains **N** chambers, numbered 1 through **N**.

There are **E** potential ventilation shafts available. Each shaft connects a specific pair of chambers, **u** and **v**, and requires a clearing effort of **w** to become operational. 

The layout of the potential shafts forms a minimal complete framework: **E** = **N** − 1, and if all shafts were operational, they would provide exactly one continuous non-looping route between any two chambers in the facility.

A specific subset of **F** chambers are designated as *vital*. You must select a subset of shafts to clear such that all vital chambers are integrated into a single connected network. This means air must be able to circulate between any two vital chambers using exclusively the cleared shafts. Shafts connecting non-vital chambers may be cleared if they are necessary to bridge the vital ones.

Each cleared shaft contributes its effort value exactly once to your total. Determine the minimum total clearing effort required to integrate all vital chambers. (If **F** = 1, the single vital chamber is already trivially integrated, requiring 0 shafts to be cleared, for a total effort of 0.)

## Input

The first line contains three integers **N**, **E**, and **F** (1 ≤ F ≤ N, 1 ≤ N ≤ 200000, E = N − 1).
The second line contains **F** distinct integers: the labels of the vital chambers.
Each of the following **E** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ N, u ≠ v, 1 ≤ w ≤ 1000000), representing a potential shaft between chamber **u** and chamber **v** with a clearing effort of **w**.

## Output

Print a single integer: the minimum total clearing effort required to ensure all vital chambers are connected to each other through cleared shafts.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Output**
```

```

### Example 3

**Input**
```
3 2 3
1 2 3

2 3 5
```

**Output**
```
9
```

The problem asks for the minimum weight set of edges that connects a specific subset of vertices in a tree, which is exactly the same unique minimal spanning subtree objective as the seed.
</PRESERVED_ANSWER>
