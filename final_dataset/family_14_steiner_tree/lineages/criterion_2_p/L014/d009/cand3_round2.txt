<STATEMENT>
# Enterprise Integration

Time limit: 2 s   Memory limit: 256 MB

## Description

In a regulated economic zone, there are $n$ independent enterprises (identified by integers 1 through $n$) and a collection of $m$ potential bilateral partnership contracts. Each contract bridges two specific enterprises and carries a precise licensing cost to execute.

Among these enterprises, a specific subset of $t$ entities are designated as primary stakeholders.

The governing trade commission has verified that the proposed contracts form a completely unified network. This means that any two enterprises in the zone can be connected via some chain of these potential contracts (where adjacent contracts in the chain share an enterprise). 

A potential contract is deemed *essential* if there exists at least one pair of distinct primary stakeholders such that every valid chain of contracts connecting them must include this specific contract. 

Your objective is to authorize a subset of the potential contracts. A subset is considered compliant if and only if it contains every *essential* contract. The authorized subset does not need to keep the network unified; its only requirement is to include all essential contracts.

Determine the minimum possible sum of licensing costs for a compliant subset of authorized contracts.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$).
The second line contains $t$ distinct integers: the identifiers of the primary stakeholders.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a potential contract between enterprise $u$ and enterprise $v$ with a licensing cost of $w$.

## Output

Print a single integer: the minimum total licensing cost of a compliant subset of authorized contracts.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the primary stakeholders are 1 and 4. 
The only valid chain of contracts connecting enterprise 1 to enterprise 4 uses the contracts between 1 and 2, 2 and 3, and 3 and 4. Because every chain connecting these two stakeholders must include these three contracts, all three are deemed essential. To form a compliant subset, all three must be included. The minimum total licensing cost is 5 + 1 + 2 = 8. 

In Example 2, there is only one primary stakeholder (enterprise 3). Because there is no pair of distinct primary stakeholders, no contract can meet the condition of being essential. The requirement is vacuously satisfied by choosing an empty subset, resulting in a minimum total licensing cost of 0.

In Example 3, the primary stakeholders are 1, 2, and 3.
Any chain connecting stakeholder 1 to stakeholder 2 must include the contract between 1 and 2, making it essential. 
Similarly, any chain connecting stakeholder 2 to stakeholder 3 must include the contract between 2 and 3, making it essential.
Both contracts are essential and must be included in any compliant subset. The minimum total licensing cost is 4 + 5 = 9.
</STATEMENT>
<RATIONALE>
I removed the explicit guarantee that the graph is a tree ($m = n - 1$) and redefined critical edges in terms of path intersections ("every valid chain connecting a pair of stakeholders must include it") rather than graph cuts. This mathematically equivalent definition pushes models toward a naive $O(T^2)$ pair-checking algorithm which will TLE, forcing them to deduce the bridge/graph-cut equivalence themselves to achieve the required $O(N)$ complexity.
</RATIONALE>
<PRESERVED_ANSWER>
The answer is unchanged because an edge is on all paths between a pair of stakeholders if and only if its removal separates those stakeholders into different connected components, making the set of essential contracts identical to the set of critical agreements in the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class remains P because finding bridges and checking if they separate specific vertices can be done in linear time using Tarjan's bridge-finding algorithm and a single DFS.
</PRESERVED_CLASS>
<RISK>
The phrase "every valid chain" could be misinterpreted as applying only to simple paths, but since any non-simple path contains a simple path, an edge is on all simple paths if and only if it is on all paths, so this distinction does not create ambiguity.
</RISK>
