**Solution Explanation**

For the given tree we have to choose a set of edges that contains the whole
path between every two *special* vertices.
The cheapest possible set is exactly the union of all those paths,
i.e. the **minimal subtree that connects all special vertices**.
An edge belongs to this subtree **iff** after removing it both
connected components still contain at least one special vertex.

So we only have to sum the weights of the edges that separate the specials
into two non‑empty groups.



--------------------------------------------------------------------

#### Algorithm
```
read n , m (= n‑1) , t
read the t special vertices
build adjacency list of the tree (weight on each edge)

if t ≤ 1 : answer = 0                     # no pair of specials → nothing needed

root the tree at vertex 1 (any vertex works)
DFS (iterative) → arrays
    parent[v]          – parent of v in the rooted tree (0 for the root)
    weight_to_parent[v]– weight of edge (parent[v] , v)
    order[]            – vertices in the order they are visited (preorder)

cnt[v] = 1 if v is special else 0          # number of specials in the subtree of v
process vertices in reverse order (postorder):
        if parent[v] != 0:
                cnt[parent[v]] += cnt[v]

answer = Σ weight_to_parent[v] over all v ≠ root
          where cnt[v] > 0  and  t - cnt[v] > 0
print answer
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs the minimum possible total fee.

---

##### Lemma 1  
For an edge `e = (parent, child)` let `S_child` be the set of special vertices
inside the subtree of `child`.  
`e` is contained in the union of all paths between pairs of special vertices  
iff `S_child` is non‑empty **and** its complement among the specials is non‑empty.

**Proof.**  
*If* `S_child` and its complement are both non‑empty, pick a special vertex
`a` in `S_child` and a special vertex `b` outside.
The unique tree path `a–b` must cross `e`, therefore `e` belongs to the union.

*Only‑if* `e` belongs to the union, there exists a pair of specials whose
path uses `e`. One of them lies in the child’s subtree, the other does not,
hence both sets are non‑empty. ∎



##### Lemma 2  
After the postorder processing `cnt[v]` equals the number of special vertices
in the subtree rooted at `v`.

**Proof.**  
Initially `cnt[v]` is `1` for a special vertex, `0` otherwise – correct for a
subtree consisting of the single vertex.
Processing vertices from leaves upwards adds the already correct counts of
all children to the parent, therefore after the parent is processed its count
is the sum over its whole subtree. By induction on the height of the subtree,
the invariant holds for every vertex. ∎



##### Lemma 3  
The algorithm adds exactly the weights of the edges that satisfy the condition
of Lemma&nbsp;1.

**Proof.**  
For a non‑root vertex `v` the edge to its parent is examined.
By Lemma&nbsp;2 `cnt[v]` is the number of specials in the child side,
so `cnt[v] > 0` means the child side is non‑empty,
and `t - cnt[v] > 0` means the other side is non‑empty.
Thus the algorithm adds the edge weight precisely when the condition of
Lemma&nbsp;1 holds. ∎



##### Lemma 4  
The set of edges selected by the algorithm is exactly the minimal subtree
connecting all special vertices.

**Proof.**  
By Lemma&nbsp;3 the algorithm selects all edges that separate the specials into
two non‑empty groups, and no other edges.
Removing any selected edge would disconnect the specials, therefore every
selected edge is necessary.
Conversely, any edge that is necessary for connecting the specials must
separate them into two non‑empty groups, hence it is selected.
Thus the selected edges are precisely the necessary ones – the minimal
connecting subtree. ∎



##### Theorem  
The algorithm outputs the minimum possible total legal fee of a valid subset
of agreements.

**Proof.**  
A valid subset must contain every edge of the minimal connecting subtree
(Lemma&nbsp;4), otherwise some pair of specials would have a missing edge on
their unique path.  
The algorithm’s subset is exactly this subtree, therefore its total weight
is a lower bound for any valid subset.
Since the algorithm’s subset itself is valid, its total weight is also an
upper bound. Hence it is the minimum. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building the adjacency list*: `O(n)`  
*Iterative DFS* (building `order`, `parent`, `weight_to_parent`): `O(n)`  
*Postorder accumulation of `cnt`*: `O(n)`  
*Final summation*: `O(n)`

Memory consumption: adjacency list `2·(n‑1)` edges, plus several `O(n)` arrays –
`O(n)` total.

Both limits satisfy `n ≤ 200 000` easily.

--------------------------------------------------------------------

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    n = int(next(it))
    m = int(next(it))          # = n-1, not used separately
    t = int(next(it))

    specials = [int(next(it)) for _ in range(t)]

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        w = int(next(it))
        adj[u].append((v, w))
        adj[v].append((u, w))

    if t <= 1:
        print(0)
        return

    is_special = [0] * (n + 1)
    for s in specials:
        is_special[s] = 1

    parent = [0] * (n + 1)          # 0 means no parent (root)
    w_to_parent = [0] * (n + 1)     # weight of edge to parent
    order = []                      # preorder

    stack = [1]
    parent[1] = -1                  # mark root
    while stack:
        v = stack.pop()
        order.append(v)
        for to, w in adj[v]:
            if to == parent[v]:
                continue
            parent[to] = v
            w_to_parent[to] = w
            stack.append(to)

    cnt = is_special[:]             # subtree special counts
    for v in reversed(order):
        p = parent[v]
        if p > 0:                   # not the root
            cnt[p] += cnt[v]

    total = 0
    for v in range(2, n + 1):       # all non‑root vertices
        if cnt[v] > 0 and t - cnt[v] > 0:
            total += w_to_parent[v]

    print(total)


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
