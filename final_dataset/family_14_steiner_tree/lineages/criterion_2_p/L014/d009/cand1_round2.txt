<METHOD_DESCRIPTION>
Instead of defining "critical" edges via graph-cuts and asking to select them, the problem asks to partition the edges into "finalized" and "rejected". The validity condition is placed on the *rejected* edges: each must independently leave all key patent holders mutually linked if removed from the original set. To minimize the finalized cost, the solver must deduce that they should reject every eligible edge, meaning the finalized set is exactly those edges that DO separate the key patent holders. This inversion forces deductive reasoning and breaks pattern-matching on the seed's direct graph-cut definition, while strictly preserving the tree structure to satisfy the gate.
</METHOD_DESCRIPTION>

<STATEMENT>
# Corporate Consolidation

Time limit: 2 s   Memory limit: 256 MB

## Description

In a regulated market, there are $n$ independent corporations (numbered 1 through $n$) and a set of $m$ proposed bilateral merger agreements. Each agreement involves two specific corporations and requires a defined legal fee to finalize.

Within this market, a particular group of $t$ corporations are identified as key patent holders.

The antitrust regulatory board has issued a certificate that enforces strict structural limits on the proposed agreements. The certificate guarantees that the market is minimally fully integrated: the proposed agreements connect all $n$ corporations, there are exactly $m = n - 1$ proposed agreements, and between any two corporations, there is exactly one unique sequence of agreements linking them.

Your goal is to partition the $m$ proposed agreements into two sets: a set of *finalized* agreements and a set of *rejected* agreements. 

A partition is considered valid if every rejected agreement independently satisfies the following redundancy condition: if you were to remove that single rejected agreement from the original set of $m$ proposed agreements, all $t$ key patent holders would still be mutually linked (i.e., any key patent holder could still reach any other key patent holder using some sequence of the remaining $m - 1$ agreements). 

You must find the minimum possible total legal fee of the finalized agreements in a valid partition.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$).
The second line contains $t$ distinct integers: the identifiers of the key patent holders.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a proposed agreement between corporation $u$ and corporation $v$ with a legal fee of $w$.

## Output

Print a single integer: the minimum total legal fee of the finalized agreements in a valid partition.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the key patent holders are 1 and 4. 
Consider the agreement between 1 and 2. If it were removed from the original set, corporation 1 would have no remaining agreements, meaning it could no longer reach corporation 4. Thus, this agreement does not satisfy the redundancy condition and cannot be rejected; it must be finalized.
Similarly, removing the agreement between 2 and 3, or the agreement between 3 and 4, would also leave key patent holders 1 and 4 unable to reach each other. None of the three agreements can be rejected. The finalized set must include all three, yielding a minimum total legal fee of 5 + 1 + 2 = 8. 

In Example 2, there is only one key patent holder (corporation 3). For any agreement you choose to remove from the original set, the single key patent holder trivially remains linked to itself. Therefore, every agreement satisfies the redundancy condition and can be placed in the rejected set. The finalized set can be empty, resulting in a minimum total legal fee of 0.

In Example 3, the key patent holders are 1, 2, and 3.
If the agreement between 1 and 2 were removed, corporation 1 could no longer reach corporations 2 and 3. This agreement cannot be rejected.
If the agreement between 2 and 3 were removed, corporation 3 could no longer reach corporations 1 and 2. This agreement also cannot be rejected.
Both agreements must be finalized. The minimum total legal fee is 4 + 5 = 9.
</STATEMENT>
<RATIONALE>
The problem was reframed around partitioning edges into a finalized set and a rejected set, rather than directly selecting "critical" edges. The validity condition is placed on the rejected edges (they must not separate the key patent holders if individually removed). To minimize the finalized cost, solvers must deduce that they should reject all eligible edges, meaning the finalized edges are exactly those that DO separate the key patent holders (the Steiner tree). This inversion forces deductive logic and breaks pattern-matching on the seed's direct graph-cut definition.
</RATIONALE>
<PRESERVED_ANSWER>
The condition allows an edge to be rejected if and only if it does not lie on a path between any two key patent holders; to minimize finalized cost, all such edges are rejected, leaving exactly the Steiner tree edges to be finalized, yielding the identical sum of weights.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires identifying edges that lie on paths between key patent holders in a tree, which can be solved in O(N) time via a simple DFS to compute subtree key counts.
</PRESERVED_CLASS>
