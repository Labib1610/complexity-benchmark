<METHOD_DESCRIPTION>Rephrases the requirement "all key nodes must be in the same connected component" as a universal condition over all possible binary state assignments to the nodes: any assignment that splits the key nodes into both states must have a selected edge crossing the states. This mathematically forces connectivity while looking like a 2-SAT or Boolean optimization problem, completely hiding the tree-pruning nature of the task from pattern-matching models.</METHOD_DESCRIPTION>

<STATEMENT>
# Corporate Consolidation

Time limit: 2 s   Memory limit: 256 MB

## Description

In a regulated market, there are $n$ independent corporations (numbered 1 through $n$) and a set of $m$ proposed bilateral merger agreements. Each agreement involves two distinct corporations and requires a defined legal fee to finalize.

The full set of proposed agreements forms a minimally integrated structure: there are exactly $m = n - 1$ proposed agreements, and any two corporations are linked by exactly one simple route (a sequence of agreements without repeating any corporation) in this full set. This guarantees there are no parallel agreements between the same pair of corporations.

Within this market, a particular group of $t$ corporations are identified as key patent holders.

Your goal is to choose a subset of the proposed agreements to finalize. A chosen subset is considered valid if it satisfies the following regulatory condition:
For every possible assignment of a status code (either 0 or 1) to each of the $n$ corporations, if the assignment gives a status of 0 to at least one key patent holder and a status of 1 to at least one key patent holder, then the chosen subset must contain at least one finalized agreement that links a corporation with status 0 to a corporation with status 1.

You must find the minimum total legal fee of a valid subset of finalized agreements.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$).
The second line contains $t$ distinct integers: the identifiers of the key patent holders.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a proposed agreement between corporation $u$ and corporation $v$ with a legal fee of $w$.

## Output

Print a single integer: the minimum total legal fee of a valid subset of finalized agreements.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the key patent holders are 1 and 4. If the finalized subset only included the agreements (1, 2) and (3, 4), an assignment of status 0 to corporations 1 and 2, and status 1 to corporations 3 and 4 would give status 0 to key holder 1 and status 1 to key holder 4. However, the subset would not contain any agreement linking a status 0 corporation to a status 1 corporation. To make the subset valid for all possible assignments, the agreement (2, 3) must also be included. The minimum total legal fee is 5 + 1 + 2 = 8.

In Example 2, there is only $t=1$ key patent holder (corporation 3). It is impossible for any assignment to give a status of 0 to at least one key patent holder and a status of 1 to at least one key patent holder. The "if" condition is never met, so the regulatory condition is vacuously satisfied without including any agreements. The minimum total legal fee is 0.

In Example 3, the key patent holders are 1, 2, and 3. To satisfy the condition for all assignments, the finalized subset must include both agreements. For instance, if the subset omitted (1, 2), assigning status 0 to corporation 1 and status 1 to corporations 2 and 3 would violate the condition. The minimum total legal fee is 4 + 5 = 9.
</STATEMENT>
<RATIONALE>
The problem of finding a minimal subtree spanning key nodes is reframed using a universal condition over Boolean state assignments. By defining validity as "any 0/1 assignment that splits the key nodes must have a finalized edge crossing the 0/1 boundary," the problem mathematically enforces connectivity without ever using path, tree, or component terminology. This forces the model to logically deduce that the condition is equivalent to connectivity on a tree, defeating algorithms that rely on surface-level pattern matching to trigger tree-pruning templates.
</RATIONALE>
<PRESERVED_ANSWER>
The Boolean assignment condition is mathematically identical to requiring that all key patent holders belong to the same connected component of the chosen subset; since the base graph is a tree with positive weights, the minimum cost subset is still exactly the unique union of paths between the key nodes.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure (a tree) and the objective (finding the minimum weight spanning subgraph for a subset of vertices) are unchanged, so it remains solvable in O(n) time via a single post-order traversal.
</PRESERVED_CLASS>
