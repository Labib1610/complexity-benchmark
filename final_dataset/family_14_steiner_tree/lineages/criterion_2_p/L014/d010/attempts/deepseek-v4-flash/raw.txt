We need to determine which edges are contested, then find the minimum total fee of a valid subset.  

A valid subset must include all contested edges. Since the graph is a tree, if we must include certain edges, the rest can be chosen freely (or not at all) to minimize cost.  

The key observation:  
- An edge is contested if there is at least one key patent holder on each side of the edge.  
- If all key patent holders are on one side, the edge is not contested.  

So we can:  
1. Root the tree at any node (say 1).  
2. Count how many key patent holders are in each subtree.  
3. For each edge (parent–child), if the number of key holders in the child’s subtree is between 1 and t-1, then the edge is contested.  
4. Sum the weights of all contested edges.  

This works because in a tree, removing an edge splits the tree into two components; if both components contain at least one key holder, the edge is contested.  

Let’s implement it.  

```python
import sys
sys.setrecursionlimit(300000)

def main():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    keys = set(map(int, input().split()))
    
    adj = [[] for _ in range(n+1)]
    edges = []
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
        edges.append((u, v, w))
    
    parent = [0]*(n+1)
    parent_w = [0]*(n+1)
    order = [1]
    parent[1] = -1
    for node in order:
        for nei, w in adj[node]:
            if nei == parent[node]:
                continue
            parent[nei] = node
            parent_w[nei] = w
            order.append(nei)
    
    sub_count = [0]*(n+1)
    for node in reversed(order):
        if node in keys:
            sub_count[node] += 1
        if parent[node] > 0:
            sub_count[parent[node]] += sub_count[node]
    
    total = 0
    for node in range(2, n+1):
        cnt = sub_count[node]
        if 0 < cnt < t:
            total += parent_w[node]
    
    print(total)

if __name__ == "__main__":
    main()
```
