We are given a tree (since \( m = n-1 \) and the graph is connected with exactly one path between any two nodes).  
We need to include all edges that lie on the path between any two key nodes.  

That means:  
- If there are 0 or 1 key nodes, the answer is 0.  
- Otherwise, we need to include the minimal subtree that connects all key nodes.  
- The cost is the sum of edge weights in that minimal subtree.  

We can solve this by:  
1. Mark key nodes.  
2. Do a DFS from any key node to find the farthest key node (call it A).  
3. Do a DFS from A to find the farthest key node (call it B) and also compute the total distance between A and B.  
4. The minimal subtree connecting all key nodes is the union of all paths from each key node to the path between A and B.  
   But a simpler way:  
   - The minimal subtree is the union of all edges that lie on paths between any two key nodes.  
   - This is equivalent to: take all edges that are on the path between any two key nodes.  
   - We can compute this by doing a DFS from any key node, and for each edge, if both sides contain at least one key node, then that edge must be included.  

We can do a DFS from any node, compute subtree key counts, and sum weights of edges where both sides have at least one key node.  

Complexity: \( O(n) \).  

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    keys = set(map(int, input().split()))
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    if t <= 1:
        print(0)
        return
    
    # DFS to count key nodes in subtree and sum weights of necessary edges
    visited = [False] * (n+1)
    total_cost = 0
    
    def dfs(u, parent):
        nonlocal total_cost
        visited[u] = True
        cnt = 1 if u in keys else 0
        for v, w in adj[u]:
            if v == parent:
                continue
            child_cnt = dfs(v, u)
            if child_cnt > 0 and (t - child_cnt) > 0:
                total_cost += w
            cnt += child_cnt
        return cnt
    
    # Start from any node, e.g., 1
    dfs(1, -1)
    print(total_cost)

if __name__ == "__main__":
    solve()
```
