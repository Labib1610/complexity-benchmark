**Solution Explanation**

The `m = n‑1` edges together with the guarantee *“all corporations can be merged into one”* mean that the given graph is a **tree**.
In a tree there is exactly one simple path between any two vertices.

For a set `S` of *special* vertices (the patent holders) the cheapest way to make them belong to the same component is to take the
**minimal subtree** that contains all vertices of `S`.  
All edges of this subtree have to be paid, all other edges can be omitted.

For an edge `e = (u , v)` (let `v` be the child of `u` in a rooted view)

```
e is necessary  ⇔  the subtree of v contains at least one special vertex
                    and also at least one special vertex lies outside this subtree
```

If the condition holds, the two sides of the edge would be separated otherwise,
so the edge must be taken.  
The answer is the sum of the weights of all necessary edges.

Thus we only have to know, for every vertex, how many special vertices are
inside its subtree.

--------------------------------------------------------------------

#### Algorithm
```
read n, m, t
read list of t special vertices
build adjacency list of the tree, each entry stores (neighbor, weight)

if t == 1:
        print 0 and exit

root the tree at vertex 1
stack = [(1, 0, -1)]               # (node, parent, edge_weight_to_parent)
order = []                         # visitation order
parent = [0]*(n+1)
edge_to_parent = [0]*(n+1)

while stack not empty:
        v, p, w = stack.pop()
        parent[v] = p
        edge_to_parent[v] = w
        order.append(v)
        for (to, wt) in adj[v]:
                if to == p: continue
                stack.append((to, v, wt))

# now process vertices bottom‑up
sub_special = [0]*(n+1)            # number of specials in the subtree of v
for v in reversed(order):
        cnt = 1 if v is special else 0
        for (to, _) in adj[v]:
                if to == parent[v]: continue
                cnt += sub_special[to]
        sub_special[v] = cnt

        # if v is not the root, decide whether the edge to its parent is needed
        if parent[v] != 0:
                if 0 < cnt < t:                # specials on both sides
                        answer += edge_to_parent[v]

print answer
```

#### Correctness Proof  

We prove that the algorithm outputs the minimum possible total fee.

---

**Lemma 1**  
For any edge `e = (parent, child)` let `C` be the set of vertices in the
child’s subtree.  
`e` belongs to the minimal subtree connecting all special vertices **iff**
`C` contains at least one special vertex and the complement `V \ C` also
contains at least one special vertex.

*Proof.*  
If both sides contain a special vertex, any connected subgraph that contains
all specials must contain a path between those two vertices, and that path
must cross `e`. Hence `e` is necessary.  
Conversely, if all specials lie on the same side of `e`, we can connect them
without using `e` (just stay inside that side), therefore `e` is not needed. ∎



**Lemma 2**  
After the bottom‑up processing `sub_special[v]` equals the number of special
vertices inside the subtree rooted at `v`.

*Proof.*  
Induction on the reversed order (post‑order).  
For a leaf the formula gives `1` if the leaf itself is special, else `0`,
which is correct.  
Assume it holds for all children of `v`. The algorithm adds the children's
counts plus the possible `1` for `v` itself, exactly the definition of the
subtree count. ∎



**Lemma 3**  
The algorithm adds the weight of an edge `e` to the answer **iff** `e` satisfies
the condition of Lemma&nbsp;1.

*Proof.*  
When processing the child endpoint `c` of `e`, `cnt = sub_special[c]` is the
number of specials in its subtree (Lemma&nbsp;2).  
The algorithm adds `w(e)` precisely when `0 < cnt < t`.  
`cnt > 0` means at least one special is inside the subtree, `cnt < t` means
at least one special is outside, i.e. the condition of Lemma&nbsp;1. ∎



**Lemma 4**  
The sum produced by the algorithm equals the total weight of the minimal
subtree that spans all special vertices.

*Proof.*  
By Lemma&nbsp;3 the algorithm sums exactly the weights of all edges satisfying
Lemma&nbsp;1, i.e. exactly the edges that belong to the minimal spanning
subtree (by Lemma&nbsp;1). ∎



**Theorem**  
The algorithm outputs the minimum possible total legal fee required to make
all patent‑holding corporations belong to the same conglomerate.

*Proof.*  
Any set of agreements that connects all specials must contain the minimal
subtree (otherwise some specials would stay disconnected). Hence its total
cost is at least the weight of that subtree.  
Conversely, executing exactly the agreements of that subtree achieves the
goal with cost equal to its weight.  
By Lemma&nbsp;4 the algorithm outputs precisely this weight, therefore it is
optimal. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(n)` edges.  
*DFS to obtain order*: `O(n)`.  
*Bottom‑up counting*: each edge examined once → `O(n)`.  

Memory: adjacency list (`2*(n-1)` entries) + a few `O(n)` arrays → `O(n)`.

Both limits satisfy `n ≤ 200 000`.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))

    specials = [False] * (n + 1)
    for _ in range(t):
        specials[int(next(it))] = True

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it)); w = int(next(it))
        adj[u].append((v, w))
        adj[v].append((u, w))

    if t <= 1:
        print(0)
        return

    parent = [0] * (n + 1)
    edge_w = [0] * (n + 1)
    order = []

    stack = [(1, 0, 0)]          # node, parent, weight to parent
    while stack:
        v, p, w = stack.pop()
        parent[v] = p
        edge_w[v] = w
        order.append(v)
        for to, wt in adj[v]:
            if to == p:
                continue
            stack.append((to, v, wt))

    sub_special = [0] * (n + 1)
    ans = 0
    for v in reversed(order):
        cnt = 1 if specials[v] else 0
        for to, _ in adj[v]:
            if to == parent[v]:
                continue
            cnt += sub_special[to]
        sub_special[v] = cnt
        if parent[v] != 0 and 0 < cnt < t:
            ans += edge_w[v]

    print(ans)


if __name__ == "__main__":
    solve()
```
