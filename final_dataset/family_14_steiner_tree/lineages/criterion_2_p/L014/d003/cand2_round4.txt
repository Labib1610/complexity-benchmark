# Connecting the Critical Facilities

Time limit: 2 s   Memory limit: 256 MB

## Description

A large industrial complex consists of facilities, numbered 1 to $n$. A specific subset of $t$ facilities are designated as critical operations centers. There are $m$ potential communication links that can be constructed between certain pairs of facilities, each requiring a specific construction cost.

Your objective is to select a subset of these links to build so that all $t$ critical facilities can communicate with one another, either directly or by routing through other intermediate facilities. You must achieve this requirement at the minimum possible total construction cost.

The $m$ potential links provided in the blueprint form a network such that, if all were constructed, there would exist exactly one valid route (a sequence of links that does not visit any facility more than once) between any two facilities in the complex.

## Input

The first line contains three integers $n$, $m$, and $t$. The site zoning limits the total facility count $n$ to a maximum of 200,000, with at least one facility present. The critical facility count $t$ ranges from a single facility up to the total number of facilities $n$.

The second line contains $t$ distinct integers: the identifiers of the critical facilities.

Each of the next $m$ lines contains three integers $u$, $v$, and $w$. The facility identifiers $u$ and $v$ are strictly distinct, taking values from 1 up to $n$. The construction cost $w$ is a positive integer bounded by a maximum per-link budget of 1,000,000.

## Output

Print a single integer: the minimum total cost to ensure all critical facilities are interconnected.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the critical facilities 1 and 4 are integrated by building the links that join 1 to 2, 2 to 3, and 3 to 4, for a total cost of 5 + 1 + 2 = 8. In Example 2, there is only one critical facility, so no links need to be constructed.
