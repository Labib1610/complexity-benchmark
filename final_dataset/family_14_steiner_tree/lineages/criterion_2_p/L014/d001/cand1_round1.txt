# Cabling the Required Sites

Time limit: 2 s   Memory limit: 256 MB

## Description

A campus consists of **n** sites (numbered 1 to **n**). Certain pairs of sites can be joined by a cabling option at a given cost. Among the sites, a specific subset of **t** sites is designated as **required**. Your task is to select a subset of the available cabling options such that all **t** required sites end up connected to one another, either directly or through intermediate relay sites.

Out of all possible combinations of the **m** cabling options, you must install a set of minimum total cost that achieves this connectivity for the required sites. The provided options are inherently sufficient to connect all **n** sites together.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers: the identifiers of the required sites.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), representing a cabling option joining site **u** and site **v** at cost **w**. The options follow the connectivity guarantees described above.

## Output

Print a single integer: the minimum total cost to connect all required sites.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the required sites 1 and 4 are connected by selecting the options that join 1 to 2, 2 to 3, and 3 to 4, for a total cost of 5 + 1 + 2 = 8. In Example 2, there is only one required site, so no cabling needs to be installed.

<RATIONALE>
I removed the explicit statement "between any two sites there is exactly one possible cabling route," which directly handed the models the unique-path property of trees. The models must now deduce this structural property themselves from the combination of "sufficient to connect all n sites" and the input constraint "m = n - 1".
</RATIONALE>
<PRESERVED_ANSWER>
The graph remains identical, and the objective of finding the minimum cost to connect the required sites is unchanged, so the optimal cost is the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains finding the minimum Steiner tree on a tree, which is solvable in O(n) time.
</PRESERVED_CLASS>
