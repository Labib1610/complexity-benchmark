# Minimum Infrastructure Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

A facility consists of **n** locations (numbered 1 to n). Certain pairs of locations can be connected by a segment at a specific installation cost. Out of all locations, a specific subset of **t** locations are designated as **critical**. Your task is to activate a subset of the available segments such that all critical locations end up connected to one another. Connections can be direct or pass through intermediate non-critical locations, which act as relays.

The available segments connect all **n** locations together. There are exactly **n − 1** segments available, and between any two locations, there is exactly one sequence of segments that connects them.

You must determine the minimum possible total installation cost of the segments you choose to activate so that every critical location is in the same connected network.

## Input

The first line provides three integers: **n**, **m**, and **t**. The facility's architectural limit allows a maximum of 200,000 locations, so **n** is a positive integer up to this limit. The number of critical locations **t** is at least a single location and at most **n**, and **m** is exactly **n − 1**.
The second line contains **t** distinct integers representing the IDs of the critical locations.
Each of the following **m** lines provides three integers **u**, **v**, and **w**. These indicate a segment connecting distinct locations **u** and **v** (both valid IDs between 1 and **n**) with an installation cost **w**. The cost **w** is a positive integer capped at exactly 1,000,000. All segments follow the structural rules described above.

## Output

Print a single integer: the minimum total cost of segments that must be activated to connect all critical locations.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the critical locations 1 and 4 can only be joined through intermediate locations 2 and 3. Thus, all three segments (5 + 1 + 2 = 8) must be activated.
In Example 2, there is only one critical location, so no segments need to be activated.
