<STATEMENT>
# Set Unification Operations

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of **n** initially isolated variables, indexed from 1 to **n**. A specific subset of **t** variables are designated as critical.

You are given a list of **m** available unification operations. Each operation can forcefully unify the set containing variable **u** with the set containing variable **v**, and requires an energy expenditure of **w**.

The available operations are strictly structured: the total number of operations **m** is exactly **n** - 1, and applying all of them would merge all variables into a single set without any redundant operations. Consequently, there is exactly one valid sequence of operations to transitively unify any two variables.

Your task is to choose a subset of these operations to execute such that all **t** critical variables end up unified in the same set. You must find the minimum total energy expenditure of the executed operations required to achieve this.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ **n** ≤ 200000, **m** = **n** - 1, 1 ≤ **t** ≤ **n**).

The second line contains **t** distinct integers: the indices of the critical variables.

The following **m** lines each contain three integers **u**, **v**, and **w**. These specify an available unification operation between variable **u** and variable **v** (where 1 ≤ **u**, **v** ≤ **n** and **u** ≠ **v**) having an energy expenditure of **w** (1 ≤ **w** ≤ 1000000).

## Output

Print a single integer representing the minimum total energy expenditure of the executed operations required to unify all critical variables.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the critical variables 1 and 4 can only be unified by executing all three operations (since the only sequence of unifications between them is through variables 2 and 3). Thus, the minimum energy is 5 + 1 + 2 = 8. In Example 2, there is only one critical variable, which is already in its own set, so no operations need to be executed.
</STATEMENT>
<RATIONALE>
I completely replaced the original "network routing" framing with a "set unification" framing. This semantic shift pushes models away from tree-traversal algorithms and strongly encourages them to apply greedy Union-Find algorithms (like Kruskal's). Because greedy algorithms minimize the spanning forest cost rather than the Steiner tree cost, they will incorrectly select cheap operations that do not lie on the unique paths between the critical variables, forcing the models to fail the hidden tests.
</RATIONALE>
<PRESERVED_ANSWER>
The required subset of operations to unify the critical variables corresponds exactly to the edges of the minimal spanning subtree containing those variables, resulting in the exact same minimum cost.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains solvable in O(n) time using the exact same leaf-pruning or post-order DFS traversal on the tree of operations.
</PRESERVED_CLASS>
