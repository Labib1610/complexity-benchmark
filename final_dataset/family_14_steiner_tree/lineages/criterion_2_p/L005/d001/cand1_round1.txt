<STATEMENT>
# Priority Site Connectivity

Time limit: 2 s   Memory limit: 256 MB

## Description

A campus has **n** facilities (numbered 1..n). You are evaluating a proposed infrastructure blueprint containing exactly **n − 1** potential bidirectional communication channels. Each channel connects two facilities and has an installation cost. The proposal guarantees that installing every channel would integrate all **n** facilities into a single contiguous network where any facility can reach any other.

Due to budget constraints, you will not install all channels. Instead, you must install a subset of them such that a specific group of **t** priority facilities are fully integrated—meaning any priority facility can exchange data with any other priority facility, possibly routing through non-priority facilities.

Determine the minimum total installation cost required to achieve this.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers: the ids of the priority facilities.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): a potential channel between facility u and facility v with installation cost w. The channels follow the blueprint properties described above.

## Output

Print a single integer: the minimum total installation cost to fully integrate all priority facilities.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, priority facilities 1 and 4 can only exchange data if the sequence of channels through facilities 2 and 3 is installed, requiring all three channels (5+1+2 = 8). In Example 2, there is only one priority facility, so zero channels need to be installed.
</STATEMENT>
<RATIONALE>
The previous version explicitly stated that "between any two sites there is exactly one possible route", handing the model the unique-path property on a silver platter. I removed this explicit hint and instead provided the mathematical equivalent: there are exactly $n-1$ connections that form a fully contiguous network. This forces models to independently deduce that the graph is a tree and therefore paths between priority nodes are unique.
</RATIONALE>
<PRESERVED_ANSWER>
The subset of edges required to connect the priority nodes is identical because the underlying graph and costs are unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class remains P (specifically $O(n)$) because any connected graph with $n$ vertices and $n-1$ edges is a tree, allowing the minimal spanning subtree to be found via simple traversal or leaf-pruning.
</PRESERVED_CLASS>
