<STATEMENT>
# Critical Facility Integration

Time limit: 2 s   Memory limit: 256 MB

## Description

A campus infrastructure consists of **n** facilities (numbered 1 to **n**). Certain pairs of facilities can be integrated by establishing a connection at a given cost. Among these, **t** facilities are flagged as **critical**. Your objective is to ensure all critical facilities can communicate with each other, either directly or by passing messages through intermediate connected facilities. 

To prevent redundant loops, the available connection options were designed minimally: the infrastructure is fully integrated so that a message can pass between any pair of facilities, but the total number of connection options is exactly one less than the number of facilities.

You must choose a subset of these connection options to establish, such that all critical facilities are integrated. Find the minimum total cost required to achieve this.

## Input

The first line contains three integers **n**, **m**, and **t**. The campus infrastructure can accommodate a maximum capacity of 200,000 facilities. The total number of connection options **m** is always exactly one less than the number of facilities **n**. The number of critical facilities **t** ranges from a minimum of a single facility up to the entire capacity of **n**.

The second line contains **t** distinct integers: the identifiers of the critical facilities.

Each of the next **m** lines provides three integers **u**, **v**, and **w**, representing a connection option between two distinct facilities **u** and **v** at cost **w**. The installation cost **w** for any connection is at least 1 credit, capped by a maximum grant limit of 1,000,000 credits. The available connection options follow the minimal design mentioned above.

## Output

Print a single integer: the minimum total cost to integrate all critical facilities.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the critical facilities 1 and 4 can only communicate by passing messages through facilities 2 and 3. Therefore, all three connections must be established, costing 5 + 1 + 2 = 8.
In Example 2, there is only one critical facility, so no connections need to be established.
</STATEMENT>
<RATIONALE>
The explicit mention of "exactly one possible route without revisiting any site" was removed to prevent models from pattern-matching the unique-path property of trees. The tree structure must now be deduced from the network being "fully integrated" (connected) with exactly n-1 edges. Additionally, numeric bounds were rewritten as physical capacities and limits within the scenario (Strategy S07).
</RATIONALE>
<PRESERVED_ANSWER>
The structural requirements and costs are mathematically identical; finding the minimum subset of edges to connect a set of vertices in a tree still yields the exact same cost.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying graph is still a tree, meaning the minimum subgraph connecting a subset of vertices is exactly the unique minimal subtree, which can be found in O(n) time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "fully integrated" as a complete graph, though the phrase "total number of connection options is exactly one less than the number of facilities" immediately contradicts and clarifies this.
</RISK>
