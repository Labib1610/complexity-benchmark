<METHOD_NAME>Permutation Symmetry Entailment</METHOD_NAME>
<METHOD_DESCRIPTION>Translates graph connectivity into the generation of a permutation subgroup. The available edges become transposition symmetries of a multivariate function, and connecting the focus vertices becomes enforcing that the chosen transpositions logically entail symmetry under any permutation of the focus variables. This obscures the "path-finding" and "tree-pruning" nature of the problem, forcing the model to realize that transpositions generate the required symmetric group if and only if they form a connected subgraph containing the target indices.</METHOD_DESCRIPTION>

<STATEMENT>
# Symmetry Enforcing Cost

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a multivariate function $F(x_1, x_2, \dots, x_n)$. 
You are given a target set of **t** indices, called the *focus indices*. You need to ensure that the function $F$ is completely symmetric with respect to any permutation of the variables at these focus indices. That is, for any two focus indices **a** and **b**, exchanging the values of $x_a$ and $x_b$ must not change the output of $F$.

You have a catalog of **m** available symmetry constraints. Each constraint is defined by a pair of indices (**u**, **v**) and provides a mathematical guarantee that $F$ is symmetric under the exchange of variable $x_u$ and variable $x_v$. Enforcing this specific constraint on $F$ incurs a cost of **w**. 

Your goal is to choose a subset of these **m** available constraints such that, by the mathematical properties of permutations, the chosen constraints logically guarantee that $F$ is invariant under the exchange of ANY pair of focus indices **a** and **b**. 

You must find the minimum possible total cost (the sum of the costs of the chosen constraints) to achieve this.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **n** ≤ 200000, **m** = **n** - 1, 1 ≤ **t** ≤ **n**).

The second line provides **t** distinct integers representing the focus indices.

The subsequent **m** lines each contain three integers **u**, **v**, and **w**. These values describe an available constraint between $x_u$ and $x_v$ (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**) that incurs a cost of **w** (1 ≤ **w** ≤ 1000000). It is guaranteed that if all **m** constraints are chosen, $F$ is guaranteed to be symmetric under any permutation of all **n** variables.

## Output

Print a single integer indicating the minimum total cost required to logically guarantee the function is symmetric with respect to all permutations of the focus variables.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the focus indices are 1 and 4. We require $F$ to be invariant when $x_1$ and $x_4$ are exchanged. The only way to logically deduce this from the available constraints is to enforce the exchange symmetries for (1, 2), (2, 3), and (3, 4). Thus, all three constraints (costing 5 + 1 + 2 = 8) must be chosen. 

In Example 2, there is only one focus index, so no exchange guarantees between distinct focus variables are required. The minimum cost is 0.

In Example 3, the focus indices are 1, 2, and 3. Choosing both available constraints guarantees symmetry for (1, 2) and (2, 3), which logically entails symmetry for all permutations of 1, 2, and 3. The cost is 4 + 5 = 9.
</STATEMENT>
<RATIONALE>
The problem was reframed from spanning vectors in a vector space to enforcing permutation symmetries on a multivariate function. This forces the model to realize that generating the symmetric group on a subset of variables requires a connected transposition subgraph containing those variables, effectively hiding the "tree-pruning" graph structure behind algebraic group properties.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical condition for a set of transpositions to generate all permutations of a subset of elements is exactly that the elements must belong to the same connected component in the transposition graph, making the required logic identical to finding the minimum Steiner tree.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the minimum Steiner tree on a tree, which is solvable in O(n) time by pruning non-focus leaves, keeping it in the polynomial time complexity class.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret "invariant under the exchange of ANY pair" as requiring direct (u, v) constraints for every pair, but the phrase "logically guarantee... by the mathematical properties of permutations" and the worked examples clearly demonstrate that transitivity is allowed and expected.
</RISK>
