# Equality Constraint Minimization

Time limit: 2 s   Memory limit: 256 MB

## Description

You are designing a system of scalar functions over **n** distinct identifiers, labeled $1$ to **n**. You are given a target set of **t** identifiers, called the *focus identifiers*. Your objective is to ensure that for any valid function $f$ in your system, $f(a) = f(b)$ holds for every pair of focus identifiers **a** and **b**. (If **t** $\le 1$, this condition is already satisfied without purchasing any constraints, so the cost is $0$.)

You are provided with a catalog of **m** available constraint operations. Each operation is defined by a pair of identifiers (**u**, **v**) and, when purchased, enforces the condition $f(u) = f(v)$ on your system. Purchasing this constraint incurs a cost of **w**.

Your goal is to choose a subset of these **m** available constraints such that, under the combined effect of your chosen constraints, the condition $f(a) = f(b)$ is logically guaranteed for all focus identifiers **a**, **b**. 

You must find the minimum possible total cost (the sum of the costs of the chosen constraints) to achieve this.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **n** ≤ 200000, **m** = **n** - 1, 1 ≤ **t** ≤ **n**).

The second line provides **t** distinct integers representing the focus identifiers.

The subsequent **m** lines each contain three integers **u**, **v**, and **w**. These values describe an available constraint enforcing $f(u) = f(v)$ (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**) that incurs a cost of **w** (1 ≤ **w** ≤ 1000000). It is guaranteed that if all **m** available constraints are purchased, $f(x) = f(y)$ is enforced for all $1 \le x, y \le n$.

## Output

Print a single integer indicating the minimum total cost required to ensure that $f(a) = f(b)$ is enforced for all pairs of focus identifiers.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the focus identifiers are 1 and 4. We require $f(1) = f(4)$ for any valid function $f$. The only way to enforce this is by purchasing the constraints $f(1) = f(2)$, $f(2) = f(3)$, and $f(3) = f(4)$. Thus, all three constraints (costing 5 + 1 + 2 = 8) must be chosen. 

In Example 2, there is only one focus identifier, so no conditions need to be enforced between distinct focus identifiers. The minimum cost is 0.
