<STATEMENT>
# Register Parity Resolution

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of **n** binary registers. 
You are given a target set of **t** indices, called the *focus registers*. You need to ensure that you can logically deduce the bitwise XOR sum for every pair of focus registers **a** and **b**.

You have a catalog of **m** available hardware probes. Each probe is defined by a pair of registers (**u**, **v**) and, when activated, continuously outputs the exact XOR sum of their current values. Activating this probe incurs a hardware cost of **w**. 

Your goal is to choose a subset of these **m** probes such that the XOR sum of every required pair of focus registers (**a**, **b**) can be deduced exclusively from the outputs of your chosen probes. (Note that if you know the XOR sum of register X and Y, and of Y and Z, you can deduce the XOR sum of X and Z by XORing the two known results).

Assume the registers' individual values are completely unknown and independent; the XOR sum of two registers can only be deduced if they can be linked through a sequence of activated intermediate probes that share common registers. It is guaranteed that if all **m** probes were activated, you would have enough information to deduce the XOR sum for any pair of the **n** registers.

You must find the minimum possible total activation cost to achieve this.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **n** ≤ 200000, **m** is exactly the minimum number of probes required to ensure the XOR sum of any pair among all **n** registers could be deduced, 1 ≤ **t** ≤ **n**).

The second line provides **t** distinct integers representing the focus registers.

The subsequent **m** lines each contain three integers **u**, **v**, and **w**. These values describe an available probe outputting the XOR sum of register **u** and register **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**) that incurs an activation cost of **w** (1 ≤ **w** ≤ 1000000).

## Output

Print a single integer indicating the minimum total cost required to ensure the XOR sums between all pairs of focus registers can be deduced from the chosen subset of probes.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the focus registers are 1 and 4. We require the XOR sum of 1 and 4. The only way to deduce this is by activating the probes for (1, 2), (2, 3), and (3, 4). Thus, all three probes (costing 5 + 1 + 2 = 8) must be chosen. 

In Example 2, there is only one focus register, so no pairs need to be deduced. The minimum cost is 0.
