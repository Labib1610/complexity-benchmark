<STATEMENT>
# Jurisprudence Citation Network

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a legal database of **n** distinct court cases, numbered $1$ to **n**. You are given a target set of **t** cases, called the *landmark cases*. 

You are provided with a catalog of **m** available bidirectional cross-references. Each cross-reference connects a pair of cases (**u**, **v**) and has an associated reading time of **w**. It is guaranteed that the full catalog of **m** available cross-references forms a fully connected jurisprudence on the **n** cases with exactly **n** - 1 cross-references. This structure guarantees that there is exactly one unique simple sequence of cross-references between any pair of cases in the database.

Your goal is to select a subset of these **m** available cross-references to study. The rule for studying is: for every possible pair of landmark cases, you must study all cross-references that make up the unique simple sequence of cross-references between them in the full database. 

You must find the minimum possible total reading time (the sum of the reading times of the studied cross-references) that satisfies this rule.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **n** ≤ 200000, **m** = **n** - 1, 1 ≤ **t** ≤ **n**).

The second line provides **t** distinct integers representing the landmark cases.

The subsequent **m** lines each contain three integers **u**, **v**, and **w**. These values describe an available bidirectional cross-reference between case **u** and case **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**) with a reading time of **w** (1 ≤ **w** ≤ 1000000). It is guaranteed that if all **m** available cross-references are used, all **n** cases are connected to each other, with exactly one unique simple sequence of cross-references between any pair of cases.

## Output

Print a single integer indicating the minimum total reading time of a chosen subset of cross-references such that, for every pair of landmark cases, all cross-references on the unique simple sequence between them are studied.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the landmark cases are 1 and 4. The unique simple sequence of cross-references between case 1 and case 4 in the full database consists of the cross-references (1, 2), (2, 3), and (3, 4). Therefore, all three of these cross-references must be studied. Their total reading time is 5 + 1 + 2 = 8.

In Example 2, there is only one landmark case. Since there are no pairs of distinct landmark cases, no cross-references need to be studied. The minimum reading time is 0.
