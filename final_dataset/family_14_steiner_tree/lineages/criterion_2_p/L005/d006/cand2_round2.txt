<STATEMENT>
# Variable Equivalence Verification

Time limit: 2 s   Memory limit: 256 MB

## Description

A formal verification system operates on $n$ scalar variables, indexed 1 through $n$. A specific subset of $t$ target variables must be proven to hold the exact same value.

The system is provided with $m$ potential identities. Each identity establishes that variable $u$ is equal to variable $v$, and requires a computational cost of $w$ to verify. Identities can be chained together (for instance, proving $x=y$ and $y=z$ establishes $x=z$). It is guaranteed that if all $m$ potential identities were verified, all $n$ variables would be proven equal. Because $m = n - 1$, this means there is exactly one non-redundant chain of potential identities between any two variables.

Your objective is to select a subset of these potential identities to verify such that every target variable is proven equal to every other target variable. You must find the absolute minimum total computational cost required to accomplish this.

## Input

The first line provides three integers $n$, $m$, and $t$ ($1 \le n \le 200000$, $m = n - 1$, $1 \le t \le n$).

The second line provides $t$ distinct integers representing the indices of the target variables.

The subsequent $m$ lines each contain three integers $u$, $v$, and $w$. These values describe a potential identity establishing that variable $u$ equals variable $v$ ($1 \le u, v \le n$, $u \neq v$), which requires a cost of $w$ to verify ($1 \le w \le 1000000$).

## Output

Print a single integer indicating the minimum total computational cost required to prove all target variables are equal.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, target variables 1 and 4 can only be proven equal by chaining through variables 2 and 3, so all three identities (5+1+2 = 8) must be verified. In Example 2, there is only one target variable, so no identities need to be enforced, making the minimum cost 0.
