<STATEMENT>
# Invariant Derivation

Time limit: 2 s   Memory limit: 256 MB

## Description

A mathematical model consists of $n$ distinct unconstrained scalar variables, indexed $1$ through $n$. 

You are provided with $m$ potential equivalence identities. Each identity states that two distinct variables are equal (i.e., $x_u = x_v$), and requires a specific computational cost to be enforced in the model. 

A specific subset of $t$ variables are designated as the *target scalars*. Your objective is to select a subset of the potential identities to enforce such that the equality of all target scalars is logically guaranteed. That is, for any two target scalars $a$ and $b$, the statement $x_a = x_b$ must be derivable solely using the properties of equality (reflexivity, symmetry, transitivity) from your enforced identities. You must determine the minimum total computational cost required to achieve this.

The system's memory architecture supports a variable count $n$ from a single scalar up to a maximum capacity of two hundred thousand. The number of potential identities $m$ is structurally constrained to be exactly one less than the variable count. It is guaranteed that if all $m$ potential identities were enforced, all $n$ variables in the model would be proven equal. The count of target scalars $t$ requires tracking at least one variable, up to the full set of $n$. The computational cost for enforcing each identity requires at least one processing unit and is limited by a hardware ceiling of one million units.

## Input

The first line provides three integers $n$, $m$, and $t$.

The second line provides $t$ distinct integers representing the indices of the target scalars.

The subsequent $m$ lines each contain three integers $u$, $v$, and $w$. These values describe a potential identity $x_u = x_v$ that costs $w$ processing units to enforce.

## Output

Print a single integer indicating the minimum total computational cost required to logically guarantee that all target scalars are equal.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, deriving the equality between target scalars 1 and 4 requires enforcing the identities $x_1 = x_2$, $x_2 = x_3$, and $x_3 = x_4$, which incurs a total cost of 5 + 1 + 2 = 8. 

In Example 2, there is only one target scalar, so its equality with itself is trivially guaranteed by reflexivity without enforcing any identities.
</STATEMENT>
<RATIONALE>
The problem was completely reframed from physical thermal networks to algebraic deduction, replacing all graph terminology with equivalence relations and logical derivation. Bounds were integrated into the scenario text (Strategy S07) rather than presented as raw inequalities. This forces the model to independently deduce that the identities form a tree topology and that the required subset is exactly the minimal spanning subtree of the target variables, preventing reliance on keyword-triggered graph templates.
</RATIONALE>
<PRESERVED_ANSWER>
Mathematical equivalence is an equivalence relation (forming connected components), and because the total identities form a tree topology, the only way to deduce equality between a set of variables is to enforce the identities along the unique paths connecting them; thus the minimum cost subset is exactly the same unique Steiner tree on the graph.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains finding the minimal subtree connecting $t$ given nodes in a tree, which is solvable in O(N) by rooting the tree and summing edges that lead to subtrees containing at least one target node.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "logically guaranteed" as allowing algebraic tricks outside of the provided identities, though the explicit restriction "derivable solely using the properties of equality (reflexivity, symmetry, transitivity) from your enforced identities" makes this highly unlikely for a competent reader.
</RISK>
