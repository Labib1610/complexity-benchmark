<METHOD_NAME>Quadratic Bound on Sequence Variations</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the equality constraint condition with a requirement that a quadratic inequality holds for all real sequences. The inequality bounds the maximum squared difference between target elements by a constant multiple of the sum of squared differences across the chosen operations. This is mathematically equivalent to the chosen operations forming a connected component containing the targets (since otherwise a step function yields 0 on the sum and >0 on the target difference), but it forces models to analyze an analytic bound rather than matching a graph connectivity pattern.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<STATEMENT>
# Analytic Sequence Binding

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing sequences of **n** real numbers, indexed $1$ to **n**. You are given a target set of **t** distinct indices, called the *focus indices*, denoted by $T$.

You are provided with a catalog of **m** available transition pairs. Each pair $i$ is defined by two indices $u_i$ and $v_i$, and an activation cost $w_i$. 

You must select a subset $S$ of these pairs. We say that your selected subset $S$ is *analytically binding* for the focus indices if there exists a strictly positive real constant $C > 0$ such that, for EVERY possible sequence of real numbers $x_1, x_2, \dots, x_n$, the following inequality holds:

$$ C \cdot \max_{a, b \in T} (x_a - x_b)^2 \le \sum_{i \in S} (x_{u_i} - x_{v_i})^2 $$

(If **t** $= 1$, the maximum squared difference among the focus indices evaluates to $0$, and the condition is trivially satisfied by any subset $S$, including the empty set, for any $C > 0$.)

Your goal is to find a subset $S$ that is analytically binding for the given focus indices $T$, such that the total activation cost $\sum_{i \in S} w_i$ is minimized.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **n** ≤ 200000, **m** = **n** - 1, 1 ≤ **t** ≤ **n**).

The second line provides **t** distinct integers representing the focus indices.

The subsequent **m** lines each contain three integers **u**, **v**, and **w**. These values describe an available transition pair $i$ between index **u** and **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**) that incurs an activation cost of **w** (1 ≤ **w** ≤ 1000000). It is guaranteed that if all **m** available pairs are selected, the subset is analytically binding for all possible focus sets.

## Output

Print a single integer indicating the minimum total activation cost required to form an analytically binding subset for the focus indices.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the focus indices are 1 and 4. We must ensure that $(x_1 - x_4)^2$ is bounded by a multiple of the sum of $(x_{u_i} - x_{v_i})^2$ for our chosen pairs. If we only select pairs (1,2) and (2,3), we bound $(x_1 - x_3)^2$, but we cannot bound $(x_1 - x_4)^2$ for an arbitrary sequence (for example, a sequence where $x_1=x_2=x_3=0$ and $x_4=1$ would yield $0$ on the right side but $C$ on the left side, which is impossible for $C>0$). Thus, all three pairs must be selected, costing 5 + 1 + 2 = 8.

In Example 2, there is only one focus index, so the condition is trivially satisfied with an empty subset $S$, costing 0.
</STATEMENT>
<RATIONALE>
The problem was completely reframed from an equality constraint minimization into ensuring an analytic quadratic bound on arbitrary real sequences. The inequality holds if and only if the chosen pairs form a connected component containing all focus indices, forcing models to deduce graph connectivity from a functional analysis property rather than relying on standard graph terminology.
</RATIONALE>
<PRESERVED_ANSWER>
The quadratic inequality holds for all sequences if and only if the focus indices are connected by the selected pairs (otherwise a step function violates it); thus, the minimal cost subset is exactly the same unique minimal subtree spanning the focus nodes.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying mathematical task remains finding the minimal subtree spanning a set of target nodes in a tree, which is solvable in $O(n)$ time.
</PRESERVED_CLASS>
<RISK>
A reader might incorrectly assume $C$ can depend on the sequence $X$, though the quantifier order ("there exists a strictly positive real constant $C > 0$ such that, for EVERY possible sequence...") unambiguously prevents this.
</RISK>
