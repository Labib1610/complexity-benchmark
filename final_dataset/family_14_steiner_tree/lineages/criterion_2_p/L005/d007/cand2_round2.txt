<STATEMENT>
# Relative Clock Synchronization

Time limit: 2 s   Memory limit: 256 MB

## Description

A distributed network contains a system of clocks, numbered sequentially starting from 1. Absolute time cannot be measured directly, but a diagnostic tool can evaluate the exact relative time offset between specific pairs of clocks. A subset of these clocks are designated as master clocks and must be synchronized relative to each other.

The system administrator has a catalog of available pairwise measurement procedures. Each procedure measures the offset between a specific pair of clocks and yields the exact mathematical difference between their times. Executing a procedure incurs a computational cost. 

It is guaranteed that the full catalog of procedures connects the clocks such that there is exactly one simple path of measurements between any two clocks. Therefore, if all available procedures were executed, the relative offsets between all clocks in the network would be fully determined.

Your objective is to select a subset of these measurement procedures to execute such that the relative offsets between all pairs of master clocks become mathematically determined (either directly from a single procedure or deduced by combining multiple procedures along a path). You must find the absolute minimum total computational cost required to achieve this.

## Input

The first line provides three integers representing the total number of clocks, the number of available procedures, and the number of master clocks. The maximum capacity of the network is exactly the number of seconds in 55 hours, 33 minutes, and 20 seconds, so the total number of clocks is between 1 and this capacity. The number of procedures is exactly one less than the total number of clocks. The number of master clocks is at least 1 and at most the total number of clocks.

The second line provides distinct integers representing the identifiers of the master clocks.

The subsequent lines (one for each available procedure) each provide three integers: the identifiers of the two distinct clocks being compared, and the computational cost of the procedure. Clock identifiers are valid integers from 1 up to the total number of clocks. The computational cost is at least 1 and restricted by a hardware limit to not exceed the cube of one hundred. It is guaranteed that the available procedures form the uniquely connected structure described above.

## Output

Print a single integer indicating the minimum total computational cost required to ensure the relative offsets between all pairs of master clocks are mathematically determined.

## Examples

### Example 1

**Input**

**Output**

```
8
```


### Example 3

**Input**


**Output**
```

```

## Note

In Example 1, the relative offset between master clocks 1 and 4 can only be deduced by combining the procedures for (1,2), (2,3), and (3,4). Thus, all three procedures (costing 5+1+2 = 8) must be executed. 

In Example 2, there is only one master clock, so no relative offsets need to be determined, requiring a computational cost of 0.
