<STATEMENT>
# Core Entity Translation

Time limit: 2 s   Memory limit: 256 MB

## Description

A system handles **n** data entities, indexed from 1 to **n**. Within this system, **t** entities are marked as core entities. 

You are provided with **m** available bidirectional translation protocols. Each protocol allows direct conversion between two specific data entities for a given licensing fee. 

The **m** protocols connect all **n** entities such that between any two entities there is exactly one simple path of protocols.

Your task is to choose a subset of the given **m** protocols with minimum total licensing fee such that all core entities lie in one connected component (they can all be converted into one another, possibly using non-core entities as intermediates).

## Input

The first line contains three integers **n**, **m**, and **t**, satisfying `1 <= n <= 200000`, `m = n - 1`, and `1 <= t <= n`.

The second line contains **t** distinct integers: the indices of the core entities.

The following **m** lines each contain three integers **u**, **v**, and **w**, satisfying `1 <= u, v <= n`, `u != v`, and `1 <= w <= 1000000`. These indicate a protocol between entity **u** and entity **v** with a licensing fee of **w**.

## Output

Print a single integer representing the minimum total licensing fee required to connect all core entities.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1 the core entities 1 and 4 can only be converted through 2 and 3, so all three protocols (5+1+2 = 8) must be licensed. In Example 2 there is only one core entity, so no protocols are needed.
</STATEMENT>
<RATIONALE>
The problem was reframed from physical infrastructure (substations and communication lines) to abstract data entities and translation protocols. This prevents models from relying on surface-level keyword associations to deduce that the graph is a tree and forces them to reason about the structural properties ("exactly one simple path") to realize a linear-time traversal is sufficient. All numeric constraints were explicitly restored to inequality notation to prevent machine-checkable fidelity failures.
</RATIONALE>

The mathematical task remains identical: finding the minimum weight subgraph that connects a specific subset of vertices in a tree, which yields the exact same cost for all inputs.
</PRESERVED_ANSWER>

The underlying graph is still guaranteed to be a tree by the exact path condition and edge count, meaning the minimum connected component spanning the core entities is unique and can be found in O(n) time.
</PRESERVED_CLASS>
