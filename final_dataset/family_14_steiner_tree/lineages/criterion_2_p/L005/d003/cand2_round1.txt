# Algebraic Equivalence System

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of **n** unknown variables, $x_1, x_2, \dots, x_n$.
You are provided a pool of **m** candidate constraints. Each candidate constraint is an equation of the form $x_u = x_v$. 

If you were to enforce all **m** candidate constraints simultaneously, the system would reduce to exactly one degree of freedom (i.e., $x_1 = x_2 = \dots = x_n$). There are exactly **m = n − 1** candidate constraints in the pool.

A specific subset of **t** variables are designated as the **target variables**. Your goal is to select a subset of the candidate constraints to enforce, such that the enforced constraints mathematically guarantee that all **t** target variables must equal each other. Enforcing the candidate constraint $x_u = x_v$ incurs a computational cost of **w**.

Determine the minimum total cost of constraints you must enforce to guarantee the target variables are mutually equal.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line provides **t** distinct integers: the indices of the target variables.
The following **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), representing a candidate constraint $x_u = x_v$ that costs **w** to enforce.

## Output

Print a single integer representing the minimum total cost required to enforce the equality of all target variables.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the target variables are $x_1$ and $x_4$. To mathematically guarantee $x_1 = x_4$ using the available constraints, you must enforce $x_1 = x_2$, $x_2 = x_3$, and $x_3 = x_4$. The total cost is 5 + 1 + 2 = 8. 

In Example 2, there is only one target variable ($x_3$). It is trivially equal to itself, so no constraints need to be enforced and the cost is 0.

Because the only available constraints are pairwise equalities, guaranteeing that a subset of variables are equal is mathematically identical to connecting them in the constraint graph; the unique minimal subset in a tree yields the exact same total cost.
</PRESERVED_ANSWER>
