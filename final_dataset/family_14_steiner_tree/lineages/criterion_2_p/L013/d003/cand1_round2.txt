<STATEMENT>
# Problem B — Translation Consistency

Time limit: 2 s   Memory limit: 256 MB

## Description

An international publisher operates across **n** distinct languages (numbered 1 through **n**). 

The publisher can retain professionals from a pool of **m** bilingual translators. Each translator provides bidirectional conversion between a specific pair of languages for a fixed retainer fee. The pool of **m** available translators is structured such that all **n** languages are interconnected, and between any two languages, there is exactly one sequence of translators that can mediate a conversation.

A forthcoming publication must be prepared in **t** priority languages. To ensure consistency, whenever a text is translated between any two distinct priority languages, the publisher must retain every translator that belongs to the unique sequence bridging them. 

Calculate the total retainer fee required to retain all translators who appear in the bridging sequence between at least one pair of distinct priority languages. A retained translator's fee is paid exactly once, regardless of how many priority pairs their sequence supports.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers: the identifiers of the priority languages.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating a translator who bridges language **u** and language **v** for a fee of **w**. The given translators form the unique-sequence structure described above.

## Output

Print a single integer: the total retainer fee to hire the required translators.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the priority languages 1 and 4 are bridged by the sequence of translators connecting 1 to 2, 2 to 3, and 3 to 4. Therefore, all three translators (fees 5+1+2 = 8) must be retained. In Example 2, there is only one priority language, meaning there are no pairs of distinct priority languages, so no translators need to be retained.
</STATEMENT>
<RATIONALE>
The explicit guarantee that the network is a tree (n-1 edges, connected, unique paths) is preserved to maintain the problem's complexity class. However, the objective has been reframed from finding a "minimum subset such that priority languages can inter-translate" to a direct edge-inclusion rule: "retain all translators who appear in the bridging sequence between at least one pair of distinct priority languages." This forces models to realize that the union of all paths between pairs of priority nodes is equivalent to the minimal connecting subtree, and that they must use a tree-pruning or subtree-counting approach to avoid TLE, rather than pattern-matching the Steiner Tree keywords.
</RATIONALE>
<PRESERVED_ANSWER>
In a tree, the union of the unique paths between all pairs of nodes in a given subset is exactly the minimal connected subgraph (Steiner tree) containing that subset, so the required edges and their total cost are identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains solvable in O(n) time by rooting the tree and counting the number of priority nodes in each subtree to determine which edges lie on a path between priority nodes.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "between at least one pair" as requiring an all-pairs path search, which is unambiguous mathematically but computationally naive; this is the intended trap for models that fail to reason about tree properties.
</RISK>
