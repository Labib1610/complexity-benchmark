We can model the translator network as a tree (since it’s minimally connected with n−1 edges).  
The problem reduces to finding the minimum total edge weight needed to connect all the priority nodes in this tree.  

This is equivalent to finding the **Steiner tree** for the set of priority nodes in a tree, which can be solved by:

1. Marking all priority nodes.
2. Removing all leaf nodes that are not priority nodes (and their incident edges) repeatedly, because they are not needed.
3. The remaining tree is the minimal subtree that connects all priority nodes.
4. Sum the weights of the edges in this remaining tree.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m, t = map(int, input().split())
priority = set(map(int, input().split()))

adj = [[] for _ in range(n + 1)]
degree = [0] * (n + 1)
weights = {}

for _ in range(m):
    u, v, w = map(int, input().split())
    adj[u].append((v, w))
    adj[v].append((u, w))
    degree[u] += 1
    degree[v] += 1
    weights[(u, v)] = w
    weights[(v, u)] = w

# If only one priority language, no edges needed
if t == 1:
    print(0)
    sys.exit()

# Remove non-priority leaves
q = deque()
in_tree = [True] * (n + 1)

for i in range(1, n + 1):
    if degree[i] == 1 and i not in priority:
        q.append(i)

while q:
    u = q.popleft()
    if not in_tree[u]:
        continue
    in_tree[u] = False
    for v, w in adj[u]:
        if in_tree[v]:
            degree[v] -= 1
            if degree[v] == 1 and v not in priority:
                q.append(v)

# Sum weights of edges where both endpoints are still in the tree
total = 0
for u in range(1, n + 1):
    if in_tree[u]:
        for v, w in adj[u]:
            if u < v and in_tree[v]:
                total += w

print(total)
```
