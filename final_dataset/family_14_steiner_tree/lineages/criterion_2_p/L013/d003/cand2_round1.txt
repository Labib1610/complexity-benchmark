<STATEMENT>
# Problem B — Translation Consistency

Time limit: 2 s   Memory limit: 256 MB

## Description

An international publisher operates across **n** distinct languages (numbered 1 through **n**). The publisher's database requires at least one language and supports a maximum capacity of 200,000 distinct languages.

The publisher can retain professionals from a pool of **m** bilingual translators. Due to a hiring freeze, the headcount of this translator pool is strictly fixed at exactly one less than the total number of languages. Each translator provides bidirectional conversion between a specific pair of distinct languages for a fixed retainer fee. The fee requested by any translator is a minimum of 1 and cannot exceed the departmental sign-off limit of 1,000,000. 

A forthcoming publication must be prepared in **t** priority languages. Depending on the project, this requires a minimum of 1 priority language and can span up to all **n** languages. The publisher needs to retain a subset of the translators such that a text can be converted from any of the **t** priority languages to any other of the **t** priority languages using exclusively the retained professionals. These conversions may route through intermediate languages, which do not themselves need to be priority languages. 

While translator pools might generally contain redundant translation loops or leave some minor languages completely isolated, you are guaranteed that this specific pool successfully links all **n** languages in the database (meaning a text can be translated between any two languages, possibly using intermediate languages).

Calculate the minimum total retainer fee required to retain a valid subset of translators. The fee for each retained translator is paid exactly once, independent of the number of conversion routes they support.

## Input

The first line contains three integers **n**, **m**, and **t**.
The second line contains **t** distinct integers: the identifiers of the priority languages.
Each of the next **m** lines contains three integers **u**, **v**, and **w**: indicating a translator who bridges language **u** and language **v** for a fee of **w**. 

## Output

Print a single integer: the minimum total retainer fee to ensure all priority languages can inter-translate.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the priority languages 1 and 4 can only be bridged through languages 2 and 3, so all three translators (fees 5+1+2 = 8) must be retained. In Example 2, there is only one priority language, so no translators need to be retained.
</STATEMENT>
<RATIONALE>
I removed the explicit guarantee of a unique path between any language pair, which trivially identifies the network as a tree. Instead, I introduced a distractor about potential translation loops and isolated languages, while stating that this specific network successfully links all languages. I also applied S07 by expressing all numeric bounds as systemic limits in the text. This forces the model to deduce from the headcount ($m = n - 1$) and the connectivity guarantee that the graph is indeed a tree, preventing surface-level pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The underlying graph remains a tree because the input guarantees $m = n - 1$ edges and full connectivity, so the minimum cost to connect the priority nodes is still exactly the unique Steiner subtree weight.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class remains P because a connected graph with $n$ vertices and $n-1$ edges is necessarily a tree, allowing the optimal subset to be found in linear time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the distractor about "redundant translation loops" as applying to the current test case despite the explicit guarantee that follows, potentially leading them to apply an NP-hard general Steiner tree algorithm and fail on time limits.
</RISK>
