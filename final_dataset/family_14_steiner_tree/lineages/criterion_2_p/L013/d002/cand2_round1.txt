<STATEMENT>
# Problem B — Translation Consistency

Time limit: 2 s   Memory limit: 256 MB

## Description

A publisher is preparing a major international release. There are distinct languages involved in their global operations. 

To facilitate communication, the publisher can hire from a pool of bilingual translators. Each translator works in both directions between exactly two specific languages and charges a fixed retainer fee. The pool of available translators is strictly non-redundant: it encompasses all languages, and while all languages can currently inter-translate using the full pool, terminating any single translator's contract would make it impossible to bridge at least one pair of languages.

The upcoming book must be finalized in a specific set of target languages. To ensure editorial consistency, the publisher must hire a subset of translators such that a manuscript can be passed from any of the target languages to any other of the target languages, relying only on the hired translators (this may require passing through intermediate languages). 

Determine the minimum total retainer fee the publisher must pay to hire a valid subset of translators. Each hired translator's fee is paid exactly once, regardless of how many translation sequences they participate in.

## Input

The first line contains three integers: the number of languages involved, the number of available translators, and the number of target languages.
The total number of languages is at least 1, constrained by a legacy database limit of exactly 200,000 languages. The number of target languages ranges from 1 up to the total number of languages.
The second line contains the distinct IDs of the target languages. Language IDs are assigned contiguously starting from 1.
Each of the subsequent lines contains three integers describing a translator: the two distinct language IDs they bridge, and their retainer fee. The retainer fee is a minimum of 1 and cannot exceed the corporate approval threshold of exactly 1,000,000. The available translators form the non-redundant structure described above.

## Output

Print a single integer: the minimum total retainer fee to ensure all target languages can inter-translate.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the target languages 1 and 4 can only be bridged through languages 2 and 3, so all three translators (fees 5+1+2 = 8) must be hired. In Example 2, there is only one target language, so no translators need to be hired.
</STATEMENT>
<RATIONALE>
I removed the explicit "exactly n-1 translator options" and "exactly one possible sequence" affordances, replacing them with a structural definition (a connected network where every edge is a bridge). This forces the model to infer that the graph is a tree rather than being handed the property directly. I also applied strategy S07, replacing all bare inequalities with scenario-based limits (such as legacy database limits and corporate thresholds) from which the bounds must be derived.
</RATIONALE>
<PRESERVED_ANSWER>
The scenario and underlying graph structure remain mathematically identical, so the minimum weight subtree connecting the target vertices has exactly the same cost for every input.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks for the minimum weight connected subgraph spanning a subset of vertices in a tree, which is solvable in O(n) time and remains in P.
</PRESERVED_CLASS>
<RISK>
A reader might misinterpret "terminating any single translator's contract would make it impossible to bridge at least one pair" as a condition on the hired subset rather than the full pool, though the text explicitly states "using the full pool".
</RISK>
