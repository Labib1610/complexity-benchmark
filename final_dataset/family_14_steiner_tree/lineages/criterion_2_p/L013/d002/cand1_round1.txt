<STATEMENT>
# Problem B — Translation Consistency

Time limit: 2 s   Memory limit: 256 MB

## Description

A multinational publisher is coordinating the launch of a new book across **n** different languages (identified by integers from 1 to **n**). 

The publisher has vetted a specific catalog of **m** freelance translators. Each freelancer specializes in a specific pair of languages, providing two-way translation between them for a flat retainer fee. This catalog has been intentionally restricted to avoid billing redundancies: it covers all **n** languages, contains exactly **n − 1** freelancers, and guarantees that for any two languages, there is exactly one sequence of freelancers that can sequentially translate a document from the first language to the second.

The book is scheduled to be published in **t** priority languages. The publisher needs to activate a subset of the freelance contracts to establish a translation framework. This framework is valid only if it satisfies a strict inclusion rule: for every possible pair of priority languages, the unique sequence of freelancers that translates between them in the full catalog must be fully present in the activated subset.

Calculate the lowest possible total retainer fee required to activate a valid framework. A freelancer's fee is only paid once, even if they are part of the connecting sequence for multiple different pairs of priority languages.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers: the ids of the priority languages.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): indicating a freelancer who translates between language **u** and language **v** for a fee of **w**. The catalog of freelancers adheres to the non-redundant structure described above.

## Output

Print a single integer representing the minimum total retainer fee required to activate a valid translation framework.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the priority languages are 1 and 4. The unique sequence translating between them in the full catalog requires the freelancers for (1,2), (2,3), and (3,4). All three must be activated (fees 5+1+2 = 8). 
In Example 2, there is only one priority language, meaning there are zero pairs to connect. No freelancers need to be activated.
</STATEMENT>
<RATIONALE>
I reframed the validity condition from a connectivity requirement ("can pass a manuscript from any target to any other") to a path-inclusion requirement ("must include the unique sequence for every pair of priority languages"). This forces models to recognize that the union of all pairwise unique paths in a tree is algorithmically equivalent to finding the minimal subtree spanning those nodes, rather than blindly implementing an $O(t^2)$ pairwise path-finding simulation which will TLE.
</RATIONALE>
<PRESERVED_ANSWER>
The minimal valid subset containing the unique paths between all pairs of priority languages is mathematically identical to the minimal connected subgraph spanning those languages, so the required freelancers and total fee are exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks for the weight of the Steiner tree on the priority languages, which can be found in $O(n)$ by rooting the tree and pruning branches without priority nodes.
</PRESERVED_CLASS>
<RISK>
Models might interpret "sequence of freelancers that translates between them" as implying directed edges, but the problem explicitly states that each freelancer provides "two-way translation".
</RISK>
