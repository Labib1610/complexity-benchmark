# Problem B — Activating the Critical Workstations (Non-Redundant Layout)

Time limit: 2 s   Memory limit: 256 MB

## Description

A facility has **n** workstations (numbered 1 to **n**). Certain pairs of workstations can be joined by a data link at a given activation cost. Among the workstations, **t** are **critical** and must all end up connected to each other through the links you activate (directly or through intermediate relay workstations).

The facility's communication infrastructure is fully integrated, meaning data can be relayed between any two workstations. However, the blueprint is completely devoid of alternative routes: data sent from one workstation to another will only ever have a single sequence of links it could possibly traverse.

Activate a set of data links of minimum total cost so that all critical workstations are connected. Report that minimum total cost.

## Input

The first line contains three integers **n**, **m**, and **t**. The facility's physical capacity limits the number of workstations **n** to a maximum of 200000 (and at least 1). The number of critical workstations **t** is at least 1 and at most **n**. The lack of alternative routes strictly fixes the total available links **m** to exactly **n** minus 1.

The second line contains **t** distinct integers: the ids of the critical workstations.

Each of the next **m** lines contains three integers **u**, **v**, and **w** representing a data link joining distinct workstations **u** and **v** (between 1 and **n**) at cost **w**. The hardware components dictate that any cost **w** is at least 1 and at most 1000000. The options form the infrastructure described above.

## Output

Print a single integer: the minimum total activation cost to connect all critical workstations.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1 the critical workstations 1 and 4 are joined only through 2 and 3, so all three links (5+1+2 = 8) are needed. In Example 2 there is one critical workstation, so no links are needed.
