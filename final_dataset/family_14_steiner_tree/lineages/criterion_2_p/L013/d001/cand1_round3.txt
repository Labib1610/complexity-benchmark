# Problem B — Activating the Critical Workstations

Time limit: 2 s   Memory limit: 256 MB

## Description

A facility contains a number of workstations, identified by integers from 1 up to the total count. The facility's architectural limit allows a maximum of 200,000 workstations to be installed, and at least one is always present. Certain pairs of workstations can be joined by a data link at a specific activation cost. The activation cost for any link is restricted by a physical hardware limit to be at least 1 and at most 1,000,000.

Among the installed workstations, a specific subset are designated as **critical**. The headcount of critical workstations is at least 1 and at most the total number of workstations in the facility. All critical workstations must end up connected to each other through the links you activate (either directly or through intermediate relay workstations).

In this facility, the available data links are strictly non-redundant: they connect all workstations, there are exactly one fewer links than the total number of workstations, and between any two workstations there is exactly one possible routing sequence.

Activate a set of data links of minimum total cost so that all critical workstations are connected. Report that minimum total cost.

## Input

The first line contains three integers **n**, **m**, and **t**. The integer **n** is the total number of workstations. The integer **m** is the total number of available data links. The integer **t** is the number of critical workstations. The values of these integers conform to the facility limits described above, and **m** is always exactly **n** − 1.

The second line contains **t** distinct integers: the identifiers of the critical workstations.

Each of the next **m** lines contains three integers **u**, **v**, and **w**, indicating that a data link can join workstation **u** and workstation **v** (**u** ≠ **v**) at a cost of **w**. The cost **w** conforms to the hardware limits described above. The provided links form the non-redundant structure described above, guaranteeing exactly one possible routing sequence between any two workstations.

## Output

Print a single integer: the minimum total activation cost to connect all critical workstations.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1 the critical workstations 1 and 4 are joined only through 2 and 3, so all three links (5+1+2 = 8) are needed. In Example 2 there is one critical workstation, so no links are needed.
