# Problem B — Module Integration Fabric

Time limit: 2 s   Memory limit: 256 MB

## Description

You are engineering the communication backbone for a distributed computing facility. The facility houses **n** processing modules, each assigned a unique integer identifier from 1 to **n**. You are provided with a blueprint of **m** possible bidirectional data conduits. Activating a conduit between its two endpoint modules requires a specific installation cost.

Within the facility, a specific subset of **t** modules are designated as critical processors. Your objective is to choose a subset of the available conduits to activate such that every critical processor can exchange data with every other critical processor. Data transmissions can be forwarded through any activated conduits, passing through non-critical modules as needed.

Calculate the minimum possible total installation cost of the activated conduits that ensures all critical processors are mutually connected.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ **n** ≤ 200000, **m** = **n** − 1, 1 ≤ **t** ≤ **n**). The facility's physical capacity restricts the number of processing modules **n**, while the blueprint provides exactly **m** potential conduits.

The second line contains **t** distinct integers, each between 1 and **n** inclusive: the identifiers of the critical processors.

Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000). These represent a potential bidirectional conduit between module **u** and module **v** with an installation cost **w**.

The system architecture guarantees that activating all **m** conduits would connect all **n** modules into a single fully integrated network. No two conduits connect the same pair of modules.

## Output

Print a single integer representing the minimum total cost to activate a subset of conduits such that all critical processors can communicate with each other.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the critical processors 1 and 4 can only communicate if the data passes through modules 2 and 3. Therefore, all three available conduits (costs 5, 1, and 2) must be activated, giving a total cost of 8.
In Example 2, there is only one critical processor, so no conduits need to be activated and the total cost is 0.
