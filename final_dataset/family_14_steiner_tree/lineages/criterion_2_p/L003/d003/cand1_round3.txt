# Problem B — Priority Connectivity

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a network of **n** nodes, each assigned a unique integer identifier from 1 to **n**. You are provided with a list of **m** possible bidirectional links. Enabling a link between its two endpoint nodes incurs a specific cost. 

Within the network, a specific subset of **t** nodes are designated as priority nodes. Your objective is to choose a subset of the available links to enable such that all priority nodes are in one connected component of the enabled links (non-priority nodes may be used as intermediate vertices).

Minimize the sum of the costs over all enabled links such that all priority nodes are mutually connected.

## Input

The first line contains three integers **n**, **m**, and **t**. The number of nodes **n** is between 1 and 200000. The number of links is exactly **m** = **n** − 1. The number of priority nodes **t** is between 1 and **n**.

The second line contains **t** distinct integers, each between 1 and **n** inclusive: the identifiers of the priority nodes.

Each of the next **m** lines contains three integers **u**, **v**, and **w**. These represent a potential bidirectional link between node **u** and node **v** (where **u** and **v** are distinct integers ranging from 1 to **n** inclusive). The cost **w** of any single link is at least 1 and at most 1000000.

These **m** links guarantee that all **n** nodes are fully connected, meaning there is exactly one simple path between any two nodes.

## Output

Print a single integer representing the minimum total cost to enable a subset of links such that all priority nodes are in the same connected component.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the priority nodes 1 and 4 are in the same connected component only if the simple path passes through nodes 2 and 3. Therefore, all three available links (costs 5, 1, and 2) must be enabled, giving a total cost of 8.
In Example 2, if **t** = 1, the minimum cost is 0 because the one required node is already connected to itself without enabling any links.
