# Problem B — Critical Database Synchronization

Time limit: 2 s   Memory limit: 256 MB

## Description

A corporate data center manages a fleet of servers. You are given a blueprint of proposed fiber-optic connections. Each proposed connection links two specific servers and requires a certain length of fiber to install.

The proposed network follows a strict minimal-wiring policy:
1. The network provides a way for data to route between any two servers in the fleet.
2. There are no redundant connections; removing even a single proposed connection would leave some servers unable to communicate with others.

A subset of these servers host critical databases. Your task is to select and install a subset of the proposed connections such that every critical database can synchronize with every other critical database. Data can seamlessly route through non-critical servers if they are part of the installed connections.

Determine the minimum total length of fiber required to ensure all critical databases are mutually connected.

## Input

The first line contains three integers **n**, **m**, and **t**.
- **n** represents the number of servers. The data center contains at least one server, and its maximum physical capacity caps this at 200,000.
- **m** represents the number of proposed connections. The minimal-wiring policy mandates this is exactly one less than the number of servers.
- **t** represents the number of critical databases. There is at least one critical database, and there can be as many as the total number of servers.

The second line contains **t** distinct integers: the identification numbers of the servers hosting critical databases.

Each of the next **m** lines contains three integers **u**, **v**, and **w**, representing a proposed connection between server **u** and server **v** requiring **w** meters of fiber.
- Server IDs **u** and **v** are distinct and range from 1 to the total number of servers.
- The fiber length **w** is at least 1 meter, and it is limited by the hardware's maximum supported distance of 1,000,000 meters.

It is guaranteed that the proposed connections satisfy the minimal-wiring policy.

## Output

Print a single integer representing the minimum total fiber length to install so that all critical databases can communicate.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, critical databases 1 and 4 can only synchronize if data passes through servers 2 and 3. Therefore, all three proposed connections (lengths 5, 1, and 2) must be installed, giving a total length of 8.
In Example 2, there is only one critical database, so no connections need to be installed and the total length is 0.
