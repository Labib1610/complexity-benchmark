<STATEMENT>
# Problem B — Module Integration Fabric

Time limit: 2 s   Memory limit: 256 MB

## Description

You are tasked with analyzing the fault tolerance of a distributed system's routing sub-network. The system contains **n** processing modules, numbered 1 through **n**. You are given a list of **m** potential bidirectional data conduits. Each conduit can be deployed between a specific pair of modules and has a known installation cost.

There are **t** modules designated as critical processors. A conduit is defined as *indispensable* if there exists at least one pair of critical processors that would have no valid communication path between them if this specific conduit were the ONLY one not deployed (assuming all other $m-1$ conduits are deployed). Data can be relayed through non-critical modules if necessary.

Determine the total installation cost of all *indispensable* conduits.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers: the ID numbers of the critical processors.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), representing a potential conduit between module **u** and module **v** with an installation cost of **w**. The system architecture guarantees that deploying all **m** conduits would successfully connect all **n** modules into a single network.

## Output

Print a single integer representing the total installation cost of all indispensable conduits.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the critical processors are 1 and 4. If the conduit between 1 and 2 is not deployed, 1 and 4 cannot communicate. Thus, it is indispensable (cost 5). The same logic applies to the conduits between 2 and 3 (cost 1) and between 3 and 4 (cost 2). The total cost of indispensable conduits is 5 + 1 + 2 = 8.
In Example 2, there is only one critical processor. Since there are no pairs of critical processors, no conduit can be indispensable. The total cost is 0.
</STATEMENT>
<RATIONALE>
Changed the objective from an optimization task ("minimum cost to connect critical processors") to a structural property check ("sum of costs of all indispensable conduits"). This breaks surface-level pattern matching to Steiner tree algorithms (like leaf pruning). To succeed efficiently without timing out, models must now logically deduce that in a tree, the set of indispensable edges is exactly the minimal subtree spanning the critical nodes, forcing them to derive the intended $O(N)$ DFS.
</RATIONALE>
<PRESERVED_ANSWER>
In a tree, an edge separates at least one pair of critical nodes if and only if it belongs to the minimal subtree spanning those nodes, so the sum of indispensable conduit costs is mathematically identical to the minimum Steiner tree cost.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks for the total weight of the minimal subtree spanning a set of vertices in a tree, which remains solvable in $O(N)$ time via a single depth-first search.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret "no valid communication path" as a directed property, though the terms "bidirectional" and "relayed through" heavily imply undirected connectivity.
</RISK>
