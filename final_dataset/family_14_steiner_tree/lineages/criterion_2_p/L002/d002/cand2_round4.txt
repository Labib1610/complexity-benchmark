# Orbital Station Power Grid

Time limit: 2 s   Memory limit: 256 MB

## Description

An orbital station consists of **n** modules (numbered 1 to **n**). These modules are interconnected by structural transit-tubes. The architecture of the station guarantees that the transit-tube layout connects all modules together such that for every pair of modules there is exactly one continuous route. This ensures the facility is fully contiguous using the absolute minimum number of tubes necessary.

During a low-power emergency, the station commander must power down non-essential areas. However, **t** specific modules contain vital life-support systems. The commander must keep a subset of tubes fully pressurized so that all **t** vital modules remain interlinked. This means every vital module must be able to reach every other vital module (either directly or through intermediate modules) exclusively by traversing pressurized tubes.

Each tube requires a certain amount of power to remain pressurized, and unpressurized tubes cannot be traversed. Determine the minimum total power required to maintain pressurization in a set of tubes that successfully connects all **t** vital modules.

## Input

The first line contains three integers **n**, **m**, and **t**. The station's registry limits the total number of modules **n** to a maximum capacity of 200,000 (with at least 1 module). The number of vital modules **t** is between 1 and **n** inclusive. Because of the station's layout, the number of tubes **m** is always exactly **n** − 1.
The second line contains **t** distinct integers: the identifiers of the vital modules.
Each of the next **m** lines contains three integers **u**, **v**, and **w**, representing a tube linking module **u** and module **v** (where **u** ≠ **v**). The power **w** required to pressurize this tube is at least 1 and capped by the maximum generator output of 1,000,000. These **m** tubes form the exact layout described above, guaranteeing exactly one route between any two modules.

## Output

Print a single integer: the minimum total power required to keep all vital modules connected.

## Examples

### Example 1

**Input**
```

```

**Output**
```
8
```


**Output**
```

```
