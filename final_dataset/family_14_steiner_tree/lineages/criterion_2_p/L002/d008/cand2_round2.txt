<METHOD_NAME>Equivalence Dependency Framing</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the matrix null-space formulation with a system of equivalence dependencies. By removing the explicit "dimension 1" and "null space" keywords, models relying on recognizing the specific linear algebra phrasing of the tree property will fail, while the underlying mathematical structure (a tree of equalities) remains exactly preserved.</METHOD_DESCRIPTION>

<STATEMENT>
# Component Synchronization Dependencies

Time limit: 2 s   Memory limit: 256 MB

## Description

You are configuring a system with $n$ continuous variables, represented as a vector $x \in \mathbb{R}^n$. The $i$-th variable is denoted as $x_i$.

There is a pool of $m$ available equivalence dependencies. Each dependency is specified by two indices $u$ and $v$, and if activated, enforces the strict constraint $x_u = x_v$. Activating this dependency incurs a configuration cost of $w$. You are guaranteed that activating all $m$ available dependencies globally synchronizes the system, forcing all $n$ variables to take the same value. Furthermore, because $m = n - 1$, no available dependency is redundant.

You are given a specific set of $t$ target variables that must be synchronized. You must select a subset of the available dependencies to activate. Your goal is to ensure that for every valid state $x$ satisfying your activated dependencies, the values of $x_i$ for all $t$ target variables are guaranteed to be identical to each other. You may choose to activate dependencies involving non-target variables if they are structurally necessary to enforce this requirement.

Find the minimum total configuration cost of a selected subset of dependencies that achieves this target synchronization. The total cost is simply the sum of the costs $w$ of the dependencies you choose to activate.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$). The available dependencies strictly satisfy the global synchronization guarantee described above.
The second line contains $t$ distinct integers: the indices of the target variables.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing an available dependency that enforces $x_u = x_v$ and requires a cost of $w$ to activate.

## Output

Print a single integer: the minimum total cost of a subset of dependencies whose resulting constraints force all target variables to be equal.

</STATEMENT>
<RATIONALE>
The seed problem guaranteed a null space of dimension 1 for a matrix formed by $m = n-1$ row vectors, which is structurally identical to a tree of $n$ vertices. By reframing the null space property as a system of equivalence dependencies that globally synchronizes the variables, the explicit linear algebra phrasing that models use to trigger tree-path algorithms is removed, while the exact mathematical constraints are preserved.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to enforce $x_u = x_v$ algebraically maps exactly to the seed's requirement of $Bx=0$ for rows with $1$ and $-1$, making the valid subsets and their costs identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the minimum-cost Steiner tree connecting the target components on a tree graph, which maintains its $O(n)$ complexity class.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "for every valid state $x$ satisfying your activated dependencies" as requiring a universally quantified check over all real numbers rather than recognizing it as a simple equality transitive closure, but the algebraic phrasing exactly matches the seed's intent.
</RISK>
