# Polynomial Ideal Generator

Time limit: 2 s   Memory limit: 256 MB

## Description

You are working in the polynomial ring $R = \mathbb{R}[x_1, x_2, \dots, x_n]$ over $n$ variables. 

You are provided with a pool of $m$ available generator polynomials. The $i$-th generator is a binomial of the form $B_i = x_u - x_v$. Adding $B_i$ to your generating set incurs a computational cost of $w$.

To ensure the algebraic structure is well-defined, you are guaranteed that the full pool of $m$ generators is minimally sufficient to generate the ideal of the main diagonal. Specifically, if you let $I_{\text{full}}$ be the ideal generated by all $m$ available binomials, then $x_k - x_l \in I_{\text{full}}$ for all $1 \le k, l \le n$. Furthermore, the available generators are strictly irredundant: removing any single generator from the full pool would strictly shrink the resulting ideal, leaving some differences outside of it. 

You are given a target set of $t$ critical variable indices. You must select a subset of the available generators. Let $I$ be the ideal generated by your chosen subset. Your goal is to ensure that for any pair of critical indices $c_x$ and $c_y$, the difference $x_{c_x} - x_{c_y}$ belongs to the ideal $I$. You may include generators involving non-critical variables if they are necessary to satisfy this algebraic requirement.

Find the minimum total cost of a selected subset of generators that achieves this goal. The total cost is the sum of the costs $w$ of the generators you choose to include.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$). 
The second line contains $t$ distinct integers: the indices of the critical variables.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing an available generator $x_u - x_v$ which requires a cost of $w$ to include.

The provided set of $m$ available generators strictly satisfies the minimal sufficiency guarantee described above.

## Output

Print a single integer: the minimum total cost of a subset of generators whose resulting ideal contains $x_{c_x} - x_{c_y}$ for all pairs of critical variables.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```
*Note: You must ensure $x_1 - x_4 \in I$. By selecting the generators $x_1 - x_2$ (cost 5), $x_2 - x_3$ (cost 1), and $x_3 - x_4$ (cost 2), the ideal generated by these three binomials contains their sum, which is exactly $x_1 - x_4$. The total cost is $5 + 1 + 2 = 8$.*

### Example 2

**Input**
```

3

3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```

```

**Output**


<RATIONALE>
I changed the framing from mechanical synchronization (shafts and belts) to abstract algebra (polynomial rings and ideals). The tree structure is now disguised as a minimally sufficient set of binomial generators for the ideal of the diagonal. This forces models to genuinely reason that $x_u - x_v \in I$ implies a linear combination of differences, mapping algebraically to a unique path in a tree, rather than relying on surface-level graph pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The ideal generated by a subset of binomials $x_u - x_v$ contains $x_a - x_b$ if and only if $a$ and $b$ are in the same connected component of the graph formed by the subset; thus the minimum cost to connect the critical indices is mathematically identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The minimal sufficiency guarantee ensures the input graph is exactly a tree, meaning the minimal connecting subgraph is the unique Steiner tree, which can be found in O(n) time via DFS, keeping the problem in P.
</PRESERVED_CLASS>
<RISK>
Models unfamiliar with polynomial ring ideals might misinterpret the condition $x_u - x_v \in I$ and attempt computationally intractable algebraic algorithms like Gröbner bases instead of recognizing the linear dependence structure.
</RISK>
