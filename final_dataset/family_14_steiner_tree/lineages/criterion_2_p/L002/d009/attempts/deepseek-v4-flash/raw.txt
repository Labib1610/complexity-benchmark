We’re given a tree with `n` nodes, `n-1` edges (each with a cost), and a set of critical nodes.  
We need to activate the minimum total edge cost such that all critical nodes become connected (directly or indirectly), because in a tree, equations create equivalence classes — entire connected components must have equal values đầu.

So the problem reduces to:  
**Given a tree with weighted edgesnk and a set of terminal nodes, find the minimum cost subgraph (i.e., a subtree) that connects all terminal nodes.**

This is a classic *Steiner tree* problem on a tree, which can be solved with dynamic programming in O(n) if the tree is small enough, but here we have up to 200k nodes-button — we need an efficient method.

**Key observation**:  
Because the set of edges is a tree, the minimal connected subgraph containing all critical nodes is the *minimal subtree* that spans them. Its cost = total weight of all edges in that minimal subtree.

Approach:
1. Root the tree at any node (say 1).
2. Compute for each node whether its subtree contains any critical node (and also the minimal cost to connect them in that subtree).
3. Standard DP:  
   - `dp[u]` = minimal cost to connect all critical nodes in subtree of `u` if we are forced to include `u`.  
   - If no critical nodes in subtree → dp[u]=0.  
   - Else dp[u] = sum of (edge_cost + dp[v]) for each child v whose subtree contains a critical node.
4. The answer is the dp value at the root (or at the "highest" node that contains all critical nodes — but considering the root covers everything, but root's dp will include edges above any LCA of critical nodes which we don't want).  
Actually we can do: after computing the `has_critical` and `dp`, we can start DFS and only sum from the topmost node that is in the minimal subtree.

Better:  
- Do a post-order DP. `has[u]` = True if u is critical or any descendant critical.  
- `cost[u]` = sum of `(w + cost[v])` for each child v with `has[v] == True`.  
- Then find the minimal subtree's cost: that's the `cost` at the *root* of the minimal subtree. That root is the node closest to the top that still contains all critical nodes. We can compute it by picking the lowest common ancestor of all critical nodes (or more simply: after DP, the minimal subtree is just the union of paths from each critical node to their LCA).

Simpler:  
We can compute the total cost of all edges in the union of paths from each critical node to a chosen root. Then subtract the cost of edges above the LCA of all critical nodes; but easier is:  
- Pick any critical node as root, do a DFS to compute for each node the total cost to connect all criticals in its subtree.

Implementation:  
1. Read tree as adjacency list.
2. Mark critical nodes.
3. Build DP iteratively (or DFS recursion with increased recursion limit).
4. Start DFS from any critical node (say first critical). Return the `dp[root]`.

Because n up to 200k, DFS recursion could hit recursion limit → use iterative or set recursionlimit(300000) and use sys.setrecursionlimit.

We’ll use iterative post-order to be safe.

Let’s write code.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    critical = set(map(int, input().split()))
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    # Root at first critical node
    root = next(iter(critical))
    
    parent = [0]*(n+1)
    parent_w = [0]*(n+1)
    order = []
    stack = [root]
    parent[root] = -1
    while stack:
        u = stack.pop()
        order.append(u)
        for v, w in adj[u]:
            if v == parent[u]:
                continue
            parent[v] = u
            parent_w[v] = w
            stack.append(v)
    
    has_crit = [False]*(n+1)
    cost = [0]*(n+1)
    
    # Process in reverse order (post-order)
    for u in reversed(order):
        if u in critical:
            has_crit[u] = True
        total_cost = 0
        for v, w in adj[u]:
            if v == parent[u]:
                continue
            if has_crit[v]:
                has_crit[u] = True
                total_cost += w + cost[v]
        cost[u] = total_cost
    
    print(cost[root])

if __name__ == "__main__":
    solve()
```
