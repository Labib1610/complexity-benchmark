<STATEMENT>
# Emergency Pressurization

Time limit: 2 s   Memory limit: 256 MB

## Description

An orbital facility consists of **n** sectors, indexed from 1 to **n**, and **m** structural transit tubes connecting pairs of sectors. The facility's layout ensures that no sector is completely isolated; there is always at least one sequence of tubes connecting any given pair of sectors.

A sudden power grid failure requires the immediate establishment of an emergency isolation perimeter. Within the facility, there are **t** priority sectors housing vital life-support generators. You must select a subset of the transit tubes to remain actively powered. Powered tubes permit passage between their two adjacent sectors, whereas unpowered tubes are sealed tight and cannot be crossed.

The selected subset of powered tubes must form a valid isolation perimeter, meaning it must be possible to travel between any two priority sectors using only the powered tubes. You may route this perimeter through non-priority sectors if necessary.

Each transit tube requires a specific continuous power draw to remain active. Determine the minimum total power draw needed to power a valid subset of tubes that guarantees mutual accessibility among all **t** priority sectors.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ **t** ≤ **n**, 1 ≤ **n** ≤ 200000, **m** = **n** − 1).
The second line provides **t** distinct integers representing the indices of the priority sectors.
Each of the following **m** lines contains three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000). This indicates a transit tube between sector **u** and sector **v** that consumes **w** units of power when active.

## Output

Output a single integer representing the minimum total power draw required to ensure all priority sectors remain mutually accessible.

<RATIONALE>
I removed the explicit textual hint that the facility utilizes the "absolute minimum number of corridors", which previously allowed models to immediately classify the network as a tree. By only providing the `m = n - 1` condition within the numeric constraints, the problem forces the model to actively deduce the tree structure from the input bounds rather than relying on surface-level textual clues. Models failing to make this deduction will likely mistake the problem for a general graph Steiner Tree problem and fail.
</RATIONALE>
<PRESERVED_ANSWER>
The underlying structure remains a connected graph with exactly n-1 edges, so the unique minimum subset of edges connecting the priority sectors and its total cost are exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The input is still guaranteed to be a tree by the connectedness and edge count, so the problem remains in P and can be solved in linear time by pruning unneeded subtrees.
</PRESERVED_CLASS>
