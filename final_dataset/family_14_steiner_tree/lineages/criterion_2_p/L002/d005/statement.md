# Permutation Orbit Optimization

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing the symmetric group $S_n$ acting on a set of $n$ elements $\{1, 2, \dots, n\}$.

There is a proposed set of $m$ generators. Each proposed generator is a transposition defined by a pair of elements $u$ and $v$, representing the operation that swaps $u$ and $v$, and has an associated inclusion cost $w$. You are guaranteed that $m = n - 1$, and that the full set of $m$ proposed transpositions generates the entire symmetric group $S_n$.

You are given a set of $t$ target elements. You must select a subset of the proposed transpositions such that, in the subgroup generated by your selected subset, all $t$ target elements belong to the same orbit. You may include proposed transpositions involving non-target elements if they help satisfy this requirement.

Find the minimum total cost of a selected subset of transpositions that satisfies this requirement. The total cost of a subset is the sum of the inclusion costs $w$ of the transpositions it contains.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$). The proposed transpositions strictly satisfy the $S_n$ generation guarantee described above.
The second line contains $t$ distinct integers: the target elements.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a proposed transposition swapping $u$ and $v$ that requires a cost of $w$ to include.

## Output

Print a single integer: the minimum total cost of a subset of transpositions whose generated subgroup places all target elements in the same orbit.
