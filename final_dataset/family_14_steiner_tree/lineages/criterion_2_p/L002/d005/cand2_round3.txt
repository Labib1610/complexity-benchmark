<METHOD_NAME>Distance Preservation Subgraph</METHOD_NAME>
<METHOD_DESCRIPTION>Shifts the objective from "connectivity" (which models easily pattern-match to a Steiner tree or minimal subtree DP) to "distance preservation" (an isometric subgraph). In a tree, preserving the exact hop-count distances between a set of terminals is mathematically equivalent to finding the minimal connecting subtree, but it forces the model to deduce this equivalence conceptually. Models that fail to bridge this gap will likely write $O(T^2)$ shortest-path algorithms and fail via Time Limit Exceeded.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Distance-Preserving Subnetwork

Time limit: 2 s   Memory limit: 256 MB

## Description

You are designing a routing configuration for a network of **n** server nodes, labeled 1 to **n**.

There is a proposed set of **m** bidirectional communication links. Each proposed link connects two distinct nodes **u** and **v** and requires a monthly maintenance cost of **w** to retain in your final configuration. You are guaranteed that **m** = **n** − 1, and that the full set of **m** proposed links connects all **n** nodes such that there is exactly one valid route (a sequence of links without repeating nodes) between any two nodes.

You are given a list of **t** critical nodes. You must select a subset of the proposed links to retain. To meet strict latency requirements, your retained subset must preserve the exact routing distance between every pair of critical nodes. 

Specifically, for any pair of critical nodes **a** and **b**, the minimum number of links (hop count) required to travel between **a** and **b** using *only* your retained subset must be exactly equal to the number of links on the unique valid route between **a** and **b** in the full proposed network. (If there is no valid route between **a** and **b** in the retained subset, their retained routing distance is considered infinite and the latency requirement is not met).

You may retain links that connect to non-critical nodes if they are necessary to preserve these distances.

Find the minimum total maintenance cost of a retained subset of links that satisfies this requirement. The total cost of a subset is the sum of the maintenance costs **w** of the links it contains.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ **t** ≤ **n**, 1 ≤ **n** ≤ 200000, **m** = **n** − 1). The proposed links strictly satisfy the connectivity guarantee described above.
The second line contains **t** distinct integers: the IDs of the critical nodes.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000), representing a proposed link between nodes **u** and **v** with a maintenance cost of **w**.

## Output

Print a single integer: the minimum total maintenance cost of a subset of links that preserves the exact routing distances between all critical nodes.

**Output**

8

<RATIONALE>
The problem was reframed from a linear span / connectivity requirement to an exact distance preservation (isometric subgraph) requirement. Because the underlying graph is strictly a tree, the only way to preserve the shortest-path distance between any two nodes is to retain the unique path connecting them. This logically forces the exact same minimal subtree solution, but requires the solver to deduce that "distance preservation in a tree" simplifies algebraically to "path inclusion", disrupting pattern-matching to standard Steiner tree templates.
</RATIONALE>
<PRESERVED_ANSWER>
Because the full network is a tree, the only path between any two nodes is the unique path; preserving its hop-count distance requires selecting all edges on that unique path, meaning the minimal valid subset is exactly the minimal connected subgraph containing all critical nodes, which matches the seed's required subset.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem mathematically reduces to finding the minimum-cost subtree spanning a set of terminal nodes in a tree, which is solvable in O(N) time via DFS/DP, preserving the polynomial complexity class.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret "minimum number of links" as minimizing the sum of weights, but the explicit clarification "(hop count)" and the separate optimization target "total maintenance cost" minimizes this risk.
</RISK>
