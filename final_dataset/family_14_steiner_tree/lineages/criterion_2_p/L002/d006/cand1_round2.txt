# Directed Routing Optimization

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a connected undirected graph $G = (V, E)$ with $n$ vertices and $m = n - 1$ edges. Because it is a connected graph with $n-1$ edges, it is guaranteed to be a tree, meaning there is exactly one simple path between any two vertices.

You are given a set of $t$ target vertices.
Your task is to select a subset of edges $S \subseteq E$.
The selected subset $S$ is considered valid if it is possible to assign a direction to each edge in $S$ such that the following condition holds:
There must exist at least one vertex $r$ (which can be any vertex in the graph, target or non-target) such that for every target vertex $x$, there is a valid directed path from $r$ to $x$ consisting entirely of directed edges from $S$. 
*(Note: A vertex is always considered to have a directed path of length 0 to itself, requiring no edges.)*

Each undirected edge has an inclusion cost $w$. If an edge is included in your subset $S$, you must pay its cost, regardless of the direction it is eventually assigned.
Find the minimum total cost of a selected subset of edges $S$ that satisfies this requirement. The total cost is the sum of the inclusion costs of the edges in $S$.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$). The graph is guaranteed to be a tree as described above.
The second line contains $t$ distinct integers: the identifiers of the target vertices (vertices are numbered from 1 to $n$).
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing an undirected edge between vertex $u$ and vertex $v$ that requires a cost of $w$ to include.

## Output

Print a single integer: the minimum total cost of a subset of edges $S$ that can be oriented to satisfy the directed path requirement.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```
