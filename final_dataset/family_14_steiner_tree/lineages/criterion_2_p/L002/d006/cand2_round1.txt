# Sensor Network Calibration

Time limit: 2 s   Memory limit: 256 MB

## Description

You are programming the calibration system for an array of $n$ independent sensors. 

There is a proposed set of $m$ calibration routines. Each routine synchronizes a specific pair of sensors $u$ and $v$, enforcing the operational constraint that their readings are identical ($R_u = R_v$). Each routine has an associated hardware lock cost $w$. You are guaranteed that $m = n - 1$, and that the full set of $m$ routines is structurally complete (meaning if all $m$ constraints are enforced, all $n$ sensors are forced to yield the exact same reading).

You are given a subset of $t$ "baseline" sensors. 

During the system's operation, exactly one unlocked calibration routine will experience a hardware fault. When a routine between $u$ and $v$ faults, it enforces a shifted constraint $R_u = R_v + \Delta$ (for some unknown, non-zero error $\Delta$) instead of $R_u = R_v$. All other routines, whether locked or unlocked, will continue to function normally and enforce strictly identical readings for their respective pairs.

You must choose a subset of the routines to permanently lock. A locked routine is immune to faults. Your selection must guarantee that, regardless of which single unlocked routine experiences the fault, the readings of all $t$ baseline sensors will remain perfectly identical to each other. 

Find the minimum total lock cost required to satisfy this guarantee. The total cost is the sum of the lock costs $w$ of the routines you choose to lock.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$). The proposed routines strictly satisfy the structural completeness guarantee described above.
The second line contains $t$ distinct integers: the indices of the baseline sensors.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a proposed calibration routine between sensor $u$ and sensor $v$ that requires a cost of $w$ to lock.

## Output

Print a single integer: the minimum total cost of a selected subset of routines that guarantees all baseline sensors maintain identical readings under any single fault of an unlocked routine.

## Examples


**Output**
```
8
```

<RATIONALE>
The problem was reframed from finding a connected component (or orbit) to an adversarial game on a system of linear constraints. By specifying that a single unlocked constraint will fail by introducing a non-zero shift $\Delta$, the model is forced to recognize that any failed constraint splits the sensor values into two distinct sets. To prevent the baseline sensors from diverging, no unlocked constraint can be one that partitions the baseline sensors—meaning exactly the edges of the Steiner subtree must be locked.
</RATIONALE>
<PRESERVED_ANSWER>
Because the constraints form a tree, a fault on any routine shifts the values of the two resulting components; thus, to keep all baseline sensors identical, every routine on any path between baseline sensors must be locked, which perfectly matches the minimum spanning tree of the targets in the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains identical (finding the minimal subtree connecting a set of target nodes in a tree), which is solvable in $O(n)$ time using a tree traversal.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "regardless of which single unlocked routine experiences the fault" if they assume multiple faults can happen simultaneously, but the wording "exactly one" and "single unlocked routine" explicitly prevents this.
</RISK>
