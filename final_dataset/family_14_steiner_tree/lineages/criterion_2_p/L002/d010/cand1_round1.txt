Full Row Rank Framing
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the explicit topological guarantee ("minimally sufficient to collapse the variables") with a purely linear-algebraic guarantee ("the coefficient matrix has full row rank"). For a system of $m = n - 1$ difference equations, full row rank mathematically implies that the nullity is 1 (the solution space is exactly the all-ones vector), which means the underlying dependency graph is a spanning tree. This forces the model to independently perform the linear algebra deduction to discover it's a tree; models that fail to make this connection will likely attempt general Steiner Tree algorithms or algebraic solvers and TLE.
</METHOD_DESCRIPTION>

<STATEMENT>
# Sparse Linear Subsystem Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a homogeneous linear system over $n$ real variables $x_1, x_2, \ldots, x_n$.

You are provided with a pool of $m$ candidate equations. Each candidate equation is specified by two indices $u$ and $v$ and an activation cost $w$. Activating this candidate adds the equation $x_u - x_v = 0$ to your system.

To ensure the system is well-posed, you are guaranteed that the coefficient matrix formed by the full pool of $m$ candidate equations has full row rank. 

You are given a target set of $t$ critical variables. You must select a subset of the candidate equations to activate. Your objective is to ensure that in the solution space of the resulting subsystem, the condition $x_i = x_j$ is algebraically entailed for all pairs of critical variables $i, j$. You may activate equations involving non-critical variables if they are necessary to establish this entailment.

It is guaranteed that a valid selection of equations always exists.

Find the minimum total activation cost of a selected subset of equations that achieves this objective. The total cost is the sum of the activation costs $w$ of the equations you choose to activate.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$). 
The second line contains $t$ distinct integers: the indices of the critical variables.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a candidate equation $x_u - x_v = 0$ which requires a cost of $w$ to activate.

The provided set of $m$ candidate equations strictly satisfies the full row rank guarantee described above.

## Output

Print a single integer: the minimum total activation cost of a subset of equations whose activation algebraically entails that all critical variables must take the same value.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

<RATIONALE>
Removed the explicit hand-holding text ("minimally sufficient to collapse the variables to a single value" and "omitting any single equation... would increase the dimension") which models used to explicitly justify that the graph is a spanning tree. It is replaced with the rigorous algebraic property that the coefficient matrix has full row rank, forcing models to deduce the acyclic topological structure from linear algebra principles rather than reading it directly from the prompt.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical condition of full row rank for $n-1$ difference equations exactly defines a spanning tree, meaning the valid subsets and their costs are identical to the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Because the underlying structure is mathematically guaranteed to be a spanning tree, the optimal solution remains the unique minimal subtree connecting the critical nodes, which is computable in $O(n)$ time (Class P).
</PRESERVED_CLASS>
<RISK>
Models might mistakenly assume that $m = n - 1$ allows for disconnected components with cycles if they fail to understand the implications of "full row rank", but this is a failure of their mathematical reasoning rather than an ambiguity in the statement.
</RISK>
