We are given a tree (since \( S = R - 1 \)) and a set of mandatory nodes.  
We need to find the minimum cost to connect all mandatory nodes, which is the weight of the minimal subtree that contains all mandatory nodes.

The minimal subtree containing a set of nodes in a tree is the union of all paths between those nodes.  
Its total edge weight can be computed by:

1. Mark all mandatory nodes.
2. Perform a DFS to compute for each edge whether it lies on a path between two mandatory nodes.
3. Sum the weights of those edges.

We can do this efficiently with a DFS that returns whether a subtree contains any mandatory node.  
If both sides of an edge contain at least one mandatory node, that edge must be included.

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    R, S, P = map(int, input().split())
    mandatory = set(map(int, input().split()))
    
    adj = [[] for _ in range(R + 1)]
    for _ in range(S):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    visited = [False] * (R + 1)
    total_cost = 0
    
    def dfs(u):
        nonlocal total_cost
        visited[u] = True
        has_mandatory = u in mandatory
        for v, w in adj[u]:
            if not visited[v]:
                child_has = dfs(v)
                if child_has and has_mandatory:
                    total_cost += w
                has_mandatory = has_mandatory or child_has
        return has_mandatory
    
    # Start from any mandatory node
    start = next(iter(mandatory))
    dfs(start)
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
