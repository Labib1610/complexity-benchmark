<METHOD_NAME>Subset-Induced Edge Cost Transformation</METHOD_NAME>
<METHOD_DESCRIPTION>Reframe the problem from finding a minimal spanning tree of terminals to selecting an optimal subset of vertices that induces a connected subgraph. The cost is the sum of all edges induced by the subset. Since the base graph is a tree, any connected induced subgraph is a subtree, and the minimal one spanning the required vertices is the unique minimal subtree. This masks the standard Steiner-tree-on-trees formulation by framing it as a node-selection and induced-edge problem.</METHOD_DESCRIPTION>

# Phase 2: Cohesive Subsystems

Time limit: 2 s   Memory limit: 256 MB

## Description

A system contains $R$ distinct components, numbered 1 to $R$. There are $S$ available integrations between certain pairs of components.

During a configuration phase, $P$ specific components are mandated to be active.

You must select a subset of the $R$ components to form a unified subsystem. To be valid, your selected subset must satisfy two conditions:
1. It must include all $P$ mandated components (it may also include any number of other components).
2. The selected components must be cohesive. This means that for any two components in your subset, it must be possible to transition between them using a sequence of integrations where every component in the sequence is part of your selected subset. If your subset consists of exactly one component, this condition is considered satisfied.

When you select a subset of components, any available integration that connects two selected components becomes "internalized". Integrations where at least one component is not selected remain uninternalized.

Each integration has a specific weight. The total cost of your subsystem is the sum of the weights of all internalized integrations. Find the minimum possible total cost to form a valid subsystem.

## Input

The first line contains three integers $R$, $S$, and $P$. 
The total number of components $R$ has a minimum of 1 and a maximum capacity equivalent to 400 racks, each holding exactly 500 components. 
The number of integrations $S$ is exactly one less than $R$. 
The number of mandated components $P$ ranges from 1 up to $R$ inclusive.

The second line contains $P$ distinct integers: the identifiers of the mandated components.

Each of the next $S$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le R$, $u \neq v$). This represents an integration between component $u$ and component $v$ with a weight $w$. The weight $w$ is at least 1 and can reach up to a maximum limit of $1000^2$. 

The integrations provided in the input guarantee that all $R$ components are fully connected, such that there is exactly one sequence of integrations between any two components without repeating integrations.

## Output

Print a single integer: the minimum total weight of a valid selected subsystem.


<RATIONALE>
Reframed the problem from finding a minimal spanning subtree of terminals to selecting an optimal subset of vertices that induces a cohesive subgraph. The cost is defined as the sum of all edges induced by the subset, which mathematically matches the original tree-connection task but forces models to reason about subset-induced edges rather than standard tree-routing algorithms. The word "trivially" was removed to pass the vocabulary gate, and bounds were made indirect as requested.
</RATIONALE>
<PRESERVED_ANSWER>
The cost of any valid subset is the sum of induced edges; on a tree, any connected induced subgraph is a subtree, so the unique minimal subtree spanning the mandated components still minimizes this cost.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying graph is still a tree and the goal is still to find the minimal subtree spanning a set of vertices, which remains solvable in linear time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "sequence of integrations where every component in the sequence is part of your selected subset" if they assume edges can be traversed without both endpoints being in the subset, but the text explicitly requires all components in the sequence to be selected.
</RISK>
