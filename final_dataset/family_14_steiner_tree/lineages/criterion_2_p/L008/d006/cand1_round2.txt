# Sub-Network Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system defined by a universal set $U$ of $R$ elements (identified by integers 1 through $R$) and a collection $E$ containing $S$ unordered pairs of these elements. A target subset $K \subseteq U$ containing $P$ elements is specified for activation.

A subset $Z \subseteq U$ is defined as *cohesive* if it satisfies two conditions:
1. It contains every element of the target subset ($K \subseteq Z$).
2. For any two elements $a, b \in Z$, there exists a sequence of elements $x_1, x_2, \dots, x_m$ all belonging to $Z$ such that $x_1 = a$, $x_m = b$, and for every index $i$ from $1$ to $m-1$, the unordered pair $\{x_i, x_{i+1}\}$ is present in $E$. (If $Z$ contains only a single element, this condition is trivially met).

When a subset $Z$ is chosen, an unordered pair from $E$ is considered *internalized* if both of its elements belong to $Z$. Each pair in $E$ has a given scalar weight. The total weight of a cohesive subset $Z$ is the sum of the scalar weights of all its internalized pairs.

Your objective is to determine the minimum possible total weight of a valid cohesive subset $Z$.

## Input

The first line contains three integers $R$, $S$, and $P$. 
The parameters satisfy $1 \le R \le 200,000$, $S = R - 1$, and $1 \le P \le R$. 

The second line contains $P$ distinct integers: the identifiers of the elements in the target subset $K$.

Each of the following $S$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le R$, $u \neq v$). This indicates that the unordered pair $\{u, v\}$ is in $E$ and has a scalar weight of $w$ ($1 \le w \le 1,000,000$). 

It is guaranteed that the entirety of $U$ is cohesive, and the collection $E$ is strictly minimal to achieve this (if any single pair were removed from $E$, $U$ would cease to be cohesive).

## Output

Print a single integer representing the minimum total weight among all valid cohesive subsets $Z$.

<RATIONALE>
The problem was completely stripped of graph-theoretic vocabulary (nodes, links, connected components, subtrees) and recast in terms of sets, unordered pairs, and sequences. The tree guarantee was replaced with exactly equivalent algebraic axioms of minimal cohesiveness and $S = R - 1$. This forces the model to independently deduce that the minimum cohesive subset corresponds to the unique minimal spanning subtree without relying on semantic keywords to trigger a DFS boilerplate.
</RATIONALE>
<PRESERVED_ANSWER>
The definition of a cohesive subset is mathematically identical to an induced connected subgraph, and internalized pairs exactly match the active edges within that subgraph; thus minimizing the sum of internalized pairs yields the exact same minimum subtree cost.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying mathematical structure remains finding the minimal Steiner tree on a graph guaranteed to be a tree, which is solvable in linear time ($O(N)$) using identical logic to the seed problem.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the sequence definition as requiring distinct elements (a simple path), but since existence of any sequence implies existence of a simple sequence in this structure, it does not alter the mathematical validity of the cohesive definition.
</RISK>
