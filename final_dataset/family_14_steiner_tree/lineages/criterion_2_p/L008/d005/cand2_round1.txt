<STATEMENT>
# Phase 2: Signal Convergence

Time limit: 2 s   Memory limit: 256 MB

## Description

A neuro-computational core consists of a set of nodes and a set of available bidirectional links between these nodes. 

The core is fully integrated, meaning a signal can be routed between any two nodes in the network. The density of the connections is strictly regulated by a structural invariant: if you were to allocate one baseline energy unit to every node in the core, and then deduct one energy unit for every available link provided in the network blueprint, the final net energy of the core would be exactly one unit.

During a diagnostic test, a specific group of nodes is injected with a trace signal. 

Your objective is to coordinate a synchronization event. You must supply power to a chosen selection of the available links. The selection must be capable of routing the trace signals from all injected nodes to at least one common meeting node anywhere in the core. The signals can travel any distance and in any direction, but they can only move across links that you have powered on. The meeting node does not have to be one of the originally injected nodes.

Each link requires a certain amount of power to activate. Determine the absolute minimum total power required to activate a selection of links that satisfies this requirement. The total power is the sum of the power requirements of the distinct links you choose to activate.

## Input

The first line contains three integers $R$, $S$, and $P$. The total number of nodes $R$ is capped at exactly two hundred thousand by the hardware's capacity. The number of links $S$ strictly follows the structural invariant described above. The number of injected nodes $P$ is at least one and can be up to the total number of nodes $R$.

The second line contains $P$ distinct integers representing the identifiers of the injected nodes.

Each of the subsequent $S$ lines contains three integers $u$, $v$, and $w$. This indicates an available bidirectional link between node $u$ and node $v$ requiring $w$ units of power to activate. The power requirement $w$ is a positive integer not exceeding one million. The nodes are numbered from $1$ to $R$.

## Output

Print a single integer: the minimum total power required to activate the chosen selection of links.

<RATIONALE>
I removed all explicit references to the network being a tree (such as "S = R - 1" or "zero redundancy"). Instead, I defined the exact same mathematical structure using an algebraic invariant disguised as a physical property (Nodes - Links = 1). This forces the model to deduce the tree structure mathematically; models relying on surface-level keyword matching will likely fail to recognize it and attempt to use a general graph Steiner Tree algorithm, which will Time Limit Exceed.
</RATIONALE>
<PRESERVED_ANSWER>
The required subgraph is still exactly the minimal connecting network for the injected nodes, so the minimal cost remains the sum of the edge weights in that unique subtree.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Because the graph remains a connected network with V - E = 1, it is mathematically guaranteed to be a tree, keeping the problem solvable in O(N) time.
</PRESERVED_CLASS>

</RISK>
