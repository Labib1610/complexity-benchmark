# Phase 2: High-Priority Routing

Time limit: 2 s   Memory limit: 256 MB

## Description

A cybersecurity firm is upgrading a facility's hardware, executing the project in three phases.

**Phase 1: Facility Survey.** The facility contains $R$ equipment rooms. Engineers have mapped out $S$ bidirectional conduit links between specific pairs of rooms. They have confirmed that data can be routed between any two rooms in the facility by traversing a sequence of these mapped links.

**Phase 2: Cable Planning.** The client has designated $P$ specific rooms as high-priority. You must decide which of the mapped conduit links will be equipped with fiber optic cables. The installed cables must ensure that every high-priority room can transmit data to every other high-priority room. Data can pass through any room (priority or non-priority) as long as it travels along the cabled links. You are given the cost to install cable in each link. Your objective is to determine the minimum total installation cost for the chosen links.

**Phase 3: Procurement.** The finance department receives your minimum cost calculation, applies a 20% markup, and finalizes the budget.

Write a program to complete Phase 2. Using the survey data and the list of high-priority rooms, output the minimum installation cost before any markups.

## Input

The first line contains three integers $R$, $S$, and $P$ ($1 \le P \le R \le 200000$). The number of mapped links $S$ is always exactly $R - 1$.
The second line contains $P$ distinct integers representing the high-priority rooms.
Each of the next $S$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le R$, $u \neq v$, $1 \le w \le 1000000$), indicating a conduit link between room $u$ and room $v$ with an installation cost of $w$.
The provided links are guaranteed to satisfy the full-facility routing confirmed in Phase 1.

## Output

Print a single integer: the minimum total installation cost determined in Phase 2.
