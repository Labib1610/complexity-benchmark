**Solution Explanation**

For the given tree we have to activate a set of edges whose total weight is minimal
and that makes all *compromised* (special) vertices belong to one connected component.
The tree may contain many non‑special vertices that can be used as intermediate
vertices.

--------------------------------------------------------------------

#### 1.  Observation – Steiner tree on a tree  

In a general graph the problem is the *Steiner tree* problem.
On a **tree** it becomes trivial:

*The cheapest subgraph that connects a given set of vertices is exactly the
union of all simple paths between them.*

Why?  
Every edge of the tree is the only possible way to go from one side of the
edge to the other side.  
If both sides contain at least one special vertex, the edge is unavoidable,
otherwise it can be omitted.  
Consequently the optimal subgraph is the **minimal subtree** that contains all
special vertices – obtained by repeatedly deleting leaf vertices that are not
special.

Therefore the answer is simply the sum of the weights of all edges whose
removal would separate the set of special vertices into two non‑empty parts.

--------------------------------------------------------------------

#### 2.  Reducing the condition to a subtree size count  

Root the tree arbitrarily (vertex 1).  
For each vertex `v` let  

```
cnt[v] = number of special vertices in the subtree of v (including v itself)
```

For the edge `parent(v) – v` :

* the edge is needed **iff** `0 < cnt[v] < P`  
  (some specials are inside the subtree, some are outside).

So we only have to know `cnt[v]` for every vertex.

--------------------------------------------------------------------

#### 3.  Computing `cnt` in one DFS  

`R ≤ 200 000`, recursion would overflow, therefore an explicit stack is used.

* First DFS (iterative) – store the order in which vertices are visited
  (`order`) and the parent of each vertex together with the weight of the
  connecting edge.
* Process `order` backwards (post‑order).  
  For a vertex `v`

```
cnt_here = (1 if v is special else 0) + sum of cnt of already processed children
```

  The sum of children is already stored in `cnt[v]` because each child,
  when processed, added its total to its parent.
* While processing `v` we already know `cnt_here`.  
  If `v` is not the root and `0 < cnt_here < P` we add the edge weight to the
  answer.
* Finally we add `cnt_here` to `cnt[parent[v]]` (if a parent exists) – this
  propagates the information upward.

All operations are `O(R)`.

--------------------------------------------------------------------

#### 4.  Correctness Proof  

We prove that the algorithm outputs the weight of the minimum required set of
edges.

---

##### Lemma 1  
For any edge `e = (parent, child)` in the rooted tree,
`e` belongs to the minimal connecting subtree of the special vertices  
iff `0 < cnt[child] < P`.

**Proof.**  
Removing `e` separates the tree into two components:
* the subtree of `child`
* the rest of the tree.

If the subtree contains no special vertex (`cnt[child]=0`) or all specials
(`cnt[child]=P`), the two components are not both needed for connecting the
special set, therefore `e` can be omitted.  
Otherwise each side contains at least one special vertex, so any connected
subgraph that contains all specials must contain a path crossing `e`; because
the tree has a unique path, `e` itself is that path. ∎



##### Lemma 2  
The algorithm adds exactly the weights of all edges satisfying the condition
of Lemma&nbsp;1.

**Proof.**  
During the backward processing of `order` the variable `cnt_here` equals the
true `cnt[child]` for the current vertex `child`.  
The algorithm checks `0 < cnt_here < P` and, if true, adds the stored weight of
the edge to the answer. No other edges are added. ∎



##### Lemma 3  
The sum produced by the algorithm equals the total weight of the minimal
subtree that contains all special vertices.

**Proof.**  
By Lemma&nbsp;1 the minimal subtree consists precisely of the edges whose
removal would split the special set, i.e. the edges with `0 < cnt < P`.  
By Lemma&nbsp;2 the algorithm sums exactly the weights of those edges.
Therefore the two sums are identical. ∎



##### Theorem  
The algorithm outputs the minimum possible total activation cost that makes all
compromised vaults mutually reachable.

**Proof.**  
The minimal possible cost is the weight of the minimal subtree connecting all
special vertices (definition of the problem).  
By Lemma&nbsp;3 the algorithm outputs exactly this weight. Hence the output is
optimal. ∎



--------------------------------------------------------------------

#### 5.  Complexity Analysis  

*Building adjacency list* : `O(R)` time, `O(R)` memory.  
*Iterative DFS & post‑order processing* : `O(R)` time, `O(R)` additional memory
(for stacks, parent array, counters).  

Overall  

```
Time   : O(R)   ( ≤ 2·10⁵ operations, easily fits 2 s )
Memory : O(R)
```

--------------------------------------------------------------------

#### 6.  Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)

    R = next(it)          # number of vertices
    S = next(it)          # always R-1
    P = next(it)          # number of special vertices

    special = [False] * (R + 1)
    for _ in range(P):
        special[next(it)] = True

    adj = [[] for _ in range(R + 1)]
    for _ in range(S):
        u = next(it)
        v = next(it)
        w = next(it)
        adj[u].append((v, w))
        adj[v].append((u, w))

    # ---------- iterative DFS to obtain parent, edge weight and order ----------
    parent = [0] * (R + 1)          # parent[1] stays 0 (root)
    parent_w = [0] * (R + 1)       # weight of edge to parent
    order = []                     # visitation order (preorder)
    stack = [1]
    parent[1] = -1                 # mark root

    while stack:
        u = stack.pop()
        order.append(u)
        for v, w in adj[u]:
            if v != parent[u]:
                parent[v] = u
                parent_w[v] = w
                stack.append(v)

    # ---------- post‑order processing ----------
    cnt = [0] * (R + 1)            # temporary accumulator for children
    answer = 0

    for u in reversed(order):
        # total specials in the subtree rooted at u
        total = cnt[u] + (1 if special[u] else 0)

        if u != 1:                 # root has no edge to parent
            if 0 < total < P:
                answer += parent_w[u]
            cnt[parent[u]] += total

    print(answer)


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
