We can model the network as a tree (since it has exactly R−1 edges and is connected).  
We need the minimal total edge cost to connect all P compromised nodes.  
That’s the **Steiner tree** problem on a tree, which has a simple solution:

- Take the set of compromised nodes.
- The optimal solution is the minimal subtree connecting them — which is the union of paths between them.
- To compute this efficiently, we can:
  1. Root the tree at any compromised node.
  2. For each edge, decide if it is needed: an edge is needed if there are compromised nodes in both sides of it.
  3. We can compute this by DFS counting compromised nodes in each subtree.

Algorithm:

1. Read input, build adjacency list.
2. Mark which nodes are compromised.
3. DFS from any node (say 1) to compute:
   - `sub_count[node]`: number of compromised nodes in subtree.
4. For each edge (parent–child) in DFS tree:
   - If `0 < sub_count[child] < P`, then this edge is needed.
   - Add its cost.
5. Output the sum.

This runs in O(R).

```python
import sys
sys.setrecursionlimit(1 << 20)

def solve():
    input_data = sys.stdin.read().strip().split()
    it = iter(input_data)
    R = int(next(it))
    S = int(next(it))
    P = int(next(it))
    
    compromised = set()
    for _ in range(P):
        compromised.add(int(next(it)))
    
    tree = [[] for _ in range(R + 1)]
    for _ in range(S):
        u = int(next(it))
        v = int(next(it))
        w = int(next(it))
        tree[u].append((v, w))
        tree[v].append((u, w))
    
    # If P == 1, no edges needed
    if P == 1:
        print(0)
        return
    
    parent = [0] * (R + 1)
    parent_cost = [0] * (R + 1)
    order = []
    stack = [1]
    parent[1] = -1
    while stack:
        u = stack.pop()
        order.append(u)
        for v, w in tree[u]:
            if v != parent[u]:
                parent[v] = u
                parent_cost[v] = w
                stack.append(v)
    
    sub_count = [0] * (R + 1)
    for u in order:
        if u in compromised:
            sub_count[u] = 1
    
    total_cost = 0
    for u in reversed(order):
        if u == 1:
            continue
        if sub_count[u] > 0 and sub_count[u] < P:
            total_cost += parent_cost[u]
        p = parent[u]
        sub_count[p] += sub_count[u]
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
