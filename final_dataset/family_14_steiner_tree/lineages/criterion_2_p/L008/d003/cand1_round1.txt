# Phase 2: High-Priority Routing

Time limit: 2 s   Memory limit: 256 MB

## Description

A cybersecurity firm is upgrading a facility's hardware. The client has designated $P$ specific equipment rooms (out of $R$ total rooms, numbered 1 to $R$) as high-priority. The project is divided into three distinct phases:

**Phase 1: Facility Survey.** Engineers map out $S$ available bidirectional conduit segments between the $R$ rooms. The engineers verify that these mapped segments provide a valid communication path between any two high-priority rooms in the facility. (They do not verify paths to non-priority rooms, which may be entirely disconnected from the main network).

**Phase 2: Cable Planning.** You are responsible for this phase. The high-priority rooms must all be able to exchange data with one another, either directly or by passing data through a sequence of intermediate rooms. You are given the cost of installing fiber optic cable in each mapped conduit segment. You must choose a subset of the available segments to cable such that all high-priority rooms are interconnected. Calculate the minimum possible total installation cost to achieve this requirement.

**Phase 3: Procurement.** The finance department takes your calculated minimum cost, adds a 20% markup for price fluctuations, and approves the final budget.

Your task is to write a program that executes Phase 2. Given the survey data from Phase 1 and the list of high-priority rooms, output the exact minimum cost before any Phase 3 markups are applied.

## Input

The first line contains three integers $R$, $S$, and $P$ ($1 \le P \le R \le 200000$). The number of segments $S$ is always exactly $R - 1$.
The second line contains $P$ distinct integers: the identifiers of the high-priority rooms.
Each of the next $S$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le R$, $u \neq v$, $1 \le w \le 1000000$): a conduit segment joining room $u$ and room $v$ at an installation cost of $w$. 
The segments provided in the input are guaranteed to satisfy the conditions verified in Phase 1.

## Output

Print a single integer: the minimum total cost calculated in Phase 2.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3

```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

Moved the definition of priority rooms to the introduction and modified the Phase 1 guarantee as instructed. By explicitly stating that non-priority rooms may be disconnected, the global tree guarantee ($S=R-1$ and fully connected) is removed. Models that rely on assuming the network is a tree will now have to consider general graph connectivity and cycles for the relevant rooms, forcing them to attempt harder Steiner tree approaches instead of simple tree pruning.
</RATIONALE>
