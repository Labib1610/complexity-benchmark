# Phase 2: High-Priority Routing

Time limit: 2 s   Memory limit: 256 MB

## Description

A cybersecurity firm is upgrading the communication hardware of a facility. The project is divided into three distinct phases.

**Phase 1: Facility Survey.** Engineers map out available bidirectional conduit segments between the equipment rooms. The rooms are numbered consecutively starting from 1. To ensure compatibility with legacy 18-bit addressing systems, the total number of rooms is capped at the largest multiple of 100,000 that can be stored in an 18-bit unsigned integer. The number of mapped segments is always exactly one less than the total number of rooms. The engineers verify that these mapped segments provide a valid communication path between all high-priority rooms. Note that Phase 1 did not verify full facility connectivity; some non-priority rooms may be completely isolated. Consequently, to maintain the total segment count, redundant cyclic links may exist elsewhere in the facility. However, the engineers guarantee a strict structural property: all high-priority rooms are situated within a portion of the network that contains no redundant paths, meaning there is exactly one unique simple path between any pair of high-priority rooms.

**Phase 2: Cable Planning.** You are responsible for this phase. The client has designated a subset of the rooms (at least one, up to the total number of rooms) as high-priority. These high-priority rooms must all be able to exchange data with one another, either directly or by passing data through a sequence of intermediate rooms. You are given the cost of installing fiber optic cable in each mapped conduit segment; this cost is a positive integer that never exceeds the square of 1,000. You must choose a subset of the available segments to cable such that the high-priority rooms are all interconnected. Calculate the minimum possible total installation cost to achieve this requirement.

**Phase 3: Procurement.** The finance department takes your calculated minimum cost, adds a 20% markup for price fluctuations, and approves the final budget.

Your task is to write a program that executes Phase 2. Given the survey data from Phase 1 and the list of high-priority rooms, output the exact minimum cost before any Phase 3 markups are applied.

## Input

The first line contains three integers: the total number of rooms, the number of mapped segments, and the number of high-priority rooms.
The second line contains distinct integers representing the identifiers of the high-priority rooms.
Each of the subsequent lines (one for each mapped segment) contains three integers $u$, $v$, and $w$, representing a conduit segment joining room $u$ and room $v$ at an installation cost of $w$.
The segments provided in the input are guaranteed to satisfy the communication paths verified in Phase 1.

## Output

Print a single integer: the minimum total cost calculated in Phase 2.

State bounds indirectly using physical and system constraints (e.g., 18-bit unsigned integer limits). Replaced the global connectivity guarantee with a guarantee that only high-priority rooms are mutually reachable and isolated from cycles. This forces models to carefully read the structural guarantees rather than blindly assuming a global tree based on $S = R - 1$, penalizing models that pattern-match "cycles" into writing exponential general Steiner tree algorithms.
</RATIONALE>
