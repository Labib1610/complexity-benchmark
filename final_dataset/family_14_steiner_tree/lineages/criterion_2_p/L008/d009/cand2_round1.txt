<STATEMENT>
# Equilibrium Integration

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of $R$ distinct resonant entities. There are $S$ bidirectional harmonic links, each connecting a pair of entities. The system's architecture was established through a precise sequential growth process: starting with a single initial entity, each of the $S$ links introduced exactly one new entity to the system by pairing it with an already-incorporated entity, until all $R$ entities were integrated.

A recent protocol requires that a specific set of $P$ entities must be activated. You may additionally activate any other entities you choose. 

A link becomes *saturated* if both of its entities are activated. If one or neither of its entities is activated, the link remains dormant. Activating entities incurs a cost based on the saturated links. Each link has a characteristic penalty $w$, and if it becomes saturated, it adds $w$ to the total system cost. Dormant links contribute 0.

To maintain system equilibrium, your chosen set of activated entities must satisfy a strict balance condition: the total number of saturated links must be exactly one less than the total number of activated entities.

Your objective is to determine the minimum possible total penalty of the saturated links such that all $P$ mandated entities are activated and the balance condition is satisfied.

## Input

The first line contains three integers $R$, $S$, and $P$. 
The maximum possible value for $R$ is the number of millimeters in 200 meters. The minimum is 1. 
The value of $S$ is exactly the amount required to form the system through the sequential single-entity integration process. 
The number of mandated entities $P$ is between 1 and $R$ inclusive.

The second line contains $P$ distinct integers representing the identifiers of the mandated entities.

Each of the following $S$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le R$, $u \neq v$). This indicates a link between entity $u$ and entity $v$ with a characteristic penalty of $w$. The penalty $w$ is a positive integer no greater than the square of 1000. 

## Output

Output a single integer representing the minimum possible total penalty of the saturated links under the given conditions.

<RATIONALE>
The explicit guarantees of "minimally cohesive" and "synchronous" (connectedness) have been completely removed. Instead, the tree structure is guaranteed via a generative description ("sequential single-entity integration"), and the connectedness requirement is replaced with its exact algebraic equivalent for forests: the number of induced edges must equal the number of vertices minus one. Models that fail to deduce this topological equivalence will likely attempt to track vertex and edge counts algebraically (e.g., via a 2D dynamic programming approach) which will inevitably exceed the time limit on N=200,000, whereas models that genuinely reason about the structure will still recognize it as a Steiner tree problem. Numeric bounds have also been replaced with physical/arithmetic equivalents to prevent simple pattern matching on constraint shapes.
</RATIONALE>
<PRESERVED_ANSWER>
Because the full graph is generated by adding one vertex per edge, it is guaranteed to be a tree; in a tree, any subset of vertices induces a forest, and the algebraic condition |E| = |V| - 1 is mathematically identical to requiring that the induced forest consists of exactly one connected component, perfectly preserving the original connectivity requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the minimum weight Steiner tree on a given set of mandated vertices, which is solvable in O(N) time on trees, keeping it firmly in the P complexity class.
</PRESERVED_CLASS>
