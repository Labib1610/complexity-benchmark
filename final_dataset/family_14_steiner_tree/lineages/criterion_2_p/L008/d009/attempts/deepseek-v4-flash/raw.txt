We can model the zones and corridors as a tree.  
The mandated zones must be included, and the activated set must be connected (since in a tree, “synchronous” means the activated zones form a connected subgraph).  

So the problem reduces to:  
Find the minimum total edge weight of a connected subgraph that contains all mandated zones.  

This is the **Steiner tree** problem on a tree, which can be solved by pruning unnecessary leaves.  

**Approach:**  
1. Mark all mandated zones.  
2. Repeatedly remove leaves that are not mandated, along with their incident edges, until no such leaf remains.  
3. The remaining tree is the minimal connected subgraph containing all mandated zones.  
4. Sum the weights of the edges in this remaining tree.  

This works because any leaf not mandated can never be part of the minimal connected subgraph.  

```python
import sys
from collections import deque

input = sys.stdin.readline

R, S, P = map(int, input().split())
mandated = set(map(int, input().split()))

adj = [[] for _ in range(R + 1)]
degree = [0] * (R + 1)

for _ in range(S):
    u, v, w = map(int, input().split())
    adj[u].append((v, w))
    adj[v].append((u, w))
    degree[u] += 1
    degree[v] += 1

# Remove leaves that are not mandated
removed = [False] * (R + 1)
q = deque()

for i in range(1, R + 1):
    if degree[i] == 1 and i not in mandated:
        q.append(i)

while q:
    u = q.popleft()
    if removed[u]:
        continue
    removed[u] = True
    for v, w in adj[u]:
        if not removed[v]:
            degree[v] -= 1
            if degree[v] == 1 and v not in mandated:
                q.append(v)

# Sum weights of edges where both endpoints are not removed
total = 0
for u in range(1, R + 1):
    if removed[u]:
        continue
    for v, w in adj[u]:
        if u < v and not removed[v]:
            total += w

print(total)
```
