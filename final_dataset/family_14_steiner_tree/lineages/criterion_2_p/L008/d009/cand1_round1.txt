<STATEMENT>
# Resonance Containment

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of $R$ distinct resonant entities. These entities interact through $S$ bidirectional harmonic links. The system integrates all entities into a single unified framework: it is possible to transition between any two entities via some sequence of links, and the total number of links $S$ is exactly $R - 1$.

A recent protocol requires that a specific set of $P$ entities must be placed in the *Active* state. You may additionally place any other entities in the *Active* state as you choose. All entities not placed in the *Active* state remain *Dormant*.

Activating entities has a cost. Each harmonic link has a characteristic penalty $w$. If both entities associated with a link are in the *Active* state, that link becomes *saturated* and adds its penalty $w$ to the total system cost. If one or neither of the associated entities is *Active*, the link remains dormant and contributes 0 to the total cost.

To ensure system stability, your chosen configuration of states must satisfy a strict numerical balance: the total number of saturated links must be exactly one less than the total number of *Active* entities.

Your objective is to determine the minimum possible total penalty of the saturated links such that all $P$ mandated entities are *Active* and the stability condition is met.

## Input

The first line contains three integers $R$, $S$, and $P$. 
The total number of entities $R$ satisfies $1 \le R \le 200000$. 
The number of harmonic links $S$ is exactly equal to $R - 1$. 
The number of mandated entities $P$ satisfies $1 \le P \le R$.

The second line contains $P$ distinct integers representing the identifiers of the mandated entities.

Each of the following $S$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le R$, $u \neq v$). This indicates a harmonic link between entity $u$ and entity $v$ with a characteristic penalty of $w$ ($1 \le w \le 1000000$). 

## Output

Output a single integer representing the minimum possible total penalty of the saturated links under the given conditions.

<RATIONALE>
I replaced the explicit topological connectivity requirement ("impossible to partition") with an equivalent algebraic constraint ($E = V - 1$ on the induced subgraph). Because the base graph is a tree, any induced subgraph is a forest, making this equation true if and only if the induced subgraph is a single connected component. This forces the model to mathematically deduce the connectivity requirement rather than relying on structural keywords.
</RATIONALE>
<PRESERVED_ANSWER>
Since any subset of vertices in a tree induces a forest, the condition that the number of internal edges equals the number of vertices minus one is mathematically identical to requiring the induced subgraph to be connected, so the set of valid configurations and their costs are exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the minimum weight connected subgraph containing a set of mandated vertices on a tree, which is solvable in O(N) time using identical tree pruning logic once the constraint is understood.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "total number of saturated links" as including links to dormant entities, though the definition explicitly states "If both entities associated with a link are in the Active state, that link becomes saturated", which strictly limits it to the induced subgraph.
</RISK>
