<METHOD_NAME>Euler_Characteristic_Substitution</METHOD_NAME>
<METHOD_DESCRIPTION>Replaced the explicit connectivity requirement ("synchronous" / no disconnected partition) with the Euler characteristic equation for trees: the number of induced edges must be exactly one less than the number of selected vertices. This requires the model to deduce that this equation enforces connectivity on a tree.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Network Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a communication network of $R$ nodes and $S$ bidirectional links. The network layout was constructed sequentially: starting with a single node, each subsequent node was added by connecting it to exactly one previously existing node, until all $R$ nodes were integrated.

A new policy requires a specific set of $P$ nodes to be activated. You may also choose to activate any number of additional nodes.

Activating nodes incurs costs on the links. Each link has a maintenance fee $w$. If both endpoints of a link are activated, the link becomes "active" and its fee $w$ is added to the total cost. If one or neither endpoint is activated, the link remains dormant and costs 0.

To ensure proper routing, the set of activated nodes and active links must form a valid sub-network. A sub-network is considered valid if the number of active links is exactly one less than the total number of activated nodes.

Your goal is to find the minimum possible total cost of the active links such that all $P$ required nodes are activated and the valid sub-network condition is met.

## Input

The first line contains three integers $R$, $S$, and $P$. 
The number of nodes $R$ satisfies $1 \le R \le 200000$. 
Based on the construction method, the number of links $S$ is exactly equal to $R - 1$. 
The number of required nodes $P$ satisfies $1 \le P \le R$.

The second line contains $P$ distinct integers representing the identifiers of the required nodes.

Each of the following $S$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le R$, $u \neq v$). This indicates a link between node $u$ and node $v$ with a maintenance fee of $w$ ($1 \le w \le 1000000$). 

## Output

Output a single integer representing the minimum possible total cost of the active links under the given conditions.

</STATEMENT>
<RATIONALE>
The explicit condition of "synchronous" entities (connectedness) has been replaced by the algebraic condition that the number of active links must be one less than the number of activated nodes. To solve this, models must recognize that since the network is constructed sequentially (forming a tree), this algebraic condition is perfectly equivalent to requiring the induced subgraph to be a single connected component.
</RATIONALE>
<PRESERVED_ANSWER>
The sequential construction ensures the graph is a tree; in a tree, any induced subgraph is a forest, and the condition $|E'| = |V'| - 1$ holds if and only if that forest consists of exactly one connected component, preserving the Steiner tree objective.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains finding the minimum weight subgraph connecting a subset of vertices in a tree, which is solvable in polynomial time (O(n)).
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "sub-network is considered valid if the number of active links is exactly one less than the total number of activated nodes" as a generic constraint rather than a guarantee of connectivity, but mathematically it is completely unambiguous and precise.
</RISK>
