# Network Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a network of $R$ servers and $S$ bidirectional cables. Each cable has a known maintenance cost. The network is connected, meaning information can be routed between any two servers.

A specific set of $P$ servers must be selected for an upgrade. You may also select any number of additional servers to be upgraded.

When a set of servers is selected, the cables connecting them are affected. Specifically, if both servers connected by a cable are selected, that cable is considered "active" and its maintenance cost is added to your total cost. If one or neither of the connected servers is selected, the cable is ignored and contributes 0 to the total cost.

To ensure proper routing among the upgraded servers, your selected set of servers must satisfy a strict structural requirement: the total number of active cables must be exactly one less than the total number of selected servers.

Your task is to find the minimum possible total cost of the active cables such that all required conditions are met.

## Input

The first line contains three integers $R$, $S$, and $P$. 
The total number of servers $R$ satisfies $1 \le R \le 200000$. 
The number of cables $S$ is exactly equal to $R - 1$. 
The number of mandated servers $P$ satisfies $1 \le P \le R$.

The second line contains $P$ distinct integers representing the identifiers of the mandated servers.

Each of the following $S$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le R$, $u \neq v$). This indicates a cable between server $u$ and server $v$ with a maintenance cost of $w$ ($1 \le w \le 1000000$). 

## Output

Output a single integer representing the minimum possible total cost of the active cables.

## Examples


**Output**

```
8
```


<RATIONALE>
Replaced the contrived "resonance" theme with standard competitive-programming terminology (servers, cables) as requested by the expert review. To disrupt the shortcut where models immediately recognize the need for a connected Steiner tree, the topological requirement ("synchronous" / connected) was replaced with an algebraic one: `active_cables = selected_servers - 1`. In an acyclic graph, this mathematically forces the selected vertices to induce exactly one connected component, preserving the logic perfectly while requiring the solver to deduce the structural meaning.
</RATIONALE>
<PRESERVED_ANSWER>
Because the underlying graph is a tree, any subgraph satisfying V - E = 1 must consist of exactly one connected component, making the algebraic constraint strictly equivalent to requiring the selected servers to form a connected subtree.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains finding the minimum weight Steiner tree on a tree, which is solvable in O(N) time through leaf pruning or dynamic programming.
</PRESERVED_CLASS>
