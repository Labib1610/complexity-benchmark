<METHOD_DESCRIPTION>Removed explicit mentions of unique paths, replacing them with a guarantee of full facility connectivity using exactly R-1 links. This mathematically guarantees a tree structure without using the semantic keywords (unique path, tree, acyclic) that trigger models to instantly apply tree-specific DP or leaf pruning.</METHOD_DESCRIPTION>

<STATEMENT>
# Architectural Core Cluster

Time limit: 2 s   Memory limit: 256 MB

## Description

An industrial facility contains $R$ modules, interconnected by $S$ bidirectional data links. 
A recent directive mandates that $P$ specific modules must be brought online into a unified operational block.

You must select a subset of the $R$ modules to bring online. The selected subset must satisfy:
1. It contains all $P$ of the mandated modules (it may also contain any number of other modules).
2. The selected modules must be fully contiguous. That is, for any two modules in the operational block, they must be able to communicate using only data links that connect two modules which are both in the block.

Whenever two modules that share a physical data link are both brought online, that link is "internalized" and requires a power cost to synchronize. Links where at least one endpoint is offline remain external and cost nothing.

The entire facility is fully integrated: it is possible to route data between any two modules in the facility using the existing links. To minimize hardware redundancy, the facility was built with exactly $S = R - 1$ data links. This structural design ensures that a valid operational block encompassing the mandates is always possible.

Your objective is to determine the minimum possible total power cost of the internalized links needed to establish a valid operational block.

## Input

The first line contains three integers $R$, $S$, and $P$. 
The total number of modules $R$ satisfies $1 \le R \le 200,000$. 
The number of data links $S$ is exactly equal to $R - 1$. 
The number of mandated modules $P$ satisfies $1 \le P \le R$.

The second line contains $P$ distinct integers: the identifiers of the mandated modules.

Each of the following $S$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le R$, $u \neq v$). This indicates a bidirectional data link between module $u$ and module $v$ with a power cost of $w$ ($1 \le w \le 1,000,000$). 

## Output

Output a single integer representing the minimum total power cost of the internalized links in a valid operational block.

## Examples

```

```

<RATIONALE>
The explicit statement that the network has "exactly one unique sequence of integrations" between any two components was removed since it acted as a dead giveaway for a tree structure. Instead, the tree property is guaranteed mathematically by stating the network is fully connected and has exactly $R-1$ edges. This forces the model to deduce the structural properties from the connectivity constraints rather than pattern-matching the phrase "unique sequence".
</RATIONALE>
<PRESERVED_ANSWER>
The graph is still a tree (guaranteed by connectivity and $S=R-1$), the subset rules and costs are identical, and the objective remains minimizing the cost of the induced subgraph connecting the required nodes, so all answers are unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Because the underlying graph remains a tree and the problem asks for the minimum weight connected subgraph containing a set of terminals, it is still solvable in O(N) time, preserving the polynomial complexity class.
</PRESERVED_CLASS>
<RISK>
The term "fully contiguous" could potentially be misinterpreted if the reader does not carefully read the subsequent sentence defining it as communication using only internal links, but the definition provided is rigorous and unambiguous.
</RISK>
