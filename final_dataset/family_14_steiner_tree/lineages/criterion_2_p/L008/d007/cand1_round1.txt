<STATEMENT>
# Architectural Core Cluster

Time limit: 2 s   Memory limit: 256 MB

## Description

An industrial facility contains $R$ logic components. These components are linked by $S$ bidirectional data integrations, forming a single connected network. 
A recent directive mandates that $P$ specific components must be isolated into a unified operational cluster.

You must select a subset of the $R$ components to form this cluster. The selected subset must satisfy two conditions:
1. It must contain all $P$ of the mandated components (it may also contain any number of additional components).
2. The selected components must be fully contiguous. This means that for any two components in the cluster, it must be possible to transmit data between them using only integrations that connect two components which are both in the cluster.

Whenever two components that share an integration are both selected for the cluster, that integration becomes "internalized" and incurs a configuration cost. Integrations where at least one endpoint is not in the cluster remain external and cost nothing.

Your objective is to determine the minimum possible total configuration cost of the internalized integrations to establish a valid operational cluster.

## Input

The first line contains three integers $R$, $S$, and $P$. 
The total number of components $R$ satisfies $1 \le R \le 200,000$. 
The number of integrations $S$ is exactly equal to $R - 1$. 
The number of mandated components $P$ satisfies $1 \le P \le R$.

The second line contains $P$ distinct integers: the identifiers of the mandated components.

Each of the following $S$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le R$, $u \neq v$). This indicates a bidirectional integration between component $u$ and component $v$ with a configuration cost of $w$ ($1 \le w \le 1,000,000$). 

## Output

Output a single integer representing the minimum total configuration cost of a valid operational cluster.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

**Output**

```

```

**Output**


<RATIONALE>
Removed the explicit statement that paths are unique and the equivalence to finding a minimum-cost network. By phrasing it purely as a subset selection problem with an induced-subgraph penalty, models must independently realize that the $S = R - 1$ constraint guarantees a tree, and that the optimal subset is exactly the minimal subtree spanning the mandated nodes.
</RATIONALE>
<PRESERVED_ANSWER>
The cost calculation (sum of edges in the induced subgraph) and the requirement for the subset to be connected and contain the mandatory nodes are mathematically identical to finding the minimal Steiner tree spanning those nodes.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying graph is still a tree (connected, $S = R - 1$), meaning the minimal connected subgraph spanning a set of vertices is unique and can be found in polynomial time ($O(R)$).
</PRESERVED_CLASS>
