<METHOD_NAME>Induced Subgraph Cost Framing</METHOD_NAME>
<METHOD_DESCRIPTION>Removes all explicit mentions of unique paths, trees, and the equivalence to a minimum-cost network. Instead, the problem is framed purely as activating a subset of components and paying for any edges whose both endpoints are active. Because the graph is a tree and weights are positive, this naturally minimizes when the selected nodes form exactly the minimal spanning subtree, but models must deduce this equivalence themselves rather than having it spoon-fed to them.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Architectural Core Cluster

Time limit: 2 s   Memory limit: 256 MB

## Description

An industrial facility contains $R$ logic components, linked by $S$ bidirectional data integrations. A recent directive mandates that $P$ specific components must be brought online to form a unified operational cluster.

To form this cluster, you will power on a chosen subset of components. This subset must satisfy two conditions:
1. It includes all $P$ of the mandated components (it may also include any number of non-mandated components).
2. The powered-on subset must be fully communicative: for any two powered-on components, it must be possible to relay signals between them by hopping only between powered-on components that share a direct integration.

When a direct integration exists between two components and *both* of those components are powered on, that integration automatically awakens and draws a specific amount of configuration power. Integrations where at least one endpoint is powered off remain dormant and draw no power.

Your objective is to choose a valid subset of components to power on such that the total configuration power drawn by the awakened integrations is as small as possible.

## Input

The first line contains three integers $R$, $S$, and $P$. 
The total number of components $R$ satisfies $1 \le R \le 200,000$. 
The number of integrations $S$ is exactly equal to $R - 1$. 
The number of mandated components $P$ satisfies $1 \le P \le R$.

The second line contains $P$ distinct integers: the identifiers of the mandated components.

Each of the following $S$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le R$, $u \neq v$). This indicates a bidirectional integration between component $u$ and component $v$ which draws $w$ ($1 \le w \le 1,000,000$) units of power if awakened. 

## Output

Output a single integer representing the minimum total power drawn by the awakened integrations in a valid component cluster.

<RATIONALE>
Removed the explicit paragraph that explained the graph has unique pathways (is a tree) and directly stated that the objective is identical to finding the minimum-cost contiguous network encompassing the mandates. The models must now read the rules for awakened integrations and deduce for themselves that finding the minimum connected induced subgraph on a tree with positive weights is equivalent to finding the minimal spanning subtree.
</RATIONALE>
<PRESERVED_ANSWER>
Because the input graph has S = R - 1 and is connected, it is a tree; forcing the chosen subset to be connected means it induces a subtree, and since all edge weights are positive, the minimum cost to include the mandated nodes is exacted by the minimal spanning subtree, which is identical to the original objective.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains solvable by finding the minimal subtree encompassing the mandated nodes, which takes O(R) time using a standard tree traversal or pruning approach.
</PRESERVED_CLASS>
