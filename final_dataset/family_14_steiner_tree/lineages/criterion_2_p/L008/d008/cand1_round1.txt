<METHOD_NAME>Cost-Function Obfuscation via Boolean Activation</METHOD_NAME>
<METHOD_DESCRIPTION>The problem is reframed from selecting a contiguous sub-network to assigning boolean activation states (active/dormant) to entities, with a pairwise penalty for co-activated entities. The tree structure is disguised as a "minimally cohesive" property, and the connected-subgraph requirement is redefined topologically as the inability to partition the active set into two mutually isolated non-empty subsets. Models relying on keyword matching for Steiner trees will fail to map this to a graph problem, while models that genuinely reason about the constraints will deduce that the induced subgraph must be connected, which in a tree implies finding the unique minimal spanning subtree.</METHOD_DESCRIPTION>

<STATEMENT>
# Resonance Containment

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of $R$ distinct resonant entities. These entities interact through $S$ bidirectional harmonic links. The system is minimally cohesive: every entity can influence every other entity through a sequence of links, but the removal of any single link would shatter this property. 

A recent protocol requires that a specific set of $P$ entities must be fully activated. You may additionally activate any other entities you choose. 

To ensure stability, the complete set of activated entities must be *synchronous*. A set of activated entities is synchronous if it is impossible to partition it into two non-empty subsets such that no harmonic link exists between an entity in the first subset and an entity in the second subset. 

Activating entities has a cost. Specifically, each harmonic link has a characteristic penalty $w$. If both entities associated with a link are activated, the link becomes "saturated" and adds its penalty $w$ to the total system cost. If one or neither of the associated entities is activated, the link remains dormant and contributes 0 to the total cost.

Your objective is to determine the minimum possible total penalty of the saturated links such that all $P$ mandated entities are activated and the entire set of activated entities is synchronous.

## Input

The first line contains three integers $R$, $S$, and $P$. 
The total number of entities $R$ satisfies $1 \le R \le 200000$. 
Because the system is minimally cohesive, the number of harmonic links $S$ is exactly equal to $R - 1$. 
The number of mandated entities $P$ satisfies $1 \le P \le R$.

The second line contains $P$ distinct integers representing the identifiers of the mandated entities.

Each of the following $S$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le R$, $u \neq v$). This indicates a harmonic link between entity $u$ and entity $v$ with a characteristic penalty of $w$ ($1 \le w \le 1000000$). 

## Output

Output a single integer representing the minimum possible total penalty of the saturated links under the given conditions.

<RATIONALE>
The framing was changed from a physical network with "contiguous" components to a system of entities with a "synchronous" activation requirement, defined via strict set non-partitionability. The objective is framed as a pairwise activation penalty rather than edge inclusion. This forces the model to mathematically deduce that "synchronous" means "connected subgraph" and "minimally cohesive" means "tree structure," preventing it from skipping straight to tree-pruning algorithms via surface pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The synchronous condition exactly requires the activated entities to form a connected induced subgraph, and the penalty sums the weights of the edges within this subgraph; because the original graph is a tree, the minimum cost connected subgraph containing the mandated entities is identical to the optimal cluster in the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying mathematical structure remains finding the minimal spanning subtree of a subset of vertices in a weighted tree, solvable in O(N) time with standard leaf-pruning or lowest-common-ancestor techniques.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the non-partitionability constraint as applying to the entire set of $R$ entities rather than just the activated subset, though the text explicitly specifies "A set of activated entities is synchronous if...".
</RISK>
