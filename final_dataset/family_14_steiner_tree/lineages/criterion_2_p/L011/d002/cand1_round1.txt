<STATEMENT>
# Problem B — Campus Network Infrastructure

Time limit: 2 s   Memory limit: 256 MB

## Description

A campus consists of **n** facilities, identified by integers from 1 to **n**. You have a list of **m** potential bidirectional communication links that can be established between specific pairs of facilities, each requiring a certain investment. 

A specific subset of **t** facilities are designated as **core facilities**. Your objective is to select a subset of the potential links to establish such that all core facilities are able to communicate with one another. They may communicate directly or relay information through other intermediate facilities (which may or may not be core facilities themselves). 

You are guaranteed that all core facilities are located within a single contiguous network segment, meaning it is always possible for them to communicate using some combination of the provided links. Furthermore, within this specific segment containing the core facilities, there are no redundant links (i.e., no closed loops of links). 

Please note that the overall campus infrastructure might be fragmented. Some non-core facilities could be completely disconnected from the segment containing the core facilities, and those other isolated segments might contain redundant links.

Determine the minimum total investment required to establish a valid network that connects all core facilities.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line provides **t** distinct integers representing the identifiers of the core facilities.
Each of the subsequent **m** lines provides three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that a link can be established between facility **u** and facility **v** with an investment of **w**.

## Output

Output a single integer representing the minimum total investment needed to ensure all core facilities are connected.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```
</STATEMENT>
<RATIONALE>
Replaced the global connectedness guarantee with a local guarantee that only the core-containing segment is acyclic and connected, explicitly allowing other components to be disconnected and contain cycles. This defeats shortcut solutions that rely on global leaf-pruning or whole-graph traversals, forcing models to genuinely implement a targeted traversal originating from the core facilities.
</RATIONALE>
<PRESERVED_ANSWER>
The reference solution uses a bottom-up traversal starting from a core facility, which only explores the acyclic core segment and remains perfectly correct even if disconnected cyclic components were present.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Finding the minimum connecting network within a component guaranteed to be acyclic is mathematically equivalent to finding the unique spanning subtree, which remains solvable in linear time (P).
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "fragmented" as implying that the core facilities themselves could be in separate components, despite the explicit guarantee that they are in a single contiguous segment.
</RISK>
