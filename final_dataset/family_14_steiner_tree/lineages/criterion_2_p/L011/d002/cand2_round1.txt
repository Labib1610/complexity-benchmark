# Problem B — Campus Network Infrastructure

Time limit: 2 s   Memory limit: 256 MB

## Description

A sprawling campus contains a number of facilities. You are provided with a catalog of potential bidirectional communication links between specific pairs of these facilities. Each potential link requires a certain financial investment to establish. 

It is guaranteed that the provided catalog contains enough links so that all designated *core facilities* are mutually connected (they can communicate directly or relay through intermediate facilities). The connectivity rules alone do not guarantee that every facility on campus is connected to the network; some facilities or groups of facilities could in principle remain completely isolated from the rest. 

To prevent infinite routing loops, the catalog is strictly curated to contain no redundant links—meaning there is at most one unique path between any two facilities in the potential infrastructure.

Your objective is to select a subset of the potential links to establish such that all core facilities are able to communicate with one another. Determine the minimum total investment required to form this valid network.

## Input

The first line provides three integers, $n$, $m$, and $t$. The campus directory has a strict upper limit of exactly $200,000$ entries, which caps the maximum possible number of facilities $n$. You are guaranteed there is at least one facility. The catalog's length $m$ is exactly one less than the total number of facilities. The count of core facilities $t$ ranges from a single facility up to the entire campus of $n$ facilities.

The second line provides $t$ distinct integers representing the identifiers of the core facilities. Valid identifiers are positive integers up to the number of facilities.

Each of the subsequent $m$ lines provides three integers $u$, $v$, and $w$. This indicates a potential bidirectional link between distinct facilities $u$ and $v$. The investment $w$ requires at least $1$ credit and is capped by the maximum single-link grant limit of $1,000,000$ credits.

## Output

Output a single integer representing the minimum total investment needed to ensure all core facilities are connected.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3

2 3 6

```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

<RATIONALE>
I removed the explicit guarantee of full campus connectivity and replaced it with a statement that only core facilities are guaranteed to be connected, explicitly mentioning that some facilities could be isolated. To maintain the P complexity class, I added that there are no redundant routing loops (forming a forest). I also applied Strategy S07 by replacing all bare inequalities with scenario-based physical limits (e.g., a directory capacity of 200,000, a grant limit of 1,000,000). This forces the model to deduce the exact graph structure from $m=n-1$ and the lack of loops, rather than relying on a direct connectivity guarantee.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical structure of the valid inputs is unchanged because a graph with no redundant loops (a forest) and exactly $n-1$ edges is necessarily a single connected component containing all vertices, ensuring all optimal investments remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class remains P because the problem explicitly restricts the input to a forest (no redundant loops), where finding the minimum connecting sub-network for a subset of nodes is solvable in linear time.
</PRESERVED_CLASS>
<RISK>
A reader might find a slight contradiction between the statement that "facilities could in principle remain completely isolated" and the mathematical reality that $m=n-1$ with no loops forces a single connected component, though this is framed as a lack of guarantee rather than a strict condition.
</RISK>
