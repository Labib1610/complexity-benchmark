# Problem B — Economic Integration

Time limit: 2 s   Memory limit: 256 MB

## Description

An economic coalition consists of **n** distinct regional currencies, labeled with integers from 1 to **n**. You are reviewing a set of potential bilateral exchange contracts. Each contract permanently fixes the exchange rate between two specific currencies. 

A special subset of **t** currencies are identified as **anchor currencies**. Your goal is to activate a collection of the potential exchange contracts so that all anchor currencies are mutually convertible at fixed rates. They can be connected directly by a contract, or indirectly via intermediate currencies (which do not necessarily have to be anchor currencies).

Activating each potential contract incurs a specific yearly maintenance cost. Find the lowest possible total maintenance cost to activate a valid collection of contracts that fully integrates all anchor currencies into a single fixed-rate system.

## Input

The first line contains three integers **n**, **m**, and **t**. The total number of currencies **n** is a positive integer. A registration system allocates exactly 5 bytes of data per currency, up to a strict maximum database capacity of 1,000,000 bytes for the entire coalition. The number of anchor currencies **t** is a positive integer, naturally limited by the total number of currencies. The integer **m** is the number of potential contracts provided in the input; its value is exactly the theoretical minimum number of contracts required to ensure that, if all **m** were activated, any currency in the coalition could be converted into any other.

The second line contains **t** distinct integers representing the labels of the anchor currencies.

Each of the following **m** lines contains three integers **u**, **v**, and **w**. This indicates a potential contract between two distinct currencies **u** and **v** (both integers from 1 to **n**) with a yearly maintenance cost of **w**. The cost **w** is a positive integer. The central vault holds exactly 1,000,000 physical tokens, which acts as the absolute maximum possible cost for any single contract.

## Output

Output a single integer representing the minimum total maintenance cost needed to ensure all anchor currencies are locked into a single fixed-rate system.
