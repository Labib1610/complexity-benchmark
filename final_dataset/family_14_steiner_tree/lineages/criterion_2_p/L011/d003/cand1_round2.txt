# Problem B — Monetary Unification

Time limit: 2 s   Memory limit: 256 MB

## Description

A financial federation consists of **n** distinct currency zones, identified by integers from 1 to **n**. You are evaluating a catalog of **m** bilateral exchange treaties. Each treaty permanently links the monetary policy of two specific zones. The potential treaties connect all **n** zones, there are exactly **n** − 1 treaties in total, and if all were activated, there would be exactly one sequence of treaties linking any two zones.

Within this federation, a specific subset of **t** zones are designated as **anchor zones**. Your task is to establish a unified exchange network for these anchor zones. You must select a subset of the treaties to activate so that every anchor zone can reach every other anchor zone, either directly or via a chain of activated treaties involving intermediate zones. 

Each treaty carries a specific annual administrative cost. You must find the minimum possible sum of administrative costs for a subset of activated treaties that successfully interconnects all **t** anchor zones. (If only one anchor zone is designated, no treaties need to be activated and the total cost is 0).

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line provides **t** distinct integers representing the identifiers of the anchor zones.
Each of the subsequent **m** lines provides three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that a proposed treaty between zone **u** and zone **v** has an annual administrative cost of **w**.

## Output

Output a single integer representing the minimum total administrative cost of the activated treaties needed to ensure all anchor zones are interconnected.

## Examples

