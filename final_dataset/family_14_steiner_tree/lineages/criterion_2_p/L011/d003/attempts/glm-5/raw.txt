Looking at this problem:

- We have n variables and m = n-1 constraints forming a tree (since all n variables connected means it's a spanning tree).
- We need to connect all t observable variables using a subset of edges with minimum total weight.
- This is the Steiner tree problem on a tree.

For Steiner tree on a tree: the answer is the sum of all edges in the minimal subtree spanning all terminals. An edge is in this subtree if and only if removing it disconnects at least two terminals (i.e., both sides have at least one terminal).

Algorithm:
1. Root the tree at any terminal.
2. Compute subtree terminal counts for each node.
3. For each edge (parent, child), if the child's subtree has between 1 and t-1 terminals (inclusive), the edge is needed.

Let me verify with examples:
- Example 1: Tree 1-2-3-4, terminals {1,4}. Edges 1-2 (subtree of 2 has 1 terminal), 2-3 (1), 3-4 (1). All needed: 5+1+2=8. ✓
- Example 2: t=1, no edges needed: 0. ✓
- Example 3: Tree 1-2-3, terminals {1,2,3}. All edges needed: 4+5=9. ✓

```python
import sys
from sys import setrecursionlimit

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    t = int(input_data[idx]); idx += 1
    
    is_terminal = [False] * (n + 1)
    for i in range(t):
        v = int(input_data[idx]); idx += 1
        is_terminal[v] = True
    
    adj = [[] for _ in range(n + 1)]
    edges = []
    for i in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        w = int(input_data[idx]); idx += 1
        adj[u].append((v, w, i))
        adj[v].append((u, w, i))
        edges.append((u, v, w))
    
    if t <= 1:
        print(0)
        return
    
    # Iterative DFS to compute subtree terminal counts
    parent = [0] * (n + 1)
    parent_edge = [-1] * (n + 1)  # edge index connecting to parent
    order = []
    visited = [False] * (n + 1)
    stack = [1]
    visited[1] = True
    while stack:
        u = stack.pop()
        order.append(u)
        for v, w, ei in adj[u]:
            if not visited[v]:
                visited[v] = True
                parent[v] = u
                parent_edge[v] = ei
                stack.append(v)
    
    cnt = [0] * (n + 1)
    for i in range(1, n + 1):
        if is_terminal[i]:
            cnt[i] = 1
    
    for u in reversed(order):
        if parent[u] != 0:
            cnt[parent[u]] += cnt[u]
    
    total = 0
    for i in range(1, n + 1):
        if parent[i] != 0:
            c = cnt[i]
            if 1 <= c <= t - 1:
                total += edges[parent_edge[i]][2]
    
    print(total)

solve()
```
