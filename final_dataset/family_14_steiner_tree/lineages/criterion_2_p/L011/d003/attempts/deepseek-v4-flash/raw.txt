We are given a tree (since m = n − 1) with weighted edges.  
We need to connect all observable variables (terminals) with minimum total edge weight.  

This is exactly the **Steiner tree** problem on a tree, which can be solved by:

- Taking the minimal subtree that connects all terminals.
- The minimal cost is the sum of edges in that minimal subtree.

Since the graph is a tree, the minimal subtree connecting a set of terminals is unique:  
It is the union of all paths between terminals.  
We can find it by:

1. Mark all terminal nodes.
2. Do a DFS/BFS from any terminal, and keep only edges that lead to at least one terminal in their subtree.
3. Sum the weights of those kept edges.

If there is only one terminal, the cost is 0.

Let’s implement this efficiently.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    terminals = set(map(int, input().split()))
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    if t == 1:
        print(0)
        return
    
    # DFS to find edges that are part of minimal subtree connecting terminals
    visited = [False] * (n+1)
    total_cost = 0
    
    def dfs(u, parent):
        nonlocal total_cost
        visited[u] = True
        has_terminal = u in terminals
        for v, w in adj[u]:
            if v == parent:
                continue
            if not visited[v]:
                child_has_terminal = dfs(v, u)
                if child_has_terminal:
                    total_cost += w
                has_terminal = has_terminal or child_has_terminal
        return has_terminal
    
    # Start from any terminal
    start = next(iter(terminals))
    dfs(start, -1)
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
