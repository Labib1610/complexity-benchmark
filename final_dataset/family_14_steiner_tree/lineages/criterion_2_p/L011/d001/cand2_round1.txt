# Problem B — Linking the Critical Servers

Time limit: 2 s   Memory limit: 256 MB

## Description

A corporate facility contains **n** servers. Certain pairs of servers can be linked by a direct data channel at a given installation expense. Among the servers, **t** are designated as **critical** and must all end up able to communicate with each other through the channels you install (either directly or via intermediate servers).

The set of proposed channels is capable of linking all servers in the facility together. To maintain strict minimal redundancy, the total number of proposed channels is exactly one less than the number of servers.

Determine a set of channels to install that minimizes the total expense while ensuring all critical servers can communicate. Report that minimum total expense.

## Input

The first line contains three integers **n**, **m**, and **t**. A facility can house up to two hundred thousand server racks, establishing the maximum possible value for the number of servers **n** (with a minimum of 1). The total number of proposed channels **m** is exactly one less than **n**. The count of critical servers **t** ranges from a single server up to the entire facility **n**.
The second line contains **t** distinct integers: the ids of the critical servers, which are assigned numbers from 1 up to **n**.
Each of the next **m** lines contains three integers **u**, **v**, and **w**, representing a proposed channel linking distinct servers **u** and **v**. The installation expense **w** starts at 1 and is capped by a strict departmental limit of one million per channel. 

## Output

Print a single integer: the minimum total expense to link all critical servers.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

This scenario requires finding a minimum-expense setup. Because of the layout of the proposed channels, an efficient exact solution is possible. In Example 1, critical servers 1 and 4 can only communicate through 2 and 3, so all three channels (5+1+2 = 8) must be installed. In Example 2, there is only one critical server, so no channels need to be installed.
