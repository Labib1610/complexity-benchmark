 We are given a tree (since m = n − 1) with weighted edges.  
We must choose a connected subgraph (market-linked means connected) that contains all mandatory assets, minimizing the sum of edge weights inside the chosen subgraph.

This is exactly the **Steiner tree** problem on a tree, where the terminals are the mandatory assets.  
On a tree, the minimal Steiner tree is simply the minimal subtree that connects all terminals.  
Its total edge weight can be computed by:

1. Mark all mandatory nodes.
2. Do a DFS from any mandatory node, and keep only edges that lead to at least one mandatory node in their subtree.
3. Sum the weights of those kept edges.

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    mandatory = set(map(int, input().split()))
    
    g = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        g[u].append((v, w))
        g[v].append((u, w))
    
    visited = [False] * (n + 1)
    total_cost = 0
    
    def dfs(u, parent):
        nonlocal total_cost
        visited[u] = True
        has_mandatory = u in mandatory
        for v, w in g[u]:
            if v == parent:
                continue
            if not visited[v]:
                child_has = dfs(v, u)
                if child_has:
                    total_cost += w
                has_mandatory = has_mandatory or child_has
        return has_mandatory
    
    # Start from any mandatory node
    start = next(iter(mandatory))
    dfs(start, -1)
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
