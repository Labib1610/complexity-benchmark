Looking at this problem, I need to understand the structure:

1. The framework is a tree (m = n-1 edges, fully cohesive means connected)
2. I can remove non-anchor joints one at a time, keeping the remaining graph connected
3. I want to minimize the total weight of remaining edges

**Key insight**: If I remove a non-anchor leaf, I remove its incident edge and the tree stays connected. So I should greedily remove non-anchor leaves to shed edge weight.

The process: repeatedly find non-anchor leaves and remove them. This removes the edge connecting them to the tree. Eventually, only anchor nodes and paths between them remain (plus subtrees containing only anchors).

**Algorithm**: 
- Process leaves in a queue (BFS-like)
- For each non-anchor leaf, remove it and its edge, add weight to removed total
- When a node becomes a leaf, check if it's non-anchor and add to queue
- Anchor nodes are never removed

The remaining edges are exactly those on paths between anchor nodes in the original tree.

So we cannot remove node 2 because it would disconnect node 1 from the rest. The remaining edges must keep all anchor nodes connected.

import sys
from collections import deque

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    t = int(input_data[idx]); idx += 1
    
    is_anchor = [False] * (n + 1)
    for i in range(t):
        a = int(input_data[idx]); idx += 1
        is_anchor[a] = True
    
    adj = [[] for _ in range(n + 1)]
    total_weight = 0
    for i in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        w = int(input_data[idx]); idx += 1
        adj[u].append((v, w))
        adj[v].append((u, w))
        total_weight += w
    
    degree = [0] * (n + 1)
    for i in range(1, n + 1):
        degree[i] = len(adj[i])
    
    removed_weight = 0
    queue = deque()
    in_queue = [False] * (n + 1)
    
    for i in range(1, n + 1):
        if degree[i] <= 1 and not is_anchor[i]:
            queue.append(i)
            in_queue[i] = True
    
    while queue:
        node = queue.popleft()
        for neighbor, weight in adj[node]:
            if degree[neighbor] > 0:
                removed_weight += weight
                degree[neighbor] -= 1
                degree[node] -= 1
                if degree[neighbor] <= 1 and not is_anchor[neighbor] and not in_queue[neighbor]:
                    queue.append(neighbor)
                    in_queue[neighbor] = True
                break
    
    print(total_weight - removed_weight)

solve()
