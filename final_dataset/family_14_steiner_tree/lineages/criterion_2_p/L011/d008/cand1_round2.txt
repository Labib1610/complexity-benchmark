# Problem B — Quantum Phase-Locking and Oscillator Isolation

Time limit: 2 s   Memory limit: 256 MB

## Description

You are managing an experimental quantum communication array. The array contains **n** quantum oscillators, indexed from 1 to **n**, and **m** active entanglement links. Each link connects two distinct oscillators and has a known thermal maintenance cost.

The initial array is fully *phase-locked*. A subset of oscillators is considered *phase-locked* if it is impossible to assign a binary state (0 or 1) to each oscillator in the subset such that:
- At least one oscillator is assigned 0.
- At least one oscillator is assigned 1.
- No active link connects an oscillator assigned 0 to an oscillator assigned 1.

A subset containing exactly one oscillator also satisfies this condition.

You may perform a sequence of isolation procedures to reduce the array's energy footprint. In a single procedure, you permanently isolate exactly one oscillator. This safely deactivates any links attached to it. However, your isolation sequence must satisfy two strict regulations:
1. You may never isolate any of the **t** *reference oscillators*, as they are required for calibration.
2. After every individual isolation procedure, the subset of remaining oscillators must still be *phase-locked*. If isolating an oscillator would cause the remaining subset to lose this property, that oscillator cannot be isolated at that time.

You can halt the isolation process at any point, including making no isolations at all. Your objective is to determine the minimum possible total thermal maintenance cost of the links that remain active in the array when you finish.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line provides **t** distinct integers representing the indices of the reference oscillators.
Each of the subsequent **m** lines provides three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating an entanglement link between oscillator **u** and oscillator **v** with a thermal maintenance cost of **w**.

## Output

Output a single integer representing the minimum possible total thermal maintenance cost of the remaining active links after a valid sequence of isolation procedures.

<RATIONALE>
The rewrite replaces the explicit concept of "connected components" and "cohesiveness" with a boolean assignment problem (phase-locking). This forces models to logically deduce that the phase-locked condition is mathematically equivalent to connectivity. The word "trivially" was removed to comply with strict vocabulary constraints, and the sentences were shortened to improve readability and reduce ambiguity.
</RATIONALE>
<PRESERVED_ANSWER>
The phase-locked condition is exactly equivalent to graph connectivity, meaning the valid operations and final minimum weight subgraph remain identical to the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure is still finding the minimum weight connected subgraph spanning a set of required vertices in a tree, which is solvable in linear time.
</PRESERVED_CLASS>
<RISK>
The definition of "phase-locked" using binary states might be misread as a 2-SAT or bipartite graph problem by models relying on superficial pattern matching, though careful reading reveals it defines connectivity.
</RISK>
