# Problem B — Operational Enclave

Time limit: 2 s   Memory limit: 256 MB

## Description

You are coordinating the startup of a facility containing **n** modules, numbered 1 to **n**. You are provided with a blueprint of **m** potential bidirectional interfaces. Each interface links two modules and requires a specific energy cost to activate.

The **m = n - 1** potential interfaces in the blueprint fully integrate the facility: all modules are linked, and there is exactly one non-repeating sequence of interfaces between any two modules. (There are no self-linking interfaces and no duplicate interfaces between the same pair of modules).

A subset of **t** modules are designated as **primary modules**. Your objective is to choose a set of interfaces of minimum total energy cost so that all primary modules are connected (possibly routing through non-primary modules).

To formally define your selection, you must designate a subset of modules to act as the **operational enclave**. This enclave must satisfy the following conditions:
1. It must include all **t** primary modules.
2. The chosen interfaces will be EXACTLY those potential interfaces that have BOTH of their endpoints within the enclave.
3. These chosen interfaces must successfully connect all modules in the enclave into a single contiguous network.

Note carefully regarding the second condition: because an interface is automatically chosen (and its cost incurred) whenever both its endpoints are in the enclave, adding non-primary modules to bridge gaps will force the inclusion of any interface connecting them to other modules in the enclave. Your goal is to minimize the total energy cost of all chosen interfaces.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line provides **t** distinct integers representing the labels of the primary modules.
Each of the subsequent **m** lines provides three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating a potential bidirectional interface between module **u** and module **v** with an activation energy cost of **w**.

## Output

Output a single integer representing the minimum total energy cost of the chosen interfaces.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

**Output**
```

```

### Example 3

**Input**
```
3 2 3

1 2 4
2 3 5
```

**Output**
```
9
```
