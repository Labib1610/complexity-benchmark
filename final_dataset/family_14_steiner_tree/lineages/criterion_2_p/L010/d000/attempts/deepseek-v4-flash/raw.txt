We are given a tree (since m = n-1 and exactly one path between any two nodes).  
We need to connect all terminal (spore) nodes with minimal total edge cost.  
This is equivalent to finding the minimal subtree that connects all terminals, which is the **Steiner tree** on a tree graph — and on a tree, the minimal subtree is simply the union of all paths between terminals.  

We can solve it by:

1. Mark all spore nodes.
2. Do a DFS/BFS to find the minimal subtree that contains all marked nodes.
3. The cost is the sum of edges in that subtree.

A common efficient method:
- Root the tree at any node.
- For each node, compute if its subtree contains any spore node.
- An edge (parent → child) is included if the child’s subtree contains at least one spore node.
- Sum the weights of included edges.

This works because if a subtree contains a spore, the edge connecting it to its parent must be in the minimal connecting subtree.

Let’s implement it.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    spores = set(map(int, input().split()))
    
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    # Root the tree at 0
    parent = [-1] * n
    parent_w = [0] * n
    order = [0]
    stack = [0]
    parent[0] = -2  # mark root
    while stack:
        u = stack.pop()
        for v, w in adj[u]:
            if parent[v] == -1:
                parent[v] = u
                parent_w[v] = w
                stack.append(v)
                order.append(v)
    
    has_spore = [False] * n
    for s in spores:
        has_spore[s-1] = True
    
    # Process in reverse order (post-order)
    total_cost = 0
    for u in reversed(order):
        if u == 0:
            continue
        if has_spore[u]:
            total_cost += parent_w[u]
            # propagate up
            p = parent[u]
            while p != -2 and not has_spore[p]:
                has_spore[p] = True
                total_cost += parent_w[p]
                p = parent[p]
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
