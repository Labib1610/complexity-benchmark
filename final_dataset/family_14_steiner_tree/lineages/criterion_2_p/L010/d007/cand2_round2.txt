Semantic Equivalence Constraint
</METHOD_NAME>
<METHOD_DESCRIPTION>
Reformulates the graph connectivity problem as an equivalence relation problem over abstract variables, where activating a constraint enforces equality. The required terminals become variables that must be forced to take the same value. The tree structure guarantees unique paths of equivalence. This obfuscates the spatial "routing" and "spanning tree" keywords, forcing models to infer that transitive equality over unique constraint paths is mathematically identical to finding a minimal subtree.
</METHOD_DESCRIPTION>

<STATEMENT>
# Variable Coherence Enforcement

Time limit: 2 s   Memory limit: 256 MB

## Description

A computational model consists of $n$ distinct variables, numbered $1$ to $n$. The model provides $m$ possible bidirectional equality constraints. The model's architecture ensures that all variables are interlinked in a single contiguous constraint network. To minimize structural redundancy, the total number of available constraints $m$ is strictly fixed at exactly $n - 1$, meaning there is exactly one unique sequence of constraints between any two variables.

A specific subset of $t$ variables are designated as target variables.

You must select a subset of the $m$ available constraints to enforce. Enforcing the constraint between variable $u$ and variable $v$ incurs a one-time penalty of $w$. Constraints that are not enforced have no effect.

The selected subset of enforced constraints must satisfy the coherence mandate: all target variables must be logically forced to hold the exact same value. Equality is transitive and may propagate through intermediate non-target variables, provided every constraint along the chain of equivalence has been enforced.

Your objective is to determine the minimum possible total penalty required to enforce a valid set of constraints that satisfies this mandate. (If only one target variable exists, no equivalence between multiple targets is needed, and zero constraints need to be enforced).

## Input

The first line provides three integers: $n$, $m$, and $t$. The system supports up to two hundred thousand variables ($1 \le n \le 200000$). The number of constraints $m$ is always strictly $n - 1$ ($m = n - 1$). The number of target variables $t$ can range from a single variable up to the entire system ($1 \le t \le n$).

The second line contains $t$ distinct integers representing the IDs of the target variables (each between $1$ and $n$).

Following this, there are $m$ lines, each detailing a single available equality constraint with three integers: $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$). The penalty $w$ for enforcing any single constraint is at least one and does not exceed one million units ($1 \le w \le 1000000$).

## Output

Print a single integer: the minimum possible total penalty required to enforce a set of constraints such that all target variables are forced to be equal.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the target variables are 1 and 4. To ensure variable 1 is forced to equal variable 4, the constraints between 1 and 2 (penalty 5), 2 and 3 (penalty 1), and 3 and 4 (penalty 2) must be enforced. The total penalty is 5 + 1 + 2 = 8. This is the minimum possible total penalty.
In Example 2, there is only one target variable (variable 3). Since no equivalence between multiple targets is required, no constraints need to be enforced. The minimum possible total penalty is 0.
</STATEMENT>
<RATIONALE>
The problem was shifted from spatial connectivity ("routing materials") to logical equivalence ("equality constraints"). This removes standard spatial keywords that trigger spanning-tree templates. Models must now deduce that enforcing transitive equality over a constraint network with exactly one unique sequence between any two variables is mathematically identical to finding a minimal subtree connecting terminal nodes. All numeric bounds have been restored to their exact mathematical notation in parentheses to satisfy the formal contract checker.
</RATIONALE>
<PRESERVED_ANSWER>
The structural requirement to enforce transitive equality across the targets on a tree of constraints exactly mirrors the requirement to connect terminals on a tree of edges, meaning the same subset of edges is always optimal and yields the exact same total weight.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying graph is still a tree and the operation is still finding the Steiner tree for a subset of vertices, keeping the time complexity at O(n) and the class in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "equality constraints" as a system of equations to be solved algebraically rather than a graph to be traversed, but the explicit mention of "interlinked in a single contiguous constraint network" and "unique sequence of constraints" strongly clarifies the graph structure.
</RISK>
