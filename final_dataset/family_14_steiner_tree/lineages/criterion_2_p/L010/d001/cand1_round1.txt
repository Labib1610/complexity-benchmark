<STATEMENT>
# Intercellular Nutrient Allocation

Time limit: 2 s   Memory limit: 256 MB

## Description

An organism's nutrient distribution system is made up of **n** junctions and **m** microscopic tubes. The system is fully contiguous: if every tube were functional, nutrients could travel between any two junctions in the organism.

Reproduction requires **t** specific spore-bearing junctions to be mutually connected so they can share nutrients. A tube only allows nutrient flow if it receives metabolic activation. Activating a tube between junction **u** and junction **v** incurs a metabolic cost of **w**.

Calculate the minimum total metabolic cost needed to activate a collection of tubes that provides a valid nutrient exchange route between every pair of spore-bearing junctions.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers: the identifiers of the junctions containing reproductive spores.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): representing a tube linking junction **u** and junction **v** with an activation cost of **w**. The tubes form the contiguous system described above.

## Output

Print a single integer: the minimum total metabolic cost to link all spore-bearing junctions.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the spore-bearing junctions 1 and 4 can only exchange nutrients via junctions 2 and 3, so all three tubes (costs 5, 1, and 2) must be activated, totaling 8.
In Example 2, there is only one spore-bearing junction, so no tubes need to be activated.

</RATIONALE>
