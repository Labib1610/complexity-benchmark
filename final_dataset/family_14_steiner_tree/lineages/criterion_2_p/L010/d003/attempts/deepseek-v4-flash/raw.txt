 We can solve this by finding the minimal subtree that connects all the quality control stations.  
Since the graph is a tree, the minimal connected subgraph containing all special nodes is the union of paths between them, which is the **Steiner tree** in a tree — and that’s simply the minimal subtree spanning all special nodes.

We can do this efficiently:

1. Mark the special nodes.
2. Do a DFS from any special node to find the farthest special node (this gives one endpoint of the diameter of the special-node set).
3. From that endpoint, do another DFS to find the total weight of the minimal subtree spanning all special nodes.

The minimal subtree weight = (sum of weights of all edges in the minimal subtree).  
We can compute it by doing a DFS from one special node, and for each edge, if the subtree on one side contains at least one special node, then that edge must be included.

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    specials = set(map(int, input().split()))
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    if t <= 1:
        print(0)
        return
    
    # DFS to count special nodes in subtree and total weight
    visited = [False] * (n+1)
    total_weight = 0
    
    def dfs(u, parent):
        nonlocal total_weight
        visited[u] = True
        cnt = 1 if u in specials else 0
        for v, w in adj[u]:
            if v == parent:
                continue
            child_cnt = dfs(v, u)
            if child_cnt > 0:
                total_weight += w
            cnt += child_cnt
        return cnt
    
    # Start from any special node
    start = next(iter(specials))
    dfs(start, -1)
    
    print(total_weight)

if __name__ == "__main__":
    solve()
```
