<STATEMENT>
# Industrial Component Routing

Time limit: 2 s   Memory limit: 256 MB

## Description

An industrial manufacturing complex features **n** distinct workstations, linked together by **m** bidirectional conveyor belts. The complex is fully integrated, meaning that for any pair of workstations, there exists exactly one valid route of belts connecting them. 

A specific subset of **t** workstations are specialized quality control stations. To run a full diagnostic protocol, every quality control station must be able to send components to every other quality control station. A belt can only transport components if it is supplied with power, and activating the belt connecting workstation **u** and workstation **v** requires a specific energy overhead **w**. Components are permitted to transit through any number of regular (non-quality control) workstations along their route, as long as the connecting belts are powered.

Your task is to find the minimum total energy overhead needed to activate a selection of conveyor belts, ensuring that all **t** quality control stations are interconnected.

## Input

The first line provides three integers: **n**, **m**, and **t** (1 ≤ **n** ≤ 200000, 1 ≤ **t** ≤ **n**, **m** = **n** − 1). Because of the strict integration layout, the number of belts **m** is always exactly one less than the number of workstations.

The second line contains **t** distinct integers representing the IDs of the quality control stations.

Following this, there are **m** lines, each detailing a single conveyor belt with three integers: **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000). This indicates a belt between workstation **u** and workstation **v** requiring energy overhead **w**. These belts form the fully integrated network mentioned previously.

## Output

Print a single integer: the minimum total energy overhead required to interconnect all quality control stations.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the quality control stations 1 and 4 can only exchange components via workstations 2 and 3, so all three conveyor belts (overheads 5, 1, and 2) must be powered on, totaling 8.
In Example 2, there is only one quality control station, so no conveyor belts need to be powered on.
