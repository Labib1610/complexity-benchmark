<STATEMENT>
# Industrial Component Routing

Time limit: 2 s   Memory limit: 256 MB

## Description

An industrial complex contains **n** manufacturing units. These units are joined by **m** bidirectional transfer tubes. The complex is fully integrated: components can be routed between any two units. Furthermore, the layout has no redundant tubes, meaning there is exactly one unique route of transfer tubes between any pair of units.

Within the complex, **t** units operate as inspection labs. To run a specific diagnostic, all inspection labs must be able to exchange components with each other. Components can travel freely through any transfer tube that is powered on. Activating the transfer tube between unit **u** and unit **v** requires a specific calibration cost **w**.

Determine the minimum total calibration cost required to power on a set of transfer tubes such that every inspection lab can exchange components with every other inspection lab (potentially routing through other intermediate units).

## Input

The first line contains three integers **n**, **m**, and **t**. The complex supports a capacity of up to 200000 manufacturing units (so 1 ≤ **n** ≤ 200000). The count of inspection labs **t** satisfies 1 ≤ **t** ≤ **n**. Because there are no redundant connections, exactly one unique path exists between any two units, making **m** = **n** − 1.

The second line contains **t** distinct integers: the identifiers of the inspection labs.

Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), representing a transfer tube linking unit **u** and unit **v**. The calibration cost **w** is bounded by a maximum safety rating (1 ≤ **w** ≤ 1000000). The transfer tubes form the fully integrated structure where every unit is reachable.

## Output

Print a single integer: the minimum total calibration cost to link all inspection labs.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the inspection labs 1 and 4 can only exchange components via units 2 and 3, so all three transfer tubes (costs 5, 1, and 2) must be powered on, totaling 8.
In Example 2, there is only one inspection lab, so no transfer tubes need to be powered on.

The problem text was rewritten to replace "conveyor belts" and "workstations" with "transfer tubes" and "manufacturing units". The topological guarantee that the graph is a tree was rephrased: instead of directly stating "m = n - 1" as a physical dictate in isolation, it is now explicitly tied to the property that "there is exactly one unique route ... between any pair of units." This forces the model to reason about the topological structure (a tree) from the unique-path property rather than relying on standard tree-terminology or isolated edge-count rules.
</RATIONALE>

</PRESERVED_ANSWER>
