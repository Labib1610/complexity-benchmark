<STATEMENT>
# Equivalence Enforcement

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of $n$ variables, numbered $1$ to $n$. You are given a list of $m$ optional equality constraints. Each constraint continuously enforces that variable $u$ and variable $v$ maintain the exact same value, and requires a one-time computational cost of $w$ to activate.

The provided set of constraints guarantees that if you were to activate all $m$ of them, all $n$ variables would be forced to a single uniform value. The total number of available constraints $m$ is exactly $n - 1$.

A specific subset of $t$ variables are designated as target variables. 

You must select a subset of the constraints to activate such that all $t$ target variables are guaranteed to hold the exact same value, purely through the direct and transitive effects of the activated constraints. 

Your objective is to determine the minimum possible total cost required to activate a valid set of constraints. (If $t = 1$, the minimum cost is 0).

## Input

The first line provides three integers: $n$, $m$, and $t$. The system supports up to two hundred thousand variables ($1 \le n \le 200000$). The number of available constraints $m$ is always exactly $n - 1$. The number of target variables $t$ can range from a single variable up to all variables ($1 \le t \le n$).

The second line contains $t$ distinct integers representing the indices of the target variables.

Following this, there are $m$ lines, each detailing a single equality constraint with three integers: $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$). The one-time cost $w$ for activating any single constraint is at least one and does not exceed one million units ($1 \le w \le 1000000$).

## Output

Print a single integer: the minimum possible total cost required to activate a set of constraints such that all target variables share the same value.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the target variables are 1 and 4. To ensure variable 1 and variable 4 share the same value, the constraints between 1 and 2 (cost 5), 2 and 3 (cost 1), and 3 and 4 (cost 2) must be activated. The total cost is 5 + 1 + 2 = 8. This is the minimum possible total cost.

In Example 2, there is only one target variable (variable 3). Since no enforcement across multiple target variables is required, zero constraints need to be activated. The minimum possible total cost is 0.

<PRESERVED_ANSWER>
The constraints form a graph with identical structure and weights; finding the minimal cost to enforce equality among target variables is mathematically identical to finding the minimum weight subtree spanning the critical nodes.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem requires computing the weight of the minimal spanning subtree for a given set of nodes in a tree, which remains solvable in O(n) time via DFS/BFS.
</PRESERVED_CLASS>
