<METHOD_NAME>Linear System Degrees of Freedom</METHOD_NAME>
<METHOD_DESCRIPTION>Transforms the graph connectivity problem into a problem of selecting linear equations to enforce equality among a subset of variables. The tree property (n-1 edges, fully connected) is restated as "n-1 equations that reduce the system's degrees of freedom to 1". This obscures the graph structure and makes models likely to attempt algebraic or general set-cover algorithms instead of tree DFS, while preserving the exact mathematical structure.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Subspace Constraint Selection

Time limit: 2 s   Memory limit: 256 MB

## Description

You are working with a vector space of dimension $n$ over the real numbers, with coordinates $(x_1, x_2, \dots, x_n)$.

You are provided a pool of $m$ optional linear constraints. Each constraint enforces the equation $x_u = x_v$ and requires a one-time cost of $w$ to include in your system.

It is mathematically guaranteed that if you were to include all $m$ constraints, the resulting system of equations would have exactly one degree of freedom, meaning the only valid solutions would be those where $x_1 = x_2 = \dots = x_n$. The total number of available constraints $m$ is exactly one less than the dimension $n$.

A specific subset $T$ consisting of $t$ coordinate indices is designated as the target.

Your objective is to select a subset of the available constraints such that, for any vector satisfying the selected constraints, all coordinates whose indices are in $T$ are strictly mathematically forced to be equal (i.e., $x_c = x_{c'}$ for all $c, c' \in T$). 

You must determine the minimum possible total cost of the selected constraints. (If $T$ contains only one index, no constraints are needed, and the cost is zero).

## Input

The first line provides three integers: $n$, $m$, and $t$. The dimension $n$ is at least 1 and can be up to the number of centimeters in exactly two kilometers. The number of constraints $m$ is always exactly one less than the dimension $n$. The size of the target subset $t$ ranges from a single index up to the full dimension.

The second line contains $t$ distinct integers representing the indices in $T$.

Following this, there are $m$ lines, each detailing a single constraint with three integers: $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$). The cost $w$ for including any single constraint is at least one and does not exceed the number of grams in exactly one metric tonne.

## Output

Print a single integer: the minimum possible total cost required to select a valid set of constraints.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the target subset is {1, 4}. To ensure that $x_1 = x_4$ is forced by the system, the constraints $x_1 = x_2$ (cost 5), $x_2 = x_3$ (cost 1), and $x_3 = x_4$ (cost 2) must be included. The total cost is 5 + 1 + 2 = 8. This is the minimum possible total cost.

In Example 2, there is only one target index (3). Since no constraints are required to force a single coordinate to equal itself, zero constraints need to be selected. The minimum possible total cost is 0.
</STATEMENT>
<RATIONALE>
The problem was reframed from a network synchronization scenario into a linear algebra constraint-selection problem. The graph's nodes are now vector space coordinates, and its edges are equations of the form $x_u = x_v$. The tree guarantee ($n-1$ edges connecting all nodes) is now described as $n-1$ equations reducing the system to 1 degree of freedom. This forces the model to mathematically deduce that the incidence matrix of these constraints forms a tree, rather than relying on standard graph keywords to trigger a tree-DFS template. Furthermore, physical constants (centimeters in 2 km, grams in a metric tonne) were used to encode the bounds indirectly.
</RATIONALE>
<PRESERVED_ANSWER>
Selecting a subset of equations $x_u = x_v$ to enforce $x_c = x_{c'}$ for all $c \in T$ is mathematically identical to selecting a subset of edges such that all vertices in $T$ belong to the same connected component; because the full set of constraints forms a tree, the minimal valid subset is exactly the unique minimal connecting subtree, keeping all answers identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains a tree with required terminal nodes, meaning the optimal solution is still found in $O(n)$ time by rooting the tree and pruning leaves that do not lead to any target node.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "vector space" and attempt to use floating-point Gaussian elimination, but this is an intended trap for models that fail to recognize the combinatorial tree structure underlying the equations.
</RISK>
