We are given a graph with \( n \) vertices and \( n-1 \) edges, each edge \( (u, v) \) with weight \( w \) representing vector \( e_u - e_v \).  
We need to select a subset of edges such that for all pairs of target vertices, the difference vector is in the span.  

Since \( m = n-1 \), the graph is a tree (if connected) or a forest.  
The condition that all \( e_i - e_j \) are in the span when all edges are taken means the graph is connected — so it’s a tree.

We need to connect all target vertices in the tree.  
The minimal cost to connect a set of vertices in a tree is the sum of weights of edges in the minimal subtree that spans all target vertices.  
This is a classic problem: find the minimal Steiner tree for a set of terminals in a tree, which is just the union of all edges on paths between terminals.

We can solve it by:
1. Mark target vertices.
2. Do a DFS from any target vertex, count edges that are on paths between targets.

**Approach:**
- Build adjacency list.
- Root the tree at any target vertex.
- DFS to compute for each node whether its subtree contains any target.
- An edge (parent–child) is needed if the child’s subtree contains at least one target and the rest of the tree (outside that subtree) also contains at least one target.  
  Equivalently: if the child’s subtree has at least one target and the total number of targets is greater than the number of targets in that subtree.

We can compute this with a single DFS.

Let’s implement:

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    targets = set(map(int, input().split()))
    adj = [[] for _ in range(n+1)]
    edges = []
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
        edges.append((u, v, w))
    
    if t <= 1:
        print(0)
        return
    
    # Root at any target
    root = next(iter(targets))
    parent = [0]*(n+1)
    parent_w = [0]*(n+1)
    order = [root]
    parent[root] = -1
    stack = [root]
    while stack:
        u = stack.pop()
        for v, w in adj[u]:
            if v != parent[u]:
                parent[v] = u
                parent_w[v] = w
                stack.append(v)
                order.append(v)
    
    # Count targets in subtree
    cnt = [0]*(n+1)
    for v in targets:
        cnt[v] = 1
    
    total_cost = 0
    # Process in reverse order (post-order)
    for u in reversed(order):
        if u == root:
            continue
        p = parent[u]
        if cnt[u] > 0 and t - cnt[u] > 0:
            total_cost += parent_w[u]
        cnt[p] += cnt[u]
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
