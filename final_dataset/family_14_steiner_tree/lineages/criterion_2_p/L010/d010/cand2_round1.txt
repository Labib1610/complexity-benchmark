<STATEMENT>
# Basis Subspace Pricing

Time limit: 2 s   Memory limit: 256 MB

## Description

You are working with a vector space defined by $n$ abstract variables, indexed from $1$ to $n$. Let $x_i$ denote the $i$-th variable.

You are given a pool of $m$ available difference generators. Each available generator is specified by two indices $u$ and $v$ and an associated price $w$, representing the expression $x_u - x_v$. The price to include this generator in your chosen working set is $w$. 

You are mathematically guaranteed that the set of all $m$ available generators forms a basis for the subspace of all expressions whose variable coefficients sum to zero. Consequently, their linear span contains all expressions of the form $x_i - x_j$ for any $1 \le i, j \le n$. Because they form a basis, there is exactly one minimal linear combination of the available generators that evaluates to any specific difference $x_i - x_j$.

A specific subset of $t$ indices are designated as target variables. 

You must select a subset of the available generators to form a working set. Your working set must satisfy the following condition: for every pair of target variables $c_a$ and $c_b$, the difference expression $x_{c_a} - x_{c_b}$ must be in the linear span of your working set. 

Your objective is to determine the minimum possible total price of a working set that satisfies this requirement. 

If there is only one target variable, the requirement is vacuously satisfied by an empty working set, and the minimum price is zero.

## Input

The first line provides three integers: $n$, $m$, and $t$. The system memory architecture dictates that the number of variables $n$ is at least one and capped at exactly two hundred thousand. The number of available generators $m$ is always exactly the dimension of the zero-sum subspace, which is $n - 1$. The number of target variables $t$ can range from a single variable up to the entire set of $n$ variables.

The second line contains $t$ distinct integers representing the indices of the target variables.

Following this, there are $m$ lines, each detailing a single available generator with three integers: $u$, $v$, and $w$. This represents the generator $x_u - x_v$. The indices $u$ and $v$ are distinct valid variables (between $1$ and $n$). The price $w$ is a strictly positive integer capped by the system's maximum unit cost of one million.

## Output

Print a single integer: the minimum possible total price required to select a valid working set of generators.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the target variables are 1 and 4. We must ensure $x_1 - x_4$ is in the linear span of our selected working set. By selecting the generators $x_1 - x_2$ (price 5), $x_2 - x_3$ (price 1), and $x_3 - x_4$ (price 2), we can form the linear combination $x_1 - x_4 = (x_1 - x_2) + (x_2 - x_3) + (x_3 - x_4)$. The total price is 5 + 1 + 2 = 8. Because the available generators form a basis, no cheaper subset spans this difference.

In Example 2, there is only one target variable (variable 3). Since there are no pairs of distinct target variables, the condition is vacuously satisfied by the empty set. The minimum possible total price is 0.

<RATIONALE>
The explicit graph terminology ("connected network", "alternative routes", "sequence") was removed to prevent models from immediately pattern-matching to a tree data structure. The problem is now framed entirely in terms of linear algebra and matroid bases, forcing the model to independently deduce that a basis of difference vectors is isomorphic to a spanning tree, and that finding the minimal spanning subset for target differences equates to computing a Steiner tree on that spanning tree.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical structure is identical (the generators form a spanning tree, and the required working set is the unique minimal subtree connecting the target vertices), so the minimum price remains exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks for the minimum weight of edges required to connect a subset of vertices in a given tree, which is solvable in O(n) time by rooting the tree and aggregating subtree target counts.
</PRESERVED_CLASS>
<RISK>
None. The linear algebra terminology rigorously and unambiguously defines the identical mathematical constraints as the original graph framing.
