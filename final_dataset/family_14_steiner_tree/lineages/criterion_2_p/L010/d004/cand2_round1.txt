<STATEMENT>
# Differential Profiling

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of **n** unknown scalar variables. 

You cannot measure these variables directly. Instead, you are offered a specific set of **m** differential tests. Performing the test between variable **u** and variable **v** reveals their exact numerical difference (i.e., the value of **u** - **v**), and requires **w** minutes of computation time. 

The set of **m** available tests is structurally complete and non-redundant: there are exactly **n** - 1 tests offered, and if you were to perform all of them, you would be able to deduce the relative differences between all **n** variables.

You have been tasked with profiling a specific subset of **t** critical variables. To complete this profile, you must select and perform a subset of the available tests such that, using *only* the numerical results of your selected tests, you can mathematically deduce the exact difference between *every possible pair* of variables within the critical subset.

Your goal is to find the minimum total computation time (the sum of the times of the selected tests) required to achieve this.

## Input

The first line provides three integers: **n**, **m**, and **t** (1 ≤ **n** ≤ 200000, 1 ≤ **t** ≤ **n**, **m** = **n** − 1).

The second line contains **t** distinct integers representing the indices of the critical variables (1-indexed).

Following this, there are **m** lines, each detailing a single available test with three integers: **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000). This indicates a test between variable **u** and variable **v** requiring **w** minutes.

## Output

Print a single integer: the minimum total computation time required to perform a valid subset of tests.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, to deduce the difference between critical variables 1 and 4, you must chain the differences from the tests between (1,2), (2,3), and (3,4). Therefore, all three tests must be selected, requiring 5 + 1 + 2 = 8 minutes.

In Example 2, there is only one critical variable, so no differences need to be deduced, and 0 tests are required.
</STATEMENT>
<RATIONALE>
The problem was shifted from a physical routing network to an algebraic system of differences. The core requirement (finding the minimal subtree connecting target nodes) is preserved because deducing the difference between two variables mathematically requires a contiguous chain of relative differences (a path in the graph). This forces the model to realize that algebraic span in this context is equivalent to graph connectivity.
</RATIONALE>
<PRESERVED_ANSWER>
Because the underlying structure is a tree, there is exactly one path of differences between any two variables, meaning the minimal subset of tests required to deduce differences between all critical variables is exactly the unique minimal subtree connecting them, preserving the exact sum of weights.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains solvable in O(n) time by rooting the implicit tree and aggregating the branches that contain critical variables, keeping it firmly in P.
</PRESERVED_CLASS>
<RISK>
A reader might fail to mathematically connect "deduce the difference" with "forming a connected path", though this is a standard property of incidence matrices and linear equations that a competent algorithmic reasoner should be able to deduce.
</RISK>
