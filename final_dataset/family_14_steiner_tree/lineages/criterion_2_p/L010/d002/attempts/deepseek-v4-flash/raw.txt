We are given a tree (since m = n - 1 and it’s connected), and we need to connect all terminal (quality control) nodes with minimum total edge cost.  

This is equivalent to finding the **minimum Steiner tree** for the given terminals in a tree, which is simply the union of all edges that lie on paths between any two terminals.  

A standard way:  
- Root the tree at any terminal.  
- Do a DFS, and for each node, check if its subtree contains any terminal.  
- If a subtree contains at least one terminal, the edge from the node to its parent must be included.  

We sum the weights of all such edges.  

Here’s the implementation:  

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    terminals = set(map(int, input().split()))
    
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    if t == 1:
        print(0)
        return
    
    visited = [False] * (n + 1)
    total_cost = 0
    
    def dfs(u, parent_edge_cost):
        nonlocal total_cost
        visited[u] = True
        has_terminal = u in terminals
        for v, w in adj[u]:
            if not visited[v]:
                child_has = dfs(v, w)
                if child_has:
                    total_cost += w
                has_terminal = has_terminal or child_has
        return has_terminal
    
    # Start from any terminal
    start = next(iter(terminals))
    dfs(start, 0)
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
