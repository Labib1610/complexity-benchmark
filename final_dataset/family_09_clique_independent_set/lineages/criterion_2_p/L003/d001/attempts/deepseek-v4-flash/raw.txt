We can model the relays as vertices of a graph where edges are conflicts.  
The key observation is that conflicts only happen between vertices whose phase frequencies differ by an odd number.  
This means the graph is **bipartite**: we can color vertices by parity of their phase frequency.  
So the problem reduces to: can we pick exactly `k` vertices with no edges between them?  
That is equivalent to finding an independent set of size `k` in a bipartite graph.

We can solve this by:

1. Building the bipartite coloring (two color classes).
2. If `k` is larger than the size of the larger color class, it’s impossible (because an independent set can contain at most all vertices from one color class).
3. Otherwise, we can always pick `k` vertices from the larger color class (or a mix if needed, but picking from one class is always safe).

Let’s implement this.

```python
import sys
input = sys.stdin.readline

n, m, k = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
part = [[], []]

for i in range(n):
    if color[i] == -1:
        stack = [i]
        color[i] = 0
        part[0].append(i)
        while stack:
            u = stack.pop()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    part[color[v]].append(v)
                    stack.append(v)

if len(part[0]) < len(part[1]):
    part[0], part[1] = part[1], part[0]

if k > len(part[0]):
    print("NO")
else:
    print("YES")
    print(" ".join(str(x + 1) for x in part[0][:k]))
```
