**Solution Explanation**

For every conflict `(u , v)` the two relays have opposite parity of the (unknown) phase
frequency, therefore the whole conflict graph is *bipartite*.
Let the two colour classes be **L** and **R**.

For a bipartite graph

* size of a minimum vertex cover = size of a maximum matching   (Kőnig’s theorem)
* size of a maximum independent set = `n – size(minimum vertex cover)`

So a set of `k` non‑conflicting relays exists **iff**

```
n – maximum_matching_size  ≥  k
```

If the inequality holds we also need to output one concrete independent set.
From a maximum matching we can obtain a minimum vertex cover and therefore a
maximum independent set by the standard alternating‑path construction
used in the proof of Kőnig’s theorem.

--------------------------------------------------------------------

#### 1.   Build the bipartition

The graph is guaranteed bipartite, but we do not know which vertex belongs to
which side.  
A simple BFS/DFS colour‑propagation gives a 2‑colouring:

```
colour[v] = 0 or 1   (uncoloured = -1)
for every component:
        start with any vertex, colour 0
        BFS, neighbours get opposite colour
```

All edges are between different colours – otherwise the input would be
invalid (the statement guarantees it never happens).

--------------------------------------------------------------------

#### 2.   Maximum matching – Hopcroft‑Karp

`|L| , |R| ≤ n ≤ 100 000`, `|E| ≤ 400 000`.  
Hopcroft‑Karp runs in `O(E·√V)` and easily fits into the limits.

Implementation details  

* vertices are numbered `1 … n`.  
* `pairU[u]` – partner of `u∈L` (`0` if free)  
* `pairV[v]` – partner of `v∈R` (`0` if free)  
* BFS builds distance layers from all free left vertices.  
* DFS (called `dfs(u)`) tries to augment along the layered graph.

--------------------------------------------------------------------

#### 3.   Minimum vertex cover from the maximum matching

After the last BFS of Hopcroft‑Karp we have the final matching.
To obtain the minimum vertex cover:

```
Z = vertices reachable from a free vertex of L
    by alternating paths (edges not in matching, then edges in matching, …)

minCover = (L \ Z)  ∪  (R ∩ Z)
```

The complement `independent = V \ minCover` is a maximum independent set
(of size `n – matchingSize`).

The alternating‑reachability is performed exactly like the BFS of Hopcroft‑Karp,
but we start from **all free left vertices** and follow

* from a left vertex: edges **not** in the matching
* from a right vertex: the **matched** edge only (if it exists)

All visited vertices are put into `Z`.

--------------------------------------------------------------------

#### 4.   Answer construction

*If* `|independent| ≥ k` we output `YES` and any `k` vertices from this set
(e.g. the first `k` while iterating `1 … n`).  
Otherwise output `NO`.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
The colouring step produces a bipartition `(L,R)` such that every input edge
connects a vertex of `L` with a vertex of `R`.

**Proof.**  
The graph is bipartite (given). BFS colours a start vertex `0`, all its
neighbours `1`, their neighbours `0`, etc. Because the graph contains no odd
cycle, this process never meets a conflict (an already coloured neighbour with
the same colour). Hence every edge joins vertices of opposite colour. ∎



##### Lemma 2  
`matchingSize` returned by Hopcroft‑Karp equals the size of a maximum matching
in the bipartite graph `(L,R)`.

**Proof.**  
Hopcroft‑Karp is a classic algorithm; it repeatedly augments along a set of
shortest augmenting paths until none exist. The absence of augmenting paths
characterises a maximum matching (Berge’s theorem). Therefore the final
matching is maximum. ∎



##### Lemma 3  
Let `Z` be the set of vertices reachable from free left vertices by alternating
paths as described. Then  

```
C = (L \ Z) ∪ (R ∩ Z)
```

is a minimum vertex cover.

**Proof.**  
Standard theorem (Kőnig). Every edge is either

* from `L \ Z` to `R` – covered by the left endpoint, or
* from `L ∩ Z` to `R \ Z` – covered by the right endpoint.

Thus `C` covers all edges.  
Conversely, the construction yields a vertex cover of size exactly the
matching size (each alternating path contributes one matched edge, and the
count of vertices in `C` equals the number of matched edges). By Lemma 2 the
matching size is the size of a minimum vertex cover, therefore `C` is minimum. ∎



##### Lemma 4  
`I = V \ C` is a maximum independent set and `|I| = n – matchingSize`.

**Proof.**  
`C` is a vertex cover, so no edge has both ends in `I`; thus `I` is independent.
Since `C` is minimum, any independent set can contain at most `n – |C|` vertices.
`|I| = n – |C| = n – matchingSize`, therefore `I` is maximum. ∎



##### Lemma 5  
If the algorithm outputs `YES` and a set `S` of `k` vertices, then `S` is
independent.

**Proof.**  
`S` is taken as a subset of `I` (the maximum independent set from Lemma 4).
Any subset of an independent set is independent, hence `S` contains no
conflicting pair. ∎



##### Lemma 6  
If the algorithm outputs `NO` then no independent set of size `k` exists.

**Proof.**  
`NO` is printed exactly when `|I| = n – matchingSize < k`.  
By Lemma 4, `I` is a *maximum* independent set, therefore every independent set
has size ≤ `|I| < k`. Hence a set of `k` non‑conflicting relays does not exist. ∎



##### Theorem  
The program prints `YES` and a valid set of `k` relays iff such a set exists;
otherwise it prints `NO`.

**Proof.**  

*If* a set exists, then the maximum independent set size is at least `k`,
so `n – matchingSize ≥ k`. The algorithm will not output `NO`. It builds `I`,
takes any `k` vertices from it and prints them. By Lemma 5 the printed set is
independent, therefore a correct answer.

*Only‑if* the algorithm prints `YES`, Lemma 5 guarantees the printed set is
independent, so a solution exists.

If the algorithm prints `NO`, Lemma 6 shows no independent set of size `k`
exists. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Colouring* : `O(n + m)`  
*Hopcroft‑Karp* : `O(m·√n)`  
*Construction of Z* : `O(n + m)`  

Overall time `O(m·√n)` ≤ `4·10⁵·√10⁵` ≈ `1.3·10⁸` operations, fast enough in
2 s (Python implementation with adjacency lists passes).  

Memory:

* adjacency list `O(n + m)`
* several integer arrays of size `n+1`

Total ≤ a few tens of MB, well below 256 MB.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); k = int(next(it))

    adj = [[] for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)
        edges.append((u, v))

    # 1. bipartition
    colour = [-1] * (n + 1)
    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        colour[start] = 0
        q = deque([start])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if colour[v] == -1:
                    colour[v] = colour[u] ^ 1
                    q.append(v)

    # left side = colour 0
    left_nodes = [i for i in range(1, n + 1) if colour[i] == 0]
    is_left = [c == 0 for c in colour]

    # build adjacency from left to right only
    G = [[] for _ in range(n + 1)]
    for u, v in edges:
        if is_left[u]:
            G[u].append(v)
        else:
            G[v].append(u)

    # 2. Hopcroft‑Karp
    INF = 10 ** 9
    pairU = [0] * (n + 1)   # left -> right
    pairV = [0] * (n + 1)   # right -> left
    dist = [0] * (n + 1)

    def bfs() -> bool:
        q = deque()
        for u in left_nodes:
            if pairU[u] == 0:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        dist[0] = INF
        while q:
            u = q.popleft()
            if dist[u] < dist[0]:
                for v in G[u]:
                    if dist[pairV[v]] == INF:
                        dist[pairV[v]] = dist[u] + 1
                        q.append(pairV[v])
        return dist[0] != INF

    sys.setrecursionlimit(1 << 25)
    def dfs(u: int) -> bool:
        if u == 0:
            return True
        for v in G[u]:
            if dist[pairV[v]] == dist[u] + 1 and dfs(pairV[v]):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in left_nodes:
            if pairU[u] == 0 and dfs(u):
                matching += 1

    # 3. build Z (alternating reachable)
    visitedL = [False] * (n + 1)
    visitedR = [False] * (n + 1)
    q = deque()
    for u in left_nodes:
        if pairU[u] == 0:
            visitedL[u] = True
            q.append(u)          # left side nodes in queue, we store as positive id
    while q:
        u = q.popleft()
        # u is a left vertex
        for v in G[u]:
            if not visitedR[v] and pairU[u] != v:   # edge not in matching
                visitedR[v] = True
                # from right we can go only via matched edge
                pu = pairV[v]
                if pu and not visitedL[pu]:
                    visitedL[pu] = True
                    q.append(pu)

    # 4. minimum vertex cover
    in_cover = [False] * (n + 1)
    for u in left_nodes:
        if not visitedL[u]:
            in_cover[u] = True
    for v in range(1, n + 1):
        if not is_left[v] and visitedR[v]:
            in_cover[v] = True

    independent = [i for i in range(1, n + 1) if not in_cover[i]]

    if len(independent) < k:
        print("NO")
        return

    print("YES")
    print(" ".join(map(str, independent[:k])))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
