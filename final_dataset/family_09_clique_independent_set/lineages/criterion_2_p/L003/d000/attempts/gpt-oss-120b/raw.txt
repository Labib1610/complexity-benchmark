**Solution Explanation**

For the given graph

* vertices are the relays `1 … n`
* every conflict edge connects a relay of the first power grid with a relay of the
  second grid – the graph is **bipartite** (the two grids are the two parts).

For a bipartite graph

* a **vertex cover** – a set of vertices touching every edge –
* a **matching** – a set of pairwise disjoint edges –

are linked by **Kőnig’s theorem**

```
size(minimum vertex cover) = size(maximum matching)
```

The complement of a vertex cover is an **independent set**
(no edge inside it).  
Therefore

```
maximum independent set size = n – size(maximum matching)
```

If this maximum size is at least `k` we can output any `k` vertices of an
independent set, otherwise the answer is `NO`.

So we have to

1. reconstruct the bipartition (the two grids) – the input does not give it,
2. find a maximum matching,
3. from it obtain a minimum vertex cover,
4. output `k` vertices outside the cover.



--------------------------------------------------------------------

#### 1.   Reconstructing the bipartition  

A BFS/DFS 2‑colouring works because the graph is guaranteed bipartite.

```
color[v] = 0 or 1   (unvisited = -1)
for every vertex not coloured yet:
        start BFS, assign colour 0 to the start,
        neighbours get opposite colour.
```

All edges go between colour `0` and colour `1`.

--------------------------------------------------------------------

#### 2.   Maximum matching – Hopcroft‑Karp  

Let  

* `L` = vertices with colour `0` (left side)  
* `R` = vertices with colour `1` (right side)

Only edges `L → R` are stored.

Hopcroft‑Karp runs in `O(E √V)` – fast enough for `n ≤ 10⁵ , m ≤ 4·10⁵`.

It maintains

* `pairU[u]` – partner of `u ∈ L` (`0` if free)
* `pairV[v]` – partner of `v ∈ R` (`0` if free)

and repeatedly performs BFS layering + DFS augmentations.

--------------------------------------------------------------------

#### 3.   Minimum vertex cover from a maximum matching  

Standard construction:

```
Z = vertices reachable from any unmatched left vertex
    by alternating paths (edges not in matching, then in matching, …)

minimum vertex cover = (L \ Z)  ∪  (R ∩ Z)
```

Implementation:

* BFS starting from all free left vertices,
* follow **non‑matching** edges from left to right,
  **matching** edges from right to left,
* mark visited vertices (`visL`, `visR`).

--------------------------------------------------------------------

#### 4.   Building the answer  

`independent = vertices not in the cover`

If `len(independent) >= k` → `YES` and output any `k` of them.  
Otherwise → `NO`.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
The BFS 2‑colouring assigns opposite colours to the endpoints of every edge.

**Proof.**  
The graph is bipartite (given). BFS starts with an arbitrary vertex coloured `0`.
Whenever an edge `(x, y)` is traversed, `y` receives colour `1‑color[x]`.
Thus every visited edge connects vertices of different colours.
All vertices are eventually visited, so the property holds for all edges. ∎



##### Lemma 2  
`matching` returned by Hopcroft‑Karp is a maximum matching of the bipartite graph.

**Proof.**  
Hopcroft‑Karp is a classic algorithm; it repeatedly finds a maximal set of
shortest augmenting paths and augments along all of them.
It terminates exactly when no augmenting path exists, which by
Berge’s theorem is equivalent to maximality of the matching.
Therefore the final matching is maximum. ∎



##### Lemma 3  
Let `Z` be the set of vertices reachable from unmatched left vertices by
alternating paths (as constructed in step&nbsp;3).  
Then `C = (L \ Z) ∪ (R ∩ Z)` is a vertex cover and its size equals the size of
the matching found in Lemma&nbsp;2.

**Proof.**  
Standard theorem for bipartite graphs:

* Every edge either has its left endpoint in `L \ Z` (if the left endpoint is
  not reachable) or its right endpoint in `R ∩ Z` (if the left endpoint is
  reachable, then the edge is either a matching edge leading to a visited right
  vertex, or a non‑matching edge whose right endpoint is visited as well).
Thus every edge is incident to a vertex of `C` → `C` is a vertex cover.

Moreover, the construction yields `|C| = |matching|` (proved in textbooks).
∎



##### Lemma 4  
The set `I = V \ C` (vertices not in the cover) is an independent set of size
`n – |matching|`.

**Proof.**  
By definition of a vertex cover, every edge has at least one endpoint in `C`.
Consequently no edge can have both endpoints in `V \ C = I`; hence `I` is
independent.
Its size is `n – |C| = n – |matching|`. ∎



##### Lemma 5  
If the algorithm outputs `YES` and a set `S` of `k` vertices, then `S` is
independent.

**Proof.**  
The algorithm chooses `S` as a subset of `I` (the complement of the minimum
vertex cover). By Lemma&nbsp;4 `I` is independent, therefore any subset of it,
including `S`, is also independent. ∎



##### Lemma 6  
If the algorithm outputs `NO` then no independent set of size `k` exists.

**Proof.**  
`NO` is printed exactly when `|I| = n – |matching| < k`.
By Lemma&nbsp;4 `I` is a maximum independent set (its size equals the
graph’s independence number, because `|I| = n – size(minimum vertex cover)
= n – size(maximum matching)` and König’s theorem gives equality).
Hence any independent set has size at most `|I| < k`. ∎



##### Theorem  
The algorithm prints `YES` and a valid set of `k` relays
iff such a set exists; otherwise it prints `NO`.

**Proof.**  

*If the algorithm prints `YES`*:  
By Lemma&nbsp;5 the printed set is independent, and its size is exactly `k`,
so a valid configuration exists.

*If a valid configuration exists*:  
Let `S*` be any independent set of size `k`.  
Maximum independent set size is `n – |matching|` (Lemma&nbsp;4), therefore
`k ≤ n – |matching|`. The algorithm would have `|I| ≥ k` and would output
`YES`. Hence it cannot output `NO`.

Thus the output is correct in both directions. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Bipartition* – BFS over all vertices and edges: `O(n + m)`  
*Hopcroft‑Karp* – `O(m √n)`  
*Construction of the minimum vertex cover* – another BFS: `O(n + m)`  

Overall time `O(m √n)` ≤ `4·10⁵·√10⁵` ≈ `1.3·10⁸` operations, fast enough in
2 seconds (Python implementation with adjacency lists passes).

Memory:

* adjacency list `O(n + m)`
* several integer arrays of length `n` or `n+1`

Total ≤ `O(n + m)` ≤ about 5 · 10⁵ integers → well below 256 MB.



--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
import collections

sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))

    adj = [[] for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)
        edges.append((u, v))

    # 1. bipartition
    color = [-1] * (n + 1)
    for start in range(1, n + 1):
        if color[start] != -1:
            continue
        q = collections.deque([start])
        color[start] = 0
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)

    # left side = color 0
    L = [i for i in range(1, n + 1) if color[i] == 0]
    R = [i for i in range(1, n + 1) if color[i] == 1]

    # build adjacency from left to right
    g = [[] for _ in range(n + 1)]
    for u, v in edges:
        if color[u] == 0:
            g[u].append(v)
        else:
            g[v].append(u)

    # 2. Hopcroft‑Karp
    pairU = [0] * (n + 1)   # left -> right
    pairV = [0] * (n + 1)   # right -> left
    dist = [0] * (n + 1)

    INF = 10 ** 9

    def bfs() -> bool:
        q = collections.deque()
        for u in L:
            if pairU[u] == 0:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        dist[0] = INF
        while q:
            u = q.popleft()
            if dist[u] < dist[0]:
                for v in g[u]:
                    if dist[pairV[v]] == INF:
                        dist[pairV[v]] = dist[u] + 1
                        q.append(pairV[v])
        return dist[0] != INF

    def dfs(u: int) -> bool:
        if u == 0:
            return True
        for v in g[u]:
            if dist[pairV[v]] == dist[u] + 1 and dfs(pairV[v]):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in L:
            if pairU[u] == 0 and dfs(u):
                matching += 1

    # 3. minimum vertex cover
    visL = [False] * (n + 1)
    visR = [False] * (n + 1)
    q = collections.deque()
    for u in L:
        if pairU[u] == 0:
            q.append(u)
            visL[u] = True
    while q:
        u = q.popleft()
        if color[u] == 0:          # left vertex, follow non‑matching edges
            for v in g[u]:
                if not visR[v] and pairU[u] != v:
                    visR[v] = True
                    q.append(v)
        else:                      # right vertex, follow matching edge back
            pu = pairV[u]
            if pu and not visL[pu]:
                visL[pu] = True
                q.append(pu)

    cover = set()
    for u in L:
        if not visL[u]:
            cover.add(u)
    for v in R:
        if visR[v]:
            cover.add(v)

    independent = [i for i in range(1, n + 1) if i not in cover]

    if len(independent) >= k:
        print("YES")
        print(' '.join(map(str, independent[:k])))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
