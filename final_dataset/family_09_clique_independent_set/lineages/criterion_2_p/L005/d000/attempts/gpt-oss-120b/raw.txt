**Solution Explanation**

For every pair `(u , v)` given in the input the two antennas interfere,
therefore an admissible set of powered antennas must contain **no**
interfering pair.
The whole graph is guaranteed to be *bipartite* – the vertices can be
coloured with two colours, all edges go between the colours.
For a bipartite graph the following classic facts hold  

* `M` – size of a maximum matching  
* `C` – size of a minimum vertex cover  

```
|C| = |M|                     (Kőnig’s theorem)
```

A set `I` of vertices is an **independent set** iff its complement is a
vertex cover, consequently

```
maximum independent set size = n – |M|
```

If we can find *any* independent set of size `≥ k`,
we can simply take the first `k` vertices of it – a subset of an
independent set is still independent.
So the whole problem reduces to

*find a maximum independent set in a bipartite graph*.

--------------------------------------------------------------------

#### 1.   Colour the graph (obtain the two sides)

Breadth‑first search from every not yet coloured vertex,
alternating colours `0 / 1`.  
Complexity `O(n+m)`.

--------------------------------------------------------------------

#### 2.   Maximum matching – Hopcroft‑Karp

Only edges from the left side (`colour = 0`) to the right side are stored.
Hopcroft‑Karp runs in `O(m·√n)` and returns the matching
`matchL[u]` (right partner of a left vertex, `0` if free) and
`matchR[v]` (left partner of a right vertex).

--------------------------------------------------------------------

#### 3.   Minimum vertex cover from the matching  

Standard construction:

* start with all **free** left vertices,
* walk alternating paths  
  – from a left vertex use **non‑matched** edges,  
  – from a right vertex use the **matched** edge only,
* all reached vertices form the set `Z`.

```
minimum vertex cover = (Left \ Z)  ∪  (Right ∩ Z)
maximum independent set = (Left ∩ Z) ∪ (Right \ Z)
```

Both sets are obtained in `O(n+m)`.

--------------------------------------------------------------------

#### 4.   Answer

If the independent set size `≥ k`  
 output `YES` and any `k` vertices of it (the first `k` are enough).  
Otherwise output `NO`.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
The colouring step produces a bipartition `(L,R)` of the vertices such
that every input edge connects a vertex of `L` with a vertex of `R`.

**Proof.**  
BFS colours the start vertex `0`. Every traversed edge connects vertices
with opposite colours, because the neighbour receives the opposite colour
of the current vertex. Since the input graph is bipartite, no conflict
appears and after the BFS of all components every vertex is coloured.
∎



##### Lemma 2  
`M` returned by Hopcroft‑Karp is a maximum matching of the bipartite graph
`(L,R)`.

**Proof.**  
Hopcroft‑Karp is a well‑known algorithm that repeatedly augments along
shortest alternating paths. It terminates exactly when no augmenting
path exists, i.e. when the current matching is maximum (Berge’s theorem).
∎



##### Lemma 3  
Let `Z` be the set of vertices reachable from the free left vertices by
alternating paths (non‑matched edges left→right, matched edges right→left).
Then  

```
C = (L \ Z) ∪ (R ∩ Z)
```

is a minimum vertex cover.

**Proof.**  
The construction is the standard proof of Kőnig’s theorem.
Every edge has at least one endpoint in `C`:

* if its left endpoint is not in `Z` – it belongs to `L \ Z ⊆ C`;
* otherwise the left endpoint is in `Z`, the edge is either matched
  (right endpoint also in `Z`) or not matched (right endpoint is reached,
  thus in `Z`). In both cases the right endpoint lies in `R ∩ Z ⊆ C`.

No smaller vertex cover exists because `|C| = |M|` (the number of matched
edges) and any vertex cover must contain at least one endpoint of each
matched edge, i.e. at least `|M|` vertices. ∎



##### Lemma 4  
`I = (L ∩ Z) ∪ (R \ Z)` is a maximum independent set.

**Proof.**  
`I` is the complement of `C` from Lemma&nbsp;3, therefore it is an
independent set. Its size is  

```
|I| = |L| + |R| – |C| = n – |M|
```

and by Lemma&nbsp;2 `|M|` is the size of a maximum matching, hence
`|I|` equals the known upper bound `n – size_of_minimum_vertex_cover`.
Thus `I` is maximum. ∎



##### Lemma 5  
If the algorithm outputs `YES` and a set `S` of `k` vertices,
then `S` is an independent set.

**Proof.**  
The algorithm first builds the maximum independent set `I` (Lemma&nbsp;4)
and then takes any `k` vertices of `I`.  
A subset of an independent set is independent, therefore `S` is
independent. ∎



##### Lemma 6  
If the algorithm outputs `NO` then **no** independent set of size `k`
exists.

**Proof.**  
`NO` is printed exactly when `|I| < k`.  
`I` is a *maximum* independent set (Lemma&nbsp;4), therefore every
independent set has size at most `|I|`. Consequently no independent set
of size `k` can exist. ∎



##### Theorem  
The program prints

* `YES` and a valid set of `k` antennas **iff** such a set exists,
* otherwise prints `NO`.

**Proof.**  

*If the program prints `YES`* – by Lemma&nbsp;5 the printed set is
independent and has size `k`, so a feasible selection exists.

*If a feasible selection exists* – there is an independent set of size
`k`. The maximum independent set `I` has size at least `k`. The program
therefore does not output `NO` (Lemma&nbsp;6) and prints `YES` together
with a suitable subset of `I`.  

Thus the output is correct in both directions. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Colouring* – `O(n + m)` time, `O(n + m)` memory.  
*Hopcroft‑Karp* – `O(m·√n)` time, `O(n + m)` memory.  
*Construction of `Z` and the independent set* – `O(n + m)` time,
`O(n)` extra memory.

Overall  

```
Time   : O(m·√n)   ≤ 4·10⁵·√10⁵  ≈ 1.3·10⁸ operations  (well inside 2 s)
Memory : O(n + m)  ≤ 5·10⁵ integers  (≈ 4 MB)
```

Both limits satisfy the problem constraints.

#### 7.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))

    adj = [[] for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)
        edges.append((u, v))

    # 1. colour the graph
    colour = [-1] * (n + 1)          # 0 = left, 1 = right
    left_vertices = []
    right_vertices = []
    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        colour[start] = 0
        q = deque([start])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if colour[v] == -1:
                    colour[v] = colour[u] ^ 1
                    q.append(v)

    for v in range(1, n + 1):
        if colour[v] == 0:
            left_vertices.append(v)
        else:
            right_vertices.append(v)

    # 2. build adjacency from left to right
    left_adj = [[] for _ in range(n + 1)]
    for u, v in edges:
        if colour[u] == 0:
            left_adj[u].append(v)
        else:
            left_adj[v].append(u)

    # 3. Hopcroft‑Karp
    INF = 10 ** 9
    matchL = [0] * (n + 1)   # left -> right
    matchR = [0] * (n + 1)   # right -> left
    dist = [0] * (n + 1)

    def bfs() -> bool:
        q = deque()
        for u in left_vertices:
            if matchL[u] == 0:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        found = False
        while q:
            u = q.popleft()
            for v in left_adj[u]:
                if matchR[v] == 0:
                    found = True
                else:
                    nxt = matchR[v]
                    if dist[nxt] == INF:
                        dist[nxt] = dist[u] + 1
                        q.append(nxt)
        return found

    def dfs(u: int) -> bool:
        for v in left_adj[u]:
            if matchR[v] == 0 or (dist[matchR[v]] == dist[u] + 1 and dfs(matchR[v])):
                matchL[u] = v
                matchR[v] = u
                return True
        dist[u] = INF
        return False

    while bfs():
        for u in left_vertices:
            if matchL[u] == 0:
                dfs(u)

    # 4. build Z (vertices reachable by alternating paths)
    visitedL = [False] * (n + 1)
    visitedR = [False] * (n + 1)
    q = deque()
    for u in left_vertices:
        if matchL[u] == 0:
            visitedL[u] = True
            q.append(('L', u))

    while q:
        side, node = q.popleft()
        if side == 'L':
            u = node
            for v in left_adj[u]:
                if not visitedR[v] and matchL[u] != v:   # non‑matched edge
                    visitedR[v] = True
                    q.append(('R', v))
        else:   # side == 'R'
            v = node
            if matchR[v] != 0:
                u = matchR[v]
                if not visitedL[u]:
                    visitedL[u] = True
                    q.append(('L', u))

    # 5. maximum independent set
    independent = []
    for u in left_vertices:
        if visitedL[u]:
            independent.append(u)
    for v in right_vertices:
        if not visitedR[v]:
            independent.append(v)

    if len(independent) >= k:
        print("YES")
        print(' '.join(map(str, independent[:k])))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
