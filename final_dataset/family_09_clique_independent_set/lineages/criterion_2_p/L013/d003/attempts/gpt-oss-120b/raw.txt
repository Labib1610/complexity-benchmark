**Solution Explanation**

For every pair `u – v` the two modules cannot be active together.
The whole graph satisfies  

*every simple cycle has even length*  

→ the graph is **bipartite**.  
In a bipartite graph each connected component can be coloured with two
colours `0` and `1` such that every edge connects vertices of different
colours.

For one component let  

* `C0` – vertices coloured `0`  
* `C1` – vertices coloured `1`

Both `C0` and `C1` are independent sets, i.e. any two vertices inside the
same colour are never adjacent.
The biggest independent set inside this component is the larger colour
class, `max(|C0|,|C1|)`.  
Taking a subset of an independent set is still independent, therefore
any number `≤ max(|C0|,|C1|)` can be realised inside the component.

For the whole graph the maximum possible size of an independent set is

```
S = Σ over all components  max(|C0| , |C1|)
```

If `S ≥ k` we can simply collect the larger colour class of every component,
obtain a set of size `S`, and output any `k` vertices from it.
If `S < k` no independent set of size `k` exists.

Thus the problem reduces to:

* colour every component (BFS/DFS),
* store the two colour classes,
* add the larger one to a global list,
* check its size.

The algorithm is linear in the size of the graph.



--------------------------------------------------------------------

#### Algorithm
```
read n, m, k
build adjacency list
colour[1…n] = -1
answer = empty list

for v = 1 … n
    if colour[v] == -1
        queue ← [v]; colour[v] = 0
        part[0] = [] ; part[1] = []
        while queue not empty
            x = pop queue
            part[colour[x]].append(x)
            for each neighbour y of x
                if colour[y] == -1
                    colour[y] = colour[x] ^ 1
                    push y to queue
                else
                    # graph is guaranteed bipartite, no check needed
        # component finished
        if len(part[0]) >= len(part[1])
            answer.extend(part[0])
        else
            answer.extend(part[1])

if len(answer) >= k
    print "YES"
    print first k numbers of answer
else
    print "NO"
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints a correct answer.

---

**Lemma 1**  
During the BFS of a component the vertices are coloured with two colours
`0` and `1` such that every edge connects vertices of different colours.

*Proof.*  
The start vertex receives colour `0`.  
Whenever we traverse an edge `x – y`, we assign to `y` the opposite colour
`colour[x] xor 1`.  
Thus every processed edge connects opposite colours. By induction over the
BFS order the statement holds for all visited edges. ∎



**Lemma 2**  
For a processed component the set `part[0]` (resp. `part[1]`) is an
independent set.

*Proof.*  
By Lemma&nbsp;1 every edge of the component has its ends in different colour
classes, therefore no two vertices inside the same class are adjacent. ∎



**Lemma 3**  
Let `C` be a component, `a = |part[0]|`, `b = |part[1]|`.  
Every independent set inside `C` has size at most `max(a,b)`.

*Proof.*  
Any independent set can contain vertices only from one colour class,
otherwise two of its vertices would be adjacent (Lemma&nbsp;1).  
Hence its size ≤ `a` or ≤ `b`, i.e. ≤ `max(a,b)`. ∎



**Lemma 4**  
The list `answer` built by the algorithm is an independent set of the whole
graph.

*Proof.*  
`answer` is the union of, for each component, either `part[0]` or `part[1]`.
Inside each component the chosen part is independent (Lemma&nbsp;2).  
There are no edges between different components, therefore the union is also
independent. ∎



**Lemma 5**  
If the algorithm outputs `YES` and prints `k` vertices from `answer`,
the printed set is a valid configuration.

*Proof.*  
`answer` is independent (Lemma&nbsp;4).  
A subset of an independent set is independent, so the first `k` vertices are
also independent. Their count is exactly `k`. ∎



**Lemma 6**  
If the algorithm outputs `NO` then no independent set of size `k` exists.

*Proof.*  
For each component the algorithm adds the larger colour class,
size `max(a,b)`.  
Thus `|answer| = Σ max(a_i , b_i)` where the sum runs over all components.
By Lemma&nbsp;3 this sum equals the maximum possible size of an independent
set in the whole graph.  
If `|answer| < k`, any independent set is smaller than `k`. ∎



**Theorem**  
The algorithm prints `YES` and a correct set of `k` modules
iff such a set exists; otherwise it prints `NO`.

*Proof.*  
*If* part: when the algorithm prints `YES`, by Lemma&nbsp;5 the printed set
is a valid independent set of size `k`.  

*Only‑if* part: when a valid set of size `k` exists, the maximum independent
set size is at least `k`. The algorithm computes this maximum as `|answer|`
(Lemmas&nbsp;3,4). Hence `|answer| ≥ k` and the algorithm will output `YES`.  

If no such set exists, `|answer| < k` and by Lemma&nbsp;6 the algorithm
outputs `NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(n + m)`  
*BFS over all components*: each vertex and edge is processed once → `O(n + m)`  
*Memory*: adjacency list `O(n + m)`, colour array `O(n)`, temporary lists
`O(n)`.

Both limits satisfy the constraints (`n ≤ 10^5`, `m ≤ 4·10^5`).

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)
    answer = []

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        q = deque([start])
        colour[start] = 0
        part = [[], []]          # part[0] and part[1]
        while q:
            v = q.popleft()
            part[colour[v]].append(v)
            for nb in adj[v]:
                if colour[nb] == -1:
                    colour[nb] = colour[v] ^ 1
                    q.append(nb)
        # add the larger colour class of this component
        if len(part[0]) >= len(part[1]):
            answer.extend(part[0])
        else:
            answer.extend(part[1])

    if len(answer) >= k:
        sys.stdout.write("YES\n")
        sys.stdout.write(" ".join(map(str, answer[:k])) + "\n")
    else:
        sys.stdout.write("NO\n")

if __name__ == "__main__":
    solve()
```
