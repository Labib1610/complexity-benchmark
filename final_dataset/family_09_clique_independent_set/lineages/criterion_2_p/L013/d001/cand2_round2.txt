# Problem B — Component Activation

Time limit: 2 s
Memory limit: 256 MB

## Description

You are tasked with configuring a large-scale distributed array consisting of **n** components (numbered 1 to **n**). To meet the operational threshold, your monitoring system must select exactly **k** components to activate.

However, certain pairs of components are known to cause destructive interference if activated simultaneously. You are provided with a list of **m** interference links. A valid operational configuration must not contain any pair of components that interfere with each other. 

With **n** up to 100000, the number of possible **k**-component combinations is $\binom{n}{k}$. This search space grows exponentially and can easily exceed $10^{5000}$ for the given limits, meaning brute-force enumeration of subsets is impossible. You must find a way to determine if a collision-free subset of size **k** exists without exhaustively checking combinations.

Additionally, it is physically guaranteed that the components can be partitioned into two unseen distinct classifications such that every interference link connects a component of the first classification to a component of the second. In other words, destructive interference only occurs between components of different classifications, and never between components sharing the same classification. The specific classification of each component is not provided in the input.

Given **k**, determine if there is a valid configuration of exactly **k** components, and if so, output one such configuration.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n), representing the number of components, the number of interference links, and the target number of components to activate.

Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), indicating that component **u** and component **v** interfere with each other. No interference link is listed more than once. It is guaranteed that the interference links adhere to the two-classification property described above.

## Output

If a valid configuration of exactly **k** components exists, print `YES` on the first line. On the second line, print **k** distinct integers separated by spaces, representing the component numbers to activate. If there are multiple valid subsets, you may output any of them.

If no such configuration is possible, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```
