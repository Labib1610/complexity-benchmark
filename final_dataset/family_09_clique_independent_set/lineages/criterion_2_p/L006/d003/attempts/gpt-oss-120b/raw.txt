**Solution Explanation**

For a bipartite graph `G = (L ∪ R , E)`  

* a *vertex cover* is a set of vertices touching every edge,
* a *matching* is a set of pairwise non‑adjacent edges,
* König’s theorem:  

```
size(minimum vertex cover) = size(maximum matching)
```

and consequently  

```
size(maximum independent set) = n – size(maximum matching)
```

So we only have to

1. recover the bipartition (`L , R`);
2. compute a maximum matching (Hopcroft‑Karp, `O(m·√n)`);
3. build a minimum vertex cover from the matching;
4. take all vertices **not** in the cover – they form a maximum independent set;
5. if its size ≥ k output any `k` of them, otherwise answer `NO`.

--------------------------------------------------------------------

#### 1.   Bipartition (graph is guaranteed bipartite)

Breadth‑first search from every unvisited vertex, colour neighbours with the opposite colour.
If a vertex is never visited it is isolated – we may give it any colour (e.g. `0`).

Complexity `O(n+m)`.

--------------------------------------------------------------------

#### 2.   Hopcroft‑Karp

We store adjacency only from the left side (`L`) to the right side (`R`).

```
pairU[u] – matched right vertex of left u   (0 = unmatched)
pairV[v] – matched left vertex of right v
dist[u]  – BFS distance layer
```

Standard BFS builds layers of the alternating graph,
DFS augments along shortest augmenting paths.
Overall `O(m·√n)` time, `O(n+m)` memory.

--------------------------------------------------------------------

#### 3.   Minimum vertex cover from a maximum matching

König’s constructive proof:

* start from all **unmatched** vertices of the left side,
* follow alternating paths (edges not in the matching from left→right,
  edges in the matching from right→left),
* let `Z` be the set of vertices reachable by such paths.

Then  

```
minimum vertex cover = (L \ Z) ∪ (R ∩ Z)
```

We obtain `Z` with a simple BFS/DFS using the same rule as in the
matching phase.

--------------------------------------------------------------------

#### 4.   Independent set

`independent = all vertices  \  minimum_vertex_cover`

Its size equals `n – size(maximum matching)`.  
If `|independent| ≥ k` we output the first `k` vertices of this set,
otherwise `NO`.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
The BFS colouring step produces a bipartition `(L,R)` such that every edge
joins a vertex of `L` with a vertex of `R`.

**Proof.** The input graph is bipartite (given). BFS colours a connected
component alternatingly; because the component is bipartite, no edge ever
connects two vertices of the same colour. Isolated vertices receive an
arbitrary colour, still respecting the property. ∎



##### Lemma 2  
`matching` returned by Hopcroft‑Karp is a maximum matching of the bipartite
graph.

**Proof.** Hopcroft‑Karp is a classic algorithm; it repeatedly finds a
maximal set of shortest augmenting paths and augments along all of them.
It terminates when no augmenting path exists, which by Berge’s theorem
means the current matching is maximum. ∎



##### Lemma 3  
Let `Z` be the set of vertices reachable from unmatched left vertices by
alternating paths (as constructed in step&nbsp;3).  
Then `C = (L \ Z) ∪ (R ∩ Z)` is a minimum vertex cover.

**Proof.** This is exactly König’s constructive proof.
Every edge either has its left endpoint in `L\Z` (hence covered) or its
right endpoint in `R∩Z`. No smaller cover exists because `|C| = |matching|`
(the number of matched left vertices equals the number of matched right
vertices, and the construction shows a bijection). By Lemma&nbsp;2 the
matching is maximum, therefore `C` is minimum. ∎



##### Lemma 4  
`I = V \ C` is a maximum independent set.

**Proof.** `I` contains no edge, because any edge would be covered by `C`
(Lemma&nbsp;3). Its size is `n – |C| = n – |matching|`. By König’s theorem
`n – |matching|` equals the size of a maximum independent set, therefore
`I` is maximum. ∎



##### Lemma 5  
If `|I| ≥ k` the algorithm outputs a set of `k` vertices with no edge between
any two of them.

**Proof.** The algorithm selects any `k` vertices from `I`.  
Since `I` is independent (Lemma&nbsp;4), any subset of it is also independent.
Thus the printed vertices satisfy the requirement. ∎



##### Lemma 6  
If `|I| < k` no independent set of size `k` exists.

**Proof.** `I` is a maximum independent set (Lemma&nbsp;4). Its cardinality is
the largest possible. If it is smaller than `k`, a set of `k` mutually
non‑adjacent vertices cannot exist. ∎



##### Theorem  
The program prints  

* `YES` and a valid set of `k` gears **iff** such a set exists,
* otherwise prints `NO`.

**Proof.**  
*If the program prints `YES`*: it happened because `|I| ≥ k`. By Lemma&nbsp;5
the printed vertices form a valid independent set of size `k`.

*If a valid set of size `k` exists*: then the maximum independent set size
is at least `k`. By Lemma&nbsp;4 `|I|` equals that maximum size, therefore
`|I| ≥ k` and the program will output `YES`.

If no such set exists, then `|I| < k` (Lemma&nbsp;6) and the program outputs
`NO`. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Colouring*: `O(n+m)` time, `O(n+m)` memory.  
*Hopcroft‑Karp*: `O(m·√n)` time, `O(n+m)` memory.  
*Building `Z` and the cover*: `O(n+m)` time, `O(n+m)` memory.  

Overall  

```
Time   : O(m·√n)   ( ≤ 4·10^5·√10^5  well below 2 s )
Memory : O(n+m)    ( ≤ 5·10^5 integers )
```

#### 7.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); k = int(next(it))
    adj = [[] for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)
        edges.append((u, v))

    # 1. bipartition
    color = [-1] * (n + 1)          # 0 = left, 1 = right
    for start in range(1, n + 1):
        if color[start] != -1:
            continue
        color[start] = 0
        q = deque([start])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)

    left = [i for i in range(1, n + 1) if color[i] == 0]
    # build adjacency from left to right only
    G = [[] for _ in range(n + 1)]
    for u, v in edges:
        if color[u] == 0:
            G[u].append(v)
        else:
            G[v].append(u)

    # 2. Hopcroft‑Karp
    INF = 10 ** 9
    pairU = [0] * (n + 1)   # left -> right
    pairV = [0] * (n + 1)   # right -> left
    dist = [0] * (n + 1)

    def bfs() -> bool:
        q = deque()
        for u in left:
            if pairU[u] == 0:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        dist[0] = INF
        while q:
            u = q.popleft()
            if dist[u] < dist[0]:
                for v in G[u]:
                    if dist[pairV[v]] == INF:
                        dist[pairV[v]] = dist[u] + 1
                        q.append(pairV[v])
        return dist[0] != INF

    def dfs(u: int) -> bool:
        if u == 0:
            return True
        for v in G[u]:
            if dist[pairV[v]] == dist[u] + 1 and dfs(pairV[v]):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in left:
            if pairU[u] == 0 and dfs(u):
                matching += 1

    # 3. build Z (vertices reachable from unmatched left via alternating paths)
    visitedL = [False] * (n + 1)
    visitedR = [False] * (n + 1)
    q = deque()
    for u in left:
        if pairU[u] == 0:
            visitedL[u] = True
            q.append(('L', u))
    while q:
        side, v = q.popleft()
        if side == 'L':
            for to in G[v]:
                if not visitedR[to] and pairU[v] != to:   # edge not in matching
                    visitedR[to] = True
                    q.append(('R', to))
        else:  # side == 'R'
            pu = pairV[v]
            if pu and not visitedL[pu]:
                visitedL[pu] = True
                q.append(('L', pu))

    # 4. minimum vertex cover
    cover = [False] * (n + 1)
    for u in left:
        if not visitedL[u]:
            cover[u] = True          # L \ Z
    for v in range(1, n + 1):
        if color[v] == 1 and visitedR[v]:
            cover[v] = True          # R ∩ Z

    # 5. independent set
    independent = [i for i in range(1, n + 1) if not cover[i]]

    if len(independent) < k:
        print("NO")
        return
    print("YES")
    print(' '.join(map(str, independent[:k])))

if __name__ == "__main__":
    solve()
```
