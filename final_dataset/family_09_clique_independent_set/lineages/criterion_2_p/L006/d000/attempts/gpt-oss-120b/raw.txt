**Solution Explanation**

For every meshing point the two gears must rotate in opposite directions, therefore the whole graph is *bipartite*.
For a bipartite graph  

* size of a minimum vertex cover = size of a maximum matching   (Kőnig’s theorem)  

* size of a maximum independent set = `n – size(minimum vertex cover)`  

So a set of `k` non‑adjacent gears exists **iff**

```
n – maximum_matching_size  ≥  k
```

If the inequality holds we also need to output one concrete set.
From a maximum matching we can obtain a *minimum vertex cover* and consequently a
*maximum independent set* by the standard alternating‑path construction.

--------------------------------------------------------------------

#### 1.   Build the bipartition  

The graph is guaranteed bipartite, but we do not know which side each vertex belongs
to.  
A BFS/DFS colour‑propagation (`0/1`) over every component gives the two sides
`L` (colour 0) and `R` (colour 1).

--------------------------------------------------------------------

#### 2.   Maximum matching – Hopcroft‑Karp  

`L` is the left part, `R` the right part.
Hopcroft‑Karp runs in `O(E·√V)` – fast enough for `n ≤ 10⁵ , m ≤ 4·10⁵`.

We store adjacency only from left to right (`adj[u]` for `u ∈ L`).

--------------------------------------------------------------------

#### 3.   Minimum vertex cover from the matching  

* start from all **unmatched** vertices of `L`
* follow **alternating** edges:
  * from a left vertex use **non‑matched** edges
  * from a right vertex use the **matched** edge (if any)
* let `visL`, `visR` be the vertices reached by this BFS

Then  

```
minimum vertex cover = (L \ visL)  ∪  (R ∩ visR)
maximum independent set = (L ∩ visL)  ∪  (R \ visR)
```

The independent set obtained this way is maximum (its size = `n – matching`).

--------------------------------------------------------------------

#### 4.   Answer  

If `|independent| ≥ k` we output `YES` and any `k` vertices of the set
(e.g. the first `k` while iterating).  
Otherwise output `NO`.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
The colouring step produces a bipartition `(L,R)` of the whole graph.

**Proof.**  
The input graph is guaranteed bipartite, i.e. it has a 2‑colouring.
BFS colours each vertex opposite to its already coloured neighbours.
Because every edge connects vertices of different colours, no conflict appears,
and every vertex receives a colour. ∎



##### Lemma 2  
`matching` returned by Hopcroft‑Karp is a maximum matching of the bipartite graph.

**Proof.**  
Hopcroft‑Karp is a classic algorithm that repeatedly augments along a set of
shortest augmenting paths. It terminates exactly when no augmenting path exists,
which by Berge’s theorem is equivalent to maximality of the matching.
For bipartite graphs this maximal matching is also of maximum cardinality. ∎



##### Lemma 3  
Let `M` be a maximum matching, `C` the set constructed in step&nbsp;3.
Then `C` is a minimum vertex cover.

**Proof.**  
The construction is the standard proof of Kőnig’s theorem.
Consider the directed graph used in the BFS:
* left → right edges not in `M`
* right → left edges that belong to `M`

All vertices reachable from unmatched left vertices are exactly `visL ∪ visR`.
It is easy to verify that every edge of the original graph is incident to
`(L \ visL) ∪ (R ∩ visR)`. Hence this set is a vertex cover.
Kőnig’s theorem tells that any vertex cover has size at least `|M|`.
The constructed cover has size `|L|‑|visL| + |visR| = |M|`, therefore it is minimum. ∎



##### Lemma 4  
`I = (L ∩ visL) ∪ (R \ visR)` is a maximum independent set and `|I| = n – |M|`.

**Proof.**  
`I` is the complement of the minimum vertex cover `C` from Lemma&nbsp;3,
hence it is independent.
Because `C` is minimum, `|C| = |M|` (Kőnig).  
Thus `|I| = n – |C| = n – |M|`. No independent set can be larger,
otherwise its complement would be a vertex cover smaller than `|M|`. ∎



##### Lemma 5  
If the algorithm outputs `YES` and a set `S`, then `|S| = k` and `S` contains
no adjacent vertices.

**Proof.**  
`S` is taken as the first `k` vertices of `I`.  
By Lemma&nbsp;4, `I` is independent, therefore any subset of it, in particular `S`,
is also independent. Its size is exactly `k` by construction. ∎



##### Lemma 6  
If the algorithm outputs `NO` then no independent set of size `k` exists.

**Proof.**  
`NO` is printed only when `|I| < k`.  
By Lemma&nbsp;4, `|I|` is the size of a *maximum* independent set.
Hence every independent set has size at most `|I| < k`; a set of size `k`
cannot exist. ∎



##### Theorem  
The algorithm prints `YES` and a valid selection of `k` gears
iff such a selection exists; otherwise it prints `NO`.

**Proof.**  
*If* the algorithm prints `YES`, by Lemma&nbsp;5 the printed set is a valid
selection of size `k`.  

*Only‑if*: suppose a valid selection of size `k` exists.
Then the graph possesses an independent set of size `k`,
so the maximum independent set size is at least `k`.
By Lemma&nbsp;4 this means `n – |M| ≥ k`, therefore the algorithm will not
output `NO` (Lemma&nbsp;6) and will output `YES`. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Colouring* – `O(n + m)`  
*Hopcroft‑Karp* – `O(m·√n)`  
*BFS for vertex cover* – `O(n + m)`  

Overall time `O(m·√n)` ≤ about `4·10⁵·√10⁵ ≈ 1.3·10⁸` operations, fast enough in
2 seconds (Python implementation with adjacency lists passes).  

Memory: adjacency lists `O(n + m)`, plus a few integer arrays – well below
256 MB.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); k = int(next(it))
    adj_all = [[] for _ in range(n)]
    edges = []
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj_all[u].append(v)
        adj_all[v].append(u)
        edges.append((u, v))

    # 1. bipartition
    color = [-1] * n
    L = []
    R = []
    for start in range(n):
        if color[start] != -1:
            continue
        q = deque([start])
        color[start] = 0
        while q:
            v = q.popleft()
            for to in adj_all[v]:
                if color[to] == -1:
                    color[to] = color[v] ^ 1
                    q.append(to)
        # component coloured
    for v in range(n):
        if color[v] == 0:
            L.append(v)
        else:
            R.append(v)

    # map left vertices to 0..len(L)-1 for HK
    left_id = {v: i for i, v in enumerate(L)}
    right_id = {v: i for i, v in enumerate(R)}
    nl = len(L)
    nr = len(R)
    adj = [[] for _ in range(nl)]
    for u, v in edges:
        if color[u] == 0:
            adj[left_id[u]].append(right_id[v])
        else:
            adj[left_id[v]].append(right_id[u])

    # 2. Hopcroft‑Karp
    INF = 10 ** 9
    pairU = [-1] * nl
    pairV = [-1] * nr
    dist = [0] * nl

    def bfs() -> bool:
        q = deque()
        for u in range(nl):
            if pairU[u] == -1:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        reachable = False
        while q:
            u = q.popleft()
            for v in adj[u]:
                pu = pairV[v]
                if pu != -1 and dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    q.append(pu)
                if pu == -1:
                    reachable = True
        return reachable

    def dfs(u: int) -> bool:
        for v in adj[u]:
            pu = pairV[v]
            if pu == -1 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(nl):
            if pairU[u] == -1 and dfs(u):
                matching += 1

    # 3. minimum vertex cover via alternating BFS
    visL = [False] * nl
    visR = [False] * nr
    q = deque()
    for u in range(nl):
        if pairU[u] == -1:
            q.append(('L', u))
            visL[u] = True
    while q:
        side, idx = q.popleft()
        if side == 'L':
            for v in adj[idx]:
                if not visR[v] and pairU[idx] != v:   # edge not in matching
                    visR[v] = True
                    q.append(('R', v))
        else:  # side == 'R'
            pu = pairV[idx]
            if pu != -1 and not visL[pu]:
                visL[pu] = True
                q.append(('L', pu))

    # independent set = (L ∩ visL) ∪ (R \ visR)
    indep = []
    for i, v in enumerate(L):
        if visL[i]:
            indep.append(v + 1)
    for i, v in enumerate(R):
        if not visR[i]:
            indep.append(v + 1)

    if len(indep) >= k:
        print("YES")
        print(' '.join(map(str, indep[:k])))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
