# Problem B — Exact-Weight Relay Configuration

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a network of **n** signal relays (numbered 1 to **n**) and **m** bidirectional interference channels. Each channel links two specific relays. 

The network designers guarantee a specific structural property of this system: if you form a closed loop by selecting a sequence of three or more relays where each is linked to the next, and the final relay is linked back to the first (with no individual relay appearing more than once in the sequence), the total number of relays in this loop will always be an even number. 

Your task is to activate exactly **k** of these relays. The interference channels dictate that for each linked pair of relays, they cannot both be activated. Thus, no two activated relays can share a channel.

A valid activation set might be distributed in complex ways across the network. In fact, some networks have a maximum possible number of mutually non-interfering relays strictly larger than half the total relays. Feasibility must therefore be evaluated from the exact channel structure, not from simple approximations.

Given the target number **k**, determine if it is possible to choose exactly **k** distinct relays to activate without triggering any interference. If it is possible, output a valid selection.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
Each of the following **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing an interference channel between relay **u** and relay **v**. No channel is listed more than once. The network is guaranteed to satisfy the even-loop structural property described above.

## Output

If exactly **k** relays can be successfully selected to be active, print `YES` on the first line. On the second line, print the **k** distinct relay numbers that form your selection, separated by spaces. Any valid selection of **k** mutually non-interfering relays will be accepted.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

<RATIONALE>
The explicit mention of the variables being "divided into two categories" was removed, as it allowed models to immediately pattern-match the graph as bipartite without reasoning about its properties. Instead, the problem now guarantees that all closed loops have an even length. To succeed, the model must recognize that the absence of odd loops is the exact definition of a bipartite graph, which allows for a polynomial-time maximum independent set solution.
</RATIONALE>

The structural guarantee of no odd loops is mathematically identical to a bipartite graph, meaning the exact same sets of valid independent vertices exist for every input as they did in the seed.
