# Frequency Allocation

Time limit: 2 s   Memory limit: 256 MB

## Description

You are configuring a communication network that supports **n** distinct radio frequencies (numbered 1 to **n**). There are **m** known interference links between specific pairs of frequencies.

The network designers guarantee a specific structural property of this system: it is possible to assign a direction to every interference link such that every frequency acts exclusively as a transmitter (all of its links go out) or exclusively as a receiver (all of its links come in). No frequency will have both incoming and outgoing links. (You are not provided with this directional assignment; you must infer the roles from the interference links if necessary).

Your task is to activate exactly **k** distinct frequencies. The safety rules dictate that for each interference link, the two linked frequencies cannot both be activated. Thus, no two activated frequencies can share an interference link.

A valid activation set is not restricted to being a subset of a single role; solutions may contain frequencies from both the transmitter and receiver groups. In fact, some networks have a maximum possible number of activated frequencies strictly larger than the number of pure transmitters or pure receivers. Feasibility must therefore be evaluated from the exact interference structure, not from role counts alone.

Given the target number **k**, determine if it is possible to choose exactly **k** distinct frequencies to activate without violating any interference link. If it is possible, output a valid selection.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
Each of the following **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing an interference link between frequency **u** and frequency **v**. No interference link is listed more than once. The network is guaranteed to satisfy the structural property described above.

## Output

If exactly **k** frequencies can be successfully activated, print `YES` on the first line. On the second line, print the **k** distinct frequency numbers that form your selection, separated by spaces. Any valid selection of **k** mutually non-interfering frequencies will be accepted.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

<RATIONALE>
The explicit mention of "two categories" in the seed acts as a strong pattern-matching cue for bipartite graphs. I replaced this with an equivalent structural property based on edge orientation (transmitters/sources and receivers/sinks). This forces the model to mathematically deduce that a graph orientable in this way is precisely a bipartite graph, requiring genuine algorithmic reasoning rather than surface-level keyword mapping. The exact numeric bounds from the seed have been fully restored.
</RATIONALE>
