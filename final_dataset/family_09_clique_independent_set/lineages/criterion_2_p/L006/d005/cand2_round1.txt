This removes bipartite keywords and forces the model to deduce the bipartite property from the mechanics of directed edges and vertex roles, defeating pattern-matching models that look for "two categories" or "bipartite".</METHOD_DESCRIPTION>

<STATEMENT>
# Flow Network Upgrades

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a communication network consisting of $n$ stations and $m$ bidirectional links. Each link connects two different stations.

The network architects guarantee a specific structural property: it is theoretically possible to assign a one-way direction to every link in the network such that every station can be classified as either a pure source (having zero incoming links) or a pure sink (having zero outgoing links). You are not provided with these directions or the classifications of the stations; you must infer the network's underlying structure from the links if necessary.

Your task is to select exactly $k$ stations to receive a high-power upgrade. To prevent interference, you cannot upgrade two stations that are directly connected by a link. Thus, no two upgraded stations can share a link. 

A valid selection is not restricted to being all sources or all sinks; it may contain a mix of both. In fact, some networks have a maximum possible number of non-interfering stations strictly larger than the number of pure sources or the number of pure sinks. Feasibility must therefore be evaluated from the exact link structure, not from the number of each type of station.

Given the target number $k$, determine if it is possible to choose exactly $k$ distinct stations to upgrade without violating the interference rule. If it is possible, output a valid selection.

## Input

The first line contains three integers $n$, $m$, and $k$.
The number of stations $n$ is strictly positive and bounded by the database capacity of exactly $100000$ station records. The number of links $m$ is non-negative and limited by the warehouse stock, which can provision up to $400000$ connections. The target upgrade count $k$ requires at least $1$ station to justify the project and cannot exceed the total number of stations $n$.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing a link between station $u$ and station $v$. No link is listed more than once. The network is guaranteed to satisfy the source/sink structural property described above.

## Output

If exactly $k$ stations can be successfully selected to be upgraded, print `YES` on the first line. On the second line, print the $k$ distinct station numbers that form your selection, separated by spaces. Any valid selection of $k$ mutually non-interfering stations will be accepted.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```

1 3
1 4

2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```

```

**Output**
```
YES

```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

<RATIONALE>
The explicit mention of the variables being perfectly divided into two categories has been replaced with a logically equivalent property: the ability to direct edges such that every vertex is a pure source or a pure sink. This forces the model to deduce that edges can only exist between a source and a sink, which means the underlying undirected graph contains no odd cycles and is therefore bipartite. The bounds were also rewritten to be derived from physical capacities rather than bare inequalities.
</RATIONALE>
<PRESERVED_ANSWER>
The problem still asks for an independent set of size exactly $k$ on the exact same graph, so any valid selection in the seed remains valid here.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying graph is still guaranteed to be bipartite (as a graph can be oriented into only pure sources and sinks if and only if it is bipartite), meaning the problem remains tractable in polynomial time via Maximum Bipartite Matching and König's theorem.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret "either a pure source... or a pure sink" as an exclusive XOR that makes isolated vertices invalid, though the phrase "can be classified as either" clarifies that isolated vertices can simply be assigned to one of the valid classes.
</RISK>
