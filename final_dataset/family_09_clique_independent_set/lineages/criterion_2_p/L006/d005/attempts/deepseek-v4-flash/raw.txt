Let's recall the key insight:

The graph is **bipartite** because all cycles have even length.  
In a bipartite graph, the maximum independent set size is the larger part of the bipartitionags, but **not all sizes between** are necessarily possible — actually in bipartite graphs, all sizes from 0 up to the maximum independent set **are** possible (because the independent set can be built by taking some vertices from each side, but must avoid edges between them).

For a bipartite graph, a valid independent set can be chosen of any size `k` as long as `0 ≤ k ≤ max_independent_set_size`. The max independent set size is `n - min_vertex_cover` = `max(n_left, n_right)` after bipartition.

Thus: we find bipartition (colors), pick the larger side. If `k` ≤ that size, we can simply take `k` vertices from that side draw the needed amount — this is valid since within one side, no edges exist.

Wait — careful: If we pick only vertices from one side, they are mutually non-adjacent.  
So algorithm:

1. Build adjacency list.
2. BFS/DFS to 2-color the graph (since it's bipartite).
3. Count sizes of both color classes.
4. If `k` > max(count0, count1) → print NO.
5. Else pick `k` vertices from the larger side (or any side that has at least k vertices), print YES and those vertices.

Edge cases:  
- m=0 → all vertices independent → can take any k.
- For disconnected graph, just handle each component.

Complexity: O(n + m).

Let's write the code.

```python
import sys
from collections import deque

def solve():
    input_data = sys.stdin.read().split()
    n, m, k = map(int, input_data[:3])
    adj = [[] for _ in range(n)]
    idx = 3
    for _ in range(m):
        u = int(input_data[idx]) - 1
        v = int(input_data[idx+1]) - 1
        idx += 2
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    sides = [[], []]
    
    for start in range(n):
        if color[start] == -1:
            color[start] = 0
            sides[0].append(start)
            q = deque([start])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = 1 - color[u]
                        sides[color[v]].append(v)
                        q.append(v)
                    elif color[v] == color[u]:
                        # Should not happen due to problem guarantee
                        pass
    
    # choose larger side
    if len(sides[0]) >= len(sides[1]):
        big_side = sides[0]
    else:
        big_side = sides[1]
    
    if len(big_side) < k:
        print("NO")
        return
    
    selected = big_side[:k]
    print("YES")
    print(" ".join(str(x+1) for x in selected))

if __name__ == "__main__":
    solve()
```
