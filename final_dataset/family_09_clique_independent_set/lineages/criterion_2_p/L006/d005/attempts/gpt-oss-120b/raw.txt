**Solution Explanation**

For every relay we know the relays that interfere with it.
The given property  

*“every cycle has even length”*  

means that the interference graph is **bipartite** – it can be coloured with
two colours, say `0` and `1`, and every edge connects vertices of different
colours.

For one connected component let  

* `L` – vertices coloured `0`
* `R` – vertices coloured `1`

Inside the component we may take **any** subset of `L` together with **any**
subset of `R` as long as we never take the two ends of an edge.
Because edges go only between the two colour classes, the only forbidden
situations are taking a vertex from `L` **and** its neighbour from `R`.
Consequently a *maximum* independent set of the component is simply the larger
colour class, and a *minimum* independent set is the smaller one (or even
empty, for an isolated vertex).

For the whole graph we have several components.
From each component we have to decide

*take the whole colour class `L`*   (size `|L|`)   **or**
*take the whole colour class `R`*   (size `|R|`)

(choosing a proper subset of a colour class is never useful – we can always
add the remaining vertices of the same colour without creating a conflict).

Thus the problem becomes:

```
For every component i we have two numbers (ai , bi) = (|Li| , |Ri|).
Choose for each i either ai or bi, the total sum must be exactly k.
```

That is a classic **subset‑sum** problem with two choices per item.
`n ≤ 10^5 , k ≤ n`, therefore a bitset DP works in `O(k/64 * components)` time.
To reconstruct one concrete solution we also store, for every reachable sum,
*which component created it* and *which side was taken*.
Each sum is created only once, so the total work of the reconstruction data
is `O(k)`.

--------------------------------------------------------------------

#### Algorithm
```
1. read the graph
2. bfs/dfs each component, 2‑colour it, store the two colour classes
3. for every component i obtain (ai , bi) and the lists Li , Ri
4. DP with a bitset:
        reachable[0] = true
        for each component i:
                reachable = (reachable << ai) | (reachable << bi)
   while doing the DP also fill three arrays of length k+1
        prev_sum[s]   – previous sum before reaching s   ( -1 = not reachable )
        taken_side[s] – 0 if ai was taken, 1 if bi was taken
        comp_id[s]    – index of the component that produced s
   each new sum is written only the first time it appears.
5. if reachable[k] is false → print "NO"
6. otherwise backtrack from k using the three arrays,
   obtaining for every component which side (0/1) was chosen.
7. output all vertices of the chosen sides.
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints “YES” and a correct set of relays
iff such a set exists.

---

##### Lemma 1  
In a bipartite connected component `C` with colour classes `L` and `R`,
any independent set of `C` can be extended to an independent set that
contains **all** vertices of either `L` or all vertices of `R`.

**Proof.**  
Take an arbitrary independent set `S`.  
If `S` contains a vertex of `L`, it cannot contain any neighbour of it,
i.e. no vertex of `R` adjacent to that vertex.  
All remaining vertices of `R` are not adjacent to any vertex of `L` already
in `S` (otherwise there would be an edge inside `S`).  
Therefore we may add *all* vertices of `L` to `S` without creating a conflict.
The same argument works symmetrically for `R`. ∎



##### Lemma 2  
For a component `C` the maximum size of an independent set equals
`max(|L|,|R|)` and the minimum size equals `min(|L|,|R|)` (or `0` for an
isolated vertex).

**Proof.**  
`L` and `R` themselves are independent sets, giving sizes `|L|` and `|R|`.
By Lemma&nbsp;1 any independent set can be enlarged to one of them,
hence no larger independent set exists. ∎



##### Lemma 3  
Let the algorithm choose for each component `i` either the whole `Li`
or the whole `Ri`.  
The union of all chosen colour classes is an independent set of the whole
graph.

**Proof.**  
Inside a component the two colour classes are disjoint and contain no edge,
so the chosen class is independent.
Between two different components there are no edges at all.
Thus the union contains no edge. ∎



##### Lemma 4  
If the DP marks sum `k` as reachable, the back‑tracking step produces a
selection of sides whose total size is exactly `k`.

**Proof.**  
During DP, when a new sum `s = t + a_i` (or `t + b_i`) is created,
`prev_sum[s]` is set to `t`, `taken_side[s]` records which side was taken,
and `comp_id[s]` records component `i`.  
Therefore the stored information describes a valid transition from a
previous reachable sum to the new one.
Starting from `k` and repeatedly following `prev_sum` we obtain a decreasing
sequence of sums that ends at `0`.  
The recorded `taken_side` for each step tells which side of the
corresponding component was used, and the sum of all those side sizes is
exactly `k`. ∎



##### Lemma 5  
If there exists an independent set of size `k`, the DP will mark `k`
as reachable.

**Proof.**  
Take such a set `S`.  
By Lemma&nbsp;1, in each component `i` we can replace the part of `S`
inside the component by either the whole `Li` or the whole `Ri`
without decreasing its size.
Thus there is a choice of sides whose total size is `k`.
The DP processes components one after another and for each component
adds exactly the two possible side sizes to every already reachable sum.
Consequently after processing all components the sum `k` becomes reachable. ∎



##### Lemma 6  
If the algorithm prints “NO”, no independent set of size `k` exists.

**Proof.**  
“NO” is printed only when the DP does **not** mark `k` reachable.
By Lemma&nbsp;5, reachability of `k` is necessary for the existence of a
size‑`k` independent set. Hence none exists. ∎



##### Lemma 7  
If the algorithm prints “YES” and outputs the vertices collected in step 7,
the output set is an independent set of size exactly `k`.

**Proof.**  
“YES” is printed only when `k` is reachable, therefore back‑tracking yields
a side choice whose total size is `k` (Lemma 4).
Step 7 outputs precisely all vertices of the chosen sides,
so the output size is `k`.  
By Lemma 3 this union is an independent set. ∎



##### Theorem  
The algorithm outputs “YES” and a correct set of `k` relays
iff such a set exists; otherwise it outputs “NO”.

**Proof.**  
*If* part: existence ⇒ DP reaches `k` (Lemma 5) ⇒ algorithm prints “YES”
and, by Lemma 7, the printed set is valid.

*Only‑if* part: algorithm prints “YES” ⇒ DP reached `k` ⇒ by Lemma 4 a
selection of sides of total size `k` exists ⇒ the corresponding union of
vertices is an independent set of size `k` (Lemma 3).  
If algorithm prints “NO”, Lemma 6 shows no such set exists. ∎

#### Complexity Analysis  

*Colouring* – `O(n + m)` time, `O(n + m)` memory.  
*DP* – bitset of `k+1 ≤ n+1` bits → `⌈(k+1)/64⌉` machine words.  
For each component one shift and one OR → `O( (k/64) * components )`
≤ `O( (n/64) * n )` in worst case, but with `n = 10^5` this is well below the
limit (≈ 1.6·10⁶ word operations).  

The auxiliary arrays `prev_sum`, `taken_side`, `comp_id` each have length
`k+1` → `O(k)` memory.

Overall  

*Time*   `O(n + m + (k/64) * components)  ≤  O( n + m + n·k/64 )`  
*Memory* `O(n + m + k)` – fits into 256 MB.

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); k = int(next(it))
    g = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        g[u].append(v)
        g[v].append(u)

    colour = [-1] * n
    comps = []          # list of (list_left, list_right)
    from collections import deque
    for start in range(n):
        if colour[start] != -1:
            continue
        q = deque([start])
        colour[start] = 0
        left, right = [], []
        while q:
            v = q.popleft()
            if colour[v] == 0:
                left.append(v)
            else:
                right.append(v)
            for to in g[v]:
                if colour[to] == -1:
                    colour[to] = colour[v] ^ 1
                    q.append(to)
        comps.append((left, right))

    # DP arrays
    reachable = 1  # bit 0 set
    prev_sum = [-1] * (k + 1)   # previous sum
    taken_side = [0] * (k + 1)  # 0 -> left, 1 -> right
    comp_of = [-1] * (k + 1)    # which component created this sum
    prev_sum[0] = -2            # start marker
    cur_sums = [0]

    for idx, (L, R) in enumerate(comps):
        a = len(L)
        b = len(R)
        new_sums = []
        for s in cur_sums:
            ns = s + a
            if ns <= k and prev_sum[ns] == -1:
                prev_sum[ns] = s
                taken_side[ns] = 0
                comp_of[ns] = idx
                new_sums.append(ns)
            ns = s + b
            if ns <= k and prev_sum[ns] == -1:
                prev_sum[ns] = s
                taken_side[ns] = 1
                comp_of[ns] = idx
                new_sums.append(ns)
        cur_sums.extend(new_sums)

    if prev_sum[k] == -1:
        print("NO")
        return

    # reconstruct choices
    choose = [None] * len(comps)   # 0 -> left, 1 -> right
    cur = k
    while cur != 0:
        idx = comp_of[cur]
        side = taken_side[cur]
        choose[idx] = side
        cur = prev_sum[cur]

    # components that were never needed (sum 0) can take any side,
    # we simply take the left side (size may be 0)
    for i in range(len(comps)):
        if choose[i] is None:
            choose[i] = 0

    answer = []
    for (L, R), side in zip(comps, choose):
        answer.extend(L if side == 0 else R)

    # answer size must be k
    answer = answer[:k]

    print("YES")
    print(' '.join(str(v + 1) for v in answer))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
