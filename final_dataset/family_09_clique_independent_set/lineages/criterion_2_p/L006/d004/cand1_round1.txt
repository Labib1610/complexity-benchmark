# Problem B — Interference-Free Monitoring

Time limit: 2 s   Memory limit: 256 MB

## Description

An intricate clockwork assembly contains **n** gears (numbered 1 to **n**) and **m** engagement points. Each engagement point links two specific gears, meaning their teeth directly interlock. 

The manufacturer guarantees that the entire assembly can rotate freely without jamming. This implies a specific structural property: there exists a valid assignment of rotational directions to all gears such that at every engagement point, the two interlocking gears rotate in strictly opposite directions (one clockwise and one counterclockwise).

Your task is to install diagnostic sensors on exactly **k** of these gears. The sensors are bulky, and if placed on two gears that directly interlock, they will physically collide. Thus, no two gears selected for sensors can share an engagement point.

Note that a valid set of sensors does not need to be restricted to gears spinning in the same direction. A valid selection can, and often must, include a mix of clockwise and counterclockwise gears, as the maximum number of non-colliding sensors can strictly exceed the total number of gears spinning in either single direction. Feasibility must therefore be evaluated from the exact interlocking structure, not simply by counting gears of a given rotational direction.

Given the target number **k**, determine if it is possible to choose exactly **k** distinct gears for sensor installation without any collisions. If it is possible, output a valid selection.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
Each of the following **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing an engagement point between gear **u** and gear **v**. No engagement point is listed more than once. The assembly is guaranteed to satisfy the free-rotation property described above.

## Output

If exactly **k** gears can be successfully selected, print `YES` on the first line. On the second line, print the **k** distinct gear numbers that form your selection, separated by spaces. Any valid selection of **k** mutually non-interlocking gears will be accepted.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

<RATIONALE>
The explicit "two camps" terminology was replaced with a domain-specific physical guarantee: gears in the assembly can rotate without jamming, which necessitates alternating clockwise and counterclockwise states. This removes the obvious graph partition affordance and forces the model to recognize that "alternating rotational states across all edges" is mathematically equivalent to a bipartite graph.
</RATIONALE>
<PRESERVED_ANSWER>
The structural guarantee remains identical (the graph is bipartite), and the task remains finding an independent set of size exactly k, so the valid outputs for any input are completely unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains finding an independent set in a bipartite graph, which is solvable in polynomial time via maximum matching and König's theorem.
</PRESERVED_CLASS>
