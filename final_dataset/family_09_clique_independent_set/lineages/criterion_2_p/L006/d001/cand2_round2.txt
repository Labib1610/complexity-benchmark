# Problem B — Interference-Free Monitoring

Time limit: 2 s   Memory limit: 256 MB

## Description

An intricate clockwork mechanism consists of **n** gears (numbered 1 to **n**) and **m** meshing points. Each meshing point engages two specific gears together. 

The manufacturer guarantees that the gear network is physically workable: the entire system can rotate freely without jamming. Mathematically, this structural guarantee means that any closed loop of gears in the network (a sequence of distinct gears where each meshes with the next, and the last meshes with the first) will always consist of an even number of gears.

You have been tasked with installing diagnostic sensors on exactly **k** of these gears. Because the sensors emit strong magnetic fields, they will interfere with each other if placed on gears that physically touch. Therefore, no two gears chosen for sensor installation can mesh with each other.

Given the target size **k**, decide whether it is possible to select exactly **k** gears for sensor installation without any interference, and if so, report a valid selection.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), indicating that gear **u** and gear **v** mesh together. The same unordered pair of gears is never listed more than once, and the network is guaranteed to satisfy the structural properties described above.

## Output

If a valid set of **k** gears can be monitored, print `YES` on the first line, then on the second line print **k** distinct gear numbers forming such a set, separated by spaces. Any valid set where no two selected gears mesh is accepted.

If no such set exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

I replaced the explicit "two rotation directions" affordance with the mathematically equivalent "even-cycle" property. This removes the obvious prompt for 2-coloring while preserving the exact bipartite structure of the graph. The solver must now recognize that a graph with only even cycles is bipartite and proceed with the maximum independent set algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The exact same gear networks are valid inputs, and the condition for a valid sensor placement (an independent set of exactly size k) is identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The graph is still rigorously guaranteed to be bipartite (expressed via the even-cycle property), so finding the maximum independent set remains in P via Hopcroft-Karp and König's theorem.
</PRESERVED_CLASS>

The phrase "closed loop of gears" is defined carefully, but a reader might mistakenly think it applies to non-simple cycles if they ignore the word "distinct".
