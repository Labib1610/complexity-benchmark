# Problem B — Mutually Disconnected Collection

Time limit: 2 s   Memory limit: 256 MB

## Description

A system has **n** elements (numbered 1..n) and **m** bidirectional links. Each link joins two elements.

The system is structured such that if you start at any element, travel along a sequence of links without using any link more than once, and return to your starting element, the total number of links you traversed will always be even.

A collection of elements is **mutually disconnected** if no two elements in the collection share a link.

Given a target size **k**, decide whether a mutually disconnected collection of exactly **k** elements exists, and if so report one.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v): a link. No link is listed twice, and the link topology is guaranteed to satisfy the even-length return property described above.

## Output

If a mutually disconnected collection of **k** elements exists, print `YES` on the first line, then on the second line print **k** distinct element numbers forming such a collection, separated by spaces. Any collection in which no two elements are linked is accepted.

If no such collection exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

## Note

In Example 1, elements 1 and 2 are not linked. In Example 3, the largest mutually disconnected collection has only 2 elements, so a target of 3 is impossible.

<RATIONALE>
I replaced the explicit mention of an "alternating-role structure" with the equivalent topological property that any closed trail of links has an even length. This removes the direct hint of a bipartition, forcing models to deduce that the graph is bipartite from its cycle properties before they can apply the matching algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The problem still asks for an independent set of size k in a graph that is structurally identical to the one in the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The property that every closed trail has an even length is mathematically equivalent to the graph being bipartite, so the problem remains solvable in polynomial time via maximum bipartite matching.
</PRESERVED_CLASS>
<RISK>
Models or readers might misinterpret the even-length return property as applying only to simple cycles rather than all closed trails, though mathematically both conditions imply the exact same bipartite structure, so this does not alter the problem.
</RISK>
