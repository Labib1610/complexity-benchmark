**Solution Explanation**

For the given graph every edge connects two different categories, i.e. the graph is
*bipartite*.  
For a bipartite graph the following classic facts hold  

* `size(minimum vertex cover) = size(maximum matching)`   (Kőnig’s theorem)  
* `size(maximum independent set) = n – size(minimum vertex cover)`

So we can

1. colour the graph into the two sides `L` and `R` (any 2‑colouring works);
2. find a maximum matching `M` between the sides (Hopcroft‑Karp, `O(m·√n)`);
3. from `M` construct a minimum vertex cover `C`;
4. the complement `I = V \ C` is a maximum independent set.

If `|I| ≥ k` we output any `k` vertices of `I`, otherwise answer is `NO`.

--------------------------------------------------------------------

#### 1.   2‑colouring

Breadth‑first search from every unvisited vertex, assigning colour `0` or `1`
alternately along edges.  
The input guarantees the graph is bipartite, therefore no conflict appears.

--------------------------------------------------------------------

#### 2.   Hopcroft‑Karp

Only vertices of colour `0` are treated as the *left* part.
We store for every left vertex its adjacency list (only neighbours on the right).

Standard implementation:

```
pairU[u] – matched right vertex of left u   (0 = free)
pairV[v] – matched left vertex of right v   (0 = free)
dist[u]  – BFS distance layer
```

BFS builds layers of the alternating graph, DFS augments along shortest
alternating paths. Complexity `O(m·√n)` fits easily into the limits
(`n ≤ 10⁵ , m ≤ 4·10⁵`).

--------------------------------------------------------------------

#### 3.   Minimum vertex cover from a maximum matching  

Let  

* `U0` – left vertices **not** matched in `M`.

Run a DFS/BFS starting from all vertices of `U0` using  

* **unmatched** edges from left → right,
* **matched**   edges from right → left.

Let `visL`, `visR` be the visited vertices on both sides.

Then (Kőnig’s theorem construction)

```
C = (L \ visL)  ∪  (R ∩ visR)
```

is a minimum vertex cover.

--------------------------------------------------------------------

#### 4.   Independent set

```
I = V \ C
```

is a maximum independent set, therefore any subset of it is also independent.
If `|I| ≥ k` we output the first `k` vertices of `I`.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct set iff such a set
exists.

---

##### Lemma 1  
The BFS colouring produces a bipartition `(L,R)` of the vertex set such that
every edge connects a vertex of `L` with a vertex of `R`.

**Proof.**  
The graph is bipartite (given). BFS assigns opposite colours to the ends of
every traversed edge, therefore all edges join different colours. ∎



##### Lemma 2  
The Hopcroft‑Karp part returns a matching `M` of maximum cardinality.

**Proof.**  
Hopcroft‑Karp is a known algorithm that repeatedly augments along a set of
shortest augmenting paths; it terminates exactly when no augmenting path
exists, which is equivalent to maximality of the matching (Berge’s theorem).
Hence the returned matching is maximum. ∎



##### Lemma 3  
The set `C` constructed in step&nbsp;3 is a minimum vertex cover.

**Proof.**  
Standard König construction: let `Z` be the set of vertices reachable from
unmatched left vertices by alternating paths (definition of `visL`, `visR`).
Then `C = (L \ Z) ∪ (R ∩ Z)` covers every edge:
* an edge with left endpoint in `Z` must have its right endpoint also in `Z`
  (otherwise the edge would be an alternating edge leaving `Z`);
  such edges are covered by the right endpoint in `C`.
* an edge with left endpoint not in `Z` is covered by that left endpoint,
  which belongs to `C`.

Moreover `|C| = |M|` (each alternating path contributes exactly one vertex of
`C` per matched edge), therefore by König’s theorem `C` is minimum. ∎



##### Lemma 4  
`I = V \ C` is a maximum independent set.

**Proof.**  
`I` contains no edge because `C` is a vertex cover.  
Size: `|I| = n – |C| = n – |M|`. By Lemma&nbsp;2 `|M|` is the size of a maximum
matching, and by König’s theorem the size of a minimum vertex cover equals that
maximum matching size. Hence `|I| = n – size(minimum vertex cover)`,
which is exactly the size of a maximum independent set. ∎



##### Lemma 5  
If the algorithm outputs `YES` and a set `S`, then `|S| = k` and `S` is
independent.

**Proof.**  
The algorithm outputs `YES` only when `|I| ≥ k`. It then selects any `k`
vertices from `I`. By Lemma&nbsp;4 `I` is independent, therefore any subset of it,
in particular `S`, is also independent. Its size is exactly `k`. ∎



##### Lemma 6  
If there exists an independent set of size `k`, the algorithm outputs `YES`.

**Proof.**  
Let `I*` be a maximum independent set. Its size is at least `k`. By Lemma&nbsp;4
the algorithm constructs a maximum independent set `I` of the same size,
hence `|I| = |I*| ≥ k`. Consequently the algorithm will find `|I| ≥ k` and answer
`YES`. ∎



##### Theorem  
The algorithm prints `YES` and a correct group of `k` devices
iff such a group exists; otherwise it prints `NO`.

**Proof.**  
*If* part: by Lemma&nbsp;5 any printed set is independent of size `k`.  
*Only‑if* part: by Lemma&nbsp;6 existence of a size‑`k` independent set forces the
algorithm to answer `YES`. When `|I| < k` no independent set can be larger than
`|I|` (Lemma&nbsp;4), thus none of size `k` exists and the algorithm correctly
prints `NO`. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Colouring* – `O(n + m)`  
*Hopcroft‑Karp* – `O(m·√n)`  
*Cover construction & output* – `O(n + m)`

Overall time `O(m·√n)` ≤ `4·10⁵·√10⁵` ≈ `1.3·10⁸` operations, fast enough in 2 s
in Python with an efficient implementation.

Memory consumption:

* adjacency list – `2·m` integers,
* several arrays of length `n` – `O(n)`.

Total ≤ about 30 MB, well below the 256 MB limit.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    # 1) 2‑colouring
    color = [-1] * (n + 1)          # 0 = left, 1 = right
    for start in range(1, n + 1):
        if color[start] != -1:
            continue
        color[start] = 0
        q = deque([start])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)

    # map original ids to left/right indices
    left_ids = []
    right_ids = []
    left_index = [0] * (n + 1)
    right_index = [0] * (n + 1)
    for v in range(1, n + 1):
        if color[v] == 0:
            left_index[v] = len(left_ids) + 1   # 1‑based for HK
            left_ids.append(v)
        else:
            right_index[v] = len(right_ids) + 1
            right_ids.append(v)

    L = len(left_ids)
    R = len(right_ids)

    # adjacency for left side using right indices
    G = [[] for _ in range(L + 1)]
    for u in range(1, n + 1):
        if color[u] != 0:
            continue
        lu = left_index[u]
        for v in adj[u]:
            rv = right_index[v]
            if rv:
                G[lu].append(rv)

    # 2) Hopcroft‑Karp
    INF = 10 ** 9
    pairU = [0] * (L + 1)
    pairV = [0] * (R + 1)
    dist = [0] * (L + 1)

    def bfs() -> bool:
        q = deque()
        for u in range(1, L + 1):
            if pairU[u] == 0:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        dist[0] = INF
        while q:
            u = q.popleft()
            if dist[u] < dist[0]:
                for v in G[u]:
                    if dist[pairV[v]] == INF:
                        dist[pairV[v]] = dist[u] + 1
                        q.append(pairV[v])
        return dist[0] != INF

    def dfs(u: int) -> bool:
        if u == 0:
            return True
        for v in G[u]:
            if dist[pairV[v]] == dist[u] + 1 and dfs(pairV[v]):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, L + 1):
            if pairU[u] == 0 and dfs(u):
                matching += 1

    # 3) minimum vertex cover
    visL = [False] * (L + 1)
    visR = [False] * (R + 1)
    q = deque()
    for u in range(1, L + 1):
        if pairU[u] == 0:
            q.append(u)
            visL[u] = True
    while q:
        u = q.popleft()
        for v in G[u]:
            if not visR[v] and pairU[u] != v:   # edge not in matching
                visR[v] = True
                pu = pairV[v]
                if pu and not visL[pu]:
                    visL[pu] = True
                    q.append(pu)

    # vertices of minimum vertex cover
    in_cover = [False] * (n + 1)
    for idx, orig in enumerate(left_ids, start=1):
        if not visL[idx]:
            in_cover[orig] = True
    for idx, orig in enumerate(right_ids, start=1):
        if visR[idx]:
            in_cover[orig] = True

    # 4) independent set = complement
    independent = [v for v in range(1, n + 1) if not in_cover[v]]

    if len(independent) < k:
        print("NO")
        return

    print("YES")
    print(" ".join(map(str, independent[:k])))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
