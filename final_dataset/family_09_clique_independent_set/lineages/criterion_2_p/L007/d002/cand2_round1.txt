# Problem B — Conflict-Free Subset

Time limit: 2 s   Memory limit: 256 MB

## Description

A network contains **n** transmitters (numbered 1 to **n**) and **m** conflict pairs. Each conflict pair indicates two transmitters that interfere with each other and cannot operate simultaneously.

Every transmitter operates at a specific, fixed integer phase level. These phase levels are internal hardware details and are not provided to you. However, the network architecture guarantees a strict property: a conflict pair can only exist between two transmitters if their phase levels differ by exactly 1. 

A subset of transmitters is **conflict-free** if no two transmitters in the subset interfere.

Given a target size **k**, decide whether a conflict-free subset of exactly **k** transmitters exists, and if so, report one.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v): a conflict pair. No conflict pair is listed twice. The pairs are guaranteed to follow the phase level property described above.

## Output

If a conflict-free subset of **k** transmitters exists, print `YES` on the first line, then on the second line print **k** distinct transmitter numbers forming such a subset, separated by spaces. Any subset in which no two transmitters conflict is accepted.

If no such subset exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

## Note

In Example 1, transmitters 1 and 2 do not conflict, so they form a valid subset of size 2. In Example 3, the largest possible conflict-free subset contains only 2 transmitters, making a subset of 3 impossible.
</STATEMENT>
<RATIONALE>
I removed the explicit mention of "two distinct operating frequencies" and replaced it with a structural guarantee that "phase levels differ by exactly 1". This forces the model to mathematically deduce that the graph is bipartite (since a difference of 1 implies alternating parities) rather than relying on the semantic giveaway of "two frequencies" to trigger a bipartite matching shortcut.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that edges only exist between nodes with phase levels differing by 1 is mathematically equivalent to the graph being bipartite, so the exact same subsets remain conflict-free.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying graph is still guaranteed to be bipartite, meaning the Maximum Independent Set problem remains solvable in polynomial time via König's theorem and bipartite matching.
</PRESERVED_CLASS>
