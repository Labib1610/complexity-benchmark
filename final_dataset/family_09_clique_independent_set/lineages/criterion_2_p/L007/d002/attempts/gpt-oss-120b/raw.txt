**Solution Explanation**

For the given graph every cycle has even length, therefore the graph is *bipartite*.
In a bipartite graph the vertex set can be split into two colour classes
`L` and `R` such that every edge connects a vertex of `L` with a vertex of `R`.

--------------------------------------------------------------------

#### 1.   Independent set in a bipartite component  

Inside one connected component choose **all vertices of the larger colour
class**.  
No two of them are adjacent (edges go only between the two colour classes),
hence they form an independent set.
Its size is `max(|L|,|R|)` – the maximum possible size of an independent set
inside this component.

--------------------------------------------------------------------

#### 2.   Whole graph  

The graph may consist of many components.
For each component we take the larger colour class.
The union of those choices is still independent because there are no edges
between different components.

Let  

```
C1 , C2 , … , Ct   – the components
Mi = max(|Li|,|Ri|) – size of the chosen class in component i
```

`M = Σ Mi` is the size of a *maximum* independent set of the whole graph.
If the required size `k` is larger than `M` the answer is impossible,
otherwise we can output any `k` vertices from the union (just the first `k`
of them).

--------------------------------------------------------------------

#### 3.   Algorithm
```
read n,m,k
build adjacency list
colour = [-1]*n          # -1 = unvisited, 0/1 = colour
answer_vertices = []    # vertices of the chosen larger colour classes

for each vertex v:
    if colour[v] == -1:
        bfs from v, colour the component
        collect vertices of colour 0 -> list0, colour 1 -> list1
        if len(list0) >= len(list1):
            answer_vertices.extend(list0)
        else:
            answer_vertices.extend(list1)

if len(answer_vertices) < k:
    print "NO"
else:
    print "YES"
    print first k numbers of answer_vertices (1‑based)
```

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
For every connected component the set `S` chosen by the algorithm
(the larger colour class) is an independent set and has maximum possible
size among all independent sets of that component.

**Proof.**  
In a bipartite component all edges go between the two colour classes.
Therefore any two vertices inside the same colour class are non‑adjacent,
so `S` is independent.  
Any independent set can contain at most one of the two colour classes,
hence its size is at most `max(|L|,|R|) = |S|`. ∎



##### Lemma 2  
The union `U` of the sets selected for all components is an independent set
of the whole graph.

**Proof.**  
Edges exist only inside a single component.  
Inside each component we selected only one colour class, which is independent
by Lemma&nbsp;1.  
Thus no edge has both ends in `U`. ∎



##### Lemma 3  
`|U|` equals the size `M` of a maximum independent set of the whole graph.

**Proof.**  
From Lemma&nbsp;1 each component contributes its maximum possible independent
set size `Mi`.  
Any independent set of the whole graph is the disjoint union of independent
sets of the components, therefore its size is at most `Σ Mi = |U|`.  
Since `U` itself is independent (Lemma&nbsp;2) and has that size, it is
maximum. ∎



##### Lemma 4  
If `k ≤ |U|` the algorithm outputs a set of exactly `k` vertices that is
independent.

**Proof.**  
The algorithm outputs the first `k` vertices of `U`.  
A subset of an independent set is independent, so the printed set is
independent and has size `k`. ∎



##### Theorem  
The algorithm prints  

* “NO” iff no independent set of size `k` exists,  
* otherwise “YES” and a valid independent set of size `k`.

**Proof.**  

*If the algorithm prints “NO”.*  
That happens only when `k > |U|`.  
By Lemma&nbsp;3 `|U|` is the maximum possible size of any independent set,
hence no set of size `k` exists.

*If the algorithm prints “YES”.*  
Then `k ≤ |U|`. By Lemma&nbsp;4 the printed vertices form an independent set
of size `k`.  

Conversely, if an independent set of size `k` exists, then `k ≤ M = |U|`
(Lemma&nbsp;3), so the algorithm will not output “NO”. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Building adjacency list*: `O(n + m)`  
*BFS over all vertices*: each vertex and edge is processed once → `O(n + m)`  
*Memory*: adjacency list `O(n + m)`, colour array `O(n)`, answer list `O(n)`.

Both limits satisfy the constraints (`n ≤ 10⁵`, `m ≤ 4·10⁵`).

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * n          # -1 = unvisited, 0/1 = colour
    chosen = []                # vertices of the larger colour class of each component

    for start in range(n):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        part = [[], []]        # vertices of colour 0 and 1
        part[0].append(start)
        while q:
            v = q.popleft()
            cv = colour[v]
            for to in adj[v]:
                if colour[to] == -1:
                    colour[to] = cv ^ 1
                    part[colour[to]].append(to)
                    q.append(to)
        # take the larger side
        if len(part[0]) >= len(part[1]):
            chosen.extend(part[0])
        else:
            chosen.extend(part[1])

    if len(chosen) < k:
        sys.stdout.write("NO")
    else:
        sys.stdout.write("YES\n")
        out = [str(v + 1) for v in chosen[:k]]
        sys.stdout.write(" ".join(out))

if __name__ == "__main__":
    solve()
```
