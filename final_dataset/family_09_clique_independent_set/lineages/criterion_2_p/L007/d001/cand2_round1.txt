<STATEMENT>
# Problem B — Signal Isolation

Time limit: 2 s
Memory limit: 256 MB

## Description

A communication network consists of **n** transmitters (numbered 1 to n) and **m** conflict pairs. Each conflict pair indicates two transmitters that disrupt each other's signals if both are active.

Extensive testing of the network topology has revealed a structural guarantee: if you trace any circular chain of disruptions (a sequence of 3 or more distinct transmitters $t_1, t_2, \dots, t_c$ where each $t_i$ disrupts $t_{i+1}$ for $1 \le i < c$, and $t_c$ disrupts $t_1$), the number of transmitters $c$ in that chain is always strictly even.

A subset of transmitters is considered **isolated** if no two transmitters in the subset disrupt each other.

Given a target size **k**, determine if an isolated subset of exactly **k** transmitters can be chosen, and if so, identify them.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
Each of the following **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing a conflict pair. No pair is listed more than once. The conflict pairs are guaranteed to satisfy the even-chain property described above.

## Output

If an isolated subset of exactly **k** transmitters exists, output `YES` on the first line. On the second line, output **k** distinct transmitter numbers that form such a subset, separated by spaces. If multiple valid subsets exist, any of them will be accepted.

If no such subset can be formed, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

## Note

In Example 1, transmitters 1 and 2 do not disrupt each other. In Example 3, the largest possible isolated subset contains only 2 transmitters, making a size of 3 impossible.
