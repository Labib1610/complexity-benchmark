**Solution Explanation**

For every conflict pair the two transmitters belong to different frequencies,
therefore the whole graph is bipartite.
For a bipartite graph

```
size of a maximum independent set = n – size of a minimum vertex cover
                                   = n – size of a maximum matching          (Kőnig’s theorem)
```

So we

1. rebuild the bipartition,
2. compute a maximum matching (Hopcroft‑Karp, `O(E·√V)`),
3. from the matching obtain a minimum vertex cover,
4. the complement of the cover is a maximum independent set.
   Its size is `n – matching_size`.  
   If this size is at least `k` we can output any `k` vertices from it,
   otherwise the answer is `NO`.

The only non‑trivial part is constructing the minimum vertex cover from a
maximum matching.  
Let `U` be the left side, `V` the right side.
Start a BFS from all **unmatched** vertices of `U` and follow

* `U → V` through **non‑matching** edges,
* `V → U` through **matching** edges.

All vertices reached by this BFS are called *visited*.
Then

```
minimum vertex cover = (U \ visited)  ∪  (V ∩ visited)
```

(standard proof of Kőnig’s theorem).

The algorithm works for every bipartite graph, even when the two sides are not
given – we colour the graph with a simple BFS first.



--------------------------------------------------------------------

#### Algorithm
```
read n,m,k
build adjacency list of the undirected graph
colour the graph (0/1) by BFS → left = colour 0, right = colour 1
build adjacency only from left to right:
    for each edge (a,b)
        if colour[a]==0: add b to adj[a]
        else:            add a to adj[b]

# Hopcroft‑Karp
pairU[u] = matched right vertex or 0
pairV[v] = matched left vertex or 0
while BFS builds distance layers:
        DFS tries to augment along shortest augmenting paths
matching_size = number of matched pairs

# minimum vertex cover
queue = all left vertices u with pairU[u]==0
visitedU, visitedV = empty sets
BFS:
    pop u from queue (left)
        for each v in adj[u]:
            if v not visitedV and pairU[u] != v:   # non‑matching edge
                visitedV.add(v)
                if pairV[v]!=0 and pairV[v] not visitedU:
                    visitedU.add(pairV[v])
                    queue.append(pairV[v])

cover = (left vertices not in visitedU)  ∪  (right vertices in visitedV)
independent = all vertices \ cover

if |independent| >= k:
        print YES and any k vertices from independent
else:   print NO
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct set iff such a set
exists.

---

##### Lemma 1  
The colouring step produces a bipartition of the graph, i.e. every edge connects
a vertex of colour 0 with a vertex of colour 1.

**Proof.** The input guarantees that the graph is bipartite.
BFS colours a connected component alternatingly; because the graph is
bipartite no conflict appears, and we repeat for all components. ∎



##### Lemma 2  
`matching_size` returned by Hopcroft‑Karp equals the size of a maximum matching
of the graph.

**Proof.** Hopcroft‑Karp is a classic algorithm that repeatedly augments along
shortest augmenting paths until none exist; at that point the current matching
is maximum (Berge’s theorem). ∎



##### Lemma 3  
After the BFS from all unmatched left vertices, the sets `visitedU`,
`visitedV` satisfy:

* every visited vertex is reachable from an unmatched left vertex by a path
  that alternates **non‑matching / matching** edges,
* no other vertex has this property.

**Proof.** The BFS exactly follows those alternating rules, starting from the
given sources, therefore it visits precisely the vertices reachable by such
paths. ∎



##### Lemma 4  
`cover = (U \ visitedU) ∪ (V ∩ visitedV)` is a minimum vertex cover.

**Proof.** Standard theorem for bipartite graphs.
Every edge either has its left endpoint in `U \ visitedU` (then the edge is
covered) or its right endpoint in `V ∩ visitedV` (also covered).  
Conversely, any vertex cover must contain at least one endpoint of each edge;
by the alternating‑path structure, the set above is of minimum possible size.
∎



##### Lemma 5  
`independent = V \ cover` is a maximum independent set and its size equals
`n – matching_size`.

**Proof.** By Lemma 4, `cover` is a minimum vertex cover, therefore its
complement is a maximum independent set.  
Kőnig’s theorem gives `|minimum vertex cover| = matching_size`, hence
`|independent| = n – matching_size`. ∎



##### Lemma 6  
If `|independent| ≥ k` the algorithm outputs a conflict‑free set of exactly
`k` vertices.

**Proof.** The algorithm selects any `k` vertices from `independent`.  
Since `independent` contains no edge of the graph, any subset of it is also
edge‑free. ∎



##### Lemma 7  
If `|independent| < k` no conflict‑free set of size `k` exists.

**Proof.** Any independent set is a subset of a maximum independent set,
so its size cannot exceed `|independent|`. ∎



##### Theorem  
The algorithm prints

* `YES` and a valid subset of size `k` **iff** such a subset exists,
* otherwise prints `NO`.

**Proof.**  
*If the algorithm prints `YES`*: by Lemma 6 the printed set is conflict‑free
and has size `k`.  

*If a conflict‑free set of size `k` exists*: its size is at most the maximum
independent set size, i.e. `k ≤ |independent|` (Lemma 5). Hence the algorithm
will find `|independent| ≥ k` and output `YES`.  

If `|independent| < k`, by Lemma 7 no such set exists, and the algorithm
outputs `NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Colouring*: `O(n + m)`  
*Hopcroft‑Karp*: `O(m·√n)` ( ≤ 4·10⁵·√10⁵ ≈ 1.3·10⁸, fast in practice)  
*BFS for vertex cover*: `O(n + m)`  
*Overall*: `O(m·√n)` time, `O(n + m)` memory.

Both limits satisfy the problem constraints.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); k = int(next(it))

    g = [[] for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        g[u].append(v)
        g[v].append(u)
        edges.append((u, v))

    # colour the graph (0/1)
    colour = [-1] * (n + 1)
    left_nodes = []
    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        colour[start] = 0
        dq = deque([start])
        while dq:
            u = dq.popleft()
            for v in g[u]:
                if colour[v] == -1:
                    colour[v] = colour[u] ^ 1
                    dq.append(v)

    # build adjacency from left (colour 0) to right (colour 1)
    adj = [[] for _ in range(n + 1)]
    for u, v in edges:
        if colour[u] == 0:
            adj[u].append(v)
        else:
            adj[v].append(u)

    # Hopcroft‑Karp
    INF = 10 ** 9
    pairU = [0] * (n + 1)   # left -> right
    pairV = [0] * (n + 1)   # right -> left
    dist = [0] * (n + 1)

    left_list = [i for i in range(1, n + 1) if colour[i] == 0]

    def bfs() -> bool:
        dq = deque()
        for u in left_list:
            if pairU[u] == 0:
                dist[u] = 0
                dq.append(u)
            else:
                dist[u] = INF
        found = False
        while dq:
            u = dq.popleft()
            for v in adj[u]:
                pu = pairV[v]
                if pu == 0:
                    found = True
                elif dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    dq.append(pu)
        return found

    def dfs(u: int) -> bool:
        for v in adj[u]:
            pu = pairV[v]
            if pu == 0 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in left_list:
            if pairU[u] == 0 and dfs(u):
                matching += 1

    # minimum vertex cover
    visitedU = [False] * (n + 1)
    visitedV = [False] * (n + 1)
    dq = deque()
    for u in left_list:
        if pairU[u] == 0:
            visitedU[u] = True
            dq.append(u)
    while dq:
        u = dq.popleft()
        for v in adj[u]:
            if not visitedV[v] and pairU[u] != v:   # non‑matching edge
                visitedV[v] = True
                pu = pairV[v]
                if pu and not visitedU[pu]:
                    visitedU[pu] = True
                    dq.append(pu)

    cover = set()
    for u in left_list:
        if not visitedU[u]:
            cover.add(u)
    for v in range(1, n + 1):
        if colour[v] == 1 and visitedV[v]:
            cover.add(v)

    independent = [i for i in range(1, n + 1) if i not in cover]

    if len(independent) >= k:
        print("YES")
        print(' '.join(map(str, independent[:k])))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
