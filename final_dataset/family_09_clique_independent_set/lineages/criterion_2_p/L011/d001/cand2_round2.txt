# Problem B — Interference-Free Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

A wireless network consists of **n** nodes (numbered 1 to **n**) and **m** known interference links. Each link indicates that two specific nodes will interfere if both are activated.

The network possesses a specific structural guarantee: the nodes can be split into two disjoint camps. You are not given which node belongs to which camp, but it is guaranteed that every interference link connects a node from one camp to a node in the other. There are no interference links between any two nodes in the same camp.

A set of nodes is **interference-free** if no two selected nodes share an interference link.

Given a target size **k**, determine whether an interference-free set of exactly **k** nodes exists. If such a set exists, you must also provide one valid selection.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ **n** ≤ 100000, 0 ≤ **m** ≤ 400000, 1 ≤ **k** ≤ **n**).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), representing an interference link between node **u** and node **v**. No link is listed more than once. The links are guaranteed to follow the two-camp structure described above.

## Output

If an interference-free set of exactly **k** nodes exists, print `YES` on the first line. On the second line, print **k** distinct node numbers forming such a set, separated by spaces. If there are multiple valid sets, any valid set is accepted.

If no such set exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

<RATIONALE>
The strategy suggested removing the partition guarantee entirely and stating links connect "arbitrary pairs". However, doing so would change the problem statement to general Maximum Independent Set (which is NP-hard), violating Constraint 3 and causing anchor solvers to fail (H5 drift) by attempting exponential-time algorithms. Following the expert review, I restored the direct partition guarantee to preserve the exact complexity class and task identity, but rephrased the "two radio channels" metaphor to "two disjoint camps" to slightly alter the pattern-matching surface without introducing ambiguity.
</RATIONALE>
<PRESERVED_ANSWER>
The structural guarantee and the definition of an interference-free set are mathematically identical to the seed, ensuring all valid independent sets remain exactly the same for any given input.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
