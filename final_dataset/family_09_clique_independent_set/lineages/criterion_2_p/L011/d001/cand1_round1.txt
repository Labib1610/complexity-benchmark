# Problem B — Interference-Free Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

A wireless network consists of **n** nodes (numbered 1 to **n**) and **m** known interference links. Each link indicates that two specific nodes will interfere if both are activated.

Due to a hardware property, it is guaranteed that there exists a theoretical assignment of a polarity (either `+1` or `-1`) to each node such that for every interference link between a node **u** and a node **v**, the sum of their polarities is exactly `0`. You are not given these polarities.

A set of nodes is **interference-free** if no two nodes in the set share an interference link.

Given a target size **k**, determine whether an interference-free set of exactly **k** nodes exists. If such a set exists, you must also provide one valid selection.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing an interference link between node **u** and node **v**. No link is listed more than once. The links are guaranteed to follow the polarity property described above.

## Output

If an interference-free set of **k** nodes exists, print `YES` on the first line. On the second line, print **k** distinct node numbers forming such a set, separated by spaces. If there are multiple valid sets, any of them will be accepted.

If no such set exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

<RATIONALE>
I removed the explicit mention of "two channels" and "different channels," which models were pattern-matching directly to a "bipartite coloring" shortcut. Instead, I introduced a mathematical property where each node has a polarity of `+1` or `-1` and interfering nodes must sum to `0`. This forces the model to deduce that a sum of `0` strictly requires opposite polarities, meaning edges only exist between differing states, which preserves the bipartite structure but requires an actual step of reasoning to uncover.
</RATIONALE>
<PRESERVED_ANSWER>
The structural guarantee that the graph is bipartite remains mathematically identical, and the definition of an interference-free set (independent set) is unchanged, meaning all valid outputs for any input remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Because the polarity condition mathematically guarantees the graph is bipartite, the problem remains equivalent to finding a Maximum Independent Set on a bipartite graph, which is solvable in polynomial time via König's theorem.
</PRESERVED_CLASS>
