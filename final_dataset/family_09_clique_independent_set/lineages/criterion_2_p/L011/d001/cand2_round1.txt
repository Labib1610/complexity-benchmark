# Problem B — Interference-Free Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

A wireless network consists of **n** nodes (numbered 1 to **n**) and **m** known interference links. Each link indicates that two specific nodes will interfere if both are activated.

Due to a hardware restriction, the network's interference structure is highly specific. It is guaranteed that there exists some theoretical way to assign a direction to every interference link such that every node in the network either has no incoming links (acting as a pure transmitter) or has no outgoing links (acting as a pure receiver), or both. You are not given these directions, and the links themselves are undirected, but this structural property is guaranteed to hold.

A set of nodes is **interference-free** if no two nodes in the set share an interference link.

Given a target size **k**, determine whether an interference-free set of exactly **k** nodes exists. If such a set exists, you must also provide one valid selection.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing an interference link between node **u** and node **v**. No link is listed more than once. The links are guaranteed to follow the structural property described above.

## Output

If an interference-free set of **k** nodes exists, print `YES` on the first line. On the second line, print **k** distinct node numbers forming such a set, separated by spaces. If there are multiple valid sets, any of them will be accepted.

If no such set exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

Removed the explicit "two channels" description that trivially gave away the graph's bipartiteness. Replaced it with a structural guarantee that the undirected edges can be oriented such that every node has either in-degree 0 or out-degree 0, which mathematically forces the graph to be bipartite while requiring an intermediate deductive step to recognize it.
</RATIONALE>
<PRESERVED_ANSWER>
The set of valid inputs is identical since any bipartite graph can be oriented this way (and vice versa), and the task of finding an independent set of size k remains exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying graph is still guaranteed to be bipartite, meaning the Maximum Independent Set can still be found in polynomial time via maximum bipartite matching and König's theorem.
</PRESERVED_CLASS>
<RISK>
Models might misread the "assign a direction" property as changing the problem to a directed graph problem, though the text explicitly states the links themselves are undirected.
</RISK>
