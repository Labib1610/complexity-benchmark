**Solution Explanation**

For the given graph we know that a 2‑colouring exists – every edge connects the two
different hidden roles.  
So the graph is *bipartite*.

For a bipartite graph

```
size(maximum independent set) = n – size(minimum vertex cover)
size(minimum vertex cover)   = size(maximum matching)          (Kőnig)
```

Therefore an independent set of size `k` exists **iff**

```
n – size(maximum matching) ≥ k .
```

If the inequality holds we also have to output one such set.
From a maximum matching we can obtain a *minimum vertex cover* and
consequently an *independent set* (the complement of the cover).

--------------------------------------------------------------------

#### 1.   Bipartition (hidden roles)

A simple BFS/DFS colours every connected component with two colours `0 / 1`.
All vertices with colour `0` belong to the left part `L`,
colour `1` to the right part `R`.

--------------------------------------------------------------------

#### 2.   Maximum matching – Hopcroft‑Karp

`|L| , |R| ≤ n ≤ 100 000`, `|E| ≤ 400 000`.  
Hopcroft‑Karp runs in `O(E·√V)` and easily fits into the limits.

Data structures  

```
adj[u]          – list of neighbours of u (both sides)
pairU[u]        – matched vertex of u (0 if free)   (only for u in L)
pairV[v]        – matched vertex of v (0 if free)   (only for v in R)
dist[u]         – BFS distance layer of u (only for u in L)
```

The algorithm repeatedly

* BFS from all free vertices of `L` builds the layered graph,
* DFS tries to augment along the layers.

When BFS cannot reach a free vertex on the right side, the matching is maximum.

--------------------------------------------------------------------

#### 3.   Minimum vertex cover from the maximum matching  

Kőnig’s constructive proof:

* start from every **unmatched** vertex of `L`,
* walk alternatingly  
  `L --non‑matched edge--> R --matched edge--> L --non‑matched edge--> …`
* let `visL`, `visR` be the vertices reached this way.

Then  

```
minimum vertex cover = (L \ visL)  ∪  (R ∩ visR)
```

The complement of this set is an independent set of size `n – |matching|`.

--------------------------------------------------------------------

#### 4.   Answer

*If* `|independent| ≥ k` we output `YES` and any `k` vertices of the independent
set (the first `k` are enough).  
Otherwise output `NO`.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
The colouring step produces a bipartition `(L,R)` such that every edge connects a
vertex of `L` with a vertex of `R`.

**Proof.** The input graph is guaranteed to be bipartite. A BFS/DFS that
alternates colours on traversed edges therefore never meets a conflict, and
every edge joins vertices of opposite colours. ∎



##### Lemma 2  
`matching` returned by Hopcroft‑Karp is a maximum matching of the bipartite
graph `(L,R)`.

**Proof.** Hopcroft‑Karp is a classic algorithm; it terminates when the BFS
cannot reach a free vertex on the right side, i.e. when there is no augmenting
path. By Berge’s theorem a matching without augmenting path is maximum. ∎



##### Lemma 3  
Let `C = (L \ visL) ∪ (R ∩ visR)` be constructed as in the algorithm.
`C` is a minimum vertex cover.

**Proof.** This is exactly the standard construction from Kőnig’s theorem.
All edges are either

* from a visited `L` vertex to a visited `R` vertex – then the right endpoint is
  in `C`;
* from a visited `L` vertex to an **un**visited `R` vertex – such an edge would
  be a non‑matched edge leaving `visL`, contradicting maximality of the
  alternating search;
* from an **un**visited `L` vertex to any `R` – then the left endpoint belongs
  to `L \ visL ⊆ C`.

Thus every edge is incident to a vertex of `C`.  
The construction is known to give a vertex cover of size equal to the
matching size, which is the minimum possible (Kőnig). ∎



##### Lemma 4  
`I = V \ C` (the set output by the algorithm) is an independent set and
`|I| = n – |matching|`.

**Proof.** By Lemma&nbsp;3 `C` is a vertex cover, therefore no edge has both ends
outside `C`. Hence `I` contains no edge – it is independent.
`|I| = n – |C| = n – |matching|` because `|C| = |matching|`. ∎



##### Lemma 5  
If the algorithm prints `YES` and a set `S` of `k` vertices, then `S` is an
all‑strangers group (independent set).

**Proof.** `S` is a subset of `I` (the algorithm takes the first `k` vertices of
`I`). By Lemma&nbsp;4 `I` is independent, therefore any subset of it is also
independent. ∎



##### Lemma 6  
If the algorithm prints `NO` then no independent set of size `k` exists.

**Proof.** `NO` is printed exactly when `|I| < k`.  
From Lemma&nbsp;4 `|I| = n – |matching|` is the size of a *maximum* independent
set (since `|matching|` is the size of a minimum vertex cover).  
Thus every independent set has size at most `|I| < k`. ∎



##### Theorem  
The program outputs

* `YES` and a correct group of `k` users **iff** such a group exists,
* otherwise `NO`.

**Proof.**  

*If* a group exists, its size `k` is ≤ the maximum independent set size.
The algorithm computes a maximum independent set `I` (Lemma&nbsp;4), therefore
`|I| ≥ k` and it prints `YES` and a subset of size `k` (Lemma&nbsp;5).

*Only‑if* the algorithm prints `YES`, Lemma&nbsp;5 guarantees the printed set
is independent, hence a valid group.

If the algorithm prints `NO`, Lemma&nbsp;6 shows that no independent set of size
`k` exists, so a required group is impossible.

Thus the output is correct in all cases. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Colouring* – `O(n + m)`  
*Hopcroft‑Karp* – `O(m·√n)` ( ≤ ≈ 4·10⁵·316 ≈ 1.3·10⁸ operations, fast in C‑Python)  
*Cover construction* – `O(n + m)`  
*Overall* – `O(m·√n)` time, `O(n + m)` memory.

Both satisfy the limits (`2 s`, `256 MB`).

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
import collections

sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); k = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    # 1. bipartition
    color = [-1] * (n + 1)          # 0 = left, 1 = right
    for start in range(1, n + 1):
        if color[start] != -1:
            continue
        q = collections.deque([start])
        color[start] = 0
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)

    left = [i for i in range(1, n + 1) if color[i] == 0]
    right = [i for i in range(1, n + 1) if color[i] == 1]

    # 2. Hopcroft‑Karp
    pairU = [0] * (n + 1)   # only meaningful for left vertices
    pairV = [0] * (n + 1)   # only for right vertices
    dist = [0] * (n + 1)

    INF = 10 ** 9

    def bfs() -> bool:
        q = collections.deque()
        for u in left:
            if pairU[u] == 0:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        reachable = False
        while q:
            u = q.popleft()
            for v in adj[u]:
                if pairV[v] == 0:
                    reachable = True          # free vertex on right reachable
                else:
                    pu = pairV[v]
                    if dist[pu] == INF:
                        dist[pu] = dist[u] + 1
                        q.append(pu)
        return reachable

    def dfs(u: int) -> bool:
        for v in adj[u]:
            if pairV[v] == 0 or (dist[pairV[v]] == dist[u] + 1 and dfs(pairV[v])):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in left:
            if pairU[u] == 0 and dfs(u):
                matching += 1

    # 3. minimum vertex cover via alternating BFS
    visL = [False] * (n + 1)
    visR = [False] * (n + 1)
    q = collections.deque()
    for u in left:
        if pairU[u] == 0:
            visL[u] = True
            q.append(u)
    while q:
        u = q.popleft()
        if color[u] == 0:          # left vertex, follow non‑matched edges
            for v in adj[u]:
                if not visR[v] and pairU[u] != v:   # edge not in matching
                    visR[v] = True
                    q.append(v)
        else:                     # right vertex, follow matched edge only
            v = pairV[u]
            if v and not visL[v]:
                visL[v] = True
                q.append(v)

    # vertex cover
    cover = set()
    for u in left:
        if not visL[u]:
            cover.add(u)
    for v in right:
        if visR[v]:
            cover.add(v)

    independent = [i for i in range(1, n + 1) if i not in cover]

    if len(independent) >= k:
        print("YES")
        print(' '.join(map(str, independent[:k])))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```

to the required input‑output format.
