<STATEMENT>
# Problem B — All-Strangers Group (Hidden Structure)

Time limit: 2 s   Memory limit: 256 MB

## Description

A social network has **n** users (numbered 1..n) and **m** friendship connections. Each connection joins two users who are friends.

In this network, the connections possess a hidden structural property: any sequence of connections that starts and ends at the same user will always consist of an even number of connections. 

A group of users is **all-strangers** if no two users in the group are friends.

Given a target size **k**, decide whether an all-strangers group of exactly **k** users exists, and if so report one.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v): a friendship connection. No connection is listed twice, and the connections are guaranteed to follow the hidden structural property described above (all return sequences have even length).

## Output

If an all-strangers group of **k** users exists, print `YES` on the first line, then on the second line print **k** distinct user numbers forming such a group, separated by spaces. Any group in which no two users are connected is accepted.

If no such group exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

## Note

In Example 1, users 1 and 2 are not friends, so they can form an all-strangers group of size 2. In Example 3, the largest possible all-strangers group has only 2 users, so finding a group of 3 is impossible.
</STATEMENT>
<RATIONALE>
Removed the explicit mention of "two roles" and "alpha/beta" assignments, which directly handed the models the concept of a bipartite partition. Instead, the bipartite guarantee is now expressed through its equivalent cycle property: all closed walks have an even length. Models must now deduce that this property defines a bipartite graph before they can apply König's theorem and bipartite matching.
</RATIONALE>
<PRESERVED_ANSWER>
The problem still asks for an independent set of size k, and the examples and valid outputs are entirely unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The input graphs are strictly bipartite (enforced by the even-length return sequence guarantee), so finding the maximum independent set remains solvable in polynomial time via bipartite matching.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "sequence of connections" as only simple cycles rather than all walks, but mathematically both interpretations (all simple cycles are even, or all closed walks are even) are exactly equivalent to the graph being bipartite, so this ambiguity does not affect correctness.
</RISK>
