# Problem B — Social Network Camps

Time limit: 2 s
Memory limit: 256 MB

## Description

A social platform has **n** users (identified by numbers 1 through n) and **m** mutual friendship links between them. 

The user base is strictly divided into **two camps**. The network is structured such that **every friendship link connects a user from one camp to a user in the opposite camp**. Friendships never occur between two users of the same camp. (The camp assignments are hidden; you must deduce them from the friendship links). Do not assume that a valid group lies within one camp. A required group may use users from both camps, and it can exist even when neither camp alone contains **k** users.

Given a target size **k**, your goal is to determine if there is a group of exactly **k** users who are **complete strangers** to each other (meaning no two users within the group share a friendship link). If such a group can be formed, you must output one.

## Input

The first line provides three integers: **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
The following **m** lines each contain two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing a friendship link. There are no duplicate links, and the network is guaranteed to adhere to the two-camp rule (all friendships bridge the two camps).

## Output

If a complete-strangers group of **k** users is possible, output `YES` on the first line. On the second line, output the **k** distinct user IDs that make up the group, separated by spaces. If multiple valid groups exist, any of them will be accepted (provided no two users in the group are connected).

If no such group can be formed, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

## Note

This task asks you to find a complete-strangers group, but the network's two-camp structure (where friendships only cross between camps) allows for an efficient exact solution. In Example 1, users 1 and 2 (who belong to the same camp) are strangers to each other. In Example 3, the largest possible group of strangers consists of only 2 users, making a group of 3 impossible.
