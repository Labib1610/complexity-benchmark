**Solution Explanation**

For every friendship the two users belong to different camps, therefore the whole
graph is *bipartite*.  
Let the two colour classes be `L` (left) and `R` (right).

For a bipartite graph

```
size of a minimum vertex cover = size of a maximum matching          (Kőnig)
size of a maximum independent set = n – size of a minimum vertex cover
```

So

```
maximum possible size of an all‑strangers group = n – (size of a maximum matching)
```

If this number is at least `k` we can output any `k` vertices of a maximum
independent set, otherwise the answer is `NO`.

--------------------------------------------------------------------

#### 1.   Building the bipartition  

The graph is guaranteed to be bipartite, but the two camps are not given.
A simple BFS/DFS colourisation (0/1) gives the partition `L` / `R`.

--------------------------------------------------------------------

#### 2.   Maximum matching – Hopcroft‑Karp  

`n ≤ 10⁵ , m ≤ 4·10⁵`.  
Hopcroft‑Karp runs in `O(m·√n)` and easily fits into the limits.

We store for every vertex its adjacency list (only neighbours of the opposite
colour).  
`pairU[u]` – partner of `u∈L` (`0` if free)  
`pairV[v]` – partner of `v∈R` (`0` if free)  

The algorithm repeatedly

* BFS – builds distance layers from all free vertices of `L`
* DFS – augments along shortest alternating paths

until no augmenting path exists.

--------------------------------------------------------------------

#### 3.   Minimum vertex cover from the maximum matching  

Standard construction:

* start from every **unmatched** vertex of `L`
* walk only
  * non‑matched edges `L → R`
  * matched edges `R → L`
* all vertices reachable form the set `Z`

Then  

```
minCover = (L \ Z)  ∪  (R ∩ Z)
maxIndep = (L ∩ Z)  ∪  (R \ Z)
```

`maxIndep` is a maximum independent set, its size is `n – |matching|`.

--------------------------------------------------------------------

#### 4.   Producing the answer  

If `|maxIndep| ≥ k` we output `YES` and the first `k` vertices of `maxIndep`
(arbitrary order).  
Otherwise output `NO`.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
The colouring obtained by the BFS is a proper bipartition of the input graph.

**Proof.**  
The graph contains only edges between the two camps. Starting a BFS from any
uncoloured vertex and always assigning the opposite colour to neighbours never
creates a conflict, because an edge never connects two vertices that should have
the same colour. All vertices reachable are coloured, and isolated vertices get
any colour. ∎



##### Lemma 2  
`matching` returned by Hopcroft‑Karp is a maximum matching of the bipartite
graph.

**Proof.**  
Hopcroft‑Karp is a classic algorithm; it repeatedly augments along a set of
shortest augmenting paths. When no augmenting path exists, the current matching
is maximum (Berge’s theorem). The algorithm terminates exactly in that
situation, therefore the produced matching is maximum. ∎



##### Lemma 3  
The set `maxIndep` constructed from `Z` is a maximum independent set.

**Proof.**  
For bipartite graphs the construction described above yields a *minimum vertex
cover* `C = (L \ Z) ∪ (R ∩ Z)` (standard theorem, proved by showing that every
edge is incident to `C` and that `C` and any vertex cover have the same size).
Since `C` is minimum, its complement `V \ C` is a maximum independent set.
By definition `V \ C = (L ∩ Z) ∪ (R \ Z) = maxIndep`. ∎



##### Lemma 4  
`|maxIndep| = n – |matching|`.

**Proof.**  
From Lemma&nbsp;3, `maxIndep` is the complement of a minimum vertex cover.
Kőnig’s theorem states that in bipartite graphs the size of a minimum vertex
cover equals the size of a maximum matching. Hence  

```
|maxIndep| = n – |minimum vertex cover|
           = n – |maximum matching|.
```
∎



##### Lemma 5  
If the algorithm outputs `YES` and a set `S`, then `S` contains exactly `k`
vertices and no two of them are adjacent.

**Proof.**  
`S` is taken as the first `k` vertices of `maxIndep`. By Lemma&nbsp;3 `maxIndep`
is independent, therefore any subset of it (including `S`) is also independent.
The algorithm selects exactly `k` vertices, so `|S| = k`. ∎



##### Lemma 6  
If the algorithm outputs `NO` then no independent set of size `k` exists.

**Proof.**  
`NO` is printed only when `|maxIndep| < k`. By Lemma&nbsp;4,
`|maxIndep|` is the size of a *maximum* independent set, therefore every
independent set has size at most `|maxIndep|`. Consequently no independent set
of size `k` can exist. ∎



##### Theorem  
The algorithm always prints a correct answer to the problem.

**Proof.**  

*If it prints `YES`*: by Lemma&nbsp;5 the printed vertices form an independent
set of size `k`, satisfying the requirement.

*If it prints `NO`*: by Lemma&nbsp;6 no independent set of size `k` exists,
hence the correct answer is `NO`.

Both cases are exhaustive, therefore the algorithm is correct. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Colouring* – `O(n + m)`  
*Hopcroft‑Karp* – `O(m·√n)`  
*Building `Z` and the answer* – `O(n + m)`  

Overall time `O(m·√n)` ≤ `4·10⁵·√10⁵` ≈ `1.3·10⁸` operations, well inside 2 s in
Python with an efficient implementation.

Memory:

* adjacency lists – `2·m` integers
* several arrays of length `n` – `O(n)`

Total ≤ `O(n + m)` ≤ about 5 · 10⁵ integers → < 10 MB, far below the limit.

#### 7.   Reference Implementation  (Python 3)

```python
import sys
import collections

def solve() -> None:
    sys.setrecursionlimit(1 << 25)
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); k = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    # 1. bipartition
    color = [-1] * (n + 1)          # 0 = left, 1 = right
    left_nodes = []
    right_nodes = []
    for start in range(1, n + 1):
        if color[start] != -1:
            continue
        dq = collections.deque([start])
        color[start] = 0
        while dq:
            u = dq.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    dq.append(v)
    for v in range(1, n + 1):
        if color[v] == 0:
            left_nodes.append(v)
        else:
            right_nodes.append(v)

    # 2. Hopcroft‑Karp
    INF = 10 ** 9
    pairU = [0] * (n + 1)   # only meaningful for left side
    pairV = [0] * (n + 1)   # only for right side
    dist = [0] * (n + 1)

    left_set = set(left_nodes)   # for quick side test

    def bfs() -> bool:
        q = collections.deque()
        for u in left_nodes:
            if pairU[u] == 0:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        found = False
        while q:
            u = q.popleft()
            for v in adj[u]:
                if pairV[v] == 0:
                    found = True          # we can reach free right vertex
                else:
                    if dist[pairV[v]] == INF:
                        dist[pairV[v]] = dist[u] + 1
                        q.append(pairV[v])
        return found

    def dfs(u: int) -> bool:
        for v in adj[u]:
            if pairV[v] == 0 or (dist[pairV[v]] == dist[u] + 1 and dfs(pairV[v])):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in left_nodes:
            if pairU[u] == 0 and dfs(u):
                matching += 1

    # 3. Build Z (vertices reachable from free left vertices via alternating paths)
    visitedL = [False] * (n + 1)
    visitedR = [False] * (n + 1)
    q = collections.deque()
    for u in left_nodes:
        if pairU[u] == 0:
            visitedL[u] = True
            q.append(u)
    while q:
        u = q.popleft()
        # u is in L side
        for v in adj[u]:
            if not visitedR[v] and pairU[u] != v:   # edge not in matching
                visitedR[v] = True
                # from R we can go only via matched edge
                pu = pairV[v]
                if pu and not visitedL[pu]:
                    visitedL[pu] = True
                    q.append(pu)

    # 4. Independent set = (L ∩ Z) ∪ (R \ Z)
    indep = []
    for u in left_nodes:
        if visitedL[u]:
            indep.append(u)
    for v in right_nodes:
        if not visitedR[v]:
            indep.append(v)

    if len(indep) >= k:
        print("YES")
        print(' '.join(map(str, indep[:k])))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
