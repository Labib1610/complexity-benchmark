**Solution Explanation**

For every pair `(u , v)` given in the input the two micro‑services share a
data volume, therefore they must **not** be selected together.
The whole set of services can be divided into two tiers such that every
edge connects a service of tier 1 with a service of tier 2 – the graph is
*guaranteed* to be bipartite.

For a bipartite graph

* size of a minimum vertex cover = size of a maximum matching  
  (Kőnig’s theorem)

* size of a maximum independent set = `n – size(minimum vertex cover)`

Consequences  

```
max independent set size = n – maxMatching
```

If this number is at least `k` we can take any `k` vertices from a
maximum independent set – a subset of an independent set is still
independent.  
If it is smaller than `k` the answer is impossible.

So we have to

1. find a bipartition of the graph,
2. compute a maximum matching,
3. build one maximum independent set,
4. output any `k` vertices of it.



--------------------------------------------------------------------

#### 1.   Bipartition (graph colouring)

Breadth‑first search colours every connected component with two colours
`0` and `1`.  
Because the input is guaranteed bipartite no conflict appears.

--------------------------------------------------------------------

#### 2.   Maximum matching – Hopcroft‑Karp

`n ≤ 10⁵ ,  m ≤ 4·10⁵`.  
Hopcroft‑Karp runs in `O( m·√n )`, easily fast enough.

* `pair[v]` – the vertex matched with `v` (`0` = free)
* `dist[u]` – distance in the BFS layering (only for left side vertices)

The algorithm repeatedly

* BFS builds the layered graph starting from all free left vertices,
* DFS searches augmenting paths inside this layered graph.

The number of found augmentations is the size of a maximum matching.

--------------------------------------------------------------------

#### 3.   From a maximum matching to a maximum independent set  

Kőnig’s theorem also gives a constructive way to obtain a *minimum*
vertex cover:

```
start = all free left vertices
run a DFS/BFS in the alternating graph
    left → right   using only NON‑matched edges
    right → left   using only MATCHED edges
let
    Lvis = visited left vertices
    Rvis = visited right vertices
minimum vertex cover = (left \ Lvis) ∪ (right ∩ Rvis)
maximum independent set = (left ∩ Lvis) ∪ (right \ Rvis)
```

The obtained independent set has size `n – maxMatching`.

--------------------------------------------------------------------

#### 4.   Output  

If `n – maxMatching ≥ k`  
 print `YES` and the first `k` vertices of the independent set.  
Otherwise print `NO`.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
The BFS colouring performed in step&nbsp;1 produces a bipartition
`L` (colour 0) and `R` (colour 1) such that every edge connects a vertex of
`L` with a vertex of `R`.

**Proof.**  
The graph is bipartite (given). BFS colours the start vertex `0`,
all its neighbours `1`, their neighbours `0`, … .
Because the graph contains no odd cycle, no edge ever connects two
vertices of the same colour. ∎



##### Lemma 2  
Hopcroft‑Karp returns a matching of maximum possible size.

**Proof.**  
Hopcroft‑Karp is a classic algorithm; its correctness (maximality) is
proved in the original paper and in every textbook. ∎



##### Lemma 3  
After the alternating‑graph search of step&nbsp;3  

```
C = (L \ Lvis) ∪ (R ∩ Rvis)
```

is a minimum vertex cover of the input graph.

**Proof.**  
Standard proof of Kőnig’s theorem:

*All edges are of three types*  

1. left vertex in `Lvis` – right vertex not in `Rvis`  
   (edge is not matched, therefore traversed from left to right,
   so the right endpoint is **not** visited) → the left endpoint belongs
   to `Lvis`, the right one not to `Rvis`.  
   The edge is covered by the right vertex (which is in `C`).

2. left vertex not in `Lvis` – right vertex in `Rvis`  
   (edge is matched, traversed from right to left) → the left endpoint
   is in `C`.

3. left vertex not in `Lvis` – right vertex not in `Rvis`  
   This can happen only for matched edges, otherwise the BFS would have
   followed the non‑matched edge. The left endpoint is in `C`.

Thus every edge has at least one endpoint in `C`.  
Conversely, the construction is known to give a vertex cover of size
`|matching|`. By König’s theorem no smaller cover exists, therefore `C`
is minimum. ∎



##### Lemma 4  
The set  

```
I = (L ∩ Lvis) ∪ (R \ Rvis)
```

produced in step&nbsp;3 is an independent set of size `n – |matching|`.

**Proof.**  
`I` is the complement of the minimum vertex cover `C` from Lemma&nbsp;3,
hence it contains no edge (otherwise that edge would not be covered by
`C`).  
`|I| = n – |C| = n – |matching|`. ∎



##### Lemma 5  
If `n – maxMatching ≥ k` the algorithm outputs `k` distinct vertices
forming an independent set.

**Proof.**  
By Lemma&nbsp;2 `maxMatching` equals the size of a maximum matching.
Lemma&nbsp;4 gives an independent set `I` of size `n – maxMatching`,
which is at least `k`.  
The algorithm outputs the first `k` vertices of `I`; any subset of an
independent set is still independent, therefore the printed vertices are
pairwise non‑adjacent. ∎



##### Lemma 6  
If `n – maxMatching < k` no independent set of size `k` exists.

**Proof.**  
For any graph `α(G)` (maximum independent set size) satisfies  
`α(G) = n – τ(G)` where `τ(G)` is the size of a minimum vertex cover.
In bipartite graphs `τ(G) = ν(G)` (size of a maximum matching) by
Kőnig’s theorem. Hence `α(G) = n – maxMatching`.  
If this number is `< k`, an independent set of size `k` cannot exist. ∎



##### Theorem  
The program prints

* `YES` and a valid set of `k` micro‑services **iff** such a set exists,
* otherwise prints `NO`.

**Proof.**  

*If the program prints `YES`* – by Lemma&nbsp;5 the printed vertices are
independent, therefore a feasible selection exists.

*If a feasible selection exists* – there is an independent set of size
`k`. Consequently `α(G) ≥ k`. By Lemma&nbsp;6 this implies
`n – maxMatching ≥ k`. The program therefore enters the `YES` branch and
outputs a set of size `k` (Lemma&nbsp;5).  

Thus the output is correct in both directions. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Colouring* – `O(n + m)`  
*Hopcroft‑Karp* – `O( m·√n )`  
*Alternating graph search* – `O(n + m)`  

Overall time `O( m·√n )` ≤ `4·10⁵·√10⁵` ≈ `1.3·10⁸` operations, well
inside the 2 s limit in CP‑optimized Python.

Memory consumption  

* adjacency list: `2·m` integers  
* several arrays of length `n+1`  

All together `< 30 MB`, far below the 256 MB limit.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
import collections

sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    # 1) bipartition by BFS colouring
    color = [-1] * (n + 1)          # 0 = left, 1 = right
    for start in range(1, n + 1):
        if color[start] != -1:
            continue
        q = collections.deque([start])
        color[start] = 0
        while q:
            u = q.popleft()
            cu = color[u]
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = cu ^ 1
                    q.append(v)

    # 2) Hopcroft‑Karp
    pair = [0] * (n + 1)            # matched partner, 0 = free
    dist = [0] * (n + 1)

    def bfs() -> bool:
        dq = collections.deque()
        for u in range(1, n + 1):
            if color[u] == 0:               # left side only
                if pair[u] == 0:
                    dist[u] = 0
                    dq.append(u)
                else:
                    dist[u] = -1
        found = False
        while dq:
            u = dq.popleft()
            for v in adj[u]:
                pu = pair[v]
                if pu != 0 and dist[pu] == -1:
                    dist[pu] = dist[u] + 1
                    dq.append(pu)
                elif pu == 0:
                    found = True
        return found

    def dfs(u: int) -> bool:
        for v in adj[u]:
            pu = pair[v]
            if pu == 0 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pair[u] = v
                pair[v] = u
                return True
        dist[u] = -1
        return False

    matching = 0
    while bfs():
        for u in range(1, n + 1):
            if color[u] == 0 and pair[u] == 0:
                if dfs(u):
                    matching += 1

    # 3) build a maximum independent set from the matching
    # alternating graph search
    left_vis = [False] * (n + 1)
    right_vis = [False] * (n + 1)
    dq = collections.deque()
    for u in range(1, n + 1):
        if color[u] == 0 and pair[u] == 0:   # free left vertices
            left_vis[u] = True
            dq.append(u)

    while dq:
        u = dq.popleft()
        if color[u] == 0:          # left → right via NON‑matched edges
            for v in adj[u]:
                if pair[u] != v and not right_vis[v]:
                    right_vis[v] = True
                    dq.append(v)
        else:                      # right → left via MATCHED edge only
            pu = pair[u]
            if pu != 0 and not left_vis[pu]:
                left_vis[pu] = True
                dq.append(pu)

    independent = []
    for v in range(1, n + 1):
        if color[v] == 0:
            if left_vis[v]:
                independent.append(v)
        else:
            if not right_vis[v]:
                independent.append(v)

    if len(independent) < k:
        sys.stdout.write("NO\n")
        return

    sys.stdout.write("YES\n")
    sys.stdout.write(" ".join(map(str, independent[:k])) + "\n")


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
