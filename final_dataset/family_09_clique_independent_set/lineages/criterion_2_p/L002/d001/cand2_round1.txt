# Concurrent Maintenance Selection

Time limit: 2 s   Memory limit: 256 MB

## Description

A cloud infrastructure operates a set of microservices. Certain pairs of these microservices share a mutable data volume and will cause data corruption if they execute their maintenance routines concurrently. 

To maintain data flow integrity, the architecture dictates that every shared data volume is mounted exactly once by a data-producer microservice and exactly once by a data-consumer microservice. The system does not explicitly label which microservice plays which role, but it is guaranteed that no volume is ever shared between two producers or between two consumers. Microservices that do not share any volumes may exist and can be considered to fulfill either role.

You must determine if it is possible to select exactly a target number of microservices to run their maintenance routines concurrently without any risk of data corruption, and if so, identify them.

## Input

The first line provides three integers **n**, **m**, and **k**. 
- **n** is the total number of microservices. The system requires at least one active microservice and is bounded by the cluster's hard limit of 100,000 process slots.
- **m** is the number of shared volumes. The storage controller supports up to a maximum capacity of 400,000 shared volumes, and it is possible to have none at all.
- **k** is the target number of microservices to select. This target requires at least one microservice and cannot exceed the total number of active microservices **n**.

The next **m** lines each contain two integers **u** and **v** (between 1 and **n**, **u** ≠ **v**), indicating that microservices **u** and **v** share a data volume. No pair of microservices is listed more than once. The input is guaranteed to adhere to the producer-consumer architecture described above.

## Output

If a safe selection of **k** microservices exists, output `YES` on the first line. On the second line, output **k** distinct integers representing the IDs of the chosen microservices, separated by spaces. If multiple valid selections exist, any is acceptable.

If no such selection can be made, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```
