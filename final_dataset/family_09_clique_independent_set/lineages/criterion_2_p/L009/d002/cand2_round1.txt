<STATEMENT>
# Problem B — Interference-Free Group

Time limit: 2 s   Memory limit: 256 MB

## Description

A sensor network consists of **n** devices (numbered 1 to **n**) and **m** interference links. Each link joins a pair of devices that interfere with each other.

The physical arrangement of the network guarantees a specific structural property: for any interference link joining device $A$ and device $B$, if we measure the minimum number of links required to travel to any device $C$ (assuming $C$ is reachable from them), the distance from $A$ to $C$ and the distance from $B$ to $C$ will always differ by exactly 1.

A collection of devices is considered **interference-free** if no two devices within the collection share an interference link.

Given a target size **k**, determine whether an interference-free collection of exactly **k** devices exists, and if so, report one such collection.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v): an interference link. No link is listed twice, and the network is guaranteed to satisfy the structural distance property described above.

## Output

If an interference-free collection of exactly **k** devices exists, print `YES` on the first line. On the second line, print **k** distinct device numbers that form such a collection, separated by spaces. Any valid collection will be accepted.

If no such collection can be formed, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

## Note

In Example 1, devices 1 and 2 do not share an interference link. In Example 3, the largest possible interference-free collection consists of only 2 devices, making a target size of 3 impossible.
</STATEMENT>
<RATIONALE>
I replaced the explicit "closed loop ... even number" property with an equivalent shortest-path property: for any edge (A,B) and node C, the distances from A to C and B to C differ by exactly 1. This forces the model to deduce mathematically that the graph contains no odd cycles (hence is bipartite) rather than triggering immediately on the structural keyword "even loop".
</RATIONALE>
<PRESERVED_ANSWER>
The structural property is mathematically equivalent to the graph being bipartite, so the valid independent sets and their maximum sizes remain identically the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Because the property strictly bounds the graph to be bipartite, finding a maximum independent set remains in P via Hopcroft-Karp and König's theorem.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "minimum number of links" if they do not realise it refers to the standard shortest-path distance in the graph, though the phrasing is standard enough that ambiguity is low.
</RISK>
