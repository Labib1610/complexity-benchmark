We can solve this by noticing the graph is bipartite.  
We can color the servers into two groups (0 and 1) such that every edge connects different groups.  
A safe cluster is just a set of servers with no edges between them — i.e., an independent set.  

In a bipartite graph, the largest independent set is the larger of the two color classes.  
We can pick any subset of size `k` from one color class if that class has at least `k` nodes.  
If neither color class has at least `k` nodes, then no independent set of size `k` exists.

Here’s the implementation:

```python
import sys
from collections import deque

def solve():
    input = sys.stdin.readline
    n, m, k = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    groups = [[], []]
    
    for i in range(n):
        if color[i] == -1:
            color[i] = 0
            groups[0].append(i)
            q = deque([i])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = 1 - color[u]
                        groups[color[v]].append(v)
                        q.append(v)
                    elif color[v] == color[u]:
                        # Should not happen per problem guarantee
                        pass
    
    # Choose the larger group
    if len(groups[0]) >= k:
        chosen = groups[0][:k]
    elif len(groups[1]) >= k:
        chosen = groups[1][:k]
    else:
        print("NO")
        return
    
    print("YES")
    print(" ".join(str(x + 1) for x in chosen))

if __name__ == "__main__":
    solve()
```
