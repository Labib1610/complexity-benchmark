**Solution Explanation**

For every conflict pair `{u , v}` the two micro‑services belong to different groups.
Therefore the whole graph is *bipartite* – its vertices can be coloured with two
colours `0 / 1` such that every edge connects vertices of different colours.
The colour of a vertex is **not** given, we have to find it.

For a bipartite graph

* a **matching** – a set of edges with no common end points – can be found in  
  `O( m √ n )` by the Hopcroft‑Karp algorithm.
* König’s theorem: size of a *minimum vertex cover* = size of a *maximum
  matching*.
* From a minimum vertex cover `C` we obtain a *maximum independent set*
  `I = V \ C`.

If the maximum independent set contains at least `k` vertices we can output
any `k` of them, otherwise a safe batch of size `k` does not exist.

--------------------------------------------------------------------

#### Algorithm
```
1. read the graph
2. colour the graph (BFS/DFS) → two parts L (colour 0) and R (colour 1)
3. build adjacency list from L to R (only one direction is needed)
4. Hopcroft‑Karp → maximum matching, arrays pairL[|L|], pairR[|R|]
5. from the matching compute a minimum vertex cover
        start from all unmatched vertices of L,
        walk alternating non‑matched / matched edges
        (standard König construction)
   let
        visitedL = vertices of L reached by this walk
        visitedR = vertices of R reached by this walk
   then
        minimum vertex cover = (L \ visitedL) ∪ (visitedR)
        maximum independent set = visitedL ∪ (R \ visitedR)
6. if |independent set| ≥ k
        output YES and any k vertices of the independent set
   else
        output NO
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct batch iff such a batch
exists.

---

##### Lemma 1  
The BFS/DFS colouring in step&nbsp;2 produces a bipartition `L , R` of the
input graph.

**Proof.**  
The input is guaranteed to be bipartite. Starting a BFS from any uncoloured
vertex, we assign colour `0` to it and colour `1` to all its neighbours, colour
`0` to the neighbours of those neighbours, and so on. Because the graph is
bipartite, no edge ever connects two vertices of the same colour, therefore the
procedure never meets a conflict. Repeating it for every component colours all
vertices, and the two colour classes form a bipartition. ∎



##### Lemma 2  
After step&nbsp;4 `pairL , pairR` describe a *maximum* matching of the
bipartite graph.

**Proof.**  
Hopcroft‑Karp repeatedly augments the current matching along a set of shortest
augmenting paths. It stops only when no augmenting path exists. By
Berge’s theorem a matching without augmenting path is maximum. ∎



##### Lemma 3  
The set  

```
C = (L \ visitedL) ∪ visitedR
```
computed in step&nbsp;5 is a *minimum* vertex cover.

**Proof.**  
The construction is the standard one from König’s theorem:

* start with all free (unmatched) vertices of the left side,
* follow alternating paths (non‑matched edge, matched edge, …).

Let `Z = visitedL ∪ visitedR` be the vertices reachable by such alternating
paths.  
König’s theorem states that `C = (L \ Z) ∪ (R ∩ Z)` is a minimum vertex cover,
and the algorithm builds exactly this set. ∎



##### Lemma 4  
The set  

```
I = visitedL ∪ (R \ visitedR)
```
is a *maximum* independent set.

**Proof.**  
`I` is the complement of the minimum vertex cover `C` (Lemma&nbsp;3), therefore
it is an independent set of size `|V| - |C|`.  
By König’s theorem `|C|` equals the size of a maximum matching, which is the
minimum possible size of a vertex cover. Hence `|I|` is the largest possible
size of an independent set – i.e. `I` is a maximum independent set. ∎



##### Lemma 5  
If the algorithm outputs `YES` and a set `B` of `k` vertices, then `B` is a
safe batch (an independent set).

**Proof.**  
`B` is taken from `I` (step&nbsp;6). `I` is an independent set (Lemma&nbsp;4), so
any subset of it, in particular `B`, contains no conflicting pair. ∎



##### Lemma 6  
If a safe batch of size `k` exists, the algorithm outputs `YES`.

**Proof.**  
Any safe batch is an independent set, therefore its size is at most the size of
a *maximum* independent set. By Lemma&nbsp;4 the algorithm computes a maximum
independent set `I`. Hence `|I| ≥ k`. Step&nbsp;6 detects this and prints `YES`. ∎



##### Lemma 7  
If the algorithm outputs `NO`, no safe batch of size `k` exists.

**Proof.**  
`NO` is printed only when `|I| < k`. Since `I` is a maximum independent set
(Lemma&nbsp;4), no independent set (hence no safe batch) can be larger than
`|I|`. Consequently a batch of size `k` does not exist. ∎



##### Theorem  
The algorithm prints  

* `YES` and a correct batch of `k` micro‑services **iff** such a batch exists,
* otherwise prints `NO`.

**Proof.**  
*If* part – existence ⇒ algorithm prints `YES` – Lemma&nbsp;6.  
*Only‑if* part – algorithm prints `YES` ⇒ printed set is a safe batch –
Lemma&nbsp;5.  
If the algorithm prints `NO`, by Lemma&nbsp;7 a batch of size `k` cannot exist. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Colouring* – `O(n + m)`  
*Hopcroft‑Karp* – `O( m √ n )`  
*Construction of the vertex cover* – `O(n + m)`  

Overall  

```
Time   : O( m √ n )   ≤ 4·10^5 · √10^5  ≈ 1.3·10^8 elementary operations
Memory : O( n + m )   ≤ 5·10^5 integers  (well below 256 MiB)
```

Both limits satisfy the problem constraints.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

sys.setrecursionlimit(1_000_000)


def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))

    adj = [[] for _ in range(n)]
    edges = []
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
        edges.append((u, v))

    # 1. bipartition by BFS colouring
    colour = [-1] * n          # 0 = left, 1 = right
    left_ids = []              # original vertex numbers (1‑based) of left side
    right_ids = []             # same for right side
    left_index = [-1] * n
    right_index = [-1] * n

    for start in range(n):
        if colour[start] != -1:
            continue
        q = deque([start])
        colour[start] = 0
        while q:
            v = q.popleft()
            for to in adj[v]:
                if colour[to] == -1:
                    colour[to] = colour[v] ^ 1
                    q.append(to)

    # build lists of vertices per side
    for v in range(n):
        if colour[v] == 0:
            left_index[v] = len(left_ids)
            left_ids.append(v + 1)
        else:
            right_index[v] = len(right_ids)
            right_ids.append(v + 1)

    L = len(left_ids)
    R = len(right_ids)

    # 2. adjacency from left to right (indices)
    g = [[] for _ in range(L)]
    for u, v in edges:
        if colour[u] == 0:          # u in left, v in right
            g[left_index[u]].append(right_index[v])
        else:                       # v in left, u in right
            g[left_index[v]].append(right_index[u])

    # 3. Hopcroft‑Karp
    INF = 10 ** 9
    pairU = [-1] * L
    pairV = [-1] * R
    dist = [0] * L

    def bfs() -> bool:
        q = deque()
        for u in range(L):
            if pairU[u] == -1:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        found = False
        while q:
            u = q.popleft()
            for v in g[u]:
                pu = pairV[v]
                if pu != -1 and dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    q.append(pu)
                elif pu == -1:
                    found = True
        return found

    sys.setrecursionlimit(1_000_000)

    def dfs(u: int) -> bool:
        for v in g[u]:
            pu = pairV[v]
            if pu == -1 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    while bfs():
        for u in range(L):
            if pairU[u] == -1:
                dfs(u)

    # 4. minimum vertex cover via König's construction
    visitedL = [False] * L
    visitedR = [False] * R
    q = deque()
    for u in range(L):
        if pairU[u] == -1:
            visitedL[u] = True
            q.append(('L', u))

    while q:
        side, x = q.popleft()
        if side == 'L':
            for v in g[x]:
                if not visitedR[v] and pairU[x] != v:   # non‑matched edge
                    visitedR[v] = True
                    q.append(('R', v))
        else:   # side == 'R'
            u = pairV[x]
            if u != -1 and not visitedL[u]:
                visitedL[u] = True
                q.append(('L', u))

    # 5. maximum independent set = visitedL ∪ (R \ visitedR)
    independent = []
    for i, ok in enumerate(visitedL):
        if ok:
            independent.append(left_ids[i])
    for i, ok in enumerate(visitedR):
        if not ok:
            independent.append(right_ids[i])

    if len(independent) >= k:
        print("YES")
        print(" ".join(map(str, independent[:k])))
    else:
        print("NO")


if __name__ == "__main__":
    solve()
```
