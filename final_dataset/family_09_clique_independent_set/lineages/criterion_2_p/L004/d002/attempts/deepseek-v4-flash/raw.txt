We can model the microservices as a bipartite graph.  
The safe batch is an independent set of size exactly `k`.  

Since the graph is bipartite, the maximum independent set size is `n - size_of_maximum_matching`.  
But here we only need to check if we can pick `k` nodes with no edges between them.

We can find the two color classes (groups) using BFS/DFS.  
Then, if either group has size at least `k`, we can pick `k` nodes from that group.  
Otherwise, it’s impossible.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m, k = map(int, input().split())
adj = [[] for _ in range(n + 1)]

for _ in range(m):
    u, v = map(int, input().split())
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * (n + 1)
group0 = []
group1 = []

for i in range(1, n + 1):
    if color[i] == -1:
        color[i] = 0
        group0.append(i)
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    if color[v] == 0:
                        group0.append(v)
                    else:
                        group1.append(v)
                    q.append(v)

if len(group0) >= k:
    print("YES")
    print(" ".join(map(str, group0[:k])))
elif len(group1) >= k:
    print("YES")
    print(" ".join(map(str, group1[:k])))
else:
    print("NO")
```
