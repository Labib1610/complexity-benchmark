<STATEMENT>
# Problem A — Compliant Committee

Time limit: 5 s   Memory limit: 256 MB

## Description

A corporate department has **n** employees (numbered 1..n) and a log of **m** restriction records. Each record is directional, indicating that a specific employee (the initiator) is restricted from working with another (the target).

A project committee of exactly **k** employees must be formed. Department policy dictates that a committee is **compliant** if it never contains both the initiator and the target of any single restriction record. That is, for every record, at least one of the two specified employees must be absent from the committee.

Given a target committee size **k**, decide whether a compliant committee of exactly **k** employees exists, and if so report one.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), indicating a restriction record where employee **u** is the initiator and employee **v** is the target. 
To prevent duplicate paperwork, for any pair of distinct employees, there is at most one restriction record involving them in either direction (e.g., if a record exists with initiator **u** and target **v**, there is no other record for **u** and **v** in any order).

## Output

If a compliant committee of **k** employees exists, print `YES` on the first line, then on the second line print **k** distinct employee numbers forming such a committee, separated by spaces. Any compliant committee is accepted.

If no such committee exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

A compliant committee ensures that no two chosen employees correspond to the initiator and target of the same restriction record. In Example 2, employees 1, 3 and 5 can be selected because no record has both its initiator and target in this group. In Example 1, no subset of three employees satisfies the policy for all restriction records.
</STATEMENT>
<RATIONALE>
Changed the relation from mutual conflicts to directed restriction records (initiator and target), while keeping the committee validity rule symmetric (neither both can be selected). This removes the obvious "undirected conflict graph" affordance, forcing the model to deduce that the underlying constraint structure is still an undirected independent set rather than directly pattern-matching to memorized undirected graph templates.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the committee cannot contain both the initiator and the target of a record is mathematically identical to the original condition that no two selected employees have a conflict pair.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Independent Set problem on an undirected graph, maintaining its NP-complete complexity.
</PRESERVED_CLASS>
<RISK>
Models might be confused by the directed flavor text and attempt to build a directed graph, but the explicit rule "never contains both" unambiguously defines the symmetric constraint.
</RISK>
