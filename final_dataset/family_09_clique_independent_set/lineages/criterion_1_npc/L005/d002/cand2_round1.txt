<STATEMENT>
# Problem A — Harmonious Delegation

Time limit: 5 s   Memory limit: 256 MB

## Description

A corporate department has **n** employees (numbered 1..n) and a log of **m** documented friction events. Each event identifies a source employee and a target employee.

When a delegation of **k** employees is assembled, the remaining **n - k** employees must manage regular operations. A delegation is considered **harmonious** if, for every friction event in the log, at least one of the two employees involved (either the source or the target) is assigned to regular operations.

Given a target delegation size **k**, decide whether a harmonious delegation of exactly **k** employees exists, and if so report one.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), meaning a friction event occurred where employee **u** is the source and employee **v** is the target. The input will never contain more than one event involving the same pair of employees (i.e., if **u** and **v** appear together on a line, they will not appear together on any other line in either order).

## Output

If a harmonious delegation of **k** employees exists, print `YES` on the first line, then on the second line print **k** distinct employee numbers forming such a delegation, separated by spaces. Any delegation satisfying the condition is accepted.

If no such delegation exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

A harmonious delegation ensures that regular operations absorb all friction events. In Example 2, choosing employees 1, 3, and 5 for the delegation leaves employees 2 and 4 for regular operations; the event between 1 and 2 is covered by employee 2, and the event between 3 and 4 is covered by employee 4. In Example 1, any delegation of three employees leaves only one employee for regular operations, which is not enough to cover the given events.
</STATEMENT>
<RATIONALE>
I changed the constraint from an exclusion within the chosen set to a covering requirement on the unchosen set (regular operations). This forces the model to deduce that "at least one involved employee is left out" is logically equivalent to "no two involved employees can both be selected", preventing surface-level pattern matching on standard independent-set phrasing.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that at least one employee from every friction event is excluded from the delegation is logically identical to the original requirement that no two employees in the delegation share a grievance, preserving all valid delegations.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Independent Set problem, as the new condition is just the contrapositive (Vertex Cover) applied to the remaining n-k vertices.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "assigned to regular operations" as a separate output task, though the output format explicitly asks only for the k employees in the delegation.
</RISK>
