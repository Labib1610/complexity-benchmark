<STATEMENT>
# Problem A — Harmonious Delegation

Time limit: 5 s   Memory limit: 256 MB

## Description

A corporate department has **n** employees (numbered 1..n) and a log of **m** formal grievances. Each grievance record specifies an initiator and a subject.

A project delegation is **harmonious** if the number of grievance records fully subsumed by the delegation is exactly zero. A record is fully subsumed if the set of employees involved in it (both the initiator and the subject) is a subset of the delegation.

Given a target delegation size **k**, determine if there is a harmonious delegation of exactly **k** employees, and if so, report one.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), indicating a grievance record where **u** is the initiator and **v** is the subject. The input will never contain more than one grievance involving the same pair of employees (i.e., if **u** and **v** appear together on a line, they will not appear together on any other line in either order).

## Output

If a harmonious delegation of **k** employees exists, print `YES` on the first line, then on the second line print **k** distinct employee numbers forming such a delegation, separated by spaces. Any delegation that fully subsumes zero grievance records is accepted.

If no such delegation exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

A harmonious delegation fully subsumes zero grievance records. In Example 2, the delegation of employees 1, 3, and 5 fully subsumes no grievance records. In Example 1, any selection of three employees will fully subsume at least one grievance record.
</STATEMENT>
<RATIONALE>
Changed the framing of the constraint from a pairwise conflict ("no employee has a grievance against another") to a set-inclusion property ("zero grievance records fully subsumed"). This forces models to deduce that avoiding subsumed pairs is mathematically equivalent to finding an independent set on an undirected graph, rather than triggering their pre-existing templates for symmetric pairwise conflicts.
</RATIONALE>
<PRESERVED_ANSWER>
A delegation subsumes zero records if and only if it never contains both the initiator and subject of any grievance, which is exactly the original condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Independent Set on an undirected graph, as we are still selecting k vertices such that no edge has both its endpoints selected.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "fully subsumed" if they ignore the parenthetical definition, but the explicit clarification "(both the initiator and the subject) is a subset of the delegation" removes any real ambiguity.
</RISK>
