**Solution Explanation**

For a document `i`

* `deg[i]` – number of shared blocks that contain `i`
* each shared block is an edge `(u , v)` of an undirected simple graph `G`
  (the two documents that reference this block).

For a set `S` of documents  

* `sumDeg(S) = Σ deg[i] , i∈S`
* `footprint(S) = number of different edges incident to at least one vertex of `S`

```
sumDeg(S) = 2·insideEdges(S) + crossingEdges(S)
footprint(S) =     insideEdges(S) + crossingEdges(S)
```

`insideEdges(S)` – edges whose both ends are inside `S`  
`crossingEdges(S)` – edges with exactly one end in `S`.

Equality `sumDeg = footprint` ⇔ `insideEdges = 0`.  
So we have to choose **k** vertices that contain **no edge between them**,
i.e. an **independent set** of size `k`.

The problem is reduced to: *find an independent set of size `k` in a graph
with `n ≤ 46` vertices*.

--------------------------------------------------------------------

#### 1.   Meet‑in‑the‑middle

Split the vertex set into two halves  

```
L : first nL vertices   (nL = n // 2,   nL ≤ 23)
R : remaining nR vertices (nR = n - nL, nR ≤ 23)
```

For each half we enumerate **all** subsets ( `2^23 = 8 388 608` – easily fast
enough) and keep only the independent ones.

*For a subset we also store*
* its size,
* its bitmask (relative to the half).

--------------------------------------------------------------------

#### 2.   Compatibility between the halves

For a left independent subset `maskL`

```
forbiddenR = union of neighbours (in R) of all vertices of maskL
```

Any right subset we add must avoid all vertices in `forbiddenR`.

--------------------------------------------------------------------

#### 3.   Fast query for the right side

We need, for many different `allowedR` masks, the **largest** independent
right subset that is a sub‑mask of `allowedR` (and also its concrete mask).

Let  

```
best[mask] = size of the largest independent right subset that equals mask
rep[mask]  = that subset mask itself (any one)
```

Initially `best[mask] = size` for every independent right subset, otherwise `-1`.

Now run a classic SOS‑DP (subset DP) that propagates the best value to all
supersets:

```
for i in 0 .. nR-1:
    for mask in 0 .. (1<<nR)-1:
        if mask & (1<<i):
            if best[mask ^ (1<<i)] > best[mask]:
                best[mask] = best[mask ^ (1<<i)]
                rep[mask]  = rep[mask ^ (1<<i)]
```

After the loops, for **any** mask `M` the array entry `best[M]` equals the
maximum size of an independent right subset that is a sub‑mask of `M`,
and `rep[M]` stores one such subset.

--------------------------------------------------------------------

#### 4.   Searching the answer

Iterate over all independent left subsets.

```
need = k - sizeL
if need < 0 : continue
allowedR = allRMask ^ forbiddenR
if best[allowedR] >= need:
        we have a solution:
        take the left subset,
        take a right subset of size exactly need
        (rep[allowedR] may be larger, we trim it)
```

Trimming a right mask to the required size is easy: iterate over its bits
and keep the first `need` vertices.

The total work is `O( 2^{nL} + 2^{nR} + n·2^{nR} )`, well below the limits.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct set iff such a set
exists.

---

##### Lemma 1  
For any vertex set `S` the equality  

```
Σ_{v∈S} deg(v) = |{ edges incident to S }|
```

holds **iff** `S` contains no edge whose both ends are in `S`.

**Proof.**  
Let `I` be the number of edges with both ends in `S`,
`C` the number of edges with exactly one end in `S`.

```
Σ deg(v) = 2·I + C          (each internal edge counted twice)
|incident| = I + C
```

Equality ⇔ `2·I + C = I + C` ⇔ `I = 0`. ∎



##### Lemma 2  
A set of vertices satisfies the required condition **iff** it is an
independent set.

**Proof.** Directly from Lemma&nbsp;1. ∎



##### Lemma 3  
`best[mask]` after the SOS‑DP equals the maximum size of an independent
right subset that is a sub‑mask of `mask`, and `rep[mask]` stores one such
subset.

**Proof.** Induction over the DP steps.
Initially the statement holds for masks that are exactly independent subsets
(their own size) and for all other masks the size is `-1` (no subset).
The transition considers removing one bit `i`. Any sub‑mask of `mask`
either already is a sub‑mask of `mask` without `i` or contains `i` and
therefore is a sub‑mask of `mask ^ (1<<i)`. Taking the maximum of the two
maintains the invariant. The stored representative is copied together with
the size, therefore it always corresponds to the stored size. ∎



##### Lemma 4  
When the algorithm reports a set, it is an independent set of size `k`.

**Proof.**  
The left part is taken from the list of independent left subsets,
the right part is taken from `rep[allowedR]`, which by Lemma&nbsp;3 is an
independent right subset.  
By construction `allowedR` contains no vertex adjacent to any vertex of the
left subset, therefore there is no edge between the two halves.
Thus the union is independent. Its size is `sizeL + need = k`. ∎



##### Lemma 5  
If an independent set `S` of size `k` exists, the algorithm finds one.

**Proof.**  
Split `S` into `SL ⊆ L` and `SR ⊆ R`. Both are independent in their halves,
so they appear in the enumerated lists.
When the algorithm processes `maskL = SL` :

* `forbiddenR` is exactly the set of neighbours of `SL` in `R`.  
  Because `S` is independent, `SR` contains none of those neighbours,
  therefore `SR ⊆ allowedR`.

* `need = k - |SL| = |SR|`.

Since `SR` is an independent right subset contained in `allowedR`,
Lemma&nbsp;3 guarantees `best[allowedR] ≥ |SR| = need`.  
Consequently the algorithm will recognise the possibility and output a
solution (maybe a different right subset, but still of size `need`). ∎



##### Theorem  
The program prints “YES” and a list of `k` indices exactly when such a
selection exists; otherwise it prints “NO”.

**Proof.**  
*If the program prints “YES”* – by Lemma&nbsp;4 the printed set is an
independent set of size `k`, therefore a valid selection (Lemma&nbsp;2).

*If a valid selection exists* – by Lemma&nbsp;5 the algorithm will find a
set and consequently print “YES”.  
If none exists, the algorithm never meets the condition and finally prints
“NO”. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

```
nL ≤ 23 , nR ≤ 23
enumerating left subsets   : 2^{nL}
enumerating right subsets  : 2^{nR}
SOS‑DP on right side       : nR · 2^{nR}
search over left subsets   : 2^{nL}
```

All together `O( (nR+1)·2^{max(nL,nR)} ) ≤ O( 24·2^{23} ) ≈ 2·10^8` elementary
operations – well inside 5 seconds in PyPy / CPython with simple bitwise
operations.

Memory:

* two integer arrays of length `2^{nR}` (`best` and `rep`) → at most
  `2·8 M·4 bytes ≈ 64 MB`.
* lists of independent subsets of each half – at most the same order,
  still far below the 256 MB limit.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); k = int(next(it))
    adj = [0] * n
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u] |= 1 << v
        adj[v] |= 1 << u

    nL = n // 2
    nR = n - nL
    left_ids = list(range(nL))
    right_ids = list(range(nL, n))

    # masks relative to halves
    left_adj = [0] * nL
    right_adj = [0] * nR
    # neighbours inside the same half
    for i in range(nL):
        mask = 0
        for j in range(nL):
            if adj[i] >> j & 1:
                mask |= 1 << j
        left_adj[i] = mask
    for i in range(nR):
        v = nL + i
        mask = 0
        for j in range(nR):
            if adj[v] >> (nL + j) & 1:
                mask |= 1 << j
        right_adj[i] = mask

    # enumerate independent subsets of left half
    left_subs = []
    for mask in range(1 << nL):
        ok = True
        # check internal edges
        # fast: for each vertex present, ensure no neighbour also present
        mm = mask
        while mm:
            v = (mm & -mm).bit_length() - 1
            if left_adj[v] & mask:
                ok = False
                break
            mm &= mm - 1
        if ok:
            left_subs.append((mask, mask.bit_count()))
    # enumerate independent subsets of right half
    sizeR = 1 << nR
    best = [-1] * sizeR
    rep = [0] * sizeR
    for mask in range(1 << nR):
        ok = True
        mm = mask
        while mm:
            v = (mm & -mm).bit_length() - 1
            if right_adj[v] & mask:
                ok = False
                break
            mm &= mm - 1
        if ok:
            sz = mask.bit_count()
            best[mask] = sz
            rep[mask] = mask

    # SOS DP to propagate best to supersets
    for i in range(nR):
        bit = 1 << i
        for mask in range(sizeR):
            if mask & bit:
                prev = mask ^ bit
                if best[prev] > best[mask]:
                    best[mask] = best[prev]
                    rep[mask] = rep[prev]

    allRMask = (1 << nR) - 1

    # precompute neighbour mask from left vertex to right half
    left_to_right = [0] * nL
    for i in range(nL):
        nb = 0
        for j in range(nR):
            if adj[i] >> (nL + j) & 1:
                nb |= 1 << j
        left_to_right[i] = nb

    for maskL, szL in left_subs:
        need = k - szL
        if need < 0:
            continue
        # compute forbidden vertices in right half
        forbid = 0
        mm = maskL
        while mm:
            v = (mm & -mm).bit_length() - 1
            forbid |= left_to_right[v]
            mm &= mm - 1
        allowed = allRMask ^ forbid
        if best[allowed] >= need:
            # we have a solution
            # take left vertices
            ans = []
            mm = maskL
            while mm:
                v = (mm & -mm).bit_length() - 1
                ans.append(v + 1)          # back to 1‑based
                mm &= mm - 1
            # take right vertices from rep[allowed], possibly trim
            maskR = rep[allowed]
            taken = 0
            while taken < need:
                v = (maskR & -maskR).bit_length() - 1
                ans.append(nL + v + 1)
                maskR &= maskR - 1
                taken += 1
            # output
            print("YES")
            print(' '.join(map(str, ans)))
            return

    print("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
