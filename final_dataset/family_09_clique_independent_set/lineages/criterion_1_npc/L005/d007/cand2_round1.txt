<METHOD_DESCRIPTION>Replaces the arbitrary arithmetic equation (which models easily simplify algebraically to discover the independent set penalty) with a natural set-theoretic equivalence (sum of sizes equals size of union) grounded in a data deduplication scenario. This forces the model to recognize that equality only holds when the sets are pairwise disjoint, which translates back to the independent set condition, without providing any algebraic formula to parse.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Deduplication Backup

Time limit: 5 s   Memory limit: 256 MB

## Description

You are managing a storage system containing **n** document files.
To save space, the system uses data deduplication. There are **m** shared data blocks in the system. Each of these data blocks is referenced by exactly two distinct document files.

For any document, its *reference count* is the number of shared data blocks it references.

When a set of documents is selected for an archive, the system calculates two metrics:
1. The *sum of reference counts*: the sum of the reference counts of all documents in the set.
2. The *archive footprint*: the total number of **unique** shared data blocks referenced by at least one document in the set.

Your task is to select exactly **k** document files from the **n** available files such that the *archive footprint* is exactly equal to the *sum of reference counts*.

If such a selection exists, report it by listing the 1-based indices of the selected files.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ **n** ≤ 46, 0 ≤ **m** ≤ **n**·(**n**−1)/2, 1 ≤ **k** ≤ **n**).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), indicating that a shared data block is referenced by document **u** and document **v**. The input will never list the same pair of documents more than once.

## Output

If a valid selection exists, print `YES` on the first line, then on the second line print the **k** distinct indices of the selected documents, separated by spaces. If multiple valid selections exist, any valid selection is accepted. Print only the **k** selected indices.

If no such selection exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

In Example 2, if we select documents 1, 3, and 5:
- Document 1 references one shared block (shared with 2). Its reference count is 1.
- Document 3 references one shared block (shared with 4). Its reference count is 1.
- Document 5 references zero shared blocks. Its reference count is 0.
The sum of reference counts is 1 + 1 + 0 = 2.
The shared blocks referenced by this set are the block for (1, 2) and the block for (3, 4). There are 2 unique blocks in total, so the archive footprint is 2.
Since the archive footprint equals the sum of reference counts (2 = 2), this selection is valid.

In Example 1, any selection of exactly 3 documents will result in at least one shared block where both referencing documents are included in the archive. For instance, if we select 1, 2, and 4, the block shared by 1 and 2 is referenced by both.
The sum of reference counts for 1, 2, and 4 is 2 + 2 + 1 = 5.
The unique shared blocks referenced are (1, 2), (1, 3), (2, 3), and (3, 4). The archive footprint is 4.
Since 5 ≠ 4, this selection is invalid. In fact, no selection of exactly 3 documents will have these two metrics equal.

<RATIONALE>
The seed problem explicitly provided an arithmetic equation that models could algebraically simplify to discover that an internal edge contributes an irreversible penalty, revealing the Independent Set structure. This rewrite completely removes the arithmetic equation, replacing it with a set-theoretic condition (sum of sizes equals size of union) in a data deduplication scenario. To succeed, the model must now use inclusion-exclusion reasoning to deduce that equality only holds when the selected documents share zero data blocks.
</RATIONALE>
