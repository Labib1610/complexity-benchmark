</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the graph independent set condition ("no two active sensors share an edge") with an equivalent mathematical condition on the symmetric difference between the active set and each edge ("the symmetric difference between the active cluster and any pattern must have size >= k"). This algebraically evaluates to the exact same requirement but defeats LLM pattern matching, forcing them to either perform the algebraic reduction themselves to uncover the pruning condition, or write a naive simulation that will inevitably Time Limit Exceed.
</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Zero-Interference Cluster

Time limit: 5 s   Memory limit: 256 MB

## Description

A scientific observatory is equipped with **n** telemetry sensors (numbered 1 to **n**). 
During initial calibration, engineers catalogued **m** potential interference patterns. Each pattern involves exactly two specific sensors.

The observatory needs to activate a focused cluster of exactly **k** sensors for a delicate measurement. Let $C$ be the set of sensors chosen for activation.
To ensure data integrity, the system calculates a *divergence score* for each of the **m** catalogued patterns. For a given pattern $P$, the divergence score is defined as the number of sensors that belong to exactly one of the two sets: the active cluster $C$, and the pattern $P$. In other words, it is the size of the symmetric difference between $C$ and $P$.

A cluster configuration is considered **clean** if, for every catalogued pattern, its divergence score is at least **k**.

Given the total number of sensors **n**, the number of known interference patterns **m**, and the target cluster size **k**, determine whether a clean cluster of exactly **k** sensors can be configured, and if so, report one.

## Input

The first line contains three integers **n**, **m**, and **k**.
The observatory's multiplexer supports a minimum of 1 and a maximum of 46 active telemetry channels, defining the limits for **n**. The engineers may have catalogued anywhere from 0 up to every possible pair of sensors as patterns for **m**. The exact target cluster size **k** is guaranteed to be at least 1 and will not exceed the available **n** sensors.

Each of the next **m** lines contains two distinct integers **u** and **v** representing the sensor numbers (from 1 to **n**) that make up a specific interference pattern. No pattern is listed more than once.

## Output

If a clean cluster of exactly **k** sensors exists, print `YES` on the first line, then on the second line print the **k** distinct sensor numbers to be activated, separated by spaces. If multiple clean clusters exist, any valid configuration is accepted. Print only the **k** activated sensors.

If no such cluster exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

In Example 2, the target cluster size is $k=3$. Activating sensors 1, 3, and 5 forms the cluster $C = \{1, 3, 5\}$.
The first pattern is $P_1 = \{1, 2\}$. The sensors belonging to exactly one of $C$ or $P_1$ are 2, 3, and 5. There are 3 such sensors, so the divergence score is 3. Since $3 \ge 3$, this pattern is clean.
The second pattern is $P_2 = \{3, 4\}$. The sensors in exactly one of $C$ or $P_2$ are 1, 4, and 5. The divergence score is 3.
Since all patterns have a divergence score of at least 3, the configuration is clean.

In Example 1, any choice of 3 sensors will completely contain at least one of the patterns. For example, if $C = \{1, 2, 3\}$, the pattern $P_1 = \{1, 2\}$ is fully contained in $C$. The sensors in exactly one of $C$ or $P_1$ is only sensor 3. The divergence score is 1, which is strictly less than $k=3$, so this configuration is not clean.
</STATEMENT>
<RATIONALE>
Replaced the direct conflict condition ('generated if and only if two specific sensors are active simultaneously') with an equivalent set-theoretic condition ('size of the symmetric difference between the active cluster and the pattern must be at least k'). This forces the model to algebraically reduce the symmetric difference condition to realize it is simply an independent set problem; without this mathematical deduction, the model cannot effectively prune its search space and will fail due to the time limit. The numeric bounds were also woven into the scenario text to prevent direct inequality matching.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $|C \Delta P| \ge k$ for a cluster of size $k$ and a pattern of size 2 simplifies algebraically to $|C \cap P| \le 1$, which is exactly the original requirement that no two sensors in a pattern can be simultaneously active, leaving all valid configurations completely unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Independent Set problem on a graph, which is NP-complete, simply presented through an equivalent mathematical definition of the edge constraint.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret 'symmetric difference' if they fail to read the explicit definition provided ('belong to exactly one of the two sets'), though the detailed worked example mitigates this risk almost entirely by demonstrating the exact calculation.
</RISK>
