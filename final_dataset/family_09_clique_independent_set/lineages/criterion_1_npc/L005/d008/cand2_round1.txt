# Problem A — Deduplication Backup

Time limit: 5 s   Memory limit: 256 MB

## Description

You are managing a storage system containing **n** document files.
To save space, the system uses data deduplication. There are **m** shared data blocks in the system. Each of these data blocks is referenced by exactly two distinct document files.

For any document, its *span* is defined as the set of shared data blocks it references.

When a set of documents is selected for an archive, the system calculates two aggregate sets to determine the archive's structural complexity:
1. The *Standard Union*: the set of all shared data blocks that are referenced by **at least one** document in the chosen set.
2. The *Symmetric Union*: the set of all shared data blocks that are referenced by an **odd number** of documents in the chosen set. (This is the generalized symmetric difference of their spans).

Your task is to select exactly **k** document files from the **n** available files such that the *Symmetric Union* of the selected files is exactly identical to their *Standard Union*.

If such a selection exists, report it by listing the 1-based indices of the selected files.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ **n** ≤ 46, 0 ≤ **m** ≤ **n**·(**n**−1)/2, 1 ≤ **k** ≤ **n**).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), indicating that a shared data block is referenced by document **u** and document **v**. The input will never list the same pair of documents more than once.

## Output

If a valid selection exists, print `YES` on the first line, then on the second line print the **k** distinct indices of the selected documents, separated by spaces. If multiple valid selections exist, any valid selection is accepted. Print only the **k** selected indices.

If no such selection exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

In Example 2, if we select documents 1, 3, and 5:
- The span of document 1 is {block (1,2)}.
- The span of document 3 is {block (3,4)}.
- The span of document 5 is empty {}.
The *Standard Union* of these spans contains block (1,2) and block (3,4).
Block (1,2) is referenced by exactly 1 selected document (document 1). Since 1 is odd, it is in the *Symmetric Union*.
Block (3,4) is referenced by exactly 1 selected document (document 3). Since 1 is odd, it is in the *Symmetric Union*.
Both sets are {block (1,2), block (3,4)} and are identical. This selection is valid.

In Example 1, any selection of exactly 3 documents will result in at least one shared block where both referencing documents are included in the archive. For instance, if we select 1, 2, and 4:
- The span of 1 includes block (1,2) and block (1,3).
- The span of 2 includes block (1,2) and block (2,3).
- The span of 4 includes block (3,4).
The *Standard Union* contains blocks (1,2), (1,3), (2,3), and (3,4).
However, block (1,2) is referenced by exactly 2 selected documents (documents 1 and 2). Since 2 is even, block (1,2) is **not** in the *Symmetric Union*.
Because the *Symmetric Union* is missing block (1,2), the two sets are not identical. In fact, no selection of exactly 3 documents will have identical sets.

<RATIONALE>
The surviving models succeeded because they translated the arithmetic equation `footprint == sum of reference counts` directly into the algebraic constraint `c_j <= 1`, recognizing it as an independent set. This rewrite shifts the constraint to the set-theoretic domain, requiring the Symmetric Union to equal the Standard Union. To reach the independent set condition, the model must deduce that subset equality implies the absence of even-frequency elements, breaking the algebraic pattern-matching they relied on.
</RATIONALE>
<PRESERVED_ANSWER>
Since each block is referenced by at most two documents globally, it can appear in a selection 0, 1, or 2 times; the Symmetric Union and Standard Union are identical if and only if no block appears 2 times, exactly matching the original independent set condition.
</PRESERVED_ANSWER>
