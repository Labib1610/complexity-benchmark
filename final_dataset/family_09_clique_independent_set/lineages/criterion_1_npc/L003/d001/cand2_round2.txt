# Problem A — Thermal Test Vector

Time limit: 5 s   Memory limit: 256 MB

## Description

You are preparing a thermal diagnostic test for a newly fabricated microchip. The chip exposes **n** input pins (numbered 1 to n). Internally, the chip contains **m** thermal comparators.

Each comparator is linked to a specific pair of distinct input pins. A comparator safely dissipates heat as long as it does not receive an active pulse from both of its linked pins simultaneously. If both linked pins receive an active pulse, the comparator overheats and triggers a hardware fault.

To safely complete the diagnostic sequence, every single one of the **m** comparators must avoid overheating. However, the diagnostic sensors require a minimum power draw, which dictates that you must deliver an active pulse to exactly **k** of the input pins, leaving the remaining **n**−**k** pins inactive.

Determine if there is a valid test sequence. If a safe configuration exists, report one by listing the **k** pins that should receive the active pulse.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), indicating that a thermal comparator is linked to input pins **u** and **v**. No two comparators are linked to the exact same pair of pins.

## Output

If a safe configuration exists, print `YES` on the first line. On the second line, print the numbers of the **k** distinct input pins that should receive an active pulse, separated by spaces. If there are multiple valid sets of pins, any configuration that prevents all comparators from overheating is accepted.

If no such configuration is possible, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

<RATIONALE>
The problem was rewritten to replace the explicit Boolean logic (NAND gates) with a physical constraint (thermal comparators overheating if both linked pins are active). This removes the direct translation from logic gates to graph properties, forcing the model to deduce the independent-set structure from the physical rules of the test. The exact numeric bounds were restored to the Input section to satisfy strict I/O contract preservation.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that a comparator overheats only if both of its linked pins are active is logically identical to a NAND gate outputting LOW only if both inputs are HIGH; thus, any set of exactly k pins that keeps all comparators safe is exactly a valid test vector from the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the Independent Set problem on a graph with n vertices and m edges, asking for an independent set of exactly size k, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
None. The conditions for an active pulse and the fault trigger are explicitly defined and map 1:1 to the original constraints.
</RISK>
