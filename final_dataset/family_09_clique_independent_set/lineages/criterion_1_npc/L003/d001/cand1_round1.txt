# Problem A — Thermal Test Vector

Time limit: 5 s   Memory limit: 256 MB

## Description

You are preparing a thermal diagnostic test for a newly fabricated microchip. The chip exposes **n** input pins (numbered 1 to n). Internally, the circuit contains **m** thermal junctions.

To draw enough baseline power to activate the thermal sensors, you must activate exactly **k** of the input pins (leaving the remaining **n**−**k** pins inactive). However, you must also avoid overheating the circuit. 

Each of the **m** thermal junctions bridges a specific pair of distinct input pins. A junction will overheat if both of its connected pins are active. As long as a junction is not simultaneously energized from both sides, it remains stable. Every single one of the **m** junctions must remain stable during the test.

Given the layout of the junctions, determine if there is a valid test configuration. If one exists, report it by listing the **k** pins that should be activated.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), indicating that a thermal junction bridges input pins **u** and **v**. No two junctions bridge the exact same pair of pins.

## Output

If a valid configuration exists, print `YES` on the first line. On the second line, print the numbers of the **k** distinct input pins that should be activated, separated by spaces. If there are multiple valid sets of pins, any configuration that keeps all junctions stable is accepted.

If no such configuration is possible, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

<RATIONALE>
Removed the explicit references to "NAND gates" and "HIGH/LOW" signals, which models were using as a direct keyword shortcut to boolean logic and independent set mapping. Replaced them with "thermal junctions" that overheat if both connected pins are energized, forcing the model to read the physical mechanics to derive the independent set constraint.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that a junction overheats if both pins are active is logically identical to a NAND gate outputting LOW when both inputs are HIGH, so the valid sets of exactly k pins remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a set of k vertices such that no two share an edge (an independent set of size k), keeping it NP-complete.
</PRESERVED_CLASS>
