<METHOD_NAME>
Quadratic Form Nullification
</METHOD_NAME>
<METHOD_DESCRIPTION>
Transforms the graph independent set problem into finding a binary vector x of Hamming weight k such that the quadratic form x^T M x evaluates to 0, where M is the adjacency matrix. This requires the model to algebraicize the graph constraint, unpack the definition of the quadratic form to realize it restricts pairwise selections, and map it back to the underlying combinatorial structure.
</METHOD_DESCRIPTION>

yes

<STATEMENT>
# Problem A — Vector Configuration

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing an $n \times n$ symmetric matrix $M$, where all elements are initially 0.
You receive $m$ updates. Each update provides two distinct 1-based indices $u$ and $v$, and sets both $M_{u,v} = 1$ and $M_{v,u} = 1$.

Your objective is to find a binary column vector $\mathbf{x}$ of dimension $n$ (where each component $x_i \in \{0, 1\}$) that satisfies two conditions:
1. The sum of the components of $\mathbf{x}$ is exactly $k$.
2. The quadratic form $\mathbf{x}^T M \mathbf{x}$ evaluates to 0.

Evaluate whether such a vector $\mathbf{x}$ exists. If it does, you must also provide the indices $i$ where $x_i = 1$.

## Input

The first line provides three integers $n$, $m$, and $k$ (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
Following this are $m$ lines, each containing two integers $u$ and $v$ (1 ≤ u, v ≤ n, u ≠ v). These indicate an update setting $M_{u,v} = 1$ and $M_{v,u} = 1$. Each update pair is listed at most once.

## Output

If a valid vector $\mathbf{x}$ can be formed, output `YES` on the first line. On the next line, output the $k$ distinct 1-based indices $i$ where $x_i = 1$, separated by spaces. Any valid set of indices will be accepted if more than one exists.

If forming such a vector is impossible, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```
</STATEMENT>
<RATIONALE>
The problem was reframed from a graph independent set constraint (no two selected members have an interaction) to an algebraic constraint (a binary vector $\mathbf{x}$ of Hamming weight $k$ such that the quadratic form $\mathbf{x}^T M \mathbf{x} = 0$). This forces the model to algebraicize the problem, unpack the definition of the quadratic form to realize it restricts pairwise selections, and map it back to the underlying combinatorial structure.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $\mathbf{x}^T M \mathbf{x} = 0$ for a binary vector and a binary matrix with zeros on the diagonal is algebraically equivalent to stating that no two indices $i, j$ with $x_i=1$ and $x_j=1$ have $M_{i,j}=1$, which exactly mirrors the original interaction constraints.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Independent Set (NP-complete), merely expressed through the adjacency matrix and its quadratic form rather than graph terminology.
</PRESERVED_CLASS>
<RISK>
Models might struggle with the notation $\mathbf{x}^T M \mathbf{x}$ if they lack linear algebra training, but this is a standard mathematical concept and unambiguous.
</RISK>
