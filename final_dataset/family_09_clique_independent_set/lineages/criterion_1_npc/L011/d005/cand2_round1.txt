# Problem A — Panel Selection

Time limit: 5 s   Memory limit: 256 MB

## Description

A social network tracks **n** member profiles, identified by numbers from 1 to **n**. The system has recorded **m** bilateral interaction events, each representing an exchange between two distinct members.

A research initiative requires selecting exactly **k** members to form a focus panel. The selection process uses an aggregate scoring condition to ensure the panel's validity.

For any proposed panel, each of the **m** recorded events is assigned a score. Let $c$ be the number of panel members involved in a given event (note that $c$ can only be 0, 1, or 2). The score for that event is defined as the factorial of $c$, denoted as $c!$ (recall that $0! = 1$, $1! = 1$, and $2! = 2$).

The proposed focus panel is considered valid if and only if the sum of these scores across all **m** events is exactly equal to **m**.

Your objective is to evaluate whether it is possible to construct a valid focus panel of exactly **k** members. If such a panel can be formed, you must also provide a list of its members.

## Input

The first line provides three integers **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
Following this are **m** lines, each containing two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v). These indicate an interaction event between member **u** and member **v**. Each interaction event is listed at most once.

## Output

If a valid focus panel of exactly **k** members can be formed, output `YES` on the first line. On the next line, output the **k** distinct member numbers that constitute the panel, separated by spaces. Any valid panel will be accepted if more than one exists.

If forming such a panel is impossible, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```

```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```
