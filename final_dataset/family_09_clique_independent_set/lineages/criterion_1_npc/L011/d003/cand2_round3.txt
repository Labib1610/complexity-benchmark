# Problem A — Panel Selection

Time limit: 5 s   Memory limit: 256 MB

## Description

A social network tracks **n** member profiles, identified by numbers from 1 to **n**. The system has recorded **m** bilateral interaction events, each representing an exchange between two distinct members.

A research initiative requires selecting exactly **k** members to form a focus panel. The selection is considered valid if and only if for every recorded interaction event, at least one of the two participating members is not included in the focus panel.

Your objective is to evaluate whether it is possible to construct a valid focus panel of exactly **k** members under these constraints. If such a panel can be formed, you must also provide a list of its members.

## Input

The first line provides three integers **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
Following this are **m** lines, each containing two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v). These indicate an interaction event between member **u** and member **v**. Each interaction event is listed at most once.

## Output

If a valid focus panel of exactly **k** members can be formed, output `YES` on the first line. On the next line, output the **k** distinct member numbers that constitute the panel, separated by spaces. Any valid panel will be accepted if more than one exists.

If forming such a panel is impossible, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

<RATIONALE>
I removed the "control group" and "partition" narrative which caused task drift in previous attempts, replacing it with a direct coverage obligation on the selected panel. By stating that every interaction must have at least one participant excluded from the panel, solvers must reason about the exclusion condition without the explicit "no internal edges" graph-theoretic cue.
</RATIONALE>
<PRESERVED_ANSWER>
Requiring that every recorded interaction has at least one participant not in the panel is logically identical to requiring that no two members in the panel have interacted, ensuring the exact same valid selections.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Independent Set problem on a graph, asking if a subset of size $k$ exists with no edges between its vertices.
</PRESERVED_CLASS>
