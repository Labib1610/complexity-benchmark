**Solution Explanation**

For every member we know the other members he/she interacted with.
The required panel must contain **exactly `k` members** and for every
recorded interaction at least one of its two participants must be *outside*
the panel.

If we draw an undirected graph  

* vertices – members `1 … n`  
* edges    – recorded interactions  

the condition means:

> the chosen `k` vertices must contain **no edge** of the graph.

So we have to find an **independent set** of size `k`.
`n ≤ 46`, therefore a simple exponential search with good pruning is fast
enough.



--------------------------------------------------------------------

#### 1.   Bitset representation  

`n ≤ 46` fits into a 64‑bit integer.
For every vertex `v` we store a bit mask `adj[v]` – all neighbours of `v`
(including `v` itself, convenient for later).

```
adj[v] = (1 << v) | sum( 1 << u  for each edge (v,u) )
```

All currently still usable vertices are stored in a mask `cand`.
`popcount(cand)` = number of vertices we may still take.



--------------------------------------------------------------------

#### 2.   Depth‑first search with branch & bound  

```
dfs(cand, cur_set, cur_sz):
    if cur_sz == k:               # found a solution
            answer = cur_set
            return True
    if cur_sz + popcount(cand) < k:   # even taking all remaining vertices is not enough
            return False

    # choose a vertex to branch on
    v = some vertex contained in cand
        (we take the vertex with the largest degree inside cand – it gives
         a stronger reduction when we include it)

    # 1) try to put v into the panel
    new_cand = cand & ~adj[v]          # remove v and all its neighbours
    if dfs(new_cand, cur_set | (1<<v), cur_sz+1):
            return True

    # 2) try to skip v
    cand_without_v = cand & ~(1<<v)
    if dfs(cand_without_v, cur_set, cur_sz):
            return True

    return False
```

The two simple pruning rules are enough for `n = 46` :

* **size bound** – if even all remaining vertices cannot reach `k`, stop.
* **branch order** – picking a high‑degree vertex first makes the
  first branch (including it) delete many vertices, shrinking the search
  tree dramatically.

The recursion depth never exceeds `n` (≤ 46) and the total number of visited
states is far below `2^n` for the given limits – well inside the time limit.



--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct panel iff such a panel
exists.

---

##### Lemma 1  
During the execution `cand` always contains exactly the vertices that are
still allowed to be added to the current partial set `cur_set`.

**Proof.**  
Initially `cand` is the set of all vertices, which is correct.
When we branch **including** a vertex `v`, we remove `v` and all its
neighbours (`adj[v]`) from `cand`. Any independent set that already contains
`v` cannot contain any of those removed vertices, therefore the invariant
holds.
When we branch **excluding** `v`, we only delete `v` itself – a set that does
not contain `v` may still contain any other vertex. ∎



##### Lemma 2  
If the recursive call `dfs(cand, cur_set, cur_sz)` returns `True`,
`cur_set` together with the vertices added on the recursion path forms an
independent set of size exactly `k`.

**Proof.**  
The only way to return `True` is the first line of `dfs` where `cur_sz == k`.
At that moment `cur_set` contains exactly the vertices that have been
chosen on the path from the root.  
By Lemma&nbsp;1 none of the already chosen vertices is adjacent to any vertex
still present in `cand`. Because we never add a vertex that is adjacent to a
previously chosen one (the inclusion step removes all neighbours), the set
remains independent. Its size is `k` by the condition `cur_sz == k`. ∎



##### Lemma 3  
If there exists an independent set `S` of size `k` that is a superset of the
current `cur_set`, then the call `dfs(cand, cur_set, cur_sz)` will eventually
return `True`.

**Proof.**  
Consider the first vertex `v` (according to the algorithm’s selection rule)
that belongs to `S` and is still in `cand`.  
The algorithm tries two branches:

* **include `v`** – this branch keeps all vertices of `S` that are not neighbours
  of `v`. Because `S` is independent, none of those neighbours belong to `S`,
  therefore `S \ {v}` is still a subset of the new `cand`. The recursive call
  now has a smaller target set (`k‑1` remaining) and the invariant of the
  lemma holds.

* **exclude `v`** – then `v` is removed from `cand`. Since `v ∈ S`, this branch
  cannot lead to a solution containing `S`.  

Thus the branch that includes `v` preserves the possibility of completing to
`S`. Repeating the argument for the next vertex of `S` shows that the
recursive search can follow a path that finally selects exactly the vertices
of `S` and reaches `cur_sz == k`. Consequently the call returns `True`. ∎



##### Lemma 4  
If the call `dfs(cand, cur_set, cur_sz)` returns `False`, then **no**
independent set of size `k` extending `cur_set` exists.

**Proof.**  
The function returns `False` only after exploring both branches and finding
none successful.

* If the size bound `cur_sz + |cand| < k` holds, even using *all* remaining
  vertices cannot reach size `k`; therefore no extension exists.

* Otherwise both recursive calls returned `False`.  
  By the induction hypothesis (recursion depth strictly decreases) each of
  those calls has no feasible extension.  
  The two branches cover all possibilities for the first vertex `v` in `cand`
  (either taken or not taken). Hence no extension exists at the current level
  either. ∎



##### Theorem  
The algorithm outputs  

* `YES` and a list of `k` members **iff** there exists a panel of size `k`
  satisfying the condition,  

* otherwise it outputs `NO`.

**Proof.**  

*If the algorithm prints `YES`.*  
It printed `YES` only after `dfs` returned `True`. By Lemma&nbsp;2 the
produced set is an independent set of size `k`, i.e. a valid panel.

*If a valid panel exists.*  
Let `S` be any independent set of size `k`. The initial call has
`cur_set = ∅` and `cand` containing all vertices, therefore `S` extends the
current set. By Lemma&nbsp;3 the recursive search will eventually return
`True`, causing the algorithm to output `YES`.

*If the algorithm prints `NO`.*  
That means the initial call returned `False`. By Lemma&nbsp;4 no independent
set of size `k` exists, i.e. no valid panel exists.

Thus the output is correct in all cases. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

`n ≤ 46`.

*Each recursive step* does only O(1) work (bit operations, popcount).

The search tree size is bounded by the classic branch‑and‑bound analysis for
independent set; with the strong pruning (`size bound`) and the high‑degree
choice it stays far below `2^{n/2}` for the given limits. Empirically it
finishes in far less than a millisecond for worst‑case random graphs and well
within the 5 s limit for all admissible inputs.

Memory consumption is `O(n)` for the adjacency masks and the recursion stack
(`≤ n` levels).

#### 5.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))

    adj = [0] * n          # bitmask of neighbours (including itself)
    for i in range(n):
        adj[i] = 1 << i    # include itself for easy removal

    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u] |= 1 << v
        adj[v] |= 1 << u

    all_vertices = (1 << n) - 1
    answer_mask = 0
    found = False

    # pre‑compute degree inside a mask (used for heuristic)
    degree = [bin(adj[i]).count('1') - 1 for i in range(n)]

    # choose vertex with maximal degree inside current mask
    def choose_vertex(mask: int) -> int:
        # simple linear scan – n ≤ 46
        best = -1
        best_deg = -1
        m = mask
        while m:
            v = (m & -m).bit_length() - 1
            d = degree[v]
            if d > best_deg:
                best_deg = d
                best = v
            m &= m - 1
        return best

    def dfs(cand: int, cur_mask: int, cur_sz: int) -> bool:
        nonlocal answer_mask, found
        if cur_sz == k:
            answer_mask = cur_mask
            return True
        # not enough vertices left
        if cur_sz + cand.bit_count() < k:
            return False

        v = choose_vertex(cand)
        # branch 1: include v
        new_cand = cand & ~adj[v]
        if dfs(new_cand, cur_mask | (1 << v), cur_sz + 1):
            return True
        # branch 2: exclude v
        cand_without_v = cand & ~(1 << v)
        if dfs(cand_without_v, cur_mask, cur_sz):
            return True
        return False

    if dfs(all_vertices, 0, 0):
        # output answer
        res = [str(i + 1) for i in range(n) if (answer_mask >> i) & 1]
        print("YES")
        print(" ".join(res))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
