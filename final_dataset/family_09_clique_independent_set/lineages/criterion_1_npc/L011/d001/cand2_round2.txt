# Problem A — Panel Selection

Time limit: 5 s   Memory limit: 256 MB

## Description

A digital community platform hosts **n** distinct user profiles, which are assigned identifiers from 1 up to **n**. The system has recorded a history of **m** bilateral exchanges, where each exchange is a direct interaction between two specific users.

An upcoming sociological study requires assembling a specialized focus group containing exactly **k** participants. To prevent echo-chamber effects, the organizers enforce a separation protocol:
- The group must be populated by choosing exactly **k** individuals from the user base.
- For every recorded exchange in the system's history, it is strictly prohibited to include both participants in the focus group. Thus, at least one individual from every exchange must be left out of the final selection.
- The formation is considered successful only if exactly **k** individuals can be chosen while perfectly adhering to this protocol.

Your task is to determine if such a focus group can be established, and if so, to identify the chosen participants.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ **n** ≤ 46, 0 ≤ **m** ≤ **n**·(**n**−1)/2, 1 ≤ **k** ≤ **n**).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), indicating that a bilateral exchange occurred between user **u** and user **v**. No exchange is recorded more than once.

## Output

If the focus group can be successfully formed, output `YES` on the first line. On the second line, output the **k** distinct identifiers of the selected users, separated by spaces. If there are several valid combinations, any one is accepted.

If it is impossible to form the group under the given rules, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

<RATIONALE>
The sequential "flagging as incompatible" mechanic was replaced with a declarative "separation protocol" requiring that at least one participant from every exchange be left out. This shifts the phrasing from a direct description of an Independent Set to its dual, Vertex Cover (leaving out `n-k` vertices to cover all edges). The exact mathematical bounds were restored in the Input section to satisfy the strict H2 checker requirement, as advised by the expert review.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that at least one individual from every interaction must be left out is logically identical to ensuring no two included individuals share an interaction, meaning the valid subsets of size k are exactly the same independent sets as in the seed problem.
</PRESERVED_ANSWER>
