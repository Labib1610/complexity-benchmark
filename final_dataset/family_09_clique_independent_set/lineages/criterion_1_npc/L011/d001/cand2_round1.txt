# Problem A — Panel Selection

Time limit: 5 s   Memory limit: 256 MB

## Description

A social platform maintains member profiles (assigned consecutive integer IDs starting from 1). Over time, the platform has logged bilateral interaction events. Each event involves exactly two distinct members.

A research study aims to assemble a focus panel of exactly **k** members. The selection process must satisfy a strict separation protocol: for every interaction event in the platform's logs, at least one of the two members involved in that event must be excluded from the panel.

Determine whether it is possible to successfully form a panel of **k** members that meets this protocol, and if so, report the members chosen.

## Input

The first line contains three integers **n**, **m**, and **k**.
- **n** represents the total number of member profiles. The platform operates on a legacy server that physically caps the system at a maximum of 46 member profiles, while guaranteeing at least a single profile exists.
- **m** represents the number of logged events. This count can be as low as zero, up to the maximum theoretical limit where every possible unique pair of members has exactly one interaction.
- **k** represents the target panel size. The study requires a minimum of one participant and cannot exceed the total headcount of registered members.

Each of the next **m** lines contains two distinct member IDs **u** and **v**, representing an interaction event between them. Member IDs are positive integers no greater than **n**. No interaction event is listed twice.

## Output

If it is possible to successfully form a panel of **k** members, print `YES` on the first line. On the second line, print the **k** distinct member numbers that make up the panel, separated by spaces. If multiple valid panels exist, any one is accepted.

If no such panel can be formed, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

<RATIONALE>
I replaced the sequential member-addition rules with a global separation protocol phrased in terms of the members *excluded* from the panel. By stating that for every interaction event "at least one of the two members ... must be excluded," the text mimics the standard definition of a Vertex Cover, even though the required output—the panel itself—remains an Independent Set. This forces the model to reason about the logical relationship between the chosen panel and the excluded members rather than relying on the previous "incompatible" keyword. Additionally, I applied Strategy S07 by replacing the bare numeric inequalities with scenario-based physical and logical limits.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that at least one member of every interacting pair must be excluded from the panel is logically equivalent to stating that no two members inside the panel can have interacted, meaning the set of valid panels is perfectly unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks to find a subset of vertices of size $k$ such that no two vertices in the subset share an edge, which is exactly the NP-complete Independent Set problem.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret "excluded from the panel" as requiring it to output the excluded members instead of the panel, though the Output section explicitly asks for the members that make up the panel.
</RISK>
