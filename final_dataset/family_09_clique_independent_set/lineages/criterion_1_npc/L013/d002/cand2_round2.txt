# Problem A — Deep-Sea Sensor Deployment

Time limit: 5 s   Memory limit: 256 MB

## Description

An oceanographic research team has identified **n** potential deployment sites along a deep-sea trench, numbered 1 through **n**. The chief scientist needs to select exactly **k** distinct sites to activate acoustic sensors for a new study.

The underwater topography features **m** natural acoustic corridors. Each corridor directly links two specific deployment sites. If sensors are activated at both ends of the same corridor, their sonar pulses will enter a feedback loop and corrupt the localized data. 

A sensor activation plan is considered viable if and only if no acoustic corridor connects two activated sensors. If both sites linked by a corridor are chosen for activation, the deployment will fail.

Given the **n** deployment sites and the **m** acoustic corridors, determine whether it is possible to select exactly **k** sites for a viable activation plan. If a viable plan is possible, you must provide one valid selection of sites.

## Input

The first line of the input contains three integers **n**, **m**, and **k** (1 ≤ **n** ≤ 46, 0 ≤ **m** ≤ **n**·(**n**−1)/2, 1 ≤ **k** ≤ **n**).
The next **m** lines each contain two integers **u** and **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), representing the two deployment sites linked by an acoustic corridor.
The order of the two sites on a line does not matter, and no acoustic corridor is listed more than once.

## Output

If a viable activation plan of exactly **k** sensors can be configured, print `YES` on the first line. On the second line, print **k** distinct integers representing the site numbers to activate, separated by spaces. If there are multiple valid selections, any one will be accepted.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```
