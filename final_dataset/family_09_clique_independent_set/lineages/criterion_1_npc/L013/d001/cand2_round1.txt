# Problem A — Operational Payload Assembly

Time limit: 5 s   Memory limit: 256 MB

## Description

A software system consists of a set of available modules, numbered sequentially starting from 1. The system is powered by a multi-core processor array containing exactly 23 primary cores and 23 auxiliary cores. Each available module requires exclusive access to one core, meaning the total count of modules, **n**, will always be at least 1 and can never exceed the combined number of cores in the array.

During integration profiling, the system logs instances of concurrent memory corruption. The logs list specific pairs of modules that corrupt each other if both are initialized in the same run. The total number of such pairs, **m**, can be anywhere from zero up to the worst-case scenario where every possible pair of modules is logged.

Your objective is to assemble a deployment payload containing exactly **k** distinct modules, where **k** is a positive integer that cannot exceed the number of available modules. A payload is deemed operational if and only if it is entirely free of corruption: out of all the modules you select, no two may appear together as a pair in the corruption logs. 

Given the exact configuration of the modules and the corruption logs, determine whether an operational payload of exactly **k** modules can be successfully assembled. If such a payload can be formed, you must also provide one valid selection of modules.

## Input

The first line of the input contains three integers **n**, **m**, and **k**. Their respective minimum and maximum limits are strictly determined by the physical constraints and worst-case scenarios described above.

The next **m** lines each contain two integers **u** and **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), representing a pair of modules that corrupt each other. The corruption relationships are symmetric, and no pair is listed more than once.

## Output

If an operational deployment payload of exactly **k** modules can be assembled, print `YES` on the first line. On the second line, print **k** distinct integers representing the module numbers in the payload, separated by spaces. If there are multiple valid payloads, any one will be accepted.

If no such payload can be assembled, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```
