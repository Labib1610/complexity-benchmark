# Problem A — Decentralized Committee

Time limit: 5 s   Memory limit: 256 MB

## Description

A candidate pool consists of **n** individuals (numbered 1 to **n**). Within this pool, there are **m** direct, two-way private communication channels, each linking a specific pair of individuals.

Your task is to form a strictly decentralized committee of exactly **k** members. A committee is strictly decentralized if there is entirely zero internal communication—meaning no two members of the committee share a private channel between them. 

Given the target size **k**, determine whether such a committee can be formed from the pool. If it is possible, identify one valid combination of **k** members. Any valid combination of **k** members that meets this condition is accepted.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing a private communication channel between candidate **u** and candidate **v**. No channel is listed twice.

## Output

If a strictly decentralized committee of **k** members exists, print `YES` on the first line, then on the second line print **k** distinct candidate numbers forming such a committee, separated by spaces. Any committee in which no two members share a channel is accepted.

If no such committee exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

In Example 2, candidates 1, 3 and 5 share no private channels among them. In Example 1, it is impossible to select three candidates such that no two share a channel.
