<STATEMENT>
# Problem A — Decentralized Committee

Time limit: 5 s   Memory limit: 256 MB

## Description

A social network features $n$ users (numbered 1 to $n$) and $m$ bidirectional communication channels. Each channel links a distinct pair of users.

You are tasked with assembling a broadcast committee of exactly $k$ users. To prevent feedback loops, the committee must be strictly decentralized. This means that no communication channel can exist between any two users selected for the committee. Any subset of $k$ users satisfying this requirement is acceptable.

Given the network's configuration, determine if it is possible to form such a committee. If it is possible, report one valid selection.

## Input

The first line contains three integers: the number of users $n$, the number of channels $m$, and the target committee size $k$.
The number of users $n$ is at least 1. The maximum possible value for $n$ is determined by the system's capacity limit, which dictates that a fully connected network of $n$ users would contain at most 1035 channels.
The number of active channels $m$ is between 0 and the number of channels in a fully connected network of $n$ users.
The target committee size $k$ is between 1 and $n$.

Each of the next $m$ lines contains two distinct integers from 1 to $n$, identifying a pair of users linked by a channel. No channel is listed more than once.

## Output

If a valid committee of $k$ users exists, print `YES` on the first line, then on the second line print $k$ distinct user numbers forming such a committee, separated by spaces. Any committee satisfying the requirement is accepted.

If no such committee exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

In Example 2, users 1, 3, and 5 share no communication channels among them. In Example 1, it is impossible to find three users who are all mutually disconnected from each other.
