# Problem A — Zero Sum Assignment

Time limit: 5 s   Memory limit: 256 MB

## Description

You are investigating a discrete mathematical function $f(x_1, x_2, \dots, x_n)$ operating on binary variables, where every $x_i \in \{0, 1\}$.

The function is formulated as the sum of $m$ distinct terms. Every term consists of the product of two different variables, $x_u \cdot x_v$. (When $m=0$, there are no terms, meaning the function evaluates to $0$ unconditionally).

Your objective is to ascertain whether there is a configuration of the $n$ variables such that exactly $k$ of them are chosen to be $1$, and the total value of the function evaluates to exactly $0$.

## Input

The first line contains three integers $n$, $m$, and $k$ (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
Each of the subsequent $m$ lines provides two integers $u$ and $v$ (1 ≤ u, v ≤ n, u ≠ v), signifying that the product $x_u \cdot x_v$ is present as a term in the function. No product is repeated in the input.

## Output

If there is a configuration that satisfies the conditions, print `YES` on the first line. On the second line, print the $k$ distinct indices of the variables that must be set to $1$, separated by spaces. Should multiple such configurations exist, demonstrating any one of them is considered correct.

If no configuration satisfies the conditions, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```
