# Problem A — Zero Sum Assignment

Time limit: 5 s   Memory limit: 256 MB

## Description

You are evaluating a multivariate function $f(x_1, x_2, \dots, x_n)$ where the domain of each variable $x_i$ is restricted to $\{0, 1\}$.

The function is formulated as the sum of $m$ distinct terms. Each term consists of the product of two different variables, $x_u \cdot x_v$. (In the case where $m=0$, the function has no terms and evaluates to $0$ regardless of the input).

Your objective is to find if there is an input vector for the $n$ variables such that exactly $k$ variables are assigned the value $1$, and the total sum of the function equals exactly $0$.

## Input

The first line provides three integers $n$, $m$, and $k$ (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
The following $m$ lines each contain two integers $u$ and $v$ (1 ≤ u, v ≤ n, u ≠ v), denoting that the product $x_u \cdot x_v$ is present as a term in the function. No product is given more than once.

## Output

If a satisfying input vector exists, output `YES` on the first line. On the second line, output the $k$ distinct indices of the variables that are assigned $1$, separated by spaces. 

If no such input vector can be found, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```
