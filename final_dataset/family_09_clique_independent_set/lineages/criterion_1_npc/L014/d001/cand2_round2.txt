# Problem A — All-Strangers Group

Time limit: 5 s   Memory limit: 256 MB

## Description

A research study involves **n** participants (numbered 1 to **n**) and **m** records of prior interactions. Each record indicates that two specific participants have previously interacted.

To ensure unbiased results, the researchers need to form a control panel of exactly **k** participants such that no two participants in the panel have ever interacted with each other.

Given the interaction records and the required panel size **k**, determine if such a completely non-interacting panel can be formed. If so, provide one valid panel.

## Input

The first line contains three integers **n**, **m**, and **k**. The number of participants **n** is between 1 and the facility's strict capacity limit of 46. The number of interaction records **m** ranges from 0 up to the maximum possible number of unique pairs, **n**(**n**−1)/2. The target panel size **k** is between 1 and **n** inclusive.

Each of the next **m** lines contains two integers **u** and **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), representing an interaction between participant **u** and participant **v**. No interaction is listed twice.

## Output

If a non-interacting panel of exactly **k** participants exists, print `YES` on the first line. On the second line, print the **k** distinct participant numbers that form this panel, separated by spaces. Any valid panel where no two members have interacted is accepted.

If no such panel can be formed, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

<RATIONALE>
The problem was reframed from a social network to a research study selection to discourage simple pattern matching to graph independent set. The bounds are presented narratively as a "facility's strict capacity limit" rather than bare inequalities, satisfying the strategy while explicitly retaining the exact numbers to pass the gate's strict bounds check.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that no two participants have interacted is mathematically identical to the original all-strangers condition, ensuring any valid set of size k remains valid.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding an independent set of size k in an undirected graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "prior interactions" as directed edges, but the input specification clearly states they are between participant u and v and the description says "no two participants... have ever interacted with each other", implying an undirected relationship.
</RISK>
