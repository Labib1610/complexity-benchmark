# Problem A — Ionization Configuration

Time limit: 5 s   Memory limit: 256 MB

## Description

You are configuring an experimental particle trap containing **n** distinct magnetic nodes, identified by integers 1 through **n**. Your objective is to assign a positive polarity to exactly **k** of these nodes. The remaining nodes will automatically be assigned a negative polarity.

The trap's containment grid relies on **m** resonant links. Each resonant link couples exactly two specific nodes. To maintain equilibrium, every resonant link requires its net polarity to be zero or negative. The net polarity of a link is calculated by adding the polarities of its two coupled nodes, where a positive polarity evaluates to +1 and a negative polarity evaluates to -1. If the net polarity of any resonant link is strictly greater than zero, the trap will destabilize and fail.

You must determine whether it is possible to select exactly **k** nodes to receive a positive polarity such that no resonant link destabilizes. 

Given the layout of the resonant links, find a valid set of **k** positive nodes, or determine that no such set exists.

## Input

The first line provides three integers: **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
The following **m** lines each contain two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing a resonant link that couples node **u** and node **v**. No two resonant links couple the exact same pair of nodes.

## Output

If it is possible to safely assign positive polarity to exactly **k** nodes, output `YES` on the first line. On the second line, output the **k** distinct node identifiers that should be selected for positive polarity, separated by spaces. If multiple valid configurations exist, any one is acceptable.

If no safe configuration of exactly **k** positive nodes is possible, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```

```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```

1 3
```

**Output**
```
YES
1
```

The models were recognizing the phrase "workload must never exceed standard mode" as a direct translation of the independent set constraint (since each link has 2 nodes, this means at most 1 workload node). To break this pattern matching, the constraint is rewritten as a physical sum of polarities (+1 and -1) that must be zero or negative. The model must now mentally evaluate the truth table of the sum to realize that the only invalid state is (+1, +1), requiring an extra step of algebraic reasoning before the independent set structure becomes apparent. Explicit bounds were restored to satisfy the strict gate checks.

The condition "sum of polarities (+1 and -1) <= 0" for two nodes precisely rejects the (+1, +1) state while allowing (+1, -1) and (-1, -1), which is mathematically identical to the seed's requirement that at most one node in a pair can be selected.
</PRESERVED_ANSWER>
