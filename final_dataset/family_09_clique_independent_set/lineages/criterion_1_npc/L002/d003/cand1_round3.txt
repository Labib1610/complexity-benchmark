# Problem A — Synthetic Genome Configuration

Time limit: 5 s   Memory limit: 256 MB

## Description

You are designing a synthetic organism that has **n** engineered traits, identified by integers 1 through **n**. Your goal is to determine whether it is possible to activate exactly **k** of these traits in a single organism while maintaining genetic stability.

The genetic structure includes **m** biochemical links. Each link binds exactly two specific traits together. Because activating traits introduces genetic instability, every link requires that the number of its connected traits that are activated must never exceed the number of its connected traits that remain dormant. If this balance rule is violated for any link, the organism will fail to synthesize. 

You must determine whether there exists a set of exactly **k** traits that can be activated while satisfying the balance rule for all links. Given the layout of the biochemical links, find a valid set of **k** traits, or determine that no such set exists.

## Input

The first line provides three integers: **n**, **m**, and **k**. 
- The total number of traits, **n**, is a positive integer no greater than the typical number of chromosomes in a human diploid cell (46).
- The number of links, **m**, is a non-negative integer that will not exceed the maximum possible number of distinct pairs that can be formed from the traits.
- The target number of traits to activate, **k**, is between 1 and **n**, inclusive.

The following **m** lines each contain two integers **u** and **v** (between 1 and **n**, where **u** is not equal to **v**), representing a link that binds trait **u** and trait **v**. No link between the same unordered pair of traits is listed more than once.

## Output

If it is possible to safely activate exactly **k** traits, output `YES` on the first line. On the second line, output the **k** distinct trait identifiers that should be activated, separated by spaces. If multiple valid configurations exist, any one is acceptable.

If no safe allocation of exactly **k** traits is possible, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```
