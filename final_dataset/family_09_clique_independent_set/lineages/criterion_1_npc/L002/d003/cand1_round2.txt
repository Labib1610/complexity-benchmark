# Problem A — Synthetic Genome Activation

Time limit: 5 s   Memory limit: 256 MB

## Description

You are engineering a synthetic plant genome containing **n** candidate traits, identified by integers 1 through **n**. Your objective is to activate exactly **k** of these traits to maximize agricultural yield.

The genome contains **m** epistatic links. Each link physically binds exactly two distinct traits. Activating traits places a metabolic burden on these links. Specifically, each link computes its metabolic load based purely on the two traits it binds: it adds 1 to its load for each of these two traits that is activated, and subtracts 1 for each of the two that remains unactivated (not selected). (For example, if one of its bound traits is activated and the other is unactivated, the link's load is +1 - 1 = 0).

For the genome to be viable, the metabolic load on every individual link must be less than or equal to 0. If even one link has a strictly positive metabolic load, the cell will fail to divide.

You must determine whether it is possible to select exactly **k** traits for activation such that the genome remains viable.

Given the configuration of the epistatic links, find a valid set of **k** traits, or determine that no such set exists.

## Input

The first line provides three integers: **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
The following **m** lines each contain two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing an epistatic link that binds trait **u** and trait **v**. No two links bind the exact same pair of traits.

## Output

If it is possible to safely activate exactly **k** traits, output `YES` on the first line. On the second line, output the **k** distinct trait identifiers that should be selected, separated by spaces. If multiple valid configurations exist, any one is acceptable.

If no safe selection of exactly **k** traits is possible, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

I changed the framing from power allocation and transformers to synthetic genomics and epistatic links. The independent set constraint, originally stated as comparing counts of selected vs unselected nodes per edge, is now formulated algebraically: each edge assigns a +1 penalty for a selected node and -1 for an unselected node, and the sum must be $\le 0$. This forces the model to algebraically deduce that at most one node per edge can be selected, preventing simple keyword matching to independent set.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic condition (+1 for activated, -1 for unactivated per edge) requires that for each edge, the sum is $\le 0$, which is only violated if both endpoints are activated (+2), making it exactly equivalent to the seed's independent set constraint.
</PRESERVED_ANSWER>
