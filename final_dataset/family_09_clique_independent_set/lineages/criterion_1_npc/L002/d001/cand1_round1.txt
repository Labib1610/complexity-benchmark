# Problem A — Focus Group Selection

Time limit: 5 s   Memory limit: 256 MB

## Description

A market research agency is executing a multi-phase campaign to evaluate a new product. The campaign proceeds as follows:

**Phase 1: Conflict Logging.** The agency surveys a pool of candidates and compiles a list of interference pairs. Each pair indicates that two specific candidates would bias each other's opinions if they were both selected.

**Phase 2: Pure Selection (Your Task).** The agency must isolate a subset of candidates. To guarantee uninfluenced feedback, the chosen subset must be completely free of interference. For any two candidates included in the final subset, they must not appear together as an interference pair in the Phase 1 logs. The final subset must contain exactly the required headcount.

**Phase 3: Deployment.** The chosen candidates are shipped the prototype, and their isolated reviews are synthesized into a final report.

You are responsible for implementing Phase 2. Given the interference logs and the target headcount, determine if a valid subset can be formed, and if so, identify the candidates to be passed to Phase 3.

## Input

The testing facility guarantees at least one candidate is surveyed, but its physical capacity limits the pool to a maximum of 46 candidates. The target headcount requires at least one participant and cannot exceed the total number of surveyed candidates. The number of interference pairs can range from none at all, up to every possible pair of candidates interfering with each other.

The first line of the input provides three integers: the number of surveyed candidates, the number of recorded interference pairs, and the target headcount. 

This is followed by a line for each interference pair, containing the two integer IDs of the candidates involved. Candidate IDs are assigned sequentially starting from 1 up to the total number of surveyed candidates. A candidate cannot interfere with themselves, and no duplicate pairs are listed.

## Output

If it is possible to form the required subset, output `YES` on the first line. On the second line, output the distinct candidate IDs that make up the subset, separated by spaces. If multiple valid subsets exist, any one is acceptable.

If no such subset of exactly the required headcount can be formed, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

```

```

### Example 3

**Input**


**Output**
```

1
```
