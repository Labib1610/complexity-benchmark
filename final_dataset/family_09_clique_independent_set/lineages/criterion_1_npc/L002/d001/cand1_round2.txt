# Problem A — Module Activation

Time limit: 5 s   Memory limit: 256 MB

## Description

You are configuring a control board that supports a total of **n** available modules, identified by integers starting from 1 up to **n**.

A system scan has generated **m** diagnostic logs. Each log lists exactly two modules that draw power from the same unregulated bus. If two modules share a bus, they cannot both be activated simultaneously without causing voltage drops.

Your task is to activate exactly **k** modules. To maintain system stability, the set of activated modules must be completely free of shared buses. That is, for any two modules you choose to activate, their identifiers must never appear together in any single diagnostic log.

Given the diagnostic logs and the target number of modules **k**, determine if such a configuration is possible, and if so, list the modules to activate.

## Input

The first line contains three integers: **n**, **m**, and **k**. The physical capacity of the board dictates that **n** is between 1 and 46, inclusive. The number of diagnostic logs **m** can be as low as 0 and as high as **n**·(**n**−1)/2. The target activation count **k** is between 1 and **n**, inclusive.

This is followed by **m** lines, each containing two integers **u** and **v**. These represent a diagnostic log between two modules. The module identifiers **u** and **v** are always between 1 and **n**, inclusive, and they refer to distinct modules (**u** is not equal to **v**). No specific pair of modules is logged more than once.

## Output

If it is possible to activate exactly **k** modules under these conditions, print `YES` on the first line. On the second line, print the **k** distinct module identifiers that should be activated, separated by spaces. If there are multiple valid sets of **k** modules, any one of them will be accepted.

If no such set of exactly **k** modules can be found, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```
