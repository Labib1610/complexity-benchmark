# Problem A — Data Center Workload Allocation

Time limit: 5 s   Memory limit: 256 MB

## Description

You are configuring a data center that contains **n** servers, identified by integers 1 through **n**. Your objective is to designate exactly **k** of these servers to run a new high-intensity workload.

The facility's power infrastructure includes **m** specialized transformers. Each transformer is wired to supply power to exactly two specific servers. Because the new workload draws a massive amount of current, every transformer requires that the number of its connected servers designated for the high-intensity workload must never exceed the number of its connected servers that remain in standard mode (i.e., not designated for the workload). If this balance rule is violated, the transformer will overload and fail.

You must determine whether it is possible to select exactly **k** servers such that no transformer is overloaded. 

Given the wiring layout of the transformers, find a valid set of **k** servers, or determine that no such set exists.

## Input

The first line provides three integers: **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
The following **m** lines each contain two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing a transformer that is wired to server **u** and server **v**. No two transformers are wired to the exact same pair of servers.

## Output

If it is possible to safely allocate the workload to exactly **k** servers, output `YES` on the first line. On the second line, output the **k** distinct server identifiers that should be selected, separated by spaces. If multiple valid configurations exist, any one is acceptable.

If no safe allocation of exactly **k** servers is possible, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```
</STATEMENT>
<RATIONALE>
Replaced the direct "at most one" and "not both" phrasing with a load-balancing rule requiring the count of designated servers on a transformer to not exceed the count of standard servers on it. This forces the model to algebraically deduce that the constraint implies a maximum of one designated server per transformer, preventing keyword-based pattern matching to Independent Set algorithms while keeping the scenario identical.
</RATIONALE>
<PRESERVED_ANSWER>
The new load-balancing rule on exactly two connected servers evaluates to true if and only if 0 or 1 of them are designated (since 1 ≤ 1 and 0 ≤ 2, but 2 ≰ 0), which is logically identical to the original "at most one" constraint, meaning all valid configurations remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Independent Set problem on a graph with n vertices and m edges, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might find the phrase "number of its connected servers that remain in standard mode" slightly wordy, but it is unambiguous since a transformer only connects to exactly two servers, each of which must be in one of the two mutually exclusive modes.
</RISK>
