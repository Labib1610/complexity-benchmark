<STATEMENT>
# Problem A — Data Center Workload Allocation

Time limit: 5 s   Memory limit: 256 MB

## Description

You are configuring a data center that contains **n** servers, identified by integers 1 through **n**. Your objective is to designate exactly **k** of these servers to run a new high-intensity workload.

The facility's power infrastructure includes **m** specialized transformers. Each transformer is wired to supply power to exactly two specific servers. Because the new workload draws a massive amount of current, running it simultaneously on both servers connected to the same transformer will cause that transformer to overload and fail. 

To maintain facility stability, you must guarantee that for every transformer in the layout, the two servers it connects to are not both included in your chosen group of **k** servers. You must determine whether it is possible to select exactly **k** servers such that this safety condition is met.

Given the wiring layout of the transformers, find a valid set of **k** servers, or determine that no such set exists.

## Input

The first line provides three integers: **n**, **m**, and **k**. The facility's maximum rack capacity dictates that **n** is at most 46, and at least 1. The transformer count **m** ranges from a minimum of 0 up to a fully wired limit of n(n−1)/2. The targeted number of servers **k** is at least 1 and at most **n**.

The following **m** lines each contain two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing a transformer that is wired to server **u** and server **v**. No two transformers are wired to the exact same pair of servers.

## Output

If it is possible to safely allocate the workload to exactly **k** servers, output `YES` on the first line. On the second line, output the **k** distinct server identifiers that should be selected, separated by spaces. If multiple valid configurations exist, any one is acceptable.

If no safe allocation of exactly **k** servers is possible, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```

```

**Output**
```
YES

```

### Example 3

**Input**
```

1 2

```

**Output**
```
YES
1
```

<RATIONALE>
The primary affordance "at most one server running the high-intensity workload" strongly mapped to standard independent set and vertex cover definitions. This was replaced with the logically equivalent condition that "the two servers it connects to are not both included," forcing models to derive the independent set structure from the negative pairwise constraint rather than matching a known template phrase. The bounds were also rewritten using strategy S07 to be expressed via physical limits while retaining the exact digits to pass strict constraint-checking gates.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that no transformer has both of its wired servers in the chosen group is logically identical to the seed's rule that at most one server per transformer can be chosen, ensuring every valid server selection remains exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Independent Set problem on a graph with $n$ vertices and $m$ edges, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models could misinterpret "not both included" as requiring exactly one to be included (an exact cover), though standard logic dictates "not both" means zero or one, which is unambiguous to a careful reader.
</RISK>
