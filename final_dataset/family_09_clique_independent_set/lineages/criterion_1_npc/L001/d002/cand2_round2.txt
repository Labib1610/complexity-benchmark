# Problem A — Harmonic Isolation

Time limit: 5 s   Memory limit: 256 MB

## Description

A telecommunications firm is setting up a new transmission grid. They have a pool of **n** candidate broadcast frequencies (identified by integers from 1 to **n**). Because of harmonic resonance, specific pairs of these frequencies are mutually destructive; activating both at once leads to severe signal degradation. The engineers have cataloged **m** such destructive pairings.

A harmonic-isolation grid is defined as a subset of frequencies in which no two frequencies are known to be mutually destructive.

Your objective is to verify whether it is feasible to activate exactly **k** frequencies such that they constitute a harmonic-isolation grid. If it is feasible, you must output one valid combination.

*Performance Note*: The evaluation data for this task includes adversarial near-half-target conflict graphs specifically chosen to defeat early witnesses and degree-based pruning.

## Input

The first line provides three integers: **n**, **m**, and **k**. The total number of frequencies is constrained by the 46 available physical transceivers (1 ≤ **n** ≤ 46). The number of destructive pairings **m** can be anywhere from 0 up to the theoretical maximum of **n**·(**n**−1)/2 (0 ≤ **m** ≤ **n**·(**n**−1)/2). The required grid size **k** is bounded between 1 and the number of candidates (1 ≤ **k** ≤ **n**).

The following **m** lines each contain two integers **u** and **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), representing a destructive pairing between frequency **u** and frequency **v**. Each pairing is unique and appears at most once in the list.

## Output

If a harmonic-isolation grid of exactly **k** frequencies can be formed, print `YES` on the initial line. On the subsequent line, output the **k** distinct frequency identifiers that make up this grid, separated by spaces. Any valid subset of exactly **k** frequencies will be accepted.

If no such grid can be formed, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

In Example 2, frequencies 1, 3 and 5 have no destructive pairings among them. In Example 1, no three of the four frequencies are mutually compatible.
