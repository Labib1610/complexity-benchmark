# Problem A — Resonant Chamber Isolation

Time limit: 5 s   Memory limit: 256 MB

## Description

An acoustic testing facility operates a network of **n** resonant chambers (identified by integers starting from 1 up to **n**). The facility has mapped out **m** structural ducts. Each duct connects a pair of chambers. If two chambers share a duct, their acoustic frequencies cross-contaminate.

A subset of chambers is considered **perfectly isolated** if no two chambers in that subset are joined by a structural duct.

Given a target quantity **k**, determine whether there exists a perfectly isolated subset of exactly **k** chambers. If such a subset exists, report one.

## Input

The first line contains three integers **n**, **m**, and **k**. The total chamber count **n** requires at least 1 chamber and is bounded by a hardware limit of 46. The duct count **m** ranges from an absolute minimum of 0 up to the theoretical limit of every chamber being pairwise connected (n(n-1)/2). The target subset size **k** is at least 1 and cannot exceed **n**.

Each of the subsequent **m** lines provides two integers **u** and **v** representing a duct between those two chambers. The values **u** and **v** are valid chamber identifiers from 1 up to **n**, and they are never identical (**u** ≠ **v**). No duplicate ducts are provided.

## Output

If a perfectly isolated subset of exactly **k** chambers can be found, output `YES` on the first line. On the second line, output **k** distinct chamber identifiers that make up such a subset, separated by spaces. 

If no such subset can be formed, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

In Example 2, chambers 1, 3 and 5 share no structural ducts among them. In Example 1, no three of the four chambers are mutually free of ducts.
