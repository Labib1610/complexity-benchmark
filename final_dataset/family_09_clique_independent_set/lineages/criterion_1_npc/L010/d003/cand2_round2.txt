<STATEMENT>
# Problem A — Module Configuration Constraints

Time limit: 5 s   Memory limit: 256 MB

## Description

A software system consists of **n** modules (labeled 1 to **n**). You are evaluating the system for a specific deployment that requires activating exactly **k** modules.

The modules interact with a set of **m** distinct shared memory banks. Each memory bank is accessible by exactly two specific modules.

A deployment is considered safe if no memory bank is accessed by multiple active modules simultaneously. Because each bank is only accessible by its two assigned modules, this requirement means that for every one of the **m** memory banks, it is strictly forbidden to activate both of the modules that have access to it. 

Determine if there is a safe deployment of exactly **k** modules. If such a deployment is possible, you must identify one valid set of modules to activate.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ **n** ≤ 46, 0 ≤ **m** ≤ **n**·(**n**−1)/2, 1 ≤ **k** ≤ **n**).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), representing a shared memory bank accessible by module **u** and module **v**. No memory bank is listed more than once.

## Output

If a safe deployment of exactly **k** modules can be formed, output `YES` on the first line. On the second line, output the **k** distinct module labels that make up this deployment, separated by spaces. If multiple valid deployments exist, print any one of them (in any order).

If no such deployment can be formed, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

In Example 2, checking the constraints shows that activating modules 1, 3, and 5 is safe because no memory bank is accessed by both of its assigned modules (the bank for 1 and 2 only sees module 1 active, and the bank for 3 and 4 only sees module 3 active). In Example 1, any selection of three modules will include both modules for at least one memory bank, meaning no safe deployment of size 3 exists.
</STATEMENT>
<RATIONALE>
The explicit set-inclusion language ("your chosen set... must include at most one") was replaced with a resource-conflict description ("strictly forbidden to activate both"). This removes the direct pattern-matching affordance for an Independent Set formulation while maintaining an exact, unambiguous logical condition that prevents semantic over-modeling.
</RATIONALE>
<PRESERVED_ANSWER>
The condition "forbidden to activate both" is logically identical to "at most one of the two", meaning the valid sets of modules are exactly the same as in the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a set of size k with no internal edges, which is the exact definition of the NP-complete Independent Set problem.
</PRESERVED_CLASS>
