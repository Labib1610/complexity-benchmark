<STATEMENT>
# Problem A — Stable Formulation

Time limit: 5 s   Memory limit: 256 MB

## Description

A laboratory tests $n$ distinct chemical compounds (labeled 1 to $n$). A stable formulation must include exactly $k$ of these compounds. Due to chemical reactivity, certain pairs of compounds will neutralize each other if both are present in the same formulation. There are $m$ such neutralizing pairs.

A valid formulation is formed by gathering exactly $k$ compounds such that no neutralizing pair is present among them. You need to determine if a valid formulation exists, and if so, identify its compounds.

## Input

The first line contains three integers $n$, $m$, and $k$. The number of compounds $n$ is constrained by the facility's 46 storage bays, with at least one compound always present. The count of neutralizing pairs $m$ ranges from zero up to the maximum possible number of distinct two-compound combinations that can be formed from $n$ items. The desired formulation size $k$ is strictly positive and cannot exceed the total number of compounds $n$.

Each of the next $m$ lines contains two integers $u$ and $v$. Both values point to valid compound labels (from 1 to $n$) and are never equal to each other, indicating that these two compounds neutralize each other. The input guarantees that no pair is duplicated.

## Output

If a valid formulation of exactly $k$ compounds can be created, output `YES` on the first line. On the second line, output the $k$ distinct compound labels in the formulation, separated by spaces. If multiple valid formulations exist, output any of them (in any order).

If no such formulation can be created, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

In Example 2, compounds 1, 3, and 5 do not neutralize one another. In Example 1, it is impossible to find three compounds that are completely free of neutralizing interactions.
