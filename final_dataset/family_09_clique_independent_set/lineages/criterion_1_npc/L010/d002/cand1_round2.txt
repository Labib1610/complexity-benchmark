# Problem A — Isolated Monitoring Array

Time limit: 5 s   Memory limit: 256 MB

## Description

A facility operates **n** monitoring devices (labeled 1 to **n**). Certain pairs of devices exhibit mutual interference, meaning they are incompatible. We are given **m** such interfering pairs. If both devices from an interfering pair are activated together, they disrupt each other.

To ensure safe operation, a selection of devices is considered stable if and only if it never includes both endpoints of any mutual interference.

You are given a target selection size **k**. Determine if there is a stable selection containing exactly **k** devices. If such a selection can be formed, you must identify one valid combination of **k** devices.

## Input

The first line contains three integers **n**, **m**, and **k**. The total device count **n** is bounded by the facility's physical slot limit of 46, and there is always at least 1 device present. The interference count **m** can be as low as 0 and reaches up to the theoretical maximum of n·(n−1)/2. The required selection size **k** is at least 1 and cannot exceed **n**.

Each of the next **m** lines contains two integers **u** and **v**, representing an interfering pair. The values **u** and **v** are valid device labels ranging from 1 to **n** inclusive, and they refer to distinct devices (**u** ≠ **v**). No interfering pair is listed more than once.

## Output

If a stable selection of exactly **k** devices can be formed, output `YES` on the first line. On the second line, output the **k** distinct device labels that make up this selection, separated by spaces. If multiple valid selections exist, print any one of them (in any order).

If no such selection can be formed, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

<RATIONALE>
The description was rewritten to remove the textbook definition of an independent set ("a set of devices where no listed conflict exists between any two chosen"). Instead, the problem defines a stable selection mechanically: it "never includes both endpoints of any mutual interference." The numeric bounds were integrated directly into prose describing facility limits and theoretical minimums/maximums to satisfy the strategy while preserving exact, machine-readable numbers to pass the gate.
</RATIONALE>
<PRESERVED_ANSWER>
The condition of never including both endpoints of an interference pair is mathematically identical to selecting an independent set of size k, so the valid outputs for any given input remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem asks for an independent set of size k in an undirected graph, which is the canonical NP-complete Independent Set problem.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "never includes both endpoints" as allowing one endpoint and thus failing to recognize that it's a standard edge-avoidance condition, but competent readers will understand this correctly.
</RISK>
