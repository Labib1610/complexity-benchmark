**Solution Explanation**

The problem asks for an *exact cover* of the set `{1,…,3q}` by some of the given triples.
An exact cover is a collection of triples such that every number appears in
exactly one chosen triple.

The classic algorithm for exact cover is **Algorithm X** (Donald Knuth) together
with the **Dancing Links** data structure.  
With at most `3·200 = 600` columns and `20000` rows the dancing‑links
implementation easily fits into the limits.

The algorithm works as follows

```
search():
    if no column left → all numbers are covered → success
    choose column c with the smallest number of rows (heuristic)
    for each row r that contains c:
        add r to the partial solution
        cover all columns of r (remove them and all rows that intersect them)
        if search() succeeds → propagate success
        uncover the columns again (backtrack)
    return failure
```

Cover / uncover are `O(number of 1‑entries removed)` and are implemented by
manipulating four doubly linked lists (`U,D,L,R`) – the “dancing links”.

If a solution is found we output the triples belonging to the selected rows,
otherwise `NO`.

The implementation details:

* **Columns** – one for each operator `1 … 3q`.  
  Header node `head` links all column headers in a circular list.
* **Rows** – one node per occurrence of a column in a triple.
* Each column header stores `size` – the current number of rows still containing it.
* The recursive search stops as soon as a solution is found.

The algorithm is exponential in the worst case (exact cover is NP‑complete) but
with the given limits it runs comfortably fast.

---

**Correctness Proof**

We prove that the algorithm prints `YES` and a valid deployment plan
iff such a plan exists.

*Lemma 1*  
During execution, the set of uncovered columns is exactly the set of operators
that are not yet assigned to a chosen triple.

*Proof.*  
Initially all columns are uncovered, i.e. no operator is assigned.  
When a row (triple) `r` is chosen, `cover(r)` removes every column `c` that
appears in `r` and also removes all rows that contain any of those columns.
Thus the operators of `r` become assigned and are no longer present among the
uncovered columns.  
`uncover(r)` restores exactly those columns and rows, undoing the assignment.
∎



*Lemma 2*  
At any recursive call, the partial solution (the set of rows already chosen)
covers each operator at most once.

*Proof.*  
By Lemma&nbsp;1 an operator is uncovered exactly while it is unassigned.
`cover(r)` removes all columns of `r`; therefore no later chosen row can contain
any of those columns because such rows have been removed from the structure.
Thus no operator can be covered twice. ∎



*Lemma 3*  
If the algorithm reaches the line “no column left”, the current set of chosen
rows forms a valid deployment plan.

*Proof.*  
“No column left” means every column has been covered, i.e. every operator is
assigned to some chosen triple (Lemma&nbsp;1).  
By Lemma&nbsp;2 each operator appears in at most one chosen triple.
Since each triple contains exactly three distinct operators, the total number
of chosen triples is `3q / 3 = q`. Hence the chosen triples partition the whole
roster – a valid plan. ∎



*Lemma 4*  
If a valid deployment plan exists, the algorithm will eventually find one.

*Proof.*  
Consider any valid plan `P`. At the root call all columns are present.
The algorithm tries every row that contains the column with minimal size.
Since `P` covers every column, in particular it contains some row `r` that
covers that column. Hence `r` is among the tried rows.
When `r` is selected, the recursive call works on the reduced exact‑cover
instance consisting of the remaining columns and rows that are compatible with
`r`. The restriction of `P` to those remaining columns is again a valid plan
for the sub‑instance. By induction on the number of remaining columns the
recursive call will eventually select exactly those rows, reaching the success
state. ∎



*Lemma 5*  
If the algorithm outputs `NO`, no valid deployment plan exists.

*Proof.*  
`NO` is printed only after the recursive search exhausts all possibilities
without reaching the “no column left” state. The search explores **all**
possible subsets of rows that could cover the columns, because for each column
it tries every row containing it and recurses on the exact remaining instance.
If none leads to a state where all columns are covered, no subset of rows can
cover every column exactly once, i.e. no valid plan exists. ∎



*Theorem*  
The program prints `YES` followed by a correct deployment plan
iff such a plan exists; otherwise it prints `NO`.

*Proof.*  
*If* part: By Lemma 3 any solution found by the algorithm is a valid plan, and
the program prints it with `YES`.  
*Only‑if* part: By Lemma 4 a valid plan guarantees that the search will find
one, thus the program will not output `NO`. Conversely, by Lemma 5, when the
program outputs `NO` no plan exists. ∎



---

**Complexity Analysis**

Let `n = 3q ≤ 600` (columns) and `m = t ≤ 20000` (rows).

*Construction* – O(total number of 1‑entries) = `3·m` ≤ 60000.

*Search* – In the worst case exponential, but each covering/uncovering step
touches only the nodes of the involved rows, i.e. `O(3·degree)`.  
Empirically for the given limits the recursion depth is at most `q = 200`,
and the total number of visited nodes stays well below the time limit.

Memory consumption: one node per 1‑entry plus column headers:
`O(3·m + n) ≤ 60000 + 600` nodes, each storing four integers → well under 256 MB.

**Reference Implementation (Python 3)**

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    triples = []
    for _ in range(t):
        a = int(next(it)); b = int(next(it)); c = int(next(it))
        triples.append((a, b, c))

    n = 3 * q                     # number of columns
    # Dancing Links structures
    # node 0 is the header
    size = [0] * (n + 1)          # column sizes, index 1..n
    U = [0] * (3 * t + n + 1)
    D = [0] * (3 * t + n + 1)
    L = [0] * (3 * t + n + 1)
    R = [0] * (3 * t + n + 1)
    C = [0] * (3 * t + n + 1)     # column of each node
    row_id = [0] * (3 * t + n + 1)

    # header links columns in a circular list
    head = 0
    for i in range(n + 1):
        U[i] = D[i] = i
        L[i] = i - 1
        R[i] = i + 1
    L[0] = n
    R[n] = 0

    node_cnt = n
    # add rows
    for rid, (a, b, c) in enumerate(triples, 1):
        first = None
        for col in (a, b, c):
            node_cnt += 1
            C[node_cnt] = col
            row_id[node_cnt] = rid
            # insert into column list (at bottom)
            D[node_cnt] = col
            U[node_cnt] = U[col]
            D[U[col]] = node_cnt
            U[col] = node_cnt
            size[col] += 1
            # link row horizontally
            if first is None:
                first = node_cnt
                L[node_cnt] = R[node_cnt] = node_cnt
            else:
                # insert to the right of first
                L[node_cnt] = L[first]
                R[node_cnt] = first
                R[L[first]] = node_cnt
                L[first] = node_cnt

    solution_rows = []

    def cover(col):
        # remove column header
        R[L[col]] = R[col]
        L[R[col]] = L[col]
        # remove rows
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                size[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col):
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                size[C[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        R[L[col]] = col
        L[R[col]] = col

    def search(k):
        if R[head] == head:   # all columns covered
            return True
        # choose column with minimal size
        c = R[head]
        min_sz = size[c]
        col = c
        j = R[c]
        while j != head:
            if size[j] < min_sz:
                min_sz = size[j]
                col = j
                if min_sz == 0:
                    break
            j = R[j]
        if min_sz == 0:
            return False
        cover(col)
        r = D[col]
        while r != col:
            solution_rows.append(row_id[r])
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            if search(k + 1):
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            solution_rows.pop()
            r = D[r]
        uncover(col)
        return False

    ok = search(0)
    out = []
    if ok:
        out.append("YES")
        # retrieve triples in order of solution_rows
        chosen = [triples[i - 1] for i in solution_rows]
        for a, b, c in chosen:
            out.append(f"{a} {b} {c}")
    else:
        out.append("NO")
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
