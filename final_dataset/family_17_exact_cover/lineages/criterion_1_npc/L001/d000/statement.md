# Logistics Provisioning Phase: Unit Assignment

Time limit: 5 s
Memory limit: 256 MB

## Description
The regional readiness exercise involves a multiphase pipeline. In the preliminary phase, an automated system analyzes years of mission logs to identify effective working relationships among the personnel. The roster consists of individuals assigned sequential ID numbers starting from 1. The preliminary system outputs a compatibility database containing specific combinations of three individuals who are authorized to deploy together.

Your module handles the second phase: unit assignment. You will receive the target number of units to form and the compatibility database generated by the preliminary phase. To comply with the strict parameters of the exercise, you must select a subset of the authorized combinations such that every single person on the roster is assigned. Because an individual cannot be physically present in multiple places, no person can appear in more than one of your chosen combinations. The total number of personnel on the roster is always exactly three times the target number of units.

Once your module outputs a valid assignment, the pipeline proceeds to the logistics phase, where gear is provisioned for each formed unit and they are dispatched to their designated zones. If the database does not allow for an assignment that includes everyone exactly once, your module must flag this so the exercise parameters can be adjusted by human coordinators.

## Input
The first line provides two integers **q** and **t** (1 ≤ q ≤ 200, 0 ≤ t ≤ 20000). Here, **q** represents the required number of units, implying a total roster of 3q personnel (numbered 1 through 3q). **t** is the number of authorized combinations in the database.

Following this, there are **t** lines representing the database. Each line contains three integers a, b, and c (1 ≤ a < b < c ≤ 3q), specifying the IDs of three individuals who may form a unit.

## Output
If a valid assignment can be formed, print `YES` on the first line. Then, print **q** lines, each containing the three IDs of the individuals in one of the selected units. 
If it is impossible to assign everyone exactly once using the provided combinations, print `NO`.

## Examples
### Example 1
Input:
```
2 3
1 2 3
4 5 6
1 4 5
```
Output:
```
YES
1 2 3
4 5 6
```
