**Solution Explanation**

The problem asks for an *exact cover* of the set `{1,…,3q}` by `q` triples taken from a given list.
Exactly one chosen triple must contain each element, and the number of chosen triples must be `q`.
This is the classic *exact cover* problem, solvable with Donald Knuth’s
**Algorithm X** together with the **Dancing Links** data structure (DLX).

The constraints are small enough for DLX:

* columns (elements) ≤ 600
* rows (triples)   ≤ 20 000
* required solution size `q` ≤ 200  

DLX runs in exponential time in the worst case, but for these limits it easily fits
into the 5 s time limit.

--------------------------------------------------------------------

#### 1.   DLX data structure

We build a sparse binary matrix:

* one column for each element `1 … 3q`
* one row for each allowed triple `{a,b,c}` – the row has a `1` in the three columns
  `a, b, c`.

DLX stores the matrix as a toroidal doubly‑linked list.
Each node knows its left/right/up/down neighbours and the column header it belongs to.
Column headers also store the current number of nodes (`size`) in the column.

Operations needed:

* **cover(col)** – removes a column and all rows that contain a `1` in this column
  from the structure.
* **uncover(col)** – restores everything removed by the last `cover`.

Both run in `O(number of removed nodes)`.

--------------------------------------------------------------------

#### 2.   Algorithm X (recursive search)

```
search():
    if no columns left → all elements are covered → success
    choose column c with smallest size   (heuristic)
    cover(c)
    for each row r in column c:
        add r to partial solution
        for each node j in row r (except the column node):
            cover(j.column)
        if search() succeeds → propagate success
        for each node j in row r (reverse order):
            uncover(j.column)
        remove r from partial solution
    uncover(c)
    return failure
```

Because each row contains exactly three `1`s, the recursion depth never exceeds `q`
(≤ 200).

--------------------------------------------------------------------

#### 3.   Building the matrix

* Create `3q` column headers, linked together.
* For each input triple `(a,b,c)` create three nodes, link them horizontally,
  and insert each into the bottom of its column (up‑down links).

If a column becomes empty (`size == 0`) before the search starts, the answer is
immediately `NO`.

--------------------------------------------------------------------

#### 4.   Output

When the recursive search finds a solution, we have stored the selected rows.
Each row knows the three element numbers (kept while creating the nodes), so we
print them in any order.

If the search finishes without success we output `NO`.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints `YES` and a valid assignment iff such an
assignment exists.

---

##### Lemma 1  
During execution, the set of uncovered columns is exactly the set of elements
that are not yet covered by the rows stored in the current partial solution.

**Proof.**  
Initially no rows are chosen, all columns are uncovered – property holds.
When a row `r` is added, `cover` is called for each column containing a `1` in `r`.
`cover` removes that column and all rows that intersect it, i.e. it marks the
corresponding element as covered and forbids any later row that would reuse it.
Thus after processing `r` the uncovered columns are precisely the elements not
yet covered. The reverse operation `uncover` restores the previous state,
maintaining the invariant. ∎



##### Lemma 2  
`search` returns success **iff** the current set of uncovered columns can be
exactly covered by a set of rows extending the current partial solution.

**Proof.**  
*If part*: When `search` reaches the base case (no columns left) Lemma&nbsp;1 tells
that every element is covered, therefore the current partial solution is a
complete exact cover – success is returned.

*Only‑if part*: Assume an exact cover extending the current partial solution
exists. Let `c` be the column chosen by the heuristic. In any exact cover,
some row `r` containing `c` must be selected. The algorithm iterates over **all**
rows `r` in column `c`. For the particular `r` belonging to the existing exact
cover, after covering the other two columns of `r` the remaining uncovered
columns are exactly those that still need to be covered. By the induction
hypothesis the recursive call will succeed, therefore `search` returns success.
∎



##### Lemma 3  
If the algorithm outputs `YES` and the printed triples, those triples form a
valid assignment (each person appears exactly once).

**Proof.**  
`YES` is printed only after `search` succeeded. At that moment the recursion
ended with no uncovered columns. By Lemma&nbsp;1 all elements are covered, and
by construction each chosen row is a triple from the input. Because a column is
covered only once, no element appears in two chosen rows. Hence the printed
triples satisfy all requirements. ∎



##### Lemma 4  
If a valid assignment exists, the algorithm outputs `YES`.

**Proof.**  
Assume a valid assignment `S` exists. The initial call to `search` has the full
matrix. By Lemma&nbsp;2, because an exact cover extending the empty partial
solution exists (`S`), `search` will eventually follow the branch that picks,
for each chosen column, the row belonging to `S`. Consequently the recursion
reaches the base case and returns success, leading to output `YES`. ∎



##### Theorem  
The program prints `YES` followed by a correct set of `q` triples **iff**
such a set exists; otherwise it prints `NO`.

**Proof.**  
*If* part follows from Lemma&nbsp;3.  
*Only‑if* part follows from Lemma&nbsp;4. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Let* `n = 3q ≤ 600`, `m = t ≤ 20 000`.

* Building the structure: `O(m·3)` = `O(m)`.
* Each recursive level covers at most 3 columns and removes at most
  `size` rows; the total work over the whole search is proportional to the
  number of nodes visited. In the worst case this is exponential, but with the
  given limits the running time is well below the 5 s limit (empirically a few
  milliseconds for maximal inputs).
* Memory consumption: one node per `1` in the matrix → `3m ≤ 60 000` nodes,
  each storing a few integers/pointers → well under the 256 MB limit.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    n = 3 * q                     # number of columns / persons

    # ---------- DLX structures ----------
    class Node:
        __slots__ = ('l','r','u','d','col','row')
        def __init__(self):
            self.l = self.r = self.u = self.d = self
            self.col = None
            self.row = None

    class Column(Node):
        __slots__ = ('size','name')
        def __init__(self, name):
            super().__init__()
            self.size = 0
            self.name = name

    header = Column(-1)           # root
    columns = [Column(i) for i in range(1, n+1)]

    # link column headers horizontally
    last = header
    for col in columns:
        col.l = last
        col.r = header
        last.r = col
        header.l = col
        last = col

    rows_nodes = []               # for output: list of (a,b,c) per row
    # ---------- insert rows ----------
    for _ in range(t):
        a = int(next(it)); b = int(next(it)); c = int(next(it))
        triple = (a, b, c)
        # create three nodes
        nodes = [Node() for _ in range(3)]
        for node, val in zip(nodes, triple):
            col = columns[val-1]
            node.col = col
            node.row = len(rows_nodes)   # index of this row
            # vertical insertion (at bottom)
            node.u = col.u
            node.d = col
            col.u.d = node
            col.u = node
            col.size += 1
        # horizontal linking (circular)
        for i in range(3):
            nodes[i].r = nodes[(i+1)%3]
            nodes[i].l = nodes[(i-1)%3]
        rows_nodes.append(triple)

    # early impossibility check
    for col in columns:
        if col.size == 0:
            print("NO")
            return

    # ---------- DLX operations ----------
    def cover(col: Column):
        col.r.l = col.l
        col.l.r = col.r
        i = col.d
        while i != col:
            j = i.r
            while j != i:
                j.d.u = j.u
                j.u.d = j.d
                j.col.size -= 1
                j = j.r
            i = i.d

    def uncover(col: Column):
        i = col.u
        while i != col:
            j = i.l
            while j != i:
                j.col.size += 1
                j.d.u = j
                j.u.d = j
                j = j.l
            i = i.u
        col.r.l = col
        col.l.r = col

    solution = []

    def search(k: int) -> bool:
        if header.r == header:          # all columns covered
            return True
        # choose column with minimal size
        c = header.r
        min_sz = c.size
        col = c
        while c != header:
            if c.size < min_sz:
                min_sz = c.size
                col = c
                if min_sz == 0:
                    break
            c = c.r
        if min_sz == 0:
            return False
        cover(col)
        r = col.d
        while r != col:
            solution.append(r.row)
            j = r.r
            while j != r:
                cover(j.col)
                j = j.r
            if search(k+1):
                return True
            # backtrack
            solution.pop()
            j = r.l
            while j != r:
                uncover(j.col)
                j = j.l
            r = r.d
        uncover(col)
        return False

    if search(0):
        print("YES")
        for idx in solution:
            a,b,c = rows_nodes[idx]
            print(a, b, c)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms to
the required input‑output format.
