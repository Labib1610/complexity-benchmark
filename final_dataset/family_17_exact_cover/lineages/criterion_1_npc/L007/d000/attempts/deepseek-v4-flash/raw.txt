We need to select exactly \( q \) triples from the given \( t \) protocols such that every anomaly from 1 to \( 3q \) appears exactly once. This is a **3-dimensional matching** problem, which is NP-hard in general, but here \( q \le 200 \) and \( t \le 20000 \), so we need a clever approach.

We can model this as an **exact cover** problem and solve it with **Algorithm X** (Dancing Links) or a backtracking with pruning. Since \( q \) is small (max 200), backtracking with bitmasks can work.

We’ll represent each anomaly as a bit in an integer (up to 600 bits, so we can use Python’s big integers). Each triple is a bitmask. We need to pick \( q \) masks that are disjoint and cover all bits.

We can use recursion with pruning:
- Sort triples by size of their smallest uncovered element to reduce branching.
- Use bitmask to track covered anomalies.
- If at any point the number of remaining triples is less than needed, prune.

Let’s implement it.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    q = int(input_data[0])
    t = int(input_data[1])
    triples = []
    idx = 2
    for _ in range(t):
        a = int(input_data[idx]) - 1
        b = int(input_data[idx+1]) - 1
        c = int(input_data[idx+2]) - 1
        idx += 3
        mask = (1 << a) | (1 << b) | (1 << c)
        triples.append((mask, a, b, c))
    
    full_mask = (1 << (3*q)) - 1
    
    # Sort triples: prefer those with smallest first uncovered element
    # We'll sort by the smallest bit index in the mask
    triples.sort(key=lambda x: (x[0] & -x[0]).bit_length() - 1)
    
    chosen = []
    
    def backtrack(covered, start):
        if covered == full_mask:
            return True
        # Find first uncovered anomaly
        # We can find the lowest zero bit
        inv = (~covered) & full_mask
        if inv == 0:
            return False
        # lowest uncovered bit
        low_bit = inv & -inv
        low_idx = low_bit.bit_length() - 1
        
        # Try triples that contain this bit
        for i in range(start, t):
            mask, a, b, c = triples[i]
            if (mask & low_bit) == 0:
                continue
            if (mask & covered) != 0:
                continue
            chosen.append((a+1, b+1, c+1))
            if backtrack(covered | mask, i+1):
                return True
            chosen.pop()
        return False
    
    if backtrack(0, 0):
        print("YES")
        for a,b,c in chosen:
            print(a,b,c)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
