# Phase II: Roster Consolidation

Time limit: 5 s   Memory limit: 256 MB

## Description
The regional emergency directorate orchestrates its annual drill through a three-phase software pipeline. 

*   **Phase I (Candidate Generation):** An automated system analyzes historical archives to generate a pool of certified response configurations. Each configuration strictly dictates the joint participation of three specific individuals, identified by their badge numbers.
*   **Phase II (Roster Consolidation):** You are responsible for this phase. The active roster for the drill is sized based on a scale factor $q$. There are $3q$ personnel on duty, assigned consecutive badge numbers from $1$ to $3q$. Every person on the roster is initially issued exactly one digital deployment token. Activating a configuration from the Phase I pool requires simultaneously consuming the unconsumed individual tokens of its three assigned members. Your objective is to determine if command can identify a selection of the certified configurations such that every individual is deployed exactly once (i.e., the roster's entire token pool is completely exhausted).
*   **Phase III (Logistics Provisioning):** If Phase II is successful, the selected configurations are passed to the logistics engine to provision vehicles and equipment. If Phase II fails, the entire drill must be rescheduled.

Your task is exclusively to implement Phase II. Given the roster size parameter $q$ and the pool of configurations generated by Phase I, determine if a valid selection exists. If it does, output the chosen configurations so they can be forwarded to Phase III. Otherwise, indicate that it is impossible.

## Input
The first line contains two integers $q$ and $t$ ($1 \le q \le 200$, $0 \le t \le 20000$), where $t$ is the number of configurations generated by Phase I.
Each of the next $t$ lines contains three integers $a$, $b$, and $c$ ($1 \le a < b < c \le 3q$), representing the badge numbers in a configuration.

## Output
If a valid selection for Phase II exists, print `YES`, followed by $q$ lines, each containing the three badge numbers of one activated configuration.
Otherwise, print `NO`.

## Examples
### Example 1
Input:
```
2 3
1 2 3
4 5 6
1 4 5
```
Output:
```
YES
1 2 3
4 5 6
```
