# Phase 3: Triad Allocation Protocol

Time limit: 5 s   Memory limit: 256 MB

## Description
The annual planetary readiness exercise requires a strict multi-phase preparation sequence.

*   **Phase 1: Personnel Audit.** The administration finalises the active roster. For this exercise, the roster size is guaranteed to be a multiple of three, specifically $3q$ individuals, assigned identification numbers consecutively from $1$ to $3q$.
*   **Phase 2: Synergy Extraction.** The analytics engine reviews past deployment metrics to identify highly cohesive three-person teams, known as triads. Because strict cohesion criteria apply, the engine outputs exactly $t$ pre-approved triads.
*   **Phase 3: Allocation Routing (Your Objective).** As the central allocation module, you must process the data from Phase 1 and Phase 2. Your mandate is to select a subset of the pre-approved triads such that every individual on the active roster is assigned to exactly one selected triad. No person may be left unassigned, and no person may be assigned to more than one triad.
*   **Phase 4: Field Execution.** The selected triads are transmitted to the logistics department for immediate deployment.

If Phase 3 cannot be completed because the pre-approved triads do not allow for a perfect, non-overlapping assignment of all $3q$ individuals, you must signal a protocol failure so the exercise can be aborted.

## Input
The first line provides two integers $q$ and $t$ ($1 \le q \le 200$, $0 \le t \le 20000$). The total number of personnel on the roster is $3q$.
The following $t$ lines represent the data generated by Phase 2. Each line contains three integers $a$, $b$, and $c$ ($1 \le a < b < c \le 3q$), denoting the ID numbers of the personnel in one pre-approved triad.

## Output
If the Phase 3 mandate can be fulfilled, print `YES` on the first line. Then, print $q$ lines, each containing the three personnel IDs of a selected triad.
If it is impossible to fulfill the mandate, print `NO`.

## Examples
### Example 1
Input:
```
2 3
1 2 3
4 5 6
1 4 5
```
Output:
```
YES
1 2 3
4 5 6
```
