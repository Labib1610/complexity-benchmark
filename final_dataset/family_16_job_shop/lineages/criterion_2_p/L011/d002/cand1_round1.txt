# Problem B — Two-Stage Assembly

Time limit: 1 s   Memory limit: 256 MB

## Description

You are cultivating a garden of **j** rare magical plants. Each plant requires a specific seed.

You must choose a single sequence in which to sow all **j** seeds. You sow them one after another without interruption. Sowing the seed for plant **i** requires **p1** minutes of continuous effort.

The moment a seed is sown, it is ready to germinate. Germinating plant **i** takes **p2** minutes. However, the garden's magical resonance can only sustain the germination of a single seed at any given time. The resonance enforces the following rules:

- The garden always germinates the seeds in the exact order they were sown.
- A seed begins germinating the exact moment it is sown, provided the resonance is not currently occupied by any earlier seed.
- If the resonance is occupied when a seed is sown, the new seed remains dormant. It will automatically begin germinating the instant all previously sown seeds have finished germinating.

Because the sowing and germination rely on different forces, you can be sowing a new seed while an earlier seed is germinating. You must determine the optimal sequence to sow the seeds to minimize the total elapsed time from when you begin sowing the first seed until the final plant has completely finished germinating.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the minutes required to sow the seed and the minutes required for it to germinate, respectively.

## Output

Print a single integer: the minimum possible time at which the final plant finishes germinating.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single seed takes 5 minutes to sow, and then 3 minutes to germinate. The plant finishes germinating at minute 8.
