We can solve this using Johnson’s rule for two-machine scheduling.  
The goal is to minimize the makespan when all jobs must go through machine 1 (primary) then machine 2 (secondary) in the same order.

**Johnson’s rule:**
- Split jobs into two sets:
  - Set A: jobs where `p1 <= p2`
  - Set B: jobs where `p1 > p2`
- Sort Set A by `p1` ascending.
- Sort Set B by `p2` descending.
- The optimal sequence is A followed by B.

Then simulate the schedule to compute the makespan.

Here’s the implementation:

```python
n = int(input())
jobs = [tuple(map(int, input().split())) for _ in range(n)]

A = []
B = []
for p1, p2 in jobs:
    if p1 <= p2:
        A.append((p1, p2))
    else:
        B.append((p1, p2))

A.sort(key=lambda x: x[0])
B.sort(key=lambda x: x[1], reverse=True)

order = A + B

time1 = 0
time2 = 0
for p1, p2 in order:
    time1 += p1
    if time2 < time1:
        time2 = time1
    time2 += p2

print(time2)
```
