# Problem B — Minimax Grid Path

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given **j** tiles. Each tile represents a single column with a top-row value **p1** and a bottom-row value **p2**.

You must arrange all **j** tiles in a sequence from left to right to form a grid with 2 rows and **j** columns. 

A path through this grid starts at the top-left cell (row 1, column 1) and ends at the bottom-right cell (row 2, column **j**).
From any cell, a path can only move exactly one cell to the right, or exactly one cell down. It cannot move left or up.
The cost of a path is the sum of the values in all the cells it visits.

For a chosen left-to-right arrangement of the **j** tiles, the "grid cost" is the maximum possible cost among all valid paths from the top-left to the bottom-right.

Your objective is to find an arrangement of the **j** tiles that minimizes the grid cost.

What is the minimum possible grid cost?

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the top-row value and bottom-row value of a tile, respectively.

## Output

Print a single integer: the minimum possible grid cost.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, if we arrange the tiles in the order of the 3rd tile, then the 2nd tile, then the 1st tile from the input:
- The top row becomes: 1, 2, 3
- The bottom row becomes: 3, 4, 2

The possible paths from top-left to bottom-right are:
- Path moving down at column 1: visits top row col 1 (value 1), then bottom row cols 1, 2, 3 (values 3, 4, 2). Cost = 1 + 3 + 4 + 2 = 10.
- Path moving down at column 2: visits top row cols 1, 2 (values 1, 2), then bottom row cols 2, 3 (values 4, 2). Cost = 1 + 2 + 4 + 2 = 9.
- Path moving down at column 3: visits top row cols 1, 2, 3 (values 1, 2, 3), then bottom row col 3 (value 2). Cost = 1 + 2 + 3 + 2 = 8.

The maximum path cost for this arrangement is 10.
This is the minimum possible grid cost across all valid arrangements.

<RATIONALE>
The problem was completely reframed from a two-stage scheduling task to finding a column permutation that minimizes the maximum path sum in a 2xN grid. This mathematically isomorphic formulation removes all temporal terminology (workers, waiting, tasks) that allowed models to pattern-match to Johnson's rule, forcing them to genuinely analyze the minimax objective to discover the optimal greedy strategy.
</RATIONALE>
<PRESERVED_ANSWER>
The maximum path sum in a 2xN grid where the path moves down at column k is exactly the sum of the first k elements of the top row and the last N-k+1 elements of the bottom row, which is algebraically identical to the completion time of the k-th job on the second machine in a two-machine flow shop.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to the two-machine flow-shop makespan minimization, which is optimally solvable in O(N log N) time using Johnson's rule.
</PRESERVED_CLASS>
