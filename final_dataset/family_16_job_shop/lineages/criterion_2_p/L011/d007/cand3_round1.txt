# Problem B — Dual-Level Track Design

Time limit: 1 s   Memory limit: 256 MB

## Description

You are constructing a dual-level marble run using a collection of **j** modular blocks. 

You must establish a single sequence (an ordering of the **j** blocks) from left to right.

Each block has an upper channel and a lower channel. For a given block, its upper channel has length **p1** and its lower channel has length **p2**.

A marble enters the first block in your sequence on the upper channel. It will drop to the lower channel in exactly one of the blocks. The marble can drop in any block **k** (where **k** is between 1 and **j**, inclusive). 

When the marble drops in the **k**-th block of your sequence, its total travel distance is calculated as follows:
- It traverses the upper channels of the 1st block, 2nd block, ..., up to and including the **k**-th block.
- It drops instantly (adding 0 to the distance) to the lower channel inside the **k**-th block.
- It then traverses the lower channels of the **k**-th block, (**k**+1)-th block, ..., up to and including the last (**j**-th) block.

Since the drop location is unpredictable, the marble could drop in any of the **j** blocks. Your task is to find an ordering of the blocks that minimizes the maximum possible distance the marble could travel.

What is this minimum possible worst-case distance?

## Input

The first line contains a single integer **j**. The number of blocks is at least 1, and at most the number of centimeters in 2 kilometers.
Each of the following **j** lines contains two integers **p1** and **p2**, representing the lengths of the upper channel and lower channel of that block, respectively. Each length is at least 1, and at most the number of millimeters in 1 kilometer.

## Output

Print a single integer: the minimum possible maximum travel distance of the marble.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, if we order the blocks as the 3rd block, then the 2nd block, then the 1st block from the input:
- If the marble drops in the first block of the sequence (input block 3), it travels 1 on the upper channel, drops, and travels 3 + 4 + 2 = 9 on the lower channels. Total distance: 1 + 9 = 10.
- If it drops in the second block (input block 2), it travels 1 + 2 = 3 on the upper channels, drops, and travels 4 + 2 = 6 on the lower channels. Total distance: 3 + 6 = 9.
- If it drops in the third block (input block 1), it travels 1 + 2 + 3 = 6 on the upper channels, drops, and travels 2 on the lower channel. Total distance: 6 + 2 = 8.
The maximum possible distance for this ordering is 10. This is the minimum possible worst-case distance across all valid orderings.

In Example 2, there is only one block. The marble travels 5 on the upper channel, drops, and travels 3 on the lower channel. The total distance is 5 + 3 = 8.
