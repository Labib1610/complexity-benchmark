# Problem B — Peak Pressure Optimization

Time limit: 1 s   Memory limit: 256 MB

## Description

You are designing a testing sequence for **j** chemical reactions inside a sealed chamber.
Each reaction consists of two phases: a pressurization phase that increases the chamber's pressure by **p1**, followed immediately by a depressurization phase that decreases the pressure by **p2**.

To maintain a stable environment, before any reactions are executed, the chamber is pre-pressurized to a baseline pressure exactly equal to the sum of the depressurization values (**p2**) of all **j** reactions.

You must establish a single processing sequence (an ordering of the **j** reactions). The reactions will be executed one after another in this exact order. 

As the sequence runs, a sensor records the pressure level inside the chamber. Specifically, for each reaction, the pressure is recorded exactly at its peak—after the pressurization phase is complete, but before the depressurization phase begins. The pressure level carries over from one reaction to the next.

Your task is to find an ordering of the **j** reactions that minimizes the maximum pressure recorded by the sensor throughout the entire sequence.

What is the minimum possible value for this maximum recorded pressure?

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the pressurization increase and depressurization decrease for that reaction, respectively.

## Output

Print a single integer: the minimum possible maximum pressure recorded during the sequence.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, the sum of all depressurization values is 2 + 4 + 3 = 9. The chamber's initial pressure is set to 9.
If we order the reactions as the 3rd, then the 2nd, then the 1st from the input:
- 3rd reaction (1, 3): Pressure increases by 1 to 10. The sensor records 10. Then pressure decreases by 3 to 7.
- 2nd reaction (2, 4): Pressure increases by 2 to 9. The sensor records 9. Then pressure decreases by 4 to 5.
- 1st reaction (3, 2): Pressure increases by 3 to 8. The sensor records 8. Then pressure decreases by 2 to 6.
The maximum pressure recorded is 10 (during the 3rd reaction). This is the minimum possible peak pressure across all valid orderings.

In Example 2, there is only one reaction. The initial pressure is 3.
It increases by 5 to 8, which is recorded. Then it decreases by 3 to 5.
The maximum recorded pressure is 8.
