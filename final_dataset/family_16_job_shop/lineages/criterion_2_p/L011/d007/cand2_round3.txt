# Problem B — Sequence Evaluation

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a set of $j$ pairs of positive integers. Each pair $i$ consists of two values, $a_i$ and $b_i$.

You must arrange all $j$ pairs into a single ordered sequence. Let your chosen sequence of pairs be $(A_1, B_1), (A_2, B_2), \dots, (A_j, B_j)$. This sequence must contain exactly the same pairs as the input, just in an order of your choosing.

Based on your chosen sequence, we compute two series of values, $X_1, X_2, \dots, X_j$ and $Y_1, Y_2, \dots, Y_j$, defined as follows:
- $X_0 = 0$
- $Y_0 = 0$
- For each step $k$ from 1 to $j$:
  - $X_k = X_{k-1} + A_k$
  - $Y_k = \max(X_k, Y_{k-1}) + B_k$

Your goal is to find an arrangement of the $j$ pairs that minimizes the final value $Y_j$.

What is the minimum possible value of $Y_j$?

## Input

The first line contains a single integer $j$ (1 ≤ $j$ ≤ 200000).
Each of the following $j$ lines contains two integers $a_i$ and $b_i$ (1 ≤ $a_i, b_i$ ≤ 1000000), representing the values of the $i$-th pair.

## Output

Print a single integer: the minimum possible value of $Y_j$ across all valid sequence arrangements.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, if we order the pairs as the 3rd pair, then the 2nd pair, then the 1st pair from the input, our sequence is $(1, 3)$, $(2, 4)$, $(3, 2)$.
We compute the sequences step by step:
- **Step 1:** $X_1 = 0 + 1 = 1$. $Y_1 = \max(1, 0) + 3 = 4$.
- **Step 2:** $X_2 = 1 + 2 = 3$. $Y_2 = \max(3, 4) + 4 = 8$.
- **Step 3:** $X_3 = 3 + 3 = 6$. $Y_3 = \max(6, 8) + 2 = 10$.
The final value $Y_3$ is 10. This is the minimum possible value across all valid arrangements.

In Example 2, there is only one pair $(5, 3)$.
- **Step 1:** $X_1 = 0 + 5 = 5$. $Y_1 = \max(5, 0) + 3 = 8$.
The final value is 8.
