# Problem B — Reactor Pressure Management

Time limit: 1 s   Memory limit: 256 MB

## Description

You are sequencing **j** fuel rods for a reactor. Each rod has a reaction spike **p1** and a subsequent cooling drop **p2**.

The reactor's internal pressure is tracked continuously. Before any rods are inserted, the reactor is pre-pressurized to a baseline level equal to the sum of the cooling drops of all **j** rods (i.e., the sum of **p2** across all rods).

When you insert the $k$-th rod in your chosen sequence, the following two events happen in exactly this order:
1. The pressure immediately increases by the rod's reaction spike **p1**. The reactor records the current pressure as a peak.
2. The rod's cooling mechanism then activates, permanently decreasing the pressure by **p2**.

This process repeats for each rod in your chosen sequence, one by one. 

Your objective is to find an insertion sequence (a permutation of the **j** rods) that minimizes the highest single peak recorded across all **j** insertions.

What is the minimum possible value of the maximum peak pressure?

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the reaction spike and the cooling drop of a rod, respectively.

## Output

Print a single integer: the minimum possible highest peak pressure across all valid sequences.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, the sum of all cooling drops is $2 + 4 + 3 = 9$. The baseline pressure is 9.

If we sequence the rods as the 3rd rod, then the 2nd rod, then the 1st rod from the input:
- For the first rod in sequence (input rod 3): $p1 = 1$, $p2 = 3$. 
  Pressure increases by 1 to $9 + 1 = 10$. (Peak recorded: 10)
  Pressure decreases by 3 to $10 - 3 = 7$.
- For the second rod in sequence (input rod 2): $p1 = 2$, $p2 = 4$. 
  Pressure increases by 2 to $7 + 2 = 9$. (Peak recorded: 9)
  Pressure decreases by 4 to $9 - 4 = 5$.
- For the third rod in sequence (input rod 1): $p1 = 3$, $p2 = 2$. 
  Pressure increases by 3 to $5 + 3 = 8$. (Peak recorded: 8)
  Pressure decreases by 2 to $8 - 2 = 6$.

The peaks recorded are 10, 9, and 8. The maximum peak is 10. This is the minimum possible highest peak across all valid sequences.

In Example 2, there is exactly one rod. The baseline pressure is 3. The rod spikes the pressure by 5 to a peak of 8, before cooling it by 3.
