# Problem B — Memory Controller Synchronization

Time limit: 1 s   Memory limit: 256 MB

## Description

You are configuring a memory controller that must process exactly **j** data blocks. Each block requires exactly **two** strictly ordered allocation phases: Virtual mapping, followed by Physical binding.

You must establish a single allocation sequence (a permutation of the **j** blocks). Both phases will process the blocks in this **exact same chosen order**.

The allocation timeline is governed by the following hardware constraints:
- There are exactly two hardware units (the Virtual unit and the Physical unit). Each unit can process only one block at a time.
- For any given block, the Physical unit can only begin its Physical binding after the Virtual unit has fully completed its Virtual mapping.
- The Virtual unit processes the blocks consecutively with zero delay gaps, starting at microsecond 0.
- The Physical unit begins processing each block at the earliest possible microsecond that satisfies all the above conditions.

The exact microsecond when the Physical unit finishes the entire sequence can be computed by tracking the availability of both units. Formally, if $p1$ and $p2$ are the Virtual and Physical durations of a block, the completion time is determined by the following logic:

```python
def compute_completion_time(sequence):
    virtual_end = 0
    physical_end = 0
    for p1, p2 in sequence:
        virtual_end += p1
        if virtual_end > physical_end:
            physical_end = virtual_end
        physical_end += p2
    return physical_end
```

Your objective is to find an ordering of the **j** blocks that minimizes the final completion time—specifically, the exact microsecond when the Physical unit finishes the last block in your sequence. 

*(Hint: Because the sum of all Physical binding times is a fixed constant regardless of the permutation, minimizing this final completion time is mathematically equivalent to minimizing the total accumulated time the Physical unit spends inactive while waiting for the Virtual unit to finish a block.)*

What is the minimum possible final completion time?

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the time required for a block's Virtual mapping and Physical binding, respectively.

## Output

Print a single integer: the minimum possible final completion time of the Physical unit.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1

```

**Output**
```
8
```

### Example 3

**Input**
```
3

```

**Output**
```
8
```

## Note

In Example 1, if we order the blocks as the 3rd block, then the 2nd block, then the 1st block from the input:
- For the first block in sequence (input block 3): $p1 = 1$, $p2 = 3$. 
  The Virtual unit finishes at $0 + 1 = 1$. 
  The Physical unit waits until microsecond 1, then finishes at $1 + 3 = 4$.
- For the second block in sequence (input block 2): $p1 = 2$, $p2 = 4$. 
  The Virtual unit finishes at $1 + 2 = 3$. 
  The Physical unit is active until microsecond 4, so it starts at 4 and finishes at $4 + 4 = 8$.
- For the third block in sequence (input block 1): $p1 = 3$, $p2 = 2$. 
  The Virtual unit finishes at $3 + 3 = 6$. 
  The Physical unit is active until microsecond 8, so it starts at 8 and finishes at $8 + 2 = 10$.

The final completion time is 10. This is the minimum possible value across all valid orderings.
