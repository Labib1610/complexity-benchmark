# Problem B — Orbital Maneuver Sequencing

Time limit: 1 s   Memory limit: 256 MB

## Description

You are programming the flight computer for a spacecraft that must execute $j$ orbital maneuvers. Each maneuver requires an engine burn of duration $p_1$ minutes and a subsequent sensor calibration of duration $p_2$ minutes.

You must establish a single execution sequence for the $j$ maneuvers. The flight computer simulates your sequence to determine the total time required, tracking progress with two variables: the Burn Clock and the Calibration Clock. Both clocks initially start at minute 0.

As the computer processes each maneuver in your chosen sequence, it updates the clocks in three exact steps:
1. It allocates the engine burn by adding $p_1$ to the Burn Clock.
2. The calibration cannot begin until the maneuver's burn is complete, and it cannot overlap with any previous calibration. Therefore, if the Calibration Clock is currently strictly less than the Burn Clock, the Calibration Clock is immediately fast-forwarded to equal the Burn Clock.
3. It allocates the calibration by adding $p_2$ to the Calibration Clock.

Your objective is to find an ordering of the $j$ maneuvers that minimizes the final value of the Calibration Clock after all $j$ maneuvers have been processed.

What is the minimum possible final value of the Calibration Clock?

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the following $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$), representing the engine burn duration and the sensor calibration duration in minutes for a maneuver, respectively.

## Output

Print a single integer: the minimum possible final value of the Calibration Clock.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal sequence is to order the input maneuvers as: the 3rd maneuver, then the 2nd maneuver, then the 1st maneuver.
- For the first maneuver in sequence (input maneuver 3): $p_1 = 1$, $p_2 = 3$. 
  Burn Clock becomes $0 + 1 = 1$. 
  Calibration Clock is updated to $\max(0, 1) = 1$. 
  Calibration Clock becomes $1 + 3 = 4$.
- For the second maneuver in sequence (input maneuver 2): $p_1 = 2$, $p_2 = 4$. 
  Burn Clock becomes $1 + 2 = 3$. 
  Calibration Clock is updated to $\max(4, 3) = 4$. 
  Calibration Clock becomes $4 + 4 = 8$.
- For the third maneuver in sequence (input maneuver 1): $p_1 = 3$, $p_2 = 2$. 
  Burn Clock becomes $3 + 3 = 6$. 
  Calibration Clock is updated to $\max(8, 6) = 8$. 
  Calibration Clock becomes $8 + 2 = 10$.

The final Calibration Clock is 10. This is the minimum possible value across all valid sequences.

<RATIONALE>
I changed the presentation from a two-team concurrent scheduling problem to a sequential procedural state-machine with two accumulators (clocks). This removes the semantic triggers of "parallel teams" and "waiting times" that models rely on to classify the problem as a two-machine flow shop, forcing them to analyze the state update logic directly while strictly preserving the operational objective. Exact numeric bounds were restored to the Input section.
</RATIONALE>
