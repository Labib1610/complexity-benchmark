Looking at this problem, I need to find an ordering of amplifiers that minimizes S_final + D, where D is fixed (sum of all p1), so I need to minimize S_final.

Let me analyze the signal propagation. If signal never hits zero, then after processing amplifiers in some order, S = sum of (p2_i - p1_i) for all amplifiers. The floor at zero can only reduce S, so S_final ≤ sum(p2_i - p1_i).

The key insight: if I process an amplifier when S ≥ p1, the contribution is (p2 - p1). If I process it when S < p1, the contribution is p2 - S (less than p2 - p1). So to minimize S_final, I want to process amplifiers when S is small (below their p1 threshold).

**Greedy approach:** At each step, if current S can "cover" some remaining amplifier (S ≥ p1), processing it gives contribution (p2 - p1). If no amplifier can be covered, I must process one that gives contribution p2 - S (which is ≤ p2 - p1 since S < p1).

To minimize, when forced to process an uncovered amplifier, pick the one with smallest p2 (gives smallest contribution p2 - S). When I can cover an amplifier, I should do so to "lock in" the better contribution (p2 - p1) before S potentially drops.

But there's a subtlety: covering an amplifier with negative (p2-p1) decreases S, potentially forcing future amplifiers to be uncovered. However, uncovered contribution is always ≤ covered contribution, so covering is never worse. Thus greedily covering whenever possible is optimal.

**Implementation:** Use a priority queue. Process amplifiers with p1 ≤ S first (by smallest p2). When stuck (no amplifier has p1 ≤ S), pick the smallest p2 amplifier to break the deadlock.

import sys

        amplifiers.append((p1, p2))
    
    amplifiers.sort()
    
    available = []  # min-heap of (p2, p1)
    ptr = 0
    S = 0
    
    while ptr < j or available:
        while ptr < j and amplifiers[ptr][0] <= S:
            p1, p2 = amplifiers[ptr]
            heapq.heappush(available, (p2, p1))
            ptr += 1
        
        if available:
            p2, p1 = heapq.heappop(available)
            S = max(S - p1, 0) + p2
        else:
            p1, p2 = amplifiers[ptr]
            ptr += 1
            S = p2  # max(S - p1, 0) + p2 where S < p1, so max = 0
    
    D = sum(p1 for p1, p2 in amplifiers)
    print(S + D)
