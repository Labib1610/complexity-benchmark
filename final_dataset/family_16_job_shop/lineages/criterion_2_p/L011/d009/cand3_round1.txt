<STATEMENT>
# Problem B — Artifact Exhibition

Time limit: 1 s   Memory limit: 256 MB

## Description

You are curating an exhibition of ancient artifacts. The gallery has a strict fire code allowing at most 200,000 items on display. You are given a collection of exactly $j$ artifacts (where $j$ is at least 1 and does not exceed the gallery's capacity). You must arrange them in a single contiguous sequence from left to right, occupying positions $1$ to $j$.

Each artifact has two aesthetic ratings: a daytime appeal and a nighttime appeal. These ratings are positive integers, and the scoring system ensures no rating exceeds 1,000,000 points.

Once the artifacts are arranged, an adversarial art critic will evaluate your sequence. The critic will select exactly one focal position $i$ ($1 \le i \le j$). The critic's evaluation score for your arrangement is calculated as:
- The sum of the daytime appeals of all artifacts from position $1$ up to position $i$ (inclusive), plus
- The sum of the nighttime appeals of all artifacts from position $i$ up to position $j$ (inclusive).

The critic will always choose the focal position $i$ that maximizes this evaluation score. 

Your objective is to order the $j$ artifacts to minimize the maximum evaluation score the critic can possibly achieve. What is this minimum possible evaluation score?

## Input

The first line contains a single integer $j$, representing the number of artifacts.
Each of the following $j$ lines contains two integers $p_1$ and $p_2$, representing the daytime appeal and nighttime appeal of an artifact, respectively. The bounds on $j$, $p_1$, and $p_2$ are as described above.

## Output

Print a single integer: the minimum possible evaluation score you can force the critic to give.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal arrangement is to place the 3rd input artifact first, then the 2nd, then the 1st. 
The sequence of (daytime, nighttime) appeals is: $(1, 3)$ at position 1, $(2, 4)$ at position 2, and $(3, 2)$ at position 3.
The critic evaluates all possible focal positions $i$:
- For $i = 1$: The score is the daytime appeal up to position 1, plus nighttime appeals from position 1 to 3. This is $1 + (3 + 4 + 2) = 10$.
- For $i = 2$: The score is the daytime appeals up to position 2, plus nighttime appeals from position 2 to 3. This is $(1 + 2) + (4 + 2) = 9$.
- For $i = 3$: The score is the daytime appeals up to position 3, plus the nighttime appeal at position 3. This is $(1 + 2 + 3) + 2 = 8$.

The critic chooses $i = 1$ to maximize the score, yielding 10. There is no arrangement of the artifacts that forces the critic's maximum score to be strictly less than 10.

<RATIONALE>
The explicit two-machine flow-shop narrative has been replaced with a minimax game on a permuted sequence. The objective function (maximum over $i$ of a prefix sum plus a suffix sum) is mathematically identical to the completion time of the final job in a 2-machine flow shop. To succeed, models can no longer rely on scheduling keywords; they must algebraically recognize that this specific minimax objective is isomorphic to the flow-shop makespan and apply Johnson's rule.
</RATIONALE>
<PRESERVED_ANSWER>
The maximum score over all focal positions $i$ is exactly the expansion of the makespan formula $C_{\max} = \max_i (\sum_{k=1}^i X_k + \sum_{k=i}^j Y_k)$, so the minimum possible value across all permutations is unchanged.
</PRESERVED_ANSWER>

The problem remains solvable in O(N log N) using Johnson's rule, keeping it squarely in P.
</PRESERVED_CLASS>
