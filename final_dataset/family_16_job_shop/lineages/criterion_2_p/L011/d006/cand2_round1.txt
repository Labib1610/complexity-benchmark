<STATEMENT>
# Problem B — Adversarial Grid Traverse

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given **j** vertical tiles, each containing two integers: a top value and a bottom value. 

You must arrange these **j** tiles in a sequence from left to right to construct a grid with 2 rows and **j** columns. The top values of the tiles will form the first row of the grid, and the bottom values will form the second row.

An adversary will traverse your constructed grid starting from the top-left cell (row 1, column 1) and ending at the bottom-right cell (row 2, column **j**). In a single step, the adversary can only move to the right (to the next column in the same row) or down (to the second row in the same column).

The cost of a traversal path is the sum of the values in all the cells visited along the path, including the starting and ending cells. The adversary, playing optimally against you, will always choose a valid path that maximizes this total cost.

Your goal is to choose the left-to-right order of the **j** tiles such that the adversary's maximum path cost is as small as possible.

What is the minimum possible cost you can force upon the adversary?

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the top value and the bottom value of a tile, respectively.

## Output

Print a single integer: the minimum possible path cost the adversary can achieve if you arrange the tiles optimally.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, if we order the tiles as the 3rd tile, then the 2nd tile, then the 1st tile from the input:
The first row (top values) is $R_1 = [1, 2, 3]$ and the second row (bottom values) is $R_2 = [3, 4, 2]$.
The adversary has three possible paths:
- Move down at column 1: $1 + 3 + 4 + 2 = 10$
- Move down at column 2: $1 + 2 + 4 + 2 = 9$
- Move down at column 3: $1 + 2 + 3 + 2 = 8$
The adversary will choose the path with the maximum cost, which is 10.
It can be shown that no other arrangement of the tiles results in a maximum path cost strictly less than 10.
