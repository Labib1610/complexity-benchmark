Looking at this problem, I need to minimize T = max over k of (prefix_sum_X[k] + suffix_sum_Y[k]).

This is the classic two-machine flow shop scheduling problem (Johnson's rule).

**Johnson's Rule:** Partition batches into two groups:
- Group 1: batches where X ≤ Y, sorted by X ascending
- Group 2: batches where X > Y, sorted by Y descending

Concatenate Group 1 followed by Group 2.

**Why it works:** The critical batch k* is where the "gap" between Phase A and Phase B is largest. Batches with X ≤ Y should come before k* (sorted by X to minimize prefix sum), and batches with X > Y should come after k* (sorted by Y descending to minimize suffix sum). Johnson's rule places the natural "pivot" at the boundary between groups.

**Verification with Example 1:**
- Batches: (3,2), (2,4), (1,3)
- Group 1 (X≤Y): (1,3), (2,4) → sorted by X: [(1,3), (2,4)]
- Group 2 (X>Y): (3,2) → sorted by Y desc: [(3,2)]
- Order: [(1,3), (2,4), (3,2)]
- T = max(1+9, 3+6, 6+2) = max(10, 9, 8) = 10 ✓

**Verification with Example 3:**
- All (2,2), all in Group 1, sorted by X (all equal)
- Order: [(2,2), (2,2), (2,2)]
- T = max(2+6, 4+4, 6+2) = 8 ✓

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    idx = 0
    j = int(data[idx]); idx += 1
    
    group1 = []  # X <= Y, sort by X ascending
    group2 = []  # X > Y, sort by Y descending
    
    for _ in range(j):
        x = int(data[idx]); idx += 1
        y = int(data[idx]); idx += 1
        if x <= y:
            group1.append((x, y))
        else:
            group2.append((x, y))
    
    group1.sort(key=lambda t: t[0])
    group2.sort(key=lambda t: -t[1])
    
    order = group1 + group2
    
    total_x = 0
    total_y = 0
    for _, y in order:
        total_y += y
    
    best = 0
    for x, y in order:
        total_x += x
        total_y -= y
        val = total_x + total_y + y
        if val > best:
            best = val
    
    print(best)

main()
```
