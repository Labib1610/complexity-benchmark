We can solve this by sorting the jobs using a known optimal ordering rule for two-machine flow shop scheduling (Johnson’s rule).  

The rule is:  
- If the two jobs have different categories (one has `p1 < p2`, the other has `p1 >= p2`), put the one with `p1 < p2` first.  
- Among jobs with `p1 < p2`, sort by `p1` ascending.  
- Among jobs with `p1 >= p2`, sort by `p2` descending.  

Then simulate the schedule to get the minimal completion time.

```python
j = int(input())
jobs = []
for _ in range(j):
    a, b = map(int, input().split())
    jobs.append((a, b))

# Johnson's rule sorting
first = []
second = []
for a, b in jobs:
    if a < b:
        first.append((a, b))
    else:
        second.append((a, b))

first.sort(key=lambda x: x[0])          # sort by p1 ascending
second.sort(key=lambda x: -x[1])        # sort by p2 descending

order = first + second

time_a = 0
time_b = 0
for a, b in order:
    time_a += a
    if time_b < time_a:
        time_b = time_a
    time_b += b

print(time_b)
```
