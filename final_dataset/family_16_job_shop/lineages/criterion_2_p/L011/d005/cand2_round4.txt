# Problem B — Festival Lineup

Time limit: 1 s   Memory limit: 256 MB

## Description

You are organizing a festival featuring **j** distinct performances. Each performance requires a specific duration on the Main Stage, and a specific duration in the Review Room.

You must establish a single lineup (an ordering of the **j** performances). The schedule is determined by the following operational rules:
- Each stage processes exactly one performance at a time.
- A performance cannot begin in the Review Room until it has completely finished on the Main Stage.
- Both the Main Stage and the Review Room will process the performances in this exact same chosen lineup order.
- The Review Room begins each performance as early as possible without violating the above rules.

To understand the impact of your lineup, consider the buffer time $D_i$ for each performance $i$ in your chosen order. We define $D_i$ as the duration between the exact moment the $i$-th performance finishes on the Main Stage and the exact moment it finishes in the Review Room. Let $A_i$ be the Main Stage duration of the $i$-th performance, and $B_i$ be its Review Room duration (where $1 \le i \le j$).

1. The first performance enters the Review Room immediately after the Main Stage, so its buffer is exactly its Review Room duration: $D_1 = B_1$.
2. For any subsequent performance $i > 1$, the Review Room might still be busy with the previous performance when the Main Stage finishes performance $i$. The previous performance finished in the Review Room exactly $D_{i-1}$ minutes after it finished on the Main Stage. Since performance $i$ takes $A_i$ minutes on the Main Stage, the Review Room will remain busy for $\max(D_{i-1} - A_i, 0)$ minutes after performance $i$ finishes on the Main Stage.
3. Once the Review Room is free, performance $i$ takes $B_i$ minutes. Thus, its buffer time is $D_i = \max(D_{i-1} - A_i, 0) + B_i$.

The final performance concludes in the Review Room at time $C$, which is the total time the Main Stage spent processing all performances plus the final buffer time:
$C = \sum_{k=1}^j A_k + D_j$.

Your task is to find an ordering of the **j** performances that minimizes $C$.
What is the minimum possible value of $C$?

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the duration the performance requires on the Main Stage and in the Review Room, respectively.

## Output

Print a single integer: the minimum possible value of $C$.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one performance. According to the rules, its buffer time is $D_1 = B_1 = 3$. The total Main Stage time is $A_1 = 5$. It concludes at time $C = A_1 + D_1 = 5 + 3 = 8$.
