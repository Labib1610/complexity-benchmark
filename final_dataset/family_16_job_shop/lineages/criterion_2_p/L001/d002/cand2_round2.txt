# Nebula Navigation

Time limit: 1 s   Memory limit: 256 MB

## Description

A fleet admiral oversees **j** spacecraft that must navigate through a hazardous nebula. The nebula consists of exactly 2 consecutive zones: an asteroid field followed by an ion storm. For each spacecraft, you are given the time it takes to navigate the asteroid field and the time it takes to navigate the ion storm.

The navigation is governed by the following mechanics:
- The admiral arranges all spacecraft into a single column, establishing their strict sequence.
- The asteroid field accommodates only one spacecraft at a time. Spacecraft traverse it consecutively in the established sequence. The first spacecraft begins immediately at time 0, and each subsequent spacecraft enters the exact moment the previous one exits.
- The instant a spacecraft exits the asteroid field, it arrives at the edge of the ion storm.
- The ion storm also accommodates only one spacecraft at a time. Spacecraft enter it in the exact order they arrive at its edge.
- If the ion storm is occupied when a spacecraft arrives, the spacecraft waits at the edge. If the ion storm is empty, the spacecraft enters immediately.

Arrange the column to minimize the time at which the last spacecraft exits the ion storm. Output that smallest possible completion time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains 2 integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the durations for a spacecraft to navigate the asteroid field and the ion storm, respectively.

## Output

Print a single integer: the smallest possible time at which all spacecraft have exited the ion storm.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single spacecraft takes 5 to navigate the asteroid field and then 3 to navigate the ion storm, exiting at time 8.
