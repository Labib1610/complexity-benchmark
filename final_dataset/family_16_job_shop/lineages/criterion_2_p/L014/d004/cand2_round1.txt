# Problem B — Artifact Inspector

Time limit: 1 s
Memory limit: 256 MB

## Description

You have **j** artifacts, each characterized by two integer properties: an *alpha* value and an *omega* value. You must arrange all **j** artifacts into a single sequence from left to right.

Once you have chosen the sequence, an inspector will evaluate it. The inspector will select a pivot position $k$ ($1 \le k \le j$). For a chosen $k$, the evaluation score is calculated as:
- The sum of the alpha values of all artifacts from the 1st position up to the $k$-th position (inclusive).
- PLUS the sum of the omega values of all artifacts from the $k$-th position up to the $j$-th position (inclusive).

The inspector is adversarial and will always choose the pivot position $k$ that makes the evaluation score as large as possible. 

Your objective is to find an arrangement of the artifacts that minimizes the inspector's maximum possible evaluation score. Report this minimum possible score.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers: the alpha value and the omega value of an artifact (1 ≤ alpha, omega ≤ 1000000).

## Output

Print a single integer: the smallest possible evaluation score the inspector can be forced to give.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, if we arrange the artifacts in the order they appear in the input—(3, 2), (2, 4), (1, 3)—the inspector evaluates the possible pivots:
- For $k=1$, score = $3 + (2 + 4 + 3) = 12$.
- For $k=2$, score = $(3 + 2) + (4 + 3) = 12$.
- For $k=3$, score = $(3 + 2 + 1) + 3 = 9$.
The inspector would choose $k=1$ or $k=2$ for a score of 12.

However, if we optimally arrange them as (1, 3), (2, 4), (3, 2):
- For $k=1$, score = $1 + (3 + 4 + 2) = 10$.
- For $k=2$, score = $(1 + 2) + (4 + 2) = 9$.
- For $k=3$, score = $(1 + 2 + 3) + 2 = 8$.
The inspector would choose $k=1$ for a maximum score of 10. This is the optimal arrangement, so the answer is 10.
