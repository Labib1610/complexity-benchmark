<STATEMENT>
# Problem B — Two-Row Grid

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given $j$ blocks. Each block has two values: a fixed top value $p1$ and a fixed bottom value $p2$.
You must arrange these $j$ blocks in a sequence from left to right to form a grid with 2 rows and $j$ columns. The blocks cannot be rotated; their top values must remain in the first row, and their bottom values must remain in the second row.

Consider a path through this grid that starts at the top-left cell (row 1, column 1) and ends at the bottom-right cell (row 2, column $j$). 
Because there are only two rows, any valid path must move right along row 1 up to some chosen column $k$ ($1 \le k \le j$), move down to row 2 at that exact column $k$, and then move right along row 2 until the end (column $j$).

The cost of such a path is the sum of the values in the cells it visits. For a chosen sequence of blocks $q_1, q_2, \dots, q_j$, the cost of the path that moves down at column $k$ is exactly:
$$ \sum_{i=1}^{k} p1_{q_i} + \sum_{i=k}^{j} p2_{q_i} $$

The **score** of your chosen arrangement is the MAXIMUM cost among all $j$ possible valid paths.
You must choose the sequence of the $j$ blocks to MINIMIZE this score. Report the smallest possible score.

## Input

The first line contains a single integer $j$ (1 ≤ $j$ ≤ 200000).
Each of the next $j$ lines contains two integers $p1$ and $p2$ (1 ≤ $p1, p2$ ≤ 1000000): the top value and the bottom value of a block.

## Output

Print a single integer: the smallest possible score among all arrangements.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, if we order the blocks as the third block, then the second, then the first, the top values are 1, 2, 3 and the bottom values are 3, 4, 2.

There are 3 possible paths:
- Move down at column 1: cost = 1 + (3 + 4 + 2) = 10
- Move down at column 2: cost = (1 + 2) + (4 + 2) = 9
- Move down at column 3: cost = (1 + 2 + 3) + 2 = 8

The score of this arrangement is the maximum of these costs, which is 10. No other arrangement yields a score strictly less than 10.

In Example 2, there is only 1 block. The grid is 2x1. The only path moves down at column 1. Its cost is 5 + 3 = 8.
