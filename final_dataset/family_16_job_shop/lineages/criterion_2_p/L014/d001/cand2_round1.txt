# Problem B — Two-Row Grid

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given **j** blocks. Each block has a top value **p1** and a bottom value **p2**.

You must arrange all **j** blocks in a sequence from left to right to form a grid with 2 rows and **j** columns. The top values of the blocks form the first row of the grid, and the bottom values form the second row. You may choose the left-to-right order of the blocks, but you cannot flip them upside down (**p1** remains in the top row, **p2** in the bottom row).

Consider a path starting at the top-left cell of the grid and ending at the bottom-right cell. You can only move right (to the next cell in the same row) or down (to the cell directly below in the same column). The cost of a path is the sum of the values in all the cells it visits, including the start and end cells.

The *score* of your grid is the maximum cost among all valid paths from the top-left to the bottom-right. 

Find an arrangement of the **j** blocks that makes the score of the grid as small as possible. Report this smallest possible score.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the top value and the bottom value of a block.

## Output

Print a single integer: the smallest possible score of the grid.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal arrangement is to place the third block first, the second block second, and the first block third. 
The grid becomes:
```
1 2 3
3 4 2
```
There are three valid paths from top-left to bottom-right:
- Move down at column 1, then right: 1 + 3 + 4 + 2 = 10
- Move right to column 2, down, then right: 1 + 2 + 4 + 2 = 9
- Move right to column 3, then down: 1 + 2 + 3 + 2 = 8

The score of this grid is the maximum of these path costs, which is 10. No arrangement yields a score smaller than 10.
