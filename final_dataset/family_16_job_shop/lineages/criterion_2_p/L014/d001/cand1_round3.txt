# Problem B — Two-Stage Baking

Time limit: 1 s   Memory limit: 256 MB

## Description

A bakery must fulfill **j** custom cake requests. Fulfilling each request involves exactly three sequential steps: preparation, inspection, and finishing. All preparation is handled by the head chef, all inspection is handled by the floor manager, and all finishing is handled by the assistant. For each request, you are given the duration of its preparation phase and the duration of its finishing phase. The inspection step always takes exactly 0 time for every request.

The rules of the kitchen are:
- The head chef, the floor manager, and the assistant each process only one request at a time.
- A request can start its inspection only after it has finished preparation, and it can start finishing only after it has finished inspection.
- You may choose the sequence in which the requests are processed, but all three staff members must process the requests in the exact same chosen sequence.

Choose the processing sequence so that the time at which the **last** request completes its finishing phase is as small as possible. Report that smallest possible finish time. If multiple sequences achieve this minimum, output only that minimum finish time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the preparation time and the finishing time of a request.

## Output

Print a single integer: the smallest possible time at which the **last** request completes its finishing phase.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single request takes 5 for preparation, 0 for inspection, and 3 for finishing, completing at time 8.

<RATIONALE>
Changed the scenario from a 2-workstation process to a 3-step process (preparation, inspection, finishing) where the middle step is explicitly stated to take exactly 0 time. This mathematically preserves the exact 2-machine flow-shop makespan while breaking the surface pattern of "two workstations", forcing models to genuinely reason that the 0-time middle stage reduces the problem back to a 2-stage process where Johnson's rule applies, rather than matching on keywords.
</RATIONALE>
<PRESERVED_ANSWER>
The middle inspection stage takes exactly 0 time and its worker is never a bottleneck, so the completion time of every sequence is mathematically identical to the original 2-stage process.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to a 2-machine flow-shop makespan minimization, which is solvable optimally in O(n log n) time using Johnson's rule.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the 0-time stage as allowing concurrent processing, though the rules explicitly forbid it by stating each staff member processes one request at a time in a strictly sequential order.
</RISK>
