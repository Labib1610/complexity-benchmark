# Problem B — Two-Stage Propagation

Time limit: 1 s
Memory limit: 256 MB

## Description

A computational simulation tracks the propagation of **j** signals through a two-layer relay. Each signal requires an inner delay and an outer delay. You must choose a permutation of the **j** given signals to feed into the simulation.

For your chosen sequence, let $x_i$ and $y_i$ be the inner and outer delays of the signal at position $i$ (where $1 \le i \le j$). The simulation calculates two timestamps for each signal in the sequence:

- The inner arrival time $T_{in}(i)$ is the sum of the inner delays of all signals up to position $i$:
  $T_{in}(i) = T_{in}(i-1) + x_i$
  
- The outer arrival time $T_{out}(i)$ is defined recursively as:
  $T_{out}(i) = \max(T_{in}(i), T_{out}(i-1)) + y_i$

The base cases are $T_{in}(0) = 0$ and $T_{out}(0) = 0$.

Your task is to determine the optimal ordering of the **j** signals that minimizes the final outer arrival time, $T_{out}(j)$. Report this minimum possible value.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **x** and **y** (1 ≤ x, y ≤ 1000000): the inner delay and the outer delay of a signal.

## Output

Print a single integer: the smallest possible value of $T_{out}(j)$ across all valid permutations of the signals.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only $j = 1$ signal. Its inner arrival time is $T_{in}(1) = T_{in}(0) + 5 = 5$. Its outer arrival time is $T_{out}(1) = \max(T_{in}(1), T_{out}(0)) + 3 = \max(5, 0) + 3 = 8$.
