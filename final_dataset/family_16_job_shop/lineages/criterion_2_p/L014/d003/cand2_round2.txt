# Problem B — Two-Stage Protocol

Time limit: 1 s
Memory limit: 256 MB

## Description

You have **j** data packets to transmit. Each packet has a header size and a payload size. 
You must arrange all **j** packets into a single sequence for transmission.

Let your chosen sequence of packets be $P_1, P_2, \dots, P_j$. Let $H_k$ and $L_k$ denote the header size and the payload size, respectively, of the packet at position $k$ in this sequence.

The transmission protocol defines a completion time $C_k$ for each packet $P_k$ in your sequence. This is calculated sequentially as follows:
- The completion time $C_1$ of the first packet $P_1$ is $H_1 + L_1$.
- For each subsequent packet $P_k$ (where $2 \le k \le j$), its completion time $C_k$ is its payload size $L_k$ plus the maximum of the following two values:
  1. The completion time of the preceding packet, $C_{k-1}$.
  2. The sum of the header sizes of all packets from $P_1$ up to $P_k$ inclusive (i.e., $\sum_{i=1}^k H_i$).

Your task is to determine the optimal sequence of the **j** packets that minimizes $C_j$, the completion time of the final packet. Print this minimum possible completion time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the header size and the payload size of a packet.

## Output

Print a single integer: the smallest possible completion time $C_j$ of the final packet.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one packet. Its header size is 5 and payload size is 3. The completion time is simply $C_1 = 5 + 3 = 8$.

In Example 1, an optimal sequence places the third packet first, then the second, then the first.
- $P_1$ has header 1, payload 3. $C_1 = 1 + 3 = 4$.
- $P_2$ has header 2, payload 4. $C_2 = 4 + \max(4, 1+2) = 4 + 4 = 8$.
- $P_3$ has header 3, payload 2. $C_3 = 2 + \max(8, 1+2+3) = 2 + 8 = 10$.
