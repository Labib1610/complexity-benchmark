# Problem B — Drone Track Routing

Time limit: 1 s
Memory limit: 256 MB

## Description

You are planning a mission involving two autonomous drones: a Scout and a Hauler. The mission requires them to process $j$ distinct checkpoints. 

You must program a flight sequence of the $j$ checkpoints for the Scout, and a flight sequence of the $j$ checkpoints for the Hauler. You are entirely free to have the Hauler visit the checkpoints in a completely different order than the Scout, or in the same order. Every checkpoint must be visited exactly once by the Scout and exactly once by the Hauler.

The Scout begins its sequence at time 0. At each checkpoint it visits, it conducts an inspection. For a given checkpoint, this inspection takes exactly **p1** microseconds. Because travel time is instantaneous (0 microseconds), the Scout moves to its next programmed checkpoint and begins inspection immediately upon finishing the previous one.

The Hauler also begins at time 0, following its own programmed sequence. At each checkpoint, the Hauler performs an extraction lasting exactly **p2** microseconds. However, the Hauler's extraction at any specific checkpoint cannot begin until the Scout has fully completed its inspection of that *exact same* checkpoint. The Hauler processes its sequence one checkpoint at a time; it cannot start extraction at the next checkpoint in its sequence until it finishes the current one. If the Hauler is ready to extract at a checkpoint but the Scout has not yet finished inspecting it, the Hauler hovers and waits. Travel time for the Hauler is also instantaneous.

Your goal is to choose a sequence for the Scout and a sequence for the Hauler such that the time the Hauler finishes its final extraction is minimized. Output this minimum possible completion time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000) representing a checkpoint. **p1** is the time required for the Scout's inspection, and **p2** is the time required for the Hauler's extraction.

## Output

Print a single integer: the minimum possible time at which the Hauler finishes its final extraction.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one checkpoint. The Scout drone begins at time 0 and finishes its inspection at time 5. The Hauler drone immediately begins its extraction and finishes at time 5 + 3 = 8.

<RATIONALE>
I explicitly removed the constraint that the two drones must follow the identical sequence of checkpoints, allowing them to follow independent sequences. This forces the model to either deduce or know the scheduling theorem that permutation schedules are dominant for 2-machine flow shops before it can safely apply the intended O(N log N) algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
By a well-known theorem in scheduling theory, the optimal makespan for a 2-machine flow shop is always achieved by a permutation schedule (where both machines process jobs in the exact same order), so allowing different sequences does not reduce the minimum possible completion time.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Because the optimal answer is still achieved by the optimal permutation schedule, the problem is still perfectly solved by Johnson's rule in O(j log j) time, remaining in P.
</PRESERVED_CLASS>
<RISK>
Models might consider the problem ambiguous if they doubt whether the Hauler can "skip" checkpoints to wait for others, but the statement strictly specifies "The Hauler processes its sequence one checkpoint at a time; it cannot start extraction at the next checkpoint in its sequence until it finishes the current one," preventing any ambiguity.
</RISK>
