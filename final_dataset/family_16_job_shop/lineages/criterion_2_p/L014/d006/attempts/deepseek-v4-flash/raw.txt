We have $j$ checkpoints, each with two times:  
- $p1$: time for Scout to inspect  
- $p2$: time for Hauler to extract  

We can reorder the checkpoints arbitrarily.  
For a given order, the completion time is:

\[
\max_{1 \le k \le j} \left( \sum_{i=1}^k p1_i + \sum_{i=k}^j p2_i \right)
\]

We want to minimize this maximum over all permutations.

---

### Key observation
If we fix an order, the expression can be rewritten as:

Let  
- $S_k = \sum_{i=1}^k p1_i$  
- $T_k = \sum_{i=k}^j p2_i$  

Then the value is $\max_k (S_k + T_k)$.

We can think of this as:  
For each checkpoint, the contribution to the sum at position $k$ is:  
- If checkpoint is before or at $k$, it contributes $p1$  
- If checkpoint is at or after $k$, it contributes $p2$  

So for each checkpoint, it contributes either $p1$ or $p2$ depending on where the "cut" $k$ is.

---

### Optimal ordering strategy
A known greedy approach:  
Sort checkpoints by **decreasing** $p2$ (or equivalently, by decreasing $p1 - p2$).  
This is similar to the classic "minimum makespan with two machines" scheduling problem (Johnson's rule for two machines).

For two-machine flow shop scheduling, the optimal order is:  
- Jobs with $p1 \le p2$ are sorted by increasing $p1$  
- Jobs with $p1 > p2$ are sorted by decreasing $p2$  
Then concatenate: first the $p1 \le p2$ group, then the $p1 > p2$ group.

---

### Implementation
We'll implement Johnson's rule:

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    jobs = []
    idx = 1
    for _ in range(j):
        p1 = int(data[idx])
        p2 = int(data[idx+1])
        idx += 2
        jobs.append((p1, p2))
    
    # Johnson's rule
    left = []  # p1 <= p2, sort by p1 ascending
    right = [] # p1 > p2, sort by p2 descending
    for p1, p2 in jobs:
        if p1 <= p2:
            left.append((p1, p2))
        else:
            right.append((p1, p2))
    
    left.sort(key=lambda x: x[0])
    right.sort(key=lambda x: -x[1])
    
    order = left + right
    
    # Compute minimal max time
    scout_time = 0
    total_p2 = sum(p2 for _, p2 in order)
    max_time = 0
    for p1, p2 in order:
        scout_time += p1
        total_p2 -= p2
        max_time = max(max_time, scout_time + total_p2)
    
    print(max_time)

if __name__ == "__main__":
    main()
```
