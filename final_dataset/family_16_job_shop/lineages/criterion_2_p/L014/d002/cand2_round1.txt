# Problem B — Two-Stage Baking

Time limit: 1 s   Memory limit: 256 MB

## Description

A bakery must fulfill **j** custom cake requests. Fulfilling a request involves a baking phase of **p1** minutes, and a subsequent decorating phase of **p2** minutes.

There is one oven and one icing station. You must arrange the requests into a single, fixed lineup. The preparation proceeds according to these operational rules:
- The oven and the icing station both become operational at minute 0.
- Whenever the oven is unoccupied, it immediately accepts the next request from your lineup that has not yet entered the oven.
- Whenever the icing station is unoccupied, it immediately accepts the request appearing earliest in your lineup that has finished its baking phase but has not yet begun its decorating phase.
- A phase cannot be paused or interrupted once it begins.

Your goal is to arrange the lineup to minimize the time at which the final request finishes its decorating phase. Output this minimum possible preparation time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the baking time and the decorating time of a request.

## Output

Print a single integer: the smallest possible time at which all requests are finished.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one request. The oven begins baking at minute 0 and finishes at minute 5. The icing station is unoccupied and the request has finished baking, so decorating begins at minute 5 and finishes at minute 8.

<RATIONALE>
The explicit recurrence relation and the direct definition of a permutation two-machine flow-shop were removed. The mechanics are now presented as an event-driven state transition, forcing the model to deduce the underlying flow-shop structure and recurrence before it can recognize the applicability of Johnson's rule.
</RATIONALE>
<PRESERVED_ANSWER>
Because baking times are strictly positive, requests always finish baking in the exact order of the lineup, which guarantees the icing station processes them in that identical permutation and yields the exact same completion times as the original recurrence.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding the optimal sequence to minimize the makespan of a two-machine flow-shop, which is solvable in O(N log N) time using Johnson's algorithm.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the icing station rule as allowing non-permutation schedules (where the icing station processes requests in a different order than the oven), though the strict positive baking times actually make this impossible.
</RISK>
