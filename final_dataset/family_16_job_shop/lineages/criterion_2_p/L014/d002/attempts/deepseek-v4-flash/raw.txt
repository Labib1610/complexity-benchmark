We can model this as a scheduling problem.  
The key is to sort the orders so that the total completion time is minimized.  

A known optimal strategy for two machines in series (mixing then frosting) is to sort by **decreasing frosting time** when the first machine is the bottleneck, but here we need to consider both.  
The optimal order is to sort by **p2 descending**, and if equal, by **p1 descending**.  

Here’s the implementation:  

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    orders = []
    idx = 1
    for _ in range(j):
        p1 = int(data[idx])
        p2 = int(data[idx+1])
        orders.append((p1, p2))
        idx += 2

    # Sort by p2 descending, then p1 descending
    orders.sort(key=lambda x: (-x[1], -x[0]))

    mixer_time = 0
    froster_time = 0
    for p1, p2 in orders:
        mixer_time += p1
        if froster_time < mixer_time:
            froster_time = mixer_time
        froster_time += p2

    print(froster_time)

if __name__ == "__main__":
    main()
```
