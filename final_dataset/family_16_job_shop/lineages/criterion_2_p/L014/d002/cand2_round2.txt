# Problem B — Two-Stage Baking

Time limit: 1 s   Memory limit: 256 MB

## Description

A bakery must process **j** custom cake orders. Each order requires **p1** minutes of baking followed by **p2** minutes of decorating.
There is a single oven and a single icing station. Each piece of equipment can handle at most one order at a time.

You must choose a single sequence for the **j** orders. Both the oven and the icing station will process all orders strictly in this exact chosen sequence.

The operation follows an event-driven timeline:
- The oven begins at time 0, drawing the first order from your sequence. It processes orders continuously; as soon as it finishes baking an order, it immediately starts the next one in the sequence.
- An order becomes available for decorating the exact moment its baking phase is complete.
- The icing station processes available orders one by one, strictly adhering to your chosen sequence. It begins decorating an order as soon as both the station is idle and the order has finished baking.

Your task is to determine the sequence of the **j** orders that minimizes the time when the final order finishes decorating. Report this smallest possible finish time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the baking time and the decorating time of an order.

## Output

Print a single integer: the smallest possible time at which all orders are finished.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one order. It finishes baking at minute 5, and finishes decorating at minute 5 + 3 = 8.
