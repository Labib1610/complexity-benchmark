# Problem B — Tile Grid Paths

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a set of **j** rectangular tiles. Each tile is divided into a top half and a bottom half, and each half contains a positive integer.

You must arrange all **j** tiles in a single row from left to right. This arrangement forms a grid with exactly 2 rows and **j** columns, where the top halves of the tiles form the first row and the bottom halves form the second row.

Consider a token placed on the top-left cell of this grid. The token must travel to the bottom-right cell. From any cell, the token can only move exactly one cell to the right, or exactly one cell down. It is not allowed to move left or up. 

The cost of a path taken by the token is the sum of the integers in all the cells it visits, including the starting and ending cells. Because the token must move down exactly once, there are exactly **j** different valid paths it could take, each corresponding to the column where it makes its downward move.

Your goal is to choose the left-to-right order of the **j** tiles such that the maximum possible path cost is minimized. Output this minimum possible value for the maximum path cost.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the integer on the top half and the integer on the bottom half of the tile, respectively.

## Output

Print a single integer: the smallest possible maximum path cost achievable by optimally ordering the tiles.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal arrangement is to place the third tile first, then the second, then the first. The resulting grid is:
Row 1: 1, 2, 3
Row 2: 3, 4, 2

The token can take 3 possible paths:
- Move down at column 1: visits values 1, 3, 4, 2. Path cost = 1 + 3 + 4 + 2 = 10.
- Move down at column 2: visits values 1, 2, 4, 2. Path cost = 1 + 2 + 4 + 2 = 9.
- Move down at column 3: visits values 1, 2, 3, 2. Path cost = 1 + 2 + 3 + 2 = 8.

The maximum path cost for this arrangement is 10. No arrangement of the tiles can result in a maximum path cost strictly less than 10.

In Example 2, the grid has only 1 column. The only path visits the top cell (5) and the bottom cell (3), with a cost of 8.
