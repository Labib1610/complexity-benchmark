# Problem B — Component Processing Sequence

Time limit: 1 s   Memory limit: 256 MB

## Description

A factory must process a batch of **j** components. You must arrange the components into a single production sequence.

The processing requires two sequential stages, handled by the Primary Forging Station and the Secondary Tempering Station. Each component must first be processed by the Primary Forging Station and then by the Secondary Tempering Station.

The operations strictly follow these rules:
- You must choose a single sequence for the components. Both stations will process the components in this exact same sequence.
- The Primary Forging Station processes components one at a time. It begins the first component at time 0 and operates continuously, starting each subsequent component the instant the previous one finishes.
- The Secondary Tempering Station processes components one at a time. It can only begin working on a component after that specific component has completely finished at the Primary Forging Station.
- The Secondary Tempering Station never sits idle if a component is ready and the station is free. It starts the next component exactly at the moment it becomes available or the moment the station finishes the previous component, whichever is later.

For each component, you are given the processing time **p1** it requires at the Primary Forging Station, and the processing time **p2** it requires at the Secondary Tempering Station.

Formally, the exact completion time at the Secondary Tempering Station is determined recursively. Let $C_1, C_2, \dots, C_j$ be your chosen sequence of components. Let $p1(C_i)$ and $p2(C_i)$ be the processing times of component $C_i$.
Because the Primary Forging Station operates continuously from time 0, the $k$-th component finishes its primary processing at time $A_k$:
$A_k = \sum_{i=1}^k p1(C_i)$

Because the Secondary Tempering Station must wait for both the component's primary processing to finish and the previous component's secondary processing to finish, it completes the $k$-th component at time $B_k$:
$B_1 = A_1 + p2(C_1)$
$B_k = \max(A_k, B_{k-1}) + p2(C_k)$ for $k \ge 2$.

Determine the optimal sequence of components to minimize the time at which the Secondary Tempering Station completes the final component. Output this minimum possible final completion time (the minimum possible value of $B_j$).

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the processing times required for a component at the Primary Forging Station and the Secondary Tempering Station, respectively.

## Output

Print a single integer: the smallest possible time at which the final component completes its tempering.

## Examples

```
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2


**Output**


### Example 3


**Output**


## Note

In Example 1, one optimal sequence is to process the 3rd component, then the 1st, then the 2nd. 
For this sequence $C = [3, 1, 2]$:
- $C_1$ (Component 3): $p1 = 1, p2 = 3$
- $C_2$ (Component 1): $p1 = 3, p2 = 2$
- $C_3$ (Component 2): $p1 = 2, p2 = 4$

Primary completion times ($A_k$):
- $A_1 = 1$
- $A_2 = 1 + 3 = 4$
- $A_3 = 4 + 2 = 6$

Secondary completion times ($B_k$):
- $B_1 = 1 + 3 = 4$
- $B_2 = \max(4, 4) + 2 = 6$
- $B_3 = \max(6, 6) + 4 = 10$

The final completion time $B_3$ is 10.

In Example 2, the single component takes 5 at the Primary Forging Station and 3 at the Secondary Tempering Station. Its primary completion is $A_1 = 5$, and its secondary completion is $B_1 = 5 + 3 = 8$.
