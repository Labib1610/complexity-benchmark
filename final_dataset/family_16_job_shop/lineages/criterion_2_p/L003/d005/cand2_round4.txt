# Problem B — Array Pivot Peak

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a collection of **j** elements. Each element has two associated integer values: a left-weight **p1** and a right-weight **p2**.

You must arrange all **j** elements into a single sequence. Let the chosen sequence be denoted by $E_1, E_2, \dots, E_j$.

For any chosen sequence, we can compute a "pivot sum" for every index $k$ ($1 \le k \le j$). The pivot sum at index $k$ is defined as the sum of the **p1** values for all elements from position $1$ to $k$ inclusive, plus the sum of the **p2** values for all elements from position $k$ to $j$ inclusive. 

The *peak value* of a sequence is the maximum pivot sum out of all $j$ possible choices for the index $k$.

Your task is to determine the optimal sequence of elements that minimizes this peak value. Output the minimum possible peak value.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the left-weight and right-weight of an element, respectively.

## Output

Print a single integer: the smallest possible peak value achievable by any arrangement of the elements.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one element. The pivot sum for index 1 is the sum of the **p1** values from position 1 to 1 (which is 5), plus the sum of the **p2** values from position 1 to 1 (which is 3). The peak value is 5 + 3 = 8.

I stripped away all domain-specific scheduling terminology (machines, processing, queues, idle time) and replaced it with an exact algebraic equivalent. The makespan of a 2-machine permutation flow shop is mathematically identical to the maximum over all $k$ of the prefix sum of the first stage plus the suffix sum of the second stage. By presenting the problem purely as array partitioning and summation, models cannot rely on keyword matching to trigger Johnson's rule and must derive the equivalence from first principles. Exact literal numeric bounds were restored to comply with expert feedback.
</RATIONALE>
