# Problem B — Grid Path Optimization

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given **j** tiles, each consisting of a top value and a bottom value. The $i$-th tile has a top value **p1** and a bottom value **p2**.

You must arrange all **j** tiles in a single sequence from left to right. This arrangement forms a grid with 2 rows and **j** columns. 

Once the sequence is chosen, consider all valid paths from the top-left cell (the top value of your first tile) to the bottom-right cell (the bottom value of your last tile) that only move right and down. 

There are exactly **j** valid paths. For any column $k$ ($1 \le k \le j$), a path visits the top cells of columns $1$ through $k$, moves down, and then visits the bottom cells of columns $k$ through $j$.

The cost of a path is the sum of the values of all the cells it visits. The score of your chosen sequence is the maximum cost among all **j** valid paths.

Your objective is to find an arrangement of the **j** tiles that minimizes this score. Output the minimum possible score.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the top value and the bottom value of a tile, respectively.

## Output

Print a single integer: the minimum possible score.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal sequence is to place the 3rd tile first, then the 2nd tile, then the 1st tile.
The top row of the grid becomes: 1, 2, 3.
The bottom row of the grid becomes: 3, 4, 2.

There are 3 valid paths:
- **Path 1** (moves down at column 1): visits top 1st, bottom 1st, bottom 2nd, bottom 3rd. Cost = 1 + 3 + 4 + 2 = 10.
- **Path 2** (moves down at column 2): visits top 1st, top 2nd, bottom 2nd, bottom 3rd. Cost = 1 + 2 + 4 + 2 = 9.
- **Path 3** (moves down at column 3): visits top 1st, top 2nd, top 3rd, bottom 3rd. Cost = 1 + 2 + 3 + 2 = 8.

The maximum path cost for this sequence is 10. No other arrangement yields a maximum path cost smaller than 10.

In Example 2, there is only 1 tile. The only path visits the top value 5 and the bottom value 3, for a total cost of 8.
