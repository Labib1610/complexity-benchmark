# Problem B — Theater Festival Schedule

Time limit: 1 s   Memory limit: 256 MB

## Description

A theater company is hosting a festival featuring **j** distinct short plays. Each play consists of two parts: a stage performance, and a subsequent post-play discussion in the lobby.

The festival operates under the following structural rules:
- The stage can only host one performance at any given moment.
- The lobby can only host one discussion at any given moment.
- A play's lobby discussion cannot begin until its stage performance has completely finished.
- If the lobby is currently occupied by a discussion, a play that has finished its stage performance will simply wait until the lobby becomes available.
- The stage does not wait for the lobby; it can immediately begin the performance of the next play in the sequence.
- The festival organizers must dictate a single sequence for all plays. The stage performances occur in this sequence, and the lobby discussions must also occur in this exact same sequence.

For each play, the duration required for its stage performance and the duration required for its lobby discussion are provided. Based on these rules, you must establish the sequence of plays that minimizes the total elapsed time from the moment the first stage performance begins to the moment the final lobby discussion is fully completed. Output this minimum possible completion time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the durations required for a play's stage performance and its lobby discussion, respectively.

## Output

Print a single integer: the smallest possible time at which all plays (both performance and discussion) are fully completed.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single play requires 5 for the stage performance and then 3 for the lobby discussion, finishing at time 8.
