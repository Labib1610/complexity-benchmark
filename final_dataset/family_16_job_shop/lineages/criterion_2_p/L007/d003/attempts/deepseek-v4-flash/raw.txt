We can model this as a two-machine scheduling problem (historian = machine 1, conservator = machine 2) with a single queue (chute) that preserves order. This is exactly the classic **Johnson's rule** for minimizing makespan in a two-machine flow shop.

The optimal order is:
- All jobs with `p1 <= p2` are scheduled first, sorted by `p1` ascending.
- Then all jobs with `p1 > p2` are scheduled, sorted by `p2` descending.

Then we simulate the process to get the completion time.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    j = int(data[0])
    jobs = []
    idx = 1
    for _ in range(j):
        p1 = int(data[idx])
        p2 = int(data[idx+1])
        idx += 2
        jobs.append((p1, p2))
    
    # Johnson's rule
    first = []
    second = []
    for p1, p2 in jobs:
        if p1 <= p2:
            first.append((p1, p2))
        else:
            second.append((p1, p2))
    
    first.sort(key=lambda x: x[0])  # ascending p1
    second.sort(key=lambda x: -x[1])  # descending p2
    
    order = first + second
    
    # Simulate
    t_hist = 0
    t_cons = 0
    for p1, p2 in order:
        t_hist += p1
        if t_cons < t_hist:
            t_cons = t_hist
        t_cons += p2
    
    print(t_cons)

if __name__ == "__main__":
    main()
```
