<STATEMENT>
# Archival Restoration

Time limit: 1 s   Memory limit: 256 MB

## Description

An archive has recently acquired **j** ancient manuscripts. You must arrange them into a single initial stack.

The archivist begins at time zero, takes the top manuscript from your stack, spends **p1** minutes transcribing it, and then immediately places it onto a single-lane gravity conveyor. Travel time down the conveyor is instantaneous. At the other end, a conservator retrieves the arriving manuscripts. The conservator spends **p2** minutes binding a manuscript before taking the next one. 

The workflow is governed by these physical constraints:
- Both the archivist and the conservator can only work on one manuscript at a time.
- The archivist works continuously as long as there are manuscripts in your initial stack.
- The conveyor has plenty of space, but because it is strictly single-lane, manuscripts cannot pass each other. The conservator therefore receives them in the exact order they were placed on the conveyor.
- The conservator works continuously as long as there is at least one manuscript waiting at the end of the conveyor. 

Determine the initial stacking arrangement of the manuscripts that minimizes the time when the conservator finishes binding the final manuscript. Report this minimum completion time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the duration required for the archivist to transcribe the manuscript, and the duration required for the conservator to bind it, respectively.

## Output

Print a single integer: the smallest possible time at which the conservator finishes the last manuscript.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single manuscript takes 5 minutes for the archivist to transcribe and then 3 minutes for the conservator to bind, finishing at minute 8.

<RATIONALE>
I removed explicit scheduling terminology like "two-phase restoration" and the direct rule that "both specialists process the manuscripts in exactly that same sequence". Instead, I framed the restriction as a physical constraint—a single-lane gravity conveyor—which forces the models to deduce logically that the non-passing physical environment mathematically mandates a single permutation flow-shop, preventing them from bypassing the reasoning step via keyword pattern-matching.
</RATIONALE>
