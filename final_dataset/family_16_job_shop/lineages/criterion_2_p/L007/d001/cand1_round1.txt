<STATEMENT>
# Archival Restoration

Time limit: 1 s   Memory limit: 256 MB

## Description

An archive has recently acquired **j** ancient manuscripts. Each manuscript must undergo a two-phase restoration process: first, it must be transcribed by the master calligrapher; second, it must be bound by the head bookbinder.

The restoration follows these strict protocols:
- The calligrapher works on transcribing only one manuscript at a time.
- The bookbinder works on binding only one manuscript at a time.
- The bookbinder can only begin binding a specific manuscript after the calligrapher has completely finished transcribing it.
- The calligrapher and the bookbinder may each process the collection of manuscripts in whatever order they choose; they are not required to follow the same sequence.

Determine the processing orders for both workers that minimize the time at which the bookbinder finishes the final manuscript. Report this minimum possible completion time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the time required for the calligrapher to transcribe the manuscript, and the time required for the bookbinder to bind it, respectively.

## Output

Print a single integer: the smallest possible time at which the bookbinder finishes the last manuscript.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single manuscript takes 5 units of time to transcribe and then 3 units of time to bind, finishing at time 8.
</STATEMENT>
<RATIONALE>
Removed the explicit requirement that both workers must process the manuscripts in the identical sequence, replacing it with the freedom to choose independent sequences. This invalidates the superficial pattern-match to the "permutation flow-shop" problem, forcing models to genuinely reason about the schedule structure and recognize that the optimal makespan for a 2-stage pipeline is always achieved by a permutation schedule. (The suggested reverse-order requirement was discarded because it mathematically changes the optimal makespan to the sum of all processing times, violating the identical-answers constraint).
</RATIONALE>
<PRESERVED_ANSWER>
A fundamental theorem of scheduling states that for a 2-machine flow shop, the minimum makespan over all independent sequence pairs is identical to the minimum makespan over identical (permutation) sequences, so the optimal time remains exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The optimal completion time is still found by applying Johnson's rule to find the optimal permutation sequence, keeping the problem in P with an O(j log j) solution.
</PRESERVED_CLASS>
<RISK>
Models might assume that since independent sequences are allowed, the problem is NP-hard (like the 3-machine flow shop), but the wording is unambiguous and the mathematical equivalence to the permutation flow shop holds.
</RISK>
