# Archival Restoration

Time limit: 1 s   Memory limit: 256 MB

## Description

An archive has recently acquired **j** ancient manuscripts. Each manuscript must undergo a two-phase restoration process: first, it must be transcribed by the master calligrapher; second, it must be bound by the head bookbinder.

The restoration follows these strict protocols:
- The calligrapher works on transcribing only one manuscript at a time.
- The bookbinder works on binding only one manuscript at a time.
- The bookbinder can only begin binding a specific manuscript after the calligrapher has completely finished transcribing it.
- You must arrange the manuscripts into a single initial queue. Because the workspace is a narrow corridor where items cannot bypass one another, the bookbinder will inevitably receive and process the manuscripts in the exact order that you arranged them for the calligrapher.

Determine the initial arrangement of manuscripts that minimizes the time at which the bookbinder finishes the final manuscript. Report this minimum possible completion time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the time required for the calligrapher to transcribe the manuscript, and the time required for the bookbinder to bind it, respectively.

## Output

Print a single integer: the smallest possible time at which the bookbinder finishes the last manuscript.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single manuscript takes 5 units of time to transcribe and then 3 units of time to bind, finishing at time 8.

<RATIONALE>
Replaced the explicit requirement that both workers use the "exact same chosen sequence" with a physical "narrow corridor" constraint that prevents items from bypassing one another. This removes the keyword phrasing that models used to immediately recognize the permutation flow-shop formulation, requiring them to logically deduce that the no-bypass rule equates to identical processing orders.
</RATIONALE>
<PRESERVED_ANSWER>
The narrow corridor rule strictly enforces that the second phase processes items in the identical order as the first phase, mathematically preserving the exact permutation schedule constraint and optimal makespans of the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying mathematical model remains exactly the 2-machine permutation flow-shop makespan problem, which is optimally solvable in O(j log j) time via Johnson's algorithm, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the narrow corridor constraint as implying physical transit times or fixed distances between manuscripts, though the wording clarifies it only determines the order of processing.
</RISK>
