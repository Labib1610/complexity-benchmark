<STATEMENT>
# Archival Restoration

Time limit: 1 s   Memory limit: 256 MB

## Description

An archive has recently acquired **j** ancient manuscripts. The restoration of each manuscript strictly requires two consecutive phases: transcription by the master calligrapher, followed by securing the pages by the head bookbinder.

The physical layout of the archive dictates how the work proceeds:
- The calligrapher may only transcribe one manuscript at a time.
- The bookbinder may only secure one manuscript at a time.
- You must establish the sequence in which the calligrapher initiates work on the manuscripts.
- The workstations are connected by a slender gravity chute. The instant the calligrapher completes a transcription, the manuscript is released into the chute and immediately slides to the lowest available position.
- The bookbinder draws manuscripts directly from the chute's lower exit. Because the chute is perfectly narrow, manuscripts cannot slide past one another while waiting. The bookbinder must accept and process the available manuscript at the exit before reaching any that follow.

Calculate the optimal sequence for the calligrapher to minimize the total elapsed time until the bookbinder completes the final manuscript, and output this minimum time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the time required for the calligrapher to transcribe the manuscript, and the time required for the bookbinder to secure it, respectively.

## Output

Print a single integer: the smallest possible time at which the bookbinder finishes the last manuscript.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single manuscript takes 5 units of time to transcribe and then 3 units of time to secure, finishing at time 8.
