# Problem B — Cargo Inspection

Time limit: 1 s   Memory limit: 256 MB

## Description

A port authority must clear a fleet of **j** vessels through a two-step cargo inspection. First, the Local Desk evaluates a vessel. Once done, the vessel proceeds to the Federal Desk. You are given the evaluation duration required at the Local Desk and the Federal Desk for each vessel.

To manage congestion, the port enforces a rigid convoy system. You must organize the vessels into a single convoy sequence. 

The operational constraints are:
- The Local Desk processes vessels one by one, strictly following your chosen convoy sequence. It begins evaluating the next vessel immediately after finishing the current one.
- After finishing at the Local Desk, a vessel waits in a single-file canal until the Federal Desk is ready for it.
- Because the canal is strictly single-file, vessels cannot bypass each other. The Federal Desk is therefore forced to process the vessels in the exact same convoy sequence. 
- The Federal Desk handles one vessel at a time. It begins evaluating a vessel as soon as both the desk is unoccupied and that vessel has arrived from the Local Desk.

Determine the optimal convoy sequence to minimize the time when the last vessel in the fleet departs the Federal Desk. Output this minimum completion time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the time required for a vessel to be evaluated at the Local Desk and the Federal Desk, respectively.

## Output

Print a single integer: the earliest possible time at which the entire fleet has cleared the Federal Desk.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single vessel takes 5 to clear the Local Desk and then 3 to clear the Federal Desk, departing at time 8.

<RATIONALE>
The problem was rewritten to disguise the standard two-machine permutation flow-shop wording. Instead of using abstract scheduling rules ("identical order requirement", "holding area"), the identical-order constraint is enforced physically via a "single-file canal" and a "convoy sequence". This forces models to reason about the physical bottlenecks and precedence constraints rather than pattern-matching the exact phrasing of Johnson's rule.
</RATIONALE>
<PRESERVED_ANSWER>
The objective is still to minimize the makespan of a two-stage sequential process where both stages process items in the exact same chosen order without interruption, so the optimal schedule length is mathematically identical to the seed.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
