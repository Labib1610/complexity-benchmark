# Problem B — Cargo Inspection

Time limit: 1 s   Memory limit: 256 MB

## Description

A port authority manages a fleet of **j** vessels arriving for cargo inspection. Every vessel requires two consecutive stages of inspection: first at the Local Desk, and then at the Federal Desk. You are given the duration each vessel takes at the Local Desk, followed by the duration it takes at the Federal Desk.

The operational rules are:
- A desk processes exactly one vessel at a time without interruption.
- A vessel can begin its Federal Desk inspection only after its Local Desk inspection is completely finished.
- Vessels that have cleared the Local Desk enter a holding pool. The Federal Desk is not required to process vessels in the order they arrived; whenever it is ready, it may select any vessel currently waiting in the pool.
- The Local Desk is free to accept the next vessel as soon as the current one finishes.

You must design a complete inspection schedule—assigning start times for every vessel at both desks—that minimizes the time at which the final vessel finishes its Federal Desk inspection. Output this minimum possible finish time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the duration required for a vessel to complete the Local Desk and the Federal Desk inspections, respectively.

## Output

Print a single integer: the smallest possible time at which all vessels have completely finished the Federal Desk inspection.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single vessel takes 5 to complete the Local Desk and then 3 to complete the Federal Desk, finishing at time 8.
</STATEMENT>
<RATIONALE>
Removed the strict requirement that vessels must be processed by the second desk in the exact same order as the first desk. By explicitly allowing the second desk to choose any waiting vessel, the problem no longer perfectly textually matches the restricted permutation flow shop definition, forcing models to either recognize that permutation schedules are dominant for two machines or attempt a flawed dynamic scheduling approach.
</RATIONALE>
<PRESERVED_ANSWER>
For a two-machine flow shop minimizing makespan, it is mathematically proven that permutation schedules (identical order on both machines) are a dominant set, meaning the absolute minimum makespan across all possible schedules is exactly equal to the minimum permutation makespan.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains solvable in O(N log N) using Johnson's algorithm, as the optimal schedule is guaranteed to be a permutation schedule that Johnson's rule finds.
</PRESERVED_CLASS>
<RISK>
Models might assume that because the second desk can reorder vessels, they must simulate an open pool to find the optimal schedule, but this is a deliberate trap rather than an ambiguity in the rules themselves.
</RISK>
