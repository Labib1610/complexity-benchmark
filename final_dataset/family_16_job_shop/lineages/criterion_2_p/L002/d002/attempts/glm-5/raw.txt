Looking at this problem, I need to find the optimal ordering of vessels through two sequential stages (Local Desk then Federal Desk), where the Federal Desk processes vessels in the same order they began at the Local Desk.

This is the classic two-machine flow shop scheduling problem (Johnson's rule).

**Key insight:** For each vessel, the Local Desk can start processing the next vessel immediately after the current one finishes (no idle time between vessels at Local Desk). So if vessels are ordered 1, 2, ..., j, the Local Desk completion times are cumulative sums of p1 values.

The Federal Desk for vessel i starts at max(LocalDeskFinish[i], FederalDeskFinish[i-1]).

**Johnson's Rule:** Sort vessels by:
- Vessels with p1 ≤ p2 first, sorted by p1 ascending
- Vessels with p1 > p2 second, sorted by p2 descending

This minimizes the makespan.

Let me verify with Example 1:
- Vessels: (3,2), (2,4), (1,3)
- p1 ≤ p2: (2,4), (1,3) → sort by p1 asc: (1,3), (2,4)
- p1 > p2: (3,2) → sort by p2 desc: (3,2)
- Order: (1,3), (2,4), (3,2)

Local Desk finish times: 1, 3, 6
Federal Desk:
- Vessel 1: starts at 1, finishes at 1+3=4
- Vessel 2: starts at max(3,4)=4, finishes at 4+4=8
- Vessel 3: starts at max(6,8)=8, finishes at 8+2=10 ✓

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    idx = 0
    j = int(data[idx]); idx += 1
    
    group1 = []  # p1 <= p2, sort by p1 ascending
    group2 = []  # p1 > p2, sort by p2 descending
    
    for _ in range(j):
        p1 = int(data[idx]); idx += 1
        p2 = int(data[idx]); idx += 1
        if p1 <= p2:
            group1.append((p1, p2))
        else:
            group2.append((p1, p2))
    
    group1.sort(key=lambda x: x[0])
    group2.sort(key=lambda x: x[1], reverse=True)
    
    local_finish = 0
    federal_finish = 0
    
    for p1, p2 in group1:
        local_finish += p1
        federal_finish = max(federal_finish, local_finish) + p2
    
    for p1, p2 in group2:
        local_finish += p1
        federal_finish = max(federal_finish, local_finish) + p2
    
    print(federal_finish)

main()
```
