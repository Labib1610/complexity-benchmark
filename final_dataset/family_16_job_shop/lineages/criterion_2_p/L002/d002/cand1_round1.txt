# Problem B — Canal Sequence

Time limit: 1 s   Memory limit: 256 MB

## Description

A port master must organize a fleet of vessels into a single-file formation to navigate a restricted waterway. The waterway consists of two sequential facilities: the Primary Toll Station, followed by the Secondary Customs House.

The transit follows these physical constraints:
- Each facility can handle exactly one vessel at any given moment.
- Every vessel must fully conclude its processing at the Primary Toll Station before it can begin processing at the Secondary Customs House.
- After finishing at the Primary Toll Station, a vessel enters a narrow connecting channel to wait until the Secondary Customs House is available. The Primary Toll Station is immediately freed to accept the next vessel in the formation.
- Because the connecting channel is strictly single-lane without any room to overtake, the vessels will inevitably arrive at and be processed by the Secondary Customs House in the exact same formation order as they entered the Primary Toll Station.

The port master must decide the initial formation of the fleet. The goal is to choose the formation that ensures the final vessel concludes its processing at the Secondary Customs House at the earliest possible time. Calculate and report this minimum possible completion time.

## Input

The first line contains a single integer **j**, representing the number of vessels in the fleet. The port's registry database guarantees the fleet contains at least one vessel, and its structural table limit caps the fleet size at exactly two hundred thousand vessels.

Each of the subsequent **j** lines contains two integers **p1** and **p2**. These represent the processing durations for that vessel at the Primary Toll Station and the Secondary Customs House, respectively. The technical specifications of the facilities mean any operation takes a minimum of one time unit, while a strict system timeout prevents any single operation from exceeding exactly one million time units.

## Output

Print a single integer: the earliest possible time at which the entire fleet has finished processing at the Secondary Customs House.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single vessel takes 5 time units to finish at the Primary Toll Station and then 3 time units to finish at the Secondary Customs House, completing its transit at time 8.
