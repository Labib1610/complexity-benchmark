# Problem B — Regulatory Backlog

Time limit: 1 s   Memory limit: 256 MB

## Description

A corporate oversight board needs to finalize $j$ pending corporate mergers. Every merger must undergo two consecutive phases of automated scrutiny: first, an anti-trust review by the monolithic AI *Argus*, and subsequently, a financial stress-test by the monolithic AI *Midas*. You are provided with the time Argus requires to evaluate each merger, followed by the time Midas requires to evaluate it.

The regulatory framework imposes the following strict conditions:
- Argus can only process one merger at a time.
- Midas can only process one merger at a time.
- Midas can only begin its evaluation of a merger after Argus has completely finished reviewing that specific merger.
- Once Argus completes a merger, it is immediately placed in a pending docket for Midas, and Argus is free to begin the next merger without delay.
- By law, Midas must process the mergers from the pending docket in the exact same sequence that they were originally submitted to Argus.

You must determine the initial sequence in which the $j$ mergers are submitted to Argus. Your goal is to choose a sequence that minimizes the exact time at which Midas completely finishes the final merger in the sequence. Report this minimum possible completion time.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the time required for Argus to review the merger, and the time required for Midas to review the merger, respectively.

## Output

Print a single integer: the smallest possible time at which Midas has completely finished reviewing all mergers.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, the optimal submission sequence is the third merger, followed by the second, and finally the first.
- **Third merger:** Argus processes it from time 0 to 1. Midas processes it from time 1 to 4.
- **Second merger:** Argus processes it from time 1 to 3. Midas processes it from time 4 to 8.
- **First merger:** Argus processes it from time 3 to 6. Midas must wait until time 8 (when it finishes the second merger) to begin. It processes the first merger from time 8 to 10.
The final merger finishes at time 10.

In Example 2, the single merger takes 5 units of time with Argus and 3 with Midas, finishing at time 8.
