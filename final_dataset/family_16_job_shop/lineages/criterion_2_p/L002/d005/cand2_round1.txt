<STATEMENT>
# Problem B — Card Split Game

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a deck of **j** cards. Each card has two positive integers printed on it: a red value (denoted **p1**) and a blue value (denoted **p2**).

You must arrange all **j** cards in a single row from left to right. Let this arrangement be $C_1, C_2, \dots, C_j$.

After you arrange the cards, an adversary will examine your row and choose a single split point $k$, where $1 \le k \le j$.
The adversary's score is calculated as the sum of the red values on all cards from the start of the row up to and including $C_k$, plus the sum of the blue values on all cards from $C_k$ to the end of the row (inclusive).

Mathematically, for a chosen $k$, the score is:
$$ \text{Score}(k) = \sum_{i=1}^k \text{red}(C_i) + \sum_{i=k}^j \text{blue}(C_i) $$

The adversary will always choose the split point $k$ that maximizes their score.
Your objective is to find an initial arrangement of the cards that minimizes this maximum possible score.

Output the smallest possible score the adversary can be forced to take.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the red value and the blue value for that card, respectively.

## Output

Print a single integer: the minimum possible score the adversary can achieve if you arrange the cards optimally.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal arrangement is to place the third card first, then the second card, and finally the first card. The row is:
- $C_1$: red = 1, blue = 3
- $C_2$: red = 2, blue = 4
- $C_3$: red = 3, blue = 2

If the adversary chooses $k=1$, their score is:
(red of $C_1$) + (blue of $C_1, C_2, C_3$) = $1 + (3 + 4 + 2) = 10$.

If the adversary chooses $k=2$, their score is:
(red of $C_1, C_2$) + (blue of $C_2, C_3$) = $(1 + 2) + (4 + 2) = 9$.

If the adversary chooses $k=3$, their score is:
(red of $C_1, C_2, C_3$) + (blue of $C_3$) = $(1 + 2 + 3) + 2 = 8$.

The adversary plays optimally and will choose $k=1$ to get a score of 10. No other arrangement of the cards can force a lower maximum score, so the answer is 10.

In Example 2, there is only one card. The only possible split point is $k=1$, giving a score of $5 + 3 = 8$.

<RATIONALE>
The problem was completely re-contextualized from a two-phase sequential scheduling task into a discrete minimax array game. The mathematical equivalence relies on the fact that the makespan of a two-machine flow shop is exactly equal to the maximum over all $k$ of the prefix sum of machine 1 up to $k$ plus the suffix sum of machine 2 from $k$. By presenting the exact formula algebraically rather than as a scheduling process, models can no longer trigger Johnson's rule through semantic association with "processing phases" or "completion times," forcing them to either derive the pairwise exchange argument from scratch or fail.
</RATIONALE>
<PRESERVED_ANSWER>
The makespan of a two-machine flow shop recursively defined as $F_k = \max(F_{k-1}, L_k) + p_{2,k}$ expands exactly to the minimax equation $\max_{1 \le k \le j} (\sum_{i=1}^k p_{1,i} + \sum_{i=k}^j p_{2,i})$, meaning the objective function evaluated on every permutation is mathematically identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Because the objective function evaluates to the exact same value for every permutation as the original makespan calculation, the optimal permutation is still found using Johnson's algorithm in O(j log j) time.
</PRESERVED_CLASS>
