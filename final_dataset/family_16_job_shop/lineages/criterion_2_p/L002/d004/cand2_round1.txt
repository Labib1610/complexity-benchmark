# Problem B — Cargo Inspection

Time limit: 1 s   Memory limit: 256 MB

## Description

A port authority must arrange $j$ cargo containers in a single row. Each container has two inspection values: a top value and a bottom value.

When you place all $j$ containers in a horizontal sequence from left to right, you create a grid with 2 rows and $j$ columns. The top values form the first row, and the bottom values form the second row.

A scanner starts at the top-left cell of this grid and must travel to the bottom-right cell. At each step, the scanner can only move one cell to the right or one cell down. Because the grid has exactly two rows, any valid path will travel rightwards along the top row up to some column $k$ ($1 \le k \le j$), move down to the bottom row at that same column $k$, and then travel rightwards along the bottom row until the final column $j$.

The score of a path is defined as the sum of the values in all the cells the scanner visits. For any sequence of containers you choose, the scanner will always take the path that results in the **maximum** possible score.

Your goal is to choose the initial left-to-right sequence of the $j$ containers such that this maximum possible score is **minimized**. Output this minimum possible score.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the top value and the bottom value of a container, respectively.

## Output

Print a single integer: the smallest possible maximum path score you can achieve by optimally ordering the containers.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, if you arrange the containers in the order of the third input, then the second, then the first, the grid becomes:
Top row: 1, 2, 3
Bottom row: 3, 4, 2

There are three possible paths for the scanner:
- Move down at column 1: visits 1, 3, 4, 2. Score = 10.
- Move down at column 2: visits 1, 2, 4, 2. Score = 9.
- Move down at column 3: visits 1, 2, 3, 2. Score = 8.

The scanner takes the maximum score, which is 10. No other sequence of containers can produce a maximum score lower than 10.

<PRESERVED_ANSWER>
The maximum path sum on a 2xN grid where a downward move occurs at column k is exactly the completion time of job k on the second machine in a 2-machine flow shop, making the min-max objective mathematically identical to minimizing the makespan.
