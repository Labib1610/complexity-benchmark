# Problem B — Cargo Sequence

Time limit: 1 s   Memory limit: 256 MB

## Description

A logistics company must process **j** specialized cargo modules. Each module requires a preparation phase at the origin facility and a finalization phase at the destination facility.

- The origin facility has only one bay, meaning it prepares one module at a time.
- The destination facility also has only one bay, meaning it finalizes one module at a time.
- A module's finalization phase cannot commence until its preparation phase has entirely concluded.
- The modules are moved from the origin to the destination by attaching them to a single continuous towing cable. Because they are fixed to the cable, the destination bay receives and must process the modules in the exact sequence they were prepared. There is ample staging space at the destination to hold modules if they arrive before the bay is free, and the travel time between facilities is zero.

You are given the preparation duration and finalization duration for each of the **j** modules. Determine the earliest possible moment that the finalization phase of the last module is completed, assuming you choose the optimal sequence to attach them to the cable.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the preparation duration and finalization duration of a module.

## Output

Print a single integer: the earliest possible time at which all modules finish their finalization phase.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single module takes 5 for preparation then 3 for finalization, finishing at time 8.

The explicit mentions of "exactly two operations" and "the same order for all containers" were replaced with a physical scenario involving an origin facility, a destination facility, and a single continuous towing cable. This forces models to deduce the permutation flow-shop constraints from the mechanical properties of the cable and staging area rather than triggering on standard scheduling terminology.
</RATIONALE>
