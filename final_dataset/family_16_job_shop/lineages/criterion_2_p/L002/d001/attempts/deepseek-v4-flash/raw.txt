We can model this as a scheduling problem.  
For each ship, we have two processing times: upper lock time and lower lock time.  
The order matters because the lower lock can only start after the upper lock finishes for that ship, and ships must maintain order.

The optimal order is to sort ships by their lower lock time in descending order (similar to Johnson’s rule for two-machine flow shop).  
Then we simulate the process to get the total completion time.

Here’s the Python solution:

```python
n = int(input())
ships = []
for _ in range(n):
    a, b = map(int, input().split())
    ships.append((a, b))

# Sort by lower lock time descending
ships.sort(key=lambda x: x[1], reverse=True)

upper_time = 0
lower_time = 0
for a, b in ships:
    upper_time += a
    lower_time = max(lower_time, upper_time) + b

print(lower_time)
```
