# Problem B — Battery Testing Sequence

Time limit: 1 s   Memory limit: 256 MB

## Description

You are testing a prototype power battery using **j** different diagnostic applications. The battery starts with 0 units of stored power and has no upper limit on its capacity.

Each application has two parameters: a power requirement **p1** and a power generation **p2**.
When you run an application, the following two steps happen in exact order:
1. The application consumes **p1** units of power. It takes as much of this as possible from the battery. If the battery currently holds less than **p1** units, the battery is completely drained to 0, and the deficit is seamlessly covered by an external power grid.
2. The application then generates **p2** units of power, which are added directly to the battery.

You must run all **j** applications exactly once, in a single sequence of your choosing.

The overall "inefficiency rating" of your test sequence is defined as the total power requirements of all applications (the sum of all **p1** values) plus the final amount of power remaining in the battery after all **j** applications have finished.

Find an execution order for the applications that makes this inefficiency rating as small as possible. Report this minimum possible inefficiency rating.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the power requirement and the power generation of an application.

## Output

Print a single integer: the minimum possible inefficiency rating.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, an optimal arrangement runs the applications in the order of the 3rd, 2nd, and 1st from the input.
- The total power requirement of all applications is $3 + 2 + 1 = 6$.
- The battery starts at 0.
- For the 3rd input application ($p1=1, p2=3$): The battery has 0. It needs 1, so the deficit of 1 is covered by the grid. The battery then generates 3, ending at 3.
- For the 2nd input application ($p1=2, p2=4$): The battery has 3. It consumes 2, leaving 1. It then generates 4, ending at $1 + 4 = 5$.
- For the 1st input application ($p1=3, p2=2$): The battery has 5. It consumes 3, leaving 2. It then generates 2, ending at $2 + 2 = 4$.
The final amount of power in the battery is 4.
The inefficiency rating is $6 + 4 = 10$.
