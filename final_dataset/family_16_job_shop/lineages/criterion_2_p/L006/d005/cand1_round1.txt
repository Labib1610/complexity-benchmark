# Problem B — Linear Structure Assembly

Time limit: 1 s   Memory limit: 256 MB

## Description

You are assembling a linear composite structure using **j** components. Each component consists of a primary segment of length **p1** and a secondary segment of length **p2**.

You must arrange all **j** components into a single sequence. Let the chosen permutation place the components into positions $1, 2, \dots, j$, where $p1_i$ and $p2_i$ are the parameters for the component assigned to position $i$.

The structural stability is evaluated by tracking a "stress offset" $D$ along the assembly.
- At the start of the assembly, the initial stress offset is $D_0 = 0$.
- As each component $i$ (from $1$ to $j$) is added, the stress offset is updated. The primary segment acts to relieve existing stress, reducing the offset by $p1_i$ (but the offset cannot become negative). The secondary segment then introduces new stress, increasing the offset by $p2_i$.
- Formally, the stress offset after the $i$-th component is given by the deterministic recurrence:
  $D_i = \max(0, D_{i-1} - p1_i) + p2_i$.

The total architectural footprint of the assembled structure is calculated as the sum of the primary segment lengths of all **j** components, plus the final stress offset $D_j$.

Find a permutation of the components that makes the final architectural footprint as small as possible. Report this minimum possible footprint value.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the primary length and the secondary length of a component.

## Output

Print a single integer: the minimum possible value of the final architectural footprint.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, an optimal arrangement places the components in the order of the 3rd, 2nd, and 1st from the input.
- Sum of all primary lengths: $3 + 2 + 1 = 6$.
- For the 3rd input component ($p1=1, p2=3$) at position 1: $D_1 = \max(0, 0 - 1) + 3 = 3$.
- For the 2nd input component ($p1=2, p2=4$) at position 2: $D_2 = \max(0, 3 - 2) + 4 = 5$.
- For the 1st input component ($p1=3, p2=2$) at position 3: $D_3 = \max(0, 5 - 3) + 2 = 4$.
The final architectural footprint is the sum of primary lengths (6) plus the final stress offset $D_3$ (4), which equals 10.
