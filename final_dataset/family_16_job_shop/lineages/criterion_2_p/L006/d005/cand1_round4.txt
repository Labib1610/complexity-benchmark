<STATEMENT>
# Problem B — Linear Structure Assembly

Time limit: 1 s   Memory limit: 256 MB

## Description

You are assembling a linear composite structure using **j** components. Each component consists of a primary segment of length **p1** and a secondary segment of length **p2**.

You must arrange all **j** components into a single sequence. Let the chosen permutation place the components into positions $1, 2, \dots, j$, where $p1_i$ and $p2_i$ are the lengths for the component assigned to position $i$.

The layout of the structure is completely defined by two sequences of coordinates along an axis: the primary endpoints $X_i$ and the secondary endpoints $Y_i$. 
- The starting coordinates are $X_0 = 0$ and $Y_0 = 0$.
- For each position $i$ from $1$ to $j$:
  - The primary segment of component $i$ is placed immediately after the primary segment of component $i-1$. Its endpoint is therefore $X_i = X_{i-1} + p1_i$.
  - The secondary segment of component $i$ spans an interval of length $p2_i$. The left end of this interval cannot be strictly less than $X_i$, nor can it be strictly less than $Y_{i-1}$. To keep the structure compact, the left end is chosen to be the minimum possible coordinate that satisfies both restrictions. The right end of this interval is $Y_i$.

No other spatial constraints or physical rules apply; only these coordinate rules define the layout and the objective.

Find a permutation of the components that makes the final secondary endpoint $Y_j$ as small as possible. Report this minimum possible value of $Y_j$.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the primary length and the secondary length of a component.

## Output

Print a single integer: the minimum possible value of the final secondary endpoint $Y_j$.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, an optimal arrangement places the components in the order of the 3rd, 2nd, and 1st from the input.
- For the 3rd input component ($p1=1, p2=3$) at position 1: $X_1 = 0 + 1 = 1$. The secondary segment must start at a coordinate $\ge 1$ and $\ge 0$. The minimum valid starting coordinate is $1$, so it ends at $Y_1 = 1 + 3 = 4$.
- For the 2nd input component ($p1=2, p2=4$) at position 2: $X_2 = 1 + 2 = 3$. The secondary segment must start at a coordinate $\ge 3$ and $\ge 4$. The minimum valid starting coordinate is $4$, so it ends at $Y_2 = 4 + 4 = 8$.
- For the 1st input component ($p1=3, p2=2$) at position 3: $X_3 = 3 + 3 = 6$. The secondary segment must start at a coordinate $\ge 6$ and $\ge 8$. The minimum valid starting coordinate is $8$, so it ends at $Y_3 = 8 + 2 = 10$.
The final secondary endpoint $Y_3$ is 10.
</STATEMENT>
<RATIONALE>
The explicit `max(X_i, Y_{i-1})` formula was replaced with equivalent geometric interval constraints ("cannot be strictly less than... minimum possible coordinate"). This forces models to logically deduce the recurrence relation rather than triggering a surface-level pattern match for the two-machine flow-shop makespan formula.
</RATIONALE>
<PRESERVED_ANSWER>
The starting coordinate of the secondary segment is defined as the minimum value $\ge X_i$ and $\ge Y_{i-1}$, which is exactly mathematically equivalent to $\max(X_i, Y_{i-1})$, preserving all coordinate calculations exactly.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying mathematical model remains an identical two-machine flow-shop scheduling problem, which is still solvable in $O(j \log j)$ time using Johnson's rule.
</PRESERVED_CLASS>
<RISK>
A model might misunderstand "cannot be strictly less than" and attempt to assign a starting coordinate that is arbitrarily large, but the instruction "minimum possible coordinate that satisfies both restrictions" unambiguously uniquely defines the exact starting point.
</RISK>
