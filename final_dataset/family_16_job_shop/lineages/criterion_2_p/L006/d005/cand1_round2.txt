# Problem B — Linear Structure Assembly

Time limit: 1 s   Memory limit: 256 MB

## Description

You are assembling a linear composite structure using **j** components. Each component consists of a primary segment of length **p1** and a secondary segment of length **p2**.

You must arrange all **j** components into a single sequence. The layout of the structure is determined by tracking two advancing markers along a coordinate axis: the primary marker and the secondary marker.

- Before any components are placed, both markers are at coordinate 0.
- You process the components one by one in the exact order of your chosen permutation.
- For each component in the sequence:
  - The primary marker is shifted forward by the component's primary length, **p1**.
  - The component's secondary segment must then be positioned. Its starting coordinate is restricted: it cannot be placed at a coordinate smaller than the new position of the primary marker, nor can it be placed at a coordinate smaller than the current position of the secondary marker.
  - To keep the assembly as compact as possible, the secondary segment begins exactly at the smallest coordinate that satisfies both restrictions. The secondary marker is then updated to the end of this secondary segment (i.e., its starting coordinate plus its length **p2**).

Find a permutation of the components that makes the final coordinate of the secondary marker as small as possible. Report this minimum possible coordinate.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the primary length and the secondary length of a component.

## Output

Print a single integer: the minimum possible final coordinate of the secondary marker.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal arrangement places the components in the order of the 3rd, 2nd, and 1st from the input.
- For the 3rd input component (**p1**=1, **p2**=3): The primary marker shifts forward by 1 to coordinate 1. The secondary segment must start at ≥ 1 (primary marker) and ≥ 0 (secondary marker). The smallest valid coordinate is 1. The secondary marker updates to 1 + 3 = 4.
- For the 2nd input component (**p1**=2, **p2**=4): The primary marker shifts forward by 2 to coordinate 3. The secondary segment must start at ≥ 3 and ≥ 4. The smallest valid coordinate is 4. The secondary marker updates to 4 + 4 = 8.
- For the 1st input component (**p1**=3, **p2**=2): The primary marker shifts forward by 3 to coordinate 6. The secondary segment must start at ≥ 6 and ≥ 8. The smallest valid coordinate is 8. The secondary marker updates to 8 + 2 = 10.
The final secondary marker is at coordinate 10.

<RATIONALE>
The seed exposed the two-machine flow-shop recurrence explicitly via the mathematical formula `Y_i = max(X_i, Y_{i-1}) + p2_i`. Models pattern-matched this equation directly to Johnson's rule. This rewrite removes the explicit algebraic `max` function and replaces it with a procedural geometric description ("smallest coordinate that satisfies both restrictions"). This forces models to synthesize the constraint logic themselves rather than relying on mathematical pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The condition "smallest coordinate $\ge X$ and $\ge Y$" is mathematically identical to $\max(X, Y)$, ensuring the marker updates compute the exact same values as the original recurrence.
</PRESERVED_ANSWER>
