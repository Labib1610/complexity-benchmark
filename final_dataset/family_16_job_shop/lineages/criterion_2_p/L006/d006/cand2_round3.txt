# Problem B — Pipeline Bottleneck Sequence

Time limit: 1 s   Memory limit: 256 MB

## Description

You are configuring a data pipeline consisting of **j** modules. The pipeline starts with 0 initial load and has no upper limit on its accumulated totals.

Each module has exactly two parameters: a phase-one metric **p1** and a phase-two metric **p2**.
The pipeline's bottleneck evaluation involves exactly two stages of calculation. First, choose a single sequence where each of the **j** modules is placed exactly once. Then, for any chosen split point **k** (where 1 ≤ **k** ≤ **j**), the "split-point score" is calculated by adding two terms:
1. Stage one: The sum of the **p1** values for all modules from position 1 to position **k** inclusive.
2. Stage two: The sum of the **p2** values for all modules from position **k** to position **j** inclusive.

The module at position **k** contributes to both terms: it is included in the prefix **p1** sum and in the suffix **p2** sum.

The overall "bottleneck rating" of your chosen sequence is the maximum split-point score across all **j** possible choices of **k**.

Find an execution order for the modules that makes this bottleneck rating as small as possible. Report this minimum possible bottleneck rating.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the phase-one metric and the phase-two metric of a module.

## Output

Print a single integer: the minimum possible bottleneck rating.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1

```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, an optimal arrangement runs the modules in the order of the 3rd, 2nd, and 1st from the input.
- The pipeline starts with 0 initial load.
- For split point k=1 (the 3rd input module, p1=1, p2=3): Stage one sum is 1. Stage two sum is 3 + 4 + 2 = 9. The split-point score is 1 + 9 = 10.
- For split point k=2 (the 2nd input module, p1=2, p2=4): Stage one sum is 1 + 2 = 3. Stage two sum is 4 + 2 = 6. The split-point score is 3 + 6 = 9.
- For split point k=3 (the 1st input module, p1=3, p2=2): Stage one sum is 1 + 2 + 3 = 6. Stage two sum is 2. The split-point score is 6 + 2 = 8.
The overall bottleneck rating is the maximum of these split-point scores, which is 10.
