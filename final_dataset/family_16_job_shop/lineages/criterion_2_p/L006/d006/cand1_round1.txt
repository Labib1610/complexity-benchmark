# Problem B — Sequence Pivot Score

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given **j** data blocks. Each block has two attributes: a left-weight **p1** and a right-weight **p2**.

You must arrange all **j** blocks into a single sequence of your choosing.

Once the sequence is chosen, we evaluate its "pivot score". To find the pivot score, we consider all **j** possible choices for a pivot block. If the block at position **k** (where $1 \le k \le j$) is chosen as the pivot, the cost is calculated as:
- The sum of the left-weights (**p1**) of all blocks from position $1$ up to and including position **k**.
- Plus the sum of the right-weights (**p2**) of all blocks from position **k** up to and including position **j**.

The overall pivot score of your sequence is the maximum cost among all **j** possible pivot choices.

Find an arrangement of the blocks that makes this pivot score as small as possible. Report this minimum possible pivot score.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the left-weight and the right-weight of a block.

## Output

Print a single integer: the minimum possible pivot score.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, an optimal arrangement places the blocks in the order of the 3rd, 2nd, and 1st from the input.
The chosen sequence of blocks is:
- Position 1: (p1=1, p2=3)
- Position 2: (p1=2, p2=4)
- Position 3: (p1=3, p2=2)

We calculate the cost for each possible pivot position **k**:
- If **k** = 1 (pivot is the 1st block):
  Left-weight sum (up to 1): 1
  Right-weight sum (from 1 to 3): 3 + 4 + 2 = 9
  Cost = 1 + 9 = 10
- If **k** = 2 (pivot is the 2nd block):
  Left-weight sum (up to 2): 1 + 2 = 3
  Right-weight sum (from 2 to 3): 4 + 2 = 6
  Cost = 3 + 6 = 9
- If **k** = 3 (pivot is the 3rd block):
  Left-weight sum (up to 3): 1 + 2 + 3 = 6
  Right-weight sum (from 3 to 3): 2
  Cost = 6 + 2 = 8

The pivot score of this sequence is the maximum of these costs, which is $\max(10, 9, 8) = 10$.
This is the minimum possible pivot score among all arrangements.
