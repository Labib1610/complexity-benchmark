<STATEMENT>
# Problem B — Chemical Batch Optimization

Time limit: 1 s   Memory limit: 256 MB

## Description

You are conducting a chemical experiment involving two vats, Vat 1 and Vat 2. Both vats initially contain exactly 0 milliliters of solution.

You have a set of **j** chemical additives to introduce into the vats. Each additive is defined by two integer parameters: a primary volume **A** and a secondary volume **B**.

You must choose a single sequence in which to process all **j** additives. For each additive in your chosen sequence, you perform the following three steps in exactly this order:
1. You pour **A** milliliters of solution into Vat 1, where **A** is the primary volume of the current additive.
2. You observe the current volumes in both vats. If Vat 1 contains strictly more solution than Vat 2, you pour extra solution into Vat 2 until its volume exactly matches the volume in Vat 1. (If Vat 2 already contains an equal or greater volume than Vat 1, you do nothing in this step).
3. You pour **B** milliliters of solution into Vat 2, where **B** is the secondary volume of the current additive.

Your goal is to arrange the additives in an order that makes the final volume of solution in Vat 2 as small as possible. Find this optimal sequence and report the resulting smallest possible final volume in Vat 2.

## Input

The first line contains a single integer **j**, representing the number of additives. As dictated by the laboratory's batch limits, **j** is at least 1 and at most the number of seconds in exactly 2 days, 7 hours, 33 minutes, and 20 seconds.
Each of the next **j** lines contains two integers **A** and **B**: the primary and secondary volumes required for that additive. These values are at least 1 and at most the number of cubic centimeters in exactly one cubic meter.

## Output

Print a single integer: the smallest possible final volume of solution in Vat 2.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, an optimal arrangement processes the additives in the order of the 3rd, 2nd, and 1st from the input.
- For the 3rd input additive (A=1, B=3): Vat 1 gets 1 mL (total 1). Vat 2 is matched to 1 mL, then gets 3 mL (total 4).
- For the 2nd input additive (A=2, B=4): Vat 1 gets 2 mL (total 3). Vat 2 has 4 mL, which is ≥ Vat 1, so no matching is needed. Vat 2 gets 4 mL (total 8).
- For the 1st input additive (A=3, B=2): Vat 1 gets 3 mL (total 6). Vat 2 has 8 mL, so no matching is needed. Vat 2 gets 2 mL (total 10).
The final volume in Vat 2 is 10.

<RATIONALE>
The problem was completely reframed from a two-machine flow-shop scheduling task to an isomorphic sequential state machine involving pouring liquids into two vats. By replacing concurrent processing times with sequential variable updates (`V1 += A`, `V2 = max(V2, V1) + B`), the underlying Johnson's rule recurrence is perfectly preserved, but all domain keywords (scheduling, machines, time, makespan) are removed. Additionally, numeric bounds are stated indirectly using physical unit conversions (S07) to prevent simple pattern matching on standard constraint ranges.
</RATIONALE>
