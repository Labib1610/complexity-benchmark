**Key Insight:** Let me define $d_i = p1_i - p2_i$ for each component. 

The recurrence is:

- $Y_i = \max(X_i, Y_{i-1}) + p2_i$

Let me track the "gap" $g_i = Y_i - X_i$:
- If $X_i \geq Y_{i-1}$ (i.e., $p1_i \geq g_{i-1}$): $Y_i = X_i + p2_i$, so $g_i = p2_i$
- If $X_i < Y_{i-1}$ (i.e., $p1_i < g_{i-1}$): $Y_i = Y_{i-1} + p2_i = X_{i-1} + g_{i-1} + p2_i$, so $g_i = g_{i-1} + p2_i - p1_i = g_{i-1} - d_i$

So: $g_i = \max(p2_i, g_{i-1} - d_i)$

**Optimal Strategy:** Components with $d_i \geq 0$ (i.e., $p1_i \geq p2_i$) can only decrease or reset the gap. Components with $d_i < 0$ can only increase the gap (unless the gap resets to $p2_i$).

For $d_i \geq 0$ components: place them in decreasing order of $d_i$ (largest $d_i$ first to reduce gap quickly, smallest $d_i$ last to minimize final gap).

For $d_i < 0$ components: place them in increasing order of $p2_i$ (smallest $p2_i$ first to minimize gap reset, and since $d_i < 0$, the gap grows by $|d_i|$ regardless of order when not resetting).

**Order:** All $d_i \geq 0$ components first (sorted by $d_i$ descending), then all $d_i < 0$ components (sorted by $p2_i$ ascending).

import sys

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    j = int(input_data[idx]); idx += 1
    
    neg = []  # d < 0
    nonneg = []  # d >= 0
    
    for _ in range(j):
        p1 = int(input_data[idx]); idx += 1
        p2 = int(input_data[idx]); idx += 1
        d = p1 - p2
        if d < 0:
            neg.append((p2, p1, d))
        else:
            nonneg.append((d, p2, p1))
    
    neg.sort(key=lambda x: x[0])  # sort by p2 ascending
    nonneg.sort(key=lambda x: -x[0])  # sort by d descending
    
    g = 0
    X = 0
    
    for p2, p1, d in neg:
        X += p1
        g = max(p2, g - d)
    
    for d, p2, p1 in nonneg:
        X += p1
        g = max(p2, g - d)
    
    print(X + g)

solve()
