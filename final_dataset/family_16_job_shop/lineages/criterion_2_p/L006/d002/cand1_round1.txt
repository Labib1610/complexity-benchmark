# Problem B — Spaceport Clearance

Time limit: 1 s   Memory limit: 256 MB

## Description

For each of **j** starships you are given its required atmospheric entry duration and landing protocol duration.

You must arrange the **j** starships into a single ordered sequence. During the event, a continuous broadcast will track the fleet. The broadcast switches its focus from atmospheric entry to landing protocol at exactly one position **k** in the sequence (where **k** is an index from 1 to **j**).

The total broadcast time for a chosen switch point **k** is defined as:
- The sum of the atmospheric entry durations of all starships from position 1 up to and including position **k**, PLUS
- The sum of the landing protocol durations of all starships from position **k** up to and including position **j**.

Because the broadcast network must reserve enough time to cover the worst-case switch point, the reserved time for a given sequence is the **maximum** total broadcast time among all possible choices of **k** (from 1 to **j**).

You may choose the sequence of the starships. Choose the sequence so that this reserved time is as small as possible. Report that smallest possible reserved time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the atmospheric entry and landing protocol durations of a starship.

## Output

Print a single integer: the smallest possible reserved time for the optimal sequence.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2 there is only one starship. The broadcast switches at position **k**=1, taking 5 for atmospheric entry and 3 for the landing protocol, for a total reserved time of 8.

The model must now mathematically deduce that minimizing this maximum sum over all pivot points is identical to minimizing the makespan of a permutation flow-shop before it can apply the optimal sorting strategy.
</RATIONALE>

The prefix/suffix sum maximum for a given sequence is mathematically identical to the makespan of that sequence in a 2-machine permutation flow-shop, ensuring the optimal cost and all examples remain exactly the same.
</PRESERVED_ANSWER>
