# Problem B — Gemstone Refraction

Time limit: 1 s   Memory limit: 256 MB

## Description

You are designing a magical barrier using **j** rectangular gemstone tiles. Each tile has two properties: a top facet resistance and a bottom facet resistance.

The rules for the barrier are:
- You must arrange all **j** tiles in a single horizontal row. Let the positions in your arrangement be numbered 1 to **j** from left to right. You may choose the order in which the tiles are placed.
- A beam of light will enter the top facet of the tile at position 1. It travels rightward through the top facets.
- At some position **k** (where 1 ≤ **k** ≤ **j**), the beam will refract downwards into the bottom facet of that same tile.
- After refracting at position **k**, it continues rightward through the bottom facets until it exits the tile at position **j**.
- The total resistance the beam encounters is the sum of the top facet resistances of the tiles from position 1 up to position **k**, plus the sum of the bottom facet resistances of the tiles from position **k** up to position **j** (inclusive).

The beam is adversarial: once you have arranged the tiles, the beam will naturally refract at the specific position **k** that results in the **maximum** possible total resistance. 

Your goal is to choose the left-to-right sequence of the tiles to make this maximum possible resistance as small as possible. Report that smallest possible maximum resistance.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the top facet resistance and the bottom facet resistance of a tile.

## Output

Print a single integer: the smallest possible maximum resistance the beam can achieve.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, if you arrange the tiles in the sequence of the 3rd, then 2nd, then 1st tile from the input, the top facet resistances from left to right are 1, 2, 3 and the bottom facet resistances are 3, 4, 2.
- If the beam refracts at position k=1, the resistance is 1 + (3+4+2) = 10.
- If it refracts at position k=2, the resistance is (1+2) + (4+2) = 9.
- If it refracts at position k=3, the resistance is (1+2+3) + 2 = 8.
The beam maximizes the resistance by choosing k=1, resulting in 10. There is no arrangement of the tiles that forces the maximum resistance to be strictly less than 10.

In Example 2, there is only 1 tile. The beam must refract at position k=1. It encounters the top facet (5) and the bottom facet (3), for a total resistance of 8.
