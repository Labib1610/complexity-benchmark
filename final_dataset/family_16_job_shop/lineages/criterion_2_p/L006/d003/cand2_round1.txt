# Problem B — Spaceport Clearance

Time limit: 1 s   Memory limit: 256 MB

## Description

You are managing the arrival of **j** starships. Each starship has an atmospheric entry duration (**p1**) and a landing duration (**p2**).

You must arrange all **j** starships into a single sequence, placing them into positions $1, 2, \dots, j$.

To evaluate a chosen sequence, you process the starships in order and maintain two running tallies: the *entry horizon* $E$ (initially 0) and the *landing horizon* $L$ (initially 0).
For each starship in your sequence, you update the tallies in three steps:
1. Increase the entry horizon $E$ by the starship's atmospheric entry duration $p1$.
2. If the landing horizon $L$ is currently less than $E$, jump $L$ forward so that it equals $E$.
3. Increase the landing horizon $L$ by the starship's landing duration $p2$.

After processing all $j$ starships in your sequence, the final value of the landing horizon $L$ is the overall clearance time.

Find an ordering of the starships that makes the overall clearance time as small as possible, and report this smallest possible time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the atmospheric entry duration and the landing duration of a starship.

## Output

Print a single integer: the smallest possible overall clearance time.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only 1 starship. The entry horizon $E$ increases by 5 to become 5. The landing horizon $L$ (initially 0) is less than 5, so it jumps to 5, then increases by 3 to become 8. The clearance time is 8.
