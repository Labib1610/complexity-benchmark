We can solve this by sorting the trains using Johnson’s rule for two-machine flow shop scheduling to minimize makespan.  

Trains with `p1 < p2` are scheduled first, sorted by `p1` ascending.  
Trains with `p1 >= p2` are scheduled last, sorted by `p2` descending.  

Then we simulate the schedule to get the finish time.  

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    trains = []
    idx = 1
    for _ in range(j):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        trains.append((p1, p2))
    
    first = []
    second = []
    for p1, p2 in trains:
        if p1 < p2:
            first.append((p1, p2))
        else:
            second.append((p1, p2))
    
    first.sort(key=lambda x: x[0])
    second.sort(key=lambda x: -x[1])
    
    order = first + second
    
    t1 = 0
    t2 = 0
    for p1, p2 in order:
        t1 += p1
        if t2 < t1:
            t2 = t1
        t2 += p2
    
    print(t2)

if __name__ == "__main__":
    main()
```
