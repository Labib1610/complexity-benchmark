 We can solve this using Johnson’s rule for two-machine scheduling.  
The idea is:

- Split jobs into two groups:
  - Group A: jobs where `p1 <= p2`
  - Group B: jobs where `p1 > p2`
- Sort Group A by `p1` ascending.
- Sort Group B by `p2` descending.
- Concatenate Group A + Group B.
- Simulate the schedule to compute the makespan.

Here’s the implementation:

```python
n = int(input())
jobs = [tuple(map(int, input().split())) for _ in range(n)]

A = []
B = []
for p1, p2 in jobs:
    if p1 <= p2:
        A.append((p1, p2))
    else:
        B.append((p1, p2))

A.sort(key=lambda x: x[0])
B.sort(key=lambda x: x[1], reverse=True)

order = A + B

time_m1 = 0
time_m2 = 0
for p1, p2 in order:
    time_m1 += p1
    time_m2 = max(time_m1, time_m2) + p2

print(time_m2)
```
