<STATEMENT>
# Crystal Lattice Synthesis

Time limit: 1 s   Memory limit: 256 MB

## Description

You are designing a linear crystal by arranging **j** distinct structural layers. You must choose a single sequence in which to stack these layers from the first to the $j$-th.

Each layer has two properties: an *intrinsic width* (**W**) and a *structural offset* (**O**).

When you place the layers in your chosen sequence, they define two coordinate profiles: the base coordinate $X$ and the outer boundary $Y$. These are determined sequentially for each layer $k$ (from $1$ to $j$):
- The base coordinate of the $k$-th layer, $X_k$, is the sum of the intrinsic widths of all layers up to and including the $k$-th layer.
- The outer boundary of the $k$-th layer, $Y_k$, is calculated as: $Y_k = \max(X_k, Y_{k-1}) + O_k$, where $O_k$ is the structural offset of the $k$-th layer.
- For the purposes of calculating the first layer's outer boundary, assume an initial $Y_0 = 0$.

Your objective is to find an arrangement of the **j** layers that minimizes the final outer boundary, $Y_j$. Output this minimum possible value.

The synthesis chamber has a structural limit: it requires at least one layer to initiate crystallization, and its maximum capacity is exactly 200000 layers.
The properties of each layer are quantized. The intrinsic width and structural offset are always positive integers, and neither can exceed 1000000 units due to the maximum energy output of the forming lasers.

## Input

The first line contains a single integer **j**, representing the number of layers.
Each of the next **j** lines contains two integers **W** and **O**: the intrinsic width and the structural offset of a layer, respectively.

## Output

Print a single integer: the minimum possible value of the final outer boundary $Y_j$.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1

```

**Output**

```

### Example 3

**Input**

3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, an optimal sequence is to order the layers as: (1 3), then (2 4), then (3 2).
- First layer (1 3): $X_1 = 1$. The outer boundary is $Y_1 = \max(1, 0) + 3 = 4$.
- Second layer (2 4): $X_2 = 1 + 2 = 3$. The outer boundary is $Y_2 = \max(3, 4) + 4 = 8$.
- Third layer (3 2): $X_3 = 3 + 3 = 6$. The outer boundary is $Y_3 = \max(6, 8) + 2 = 10$.
The final outer boundary $Y_3$ is 10, which is the minimum possible value.

Replaced the temporal 2-machine flow shop scenario (arrival delays, processing times, queues) with a spatial geometric recurrence (crystal layers, base coordinates, outer boundaries). This forces the model to recognize that the abstract recurrence $Y_k = \max(X_k, Y_{k-1}) + O_k$ is mathematically isomorphic to a flow shop makespan and can be optimized using Johnson's rule, rather than relying on scheduling keywords to trigger the algorithm. The bounds were also moved from bare inequalities into physical constraints in the text.
</RATIONALE>
