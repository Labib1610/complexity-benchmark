<STATEMENT>
# Convoy Ascent

Time limit: 1 s   Memory limit: 256 MB

## Description

You are organizing a convoy of **j** supply vehicles. The route has exactly 2 narrow checkpoints: the valley checkpoint and the ridge checkpoint.

Each vehicle must clear the valley checkpoint before it can proceed to the ridge checkpoint. Because the path is narrow, the vehicles must be assigned a strict departure sequence (a unique rank from 1 to **j** for each vehicle).

For a vehicle assigned rank $k$ (where $k > 1$):
- It cannot begin the valley checkpoint until the vehicle with rank $k-1$ has completely cleared the valley checkpoint.
- It cannot begin the ridge checkpoint until two conditions are met: it must have completely cleared the valley checkpoint, and the vehicle with rank $k-1$ must have completely cleared the ridge checkpoint.

The vehicle with rank 1 begins the valley checkpoint at time 0, and begins the ridge checkpoint immediately after clearing the valley checkpoint.

You are given the transit duration for each vehicle through the valley checkpoint and the ridge checkpoint. Your goal is to assign the ranks to the vehicles such that the time when the vehicle with rank **j** completely clears the ridge checkpoint is minimized. Report this minimum time.

## Input

The first line contains a single integer **j** (1 ≤ **j** ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ **p1**, **p2** ≤ 1000000): the transit durations of a vehicle through the valley checkpoint and the ridge checkpoint.

## Output

Print a single integer: the smallest possible time at which the vehicle with rank **j** clears the ridge checkpoint.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single vehicle takes 5 at the valley checkpoint, then 3 at the ridge checkpoint, clearing it at time 8.
</STATEMENT>
<RATIONALE>
Changed the framing from a "railway with two stages handling trains in the same chosen order" to a "convoy with a strict departure sequence where rank k waits for rank k-1". This forces models to deduce the flow-shop structure from the explicit sequential dependencies rather than pattern-matching "two stages" and "same order".
</RATIONALE>
<PRESERVED_ANSWER>
The dependencies exactly mirror a two-machine flow shop where jobs are sequenced in the same order on both machines, meaning the minimum completion time of the last job is identical to the original makespan.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is mathematically identical to the two-machine flow-shop problem, which remains solvable in O(n log n) time using Johnson's rule.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "begins the ridge checkpoint immediately after clearing the valley checkpoint" for rank 1 as implying travel time between checkpoints is non-zero for other ranks, though the lack of any transit time variable makes this unlikely.
</RISK>
