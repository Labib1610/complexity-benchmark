# Interstellar Fleet Deployment

Time limit: 1 s   Memory limit: 256 MB

## Description

You are coordinating the deployment of **j** starships across a binary wormhole system. The transit consists of exactly two sequential phenomena: the Alpha Rift and the Omega Rift. Every starship must travel through the Alpha Rift first and then the Omega Rift.

For each starship, you are provided its transit duration through the Alpha Rift and the Omega Rift. The physics of the rifts impose the following rules:

- Each rift accommodates only one starship at a time.
- A starship can enter the Omega Rift only after it has completely exited the Alpha Rift.
- You must choose the sequence in which the starships are deployed. Both the Alpha Rift and the Omega Rift must process the starships in this exact same chosen sequence.

To ensure the fleet reaches the vanguard as early as possible, choose the deployment sequence so that the time at which the **last** starship exits the Omega Rift is as small as possible. Report that smallest possible completion time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the transit durations of a starship through the Alpha Rift and the Omega Rift, respectively.

## Output

Print a single integer: the smallest possible time at which the entire fleet has finished traversing the Omega Rift.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single starship takes 5 time units in the Alpha Rift, then 3 time units in the Omega Rift, completing its deployment at time 8.
