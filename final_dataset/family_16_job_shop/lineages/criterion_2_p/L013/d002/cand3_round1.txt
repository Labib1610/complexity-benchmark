<STATEMENT>
# Double-Decker Bridge Inspection

Time limit: 1 s   Memory limit: 256 MB

## Description

You are designing a double-decker bridge made of **j** modular sections. You must arrange these **j** sections in a sequence from west to east.

Each section has an upper deck and a lower deck. For each section, you are given the inspection effort required for its upper deck and its lower deck. 

A maintenance inspector will evaluate the bridge by walking from west to east. The inspector's route follows these rules:
- They always start on the upper deck of the first (westernmost) section.
- At exactly one section **k** (where 1 ≤ **k** ≤ **j**), the inspector will evaluate the upper deck of that section, then immediately use a staircase to descend, and then evaluate the lower deck of that same section **k**.
- For all sections after **k**, the inspector will evaluate only the lower deck, continuing to the easternmost end.

The total effort of the inspector's route is the sum of the upper deck efforts for sections 1 through **k**, plus the sum of the lower deck efforts for sections **k** through **j**.

The "bridge hazard rating" is defined as the MAXIMUM total effort among all **j** possible routes the inspector could choose (i.e., the worst-case route).

You can choose the west-to-east order of the **j** sections. Your goal is to arrange the sections to minimize the bridge hazard rating. Report this smallest possible hazard rating.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the inspection effort for the upper deck and the lower deck of that section.

## Output

Print a single integer: the smallest possible bridge hazard rating.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, if you arrange the sections such that their (upper, lower) efforts are (1, 3), (2, 4), and (3, 2) from west to east, the three possible routes have efforts:
- Descend at section 1: 1 + (3 + 4 + 2) = 10
- Descend at section 2: (1 + 2) + (4 + 2) = 9
- Descend at section 3: (1 + 2 + 3) + 2 = 8
The maximum effort among these routes is 10. This is the minimum possible hazard rating for any arrangement.

<RATIONALE>
The problem was completely reframed from a temporal scheduling task (2-machine flow shop) to a spatial routing task (minimizing the maximum path sum on a 2xN grid). This removes all scheduling terminology like "stages", "waiting", and "processing time", forcing models to mathematically recognize that the 2xN grid path sum over permutations is structurally isomorphic to the flow shop makespan before they can apply Johnson's rule.
</RATIONALE>
<PRESERVED_ANSWER>
The makespan of a 2-machine flow shop is mathematically identical to the maximum path sum in a 2xN grid where columns can be permuted, so the optimal permutation and the resulting minimum value are exactly the same for every input.
</PRESERVED_ANSWER>

The problem remains solvable exactly by Johnson's rule in O(j log j) time, keeping it in the same complexity class.
