# Energy Node Calibration

Time limit: 1 s   Memory limit: 256 MB

## Description

You are configuring a linear array of **j** energy nodes. You must choose a single sequence in which to arrange all **j** nodes from position 1 to position $j$.

Each node has two properties: a *charging duration* and a *discharging duration*.
Once you fix the sequence $S = (S_1, S_2, \dots, S_j)$, you simulate a running energy balance to determine the sequence's peak stress.

The simulation works as follows:
1. The running balance starts at 0.
2. For each position $k$ from 1 to $j$ in order:
   - The balance increases by the charging duration of the node $S_k$.
   - At this exact moment, the current balance is recorded as the *transient peak* for step $k$.
   - The balance then decreases by the discharging duration of the node $S_k$.

The *baseline stress* of the sequence is the maximum of the $j$ recorded transient peaks. 
The *total peak stress* of the sequence is defined as its baseline stress plus the sum of the discharging durations of all $j$ nodes.

Your objective is to find an arrangement sequence $S$ that minimizes the total peak stress. Output this minimum possible total peak stress.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the charging duration and the discharging duration of a node, respectively.

## Output

Print a single integer: the minimum possible total peak stress.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

For example, if the nodes in Example 1 were arranged in the given input order:
- Step 1 (node with 3, 2): Balance increases by 3 (peak = 3), decreases by 2 (balance = 1).
- Step 2 (node with 2, 4): Balance increases by 2 (peak = 3), decreases by 4 (balance = -1).
- Step 3 (node with 1, 3): Balance increases by 1 (peak = 0), decreases by 3 (balance = -4).
The transient peaks are 3, 3, and 0. The baseline stress is max(3, 3, 0) = 3.
The sum of all discharging durations is 2 + 4 + 3 = 9.
The total peak stress would be 3 + 9 = 12.
An optimal arrangement sequence achieves a minimum total peak stress of 10.

In Example 2, there is only one node. The balance starts at 0. It increases by the charging duration (5), so the transient peak is 5. It then decreases by the discharging duration (3). The baseline stress is 5. The sum of all discharging durations is 3. The total peak stress is 5 + 3 = 8.
</STATEMENT>
<RATIONALE>
I transformed the static prefix/suffix formula into an equivalent step-by-step state simulation by factoring out the constant total sum of all discharging durations. This forces models to algebraically reconstruct the original formula to recognize the 2-machine flow shop structure; otherwise, they will likely misinterpret the running balance as a sequence-dependent setup time problem and fail to find the O(N log N) optimal sorting strategy.
</RATIONALE>
<PRESERVED_ANSWER>
The computed total peak stress is mathematically identical to the original formula because the transient peak for step k is exactly the prefix sum of charging durations minus the prefix sum (up to k-1) of discharging durations, which when added to the total sum of discharging durations exactly yields the original prefix plus suffix sum.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the 2-machine flow shop makespan minimization (solvable in O(N log N) via Johnson's rule), just presented via an algebraically equivalent expression.
</PRESERVED_CLASS>
