We need to minimize the maximum over pivot positions of:

\[
F(S) = \max_{1 \le k \le j} \left( \sum_{i=1}^{k} p1_{S_i} + \sum_{i=k}^{j} p2_{S_i} \right)
\]

Let’s denote:
- \( A_i = p1_i \)
- \( B_i = p2_i \)

For a fixed order, the expression for pivot \( k \) is:

\[
\text{prefix}_A(k) + \text{suffix}_B(k)
\]

where  
\(\text{prefix}_A(k) = \sum_{i=1}^k A_{S_i}\)  
\(\text{suffix}_B(k) = \sum_{i=k}^j B_{S_i}\)

We want to minimize the maximum of these sums.

---

### Key observation
If we reorder, the total sum of all \( A \) and \( B \) is fixed.  
For each pivot \( k \), the value is:

\[
\text{prefix}_A(k) + \text{suffix}_B(k) = \text{prefix}_A(k) + \text{total}_B - \text{prefix}_B(k-1)
\]

Where \(\text{prefix}_B(0) = 0\).

So:

\[
F(S) = \text{total}_B + \max_{1 \le k \le j} \left( \text{prefix}_A(k) - \text{prefix}_B(k-1) \right)
\]

We want to minimize this maximum.

---

### Reformulation
Let’s define for each node \( i \):
- \( a_i = p1_i \)
- \( b_i = p2_i \)

We need to order them to minimize:

\[
\max_{1 \le k \le j} \left( \sum_{i=1}^k a_{S_i} - \sum_{i=1}^{k-1} b_{S_i} \right)
\]

This is like a scheduling problem: we want to keep the cumulative difference small.

---

### Greedy approach
This is similar to the classic "minimize maximum prefix sum" problem.  
We can sort by \( a_i - b_i \)? Let’s test.

If we place nodes with \( a_i - b_i \) negative first, the cumulative difference decreases early, which might help.

Actually, the known optimal strategy for minimizing the maximum of prefix sums of \( a \) minus prefix sums of \( b \) is to sort by \( a_i - b_i \) in **non-decreasing** order (i.e., most negative first).  
This is because we want to "pay" the \( b \) costs early to reduce the peak.

---

### Proof sketch
Let \( d_i = a_i - b_i \).  
The expression for pivot \( k \) is:

\[
\sum_{i=1}^k a_{S_i} - \sum_{i=1}^{k-1} b_{S_i} = a_{S_k} + \sum_{i=1}^{k-1} (a_{S_i} - b_{S_i}) = a_{S_k} + \sum_{i=1}^{k-1} d_{S_i}
\]

So the maximum over \( k \) is:

\[
\max_{1 \le k \le j} \left( a_{S_k} + \sum_{i=1}^{k-1} d_{S_i} \right)
\]

We want to minimize this.  
If we sort by \( d_i \) ascending, the prefix sums of \( d \) are as small as possible at each step, which minimizes the maximum.

---

### Algorithm
1. Read all nodes.
2. Sort by \( d_i = p1_i - p2_i \) ascending.
3. Compute prefix sums of \( d \) and track the maximum of \( a_{S_k} + \text{prefix\_d}_{k-1} \).
4. Add total \( B \) to the result.

---

### Implementation
```python
import sys

def main():
    input = sys.stdin.readline
    n = int(input())
    nodes = []
    total_b = 0
    for _ in range(n):
        a, b = map(int, input().split())
        nodes.append((a, b))
        total_b += b
    
    # Sort by a - b ascending
    nodes.sort(key=lambda x: x[0] - x[1])
    
    prefix_d = 0
    max_val = 0
    for a, b in nodes:
        max_val = max(max_val, a + prefix_d)
        prefix_d += (a - b)
    
    print(total_b + max_val)

if __name__ == "__main__":
    main()
```
