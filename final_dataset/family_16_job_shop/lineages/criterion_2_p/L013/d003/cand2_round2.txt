<STATEMENT>
# Festival Firework Sequence

Time limit: 1 s   Memory limit: 256 MB

## Description

You are organizing a grand festival and must determine a single launch sequence for **j** fireworks. Every firework goes through exactly two consecutive phases: a ground ignition phase, followed by an aerial display phase.

You must choose one sequence in which all fireworks are launched. Both the ground ignition rack and the sky sector process the fireworks in this exact chosen sequence. 

The timing follows these strict rules:
- The ground ignition rack can only ignite one firework at a time. It operates continuously without pauses: the first firework in your sequence begins ignition at time 0, and each subsequent firework begins its ignition the instant the previous firework's ignition finishes.
- The sky sector can only host one aerial display at a time.
- A firework cannot begin its aerial display until two conditions are met: its own ground ignition must be fully complete, and the previous firework in the sequence must have fully finished its aerial display. It begins its display the instant both conditions are satisfied.
- Once a firework's aerial display begins, it takes its full duration to complete.

Given the required ground ignition time and aerial display time for each firework, find a launch sequence that allows the festival to conclude as early as possible. Output the minimum possible time at which the final firework in your sequence completes its aerial display.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the duration of the ground ignition and the duration of the aerial display for that firework, respectively.

## Output

Print a single integer: the smallest possible time at which all fireworks have completed their aerial displays.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single firework takes 5 for ground ignition, finishing at time 5. Its aerial display starts immediately and takes 3, finishing at time 8.

<RATIONALE>
Removed the explicit mathematical formulas for $A_k$ and $B_k$ and the explicit $\max$ function which directly mirrored standard flow-shop makespan equations. Replaced them with equivalent logical conditions in a new narrative (fireworks ignition and display) to force solvers to model the timing dependencies themselves from the text rather than triggering on the algebraic pattern.
</RATIONALE>
<PRESERVED_ANSWER>
The objective and constraints are mathematically identical to a two-machine flow-shop, so the optimal sequence and minimum completion time remain exactly the same for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem retains the exact structure of a two-stage flow-shop makespan minimization, which is solved optimally in O(n log n) time using Johnson's rule.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "the instant both conditions are satisfied" if they fail to realize this acts as a maximum over the two completion times, but the phrasing is logically precise.
</RISK>
