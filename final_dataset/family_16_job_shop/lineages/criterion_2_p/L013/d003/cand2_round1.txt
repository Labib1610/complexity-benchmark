# Mountain Railway Ascent

Time limit: 1 s   Memory limit: 256 MB

## Description

You are managing the daily dispatch of **j** trains up a steep mountain railway. 
Each train requires a specific ascent duration **p1** and a summit docking duration **p2**.

You must choose a single sequence in which the trains will depart. The overall time required to complete the daily operations is determined by the total ascent time of all trains, plus an accumulated bottleneck delay **D**.

The process works as follows:
- Initially, before any trains depart, the bottleneck delay is $D = 0$.
- You process the trains one by one in your chosen sequence.
- When processing a train with ascent duration $p1$ and docking duration $p2$, the current bottleneck delay $D$ is updated to a new value: first, it is reduced by $p1$ (but it cannot drop below $0$), and then it is increased by $p2$. Mathematically, $D_{new} = \max(D_{current} - p1, 0) + p2$.
- After all **j** trains have updated the bottleneck delay in sequence, the final completion time of the schedule is exactly the sum of the $p1$ durations of all **j** trains, plus the final value of $D$.

To ensure the summit station can begin its daily operations as early as possible, find a departure sequence that minimizes this final completion time. Report this minimum possible value.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the ascent duration and the docking duration of a train, respectively.

## Output

Print a single integer: the smallest possible final completion time.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal sequence processes the third train (1 3), then the second (2 4), then the first (3 2).
- Initially $D = 0$.
- Third train (1 3): $D = \max(0 - 1, 0) + 3 = 3$.
- Second train (2 4): $D = \max(3 - 2, 0) + 4 = 5$.
- First train (3 2): $D = \max(5 - 3, 0) + 2 = 4$.
The sum of all $p1$ durations is $1 + 2 + 3 = 6$.
The final completion time is $6 + 4 = 10$.

In Example 2, the single train updates $D = \max(0 - 5, 0) + 3 = 3$. The sum of $p1$ is 5. The final time is $5 + 3 = 8$.
