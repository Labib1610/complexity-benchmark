# Problem B — Structural Bracket Assembly

Time limit: 1 s   Memory limit: 256 MB

## Description

You are assembling a batch of $j$ structural brackets along a single-axis rail. You must arrange the $j$ given brackets into a single sequence $B_1, B_2, \dots, B_j$ (a permutation of the given brackets).

Each bracket requires two solid mounting blocks: an Alpha block of length $d_1$ and a Beta block of length $d_2$. Let $d_1(B_k)$ and $d_2(B_k)$ denote the block lengths for the bracket placed at position $k$ in your sequence.

For each position $k$ ($1 \le k \le j$), you must place its Alpha block and Beta block on the rail. The placement is governed by three distinct sets of physical linkages. Each linkage forces one block to be placed entirely before another (meaning the first block's rightmost edge does not exceed the second block's leftmost edge):
- **Internal Links:** For every bracket $k$, an internal link forces its Alpha block to be placed entirely before its own Beta block.
- **Alpha Daisy-Chain:** For every $k < j$, an Alpha rail tether forces the Alpha block of bracket $k$ to be placed entirely before the Alpha block of bracket $k+1$.
- **Beta Daisy-Chain:** For every $k < j$, a Beta rail tether forces the Beta block of bracket $k$ to be placed entirely before the Beta block of bracket $k+1$.

Blocks that are not connected by these specific linkages are allowed to overlap in space.

Assume the rail begins at coordinate 0, meaning no block may occupy negative coordinates. Your goal is to find a sequence of the $j$ brackets and a valid placement of all blocks that minimizes the rightmost coordinate occupied by the Beta block of the final bracket $B_j$. Report this smallest possible final boundary value.

Note: The answer may exceed the range of a 32-bit signed integer.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $d_1$ and $d_2$ ($1 \le d_1, d_2 \le 1000000$): the lengths of the Alpha and Beta blocks of a bracket.

## Output

Print a single integer: the smallest possible final boundary value.

```

**Output**

```

**Output**

```

```

## Note

In Example 2, there is only one bracket with $d_1 = 5$ and $d_2 = 3$. We can place its Alpha block starting at coordinate 0, occupying the interval $[0, 5]$. The internal link requires the Alpha block to be entirely before the Beta block, so the Beta block can start at coordinate 5, occupying the interval $[5, 8]$. The rightmost coordinate occupied by the Beta block is 8.
