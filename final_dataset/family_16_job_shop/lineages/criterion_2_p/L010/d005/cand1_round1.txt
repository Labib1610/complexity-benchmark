# Problem B — Pivot Sum Minimization

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a collection of $j$ pairs of values. Each pair has a Left value $d_1$ and a Right value $d_2$. You must arrange the $j$ given pairs into a single sequence $P_1, P_2, \dots, P_j$ (a permutation of the given pairs).

Let $d_1(P_k)$ and $d_2(P_k)$ denote the Left and Right values of the pair placed at position $k$ in your sequence.

For any index $i$ ($1 \le i \le j$), we define the *pivot sum* at $i$ as the sum of the Left values from the start of the sequence up to $i$, plus the sum of the Right values from $i$ to the end of the sequence. Formally:
$$S(i) = \sum_{k=1}^{i} d_1(P_k) + \sum_{k=i}^{j} d_2(P_k)$$

The *capacity* of your chosen sequence is the maximum pivot sum over all possible choices of $i$:
$$C = \max_{1 \le i \le j} S(i)$$

Your goal is to find a sequence of the $j$ pairs that minimizes the capacity $C$. Report this smallest possible capacity.

Note: The answer may exceed the range of a 32-bit signed integer.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $d_1$ and $d_2$ ($1 \le d_1, d_2 \le 1000000$): the Left and Right values of a pair.

## Output

Print a single integer: the smallest possible capacity $C$.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal sequence is to place the pairs in the order $(1, 3)$, $(2, 4)$, and $(3, 2)$. 
The pivot sums for this sequence are:
- For $i=1$: $S(1) = 1 + (3 + 4 + 2) = 10$
- For $i=2$: $S(2) = (1 + 2) + (4 + 2) = 9$
- For $i=3$: $S(3) = (1 + 2 + 3) + 2 = 8$
The capacity is $\max(10, 9, 8) = 10$. There is no arrangement of the pairs that results in a capacity strictly less than 10.
