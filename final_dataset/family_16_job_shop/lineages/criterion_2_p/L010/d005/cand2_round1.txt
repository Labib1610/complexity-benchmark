# Problem B — Sequential State Evaluation

Time limit: 1 s   Memory limit: 256 MB

## Description

You are processing a batch of $j$ data packets. You must arrange the $j$ given packets into a single sequence $P_1, P_2, \dots, P_j$ (a permutation of the given packets).

Each packet has an Alpha parameter $d_1$ and a Beta parameter $d_2$. Let $d_1(P_k)$ and $d_2(P_k)$ denote the respective parameters for the packet placed at position $k$ in your sequence.

During processing, you maintain two running counters, $A$ and $B$. Initially, both $A = 0$ and $B = 0$. 
For each packet in your sequence, from $k = 1$ to $j$, you update the counters in this exact order:
1. Increase $A$ by the packet's Alpha parameter: $A \leftarrow A + d_1(P_k)$
2. Set $B$ to the maximum of $A$ and $B$: $B \leftarrow \max(A, B)$
3. Increase $B$ by the packet's Beta parameter: $B \leftarrow B + d_2(P_k)$

Your goal is to find a sequence of the $j$ packets that minimizes the final value of $B$ after all packets are processed. Report this smallest possible final value.

Note: The answer may exceed the range of a 32-bit signed integer.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $d_1$ and $d_2$ ($1 \le d_1, d_2 \le 1000000$): the Alpha and Beta parameters of a packet.

## Output

Print a single integer: the smallest possible final value of $B$.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, an optimal sequence is the third packet, then the second, then the first.
Initial state: $A = 0, B = 0$.
- **Packet 3** ($d_1=1, d_2=3$):
  1. $A \leftarrow 0 + 1 = 1$
  2. $B \leftarrow \max(1, 0) = 1$
  3. $B \leftarrow 1 + 3 = 4$
- **Packet 2** ($d_1=2, d_2=4$):
  1. $A \leftarrow 1 + 2 = 3$
  2. $B \leftarrow \max(3, 4) = 4$
  3. $B \leftarrow 4 + 4 = 8$
- **Packet 1** ($d_1=3, d_2=2$):
  1. $A \leftarrow 3 + 3 = 6$
  2. $B \leftarrow \max(6, 8) = 8$
  3. $B \leftarrow 8 + 2 = 10$

The final value of $B$ is 10.
