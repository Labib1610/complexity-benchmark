We need to arrange the brackets to minimize the final Beta footprint’s rightmost coordinate.  

The key observation:  
- For each bracket, the Beta footprint must start at least at the end of its Alpha footprint.  
- The Alpha footprints are placed sequentially, each starting where the previous one ended.  
- The Beta footprints are also placed sequentially, each starting where the previous one ended.  

If we place bracket \( i \) at position \( k \), its Alpha starts at the current Alpha position, and its Beta starts at the current Beta position, but must be at least at the end of its own Alpha.  

So the minimal final coordinate depends on the order.  

We can think of it as:  
- We have a sequence of pairs \((d_1, d_2)\).  
- The Alpha track accumulates \( \sum d_1 \).  
- The Beta track accumulates \( \sum d_2 \), but each Beta start must be at least the end of its own Alpha.  

If we process brackets in some order, the Beta position after processing bracket \( k \) is:  
\[
\text{BetaPos} = \max(\text{BetaPos} + d_2, \text{AlphaPos} + d_2)
\]
where AlphaPos is the end of the current bracket’s Alpha.  

This is equivalent to:  
- Start with AlphaPos = 0, BetaPos = 0.  
- For each bracket in order:  
  - AlphaPos += d1  
  - BetaPos = max(BetaPos, AlphaPos) + d2  

We want to minimize the final BetaPos.  

This is a known scheduling problem: we should sort brackets by \( d_1 \) descending? Actually, the optimal order is to sort by \( d_1 \) descending, because larger Alpha spans should be placed earlier to reduce the “waiting” of Beta behind Alpha.  

Let’s test:  
If we sort by \( d_1 \) descending, we minimize the maximum of (BetaPos, AlphaPos) at each step.  

Proof sketch:  
- If a bracket with large \( d_1 \) is placed later, its Alpha end will be large, forcing Beta to wait longer.  
- Placing large \( d_1 \) early reduces the gap.  

So the solution:  
1. Read all brackets.  
2. Sort by \( d_1 \) descending.  
3. Simulate the process.  

Complexity: \( O(j \log j) \), fine for \( j \le 200000 \).  

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    brackets = []
    idx = 1
    for _ in range(j):
        d1 = int(data[idx])
        d2 = int(data[idx+1])
        brackets.append((d1, d2))
        idx += 2
    
    # Sort by d1 descending
    brackets.sort(key=lambda x: -x[0])
    
    alpha_pos = 0
    beta_pos = 0
    for d1, d2 in brackets:
        alpha_pos += d1
        beta_pos = max(beta_pos, alpha_pos) + d2
    
    print(beta_pos)

if __name__ == "__main__":
    main()
```
