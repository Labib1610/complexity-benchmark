<STATEMENT>
# Problem B — Network Potential Configuration

Time limit: 1 s   Memory limit: 256 MB

## Description

You are configuring a dependency network for a batch of $j$ computational nodes. You must arrange the $j$ given nodes into a single linear sequence $v_1, v_2, \dots, v_j$ (a single permutation of the given nodes).

Each node has a primary weight $w_1$ and a secondary weight $w_2$. Let $w_1(v_k)$ and $w_2(v_k)$ denote the respective weights for the node placed at position $k$ in your sequence.

For your chosen sequence, you must assign a Primary Potential $\Phi_1(k)$ and a Secondary Potential $\Phi_2(k)$ for each position $k$ ($1 \le k \le j$). To ensure network stability, the potentials must satisfy the following directed edge requirements:
- The difference from the current position's Primary Potential to the next position's Primary Potential must be at least the current node's primary weight:
  $\Phi_1(k+1) - \Phi_1(k) \ge w_1(v_k)$ for $1 \le k < j$
- The difference from a position's Primary Potential to its own Secondary Potential must be at least its primary weight:
  $\Phi_2(k) - \Phi_1(k) \ge w_1(v_k)$ for $1 \le k \le j$
- The difference from the current position's Secondary Potential to the next position's Secondary Potential must be at least the current node's secondary weight:
  $\Phi_2(k+1) - \Phi_2(k) \ge w_2(v_k)$ for $1 \le k < j$

Assume the baseline potential is $\Phi_1(1) \ge 0$. Your goal is to find a sequence of the $j$ nodes and a valid potential assignment that minimizes the network's terminal boundary, which is defined as $\Phi_2(j) + w_2(v_j)$. Report this smallest possible terminal boundary value.

Note: Mathematically, for a chosen sequence, the minimum possible terminal boundary is exactly equal to the maximum, over all split positions $m$ ($1 \le m \le j$), of the sum of the primary weights from position $1$ to $m$ inclusive, plus the sum of the secondary weights from position $m$ to $j$ inclusive.
The answer may exceed the range of a 32-bit signed integer.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $w_1$ and $w_2$ ($1 \le w_1, w_2 \le 1000000$): the primary and secondary weights of a node.

## Output

Print a single integer: the smallest possible terminal boundary value.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one node with $w_1 = 5$ and $w_2 = 3$. We can set $\Phi_1(1) = 0$, satisfying $\Phi_1(1) \ge 0$. The edge requirements state $\Phi_2(1) - \Phi_1(1) \ge w_1(v_1) = 5$, so $\Phi_2(1) \ge 5$. We can set $\Phi_2(1) = 5$. The terminal boundary is $\Phi_2(1) + w_2(v_1) = 5 + 3 = 8$.
</STATEMENT>
<RATIONALE>
Changed the theme from physical structural brackets on a 1D rail to computational nodes with directed potential constraints. This removes the implicit geometric/scheduling affordances (which models easily map to a two-machine flow-shop) and forces the model to algebraically analyze the inequalities from scratch to discover the optimal ordering rule.
</RATIONALE>
<PRESERVED_ANSWER>
The system of inequalities for the potentials $\Phi_1$ and $\Phi_2$ is mathematically identical to the distance constraints for the coordinates $X$ and $Y$ in the seed, meaning the exact same sequence minimizes the objective function.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem requires finding a permutation to minimize the maximum over all splits of prefix and suffix sums, which remains optimally solvable in O(n log n) time using Johnson's rule.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the split-sum formula in the note as a different objective if they fail to recognize its mathematical equivalence to the potential constraints, but the wording explicitly states it is an equivalent property.
</RISK>
