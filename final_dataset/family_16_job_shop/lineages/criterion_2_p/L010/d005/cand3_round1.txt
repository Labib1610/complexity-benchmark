<STATEMENT>
# Problem B — Conduit Peak Saturation

Time limit: 1 s
Memory limit: 256 MB

## Description

You have a set of $j$ dual-layer crystals. Each crystal has an upper layer resonance and a lower layer resonance. You must arrange all $j$ given crystals into a single sequence (a permutation of the given crystals) to form a two-layer conduit.

Once arranged, an energy pulse will travel through the conduit. The pulse enters at the upper layer of the first crystal in your sequence and must exit from the lower layer of the last crystal. 
The pulse moves according to these rules:
- From the upper layer of the crystal at position $i$, it can either move forward to the upper layer of the crystal at position $i+1$ (if $i < j$), or it can drop to the lower layer of the current crystal at position $i$.
- From the lower layer of the crystal at position $i$, it can only move forward to the lower layer of the crystal at position $i+1$ (if $i < j$).
- The pulse can never move backwards, nor can it move from a lower layer to an upper layer.

This means the pulse will travel along the upper layers from position $1$ up to some drop position $k$ ($1 \le k \le j$), drop to the lower layer at position $k$, and then travel along the lower layers from position $k$ to position $j$.

As the pulse travels, it absorbs the resonance of every layer it passes through. The total resonance of a specific path is the sum of the resonances of all upper and lower layers visited. Because the pulse's drop position $k$ is unpredictable, the conduit's *peak saturation* is defined as the maximum total resonance among all $j$ possible valid paths the pulse could take.

Your goal is to find a sequence of the $j$ crystals that minimizes the conduit's peak saturation, and report this smallest possible peak saturation value.

Note: The answer may exceed the range of a 32-bit signed integer.

## Input

The first line contains a single integer $j$, representing the number of crystals. The number of crystals is at least one, and at most the exact number of seconds in $55$ hours, $33$ minutes, and $20$ seconds.
Each of the next $j$ lines contains two integers: the upper layer resonance and the lower layer resonance of a crystal. These resonance values are positive integers, with a maximum possible value equal to the number of millimeters in exactly one kilometer.

## Output

Print a single integer: the smallest possible peak saturation of the conduit.

**Input**

```

**Output**
```
10
```

**Output**

```

### Example 3

```

**Output**

```

## Note

In Example 1, one optimal arrangement is to place the crystals in the order of the 3rd input crystal, then the 2nd, then the 1st. 
The upper layer resonances in this sequence are $1, 2, 3$.
The lower layer resonances in this sequence are $3, 4, 2$.
The $j=3$ possible paths for the pulse are:
- Drop at position 1: upper $1$, lower $3, 4, 2$. Total = $1+3+4+2 = 10$.
- Drop at position 2: upper $1, 2$, lower $4, 2$. Total = $1+2+4+2 = 9$.
- Drop at position 3: upper $1, 2, 3$, lower $2$. Total = $1+2+3+2 = 8$.
The maximum of these path totals is $10$. Thus, the peak saturation for this sequence is $10$. No sequence can achieve a peak saturation lower than $10$.
