# Canyon Caravan

Time limit: 1 s   Memory limit: 256 MB

## Description

A merchant caravan consisting of **j** wagons needs to traverse a treacherous canyon. The canyon features exactly **two** sequential bottlenecks: a rickety bridge followed by a dark tunnel. Every wagon must cross the bridge first and then traverse the tunnel. For each wagon, you are given its crossing time for the bridge and its crossing time for the tunnel. The rules are:

- The bridge can support only one wagon at a time.
- The tunnel can accommodate only one wagon at a time.
- A wagon can enter the tunnel only after it has finished crossing the bridge.
- You must select one sequence from the $j!$ possible permutations of wagons (the wagons proceed through the bridge and the tunnel in this same chosen order, as the path is too narrow for overtaking).

Evaluate the possible orderings to find the sequence where the time at which the **last** wagon exits the tunnel is as small as possible. Report that smallest possible completion time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **b** and **t** (1 ≤ b, t ≤ 1000000): the crossing times of a wagon for the bridge and the tunnel, respectively.

## Output

Print a single integer: the smallest possible time at which all wagons have exited the tunnel.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2 the single wagon takes 5 on the bridge then 3 in the tunnel, exiting at time 8.
</STATEMENT>
<RATIONALE>
I replaced the standard factory/jobs/machines scheduling scenario with a physical caravan traversing a canyon with two bottlenecks (a bridge and a tunnel). This removes the standard flow-shop keywords that trigger models to instantly retrieve Johnson's rule by name, forcing them to recognize the structural equivalence of the bottleneck pipeline and derive the sorting comparator from the mechanics of the scenario.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical model of the caravan is identical to the two-machine flow shop, so the optimal completion time and the sequencing logic achieving it remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is structurally isomorphic to the two-machine flow shop problem, which remains solvable in O(n log n) time.
</PRESERVED_CLASS>
