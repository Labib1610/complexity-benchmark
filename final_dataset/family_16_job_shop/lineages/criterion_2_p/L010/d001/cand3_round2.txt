# Problem B — Mountain Pass Convoy

Time limit: 1 s   Memory limit: 256 MB

## Description

A convoy of **j** wagons must cross a mountain pass. Every wagon must first cross a narrow bridge and then pass through a single-lane tunnel. For each wagon, you are given the time it takes to cross the bridge and the time it takes to travel through the tunnel. The rules are:

- The bridge accommodates only one wagon at a time.
- The tunnel accommodates only one wagon at a time.
- A wagon can enter the tunnel only after it has finished crossing the bridge.
- You must choose a single sequence for the wagons (both the bridge and the tunnel process the wagons in this same chosen order).

Determine an arrangement of the wagons that minimizes the time at which the **last** wagon exits the tunnel. Report that smallest possible completion time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the duration a wagon takes on the bridge and the duration it takes in the tunnel.

## Output

Print a single integer: the smallest possible time at which all wagons have exited the tunnel.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2 the single wagon takes 5 on the bridge then 3 in the tunnel, exiting at time 8.

<RATIONALE>
Changed the domain from job scheduling on machines to a convoy of wagons crossing a bridge and a tunnel. This preserves the two-stage pipeline structure with identical ordering and non-overlapping constraints, but removes the canonical "machine" and "job" keywords that trigger models to instantly retrieve Johnson's rule. The model must now manually deduce the bottleneck structure and derive the optimal sorting strategy.
</RATIONALE>
<PRESERVED_ANSWER>
The bridge and tunnel act exactly as machine 1 and machine 2, with identical non-overlapping and precedence constraints, ensuring the exact same makespan for any given permutation of the entities.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to the two-machine flow-shop scheduling problem, which is solvable in O(n log n) time.
</PRESERVED_CLASS>
