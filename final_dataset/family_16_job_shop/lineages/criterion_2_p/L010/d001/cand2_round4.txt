# Problem B — Mountain Traversals

Time limit: 1 s   Memory limit: 256 MB

## Description

A fleet of **j** convoys must traverse a hazardous mountain route. The route consists of exactly two narrow bottlenecks in sequence: the North Gorge followed immediately by the South Pass. Every convoy must completely cross the North Gorge first and then cross the South Pass. For each convoy you are given its travel time through the North Gorge and through the South Pass. The rules are:

- Each bottleneck accommodates only one convoy at a time.
- A convoy can start crossing the South Pass only after it has finished crossing the North Gorge.
- The convoys must be dispatched in a single unified sequence. Due to the narrowness of the connecting terrain, no convoy can overtake another between the bottlenecks; thus, the order in which convoys cross the North Gorge is exactly the order in which they must cross the South Pass.

Evaluate the possible dispatch orderings to find the sequence where the time at which the **last** convoy finishes crossing the South Pass is as small as possible. Report that smallest possible finish time.

## Input

The first line contains a single integer **j**. The staging area operates with at least a single convoy, and its physical space limits the maximum fleet size to exactly two hundred thousand.
Each of the next **j** lines contains two integers **p1** and **p2**: the travel durations of a convoy through the North Gorge and the South Pass. The minimum duration is exactly one, and fuel reserves limit the maximum duration of any single traverse to exactly one million.

## Output

Print a single integer: the smallest possible time at which all convoys are finished.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2 the single convoy takes 5 in the North Gorge then 3 in the South Pass, finishing at time 8.
