# Problem B — Pivot Sum Minimization

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a set of $j$ components. Each component has an Alpha attribute $d_1$ and a Beta attribute $d_2$. 

You must arrange all $j$ components into a single ordered sequence $C_1, C_2, \dots, C_j$ (a permutation of the given components). 

For your chosen sequence, we define the **pivot sum** at index $i$ ($1 \le i \le j$) as the sum of the Alpha attributes of all components from the start of the sequence up to index $i$, plus the sum of the Beta attributes of all components from index $i$ to the end of the sequence.

Formally, the pivot sum $P(i)$ at index $i$ is:
$$P(i) = \sum_{k=1}^{i} d_1(C_k) + \sum_{k=i}^{j} d_2(C_k)$$

The **peak value** of the sequence is the maximum of $P(i)$ over all possible pivot indices $1 \le i \le j$.

Your goal is to find an arrangement of the $j$ components that minimizes this peak value. Report the smallest possible peak value.

Note: The answer may exceed the range of a 32-bit signed integer.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $d_1$ and $d_2$ ($1 \le d_1, d_2 \le 1000000$): the Alpha and Beta attributes of a component.

## Output

Print a single integer: the smallest possible peak value achievable by any valid sequence of the components.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one component with $d_1 = 5$ and $d_2 = 3$. The only possible sequence has this component at index 1. The pivot sum at index 1 is $P(1) = d_1(C_1) + d_2(C_1) = 5 + 3 = 8$. The peak value is 8, which is the minimum possible.

In Example 1, one optimal sequence places the component `1 3` first, `2 4` second, and `3 2` third. 
The pivot sums are:
- $P(1) = 1 + (3 + 4 + 2) = 10$
- $P(2) = (1 + 2) + (4 + 2) = 9$
- $P(3) = (1 + 2 + 3) + 2 = 8$
The peak value for this sequence is $\max(10, 9, 8) = 10$. No sequence can achieve a peak value strictly less than 10.
