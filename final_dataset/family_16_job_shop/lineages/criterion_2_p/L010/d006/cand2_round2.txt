<STATEMENT>
# Problem B — Sequence Peak Minimization

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a set of $j$ items. You must arrange the $j$ given items into a single sequence $C_1, C_2, \dots, C_j$ (which must be a permutation of the given items).

Each item has an Alpha value $d_1$ and a Beta value $d_2$. Let $d_1(C_k)$ and $d_2(C_k)$ denote the respective values for the item placed at position $k$ in your sequence.

For your chosen sequence, we evaluate a series of baseline values $B_0, B_1, \dots, B_j$ and peak values $P_1, P_2, \dots, P_j$ as follows:

First, the initial baseline $B_0$ is defined as the sum of the Beta values of all $j$ items in the input (this sum is a constant for any permutation):
$B_0 = \sum_{i=1}^j d_2(C_i)$

Then, for each step $k$ from $1$ to $j$, we compute:
1. The **peak value** at step $k$, defined as the previous baseline plus the Alpha value of the $k$-th item:
$P_k = B_{k-1} + d_1(C_k)$
2. The **new baseline** at step $k$, defined as the peak value at step $k$ minus the Beta value of the $k$-th item:
$B_k = P_k - d_2(C_k)$

Your goal is to find a permutation of the $j$ items that minimizes the maximum peak value achieved during the process. That is, you want to minimize $\max_{1 \le k \le j} P_k$. Report this smallest possible maximum peak value.

Note: The answer may exceed the range of a 32-bit signed integer.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $d_1$ and $d_2$ ($1 \le d_1, d_2 \le 1000000$): the Alpha and Beta values of an item.

## Output

Print a single integer: the smallest possible maximum peak value $\max_{1 \le k \le j} P_k$ over all valid permutations.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one item with $d_1 = 5$ and $d_2 = 3$. 
The initial baseline is $B_0 = 3$. 
At step 1, the peak value is $P_1 = B_0 + d_1(C_1) = 3 + 5 = 8$. 
The new baseline is $B_1 = P_1 - d_2(C_1) = 8 - 3 = 5$. 
The maximum peak value is exactly 8, which is the minimum possible.
</STATEMENT>
<RATIONALE>
I replaced the geometric scheduling scenario (which models recognize as a 2-machine permutation flow shop) with an algebraic sequence evaluation. The algebraic form evaluates $P_k = B_0 + \sum_{i=1}^k d_1 - \sum_{i=1}^{k-1} d_2$, which simplifies exactly to the 2-machine makespan formula $\max_k (\sum_{i=1}^k d_1 + \sum_{i=k}^j d_2)$. This forces the model to mathematically analyze the prefix sums to discover Johnson's rule, bypassing surface-level pattern matching on scheduling tracks.
</RATIONALE>
<PRESERVED_ANSWER>
The maximum peak value in the algebraic sequence is mathematically identical to the makespan of a 2-machine flow shop (the critical path length formula), ensuring the minimum possible value is exactly the same for every input.
</PRESERVED_ANSWER>

The problem remains equivalent to finding the optimal permutation for a 2-machine flow shop, which is optimally solvable in O(n log n) time using Johnson's rule.
</PRESERVED_CLASS>
