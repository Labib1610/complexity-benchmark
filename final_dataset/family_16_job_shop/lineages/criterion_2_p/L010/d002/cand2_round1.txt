<STATEMENT>
# Problem B — Sequence Evaluation

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a collection of $j$ components. You must arrange these components into a single sequence $C_1, C_2, \dots, C_j$ (a permutation of the given components).

Each component has a primary coefficient $p_1$ and a secondary coefficient $p_2$. Let $p_1(C_k)$ and $p_2(C_k)$ denote the coefficients for the component placed at position $k$ in your sequence.

For your chosen sequence, you must assign a primary state value $X_k$ and a secondary state value $Y_k$ for each position $k$ ($1 \le k \le j$). To be valid, the state assignments must satisfy the following lower bounds on their differences:
- $X_{k+1} - X_k \ge p_1(C_k)$ for $1 \le k < j$
- $Y_{k+1} - Y_k \ge p_2(C_k)$ for $1 \le k < j$
- $Y_k - X_k \ge p_1(C_k)$ for $1 \le k \le j$

Assume $X_1 \ge 0$. Your goal is to find a sequence of the $j$ components and a valid state assignment that minimizes the final terminal value, defined as $Y_j + p_2(C_j)$. Report this smallest possible terminal value.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the primary and secondary coefficients of a component.

## Output

Print a single integer: the smallest possible terminal value.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one component with $p_1 = 5$ and $p_2 = 3$. We can choose $X_1 = 0$. The third condition requires $Y_1 - X_1 \ge 5$, so we can set $Y_1 = 5$. The terminal value is $Y_1 + p_2(C_1) = 5 + 3 = 8$.
</STATEMENT>
