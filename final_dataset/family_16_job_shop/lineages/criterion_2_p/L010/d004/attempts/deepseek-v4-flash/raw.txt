We can model this as a scheduling problem.  
For each bracket, we have two spans: \(d_1\) (Alpha) and \(d_2\) (Beta).  
The constraints essentially mean:

- The Alpha coordinates must be spaced by at least \(d_1\) of the previous bracket.
- The Beta coordinates must be spaced by at least \(d_2\) of the previous bracket.
- For each bracket, Beta must be at least \(d_1\) ahead of its own Alpha.

If we place brackets in some order, the minimal final boundary is:

\[
\text{final} = \sum_{k=1}^{j} d_1(B_k) + \max_{1 \le k \le j} \left( d_2(B_k) + \sum_{i=k+1}^{j} d_1(B_i) \right)
\]

We can rearrange to see that the optimal order is to sort brackets by \(d_2\) descending, and if equal, by \(d_1\) descending.  
Then compute the result.

Here’s the implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    j = int(input())
    brackets = []
    for _ in range(j):
        d1, d2 = map(int, input().split())
        brackets.append((d1, d2))
    
    # Sort by d2 descending, then d1 descending
    brackets.sort(key=lambda x: (-x[1], -x[0]))
    
    total_d1 = sum(d1 for d1, _ in brackets)
    max_val = 0
    suffix_sum = total_d1
    for d1, d2 in brackets:
        suffix_sum -= d1
        max_val = max(max_val, d2 + suffix_sum)
    
    print(total_d1 + max_val)

if __name__ == "__main__":
    solve()
```
