# Problem B — Adversarial Sequence Game

Time limit: 1 s   Memory limit: 256 MB

## Description

You are playing a game with $j$ cards. You must arrange the $j$ given cards into a single sequence $C_1, C_2, \dots, C_j$ (a permutation of the given cards).

Each card has two values. For each card, you are given its first value $d_1$ and its second value $d_2$. Let $d_1(C_i)$ and $d_2(C_i)$ denote the respective values for the card placed at position $i$ in your sequence.

After you have chosen your sequence, an adversary will choose a single integer split point $k$ ($1 \le k \le j$). The adversary will then calculate their score as the sum of the first values of the cards at positions $1$ through $k$ inclusive, plus the sum of the second values of the cards at positions $k$ through $j$ inclusive. Mathematically, the adversary's score for a chosen $k$ is:

$$ \sum_{i=1}^k d_1(C_i) + \sum_{i=k}^j d_2(C_i) $$

The adversary will always choose the split point $k$ that maximizes their score.

Your goal is to find a sequence of the $j$ cards that minimizes the score the adversary can achieve. Report this smallest possible adversary score.

Note: The answer may exceed the range of a 32-bit signed integer.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $d_1$ and $d_2$ ($1 \le d_1, d_2 \le 1000000$): the first and second values of a card.

## Output

Print a single integer: the smallest possible adversary score.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal sequence of the cards is to place them in the order: third card, then second card, then first card. Their $(d_1, d_2)$ values in this sequence are $(1, 3)$, $(2, 4)$, and $(3, 2)$.
- If the adversary chooses $k=1$, their score is $1 + (3 + 4 + 2) = 10$.
- If the adversary chooses $k=2$, their score is $(1 + 2) + (4 + 2) = 9$.
- If the adversary chooses $k=3$, their score is $(1 + 2 + 3) + 2 = 8$.
The adversary will choose $k=1$ to maximize their score, resulting in a score of 10. No other sequence of cards can force the adversary to get a maximum score lower than 10.

In Example 2, there is only one card with $d_1 = 5$ and $d_2 = 3$. The only possible sequence is this single card. The adversary must choose $k = 1$. Their score is $d_1(C_1) + d_2(C_1) = 5 + 3 = 8$. The smallest possible adversary score is 8.
