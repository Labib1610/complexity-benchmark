# Problem B — Dual-Axis Lens Alignment

Time limit: 1 s   Memory limit: 256 MB

## Description

You are aligning a batch of $j$ optical lenses along a dual-axis rail system. You must arrange the $j$ given lenses into a single sequence $L_1, L_2, \dots, L_j$ (a permutation of the given lenses).

Each lens has two properties: a Primary Axis clearance $d_1$ and a Secondary Axis clearance $d_2$. Let $d_1(L_i)$ and $d_2(L_i)$ denote the respective clearances for the lens placed at position $i$ in your sequence.

A calibration laser is fired through the aligned lenses. The laser starts on the Primary Axis and eventually shifts to the Secondary Axis. Specifically, the laser will travel along the Primary Axis for the first $k$ lenses (from position $1$ to position $k$), shift axes at position $k$, and then travel along the Secondary Axis for the remaining lenses (from position $k$ to position $j$). Here, the shift position $k$ can be any integer from $1$ to $j$.

The total spatial footprint for a given shift position $k$ is calculated as the sum of the Primary clearances of the lenses from position $1$ to $k$, plus the sum of the Secondary clearances of the lenses from position $k$ to $j$. Mathematically, the footprint for shift position $k$ is:
$$ \sum_{i=1}^{k} d_1(L_i) + \sum_{i=k}^{j} d_2(L_i) $$

Because the laser's shift position $k$ is unpredictable, the alignment rail must be designed to accommodate the worst-case scenario. The *final boundary value* of a specific lens sequence is the maximum total spatial footprint over all $j$ possible shift positions.

Your goal is to find an arrangement of the $j$ lenses that minimizes this final boundary value. Report this smallest possible final boundary value.

Note: The answer may exceed the range of a 32-bit signed integer.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $d_1$ and $d_2$ ($1 \le d_1, d_2 \le 1000000$): the Primary and Secondary Axis clearances of a lens.

## Output

Print a single integer: the smallest possible final boundary value.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one lens with $d_1 = 5$ and $d_2 = 3$. The only possible shift position is $k = 1$. The total spatial footprint is $d_1(L_1) + d_2(L_1) = 5 + 3 = 8$. The final boundary value is 8.
</STATEMENT>
<RATIONALE>
The seed problem explicitly modeled a 2-machine flow shop using sequential placement coordinates and non-overlapping constraints, which LLMs heavily rely on to pattern-match Johnson's rule. I replaced the scheduling inequalities with a mathematically identical formulation: minimizing the maximum path sum in a $2 \times N$ grid. This forces the model to independently deduce that this minimax prefix/suffix sum problem is structurally equivalent to 2-machine flow shop scheduling, effectively removing the surface hint.
</RATIONALE>
<PRESERVED_ANSWER>
The makespan of a 2-machine flow shop is algebraically identical to the maximum path sum of a 2xN grid where the rows are the machine processing times; thus, the optimum permutation and resulting value are strictly identical for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains solvable in O(N log N) time using Johnson's rule, as the underlying mathematical objective (minimize the maximum of prefix A + suffix B) is exactly the 2-machine flow shop makespan.
</PRESERVED_CLASS>
