# Problem B — Thermal Buffer Optimization

Time limit: 1 s   Memory limit: 256 MB

## Description

You are calibrating a sequence of $j$ thermal regulators. You must arrange the $j$ given regulators into a single sequence $P_1, P_2, \dots, P_j$ (a permutation of the given regulators).

Each regulator $k$ in your sequence has a cooling capacity $d_1(P_k)$ and a heat output $d_2(P_k)$.

The system maintains a residual temperature $T$, which is initially $0$. As each regulator in your sequence operates one after another, it updates the temperature in two sequential steps:
1. First, the regulator applies its cooling capacity, reducing the temperature by $d_1(P_k)$. However, the temperature cannot drop below absolute zero ($0$). Thus, the temperature becomes $\max(0, T - d_1(P_k))$.
2. Second, the regulator performs its operation, adding its heat output $d_2(P_k)$ to the system. The temperature becomes $\max(0, T - d_1(P_k)) + d_2(P_k)$.

After all $j$ regulators have operated in the chosen order, the system reaches a final residual temperature $T_{final}$.

To account for total energy dissipation, the overall thermal footprint of the sequence is defined as the final residual temperature plus the sum of the cooling capacities of all $j$ regulators:
$\text{Footprint} = T_{final} + \sum_{k=1}^j d_1(P_k)$

Your goal is to find a sequence of the $j$ regulators that minimizes the overall thermal footprint. Report this smallest possible thermal footprint.

Note: The answer may exceed the range of a 32-bit signed integer.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $d_1$ and $d_2$ ($1 \le d_1, d_2 \le 1000000$): the cooling capacity and heat output of a regulator.

## Output

Print a single integer: the smallest possible overall thermal footprint.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one regulator with $d_1 = 5$ and $d_2 = 3$. We start with $T = 0$. 
Applying the regulator:
1. The temperature is cooled by $5$: $\max(0, 0 - 5) = 0$.
2. The temperature is heated by $3$: $0 + 3 = 3$.
The final residual temperature is $T_{final} = 3$. The sum of all cooling capacities is $5$. The overall thermal footprint is $3 + 5 = 8$.

<RATIONALE>
The problem was completely reframed from a 2-machine flow-shop (parallel spatial paths with dependencies) to a 1D state variable updated via a mathematical recurrence. The algebraic identity `max(D, C) + b = max(D - a, 0) + b + C` is used to perfectly hide the 2D path structure. To solve this efficiently, a model must now algebraically unpack the state transition to realize it's isomorphic to a flow-shop makespan, rather than just pattern-matching on "two axes" or "two stages".
</RATIONALE>

The mathematical transformation is an exact identity: minimizing the final 1D buffer state plus the sum of all first-stage costs is algebraically identical to minimizing the makespan of the original 2-machine flow-shop for every possible permutation.
