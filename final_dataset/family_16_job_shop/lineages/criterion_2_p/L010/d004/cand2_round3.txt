<STATEMENT>
# Problem B — Dual-Axis Lens Alignment

Time limit: 1 s   Memory limit: 256 MB

## Description

You are aligning a batch of $j$ optical lenses along a dual-axis rail system. You must arrange the $j$ given lenses into a single sequence $L_1, L_2, \dots, L_j$ (a permutation of the given lenses).

Each lens requires a specific spatial clearance on both axes. For each lens, you are given its Primary Axis clearance $d_1$ and its Secondary Axis clearance $d_2$. Let $d_1(L_k)$ and $d_2(L_k)$ denote the respective clearances for the lens placed at position $k$ in your sequence.

You must assign a starting Primary coordinate $X_k$ and a starting Secondary coordinate $Y_k$ for each position $k$ ($1 \le k \le j$). This defines a Primary interval $[X_k, X_k + d_1(L_k)]$ and a Secondary interval $[Y_k, Y_k + d_2(L_k)]$ for each lens in your sequence.

The physical placement must satisfy the following geometric alignment rules. For any two intervals $A$ and $B$, saying "$A$ precedes $B$" means that the starting coordinate of $B$ must be greater than or equal to the ending coordinate of $A$.

- **Primary Axis Sequence:** For any $1 \le k < j$, the Primary interval of the lens at position $k$ must precede the Primary interval of the lens at position $k+1$.
- **Cross-Axis Alignment:** For any $1 \le k \le j$, the Primary interval of the lens at position $k$ must precede its own Secondary interval.
- **Secondary Axis Sequence:** For any $1 \le k < j$, the Secondary interval of the lens at position $k$ must precede the Secondary interval of the lens at position $k+1$.

Assume the coordinate system requires $X_1 \ge 0$. Your goal is to find a sequence of the $j$ lenses and a valid coordinate assignment that minimizes the furthest coordinate reached on the Secondary Axis by the final lens, which is the ending coordinate of the final lens's Secondary interval ($Y_j + d_2(L_j)$). Report this smallest possible final boundary value.

Note: The answer may exceed the range of a 32-bit signed integer.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $d_1$ and $d_2$ ($1 \le d_1, d_2 \le 1000000$): the Primary and Secondary Axis clearances of a lens.

## Output

Print a single integer: the smallest possible final boundary value.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one lens with $d_1 = 5$ and $d_2 = 3$. We can set $X_1 = 0$, satisfying $X_1 \ge 0$. The Primary interval is $[0, 5]$. The Cross-Axis Alignment rule requires that this precedes the Secondary interval, meaning $Y_1 \ge 5$. We can set $Y_1 = 5$, giving a Secondary interval of $[5, 8]$. The final boundary value is the ending coordinate of this interval, which is $8$.
</STATEMENT>
<RATIONALE>
The explicit algebraic inequalities were replaced with a geometric "precedes" relation on intervals. This preserves the exact mathematical constraints of the flow-shop problem while removing the standard algebraic signature that LLMs use to pattern-match Johnson's Rule. The use of "interval" terminology also acts as a distractor, potentially leading models to incorrectly apply greedy interval scheduling algorithms.
</RATIONALE>
<PRESERVED_ANSWER>
The interval non-overlapping constraints are mathematically identical to the original coordinate inequalities, meaning the valid coordinate space and the optimal permutation remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to the two-machine permutation flow-shop scheduling problem, solvable in O(j log j) time using Johnson's algorithm.
</PRESERVED_CLASS>
