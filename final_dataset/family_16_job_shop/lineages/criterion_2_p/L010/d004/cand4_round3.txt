# Problem B — State Machine Sequence Optimization

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given $j$ instructions to process through a simple state machine. You must arrange the $j$ instructions into a single ordered sequence $I_1, I_2, \dots, I_j$ (a permutation of the given instructions).

Each instruction requires two integer parameters: a shift $d_1$ and an offset $d_2$. Let $d_1(I_k)$ and $d_2(I_k)$ denote the parameters for the instruction placed at position $k$ in your sequence.

The state machine maintains two internal accumulators, $A$ and $B$, both initialized to $0$. It processes the chosen sequence of instructions one by one. For each instruction $I_k$ in order from $k=1$ to $j$, the machine updates the accumulators using the following exact logic:
1. $A \leftarrow A + d_1(I_k)$
2. $B \leftarrow \max(A, B) + d_2(I_k)$

Your goal is to find a permutation of the $j$ instructions that minimizes the final value of the accumulator $B$ after all $j$ instructions have been processed. Report this minimum possible final value.

Note: The answer may exceed the range of a 32-bit signed integer.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $d_1$ and $d_2$ ($1 \le d_1, d_2 \le 1000000$): the shift and offset parameters of an instruction.

## Output

Print a single integer: the smallest possible final value of $B$.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one instruction with $d_1 = 5$ and $d_2 = 3$. The machine starts with $A=0$ and $B=0$. Processing the single instruction updates the accumulators as follows:
- $A \leftarrow 0 + 5 = 5$
- $B \leftarrow \max(5, 0) + 3 = 8$

The final value of $B$ is 8.

By baking the tightest bounds into a deterministic state-machine update loop, the semantic triggers for "two-machine flow shop" are completely removed, forcing solvers to recognize the mathematical structure of Johnson's rule from raw algebra rather than terminology.
</RATIONALE>

The state machine's deterministic recurrence exactly computes the tightest possible geometric boundaries required by the seed's placement rules, meaning the final value of B for any permutation is identical to the seed's final boundary value.
</PRESERVED_ANSWER>

The problem remains mathematically identical to a two-machine flow-shop scheduling problem, which is optimally solved in O(N log N) time using Johnson's rule.
