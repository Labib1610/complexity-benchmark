# Problem B — Sequential State Carryover

Time limit: 1 s   Memory limit: 256 MB

## Description

You are processing a batch of $j$ data packets sequentially. You must arrange the $j$ given packets into a single sequence $P_1, P_2, \dots, P_j$ (a permutation of the given packets).

Each packet requires two parameters for processing: a primary value $d_1$ and a secondary value $d_2$. Let $x_k$ and $y_k$ denote the primary and secondary values of the packet placed at position $k$ in your chosen sequence.

When the sequence is processed, a carryover state $W_k$ is computed step by step:
- For the first packet in the sequence ($k=1$), the carryover is initialized to its secondary value:
  $W_1 = y_1$
- For each subsequent packet ($k=2, 3, \dots, j$), the carryover is updated by subtracting the current packet's primary value from the previous carryover (bounded below by zero), and then adding the current packet's secondary value. That is:
  $W_k = \max(W_{k-1} - x_k, 0) + y_k$

The overall "final boundary value" of the processed sequence is defined as the final carryover $W_j$ plus the sum of all primary values in the batch. That is:
Final Boundary Value = $W_j + \sum_{i=1}^j x_i$

Your goal is to find a permutation of the $j$ packets that minimizes this final boundary value, and report this smallest possible value.

Note: The answer may exceed the range of a 32-bit signed integer.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $d_1$ and $d_2$ ($1 \le d_1, d_2 \le 1000000$): the primary and secondary values of a packet.

## Output

Print a single integer: the smallest possible final boundary value.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal sequence of the packets is to place the packet with parameters (1, 3) first, then (2, 4), and finally (3, 2).
The sequence of parameters is:
- $k=1$: $x_1 = 1$, $y_1 = 3$
- $k=2$: $x_2 = 2$, $y_2 = 4$
- $k=3$: $x_3 = 3$, $y_3 = 2$

The carryover values are computed as:
- $W_1 = y_1 = 3$
- $W_2 = \max(W_1 - x_2, 0) + y_2 = \max(3 - 2, 0) + 4 = 1 + 4 = 5$
- $W_3 = \max(W_2 - x_3, 0) + y_3 = \max(5 - 3, 0) + 2 = 2 + 2 = 4$

The sum of all primary values is $1 + 2 + 3 = 6$.
The final boundary value is $W_3 + 6 = 4 + 6 = 10$. This is the minimum possible over all permutations.

In Example 2, there is only one packet with $d_1 = 5$ and $d_2 = 3$. The sequence has only one position, so $x_1 = 5$ and $y_1 = 3$. The carryover is $W_1 = y_1 = 3$. The final boundary value is $W_1 + x_1 = 3 + 5 = 8$.
