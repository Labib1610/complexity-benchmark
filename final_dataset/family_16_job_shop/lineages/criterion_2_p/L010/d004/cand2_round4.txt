# Problem B — Matrix Column Permutation

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a set of $j$ columns. Each column consists of exactly two positive integers: a top value $d_1$ and a bottom value $d_2$.

You must choose an order in which to arrange these $j$ columns from left to right to form a $2 \times j$ grid. In this grid, the first row contains the $d_1$ values and the second row contains the corresponding $d_2$ values of the columns in your chosen order.

Consider a path through this grid that starts at the top-left cell (row 1, column 1) and ends at the bottom-right cell (row 2, column $j$). In a single step, a path can only move one cell to the right or one cell down. The cost of a path is the sum of the values in all the cells it visits, including the start and end cells. 

For any chosen arrangement of the $j$ columns, there are multiple valid paths. We define the *grid score* of an arrangement as the maximum path cost among all valid paths from the top-left to the bottom-right.

Your goal is to find an arrangement of the $j$ columns that minimizes the grid score. Report this smallest possible grid score.

Note: The answer may exceed the range of a 32-bit signed integer.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $d_1$ and $d_2$ ($1 \le d_1, d_2 \le 1000000$): the top and bottom values of a column.

## Output

Print a single integer: the smallest possible grid score.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one column with $d_1 = 5$ and $d_2 = 3$. The grid is $2 \times 1$. The only valid path visits the top cell (value 5) and moves down to the bottom cell (value 3). Its cost is $5 + 3 = 8$. The grid score is 8, which is the smallest possible.
