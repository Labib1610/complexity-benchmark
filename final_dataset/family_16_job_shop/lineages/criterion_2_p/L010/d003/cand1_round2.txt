# Problem B — Data Pipeline Sequence

Time limit: 1 s   Memory limit: 256 MB

## Description

A data pipeline is processing a batch of $j$ files. You must arrange the $j$ files into a single sequence $O_1, O_2, \dots, O_j$ (a permutation of the given files).

Each file requires exactly 2 operations: compression and encryption. For each file, you are given its compression duration, $d_1$, and its encryption duration, $d_2$. Let $d_1(O_k)$ and $d_2(O_k)$ denote the respective durations for the file placed at position $k$ in your sequence.

You must assign a compression start timestamp $X_k$ and an encryption start timestamp $Y_k$ for each position $k$ ($1 \le k \le j$). The assignment must satisfy the following transition inequalities:
- $X_{k+1} \ge X_k + d_1(O_k)$ for $1 \le k < j$
- $Y_k \ge X_k + d_1(O_k)$ for $1 \le k \le j$
- $Y_{k+1} \ge Y_k + d_2(O_k)$ for $1 \le k < j$

Assume $X_1 \ge 0$. Find a sequence of the $j$ files and a valid timestamp assignment that minimizes the final target value, defined as $Y_j + d_2(O_j)$. Report this smallest possible target value.

## Input

The first line contains a single integer $j$. The number of files $j$ is limited by the pipeline's maximum batch capacity of 200000, and is at least 1.
Each of the next $j$ lines contains 2 integers $d_1$ and $d_2$: the compression and encryption durations of a file. Each duration is at least 1, and can reach up to the system timeout limit of 1000000.

## Output

Print a single integer: the smallest possible final target value.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one file with $d_1 = 5$ and $d_2 = 3$. We can set $X_1 = 0$, satisfying $X_1 \ge 0$. The inequalities require $Y_1 \ge X_1 + d_1(O_1) = 5$. We can set $Y_1 = 5$. The final target value is $Y_1 + d_2(O_1) = 5 + 3 = 8$.
