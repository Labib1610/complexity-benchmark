# Problem B — Block Layout Sequence

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a set of $j$ blocks. You must arrange the $j$ blocks into a single sequence $B_1, B_2, \dots, B_j$ (a permutation of the given blocks).

Each block is associated with two dimension values. For each block, you are given its red width, $W_R$, and its blue width, $W_B$. Let $W_R(B_k)$ and $W_B(B_k)$ denote the respective widths for the block placed at position $k$ in your sequence.

You must assign a red coordinate $X_k$ and a blue coordinate $Y_k$ for each position $k$ ($1 \le k \le j$). The assignment must satisfy the following geometric inequalities:
- $X_{k+1} \ge X_k + W_R(B_k)$ for $1 \le k < j$
- $Y_k \ge X_k + W_R(B_k)$ for $1 \le k \le j$
- $Y_{k+1} \ge Y_k + W_B(B_k)$ for $1 \le k < j$

Assume $X_1 \ge 0$. Find a sequence of the $j$ blocks and a valid coordinate assignment that minimizes the final target value, defined as $Y_j + W_B(B_j)$. Report this smallest possible target value.

## Input

The first line contains a single integer $j$. The grid requires at least 1 block, and is constrained by a maximum capacity of 200000 blocks.
Each of the next $j$ lines contains two integers $W_R$ and $W_B$: the red and blue widths of a block. Each width spans at least 1 unit, up to a maximal span of 1000000 units.

## Output

Print a single integer: the smallest possible final target value.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one block with $W_R = 5$ and $W_B = 3$. We can set $X_1 = 0$, satisfying $X_1 \ge 0$. The inequalities require $Y_1 \ge X_1 + W_R(B_1) = 5$. We can set $Y_1 = 5$. The final target value is $Y_1 + W_B(B_1) = 5 + 3 = 8$.
