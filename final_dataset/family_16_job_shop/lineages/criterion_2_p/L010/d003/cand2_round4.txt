# Problem B — Dual-Axis Lens Alignment

Time limit: 1 s   Memory limit: 256 MB

## Description

You are aligning a batch of $j$ optical lenses along a dual-axis rail system. You must arrange the $j$ given lenses into a single sequence $L_1, L_2, \dots, L_j$ (a permutation of the given lenses).

Each lens requires a specific spatial clearance on both axes. For each lens, you are given its Primary Axis clearance $d_1$ and its Secondary Axis clearance $d_2$. Let $d_1(L_k)$ and $d_2(L_k)$ denote the respective clearances for the lens placed at position $k$ in your sequence.

You must assign a starting Primary coordinate $X_k$ and a starting Secondary coordinate $Y_k$ for each position $k$ ($1 \le k \le j$). The physical placement must satisfy the following non-overlapping and alignment rules:
- On the Primary Axis, lenses are placed one after another in your chosen sequence without overlapping. Thus, the next lens cannot start its Primary clearance until the current one's clearance ends:
  $X_{k+1} \ge X_k + d_1(L_k)$ for $1 \le k < j$
- For any given lens, its Secondary Axis clearance must start physically at or after the coordinate where its own Primary Axis clearance ends:
  $Y_k \ge X_k + d_1(L_k)$ for $1 \le k \le j$
- On the Secondary Axis, lenses are placed one after another in the exact same chosen sequence without overlapping. Thus, the next lens cannot start its Secondary clearance until the current one's clearance ends:
  $Y_{k+1} \ge Y_k + d_2(L_k)$ for $1 \le k < j$

Assume the alignment rail begins at $X_1 \ge 0$. Your goal is to find a sequence of the $j$ lenses and a valid coordinate assignment that minimizes the furthest coordinate reached on the Secondary Axis by the final lens, which is defined as $Y_j + d_2(L_j)$. Report this smallest possible final boundary value.

Note: The answer may exceed the range of a 32-bit signed integer.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $d_1$ and $d_2$ ($1 \le d_1, d_2 \le 1000000$): the Primary and Secondary Axis clearances of a lens.

## Output

Print a single integer: the smallest possible final boundary value.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one lens with $d_1 = 5$ and $d_2 = 3$. We can set $X_1 = 0$, satisfying $X_1 \ge 0$. The alignment rules require $Y_1 \ge X_1 + d_1(L_1) = 5$. We can set $Y_1 = 5$. The final boundary value is $Y_1 + d_2(L_1) = 5 + 3 = 8$.
