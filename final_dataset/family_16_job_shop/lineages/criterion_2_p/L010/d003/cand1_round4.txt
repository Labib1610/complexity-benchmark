<STATEMENT>
# Abstract Sequence Recurrence

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a multiset of $j$ pairs of integers. You must arrange these $j$ pairs into a single sequence $P_1, P_2, \dots, P_j$ (a permutation of the given pairs).

Each pair is associated with two values. For each pair, you are given its primary value, $d_1$, and its secondary value, $d_2$. Let $d_1(P_k)$ and $d_2(P_k)$ denote the respective values for the pair placed at position $k$ in your sequence.

You must assign a primary variable $X_k$ and a secondary variable $Y_k$ for each position $k$ ($1 \le k \le j$). The assignment must satisfy the following difference constraints:
- $X_{k+1} - X_k \ge d_1(P_k)$ for $1 \le k < j$
- $Y_k - X_k \ge d_1(P_k)$ for $1 \le k \le j$
- $Y_{k+1} - Y_k \ge d_2(P_k)$ for $1 \le k < j$

Assume $X_1 \ge 0$. Find a sequence of the $j$ pairs and a valid variable assignment that minimizes the final target value, defined as $Y_j + d_2(P_j)$. Report this smallest possible target value.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $d_1$ and $d_2$ ($1 \le d_1, d_2 \le 1000000$): the primary and secondary values of a pair.

## Output

Print a single integer: the smallest possible final target value.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one pair with $d_1 = 5$ and $d_2 = 3$. We can set $X_1 = 0$, satisfying $X_1 \ge 0$. The constraints require $Y_1 - X_1 \ge d_1(P_1) = 5$, giving $Y_1 \ge 5$. We can set $Y_1 = 5$. The final target value is $Y_1 + d_2(P_1) = 5 + 3 = 8$.
