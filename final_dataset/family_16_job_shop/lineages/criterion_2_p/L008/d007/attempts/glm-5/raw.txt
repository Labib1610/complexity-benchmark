Looking at this problem, I need to find an optimal ordering of sectors to minimize the completion metric.

Let me trace through the mechanics:
- Primary tracker after all sectors = sum of all p1 values (fixed regardless of order)
- Secondary tracker evolves based on the sequence

For each sector with (p1, p2):
- baseline = secondary - p1
- threshold = primary + p1 (primary is the value BEFORE adding this p1)
- target = max(baseline, threshold)
- secondary = target + 2*p2

Let me define:
- S = sum of all p1 (final primary tracker)
- After sector i: secondary = max(prev_secondary - p1_i, primary_before_i + p1_i) + 2*p2_i

The completion metric = (S + final_secondary) / 2.

Since S is fixed, I need to minimize final_secondary.

Let me think about this differently. Let's track the "excess" = secondary - primary at each step.

Initially excess = 0. After processing sector i:
- new_primary = old_primary + p1_i
- target = max(old_secondary - p1_i, old_primary + p1_i)
- new_secondary = target + 2*p2_i

Excess after = new_secondary - new_primary = max(old_secondary - p1_i, old_primary + p1_i) + 2*p2_i - old_primary - p1_i
= max(old_secondary - old_primary - 2*p1_i, 0) + 2*p2_i
= max(old_excess - 2*p1_i, 0) + 2*p2_i

So excess evolves as: excess = max(excess - 2*p1, 0) + 2*p2

Final secondary = S + final_excess, so metric = (S + S + final_excess)/2 = S + final_excess/2.

Since S is fixed, minimize final_excess.

This is a classic scheduling problem! We want to minimize the final "excess" where each job has a "cost" of 2*p1 (reduction) and "gain" of 2*p2 (addition).

The optimal strategy: process jobs where p1 > p2 first (in decreasing order of p1), then jobs where p1 ≤ p2 (in increasing order of p2). This is the classic "minimize maximum lateness" / Johnson's rule variant.

Let me verify with Example 1:
- Sectors: (3,2), (2,4), (1,3)
- p1 > p2: (3,2) → sort by p1 desc: (3,2)
- p1 ≤ p2: (2,4), (1,3) → sort by p2 asc: (1,3), (2,4)
- Order: (3,2), (1,3), (2,4)

Excess: start 0
- (3,2): max(0-6,0)+4 = 4
- (1,3): max(4-2,0)+6 = 8
- (2,4): max(8-4,0)+8 = 12

S = 6, metric = 6 + 12/2 = 12. But expected is 10...

Let me try the example's order: (1,3), (2,4), (3,2)
- (1,3): max(0-2,0)+6 = 6
- (2,4): max(6-4,0)+8 = 10
- (3,2): max(10-6,0)+4 = 8

S = 6, metric = 6 + 8/2 = 10. ✓

So the optimal order has p1 ≤ p2 sectors first. Let me reconsider: we want to minimize final excess, so we should do "gain-heavy" jobs (p2 > p1) later, and "reduction-heavy" jobs (p1 > p2) first... but that gave 12.

Actually, let me reconsider. The excess only grows when excess < 2*p1 (then we reset to 0 and add 2*p2). When excess ≥ 2*p1, we subtract 2*p1 and add 2*p2.

To minimize final excess, we want to end with jobs that reduce excess (p1 > p2) and the excess should be large enough to absorb them.

The correct approach: jobs with p1 > p2 should come last (in increasing order of p2), and jobs with p1 ≤ p2 should come first (in increasing order of p2). Let me verify:

Order: (1,3), (2,4) [p1≤p2, by p2 asc], then (3,2) [p1>p2, by p2 asc]
- (1,3): max(0-2,0)+6 = 6
- (2,4): max(6-4,0)+8 = 10
- (3,2): max(10-6,0)+4 = 8

S=6, metric = 6 + 4 = 10. ✓

Let me verify Example 3: all (2,2), p1=p2, so all in first group by p2 asc (any order).
- (2,2): max(0-4,0)+4 = 4
- (2,2): max(4-4,0)+4 = 4
- (2,2): max(4-4,0)+4 = 4

S=6, metric = 6 + 2 = 8. ✓

Example 2: (5,3), p1>p2, second group.
- (5,3): max(0-10,0)+6 = 6
S=5, metric = 5 + 3 = 8. ✓

So the algorithm:
1. Split into group A (p1 ≤ p2) sorted by p2 ascending
2. Group B (p1 > p2) sorted by p2 ascending
3. Process A then B, tracking excess
4. Answer = S + excess/2

```python
import sys

def main():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    j = int(input_data[idx]); idx += 1
    
    group_a = []  # p1 <= p2
    group_b = []  # p1 > p2
    total_p1 = 0
    
    for _ in range(j):
        p1 = int(input_data[idx]); idx += 1
        p2 = int(input_data[idx]); idx += 1
        total_p1 += p1
        if p1 <= p2:
            group_a.append((p2, p1))
        else:
            group_b.append((p2, p1))
    
    group_a.sort()
    group_b.sort()
    
    excess = 0
    for p2, p1 in group_a:
        excess = max(excess - 2*p1, 0) + 2*p2
    for p2, p1 in group_b:
        excess = max(excess - 2*p1, 0) + 2*p2
    
    print(total_p1 + excess // 2)

main()
```
