 We can model this as a scheduling problem.  
The key is that the Radar Rover must process all sectors in priority order, and the Sampling Rover can only start a sector after Radar finishes it, but it also must follow priority order among available jobs.

This is essentially a **two-machine flow shop** problem with the same order on both machines, which is solved optimally by **Johnson’s rule**.  
Johnson’s rule minimizes the makespan (total completion time) for two machines when all jobs must go through machine 1 then machine 2 in the same order.

**Johnson’s rule:**
- Partition jobs into two sets:
  - Set A: jobs where `p1 <= p2`
  - Set B: jobs where `p1 > p2`
- Sort Set A by `p1` ascending.
- Sort Set B by `p2` descending.
- The optimal sequence is A followed by B.

Then simulate the schedule to get the total time.

Here’s the implementation:

```python
n = int(input())
jobs = []
for _ in range(n):
    p1, p2 = map(int, input().split())
    jobs.append((p1, p2))

# Johnson's rule
A = []
B = []
for p1, p2 in jobs:
    if p1 <= p2:
        A.append((p1, p2))
    else:
        B.append((p1, p2))

A.sort(key=lambda x: x[0])  # sort by p1 ascending
B.sort(key=lambda x: x[1], reverse=True)  # sort by p2 descending

order = A + B

# Simulate
time_radar = 0
time_sampling = 0
for p1, p2 in order:
    time_radar += p1
    if time_sampling < time_radar:
        time_sampling = time_radar
    time_sampling += p2

print(time_sampling)
```
