# Problem B — Expedition Pipeline

Time limit: 1 s   Memory limit: 256 MB

## Description

An expedition needs to survey **j** distinct sectors. For each sector, you are given a surface scan parameter **p1** and a deep core extraction parameter **p2**.

You must arrange the **j** sectors into a single linear sequence. As the expedition processes your sequence sector by sector, it tracks a `calibration level`, which is initially 0.

For each sector in your sequence, the `calibration level` is updated to the maximum of the following two values:
1. The value obtained by taking the current `calibration level`, subtracting the sector's **p1** parameter, and then adding the sector's **p2** parameter.
2. The sector's **p2** parameter exactly.

After all **j** sectors have been processed, the expedition's overall completion metric is calculated as the sum of the **p1** parameters of all **j** sectors, plus the final `calibration level`.

Determine the sequence of sectors that minimizes this overall completion metric. Report that smallest possible metric.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the surface scan parameter and deep core extraction parameter for a sector, respectively.

## Output

Print a single integer: the smallest possible overall completion metric.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal sequence is the third sector, then the second, then the first.
- Processing the third sector (1, 3): The `calibration level` updates to max(0 - 1 + 3, 3) = max(2, 3) = 3.
- Processing the second sector (2, 4): The `calibration level` updates to max(3 - 2 + 4, 4) = max(5, 4) = 5.
- Processing the first sector (3, 2): The `calibration level` updates to max(5 - 3 + 2, 2) = max(4, 2) = 4.
After processing all sectors, the final `calibration level` is 4. The sum of all **p1** parameters is 3 + 2 + 1 = 6. The overall completion metric is 6 + 4 = 10.

In Example 2, processing the single sector (5, 3):
- The `calibration level` updates to max(0 - 5 + 3, 3) = max(-2, 3) = 3.
The sum of all **p1** parameters is 5. The overall completion metric is 5 + 3 = 8.
