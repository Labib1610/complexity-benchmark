We need to schedule jobs on two machines: a surface scanner and a deep core extractor. Each job has a surface time and a deep core time. The surface scanner can process only one job at a time, and the deep core extractor can process only one job at a time. The deep core extraction for a job can only start after its surface scan is complete. We want to minimize the makespan (total time to finish all jobs).

This is a classic two-machine flow shop scheduling problem, and the optimal solution is given by Johnson's rule:

1. Split jobs into two sets:
   - Set A: jobs where surface time ≤ deep core time.
   - Set B: jobs where surface time > deep core time.
2. Sort Set A by surface time ascending.
3. Sort Set B by deep core time descending.
4. The optimal sequence is Set A followed by Set B.

Then simulate the schedule to compute the makespan.

Let's implement this.

```python
def solve():
    n = int(input().strip())
    jobs = []
    for _ in range(n):
        s, d = map(int, input().split())
        jobs.append((s, d))
    
    A = []
    B = []
    for s, d in jobs:
        if s <= d:
            A.append((s, d))
        else:
            B.append((s, d))
    
    A.sort(key=lambda x: x[0])  # ascending surface time
    B.sort(key=lambda x: x[1], reverse=True)  # descending deep time
    
    sequence = A + B
    
    surface_end = 0
    deep_end = 0
    for s, d in sequence:
        surface_end += s
        if deep_end < surface_end:
            deep_end = surface_end
        deep_end += d
    
    print(deep_end)

if __name__ == "__main__":
    solve()
```
