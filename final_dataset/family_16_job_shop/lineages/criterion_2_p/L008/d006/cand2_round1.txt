# Problem B — Stability Index

Time limit: 1 s   Memory limit: 256 MB

## Description

An expedition needs to process **j** sectors. For each sector, you are given a calibration shift **p1** and a baseline target **p2**.

You must arrange the **j** sectors into a single linear sequence. As the expedition processes your sequence sector by sector, it maintains a `stability index` (initially 0).

For each sector in your sequence, the `stability index` is updated as follows:
First, the index is temporarily adjusted by subtracting **p1** and adding **p2** (note that this temporary value can be negative).
Then, the sector's intrinsic properties guarantee a baseline: if this adjusted index is strictly less than **p2**, the index is immediately boosted to exactly **p2**.
Equivalently, the new `stability index` is calculated as `max(current_index - p1 + p2, p2)`.

After all **j** sectors have been processed, the overall completion metric is calculated as the final `stability index` plus the total sum of the **p1** parameters of all **j** sectors.

Determine the sequence of sectors that minimizes this overall completion metric. Report that smallest possible metric.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the calibration shift and baseline target for a sector, respectively.

## Output

Print a single integer: the smallest possible overall completion metric.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal sequence is the third sector, then the second, then the first.
- Processing the third sector (1, 3): The starting index is 0. The adjusted index is 0 - 1 + 3 = 2. Since 2 is less than the baseline 3, the index is boosted to 3. (Equivalently, max(0 - 1 + 3, 3) = 3).
- Processing the second sector (2, 4): The current index is 3. The adjusted index is 3 - 2 + 4 = 5. Since 5 is not less than 4, the index remains 5. (max(3 - 2 + 4, 4) = 5).
- Processing the first sector (3, 2): The current index is 5. The adjusted index is 5 - 3 + 2 = 4. Since 4 is not less than 2, the index remains 4. (max(5 - 3 + 2, 2) = 4).
The final `stability index` is 4. The sum of all **p1** parameters is 1 + 2 + 3 = 6.
The overall completion metric is 4 + 6 = 10.

In Example 2, processing the single sector (5, 3):
- The starting index is 0. The adjusted index is 0 - 5 + 3 = -2. Since -2 is less than 3, the index is boosted to 3. (max(0 - 5 + 3, 3) = 3).
The final `stability index` is 3. The sum of all **p1** parameters is 5.
The overall completion metric is 3 + 5 = 8.
