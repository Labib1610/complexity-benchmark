# Problem B — Studio Pipeline

Time limit: 1 s   Memory limit: 256 MB

## Description

A studio handles **j** commissions. Each commission has a sketching duration and a coloring duration. You must choose a sequence in which to arrange these **j** commissions.

A manager will review your sequence. To evaluate the timeline, the manager will select exactly one commission, say the one at position $k$ (where $1 \le k \le j$), as the "pivot". The timeline's score for that pivot is calculated as:
- The sum of the sketching durations of all commissions from the 1st up to and including the $k$-th commission in your sequence, PLUS
- The sum of the coloring durations of all commissions from the $k$-th up to and including the **j**-th commission in your sequence.

Since the manager can choose any of the **j** commissions to be the pivot, the overall timeline cost is defined as the **maximum** score among all **j** possible pivots.

Choose the order of the commissions so that this overall timeline cost is as small as possible. Report that smallest possible cost.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the sketching and coloring durations of a commission.

## Output

Print a single integer: the smallest possible overall timeline cost.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal arrangement is to place the commissions in the following order: the third commission (1, 3), then the second (2, 4), then the first (3, 2).
The 3 possible pivot choices yield the following scores:
- Pivot at position 1: (1) + (3 + 4 + 2) = 10
- Pivot at position 2: (1 + 2) + (4 + 2) = 9
- Pivot at position 3: (1 + 2 + 3) + (2) = 8
The maximum score for this arrangement is 10. No other arrangement yields a smaller maximum score.

In Example 2, the single commission has durations 5 and 3. The only pivot is at position 1, giving a score of (5) + (3) = 8.
