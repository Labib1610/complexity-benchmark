We can solve this by sorting the vessels using a greedy rule:  
- Vessels with smaller `t1` should go first, but if `t1` is equal, larger `t2` should go first.  
This is a known optimal ordering for two-machine flow shop scheduling (Johnson’s rule).

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    j = int(data[0])
    vessels = []
    idx = 1
    for _ in range(j):
        t1 = int(data[idx])
        t2 = int(data[idx + 1])
        idx += 2
        vessels.append((t1, t2))
    
    # Johnson's rule: sort by t1 ascending, t2 descending when t1 equal
    vessels.sort(key=lambda x: (x[0], -x[1]))
    
    alpha_end = 0
    beta_end = 0
    for t1, t2 in vessels:
        alpha_end += t1
        if beta_end < alpha_end:
            beta_end = alpha_end
        beta_end += t2
    
    print(beta_end)

if __name__ == "__main__":
    main()
```
