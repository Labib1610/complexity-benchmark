<STATEMENT>
# Problem B — Signal Amplifier Chain

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given **j** amplifier modules to connect in a linear sequence. You must determine the optimal order in which to arrange them.

Each module has a specific *gain* parameter and a *drop* parameter.

When the modules are arranged in a sequence, the internal voltage is measured at **j** different test points (one test point immediately after each module). The voltage at each test point is determined as follows:
- The voltage at test point 1 (after the first module) is exactly the gain parameter of the first module in the sequence.
- For each subsequent module $k$ (from 2 to $j$), the voltage at test point $k$ is exactly:
  (the voltage at test point $k-1$) + (the gain of module $k$) - (the drop of module $k-1$).

Note that the drop of the $j$-th (last) module does not decrease the voltage at any test point, but it still counts towards the total drop of the system.

The *peak voltage* of your sequence is the maximum voltage recorded across all **j** test points.

The system's *overall rating* is calculated as the peak voltage of the sequence, PLUS the sum of the drop parameters of all **j** modules.

Determine the arrangement of the modules that minimizes the peak voltage (and therefore minimizes the overall rating). Output this minimum possible overall rating.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the gain parameter and the drop parameter of a module.

## Output

Print a single integer: the smallest possible overall rating.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single module has a gain parameter of 5 and a drop parameter of 3. The voltage at test point 1 is 5. The peak voltage is 5. The sum of all drop parameters is 3. The overall rating is 5 + 3 = 8.
