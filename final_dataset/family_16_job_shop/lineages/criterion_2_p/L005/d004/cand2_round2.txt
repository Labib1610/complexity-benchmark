# Problem B — Packet Relay

Time limit: 1 s   Memory limit: 256 MB

## Description

You are responsible for routing a batch of **j** data packets from a source server to a destination server through a single intermediate relay node. You must choose a strict transmission sequence for the batch.

The network operates under the following mechanics:
- The source server transmits the packets to the relay node in your chosen sequence, one after another, continuously without any gaps.
- The relay node then transmits the packets to the destination server in that exact same sequence, one after another.
- The relay node is single-threaded and can only process one outgoing packet at a time. It will begin transmitting a packet to the destination server at the exact moment both of these prerequisites are satisfied:
  1. The packet has been fully received from the source server.
  2. The relay node's outgoing channel is free (i.e., it has completely finished transmitting the previous packet in your sequence, if any).

For each packet, you are given two parameters: the time it takes the source server to transmit it to the relay node, and the time it takes the relay node to transmit it to the destination server.

Your objective is to determine the transmission sequence of the **j** packets that minimizes the exact time at which the relay node finishes transmitting the final packet in the sequence. Output this minimum possible time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the source transmission time and the relay transmission time of a packet.

## Output

Print a single integer: the smallest possible time at which the relay node finishes transmitting the last packet.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single packet takes 5 units of time for the source server to transmit, and 3 units of time for the relay node to transmit. The source server finishes transmitting at time 5. The relay node then immediately begins transmitting, finishing at time 5 + 3 = 8.

<RISK>
Models might misinterpret "continuously without any gaps" as meaning the relay node also transmits without gaps, but the explicit prerequisites for the relay node's transmission clarify that it must wait for packets to arrive and for its channel to be free.
