# Problem B — Canal Convoy

Time limit: 1 s   Memory limit: 256 MB

## Description

A fleet of **j** vessels must travel down a narrow canal. Because overtaking is impossible, you must arrange the fleet into a strict entry sequence.

Each vessel has a specific *bow parameter* and a specific *stern parameter*.

Once you choose the sequence of the $j$ vessels, their parameters form a $2 \times j$ grid. The top row of the grid consists of the bow parameters of the vessels in your chosen order. The bottom row consists of their stern parameters in the same order.

An automated tracking system evaluates your sequence by calculating its *clearance time*. To do this, it considers all possible valid paths through the grid from the top-left cell (the bow parameter of the first vessel) to the bottom-right cell (the stern parameter of the last vessel). 
A valid path can only move right (to the parameter of the next vessel in the same row) or down (from the bow parameter to the stern parameter of the same vessel). It cannot move left or up.

The cost of a path is the sum of the parameters in all the cells it visits. The clearance time of your sequence is the **maximum** possible cost among all valid paths through the grid.

Determine the arrangement of the fleet that minimizes this clearance time. Output this minimum possible clearance time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the bow parameter and the stern parameter of a vessel.

## Output

Print a single integer: the smallest possible clearance time.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, if we order the vessels as Vessel 3, then Vessel 2, then Vessel 1, the grid is:
Top row (bow):   1  2  3
Bottom row (stern): 3  4  2

There are 3 valid paths from the top-left to the bottom-right:
- Path 1 (move down at the 1st vessel): 1 + 3 + 4 + 2 = 10
- Path 2 (move down at the 2nd vessel): 1 + 2 + 4 + 2 = 9
- Path 3 (move down at the 3rd vessel): 1 + 2 + 3 + 2 = 8

The clearance time for this sequence is the maximum of these path costs, which is 10. No other arrangement of the vessels produces a clearance time strictly less than 10.

In Example 2, the single vessel forms a $2 \times 1$ grid. The only valid path visits the top cell (5) and then the bottom cell (3). Its cost is 5 + 3 = 8.
