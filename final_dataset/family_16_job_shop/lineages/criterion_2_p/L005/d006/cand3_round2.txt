# Problem B — Dual-Track Railway Layout

Time limit: 1 s   Memory limit: 256 MB

## Description

A set of **j** signal zones must be organized for a dual-track railway layout. You must arrange the signal zones into a strict sequence, determining exactly which zone is placed first, second, and so on.

For each signal zone, the layout consists of two distinct physical installations: the Alpha installation on Track A and the Beta installation on Track B. You are provided the length of the Alpha installation, **t1**, and the length of the Beta installation, **t2**, for each signal zone.

To ensure proper synchronization, the placement of these installations along the tracks is strictly dictated by the following spatial constraints:
- The Alpha installation for the first signal zone in your sequence begins at distance coordinate 0.
- For every signal zone after the first, its Alpha installation begins at the exact distance coordinate where the Alpha installation of the preceding signal zone ends.
- A signal zone's Beta installation begins at the smallest distance coordinate such that all applicable conditions below are true:
  1. The coordinate is at least the distance coordinate where the signal zone's own Alpha installation ends.
  2. If the signal zone is not the first in the sequence, the coordinate is at least the distance coordinate where the Beta installation of the preceding signal zone ends.
- A signal zone's Alpha installation occupies exactly its given **t1** length.
- A signal zone's Beta installation occupies exactly its given **t2** length.

Your task is to determine the optimal sequence of the signal zones that minimizes the distance coordinate at which the Beta installation for the final signal zone ends.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the Alpha installation length and the Beta installation length of a signal zone.

## Output

Print a single integer: the smallest possible distance coordinate at which the Beta installation for the final signal zone in your sequence ends.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single signal zone has an Alpha installation length of 5 and a Beta installation length of 3. Its Alpha installation begins at distance coordinate 0 and ends at distance coordinate 5. Its Beta installation begins immediately at distance coordinate 5, ending at distance coordinate 5 + 3 = 8.
