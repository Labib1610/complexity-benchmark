# Problem B — Composite Pillar

Time limit: 1 s   Memory limit: 256 MB

## Description

You are constructing a composite pillar out of **j** distinct cylindrical segments. You must determine the order in which to stack these segments from top (position 1) to bottom (position **j**).

Each segment has two material properties: a core density **t1** and a mantle density **t2**.

When subjected to pressure, a critical stress line will form through the pillar. The stress line always begins at the top of the pillar in the core. At some segment **k** (where 1 ≤ k ≤ j), the stress line deflects from the core into the mantle, and stays in the mantle from segment **k** all the way down to the bottom of the pillar.

The total mechanical strain of such a stress line is calculated as the sum of:
- The core densities (**t1**) of all segments from position 1 down to position **k** (inclusive).
- The mantle densities (**t2**) of all segments from position **k** down to position **j** (inclusive).

Notice that the segment at position **k**, where the deflection occurs, contributes both its core density and its mantle density to the total mechanical strain.

Structural failure happens along the stress line that produces the **maximum** possible total mechanical strain. Therefore, for any given ordering of the segments, the pillar's overall vulnerability is defined as this maximum strain over all possible deflection segments **k** (1 ≤ k ≤ j).

Your task is to find an ordering of the **j** segments that minimizes the pillar's overall vulnerability.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the core density and the mantle density of a segment.

## Output

Print a single integer: the smallest possible vulnerability (the minimum possible maximum total mechanical strain) of the pillar.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only a single segment, so the stress line must deflect at position k = 1. The total mechanical strain is the core density of the segment (5) plus its mantle density (3), which equals 8.

<RATIONALE>
I completely removed the two-machine flow-shop scheduling scenario, which models easily pattern-match to Johnson's rule. I replaced it with a mathematically isomorphic minimax problem over prefix and suffix sums of structural weights. To solve it, the model must now independently recognize that minimizing the maximum prefix-plus-suffix sum is structurally identical to the makespan of a two-machine pipeline, forcing genuine algorithmic deduction rather than keyword-triggered pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The makespan of a 2-machine flow-shop is mathematically equivalent to the maximum, over all possible transition points k, of the sum of the first phase's durations up to k and the second phase's durations from k onwards; thus the objective function evaluates to the exact same value for every permutation.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains optimally solvable in O(j log j) time using Johnson's rule, as the underlying mathematical objective function and permutation space are identical to the seed.
</PRESERVED_CLASS>
<RISK>
Models might struggle to parse the definition of the stress line's mechanical strain, though the phrasing "sum of... from position 1 down to position k (inclusive)" is highly standard and explicitly clarified in the note.
</RISK>
