We can solve this by sorting the vessels in a specific order.  

The key observation is:  
For two consecutive vessels A and B, the total time depends on their order.  
If we have vessel A with `(t1_A, t2_A)` and vessel B with `(t1_B, t2_B)`,  
the difference in completion time between order A→B and B→A can be compared.  

The optimal order is to sort by `t2` descending, and if equal, by `t1` descending.  
This is a known greedy for this type of scheduling problem.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    j = int(input())
    vessels = []
    for _ in range(j):
        t1, t2 = map(int, input().split())
        vessels.append((t1, t2))
    
    # Sort by stern parameter descending, then bow parameter descending
    vessels.sort(key=lambda x: (-x[1], -x[0]))
    
    time = 0
    for t1, t2 in vessels:
        time = max(time, 0) + t1
        time += t2
    
    print(time)

if __name__ == "__main__":
    main()
```
