# Problem B — Waterway Routing

Time limit: 1 s   Memory limit: 256 MB

## Description

A fleet of vessels must travel through a two-part waterway. Every vessel must first navigate the Upstream stretch, and then immediately navigate the Downstream lock.

Because both sections are strictly one-lane and overtaking is physically impossible, the vessels must be organized into a single sequence before entering. This sequence dictates their order through the entire waterway.

Once the fleet's sequence is chosen, their progress is deterministic:
- The Upstream stretch processes vessels sequentially without gaps. The first vessel starts at time 0, and each following vessel enters the Upstream stretch precisely when the one before it exits.
- The Downstream lock also processes vessels sequentially. A vessel will enter the Downstream lock as soon as it is physically able to do so. This happens at the exact moment it clears the Upstream stretch, or the exact moment the previous vessel clears the Downstream lock, whichever is later. (The first vessel naturally enters the Downstream lock the exact moment it clears the Upstream stretch).

You are given the duration each vessel takes to clear the Upstream stretch, and the duration it takes to clear the Downstream lock. Determine the sequence of the fleet that minimizes the time at which the final vessel completes the Downstream lock. Output this minimum possible completion time.

The fleet contains at least one vessel, and the waterway's daily processing capacity guarantees the total number of vessels **j** will not exceed two hundred thousand. For each vessel, both transit durations are given as integers. Due to waterway speed limits, each transit duration is at least 1, and no single transit duration will exceed one million.

## Input

The first line contains a single integer **j**, representing the number of vessels in the fleet.
Each of the next **j** lines contains exactly 2 integers **t1** and **t2**: the time required for the vessel to navigate the Upstream stretch and the time required to navigate the Downstream lock, respectively.

## Output

Print a single integer: the smallest possible time at which the last vessel completes the Downstream lock.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single vessel takes 5 to clear the Upstream stretch, finishing at time 5. It immediately enters the Downstream lock, taking 3, and finishes at time 8.
