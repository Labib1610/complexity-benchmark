<METHOD_NAME>Point-wise Contribution Masking</METHOD_NAME>
<METHOD_DESCRIPTION>Instead of defining the objective via prefix and suffix sums over the sequence, the objective is defined by how each element contributes to any given position $k$ based on its relative placement ($i < k$, $i > k$, or $i = k$). This mathematically evaluates to the exact same prefix+suffix sums, but prevents LLMs from pattern-matching the "sum from 1 to k" phrases that trigger Johnson's rule templates.</METHOD_DESCRIPTION>

# Problem B — Interference Minimization

Time limit: 1 s   Memory limit: 256 MB

## Description

You must install a set of **j** transmitter modules into a linear array of slots numbered $1$ to $j$. You must arrange the modules into a strict sequence, assigning each module to exactly one slot so that every slot contains exactly one module.

For each module, you are provided its forward emission value, **t1**, and its backward emission value, **t2**.

Once all modules are installed in your chosen sequence, they generate interference at every slot. For any specific slot $k$ (where $k$ ranges from $1$ to $j$), the total interference at slot $k$ is the sum of the contributions from all $j$ modules. 

A module placed at slot $i$ contributes to the interference at slot $k$ based on its relative position:
- If $i < k$ (the module is placed before slot $k$), it contributes its forward emission **t1** to slot $k$.
- If $i = k$ (the module is placed exactly at slot $k$), it contributes both its forward and backward emissions (**t1** + **t2**) to slot $k$.
- If $i > k$ (the module is placed after slot $k$), it contributes its backward emission **t2** to slot $k$.

The *peak interference* of your chosen sequence is defined as the maximum total interference found across all $j$ possible slots. 

Your task is to determine an optimal sequence of the modules that minimizes this overall *peak interference*.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the forward emission and the backward emission of a module.

## Output

Print a single integer: the smallest possible *peak interference* you can achieve by optimally sequencing the modules.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one module ($j=1$) placed at slot $i=1$. The only slot to evaluate is $k=1$. Since $i=k$, the module contributes both its forward emission (5) and backward emission (3) to slot 1. The total interference at slot 1 is 5 + 3 = 8. The peak interference is therefore 8.
</STATEMENT>
<RATIONALE>
I completely removed the "prefix sum plus suffix sum" wording that solvers use to pattern-match Johnson's rule. Instead, I defined the objective through point-wise contributions of a piecewise function based on relative positions ($i < k$, $i = k$, $i > k$), forcing the model to algebraically deduce that this equates to the classic prefix and suffix sums before it can recognize the underlying flow-shop structure.
</RATIONALE>
<PRESERVED_ANSWER>
The total interference at slot $k$ mathematically simplifies to the exact same formula (sum of $t1$ for $i \le k$ plus sum of $t2$ for $i \ge k$), meaning the objective function and thus the optimal sequence and value are perfectly identical for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to minimizing the makespan of a 2-machine flow shop, which is optimally solved in $O(j \log j)$ time using Johnson's rule.
</PRESERVED_CLASS>
