<STATEMENT>
# Problem B — Artifact Alignment

Time limit: 1 s   Memory limit: 256 MB

## Description

A collection of **j** magical artifacts must be arranged into a strict linear sequence. You must determine the exact order of the artifacts, from first to last.

Each artifact has two properties: a *resonance influx*, **t1**, and a *resonance decay*, **t2**.

To evaluate the stability of your chosen sequence, a sequential test is performed. The test tracks two values, $A$ and $C$, and records the peak instability. The procedure is as follows:

1. First, calculate the total sum of the resonance decay (**t2**) values for all **j** artifacts. Set $C$ to this total.
2. Initialize the accumulated influx $A = 0$.
3. Process the artifacts one by one, strictly in your chosen order. For each artifact:
   - Add its resonance influx (**t1**) to $A$.
   - Record the current *instability level*, which is calculated exactly as $A + C$.
   - Subtract this artifact's resonance decay (**t2**) from $C$.
4. The *overall instability* of your sequence is the highest *instability level* recorded during step 3.

Your task is to determine the optimal sequence of the artifacts that minimizes this *overall instability*.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the resonance influx and the resonance decay of an artifact.

## Output

Print a single integer: the smallest possible *overall instability* you can achieve by optimally sequencing the artifacts.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one artifact ($j=1$). The evaluation procedure runs as follows:
- In step 1, $C$ is set to the total decay of all artifacts (which is just 3).
- In step 2, $A$ is initialized to 0.
- In step 3, we process the single artifact:
  - Add its influx (5) to $A$, making $A = 5$.
  - Record the instability level: $A + C = 5 + 3 = 8$.
  - Subtract its decay (3) from $C$, making $C = 0$.
- In step 4, the highest instability level recorded is 8.
</STATEMENT>
<RATIONALE>
I transformed the explicit prefix-plus-suffix sum into a running state simulation. By having an accumulator $A$ increase with $t1$ and a countdown $C$ decrease with $t2$, the sum $A+C$ mathematically identically computes the chain duration at each step. This forces the model to symbolically execute the loop to discover the two-machine flow-shop structure, breaking the superficial pattern-matching of prefix/suffix formulas.
</RATIONALE>
<PRESERVED_ANSWER>
The sequence of values $A+C$ generated by the procedure is mathematically identical to the prefix and suffix sums of the seed for any given permutation, so the minimum possible peak value is identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The objective function evaluated is exactly the makespan of a 2-machine flow shop, meaning Johnson's algorithm still solves it optimally in O(j log j).
</PRESERVED_CLASS>
<RISK>
Models might misunderstand whether the initial $C$ includes all items or just the ones processed so far, though "all j artifacts" is explicitly stated.
</RISK>
