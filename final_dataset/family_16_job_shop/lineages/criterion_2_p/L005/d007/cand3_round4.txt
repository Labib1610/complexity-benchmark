# Problem B — Audit Peak

Time limit: 1 s   Memory limit: 256 MB

## Description

You are assigned to audit a set of **j** financial accounts. You must determine the exact sequence in which to process them, from first to last.

Each account has two values: an **inflow** **t1** and an **outflow** **t2**.

To evaluate the stability of your chosen sequence, an automated system calculates the **running balance** at each step of the audit. 
Before the audit begins, the system initializes the running balance to the sum of the **outflow** values (**t2**) of all **j** accounts.

Then, the system processes the accounts one by one in your chosen sequence. For each account at position $k$ (where $k$ ranges from $1$ to **j**):
1. The system adds the account's **inflow** (**t1**) to the running balance.
2. The system records the current running balance as the **exposure** at step $k$.
3. The system subtracts the account's **outflow** (**t2**) from the running balance before moving to the next step.

The **peak exposure** of the entire sequence is defined as the maximum **exposure** recorded among all **j** steps.

Your task is to determine the optimal sequence of the accounts that minimizes this peak exposure.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the inflow and outflow of an account.

## Output

Print a single integer: the smallest possible peak exposure you can achieve by optimally sequencing the accounts.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one account ($j=1$). 
- The initial running balance is the sum of all outflows: `3`.
- **Step 1**: Add the inflow (`5`) to the balance, making it `8`. The exposure at step 1 is `8`. Subtract the outflow (`3`), leaving a balance of `5`.
The peak exposure is `8`. This is the minimum possible since there is only one sequence.

In Example 1, the optimal sequence is to process the 3rd account, then the 2nd, then the 1st.
- The initial running balance is the sum of all outflows: `2 + 4 + 3 = 9`.
- **Step 1** (Account 3: inflow=1, outflow=3): Add 1 (balance = 10). Exposure is `10`. Subtract 3 (balance = 7).
- **Step 2** (Account 2: inflow=2, outflow=4): Add 2 (balance = 9). Exposure is `9`. Subtract 4 (balance = 5).
- **Step 3** (Account 1: inflow=3, outflow=2): Add 3 (balance = 8). Exposure is `8`. Subtract 2 (balance = 6).
The peak exposure across all steps is `10`.
