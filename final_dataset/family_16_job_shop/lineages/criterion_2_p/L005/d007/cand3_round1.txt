# Problem B — Satellite Boot Sequence

Time limit: 1 s   Memory limit: 256 MB

## Description

You are configuring the boot sequence for a satellite that consists of **j** distinct software modules. You must determine the exact order in which these modules will initialize.

Each module requires two power specifications: an **Activation Draw** ($A$) and a **Background Drain** ($B$). 

Before the boot sequence begins, all modules are in a standby state. The initial **System Load** is equal to the sum of the Background Drains of all **j** modules. The **Active Power** of the satellite starts at 0.

As the modules initialize one by one in your chosen sequence, the power system undergoes the following changes for each module:
1. The module's Activation Draw is permanently added to the satellite's **Active Power**.
2. The **Transient Stress** during this module's initialization is measured. This is exactly the current Active Power plus the current System Load.
3. The module completes its initialization and exits standby mode, so its Background Drain is permanently subtracted from the **System Load**.

The **Maximum Transient Stress** of the entire sequence is the highest Transient Stress measured across all $j$ initialization steps.

Your task is to find an ordering of the $j$ modules that minimizes the Maximum Transient Stress.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **A** and **B** (1 ≤ A, B ≤ 1000000): the Activation Draw and the Background Drain of a module.

## Output

Print a single integer: the smallest possible Maximum Transient Stress achievable by optimally ordering the boot sequence.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal sequence is to boot the modules in the order of the third module, then the second, then the first.
The initial System Load is $2 + 4 + 3 = 9$. The Active Power starts at $0$.

- **Step 1 (Module 3: A=1, B=3):**
  - Active Power increases by 1 (Total: 1).
  - Transient Stress is Active Power + System Load = $1 + 9 = 10$.
  - System Load decreases by 3 (Total: 6).
- **Step 2 (Module 2: A=2, B=4):**
  - Active Power increases by 2 (Total: 3).
  - Transient Stress is $3 + 6 = 9$.
  - System Load decreases by 4 (Total: 2).
- **Step 3 (Module 1: A=3, B=2):**
  - Active Power increases by 3 (Total: 6).
  - Transient Stress is $6 + 2 = 8$.
  - System Load decreases by 2 (Total: 0).

The Maximum Transient Stress across all steps is 10.

<RATIONALE>
The problem was completely reframed from calculating a static chain duration over a pivot to simulating a dynamic state over time. By defining the objective through an iterative process of adding and subtracting from running totals, the model is prevented from directly pattern-matching the prefix-suffix sum formula that is characteristic of the 2-machine flow shop scheduling problem. To succeed, the model must now algebraically unpack the simulation to recognize the underlying mathematical structure.
</RATIONALE>
<PRESERVED_ANSWER>
The Transient Stress at the k-th step evaluates to exactly the sum of Activation Draws up to step k plus the sum of Background Drains from step k to the end, which maps identically to the Alpha and Beta sector transit time logic of the seed.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
