# Problem B — Canal Convoy

Time limit: 1 s   Memory limit: 256 MB

## Description

A fleet of **j** vessels must be organized for a canal crossing. You must arrange the fleet into a strict sequence, determining exactly which vessel is first, second, and so on.

Each vessel has two characteristic values: a *bow coefficient* **t1** and a *stern coefficient* **t2**.

When the fleet is arranged in a specific sequence, a safety protocol evaluates the *structural stress* on the canal. The evaluation considers every position $k$ (where $k$ ranges from $1$ to $j$) in your sequence as a potential 'stress focal point'.

For a specific focal point at position $k$, its *local stress load* is exactly the sum of:
- The *bow coefficients* of all vessels from position $1$ up to position $k$ in your chosen sequence (inclusive).
- The *stern coefficients* of all vessels from position $k$ up to position $j$ in your chosen sequence (inclusive).

The *peak stress load* of the entire sequence is defined as the maximum *local stress load* calculated among all $j$ possible choices for the focal point position $k$.

Your task is to determine a sequence for the fleet that minimizes this *peak stress load*, and output this minimum possible value.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the bow coefficient and the stern coefficient of a vessel.

## Output

Print a single integer: the smallest possible *peak stress load* you can achieve by optimally sequencing the fleet.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one vessel ($j=1$). The only possible focal point is $k=1$. The local stress load for $k=1$ is the bow coefficient of the first vessel (5) plus the stern coefficient from position 1 onwards (3). The peak stress load is therefore 5 + 3 = 8.

<RATIONALE>
The seed problem exactly formulates the makespan of a 2-machine flow shop using a prefix-suffix sum over "transit times" through two "sectors". To break the pattern matching that allows models to instantly recall Johnson's rule, the temporal scheduling terminology was completely replaced with static structural properties ("bow/stern coefficients" and "stress load"). The exact algebraic prefix-suffix sum structure is preserved to prevent task drift, forcing the model to recognize the mathematical equivalence to a scheduling problem without semantic hints.
</RATIONALE>
<PRESERVED_ANSWER>
The objective function remains exactly the maximum over $k$ of the sum of the first parameter up to $k$ plus the sum of the second parameter from $k$ to $j$, so the minimal peak value is identical for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains algebraically identical to minimizing the makespan of a 2-machine flow shop, which is optimally solved in O(n log n) time using Johnson's rule.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "from position 1 up to position k" as referring to the input order rather than the chosen sequence, though the phrase "in your chosen sequence" explicitly mitigates this.
</RISK>
