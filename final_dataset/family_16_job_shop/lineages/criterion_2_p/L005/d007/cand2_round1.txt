# Problem B — Canal Convoy

Time limit: 1 s   Memory limit: 256 MB

## Description

A fleet of **j** vessels must be organized for a canal crossing. You must arrange the fleet into a strict sequence, determining exactly which vessel is first, second, and so on.

The maximum possible number of vessels in the fleet corresponds exactly to the number of seconds in 55 hours, 33 minutes, and 20 seconds; the minimum is 1.

Each vessel is characterized by two parameters: its Alpha sector transit time, **t1**, and its Beta sector transit time, **t2**. Each transit time is a positive integer that does not exceed the square of 1000.

The crossing procedure generates a base thermal load on the canal's monitoring system. This *baseline load* is exactly equal to the sum of the Beta sector transit times (**t2**) of all vessels in the fleet, regardless of their sequence.

As the vessels cross, the system experiences a series of load spikes. For each position $k$ independently (where $k$ ranges from $1$ to $j$), its *spike value* is calculated by taking the *baseline load* and applying these adjustments:
1. Add the Beta sector transit time (**t2**) of the vessel at position $k$.
2. For every position $i$ from $1$ up to $k$ (inclusive), add the Alpha transit time (**t1**) of the vessel at position $i$, and subtract the Beta transit time (**t2**) of the vessel at position $i$.

The *exposure rating* of the entire fleet sequence is defined as the maximum *spike value* observed across all $j$ positions.

Your task is to determine the optimal sequence of the fleet that minimizes this overall *exposure rating*.

## Input

The first line contains a single integer **j**.
Each of the next **j** lines contains exactly 2 integers **t1** and **t2**: the Alpha sector transit time and the Beta sector transit time of a vessel.

## Output

Print a single integer: the smallest possible *exposure rating* you can achieve by optimally sequencing the fleet.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one vessel ($j=1$). The baseline load is its Beta transit time (3). The only possible spike is at position $k=1$. We start with the baseline load (3), add the Beta transit time of the vessel at position 1 (3), then for position 1 we add its Alpha transit time (5) and subtract its Beta transit time (3). The spike value is therefore 3 + 3 + 5 - 3 = 8. The exposure rating is 8.

<RATIONALE>
The explicit prefix/suffix summation that models recognized as a 2-machine flow shop makespan has been algebraically manipulated into an equivalent running-balance formula. The bounds have also been replaced with indirect physical/arithmetic derivations. Models can no longer rely on pattern-matching the flow-shop objective and must now either symbolically reverse the algebra or correctly derive the optimal swap condition from scratch.
</RATIONALE>
<PRESERVED_ANSWER>
The new formula for the spike value at position k simplifies algebraically to exactly the same prefix-plus-suffix sum as the original chain duration, meaning every permutation evaluates to the identical score.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Because the objective function is mathematically equivalent for every sequence, the optimal solution remains achievable using Johnson's rule in O(n log n) time, keeping the problem in P.
</PRESERVED_CLASS>

A reader might mistakenly think the baseline load is cumulatively modified for each successive $k$, though the wording "For each position $k$ independently... taking the baseline load" explicitly guards against this.
