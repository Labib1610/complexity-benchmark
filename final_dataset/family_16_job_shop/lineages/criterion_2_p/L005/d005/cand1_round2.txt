# Problem B — Enchantment Sequence

Time limit: 1 s   Memory limit: 256 MB

## Description

You must perform a sequence of **j** magical enchantments. You need to determine the optimal order in which to cast them.

For each enchantment, you are given the duration of its spoken incantation, **t1**, and the duration of its aura stabilization, **t2**.

The process of casting the enchantments follows these precise rules:
- You choose a single strict sequence for the **j** enchantments.
- You begin speaking the incantation for the first enchantment in your sequence at time 0.
- You have only one mouth, so you must speak the incantations one after another. You do this back-to-back with no delays; as soon as you finish the incantation for one enchantment, you immediately begin the incantation for the next one in your sequence.
- After you finish an enchantment's incantation, its magical aura must then stabilize. This stabilization takes exactly **t2** seconds.
- The fabric of reality can only stabilize one aura at a time. Furthermore, auras must stabilize in the exact same sequence that they were chanted.
- Therefore, an enchantment's aura will only begin stabilizing once both of the following prerequisites are met:
  1. You have completely finished speaking its incantation.
  2. The aura of the preceding enchantment in your sequence (if any) has completely finished stabilizing.
- If you finish an incantation but the previous aura is still stabilizing, the new aura waits in suspension and begins stabilizing the exact moment the previous one finishes.

Your task is to find the ordering of the enchantments that minimizes the time at which the final enchantment's aura completely finishes stabilizing.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the incantation duration and the stabilization duration for an enchantment.

## Output

Print a single integer: the smallest possible time at which the final enchantment's aura completely finishes stabilizing.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one enchantment. Its incantation takes 5 seconds, finishing at time 5. Its aura immediately begins stabilizing, taking 3 seconds, and finishes at time 5 + 3 = 8.
