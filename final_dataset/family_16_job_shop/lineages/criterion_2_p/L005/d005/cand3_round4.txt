# Problem B — Permutation Recurrence

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a collection of **j** elements. For each element, you are provided with two positive integers: **t1** and **t2**.

You must arrange all **j** elements into a single sequence (a permutation). Once you have chosen this sequence, let the **t1** values of the elements in your chosen order be denoted as $X_1, X_2, \dots, X_j$, and their corresponding **t2** values be denoted as $Y_1, Y_2, \dots, Y_j$.

Based on your sequence, we define two series of values, $A_0, A_1, \dots, A_j$ and $B_0, B_1, \dots, B_j$, computed according to the following rules:
- $A_0 = 0$
- $B_0 = 0$
- For each index $k$ from $1$ to **j**:
  - $A_k = A_{k-1} + X_k$
  - $B_k = \max(A_k, B_{k-1}) + Y_k$

Your task is to determine the optimal ordering of the **j** elements that minimizes the final value $B_j$.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the two values associated with an element.

## Output

Print a single integer: the smallest possible value of $B_j$ that can be achieved by optimally ordering the elements.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only a single element, so the sequence is trivially chosen. We have $X_1 = 5$ and $Y_1 = 3$.
First, we compute the $A$ sequence: $A_1 = A_0 + X_1 = 0 + 5 = 5$.
Then, we compute the $B$ sequence: $B_1 = \max(A_1, B_0) + Y_1 = \max(5, 0) + 3 = 8$.
The final value $B_1$ is 8.
