# Problem B — Sequence Evaluation

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a collection of $j$ pairs of positive integers. The $i$-th pair is $(x_i, y_i)$.

You must choose a permutation $P$ of the indices $1, 2, \dots, j$. This permutation reorders the pairs into a sequence: $(x_{P[1]}, y_{P[1]}), (x_{P[2]}, y_{P[2]}), \dots, (x_{P[j]}, y_{P[j]})$.

For a chosen permutation $P$, we define the evaluation function $E(P)$ as the maximum value over all possible split points $k$ ($1 \le k \le j$) of the following sum:

$$E(P) = \max_{1 \le k \le j} \left( \sum_{i=1}^{k} x_{P[i]} + \sum_{i=k}^{j} y_{P[i]} \right)$$

In other words, for a chosen split point $k$, you sum the $x$-values of the first $k$ pairs in your sequence, and add the sum of the $y$-values of the pairs from index $k$ to $j$ inclusive. The evaluation $E(P)$ is the maximum of these sums across all $j$ possible choices of $k$.

Your task is to find a permutation $P$ that minimizes $E(P)$, and output this minimum possible value.

## Input

The first line contains a single integer **j** (1 ≤ **j** ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **x** and **y** (1 ≤ **x**, **y** ≤ 1000000): the values for a pair.

## Output

Print a single integer: the smallest possible value of $E(P)$ over all valid permutations $P$.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1

```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, if we choose the permutation $P = [3, 2, 1]$, the sequence of pairs is $(1, 3), (2, 4), (3, 2)$.
We can evaluate this sequence for each split point $k$:
- For $k=1$: $\sum_{i=1}^1 x_{P[i]} + \sum_{i=1}^3 y_{P[i]} = 1 + (3 + 4 + 2) = 10$.
- For $k=2$: $\sum_{i=1}^2 x_{P[i]} + \sum_{i=2}^3 y_{P[i]} = (1 + 2) + (4 + 2) = 9$.
- For $k=3$: $\sum_{i=1}^3 x_{P[i]} + \sum_{i=3}^3 y_{P[i]} = (1 + 2 + 3) + 2 = 8$.

The maximum of these sums is $10$. This arrangement achieves the minimum possible evaluation $E(P) = 10$.
