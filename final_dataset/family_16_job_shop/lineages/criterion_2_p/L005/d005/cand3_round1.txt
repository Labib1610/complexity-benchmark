# Problem B — Domino Traversal

Time limit: 1 s   Memory limit: 256 MB

## Description

A level for a puzzle game consists of a sequence of vertical dominoes placed side-by-side. The level editor requires you to place at least one domino, and the engine supports a maximum width of two hundred thousand dominoes.

Each domino features a top number **t1** and a bottom number **t2**. The minimum number on any half is one, and the data type limit restricts any single number to exactly one million.

You must choose the left-to-right sequence in which to arrange the given dominoes. You may not rotate or flip the dominoes; you may only choose their order.

Once the sequence is arranged, a player will traverse it. The player starts at the top half of the leftmost domino and must end their traversal at the bottom half of the rightmost domino. During the traversal, the player may only make two types of moves:
- **Move right:** from the top half of a domino to the top half of the next domino, or from the bottom half of a domino to the bottom half of the next domino.
- **Move down:** from the top half of a domino to the bottom half of that exact same domino.

The player's score is the sum of all numbers on the halves they visit. The player will always choose the valid path that maximizes their total score.

Your task is to order the dominoes to minimize this maximum possible score.

## Input

The first line contains a single integer **j**.
Each of the next **j** lines contains exactly 2 integers **t1** and **t2**: the top number and the bottom number of a domino.

## Output

Print a single integer: the smallest possible maximum score the player can achieve across all valid arrangements.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one domino, with a top number of 5 and a bottom number of 3. The player starts at the top half (5), has no other domino to move right to, so they must move down to the bottom half (3). The only possible path visits both halves, giving a score of 5 + 3 = 8.
