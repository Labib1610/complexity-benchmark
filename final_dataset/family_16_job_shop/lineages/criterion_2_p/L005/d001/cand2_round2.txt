# Problem B — Cargo Pipeline

Time limit: 1 s   Memory limit: 256 MB

## Description

A logistics company routes a batch of **j** cargo containers through exactly 2 facilities: a security checkpoint and a scanning tunnel. Every container must complete the checkpoint before it can proceed to the scanning tunnel. For each container, you are given its checkpoint duration and its scanning duration. The operational rules are:

- The checkpoint facility and the scanning tunnel can each process only one container at a time.
- A container can only begin its scanning phase after its checkpoint phase is entirely finished.
- You must select the sequence in which containers enter the track. Since containers cannot overtake one another on the track, both facilities will process the containers in that exact same chosen sequence.

Choose the sequence so that the time at which the **last** container finishes the scanning tunnel is as small as possible. Report that smallest possible finish time.

## Input

The first line contains a single integer **j**. A batch contains at least 1 container, and the track's structural capacity limits the batch to a maximum of 200000 containers.
Each of the next **j** lines contains two integers **p1** and **p2**: the checkpoint duration and scanning duration of a container. Every duration requires at least 1 minute, and safety regulations strictly cap any single duration at 1000000 minutes.

## Output

Print a single integer: the smallest possible time at which all containers are finished.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2 the single container takes 5 to pass the checkpoint then 3 to scan, finishing at time 8.
