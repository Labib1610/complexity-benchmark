We can model the problem as a graph where each hub has degree exactly 3, and we need to 3-color the edges so that no two edges sharing a vertex have the same color.  

This is equivalent to edge-coloring a 3-regular graph with 3 colors, which is always possible by **Kőnig’s line coloring theorem** for bipartite graphs, but here the graph may not be bipartite. However, for cubic graphs, a 3-edge-coloring exists if and only if the graph is **3-edge-colorable**, which is equivalent to being **bridgeless** (by the Four Color Theorem equivalent for cubic graphs).  

Since the problem guarantees each vertex has degree 3, we can attempt a constructive approach:  
- Use a backtracking or greedy method with constraint propagation.  
- Since n ≤ 2000, m ≤ 3000, we can use a simple backtracking with heuristics.

Here’s a possible implementation:

```python
import sys
sys.setrecursionlimit(10000)

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    edges = []
    adj = [[] for _ in range(n)]
    for i in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        edges.append((u, v))
        adj[u].append(i)
        adj[v].append(i)
    
    color = [-1] * m
    
    # Try to color edges with backtracking
    # Use MRV heuristic: pick edge with fewest available colors
    def available_colors(e):
        u, v = edges[e]
        used = set()
        for idx in adj[u]:
            if color[idx] != -1:
                used.add(color[idx])
        for idx in adj[v]:
            if color[idx] != -1:
                used.add(color[idx])
        return [c for c in (1,2,3) if c not in used]
    
    # Sort edges by degree of constraint (number of adjacent edges)
    order = sorted(range(m), key=lambda e: len(adj[edges[e][0]]) + len(adj[edges[e][1]]), reverse=True)
    
    def backtrack(pos):
        if pos == m:
            return True
        e = order[pos]
        if color[e] != -1:
            return backtrack(pos+1)
        for c in available_colors(e):
            color[e] = c
            if backtrack(pos+1):
                return True
            color[e] = -1
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(str(color[i]) for i in range(m)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
