We can model this as a graph problem. Each vertex has degree exactly 3, and we need to 3-color the edges such that at each vertex, the three incident edges have all three different colors.

This is equivalent to finding a **proper 3-edge-coloring** of a cubic (3-regular) graph. By **Kőnig’s line coloring theorem**, every bipartite cubic graph has a 3-edge-coloring. But here the graph may not be bipartite. However, every bridgeless cubic graph has a 3-edge-coloring (by the **Petersen's theorem**), but if the graph has bridges, it may fail.

Since n ≤ 2000, we can use a constructive algorithm based on **Kőnig’s theorem** for bipartite graphs, or use a backtracking/flow approach.

A simpler approach:  
- Since each vertex has degree 3, we can try to find a **perfect matching** for each color.  
- We can use a **greedy + backtracking** with pruning, but that might be too slow for n=2000.  
- Better: Use **Kőnig’s line coloring** for bipartite graphs. If the graph is not bipartite, we can still try to find a 3-edge-coloring via **edge coloring by Vizing's theorem** (but that's complex).

Given constraints, we can use a **matching-based algorithm**:

1. Find a perfect matching (color 1).
2. Remove those edges; the remaining graph is 2-regular (cycles).  
3. Color each cycle alternately with colors 2 and 3.

If the graph is cubic and has a perfect matching, this works.  
If no perfect matching exists, output NO.

We can find a perfect matching using **Blossom algorithm** (general graph matching).  
But implementing Blossom in Python for n=2000 is heavy.  
However, since the graph is cubic, we can use a simpler approach:  
- Use **Tutte's theorem**? Not constructive.

Given the time limit, we can implement a **backtracking with constraint propagation** for edge coloring, but that might be too slow.

Actually, for cubic graphs, a 3-edge-coloring exists iff the graph is **bridgeless** (by Petersen's theorem).  
So we can check for bridges. If there is a bridge, output NO.  
If no bridges, we can find a 3-edge-coloring via a known constructive method:  
- Find a perfect matching (color 1) using **Edmonds' Blossom algorithm** (implementable).  
- Then color the remaining cycles with 2 and 3.

Let's implement Blossom for perfect matching in general graph.

We'll implement a standard Blossom algorithm for maximum matching, then check if it's perfect (size n/2).  
If yes, assign color 1 to those edges.  
Then the remaining graph is 2-regular (disjoint cycles).  
For each cycle, alternate colors 2 and 3.

Let's code it.

```python
import sys
sys.setrecursionlimit(1000000)

def find_perfect_matching(n, edges):
    # Build adjacency list
    adj = [[] for _ in range(n)]
    for idx, (u, v) in enumerate(edges):
        adj[u].append((v, idx))
        adj[v].append((u, idx))
    
    # Blossom algorithm for maximum matching
    match = [-1] * n
    p = [-1] * n
    base = list(range(n))
    q = []
    used = [False] * n
    blossom = [False] * n
    
    def lca(a, b):
        used_lca = [False] * n
        while True:
            a = base[a]
            used_lca[a] = True
            if match[a] == -1:
                break
            a = p[match[a]]
        while True:
            b = base[b]
            if used_lca[b]:
                return b
            b = p[match[b]]
    
    def mark_path(v, b, children):
        while base[v] != b:
            blossom[base[v]] = blossom[base[match[v]]] = True
            p[v] = children
            children = match[v]
            v = p[match[v]]
    
    def find_path(root):
        nonlocal p, base, used, q, blossom
        used = [False] * n
        p = [-1] * n
        base = list(range(n))
        q = [root]
        used[root] = True
        for qi in range(len(q)):
            v = q[qi]
            for to, _ in adj[v]:
                if base[v] == base[to] or match[v] == to:
                    continue
                if to == root or (match[to] != -1 and p[match[to]] != -1):
                    curbase = lca(v, to)
                    blossom = [False] * n
                    mark_path(v, curbase, to)
                    mark_path(to, curbase, v)
                    for i in range(n):
                        if blossom[base[i]]:
                            base[i] = curbase
                            if not used[i]:
                                used[i] = True
                                q.append(i)
                elif p[to] == -1:
                    p[to] = v
                    if match[to] == -1:
                        return to
                    to = match[to]
                    used[to] = True
                    q.append(to)
        return -1
    
    for i in range(n):
        if match[i] == -1:
            v = find_path(i)
            while v != -1:
                pv = p[v]
                nv = match[pv]
                match[v] = pv
                match[pv] = v
                v = nv
    
    # Check perfect
    if all(m != -1 for m in match):
        matching_edges = []
        for u in range(n):
            if u < match[u]:
                # find edge index
                for to, idx in adj[u]:
                    if to == match[u]:
                        matching_edges.append(idx)
                        break
        return matching_edges
    else:
        return None

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    edges = []
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges.append((u, v))
    
    # Check if graph is cubic
    deg = [0]*n
    for u,v in edges:
        deg[u]+=1
        deg[v]+=1
    if any(d != 3 for d in deg):
        print("NO")
        return
    
    # Find perfect matching for color 1
    match_edges = find_perfect_matching(n, edges)
    if match_edges is None:
        print("NO")
        return
    
    color = [0]*m
    for idx in match_edges:
        color[idx] = 1
    
    # Remaining edges form cycles
    # Build adjacency for remaining edges
    adj_rem = [[] for _ in range(n)]
    for idx, (u,v) in enumerate(edges):
        if color[idx] == 0:
            adj_rem[u].append((v, idx))
            adj_rem[v].append((u, idx))
    
    visited = [False]*n
    for i in range(n):
        if not visited[i] and adj_rem[i]:
            # traverse cycle
            cycle_edges = []
            start = i
            prev = -1
            cur = start
            while True:
                visited[cur] = True
                # pick next
                nxt = None
                nxt_idx = None
                for to, idx in adj_rem[cur]:
                    if to != prev:
                        nxt = to
                        nxt_idx = idx
                        break
                if nxt is None:
                    break
                cycle_edges.append(nxt_idx)
                prev, cur = cur, nxt
                if cur == start:
                    break
            # color cycle alternately 2,3
            for k, idx in enumerate(cycle_edges):
                color[idx] = 2 if k % 2 == 0 else 3
    
    # Check all colored
    if any(c == 0 for c in color):
        print("NO")
        return
    
    print("YES")
    print(" ".join(str(c) for c in color))

if __name__ == "__main__":
    solve()
```
