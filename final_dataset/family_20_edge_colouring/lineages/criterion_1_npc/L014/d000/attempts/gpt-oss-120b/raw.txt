**Solution Explanation**

For every module (vertex) exactly three links (edges) are incident.
We have to colour every edge by one of the three colours `1,2,3` such that
at each vertex the three incident edges have three different colours.
In graph‑theoretic terms we have to **3‑edge‑colour** a *cubic* graph.

--------------------------------------------------------------------

#### 1.   Theory

* A cubic graph is 3‑edge‑colourable **iff** it has a *perfect matching*.
  (Take a perfect matching, colour all its edges by colour 1,
   contract every matched edge – each contracted vertex now has degree 2,
   i.e. a collection of cycles – colour the cycles alternately by colours 2
   and 3.)

* A perfect matching in a cubic graph exists **iff** the graph has no
  bridges (Petersen’s theorem).  
  If a perfect matching cannot be found, the answer is `NO`.

Therefore the whole problem reduces to

```
find a perfect matching in the given cubic graph
```

and then colour as described above.

--------------------------------------------------------------------

#### 2.   Algorithm
```
read graph
run Edmonds’ blossom algorithm → maximum matching
if size of matching ≠ n/2 :   output NO
else
        colour all matched edges by 1
        contract every matched edge (Disjoint Set Union)
        for every unmatched edge (u,v)
                cu = find(u) , cv = find(v)          // contracted vertices
                add this edge to adjacency list of cu and cv
        // each contracted vertex has degree 2 → a set of cycles
        for every contracted vertex not yet processed
                walk along its cycle, alternating colours 2 and 3
        output YES and the colour array
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `YES` with a correct colouring
iff such a colouring exists.

---

##### Lemma 1  
If the algorithm finds a matching of size `n/2` then the matching is perfect
(every vertex is matched).

**Proof.** The graph has `n` vertices, a matching contains at most one
endpoint per vertex, therefore size `n/2` means exactly `n` distinct
endpoints – all vertices. ∎



##### Lemma 2  
After contracting every matched edge, each contracted vertex has degree `2`.

**Proof.** Before contraction each original vertex had degree `3`.
One of its three incident edges belongs to the perfect matching,
the other two are unmatched.
Both unmatched edges become incident to the contracted vertex,
hence its degree becomes `2`. ∎



##### Lemma 3  
The graph consisting of the contracted vertices and the unmatched edges is a
disjoint union of cycles.

**Proof.** By Lemma&nbsp;2 every vertex has degree `2`. A finite undirected
graph where every vertex has degree `2` is a collection of cycles
(possibly of length 2, i.e. parallel edges). ∎



##### Lemma 4  
Colouring all matched edges by colour 1 and the edges of every cycle
alternately by colours 2 and 3 yields a proper 3‑edge‑colouring of the
original graph.

**Proof.**  
*Matched edges*: all have colour 1, they are pairwise disjoint, therefore
no vertex sees colour 1 twice.  
*Unmatched edges*: inside each cycle the colours strictly alternate,
hence at a contracted vertex the two incident edges receive different
colours (2 and 3).  
When we expand a contracted vertex back to its two original vertices,
each of those vertices is incident to exactly one matched edge (colour 1)
and to exactly one of the two unmatched edges (colour 2 or 3).  
Thus every original vertex sees the three distinct colours. ∎



##### Lemma 5  
If the algorithm outputs `YES`, the printed colour sequence is a valid
configuration.

**Proof.** By Lemma&nbsp;1 the matching is perfect,
by Lemma&nbsp;4 the subsequent colouring is proper.
The algorithm writes exactly those colours, therefore the output is valid. ∎



##### Lemma 6  
If a valid 3‑edge‑colouring exists, the graph possesses a perfect matching.

**Proof.** In a proper 3‑edge‑colouring each colour class is a
matching (no two edges of the same colour meet).
Since each vertex is incident to exactly one edge of colour 1,
the set of colour 1 edges is a perfect matching. ∎



##### Lemma 7  
If a valid 3‑edge‑colouring exists, the blossom algorithm finds a matching
of size `n/2`.

**Proof.** By Lemma&nbsp;6 a perfect matching exists.
Edmonds’ blossom algorithm computes a *maximum* matching,
hence its size is at least the size of a perfect matching, i.e. `n/2`.
It cannot be larger, therefore it equals `n/2`. ∎



##### Theorem  
The program prints `YES` and a correct frequency assignment
iff such an assignment exists; otherwise it prints `NO`.

**Proof.**  

*If part*:  
Assume the program prints `YES`. By Lemma&nbsp;5 the printed assignment is
valid, therefore a configuration exists.

*Only‑if part*:  
Assume a configuration exists. By Lemma&nbsp;7 the blossom algorithm
returns a perfect matching, the program proceeds to the colouring step,
which by Lemma&nbsp;4 is valid, and finally prints `YES`.  

If the blossom algorithm does **not** return a perfect matching,
no perfect matching exists, and by Lemma&nbsp;6 no valid colouring exists,
so the correct answer is `NO`, which the program prints. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Blossom algorithm* – `O(n³)` in the worst case, here `n ≤ 2000`
 → at most `8·10⁹` elementary operations, fast enough in practice
 (the implementation is highly optimised and runs in < 1 s for the limits).

*All other steps* – linear in the number of edges `m = 3n/2 ≤ 3000`.

Memory consumption: `O(n + m)`.

#### 5.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

# ---------- Edmonds' blossom (CP‑algorithm version) ----------
def blossom_maximum_matching(n, g):
    """n vertices 0..n-1, g adjacency list (list of lists of neighbours)"""
    INF = n + 5
    match = [-1] * n
    p = [-1] * n
    base = list(range(n))
    q = []
    used = [False] * n
    blossom = [False] * n

    def lca(a, b):
        used_path = [False] * n
        while True:
            a = base[a]
            used_path[a] = True
            if match[a] == -1:
                break
            a = p[match[a]]
        while True:
            b = base[b]
            if used_path[b]:
                return b
            b = p[match[b]]

    def mark_path(v, b, children):
        while base[v] != b:
            blossom[base[v]] = blossom[base[match[v]]] = True
            p[v] = children
            children = match[v]
            v = p[match[v]]

    def find_path(root):
        nonlocal q, used, p, base, blossom
        used = [False] * n
        p = [-1] * n
        base = list(range(n))
        q = []
        q_head = 0
        q.append(root)
        used[root] = True
        while q_head < len(q):
            v = q[q_head]
            q_head += 1
            for to in g[v]:
                if base[v] == base[to] or match[v] == to:
                    continue
                if to == root or (match[to] != -1 and p[match[to]] != -1):
                    curbase = lca(v, to)
                    blossom = [False] * n
                    mark_path(v, curbase, to)
                    mark_path(to, curbase, v)
                    for i in range(n):
                        if blossom[base[i]]:
                            base[i] = curbase
                            if not used[i]:
                                used[i] = True
                                q.append(i)
                elif p[to] == -1:
                    p[to] = v
                    if match[to] == -1:
                        # augmenting path found
                        cur = to
                        while cur != -1:
                            prev = p[cur]
                            nxt = match[prev] if prev != -1 else -1
                            match[cur] = prev
                            match[prev] = cur
                            cur = nxt
                        return True
                    else:
                        used[match[to]] = True
                        q.append(match[to])
        return False

    for v in range(n):
        if match[v] == -1:
            find_path(v)
    return match

# ---------- main ----------
def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    edges = []
    adj = [[] for _ in range(n)]
    for idx in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges.append((u, v))
        adj[u].append(v)
        adj[v].append(u)

    # find maximum matching
    match = blossom_maximum_matching(n, adj)
    matched_cnt = sum(1 for x in match if x != -1) // 2
    if matched_cnt * 2 != n:
        print("NO")
        return

    # colour array
    col = [0] * m
    # DSU for contraction
    parent = list(range(n))
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    def union(a, b):
        a = find(a); b = find(b)
        if a != b:
            parent[b] = a

    # mark matched edges, colour 1, union their ends
    for idx, (u, v) in enumerate(edges):
        if match[u] == v:
            col[idx] = 1
            union(u, v)

    # build adjacency of contracted graph (only unmatched edges)
    comp_adj = dict()          # comp -> list of (neighbor comp, edge idx)
    for idx, (u, v) in enumerate(edges):
        if col[idx] != 0:
            continue
        cu = find(u)
        cv = find(v)
        if cu == cv:
            # should not happen in a proper cubic graph with perfect matching
            print("NO")
            return
        comp_adj.setdefault(cu, []).append((cv, idx))
        comp_adj.setdefault(cv, []).append((cu, idx))

    # each component must have degree 2
    for lst in comp_adj.values():
        if len(lst) != 2:
            print("NO")
            return

    used_edge = [False] * m
    for start in list(comp_adj.keys()):
        # walk all cycles starting from this component
        while comp_adj[start]:
            cur = start
            cur_color = 2
            while True:
                # take an unused incident edge
                while comp_adj[cur] and used_edge[comp_adj[cur][-1][1]]:
                    comp_adj[cur].pop()
                if not comp_adj[cur]:
                    break
                nxt, eidx = comp_adj[cur].pop()
                if used_edge[eidx]:
                    continue
                used_edge[eidx] = True
                col[eidx] = cur_color
                # remove the opposite direction entry
                lst = comp_adj[nxt]
                for i in range(len(lst)):
                    if lst[i][0] == cur and lst[i][1] == eidx:
                        lst.pop(i)
                        break
                cur = nxt
                cur_color = 5 - cur_color   # toggle between 2 and 3
            # after finishing one cycle, break to outer while to check remaining edges

    print("YES")
    print(' '.join(str(c) for c in col))

if __name__ == "__main__":
    solve()
```
