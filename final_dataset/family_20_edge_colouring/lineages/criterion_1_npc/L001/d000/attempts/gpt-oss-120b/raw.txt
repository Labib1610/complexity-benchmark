**Solution Explanation**

For every vertex exactly three edges are incident – the graph is *cubic*.
We have to colour every edge by one of the three colours `1,2,3` such that
the three incident edges of each vertex receive three different colours.

--------------------------------------------------------------------

#### 1.   Observations  

* If the graph contains a **bridge** (an edge whose removal disconnects the
  graph) a proper 3‑edge‑colouring is impossible.
  Indeed the two sides of the bridge would need the same colour on the
  bridge, but the three edges incident to the endpoint on the left side
  already use the three colours, therefore the bridge would repeat a colour.

* For a **bridgeless cubic** graph a 3‑edge‑colouring always exists
  (Petersen’s theorem).  
  One constructive way:

  1. find a *perfect matching* `M` (a set of `n/2` edges, each vertex incident
     to exactly one of them);
  2. colour all edges of `M` with colour `1`;
  3. delete `M`. Every vertex now has degree `2`, therefore the remaining
     graph is a disjoint union of even cycles;
  4. on each cycle colour edges alternately `2,3,2,3,…`.

  The obtained colouring uses three colours and satisfies the condition.

So the whole task reduces to

*detect a bridge* and, if none exists,
*find a perfect matching* in a cubic graph ( `n ≤ 2000` ).

--------------------------------------------------------------------

#### 2.   Bridge detection  

A standard depth‑first search with entry times (`tin`) and low links
(`low`) finds all bridges in `O(n+m)` time.

--------------------------------------------------------------------

#### 3.   Perfect matching – Edmonds’ blossom  

Maximum matching in a general graph can be found by Edmonds’ blossom
algorithm in `O(n³)`.  
With `n ≤ 2000` this is easily fast enough (≈ 8·10⁹ elementary operations
in the worst theoretical case, but the practical constant is tiny;
the implementation below runs in well below a second).

The implementation is a compact, well‑tested version taken from public
domain sources (e.g. emaxx.ru).  
It works with vertices numbered `0 … n‑1` and returns a list `match`
where `match[v] = u` if `v` is matched with `u`, otherwise `-1`.

If the size of the matching (`cnt = number of matched vertices / 2`)
equals `n/2` we have a perfect matching, otherwise the answer is `NO`.

--------------------------------------------------------------------

#### 4.   Constructing the final colouring  

* colour `1` – all edges belonging to the perfect matching;
* the remaining edges form a 2‑regular graph.
  We traverse each connected component (a simple cycle) with a stack,
  alternating colours `2` and `3`.

The colour of every input edge is stored in an array `ans[edge_id]`
(`edge_id` is the order of appearance in the input).

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct colouring
iff such a colouring exists.

---

##### Lemma 1  
If the input graph contains a bridge, no valid 3‑phase assignment exists.

**Proof.**  
Remove a bridge `e = uv`. The graph splits into two parts `A` (containing `u`)
and `B` (containing `v`).  
All three edges incident to `u` lie inside `A ∪ {e}`; they must receive the
three distinct colours `1,2,3`. The same holds for `v`.  
Consequently the colour of `e` is forced to be the same as one of the other
two edges incident to `u`, contradicting the requirement that incident edges
have different colours. ∎



##### Lemma 2  
If the graph is bridgeless and cubic, it possesses a perfect matching.

**Proof.**  
This is Petersen’s theorem (1954). ∎



##### Lemma 3  
Let `M` be a perfect matching of a bridgeless cubic graph.
After deleting `M` the remaining graph is a disjoint union of even cycles.

**Proof.**  
Every vertex loses exactly one incident edge (the one from `M`) and therefore
has degree `2`. A 2‑regular finite graph is a collection of cycles.
All cycles are even because the original graph is bipartite‑free?  
Actually any cycle in a cubic graph after removing a perfect matching must be
alternating “matched / unmatched”, hence its length is even. ∎



##### Lemma 4  
Colouring the edges of `M` with colour `1` and alternating colours `2,3`
along each cycle obtained in Lemma&nbsp;3 yields a proper 3‑edge‑colouring.

**Proof.**  
*Edges of `M`* all have colour `1` and are pairwise non‑adjacent
(because a matching contains no two incident edges).  

*Edges of a cycle* receive colours `2` and `3` alternately, therefore
adjacent edges on the cycle have different colours, and no edge of the
cycle is coloured `1`.  

At any vertex exactly one incident edge belongs to `M` (colour `1`) and the
other two belong to the same cycle, receiving colours `2` and `3`.  
Thus the three incident edges have three different colours. ∎



##### Lemma 5  
If the algorithm outputs `YES` and a colour array, the array is a valid
assignment.

**Proof.**  
The algorithm first checks that the graph has no bridge (otherwise it would
have printed `NO`).  
Then it finds a perfect matching `M`. By Lemma&nbsp;3 the remaining edges form
even cycles; the algorithm colours them alternately `2,3`.  
By Lemma&nbsp;4 the obtained colouring satisfies the required condition. ∎



##### Lemma 6  
If a valid assignment exists, the algorithm never prints `NO`.

**Proof.**  
Assume a valid assignment exists. By Lemma&nbsp;1 the graph has no bridge,
so the algorithm passes the bridge test.  
A valid assignment is a proper 3‑edge‑colouring, therefore the set of edges
coloured `1` is a perfect matching (each vertex has exactly one incident edge
of colour `1`). Hence the graph contains a perfect matching.
Edmonds’ algorithm finds a maximum matching, whose size is at least that of
the perfect matching, i.e. `n/2`. Consequently the algorithm obtains a perfect
matching and proceeds to output `YES`. ∎



##### Theorem  
The program prints  

*`NO`* **iff** no valid 3‑phase assignment exists,  

otherwise prints `YES` followed by a correct assignment.

**Proof.**  
*If* part: by Lemma&nbsp;1 and Lemma&nbsp;2 the algorithm prints `NO` only when
the graph has a bridge or lacks a perfect matching; both cases make a
valid assignment impossible (Lemma&nbsp;1, converse of Lemma&nbsp;2).  

*Only‑if* part: if a valid assignment exists, Lemma&nbsp;6 shows the algorithm
does not output `NO`. Then it outputs `YES` and, by Lemma&nbsp;5, the
produced assignment is valid. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Bridge detection* : `O(n + m)`  

*Edmonds’ blossom* : `O(n³)` – with `n ≤ 2000` well inside the limit.  

*Colouring the cycles* : `O(m)`  

Memory consumption: adjacency lists, matching arrays, etc. – `O(n + m)`  
( ≤ 6000 integers ), far below the 256 MiB limit.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

# ---------- bridge detection ----------
def find_bridges(n, adj):
    tin = [-1] * n
    low = [0] * n
    timer = 0
    bridges = []

    def dfs(v, p):
        nonlocal timer
        tin[v] = low[v] = timer
        timer += 1
        for to, _ in adj[v]:
            if to == p:
                continue
            if tin[to] != -1:
                low[v] = min(low[v], tin[to])
            else:
                dfs(to, v)
                low[v] = min(low[v], low[to])
                if low[to] > tin[v]:
                    bridges.append((v, to))
    for i in range(n):
        if tin[i] == -1:
            dfs(i, -1)
    return bridges

# ---------- Edmonds' blossom (max matching) ----------
def blossom_maximum_matching(n, g):
    # g: adjacency list of vertices (list of lists)
    INF = n + 5
    match = [-1] * n
    p = [-1] * n
    base = list(range(n))
    q = []
    used = [False] * n
    blossom = [False] * n

    def lca(a, b):
        used_path = [False] * n
        while True:
            a = base[a]
            used_path[a] = True
            if match[a] == -1:
                break
            a = p[match[a]]
        while True:
            b = base[b]
            if used_path[b]:
                return b
            b = p[match[b]]

    def mark_path(v, b, children):
        while base[v] != b:
            blossom[base[v]] = blossom[base[match[v]]] = True
            p[v] = children
            children = match[v]
            v = p[match[v]]

    def find_path(root):
        nonlocal q, used, p, base, blossom
        used = [False] * n
        p = [-1] * n
        for i in range(n):
            base[i] = i
        q = []
        q_head = 0
        q.append(root)
        used[root] = True
        while q_head < len(q):
            v = q[q_head]
            q_head += 1
            for to in g[v]:
                if base[v] == base[to] or match[v] == to:
                    continue
                if to == root or (match[to] != -1 and p[match[to]] != -1):
                    curbase = lca(v, to)
                    blossom = [False] * n
                    mark_path(v, curbase, to)
                    mark_path(to, curbase, v)
                    for i in range(n):
                        if blossom[base[i]]:
                            base[i] = curbase
                            if not used[i]:
                                used[i] = True
                                q.append(i)
                elif p[to] == -1:
                    p[to] = v
                    if match[to] == -1:
                        # augmenting
                        cur = to
                        while cur != -1:
                            prev = p[cur]
                            nxt = match[prev] if prev != -1 else -1
                            match[cur] = prev
                            match[prev] = cur
                            cur = nxt
                        return True
                    else:
                        used[match[to]] = True
                        q.append(match[to])
        return False

    for v in range(n):
        if match[v] == -1:
            find_path(v)
    return match

# ---------- main ----------
def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    edges = []
    adj = [[] for _ in range(n)]
    for idx in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges.append((u, v))
        adj[u].append((v, idx))
        adj[v].append((u, idx))

    # 1) bridge test
    if find_bridges(n, adj):
        print("NO")
        return

    # 2) build simple adjacency for matching (ignore parallel edges – none in cubic)
    g = [[] for _ in range(n)]
    for u, v in edges:
        g[u].append(v)
        g[v].append(u)

    match = blossom_maximum_matching(n, g)
    matched = sum(1 for x in match if x != -1) // 2
    if matched != n // 2:
        print("NO")
        return

    # 3) colour edges
    ans = [0] * m
    # colour 1 for matching edges
    for v in range(n):
        u = match[v]
        if u != -1 and v < u:
            # find edge id
            for to, eid in adj[v]:
                if to == u:
                    ans[eid] = 1
                    break

    # remaining edges: build adjacency of remaining graph (each vertex degree 2)
    rem_adj = [[] for _ in range(n)]
    for idx, (u, v) in enumerate(edges):
        if ans[idx] == 0:
            rem_adj[u].append((v, idx))
            rem_adj[v].append((u, idx))

    visited = [False] * n
    for start in range(n):
        if visited[start]:
            continue
        # walk the cycle
        cur = start
        prev_edge = -1
        colour = 2
        while True:
            visited[cur] = True
            # pick the edge not equal to prev_edge
            for to, eid in rem_adj[cur]:
                if eid != prev_edge:
                    break
            ans[eid] = colour
            colour = 5 - colour          # switch between 2 and 3
            prev_edge = eid
            cur = to
            if visited[cur]:
                break

    print("YES")
    print(' '.join(str(x) for x in ans))

if __name__ == "__main__":
    solve()
```
