We can model this as a bipartite graph edge-coloring problem.  
The ports are vertices, cables are edges, and we need to color edges so that no two edges sharing a vertex have the same color.  
The minimum number of colors needed is the maximum degree Δ, and for bipartite graphs, Δ colors always suffice.

We can use a simple greedy algorithm with augmenting paths to color edges in O(m Δ) worst-case, but here we can do it efficiently using the standard bipartite edge-coloring algorithm with complexity O(m log Δ) or O(m Δ) with small Δ.  
Given constraints (m up to 400,000), we need an efficient approach.

We'll implement the **Kőnig's line coloring** algorithm using a simple greedy with color swaps (also known as the "edge coloring by augmenting paths" method).  
We'll maintain for each vertex a set of used colors, and for each edge, assign the smallest available color; if conflict, we perform a color swap along an alternating path.
