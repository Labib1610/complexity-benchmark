# Quantum State Stabilization

Time limit: 2 s   Memory limit: 256 MB

## Description

You are tasked with stabilizing a quantum system by selecting exactly **k** valid states from a given set of **t** observed states. Each state is defined by a triplet of quantum numbers: principal **p**, azimuthal **a**, and magnetic **m**. Each quantum number takes an integer value from 1 to **k**.

To achieve full stabilization, the system must consist of exactly **k** states such that they are mutually exclusive across all three dimensions simultaneously. This means that among the **k** chosen states, every principal number from 1 to **k** must appear exactly once, every azimuthal number from 1 to **k** must appear exactly once, and every magnetic number from 1 to **k** must appear exactly once.

The search space for selecting **k** states out of **t** possibilities is enormous, requiring a highly efficient approach to identify a valid subset. The observed states are generated by a specific particle beam preparation process which introduces a strict dependency: for any given principal number **p**, all observed states with that principal number will share the exact same azimuthal number **a**. Additionally, no two observed states with different principal numbers will ever possess the same azimuthal number.

Determine if there exists a subset of **k** states that perfectly stabilizes the system. If multiple stabilizing subsets exist, any valid one is acceptable.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 1200, 0 ≤ t ≤ k·k): the required number of states and the total number of observed states.
Each of the next **t** lines contains three integers **p**, **a**, and **m** (1 ≤ p, a, m ≤ k), representing an observed state. No state is listed more than once. Consistent with the beam preparation, every listed state with the same **p** value has the same **a** value, and states with different **p** values have different **a** values.

## Output

If a stabilizing subset of **k** states exists, print `YES` on the first line. Then print **k** lines, each containing the three integers **p**, **a**, and **m** of one chosen state (in any order). 
If no such subset exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 1 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 2 1
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```
