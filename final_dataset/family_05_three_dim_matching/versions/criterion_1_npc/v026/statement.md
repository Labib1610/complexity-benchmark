# Pipeline Stage 2: Linkage Synthesis

Time limit: 5 s   Memory limit: 256 MB

## Description

The automated data pipeline of a deep-space control node consists of three sequential phases:

**Phase 1: Initialization.** The system establishes connections with orbital satellites. It powers up **k** sensor arrays, **k** calibration targets, and **k** frequency bands. All components are assigned integer IDs from 1 to **k**. A preliminary diagnostic sweep tests the hardware and outputs a manifest of stable linkages. A stable linkage is a specific triad `(array_ID, target_ID, band_ID)` that can operate together without interference.

**Phase 2: Linkage Synthesis (Your Task).** The synthesis firmware must process the manifest generated by Phase 1. It must isolate exactly **k** linkages from the manifest such that every sensor array, every calibration target, and every frequency band is incorporated into **exactly one** selected linkage. 

**Phase 3: Telemetry Extraction.** If Phase 2 successfully isolates the required linkages, the system locks them in and begins downloading the payload. If Phase 2 determines no such isolation is possible, it must issue an abort signal to prevent a cascade failure.

You are responsible only for implementing the Phase 2 Linkage Synthesis module. Given the manifest from Phase 1, determine if it is possible to proceed to Phase 3, and if so, provide the linkages to be activated.

## Input

The first line of the manifest contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the number of components of each type, and the number of stable linkages in the manifest.
Each of the next **t** lines contains three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing a stable linkage consisting of sensor array **x**, calibration target **y**, and frequency band **z**. No linkage is listed more than once.

## Output

If a valid synthesis of **k** linkages exists to proceed to Phase 3, print `YES` on the first line, then print **k** lines, each containing the three IDs `x y z` of one selected linkage. Any synthesis in which every sensor array, calibration target, and frequency band is used exactly once is accepted; the linkages may be printed in any order.

If no valid synthesis exists, print `NO` (which serves as the abort signal for Phase 3).

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both stable linkages in the manifest use calibration target 1, so calibration target 2 can never be incorporated into a linkage.
