# Problem A — Resonant Hyperspace

Time limit: 5 s   Memory limit: 256 MB

## Description

A starfleet is preparing for a rapid succession of *k* hyperspace jumps. A successful jump relies on perfectly aligning three independent navigational components: a pulsar frequency, a gravimetric distortion, and a subspace harmonic. The fleet's warp drive is capable of tuning exactly *k* distinct pulsar frequencies, *k* unique gravimetric distortions, and *k* different subspace harmonics. Every component is designated by an integer from 1 up to *k*.

Due to subspace volatility, not all combinations of these components can be safely engaged. The navigational mainframe has pre-calculated exactly *t* stable synchronization profiles. Each profile is defined by a triplet `(x, y, z)`, meaning that pulsar frequency *x*, gravimetric distortion *y*, and subspace harmonic *z* can be safely aligned for one jump.

To avoid a catastrophic resonant collapse of local space-time, the fleet must carry out the *k* jumps without ever reusing any component setting. By the end of the sequence, each of the *k* pulsar frequencies must have been used in exactly one jump, each gravimetric distortion in exactly one jump, and each subspace harmonic in exactly one jump.

Your task is to determine whether it is possible to choose exactly *k* stable profiles from the mainframe's list to satisfy these strict non-repetition rules. If a valid itinerary exists, you must output one such set of profiles.

The fleet must make at least one jump to escape the current sector. Furthermore, the flagship's thermal accumulator bank contains exactly 22 cooling cells, and each jump permanently expends one cell, meaning the planned sequence cannot exceed this maximum number of jumps. The total number of stable profiles *t* can range from zero up to the theoretical maximum where every conceivable triplet of the *k* components is stable.

## Input

The first line provides the two integers *k* and *t*. 
The subsequent *t* lines each contain three integers *x*, *y*, and *z*, detailing a stable profile made up of pulsar frequency *x*, gravimetric distortion *y*, and subspace harmonic *z*. All provided profiles are distinct.

## Output

If a safe itinerary of *k* jumps can be formed, print `YES` on the first line. Following that, output *k* lines, each containing the three integers `x y z` of a chosen profile. Any valid itinerary that uses every component exactly once is acceptable; the profiles may be printed in any order.

If no such itinerary is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both stable profiles require gravimetric distortion 1, meaning gravimetric distortion 2 can never be utilized.

<RATIONALE>
I removed the explicit numerical inequalities for the bounds `k` and `t` and instead embedded them into the physical constraints of the scenario (e.g., exactly 22 cooling cells). Models that rely on shallow pattern matching of input sections to determine bounds will fail to realize `k` is small enough for exact-cover backtracking, potentially leading them to attempt flawed polynomial-time heuristics.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical requirements of finding a perfectly constrained selection of vectors without repetition are completely unchanged, ensuring the same outputs are valid.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret "every conceivable triplet of the k components" as something other than k^3, though mathematically it unambiguously means k * k * k.
</RISK>
