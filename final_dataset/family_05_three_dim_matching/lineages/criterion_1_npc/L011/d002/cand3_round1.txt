<STATEMENT>
# Problem A — Orbital Defense Grid

Time limit: 5 s   Memory limit: 256 MB

## Description

A planetary defense grid is modeled as a three-dimensional cubic sector of space, divided into coordinates `(x, y, z)` where each axis ranges from 1 to **k**. 

The military needs to deploy exactly **k** orbital defense satellites into this sector. Each satellite is equipped with high-energy lasers that fire continuously in straight lines along all three axes (parallel to the X, Y, and Z axes). To prevent catastrophic beam interference, no two satellites can be placed such that they share the same X-coordinate, the same Y-coordinate, or the same Z-coordinate. 

Due to gravitational anomalies, satellites cannot be placed just anywhere. There are exactly **t** stable anchor points in the sector, each given by a specific coordinate `(x, y, z)`. Satellites may only be deployed at these stable anchor points.

Your task is to determine whether it is possible to deploy exactly **k** satellites at the available anchor points such that no two satellites interfere with each other. If such a deployment is possible, you must provide the coordinates for the **k** satellites.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the required number of satellites (which is also the size of the grid along each dimension) and the number of stable anchor points.
Each of the next **t** lines contains three integers **x**, **y**, and **z** (1 ≤ x, y, z ≤ k), representing the coordinates of a stable anchor point. All listed anchor points are distinct.

## Output

If a safe deployment of **k** satellites is possible, print `YES` on the first line. Then, print **k** lines, each containing the three integers `x y z` of a selected anchor point. Any valid selection of anchor points is accepted, and they may be printed in any order.

If no such deployment is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both stable anchor points share the same Y-coordinate (1). If satellites are placed at both points, their lasers will intersect along the Y-axis. Therefore, it is impossible to safely deploy 2 satellites.
</STATEMENT>
<RATIONALE>
Changed the scenario to placing satellites in a 3D grid where lasers prevent sharing coordinates, deliberately removing the seed's explicit instruction that every parameter must be "utilized exactly once". This forces the model to deduce via the Pigeonhole Principle that deploying $k$ satellites in a $k$-sized grid without interference means each axis coordinate is used exactly once, a realization necessary to optimize the backtracking search from a naive $O(2^t)$ over all points to an efficient $O(k!)$ search grouped by one dimension.
</RATIONALE>
<PRESERVED_ANSWER>
Selecting exactly $k$ points from the given $t$ points such that no two share an X, Y, or Z coordinate mathematically guarantees (by the Pigeonhole Principle) that every coordinate from 1 to $k$ is used exactly once, perfectly matching the seed's constraints.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching, asking to find a subset of $k$ triples that form an exact cover of three sets of size $k$, which is NP-complete.
</PRESERVED_CLASS>
