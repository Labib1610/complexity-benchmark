# Problem A — Phase-Shift Matrix

Time limit: 5 s   Memory limit: 256 MB

## Description

A dimensional matrix requires the selection of exactly **k** distinct configurations. Each configuration is defined by three independent coordinates: a spatial axis, a temporal axis, and a quantum axis. The system provides exactly **k** distinct spatial axes, **k** distinct temporal axes, and **k** distinct quantum axes. All coordinates are indexed starting from 1 up to **k**.

The system has identified a pool of exactly **t** stable configurations. Each stable configuration is given as a triplet `(x, y, z)`, meaning that spatial axis **x**, temporal axis **y**, and quantum axis **z** can be safely combined.

You must select exactly **k** configurations from this pool such that no coordinate is ever reused. Over the chosen set of **k** configurations, every single spatial axis must be utilized exactly once, every temporal axis exactly once, and every quantum axis exactly once. The order of chosen configurations is irrelevant; only which triplets are selected matters. There are no constraints between chosen configurations other than coordinate uniqueness.

Determine whether it is possible to select exactly **k** stable configurations from the provided pool that satisfy these strict non-repetition constraints. If such a selection exists, provide one valid set of configurations.

## Input

The first line contains two integers **k** and **t**. The physical capacity of the system's matrix exactly equals 22 slots, restricting **k** to be at most this capacity (with a minimum of 1). The number of stable configurations **t** ranges from a complete absence (zero) up to the theoretical maximum where all independent combinations are valid (the cube of **k**).

Each of the following **t** lines contains three integers **x**, **y**, and **z**. These represent a stable configuration consisting of spatial axis **x**, temporal axis **y**, and quantum axis **z**. The coordinates **x**, **y**, and **z** are positive integers that do not exceed **k**. All listed configurations are distinct.

## Output

If a valid selection of **k** configurations is possible, print `YES` on the first line. Then, print **k** lines, each containing the three integers `x y z` of one selected configuration. Any valid selection that perfectly utilizes all axes exactly once is accepted; the chosen configurations may be printed in any order.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both stable configurations require temporal axis 1, meaning temporal axis 2 can never be utilized.
