# Phase-Space Navigation

Time limit: 5 s
Memory limit: 256 MB

## Description

To cross the galactic void, a vanguard vessel must plot a continuous trajectory consisting of exactly **k** discrete phase-shifts. A single phase-shift is formed by locking in three independent engine coordinates: a warp tensor, a flux manifold, and a tachyon emission. The ship's drive supports exactly **k** distinct warp tensors, **k** distinct flux manifolds, and **k** distinct tachyon emissions. Every coordinate is identified by an integer from 1 to **k**. The vessel's hardware limits the number of distinct coordinates per type to a maximum of 22.

The navigation mainframe contains a database of **t** pre-calculated safe configurations. Each configuration, given as a triplet `(x, y, z)`, guarantees that warp tensor **x**, flux manifold **y**, and tachyon emission **z** can be engaged simultaneously without destabilizing the core. The database may contain anywhere from 0 configurations up to the theoretical maximum (the cube of the number of coordinates).

The vessel must perform exactly **k** phase-shifts to reach its destination. However, the core's thermal limits impose a rigid constraint: over the entire sequence of **k** shifts, every single warp tensor (1 through **k**) must be engaged exactly once, every single flux manifold (1 through **k**) exactly once, and every single tachyon emission (1 through **k**) exactly once.

You must determine if there is a valid sequence of **k** configurations chosen from the database that perfectly covers all coordinates without any reuse. The database may contain dense, highly overlapping configurations designed to test the limits of the ship's routing logic; your solution must efficiently handle worst-case scenarios where many paths seem viable but ultimately conflict deep in the sequence. If a valid set of **k** configurations exists, output it.

## Input

The first line specifies the number of discrete coordinates of each type, **k**, and the number of safe configurations, **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k).
The following **t** lines each contain three integers **x**, **y**, and **z** (1 ≤ x, y, z ≤ k), describing a safe configuration composed of warp tensor **x**, flux manifold **y**, and tachyon emission **z**. All provided configurations in the input are distinct.

## Output

If a safe trajectory of **k** phase-shifts is possible, print `YES` on the first line. Then, print **k** lines, each containing the three integers `x y z` of one chosen configuration. Any valid set of configurations that perfectly utilizes every coordinate exactly once is accepted. The chosen configurations can be printed in any order.

If no such trajectory exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both safe configurations require flux manifold 1, meaning flux manifold 2 can never be engaged, making a complete trajectory impossible.
