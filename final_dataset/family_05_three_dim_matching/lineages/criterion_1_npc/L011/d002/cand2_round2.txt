# Problem A — Resonant Hyperspace

Time limit: 5 s   Memory limit: 256 MB

## Description

A starfleet's hyperdrive core consists of three independent synchronization rings: the Pulsar ring, the Gravimetric ring, and the Subspace ring. Each ring contains exactly **k** distinct phase-coils, numbered 1 through **k**.

To initiate a jump sequence, all **3k** phase-coils across the three rings must be charged. 

The fleet has a database of **t** stable calibration vectors. Each vector acts as a localized charge that simultaneously strikes exactly three phase-coils: one specific coil **x** on the Pulsar ring, one coil **y** on the Gravimetric ring, and one coil **z** on the Subspace ring.

Because the phase-coils are highly volatile, a coil will rupture if it is struck more than once. Therefore, you must select exactly **k** vectors from the database such that no two selected vectors share the same Pulsar coil, Gravimetric coil, or Subspace coil. This ensures every single phase-coil on all three rings is charged exactly once.

Determine whether it is possible to choose such a set of **k** vectors. If it is possible, provide one valid selection.

## Input

The first line contains two integers **k** and **t**. The hyperdrive's architecture supports a maximum capacity of 22 phase-coils per ring, and requires a minimum of 1 installed coil, meaning **k** is an integer from 1 to 22 inclusive. The number of stable vectors **t** can range from an empty database (0) up to a fully saturated database where every conceivable triplet of coils is stable (exactly **k** times **k** times **k**).

Each of the next **t** lines contains three integers **x**, **y**, and **z**. These represent a stable vector that charges Pulsar coil **x**, Gravimetric coil **y**, and Subspace coil **z**. Each identifier corresponds to an installed coil, meaning it is an integer at least 1 and at most **k**. All provided vectors are distinct.

## Output

If a valid selection of **k** vectors exists, print `YES` on the first line. Then, print **k** lines, each containing the three integers `x y z` of one chosen vector. Any valid selection that charges all phase-coils exactly once is accepted, and the chosen vectors may be printed in any order.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both stable vectors require Gravimetric coil 1, meaning Gravimetric coil 2 can never be charged. Thus, a complete charge of all coils is impossible.
