<STATEMENT>
# Problem A — Calibration Matrices

Time limit: 5 s   Memory limit: 256 MB

## Description

A satellite communications array requires the calibration of exactly **k** distinct transmission channels. Each channel configuration is composed of three parameters: a frequency band, a modulation scheme, and an encryption key. For each parameter category, the available options are indexed by integers from 1 to **k**. The hardware capacity limits the number of channels **k** to at most 22.

Due to signal interference, only specific combinations of parameters are viable. The engineering team has certified exactly **t** approved configurations. Each approved configuration is given as a triplet `(x, y, z)`, meaning frequency band **x**, modulation scheme **y**, and encryption key **z** can be successfully combined.

To finalize the calibration, you must select exactly **k** configurations from the approved list. This selection must satisfy the following hardware capacity limits:
- Each frequency band (from 1 to **k**) can be utilized by at most one selected configuration.
- Each modulation scheme (from 1 to **k**) can be utilized by at most one selected configuration.
- Each encryption key (from 1 to **k**) can be utilized by at most one selected configuration.

Determine whether it is possible to select exactly **k** approved configurations that satisfy these conditions. If a valid set exists, provide it.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the number of options in each parameter category and the total number of approved configurations.
Each of the following **t** lines provides three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing an approved configuration utilizing frequency band **x**, modulation scheme **y**, and encryption key **z**. All listed configurations are distinct.

## Output

If a valid selection of **k** configurations can be formed, print `YES` on the first line. Then, output **k** lines, each containing the three integers `x y z` of one selected configuration. Any valid selection of **k** configurations that meets the hardware capacity limits is accepted; the chosen configurations may be printed in any order.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both approved configurations use modulation scheme 1. If both are selected to meet the requirement of exactly **k** = 2 configurations, modulation scheme 1 would be utilized by more than one selected configuration, which violates the hardware capacity limits. Therefore, a valid selection is impossible.
</STATEMENT>
<RATIONALE>
The explicit sorting condition (which models easily recognize as a permutation/exact-cover requirement) has been removed. It is replaced with a capacity constraint specifying that each index can be used "at most once". Since exactly $k$ configurations must be selected and there are exactly $k$ indices per category, the Pigeonhole Principle forces each index to be used exactly once, maintaining the underlying mathematical requirement while avoiding structural giveaways like "cover".
</RATIONALE>
<PRESERVED_ANSWER>
Selecting exactly $k$ items such that each of the $k$ available options in a category is used at most once is mathematically identical to selecting items such that their category indices form the sequence $1 \dots k$ when sorted.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching (NP-complete), as finding a subset of triples such that every element in three disjoint sets of size $k$ appears exactly once is enforced by the combination of the selection size and the "at most one" capacity limit.
</PRESERVED_CLASS>
