<METHOD_NAME>Polynomial Identity Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the sum of powers of 2 (which models trivially recognize as bitmasks) with a requirement that two polynomials in a continuous variable $w$ must be identical for all real $w$. This mathematically forces the multiset of coordinates to match $\{1 \dots k\}$ via coefficient matching, while removing the explicit bitwise/binary affordance.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Calibration Matrices

Time limit: 5 s   Memory limit: 256 MB

## Description

A satellite communications array requires the setup of a stable transmission network. The system has a capacity limit of **k** channels (where **k** is at most 22).

The engineering team has certified exactly **t** approved configurations. Each approved configuration is given as a triplet `(x, y, z)`, representing a channel utilizing frequency band **x**, modulation scheme **y**, and encryption key **z**. All values are integers between 1 and **k**. All listed configurations are distinct.

To finalize the network setup, you must select and deploy exactly **k** configurations from the approved list.

A deployed network is considered fully operational only if its resonance levels match the baseline threshold across all three parameter types under any environmental condition. The environmental condition is represented by a real number $w$. For a selection of **k** configurations $(x_1, y_1, z_1), (x_2, y_2, z_2), \dots, (x_k, y_k, z_k)$, the system's resonance polynomials are evaluated as follows:
- The frequency resonance is $R_f(w) = \sum_{i=1}^k w^{x_i}$.
- The modulation resonance is $R_m(w) = \sum_{i=1}^k w^{y_i}$.
- The encryption resonance is $R_e(w) = \sum_{i=1}^k w^{z_i}$.

The baseline threshold for a system of capacity **k** is defined as the polynomial $B_k(w) = \sum_{j=1}^k w^j$.

A valid deployment of **k** configurations must satisfy all three of the following conditions simultaneously:
1. $R_f(w) = B_k(w)$ for all real numbers $w$.
2. $R_m(w) = B_k(w)$ for all real numbers $w$.
3. $R_e(w) = B_k(w)$ for all real numbers $w$.

Determine whether it is possible to deploy exactly **k** approved configurations that meet these criteria. If a valid set exists, provide it.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the capacity limit and the total number of approved configurations.
Each of the following **t** lines provides three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing an approved configuration utilizing frequency band **x**, modulation scheme **y**, and encryption key **z**. All listed configurations are distinct.

## Output

If a valid deployment of **k** configurations can be formed, print `YES` on the first line. Then, output **k** lines, each containing the three integers `x y z` of one selected configuration. Any valid deployment of **k** configurations is accepted; the chosen configurations may be printed in any order.

If no such deployment is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, the baseline polynomial is $B_2(w) = w^1 + w^2$. If we select the only two available configurations, their modulation schemes are $y_1 = 1$ and $y_2 = 1$. The modulation resonance would be $R_m(w) = w^1 + w^1 = 2w$. Since $2w$ is not equal to $w + w^2$ for all real numbers $w$, a valid deployment is impossible.
</STATEMENT>

<RATIONALE>
The problem was modified to replace the sum of powers of 2 with an equivalent continuous polynomial identity in a variable $w$. This removes the explicit binary/bitmask affordance that models use to pattern-match the problem to exact cover. To succeed, a model must now genuinely deduce that polynomial equality over all reals requires corresponding coefficients to be identical, which in turn forces the multiset of chosen coordinates to be exactly $\{1 \dots k\}$.
</RATIONALE>

<PRESERVED_ANSWER>
Two polynomials are identically equal for all real numbers if and only if their coefficients are exactly equal, meaning the chosen configurations must contain exactly one of each value from 1 to $k$ for each parameter, perfectly matching the original power-of-two logic.
</PRESERVED_ANSWER>

<PRESERVED_CLASS>
The underlying requirement remains that exactly one of each parameter value must be selected, keeping it identical to 3-Dimensional Matching (Exact Cover).
</PRESERVED_CLASS>

<RISK>
Models might misinterpret the continuous variable $w$ as requiring numerical sampling or floating-point evaluation rather than algebraic coefficient matching, though the Note strongly hints at symbolic coefficient comparison.
</RISK>
