<METHOD_NAME>Sum of Powers Identity Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the requirement for distinctness (Exact Cover) with the mathematically equivalent condition that the sum of 2^(x-1) over exactly k elements equals 2^k - 1. Models that fail to deduce this equivalence will implement a sum-tracking DFS which fails to prune duplicate selections early, resulting in a Time Limit Exceeded. Models that reason deeply will recognize the identity, map it back to Exact Cover, and use DLX or bitmask DFS with early pruning.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Harmonic Frameworks

Time limit: 5 s   Memory limit: 256 MB

## Description

A construction firm is designing a **k**-stage structural framework. There are **k** possible length categories, **k** possible width categories, and **k** possible height categories, each indexed from 1 to **k**. The hardware capacity limits **k** to at most 22.

The supplier has provided a catalog of exactly **t** available block types. Each block type is given as a triplet `(x, y, z)`, representing a block that belongs to length category **x**, width category **y**, and height category **z**. All block types listed in the catalog are distinct.

To complete the framework, you must choose a subset of exactly **k** blocks from the catalog. A framework is considered perfectly balanced if and only if your chosen subset satisfies the *Harmonic Volume Condition*.

Let the chosen blocks have length categories $x_1, x_2, \dots, x_k$, width categories $y_1, y_2, \dots, y_k$, and height categories $z_1, z_2, \dots, z_k$. The condition requires that all three of the following equations must hold simultaneously:
1. $\sum_{i=1}^k 2^{x_i - 1} = 2^k - 1$
2. $\sum_{i=1}^k 2^{y_i - 1} = 2^k - 1$
3. $\sum_{i=1}^k 2^{z_i - 1} = 2^k - 1$

Determine whether it is possible to choose exactly **k** blocks from the catalog such that the Harmonic Volume Condition is satisfied. If a valid subset exists, provide it.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the number of categories for each dimension and the total number of available block types.
Each of the following **t** lines provides three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing an available block type with length category **x**, width category **y**, and height category **z**. All listed block types are distinct.

## Output

If a valid subset of **k** blocks can be formed, print `YES` on the first line. Then, output **k** lines, each containing the three integers `x y z` of one selected block. Any valid subset of **k** blocks satisfying the condition is accepted; the chosen blocks may be printed in any order.

If no such subset is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, you must select exactly $k=2$ blocks. The only available blocks are `1 1 1` and `2 1 2`. If you select both, the sum for the second parameter (width) is $2^{1-1} + 2^{1-1} = 2^0 + 2^0 = 1 + 1 = 2$. The required sum for $k=2$ is $2^2 - 1 = 3$. Since $2 \neq 3$, the Harmonic Volume Condition is not satisfied for the width dimension. Thus, a valid framework cannot be formed.
</STATEMENT>
<RATIONALE>
I completely removed the concepts of "perfect isolation" and "not sharing parameters," replacing them with a mathematical condition regarding the sum of powers of 2. This forces the model to mathematically deduce that a sum of exactly $k$ powers of 2 equalling $2^k - 1$ strictly requires the powers to be distinct. If it fails to deduce this and instead implements a naive sum-tracking DFS, it will fail to prune duplicates early and will Time Limit Exceed.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical condition $\sum_{i=1}^k 2^{v_i - 1} = 2^k - 1$ for exactly $k$ integers $v_i \in \{1 \dots k\}$ is satisfied if and only if the integers form a permutation of $\{1 \dots k\}$, making the set of valid configurations identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains 3-Dimensional Matching (NP-complete), as the mathematical condition is merely an isomorphic way of defining exact covers over the three dimensions.
</PRESERVED_CLASS>
