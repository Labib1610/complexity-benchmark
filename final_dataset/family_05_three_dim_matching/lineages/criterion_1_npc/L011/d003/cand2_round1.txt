# Problem A — Limited Edition Action Figures

Time limit: 5 s   Memory limit: 256 MB

## Description

A toy factory produces custom action figures. Each figure is assembled from three components: a head, a torso, and a pair of legs. The factory's inventory contains exactly **k** distinct head molds, **k** distinct torso molds, and **k** distinct leg molds. Within each category, the molds are numbered from 1 to **k**.

Due to structural differences, not all components can be snapped together. The engineering team has tested the molds and approved exactly **t** viable assembly designs. Each approved design is a specific combination `(x, y, z)`, indicating that head mold **x**, torso mold **y**, and leg mold **z** fit together perfectly to form a complete figure.

The factory manager plans to launch a limited-edition series consisting of exactly **k** action figures. These **k** figures must be chosen from the **t** approved assembly designs. To maximize the visual variety of the series, the manager enforces a strict exclusivity rule on the chosen designs: no two selected designs may use the same head mold, no two may use the same torso mold, and no two may use the same leg mold.

Determine whether it is possible to select exactly **k** assembly designs from the approved list that satisfy this exclusivity rule. If it is possible, provide one valid selection of designs.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the number of molds in each of the three component categories, and the total number of approved assembly designs.
Each of the next **t** lines contains three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing an approved design consisting of head mold **x**, torso mold **y**, and leg mold **z**. All listed assembly designs are distinct.

## Output

If a valid series of **k** action figures is possible, print `YES` on the first line. Then, print **k** lines, each containing the three integers `x y z` of one selected assembly design. Any valid selection of **k** designs that satisfies the exclusivity rule is accepted; the chosen designs may be printed in any order.

If no such series is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both approved designs require torso mold 1, so they cannot both be selected for the series. A selection of 2 designs is therefore impossible.
