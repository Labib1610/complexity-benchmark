**Solution Explanation**

For every component we have a *column* :

* columns `0 … k‑1` – the `k` molds,
* columns `k … 2k‑1` – the `k` dyes,
* columns `2k … 3k‑1` – the `k` packaging lines.

A certified configuration `(x , y , z)` is a *row* that covers exactly three
columns  

```
x‑1 ,          k + (y‑1) ,          2k + (z‑1)
```

The task is to choose `k` rows so that every column is covered **once**.
That is exactly the **exact cover** problem.

`k ≤ 22`, therefore the universe has at most `3·22 = 66` columns and at most
`k³ = 10648` rows – tiny for Donald Knuth’s dancing‑links algorithm
(Algorithm X).  
The algorithm repeatedly

* picks a column with the smallest number of rows (branching factor minimisation),
* tries each row that contains this column,
* removes all columns covered by this row,
* recurses.

If all columns disappear we have found a solution.

The algorithm is backtracking, but with the heuristic it finishes instantly
for the given limits.



--------------------------------------------------------------------

#### Algorithm
```
read k , t
for each of the t triples (x,y,z)
        create a row containing the three column indices
run DLX (Algorithm X) on the matrix with 3k columns
if a solution is found
        print YES and the stored triples of the chosen rows
else
        print NO
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct set of triples
iff such a set exists.

---

##### Lemma 1  
In the DLX matrix each row corresponds to exactly one certified triple and
covers exactly the three columns representing its mold, dye and packaging line.

*Proof.* Construction of the matrix uses the mapping described above,
and each input triple creates one row containing precisely those three
columns. ∎



##### Lemma 2  
A set of rows is a solution of the exact‑cover problem **iff**
the corresponding triples use every mold, every dye and every packaging line
exactly once.

*Proof.* By Lemma&nbsp;1 a row covers the three columns of its triple.
Exact cover means every column is covered by **one** chosen row,
hence each component index appears in exactly one chosen triple. ∎



##### Lemma 3  
If the DLX recursion reaches a state where no columns remain,
the rows selected on the recursion path form a valid production cycle.

*Proof.* No columns left ⇒ every column has been covered exactly once.
By Lemma&nbsp;2 the associated triples satisfy the exclusivity rule and their
count equals the number of removed columns divided by three, i.e. `k`. ∎



##### Lemma 4  
If a valid production cycle exists, DLX will eventually find it.

*Proof.* Consider any valid set `S` of `k` rows.
During the search DLX explores **all** possibilities that respect the
exact‑cover constraints: at each step it may choose any row that contains the
currently selected column.
Because `S` itself respects the constraints, there is a sequence of choices
that picks exactly the rows of `S`.  
DLX performs a depth‑first search over all such sequences, therefore it will
reach the leaf where all columns are removed, i.e. find `S`. ∎



##### Lemma 5  
If DLX reports failure (no exact cover), then no valid production cycle exists.

*Proof.* DLX exhaustively explores every combination of rows that could
cover the columns without conflict. By Lemma&nbsp;2 any valid cycle would be
such a combination. Since none is found, none exists. ∎



##### Theorem  
The program outputs  

* `YES` followed by `k` triples that satisfy the exclusivity rule  
  **iff** such a set exists,
* otherwise outputs `NO`.

*Proof.*  

*If* the program prints `YES`, it did so after DLX returned a set of rows.
By Lemma&nbsp;3 the corresponding triples form a valid cycle.

*Only‑if* a valid cycle exists, Lemma&nbsp;4 guarantees DLX finds an exact
cover, so the program prints `YES`.  
If no cycle exists, Lemma&nbsp;5 shows DLX cannot find an exact cover,
hence the program prints `NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`C = 3k ≤ 66` columns, `R = t ≤ k³ ≤ 10648` rows.

DLX operations are `O(1)` per node.  
The worst‑case time is exponential in `k` (the problem is NP‑complete),
but with `k ≤ 22` the search space is tiny; in practice it finishes far
below the 5 s limit.

Memory consumption: one node per 1‑entry → `3·R` nodes, each storing a few
integers → well under the 256 MB limit (≈ 1 MB).

#### Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(1000000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    # column indices: 0..k-1 molds, k..2k-1 dyes, 2k..3k-1 packs
    ncol = 3 * k

    rows = []          # list of triples (x,y,z)
    row_nodes = []     # list of column indices for each row

    for _ in range(t):
        x = int(next(it)) - 1
        y = int(next(it)) - 1
        z = int(next(it)) - 1
        rows.append((x + 1, y + 1, z + 1))
        row_nodes.append([x, k + y, 2 * k + z])

    # ---------- DLX structures ----------
    max_nodes = 3 * t + ncol + 1
    up = [0] * max_nodes
    down = [0] * max_nodes
    left = [0] * max_nodes
    right = [0] * max_nodes
    col = [0] * max_nodes
    row_id = [0] * max_nodes
    size = [0] * (ncol + 1)          # size[0] unused, columns are 1..ncol

    header = 0
    # header linked list of column headers 1..ncol
    for i in range(ncol + 1):
        up[i] = down[i] = i
        left[i] = i - 1
        right[i] = i + 1
    left[0] = ncol
    right[ncol] = 0

    node_cnt = ncol + 1

    # add rows
    for r, cols in enumerate(row_nodes, start=1):
        first = -1
        for c in cols:
            c += 1                     # shift to 1‑based column header
            node = node_cnt
            node_cnt += 1

            col[node] = c
            row_id[node] = r

            # vertical links
            up[node] = up[c]
            down[node] = c
            down[up[c]] = node
            up[c] = node
            size[c] += 1

            # horizontal links
            if first == -1:
                left[node] = right[node] = node
                first = node
            else:
                left[node] = left[first]
                right[node] = first
                right[left[first]] = node
                left[first] = node

    solution = []
    answer = None

    def cover(c):
        # remove column header
        left[right[c]] = left[c]
        right[left[c]] = right[c]
        i = down[c]
        while i != c:
            j = right[i]
            while j != i:
                down[up[j]] = down[j]
                up[down[j]] = up[j]
                size[col[j]] -= 1
                j = right[j]
            i = down[i]

    def uncover(c):
        i = up[c]
        while i != c:
            j = left[i]
            while j != i:
                size[col[j]] += 1
                down[up[j]] = j
                up[down[j]] = j
                j = left[j]
            i = up[i]
        left[right[c]] = c
        right[left[c]] = c

    def search(kd):
        nonlocal answer
        if right[header] == header:          # all columns covered
            answer = solution.copy()
            return True
        # choose column with minimal size
        c = right[header]
        min_sz = size[c]
        cc = c
        while cc != header:
            if size[cc] < min_sz:
                min_sz = size[cc]
                c = cc
                if min_sz == 0:
                    break
            cc = right[cc]
        if min_sz == 0:
            return False

        cover(c)
        r = down[c]
        while r != c:
            solution.append(row_id[r])
            j = right[r]
            while j != r:
                cover(col[j])
                j = right[j]
            if search(kd + 1):
                return True
            # backtrack
            j = left[r]
            while j != r:
                uncover(col[j])
                j = left[j]
            solution.pop()
            r = down[r]
        uncover(c)
        return False

    if search(0):
        out = ["YES"]
        for idx in answer:
            out.append("{} {} {}".format(*rows[idx - 1]))
        sys.stdout.write("\n".join(out))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```
