We can model this as a matching problem.  
Since \( k \leq 22 \), we can use bitmask DP to check feasibility.

We need to select exactly \( k \) triples such that:

- Sum of \( 2^{x_i} = B_k \)
- Sum of \( 2^{y_i} = B_k \)
- Sum of \( 2^{z_i} = B_k \)

Since \( B_k = 2^{k+1} - 2 \), each coordinate sum must have exactly one of each bit from 1 to k.

That means: for each bit position \( j \) (1..k), exactly one selected configuration must have \( x = j \), exactly one must have \( y = j \), and exactly one must have \( z = j \).

So we need a perfect matching between the k values of x, y, z.

We can solve with a backtracking / DP over bitmasks:

- State: mask of used x-values, mask of used y-values, mask of used z-values.
- We try to assign each configuration to fill the next missing x, y, z.

But t can be up to \( k^3 = 10648 \), and k=22, so brute force over all permutations is too large.  
We can use a recursive search with memoization.

We can also reduce the problem:  
We need to pick k triples such that the sets of x, y, z are each exactly {1..k}.  
This is equivalent to finding a perfect matching in a 3-partite hypergraph.

We can do a DFS:  
- Maintain which x, y, z are still missing.  
- At each step, pick the smallest missing x, and try all configurations with that x that also have missing y and z.  
- Recurse.

Because k ≤ 22, the state space is \( 2^{22} \times 2^{22} \times 2^{22} \) which is too large for full memoization, but with pruning and the fact that we always pick the smallest missing x, the branching is limited.

We can also use a bipartite matching approach:  
First, match x to y, then match y to z, but that doesn’t guarantee the same triple.

Better: Use a recursive backtracking with bitmasks and memoization on (mask_x, mask_y, mask_z).  
Since k=22, the number of states visited will be much smaller in practice.

Let’s implement that.

```python
import sys
sys.setrecursionlimit(1000000)

def solve():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    configs = []
    for _ in range(t):
        x, y, z = map(int, input().split())
        configs.append((x-1, y-1, z-1))  # 0-indexed

    full_mask = (1 << k) - 1
    # Group configs by x
    by_x = [[] for _ in range(k)]
    for idx, (x, y, z) in enumerate(configs):
        by_x[x].append((y, z, idx))

    memo = {}
    chosen = []

    def dfs(mask_x, mask_y, mask_z):
        if mask_x == full_mask and mask_y == full_mask and mask_z == full_mask:
            return True
        if mask_x == full_mask:
            return False
        # pick smallest missing x
        # find first zero bit in mask_x
        # use bit trick
        inv = (~mask_x) & full_mask
        if inv == 0:
            return False
        x = (inv & -inv).bit_length() - 1
        key = (mask_x, mask_y, mask_z)
        if key in memo:
            return False  # already failed
        for y, z, idx in by_x[x]:
            if (mask_y >> y) & 1:
                continue
            if (mask_z >> z) & 1:
                continue
            chosen.append(idx)
            if dfs(mask_x | (1 << x), mask_y | (1 << y), mask_z | (1 << z)):
                return True
            chosen.pop()
        memo[key] = False
        return False

    if dfs(0, 0, 0):
        print("YES")
        for idx in chosen:
            x, y, z = configs[idx]
            print(x+1, y+1, z+1)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
