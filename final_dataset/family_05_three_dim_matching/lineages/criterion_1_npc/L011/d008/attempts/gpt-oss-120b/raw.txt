**Solution Explanation**

For a fixed `k` we have the three sets  

```
X = {1,…,k}   (frequency)
Y = {1,…,k}   (modulation)
Z = {1,…,k}   (encryption)
```

For a chosen collection of `k` triples  

```
(xi , yi , zi)      i = 1 … k
```

the three resonance sums are

```
 Σ 2^{xi} , Σ 2^{yi} , Σ 2^{zi}
```

`B_k = 2^1+…+2^k` is the sum of *different* powers of two.
A sum of powers of two equals `B_k` **iff** every exponent `1…k` appears
*exactly once*.
Therefore a valid deployment must satisfy

* the `x`‑coordinates are a permutation of `1…k`,
* the `y`‑coordinates are a permutation of `1…k`,
* the `z`‑coordinates are a permutation of `1…k`.

So we have to pick `k` triples such that each element of `X`, each element of
`Y` and each element of `Z` is used **once**.
That is exactly an *exact cover* problem:

* columns : `k` columns for `X`, `k` for `Y`, `k` for `Z`   → `3k` columns
* rows    : one row for every approved triple `(x,y,z)`,
            covering the three columns `X_x , Y_y , Z_z`.

We need `k` rows that cover every column exactly once.

`k ≤ 22`, therefore at most `66` columns and at most `k³ ≤ 10648` rows.
The classic Algorithm X (Dancing Links) solves such instances easily.

--------------------------------------------------------------------

#### Algorithm
```
read k , t
for each triple (x,y,z)
        create a row covering columns  X_(x-1) , Y_(k+y-1) , Z_(2k+z-1)

run Algorithm X (depth‑first search)
        choose the column with the smallest number of rows (heuristic)
        try each row that covers this column
                cover its three columns
                recurse
                if a solution of size k is found → stop
                uncover again

if a solution was found
        output YES and the k triples of the chosen rows
else
        output NO
```

The recursion depth never exceeds `k` (≤ 22).  
All operations on the dancing‑link structure are `O(1)`, therefore the
running time is proportional to the number of visited nodes, which is tiny
for the given limits.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct set of triples
iff such a set exists.

---

##### Lemma 1  
A set of `k` triples satisfies the three resonance equalities  
iff each value `1…k` occurs exactly once among the `x`‑coordinates,
exactly once among the `y`‑coordinates and exactly once among the `z`‑coordinates.

**Proof.**  
`Σ 2^{xi} = B_k = Σ_{j=1}^k 2^j`.  
Binary representation of a sum of powers of two is unique; the right hand
side contains each power `2^j` once, therefore the left hand side must also
contain each power once, i.e. the multiset `{xi}` equals `{1,…,k}`.
The same argument holds for `y` and `z`. ∎



##### Lemma 2  
A collection of `k` triples fulfills Lemma&nbsp;1  
iff the corresponding `k` rows form an exact cover of the `3k` columns.

**Proof.**  
Row `(x,y,z)` covers exactly the three columns representing the three
coordinates.  
If every column is covered exactly once, each value `1…k` appears in the
corresponding coordinate exactly once, which is Lemma&nbsp;1.
Conversely, Lemma&nbsp;1 guarantees that each value appears once, therefore
each column is covered once. ∎



##### Lemma 3  
Algorithm X returns a set of rows exactly when an exact cover exists.

**Proof.**  
Algorithm X is a depth‑first search that explores all possible subsets of
rows that are pairwise column‑disjoint.
It backtracks whenever a column cannot be covered any more.
If an exact cover exists, the recursion can follow the rows of that cover,
never encountering a dead end, and finally reaches depth `k` where all
columns are covered – it returns this set.
If no exact cover exists, every branch eventually hits a column with no
available rows, causing backtracking; the algorithm exhausts the whole
search tree and returns failure. ∎



##### Lemma 4  
If the program outputs `YES` and the printed triples, they satisfy the three
resonance equalities.

**Proof.**  
`YES` is printed only when Algorithm X found a set of `k` rows.
By Lemma&nbsp;3 this set is an exact cover.
By Lemma&nbsp;2 the corresponding triples satisfy Lemma&nbsp;1,
hence the three resonance sums equal `B_k`. ∎



##### Lemma 5  
If a valid deployment of `k` triples exists, the program outputs `YES`.

**Proof.**  
A valid deployment satisfies Lemma&nbsp;1, therefore its triples form an
exact cover (Lemma&nbsp;2).  
Algorithm X will find such a cover (Lemma&nbsp;3) and the program prints
`YES`. ∎



##### Theorem  
The program prints `YES` and a correct list of `k` triples
iff such a list exists; otherwise it prints `NO`.

**Proof.**  
*If* part: by Lemma&nbsp;5 a solution ⇒ program prints `YES`.  
*Only‑if* part: by Lemma&nbsp;4 any printed list is a correct solution.  
If no solution exists, Algorithm X fails, the program prints `NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Columns* : `3k ≤ 66`  
*Rows*    : `t ≤ k³ ≤ 10648`

Construction of the dancing‑link structure: `O(t)`.

During the search each recursive step covers/uncovers three columns,
each in `O(1)`.  
The depth is at most `k ≤ 22`.  
The total number of visited nodes is far below the worst‑case exponential
(`k!`) for the given limits; in practice it finishes well within the
5 seconds limit.

Memory consumption: one node per row per column → `3t` nodes,
each a few integers → < 1 MB.

--------------------------------------------------------------------

#### Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(1000000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    # column indices: 0..k-1 for X, k..2k-1 for Y, 2k..3k-1 for Z
    ncol = 3 * k

    # dancing links structures
    # header node is 0
    size = 1  # next free node index
    # arrays
    left = [0]
    right = [0]
    up = [0]
    down = [0]
    col = [0]          # column of node
    row_id = [0]       # which input row (0‑based) the node belongs to

    # column header nodes 1..ncol
    for c in range(ncol):
        left.append(c)          # will be fixed later
        right.append(c + 1 if c + 1 <= ncol else 0)
        up.append(c)
        down.append(c)
        col.append(c)           # column header points to itself
        row_id.append(-1)
    left[0] = ncol
    right[ncol] = 0
    # fix left/right of column headers
    for c in range(1, ncol + 1):
        left[c] = c - 1
        right[c] = c + 1 if c + 1 <= ncol else 0

    # store the triples for output
    triples = []

    # add a row (three columns) for each triple
    for idx in range(t):
        x = int(next(it)) - 1
        y = int(next(it)) - 1
        z = int(next(it)) - 1
        triples.append((x + 1, y + 1, z + 1))
        cols = [x, k + y, 2 * k + z]          # column numbers (0‑based)
        first = None
        for c in cols:
            node = size
            size += 1
            # ensure arrays are long enough
            left.append(0)
            right.append(0)
            up.append(0)
            down.append(0)
            col.append(c)
            row_id.append(idx)

            # vertical links (insert above column header)
            up[node] = up[c + 1]
            down[node] = c + 1
            down[up[node]] = node
            up[down[node]] = node

            # horizontal links within the row
            if first is None:
                first = node
                left[node] = right[node] = node
            else:
                # insert to the right of first
                left[node] = left[first]
                right[node] = first
                right[left[node]] = node
                left[first] = node

    # column sizes for heuristic
    col_size = [0] * (ncol + 1)
    for c in range(1, ncol + 1):
        cnt = 0
        i = down[c]
        while i != c:
            cnt += 1
            i = down[i]
        col_size[c] = cnt

    solution = []
    found = False

    def cover(c):
        # remove column header
        left[right[c]] = left[c]
        right[left[c]] = right[c]
        # remove rows
        i = down[c]
        while i != c:
            j = right[i]
            while j != i:
                up[down[j]] = up[j]
                down[up[j]] = down[j]
                col_size[col[j] + 1] -= 1
                j = right[j]
            i = down[i]

    def uncover(c):
        i = up[c]
        while i != c:
            j = left[i]
            while j != i:
                col_size[col[j] + 1] += 1
                up[down[j]] = j
                down[up[j]] = j
                j = left[j]
            i = up[i]
        left[right[c]] = c
        right[left[c]] = c

    def search():
        nonlocal found
        if right[0] == 0:          # all columns covered
            found = True
            return
        # choose column with minimal size
        c = right[0]
        min_sz = col_size[c]
        j = right[c]
        while j != 0:
            if col_size[j] < min_sz:
                c = j
                min_sz = col_size[j]
                if min_sz == 0:
                    break
            j = right[j]
        if min_sz == 0:
            return
        cover(c)
        r = down[c]
        while r != c:
            solution.append(row_id[r])
            j = right[r]
            while j != r:
                cover(col[j] + 1)
                j = right[j]
            search()
            if found:
                return
            # backtrack
            j = left[r]
            while j != r:
                uncover(col[j] + 1)
                j = left[j]
            solution.pop()
            r = down[r]
        uncover(c)

    search()

    out = []
    if found:
        out.append("YES")
        for idx in solution:
            x, y, z = triples[idx]
            out.append(f"{x} {y} {z}")
    else:
        out.append("NO")
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
