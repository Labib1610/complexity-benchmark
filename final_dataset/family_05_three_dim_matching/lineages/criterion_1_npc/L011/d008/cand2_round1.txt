# Problem A — Orbital Uplink Calibration

Time limit: 5 s   Memory limit: 256 MB

## Description

An orbital satellite constellation needs to establish a synchronized uplink grid. The network supports a channel capacity of exactly **k** concurrent streams. The maximum allowed capacity **k** is equal to the total number of players on the pitch at any one time during a standard association football match (excluding substitutes).

Mission control has pre-authorized a pool of **t** distinct stream profiles. Each profile is defined by a triplet of integers `(x, y, z)`, corresponding respectively to its assigned frequency spectrum **x**, phase modulation **y**, and cryptographic seed **z**. These parameters are always positive integers no greater than **k**.

To bring the grid online, you must select and activate exactly **k** profiles from the pre-authorized pool.

The grid is considered perfectly synchronized if and only if the cumulative resonance in all three technological domains matches a specific target constant. The resonance is computed using powers of 2. For any chosen set of **k** profiles $(x_1, y_1, z_1), (x_2, y_2, z_2), \dots, (x_k, y_k, z_k)$, the grid yields the following three metrics:
- The spectrum resonance: $\sum_{i=1}^k 2^{x_i}$
- The phase resonance: $\sum_{i=1}^k 2^{y_i}$
- The cryptographic resonance: $\sum_{i=1}^k 2^{z_i}$

For a grid of capacity **k**, the target constant is defined as the sum $C_k = \sum_{j=1}^k 2^j$.

A successful activation of **k** profiles must simultaneously ensure:
1. The spectrum resonance evaluates to exactly $C_k$.
2. The phase resonance evaluates to exactly $C_k$.
3. The cryptographic resonance evaluates to exactly $C_k$.

Determine whether a set of exactly **k** profiles can be chosen to achieve perfect synchronization. If a valid configuration exists, output it.

## Input

The first line specifies two integers, **k** and **t** (1 ≤ k, 0 ≤ t ≤ k³): the channel capacity and the number of pre-authorized profiles. The absolute maximum for **k** is the total number of players on the pitch at any one time during a standard association football match (excluding substitutes).
This is followed by **t** lines, each containing three integers **x**, **y**, and **z** (1 ≤ x, y, z ≤ k), representing the spectrum, phase, and cryptographic seed of one profile. Every profile in the list is unique.

## Output

If a perfectly synchronized grid of **k** profiles can be formed, print `YES` on the first line. Then, print **k** lines, each containing the three integers `x y z` of a selected profile. If multiple valid sets exist, any of them will be accepted, and the profiles may be printed in any order.

If achieving perfect synchronization is impossible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, the target constant for capacity 2 is $C_2 = 2^1 + 2^2 = 6$. If we activate the only two available profiles, the phase resonance would be $2^1 + 2^1 = 4$. This does not equal the target constant $C_2 = 6$. Thus, perfect synchronization is impossible.

In base-2, the target sum is 2^{k+1}-2. Because the minimum number of powers of 2 required to sum to this value is exactly k (its Hamming weight), restricting the sum to exactly k terms still uniquely forces the selection of exactly one of each power 2^1 to 2^k, preserving the 3-Dimensional Matching reduction while hiding the positional-notation shortcut.
