<STATEMENT>
# Problem A — Resource Alignment

Time limit: 5 s   Memory limit: 256 MB

## Description

A facility must stabilize its core by activating exactly **k** operational protocols. The core's status is defined by three independent parameters: Alpha, Beta, and Gamma. Each parameter operates on an integer scale from 1 to **k**.

You are given a catalog of **t** tested protocols. Each protocol is specified by a triplet `(x, y, z)`, indicating it locks Alpha at **x**, Beta at **y**, and Gamma at **z**. 

To prevent catastrophic interference, the **k** activated protocols must be strictly orthogonal. Specifically, no two activated protocols may share the same Alpha value, no two may share the same Beta value, and no two may share the same Gamma value. 

Determine whether it is possible to select exactly **k** protocols from the catalog that satisfy this strict orthogonality requirement. If such a selection exists, output any one valid set of **k** protocols.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the required number of protocols (which also dictates the parameter range 1 through **k**) and the total number of tested protocols in the catalog.
Each of the next **t** lines contains three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing a protocol with Alpha **x**, Beta **y**, and Gamma **z**. All listed protocols are distinct.

## Output

If a valid set of exactly **k** protocols exists, print `YES` on the first line. Then, print **k** lines, each containing the three integers `x y z` of one selected protocol. Any valid orthogonal selection is accepted; the chosen protocols may be printed in any order.

If no such set is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both tested protocols lock Beta at 1. Since no two activated protocols can share the same Beta value, at most one protocol can be selected, making it impossible to form the required set of 2 protocols.
</STATEMENT>
<RATIONALE>
The original statement explicitly required assigning exactly one profile per operator, prompting models to loop over the $k$ operators and backtrack over available terminals/shifts. I reframed the problem as selecting a subset of exactly $k$ orthogonal protocols from a catalog of $t$ options, where no two protocols can share any parameter value. This forces the model to deduce the pigeonhole principle (that picking $k$ orthogonal items from a domain of $k$ implies exactly one per domain value) to discover the efficient $O(k!)$ backtracking strategy, otherwise they will fall back to an $O(2^t)$ subset search which will time out.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to select $k$ items from a set of $t$ such that no two share any of the three coordinates (from a domain of size $k$) is mathematically identical to finding a perfect 3D matching, preserving the exact same valid subsets and outputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching, continuing to be NP-complete.
</PRESERVED_CLASS>
