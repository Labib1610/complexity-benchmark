We need to select exactly k triples (x, y, z) such that all x, y, z are permutations of 1..k.  
This is a 3D matching problem, which is NP-hard in general, but k ≤ 22 allows a meet-in-the-middle or backtracking with pruning.

A common approach:  
- Split the problem into two halves: first choose assignments for operators 1..k/2, then for the rest.  
- Use bitmasks for terminals and shifts.  
- For each half, store possible (mask_terminal, mask_shift) combinations.  
- Then try to combine two halves that are disjoint in both masks.

We can implement a recursive backtracking with memoization on (operator_index, terminal_mask, shift_mask).  
Since k ≤ 22, the state space is large but with pruning and early termination it can work.

Here’s the solution:

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    profiles = []
    for _ in range(t):
        x, y, z = map(int, input().split())
        profiles.append((x-1, y-1, z-1))
    
    # Group profiles by operator
    by_op = [[] for _ in range(k)]
    for x, y, z in profiles:
        by_op[x].append((y, z))
    
    # Sort each list to have deterministic order
    for i in range(k):
        by_op[i].sort()
    
    # Backtracking with memoization
    memo = {}
    chosen = [None] * k
    
    def dfs(op_idx, term_mask, shift_mask):
        if op_idx == k:
            return True
        key = (op_idx, term_mask, shift_mask)
        if key in memo:
            return memo[key]
        for y, z in by_op[op_idx]:
            if not (term_mask >> y) & 1 and not (shift_mask >> z) & 1:
                chosen[op_idx] = (op_idx, y, z)
                if dfs(op_idx + 1, term_mask | (1 << y), shift_mask | (1 << z)):
                    memo[key] = True
                    return True
        memo[key] = False
        return False
    
    if dfs(0, 0, 0):
        print("YES")
        for x, y, z in chosen:
            print(x+1, y+1, z+1)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
