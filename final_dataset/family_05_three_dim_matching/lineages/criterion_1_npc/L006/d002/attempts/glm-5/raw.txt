Looking at this problem, I need to find k protocols where each protocol uses distinct raw materials, catalysts, and finishing treatments (all three must be permutations of 1..k).

This is a 3-dimensional matching problem. With k ≤ 22, I'll use a meet-in-the-middle approach combined with DP over subsets.

**Approach:**
1. Group protocols by raw material m. For each m, I have a list of (c, f) pairs.
2. Use meet-in-the-middle: split materials into two halves A and B.
3. For half A: enumerate all ways to assign materials in A to distinct catalysts, tracking which catalysts are used. For each subset of catalysts used, store the corresponding finishing treatment assignment (as a bitmask).
4. For half B: similarly enumerate, but track which catalysts are NOT used (complement).
5. For each subset S of catalysts used by A, I need B to use exactly the complement. Among all valid B assignments using catalysts in complement, I need to find one where the finishing treatments don't conflict with A's assignment.

For the finishing treatment matching, I use a DP: for each subset T of finishing treatments used by B, check if there's a valid B assignment. Then for A's assignment with finishing mask F_A, I need B to use finishing treatments in complement of F_A.

I store for A: `dpA[S]` = set of possible finishing masks F_A (as a frozenset or list).
For B: `dpB[S]` = set of possible finishing masks F_B.

Then for each S, check if there's F_A in dpA[S] and F_B in dpB[complement] with F_A | F_B = full mask and F_A & F_B = 0.

To reconstruct, I store parent pointers.
