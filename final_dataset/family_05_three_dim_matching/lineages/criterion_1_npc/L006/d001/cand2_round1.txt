<STATEMENT>
# Problem A — Architectural Harmony

Time limit: 5 s   Memory limit: 256 MB

## Description

You are commissioning an architectural installation comprising a network of specialized modules. The facility provides three independent infrastructure grids: the primary power grid, the liquid cooling grid, and the fiber-optic data grid. Each grid features a sequence of connection ports numbered consecutively starting from 1 up to **k**.

You have a manifest of **t** available modules. Each module is manufactured with fixed connections: it plugs into one specific port on the power grid, one specific port on the cooling grid, and one specific port on the data grid. No two modules in the manifest have the exact same combination of port connections across all three grids.

To achieve system harmony, you must activate a subset of exactly **k** modules. A selection is considered harmonious if:
- Every port on the primary power grid is occupied by exactly one activated module.
- Every port on the liquid cooling grid is occupied by exactly one activated module.
- Every port on the fiber-optic data grid is occupied by exactly one activated module.

Determine whether it is possible to achieve system harmony using the available modules, and if so, report one valid selection.

## Input

The first line contains two integers **k** and **t**. The number of ports per grid, **k**, is at least 1 and is bounded by the atomic number of titanium. The manifest size **t** is non-negative and will not exceed the total number of theoretically possible unique port combinations. 

Each of the next **t** lines contains three integers **x**, **y**, **z**. These values specify a module's connection ports on the power grid, cooling grid, and data grid, respectively. Each port number is between 1 and **k**, inclusive. No module's exact combination of the three ports is listed more than once.

## Output

If a harmonious selection of **k** modules exists, print `YES` on the first line, then print **k** lines, each containing the three port numbers `x y z` of one activated module. Any selection meeting the conditions is accepted; the modules may be printed in any order.

If no harmonious selection exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both available modules connect to cooling grid port 1, so cooling grid port 2 can never be occupied.
</STATEMENT>
<RATIONALE>
I replaced the explicit numeric bounds `(1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k)` with indirect descriptions based on a physical constant (the atomic number of titanium) and the maximum theoretical combinations. This forces the model to derive the bounds rather than relying on surface-level pattern matching of small integers to trigger an exponential search technique like bitmask backtracking. The scenario was also reframed as an architectural infrastructure grid to obscure the standard 3-partite matching vocabulary.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to select exactly $k$ modules such that every port on three grids is occupied exactly once is logically identical to selecting $k$ blocks such that every shape, color, and material is represented exactly once.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching, which is NP-complete, as it asks to find a perfect 3-partite matching in a given set of triplets.
</PRESERVED_CLASS>
<RISK>
The most likely way this could be judged ambiguous is if a model fails to correctly retrieve the atomic number of titanium (22), though this is a standard and unambiguous scientific fact.
</RISK>
