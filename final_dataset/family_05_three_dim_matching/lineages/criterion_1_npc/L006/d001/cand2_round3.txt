# Problem A — Structural Integrity

Time limit: 5 s   Memory limit: 256 MB

## Description

You are overseeing the construction of an experimental habitat. The structure is assembled from specialized load-bearing struts. Every strut is defined by three distinct structural parameters: its anchor point, its tension rating, and its composite alloy. Each parameter is designated by an integer from 1 to **k**. The habitat's modular scale **k** is restricted by physical design limits to a maximum of 22 distinct values per parameter.

You are provided with an inventory of **t** specific struts that have been delivered to the site. The total deliveries can range from 0 up to the theoretical maximum of **k**·**k**·**k** unique combinations. No two struts in the inventory have the exact same combination of anchor point, tension rating, and composite alloy.

To ensure the habitat's structural integrity, you must install a subset of exactly **k** struts from the inventory to form a "flawless framework". A framework is considered flawless if it satisfies all of the following conditions:
- Every anchor point from 1 to **k** is utilized exactly once among the installed struts.
- Every tension rating from 1 to **k** is utilized exactly once among the installed struts.
- Every composite alloy from 1 to **k** is utilized exactly once among the installed struts.

Determine whether it is possible to construct a flawless framework using the delivered inventory, and if so, report one valid installation plan.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the number of distinct values for each structural parameter, and the number of struts in the inventory. 
Each of the next **t** lines contains three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing a strut in the inventory with anchor point **x**, tension rating **y**, and composite alloy **z**. No strut configuration is listed more than once.

## Output

If a flawless framework of **k** struts can be constructed, print `YES` on the first line, then print **k** lines, each containing the three parameters `x y z` of one installed strut. Any valid installation plan is accepted; the struts may be printed in any order.

If no flawless framework can be constructed, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both available struts have tension rating 1, so tension rating 2 can never be included in the framework.
