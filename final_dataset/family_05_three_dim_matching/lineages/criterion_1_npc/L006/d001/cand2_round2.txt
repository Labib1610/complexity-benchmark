# Problem A — Orbital Network

Time limit: 5 s
Memory limit: 256 MB

## Description

You are configuring a communication network for an orbital station. The station requires a synchronized deployment of connection modules. Each individual module operates using three distinct settings: a target zone, a broadcast frequency, and an encryption protocol. Each setting is configured to an integer value from 1 to **k**.

You have a manifest of **t** pre-configured modules currently available in storage. No two modules in the manifest share the exact same configuration of zone, frequency, and protocol.

Your task is to deploy exactly **k** modules to establish a fully synchronized network. The deployment is considered synchronized if and only if it fulfills these operational requirements:
- Every zone from 1 to **k** is targeted by exactly one deployed module.
- Every frequency from 1 to **k** is broadcast by exactly one deployed module.
- Every protocol from 1 to **k** is utilized by exactly one deployed module.

Determine whether it is possible to achieve a fully synchronized network using the available modules. If it is possible, report one valid deployment.

## Input

The first line contains two integers **k** and **t**. The station's architecture supports a maximum of 22 concurrent zones, meaning the parameter limit **k** is an integer between 1 and 22 inclusive. The inventory count **t** can range from 0 up to the theoretical maximum of **k·k·k**.

Each of the next **t** lines contains three integers **x**, **y**, and **z**, representing a module configured for zone **x**, frequency **y**, and protocol **z**. Each setting value is between 1 and **k** inclusive. No module configuration appears more than once in the manifest.

## Output

If a fully synchronized network of **k** modules can be formed, print `YES` on the first line. Then, output **k** lines, each containing the three settings `x y z` of a deployed module. Any deployment that meets the requirements is acceptable, and the modules may be listed in any order.

If no such network can be formed, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both available modules broadcast on frequency 1, meaning frequency 2 can never be utilized in the deployment.
