<STATEMENT>
# Problem A — Orthogonal Vector Assembly

Time limit: 5 s   Memory limit: 256 MB

## Description

You are tasked with assembling a perfect structural matrix from a large database of candidate row vectors.

The structural matrix must consist of exactly $W$ rows. The value of $W$ is strictly determined by the physical limits of the assembly environment: it requires at least a single row to be valid, and cannot exceed the system's maximum row capacity of twenty-two.

You are given a database of $N$ known candidate vectors. Each vector has exactly three components. The size of the database can range from empty up to the theoretical maximum volume of $W \times W \times W$. Each candidate vector is given as a triplet of integers $(X, Y, Z)$, where each integer corresponds to a valid component address. All candidate vectors in the database are distinct.

Your objective is to select a subset of exactly $W$ vectors from the database to form the rows of the structural matrix. The selection must satisfy the following orthogonality condition:
- When the $W$ chosen vectors are stacked to form a $W \times 3$ matrix, the first column must be a permutation of the integers from $1$ to $W$, the second column must be a permutation of the integers from $1$ to $W$, and the third column must be a permutation of the integers from $1$ to $W$.

The vector database may be adversarially ordered and often contains dense, deliberately ambiguous instances. In these cases, nearly all partial subset assignments remain viable until very late in the validation process. Consequently, fixed-order unpruned evaluation will stall. You must determine if a valid structural matrix can be formed despite these worst-case exact-assembly challenges.

## Input

The first line contains two integers $W$ and $N$: the required number of rows and the number of candidate vectors. The bounds for these values are defined by the physical limits and theoretical maximums described above.

Each of the next $N$ lines contains three integers $X, Y$, and $Z$, representing an available candidate vector. Each component is a valid address bounded between the minimum threshold of one and $W$ inclusive. No vector is listed more than once.

## Output

If a valid structural matrix exists, print `YES` on the first line, then print $W$ lines, each containing the three integers `X Y Z` of one chosen vector. Any selection meeting the conditions is accepted; the vectors may be printed in any order.

If no such matrix exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both available vectors have $1$ as their second component. Choosing both would mean the second column is not a permutation of the integers from $1$ to $2$, so it is impossible to form a valid matrix.
</STATEMENT>
<RATIONALE>
The problem was reframed from selecting uniquely typed resources to selecting abstract vectors whose columns must form permutations. This symmetric framing discourages models from grouping the search state by the first coordinate (a key DFS optimization). An explicit warning about adversarial ordering was added to further bait models into abandoning simple DFS in favor of overly complex or un-grouped search strategies that are prone to bugs or Time Limit Exceeded errors. Numeric bounds were also moved entirely into the text to satisfy S07.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that exactly W vectors are chosen such that each column is a permutation of 1..W is mathematically identical to choosing exactly one of each resource type for exactly W batches.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching (an NP-complete exact cover problem), just described through matrix column permutations instead of chemical reagents.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "permutation of the integers from 1 to W" as requiring the rows to be ordered in a specific way, though the output format explicitly states "vectors may be printed in any order".
</RISK>
