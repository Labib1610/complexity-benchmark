We need to select exactly k distinct modules such that for each of the three coordinates, the sum of 2^(value-1) equals 2^k - 1.  

That means for each coordinate, the selected values must be exactly the set {1, 2, ..., k} — each value appears exactly once.  

So the problem reduces to:  
Find k distinct triples (x, y, z) from the given list such that the x's are a permutation of 1..k, the y's are a permutation of 1..k, and the z's are a permutation of 1..k.

This is equivalent to finding a perfect matching in a 3-partite 3-uniform hypergraph, which is NP-hard in general. But k ≤ 22, and t ≤ k³, so we can use backtracking with pruning.

We can model it as:  
We need to assign each value 1..k for x, y, z exactly once.  
We can do DFS over the x values, trying to match each x with a y and z that are still unused.

We'll store modules in a dictionary: for each x, a list of (y, z) pairs.

Then backtrack:
- For x from 1 to k, try each unused (y, z) from its list.
- Keep used_y and used_z sets.
- If we reach x = k+1, we have a solution.

We also need to output the triples in any order.

Let's implement this efficiently.

```python
import sys

def solve():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    modules = [[] for _ in range(k + 1)]
    for _ in range(t):
        x, y, z = map(int, input().split())
        modules[x].append((y, z))
    
    used_y = [False] * (k + 1)
    used_z = [False] * (k + 1)
    chosen = [None] * (k + 1)  # chosen[x] = (y, z)
    
    def dfs(x):
        if x > k:
            return True
        for y, z in modules[x]:
            if not used_y[y] and not used_z[z]:
                used_y[y] = True
                used_z[z] = True
                chosen[x] = (y, z)
                if dfs(x + 1):
                    return True
                used_y[y] = False
                used_z[z] = False
        return False
    
    if dfs(1):
        print("YES")
        for x in range(1, k + 1):
            y, z = chosen[x]
            print(x, y, z)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
