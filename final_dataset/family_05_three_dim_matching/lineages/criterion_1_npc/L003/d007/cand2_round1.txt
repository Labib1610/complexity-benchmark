<STATEMENT>
# Sensor Network Stability

Time limit: 5 s   Memory limit: 256 MB

## Description

You are deploying a specialized sensor network consisting of exactly **k** sensors. You are provided with a catalog of **t** available sensor models. Each sensor model is defined by three frequency parameters: an Alpha frequency **x**, a Beta frequency **y**, and a Gamma frequency **z**. All frequency parameters are integers from 1 to **k**.

To ensure the network is free from interference, the chosen set of **k** sensors must pass a mathematical stability test in each of the three frequency bands independently.

For the Alpha band, let the Alpha frequencies of your **k** chosen sensors be $x_1, x_2, \dots, x_k$. Consider a signal function formed by a weighted sum of powers of $v$ up to $k-1$, using real coefficients $c_1, c_2, \dots, c_k$:
$S_\alpha(v) = c_1 + c_2 v + c_3 v^2 + \dots + c_k v^{k-1}$

The Alpha frequencies are considered *stable* if the only way this signal can evaluate to zero at all **k** chosen frequencies (i.e., $S_\alpha(x_1) = 0, S_\alpha(x_2) = 0, \dots, S_\alpha(x_k) = 0$) is when all its coefficients are exactly zero ($c_1 = c_2 = \dots = c_k = 0$).

The Beta frequencies ($y_1, y_2, \dots, y_k$) and Gamma frequencies ($z_1, z_2, \dots, z_k$) must independently satisfy this exact same stability condition, using their own respective signal functions $S_\beta(v)$ and $S_\gamma(v)$.

Determine if it is possible to select exactly **k** sensors from the catalog such that the Alpha, Beta, and Gamma frequency sets are all stable.

## Input

The first line provides two integers, **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k³), where **k** is the required number of sensors and **t** is the total number of available sensor models in the catalog.
The next **t** lines each contain three integers **x**, **y**, and **z** (1 ≤ x, y, z ≤ k), representing the Alpha, Beta, and Gamma frequencies of a sensor model. Every sensor model listed in the input is distinct. You may choose only among these listed models, and each model from the catalog may be selected at most once.

## Output

If a stable network can be formed, output `YES` on the initial line. Following this, output **k** lines each containing three integers `x y z`, specifying the sensors used for your network. If several valid selections exist, supplying any one of them is sufficient. The sensors may be printed in any sequence.

If it is impossible to find **k** sensors satisfying the condition, output `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Output**

```

```

**Output**
```

1 1 1
```

## Note

In Example 2, you must select exactly 2 sensors. The only option is to select both available models: `1 1 1` and `2 1 2`. 
Their Beta frequencies are $y_1 = 1$ and $y_2 = 1$. 
We evaluate the stability of the Beta frequencies. For $k=2$, the signal function is $S_\beta(v) = c_1 + c_2 v$. 
We require the signal to evaluate to zero at both chosen Beta frequencies: $S_\beta(y_1) = c_1 + c_2(1) = 0$ and $S_\beta(y_2) = c_1 + c_2(1) = 0$. 
This system of equations is satisfied by non-zero coefficients, for example, $c_1 = -1$ and $c_2 = 1$. 
Because there is a non-zero solution that makes the signal evaluate to zero at all chosen Beta frequencies, the Beta frequencies are not stable. Thus, this selection is invalid, and no valid selection of 2 sensors is possible.
</STATEMENT>
<RATIONALE>
I replaced the "diversity product" with a mathematical requirement that a system of linear equations (forming a Vandermonde matrix) has only the trivial solution. By the fundamental theorem of algebra (or properties of Vandermonde determinants), a function of degree $k-1$ can only have $k$ roots if it is identically zero, which requires all evaluation points to be distinct. This forces the model to deduce the linear algebra equivalence to recognize that the condition simply demands distinct frequencies across all chosen sensors.
</RATIONALE>

The condition that the linear system has only the trivial solution is mathematically identical to requiring that the $k$ chosen values in each dimension are all distinct, which perfectly preserves the original exact cover constraint.
