We need to select exactly `k` components such that the product of the number of distinct values in each of the three dimensions equals `k³`.  

Since `k` is at most 22, the number of possible distinct values in each dimension is at most `k`.  
The product condition means each diversity must be exactly `k` (since all are ≤ k and their product is k³).  
So we need to select `k` components where each dimension has all `k` distinct values from 1 to k.

This becomes:  
- We need at least one component for each value in each dimension.  
- We need exactly `k` components total.  
- Since each dimension needs all k values, and we have k components, each component must cover a unique value in each dimension.  
That means the selected components must form a **Latin square** pattern: each value 1..k appears exactly once in each dimension.

So the problem reduces to:  
Can we pick k distinct triples from the catalog such that in each coordinate, all values 1..k appear exactly once?

This is equivalent to finding a perfect matching in a 3D matching problem, but with k ≤ 22 we can use backtracking with pruning.

We can model it as:  
- We need to assign each value 1..k in the first dimension to a component, and ensure the other two dimensions also cover all values exactly once.

We can do backtracking over the first dimension values, trying components that have that x value, and ensuring y and z are not used yet.

Let’s implement that.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    k = int(next(it))
    t = int(next(it))
    
    # Group components by x value
    by_x = [[] for _ in range(k+1)]
    for _ in range(t):
        x = int(next(it))
        y = int(next(it))
        z = int(next(it))
        by_x[x].append((x, y, z))
    
    # We need exactly one component for each x value 1..k
    # and y and z must each cover 1..k exactly once.
    
    used_y = [False]*(k+1)
    used_z = [False]*(k+1)
    chosen = [None]*(k+1)
    
    # Pre-check: each x must have at least one component
    for x in range(1, k+1):
        if not by_x[x]:
            print("NO")
            return
    
    def backtrack(x):
        if x == k+1:
            return True
        for comp in by_x[x]:
            _, y, z = comp
            if not used_y[y] and not used_z[z]:
                used_y[y] = True
                used_z[z] = True
                chosen[x] = comp
                if backtrack(x+1):
                    return True
                used_y[y] = False
                used_z[z] = False
        return False
    
    if backtrack(1):
        print("YES")
        for x in range(1, k+1):
            print(*chosen[x])
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
