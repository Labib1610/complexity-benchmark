<METHOD_NAME>Global Cardinality Product</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the pairwise Hamming distance constraint with a global constraint on the product of the number of unique values in each dimension. Models relying on recognizing pairwise incompatibilities to construct a constraint graph or DLX matrix will struggle to parse this non-linear global aggregation into a standard exact cover problem.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Alloy Formulation

Time limit: 5 s
Memory limit: 256 MB

## Description

You are formulating a new alloy. The material requires a combination of exactly **k** distinct component types.

You have access to a catalog containing **t** available component types. Each component type is characterized by three elemental ratings: Alpha, Beta, and Gamma. Each rating is expressed as an integer from 1 to **k**.

When a subset of components is mixed, the "diversity" of each elemental rating is defined as the number of unique values of that rating present in the mixture. Specifically, the Alpha diversity is the number of unique Alpha ratings among the selected components. The Beta and Gamma diversities are determined in the exact same manner for their respective ratings.

To achieve the required structural stability, your selected subset of exactly **k** components must satisfy a strict mathematical condition: the product of its Alpha diversity, its Beta diversity, and its Gamma diversity must be no less than **k**³.

Determine if such an alloy can be formulated from the given catalog.

## Input

The first line provides two integers, **k** and **t**. The target number of components, **k**, is at least 1 and does not exceed the atomic number of Titanium. The catalog size, **t**, ranges from 0 up to the cube of **k**.

The next **t** lines each contain three integers representing the Alpha, Beta, and Gamma ratings of a component type in the catalog. Every component type in the input is distinct.

## Output

If a valid alloy can be formulated, output `YES` on the initial line. Following this, output **k** lines, each containing the three ratings of a selected component type. If several valid selections exist, supplying any one of them is sufficient. The components may be printed in any sequence.

If it is impossible to select exactly **k** components satisfying the stability condition, output `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, the two available component types are `1 1 1` and `2 1 2`. If both are selected to form a subset of size 2, the Alpha ratings present are {1, 2} (diversity 2), the Beta ratings present are {1} (diversity 1), and the Gamma ratings present are {1, 2} (diversity 2). The product of these diversities is 2 × 1 × 2 = 4. Since 4 is less than 2³ (8), this selection does not satisfy the stability condition. With only 2 components available, it is impossible to formulate the alloy.
</STATEMENT>
<RATIONALE>
The pairwise Hamming distance constraint was replaced with a global condition on the product of the number of unique values in each dimension. The upper bound for `k` is stated indirectly via the atomic number of Titanium (22). This forces the model to mathematically deduce that a product of three subset diversities reaching `k^3` implies each must be exactly `k`, which in turn means all selected elements are entirely distinct across every dimension, rather than pattern-matching to Exact Cover via pairwise disjointness.
</RATIONALE>
<PRESERVED_ANSWER>
Because each rating is bounded by `k` and exactly `k` components are chosen, the maximum possible diversity for any rating is `k`; thus, their product can only be at least `k^3` if all three diversities are exactly `k`, meaning all selected components differ completely in every position, which is mathematically identical to requiring a pairwise Hamming distance of exactly 3.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching (or Exact Cover), where `k` tuples must be selected such that every coordinate value from 1 to `k` is covered exactly once, maintaining its NP-complete status.
</PRESERVED_CLASS>
