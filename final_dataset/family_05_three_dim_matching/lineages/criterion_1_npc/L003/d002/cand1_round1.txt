<STATEMENT>
# Problem A — Pipeline Hardware Allocation

Time limit: 5 s   Memory limit: 256 MB

## Description

A manufacturing facility builds custom circuit boards through a three-step automated process.

**Step 1: Ingestion.** Raw materials are transported to the main floor.

**Step 2: Equipment Synchronization.** The floor houses $k$ mechanical actuators, $k$ laser scanners, and $k$ processing units. For each equipment category, the items are labeled with integers from 1 to $k$. The main floor provides 22 installation bays per equipment category, which serves as the absolute physical limit for the equipment count. 

A single, independent manufacturing track is formed by linking together one mechanical actuator, one laser scanner, and one processing unit. However, due to complex timing dependencies, a track can only function if the specific combination of components is explicitly listed as a certified configuration. The total number of certified configurations, $t$, will never exceed the theoretical maximum number of ways to pick one component from each of the three categories.

Your objective is to fully utilize the facility's hardware. You must select a subset of the certified configurations to deploy as functional tracks. The deployment is only successful if no hardware is left idle and no hardware is assigned to more than one track simultaneously. 

**Step 3: Diagnostics.** Completed boards are tested.

Your module handles Step 2. Given the quantity $k$ and the list of certified configurations, determine if the facility can successfully deploy all of its equipment into functional tracks. If so, output the configurations to be activated.

## Input

The first line contains two integers $k$ and $t$. The quantity of equipment in each category, $k$, is at least 1 and cannot exceed the facility's physical limit of 22 installation bays per category. The number of configurations, $t$, is non-negative and bounded by the total number of ways to select one component from each of the three categories.

Then, $t$ lines follow. Each line consists of three integers $x$, $y$, and $z$ (ranging from 1 to $k$), indicating that mechanical actuator $x$, laser scanner $y$, and processing unit $z$ can operate together as a certified configuration. All listed configurations are unique.

## Output

If all equipment can be successfully deployed such that every component is used exactly once, print `YES` on the first line. On the following $k$ lines, print three integers `x y z` per line, representing the equipment used in each activated track. Any valid deployment will be accepted. You may print the chosen tracks in any order.

If there is no way to deploy all equipment without leaving components idle or sharing them, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both certified configurations require laser scanner 1. This means laser scanner 2 cannot be deployed, making it impossible to fully utilize the hardware without sharing components.

<RATIONALE>
Removed the direct "choose k configurations such that every individual [item] is incorporated into exactly one track" sentence, which reads as a textbook definition of Exact Cover / 3D Matching. Replaced it with a requirement to "fully utilize the facility's hardware" where "no hardware is left idle and no hardware is assigned to more than one track simultaneously." Also stated the numeric bounds indirectly through physical limits (22 installation bays) and combinatorial logic (ways to pick one from each category) per strategy S07.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to use all hardware without sharing any components is logically identical to finding exactly $k$ disjoint triplets that cover all $3k$ items, preserving the solution set.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains 3-Dimensional Matching as the core objective is to find a perfect 3-uniform hypergraph matching.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "ways to select one component from each of the three categories" as something other than $k^3$, but since this is only an upper bound for $t$ (which is read dynamically), it shouldn't cause algorithmic failure.
</RISK>
