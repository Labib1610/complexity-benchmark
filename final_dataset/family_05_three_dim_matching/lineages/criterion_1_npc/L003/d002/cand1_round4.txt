# Problem A — Pipeline Hardware Allocation

Time limit: 5 s   Memory limit: 256 MB

## Description

A purification plant processes water through a three-stage automated sequence.

**Stage 1: Intake.** Raw water is drawn into the main facility.

**Stage 2: Hardware Synchronization.** The facility contains exactly **k** intake pumps, **k** membrane filters, and **k** discharge valves. Within each category, the hardware components are identified by integers from 1 to **k**. A single filtration pipeline requires linking together exactly one intake pump, one membrane filter, and one discharge valve. However, due to pressure dependencies, a pipeline can only be formed if its specific combination of (pump, filter, valve) is explicitly provided as a tested blueprint.

Your task is to establish exactly **k** independent pipelines by selecting exactly **k** blueprints from the provided list. This selection must satisfy a strict requirement: every intake pump (from 1 to **k**) must be used in exactly one selected blueprint; independently, every membrane filter (from 1 to **k**) must be used in exactly one selected blueprint; and every discharge valve (from 1 to **k**) must be used in exactly one selected blueprint.

**Stage 3: Outflow.** Processed water is released.

Your module handles Stage 2. Given the quantity **k** and the list of tested blueprints, determine if the facility can successfully deploy all of its hardware into **k** functional pipelines according to the rule above. If so, output the blueprints to be activated.

## Input

The first line provides two integers **k** and **t**. The integer **k** is the quantity of hardware in each category. The plant's physical layout limits **k** to be at most 22, and it must be at least 1 to operate. The integer **t** is the number of tested blueprints available; it ranges from a minimum of 0 up to the maximum possible combinations (**k** cubed).

Following this are **t** lines, each containing three integers **x**, **y**, and **z**. These indicate that intake pump **x**, membrane filter **y**, and discharge valve **z** form a tested blueprint. Since they refer to the available hardware, each ID is a positive integer bounded by **k**. No combination is listed more than once.

## Output

If it is possible to form exactly **k** pipelines such that every pump, filter, and valve is used exactly once across the selected blueprints, print `YES` on the first line. On the following **k** lines, print three integers `x y z` per line, representing the hardware used in each pipeline. Any valid set of **k** blueprints that meets this exactness condition will be accepted. You may print the chosen pipelines in any order.

If there is no way to deploy all hardware into **k** pipelines under these rules, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both tested blueprints require membrane filter 1. This means membrane filter 2 cannot be used, making it impossible to satisfy the requirement that each filter appears in exactly one selected blueprint. Thus, 2 valid pipelines cannot be formed.
