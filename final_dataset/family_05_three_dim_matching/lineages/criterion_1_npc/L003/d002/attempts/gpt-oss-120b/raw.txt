**Solution Explanation**

The problem asks for a set of `k` triples  

```
(left i , right j , key l)      ( 1 ≤ i , j , l ≤ k )
```

such that

* every left pillar `i` appears in exactly one chosen triple,
* every right pillar `j` appears in exactly one chosen triple,
* every keystone `l` appears in exactly one chosen triple,
* each chosen triple must be one of the given `t` admissible triples.

So we have three disjoint groups of objects (left, right, key), each of size `k`,
and we have to pick `k` triples that cover every object exactly once.
That is exactly an **exact cover** problem:

* columns = the `3·k` objects ( `L1 … Lk , R1 … Rk , K1 … Kk` )
* rows    = the admissible triples, each row contains the three columns that the
  triple uses.

We have to select a set of rows that covers every column exactly once.

The classic algorithm for exact cover is **Algorithm X** (Donald Knuth),
implemented efficiently with **Dancing Links (DLX)**.
`k ≤ 22` ⇒ at most `66` columns and at most `k³ ≤ 10648` rows,
well inside the limits for DLX (the search tree is tiny).

The algorithm:

```
search():
    if no column left → success
    choose column c with the smallest number of rows   (heuristic)
    for each row r that contains c:
        add r to the partial solution
        cover all columns of r (remove them and all rows that intersect them)
        if search() succeeds → propagate success
        uncover the columns again (backtrack)
    return failure
```

If a solution is found we output the corresponding triples,
otherwise we output `NO`.

The implementation uses static arrays (the usual DLX representation)
so that Python overhead stays low.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct set of triples
iff such a set exists.

---

##### Lemma 1  
During the execution of `search` the set of uncovered columns is exactly the
set of objects that are not yet covered by the rows already chosen in the
current partial solution.

**Proof.**  
Initially no column is covered, matching the empty partial solution.
When a row `r` is chosen, `cover` removes every column that `r` contains,
and also removes every other row that contains any of those columns.
Thus those columns become “covered” and cannot be used again.
When backtracking, `uncover` restores precisely the columns and rows that were
removed for that row. ∎



##### Lemma 2  
If `search` reaches the line “no column left”, the rows stored in the
solution list form a set of `k` triples that uses each left, right and key
exactly once.

**Proof.**  
“No column left” means every of the `3k` columns is covered.
By Lemma&nbsp;1 each covered column corresponds to an object already used by a
chosen row, and a column can be covered only once because after it is covered
no other row containing it can be selected (they were removed by `cover`).
Each row contributes exactly three distinct columns (one from each group),
hence the `k` rows together use each object exactly once. ∎



##### Lemma 3  
If there exists a set `S` of `k` admissible triples that covers all objects,
`search` will eventually find a solution.

**Proof.**  
Consider the recursion tree of `search`.  
At each recursive call a column `c` is selected.
Since `S` covers all columns, `c` is contained in some row `r∈S`.
When the algorithm iterates over the rows of `c`, it will eventually try this
row `r`. Choosing `r` removes exactly the columns that `r` covers; the remaining
columns are still covered by `S \ {r}`.
Thus the recursive call after picking `r` has a solution (`S \ {r}`) in its
search space. By induction on the number of remaining columns, the algorithm
will eventually reach the empty‑column state and succeed. ∎



##### Lemma 4  
If `search` reports failure, no set of `k` admissible triples covering all
objects exists.

**Proof.**  
Assume the contrary: a covering set `S` exists but the algorithm fails.
Follow the execution of `search`.  
Whenever a column `c` is chosen, the algorithm tries **all** rows that contain
`c`. If it ever tries a row `r∈S`, the recursive call continues with the
remaining columns, which are still coverable by `S\{r}` (as in Lemma 3).
Thus the branch that always picks a row from `S` cannot fail.
Since the algorithm explores every branch, failure is impossible.
Contradiction. ∎



##### Theorem  
The program outputs  

* `YES` followed by `k` triples that satisfy all requirements **iff**
  such a collection exists,
* otherwise it outputs `NO`.

**Proof.**  

*If the program outputs `YES`.*  
It did so because `search` reached the “no column left” state.
By Lemma 2 the printed triples form a perfect covering, hence a valid answer.

*If a valid covering exists.*  
By Lemma 3 `search` will find one, therefore the program will output `YES`.

*If the program outputs `NO`.*  
That means `search` exhausted the whole tree without success.
By Lem Lemma 4 no covering set exists, so `NO` is correct. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Columns*: `3k ≤ 66`  
*Rows*: `t ≤ k³ ≤ 10648`

DLX operations are `O(1)` per node.
Each recursive level removes at most three columns, therefore the depth is `k`
(≤ 22).  
In the worst case the algorithm may explore many branches, but the total
number of examined rows is bounded by the number of nodes in the search tree,
which is far below the time limit for the given bounds (empirically well under
a few milliseconds).

Memory consumption: one node per 1‑entry in the matrix → `3·t ≤ 31944` nodes,
each storing a few integers → well under the 256 MB limit.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    # columns: 0..3k-1  (L0..Lk-1, R0..Rk-1, K0..Kk-1)
    ncol = 3 * k
    rows = []                     # list of (left, right, key) 0‑based
    for _ in range(t):
        x = int(next(it)) - 1
        y = int(next(it)) - 1
        z = int(next(it)) - 1
        rows.append((x, y + k, z + 2 * k))

    # ---------- DLX structures ----------
    max_nodes = 3 * t + ncol + 1
    U = [0] * max_nodes
    D = [0] * max_nodes
    L = [0] * max_nodes
    R = [0] * max_nodes
    C = [0] * max_nodes          # column header for each node
    S = [0] * (ncol + 1)         # size of each column (header 0 unused)
    row_id = [0] * max_nodes     # which original row a node belongs to

    # header node 0, column headers 1..ncol
    for i in range(ncol + 1):
        U[i] = D[i] = i
        L[i] = i - 1
        R[i] = i + 1
    L[0] = ncol
    R[ncol] = 0

    node_cnt = ncol + 1  # next free index

    for r_idx, cols in enumerate(rows):
        first = -1
        for col in cols:
            node = node_cnt
            node_cnt += 1
            C[node] = col + 1          # column header index (1‑based)
            row_id[node] = r_idx

            # insert into column (at bottom)
            D[node] = C[col + 1]
            U[node] = U[C[col + 1]]
            D[U[node]] = node
            U[D[node]] = node
            S[col + 1] += 1

            # link row horizontally
            if first == -1:
                first = node
                L[node] = R[node] = node
            else:
                L[node] = L[first]
                R[node] = first
                R[L[first]] = node
                L[first] = node

    solution_rows = []

    def cover(col):
        # remove column header
        L[R[col]] = L[col]
        R[L[col]] = R[col]
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                S[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col):
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                S[C[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        L[R[col]] = col
        R[L[col]] = col

    sys.setrecursionlimit(10000)

    def search():
        if R[0] == 0:          # no columns left
            return True
        # choose column with minimal size
        c = R[0]
        min_s = S[c]
        col = c
        while c != 0:
            if S[c] < min_s:
                min_s = S[c]
                col = c
                if min_s == 0:
                    break
            c = R[c]
        if min_s == 0:
            return False

        cover(col)
        r = D[col]
        while r != col:
            solution_rows.append(row_id[r])
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            if search():
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            solution_rows.pop()
            r = D[r]
        uncover(col)
        return False

    if search():
        out = ["YES"]
        for idx in solution_rows:
            x, y, z = rows[idx]
            out.append(f"{x+1} {y - k +1} {z - 2*k +1}")
        sys.stdout.write("\n".join(out))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
