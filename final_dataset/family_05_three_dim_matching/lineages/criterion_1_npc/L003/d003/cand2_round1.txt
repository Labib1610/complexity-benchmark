<STATEMENT>
# Archway Assembly

Time limit: 5 s   Memory limit: 256 MB

## Description

A heritage site requires the reconstruction of a ruined colonnade. The completed structure must contain exactly **k** distinct arches.

Constructing one arch requires three specific elements: a left pillar, a right pillar, and a keystone. The archaeological dig has uncovered exactly **k** left pillars, **k** right pillars, and **k** keystones. Within each element type, the recovered stones are numbered from 1 to **k**.

Because of centuries of uneven weathering, these ancient stones cannot be combined at random. Structural engineers have physically tested the stones and documented a catalogue of stable configurations. An arch is structurally viable if and only if its exact triplet of (left pillar, right pillar, keystone) appears in this documented catalogue.

Your task is to assemble exactly **k** standalone arches. To do this, you must select **k** configurations from the engineers' catalogue so that every single left pillar, every single right pillar, and every single keystone is used in exactly one arch.

Given the number **k** and the catalogue of stable configurations, determine whether all the stones can be grouped to successfully reconstruct the entire colonnade. If it is possible, output the configurations used.

## Input

The first line provides two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k), representing the number of stones of each type and the total number of stable configurations in the catalogue, respectively.
The following **t** lines each contain three integers **x**, **y**, and **z** (1 ≤ x, y, z ≤ k). This indicates that left pillar **x**, right pillar **y**, and keystone **z** can be combined to form a stable arch. Every configuration in the catalogue is distinct.

## Output

If the stones can be successfully divided into **k** arches, print `YES` on the first line. On the next **k** lines, output three integers `x y z` per line, indicating the stones used for each reconstructed arch. Any valid grouping that uses each stone exactly once is acceptable. The reconstructed arches may be printed in any sequence.

If it is impossible to group all the stones into **k** arches, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both stable configurations require right pillar 1. Consequently, right pillar 2 cannot be used, making it impossible to construct 2 valid arches.
