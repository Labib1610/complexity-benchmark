**Solution Explanation**

For every left pillar `L₁ … L_k`, right pillar `R₁ … R_k` and keystone `K₁ … K_k`
we create one column in an exact‑cover matrix.
A catalog entry `(x , y , z)` becomes a row that contains the three columns

* `L_x`
* `R_y`
* `K_z`

Choosing a set of rows that covers every column exactly once is exactly the
required collection of `k` disjoint triples.

The problem is therefore an *exact cover* problem with  

* `3·k ≤ 66` columns  
* at most `k³ ≤ 10648` rows.

The classic algorithm for exact cover is **Algorithm X** with the
*Dancing Links* data structure (DLX).  
With the very small number of columns the recursive search finishes
instantly for the given limits.

--------------------------------------------------------------------

#### Algorithm
```
build DLX structure
    for each column create a header node
    for each triple (x,y,z) add a row node linked to the three columns

search()
    if all columns are covered          → solution found
    choose column c with the smallest size (fewest rows)
    for each row r that contains c
        add r to the partial solution
        cover all columns of r
        if search() succeeds → propagate success
        uncover all columns of r   (backtrack)
    return failure
```

The recursion depth never exceeds `k` because each chosen row covers three
previously uncovered columns, and we need exactly `k` rows.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs `YES` and a correct set of triples
iff such a set exists.

---

##### Lemma 1  
During the execution of `search` the set of uncovered columns is exactly the
set of pieces (left, right, keystone) that are not used by the rows already
chosen in the current partial solution.

**Proof.**  
Initially no column is covered, i.e. all pieces are unused.
When a row `r` is chosen, `cover` removes from the structure every column
contained in `r`. Those columns correspond precisely to the three pieces used
by `r`. No other columns are removed. The inverse operation `uncover`
restores them. By induction over the recursion depth the statement holds. ∎



##### Lemma 2  
If `search` reaches the line “all columns are covered”, the rows stored in the
partial solution form a set of `k` triples that uses every piece exactly once.

**Proof.**  
All columns are covered ⇒ every piece appears in at least one chosen row.
By Lemma&nbsp;1 a column can be covered only once, therefore exactly once.
Each row contains three distinct columns, i.e. three distinct pieces, so the
rows are pairwise disjoint. The number of rows equals the number of columns
divided by three, i.e. `3k / 3 = k`. ∎



##### Lemma 3  
If there exists a collection `S` of `k` admissible triples using every piece
exactly once, then `search` will eventually find a solution.

**Proof.**  
Consider the execution tree of `search`.  
At each recursive call a column `c` is selected.
Since `S` covers all columns, `c` belongs to exactly one row `r∈S`.
That row is present among the rows iterated in the loop for column `c`.
When the algorithm tries `r`, it covers all columns of `r`; the remaining
uncovered columns are exactly those covered by `S \ {r}` (Lemma&nbsp;1).
Thus the recursive call continues with a sub‑instance that still has a perfect
solution (`S \ {r}`). By induction on the number of remaining rows, the
recursive search will eventually choose all rows of `S` and succeed. ∎



##### Lemma 4  
If `search` returns failure, no collection of `k` admissible triples covering
all pieces exists.

**Proof.**  
Assume the contrary: a perfect collection `S` exists.
During the search, at the first node where the algorithm diverges from `S`,
it tries a row `r` that is **not** in `S`. After covering `r` the remaining
uncovered columns are a superset of those required by `S \ {r}`.
If the recursive call later fails, then by the induction hypothesis the
sub‑instance has no perfect cover, contradicting the existence of `S \ {r}`.
Hence the algorithm can never discard all possibilities before exploring the
branch that follows `S`. Therefore failure is impossible when a solution
exists. ∎



##### Theorem  
The program prints  

* `YES` and a list of `k` triples **iff** such a list exists,  
* otherwise prints `NO`.

**Proof.**  

*If the program prints `YES`.*  
It printed the rows stored when `search` terminated with all columns covered.
By Lemma&nbsp;2 these rows are a valid reconstruction.

*If a valid reconstruction exists.*  
By Lemma&nbsp;3 `search` will eventually find it, thus will terminate with
success and the program prints `YES`.

*If the program prints `NO`.*  
That happens only when `search` exhausts the whole search tree and returns
failure. By Lemma&nbsp;4 no perfect reconstruction exists. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Let `C = 3k ≤ 66` be the number of columns, `R = t ≤ 10648` the number of rows.*

Building the DLX structure: `O(C + 3R)`.

The exact‑cover search explores only a tiny fraction of the theoretical
`R!` possibilities; with the column‑size heuristic it is exponential in `k`
but `k ≤ 22`. In the worst case the algorithm may try all possibilities,
which is bounded by `O(R·k)` per recursion level, giving a very loose upper
bound `O(R·k·2^k)`. For the given limits this easily fits into the 5 s time
limit.

Memory consumption: one node per 1‑entry in the matrix → `3R` nodes,
each storing four integer links → well below the 256 MB limit
(≈ 3·10⁴ · 4 · 4 bytes ≈ 0.5 MB).

#### Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(1000000)

class DLXNode:
    __slots__ = ('left', 'right', 'up', 'down', 'col', 'row_id')
    def __init__(self):
        self.left = self.right = self.up = self.down = self
        self.col = None          # column header
        self.row_id = None       # identifier of the row (triple)

class ColumnNode(DLXNode):
    __slots__ = ('size', 'name')
    def __init__(self, name):
        super().__init__()
        self.size = 0
        self.name = name

class DLX:
    def __init__(self, n_cols):
        self.header = ColumnNode('header')
        self.cols = [ColumnNode(i) for i in range(n_cols)]
        # link column headers horizontally
        last = self.header
        for c in self.cols:
            c.left = last
            c.right = self.header
            last.right = c
            self.header.left = c
            last = c
        self.solution = []

    def add_row(self, row_id, columns):
        first = None
        for col_idx in columns:
            col = self.cols[col_idx]
            node = DLXNode()
            node.col = col
            node.row_id = row_id
            # vertical link
            node.up = col.up
            node.down = col
            col.up.down = node
            col.up = node
            col.size += 1
            # horizontal link
            if first is None:
                first = node
                node.left = node.right = node
            else:
                node.left = first.left
                node.right = first
                first.left.right = node
                first.left = node
        # nothing to return

    def cover(self, col):
        col.right.left = col.left
        col.left.right = col.right
        i = col.down
        while i != col:
            j = i.right
            while j != i:
                j.down.up = j.up
                j.up.down = j.down
                j.col.size -= 1
                j = j.right
            i = i.down

    def uncover(self, col):
        i = col.up
        while i != col:
            j = i.left
            while j != i:
                j.col.size += 1
                j.down.up = j
                j.up.down = j
                j = j.left
            i = i.up
        col.right.left = col
        col.left.right = col

    def search(self, k):
        if self.header.right == self.header:   # all columns covered
            return True
        # choose column with minimal size
        c = self.header.right
        min_sz = c.size
        col = c
        while c != self.header:
            if c.size < min_sz:
                min_sz = c.size
                col = c
                if min_sz == 0:
                    break
            c = c.right
        if min_sz == 0:
            return False
        self.cover(col)
        r = col.down
        while r != col:
            self.solution.append(r.row_id)
            j = r.right
            while j != r:
                self.cover(j.col)
                j = j.right
            if self.search(k):
                return True
            # backtrack
            j = r.left
            while j != r:
                self.uncover(j.col)
                j = j.left
            self.solution.pop()
            r = r.down
        self.uncover(col)
        return False

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))
    triples = []
    for _ in range(t):
        x = int(next(it)) - 1
        y = int(next(it)) - 1
        z = int(next(it)) - 1
        triples.append((x, y, z))

    n_cols = 3 * k
    dlx = DLX(n_cols)
    for idx, (x, y, z) in enumerate(triples):
        dlx.add_row(idx, [x, k + y, 2 * k + z])

    if dlx.search(k):
        out = ['YES']
        for idx in dlx.solution:
            x, y, z = triples[idx]
            out.append(f"{x+1} {y+1} {z+1}")
        sys.stdout.write('\n'.join(out))
    else:
        sys.stdout.write('NO')

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
