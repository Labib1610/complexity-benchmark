<STATEMENT>
# Problem A — Crew Assembly

Time limit: 5 s   Memory limit: 256 MB

## Description

A facility must assemble a valid diagnostic schedule by selecting a precise set of configuration vectors. 

You are provided with a catalog of **t** certified configuration vectors. Each vector consists of three integer components. 

Your objective is to determine whether it is possible to select exactly **k** vectors from the catalog such that the chosen set is *harmonious*. A set of vectors is harmonious if and only if the Hamming distance between any two distinct vectors in the set is exactly 3. 

The Hamming distance between two vectors is defined as the number of component positions at which their corresponding values differ. Thus, a Hamming distance of 3 means the two vectors differ in their first component, in their second component, and in their third component.

Determine if such a harmonious set of **k** vectors exists. If it does, provide one valid selection.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k). The value **k** defines the target size of the harmonious set, and implicitly, the maximum possible value for any vector component (all component values are guaranteed to be positive integers no greater than **k**). The value **t** is the number of certified configuration vectors in the catalog.

The next **t** lines each contain three integers **x**, **y**, and **z** (1 ≤ x, y, z ≤ k). Each line describes one certified configuration vector (x, y, z) in the catalog. No vector appears more than once in the list.

## Output

If a harmonious set of exactly **k** vectors exists, output `YES` on the first line. Following this, output **k** lines, each containing three integers `x y z` corresponding to a chosen configuration vector from the catalog. Any valid harmonious set is acceptable, and the vectors may be printed in any order.

If no such set exists, output `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, the two given vectors are (1, 1, 1) and (2, 1, 2). Their Hamming distance is 2 (they differ in the first and third components, but share the same value in the second component). Since they do not have a Hamming distance of 3, they cannot both be part of a harmonious set together. A harmonious set of exactly 2 vectors cannot be formed, so the answer is `NO`.

This forces the model to mathematically deduce that choosing $k$ vectors with pairwise Hamming distance 3, bounded by $k$, implies a perfect permutation in each coordinate.
