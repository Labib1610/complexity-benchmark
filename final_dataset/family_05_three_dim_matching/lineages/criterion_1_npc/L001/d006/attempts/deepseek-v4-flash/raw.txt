We need to select exactly k triples from the given list such that no two selected triples share any coordinate value.

This is essentially finding a perfect matching in a 3-partite 3-uniform hypergraph, which can be solved via maximum bipartite matching after reducing the problem.

Here’s the approach:

1. We have k possible values for each of the three coordinates.
2. We need to pick k triples such that each value in each coordinate is used exactly once.
3. This is equivalent to finding a perfect matching in a bipartite graph where:
   - Left side: all possible (x, y) pairs (k² nodes)
   - Right side: all possible z values (k nodes)
   - Edge exists if (x, y, z) is in the catalog.
4. We need to match each (x, y) pair to a distinct z, but we only need k matches total, and each x and y must be used exactly once.

A simpler reduction:  
We can model it as a bipartite matching between:
- Left: all possible x values (k nodes)
- Right: all possible (y, z) pairs (k² nodes)
- Edge if (x, y, z) exists.

We need a perfect matching of size k, where each x is matched to a distinct (y, z) pair, and each y and z appear exactly once.

This is a 3D matching problem, which is NP-hard in general, but since k ≤ 22, we can use backtracking with pruning.

Given the constraints (k ≤ 22, t ≤ k³), we can do a DFS with bitmask pruning.

Let’s implement a backtracking solution:

- Represent each triple as (a, b, c).
- We’ll try to assign for each a (frequency multiplier) a distinct b and c.
- Use bitmasks for used b and used c.
- Sort triples to improve pruning.

Here’s the code:

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    k = int(input_data[0])
    t = int(input_data[1])
    triples = []
    idx = 2
    for _ in range(t):
        a = int(input_data[idx]); b = int(input_data[idx+1]); c = int(input_data[idx+2])
        idx += 3
        triples.append((a, b, c))
    
    # Group triples by a
    by_a = [[] for _ in range(k+1)]
    for a, b, c in triples:
        by_a[a].append((b, c))
    
    # Sort each group for deterministic order
    for i in range(1, k+1):
        by_a[i].sort()
    
    used_b = 0
    used_c = 0
    chosen = []
    
    # Backtracking
    def dfs(a):
        nonlocal used_b, used_c
        if a > k:
            return len(chosen) == k
        # Try to pick a triple for this a
        for b, c in by_a[a]:
            if not (used_b & (1 << (b-1))) and not (used_c & (1 << (c-1))):
                used_b |= (1 << (b-1))
                used_c |= (1 << (c-1))
                chosen.append((a, b, c))
                if dfs(a+1):
                    return True
                chosen.pop()
                used_b ^= (1 << (b-1))
                used_c ^= (1 << (c-1))
        # Also possible to skip this a (if we don't need to use all a values)
        # But we need exactly k triples, and there are k possible a values.
        # Since we need exactly k triples and each a can be used at most once,
        # we must use all a values 1..k exactly once.
        # So no skip.
        return False
    
    if dfs(1):
        print("YES")
        for a, b, c in chosen:
            print(a, b, c)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
