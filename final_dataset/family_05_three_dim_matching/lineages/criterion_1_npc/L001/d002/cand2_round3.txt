# Problem A — Tripartite Roster

Time limit: 5 s   Memory limit: 256 MB

## Description

An operation requires coordinating three distinct pools of resources. Each pool contains exactly **k** elements:
- Pool A (Specialists), identified by integers 1 through k,
- Pool B (Machines), identified by integers 1 through k,
- Pool C (Time slots), identified by integers 1 through k.

A deployment unit is formed by selecting a triplet consisting of exactly one element from Pool A, one element from Pool B, and one element from Pool C. You will receive a catalog of authorized triplets. Only triplets present in this catalog may be selected.

Your task is to determine if a valid operational roster can be formed. A valid roster must consist of exactly **k** authorized triplets chosen from the catalog. To be valid, the roster must satisfy the following condition: for each integer *i* from 1 to *k*, element *i* of Pool A must appear in exactly one chosen triplet, element *i* of Pool B must appear in exactly one chosen triplet, and element *i* of Pool C must appear in exactly one chosen triplet.

If such a roster exists, you must provide any one valid set of **k** triplets.

## Input

The first line provides two integers **k** and **t**. The pool size **k** is a positive integer that cannot exceed the 22 available operational sectors. The catalog size **t** is a non-negative integer that cannot exceed the total number of all possible combinations of taking one element from each pool.

The following **t** lines each contain three integers **x**, **y**, and **z**, describing an authorized triplet consisting of element **x** from Pool A, element **y** from Pool B, and element **z** from Pool C. The identifiers **x**, **y**, and **z** are positive integers that cannot exceed the pool size **k**. No triplet appears more than once in the catalog.

## Output

If a valid roster of **k** triplets can be formulated, output `YES` on the first line. Following this, output **k** lines, each containing three integers `x y z` corresponding to a chosen triplet from the catalog. You may print the chosen triplets in any order. Any valid roster that satisfies the condition is acceptable.

If no such roster can be formulated, output `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both authorized triplets require element 1 from Pool B, meaning element 2 from Pool B can never be utilized in the roster. Thus, no valid roster can be formed.
