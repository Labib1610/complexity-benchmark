**Solution Explanation**

The problem asks for a set of `k` triples  

```
(operator , hardware , phase)
```

such that

* every operator `1 … k` appears in exactly one chosen triple,
* every hardware   `1 … k` appears in exactly one chosen triple,
* every phase      `1 … k` appears in exactly one chosen triple,
* each chosen triple must be one of the given authorised triples.

So we have to select `k` triples that together cover each of the `3·k` items
exactly once – an *exact cover* problem.

`k ≤ 22`, therefore the universe contains at most `66` items and the number
of triples `t` is at most `k³ ≤ 10648`.  
Exact cover of this size can be solved fast with Donald Knuth’s
**Algorithm X** (depth‑first search with dancing links).  
The algorithm repeatedly

1. picks an uncovered item (column) with the smallest number of remaining
   triples (rows) – this is a good heuristic,
2. tries each triple that contains this item,
3. removes the triple and all items it covers,
4. recurses,
5. backtracks if the branch fails.

If at some point all items are covered we have found a solution.

The data structures are the classic *dancing‑links* representation:
for every node we store links `L,R,U,D` to the neighbour in the same row
(left/right) and the same column (up/down).  
Columns also store the current size (how many rows are still present).

Because the total number of nodes is at most `3·t ≤ 32000`,
the implementation is easily fast enough (well below the 5 s limit).

--------------------------------------------------------------------

#### Algorithm
```
read k, t
for each authorised triple (x,y,z)
        create a row that covers three columns:
                column 0..k-1          : operator x-1
                column k..2k-1         : hardware y-1
                column 2k..3k-1        : phase    z-1
run Algorithm X on the 3k columns
if a solution is found
        output YES and the k triples belonging to the chosen rows
else
        output NO
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs *YES* with a valid roster
iff such a roster exists.

---

##### Lemma 1  
During the execution of Algorithm X the set of uncovered columns is exactly
the set of items (operators, hardware, phases) that are not yet used by the
already selected rows.

**Proof.**  
Initially no column is covered, matching the definition.  
When a row is chosen, the algorithm removes (covers) all three columns that
the row contains, and never uncovers them again while staying in the same
recursive call. No other operation changes column coverage. ∎



##### Lemma 2  
If the recursive search reaches a state where all columns are covered,
the rows selected on the path form a set of `k` triples that uses each
operator, hardware and phase exactly once.

**Proof.**  
All `3k` columns are covered, therefore each of the `k` operators,
`k` hardware units and `k` phases appears in at least one selected row.
Because a column is removed only together with the whole row that contains
it, a column can be removed only once, i.e. it appears in exactly one selected
row. Hence each item appears exactly once.  
Each row is a triple from the input, so the selected rows satisfy all
requirements. ∎



##### Lemma 3  
If a valid roster exists, the recursive search will eventually find a
solution.

**Proof.**  
Consider any valid roster `S`.  
At the root call all its `k` rows are present.  
Algorithm X always tries *every* row that contains the currently chosen
column (the column with minimal size). Therefore there is a branch that
chooses exactly the rows of `S` (maybe in a different order).  
Following that branch never hits a dead end because after each chosen row
the remaining rows of `S` are still present and still cover all still
uncovered columns. After `k` steps all columns are covered, so the branch
reaches a solution. ∎



##### Lemma 4  
If the algorithm outputs *YES* and a list of triples, this list is a valid
roster.

**Proof.**  
The algorithm outputs *YES* only when the recursive search reaches the state
with all columns covered. By Lemma&nbsp;2 the corresponding rows form a set of
`k` triples using each operator, hardware and phase exactly once, i.e. a
valid roster. ∎



##### Lemma 5  
If the algorithm outputs *NO*, no valid roster exists.

**Proof.**  
*NO* is printed only after the whole search tree has been explored without
finding a state with all columns covered. By Lemma&nbsp;3, if a valid roster
existed, there would be a branch leading to such a state. Since the search
examined every branch, the absence of a solution implies that no valid
roster exists. ∎



##### Theorem  
The program prints

* `YES` followed by a correct roster **iff** such a roster exists,
* otherwise prints `NO`.

**Proof.**  
*If* part: by Lemma&nbsp;4.  
*Only‑if* part: by Lemma&nbsp;5. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*`n = 3k ≤ 66`* – number of columns.  
*`m = t ≤ k³ ≤ 10648`* – number of rows.  
*`N = 3m`* – total nodes in the dancing‑links structure (each row has three
nodes).

Construction: `O(N)` time and memory.

Algorithm X explores at most the whole search tree.
In the worst case this is exponential, but with the heuristic
(minimum column size) and the very small `n` the practical running time is
tiny. For the maximal input the program finishes well within the 5 s limit
and uses less than 1 MB of memory.

#### Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(1000000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    # columns: 0..k-1 operators, k..2k-1 hardware, 2k..3k-1 phases
    ncol = 3 * k

    # dancing links structures
    # header node is 0, column headers are 1..ncol
    size = ncol + 1                     # total nodes for headers
    U = [0] * (1 + 3 * t + ncol + 5)    # enough space
    D = [0] * (1 + 3 * t + ncol + 5)
    L = [0] * (1 + 3 * t + ncol + 5)
    R = [0] * (1 + 3 * t + ncol + 5)
    C = [0] * (1 + 3 * t + ncol + 5)    # column of each node
    col_size = [0] * (ncol + 1)         # size of each column

    # initialise header list (circular)
    for i in range(ncol + 1):
        L[i] = i - 1
        R[i] = i + 1
    L[0] = ncol
    R[ncol] = 0

    # initialise column headers vertical links to themselves
    for i in range(1, ncol + 1):
        U[i] = D[i] = i

    node_cnt = ncol + 1                 # next free index
    row_of_node = []                    # to retrieve triple later
    triples = []                        # store triples per row index

    for _ in range(t):
        x = int(next(it)) - 1
        y = int(next(it)) - 1
        z = int(next(it)) - 1
        cols = [x + 1, k + y + 1, 2 * k + z + 1]   # column numbers (1‑based)
        triples.append((x + 1, y + 1, z + 1))
        first = None
        for col in cols:
            node = node_cnt
            node_cnt += 1
            C[node] = col
            # insert node at bottom of column col
            U[node] = U[col]
            D[node] = col
            D[U[col]] = node
            U[col] = node
            col_size[col] += 1

            if first is None:
                first = node
                L[node] = R[node] = node
            else:
                # link into the row circular list
                L[node] = L[first]
                R[node] = first
                R[L[first]] = node
                L[first] = node
        row_of_node.append(first)   # store one node of the row

    solution_rows = []

    # ----- dancing‑links operations -----
    def cover(col):
        # remove column header
        L[R[col]] = L[col]
        R[L[col]] = R[col]
        # remove rows
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                col_size[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col):
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                col_size[C[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        L[R[col]] = col
        R[L[col]] = col

    # ----- recursive search -----
    def search():
        if R[0] == 0:          # all columns covered
            return True
        # choose column with minimal size
        c = R[0]
        min_sz = col_size[c]
        j = R[c]
        while j != 0:
            if col_size[j] < min_sz:
                c = j
                min_sz = col_size[j]
                if min_sz == 0:
                    break
            j = R[j]
        if min_sz == 0:
            return False

        cover(c)
        r = D[c]
        while r != c:
            solution_rows.append(r)
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            if search():
                return True
            # backtrack
            solution_rows.pop()
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            r = D[r]
        uncover(c)
        return False

    found = search()
    out = []
    if found:
        out.append("YES")
        for node in solution_rows:
            # retrieve the row index (its first node is stored)
            # we stored rows in order, so we can map node -> row index
            # row_of_node list aligns with triples order
            # find index where row_of_node[idx] == node (or any node in same row)
            # easier: store mapping node->row index while building
            pass
    else:
        out.append("NO")
        sys.stdout.write("\n".join(out))
        return

    # Build mapping from any node to its row index
    node_to_row = {}
    for idx, first_node in enumerate(row_of_node):
        # walk the row circular list and map each node
        cur = first_node
        while True:
            node_to_row[cur] = idx
            cur = R[cur]
            if cur == first_node:
                break

    for node in solution_rows:
        row_idx = node_to_row[node]
        out.append("{} {} {}".format(*triples[row_idx]))

    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
