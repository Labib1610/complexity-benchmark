<STATEMENT>
# Problem A — Network Alignment

Time limit: 5 s   Memory limit: 256 MB

## Description

An experimental network consists of three distinct sets of nodes. Each set contains exactly **k** nodes:
- Red nodes, labeled 1 through k,
- Green nodes, labeled 1 through k,
- Blue nodes, labeled 1 through k.

A triplet connection links exactly one Red node, one Green node, and one Blue node. You are provided with a list of **t** feasible triplet connections that can be activated.

Your task is to select exactly **k** triplet connections from the given list to form a complete network alignment. A valid alignment must ensure that each of the 3k nodes in the network is part of exactly one of the chosen triplet connections.

Determine if such a selection exists. If it does, output the chosen triplet connections.

## Input

The first line provides two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k), representing the size of each node set and the total number of feasible triplet connections.
The following **t** lines each contain three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), describing a feasible triplet connection linking Red node **x**, Green node **y**, and Blue node **z**. No triplet connection appears more than once in the list.

## Output

If a valid selection of **k** triplet connections can be found, output `YES` on the first line. Following this, output **k** lines, each containing three integers `x y z` corresponding to a chosen triplet connection. Any valid selection that perfectly aligns the nodes is acceptable. The triplet connections may be printed in any order.

If no such selection can be found, output `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both feasible triplet connections link to Green node 1, meaning Green node 2 can never be included in any selection of **k** triplet connections.

<RATIONALE>
The previous wording used "time slot," which provided a strong conceptual affordance for models to group by time and iterate linearly, framing the problem as a sequence of independent choices. By replacing the resource pools with three symmetric sets of nodes (Red, Green, Blue) and asking for a "complete network alignment," the sequential "time" intuition is removed. The model must now deduce the symmetric constraints of the 3-dimensional matching problem without relying on the temporal heuristic. Exact inequality bounds were restored to ensure the automated checker recognizes them.
</RATIONALE>
