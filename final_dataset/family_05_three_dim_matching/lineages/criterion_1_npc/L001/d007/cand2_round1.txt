<METHOD_NAME>Algebraic Independence Obfuscation (Vandermonde Systems)</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the pairwise distinctness constraint of a 3-Dimensional Matching problem with an equivalent algebraic condition: requiring that a system of equations formed by the powers of the selected parameters has a unique solution. Because the coefficient matrix is a Vandermonde matrix multiplied by a diagonal matrix of the parameters, its determinant is non-zero if and only if all parameters are distinct. This forces the model to perform genuine mathematical deduction to recover the discrete combinatorial structure; models that rely on surface pattern matching will likely attempt to implement numerical solvers or brute-force matrix rank checks, which will fail the time limit.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Polynomial Interference

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing a complex signal processing network. The network operates on a fundamental dimension **k**.

You are provided with a catalog of **t** available filter models. Each filter model is manufactured with three specific integer parameters: an alpha-coefficient, a beta-coefficient, and a gamma-coefficient. For every available model, these three parameters are integers between 1 and **k** inclusive.

Your task is to determine whether it is possible to select exactly **k** filter models from the catalog to form a stable configuration. 

A configuration of **k** models is considered *stable* if and only if, when the selected models are assigned indices $i = 1, 2, \dots, k$ in any arbitrary order, they satisfy all three of the following algebraic independence conditions:

1. Let the alpha-coefficient of the $i$-th selected model be $a_i$. The system of **k** linear equations in **k** real variables $U_1, U_2, \dots, U_k$, where the $i$-th equation is:
   $U_1 \cdot (a_i)^1 + U_2 \cdot (a_i)^2 + \dots + U_k \cdot (a_i)^k = i$
   must have exactly one unique solution.

2. Let the beta-coefficient of the $i$-th selected model be $b_i$. The system of **k** linear equations in **k** real variables $V_1, V_2, \dots, V_k$, where the $i$-th equation is:
   $V_1 \cdot (b_i)^1 + V_2 \cdot (b_i)^2 + \dots + V_k \cdot (b_i)^k = i$
   must have exactly one unique solution.

3. Let the gamma-coefficient of the $i$-th selected model be $c_i$. The system of **k** linear equations in **k** real variables $W_1, W_2, \dots, W_k$, where the $i$-th equation is:
   $W_1 \cdot (c_i)^1 + W_2 \cdot (c_i)^2 + \dots + W_k \cdot (c_i)^k = i$
   must have exactly one unique solution.

## Input

The first line specifies the network dimension **k** and the catalog size **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k).

The following **t** lines each contain three integers representing the alpha, beta, and gamma coefficients of a filter model. All parameter values are between 1 and **k**. No two filter models in the catalog have the exact same combination of all three parameters.

## Output

If a stable configuration of exactly **k** filters is possible, print `YES` on the first line. Following this, print **k** lines, each containing the three parameters of an installed filter model. If multiple valid configurations exist, any of them is acceptable, and the models may be printed in any order.

If no such configuration is possible, print `NO`.

## Note

In Example 2, the network dimension **k** is 2, so exactly 2 models must be selected. There are only two available models in the catalog, so both must be chosen. The first model has parameters (1, 1, 1) and the second has parameters (2, 1, 2). 

Let's check the stability condition for the beta-coefficients (the second parameter). The selected beta-coefficients are $b_1 = 1$ and $b_2 = 1$. The second system of equations becomes:
$V_1 \cdot (1)^1 + V_2 \cdot (1)^2 = 1 \implies V_1 + V_2 = 1$
$V_1 \cdot (1)^1 + V_2 \cdot (1)^2 = 2 \implies V_1 + V_2 = 2$

This system of equations is contradictory and has no solution. Because it does not have exactly one unique solution, this configuration is not stable. Therefore, a successful configuration is impossible.
</STATEMENT>
<RATIONALE>
I completely replaced the domain with an algebraic constraint based on systems of linear equations. By requiring that the Vandermonde-like coefficient matrices of the selected parameters have exactly one unique solution, the problem implicitly demands that all selected parameters be distinct, forcing the model to mathematically deduce the exact cover structure rather than pattern-matching on sets.
</RATIONALE>
<PRESERVED_ANSWER>
The Vandermonde-like matrix determinant is non-zero if and only if all generating parameters are strictly distinct; since exactly k parameters are chosen from the range 1 to k, this mathematically guarantees they form a permutation of 1 to k, making the constraint identical to the original pairwise distinctness requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching, which is NP-complete, as the algebraic condition is just a mathematically equivalent way of stating that the three parameter sets must each be a permutation of 1 to k.
</PRESERVED_CLASS>
