<METHOD_NAME>Algebraic Power Sums Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit pairwise distinctness condition with an equivalent system of power sum equations. By requiring the sum of the j-th powers of the selected parameters to equal the sum of the j-th powers of the integers 1 to k, it mathematically forces each parameter set to be a permutation of 1..k (via Newton's identities). This defeats models that rely on direct text matching for exact cover / 3-dimensional matching, as they fail to recognize the algebraic equivalence and cannot solve the equations directly.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Spectral Interference

Time limit: 5 s   Memory limit: 256 MB

## Description

You are configuring a spectral signal processing network. The network operates at a fundamental resolution **k**.

You are provided with a catalog of **t** available filter models. Each filter model is manufactured with three specific integer parameters: a frequency multiplier $\alpha$, a phase shift $\beta$, and an amplitude scale $\gamma$. For every available model, these three parameters satisfy $1 \le \alpha \le k$, $1 \le \beta \le k$, and $1 \le \gamma \le k$. No two filter models in the catalog have the exact same combination of all three parameters.

Your task is to determine whether it is possible to select exactly **k** filter models from the catalog to install into the network such that they achieve perfect spectral stability. 

A selection of exactly **k** filter models achieves perfect spectral stability if, after selecting the **k** models, you can fix an arbitrary ordering of them as $i=1,\dots,k$ (where the $i$-th model has parameters $\alpha_i, \beta_i, \gamma_i$) such that the following three systems of equations are simultaneously satisfied for every integer $j$ from $1$ to $k$:

1. $\sum_{i=1}^k \alpha_i^j = \sum_{i=1}^k i^j$
2. $\sum_{i=1}^k \beta_i^j = \sum_{i=1}^k i^j$
3. $\sum_{i=1}^k \gamma_i^j = \sum_{i=1}^k i^j$

## Input

The first line specifies the resolution **k** and the catalog size **t** ($1 \le k \le 22$, $0 \le t \le k \cdot k \cdot k$).

The following **t** lines each contain three integers representing the frequency multiplier $\alpha$, phase shift $\beta$, and amplitude scale $\gamma$ of a filter model. All parameter values are between $1$ and **k** inclusive. No two filter models in the catalog have the exact same combination of all three parameters.

## Output

If a successful installation of exactly **k** filters is possible, print `YES` on the first line. Following this, print **k** lines, each containing the three parameters $\alpha, \beta, \gamma$ of an installed filter model. If multiple valid installations exist, any of them is acceptable, and the models may be printed in any order.

If no such installation is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, the resolution **k** is 2, so exactly 2 models must be installed. There are only two available models in the catalog, so both must be selected. The first model has parameters $\alpha_1=1, \beta_1=1, \gamma_1=1$ and the second has parameters $\alpha_2=2, \beta_2=1, \gamma_2=2$. Evaluating the second system of equations for $j=1$, we get $\beta_1^1 + \beta_2^1 = 1 + 1 = 2$. However, the right side requires $\sum_{i=1}^2 i^1 = 1 + 2 = 3$. Since $2 \neq 3$, the system is not satisfied, and therefore a successful installation is impossible.
</STATEMENT>
<RATIONALE>
The problem replaces the explicit requirement that selected models must have distinct parameters in all three coordinates with an equivalent mathematical formulation using power sums. By Newton's identities, the power sum equations force the chosen parameters to be exactly a permutation of 1 to k, safely replicating the 3-Dimensional Matching constraints without using recognizable exact cover language.
</RATIONALE>
<PRESERVED_ANSWER>
The power sum equations uniquely determine the multiset of values for each parameter to be exactly {1, ..., k}, which is mathematically identical to requiring exactly k items with pairwise distinct coordinates in every dimension.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching (NP-complete), as finding a set of k triples satisfying the power sum equations is structurally identical to finding a perfect 3D matching.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the power sum equations as a numeric requirement to be computed with large integers, failing to recognize the permutation equivalence and thus failing to implement the backtracking search correctly.
</RISK>
