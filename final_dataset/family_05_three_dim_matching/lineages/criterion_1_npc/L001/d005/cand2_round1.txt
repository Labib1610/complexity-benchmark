# Problem A — Orbital Constellation

Time limit: 5 s   Memory limit: 256 MB

## Description

You are planning a satellite constellation in a complex planetary system. You have a list of **t** viable orbital slots. Each slot is defined by three orbital parameters: altitude index **a**, inclination index **i**, and eccentricity index **e**. All parameter indices are integers ranging from 1 to **k**.

Your objective is to select exactly **k** orbital slots from the provided list to deploy your satellites. 

To ensure the constellation is safe from any single-axis cascading collisions, any two selected orbital slots $S_1 = (a_1, i_1, e_1)$ and $S_2 = (a_2, i_2, e_2)$ must have a strictly positive separation volume. The separation volume between two slots is calculated as:
$V(S_1, S_2) = |a_1 - a_2| \times |i_1 - i_2| \times |e_1 - e_2|$

A constellation is valid if and only if $V(S_1, S_2) > 0$ for all pairs of distinct selected slots.

Determine if a valid constellation of exactly **k** slots can be formed from the given list. If it is possible, provide the parameters of the **k** chosen slots.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k). Here, **k** determines the upper bound for the orbital parameters, and **t** is the number of viable orbital slots available.

The next **t** lines each contain three integers **a**, **i**, **e** (1 ≤ a, i, e ≤ k). Each line describes the parameters of a viable orbital slot. No slot appears more than once in the list.

## Output

If a valid constellation of exactly **k** slots exists, output `YES` on the first line. Following this, output **k** lines, each containing three integers `a i e` corresponding to a chosen orbital slot. Any valid constellation is acceptable, and the chosen slots may be printed in any order.

If no such constellation exists, output `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both viable slots share an inclination index of 1. If both are selected to form a constellation of exactly 2 slots, their separation volume is:
$V = |1 - 2| \times |1 - 1| \times |1 - 2| = 1 \times 0 \times 1 = 0$.
Because the separation volume is not strictly positive, this pair cannot be part of a valid constellation.

<RATIONALE>
I removed the explicit exact-cover phrasing ("no two share the same coordinate") and replaced it with a pairwise algebraic constraint ($V(S_1, S_2) > 0$). Models that pattern-match on the surface will perceive this as a generic Maximum Clique or Subgraph problem and likely implement a standard clique-finding algorithm, which will Time Out on up to 10,648 vertices. Models that genuinely reason will deduce that the algebraic constraint on bounded integers implies each parameter must be a permutation, thereby recovering the Exact Cover structure and applying the necessary pruning to pass.
</RATIONALE>
