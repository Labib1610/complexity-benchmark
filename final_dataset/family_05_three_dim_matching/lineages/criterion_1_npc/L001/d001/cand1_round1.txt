# Problem A — Roster Assignment

Time limit: 5 s   Memory limit: 256 MB

## Description

A critical facility requires a perfect roster assignment. The facility has:
- exactly **k** personnel, numbered 1 to **k**,
- exactly **k** workstations, numbered 1 to **k**,
- exactly **k** shifts, numbered 1 to **k**.

A roster assignment is formed by selecting combinations of one person, one workstation, and one shift. You are provided with a list of certified combinations `(x, y, z)`. In this adversarial scenario, the list of certified combinations is often structured and ordered to defeat greedy choices and force worst-case assignment conflicts.

A valid complete roster must consist of exactly **k** certified combinations such that every person, every workstation, and every shift appears in **exactly one** chosen combination. 

Determine whether assembling such a complete roster is possible under these conditions, and if so report one valid set of combinations.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the number of entities in each group and the total number of certified combinations.
Each of the next **t** lines contains three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing a certified combination. No combination is listed more than once.

## Output

If a valid complete roster of **k** combinations exists, print `YES` on the first line, then print **k** lines, each containing the three members `x y z` of one chosen combination. Any complete roster in which every person, workstation, and shift is used exactly once is accepted; the combinations may be printed in any order.

If no valid complete roster exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both certified combinations require workstation 1, so workstation 2 can never be utilized.
