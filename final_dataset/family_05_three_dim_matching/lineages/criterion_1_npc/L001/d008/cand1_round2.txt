# Problem A — Holographic Projections

Time limit: 5 s   Memory limit: 256 MB

## Description

You are calibrating a holographic display system that operates at a resolution level **k**. 
The system can be configured by illuminating specific voxels. You are given a catalog of **t** available voxels, each defined by a coordinate triplet $(x, y, z)$.

To form a stable image, you must select exactly **k** voxels from this catalog. Let $V$ be your chosen set of **k** voxels. 
The system evaluates the spatial distribution of $V$ by calculating its footprint across the three primary axes:
- Let $X(V)$ be the set of all $x$-coordinates of the voxels in $V$.
- Let $Y(V)$ be the set of all $y$-coordinates of the voxels in $V$.
- Let $Z(V)$ be the set of all $z$-coordinates of the voxels in $V$.

The *dispersion metric* of your selection is defined as the sum of the cardinalities of these three sets: $|X(V)| + |Y(V)| + |Z(V)|$.

Your task is to determine whether it is possible to select exactly **k** voxels from the catalog such that their dispersion metric is exactly **3k**.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k), representing the resolution level and the number of available voxels.

The following **t** lines each contain three positive integers $x, y, z$ representing the coordinates of an available voxel. It is guaranteed that no coordinate in the input is strictly greater than **k** (i.e., $1 \le x, y, z \le k$). No two voxels in the catalog have the exact same combination of all three coordinates.

## Output

If it is possible to select exactly **k** voxels that achieve a dispersion metric of **3k**, print `YES` on the first line. Following this, print **k** lines, each containing the $(x, y, z)$ coordinates of a selected voxel. If there are multiple valid selections, any of them is acceptable, and the voxels may be printed in any order.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, the resolution level **k** is 2, meaning exactly 2 voxels must be chosen. There are only two available voxels in the catalog, so both must be selected: $V = \{(1, 1, 1), (2, 1, 2)\}$.
- The set of $x$-coordinates is $X(V) = \{1, 2\}$, so $|X(V)| = 2$.
- The set of $y$-coordinates is $Y(V) = \{1\}$, so $|Y(V)| = 1$.
- The set of $z$-coordinates is $Z(V) = \{1, 2\}$, so $|Z(V)| = 2$.
The dispersion metric is $|X(V)| + |Y(V)| + |Z(V)| = 2 + 1 + 2 = 5$. Because the metric is not equal to **3k** (which would be 6), this selection is invalid. No valid selection exists, so the output is `NO`.
