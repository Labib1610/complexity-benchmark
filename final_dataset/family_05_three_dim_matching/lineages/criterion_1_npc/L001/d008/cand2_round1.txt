<METHOD_NAME>
Cumulative-Frequency-Equivalence
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the Exact Cover requirement ("all chosen values must be distinct") with a mathematically equivalent condition on the cumulative frequency distribution: demanding that exactly k-x+1 chosen elements are >= x for all x in 1..k. Because elements are bounded by k, this mathematically forces exactly one of each value to be present. Models relying on surface pattern-matching will fail to recognize the exact cover structure, implement the condition literally without pruning the search space, and fail via Time Limit Exceeded.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<STATEMENT>
# Problem A — Signal Penetration Profile

Time limit: 5 s   Memory limit: 256 MB

## Description

You are designing a communication network for a newly established colony. The network requires exactly **k** transmission towers to be active.

You have a catalog of **t** available tower configurations. Each configuration is manufactured to operate on three specific frequency bands: the alpha band, the beta band, and the gamma band.

The regulatory board enforces a strict "penetration profile" for the network to ensure even coverage without interference. Once you select exactly **k** tower configurations from the catalog, you must verify their compliance. 

For every integer threshold **x** from 1 to **k** (inclusive), your selection of **k** towers must satisfy the following three conditions:
1. The number of chosen towers operating with an alpha band greater than or equal to **x** must be exactly **k** - **x** + 1.
2. The number of chosen towers operating with a beta band greater than or equal to **x** must be exactly **k** - **x** + 1.
3. The number of chosen towers operating with a gamma band greater than or equal to **x** must be exactly **k** - **x** + 1.

If all three conditions hold for every threshold **x** from 1 to **k**, the network is compliant.

Your task is to determine whether it is possible to select exactly **k** tower configurations from the catalog such that the resulting network is compliant.

## Input

The first line specifies the required number of towers **k** and the catalog size **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k).

The following **t** lines each contain three positive integers representing the alpha, beta, and gamma bands of an available tower configuration. You are guaranteed that no frequency band in the input is strictly greater than **k**. No two configurations in the catalog have the exact same combination of all three bands.

## Output

If a compliant network of exactly **k** towers can be formed, print `YES` on the first line. Following this, print **k** lines, each containing the three frequency bands of a chosen tower configuration. If multiple valid networks exist, any of them is acceptable, and the configurations may be printed in any order.

If no such network is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, exactly **k** = 2 towers must be selected. The catalog only contains two configurations, so both must be selected: (1, 1, 1) and (2, 1, 2). 

Let us check the penetration profile for the threshold **x** = 2:
- The alpha bands of the chosen towers are 1 and 2. The number of chosen towers with an alpha band ≥ 2 is 1. The required count is **k** - **x** + 1 = 2 - 2 + 1 = 1. This matches.
- The beta bands of the chosen towers are 1 and 1. The number of chosen towers with a beta band ≥ 2 is 0. The required count is **k** - **x** + 1 = 2 - 2 + 1 = 1. This does not match (0 ≠ 1).

Because the beta bands fail the profile requirement for threshold **x** = 2, the network is not compliant. Therefore, a compliant network is impossible to form.
</STATEMENT>
<RATIONALE>
I completely removed all language related to uniqueness, distinct values, or exact covers. Instead, I introduced a mathematically equivalent condition based on cumulative frequencies. To pass within the time limit, a model must deduce that the cumulative condition is just a disguised way of mandating exactly one of each value from 1 to k, and use that insight to prune its backtracking search. Models relying on surface pattern matching will fail to recognize the exact cover structure and will write a naive search that times out.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that exactly k - x + 1 elements are >= x for all x in 1..k mathematically forces a multiset of size k with elements bounded by k to be exactly the set {1, 2, ..., k}, meaning the constraint is strictly identical to requiring k distinct values.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Because the cumulative frequency condition is logically identical to the original exact cover requirement for every valid input, the problem remains structurally identical to 3-Dimensional Matching and stays NP-complete.
</PRESERVED_CLASS>
