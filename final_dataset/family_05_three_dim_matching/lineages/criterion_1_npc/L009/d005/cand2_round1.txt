# Problem A — Dimensional Resonance Array

Time limit: 5 s   Memory limit: 256 MB

## Description

A quantum communications array processes data streams across three distinct properties:
- **k** frequency bands, labeled by integers 1 through **k**,
- **k** polarization states, labeled by integers 1 through **k**,
- **k** phase shifts, labeled by integers 1 through **k**.

You are given a catalog of **t** potential signal links. Each link is specified by a triplet `(x, y, z)`, representing its frequency band, polarization state, and phase shift, respectively.

Your task is to establish a stable array by activating exactly **k** links from this catalog. A set of exactly **k** links achieves dimensional resonance if and only if the following three conservation laws hold simultaneously:

- **Frequency Conservation**: When you evaluate $50^x$ (50 raised to the power of **x**) for each chosen link and sum these values, the aggregate must exactly equal the integer $\frac{50^{k+1}-50}{49}$.
- **Polarization Conservation**: When you evaluate $50^y$ (50 raised to the power of **y**) for each chosen link and sum these values, the aggregate must exactly equal the integer $\frac{50^{k+1}-50}{49}$.
- **Phase Conservation**: When you evaluate $50^z$ (50 raised to the power of **z**) for each chosen link and sum these values, the aggregate must exactly equal the integer $\frac{50^{k+1}-50}{49}$.

Determine if a valid configuration of exactly **k** links exists. If it does, output the links that form it.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k), representing the scale parameter and the number of available links.
The next **t** lines each contain three integers **x**, **y**, and **z** (1 ≤ x, y, z ≤ k). These describe the properties of one available link. No link is listed more than once.

## Output

If a resonant configuration of exactly **k** links is possible, print `YES` on the first line. Then, output **k** lines, each containing the three integers `x y z` of a selected link. The links can be printed in any order.

If no such configuration is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both available links have a polarization state of 1. If we select exactly 2 links from this catalog, the sum for the Polarization Conservation will be $50^1 + 50^1 = 100$. However, for **k** = 2, the required aggregate is $(50^3 - 50) / 49 = 124950 / 49 = 2550$. Because 100 does not equal 2550, this selection fails the conservation law, making a valid array impossible.
</STATEMENT>
<RATIONALE>
Replaced the highly recognizable base-2 bitmask condition ($2^x$ summing to $2^{k+1}-2$) with an algebraically equivalent base-50 condition ($50^x$ summing to $(50^{k+1}-50)/49$). This forces models to generalize the concept of positional numeral systems to recognize the exact-cover requirement, defeating those that merely pattern-match powers of 2 to bitwise subsets.
</RATIONALE>
<PRESERVED_ANSWER>
Because k is at most 22, which is strictly less than the base 50, summing exactly k powers of 50 cannot produce any carries; thus the sum uniquely identifies a multiset of exponents, forcing exactly one of each integer from 1 to k just as the seed did.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching, as it still requires selecting k triples such that every coordinate 1..k appears exactly once in each dimension.
</PRESERVED_CLASS>
