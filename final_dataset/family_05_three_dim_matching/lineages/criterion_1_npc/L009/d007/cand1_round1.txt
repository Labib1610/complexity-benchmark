# Problem A — Harmonic Synthesis

Time limit: 5 s   Memory limit: 256 MB

## Description

A subspace harmonic generator needs to synchronize its frequencies across three control dimensions:
- **k** alpha channels, labeled 1 through **k**,
- **k** beta channels, labeled 1 through **k**,
- **k** gamma channels, labeled 1 through **k**.

You are provided with a catalog of **t** available synthesis triplets. Each triplet `(x, y, z)` specifies its alpha channel **x**, beta channel **y**, and gamma channel **z**.

To achieve perfect resonance, you must activate exactly **k** triplets from the catalog. A selection of exactly **k** triplets forms a valid resonance state if and only if it satisfies the following amplitude condition:
- For each activated triplet `(x, y, z)`, its amplitude contribution is defined as $A = 2^x + 2^{k+y} + 2^{2k+z}$.
- The cumulative system amplitude, calculated as the arithmetic sum of the amplitude contributions of all **k** activated triplets, must be exactly equal to $2^{3k+1} - 2$.

Determine whether a valid resonance state of exactly **k** triplets exists. If so, output one such valid set of **k** triplets.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the scale of the system and the number of available synthesis triplets in the catalog.
Each of the next **t** lines contains three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing an available triplet. No triplet is listed more than once.

## Output

If a valid resonance state of exactly **k** triplets exists, print `YES` on the first line, then print **k** lines, each containing the three parameters `x y z` of one chosen triplet. Any valid configuration is accepted; the triplets may be printed in any order.

If no valid configuration exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, **k** = 2, so the target cumulative system amplitude is $2^{3(2)+1} - 2 = 2^7 - 2 = 126$.
If we select the two available triplets:
- The triplet `1 1 1` has an amplitude contribution of $2^1 + 2^{2+1} + 2^{4+1} = 2 + 8 + 32 = 42$.
- The triplet `2 1 2` has an amplitude contribution of $2^2 + 2^{2+1} + 2^{4+2} = 4 + 8 + 64 = 76$.

The arithmetic sum of these contributions is $42 + 76 = 118$. Since this sum does not exactly equal the target amplitude of 126, this configuration is invalid, making it impossible to form a resonance state.

<RATIONALE>
Changed the positional encoding from base 100 to base 2 and updated the target to the analogous geometric sum ($2^{3k+1} - 2$). This forces the model to deduce the popcount invariant—that a sum of $3k$ powers of 2 can only equal this target if no carries occur—to realize it can still be solved as an exact cover problem.
</RATIONALE>
<PRESERVED_ANSWER>
The maximum number of set bits when summing $3k$ powers of 2 is $3k$, which matches the target sum's bit count exactly; therefore, equality holds if and only if no carries occur, meaning all $3k$ exponents are distinct, perfectly preserving the exact cover requirement.
</PRESERVED_ANSWER>
