<METHOD_DESCRIPTION>
The problem's exact-cover nature is obfuscated by replacing the superincreasing capacity values ($2^i$) and the explicit "covering levels" concept with an identity between rational functions in the complex plane. Each path's energy is defined as a sum of simple poles, and the target is a sum of $3k$ distinct poles. By linear independence, the only way $k$ paths (providing $3k$ poles total) can sum to the target function is if their multiset of poles exactly matches the target's set of $3k$ poles without duplication. This requires genuine mathematical reasoning to deduce the exact cover requirement, defeating models that rely on recognizing $2^i$ bitmasks or the explicit "draws from 3 levels" phrasing.
</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Resonant Waveforms

Time limit: 5 s   Memory limit: 256 MB

## Description

A quantum communications array operates across three distinct parameter spaces:
- **k** alpha-modulators (indexed 1 to **k**),
- **k** beta-modulators (indexed 1 to **k**),
- **k** gamma-modulators (indexed 1 to **k**).

The baseline transfer function of the array is defined over the complex frequency domain $s$ as:
$T(s) = \sum_{j=1}^{3k} \frac{1}{s - j}$

You are provided with a catalog of **t** potential signal paths. Each path is characterized by a triplet `(x, y, z)`, corresponding to its alpha-modulator, beta-modulator, and gamma-modulator indices, respectively.

When a path `(x, y, z)` is activated, its energy signature is given by the rational function:
$E(s) = \frac{1}{s - x} + \frac{1}{s - (k+y)} + \frac{1}{s - (2k+z)}$

Your objective is to stabilize the array by activating exactly **k** paths from the catalog. The array reaches a stable state if and only if the combined energy signature of the chosen paths exactly matches the baseline transfer function. That is, the algebraic sum of the energy signatures of the **k** chosen paths must equal $T(s)$ for all complex values of $s$ where the functions are defined.

Determine whether there is a subset of exactly **k** paths that achieves this stable configuration. If a valid configuration exists, output one such valid set.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the scale of the system and the number of available signal paths in the catalog.
Each of the next **t** lines contains three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing an available path. No path is listed more than once.

## Output

If a valid stable configuration of exactly **k** paths exists, print `YES` on the first line, then print **k** lines, each containing the three parameters `x y z` of one chosen path. Any valid configuration is accepted; the paths may be printed in any order.

If no valid configuration exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, **k** = 2.
The baseline transfer function is:
$T(s) = \frac{1}{s - 1} + \frac{1}{s - 2} + \frac{1}{s - 3} + \frac{1}{s - 4} + \frac{1}{s - 5} + \frac{1}{s - 6}$

If we select the two available paths:
- The path `1 1 1` has the energy signature $E_1(s) = \frac{1}{s - 1} + \frac{1}{s - 3} + \frac{1}{s - 5}$.
- The path `2 1 2` has the energy signature $E_2(s) = \frac{1}{s - 2} + \frac{1}{s - 3} + \frac{1}{s - 6}$.

The combined signature of these two paths is $E_1(s) + E_2(s) = \frac{1}{s - 1} + \frac{1}{s - 2} + \frac{2}{s - 3} + \frac{1}{s - 5} + \frac{1}{s - 6}$. 
Since this combined function includes the term $\frac{2}{s - 3}$ and is missing a term for $s = 4$, it does not exactly equal the baseline transfer function $T(s)$ for all $s$. Thus, this configuration is invalid, making it impossible to form a stable configuration.
</STATEMENT>
<RATIONALE>
The explicit superincreasing capacity recurrence ($2^i$) and the structural description of "drawing from 3 levels to cover all 3k levels" have been completely removed. Instead, the exact-cover condition is encoded as an identity between rational functions. Models can no longer rely on recognizing $2^i$ bitmasks or pattern-matching the set-cover phrasing; they must mathematically deduce that matching a sum of $3k$ distinct simple poles using exactly $k$ paths (providing 3 poles each) requires selecting each pole exactly once.
</RATIONALE>
<PRESERVED_ANSWER>
Because simple poles $\frac{1}{s-j}$ are linearly independent, the sum of $k$ energy signatures equals the target function if and only if the multiset of poles in the chosen paths exactly matches the target's set of $3k$ distinct poles, perfectly preserving the exact cover constraints of the original problem.
</PRESERVED_ANSWER>

The problem remains exactly 3-Dimensional Matching (NP-complete), as finding $k$ triplets that perfectly partition the $3k$ indices is mathematically identical to the original formulation.
</PRESERVED_CLASS>
