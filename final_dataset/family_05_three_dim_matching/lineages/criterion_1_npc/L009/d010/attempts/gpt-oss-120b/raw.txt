**Solution Explanation**

For a fixed `k ( 1 ≤ k ≤ 22 )`

```
target = 2^{k+1} – 2 = 2^1 + 2^2 + … + 2^k
```

If we take exactly `k` triples and the three sums of powers of two are equal to
`target`, then the multiset of the `x`‑coordinates must be `{1,…,k}` :

* each term of the sum is a power `2^i ( i ≥ 1 )`,
* we have exactly `k` terms,
* the binary representation of `target` already contains **all**
  powers `2^1 … 2^k` once.

The same argument holds for the `y`‑ and the `z`‑coordinates.
Consequently a feasible set of `k` triples is exactly a **perfect 3‑dimensional
matching** :

* each value `1 … k` appears exactly once as an `x`,
* each value `1 … k` appears exactly once as a `y`,
* each value `1 … k` appears exactly once as a `z`.

--------------------------------------------------------------------

#### 1.   Reformulation as Exact Cover  

Create a universe of `3k` elements  

```
X1 … Xk ,   Y1 … Yk ,   Z1 … Zk
```

Every given triple `(x,y,z)` corresponds to a subset containing the three
elements `{ Xx , Yy , Zz }`.

We have to choose **k** subsets so that every element of the universe is
covered **once** – the classical *Exact Cover* problem.

The size of the universe is at most `66` (`k = 22`) and the number of subsets
is at most `k³ ≤ 10648`.  
For this size the dancing‑links (Algorithm X) solves the problem instantly.

--------------------------------------------------------------------

#### 2.   Dancing Links (Algorithm X)

* column `i`  – one element of the universe  
  (first `k` columns → X‑elements, next `k` → Y‑elements, last `k` → Z‑elements)
* a row → one triple, it contains exactly three 1‑entries (the three columns)

Algorithm X repeatedly  

```
choose a column with the smallest number of rows   (branching factor heuristic)
cover the column
for each row r that contains this column
        add r to the partial solution
        cover all other columns of r
        recurse
        uncover those columns again
uncover the chosen column
```

When all columns are covered we have an exact cover.

The implementation follows the standard textbook version
( arrays `L,R,U,D, C, size, row_of_node` ).  
The recursion depth never exceeds `k ≤ 22`.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct set of triples
iff such a set exists.

---

##### Lemma 1  
If a set of `k` triples satisfies the three sum conditions, then the
`x`‑coordinates of the set are a permutation of `{1,…,k}`.  
The same holds for the `y`‑ and `z`‑coordinates.

**Proof.**  
`target = Σ_{i=1}^{k} 2^i` is the binary representation that contains every
power `2^i (1 ≤ i ≤ k)` exactly once.
A sum of `k` powers of two can equal `target` only when each power appears
once, otherwise the sum would be either too small or would need a non‑power
term. ∎



##### Lemma 2  
A set of `k` triples satisfies the three sum conditions **iff**
it is an exact cover of the universe `{X1…Xk,Y1…Yk,Z1…Zk}`.

**Proof.**  
*If* the set satisfies the conditions, by Lemma&nbsp;1 each value `i`
appears exactly once as an `x`, once as a `y` and once as a `z`.  
Thus the three elements `Xi, Yi, Zi` are covered once – an exact cover.

*Only‑if* an exact cover uses each `Xi, Yi, Zi` once.
Consequently the multiset of `x`‑coordinates is `{1…k}`, the same for `y`,
`z`; the three sums are exactly `target`. ∎



##### Lemma 3  
Algorithm X (dancing links) returns a family of rows that is an exact cover
iff such a cover exists.

**Proof.**  
Algorithm X is a depth‑first search of the solution space of the exact cover
problem.  
Covering a column removes all rows that would conflict with the current
partial solution, and uncovering restores them – this is a reversible
bijection between search states and partial exact covers.
The algorithm explores *all* possibilities (unless it finds a solution and
returns early). Therefore it finds a solution exactly when one exists. ∎



##### Lemma 4  
If the program prints “YES” and the listed triples, they satisfy the required
sum conditions.

**Proof.**  
When “YES” is printed, the program has obtained a set of rows from
Algorithm X, i.e. an exact cover of the universe.
By Lemma&nbsp;2 the corresponding triples fulfil the three sum conditions. ∎



##### Lemma 5  
If a feasible set of `k` triples exists, the program prints “YES”.

**Proof.**  
A feasible set is, by Lemma&nbsp;2, an exact cover.
By Lemma&nbsp;3 Algorithm X finds an exact cover whenever one exists,
hence the program reaches the success case and prints “YES”. ∎



##### Theorem  
The program outputs  

* “YES” followed by `k` triples that satisfy all three sum conditions
  **iff** such a set exists,
* otherwise outputs “NO”.

**Proof.**  
*If* the program outputs “YES”, Lemma&nbsp;4 guarantees correctness of the
triples.  
*Only if* a correct set exists, Lemma&nbsp;5 guarantees that the program finds
one and outputs “YES”.  
If the search finishes without a cover, by Lemma&nbsp;3 no exact cover exists,
hence by Lemma&nbsp;2 no feasible set exists, and the program correctly prints
“NO”. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

```
k ≤ 22 ,   t ≤ k³ ≤ 10648
universe size   U = 3k ≤ 66
rows            ≤ 10648
columns per row = 3
```

*Building the structure* : `O(t)`.

*Algorithm X* :

* each recursive level removes at most `U` columns and at most `t` rows,
  but the depth is `k ≤ 22`.
* The worst‑case time of exact cover is exponential, but with the
  “choose column with minimum size” heuristic and such a tiny universe
  it runs far below the time limit (well under a millisecond for the
  maximal input).

Memory consumption:

* one node per `1` in the matrix → `3·t ≤ 31944` nodes,
  each stored in a few integer arrays ⇒ < 1 MiB.

Both limits satisfy the given constraints.

#### 5.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    triples = []                     # (x,y,z)
    for _ in range(t):
        x = int(next(it)) - 1        # 0‑based
        y = int(next(it)) - 1
        z = int(next(it)) - 1
        triples.append((x, y, z))

    # ---------- dancing links ----------
    C = 3 * k                        # number of columns
    max_nodes = 1 + C + 3 * t + 5    # root + column headers + each 1 in matrix

    L = [0] * max_nodes
    R = [0] * max_nodes
    U = [0] * max_nodes
    D = [0] * max_nodes
    col = [0] * max_nodes            # column of a node
    row_of_node = [0] * max_nodes    # which triple the node belongs to
    size = [0] * (C + 1)             # size of each column, indexed by header id (1..C)

    # root is 0
    for i in range(C + 1):
        L[i] = i - 1
        R[i] = i + 1
        U[i] = D[i] = i
    L[0] = C
    R[C] = 0

    node_cnt = C + 1                 # next free node index

    # add rows
    for idx, (x, y, z) in enumerate(triples):
        cols = [x, k + y, 2 * k + z]     # column numbers 0..C-1
        first = -1
        for c in cols:
            header = c + 1                # column header id
            nid = node_cnt
            node_cnt += 1
            col[nid] = header
            row_of_node[nid] = idx

            # insert vertically just before header (i.e. at the bottom)
            U[nid] = U[header]
            D[nid] = header
            D[U[header]] = nid
            U[header] = nid
            size[header] += 1

            # link horizontally
            if first == -1:
                first = nid
                L[nid] = R[nid] = nid
            else:
                # insert to the left of first (circular list)
                L[nid] = L[first]
                R[nid] = first
                R[L[first]] = nid
                L[first] = nid

    # ---------- algorithm X ----------
    solution_rows = []          # list of triple indices forming the solution
    found = False

    def cover(c):
        # remove column header c
        L[R[c]] = L[c]
        R[L[c]] = R[c]
        # remove rows
        i = D[c]
        while i != c:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                size[col[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(c):
        i = U[c]
        while i != c:
            j = L[i]
            while j != i:
                size[col[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        L[R[c]] = c
        R[L[c]] = c

    def choose_column():
        # heuristic: column with smallest size (>0)
        c = R[0]
        best = c
        min_sz = size[c]
        while c != 0:
            if size[c] < min_sz:
                min_sz = size[c]
                best = c
                if min_sz == 0:
                    break
            c = R[c]
        return best

    def search():
        nonlocal found
        if R[0] == 0:               # all columns covered
            found = True
            return True
        c = choose_column()
        if size[c] == 0:
            return False
        cover(c)
        r = D[c]
        while r != c:
            solution_rows.append(row_of_node[r])
            j = R[r]
            while j != r:
                cover(col[j])
                j = R[j]
            if search():
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(col[j])
                j = L[j]
            solution_rows.pop()
            r = D[r]
        uncover(c)
        return False

    if search():
        out = ['YES']
        for idx in solution_rows:
            x, y, z = triples[idx]
            out.append(f"{x+1} {y+1} {z+1}")
        sys.stdout.write("\n".join(out))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
