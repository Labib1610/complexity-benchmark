We need to select exactly k paths such that for each coordinate (x, y, z), the sum of 2^coordinate equals 2^(k+1) − 2.  

Notice that 2^(k+1) − 2 =  sum_{i=1}^{k} 2^i.  
So for each coordinate, the multiset of chosen values must be exactly {1,2,…,k} (each exactly once).  
Thus, we need to pick k distinct paths such that the x-values are a permutation of 1..k, similarly for y and z.  

This is equivalent to finding a perfect matching in a 3-partite hypergraph: we have k possible values for each coordinate, and each path is a triple (x,y,z). We need to select k triples such that each value 1..k appears exactly once in each coordinate.  

Since k ≤ 22, we can use bitmask DP over two coordinates, and greedily assign the third.  
We can fix the order of x from 1 to k, and for each x, choose a path with that x, ensuring y and z are unused.  
We can do DP over (mask_y, mask_z) → possible.  
But k=22, masks have 2^22 ≈ 4 million, and pair of masks impossible.  
We need a smarter approach.  

Observation: Since each coordinate must be a permutation, we can treat this as a 3D matching problem.  
But k is small enough for backtracking with pruning? 22 is too large for naive.  

We can use the fact that each path is unique, and t ≤ k^3.  
We can model as exact cover: we need to cover each value in each coordinate exactly once.  
We can use Algorithm X (Dancing Links) but with 3*k constraints and t items.  
k=22 → 66 constraints, t up to 10648. That’s feasible with DLX.  

We can implement DLX to find exact cover.  
Each path covers three constraints: (x,0), (y,1), (z,2).  
We need to select exactly k rows such that all 3k constraints are covered exactly once.  

DLX will work.  

Let’s implement.  

We need to output the selected paths.  

We’ll build a sparse matrix: columns = 3*k.  
Rows = t.  
Each row has 3 ones.  

We’ll implement DLX with dancing links.  

Since k ≤ 22, columns ≤ 66, rows ≤ 10648.  
DLX will be fast enough.  

We’ll also add a heuristic: choose column with fewest candidates.  

Let’s code.  

We need to be careful with recursion depth: k ≤ 22, so depth ≤ 22, fine.  

Implementation details:  
- Node class with left, right, up, down, col, row_id.  
- Column objects with size.  
- We’ll use arrays for speed.  

We’ll implement as arrays of integers for left, right, up, down, col, row.  
We’ll have a header node (index 0).  
Columns 1..3k.  
Then rows.  

We’ll build.  

Then DLX search:  
- If head.right == head: found solution.  
- Choose column with min size.  
- Cover that column.  
- For each row in that column (down links), try selecting it: cover all columns in that row, then recurse. If success, return. Uncover.  
- Uncover column.  

We need to store selected rows.  

Let’s implement.  

We’ll also need to map row index to original path.  

Let’s write code.  

We’ll read input, build matrix.  

Edge cases: t=0 → NO.  
k=1: only path (1,1,1) if exists → YES else NO.

import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))
    paths = []
    for _ in range(t):
        x = int(next(it))
        y = int(next(it))
        z = int(next(it))
        paths.append((x, y, z))

    if t == 0:
        print("NO")
        return

    # columns: 0..3k-1
    # 0..k-1 for x, k..2k-1 for y, 2k..3k-1 for z
    ncols = 3 * k
    nrows = t

    # DLX arrays
    # We'll use 1-indexed nodes: 0 is header
    # Each column has a header node
    # We'll create column nodes first
    left = [0] * (1 + ncols + nrows * 3)
    right = [0] * (1 + ncols + nrows * 3)
    up = [0] * (1 + ncols + nrows * 3)
    down = [0] * (1 + ncols + nrows * 3)
    col = [0] * (1 + ncols + nrows * 3)
    row = [0] * (1 + ncols + nrows * 3)

    # column headers
    for i in range(ncols + 1):
        left[i] = i - 1
        right[i] = i +  ​1
        up[i] = i
        down[i] = i
        col[i] = i
        row[i] = -1
    left[0] = ncols
    right[ncols] = 0

    size = [0] * (ncols + 1)

    # We'll add rows
    node_idx = ncols +  ​1
    # For each column, keep last node index (initially column header)
    last = [i for i in range(ncols + 1)]

    for r in range(t):
        x, y, z = paths[r]
        cols = [x-1, k + (y-1), 2*k + (z-1)]
        # sort columns to keep order (not necessary but helps)
        cols.sort()
        first = -1
        prev = -1
        for c in cols:
            idx = node_idx
            node_idx += 1
            left[idx] = prev
            right[idx] = -1
            if prev != -1:
                right[prev] = idx
            else:
                first = idx
            # vertical links
            up[idx] = last[c]
            down[idx] = c
            down[last[c]] = idx
            up[c] = idx
            last[c] = idx
            col[idx] = c
            row[idx] = r
            size[c] += 1
            prev = idx
        # close row loop
        right[prev] = first
        left[first] = prev

    # Now DLX search
    answer = []

    def cover(c):
        # remove column c from header
        right[left[c]] = right[c]
        left[right[c]] = left[c]
        # for each row in this column
        i = down[c]
        while i != c:
            # cover all columns in this row
            j = right[i]
            while j != i:
                up[down[j]] = up[j]
                down[up[j]] = down[j]
                size[col[j]] -= 1
                j = right[j]
            i = down[i]

    def uncover(c):
        i = up[c]
        while i != c:
            j = left[i]
            while j != i:
                size[col[j]] += 1
                up[down[j]] = j
                down[up[j]] = j
                j = left[j]
            i = up[i]
        right[left[c]] = c
        left[right[c]] = c

    def search():
        if right[0] == 0:
            return True
        # choose column with min size
        c = right[0]
        min_size = size[c]
        j = right[c]
        while j != 0:
            if size[j] < min_size:
                min_size = size[j]
                c = j
            j = right[j]
        if min_size == 0:
            return False
        cover(c)
        r = down[c]
        while r != c:
            answer.append(row[r])
            # cover all columns in this row
            j = right[r]
            while j != r:
                cover(col[j])
                j = right[j]
            if search():
                return True
            # backtrack
            j = left[r]
            while j != r:
                uncover(col[j])
                j = left[j]
            answer.pop()
            r = down[r]
        uncover(c)
        return False

    if search():
        print("YES")
        for idx in answer:
            x, y, z = paths[idx]
            print(x, y, z)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
