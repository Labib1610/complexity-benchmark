<STATEMENT>
# Problem A — Resonant Waveforms

Time limit: 5 s   Memory limit: 256 MB

## Description

A quantum communications array operates across three distinct parameter spaces:
- **k** frequency bands (indexed 1 to **k**),
- **k** polarization states (indexed 1 to **k**),
- **k** phase shifts (indexed 1 to **k**).

The system's energy distribution is modeled by a scalar field over $3k$ spatial variables, $v_1, v_2, \dots, v_{3k}$. The baseline field equation is the product of all these variables:
$$\Phi(v_1, \dots, v_{3k}) = \prod_{i=1}^{3k} v_i$$

You are provided with a catalog of **t** potential signal paths. Each path is characterized by a triplet `(x, y, z)`, corresponding to its frequency band, polarization state, and phase shift, respectively.

When a path `(x, y, z)` is activated, it acts on the field as a third-order mixed partial differential operator, targeting the variables corresponding to its parameters:
$$\nabla = \frac{\partial^3}{\partial v_x \partial v_{k+y} \partial v_{2k+z}}$$

Your objective is to stabilize the array by activating exactly **k** paths from the catalog. When multiple paths are activated, their combined effect on the system is the composition of their individual operators applied to the baseline field $\Phi$.

The array reaches a stable state if and only if this combined operator, when applied to $\Phi$, evaluates to exactly 1.

Determine whether there is a subset of exactly **k** paths that achieves this stable configuration. If a valid configuration exists, output one such valid set.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the scale of the system and the number of available signal paths in the catalog.
Each of the next **t** lines contains three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing an available path. No path is listed more than once.

## Output

If a valid stable configuration of exactly **k** paths exists, print `YES` on the first line, then print **k** lines, each containing the three parameters `x y z` of one chosen path. Any valid configuration is accepted; the paths may be printed in any order.

If no valid configuration exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```

```

**Output**
```

```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, **k** = 2, so the system is modeled over $3 \times 2 = 6$ variables.
The baseline field is $\Phi = v_1 v_2 v_3 v_4 v_5 v_6$.

If we select the two available paths:
- The path `1 1 1` acts as the operator $\nabla_1 = \frac{\partial^3}{\partial v_1 \partial v_3 \partial v_5}$.
- The path `2 1 2` acts as the operator $\nabla_2 = \frac{\partial^3}{\partial v_2 \partial v_3 \partial v_6}$.

Composing these two operators yields a combined operator of order 6:
$$\nabla_{1,2} = \frac{\partial^6}{\partial v_1 \partial v_2 \partial v_3^2 \partial v_5 \partial v_6}$$

When we apply $\nabla_{1,2}$ to the baseline field $\Phi$, we must differentiate with respect to $v_3$ twice. Because $\Phi$ only contains $v_3$ to the first power, the second derivative with respect to $v_3$ is 0.
Thus, the combined effect on $\Phi$ evaluates to 0, not exactly 1. This configuration is invalid, making it impossible to form a stable configuration.
