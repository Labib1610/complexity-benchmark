<STATEMENT>
# Problem A — Holographic Storage

Time limit: 5 s   Memory limit: 256 MB

## Description

You are initializing a holographic storage crystal. The crystal's addressing space is a 3D grid of dimensions **k** × **k** × **k**, where each node is identified by a coordinate triplet `(x, y, z)` with 1 ≤ x, y, z ≤ k.

Due to imperfections in the crystal lattice, only **t** specific nodes are structurally sound enough to hold data. You are provided with the coordinates of these sound nodes.

Your task is to select exactly **k** sound nodes to form a stable memory cluster. A memory cluster is considered stable if and only if no two selected nodes share the same **x**-coordinate, no two share the same **y**-coordinate, and no two share the same **z**-coordinate.

Determine whether it is possible to form a stable memory cluster. If it is, output one valid selection of **k** nodes.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the required cluster size and the number of sound nodes.
Each of the next **t** lines contains three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing the coordinates of a sound node. No node is listed more than once.

## Output

If a stable memory cluster of **k** nodes can be formed, print `YES` on the first line. Then, print **k** lines, each containing the coordinates `x y z` of one selected node. The nodes may be printed in any order.

If no such cluster can be formed, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both sound nodes have a **y**-coordinate of 1. Since nodes in a stable memory cluster cannot share the same **y**-coordinate, at most one of these nodes can be selected. Therefore, it is impossible to select 2 nodes to form the cluster.

<RATIONALE>
The scenario was changed from assembling crews out of three distinct pools of resources (specialists, machines, time slots) to selecting points in a uniform 3D coordinate grid. This removes the semantic asymmetry that naturally prompts models to iterate over one specific set (e.g., treating "specialists" as the primary variable to assign). Models must now independently recognize that selecting `k` points with mutually distinct coordinates across all three dimensions is structurally identical to exact cover or 3D matching.
</RATIONALE>
<PRESERVED_ANSWER>
Every valid memory cluster of `k` nodes corresponds directly to a valid set of `k` crews, as the constraint of distinct x, y, and z coordinates perfectly mirrors the constraint of distinct specialists, machines, and time slots.
</PRESERVED_ANSWER>
