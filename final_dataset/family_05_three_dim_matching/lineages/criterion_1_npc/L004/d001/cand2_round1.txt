<STATEMENT>
# Problem A — Seismic Sensor Network

Time limit: 5 s   Memory limit: 256 MB

## Description

A geological survey team must deploy exactly **k** monitoring probes in a subterranean grid. The surveyed region is divided into **k** longitudinal sectors, **k** latitudinal sectors, and **k** depth levels. Each sector and level is indexed by an integer from 1 to **k**.

Due to rock density variations, a probe can only be safely anchored at certain stable locations, defined by a triplet `(lon, lat, depth)`. You are provided with a list of these stable anchoring sites.

You must select exactly **k** stable sites to deploy the probes. To ensure the acoustic signaling between probes does not interfere, no two deployed probes can share the same longitudinal sector, no two can share the same latitudinal sector, and no two can share the same depth level. Consequently, across your chosen deployment sites, every integer from 1 to **k** must be occupied **exactly once** as a longitudinal sector, **exactly once** as a latitudinal sector, and **exactly once** as a depth level.

Determine whether such a deployment is possible, and if so, report one valid set of anchoring sites.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the dimension limit and the number of stable anchoring sites.
Each of the next **t** lines contains three integers **lon**, **lat**, **depth** (1 ≤ lon, lat, depth ≤ k), representing a stable site. No site is listed more than once.

## Output

If a valid deployment of **k** sites exists, print `YES` on the first line, then print **k** lines, each containing the three values `lon lat depth` of one chosen site. Any selection meeting the requirement is accepted; the sites may be printed in any order.

If no valid deployment exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both stable sites use the value 1 for the latitudinal sector, meaning the latitudinal sector 2 can never be occupied.

<RATIONALE>
The problem was completely reframed from generic "parameters/configurations" into a 3D spatial geometry scenario (placing non-interfering probes in a grid). This masks the 3-partite nature of the problem, making it harder for models to instantly recognize it as Exact Cover or a 3-uniform hypergraph matching task. Models are now forced to translate the spatial "no sharing" constraints back into an abstract exact-cover formulation if they want to employ optimal algorithms like DLX.
</RATIONALE>
