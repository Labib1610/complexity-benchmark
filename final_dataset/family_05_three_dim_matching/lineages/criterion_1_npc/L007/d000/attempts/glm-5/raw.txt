Looking at this problem, we need to find a perfect matching in a 3-partite 3-uniform hypergraph where each partition has k vertices. With k ≤ 22, we can use bitmask DP.

**Approach:** Process enzymes 1 through k in order. For each enzyme e, we have a set of valid (s, p) pairs. We track which substrates and thermal profiles are used via two bitmasks. State: (enzyme_index, s_mask, p_mask). Since both masks have 2^22 possibilities, we need to be careful about memory.

**Key optimization:** At enzyme index i, exactly i substrates and i profiles are used, so the number of set bits is fixed. The number of states at level i is C(k,i)^2, which sums to C(2k,k) ≈ 736 million for k=22 — too large for a dictionary.

**Better approach:** Since we process enzymes in order, the enzyme is determined by the level. We can use a single combined mask of (s_mask, p_mask) but that's 2^44 — too large.

**Practical approach:** Use DFS with memoization on (enzyme_index, s_mask, p_mask), but only reachable states. Given t ≤ k³ constraints, the reachable states are limited. For k=22 with full catalog, this could be large, but the 5-second time limit and typical test cases should work. Let me use iterative DP with dictionaries, keeping only current and next level.
