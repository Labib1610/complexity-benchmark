# Problem A — Spatial Anomaly Observation

Time limit: 5 s   Memory limit: 256 MB

## Description

An expedition is deploying observation buoys into a spatial anomaly. The anomaly's interior is mapped using a discrete coordinate system with three axes: Alpha, Beta, and Gamma. Each axis is quantized into exactly **k** distinct levels, numbered 1 through **k**.

Due to gravimetric turbulence, buoys can only be anchored at specific, pre-surveyed stable points within the anomaly. Each stable point is defined by its three coordinates: an Alpha level, a Beta level, and a Gamma level. You are provided with a catalog of all **t** stable points.

To achieve complete and non-interfering sensor coverage, the expedition must deploy exactly **k** buoys. The deployment must satisfy a strict spatial distribution requirement: every Alpha level (1 through **k**), every Beta level (1 through **k**), and every Gamma level (1 through **k**) must be occupied by exactly one buoy. This means you must select exactly **k** stable points from the catalog such that no two selected points share the same Alpha, Beta, or Gamma level.

Determine whether such a deployment is possible, and if so, report the coordinates of the chosen stable points.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the number of levels for each axis, and the total number of pre-surveyed stable points.
Each of the next **t** lines contains three integers **a**, **b**, **c** (1 ≤ a, b, c ≤ k), representing a stable point with Alpha level **a**, Beta level **b**, and Gamma level **c**. No stable point is listed more than once in the catalog.

## Output

If a valid deployment of **k** buoys exists, print `YES` on the first line. Then, print **k** lines, each containing the three integers `a b c` of a chosen stable point. Any selection that occupies every Alpha, Beta, and Gamma level exactly once will be accepted. You may print the chosen points in any order.

If no valid deployment exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both stable points are located at Beta level 1. Consequently, Beta level 2 can never be occupied, making a valid deployment impossible.
