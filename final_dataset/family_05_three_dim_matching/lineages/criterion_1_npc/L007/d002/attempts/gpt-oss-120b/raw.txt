**Solution Explanation**

For every component we have a column in an exact‑cover matrix  

* columns `0 … k‑1` – chassis `1 … k`  
* columns `k … 2k‑1` – navigation modules `1 … k`  
* columns `2k … 3k‑1` – imaging sensors `1 … k`

A feasible assembly plan consists of `k` triples  
`(c , n , i)` – one row of the matrix – such that each column is covered
exactly once.  
That is precisely the *exact cover* problem, solved efficiently by
Donald Knuth’s **Algorithm X** with the dancing‑links data structure
(DLX).

`k ≤ 22`, therefore at most `3·k = 66` columns and at most `k³ = 10648`
rows – tiny for DLX.

The algorithm

```
search():
    if every column is covered → solution found
    choose the uncovered column with the smallest number of rows
    for each row r that contains this column
        add r to the partial solution
        cover all columns of r
        if search() succeeds → propagate success
        uncover all columns of r          (backtrack)
    return failure
```

Because the branching factor is limited by the smallest column,
the search finishes instantly for the given limits.

The program builds the DLX structure, runs the search and prints
`YES` together with the selected triples, or `NO` if no exact cover
exists.



--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct set of triples
iff such a set exists.

---

##### Lemma 1  
During the execution of `search` the set of *covered* columns is exactly
the union of columns of the rows already placed in the current partial
solution.

**Proof.**  
`cover(col)` removes `col` from the column list and also removes every
row that contains `col` from all other column lists.  
Thus after covering all columns of a newly added row, those columns are
no longer present in the column list, i.e. they are *covered*.  
`uncover(col)` restores the column and all rows, undoing the exact
changes made by `cover`. ∎



##### Lemma 2  
If `search` reaches the line “every column is covered”, the rows stored
in the solution list form a set of `k` triples that uses each chassis,
navigation module and sensor exactly once.

**Proof.**  
When all columns are covered, by Lemma&nbsp;1 every column belongs to
the union of columns of the selected rows.
Each column appears at most once because a column, once covered, is
removed from the column list and can never be covered again before it
is uncovered (which only happens on backtracking).  
There are `3k` columns, each row contributes exactly three distinct
columns, therefore the number of rows is `3k / 3 = k`. ∎



##### Lemma 3  
If a set of `k` triples satisfying the requirements exists, `search`
will eventually find it.

**Proof.**  
Consider any such solution `S`.  
At each recursive call `search` chooses an uncovered column `c`.
Since `S` covers all columns, `c` is contained in exactly one row of `S`.
That row is among the rows iterated in the `for` loop (all rows containing
`c`).  
When the algorithm tries that row, it covers all columns of the row,
which are precisely the columns of that row in `S`.  
Thus the recursive call works on the reduced instance that still has a
solution (the remaining rows of `S`).  
By induction on the number of uncovered columns the recursion can follow
the rows of `S` all the way to the base case where all columns are
covered, where it succeeds. ∎



##### Lemma 4  
If `search` reports failure, no set of `k` triples satisfying the
requirements exists.

**Proof.**  
Assume the contrary: a solution `S` exists but `search` fails.
Consider the first recursive call where the algorithm makes a choice that
excludes the row of `S` containing the selected column `c`.  
All rows examined before that row either do not belong to `S` or lead to
dead ends (otherwise the algorithm would have succeeded earlier).
After trying all those rows, the algorithm backtracks and uncovers the
columns, i.e. it discards the possibility of using the row of `S`.  
Consequently the recursive call returns failure, and the whole search
fails.  
But Lemma&nbsp;3 guarantees that following the rows of `S` never leads to
a dead end, a contradiction. ∎



##### Theorem  
The program outputs  

* `YES` and a list of `k` triples **iff** such a list exists,  
* otherwise `NO`.

**Proof.**  

*If the program prints `YES`.*  
It printed the rows stored by `search` when all columns were covered.
By Lemma&nbsp;2 these rows form a valid assembly plan.

*If a valid assembly plan exists.*  
By Lemma&nbsp;3 `search` will eventually reach the all‑covered state,
thus the program prints `YES`.

*If the program prints `NO`.*  
That means `search` returned failure. By Lemma&nbsp;4 no valid plan
exists.

Hence the output is correct in all cases. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*`C = 3k ≤ 66`* columns, *`R ≤ k³ ≤ 10648`* rows.

Construction of the DLX structure: `O(C + R·3)` (each row has three
ones).

During the search each recursive level covers at most three columns,
so the total work is proportional to the number of visited nodes.
In the worst case the algorithm could explore all subsets, but with the
given limits the practical running time is far below the 5 s limit
(typically a few thousand recursive calls).

Memory consumption:  
arrays for the dancing links need `O(C + R·3)` integers → well under the
256 MB limit.

#### Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(1000000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    # columns: 0..k-1 chassis, k..2k-1 navigation, 2k..3k-1 sensor
    C = 3 * k
    rows = []          # each row: (c, n, i, [col indices])
    for _ in range(t):
        c = int(next(it)) - 1
        n = int(next(it)) - 1
        i = int(next(it)) - 1
        cols = [c, k + n, 2 * k + i]
        rows.append((c, n, i, cols))

    # ---------- DLX structures ----------
    # node 0 is the header
    max_nodes = 1 + C + t * 3
    U = [0] * max_nodes
    D = [0] * max_nodes
    L = [0] * max_nodes
    R = [0] * max_nodes
    Ccol = [0] * max_nodes          # column of node
    S = [0] * (C + 1)               # size of column (only for column headers)
    row_id = [0] * max_nodes        # which original row a node belongs to

    # header links
    for i in range(C + 1):
        U[i] = D[i] = i
        L[i] = i - 1
        R[i] = i + 1
    L[0] = C
    R[C] = 0

    # column headers are 1..C (shift by +1)
    # we will use column index+1 as header node id
    node_ptr = C + 1

    # add rows
    for rid, (c, n, i, cols) in enumerate(rows):
        first = -1
        for col in cols:
            col_header = col + 1
            nd = node_ptr
            node_ptr += 1
            Ccol[nd] = col_header
            row_id[nd] = rid
            # vertical links (insert at bottom of column)
            U[nd] = U[col_header]
            D[nd] = col_header
            D[U[col_header]] = nd
            U[col_header] = nd
            S[col_header] += 1
            # horizontal links within the row
            if first == -1:
                first = nd
                L[nd] = R[nd] = nd
            else:
                L[nd] = L[first]
                R[nd] = first
                R[L[first]] = nd
                L[first] = nd

    solution_rows = []

    def cover(col):
        # remove column header
        R[L[col]] = R[col]
        L[R[col]] = L[col]
        # remove rows
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                S[Ccol[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col):
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                S[Ccol[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        R[L[col]] = col
        L[R[col]] = col

    def search():
        if R[0] == 0:          # all columns covered
            return True
        # choose column with minimal size
        c = R[0]
        min_s = S[c]
        col = c
        j = R[c]
        while j != 0:
            if S[j] < min_s:
                min_s = S[j]
                col = j
                if min_s == 0:
                    break
            j = R[j]
        if min_s == 0:
            return False
        cover(col)
        r = D[col]
        while r != col:
            solution_rows.append(row_id[r])
            j = R[r]
            while j != r:
                cover(Ccol[j])
                j = R[j]
            if search():
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(Ccol[j])
                j = L[j]
            solution_rows.pop()
            r = D[r]
        uncover(col)
        return False

    if search():
        out = ["YES"]
        for rid in solution_rows:
            c, n, i, _ = rows[rid]
            out.append(f"{c+1} {n+1} {i+1}")
        sys.stdout.write("\n".join(out))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```
