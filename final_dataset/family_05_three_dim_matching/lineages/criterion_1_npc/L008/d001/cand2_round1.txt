<STATEMENT>
# Problem A — Perfectly Diverse Conservatory

Time limit: 5 s   Memory limit: 256 MB

## Description

You are the head botanist of a conservatory that is cultivating a new exhibition. The exhibition will feature a collection of exactly **k** hybrid plants.

Every cultivated hybrid plant exhibits exactly three genetic traits: a flower morphology, a pigmentation, and a foliage structure. Within the conservatory's catalog, there are **k** documented morphologies, **k** documented pigmentations, and **k** documented foliage structures. Each trait is identified by an integer from 1 to **k**.

Through prior experiments, the botanists have successfully grown **t** specific hybrid variants. You are given the trait profile for each of these **t** viable variants.

Your task is to select a subset of exactly **k** variants from the viable list to form the exhibition. The board of directors has mandated that the exhibition must be perfectly diverse. A collection is perfectly diverse if and only if the **k** plants in the exhibition have mutually distinct flower morphologies, mutually distinct pigmentations, and mutually distinct foliage structures.

Determine if it is possible to curate such an exhibition, and if so, list the trait profiles of the selected plants.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the number of documented traits in each category, and the number of viable hybrid variants.
Each of the next **t** lines contains three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing a viable variant with flower morphology **x**, pigmentation **y**, and foliage structure **z**. No variant is listed more than once.

## Output

If a perfectly diverse exhibition of **k** plants can be formed, print `YES` on the first line, then print **k** lines, each containing the three integers `x y z` of one selected variant. The variants may be printed in any order.

If no such exhibition can be formed, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both viable variants have pigmentation 1. If both are selected to meet the requirement of **k** = 2 plants, their pigmentations will not be mutually distinct. Thus, a perfectly diverse exhibition is impossible.
</STATEMENT>
<RATIONALE>
The problem was completely reframed from a network routing scenario to a botanical genetics scenario. Crucially, the exact cover requirement ("allocated without omission or duplication") was replaced with a uniqueness constraint ("mutually distinct"). Because the number of chosen plants ($k$) equals the number of possible traits in each category ($k$), the Pigeonhole Principle dictates this is still an exact cover. This forces models to independently deduce the perfect matching structure; if they fail to realize they can group their backtracking by one of the traits, their search space becomes $\binom{t}{k}$ instead of a constrained depth-$k$ tree, resulting in a Time Limit Exceeded.
</RATIONALE>
<PRESERVED_ANSWER>
Selecting exactly $k$ triplets out of $t$ such that no two share an $x$, $y$, or $z$ coordinate is mathematically identical to finding a perfect 3D matching, preserving all valid solutions exactly.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching (or Exact Cover), which is NP-complete.
</PRESERVED_CLASS>
