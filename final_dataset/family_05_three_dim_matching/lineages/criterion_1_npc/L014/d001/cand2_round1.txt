<STATEMENT>
# Problem A — Compound Synthesis

Time limit: 5 s   Memory limit: 256 MB

## Description

A laboratory is synthesizing complex compounds. The inventory contains distinct base fluids (labeled 1 through **k**), distinct catalysts (labeled 1 through **k**), and distinct thermal profiles (labeled 1 through **k**).

When mixed, a specific base fluid, a single catalyst, and one thermal profile form a reaction. You are provided with a database of **t** known stable reactions.

A full synthesis protocol is defined by selecting a subset of these stable reactions. To prevent cross-contamination and ensure absolute resource efficiency, this chosen subset must collectively incorporate every single base fluid exactly once, every single catalyst exactly once, and every single thermal profile exactly once across all the selected reactions combined.

Your task is to determine whether such a protocol can be formed from the database. If it is possible, you must also provide the list of the reactions that achieve this exact utilization.

## Input

The first line contains two integers **k** and **t**: the number of each type of ingredient and the number of known stable reactions. The laboratory operates a standard 22-slot testing rig, which strictly limits the number of available items in each ingredient category to at most the rig's capacity, with at least one item of each type required to run a test. The number of known reactions **t** can range from none at all up to the theoretical maximum where every possible combination of one base fluid, one catalyst, and one thermal profile is stable.

Each of the next **t** lines contains three integers **x**, **y**, **z** (between 1 and **k** inclusive), representing a stable reaction made of base fluid **x**, catalyst **y**, and thermal profile **z**. No reaction is listed more than once.

## Output

If a valid protocol can be formed, print `YES` on the first line, then print **k** lines, each containing the three integers `x y z` of one chosen reaction. Any valid subset is accepted; the reactions may be printed in any order.

If no such protocol can be formed, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both stable reactions require catalyst 1, meaning any subset will either fail to incorporate catalyst 2 or will use catalyst 1 more than once.

<RATIONALE>
The explicit instruction to pick "exactly k stable reactions" was replaced with a global exact-incidence requirement for the ingredients. This removes the obvious prompt to use row-wise backtracking (where a model iterates over the base fluids and picks one reaction for each). Additionally, the explicit numerical inequalities for `k` and `t` were replaced with physical scenario constraints (a 22-slot rig and a theoretical maximum of combinations) to force the model to derive the bounds itself.
</RATIONALE>
<PRESERVED_ANSWER>
Because each reaction contains exactly one of each ingredient type, a subset that uses every ingredient exactly once across $k$ available items of each type must necessarily consist of exactly $k$ reactions, making the valid solutions identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching, which is an NP-complete exact cover problem.
</PRESERVED_CLASS>
