<STATEMENT>
# Problem A — Exhibition Curation

Time limit: 5 s   Memory limit: 256 MB

## Description

You are curating a prestigious art exhibition. The gallery mandates that exactly **k** sculptures be put on display. You have a catalog of **t** available sculptures to choose from. 

Each available sculpture has three attributes:
- Its material, represented by an integer from 1 to **k**.
- Its artistic style, represented by an integer from 1 to **k**.
- Its assigned display pavilion, represented by an integer from 1 to **k**.

To ensure a perfectly balanced exhibition, the board of directors has established strict representation requirements. You must select exactly **k** sculptures from the catalog such that:
- Every material from 1 to **k** is featured in exactly one selected sculpture.
- Every artistic style from 1 to **k** is featured in exactly one selected sculpture.
- Every display pavilion from 1 to **k** hosts exactly one selected sculpture.

Determine whether it is possible to curate an exhibition that meets all these requirements. If a valid selection exists, you must output one valid set of **k** chosen sculptures.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the number of categories for each attribute, and the total number of sculptures available in the catalog.
Each of the following **t** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v, w ≤ k). These represent a single available sculpture made of material **u**, designed in style **v**, and assigned to pavilion **w**. No identical sculpture (having the same material, style, and pavilion) is listed more than once in the catalog.

## Output

If a valid exhibition of **k** sculptures can be curated, print `YES` on the first line. Then, print **k** lines, each containing the three integers `u v w` representing a selected sculpture. Any valid selection of sculptures that satisfies all board requirements is accepted. The sculptures may be printed in any order.

If no such exhibition is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both available sculptures are designed in artistic style 1. As a result, artistic style 2 can never be featured, making a valid exhibition impossible.

The problem was completely reframed from a network routing scenario to selecting items (sculptures) with three symmetric properties. This removes the "input to output" conceptual asymmetry that previously triggered rote network-routing heuristics or guided the models to automatically group by the first column without reasoning about the underlying 3-dimensional matching structure.
</RATIONALE>
