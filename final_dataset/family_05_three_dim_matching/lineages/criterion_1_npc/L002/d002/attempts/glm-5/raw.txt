Looking at this problem, we need to select exactly k pathways where each input, output, and frequency is used exactly once. This is a 3-dimensional matching problem.

Since k ≤ 22, I'll use a meet-in-the-middle approach:
1. Split frequencies into two halves
2. For each half, enumerate all valid partial matchings (input→output assignments using only those frequencies)
3. For each partial matching in the first half, check if there's a complementary matching in the second half

The key insight: a partial matching is a permutation of some subset of inputs to outputs. We represent it as a bitmask of used outputs. For the first half, we store (used_inputs, used_outputs) → best matching. For the second half, we look for complementary matchings.

To make this efficient, I group pathways by frequency and use DP over frequency subsets, tracking which (input_mask, output_mask) states are reachable.

import sys

def solve():
    data = sys.stdin.buffer.read().split()
    idx = 0
    k = int(data[idx]); idx += 1
    t = int(data[idx]); idx += 1
    
    freq_data = [[] for _ in range(k + 1)]
    for _ in range(t):
        u = int(data[idx]); idx += 1
        v = int(data[idx]); idx += 1
        w = int(data[idx]); idx += 1
        freq_data[w].append((u, v))
    
    if k == 0:
        print("YES")
        return
    
    full_mask = (1 << k) - 1
    half1 = k // 2
    freqs1 = list(range(1, half1 + 1))
    freqs2 = list(range(half1 + 1, k + 1))
    
    def compute_states(freqs):
        dp = {(0, 0): []}
        for freq in freqs:
            new_dp = dict(dp)
            for (in_mask, out_mask), path in dp.items():
                for u, v in freq_data[freq]:
                    u_bit = 1 << (u - 1)
                    v_bit = 1 << (v - 1)
                    if not (in_mask & u_bit) and not (out_mask & v_bit):
                        ns = (in_mask | u_bit, out_mask | v_bit)
                        if ns not in new_dp:
                            new_dp[ns] = path + [(freq, u, v)]
            dp = new_dp
        return dp
    
    dp1 = compute_states(freqs1)
    dp2 = compute_states(freqs2)
    
    for (in1, out1), path1 in dp1.items():
        key2 = (full_mask & ~in1, full_mask & ~out1)
        if key2 in dp2:
            result = path1 + dp2[key2]
            print("YES")
            for freq, u, v in result:
                print(f"{u} {v} {freq}")
            return
    
    print("NO")

solve()
