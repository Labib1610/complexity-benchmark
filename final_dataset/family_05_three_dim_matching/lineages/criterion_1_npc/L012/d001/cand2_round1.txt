<STATEMENT>
# Problem A — Resonance Calibration

Time limit: 5 s
Memory limit: 256 MB

## Description

A geological scanner operates in a subterranean grid. Positions in this grid are defined by three coordinates: stratum, parallel, and meridian. Each coordinate takes a positive integer value up to the grid's dimension **k**. 

The scanner has identified **t** candidate resonance pockets at specific locations. 

To calibrate the scanning array, you must activate a configuration of these candidate pockets. A successful calibration must probe the environment comprehensively but without redundancy. Specifically, the activated configuration must be chosen such that each individual stratum contains exactly one activated pocket, each individual parallel contains exactly one activated pocket, and each individual meridian contains exactly one activated pocket.

Determine whether such a configuration is possible, and if so, report the locations of the pockets you choose to activate.

## Input

The first line contains two integers **k** and **t**: the grid dimension and the number of candidate resonance pockets. The grid dimension **k** is a positive integer bounded by the scanner's 22 available calibration frequencies. The number of candidate pockets **t** can be anywhere from zero up to the theoretical maximum where every discrete location in the cubic grid contains one.

Each of the next **t** lines contains three integers **x**, **y**, **z**, representing the stratum, parallel, and meridian of a candidate pocket. Constraints on the coordinates are defined by the grid dimension. No location is listed more than once.

## Output

If a valid configuration of pockets exists, print `YES` on the first line. Then, output the locations of the activated pockets, one per line, as three space-separated integers `x y z`. Any valid configuration is accepted, and the pockets may be printed in any order.

If no such configuration is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both candidate pockets are located at parallel 1. Any configuration that activates both would result in parallel 1 containing two pockets, while activating only one would leave either a stratum or a meridian unoccupied. Thus, a comprehensive and non-redundant calibration cannot be achieved.
</STATEMENT>
<RATIONALE>
The explicit instruction to "select exactly k pockets" and the framing of "interference" (no two pockets share a coordinate) have been removed. Instead, the problem requires that each coordinate plane contains exactly one activated pocket, forcing the model to deduce that exactly $k$ pockets must be chosen and that they form a 3-dimensional matching. Numeric bounds are now presented indirectly as physical limits rather than bare inequalities, requiring the model to extract the constraints from the scenario.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that each stratum, parallel, and meridian contains exactly one activated pocket mathematically forces the selection of exactly $k$ pockets with mutually distinct coordinates on all three axes, which is identical to the original interference and cardinality rules.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching, a known NP-complete problem, as it asks for a subset of triples such that each element in three disjoint sets of size $k$ appears exactly once.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "contains exactly one activated pocket" as applying to lines or points rather than coordinate planes (e.g., $x=c$), but the phrasing "each individual stratum" combined with the definition of stratum as a coordinate strongly points to the intended meaning.
</RISK>
