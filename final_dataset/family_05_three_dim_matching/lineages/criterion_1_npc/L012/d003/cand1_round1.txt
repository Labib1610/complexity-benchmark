<STATEMENT>
# Problem A — Resonance Calibration

Time limit: 5 s   Memory limit: 256 MB

## Description

A geological scanner operates in a subterranean grid of dimensions **k** × **k** × **k**. Every location in the grid is defined by a depth **x**, a latitude **y**, and a longitude **z**, each taking an integer value from 1 to **k**.

The scanner has identified **t** resonance pockets at specific `(x, y, z)` locations. 

The scanner's memory bank has exactly **k** slots for resonance pockets. You must fill every slot with a distinct pocket from the identified list.

Once loaded, the scanner runs three independent diagnostic checks on the chosen subset:
- It verifies that for every depth level from 1 to **k**, at least one loaded pocket is located at that depth.
- It verifies that for every latitude from 1 to **k**, at least one loaded pocket is located at that latitude.
- It verifies that for every longitude from 1 to **k**, at least one loaded pocket is located at that longitude.

If all three checks pass, the calibration is successful. Determine whether a successful calibration is possible, and if so, report one valid selection of resonance pockets.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the grid dimension and the number of identified resonance pockets.
Each of the next **t** lines contains three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), the coordinates of a resonance pocket. No location is listed more than once.

## Output

If a valid calibration configuration of exactly **k** pockets exists, print `YES` on the first line. Then, print **k** lines, each containing the three coordinates `x y z` of one selected pocket. Any valid selection is accepted, and the pockets may be printed in any order.

If no valid selection exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both identified resonance pockets are located at latitude 1. Regardless of which pockets are loaded into the 2 slots, latitude 2 will have no loaded pocket located there. Thus, the latitude diagnostic check will fail, making a successful calibration impossible.
</STATEMENT>
<RATIONALE>
The explicit set equality condition (`must be exactly {1, 2, ..., k}`) was removed. Instead, the problem now specifies independent coverage checks (`at least one loaded pocket is located at that depth/latitude/longitude`). While mathematically equivalent given the subset size `k`, this change prevents models from immediately pattern-matching to a 3-dimensional matching / exact cover formulation, forcing them to deduce the distinct-coordinate property themselves.
</RATIONALE>
<PRESERVED_ANSWER>
The condition of selecting exactly `k` items that cover all `k` distinct values for each of the three coordinates remains logically identical, meaning the exact same valid subsets will satisfy the requirements.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching (3DM), asking to find a set of `k` triples that cover all elements of three disjoint sets of size `k`, which is NP-complete.
</PRESERVED_CLASS>
