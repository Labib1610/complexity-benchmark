 We need to check if we can pick exactly k points from the given t points such that for every pair, the 3D Manhattan distance is strictly greater than each of the three 2D projection distances.

Let’s analyze the condition.

For two points \( (x_1, y_1, z_1) \) and \( (x_2, y_2, z_2) \):

- 3D distance: \( d_3 = |x_1 - x_2| + |y_1 - y_2| + |z_1 - z_2| \)
- XY projection: \( d_{xy} = |x_1 - x_2| + |y_1 - y_2| \)
- XZ projection: \( d_{xz} = |x_1 - x_2| + |z_1 - z_2| \)
- YZ projection: \( d_{yz} = |y_1 - y_2| + |z_1 - z_2| \)

We require:
\[
d_3 > d_{xy}, \quad d_3 > d_{xz}, \quad d_3 > d_{yz}
\]

Notice:
- \( d_3 > d_{xy} \) means \( |z_1 - z_2| > 0 \) → z coordinates must differ.
- \( d_3 > d_{xz} \) means \( |y_1 - y_2| > 0 \) → y coordinates must differ.
- \( d_3 > d_{yz} \) means \( |x_1 - x_2| > 0 \) → x coordinates must differ.

So the condition is equivalent to: **any two chosen points must differ in all three coordinates**.

That means: no two chosen points can share the same x, same y, or same z.

We need to select k points from the given set such that all x, y, z are distinct among chosen points.

This is a 3D matching problem: we have a set of points, and we need to pick k points with all coordinates distinct.

Since k ≤ 22, we can use a backtracking / DFS with pruning, or a maximum matching approach.

We can model it as:  
We have three sets: X = {1..k}, Y = {1..k}, Z = {1..k}.  
Each point is a triple (x, y, z). We need to select k triples such that no two share any coordinate.

This is exactly a 3-dimensional matching problem, which is NP-hard in general, but with k ≤ 22 and t ≤ k³, we can use backtracking with pruning.

We can sort points and try to assign them one by one, keeping used sets for x, y, z.

Because k is small (≤22), backtracking should be fast enough if we prune well.

We can also use a bipartite matching approach:  
First, we can fix an ordering of x values, and for each x, we need to pick a distinct y and z. This is like a bipartite matching between y and z for each x, but we need to pick exactly one point per x value (if possible). However, we don't necessarily need to use all x values — we just need k points, and each x can be used at most once.

We can do a DFS over x values from 1..k, and for each x, try all points with that x that have unused y and z. This is a standard exact cover / matching.

Given k ≤ 22, the worst-case branching is manageable.

Let’s implement a recursive backtracking:

- Sort points by x, then y, then z.
- Keep arrays used_y, used_z of size k+1 (1-indexed).
- DFS(index, count):  
  - If count == k: success.
  - If index == t: fail.
  - Try to skip current point.
  - If x, y, z all unused, try taking it, mark used, recurse, unmark.

We can also add a heuristic: if remaining points < k - count, prune.

Let’s code it.

```python
import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))
    points = []
    for _ in range(t):
        x = int(next(it))
        y = int(next(it))
        z = int(next(it))
        points.append((x, y, z))
    
    # Sort points for better pruning
    points.sort()
    
    used_x = [False] * (k + 1)
    used_y = [False] * (k + 1)
    used_z = [False] * (k + 1)
    chosen = []
    
    def dfs(idx, count):
        if count == k:
            return True
        if idx == t:
            return False
        if t - idx < k - count:
            return False
        
        x, y, z = points[idx]
        
        # Try skipping
        if dfs(idx + 1, count):
            return True
        
        # Try taking if possible
        if not used_x[x] and not used_y[y] and not used_z[z]:
            used_x[x] = True
            used_y[y] = True
            used_z[z] = True
            chosen.append((x, y, z))
            if dfs(idx + 1, count + 1):
                return True
            chosen.pop()
            used_x[x] = False
            used_y[y] = False
            used_z[z] = False
        
        return False
    
    if dfs(0, 0):
        print("YES")
        for p in chosen:
            print(p[0], p[1], p[2])
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
