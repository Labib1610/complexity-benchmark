<STATEMENT>
# Problem A — Protocol Deployment

Time limit: 5 s   Memory limit: 256 MB

## Description

You are overseeing a communications network that requires establishing a full array of operational protocols. Each protocol is defined by three independent parameters: a frequency band, a spatial sector, and a temporal phase. Each parameter is identified by an integer from $1$ to $k$.

You are provided with a raw log of certified protocols. Each entry in the log is a triplet $(x, y, z)$, which specifies that frequency band $x$, spatial sector $y$, and temporal phase $z$ can be combined into a stable protocol. 

Your objective is to authorize a deployment $D$, which must be a subset of exactly $k$ protocols chosen from the log. To ensure maximum network coverage, the deployment must satisfy a specific diversity metric. Let $c_1$ be the number of distinct frequency bands present in $D$, $c_2$ be the number of distinct spatial sectors present in $D$, and $c_3$ be the number of distinct temporal phases present in $D$. The deployment is considered valid if and only if $c_1 + c_2 + c_3 \ge 3k$.

Determine whether such a deployment is possible. If it is, output the protocols that form the deployment.

## Input

The first line contains two integers $k$ and $t$ ($1 \le k \le 22$, $0 \le t \le k^3$), denoting the parameter bound (which is also the required number of protocols) and the total number of certified protocols in the log.
The next $t$ lines each contain three integers $x$, $y$, and $z$ ($1 \le x, y, z \le k$), detailing a certified protocol. No protocol appears more than once in the log.

## Output

If a valid deployment of $k$ protocols is possible, print `YES` on the first line. Then, print $k$ lines, each containing the three integers $x$ $y$ $z$ of an authorized protocol. The chosen protocols can be printed in any order. Any valid deployment will be accepted.

If no such deployment is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, the chosen set $D$ must contain $k=2$ protocols. If we select both available protocols, we have $D = \{(1, 1, 1), (2, 1, 2)\}$. The number of distinct frequency bands is $c_1 = 2$ (bands 1 and 2), the number of distinct spatial sectors is $c_2 = 1$ (sector 1), and the number of distinct temporal phases is $c_3 = 2$ (phases 1 and 2). The sum of these diversity metrics is $2 + 1 + 2 = 5$. Since $5$ is not at least $3k$ (which is $6$), this is not a valid deployment.
</STATEMENT>

Replaced the explicit "no two may share" exact-cover constraint with an algebraic inequality on the sum of distinct coordinate values. This forces the model to mathematically deduce that $c_1, c_2, c_3$ must all exactly equal $k$, which implies the intersectionless property required for efficient backtracking pruning.
</RATIONALE>
<PRESERVED_ANSWER>
Since the coordinate domain is $1..k$ and the subset size is $k$, the condition $c_1 + c_2 + c_3 \ge 3k$ is mathematically equivalent to requiring exactly $k$ distinct values for each parameter, meaning no two protocols in the subset share any parameter.
</PRESERVED_ANSWER>
