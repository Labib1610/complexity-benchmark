# Problem A — Deep Space Relays

Time limit: 5 s   Memory limit: 256 MB

## Description

You are designing a communication array and must select exactly $k$ relay configurations from a provided catalog.

You are given a log of $t$ candidate relays. Each candidate is specified by a triplet of integers $(x, y, z)$, where each integer is between $1$ and $k$ inclusive.

To prevent signal interference, the chosen $k$ relays must satisfy a specific energy signature condition across all three of their parameters. 

Specifically, let the target signature $S = 6^1 + 6^2 + \dots + 6^k$. 
For a chosen set of $k$ relays, if you calculate $6^x$ for each chosen relay and sum these values, the total must exactly equal $S$. 
Similarly, calculating and summing $6^y$ for the $k$ chosen relays must exactly equal $S$, and doing the same for $6^z$ must also equal $S$.

Determine whether it is possible to select exactly $k$ relays that meet this requirement. If it is, output the $k$ chosen relays.

## Input

The first line contains two integers $k$ and $t$ ($1 \le k \le 22$, $0 \le t \le k^3$), denoting the required number of relays (which is also the upper bound for any parameter) and the total number of candidate relays in the log.
The next $t$ lines each contain three integers $x$, $y$, and $z$ ($1 \le x, y, z \le k$), detailing a candidate relay. No relay appears more than once in the log.

## Output

If a valid selection of $k$ relays is possible, print `YES` on the first line. Then, print $k$ lines, each containing the three integers $x$ $y$ $z$ of a chosen relay. The chosen relays can be printed in any order. Any valid selection will be accepted.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, $k=2$, so the target signature $S = 6^1 + 6^2 = 42$. 
If we select both available candidate relays, their $y$ parameters are $1$ and $1$. 
The sum of $6^y$ for these chosen relays is $6^1 + 6^1 = 12$, which does not equal $42$. 
Therefore, it is impossible to select 2 relays that satisfy the energy signature condition.

<PRESERVED_ANSWER>
Because the maximum possible carry in base 6 for $k \le 22$ is mathematically insufficient to bridge the gap between powers, the sum $\sum_{i=1}^k 6^{v_i} = \sum_{i=1}^k 6^i$ is satisfied if and only if the multiset $\{v_i\}$ is exactly $\{1, \dots, k\}$, making it strictly equivalent to the original distinctness condition.
</PRESERVED_ANSWER>
