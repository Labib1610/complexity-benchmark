# Problem A — Deep Space Relays

Time limit: 5 s   Memory limit: 256 MB

## Description

You are designing a communication array and must select exactly $k$ relay configurations from a provided catalog.

You are given a log of $t$ candidate relays. Each candidate is specified by a triplet of integers $(a, b, c)$.

To prevent signal interference, the $k$ chosen relays must satisfy a strict global isolation metric. Let the chosen relays be indexed from $1$ to $k$, such that the $i$-th chosen relay is $(a_i, b_i, c_i)$. The selection is valid if and only if the following product over all pairs of distinct chosen relays is strictly greater than zero:

$$ \prod_{1 \le i < j \le k} (a_i - a_j)^2 (b_i - b_j)^2 (c_i - c_j)^2 > 0 $$

This mathematical condition ensures that no two chosen relays share the same first, second, or third parameter. For $k=1$, the empty product is defined as $1$, so the condition holds.

Determine whether it is possible to select exactly $k$ valid relays from the log. If it is, output the $k$ chosen relays.

## Input

The first line contains two integers $k$ and $t$ ($1 \le k \le 22$, $0 \le t \le k^3$), denoting the required number of relays and the total number of candidate relays in the log. Each coordinate value of a candidate relay is guaranteed to lie in the range from $1$ to $k$ inclusive.

The next $t$ lines each contain three integers $a$, $b$, and $c$ ($1 \le a, b, c \le k$), detailing a candidate relay. No relay appears more than once in the log.

## Output

If a valid selection of $k$ relays is possible, print `YES` on the first line. Then, print $k$ lines, each containing the three integers $a$ $b$ $c$ of a chosen relay. The chosen relays can be printed in any order. Any valid selection will be accepted.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, for the two candidate relays $(1, 1, 1)$ and $(2, 1, 2)$, the isolation product is $(1 - 2)^2 \times (1 - 1)^2 \times (1 - 2)^2 = 1 \times 0 \times 1 = 0$. Since the product is not strictly greater than zero, they do not satisfy the isolation condition. It is impossible to select 2 relays that satisfy the requirement.

Removed the structural giveaway word "trivially" that triggered the gate rejection. Replaced the clumsy "upper bound for any parameter" wording with a direct constraint restatement. Added an explicit equivalence sentence clarifying the product condition to ensure perfect clarity while maintaining the algebraic disguise, preventing the model from immediately treating the search space as a combinatorial set-cover problem.

<PRESERVED_ANSWER>
The condition that the product of squared differences is strictly greater than zero is mathematically equivalent to requiring that all chosen relays have distinct values in each coordinate position, which is exactly the seed's isolation constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching, as selecting $k$ triplets from a space of size $k$ with mutually distinct coordinates in all three dimensions is the standard definition of the NP-complete 3DM problem.
