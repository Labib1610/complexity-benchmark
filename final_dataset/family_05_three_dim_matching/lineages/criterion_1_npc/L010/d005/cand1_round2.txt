<STATEMENT>
# Problem A — Deep Space Relays

Time limit: 5 s   Memory limit: 256 MB

## Description

You are designing a communication array and must select exactly $k$ relay configurations from a provided catalog.

You are given a log of $t$ candidate relays. Each candidate is specified by a triplet of integers $(x, y, z)$, where each integer is between $1$ and $k$ inclusive.

To prevent signal interference, the chosen $k$ relays must satisfy a global non-degeneracy condition. Let the $k$ chosen relays be arbitrarily indexed from $1$ to $k$, where the $i$-th chosen relay is represented by the triplet $(x_i, y_i, z_i)$. A selection of exactly $k$ relays is valid if and only if the following product is strictly greater than zero:

$$ \prod_{1 \le i < j \le k} \left( (x_i - x_j)^2 \cdot (y_i - y_j)^2 \cdot (z_i - z_j)^2 \right) > 0 $$

For $k=1$, the product is empty and the condition is considered trivially satisfied.

Determine whether it is possible to select exactly $k$ candidate relays from the log such that this condition is satisfied. If it is, output the $k$ chosen relays.

## Input

The first line contains two integers $k$ and $t$ ($1 \le k \le 22$, $0 \le t \le k^3$), denoting the required number of relays (which is also the upper bound for any parameter) and the total number of candidate relays in the log.
The next $t$ lines each contain three integers $x$, $y$, and $z$ ($1 \le x, y, z \le k$), detailing a candidate relay. No relay appears more than once in the log.

## Output

If a valid selection of $k$ relays is possible, print `YES` on the first line. Then, print $k$ lines, each containing the three integers $x$ $y$ $z$ of a chosen relay. The chosen relays can be printed in any order. Any valid selection will be accepted.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, any selection of $k=2$ relays must satisfy the non-degeneracy condition. If we select the only two available relays, let relay 1 be $(1, 1, 1)$ and relay 2 be $(2, 1, 2)$. The product evaluates to:
$$((1 - 2)^2 \cdot (1 - 1)^2 \cdot (1 - 2)^2) = (1 \cdot 0 \cdot 1) = 0$$
Since $0$ is not strictly greater than zero, this selection is invalid. It is impossible to select 2 valid relays.
</STATEMENT>
<RATIONALE>
Replaced the pairwise "mutually isolated" textual constraint with a mathematically identical polynomial discriminant condition. This forces the model to algebraically deduce that the product is non-zero if and only if all parameters are pairwise distinct, disrupting the surface-level keywords that instantly trigger Algorithm X and Exact Cover templates.
</RATIONALE>
<PRESERVED_ANSWER>
The product of squared differences is strictly greater than zero if and only if every squared difference is positive, meaning no two chosen relays share an x, y, or z parameter, exactly preserving the original isolation condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching because the underlying requirement—selecting k triplets from a catalog such that no two share any coordinate—is mathematically unchanged.
</PRESERVED_CLASS>
<RISK>
Models failing to simplify the polynomial may attempt to evaluate it directly during the backtracking search, which could lead to Time Limit Exceeded or integer overflow, though this reflects a failure in algorithmic reasoning rather than ambiguity in the problem statement.
</RISK>
