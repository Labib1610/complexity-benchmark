 We need to select exactly \( k \) relays such that no two share the same \( a \), \( b \), or \( c \) value.  
That means we need a set of \( k \) triples where all \( a \)'s are distinct, all \( b \)'s are distinct, and all \( c \)'s are distinct.

Since each coordinate is between 1 and \( k \), this is equivalent to finding a perfect matching in a 3-partite 3-uniform hypergraph, which is a known NP-hard problem in general.  
But here \( k \le 22 \), so we can use backtracking with pruning.

We can model it as:  
We have \( k \) possible values for each coordinate. We need to pick \( k \) triples from the given list such that each value 1..k appears exactly once in each coordinate position.

This is a **3D matching** problem.  
We can solve it with recursive backtracking, trying to assign relays for each value of \( a \) in order.

**Approach:**
- Store relays grouped by their `a` value.
- For each `a` from 1 to k, try each relay with that `a` that hasn't used its `b` or `c` yet.
- Recurse to next `a`.
- If we reach `a = k+1`, we have a solution.

Since \( k \le 22 \) and \( t \le k^3 \), worst-case branching is manageable with pruning.

We'll implement:

```python
import sys

def solve():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    relays = []
    by_a = [[] for _ in range(k+1)]
    for _ in range(t):
        a,b,c = map(int, input().split())
        relays.append((a,b,c))
        by_a[a].append((b,c))
    
    used_b = [False]*(k+1)
    used_c = [False]*(k+1)
    chosen = [None]*(k+1)
    
    def dfs(a):
        if a > k:
            return True
        for b,c in by_a[a]:
            if not used_b[b] and not used_c[c]:
                used_b[b] = True
                used_c[c] = True
                chosen[a] = (a,b,c)
                if dfs(a+1):
                    return True
                used_b[b] = False
                used_c[c] = False
        return False
    
    if dfs(1):
        print("YES")
        for a in range(1,k+1):
            print(*chosen[a])
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
