We need to select exactly \( k \) relays such that for each of the three channel types, the determinant of the corresponding matrix is non-zero.  

The key observation: For a matrix \( M \) where \( M_{i,j} = \min(a_i, j) \), the determinant is non-zero if and only if the multiset of \( a_i \) values is exactly \(\{1, 2, \dots, k\}\) (i.e., a permutation of 1..k).  

Why?  
- If two rows have the same \( a_i \), they are identical → determinant zero.  
- If some value \( v \) in 1..k is missing, then the column \( v \) will be all 1's for rows with \( a_i \ge v \), and rows with \( a_i < v \) have 1's in that column too, causing linear dependence.  
- If the values are a permutation, the matrix is upper triangular after sorting rows by \( a_i \), with diagonal entries 1, so determinant = ±1.

Thus, the problem reduces to:  
We need to pick \( k \) relays such that for each of the three coordinates, the set of values is exactly \(\{1, 2, \dots, k\}\).  

So each coordinate must be a permutation of 1..k.  

We can model this as a matching problem:  
We need to select \( k \) triples from the given list such that each coordinate covers all numbers 1..k exactly once.  

This is a 3-dimensional matching problem, which is NP-hard in general, but here \( k \le 22 \) and \( t \le k^3 \). We can use backtracking with pruning, or reduce to bipartite matching per coordinate?  

Actually, we can think of it as: we need to assign each number 1..k to a relay for each coordinate, but each relay is used once. This is a 3D matching, but with small k we can do backtracking with bitmasks.

We can do DFS:  
- State: which numbers are used in coordinate a, b, c (bitmasks).  
- At each step, pick a relay that has unused numbers in all three coordinates.  
- If we reach k relays, success.  

Since k ≤ 22, bitmask fits in an integer. We can pre-filter relays that have all three values distinct? Not necessary, but we can prune.

We also need to output the chosen relays.

Let's implement backtracking with memoization on (mask_a, mask_b, mask_c, idx) but idx up to t (≤ 22^3 = 10648) and masks up to 2^22, too big for full memo. But we can do DFS with pruning:  
- Sort relays by some heuristic.  
- Use bitmask to track used numbers.  
- At each step, try relays that have all three numbers unused.  

Since k ≤ 22, worst-case branching could be large, but with pruning and small k it should pass in 5s.

Let's code it.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    k = int(next(it))
    t = int(next(it))
    relays = []
    for _ in range(t):
        a = int(next(it))
        b = int(next(it))
        c = int(next(it))
        relays.append((a, b, c))
    
    # Pre-filter: each relay must have all values <= k (given) and we need each coordinate to be a permutation.
    # We'll do DFS.
    
    # Sort relays maybe by some heuristic: e.g., by sum of values or by rarity.
    # We'll just keep original order.
    
    full_mask = (1 << k) - 1
    chosen = []
    
    # We'll use recursion with bitmasks.
    # To speed up, we can precompute for each relay the bit for each coordinate.
    relay_bits = []
    for a, b, c in relays:
        if 1 <= a <= k and 1 <= b <= k and 1 <= c <= k:
            relay_bits.append((1 << (a-1), 1 << (b-1), 1 << (c-1), (a,b,c)))
        # else skip? But constraints say all <= k, so no skip needed.
    
    # We'll do DFS with pruning: if remaining relays < needed, fail.
    # Also, we can check if for each coordinate, the number of unused values equals number of remaining relays.
    
    def dfs(mask_a, mask_b, mask_c, start_idx, chosen_list):
        if len(chosen_list) == k:
            return True
        # Prune: if not enough relays left
        if start_idx >= len(relay_bits):
            return False
        # Prune: if any coordinate has more unused values than remaining slots
        remaining = k - len(chosen_list)
        if bin(mask_a).count("1") != remaining or bin(mask_b).count("1") != remaining or bin(mask_c).count("1") != remaining:
            return False
        
        for i in range(start_idx, len(relay_bits)):
            ba, bb, bc, triple = relay_bits[i]
            if (mask_a & ba) == 0 and (mask_b & bb) == 0 and (mask_c & bc) == 0:
                chosen_list.append(triple)
                if dfs(mask_a | ba, mask_b | bb, mask_c | bc, i+1, chosen_list):
                    return True
                chosen_list.pop()
        return False
    
    if dfs(0, 0, 0, 0, chosen):
        print("YES")
        for a,b,c in chosen:
            print(a,b,c)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
