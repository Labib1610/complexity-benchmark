# Problem A — Deep Space Relays

Time limit: 5 s   Memory limit: 256 MB

## Description

You are designing a communication array and must select exactly $k$ relay configurations from a provided catalog.

You are given a log of $t$ candidate relays. Each candidate is specified by a triplet of positive integers $(a, b, c)$, representing its primary, secondary, and tertiary channel assignments.

When a relay is activated, each of its channels emits a harmonic signature based on its assignment. The signature value $H(x)$ of a channel assignment $x$ is defined recursively:
- $H(1) = 1$
- $H(x) = 23 \cdot H(x-1) + 1$ for all integers $x > 1$.

To ensure the array operates without signal collapse, the selected relays must form a harmonically stable network. A selection of exactly $k$ relays is considered valid if and only if it satisfies all three of the following conditions (where $a_i, b_i, c_i$ denote the primary, secondary, and tertiary channels of the $i$-th chosen relay):
1. The sum of their primary channel signatures, $\sum_{i=1}^k H(a_i)$, is exactly equal to $T_k$.
2. The sum of their secondary channel signatures, $\sum_{i=1}^k H(b_i)$, is exactly equal to $T_k$.
3. The sum of their tertiary channel signatures, $\sum_{i=1}^k H(c_i)$, is exactly equal to $T_k$.

Here, $T_k$ is the ideal array signature, defined as $T_k = \sum_{j=1}^k H(j)$.

Determine whether it is possible to select exactly $k$ valid relays from the log. If it is, output the $k$ chosen relays.

## Input

The first line contains two integers $k$ and $t$ ($1 \le k \le 22$, $0 \le t \le k^3$), denoting the required number of relays and the total number of candidate relays in the log. 

The next $t$ lines each contain three integers $a$, $b$, and $c$, detailing a candidate relay. Each parameter of a candidate relay is a positive integer that does not exceed $k$ ($1 \le a, b, c \le k$). No relay appears more than once in the log.

## Output

If a valid selection of exactly $k$ relays is possible, print `YES` on the first line. Then, print $k$ lines, each containing the three integers $a$ $b$ $c$ of a chosen relay. The chosen relays can be printed in any order. Any valid selection will be accepted.

If no such selection is possible, print `NO`.

## Note

In Example 2, the required number of relays is $k=2$. The ideal array signature is $T_2 = H(1) + H(2)$.
Using the formula, $H(1) = 1$ and $H(2) = 23 \cdot 1 + 1 = 24$. So $T_2 = 1 + 24 = 25$.

The two candidate relays are $(1, 1, 1)$ and $(2, 1, 2)$. If we select both of them, we check the validity conditions:
- Primary sum: Their primary channels are $a_1=1$ and $a_2=2$. The sum is $H(1) + H(2) = 1 + 24 = 25$, which exactly equals $T_2$.
- Secondary sum: Their secondary channels are $b_1=1$ and $b_2=1$. The sum is $H(1) + H(1) = 1 + 1 = 2$.

Because the secondary sum ($2$) is not equal to $T_2$ ($25$), this selection is invalid. It is impossible to select 2 relays that satisfy all requirements.
