<METHOD_NAME>Sum of Squares Frequency Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the product of unique element counts with the sum of squares of coordinate frequencies over the chosen set. Because exactly k relays are chosen, the minimum possible sum of squares for each coordinate is k, which occurs if and only if all frequencies are 0 or 1. Thus, the sum equals 3k if and only if the chosen items form a 3-dimensional matching. This hides the exact cover structure behind a non-linear algebraic condition.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Deep Space Relays

Time limit: 5 s   Memory limit: 256 MB

## Description

You are designing a communication array and must select exactly $k$ relay configurations from a provided catalog.

You are given a log of $t$ candidate relays. Each candidate is specified by a triplet of positive integers $(a, b, c)$.

To prevent signal interference, the $k$ chosen relays must satisfy a strict global isolation metric. For any integer $x$, let $c_1(x)$ be the number of chosen relays whose first parameter is $x$, let $c_2(x)$ be the number of chosen relays whose second parameter is $x$, and let $c_3(x)$ be the number of chosen relays whose third parameter is $x$. 

The selection is valid if and only if the sum of the squares of these counts over all possible values of $x$ is exactly $3k$:

$$ \sum_{x} \left( c_1(x)^2 + c_2(x)^2 + c_3(x)^2 \right) = 3k $$

Determine whether it is possible to select exactly $k$ valid relays from the log. If it is, output the $k$ chosen relays.

## Input

The first line contains two integers $k$ and $t$ ($1 \le k \le 22$, $0 \le t \le k^3$), denoting the required number of relays and the total number of candidate relays in the log. 

The next $t$ lines each contain three integers $a$, $b$, and $c$, detailing a candidate relay. Each parameter of a candidate relay is a positive integer that does not exceed $k$ ($1 \le a, b, c \le k$). No relay appears more than once in the log.

## Output

If a valid selection of exactly $k$ relays is possible, print `YES` on the first line. Then, print $k$ lines, each containing the three integers $a$ $b$ $c$ of a chosen relay. The chosen relays can be printed in any order. Any valid selection will be accepted.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, the two candidate relays are $(1, 1, 1)$ and $(2, 1, 2)$. If we select both of them ($k=2$), we determine the counts for each parameter across the chosen relays:
- For the first parameter, $c_1(1) = 1$ and $c_1(2) = 1$. The sum of squares is $1^2 + 1^2 = 2$.
- For the second parameter, $c_2(1) = 2$. The sum of squares is $2^2 = 4$.
- For the third parameter, $c_3(1) = 1$ and $c_3(2) = 1$. The sum of squares is $1^2 + 1^2 = 2$.

The total sum of their squares is $2 + 4 + 2 = 8$. Since $8$ is not equal to $3k = 6$, they do not satisfy the isolation condition. It is impossible to select 2 relays that satisfy the requirement.
</STATEMENT>
<RATIONALE>
The explicit product of cardinalities $|S_1| \times |S_2| \times |S_3| = k^3$ was replaced with an equivalent condition based on the sum of squares of parameter frequencies. Because exactly $k$ items are selected, the minimum possible sum of squares for any coordinate is $k$ (occurring when all frequencies are 0 or 1). Thus, a total sum of $3k$ forces every selected relay to have completely distinct parameters, preserving the exact 3-dimensional matching requirement but hiding it behind a non-linear algebraic formulation.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $\sum c_i(x)^2 = 3k$ for $k$ items is mathematically equivalent to $|S_1| \times |S_2| \times |S_3| = k^3$, so the exact same subsets of relays remain valid.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching, which is NP-complete, because the new condition strictly enforces that all selected triples are disjoint in every coordinate.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the sum over all possible values of $x$ as an infinite sum, though the problem defines counts purely based on the finite set of chosen relays (meaning all other terms are $0^2=0$, which is standard mathematical notation).
</RISK>
