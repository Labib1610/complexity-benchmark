We need to select exactly \( k \) relays from the given \( t \) candidates such that the sum of squares of counts for each parameter value equals \( 3k \).

Let’s break down the condition:

For each coordinate (first, second, third), if we have counts \( c_1(x), c_2(x), c_3(x) \), the condition is:

\[
\sum_x c_1(x)^2 + \sum_x c_2(x)^2 + \sum_x c_3(x)^2 = 3k
\]

Since we select exactly \( k \) relays, the sum of counts for each coordinate is \( k \). The sum of squares is minimized when counts are as equal as possible. For \( k \) items distributed among \( k \) possible values (since parameters are between 1 and \( k \)), the minimum sum of squares for one coordinate is \( k \) (when each value appears exactly once). So the minimum total is \( 3k \).

Thus, the condition is satisfied **only if** for each coordinate, every value from 1 to \( k \) appears exactly once among the selected relays.

That means the selected \( k \) relays must form a **Latin square** pattern: each coordinate is a permutation of \( 1, 2, \dots, k \).

So the problem reduces to:  
Given a set of triples \((a,b,c)\) with \(1 \le a,b,c \le k\), can we choose exactly \( k \) of them such that each number 1..k appears exactly once in each coordinate?

This is equivalent to finding a perfect matching in a 3-partite 3-uniform hypergraph, which is NP-hard in general. But here \( k \le 22 \), so we can use backtracking with pruning.

We can model it as:  
We need to assign each number 1..k to a distinct relay for the first coordinate, and also ensure the second and third coordinates are permutations.

We can do a DFS over the first coordinate values, trying to match each to a candidate relay, while maintaining used sets for second and third coordinates.

Because \( k \) is small (max 22), and \( t \le k^3 \), we can use bitmask DP or backtracking.

Let’s implement a backtracking solution:

- Sort candidates by first coordinate for faster pruning.
- Use bitmasks for used second and third values.
- At each step, pick the first coordinate value with the fewest available candidates (MRV heuristic).

We'll implement it carefully.

```python
import sys

def solve():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    relays = []
    for _ in range(t):
        a, b, c = map(int, input().split())
        relays.append((a-1, b-1, c-1))  # 0-index for bitmask

    # Group by first coordinate
    by_first = [[] for _ in range(k)]
    for idx, (a,b,c) in enumerate(relays):
        by_first[a].append((b,c,idx))

    # For MRV, we need to know which first values are still unassigned
    used_first = 0
    used_second = 0
    used_third = 0
    chosen = [None]*k

    # Precompute for each first value the list of (second, third, relay_index)
    # We'll sort by number of options maybe

    def dfs(mask_first, mask_second, mask_third):
        if mask_first == (1<<k)-1:
            return True
        # Choose the first value with fewest remaining options
        best_val = -1
        best_options = None
        for v in range(k):
            if not (mask_first >> v) & 1:
                opts = []
                for b,c,idx in by_first[v]:
                    if not (mask_second >> b) & 1 and not (mask_third >> c) & 1:
                        opts.append((b,c,idx))
                if best_val == -1 or len(opts) < len(best_options):
                    best_val = v
                    best_options = opts
                    if len(opts) == 0:
                        break
        if not best_options:
            return False
        # Try each option
        for b,c,idx in best_options:
            chosen[best_val] = relays[idx]
            if dfs(mask_first | (1<<best_val), mask_second | (1<<b), mask_third | (1<<c)):
                return True
        return False

    if dfs(0,0,0):
        print("YES")
        for a,b,c in chosen:
            print(a+1, b+1, c+1)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
