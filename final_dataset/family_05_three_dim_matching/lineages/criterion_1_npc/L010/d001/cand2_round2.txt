<STATEMENT>
# Problem A — Crew Assembly

Time limit: 5 s   Memory limit: 256 MB

## Description

A project must assemble complete work crews. There are three distinct categories of resources available:
- specialists (group X), identified by positive integers starting from 1 up to the group size **k**,
- machines (group Y), identified by positive integers starting from 1 up to the group size **k**,
- time slots (group Z), identified by positive integers starting from 1 up to the group size **k**.

A crew requires exactly one specialist, one machine, and one time slot. You are provided with a list of operational deployments `(x, y, z)` that are known to function together.

Your objective is to form a comprehensive schedule from the provided deployments. The schedule is valid if and only if every single specialist, every single machine, and every single time slot is incorporated into some crew, and no specialist, machine, or time slot is assigned to more than one crew. 

Determine whether such a schedule is possible. If it is, output one valid configuration of crews.

## Input

The first line contains two integers **k** and **t**. The group size **k** requires a minimum of 1 member and cannot exceed the facility's strict capacity limit of 22. The deployment count **t** has a minimum of 0 and a maximum equal to the total theoretical combinations (**k** times **k** times **k**).
Each of the next **t** lines contains three integers **x**, **y**, and **z**, representing an operational deployment. Because these are valid identifiers within their groups, they range from a minimum of 1 to a maximum of **k**. No deployment is listed more than once.

## Output

If a valid schedule exists, print `YES` on the first line, followed by **k** lines. Each of these **k** lines must contain the three members `x y z` of one crew in the schedule. Any valid schedule is accepted; the crews may be printed in any order.

If no valid schedule exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both operational deployments require machine 1, meaning machine 2 cannot be covered.
