We need to select exactly \( k \) relays such that for each of the three coordinates (a, b, c), the corresponding \( k \times k \) matrix (rows = relays, columns = channel values) has a non-zero determinant.

This is equivalent to: for each coordinate, the selected relays must have distinct values from 1 to \( k \), and all \( k \) values must appear exactly once.  
So each coordinate must be a permutation of \( 1, 2, \dots, k \).

Thus, we need to find \( k \) relays such that:
- The first coordinates are a permutation of 1..k
- The second coordinates are a permutation of 1..k
- The third coordinates are a permutation of 1..k

This is a 3D matching / permutation problem. Since \( k \le 22 \), we can use backtracking with pruning.

We can model it as:  
We need to pick \( k \) triples from the given list, one for each value of the first coordinate, such that the second and third coordinates are also permutations.

We can do DFS over the first coordinate values 1..k, trying to assign a relay for each.  
We keep track of used second and third values.

We also need to handle the case \( t = 0 \) → impossible unless \( k = 0 \), but \( k \ge 1 \).

Let’s implement:

```python
import sys

def solve():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    relays = []
    for _ in range(t):
        a, b, c = map(int, input().split())
        relays.append((a, b, c))
    
    # Group relays by first coordinate
    by_a = [[] for _ in range(k+1)]
    for r in relays:
        by_a[r[0]].append(r)
    
    # If any first coordinate missing, impossible
    for i in range(1, k+1):
        if not by_a[i]:
            print("NO")
            return
    
    used_b = [False]*(k+1)
    used_c = [False]*(k+1)
    chosen = [None]*(k+1)
    
    def dfs(a):
        if a == k+1:
            return True
        for (x, b, c) in by_a[a]:
            if not used_b[b] and not used_c[c]:
                used_b[b] = True
                used_c[c] = True
                chosen[a] = (x, b, c)
                if dfs(a+1):
                    return True
                used_b[b] = False
                used_c[c] = False
        return False
    
    if dfs(1):
        print("YES")
        for a in range(1, k+1):
            print(*chosen[a])
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
