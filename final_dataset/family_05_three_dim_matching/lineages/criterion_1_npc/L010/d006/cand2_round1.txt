# Problem A — Deep Space Relays

Time limit: 5 s   Memory limit: 256 MB

## Description

You are designing a communication array and must select exactly $k$ relay configurations from a provided catalog.

You are given a log of $t$ candidate relays. Each candidate is specified by a triplet of integers $(a, b, c)$.

Each candidate relay generates a unique harmonic signature, calculated as:
$$ H(a, b, c) = 2^a + 2^{b + 30} + 2^{c + 60} $$

To prevent signal interference and achieve perfect resonance, the $k$ chosen relays must have a combined harmonic signature exactly equal to the ideal system resonance $R_k$. The ideal system resonance for an array of size $k$ is defined as:
$$ R_k = \sum_{j=1}^k \left( 2^j + 2^{j + 30} + 2^{j + 60} \right) $$

Determine whether it is possible to select exactly $k$ relays from the log such that the sum of their harmonic signatures is exactly $R_k$. If it is, output the $k$ chosen relays.

## Input

The first line contains two integers $k$ and $t$ ($1 \le k \le 22$, $0 \le t \le k^3$), denoting the required number of relays and the total number of candidate relays in the log. Each coordinate value of a candidate relay is guaranteed to lie in the range from $1$ to $k$ inclusive.

The next $t$ lines each contain three integers $a$, $b$, and $c$ ($1 \le a, b, c \le k$), detailing a candidate relay. No relay appears more than once in the log.

## Output

If a valid selection of $k$ relays is possible, print `YES` on the first line. Then, print $k$ lines, each containing the three integers $a$ $b$ $c$ of a chosen relay. The chosen relays can be printed in any order. Any valid selection will be accepted.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, the ideal system resonance for $k=2$ is $R_2 = (2^1 + 2^{31} + 2^{61}) + (2^2 + 2^{32} + 2^{62})$. 
The log provides two relays:
- $(1, 1, 1)$ with signature $2^1 + 2^{31} + 2^{61}$
- $(2, 1, 2)$ with signature $2^2 + 2^{31} + 2^{62}$

If we select both relays, their combined signature is $(2^1 + 2^2) + (2 \times 2^{31}) + (2^{61} + 2^{62})$. 
Because the $b$-components sum to $2 \times 2^{31} = 2^{32}$ instead of $2^{31} + 2^{32}$, the combined signature does not equal $R_2$. It is impossible to select 2 relays that satisfy the requirement.
