<STATEMENT>
# Problem A — Squad Assembly

Time limit: 5 s   Memory limit: 256 MB

## Description

You oversee a critical manufacturing operation utilizing $k$ technicians, $k$ fabrication units, and $k$ production shifts. Every resource across these three domains is tagged with an identifier ranging from $1$ to $k$.

An operational squad is formed by grouping exactly one technician, one fabrication unit, and one production shift. Not all groupings are viable; you are provided with a log of approved configurations $(x, y, z)$, meaning technician $x$, unit $y$, and shift $z$ can seamlessly function together. 

Be warned that the provided log is deliberately adversarial. The data can be exceptionally dense, and the configurations are intentionally ordered to defeat constrained-first branching logic. Furthermore, the instances are explicitly selected to maximize the size of the search tree.

Your objective is to assemble exactly $k$ squads from the approved log to fulfill the operation's requirements. A set of squads is only acceptable if it completely consumes all available assets—each technician, each fabrication unit, and each production shift must appear in exactly one of the $k$ established squads.

Determine whether such an arrangement can be achieved and, if so, output the configurations that constitute the squads.

## Input

The first line contains two integers $k$ and $t$ ($1 \le k \le 22$, $0 \le t \le k^3$), denoting the count of each resource type and the total number of approved configurations.
The subsequent $t$ lines each provide three integers $x$, $y$, and $z$ ($1 \le x, y, z \le k$), detailing a single approved configuration. All configurations in the log are strictly unique.

## Output

If exactly $k$ acceptable squads can be assembled, print `YES` on the first line. Then, print $k$ lines, each containing the identifiers $x$ $y$ $z$ of an assembled squad. The squads can be printed in any sequence, and any valid arrangement is accepted.

If no such arrangement exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both viable configurations demand fabrication unit 1. Thus, it is not possible to assign unit 2 to any squad, meaning no valid arrangement can be formed.
