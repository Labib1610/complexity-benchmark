<STATEMENT>
# Problem A — Squad Assembly

Time limit: 5 s   Memory limit: 256 MB

## Description

You are overseeing a manufacturing operation that requires $k$ technicians, $k$ hardware units, and $k$ operational shifts. Each technician, hardware unit, and shift is assigned a distinct identification number from $1$ to $k$.

A complete work squad consists of exactly one technician, one hardware unit, and one shift. However, they cannot be mixed arbitrarily. You are provided with a raw log of certified configurations. Each configuration is a triplet $(x, y, z)$, which specifies that technician $x$, hardware unit $y$, and shift $z$ are compatible and can operate together as a squad. 

Your objective is to authorize exactly $k$ configurations from the log to form a deployment. For the deployment to be valid, every single available resource must be fully utilized. This means that across the $k$ authorized squads, each of the $k$ technicians, each of the $k$ hardware units, and each of the $k$ shifts must be included exactly once.

Determine whether such a deployment is possible. If it is, output the configurations that form the squads.

## Input

The first line contains two integers $k$ and $t$ ($1 \le k \le 22$, $0 \le t \le k^3$), denoting the number of each type of resource and the total number of certified configurations in the log.
The next $t$ lines each contain three integers $x$, $y$, and $z$ ($1 \le x, y, z \le k$), detailing a certified configuration. No configuration appears more than once in the log.

## Output

If a valid deployment of $k$ squads is possible, print `YES` on the first line. Then, print $k$ lines, each containing the three integers $x$ $y$ $z$ of an authorized configuration. The chosen configurations can be printed in any order. Any valid deployment will be accepted.

If no such deployment is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both certified configurations require hardware unit 1. Consequently, it is impossible to incorporate hardware unit 2 into any squad, meaning a valid deployment cannot be formed.
