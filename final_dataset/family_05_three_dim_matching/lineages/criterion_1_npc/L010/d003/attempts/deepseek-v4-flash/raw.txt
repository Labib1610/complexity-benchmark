We need to select exactly \( k \) triples \((x, y, z)\) such that all \( x \), all \( y \), and all \( z \) are distinct.  
This is a 3D matching problem, but with \( k \le 22 \), we can solve it with backtracking and pruning.

We can model it as:  
- We have sets of available \( x \), \( y \), \( z \) values.  
- We need to pick \( k \) triples from the given list, each using a unique \( x \), \( y \), and \( z \).

A direct backtracking over triples works if we sort and prune well.  
We can also use bitmask DP:  
- State: mask of used \( x \) and used \( y \) (since \( z \) is determined by count).  
- But \( k \) up to 22 means \( 2^{22} \) is too large for full DP with two masks.  
So backtracking with ordering and pruning is better.

We'll:
1. Store triples in a list.
2. Sort them (e.g., by x, then y, then z) to help pruning.
3. Use recursion: at each step, try to pick a triple whose x, y, z are all unused.
4. Keep track of used x, y, z via boolean arrays.
5. If we reach k triples, output them.

We also add a pruning: if at any point the number of remaining triples that can still be used (with unused x,y,z) is less than needed, backtrack.

Let's implement.

```python
import sys

def solve():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    triples = []
    for _ in range(t):
        x, y, z = map(int, input().split())
        triples.append((x-1, y-1, z-1))  # 0-index for bitmasking
    
    # Sort for better pruning
    triples.sort()
    
    used_x = [False]*k
    used_y = [False]*k
    used_z = [False]*k
    
    chosen = []
    
    # Precompute for pruning: for each index, list of triples that can still be used
    # We'll just do simple recursion with pruning by counting available triples
    
    def backtrack(start, count):
        if count == k:
            return True
        # Prune: if not enough triples left
        remaining = 0
        for i in range(start, t):
            x, y, z = triples[i]
            if not used_x[x] and not used_y[y] and not used_z[z]:
                remaining += 1
        if remaining < k - count:
            return False
        
        for i in range(start, t):
            x, y, z = triples[i]
            if not used_x[x] and not used_y[y] and not used_z[z]:
                # choose
                used_x[x] = used_y[y] = used_z[z] = True
                chosen.append((x+1, y+1, z+1))
                if backtrack(i+1, count+1):
                    return True
                # backtrack
                chosen.pop()
                used_x[x] = used_y[y] = used_z[z] = False
        return False
    
    if backtrack(0, 0):
        print("YES")
        for x, y, z in chosen:
            print(x, y, z)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
