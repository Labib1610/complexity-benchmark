We can model this as a bipartite matching problem between agents and frequencies, since the alias is already fixed for each agent.

We have:
- Each agent `x` has a fixed alias `y`.
- For each allowed combination `(x, y, z)`, we know that agent `x` can use frequency `z`.

We need to assign each agent a distinct frequency such that every frequency is used exactly once. This is a perfect matching problem in a bipartite graph (agents on one side, frequencies on the other).

We can solve it using the Hopcroft–Karp algorithm or a simple DFS-based augmenting path algorithm (Hungarian / Kuhn's algorithm), which is efficient enough for `k ≤ 1200`.

import sys

def solve():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    
    allowed = [[] for _ in range(k + 1)]
    alias_of = [0] * (k + 1)
    
    for _ in range(t):
        x, y, z = map(int, input().split())
        allowed[x].append(z)
        alias_of[x] = y  # fixed alias for agent x
    
    match_freq = [0] * (k + 1)
    match_agent = [0] * (k + 1)
    
    def dfs(agent, visited):
        for freq in allowed[agent]:
            if not visited[freq]:
                visited[freq] = True
                if match_agent[freq] == 0 or dfs(match_agent[freq], visited):
                    match_agent[freq] = agent
                    match_freq[agent] = freq
                    return True
        return False
    
    for agent in range(1, k + 1):
        visited = [False] * (k + 1)
        if not dfs(agent, visited):
            print("NO")
            return
    
    print("YES")
    for agent in range(1, k + 1):
