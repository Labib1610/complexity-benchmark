We can model this as a matching problem.  
Each specialist is tied to exactly one machine, and different specialists have different machines.  
So we can think of each specialist as a node that can be matched to a time slot, but only if the corresponding (machine, time slot) combination is allowed.

We need to assign each specialist a distinct time slot such that the allowed combination exists.

This becomes a bipartite matching problem between specialists and time slots.

We’ll use a standard DFS-based bipartite matching (Kuhn’s algorithm) since k ≤ 1200, which is fine.

```python
import sys
sys.setrecursionlimit(10000)

def solve():
    input = sys.stdin.readline
    k, t = map(int, input().split())
```
```python
    allowed = [[] for _ in range(k + 1)]
    machine_of = [0] * (k + 1)
    for _ in range(t):
        x, y, z = map(int, input().split())
        allowed[x].append(z)
        machine_of[x] = y  # same machine for all entries of this specialist
    
    match_time = [0] * (k + 1)
    
    def dfs(spec, visited):
        for time_slot in allowed[spec]:
            if not visited[time_slot]:
                visited[time_slot] = True
                if match_time[time_slot] == 0 or dfs(match_time[time_slot], visited):
                    match_time[time_slot] = spec
                    return True
        return False
    
    for spec in range(1, k + 1):
        visited = [False] * (k + 1)
        if not dfs(spec, visited):
            print("NO")
            return
    
    print("YES")
    for time_slot in range(1, k + 1):
        spec = match_time[time_slot]
        print(spec, machine_of[spec], time_slot)

if __name__ == "__main__":
    solve()
```
