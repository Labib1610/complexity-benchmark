We need to find the lexicographically smallest triangle (3-clique) in an undirected graph.

A direct approach:  
- Iterate over the first vertex `a` from 1 to n.  
- For each `a`, iterate over the second vertex `b` from `a+1` to n, but only if `(a,b)` is an edge.  
- For each such pair, iterate over `c` from `b+1` to n, and check if both `(a,c)` and `(b,c)` are edges.  
- The first such triple found (in this order) is the answer.

Since n ≤ 2000 and m ≤ 2e5, we can store adjacency in a boolean matrix (n+1 by n+1) for O(1) edge checks.  
The triple loop is O(n^3) in worst case, but with early exit and only checking edges for `b`, it will be fast enough for n=2000 (about 8e9 worst-case, but in practice we stop early because we only iterate over actual edges for `b`).

We can optimize by iterating over neighbors of `a` for `b`, and then checking neighbors of `b` for `c`.

Let's implement:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = adj[v][u] = True

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if adj[a][b]:
                for c in range(b + 1, n + 1):
                    if adj[a][c] and adj[b][c]:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    main()
```
