We can solve this by checking each vertex as the smallest possible `a`, then looking for the smallest `b` and `c` that form a triangle with `a`.  

We’ll use an adjacency matrix (or set) for O(1) edge checks, and iterate in increasing order to get the lexicographically smallest triangle.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(n):
        for b in sorted(adj[a]):
            if b <= a:
                continue
            for c in sorted(adj[b]):
                if c <= b:
                    continue
                if c in adj[a]:
                    print(a+1, b+1, c+1)
                    return

if __name__ == "__main__":
    main()
```
