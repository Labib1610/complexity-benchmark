We need to find the lexicographically smallest triangle (3-clique) in an undirected graph.

A direct approach:  
- Iterate over all possible first vertices `a` from 1 to n.  
- For each `a`, iterate over possible second vertices `b > a` that are connected to `a`.  
- For each such pair, check if there exists a `c > b` connected to both `a` and `b`.  
- The first such triple found (in lexicographic order) is the answer.

We can speed up neighbor checks using sets for adjacency.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(n):
        for b in adj[a]:
            if b <= a:
                continue
            for c in adj[a]:
                if c <= b:
                    continue
                if c in adj[b]:
                    print(a + 1, b + 1, c + 1)
                    return

if __name__ == "__main__":
    main()
```
