We can solve this by checking each possible triple in a smart way.  
Since \( n \) can be up to 2000, checking all triples naively is too slow.  
Instead, we can iterate over the first vertex `a` from 1 to n, and for each `a`, look at its neighbors.  
For each pair of neighbors `(b, c)` of `a`, if `b` and `c` are also connected, we found a triangle.  
We stop at the first (lexicographically smallest) such triple.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        neighbors = sorted(adj[a])
        for i in range(len(neighbors)):
            b = neighbors[i]
            if b <= a:
                continue
            for j in range(i + 1, len(neighbors)):
                c = neighbors[j]
                if c <= b:
                    continue
                if c in adj[b]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
