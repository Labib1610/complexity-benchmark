We need to find a triangle in the graph (three mutually connected nodes) and output the lexicographically smallest one.

A straightforward approach:  
- Since the graph is guaranteed to have at least one triangle, we can iterate over all triples in lexicographic order and check if all three edges exist.  
- But n can be up to 2000, so checking all triples O(n³) is too slow.  
- Instead, we can use an adjacency matrix (or set) and iterate over edges, checking for a common neighbor.

Algorithm:
1. Read n, m.
2. Build adjacency matrix (boolean) for O(1) edge checks.
3. Iterate over all edges (u, v) with u < v.
4. For each such edge, check all w > v to see if both (u, w) and (v, w) exist.
5. The first found triple in lexicographic order (since we iterate u from 1..n, v from u+1..n, w from v+1..n) will be the answer.

This is O(m * n) in worst case, which is fine for m up to 2e5 and n up to 2000.

```python
n, m = map(int, input().split())
adj = [[False] * (n + 1) for _ in range(n + 1)]
edges = []
for _ in range(m):
    u, v = map(int, input().split())
    adj[u][v] = adj[v][u] = True
    if u > v:
        u, v = v, u
    edges.append((u, v))

# Sort edges lexicographically
edges.sort()

for u, v in edges:
    for w in range(v + 1, n + 1):
        if adj[u][w] and adj[v][w]:
            print(u, v, w)
            exit()
```
