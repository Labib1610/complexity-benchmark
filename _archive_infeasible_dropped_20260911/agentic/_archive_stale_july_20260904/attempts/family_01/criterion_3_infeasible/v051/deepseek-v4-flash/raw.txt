We can solve this by checking each vertex in increasing order and looking for a triangle that includes it.  

We can use an adjacency matrix (or set) for fast neighbor checks. For each vertex `a` from 1 to n, we check its neighbors in increasing order, and for each neighbor `b`, we look for a common neighbor `c` that is greater than `b`. The first such triple found will be lexicographically smallest.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        for b in sorted(adj[a]):
            if b <= a:
                continue
            for c in sorted(adj[b]):
                if c <= b:
                    continue
                if c in adj[a]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
