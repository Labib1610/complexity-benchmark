We need to find the lexicographically smallest triangle in an undirected graph.  
Since the graph can have up to 2000 nodes and 200,000 edges, we can’t check all triples directly (that would be O(n³)).  

We can use an adjacency matrix (boolean) for O(1) edge checks, and then iterate over possible triples in lexicographic order, stopping at the first found.  

Here’s the implementation:  

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = adj[v][u] = True
    
    for a in range(1, n - 1):
        for b in range(a + 1, n):
            if not adj[a][b]:
                continue
            for c in range(b + 1, n + 1):
                if adj[a][c] and adj[b][c]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
