# Problem C — Unstable Core

Time limit: 2 s   Memory limit: 256 MB

A laboratory is testing a mixture of $n$ chemical compounds. The design specifies $m$ binary incompatibilities, where two specific compounds react violently if they come into contact.

The researchers intended to find a safe subset of compounds. However, the current batch is completely unusable. An inspection reveals a fatal structural flaw: the presence of an unstable core. Specifically, an unstable core is a set of exactly three compounds where one compound is directly incompatible with the other two, and those other two compounds are also directly incompatible with each other. In this arrangement, isolation is impossible, as the mutual reactivity cannot be resolved.

To authorize a new batch, the lead chemist requires a formal defect report identifying the components involved in one of these minimal conflicting cores. Your task is to find a set of three compounds that form this exact configuration.

## Input
The first line contains two integers $n$ and $m$. The number of chemical compounds $n$ is at least the minimum number needed to form an unstable core, and does not exceed two thousand. The number of incompatibilities $m$ is at least the number of interactions within a single core, and at most the maximum possible number of distinct pairs among $n$ compounds, capped at two hundred thousand.

The following $m$ lines each contain two integers $u$ and $v$. The identifiers $u$ and $v$ are strictly positive and do not exceed the total number of compounds. A compound cannot be incompatible with itself, and each incompatible pair is recorded at most once.
It is guaranteed that at least one unstable core exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, representing the IDs of three compounds that form an unstable core. The IDs must be printed in ascending order ($a < b < c$).
If there are multiple such combinations, you must output the one that is lexicographically smallest. That is, minimize $a$; if there is a tie, minimize $b$; and if there is still a tie, minimize $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
Changed the scenario from mechanical cogs interlocking in a cycle to chemical compounds forming an unstable core. The definition of the 3-cycle was rewritten from a sequential loop to a static structural property (one element connected to two others, which are also connected to each other) to prevent models from easily matching standard cycle-finding keywords. Numeric bounds were replaced with indirect descriptions derived from the scenario, forcing the model to infer the exact limits from the properties of the core.
</RATIONALE>
<PRESERVED_ANSWER>
The structural property still requires finding three mutually connected vertices and outputting the lexicographically smallest triplet, which is mathematically identical to the seed's requirement of finding a 3-cycle.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Finding a 3-clique in an undirected graph can still be done efficiently by checking neighbor intersections in $O(nm / 64)$ time, preserving the intended complexity class.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "minimum number needed to form an unstable core" if they fail to read carefully, although the text explicitly states "an unstable core is a set of exactly three compounds" right before the input section.
</RISK>
