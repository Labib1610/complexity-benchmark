# Problem C — Territorial Deadlock

Time limit: 2 s   Memory limit: 256 MB

In a sprawling wildlife reserve, researchers are tracking $n$ animal packs. Field documentation has recorded $m$ specific combinations of two packs that engage in violent territorial disputes when their hunting grounds overlap.

The head biologist needs to identify a territorial deadlock to justify expanding the reserve. To do this, you must select exactly three distinct packs from the $n$ available. A selection of three packs forms a territorial deadlock if and only if every pair of packs within that selection engages in a violent territorial dispute according to the documentation. 

You must search the field documentation to find a territorial deadlock. It is guaranteed that the reserve is overpopulated and at least one such selection of three packs exists.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$).
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that pack $u$ and pack $v$ engage in a violent territorial dispute. 
It is guaranteed that at least one territorial deadlock of three packs exists.

## Output
Print three integers $a$, $b$, and $c$ on one line with $a < b < c$ such that the pairs $\{a, b\}$, $\{a, c\}$, and $\{b, c\}$ are all listed as engaging in a dispute in the input. 
If multiple territorial deadlocks exist, output the one with the smallest value for $a$; if there is a tie, choose the one with the smallest value for $b$; and if still tied, the smallest value for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
