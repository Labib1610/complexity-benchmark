Looking at this problem, I need to find a triangle (3-clique) in a graph with n ≤ 2000 vertices and m ≤ 2×10^5 edges.

**Key insight:** If I sort vertices by degree and only consider edges where the first endpoint has degree ≤ second endpoint's degree, each vertex has at most O(√m) such "outgoing" edges. This gives O(m√m) edge-pairs to check, which is about 9×10^7 — feasible.

**Optimization for finding the lexicographically smallest triangle:**
- Process candidate pairs (a, b) in sorted order (by a, then b)
- For each pair, collect common neighbors in sorted order
- The first valid triangle found is the lexicographically smallest

**Further optimization:** Since we want the smallest `a`, once we find any triangle with vertex `a`, we can skip all pairs with larger `a` values. This early termination makes it much faster in practice.

```python
import sys
from bisect import insort

def main():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [set() for _ in range(n + 1)]
    deg = [0] * (n + 1)
    
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        adj[u].add(v)
        adj[v].add(u)
        deg[u] += 1
        deg[v] += 1
    
    # Build directed edges: low-degree -> high-degree (tie-break by vertex id)
    out_adj = [[] for _ in range(n + 1)]
    for u in range(1, n + 1):
        du = deg[u]
        for v in adj[u]:
            dv = deg[v]
            if du < dv or (du == dv and u < v):
                out_adj[u].append(v)
    
    for u in range(1, n + 1):
        out_adj[u].sort()
    
    best = None
    best_a = n + 1
    
    for a in range(1, n + 1):
        if a >= best_a:
            break
        out_a = out_adj[a]
        la = len(out_a)
        # Check all pairs in out_a
        for i in range(la):
            b = out_a[i]
            if best is not None and a == best_a and b >= best[1]:
                continue
            adj_b = adj[b]
            # Find smallest c in out_a[i+1:] that's also in adj_b
            for j in range(i + 1, la):
                c = out_a[j]
                if c in adj_b:
                    if best is None or a < best_a or (a == best_a and (b < best[1] or (b == best[1] and c < best[2]))):
                        best = (a, b, c)
                        best_a = a
                    break
    
    print(best[0], best[1], best[2])

main()
```

The algorithm:
1. Direct edges from lower-degree to higher-degree vertex (each vertex has ≤ O(√m) outgoing edges)
2. For each vertex `a`, check pairs (b, c) among its outgoing neighbors where b-c is also an edge
3. Process in sorted order and use early termination once we find the minimum `a`
4. For each (a, b), find the smallest valid c by checking outgoing neighbors in sorted order

This finds the lexicographically smallest triangle efficiently.
