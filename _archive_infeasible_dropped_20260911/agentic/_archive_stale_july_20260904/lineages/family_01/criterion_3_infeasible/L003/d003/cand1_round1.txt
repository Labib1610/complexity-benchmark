# Problem C — Roster Evaluation

Time limit: 2 s   Memory limit: 256 MB

Factory management is investigating historical scheduling failures caused by interlocking worker conflicts. You are provided with a dispute log from a period when the shift-generation algorithm crashed. A crash of this specific type is triggered whenever there is a group of three distinct workers who all have mutually recorded disputes with one another in the log. 

Your task is to analyze the log and identify the workers involved in the deadlock that caused the crash.

## Input
The first line provides two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), denoting the total number of workers and the total number of recorded disputes.
Following this, there are $m$ lines. Each line contains two integers $u$ and $v$, representing a dispute between worker $u$ and worker $v$.

## Output
Output a single line containing three space-separated integers $a$, $b$, and $c$, ordered such that $a < b < c$. These integers must represent the workers forming the three-person deadlock. Should the log contain more than one such group, you must output the sequence that comes first lexicographically (minimizing $a$; then minimizing $b$ in the event of a tie; and finally minimizing $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
