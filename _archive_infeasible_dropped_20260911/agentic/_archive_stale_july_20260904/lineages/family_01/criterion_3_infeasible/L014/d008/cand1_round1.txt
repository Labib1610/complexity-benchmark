<STATEMENT>
# Problem C — Cargo Prohibition Protocol

Time limit: 2 s   Memory limit: 256 MB

A logistics firm operates a shipping route for hazardous materials. Certain pairs of these materials are highly reactive and are strictly prohibited from sharing a vessel. This restriction is mutual: if material $u$ cannot be shipped with material $v$, then $v$ cannot be shipped with $u$.

The proposed loading schedule is structurally impossible to fulfill. You must produce a definitive proof of this impossibility to trigger an automatic schedule rejection.

To establish this proof, you are required to isolate a "deadlock" configuration consisting of exactly three distinct materials. Let $E_k$ denote the set of materials that are explicitly prohibited from sharing a vessel with material $k$. A configuration of three distinct materials $S = \{a, b, c\}$ is deemed a deadlock if and only if:
$$S \subseteq (E_a \cap E_b) \cup (E_b \cap E_c) \cup (E_c \cap E_a)$$

Because the automated auditing system requires deterministic reporting, it will not accept an arbitrary deadlock configuration. The system demands the canonical proof, meaning you must systematically ensure no earlier configuration could have been reported.

## Input
The first line provides two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n(n-1)/2, 2 \cdot 10^5)$), indicating the number of hazardous materials and the number of prohibited pairs. The materials are identified by integers from $1$ to $n$.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$) — a pair of materials that are prohibited from sharing a vessel. 
It is guaranteed that the input contains at least one deadlock configuration of three materials.

## Output
Output a single line containing three integers $a$, $b$, and $c$ ($a < b < c$), representing the identifiers of the materials in the deadlock configuration.
To satisfy the deterministic auditing system, if more than one such configuration exists, you must output the lexicographically earliest one among all valid configurations. This means you must minimize $a$; if there is a tie, minimize $b$; and if still tied, minimize $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```
### Explanation for Example 1
The explicit prohibition sets are:
- $E_1 = \{2, 3\}$
- $E_2 = \{1, 3, 4\}$
- $E_3 = \{1, 2, 4\}$
- $E_4 = \{2, 3\}$

Consider the configuration $S = \{1, 2, 3\}$:
- $E_1 \cap E_2 = \{3\}$
- $E_2 \cap E_3 = \{1, 4\}$
- $E_3 \cap E_1 = \{2\}$
The union of these intersections is $\{1, 2, 3, 4\}$. Since $S \subseteq \{1, 2, 3, 4\}$, it is a valid deadlock. 

Consider $S = \{2, 3, 4\}$:
- $E_2 \cap E_3 = \{1, 4\}$
- $E_3 \cap E_4 = \{2\}$
- $E_4 \cap E_2 = \{3\}$
The union is $\{1, 2, 3, 4\}$. Since $S \subseteq \{1, 2, 3, 4\}$, it is also a valid deadlock. 
The configuration $\{1, 2, 3\}$ is reported because it is lexicographically smaller.

<RATIONALE>
The definition of a 3-clique is replaced with an equivalent set-theoretic condition: $S \subseteq (E_a \cap E_b) \cup (E_b \cap E_c) \cup (E_c \cap E_a)$. Pattern-matching models will fail by attempting to literally compute these set operations for all $O(N^3)$ triplets, which will Time Out. Models that genuinely reason will deduce algebraically that since $a \notin E_a$, the only way for $a$ to be in the union is if $a \in E_b \cap E_c$, meaning $a, b, c$ must be mutually connected, allowing them to use the intended efficient algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The set-theoretic subset condition is mathematically strictly equivalent to the three materials forming a 3-clique in the incompatibility graph, meaning the valid configurations remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks for the lexicographically first 3-clique in an undirected graph, preserving the certificate-style infeasibility complexity class.
</PRESERVED_CLASS>
