<METHOD_DESCRIPTION>Replaces the condition "all pairs are connected" (clique/triangle) with a localized degree-counting property: "in the subset restricted to these elements, every element has degree exactly 2". This prevents models from pattern-matching "triangle" or "mutual interference", forcing them to deduce the structure from the induced degree sequence.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem C — Cargo Prohibition Protocol

Time limit: 2 s   Memory limit: 256 MB

A logistics firm operates a shipping route for hazardous materials. Certain pairs of these materials are highly reactive and are documented in a database of interference reports. 

The proposed loading schedule is structurally impossible to fulfill. You must produce a definitive proof of this impossibility to trigger an automatic schedule rejection.

To establish this proof, you are required to isolate a "deadlock" configuration consisting of exactly three distinct materials. When auditing a candidate trio of three distinct materials, the automated system filters the entire database of interference reports to find only those "internal" reports. An interference report is considered internal to the trio if and only if both materials listed in that report are members of the candidate trio. The trio is classified as a deadlock if and only if each of the three materials is listed in exactly two internal reports.

Because the automated auditing system requires deterministic reporting, it will not accept an arbitrary deadlock configuration. The system demands the canonical proof, meaning you must systematically ensure no earlier configuration could have been reported.

## Input
The first line provides two integers $n$ and $m$. The materials are identified by consecutive integers starting from $1$. The maximum possible number of materials is exactly the number of millimeters in two meters. The number of interference reports, $m$, will not exceed the number of seconds in $55$ hours, $33$ minutes, and $20$ seconds, nor will it exceed the theoretical maximum of all possible pairs of materials. The minimum value for both $n$ and $m$ is $3$.

Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$) — a pair of materials documented in an interference report. Each pair is listed at most once, and order does not matter.
It is guaranteed that the input contains at least one deadlock configuration of three materials.

## Output
Output a single line containing three integers $a$, $b$, and $c$ ($a < b < c$), representing the identifiers of the materials in the deadlock configuration.
To satisfy the deterministic auditing system, if more than one such configuration exists, you must output the lexicographically earliest one among all valid configurations. This means you must minimize $a$; if there is a tie, minimize $b$; and if still tied, minimize $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
Removed the 2-coloring/bipartite framing ("impossible to assign to Hold A or Hold B") which models easily recognized as finding an odd cycle (triangle). Replaced it with a localized degree-counting condition on the induced subgraph ("each of the three materials is listed in exactly two internal reports"), which forces the model to deduce that only a triangle satisfies this property. Additionally, applied S07 by describing the bounds $2000$ and $200000$ via exact physical and temporal measurements.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that each of the three materials appears in exactly two internal reports is mathematically satisfied if and only if all three possible pairs among them exist in the database, which is exactly the original triangle condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding the lexicographically first triangle in an undirected graph, keeping it in the same complexity class.
</PRESERVED_CLASS>
<RISK>
Models might struggle to parse the indirect bounds (e.g., calculating the seconds correctly), though the arithmetic is straightforward and unambiguous.
</RISK>
