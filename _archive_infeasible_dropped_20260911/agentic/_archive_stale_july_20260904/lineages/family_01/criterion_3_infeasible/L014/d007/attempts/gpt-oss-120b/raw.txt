**Solution Explanation**

For every material we know the list of materials it is forbidden to share a vessel with.
A *dead‑lock* is exactly a triangle in this undirected graph:
three distinct vertices `a < b < c` such that all three edges  
`(a,b) , (a,c) , (b,c)` are present.

The required output is the lexicographically smallest triangle,
i.e. the smallest possible `a`; if several triangles have this `a`,
the smallest possible `b`; and finally the smallest possible `c`.

`n ≤ 2000`, therefore an `O(n²)` algorithm is easily fast enough.



--------------------------------------------------------------------

#### 1.   Bitset representation

For each vertex `v` we store a bitset `adj[v]` (as a Python `int`):
bit `i` (0‑based) is `1` iff the edge `(v, i+1)` exists.

```
adj[v] = sum( 1 << (u-1)  for every neighbour u of v )
```

With this representation the set of common neighbours of two vertices
`x` and `y` is simply

```
common = adj[x] & adj[y]          # bitwise AND
```

Finding the smallest vertex `c` larger than a given bound `b`
among those common neighbours is done by masking away all bits
`≤ b` and taking the least significant remaining `1`.

```
mask   = ~((1 << b) - 1)          # bits b, b+1, … are 1
cand   = common & mask
lowest = cand & -cand             # isolates lowest 1‑bit
c      = lowest.bit_length()      # 1‑based vertex number
```

All operations are O(1) on a 2000‑bit integer.



--------------------------------------------------------------------

#### 2.   Searching the lexicographically smallest triangle

We iterate `a` from `1` to `n`.
For each `a` we iterate `b` from `a+1` to `n`.
If the edge `(a,b)` exists we look for a suitable `c` as described above.
The first triple we encounter is automatically the lexicographically
smallest one, because the loops increase `a` first, then `b`, then `c`.

The total work is `O(n²)` edge checks plus the constant‑time bitset
operations – well below the limits.



--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
triangle.

---

##### Lemma 1  
For any vertices `x < y`, after the masking step `cand` contains exactly the
vertices `z` such that `z > y` and edges `(x,z)` and `(y,z)` exist.

**Proof.**  
`common = adj[x] & adj[y]` has a `1`‑bit precisely for vertices adjacent to
both `x` and `y`.  
`mask` has `1`‑bits for all positions `≥ y` (remember vertices are 1‑based,
bits are 0‑based, therefore `mask` clears bits `0 … y-1`).  
`cand = common & mask` therefore keeps a `1`‑bit exactly for those common
neighbours whose index `z` satisfies `z ≥ y+1`, i.e. `z > y`. ∎



##### Lemma 2  
If `cand ≠ 0`, `c = lowest.bit_length()` is the smallest vertex `c` with
`c > y` that together with `x` and `y` forms a triangle.

**Proof.**  
`lowest = cand & -cand` isolates the least significant `1`‑bit of `cand`,
which corresponds to the smallest index among the set bits of `cand`.  
`bit_length()` returns that index + 1, i.e. the vertex number.
By Lemma&nbsp;1 every set bit of `cand` corresponds to a vertex forming a
triangle with `x` and `y`, and the isolated bit is the smallest such vertex. ∎



##### Lemma 3  
When the algorithm prints a triple `(a,b,c)`, it is a triangle
(`a<b<c` and all three edges exist).

**Proof.**  
The outer loops guarantee `a<b`.  
The inner test `if edge (a,b)` ensures that edge `(a,b)` exists.  
`c` is obtained from `cand` which, by Lemma&nbsp;1, contains only vertices
adjacent to both `a` and `b`. Hence edges `(a,c)` and `(b,c)` exist.
The masking guarantees `c>b`, therefore `a<b<c`. ∎



##### Lemma 4  
If a triangle exists, the algorithm will eventually output one.

**Proof.**  
Consider the lexicographically smallest triangle `(a*,b*,c*)`.
When the outer loops reach `a = a*` and `b = b*`, the edge `(a*,b*)` is present,
so the algorithm examines `cand`.  
Since `c*` is adjacent to both `a*` and `b*` and `c* > b*`,
by Lemma&nbsp;1 its bit is set in `cand`. Hence `cand ≠ 0`,
and the algorithm will output a triangle (possibly with a smaller `c`,
but still a triangle). ∎



##### Lemma 5  
The first triangle printed by the algorithm is the lexicographically smallest
triangle of the graph.

**Proof.**  
The loops enumerate pairs `(a,b)` in increasing lexicographic order.
For a fixed `(a,b)` the algorithm, by Lemma&nbsp;2, chooses the smallest
possible `c`.  
Therefore any triangle discovered later has either a larger `a`,
or the same `a` and larger `b`, or the same `a,b` and larger `c`.
Thus the first printed triangle is lexicographically minimal. ∎



##### Theorem  
The algorithm outputs exactly the lexicographically smallest triple
`a<b<c` that forms a triangle in the given graph.

**Proof.**  
By Lemma&nbsp;3 any printed triple is a triangle.
By Lemma&nbsp;4 at least one triangle will be printed.
By Lemma&nbsp;5 the first printed triangle is the lexicographically smallest
among all triangles. The algorithm terminates after printing it, so the
output satisfies the specification. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building bitsets* : `O(m)`  
*Main double loop* : `O(n²)` iterations, each does only constant‑time
operations (bitwise AND, masking, extracting lowest bit).  

```
Time   ≤ 4·10⁶  operations  << 2 seconds
Memory ≤ n·(n bits) ≈ 2000·2000 /8  ≈ 0.5 MiB  (plus small overhead)
```

Both limits are easily satisfied.

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    # adjacency matrix for quick edge existence test
    adj_mat = [bytearray(n + 1) for _ in range(n + 1)]
    # bitset adjacency
    adj_bits = [0] * (n + 1)

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        if u == v:
            continue
        if not adj_mat[u][v]:
            adj_mat[u][v] = adj_mat[v][u] = 1
            adj_bits[u] |= 1 << (v - 1)
            adj_bits[v] |= 1 << (u - 1)

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if not adj_mat[a][b]:
                continue
            common = adj_bits[a] & adj_bits[b]
            # keep only vertices > b
            mask = ~((1 << b) - 1)
            cand = common & mask
            if cand:
                lowest = cand & -cand
                c = lowest.bit_length()  # 1‑based
                # c is guaranteed > b
                print(a, b, c)
                return

if __name__ == "__main__":
    solve()
```

and conforms to the required input‑output format.
