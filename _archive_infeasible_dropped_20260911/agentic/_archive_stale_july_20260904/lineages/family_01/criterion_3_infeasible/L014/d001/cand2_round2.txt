# Problem C — Flight Manifest Rejection

Time limit: 2 s   Memory limit: 256 MB

A cargo operator relies on a pair of transport aircraft to move various industrial chemicals. Many of these substances are highly unstable when placed in proximity, meaning specific pairs will react critically and must be loaded onto different aircraft.

The proposed shipping schedule is structurally defective: it is impossible to partition the chemicals between only two aircraft without causing a reaction. Your objective is not to find a safe loading configuration, but rather to automatically generate a safety rejection report that proves no such configuration is possible.

To construct this proof, you must isolate a group of three distinct chemicals where every possible pair within the group is known to be reactive. Since each chemical in this trio conflicts with the other two, they would inherently require a minimum of three separate aircraft, which definitively invalidates the two-aircraft limitation.

## Input
The first line provides two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n(n-1)/2, 2 \cdot 10^5)$), denoting the total number of chemicals and the number of documented reactive pairs. The chemicals are identified by integers from $1$ to $n$.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that chemical $u$ and chemical $v$ react critically with each other. 
It is guaranteed that the provided data contains at least one such group of three chemicals.

## Output
Output a single line containing three integers $a$, $b$, and $c$, ordered such that $a < b < c$. These must be the identifiers of the three chemicals comprising the proof.
If multiple such groups exist, output the one that is lexicographically smallest (i.e., minimize $a$; in case of a tie, minimize $b$; then minimize $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
