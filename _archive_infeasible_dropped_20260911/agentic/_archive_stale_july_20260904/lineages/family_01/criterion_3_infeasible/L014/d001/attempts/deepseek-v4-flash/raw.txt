 We need to find a triangle in the graph — three chemicals that are all pairwise connected by reactive edges.  
That means we’re looking for a 3-clique.  

We can do this efficiently by checking each vertex and seeing if any two of its neighbors are connected.  
We’ll iterate vertices in increasing order and return the first triangle found, which gives the lexicographically smallest triple.

```python
n, m = map(int, input().split())
adj = [set() for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].add(v)
    adj[v].add(u)

for a in range(n):
    for b in adj[a]:
        if b > a:
            for c in adj[a]:
                if c > b and c in adj[b]:
                    print(a+1, b+1, c+1)
                    exit()
```
