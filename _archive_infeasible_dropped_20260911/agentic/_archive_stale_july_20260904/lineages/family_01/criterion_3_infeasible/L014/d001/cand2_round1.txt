# Problem C — Flight Manifest Rejection

Time limit: 2 s   Memory limit: 256 MB

A cargo company relies on two transport planes to ship various industrial chemicals. Many of these chemicals are volatile when mixed, meaning certain pairs will react dangerously and must be transported on different planes.

The current shipping manifest is fundamentally flawed: it is impossible to divide all the chemicals between just two planes without risking a reaction. Your task is to generate an automated safety rejection report. You do not need to attempt a safe allocation; you only need to prove that no such allocation exists.

To provide this proof, you must identify a "volatile triad". A volatile triad is defined as a selection of exactly three chemicals such that exactly three of the documented reactive pairs consist entirely of chemicals from this selection. Identifying this group formally demonstrates that a two-plane plan is impossible, as they cannot be safely separated into two groups.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n(n-1)/2, 2 \cdot 10^5)$), representing the number of chemicals and the number of reactive pairs. Chemicals are numbered from $1$ to $n$.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$) — a pair of chemicals that react dangerously with each other. 
It is guaranteed that at least one volatile triad exists in the given data.

## Output
Print three integers $a$, $b$, and $c$ on a single line with $a < b < c$, representing the IDs of the three chemicals that form a volatile triad.
If there are multiple such groups, output the one that is lexicographically smallest (i.e., smallest $a$; ties broken by smallest $b$; then smallest $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
Removed the direct description of the triad as a group where "every chemical... reacts dangerously with the other two", which acts as a direct trigger for common-neighbor triangle detection. Instead, it is defined as a set of three chemicals that strictly contain exactly three reactive pairs. This forces the model to deduce that a subset of 3 vertices containing 3 edges is equivalent to a fully connected triangle before applying standard graph algorithms.
</RATIONALE>
<PRESERVED_ANSWER>
A subset of 3 nodes in a simple graph can have at most 3 edges; requiring exactly 3 edges is mathematically identical to requiring a triangle, so the correct outputs remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a triangle (K3) in a graph, preserving the O(n*m/64) complexity class of certificate-style infeasibility.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "exactly three of the documented reactive pairs" as a requirement to check the degree of the nodes rather than the induced subgraph, though "consist entirely of chemicals from this selection" clarifies it means edges within the subset.
</RISK>
