<METHOD_NAME>Algebraic Compatibility Summation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the structural definition of a triangle (three mutually connected vertices or mutual members of a prohibition set) with an algebraic condition on a pairwise compatibility function. By defining C(u,v)=0 for prohibited pairs and C(u,v)=1 otherwise, the condition that three materials are mutually prohibited is transformed into the equation C(a,b) + C(b,c) + C(a,c) = 0. This forces the model to deduce that the sum of non-negative integers equals zero if and only if all terms are zero, breaking surface-level graph pattern matching.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem C — Cargo Prohibition Protocol

Time limit: 2 s   Memory limit: 256 MB

A logistics firm operates a shipping route for hazardous materials. Certain pairs of these materials are highly reactive and are explicitly prohibited from sharing a vessel.

The proposed loading schedule is structurally impossible to fulfill. You must produce a definitive proof of this impossibility to trigger an automatic schedule rejection.

To establish this proof, you are required to isolate a "deadlock" configuration. Let the compatibility function $C(u, v)$ between two distinct materials $u$ and $v$ evaluate to $0$ if the pair is explicitly prohibited from sharing a vessel (i.e., the pair appears in the input list of prohibitions), and $1$ otherwise.
A deadlock configuration is defined as a set of exactly three distinct materials $a, b,$ and $c$ such that:
$C(a, b) + C(b, c) + C(a, c) = 0$

Because the automated auditing system requires deterministic reporting, it will not accept an arbitrary deadlock configuration. The system demands the canonical proof, meaning you must systematically ensure the output is the lexicographically earliest valid configuration.

## Input
The first line provides two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n(n-1)/2, 2 \cdot 10^5)$), indicating the number of hazardous materials and the number of prohibited pairs. The materials are identified by integers from $1$ to $n$.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$) — a pair of materials that are prohibited from sharing a vessel. 
It is guaranteed that the input contains at least one deadlock configuration of three materials.

## Output
Output a single line containing three integers $a$, $b$, and $c$ ($a < b < c$), representing the identifiers of the materials in the deadlock configuration.
To satisfy the deterministic auditing system, if more than one such configuration exists, you must output the lexicographically earliest one among all valid configurations. This means you must minimize $a$; if there is a tie, minimize $b$; and if still tied, minimize $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
The explicit description of "each material being in the prohibited set of the other two" was replaced with an algebraic condition on an indicator function. The model must now deduce that since C(u,v) is either 0 or 1, their sum equals zero if and only if all three terms are exactly zero, meaning all three pairs are explicitly prohibited in the input. This breaks simple structural pattern matching for triangles. The exact numeric bounds from the seed have been strictly restored to resolve previous gate failures.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $C(a,b)+C(b,c)+C(a,c)=0$ is mathematically equivalent to requiring all three pairs to be prohibited, which is exactly the original requirement of finding a triangle of prohibited pairs; the lexicographical tie-break rule is identical.
</PRESERVED_ANSWER>
