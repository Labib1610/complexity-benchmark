<METHOD_NAME>Algebraic Indicator Summation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the logical/set-based mutual exclusion condition with an algebraic equation over indicator functions. By defining a compatibility score that is 0 for prohibited pairs and 1 for permitted pairs, the triangle condition becomes a root-finding problem (sum of scores = 0). This prevents pattern matching on graph cliques or set intersections.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem C — Cargo Prohibition Protocol

Time limit: 2 s   Memory limit: 256 MB

A logistics firm operates a shipping route for hazardous materials. Certain pairs of these materials are highly reactive and are strictly prohibited from sharing a vessel.

The proposed loading schedule is structurally impossible to fulfill. You must produce a definitive proof of this impossibility to trigger an automatic schedule rejection.

To establish this proof, you are required to isolate a "deadlock" configuration. For any two distinct materials $u$ and $v$, define their compatibility score $C(u, v)$ to be $0$ if they are explicitly prohibited from sharing a vessel, and $1$ if they are permitted to share a vessel. 

A deadlock configuration is a combination of exactly three distinct materials. Let these materials be sorted by their identifiers such that $a < b < c$. The combination is a deadlock if:

$C(a, b) + C(b, c) + C(a, c) = 0$

Because the automated auditing system requires deterministic reporting, it will not accept an arbitrary deadlock configuration. The system demands the canonical proof, meaning you must systematically ensure no earlier configuration could have been reported. 

## Input
The first line provides two integers $n$ and $m$, indicating the total count of hazardous materials and the total count of prohibited pairs. The firm's database is designed to handle up to two thousand hazardous materials, and there are currently at least three such materials in the system. The number of prohibited pairs $m$ is at least three, and is bounded by either two hundred thousand or the theoretical maximum number of distinct pairs for $n$ materials, whichever is smaller. The materials are identified by integers from $1$ to $n$.

Each of the following $m$ lines contains two distinct integers $u$ and $v$ between $1$ and $n$ inclusive, representing a pair of materials that are prohibited from sharing a vessel. 
It is guaranteed that the input contains at least one deadlock configuration.

## Output
Output a single line containing three integers $a$, $b$, and $c$ ($a < b < c$), representing the identifiers of the materials in the deadlock configuration.
To satisfy the deterministic auditing system, if more than one such configuration exists, you must output the lexicographically earliest sequence $(a, b, c)$ among all valid configurations. This means you must minimize $a$; if there is a tie, minimize $b$; and if still tied, minimize $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
The explicit subset-based mutual exclusion condition was replaced with an algebraic equation over indicator functions. By defining a compatibility score that is 0 for prohibited pairs and 1 for permitted pairs, the model must deduce that a sum of non-negative indicators equaling zero requires all terms to be zero. This forces an intermediate reasoning step to translate the algebraic property back into the structural presence of three mutually prohibited pairs, defeating direct pattern matching on graph cliques. Numeric bounds are also restated indirectly in the text.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the sum of the three compatibility scores equals zero is mathematically identical to requiring that all three pairs are prohibited, which preserves the exact same set of valid configurations (triangles) and thus the identical lexicographically first answer.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a 3-clique (triangle) in an undirected graph, keeping it firmly in the same complexity class.
</PRESERVED_CLASS>
<RISK>
Models might struggle to parse the phrase "theoretical maximum number of distinct pairs for n materials" as exactly n(n-1)/2, though this only serves as an upper bound guarantee on the input size and does not affect the algorithmic logic.
</RISK>
