<STATEMENT>
# Problem C — Cargo Prohibition Protocol

Time limit: 2 s   Memory limit: 256 MB

A logistics firm operates a shipping route for hazardous materials. Certain pairs of these materials are highly reactive and are explicitly prohibited from sharing a single cargo vessel.

The proposed loading schedule is structurally impossible to fulfill. You must produce a definitive proof of this impossibility to trigger an automatic schedule rejection.

To establish this proof, you are required to isolate a "deadlock configuration". A deadlock configuration is defined as a set of exactly three distinct materials which cannot be distributed across two cargo vessels without placing at least one prohibited pair together in the same vessel.

Because the automated auditing system requires deterministic reporting, it will not accept an arbitrary deadlock configuration. The system demands the canonical proof, meaning you must systematically ensure no earlier configuration could have been reported.

## Input
The first line provides two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n(n-1)/2, 2 \cdot 10^5)$), indicating the number of hazardous materials and the number of prohibited pairs. The materials are identified by integers from $1$ to $n$.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$) — a pair of materials that are prohibited from sharing a vessel. 
It is guaranteed that the input contains at least one deadlock configuration of three materials.

## Output
Output a single line containing three integers $a$, $b$, and $c$ ($a < b < c$), representing the identifiers of the materials in the deadlock configuration.
To satisfy the deterministic auditing system, if more than one such configuration exists, you must output the lexicographically earliest one among all valid configurations. This means you must minimize $a$; if there is a tie, minimize $b$; and if still tied, minimize $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
I replaced the explicit mutual-exclusion definition (which directly describes the edges of a triangle) with a functional property based on the Pigeonhole Principle: the inability to partition three items into two conflict-free sets. This forces the model to deduce that the only way three items cannot be 2-colored is if they form a 3-clique, requiring an extra layer of structural reasoning before applying a triangle-finding algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that a set of three distinct items cannot be partitioned into two conflict-free vessels is mathematically equivalent to requiring that all three pairs among them are mutually conflicting (a triangle), so the set of valid configurations and their lexicographical ordering are identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying mathematical task remains finding the lexicographically first triangle in an undirected graph, preserving the required $O(M \sqrt{M})$ or bitset-optimized $O(NM/64)$ time complexity.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "distributed across two cargo vessels" as implying the vessels are ordered or that empty vessels are strictly forbidden, though neither edge-case interpretation changes the logical equivalence to a triangle.
</RISK>
