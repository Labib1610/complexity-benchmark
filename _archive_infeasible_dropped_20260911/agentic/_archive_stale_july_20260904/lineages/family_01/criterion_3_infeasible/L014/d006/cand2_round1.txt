# Problem C — Cargo Prohibition Protocol

Time limit: 2 s   Memory limit: 256 MB

A logistics firm operates a shipping route for hazardous materials. Certain pairs of these materials are highly reactive and are strictly prohibited from sharing a vessel.

The proposed loading schedule is structurally impossible to fulfill. You must produce a definitive proof of this impossibility to trigger an automatic schedule rejection.

To establish this proof, you are required to isolate a "deadlock" configuration of exactly three distinct materials. A configuration of three materials is considered a deadlock if and only if these three specific materials cannot be safely transported using fewer than three vessels. A transport assignment is considered safe if no two materials assigned to the same vessel are prohibited from sharing it.

Because the automated auditing system requires deterministic reporting, it will not accept an arbitrary deadlock configuration. The system demands the canonical proof, meaning you must systematically ensure no earlier configuration could have been reported.

## Input
The first line provides two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n(n-1)/2, 2 \cdot 10^5)$), indicating the number of hazardous materials and the number of prohibited pairs. The materials are identified by integers from $1$ to $n$.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$) — a pair of materials that are prohibited from sharing a vessel. 
It is guaranteed that the input contains at least one deadlock configuration of three materials.

## Output
Output a single line containing three integers $a$, $b$, and $c$ ($a < b < c$), representing the identifiers of the materials in the deadlock configuration.
To satisfy the deterministic auditing system, if more than one such configuration exists, you must output the lexicographically earliest one among all valid configurations. This means you must minimize $a$; if there is a tie, minimize $b$; and if still tied, minimize $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
I changed the deadlock definition from an explicit property about pairs having the same status to a domain-specific condition requiring that the three materials cannot be safely transported in fewer than three vessels. This forces the model to logically deduce that the condition evaluates the chromatic number of the 3-vertex induced subgraph. Identifying that a chromatic number of 3 for 3 vertices strictly implies a triangle (all pairs prohibited) requires deeper reasoning than pattern-matching the previous triad equality property.
</RATIONALE>
<PRESERVED_ANSWER>
A set of three materials requires three vessels if and only if no two materials can safely share a vessel, which means all three pairs are prohibited (a triangle), so the valid configurations and their lexicographical order remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core computational task still reduces to finding the lexicographically first triangle in an undirected graph, preserving the intended complexity class and bitset intersection algorithm.
</PRESERVED_CLASS>
<RISK>
A model might misread "fewer than three vessels" as a global requirement for all $N$ materials rather than just the isolated configuration, though the phrase "these three specific materials" heavily mitigates this risk.
</RISK>
