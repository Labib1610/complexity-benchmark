# Problem C — Cargo Prohibition Protocol

Time limit: 2 s   Memory limit: 256 MB

A logistics firm operates a shipping route for hazardous materials. Certain pairs of these materials are highly reactive and are explicitly prohibited from sharing a single cargo vessel.

To satisfy the safety regulations, materials are theoretically loaded onto vessels in a linear sequence. A specific loading sequence of three materials is considered "hazardous" if the first material in the sequence is prohibited from sharing a vessel with the second material, AND the second material is prohibited from sharing a vessel with the third material.

The proposed loading schedule is structurally impossible to fulfill. You must produce a definitive proof of this impossibility to trigger an automatic schedule rejection.

To establish this proof, you are required to isolate a "deadlock configuration". A deadlock configuration is a set of exactly three distinct materials such that *every* possible loading sequence of these three materials (all 6 permutations) is hazardous. In other words, no matter what order you attempt to load them in, the sequence always violates the safety checks.

Because the automated auditing system requires deterministic reporting, it will not accept an arbitrary deadlock configuration. The system demands the canonical proof, meaning you must systematically ensure no earlier configuration could have been reported.

## Input
The first line provides two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n(n-1)/2, 2 \cdot 10^5)$), indicating the number of hazardous materials and the number of prohibited pairs. The materials are identified by integers from $1$ to $n$.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$) — a pair of materials that are prohibited from sharing a vessel. 
It is guaranteed that the input contains at least one deadlock configuration of three materials.

## Output
Output a single line containing three integers $a$, $b$, and $c$ ($a < b < c$), representing the identifiers of the materials in the deadlock configuration.
To satisfy the deterministic auditing system, if more than one such configuration exists, you must output the lexicographically earliest one among all valid configurations. This means you must minimize $a$; if there is a tie, minimize $b$; and if still tied, minimize $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
The previous framing described the impossibility of partitioning three items into two vessels, which models easily recognized as the Pigeonhole Principle implying all three pairs must be prohibited (a triangle). I replaced this with a permutation-invariance constraint: a sequence is hazardous if adjacent items are prohibited, and a deadlock requires all 6 permutations to be hazardous. This forces the model to mathematically deduce that all 6 permutations being hazardous is logically equivalent to all 3 pairs being prohibited, preventing surface-level pattern matching from triggering standard graph algorithms.
</RATIONALE>
<PRESERVED_ANSWER>
A set of three materials has all 6 of its permutations flagged as hazardous if and only if every pair among the three is explicitly prohibited, which is exactly the definition of a triangle in the prohibited-pair graph, ensuring all valid configurations remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks to find the lexicographically first triangle in a graph, preserving the $O(n^3)$ naive complexity and $O(m \sqrt{m})$ or bitset-optimized intended complexity.
</PRESERVED_CLASS>
