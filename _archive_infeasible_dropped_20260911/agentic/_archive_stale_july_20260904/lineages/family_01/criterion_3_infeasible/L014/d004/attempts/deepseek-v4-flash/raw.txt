We need to find the lexicographically smallest triangle in the graph, where a triangle means three vertices that are all pairwise connected (a 3-clique).  

The problem states that a deadlock is exactly three materials where all three pairs are prohibited — i.e., a triangle in the graph.  

We can solve this by iterating over possible smallest vertex `a`, then `b`, then checking for `c`.  
Since `n` can be up to 2000, we can use adjacency sets for fast lookups.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if b in adj[a]:
                common = adj[a] & adj[b]
                for c in sorted(common):
                    if c > b:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    main()
```
