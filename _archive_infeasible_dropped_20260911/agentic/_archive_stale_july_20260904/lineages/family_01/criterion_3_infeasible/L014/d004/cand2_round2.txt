<STATEMENT>
# Problem C — Cargo Prohibition Protocol

Time limit: 2 s   Memory limit: 256 MB

A logistics firm operates a dual-vessel shipping route for hazardous materials. Certain pairs of these materials are highly reactive when stored in the same vessel and are strictly prohibited from sharing a cargo hold.

For any material $x$, let $P(x)$ denote the set of materials that are explicitly prohibited from sharing a vessel with $x$ as given in the input. Note that this prohibition is symmetric; if $u$ and $v$ are a prohibited pair, then $u \in P(v)$ and $v \in P(u)$.

The proposed loading schedule is structurally impossible to fulfill. You must produce a definitive proof of this impossibility to trigger an automatic schedule rejection.

To establish this proof, you are required to isolate a "deadlock" configuration. A deadlock consists of exactly three distinct materials, denoted as $a, b,$ and $c$ (ordered such that $a < b < c$), which satisfy the following mutual inclusion conditions:
- $b$ is an element of $P(a)$
- $c$ is an element of $P(a)$
- $c$ is an element of $P(b)$

The presence of such a configuration demonstrates that no valid assignment to the two vessels can exist.

Because the automated auditing system requires deterministic reporting, it will not accept an arbitrary deadlock configuration. The system demands the canonical proof, meaning you must systematically ensure no earlier configuration could have been reported.

## Input
The first line provides two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n(n-1)/2, 2 \cdot 10^5)$), indicating the number of hazardous materials and the number of prohibited pairs. The materials are identified by integers from $1$ to $n$.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$) — a pair of materials that are prohibited from sharing a vessel. 
It is guaranteed that the input contains at least one deadlock configuration of three materials.

## Output
Output a single line containing three integers $a$, $b$, and $c$ ($a < b < c$), representing the identifiers of the materials in the deadlock configuration.
To satisfy the deterministic auditing system, if more than one such configuration exists, you must output the one that minimizes the first identifier $a$. If there are multiple valid configurations tied for the smallest $a$, break the tie by minimizing the second identifier $b$. If there is still a tie, minimize the third identifier $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
The description of the triangle (3-clique) was rewritten from a pairwise graph property ("any two materials chosen from the set") into a set-theoretic mutual inclusion property ($b \in P(a)$, $c \in P(a)$, $c \in P(b)$). This removes the linguistic triggers for standard graph algorithms while explicitly guiding reasoning models toward the intended set-intersection (bitset) solution. All numeric bounds and tie-breaking rules were restored precisely to their original formal structures to ensure strict contract fidelity.
</RATIONALE>
