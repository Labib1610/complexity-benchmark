We need to find three distinct edges (reports) whose symmetric difference is empty.  
That means each worker appears in exactly 0 or 2 of the three edges.  
Since each edge has two workers, the only way this happens is if the three edges form a triangle:  
edges (a,b), (b,c), (a,c).  

So the problem reduces to finding the lexicographically smallest triangle in an undirected graph.  

We can do this efficiently:  
- For each vertex `a` from 1 to n,  
  - For each neighbor `b` of `a` with `b > a`,  
    - For each neighbor `c` of `a` with `c > b`,  
      - Check if edge (b,c) exists.  
- The first found triangle is the lexicographically smallest because we iterate `a` in increasing order, then `b`, then `c`.  

We can store edges in a set for O(1) lookup.  

Complexity:  
- Worst case O(n * deg(a)^2), but with n ≤ 2000 and m ≤ 2e5, this is acceptable if we break early.  

Here’s the implementation:  

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n + 1)]
    edge_set = set()
    
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].append(v)
        adj[v].append(u)
        edge_set.add((u, v))
        edge_set.add((v, u))
    
    for a in range(1, n + 1):
        for b in adj[a]:
            if b <= a:
                continue
            for c in adj[a]:
                if c <= b:
                    continue
                if (b, c) in edge_set:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
