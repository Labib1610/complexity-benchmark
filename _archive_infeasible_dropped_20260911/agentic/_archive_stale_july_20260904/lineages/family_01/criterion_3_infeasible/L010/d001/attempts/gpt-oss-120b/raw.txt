**Solution Explanation**

For every pair of workers we know whether they *conflict*.
A deadlock is a triangle – three workers `a<b<c` such that all three
pairs `{a,b}`, `{a,c}`, `{b,c}` are conflicts.
The task is to output the lexicographically smallest triangle
(the smallest `a`, then smallest `b`, then smallest `c`).

`n ≤ 2000`, therefore an `n × n` adjacency matrix fits easily into memory.
We store each row as a Python integer – a bitset – because bit operations
are extremely fast.

--------------------------------------------------------------------

#### Data structures

* `adj[i]` – integer, bit `j` (`0‑based`) is `1` iff workers `i` and `j+1`
  conflict. (`i` is 1‑based, bit `0` corresponds to worker `1`.)
* `nbr[i]` – sorted list of neighbours of `i` (only needed for iterating
  over edges).

--------------------------------------------------------------------

#### Algorithm
```
read n, m
build adj[1..n] and nbr[1..n]

for a = 1 .. n:
    for each b in nbr[a] with b > a:          # edges (a,b) with a<b
        common = adj[a] & adj[b]              # workers conflicting with both
        # we need a c > b
        mask = common >> b                    # discard bits ≤ b
        if mask != 0:
            # lowest set bit of mask gives the smallest possible c
            low = mask & -mask                # isolate lowest 1‑bit
            offset = low.bit_length() - 1     # its index (0‑based)
            c = b + offset
            output a b c and finish
```

The outer loops enumerate all possible `(a,b)` in increasing order of `a`
and, for a fixed `a`, in increasing order of `b`.  
The first time we find a suitable `c` it is automatically the smallest
`c` for this `(a,b)`, therefore the whole triple `(a,b,c)` is the
lexicographically smallest triangle in the whole graph.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
triangle.

---

##### Lemma 1  
For fixed `a<b`, if `common = adj[a] & adj[b]` and `mask = common >> b`,
then any set bit in `mask` corresponds to a worker `c` with `c>b`
that forms a triangle `{a,b,c}`.

**Proof.**  
`common` has a `1` at position `c-1` iff both edges `{a,c}` and `{b,c}`
exist (definition of `adj`).  
Shifting right by `b` removes bits for workers `≤ b`.  
Thus a set bit in `mask` corresponds to a worker `c>b` adjacent to both
`a` and `b`. ∎



##### Lemma 2  
If `mask ≠ 0`, the algorithm computes the smallest such `c`.

**Proof.**  
`low = mask & -mask` isolates the least‑significant `1`‑bit of `mask`,
i.e. the smallest index `k` with `mask`’s bit `k` equal to `1`.  
`offset = k` and `c = b + k`.  
Because all bits with index `<k` are zero, no worker `c'` with `b < c' < c`
belongs to `mask`. Hence `c` is the smallest worker `>b` forming a triangle
with `a` and `b`. ∎



##### Lemma 3  
When the algorithm outputs a triple `(a,b,c)`, it is a triangle.

**Proof.**  
The outer loops guarantee that edge `{a,b}` exists (`b` is taken from
`nbr[a]`).  
By Lemma&nbsp;1, `c` is adjacent to both `a` and `b`.  
Therefore all three edges are present – it is a triangle. ∎



##### Lemma 4  
Let `T* = (a*,b*,c*)` be the lexicographically smallest triangle.
The algorithm will output `T*`.

**Proof.**  
Consider the iteration when `a = a*`.  
All neighbours `b` of `a*` with `b>a*` are processed in increasing order,
so `b = b*` is examined before any larger `b`.  
At this moment `mask` is non‑empty because `{a*,b*,c*}` is a triangle,
hence the algorithm finds a `c`.  
By Lemma&nbsp;2 this `c` is the smallest possible for this `(a*,b*)`,
therefore `c = c*`.  
Consequently the algorithm outputs `(a*,b*,c*)`. ∎



##### Lemma 5  
The algorithm never outputs a triangle lexicographically larger than the
first one it could output.

**Proof.**  
The loops enumerate `(a,b)` in strict lexicographic order.
For each pair the smallest feasible `c` is chosen (Lemma&nbsp;2).
Thus the first triangle encountered is the smallest among all triangles. ∎



##### Theorem  
The algorithm terminates and prints the lexicographically smallest
triangle of the given graph.

**Proof.**  
The graph contains at least one triangle (guaranteed).  
During the enumeration, when the pair `(a*,b*)` belonging to the smallest
triangle is processed, Lemma&nbsp;4 shows the algorithm finds `c*` and outputs
the triangle, then terminates.  
By Lemma&nbsp;5 no earlier output could be larger, therefore the printed
triangle is exactly the lexicographically smallest one. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency*: `O(m)` time, `O(n)` integers (≈ 2000·2000 bits ≈ 0.5 MiB).  
*Main loops*: each edge `(a,b)` is examined once.
For each edge we perform a constant‑time bitwise `&` and a shift,
both `O(1)` on Python’s big integers (size ≤ 2000 bits).  
Hence total time `O(m) ≤ 2·10⁵`.  
Memory consumption: `O(n² / wordsize) ≈ 0.5 MiB` plus neighbour lists,
well below the limits.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * (n + 1)          # 1‑based
    nbr = [[] for _ in range(n + 1)]

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        if u == v:
            continue
        # set bits (0‑based)
        adj[u] |= 1 << (v - 1)
        adj[v] |= 1 << (u - 1)
        nbr[u].append(v)
        nbr[v].append(u)

    # sort neighbour lists for deterministic order
    for i in range(1, n + 1):
        nbr[i].sort()

    for a in range(1, n + 1):
        for b in nbr[a]:
            if b <= a:
                continue
            common = adj[a] & adj[b]
            # keep only vertices > b
            mask = common >> b
            if mask:
                low = mask & -mask          # lowest set bit
                offset = low.bit_length() - 1
                c = b + offset
                # a < b < c holds automatically
                sys.stdout.write(f"{a} {b} {c}")
                return

if __name__ == "__main__":
    solve()
```
