# Problem C — Proof of Impossibility

Time limit: 2 s   Memory limit: 256 MB

The factory still has only two shifts, 1 and 2, but the roster is known to be hopeless. Your job is not to schedule — it is to search the conflict data to certify the impossibility. 

Consider the conflict data as an incidence matrix where each row corresponds to a worker ID and each column corresponds to a conflict record, with a 1 indicating the worker is involved in that record and 0 otherwise. A deadlock is defined by a choice of exactly three columns such that the vector formed by summing these three columns contains exactly three 2s, and 0s everywhere else. Such a configuration provides an undeniable certificate that two shifts cannot suffice. Finding such a deadlock can appear daunting given the sheer number of possible subsets of columns to check.

It is guaranteed that the conflict data contains at least one such deadlock. Output the worker IDs involved in one such deadlock.

## Input
The first line contains two integers n and m (3 ≤ n ≤ 2000, 3 ≤ m ≤ min(n·(n−1)/2, 2·10⁵)).
Each of the next m lines contains two integers u v — the two worker IDs involved in a conflict record.
It is guaranteed that at least one deadlock exists.

## Output
Print three integers a b c on one line with a < b < c representing the three workers whose corresponding rows sum to 2 in the deadlock. Output the lexicographically smallest such group of workers (smallest a; ties by smallest b; then smallest c).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
I reframed the deadlock condition as a property of an incidence matrix, specifically looking for three columns whose sum yields exactly three 2s and 0s elsewhere. This removes the explanatory language that framed it as a graph or common-neighbor problem, forcing the model to mathematically deduce that this matrix condition is equivalent to finding a triangle in a graph.
</RATIONALE>
<PRESERVED_ANSWER>
The incidence matrix condition (three columns summing to exactly three 2s) is mathematically identical to finding three edges whose endpoints form a triangle, so the exact same deadlocks are found.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem still requires finding a triangle (K3) in a graph, which maintains the certificate-style infeasibility check and its O(m * n / 64) bitset complexity.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "vector formed by summing these three columns" if they don't realize it means the element-wise sum of the column vectors, though this is standard linear algebra terminology.
</RISK>
