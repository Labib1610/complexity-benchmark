**Solution Explanation**

For three reports (edges) to satisfy  

*“no worker appears an odd number of times”*  

the degree of every worker inside the three edges must be even.
The total degree of the three edges is `6`, therefore the only possible
even degree distribution is `2,2,2`.  
Consequently the three edges must connect exactly three different workers,
each pair of them being incompatible – i.e. the three edges form a **triangle**.

So the task is:

*find the lexicographically smallest triangle*  
`a < b < c` in the given undirected simple graph.

`n ≤ 2000`, therefore a bitset of length `n` fits into a Python `int`
(2000 bits ≈ 250 bytes).  
With bitsets the intersection of two neighbour sets is an `O(1)` operation.



--------------------------------------------------------------------

#### Data structures
* `adj[i]` – Python `int` whose `j‑th` bit (`j` from `0`) is `1`
  iff there is an edge `i – (j+1)`.
* adjacency list `g[i]` – all neighbours of vertex `i` (needed to iterate
  only over existing edges).

--------------------------------------------------------------------

#### Algorithm
```
read n, m
build adj[1..n] as 0
for each edge (u,v):
        set bit v-1 in adj[u] and bit u-1 in adj[v]
        add v to g[u], u to g[v]

for a = 1 .. n:
        for each b in g[a] with b > a:          # each edge a‑b once
                common = adj[a] & adj[b]        # vertices adjacent to both
                # we need c > b, otherwise (a,b,c) would not be sorted
                mask = ~((1 << b) - 1)          # bits b, b+1, … are 1
                common &= mask
                if common != 0:                # a triangle exists
                        # lowest set bit gives the smallest possible c
                        low = common & -common
                        c = low.bit_length()    # 1‑based index
                        output a b c and finish
```

*Why does the first found triangle give the lexicographically smallest
`(a,b,c)`?*  
The outer loops enumerate `a` increasingly, and for a fixed `a` enumerate
`b` increasingly (`b > a`).  
For a given pair `(a,b)` we take the smallest possible `c > b`.  
Therefore the first triangle discovered is exactly the minimal triple.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest
triangle.

---

##### Lemma 1  
A set of three edges satisfies the parity condition *iff* the three edges
form a triangle.

**Proof.**  
In any three edges the sum of vertex degrees equals `6`.  
If every vertex degree is even, the only possible multiset of degrees is
`{2,2,2}` (three vertices each of degree `2`).  
Thus exactly three distinct vertices are incident to the three edges and
each pair of them is connected – a triangle. ∎



##### Lemma 2  
When the algorithm processes a pair `(a,b)` (`a<b`) it finds a vertex `c`
iff the graph contains the triangle `{a,b,c}` with `c>b`.

**Proof.**  
`common = adj[a] & adj[b]` contains precisely the vertices adjacent to
both `a` and `b`.  
Masking with `mask` removes all vertices `≤ b`.  
Hence `common` is non‑zero exactly when there exists a vertex `c>b`
adjacent to both `a` and `b`, i.e. when `{a,b,c}` is a triangle with
ordered vertices. ∎



##### Lemma 3  
If the algorithm outputs `(a,b,c)`, then `(a,b,c)` is a triangle.

**Proof.**  
Output occurs only after Lemma&nbsp;2 guarantees existence of a vertex
`c>b` adjacent to both `a` and `b`.  
Edges `(a,b)`, `(a,c)`, `(b,c)` are present, therefore they form a triangle. ∎



##### Lemma 4  
The first triangle output by the algorithm is the lexicographically
smallest triangle in the graph.

**Proof.**  
The outer loop enumerates `a` in increasing order.
For a fixed `a`, the inner loop enumerates all neighbours `b>a` in
increasing order (the adjacency list can be sorted once, or we rely on
the natural order of iteration; we sort it for clarity).  
For each examined pair `(a,b)` the algorithm chooses the smallest possible
`c>b` (the least set bit of `common`).  
Thus any triangle `(a',b',c')` with `a' < a` would have been examined
earlier, and any triangle with the same `a` but `b' < b` would also have
been examined earlier.  
Consequently the first discovered triangle is minimal in the lexicographic
order `(a,b,c)`. ∎



##### Theorem  
The algorithm always terminates and prints the three worker IDs of a
deadlock, i.e. a triangle, which is lexicographically minimal among all
such triples.

**Proof.**  
Existence of at least one deadlock guarantees at least one triangle
(Lemma&nbsp;1).  
The double loop iterates over all edges, a finite set, therefore the
algorithm terminates.  
When it meets the first edge belonging to the minimal triangle, Lemma&nbsp;2
detects the third vertex and the algorithm outputs it.
By Lemma&nbsp;3 the output is indeed a triangle, and by Lemma&nbsp;4 it is
the lexicographically smallest one. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency:* `O(m)`  
*Main loops:* each edge `(a,b)` is processed once.
Intersection of two bitsets is a single integer `&` → `O(1)`.  
Thus total time `O(m)`.  
`m ≤ 2·10⁵`, well within the limit.

Memory: one `int` per vertex (`≈ 250 bytes`) → `O(n)` ≈ 0.5 MB,
plus adjacency lists `O(m)`. Fits easily into 256 MB.

--------------------------------------------------------------------

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * (n + 1)          # 1‑based
    g = [[] for _ in range(n + 1)]

    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u] |= 1 << (v - 1)
        adj[v] |= 1 << (u - 1)
        g[u].append(v)
        g[v].append(u)

    # sort adjacency lists to guarantee increasing order of b
    for lst in g:
        lst.sort()

    full_mask = (1 << n) - 1

    for a in range(1, n + 1):
        for b in g[a]:
            if b <= a:
                continue
            common = adj[a] & adj[b]
            # keep only vertices > b
            mask = full_mask ^ ((1 << b) - 1)   # bits b..n-1 are 1
            common &= mask
            if common:
                low = common & -common            # lowest set bit
                c = low.bit_length()             # 1‑based vertex id
                print(a, b, c)
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input‑output format.
