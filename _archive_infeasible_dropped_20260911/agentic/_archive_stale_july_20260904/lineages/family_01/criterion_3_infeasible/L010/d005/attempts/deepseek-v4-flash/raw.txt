We need to find three distinct reports (edges) such that each worker appears an even number of times (0 or 2) among them.  
That means the three edges form a triangle in the graph.  

So the problem reduces to: find the lexicographically smallest triangle in an undirected graph.  

We can do this by iterating over vertices in increasing order, and for each vertex, checking pairs of its neighbors to see if they are connected.  

Since n ≤ 2000, we can use an adjacency matrix (boolean) for O(1) edge checks.  

Here’s the implementation:  

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = adj[v][u] = True

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if adj[a][b]:
                for c in range(b + 1, n + 1):
                    if adj[a][c] and adj[b][c]:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    main()
```
