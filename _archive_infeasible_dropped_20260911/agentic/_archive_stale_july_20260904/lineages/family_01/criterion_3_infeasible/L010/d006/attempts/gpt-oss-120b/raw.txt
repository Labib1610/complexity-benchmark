**Solution Explanation**

For three reports (edges)  

```
a = {x , y}
b = {x , z}
c = {y , z}
```

the workers that appear in exactly one of the two edges are exactly the two
workers of the third edge, e.g.  

`a Δ b = {y , z} = c` , `a Δ c = {x , z} = b` , `b Δ c = {x , y} = a`.

So the required “deadlock’’ is exactly a **triangle** in the incompatibility
graph.

The task is therefore:

*given an undirected simple graph ( `n ≤ 2000` ), find a triangle.
Among all triangles output the lexicographically smallest sorted triple of
its three vertices.*

--------------------------------------------------------------------

#### 1.   Data structure – bitsets  

`n ≤ 2000`, therefore a 2000‑bit integer fits easily into a Python `int`.
For every vertex `v` we store

```
mask[v]  – an integer whose i‑th bit (0‑based) is 1  ⇔  edge (v , i+1) exists
```

All edges are distinct, so the masks are built in `O(m)` time.

--------------------------------------------------------------------

#### 2.   Enumerating triangles  

Consider an edge `(u , v)` with `u < v`.  
A vertex `w` forms a triangle with this edge **iff** it is adjacent to both
`u` and `v`, i.e. `w` belongs to the set

```
common = mask[u] & mask[v]
```

We need only triangles with `u < v < w` to avoid duplicates.
All vertices larger than `v` correspond to bits with index `≥ v`
(because vertex numbers are 1‑based, bit index = vertex‑1).

```
common_shifted = common >> v          # drop bits ≤ v‑1
```

If `common_shifted` is non‑zero, its lowest set bit gives the smallest possible
`w` for this edge:

```
low = common_shifted & -common_shifted          # lowest 1‑bit
pos = low.bit_length() - 1                      # its position (0‑based)
w   = v + pos + 1                               # back to vertex number
```

The triple `(u , v , w)` is a triangle, already sorted.
We keep the lexicographically smallest triple seen so far.

The whole algorithm:

```
best = None
for each edge (u , v) with u < v:
        common = mask[u] & mask[v]
        common_shifted = common >> v
        if common_shifted:
                low = common_shifted & -common_shifted
                pos = low.bit_length() - 1
                w = v + pos + 1
                cand = (u, v, w)
                if best is None or cand < best:
                        best = cand
```

`m ≤ 2·10⁵`, each iteration performs only a few integer operations – well
within the limits.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
sorted triple of vertices forming a triangle.

---

##### Lemma 1  
For any edge `(u , v)` with `u < v`, the algorithm finds the smallest vertex
`w > v` such that `{u , v , w}` is a triangle, if such a vertex exists.

**Proof.**  
`common = mask[u] & mask[v]` contains precisely the vertices adjacent to both
`u` and `v`.  
Shifting right by `v` removes all bits belonging to vertices `≤ v`.  
If the shifted value is non‑zero, its lowest set bit corresponds to the smallest
remaining vertex index, i.e. the smallest `w > v` in `common`. The conversion
back to a vertex number (`w = v + pos + 1`) is exact. ∎



##### Lemma 2  
Every triangle `{a , b , c}` with `a < b < c` is examined by the algorithm and
produces the candidate triple `(a , b , c)`.

**Proof.**  
The edge `(a , b)` appears in the input, and the algorithm processes it with
`u = a , v = b`.  
Since `c` is adjacent to both `a` and `b`, `c` belongs to `common`.  
Because `c > b = v`, after the shift `c` is still present, therefore
`common_shifted` is non‑zero and Lemma&nbsp;1 returns exactly this `c`. ∎



##### Lemma 3  
The set of candidate triples generated by the algorithm is exactly the set of
all triangles of the graph, each once.

**Proof.**  
*Existence*: by Lemma&nbsp;2 every triangle yields a candidate.  
*Uniqueness*: a triangle `{a , b , c}` (sorted) is generated only when the
algorithm processes edge `(a , b)`. For the other two edges the condition
`w > v` fails (`c` is not larger than the larger endpoint), so they do not
produce the same triple. ∎



##### Lemma 4  
`best` after the loop finishes is the lexicographically smallest sorted
triple among all triangles.

**Proof.**  
`best` is initialised to `None` and updated with `cand` whenever `cand < best`
(in lexicographic order). By Lemma&nbsp;3 every triangle appears as some
`cand`. The standard “keep the minimum while scanning’’ argument shows that
after scanning all candidates the stored value is the minimum of the whole
set. ∎



##### Theorem  
The algorithm outputs the IDs of the three workers of a deadlock, i.e. a
triangle, and among all possible deadlocks the printed sorted triple is
lexicographically minimal.

**Proof.**  
Existence of at least one triangle is guaranteed by the statement, therefore
the loop finds at least one candidate and `best` becomes defined.
By Lemma&nbsp;4 `best` is the minimal sorted triple of a triangle.
The program prints exactly this triple, satisfying the required output. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building masks*: `O(m)`  
*Main loop*: one iteration per edge → `O(m)` integer operations.  
All operations are on at most 2000‑bit integers, i.e. `O(1)` in Python.

Memory: `n` masks, each an integer ≤ 2ⁿ → `O(n)` ≈ 2000 integers.

Both time (`≤ 2·10⁵` simple operations) and memory fit easily into the limits.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    masks = [0] * (n + 1)          # 1‑based
    edges = []

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        if u > v:
            u, v = v, u
        edges.append((u, v))
        # set bits (0‑based)
        masks[u] |= 1 << (v - 1)
        masks[v] |= 1 << (u - 1)

    best = None

    for u, v in edges:            # u < v
        common = masks[u] & masks[v]
        # keep only vertices > v
        common_shifted = common >> v
        if common_shifted:
            low = common_shifted & -common_shifted
            pos = low.bit_length() - 1
            w = v + pos + 1
            cand = (u, v, w)
            if best is None or cand < best:
                best = cand

    # best is guaranteed to exist
    print(*best)

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
