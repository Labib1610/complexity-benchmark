 We need to find a triangle in an undirected graph. Since the graph is guaranteed to have at least one triangle, we can iterate over vertices and check for triangles efficiently.

A simple approach:  
- For each vertex `u`, check all pairs of its neighbors `(v, w)` and see if `v` and `w` are connected.  
- To get the lexicographically smallest triangle, we can iterate `u` from 1 to n, and for each `u`, check neighbors in increasing order.  
- We can use an adjacency matrix or a set for O(1) edge lookup.

Since `n ≤ 2000`, an adjacency matrix of size 2000×2000 is fine.

Here’s the implementation:

```python
n, m = map(int, input().split())
adj = [[False] * (n + 1) for _ in range(n + 1)]
neighbors = [[] for _ in range(n + 1)]

for _ in range(m):
    u, v = map(int, input().split())
    adj[u][v] = adj[v][u] = True
    neighbors[u].append(v)
    neighbors[v].append(u)

# Sort neighbors for lexicographic order
for i in range(1, n + 1):
    neighbors[i].sort()

# Find the smallest triangle
for a in range(1, n + 1):
    for b in neighbors[a]:
        if b <= a:
            continue
        for c in neighbors[b]:
            if c <= b:
                continue
            if adj[a][c]:
                print(a, b, c)
                exit()
```
