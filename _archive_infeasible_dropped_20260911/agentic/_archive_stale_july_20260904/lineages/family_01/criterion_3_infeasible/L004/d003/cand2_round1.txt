# Critical Interference

Time limit: 2 s
Memory limit: 256 MB

A radio frequency allocation system is being tested on a network of transmission towers. Each tower is assigned a unique identifier starting from 1 up to the total headcount of towers. The central registry requires at least three towers, but imposes a strict maximum capacity of two thousand towers in any network.

Because of signal overlap, certain pairs of towers create severe interference if they broadcast on the same frequency. The system only has two distinct frequencies available. 

The developers know that a valid two-frequency assignment is impossible for the given configurations. To prove this to the regulators, you must find a critical triplet: a set of three distinct towers where every tower in the set interferes with the other two. Any such triplet demonstrates that two frequencies are insufficient.

The number of interference records is at least three. The logging database has a strict limit of two hundred thousand records, so the total number of records will never exceed this capacity. Furthermore, there can be at most one record for any unique pair of towers, so the number of records is also bounded by this physical limit.

## Input
The first line contains two integers $n$ and $m$, representing the total headcount of towers and the number of interference records, respectively. 
Each of the next $m$ lines contains two integers $u$ and $v$, representing a pair of towers that interfere with each other.
It is guaranteed that at least one critical triplet exists.

## Output
Print three integers on one line, representing the identifiers of the three towers that form the critical triplet. The three identifiers must be printed from smallest to largest.
If multiple critical triplets exist, select the one whose first identifier is as small as possible. If there is still a tie, minimize the second identifier, and finally the third.

## Example 1
### Input
```
4 5
1 2
1 3
2 3
2 4
3 4
```
### Output
```
1 2 3
```

## Example 2
### Input
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
### Output
```
1 2 4
```
