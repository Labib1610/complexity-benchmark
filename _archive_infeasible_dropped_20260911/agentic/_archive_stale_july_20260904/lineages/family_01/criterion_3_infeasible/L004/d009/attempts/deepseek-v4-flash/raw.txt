 We need to find a triplet of vertices (a, b, c) with a < b < c such that the quadratic form  
E(x1, x2, x3) = x1² + 4x2² + 9x3² − 2x1x2·I12 − 6x2x3·I23 − 3x1x3·I13  
can be zero for some nonzero real (x1, x2, x3).

This is equivalent to the matrix  
```
[ 1      -I12    -1.5*I13 ]
[-I12     4      -3*I23   ]
[-1.5*I13 -3*I23   9      ]
```
being singular (determinant = 0), because the quadratic form is xᵀ M x, and zero for nonzero x means M is not positive definite (here it's symmetric, so singular).

We can compute the determinant condition for each triplet.

Let’s denote:
- I12 = 1 if edge (a,b) exists else 0
- I23 = 1 if edge (b,c) exists else 0
- I13 = 1 if edge (a,c) exists else 0

The determinant of M:

```
det = 1*(4*9 - (-3*I23)^2) 
    - (-I12)*((-I12)*9 - (-1.5*I13)*(-3*I23))
    + (-1.5*I13)*((-I12)*(-3*I23) - 4*(-1.5*I13))
```

Let’s simplify:

First term: 1*(36 - 9*I23²) = 36 - 9*I23²  
Since I23 is 0 or 1, I23² = I23, so = 36 - 9*I23.

Second term: -(-I12) = +I12, times [ (-I12)*9 - (-1.5*I13)*(-3*I23) ]  
= I12 * [ -9*I12 - (4.5*I13*I23) ]  
= I12 * [ -9*I12 - 4.5*I13*I23 ]  
= -9*I12² - 4.5*I12*I13*I23  
Since I12² = I12, = -9*I12 - 4.5*I12*I13*I23.

Third term: (-1.5*I13) * [ (-I12)*(-3*I23) - 4*(-1.5*I13) ]  
= (-1.5*I13) * [ 3*I12*I23 + 6*I13 ]  
= -4.5*I12*I13*I23 - 9*I13²  
= -4.5*I12*I13*I23 - 9*I13.

Sum:  
det = (36 - 9*I23) + (-9*I12 - 4.5*I12*I13*I23) + (-4.5*I12*I13*I23 - 9*I13)  
= 36 - 9*I23 - 9*I12 - 9*I13 - 9*I12*I13*I23.

So det = 36 - 9*(I12 + I13 + I23 + I12*I13*I23).

Set det = 0:  
36 - 9*(I12 + I13 + I23 + I12*I13*I23) = 0  
=> I12 + I13 + I23 + I12*I13*I23 = 4.

Since each I is 0 or 1, the only way to get sum = 4 is if all three are 1 (since 1+1+1+1=4).  
So the condition is: all three edges among the triplet exist → it's a triangle.

Thus the problem reduces to: find the lexicographically smallest triangle in the graph.

We can do this by iterating a from 1 to n, b from a+1 to n, c from b+1 to n, and checking if all three edges exist. Since n ≤ 2000, O(n³) is too slow (8e9). We need a better approach.

We can use adjacency sets and iterate over edges (a,b) with a<b, then for each common neighbor c > b, check if (a,c) and (b,c) exist. That's O(m * degree) worst-case, but with m up to 2e5 and n=2000, it's feasible if we use sets.

We want lexicographically smallest (a,b,c). So we can iterate a from 1..n, then b from a+1..n, and check if there is a c > b such that both (a,c) and (b,c) exist. We can find the smallest such c by intersecting adjacency sets.

Implementation plan:
- Build adjacency sets for each vertex.
- For a in 1..n:
  - For b in a+1..n:
    - If (a,b) not in edges, skip.
    - Compute common = adj[a] & adj[b]
    - Filter c > b, take min.
    - If found, print and exit.

This is O(n² * set_intersection) but n=2000, so n²=4e6, each intersection is O(degree) but with sets it's fast enough.

Let's code it.```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n+1)]
    edges = set()
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
        edges.add((u, v) if u < v else (v, u))
    
    for a in range(1, n+1):
        for b in range(a+1, n+1):
            if (a, b) not in edges:
                continue
            # find smallest c > b that is connected to both a and b
            common = adj[a] & adj[b]
            for c in sorted(common):
                if c > b:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    solve()
```
