# Critical Interference

Time limit: 2 s
Memory limit: 256 MB

An experimental security framework is being tested to partition $n$ communication terminals (labeled 1 through $n$) into two separate operational frequencies. During testing, engineers discovered $m$ hardware links that produce critical interference. This interference is always asymmetric: between any two linked terminals, the one with the lower numerical label broadcasts a jamming wave to the terminal with the higher numerical label. This physical rule applies no matter how the link is recorded in the system logs.

Because of these jamming waves, a valid two-frequency partition cannot be achieved. You must provide a proof of this failure. To do so, locate three distinct terminals $a$, $b$, and $c$ (where $a < b < c$) that mutually interfere in the following pattern:
- Terminal $a$ broadcasts a jamming wave to terminal $b$.
- Terminal $a$ broadcasts a jamming wave to terminal $c$.
- Terminal $b$ broadcasts a jamming wave to terminal $c$.

Finding this specific triad of terminals confirms the framework's flaw. At least one such triad is guaranteed to be present in the network.

## Input
The first line provides two integers $n$ and $m$, representing the terminal headcount and hardware link count respectively ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$).
The subsequent $m$ lines each contain two integers $u$ and $v$ — indicating a hardware link between these terminals. The jamming wave always propagates from the terminal with the smaller identifier to the terminal with the larger identifier.
The network is guaranteed to contain at least one triad meeting the failure conditions.

## Output
Output a single line containing three integers $a$, $b$, and $c$ with $a < b < c$, representing the labels of the chosen terminals.
If multiple valid triads exist, you must output the lexicographically smallest one (prioritizing the smallest value for $a$, then for $b$, and finally for $c$).

## Example 1
### Input
```
4 5
1 2
1 3
2 3
2 4
3 4
```
### Output
```
1 2 3
```

## Example 2
### Input
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
### Output
```
1 2 4
```
