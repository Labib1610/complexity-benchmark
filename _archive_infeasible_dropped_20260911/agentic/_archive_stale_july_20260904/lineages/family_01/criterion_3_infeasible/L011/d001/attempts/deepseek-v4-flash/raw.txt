 We need to find a triangle (three vertices all pairwise connected) in the graph, and among all triangles, pick the one with the smallest lexicographic order of its vertices.

Since \( n \) can be up to 2000, we can use an adjacency matrix for O(1) edge checks.  
We iterate over all triples \( (a, b, c) \) with \( a < b < c \) and check if all three edges exist. The first one we find in lexicographic order is the answer.

Here’s the implementation:

```python
n, m = map(int, input().split())
adj = [[False] * (n + 1) for _ in range(n + 1)]

for _ in range(m):
    u, v = map(int, input().split())
    adj[u][v] = adj[v][u] = True

for a in range(1, n + 1):
    for b in range(a + 1, n + 1):
        if not adj[a][b]:
            continue
        for c in range(b + 1, n + 1):
            if adj[a][c] and adj[b][c]:
                print(a, b, c)
                exit()
```
