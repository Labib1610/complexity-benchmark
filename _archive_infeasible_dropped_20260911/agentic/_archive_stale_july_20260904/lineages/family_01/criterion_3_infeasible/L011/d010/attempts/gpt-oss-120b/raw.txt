**Solution Explanation**

For three different steps `a < b < c` we build the three vectors  

```
v_a = ( x_a1 , x_a2 , x_a3 )
v_b = ( x_b1 , x_b2 , x_b3 )
v_c = ( x_c1 , x_c2 , x_c3 )
```

```
x_i j = a_i + a_j   if steps i and j share a tool
x_i j = 0           otherwise
```

The three vectors are linearly independent **iff** the 3×3 matrix whose rows are
`v_a , v_b , v_c` has non‑zero determinant.

The matrix (rows `a , b , c`) is

```
[ 0               e_ab·(a+b)   e_ac·(a+c) ]
[ e_ab·(a+b)      0            e_bc·(b+c) ]
[ e_ac·(a+c)      e_bc·(b+c)   0          ]
```

`e_xy` is `1` when the edge `{x,y}` exists, otherwise `0`.

For a symmetric matrix with zero diagonal and off‑diagonal entries `x , y , z`

```
| 0  x  y |
| x  0  z |   determinant = 2·x·y·z
| y  z  0 |
```

Therefore

```
det = 2 · (e_ab·(a+b)) · (e_ac·(a+c)) · (e_bc·(b+c))
```

All identifiers are positive, so the product is non‑zero **iff**
`e_ab = e_ac = e_bc = 1`, i.e. the three steps form a triangle
(a 3‑clique) in the given graph.

Consequently the problem is reduced to:

*find the lexicographically smallest triangle*.

--------------------------------------------------------------------

#### Finding the smallest triangle

`n ≤ 2000`, so an `n × n` adjacency matrix fits easily
(≈ 4 MiB).  
We store each row as a Python `int` bitset: bit `v‑1` is `1`
iff the edge `{row , v}` exists.

For every edge `{a,b}` with `a < b`

```
common = adjacency[a] & adjacency[b]          # vertices adjacent to both a and b
common >>= b                                   # discard vertices ≤ b
if common != 0:
        tz = (common & -common).bit_length() - 1   # index of lowest set bit
        c = b + 1 + tz
        answer = (a,b,c)   # this is the first triangle, thus lexicographically minimal
        stop
```

Why is it the first triangle?

* we iterate `a` from `1` to `n`
* for a fixed `a` we iterate `b` from `a+1` to `n`
* the first `c` we obtain is the smallest possible `c > b`

Hence the first found triple is exactly the lexicographically smallest one.

The total work is `O(m)` bit operations, well below the limits.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest
triple of steps whose vectors are linearly independent.

---

##### Lemma 1  
For three distinct steps `a,b,c` the vectors `v_a , v_b , v_c` are linearly
independent **iff** `{a,b,c}` is a triangle in the graph.

**Proof.**  
From the determinant calculation above  

```
det = 2·(e_ab·(a+b))·(e_ac·(a+c))·(e_bc·(b+c))
```

All factors `(a+b) , (a+c) , (b+c)` are positive.
Thus `det ≠ 0` ⇔ each `e_xy = 1` ⇔ every pair among `{a,b,c}` is an edge,
i.e. they form a triangle. ∎



##### Lemma 2  
When the algorithm examines an edge `{a,b}` (`a<b`) and finds a vertex
`c` as described, the triple `(a,b,c)` is a triangle.

**Proof.**  
`common = adjacency[a] & adjacency[b]` contains exactly the vertices
adjacent to **both** `a` and `b`. After shifting right by `b`,
the lowest set bit corresponds to the smallest vertex `c > b`
adjacent to both. Hence edges `{a,c}` and `{b,c}` exist, together with
`{a,b}` we have a triangle. ∎



##### Lemma 3  
If the algorithm outputs `(a,b,c)`, then no triangle `(a',b',c')`
with lexicographically smaller order exists.

**Proof.**  
The outer loops enumerate pairs `(a,b)` in increasing lexicographic order:
first by `a`, then by `b`.  
For a fixed pair the algorithm chooses the smallest possible `c>b`
that together with `a,b` forms a triangle (Lemma&nbsp;2).  
Therefore any triangle with a smaller `a` would have been examined earlier,
and any triangle with the same `a` but smaller `b` also earlier.
If `a` and `b` are equal, the chosen `c` is the smallest possible,
so no triangle with the same `a,b` and smaller `c` exists.
Thus the first triangle found is the lexicographically smallest. ∎



##### Lemma 4  
The algorithm always finds a triangle.

**Proof.**  
The statement of the problem guarantees at least one triangle.
When the outer loops eventually reach the smallest such triangle,
its three edges are present, so the intersection test succeeds and the
algorithm outputs it. ∎



##### Theorem  
The algorithm prints three integers `a<b<c` that form an unresolvable
bottleneck, and the printed triple is the lexicographically smallest
among all such triples.

**Proof.**  
By Lemma&nbsp;4 the algorithm outputs some triple.
By Lemma&nbsp;2 this triple is a triangle, therefore by Lemma&nbsp;1 its
vectors are linearly independent, i.e. it is an unresolvable bottleneck.
Lemma&nbsp;3 shows that no lexicographically smaller triangle exists.
Hence the output satisfies the required specification. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Memory* : adjacency matrix as `n` integers → `O(n)` bits ≈ 4 MiB.  

*Time* :

```
building adjacency : O(m)
outer loops over edges : each edge examined once → O(m) bit operations
finding lowest set bit : O(1)
```

Overall `O(m)` time, at most `2·10^5` operations, easily within 2 seconds.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * (n + 1)          # 1‑based, bit i‑1 corresponds to vertex i
    edges = []                   # list of (a,b) with a<b

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        if u == v:
            continue
        if u > v:
            u, v = v, u
        # set bits
        adj[u] |= 1 << (v - 1)
        adj[v] |= 1 << (u - 1)
        edges.append((u, v))

    # sort edges to guarantee lexicographic order of (a,b)
    edges.sort()

    for a, b in edges:
        # vertices adjacent to both a and b
        common = adj[a] & adj[b]
        # discard vertices <= b
        common >>= b
        if common:
            # index of lowest set bit
            tz = (common & -common).bit_length() - 1
            c = b + 1 + tz
            print(a, b, c)
            return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
