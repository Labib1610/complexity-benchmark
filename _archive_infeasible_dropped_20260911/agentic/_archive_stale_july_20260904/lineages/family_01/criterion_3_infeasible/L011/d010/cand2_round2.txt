# Distributed Consensus Diagnostics

Time limit: 2 s   Memory limit: 256 MB

A distributed database cluster uses a two-phase commit protocol. The cluster consists of $n$ nodes. Certain pairs of nodes have a bidirectional high-speed synchronization link.

The system administrator is trying to partition the cluster into exactly two independent sub-networks such that no two nodes within the same sub-network share a synchronization link. This operation has failed. Your diagnostic software must isolate a minimal certificate of this failure by identifying a "consensus deadlock": a group of exactly three distinct nodes that structurally prevents such a partition. Because these three nodes are completely interconnected, any attempt to divide them into only two sub-networks will inevitably place at least one linked pair in the same sub-network.

A group of exactly three distinct nodes forms a consensus deadlock if and only if, for every node in the group, its synchronization links include both of the other two nodes in the group.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), representing the total number of nodes and the number of synchronization links. Nodes are numbered from $1$ to $n$.

Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that node $u$ and node $v$ share a synchronization link.

It is guaranteed that at least one consensus deadlock exists in the provided data.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, with $a < b < c$, representing the identifiers of the three nodes that form a consensus deadlock. If multiple such groups exist, output the one that is lexicographically smallest (i.e., the one with the smallest possible value for $a$; in case of a tie, the smallest possible value for $b$; and finally the smallest possible value for $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
