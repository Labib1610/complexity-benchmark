 We need to find a triple of vertices (a, b, c) such that exactly 12 of the 27 possible assignments of values 1, 2, 3 to them result in a "relaxed" state (tension = 2).  

Let’s analyze the condition.  
For three vertices, the edges among them are either present or not. The tension is the sum of absolute differences over all edges present in the triple.  

We can brute-force check all triples, but n can be up to 2000, so O(n^3) is too slow. We need a smarter approach.  

First, let's understand the condition mathematically.  
For a triple (a, b, c), let’s denote the edges among them:  
- If all three edges are present (triangle), then tension = |x-y| + |y-z| + |z-x|.  
- If exactly two edges are present (a path), say edges (a,b) and (b,c), then tension = |x-y| + |y-z|.  
- If exactly one edge is present, tension = |x-y|.  
- If no edges, tension = 0.  

We need exactly 12 of the 27 assignments to have tension = 2.  

Let’s check each case:  

**Case 1: No edges** → tension always 0 → 0 relaxed states.  

**Case 2: One edge** → tension = |x-y|. This equals 2 only when the two values differ by 2. For values {1,2,3}, that happens for (1,3) or (3,1) → 2 assignments for that edge, and the third vertex can be any of 3 values → 2*3 = 6 relaxed states. Not 12.  

**Case 3: Two edges (path)** → tension = |x-y| + |y-z|. We need this sum = 2.  
Possible combinations:  
- (1,2,1): |1-2|+|2-1| = 1+1=2  
- (2,1,2): 1+1=2  
- (2,3,2): 1+1=2  
- (3,2,3): 1+1=2  
- (1,3,1): 2+2=4 (no)  
- (3,1,3): 2+2=4 (no)  
- (1,2,3): 1+1=2? Wait |1-2|=1, |2-3|=1 → sum=2. Yes.  
- (3,2,1): 1+1=2.  
- (1,3,2): 2+1=3 (no)  
- (2,3,1): 1+2=3 (no)  
- (2,1,3): 1+2=3 (no)  
- (3,1,2): 2+1=3 (no)  

So valid assignments: (1,2,1), (2,1,2), (2,3,2), (3,2,3), (1,2,3), (3,2,1) → 6 assignments. Not 12.  

**Case 4: Triangle** → tension = |x-y| + |y-z| + |z-x|.  
We need sum = 2.  
Possible values:  
- All same: 0  
- Two same, one different: e.g., (1,1,2): |0|+|1|+|1| = 2 → yes.  
  Similarly (1,2,1), (2,1,1), (1,1,3): 0+2+2=4 (no), (1,3,1): 2+0+2=4 (no), (3,1,1): 2+2+0=4 (no).  
  So only when the two same values are 1 and the different is 2, or two same are 2 and different is 1, or two same are 2 and different is 3, or two same are 3 and different is 2.  
  Let’s count:  
  - Two 1's and one 2: permutations: (1,1,2), (1,2,1), (2,1,1) → 3  
  - Two 2's and one 1: (2,2,1), (2,1,2), (1,2,2) → 3  
  - Two 2's and one 3: (2,2,3), (2,3,2), (3,2,2) → 3  
  - Two 3's and one 2: (3,3,2), (3,2,3), (2,3,3) → 3  
  Total = 12.  

So the condition "exactly 12 relaxed states" happens **only** when the triple forms a triangle (all three edges present).  

Thus, we just need to find the lexicographically smallest triangle in the graph.  

We can do this by iterating over a in increasing order, then b > a, and check if edge (a,b) exists, then for c > b, check if edges (a,c) and (b,c) exist.  

Since n ≤ 2000, we can store adjacency as a boolean matrix or set for O(1) checks. O(n^3) worst-case is 8e9, too slow. But we can break early: we only need the first triangle found in lexicographic order.  

We can iterate a from 1 to n, b from a+1 to n, and if edge (a,b) exists, then for c from b+1 to n, check if (a,c) and (b,c) exist. The first found is the answer.  

Worst-case if no triangle, we might check many, but we can optimize: for each a, we can get list of neighbors > a, then for each pair of neighbors (b,c) with b<c, check if edge (b,c) exists. That’s O(sum over a of deg(a)^2) which could be large but with n=2000 and m up to 2e5, it's acceptable if we break early.  

We'll implement with adjacency sets for O(1) edge checks.  

```python
n, m = map(int, input().split())
adj = [set() for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].add(v)
    adj[v].add(u)

for a in range(n):
    for b in adj[a]:
        if b > a:
            for c in adj[a]:
                if c > b and c in adj[b]:
                    print(a+1, b+1, c+1)
                    exit()
```
