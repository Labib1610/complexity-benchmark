<STATEMENT>
# Production Line Diagnostics

Time limit: 2 s   Memory limit: 256 MB

A manufacturing facility operates continuously. Certain pairs of manufacturing steps require a shared specialized calibration tool. 

Your diagnostic software must isolate a root cause of an allocation failure by identifying a group of exactly three steps that form an unresolvable bottleneck. 

Consider any group of exactly three distinct steps. We evaluate the group by assigning each of its three steps a polarity of either $+1$ or $-1$. There are exactly $2^3 = 8$ possible polarity assignments for the group.

For a given assignment, we calculate the group's *internal tension*. For every shared calibration tool required by a pair of steps within the group, we multiply the polarities of those two steps. The internal tension $T$ is the sum of these products over all shared tools within the group.

An assignment's *feedback* is defined as the cube of its internal tension (i.e., $T^3$).

A group of three distinct steps is classified as an unresolvable bottleneck if the sum of the feedback values across all 8 possible polarity assignments is exactly 48.

## Input
The first line provides the total number of manufacturing steps $n$ and the number of shared tool requirements $m$.
The facility layout features exactly 2000 distinct bays, meaning the number of steps $n$ can be at most 2000, while a minimum of 3 steps is required for a valid configuration. 
The number of shared tool requirements $m$ is also at least 3. The maintenance log can store up to 200,000 tool sharing records, so $m$ is bounded by this storage limit or the maximum possible number of unique pairs of steps, whichever is smaller.

Each of the subsequent $m$ lines contains two distinct integers $u$ and $v$ between 1 and $n$, representing a shared calibration tool between step $u$ and step $v$. Each pair of steps shares at most one calibration tool.

It is guaranteed that at least one unresolvable bottleneck exists in the provided data.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, with $a < b < c$, representing the identifiers of the three steps that form an unresolvable bottleneck. If multiple such groups exist, output the combination that is sequentially lowest: the one with the smallest possible value for $a$; in case of a tie, the smallest possible value for $b$; and finally the smallest possible value for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
I replaced the boolean/parity condition (which models easily recognize as a 2-coloring/triangle check) with a mathematically equivalent polynomial invariant over {-1, 1}. Specifically, the problem now asks for a group of 3 steps where the sum of the cubed edge-weights over all 8 polarity assignments equals 48. This forces the model to either algebraically simplify the sum to prove it is mathematically identical to checking for 3 edges (a triangle), or attempt a literal $O(n^3)$ simulation of the 8 assignments which will fail the time limit. The numeric bounds were also rewritten into the scenario text (Strategy S07) to remove bare inequalities.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic expansion of the sum of $T^3$ over all 8 polarity assignments evaluates to exactly 48 if and only if all three possible edges exist between the three steps, meaning the target structure is still exactly a triangle.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a 3-cycle (triangle) in an undirected graph, which remains solvable in identical polynomial time using bitset intersections or adjacency iteration.
</PRESERVED_CLASS>
