 We need to find a triangle in the graph (three mutually connected vertices) with the smallest lexicographical order.  
Since the graph is undirected, we can iterate over vertices in increasing order and check for triangles.

Here’s the approach:
- Read `n` and `m`.
- Build an adjacency set for O(1) edge lookups.
- For each `a` from 1 to n:
  - For each `b` in neighbors of `a` where `b > a`:
    - For each `c` in neighbors of `a` where `c > b`:
      - If `c` is also a neighbor of `b`, we found a triangle `(a, b, c)`.
      - Since we iterate in increasing order, the first found is the lexicographically smallest.

We can optimize by only checking neighbors of `a` that are greater than `a`, and then checking if `b` and `c` are connected.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        for b in sorted(adj[a]):
            if b <= a:
                continue
            for c in sorted(adj[a]):
                if c <= b:
                    continue
                if c in adj[b]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
