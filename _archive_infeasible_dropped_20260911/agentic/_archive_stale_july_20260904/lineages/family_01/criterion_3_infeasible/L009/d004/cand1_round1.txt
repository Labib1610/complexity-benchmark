<STATEMENT>
# Problem C — Proof of Impossibility

Time limit: 2 s   Memory limit: 256 MB

The laboratory protocol requires isolating reactive materials to prevent hazards. We define a *safe set* of materials as any group where no two materials in the group are mutually volatile according to the provided registry. 

Your task is to identify a minimal certificate of instability. A certificate consists of exactly three distinct materials with the following property: if we restrict our attention only to these three materials, the maximum number of materials you can select from this trio to form a safe set is exactly one. 

It is guaranteed that the provided registry contains at least one such certificate.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a mutually volatile pair.
It is guaranteed that a certificate of three materials exists.

## Output
Print three integers $a$, $b$, and $c$ on one line with $a < b < c$ representing the materials of a minimal certificate. Output the lexicographically smallest such certificate (smallest $a$; ties by smallest $b$; then smallest $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
The models were using the "two separate storage units" framing to recognize a 2-coloring impossibility, which trivially reduces to finding a triangle (K3) on three vertices. This rewrite removes the bipartite coloring affordance entirely. Instead, it defines the certificate using an independent set constraint (maximum safe set size of 1 within the trio), which mathematically forces all three pairs to be volatile but requires the model to genuinely deduce this equivalence.
</RATIONALE>
<PRESERVED_ANSWER>
If the maximum size of a safe set within a trio is exactly one, then no two materials in the trio can be safe together, meaning every pair is mutually volatile (a triangle); thus the required output is identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the task of finding the lexicographically smallest triangle (K3) in a graph, preserving the O(n*m/64) complexity class and intended bitset algorithm.
</PRESERVED_CLASS>
