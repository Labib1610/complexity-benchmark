 We need to find a triple of vertices such that among them, the maximum number of vertices we can pick without picking two that are connected by an edge is exactly 1.  
That means:  
- The triple must contain at least one edge (otherwise we could pick all 3).  
- The triple must not contain a triangle (otherwise we could pick only 1, but the condition says maximum is exactly 1, so a triangle would give max 1, but that’s allowed? Wait, let’s check:  
If the triple is a triangle, then any two are connected, so we can pick at most 1 vertex. That satisfies “maximum is exactly 1”.  
If the triple has exactly one edge, then we can pick the two non-connected vertices, so max is 2 — not allowed.  
If the triple has two edges (a path of length 2), then we can pick the two endpoints, so max is 2 — not allowed.  
If the triple has no edges, max is 3 — not allowed.  

So the only allowed case is a triangle.  
Thus we need to find the lexicographically smallest triangle in the graph.

We can do this by iterating over vertices in increasing order, and for each vertex `a`, check its neighbors in increasing order, and for each neighbor `b > a`, check if there is a common neighbor `c > b` that is connected to both. The first found is the answer.

We can use adjacency sets for O(1) edge checks.

```python
n, m = map(int, input().split())
adj = [set() for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].add(v)
    adj[v].add(u)

for a in range(n):
    for b in sorted(adj[a]):
        if b > a:
            for c in sorted(adj[a]):
                if c > b and c in adj[b]:
                    print(a+1, b+1, c+1)
                    exit()
```
