# Problem C — Dense Triplets

Time limit: 2 s   Memory limit: 256 MB

You are given a dataset containing $n$ items and a list of $m$ distinct, unordered pairs of these items.

A *dense triplet* is a selection of exactly three pairs from the provided list such that, when you collect all the items mentioned across these three selected pairs, there are exactly three distinct items in total. 

Your task is to identify the three items that make up a dense triplet. It is guaranteed that the provided list contains at least one such selection of three pairs.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of items in the dataset.
It is guaranteed that a dense triplet exists.

## Output
Print three integers $a$, $b$, and $c$ on one line with $a < b < c$ representing the exactly three distinct items involved in a dense triplet. If there are multiple valid sets of three items that can be formed this way, output the sequence $(a, b, c)$ that is lexicographically smallest (i.e., smallest $a$; ties broken by smallest $b$; then smallest $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
Replaced the "impossibility of 2-unit assignment" framing with an edge-centric combinatorial definition: selecting three pairs that collectively contain exactly three distinct items. This completely removes the bipartite/2-coloring affordance that models used to immediately recognize the target as a triangle. Models that literally translate the new definition will attempt an $O(M^3)$ search over triplets of edges and fail the time limit; to succeed, they must deduce that this structure is mathematically equivalent to a triangle and use an efficient graph algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
In a simple graph, the only way to select 3 distinct edges that span exactly 3 distinct vertices is if those 3 edges form a triangle (K3), meaning the valid sets of three items are exactly identical to the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying task remains searching for a triangle (K3) in an undirected graph, preserving the exact structural complexity and requiring the same algorithmic optimization to pass.
</PRESERVED_CLASS>
<RISK>

</RISK>
