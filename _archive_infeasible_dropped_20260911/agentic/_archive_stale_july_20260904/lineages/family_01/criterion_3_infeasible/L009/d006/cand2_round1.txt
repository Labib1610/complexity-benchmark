<METHOD_DESCRIPTION>Replaces the impossibility of 2-coloring (putting 3 items in 2 containers) with a logically equivalent property based on omitting elements: "if any one of the three materials is set aside, the remaining two are always documented as a mutually volatile pair." This breaks the "bipartite/2-coloring" pattern match while perfectly describing a triangle.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem C — Proof of Impossibility

Time limit: 2 s   Memory limit: 256 MB

The laboratory protocol requires isolating reactive materials to prevent hazards. Certain pairs of materials are documented as mutually volatile.

Your task is to identify a core instability triplet. A triplet consists of exactly three distinct materials with the following property: if any one of the three materials is set aside, the remaining two are always documented as a mutually volatile pair.

It is guaranteed that the provided registry contains at least one such triplet.

## Input
The first line contains two integers $n$ and $m$. The facility handles a number of distinct materials, $n$. To permit at least one triplet, $n$ is no less than three, and its maximum capacity is two thousand. 
The documentation system contains $m$ records of mutually volatile pairs. The number of records is at least three, and never exceeds two hundred thousand (or the theoretical maximum number of unique pairs for $n$ materials, whichever is smaller).
Each of the next $m$ lines contains two integers $u$ and $v$ — a mutually volatile pair.
It is guaranteed that a core instability triplet exists.

## Output
Print three integers $a$, $b$, and $c$ on one line with $a < b < c$ representing the materials of a core instability triplet. Output the lexicographically smallest such triplet (smallest $a$; ties by smallest $b$; then smallest $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
I removed the "two containers" framing, which models were using as a shortcut to recognize a 2-coloring/bipartite impossibility condition (which for 3 nodes is a triangle). Instead, I defined the triplet by the property of its subsets of size 2. This forces the model to reason about the implications of the subset property rather than pattern-matching the bipartite definition. I also applied S07 by describing the bounds indirectly via physical capacities.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that any two materials from the chosen three form a volatile pair is logically identical to a triangle (a 3-clique), which is exactly what the original "impossible to partition into two valid containers" condition required.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core computational task remains finding a triangle in an undirected graph, preserving the $O(nm/64)$ bitset intersection complexity class.
</PRESERVED_CLASS>
