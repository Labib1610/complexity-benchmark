Looking at this problem, I need to find three distinct materials where the product of their internal reactivity scores equals 8.

For three materials, each can have internal reactivity 0, 1, or 2 (number of edges to the other two in the trio). The product must be 8 = 2×2×2, meaning all three materials must have internal reactivity 2. This means all three pairs must be edges - it's a triangle (3-clique).

So I need to find the lexicographically smallest triangle in the graph.

**Approach:**
- For each vertex `a` from 1 to n, look at its neighbors with ID > a
- For each pair of neighbors (b, c) where b < c, check if there's an edge between b and c
- The first triangle found this way is lexicographically smallest (since we iterate a from smallest, then b, then c)

To make the edge check efficient, I'll use bitsets. With n ≤ 2000, I can represent each vertex's adjacency as a Python integer (bitset). Checking if b and c are connected is just checking if bit c is set in adj[b].

For efficiency, when processing vertex `a`, I iterate through pairs of its neighbors. To optimize, I can use bitset operations: for each neighbor b of a (with b > a), compute the intersection of adj[a] and adj[b], then find all bits > b in that intersection - those give valid c values.

```python
import sys

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [0] * (n + 1)
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        if u > v:
            u, v = v, u
        adj[u] |= (1 << v)
        adj[v] |= (1 << u)
    
    for a in range(1, n + 1):
        neighbors_a = adj[a]
        b = a + 1
        while b <= n:
            if (neighbors_a >> b) & 1:
                # Find c > b where c is neighbor of both a and b
                common = neighbors_a & adj[b]
                # Mask to keep only bits > b
                mask = ~((1 << (b + 1)) - 1)
                common &= mask
                if common:
                    # Find lowest set bit
                    c = (common & -common).bit_length() - 1
                    print(f"{a} {b} {c}")
                    return
            b += 1
    
    # Should not reach here per problem guarantee
    print("-1")

solve()
```

Wait, the inner loop iterating through all b could be slow if a has many neighbors. Let me optimize by only iterating through actual neighbors of a.

Actually, with n ≤ 2000 and using bitset intersection, the approach is: for each a, for each neighbor b > a, compute intersection and find smallest c > b. The total work is O(sum of degrees) for the b-loop, and each intersection is O(n/64) bit operations. This should be efficient enough.

Let me refine to iterate only over actual neighbors:

```python
import sys

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [0] * (n + 1)
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        adj[u] |= (1 << v)
        adj[v] |= (1 << u)
    
    for a in range(1, n + 1):
        neighbors_a = adj[a]
        # Iterate through neighbors b > a
        temp = neighbors_a >> (a + 1)
        while temp:
            lsb = temp & (-temp)
            b = (lsb.bit_length() - 1) + (a + 1)
            temp ^= lsb
            
            common = neighbors_a & adj[b]
            mask = ~((1 << (b + 1)) - 1)
            common &= mask
            if common:
                c = (common & -common).bit_length() - 1
                print(f"{a} {b} {c}")
                return
    
    print("-1")

solve()
```

This should correctly find the lexicographically smallest triangle efficiently.
