<STATEMENT>
# Problem C — Resilient Triad

Time limit: 2 s   Memory limit: 256 MB

A planetary communication grid consists of multiple relay stations. Certain pairs of stations are connected by direct, bidirectional transmission links.

To ensure critical emergency broadcasts are never interrupted, the network administrators want to identify a *Resilient Triad*. A Resilient Triad is a group of exactly three distinct relay stations that meets the following strict redundancy standard:
1. **Internal Routing**: For any two stations in the triad, it must be possible to transmit data between them. Data can be routed through a sequence of links, but every link used in the transmission must strictly connect two stations that are both members of the triad.
2. **Link Redundancy**: If any single transmission link between members of the triad is permanently disabled, the Internal Routing requirement must still be fully satisfied for all three stations using only the surviving links within the triad.

It is guaranteed that the provided network contains at least one such Resilient Triad.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), representing the number of relay stations and the number of transmission links, respectively. Stations are numbered from $1$ to $n$.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), representing a bidirectional transmission link between station $u$ and station $v$. It is guaranteed that no two links connect the same pair of stations.
It is guaranteed that a Resilient Triad exists.

## Output
Print three integers $a$, $b$, and $c$ on one line with $a < b < c$ representing the stations of a Resilient Triad. Output the lexicographically smallest such triad (smallest $a$; ties broken by smallest $b$; then smallest $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
The problem was completely reframed from chemistry/reactive symmetry to network reliability and fault tolerance. Instead of explicitly stating rules about degrees or mutual volatility, the constraint is now framed as a requirement for 1-edge fault tolerance within the induced 3-node subgraph. This forces the model to logically deduce that the only 3-node configuration capable of surviving the loss of any single internal link while remaining connected is a complete graph (a triangle).
</RATIONALE>
<PRESERVED_ANSWER>
A 3-node set satisfies internal routing and 1-edge fault tolerance if and only if all 3 possible edges between the nodes exist (a triangle), which is exactly the same structural requirement as the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying computational task remains finding a triangle (K3) in a graph, which preserves the O(n * m / 64) bitset intersection complexity class.
</PRESERVED_CLASS>
<RISK>
The phrase "permanently disabled" could theoretically be misinterpreted as modifying the global graph for subsequent checks, but the wording "If any single... is disabled" strongly implies a hypothetical condition for validating the triad, keeping ambiguity minimal.
</RISK>
