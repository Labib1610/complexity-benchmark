We can solve this by checking each vertex in increasing order and looking for a triangle that includes it.  

We’ll use adjacency sets for fast lookups. For each vertex `a` from 1 to n, we check all pairs `b < c` among its neighbors, and if `b` and `c` are also connected, we found the lexicographically smallest triple.  

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)

    for a in range(1, n + 1):
        neighbors = sorted(adj[a])
        for i in range(len(neighbors)):
            b = neighbors[i]
            for j in range(i + 1, len(neighbors)):
                c = neighbors[j]
                if c in adj[b]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    solve()
```
