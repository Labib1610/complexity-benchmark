**Solution Explanation**

For every chemical we know the list of chemicals it reacts with – an undirected
graph `G`.
We have to output the lexicographically smallest triangle  
`a < b < c ,  (a,b) , (a,c) , (b,c) ∈ E(G)`.

`n ≤ 2000`, therefore a 2000‑bit bitset fits easily into a Python `int`.
With bitsets the intersection of two neighbour sets is a single machine operation.



--------------------------------------------------------------------

#### Data structures

* `adj[v]` – `int` whose `i`‑th bit ( `i` starts with **1** ) is `1`
  iff the edge `v‑i` exists.
* `neighbors[v]` – sorted list of neighbours of `v`.
  It is used only to iterate over possible `b` values in increasing order.

--------------------------------------------------------------------

#### Finding the smallest triangle  

The outer loop runs `a = 1 … n‑2`.  
For a fixed `a` we look at neighbours `b` of `a` with `b > a`
(in increasing order because `neighbors[a]` is sorted).

For a concrete pair `(a,b)` the vertices that are adjacent to **both**
`a` and `b` are

```
common = adj[a] & adj[b]                # bitset intersection
```

We need the smallest `c > b` that belongs to `common`.

```
t = common >> (b+1)      # delete bits 0 … b
if t != 0:
        # lowest set bit of t
        low = (t & -t).bit_length() - 1
        c = b + 1 + low
        answer = (a,b,c)                # first one found – lexicographically minimal
        output and stop
```

Why is the first found triangle already the lexicographically smallest one?

* `a` grows from `1` upwards – any triangle with a smaller `a` would have been
  examined earlier.
* for a fixed `a` the neighbours `b` are processed increasingly – the first
  suitable `b` is the smallest possible.
* for a fixed pair `(a,b)` we explicitly take the smallest admissible `c`.

Thus the moment we meet a triangle we can stop.

The whole algorithm works in  

```
O( n + m +  Σ_{(a,b)∈E} 1 )   =   O(n + m)
```

bit operations, well below the limits (`m ≤ 2·10⁵`).

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
triangle.

---

##### Lemma 1  
For a fixed pair of vertices `a < b` the algorithm, if it finds a vertex `c`,
returns the smallest possible `c` with `c > b` such that
`(a,c)` and `(b,c)` are edges.

**Proof.**  
`common = adj[a] & adj[b]` contains exactly the vertices adjacent to **both**
`a` and `b`.  
Shifting by `b+1` removes all bits `≤ b`.  
If the result `t` is non‑zero, its least significant set bit corresponds to the
smallest remaining index `c' = b+1+low`.  
Thus `c'` is the smallest vertex `> b` belonging to `common`. ∎



##### Lemma 2  
When the algorithm outputs a triple `(a,b,c)`, it is a triangle of the graph,
i.e. all three edges exist.

**Proof.**  
`b` is taken from `neighbors[a]`, therefore edge `(a,b)` exists.  
`c` is taken from `common = adj[a] & adj[b]`, therefore both edges
`(a,c)` and `(b,c)` exist. ∎



##### Lemma 3  
Let `(a₀,b₀,c₀)` be the first triangle found by the algorithm.
For every triangle `(a,b,c)` in the graph we have  
`a₀ < a` or (`a₀ = a` and `b₀ < b`) or (`a₀ = a` and `b₀ = b` and `c₀ ≤ c`).

**Proof.**  
The outer loop enumerates `a` in increasing order.
If a triangle has `a < a₀` the algorithm would have processed this smaller `a`
earlier and would have found a triangle then – contradiction.
Hence every triangle has `a ≥ a₀`.

Assume `a = a₀`.  
Inside the `a`‑iteration, neighbours `b` are examined in increasing order.
If a triangle has `b < b₀` it would have been examined earlier, again a
contradiction.  
Thus for `a = a₀` we have `b ≥ b₀`.

Assume `a = a₀` and `b = b₀`.  
By Lemma&nbsp;1 the algorithm chooses the smallest admissible `c`,
therefore any other triangle with the same `a,b` has `c ≥ c₀`. ∎



##### Lemma 4  
The triple output by the algorithm is the lexicographically smallest
triangle of the graph.

**Proof.**  
Lexicographic order compares first `a`, then `b`, then `c`.
Lemma&nbsp;3 shows that no triangle has a smaller `a`,
or the same `a` with a smaller `b`,
or the same `a,b` with a smaller `c`.
Hence the output triangle is minimal in lexicographic order. ∎



##### Theorem  
The program prints three integers `a b c` (`a<b<c`) such that all three
pairwise edges exist, and among all such triples it prints the lexicographically
smallest one.

**Proof.**  
Existence: the statement of the problem guarantees at least one triangle,
so the algorithm will eventually encounter a pair `(a,b)` for which Lemma&nbsp;1
produces a `c`; by Lemma&nbsp;2 this yields a triangle, thus the algorithm
terminates with an output.

Minimality follows directly from Lemma&nbsp;4. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*building the bitsets* : `O(m)`  
*building neighbour lists* : `O(m)`  

Main loops: each edge `(a,b)` is considered exactly once (when `a<b`);
all operations inside are constant‑time bit operations.

```
Time   :  O(n + m)      ≤  O(2·10⁵)
Memory :  O(n) integers + O(m) for neighbour lists
          ≤  a few MB (well inside 256 MB)
```

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * (n + 1)                # bitsets, 1‑based
    neigh = [[] for _ in range(n + 1)]

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u] |= 1 << v
        adj[v] |= 1 << u
        neigh[u].append(v)
        neigh[v].append(u)

    for v in range(1, n + 1):
        neigh[v].sort()

    for a in range(1, n - 1):
        for b in neigh[a]:
            if b <= a:
                continue
            # vertices adjacent to both a and b
            common = adj[a] & adj[b]
            # keep only vertices > b
            t = common >> (b + 1)
            if t:
                low = (t & -t).bit_length() - 1   # position of least set bit
                c = b + 1 + low
                # a<b<c holds automatically
                sys.stdout.write(f"{a} {b} {c}\n")
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input/output format.
