We need to find a triple \((a,b,c)\) such that for each of the three choices of the primary material, the other two are connected by an edge.  

That means:  
- For primary \(a\): edge \((b,c)\) exists  
- For primary \(b\): edge \((a,c)\) exists  
- For primary \(c\): edge \((a,b)\) exists  

So the triple must form a triangle in the graph.  

We need the lexicographically smallest triangle.  

Since \(n \le 2000\), we can check all triples in \(O(n^3)\) which is too slow. But we can do better:  
For each pair \((u,v)\) that is an edge, we check if there is a common neighbor \(w\) such that \(w > v\) (to keep lexicographic order) and \((u,w)\) and \((v,w)\) are edges.  

We can store adjacency as a set for fast lookup.  

Algorithm:  
1. Read graph, store adjacency sets.  
2. Iterate over all edges \((u,v)\) with \(u < v\).  
3. For each such edge, iterate over neighbors \(w\) of \(u\) with \(w > v\).  
4. If \((v,w)\) is also an edge, we found a triangle \((u,v,w)\).  
5. Since we iterate in increasing order of \(u\), then \(v\), then \(w\), the first found is lexicographically smallest.  

Complexity: \(O(m \cdot \text{degree})\) worst-case, but with \(n=2000\) and \(m \le 2\cdot 10^5\) it's fine.  

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n+1)]
    edges = []
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
        if u > v:
            u, v = v, u
        edges.append((u, v))
    
    edges.sort()
    
    for u, v in edges:
        # find w > v such that (u,w) and (v,w) exist
        for w in adj[u]:
            if w > v and w in adj[v]:
                print(u, v, w)
                return

if __name__ == "__main__":
    solve()
```
