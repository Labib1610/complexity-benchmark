We can model the problem as a graph with \( n \) vertices and \( m \) edges.  
For a triple \((a,b,c)\):

- \( S \) = sum of degrees of \( a, b, c \)
- \( U \) = number of edges not incident to any of \( a, b, c \)

We need \( S + U = m + 3 \).

Let’s derive a simpler condition.  
Let \( E_{in} \) = number of edges among the three chosen vertices.  
Let \( E_{out} \) = number of edges with exactly one endpoint in the triple.  
Then:

- \( S = 2E_{in} + E_{out} \)
- \( U = m - E_{in} - E_{out} \)

So:

\[
S + U = (2E_{in} + E_{out}) + (m - E_{in} - E_{out}) = m + E_{in}
\]

We need \( m + E_{in} = m + 3 \), so \( E_{in} = 3 \).

That means the three chosen vertices must form a triangle (all three edges among them exist).

So the problem reduces to: find the lexicographically smallest triangle in the graph.

We can do this by iterating over \( a \) from 1 to \( n \), then \( b > a \), then checking if edge \((a,b)\) exists, and then finding the smallest \( c > b \) such that edges \((a,c)\) and \((b,c)\) exist.

We can store adjacency as a set for O(1) lookups.

Complexity: \( O(n^2) \) worst-case for checking pairs, which is fine for \( n \le 2000 \).

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if b not in adj[a]:
                continue
            # Find smallest c > b connected to both a and b
            for c in range(b + 1, n + 1):
                if c in adj[a] and c in adj[b]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
