**Solution Explanation**

For a triple of distinct workers `x , y , z`

* `deg[x] , deg[y] , deg[z]` – number of incident files (edges) of each worker  
* `S = deg[x] + deg[y] + deg[z]`
* `U` – number of files that contain none of the three workers

Let  

`I` – number of files that contain **at least one** of the three workers.  
Obviously `U = m – I`.

```
condition :  S + U = m + 3
⇔  S + (m – I) = m + 3
⇔  S – I = 3
```

`I` counts every edge once, while `S` counts an edge twice if both its
endpoints belong to the triple.
Let `e` be the number of edges whose both endpoints are inside the triple
(`e = 0 … 3`). Then

```
I = S – e                (each internal edge was counted twice in S)
```

Insert into the condition:

```
S – (S – e) = 3   ⇒   e = 3
```

So the three workers must be pairwise connected – they form a **triangle**.
Conversely, any triangle satisfies the required equality.
Therefore the whole task is:

> find the lexicographically smallest triangle `(a,b,c)` (`a<b<c`) in the
> given undirected simple graph.

--------------------------------------------------------------------

#### Finding the smallest triangle

`n ≤ 2000`, therefore a bitset of length `n` fits into a Python integer
(`2000` bits ≈ 250 bytes).  
For every vertex `v` we store

```
adj[v] : integer, bit i (0‑based) is 1  ⇔  edge (v , i+1) exists
```

and also a sorted list `nbr[v]` of its neighbours.

For a fixed ordered pair `a<b` that is an edge, the vertices that together
with `a` and `b` form a triangle are exactly the common neighbours:

```
common = adj[a] & adj[b]
```

We need the smallest `c` with `c>b`.  
Bits `0 … b-1` are irrelevant, we shift them away:

```
mask = common >> b          # bit 0 now corresponds to vertex b+1
```

If `mask` is non‑zero, the least set bit gives the required `c`.

The whole search:

```
for a = 1 … n
    for b in nbr[a] with b > a
        common = adj[a] & adj[b]
        mask   = common >> b
        if mask != 0
            low = mask & -mask               # lowest set bit
            idx = low.bit_length() - 1       # position inside mask
            c   = b + 1 + idx
            output a b c   (they are already a<b<c)
            terminate
```

The outer loops enumerate edges in increasing order of `a` and, for a fixed
`a`, in increasing order of `b`.  
The first triangle found is therefore the lexicographically smallest one.

Complexities  

*building* – `O(m)` time, `O(n)` memory (bitsets)  
*search* – each edge is processed once, each step uses only a few integer
operations → `O(m)` time, `O(n)` memory.

Both limits easily satisfy the constraints (`n ≤ 2000`, `m ≤ 2·10⁵`).

#### Correctness Proof  

We prove that the algorithm outputs exactly the required triple.

---

##### Lemma 1  
For any three distinct vertices `x,y,z` the equality `S+U = m+3` holds
iff `{x,y,z}` induces a triangle (all three edges among them exist).

**Proof.**  
From the derivation in the statement part:

```
S+U = m+3  ⇔  S - I = 3
I = S - e   (e = number of internal edges)
⇒  S - (S - e) = 3  ⇔  e = 3
```

`e = 3` means exactly the three possible edges among the three vertices are
present, i.e. they form a triangle. ∎



##### Lemma 2  
When the algorithm examines an ordered edge `(a,b)` (`a<b`) it finds the
smallest vertex `c>b` such that `{a,b,c}` is a triangle, if such a `c` exists.

**Proof.**  
`common = adj[a] & adj[b]` contains precisely the vertices adjacent to **both**
`a` and `b`.  
Shifting right by `b` discards vertices `≤ b`.  
If the resulting mask is non‑zero, its lowest set bit corresponds to the
minimum remaining vertex `c`. The computation of `c` restores the original
index, therefore the algorithm obtains the smallest possible `c`. ∎



##### Lemma 3  
If the algorithm outputs a triple `(a,b,c)`, then it is a triangle.

**Proof.**  
The algorithm outputs only after finding a non‑zero `mask` for some edge
`(a,b)`. By Lemma&nbsp;2 the corresponding `c` belongs to `common`,
hence edges `(a,c)` and `(b,c)` exist. Edge `(a,b)` also exists because we
iterate over neighbours. Thus all three edges are present – a triangle. ∎



##### Lemma 4  
The first triangle output by the algorithm is the lexicographically smallest
triangle in the graph.

**Proof.**  
The outer loop enumerates `a` increasingly.
For a fixed `a`, the inner loop enumerates neighbours `b` increasingly,
and only those with `b>a`.  
Therefore triangles are considered in the order of increasing `(a,b)`.
For a given `(a,b)` Lemma&nbsp;2 guarantees that the smallest possible `c`
is examined.  
Consequently, the first triangle discovered has the minimal possible `a`;
among those with that `a` it has the minimal possible `b`;
and for that pair the minimal possible `c`. ∎



##### Lemma 5  
The algorithm always terminates.

**Proof.**  
The input guarantees at least one triangle exists.
The algorithm scans every edge; when it reaches the edge belonging to the
lexicographically smallest triangle, Lemma&nbsp;2 finds its third vertex,
outputs it and stops. ∎



##### Theorem  
The algorithm prints three integers `a<b<c` that satisfy `S+U = m+3`
and are lexicographically minimal among all such triples.

**Proof.**  
By Lemma&nbsp;3 the printed triple is a triangle, therefore by Lemma&nbsp;1
it satisfies the required equality.  
By Lemma&nbsp;4 it is the lexicographically smallest triangle, and by
Lemma&nbsp;1 any valid triple must be a triangle. Hence it is the
lexicographically smallest valid triple. ∎

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * (n + 1)          # bitset, 0‑based bits
    nbr = [[] for _ in range(n + 1)]

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        # store edge
        adj[u] |= 1 << (v - 1)
        adj[v] |= 1 << (u - 1)
        nbr[u].append(v)
        nbr[v].append(u)

    # sort neighbour lists for deterministic order
    for i in range(1, n + 1):
        nbr[i].sort()

    for a in range(1, n + 1):
        for b in nbr[a]:
            if b <= a:
                continue
            common = adj[a] & adj[b]
            mask = common >> b          # keep only vertices > b
            if mask:
                low = mask & -mask       # lowest set bit
                idx = low.bit_length() - 1
                c = b + 1 + idx
                # a < b < c holds by construction
                print(a, b, c)
                return

if __name__ == "__main__":
    solve()
```
