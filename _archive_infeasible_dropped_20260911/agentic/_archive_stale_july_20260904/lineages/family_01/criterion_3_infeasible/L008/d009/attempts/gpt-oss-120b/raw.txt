**Solution Explanation**

For three different workers `a , b , c`

* `deg(x)` – number of incident files (edges) that contain worker `x`
* `T = deg(a)+deg(b)+deg(c)`
* `E` – number of files that contain **exactly one** of `{a,b,c}`

Every file that touches the set `{a,b,c}` is of one of two kinds  

* internal – both its workers are inside the set (there are `k` such files)  
* external – exactly one worker is inside the set (there are `E` such files)

Counting the ends of all those files gives  

```
T = 2·k + E                (each internal file contributes 2, each external 1)
```

The required condition is `T = E + 6`, therefore  

```
2·k + E = E + 6   →   k = 3
```

`k = 3` means that **all three possible internal files are present**,
i.e. the three workers form a triangle in the graph of incident files.

So the whole task is:

*find the lexicographically smallest triangle in an undirected simple graph
with `n ≤ 2000` vertices and `m ≤ 2·10⁵` edges.*

--------------------------------------------------------------------

#### Data structures

`n ≤ 2000` → we can store the adjacency of each vertex as a bitset inside a
single Python integer (`int`).  
Bit `i` (0‑based) of `mask[v]` is `1` iff the edge `v – (i+1)` exists.

Additionally we keep for every vertex a **sorted list of neighbours**
(`adj_list[v]`) – needed to iterate `b` in increasing order.

--------------------------------------------------------------------

#### Algorithm
```
read n , m
build mask[1..n] = 0
build adj_list[1..n] = empty list
for each edge (u,v):
        set the bits in both masks
        append each vertex to the other's list

for a = 1 .. n:
        for b in adj_list[a] with b > a:          # neighbours in increasing order
                common = mask[a] & mask[b]       # vertices adjacent to both a and b
                # we need a vertex c > b
                common_shifted = common >> b      # drop bits ≤ b
                if common_shifted != 0:
                        # lowest set bit gives the smallest possible c
                        low = common_shifted & -common_shifted
                        pos = low.bit_length() - 1          # 0‑based inside shifted mask
                        c = pos + b + 1
                        output a b c and terminate
```

The first triangle found is automatically the one with minimal `a`,
then minimal `b`, then minimal `c`, because the loops enumerate them
in exactly that order.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs exactly the required triple.

---

**Lemma 1**  
For any three distinct vertices `a,b,c` the equality `T = E + 6` holds
iff the three edges `{a,b}`, `{a,c}`, `{b,c}` are all present (i.e. they form a triangle).

*Proof.*  
As shown in the beginning, `T = 2·k + E` where `k` is the number of internal edges.
`T = E + 6` ⇒ `2·k = 6` ⇒ `k = 3`.  
`k = 3` means all three possible internal edges exist, which is exactly a triangle. ∎



**Lemma 2**  
When the algorithm reaches a pair `(a,b)` (`a<b`) it examines exactly the set
`{ c | c > b  and  (a,c) ∈ E  and  (b,c) ∈ E }`.

*Proof.*  
`mask[a] & mask[b]` contains precisely the vertices adjacent to **both** `a` and `b`.
Shifting right by `b` discards bits `0 … b` (i.e. vertices `≤ b`).  
Thus the remaining set corresponds exactly to vertices `c > b` adjacent to both. ∎



**Lemma 3**  
If a triangle `{a,b,c}` exists with `a<b<c`, the algorithm will output a
(triple) not larger than it in lexicographic order.

*Proof.*  
The outer loop iterates `a` increasingly, so the first `a` for which any
triangle exists is the smallest possible first element.
For this fixed `a`, the inner loop iterates `b` increasingly among neighbours
greater than `a`; therefore the first `b` that participates in a triangle is the
smallest possible second element.
By Lemma&nbsp;2 the algorithm then looks at all admissible `c>b` and picks the
smallest one, which is the minimal third element.
Hence the produced triple is lexicographically minimal among all triangles. ∎



**Lemma 4**  
If the algorithm outputs a triple `(a,b,c)`, then `{a,b,c}` is a triangle.

*Proof.*  
The algorithm outputs only after finding `c` such that `c` is in
`mask[a] & mask[b]` (Lemma&nbsp;2). Therefore edges `{a,c}` and `{b,c}` exist.
Since the inner loop iterates only neighbours `b` of `a`, edge `{a,b}` also exists.
Thus all three edges are present – a triangle. ∎



**Theorem**  
The algorithm always terminates and prints the lexicographically smallest
triple of distinct workers satisfying `T = E + 6`.

*Proof.*  

*Existence & termination*: the statement guarantees at least one triangle,
hence at some iteration the condition of Lemma&nbsp;4 is met and the algorithm
outputs and stops.

*Validity*: by Lemma&nbsp;4 the printed triple is a triangle, and by Lemma&nbsp;1
any triangle satisfies the required equation, so the output is valid.

*Optimality*: by Lemma&nbsp;3 the first triangle found is the lexicographically
smallest among all triangles, therefore also the smallest among all valid
triples. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`n ≤ 2000`, `m ≤ 2·10⁵`.

* Building masks and adjacency lists: `O(m)`.
* Main loops: for each edge `(a,b)` with `a<b` we perform a single bitwise `&`
  and a constant‑time search for the lowest set bit.  
  Hence `O(m)` operations, each on integers of at most 2000 bits (fits in a
  machine word array, Python handles it efficiently).

Overall time `O(m)`, at most about `2·10⁵` elementary operations – well within
the limit.  
Memory: `n` integers of ~2000 bits → < 0.5 MiB, plus adjacency lists → `O(m)`.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    mask = [0] * (n + 1)          # 1‑based
    adj = [[] for _ in range(n + 1)]

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        if u == v:
            continue
        # set bits (0‑based inside integer)
        mask[u] |= 1 << (v - 1)
        mask[v] |= 1 << (u - 1)
        if u < v:
            adj[u].append(v)
            adj[v].append(u)
        else:
            adj[v].append(u)
            adj[u].append(v)

    # neighbours are already collected; sort them for deterministic order
    for lst in adj:
        lst.sort()

    for a in range(1, n + 1):
        ma = mask[a]
        for b in adj[a]:
            if b <= a:
                continue
            common = ma & mask[b]
            # keep only vertices > b
            shifted = common >> b
            if shifted:
                low = shifted & -shifted
                pos = low.bit_length() - 1   # 0‑based inside shifted
                c = pos + b + 1
                sys.stdout.write(f"{a} {b} {c}")
                return

if __name__ == "__main__":
    solve()
```

to the required input‑output format.
