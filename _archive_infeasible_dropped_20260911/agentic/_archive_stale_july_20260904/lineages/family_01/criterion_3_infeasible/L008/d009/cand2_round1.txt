# Problem C — Proof of Impossibility

Time limit: 2 s
Memory limit: 256 MB

Management insists on dividing the workforce into exactly two non-overlapping shifts. However, the HR department knows this plan is doomed. You must provide undeniable proof of this failure.

HR has a collection of incident files. Each file lists two specific workers who cannot be placed on the same shift. 

You can prove the plan is impossible by finding a specific combination of records. Specifically, you must identify a set of exactly three incident files such that their symmetric difference is empty. In this context, the symmetric difference of a collection of files is defined as the set of workers who appear in an odd number of those files.

It is guaranteed that at least one such set of three files exists. Your task is to deduce the IDs of the workers involved in this set of files and report them to HR.

## Input
The first line provides the workforce size $n$ and the total incident count $m$. The workforce size $n$ is at least the minimum needed to form such a group, and is bounded above by the facility's strict fire-code capacity of 2000 personnel. The incident count $m$ is at least 3. The HR archive room has a physical storage limit of 200,000 file folders, so $m$ will never exceed this number; naturally, $m$ is also bounded by the maximum possible number of unique worker pairs. Workers are identified by integers from 1 to $n$.

Each of the next $m$ lines contains two integers $u$ and $v$ (1 ≤ $u$, $v$ ≤ $n$, $u \ne v$), identifying the two workers involved in a single incident file. Data entry protocols ensure that no two incident files list the exact same pair of workers.

It is guaranteed that at least one valid set of three files exists.

## Output
Output three space-separated integers $a$, $b$, and $c$ representing the IDs of the workers involved in the identified set of files. They must be printed such that $a < b < c$.

To ensure a unique valid response when multiple such valid sets of files exist, you must select the set whose involved workers minimize the value of $a$. If there is a tie, minimize the value of $b$ among the tied sets, and if a tie still persists, minimize $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<METHOD_NAME>Symmetric Difference Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit "three files involving exactly three workers" affordance with the mathematical equivalent that the symmetric difference of the three files is empty. This removes the trigger for triangle-finding algorithms and baits models into simulating the condition directly, which requires an O(M^3) triplet loop that will fail via Time Limit Exceeded.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<RATIONALE>
The surviving models succeeded because they recognized "three records spanning three unique workers" as the definition of a triangle in a simple graph. By redefining the target as three files whose symmetric difference is empty, I completely removed the mention of "three unique workers". The models must now either mathematically prove that this condition implies a triangle, or fall into the trap of brute-forcing all $\binom{M}{3}$ file combinations.
</RATIONALE>
<PRESERVED_ANSWER>
Because the input contains no duplicate pairs, the only way three distinct edges can have an empty symmetric difference is if every vertex in their union has degree 2, which mathematically guarantees the subgraph is exactly a triangle (3 workers), preserving all answers.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the task of finding a 3-clique (triangle) in an undirected graph, which is solvable using the exact same $O(M \sqrt{M})$ or $O(NM/64)$ bitset adjacency algorithms as the seed.
</PRESERVED_CLASS>
<RISK>
A model might find it ambiguous how to map the chosen set of files to exactly three workers if it fails to perform the mathematical deduction, though the output format explicitly requesting three integers $a, b, c$ resolves this practically.
</RISK>
