 We need to find a triangle (three mutually connected nodes) in an undirected graph, with the smallest lexicographic order of the triple (a, b, c) where a < b < c.

A straightforward approach:  
- For each node `a` from 1 to n,  
  - For each neighbor `b` of `a` where `b > a`,  
    - For each neighbor `c` of `b` where `c > b`,  
      - Check if `c` is also a neighbor of `a`.  
- The first found triple in this order is the answer.

Since n ≤ 2000 and m ≤ 200000, this O(n * degree²) could be too slow in worst case, but we can optimize by using adjacency sets for O(1) lookups.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(n):
        for b in adj[a]:
            if b > a:
                for c in adj[b]:
                    if c > b and c in adj[a]:
                        print(a+1, b+1, c+1)
                        return

if __name__ == "__main__":
    main()
```
