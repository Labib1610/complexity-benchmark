We need to find three distinct workers such that there are exactly three incident files among them, each file connecting two of the three workers. That means the three workers form a triangle in the graph of incidents.

We can solve this by iterating over all possible triples in sorted order and checking if all three edges exist. Since n ≤ 2000, we can use an adjacency matrix (or set) for O(1) edge lookup.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = adj[v][u] = True

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if not adj[a][b]:
                continue
            for c in range(b + 1, n + 1):
                if adj[a][c] and adj[b][c]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
