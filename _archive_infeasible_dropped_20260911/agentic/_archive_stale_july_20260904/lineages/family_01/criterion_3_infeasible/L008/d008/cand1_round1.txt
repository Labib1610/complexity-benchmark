<METHOD_DESCRIPTION>
Replaces the direct description of the scheduling conflict (which models easily mapped to a triangle/3-cycle) with an algorithmic audit process. By requiring that each worker in the 3-person group appears in an "even, strictly positive" number of internal incident files, it mathematically forces every worker to have exactly 2 internal files (since the maximum possible in a group of 3 is 2). This perfectly describes a triangle. Pattern-matching models will fail to recognize the triangle and will likely write an $O(n^3)$ simulation that times out, whereas models capable of genuine reasoning will deduce that the degree must be 2, recognize the triangle, and implement the fast $O(nm/64)$ algorithm.
</METHOD_DESCRIPTION>

yes

<STATEMENT>
# Problem C — Proof of Impossibility

Time limit: 2 s
Memory limit: 256 MB

Management insists on dividing the workforce into exactly two non-overlapping shifts. However, the HR department knows this plan is doomed. You must provide undeniable proof of this failure.

HR has a collection of incident files, where each file lists two specific workers who cannot be placed on the same shift. 

You must identify a group of exactly three distinct workers. To verify if a group is contradictory, HR will perform the following audit:
1. They will isolate all incident files where both listed workers belong to the proposed group.
2. For each of the three workers, they will count how many of these isolated files feature that worker.
3. The group is confirmed as contradictory if all three workers have an even, strictly positive count.

It is guaranteed that at least one such group of three workers exists. Your task is to identify the three distinct workers comprising this group and report them to HR.

## Input
The first line provides the workforce size $n$ and the total incident count $m$. The workforce size $n$ is bounded below by 3 and bounded above by the facility capacity of 2000. The incident count $m$ is at least 3, and is capped by either the theoretical maximum of $n(n-1)/2$ distinct combinations, or the archival capacity of $2 \cdot 10^5$, whichever is smaller. Workers are identified by integers from 1 to $n$.

Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), identifying the two workers involved in a single incident. No two incident files list the exact same pair of workers.

It is guaranteed that at least one valid contradictory group exists.

## Output
Output three space-separated integers $a$, $b$, and $c$ representing the IDs of the three workers involved. They must be printed such that $a < b < c$.

To ensure a unique valid response when multiple such groups exist, you must select the one that minimizes the value of $a$. If there is a tie, minimize the value of $b$ among the tied triplets, and if a tie still persists, minimize $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
The previous wording allowed models to immediately map "impossible to divide into two shifts without conflict" to a triangle graph structure. By replacing this with a mechanical audit process checking for an "even, strictly positive count" of internal files, models must now logically deduce that in a group of 3, the only valid count is 2, which equates to all 3 pairs existing (a triangle). This forces genuine reasoning to discover the underlying structure required for an efficient solution.
</RATIONALE>
<PRESERVED_ANSWER>
Because the group size is exactly 3 and there are no duplicate files, the maximum number of internal files any one worker can be part of is 2; thus, an "even, strictly positive count" can only mean exactly 2 for all three workers, which mathematically requires all three possible incident files among them to exist, exactly matching the original triangle requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a triangle (K3) in an undirected graph, maintaining the exact same computational complexity and allowing the same optimized bitset adjacency algorithm.
</PRESERVED_CLASS>
<RISK>
A model might attempt to simulate the audit process directly on all $O(n^3)$ triplets instead of deducing the triangle property, which would lead to a Time Limit Exceeded error rather than an incorrect interpretation of the rules.
</RISK>
