**Solution Explanation**

For every worker we know the workers he/she cannot share a shift with.
If three workers `a < b < c` are pairwise forbidden, the three incident
records

```
a – b , a – c , b – c
```

form a *triangle* in the undirected graph whose vertices are workers and
edges are the given records.

The task is therefore:

*find the lexicographically smallest triangle*  
(`a` minimal, then `b`, then `c`).

`n ≤ 2000`, so an `O(n²)` algorithm is easily fast enough.



--------------------------------------------------------------------

#### 1.   Bitset representation  

For every vertex `v` we store a bitset `mask[v]` (Python `int`) :

```
bit i (0‑based) is 1  ⇔  vertex (i+1) is adjacent to v
```

`mask[v]` can be built in `O(m)` time.

With bitsets we can intersect neighbour sets of two vertices in one
operation:

```
common = mask[a] & mask[b]          # vertices adjacent to both a and b
```

--------------------------------------------------------------------

#### 2.   Searching the smallest triangle  

We iterate `a` from `1` to `n‑2` and for each `a` iterate `b` from `a+1`
to `n‑1`.

* If there is **no** edge `a‑b` we continue.
* Otherwise we look for a common neighbour `c` that is larger than `b`
  (otherwise the triple would not be ordered).

```
common = mask[a] & mask[b]          # all common neighbours
# delete vertices ≤ b
common >>= b                         # now bit 0 corresponds to vertex b+1
if common != 0:
        low = common & -common       # lowest set bit
        idx = low.bit_length() - 1   # position of that bit
        c = idx + b + 1
        answer = (a, b, c)           # first found is lexicographically minimal
```

Why is the first found triangle the required one?

* `a` grows from the smallest possible value.
* For a fixed `a`, `b` grows from the smallest possible value.
* For a fixed pair `(a,b)` we pick the smallest possible `c`
  (the lowest set bit).

Thus the enumeration order is exactly the lexicographic order demanded
by the statement.

The whole loop runs at most `n·(n‑1)/2 ≤ 2·10⁶` iterations, each doing a
few integer operations – well inside the limits.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest
triangle.

---

##### Lemma 1  
For any vertices `a < b`, after `common >>= b` the lowest set bit of
`common` (if any) corresponds to the smallest vertex `c > b` that is
adjacent to both `a` and `b`.

**Proof.**  
Before the shift, bit `i` (0‑based) represents vertex `i+1`.  
Shifting right by `b` discards bits `0 … b‑1`, i.e. vertices `1 … b`.  
Now bit `0` represents vertex `b+1`, bit `1` vertex `b+2`, etc.
Therefore the lowest set bit after the shift is exactly the smallest
vertex larger than `b` that belongs to the original set. ∎



##### Lemma 2  
When the algorithm prints a triple `(a,b,c)`, the three edges
`a‑b`, `a‑c`, `b‑c` are all present in the input.

**Proof.**  
* `a‑b` is checked explicitly before the inner work.  
* `c` is obtained from `common = mask[a] & mask[b]`; a vertex belongs to
  this intersection iff it is adjacent to **both** `a` and `b`.  
  Hence edges `a‑c` and `b‑c` exist. ∎



##### Lemma 3  
The first printed triple is the lexicographically smallest triangle
among all triangles of the graph.

**Proof.**  
The outer loops enumerate pairs `(a,b)` in increasing lexicographic order:
`a` increases first, and for a fixed `a` the `b` loop increases.
For a fixed pair `(a,b)` Lemma&nbsp;1 guarantees that the algorithm
chooses the smallest possible `c > b`.  
Consequently, the enumeration order of triples is exactly the
lexicographic order required.  
Since the algorithm stops at the first found triangle, that triangle is
the smallest one. ∎



##### Lemma 4  
If the graph contains at least one triangle, the algorithm will find
one.

**Proof.**  
Take the lexicographically smallest triangle `(a,b,c)`.  
When the outer loops reach this pair `(a,b)`, the edge `a‑b` is present,
so the algorithm computes `common = mask[a] & mask[b]`.  
Vertex `c` is a common neighbour and `c > b`, therefore after the shift
`common` is non‑zero and Lemma&nbsp;1 will return exactly this `c`.  
Thus the algorithm discovers the triangle. ∎



##### Theorem  
The algorithm always outputs three distinct worker IDs `a<b<c` that form
a triangle, and among all such triples it outputs the one with minimal
`a`, then minimal `b`, then minimal `c`.

**Proof.**  
Existence follows from Lemma&nbsp;4 (a triangle is guaranteed).  
Lemma&nbsp;2 shows the output indeed forms a triangle.  
Lemma&nbsp;3 proves the output is the lexicographically smallest
triangle. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building masks* : `O(m)` time, `O(n)` integers (each up to `2ⁿ` bits).  
*Search* : at most `n·(n‑1)/2` iterations, each `O(1)` → `O(n²)` time.  

With `n ≤ 2000` this is ≤ 2·10⁶ operations.

Memory: `n` integers, each ≤ `2ⁿ` → at most `n·n/8` bytes ≈ 0.5 MiB,
well below the limit.



--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    masks = [0] * (n + 1)          # 1‑based
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        masks[u] |= 1 << (v - 1)
        masks[v] |= 1 << (u - 1)

    for a in range(1, n - 1):
        mask_a = masks[a]
        for b in range(a + 1, n):
            # edge a‑b ?
            if (mask_a >> (b - 1)) & 1 == 0:
                continue
            common = mask_a & masks[b]
            # keep only vertices > b
            common >>= b
            if common:
                low = common & -common
                idx = low.bit_length() - 1   # position after shift
                c = idx + b + 1
                print(a, b, c)
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input‑output format.
