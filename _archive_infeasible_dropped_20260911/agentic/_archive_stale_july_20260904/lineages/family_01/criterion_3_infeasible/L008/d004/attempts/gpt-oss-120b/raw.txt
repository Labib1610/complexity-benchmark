**Solution Explanation**

For three workers `a , b , c` to form a *deadlock* we need the three incident
files  

```
(a , b) , (a , c) , (b , c)
```

i.e. the three workers must be pairwise connected – they form a **triangle**
in the undirected graph whose vertices are workers and edges are incident
files.

The task is therefore:

*find the lexicographically smallest triangle*  
(`a < b < c`, minimise `a`, then `b`, then `c`).

`n ≤ 2000`, therefore an `O(n²)` algorithm is easily fast enough.



--------------------------------------------------------------------

#### 1.   Data structure – bitsets

For every vertex `v` we store the set of its neighbours as a bitset
(`int` in Python).  
Bit `i` (0‑based) of `adj[v]` is `1` **iff** the edge `(v , i)` exists.

```
adj = [0] * n
for each edge (u , v):
        u -= 1 ; v -= 1                # to 0‑based
        adj[u] |= 1 << v
        adj[v] |= 1 << u
```

All operations on a bitset are O(1) (`& , | , >> , -`).

--------------------------------------------------------------------

#### 2.   Searching triangles in lexicographic order  

We iterate over the first two vertices of the triangle in the required
order:

```
for a = 0 … n-1:
        for b = a+1 … n-1:
                if edge (a,b) exists:
                        common = adj[a] & adj[b]          # vertices adjacent to both
                        # we need a vertex c larger than b
                        mask = common >> (b+1)
                        if mask != 0:                     # at least one such c
                                low = mask & -mask        # lowest set bit
                                c = (b+1) + low.bit_length() - 1
                                output a+1, b+1, c+1
                                return
```

*Why does this give the smallest triple?*  
The outer loops enumerate `(a,b)` in increasing order of `a`,
and for a fixed `a` in increasing order of `b`.  
For a given pair `(a,b)` we look for the **smallest** possible `c > b`
(the lowest set bit of `mask`).  
Consequently the first triangle we encounter is exactly the lexicographically
minimum one.

The existence of at least one triangle is guaranteed, so the algorithm
always terminates with an answer.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs the required triple.

---

##### Lemma 1  
For any vertices `a < b`, `common = adj[a] & adj[b]` contains exactly the
vertices adjacent to **both** `a` and `b`.

**Proof.**  
Bit `i` of `adj[a]` is `1` iff edge `(a,i)` exists, similarly for `adj[b]`.
Bitwise `&` keeps a bit `1` only when it is `1` in both operands, i.e. when
both edges exist. ∎



##### Lemma 2  
`mask = common >> (b+1)` has a set bit at position `k` (0‑based)  
iff vertex `c = b+1+k` satisfies `c > b` and edges `(a,c)` and `(b,c)` exist.

**Proof.**  
`common` contains all common neighbours (Lemma&nbsp;1).  
Shifting right by `b+1` discards bits `0 … b`.  
Thus a remaining set bit corresponds to a vertex index larger than `b`,
and because it was present in `common`, it is adjacent to both `a` and `b`. ∎



##### Lemma 3  
If `mask ≠ 0`, the vertex `c` computed by  

```
low = mask & -mask          # lowest set bit
c   = (b+1) + low.bit_length() - 1
```

is the smallest vertex `c > b` that together with `a , b` forms a triangle.

**Proof.**  
`low` isolates the least‑significant `1` of `mask`, i.e. the smallest
remaining index `k`.  
`c = b+1+k` is therefore the smallest vertex larger than `b` whose bit is set
in `mask`. By Lemma&nbsp;2 such a vertex is adjacent to both `a` and `b`,
hence `(a,b,c)` is a triangle, and no smaller `c` can work. ∎



##### Lemma 4  
When the algorithm prints a triple `(a,b,c)`, it is a triangle and
`a < b < c`.

**Proof.**  
The outer loops guarantee `a < b`.  
Printing happens only after the test `mask != 0`, therefore a `c` is
obtained as in Lemma&nbsp;3, which satisfies `c > b`.  
By Lemma&nbsp;3 edges `(a,b) , (a,c) , (b,c)` all exist, i.e. the three
workers form a triangle. ∎



##### Lemma 5  
Let `T* = (a*,b*,c*)` be the lexicographically smallest triangle
(`a*<b*<c*`). The algorithm prints exactly `T*`.

**Proof.**  
Consider the moment the outer loops reach the pair `(a*,b*)`.  
Since `(a*,b*)` is an edge of `T*`, the inner `if` succeeds.
All common neighbours of `a*` and `b*` include `c*` and possibly larger ones.
Thus `mask` is non‑zero, and by Lemma&nbsp;3 the algorithm will choose the
smallest such `c`, which is `c*`.  
Therefore the algorithm prints `T*` at that iteration.

For any earlier iteration we have either

* `a < a*`, or
* `a = a*` and `b < b*`.

In both cases the produced triple would be lexicographically smaller than
`T*`, contradicting the definition of `T*`. Hence no earlier iteration can
output a triangle, and the first printed triangle is exactly `T*`. ∎



##### Theorem  
The algorithm always outputs three distinct worker IDs `a<b<c` that form a
deadlock, and among all possible deadlocks the printed triple is the
lexicographically smallest one.

**Proof.**  
Existence of a deadlock guarantees at least one triangle, so the loops will
eventually encounter a pair `(a,b)` belonging to some triangle, making
`mask ≠ 0` and causing an output.  
By Lemma&nbsp;4 the output is a triangle with ordered vertices.  
By Lemma&nbsp;5 it is the lexicographically smallest triangle, which is
exactly the required deadlock. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency bitsets* : `O(m)`  
*Main double loop* : at most `n·(n-1)/2 ≤ 2·10⁶` iterations, each O(1).  

```
Time   :  O(n² + m)   ≤  O(2·10⁶)   (well below 2 s)
Memory :  O(n) bitsets, each ≤ 2000 bits → about 2000·2000 / 8 ≈ 0.5 MiB
```

Both limits satisfy the problem constraints.

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * n                     # bitset for each vertex, 0‑based
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u] |= 1 << v
        adj[v] |= 1 << u

    for a in range(n):
        for b in range(a + 1, n):
            # edge (a,b) ?
            if (adj[a] >> b) & 1:
                common = adj[a] & adj[b]
                # keep only vertices > b
                mask = common >> (b + 1)
                if mask:
                    low = mask & -mask               # lowest set bit
                    c = (b + 1) + low.bit_length() - 1
                    # output 1‑based, sorted
                    print(a + 1, b + 1, c + 1)
                    return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
