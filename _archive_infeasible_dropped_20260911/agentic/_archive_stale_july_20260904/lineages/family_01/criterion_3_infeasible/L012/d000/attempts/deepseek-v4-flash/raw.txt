We need to find a triangle in an undirected graph, and among all triangles, output the lexicographically smallest one.

A direct approach:  
- Since \( n \leq 2000 \), we can store the graph as an adjacency matrix (boolean) for O(1) edge checks.  
- Iterate over all triples in sorted order and check if they form a triangle.  
- The first one found will be lexicographically smallest.

Complexity: \( O(n^3) \) = \( 8 \times 10^9 \) worst-case, too slow.  
We need a better method.

We can instead iterate over each possible smallest vertex `a`, then for each neighbor `b > a`, check if there is a common neighbor `c > b` that is connected to both.  
We can do this efficiently using adjacency sets.

Algorithm:
1. Build adjacency sets for each vertex.
2. For `a` from 1 to n:
   - For each `b` in neighbors of `a` with `b > a`:
     - For each `c` in neighbors of `b` with `c > b`:
       - If `c` is also neighbor of `a`, we found the lexicographically smallest triangle.

This is still potentially \( O(n^3) \) in worst case, but with \( m \le 2\cdot 10^5 \), the number of edges is limited, so the loops over neighbors are bounded by degree.  
We can also break early once we find the first triangle.

Let's implement it.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(n):
        for b in adj[a]:
            if b <= a:
                continue
            for c in adj[b]:
                if c <= b:
                    continue
                if c in adj[a]:
                    print(a+1, b+1, c+1)
                    return

if __name__ == "__main__":
    solve()
```
