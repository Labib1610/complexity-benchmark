We need to find the lexicographically smallest triple of distinct vertices such that **every 2-coloring of that triple** results in at least one edge being monochromatic.

That means: among the three selected vertices, there is **no valid 2-coloring** with all edges going between different colors. If the induced subgraph on those three vertices is not bipartite, it cannot be 2-colored properly.  
A 3-vertex graph is non-bipartite iff it contains a triangle.

So the task reduces to:  
Find the lexicographically smallest triangle in the graph. A triangle is a triple (a,b,c) with a < b < c and all three edges present.

We can solve by iterating `a` from 1 to n, then `b` from a+1 to n, and checking for smallest `c > b` such that edges ab, ac, bc exist sneaking. With an adjacency matrix or set for O(1) edge lookup.

Since n ≤ 2000, an adjacency matrix of size n×n is fine.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = adj[v][u] = True

    # Find lexicographically smallest triangle
    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if not adj[a][b]:
                continue
            for c in range(b + 1, n + 1):
                if adj[a][c] and adj[b][c]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
