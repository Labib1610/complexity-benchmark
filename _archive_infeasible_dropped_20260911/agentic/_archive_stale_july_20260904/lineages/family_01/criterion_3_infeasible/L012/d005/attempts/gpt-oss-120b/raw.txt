**Solution Explanation**

For every process we know the set of processes it conflicts with.
A failing subset of three processes is exactly a *triangle* in this undirected
graph: three vertices `a<b<c` such that all three edges  
`(a,b) , (a,c) , (b,c)` are present.

The task is to output the lexicographically smallest triangle
(`a` minimal, then `b`, then `c`).

`n ≤ 2000`, therefore a bitset of length `n` fits into a Python integer
(2000 bits ≈ 250 bytes).  
With bitsets we can intersect neighbour sets in O(1) word operations.



--------------------------------------------------------------------

#### Data structures
* `adj_bits[i]` – integer whose `j`‑th bit (`j` 0‑based) is `1`
  iff there is an edge `i – j`.
* `adj_list[i]` – sorted list of neighbours of vertex `i`
  (only vertices with larger index are stored, to keep the iteration order).

--------------------------------------------------------------------

#### Algorithm
```
read n, m
initialise adj_bits[0…n-1] = 0
initialise adj_list[0…n-1] = empty list

for each edge (u,v):
        u-- ; v--                     # to 0‑based
        set the bits in both directions
        if u < v:  adj_list[u].append(v)
        else:      adj_list[v].append(u)

for a = 0 … n-1 (in increasing order):
        for b in adj_list[a] (already sorted, all b > a):
                common = adj_bits[a] & adj_bits[b]          # neighbours of both
                # we need c > b, delete bits ≤ b
                mask = ~((1 << (b+1)) - 1)                  # bits b+1 … n-1 are 1
                common &= mask
                if common != 0:                             # at least one c exists
                        # lowest set bit = smallest possible c
                        low = common & -common
                        c = low.bit_length() - 1
                        output a+1, b+1, c+1 (already a<b<c)
                        terminate
```

*Why does it give the lexicographically smallest triangle?*  
The outer loops enumerate `(a,b)` in strictly increasing lexicographic order.
For a fixed `(a,b)` we pick the smallest possible `c` (`c > b`) because we
extract the lowest set bit of `common`.  
Therefore the first triangle we encounter is exactly the required one.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest triangle.

---

**Lemma 1**  
For any vertices `a<b`, after `common = adj_bits[a] & adj_bits[b]` and
`common &= mask` (mask clears bits `0…b`), the set bits of `common`
are precisely the vertices `c` such that `c>b` and edges `(a,c)` and `(b,c)`
exist.

*Proof.*  
`adj_bits[a]` has a 1‑bit exactly at vertices adjacent to `a`.  
Intersection with `adj_bits[b]` keeps a 1‑bit exactly at vertices adjacent to
both `a` and `b`.  
Mask removes all bits `≤ b`; remaining bits correspond to vertices `c>b`
adjacent to both. ∎



**Lemma 2**  
If the algorithm prints a triple `(a,b,c)`, then `{a,b,c}` is a triangle.

*Proof.*  
`b` is taken from `adj_list[a]`, therefore edge `(a,b)` exists.  
By Lemma&nbsp;1, `c` is a vertex with `c>b` that is adjacent to both `a` and `b`,
hence edges `(a,c)` and `(b,c)` exist. ∎



**Lemma 3**  
If a triangle `{x,y,z}` with `x<y<z` exists, the algorithm will eventually
consider the pair `(a,b) = (x,y)` and will find `c = z`.

*Proof.*  
When `a = x` the inner loop iterates over all neighbours `b> a`.  
Since edge `(x,y)` exists, `y` appears in `adj_list[x]`, so the pair `(x,y)`
is examined.  
By Lemma&nbsp;1, `common` after masking contains exactly the vertices `c>y`
adjacent to both `x` and `y`. Because `z` satisfies this, `common` is non‑zero,
and the lowest set bit is at most `z`. Since `z` is the smallest such vertex,
the lowest set bit equals `z`. Hence the algorithm will output `(x,y,z)`. ∎



**Lemma 4**  
The first triangle output by the algorithm is the lexicographically smallest
triangle of the graph.

*Proof.*  
Pairs `(a,b)` are examined in increasing lexicographic order:
`a` grows from `1` to `n`, and for each `a` the neighbours `b` are processed
in increasing order.  
For a fixed `(a,b)` the algorithm chooses the smallest possible `c>b`
(Lowest set bit).  
Thus any triangle discovered later has either a larger `a`,
or the same `a` and larger `b`,
or the same `a,b` and larger `c`.  
Consequently the first discovered triangle is lexicographically minimal. ∎



**Theorem**  
The algorithm always terminates and prints the lexicographically smallest
triple of processes that are pairwise mutually exclusive.

*Proof.*  
Existence of at least one triangle is guaranteed, so by Lemma&nbsp;3 the
algorithm will find one and terminate.  
By Lemma&nbsp;2 the printed triple is indeed a triangle.  
By Lemma&nbsp;4 it is the lexicographically smallest such triangle. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building the structures*: `O(m)` time, `O(n)` memory for the bitsets
(`n` integers) plus `O(m)` for adjacency lists.

*Main loops*: For each edge `(a,b)` we perform a constant‑time bitwise
`&` and a mask operation, i.e. `O(1)`.  
Thus total time `O(m)`.  
`n ≤ 2000`, `m ≤ 2·10⁵`, well within limits.

Memory: `n` integers ≈ 250 KB, adjacency lists `O(m)` integers → ≤ 2 MB.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj_bits = [0] * n
    adj_list = [[] for _ in range(n)]

    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        # set bits
        adj_bits[u] |= 1 << v
        adj_bits[v] |= 1 << u
        if u < v:
            adj_list[u].append(v)
        else:
            adj_list[v].append(u)

    # ensure neighbours are sorted (they already are because we added in input order,
    # but sorting guarantees correctness)
    for lst in adj_list:
        lst.sort()

    for a in range(n):
        bits_a = adj_bits[a]
        for b in adj_list[a]:          # b > a
            # intersection of neighbours of a and b
            common = bits_a & adj_bits[b]
            # keep only vertices > b
            mask = ~((1 << (b + 1)) - 1)
            common &= mask
            if common:
                low = common & -common          # lowest set bit
                c = low.bit_length() - 1
                # output in 1‑based, already a<b<c
                sys.stdout.write(f"{a+1} {b+1} {c+1}")
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
