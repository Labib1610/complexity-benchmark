We can solve this by checking all triples in lexicographic order and stopping at the first fully connected triangle.  
Since \( n \leq 2000 \), a naive triple loop would be too slow (\( O(n^3) \)).  
We can instead iterate over each vertex as the smallest in the triple, then check pairs among its neighbors.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(n):
        for b in adj[a]:
            if b > a:
                for c in adj[a]:
                    if c > b and c in adj[b]:
                        print(a + 1, b + 1, c + 1)
                        return

if __name__ == "__main__":
    main()
```
