**Solution Explanation**

For every process we know the set of processes it conflicts with.
The required three processes must be pairwise conflicting – they form a
*triangle* in the undirected graph whose vertices are the processes and
edges are the given constraints.

The graph has  

* `n ≤ 2000` vertices  
* `m ≤ 2·10⁵` edges  

and we have to output the lexicographically smallest triangle
`a < b < c`.

--------------------------------------------------------------------

#### 1.   Bitset representation  

`n = 2000` fits into a 2000‑bit integer (`int` in Python has arbitrary
precision).  
For every vertex `v` we store one integer `bits[v]` :

```
bit i (0‑based) of bits[v] == 1   ⇔   vertex (i+1) is adjacent to v
```

Setting an edge `(u , v)` :

```
bits[u] |= 1 << (v-1)
bits[v] |= 1 << (u-1)
```

All operations on these bitsets are O(1) word operations.

--------------------------------------------------------------------

#### 2.   Searching the smallest triangle  

We enumerate the first two vertices of the triangle in increasing order.
For a fixed ordered pair `a < b` we already know that the edge `a‑b`
exists, otherwise the pair cannot start a triangle.

All possible third vertices are exactly the common neighbours of `a`
and `b` :

```
common = bits[a] & bits[b]
```

We need the smallest `c` that is **larger than `b`**.
Bits `0 … b-1` correspond to vertices `1 … b`, therefore we discard them
by a right shift:

```
mask = common >> b          # bits for vertices > b
```

If `mask` is non‑zero, the least significant set bit gives the smallest
`c`.  
The usual trick `x & -x` isolates that bit; its index is
`(x & -x).bit_length() - 1`.

```
low = mask & -mask
c   = b + low.bit_length() - 1
```

The first triple we encounter while iterating `a` then `b` is exactly the
lexicographically smallest one, because the loops are in increasing
order.

The total work:

* building the bitsets – `O(m)`
* the double loop – at most `n·(n-1)/2 ≤ 2·10⁶` iterations,
  each doing only a few integer operations.

Both time and memory easily satisfy the limits.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest
triangle.

---

##### Lemma 1  
For any vertices `a < b` the set `common = bits[a] & bits[b]` is exactly
the set of vertices adjacent to **both** `a` and `b`.

**Proof.**  
`bits[a]` has a 1‑bit at position `v-1` iff `a` is adjacent to `v`.  
The same holds for `bits[b]`.  
The bitwise AND keeps a 1 at position `v-1` iff both bits were 1,
i.e. iff `v` is adjacent to both `a` and `b`. ∎



##### Lemma 2  
If `mask = common >> b` is non‑zero, the vertex  

```
c = b + (mask & -mask).bit_length() - 1
```

is the smallest vertex `c > b` that belongs to `common`.

**Proof.**  
`common >> b` discards bits `0 … b-1`; the remaining least significant
set bit corresponds to the smallest index `k ≥ 0` such that bit `b+k`
is set in `common`.  
`mask & -mask` isolates exactly this bit; its index is
`(mask & -mask).bit_length() - 1 = k`.  
Therefore `c = b + k` is the smallest vertex larger than `b` contained in
`common`. ∎



##### Lemma 3  
When the algorithm prints a triple `(a,b,c)`, the three vertices form a
triangle.

**Proof.**  
The outer loops guarantee `a < b` and that edge `a‑b` exists
(the inner loop continues only if that edge is present).  
By Lemma&nbsp;1, `c` is taken from `common = bits[a] & bits[b]`,
hence `c` is adjacent to both `a` and `b`.  
Thus all three edges `a‑b`, `a‑c`, `b‑c` exist – a triangle. ∎



##### Lemma 4  
The first printed triple is the lexicographically smallest triangle in
the graph.

**Proof.**  
The algorithm enumerates all ordered pairs `(a,b)` with `a < b` in
strictly increasing lexicographic order.
For a fixed pair it outputs the smallest possible `c > b`
(Lemma&nbsp;2).  
Consequently, any triangle `(a',b',c')` with `(a',b')` lexicographically
smaller than the pair at which the algorithm stops would have been found
earlier.  
If two triangles share the same `(a,b)`, the one with the smaller `c`
is output because we choose the minimal `c`.  
Therefore the first printed triple is the minimal one overall. ∎



##### Theorem  
The algorithm always terminates and outputs the lexicographically
smallest triple of distinct vertices that are pairwise adjacent
(i.e. a minimal failing subset of three processes).

**Proof.**  
Existence of at least one triangle is guaranteed, so some iteration will
find a non‑empty `mask` and terminate.  
By Lemma&nbsp;3 the printed triple is a triangle.  
By Lemma&nbsp;4 it is the lexicographically smallest such triangle. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Memory* : `n+1` integers, each ≤ `2ⁿ` → `O(n)` bits ≈ 2000·256 bytes ≈ 0.5 MiB.

*Time* :

* building adjacency bitsets: `O(m)`
* double loop over `a<b`: at most `n·(n-1)/2 ≤ 2·10⁶` iterations,
  each performing a constant number of integer operations.

Overall `O(n² + m)` ≤ `O(2·10⁶)` operations, well inside the 2 s limit.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    bits = [0] * (n + 1)          # 1‑based
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        bits[u] |= 1 << (v - 1)
        bits[v] |= 1 << (u - 1)

    for a in range(1, n - 1):
        bits_a = bits[a]
        for b in range(a + 1, n):
            # edge a‑b must exist
            if not ((bits_a >> (b - 1)) & 1):
                continue
            common = bits_a & bits[b]
            # keep only vertices > b
            mask = common >> b
            if mask:
                low = mask & -mask               # lowest set bit
                c = b + low.bit_length() - 1
                # output in ascending order (already a<b<c)
                sys.stdout.write(f"{a} {b} {c}")
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input‑output format.
