To solve this problem, we need to find three sensors such that every pair among them is interlocked (i.e., they form a triangle in the graph of interlocks). The solution must be the lexicographically smallest such triplet.

### Approach
1. **Graph Representation**: Represent the interlocks as an adjacency list or adjacency matrix. Given the constraints (n up to 2000), an adjacency matrix (using a bitset for efficiency) is feasible.
2. **Check for Triangles**: For each node `a` in ascending order, check all pairs of nodes `b` and `c` (where `a < b < c`) that are both connected to `a` and to each other. The first such triplet found will be the lexicographically smallest because we check in order.
3. **Efficiency**: Using a bitset representation for the adjacency matrix allows efficient intersection checks. For each node `a`, we can iterate through its neighbors `b` (greater than `a`), and for each such `b`, check if there exists a neighbor `c` of `a` that is also a neighbor of `b` and `c > b`. The first such triplet found is the answer.

### Solution Code
```python
import sys

def solve():
    input = sys.stdin.read().split()
    ptr = 0
    n, m = map(int, input[ptr:ptr+2])
    ptr +=2
    
    adj = [0] * (n + 1)  # using bitmask for adjacency
    
    for _ in range(m):
        u, v = map(int, input[ptr:ptr+2])
        ptr +=2
        adj[u] |= 1 << v
        adj[v] |= 1 << u
    
    for a in range(1, n + 1):
        neighbors_a = adj[a]
        # Iterate through all b > a that are neighbors of a
        b_candidates = []
        for b in range(a + 1, n + 1):
            if (neighbors_a >> b) & 1:
                b_candidates.append(b)
        # Now for each b in b_candidates, check if there's a c > b that is neighbor of both a and b
        for b in b_candidates:
            common = adj[a] & adj[b]
            # We need c > b and c is in common
            # So find the smallest c > b in common
            # To find the smallest c > b, we can mask out bits <= b
            mask = (1 << (n + 1)) - 1
            mask &= ~((1 << (b + 1)) - 1)
            common &= mask
            if common:
                # Find the lowest set bit in common
                c = (common & -common).bit_length() - 1
                print(a, b, c)
                return
    # Shouldn't reach here per problem statement
    print(-1, -1, -1)

solve()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Adjacency Representation**: Each node's adjacency list is represented as a bitmask. For example, if node 1 is connected to nodes 2 and 3, `adj[1]` will have bits 2 and 3 set.
3. **Finding Triangles**: For each node `a` (starting from 1), we check all nodes `b` greater than `a` that are connected to `a`. For each such `b`, we compute the intersection of neighbors of `a` and `b` (using bitwise AND). We then look for the smallest node `c` greater than `b` in this intersection. The first such triplet `(a, b, c)` found is printed, ensuring lexicographical order.
4. **Efficiency**: The bitmask operations allow efficient intersection checks. The loop structure ensures that we check nodes in ascending order, guaranteeing the lexicographically smallest triplet is found first.

This approach efficiently checks for the presence of a triangle in the graph while leveraging bitwise operations for performance, making it suitable for the given constraints.
