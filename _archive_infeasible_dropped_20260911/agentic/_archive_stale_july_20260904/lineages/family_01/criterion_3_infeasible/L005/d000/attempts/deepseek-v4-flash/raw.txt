 We need to find any triangle in the graph, and specifically the lexicographically smallest one.  
Since the graph is guaranteed to have at least one triangle, we can iterate over vertices in increasing order and check for triangles.

A simple approach:  
- For each vertex `a` from 1 to n,  
  - For each neighbor `b` of `a` where `b > a`,  
    - For each neighbor `c` of `a` where `c > b`,  
      - If `b` and `c` are connected, we found a triangle `(a, b, c)`.  
Since we iterate in increasing order, the first found will be lexicographically smallest.

We can store adjacency as a set for O(1) edge lookup.

Here’s the implementation:

```python
n, m = map(int, input().split())
adj = [set() for _ in range(n + 1)]

for _ in range(m):
    u, v = map(int, input().split())
    adj[u].add(v)
    adj[v].add(u)

for a in range(1, n + 1):
    for b in adj[a]:
        if b > a:
            for c in adj[a]:
                if c > b and c in adj[b]:
                    print(a, b, c)
                    exit()
```
