# Problem C — Proof of Impossibility

Time limit: 2 s   Memory limit: 256 MB

The factory still has only two shifts, 1 and 2, but the roster is known to be hopeless. Your job is not to schedule — it is to certify the impossibility. You must find a group of three workers where each worker in the group conflicts with both of the other two. Any such group proves two shifts cannot suffice. Output one such group. 

The conflict data is adversarial: the lexicographically smallest valid group can occur only after all earlier candidate triples have been rejected.

## Input
The first line contains two integers n and m (3 ≤ n ≤ 2000, 3 ≤ m ≤ min(n·(n−1)/2, 2·10⁵)).
Each of the next m lines contains two integers u v — a conflicting pair.
The instances are constructed such that the earliest valid trio might only be located after exhaustively eliminating all preceding possibilities.

## Output
Print three integers a b c on one line with a < b < c such that all three pairs a–b, a–c, and b–c are listed as conflicts. Output the lexicographically smallest such group (smallest a; ties by smallest b; then smallest c).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
