**Solution Explanation**

For every worker `i (1 … n)` we store the set of workers that conflict with `i`.
`n ≤ 2000`, therefore a bitset of `n` bits fits easily into a Python integer
(`2000` bits ≈ `250` bytes).

For a triangle `{a,b,c}` we need the three edges  

```
a–b , a–c , b–c
```

The required output is the lexicographically smallest triple
`a < b < c`.  
Hence we can simply try all possible `a` in increasing order,
for each `a` all possible `b > a` that are neighbours of `a`,
and finally the smallest `c > b` that is neighbour of **both** `a` and `b`.

The intersection of the neighbour sets of `a` and `b` is a bitset.
From it we have to obtain the smallest index larger than `b`.
With bit operations this is `O(1)` :

```
common = adj[a] & adj[b]                # neighbours of both a and b
x = common >> b                          # discard bits ≤ b
if x != 0:
        # lowest set bit of x
        low = (x & -x).bit_length() - 1
        c = b + low
        triangle (a,b,c) found
```

The first triangle discovered in this order is exactly the lexicographically
smallest one, because we increase `a`, then `b`, then the smallest possible `c`.

The total work:

* building the bitsets – `O(m)`
* iterating over all edges `(a,b)` – at most `m` iterations,
  each does only a few integer operations.

With `n ≤ 2000` and `m ≤ 2·10⁵` this easily fits into the limits.



--------------------------------------------------------------------

#### Algorithm
```
read n, m
adj = [0] * (n+1)          # 1‑based, each entry is an int bitset

for each of the m edges (u,v):
        set bit v-1 in adj[u]
        set bit u-1 in adj[v]

for a = 1 … n:
        bits_a = adj[a]
        # iterate over neighbours b > a
        # we extract them by scanning bits of bits_a
        # but we only need those > a, so we shift right a
        nb = bits_a >> a
        while nb:
                # lowest neighbour > a
                lowb = (nb & -nb).bit_length() - 1
                b = a + 1 + lowb          # because we shifted by a
                # find common neighbours of a and b larger than b
                common = adj[a] & adj[b]
                x = common >> b
                if x:
                        lowc = (x & -x).bit_length() - 1
                        c = b + lowc
                        output a b c and exit
                # remove this b and continue
                nb &= nb - 1
```

The inner `while nb` iterates over all neighbours `b` of `a` with `b>a`.
The total number of processed pairs `(a,b)` equals the number of edges,
so the algorithm is linear in `m`.



--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest triangle.

---

**Lemma 1**  
For any pair of vertices `a < b`, the algorithm finds the smallest vertex
`c > b` such that edges `a–c` and `b–c` exist, if such a `c` exists.

*Proof.*  
`common = adj[a] & adj[b]` contains exactly the vertices adjacent to both
`a` and `b`.  
`x = common >> b` discards all bits `≤ b`.  
If `x ≠ 0`, its lowest set bit corresponds to the smallest index `c'` with
`c' > b` that belongs to `common`.  
`c = b + (position of that lowest bit)` is therefore the smallest `c > b`
adjacent to both `a` and `b`. ∎



**Lemma 2**  
When the outer loop is at vertex `a`, the inner loop examines neighbours
`b` in strictly increasing order.

*Proof.*  
`nb = adj[a] >> a` removes bits `≤ a`.  
Repeatedly extracting the lowest set bit of `nb` yields the neighbours
`b` in increasing order, because after each extraction the bit is cleared
and the next lowest bit becomes the new lowest. ∎



**Lemma 3**  
If the algorithm outputs a triple `(a,b,c)`, then `{a,b,c}` is a triangle
(i.e. all three edges are present).

*Proof.*  
`b` is a neighbour of `a` by construction (bit set in `adj[a]`).  
`c` is obtained from `common = adj[a] & adj[b]`, therefore `c` is neighbour of
both `a` and `b`. Hence edges `a–b`, `a–c`, `b–c` all exist. ∎



**Lemma 4**  
The first triangle output by the algorithm is the lexicographically
smallest triangle in the graph.

*Proof.*  
Consider any triangle `{a',b',c'}` with `a' < b' < c'`.  
During the outer loop the algorithm reaches `a = a'` before any larger `a`.  
By Lemma&nbsp;2, when `a = a'` the inner loop processes neighbours `b`
in increasing order, thus it will encounter `b = b'` before any larger
neighbour.  
When processing this pair `(a',b')`, Lemma&nbsp;1 guarantees that the
algorithm finds the smallest possible `c > b'` that together with `a',b'`
forms a triangle; this `c` is exactly `c'` (or a smaller one, which would
already be a triangle with the same `a',b'`).  
Consequently the algorithm outputs a triangle no later (lexicographically)
than `{a',b',c'}`. Since this holds for every triangle, the first output
must be the lexicographically smallest. ∎



**Theorem**  
The algorithm always terminates and prints the lexicographically smallest
triple `a b c` (`a<b<c`) such that all three conflict pairs are present.

*Proof.*  
The input guarantees at least one triangle, so some pair `(a,b)` will have
`x ≠ 0` and the algorithm will output a triangle (Lemma&nbsp;3) and stop.  
By Lemma&nbsp;4 this triangle is the lexicographically smallest one. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency bitsets*: `O(m)` time, `O(n)` integers (≈ 250 KB).  
*Main loops*: each edge `(a,b)` is examined once → `O(m)` iterations,
each does a constant number of bit operations.  

Total time `O(m) ≤ 2·10⁵`, well below the 2 s limit.  
Memory usage `O(n)` integers ≈ `0.5 MB`.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * (n + 1)          # 1‑based, bit i‑1 corresponds to vertex i

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u] |= 1 << (v - 1)
        adj[v] |= 1 << (u - 1)

    for a in range(1, n + 1):
        # neighbours of a that are > a
        nb = adj[a] >> a
        while nb:
            lowb = (nb & -nb).bit_length() - 1   # position of lowest set bit
            b = a + 1 + lowb                       # actual vertex number
            # common neighbours of a and b
            common = adj[a] & adj[b]
            x = common >> b
            if x:
                lowc = (x & -x).bit_length() - 1
                c = b + lowc
                sys.stdout.write(f"{a} {b} {c}\n")
                return
            nb &= nb - 1   # clear lowest set bit

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
