We can solve this by reading all jobs, checking each job’s total time, and also summing the totals for each leg.  

If any job’s `p1 + p2 > T`, we print `JOB i` immediately.  
Otherwise, after checking all jobs, if the sum of leg 1 or leg 2 exceeds `T`, we print `LOAD c`.  

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    j = int(data[0])
    T = int(data[1])
    
    sum1 = 0
    sum2 = 0
    
    idx = 2
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        
        sum1 += p1
        sum2 += p2
    
    if sum1 > T:
        print("LOAD 1")
    elif sum2 > T:
        print("LOAD 2")

if __name__ == "__main__":
    main()
```
