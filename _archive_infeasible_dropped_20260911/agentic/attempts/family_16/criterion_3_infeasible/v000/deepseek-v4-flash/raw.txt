We can solve this by checking two conditions in order:

1. If any job has `p1 + p2 > T`, output `JOB i`.
2. Otherwise, compute total load on machine 1 and machine 2. If either exceeds `T`, output `LOAD c`.

Here’s the implementation:

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    
    n = int(data[0])
    T = int(data[1])
    
    idx = 2
    load1 = 0
    load2 = 0
    
    for i in range(1, n + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        
        load1 += p1
        load2 += p2
    
    if load1 > T:
        print("LOAD 1")
    elif load2 > T:
        print("LOAD 2")

if __name__ == "__main__":
    main()
```
