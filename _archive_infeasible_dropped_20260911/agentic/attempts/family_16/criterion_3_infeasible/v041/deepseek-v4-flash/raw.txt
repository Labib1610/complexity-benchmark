 We need to check two conditions in order:  

1. If any packet has `p1 + p2 > T`, output `JOB i` (1-based index).  
2. Otherwise, if the sum of all `p1` values > T, output `LOAD 1`; if the sum of all `p2` values > T, output `LOAD 2`.  

Since the problem guarantees exactly one condition will be true, we can check in that order.  

```python
j, T = map(int, input().split())
total_p1 = 0
total_p2 = 0

for i in range(1, j + 1):
    p1, p2 = map(int, input().split())
    total_p1 += p1
    total_p2 += p2
    if p1 + p2 > T:
        print(f"JOB {i}")
        break
else:
    if total_p1 > T:
        print("LOAD 1")
    else:
        print("LOAD 2")
```
