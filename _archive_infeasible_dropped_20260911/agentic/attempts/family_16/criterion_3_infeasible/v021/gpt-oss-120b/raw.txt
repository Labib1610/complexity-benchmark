**Solution Explanation**

For every job we know

* `p1` – time on channel 1 (header)  
* `p2` – time on channel 2 (payload)

The whole schedule must finish inside the window `T`.

The statement guarantees that the window is impossible, i.e. **at least one**
of the following holds

* there is a job whose total time `p1+p2` exceeds `T`;
* the total time needed on channel 1 (` Σ p1 `) exceeds `T`;
* the total time needed on channel 2 (` Σ p2 `) exceeds `T`.

Exactly one of these three conditions is true for the test data, therefore we
only have to find any condition that holds and output the required text.

--------------------------------------------------------------------

#### Algorithm
```
read j, T
sum1 = 0                     # Σ p1
sum2 = 0                     # Σ p2
bad_job = 0                  # index of a job with p1+p2 > T (0 = none yet)

for i = 1 .. j:
        read p1, p2
        sum1 += p1
        sum2 += p2
        if bad_job == 0 and p1 + p2 > T:
                bad_job = i

if bad_job != 0:
        print "JOB", bad_job
else if sum1 > T:
        print "LOAD 1"
else:
        print "LOAD 2"
```

The algorithm follows the specification directly:
* while scanning the input we accumulate the two channel loads,
* simultaneously we remember the first job whose own duration is too large.

Because the input size is at most `2·10⁵`, a single linear pass is easily fast
enough.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm always prints a correct certificate.

---

**Lemma 1**  
If the algorithm prints `JOB i`, then job `i` cannot be completed inside the
window `T`.

*Proof.* The algorithm prints `JOB i` only when it has found an index `i`
with `p1_i + p2_i > T`. The job needs at least its header time plus its payload
time, executed sequentially, therefore it needs more than `T` time units.
∎



**Lemma 2**  
If the algorithm prints `LOAD 1`, then channel 1 cannot finish all its
assignments within the window `T`.

*Proof.* `LOAD 1` is printed only when `sum1 = Σ p1 > T`.  
Channel 1 can process only one transmission at a time, thus it must be active
for at least the sum of all header times, i.e. `sum1`. Since `sum1 > T`,
the window is insufficient. ∎



**Lemma 3**  
If the algorithm prints `LOAD 2`, then channel 2 cannot finish all its
assignments within the window `T`.

*Proof.* Symmetric to Lemma&nbsp;2, using `sum2 = Σ p2 > T`. ∎



**Theorem**  
For every admissible input the algorithm outputs a line that correctly
certifies the impossibility of completing all jobs within the window `T`.

*Proof.* The problem statement guarantees that at least one of the three
conditions holds:

* there exists a job `i` with `p1_i + p2_i > T`; or
* `Σ p1 > T`; or
* `Σ p2 > T`.

The algorithm examines the whole input:

* If a job with `p1+p2 > T` exists, the first such job is stored in
  `bad_job` and the algorithm prints `JOB i`. By Lemma 1 the printed line is a
  valid certificate.

* Otherwise no job violates the per‑job bound, therefore the first condition is
  false. By the guarantee, at least one of the channel‑load conditions is true.
  The algorithm checks `sum1 > T`; if it holds it prints `LOAD 1`,
  which is correct by Lemma 2.  
  If `sum1 ≤ T`, then `sum2 > T` must be true, and the algorithm prints
  `LOAD 2`, correct by Lemma 3.

In all cases the printed line is a correct proof of impossibility. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

The loop processes each of the `j` jobs once, performing O(1) work.
*Time*: `O(j)`  
*Memory*: `O(1)` (only a few integer variables)

--------------------------------------------------------------------

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    j = next(it)
    T = next(it)

    sum1 = 0
    sum2 = 0
    bad_job = 0

    for idx in range(1, j + 1):
        p1 = next(it)
        p2 = next(it)
        sum1 += p1
        sum2 += p2
        if bad_job == 0 and p1 + p2 > T:
            bad_job = idx

    out = []
    if bad_job:
        out = f"JOB {bad_job}"
    elif sum1 > T:
        out = "LOAD 1"
    else:
        out = "LOAD 2"

    sys.stdout.write(out + "\n")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
