We can solve this by scanning the jobs once, checking both conditions:

- If any job has `p1 + p2 > T`, we can immediately output `JOB i`.
- Otherwise, we sum up all `p1` and `p2` values. If either sum exceeds `T`, we output `LOAD 1` or `LOAD 2` accordingly.

Since the problem guarantees at least one condition holds, we can stop early when we find a job that is too long.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    j = int(data[0])
    T = int(data[1])
    
    total1 = 0
    total2 = 0
    
    idx = 2
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        
        total1 += p1
        total2 += p2
    
    if total1 > T:
        print("LOAD 1")
    else:
        print("LOAD 2")

if __name__ == "__main__":
    main()
```
