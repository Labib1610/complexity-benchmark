 We need to check two conditions in order:

1. If any job has `p1 + p2 > T`, print `JOB i` (1-based index).
2. Otherwise, if the sum of all `p1` > T, print `LOAD 1`; if sum of all `p2` > T, print `LOAD 2`.

We can do this in a single pass while reading input.

```python
j, T = map(int, input().split())
sum1 = 0
sum2 = 0

for i in range(1, j + 1):
    p1, p2 = map(int, input().split())
    if p1 + p2 > T:
        print(f"JOB {i}")
        break
    sum1 += p1
    sum2 += p2
else:
    if sum1 > T:
        print("LOAD 1")
    elif sum2 > T:
        print("LOAD 2")
```
