Looking at this problem, I need to check two conditions and output the first one that applies:

1. If any single JOB has p1 + p2 > T, output `JOB i` (1-based index)
2. If total workload on appliance 1 or 2 exceeds T, output `LOAD c`

The problem guarantees exactly one reason always applies, so I just need to find which one.

Let me trace through the examples:
- Example 1: JOB 1 has 70+60=130 > 100, so output `JOB 1`
- Example 2: No single job exceeds 150, but appliance 1 total is 200 > 150, so output `LOAD 1`

The order of checking matters - I should check for a single JOB violation first, then check for LOAD violations.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    idx = 0
    j = int(data[idx]); idx += 1
    T = int(data[idx]); idx += 1
    
    total1 = 0
    total2 = 0
    
    for i in range(1, j + 1):
        p1 = int(data[idx]); idx += 1
        p2 = int(data[idx]); idx += 1
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        total1 += p1
        total2 += p2
    
    if total1 > T:
        print("LOAD 1")
    else:
        print("LOAD 2")

main()
```
