**Solution Explanation**

For each job we know the time it needs on appliance 1 (`p1`) and on appliance 2
(`p2`).  
The deadline `T` is impossible for **every** input, and exactly one of the
following reasons is true:

* some single job needs more than `T` time in total (`p1 + p2 > T`);
* the total time needed on appliance 1 (`Σ p1`) is larger than `T`;
* the total time needed on appliance 2 (`Σ p2`) is larger than `T`.

We only have to find **one** certificate that proves the impossibility.

--------------------------------------------------------------------

#### Algorithm
```
read j, T
sum1 = 0
sum2 = 0
for i = 1 … j
        read p1, p2
        if p1 + p2 > T               # single‑job certificate
                output "JOB i" and stop
        sum1 += p1
        sum2 += p2
# no single job is too long – a load overload must exist
if sum1 > T
        output "LOAD 1"
else            # sum2 must be > T because a certificate is guaranteed
        output "LOAD 2"
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm always outputs a correct certificate.

---

**Lemma 1**  
If the algorithm outputs `JOB i`, then job *i* alone cannot finish before the
deadline `T`.

*Proof.* The algorithm outputs `JOB i` only when it encounters job *i* with
`p1_i + p2_i > T`. A job must first run `p1_i` on appliance 1 and then `p2_i`
on appliance 2, so its total processing time is exactly `p1_i + p2_i`, which
exceeds `T`. ∎



**Lemma 2**  
If the algorithm finishes the loop without outputting a `JOB`,
then for every job `k` we have `p1_k + p2_k ≤ T`.

*Proof.* The loop would have printed `JOB k` immediately when it saw a job with
`p1_k + p2_k > T`. Since it never did, no such job exists. ∎



**Lemma 3**  
If after the loop the algorithm outputs `LOAD 1`, then the total workload of
appliance 1 exceeds `T`.

*Proof.* The algorithm outputs `LOAD 1` only when `sum1 = Σ p1_k` is greater
than `T`. This sum is precisely the total amount of time appliance 1 must work,
hence it exceeds the deadline. ∎



**Lemma 4**  
If the algorithm outputs `LOAD 2`, then the total workload of appliance 2 exceeds
`T`.

*Proof.* Symmetric to Lemma&nbsp;3. ∎



**Theorem**  
The algorithm always prints a string that is a valid certificate of impossibility.

*Proof.* Two cases.

*Case 1* – during the scan a job with `p1 + p2 > T` is found.  
The algorithm prints `JOB i`. By Lemma&nbsp;1 this is a valid certificate.

*Case 2* – no such job exists.  
By Lemma&nbsp;2 every job fits individually, so the impossibility must come from
overload of an appliance. Because the problem guarantees that *some* certificate
exists, at least one of the two total loads exceeds `T`.  
The algorithm checks `sum1` first; if it exceeds `T` it prints `LOAD 1`
(Lemma&nbsp;3). Otherwise `sum2` must exceed `T` and it prints `LOAD 2`
(Lemma&nbsp;4). In both sub‑cases the printed line is a valid certificate.

Thus the algorithm always outputs a correct answer. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

The loop processes each of the `j` jobs once, using only O(1) work per job.

*Time*: `O(j)`  
*Memory*: `O(1)` (only a few integer variables)

With `j ≤ 200 000` this easily fits the limits.

--------------------------------------------------------------------

#### Reference Implementation (Python 3)

```python
import sys

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    j = next(it)
    T = next(it)

    sum1 = 0
    sum2 = 0

    for idx in range(1, j + 1):
        p1 = next(it)
        p2 = next(it)
        if p1 + p2 > T:
            sys.stdout.write(f"JOB {idx}\n")
            return
        sum1 += p1
        sum2 += p2

    if sum1 > T:
        sys.stdout.write("LOAD 1\n")
    else:
        # guaranteed that some certificate exists, so sum2 > T
        sys.stdout.write("LOAD 2\n")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms to
the required input‑output format.
