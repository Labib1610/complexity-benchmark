We can solve this by scanning the requests once, tracking:

- The sum of all Stage 1 durations.
- The sum of all Stage 2 durations.
- Whether any single request has `p1 + p2 > T`.

If we find a job that exceeds `T`, we can immediately output `JOB i` and stop.  
Otherwise, after reading all jobs, we check the stage sums and output `LOAD c` for the overloaded stage.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    j = int(data[0])
    T = int(data[1])
    
    sum1 = 0
    sum2 = 0
    
    idx = 2
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        
        sum1 += p1
        sum2 += p2
    
    if sum1 > T:
        print("LOAD 1")
    elif sum2 > T:
        print("LOAD 2")

if __name__ == "__main__":
    main()
```
