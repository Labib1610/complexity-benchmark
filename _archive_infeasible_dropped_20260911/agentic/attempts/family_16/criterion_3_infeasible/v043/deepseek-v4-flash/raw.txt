We can scan the input once, checking each order’s total duration and summing up the total time for each phase.

If we find any order where `p1 + p2 > T`, we output `JOB i`.  
If no such order exists, we check the total loads; the first phase sum or second phase sum that exceeds `T` gives the `LOAD c` output.

Here’s the code:  

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    
    sum1 = 0
    sum2 = 0
    idx = 2
    
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        
        sum1 += p1
        sum2 += p2
    
    if sum1 > T:
        print("LOAD 1")
    elif sum2 > T:
        print("LOAD 2")

if __name__ == "__main__":
    main()
```
