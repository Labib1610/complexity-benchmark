 We can solve this by checking two conditions in order:

1. If any job has `p1 + p2 > T`, output `JOB i` (1-based index).
2. Otherwise, if the sum of all `p1` or the sum of all `p2` exceeds `T`, output `LOAD 1` or `LOAD 2` accordingly.

Here’s the implementation:

```python
j, T = map(int, input().split())
sum1 = 0
sum2 = 0
for i in range(1, j + 1):
    p1, p2 = map(int, input().split())
    if p1 + p2 > T:
        print(f"JOB {i}")
        exit()
    sum1 += p1
    sum2 += p2

if sum1 > T:
    print("LOAD 1")
elif sum2 > T:
    print("LOAD 2")
```
