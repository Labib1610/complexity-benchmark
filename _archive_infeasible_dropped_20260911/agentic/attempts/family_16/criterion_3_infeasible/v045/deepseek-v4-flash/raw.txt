We can check both conditions directly:

- For `JOB i`, check if `p1 + p2 > T`.
- For `LOAD c`, check if the sum of all `p1` (for Stage 1) or all `p2` (for Stage 2) exceeds `T`.

Since the problem guarantees exactly one of these is true, we can check in order and output the first match.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    
    idx = 2
    sum1 = 0
    sum2 = 0
    
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        sum1 += p1
        sum2 += p2
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
    
    if sum1 > T:
        print("LOAD 1")
        return
    if sum2 > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
