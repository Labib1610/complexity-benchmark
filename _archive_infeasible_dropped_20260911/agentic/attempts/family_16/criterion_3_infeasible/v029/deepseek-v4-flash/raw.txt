We can scan the input and check the two conditions in order, but we must be careful:  
The problem says exactly one of the two reasons always applies for the provided inputs, but we should still implement a straightforward check.

A simple approach:

1. Read `j` and `T`.
2. Read each job; also keep running totals for `p1` and `p2`.
3. If any `p1 + p2 > T`, immediately print `JOB i` and finish (using 1-based index).
4. After reading all jobs, check totals:
   - If total1 > T, print `LOAD 1`.
   - Else if total2 > T, print `LOAD 2`.

Let's write the solution.  

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    j = int(data[0])
    T = int(data[1])
    
    total1 = 0
    total2 = 0
    
    idx = 2
    for i in range(1, j + 1):
        p1 = int(data[idx]); p2 = int(data[idx + 1])
        idx += 2
        total1 += p1
        total2 += p2
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
    
    if total1 > T:
        print("LOAD 1")
    else:
        print("LOAD 2")

if __name__ == "__main__":
    main()
```
