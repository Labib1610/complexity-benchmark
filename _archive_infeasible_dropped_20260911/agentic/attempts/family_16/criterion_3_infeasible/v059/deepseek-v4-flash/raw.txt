We need to check two conditions in order:

1. **Rule A**: If any job has `p1 + p2 > T`, output `JOB i` (1-indexed).
2. **Rule B**: If the sum of all `p1` > T, output `LOAD 1`; if sum of all `p2` > T, output `LOAD 2`.

We must check Rule A first, because if any job exceeds T individually, we output that immediately.  
If no job triggers Rule A, then check Rule B.

Here’s the implementation:

```python
j, T = map(int, input().split())

sum1 = 0
sum2 = 0

for i in range(1, j + 1):
    p1, p2 = map(int, input().split())
    if p1 + p2 > T:
        print(f"JOB {i}")
        exit()
    sum1 += p1
    sum2 += p2

if sum1 > T:
    print("LOAD 1")
elif sum2 > T:
    print("LOAD 2")
```
