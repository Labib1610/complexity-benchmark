We need to parse the input, check two conditions:

1. **Isolated Task Violation**: If any single task’s total time (sum of its two subsystem times) exceeds the budget `T`, output `JOB i` where `i` is the 1-based index of that task.
2. **Subsystem Saturation**: If the sum of times on subsystem 1 exceeds `T`, output `LOAD 1`. If the sum of times on subsystem 2 exceeds `T`, output `LOAD 2`.

We must check in order: first any isolated task violation, then subsystem saturation.

Here’s the implementation:

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    
    idx = 0
    n = int(data[idx]); idx += 1
    T = int(data[idx]); idx += 1
    
    sum1 = 0
    sum2 = 0
    
    for i in range(1, n + 1):
        a = int(data[idx]); idx += 1
        b = int(data[idx]); idx += 1
        if a + b > T:
            print(f"JOB {i}")
            return
        sum1 += a
        sum2 += b
    
    if sum1 > T:
        print("LOAD 1")
        return
    if sum2 > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
