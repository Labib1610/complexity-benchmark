 We need to check two conditions in order:  

1. If any job has `p1 + p2 > T`, output `JOB i` (1-based index).  
2. Otherwise, if the sum of all `p1` exceeds `T`, output `LOAD 1`.  
3. Otherwise, if the sum of all `p2` exceeds `T`, output `LOAD 2`.  

We can do this in a single pass.  

```python
j, T = map(int, input().split())
sum_p1 = 0
sum_p2 = 0

for i in range(1, j + 1):
    p1, p2 = map(int, input().split())
    if p1 + p2 > T:
        print(f"JOB {i}")
        break
    sum_p1 += p1
    sum_p2 += p2
else:
    if sum_p1 > T:
        print("LOAD 1")
    elif sum_p2 > T:
        print("LOAD 2")
```
