We can solve this by checking two conditions in order:

1. If any job has `p1 + p2 > T`, output `JOB i`.
2. Otherwise, check if the sum of all `p1` exceeds `T` → output `LOAD 1`, or if the sum of all `p2` exceeds `T` → output `LOAD 2`.

Here’s the implementation:

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    j = int(data[0])
    T = int(data[1])
    
    total1 = 0
    total2 = 0
    
    idx = 2
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        
        total1 += p1
        total2 += p2
    
    if total1 > T:
        print("LOAD 1")
    elif total2 > T:
        print("LOAD 2")

if __name__ == "__main__":
    main()
```
