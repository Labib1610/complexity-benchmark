We can solve this by checking two conditions in order:

1. If any job has `p1 + p2 > T`, output `JOB i`.
2. Otherwise, check if the sum of all `p1` values exceeds `T` → `LOAD 1`, or sum of all `p2` values exceeds `T` → `LOAD 2`.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    j = int(data[0])
    T = int(data[1])
    
    sum1 = 0
    sum2 = 0
    
    idx = 2
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        
        sum1 += p1
        sum2 += p2
    
    if sum1 > T:
        print("LOAD 1")
    elif sum2 > T:
        print("LOAD 2")

if __name__ == "__main__":
    main()
```
