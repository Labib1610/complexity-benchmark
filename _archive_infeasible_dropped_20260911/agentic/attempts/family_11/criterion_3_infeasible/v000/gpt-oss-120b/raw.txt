**Solution Explanation**

We have `u` required skills numbered `1 … u`.  
From the `s` consultants we read all skills they possess.
A skill is *present* if it appears at least once among all consultants.
The problem guarantees that at least one skill is missing; we have to output the
smallest missing skill id.

The task is exactly:

```
given a subset S ⊆ {1,…,u},
find   min { x | 1 ≤ x ≤ u , x ∉ S }.
```

`u ≤ 200 000`, total number of listed skills ≤ 200 000, so a linear algorithm
works easily.

--------------------------------------------------------------------

#### Algorithm
1. Create a boolean array `present[1…u]`, initially all `False`.
2. Scan the input.
   For each listed skill `k` set `present[k] = True`.
3. After all data are processed, scan `present` from `1` upwards and output the
   first index whose value is `False`.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs exactly the smallest skill id that no
consultant has.

*Lemma 1*  
After step 2, for every skill `x` (1 ≤ x ≤ u) `present[x]` is `True` **iff**
there exists at least one consultant that possesses skill `x`.

*Proof.*  
During scanning each occurrence of skill `x` sets `present[x]` to `True`.  
If no consultant has `x`, the assignment is never executed, leaving the
initial value `False`. Conversely, if at least one consultant has `x`, the
assignment occurs at least once, making the value `True`. ∎



*Lemma 2*  
The first index `m` found in step 3 (the smallest `m` with `present[m] = False`)
is a skill that no consultant has.

*Proof.*  
By Lemma 1, `present[m] = False` means no consultant possesses skill `m`. ∎



*Lemma 3*  
No skill with identifier smaller than `m` is missing.

*Proof.*  
Step 3 examines indices in increasing order and stops at the first `False`.
Hence every earlier index `i < m` satisfied `present[i] = True`, and by
Lemma 1 each such `i` is possessed by some consultant. ∎



*Theorem*  
The algorithm outputs the smallest skill id that no consultant has.

*Proof.*  
By Lemma 2 the reported `m` is a missing skill.
By Lemma 3 no smaller skill is missing.
Therefore `m` is exactly the smallest missing skill. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

* Let `T` be the total number of listed skills ( ≤ 200 000 ).
* Scanning all consultants processes each listed skill once: **O(T)** time.
* The final linear scan over `u` skills costs **O(u)** time.
* Total time: **O(u + T)** ≤ O(200 000 + 200 000) well inside limits.
* Memory: the boolean array of size `u+1` → **O(u)** ≤ 200 001 bytes
  (using a `bytearray`).  

--------------------------------------------------------------------

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    u, s = data[0], data[1]
    present = bytearray(u + 1)          # index 0 unused
    idx = 2
    for _ in range(s):
        c = data[idx]
        idx += 1
        for _ in range(c):
            skill = data[idx]
            idx += 1
            present[skill] = 1
    for skill_id in range(1, u + 1):
        if not present[skill_id]:
            sys.stdout.write(str(skill_id))
            return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
