We can solve this by marking which skills appear at least once, then scanning from 1 to u to find the first missing one.  

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    u = int(data[0])
    s = int(data[1])
    
    seen = [False] * (u + 1)
    idx = 2
    for _ in range(s):
        c = int(data[idx])
        idx += 1
        for _ in range(c):
            skill = int(data[idx])
            idx += 1
            seen[skill] = True
    
    for i in range(1, u + 1):
        if not seen[i]:
            print(i)
            return

if __name__ == "__main__":
    main()
```
