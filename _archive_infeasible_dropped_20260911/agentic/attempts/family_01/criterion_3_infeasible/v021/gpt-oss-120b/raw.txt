**Solution Explanation**

For every body we store the set of bodies it resonates with.
Because `n ≤ 2000` we can keep each set as a bitset inside a Python integer
(`bit i` = 1  ⇔  body *i* is a neighbour).

For a triangle `{a,b,c}` (`a<b<c`) we need the three edges  

```
a–b , a–c , b–c
```

If we already know that `a–b` exists, then `c` must be a common neighbour of
`a` **and** `b` and also larger than `b`.

```
common = neighbours[a] ∧ neighbours[b]          # bitwise AND
c is the smallest set bit of common that is > b
```

The smallest set bit can be obtained with the classic trick  

```
low = x & -x          # isolates the lowest 1‑bit
index = low.bit_length() - 1
```

The algorithm enumerates all pairs `(a,b)` in lexicographic order
(`a` from `0` to `n‑1`, `b` from `a+1` to `n‑1`).  
The first pair for which a suitable `c` exists yields the lexicographically
smallest triangle, and we can stop immediately.

`n = 2000` → at most `~2·10⁶` pairs, each processed in O(1) time.
Overall complexity  

*Time*   `O(n² + m)`   (building the bitsets + scanning pairs)  
*Memory* `O(n)`        (one integer per vertex, ≤ 2000 bits each)

Both satisfy the limits.

#### Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
triangle.

---

**Lemma 1**  
For any vertices `a<b`, if edge `a–b` exists then
`common = neighbours[a] ∧ neighbours[b]` contains exactly the vertices that are
adjacent to **both** `a` and `b`.

*Proof.* By definition `neighbours[x]` has a 1‑bit precisely for vertices
adjacent to `x`. Bitwise AND keeps a 1‑bit only when it is 1 in both operands,
i.e. when the vertex is adjacent to both `a` and `b`. ∎



**Lemma 2**  
Let `c` be the smallest vertex `> b` such that edges `a–c` and `b–c` exist.
Then `c` is the smallest set bit of `common` after position `b`.

*Proof.* By Lemma&nbsp;1, `common` has a 1‑bit exactly for vertices adjacent to
both `a` and `b`. Restricting to positions `> b` discards all vertices `≤ b`.
The remaining lowest 1‑bit is therefore the smallest vertex `> b` adjacent to
both, i.e. the required `c`. ∎



**Lemma 3**  
If the algorithm prints a triple `(a,b,c)`, then `{a,b,c}` is a triangle.

*Proof.* The algorithm prints only after confirming that the bit `b` is set in
`neighbours[a]` (edge `a–b`).  
It then computes `common = neighbours[a] ∧ neighbours[b]` and extracts a
vertex `c` from it, guaranteeing that both bits `c` are set in
`neighbours[a]` and `neighbours[b]`. Hence edges `a–c` and `b–c` exist.
All three edges are present, so `{a,b,c}` is a triangle. ∎



**Lemma 4**  
When the algorithm prints `(a,b,c)`, no triangle `(a',b',c')` with
lexicographically smaller `(a',b',c')` exists.

*Proof.* The outer loops enumerate pairs `(a,b)` in increasing lexicographic
order. The first printed pair is the first pair for which a suitable `c`
exists. For this fixed `(a,b)`, Lemma&nbsp;2 shows that the algorithm chooses the
smallest possible `c`. Therefore any triangle with a smaller `a` would have
been examined earlier, and any triangle with the same `a` but smaller `b`
would also have been examined earlier. If `a` and `b` are equal, the chosen `c`
is minimal. Hence no lexicographically smaller triangle exists. ∎



**Theorem**  
The algorithm outputs the lexicographically smallest triple
`a<b<c` such that all three edges among them are present.

*Proof.* By Lemma&nbsp;3 the output is always a triangle.
By Lemma&nbsp;4 no lexicographically smaller triangle exists.
Thus the output is exactly the required smallest triangle. ∎

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    # neighbours[i] is a bitset (int) of vertices adjacent to i (0‑based)
    neighbours = [0] * n
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        neighbours[u] |= 1 << v
        neighbours[v] |= 1 << u

    for a in range(n):
        na = neighbours[a]
        for b in range(a + 1, n):
            # check edge a–b
            if (na >> b) & 1:
                common = na & neighbours[b]          # vertices adjacent to both
                # keep only vertices > b
                mask = common >> (b + 1)
                if mask:
                    low = mask & -mask               # lowest set bit
                    idx = low.bit_length() - 1      # position inside mask
                    c = b + 1 + idx
                    # output 1‑based indices
                    sys.stdout.write(f"{a+1} {b+1} {c+1}")
                    return

if __name__ == "__main__":
    solve()
```
