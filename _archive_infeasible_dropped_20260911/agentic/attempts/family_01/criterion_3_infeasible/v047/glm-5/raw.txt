Looking at this problem, I need to find a triangle (3-clique) in an undirected graph, and output the lexicographically smallest one.

**Key Insight:** For the lexicographically smallest triangle, I iterate through all possible first vertices `a` from 1 to n. For each `a`, I look at its neighbors with ID > a. Among those neighbors, I need to find two vertices `b < c` that are connected by an edge. To find the lexicographically smallest `(b, c)` pair, I iterate `b` from smallest to largest, and for each `b`, find the smallest `c > b` that is both a neighbor of `a` and a neighbor of `b`.

**Efficiency consideration:** Using sets for adjacency lists gives O(1) lookups. The worst case could be expensive, but with n ≤ 2000 and m ≤ 2×10⁵, and the early termination when we find the first valid triangle, this approach is efficient enough. The key optimization is that we stop as soon as we find the first valid `a` (since we iterate `a` from 1 upward, the first found is lexicographically smallest), and within each `a`, we stop at the first valid `b`, and within each `b`, we take the minimum valid `c`.

```python
import sys

def main():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        neighbors_a = sorted(x for x in adj[a] if x > a)
        for b in neighbors_a:
            adj_b = adj[b]
            min_c = n + 1
            for c in neighbors_a:
                if c > b and c in adj_b:
                    if c < min_c:
                        min_c = c
            if min_c <= n:
                print(f"{a} {b} {min_c}")
                return
    
    # Should not reach here per problem guarantee
    print("-1 -1 -1")

main()
```
