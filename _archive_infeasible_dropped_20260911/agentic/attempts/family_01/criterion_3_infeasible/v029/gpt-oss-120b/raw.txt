**Solution Explanation**

For every particle `v` we store the set of its neighbours as a bitset  
(`int` in Python).  
Bit `i‑1` (0‑based) is `1` iff particle `i` is entangled with `v`.

```
adj[v]  – integer, bit i‑1 = 1  ⇔  (v , i) is an edge
```

A triangle `a < b < c` exists iff

```
edge (a,b)   and   edge (a,c)   and   edge (b,c)
```

For a fixed ordered pair `(a,b)` (`a<b` and the edge exists) the vertices
that are adjacent to **both** `a` and `b` are exactly the bits of

```
common = adj[a] & adj[b]
```

We only need vertices larger than `b`, therefore we mask away the lower
bits:

```
mask   = ~((1 << b) - 1)          # bits b … n‑1 are 1
cands  = common & mask
```

If `cands` is non‑zero, the least set bit gives the smallest possible `c`
(because bits correspond to increasing vertex numbers).  
The first triangle we meet while iterating `a` from `1` to `n` and,
inside it, `b` from the neighbours of `a` larger than `a`, is exactly the
lexicographically smallest one.

`n ≤ 2000`, therefore a bitset fits easily into a Python integer
(about 250 bytes).  
All operations on a bitset are O(1) word operations, so the total
complexity is

```
O( Σ degree(a) ) = O(m)          (one bit‑and per edge)
```

which easily satisfies the limits.

--------------------------------------------------------------------

#### Algorithm
```
read n, m
adj[1…n] = 0
neigh[1…n] = empty list

for each edge (u,v):
        if u > v: swap so u < v
        set bit v-1 in adj[u] , bit u-1 in adj[v]
        add v to neigh[u] , u to neigh[v]

for a = 1 … n:
        for each b in neigh[a] with b > a (neigh[a] is sorted):
                common = adj[a] & adj[b]
                mask   = ~((1 << b) - 1)          # keep bits > b
                cands  = common & mask
                if cands != 0:
                        # lowest set bit → smallest c
                        low = cands & -cands
                        c = low.bit_length()          # 1‑based index
                        output a, b, c
                        exit
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest
triangle.

---

**Lemma 1**  
For any vertices `a<b`, `cands = (adj[a] & adj[b]) & mask` contains exactly
the vertices `c` such that `c>b` and edges `(a,c)` and `(b,c)` exist.

*Proof.*  
`adj[a] & adj[b]` has a `1` at position `c-1` iff both edges `(a,c)` and
`(b,c)` are present.  
`mask` has `1`s only at positions `≥ b`.  
Therefore the conjunction keeps precisely those `c` with `c>b` that are
adjacent to both `a` and `b`. ∎



**Lemma 2**  
If `cands` is non‑zero, `c = low.bit_length()` (where `low = cands & -cands`)
is the smallest vertex `c` satisfying the triangle condition with the
current `a,b`.

*Proof.*  
`low` isolates the least significant set bit of `cands`, i.e. the smallest
index `c-1`. `bit_length()` returns that index + 1, i.e. the vertex number.
By Lemma&nbsp;1 every set bit corresponds to a valid `c`, thus the least
significant one gives the smallest such `c`. ∎



**Lemma 3**  
When the algorithm prints a triple `(a,b,c)`, it is a triangle
(`a<b<c` and all three edges exist).

*Proof.*  
`a<b` by the outer loops.  
`b` is taken from `neigh[a]`, therefore edge `(a,b)` exists.  
`c` is obtained from `cands`, which by Lemma&nbsp;1 guarantees `c>b` and
edges `(a,c)` and `(b,c)`. ∎



**Lemma 4**  
Let `T` be the lexicographically smallest triangle in the graph.
The algorithm will encounter `T` and output it.

*Proof.*  
Consider the ordered pair `(a,b)` of `T`.  
When the outer loop reaches this `a`, the inner loop iterates over all
neighbours `b' > a` in increasing order, so it will process exactly this
`b`.  
At that moment `cands` contains `c` (Lemma&nbsp;1), therefore it is
non‑empty and the algorithm will output the triangle `(a,b,c)` (Lemma 2).
Since all earlier `(a',b')` are lexicographically smaller than `(a,b)`,
they cannot form a triangle (otherwise `T` would not be minimal). Hence
the first printed triangle is exactly `T`. ∎



**Theorem**  
The algorithm outputs the lexicographically smallest resonance triad
(triangle) of the given graph.

*Proof.*  
By Lemma 3 any printed triple is a triangle.  
By Lemma 4 the first printed triangle is the lexicographically smallest
one, and the algorithm terminates immediately after printing it.
Thus the output satisfies the specification. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building structures* : `O(m)`  
*Main loops* : each edge `(a,b)` with `a<b` is examined once, performing a
constant‑time bit‑and and a few integer operations → `O(m)`  

Memory: `adj` stores `n` integers of at most `n` bits → `O(n)` bits,
i.e. ≤ 2000 · 2000 ≈ 4 Mbit ≈ 0.5 MiB, well inside the limit.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * (n + 1)          # 1‑based
    neigh = [[] for _ in range(n + 1)]

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        if u > v:
            u, v = v, u
        # set bits
        adj[u] |= 1 << (v - 1)
        adj[v] |= 1 << (u - 1)
        neigh[u].append(v)
        neigh[v].append(u)

    # sort neighbour lists for deterministic order
    for lst in neigh:
        lst.sort()

    for a in range(1, n + 1):
        for b in neigh[a]:
            if b <= a:
                continue
            common = adj[a] & adj[b]
            # keep only vertices > b
            mask = ~((1 << b) - 1)
            cands = common & mask
            if cands:
                low = cands & -cands
                c = low.bit_length()          # 1‑based index
                sys.stdout.write(f"{a} {b} {c}")
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input‑output format.
