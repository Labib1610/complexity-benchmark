**Solution Explanation**

For every worker we know the workers he/she is incompatible with.
The incompatibility relation is an undirected simple graph `G`.
We are guaranteed that `G` contains at least one triangle (3‑clique).
We have to output the *lexicographically smallest* triangle  
`a < b < c` – i.e. smallest `a`, then smallest `b`, then smallest `c`.

`n ≤ 2000`, therefore a whole adjacency matrix fits into a 2000‑bit
bitset.  
Bit operations on a 2000‑bit integer are performed on about `2000/64 = 32`
machine words – extremely fast.

--------------------------------------------------------------------

#### 1.   Data structures

* `bits[v]` – Python `int` whose binary representation has a `1` at
  position `u‑1` (`0`‑based) iff `{v,u}` is an edge.
* `adj[v]` – sorted list of neighbours of `v` (only needed for the outer
  loops).

--------------------------------------------------------------------

#### 2.   Finding the smallest triangle

We iterate vertices in increasing order.

```
for a = 1 .. n
    for each neighbour b of a with b > a   (adj[a] is sorted)
        common = bits[a] & bits[b]          # vertices adjacent to both
        # we need a vertex c > b
        mask   = all_bits ^ ((1 << b) - 1)   # bits with index >= b
        cand   = common & mask
        if cand != 0:
            c = position of lowest set bit in cand   # smallest possible c
            output a, b, c
```

* `all_bits = (1 << n) - 1` – `n` low bits are `1`.
* `((1 << b) - 1)` has `1` in positions `0 … b‑1`.  
  XOR with `all_bits` clears them, leaving only positions `b … n‑1`,
  i.e. vertices `> b`.
* `cand & -cand` isolates the lowest set bit; its 1‑based index is the
  required `c`.

Because the outer loops walk `a` then `b` in increasing order and we
pick the smallest possible `c`, the first triangle we encounter is
exactly the lexicographically smallest one.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest
triangle.

---

##### Lemma 1  
For fixed vertices `a < b`, `cand` (as defined above) contains exactly
the vertices `c` such that `{a,c}` and `{b,c}` are edges and `c > b`.

**Proof.**  
`common = bits[a] & bits[b]` has a `1` at position `c‑1` iff both edges
`a‑c` and `b‑c` exist.  
`mask` has `1` at positions `c‑1` iff `c > b`.  
Intersection `common & mask` therefore has a `1` exactly for those
`c` satisfying both conditions. ∎



##### Lemma 2  
If `cand ≠ 0`, the vertex `c` obtained from the lowest set bit of `cand`
is the smallest vertex `> b` that together with `a,b` forms a triangle.

**Proof.**  
By Lemma&nbsp;1, `cand` contains precisely the admissible vertices.
The lowest set bit corresponds to the smallest index among them,
hence the smallest such `c`. ∎



##### Lemma 3  
When the algorithm prints a triple `(a,b,c)`, it is a triangle
(`a<b<c` and all three edges exist).

**Proof.**  
`b` is taken from `adj[a]`, therefore edge `a‑b` exists and `b>a`.  
`c` is obtained only if `cand ≠ 0`; by Lemma&nbsp;1 this implies edges
`a‑c` and `b‑c` exist and `c>b`. ∎



##### Lemma 4  
Let `T = (a₀,b₀,c₀)` be the first triangle output by the algorithm.
For any triangle `T' = (a',b',c')` we have
`a₀ ≤ a'`. If `a₀ = a'` then `b₀ ≤ b'`. If also `b₀ = b'` then `c₀ ≤ c'`.

**Proof.**  
The outermost loop enumerates `a` increasingly; the inner loop enumerates
`b` increasingly for the current `a`.  
Thus the algorithm examines all candidate pairs `(a,b)` in lexicographic
order.  
The first time a pair `(a,b)` yields a non‑empty `cand`, the algorithm
outputs the smallest possible `c` for this pair (Lemma&nbsp;2) and stops.
Consequently no earlier pair `(a',b')` (lexicographically smaller) can
produce a triangle, otherwise the algorithm would have stopped earlier.
Hence the printed triangle is lexicographically minimal. ∎



##### Theorem  
The algorithm always outputs the lexicographically smallest triangle
in the given graph.

**Proof.**  
Existence of at least one triangle guarantees the algorithm will find
`cand ≠ 0` for some pair and therefore output a triple.
By Lemma&nbsp;3 the output is a triangle.
By Lemma&nbsp;4 it is lexicographically minimal among all triangles. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building the bitsets* – `O(m)` operations.  

*Main loops* – for each edge `{a,b}` with `a<b` we perform one bitwise
`&` on two `n`‑bit integers (`≈ n/word = 32` machine words) and a few
constant‑time integer operations.

```
time ≤  O(m * (n / word))   ≤ 2·10⁵ * 32  < 7·10⁶   operations
```

Well inside the 2 s limit.

Memory:

* `bits` – `n` integers, each ≤ 2ⁿ, i.e. about `n * n / 8` bytes  
  (`2000 * 2000 / 8 ≈ 0.5 MiB`).
* adjacency lists – `O(m)` integers.

Total far below 256 MiB.

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    bits = [0] * (n + 1)          # 1‑based
    adj = [[] for _ in range(n + 1)]

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        if u == v:
            continue
        bits[u] |= 1 << (v - 1)
        bits[v] |= 1 << (u - 1)
        if u < v:
            adj[u].append(v)
            adj[v].append(u)
        else:
            adj[v].append(u)
            adj[u].append(v)

    # sort neighbour lists for deterministic order
    for lst in adj:
        lst.sort()

    all_bits = (1 << n) - 1

    for a in range(1, n + 1):
        ba = bits[a]
        for b in adj[a]:
            if b <= a:
                continue
            common = ba & bits[b]
            # keep only vertices with index > b (i.e. position >= b)
            mask = all_bits ^ ((1 << b) - 1)
            cand = common & mask
            if cand:
                # lowest set bit
                low = cand & -cand
                c = low.bit_length()          # 1‑based vertex number
                # a < b < c holds by construction
                sys.stdout.write(f"{a} {b} {c}")
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
