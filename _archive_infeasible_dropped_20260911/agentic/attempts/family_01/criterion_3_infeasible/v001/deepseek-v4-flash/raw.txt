 We need to find a triangle in an undirected graph. The graph is given by edges, and we need the lexicographically smallest triangle (a < b < c).  
We can do this by iterating over vertices in increasing order and checking their neighbors for a common connection.

Here’s the implementation:

```python
n, m = map(int, input().split())
adj = [set() for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].add(v)
    adj[v].add(u)

for a in range(n):
    for b in sorted(adj[a]):
        if b > a:
            for c in sorted(adj[b]):
                if c > b and c in adj[a]:
                    print(a + 1, b + 1, c + 1)
                    exit()
```
