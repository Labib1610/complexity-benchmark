**Solution Explanation**

For every employee we know the list of employees that cannot work together with him.
The incompatibility graph is undirected.
We have to output the lexicographically smallest triangle  
`a < b < c` such that all three edges `{a,b}`, `{a,c}`, `{b,c}` exist.

`n ≤ 2000`, therefore a *bitset* of length `n` fits into a Python integer
(`2000` bits ≈ `250` bytes).  
With bitsets the intersection of two neighbour sets is a single `&`
operation.

--------------------------------------------------------------------

#### Data structures

* `adj_int[v]` – integer whose `i`‑th bit (`i = 0 … n‑1`) is `1`
  iff vertex `v` (1‑based) is adjacent to vertex `i+1`.
* `adj_list[v]` – sorted list of neighbours of `v` (only vertices `> v`
  are needed later, but sorting once is cheap).

--------------------------------------------------------------------

#### Algorithm
```
read n, m
initialise adj_int[1…n] = 0
for each edge (u, v):
        if u > v: swap
        set bit (v-1) in adj_int[u]
        set bit (u-1) in adj_int[v]
        store v in adj_list[u] , u in adj_list[v]

for a = 1 … n:
        sort adj_list[a]                     # once, O(m log m) total
        for each b in adj_list[a] with b > a (list already sorted):
                # vertices that are neighbours of both a and b
                common = adj_int[a] & adj_int[b]

                # keep only vertices c with c > b
                mask = ((1 << n) - 1) ^ ((1 << b) - 1)   # bits b … n-1 = 1
                common &= mask

                if common != 0:
                        # smallest c is the least significant set bit
                        low = common & -common
                        c = low.bit_length()            # 1‑based index
                        output a b c and terminate
```

The outer loops enumerate `(a,b)` in increasing order,
and for a fixed pair we take the smallest possible `c`.  
Consequently the first triangle found is exactly the lexicographically
smallest one.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest
triangle.

---

**Lemma 1**  
For any vertices `a < b`, after `common &= mask` the set represented by
`common` equals `{ c | c > b  and  {a,c} , {b,c} are edges }`.

*Proof.*  
`adj_int[a] & adj_int[b]` contains exactly the vertices adjacent to **both**
`a` and `b`.  
`mask` has bits `1` for indices `b … n-1` (i.e. vertices `c ≥ b+1`),
`0` otherwise.  
Bitwise `&` removes all vertices `c ≤ b`. ∎



**Lemma 2**  
If `common != 0` then `c = low.bit_length()` is the smallest vertex
`c > b` that together with `a,b` forms a triangle.

*Proof.*  
`low = common & -common` isolates the least significant set bit of
`common`, i.e. the smallest index present.  
`low.bit_length()` returns that index + 1, which is exactly the vertex
number. By Lemma&nbsp;1 every set bit corresponds to a vertex forming a
triangle with `a,b`; the least significant one is the smallest such
vertex. ∎



**Lemma 3**  
When the algorithm outputs a triple `(a,b,c)`, it is a triangle
(`a<b<c` and all three edges exist).

*Proof.*  
`b` is taken from `adj_list[a]`, therefore `{a,b}` is an edge and `a<b`.  
`c` is obtained from `common` which, by Lemma&nbsp;1, contains only vertices
adjacent to both `a` and `b` and larger than `b`. Hence `{a,c}` and `{b,c}`
are edges and `c>b`. ∎



**Lemma 4**  
Let `T` be the lexicographically smallest triangle in the graph.
The algorithm will output `T`.

*Proof.*  
Consider the enumeration order of pairs `(a,b)`:
`a` increases from `1` to `n`; for a fixed `a`, `b` increases over the
sorted neighbour list, i.e. in increasing order.
Thus the first pair `(a,b)` that belongs to any triangle is exactly the
pair `(a_T, b_T)` of triangle `T` (otherwise a triangle with a smaller
`a` or same `a` and smaller `b` would exist, contradicting minimality of
`T`).  

When processing this pair, Lemma&nbsp;1 guarantees that `common` contains
all possible `c` completing a triangle, and Lemma&nbsp;2 selects the
smallest such `c`, which is `c_T`. Therefore the algorithm outputs
`(a_T, b_T, c_T) = T`. ∎



**Theorem**  
The algorithm always terminates and prints the lexicographically smallest
triangle of the given graph.

*Proof.*  
The graph is guaranteed to contain at least one triangle, so some pair
`(a,b)` will have `common != 0`. The loops eventually reach that pair,
hence the algorithm terminates. By Lemma&nbsp;3 the printed triple is a
triangle, and by Lemma&nbsp;4 it is the lexicographically smallest one. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency*: `O(m)` time, `O(n)` integers (≈ 2000·250 B).

*Sorting neighbour lists*: total `O(m log n)` (with `n ≤ 2000` this is tiny).

*Main loops*: each edge `(a,b)` is examined once.
For each edge we perform a constant‑time bitwise `&` on integers of size
`n ≤ 2000` bits → `O(1)` in Python (the operation works on machine words).
Thus `O(m)` time.

Overall  

*Time*: `O(m log n)` ≤ `O(2·10⁵·log 2000)` well below the limit.  
*Memory*: `O(n + m)` ≤ a few MB.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj_int = [0] * (n + 1)          # 1‑based
    adj_list = [[] for _ in range(n + 1)]

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        if u > v:
            u, v = v, u
        # set bits
        adj_int[u] |= 1 << (v - 1)
        adj_int[v] |= 1 << (u - 1)
        adj_list[u].append(v)
        adj_list[v].append(u)

    full_mask = (1 << n) - 1

    for a in range(1, n + 1):
        adj_list[a].sort()
        for b in adj_list[a]:
            if b <= a:
                continue
            common = adj_int[a] & adj_int[b]
            # keep only vertices > b
            mask = full_mask ^ ((1 << b) - 1)   # bits b .. n-1 are 1
            common &= mask
            if common:
                low = common & -common
                c = low.bit_length()            # 1‑based
                sys.stdout.write(f"{a} {b} {c}")
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input‑output format.
