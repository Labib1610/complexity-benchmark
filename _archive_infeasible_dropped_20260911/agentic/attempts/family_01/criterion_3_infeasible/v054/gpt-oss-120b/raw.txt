**Solution Explanation**

For every pair of employees we know whether they are incompatible.
A *deadlock subset of size three* is exactly a triangle in the undirected
graph formed by the incompatibilities.

We have to output the lexicographically smallest triangle  
`a < b < c` – i.e. the smallest possible `a`, then `b`, then `c`.

`n ≤ 2000`, `m ≤ 2·10⁵`.  
`n` is small enough to keep an adjacency matrix, but a plain
`n × n` list of booleans would be too slow for the inner loops.
Instead we store each row as a bitset inside a Python `int`.
Bit `i` (0‑based) of `adj[u]` is `1` iff the edge `u – (i+1)` exists.

With bitsets we can intersect two neighbour sets in O(1) time
(the operation is a single integer `&`).

--------------------------------------------------------------------

#### Algorithm
```
read n, m
adj[1…n] = 0                     # integer bitsets, 0‑based bits
edges = []                       # list of (u,v) with u < v

for each input edge (x, y):
        if x > y: swap
        set bit (y-1) in adj[x]
        set bit (x-1) in adj[y]
        edges.append( (x, y) )   # keep u < v for later enumeration

# enumerate triangles in lexicographic order
for a = 1 … n:
        # neighbours of a that are larger than a, sorted increasingly
        for each b in neighbours_of_a where b > a (taken from edges):
                # common neighbours of a and b
                common = adj[a] & adj[b]

                # we need only vertices > b
                # delete bits 0 … b (inclusive)
                common >>= (b)          # now bit 0 corresponds to vertex b+1
                if common == 0: continue

                # smallest set bit gives the smallest possible c
                low = common & -common          # isolate lowest 1‑bit
                c = (low.bit_length() - 1) + b + 1   # convert back to vertex number

                output a, b, c (already a<b<c) and finish
```

The outer loop runs `a = 1 … n`.  
For a fixed `a` we look at its neighbours `b` with `b > a` in increasing
order because the edges were stored that way.
The first triangle we encounter is therefore the lexicographically
smallest one.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
triangle.

---

**Lemma 1**  
For any vertices `u < v`, after `common = adj[u] & adj[v]` and
`common >>= v`, the set bits of `common` correspond precisely to the vertices
`w` such that `w > v` and edges `u–w` and `v–w` both exist.

*Proof.*  
`adj[u]` has a 1‑bit at position `w-1` iff edge `u–w` exists.
Similarly for `adj[v]`.  
The bitwise `&` keeps a 1‑bit exactly when both edges exist.
Shifting right by `v` discards bits `0 … v-1`, i.e. vertices `≤ v`.
Thus remaining bits correspond exactly to vertices `w > v` adjacent to
both `u` and `v`. ∎



**Lemma 2**  
If `common` after the shift is non‑zero, the vertex `c` computed as  

```
low = common & -common
c = (low.bit_length() - 1) + v + 1
```

is the smallest vertex `w > v` that together with `u` and `v` forms a
triangle.

*Proof.*  
`common & -common` isolates the least significant 1‑bit of `common`,
i.e. the smallest index `i` with a set bit.
`i = low.bit_length() - 1`.  
Because of Lemma&nbsp;1, this index corresponds to vertex `w = i + v + 1`,
the smallest vertex `> v` adjacent to both `u` and `v`. ∎



**Lemma 3**  
When the algorithm prints a triple `(a,b,c)`, it is a triangle
(`a<b<c` and all three edges exist).

*Proof.*  
`b` is taken from the neighbour list of `a`, therefore edge `a–b` exists.
`c` is obtained from Lemma&nbsp;2, guaranteeing edges `a–c` and `b–c`.
The construction ensures `a<b<c`. ∎



**Lemma 4**  
The algorithm examines candidate triples in strict lexicographic order.

*Proof.*  
The outer loop iterates `a = 1,2,…`.  
For a fixed `a`, the inner loop iterates over neighbours `b` with `b>a`
in increasing order (edges were stored with `u<v`).  
For each pair `(a,b)` the algorithm chooses the smallest possible `c`
(Lemma&nbsp;2).  
Thus the sequence of examined triples is exactly the lexicographic order
on `(a,b,c)`. ∎



**Theorem**  
The algorithm outputs the lexicographically smallest triangle of the graph.

*Proof.*  
By Lemma&nbsp;3 any printed triple is a triangle.
By Lemma&nbsp;4 the first triangle encountered during the enumeration is the
lexicographically smallest one.
The algorithm stops immediately after printing the first triangle,
hence the output is exactly that smallest triangle. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building the adjacency bitsets*: `O(m)` time, `O(n)` integers  
(`n ≤ 2000`, each integer holds ≤ 2000 bits).

*Enumeration*:
- Outer loop runs `n` times.
- For each vertex `a` we iterate over its neighbours `b>a`.  
  The total number of such ordered pairs is exactly the number of edges,
  i.e. `m`.
- For each pair we perform a constant‑time bitwise `&`, a shift and a few
  integer operations.

Hence total time `O(m) ≤ 2·10⁵`, well within the limit.
Memory consumption: `n` integers ≈ `n·2000/8` bytes ≈ 0.5 MiB,
plus the edge list – far below 256 MiB.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * (n + 1)          # 1‑based, bits 0..n-1
    edges = []                   # store (u,v) with u < v

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        if u > v:
            u, v = v, u
        # set bits
        adj[u] |= 1 << (v - 1)
        adj[v] |= 1 << (u - 1)
        edges.append((u, v))

    # Build neighbour lists for fast iteration of b > a
    neigh = [[] for _ in range(n + 1)]
    for u, v in edges:
        neigh[u].append(v)   # v > u by construction

    for a in range(1, n + 1):
        for b in neigh[a]:          # b > a, already increasing
            common = adj[a] & adj[b]
            # discard vertices <= b
            common >>= b
            if common == 0:
                continue
            low = common & -common
            c = (low.bit_length() - 1) + b + 1
            # a < b < c holds
            sys.stdout.write(f"{a} {b} {c}")
            return

if __name__ == "__main__":
    solve()
```
