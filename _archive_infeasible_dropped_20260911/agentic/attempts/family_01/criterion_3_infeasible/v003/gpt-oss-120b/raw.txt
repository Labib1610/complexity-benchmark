**Solution Explanation**

For every pair of workers we know whether they *cannot* work together.
The required group of three workers is exactly a **triangle** in this
undirected graph:

```
a – b
|  /
c
```

We have to output the lexicographically smallest triangle  
`a < b < c`.

`n ≤ 2000`, therefore a bitset of length `n` fits into a Python integer
(2000 bits ≈ 250 bytes).  
With bitsets the intersection of two neighbour sets is a single
`&` operation.



--------------------------------------------------------------------

#### Data structures

* `adj_int[i]` – Python `int` whose binary representation has bit `j`
  set (`1`) iff there is an edge `i – j`.  
  Bits are 1‑based, i.e. bit `k` corresponds to vertex `k`.

* `has_edge[i][j]` – `True` iff edge `i – j` exists.
  Implemented as a list of `bytearray`s (`n+1` × `n+1`), O(1) test.

Both structures are built while reading the input.

--------------------------------------------------------------------

#### Finding the smallest triangle

We iterate vertices in increasing order, guaranteeing the lexicographic
order automatically.

```
for a = 1 .. n:
    for b = a+1 .. n:
        if not edge a‑b: continue
        common = adj_int[a] & adj_int[b]          # neighbours of both
        # we need c > b, therefore delete bits ≤ b
        mask = ~((1 << (b+1)) - 1)                # bits b+1 .. n are 1
        common &= mask
        if common != 0:
            c = (common & -common).bit_length() - 1   # lowest set bit
            output a b c
            return
```

* `common & -common` isolates the lowest set bit.
* `bit_length()` returns index of the highest set bit + 1,
  therefore `-1` gives the vertex number.

The first triple found is the lexicographically smallest one,
because the outer loops increase `a` first, then `b`, and we always pick
the smallest possible `c`.

Complexities  

*building* – `O(m)`  
*search* – at most `O(n²)` iterations, each does only a few integer
operations → well below the limits (`n = 2000` → 2 M iterations).

Memory – `adj_int` (≈ 2000 · 250 B) + `has_edge` (≈ 4 MB) → < 10 MB.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
triangle.

---

**Lemma 1**  
For any vertices `a` and `b` the expression  
`adj_int[a] & adj_int[b]` has a bit `c` set **iff** edges `a‑c` and `b‑c`
both exist.

*Proof.* By definition `adj_int[x]` contains exactly the neighbours of `x`.
Intersection keeps a bit only when it is present in both sets, i.e. when
both edges exist. ∎



**Lemma 2**  
After masking with `mask = ~((1 << (b+1)) - 1)` all bits `≤ b` are cleared
and bits `> b` stay unchanged.

*Proof.* `(1 << (b+1)) - 1` is a number whose lower `b+1` bits are `1`.
Negating it flips those bits to `0` and all higher bits to `1`. ∎



**Lemma 3**  
If after masking `common != 0`, the vertex `c` obtained by  
`c = (common & -common).bit_length() - 1` is the smallest vertex
`c > b` that together with `a,b` forms a triangle.

*Proof.* `common & -common` isolates the least significant `1` bit,
i.e. the smallest index still set. `bit_length()-1` converts that bit
position to the vertex number. By Lemma&nbsp;1 the bit is set only for a
common neighbour, and by Lemma&nbsp;2 all remaining bits correspond to
vertices `> b`. Hence `c` is the smallest such vertex. ∎



**Lemma 4**  
When the algorithm prints a triple `(a,b,c)`, it is a triangle and
satisfies `a < b < c`.

*Proof.* The loops enforce `a < b`. The edge test guarantees `a‑b`
exists. By Lemma&nbsp;3 the found `c` is a common neighbour of `a` and `b`,
so edges `a‑c` and `b‑c` exist (Lemma&nbsp;1). The mask guarantees `c > b`. ∎



**Lemma 5**  
If a triangle exists, the algorithm will eventually print one.

*Proof.* Consider the lexicographically smallest triangle
`(a*,b*,c*)`. The outer loops will reach `a = a*` and then `b = b*`
because they enumerate all pairs with `a < b`. Since `a*‑b*` is an edge,
the algorithm proceeds to compute `common`. `c*` is a common neighbour,
so after masking (which does not delete `c*` because `c* > b*`) the bit
for `c*` remains set, thus `common != 0`. Consequently the algorithm
outputs a triangle (maybe with an even smaller `c`, but that would be
lexicographically smaller, contradicting minimality of `(a*,b*,c*)`).
Hence it certainly outputs some triangle. ∎



**Lemma 6**  
The first triangle output by the algorithm is the lexicographically
smallest triangle of the graph.

*Proof.* Suppose the algorithm outputs `(a,b,c)`. By construction all
pairs `(a',b')` with `a' < a` or (`a' = a` and `b' < b`) have been examined
and none produced a triangle, otherwise the algorithm would have stopped
earlier. Therefore no triangle has a smaller first element than `a`,
and none has the same `a` with a smaller second element than `b`.  
For this fixed `(a,b)` the algorithm chooses the smallest possible `c`
(Lemma&nbsp;3). Hence no triangle is lexicographically smaller. ∎



**Theorem**  
The algorithm always terminates and prints the lexicographically smallest
triple of workers that are pairwise incompatible.

*Proof.* Termination follows from the finite double loop. Existence of a
triangle is guaranteed by the problem statement, and Lemma&nbsp;5 ensures
the algorithm finds one. By Lemma&nbsp;4 the printed triple is a valid
triangle, and Lemma&nbsp;6 shows it is the lexicographically smallest
such triangle. ∎

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    # adjacency bitsets, 1‑based
    adj_int = [0] * (n + 1)
    # edge existence matrix for O(1) test
    has_edge = [bytearray(n + 1) for _ in range(n + 1)]

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        if u > v:
            u, v = v, u
        # set bits
        adj_int[u] |= 1 << v
        adj_int[v] |= 1 << u
        has_edge[u][v] = 1
        has_edge[v][u] = 1

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if not has_edge[a][b]:
                continue
            common = adj_int[a] & adj_int[b]
            # keep only vertices > b
            mask = ~((1 << (b + 1)) - 1)
            common &= mask
            if common:
                # lowest set bit -> smallest c
                low = common & -common
                c = low.bit_length() - 1
                sys.stdout.write(f"{a} {b} {c}")
                return

if __name__ == "__main__":
    solve()
```

and conforms to the required input‑output format.
