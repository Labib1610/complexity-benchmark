We can solve this by checking each possible triple in increasing order and stopping at the first valid one.  
Since \(n \le 2000\), checking all triples naively would be \(O(n^3)\), which is too slow.  
Instead, we can use an adjacency set for \(O(1)\) edge lookups and iterate over edges to find a triangle efficiently.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
        edges.append((u, v))
    
    # Try to find a triangle
    for u in range(1, n + 1):
        for v in adj[u]:
            if v > u:
                common = adj[u] & adj[v]
                if common:
                    w = min(common)
                    a, b, c = sorted([u, v, w])
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
