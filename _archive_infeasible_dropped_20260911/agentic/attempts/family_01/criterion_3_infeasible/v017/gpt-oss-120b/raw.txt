**Solution Explanation**

For every pair of access points we know whether they interfere.
We have to output a triple `a < b < c` such that all three pairs
`(a,b) , (a,c) , (b,c)` interfere – i.e. a *triangle* in the undirected graph.
If several triangles exist we need the lexicographically smallest one:
first minimise `a`, then `b`, then `c`.

`n ≤ 2000`, therefore an `O(n²)` algorithm is easily fast enough.
The only difficulty is to test quickly whether a third vertex `c`
is adjacent to both `a` and `b`.

--------------------------------------------------------------------

#### 1.   Bitset representation  

For every vertex `v` we store the set of its neighbours as a bitset
inside a Python integer:

```
adj[v]  – integer, bit i (1‑based) is 1  ⇔  edge (v,i) exists
```

Setting a bit: `adj[u] |= 1 << v` .  
Testing an edge `(u,v)`: `(adj[u] >> v) & 1`.

The bitwise **AND** of two such integers gives the common neighbours of the
two vertices.

--------------------------------------------------------------------

#### 2.   Searching the smallest triangle  

We enumerate the first two vertices in increasing order:

```
for a = 1 … n
    for b = a+1 … n
        if (a,b) is not an edge: continue
        common = adj[a] & adj[b]          # neighbours of both a and b
        common >>= b                     # delete vertices ≤ b
        if common != 0:
               # the least set bit is the smallest possible c
               lsb = common & -common
               pos = lsb.bit_length() - 1      # 0‑based position after the shift
               c = b + 1 + pos
               output a b c and finish
```

*Why does this give the required ordering?*

* The outer loops increase `a` first, then `b`.  
  The first pair `(a,b)` that can be completed to a triangle is therefore
  the one with the smallest possible `a`, and among those the smallest `b`.

* After fixing `a,b` we look only at vertices `c > b`
  (`common >>= b`).  
  The least set bit of the remaining mask is the smallest feasible `c`.

Thus the first triangle we encounter is exactly the lexicographically
smallest one.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs the required triple.

---

##### Lemma 1  
For any vertices `a < b`, after the statement  
`common = adj[a] & adj[b];  common >>= b`  
the set bits of `common` correspond precisely to vertices `c` such that  

* `c > b`,
* edges `(a,c)` and `(b,c)` exist.

**Proof.**  
`adj[a] & adj[b]` contains exactly the vertices adjacent to **both** `a` and `b`.  
Shifting right by `b` discards the lowest `b` bits, i.e. all vertices
`≤ b`. The remaining bits keep their relative order, now representing vertices
`b+1, b+2, …`. ∎



##### Lemma 2  
If `common` (as defined above) is non‑zero, the vertex  

```
c = b + 1 + (lsb.bit_length() - 1)
```

is the smallest vertex `c > b` that together with `a,b` forms a triangle.

**Proof.**  
`lsb = common & -common` isolates the least significant set bit of `common`,
i.e. the smallest index after the shift.
Its position `pos = lsb.bit_length() - 1` is the number of zero bits
to its right, therefore the vertex represented is `b+1+pos`.  
By Lemma&nbsp;1 this vertex is adjacent to both `a` and `b`,
and any smaller vertex `> b` would correspond to a set bit left of `lsb`,
which does not exist. ∎



##### Lemma 3  
When the algorithm prints a triple `(a,b,c)`, it is a triangle
(`a<b<c` and all three edges exist).

**Proof.**  
`b` is chosen only if edge `(a,b)` exists (explicit test).  
`c` is obtained from a non‑zero `common`, therefore by Lemma&nbsp;1
edges `(a,c)` and `(b,c)` exist, and `c>b`. ∎



##### Lemma 4  
Let `T* = (a*,b*,c*)` be the lexicographically smallest triangle
in the whole graph.  
The algorithm will output exactly `T*`.

**Proof.**  
Consider the outer loops. They enumerate all ordered pairs `(a,b)` with
`a<b` in lexicographic order.
The first pair for which `common` is non‑empty is `(a*,b*)`:

* For any pair `(a,b)` with `a<a*` there is **no** vertex `c` forming a
  triangle, otherwise `(a,b,c)` would be lexicographically smaller than `T*`.
* For `a = a*` and `b < b*` the same holds, otherwise we would have a triangle
  `(a*,b,c)` with `b<b*`.

Thus the algorithm reaches `(a*,b*)` before any pair that can be completed
to a triangle.

At this pair `common` is non‑empty (because `c*` is a common neighbour),
and by Lemma&nbsp;2 the algorithm selects the smallest possible `c`,
which is exactly `c*`. ∎



##### Theorem  
The algorithm always terminates and prints the three vertex IDs of the
lexicographically smallest triangle of the given graph.

**Proof.**  
The graph contains at least one triangle, so some pair `(a,b)` will have
`common ≠ 0`. The double loop scans a finite number of pairs, therefore the
algorithm reaches such a pair and terminates.  
By Lemma&nbsp;3 the printed triple is a triangle.
By Lemma&nbsp;4 it is the lexicographically smallest one. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building the bitsets* : `O(m)` operations.  
*Main loops* : at most `n·(n-1)/2 ≤ 2·10⁶` iterations, each doing only a few
bitwise operations → `O(n²)` time.  

Memory: one integer per vertex, i.e. `O(n)` bits ≈ `2000·2000 / 8 ≈ 0.5 MiB`,
well inside the limit.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    # adjacency as bitsets, 1‑based indexing
    adj = [0] * (n + 1)
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u] |= 1 << v
        adj[v] |= 1 << u

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            # edge (a,b) ?
            if ((adj[a] >> b) & 1) == 0:
                continue
            common = adj[a] & adj[b]
            # keep only vertices > b
            common >>= b
            if common:
                lsb = common & -common          # lowest set bit
                pos = lsb.bit_length() - 1     # position after the shift
                c = b + 1 + pos
                sys.stdout.write(f"{a} {b} {c}")
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
