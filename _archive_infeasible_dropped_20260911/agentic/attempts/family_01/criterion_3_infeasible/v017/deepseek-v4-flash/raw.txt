We need to find a triangle (3 mutually connected nodes) with the lexicographically smallest sorted triple.  
Since n can be up to 2000 and m up to 2e5, we can iterate over possible smallest node a, then second smallest b, and check for a common neighbor c > b.  
We can store adjacency as sets for O(1) neighbor checks.  
We iterate a from 1 to n, b from a+1 to n, and if edge (a,b) exists, we look for the smallest c > b such that c is adjacent to both a and b.  
To make this efficient, we can precompute adjacency bitsets (Python integers) for each node. Then for each pair (a,b), we compute common = adj[a] & adj[b], and pick the smallest bit > b.  
Complexity: O(n^2) pair checks, each with bit operations on big integers (up to 2000 bits), which is fast enough.  
We stop at first found because iterating a,b in increasing order ensures lexicographically smallest.  

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    
    adj = [0] * (n + 1)
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u] |= 1 << v
        adj[v] |= 1 << u
    
    for a in range(1, n+1):
        for b in range(a+1, n+1):
            if (adj[a] >> b) & 1:
                common = adj[a] & adj[b]
                # remove bits <= b
                common &= ~((1 << (b+1)) - 1)
                if common:
                    # find lowest set bit
                    c = (common & -common).bit_length() - 1
                    # Actually: lowbit = common & -common; c = lowbit.bit_length() - 1
                    low = common & -common
                    c = low.bit_length() - 1
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
