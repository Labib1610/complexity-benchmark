**Solution Explanation**

For every tower `v` we store the set of its neighbours as a bit mask  
(`bit i` is set ⇔ tower `i+1` is adjacent to `v`).  
`n ≤ 2000`, therefore one Python integer (≈ 2000 bits) is enough.

A triangle `(a,b,c)` with `a<b<c` exists iff for some edge `a‑b`

```
c ∈ N(a) ∩ N(b)   and   c > b
```

`N(x)` – neighbour mask of `x`.

If we examine the vertices in increasing order

```
for a = 1 .. n
    for b = a+1 .. n   (only if edge a‑b exists)
        common = N(a) & N(b)
        keep only vertices > b
        if common ≠ 0 → the smallest set bit is the smallest possible c
```

the first triangle we meet is exactly the lexicographically smallest one,
because `a` grows first, then `b`, then the smallest possible `c`.

All operations on the masks are O(1) (bitwise `&`, `|`, shifts).  
The outer loops run over all edges, i.e. `O(m)`.  
`m ≤ 2·10⁵`, well inside the limits.



--------------------------------------------------------------------

#### Algorithm
```
read n, m
mask[1..n] = 0
edges = empty list

for each of the m lines (u, v):
        set bit (v-1) in mask[u]
        set bit (u-1) in mask[v]
        store (u, v) with u < v in edges

full_mask = (1 << n) - 1          # bits 0 … n-1 are 1

for a from 1 to n:
        for each b > a such that edge a‑b exists:
                common = mask[a] & mask[b]
                # keep only vertices with index > b
                keep = full_mask ^ ((1 << b) - 1)   # bits b … n-1 are 1
                cand = common & keep
                if cand != 0:
                        # lowest set bit = smallest c
                        low = cand & -cand
                        c_index = low.bit_length() - 1   # 0‑based
                        c = c_index + 1
                        output a, b, c
                        exit
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest triangle.

---

**Lemma 1**  
For any vertices `a<b`, `cand = (N(a) ∩ N(b)) ∩ {c | c>b}` contains exactly the
vertices `c` that together with `a,b` form a triangle and satisfy `c>b`.

*Proof.*  
`mask[a] & mask[b]` is the set `N(a) ∩ N(b)`.  
`keep` has bits `b … n-1` set and lower bits cleared, therefore
`common & keep` keeps precisely those vertices whose index is larger than `b`. ∎



**Lemma 2**  
If `cand ≠ 0` then `c = smallest index in cand` is the smallest possible
third vertex of a triangle with the current pair `(a,b)`.

*Proof.*  
`cand` is a set of integers larger than `b`. The operation
`cand & -cand` extracts the least significant 1‑bit, i.e. the smallest element.
Thus `c` is the minimal element of `cand`. ∎



**Lemma 3**  
When the algorithm prints `(a,b,c)`, the three edges
`a‑b`, `a‑c`, `b‑c` are present in the graph.

*Proof.*  
`a‑b` is an input edge (the inner loop iterates only over existing edges).  
By Lemma&nbsp;1, `c ∈ N(a) ∩ N(b)`, therefore edges `a‑c` and `b‑c` exist. ∎



**Lemma 4**  
Let `(a₀,b₀,c₀)` be the first triangle output by the algorithm.
For any triangle `(a,b,c)` with `a<b<c` we have
`a₀ ≤ a`. If `a₀ = a` then `b₀ ≤ b`. If also `b₀ = b` then `c₀ ≤ c`.

*Proof.*  
The outer loop enumerates `a` in increasing order.
The inner loop enumerates, for this `a`, all `b>a` that are neighbours,
also in increasing order.
Thus the algorithm examines all candidate pairs `(a,b)` in lexicographic order.
For a fixed pair it chooses the smallest possible `c` (Lemma&nbsp;2).
Consequently the first successful triple is lexicographically minimal. ∎



**Theorem**  
The algorithm outputs the lexicographically smallest triple
`a<b<c` such that all three edges exist.

*Proof.*  
By Lemma&nbsp;3 the printed triple is a triangle.
By Lemma&nbsp;4 no other triangle is lexicographically smaller.
Therefore the output satisfies the specification. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building masks*: `O(m)`  
*Main loops*: each edge `a‑b` is processed once → `O(m)` bit operations.  
All other work is `O(1)` per iteration.

```
Time   :  O(m)   ≤ 2·10⁵
Memory :  O(n)   (n integers, each ≤ 2ⁿ)
```

Both are well within the limits.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    masks = [0] * (n + 1)          # 1‑based
    adj = [set() for _ in range(n + 1)]

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        if u > v:
            u, v = v, u
        masks[u] |= 1 << (v - 1)
        masks[v] |= 1 << (u - 1)
        adj[u].add(v)
        adj[v].add(u)

    full_mask = (1 << n) - 1

    for a in range(1, n + 1):
        # neighbours larger than a
        for b in sorted(v for v in adj[a] if v > a):
            common = masks[a] & masks[b]
            # keep only vertices > b
            keep = full_mask ^ ((1 << b) - 1)   # bits b..n-1 are 1
            cand = common & keep
            if cand:
                low = cand & -cand
                c_index = low.bit_length() - 1   # 0‑based
                c = c_index + 1
                sys.stdout.write(f"{a} {b} {c}")
                return

if __name__ == "__main__":
    solve()
```

to the required input‑output format.
