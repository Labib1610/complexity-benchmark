We can solve this by finding a triangle (3-cycle) in the undirected graph, but we need the lexicographically smallest one.

The approach:

1. Read employees and restriction edges into an adjacency set.
2. Iterate `a` from 1 to n:
   - Iterate neighbors `b` greater than `a` (restricted with `a`).
   - For each `b`, check neighbors `c` greater than `b` that are connected to both `a` and `b`.
   - The first such `(a, b, c)` is the lexicographically smallest triangle.

We can make it efficient by storing each employee's neighbors in a `set`.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)

    for a in range(n):
        for b in adj[a]:
            if b > a:
                # intersection of neighbors of a and b
                common = adj[a] & adj[b]
                for c in common:
                    if c > b:
                        print(a + 1, b + 1, c + 1)
                        return

if __name__ == "__main__":
    main()
```
