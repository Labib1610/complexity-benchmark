**Solution Explanation**

For every chemical we know the list of chemicals it reacts with.
The reactions form an undirected graph `G = (V,E)` (`|V| = n`,
`|E| = m`).  
A triple `{a,b,c}` with all three edges present is a **triangle**.
The task is to output the lexicographically smallest triangle
(`a < b < c`, smallest `a`, then `b`, then `c`).

`n ≤ 2000`, therefore a bitset of length `n` fits easily into a Python
integer (≈ 2000 bits ≈ 250 bytes).  
With a bitset we can test an edge and intersect neighbour sets in *O(1)*
time.

--------------------------------------------------------------------

#### Data structure

`adj[v]` – integer whose `i`‑th bit (`i = 0 … n‑1`) is `1`
iff vertex `v` is adjacent to vertex `i+1`.

```
adj[u] |= 1 << (v-1)
adj[v] |= 1 << (u-1)
```

--------------------------------------------------------------------

#### Finding the smallest triangle

We enumerate the first two vertices of the triangle in lexicographic
order:

```
for a = 1 … n-2:
    for b = a+1 … n-1:
        if edge (a,b) exists:
            # look for the smallest c > b
```

*Edge test* – one bit operation:

```
if (adj[a] >> (b-1)) & 1:
```

All common neighbours of `a` and `b` are

```
common = adj[a] & adj[b]          # bits of vertices adjacent to both
```

Only vertices larger than `b` may become the third vertex,
so we discard the lower bits:

```
common >>= b                       # remove bits 0 … b-1
```

If `common` is non‑zero, its least significant set bit corresponds to the
smallest possible `c`.  
Extract it with `low = common & -common`.  
Its position (0‑based) is `pos = low.bit_length() - 1`.  
The original vertex number is

```
c = b + 1 + pos          # because we shifted by b bits before
```

The first triple we encounter is exactly the lexicographically smallest
one, so we output it and terminate.

The algorithm performs at most `n·(n-1)/2 ≤ 2·10⁶` iterations,
each consisting of a few integer operations – easily fast enough.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest
triangle.

---

##### Lemma 1  
For any vertices `a < b`, after the statement  
`common = (adj[a] & adj[b]) >> b`  
the set bits of `common` are exactly the vertices `c` such that  
`c > b` and edges `(a,c)` and `(b,c)` exist.

**Proof.**  
`adj[a] & adj[b]` has a set bit at position `c-1` iff both
`adj[a]` and `adj[b]` have that bit set, i.e. iff edges `(a,c)` and
`(b,c)` exist.  
Shifting right by `b` removes bits `0 … b-1`, i.e. all vertices
`c ≤ b`. The remaining bits correspond precisely to vertices `c > b`
with the required edges. ∎



##### Lemma 2  
If `common` (as defined in Lemma&nbsp;1) is non‑zero,
`c = b + 1 + pos` where `pos` is the position of its least significant
set bit, is the smallest vertex `c > b` that together with `a,b` forms a
triangle.

**Proof.**  
By Lemma&nbsp;1 the set bits of `common` are exactly the admissible
vertices `c`. The least significant set bit corresponds to the smallest
such vertex because bits are ordered by vertex number.
Undoing the earlier right shift adds `b` to the index, and the extra
`+1` converts from 0‑based to 1‑based numbering, yielding the smallest
`c`. ∎



##### Lemma 3  
When the algorithm prints a triple `(a,b,c)`, it is a triangle.

**Proof.**  
The algorithm prints only after confirming that edge `(a,b)` exists and
`common` is non‑zero. By Lemma&nbsp;2 the obtained `c` satisfies
edges `(a,c)` and `(b,c)`. Hence all three edges are present – it is a
triangle. ∎



##### Lemma 4  
Let `(a₀,b₀,c₀)` be the first triple printed by the algorithm.
For any triangle `(a,b,c)` we have `(a₀,b₀,c₀) ≤_lex (a,b,c)`.

**Proof.**  
The outer loops enumerate pairs `(a,b)` in increasing lexicographic order:
first by `a`, then by `b`.  
Consider any triangle `(a,b,c)`.  
When the algorithm reaches the pair `(a,b)`, Lemma&nbsp;1 guarantees that
`common` contains `c` (since `c > b`). Therefore `common` is non‑zero,
and the algorithm would output a triangle at that moment (Lemma&nbsp;2)
unless it already stopped earlier.  
Thus the algorithm can stop only at a pair `(a₀,b₀)` that is **not larger**
than `(a,b)` in lexicographic order. Consequently `(a₀,b₀) ≤_lex (a,b)`.
If `(a₀,b₀) = (a,b)`, Lemma&nbsp;2 gives `c₀ ≤ c`. Hence the whole triple
is lexicographically minimal. ∎



##### Theorem  
The algorithm always outputs the lexicographically smallest triple of
vertices that forms a triangle.

**Proof.**  
Existence of at least one triangle is guaranteed, so the algorithm will
find a non‑empty `common` at some iteration and terminate, outputting a
triangle (Lemma&nbsp;3). By Lemma&nbsp;4 this triangle is lexicographically
minimal among all triangles. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency bitsets* : `O(m)`  
*Main loops* : at most `n·(n-1)/2 ≤ 2·10⁶` iterations, each `O(1)`.

```
Time   : O(n²)   ≤ 2·10⁶ elementary operations  (< 0.1 s in Python)
Memory : O(n)    (n+1 integers, each ≤ 2ⁿ)  ≈ 2000·250 B ≈ 0.5 MB
```

Both limits satisfy the problem constraints.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    n = next(it)
    m = next(it)

    # adjacency as bitsets, 1‑based vertices, bits 0..n-1
    adj = [0] * (n + 1)
    for _ in range(m):
        u = next(it)
        v = next(it)
        bit_u = 1 << (v - 1)
        bit_v = 1 << (u - 1)
        adj[u] |= bit_u
        adj[v] |= bit_v

    for a in range(1, n - 1):
        mask_a = adj[a]
        for b in range(a + 1, n):
            # edge (a,b) ?
            if (mask_a >> (b - 1)) & 1:
                common = mask_a & adj[b]      # neighbours of both
                common >>= b                  # keep only c > b
                if common:
                    low = common & -common     # least significant set bit
                    pos = low.bit_length() - 1
                    c = b + 1 + pos
                    sys.stdout.write(f"{a} {b} {c}")
                    return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
