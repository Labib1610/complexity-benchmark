We can solve this by checking all triples, but that would be too slow for \( n = 2000 \).  
Instead, we can use the fact that if the graph is not bipartite, there must be a triangle.  
We can find a triangle in \( O(n^2) \) using adjacency matrix bitsets.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)

    # Try to find triangle with smallest lexicographic order
    for a in range(n):
        for b in adj[a]:
            if b > a:
                common = adj[a] & adj[b]
                if common:
                    c = min(common)
                    if c > b:
                        print(a + 1, b + 1, c + 1)
                        return

if __name__ == "__main__":
    main()
```
