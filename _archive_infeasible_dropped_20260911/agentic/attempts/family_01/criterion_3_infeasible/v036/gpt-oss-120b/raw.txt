**Solution Explanation**

For every pair of workers we know whether they *cannot* work together.
The required group of three workers is exactly a **triangle** in this
undirected graph.
We have to output the lexicographically smallest triangle  
`a < b < c` (smallest `a`, then `b`, then `c`).

`n ≤ 2000`, therefore a bitset of length `n` fits into a Python integer
(`2000` bits ≈ `250` bytes).  
With bitsets we can intersect neighbour sets in O(1) word operations.



--------------------------------------------------------------------

#### Data structures

* `adj[i]` – Python `int` whose `j`‑th bit (`j` from `1` to `n`) is `1`
  iff there is an edge `i‑j`.
* `nbr[i]` – list of neighbours of vertex `i` (sorted increasingly).

--------------------------------------------------------------------

#### Algorithm
```
read n, m
adj = [0]*(n+1)
nbr = [[] for _ in range(n+1)]

for each edge (u,v):
        set bit v in adj[u] and bit u in adj[v]
        add v to nbr[u], u to nbr[v]

for a = 1 .. n-2:
        for b in nbr[a] with b > a:          # neighbours larger than a
                common = adj[a] & adj[b]     # vertices adjacent to both
                # keep only vertices larger than b
                mask = ((1 << (n+1)) - 1) ^ ((1 << (b+1)) - 1)
                common &= mask
                if common != 0:
                        # lowest set bit = smallest possible c
                        low = common & -common
                        c = low.bit_length() - 1
                        output a b c and terminate
```

*The outer loops enumerate all possible `(a,b)` with `a<b` in increasing
lexicographic order.  
For a fixed pair we instantly know whether a suitable `c` exists
by intersecting the two neighbour bitsets and discarding vertices `≤ b`.
If the intersection is non‑empty, the smallest remaining vertex is the
desired `c`.*

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
triangle.

---

##### Lemma 1  
For any vertices `a<b`, after the statement  
`common = adj[a] & adj[b]` the set bits of `common` are precisely the vertices
adjacent to **both** `a` and `b`.

**Proof.**  
`adj[a]` has a `1` at position `v` iff edge `a‑v` exists.
Bitwise AND keeps a `1` at `v` only if both operands have `1`,
i.e. both edges `a‑v` and `b‑v` exist. ∎



##### Lemma 2  
After `common &= mask` the set bits of `common` are exactly the vertices
`c` such that `c>b` and edges `a‑c` and `b‑c` exist.

**Proof.**  
`mask` has `1` for all indices `>b` and `0` otherwise.
AND with `mask` removes every bit `≤b` and keeps all bits `>b`.  
By Lemma&nbsp;1 the remaining bits correspond to vertices adjacent to both
`a` and `b`. ∎



##### Lemma 3  
If after masking `common ≠ 0`, the vertex `c` obtained by  
`c = (common & -common).bit_length() - 1` is the smallest vertex
`c>b` that together with `a,b` forms a triangle.

**Proof.**  
`common & -common` isolates the lowest set bit of `common`,
i.e. the smallest index present.
`bit_length()-1` converts this power‑of‑two to its index.
By Lemma&nbsp;2 every set bit corresponds to a valid `c`,
hence the isolated one is the smallest such `c`. ∎



##### Lemma 4  
When the algorithm prints a triple `(a,b,c)`, it is a triangle
(`a<b<c` and all three edges exist).

**Proof.**  
`b` is taken from `nbr[a]`, therefore edge `a‑b` exists.
By Lemma&nbsp;3 the printed `c` satisfies `c>b` and edges `a‑c` and `b‑c`
exist. ∎



##### Lemma 5  
The first printed triangle is the lexicographically smallest triangle
in the whole graph.

**Proof.**  
The outer loop enumerates `a` increasingly.
For a fixed `a`, the inner loop enumerates `b>a` increasingly.
Thus pairs `(a,b)` are visited in lexicographic order.
For a given pair, Lemma&nbsp;3 yields the smallest possible `c`.
Consequently the first triple found is the smallest among all triples,
because any earlier triple would have a smaller `(a,b)` pair,
contradicting the order of enumeration. ∎



##### Theorem  
The algorithm always terminates and outputs the lexicographically smallest
triple of workers that are pairwise incompatible.

**Proof.**  
The input guarantees at least one triangle, so some pair `(a,b)` will have
`common ≠ 0`. Hence the algorithm will eventually hit the `if common:` branch
and terminate.  
By Lemma&nbsp;4 the printed triple is a triangle.
By Lemma&nbsp;5 it is the lexicographically smallest one. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency:* `O(m)`  
*Main loops:* each edge `(a,b)` with `a<b` is examined once.
For each such edge we perform a constant‑time bitwise AND and a few integer
operations → `O(m)`.

Memory: `adj` stores `n+1` integers, each ≤ `2^{n+1}` → `O(n)` bits  
(`≈ 250 KB` for `n=2000`).  
Neighbour lists store `2m` integers → `O(m)`.

Both limits satisfy the constraints.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * (n + 1)          # bitsets
    nbr = [[] for _ in range(n + 1)]

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        # set bits
        adj[u] |= 1 << v
        adj[v] |= 1 << u
        nbr[u].append(v)
        nbr[v].append(u)

    for i in range(1, n + 1):
        nbr[i].sort()

    full_mask = (1 << (n + 1)) - 1   # bits 0..n set, we ignore bit 0

    out = []
    for a in range(1, n - 1):
        for b in nbr[a]:
            if b <= a:
                continue
            common = adj[a] & adj[b]
            # keep only vertices > b
            mask = full_mask ^ ((1 << (b + 1)) - 1)
            common &= mask
            if common:
                low = common & -common
                c = low.bit_length() - 1
                out = [a, b, c]
                sys.stdout.write(f"{a} {b} {c}\n")
                return

if __name__ == "__main__":
    solve()
```

and conforms to the required input‑output format.
