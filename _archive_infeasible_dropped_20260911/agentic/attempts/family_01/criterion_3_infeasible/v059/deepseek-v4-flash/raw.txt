We can solve this by checking all triples, but we need to be efficient.  
One approach: for each node `a` from `1` to `n`, look at its neighbors, and among them find the smallest pair `(b, c)` with `b < c` such that `b` and `c` are also connected.  

Since `n <= 2000` and `m <= 200000`, an adjacency matrix of booleans is feasible: `n^2 = 4e6` — acceptable in Python with memory optimization.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = adj[v][u] = True

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if adj[a][b]:
                for c in range(b + 1, n + 1):
                    if adj[a][c] and adj[b][c]:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    main()
```
