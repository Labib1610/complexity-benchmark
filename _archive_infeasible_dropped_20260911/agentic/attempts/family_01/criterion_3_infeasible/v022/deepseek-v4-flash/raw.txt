 We can solve this by checking all triples in increasing order and stopping at the first complete triangle.  
Since we need the lexicographically smallest, we iterate `a` from 1 to n, then `b` from a+1, then `c` from b+1, and check if all three edges exist.

Here’s the code:

```python
n, m = map(int, input().split())
adj = [[False] * (n + 1) for _ in range(n + 1)]

for _ in range(m):
    u, v = map(int, input().split())
    adj[u][v] = adj[v][u] = True

for a in range(1, n + 1):
    for b in range(a + 1, n + 1):
        if not adj[a][b]:
            continue
        for c in range(b + 1, n + 1):
            if adj[a][c] and adj[b][c]:
                print(a, b, c)
                exit()
```
