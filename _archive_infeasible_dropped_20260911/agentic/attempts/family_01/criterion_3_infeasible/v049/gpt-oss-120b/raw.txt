**Solution Explanation**

For every entity we know the other entities it conflicts with.
The required triple is a *triangle* in the undirected graph formed by the
conflict edges.
We have to output the lexicographically smallest triangle  
`a < b < c` (first minimise `a`, then `b`, then `c`).

--------------------------------------------------------------------

#### 1.   Bitset representation  

`n ≤ 2000`, therefore a 2000‑bit integer fits easily into a Python `int`.
For every vertex `v` we store one integer `mask[v]` :

```
bit i (0‑based) is 1  ⇔  vertex (i+1) is adjacent to v
```

Setting a bit is `mask[u] |= 1 << (v-1)` and `mask[v] |= 1 << (u-1)`.

With bitsets the intersection of two neighbour sets is a single
`&` operation, and testing whether a vertex `b` is adjacent to `a`
is a single bit test.

--------------------------------------------------------------------

#### 2.   Searching triangles in lexicographic order  

We iterate `a` from `1` to `n`.
For each `a` we iterate `b` from `a+1` to `n`.
If `a` and `b` are adjacent we look for a common neighbour `c` that is
larger than `b`.

```
common = mask[a] & mask[b]          # all common neighbours
common >>= b                         # discard vertices ≤ b
if common != 0:
        # the least set bit gives the smallest possible c
        low = common & -common
        tz  = low.bit_length() - 1          # trailing zeros
        c = b + 1 + tz
        output a b c
```

Because the outer loops increase `a` and then `b`,
the first triangle we encounter is exactly the lexicographically smallest
one.

The algorithm performs at most `n·(n-1)/2 ≤ 2·10⁶` iterations,
each using only a few integer operations – easily fast enough.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest triangle.

---

##### Lemma 1  
For fixed `a` and `b` (`a < b`) the expression  

```
common = mask[a] & mask[b];  common >>= b
```

contains a `1` at position `k` (0‑based) **iff** vertex `c = b+1+k`
is adjacent to both `a` and `b` and `c > b`.

**Proof.**  
`mask[a] & mask[b]` has a `1` exactly at positions of vertices adjacent to
both `a` and `b`. Shifting right by `b` removes the first `b` bits,
i.e. vertices `1 … b`. The remaining bits correspond precisely to vertices
`b+1 … n`. ∎



##### Lemma 2  
If `common` (after the shift) is non‑zero, the vertex  

```
c = b + 1 + tz
```

where `tz` is the number of trailing zeros of `common`,
is the smallest vertex `> b` that together with `a` and `b` forms a triangle.

**Proof.**  
`common`'s least significant `1` corresponds (by Lemma&nbsp;1) to the
smallest vertex `c > b` adjacent to both `a` and `b`.  
`tz` counts the zeros before that `1`, therefore `c = b+1+tz`. ∎



##### Lemma 3  
When the algorithm prints a triple `(a,b,c)`, it is a triangle
(`a<b<c` and all three edges exist).

**Proof.**  
`b` is chosen only if the bit for `b` in `mask[a]` is set → edge `a‑b`.  
`c` is obtained from `common` which is the intersection of the neighbour
sets of `a` and `b`; thus edges `a‑c` and `b‑c` exist.  
By construction `a<b<c`. ∎



##### Lemma 4  
Let `T` be the lexicographically smallest triangle in the graph.
The algorithm will output `T`.

**Proof.**  
Consider the outer loops. They enumerate all ordered pairs `(a,b)` with
`a<b` in increasing lexicographic order.
When the pair `(a_T , b_T)` of triangle `T` is reached, the algorithm
detects that `a_T` and `b_T` are adjacent.
By Lemma&nbsp;2 it then finds the smallest `c > b_T` that together with
`a_T , b_T` forms a triangle.
Since `T` is the smallest triangle, that `c` must be exactly `c_T`.
Thus the algorithm outputs `T` at that moment and terminates. ∎



##### Theorem  
The algorithm always terminates and prints the lexicographically smallest
triple of mutually conflicting entities.

**Proof.**  
The input guarantees at least one triangle, so by Lemma&nbsp;4 the
algorithm will encounter its first edge pair and output that triangle,
hence terminates.
By Lemma&nbsp;3 the printed triple is indeed a triangle,
and by Lemma&nbsp;4 it is the lexicographically smallest one. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building masks* : `O(m)`  
*Main loops* : at most `n·(n-1)/2` iterations, each `O(1)`  
```
Time   :  O(n² + m)   ≤  O(4·10⁶)   (well below 2 s)
Memory :  n integers ≈ 2000·(2000/8) B ≈ 0.5 MB
```

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    masks = [0] * (n + 1)          # 1‑based
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        masks[u] |= 1 << (v - 1)
        masks[v] |= 1 << (u - 1)

    for a in range(1, n + 1):
        mask_a = masks[a]
        for b in range(a + 1, n + 1):
            if (mask_a >> (b - 1)) & 1:          # edge a‑b exists
                common = mask_a & masks[b]
                common >>= b                     # keep only vertices > b
                if common:
                    low = common & -common        # lowest set bit
                    tz = low.bit_length() - 1    # trailing zeros
                    c = b + 1 + tz
                    # output in increasing order
                    sys.stdout.write(f"{a} {b} {c}")
                    return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
