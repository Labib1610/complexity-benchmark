We need the lexicographically smallest triangle in a graph.  

One way: iterate `a` from 1 to n, for each `b` from `a+1` to n where edge exists, check `c` from `b+1` to n and see if `a-b`, `a-c`, `b-c` edges exist.  
n ≤ 2000, so O(n³) is too big. But we can do:

- Store adjacency as a bitset (integer bitmask) per node.
- For each `a`, mark its neighbors.
- For each `b > a` that is adjacent to `a`, we look for common neighbor `c > b` that is adjacent to both.

Check using bit operations:  
adj[a] & adj[b] gives common neighbors. Then find smallest c > b in that intersection. If found, output (a,b,c).

Complexity: O(n² / word_size) using big integers, with n=2000 → fine.

Implementation:  
Read n, m. Build adjacency bitmask lists of length n+1, each initial 0. For each edge (u,v), set bits in both adj.  
Loop a from 1 to n:  
  for b from a+1 to n:  
    if (adj[a] >> b) & 1:  
      common = adj[a] & adj[b]  
      mask = common & (~((1 << (b+1)) - 1))   # bits >= b+1  
      if mask: find position of lowest set bit → c.  
      output and exit.

Bit positions: let's index bits starting 0 for worker 1, or we can use bit index = worker id. For n ≤ 2000 bits fine.

import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    m = int(data[1])
    
    # adjacency bitmasks (bit i = worker i is neighbor)
    adj = [0] * (n + 1)
    
    ptr = 2
    for _ in range(m):
        u = int(data[ptr])
        v = int(data[ptr + 1])
        ptr += 2
        adj[u] |= (1 << v)
        adj[v] |= (1 << u)
    
    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if (adj[a] >> b) & 1:
                common = adj[a] & adj[b]
                # keep only candidates c > b
                mask = common & ~((1 << (b + 1)) - 1)
                if mask:
                    lowest = mask & -mask
                    c = lowest.bit_length() - 1
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
