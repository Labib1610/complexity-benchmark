**Solution Explanation**

For every worker we know the workers he/she refuses to work with.
The data form an undirected simple graph  

* vertices – workers `1 … n`  
* edges – mutual grievances  

A *deadlocked* set of three workers is exactly a **triangle** in this graph.
We have to output the lexicographically smallest triangle  
`a < b < c` (smallest `a`, then smallest `b`, then smallest `c`).

--------------------------------------------------------------------

#### 1.   Data structures  

* `adj_mask[v]` – an integer whose binary representation is a bitset of the
  neighbours of vertex `v`.  
  Bit `i` (0‑based) is set **iff** there is an edge `v – (i+1)`.  
  With `n ≤ 2000` a 2000‑bit integer easily fits into Python’s arbitrary length
  integers.

* `adj_list[v]` – sorted list of neighbours of `v`.  
  Needed to iterate `b` in increasing order.

Both structures are built from the `m` input edges in `O(m)` time.

--------------------------------------------------------------------

#### 2.   Searching the smallest triangle  

We enumerate possible first two vertices `a , b` in the required order:

```
for a = 1 … n:
        for b in adj_list[a] with b > a (list already sorted):
                # a < b is guaranteed
                common = adj_mask[a] & adj_mask[b]          # vertices adjacent to both
                # we need a vertex c > b
                mask = common >> b                          # drop bits ≤ b
                if mask != 0:
                        # lowest set bit of mask = the smallest possible c
                        low = mask & -mask
                        pos = low.bit_length() - 1          # 0‑based position inside mask
                        c = b + 1 + pos
                        output a b c and finish
```

*Why does this give the lexicographically smallest triangle?*  

* The outer loop increases `a`. The first triangle found therefore has the
  smallest possible `a`.
* For a fixed `a` the inner loop scans `b` in increasing order, so the first
  found triangle also has the smallest possible `b`.
* For a fixed pair `(a,b)` we look for the **smallest** `c > b` that is adjacent
  to both – exactly the lowest set bit after shifting by `b`.

Thus the first triangle discovered is the required answer.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest triangle.

---

##### Lemma 1  
For any vertices `a < b`, `mask = (adj_mask[a] & adj_mask[b]) >> b`
has a set bit at position `p` (0‑based) **iff** vertex `c = b+1+p`
forms a triangle `(a,b,c)`.

**Proof.**  
`adj_mask[a] & adj_mask[b]` contains exactly the vertices adjacent to **both**
`a` and `b`. Shifting right by `b` discards bits for vertices `≤ b`.  
Therefore a remaining set bit at position `p` corresponds to vertex
`c = b+1+p` (`c > b`) that is adjacent to both `a` and `b`. ∎



##### Lemma 2  
If `mask ≠ 0` then `c = b + 1 + pos` with `pos = (mask & -mask).bit_length() - 1`
is the smallest vertex `c > b` that together with `a,b` forms a triangle.

**Proof.**  
`mask & -mask` isolates the lowest set bit of `mask`. Its index `pos`
is the smallest position of a set bit, i.e. the smallest `p` such that
`mask` has a 1 at `p`. By Lemma&nbsp;1 this `p` yields the smallest possible
`c = b+1+p`. ∎



##### Lemma 3  
When the algorithm prints a triple `(a,b,c)`, it is a triangle.

**Proof.**  
The algorithm prints only after finding `mask ≠ 0` and computing `c` as in
Lemma&nbsp;2. By Lemma&nbsp;1 the existence of that set bit guarantees that
edges `(a,b)`, `(a,c)`, `(b,c)` are present. ∎



##### Lemma 4  
Let `T` be the set of all triangles. The algorithm outputs the triangle with
minimum lexicographic order.

**Proof.**  
Consider the ordered enumeration performed by the algorithm:

1. `a` increases from `1` to `n`.  
   The first printed triangle therefore has the smallest possible first
   element among all triangles, because any triangle with a smaller `a`
   would have been examined earlier.

2. For this fixed `a`, `b` runs through the neighbours of `a` in increasing
   order, skipping those `≤ a`.  
   Hence the printed triangle has the smallest possible second element among
   triangles whose first element equals this `a`.

3. For this fixed pair `(a,b)`, Lemma&nbsp;2 shows that the algorithm chooses
   the smallest feasible `c`.  

Thus the printed triple is lexicographically minimal among all triangles. ∎



##### Theorem  
The algorithm always terminates and prints the lexicographically smallest
triangle of the given graph.

**Proof.**  

*Termination.*  
The outer loops iterate over a finite set of vertex pairs; inside we perform
only constant‑time operations. Hence the algorithm finishes.

*Existence of output.*  
The statement of the problem guarantees at least one triangle, i.e. the set
`T` is non‑empty. By Lemma&nbsp;4 the algorithm will eventually encounter a
pair `(a,b)` belonging to some triangle and will output the corresponding
`c`. Therefore it always prints a triple.

*Correctness of the printed triple.*  
By Lemma&nbsp;3 the printed triple is a triangle. By Lemma&nbsp;4 it is the
lexicographically smallest triangle. ∎
