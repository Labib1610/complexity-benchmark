 We can solve this by checking all triples in increasing order and stopping at the first fully connected triple.  
Since \( n \) can be up to 2000, checking all triples naively would be \( O(n^3) \), which is too slow.  
Instead, we can use adjacency sets and iterate over edges to find a triangle efficiently.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    edges = []
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
        edges.append((u, v))
    
    # Try to find a triangle
    for u, v in edges:
        # Find common neighbor w of u and v
        common = adj[u] & adj[v]
        if common:
            w = min(common)
            # Output sorted triple
            a, b, c = sorted([u+1, v+1, w+1])
            print(a, b, c)
            return

if __name__ == "__main__":
    main()
```
