**Solution Explanation**

For every substance we know the other substances it reacts with.
The data form an undirected simple graph  

* vertices – substances `1 … n`  
* edges – reactive pairs.

A *dangerous* triple is exactly a **triangle** (3‑clique) in this graph.
We have to output the lexicographically smallest triangle  
`a < b < c`.

--------------------------------------------------------------------

#### 1.   Bitset representation  

`n ≤ 2000`, therefore a vertex can be represented by a bitset of length `n+1`
(`bit i` = 1  **iff**  there is an edge to vertex `i`).

In Python an integer works as an arbitrary length bitset, all operations are
`O(1)` on 2000 bits.

```
adj[v]  – integer, bit i set ⇔ edge (v,i) exists
```

While reading the input we fill the bitsets:

```
adj[u] |= 1 << v
adj[v] |= 1 << u
```

--------------------------------------------------------------------

#### 2.   Searching the smallest triangle  

We iterate over all possible ordered pairs `(a,b)` with `a < b`
in increasing lexicographic order.

```
for a = 1 … n-2
    for b = a+1 … n-1
        if edge (a,b) exists:
            common = adj[a] & adj[b]          # vertices adjacent to both a and b
            keep only vertices > b
            if common ≠ 0:
                c = smallest vertex in common
                output a b c
```

*Why does this give the lexicographically smallest triangle?*

* the outer loops increase `a` first, then `b` – exactly the required order.
* `common` contains **all** vertices adjacent to both `a` and `b`.  
  After discarding vertices `≤ b` the smallest remaining vertex is the
  smallest possible `c` for this `(a,b)`.  
  The first `(a,b)` for which such a `c` exists is therefore the global
  lexicographically smallest triangle.

All operations inside the loops are bit operations on 2000‑bit integers,
hence `O(1)`.  
The double loop runs at most `n·(n-1)/2 ≤ 2·10⁶` iterations – easily fast
enough.

--------------------------------------------------------------------

#### 3.   Obtaining the smallest vertex from a bitset  

`common` has bits only for vertices `> b`.  
The lowest set bit is obtained by `low = common & -common`.  
Its index (the vertex number) is `low.bit_length() - 1`.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest triangle.

---

##### Lemma 1  
For any vertices `a < b`, after the statement  

```
common = adj[a] & adj[b]
common &= mask   (mask keeps only bits > b)
```

`common` contains exactly the vertices `c` such that `{a,b,c}` is a triangle
and `c > b`.

**Proof.**  
`adj[a] & adj[b]` contains precisely the vertices adjacent to **both** `a`
and `b`. Adding the mask removes all vertices `≤ b`. ∎



##### Lemma 2  
If `common ≠ 0` then `c = low.bit_length() - 1` (where `low = common & -common`)
is the smallest vertex `c > b` that together with `a,b` forms a triangle.

**Proof.**  
`low` is the lowest set bit of `common`. By Lemma&nbsp;1 every set bit of
`common` corresponds to a vertex `c` that makes a triangle with `a,b`.  
Therefore the lowest set bit corresponds to the smallest such `c`. ∎



##### Lemma 3  
When the algorithm prints a triple `(a,b,c)`, it is a triangle and
`a < b < c`.

**Proof.**  
The algorithm prints only after confirming that edge `(a,b)` exists
(`(adj[a]>>b)&1 == 1`).  
By Lemma&nbsp;2 the obtained `c` satisfies `c > b` and edges `(a,c)` and
`(b,c)` exist (again by Lemma&nbsp;1). Hence `{a,b,c}` is a triangle and
`a<b<c`. ∎



##### Lemma 4  
Let `T = (a₀,b₀,c₀)` be the first triple printed by the algorithm.
For any triangle `T' = (a',b',c')` we have `T ≤_lex T'`.

**Proof.**  
The outer loops enumerate all ordered pairs `(a,b)` with `a<b` in
lexicographic order.
Consider any triangle `T'`. Its first two vertices `(a',b')` appear at some
iteration of the loops.
If the algorithm prints before that iteration, then `a₀ < a'` or
`a₀ = a'` and `b₀ < b'`, giving `T <_lex T'`.  
If the algorithm reaches the iteration `(a',b')` first, then `common` is
non‑empty (because `c'` belongs to it). By Lemma&nbsp;2 the algorithm chooses
the smallest possible `c` for this pair, i.e. `c₀ ≤ c'`. Consequently
`(a₀,b₀,c₀) = (a',b',c₀) ≤_lex (a',b',c')`. ∎



##### Theorem  
The algorithm outputs the lexicographically smallest triple
`a<b<c` that forms a triangle.

**Proof.**  
By Lemma&nbsp;3 the printed triple is a triangle.
By Lemma&nbsp;4 no other triangle is lexicographically smaller.
Therefore the printed triple is exactly the required answer. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Memory* : `n+1` integers, each ≤ `2^{n+1}` → `O(n)` bits ≈ 2000 bits per vertex,
negligible (well below 256 MB).

*Time* :

```
building adjacency bitsets : O(m)
double loop over (a,b)      : O(n²)   ( ≤ 2·10⁶ )
inside each iteration       : O(1)   (bit operations)
```

Overall `O(n² + m)` ≤ `O(2·10⁶)`, far below the 2 s limit.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * (n + 1)          # bit i set ⇔ edge to i
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u] |= 1 << v
        adj[v] |= 1 << u

    full_mask = (1 << (n + 1)) - 1   # bits 0..n set, we ignore bit 0

    for a in range(1, n - 1):
        bits_a = adj[a]
        for b in range(a + 1, n):
            # does edge (a,b) exist ?
            if (bits_a >> b) & 1:
                common = bits_a & adj[b]
                # keep only vertices > b
                mask = full_mask ^ ((1 << (b + 1)) - 1)
                common &= mask
                if common:
                    low = common & -common          # lowest set bit
                    c = low.bit_length() - 1
                    print(a, b, c)
                    return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
