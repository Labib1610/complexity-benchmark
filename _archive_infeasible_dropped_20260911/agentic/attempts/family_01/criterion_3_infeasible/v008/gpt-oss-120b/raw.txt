**Solution Explanation**

For every worker we know the set of workers he/she conflicts with.
A triple `a < b < c` is a *proof of impossibility* iff the three edges  
`a‑b , a‑c , b‑c` are all present – i.e. the three vertices form a triangle.

The required output is the lexicographically smallest triangle:
first minimise `a`, then `b`, then `c`.

`n ≤ 2000`, therefore we can store for every vertex a **bitset** of its
neighbours – an integer whose `i`‑th bit (0‑based) tells whether the vertex
`i+1` is adjacent.

--------------------------------------------------------------------

#### Data structures

* `adj_bit[v]` – integer bitset of neighbours of vertex `v` (bits `0 … n‑1`).
* `adj_mat[v]` – `bytearray` of length `n+1` (`adj_mat[v][u] = 1` iff edge `v‑u`
  exists). Needed for O(1) edge test while iterating pairs.
* `mask_gt[b]` – bitmask whose bits are `1` exactly for vertices `> b`.
  `mask_gt[b] = all_ones ^ ((1 << b) - 1)` where `all_ones = (1 << n) - 1`.

--------------------------------------------------------------------

#### Algorithm
```
read n, m
initialise adj_bit[1…n] = 0
initialise adj_mat[1…n] = bytearray(n+1)

for each edge (u, v):
        set the two bits in adj_bit
        adj_mat[u][v] = adj_mat[v][u] = 1

pre‑compute mask_gt[0…n]

for a = 1 … n:
        for b = a+1 … n:
                if not adj_mat[a][b]: continue          # no edge a‑b
                common = adj_bit[a] & adj_bit[b] & mask_gt[b]
                if common == 0: continue                # no c > b completing a triangle
                # smallest c is the least significant set bit of common
                lowbit = common & -common
                c_index = lowbit.bit_length() - 1       # 0‑based
                c = c_index + 1
                output a b c and terminate
```

The outer loops enumerate pairs `(a,b)` in lexicographic order.
For a fixed pair we intersect the neighbour sets of `a` and `b`,
restrict to vertices larger than `b` (using `mask_gt[b]`) and take the
smallest remaining vertex – that gives the smallest possible `c`.
The first triangle we encounter is therefore the lexicographically smallest
one.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
triangle.

---

**Lemma 1**  
For any vertices `a < b`, `common = adj_bit[a] ∧ adj_bit[b] ∧ mask_gt[b]`
contains exactly the vertices `c` such that `c > b` and edges `a‑c` and
`b‑c` exist.

*Proof.*  
`adj_bit[a]` has a `1` at position `c-1` iff edge `a‑c` exists.
Similarly for `adj_bit[b]`. Their bitwise AND therefore has a `1` exactly
for vertices adjacent to **both** `a` and `b`.  
`mask_gt[b]` has `1`s only for positions `c-1` with `c > b`.  
Intersecting with it removes all `c ≤ b`. ∎



**Lemma 2**  
If `common` is non‑zero, the vertex `c` obtained from the least significant
set bit of `common` is the smallest vertex `c > b` that together with `a,b`
forms a triangle.

*Proof.*  
By Lemma&nbsp;1 every set bit of `common` corresponds to a suitable `c`.
Bits are ordered by vertex number, the least significant set bit corresponds
to the smallest index, i.e. the smallest vertex number. ∎



**Lemma 3**  
When the algorithm outputs a triple `(a,b,c)`, it is a triangle.

*Proof.*  
The algorithm checks `adj_mat[a][b] = 1`, so edge `a‑b` exists.
By Lemma&nbsp;2, `c` satisfies edges `a‑c` and `b‑c`. Hence all three edges are
present – a triangle. ∎



**Lemma 4**  
Let `T* = (a*,b*,c*)` be the lexicographically smallest triangle in the
graph. The algorithm will output `T*`.

*Proof.*  
Consider the double loop. It enumerates all ordered pairs `(a,b)` with
`a < b` in increasing lexicographic order.
When the pair `(a*,b*)` is reached, `adj_mat[a*][b*] = 1` (since `T*` is a
triangle). By Lemma&nbsp;1, `common` contains all vertices `c` that together
with `a*,b*` form a triangle, in particular `c*`. Because `c* > b*`,
`c*` is present in `common`. By Lemma&nbsp;2 the algorithm will pick the
smallest such `c`, which is exactly `c*` (any other feasible `c` would be
≥ `c*`). Therefore the algorithm outputs `(a*,b*,c*)` and terminates
before any lexicographically larger pair is examined. ∎



**Theorem**  
The algorithm always terminates and prints the lexicographically smallest
triple of workers that are pairwise in conflict.

*Proof.*  
The input guarantees at least one triangle, so some iteration will find a
non‑empty `common` and terminate. By Lemma&nbsp;3 the printed triple is a
triangle, and by Lemma&nbsp;4 it is the lexicographically smallest one. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building structures*: `O(m)` time, `O(n + m)` memory.  
*Main loops*: at most `n·(n-1)/2 ≤ 2·10⁶` iterations (since `n ≤ 2000`);
each iteration does only constant‑time bit operations.
Thus `O(n²)` ≤ `4·10⁶` operations, well within limits.

Memory:
* `adj_bit` – `n` integers, each ≤ `2ⁿ` → negligible.
* `adj_mat` – `n·(n+1)` bytes ≈ 4 MB for `n = 2000`.
* masks – `n+1` integers.

Total < 10 MB, far below the 256 MB limit.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj_bit = [0] * (n + 1)
    adj_mat = [bytearray(n + 1) for _ in range(n + 1)]

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj_bit[u] |= 1 << (v - 1)
        adj_bit[v] |= 1 << (u - 1)
        adj_mat[u][v] = adj_mat[v][u] = 1

    all_ones = (1 << n) - 1
    mask_gt = [0] * (n + 1)
    for b in range(n + 1):
        mask_gt[b] = all_ones ^ ((1 << b) - 1)   # bits for vertices > b

    out = []
    for a in range(1, n + 1):
        ba = adj_bit[a]
        for b in range(a + 1, n + 1):
            if not adj_mat[a][b]:
                continue
            common = ba & adj_bit[b] & mask_gt[b]
            if common:
                lowbit = common & -common
                c_index = lowbit.bit_length() - 1   # 0‑based
                c = c_index + 1
                out = [a, b, c]
                sys.stdout.write(f"{a} {b} {c}\n")
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
