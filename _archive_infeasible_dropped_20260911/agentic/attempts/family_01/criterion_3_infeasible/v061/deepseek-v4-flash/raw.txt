 We need to find a triangle in an undirected graph where vertices are properties and edges are incompatibilities.  
The graph is guaranteed to contain at least one triangle.  
We can use an adjacency matrix for fast lookups, then iterate over all triples in lexicographic order and stop at the first triangle.

```python
n, m = map(int, input().split())
adj = [[False] * (n + 1) for _ in range(n + 1)]

for _ in range(m):
    u, v = map(int, input().split())
    adj[u][v] = adj[v][u] = True

for a in range(1, n + 1):
    for b in range(a + 1, n + 1):
        if adj[a][b]:
            for c in range(b + 1, n + 1):
                if adj[a][c] and adj[b][c]:
                    print(a, b, c)
                    exit()
```
