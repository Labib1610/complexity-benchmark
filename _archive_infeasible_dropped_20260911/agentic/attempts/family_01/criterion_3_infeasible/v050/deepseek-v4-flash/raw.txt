 We need to find a triangle in an undirected graph.  
The graph is given by edges, and we need to output the lexicographically smallest triangle (a < b < c).  

A simple approach:  
- Store edges in an adjacency set for O(1) lookups.  
- Iterate over all possible triples in increasing order and check if all three edges exist.  
- Since n ≤ 2000, O(n³) would be too slow (8e9 operations).  
- Instead, we can iterate over edges and check for a common neighbor.  

We can do:  
- For each edge (u, v) with u < v, check all neighbors w of u (where w > v) and see if (v, w) is an edge.  
- Keep track of the smallest triangle found.  

This is O(m * degree) which is acceptable for m ≤ 2e5.  

Here’s the implementation:  

```python
n, m = map(int, input().split())
adj = [set() for _ in range(n)]
edges = []

for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].add(v)
    adj[v].add(u)
    if u > v:
        u, v = v, u
    edges.append((u, v))

best = None

for u, v in edges:
    # find w > v such that u-w and v-w exist
    for w in adj[u]:
        if w > v and w in adj[v]:
            if best is None or (u, v, w) < best:
                best = (u, v, w)

a, b, c = best
print(a + 1, b + 1, c + 1)
```
