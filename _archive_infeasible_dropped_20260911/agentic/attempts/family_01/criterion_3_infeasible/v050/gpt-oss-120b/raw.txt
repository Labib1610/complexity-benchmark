**Solution Explanation**

For every supplier we store the set of his partners as a bit mask.
Vertex `v` corresponds to bit `v‑1` (bits are 0‑based).

```
adj[v]  – integer, bit i is 1  ⇔  there is an agreement between v and i+1
```

`n ≤ 2000`, therefore one integer of at most 2000 bits is enough
(≈ 250 bytes).  
Bit operations on Python integers are implemented in C and are very fast,
so the whole algorithm works in `O(n²)` time.

--------------------------------------------------------------------

#### Finding the lexicographically smallest triangle  

A triangle is a triple `a < b < c` such that all three edges exist.
We enumerate the first two vertices `a , b` in increasing order.
For a fixed pair `(a,b)` we need a vertex `c > b` that is adjacent to **both**
`a` and `b`.

```
common = adj[a] & adj[b]          # vertices adjacent to a and b
common_shift = common >> b        # delete vertices ≤ b
```

If `common_shift` is non‑zero, it contains exactly the vertices `c > b`
forming a triangle with `a , b`.  
The least significant set bit of `common_shift` gives the smallest possible
`c`, because we already iterate `a` and `b` increasingly.

The position of the lowest set bit:

```
lsb = common_shift & -common_shift          # single 1‑bit
c_index = lsb.bit_length() - 1              # 0‑based
c = b + 1 + c_index                          # back to 1‑based vertex number
```

The first triangle discovered in this double loop is
the lexicographically smallest one, because:

* `a` grows from `1` to `n‑2`;
* for a fixed `a`, `b` grows from `a+1` to `n‑1`;
* for a fixed pair `(a,b)` we choose the smallest possible `c`.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
triangle.

---

##### Lemma 1  
For any vertices `a<b` the expression  

```
common_shift = (adj[a] & adj[b]) >> b
```

has a set bit at position `k (0‑based)` **iff** vertex `c = b+1+k`
is adjacent to both `a` and `b`.

**Proof.**  
`adj[a] & adj[b]` contains precisely the vertices adjacent to **both**
`a` and `b`. Shifting right by `b` discards bits `0 … b‑1`,
i.e. vertices `1 … b`. The remaining bit `k` corresponds to vertex
`b+1+k`. ∎



##### Lemma 2  
If `common_shift ≠ 0`, the vertex  

```
c = b + 1 + ( (common_shift & -common_shift).bit_length() - 1 )
```

is the smallest vertex `> b` adjacent to both `a` and `b`.

**Proof.**  
`common_shift & -common_shift` isolates the lowest set bit of `common_shift`,
hence its index `k` is the smallest `k` with a set bit.
By Lemma&nbsp;1 this `k` corresponds to the smallest vertex `c = b+1+k`
adjacent to both `a` and `b`. ∎



##### Lemma 3  
When the algorithm prints a triple `(a,b,c)`, the three edges
`a‑b , a‑c , b‑c` are present in the input graph.

**Proof.**  
* The inner loop continues only if bit `b‑1` of `adj[a]` is set,
  i.e. edge `a‑b` exists.
* `c` is obtained from `common_shift`, which is derived from
  `adj[a] & adj[b]`. Therefore both bits `c‑1` in `adj[a]` and `adj[b]`
  are set, i.e. edges `a‑c` and `b‑c` exist. ∎



##### Lemma 4  
The first triangle found by the double loop `(a from 1, b from a+1)`
is the lexicographically smallest triangle of the graph.

**Proof.**  
Consider any triangle `(x,y,z)` with `x<y<z`.

* The outer loop reaches `a = x` before any larger `a`.
* For this `a = x` the inner loop reaches `b = y` before any larger `b`.
* When processing this pair, Lemma&nbsp;2 returns the smallest possible
  `c > b` that closes a triangle, which is at most `z`.
  Hence a triangle `(x,y,c)` with `c ≤ z` is found at this moment.

Therefore no triangle with a smaller `a` exists,
and for this `a` none with a smaller `b` exists.
For the same `a,b` the algorithm picks the smallest possible `c`.
Consequently the first printed triangle is lexicographically minimal. ∎



##### Theorem  
The algorithm always outputs three integers `a<b<c` that form a triangle,
and this triangle is the lexicographically smallest among all triangles
in the given graph.

**Proof.**  
Existence of at least one triangle is guaranteed by the statement.
The double loop examines every unordered pair `{a,b}` with `a<b`;
for a pair belonging to a triangle, Lemma&nbsp;2 yields a suitable `c`,
so the algorithm will eventually print a triangle.
By Lemma&nbsp;3 the printed triple indeed consists of three mutually adjacent
vertices.
By Lemma&nbsp;4 this printed triple is the lexicographically smallest one. ∎

#### Complexity Analysis  

*Building the adjacency masks* – `O(m)` time, `O(n)` memory  
(`n+1` integers, each ≤ 2000 bits).

*Search* – Two nested loops over all ordered pairs `a<b`  

```
∑_{a=1}^{n} (n-a) = n·(n-1)/2 = O(n²)  ≤ 2·10⁶   (n ≤ 2000)
```

Each iteration performs only a few integer operations (`&`, `>>`,
bit test, possibly one `& -` and `bit_length`), all `O(1)`.

Hence  

* **Time:** `O(n²)   ( ≤ 4·10⁶ elementary operations )`
* **Memory:** `O(n)` integers ≈ 2000·250 B ≈ 0.5 MB.

Both limits are far below the given constraints.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    # adjacency as bit masks, vertex i ↔ bit i-1
    adj = [0] * (n + 1)
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u] |= 1 << (v - 1)
        adj[v] |= 1 << (u - 1)

    for a in range(1, n - 1):
        for b in range(a + 1, n):
            # edge a‑b ?
            if ((adj[a] >> (b - 1)) & 1) == 0:
                continue
            common = adj[a] & adj[b]
            # keep only vertices > b
            common_shift = common >> b
            if common_shift:
                # lowest set bit → smallest possible c
                lsb = common_shift & -common_shift
                c_idx = lsb.bit_length() - 1      # 0‑based index inside shifted mask
                c = b + 1 + c_idx
                sys.stdout.write(f"{a} {b} {c}")
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
