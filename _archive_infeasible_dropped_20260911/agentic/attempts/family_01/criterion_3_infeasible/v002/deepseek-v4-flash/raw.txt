We can solve this by checking each possible triple in lexicographic order and stopping at the first one that forms a triangle.  

Since n can be up to 2000, checking all triples naively would be too slow (O(n³) ≈ 8×10⁹).  
Instead, we can use an adjacency matrix (or set) for O(1) edge lookups and iterate over pairs, then check for a common neighbor.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if b in adj[a]:
                for c in range(b + 1, n + 1):
                    if c in adj[a] and c in adj[b]:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    main()
```
