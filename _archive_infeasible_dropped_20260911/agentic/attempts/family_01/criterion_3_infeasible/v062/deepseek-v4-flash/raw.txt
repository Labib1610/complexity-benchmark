We can solve this by checking each possible triple in lexicographic order, but that would be too slow for \( n = 2000 \). Instead, we can use an adjacency matrix and iterate over possible first two vertices, then check for a common neighbor.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = adj[v][u] = True

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if adj[a][b]:
                for c in range(b + 1, n + 1):
                    if adj[a][c] and adj[b][c]:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    main()
```
