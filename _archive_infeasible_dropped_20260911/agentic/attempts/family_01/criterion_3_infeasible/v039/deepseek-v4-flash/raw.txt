We need to find a triangle in an undirected graph where the condition is that three nodes are all connected to each other.  

Given constraints (n ≤ 2000, m ≤ 200000), an O(n³) check is too slow. But we can do better:  
We can iterate over edges (u, v) and for each check any common neighbor w. Since n is up to 2000, we can store adjacency as a bitset (Python int as bitmask) to quickly compute intersection.  

The algorithm:
1. Read graph into adjacency bitmask for each node.
2. Iterate u from 1 to n, and for each neighbor v > u, check intersection of adj[u] and adj[v]; pick the smallest w in intersection.
3. Once found, we have the triangle, and we can break because we iterate sorted to guarantee lexicographically smallest.

Here’s the code:

```python
import sys

def solve():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    m = int(data[1])
    adj = [0] * (n + 1)
    idx = 2
    for _ in range(m):
        u = int(data[idx])
        v = int(data[idx + 1])
        idx += 2
        adj[u] |= (1 << (v - 1))
        adj[v] |= (1 << (u - 1))
    
    for a in range(1, n + 1):
        mask_a = adj[a]
        # Check neighbors b > a
        nbrs = mask_a & ~((1 << a) - 1)  # only > a
        while nbrs:
            lsb = nbrs & -nbrs
            b = lsb.bit_length()  # b = index + 1
            intersection = adj[a] & adj[b]
            if intersection:
                c_bit = intersection & -intersection
                c = c_bit.bit_length()
                print(a, b, c)
                return
            nbrs ^= lsb

if __name__ == "__main__":
    solve()
```
