 We can solve this by checking each possible triple of vertices and verifying if all three edges exist.  
Since \( n \) can be up to 2000, checking all triples directly would be \( O(n^3) \), which is too slow.  
Instead, we can iterate over each edge and check for a common neighbor that forms a triangle.  

Here’s the implementation:  

```python
n, m = map(int, input().split())
adj = [set() for _ in range(n)]
edges = []

for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].add(v)
    adj[v].add(u)
    edges.append((u, v))

# Check each edge for a common neighbor
for u, v in edges:
    common = adj[u] & adj[v]
    if common:
        w = min(common)
        a, b, c = sorted([u, v, w])
        print(a + 1, b + 1, c + 1)
        break
```
