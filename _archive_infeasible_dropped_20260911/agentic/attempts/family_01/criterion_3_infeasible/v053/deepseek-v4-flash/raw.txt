We can approach this by trying each access point as the smallest ID in the triangle.  
We need to find a triangle $(a, b, c)$ such that $a$ is as small as possible, then $b$ as small as possible, then $c$ as small as possible.

Since $n \le 2000$, we can iterate $a$, then $b$, then look for a $c$ that is connected to both $a$ and $b$.

Steps:
- Store adjacency as sets for fast lookup.
- Iterate $a$ from 1 to n:
  - For each neighbor $b$ of $a$ with $b > a$:
    - For each neighbor $c$ of $a$ with $c > b$:
      - If $c$ is connected to $b$, then we have a triangle $(a, b, c)$, output and exit.

The first found triangle will have the lexicographically smallest IDs because we iterate $a, b, c$ in increasing order.

Complexity is $O(n^3/64)$ if using bitsets, but with $m$ up to $2\cdot 10^5$, simple boolean adjacency check is okay.

Implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [0] * n
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u] |= (1 << v)
        adj[v] |= (1 << u)
    for a in range(n - 2):
        adj_a = adj[a]
        for b in range(a + 1, n - 1):
            if not (adj_a >> b) & 1:
                continue
            # candidates = neighbors of a that are > b
            candidates = adj_a & ~((1 << (b + 1)) - 1)
            # need b also connected to c
            candidates &= adj[b]
            # smallest c
            if candidates:
                c = (candidates & -c).bit_length() - 1
                print(a + 1, b + 1, c + 1)
                return

if __name__ == "__main__":
    solve()
```
