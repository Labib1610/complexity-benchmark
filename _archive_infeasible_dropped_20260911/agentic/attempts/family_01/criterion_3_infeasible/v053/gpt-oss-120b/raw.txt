**Solution Explanation**

For every access point we store the set of its neighbours as a bitset.
`bit i` of the bitset of vertex `v` is `1` iff the edge `v – i` exists.

For a triangle `{a,b,c}` with `a<b<c`

```
a is connected with b   →  edge (a,b)
a is connected with c   →  bit c is set in bitset[a]
b is connected with c   →  bit c is set in bitset[b]
```

So for a fixed pair `(a,b)` the vertices that can be the third vertex are exactly

```
common = bitset[a]  AND  bitset[b]
```

We need the smallest `c > b` contained in `common`.  
With bit operations this is `O(1)` :

```
mask = common >> (b+1)          # discard bits ≤ b
if mask != 0:
        low = mask & -mask       # lowest set bit
        c   = (low.bit_length()-1) + (b+1)
```

If we examine the pairs `(a,b)` in lexicographic order (`a` increasing,
for equal `a` – `b` increasing) and for each pair take the smallest possible
`c`, the first triangle we encounter is exactly the required one
(the smallest sorted triple).

`n ≤ 2000`, therefore a bitset fits into a Python integer
(`2000` bits ≈ 250 bytes).  
The number of edges `m ≤ 2·10⁵`, so iterating over all edges is fast.

--------------------------------------------------------------------

#### Algorithm
```
read n, m
adj = [0] * n                     # bitsets
edges = []

for each of the m lines:
        u, v = read (1‑based)
        u -= 1; v -= 1
        adj[u] |= 1 << v
        adj[v] |= 1 << u
        if u > v: swap(u,v)
        edges.append( (u,v) )

sort edges by (u,v)

for (a,b) in edges:               # a < b
        common = adj[a] & adj[b]
        mask   = common >> (b+1)   # keep only vertices > b
        if mask:
                low = mask & -mask
                c   = (low.bit_length()-1) + (b+1)
                output a+1, b+1, c+1
                exit
```

The program always terminates because the statement guarantees at least one
triangle.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
sorted triangle.

---

**Lemma 1**  
For any pair of vertices `a<b`, a vertex `c` (`c>b`) forms a triangle
`{a,b,c}` iff `c` is a set bit in `adj[a] & adj[b]`.

*Proof.*  
`c` is adjacent to `a` ⇔ bit `c` in `adj[a]` is `1`.  
`c` is adjacent to `b` ⇔ bit `c` in `adj[b]` is `1`.  
Both hold ⇔ bit `c` in the bitwise AND is `1`. ∎



**Lemma 2**  
For a fixed pair `(a,b)` the algorithm finds the smallest vertex `c>b`
that together with `a,b` forms a triangle, if such a vertex exists.

*Proof.*  
`common = adj[a] & adj[b]`. By Lemma&nbsp;1, the set bits of `common`
are exactly the feasible `c`.  
`mask = common >> (b+1)` discards all bits `≤ b`.  
If `mask ≠ 0`, its lowest set bit corresponds to the smallest remaining
vertex. `low = mask & -mask` isolates that bit, and its index is obtained by
`low.bit_length()-1`. Adding back the shift `(b+1)` yields the original vertex
number `c`. Hence the algorithm returns the minimal possible `c`. ∎



**Lemma 3**  
Let `T` be the triangle output by the algorithm, and let `T'` be any other
triangle. Then the sorted triple of `T` is lexicographically not larger than
that of `T'`.

*Proof.*  
Consider the sorted triples `(a,b,c)` of `T` and `(a',b',c')` of `T'`.
The algorithm processes all edges `(x,y)` with `x<y` in increasing order of
`x` then `y`.  
When it reaches edge `(a,b)`, by Lemma&nbsp;2 it chooses the smallest possible
`c>b` that completes a triangle, therefore `c` is the minimal third vertex
compatible with this pair.

If `a < a'`, then `(a,b,c)` is lexicographically smaller because the first
element is smaller.  
If `a = a'` but `b < b'`, again the first differing element is smaller.
If `a = a'` and `b = b'`, then `c` is the smallest possible third vertex for
this pair, so `c ≤ c'`.  
Thus in all cases `(a,b,c) ≤ (a',b',c')`. ∎



**Theorem**  
The algorithm outputs the lexicographically smallest sorted triple of vertices
that form a triangle.

*Proof.*  
Existence: the statement guarantees at least one triangle, so some edge
will have a non‑empty `mask`, and the algorithm will output a triangle.  

Minimality: by Lemma&nbsp;3 the produced triangle is not larger than any other
triangle, i.e. it is the lexicographically smallest. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency bitsets*: `O(m)`  
*Sorting edges*: `O(m log m)` ( `m ≤ 2·10⁵` )  
*Scanning edges*: each edge constant work → `O(m)`  

Memory: `n` bitsets, each an integer of ≤ 2000 bits → `O(n)` ≈ a few MB.

Both limits satisfy the problem constraints.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * n
    edges = []

    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u] |= 1 << v
        adj[v] |= 1 << u
        if u > v:
            u, v = v, u
        edges.append((u, v))

    edges.sort()                     # lexicographic order

    for a, b in edges:               # a < b
        common = adj[a] & adj[b]
        mask = common >> (b + 1)      # keep only vertices > b
        if mask:
            low = mask & -mask        # lowest set bit
            c = (low.bit_length() - 1) + (b + 1)
            print(a + 1, b + 1, c + 1)
            return

if __name__ == "__main__":
    solve()
```

to the required input‑output format.
