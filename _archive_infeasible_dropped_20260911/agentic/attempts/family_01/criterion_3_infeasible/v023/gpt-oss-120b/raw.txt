**Solution Explanation**

For every coil we store the set of coils that resonate with it.
The set is kept as a bitset – a Python `int` whose binary representation has
bit `i‑1` set iff coil `i` is a neighbour.

```
neigh[v]  – integer, bit i‑1 = 1  ⇔  (v , i) is an input edge
```

`n ≤ 2000`, therefore a bitset needs at most 2000 bits → one Python integer,
bit operations are O(1) on this size.

--------------------------------------------------------------------

#### Finding the lexicographically smallest triangle  

We need the smallest triple `a < b < c` such that all three edges exist.
We enumerate `a` from `1` to `n`.  
For a fixed `a` we look at its neighbours `b` with `b > a` (sorted list).
For each such pair `(a,b)` the common neighbours are

```
common = neigh[a] & neigh[b]          # bitwise AND
```

Only a neighbour `c` larger than `b` can give a valid triangle,
so we delete all bits `≤ b`:

```
mask = (1 << b) - 1          # bits 0 … b‑1 are 1
common = common & ~mask      # keep bits b … n‑1
```

If `common` is non‑zero, the lowest set bit corresponds to the smallest possible
`c`.  
The lowest set bit of a positive integer `x` is `x & -x`.  
Its index (0‑based) is `bit_length() - 1`.

```
low = common & -common
c   = low.bit_length()          # because bit 0 → coil 1, …, bit k → coil k+1
```

The first triple we encounter while iterating `a` then `b` is exactly the
lexicographically smallest one, because:

* `a` grows from the smallest possible,
* for a fixed `a` we try `b` in increasing order,
* for a fixed `(a,b)` we pick the smallest admissible `c`.

The problem guarantees that at least one triangle exists, so the algorithm
will always output a result.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest triangle.

---

**Lemma 1**  
For any pair of vertices `a < b`, after the masking step `common`
contains exactly the vertices `c` such that `c > b` and edges
`(a,c)` and `(b,c)` are present.

*Proof.*  
`neigh[a] & neigh[b]` contains all vertices adjacent to **both** `a` and `b`,
including those ≤ `b`.  
`mask = (1<<b)-1` has bits `0 … b‑1` set, i.e. vertices `1 … b`.  
`~mask` has bits `b … n‑1` set and lower bits cleared.  
Bitwise `&` with `~mask` removes all vertices `≤ b`. ∎



**Lemma 2**  
If after masking `common ≠ 0`, the vertex `c` obtained by
`low = common & -common` and `c = low.bit_length()` is the smallest vertex
`c > b` that together with `a,b` forms a triangle.

*Proof.*  
`common`’s set bits are exactly the admissible vertices (Lemma&nbsp;1).  
The lowest set bit of a positive integer is the smallest index among its set
bits. `low = common & -common` isolates that bit.  
`low.bit_length()` returns the index + 1, i.e. the vertex number.
Thus `c` is the smallest admissible vertex. ∎



**Lemma 3**  
When the algorithm outputs a triple `(a,b,c)`, it is a triangle
(`a<b<c` and all three edges are present).

*Proof.*  
`b` is taken from the neighbour list of `a`, therefore edge `(a,b)` exists.  
`c` is taken from `common`, which by Lemma&nbsp;1 guarantees edges `(a,c)` and
`(b,c)` and also `c>b`. Hence all three edges exist and `a<b<c`. ∎



**Lemma 4**  
Let `T* = (a*,b*,c*)` be the lexicographically smallest triangle.
The algorithm will output `T*`.

*Proof.*  
Consider the outer loop iteration with `a = a*`.  
All smaller `a` have no triangle (otherwise `T*` would not be minimal).
Inside this iteration, the inner loop examines neighbours `b` of `a*` in
increasing order. The first `b` that can belong to a triangle is `b*`,
because any `b < b*` together with `a*` cannot be completed to a triangle
(otherwise a smaller triangle would exist).

When processing `(a*,b*)` the masking step leaves exactly the vertices that
complete a triangle (Lemma&nbsp;1). Since `c*` is the smallest such vertex,
`common` is non‑empty and Lemma&nbsp;2 returns `c = c*`.  
Thus the algorithm outputs `(a*,b*,c*)`. ∎



**Theorem**  
The algorithm always prints the lexicographically smallest triple of
coils that form a triangle.

*Proof.*  
By Lemma&nbsp;3 any printed triple is a triangle.
By Lemma&nbsp;4 the triangle printed is exactly the lexicographically smallest
one. ∎

#### Complexity Analysis  

*Building bitsets*: `O(m)`  
*Neighbour lists*: also `O(m)`  

Main loops: for each edge `(a,b)` with `a<b` we perform a constant‑time
bitwise `AND`, a mask, and a few integer operations.
The number of such ordered pairs is exactly `m`.  

```
Time   :  O(m)          ( ≤ 2·10^5 )
Memory :  O(n) bitsets  ( n·2000 bits ≈ 0.5 MiB ) + adjacency lists
```

Both limits satisfy the given constraints.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    neigh = [0] * (n + 1)          # 1‑based
    adj = [[] for _ in range(n + 1)]

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        if u == v:
            continue
        # set bits
        neigh[u] |= 1 << (v - 1)
        neigh[v] |= 1 << (u - 1)
        # store for ordered iteration
        if u < v:
            adj[u].append(v)
        else:
            adj[v].append(u)

    for a in range(1, n + 1):
        # neighbours larger than a are already in adj[a] (by construction)
        for b in sorted(adj[a]):          # ensure increasing order
            # common neighbours of a and b
            common = neigh[a] & neigh[b]
            # keep only vertices > b
            mask = (1 << b) - 1            # bits 0..b-1 set
            common &= ~mask
            if common:
                low = common & -common      # lowest set bit
                c = low.bit_length()        # vertex number
                # a < b < c holds automatically
                print(a, b, c)
                return

if __name__ == "__main__":
    solve()
```

to the required input‑output format.
