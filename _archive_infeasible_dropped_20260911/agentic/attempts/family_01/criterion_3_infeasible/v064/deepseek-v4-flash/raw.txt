We can solve this by storing the graph as adjacency sets and then iterating over all possible triples in lexicographic order until we find a triangle.  

Since \( n \) can be up to 2000, checking all triples naively would be too slow. Instead, we can iterate over the first vertex \( a \), then over its neighbors \( b > a \), and then check if \( c \) is a common neighbor of both \( a \) and \( b \), with \( c > b \).  

We can speed up the common neighbor check using set intersection.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        for b in adj[a]:
            if b <= a:
                continue
            for c in adj[b]:
                if c <= b:
                    continue
                if c in adj[a]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
