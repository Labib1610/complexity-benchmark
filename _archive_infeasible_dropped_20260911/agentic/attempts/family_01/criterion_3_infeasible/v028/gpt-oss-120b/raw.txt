**Solution Explanation**

For every particle type `v` we store the set of types it resonates with.
Because `n ≤ 2000` the set fits into one Python integer – the `i`‑th bit
(`i = 0 … n‑1`) tells whether the edge `v – (i+1)` exists.

```
adj[v]  – integer, bit (u‑1) is 1  ⇔  edge v‑u exists
```

A *triangle* (resonance cascade) is a triple `a<b<c` such that

```
edge a‑b , edge a‑c , edge b‑c
```

The lexicographically smallest triangle is obtained by the first `a`
(for which a triangle exists), then the first `b>a`,
and finally the smallest possible `c>b`.
Scanning `a` and `b` in increasing order and always choosing the smallest
`c` guarantees the required order.

--------------------------------------------------------------------

#### Finding the smallest `c` for a fixed pair `(a,b)`

`adj[a] & adj[b]` is the set of vertices adjacent to **both** `a` and `b`.
We only need vertices larger than `b`:

```
mask = bits b, b+1, … , n   (1‑based numbers)
mask = (1<<n)-1  xor  ((1<<b)-1)
candidates = (adj[a] & adj[b]) & mask
```

If `candidates` is non‑zero, its lowest set bit is the smallest admissible
`c`. The lowest bit of an integer `x` is obtained by `x & -x`;
its position (1‑based) is ` (x & -x).bit_length() `.

--------------------------------------------------------------------

#### Algorithm
```
read n , m
adj[1…n] = 0
for each edge u‑v:
        set the corresponding bits in adj[u] and adj[v]

full = (1<<n) - 1          # bits 0 … n‑1 are 1

for a = 1 … n-2:                     # a must have at least two larger vertices
        for b = a+1 … n-1:
                if edge a‑b does not exist: continue
                common = adj[a] & adj[b]
                mask   = full ^ ((1<<b) - 1)      # bits for vertices > b
                cand   = common & mask
                if cand != 0:
                        low = cand & -cand        # lowest set bit
                        c   = low.bit_length()    # vertex number
                        output a b c
                        stop
```

The first printed triple is the lexicographically smallest triangle,
because the loops enumerate `(a,b)` in lexicographic order and for each
pair the smallest possible `c` is chosen.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
triangle.

---

##### Lemma 1  
For fixed vertices `a<b`, if `cand = (adj[a] & adj[b])` contains a vertex
`c>b`, then `a,b,c` form a triangle.

**Proof.**  
`c ∈ adj[a]`  ⇒ edge `a‑c` exists.  
`c ∈ adj[b]`  ⇒ edge `b‑c` exists.  
By the outer test we already know edge `a‑b` exists. ∎



##### Lemma 2  
For fixed `a<b` the algorithm, if it finds a vertex `c`, returns the
smallest possible `c` that is larger than `b` and together with `a,b`
forms a triangle.

**Proof.**  
`cand` consists exactly of vertices adjacent to both `a` and `b` and larger
than `b` (the mask removes all `≤b`).  
If `cand≠0`, its lowest set bit corresponds to the smallest vertex in the
set, because bits are ordered by vertex number. The algorithm extracts that
bit and returns its vertex number, which is therefore the smallest feasible
`c`. ∎



##### Lemma 3  
If the algorithm outputs a triple `(a,b,c)`, then it is a triangle and is
lexicographically minimal among all triangles.

**Proof.**  
By Lemma&nbsp;1 the triple is a triangle.  
Assume there exists another triangle `(a',b',c')` that is lexicographically
smaller.
*If `a' < a`*: the outer loop would encounter `a'` before `a`.  
*If `a' = a` and `b' < b`*: the inner loop would encounter `b'` before `b`.  
*If `a' = a`, `b' = b` and `c' < c`*: Lemma&nbsp;2 tells the algorithm would
have returned `c'` instead of `c`.  
All three possibilities contradict the moment the algorithm stops.
Hence no lexicographically smaller triangle exists. ∎



##### Lemma 4  
If at least one triangle exists, the algorithm will output one.

**Proof.**  
Let `(a*,b*,c*)` be the lexicographically smallest triangle.
When the outer loop reaches `a = a*` and the inner loop reaches `b = b*`,
edge `a‑b` is present, so the algorithm examines `cand`.
Since `c* > b*` and `c*` is adjacent to both `a*` and `b*`,
`c*` belongs to `cand`, therefore `cand ≠ 0`.
Consequently the algorithm outputs a triangle (Lemma&nbsp;2) and stops. ∎



##### Theorem  
The algorithm always terminates and prints the lexicographically smallest
triple of distinct vertices that are pairwise adjacent.

**Proof.**  
Termination follows from the finite double loop.  
Existence of an output is guaranteed by Lemma&nbsp;4.
When an output is produced, Lemma&nbsp;3 shows it is a triangle and
lexicographically minimal. ∎

#### Complexity Analysis  

`n ≤ 2000`.

The double loop iterates over all ordered pairs `a<b`, i.e.  
`n·(n‑1)/2 ≤ 2·10⁶` iterations.

All operations inside the loops are constant‑time bitwise operations on
Python integers of at most 2000 bits.

```
Time   :  O(n²)   ≤ 2·10⁶ elementary operations  (well below 2 s)
Memory :  O(n)    adjacency integers (≈ 2000·256 bits ≈ 64 KB)
```

Both limits satisfy the problem constraints.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = list(map(int, sys.stdin.read().split()))
    it = iter(data)
    n = next(it)
    m = next(it)

    adj = [0] * (n + 1)          # adjacency as bitsets
    for _ in range(m):
        u = next(it)
        v = next(it)
        adj[u] |= 1 << (v - 1)
        adj[v] |= 1 << (u - 1)

    full_mask = (1 << n) - 1     # bits 0 .. n-1 are 1

    for a in range(1, n - 1):
        bits_a = adj[a]
        for b in range(a + 1, n):
            # edge a‑b ?
            if not ((bits_a >> (b - 1)) & 1):
                continue
            common = bits_a & adj[b]
            # mask vertices > b (indices b .. n-1)
            mask = full_mask ^ ((1 << b) - 1)
            cand = common & mask
            if cand:
                low = cand & -cand          # lowest set bit
                c = low.bit_length()        # vertex number (1‑based)
                sys.stdout.write(f"{a} {b} {c}\n")
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
