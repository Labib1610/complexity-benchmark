**Solution Explanation**

For every component `v` we store the set of its reactive partners.
Because `n ≤ 2000` we can keep each set as a bit mask inside a Python
integer – bit `i` (0‑based) is `1` iff component `v` reacts with component
`i+1`.

A required certificate is a triangle `a < b < c` such that all three edges
exist.
The lexicographically smallest triangle is obtained by the following
enumeration order:

```
for a = 1 … n
    for every neighbour b of a with b > a   (in increasing order)
        find the smallest c > b that is neighbour of both a and b
        output a b c
```

If we already know the neighbour sets of `a` and `b` as bit masks,
the common neighbours are simply the bitwise **and** of the two masks.
To restrict to vertices larger than `b` we shift the mask right by `b`
positions and look at the lowest set bit.

All operations are O(1) on the integer masks, therefore the whole algorithm
runs in `O(m)` time (each edge is examined once) and uses `O(n)` memory.



--------------------------------------------------------------------

#### Algorithm
```
read n, m
adj_mask[0…n-1] = 0                     # integer masks
adj_list[0…n-1] = []                     # neighbour lists (sorted)

for each edge (u, v):
    u--, v--                             # to 0‑based
    set the bits in both masks
    adj_mask[u] |= 1 << v
    adj_mask[v] |= 1 << u
    append v to adj_list[u], u to adj_list[v]

for a from 0 to n-1:
    sort adj_list[a]                     # ensures increasing order
    for b in adj_list[a]:
        if b <= a: continue               # we need a < b
        common = adj_mask[a] & adj_mask[b]   # vertices adjacent to both
        # keep only vertices > b
        common >>= (b + 1)
        if common == 0: continue
        # lowest set bit gives the smallest possible c
        low_bit = common & -common
        c = (b + 1) + (low_bit.bit_length() - 1)
        output a+1, b+1, c+1 and terminate
```

The first triangle found is exactly the lexicographically smallest one,
because the outer loops enumerate `a` then `b` in increasing order,
and for a fixed pair `(a,b)` we pick the smallest possible `c`.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest triangle
`(a,b,c)` with `a<b<c` and all three edges present.

---

**Lemma 1**  
For any vertices `x` and `y` the expression  
`adj_mask[x] & adj_mask[y]` has a set bit at position `z` (0‑based)  
iff edges `x–z` and `y–z` both exist.

*Proof.* By construction `adj_mask[x]` has exactly the bits of neighbours of
`x`. The bitwise **and** keeps a bit only if it is set in both masks,
i.e. `z` is neighbour of both `x` and `y`. ∎



**Lemma 2**  
After shifting `common = (adj_mask[a] & adj_mask[b]) >> (b+1)`,
the lowest set bit of `common` corresponds to the smallest vertex `c`
such that `c > b` and edges `a–c` and `b–c` exist.

*Proof.* By Lemma&nbsp;1 the unshifted mask contains exactly the common
neighbours of `a` and `b`. Shifting right by `b+1` discards all bits
with index ≤ `b`. Hence the remaining bits represent precisely the common
neighbours larger than `b`. The lowest set bit among them is the smallest
such vertex. ∎



**Lemma 3**  
When the algorithm reaches a pair `(a,b)` with `a<b` and finds a vertex
`c` as described in Lemma&nbsp;2, the triple `(a,b,c)` is a triangle.

*Proof.* By Lemma&nbsp;2, `c` is a common neighbour of `a` and `b`,
so edges `a–c` and `b–c` exist. The outer loop guarantees that edge
`a–b` exists because `b` is taken from `adj_list[a]`. Therefore all three
edges are present, i.e. `(a,b,c)` is a triangle. ∎



**Lemma 4**  
The algorithm outputs the lexicographically smallest triangle.

*Proof.*  
The outermost loop iterates `a` from `1` to `n`.  
For a fixed `a`, the inner loop iterates `b` over all neighbours of `a`
with `b>a` in increasing order.  
Thus the algorithm examines all possible pairs `(a,b)` in the exact order
required for lexicographic comparison of the first two components.

For a given pair `(a,b)` Lemma&nbsp;2 yields the smallest feasible `c`.
Consequently, the first triangle discovered by the algorithm has the
smallest possible `a`; if several triangles share that `a`, it has the
smallest possible `b`; and among those it has the smallest possible `c`.
Hence it is the lexicographically smallest triangle. ∎



**Theorem**  
The algorithm always terminates and prints three integers `a<b<c`
such that all three edges `a–b`, `a–c`, `b–c` are present, and the printed
triplet is the lexicographically smallest among all such triplets.

*Proof.*  
Existence of at least one triangle is guaranteed by the problem statement,
so the loops will eventually encounter a pair `(a,b)` belonging to some
triangle, and Lemma&nbsp;2 ensures a corresponding `c` is found, causing
termination.

By Lemma&nbsp;3 the printed triple is a triangle.
By Lemma&nbsp;4 it is the lexicographically smallest one. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building masks and lists*: `O(m)` time, `O(n)` memory.  
*Search*: each edge `(a,b)` with `a<b` is examined once, all operations on
bit masks are `O(1)`. Hence total time `O(m)`.  
Memory consumption: one integer mask per vertex (`≈ n·2000/8` bytes) plus
adjacency lists, well within the limits (`O(n + m)`).

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj_mask = [0] * n          # bit masks
    adj_list = [[] for _ in range(n)]

    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj_mask[u] |= 1 << v
        adj_mask[v] |= 1 << u
        adj_list[u].append(v)
        adj_list[v].append(u)

    for a in range(n):
        adj_list[a].sort()
        mask_a = adj_mask[a]
        for b in adj_list[a]:
            if b <= a:
                continue
            # common neighbours of a and b
            common = mask_a & adj_mask[b]
            # keep only vertices > b
            common >>= (b + 1)
            if common == 0:
                continue
            # lowest set bit -> smallest c
            low = common & -common
            c = (b + 1) + (low.bit_length() - 1)
            # output 1‑based
            sys.stdout.write(f"{a+1} {b+1} {c+1}")
            return

if __name__ == "__main__":
    solve()
```
