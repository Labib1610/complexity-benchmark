**Solution Explanation**

For the given durations `d1 … dn`

* let `S = sum di`
* let `H = S/2` (integer because we only need the answer when `S` is even)

Exactly one of the following statements is true for every test case
(because the problem guarantees that a partition does **not** exist).

1. `S` is odd → impossible for two equal integer sums.  
   Certificate: `ODD`
2. Some task is longer than `H`.  
   Certificate: `MAX`
3. All tasks have a common divisor `g ≥ 2` that does **not** divide `H`.  
   Certificate: `MOD g`

The three tests are independent, we may output any that holds.

--------------------------------------------------------------------

#### Algorithm
```
read n and the array a
S = sum(a)

if S is odd:
        print "ODD"
        stop

H = S // 2
if max(a) > H:
        print "MAX"
        stop

g = gcd of all numbers in a          # Euclidean algorithm, O(n)
# the statement of the problem guarantees that now
# g ≥ 2 and H % g != 0
print "MOD g"
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm always prints a correct certificate.

---

##### Lemma 1  
If `S` is odd, no partition into two equal integer sums exists.

**Proof.** Two equal integers add up to an even number. ∎



##### Lemma 2  
If some task duration `di` is larger than `S/2`, no partition exists.

**Proof.** In any partition the machine that receives this task already has
total time `> S/2`. The other machine can never catch up, because the whole
sum is `S`. ∎



##### Lemma 3  
Let `g = gcd(d1,…,dn)`.  
If `g ≥ 2` and `g ∤ (S/2)`, then no partition exists.

**Proof.** Every task duration is a multiple of `g`, therefore the total time
on each machine must also be a multiple of `g`. The required common sum is
`S/2`, which is **not** a multiple of `g`; contradiction. ∎



##### Lemma 4  
If the algorithm reaches the third step, then `g ≥ 2` and `g ∤ (S/2)`.

**Proof.**  
*Reaching step 3* means:

* `S` is even,
* `max(ai) ≤ S/2`.

The problem statement guarantees that at least one of the three reasons is
true and the first two are false, therefore the third one must be true.
Consequently there exists a divisor `d ≥ 2` of all numbers that does **not**
divide `S/2`. The greatest common divisor `g` also divides all numbers,
so `d` divides `g`. If `g` itself divided `S/2`, every divisor of `g`
(including `d`) would also divide `S/2`, contradicting the definition of `d`.
Hence `g ≥ 2` and `g ∤ (S/2)`. ∎



##### Lemma 5  
When the algorithm prints `MOD g`, the certificate is valid.

**Proof.** By Lemma&nbsp;4 the printed `g` satisfies the condition of
Lemma&nbsp;3, which is exactly the required certificate. ∎



##### Theorem  
The algorithm always outputs a line that correctly certifies the impossibility
of splitting the tasks equally.

**Proof.**  
The algorithm distinguishes three exhaustive cases, each handled by a
different `if` branch.

* If `S` is odd → Lemma&nbsp;1 → output `ODD` is correct.
* Else, if a task exceeds `S/2` → Lemma&nbsp;2 → output `MAX` is correct.
* Else → Lemma&nbsp;5 → output `MOD g` is correct.

One of the branches is always taken, therefore the output is always a valid
certificate. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

* Computing the sum, the maximum and the gcd: `O(n)` time.  
* Only a few integer variables are stored: `O(1)` additional memory.

Both limits satisfy the required constraints (`n ≤ 10^5`).

#### Reference Implementation  (Python 3)

```python
import sys
import math

def solve() -> None:
    data = list(map(int, sys.stdin.read().split()))
    n = data[0]
    a = data[1:]

    total = sum(a)

    # 1. odd total
    if total & 1:
        print("ODD")
        return

    half = total // 2

    # 2. a task longer than half
    if max(a) > half:
        print("MAX")
        return

    # 3. common divisor that does not divide half
    g = 0
    for v in a:
        g = math.gcd(g, v)

    # problem guarantee ensures this condition holds here
    print(f"MOD {g}")

if __name__ == "__main__":
    solve()
```

and conforms to the required input‑output format.
