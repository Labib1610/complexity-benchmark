We need to find **k+1** pairwise independent corridors (edges that share no vertices).  

A simple greedy approach works:  
- Iterate through the edges.  
- Keep an edge if neither of its endpoints has been used yet.  
- Stop once we have **k+1** edges.  

Since the problem guarantees that at least **k+1** such edges exist, this greedy will always succeed.  

```python
import sys

def main():
    input = sys.stdin.readline
    n, m, k = map(int, input().split())
    edges = []
    for _ in range(m):
        u, v = map(int, input().split())
        edges.append((u, v))
    
    used = [False] * (n + 1)
    result = []
    
    for u, v in edges:
        if not used[u] and not used[v]:
            used[u] = True
            used[v] = True
            result.append((u, v))
            if len(result) == k + 1:
                break
    
    for u, v in result:
        print(u, v)

if __name__ == "__main__":
    main()
```
