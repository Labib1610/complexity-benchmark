We can solve this by simply tracking which specialists appear in any combination.  
Since the problem guarantees at least one specialist is missing, we just find the smallest one.

```python
k, t = map(int, input().split())
seen = [False] * (k + 1)

for _ in range(t):
    x, y, z = map(int, input().split())
    seen[x] = True

for i in range(1, k + 1):
    if not seen[i]:
        print(i)
        break
```
