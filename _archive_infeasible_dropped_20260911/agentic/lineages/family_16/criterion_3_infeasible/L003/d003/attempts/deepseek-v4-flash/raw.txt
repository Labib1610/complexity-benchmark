We can check the two possible certificate types directly:

- **JOB i**: If `p1 + p2 > T`, then that job alone exceeds the deadline.
- **LOAD c**: If the sum of all `p1` > T, then stage 1 alone exceeds; if sum of all `p2` > T, then stage 2 alone exceeds.

Since the problem guarantees at least one applies, we can check in order: first any job exceeding T, then stage loads.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    idx = 2
    sum1 = 0
    sum2 = 0
    jobs = []
    for i in range(j):
        p1 = int(data[idx])
        p2 = int(data[idx+1])
        idx += 2
        jobs.append((p1, p2))
        sum1 += p1
        sum2 += p2
        if p1 + p2 > T:
            print(f"JOB {i+1}")
            return
    if sum1 > T:
        print("LOAD 1")
        return
    if sum2 > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
