<METHOD_NAME>Pure Algebraic Subsystem Isolation</METHOD_NAME>
<METHOD_DESCRIPTION>Removes all scheduling terminology (jobs, machines, durations, deadlines) and explicit mentions of sums. Presents the problem purely as finding a minimal infeasible subsystem of linear inequalities. Models must independently deduce that the algebraic constraints describe bounded disjoint intervals, and thus derive the `sum > T` conditions, rather than pattern-matching the text.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of inequalities over the real numbers. For a given integer $j$, there are $4j$ variables: $x_{i,1}, y_{i,1}, x_{i,2}, y_{i,2}$ for $1 \le i \le j$.
You are given a constant $T$ and a matrix $D$ of size $j \times 2$.

The full system of constraints is defined as follows:

- **(A)** $y_{i,c} - x_{i,c} \ge D_{i,c}$ for all $1 \le i \le j$ and $c \in \{1, 2\}$
- **(B)** $x_{i,c} \ge 0$ for all $1 \le i \le j$ and $c \in \{1, 2\}$
- **(C)** $y_{i,c} \le T$ for all $1 \le i \le j$ and $c \in \{1, 2\}$
- **(D)** $x_{i,2} - y_{i,1} \ge 0$ for all $1 \le i \le j$
- **(E)** $\max(x_{u,c} - y_{v,c}, x_{v,c} - y_{u,c}) \ge 0$ for all $c \in \{1, 2\}$ and all pairs of distinct indices $u, v \in \{1, \dots, j\}$

It is guaranteed that the full system has no solution in $\mathbb{R}^{4j}$.
Your task is to identify a minimal infeasible subsystem. For every test input, exactly one of the following specific subsystems is guaranteed to be infeasible on its own. You must output the label of the one that is infeasible:

* `JOB i` (where $i$ is a 1-based index): The subsystem restricted to the variables $x_{i,1}, y_{i,1}, x_{i,2}, y_{i,2}$ and consisting exactly of the constraints (A), (B), (C) for this specific $i$ and both $c \in \{1, 2\}$, along with constraint (D) for this specific $i$.
* `LOAD c` (where $c$ is either 1 or 2): The subsystem restricted to the variables $x_{k,c}, y_{k,c}$ for all $1 \le k \le j$, consisting exactly of the constraints (A), (B), (C) for all $k$ at this specific $c$, along with constraint (E) for all pairs of distinct indices $u, v$ at this specific $c$.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers, representing $D_{i,1}$ and $D_{i,2}$ respectively for $1 \le i \le j$ ($1 \le D_{i,1}, D_{i,2} \le 1000000$).

## Output

Print a single line containing either `JOB i` (if the isolated subsystem for $i$ is infeasible) or `LOAD c` (if the isolated subsystem for $c$ is infeasible).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, the subsystem for `JOB 1` consists of $y_{1,1} - x_{1,1} \ge 70$, $x_{1,1} \ge 0$, $y_{1,1} \le 100$, $y_{1,2} - x_{1,2} \ge 60$, $x_{1,2} \ge 0$, $y_{1,2} \le 100$, and $x_{1,2} - y_{1,1} \ge 0$. This specific set of inequalities admits no simultaneous real solution for $x_{1,1}, y_{1,1}, x_{1,2}, y_{1,2}$.
In Example 2, the subsystem for `LOAD 1` over the 8 variables $x_{k,1}, y_{k,1}$ ($1 \le k \le 4$) with $D_{k,1} = 50$ and $T = 150$, including the pairwise constraints (E), admits no simultaneous real solution.
</STATEMENT>
<RATIONALE>
I transformed the problem from a scheduling scenario with explicit sum-based certificates into a pure algebraic system of inequalities. I removed all explanatory notes that explicitly linked the certificates to row/column sums. This forces the model to mathematically analyze the subsystems to deduce that they represent bounded disjoint intervals, and thus derive the `sum > T` conditions themselves.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic inequalities are mathematically identical to the original temporal constraints (start/end times, durations, sequential stages, mutual exclusion), so the conditions for a subsystem to be infeasible (sum of durations exceeding T) remain exactly the same for every input.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires identifying a single impossible constraint subsystem, which is solvable in O(N) time by checking the implicitly required sums, keeping it in the same complexity class.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the `max` formulation in constraint (E) if they don't recognize it as a standard disjunction for non-overlapping intervals, though mathematically it is unambiguous.
</RISK>
