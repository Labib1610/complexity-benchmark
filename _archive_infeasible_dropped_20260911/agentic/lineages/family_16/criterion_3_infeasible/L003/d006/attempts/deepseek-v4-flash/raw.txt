We can check each possible certificate type directly:

- **JOB i**: For a single signal, the earliest possible finish time in stage 2 is  
  \( D_{i,1} + D_{i,2} \). If this exceeds \( T \), then `JOB i` is valid.
- **LOAD c**: For a single stage, the total processing time of all signals in that stage is  
  \(\sum D_{i,c}\). If this exceeds \( T \), then `LOAD c` is valid.

Since the problem guarantees exactly one type applies, we can check in order.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    durations = []
    idx = 2
    for _ in range(j):
        p1 = int(data[idx])
        p2 = int(data[idx+1])
        idx += 2
        durations.append((p1, p2))
    
    # Check JOB certificates
    for i, (p1, p2) in enumerate(durations, start=1):
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
    
    # Check LOAD certificates
    sum1 = sum(p1 for p1, _ in durations)
    sum2 = sum(p2 for _, p2 in durations)
    if sum1 > T:
        print("LOAD 1")
        return
    if sum2 > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
