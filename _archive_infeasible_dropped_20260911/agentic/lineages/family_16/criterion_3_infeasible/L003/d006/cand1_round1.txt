<STATEMENT>
# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a mathematical constraint system over $2j$ subsets of the real line. The subsets are denoted as $I_{i,c}$ for $i \in \{1, \dots, j\}$ and $c \in \{1, 2\}$. Each subset is required to be a finite union of closed intervals. Let $\mu(S)$ denote the total length (Lebesgue measure) of a subset $S$.

You are provided with a bounding constant $T$ and a $j \times 2$ matrix $D$. A valid assignment of these subsets must satisfy all of the following axioms:

- **Measure Axiom:** For all $i$ and $c$, $\mu(I_{i,c}) \ge D_{i,c}$.
- **Precedence Axiom:** For all $i$, $\sup(I_{i,1}) \le \inf(I_{i,2})$. (Every real number in $I_{i,1}$ is less than or equal to every real number in $I_{i,2}$.)
- **Disjointness Axiom:** For a fixed $c$, the intersection of any two different subsets has measure zero. That is, $\mu(I_{i,c} \cap I_{k,c}) = 0$ for all $i \neq k$.
- **Bounding Axiom:** For all $i$ and $c$, $I_{i,c} \subseteq [0, T]$.

For every test input, it is guaranteed that no valid assignment of subsets exists. Your task is to output a short certificate that isolates a contradictory subsystem. For every test input, exactly one of these certificate types is guaranteed to apply. Print exactly the one that holds:

* `JOB i` (where **i** is a 1-based index): The axioms restricted only to the subsets $I_{i,1}$ and $I_{i,2}$ (Measure, Precedence, and Bounding) are inherently contradictory.
* `LOAD c` (where **c** is either 1 or 2): The axioms restricted only to the subsets $I_{1,c}, I_{2,c}, \dots, I_{j,c}$ (Measure, Disjointness, and Bounding) are inherently contradictory.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers $D_{i,1}$ and $D_{i,2}$ (1 ≤ $D_{i,1}$, $D_{i,2}$ ≤ 1000000): representing the minimum required measures for $I_{i,1}$ and $I_{i,2}$ respectively.

## Output

Print a single line containing either `JOB i` (where the restricted subsystem for index **i** across both $c$ is contradictory) or `LOAD c` (where the restricted subsystem for index **c** across all $i$ is contradictory).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
</STATEMENT>
<RATIONALE>
Removed all explicit row/column sum formulas and replaced the temporal scheduling domain with a formal measure-theoretic constraint system over subsets of the real line. Models can no longer pattern-match explicit sum conditions from the text or rely on intuition about "jobs" and "stages", and must instead formally deduce that the Precedence Axiom implies a row sum bound and the Disjointness Axiom implies a column sum bound.
</RATIONALE>
<PRESERVED_ANSWER>
The Precedence Axiom forces $I_{i,1}$ strictly to the left of $I_{i,2}$, meaning their combined measure cannot exceed the bounding interval exactly when $D_{i,1} + D_{i,2} > T$; similarly, the Disjointness Axiom forces subsets to be mutually exclusive, meaning their union's measure exceeds the bounding interval exactly when the column sum exceeds $T$.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains an INFEASIBLE certificate check, solvable in linear time by checking row sums and column sums against $T$.
</PRESERVED_CLASS>
<RISK>
Models might struggle with the definition of supremum and infimum for empty sets, but since the Measure Axiom requires $D_{i,c} \ge 1$, the subsets are guaranteed to be non-empty, making the mathematical definitions perfectly rigorous and unambiguous.
</RISK>
