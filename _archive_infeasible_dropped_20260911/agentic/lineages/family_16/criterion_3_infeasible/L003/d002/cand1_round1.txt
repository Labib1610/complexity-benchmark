<STATEMENT>
# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A system processes **j** jobs through exactly two sequential stages. Every job must clear stage 1 completely before it can enter stage 2. For each job, you are given its required duration in stage 1 and in stage 2. A stage can only advance one job at any given moment.

There is a required time limit **T**: every job must be completely finished by time **T** (starting from time 0).

For every input in this problem, it is guaranteed that the time limit cannot be met, no matter how the jobs are ordered. Your task is to prove the time limit is impossible by outputting a short certificate that identifies a fundamental bottleneck. 

Exactly one of the following bottlenecks will be present. Print the one that holds:

**Sequential constraint violation:** A single job cannot meet the deadline due to its own sequential processing requirements, even if all other jobs were removed from the system. If this is the case, print `JOB i`, where **i** (1-based index) is a job that cannot finish in time.

**Capacity constraint violation:** A single stage cannot process all of its assigned work within the deadline, because it processes jobs serially and the total volume of work assigned to it exceeds the available time window. If this is the case, print `LOAD c`, where **c** is the stage number (1 or 2) that has too much work.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the durations of a job in stage 1 and stage 2.

## Output

Print a single line containing either `JOB i` (where job **i**'s sequential processing requirement exceeds **T**) or `LOAD c` (where the total serial workload for stage **c** exceeds **T**).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, job 1 requires 70 units in stage 1 and 60 in stage 2. Because a single job's stages cannot overlap, it requires 130 units of continuous processing, exceeding the 100 limit. Thus, `JOB 1` proves the deadline is impossible. 
In Example 2, no single job exceeds the limit on its own. However, stage 1 must process four jobs serially at 50 units each. The total load on stage 1 is 200 units, exceeding the 150 limit, so `LOAD 1` is the certificate.
