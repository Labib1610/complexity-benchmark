<STATEMENT>
# Problem C — Impossible Signal Routing

Time limit: 2 s   Memory limit: 256 MB

## Description

You are configuring a two-stage signal routing protocol. The system has two data channels, Channel 1 and Channel 2. Each channel has a transmission window of exactly **T** microseconds, with timestamps running from $0$ to $T$.

There are **j** data streams that need to be routed. Each stream $i$ (for $1 \le i \le j$) consists of a primary packet requiring $p_{i,1}$ microseconds of transmission time, and a secondary packet requiring $p_{i,2}$ microseconds.

A fully valid routing configuration must assign a starting timestamp to every packet, satisfying all of the following rules:
- **Window Bounds:** Every packet must be transmitted entirely within the $0$ to $T$ window. (i.e., start time $\ge 0$, and start time + packet time $\le T$).
- **Channel Assignment:** All primary packets are transmitted on Channel 1. All secondary packets are transmitted on Channel 2.
- **Interference-Free:** Packets on the same channel cannot overlap in time.
- **Causality:** For every stream $i$, its secondary packet cannot begin transmission until its primary packet has completely finished transmitting.

For every test input, it is guaranteed that no fully valid routing configuration exists. Your task is to output a short certificate that proves the requirements are contradictory.

To do this, you must identify the fundamental bottleneck by finding which of the following isolated algebraic systems has no valid real-valued solution. Exactly one of these systems is guaranteed to be unsolvable. Print the certificate for the one that holds:

* `JOB i` (where **i** is a 1-based index, $1 \le i \le j$): The causality system for stream $i$. We seek two real numbers $u$ and $v$ (representing the start times for stream $i$'s primary and secondary packets) such that:
  - $0 \le u$
  - $u + p_{i,1} \le v$
  - $v + p_{i,2} \le T$

* `LOAD c` (where **c** is either 1 or 2): The interference-free system for Channel $c$. We seek $j$ real numbers $x_1, x_2, \dots, x_j$ (representing the start times for all packets on Channel $c$) such that:
  - For all $k \in \{1, \dots, j\}$, $0 \le x_k$ and $x_k + p_{k,c} \le T$.
  - For every pair of distinct indices $k$ and $m$, either $x_k + p_{k,c} \le x_m$ or $x_m + p_{m,c} \le x_k$.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing $p_{i,1}$ and $p_{i,2}$ respectively for stream $i$.

## Output

Print a single line containing either `JOB i` (where **i** is a 1-based index, $1 \le i \le j$) or `LOAD c` (where **c** is either 1 or 2), corresponding to the unique algebraic system that has no solution.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is the correct certificate. The causality system for stream 1 requires finding start times $u$ and $v$ such that $0 \le u$, $u + 70 \le v$, and $v + 60 \le 100$. No such real numbers exist that satisfy all three inequalities simultaneously. Thus, this isolated system is unsolvable.

In Example 2, `LOAD 1` is the correct certificate. The interference-free system for Channel 1 requires finding four non-negative start times $x_1, x_2, x_3, x_4$ such that each packet of length 50 finishes by $T=150$, and for any distinct pair, one must finish before the other starts. No such set of four real numbers exists. Thus, this isolated system is unsolvable.
</STATEMENT>
<RATIONALE>
Replaced the narrative descriptions of "waived rules" and "infinite machines" with exact algebraic coordinate systems. This forces the model to mathematically deduce that the `JOB i` inequalities are equivalent to `p1 + p2 > T` and the `LOAD c` inequalities are equivalent to `sum > T`, removing the semantic keywords that allowed surface pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The causality system is mathematically unsolvable if and only if $p_{i,1} + p_{i,2} > T$, and the interference-free system is unsolvable if and only if the sum of all $p_{k,c}$ exceeds $T$, which are exactly the conditions for the original `JOB i` and `LOAD c` certificates.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity remains O(N) as the solution still only requires checking sums and individual pairs against T.
</PRESERVED_CLASS>
