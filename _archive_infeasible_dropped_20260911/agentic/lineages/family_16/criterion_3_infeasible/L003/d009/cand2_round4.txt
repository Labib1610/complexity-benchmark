<STATEMENT>
# Problem C — Impossible Ferry Loading

Time limit: 2 s   Memory limit: 256 MB

## Description

You are the loading master for a cargo ferry. The ferry has two parallel parking lanes, Lane 1 and Lane 2. Each lane has a usable parking length of exactly **T** meters. 

There are **j** transport teams that need to board. Each team $i$ (for $1 \le i \le j$) consists of a primary vehicle of length $p_{i,1}$ meters and a secondary vehicle of length $p_{i,2}$ meters. 

A valid parking configuration must assign a center coordinate $C_{i,k} \in \mathbb{R}$ to each vehicle $k \in \{1, 2\}$ of each team $i$, where $k=1$ represents Lane 1 (primary vehicles) and $k=2$ represents Lane 2 (secondary vehicles). The assignment is valid if and only if it satisfies the following system of physical inequalities:

- **Bounds:** Every vehicle must be fully contained within the $0$ to $T$ coordinate bounds. Algebraically, for all $i$ and $k$:
  $2 \cdot C_{i,k} \ge p_{i,k}$  and  $2 \cdot C_{i,k} \le 2T - p_{i,k}$
- **Collision Avoidance:** Vehicles parked in the same lane cannot overlap. For any two distinct teams $x$ and $y$, their vehicles in the same lane $k$ must satisfy:
  $4 \cdot (C_{x,k} - C_{y,k})^2 \ge (p_{x,k} + p_{y,k})^2$
- **Team Sequence:** For every team $i$, the primary vehicle must be parked completely ahead of its secondary vehicle:
  $2 \cdot (C_{i,2} - C_{i,1}) \ge p_{i,1} + p_{i,2}$

For every test input, it is guaranteed that no valid parking configuration exists. Your task is to output a short certificate that proves the system of inequalities is contradictory. 

To do this, you must identify the fundamental bottleneck by finding which of the following relaxed algebraic systems is still impossible to satisfy. Exactly one of these systems is guaranteed to remain contradictory. Print the certificate for the one that holds:

* `JOB i` (where **i** is a 1-based index, $1 \le i \le j$): The "Team $i$ Isolation" system. In this system, the Collision Avoidance inequalities are removed for all variables. Furthermore, the Team Sequence inequality is removed for all teams EXCEPT team $i$. (The Bounds inequalities remain in effect for all variables).
* `LOAD c` (where **c** is either 1 or 2): The "Lane $c$ Isolation" system. In this system, the Team Sequence inequalities are removed entirely. The Collision Avoidance inequalities are removed for lane $3-c$, but remain in effect for all pairs of vehicles in lane $c$. (The Bounds inequalities remain in effect for all variables).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing $p_{i,1}$ and $p_{i,2}$ respectively for team $i$.

## Output

Print a single line containing either `JOB i` (where **i** is a 1-based index, $1 \le i \le j$) or `LOAD c` (where **c** is either 1 or 2), corresponding to the unique relaxed system that remains contradictory.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is the correct certificate. Under the Team 1 Isolation system, we only need to satisfy the Bounds inequalities for all variables, and the strict Team Sequence inequality for team 1. However, team 1's variables $C_{1,1}$ and $C_{1,2}$ must satisfy $2 \cdot C_{1,1} \ge 70$, $2 \cdot C_{1,2} \le 200 - 60$, and $2 \cdot (C_{1,2} - C_{1,1}) \ge 70 + 60$. This subsystem is algebraically contradictory. Thus, this system remains impossible.

In Example 2, `LOAD 1` is the correct certificate. Under the Lane 1 Isolation system, the Team Sequence inequalities are removed. However, we still must assign coordinates to all four primary vehicles in Lane 1 such that the Bounds and Collision Avoidance inequalities are satisfied. This requires packing four non-overlapping segments of length 50 into a domain of capacity 150, which is mathematically impossible. Thus, this system remains impossible.
