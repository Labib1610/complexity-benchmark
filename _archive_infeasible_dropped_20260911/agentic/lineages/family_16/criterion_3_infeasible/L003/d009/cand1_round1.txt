<STATEMENT>
# Problem C — Impossible Ferry Loading

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a cargo ferry's parking capacity using a continuous mathematical model. The ferry has two parallel parking lanes, modeled as the real interval $[0, T]$.
There are **j** transport teams. Each team $i$ (for $1 \le i \le j$) requires space for a primary vehicle of length $p_{i,1}$ and a secondary vehicle of length $p_{i,2}$.

A valid parking configuration is an assignment of Lebesgue-measurable sets $S_{i,1} \subset \mathbb{R}$ and $S_{i,2} \subset \mathbb{R}$ for each team $i$, satisfying all of the following axioms:
- **Measure:** For every team $i$, the Lebesgue measure of $S_{i,1}$ is exactly $p_{i,1}$, and the Lebesgue measure of $S_{i,2}$ is exactly $p_{i,2}$.
- **Domain:** For every team $i$, $S_{i,1} \subset [0, T]$ and $S_{i,2} \subset [0, T]$.
- **Lane 1 Exclusion:** For any two distinct teams $a$ and $b$ ($a \neq b$), $S_{a,1} \cap S_{b,1} = \emptyset$.
- **Lane 2 Exclusion:** For any two distinct teams $a$ and $b$ ($a \neq b$), $S_{a,2} \cap S_{b,2} = \emptyset$.
- **Team Sequence:** For every team $i$, every element $x \in S_{i,1}$ and every element $y \in S_{i,2}$ must satisfy $x \le y$.

For every test input, it is guaranteed that no valid parking configuration exists. Your task is to output a short certificate that proves the axioms are contradictory.

To do this, you must identify the fundamental bottleneck by finding which of the following relaxed axiomatic systems still has no valid assignment of sets. Exactly one of these systems is guaranteed to remain impossible. Print the certificate for the one that holds:

* `JOB i` (where **i** is a 1-based index, $1 \le i \le j$): The system consisting ONLY of the Measure axiom (for all teams), the Domain axiom (for all teams), and the Team Sequence axiom enforced only for team $i$. (The Exclusion axioms are discarded entirely).
* `LOAD c` (where **c** is either 1 or 2): The system consisting ONLY of the Measure axiom (for all teams), the Domain axiom (for all teams), and the Lane $c$ Exclusion axiom. (The Team Sequence axiom is discarded entirely, and the Exclusion axiom for the other lane is discarded).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing $p_{i,1}$ and $p_{i,2}$ respectively for team $i$.

## Output

Print a single line containing either `JOB i` (where **i** is a 1-based index, $1 \le i \le j$) or `LOAD c` (where **c** is either 1 or 2), corresponding to the unique relaxed system that remains impossible.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is the correct certificate. Under this relaxed system, we only need to find sets $S_{1,1}, S_{1,2} \subset [0, 100]$ with measures 70 and 60 respectively, such that for all $x \in S_{1,1}$ and $y \in S_{1,2}$, $x \le y$. This requires all elements of $S_{1,1}$ to precede all elements of $S_{1,2}$, which is mathematically impossible within a domain of measure 100 given their required measures.

In Example 2, `LOAD 1` is the correct certificate. Under this relaxed system, we only need to find four mutually disjoint sets $S_{1,1}, S_{2,1}, S_{3,1}, S_{4,1} \subset [0, 150]$, each with measure 50. Since the union of these disjoint sets would require a total measure of 200, it is impossible to assign them within a domain of measure 150.

<RATIONALE>
Removed all physical terminology like "parked ahead", "overlap freely", and "mutual collision physics". Replaced the interval packing constraints with an equivalent measure-theoretic set assignment problem. This forces the model to mathematically deduce that disjoint subsets of a domain imply a sum constraint, and that an element-wise inequality between subsets implies an additive constraint, rather than triggering a pre-memorized heuristic for scheduling or packing.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical conditions for impossibility strictly map to the original constraints: sets separated by an element-wise inequality require their total measure to not exceed the domain's measure (p1 + p2 <= T), and mutually disjoint sets require their combined measure to not exceed the domain's measure (sum(p) <= T).
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class remains exactly linear time, as the conditions to check are still just whether a single pair's sum exceeds T or whether a lane's total sum exceeds T.
</PRESERVED_CLASS>
