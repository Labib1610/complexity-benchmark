<METHOD_NAME>Algebraic Constraint Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaced natural language descriptions of non-overlapping intervals and sequential dependencies with their exact algebraic equivalents (midpoint absolute distance and coordinate offsets). This prevents models from pattern-matching keywords like "overlap freely" to a sum-of-lengths check, forcing them to mathematically deduce that the surviving inequalities imply the bottleneck.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem C — Impossible Factory Layout

Time limit: 2 s   Memory limit: 256 MB

## Description

You are designing a layout for a dual-stage manufacturing facility. The facility has two parallel assembly lines, Line 1 and Line 2, each extending exactly **T** meters from a starting wall (coordinate $0$) to an ending wall (coordinate $T$).

There are **j** products that must be manufactured. For each product $i$ (from $1$ to $j$), you must place a primary machine on Line 1 of length $p_{i,1}$ meters, and a secondary machine on Line 2 of length $p_{i,2}$ meters.

A valid layout must assign a real-valued starting coordinate $x_{i,c}$ to every product $i$ on each line $c \in \{1, 2\}$, satisfying all of the following physical rules:
- **Boundary Bounds:** Every machine must be completely contained within the $0$ to $T$ coordinate bounds. Specifically, $x_{i,c} \ge 0$ and $x_{i,c} + p_{i,c} \le T$.
- **Flow Offset:** For every product $i$, the secondary machine's start coordinate must be offset from its primary machine's start coordinate by at least the primary machine's length: $x_{i,2} - x_{i,1} \ge p_{i,1}$.
- **Line 1 Center-Distance:** Primary machines cannot share space. For any two distinct products $a$ and $b$, the absolute distance between their midpoints must be at least half their combined lengths: $\left| \left(x_{a,1} + \frac{p_{a,1}}{2}\right) - \left(x_{b,1} + \frac{p_{b,1}}{2}\right) \right| \ge \frac{p_{a,1} + p_{b,1}}{2}$.
- **Line 2 Center-Distance:** Secondary machines cannot share space. For any two distinct products $a$ and $b$, the absolute distance between their midpoints must be at least half their combined lengths: $\left| \left(x_{a,2} + \frac{p_{a,2}}{2}\right) - \left(x_{b,2} + \frac{p_{b,2}}{2}\right) \right| \ge \frac{p_{a,2} + p_{b,2}}{2}$.

For every test input, it is guaranteed that no valid layout exists. Your task is to output a short certificate that proves the rules are contradictory. 

To do this, you must identify the fundamental bottleneck by finding which of the following relaxed geometric scenarios is still impossible to satisfy. In a relaxed scenario, we evaluate if the machines can be assigned starting coordinates within the $0$ to $T$ bounds under modified constraint rules. Exactly one of these scenarios is guaranteed to remain impossible. Print the certificate for the one that holds:

* `JOB i` (where **i** is a 1-based index, $1 \le i \le j$): The "Product $i$ Bottleneck". In this scenario, the Line 1 and Line 2 Center-Distance rules are entirely removed. The Flow Offset rule is also removed for all products *except* product $i$. However, for product $i$, the Flow Offset rule remains strictly enforced. (The Boundary Bounds rule always remains active for all products).
* `LOAD c` (where **c** is either 1 or 2): The "Line $c$ Bottleneck". In this scenario, the Flow Offset rule is entirely removed for all products. Furthermore, the Center-Distance rule for Line $3-c$ is removed. However, the Center-Distance rule for Line $c$ remains strictly enforced. (The Boundary Bounds rule always remains active for all products).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing $p_{i,1}$ and $p_{i,2}$ respectively for product $i$.

## Output

Print a single line containing either `JOB i` (where **i** is a 1-based index, $1 \le i \le j$) or `LOAD c` (where **c** is either 1 or 2), corresponding to the unique relaxed scenario that remains impossible.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is the correct certificate. Under the Product 1 Bottleneck scenario, the Center-Distance rules are removed, allowing machines from different products to share space. The Flow Offset rule is also removed for products 2 and 3. We only need to satisfy the Boundary Bounds for all machines and the Flow Offset for product 1. However, product 1's primary and secondary machines must still satisfy $x_{1,2} - x_{1,1} \ge 70$ and fit within the $100$-meter bounds ($x_{1,1} \ge 0$ and $x_{1,2} + 60 \le 100$). Combining these yields $100 \ge x_{1,2} + 60 \ge x_{1,1} + 70 + 60 \ge 130$, which is physically impossible. Thus, this scenario remains impossible.

In Example 2, `LOAD 1` is the correct certificate. Under the Line 1 Bottleneck scenario, the Flow Offset rule is removed, and the Line 2 Center-Distance rule is removed. However, we still must place all four primary machines on Line 1 such that no two share space (the Line 1 Center-Distance rule). The midpoint distance inequality ensures that the machines occupy disjoint intervals. Fitting four 50-meter machines into a 150-meter boundary without overlapping requires $200$ meters of space, which is impossible. Thus, this scenario remains impossible.
</STATEMENT>
<RATIONALE>
The rewrite replaces the natural language descriptions of "non-overlapping" and "sequential" intervals with their exact algebraic equivalents (midpoint absolute distance and coordinate offsets). This prevents models from using keyword shortcuts like "overlap freely" to directly trigger a sum-of-lengths check, forcing them to mathematically deduce that the surviving inequalities imply the bottleneck.
</RATIONALE>
<PRESERVED_ANSWER>
The absolute distance inequality is mathematically identical to non-overlapping intervals, and the offset inequality is identical to sequential ordering, meaning the exact same bottleneck sums apply to every input.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires an $O(N)$ scan to find either a pair whose sum exceeds T or a line whose total sum exceeds T, keeping it in the same complexity class.
</PRESERVED_CLASS>
<RISK>
The absolute value midpoint formula might be considered slightly dense, but it is standard mathematical notation and unambiguously defines non-overlapping intervals.
</RISK>
