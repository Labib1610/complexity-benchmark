<STATEMENT>
# Problem C — Impossible System of Functions

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of $j$ paired parameters. Each pair $i$ (for $1 \le i \le j$) has two given positive lengths, $p_{i,1}$ and $p_{i,2}$. We are interested in finding a set of real starting values $E_{i,1}$ and $E_{i,2}$ for all $1 \le i \le j$ that satisfy a set of strict conditions over the domain $[0, T]$.

For any scalar $E$ and maximum length $p$, define the profile function:
$C(x; E, p) = \max(0, \min(p, x - E))$.

A valid full system requires finding $E_{i,1}$ and $E_{i,2}$ ($1 \le i \le j$) such that all of the following hold:
- **Domain Bounds:** For all $i$ and for $c \in \{1, 2\}$, $E_{i,c} \ge 0$ and $E_{i,c} + p_{i,c} \le T$.
- **Sequential Link:** For all $i$, $E_{i,2} \ge E_{i,1} + p_{i,1}$.
- **Growth Limit 1:** The combined function $F_1(x) = \sum_{i=1}^j C(x; E_{i,1}, p_{i,1})$ must satisfy $F_1(y) - F_1(x) \le y - x$ for all $0 \le x < y \le T$.
- **Growth Limit 2:** The combined function $F_2(x) = \sum_{i=1}^j C(x; E_{i,2}, p_{i,2})$ must satisfy $F_2(y) - F_2(x) \le y - x$ for all $0 \le x < y \le T$.

For every test input, it is guaranteed that no valid full system exists. Your task is to output a short certificate that proves the system is contradictory. 

To do this, you must identify which of the following relaxed systems is still impossible to satisfy. Exactly one of these relaxed systems is guaranteed to remain impossible. Print the certificate for the one that holds:

* `JOB i` (where **i** is a 1-based index, $1 \le i \le j$): The "Pair $i$ Isolation". In this relaxed system, we only require that the variables $E_{i,1}$ and $E_{i,2}$ for this specific $i$ satisfy the Domain Bounds and the Sequential Link. All other variables and the Growth Limit conditions are ignored.
* `LOAD c` (where **c** is either 1 or 2): The "Class $c$ Isolation". In this relaxed system, we only require that the variables $E_{1,c}, E_{2,c}, \dots, E_{j,c}$ satisfy the Domain Bounds and the Growth Limit $c$. All other variables, the Sequential Link, and the other Growth Limit are ignored.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing $p_{i,1}$ and $p_{i,2}$ respectively for pair $i$.

## Output

Print a single line containing either `JOB i` (where **i** is a 1-based index, $1 \le i \le j$) or `LOAD c` (where **c** is either 1 or 2), corresponding to the unique relaxed system that remains impossible.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is the correct certificate. Under the Pair 1 Isolation system, we only need to satisfy the Domain Bounds and Sequential Link for $i=1$. The Sequential Link requires $E_{1,2} \ge E_{1,1} + 70$. The Domain Bounds require $E_{1,1} \ge 0$ and $E_{1,2} + 60 \le 100$. Combining these gives $E_{1,2} \ge 70$, so $E_{1,2} + 60 \ge 130$, which strictly violates the bound of $100$. Thus, this relaxed system is impossible.

In Example 2, `LOAD 1` is the correct certificate. Under the Class 1 Isolation system, we require $E_{i,1} \ge 0$ and $E_{i,1} + 50 \le 150$ for all four items. Any valid choice of starting values within these bounds forces the combined function $F_1(x)$ to accumulate a total increase of $200$ over the domain. Because the Growth Limit 1 restricts the maximum increase over any interval to the length of that interval, the limit of $150$ is inevitably exceeded, making the Class 1 Isolation system impossible.

<RATIONALE>
The physical 1D parking constraints were replaced with an equivalent system of piecewise linear profile functions subject to a 1-Lipschitz condition. This removes the semantic affordances of "lanes" and "overlapping" that allowed models to directly guess the `sum <= T` invariant, forcing them to algebraically deduce that the global variation of the combined profile function equates to the sum of the parameters.
</RATIONALE>
<PRESERVED_ANSWER>
The profile function $C(x; E, p)$ computes the intersection length of an interval $[E, E+p]$ with $(-\infty, x]$, meaning the 1-Lipschitz Growth Limit is exactly equivalent to requiring that the intervals are disjoint, preserving all original impossibility conditions.
</PRESERVED_ANSWER>
