<STATEMENT>
# Problem C — Measure-Theoretic Contradictions

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of constraints over subsets of the real line. You are given a domain bound $T$ and $j$ pairs of positive integers $\alpha_1, \beta_1$ through $\alpha_j, \beta_j$.

You must determine if there exist $2j$ sets of real numbers, denoted $A_1, A_2, \dots, A_j$ and $B_1, B_2, \dots, B_j$, satisfying all of the following conditions:
1. **Domain:** Every set $A_i$ and $B_i$ is a subset of the closed interval $[0, T]$.
2. **Measure:** For each $i$ ($1 \le i \le j$), the total length (Lebesgue measure) of $A_i$ is exactly $\alpha_i$, and the total length of $B_i$ is exactly $\beta_i$.
3. **Mutual Exclusivity:** The sets $A_1, A_2, \dots, A_j$ are pairwise disjoint. Similarly, the sets $B_1, B_2, \dots, B_j$ are pairwise disjoint.
4. **Precedence:** For each $i$ ($1 \le i \le j$), every element in $A_i$ is strictly less than every element in $B_i$. (That is, $\sup(A_i) \le \inf(B_i)$).

You are guaranteed that for every test input, no such collection of sets exists. Your task is to output a short certificate identifying a specific independent reason why the system is contradictory. 

A certificate of contradiction is found by relaxing the conditions and showing that a subset of the rules is already impossible. You must output a certificate in one of the following formats. If multiple certificates are valid for a given input, you may output any one of them:

* `JOB i` (where $1 \le i \le j$): The constraints are contradictory for index $i$ in isolation. Specifically, it is mathematically impossible to find just the two sets $A_i$ and $B_i$ satisfying Rule 1 (Domain), Rule 2 (Measure), and Rule 4 (Precedence), even if we completely ignore Rule 3 and all other indices.
* `LOAD c` (where $c$ is either 1 or 2): The constraints are contradictory for a single family of sets in isolation.
    - If $c=1$, it is mathematically impossible to find sets $A_1, \dots, A_j$ satisfying Rule 1 (Domain), Rule 2 (Measure for the $A$ sets), and Rule 3 (Mutual Exclusivity for the $A$ sets), even if we ignore the $B$ sets and Rule 4 entirely.
    - If $c=2$, it is mathematically impossible to find sets $B_1, \dots, B_j$ satisfying Rule 1 (Domain), Rule 2 (Measure for the $B$ sets), and Rule 3 (Mutual Exclusivity for the $B$ sets), even if we ignore the $A$ sets and Rule 4 entirely.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **$\alpha_i$** and **$\beta_i$** (1 ≤ $\alpha_i$, $\beta_i$ ≤ 1000000), representing the required measures for $A_i$ and $B_i$ respectively for index $i$.

## Output

Print a single line containing either `JOB i` (where **i** is a 1-based index, $1 \le i \le j$) or `LOAD c` (where **c** is either 1 or 2), corresponding to a valid contradiction certificate as described above. If multiple certificates are valid, print any one of them.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is a valid certificate. If we consider only $A_1$ and $B_1$, they must be subsets of $[0, 100]$ with lengths 70 and 60 respectively. Furthermore, every element of $A_1$ must be less than every element of $B_1$. This requires the interval from $\inf(A_1)$ to $\sup(B_1)$ to have a length of at least $70 + 60 = 130$, which cannot fit within $[0, 100]$. Thus, the constraints for index 1 are isolatedly contradictory.

In Example 2, `LOAD 1` is a valid certificate. If we consider only the $A$ sets ($A_1, A_2, A_3, A_4$), they must be pairwise disjoint subsets of $[0, 150]$, each with a measure of 50. The union of these disjoint sets would require a total measure of $4 \times 50 = 200$, which is impossible within a domain of length 150. Thus, the mutual exclusivity of the $A$ family is isolatedly contradictory.
</STATEMENT>
<RATIONALE>
I replaced the physical vehicle-parking scenario with an abstract mathematical problem about measurable subsets of the real line. This removes the affordance of directly mapping "lengths in a lane" to simple sum operations, forcing the model to logically deduce that disjoint sets in a domain imply a sum-of-measures bound, and that precedence between two sets implies their measures sum to at most the domain width.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical conditions for impossibility of the relaxed constraints identically reduce to `sum(alpha) > T`, `sum(beta) > T`, and `alpha_i + beta_i > T`, which exactly matches the original sum and pair-length checks, ensuring all valid certificates remain identical.
</PRESERVED_ANSWER>

The complexity class is unchanged (INFEASIBLE / $O(N)$ certification) because the required checks are still simple linear scans and sums of the input arrays.
</PRESERVED_CLASS>
