<STATEMENT>
# Problem C — Impossible Ferry Loading

Time limit: 2 s   Memory limit: 256 MB

## Description

You are auditing a real-time stream processing framework. The framework must execute **j** parallel streams. Each stream $i$ (for $1 \le i \le j$) consists of a Phase 1 filter requiring $p_{i,1}$ milliseconds, and a Phase 2 filter requiring $p_{i,2}$ milliseconds. 

A valid execution plan must assign a start time $x_{i,c} \ge 0$ to each filter $c \in \{1, 2\}$ of each stream $i$, satisfying the following system of inequalities:
- **Deadline:** Every filter must complete by the strict deadline of **T** milliseconds. Thus, $x_{i,c} + p_{i,c} \le T$ for all $i$ and $c$.
- **Causality:** For every stream $i$, Phase 2 cannot begin until Phase 1 completes. Thus, $x_{i,1} + p_{i,1} \le x_{i,2}$.
- **Mutual Exclusion:** A phase processor can only handle one stream's filter at a time. For any two distinct streams $i$ and $k$, and for each phase $c$, their filters must not run concurrently. Thus, either $x_{i,c} + p_{i,c} \le x_{k,c}$ or $x_{k,c} + p_{k,c} \le x_{i,c}$.

For every test input, the full system of constraints is guaranteed to have no valid assignment of start times. Your task is to output a short certificate proving the impossibility.

To do this, you must identify a relaxed system of constraints that is *already* impossible to satisfy. Consider the following relaxed systems:
* `JOB i` (where **i** is a 1-based index, $1 \le i \le j$): The Mutual Exclusion constraints are completely removed for all streams and phases. The Causality constraint is removed for all streams EXCEPT stream $i$. The Deadline constraints remain active for all filters.
* `LOAD c` (where **c** is either 1 or 2): The Causality constraints are completely removed for all streams. The Mutual Exclusion constraints are removed for phase $3-c$, but remain active for all filters in phase $c$. The Deadline constraints remain active for all filters.

It is guaranteed that exactly one category of relaxed system (either the `JOB` category or the `LOAD` category) will contain systems that are impossible to satisfy. Find and print the certificate (`JOB i` or `LOAD c`) for any relaxed system that admits no valid assignment of start times. If multiple indices within the active category yield an impossible system, any one of them is accepted.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing $p_{i,1}$ and $p_{i,2}$ respectively for stream $i$.

## Output

Print a single line containing either `JOB i` (where **i** is a 1-based index, $1 \le i \le j$) or `LOAD c` (where **c** is either 1 or 2), corresponding to a relaxed system that has no valid assignment.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is a valid certificate. Under the relaxed system for `JOB 1`, Mutual Exclusion is removed, so streams can run concurrently. Causality is removed for streams 2 and 3. We only need to satisfy the Deadline constraints for all filters, and the Causality constraint for stream 1 ($x_{1,1} + 70 \le x_{1,2}$). Since $x_{1,2} + 60 \le 100$, this requires $x_{1,1} + 130 \le 100$, which is impossible for $x_{1,1} \ge 0$. Thus, this relaxed system admits no solution.

In Example 2, `LOAD 1` is a valid certificate. Under the relaxed system for `LOAD 1`, Causality is removed for all streams, and Mutual Exclusion is removed for Phase 2. However, Mutual Exclusion remains active for all four Phase 1 filters. They must run sequentially without overlapping, requiring at least $50 + 50 + 50 + 50 = 200$ milliseconds. This violates the Deadline constraint $T = 150$. Thus, this relaxed system admits no solution.
