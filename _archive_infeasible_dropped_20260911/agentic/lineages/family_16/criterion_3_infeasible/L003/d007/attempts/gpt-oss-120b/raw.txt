**Solution Explanation**

For every team `i`

* primary vehicle length `a[i]` must be placed in lane 1,
* secondary vehicle length `b[i]` must be placed in lane 2,
* the primary must finish not later than the secondary starts  
  (`end₁ ≤ start₂`).

All intervals have to stay inside `[0, T]`.

We are told that **no** feasible loading exists, and that exactly one of the
three relaxed scenarios is still impossible:

* **JOB i** – only the ordering of team *i* is kept, all other orderings and
  all non‑overlap constraints are removed.
* **LOAD 1** – ordering is completely removed, lane 2 may overlap,
  only lane 1 must respect non‑overlap.
* **LOAD 2** – symmetric for lane 2.

--------------------------------------------------------------------

#### 1.   When does `JOB i` stay impossible?

With all non‑overlap rules removed, each vehicle can be placed anywhere
independently, only the ordering of team *i* matters:

```
choose start₁ ≥ 0
end₁ = start₁ + a[i]
choose start₂ = end₁          (any larger value also works)
end₂ = start₂ + b[i] ≤ T
```

Thus we need a `start₁` with  

`start₁ + a[i] + b[i] ≤ T`  →  `a[i] + b[i] ≤ T`.

If for some team `a[i] + b[i] > T`, even this relaxed problem is impossible,
so the certificate is `JOB i` (the first such team).

--------------------------------------------------------------------

#### 2.   When does `LOAD 1` stay impossible?

All orderings are ignored, lane 2 may overlap, only lane 1 must contain all
primary vehicles without overlap. That is exactly the classic bin‑packing
into a single segment of length `T`. It is possible **iff**

```
sum_a = Σ a[i] ≤ T
```

If `sum_a > T` the relaxed problem cannot be solved → `LOAD 1`.

--------------------------------------------------------------------

#### 3.   When does `LOAD 2` stay impossible?

Symmetric to the previous case, it happens exactly when

```
sum_b = Σ b[i] > T
```

→ `LOAD 2`.

--------------------------------------------------------------------

#### 4.   Uniqueness guarantee

The statement guarantees that exactly one of the three conditions holds,
so checking them in the order

1. a team with `a[i] + b[i] > T`  → `JOB i`
2. `sum_a > T`                    → `LOAD 1`
3. otherwise `sum_b > T`          → `LOAD 2`

will always produce the correct unique answer.

--------------------------------------------------------------------

#### 5.   Algorithm
```
read j, T
sum_a = 0, sum_b = 0
for i = 1 .. j
        read a, b
        if a + b > T and not yet found_bad_team:
                bad_team = i
        sum_a += a
        sum_b += b
if bad_team exists:
        output "JOB bad_team"
elif sum_a > T:
        output "LOAD 1"
else:
        output "LOAD 2"
```
`j ≤ 2·10⁵`, all operations are O(j) time, O(1) extra memory.

--------------------------------------------------------------------

#### 6.   Correctness Proof  

We prove that the algorithm always outputs the required certificate.

---

**Lemma 1**  
If for some team `i` we have `a[i] + b[i] > T`, then the relaxed problem
described in `JOB i` is infeasible.

*Proof.* Any placement respecting the ordering must satisfy
`start₁ + a[i] + b[i] ≤ T` (see section 1). This inequality is impossible
when `a[i] + b[i] > T`. ∎



**Lemma 2**  
If for every team `a[i] + b[i] ≤ T` and `sum_a ≤ T`, then the relaxed problem
described in `LOAD 1` is feasible.

*Proof.* Place the primary vehicles consecutively from coordinate 0 in lane 1.
Total occupied length is `sum_a ≤ T`, so all fit without overlap.
All other constraints are removed, therefore a feasible configuration exists. ∎



**Lemma 3**  
If `sum_a > T` then the relaxed problem of `LOAD 1` is infeasible.

*Proof.* Any feasible placement of all primary vehicles without overlap
needs total length at least `sum_a`. Since the lane length is only `T`,
this is impossible. ∎



**Lemma 4**  
Analogous statements hold for lane 2 and `LOAD 2`.

*Proof.* Same reasoning with `b[i]` and `sum_b`. ∎



**Theorem**  
The algorithm outputs

* `JOB i` for the unique team `i` with `a[i] + b[i] > T` if such a team
  exists;
* otherwise `LOAD 1` if `sum_a > T`;
* otherwise `LOAD 2`.

This output is exactly the certificate guaranteed to exist.

*Proof.*  
Three cases:

1. **There exists a team with `a[i] + b[i] > T`.**  
   By Lemma 1 the `JOB i` scenario is impossible.  
   The algorithm detects the first such team and outputs `JOB i`.  
   The problem statement guarantees uniqueness, so no other certificate can
   be valid.

2. **No such team, but `sum_a > T`.**  
   By Lemma 3 `LOAD 1` remains impossible, while Lemma 2 shows that if
   `sum_a ≤ T` it would be possible.  
   The algorithm reaches the second test and outputs `LOAD 1`.

3. **Neither of the above, therefore `sum_b > T`.**  
   By Lemma 4 `LOAD 2` is the only remaining impossible relaxation, and the
   algorithm outputs it.

In all cases the algorithm outputs the unique correct certificate. ∎



--------------------------------------------------------------------

#### 7.   Complexity Analysis

*Time*: `O(j)` – one pass over the input.  
*Memory*: `O(1)` – only a few integer variables.

--------------------------------------------------------------------

#### 8.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    j = int(next(it))
    T = int(next(it))

    sum_a = 0
    sum_b = 0
    bad_team = -1  # 1‑based index, -1 means none found yet

    for idx in range(1, j + 1):
        a = int(next(it))
        b = int(next(it))
        if bad_team == -1 and a + b > T:
            bad_team = idx
        sum_a += a
        sum_b += b

    out = []
    if bad_team != -1:
        out.append(f"JOB {bad_team}")
    elif sum_a > T:
        out.append("LOAD 1")
    else:
        out.append("LOAD 2")
    sys.stdout.write(out[0])

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
