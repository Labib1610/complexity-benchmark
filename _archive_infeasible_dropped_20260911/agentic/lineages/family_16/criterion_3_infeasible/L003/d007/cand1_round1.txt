<STATEMENT>
# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of temporal constraints over a set of **j** signals. The system features exactly 2 sequential processing stages, numbered 1 and 2. 
Each signal $i$ (for $1 \le i \le j$) has a required duration defined by a matrix $D$, where $D_{i,1}$ is the duration in stage 1 and $D_{i,2}$ is the duration in stage 2.

We define the activation and deactivation times for each signal $i$ in each stage $c \in \{1, 2\}$ as real numbers $S_{i,c}$ and $E_{i,c}$.
A valid configuration must satisfy all of the following inequalities:
- **(W1)** $E_{i,c} - S_{i,c} \ge D_{i,c}$ for all $i \in \{1 \dots j\}$ and all $c \in \{1, 2\}$.
- **(W2)** $S_{i,2} - E_{i,1} \ge 0$ for all $i \in \{1 \dots j\}$.
- **(W3)** For a given stage $c$ and any pair of distinct signals $i$ and $k$, either $S_{k,c} - E_{i,c} \ge 0$ or $S_{i,c} - E_{k,c} \ge 0$.
- **(W4)** $T - E_{i,c} \ge 0$ for all $i \in \{1 \dots j\}$ and all $c \in \{1, 2\}$.
- **(W5)** $S_{i,c} \ge 0$ for all $i \in \{1 \dots j\}$ and all $c \in \{1, 2\}$.

For every test input, it is guaranteed that no valid configuration exists. Your task is to output a short certificate that proves the system is contradictory. By summing a specific subset of these inequalities, we can derive a falsehood of the form $T \ge X$ where $X > T$.

For every test input, exactly one such certificate is guaranteed to yield a contradiction. Print the one that holds:

* `JOB i` (where **i** is a 1-based index, $1 \le i \le j$): A contradiction is derived by summing exactly five inequalities: (W1) for signal **i** in stage 1, (W1) for signal **i** in stage 2, (W2) for signal **i**, (W4) for signal **i** in stage 2, and (W5) for signal **i** in stage 1.
* `LOAD c` (where **c** is either 1 or 2): A contradiction is derived by summing the following inequalities for a stage **c**: (W1) for all $j$ signals in stage **c**, (W3) chosen as $S_{k,c} - E_{i,c} \ge 0$ for every adjacent pair of signals where $k$ immediately follows $i$ in an arbitrary permutation of the $j$ signals, (W4) for the last signal in that permutation, and (W5) for the first signal in that permutation. This sum yields a contradiction regardless of the chosen permutation.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): representing $D_{i,1}$ and $D_{i,2}$ respectively for signal $i$.

## Output

Print a single line containing either `JOB i` (where **i** is a 1-based index, $1 \le i \le j$, and the specified linear combination for signal **i** yields a contradiction) or `LOAD c` (where **c** is either 1 or 2, and the specified linear combination for stage **c** yields a contradiction).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is the certificate. Summing the specified inequalities for signal 1:
$(E_{1,1} - S_{1,1}) + (E_{1,2} - S_{1,2}) + (S_{1,2} - E_{1,1}) + (100 - E_{1,2}) + S_{1,1} \ge 70 + 60 + 0 + 0 + 0$
This simplifies to $100 \ge 130$, which is a contradiction.

In Example 2, `LOAD 1` is the certificate. For any permutation of the 4 signals in stage 1, summing the (W1) constraints for all 4 signals, the 3 connecting (W3) constraints, the (W4) constraint for the last signal, and the (W5) constraint for the first signal yields:
$150 \ge 50 + 50 + 50 + 50$
This simplifies to $150 \ge 200$, which is a contradiction.

<RATIONALE>
The previous problem description allowed models to bypass mathematical reasoning by pattern-matching the semantic concepts of "isolated job" and "isolated stage" directly to the $p_1+p_2 > T$ and $\sum p_c > T$ checks. This rewrite replaces those semantic descriptions with rigorous linear combinations of the system's inequalities. To solve the problem, a model must now trace the telescoping sums to realize they algebraically simplify to the exact same threshold checks.
</RATIONALE>
<PRESERVED_ANSWER>
The linear combinations perfectly telescope such that the `JOB i` sum evaluates to $T \ge p_1 + p_2$ and the `LOAD c` sum evaluates to $T \ge \sum p_c$, making the contradiction conditions mathematically identical to the original seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires checking individual job sums and total stage sums against $T$, which remains solvable in $O(N)$ time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "arbitrary permutation" as requiring them to computationally check all $O(N!)$ permutations, but the Note explicitly demonstrates that the sum algebraically simplifies to a constant $T \ge \sum D$, proving permutation independence.
</RISK>
