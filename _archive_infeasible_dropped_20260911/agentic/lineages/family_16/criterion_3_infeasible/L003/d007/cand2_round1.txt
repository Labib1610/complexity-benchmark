<STATEMENT>
# Problem C — System Defect Certification

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a system of equations over $4j$ real variables. For each index $i$ from $1$ to $j$, there are four variables: $X_{i,1}, Y_{i,1}, X_{i,2}, Y_{i,2}$. 

Let the domain $\mathcal{D}$ be the set of all real assignments to these variables that satisfy $0 \le X_{i,c} \le Y_{i,c} \le T$ for all $i \in \{1, \dots, j\}$ and $c \in \{1, 2\}$.

You are given a matrix $P$ of size $j \times 2$, containing positive integers. 

We define the **internal defect** for a specific index $i \in \{1, \dots, j\}$ as:
$$ \Delta(i) = |Y_{i,1} - X_{i,1} - P_{i,1}| + |Y_{i,2} - X_{i,2} - P_{i,2}| + |X_{i,2} - Y_{i,1}| $$

We define the **lateral defect** for a specific dimension $c \in \{1, 2\}$ and a pair of distinct indices $i, k \in \{1, \dots, j\}$ as:
$$ \Gamma_c(i, k) = \max(0, \min(Y_{i,c} - X_{k,c}, Y_{k,c} - X_{i,c})) $$

A fully valid configuration is an assignment in $\mathcal{D}$ where $\Delta(i) = 0$ for all $i$, and $\Gamma_c(i, k) = 0$ for all $c \in \{1, 2\}$ and all $i \neq k$.

For every test input, it is guaranteed that no fully valid configuration exists. Your task is to output a short certificate that proves the system is contradictory. For every test input, exactly one of these certificate types is guaranteed to apply. Print the one that holds:

* `JOB i` (where **i** is a 1-based index, $1 \le i \le j$): This certificate is valid if there exists no assignment in $\mathcal{D}$ that satisfies $\Delta(i) = 0$.
* `LOAD c` (where **c** is either 1 or 2): This certificate is valid if there exists no assignment in $\mathcal{D}$ that satisfies both $Y_{i,c} - X_{i,c} = P_{i,c}$ for all $i \in \{1, \dots, j\}$, and $\Gamma_c(i, k) = 0$ for all $i \neq k$.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing $P_{i,1}$ and $P_{i,2}$ respectively for index $i$.

## Output

Print a single line containing either `JOB i` (where **i** is a 1-based index, $1 \le i \le j$) or `LOAD c` (where **c** is either 1 or 2), corresponding to the valid certificate for the given input.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is the certificate because for index 1, attempting to satisfy $\Delta(1) = 0$ forces $Y_{1,1} - X_{1,1} = 70$, $Y_{1,2} - X_{1,2} = 60$, and $X_{1,2} = Y_{1,1}$. This algebraic chain implies $Y_{1,2} = X_{1,1} + 130$. Since the domain $\mathcal{D}$ requires $X_{1,1} \ge 0$, this leads to $Y_{1,2} \ge 130$, which contradicts the domain constraint $Y_{1,2} \le 100$.

In Example 2, `LOAD 1` is the certificate because satisfying $Y_{i,1} - X_{i,1} = 50$ for all four indices simultaneously with $\Gamma_1(i, k) = 0$ (which forces the intervals $[X_{i,1}, Y_{i,1}]$ to be mutually disjoint) would require a total domain span of at least $4 \times 50 = 200$. This contradicts the domain constraint $Y_{i,1} \le 150$.
</STATEMENT>
<RATIONALE>
The problem was completely stripped of scheduling terminology and recast as a system of algebraic equations over real variables. The sequential and duration constraints were merged into an "internal defect" equation using absolute values, which mathematically forces $P_{i,1} + P_{i,2} \le T$. The exclusivity constraint was replaced by a "lateral defect" equation using a min/max formulation, which enforces disjoint intervals and limits the sum to $T$. This forces models to genuinely solve the algebraic system to discover the underlying $O(j)$ check, rather than guessing it from semantic keywords like "duration" or "stage".
</RATIONALE>
<PRESERVED_ANSWER>
The condition $\Delta(i) = 0$ in domain $\mathcal{D}$ is mathematically satisfiable if and only if $P_{i,1} + P_{i,2} \le T$, and the condition for `LOAD c` is satisfiable if and only if $\sum P_{i,c} \le T$, meaning the exact same inputs will trigger the exact same certificates.
</PRESERVED_ANSWER>
