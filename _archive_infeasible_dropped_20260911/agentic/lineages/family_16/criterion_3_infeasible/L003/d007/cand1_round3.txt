<STATEMENT>
# Problem C — Inconsistent Inequality System: Core Extraction

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of mathematical inequalities over a set of **j** elements. The system features exactly 2 sequential strata, numbered 1 and 2. 
Each element $i$ (for $1 \le i \le j$) has associated constants defined by a matrix $D$, where $D_{i,1}$ applies to stratum 1 and $D_{i,2}$ applies to stratum 2.

We seek to assign non-negative real numbers to variables $S_{i,c}$ and $E_{i,c}$ for each element $i$ in each stratum $c \in \{1, 2\}$.
A valid assignment must satisfy all of the following rules simultaneously:
- **Span constraint:** $E_{i,c} \ge S_{i,c} + D_{i,c}$ for all $i$ and all $c$.
- **Sequential constraint:** $S_{i,2} \ge E_{i,1}$ for all $i$.
- **Orthogonality constraint:** For a given stratum $c$, no two elements can overlap in their $(S, E)$ intervals. For any $i \neq k$, either $S_{i,c} \ge E_{k,c}$ or $S_{k,c} \ge E_{i,c}$.
- **Bounding constraint:** $E_{i,c} \le T$ for all $i$ and all $c$.

For every test input, it is guaranteed that no valid assignment exists. Your task is to output a short certificate that proves the system is contradictory. For every test input, exactly one of these certificate types is guaranteed to apply. Print the one that holds:

* `JOB i` (where **i** is a 1-based index, $1 \le i \le j$): The inequalities restricted only to element **i** across both strata (Span, Sequential, Non-negative variables, and Bounding) are already contradictory.
* `LOAD c` (where **c** is either 1 or 2): The inequalities restricted only to stratum **c** across all elements (Span, Orthogonality, Non-negative variables, and Bounding) are already contradictory.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): representing $D_{i,1}$ and $D_{i,2}$ respectively for element $i$.

## Output

Print a single line containing either `JOB i` (where **i** is a 1-based index, $1 \le i \le j$, and the isolated constraints for element **i** prove the bounding constraint is impossible) or `LOAD c` (where **c** is either 1 or 2, and the isolated constraints for stratum **c** prove the bounding constraint is impossible).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is the certificate because for element 1, the span and sequential constraints require $E_{1,2} \ge S_{1,2} + 60 \ge E_{1,1} + 60 \ge S_{1,1} + 70 + 60 \ge 130$. Since $S_{1,1} \ge 0$, $E_{1,2} \ge 130$, which contradicts the bounding constraint $E_{1,2} \le 100$.
In Example 2, `LOAD 1` is the certificate because stratum 1 has 4 elements each with $D_{i,1} = 50$. The orthogonality and span constraints require the maximum $E_{i,1}$ to be at least $4 \times 50 = 200$, which contradicts the bounding constraint $E_{i,1} \le 150$.
</STATEMENT>
<RATIONALE>
The rewrite strips all scheduling-specific terminology (signals, stages, duration, exclusivity, global deadline) and replaces it with an abstract mathematical system of inequalities (elements, strata, span, orthogonality, bounding constraint). This targets the LLMs' reliance on mapping scheduling problem descriptions directly to the standard makespan/load formulas (`p1+p2 > T` and `sum > T`). By presenting it purely algebraically, models must now genuinely deduce the mathematical implications of the axioms to derive those thresholds, rather than retrieving them via semantic association.
</RATIONALE>

The mathematical system of inequalities is perfectly isomorphic to the original scheduling constraints, meaning the exact same inputs will trigger the exact same logical contradictions (JOB i or LOAD c) for the exact same reasons.
