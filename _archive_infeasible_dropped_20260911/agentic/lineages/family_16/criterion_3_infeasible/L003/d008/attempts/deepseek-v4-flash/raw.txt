We can solve this by checking the three possible certificates:

1. **JOB i** — For a team, if `p1 + p2 > T`, then that team alone cannot fit sequentially in the ferry, so `JOB i` is the answer.
2. **LOAD 1** — If the sum of all primary lengths exceeds `T`, then Lane 1 cannot hold all primaries, so `LOAD 1` is the answer.
3. **LOAD 2** — If the sum of all secondary lengths exceeds `T`, then Lane 2 cannot hold all secondaries, so `LOAD 2` is the answer.

Since the problem guarantees exactly one remains impossible, we check in that order.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    idx = 2
    sum1 = 0
    sum2 = 0
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        sum1 += p1
        sum2 += p2
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
    if sum1 > T:
        print("LOAD 1")
        return
    if sum2 > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
