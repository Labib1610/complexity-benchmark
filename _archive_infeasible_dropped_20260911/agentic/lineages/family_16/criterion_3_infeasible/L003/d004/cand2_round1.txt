<METHOD_NAME>Formal Inequality System Translation</METHOD_NAME>
<METHOD_DESCRIPTION>Translates the scheduling narrative (jobs, stages, deadlines) into a purely mathematical system of variables, inequalities, and disjoint open intervals. It removes all direct mentions of arithmetic sums or sequential processing. Models that rely on surface pattern matching of "total time" or "sum of durations" will fail because the arithmetic conditions (p1+p2 > T and sum(pi) > T) must now be logically deduced from the impossibility of the specified mathematical subsystems.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A system of variables $S_{i,1}$ and $S_{i,2}$ (for $1 \le i \le j$) is proposed to satisfy the following five conditions, given a set of positive integer constants $p_{i,1}, p_{i,2}$ and a limit $T$:

1. $S_{i,1} \ge 0$ for all $1 \le i \le j$.
2. $S_{i,2} \ge S_{i,1} + p_{i,1}$ for all $1 \le i \le j$.
3. $S_{i,2} + p_{i,2} \le T$ for all $1 \le i \le j$.
4. For any pair of distinct indices $i$ and $k$, the open intervals $(S_{i,1}, S_{i,1} + p_{i,1})$ and $(S_{k,1}, S_{k,1} + p_{k,1})$ are disjoint.
5. For any pair of distinct indices $i$ and $k$, the open intervals $(S_{i,2}, S_{i,2} + p_{i,2})$ and $(S_{k,2}, S_{k,2} + p_{k,2})$ are disjoint.

For every input in this problem, it is guaranteed that no assignment of real numbers to $S_{i,1}$ and $S_{i,2}$ can satisfy all five conditions simultaneously. Your task is to prove this impossibility by identifying a specific subset of these conditions that is already contradictory on its own.

Exactly one of the following isolated subsystems will be impossible. Print the certificate string for the one that holds:

* `JOB i` (where **i** is a 1-based index): The subsystem consisting exclusively of conditions 1, 2, and 3 for a single specific index **i** admits no valid assignment for $S_{i,1}$ and $S_{i,2}$.
* `LOAD 1`: The subsystem consisting exclusively of condition 4, along with the boundary requirements $S_{i,1} \ge 0$ and $S_{i,1} + p_{i,1} \le T$ for all $1 \le i \le j$, admits no valid assignment for the variables $S_{1,1}, \dots, S_{j,1}$.
* `LOAD 2`: The subsystem consisting exclusively of condition 5, along with the boundary requirements $S_{i,2} \ge 0$ and $S_{i,2} + p_{i,2} \le T$ for all $1 \le i \le j$, admits no valid assignment for the variables $S_{1,2}, \dots, S_{j,2}$.

*(Note: The boundary requirements for `LOAD 1` and `LOAD 2` isolate the interval-packing constraints from condition 2).*

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers $p_{i,1}$ and $p_{i,2}$ (1 ≤ $p_{i,1}, p_{i,2}$ ≤ 1000000): the constants for index $i$.

## Output

Print a single line containing either `JOB i` (where the subsystem for index **i** alone is impossible) or `LOAD c` (where the subsystem for interval packing **c** is impossible, with **c** being 1 or 2).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is the correct certificate because the subsystem for `JOB 1` requires $S_{1,1} \ge 0$, $S_{1,2} \ge S_{1,1} + 70$, and $S_{1,2} + 60 \le 100$. This implies $S_{1,1} + 130 \le 100$, which is impossible for any non-negative $S_{1,1}$. The interval packing subsystems are both satisfiable: `LOAD 1` requires packing intervals of total length 75 into a space of 100, and `LOAD 2` requires packing a total length of 66 into 100.

In Example 2, `LOAD 1` is the certificate. The subsystem requires finding four disjoint open intervals of length 50, all contained within the bounds $[0, 150]$. This requires a total length of 200 within a space of 150, which is impossible. The `JOB` subsystems are all satisfiable (each requires $50+1 \le 150$), and `LOAD 2` is satisfiable (requires packing a total length of 4 into 150).
</STATEMENT>
<RATIONALE>
The problem was completely reframed from a job-scheduling narrative into a formal mathematical system of inequalities and disjoint open intervals. This removes all direct mentions of arithmetic sums or sequential processing that models were using as shortcuts. To solve the problem, a model must now logically deduce that the impossibility of the interval-packing subsystem implies the sum of lengths exceeds T, and that the single-index subsystem implies the sum of its two constants exceeds T.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical conditions are perfectly equivalent to the original scheduling constraints: a sequential job exceeding the deadline corresponds to the `JOB i` subsystem being impossible, and a machine's total workload exceeding the deadline corresponds to the `LOAD c` disjoint-interval subsystem being impossible.
</PRESERVED_ANSWER>
