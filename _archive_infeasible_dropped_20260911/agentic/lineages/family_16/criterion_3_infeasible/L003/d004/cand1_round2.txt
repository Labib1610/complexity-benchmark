<STATEMENT>
# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A system processes **j** jobs through exactly two sequential stages. Every job must clear stage 1 completely before it can enter stage 2. A stage can only advance one job at any given moment.

Let $M$ be a $2 \times j$ matrix representing the processing times, where the entry $M_{c, i}$ is the required duration for job $i$ in stage $c$. 

There is a required time limit **T**: every job must be completely finished by time **T**.

For every input in this problem, it is guaranteed that the time limit cannot be met, no matter how the jobs are ordered. Your task is to prove the time limit is impossible by outputting a short certificate that can be checked directly against the input.

Exactly one of the following reasons will always apply. Print the certificate for the one that holds:

* `JOB i` (where **i** is a 1-based index): The isolated sequential processing of job **i** cannot fit within the deadline. Mathematically, this corresponds to the $\ell_1$-norm of the **i**-th column of $M$ being strictly greater than **T**.
* `LOAD c` (where **c** is either 1 or 2): The continuous back-to-back operation of stage **c** alone requires more time than the deadline. Mathematically, this corresponds to the $\ell_1$-norm of the **c**-th row of $M$ being strictly greater than **T**.

If multiple jobs satisfy the `JOB` condition, printing any one of their indices is valid. If both stages satisfy the `LOAD` condition, printing either `LOAD 1` or `LOAD 2` is valid.

## Input

The first line contains two integers **j** and **T** (1 ≤ **j** ≤ 200000, 1 ≤ **T** ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ **p1**, **p2** ≤ 1000000): the durations of a job in stage 1 and stage 2. These correspond to the entries $M_{1, i}$ and $M_{2, i}$ for the **i**-th job.

## Output

Print a single line containing either `JOB i` (where job **i**'s column $\ell_1$-norm exceeds **T**) or `LOAD c` (where stage **c**'s row $\ell_1$-norm exceeds **T**).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` proves the time limit is impossible because the $\ell_1$-norm of the 1st column is $|70| + |60| = 130$, which is strictly greater than the time limit of 100. 
In Example 2, `LOAD 1` is the certificate because the $\ell_1$-norm of the 1st row (stage 1's durations) is $|50| + |50| + |50| + |50| = 200$, which is strictly greater than the time limit of 150.
</STATEMENT>
<RATIONALE>
The explicit arithmetic shortcuts (`p1+p2 > T` and `sum > T`) were replaced with the mathematically equivalent $\ell_1$-norm of the columns and rows of a $2 \times j$ duration matrix. This forces models to genuinely map linear algebra concepts back to the scheduling problem rather than relying on surface-level text matching for the known bounds. The structural constraints and non-uniqueness guarantees were explicitly restored to address expert feedback.
</RATIONALE>
<PRESERVED_ANSWER>
The $\ell_1$-norm of a matrix column/row with positive entries is exactly the sum of its elements, keeping the `JOB i` and `LOAD c` conditions mathematically identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains in INFEASIBLE (co-NP style certification) because it still asks to verify the exact same linear time check for a single job or machine bottleneck.
</PRESERVED_CLASS>
<RISK>
Models might incorrectly compute the induced matrix norm instead of the vector norm of the specific row/column, but the text explicitly specifies "the $\ell_1$-norm of the i-th column" and "the c-th row", which unambiguously refers to the vector norm.
</RISK>
