# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given an integer **j** and a threshold **T**. You are also given **j** pairs of positive integers, where the **k**-th pair is $(u_k, v_k)$ for $1 \le k \le j$.

For each $k \in \{1, \dots, j\}$, define two step functions over the real numbers:
$F_k(x) = \begin{cases} 1 & \text{if } 0 \le x < u_k \\ 0 & \text{otherwise} \end{cases}$

$G_k(x) = \begin{cases} 1 & \text{if } 0 \le x < v_k \\ 0 & \text{otherwise} \end{cases}$

Furthermore, define the partial sums $S_k = \sum_{m=1}^{k-1} u_m$ and $R_k = \sum_{m=1}^{k-1} v_m$. For $k=1$, the empty sums evaluate to zero (i.e., $S_1 = 0$ and $R_1 = 0$).

For every input in this problem, it is mathematically guaranteed that exactly one of the following three integral inequalities evaluates to true. Your task is to determine which condition holds and output its corresponding certificate code:

* `JOB i` (where **i** is a 1-based index): 
  $\int_{0}^{\infty} F_i(x) \,dx + \int_{0}^{\infty} G_i(x) \,dx > T$

* `LOAD 1`: 
  $\int_{0}^{\infty} \left( \sum_{k=1}^j F_k(x - S_k) \right) dx > T$

* `LOAD 2`: 
  $\int_{0}^{\infty} \left( \sum_{k=1}^j G_k(x - R_k) \right) dx > T$

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **u_k** and **v_k** (1 ≤ u_k, v_k ≤ 1000000): the values for the **k**-th pair.

## Output

Print a single line containing either `JOB i` (where **i** is the index of the pair satisfying the first condition), `LOAD 1`, or `LOAD 2` (if the second or third condition is satisfied, respectively).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is the correct certificate because for $i=1$, $\int_{0}^{\infty} F_1(x) \,dx + \int_{0}^{\infty} G_1(x) \,dx = 70 + 60 = 130$, which is strictly greater than the threshold $T = 100$. 
In Example 2, `LOAD 1` is the correct certificate because the sum of the shifted functions $F_k(x - S_k)$ forms a single step function that is $1$ on the interval $[0, 200)$ and $0$ elsewhere. Its integral from $0$ to $\infty$ is $200$, which is strictly greater than the threshold $T = 150$.
