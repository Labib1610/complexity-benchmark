<METHOD_NAME>Matrix Norm Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Transforms the scheduling domain into a matrix property domain. The job duration sum becomes the L1 norm of a column vector, and the machine load sum becomes the L1 norm of a row vector. This prevents models from pattern-matching standard scheduling keywords while preserving the exact mathematical conditions.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a matrix $M$ of positive integers with exactly 2 rows and **j** columns, along with a threshold **T**. 

For every input in this problem, it is guaranteed that the matrix cannot satisfy a specific bounding condition relative to **T**. Your task is to prove this by outputting a short certificate that can be checked directly against the input.

Exactly one of the following reasons will always apply. Print the certificate for the one that holds:

* `JOB i` (where **i** is a 1-based column index): The $L_1$ norm of the **i**-th column vector of $M$ is strictly greater than **T**.
* `LOAD c` (where **c** is a row index, either 1 or 2): The $L_1$ norm of the **c**-th row vector of $M$ is strictly greater than **T**.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), defining the elements of the columns of $M$ in order. Specifically, the $i$-th such line provides the entries for the $i$-th column such that $M_{1, i}$ is **p1** and $M_{2, i}$ is **p2**.

## Output

Print a single line containing either `JOB i` (where the **i**-th column's $L_1$ norm extends past the threshold) or `LOAD c` (where the **c**-th row's $L_1$ norm extends past the threshold).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is the certificate because the $L_1$ norm of the 1st column vector is $70 + 60 = 130$, which strictly exceeds the threshold of 100. 
In Example 2, `LOAD 1` is the certificate because the $L_1$ norm of the 1st row vector is $50 + 50 + 50 + 50 = 200$, which strictly exceeds the threshold of 150.
</STATEMENT>
<RATIONALE>
Changed the domain from job scheduling to matrix properties. The condition for a job exceeding the deadline is recast as the $L_1$ norm of a column vector exceeding a threshold, and the machine load is recast as the $L_1$ norm of a row vector. This forces the model to understand the mathematical equivalence rather than relying on scheduling heuristics.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical conditions (column sum > T and row sum > T) are exactly identical to the original job duration and machine load conditions, ensuring identical outputs for all guaranteed-unique test cases.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires $O(j)$ time to compute the row and column sums and check them against the threshold, keeping it in the same complexity class.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the $L_1$ norm, although the Note explicitly demonstrates it as a simple sum of elements.
</RISK>
