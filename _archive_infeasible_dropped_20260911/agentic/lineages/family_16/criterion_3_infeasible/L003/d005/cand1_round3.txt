# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of inequalities and disjunctions over $4j$ real variables. For each element $i$ (where $1 \le i \le j$), there are four variables: $x_{i,1}, y_{i,1}, x_{i,2},$ and $y_{i,2}$. 
You are given a global bound $T$, and for each element $i$, two parameters $\Delta_{i,1}$ and $\Delta_{i,2}$.

A valid assignment to these variables must satisfy all of the following conditions for all $i, k \in \{1, \dots, j\}$ (with $i \neq k$) and $c \in \{1, 2\}$:
1. **Base bounds:** $x_{i,c} \ge 0$
2. **Offset bounds:** $y_{i,c} - x_{i,c} \ge \Delta_{i,c}$
3. **Cross-dimension link:** $x_{i,2} - y_{i,1} \ge 0$
4. **Separation:** $\max(x_{i,c} - y_{k,c},\ x_{k,c} - y_{i,c}) \ge 0$
5. **Global cap:** $y_{i,c} \le T$

For every test input, it is guaranteed that the full system of constraints has no valid assignment. Your task is to output a short certificate that proves the system is contradictory. For every test input, exactly one of these certificate types is guaranteed to apply. Print the one that holds:

* `JOB i` (where **i** is a 1-based index): The subset of constraints restricted only to the variables of element **i** (specifically, conditions 1, 2, 3, and 5 for a fixed $i$ across both dimensions) is already contradictory.
* `LOAD c` (where **c** is either 1 or 2): The subset of constraints restricted only to the variables of dimension **c** (specifically, conditions 1, 2, 4, and 5 for a fixed $c$ across all elements) is already contradictory.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers (1 ≤ d1, d2 ≤ 1000000): the parameters $\Delta_{i,1}$ and $\Delta_{i,2}$ for element $i$.

## Output

Print a single line containing either `JOB i` (where the isolated constraints for element **i** prove the system is contradictory) or `LOAD c` (where **c** is either 1 or 2, and the isolated constraints for dimension **c** prove the system is contradictory).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is the certificate. If we isolate the constraints for element 1, we require $y_{1,2} \ge x_{1,2} + 60 \ge y_{1,1} + 60 \ge x_{1,1} + 70 + 60 \ge 130$. This directly contradicts the global cap $y_{1,2} \le 100$.
In Example 2, `LOAD 1` is the certificate. If we isolate the constraints for dimension 1, the separation and offset bounds force the maximum $y_{i,1}$ among the 4 elements to be at least $4 \times 50 = 200$, which contradicts the global cap $y_{i,1} \le 150$.
</STATEMENT>
<RATIONALE>
I removed all scheduling terminology (entities, domains, span, sequential, non-overlap) and replaced it with a purely abstract system of real-valued inequalities and disjunctions. Models can no longer rely on semantic cues to guess that they should sum the parameters. Instead, they must formally analyze the subsystems to deduce that the element-isolated constraints are unsatisfiable iff $\Delta_{i,1} + \Delta_{i,2} > T$, and the dimension-isolated constraints are unsatisfiable iff $\sum \Delta_{i,c} > T$.
</RATIONALE>
<PRESERVED_ANSWER>
The element-isolated subsystem algebraically simplifies to $\Delta_{i,1} + \Delta_{i,2} > T$, and the dimension-isolated subsystem (a 1D continuous packing problem) simplifies to $\sum \Delta_{i,c} > T$, perfectly matching the exact mathematical conditions of the seed's `JOB` and `LOAD` certificates.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires an $O(N)$ linear scan to check individual sums and total sums against $T$; only the presentation of the rules has changed.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the certificate definitions as a requirement to literally deploy an SMT solver (like Z3) or LP solver on the subsystems, which would correctly identify the answers but fail due to Time Limit Exceeded given $N=200,000$.
</RISK>
