# Problem C — Spectral Band Allocation: Certify Contradiction

Time limit: 2 s   Memory limit: 256 MB

## Description

You are modeling the energy spectrum of a quantum system containing **j** particles. The system features exactly 2 energetic states: the ground state (state 1) and the excited state (state 2). 
Each particle $i$ (for $1 \le i \le j$) requires a ground state energy band $G_i$ and an excited state energy band $X_i$. 
Both $G_i$ and $X_i$ must be continuous, closed intervals of real numbers. You are given the minimum required width of these bands: $p_{i,1}$ for $G_i$ and $p_{i,2}$ for $X_i$.

A valid physical model must assign these intervals such that all of the following rules are satisfied:
- **Band Width:** The length of the interval $G_i$ (its maximum value minus its minimum value) must be at least $p_{i,1}$, and the length of $X_i$ must be at least $p_{i,2}$ for all $i$.
- **State Ordering:** For every particle $i$, no energy value in its ground band $G_i$ can be strictly greater than any energy value in its excited band $X_i$.
- **Exclusion Principle:** For a given state $c$ (where $c=1$ corresponds to the ground bands and $c=2$ corresponds to the excited bands), the interiors of the bands of any two distinct particles must be disjoint. (Bands of different particles may share boundary points).
- **System Bounds:** All bands $G_i$ and $X_i$ for all particles must be entirely contained within the absolute energy range $[0, T]$.

For every test input, it is guaranteed that no valid assignment of intervals exists. Your task is to output a short certificate that proves the model is contradictory. For every test input, exactly one of these certificate types is guaranteed to apply. Print the one that holds:

* `JOB i` (Joint Orbital Bounds for particle **i**, where **i** is a 1-based index): The constraints restricted only to particle **i** across both states (Band Width, State Ordering, and System Bounds) are already contradictory.
* `LOAD c` (Level Overlap Aggregation Denied for state **c**, where **c** is either 1 or 2): The constraints restricted only to state **c** across all particles (Band Width, Exclusion Principle, and System Bounds) are already contradictory.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the minimum required widths of particle $i$'s ground band and excited band, respectively.

## Output

Print a single line containing either `JOB i` (where the isolated constraints for particle **i** prove the system bounds are impossible) or `LOAD c` (where **c** is either 1 or 2, and the isolated constraints for state **c** prove the system bounds are impossible).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is the certificate because for particle 1, the Band Width and State Ordering constraints require that the maximum value of $X_1$ is at least the minimum value of $G_1$ plus $70 + 60 = 130$. Since the minimum value of $G_1$ cannot be less than 0, the maximum value of $X_1$ must be at least 130. This contradicts the System Bounds which require all values to be within $[0, 100]$.
In Example 2, `LOAD 1` is the certificate because state 1 (the ground state) has 4 particles each requiring a band of length 50. The Exclusion Principle requires the interiors of these 4 bands to be disjoint, so their union spans a total length of at least $4 \times 50 = 200$. This contradicts the System Bounds which restrict all bands to a range of length 150.
