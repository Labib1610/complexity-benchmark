# Problem C — Impossible System: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of inequalities over $2j$ real variables, denoted $X_1, X_2, \dots, X_j$ and $Y_1, Y_2, \dots, Y_j$.
The system is parameterized by a positive integer $T$ and $j$ pairs of positive integers. For each index $i$ (from 1 to $j$), the $i$-th pair is $(A_i, B_i)$.

A valid assignment of real numbers to the variables must satisfy all of the following rules:
- **(C1)** For all $i$: $X_i \ge A_i$ and $X_i + A_i \le 2T$
- **(C2)** For all $i$: $Y_i \ge B_i$ and $Y_i + B_i \le 2T$
- **(C3)** For all $i$: $Y_i - X_i \ge A_i + B_i$
- **(C4)** For all $i \neq k$: $|X_i - X_k| \ge A_i + A_k$
- **(C5)** For all $i \neq k$: $|Y_i - Y_k| \ge B_i + B_k$

For every test input, it is guaranteed that the full system of inequalities has no valid real solution. Your task is to output a short certificate that proves the system is contradictory. For every test input, exactly one of these certificate types is guaranteed to apply. Print the one that holds:

* `JOB i` (where **i** is a 1-based index): The subsystem consisting only of rules (C1), (C2), and (C3) restricted to the specific index **i** is already contradictory.
* `LOAD c` (where **c** is either 1 or 2): The subsystem restricted only to set **c** across all indices is already contradictory. Specifically, for $c=1$, this means rules (C1) and (C4) over $X_1 \dots X_j$ admit no solution. For $c=2$, this means rules (C2) and (C5) over $Y_1 \dots Y_j$ admit no solution.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **A_i** and **B_i** (1 ≤ A_i, B_i ≤ 1000000): the parameters for index $i$.

## Output

Print a single line containing either `JOB i` (where the isolated constraints for index **i** prove the system is impossible) or `LOAD c` (where **c** is either 1 or 2, and the isolated constraints for set **c** prove the system is impossible).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is the certificate because for index 1, rule (C1) requires $X_1 \ge 70$, and rule (C3) requires $Y_1 - X_1 \ge 130$. Adding these inequalities implies $Y_1 \ge 200$. However, rule (C2) requires $Y_1 + 60 \le 200$ (since $2T = 200$), which means $Y_1 \le 140$. This is a contradiction.

In Example 2, `LOAD 1` is the certificate because set 1 has 4 variables each with $A_i = 50$. Rule (C4) requires any two variables to have an absolute difference of at least 100. Rule (C1) requires all 4 variables to be within the range $X_i \ge 50$ and $X_i \le 250$ (since $2T = 300$). It is impossible to pick 4 values in the interval $[50, 250]$ such that any two are separated by at least 100.
