<STATEMENT>
# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a system of linear inequalities over $4j$ real variables. For each $i \in \{1, 2, \dots, j\}$, there are four variables: $u_i, v_i, w_i,$ and $z_i$.

The system is parameterized by a global bound $T$ and a set of $j$ pairs of positive integers $(p_{i,1}, p_{i,2})$. A valid assignment of real numbers to the variables must satisfy all of the following conditions:

* **Condition 1:** $v_i \ge p_{i,1}$ for all $i$.
* **Condition 2:** $z_i \ge p_{i,2}$ for all $i$.
* **Condition 3:** $u_i \ge v_i$ for all $i$.
* **Condition 4:** $w_i + z_i \le 2T$ for all $i$.
* **Condition 5:** $w_i - z_i \ge u_i + v_i$ for all $i$.
* **Condition 6:** For any $i \neq k$, either $u_i + v_i \le u_k - v_k$ or $u_k + v_k \le u_i - v_i$.
* **Condition 7:** For any $i \neq k$, either $w_i + z_i \le w_k - z_k$ or $w_k + z_k \le w_i - z_i$.

For every test input, it is guaranteed that no valid assignment of real numbers exists that satisfies all 7 conditions simultaneously. Your task is to output a short certificate that proves the system is contradictory. For every test input, exactly one of these certificate types is guaranteed to apply. Print the one that holds:

* `JOB i` (where **i** is a 1-based index): The subsystem consisting only of Conditions 1, 2, 3, 4, and 5 restricted to the variables for index **i** is already contradictory.
* `LOAD c` (where **c** is either 1 or 2):
  * If **c** = 1: The subsystem consisting only of Conditions 1, 3, 6, and the additional boundary condition $u_i + v_i \le 2T$ (for all $i$) is already contradictory.
  * If **c** = 2: The subsystem consisting only of Conditions 2, 4, 7, and the additional boundary condition $w_i - z_i \ge 0$ (for all $i$) is already contradictory.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the parameters $p_{i,1}$ and $p_{i,2}$ for index $i$.

## Output

Print a single line containing either `JOB i` (where the isolated subsystem for index **i** proves the system is contradictory) or `LOAD c` (where **c** is either 1 or 2, and the isolated subsystem for group **c** proves the system is contradictory).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is the certificate because for index 1, the subsystem requires $w_1 + z_1 \le 200$. From Condition 5, $w_1 - z_1 \ge u_1 + v_1$. From Condition 3, $u_1 \ge v_1$, so $w_1 - z_1 \ge 2v_1$. This implies $w_1 \ge 2v_1 + z_1$. Substituting this into Condition 4 gives $2v_1 + 2z_1 \le w_1 + z_1 \le 2T = 200$, so $v_1 + z_1 \le 100$. However, Conditions 1 and 2 require $v_1 \ge 70$ and $z_1 \ge 60$, meaning $v_1 + z_1 \ge 130$, which contradicts $v_1 + z_1 \le 100$.

In Example 2, `LOAD 1` is the certificate. For **c** = 1, Condition 6 enforces that the variables for the 4 indices cannot overlap in their values. Specifically, the algebraic span from the smallest $u_i - v_i$ to the largest $u_i + v_i$ must be at least $2 \sum v_i = 400$. However, Condition 3 ($u_i - v_i \ge 0$) and the boundary condition ($u_i + v_i \le 300$) restrict this span to at most 300, which is a contradiction.
