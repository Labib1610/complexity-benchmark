# Problem C — Impossible System: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of inequalities over $4j$ non-negative real variables: $X_{i,1}, Y_{i,1}, X_{i,2}, Y_{i,2}$ for $1 \le i \le j$.

The system is defined by a global constant $T$ and $2j$ individual constants $P_{i,1}, P_{i,2}$ for $1 \le i \le j$. All variables are inherently constrained to be non-negative ($X_{i,c} \ge 0, Y_{i,c} \ge 0$). The inequalities are grouped into five families:
- **Family 1:** $Y_{i,1} - X_{i,1} \ge P_{i,1}$ for all $i \in \{1, \dots, j\}$.
- **Family 2:** $Y_{i,2} - X_{i,2} \ge P_{i,2}$ for all $i \in \{1, \dots, j\}$.
- **Family 3:** $X_{i,2} \ge Y_{i,1}$ for all $i \in \{1, \dots, j\}$.
- **Family 4:** $Y_{i,c} \le T$ for all $i \in \{1, \dots, j\}$ and all $c \in \{1, 2\}$.
- **Family 5:** $\max(X_{i,c} - Y_{k,c}, X_{k,c} - Y_{i,c}) \ge 0$ for all $c \in \{1, 2\}$ and all pairs $i \neq k$.

For every test input, it is guaranteed that the full system has no valid assignment of variables. Your task is to output a short certificate that isolates the contradiction. For every test input, exactly one of the following restricted subsystems is guaranteed to have no solution. Print the label of the unique subsystem that is contradictory:

* `JOB i` (where $i$ is a 1-based index): The subsystem consisting of the non-negativity constraints for variables of index $i$, along with Families 1, 2, 3, and 4 restricted to this specific $i$.
* `LOAD c` (where $c \in \{1, 2\}$): The subsystem consisting of the non-negativity constraints for variables with second index $c$, along with Families $c$, 4, and 5 restricted to this specific $c$ across all $i$.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200,000$, $1 \le T \le 1,000,000,000$).
Each of the next $j$ lines contains two integers $P_{i,1}$ and $P_{i,2}$ ($1 \le P_{i,1}, P_{i,2} \le 1,000,000$).

## Output

Print a single line containing either `JOB i` (where the isolated subsystem for index $i$ is impossible) or `LOAD c` (where $c \in \{1, 2\}$, and the isolated subsystem for second index $c$ is impossible).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is the certificate because the subsystem for $i=1$ requires $Y_{1,2} \ge X_{1,2} + 60 \ge Y_{1,1} + 60 \ge X_{1,1} + 70 + 60 \ge 130$. Since $X_{1,1} \ge 0$, this implies $Y_{1,2} \ge 130$, which contradicts the Family 4 constraint $Y_{1,2} \le 100$.

In Example 2, `LOAD 1` is the certificate because the subsystem for $c=1$ requires four variables $Y_{i,1}$ to be bounded by 150 (Family 4), while Family 1 and Family 5 require them to represent the upper bounds of four non-overlapping intervals of length 50 in the non-negative domain. This requires the maximum $Y_{i,1}$ to be at least $4 \times 50 = 200$, contradicting $Y_{i,1} \le 150$.
