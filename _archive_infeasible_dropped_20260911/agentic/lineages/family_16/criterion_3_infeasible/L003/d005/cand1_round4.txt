<STATEMENT>
# Problem C — Inconsistent Systems: Uncovering the Contradiction

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of linear inequalities over $4j$ non-negative real variables. For a given positive integer $j$, the variables are $x_{i,c}$ and $y_{i,c}$ for all $i \in \{1, \dots, j\}$ and $c \in \{1, 2\}$.

The system is parameterized by a bound $T$ and a set of constants $d_{i,c} \ge 0$. A valid assignment must satisfy all of the following constraint families:

1. **Expansion:** For every $i \in \{1, \dots, j\}$ and every $c \in \{1, 2\}$, $y_{i,c} \ge x_{i,c} + d_{i,c}$.
2. **Phase linkage:** For every $i \in \{1, \dots, j\}$, $x_{i,2} \ge y_{i,1}$.
3. **Upper boundary:** For every $i \in \{1, \dots, j\}$ and every $c \in \{1, 2\}$, $y_{i,c} \le T$.
4. **Exclusion:** For every $c \in \{1, 2\}$ and every pair of distinct indices $i, k$ such that $1 \le i < k \le j$, either $x_{i,c} \ge y_{k,c}$ or $x_{k,c} \ge y_{i,c}$.

For every test input, it is guaranteed that the full system of constraints admits no valid assignment. Your task is to output a short certificate that isolates the source of the contradiction. For every test input, exactly one of these specific certificates is guaranteed to apply. Print the one that holds:

* `JOB i` (where $i$ is a 1-based index): The subsystem consisting only of the non-negativity requirements ($x_{i,c} \ge 0, y_{i,c} \ge 0$), Expansion, Phase linkage, and Upper boundary constraints restricted to this specific index $i$ is already logically inconsistent.
* `LOAD c` (where $c$ is either 1 or 2): The subsystem consisting only of the non-negativity requirements, Expansion, Exclusion, and Upper boundary constraints restricted to this specific dimension $c$ (across all indices $1 \le i \le j$) is already logically inconsistent.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $d_{i,1}$ and $d_{i,2}$ ($1 \le d_{i,1}, d_{i,2} \le 1000000$): the constants for index $i$ in dimension 1 and dimension 2.

## Output

Print a single line containing either `JOB i` (where the isolated constraints for index $i$ are inconsistent) or `LOAD c` (where $c$ is either 1 or 2, and the isolated constraints for dimension $c$ are inconsistent).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is the correct certificate because for index 1, the Expansion and Phase linkage constraints require $y_{1,2} \ge x_{1,2} + 60 \ge y_{1,1} + 60 \ge x_{1,1} + 70 + 60 \ge 130$. Since variables must be non-negative, $x_{1,1} \ge 0$, which forces $y_{1,2} \ge 130$. This contradicts the Upper boundary constraint $y_{1,2} \le 100$.

In Example 2, `LOAD 1` is the correct certificate because for dimension $c=1$, there are 4 indices, each with $d_{i,1} = 50$. The Expansion and Exclusion constraints force the intervals $[x_{i,1}, y_{i,1})$ to be disjoint and have length at least 50. The maximum $y_{i,1}$ across all $i$ must therefore be at least $4 \times 50 = 200$, which contradicts the Upper boundary constraint $y_{i,1} \le 150$.
</STATEMENT>
