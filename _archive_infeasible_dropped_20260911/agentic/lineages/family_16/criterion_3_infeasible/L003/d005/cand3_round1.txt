# Problem C — Inconsistent Inequality System

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a parameter $T$ and a set of $2j$ positive constants $p_{i,1}$ and $p_{i,2}$ for $1 \le i \le j$.
Consider a system of inequalities over $4j$ real variables $x_{i,c}$ and $y_{i,c}$ (for $1 \le i \le j$ and $c \in \{1, 2\}$).
A valid solution must satisfy all of the following conditions:
- **Difference condition:** $y_{i,c} - x_{i,c} \ge p_{i,c}$ for all $1 \le i \le j$ and $c \in \{1, 2\}$.
- **Chain condition:** $x_{i,2} \ge y_{i,1}$ for all $1 \le i \le j$.
- **Disjunction condition:** For each $c \in \{1, 2\}$, and for any pair of distinct indices $i$ and $k$, either $x_{i,c} \ge y_{k,c}$ or $x_{k,c} \ge y_{i,c}$.
- **Boundary condition:** $x_{i,c} \ge 0$ and $y_{i,c} \le T$ for all $1 \le i \le j$ and $c \in \{1, 2\}$.

Your task is to analyze the system and identify a minimal contradictory subsystem. You must output exactly one of the following formatted strings to identify the subsystem that is inherently inconsistent:

* `JOB i` : The subsystem restricted to a single index $i$ across both values of $c$ (using only the Difference, Chain, and Boundary conditions for that specific $i$) is inconsistent over the real numbers.
* `LOAD c` : The subsystem restricted to a single value $c$ across all indices $i$ (using only the Difference, Disjunction, and Boundary conditions for that specific $c$) is inconsistent over the real numbers.
* `SYSTEM` : The full system is inconsistent, but no single `JOB` or `LOAD` subsystem is inconsistent on its own. (For example, if $T=10$ and we have two indices with constants $(6, 4)$ and $(4, 6)$, both `JOB` and `LOAD` subsystems are perfectly consistent, but the full coupled system has no solution).

If multiple subsystems are inconsistent, report the one with the highest precedence: `JOB i` (prioritizing the smallest index $i$) > `LOAD c` (prioritizing $c=1$) > `SYSTEM`.

## Input

The first line contains two integers $j$ and $T$ (1 ≤ $j$ ≤ 200,000, 1 ≤ $T$ ≤ 1,000,000,000).
Each of the next $j$ lines contains two integers $p_{i,1}$ and $p_{i,2}$ (1 ≤ $p_{i,1}, p_{i,2}$ ≤ 1,000,000).

## Output

Print a single line containing the highest-precedence inconsistent subsystem (`JOB i`, `LOAD c`, or `SYSTEM`).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
