We can check both conditions directly:

- If any row sum \( D_{i,1} + D_{i,2} > T \), output `JOB i`.
- Otherwise, if any column sum \( \sum_{i} D_{i,1} > T \) or \( \sum_{i} D_{i,2} > T \), output `LOAD 1` or `LOAD 2` respectively.

Since the problem guarantees at least one condition holds, we just check in that order.

```python
j, T = map(int, input().split())
d1 = []
d2 = []
for i in range(j):
    a, b = map(int, input().split())
    d1.append(a)
    d2.append(b)
    if a + b > T:
        print(f"JOB {i+1}")
        exit()

if sum(d1) > T:
    print("LOAD 1")
elif sum(d2) > T:
    print("LOAD 2")
```
