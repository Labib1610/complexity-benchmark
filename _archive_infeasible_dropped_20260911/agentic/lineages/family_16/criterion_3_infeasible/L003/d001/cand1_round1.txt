# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A processing pipeline handles **j** items across two sequential stations. Each item must be completely processed at station 1 before it can be routed to station 2. Neither station has parallel capabilities; each processes one item at a time.

You are given a strict deadline **T** by which all items must have completed station 2.

In every test case, this deadline is structurally impossible to meet. Your task is to output a certificate that proves the impossibility by identifying a constraint whose absolute minimum time requirement strictly exceeds **T**.

The certificate must be one of the following, and exactly one will apply:

- `JOB i` : The end-to-end critical path of item **i** (1-based) strictly exceeds the deadline. Because an item's phases must occur disjointly in time, its total transit time cannot be compressed below the combined duration of its two phases.
- `LOAD c` : The total sequential work demanded of station **c** (1 or 2) strictly exceeds the deadline. Because a station lacks parallel capabilities, its active time cannot be compressed below the combined duration of all items processed at that station.

You must evaluate these minimum time requirements and print the single certificate that exceeds **T**.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the processing times of an item at station 1 and station 2.

## Output

Print a single line containing the applicable certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, the end-to-end critical path for item 1 requires 70 time units at station 1 followed by 60 time units at station 2. Because these phases must occur disjointly, its minimum transit time is 130. This exceeds the deadline of 100, so `JOB 1` proves the impossibility.

In Example 2, no single item's critical path exceeds 150. However, station 1 must process four items sequentially for 50 time units each. Its minimum sequential work is therefore 200, which exceeds 150. Thus, `LOAD 1` is the certificate.
