# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A system processes **j** jobs through exactly two sequential stages. Every job must clear stage 1 completely before it can enter stage 2. For each job, you are given its required duration in stage 1 and in stage 2. A stage can only advance one job at any given moment.

There is a required time limit **T**: every job must be completely finished by time **T**.

For every input in this problem, it is guaranteed that the time limit cannot be met, no matter how the jobs are ordered. Your task is to prove the time limit is impossible by outputting a short certificate that can be checked directly against the input. 

Exactly one of the following reasons always applies. Print the one that holds:

**Sequential constraint violation:** Because a job's stages cannot overlap, it requires its stage 1 duration plus its stage 2 duration to complete. If there is a job whose stage 1 duration plus its stage 2 duration is strictly greater than **T**, print `JOB i`, where **i** (1-based index) is such a job.

**Capacity constraint violation:** Because a stage processes jobs serially, it must be active for at least the sum of all durations assigned to it. If the sum of all stage 1 durations is strictly greater than **T**, print `LOAD 1`. If the sum of all stage 2 durations is strictly greater than **T**, print `LOAD 2`.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the durations of a job in stage 1 and stage 2.

## Output

Print a single line containing either `JOB i` (where job **i**'s total duration exceeds **T**) or `LOAD c` (where the sum of durations for stage **c** exceeds **T**).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, job 1 requires 70 + 60 = 130 > 100 time units without overlap, so `JOB 1` proves the time limit is impossible. 
In Example 2, no single job exceeds 150, but stage 1 must process 50 + 50 + 50 + 50 = 200 > 150 units of work serially, so `LOAD 1` is the certificate.
