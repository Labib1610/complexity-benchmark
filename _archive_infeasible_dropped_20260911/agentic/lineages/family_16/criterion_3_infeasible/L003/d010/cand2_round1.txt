# Problem C — Impossible Ferry Loading

Time limit: 2 s   Memory limit: 256 MB

## Description

You are verifying the safety constraints for a cargo ferry. The ferry's loading protocol is defined by a system of inequalities over a set of real-valued variables.

For a ferry with a capacity parameter **T** and **j** transport teams, a valid configuration requires assigning four real numbers $(u_i, v_i, w_i, z_i)$ to each team $i$ (for $1 \le i \le j$). The given parameters $p_{i,1}$ and $p_{i,2}$ represent the primary and secondary dimension constants for team $i$.

A configuration is valid if and only if it satisfies all of the following constraint rules:
1. **Dimension:** For Domain 1, $v_i - u_i = p_{i,1}$. For Domain 2, $z_i - w_i = p_{i,2}$.
2. **Domain Assignment:** For each team $i$, variables $u_i$ and $v_i$ are assigned to Domain 1. Variables $w_i$ and $z_i$ are assigned to Domain 2.
3. **Bounds:** Every variable must be bounded between $0$ and $T$. For Domain 1, $0 \le u_i < v_i \le T$. For Domain 2, $0 \le w_i < z_i \le T$.
4. **Exclusivity:** For Domain 1, any two distinct teams $a$ and $b$ must satisfy $(v_a \le u_b) \lor (v_b \le u_a)$. For Domain 2, any two distinct teams $a$ and $b$ must satisfy $(z_a \le w_b) \lor (z_b \le w_a)$.
5. **Sequence:** For every team $i$, their variables must satisfy $v_i \le w_i$.

For every test input, it is guaranteed that no valid assignment of real numbers exists. Your task is to output a short certificate that proves the rules are contradictory. 

To do this, you must identify the fundamental bottleneck by finding a specific subset of these rules that is already impossible to satisfy on its own. Exactly one of the following isolated rule subsets is guaranteed to be contradictory (even when all other rules and variables are ignored). Print the certificate for the unique subset that fails:

* `JOB i` (where **i** is a 1-based index, $1 \le i \le j$): The subset consisting only of Rules 1, 2, 3, and 5, enforced exclusively on the variables $(u_i, v_i, w_i, z_i)$ of team $i$. (All other rules, and variables for all other teams, are ignored).
* `LOAD c` (where **c** is either 1 or 2): The subset consisting only of Rules 1, 2, 3, and 4, enforced exclusively on the variables assigned to Domain $c$. (All other rules, and all variables assigned to the other domain, are ignored).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing $p_{i,1}$ and $p_{i,2}$ respectively for team $i$.

## Output

Print a single line containing either `JOB i` (where **i** is a 1-based index, $1 \le i \le j$) or `LOAD c` (where **c** is either 1 or 2), corresponding to the unique rule subset that remains impossible.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is the correct certificate. If we only enforce the Dimension, Domain Assignment, Bounds, and Sequence rules for team 1, their variables must satisfy $0 \le u_1 < v_1 \le w_1 < z_1 \le 100$, with $v_1 - u_1 = 70$ and $z_1 - w_1 = 60$. This implies $z_1 - u_1 \ge 130$, which contradicts the bound $z_1 \le 100$.

In Example 2, `LOAD 1` is the correct certificate. If we only enforce the Dimension, Domain Assignment, Bounds, and Exclusivity rules for Domain 1, we must find four pairs of variables $(u_i, v_i)$ within $[0, 150]$ such that $v_i - u_i = 50$ and no two pairs overlap ($(v_a \le u_b) \lor (v_b \le u_a)$). This requires a total coordinate span of at least $200$, which contradicts the $150$ bounds.
</STATEMENT>
<RATIONALE>
The models were using the spatial terminology ("parking length", "non-overlapping", "ahead of") to immediately map the problem to summing lengths and checking against `T`. I removed this affordance by translating the physical layout constraints into a pure system of algebraic inequalities. The models must now genuinely analyze the exclusivity and sequence rules to deduce that they imply the exact same sum-based bottlenecks, rather than relying on pattern matching to physical packing scenarios.
</RATIONALE>
<PRESERVED_ANSWER>
The system of inequalities is mathematically isomorphic to the original physical rules: `JOB i` fails if and only if $p_{i,1} + p_{i,2} > T$, and `LOAD c` fails if and only if the sum of dimension constants for Domain $c$ exceeds $T$.
</PRESERVED_ANSWER>

The complexity class remains identical because the underlying bottleneck conditions ($O(N)$ checks for pairwise sums and total sums) have not changed.
