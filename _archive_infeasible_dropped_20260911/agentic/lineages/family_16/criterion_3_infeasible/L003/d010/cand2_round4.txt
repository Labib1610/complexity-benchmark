# Problem C — Impossible Memory Allocation

Time limit: 2 s   Memory limit: 256 MB

## Description

You are programming a memory controller for a system with two independent memory banks, Bank 1 and Bank 2. Each bank provides a contiguous address space from $0$ to $T$.

There are $j$ processes. Each process $i$ (for $1 \le i \le j$) requires an instruction buffer of exactly $p_{i,1}$ bytes in Bank 1 and a data buffer of exactly $p_{i,2}$ bytes in Bank 2. All buffers must be allocated as contiguous blocks of memory within their respective banks, and no two buffers within the same bank may overlap (though they may abut).

Additionally, to ensure safe prefetching, the memory controller enforces a strict cross-bank address dependency for every process: the starting address of a process's data buffer in Bank 2 must be numerically greater than or equal to the ending address of its instruction buffer in Bank 1. 

For every test input, it is guaranteed that the system is out of memory and no valid allocation exists. Your task is to output a short certificate proving the requirements are contradictory. 

You must identify a specific isolated reason for the failure. Output one of the following certificates:

* `JOB i` (where $i$ is a 1-based index, $1 \le i \le j$): The sizes of the buffers for process $i$, combined with its cross-bank address dependency and the $T$-byte bank limits, form a contradiction on their own (even if all other processes and overlap rules are ignored).
* `LOAD 1`: The instruction buffer sizes for all processes, combined with the non-overlapping requirement in Bank 1 and the $T$-byte limit, form a contradiction (even if Bank 2 and all dependencies are ignored).
* `LOAD 2`: The data buffer sizes for all processes, combined with the non-overlapping requirement in Bank 2 and the $T$-byte limit, form a contradiction (even if Bank 1 and all dependencies are ignored).

It is guaranteed that for every input, at least one of these specific contradictions is present. If multiple certificates are valid for a given input, you may output any one of them.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing $p_{i,1}$ and $p_{i,2}$ respectively for process $i$.

## Output

Print a single line containing either `JOB i` (where $i$ is a 1-based index, $1 \le i \le j$) or `LOAD c` (where $c$ is either 1 or 2), corresponding to a valid contradictory rule subset.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is a correct certificate. If we only enforce the rules for process 1, its instruction and data buffers must be placed such that the data buffer starts after the instruction buffer ends. This requires a total address span of 130 bytes, which is impossible given the $100$-byte bounds of the banks.

In Example 2, `LOAD 1` is a correct certificate. If we only enforce the non-overlapping rules for Bank 1, all four instruction buffers must be placed in Bank 1. This requires 200 bytes of space, which is impossible given the bank's $150$-byte capacity.
