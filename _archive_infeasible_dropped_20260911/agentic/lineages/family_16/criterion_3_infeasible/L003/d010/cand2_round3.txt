# Problem C — Infeasible Function Spaces

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a functional analysis problem involving two continuous domains, Domain 1 and Domain 2. Both domains are defined over the real interval $[0, T]$.

There are **j** parameter pairs. Each pair $i$ (for $1 \le i \le j$) provides two positive integers $p_{i,1}$ and $p_{i,2}$.

A valid system must define an indicator function (a function taking values in $\{0, 1\}$) for every parameter, satisfying all of the following analytical rules:
1. **Measure:** The definite integral $\int_0^T I_{i,1}(x) dx$ exactly equals $p_{i,1}$. The integral $\int_0^T I_{i,2}(x) dx$ exactly equals $p_{i,2}$.
2. **Domain Assignment:** All first indicator functions $I_{i,1}$ are defined on Domain 1. All second indicator functions $I_{i,2}$ are defined on Domain 2.
3. **Contiguous Support:** The support of every indicator function (the set of points where it equals 1) must be a single contiguous interval completely contained within $[0, T]$.
4. **Orthogonality:** Indicator functions defined on the same domain cannot overlap on sets of positive measure. For any $a \neq b$ and domain $c \in \{1, 2\}$, $\int_0^T I_{a,c}(x) I_{b,c}(x) dx = 0$.
5. **Sup-Inf Precedence:** For every pair $i$, the supremum of the support of $I_{i,1}$ must be less than or equal to the infimum of the support of $I_{i,2}$.

For every test input, it is guaranteed that no valid system of functions exists. Your task is to output a short certificate that proves the rules are contradictory. 

To do this, you must identify the fundamental bottleneck by finding a specific subset of these rules that is already impossible to satisfy on its own. Exactly one of the following isolated rule subsets is guaranteed to be contradictory (even when all other rules and functions are ignored). Print the certificate for the unique subset that fails:

* `JOB i` (where **i** is a 1-based index, $1 \le i \le j$): The subset consisting only of Rules 1, 2, 3, and 5, enforced exclusively on the two indicator functions of pair $i$. (All other rules, and all other pairs, are ignored).
* `LOAD c` (where **c** is either 1 or 2): The subset consisting only of Rules 1, 2, 3, and 4, enforced exclusively on the indicator functions assigned to Domain $c$. (All other rules, and all functions assigned to the other domain, are ignored).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing $p_{i,1}$ and $p_{i,2}$ respectively for pair $i$.

## Output

Print a single line containing either `JOB i` (where **i** is a 1-based index, $1 \le i \le j$) or `LOAD c` (where **c** is either 1 or 2), corresponding to the unique rule subset that remains impossible.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is the correct certificate. If we only enforce the Measure, Domain Assignment, Contiguous Support, and Sup-Inf Precedence rules for pair 1, their two indicator functions must be supported on disjoint, ordered intervals within the $[0, 100]$ domain. This is analytically impossible given their required integrals of 70 and 60, as their combined measure exceeds the domain size.

In Example 2, `LOAD 1` is the correct certificate. If we only enforce the Measure, Domain Assignment, Contiguous Support, and Orthogonality rules for Domain 1, all four first indicator functions must have mutually orthogonal supports within Domain 1. This is impossible given the domain's measure of 150 and the aggregate required integral of 200.
