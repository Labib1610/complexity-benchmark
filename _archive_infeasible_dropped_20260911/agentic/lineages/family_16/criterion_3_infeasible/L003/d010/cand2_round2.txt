# Problem C — System of Inequalities

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a mathematical system of inequalities over $2j$ real variables. The variables are paired as $(x_i, y_i)$ for $1 \le i \le j$. 
The system is parameterized by a global constant **T** and $j$ pairs of positive constants $(p_{i,1}, p_{i,2})$.

A valid assignment must choose real values for all $x_i$ and $y_i$ such that all of the following constraints are satisfied simultaneously:
1. **Domain 1:** For all $i$, $0 \le x_i$ and $x_i + p_{i, 1} \le T$.
2. **Domain 2:** For all $i$, $0 \le y_i$ and $y_i + p_{i, 2} \le T$.
3. **Precedence:** For all $i$, $x_i + p_{i, 1} \le y_i$.
4. **Separation 1:** For any distinct $i$ and $k$, either $x_k - x_i \ge p_{i, 1}$ or $x_i - x_k \ge p_{k, 1}$.
5. **Separation 2:** For any distinct $i$ and $k$, either $y_k - y_i \ge p_{i, 2}$ or $y_i - y_k \ge p_{k, 2}$.

For every test input, it is guaranteed that no valid assignment exists for the full system. Your task is to output a short certificate that proves the system is contradictory. 

You must identify a specific isolated subset of these constraints that is impossible to satisfy on its own. Output any certificate that satisfies one of the allowed conditions. Print a valid certificate corresponding to a contradictory allowed subset:

* `JOB i` (where **i** is a 1-based index, $1 \le i \le j$): The subset consisting only of constraints 1, 2, and 3, enforced exclusively on the variables $x_i$ and $y_i$, forms a contradiction. (All other constraints and variables are ignored). Print `JOB i` for **any** 1-based index $i$ such that this subsystem is inconsistent.
* `LOAD c` (where **c** is either 1 or 2): If $c=1$, the subset consisting only of constraints 1 and 4, enforced exclusively on the variables $x_1 \dots x_j$, forms a contradiction. If $c=2$, the subset consisting only of constraints 2 and 5, enforced exclusively on the variables $y_1 \dots y_j$, forms a contradiction. Print `LOAD c` for any $c \in \{1, 2\}$ such that the corresponding subsystem is inconsistent.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing $p_{i,1}$ and $p_{i,2}$ respectively for $i = 1 \dots j$.

## Output

Print a single line containing either `JOB i` (where **i** is a 1-based index, $1 \le i \le j$) or `LOAD c` (where **c** is either 1 or 2), corresponding to a contradictory allowed subset.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, one valid certificate is `JOB 1`. If we only enforce the Domain 1, Domain 2, and Precedence constraints for $i=1$, we require $x_1 \ge 0$, $y_1 \le 100 - 60 = 40$, and $y_1 - x_1 \ge 70$. This implies $40 \ge y_1 \ge x_1 + 70 \ge 70$, which is impossible.

In Example 2, one valid certificate is `LOAD 1`. If we only enforce the Domain 1 and Separation 1 constraints for all $i$, all four $x_i$ variables must be placed in the interval $[0, 150]$ such that every pair is separated by at least $50$. This requires at least $4 \times 50 = 200$ total space, which is impossible within the bound $T=150$.
