# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A factory processes **j** jobs through exactly two machines. Every job is processed on machine 1 first and then on machine 2. For each job you are given its processing time on machine 1 and on machine 2. Each machine processes only one job at a time, and a job reaches machine 2 only after finishing on machine 1.

There is a required deadline **T**: every job must be completely finished by time **T**. 

For all inputs in this problem, it is guaranteed that the deadline is impossible to meet. Your task is to output a short certificate proving this impossibility. A valid certificate must take one of the following forms:

- `JOB i` — where **i** (1-based) is the index of a job that inherently requires more sequential time from start to finish than the deadline permits.
- `LOAD c` — where **c** is 1 or 2, representing a machine that is assigned more total work than the duration of the deadline allows it to complete.

Output the applicable certificate. You may assume that exactly one such certificate is valid for each given input.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the processing times of a job on machine 1 and machine 2.

## Output

Print a single line containing the certificate of impossibility: either `JOB i` (where i is the job index) or `LOAD c` (where c is the machine number).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, job 1 requires 70 time units on machine 1 and 60 time units on machine 2. Even if it were the only task, it inherently requires 130 sequential time units, which strictly exceeds the deadline of 100. Thus, `JOB 1` is the valid certificate.

In Example 2, no single job exceeds the deadline on its own. However, machine 1 is required to operate for a combined 200 time units overall. Since it processes tasks one at a time, its total work exceeds the 150-unit deadline, making `LOAD 1` the valid certificate.
