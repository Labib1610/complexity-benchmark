# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A data pipeline processes **j** batches through exactly two sequential stages. Every batch must be completely processed in stage 1 before it can move to stage 2. For each batch, you are given its processing time in stage 1 and stage 2. Each stage can only process one batch at a time.

There is a strict latency requirement **T**: the entire set of batches must be fully processed through both stages by time **T**. In general, finding a valid processing sequence requires evaluating the **j!** possible batch orderings to see if any permutation meets the latency requirement.

For the inputs provided in this problem, no sequence among the **j!** possibilities will successfully meet the latency requirement **T**. Instead of searching for a valid sequence, you must output a short certificate proving that the latency requirement is impossible to meet.

A certificate is considered valid if it meets one of the following criteria:
- `JOB i` (where $i$ is the 1-based batch index): Valid if and only if $p1_i + p2_i > T$.
- `LOAD c` (where $c \in \{1, 2\}$): Valid if and only if the sum of processing times across all batches in stage $c$ is strictly greater than $T$. (That is, $\sum_{k=1}^j p1_k > T$ for $c=1$, or $\sum_{k=1}^j p2_k > T$ for $c=2$).

For every test case, you are guaranteed that exactly one of the two reason categories applies (either there is at least one valid `JOB` certificate, or there is at least one valid `LOAD` certificate). If multiple valid certificates exist (e.g., multiple batches satisfy the `JOB` condition, or multiple stages satisfy the `LOAD` condition), you may print any one of them.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the processing times of a batch in stage 1 and stage 2.

## Output

Print a single line containing a valid certificate of impossibility: either `JOB i` (where $i$ is the 1-based batch index) or `LOAD c` (where $c$ is the stage number). If multiple valid certificates exist, print any one of them.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, batch 1 requires $70 + 60 = 130$ time units sequentially across the two stages. Since $130 > 100$, `JOB 1` is a valid certificate. In Example 2, no single batch violates the latency requirement on its own, but the first stage is required to operate for a combined $200$ time units overall. Since $200 > 150$, `LOAD 1` is a valid certificate.
