# Problem C — Impossible Set Selection: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given **j** tasks. For each task $k$ (where $k$ is a 1-based index from 1 to **j**), you must construct two real-valued matrices: $M_{1,k}$ (belonging to group 1) and $M_{2,k}$ (belonging to group 2).

The matrix $M_{1,k}$ must be constructed to have exactly **r1** rows.
The matrix $M_{2,k}$ must be constructed to have exactly **r2** rows.

A valid construction must satisfy three rules:

- **Rule 1 (Column Space):** Every constructed matrix must have exactly $\mathbf{T}$ columns.
- **Rule 2 (Group Independence):** For a given group $c \in \{1, 2\}$, if you vertically concatenate the matrices $M_{c,1}, M_{c,2}, \dots, M_{c,j}$ into a single large block matrix, the resulting matrix must have linearly independent rows (i.e., it must have full row rank).
- **Rule 3 (Task Independence):** For a given task $k$, if you vertically concatenate the matrices $M_{1,k}$ and $M_{2,k}$ into a single block matrix, the resulting matrix must have linearly independent rows.

For all test cases provided in this problem, it is guaranteed that no valid construction can satisfy all three rules simultaneously. Your objective is to certify this impossibility by identifying a localized contradiction. Exactly one of the following two types of certificates will be valid for the given input. Print the one that applies:

- **Task-specific contradiction:** There is a single task **i** (1-based index) such that Rule 1 (for task **i**) and Rule 3 (for task **i**) cannot be simultaneously satisfied, even if we completely ignore Rule 2 and all other tasks. Print: `JOB i`.
- **Group-specific contradiction:** There is a single group **c** (where **c** is 1 or 2) such that Rule 1 (for group **c**) and Rule 2 (for group **c**) cannot be simultaneously satisfied, even if we completely ignore Rule 3 and the other group. Print: `LOAD c`.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **r1** and **r2** (1 ≤ r1, r2 ≤ 1000000): the required number of rows for $M_{1,k}$ and $M_{2,k}$ respectively.

## Output

Print a single line containing the certificate of impossibility: either `JOB i` (where i is the task index) or `LOAD c` (where c is the group number).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, consider task 1. The required row counts are 70 for $M_{1,1}$ and 60 for $M_{2,1}$. Rule 3 requires that their vertical concatenation (which would have $70 + 60 = 130$ rows) has linearly independent rows. However, Rule 1 strictly limits every matrix to exactly 100 columns. A matrix with 130 rows and 100 columns cannot possibly have linearly independent rows. Thus, it is impossible to construct these matrices, and `JOB 1` is the correct certificate.

In Example 2, no single task violates the rules on its own. However, consider group 1. Rule 2 requires the vertical concatenation of the four $M_{1,k}$ matrices (each having 50 rows) to have linearly independent rows. This concatenated matrix would have $50 \times 4 = 200$ rows. Since it is restricted to exactly 150 columns by Rule 1, it cannot have linearly independent rows. Thus, `LOAD 1` is the correct certificate.

<METHOD_DESCRIPTION>Replaces the original geometric interval-packing domain with an isomorphic linear algebra domain. Instead of disjoint intervals embedded in a discrete universe of size T, the problem asks for matrices with linearly independent rows embedded in a column space of dimension T. This completely removes the coordinates x, y, z that the models used to algebraically derive the capacity constraint, forcing them to reason about matrix rank bounds from scratch.</METHOD_DESCRIPTION>

<RATIONALE>
I completely replaced the geometric domain of interval packing with an isomorphic linear algebra domain involving matrix rank. By defining the constraints as requiring vertically concatenated matrices to have linearly independent rows, the condition mathematically simplifies to the exact same additive capacity check (rows ≤ columns). This removes all references to coordinates and intervals, preventing models from relying on their memorized `z - x = p1 + p2` derivation.
</RATIONALE>
<PRESERVED_ANSWER>
The condition for a matrix of size R x T to have linearly independent rows is exactly R ≤ T; thus, the row-sum checks perfectly mirror the original interval-length sum checks, triggering exactly the same certificates for every input.
</PRESERVED_ANSWER>
