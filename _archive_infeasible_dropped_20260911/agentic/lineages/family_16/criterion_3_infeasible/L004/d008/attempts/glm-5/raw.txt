Looking at this problem, I need to find either:
1. A job where p1+p2 > T (can't fit the contiguous block in the universe)
2. A collection where the total sum of sizes exceeds T (can't fit disjoint sets)

The key insight is that if neither condition holds, a valid construction exists. For each job k, I can assign S1,k = {sum of previous p1 values + 1, ..., sum of previous p1 values + p1} and S2,k = {that + p1 + 1, ..., that + p1 + p2}. Since all p1+p2 ≤ T and total sums ≤ T, these blocks fit within [1,T] and are disjoint within each collection.

So I just need to check both conditions and output whichever applies first.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    idx = 0
    j = int(data[idx]); idx += 1
    T = int(data[idx]); idx += 1
    
    sum1 = 0
    sum2 = 0
    job_ans = -1
    
    for i in range(1, j + 1):
        p1 = int(data[idx]); idx += 1
        p2 = int(data[idx]); idx += 1
        if p1 + p2 > T and job_ans == -1:
            job_ans = i
        sum1 += p1
        sum2 += p2
    
    if job_ans != -1:
        print(f"JOB {job_ans}")
        return
    
    if sum1 > T:
        print("LOAD 1")
        return
    
    if sum2 > T:
        print("LOAD 2")
        return
    
    # Should not reach here per problem guarantee
    print("LOAD 1")

main()
```
