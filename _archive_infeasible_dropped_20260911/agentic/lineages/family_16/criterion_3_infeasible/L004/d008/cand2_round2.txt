<METHOD_DESCRIPTION>Replaces explicit coordinate equations (y-x=p1, z-y=p2) defining contiguous intervals with an equivalent structural rule about the difference between the maximum and minimum elements across the two sets. <STATEMENT>
# Problem C — Impossible Set Selection: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given **j** jobs. For each job $k$ (where $k$ is a 1-based index from 1 to **j**), you must construct two sets of integers: $S_{1,k}$ (belonging to collection 1) and $S_{2,k}$ (belonging to collection 2). 

The number of elements in $S_{1,k}$ must exactly equal **p1**.
The number of elements in $S_{2,k}$ must exactly equal **p2**.

A valid construction must satisfy three rules:

- **Rule 1 (Domain):** All elements of every generated set must be chosen strictly from the integer universe $\{1, 2, \dots, \mathbf{T}\}$.
- **Rule 2 (Disjointness):** For a given collection $c \in \{1, 2\}$, the sets $S_{c,1}, S_{c,2}, \dots, S_{c,j}$ must be mutually disjoint (no two sets in the same collection can share any integers).
- **Rule 3 (Strict Precedence):** For a given job $k$, every integer in $S_{1,k}$ must be strictly less than every integer in $S_{2,k}$. Additionally, the difference between the greatest element in $S_{2,k}$ and the least element in $S_{1,k}$ must be exactly one less than the cardinality of the union $S_{1,k} \cup S_{2,k}$.

For all test cases provided in this problem, it is guaranteed that no valid construction can satisfy all three rules simultaneously. Your task is to certify this impossibility by identifying a localized contradiction. Exactly one of the following two types of certificates will be valid for the given input. Print the one that applies:

- **Job-specific contradiction:** There is a single job **i** (1-based index) such that Rule 1 (for job **i**) and Rule 3 (for job **i**) cannot be simultaneously satisfied, even if we completely ignore Rule 2 and all other jobs. Print: `JOB i`.
- **Collection-specific contradiction:** There is a single collection **c** (where **c** is 1 or 2) such that Rule 1 (for collection **c**) and Rule 2 (for collection **c**) cannot be simultaneously satisfied, even if we completely ignore Rule 3 and the other collection. Print: `LOAD c`.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required sizes of $S_{1,k}$ and $S_{2,k}$ respectively.

## Output

Print a single line containing the certificate of impossibility: either `JOB i` (where i is the job index) or `LOAD c` (where c is the collection number).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, consider job 1. The required sizes are 70 for $S_{1,1}$ and 60 for $S_{2,1}$. Rule 3 requires all elements in $S_{1,1}$ to be strictly less than those in $S_{2,1}$, meaning the sets are disjoint and the cardinality of their union is 130. Rule 3 also requires the difference between the maximum element of $S_{2,1}$ and the minimum element of $S_{1,1}$ to be exactly 129. This means the elements must span a contiguous range of 130 integers. Given Rule 1, all elements must be chosen from the universe of integers up to 100, which cannot accommodate a span of 130. Thus, `JOB 1` is the correct certificate. 

In Example 2, no single job violates the rules on its own. However, consider collection 1. Rule 2 requires the four $S_{1,k}$ sets (each of size 50) to be mutually disjoint. This requires 200 distinct integers. Rule 1 restricts the available integers to the universe $\{1, 2, \dots, 150\}$. It is impossible to choose 200 distinct integers from a universe of 150. Thus, `LOAD 1` is the correct certificate.
</STATEMENT>
<RATIONALE>
The explicit half-open interval coordinates (`x_k`, `y_k`, `z_k`) and their algebraic relationships (`y_k - x_k = p1`) have been replaced with an equivalent condition on the overall span of the sets. Models can no longer pattern-match the algebraic equations to natively deduce `p1 + p2 > T`, and must instead logically deduce that a span of `p1 + p2 - 1` for `p1 + p2` elements implies a contiguous block of length `p1 + p2`.
</RATIONALE>
<PRESERVED_ANSWER>
The span condition mathematically forces the union of the two sets to be a contiguous block of `p1 + p2` integers, making the required integer universe capacity identical to the original problem for all cases.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires an $O(N)$ linear scan to check if any individual job's combined size exceeds $T$, or if either collection's sum of sizes exceeds $T$.
</PRESERVED_CLASS>
