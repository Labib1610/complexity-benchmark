<STATEMENT>
# Problem C — Impossible Set Selection: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given **j** broadcast jobs. For each job $k$ (where $k$ is a 1-based index from 1 to **j**), you must allocate two frequency bands: a transmission band $B_{1,k}$ (band type 1) and a receiving band $B_{2,k}$ (band type 2).

Each band must be a contiguous range of discrete frequency channels.
The transmission band $B_{1,k}$ requires a bandwidth of exactly **p1** channels.
The receiving band $B_{2,k}$ requires a bandwidth of exactly **p2** channels.

A valid allocation must satisfy three rules:

- **Rule 1 (Spectrum Limit):** All allocated frequency channels across all bands must fall strictly within an uninterrupted block of **T** available discrete channels.
- **Rule 2 (Interference-Free):** For a given band type $c \in \{1, 2\}$, the bands $B_{c,1}, B_{c,2}, \dots, B_{c,j}$ must be mutually disjoint (no two jobs can share a frequency channel for the same band type).
- **Rule 3 (Phase Continuity):** For a given job $k$, every frequency channel in its transmission band $B_{1,k}$ must be strictly lower than every channel in its receiving band $B_{2,k}$. Additionally, the two bands must be perfectly adjacent: there can be no unallocated gaps between the highest channel of $B_{1,k}$ and the lowest channel of $B_{2,k}$.

For all test cases provided in this problem, it is guaranteed that no valid allocation can satisfy all three rules simultaneously. Your task is to certify this impossibility by identifying a localized contradiction. Exactly one of the following two types of certificates will be valid for the given input. Print the one that applies:

- **Job-specific contradiction:** There is a single job **i** (1-based index) such that Rule 1 (for job **i**) and Rule 3 (for job **i**) cannot be simultaneously satisfied, even if we completely ignore Rule 2 and all other jobs. Print: `JOB i`.
- **Collection-specific contradiction:** There is a single band type **c** (where **c** is 1 or 2) such that Rule 1 (for band type **c**) and Rule 2 (for band type **c**) cannot be simultaneously satisfied, even if we completely ignore Rule 3 and the other band type. Print: `LOAD c`.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required bandwidths (in number of channels) for $B_{1,k}$ and $B_{2,k}$ respectively.

## Output

Print a single line containing the certificate of impossibility: either `JOB i` (where i is the job index) or `LOAD c` (where c is the band type).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, consider job 1. The required bandwidths dictate that $B_{1,1}$ spans 70 channels and $B_{2,1}$ spans 60 channels. Rule 3 requires these bands to be adjacent and in strict order, meaning they form a combined continuous block of 130 channels. Given the spectrum limit of 100 channels (Rule 1), it is impossible to place this combined block. Thus, `JOB 1` is the correct certificate. 

In Example 2, no single job violates the rules on its own. However, consider band type 1. Rule 2 requires the four $B_{1,k}$ bands (each requiring 50 channels) to be mutually disjoint. Since all bands must be formed within the 150 available channels (Rule 1), four disjoint bands of 50 channels each would require at least 200 channels, which contradicts Rule 1. Thus, `LOAD 1` is the correct certificate.
