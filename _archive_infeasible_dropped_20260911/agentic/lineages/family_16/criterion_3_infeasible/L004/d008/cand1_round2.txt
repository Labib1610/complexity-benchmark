# Problem C — Impossible Set Selection: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given **j** jobs. For each job $k$ (where $k$ is a 1-based index from 1 to **j**), you must construct two sets of integers: $S_{1,k}$ (belonging to collection 1) and $S_{2,k}$ (belonging to collection 2). 

The number of elements in $S_{1,k}$ must exactly equal **p1**.
The number of elements in $S_{2,k}$ must exactly equal **p2**.

A valid construction must satisfy three rules:

- **Rule 1 (Domain):** All selected integers for every generated set must fall strictly within the integer universe $\{1, 2, \dots, \mathbf{T}\}$. To guarantee this, the sets must satisfy $S_{1,k} \subseteq \{1, 2, \dots, \mathbf{T}\}$ and $S_{2,k} \subseteq \{1, 2, \dots, \mathbf{T}\}$.
- **Rule 2 (Disjointness):** For a given collection $c \in \{1, 2\}$, the sets $S_{c,1}, S_{c,2}, \dots, S_{c,j}$ must be mutually disjoint (no two sets in the same collection can share any integers).
- **Rule 3 (Sequential Contiguity):** For a given job $k$, the union $S_{1,k} \cup S_{2,k}$ must consist of consecutive integers (i.e., it forms a single contiguous block with no gaps). Furthermore, every integer in $S_{1,k}$ must be strictly less than every integer in $S_{2,k}$.

For all test cases provided in this problem, it is guaranteed that no valid construction can satisfy all three rules simultaneously. Your task is to certify this impossibility by identifying a localized contradiction. Exactly one of the following two types of certificates will be valid for the given input. Print the one that applies:

- **Job-specific contradiction:** There is a single job **i** (1-based index) such that Rule 1 (for job **i**) and Rule 3 (for job **i**) cannot be simultaneously satisfied, even if we completely ignore Rule 2 and all other jobs. Print: `JOB i`.
- **Collection-specific contradiction:** There is a single collection **c** (where **c** is 1 or 2) such that Rule 1 (for collection **c**) and Rule 2 (for collection **c**) cannot be simultaneously satisfied, even if we completely ignore Rule 3 and the other collection. Print: `LOAD c`.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required sizes of $S_{1,k}$ and $S_{2,k}$ respectively.

## Output

Print a single line containing the certificate of impossibility: either `JOB i` (where i is the job index) or `LOAD c` (where c is the collection number).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, consider job 1. The required sizes dictate that $|S_{1,1}| = 70$ and $|S_{2,1}| = 60$. By Rule 3, their union must form a set of consecutive integers, and all elements in $S_{1,1}$ must strictly precede those in $S_{2,1}$. This implies the union must be a contiguous block of $70 + 60 = 130$ distinct integers. However, Rule 1 restricts all integers to the universe $\{1, 2, \dots, 100\}$, which can only accommodate at most 100 integers. Thus, Rule 1 and Rule 3 cannot be simultaneously satisfied for job 1. `JOB 1` is the correct certificate. 

In Example 2, no single job violates the rules on its own. However, consider collection 1. Rule 2 requires the four $S_{1,k}$ sets (each of size 50) to be mutually disjoint. This requires a total of $4 \times 50 = 200$ distinct integers. Since Rule 1 restricts all sets to the universe $\{1, 2, \dots, 150\}$, it is impossible to find 200 distinct integers. Thus, Rule 1 and Rule 2 cannot be simultaneously satisfied for collection 1, making `LOAD 1` the correct certificate.
