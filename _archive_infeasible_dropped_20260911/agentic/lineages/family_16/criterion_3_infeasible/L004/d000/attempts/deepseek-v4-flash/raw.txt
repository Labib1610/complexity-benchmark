We can solve this by scanning the jobs once, checking both conditions in order:

1. If any job has `p1 + p2 > T`, print `JOB i` immediately.
2. Otherwise, accumulate totals for machine 1 and machine 2.  
   If either total exceeds `T`, print `LOAD c`.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    j = int(data[0])
    T = int(data[1])
    
    total1 = 0
    total2 = 0
    
    idx = 2
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        
        total1 += p1
        total2 += p2
        
        if total1 > T:
            print("LOAD 1")
            return
        if total2 > T:
            print("LOAD 2")
            return

if __name__ == "__main__":
    main()
```
