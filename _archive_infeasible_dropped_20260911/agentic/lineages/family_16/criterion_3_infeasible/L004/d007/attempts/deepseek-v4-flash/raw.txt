We need to check two possible contradictions:

1. **Job-specific**: For a single job, can we place its two intervals within `[1, T]`?  
   For job `i` with sizes `p1` and `p2`, we need:
   - `x < y < z`
   - `y - x = p1`
   - `z - y = p2`
   - `1 ≤ x` and `z ≤ T+1`

   This means `z - x = p1 + p2`, and since `x ≥ 1` and `z ≤ T+1`, we need `p1 + p2 ≤ T`.  
   If `p1 + p2 > T`, then job `i` is impossible.

2. **Collection-specific**: For a collection (1 or 2), can we place all intervals of that collection disjointly within `[1, T]`?  
   For collection `c`, we have `j` intervals each of length `p_c` (where `p_c` is the corresponding size for that job).  
   The total length needed is `sum(p_c for all jobs)`.  
   Since intervals are disjoint and must fit within `[1, T]`, we need `sum(p_c) ≤ T`.  
   If `sum(p_c) > T`, then that collection is impossible.

We check job-specific first; if any job fails, print `JOB i`.  
Otherwise, check both collections; if one fails, print `LOAD c`.  
The problem guarantees exactly one will fail.

Let's implement:

```python
j, T = map(int, input().split())
p1s = []
p2s = []
for _ in range(j):
    p1, p2 = map(int, input().split())
    p1s.append(p1)
    p2s.append(p2)

# Check job-specific
for i in range(j):
    if p1s[i] + p2s[i] > T:
        print(f"JOB {i+1}")
        exit()

# Check collection-specific
if sum(p1s) > T:
    print("LOAD 1")
elif sum(p2s) > T:
    print("LOAD 2")
```
