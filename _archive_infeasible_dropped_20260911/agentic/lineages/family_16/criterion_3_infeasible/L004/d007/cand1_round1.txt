<STATEMENT>
# Problem C — Impossible Set Selection: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given **j** jobs. For each job $k$ (where $k$ is a 1-based index from 1 to **j**), you must construct two sets of integers: $S_{1,k}$ (belonging to collection 1) and $S_{2,k}$ (belonging to collection 2). 

To define these sets, you must assign three integer coordinates $x_k$, $y_k$, and $z_k$ for each job. The sets are defined as half-open intervals of integers:
- $S_{1,k} = \{ v \in \mathbb{Z} \mid x_k \le v < y_k \}$
- $S_{2,k} = \{ v \in \mathbb{Z} \mid y_k \le v < z_k \}$

The number of elements in $S_{1,k}$ (which evaluates to $y_k - x_k$) must exactly equal **p1**.
The number of elements in $S_{2,k}$ (which evaluates to $z_k - y_k$) must exactly equal **p2**.

A valid construction must satisfy three rules:

- **Rule 1 (Domain):** All selected coordinates must be constrained such that the elements of every generated set fall strictly within the integer universe $\{1, 2, \dots, \mathbf{T}\}$. To guarantee this, the coordinates must satisfy $1 \le x_k$ and $z_k \le \mathbf{T} + 1$.
- **Rule 2 (Disjointness):** For a given collection $c \in \{1, 2\}$, the sets $S_{c,1}, S_{c,2}, \dots, S_{c,j}$ must be mutually disjoint (no two sets in the same collection can share any integers).
- **Rule 3 (Strict Precedence):** For a given job $k$, the coordinates must satisfy $x_k < y_k < z_k$, ensuring that every integer in $S_{1,k}$ is strictly less than every integer in $S_{2,k}$.

For all test cases provided in this problem, it is guaranteed that no valid construction can satisfy all three rules simultaneously. Your task is to certify this impossibility by identifying a localized contradiction. Exactly one of the following two types of certificates will be valid for the given input. Print the one that applies:

- **Job-specific contradiction:** There is a single job **i** (1-based index) such that Rule 1 (for job **i**) and Rule 3 (for job **i**) cannot be simultaneously satisfied, even if we completely ignore Rule 2 and all other jobs. Print: `JOB i`.
- **Collection-specific contradiction:** There is a single collection **c** (where **c** is 1 or 2) such that Rule 1 (for collection **c**) and Rule 2 (for collection **c**) cannot be simultaneously satisfied, even if we completely ignore Rule 3 and the other collection. Print: `LOAD c`.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required sizes of $S_{1,k}$ and $S_{2,k}$ respectively.

## Output

Print a single line containing the certificate of impossibility: either `JOB i` (where i is the job index) or `LOAD c` (where c is the collection number).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, consider job 1. The required sizes dictate that $y_1 - x_1 = 70$ and $z_1 - y_1 = 60$, meaning $z_1 - x_1 = 130$. Given the domain constraints on the coordinates ($1 \le x_1$ and $z_1 \le 101$), it is impossible to place these boundaries without violating Rule 1. Thus, `JOB 1` is the correct certificate. 

In Example 2, no single job violates the rules on its own. However, consider collection 1. Rule 2 requires the four $S_{1,k}$ sets (each of size 50) to be mutually disjoint. Since all sets must be formed within the coordinate bounds up to $151$, four disjoint sets of size 50 would require an upper coordinate bound of at least $1 + 200 = 201$, which contradicts Rule 1. Thus, `LOAD 1` is the correct certificate.

<RATIONALE>
The problem was reformulated using half-open integer intervals [x, y) and [y, z). This elegantly shifts the domain's upper bound coordinate to T + 1 while keeping the mathematical capacity exactly T. Models that rely on superficial pattern matching will extract T + 1 as the new capacity limit and check `p1 + p2 > T + 1`, causing them to fail on tight-bound test cases where rigorous deduction correctly yields `p1 + p2 > T`.
</RATIONALE>
<PRESERVED_ANSWER>
The number of integers in a half-open interval [a, b) is exactly b - a, and the constraint 1 <= x and z <= T + 1 perfectly bounds the generated integers within {1, ..., T}, making the underlying subset selection mathematically identical to the seed problem.
