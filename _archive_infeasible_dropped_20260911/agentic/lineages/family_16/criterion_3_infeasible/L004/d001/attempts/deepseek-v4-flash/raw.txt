We can check two simple conditions:

1. If any job has `p1 + p2 > T`, then that job alone cannot finish in time → output `JOB i`.
2. Otherwise, if the sum of all `p1` exceeds `T`, machine 1 is overloaded → output `LOAD 1`.  
   Similarly, if the sum of all `p2` exceeds `T`, machine 2 is overloaded → output `LOAD 2`.

If neither condition holds, the problem guarantees one of them will, so we just check in that order.

```python
j, T = map(int, input().split())
total1 = 0
total2 = 0
for i in range(1, j + 1):
    p1, p2 = map(int, input().split())
    if p1 + p2 > T:
        print(f"JOB {i}")
        exit()
    total1 += p1
    total2 += p2

if total1 > T:
    print("LOAD 1")
elif total2 > T:
    print("LOAD 2")
```
