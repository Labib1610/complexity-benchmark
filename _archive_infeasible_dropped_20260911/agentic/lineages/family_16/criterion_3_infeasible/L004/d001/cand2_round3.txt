# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing facility must process **j** items using two sequential stages. Every item must first complete stage 1, and only then can it begin stage 2. Stage 1 and stage 2 are handled by separate, dedicated equipment. Each piece of equipment can handle only one item at a time. The durations required for stage 1 and stage 2 for each item are provided.

All operations must be fully completed by a strict time limit **T**. 

For the specific scenarios provided in this test, no valid ordering of items exists that can meet the time limit **T**. Your task is to provide a brief proof that the limit is unreachable. Due to the nature of the test cases, exactly one of the following two fundamental constraints will always be violated, and you must output the corresponding proof:

- **Individual Item Constraint:** An item requires its full duration on the first equipment followed immediately by its full duration on the second. If an item cannot possibly complete within the time limit even if it were the only item in the facility, output `JOB i` where **i** (1-based) is the index of that item.
- **Equipment Capacity Constraint:** Each piece of equipment processes items one by one. If the total active duration required by all items on a single piece of equipment exceeds the time available before **T**, output `LOAD c` where **c** is 1 or 2, representing the equipment that exceeds the limit.

Exactly one of these two constraint violations will apply to any given input. You should output the proof for the one that holds.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the durations required for the item on stage 1 and stage 2, respectively.

## Output

Print a single line containing the proof of impossibility: either `JOB i` (where **i** is the 1-based index of the item violating the individual constraint) or `LOAD c` (where **c** is 1 or 2, representing the equipment violating the capacity constraint). Exactly one of these will apply.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, the first item requires 70 time units on stage 1 and 60 on stage 2 sequentially. Since this spans 130 time units and 130 > 100, it cannot finish by the limit, so `JOB 1` is the proof.
In Example 2, no single item violates the individual constraint. However, the equipment for stage 1 must be active for 50+50+50+50 = 200 time units in total. Since 200 > 150, the limit is unreachable, so `LOAD 1` is the proof.
