# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A factory processes **j** jobs through exactly two machines. Every job must be processed on machine 1 first, and subsequently on machine 2. For each job, its processing time on machine 1 and machine 2 is given. Each machine can process at most one job at any given moment, and a job cannot begin processing on machine 2 until it has entirely finished on machine 1.

The factory has a strict deadline **T**: all jobs must be fully completed by time **T**. Determining whether a valid schedule exists typically involves evaluating up to **j!** possible processing sequences to find one that completes before the deadline.

However, for all inputs provided in this problem, it is guaranteed that no valid schedule can meet the deadline **T**. Your task is not to search for a schedule, but to output a short certificate that mathematically proves the deadline is impossible. 

The impossibility can always be proven by demonstrating a fundamental bottleneck. You must output a valid certificate in one of the following two formats. If multiple certificates (of the same or different types) are valid for a given input, outputting any one of them is acceptable.

- `JOB i` : This certificate proves impossibility by isolating a single job **i** (1-based index). It is valid if and only if the inherent sequential requirement of job **i** (its processing time on machine 1 plus its processing time on machine 2) strictly exceeds **T**.
- `LOAD c` : This certificate proves impossibility based on the total volume of work assigned to a single machine **c** (where **c** is 1 or 2). It is valid if and only if the sum of the processing times of all **j** jobs on machine **c** strictly exceeds **T**.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
The following **j** lines each contain two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the processing times of the job on machine 1 and machine 2, respectively.

## Output

Print a single line containing any valid certificate: either `JOB i` (where **i** is the 1-based index of a qualifying job) or `LOAD c` (where **c** is 1 or 2 for a qualifying machine).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In the first example, the first job requires 70 units of time on machine 1 and 60 units on machine 2. Since it must be processed sequentially, it requires at least 130 time units, which exceeds the deadline of 100. Thus, `JOB 1` is a valid certificate.
In the second example, no individual job exceeds the deadline. However, machine 1 has a total of 200 units of work assigned to it. Since machine 1 can only process one job at a time, it cannot finish in 150 time units. Thus, `LOAD 1` is a valid certificate.
