<STATEMENT>
# Problem C — Impossible Set Selection: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of assignments for **j** queries. For each query $k$ (where $k$ is an integer from 1 to **j**), you must populate two sets of integers: $A_{k,1}$ (for dimension 1) and $A_{k,2}$ (for dimension 2). There are exactly 2 dimensions in this system.

The number of distinct integers in $A_{k,1}$ must be exactly **p1**.
The number of distinct integers in $A_{k,2}$ must be exactly **p2**.

A valid system must satisfy three axioms:

- **Axiom I (Bounds):** All assigned integers must be bounded by **T**. Formally, $A_{k,c} \subseteq \mathbb{Z} \cap [1, \mathbf{T}]$ for all $k \in \{1, \dots, \mathbf{j}\}$ and $c \in \{1, 2\}$.
- **Axiom II (Orthogonality):** For a fixed dimension $c \in \{1, 2\}$, the sum of the sizes of the sets across all queries must equal the size of their overall union. That is, $\sum_{k=1}^{\mathbf{j}} |A_{k,c}| = |\bigcup_{k=1}^{\mathbf{j}} A_{k,c}|$.
- **Axiom III (Sequential Cohesion):** For a fixed query $k$, no integer $z$ exists such that $\min(A_{k,1}) < z < \max(A_{k,2})$ and $z \notin (A_{k,1} \cup A_{k,2})$. Furthermore, the Cartesian product $A_{k,1} \times A_{k,2}$ contains no pair $(x, y)$ where $x \ge y$.

For all test cases provided in this problem, it is guaranteed that no valid assignment can satisfy all three axioms simultaneously. Your task is to identify and print the localized contradiction. Exactly one of the following two certificates will be valid for the given input:

- **Query-specific contradiction:** There is a single query **i** (1-based index) such that Axiom I and Axiom III cannot be simultaneously satisfied for query **i**, even if we completely ignore Axiom II and all other queries. Print: `JOB i`.
- **Dimension-specific contradiction:** There is a single dimension **c** (where **c** is 1 or 2) such that Axiom I and Axiom II cannot be simultaneously satisfied for dimension **c**, even if we completely ignore Axiom III and the other dimension. Print: `LOAD c`.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required exact number of distinct integers for $A_{k,1}$ and $A_{k,2}$ respectively.

## Output

Print a single line containing the certificate of impossibility: either `JOB i` (where i is the query index) or `LOAD c` (where c is the dimension number).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, consider query 1. The required sizes dictate that $|A_{1,1}| = 70$ and $|A_{1,2}| = 60$. By Axiom III, the Cartesian product constraint implies all elements in $A_{1,1}$ are strictly less than those in $A_{1,2}$, meaning the sets are disjoint. The missing-integer constraint implies their union forms a single block of integers without gaps. Thus, the union must span exactly $70 + 60 = 130$ distinct integers. However, Axiom I restricts all integers to the interval $[1, 100]$, which can only accommodate at most 100 distinct values. Thus, Axiom I and Axiom III contradict for query 1. `JOB 1` is the correct certificate.

In Example 2, no single query violates the axioms on its own. However, consider dimension 1. Axiom II requires the sum of the set sizes to equal the size of their union, which implies the four $A_{k,1}$ sets (each of size 50) must be mutually disjoint. This requires a union of exactly $4 \times 50 = 200$ distinct integers. Since Axiom I restricts all sets to the interval $[1, 150]$, finding 200 distinct integers is impossible. Thus, Axiom I and Axiom II contradict for dimension 1, making `LOAD 1` the correct certificate.

<RATIONALE>
The rewrite replaces the natural-language terminology ("disjoint", "contiguous", "strictly less than") with formal mathematical axioms. Disjointness is expressed through cardinality sums matching union sizes, and contiguity/ordering is expressed through missing-integer conditions and Cartesian product constraints. This forces the model to deduce the mathematical implications (p1+p2 > T and sum(p) > T) instead of pattern-matching standard problem-statement phrasing.
</RATIONALE>
