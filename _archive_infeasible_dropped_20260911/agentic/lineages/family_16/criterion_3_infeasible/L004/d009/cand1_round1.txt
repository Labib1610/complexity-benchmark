# Problem C — Impossible Array Synthesis: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given **j** jobs. For each job $k$ (where $k$ is a 1-based index from 1 to **j**), you must construct two binary arrays: $A_k$ and $B_k$. 

The array $A_k$ must contain exactly **p1** instances of the value `1`.
The array $B_k$ must contain exactly **p2** instances of the value `1`.

A valid construction must satisfy three rules:

- **Rule 1 (Dimensionality):** Every array $A_k$ and $B_k$ must have a fixed length of exactly **T** elements, indexed from 1 to **T**. All elements must be strictly either `0` or `1`.
- **Rule 2 (Columnar Sparsity):** If you stack all arrays $A_1, A_2, \dots, A_j$ as rows to form a matrix, the sum of the values in any single column must not exceed 1. The exact same independent restriction applies to the matrix formed by stacking all arrays $B_1, B_2, \dots, B_j$ as rows.
- **Rule 3 (Sequential Contiguity):** For a given job $k$, define a combined array $C_k$ such that $C_k[x] = 1$ if $A_k[x] = 1$ or $B_k[x] = 1$ (or both), and $C_k[x] = 0$ otherwise. The array $C_k$ must consist of a single uninterrupted contiguous block of `1`s, with all other elements being `0`. Furthermore, there must not exist any index $u$ where $B_k[u] = 1$ and an index $v \ge u$ where $A_k[v] = 1$.

For all test cases provided in this problem, it is guaranteed that no valid construction can satisfy all three rules simultaneously. Your task is to certify this impossibility by identifying a localized contradiction. Exactly one of the following two types of certificates will be valid for the given input. Print the one that applies:

- **Job-specific contradiction:** There is a single job **i** (1-based index) such that Rule 1 (for job **i**) and Rule 3 (for job **i**) cannot be simultaneously satisfied, even if we completely ignore Rule 2 and all other jobs. Print: `JOB i`.
- **Load-specific contradiction:** There is a single load **c** (where **c**=1 refers to the $A$ arrays, and **c**=2 refers to the $B$ arrays) such that Rule 1 (for load **c**) and Rule 2 (for load **c**) cannot be simultaneously satisfied, even if we completely ignore Rule 3 and the other load. Print: `LOAD c`.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required number of `1`s in $A_k$ and $B_k$ respectively, for that job.

## Output

Print a single line containing the certificate of impossibility: either `JOB i` (where i is the job index) or `LOAD c` (where c is the load number).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, consider job 1. The required counts dictate that $A_1$ has 70 ones and $B_1$ has 60 ones. By Rule 3, $C_1$ must form a single contiguous block of `1`s. The condition that no index $u$ with $B_1[u]=1$ can be less than or equal to any index $v$ with $A_1[v]=1$ implies that $A_1$ and $B_1$ cannot share any indices where they are both `1` (which would mean $u=v$). Because they do not overlap, the number of `1`s in $C_1$ is exactly the sum of the number of `1`s in $A_1$ and $B_1$, which is $70 + 60 = 130$. However, Rule 1 restricts the array length to 100, which can accommodate at most 100 ones. Thus, Rule 1 and Rule 3 cannot be simultaneously satisfied for job 1. `JOB 1` is the correct certificate. 

In Example 2, no single job violates the rules on its own. However, consider load 1 (the $A$ arrays). Rule 2 requires that across all four $A$ arrays (each containing 50 ones), no column sum exceeds 1. This requires a total of $4 \times 50 = 200$ distinct columns to hold the ones. Since Rule 1 restricts the arrays to exactly 150 elements, it is impossible to place 200 ones without exceeding a column sum of 1. Thus, Rule 1 and Rule 2 cannot be simultaneously satisfied for load 1, making `LOAD 1` the correct certificate.
