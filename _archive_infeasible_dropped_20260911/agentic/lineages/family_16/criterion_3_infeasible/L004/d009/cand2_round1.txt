# Problem C — Impossible Set Selection: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are configuring a control system for **j** jobs. The system consists of two switchboards: Board 1 and Board 2. Both boards have **j** rows (each row corresponding to a job, from 1 to **j**) and **T** columns (numbered 1 to **T**). Every switch in these boards can be either ON or OFF.

For each job $k$, you must turn ON exactly **p1** switches in row $k$ of Board 1, and exactly **p2** switches in row $k$ of Board 2.

A valid configuration must satisfy three rules:

- **Rule 1 (Grid Boundaries):** All ON switches must be located strictly within the **T** available columns of the boards.
- **Rule 2 (Vertical Isolation):** Within Board 1, any given column may contain at most one ON switch across all **j** rows (representing the maximum load a column can handle). This same load restriction applies independently to Board 2.
- **Rule 3 (Horizontal Sequence):** For any specific job $k$, consider the column indices of all ON switches in row $k$ across both boards combined. These indices must form an uninterrupted sequence of consecutive integers. Furthermore, for job $k$, every ON switch in Board 1 must be located in a column strictly to the left of every ON switch in Board 2.

For all test cases provided, it is guaranteed that no configuration can satisfy all three rules simultaneously. Your task is to certify this impossibility by identifying a localized contradiction. Exactly one of the following two types of certificates will be valid. Print the one that applies:

- **Job-specific contradiction:** There is a single job **i** (1-based index) such that Rule 1 and Rule 3 cannot be simultaneously satisfied for its row, even if we completely ignore Rule 2 and all other jobs. Print: `JOB i`.
- **Board-specific contradiction (Overload):** There is a single board **c** (where **c** is 1 or 2) such that Rule 1 and Rule 2 cannot be simultaneously satisfied for board **c**, even if we completely ignore Rule 3 and the other board. Print: `LOAD c`.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required number of ON switches for job $k$ in Board 1 and Board 2 respectively.

## Output

Print a single line containing the certificate of impossibility: either `JOB i` (where i is the job index) or `LOAD c` (where c is the board number).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, consider job 1. The requirements dictate that exactly 70 switches must be ON in Board 1 and 60 switches in Board 2 for this job's row. By Rule 3, their combined column indices must form an uninterrupted sequence, and all ON switches in Board 1 must strictly precede those in Board 2. This implies the ON switches for job 1 must span a continuous horizontal block of $70 + 60 = 130$ distinct columns. However, Rule 1 restricts the boards to exactly 100 columns, which can only accommodate a sequence of at most 100 switches. Thus, Rule 1 and Rule 3 cannot be simultaneously satisfied for job 1. `JOB 1` is the correct certificate. 

In Example 2, no single job violates the rules on its own. However, consider Board 1. The requirements dictate that each of the four jobs must have 50 switches ON in Board 1. By Rule 2, no column in Board 1 can contain more than one ON switch. This requires a total of $4 \times 50 = 200$ distinct columns to accommodate all jobs without vertical overlap. Since Rule 1 restricts the board to exactly 150 columns, it is impossible to satisfy this load. Thus, Rule 1 and Rule 2 cannot be simultaneously satisfied for Board 1, making `LOAD 1` the correct certificate.
