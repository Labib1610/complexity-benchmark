We can check both possible contradictions:

- **Job-specific**: For each job, if `p1 + p2 > T`, then Rule 1 and Rule 3 cannot both hold for that job.
- **Load-specific**: For each load type, if the sum of all `p1` (or `p2`) across all jobs exceeds `T`, then Rule 1 and Rule 2 cannot both hold for that load type.

Since the problem guarantees exactly one certificate is valid, we check jobs first, then loads.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    p1_list = []
    p2_list = []
    idx = 2
    for i in range(j):
        p1 = int(data[idx])
        p2 = int(data[idx+1])
        idx += 2
        p1_list.append(p1)
        p2_list.append(p2)
        if p1 + p2 > T:
            print(f"JOB {i+1}")
            return

    if sum(p1_list) > T:
        print("LOAD 1")
        return
    if sum(p2_list) > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
