<STATEMENT>
# Problem C — Impossible Set Selection: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given **j** jobs. For each job $k$ (where $k$ is a 1-based index from 1 to **j**), you must construct two discrete sets of integers: $S_{1,k}$ (belonging to collection 1) and $S_{2,k}$ (belonging to collection 2). 

The exact required cardinality for $S_{1,k}$ is **p1**.
The exact required cardinality for $S_{2,k}$ is **p2**.

A valid system of sets must satisfy three axioms:

- **Axiom I (Bounded Universe):** All elements in every set must be chosen from the discrete interval $[1, \mathbf{T}]$. Formally, for all $k$ and for all $c \in \{1, 2\}$, $S_{c,k} \subseteq \{x \in \mathbb{Z} \mid 1 \le x \le \mathbf{T}\}$.
- **Axiom II (Orthogonality):** For a given collection $c \in \{1, 2\}$, the cardinality of the union of all sets in that collection must equal the sum of their individual cardinalities. Formally, $\left| \bigcup_{k=1}^j S_{c,k} \right| = \sum_{k=1}^j |S_{c,k}|$.
- **Axiom III (Span and Precedence):** For a given job $k$, the arithmetic difference between the maximum element of $S_{2,k}$ and the minimum element of $S_{1,k}$ must be exactly $|S_{1,k}| + |S_{2,k}| - 1$. Furthermore, every element in $S_{1,k}$ must be strictly less than every element in $S_{2,k}$.

For all test cases provided in this problem, it is guaranteed that no valid system of sets can satisfy all three axioms simultaneously. Your task is to certify this impossibility by identifying a localized contradiction. Exactly one of the following two types of certificates will be valid for the given input. Print the one that applies:

- **Job-specific contradiction:** There is a single job **i** (1-based index) such that Axiom I (for job **i**) and Axiom III (for job **i**) cannot be simultaneously satisfied, even if we completely ignore Axiom II and all other jobs. Print: `JOB i`.
- **Collection-specific contradiction:** There is a single collection **c** (where **c** is 1 or 2) such that Axiom I (for collection **c**) and Axiom II (for collection **c**) cannot be simultaneously satisfied, even if we completely ignore Axiom III and the other collection. Print: `LOAD c`.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required cardinalities of $S_{1,k}$ and $S_{2,k}$ respectively.

## Output

Print a single line containing the certificate of impossibility: either `JOB i` (where i is the job index) or `LOAD c` (where c is the collection number).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, consider job 1. The required cardinalities dictate that $|S_{1,1}| = 70$ and $|S_{2,1}| = 60$. By Axiom III, the difference between the maximum of $S_{2,1}$ and the minimum of $S_{1,1}$ must be exactly $70 + 60 - 1 = 129$. However, Axiom I restricts all elements to the interval $[1, 100]$, meaning the maximum possible difference between any two elements is $100 - 1 = 99$. Thus, Axiom I and Axiom III cannot be simultaneously satisfied for job 1. `JOB 1` is the correct certificate. 

In Example 2, no single job violates the axioms on its own. However, consider collection 1. Axiom II requires that the cardinality of the union of the four $S_{1,k}$ sets (each of cardinality 50) equals the sum of their individual cardinalities, which is $4 \times 50 = 200$. Since Axiom I restricts all sets to the interval $[1, 150]$, the maximum possible cardinality for any union of these sets is 150. Thus, Axiom I and Axiom II cannot be simultaneously satisfied for collection 1, making `LOAD 1` the correct certificate.
