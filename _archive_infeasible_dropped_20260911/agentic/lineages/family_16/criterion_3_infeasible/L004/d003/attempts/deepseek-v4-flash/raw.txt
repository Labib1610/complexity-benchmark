We can read all orders and first check if any single job has `p1 + p2 > T`.  
If yes, print `JOB <index>`.  
If not, check the sum of `p1` across all jobs and the sum of `p2` across all jobs.  
If sums exceed `T`, print `LOAD <workstation>`.  

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    j = int(data[0])
    T = int(data[1])
    
    sum1 = 0
    sum2 = 0
    idx = 2
    
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        
        sum1 += p1
        sum2 += p2
    
    if sum1 > T:
        print("LOAD 1")
        return
    if sum2 > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
