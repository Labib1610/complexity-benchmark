<STATEMENT>
# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing facility processes **j** orders using two specialized stages. Each order must first be processed at stage 1 and subsequently at stage 2. Each stage can handle only one order at a time, and an order cannot begin at stage 2 until its processing at stage 1 is complete. For each order, you are given its required processing duration at stage 1 and stage 2.

All orders must be fully completed by a strict deadline **T**. 

For all test cases provided in this problem, it is guaranteed that meeting the deadline **T** is impossible regardless of the processing sequence. Your job is not to search for a schedule; it is to output a short certificate that proves the impossibility directly from the input. 

Exactly one of the following reasons always applies. Print the certificate for the one that holds:
- A single order's sequential completion across the first and second stages inherently requires strictly more time than the deadline allows. Print: `JOB i`, where **i** is the 1-based order index.
- A single stage's cumulative busy interval to process all its assigned orders strictly exceeds the deadline. Print: `LOAD c`, where **c** is the stage number (1 or 2).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the processing times of an order on stage 1 and stage 2.

## Output

Print a single line containing the certificate of impossibility: either `JOB i` (where i is the order index) or `LOAD c` (where c is the stage number).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, even if the facility only had to process the first order, it would still fail to meet the 100-unit deadline because of the time it must spend sequentially across the two stages (70 then 60, total 130). Thus, `JOB 1` proves the deadline is impossible. In Example 2, no single order violates the deadline on its own, but the first stage is required to operate for a combined 200 time units overall. Since it processes tasks one at a time, it cannot finish within the 150-unit deadline, making `LOAD 1` the valid certificate.
</STATEMENT>
