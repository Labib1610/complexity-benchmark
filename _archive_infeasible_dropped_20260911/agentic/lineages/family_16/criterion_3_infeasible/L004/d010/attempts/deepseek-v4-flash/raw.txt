 We need to check two possible contradictions:

1. **Job-specific**: For a single job, can we place its two sets on a path of length T?  
   For a job with sizes `p1` and `p2`, the union must be connected and all vertices of set 1 must be before set 2.  
   This means the smallest possible span is `p1 + p2` (if they are adjacent blocks).  
   If `p1 + p2 > T`, then it's impossible for that job alone → `JOB i`.

2. **Load-specific**: For a given load type (1 or 2), can we place all jobs' sets of that type disjointly on a path of length T?  
   For load type 1: sum of all `p1` must be ≤ T.  
   For load type 2: sum of all `p2` must be ≤ T.  
   If sum > T, then impossible → `LOAD c`.

We check job-specific first (since it's more specific), then load-specific.

```python
j, T = map(int, input().split())
p1s = []
p2s = []
for i in range(j):
    p1, p2 = map(int, input().split())
    p1s.append(p1)
    p2s.append(p2)
    if p1 + p2 > T:
        print(f"JOB {i+1}")
        exit()

if sum(p1s) > T:
    print("LOAD 1")
    exit()

if sum(p2s) > T:
    print("LOAD 2")
    exit()
```
