# Problem C — Path Graph Induction: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given **j** jobs. For each job $k$ (where $k$ is a 1-based index from 1 to **j**), you must select two subsets of vertices: Load 1 (denoted $V_{k,1}$) and Load 2 (denoted $V_{k,2}$).

The number of vertices in $V_{k,1}$ must exactly equal **p1**.
The number of vertices in $V_{k,2}$ must exactly equal **p2**.

A valid selection must satisfy three constraints:

- **Constraint 1 (Host Graph):** All selected subsets must be drawn from the vertex set of a single host path graph $P$, which consists of exactly **T** vertices labeled $1, 2, \dots, T$, with an undirected edge between $v$ and $v+1$ for all $1 \le v < T$.
- **Constraint 2 (Vertex Disjointness):** For a given load type (Load 1 or Load 2), the subsets must be mutually vertex-disjoint across all $j$ jobs. That is, for any $k \neq m$, $V_{k,1} \cap V_{m,1} = \emptyset$ and $V_{k,2} \cap V_{m,2} = \emptyset$.
- **Constraint 3 (Induced Connectivity and Orientation):** For any single job $k$, the subgraph of $P$ induced by the union $V_{k,1} \cup V_{k,2}$ must be a connected subgraph. Furthermore, for every vertex $x \in V_{k,1}$ and every vertex $y \in V_{k,2}$, the label of $x$ must be strictly less than the label of $y$.

For all test cases provided in this problem, it is guaranteed that no valid selection can satisfy all three constraints simultaneously. Your task is to certify this impossibility by identifying a localized contradiction. Exactly one of the following two types of certificates will be valid for the given input. Print the one that applies:

- **Job-specific contradiction:** There is a single job **i** (1-based index) such that Constraint 1 and Constraint 3 cannot be simultaneously satisfied for job **i**, even if we completely ignore Constraint 2 and all other jobs. Print: `JOB i`.
- **Load-specific contradiction:** There is a single load type **c** (where **c** is 1 for Load 1 or 2 for Load 2) such that Constraint 1 and Constraint 2 cannot be simultaneously satisfied for Load **c**, even if we completely ignore Constraint 3 and the other load type. Print: `LOAD c`.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required number of vertices for Load 1 and Load 2 respectively, for that job.

## Output

Print a single line containing the certificate of impossibility: either `JOB i` (where i is the job index) or `LOAD c` (where c is the load type, 1 or 2).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, consider job 1. The required sizes dictate that $V_{1,1}$ has 70 vertices and $V_{1,2}$ has 60 vertices. By Constraint 3, the induced subgraph on their union must be connected, meaning the union forms a contiguous sequence of vertices in the path graph. The orientation rule requires all vertices in $V_{1,1}$ to have strictly smaller labels than those in $V_{1,2}$, which forces the sets to be disjoint. Thus, the union must contain exactly 130 distinct vertices. However, Constraint 1 restricts the host graph to exactly **100** vertices, making it impossible to find a valid connected subgraph of size 130. Thus, Constraint 1 and Constraint 3 cannot be simultaneously satisfied for job 1. `JOB 1` is the correct certificate.

In Example 2, no single job violates the constraints on its own. However, consider Load 1. Constraint 2 requires the four $V_{k,1}$ subsets (each having 50 vertices) to be entirely vertex-disjoint. This requires 200 distinct vertices to be available in the host graph. Since Constraint 1 restricts the host graph to **150** vertices, it is impossible to select these disjoint subsets. Thus, Constraint 1 and Constraint 2 cannot be simultaneously satisfied for Load 1, making `LOAD 1` the correct certificate.
