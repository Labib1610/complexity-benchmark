# Problem C — Impossible Allocation: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing **j** jobs. For each job $k$ (where $k$ is a 1-based index from 1 to **j**), you must assign two sets of integers: Load 1 and Load 2. 

The number of elements in Load 1 for job $k$ must exactly equal **p1**.
The number of elements in Load 2 for job $k$ must exactly equal **p2**.

A valid assignment must satisfy three rules:

- **Rule 1 (Domain Boundary):** All elements in any Load 1 or Load 2 set must be integers from 1 to **T** inclusive.
- **Rule 2 (Load Exclusivity):** For a given load type (Load 1 or Load 2), an integer can belong to that load type for at most one job. Specifically, no integer $x$ can be in Load 1 of job $a$ and Load 1 of job $b$ (where $a \neq b$). The same restriction applies to Load 2.
- **Rule 3 (Span Integrity):** For any single job $k$, every integer in its Load 1 must be strictly less than every integer in its Load 2. Furthermore, if $m$ is the smallest integer in its Load 1 and $M$ is the largest integer in its Load 2, the number of elements in the union of its Load 1 and Load 2 must exactly equal $M - m + 1$.

For all test cases provided in this problem, it is guaranteed that no valid assignment can satisfy all three rules simultaneously. Your task is to certify this impossibility by identifying a localized contradiction. Exactly one of the following two types of certificates will be valid for the given input. Print the one that applies:

- **Job-specific contradiction:** There is a single job **i** (1-based index) such that Rule 1 (for job **i**) and Rule 3 (for job **i**) cannot be simultaneously satisfied, even if we completely ignore Rule 2 and all other jobs. Print: `JOB i`.
- **Load-specific contradiction:** There is a single load type **c** (where **c** is 1 or 2) such that Rule 1 (for load **c**) and Rule 2 (for load **c**) cannot be simultaneously satisfied, even if we completely ignore Rule 3 and the other load type. Print: `LOAD c`.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required number of elements for Load 1 and Load 2 respectively, for that job.

## Output

Print a single line containing the certificate of impossibility: either `JOB i` (where i is the job index) or `LOAD c` (where c is the load type, 1 or 2).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, consider job 1. The required sizes dictate that Load 1 has 70 elements and Load 2 has 60 elements. By Rule 3, all elements in Load 1 must be strictly less than those in Load 2, making the two sets disjoint. Their union therefore contains 130 elements. Rule 3 also requires that if $m$ is the minimum element of Load 1 and $M$ is the maximum element of Load 2, the union's size must equal $M - m + 1$. This forces $M - m + 1 = 130$, meaning the elements must span a range of 130 integers. However, Rule 1 restricts all elements to the range from 1 to **100**, meaning the maximum possible span is 100. Thus, Rule 1 and Rule 3 cannot be simultaneously satisfied for job 1. `JOB 1` is the correct certificate. 

In Example 2, no single job violates the rules on its own. However, consider Load 1. Rule 2 requires the four Load 1 sets (each having 50 elements) to be completely disjoint across all jobs. This requires 200 distinct integers to be available. Since Rule 1 restricts the available integers to the range from 1 to **150**, it is impossible to assign all of them without reusing an integer. Thus, Rule 1 and Rule 2 cannot be simultaneously satisfied for Load 1, making `LOAD 1` the correct certificate.

<RATIONALE>
Changed the domain from physical pixel arrays on a canvas to abstract sets of integers. The concept of a "contiguous streak" was replaced by an algebraic span constraint: the size of the union must equal $M - m + 1$. This defeats models that rely on surface pattern matching by forcing them to algebraically deduce that $p_1 + p_2 = M - m + 1 \le T$, rather than simply mapping "streak" to addition.
</RATIONALE>
