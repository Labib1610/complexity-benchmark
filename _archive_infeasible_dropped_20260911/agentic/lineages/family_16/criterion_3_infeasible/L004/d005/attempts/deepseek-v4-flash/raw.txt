We can check both possible contradictions:

1. **JOB i**: If for any order `p1 + p2 > T`, then that order alone cannot fit within the deadline, so we print `JOB i`.
2. **LOAD c**: If the sum of all `p1` exceeds `T`, then workstation 1 cannot fit all jobs; similarly for `p2` and workstation 2.

Since the problem guarantees at least one contradiction exists, we can check in that order.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    
    total1 = 0
    total2 = 0
    
    idx = 2
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        
        total1 += p1
        total2 += p2
    
    if total1 > T:
        print("LOAD 1")
        return
    
    if total2 > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
