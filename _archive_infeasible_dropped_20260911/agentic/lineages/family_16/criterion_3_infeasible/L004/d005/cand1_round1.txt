<STATEMENT>
# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A scheduling system must assign start times $S_{1,k}$ and $S_{2,k}$ for a set of $j$ orders. Each order $k$ (1-indexed) requires a processing duration of $p_{1,k}$ on resource 1 and $p_{2,k}$ on resource 2. A valid schedule must satisfy the following five families of constraints:

- **(F1) Base non-negativity:** $S_{1,k} \ge 0$ and $S_{2,k} \ge 0$ for all $k$.
- **(F2) Intra-order precedence:** $S_{2,k} - S_{1,k} \ge p_{1,k}$ for all $k$.
- **(F3) Resource 1 exclusion:** For any two distinct orders $x$ and $y$, either $S_{1,x} - S_{1,y} \ge p_{1,y}$ or $S_{1,y} - S_{1,x} \ge p_{1,x}$.
- **(F4) Resource 2 exclusion:** For any two distinct orders $x$ and $y$, either $S_{2,x} - S_{2,y} \ge p_{2,y}$ or $S_{2,y} - S_{2,x} \ge p_{2,x}$.
- **(F5) Global deadline:** $S_{1,k} + p_{1,k} \le T$ and $S_{2,k} + p_{2,k} \le T$ for all $k$.

For all test cases provided in this problem, it is guaranteed that the full system of constraints (F1) through (F5) has no valid real solution. Your job is not to search for a schedule, but to prove this impossibility by identifying a minimal contradictory subsystem. 

Exactly one of the following two types of contradictory subsystems will be present in the given input. Evaluate the conditions algebraically and print the one that holds:

- **Type A Contradiction:** There exists a single order $i$ (1-based index) such that its specific instances of (F1), (F2), and (F5) form a contradictory system of constraints on their own (independent of all other variables and constraints). Print: `JOB i`.
- **Type B Contradiction:** There exists a resource $c \in \{1, 2\}$ such that the instances of (F1), (F5), and the exclusion constraint for resource $c$ (either F3 or F4), taken across all orders $1 \dots j$, form a contradictory system of constraints on their own (independent of (F2) and the constraints of the other resource). Print: `LOAD c`.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the processing times of an order on resource 1 and resource 2.

## Output

Print a single line containing the certificate of impossibility: either `JOB i` (where i is the order index) or `LOAD c` (where c is the resource number).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, if we isolate the constraints for order 1 under a Type A Contradiction, we have $S_{1,1} \ge 0$, $S_{2,1} \ge 0$ (from F1), $S_{2,1} - S_{1,1} \ge 70$ (from F2), and $S_{1,1} + 70 \le 100$, $S_{2,1} + 60 \le 100$ (from F5). This small system of constraints has no real solution for $S_{1,1}$ and $S_{2,1}$. Thus, `JOB 1` is the valid certificate.

In Example 2, no single order creates a Type A contradiction. However, a Type B contradiction exists for resource 1. The constraints (F1), (F5), and (F3) for $c=1$ form a system across variables $S_{1,1}, S_{1,2}, S_{1,3}, S_{1,4}$ that has no valid real solution, because the exclusion requirements cannot be mutually satisfied within the boundaries of (F1) and (F5). Thus, `LOAD 1` is the valid certificate.
</STATEMENT>
<RATIONALE>
Removed the semantic descriptions of the bottlenecks ("isolation witness", "relaxation witness") which models were pattern-matching to $p1+p2 > T$ and $\sum p > T$. Replaced them with a formal system of algebraic constraints (F1-F5) and redefined the witnesses as minimal contradictory subsystems. Models must now algebraically deduce the $O(N)$ reductions themselves rather than relying on wording cues.
</RATIONALE>
<PRESERVED_ANSWER>
The Type A subsystem is algebraically contradictory if and only if $p_{1,i} + p_{2,i} > T$, and the Type B subsystem is contradictory if and only if the sum of processing times on resource $c$ exceeds $T$, which exactly matches the original bottleneck definitions.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires an $O(N)$ linear scan to check the $p1+p2$ sums and the aggregate resource sums, keeping it in the exact same complexity class.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the disjunctive constraints in F3/F4, but standard mathematical definitions of "contradictory system of constraints" unambiguously mean no valid assignment exists.
</RISK>
