<STATEMENT>
# Problem C — Impossible System: Identify the Contradiction

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of inequalities involving $2j$ real variables: $\alpha_1, \alpha_2, \dots, \alpha_j$ and $\beta_1, \beta_2, \dots, \beta_j$.
For each index $k \in \{1, \dots, j\}$, you are given two strictly positive constants $U_k$ and $V_k$. You are also given a global constant $M$.

Consider the following set of constraints:
For every $k \in \{1, \dots, j\}$:
1. $\alpha_k \ge 0$
2. $\beta_k \ge 0$
3. $\alpha_k + U_k \le \beta_k$
4. $\alpha_k + U_k \le M$
5. $\beta_k + V_k \le M$

For every pair of distinct indices $x, y \in \{1, \dots, j\}$:
6. $\alpha_x \ge \alpha_y + U_y$  or  $\alpha_y \ge \alpha_x + U_x$
7. $\beta_x \ge \beta_y + V_y$  or  $\beta_y \ge \beta_x + V_x$

It is guaranteed that the full system of constraints has no solution over the real numbers. Your task is to pinpoint the minimal contradictory subsystem. Exactly one of the following three statements will be true for the given input. You must print the corresponding legacy output string:

- **Local Contradiction:** There is a single index $i$ (1-based) such that the subsystem comprising only constraints (1), (3), and (5) evaluated for this specific $i$ has no solution.
  Print: `JOB i`

- **Global Contradiction on $\alpha$:** The subsystem comprising only constraints (1) and (4) for all $k$, alongside constraint (6) for all distinct pairs $x, y$, has no solution.
  Print: `LOAD 1`

- **Global Contradiction on $\beta$:** The subsystem comprising only constraints (2) and (5) for all $k$, alongside constraint (7) for all distinct pairs $x, y$, has no solution.
  Print: `LOAD 2`

## Input

The first line contains two integers **j** and **M** (1 ≤ j ≤ 200000, 1 ≤ M ≤ 1000000000).
Each of the next **j** lines contains two integers **U_k** and **V_k** (1 ≤ U_k, V_k ≤ 1000000).

## Output

Print a single line containing the identified contradiction: either `JOB i` (where i is the 1-based index), `LOAD 1`, or `LOAD 2`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for $i=1$, we have $U_1 = 70$ and $V_1 = 60$. The local constraints are:
(1) $\alpha_1 \ge 0$
(3) $\alpha_1 + 70 \le \beta_1$
(5) $\beta_1 + 60 \le 100$
Combining these yields $0 + 70 + 60 \le \alpha_1 + 70 + 60 \le \beta_1 + 60 \le 100$, which simplifies to $130 \le 100$, a contradiction. Thus, `JOB 1` is the correct output.

In Example 2, no single index $i$ creates a local contradiction (e.g., $50 + 1 \le 150$ is satisfiable). However, looking at the global constraints on $\alpha$:
(1) $\alpha_k \ge 0$ for all $k$
(4) $\alpha_k + 50 \le 150 \implies \alpha_k \le 100$ for all $k$
(6) For any $x \neq y$, $|\alpha_x - \alpha_y| \ge 50$.
This requires finding four real numbers in the range $[0, 100]$ such that any two differ by at least 50. This is impossible because the maximum difference between the smallest and largest would need to be at least $3 \times 50 = 150$, but the available range is only 100. Thus, `LOAD 1` is the correct output.

They must now genuinely deduce that the inconsistency of the specified continuous subsystems algebraically reduces to those exact same sums.
