The certificates of impossibility are redefined as identifying which specific minimal relaxed subsystem is inherently contradictory, forcing models to algebraically derive the lower bounds (e.g. p1+p2 > T from X>=0, Y>=X+p1, Y+p2<=T) rather than matching scheduling heuristics.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of constraints over $2j$ real-valued variables, denoted $X_i$ and $Y_i$ for $1 \le i \le j$.
For each index $i$, you are given two positive values $p1_i$ and $p2_i$. Additionally, you are given a global bound $T$.

A valid assignment of the variables must satisfy all of the following conditions:
**(C1)** $X_i \ge 0$ for all $i$.
**(C2)** $Y_i \ge X_i + p1_i$ for all $i$.
**(C3)** $Y_i + p2_i \le T$ for all $i$.
**(C4)** For any pair of distinct indices $i$ and $k$, the intervals $[X_i, X_i + p1_i)$ and $[X_k, X_k + p1_k)$ do not intersect.
**(C5)** For any pair of distinct indices $i$ and $k$, the intervals $[Y_i, Y_i + p2_i)$ and $[Y_k, Y_k + p2_k)$ do not intersect.

For every test case, it is guaranteed that the full system of constraints admits no valid assignment. Your task is to output a short certificate that isolates a trivially contradictory subsystem. 

The problem guarantees that exactly one of the following relaxed subsystems will be contradictory on its own for the provided inputs. You must identify which one applies and print its corresponding label:

- **Type 1 Contradiction:** For a specific index $i$, the subsystem consisting only of constraints (C1), (C2), and (C3) for that single index admits no valid assignment. 
  *Output:* `JOB i` (where `i` is the 1-based index).
- **Type 2 Contradiction:** The subsystem consisting only of constraint (C4), along with the bounding conditions $X_i \ge 0$ and $X_i + p1_i \le T$ for all $1 \le i \le j$, admits no valid assignment.
  *Output:* `LOAD 1`
- **Type 3 Contradiction:** The subsystem consisting only of constraint (C5), along with the bounding conditions $Y_i \ge 0$ and $Y_i + p2_i \le T$ for all $1 \le i \le j$, admits no valid assignment.
  *Output:* `LOAD 2`

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), corresponding to $p1_i$ and $p2_i$ for $i = 1, 2, \dots, j$.

## Output

Print a single line containing the certificate of contradiction: either `JOB i` (where i is the index), `LOAD 1`, or `LOAD 2`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for index 1 we have $p1_1 = 70$ and $p2_1 = 60$. The constraints (C1) $X_1 \ge 0$, (C2) $Y_1 \ge X_1 + 70$, and (C3) $Y_1 + 60 \le 100$ algebraically imply $100 \ge Y_1 + 60 \ge X_1 + 130 \ge 130$, which is false. Thus, `JOB 1` is the correct certificate.

In Example 2, no single index produces a Type 1 contradiction. However, (C4) requires four mutually disjoint intervals of length 50. To satisfy $X_i \ge 0$ and $X_i + 50 \le 150$ for all $i$, these four intervals would have to be packed entirely within the span $[0, 150]$. This requires a total length of 200 within a span of 150, which is impossible, forming a Type 2 contradiction. Thus, `LOAD 1` is the correct certificate.
</STATEMENT>

The problem has been completely stripped of its flow-shop scheduling terminology and reframed as identifying the minimal contradictory subsystem in a set of inequalities and non-overlapping interval constraints. To solve the problem, models can no longer map the text to known scheduling heuristics; they must perform the algebraic deduction (e.g., deriving $p1_i + p2_i > T$ from the Type 1 subsystem) to discover the $O(N)$ checks.
</RATIONALE>
