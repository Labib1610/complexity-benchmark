<STATEMENT>
# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing facility processes $j$ orders using two specialized workstations. Each order must first be processed at workstation 1 and subsequently at workstation 2. Each workstation can handle only one order at a time, and an order cannot begin at workstation 2 until its processing at workstation 1 is complete. For each order, you are given its required processing time at workstation 1 ($p1$) and workstation 2 ($p2$).

All orders must be completely finished by time $T$. 

Formally, an assignment of start times $S_{i,1}$ and $S_{i,2}$ for each order $i$ ($1 \le i \le j$) is valid if it satisfies:
C1. $S_{i,1} \ge 0$
C2. $S_{i,2} \ge S_{i,1} + p1_i$
C3. $S_{i,2} + p2_i \le T$
C4. For any two distinct orders $i$ and $k$, the intervals $[S_{i,1}, S_{i,1} + p1_i)$ and $[S_{k,1}, S_{k,1} + p1_k)$ do not overlap.
C5. For any two distinct orders $i$ and $k$, the intervals $[S_{i,2}, S_{i,2} + p2_i)$ and $[S_{k,2}, S_{k,2} + p2_k)$ do not overlap.

For all test cases provided in this problem, it is guaranteed that no valid assignment of start times exists. Your job is not to search for a schedule; it is to prove infeasibility using one directly checkable contradiction. Exactly one of the following cases always applies. Print the one that holds:

- Case 1: The constraints C1, C2, and C3 for a specific individual order $i$ admit no valid assignment. Print: `JOB i` (1-based index).
- Case 2: The constraints $S_{i,1} \ge 0$, $S_{i,1} + p1_i \le T$, and C4 across all orders admit no valid assignment. Print: `LOAD 1`.
- Case 3: The constraints $S_{i,2} \ge 0$, $S_{i,2} + p2_i \le T$, and C5 across all orders admit no valid assignment. Print: `LOAD 2`.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p1$ and $p2$ ($1 \le p1, p2 \le 1000000$): the processing times of an order on workstation 1 and workstation 2.

## Output

Print a single line containing the certificate of impossibility: either `JOB i` (where $i$ is the order index) or `LOAD c` (where $c$ is the workstation number).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, consider order 1. By C1 and C2, $S_{1,2} \ge 70$. By C3, $S_{1,2} + 60 \le 100$, so $S_{1,2} \le 40$. This is a contradiction, meaning C1, C2, and C3 cannot be simultaneously satisfied for this order. Thus, `JOB 1` is the valid certificate.

In Example 2, no single order violates the constraints on its own. However, workstation 1 must process four orders of length 50 without overlap (C4) between time 0 and time 150 (since $S_{i,1} \ge 0$ and $S_{i,1} + 50 \le 150$). The combined required time is 200. It is impossible to fit these non-overlapping intervals within the limit. Thus, `LOAD 1` is the valid certificate.
</STATEMENT>

Replaced explicit arithmetic conditions (p1+p2>T and sum>T) with equivalent formal constraints on interval assignments. This forces the model to deduce the aggregate bounds from the constraint definitions rather than pattern-matching the inequalities.
</RATIONALE>
<PRESERVED_ANSWER>
The definitions of Case 1, 2, and 3 mathematically perfectly map to p1+p2>T, sum(p1)>T, and sum(p2)>T, so the output matches identically.
</PRESERVED_ANSWER>

The problem remains an O(N) check of three independent infeasibility certificates.
