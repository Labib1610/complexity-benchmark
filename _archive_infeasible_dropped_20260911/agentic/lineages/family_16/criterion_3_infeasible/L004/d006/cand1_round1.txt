<STATEMENT>
# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given **j** pairs of positive integers $(p_{1,k}, p_{2,k})$ for $k \in \{1, \dots, \mathbf{j}\}$ and a target limit $\mathbf{T}$. 

Consider the following system of inequalities over $2\mathbf{j}$ real variables $X_1, \dots, X_j$ and $Y_1, \dots, Y_j$:

- **C1 (Coupling):** For all $k \in \{1, \dots, \mathbf{j}\}$, $Y_k - X_k \ge p_{1,k}$.
- **C2 (Domain bounds):** For all $k \in \{1, \dots, \mathbf{j}\}$, the variables must satisfy $X_k \ge 0$, $X_k + p_{1,k} \le \mathbf{T}$, $Y_k \ge 0$, and $Y_k + p_{2,k} \le \mathbf{T}$.
- **C3 (X-Separation):** For all pairs of distinct indices $a, b \in \{1, \dots, \mathbf{j}\}$, $|2X_a - 2X_b + p_{1,a} - p_{1,b}| \ge p_{1,a} + p_{1,b}$.
- **C4 (Y-Separation):** For all pairs of distinct indices $a, b \in \{1, \dots, \mathbf{j}\}$, $|2Y_a - 2Y_b + p_{2,a} - p_{2,b}| \ge p_{2,a} + p_{2,b}$.

For all test cases provided in this problem, it is guaranteed that no real numbers $X_1, \dots, X_j, Y_1, \dots, Y_j$ can satisfy all four conditions simultaneously. Your task is to certify this impossibility by identifying a localized contradiction. Exactly one of the following isolated subsystems is already impossible on its own. Print the certificate for the one that applies:

- **Local Coupling Contradiction:** There is a single index **i** (1-based index) such that C1 and C2 cannot be satisfied for this specific **i**, even if we completely ignore C3, C4, and all other variables. Print: `JOB i`.
- **X-Separation Contradiction:** The domain bounds on $X$ from C2 (namely $X_k \ge 0$ and $X_k + p_{1,k} \le \mathbf{T}$) and the C3 inequalities cannot be satisfied for the variables $X_1, \dots, X_j$, even if we completely ignore C1, C4, and all $Y$ variables. Print: `LOAD 1`.
- **Y-Separation Contradiction:** The domain bounds on $Y$ from C2 (namely $Y_k \ge 0$ and $Y_k + p_{2,k} \le \mathbf{T}$) and the C4 inequalities cannot be satisfied for the variables $Y_1, \dots, Y_j$, even if we completely ignore C1, C3, and all $X$ variables. Print: `LOAD 2`.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the values of $p_{1,k}$ and $p_{2,k}$ for $k = 1, \dots, \mathbf{j}$.

## Output

Print a single line containing the certificate of impossibility: either `JOB i` (where i is the 1-based index) or `LOAD c` (where c is 1 or 2).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, consider index 1. Condition C1 requires $Y_1 - X_1 \ge 70$. Condition C2 requires $X_1 \ge 0$, $X_1 + 70 \le 100$, $Y_1 \ge 0$, and $Y_1 + 60 \le 100$. From C2, the maximum possible value for $Y_1$ is $100 - 60 = 40$. However, C1 and C2 also require $Y_1 \ge X_1 + 70 \ge 0 + 70 = 70$. This is a contradiction ($40 \ge 70$ is false). Thus, `JOB 1` is the correct certificate. 

In Example 2, no single index creates a Local Coupling Contradiction. However, consider the X-Separation Contradiction. We need to find $X_1, X_2, X_3, X_4$ satisfying C2 ($X_k \ge 0$ and $X_k + 50 \le 150$) and C3 ($|2X_a - 2X_b| \ge 100$ for all $a \neq b$, since $p_{1,a} = p_{1,b} = 50$). This implies any two values among $X_1, X_2, X_3, X_4$ must be at least 50 apart. The maximum number of such values that can fit in the range $[0, 100]$ (since $X_k \le 150 - 50 = 100$) is 3 (for example: 0, 50, 100). We cannot place 4 values. Thus, `LOAD 1` is the correct certificate.

<RATIONALE>
The physical scheduling scenario (intervals, workstations, deadlines) has been completely replaced with an algebraically isomorphic system of inequalities. The non-overlap constraint was translated into an absolute-value inequality on continuous variables. This removes all domain vocabulary that models previously relied on to trigger their hardcoded `sum > T` and `p1 + p2 > T` shortcuts, forcing them to mathematically deduce the invariants from the inequalities themselves.
</RATIONALE>
<PRESERVED_ANSWER>
The absolute-value inequality in C3 is mathematically identical to the requirement that intervals of length $p_{1,k}$ starting at $X_k$ do not overlap, meaning the existence of a solution remains perfectly equivalent to $\sum p_{1,k} \le T$, preserving all original output conditions.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks to identify which of the three independent mathematical subsystems is unsatisfiable, which reduces to the exact same $O(N)$ additive checks as the original INFEASIBLE certification task.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the absolute value inequality C3 as a generic distance constraint rather than a strict interval non-overlap condition, though the mathematical equivalence is exact and the example explanation explicitly walks through the deduction.
</RISK>
