<STATEMENT>
# Problem C — Impossible Bounds: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given an integer **j** and a global bound **T**. For each index $k$ (where $k$ is a 1-based index from 1 to **j**), you are given two positive integers, $p_{1,k}$ and $p_{2,k}$.

We wish to determine if there exist $2j$ real numbers—specifically, a value $A_k$ and a value $B_k$ for each index $k \in \{1, \dots, \mathbf{j}\}$—that satisfy the following three constraint families:

- **Family 1 (Global Bounds):** For every index $k \in \{1, \dots, \mathbf{j}\}$, $0 \le A_k$, $A_k + p_{1,k} \le \mathbf{T}$, $0 \le B_k$, and $B_k + p_{2,k} \le \mathbf{T}$.
- **Family 2 (Cross-Variable Link):** For every index $k \in \{1, \dots, \mathbf{j}\}$, $A_k + p_{1,k} \le B_k$.
- **Family 3 (Intra-Group Separation):** For each group identifier $c \in \{1, 2\}$ (where $c=1$ corresponds to the $A$ variables and $p_1$ lengths, and $c=2$ corresponds to the $B$ variables and $p_2$ lengths), and for any pair of distinct indices $k$ and $m$ (where $k \neq m$), the open interval $(X_{c,k}, X_{c,k} + p_{c,k})$ and the open interval $(X_{c,m}, X_{c,m} + p_{c,m})$ must be disjoint. Here $X_{1,k}$ denotes $A_k$ and $X_{2,k}$ denotes $B_k$.

For all test cases provided in this problem, it is guaranteed that no such real numbers can satisfy all three constraint families simultaneously. Your task is to certify this impossibility by identifying a localized contradiction. Exactly one of the following two types of certificates will be valid for the given input. Print the one that applies:

- **Index-specific contradiction:** There is a single index **i** (1-based) such that Family 2 (for index **i**) and Family 1 (for index **i**, on both $A$ and $B$) cannot be simultaneously satisfied, even if we completely ignore Family 3 and all other indices. Print: `JOB i`.
- **Group-specific contradiction:** There is a single group identifier **c** (where **c** is 1 or 2) such that Family 3 (for group **c**) and Family 1 (for group **c** across all indices) cannot be simultaneously satisfied, even if we completely ignore Family 2 and the other group. Print: `LOAD c`.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the respective constraint lengths for group 1 and group 2 at that index.

## Output

Print a single line containing the certificate of impossibility: either `JOB i` (where i is the index) or `LOAD c` (where c is the group identifier, 1 or 2).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, consider index 1. Family 1 requires $A_1 \ge 0$ and $B_1 + 60 \le 100$. Family 2 requires $B_1 \ge A_1 + 70$. Combining these gives $100 \ge B_1 + 60 \ge A_1 + 130 \ge 130$, which is a contradiction ($100 \ge 130$). Thus, `JOB 1` is the correct certificate. 

In Example 2, no single index violates the constraints on its own. However, consider group 1. Family 3 requires the four intervals $(A_k, A_k + 50)$ to be disjoint. Family 1 requires all of them to be sub-intervals of $[0, 150]$. Four disjoint intervals of length 50 require a total domain width of at least 200, which contradicts Family 1. Thus, `LOAD 1` is the correct certificate.
</STATEMENT>
<RATIONALE>
The problem was completely stripped of its scheduling terminology (workstations, jobs, intervals, precedence) and reformulated as a pure algebraic system of inequalities over real numbers. This forces models to logically deduce that checking the unsatisfiability of Family 1 and 2 is structurally identical to $p_1+p_2 > T$, and checking Family 1 and 3 is structurally identical to $\sum p_c > T$, rather than blindly relying on memorised scheduling heuristics. It also creates a powerful trap for models that attempt to pass the abstract mathematical description directly into an SMT solver like Z3, which will result in a Time Limit Exceeded failure on inputs of size 200,000.
</RATIONALE>

The mathematical requirements for the real numbers $A_k$ and $B_k$ are perfectly isomorphic to the start times of the intervals in the original scheduling problem, meaning the exact same outputs will be triggered under the exact same conditions.
</PRESERVED_ANSWER>

The complexity class remains identical $O(N)$ because the logic reduces to exactly the same linear scan over the array to check local sums and aggregate totals.
</PRESERVED_CLASS>
