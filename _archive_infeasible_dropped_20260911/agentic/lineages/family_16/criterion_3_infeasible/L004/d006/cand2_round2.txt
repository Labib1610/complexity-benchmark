<STATEMENT>
# Problem C — Infeasible System of Inequalities

Time limit: 2 s   Memory limit: 256 MB

## Description

You are studying a mathematical system of constraints over $4N$ real variables. For each integer $k \in \{1, 2, \dots, N\}$, there are four variables: $x_{1,k}, y_{1,k}, x_{2,k}, y_{2,k}$.
You are given a global constant $M$ and, for each $k$, two strictly positive constants $A_k$ and $B_k$.

The variables are subject to four families of conditions:

- **Family 1 (Spans):** For all $k \in \{1 \dots N\}$, $y_{1,k} - x_{1,k} = A_k$ and $y_{2,k} - x_{2,k} = B_k$.
- **Family 2 (Global Bounds):** For all $k \in \{1 \dots N\}$ and for $c \in \{1, 2\}$, $x_{c,k} \ge 0$ and $y_{c,k} \le M$.
- **Family 3 (Intra-index Ordering):** For all $k \in \{1 \dots N\}$, $x_{2,k} \ge y_{1,k}$.
- **Family 4 (Inter-index Disjointness):** For any pair of distinct indices $k \neq m$ and for a fixed $c \in \{1, 2\}$, the open intervals $(x_{c,k}, y_{c,k})$ and $(x_{c,m}, y_{c,m})$ have an empty intersection.

For all test cases provided in this problem, it is guaranteed that the full system of constraints (satisfying all four families simultaneously) has no real solution. Your task is to output a localized certificate of this infeasibility. 

Exactly one of the following two types of localized contradictions will be present for any given input. You are not asked to construct a solution; output the directly checkable impossibility certificate that applies:

- **Index-specific contradiction:** There exists a single index $i$ ($1 \le i \le N$) such that the conditions from Families 1, 2, and 3, when restricted *only* to $k = i$, form a system with no real solution.
  If this applies, print: `JOB i`
  (If multiple indices $i$ satisfy this requirement, printing any one of them is valid.)

- **Dimension-specific contradiction:** There exists a single dimension $c$ ($c \in \{1, 2\}$) such that the conditions from Families 1, 2, and 4, when restricted *only* to this specific dimension $c$ across all $k \in \{1 \dots N\}$, form a system with no real solution.
  If this applies, print: `LOAD c`

## Input

The first line contains two integers $N$ and $M$ ($1 \le N \le 200000$, $1 \le M \le 1000000000$).
Each of the next $N$ lines contains two integers $A_k$ and $B_k$ ($1 \le A_k, B_k \le 1000000$).

## Output

Print a single line containing the certificate of impossibility: either `JOB i` (where i is the 1-based index) or `LOAD c` (where c is 1 or 2).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, consider index 1. The conditions from Families 1, 2, and 3 for $k=1$ cannot be simultaneously satisfied because chaining the required spans and ordering forces a minimum difference between $y_{2,1}$ and $x_{1,1}$ that exceeds the global bound $M=100$. Thus, `JOB 1` is a valid certificate.

In Example 2, no single index is contradictory under Families 1, 2, and 3. However, consider dimension 1. The conditions from Families 1, 2, and 4 for $c=1$ cannot be simultaneously satisfied because placing four disjoint open intervals of length 50 requires a continuous span strictly greater than the global bound $M=150$. Thus, `LOAD 1` is a valid certificate.
</STATEMENT>
<RATIONALE>
The problem was completely reframed from a physical scheduling scenario into an abstract algebraic system of inequalities over $4N$ real variables. The checkable conditions (`p1+p2 > T` and `sum > T`) are now implicitly defined as the mathematical infeasibility of specific subsets of these constraint families, forcing the model to algebraically deduce the minimal bounds rather than rely on scheduling heuristics.
</RATIONALE>
<PRESERVED_ANSWER>
The condition for an index-specific contradiction mathematically simplifies exactly to $A_i + B_i > M$, and the dimension-specific contradiction exactly to $\sum P_{c,k} > M$, keeping all valid outputs identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains solvable in $O(N)$ time by iterating over the inputs to check the two derived algebraic bounds, keeping the complexity class unchanged.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the term "open intervals ... have an empty intersection" in Family 4, though this is standard mathematical terminology that perfectly maps to the seed's "mutually disjoint (they cannot overlap in time, though they may share endpoints)".
</RISK>
