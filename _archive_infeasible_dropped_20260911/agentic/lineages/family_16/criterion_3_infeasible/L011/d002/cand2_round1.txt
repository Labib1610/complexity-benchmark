<STATEMENT>
# Problem C — Unattainable Target: Provide Evidence

Time limit: 2 s   Memory limit: 256 MB

## Description

A ground station needs to route $j$ data transmissions through a relay satellite. Every transmission is sent on the uplink frequency first, and then broadcast on the downlink frequency. For each transmission, you are given its duration on the uplink and its duration on the downlink. Each frequency can carry only one transmission at a time, and a transmission can only start its downlink after its uplink has entirely finished.

There is a hard time limit $T$: every transmission must be completely finished by millisecond $T$.

You do not need to find an order; for every input in this problem, no sequence of transmissions can possibly finish by the limit $T$. Your task is to output a certificate that proves the limit is unattainable. Every input is guaranteed to allow exactly one of the following types of impossibility proofs. Print the one that holds:

- A single transmission's inherent requirements cannot fit within the time limit. Print: `JOB i` — where $i$ (1-based) is a transmission that requires a completion time strictly greater than $T$ even if it were the only transmission being processed.

- A frequency is assigned a workload that cannot be processed sequentially within the time limit. Print: `LOAD c` — where $c$ is 1 (for the uplink) or 2 (for the downlink) and the frequency $c$ cannot possibly finish all its assigned operations by $T$, regardless of scheduling order.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the durations of a transmission on the uplink and the downlink.

## Output

Print a single line: `JOB i` (a transmission that cannot finish by $T$ on its own) or `LOAD c` (a frequency that cannot finish its operations by $T$).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, if transmission 1 were the only data routed, its required sequence of operations would take 130 milliseconds, which exceeds the limit of 100. Thus, `JOB 1` proves the limit is impossible. In Example 2, no single transmission requires more than 150 milliseconds on its own, but the uplink frequency must process a sequential workload of 200 milliseconds, which exceeds 150. Thus, `LOAD 1` is the certificate.
</STATEMENT>
<RATIONALE>
The original problem explicitly provided the additive formulas (`p1 + p2 > T` and `sum > T`) for the certificates, allowing models to pattern-match the arithmetic without reasoning about the schedule constraints. These formulas were replaced with logical definitions based on scheduling mechanics. Models must now deduce that a single transmission's minimum completion time is the sum of its two sequential stages, and that a single frequency's minimum processing time is the sum of all operations assigned to it.
</RATIONALE>
<PRESERVED_ANSWER>
The conditions for outputting `JOB i` and `LOAD c` remain mathematically identical to the seed, simply described through their scheduling implications rather than explicit arithmetic, so the exact same certificates are required for every input.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still only requires a single linear scan to check the sum of durations for each job and the total duration for each machine, keeping it firmly in the same $O(N)$ certification class.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "even if it were the only transmission being processed" as ignoring the sequential dependency between uplink and downlink, but the earlier text strictly enforces that "a transmission can only start its downlink after its uplink has entirely finished", which resolves any ambiguity.
</RISK>
