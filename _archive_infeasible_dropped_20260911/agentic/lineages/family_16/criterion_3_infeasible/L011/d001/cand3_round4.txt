<STATEMENT>
# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A factory processes a batch of jobs through exactly 2 machines. Every job must be processed on machine 1 first, and then on machine 2. Each machine processes only one job at a time, and a job can only start on machine 2 after it has completely finished on machine 1. 

There is a strict deadline $T$: all jobs must be fully completed by time $T$.

Your task is to prove that the optimal two-machine schedule cannot possibly meet the deadline $T$. To do this, you must output a certificate of infeasibility. The certificate must reflect the structural bottleneck that strictly exceeds the deadline, using one of the following formats:

- `JOB i` — if the sequential processing time of job $i$ (1-based index) alone makes it impossible to finish by $T$.
- `LOAD c` — if the total aggregate processing time required on machine $c$ (where $c$ is 1 or 2) exceeds $T$.

Analyze the optimal schedule's infeasibility and print the specific bottleneck (either a single job or a machine load) that strictly exceeds $T$.

## Input

The first line contains two integers $j$ and $T$. The number of jobs $j$ is at least 1 and bounded by the factory's maximum batch capacity of 200000. The deadline $T$ is at least 1 and bounded by the planning horizon of 1000000000 time units.
Each of the next $j$ lines contains two integers $p_1$ and $p_2$. The processing times $p_1$ and $p_2$ are at least 1 and bounded by the maximum machine operation time of 1000000.

## Output

Print a single line containing the certificate of infeasibility: either `JOB i` (where job $i$'s total sequential time exceeds $T$) or `LOAD c` (where machine $c$'s total load exceeds $T$).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, job 1 requires 70 + 60 = 130 time units sequentially. Since 130 > 100, `JOB 1` proves the deadline is impossible. 
In Example 2, no single job exceeds 150, but machine 1 must process 50 + 50 + 50 + 50 = 200 units of work. Since 200 > 150, `LOAD 1` is the certificate.
