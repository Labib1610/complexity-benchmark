# Problem C — Unattainable Target: Provide Evidence

Time limit: 2 s   Memory limit: 256 MB

## Description

A ground station needs to route $j$ data transmissions through a relay satellite. Every transmission is sent on the uplink frequency first, and then broadcast on the downlink frequency. For each transmission, you are given its duration on the uplink and its duration on the downlink. Each frequency can carry only one transmission at a time, and a transmission can only start its downlink after its uplink has entirely finished.

There is a hard time limit $T$: every transmission must be completely finished by millisecond $T$.

You do not need to find an order; for every input in this problem, no sequence of transmissions can possibly finish by the limit $T$. Your task is to output a certificate that proves the limit is unattainable. Every input is guaranteed to satisfy exactly one of the following properties. Print the one that holds:

- A single transmission is too long. If some transmission's two durations add up to more than $T$, that transmission alone (uplink then downlink, in sequence) cannot finish by $T$. Print: `JOB i` — where $i$ (1-based) is such a transmission.

- A frequency is overloaded. A frequency carries its transmissions one at a time, so it needs at least the sum of all its durations. If the total time needed on the uplink (or the downlink) exceeds $T$, the limit is impossible. Print: `LOAD c` — where $c$ is 1 (for the uplink) or 2 (for the downlink) and the total duration on frequency $c$ exceeds $T$.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the durations of a transmission on the uplink and the downlink.

## Output

Print a single line: `JOB i` (a transmission whose $p_1 + p_2$ exceeds $T$) or `LOAD c` (a frequency $c$ whose total load exceeds $T$).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, transmission 1 needs $70 + 60 = 130 > 100$ milliseconds in sequence, so `JOB 1` proves the limit is impossible. In Example 2 no single transmission exceeds 150, but the uplink frequency must carry $50+50+50+50 = 200 > 150$ milliseconds of data in total, so `LOAD 1` is the certificate.
