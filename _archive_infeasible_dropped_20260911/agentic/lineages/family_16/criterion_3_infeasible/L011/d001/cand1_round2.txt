<STATEMENT>
# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A factory processes $j$ jobs through exactly two machines. Every job is processed on machine 1 first and then on machine 2. For each job you are given its processing time on machine 1 and on machine 2. Each machine processes only one job at a time, and a job reaches machine 2 only after finishing on machine 1.

There is a required deadline $T$: every job must be completely finished by time $T$.

For every input in this problem, no sequence of jobs can possibly meet the deadline. Your task is to furnish a certificate demonstrating why the deadline cannot be met. You will not need to search through orderings; instead, you must identify the structural bottleneck. Exactly one of the following bottlenecks will be present in any given input. Print the corresponding certificate:

- **Individual Job Bottleneck:** A specific job $i$ requires more time to complete its sequential stages than the deadline permits ($p_1 + p_2 > T$). Output `JOB i` (where $i$ is the 1-based index).
- **Machine Capacity Bottleneck:** A specific machine $c$ does not have enough time before the deadline to process all its assigned work, even with no idle time (the sum of all processing times on machine $c$ exceeds $T$). Output `LOAD c` (where $c \in \{1, 2\}$).

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the processing times of a job on machine 1 and machine 2.

## Output

Print a single line containing the valid certificate: `JOB i` (where job $i$ has $p_1 + p_2 > T$) or `LOAD c` (where machine $c$'s total processing time exceeds $T$). Exactly one such certificate will be valid for each input.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, job 1 requires $70 + 60 = 130 > 100$ time units in sequence, so `JOB 1` proves the deadline is impossible. In Example 2 no single job exceeds 150, but machine 1 must process $50+50+50+50 = 200 > 150$ units of work in total, so `LOAD 1` is the certificate.
