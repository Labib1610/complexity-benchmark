<STATEMENT>
# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A factory processes $j$ jobs through exactly two machines. Every job is processed on machine 1 first and then on machine 2. For each job, you are given its processing time on machine 1 and on machine 2. Each machine processes only one job at a time, and a job reaches machine 2 only after completely finishing on machine 1.

There is a required deadline $T$: every job must be completely finished by time $T$.

While analyzing all possible orderings to find a valid schedule is a large task, for every input in this problem, no sequence of jobs can possibly meet the deadline. Your task is to output a certificate demonstrating this impossibility. The test data guarantees that at least one of the following structural bottlenecks will exceed $T$. If multiple valid certificates exist (for instance, several jobs exceed the limit, or both machines are overloaded), you may output any one of them.

- **Job Sequential Bottleneck**: A single job is too long. If some job's two processing times add up to more than $T$, that job alone (machine 1 then machine 2, in sequence) cannot finish by $T$. Print: `JOB i` — where $i$ (1-based) is the index of any such job.

- **Machine Aggregate Bottleneck**: A machine is overloaded. A machine runs its jobs one at a time, so it needs at least the sum of all its processing times. If the total work on machine 1 (or machine 2) exceeds $T$, the deadline is impossible. Print: `LOAD c` — where $c$ is 1 or 2, and the total processing time on machine $c$ exceeds $T$.

## Input

The first line contains two integers $j$ and $T$. The value of $j$ is at least 1 and at most the number of square centimeters in 20 square meters. The value of $T$ is at least 1 and at most the number of cubic millimeters in one cubic meter.

Each of the next $j$ lines contains two integers $p_1$ and $p_2$, representing the processing times of a job on machine 1 and machine 2. Both $p_1$ and $p_2$ are at least 1 and at most the number of square millimeters in one square meter.

## Output

Print a single line containing a valid certificate: either `JOB i` (for any job $i$ whose $p_1 + p_2$ strictly exceeds $T$) or `LOAD c` (for any machine $c$ whose total load strictly exceeds $T$).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, job 1 needs 70 + 60 = 130 > 100 time units in sequence, so `JOB 1` proves the deadline is impossible. In Example 2, no single job exceeds 150, but machine 1 must process 50+50+50+50 = 200 > 150 units of work in total, so `LOAD 1` is the certificate.
</STATEMENT>
<RATIONALE>
The explicit guarantee that "exactly one of the following properties holds" was removed and replaced with "at least one of the following structural bottlenecks will exceed T". This prevents models from using an `else` shortcut to output the final condition without actually checking it. Additionally, numeric bounds were replaced with exact geometric unit conversions (e.g., cubic millimeters in a cubic meter for 10^9) to force derivation of the constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The problem asks for identical certificate types (`JOB i` or `LOAD c`) under the exact same strict inequality conditions, and permits any valid certificate to be printed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires an O(j) linear scan to check sequential job sums and aggregate machine loads against T, preserving its certification-checking nature.
</PRESERVED_CLASS>
<RISK>
Models might struggle with the geometric unit conversions if they lack physical common sense, though the math itself is standard SI prefix knowledge.
</RISK>
