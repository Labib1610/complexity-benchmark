# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A factory processes $j$ jobs through exactly two machines. Every job is processed on machine 1 first and then on machine 2. For each job you are given its processing time on machine 1 and on machine 2. Each machine processes only one job at a time, and a job reaches machine 2 only after finishing on machine 1.

There is a required deadline $T$: every job must be completely finished by time $T$.

For every input in this problem, no sequence of jobs can possibly meet the deadline. Your task is to output a certificate that reflects the infeasibility of the optimal two-machine schedule. You must provide a proof of impossibility using one of the following two formats:

- `JOB i`: Use this if a single job is too long. Specifically, if there is a job $i$ (1-based index) such that its processing time on machine 1 plus its processing time on machine 2 is strictly greater than $T$.
- `LOAD c`: Use this if a machine is overloaded. Specifically, if the sum of the processing times of all jobs on machine $c$ (where $c$ is 1 or 2) is strictly greater than $T$.

It is guaranteed that for every test case, exactly one of these two reason categories applies. Output the applicable certificate.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the processing times of a job on machine 1 and machine 2.

## Output

Print a single line containing the applicable certificate: either `JOB i` for a job with $p_1 + p_2 > T$, or `LOAD c` for a machine with total load $> T$.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, job 1 needs $70 + 60 = 130 > 100$ time units in sequence, so `JOB 1` proves the deadline is impossible. In Example 2 no single job exceeds 150, but machine 1 must process $50+50+50+50 = 200 > 150$ units of work in total, so `LOAD 1` is the certificate.
