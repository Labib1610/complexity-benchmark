<STATEMENT>
# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A factory processes $j$ jobs through exactly two machines. Every job is processed on machine 1 first and then on machine 2. For each job you are given its processing time on machine 1 and on machine 2. Each machine processes only one job at a time, and a job reaches machine 2 only after finishing on machine 1.

There is a required deadline $T$: every job must be completely finished by time $T$.

There are $j!$ possible permutations for scheduling these jobs. While analyzing all possible orderings to find a valid schedule is a large task, for every input in this problem, no sequence of jobs can possibly meet the deadline. Your task is to construct a certificate proving that the optimal two-machine schedule cannot complete by $T$. 

The certificate must isolate the bottleneck and be formatted as one of the following:
- `JOB i` — where $i$ (1-based) is the index of a job whose inherent sequential requirement alone makes the deadline unachievable.
- `LOAD c` — where $c$ is the machine identifier (1 or 2) whose aggregate volume of assigned work alone makes the deadline unachievable.

You are guaranteed that for each given factory scenario, exactly one such bottleneck exists that independently exceeds the deadline.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the processing times of a job on machine 1 and machine 2.

## Output

Print a single line containing the certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, the first job requires 70 time units on the first machine followed by 60 time units on the second. Since it cannot be completed within the 100 time units even if it is the only job in the system, `JOB 1` is the certificate. 

In Example 2, no single job violates the deadline on its own, but the total time required by machine 1 to process all its assigned tasks is 200, which exceeds 150, so `LOAD 1` is the certificate.
</STATEMENT>
<RATIONALE>
Removed the explicit algebraic formulas (`p1 + p2 > T` and `sum > T`) from the certificate descriptions, replacing them with phrasing about the "inherent sequential requirement" and "aggregate volume of assigned work". This forces the model to reason about what makes a two-machine schedule infeasible in these specific ways rather than just copying formulas into an if/else block.
</RATIONALE>
<PRESERVED_ANSWER>
The conditions that trigger `JOB i` and `LOAD c` remain mathematically identical, and the problem still guarantees exactly one applies, ensuring the same output is valid.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The solution still requires checking the sum of processing times for each job and the sum of processing times for each machine, which is an O(N) scan.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "inherent sequential requirement" or "aggregate volume", though the Note clarifies how the values 130 and 200 relate to the example inputs.
</RISK>
