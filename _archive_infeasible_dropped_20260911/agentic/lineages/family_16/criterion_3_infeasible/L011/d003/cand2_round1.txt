<STATEMENT>
# Problem C — Unattainable Target: Provide Evidence

Time limit: 2 s   Memory limit: 256 MB

## Description

A ground station needs to route $j$ data transmissions through a relay satellite. Every transmission is sent on the uplink frequency first, and then broadcast on the downlink frequency. For each transmission, you are given its duration on the uplink and its duration on the downlink. Each frequency can carry only one transmission at a time, and a transmission can only start its downlink after its uplink has entirely finished.

There is a hard time limit $T$: every transmission must be completely finished by millisecond $T$.

You do not need to find an order; for every input in this problem, no sequence of transmissions can possibly finish by the limit $T$. Your task is to output a certificate that proves the limit is unattainable. Every input is guaranteed to satisfy exactly one of the following properties. Print the certificate for the one that holds:

- A fundamental delay in a single transmission: The inherent end-to-end latency of a specific transmission strictly exceeds the operational window. Print: `JOB i` — where $i$ (1-based) is such a transmission.

- A fundamental capacity shortfall on a single frequency: The aggregate active time required by all assigned traffic on a single frequency renders the deadline unachievable, independent of any cross-frequency dependencies. Print: `LOAD c` — where $c$ is 1 (for the uplink) or 2 (for the downlink) and is such a frequency.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the durations of a transmission on the uplink and the downlink.

## Output

Print a single line: `JOB i` (where $i$ is a transmission whose inherent end-to-end latency violates the limit) or `LOAD c` (where $c$ is a frequency whose aggregate active time exceeds the limit).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, transmission 1 requires 70 milliseconds on the uplink and 60 milliseconds on the downlink. Its inherent end-to-end latency is 130 milliseconds, which exceeds the 100 millisecond limit. Thus, `JOB 1` is the certificate.

In Example 2, no single transmission violates the limit. However, the uplink frequency is assigned four transmissions of 50 milliseconds each, totalling 200 milliseconds of aggregate active time. This exceeds the 150 millisecond limit, so `LOAD 1` is the certificate.
</STATEMENT>

The suggested removal of adding a mandatory 1ms transition mathematically changes the condition from `p1 + p2 > T` to `p1 + 1 + p2 > T`, which would cause the reference solution to fail on some inputs, violating the hard constraint of Identical Answers. Instead, the affordance was removed by rewriting the explicit tutorial language ("even if it were granted exclusive access", "idealised relaxation") into standard physical descriptions ("inherent end-to-end latency", "aggregate active time"). This forces the model to deduce the mathematical formulas for the bottlenecks rather than being handed explicit isolation instructions.
</RATIONALE>
