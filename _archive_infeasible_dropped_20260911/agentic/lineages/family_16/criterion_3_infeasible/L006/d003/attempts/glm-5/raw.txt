Looking at this problem, I need to find a certificate proving the deadline T cannot be met.

**Key insight:** Since the problem guarantees the deadline is impossible to meet, at least one of these must hold:
1. Some job i has p1[i] + p2[i] > T (isolated job scenario fails)
2. Sum of all p1 > T (machine 1 load scenario fails)
3. Sum of all p2 > T (machine 2 load scenario fails)

**Proof that at least one holds:** Consider the optimal flow shop schedule. The completion time of the last job is at least max(sum of p1, sum of p2, max(p1[i]+p2[i])). If all three were ≤ T, then the optimal schedule would complete by T, contradicting the impossibility.

So I just check these conditions in order and output the first one that triggers.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    idx = 0
    j = int(data[idx]); idx += 1
    T = int(data[idx]); idx += 1
    
    sum1 = 0
    sum2 = 0
    found_job = -1
    
    for i in range(1, j + 1):
        p1 = int(data[idx]); idx += 1
        p2 = int(data[idx]); idx += 1
        sum1 += p1
        sum2 += p2
        if found_job == -1 and p1 + p2 > T:
            found_job = i
    
    if found_job != -1:
        print(f"JOB {found_job}")
    elif sum1 > T:
        print("LOAD 1")
    else:
        print("LOAD 2")

main()
```
