# SLA Rejection Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

A cloud computing platform processes a sequence of $j$ client requests. Each request provides two parameters: $p_1$ and $p_2$. 

To ensure SLA compliance, the system evaluates three stress-test metrics based on the work done by a conservative vector field $\mathbf{F}(x, y) = \hat{\imath} + \hat{\jmath}$ operating on a 2D resource plane. The input guarantees exactly one of these metrics will strictly exceed the threshold $T$, and you must print its corresponding rejection certificate.

- **Isolated Job Obstruction:** There is a request $i$ ($1 \le i \le j$) such that the work done by the field $\mathbf{F}$ in moving a particle from the origin $(0,0)$ to the coordinate $(p_{1, i}, p_{2, i})$ strictly exceeds $T$. If this category applies, print `JOB i`. (If multiple requests satisfy this, printing any one of them is acceptable).

- **Continuous Utilization Exhaustion:** There is a component $c \in \{1, 2\}$ such that the aggregate work done by the field $\mathbf{F}$ strictly exceeds $T$.
  - For $c = 1$, the particle is moved from the origin to the coordinate $(\sum_{k=1}^j p_{1, k}, 0)$. If the work done strictly exceeds $T$, print `LOAD 1`.
  - For $c = 2$, the particle is moved from the origin to the coordinate $(0, \sum_{k=1}^j p_{2, k})$. If the work done strictly exceeds $T$, print `LOAD 2`.
  (If both satisfy this, either is acceptable).

Output must be consistent with the unique applicable limitation category guaranteed by the input.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the parameters for a request.

## Output

Print a single line containing either `JOB i` or `LOAD c`. The output must be consistent with the unique applicable limitation category guaranteed by the input.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, consider the isolated job check for request 1. 
The particle moves from $(0,0)$ to $(70, 60)$. The work done by the field $\mathbf{F}(x, y) = \hat{\imath} + \hat{\jmath}$ along this path evaluates to $130$. Since $130 > 100$, `JOB 1` is a valid rejection certificate.

In Example 2, consider the continuous exhaustion check for component 1. 
The aggregate coordinate is $(50+50+50+50, 0) = (200, 0)$. The work done in moving a particle from $(0,0)$ to $(200, 0)$ evaluates to $200$. Since $200 > 150$, `LOAD 1` is a valid rejection certificate.
