We need to determine a valid rejection certificate: either `JOB i` or `LOAD c`.  
The problem states that exactly one of the two families appliesainer, but we must detect it efficiently for large input sizes.

The idea:

- **Isolated Job Bottleneck**:  
  For each job `i`, we consider only its own `(p1, p2)` and set all others to zero.  
  In that case:  
  - E_i = p1_i  
  - T_i = max(E_i, 0) + p2_i = p1_i + p2_i  
  All previous and later steps contribute 0, so T_j = p1_i + p2_i.  
  So the condition is: if any `p1_i + p2_i > T`, this family is valid and we output `JOB i`.

- **Machine Saturation**:  
  **LOAD 1**:  
  Set all p2 to 0 individually, but keep p1.  
  Then:  
  E_k = sum of p1 up to k  
  T_k = max(E_k, T_{k-1}) + 0 = max(E_k, T_{k-1})  
  Since T_k equals the maximum E so far, final T_j = sum of all p1.  
  Condition: sum(p1) > T.

  **LOAD 2**:  
  Set all p1 to 0, keep p2.  
  Then:  
  E_k = 0 always.  
  T_k = max(0, T_{k-1}) + p2_k = T_{k-1} + p2_k  
  Final T_j = sum of all p2.  
  Condition: sum(p2) > T.

Given guarantees, we can just check:

- If any `p1_i + p2_i > T`: output `JOB i`  
- Else if sum(p1) > T: output `LOAD 1`  
- Else if sum(p2) > T: output `LOAD 2`

But careful: Since exactly one family applies, only one of these will be true)Skip.  
We'll run checks in order.

Let's implement it.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    j = int(data[0])
    T = int(data[1])
    p1_list = []
    p2_list = []
    idx = 2
    for _ in range(j):
        p1 = int(data[idx])
        p2 = int(data[idx+1])
        idx += 2
        p1_list.append(p1)
        p2_list.append(p2)
    
    # Check isolated job bottleneck
    for i in range(j):
        if p1_list[i] + p2_list[i] > T:
            print(f"JOB {i+1}")
            return
    
    # Check LOAD 1
    if sum(p1_list) > T:
        print("LOAD 1")
        return
    
    # Check LOAD 2
    if sum(p2_list) > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
