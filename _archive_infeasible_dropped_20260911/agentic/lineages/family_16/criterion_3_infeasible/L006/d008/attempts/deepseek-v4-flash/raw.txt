We need to determine which category applies and output the corresponding certificate.

The key is to check both categories efficiently:

1. **Isolated Job Obstruction**: For each request `i`, simulate the sequence where only request `i` has its actual parameters and all others are `(0,0)`.  
   The final metric for that case is simply:  
   - `S = p1[i]`  
   - `D = p2[i]` (since `D` starts at 0, `max(0, 0 - p1[i]) = 0`, then add `p2[i]`)  
   So the metric is `p1[i] + p2[i]`.  
   If this exceeds `T`, we can output `JOB i`.

2. **Continuous Utilization Exhaustion**:  
   - For `c=1`: zero out all `v`, keep `u`.  
     Then `D` stays 0 always (since `max(0, D - u) + 0 = 0`), and `S` is the sum of all `u`.  
     Metric = sum of all `p1`.  
   - For `c=2`: zero out all `u`, keep `v`.  
     Then `S` stays 0, and `D` accumulates as `D = D + v` each step (since `max(0, D - 0) = D`).  
     Metric = sum of all `p2`.  

So we just need to check:
- If any `p1[i] + p2[i] > T` → `JOB i`
- Else if `sum(p1) > T` → `LOAD 1`
- Else if `sum(p2) > T` → `LOAD 2`

The problem guarantees exactly one category applies, so we can check in that order.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    p1 = []
    p2 = []
    idx = 2
    for _ in range(j):
        p1.append(int(data[idx]))
        p2.append(int(data[idx+1]))
        idx += 2

    # Check isolated job obstruction
    for i in range(j):
        if p1[i] + p2[i] > T:
            print(f"JOB {i+1}")
            return

    # Check continuous utilization exhaustion
    if sum(p1) > T:
        print("LOAD 1")
        return
    if sum(p2) > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
