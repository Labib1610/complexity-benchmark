<METHOD_NAME>Algebraic Recurrence Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Rewrites the standard max(A, B) flow-shop recurrence into an algebraically equivalent but structurally obscure difference-based accumulation $S_2 = S_2 + \max(S_1 - S_2, 0) + p_2$. It replaces the "zero out other jobs" wording with explicit binary indicator masks. Models that just pattern-match the standard flow shop will fail to recognize the equivalence and either TLE by simulating $O(N^2)$ mask combinations or fail to find the $O(N)$ reduction, while models that algebraically reduce the recurrence will easily find the $O(N)$ solution.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<STATEMENT>
# SLA Rejection Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

A cloud computing platform processes a sequence of $j$ client requests. Each request requires processing on two subsystems. Let $p_{1,k}$ and $p_{2,k}$ be the processing times of the $k$-th request on subsystem 1 and subsystem 2, respectively. For given binary indicator vectors $M$ and $N$ of length $j$, let $M_k$ and $N_k$ denote their $k$-th elements. We define the state variables $S_{1,k}$ and $S_{2,k}$ for the requests $k = 1, 2, \dots, j$ by the following recurrences:

- $S_{1,0} = 0$ and $S_{2,0} = 0$
- $S_{1,k} = S_{1,k-1} + M_k \cdot p_{1, k}$
- $S_{2,k} = S_{2,k-1} + \max(S_{1,k} - S_{2,k-1}, 0) + N_k \cdot p_{2, k}$

The final completion time of the entire sequence under masks $M$ and $N$ is $S_{2,j}$. The client requires the completion time under full operation (where $M_k = 1$ and $N_k = 1$ for all $k$) to be at most $T$.

For every input provided, it is impossible to meet this deadline. The input guarantees that exactly one of the two following limitation categories applies. You must print a short rejection certificate from the applicable category:

- **Isolated Mask Obstruction:** There is a request $i$ ($1 \le i \le j$) such that if we evaluate the recurrences using indicator vectors where $M_i = 1$ and $N_i = 1$, and $M_k = N_k = 0$ for all $k \neq i$, the final value $S_{2,j}$ strictly exceeds $T$. If this category applies, print `JOB i`. If multiple requests satisfy this, printing any one of them is acceptable.

- **Asymmetric Mask Exhaustion:** There is a subsystem $c \in \{1, 2\}$ such that if we evaluate the recurrences using asymmetric masks, the final value $S_{2,j}$ strictly exceeds $T$.
  - If $c = 1$, the asymmetric masks are $M_k = 1$ for all $k$, and $N_k = 0$ for all $k$.
  - If $c = 2$, the asymmetric masks are $M_k = 0$ for all $k$, and $N_k = 1$ for all $k$.
  If this category applies, print `LOAD c`. If both subsystems satisfy this, printing either is acceptable.

Output must be consistent with the unique applicable limitation category guaranteed by the input.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the processing times of a request on subsystem 1 and subsystem 2, respectively.

## Output

Print a single line containing either `JOB i` or `LOAD c`. The output must be consistent with the unique applicable limitation category guaranteed by the input.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, consider the Isolated Mask Obstruction for request 1, where $M = [1, 0, 0]$ and $N = [1, 0, 0]$:
For $k=1$: $S_{1,1} = 0 + 1 \cdot 70 = 70$. $S_{2,1} = 0 + \max(70 - 0, 0) + 1 \cdot 60 = 130$.
For $k=2$: $S_{1,2} = 70 + 0 \cdot 2 = 70$. $S_{2,2} = 130 + \max(70 - 130, 0) + 0 \cdot 2 = 130$.
For $k=3$: $S_{1,3} = 70 + 0 \cdot 3 = 70$. $S_{2,3} = 130 + \max(70 - 130, 0) + 0 \cdot 4 = 130$.
The final value $S_{2,3}$ is 130, which exceeds $T=100$. Thus, `JOB 1` is a valid rejection certificate.

In Example 2, consider the Asymmetric Mask Exhaustion for subsystem 1, where $M = [1, 1, 1, 1]$ and $N = [0, 0, 0, 0]$:
For $k=1$: $S_{1,1} = 0 + 1 \cdot 50 = 50$. $S_{2,1} = 0 + \max(50 - 0, 0) + 0 \cdot 1 = 50$.
For $k=2$: $S_{1,2} = 50 + 1 \cdot 50 = 100$. $S_{2,2} = 50 + \max(100 - 50, 0) + 0 \cdot 1 = 100$.
For $k=3$: $S_{1,3} = 100 + 1 \cdot 50 = 150$. $S_{2,3} = 100 + \max(150 - 100, 0) + 0 \cdot 1 = 150$.
For $k=4$: $S_{1,4} = 150 + 1 \cdot 50 = 200$. $S_{2,4} = 150 + \max(200 - 150, 0) + 0 \cdot 1 = 200$.
The final value $S_{2,4}$ is 200, which exceeds $T=150$. Thus, `LOAD 1` is a valid rejection certificate.
</STATEMENT>
<RATIONALE>
The flow-shop completion time recurrence $\max(A, B)$ was rewritten into an algebraically identical difference-based accumulation $S_2 = S_2 + \max(S_1 - S_2, 0) + p_2$. The textual descriptions of "zeroing out other processing times" were replaced with explicit binary indicator vectors $M$ and $N$. This forces the model to mathematically simplify the new recurrence under the specified masks to discover the $O(N)$ reduction; models that merely pattern-match will likely attempt an $O(N^2)$ simulation and Time Limit Exceed.
</RATIONALE>
<PRESERVED_ANSWER>
The state transition $S_{2,k} = S_{2,k-1} + \max(S_{1,k} - S_{2,k-1}, 0) + N_k \cdot p_{2, k}$ simplifies algebraically to $S_{2,k} = \max(S_{1,k}, S_{2,k-1}) + N_k \cdot p_{2, k}$, which is exactly the standard flow-shop recurrence; applying the isolated and asymmetric masks yields the exact same logical conditions and outputs as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class remains $O(N)$ because evaluating the mathematically simplified recurrence for the given masks still reduces to checking $p_{1,i} + p_{2,i} > T$ or $\sum p_{1,k} > T$ or $\sum p_{2,k} > T$.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the indicator vectors as meaning they have to test all possible $2^j$ combinations of masks, although the statement explicitly defines the exact masks to test for each category.
</RISK>
