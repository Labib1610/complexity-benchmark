# Cellular Viability Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

A cellular ribosome network operates a two-stage assembly pathway for synthesizing essential protein chains. A batch of **j** peptide sequences has been transcribed, which must pass through exactly **two** catalytic enzymes. To ensure proper folding, every sequence must be processed by Enzyme Alpha (stage 1) first and then by Enzyme Beta (stage 2). Each enzyme can only catalyze one sequence at a time, and a sequence can only bind to Enzyme Beta after it has completely finished its reaction with Enzyme Alpha.

The organism is under environmental stress and has a strict viability threshold of **T** nanoseconds: all **j** sequences must be completely synthesized and folded by time **T**.

For every input in this problem, the viability threshold is guaranteed to be impossible to meet, regardless of how the synthesis is ordered. Your task is to generate a short biological rejection certificate that proves the threshold is impossible, which is verifiable directly against the input.

Exactly one of the following rejection reasons always applies. Print the one that holds:

- **A single sequence is too long.** If a specific sequence's reaction times on both enzymes add up to more than **T**, that sequence alone (reacting on stage 1 then stage 2, in sequence) cannot finish by **T**.
  Print: `JOB i` — where **i** (1-based index) is such a sequence. (The output code `JOB` stands for "Just One Block").

- **An enzyme is overloaded.** Because an enzyme processes sequences one at a time, it requires a time span at least equal to the sum of all its reaction times. If the total reaction time required on stage 1 (or stage 2) exceeds **T**, the threshold is impossible.
  Print: `LOAD c` — where **c** is 1 or 2, representing the stage whose total reaction time exceeds **T**.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the reaction times of a sequence on Enzyme Alpha (stage 1) and Enzyme Beta (stage 2), respectively.

## Output

Print a single line: `JOB i` (where a sequence's p1 + p2 exceeds T) or `LOAD c` (where stage c's total load exceeds T).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, sequence 1 needs 70 + 60 = 130 > 100 nanoseconds in sequence, so `JOB 1` proves the threshold is impossible. In Example 2 no single sequence exceeds 150, but stage 1 must process 50+50+50+50 = 200 > 150 nanoseconds of work in total, so `LOAD 1` is the rejection certificate.
