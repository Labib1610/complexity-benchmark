# SLA Rejection Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

A cloud computing platform provides a two-stage pipeline for processing client requests. A batch of **j** jobs has been submitted, which must pass through exactly **two** machines. To maintain data integrity, every job must be processed on machine 1 first and then on machine 2. Each machine can only process one job at a time, and a job can only arrive at machine 2 after it has completely finished on machine 1.

The client has requested a strict Service Level Agreement (SLA) deadline of **T** milliseconds: all **j** jobs must be completely finished by time **T**.

For every input in this problem, the requested SLA is guaranteed to be impossible to meet. Furthermore, this impossibility can always be proven by a simple certificate verifiable directly against the input data. The test cases are carefully constructed such that exactly one of the following two types of bottleneck is present, providing a unique rejection certificate:

- **Machine Bottleneck:** Because a machine processes jobs one at a time, it requires a time span at least equal to its total assigned work. If the raw volume of work assigned to a single machine means it cannot finish before the deadline even with zero idle time, output `LOAD c` (where **c** is 1 or 2 for the overloaded machine).

- **Job Bottleneck:** A job must be fully processed on machine 1 before it can start on machine 2. If a job's own sequential work requirement means it cannot finish before the deadline even if it were the only job in the system, output `JOB i` (where **i** is the 1-based index of the job).

Exactly one such certificate (either a single overloaded machine or a single bottleneck job) is guaranteed to exist for each test case. Print the one that holds.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **s1** and **s2** (1 ≤ s1, s2 ≤ 1000000): the processing times of a job on machine 1 and machine 2, respectively.

## Output

Print a single line containing the valid rejection certificate: either `LOAD c` or `JOB i`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, the first job requires 70 milliseconds on machine 1 and then 60 milliseconds on machine 2. Even in isolation, it needs 130 milliseconds, which exceeds the 100 millisecond deadline. Thus, `JOB 1` proves the SLA is impossible. 
In Example 2, no individual job exceeds the deadline. However, machine 1 has a total work volume of 200 milliseconds (50+50+50+50). Since it processes one job at a time, it cannot finish within the 150 millisecond deadline, making `LOAD 1` the valid certificate.
