# SLA Rejection Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

A cloud computing platform processes client requests through a two-stage pipeline. A batch of $j$ tasks has been submitted. Each task must be processed completely on server 1, and only after it is fully completed on server 1 can it be transferred to server 2 for its second stage. Both servers are strictly sequential: they handle exactly one task at a time. 

The client requires a Service Level Agreement (SLA) stipulating that all $j$ tasks must be fully completed by a hard deadline of $T$ milliseconds from the start of processing. 

For every input provided, it is impossible to meet this SLA deadline under any valid scheduling order. Your objective is to output a short rejection certificate that proves the deadline cannot be met.

The test cases are rigorously constructed such that exactly one of the following two reasons for failure applies. You must output the corresponding certificate for the unique bottleneck that applies:

- **Single Task Duration:** The sum of the processing times for a single task across both servers ($p1 + p2$) is strictly greater than the deadline $T$. 
  Print: `JOB i` — where $i$ (1-based index) is the specific task meeting this condition.

- **Server Workload:** The sum of processing times of all tasks on a single server is strictly greater than the deadline $T$. 
  Print: `LOAD c` — where $c$ is either 1 or 2, indicating the server whose total required processing time exceeds $T$.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
The following $j$ lines each contain two integers $p1$ and $p2$ ($1 \le p1, p2 \le 1000000$), representing the required processing time for the task on server 1 and server 2, respectively.

## Output

Print a single line containing either `JOB i` (if $p1_i + p2_i > T$ for task $i$) or `LOAD c` (if the sum of processing times of all tasks on server $c$ exceeds $T$).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
