# SLA Rejection Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

A cloud computing platform uses a two-stage pipeline to process client requests. A batch of **j** jobs has been submitted. Every job must be processed on machine 1 and then on machine 2. Each machine processes one job at a time. A job can only begin on machine 2 after it has completely finished on machine 1.

The client requires all **j** jobs to be completely finished by a strict Service Level Agreement (SLA) deadline of **T** milliseconds. 

For every input provided, it is impossible to meet this deadline, regardless of how the jobs are scheduled. Your task is to output a short rejection certificate proving the deadline cannot be met. 

The inputs are rigorously constructed such that exactly one of the following two reasons applies for every input. You must output the certificate corresponding to the single applicable reason:

- **Sequential Job Limit:** A single job cannot complete within the SLA. Because it must be processed on machine 1 then machine 2, its required sequential time strictly exceeds the SLA. 
  Print `JOB i`, where **i** is the 1-based index of such a job. If multiple jobs qualify, any one is acceptable.

- **Total Machine Workload:** A single machine cannot finish its required work within the SLA. The sum of the processing times for all jobs on this specific machine strictly exceeds the SLA. 
  Print `LOAD c`, where **c** is the machine number (1 or 2). If both machines qualify, either is acceptable.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the processing times of a job on machine 1 and machine 2, respectively.

## Output

Print a single line containing either `JOB i` (for a job whose sequential time exceeds T) or `LOAD c` (for a machine whose total load exceeds T), consistent with the guaranteed single applicable reason.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, the first job requires 70 milliseconds on machine 1 and 60 milliseconds on machine 2. Its required sequential time is 130 milliseconds, which strictly exceeds the 100-millisecond SLA. Therefore, `JOB 1` is a valid rejection certificate.

In Example 2, no single job exceeds the 150-millisecond SLA. However, the total workload on machine 1 is 50 + 50 + 50 + 50 = 200 milliseconds, which strictly exceeds the 150-millisecond SLA. Therefore, `LOAD 1` is a valid rejection certificate.
