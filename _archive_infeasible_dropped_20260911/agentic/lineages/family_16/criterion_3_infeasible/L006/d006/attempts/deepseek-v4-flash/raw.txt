We can check the two categories directly:

1. **Isolated Job Obstruction**: For each job, if `p1 + p2 > T`, then that job alone would miss the deadline.  
2. **Continuous Utilization Exhaustion**:  
   - Machine 1 total load = sum of all `p1`. If that sum > T, then `LOAD 1`.  
   - Machine 2 total load = sum of all `p2`. If that sum > T, then `LOAD 2`.

Since the input guarantees exactly one category applies, we can check in that order.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    idx = 2
    sum1 = 0
    sum2 = 0
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        sum1 += p1
        sum2 += p2
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
    if sum1 > T:
        print("LOAD 1")
        return
    if sum2 > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
