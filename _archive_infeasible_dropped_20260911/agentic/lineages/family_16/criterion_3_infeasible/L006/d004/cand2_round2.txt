<METHOD_NAME>System of Inequalities Translation</METHOD_NAME>
<METHOD_DESCRIPTION>Translates the physical scheduling constraints into a formal system of mathematical inequalities (start times and durations). The rejection certificates are defined as specific subsets of these inequalities that are logically contradictory. The models must deduce that a chain of two inequalities implies p1+p2 > T, and that non-overlapping constraints in a bounded interval imply the sum of durations exceeds T.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# SLA Rejection Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

A cloud computing platform uses a two-stage pipeline to process client requests. A batch of $j$ jobs has been submitted. Every job must be processed on machine 1 and then on machine 2. Each machine processes one job at a time without preemption. A job can only begin on machine 2 after it has completely finished on machine 1.

The client requires all $j$ jobs to be completely finished by a strict Service Level Agreement (SLA) deadline of $T$ milliseconds. 

Formally, a valid schedule assigns each job $k$ ($1 \le k \le j$) a start time $S_{1,k}$ on machine 1 and a start time $S_{2,k}$ on machine 2, such that the following conditions hold:
- **C1 (Positivity):** $S_{1,k} \ge 0$ for all $k$.
- **C2 (Sequentiality):** $S_{1,k} + p_{1,k} \le S_{2,k}$ for all $k$, where $p_{1,k}$ is the processing time of job $k$ on machine 1.
- **C3 (Deadline):** $S_{2,k} + p_{2,k} \le T$ for all $k$, where $p_{2,k}$ is the processing time of job $k$ on machine 2.
- **C4 (Machine 1 Non-overlap):** For any two distinct jobs $k$ and $m$, their processing intervals on machine 1 do not overlap. That is, either $S_{1,k} + p_{1,k} \le S_{1,m}$ or $S_{1,m} + p_{1,m} \le S_{1,k}$.
- **C5 (Machine 2 Non-overlap):** For any two distinct jobs $k$ and $m$, their processing intervals on machine 2 do not overlap. That is, either $S_{2,k} + p_{2,k} \le S_{2,m}$ or $S_{2,m} + p_{2,m} \le S_{2,k}$.

For every input provided, no valid schedule exists; it is impossible to meet all conditions simultaneously. Your task is to output a short rejection certificate proving the deadline cannot be met by identifying a specific subset of these conditions that is already logically contradictory.

You must check the following specific scenarios and output a certificate for one that is contradictory:

- **Isolated Job Scenario:** For some job $i$, the subset of conditions consisting only of C1, C2, and C3 for that specific job $i$ is logically contradictory on its own. If this is the case, print `JOB i` (where $i$ is the 1-based index). If multiple jobs qualify, any one is acceptable.

- **Independent Machine Scenario:** For some machine $c \in \{1, 2\}$, the subset of conditions consisting only of the non-overlap condition for machine $c$ (C4 if $c=1$, or C5 if $c=2$), along with the bounds $S_{c,k} \ge 0$ and $S_{c,k} + p_{c,k} \le T$ for all jobs $k$, is logically contradictory. If this is the case, print `LOAD c`. If both machines qualify, either is acceptable.

It is guaranteed that for every input, at least one of these specific scenarios will yield a contradictory subset.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the processing times of a job on machine 1 and machine 2, respectively.

## Output

Print a single line containing either `JOB i` (for a job qualifying under the isolated job scenario) or `LOAD c` (for a machine qualifying under the independent machine scenario).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, under the Isolated Job Scenario for job 1, conditions C1, C2, and C3 require $S_{1,1} \ge 0$, $S_{1,1} + 70 \le S_{2,1}$, and $S_{2,1} + 60 \le 100$. These inequalities imply $130 \le 100$, which is a contradiction. Therefore, `JOB 1` is a valid rejection certificate.

In Example 2, no single job's C1, C2, and C3 are contradictory. However, under the Independent Machine Scenario for machine 1, we require four non-overlapping intervals (from C4), each of length 50, to all fit within the bounds $S_{1,k} \ge 0$ and $S_{1,k} + 50 \le 150$. Packing four intervals of length 50 requires at least 200 milliseconds, making it impossible to fit them within a 150-millisecond window. This forms a contradiction, so `LOAD 1` is a valid rejection certificate.
</STATEMENT>
<RATIONALE>
The problem was reframed by defining the certificates as logically contradictory subsets of a formal system of inequalities, rather than using physical analogies like "infinitely fast" or "removed from the system." This forces the model to mathematically deduce that C1+C2+C3 implies `p1 + p2 > T` and that the non-overlap condition bounded by `[0, T]` implies `sum(p) > T`.
</RATIONALE>
<PRESERVED_ANSWER>
The subsets of inequalities are logically contradictory if and only if the exact same additive lower bounds from the seed problem (`p1 + p2 > T` and `sum(p) > T`) are violated, ensuring identical answers for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class remains exactly $O(N)$ because the logic reduces perfectly to checking the same single-job sums and machine-wide sums as the original problem.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "logically contradictory" as requiring an SAT solver or constraint programming approach, but the $O(N)$ requirement and the explicit breakdown in the Note should guide them to the arithmetic shortcuts.
</RISK>
