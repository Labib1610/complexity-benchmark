 We need to check two conditions:

1. **Sequential Bottleneck**: If any job has `p1 + p2 > T`, we can immediately output `JOB i` (1-based index).
2. **Machine Capacity Limit**: If the sum of all `p1` > T or sum of all `p2` > T, we output `LOAD 1` or `LOAD 2` respectively.

We can check these in order.  

Here’s the code:

```python
j, T = map(int, input().split())
total1 = 0
total2 = 0
jobs = []
for i in range(j):
    p1, p2 = map(int, input().split())
    jobs.append((p1, p2))
    total1 += p1
    total2 += p2

# Check sequential bottleneck
for idx, (p1, p2) in enumerate(jobs, start=1):
    if p1 + p2 > T:
        print(f"JOB {idx}")
        exit()

# Check machine capacity
if total1 > T:
    print("LOAD 1")
    exit()
if total2 > T:
    print("LOAD 2")
    exit()
```
