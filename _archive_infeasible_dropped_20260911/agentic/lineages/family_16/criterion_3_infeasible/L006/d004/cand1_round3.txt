<STATEMENT>
# SLA Rejection Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

A cloud computing platform uses a two-stage pipeline to process client requests. A batch of **j** jobs has been submitted. Every job must be processed on machine 1 and then on machine 2. Each machine processes one job at a time without preemption. A job can only begin on machine 2 after it has completely finished on machine 1.

The client requires all **j** jobs to be completely finished by a strict Service Level Agreement (SLA) deadline of **T** milliseconds. 

For every input provided, it is impossible to meet this deadline, regardless of how the jobs are scheduled. Your task is to output a short rejection certificate proving the deadline cannot be met. 

A certificate highlights a specific physical limitation that makes the deadline unachievable. For every input, at least one such limitation will be present. You must print one valid certificate that applies:

- **Sequential Bottleneck:** A job cannot begin on machine 2 until it has completely finished on machine 1. If the minimum time from when job **i** starts on machine 1 to when it finishes on machine 2 strictly exceeds the SLA deadline **T**, print `JOB i` (where **i** is the 1-based index). If multiple jobs qualify, any one is acceptable.

- **Machine Capacity Limit:** Each machine processes one job at a time without preemption. Therefore, a machine must remain active for a certain cumulative duration to clear its assigned tasks. If this required active time for machine **c** strictly exceeds the SLA deadline **T**, print `LOAD c` (where **c** is the machine number, 1 or 2). If both machines qualify, either is acceptable.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the processing times of a job on machine 1 and machine 2, respectively.

## Output

Print a single line containing either `JOB i` (for a job qualifying under the Sequential Bottleneck) or `LOAD c` (for a machine qualifying under the Machine Capacity Limit).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, under the Sequential Bottleneck for job 1, it requires 70 milliseconds on machine 1 and 60 milliseconds on machine 2. Since it must run sequentially, its minimum time from start to finish is 130 milliseconds, which strictly exceeds the 100-millisecond SLA. Therefore, `JOB 1` is a valid rejection certificate.

In Example 2, no single job exceeds the 150-millisecond SLA. However, under the Machine Capacity Limit for machine 1, the machine must process four jobs taking 50 milliseconds each. Because it processes one job at a time, its required active time is 200 milliseconds, which strictly exceeds the 150-millisecond SLA. Therefore, `LOAD 1` is a valid rejection certificate.
