<STATEMENT>
# SLA Rejection Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description
A data processing pipeline processes a sequence of $j$ jobs through exactly two stages. Each job $k$ (for $1 \le k \le j$) requires a processing weight of $p_{1,k}$ at stage 1 and $p_{2,k}$ at stage 2.

The pipeline's total processing footprint is evaluated by tracing data paths. A valid data path starts at stage 1 of job 1 and ends at stage 2 of job $j$. From any given stage $m$ of job $k$, the path can only advance in two ways:
- Move to the same stage $m$ of the next job $k+1$ (valid if $k < j$).
- Transition to the next stage $m+1$ of the current job $k$ (valid if $m < 2$).

The total weight of a data path is the sum of the processing weights of all the stage-job nodes it traverses. The final evaluation metric of the pipeline is the maximum total weight among all valid data paths. The system requires this maximum weight to be at most $T$.

For every input provided, it is impossible to meet this deadline. The input guarantees that exactly one of the two following structural failure families is the reason. You must print a short rejection certificate identifying a valid witness from the applicable family.

- **Isolated Job Bottleneck:** There is a job $i$ ($1 \le i \le j$) such that if we construct a hypothetical network where job $i$ retains its actual weights $p_{1,i}$ and $p_{2,i}$, but every other job $k \neq i$ is instantaneous (replaced with $p_{1,k} = 0$ and $p_{2,k} = 0$), the maximum weight among all valid data paths in this modified network strictly exceeds $T$.
  If this family applies, print `JOB i`.

- **Stage Saturation:** There is a stage $c \in \{1, 2\}$ such that if we construct a hypothetical network where the *other* stage takes 0 weight for all jobs, the maximum weight among all valid data paths in this modified network strictly exceeds $T$.
  - If $c = 1$, we evaluate using $p_{1,k}$ as given, but $p_{2,k} = 0$ for all $k$.
  - If $c = 2$, we evaluate using $p_{1,k} = 0$, but $p_{2,k}$ as given for all $k$.
  If this family applies, print `LOAD c`.

**Uniqueness and Multiplicity:** For every input, exactly one of the two failure families is guaranteed to hold. However, within the applicable family, there may be multiple valid witnesses (e.g., multiple jobs $i$ that individually exceed $T$, or both stages exceeding $T$). Outputting any one valid witness from the applicable family is acceptable.

## Input
The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the weights required at stage 1 and stage 2 for a job, respectively.

## Output
Print a single line containing either `JOB i` or `LOAD c` where `c` is 1 or 2. The output must be a valid witness from the unique applicable failure family guaranteed by the input.

## Examples

### Example 1
**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2
**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note
In Example 1, consider the hypothetical network for job 1 where jobs 2 and 3 take 0 weight:
The modified weights for (stage 1, stage 2) are $(70, 60)$, $(0, 0)$, $(0, 0)$.
A valid data path traversing stage 1 of job 1, transitioning to stage 2 of job 1, and then advancing through stage 2 of jobs 2 and 3 has a total weight of $70 + 60 + 0 + 0 = 130$. The maximum weight among all valid paths is 130. Since $130 > 100$, `JOB 1` is a valid rejection certificate.

In Example 2, consider the hypothetical network for stage 1 where all stage 2 weights are 0:
The modified weights use the given stage 1 weights and 0 for stage 2.
A valid data path advancing through stage 1 of all jobs 1 to 4, and transitioning to stage 2 at job 4 has a total weight of $50 + 50 + 50 + 50 + 0 = 200$. The maximum weight among all valid paths is 200. Since $200 > 150$, `LOAD 1` is a valid rejection certificate.
