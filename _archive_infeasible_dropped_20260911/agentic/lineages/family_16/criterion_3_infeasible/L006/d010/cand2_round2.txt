<METHOD_NAME>Vector Norm Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit job-sum and machine-load inequalities with equivalent vector norm conditions ($L_1$ norm for a single job's total time, and $L_\infty$ norm for the aggregate machine loads). <STATEMENT>
# SLA Rejection Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description
A data processing pipeline receives a set of $j$ jobs. Each job $k$ (for $1 \le k \le j$) requires $p_{1,k}$ milliseconds on machine 1 and $p_{2,k}$ milliseconds on machine 2.

We represent the resource requirements of each job $k$ as a 2-dimensional vector $\vec{r}_k = (p_{1,k}, p_{2,k})$. 

The pipeline must complete all operations within a strict deadline $T$. For every input provided, the schedule is impossible to complete within $T$. The input guarantees that the failure is caused by exactly one of the two structural bottlenecks defined below. You must print a short rejection certificate identifying a valid witness from the applicable bottleneck family.

- **Isolated Job Bottleneck:** There is a job $i$ ($1 \le i \le j$) whose total sequential processing requirement independently violates the deadline. This occurs if the $L_1$ norm (Manhattan length) of its resource vector strictly exceeds the deadline $T$. That is, $\|\vec{r}_i\|_1 > T$.
  If this family applies, print `JOB i`.

- **Machine Saturation:** The aggregate resource requirement across all jobs overloads a specific machine. Let $\vec{S} = \sum_{k=1}^j \vec{r}_k$ be the vector sum of all job resources. This bottleneck occurs if the $L_\infty$ norm (Chebyshev length) of the aggregate vector $\vec{S}$ strictly exceeds the deadline $T$. That is, $\|\vec{S}\|_\infty > T$.
  If this family applies, there is a machine $c \in \{1, 2\}$ whose corresponding component in the aggregate vector $\vec{S}$ strictly exceeds $T$. Print `LOAD c`.

**Uniqueness and Multiplicity:** For every input, exactly one of the two bottleneck families is guaranteed to hold. Within the applicable family, there may be multiple valid witnesses (e.g., multiple jobs that individually exceed $T$, or both machines exceeding $T$). Outputting any one valid witness from the applicable family is acceptable.

## Input
The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_{1,k}$ and $p_{2,k}$ ($1 \le p_{1,k}, p_{2,k} \le 1000000$): the time required on machine 1 and machine 2 for job $k$, respectively.

## Output
Print a single line containing either `JOB i` or `LOAD c`. The output must be a valid witness from the unique applicable failure family guaranteed by the input.

## Examples

### Example 1
**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2
**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note
In Example 1, the resource vector for job 1 is $\vec{r}_1 = (70, 60)$. Its $L_1$ norm evaluates to $130$. Since $130 > 100$, the Isolated Job Bottleneck applies and `JOB 1` is a valid rejection certificate.

In Example 2, the aggregate resource vector is the sum of all four jobs: $\vec{S} = (200, 4)$. The $L_\infty$ norm of $\vec{S}$ evaluates to $200$. Since $200 > 150$, the Machine Saturation bottleneck applies. The component exceeding the deadline corresponds to machine 1, so `LOAD 1` is a valid rejection certificate.
</STATEMENT>
<RATIONALE>
The problem was rewritten to completely remove the flow-shop sequence simulation, directly addressing the expert's and gate's feedback. Instead, the failure conditions are disguised using $L_1$ and $L_\infty$ vector norms of the jobs' resource requirements. This forces the model to understand the geometric definitions of these norms and translate them into the correct arithmetic checks (`p1+p2 > T` and `sum > T`), defeating models that merely pattern-match standard scheduling problem descriptions.
</RATIONALE>
<PRESERVED_ANSWER>
The $L_1$ norm of a job's resource vector is exactly $p_1+p_2$, and the $L_\infty$ norm of the aggregate vector is exactly $\max(\sum p_1, \sum p_2)$, precisely matching the original bottleneck conditions and preserving all outputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains solvable in $O(N)$ time by iterating through the jobs to check the $L_1$ norm of each and accumulating the vector sum to check its $L_\infty$ norm.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the vector components if they assume 0-based indexing for the dimensions, but the mapping to machines 1 and 2 is explicitly stated in the definitions.
</RISK>
