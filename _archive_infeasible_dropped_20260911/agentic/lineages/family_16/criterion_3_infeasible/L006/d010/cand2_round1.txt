<STATEMENT>
# SLA Rejection Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description
A data processing pipeline processes a sequence of $j$ jobs. Each job $k$ (for $1 \le k \le j$) requires $p_{1,k}$ milliseconds on machine 1 and then $p_{2,k}$ milliseconds on machine 2.

The pipeline tracks two timestamps for each job $k$:
- $E_k$: the time when the job completes on machine 1.
- $T_k$: the time when the job completes on machine 2.

Initially, at step 0 (before any jobs are processed), $E_0 = 0$ and $T_0 = 0$. For each job $k$ from $1$ to $j$, the timestamps are calculated sequentially:
- Machine 1 processes one job at a time, so job $k$ starts on machine 1 exactly when the previous job finishes on machine 1:
  $E_k = E_{k-1} + p_{1,k}$
- Machine 2 also processes one job at a time, but job $k$ cannot start on machine 2 until BOTH its own processing on machine 1 is finished AND the previous job's processing on machine 2 is finished:
  $T_k = \max(E_k, T_{k-1}) + p_{2,k}$

The final evaluation metric for the entire sequence is the completion time of the last job on machine 2, which is $T_j$. The system requires $T_j \le T$.

For every input provided, it is impossible to meet this deadline. The input guarantees that exactly one of the two failure families below is the reason. You must print a short rejection certificate identifying a valid witness from the applicable family.

- **Isolated Job Bottleneck:** There is a job $i$ ($1 \le i \le j$) such that if we compute a hypothetical evaluation where the state transitions for all other jobs $k \neq i$ are suppressed, the final metric $T_j$ strictly exceeds $T$.
  In this hypothetical evaluation, for all $k \neq i$, the state remains unchanged: $E_k = E_{k-1}$ and $T_k = T_{k-1}$. For the single job $i$, the normal transitions apply: $E_i = E_{i-1} + p_{1,i}$ and $T_i = \max(E_i, T_{i-1}) + p_{2,i}$.
  If this family applies, print `JOB i`.

- **Machine Saturation:** There is a machine $c \in \{1, 2\}$ such that if we compute a hypothetical evaluation where the time additions for the *other* machine are suppressed, the final metric $T_j$ strictly exceeds $T$.
  - If $c = 1$, we suppress machine 2's additions: for all $k$ from $1$ to $j$, the transitions are $E_k = E_{k-1} + p_{1,k}$ and $T_k = \max(E_k, T_{k-1})$.
  - If $c = 2$, we suppress machine 1's additions: for all $k$ from $1$ to $j$, the transitions are $E_k = E_{k-1}$ and $T_k = \max(E_k, T_{k-1}) + p_{2,k}$.
  If this family applies, print `LOAD c`.

**Uniqueness and Multiplicity:** For every input, exactly one of the two failure families is guaranteed to hold. However, within the applicable family, there may be multiple valid witnesses (e.g., multiple jobs $i$ that individually exceed $T$, or both machines exceeding $T$). Outputting any one valid witness from the applicable family is acceptable.

## Input
The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the time required on machine 1 and machine 2 for a job, respectively.

## Output
Print a single line containing either `JOB i` or `LOAD c`. The output must be a valid witness from the unique applicable failure family guaranteed by the input.

## Examples

### Example 1
**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2
**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note
In Example 1, consider the hypothetical evaluation for job 1 where state transitions for jobs 2 and 3 are suppressed:
Step 1 (job 1, normal): $E_1 = 0 + 70 = 70$. $T_1 = \max(70, 0) + 60 = 130$.
Step 2 (job 2, suppressed): $E_2 = E_1 = 70$. $T_2 = T_1 = 130$.
Step 3 (job 3, suppressed): $E_3 = E_2 = 70$. $T_3 = T_2 = 130$.
The final metric $T_3 = 130$. Since $130 > 100$, `JOB 1` is a valid rejection certificate.

In Example 2, consider the hypothetical evaluation for machine 1 where machine 2's additions are suppressed:
Step 1: $E_1 = 0 + 50 = 50$. $T_1 = \max(50, 0) = 50$.
Step 2: $E_2 = 50 + 50 = 100$. $T_2 = \max(100, 50) = 100$.
Step 3: $E_3 = 100 + 50 = 150$. $T_3 = \max(150, 100) = 150$.
Step 4: $E_4 = 150 + 50 = 200$. $T_4 = \max(200, 150) = 200$.
The final metric $T_4 = 200$. Since $200 > 150$, `LOAD 1` is a valid rejection certificate.
</STATEMENT>
<RATIONALE>
The models were pattern-matching the phrase "instantaneous (replaced with p=0)" directly to algebraic sums, bypassing the need to analyze the recurrence relation. I removed the explicit parameter zeroing and instead defined the hypothetical scenarios by providing modified recurrence equations where specific state transitions or additions are suppressed. A literal implementation of these equations takes O(n²) time and will TLE, forcing models to algebraically prove that the modified recurrences still collapse to the O(1) properties p1+p2 and sum(p).
</RATIONALE>
<PRESERVED_ANSWER>
The modified recurrence equations mathematically evaluate to the exact same values as the original zero-parameter simulations (e.g. keeping E_k and T_k unchanged is identical to adding 0), so the conditions for JOB i and LOAD c remain identical for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class remains INFEASIBLE (solvable in O(n) time) because the modified recurrence equations still algebraically simplify to checking if p1+p2 > T or sum(p) > T.
</PRESERVED_CLASS>
