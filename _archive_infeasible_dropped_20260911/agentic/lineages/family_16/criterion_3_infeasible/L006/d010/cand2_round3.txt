<METHOD_NAME>Matrix State Transition Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaced the explicit hypothetical sequences and simulated variables with a formal state transition operator $\boxplus$ and indicator matrices (Hadamard products). This hides the simple algebraic sums (e.g., $p_1+p_2$ and $\sum p_c$) behind a matrix projection operation. Models relying on surface patterns will likely attempt a literal $O(j^2)$ simulation of the transition operator for all items, resulting in a Time Limit Exceeded, while models that genuinely reason about the algebraic properties of $\boxplus$ over sparse matrices will discover the $O(j)$ simplifications.</METHOD_DESCRIPTION>

<STATEMENT>
# SLA Rejection Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description
A data processing pipeline processes a sequence of $j$ jobs. There are exactly 2 machines. Every job is processed on machine 1 first, then on machine 2; each machine processes at most one job at a time.

The processing requirements are given as a $2 \times j$ parameter matrix $P$, where $P_{1,k}$ and $P_{2,k}$ are the times required for job $k$ ($1 \le k \le j$) on machine 1 and machine 2, respectively.

We define the state transition operator $\boxplus$ which updates the completion timestamps $(E, T)$ after processing a job with parameters $(m_1, m_2)$:
$(E, T) \boxplus (m_1, m_2) = (E + m_1, \max(E + m_1, T) + m_2)$

For any $2 \times j$ matrix $M$, the pipeline duration function $D(M)$ is the second component of the final state $(E_j, T_j)$, which is obtained by starting from $(E_0, T_0) = (0, 0)$ and applying:
$(E_k, T_k) = (E_{k-1}, T_{k-1}) \boxplus (M_{1,k}, M_{2,k})$ for $k = 1 \dots j$.
Thus, $D(M) = T_j$.

The system requires $D(P) \le T$. For every input provided, this deadline is impossible to meet. The input guarantees that exactly one bottleneck family is guaranteed to apply; within that family, multiple witnesses may exist. You must print a short rejection certificate identifying a valid witness from the applicable family. Outputting any one valid witness from the applicable family is acceptable.

- **Isolated Job Bottleneck:** There is an index $i$ ($1 \le i \le j$) such that $D(P \odot C^{(i)}) > T$, where $C^{(i)}$ is a $2 \times j$ indicator matrix for column $i$ (all entries are $0$ except $C^{(i)}_{1,i} = 1$ and $C^{(i)}_{2,i} = 1$), and $\odot$ is the element-wise Hadamard product. If this family applies, print `JOB i`.

- **Machine Saturation:** There is an index $c \in \{1, 2\}$ such that $D(P \odot R^{(c)}) > T$, where $R^{(c)}$ is a $2 \times j$ indicator matrix for row $c$ (all entries are $0$ except $R^{(c)}_{c,k} = 1$ for all $1 \le k \le j$). If this family applies, print `LOAD c`.

## Input
The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $P_{1,k}$ and $P_{2,k}$ ($1 \le P_{1,k}, P_{2,k} \le 1000000$): the time required on machine 1 and machine 2 for job $k$, respectively.

## Output
Print a single line containing either `JOB i` or `LOAD c`. The output must be a valid witness from the unique applicable failure family guaranteed by the input: either `JOB i` satisfying $D(P \odot C^{(i)}) > T$, or `LOAD c` satisfying $D(P \odot R^{(c)}) > T$.

## Examples

### Example 1
**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2
**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note
In Example 1, $P = \begin{pmatrix} 70 & 2 & 3 \\ 60 & 2 & 4 \end{pmatrix}$.
For job 1, $P \odot C^{(1)} = \begin{pmatrix} 70 & 0 & 0 \\ 60 & 0 & 0 \end{pmatrix}$.
Step 1: $(0, 0) \boxplus (70, 60) = (70, 130)$.
Step 2: $(70, 130) \boxplus (0, 0) = (70, 130)$.
Step 3: $(70, 130) \boxplus (0, 0) = (70, 130)$.
The final metric $D(P \odot C^{(1)}) = 130$. Since $130 > 100$, `JOB 1` is a valid rejection certificate.

In Example 2, $P = \begin{pmatrix} 50 & 50 & 50 & 50 \\ 1 & 1 & 1 & 1 \end{pmatrix}$.
For machine 1, $P \odot R^{(1)} = \begin{pmatrix} 50 & 50 & 50 & 50 \\ 0 & 0 & 0 & 0 \end{pmatrix}$.
Step 1: $(0, 0) \boxplus (50, 0) = (50, 50)$.
Step 2: $(50, 50) \boxplus (50, 0) = (100, 100)$.
Step 3: $(100, 100) \boxplus (50, 0) = (150, 150)$.
Step 4: $(150, 150) \boxplus (50, 0) = (200, 200)$.
The final metric $D(P \odot R^{(1)}) = 200$. Since $200 > 150$, `LOAD 1` is a valid rejection certificate.
</STATEMENT>
<RATIONALE>
The problem was rewritten to use formal matrix operations (Hadamard products and indicator matrices) and a state transition operator $\boxplus$ instead of explicit loops and hypothetical job parameters. This forces the model to either trace the recurrence and simplify it algebraically (which yields the $O(j)$ sums) or write a literal simulation of the transition function (which takes $O(j^2)$ time and gets TLE). The explicit number "2" for machines and strict inequalities were fully restored to satisfy the gate constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The matrix projections $P \odot C^{(i)}$ and $P \odot R^{(c)}$ mathematically evaluate to the exact same zero-padded sequences as the seed problem's hypothetical scenarios, yielding identical duration metrics.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The conditions remain an $O(j)$ check of isolated job totals against $T$ and machine totals against $T$, preserving the linear time impossibility certification.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the standard mathematical notation for Hadamard product $\odot$, although it is explicitly defined as "element-wise Hadamard product" in the text.
</RISK>
