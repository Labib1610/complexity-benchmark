We need to determine which category applies: either an isolated job obstruction or continuous utilization exhaustion.  

We can check both conditions efficiently:

- For **JOB i**: For each job, we compute the hypothetical completion time if only that job has non-zero processing times.  
  The completion time for job `i` alone is simply `p1[i] + p2[i]` (since all other jobs take zero time, the sequence reduces to just that job).  
  If `p1[i] + p2[i] > T`, then `JOB i` is valid.

- For **LOAD c**:  
  - If `c = 1`, we set all `p2` to 0. Then the completion time is just the sum of all `p1` values.  
  - If `c = 2`, we set all `p1` to 0. Then the completion time is the sum of all `p2` values.  
  If the sum exceeds `T`, then `LOAD c` is valid.

Since the problem guarantees exactly one category applies, we can check in order: first check all jobs for `JOB`, then check loads.  

Here’s the implementation:

```python
import sys

def main():
    input_data = sys.stdin.read().strip().split()
    j = int(input_data[0])
    T = int(input_data[1])
    
    p1 = []
    p2 = []
    idx = 2
    for _ in range(j):
        p1.append(int(input_data[idx]))
        p2.append(int(input_data[idx+1]))
        idx += 2
    
    # Check JOB condition
    for i in range(j):
        if p1[i] + p2[i] > T:
            print(f"JOB {i+1}")
            return
    
    # Check LOAD condition
    if sum(p1) > T:
        print("LOAD 1")
        return
    if sum(p2) > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
