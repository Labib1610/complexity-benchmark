# Problem C — Impossible Poset Embeddings

Time limit: 2 s   Memory limit: 256 MB

## Description

Let $(X, \prec)$ be a totally ordered set with exactly **T** elements. 
We are given a collection of **j** distinct items. For each item $i$ ($1 \le i \le j$), we are assigned two target cardinalities: $\alpha_i$ and $\beta_i$.

We wish to construct two families of subsets of $X$, denoted $\mathcal{A} = \{A_1, A_2, \dots, A_j\}$ and $\mathcal{B} = \{B_1, B_2, \dots, B_j\}$, satisfying all of the following properties:
1. **$\mathcal{A}$-Disjointness:** For all $i \neq k$, $A_i \cap A_k = \emptyset$.
2. **$\mathcal{B}$-Disjointness:** For all $i \neq k$, $B_i \cap B_k = \emptyset$.
3. **Cardinality:** For each $i \in \{1 \dots j\}$, $|A_i| = \alpha_i$ and $|B_i| = \beta_i$.
4. **Strict Precedence:** For each $i \in \{1 \dots j\}$, the Cartesian product $A_i \times B_i$ is a subset of the strict relation $\prec$. (That is, for every $x \in A_i$ and every $y \in B_i$, we have $x \prec y$).

*(Note: There is no disjointness requirement between a set in $\mathcal{A}$ and a set in $\mathcal{B}$. An element of $X$ may belong to both $A_i$ and $B_k$, provided the Strict Precedence property is not violated.)*

Every provided configuration is mathematically impossible—there is no valid way to construct the families $\mathcal{A}$ and $\mathcal{B}$ in $X$ that satisfies all properties. Your task is to identify the bottleneck that proves the configuration cannot exist, providing a short certificate.

Exactly one of the following foundational requirements is broken. Output the applicable certificate:

- **Precedence Failure:** For some index $i$, it is impossible to find two subsets of $X$ of sizes $\alpha_i$ and $\beta_i$ such that every element of the first strictly precedes every element of the second. Output `JOB i` (where $i$ is the 1-based index).
- **$\mathcal{A}$-System Packing Failure:** It is impossible to find $j$ pairwise disjoint subsets of $X$ with the specified sizes $\alpha_1, \dots, \alpha_j$. Output `LOAD 1`.
- **$\mathcal{B}$-System Packing Failure:** It is impossible to find $j$ pairwise disjoint subsets of $X$ with the specified sizes $\beta_1, \dots, \beta_j$. Output `LOAD 2`.

You are guaranteed that exactly one of these requirements will be broken for the given input.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers $\alpha_i$ and $\beta_i$ (1 ≤ $\alpha_i$, $\beta_i$ ≤ 1000000): the required cardinalities for $A_i$ and $B_i$.

## Output

Print a single line: `JOB i` (for a precedence bottleneck) or `LOAD c` (for a packing bottleneck, where **c** is 1 for the $\mathcal{A}$-system or 2 for the $\mathcal{B}$-system).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for index 1, we require subsets $A_1$ and $B_1$ of sizes 70 and 60 respectively. There is no way to place these into a totally ordered set of 100 elements such that all elements of $A_1$ strictly precede all elements of $B_1$. Thus `JOB 1` is the correct proof of impossibility. 

In Example 2, no single index breaks the precedence requirement. However, the $\mathcal{A}$-system requires pairwise disjoint subsets of sizes 50, 50, 50, and 50. There is no way to pack these disjoint subsets (totaling 200 elements) into $X$, which only has 150 elements. Thus `LOAD 1` is the correct output.
