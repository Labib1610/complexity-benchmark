<STATEMENT>
# Problem C — Impossible Mapping: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a codomain $\mathcal{T} = \{1, 2, \dots, T\}$. A configuration consists of $j$ pairs of finite sets $(A_1, B_1), (A_2, B_2), \dots, (A_j, B_j)$ where $|A_i| = p_{1,i}$ and $|B_i| = p_{2,i}$ for each index $i$.

A valid configuration requires the existence of two injective functions:
$f: \bigsqcup_{i=1}^j A_i \to \mathcal{T}$
$g: \bigsqcup_{i=1}^j B_i \to \mathcal{T}$
subject to the cross-mapping constraint that for every $i \in \{1 \dots j\}$, if $x \in A_i$ and $y \in B_i$, then $f(x) < g(y)$.

Every provided configuration is mathematically impossible—no such pair of functions $(f, g)$ can exist. Your task is to identify the narrowest obstruction that prevents their existence, outputting the corresponding certificate.

The system guarantees exactly one type of structural obstruction is present. You must output its certificate:
- If for some index $i$, it is impossible to simultaneously define injective functions $f_i: A_i \to \mathcal{T}$ and $g_i: B_i \to \mathcal{T}$ that satisfy $f_i(x) < g_i(y)$ for all $x \in A_i$ and $y \in B_i$, output `JOB i` (where $i$ is the 1-based index).
- If all individual pairs can be mapped, but it is impossible to define an injective function $f$ from the entire disjoint union $\bigsqcup_{i=1}^j A_i$ to $\mathcal{T}$, output `LOAD 1`.
- If neither of the above applies, it is impossible to define an injective function $g$ from the entire disjoint union $\bigsqcup_{i=1}^j B_i$ to $\mathcal{T}$. Output `LOAD 2`.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the set sizes $|A_i|$ and $|B_i|$ respectively.

## Output

Print a single line: `JOB i` (for the first type of obstruction), `LOAD 1` (for the second type), or `LOAD 2` (for the third type).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for index 1, $|A_1| = 70$ and $|B_1| = 60$. There are no injective functions $f_1: A_1 \to \{1 \dots 100\}$ and $g_1: B_1 \to \{1 \dots 100\}$ such that all values in the image of $f_1$ are strictly less than all values in the image of $g_1$. This triggers the first obstruction type, so `JOB 1` is the correct proof.

In Example 2, all individual pairs can be mapped. However, the disjoint union $\bigsqcup_{i=1}^4 A_i$ has a cardinality of $50 + 50 + 50 + 50 = 200$. It is impossible to define an injective function from a set of size 200 to a codomain of size 150. This triggers the second obstruction type, so `LOAD 1` is the correct output.
</STATEMENT>
<RATIONALE>
The explicit scheduling rules (setup/teardown routines and capacity limits) have been replaced with the abstract mathematical requirement of defining injective functions from disjoint unions to a bounded codomain. Models must now deduce that the existence of an injective function requires the domain size to be at most the codomain size, forcing them to derive the additive threshold checks mathematically rather than pattern-matching on physical capacity constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The condition for an injective function to exist from a disjoint union to a set of size T is exactly that the sum of the set sizes is <= T, and the strict inequality constraint for a single pair exactly requires their combined sizes to be <= T, perfectly preserving the original arithmetic failure conditions.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
<RISK>
Models might struggle with the mathematical notation of the disjoint union $\bigsqcup$, though it is a standard concept in set theory and its cardinality is unambiguously the sum of the cardinalities of the constituent sets.
</RISK>
