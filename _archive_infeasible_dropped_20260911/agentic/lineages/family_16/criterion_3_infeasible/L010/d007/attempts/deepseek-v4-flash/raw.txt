We can check each condition in order:

1. **Separation failure**: For entity `i`, we need `p1 + p2 <= T` because all `X` elements must be strictly less than all `Y` elements, so the smallest possible arrangement is `1..p1` for X and `T-p2+1..T` for Y. If `p1 + p2 > T`, it's impossible.

2. **X-domain exhaustion**: Sum of all `p1` must be ≤ `T`, otherwise we can't pick disjoint X sets.

3. **Y-domain exhaustion**: Sum of all `p2` must be ≤ `T`, otherwise we can't pick disjoint Y sets.

Since exactly one condition is broken, we check in that order.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    p1s = []
    p2s = []
    idx = 2
    for _ in range(j):
        p1 = int(data[idx])
        p2 = int(data[idx+1])
        idx += 2
        p1s.append(p1)
        p2s.append(p2)
    
    # Check separation failure
    for i in range(j):
        if p1s[i] + p2s[i] > T:
            print(f"JOB {i+1}")
            return
    
    # Check X exhaustion
    if sum(p1s) > T:
        print("LOAD 1")
        return
    
    # Check Y exhaustion
    if sum(p2s) > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
