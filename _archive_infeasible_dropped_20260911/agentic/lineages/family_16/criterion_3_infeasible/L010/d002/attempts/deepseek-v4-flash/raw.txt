We can check the two bottleneck conditions directly:

1. **Component Delay**: If for any component `p1 + p2 > T`, then it’s impossible to schedule that component’s two phases sequentially within the window. Output `JOB i`.

2. **Machine Saturation**: If the sum of all `p1` durations exceeds `T`, then the build machine is overloaded → `LOAD 1`. If the sum of all `p2` durations exceeds `T`, then the testing machine is overloaded → `LOAD 2`.

We check component delay first, then machine saturation.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    
    total_p1 = 0
    total_p2 = 0
    
    idx = 2
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        
        total_p1 += p1
        total_p2 += p2
    
    if total_p1 > T:
        print("LOAD 1")
        return
    
    if total_p2 > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
