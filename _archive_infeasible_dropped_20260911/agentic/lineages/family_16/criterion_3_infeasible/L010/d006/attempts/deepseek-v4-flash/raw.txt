We can check each condition in order:

1. **Lifecycle failure**: For each application, if `p1 + p2 > T`, it’s impossible to place all setups before all teardowns within `T` slots.  
2. **Setup congestion**: If the sum of all `p1` values exceeds `T`, then setup capacity is violated.  
3. **Teardown congestion**: If the sum of all `p2` values exceeds `T`, then teardown capacity is violated.

Since exactly one condition is broken, we check in that order and output the first match.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    
    idx = 2
    total_p1 = 0
    total_p2 = 0
    
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        
        total_p1 += p1
        total_p2 += p2
    
    if total_p1 > T:
        print("LOAD 1")
        return
    
    if total_p2 > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
