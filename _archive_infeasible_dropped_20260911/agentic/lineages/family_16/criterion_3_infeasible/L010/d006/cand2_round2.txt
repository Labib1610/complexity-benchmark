<STATEMENT>
# Problem C — Impossible Protocol: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A state space consists of **T** discrete states, represented as integers from 1 to **T** inclusive. A session consists of **j** independent exchanges. For each exchange $i$, the protocol must select two subsets of states:
- A Q-set consisting of exactly **p1** distinct states.
- An R-set consisting of exactly **p2** distinct states.

A valid session must satisfy three strict properties:
1. **Intra-Exchange Isolation:** For any single exchange $i$, if we take the union of its Q-set and its R-set and sort these states in ascending order, the resulting sequence must contain exactly **p1 + p2** states. Furthermore, the first **p1** states in this sequence must be exactly the elements of the Q-set, and the remaining **p2** states must be exactly the elements of the R-set.
2. **Global Q-Isolation:** No state in the state space can be included in the Q-set of more than one exchange.
3. **Global R-Isolation:** No state in the state space can be included in the R-set of more than one exchange.

Every provided configuration represents an impossible session—there is no valid way to select the sets that satisfies all properties within a state space of size **T**. Instead of attempting to select them, your task is to identify the bottleneck that proves the configuration is unachievable, providing a short certificate the system can verify.

Exactly one of the following foundational requirements is broken. Output the applicable certificate:

- **Isolation Failure:** For some exchange $i$, there exist no Q-set and R-set choices from the **T** available states that satisfy the Intra-Exchange Isolation property. Output `JOB i` (where $i$ is the 1-based index of the exchange).
- **Q-Capacity Exceeded:** There exist no **j** Q-sets from the **T** available states that satisfy the Global Q-Isolation property. Output `LOAD 1`.
- **R-Capacity Exceeded:** There exist no **j** R-sets from the **T** available states that satisfy the Global R-Isolation property. Output `LOAD 2`.

You are guaranteed that exactly one of these requirements will be broken for the given input.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required sizes for the Q-set and the R-set of an exchange.

## Output

Print a single line: `JOB i` (for an isolation bottleneck) or `LOAD c` (for a capacity bottleneck, where **c** is 1 for Q-capacity or 2 for R-capacity).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for exchange 1, the Q-set requires 70 distinct states and the R-set requires 60 distinct states. There is no way to select these sets from the 100 available states such that, when combined and sorted, the first 70 states are exactly the Q-set and the remaining 60 states are exactly the R-set. This breaks the Intra-Exchange Isolation property, making `JOB 1` the correct proof of impossibility. 

In Example 2, no single exchange breaks Intra-Exchange Isolation. However, the Q-sets require 50, 50, 50, and 50 states respectively. There is no way to choose these 4 sets from the 150 available states such that no state is assigned to more than one Q-set, breaking the Global Q-Isolation property. Thus `LOAD 1` is the correct output.

<RATIONALE>
The direct mathematical inequalities (`max < min`) from the seed were replaced with an operational sorting property on set unions. To satisfy the new sequence partitioning definition, models must reason that the combined set requires exactly `p1+p2` distinct elements, which forces them to deduce the `p1+p2 <= T` cardinality constraint rather than relying on surface pattern matching of standard cryptographic or scheduling terminology.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that the union contains exactly p1+p2 states enforces that the sets are disjoint, and the requirement that the first p1 states belong to the Q-set enforces that all elements in Q are strictly less than all elements in R, making it mathematically identical to the seed's causality constraint.
</PRESERVED_ANSWER>
