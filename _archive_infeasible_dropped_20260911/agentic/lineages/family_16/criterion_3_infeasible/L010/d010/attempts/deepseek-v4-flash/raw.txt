We can check the three conditions in order:

1. **Sequential Violation**: If any order has `p1 + p2 > T`, output `JOB i`.
2. **Assembly Saturation**: If the sum of all `p1` values exceeds `T`, output `LOAD 1`.
3. **Painting Saturation**: If the sum of all `p2` values exceeds `T`, output `LOAD 2`.

Since the problem guarantees exactly one condition is violated, we can check them in this order.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    idx = 2
    total_p1 = 0
    total_p2 = 0
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        total_p1 += p1
        total_p2 += p2
    if total_p1 > T:
        print("LOAD 1")
        return
    if total_p2 > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
