<STATEMENT>
# Problem C — Infeasible System: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of algebraic constraints involving **j** components. For each component **i** (from 1 to **j**), there are four real-valued variables to be determined: $x_{i,1}$, $x_{i,2}$, $y_{i,1}$, and $y_{i,2}$.

The system is defined by the following sets of constraints, where **T** is a global bound, and for each component **i**, $p_{i,1}$ and $p_{i,2}$ are given positive constants:

**Internal Constraints:**
For each component **i**:
1. $x_{i,2} - x_{i,1} = p_{i,1}$
2. $y_{i,2} - y_{i,1} = p_{i,2}$
3. $y_{i,1} \ge x_{i,2}$

**Mutual Exclusion Constraints:**
4. For any pair of distinct components **i** and **k**, their $x$-domains must not intersect in their interiors. That is, either $x_{i,1} \ge x_{k,2}$ or $x_{k,1} \ge x_{i,2}$.
5. For any pair of distinct components **i** and **k**, their $y$-domains must not intersect in their interiors. That is, either $y_{i,1} \ge y_{k,2}$ or $y_{k,1} \ge y_{i,2}$.

**Global Boundary Constraints:**
6. For all components **i**: $x_{i,1} \ge 0$ and $y_{i,2} \le T$.

Every provided test case represents an impossible configuration—there is no assignment of real numbers to these $4j$ variables that satisfies all constraints simultaneously. Your task is to identify the bottleneck that proves the system is unachievable, providing a short certificate the verifier can check.

A configuration is impossible because exactly one of the following isolated constraint subsystems is inherently contradictory. Output the applicable certificate:

- **Component Subsystem:** For some component **i**, there exists no assignment of real numbers to its four variables $(x_{i,1}, x_{i,2}, y_{i,1}, y_{i,2})$ that satisfies constraints 1, 2, 3, and 6. Output `JOB i` (where **i** is the 1-based index of the component).
- **X-Exclusion Subsystem:** There exists no assignment of real numbers to the $2j$ variables $(x_{1,1}, x_{1,2}, \dots, x_{j,1}, x_{j,2})$ that satisfies constraint 1 for all **i**, constraint 4 for all pairs, and the bounds $x_{i,1} \ge 0$ and $x_{i,2} \le T$ for all **i**. Output `LOAD 1`.
- **Y-Exclusion Subsystem:** There exists no assignment of real numbers to the $2j$ variables $(y_{1,1}, y_{1,2}, \dots, y_{j,1}, y_{j,2})$ that satisfies constraint 2 for all **i**, constraint 5 for all pairs, and the bounds $y_{i,1} \ge 0$ and $y_{i,2} \le T$ for all **i**. Output `LOAD 2`.

You are guaranteed that exactly one of these three subsystems is contradictory for the given input.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the constants $p_{i,1}$ and $p_{i,2}$ for a component.

## Output

Print a single line: `JOB i` (if the Component Subsystem for **i** is contradictory) or `LOAD c` (where **c** is 1 for the X-Exclusion Subsystem or 2 for the Y-Exclusion Subsystem).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for component 1, its constants are 70 and 60 respectively. There is no assignment of real numbers to its four variables that satisfies constraints 1, 2, 3, and 6 simultaneously, breaking the Component Subsystem. Thus `JOB 1` is the correct proof of impossibility. 

In Example 2, no single component breaks its Component Subsystem. However, the $p_{i,1}$ constants are 50, 50, 50, and 50. There is no assignment of real numbers for the $x$ variables that satisfies constraint 1 for all **i**, constraint 4 for all pairs, and the bounds $x_{i,1} \ge 0, x_{i,2} \le 150$ for all **i**, breaking the X-Exclusion Subsystem. Thus `LOAD 1` is the correct output.
