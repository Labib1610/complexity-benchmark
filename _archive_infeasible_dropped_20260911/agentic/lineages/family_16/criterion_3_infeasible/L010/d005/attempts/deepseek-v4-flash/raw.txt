We can check each condition in order:

1. **Causality**: For exchange `i`, we need to place `p1` query values and `p2` reply values in `{1..T}` such that all query values are strictly less than all reply values.  
   The smallest possible maximum for queries is `p1` (if we use `1..p1`).  
   The largest possible minimum for replies is `T - p2 + 1` (if we use the top `p2` values).  
   So we need `p1 < T - p2 + 1`, i.e. `p1 + p2 <= T`.  
   If this fails for some `i`, output `JOB i`.

2. **Query Collision**: We need `j` disjoint sets of sizes `p1_i`.  
   Total needed = sum of all `p1_i`. If this exceeds `T`, output `LOAD 1`.

3. **Reply Collision**: Similarly, sum of all `p2_i` must be ≤ `T`, otherwise output `LOAD 2`.

Since exactly one condition is broken, we check in that order.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    p1_list = []
    p2_list = []
    idx = 2
    for i in range(j):
        p1 = int(data[idx])
        p2 = int(data[idx+1])
        idx += 2
        p1_list.append(p1)
        p2_list.append(p2)
    
    # Check causality
    for i in range(j):
        if p1_list[i] + p2_list[i] > T:
            print(f"JOB {i+1}")
            return
    
    # Check query collision
    if sum(p1_list) > T:
        print("LOAD 1")
        return
    
    # Check reply collision
    if sum(p2_list) > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
