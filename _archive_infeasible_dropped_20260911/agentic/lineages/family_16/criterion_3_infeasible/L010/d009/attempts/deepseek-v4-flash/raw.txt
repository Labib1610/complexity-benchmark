We can check each condition in order:

1. **Phase Violation** — For a single database, we need to see if it’s possible to place its deltas and snapshots so that the final tracker equals `p2`.  
   The tracker resets to 0 on a Delta, and increments by 1 on a Snapshot.  
   To end at `p2`, the last `p2` snapshots must not be followed by any delta.  
   So we need at least `p1 + p2` seconds if all deltas must come before the last `p2` snapshots.  
   If `p1 + p2 > T`, it’s impossible for that job.

2. **Delta Saturation** — If the sum of all `p1` exceeds `T`, we can’t schedule all deltas.

3. **Snapshot Saturation** — If the sum of all `p2` exceeds `T`, we can’t schedule all snapshots.

We check in that order, and since exactly one condition is broken, we output the first one we find.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    idx = 2
    total_p1 = 0
    total_p2 = 0
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        total_p1 += p1
        total_p2 += p2
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
    if total_p1 > T:
        print("LOAD 1")
        return
    if total_p2 > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
