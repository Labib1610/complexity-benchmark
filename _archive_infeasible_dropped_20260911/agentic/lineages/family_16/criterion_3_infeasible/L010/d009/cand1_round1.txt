# Problem C — Impossible Allocation: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are tasked with verifying a proposed layout on a $2 \times T$ manufacturing grid. The grid consists of 2 rows (Row 1 and Row 2) and $T$ columns (numbered $1$ to $T$). There are $j$ distinct product orders. 

For each product order $i \in \{1, \dots, j\}$, the layout must allocate exactly $p1_i$ cells in Row 1 and exactly $p2_i$ cells in Row 2. 
The grid has the following physical constraints:
- Any given cell in the grid can be allocated to at most one product order.
- Consequently, Row 1 can hold at most one product's block per column, and Row 2 can hold at most one product's block per column.

Additionally, the manufacturing process enforces a strict spatial separation for every product. For a layout to be valid, every product order $i$ must satisfy the following geometric condition:
Let $C_{1,i}$ be the set of column indices where product $i$ is allocated a cell in Row 1.
Let $C_{2,i}$ be the set of column indices where product $i$ is allocated a cell in Row 2.
It is strictly required that $\max(C_{1,i}) < \min(C_{2,i})$.

Every configuration provided in the input is mathematically impossible to lay out—there is no valid way to place all required cells while satisfying the spatial separation condition for all products. Your task is to identify the bottleneck that proves the configuration is unachievable.

Exactly one of the following foundational requirements is broken. Output the applicable certificate:

- **Spatial Violation:** For some product order $i$, it is impossible to place its $p1_i$ Row 1 cells and $p2_i$ Row 2 cells within the $T$ columns such that its spatial separation condition is satisfied (even if it were the only product on the grid). Output `JOB i` (where $i$ is the 1-based index of the product).
- **Row 1 Saturation:** It is impossible to place all required Row 1 cells for all $j$ products within the $T$ columns. Output `LOAD 1`.
- **Row 2 Saturation:** It is impossible to place all required Row 2 cells for all $j$ products within the $T$ columns. Output `LOAD 2`.

You are guaranteed that exactly one of these requirements will be broken for the given input.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required number of Row 1 cells and Row 2 cells respectively for product $i$ (i.e., $p1_i$ and $p2_i$).

## Output

Print a single line: `JOB i` (for a spatial violation) or `LOAD c` (for a saturation failure, where **c** is 1 for Row 1 saturation or 2 for Row 2 saturation).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
