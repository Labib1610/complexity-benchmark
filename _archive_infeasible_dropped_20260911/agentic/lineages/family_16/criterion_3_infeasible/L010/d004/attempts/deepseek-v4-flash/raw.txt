We can check the three invariants in order:

1. **Motif Span Invariant**: For each motif, the minimum total length needed is `p1 + p2` (alpha then beta, no gap). If `p1 + p2 > T`, that motif is impossible.  
2. **Alpha Channel Invariant**: The sum of all `p1` must be ≤ `T`, otherwise they cannot all fit without overlap.  
3. **Beta Channel Invariant**: The sum of all `p2` must be ≤ `T`, otherwise they cannot all fit without overlap.

Since exactly one invariant is broken, we check in that order and output the first failure.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    
    total_p1 = 0
    total_p2 = 0
    
    idx = 2
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        
        total_p1 += p1
        total_p2 += p2
    
    if total_p1 > T:
        print("LOAD 1")
        return
    
    if total_p2 > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
