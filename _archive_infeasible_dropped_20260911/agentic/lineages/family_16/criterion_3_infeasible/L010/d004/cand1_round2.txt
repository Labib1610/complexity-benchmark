# Problem C — Impossible Canvas: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing plant is decorating a continuous canvas of material of width **T** millimeters. The order consists of **j** distinct motifs. The decoration process involves two steps: applying a primer coat, followed by a finish coat.

For each motif, the primer coat occupies a continuous segment of width **p1** mm, and the finish coat occupies a continuous segment of width **p2** mm. 

The placement of these segments must adhere to the following rules:
1. For any single motif, its finish coat segment must be positioned sequentially after its primer coat segment on the canvas.
2. All primer coat segments for all motifs share the same Layer 1 applicator, so they must be placed as non-overlapping segments.
3. All finish coat segments for all motifs share the same Layer 2 applicator, so they must also be placed as non-overlapping segments.
4. All segments must fit entirely within the canvas span, from 0 to **T**.

Every provided order represents an impossible configuration—there is no valid arrangement of segments that can satisfy all constraints on a canvas of width **T**. Instead of attempting to place them, your task is to identify a bottleneck that proves the configuration is unachievable, providing a short certificate the system can verify.

Exactly one of the following bottlenecks will always be present. Output the applicable certificate:

- **Motif Spread.** A valid arrangement requires a motif's primer and finish coats to be placed as two sequential segments. If it is mathematically impossible to fit these two segments for a specific motif inside the canvas [0, **T**] even when all other motifs are ignored, output `JOB i`, where **i** is the 1-based index of the motif.
- **Applicator Saturation.** A valid arrangement requires an applicator to contain its respective segments for all motifs as non-overlapping segments. If it is mathematically impossible to place all segments assigned to applicator **c** inside the canvas [0, **T**] without overlap, even when sequential dependencies between primer and finish coats are ignored, output `LOAD c`, where **c** is 1 for the Layer 1 applicator or 2 for the Layer 2 applicator.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the primer coat width and finish coat width of a motif.

## Output

Print a single line: `JOB i` (for a motif bottleneck) or `LOAD c` (for an applicator bottleneck).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for motif 1, any arrangement must place its 60 mm finish coat sequentially after its 70 mm primer coat. It is mathematically impossible to fit these two sequential segments within the 100 mm canvas even in isolation, making `JOB 1` the correct proof of impossibility. 

In Example 2, no single motif is impossible to fit in isolation. However, the Layer 1 applicator must accommodate four non-overlapping segments each of width 50 mm. It is mathematically impossible to place these four segments without overlap inside the 150 mm canvas, making `LOAD 1` the correct output.
