<STATEMENT>
# Problem C — Impossible Ribbon: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing plant is decorating a continuous ribbon of length **T** millimeters. The order consists of **j** distinct designs. A complete decoration configuration assigns a primary center coordinate $c_k$ and a secondary center coordinate $d_k$ for each design $k$ (where $k$ ranges from 1 to $j$). The base and top layer lengths for design $k$ are $w_k$ and $v_k$, respectively.

A configuration is valid if it satisfies all of the following conditions:
(1) Boundary Limits: For every $k$, $w_k / 2 \le c_k \le T - w_k / 2$ and $v_k / 2 \le d_k \le T - v_k / 2$.
(2) Layer Sequencing: For every $k$, $c_k + w_k / 2 \le d_k - v_k / 2$.
(3) Primary Separation: For every pair of distinct designs $k$ and $m$, $|c_k - c_m| \ge (w_k + w_m) / 2$.
(4) Secondary Separation: For every pair of distinct designs $k$ and $m$, $|d_k - d_m| \ge (v_k + v_m) / 2$.

Every provided order represents an impossible configuration—there is no assignment of real numbers to $c_k$ and $d_k$ that can satisfy all conditions. Your task is to pinpoint the exact source of the contradiction by identifying a specific restricted subset of conditions that is inherently unsolvable. Exactly one of the following unsolvable subsets will be present in every test case:

- **Isolated Sequencing:** The system of inequalities consisting of conditions (1) and (2) applied only to a specific design $i$ admits no real solutions for $c_i$ and $d_i$. If this occurs, output `JOB i` (where $i$ is the 1-based index of the design).
- **Primary Crowding:** The system of inequalities consisting of the $c$-variable bounds in (1) (namely $w_k / 2 \le c_k \le T - w_k / 2$ for all $k$) and all conditions in (3) admits no real solutions for $c_1, \dots, c_j$. If this occurs, output `LOAD 1`.
- **Secondary Crowding:** The system of inequalities consisting of the $d$-variable bounds in (1) (namely $v_k / 2 \le d_k \le T - v_k / 2$ for all $k$) and all conditions in (4) admits no real solutions for $d_1, \dots, d_j$. If this occurs, output `LOAD 2`.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **w** and **v** (1 ≤ w, v ≤ 1000000): the base layer length and top layer length of a design, given in order from 1 to $j$.

## Output

Print a single line: `JOB i` (for an isolated sequencing bottleneck) or `LOAD c` (for a crowding bottleneck, where `c` is 1 for primary or 2 for secondary).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for design 1, $w_1 = 70$ and $v_1 = 60$. The system of inequalities for this design requires $35 \le c_1 \le 65$, $30 \le d_1 \le 70$, and $c_1 + 35 \le d_1 - 30$. This simplifies to $c_1 + 65 \le d_1$. The minimum possible value for $c_1 + 65$ is $35 + 65 = 100$. For this to be $\le d_1$, we would need $d_1 \ge 100$, which contradicts the boundary limit $d_1 \le 70$. Thus, it admits no real solutions, making `JOB 1` the correct proof of impossibility.

In Example 2, no single design's conditions (1) and (2) are unsolvable. However, the primary crowding system requires placing four center coordinates $c_1, \dots, c_4$ such that $25 \le c_k \le 125$ and any two centers are separated by at least 50. This is mathematically equivalent to packing four non-overlapping segments of length 50 into a bounded space of 150, which requires a total space of at least 200. Thus, the system admits no real solutions for $c_1, \dots, c_4$, making `LOAD 1` the correct output.
</STATEMENT>
<RATIONALE>
The explicit descriptions of "sum of segments exceeding T" have been replaced with a formal system of algebraic inequalities using center coordinates and absolute differences. To solve the problem, models must now deduce that the feasibility of these specific inequality subsets is mathematically identical to checking whether $w_i + v_i > T$, $\sum w_k > T$, or $\sum v_k > T$, preventing them from pattern-matching the thresholds directly from the text.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic condition for "Isolated Sequencing" being unsolvable is exactly $w_i + v_i > T$, while the "Crowding" systems are unsolvable exactly when $\sum w_k > T$ or $\sum v_k > T$, preserving all outputs perfectly.
</PRESERVED_ANSWER>
