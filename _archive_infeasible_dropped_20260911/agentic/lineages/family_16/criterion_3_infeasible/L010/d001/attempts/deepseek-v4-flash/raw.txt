We can solve this by checking two conditions:

1. **Component Delay**: For each job, if `p1 + p2 > T`, then even if it starts at time 0, it cannot finish by time `T`. Output `JOB i` for the first such job.

2. **Machine Saturation**: If no job individually exceeds `T`, check if the sum of all `p1` exceeds `T` (build machine) or sum of all `p2` exceeds `T` (testing machine). Output `LOAD 1` or `LOAD 2` accordingly.

Here’s the implementation:

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    idx = 2
    sum_p1 = 0
    sum_p2 = 0
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        sum_p1 += p1
        sum_p2 += p2
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
    if sum_p1 > T:
        print("LOAD 1")
    elif sum_p2 > T:
        print("LOAD 2")

if __name__ == "__main__":
    main()
```
