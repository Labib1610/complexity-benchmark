We can check each condition in order:

1. **Causal Violation**: For a single flow, if it needs both ingress and egress packets, the egress packets must come before any ingress packet. That means all egress packets must be scheduled in the first `p2` slots, and all ingress packets in the remaining slots. So the condition for feasibility is `p1 + p2 <= T`. If violated, output `JOB i`.

2. **Ingress Saturation**: If the sum of all `p1` exceeds `T`, output `LOAD 1`.

3. **Egress Saturation**: If the sum of all `p2` exceeds `T`, output `LOAD 2`.

Since exactly one is broken, we check in that order.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    idx = 2
    total_p1 = 0
    total_p2 = 0
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        total_p1 += p1
        total_p2 += p2
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
    if total_p1 > T:
        print("LOAD 1")
        return
    if total_p2 > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
