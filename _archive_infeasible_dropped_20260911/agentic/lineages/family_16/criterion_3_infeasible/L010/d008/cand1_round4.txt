# Problem C — Algebraic Certificate of Impossibility

Time limit: 2 s   Memory limit: 256 MB

## Description

You are tasked with analyzing the feasibility of constructing two binary matrices (matrices containing only 0s and 1s), $A$ and $B$, each of dimension $j \times T$ (with $j$ rows and $T$ columns). 

For each row index $i \in \{1, \dots, j\}$, the $i$-th row of $A$ must contain exactly $p1_i$ ones, and the $i$-th row of $B$ must contain exactly $p2_i$ ones. All other entries in the matrices must be zero.

A valid construction must satisfy three algebraic invariants:
1. **Upper Triangular Projection:** Let $M$ be the $T \times T$ strictly upper triangular matrix of ones (i.e., $M_{x, y} = 1$ if $x < y$, and $0$ otherwise). For every row $i$, the bilinear form $A_{i, *} M B_{i, *}^T$ must be exactly equal to $p1_i \times p2_i$. (Here, $A_{i, *}$ and $B_{i, *}$ denote the $i$-th rows of $A$ and $B$, treated as $1 \times T$ row vectors).
2. **Diagonal Gramian A:** The matrix product $A A^T$ must be a diagonal matrix.
3. **Diagonal Gramian B:** The matrix product $B B^T$ must be a diagonal matrix.

For every provided test case, it is mathematically impossible to construct matrices $A$ and $B$ that satisfy all invariants. Furthermore, you are guaranteed that exactly one of the following foundational obstructions is the sole reason for the impossibility:

- **Local Projection Failure:** For some row $i$, there do not exist binary vectors $A_{i, *}$ and $B_{i, *}$ of the required weights that satisfy the Upper Triangular Projection invariant. Output `JOB i` (where $i$ is the 1-based index of the row).
- **Gramian A Exhaustion:** There is no way to construct the matrix $A$ with the required row weights such that $A A^T$ is diagonal. Output `LOAD 1`.
- **Gramian B Exhaustion:** There is no way to construct the matrix $B$ with the required row weights such that $B B^T$ is diagonal. Output `LOAD 2`.

Your task is to identify the bottleneck and output the applicable certificate.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required number of ones for the $i$-th row of $A$ and $B$ respectively (i.e., $p1_i$ and $p2_i$).

## Output

Print a single line: `JOB i` (for a local projection failure) or `LOAD c` (for a Gramian exhaustion, where **c** is 1 for Gramian A exhaustion or 2 for Gramian B exhaustion).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, row 1 requires $p1_1 = 70$ ones in $A$ and $p2_1 = 60$ ones in $B$. There is no way to place these ones in vectors of length $T = 100$ such that $A_{1, *} M B_{1, *}^T = 4200$. For this bilinear form to reach its theoretical maximum of $p1_1 \times p2_1$, all ones in $A_{1, *}$ must be positioned at strictly smaller indices than all ones in $B_{1, *}$. The available $100$ columns cannot accommodate this strict ordering for $130$ total non-zero entries. Thus `JOB 1` is the correct proof of impossibility. 

In Example 2, no single row violates the projection invariant. However, matrix $A$ requires four rows each with $50$ ones. To satisfy the Diagonal Gramian A invariant, the rows of $A$ must be orthogonal, meaning no two rows can share a 1 in the same column. It is impossible to place $4 \times 50$ ones into $150$ columns without overlap. This breaks the Gramian A invariant. Thus `LOAD 1` is the correct output.
