# Problem C — Impossible Allocation: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

An automotive factory operates an assembly line with exactly $T$ distinct, sequential workstations, numbered $1$ to $T$. There are $j$ product orders that need to be processed. For each order $i$, the factory must assign exactly $p1_i$ distinct workstations to apply the base coat, and exactly $p2_i$ distinct workstations to apply the finish coat.

The assignment of workstations must strictly follow three physical constraints:
1. **Process Flow:** For any given order, every workstation assigned to apply its base coat must appear strictly earlier on the assembly line than every workstation assigned to apply its finish coat.
2. **Base Station Limit:** Each workstation can be assigned to apply a base coat for at most one order in total. Thus, no two orders can share a workstation for their base coats.
3. **Finish Station Limit:** Each workstation can be assigned to apply a finish coat for at most one order in total. Thus, no two orders can share a workstation for their finish coats.

*(Note: The base coat and finish coat apparatuses are independent. A single workstation is capable of applying a base coat for one order and a finish coat for a different order simultaneously.)*

Every provided configuration is mathematically impossible to fulfill—there is no valid way to assign the workstations to satisfy all constraints. Instead of attempting to generate an assignment, your task is to identify the bottleneck that proves the configuration is unachievable, providing a short certificate.

Exactly one of the following foundational constraints is broken. Output the applicable certificate:

- **Flow Impossibility:** For some order $i$, there do not exist any two sets of workstations of the required sizes ($p1_i$ for base coats and $p2_i$ for finish coats) within the $T$-workstation line that satisfy the Process Flow constraint. Output `JOB i` (where $i$ is the 1-based index of the order).
- **Base Coat Bottleneck:** There is no way to assign the required base coat workstations for all $j$ orders such that the Base Station Limit is satisfied. Output `LOAD 1`.
- **Finish Coat Bottleneck:** There is no way to assign the required finish coat workstations for all $j$ orders such that the Finish Station Limit is satisfied. Output `LOAD 2`.

You are guaranteed that exactly one of these bottlenecks will be the source of failure for the given input.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required number of base coat workstations and finish coat workstations respectively for order $i$.

## Output

Print a single line: `JOB i` (for a flow impossibility) or `LOAD c` (for a bottleneck failure, where **c** is 1 for a base coat bottleneck or 2 for a finish coat bottleneck).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, order 1 requires 70 base coat workstations and 60 finish coat workstations. There is no way to select these from an assembly line of 100 workstations such that every base coat is applied at an earlier workstation than every finish coat, breaking the Process Flow constraint. Thus `JOB 1` is the correct proof of impossibility. 

In Example 2, no single order breaks the Process Flow constraint. However, the orders require 50 base coat workstations each. There is no way to assign these mutually exclusive base coat workstations (totaling 200) on an assembly line of 150 workstations, breaking the Base Station Limit. Thus `LOAD 1` is the correct output.
