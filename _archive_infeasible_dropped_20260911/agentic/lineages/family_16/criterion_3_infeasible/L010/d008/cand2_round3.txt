<STATEMENT>
# Problem C — Impossible Synthesis: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A laboratory is attempting to synthesize a complex structure on a linear polymer substrate. The substrate consists of $T$ discrete binding sites, sequentially indexed from $1$ to $T$. There are $j$ distinct target molecules. For each molecule $i$, the synthesis protocol requires forming exactly $p1_i$ alpha-bonds and exactly $p2_i$ beta-bonds with the substrate.

A valid synthesis configuration must satisfy three strict stereochemical rules:
1. **Structural Polarity:** For any single molecule $i$, there must exist a spatial division (a point between two adjacent binding sites) such that all of its alpha-bonds are located strictly to the left of the division, and all of its beta-bonds are located strictly to the right of the division.
2. **Alpha Exclusivity:** Each binding site on the substrate can host at most one alpha-bond (across all molecules).
3. **Beta Exclusivity:** Each binding site on the substrate can host at most one beta-bond (across all molecules).

*(Note: A single binding site may simultaneously host one alpha-bond for molecule A and one beta-bond for molecule B, provided the polarity rule is maintained for both molecules.)*

Every synthesis protocol provided in the input is mathematically impossible to achieve. Your task is not to attempt the synthesis, but to output a short certificate identifying the specific bottleneck that makes it impossible. 

Exactly one of the following foundational requirements is broken for each input. Output the corresponding certificate:

- **Polarity Impossibility:** For some molecule $i$, the substrate is simply too short to accommodate its required bonds while satisfying the Structural Polarity rule, even if it were the only molecule present. Output `JOB i` (where $i$ is the 1-based index of the molecule).
- **Alpha Saturation:** It is impossible to place all required alpha-bonds for all $j$ molecules without violating Alpha Exclusivity. Output `LOAD 1`.
- **Beta Saturation:** It is impossible to place all required beta-bonds for all $j$ molecules without violating Beta Exclusivity. Output `LOAD 2`.

You are guaranteed that exactly one of these bottlenecks applies to the given input.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required number of alpha-bonds and beta-bonds respectively for molecule $i$.

## Output

Print a single line containing the exact certificate string: `JOB i` (if polarity fails for molecule $i$), `LOAD 1` (for alpha saturation), or `LOAD 2` (for beta saturation).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, molecule 1 requires 70 alpha-bonds and 60 beta-bonds. There is no way to place these on a substrate of 100 sites such that a spatial partition strictly separates all alpha-bonds to the left and all beta-bonds to the right. Thus `JOB 1` is the correct impossibility certificate.

In Example 2, no individual molecule violates the polarity rule. However, the four molecules require a total of 200 alpha-bonds. There is no way to assign these distinct alpha-bonds to a substrate of only 150 sites, breaking the Alpha Exclusivity rule. Thus `LOAD 1` is the correct output.
</STATEMENT>
<RATIONALE>
The abstract subset separation constraint was translated into a physical "spatial division" requirement on a polymer substrate. This removes explicit algebraic hints (like supremum/infimum or strictly less than inequalities) that models use to shortcut to the `p1 + p2 > T` check, forcing them to geometrically deduce that separating $p1$ elements to the left and $p2$ elements to the right of a partition requires at least $p1 + p2$ distinct sites. The strict single-failure guarantee was preserved to maintain identical semantics.
</RATIONALE>
<PRESERVED_ANSWER>
The condition for Polarity Impossibility mathematically requires exactly $p1_i + p2_i > T$, and the Saturation conditions require $\sum p1_i > T$ and $\sum p2_i > T$, perfectly mirroring the seed's logic and outputting identical certificates.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains an $O(j)$ sequential feasibility check requiring only basic arithmetic to identify the bottleneck, keeping it squarely in the INFEASIBLE class.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the "spatial division" as occupying a binding site itself, but the explicit parenthetical "(a point between two adjacent binding sites)" eliminates this ambiguity.
</RISK>
