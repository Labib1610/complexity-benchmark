# Problem C — Impossible Allocation: The Dominant Bottleneck

Time limit: 2 s   Memory limit: 256 MB

## Description

A system attempts to allocate discrete elements from a linearly ordered universe $U = \{1, 2, \dots, T\}$. There are $j$ entities. For each entity $i$, the system must select two subsets of $U$: a subset $X_i$ containing exactly $p1_i$ elements, and a subset $Y_i$ containing exactly $p2_i$ elements.

A valid allocation must satisfy three structural axioms:
1. **Supremum-Infimum Separation:** For any single entity $i$, every element in $X_i$ must be strictly less than every element in $Y_i$.
2. **X-Orthogonality:** For any two distinct entities $i$ and $k$, the intersection of $X_i$ and $X_k$ is empty.
3. **Y-Orthogonality:** For any two distinct entities $i$ and $k$, the intersection of $Y_i$ and $Y_k$ is empty.

*(Note: An element $u \in U$ may simultaneously belong to $X_i$ and $Y_k$, provided this does not violate the separation axiom for their respective entities.)*

Every provided configuration is mathematically impossible to allocate within a universe of size $T$. To diagnose the failure, the system evaluates the **theoretical minimum universe size** needed to satisfy each axiom in isolation, ignoring the other two axioms:
- **Separation Size:** For each entity $i$, the minimum universe size required to select $X_i$ and $Y_i$ satisfying the Supremum-Infimum Separation axiom for that specific entity.
- **X-Domain Size:** The minimum universe size required to select subsets $X_1, \dots, X_j$ satisfying the X-Orthogonality axiom for all entities combined.
- **Y-Domain Size:** The minimum universe size required to select subsets $Y_1, \dots, Y_j$ satisfying the Y-Orthogonality axiom for all entities combined.

Your task is to identify the **Dominant Bottleneck**—the structural axiom that demands the strictly largest minimum universe size. You must output the certificate for this dominant bottleneck:
- If a specific entity's Separation Size is the strictly largest among all evaluated sizes (including other entities' Separation Sizes, the X-Domain Size, and the Y-Domain Size), output `JOB i`, where $i$ is the 1-based index of that entity.
- If the X-Domain Size is the strictly largest, output `LOAD 1`.
- If the Y-Domain Size is the strictly largest, output `LOAD 2`.

*(Note: You are guaranteed that there is a unique strict maximum among these required sizes for the given input.)*

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required number of elements for $X_i$ and $Y_i$ respectively.

## Output

Print a single line containing the certificate of the Dominant Bottleneck: `JOB i`, `LOAD 1`, or `LOAD 2`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, entity 1 requires a universe of at least 130 elements to satisfy its Separation axiom, which is strictly larger than the universe size required to satisfy global X-Orthogonality or global Y-Orthogonality. Thus, `JOB 1` is the dominant bottleneck. 

In Example 2, satisfying global X-Orthogonality requires a universe of at least 200 elements, which is strictly larger than the universe size required for Y-Orthogonality or for any single entity's Separation. Thus, `LOAD 1` is the dominant bottleneck.

<RATIONALE>
Removed the explicit guarantee that exactly one requirement fails against T, replacing it with a requirement to find the "Dominant Bottleneck" (the axiom demanding the largest minimum universe size). This removes the justification for the models' shortcut of checking `> T` in an arbitrary order and stopping early. Models must now deduce how to mathematically calculate the minimum sizes ($p1+p2$, $\sum p1$, $\sum p2$) and implement a maximum-finding comparison. 
</RATIONALE>
<PRESERVED_ANSWER>
Because the hidden test suite was built for the seed problem's guarantee that exactly one requirement exceeds T, exactly one of the required sizes will be > T while all others are <= T, meaning the maximum size will always perfectly correspond to the single broken requirement identified by the original logic.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires $O(N)$ linear scanning to compute the sums and pairwise sums, keeping it in the same complexity class.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "minimum universe size required to select X_1 ... X_j satisfying X-Orthogonality" as something other than the sum of sizes (e.g., the maximum single size), though the phrasing is mathematically standard for set disjointness.
</RISK>
