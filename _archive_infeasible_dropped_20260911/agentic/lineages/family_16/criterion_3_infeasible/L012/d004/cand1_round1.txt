<STATEMENT>
# Problem C — Impossible Window: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a constraint satisfaction problem involving $j$ discrete entities. For each entity $k$ ($1 \le k \le j$), you must assign two sets of integers, $S_{k,1}$ and $S_{k,2}$, chosen from the universal set $U = \{1, 2, \dots, T\}$.

A valid assignment must satisfy three rules:
1. **Cardinality**: For all $k$, $|S_{k,1}| = p_{k,1}$ and $|S_{k,2}| = p_{k,2}$.
2. **Strict Precedence**: For all $k$, every element in $S_{k,1}$ must be strictly less than every element in $S_{k,2}$.
3. **Mutual Exclusion**: For any two distinct entities $k$ and $m$, $S_{k,1} \cap S_{m,1} = \emptyset$ and $S_{k,2} \cap S_{m,2} = \emptyset$.

For every input, it is guaranteed that no valid assignment exists. Furthermore, exactly one of the following $j+2$ relaxed systems is already unsatisfiable on its own. Your task is to identify it and output its corresponding code:

- `JOB i` (where $i$ is an integer from $1$ to $j$): The system restricted to entity $i$ alone. Rule 3 is ignored. Rules 1 and 2 must hold.
- `LOAD c` (where $c$ is either $1$ or $2$): The system evaluating only domain $c$ across all entities. Rule 2 is ignored. Rule 1 is enforced strictly for domain $c$ ($|S_{k,c}| = p_{k,c}$ for all $k$). Rule 3 is enforced strictly for domain $c$ ($S_{k,c} \cap S_{m,c} = \emptyset$ for all $k \neq m$).

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_{k,1}$ and $p_{k,2}$ ($1 \le p_{k,1}, p_{k,2} \le 1000000$): the required cardinalities for entity $k$'s sets.

## Output

Print a single line containing either `JOB i` (if the relaxed system for entity $i$ is unsatisfiable) or `LOAD c` (if the relaxed system for domain $c$ is unsatisfiable).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, under the `JOB 1` relaxation, we need to choose sets $S_{1,1}$ and $S_{1,2}$ from $\{1, \dots, 100\}$ such that $|S_{1,1}| = 70$, $|S_{1,2}| = 60$, and every element in $S_{1,1}$ is strictly less than every element in $S_{1,2}$. There is no way to pick these elements from a universal set of size 100 to satisfy the strict precedence alongside the cardinality requirements. Thus, `JOB 1` is the unsatisfiable system.

In Example 2, no single entity violates the `JOB` relaxation. However, under the `LOAD 1` relaxation, we must choose mutually disjoint sets $S_{1,1}, S_{2,1}, S_{3,1}, S_{4,1}$ from $\{1, \dots, 150\}$, each of size 50. There are not enough elements in the universal set to accommodate these disjoint sets simultaneously. Thus, `LOAD 1` is the unsatisfiable system.
