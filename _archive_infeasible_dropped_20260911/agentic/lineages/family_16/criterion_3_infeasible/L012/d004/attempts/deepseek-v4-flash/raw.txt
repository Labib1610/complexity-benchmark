We can check each project individually: if `p1 + p2 > T`, then that project alone is impossible, so we output `JOB i`.  
If no such project exists, we check the total load on each unit: if the sum of all `p1` exceeds `T`, output `LOAD 1`; if the sum of all `p2` exceeds `T`, output `LOAD 2`.  

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    idx = 2
    total1 = 0
    total2 = 0
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        total1 += p1
        total2 += p2
    if total1 > T:
        print("LOAD 1")
    elif total2 > T:
        print("LOAD 2")

if __name__ == "__main__":
    main()
```
