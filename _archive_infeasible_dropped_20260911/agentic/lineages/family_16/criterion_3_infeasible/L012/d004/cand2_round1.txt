<STATEMENT>
# Problem C — Impossible Window: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are evaluating a layout process with $j$ components. Each component requires two contiguous segments to be reserved on a linear track: a primary segment of length $p_1$ and a secondary segment of length $p_2$. 

The track has a strict usable length of $T$ units, starting at position $0$ and ending at position $T$.

The placement of these segments must satisfy the following rules:
1. For any single component, its primary segment must be placed entirely to the left of its secondary segment (the coordinate of the rightmost edge of the primary segment must be less than or equal to the coordinate of the leftmost edge of the secondary segment).
2. The track has two independent layers: a primary layer and a secondary layer. All primary segments are placed on the primary layer, and all secondary segments on the secondary layer.
3. No two segments on the same layer may overlap. (A primary segment and a secondary segment can occupy the same horizontal track positions, as they are on different layers).

For every input, it is guaranteed that it is impossible to place all segments within the $T$-unit track. Furthermore, exactly one of the following two isolated conditions will serve as a proof of impossibility. Your task is to evaluate the components and output the code for the proof that applies:

- `JOB i` (where $i$ is the 1-based index of a component): Even if component $i$ were the only component being placed on the track, it would be impossible to place its primary and secondary segments within the $[0, T]$ bounds while respecting its left-to-right sequence requirement.
- `LOAD c` (where $c$ is 1 for the primary layer or 2 for the secondary layer): Even if we completely waive the left-to-right sequence requirement for all components, it would be impossible to pack all the components' segments for layer $c$ into the $[0, T]$ bounds without overlapping.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the lengths of the component's primary segment and secondary segment, respectively.

## Output

Print a single line containing either `JOB i` (if component $i$'s segments alone violate the track bounds) or `LOAD c` (if layer $c$'s segments alone violate the track bounds).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, if we place only the first component, its primary segment of length 70 must be placed to the left of its secondary segment of length 60. It is impossible to place both within the $[0, 100]$ interval without violating this sequence. Thus, `JOB 1` is a valid proof of impossibility. 

In Example 2, no single component is impossible to place on its own. However, if we examine the primary layer, we have four segments of length 50. Even without any left-to-right constraints, it is impossible to pack four non-overlapping segments of length 50 into the $[0, 150]$ interval. Thus, `LOAD 1` is the valid proof.
</STATEMENT>
<RATIONALE>
The explicit arithmetic reductions that allowed models to trivially check `p1 + p2 > T` and `sum(p) > T` were removed. By mapping the scheduling constraints to a geometric segment-packing scenario, the certificates are now defined purely in terms of geometric feasibility. Models must now logically deduce that satisfying the left-to-right sequence for a single pair of segments requires `p1 + p2 <= T`, and that packing all segments on a layer without overlapping requires the sum of their lengths to be `<= T`.
</RATIONALE>
<PRESERVED_ANSWER>
The geometric condition for a single component fitting with a left-to-right constraint is exactly `p1 + p2 <= T`, and the condition for packing non-overlapping segments on a layer is exactly `sum(p) <= T`, so the identical certificates will trigger on the identical inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires a single pass over the input array to check the component-wise sums and the two layer-wise sums, maintaining its $O(J)$ linear time complexity.
</PRESERVED_CLASS>
<RISK>
Models might overthink the phrasing "pack all the components' segments for layer $c$... without overlapping" and attempt to simulate a complex 1D bin packing algorithm, failing to realize that for contiguous contiguous segments on a single continuous track, feasibility is strictly equivalent to the sum of lengths not exceeding the track length.
</RISK>
