<STATEMENT>
# Spaceship Power Allocation Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

You are the chief engineer of a spaceship managing $j$ critical subsystems. Each subsystem requires two distinct energy bursts to reboot: a **Capacitor Charge** burst and a **System Initialization** burst. 

The reboot sequence is strictly governed by the following safety constraints:
1. **Precedence**: For any given subsystem, its System Initialization burst cannot begin until its Capacitor Charge burst has completely finished.
2. **Capacitor Grid Capacity**: The ship's capacitor grid can process at most one Capacitor Charge burst at any given moment.
3. **Initialization Grid Capacity**: The ship's initialization grid can process at most one System Initialization burst at any given moment.
4. **Time Limit**: All bursts across all subsystems must be fully completed within a strict operating window of $T$ milliseconds.

The ship's computer has determined that no valid sequence of operations can satisfy all four constraints simultaneously. To isolate the bottleneck, you must conduct three hypothetical scheduling experiments. The input data guarantees that exactly one of the three experiment types will yield a duration strictly greater than $T$. You must output the corresponding error code for the experiment that proves $T$ is impossible to meet:

- **Experiment Type 1 (Output `JOB i`)**: Isolate a single subsystem $i$ and schedule it on the grids while all other subsystems remain offline. All safety constraints (Precedence and Grid Capacities) apply normally. Calculate the earliest possible time this isolated subsystem can completely finish both of its bursts. If this completion time strictly exceeds $T$, output `JOB i` where $i$ is the 1-based index of the subsystem. If multiple subsystems exceed $T$ in isolation, outputting any such index $i$ is acceptable.
- **Experiment Type 2 (Output `LOAD 1`)**: Schedule all subsystems on both grids using a "deferred handover" protocol. Under this protocol, all original safety constraints remain fully in effect, but additionally, the Initialization Grid is temporarily locked and cannot begin processing ANY bursts until the Capacitor Grid has completely finished processing the Capacitor Charge bursts for all $j$ subsystems. Assuming bursts are scheduled as tightly as possible to minimize idle time, calculate the duration of the Capacitor Grid's operational phase—defined strictly as the time elapsed from the exact millisecond it begins its very first burst until the exact millisecond it finishes its final burst. If this operational phase duration strictly exceeds $T$, output `LOAD 1`.
- **Experiment Type 3 (Output `LOAD 2`)**: Schedule all subsystems using the exact same "deferred handover" protocol described in Experiment 2. Assuming bursts are scheduled as tightly as possible to minimize idle time, calculate the duration of the Initialization Grid's operational phase—defined strictly as the time elapsed from the exact millisecond it begins its very first burst until the exact millisecond it finishes its final burst. If this operational phase duration strictly exceeds $T$, output `LOAD 2`.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the duration in milliseconds for the subsystem's **Capacitor Charge** burst and its **System Initialization** burst, respectively.

## Output

Print a single line containing either `JOB i` (if Experiment Type 1 yields a duration $> T$ for subsystem $i$), `LOAD 1` (if Experiment Type 2 yields a duration $> T$), or `LOAD 2` (if Experiment Type 3 yields a duration $> T$).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, under Experiment Type 1 for subsystem 1, we isolate it from all other subsystems. It must complete its 70 ms Capacitor Charge followed immediately by its 60 ms System Initialization. The earliest possible time to complete both is 130 ms. Since 130 ms strictly exceeds the 100 ms Time Limit, `JOB 1` is a valid bottleneck proof.

In Example 2, no individual subsystem exceeds the 150 ms limit under Experiment Type 1 (each takes 51 ms). However, under Experiment Type 2's deferred handover protocol, the Capacitor Grid must process all four 50 ms bursts. Scheduled as tightly as possible, it runs continuously without forced idle time. Its operational phase duration is 200 ms. Since 200 ms strictly exceeds the 150 ms Time Limit, `LOAD 1` is the valid bottleneck proof.
