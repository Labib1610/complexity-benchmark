# Spaceship Power Allocation Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

You are the chief engineer of a spaceship managing $j$ critical subsystems. Each subsystem $i$ requires two distinct energy bursts to reboot: a **Capacitor Charge** burst of exact duration $p_{i,1}$ milliseconds, and a **System Initialization** burst of exact duration $p_{i,2}$ milliseconds.

A valid reboot sequence assigns each subsystem $i$ a Capacitor Charge time interval $C_i$ and an Initialization time interval $I_i$ such that:
1. The length of $C_i$ is exactly $p_{i,1}$.
2. The length of $I_i$ is exactly $p_{i,2}$.
3. For each subsystem $i$, all points in time in $C_i$ are strictly less than all points in time in $I_i$.
4. The intersection of $C_a$ and $C_b$ is empty for all $a \neq b$.
5. The intersection of $I_a$ and $I_b$ is empty for all $a \neq b$.
6. All intervals $C_i$ and $I_i$ (for $1 \le i \le j$) are subsets of the continuous time window $[0, T]$.

The ship's computer has determined that no valid assignment of intervals exists. You must isolate the fundamental bottleneck by outputting a specific error code. The input guarantees that exactly one of the following three logical contradictions can be demonstrated using only the given durations:

- **`JOB i`**: The required temporal span of $C_i \cup I_i$ for a single subsystem $i$, dictated by constraints 1, 2, and 3, strictly exceeds the size of the window $[0, T]$. If this is true for multiple subsystems, outputting `JOB i` for any such 1-based index $i$ is acceptable.
- **`LOAD 1`**: The required total measure of $\bigcup_{k=1}^j C_k$, dictated by constraints 1 and 4, strictly exceeds the measure of the continuous time window $[0, T]$.
- **`LOAD 2`**: The required total measure of $\bigcup_{k=1}^j I_k$, dictated by constraints 2 and 5, strictly exceeds the measure of the continuous time window $[0, T]$.

You do not need to construct an execution order; you only need to evaluate these three conditions and output the corresponding certificate.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_{i,1}$ and $p_{i,2}$ ($1 \le p_{i,1}, p_{i,2} \le 1000000$): the duration in milliseconds for subsystem $i$'s Capacitor Charge burst and its System Initialization burst, respectively.

## Output

Print a single line containing either `JOB i` (if the first condition holds for subsystem $i$), `LOAD 1` (if the second condition holds), or `LOAD 2` (if the third condition holds).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for subsystem 1, $C_1$ must have length 70 and $I_1$ must have length 60. Since all points in $C_1$ must strictly precede all points in $I_1$, the minimum temporal span from the start of $C_1$ to the end of $I_1$ is 130. Since $130 > 100$, the interval $[0, T]$ cannot contain them. `JOB 1` is the valid bottleneck proof.

In Example 2, no individual subsystem violates the temporal span limit. However, the intervals $C_1, C_2, C_3, C_4$ must be pairwise disjoint, and their lengths are 50 each. The measure of their union is 200. Since $200 > 150$, they cannot all be subsets of $[0, 150]$. `LOAD 1` is the valid bottleneck proof.
</STATEMENT>
<RATIONALE>
The previous framing used "hypothetical scheduling experiments" which LLMs mapped directly to the sums of machine workloads. This version replaces the operational scenario with a formal mathematical definition of the identical logic using interval constraints and Lebesgue measure. The model must now translate properties of disjoint sets and temporal spans back into the equivalent arithmetic checks (e.g. recognizing that the measure of disjoint sets is the sum of their measures) rather than relying on surface-level scheduling patterns.
</RATIONALE>
<PRESERVED_ANSWER>
The conditions exactly map to checking if $p_{i,1} + p_{i,2} > T$ for any job, $\sum p_{i,1} > T$, or $\sum p_{i,2} > T$, which are mathematically identical to the original impossibility certificates.
</PRESERVED_ANSWER>
