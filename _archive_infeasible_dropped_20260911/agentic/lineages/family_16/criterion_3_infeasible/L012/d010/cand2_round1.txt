# Spaceship Power Allocation Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

You are the chief engineer of a spaceship managing $j$ critical subsystems. Each subsystem requires two distinct energy bursts to reboot: a **Capacitor Charge** burst and a **System Initialization** burst. 

The reboot sequence is strictly governed by the following safety constraints:
1. **Precedence**: For any given subsystem, its System Initialization burst cannot begin until its Capacitor Charge burst has completely finished.
2. **Capacitor Grid Capacity**: The ship's capacitor grid can process at most one Capacitor Charge burst at any given moment.
3. **Initialization Grid Capacity**: The ship's initialization grid can process at most one System Initialization burst at any given moment.
4. **Time Limit**: All bursts across all subsystems must be fully completed within a strict operating window of $T$ milliseconds.

The ship's computer has determined that no valid sequence of operations can satisfy all four constraints simultaneously. To isolate the bottleneck, you must conduct three hypothetical scheduling experiments. The input data guarantees that exactly one of the three experiment types will yield a resulting completion time strictly greater than $T$. You must output the corresponding error code for the experiment that proves $T$ is impossible to meet:

- **Experiment Type 1 (Output `JOB i`)**: Remove the capacity limits of both grids (ignoring Constraints 2 and 3), allowing any number of bursts to run simultaneously. We wish to schedule the bursts to minimize the average completion time across all $j$ subsystems, while strictly respecting the precedence rule for each subsystem (Constraint 1). In this optimal schedule, determine the exact completion time for each subsystem $i$. If subsystem $i$'s completion time strictly exceeds $T$, output `JOB i` where $i$ is the 1-based index of the subsystem. If multiple subsystems exceed $T$ under this experiment, outputting any such index $i$ is acceptable.
- **Experiment Type 2 (Output `LOAD 1`)**: Set the duration of all System Initialization bursts to 0 milliseconds and remove the initialization grid's capacity limit (ignoring Constraint 3). The capacitor grid remains strictly serial (Constraint 2). We are allowed to process the Capacitor Charge bursts in any permutation, provided the permutation is *stable*—meaning no subsystem is processed more than 50 positions away from its original input index. Calculate the absolute minimum possible completion time for the entire batch of $j$ subsystems across all valid stable permutations. If this minimum completion time strictly exceeds $T$, output `LOAD 1`.
- **Experiment Type 3 (Output `LOAD 2`)**: Set the duration of all Capacitor Charge bursts to 0 milliseconds and remove the capacitor grid's capacity limit (ignoring Constraint 2). The initialization grid remains strictly serial (Constraint 3). We are allowed to process the System Initialization bursts in any permutation, provided the permutation is *harmonic*—meaning the sequence of 1-based indices contains at most 1000 inversions. Calculate the absolute minimum possible completion time for the entire batch of $j$ subsystems across all valid harmonic permutations. If this minimum completion time strictly exceeds $T$, output `LOAD 2`.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the duration in milliseconds for the subsystem's **Capacitor Charge** burst and its **System Initialization** burst, respectively.

## Output

Print a single line containing either `JOB i` (if Experiment Type 1 yields a completion time $> T$ for subsystem $i$), `LOAD 1` (if Experiment Type 2 yields a minimum time $> T$), or `LOAD 2` (if Experiment Type 3 yields a minimum time $> T$).


## Note

In Example 1, under Experiment Type 1, we ignore grid capacities. To minimize the average completion time, all subsystems start immediately at time 0. Subsystem 1 completes its 70 ms Capacitor Charge followed immediately by its 60 ms System Initialization, finishing at 130 ms. Since 130 ms strictly exceeds the 100 ms Time Limit, `JOB 1` is a valid bottleneck proof.

In Example 2, no individual subsystem exceeds the 150 ms limit under Experiment Type 1. However, under Experiment Type 2, we assume System Initialization bursts take 0 ms. We must process all four 50 ms Capacitor Charge bursts serially. Regardless of which stable permutation is chosen to minimize the completion time, the capacitor grid must run continuously for 200 ms. Since 200 ms strictly exceeds the 150 ms Time Limit, `LOAD 1` is the valid bottleneck proof.
