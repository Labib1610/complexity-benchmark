# Spaceship Power Allocation Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

You are the chief engineer of a spaceship managing $j$ critical subsystems. Each subsystem requires two distinct energy bursts to reboot: a **Capacitor Charge** burst and a **System Initialization** burst. 

The reboot sequence is governed by the following safety constraints:
1. **Precedence**: For any given subsystem, its System Initialization burst cannot begin until its Capacitor Charge burst has completely finished.
2. **Capacitor Grid Capacity**: The ship's capacitor grid can process at most one Capacitor Charge burst at any given moment.
3. **Initialization Grid Capacity**: The ship's initialization grid can process at most one System Initialization burst at any given moment.
4. **Time Limit**: All bursts across all subsystems must be fully completed within a strict operating window of $T$ milliseconds.

The ship's computer has determined that no valid sequence of operations can satisfy all four constraints simultaneously. To isolate the exact bottleneck, the diagnostic system defines three theoretical scheduling simulations. The input data guarantees that exactly one of these simulations will yield an optimal schedule whose minimum completion time strictly exceeds $T$. You must output the error code corresponding to the simulation that fails the time limit.

- **Simulation A**: The diagnostic system evaluates each subsystem in complete isolation, assuming it has exclusive access to both grids and does not wait for any other subsystem. If the minimum time to complete subsystem $i$ under these conditions strictly exceeds $T$, output `JOB i` (where $i$ is the 1-based index of the subsystem).
- **Simulation B**: The diagnostic system artificially sets the duration of every System Initialization burst to 0 milliseconds. The Capacitor Charge bursts retain their original durations and must still be processed sequentially on the Capacitor Grid. The system evaluates all possible orderings to find the optimal sequence that minimizes the total time required to fully process all subsystems. If the completion time of this optimal sequence strictly exceeds $T$, output `LOAD 1`.
- **Simulation C**: The diagnostic system artificially sets the duration of every Capacitor Charge burst to 0 milliseconds. The System Initialization bursts retain their original durations and must still be processed sequentially on the Initialization Grid. The system evaluates all possible orderings to find the optimal sequence that minimizes the total time required to fully process all subsystems. If the completion time of this optimal sequence strictly exceeds $T$, output `LOAD 2`.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the duration in milliseconds for the subsystem's **Capacitor Charge** burst and its **System Initialization** burst, respectively.

## Output

Print a single line containing either `JOB i` (if Simulation A fails for subsystem $i$), `LOAD 1` (if Simulation B fails), or `LOAD 2` (if Simulation C fails).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, under Simulation A, subsystem 1 must complete its 70 ms Capacitor Charge and its 60 ms System Initialization in sequence. The absolute minimum time to complete both is 130 ms, which strictly exceeds the 100 ms limit. This simulation fails, so the output is `JOB 1`.

In Example 2, no individual subsystem exceeds the 150 ms limit in Simulation A. However, in Simulation B, the System Initialization bursts take 0 ms, but the four 50 ms Capacitor Charge bursts must still be scheduled sequentially without overlapping. The minimum possible completion time for all subsystems in this simulation is 200 ms, which strictly exceeds the 150 ms limit. This simulation fails, so the output is `LOAD 1`.

<RATIONALE>
I changed the descriptions of the relaxed constraints from explicitly exposing the bounds to framing them as hypothetical scheduling simulations where the system must find the "optimal sequence". This forces the model to reason that when one phase takes 0 time, the makespan of any sequence is simply the sum of the remaining phase's durations, breaking simple pattern matching of aggregate bounds and forcing an actual understanding of the structure.
</RATIONALE>
<PRESERVED_ANSWER>
The minimum completion time of the optimal sequence in Simulation B (or C) is exactly the sum of the non-zero bursts, which is mathematically identical to the original LOAD conditions, ensuring all outputs remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires $O(N)$ time to check the three failure conditions (a single job's sum, or the sum of all phase 1s, or the sum of all phase 2s), keeping it in the INFEASIBLE certification class.
</PRESERVED_CLASS>
<RISK>
A model might doubt that all orderings have the identical completion time and attempt to write a complex scheduling algorithm (like Johnson's rule) which could time out or be implemented incorrectly, but this is exactly the intended structural deduction required.
</RISK>
