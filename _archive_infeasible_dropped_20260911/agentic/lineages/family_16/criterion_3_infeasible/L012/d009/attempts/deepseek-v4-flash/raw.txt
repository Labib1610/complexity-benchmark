We need to check three possible bottlenecks:

1. **JOB i**: For each subsystem, the minimum time to finish both bursts is simply \( p_1 + p_2 \) (charge must finish first, then init). If any `p1 + p2 > T`, output `JOB i` for that subsystem.

2. **LOAD 1**: Set `p2 = 0` for all jobs. Only capacitor charges are serial. Since all init times are zero, the total time = sum of all `p1`. If sum > T, output `LOAD 1`.

3. **LOAD 2**: Set `p1 = 0` for all jobs. Only init bursts are serial. Total time = sum of all `p2`. If sum > T, output `LOAD 2`.

The problem guarantees exactly one of these will be > T.

We need to read quickly and print the right code. Let's implement.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    j = int(data[0])
    T = int(data[1])
    
    sum_p1 = 0
    sum_p2 = 0
    idx = 2
    job_bottleneck = None
    
    for i in range(1, j + 1):
        p1 = int(data[idx]); p2 = int(data[idx+1])
        idx += 2
        sum_p1 += p1
        sum_p2 += p2
        if job_bottleneck is None and p1 + p2 > T:
            job_bottleneck = i
    
    if job_bottleneck is not None:
        sys.stdout.write(f"JOB {job_bottleneck}\n")
    elif sum_p1 > T:
        sys.stdout.write("LOAD 1\n")
    else:
        sys.stdout.write("LOAD 2\n")

if __name__ == "__main__":
    main()
```
