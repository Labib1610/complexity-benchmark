# Spaceship Power Allocation Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

You are the chief engineer of a spaceship managing $j$ critical subsystems. Each subsystem $i$ (for $1 \le i \le j$) requires two distinct energy bursts to reboot: a Capacitor Charge burst taking $p_{1,i}$ milliseconds, and a System Initialization burst taking $p_{2,i}$ milliseconds.

A full reboot execution is defined by two scheduling functions:
- $f: \{1, 2, \dots, j\} \to [0, \infty)$ assigning the exact start time of the Capacitor Charge burst for each subsystem.
- $g: \{1, 2, \dots, j\} \to [0, \infty)$ assigning the exact start time of the System Initialization burst for each subsystem.

The completion time of an execution is defined as $\max_{k=1}^j (g(k) + p_{2,k})$.

A valid execution must satisfy the following constraints:
1. **Precedence**: For all $k \in \{1 \dots j\}$, $g(k) \ge f(k) + p_{1,k}$.
2. **Capacitor Grid**: For any $k \ne m$, the intervals $[f(k), f(k) + p_{1,k})$ and $[f(m), f(m) + p_{1,m})$ do not intersect.
3. **Initialization Grid**: For any $k \ne m$, the intervals $[g(k), g(k) + p_{2,k})$ and $[g(m), g(m) + p_{2,m})$ do not intersect.
4. **Time Limit**: The completion time of the execution must be $\le T$.

The ship's computer has determined that no valid execution can satisfy all four constraints simultaneously. The input data guarantees that exactly one of the following relaxed hypothetical scenarios still has a minimum possible completion time strictly greater than $T$. You must isolate the exact bottleneck by outputting the corresponding error code:

- `JOB i` (where $i$ is a 1-based subsystem index): Consider a modified scenario where Constraints 2 and 3 are dropped. If the minimum possible completion time $\max_{k=1}^j (g(k) + p_{2,k})$ over all functions $f$ and $g$ satisfying Constraint 1 exceeds $T$, output `JOB i` for the specific subsystem $i$ that uniquely forces this violation.
- `LOAD 1`: Consider a modified scenario where $p_{2,k} = 0$ for all $k$, and Constraint 3 is dropped. If the minimum possible completion time $\max_{k=1}^j (g(k) + 0)$ over all functions $f$ and $g$ satisfying Constraints 1 and 2 exceeds $T$, output `LOAD 1`.
- `LOAD 2`: Consider a modified scenario where $p_{1,k} = 0$ for all $k$, and Constraint 2 is dropped. If the minimum possible completion time $\max_{k=1}^j (g(k) + p_{2,k})$ over all functions $f$ and $g$ satisfying Constraints 1 and 3 exceeds $T$, output `LOAD 2`.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_{1,i}$ and $p_{2,i}$ ($1 \le p_{1,i}, p_{2,i} \le 1000000$): the duration in milliseconds for the $i$-th subsystem's Capacitor Charge burst and its System Initialization burst, respectively.

## Output

Print a single line containing either `JOB i` (if the first scenario violates the time limit due to subsystem $i$), `LOAD 1` (if the second scenario violates the time limit), or `LOAD 2` (if the third scenario violates the time limit).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for the first scenario, the minimum possible completion time is 130 ms, which is dictated by subsystem 1. Since 130 > 100, `JOB 1` is the valid proof.
In Example 2, the first scenario yields a minimum completion time of 51 ms. However, in the second scenario (where $p_{2,k}=0$ and Constraint 3 is dropped), the non-intersecting requirement for the Capacitor Charge intervals forces the minimum possible completion time to be 200 ms. This violates the 150 ms limit, so `LOAD 1` is the valid proof.
