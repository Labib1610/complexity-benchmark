<METHOD_NAME>System of Inequalities Framing</METHOD_NAME>
<METHOD_DESCRIPTION>Translates the scheduling problem into a pure algebraic system of inequalities. By defining the relaxed systems as specific subsets of these inequalities, models are forced to mathematically derive the conditions for unsatisfiability (sum of pairs > T, or sum of components > T) rather than relying on scheduling heuristics.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem C — Impossible Window: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a system of constrained variables. For $j$ distinct elements (indexed $i = 1 \dots j$), there are four real-valued variables: $x_{i,1}, y_{i,1}, x_{i,2}, y_{i,2}$. 

A valid assignment of real numbers to these $4j$ variables must satisfy the following six families of conditions:
1. **Span 1**: For all $i$, $y_{i,1} - x_{i,1} = p_{i,1}$
2. **Span 2**: For all $i$, $y_{i,2} - x_{i,2} = p_{i,2}$
3. **Chain**: For all $i$, $y_{i,1} \le x_{i,2}$
4. **Boundary**: For all $i$, $0 \le x_{i,1}$ and $y_{i,2} \le T$
5. **Disjunction 1**: For all pairs $i \neq k$, either $y_{i,1} \le x_{k,1}$ or $y_{k,1} \le x_{i,1}$
6. **Disjunction 2**: For all pairs $i \neq k$, either $y_{i,2} \le x_{k,2}$ or $y_{k,2} \le x_{i,2}$

For every input, it is guaranteed that the full system of conditions has no valid assignment. Furthermore, exactly one of the following isolated subsystems is logically contradictory on its own, providing a certificate of impossibility:

- `JOB i` (where $i$ is the 1-based index of an element): The subsystem consisting only of **Span 1**, **Span 2**, **Chain**, and **Boundary** for that single specific element $i$ has no assignment.
- `LOAD 1`: The subsystem consisting only of **Span 1** (for all $j$ elements), **Disjunction 1**, and a modified boundary condition ($0 \le x_{i,1}$ and $y_{i,1} \le T$ for all $i$) has no assignment.
- `LOAD 2`: The subsystem consisting only of **Span 2** (for all $j$ elements), **Disjunction 2**, and a modified boundary condition ($0 \le x_{i,2}$ and $y_{i,2} \le T$ for all $i$) has no assignment.

Your task is to identify which certificate of impossibility applies and output its code.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_{i,1}$ and $p_{i,2}$ ($1 \le p_{i,1}, p_{i,2} \le 1000000$).

## Output

Print a single line containing either `JOB i` (if element $i$'s isolated subsystem is contradictory) or `LOAD c` (where $c \in \{1, 2\}$ depending on which Disjunction subsystem is contradictory).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, element 1 has $p_{1,1} = 70$ and $p_{1,2} = 60$. Its `JOB 1` subsystem requires satisfying the Span 1, Span 2, Chain, and Boundary conditions algebraically. By substitution, these inequalities force $y_{1,2} \ge 130$, which contradicts the Boundary condition $y_{1,2} \le 100$. Thus, `JOB 1` is the valid certificate.

In Example 2, no single element's `JOB` subsystem is contradictory. However, the `LOAD 1` subsystem requires assigning variables for four elements, each requiring a Span 1 difference of 50, such that they satisfy the Disjunction 1 inequalities within the boundaries 0 and 150. This algebraically requires a total boundary difference of at least 200, which contradicts the maximum available difference of 150. Thus, `LOAD 1` is the valid certificate.
</STATEMENT>
<RATIONALE>
Transformed the scheduling scenario into a pure algebraic system of inequalities. This removes all semantic clues ("jobs", "intervals", "overlap") and forces the model to mathematically deduce that the Chain and Boundary conditions imply $p_1 + p_2 > T$, while the Disjunction conditions imply $\sum p > T$.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic conditions for unsatisfiability of the isolated subsystems exactly match the original problem's conditions: $p_{i,1} + p_{i,2} > T$ for `JOB i`, and $\sum p_{i,c} > T$ for `LOAD c`.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The required checks remain a single $O(N)$ pass to find the maximum sequential sum and the two total sums, keeping the problem in the same complexity class.
</PRESERVED_CLASS>
<RISK>
Models might attempt to use an SMT solver or simulate the inequalities directly due to the algebraic framing, leading to Time Limit Exceeded, but the mathematical definitions are completely unambiguous.
</RISK>
