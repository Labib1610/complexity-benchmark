<METHOD_NAME>System_of_Inequalities_Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the scheduling formulation (intervals, non-overlapping, precedence) with a purely algebraic system of inequalities over real numbers. The certificates are defined as the logical unsatisfiability of specific subsystems. The "sum > T" condition is mathematically mapped to a condition on the maximum span of coordinates being greater than the sum of parameters, which is mathematically identical but algebraically obscures the simple sum check. This prevents models from pattern-matching the standard scheduling load check and forces them to deduce the unsatisfiability conditions from the inequalities.
</METHOD_DESCRIPTION>

<STATEMENT>
# Problem C — Impossible Window: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of $j$ components. For each component $i \in \{1 \dots j\}$, you are given two parameters, denoted $p_{1,i}$ and $p_{2,i}$ (given as $p_1$ and $p_2$ in the input). 

You are tasked with assigning real-valued coordinates $x_i$ and $y_i$ to each component in order to satisfy the following four conditions simultaneously:

1. **Internal**: $y_i - x_i \ge p_{1,i}$ for all $i \in \{1 \dots j\}$.
2. **Span X**: There exist (not necessarily distinct) indices $u, v \in \{1 \dots j\}$ such that $(x_u + p_{1,u}) - x_v \ge \sum_{k=1}^j p_{1,k}$.
3. **Span Y**: There exist (not necessarily distinct) indices $u, v \in \{1 \dots j\}$ such that $(y_u + p_{2,u}) - y_v \ge \sum_{k=1}^j p_{2,k}$.
4. **Boundaries**: $x_i \ge 0$ and $y_i + p_{2,i} \le T$ for all $i \in \{1 \dots j\}$.

For every valid input, it is guaranteed that the full system of conditions is impossible to satisfy. Furthermore, **exactly one** of the following three isolated subsystems has no valid assignment of its respective variables over the real numbers. Your task is to identify which subsystem is unsatisfiable and output its corresponding code:

- `JOB i` (where $i$ is a 1-based index): The subsystem consisting solely of **Internal** for component $i$, and **Boundaries** for component $i$. (This subsystem only restricts $x_i$ and $y_i$).
- `LOAD 1`: The subsystem consisting solely of **Span X**, and the relaxed boundaries $x_i \ge 0$ and $x_i + p_{1,i} \le T$ for all $i \in \{1 \dots j\}$. (This subsystem only restricts $x_1 \dots x_j$).
- `LOAD 2`: The subsystem consisting solely of **Span Y**, and the relaxed boundaries $y_i \ge 0$ and $y_i + p_{2,i} \le T$ for all $i \in \{1 \dots j\}$. (This subsystem only restricts $y_1 \dots y_j$).

Exactly one listed reason applies for every test input; output that one.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the parameters $p_{1,i}$ and $p_{2,i}$ for the $i$-th component.

## Output

Print a single line containing either `JOB i` (if component $i$'s isolated subsystem is unsatisfiable), `LOAD 1` (if the Span X subsystem is unsatisfiable), or `LOAD 2` (if the Span Y subsystem is unsatisfiable).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for component 1, the **Internal** condition requires $y_1 - x_1 \ge 70$, and the **Boundaries** condition requires $x_1 \ge 0$ and $y_1 + 60 \le 100$. This implies $100 \ge y_1 + 60 \ge x_1 + 70 + 60 \ge 130$, which is impossible. Thus, the subsystem for `JOB 1` is unsatisfiable.

In Example 2, the **Span X** condition requires finding $u, v$ such that $(x_u + 50) - x_v \ge 200$. The relaxed boundaries for `LOAD 1` require $x_i \ge 0$ and $x_i + 50 \le 150$ for all $i$. This implies $x_u + 50 \le 150$ and $x_v \ge 0$, so $(x_u + 50) - x_v$ can be at most 150. Satisfying the requirement of $\ge 200$ is impossible, making `LOAD 1` the valid proof.
</STATEMENT>
<RATIONALE>
I reformulated the constraints into a pure algebraic system of inequalities, replacing the "non-overlapping" scheduling concept with a mathematically equivalent "max span" condition (Span X and Span Y). This forces the model to algebraically deduce that the Span X subsystem is unsatisfiable if and only if the sum of $p_{1,k}$ exceeds $T$, preventing the shortcut of pattern-matching the standard load check without understanding the underlying math.
</RATIONALE>
<PRESERVED_ANSWER>
The subsystem for `JOB i` is unsatisfiable iff $p_{1,i} + p_{2,i} > T$, and the subsystems for `LOAD 1` and `LOAD 2` are unsatisfiable iff $\sum p_{1,i} > T$ and $\sum p_{2,i} > T$ respectively, perfectly matching the original certificates.
</PRESERVED_ANSWER>
