<METHOD_DESCRIPTION>
Replaces the verbal scheduling rules with a formal system of inequalities. The certificates are defined as specific subsets of these inequalities that cannot be satisfied simultaneously. This forces the model to deduce the sum and single-job bounds from the algebraic properties of non-overlapping intervals, breaking semantic pattern matching on terms like "capacity" or "workload", and circumventing unconditional fallback shortcuts by requiring explicit evaluation of the mathematical conditions.
</METHOD_DESCRIPTION>

<STATEMENT>
# Problem C — Impossible Window: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a formal constraint system. For $j$ items, you must assign two real-valued variables, $u_i$ and $v_i$ (for $i = 1 \dots j$). 
Each item $i$ has two associated positive constants, $p_{1,i}$ and $p_{2,i}$.

A valid assignment must satisfy the following system of inequalities:
1. **Lower Bound**: $u_i \ge 0$ for all $i$.
2. **Sequence**: $u_i + p_{1,i} \le v_i$ for all $i$.
3. **Upper Bound**: $v_i + p_{2,i} \le T$ for all $i$.
4. **Separation 1**: For every pair of distinct items $i$ and $k$, either $u_i + p_{1,i} \le u_k$ or $u_k + p_{1,k} \le u_i$.
5. **Separation 2**: For every pair of distinct items $i$ and $k$, either $v_i + p_{2,i} \le v_k$ or $v_k + p_{2,k} \le v_i$.

For every input provided, it is guaranteed that no valid assignment exists because the parameter $T$ is too small. Your task is to output a certificate identifying a specific contradictory subset of conditions. 

The input guarantees that at least one of the following three types of subsets cannot be satisfied simultaneously. If multiple valid certificates apply, printing any one is acceptable:

- `JOB i` : The set of conditions consisting only of rules **1**, **2**, and **3** for a specific item $i$ cannot be satisfied simultaneously.
- `LOAD 1` : The set of conditions consisting only of rule **1**, rule **4**, and the requirement $u_i + p_{1,i} \le T$ for all items $i$, cannot be satisfied simultaneously.
- `LOAD 2` : The set of conditions consisting only of the requirement $v_i \ge 0$, rule **5**, and rule **3** for all items $i$, cannot be satisfied simultaneously.

Output the corresponding string (`JOB i` where $i$ is the 1-based index, `LOAD 1`, or `LOAD 2`).

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_{1,i}$ and $p_{2,i}$ ($1 \le p_{1,i}, p_{2,i} \le 1000000$): the constants for item $i$.

## Output

Print a single line containing either `JOB i` (where $i$ is the 1-based index of the item), `LOAD 1`, or `LOAD 2`, corresponding to a valid certificate.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for item 1, the constants are $p_{1,1} = 70$ and $p_{2,1} = 60$. The set of conditions for `JOB 1` requires $u_1 \ge 0$, $u_1 + 70 \le v_1$, and $v_1 + 60 \le 100$. This implies $0 + 70 + 60 \le 100$, which is $130 \le 100$. This is a contradiction, so `JOB 1` is a valid certificate.

In Example 2, the `LOAD 1` conditions require finding four values $u_1, u_2, u_3, u_4 \ge 0$ such that all $u_i + 50 \le 150$, and for any pair, the intervals $[u_i, u_i+50]$ do not overlap. This requires packing four non-overlapping intervals of length 50 into a domain of length 150. This requires at least $4 \times 50 = 200$ total length, which exceeds 150. This is a contradiction, making `LOAD 1` a valid certificate.
</STATEMENT>
<RATIONALE>
I changed the scheduling problem into a formal system of inequalities, defining the bottlenecks as subsets of these conditions that cannot be satisfied simultaneously. This forces the model to mathematically deduce that the separation constraints represent 1D packing, requiring it to compute the sum of intervals rather than relying on semantic pattern-matching of "capacity" or "workload".
</RATIONALE>
<PRESERVED_ANSWER>
The unsatisfiability of the defined inequality subsets is mathematically identical to the original scheduling bottlenecks ($p_{1,i} + p_{2,i} > T$, $\sum p_{1,i} > T$, and $\sum p_{2,i} > T$), ensuring identical outputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The algorithm remains an $O(j)$ check of individual sums and pairs, preserving the infeasible class.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "cannot be satisfied simultaneously" as referring to the entire system rather than the isolated subset, though the phrase "consisting only of" makes this explicit.
</RISK>
