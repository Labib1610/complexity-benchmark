# Problem C — Impossible Window: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a mathematical system of $j$ pairs of closed intervals $(A_i, B_i)$ on the real number line. For each $i \in \{1, \dots, j\}$, the interval $A_i$ must have a length of exactly $p_1$, and the interval $B_i$ must have a length of exactly $p_2$.

A valid configuration of these $2j$ intervals must satisfy four conditions:
1. **Domain**: For all $i$, $A_i \subset [0, T]$ and $B_i \subset [0, T]$.
2. **Order**: For each $i$, and for any real numbers $a \in A_i$ and $b \in B_i$, it must hold that $a \le b$.
3. **Separation A**: For any $i \ne k$, the intersection of the interiors of $A_i$ and $A_k$ must be empty.
4. **Separation B**: For any $i \ne k$, the intersection of the interiors of $B_i$ and $B_k$ must be empty.

It is guaranteed that no valid configuration exists for the given inputs. Furthermore, exactly one of the following isolated logical constraints will act as a minimal proof of impossibility. Your task is to output the code for the proof that applies:

- `JOB i` (where $i$ is the 1-based index): This proof applies if the subsystem consisting solely of **Domain** for $A_i$ and $B_i$, and **Order** for $A_i$ and $B_i$, is logically impossible to satisfy on its own.
- `LOAD 1`: This proof applies if the subsystem consisting solely of **Domain** for all $A$ intervals and **Separation A** for all $A$ intervals is logically impossible to satisfy on its own.
- `LOAD 2`: This proof applies if the subsystem consisting solely of **Domain** for all $B$ intervals and **Separation B** for all $B$ intervals is logically impossible to satisfy on its own.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the required lengths of the intervals $A_i$ and $B_i$, respectively.

## Output

Print a single line containing either `JOB i` (if the isolated constraints for index $i$ alone are unsatisfiable), `LOAD 1` (if the isolated constraints for the $A$ intervals alone are unsatisfiable), or `LOAD 2` (if the isolated constraints for the $B$ intervals alone are unsatisfiable).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for $i=1$, interval $A_1$ requires a length of 70 and $B_1$ requires a length of 60. The isolated subset of constraints for $i=1$ requires placing these two intervals into $[0, 100]$ such that all points in $A_1$ are less than or equal to all points in $B_1$. This requires a total span of at least 130, which is logically impossible. Thus, `JOB 1` is the valid proof.

In Example 2, no individual index $i$ has impossible constraints on its own. However, the constraints for the $A$ intervals require packing four intervals of length 50 (total length 200) into the domain $[0, 150]$ such that their interiors do not intersect. This is logically impossible, making `LOAD 1` the valid proof.
