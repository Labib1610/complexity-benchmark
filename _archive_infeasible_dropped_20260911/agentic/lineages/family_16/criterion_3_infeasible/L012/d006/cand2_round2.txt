# Spaceship Power Allocation Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

You are the chief engineer of a spaceship managing $j$ critical subsystems. Each subsystem requires a two-stage reboot sequence: a **Phase 1** diagnostic burst followed by a **Phase 2** diagnostic burst.

The reboot sequence is subject to the following physical constraints:
1. **Precedence**: For any given subsystem, its Phase 2 burst cannot start until its Phase 1 burst has fully completed.
2. **Phase 1 Grid**: The ship's primary grid can only process one subsystem's Phase 1 burst at a time.
3. **Phase 2 Grid**: The ship's secondary grid can only process one subsystem's Phase 2 burst at a time.
4. **Time Limit**: The entire sequence for all $j$ subsystems must be fully completed within a strict operating window of exactly $T$ milliseconds.

The ship's computer has determined that completing the reboot within $T$ milliseconds is impossible. Any valid schedule's total completion time is bounded below by several theoretical minimums. The computer guarantees that exactly one of the following theoretical minimum completion times strictly exceeds $T$, which serves as the certificate of failure:

- `JOB i` (where $i$ is the 1-based index of a subsystem): The minimum time required to process subsystem $i$ alone, given that its two bursts must run sequentially.
- `LOAD 1`: The minimum time required by the Phase 1 grid to process all $j$ of its assigned bursts, given that they cannot overlap.
- `LOAD 2`: The minimum time required by the Phase 2 grid to process all $j$ of its assigned bursts, given that they cannot overlap.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the duration in milliseconds for the subsystem's **Phase 1** burst and its **Phase 2** burst, respectively.

## Output

Print a single line containing the exact certificate of failure: `JOB i` (if subsystem $i$'s theoretical minimum completion time strictly exceeds $T$), `LOAD 1` (if the Phase 1 grid's theoretical minimum completion time strictly exceeds $T$), or `LOAD 2` (if the Phase 2 grid's theoretical minimum completion time strictly exceeds $T$).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, the first subsystem requires 70 milliseconds for its Phase 1 burst and then 60 milliseconds for its Phase 2 burst. Since these must run sequentially, the minimum time to process subsystem 1 alone is 130 milliseconds. This strictly exceeds the 100-millisecond window, making `JOB 1` the valid certificate.

In Example 2, no single subsystem's sequential requirement exceeds 150 milliseconds. However, the Phase 1 grid must process four bursts of 50 milliseconds each. Since they cannot overlap, the minimum time required by the Phase 1 grid is 200 milliseconds. This strictly exceeds the 150-millisecond window, making `LOAD 1` the valid certificate.

<RATIONALE>
The problem was completely reverted to the original scheduling narrative to fix the boundary and semantic ambiguities introduced by the previous interval-allocation abstraction. To maintain difficulty, the text now frames the failure conditions as "theoretical minimum completion times" rather than "logically unsatisfiable relaxed systems." This forces the model to deduce that the minimum time for non-overlapping tasks on a single grid is their sum, and the minimum time for sequential tasks for one job is their sum, without explicitly providing the arithmetic formulas.
</RATIONALE>
<PRESERVED_ANSWER>
The conditions for printing `JOB i`, `LOAD 1`, and `LOAD 2` map exactly to $p1_i + p2_i > T$, $\sum p1_i > T$, and $\sum p2_i > T$, which are mathematically identical to the seed's isolated satisfiability checks.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class remains INFEASIBLE (O(N) impossibility certification) because it still requires checking a set of independent bounds (one per job and two aggregates) in a single pass.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "minimum time required by the Phase 1 grid" as the maximum single burst duration rather than the sum of all bursts, though "process all $j$ of its assigned bursts, given that they cannot overlap" heavily implies a sum.
</RISK>
