We can check each subsystem’s charge time and also the total charge time for all subsystems.  
If any single subsystem exceeds the limit, we output `JOB i`.  
Otherwise, if the sum of all charge times exceeds the limit, we output `LOAD 1`.  
Otherwise, we output `LOAD 2`.  

```python
n, T = map(int, input().split())
total = 0
for i in range(1, n + 1):
    a, b = map(int, input().split())
    if a > T:
        print(f"JOB {i}")
        exit()
    total += a

if total > T:
    print("LOAD 1")
else:
    print("LOAD 2")
```
