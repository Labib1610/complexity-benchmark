<STATEMENT>
# Algebraic Subsystem Unsatisfiability

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of algebraic constraints over $2j$ real variables: $x_1, x_2, \dots, x_j$ and $y_1, y_2, \dots, y_j$.
You are given a constant $T$ and $j$ pairs of constants $(p_{1, i}, p_{2, i})$.

The full system $\mathcal{S}$ consists of the following four families of constraints:
1. **Bounding**: For all $i \in \{1, \dots, j\}$, $x_i \ge 0$ and $y_i + p_{2, i} \le T$.
2. **Linking**: For all $i \in \{1, \dots, j\}$, $x_i + p_{1, i} \le y_i$.
3. **Separation X**: For all pairs of distinct indices $i, k \in \{1, \dots, j\}$, $(x_i + p_{1, i} \le x_k) \lor (x_k + p_{1, k} \le x_i)$.
4. **Separation Y**: For all pairs of distinct indices $i, k \in \{1, \dots, j\}$, $(y_i + p_{2, i} \le y_k) \lor (y_k + p_{2, k} \le y_i)$.

It is guaranteed that $\mathcal{S}$ has no valid assignment over the real numbers. Furthermore, it is guaranteed that exactly one of the following three cases applies, yielding a unique minimal certificate of unsatisfiability:

- **Case 1**: There is exactly one index $i \in \{1, \dots, j\}$ for which the subsystem containing only the **Bounding** constraints for $i$ and the **Linking** constraint for $i$ is unsatisfiable. The certificate is `JOB i` (where `i` is the actual 1-based integer index).
- **Case 2**: The subsystem containing only the constraints $x_i \ge 0$ and $x_i + p_{1, i} \le T$ for all $i \in \{1, \dots, j\}$, along with all **Separation X** constraints, is unsatisfiable. The certificate is `LOAD 1`.
- **Case 3**: The subsystem containing only the constraints $y_i \ge 0$ and $y_i + p_{2, i} \le T$ for all $i \in \{1, \dots, j\}$, along with all **Separation Y** constraints, is unsatisfiable. The certificate is `LOAD 2`.

Your task is to output the valid certificate.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_{1, i}$ and $p_{2, i}$ ($1 \le p_{1, i}, p_{2, i} \le 1000000$).

## Output

Print a single line containing the exact certificate of unsatisfiability (`JOB i`, `LOAD 1`, or `LOAD 2`).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, the restricted subsystem for $i=1$ consists of the constraints $x_1 \ge 0$, $y_1 + 60 \le 100$, and $x_1 + 70 \le y_1$. Substituting the inequalities yields $x_1 + 130 \le 100$, which implies $x_1 \le -30$. This contradicts $x_1 \ge 0$, making this subsystem logically unsatisfiable over the reals, and thus `JOB 1` is the certificate.

In Example 2, the isolated variables for any $i$ are satisfiable (e.g., $x_1 = 0, y_1 = 50$ satisfies the constraints for $i=1$). However, Case 2 requires finding four real numbers $x_1, x_2, x_3, x_4 \ge 0$ such that $x_i + 50 \le 150$ for all $i$, and for any distinct pair $i, k$, either $x_i + 50 \le x_k$ or $x_k + 50 \le x_i$. It is mathematically impossible to satisfy these conditions simultaneously, making `LOAD 1` the valid certificate.
</STATEMENT>
<RATIONALE>
The problem was completely abstracted from an operational scheduling scenario into a pure formal system of algebraic inequalities and logical disjunctions. To succeed, the model must now deduce the theorem that a set of bounded variables subject to pairwise separation constraints is unsatisfiable if and only if the sum of the separation constants exceeds the bounding interval, stripping away all geometric and semantic cues (like "intervals" or "durations") that previously trivialized the reasoning.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic conditions for unsatisfiability perfectly map to the original problem: the bounding and linking constraints for $i$ are unsatisfiable iff $p_{1,i} + p_{2,i} > T$, and the separation constraints within bounds are unsatisfiable iff the sum of the constants exceeds $T$, preserving all original logic.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains in the same complexity class ($O(N)$) because it still only requires checking if $p_{1,i} + p_{2,i} > T$, $\sum p_{1,i} > T$, or $\sum p_{2,i} > T$, just framed through an algebraic isomorphism.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the disjunctions ($\lor$) as requiring an SMT solver or backtracking, leading them to write $O(N!)$ code that TLEs, but the problem statement itself is mathematically unambiguous.
