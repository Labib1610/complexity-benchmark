<STATEMENT>
# Set Assignment Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

You are studying a mathematical system on the domain $D = [0, T]$. There are $j$ elements, numbered 1 to $j$. For each element $i$, you must assign two sets of real numbers, $A_i$ and $B_i$. Each set must be constructed as a finite union of intervals. Let $||S||$ denote the total length of the intervals comprising a set $S$.

A valid assignment must satisfy the following five rules:
1. **Domain**: For all $1 \le i \le j$, $A_i \subseteq D$ and $B_i \subseteq D$.
2. **Quota**: For all $1 \le i \le j$, $||A_i|| \ge u_i$ and $||B_i|| \ge v_i$, where $u_i$ and $v_i$ are given constants.
3. **Separation**: For all $1 \le i \le j$, every real number in $A_i$ must be less than or equal to every real number in $B_i$.
4. **A-Exclusivity**: For any $x \neq y$, the intersection $A_x \cap A_y$ must have a total length of zero (i.e. they may only overlap at interval endpoints).
5. **B-Exclusivity**: For any $x \neq y$, the intersection $B_x \cap B_y$ must have a total length of zero.

It is given that no assignment can satisfy all five rules simultaneously for the given parameters. The impossibility is caused by a bottleneck that can be isolated. Exactly one of the following error codes correctly identifies an unsatisfiable relaxed system:

- `JOB i` (where $i$ is the 1-based index of an element): This code applies if the relaxed system consisting solely of **Domain**, **Quota**, and **Separation** for element $i$'s sets ($A_i$ and $B_i$) is logically unsatisfiable on its own.
- `LOAD 1`: This code applies if the relaxed system consisting solely of **Domain**, **Quota**, and **A-Exclusivity** for all $j$ of the $A$ sets ($A_1, \dots, A_j$) is logically unsatisfiable on its own.
- `LOAD 2`: This code applies if the relaxed system consisting solely of **Domain**, **Quota**, and **B-Exclusivity** for all $j$ of the $B$ sets ($B_1, \dots, B_j$) is logically unsatisfiable on its own.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $u_i$ and $v_i$ ($1 \le u_i, v_i \le 1000000$): the required minimum lengths for $A_i$ and $B_i$, respectively.

## Output

Print a single line containing either `JOB i` (if element $i$'s constraint subset alone is unsatisfiable), `LOAD 1` (if the A-Exclusivity constraint subset alone is unsatisfiable), or `LOAD 2` (if the B-Exclusivity constraint subset alone is unsatisfiable).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, element 1 requires $||A_1|| \ge 70$ and $||B_1|| \ge 60$. The subset of constraints for element 1 requires finding two sets in $[0, 100]$ such that every point in $A_1$ is $\le$ every point in $B_1$. This implies that the sum of their lengths cannot exceed 100, which makes $70 + 60 \le 100$ logically unsatisfiable. This makes `JOB 1` a valid proof of impossibility. 

In Example 2, no individual element's isolated constraints are unsatisfiable. However, the A-Exclusivity rule requires assigning four sets $A_1, \dots, A_4$, each of length at least 50, such that their pairwise intersections have length zero. Packing these into the domain $[0, 150]$ requires a total length of 200, which is logically unsatisfiable, making `LOAD 1` the valid proof.
