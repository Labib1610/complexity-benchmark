<STATEMENT>
# Subspace Measure Certificates

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a 1-dimensional topological manifold parameterized by a coordinate $t \in [0, T]$. You are given $j$ distinct topological features to embed into this manifold. Each feature $i$ consists of a primary domain and a secondary domain.

An embedding is valid if it satisfies the following geometric constraints:
1. **Primary Separation**: The primary domains of any two distinct features must not overlap (their intersection may at most contain boundary points).
2. **Secondary Separation**: The secondary domains of any two distinct features must not overlap (their intersection may at most contain boundary points).
3. **Domain Precedence**: For any given feature $i$, the minimum coordinate of its secondary domain must be greater than or equal to the maximum coordinate of its primary domain.
4. **Manifold Boundary**: All primary and secondary domains must be contiguous intervals entirely contained within the manifold $[0, T]$.
5. **Measure Requirement**: For each feature $i$, the Lebesgue measure (length) of its primary domain must be exactly $p_1$, and the Lebesgue measure of its secondary domain must be exactly $p_2$.

The automated prover has determined that the manifold boundary $T$ is insufficient to embed all features simultaneously. Exactly one of the following error codes will correctly explain the bottleneck:

- `JOB i` (where $i$ is the 1-based index of a feature): This code applies if the relaxed system consisting solely of **Domain Precedence**, **Manifold Boundary**, and **Measure Requirement** for feature $i$'s two domains is logically unsatisfiable on its own.
- `LOAD 1`: This code applies if the relaxed system consisting solely of **Primary Separation**, **Manifold Boundary**, and **Measure Requirement** for all $j$ primary domains is logically unsatisfiable on its own.
- `LOAD 2`: This code applies if the relaxed system consisting solely of **Secondary Separation**, **Manifold Boundary**, and **Measure Requirement** for all $j$ secondary domains is logically unsatisfiable on its own.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the required Lebesgue measures for the feature's primary and secondary domains, respectively.

## Output

Print a single line containing either `JOB i` (if feature $i$'s isolated constraint subset is unsatisfiable), `LOAD 1` (if the Primary Separation constraint subset alone is unsatisfiable), or `LOAD 2` (if the Secondary Separation constraint subset alone is unsatisfiable).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, the first feature requires a primary domain of measure 70 and a secondary domain of measure 60. The subset of constraints for feature 1 requires mapping a contiguous interval of length 70 and a subsequent contiguous interval of length 60 into the manifold $[0, 100]$, which is logically unsatisfiable. This makes `JOB 1` a valid proof of impossibility. 

In Example 2, no individual feature's isolated constraints are unsatisfiable. However, the Primary Separation rule is assigned four domains of measure 50 each. The subset of constraints for the primary domains requires packing four non-overlapping contiguous intervals of length 50 into the manifold $[0, 150]$, which is logically unsatisfiable, making `LOAD 1` the valid proof.
