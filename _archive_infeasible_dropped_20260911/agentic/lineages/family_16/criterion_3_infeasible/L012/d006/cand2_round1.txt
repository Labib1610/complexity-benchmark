<STATEMENT>
# Interval Allocation Contradiction

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a one-dimensional allocation model over the domain $D = [0, T]$.
There are $j$ entities. Each entity $i$ (for $1 \le i \le j$) requires two allocations, which must be formed as continuous intervals of real numbers, denoted $A_i$ and $B_i$.
The length of interval $A_i$ must be exactly $p_1$, and the length of interval $B_i$ must be exactly $p_2$.

A complete valid allocation must satisfy four rules:
1. **Domain**: $A_i \subset D$ and $B_i \subset D$ for all $i$.
2. **Sequence**: For each entity $i$, every value in $B_i$ must be strictly greater than every value in $A_i$.
3. **Collision A**: For any two distinct entities $u$ and $v$, the interior of $A_u$ and the interior of $A_v$ must not intersect.
4. **Collision B**: For any two distinct entities $u$ and $v$, the interior of $B_u$ and the interior of $B_v$ must not intersect.

The parameters provided guarantee that no complete valid allocation exists. Furthermore, the impossibility is caused by exactly one of the following isolated logical contradictions:
- `JOB i` (for a specific $i \in \{1, \dots, j\}$): Rules 1 and 2, when applied only to entity $i$'s intervals, are impossible to satisfy.
- `LOAD 1`: Rules 1 and 3, when applied to the $A$ intervals of all $j$ entities, are impossible to satisfy.
- `LOAD 2`: Rules 1 and 4, when applied to the $B$ intervals of all $j$ entities, are impossible to satisfy.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the required lengths for interval $A_i$ and interval $B_i$, respectively.

## Output

Print a single line containing either `JOB i` (if entity $i$'s isolated constraints are unsatisfiable), `LOAD 1` (if the Collision A constraints are isolatedly unsatisfiable), or `LOAD 2` (if the Collision B constraints are isolatedly unsatisfiable).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, entity 1 requires an interval $A_1$ of length 70 and an interval $B_1$ of length 60. Rule 2 dictates that every value in $B_1$ must be strictly greater than every value in $A_1$. Mapping both of these intervals into the domain $[0, 100]$ while respecting this sequence is impossible, making `JOB 1` the valid contradiction. 

In Example 2, no individual entity violates Rules 1 and 2 on its own. However, Rule 3 requires packing four disjoint interiors of length 50 into the domain $[0, 150]$, which is impossible, making `LOAD 1` the valid contradiction.
</STATEMENT>
<RATIONALE>
The problem has been entirely reframed from a machine scheduling task into a formal 1D geometry and set theory problem. By removing vocabulary like "capacity", "bursts", and "time limit", models can no longer pattern-match their way to computing sums. They must now logically deduce that packing disjoint intervals of given lengths into a bounded domain mathematically requires the sum of their lengths to be independently checked against the domain's size.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that interval $B_i$ is strictly greater than $A_i$ within $[0, T]$ is mathematically identical to $p_1 + p_2 > T$, and packing disjoint interiors into $[0, T]$ is mathematically identical to checking if the sum of lengths exceeds $T$.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires $O(N)$ time to verify the exact same three linear threshold conditions, maintaining its status as a simple infeasibility certificate task.
</PRESERVED_CLASS>
<RISK>
Models might struggle with the term "interior" if they lack mathematical training, but in the context of intervals and the provided examples, its meaning (non-overlapping lengths) is standard and unambiguous.
</RISK>
