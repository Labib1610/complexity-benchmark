# Spacecraft Component Calibration

Time limit: 2 s   Memory limit: 256 MB

## Description

You are calibrating $j$ distinct sensor arrays on a spacecraft. Each sensor array requires two sequential continuous calibration segments: a **Primary Alignment** and a **Secondary Alignment**.

These segments must be mapped onto a linear calibration track of total length $T$, starting at coordinate $0$ and ending at coordinate $T$.

The mapping must satisfy these geometric rules:
1. **Sequence**: For any single sensor array, its Secondary Alignment segment must be placed such that its starting coordinate is greater than or equal to the ending coordinate of its Primary Alignment segment.
2. **Primary Track Exclusivity**: No two Primary Alignment segments from any sensor arrays may overlap with each other.
3. **Secondary Track Exclusivity**: No two Secondary Alignment segments from any sensor arrays may overlap with each other.
4. **Track Boundary**: All segments for all sensor arrays must be fully contained within the track coordinates $[0, T]$.

The diagnostic system has determined that the track length $T$ is strictly too short to accommodate all segments under these rules. The failure is guaranteed to fall into exactly one of the following three contradiction categories:

- `JOB i` (where $i$ is the 1-based index of a sensor array): The relaxed scenario consisting solely of the **Sequence** and **Track Boundary** rules for sensor array $i$ is geometrically impossible to satisfy on its own. If multiple sensor arrays fit this description, outputting `JOB i` for any such valid $i$ is accepted.
- `LOAD 1`: The relaxed scenario consisting solely of the **Primary Track Exclusivity** and **Track Boundary** rules across all $j$ Primary Alignment segments is geometrically impossible to satisfy on its own.
- `LOAD 2`: The relaxed scenario consisting solely of the **Secondary Track Exclusivity** and **Track Boundary** rules across all $j$ Secondary Alignment segments is geometrically impossible to satisfy on its own.

## Input

The first line contains two integers $j$ and $T$. The spacecraft has exactly $200000$ sensor bays, meaning the number of arrays $j$ satisfies $1 \le j \le 200000$. The track length $T$ is bounded by the hull length, meaning $1 \le T \le 1000000000$.

Each of the next $j$ lines contains two integers $p_1$ and $p_2$. These represent the length of the **Primary Alignment** segment and the length of the **Secondary Alignment** segment for that sensor array, respectively. Each segment length is governed by standard component sizes, satisfying $1 \le p_1, p_2 \le 1000000$.

## Output

Print a single line containing either `JOB i` (if sensor array $i$'s constraint subset alone is unsatisfiable), `LOAD 1` (if the Primary Track Exclusivity constraint subset alone is unsatisfiable), or `LOAD 2` (if the Secondary Track Exclusivity constraint subset alone is unsatisfiable).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

<RATIONALE>
The problem was completely reframed from a time-based scheduling task to a 1D geometric segment mapping task. By replacing computational workload and operating windows with linear coordinate placement and non-overlapping track segments, models that rely on keyword association for scheduling heuristics will fail to trigger their templates. They must now genuinely deduce that fitting non-overlapping continuous segments into a bounded space requires their sum to be at most the space's length, and that sequence rules imply a single array's combined length cannot exceed the track. The guarantee structure was carefully restored to the seed's semantics, ensuring it specifies exactly one applicable category of contradiction rather than exactly one unique certificate.
</RATIONALE>

The geometric constraints (Sequence, Exclusivity, Boundary) mathematically reduce to the exact same three independent inequalities as the original time constraints (p1+p2 > T, sum(p1) > T, sum(p2) > T), preserving all outputs.
</PRESERVED_ANSWER>
