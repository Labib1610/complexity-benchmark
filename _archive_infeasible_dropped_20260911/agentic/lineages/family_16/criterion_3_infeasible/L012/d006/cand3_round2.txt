<STATEMENT>
# System of Inequalities Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of inequalities involving $4j$ real variables: $A_1 \dots A_j$, $B_1 \dots B_j$, $C_1 \dots C_j$, and $D_1 \dots D_j$. 
You are given $j$ pairs of positive integers $(p_1, p_2)$ and a global upper bound $T$.

A valid assignment of the variables must satisfy four families of conditions:
1. **Internal Monotonicity**: For any given index $i$, $C_i \ge B_i$.
2. **Alpha Separation**: For every pair of distinct indices $u$ and $v$, either $B_u \le A_v$ or $B_v \le A_u$.
3. **Beta Separation**: For every pair of distinct indices $u$ and $v$, either $D_u \le C_v$ or $D_v \le C_u$.
4. **Domain Spans**: For any given index $i$, its variables must satisfy $B_i - A_i = p_1$ and $D_i - C_i = p_2$ (where $p_1, p_2$ are the input values for pair $i$), along with the bounds $A_i \ge 0$, $B_i \le T$, $C_i \ge 0$, and $D_i \le T$.

The system has determined that the bound $T$ is too strict to satisfy all conditions simultaneously. Exactly one of the following error codes will correctly explain the bottleneck:

- `JOB i` (where $i$ is the 1-based index of a pair): This code applies if the relaxed system consisting solely of **Internal Monotonicity** for pair $i$ and **Domain Spans** for pair $i$ is logically unsatisfiable on its own.
- `LOAD 1`: This code applies if the relaxed system consisting solely of **Alpha Separation** and **Domain Spans** for all $j$ pairs is logically unsatisfiable on its own.
- `LOAD 2`: This code applies if the relaxed system consisting solely of **Beta Separation** and **Domain Spans** for all $j$ pairs is logically unsatisfiable on its own.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the required differences $B_i - A_i = p_1$ and $D_i - C_i = p_2$ for pair $i$, respectively.

## Output

Print a single line containing either `JOB i` (if pair $i$'s constraint subset alone is unsatisfiable), `LOAD 1` (if the Alpha Separation constraint subset alone is unsatisfiable), or `LOAD 2` (if the Beta Separation constraint subset alone is unsatisfiable).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, the first pair requires $B_1 - A_1 = 70$ and $D_1 - C_1 = 60$. The restricted system for pair 1 requires satisfying these differences along with $C_1 \ge B_1$ and the domain bounds $A_1 \ge 0$ and $D_1 \le 100$. This implies $D_1 \ge 130$, which contradicts $D_1 \le 100$, making the system logically unsatisfiable. This makes `JOB 1` a valid error code.

In Example 2, no individual pair's isolated constraints are unsatisfiable. However, Alpha Separation requires four pairs of variables to be strictly ordered (e.g., $B_u \le A_v$), with each pair having a difference $B_i - A_i = 50$. Packing four such spans into the bounds $A_i \ge 0$ and $B_i \le 150$ is logically unsatisfiable, making `LOAD 1` the valid error code.
