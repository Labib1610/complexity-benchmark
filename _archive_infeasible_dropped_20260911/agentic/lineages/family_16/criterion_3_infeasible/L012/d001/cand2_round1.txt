<STATEMENT>
# Problem C — Impossible Window: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are auditing $j$ data-transfer routines (referred to as "jobs"). Each job consists of transmitting a header via Channel 1, followed by transmitting its payload via Channel 2. A channel can only handle one transmission at a time, and a job's payload transmission cannot begin until its header transmission has completely finished.

There is a strict operational window of $T$ microseconds. All jobs must fully complete both of their transmissions within this window.

For every input in this problem, it is guaranteed that the time window is too small, regardless of the order in which the jobs are executed. Your task is to output a short text code that proves this impossibility.

You must provide exactly one of the following two types of evidence. Print the one that applies:

- `JOB i` : The inherent sequential requirement of job $i$ (1-based) prevents it from completing within the window, even if it were the only job being processed.
- `LOAD c` : The total active time required by Channel $c$ ($c \in \{1, 2\}$) to process its portion of the schedule exceeds the window, which is impossible since the channel can only handle one transmission at a time.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the duration in microseconds for the job's header on Channel 1 and its payload on Channel 2.

## Output

Print a single line containing either `JOB i` (if job $i$'s sequential requirement cannot fit in the window) or `LOAD c` (if Channel $c$'s required active time exceeds the window).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, the first job takes 70 microseconds on Channel 1 and then 60 microseconds on Channel 2 sequentially, which alone exceeds the 100-microsecond window. Thus, `JOB 1` is valid evidence. 

In Example 2, no single job violates the window on its own. However, Channel 1 is required to be active for four separate 50-microsecond transmissions. Because it processes them one at a time, this requires 200 microseconds, exceeding the 150-microsecond window, making `LOAD 1` valid evidence.
