 We need to check two conditions:

1. **Job condition**: If any job has `p1 + p2 > T`, then output `JOB i` (1-based index).
2. **Load condition**: If the sum of all `p1` values > T, output `LOAD 1`. If the sum of all `p2` values > T, output `LOAD 2`.

We check the job condition first, then the load conditions.  
If neither triggers, we still must output something — but the problem guarantees one will trigger.

Here’s the code:

```python
j, T = map(int, input().split())
p1s = []
p2s = []
for i in range(j):
    p1, p2 = map(int, input().split())
    p1s.append(p1)
    p2s.append(p2)
    if p1 + p2 > T:
        print(f"JOB {i+1}")
        exit()

if sum(p1s) > T:
    print("LOAD 1")
    exit()

if sum(p2s) > T:
    print("LOAD 2")
    exit()
```
