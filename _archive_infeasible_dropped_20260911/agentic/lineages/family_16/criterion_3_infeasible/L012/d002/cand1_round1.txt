# Problem C — Impossible Window: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are auditing $j$ data-transfer routines (referred to as "jobs"). Each job requires a transmission on Channel 1 (the header), followed by a transmission on Channel 2 (the payload). A channel can only handle one transmission at a time (transmissions on the same channel must be serialized). Furthermore, a job's payload transmission cannot begin until its header transmission has completely finished (a dependency constraint from Channel 1 to Channel 2).

There is a strict operational window of $T$ microseconds. All jobs must fully complete both of their transmissions within this window.

For every input in this problem, no valid schedule exists. Your task is to output a short text code that identifies the structural bottleneck preventing a valid schedule:

- `JOB i` (where $i$ is the 1-based index): The minimum completion time forced by the dependency constraint of job $i$ alone exceeds the window $T$.
- `LOAD c` (where $c$ is 1 or 2): The minimum completion time forced by the serialization of all transmissions on Channel $c$ exceeds the window $T$.

If multiple bottleneck types apply, prioritize outputting `JOB i`. If multiple jobs have a bottleneck, output the one with the smallest index. If no job has a bottleneck but both channels do, output `LOAD 1`.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the duration in microseconds for the job's header on Channel 1 and its payload on Channel 2, respectively.

## Output

Print a single line containing either `JOB i` or `LOAD c` according to the bottleneck rules above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, the first job requires 70 microseconds on Channel 1 and 60 microseconds on Channel 2. The dependency constraint forces these to occur sequentially, resulting in a minimum completion time of 130 microseconds. Since this exceeds the 100-microsecond window, `JOB 1` is the structural bottleneck.

In Example 2, no individual job's dependency constraint violates the 150-microsecond window. However, Channel 1 is assigned four transmissions of 50 microseconds each. The serialization constraint on Channel 1 forces a minimum completion time of 200 microseconds, making `LOAD 1` the bottleneck.
