 We need to check two conditions in order:

1. **JOB condition**: If any order has \( p_1 + p_2 > T \), then output `JOB i` (1-based index).
2. **LOAD condition**: If the sum of all \( p_1 \) > T or sum of all \( p_2 \) > T, then output `LOAD 1` or `LOAD 2` respectively.

Since the problem guarantees exactly one of these will be true, we can check in that order.

```python
j, T = map(int, input().split())
total1 = 0
total2 = 0

for i in range(1, j + 1):
    p1, p2 = map(int, input().split())
    if p1 + p2 > T:
        print(f"JOB {i}")
        exit()
    total1 += p1
    total2 += p2

if total1 > T:
    print("LOAD 1")
elif total2 > T:
    print("LOAD 2")
```
