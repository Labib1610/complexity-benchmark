<STATEMENT>
# Spaceship Power Allocation Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

You are generating a schedule to reboot $j$ critical subsystems. For each subsystem $k \in \{1, \dots, j\}$, you must assign two right-half-open time intervals:
- $C_k = [a_k, b_k)$, representing the Capacitor Charge, which must have a duration $b_k - a_k = p_{1,k}$.
- $I_k = [c_k, d_k)$, representing the System Initialization, which must have a duration $d_k - c_k = p_{2,k}$.

A valid schedule must satisfy four conditions:
1. **Precedence**: $c_k \ge b_k$ for all $k$. (A subsystem's initialization cannot start until its charge is complete).
2. **Capacitor Grid**: $C_x \cap C_y = \emptyset$ for all $x \neq y$. (No two Capacitor Charge intervals may overlap).
3. **Initialization Grid**: $I_x \cap I_y = \emptyset$ for all $x \neq y$. (No two System Initialization intervals may overlap).
4. **Deadline**: $\bigcup_{k=1}^j (C_k \cup I_k) \subseteq [0, T]$. (All operations must complete within the operational window $[0, T]$).

The ship's computer has determined that no such schedule exists. To log the error, you must identify the exact bottleneck. The input data guarantees that exactly one of the following inherent requirements for any assignment of intervals satisfying conditions 1, 2, and 3 strictly exceeds $T$:
- **Subsystem Bottleneck**: The minimum possible value of $d_k - a_k$ for some specific subsystem $k$. If this strictly exceeds $T$, output `JOB k`.
- **Capacitor Bottleneck**: The minimum possible measure (total length) of the set $\bigcup_{k=1}^j C_k$. If this strictly exceeds $T$, output `LOAD 1`.
- **Initialization Bottleneck**: The minimum possible measure (total length) of the set $\bigcup_{k=1}^j I_k$. If this strictly exceeds $T$, output `LOAD 2`.

You must output the exact error string (`JOB k`, `LOAD 1`, or `LOAD 2`) corresponding to the single requirement that strictly exceeds $T$.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_{1,k}$ and $p_{2,k}$ ($1 \le p_{1,k}, p_{2,k} \le 1000000$): the required duration in milliseconds for subsystem $k$'s Capacitor Charge ($C_k$) and System Initialization ($I_k$), respectively.

## Output

Print a single line containing the error string (`JOB k`, `LOAD 1`, or `LOAD 2`) that corresponds to the bottleneck strictly exceeding $T$.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

**Note**
For subsystem 1, $C_1 = [a_1, b_1)$ has length 70 and $I_1 = [c_1, d_1)$ has length 60. By condition 1, $c_1 \ge b_1$. Therefore, $d_1 - a_1 = (d_1 - c_1) + (c_1 - b_1) + (b_1 - a_1) = 60 + (c_1 - b_1) + 70 \ge 130$. The minimum possible value of $d_1 - a_1$ is 130, which strictly exceeds $T = 100$. This triggers `JOB 1`.

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

**Note**
No individual subsystem has a minimum $d_k - a_k$ exceeding 150. However, by condition 2, the intervals $C_1, C_2, C_3, C_4$ must not overlap. Since each has a duration of 50, any valid assignment requires the set $\bigcup_{k=1}^4 C_k$ to have a total measure of exactly 200. This strictly exceeds $T = 150$, triggering `LOAD 1`.
</STATEMENT>
<RATIONALE>
Removed the explicit arithmetic descriptions of the three bounds (e.g., "processed sequentially", "processed back-to-back"). Replaced them with the equivalent properties of disjoint intervals and set measures. This forces models to geometrically deduce that the measure of a union of pairwise disjoint intervals is exactly the sum of their lengths, breaking simple keyword-to-code mapping.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical minimums for the three set-theoretic bounds evaluate identically to the original arithmetic bounds ($p_{1,k} + p_{2,k}$, $\sum p_{1,k}$, and $\sum p_{2,k}$), so the correct output for any input remains unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires exactly the same $O(N)$ sequential checks to identify which of the three bounds exceeds $T$, preserving the complexity class.
</PRESERVED_CLASS>
<RISK>
A reader might initially be confused by "minimum possible measure" for a union of sets, but the strict non-overlap constraints and the provided examples make it unambiguous that this measure is mathematically invariant and equal to the sum of the individual interval lengths.
</RISK>
