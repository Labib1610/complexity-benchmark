We can check the three scenarios in order:

1. **JOB i**: For each subsystem, if `p1 + p2 > T`, then that subsystem alone violates the time limit.
2. **LOAD 1**: If the sum of all `p1` values exceeds `T`, then the capacitor-only schedule violates the limit.
3. **LOAD 2**: If the sum of all `p2` values exceeds `T`, then the initialization-only schedule violates the limit.

The problem guarantees exactly one of these will be true, so we can check in that order.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    
    p1_sum = 0
    p2_sum = 0
    
    idx = 2
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        
        p1_sum += p1
        p2_sum += p2
    
    if p1_sum > T:
        print("LOAD 1")
        return
    
    if p2_sum > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
