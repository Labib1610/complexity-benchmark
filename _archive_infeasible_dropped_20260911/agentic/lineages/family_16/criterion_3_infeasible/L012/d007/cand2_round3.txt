<STATEMENT>
# 1D Geometric Placement Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a 1D placement problem involving $j$ composite objects. Each object $i$ (for $1 \le i \le j$) consists of two contiguous line segments: a primary segment of length $p_{1,i}$ and a secondary segment of length $p_{2,i}$.

The segments must be placed on a coordinate axis, subject to the following rules:
1. **Internal Ordering**: For any single object, its secondary segment must be placed such that its starting coordinate is greater than or equal to the ending coordinate of its primary segment.
2. **Primary Exclusivity**: Any two primary segments (from different objects) may at most touch at their endpoints; their interiors must not intersect.
3. **Secondary Exclusivity**: Any two secondary segments (from different objects) may at most touch at their endpoints; their interiors must not intersect.
4. **Bounding Limit**: Every segment must be positioned entirely within the closed coordinate interval $[0, T]$.

The input data represents a configuration where it is strictly impossible to satisfy all rules simultaneously. Furthermore, the input guarantees that exactly one of the following three independent relaxations is impossible to satisfy within the interval $[0, T]$. Your task is to output the code corresponding to the unique impossible relaxation:

- `JOB i` (where $i$ is the 1-based index of the object): It is impossible to place the primary and secondary segments of object $i$ such that they satisfy the **Internal Ordering** rule and the **Bounding Limit** rule (ignoring all other objects).
- `LOAD 1`: It is impossible to place all $j$ primary segments such that they satisfy the **Primary Exclusivity** rule and the **Bounding Limit** rule (ignoring all secondary segments and the Internal Ordering rule).
- `LOAD 2`: It is impossible to place all $j$ secondary segments such that they satisfy the **Secondary Exclusivity** rule and the **Bounding Limit** rule (ignoring all primary segments and the Internal Ordering rule).

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the lengths of the object's primary segment and secondary segment, respectively.

## Output

Print a single line containing either `JOB i` (if object $i$'s isolated placement is impossible), `LOAD 1` (if the primary segments' placement is impossible), or `LOAD 2` (if the secondary segments' placement is impossible).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, object 1 has a primary segment of length 70 and a secondary segment of length 60. The **Internal Ordering** rule requires the secondary segment to start at or after the primary segment ends. The minimum required span for these two segments is $70 + 60 = 130$. Since this strictly exceeds $T = 100$, it is impossible to satisfy the **Bounding Limit** rule for object 1 in isolation. Thus, `JOB 1` is the valid proof of impossibility.

In Example 2, no single object violates the **Bounding Limit** under the **Internal Ordering** rule. However, the **Primary Exclusivity** rule requires placing four primary segments of length 50 such that their interiors do not intersect. The minimum required span for these four segments is $50 + 50 + 50 + 50 = 200$. Since $200$ strictly exceeds $T = 150$, it is impossible to place all primary segments within $[0, 150]$. Thus, `LOAD 1` is the valid proof.
</STATEMENT>
<RATIONALE>
The problem was rewritten to use 1D geometric placement rather than task scheduling. By describing the bottleneck certificates as independent geometric relaxations (e.g., fitting N non-overlapping segments into an interval [0, T]), models can no longer rely on explicitly stated summation triggers like "process all J bursts back-to-back". They must instead reason about the mathematical implications of the spatial constraints to deduce the correct inequalities.
</RATIONALE>
<PRESERVED_ANSWER>
The geometric span of non-overlapping segments exactly equals the sum of their lengths, and the span of two ordered segments exactly equals the sum of their lengths, making the mathematical thresholds identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains an O(N) certificate verification task checking the exact same three independent linear inequalities.
</PRESERVED_CLASS>
<RISK>
Models or readers might overthink the geometric packing aspect and assume a complex subset-sum or bin-packing problem, though the explicit relaxation instructions ("ignoring all other objects/segments") mathematically reduce it back to simple sums.
</RISK>
