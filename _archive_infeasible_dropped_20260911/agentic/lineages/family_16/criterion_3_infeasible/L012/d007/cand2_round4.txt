# Spaceship Power Allocation Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

You are the chief engineer of a spaceship managing $j$ critical subsystems. Each subsystem requires two power bursts to reboot: a **Capacitor Charge** burst and a **System Initialization** burst. 

The reboot sequence is subject to the following safety constraints:
1. **Precedence**: For any given subsystem, its System Initialization burst must start at or after the exact moment its Capacitor Charge burst finishes.
2. **Capacitor Grid Capacity**: The ship's capacitor grid can only handle one Capacitor Charge burst at a time. No two Capacitor Charge bursts may overlap.
3. **Initialization Grid Capacity**: The ship's initialization grid can only handle one System Initialization burst at a time. No two System Initialization bursts may overlap.
4. **Time Limit**: The entire reboot process for all bursts across all subsystems must be completely contained within a strict operating window of $[0, T]$ milliseconds.

The ship's computer has determined that the window $T$ is too short to reboot all subsystems. You must output an error code corresponding to a valid impossibility certificate. The input data guarantees that at least one of the following certificates is true. If multiple certificates are true (for example, multiple subsystems fail, or both grids fail), outputting any valid one is accepted:

- `JOB i` (where $i$ is the 1-based index of a subsystem): For subsystem $i$, there does not exist any time instant $t$ ($0 \le t \le T$) such that the interval $[0, t]$ has a length of at least the subsystem's Capacitor Charge duration, and the interval $[t, T]$ has a length of at least its System Initialization duration. (If multiple subsystems satisfy this, you may output `JOB i` for any such $i$).
- `LOAD 1`: There does not exist a set of mutually disjoint sub-intervals within $[0, T]$ whose lengths are exactly the Capacitor Charge durations of all $j$ subsystems.
- `LOAD 2`: There does not exist a set of mutually disjoint sub-intervals within $[0, T]$ whose lengths are exactly the System Initialization durations of all $j$ subsystems.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the duration in milliseconds for the subsystem's **Capacitor Charge** burst and its **System Initialization** burst, respectively.

## Output

Print a single line containing a valid impossibility certificate: `JOB i`, `LOAD 1`, or `LOAD 2`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for the first subsystem, its Capacitor Charge is 70 and System Initialization is 60. There is no time $t \in [0, 100]$ such that $t \ge 70$ and $100 - t \ge 60$. Thus, `JOB 1` is a valid certificate.

In Example 2, the Capacitor Charge durations are 50, 50, 50, and 50. There is no way to place four mutually disjoint sub-intervals of length 50 within the interval $[0, 150]$. Thus, `LOAD 1` is a valid certificate.
</STATEMENT>
<RATIONALE>
The explicit sum and sequential addition checks have been replaced with their mathematical equivalents in 1D geometry (interval partitioning and disjoint sub-interval packing). This forces the model to algebraically deduce that checking for the non-existence of a valid partition point `t` is equivalent to checking `p1 + p2 > T`, and checking for the non-existence of disjoint sub-intervals is equivalent to checking `sum > T`. Furthermore, the uniqueness wording flagged by the gate has been replaced with an explicit existence-based certificate that accepts any valid witness.
</RATIONALE>
<PRESERVED_ANSWER>
The geometric conditions are mathematically identical to the original arithmetic bounds: an interval [0, T] can hold disjoint segments of given lengths if and only if their sum is <= T, and a point t where t >= p1 and T - t >= p2 exists if and only if p1 + p2 <= T.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class remains exactly the same because the conditions still trivially reduce to O(1) checks per job and O(N) sums for the loads, preserving the O(N) linear scan algorithm.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "mutually disjoint sub-intervals" as requiring the intervals to be placed in the specific order of the input subsystems, though the math (sum <= T) remains completely unaffected even if they make this assumption.
</RISK>
