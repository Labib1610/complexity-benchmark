We can solve this by checking two conditions:

1. **JOB condition**: If any project has `p1 + p2 > T`, then that project alone cannot finish in time. Output `JOB i` for the first such project.

2. **LOAD condition**: If the sum of all `p1` > T, then the primary unit is overloaded. If the sum of all `p2` > T, then the secondary unit is overloaded. Output `LOAD 1` or `LOAD 2` accordingly.

Since the problem guarantees exactly one proof applies, we can check in that order.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    idx = 2
    sum1 = 0
    sum2 = 0
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        sum1 += p1
        sum2 += p2
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
    if sum1 > T:
        print("LOAD 1")
        return
    if sum2 > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
