# Problem C — Impossible Window: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are evaluating a manufacturing process with $j$ custom orders. Each order requires fabrication on Machine 1, and only after that is fully completed, finishing on Machine 2. A machine can process at most one order at any given moment.

The factory has a strict operating shift of $T$ minutes. All orders must complete both fabrication and finishing within this shift.

For every input, it is guaranteed that the shift is too short to fulfill all orders, no matter how they are scheduled. Furthermore, exactly one of the following two proofs of impossibility will apply. Your task is to verify the orders and output the code for the proof that applies:

- `JOB i` (where $i$ is the 1-based index of an order): Impossibility is proven by the fact that order $i$ cannot be completed within the shift even if it were the only order assigned to the factory, due to its strict fabrication-before-finishing dependency.
- `LOAD c` (where $c$ is 1 or 2): Impossibility is proven by the fact that Machine $c$ cannot complete its assigned work within the shift even if we were to completely drop the rule that fabrication must precede finishing, due to the machine's inability to process multiple orders concurrently.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the duration in minutes for the order's fabrication on Machine 1 and its finishing on Machine 2, respectively.

## Output

Print a single line containing either `JOB i` (if isolating order $i$'s dependency proves impossibility) or `LOAD c` (if isolating Machine $c$'s concurrency limit proves impossibility).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, the first order requires 70 minutes on Machine 1 and 60 minutes on Machine 2. It cannot meet the 100-minute shift strictly due to its own stage dependency, making `JOB 1` a valid proof of impossibility. 

In Example 2, no individual order violates the 150-minute shift when considered in isolation. However, Machine 1 is assigned four fabrication tasks of 50 minutes each. Because the machine cannot process multiple tasks at once, it cannot complete its assigned work within the shift regardless of stage dependencies, making `LOAD 1` the valid proof.
