# Spaceship Power Allocation Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

You are the chief engineer of a spaceship managing $j$ critical subsystems. Each subsystem requires two distinct energy bursts to reboot: a **Capacitor Charge** burst and a **System Initialization** burst. 

The reboot sequence is strictly governed by the following safety constraints:
1. **Precedence**: For any given subsystem, its System Initialization burst cannot begin until its Capacitor Charge burst has completely finished.
2. **Capacitor Grid Capacity**: The ship's capacitor grid can process at most one Capacitor Charge burst at any given moment.
3. **Initialization Grid Capacity**: The ship's initialization grid can process at most one System Initialization burst at any given moment.
4. **Time Limit**: All bursts across all subsystems must be fully completed within a strict operating window of $T$ milliseconds.

The ship's computer has determined that no valid sequence of operations can satisfy all four constraints simultaneously. The input data guarantees that exactly one of the following hypothetical hardware upgrades still forces an unavoidable violation of Constraint 4. You must isolate the exact bottleneck by outputting the corresponding error code:

- `JOB i` (where $i$ is the 1-based index of a subsystem): The time limit is violated even under a hypothetical upgrade where every subsystem *except* $i$ is granted instantaneous execution (their Capacitor Charge and System Initialization durations become 0, consuming no grid capacity). The Precedence constraint is still strictly enforced for all subsystems, and subsystem $i$ retains its original durations.
- `LOAD 1`: The time limit is violated even under a hypothetical upgrade where the initialization grid is replaced by a quantum matrix. This matrix executes all System Initialization bursts instantaneously (their durations become 0) and can handle any number of them simultaneously. The capacitor grid remains unchanged, and the Precedence constraint (a subsystem's System Initialization cannot begin until its Capacitor Charge is fully complete) remains strictly enforced for all subsystems.
- `LOAD 2`: The time limit is violated even under a hypothetical upgrade where the capacitor grid is replaced by a quantum matrix. This matrix executes all Capacitor Charge bursts instantaneously (their durations become 0) and can handle any number of them simultaneously. The initialization grid remains unchanged, and the Precedence constraint (a subsystem's System Initialization cannot begin until its Capacitor Charge is fully complete) remains strictly enforced for all subsystems.

## Input

The first line provides the subsystem count $j$ and the operating window $T$. The system scales from a single subsystem up to two hundred thousand subsystems. The operating window can be as tight as one millisecond or as long as one billion milliseconds.

Each of the subsequent $j$ lines contains two integers $p_1$ and $p_2$. These represent the duration in milliseconds for the subsystem's **Capacitor Charge** burst and its **System Initialization** burst, respectively. A burst always takes at least one millisecond, and physical limits cap any single burst at one million milliseconds.

## Output

Print a single line containing either `JOB i` (if the scenario where only subsystem $i$ retains its durations violates the time limit), `LOAD 1` (if the scenario with instantaneous System Initializations violates the time limit), or `LOAD 2` (if the scenario with instantaneous Capacitor Charges violates the time limit).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, under the `JOB 1` hypothetical upgrade, subsystems 2 and 3 execute instantaneously. Subsystem 1 must still complete its 70 ms Capacitor Charge and its 60 ms System Initialization. Due to Constraint 1 (Precedence), these cannot overlap. The absolute minimum time to complete both is 130 ms. This unavoidably violates the 100 ms Time Limit (Constraint 4). Thus, `JOB 1` is the valid proof.

In Example 2, no individual subsystem exceeds the 150 ms limit. However, under the `LOAD 1` hypothetical upgrade, all System Initializations execute instantaneously. The Capacitor Charges must still be processed sequentially on the unmodified capacitor grid. The minimum time to process all four 50 ms bursts is 200 ms, which unavoidably violates Constraint 4. Thus, `LOAD 1` is the valid proof.
