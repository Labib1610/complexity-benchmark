# Problem C — Subspace Projection Diagnostics

Time limit: 2 s   Memory limit: 256 MB

## Description

A computational geometry task requires mapping a set of $j$ vectors into a one-dimensional coordinate space of length $T$. Each vector $k \in \{1, 2, \dots, j\}$ is defined by two components: $p_{1,k}$ and $p_{2,k}$. The goal is to assign two scalar base coordinates, $X_k$ and $Y_k$, to each vector $k$.

A valid coordinate mapping must satisfy the following algebraic constraints:
1. **Domain:** For all $k$, the intervals $[X_k, X_k + p_{1,k})$ and $[Y_k, Y_k + p_{2,k})$ must be sub-intervals of the available space $[0, T]$.
2. **Component Ordering:** For all $k$, the coordinate $Y_k$ must be strictly greater than or equal to $X_k + p_{1,k}$.
3. **First Component Isolation:** For any two distinct vectors $k$ and $m$, their first-component intervals $[X_k, X_k + p_{1,k})$ and $[X_m, X_m + p_{1,m})$ must not intersect.
4. **Second Component Isolation:** For any two distinct vectors $k$ and $m$, their second-component intervals $[Y_k, Y_k + p_{2,k})$ and $[Y_m, Y_m + p_{2,m})$ must not intersect.

For every given input, it is mathematically guaranteed that no valid mapping exists. You must provide a short certificate proving this impossibility. Exactly one of the following two structural bottlenecks will apply to the given input, and you must output the corresponding certificate:

- `JOB i` (where $i \in \{1, \dots, j\}$): The trace of the $2 \times 2$ diagonal matrix whose main diagonal consists of $p_{1,i}$ and $p_{2,i}$ strictly exceeds $T$. This makes it impossible to satisfy rules 1 and 2 for vector $i$ alone. If multiple vectors fit this description, you may output any one of them.
- `LOAD c` (where $c \in \{1, 2\}$): The trace of the $j \times j$ diagonal matrix whose main diagonal consists of the $c$-th components of all $j$ vectors strictly exceeds $T$. This makes it impossible to satisfy the isolation rule for component $c$ within the domain $[0, T]$. If both components fit this description, you may output either one.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the first and second components of a vector, respectively. Vectors are implicitly numbered 1 to **j**.

## Output

Print a single line containing the certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, **T** = 100. For vector 1, the components are 70 and 60. The trace of the $2 \times 2$ diagonal matrix with these entries is 130. Since $130 > 100$, the mapping is impossible. Thus, `JOB 1` proves the inconsistency.

In Example 2, **T** = 150. For the first component ($c=1$), the values across all 4 vectors are 50, 50, 50, and 50. The trace of the $4 \times 4$ diagonal matrix with these entries is 200. Since $200 > 150$, the mapping is impossible. Thus, `LOAD 1` proves the inconsistency.
