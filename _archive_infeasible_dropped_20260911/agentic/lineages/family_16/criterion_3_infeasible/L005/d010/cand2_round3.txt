<STATEMENT>
# Problem C — Schedule Diagnostics

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing plant must process a set of jobs $J = \{1, 2, \dots, j\}$. Each job requires an operation on Machine 1 and an operation on Machine 2. 

To program the plant's automated controllers, a schedule is defined by assigning each job $k \in J$ a temporal midpoint $M_{1,k}$ for its operation on Machine 1, and a temporal midpoint $M_{2,k}$ for its operation on Machine 2. The plant operates continuously from time $0$ to a strict deadline $T$.

A schedule is mathematically valid if and only if it satisfies the following system of coordinate constraints:
1. **Machine 1 Domain:** For all $k \in J$, $M_{1,k} \ge \frac{p_{1,k}}{2}$ and $M_{1,k} \le T - \frac{p_{1,k}}{2}$.
2. **Machine 2 Domain:** For all $k \in J$, $M_{2,k} \ge \frac{p_{2,k}}{2}$ and $M_{2,k} \le T - \frac{p_{2,k}}{2}$.
3. **Sequential Dependency:** For all $k \in J$, the coordinate difference must satisfy $M_{2,k} - M_{1,k} \ge \frac{p_{1,k} + p_{2,k}}{2}$.
4. **Machine 1 Isolation:** For any two distinct jobs $k, m \in J$, the distance between their midpoints on Machine 1 must satisfy $|M_{1,k} - M_{1,m}| \ge \frac{p_{1,k} + p_{1,m}}{2}$.
5. **Machine 2 Isolation:** For any two distinct jobs $k, m \in J$, the distance between their midpoints on Machine 2 must satisfy $|M_{2,k} - M_{2,m}| \ge \frac{p_{2,k} + p_{2,m}}{2}$.

For every given test case, it is guaranteed that no valid schedule exists that satisfies all five constraints. Your task is not to search for a schedule, but to output a short certificate proving this impossibility. Exactly one of the following two explicit algebraic bottlenecks will apply, and you must output the corresponding certificate:

- `JOB i` (where $i \in J$): The maximum possible valid coordinate for $M_{2,i}$ minus the minimum possible valid coordinate for $M_{1,i}$ (as dictated by their respective Domain constraints) is strictly less than the required Sequential Dependency separation. If multiple jobs fit this description, you may output any one of them.
- `LOAD c` (where $c \in \{1, 2\}$): The absolute minimum coordinate span required to pack all midpoints on Machine $c$ (calculated as the sum of the required Isolation distances between adjacent midpoints in any sorted order, plus the required Domain boundary margins for the first and last midpoints) strictly exceeds the total available span $T$. If both machines fit this description, you may output either one.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the processing duration parameters $p_{1,k}$ and $p_{2,k}$ for the job on Machine 1 and Machine 2, respectively. Jobs are implicitly numbered 1 to **j**.

## Output

Print a single line containing the certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, **T** = 100. For job 1, $p_{1,1} = 70$ and $p_{2,1} = 60$.
The Machine 1 Domain requires $M_{1,1} \ge 35$. The Machine 2 Domain requires $M_{2,1} \le 100 - 30 = 70$.
The maximum possible coordinate for $M_{2,1}$ is 70, and the minimum for $M_{1,1}$ is 35. Their difference is $70 - 35 = 35$.
However, the Sequential Dependency constraint requires $M_{2,1} - M_{1,1} \ge \frac{70 + 60}{2} = 65$.
Since $35 < 65$, the constraints are algebraically impossible for job 1. Thus, `JOB 1` proves the inconsistency.

In Example 2, **T** = 150. For Machine 1, we must pack four midpoints, each with $p_{1,k} = 50$.
The required Isolation distance between any two adjacent midpoints is $\frac{50 + 50}{2} = 50$. For 4 jobs, there are 3 adjacent pairs, requiring a span of $3 \times 50 = 150$.
Additionally, the Domain constraints require the first midpoint to be at least $\frac{50}{2} = 25$ from $0$, and the last midpoint to be at least $25$ from $150$.
The absolute minimum span required is $25 + 150 + 25 = 200$.
Since $200$ strictly exceeds the available span of $150$, the constraints are impossible. Thus, `LOAD 1` proves the inconsistency.

<RATIONALE>
The rewrite maintains the exact 2-machine scheduling context but shifts the mathematical formulation from interval endpoints to temporal midpoints. The impossibility certificates are explicitly defined as algebraic failures of these midpoint coordinate bounds, forcing the model to construct and simplify the inequalities (which mathematically reduce exactly to `p1+p2 > T` and `sum > T`) rather than pattern-matching standard interval heuristic shortcuts.
</RATIONALE>
<PRESERVED_ANSWER>
The midpoint inequalities are a mathematically exact bijection to the original interval constraints, meaning the algebraic failure conditions simplify precisely to `p1+p2 > T` and `sum(p) > T`, preserving all original logic.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Checking the algebraic bounds requires a single $O(N)$ pass to verify the per-job differences and the machine-wide sums, maintaining the exact linear time complexity.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "sum of the required Isolation distances... plus the required Domain boundary margins" as being dependent on the sorting order, though the math guarantees the sum telescopes to exactly $\sum p_{c,k}$ for any permutation.
</RISK>
