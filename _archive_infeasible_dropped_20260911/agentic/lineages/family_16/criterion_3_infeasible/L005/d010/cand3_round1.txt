<STATEMENT>
# Problem C — Set System Diagnostics

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a universe of integers $U = \{1, 2, \dots, T\}$. We must assign two subsets, $A_k \subset U$ and $B_k \subset U$, to each item $k$ in a collection of $j$ items. The items are implicitly numbered 1 to $j$ and are referred to as `JOB 1`, `JOB 2`, $\dots$, `JOB j`.

A valid assignment must satisfy the following rules:
1. **Cardinality:** For each `JOB k`, the subset $A_k$ must contain exactly $p_{1,k}$ integers, and the subset $B_k$ must contain exactly $p_{2,k}$ integers.
2. **Consecutiveness:** For each `JOB k`, the elements of $A_k$ must be consecutive integers. The elements of $B_k$ must also be consecutive integers.
3. **Element-wise Precedence:** For each `JOB k`, every integer $x \in A_k$ and every integer $y \in B_k$ must satisfy $x < y$.
4. **Primary Disjointness:** For any two distinct items $k$ and $m$, their first subsets must not intersect ($A_k \cap A_m = \emptyset$).
5. **Secondary Disjointness:** For any two distinct items $k$ and $m$, their second subsets must not intersect ($B_k \cap B_m = \emptyset$).

For every given input, it is guaranteed that no valid assignment exists. You must provide a short certificate proving this impossibility. Exactly one of the following two structural bottlenecks will apply, and you must output the corresponding certificate:

- `JOB i` (where $i \in \{1, \dots, j\}$): The system of constraints formed by the definition of $U$ and rules 1, 2, and 3 is intrinsically inconsistent when restricted to `JOB i` in isolation. If multiple items fit this description, you may output any one of them.
- `LOAD c` (where $c \in \{1, 2\}$): The system of constraints formed by the definition of $U$, rules 1, 2, and the disjointness rule for subset class $c$ (rule 4 for $c=1$, rule 5 for $c=2$) is intrinsically inconsistent when applied to the entire collection of $j$ items. (The certificate uses the term `LOAD` to indicate that the total element capacity required by the subset class exceeds the universe size). If both subset classes fit this description, you may output either one.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required cardinalities for subset $A_k$ and subset $B_k$, respectively, for the $k$-th item. Items are implicitly numbered 1 to **j**.

## Output

Print a single line containing the certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, **T** = 100, so $U = \{1, 2, \dots, 100\}$. For `JOB 1`, subset $A_1$ must contain 70 consecutive integers and $B_1$ must contain 60 consecutive integers. The element-wise precedence rule requires all elements in $A_1$ to be strictly less than all elements in $B_1$. The minimum possible maximum element of $A_1$ is 70. The minimum possible minimum element of $B_1$ is therefore 71, meaning $B_1$ would require integers up to $71 + 60 - 1 = 130$. Since $130 \notin U$, it is mathematically impossible to satisfy the rules for `JOB 1` in isolation. Thus, `JOB 1` is the correct certificate.

In Example 2, **T** = 150, so $U = \{1, 2, \dots, 150\}$. The primary disjointness rule requires $A_1, A_2, A_3, A_4$ to be mutually disjoint. Each must contain 50 integers, requiring a total of 200 distinct integers. Since $U$ only contains 150 integers, it is impossible to satisfy the rules for the first subset class across all jobs. Thus, `LOAD 1` proves the inconsistency.
