<STATEMENT>
# Problem C — Spectrum Diagnostics

Time limit: 2 s   Memory limit: 256 MB

## Description

A telecommunications authority must allocate radio frequencies for a set of channels $J = \{1, 2, \dots, j\}$. Each channel $k \in J$ requires a continuous frequency band for its Uplink (of bandwidth $p_{1,k}$ MHz) and a continuous frequency band for its Downlink (of bandwidth $p_{2,k}$ MHz).

A valid frequency allocation must assign a starting frequency $U_k$ for the Uplink and $D_k$ for the Downlink for each channel $k$, satisfying the following constraints:
1. **Spectrum Limits:** All allocated bands must fit entirely within the available spectrum block from $0$ MHz to $T$ MHz. Thus, for all $k \in J$, $U_k \ge 0$, $U_k + p_{1,k} \le T$, $D_k \ge 0$, and $D_k + p_{2,k} \le T$.
2. **Duplex Spacing:** To prevent self-interference, a channel's Downlink band must be allocated at higher frequencies than its Uplink band, without overlapping. Thus, for all $k \in J$, $D_k \ge U_k + p_{1,k}$.
3. **Uplink Isolation:** No two distinct channels can share any Uplink frequencies. For any $k, m \in J$ ($k \neq m$), either $U_k + p_{1,k} \le U_m$ or $U_m + p_{1,m} \le U_k$.
4. **Downlink Isolation:** No two distinct channels can share any Downlink frequencies. For any $k, m \in J$ ($k \neq m$), either $D_k + p_{2,k} \le D_m$ or $D_m + p_{2,m} \le D_k$.

For every given input, it is guaranteed that no valid allocation exists. You must provide a short certificate proving this impossibility. Exactly one of the following two structural bottlenecks will apply, and you must output the corresponding certificate:

- `JOB i` (where $i \in J$): The system of constraints formed by the Spectrum Limits and Duplex Spacing rules is intrinsically inconsistent when restricted to the single channel $i$. If multiple channels fit this description, you may output any one of them.
- `LOAD c` (where $c \in \{1, 2\}$): The system of constraints formed by the Spectrum Limits and the isolation rule for link type $c$ (Uplink Isolation for $c=1$, Downlink Isolation for $c=2$) is intrinsically inconsistent when applied to the entire set $J$, even if the Duplex Spacing rule is ignored. If both link types fit this description, you may output either one.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required bandwidth for a channel's Uplink and Downlink, respectively. Channels are implicitly numbered 1 to **j**.

## Output

Print a single line containing the certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, **T** = 100. For channel 1, the Spectrum Limits require $U_1 \ge 0$ and $D_1 + 60 \le 100$. The Duplex Spacing rule requires $D_1 \ge U_1 + 70$. Combining these constraints yields $70 \le U_1 + 70 \le D_1 \le 40$, which is mathematically impossible. Thus, `JOB 1` proves the inconsistency.

In Example 2, **T** = 150. For the Uplink (link type 1), the Spectrum Limits require all four Uplink bands to be sub-intervals within $[0, 150]$. The Uplink Isolation constraint requires these four bands to be mutually disjoint. Since each has a bandwidth of 50, requiring a total bandwidth of 200, no arrangement of these disjoint bands can exist entirely within a spectrum of 150 MHz. Thus, `LOAD 1` proves the inconsistency.
