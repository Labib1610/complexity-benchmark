We can check both conditions directly:

- For **JOB i**: if `p1 + p2 > T`, that item alone cannot finish in time.
- For **LOAD c**: if the sum of all `p1` (facility 1) or all `p2` (facility 2) exceeds `T`, that facility is overloaded.

We check jobs first, then loads, and output the first valid certificate.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    j = int(data[0])
    T = int(data[1])
    
    sum1 = 0
    sum2 = 0
    
    idx = 2
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        
        sum1 += p1
        sum2 += p2
    
    if sum1 > T:
        print("LOAD 1")
    elif sum2 > T:
        print("LOAD 2")

if __name__ == "__main__":
    main()
```
