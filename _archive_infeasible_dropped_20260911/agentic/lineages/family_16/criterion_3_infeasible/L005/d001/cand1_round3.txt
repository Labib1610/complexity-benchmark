<STATEMENT>
# Problem C — Schedule Diagnostics

Time limit: 2 s   Memory limit: 256 MB

## Description

A factory processes **j** jobs through two machines. Every job is processed on machine 1 first and then on machine 2. For each job, you are given its processing time on machine 1 and on machine 2. Each machine processes only one job at a time, and a job reaches machine 2 only after finishing on machine 1.

There is a strict deadline **T**: every job must be completely finished by time **T**.

You must evaluate the system and demonstrate why the deadline **T** cannot be met. Provide a single piece of evidence in one of the following formats:

- `JOB i` — if job **i** (1-based index) cannot possibly finish by **T** even if it were the only job in the system (its processing time on machine 1 plus its processing time on machine 2 is strictly greater than **T**).
- `LOAD c` — if machine **c** (where **c** is 1 or 2) is required to perform a total amount of work across all jobs that is strictly greater than **T**. Since a machine processes jobs sequentially, this guarantees the deadline will be missed.

If multiple jobs or machines satisfy these criteria, you may output any valid one.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the processing times of a job on machine 1 and machine 2.

## Output

Print a single line containing valid evidence: either `JOB i` (where job `i` requires more than `T` time sequentially) or `LOAD c` (where machine `c` has a total processing time exceeding `T`).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, job 1 requires 70 + 60 = 130 time units in sequence. Since 130 > 100, no schedule can finish job 1 by the deadline, making `JOB 1` valid evidence. In Example 2, no individual job exceeds 150 time units, but machine 1 must process 50 + 50 + 50 + 50 = 200 units of work. Since 200 > 150, machine 1 alone guarantees the deadline is missed, making `LOAD 1` valid evidence.
</STATEMENT>
<RATIONALE>
The strategy suggested making the bottleneck depend on schedule completion, but doing so would change the correct answers and violate G1. Instead, I removed the affordance that "exactly one condition will be present" and reframed the task as providing evidence of impossibility. This forces models to understand the criteria independently rather than assuming a mutually exclusive choice provided by the test cases.
</RATIONALE>

The conditions for printing `JOB i` or `LOAD c` are mathematically identical to the seed, and the problem explicitly accepts any valid output if multiple exist, preserving the correctness of the original reference solution.
</PRESERVED_ANSWER>
