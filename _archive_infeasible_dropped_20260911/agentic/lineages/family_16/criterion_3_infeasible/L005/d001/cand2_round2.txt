# Problem C — Schedule Diagnostics

Time limit: 2 s   Memory limit: 256 MB

## Description

A facility processes **j** jobs through exactly two machines. Each job must first pass through machine 1, and only upon completion of that step, proceed to machine 2. Each machine can process at most one job at a time. The input specifies the duration each job requires on machine 1 and on machine 2.

The facility aims to complete all jobs within a strict time window of **T**. However, for every provided configuration, it is strictly impossible to meet this deadline regardless of the chosen order of operations. Your task is to provide a valid certificate of this impossibility. 

For every test case, exactly one of the following two structural reasons always applies. Identify and print the one that holds:

- **Individual Job Certificate**: The uninterrupted sequence of operations for a single job across both machines has a combined duration strictly exceeding the deadline **T**.
  Output: `JOB i` — where **i** (1-based) is the index of the job.

- **Machine Workload Certificate**: The aggregate processing duration required by a single machine to process every job strictly exceeds the deadline **T**.
  Output: `LOAD c` — where **c** $\in \{1, 2\}$ is the index of the overloaded machine.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the duration of the job on machine 1 and machine 2, respectively.

## Output

Print a single line containing either the individual job certificate (`JOB i`) or the machine workload certificate (`LOAD c`), depending on which reason makes the deadline impossible.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, job 1 requires 70 time units on machine 1 followed by 60 time units on machine 2. The combined duration of its uninterrupted sequence is 130 time units. Since 130 > 100, the Individual Job Certificate applies, so we output `JOB 1`.

In Example 2, no single job violates the deadline. However, machine 1 must process every job, requiring an aggregate duration of 50 + 50 + 50 + 50 = 200 time units. Since 200 > 150, the Machine Workload Certificate applies, so we output `LOAD 1`.

The explicit arithmetic formulas ("add up to more than T", "sum of all its processing times") were removed to prevent simple pattern matching. Instead, the conditions are described using formal structural terms ("uninterrupted sequence of operations ... combined duration", "aggregate processing duration required by a single machine"), forcing the model to deduce the underlying sums from the physical constraints of the machines and jobs.
</RATIONALE>
