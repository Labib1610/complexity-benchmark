# Problem C — Schedule Diagnostics

Time limit: 2 s   Memory limit: 256 MB

## Description

A factory processes **j** jobs through exactly two machines. Every job must be processed on machine 1 first, and then on machine 2. For each job, you are given its required processing time on machine 1 and on machine 2. Each machine can process only one job at a time, and a job can only begin on machine 2 after it has completely finished on machine 1.

The factory aims to complete all jobs by a strict deadline **T**. However, an initial diagnostic has determined that no valid schedule can meet this deadline due to a fundamental capacity violation. You must identify the specific violation that makes the deadline unachievable.

It is guaranteed that exactly one of the following fundamental limits is violated in the given input:
- An individual job cannot complete its required sequence of operations within the time limit, even if it never has to wait for a machine. In this case, print `JOB i` where **i** (1-based) is the index of that job.
- A specific machine is assigned a total volume of work that exceeds the available time, meaning it cannot finish even if it operates continuously with no idle time. In this case, print `LOAD c` where **c** is the machine number (1 or 2).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the required processing time of that job on machine 1 and machine 2, respectively.

## Output

Print a single line identifying the capacity violation: either `JOB i` (where i is the job index) or `LOAD c` (where c is 1 or 2).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
