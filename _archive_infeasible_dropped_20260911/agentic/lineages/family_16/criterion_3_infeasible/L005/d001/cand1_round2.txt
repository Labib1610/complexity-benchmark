# Problem C — Schedule Diagnostics

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing facility is tasked with completing **j** jobs. The production pipeline consists of two stages: machine 1 followed by machine 2. Each job must first complete its required processing on machine 1. Only after a job has fully completed on machine 1 can it be handed over to machine 2. Both machines are strictly sequential; neither machine can process more than one job at a time.

Management has set a firm deadline: the entire batch of jobs must be completely finished by time **T**. 

An initial review of the processing times reveals that meeting this deadline by time **T** is impossible, regardless of how the jobs are ordered. Your task is to output a proof of this impossibility by identifying the specific structural bottleneck that strictly exceeds the available time **T**.

You must output a certificate matching exactly one of the following two formats:

- `JOB i` : This certificate proves that job **i** (1-based) is intrinsically too long. Output this if the processing time of job **i** on machine 1 plus its processing time on machine 2 is strictly greater than **T** (i.e., `p1 + p2 > T`). Such a job cannot finish by time **T** even if it never waits in any queue.
- `LOAD c` : This certificate proves that machine **c** (where **c** is 1 or 2) is overloaded. Output this if the sum of processing times across all jobs on machine **c** is strictly greater than **T**. Because a machine operates sequentially, it requires at least this much total active time, making completion by time **T** impossible.

For every test case, you are guaranteed that exactly one valid certificate exists. There will be exactly one bottleneck (either a single job's combined time, or a single machine's total time) that is strictly greater than **T**.

## Input
The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
The following **j** lines specify the processing times. The **i**-th such line contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the required time for job **i** on machine 1 and machine 2, respectively.

## Output
Print a single line containing either:
- `JOB i` where **i** is the 1-based index of a job for which `p1 + p2 > T`.
- `LOAD c` where **c** is 1 or 2, indicating that the sum of processing times on machine **c** strictly exceeds **T**.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
