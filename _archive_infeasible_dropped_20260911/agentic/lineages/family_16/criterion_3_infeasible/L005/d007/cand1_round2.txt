<STATEMENT>
# Problem C — Schedule Diagnostics

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing plant must process **j** items through two sequential stages. A schedule assigns each item **k** a start time $S_{1,k}$ on facility 1 and a start time $S_{2,k}$ on facility 2.
Any valid schedule must satisfy the following constraints:
1. $S_{1,k} \ge 1$ and $S_{2,k} \ge 1$ for all **k**.
2. $S_{2,k} \ge S_{1,k} + p_{1,k}$ for all **k** (stage 2 cannot start until stage 1 finishes).
3. The completion time of item **k** on stage 1 is $C_{1,k} = S_{1,k} + p_{1,k}$, and on stage 2 is $C_{2,k} = S_{2,k} + p_{2,k}$.
4. For any two distinct items **k** and **m**, their processing intervals on facility 1, $[S_{1,k}, C_{1,k})$, do not intersect.
5. For any two distinct items **k** and **m**, their processing intervals on facility 2, $[S_{2,k}, C_{2,k})$, do not intersect.

The plant is given a time parameter **T**. A schedule is successful if $C_{2,k} \le T + 1$ for all items **k**.

For every given input, it is guaranteed that no successful schedule exists. You must provide a short certificate proving this impossibility. Exactly one of the following two structural bottlenecks will apply, and you must output the corresponding certificate:

- `JOB i` (where **i** is the 1-based index of the item): Let $\Sigma_{\text{JOB}}(i)$ be the isolated subsystem formed by constraints (1), (2), and (3) for a specific item **i**. The projection of its valid solution space onto the $C_{2,i}$ coordinate forms a closed ray $[ \alpha_i, \infty )$. The certificate is valid if the infimum of this ray, $\alpha_i$, strictly exceeds $T + 1$. This bottleneck exists internally to the item, even if the non-intersection constraints (4) and (5) are completely ignored. If multiple items fit this description, you may output any one of them.
- `LOAD c` (where **c** is 1 or 2): Let $\Sigma_{\text{LOAD}}(c)$ be the isolated subsystem formed by constraints (1), (3), and the non-intersection constraint for facility **c** (constraint (4) if **c** = 1, or constraint (5) if **c** = 2) for all items. The projection of its valid solution space onto the coordinate representing $\max_k C_{c,k}$ forms a closed ray $[ \beta_c, \infty )$. The certificate is valid if the infimum of this ray, $\beta_c$, strictly exceeds $T + 1$. This bottleneck exists globally on the facility, even if constraint (2) and the other facility's constraints are completely ignored. If both facilities fit this description, you may output either one.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the processing duration of an item at stage 1 and stage 2, respectively.

## Output

Print a single line containing the certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, **T** = 100. The absolute deadline is $C_{2,k} \le 101$. For item 1, evaluating $\Sigma_{\text{JOB}}(1)$ (constraints 1, 2, and 3) yields a solution space where the projection onto $C_{2,1}$ is the ray $[131, \infty)$. Since the infimum $\alpha_1 = 131$ is strictly greater than 101, this forms a valid `JOB 1` certificate.

In Example 2, **T** = 150. The absolute deadline is $C_{2,k} \le 151$. No single item yields an $\alpha_i > 151$ under $\Sigma_{\text{JOB}}(i)$. However, evaluating $\Sigma_{\text{LOAD}}(1)$ (constraints 1, 3, and 4) yields a solution space where the projection onto $\max_k C_{1,k}$ is the ray $[201, \infty)$. Since the infimum $\beta_1 = 201$ is strictly greater than 151, this forms a valid `LOAD 1` certificate.
</STATEMENT>
<RATIONALE>
The exact constraints from the seed problem are preserved verbatim to ensure no numeric bounds or references are dropped, passing the gate checks. The descriptions of the `JOB i` and `LOAD c` certificates have been abstractly reframed using topological projections of the feasible regions (closed rays and infimums). This forces the models to algebraically derive that the infimums correspond to the sums of processing times, preventing them from bypassing the logic via surface-level pattern matching of "mathematically incompatible" wording.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical condition for the infimum of the closed ray to strictly exceed T + 1 is logically identical to the original condition of the constraint subsets being mathematically incompatible with C <= T + 1, ensuring all valid certificates remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class remains O(N) because the task still requires a single linear scan to compute the infimums (sums of processing times) and check if they exceed T + 1.
</PRESERVED_CLASS>
<RISK>
Models might struggle to correctly parse the mathematical notation of closed rays and infimums, potentially leading to confusion about which specific variables need to be summed to calculate alpha and beta.
</RISK>
