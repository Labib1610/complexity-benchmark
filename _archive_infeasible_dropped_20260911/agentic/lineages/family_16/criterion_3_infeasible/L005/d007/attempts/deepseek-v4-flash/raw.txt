We need to determine whether the impossibility of scheduling comes from a single job’s internal constraints or from the load on one of the two machines.  

For a **JOB i** certificate:  
- The earliest possible completion time for job i on machine 2 is `p1[i] + p2[i]` (since it must finish stage 1 before starting stage 2).  
- If `p1[i] + p2[i] > T + 1`, then that job alone makes scheduling impossible.  

For a **LOAD c** certificate:  
- For machine 1: the sum of all `p1` must be ≤ `T + 1`; if not, impossible.  
- For machine 2: the sum of all `p2` must be ≤ `T + 1`; if not, impossible.  

We check job certificates first, then load certificates.  

Here’s the implementation:  

```python
j, T = map(int, input().split())
p1 = []
p2 = []
for _ in range(j):
    a, b = map(int, input().split())
    p1.append(a)
    p2.append(b)

# Check JOB certificates
for i in range(j):
    if p1[i] + p2[i] > T + 1:
        print(f"JOB {i+1}")
        exit()

# Check LOAD certificates
if sum(p1) > T + 1:
    print("LOAD 1")
    exit()
if sum(p2) > T + 1:
    print("LOAD 2")
    exit()
```
