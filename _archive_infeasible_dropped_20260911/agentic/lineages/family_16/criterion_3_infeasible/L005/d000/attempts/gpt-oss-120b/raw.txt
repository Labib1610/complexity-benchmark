**Solution Explanation**

For every job we know the processing time on machine 1 (`p1`) and on machine 2
(`p2`).  
Two kinds of bottlenecks are possible, and the statement guarantees that **exactly
one** of them occurs.

* **JOB** – a single job needs more than `T` time in total (`p1+p2 > T`).
* **LOAD** – the sum of all processing times on a machine exceeds `T`.

The task is to find which case happens and output the required line.



--------------------------------------------------------------------

#### Algorithm
```
read j, T
total1 = total2 = 0
bad_job = None

for i = 1 … j
        read p1, p2
        if bad_job is None and p1 + p2 > T
                bad_job = i            # first job that is too long
        total1 += p1
        total2 += p2

if bad_job is not None
        print "JOB bad_job"
else if total1 > T
        print "LOAD 1"
else
        print "LOAD 2"
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm always prints the correct answer.

*Lemma 1*  
If there exists a job `k` with `p1_k + p2_k > T`, the algorithm prints  
`JOB k` (or another such job).

*Proof.*  
During the scan of the input, the algorithm checks the condition
`p1 + p2 > T` for each job.
The first job that satisfies it stores its index in `bad_job`.
If at least one such job exists, after the loop `bad_job` is not `None`,
so the algorithm prints `JOB bad_job`. ∎



*Lemma 2*  
If no job violates the deadline, then `bad_job` stays `None`.

*Proof.*  
The only assignment to `bad_job` occurs when a job fulfills the condition
`p1 + p2 > T`. By assumption no job fulfills it, therefore the assignment
never happens and `bad_job` remains `None`. ∎



*Lemma 3*  
If `bad_job` is `None`, the algorithm prints `LOAD 1` exactly when the total
processing time of machine 1 exceeds `T`, otherwise it prints `LOAD 2`.

*Proof.*  
When `bad_job` is `None` the algorithm reaches the `else` part.
There it compares `total1` with `T`. If `total1 > T` it prints `LOAD 1`,
otherwise it prints `LOAD 2`. By definition `total1` (resp. `total2`) is the
sum of all `p1` (resp. `p2`) values, i.e. the load of the corresponding machine. ∎



*Theorem*  
The algorithm outputs exactly the bottleneck described in the statement.

*Proof.*  
Two exhaustive cases:

1. **A job is too long.**  
   By definition such a job exists, therefore by Lemma&nbsp;1 the algorithm
   prints `JOB i` for some violating job `i`. This matches the required output.

2. **No job is too long.**  
   Then, by Lemma&nbsp;2, `bad_job` is `None`.  
   The problem guarantees that a machine overload exists, i.e.
   either `total1 > T` or `total2 > T` (but not both).  
   By Lemma&nbsp;3 the algorithm prints `LOAD 1` exactly in the first case,
   otherwise `LOAD 2`. Hence the printed line is the correct overload.

In every possible input exactly one of the two cases holds, so the algorithm
always prints the correct answer. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

The loop processes each of the `j` jobs once, performing only O(1) work.
```
Time   :  O(j)   ( ≤ 2·10⁵ )
Memory :  O(1)   (only a few integer variables)
```

--------------------------------------------------------------------

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    j = next(it)
    T = next(it)

    total1 = 0
    total2 = 0
    bad_job = None

    for idx in range(1, j + 1):
        p1 = next(it)
        p2 = next(it)
        if bad_job is None and p1 + p2 > T:
            bad_job = idx
        total1 += p1
        total2 += p2

    if bad_job is not None:
        sys.stdout.write(f"JOB {bad_job}")
    elif total1 > T:
        sys.stdout.write("LOAD 1")
    else:
        sys.stdout.write("LOAD 2")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
