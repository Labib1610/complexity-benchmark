**Solution Explanation**

For every job `i`

* it needs `p1[i]` time on machine 1,
* then `p2[i]` time on machine 2,
* machines work one job at a time.

The statement guarantees that **no schedule can finish all jobs before the deadline `T`**.
We have to output a short certificate that can be verified directly from the input.
Exactly one of the following reasons is true:

* **Routing delay** – there is a job `i` that already exceeds the deadline when it is the
  only job (`p1[i] + p2[i] > T`).  
  Certificate: `JOB i`.

* **Throughput saturation** – even if the precedence between the two stages is ignored,
  a machine would need more than `T` time to process all its jobs back‑to‑back.
  That is `sum(p1) > T` (machine 1) or `sum(p2) > T` (machine 2).  
  Certificate: `LOAD 1` or `LOAD 2`.

Because the input guarantees that at least one of the two reasons holds,
checking them in any order is sufficient.

--------------------------------------------------------------------

#### Algorithm
```
read j, T
total1 = 0
total2 = 0
for i = 1 .. j
        read p1, p2
        if p1 + p2 > T               # routing delay found
                output "JOB i" and stop
        total1 += p1
        total2 += p2
# no routing delay, therefore a load certificate must exist
if total1 > T
        output "LOAD 1"
else
        output "LOAD 2"   # total2 must be > T
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm always outputs a valid certificate.

---

**Lemma 1**  
If the algorithm outputs `JOB i`, then job `i` alone cannot finish before `T`.

*Proof.* The algorithm outputs `JOB i` only when `p1[i] + p2[i] > T`.  
Running only this job needs exactly `p1[i]` time on machine 1 and then `p2[i]` on
machine 2, i.e. `p1[i] + p2[i]` total time, which exceeds `T`. ∎



**Lemma 2**  
If the algorithm reaches the second phase (no `JOB` printed) then for every job `i`
`p1[i] + p2[i] ≤ T`.

*Proof.* The algorithm would have printed `JOB i` as soon as it saw a job with
`p1[i] + p2[i] > T`. Since it did not, all jobs satisfy the inequality. ∎



**Lemma 3**  
If the algorithm outputs `LOAD 1`, then machine 1 cannot finish all its work
before `T` even without precedence constraints.

*Proof.* `LOAD 1` is printed only when `total1 = Σ p1[i] > T`.  
Without precedence, the optimal schedule on a single machine is to process jobs
back‑to‑back, taking exactly `total1` time, which is larger than `T`. ∎



**Lemma 4**  
If the algorithm outputs `LOAD 2`, then machine 2 cannot finish all its work
before `T` even without precedence constraints.

*Proof.* Symmetric to Lemma&nbsp;3, using `total2 = Σ p2[i] > T`. ∎



**Theorem**  
The algorithm always prints a certificate that is correct for the given input.

*Proof.* Two cases.

1. The algorithm prints `JOB i`. By Lemma&nbsp;1 this certificate is valid.

2. The algorithm never prints `JOB`. By Lemma&nbsp;2 every job fits individually,
   therefore the impossibility of a full schedule must stem from a throughput
   limitation. The algorithm then checks the two machines.
   Because the problem guarantees that at least one reason holds, either
   `total1 > T` or `total2 > T`. The algorithm prints the corresponding `LOAD`
   line, which is valid by Lemma&nbsp;3 or Lemma&nbsp;4. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

The algorithm scans the input once.

*Time*: `O(j)`  
*Memory*: `O(1)` (only a few counters and the current job)

Both satisfy the limits (`j ≤ 200 000`).

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    j = int(next(it))
    T = int(next(it))

    total1 = 0
    total2 = 0

    for idx in range(1, j + 1):
        p1 = int(next(it))
        p2 = int(next(it))
        if p1 + p2 > T:
            sys.stdout.write(f"JOB {idx}\n")
            return
        total1 += p1
        total2 += p2

    if total1 > T:
        sys.stdout.write("LOAD 1\n")
    else:
        sys.stdout.write("LOAD 2\n")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms to the required input
