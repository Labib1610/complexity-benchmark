We can check both conditions efficiently:

- For `JOB i`: if `p1[i] + p2[i] > T`, that job alone cannot finish in time.
- For `LOAD c`: if the sum of all `p1` (for c=1) or all `p2` (for c=2) exceeds `T`, that facility alone cannot finish all jobs back-to-back.

We just need to find any valid certificate.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    j = int(data[0])
    T = int(data[1])
    
    total1 = 0
    total2 = 0
    idx = 2
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        total1 += p1
        total2 += p2
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
    
    if total1 > T:
        print("LOAD 1")
        return
    if total2 > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
