We can check both conditions:

1. **Routing Delay**: If any job has `p1 + p2 > T`, then even alone it can’t finish by `T`. Output `JOB i`.
2. **Throughput Saturation**: If the sum of all `p1` > `T`, station 1 is overloaded. If the sum of all `p2` > `T`, station 2 is overloaded. Output `LOAD c`.

Since the problem guarantees exactly one category applies, we can check in that order.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    idx = 2
    sum1 = 0
    sum2 = 0
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        sum1 += p1
        sum2 += p2
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
    if sum1 > T:
        print("LOAD 1")
        return
    if sum2 > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
