<STATEMENT>
# Problem C — Schedule Diagnostics

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing plant must route **j** jobs through two sequential processing stations. Every job must be fully processed at station 1 before it can be transferred to station 2. The required processing duration for each job at station 1 and station 2 is provided. A station can process only a single job at any given moment.

The plant operates under a strict completion deadline **T**. For a production run to be successful, all jobs must clear station 2 by time **T**.

For every given configuration, no valid schedule exists that can meet the deadline. You must provide a structural certificate proving this impossibility. Exactly one of the following two proof categories will apply to the configuration, and you must output the certificate for the uniquely applicable category:

- **Routing Delay:** Consider the theoretical scenario where a particular job is prioritized above all else. It is placed on the first station at time zero, and the moment it finishes it is immediately moved to the second station, which is kept completely clear for its arrival. If this flawless, zero-wait progression still results in the job clearing the second station after the deadline, it is impossible for the plant to succeed.
  Output format: `JOB i`, where **i** (1-based index) is the failing job. If multiple jobs fail this way, you may output any one of them.

- **Throughput Saturation:** Consider the theoretical scenario where a particular station is fed a continuous stream of work, starting at time zero. It suffers no starvation, never waits for the other station, and operates with absolutely no idle time until it has processed every job. If this perfectly continuous operation still leaves the station working after the deadline, the plant cannot possibly succeed.
  Output format: `LOAD c`, where **c** is the station number (1 or 2) that is saturated. If both stations are saturated, you may output either one.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the processing duration of a job at station 1 and station 2, respectively.

## Output

Print a single line containing the exact certificate for the uniquely applicable category: either `JOB i` for a routing delay or `LOAD c` for throughput saturation.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, if job 1 were prioritized with zero wait time, it would spend 70 time units on the first station and 60 on the second. It would finish at time 130, which falls after the deadline of 100. Thus, a routing delay certificate `JOB 1` is printed. 
In Example 2, no single job's zero-wait progression misses the deadline. However, if the first station runs continuously with no idle time, it will take 50+50+50+50 = 200 time units to clear its queue. This extends past the 150 deadline, so a throughput saturation certificate `LOAD 1` is printed.

The mathematical conditions required to trigger a `JOB` or `LOAD` certificate remain completely identical (p1+p2 > T, or sum(p) > T), ensuring the exact same certificate will be emitted for any given input.
</PRESERVED_ANSWER>
