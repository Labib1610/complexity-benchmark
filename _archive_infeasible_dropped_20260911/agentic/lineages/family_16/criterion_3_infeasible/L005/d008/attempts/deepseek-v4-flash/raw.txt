We can solve this by checking two conditions:

1. **JOB check**: For each item, if `p1 + p2 > T`, then even alone it can’t finish by `T+1` because the earliest possible finish is `1 + p1 + p2`.  
   If any such item exists, output `JOB i`.

2. **LOAD check**: If no job fails alone, check each facility separately.  
   For facility 1: total processing time of all items must be ≤ T, otherwise impossible to schedule all without overlap starting at time 1.  
   For facility 2: same check.  
   If either sum > T, output `LOAD c`.

Since the problem guarantees at least one bottleneck exists, one of these will trigger.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    items = []
    idx = 2
    for i in range(j):
        p1 = int(data[idx])
        p2 = int(data[idx+1])
        idx += 2
        items.append((p1, p2))
    
    # JOB check
    for i, (p1, p2) in enumerate(items, start=1):
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
    
    # LOAD check
    sum1 = sum(p1 for p1, _ in items)
    sum2 = sum(p2 for _, p2 in items)
    if sum1 > T:
        print("LOAD 1")
    elif sum2 > T:
        print("LOAD 2")

if __name__ == "__main__":
    main()
```
