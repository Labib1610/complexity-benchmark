<STATEMENT>
# Problem C — Schedule Diagnostics

Time limit: 2 s   Memory limit: 256 MB

## Description

We define a system of potentials $P(E)$ for a set of events $E$. A valid configuration must assign a finite real number $P(E) \ge 1$ to every event.

There are **j** items. For each item **k** (1 ≤ k ≤ j), there are two sequences of events:
- $U_{k,0}, U_{k,1}, \dots, U_{k,p_{1,k}}$
- $V_{k,0}, V_{k,1}, \dots, V_{k,p_{2,k}}$

A configuration is valid if it satisfies all of the following rules:
1. $P(U_{k,x}) \ge P(U_{k,x-1}) + 1$ for all **k** and all $1 \le x \le p_{1,k}$.
2. $P(V_{k,y}) \ge P(V_{k,y-1}) + 1$ for all **k** and all $1 \le y \le p_{2,k}$.
3. $P(V_{k,0}) \ge P(U_{k,p_{1,k}})$ for all **k**.
4. For any pair of distinct items **k** and **m**, either $P(U_{k,0}) \ge P(U_{m,p_{1,m}})$ or $P(U_{m,0}) \ge P(U_{k,p_{1,k}})$.
5. For any pair of distinct items **k** and **m**, either $P(V_{k,0}) \ge P(V_{m,p_{2,m}})$ or $P(V_{m,0}) \ge P(V_{k,p_{2,k}})$.

A configuration is successful if $P(V_{k,p_{2,k}}) \le T + 1$ for all items **k**.

For every given input, it is guaranteed that no successful configuration exists. You must provide a short certificate proving this impossibility. Exactly one of the following two structural bottlenecks will apply, and you must output the corresponding certificate:

- `JOB i` (where **i** is the 1-based index of the item): The subsystem consisting ONLY of the base requirement $P(E) \ge 1$ and rules 1, 2, and 3 for a specific item **i**. This subsystem alone forces $P(V_{i,p_{2,i}}) > T + 1$ (meaning every valid configuration of this subsystem has $P(V_{i,p_{2,i}}) > T + 1$). This bottleneck exists internally to the item, even if rules 4 and 5 (and the rules for all other items) are completely ignored. If multiple items fit this description, you may output any one of them.
- `LOAD c` (where **c** is 1 or 2): The subsystem consisting ONLY of the base requirement $P(E) \ge 1$, rule **c** for all items, and rule **c**+3 for all pairs of items. This subsystem alone forces the maximum potential among the events it references to strictly exceed $T + 1$. This bottleneck exists globally for the sequence **c**, even if rule 3 and the rules for the other sequence are completely ignored. If both **c**=1 and **c**=2 fit this description, you may output either one.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers $p_1$ and $p_2$ (1 ≤ $p_1$, $p_2$ ≤ 1000000): the sequence lengths $p_{1,k}$ and $p_{2,k}$ for item **k**.

## Output

Print a single line containing the certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, **T** = 100. The absolute limit is $T+1 = 101$.
For item 1, evaluating the subsystem of rules 1, 2, and 3 yields:
$P(U_{1,70}) \ge P(U_{1,0}) + 70 \ge 71$
$P(V_{1,0}) \ge P(U_{1,70}) \ge 71$
$P(V_{1,60}) \ge P(V_{1,0}) + 60 \ge 131$
Since $131 > 101$, this subsystem alone forces the potential to exceed $T+1$. This forms a valid `JOB 1` certificate.

In Example 2, **T** = 150. The limit is $151$.
No single item forces a potential > 151 under rules 1, 2, and 3.
However, evaluating the subsystem of rule 1 and rule 4 for all items:
Rule 4 requires that for any pair of items, one $U$ sequence must completely follow the other.
By rule 1, each sequence requires a potential difference of at least 50.
Since all potentials must be $\ge 1$, the maximum potential among these events across all 4 items must be at least $1 + 4 \times 50 = 201$.
Since $201 > 151$, this forms a valid `LOAD 1` certificate.
</STATEMENT>
<RATIONALE>
I changed the framing from a scheduling problem with start and completion times to a mathematical system of event potentials bounded by inequalities. This forces the model to deduce that the minimum maximum potential corresponds to a sum of sequence lengths, rather than relying on memorized scheduling formulas for job and machine bounds.
</RATIONALE>
<PRESERVED_ANSWER>
The inequalities for the event potentials mathematically map exactly to the original start-time and non-intersection constraints, meaning identical conditions trigger `JOB i` and `LOAD c`.
</PRESERVED_ANSWER>

The problem still asks to evaluate linear sums of given inputs against a threshold to certify infeasibility, which remains an O(j) check.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "the maximum potential among the events it references" if they fail to realize that rules 1 and 4 exclusively reference the $U$ events, and rules 2 and 5 exclusively reference the $V$ events.
</RISK>
