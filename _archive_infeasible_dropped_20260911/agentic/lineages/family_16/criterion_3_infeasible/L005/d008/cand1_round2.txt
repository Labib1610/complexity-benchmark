<METHOD_NAME>Set-Theoretic Bounding Intervals</METHOD_NAME>
<METHOD_DESCRIPTION>Replaced explicit algebraic subsystem bounds with set-theoretic bounding arguments on interval unions and convex hulls. This forces the model to geometrically deduce the algebraic sums rather than pattern-matching explicit formulas, while maintaining standard scheduling terminology.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem C — Schedule Diagnostics

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing plant must process **j** items through two sequential stages. A schedule assigns each item **k** a processing interval $A_{1,k}$ on facility 1 and a processing interval $A_{2,k}$ on facility 2.
Any valid schedule must satisfy the following constraints:
1. For each item **k** and facility **c**, the processing interval is a half-open interval $A_{c,k} = [S_{c,k}, C_{c,k})$ with $S_{c,k} \ge 1$.
2. For each item **k**, the length of $A_{1,k}$ is $p_{1,k}$, and the length of $A_{2,k}$ is $p_{2,k}$.
3. For each item **k**, stage 2 must not start until stage 1 has finished: $S_{2,k} \ge C_{1,k}$.
4. For each facility **c** $\in \{1, 2\}$, the intervals $A_{c,k}$ for all distinct items **k** are pairwise disjoint (a facility processes only one item at a time).

The plant is given a time parameter **T**. A schedule is successful if the supremum of all processing intervals across all items and facilities is at most $T + 1$.

For every given input, it is guaranteed that no successful schedule exists. You are not required to find a schedule; instead, you must output a short certificate proving this impossibility. Exactly one of the following two bounding arguments will apply, and you must output the corresponding certificate:

- `JOB i` (where **i** is the 1-based index of the item): Consider the smallest single contiguous interval that contains both $A_{1,i}$ and $A_{2,i}$ for a specific item **i**. Due to constraints (1), (2), and (3), the supremum (upper bound) of this encompassing interval has a minimum possible value, independent of any other items in the system. If this minimum possible value strictly exceeds $T + 1$, the item itself makes the schedule impossible. If multiple items fit this description, you may output any one of them.
- `LOAD c` (where **c** is 1 or 2): Consider the union $\bigcup_{k=1}^j A_{c,k}$ of all processing intervals on a specific facility **c**. Due to constraints (1), (2), and (4), the supremum of this union has a minimum possible value, independent of the other facility or the ordering of stages. If this minimum possible value strictly exceeds $T + 1$, the facility's workload makes the schedule impossible. If both facilities fit this description, you may output either one.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the processing duration of an item at stage 1 and stage 2, respectively.

## Output

Print a single line containing the certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, **T** = 100, meaning the absolute deadline for any processing is 101. For item 1, the intervals $A_{1,1}$ and $A_{2,1}$ have lengths 70 and 60. Because $A_{2,1}$ must strictly follow $A_{1,1}$ and neither can start before 1, the smallest contiguous interval containing both must have a length of at least 130 and start no earlier than 1. The supremum of this encompassing interval has a minimum possible value of 131. Since 131 strictly exceeds 101, this forms a valid `JOB 1` certificate.

In Example 2, **T** = 150, meaning the absolute deadline is 151. No single item has an encompassing interval whose minimum supremum exceeds 151. However, on facility 1, the intervals $A_{1,k}$ for the 4 items have lengths 50, 50, 50, and 50. Because they are pairwise disjoint and none can start before 1, their union has a total length of 200. The supremum of any set of non-overlapping intervals starting at or after 1 with a total length of 200 must be at least 201. Since 201 strictly exceeds 151, this forms a valid `LOAD 1` certificate.
</STATEMENT>
<RATIONALE>
I removed the explicit formulas and closed-ray projections that allowed models to directly compute the bounds via pattern matching. By framing the bottlenecks as the minimum possible suprema of interval unions and convex hulls, models must logically deduce that these translate to the sum of processing times and the sum of an item's stages, respectively.
</RATIONALE>
<PRESERVED_ANSWER>
The minimum supremum of the encompassing interval for item i is exactly 1 + p1_i + p2_i, and for the union on facility c is exactly 1 + sum(p_c), which are mathematically identical to the seed's subsystem bounds.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The required checks remain a linear scan to find an item where p1 + p2 > T or a facility where sum(p) > T, keeping the problem in O(N) time.
</PRESERVED_CLASS>
<RISK>
Models or users might misinterpret "smallest single contiguous interval that contains both" if they don't grasp that it spans the gap between the intervals, but the definition is standard and the example clarifies the length calculation.
</RISK>
