We can check each condition efficiently without constructing schedules.

For **JOB i**:
- If `p1 + p2 > T + 1`, then that job alone cannot finish by the deadline.

For **LOAD c**:
- If the sum of all `p1` or sum of all `p2` exceeds `T + 1`, then that facility would be overloaded.

We just check both conditions.  

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    j = int(next(it))
    T = int(next(it))
    deadline = T + 1
    
    sum1 = 0
    sum2 = 0
    jobs = []
    for i in range(1, j + 1):
        p1 = int(next(it))
        p2 = int(next(it))
        jobs.append((p1, p2))
        sum1 += p1
        sum2 += p2
    
    # Check JOB condition
    for idx, (p1, p2) in enumerate(jobs, start=1):
        if p1 + p2 > deadline:
            print(f"JOB {idx}")
            return
    
    # Check LOAD condition
    if sum1 > deadline:
        print("LOAD 1")
        return
    if sum2 > deadline:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
