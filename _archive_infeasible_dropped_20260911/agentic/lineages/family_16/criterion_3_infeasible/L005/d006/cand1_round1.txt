<METHOD_NAME>Constraint Incompatibility Framing</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces hypothetical procedural descriptions with formal scheduling constraints, defining the certificates as identifying specific subsets of constraints that are mathematically incompatible with the deadline. This forces models to algebraically deduce the threshold conditions (p1+p2 > T and sum(p_c) > T) from first principles rather than pattern-matching "routing delay" or "throughput saturation" to simple sums.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem C — Schedule Diagnostics

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing plant must process **j** items through two sequential stages. A schedule assigns each item **k** a start time $S_{1,k}$ on facility 1 and a start time $S_{2,k}$ on facility 2.
Any valid schedule must satisfy the following constraints:
1. $S_{1,k} \ge 1$ and $S_{2,k} \ge 1$ for all **k**.
2. $S_{2,k} \ge S_{1,k} + p_{1,k}$ for all **k** (stage 2 cannot start until stage 1 finishes).
3. The completion time of item **k** on stage 1 is $C_{1,k} = S_{1,k} + p_{1,k}$, and on stage 2 is $C_{2,k} = S_{2,k} + p_{2,k}$.
4. For any two distinct items **k** and **m**, their processing intervals on facility 1, $[S_{1,k}, C_{1,k})$, do not intersect.
5. For any two distinct items **k** and **m**, their processing intervals on facility 2, $[S_{2,k}, C_{2,k})$, do not intersect.

The plant is given a time parameter **T**. A schedule is successful if $C_{2,k} \le T + 1$ for all items **k**.

For every given input, it is guaranteed that no successful schedule exists. You must provide a short certificate proving this impossibility. Exactly one of the following two reasons will apply, and you must output the corresponding certificate:

- `JOB i` (where **i** is the 1-based index of the item): The subset of constraints (1), (2), and (3) alone are mathematically incompatible with $C_{2,i} \le T + 1$ for a specific item **i**, even if the non-intersection constraints (4) and (5) are completely ignored. If multiple items fit this description, you may output any one of them.
- `LOAD c` (where **c** is 1 or 2): The subset of constraints (1), (3), and the non-intersection constraint for facility **c** (constraint (4) if **c** = 1, or constraint (5) if **c** = 2) are mathematically incompatible with $C_{c,k} \le T + 1$ for all **k**, even if constraint (2) and the other facility's constraints are completely ignored. If both facilities fit this description, you may output either one.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the processing duration of an item at stage 1 and stage 2, respectively.

## Output

Print a single line containing the certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, **T** = 100. The absolute deadline is $C_{2,k} \le 101$. For item 1, any assignment of start times satisfying constraints (1), (2), and (3) will force $C_{2,1} \ge 131$. Since $131 > 101$, this is mathematically incompatible with the deadline. Thus, `JOB 1` is printed. 

In Example 2, **T** = 150. The absolute deadline is $C_{2,k} \le 151$. No single item violates the deadline under constraints (1)-(3) alone. However, considering facility 1 and ignoring constraint (2) and facility 2: any assignment satisfying constraints (1), (3), and (4) forces the maximum completion time on facility 1 to be at least 201. Since $201 > 151$, this is incompatible with $C_{1,k} \le 151$ for all **k**. Thus, `LOAD 1` is printed.
</STATEMENT>
<RATIONALE>
I reframed the hypothetical delay and saturation scenarios as formal constraint incompatibility problems. This forces the model to deduce the algebraic conditions (p1+p2 > T and sum(p_c) > T) from the definitions of the constraint subsets rather than pattern-matching descriptive text.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical conditions for constraints (1)-(3) to be incompatible with C2 <= T+1 is exactly p1+p2 > T, and for constraints (1), (3), (4/5) to be incompatible with Cc <= T+1 is exactly sum(p_c) > T, which perfectly match the original criteria.
</PRESERVED_ANSWER>

The problem still asks for an O(N) verification of either a single job's sequential processing time or a single facility's total workload exceeding the time bound, keeping it in the same complexity class.
</PRESERVED_CLASS>
