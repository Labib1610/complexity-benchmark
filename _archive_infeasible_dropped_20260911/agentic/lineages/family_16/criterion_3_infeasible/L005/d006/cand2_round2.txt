# Problem C — Schedule Diagnostics

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing plant must process **j** items through two sequential stages. Every item must fully complete stage 1 at the first facility before it can advance to stage 2 at the second facility. The required processing duration for each item at stage 1 and stage 2 is provided. A facility can process only a single item at any given moment.

The input provides an integer parameter **T**, representing the absolute deadline for the production run. A schedule is only successful if all items clear stage 2 within a total time window of **T**.

For every given input, no valid schedule exists that can meet this deadline. You must provide a short certificate proving this impossibility. You are not asked to construct a schedule; only output a certificate that can be checked directly from the input parameters.

Let $P$ be a sequence of $j$ vectors in $\mathbb{Z}^2$, where the $i$-th vector $P_i = (p_{i,1}, p_{i,2})$ represents the processing durations of item $i$ (1-based index) at stage 1 and stage 2, respectively. Because durations are strictly positive, all vectors lie in the first quadrant.

Exactly one of the following two fundamental capacity violations will apply, and you must output the corresponding certificate:

- **Routing Delay:** If the $L_1$ norm of the vector $P_i$ strictly exceeds **T**, output `JOB i`. If multiple items satisfy this, you may output any one of them.

- **Throughput Saturation:** Let $V_c$ be the projection of the entire sequence $P$ onto the $c$-th coordinate axis, forming a single vector of $j$ components. If the $L_1$ norm of $V_c$ strictly exceeds **T**, output `LOAD c` (where $c \in \{1, 2\}$). If both facilities satisfy this, you may output either one.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the processing duration of an item at stage 1 and stage 2, respectively.

## Output

Print a single line containing the certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, **T** = 100. The duration vectors are $P_1 = (70, 60)$, $P_2 = (2, 2)$, and $P_3 = (3, 4)$. The $L_1$ norm of $P_1$ is $|70| + |60| = 130$. Since 130 strictly exceeds the deadline **T** = 100, a routing delay certificate `JOB 1` is printed. 

In Example 2, **T** = 150. No individual item has an $L_1$ norm exceeding 150 (each is $|50| + |1| = 51$). However, projecting the sequence onto the first coordinate axis gives $V_1 = (50, 50, 50, 50)$. The $L_1$ norm of $V_1$ is $|50| + |50| + |50| + |50| = 200$. Since 200 strictly exceeds **T** = 150, a throughput saturation certificate `LOAD 1` is printed.
