<STATEMENT>
# Problem C — Schedule Diagnostics

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing plant must process **j** items through two sequential stages. A schedule assigns each item **k** a start time $S_{1,k}$ on facility 1 and a start time $S_{2,k}$ on facility 2.
Any valid schedule must satisfy the following constraints:
1. **Earliest start:** $S_{1,k} \ge 1$ and $S_{2,k} \ge 1$ for all **k**.
2. **Sequential flow:** $S_{2,k} \ge S_{1,k} + p_{1,k}$ for all **k** (stage 2 cannot start until stage 1 finishes).
3. **Durations:** The processing interval of item **k** on facility 1 is $[S_{1,k}, C_{1,k})$ where $C_{1,k} = S_{1,k} + p_{1,k}$, and on facility 2 is $[S_{2,k}, C_{2,k})$ where $C_{2,k} = S_{2,k} + p_{2,k}$.
4. **No overlap on facility 1:** For any two distinct items **k** and **m**, their processing intervals on facility 1 do not intersect.
5. **No overlap on facility 2:** For any two distinct items **k** and **m**, their processing intervals on facility 2 do not intersect.

The plant is given an operational calendar represented by the interval $[1, T+1)$, which has a total measure of **T**. A schedule is successful if all processing intervals on both facilities are entirely contained within this operational calendar.

For every given input, it is guaranteed that no successful schedule exists. You must provide a short certificate proving this impossibility. Exactly one of the following two structural bottlenecks will apply, and you must output the corresponding certificate:

- `JOB i` (where **i** is the 1-based index of the item): This certificate is valid if the minimum possible scalar distance between $S_{1,i}$ and $C_{2,i}$, dictated purely by the item's own durations and sequential flow constraints, strictly exceeds the measure of the operational calendar. If multiple items fit this description, you may output any one of them.
- `LOAD c` (where **c** is 1 or 2): This certificate is valid if the required total measure of the union of all items' processing intervals on facility **c**, dictated by their individual durations and the non-overlap constraint, strictly exceeds the measure of the operational calendar. If both facilities fit this description, you may output either one.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the processing duration of an item at stage 1 and stage 2, respectively.

## Output

Print a single line containing the certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, the operational calendar has measure 100. For item 1, the minimum possible scalar distance between $S_{1,1}$ and $C_{2,1}$ is 130 (since its stage 1 duration is 70, its stage 2 duration is 60, and stage 2 must follow stage 1). Because 130 strictly exceeds 100, `JOB 1` is a valid certificate.

In Example 2, the operational calendar has measure 150. On facility 1, there are 4 items each requiring an interval of duration 50. Because these intervals cannot overlap, the total measure of their union must be exactly 200. Since 200 strictly exceeds the operational calendar's measure of 150, `LOAD 1` is a valid certificate.
</STATEMENT>
<RATIONALE>
Replaced the explicit "relaxed scenario" descriptions with equivalent properties of interval sets to prevent pattern matching. `JOB i` is now defined as the minimum scalar distance between endpoints exceeding the calendar, forcing the deduction that this distance is $p_1 + p_2$. `LOAD c` is defined as the total measure of the union of disjoint intervals exceeding the calendar, forcing the deduction that this measure is the sum of durations.
</RATIONALE>
<PRESERVED_ANSWER>
The minimum scalar distance between endpoints is mathematically identical to $p_1 + p_2$, and the total measure of the union of disjoint intervals is exactly the sum of their durations, meaning the conditions for the certificates are unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains an $O(N)$ impossibility certification task where the algorithm must check single-job sequential bounds and single-facility serial bounds.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "scalar distance between $S_{1,i}$ and $C_{2,i}$" as requiring actual schedule construction rather than a theoretical lower bound, though "minimum possible... dictated purely by the item's own durations" clarifies it is a static property of the job.
</RISK>
