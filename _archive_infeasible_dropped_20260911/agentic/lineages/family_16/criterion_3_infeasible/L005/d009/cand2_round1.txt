<STATEMENT>
# Problem C — Schedule Diagnostics

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing plant must process a set of items $J = \{1, 2, \dots, j\}$ through two sequential stages. A schedule assigns each item $k \in J$ a half-open processing interval $I_{1,k} = [S_{1,k}, C_{1,k})$ on facility 1 and a half-open processing interval $I_{2,k} = [S_{2,k}, C_{2,k})$ on facility 2.

Any valid schedule must satisfy the following constraints:
1. **Domain:** For all $k \in J$, both intervals $I_{1,k}$ and $I_{2,k}$ must be sub-intervals of the available time window $[1, T+1]$.
2. **Durations:** For all $k \in J$, the length of $I_{1,k}$ is exactly $p_{1,k}$ (i.e., $C_{1,k} - S_{1,k} = p_{1,k}$), and the length of $I_{2,k}$ is exactly $p_{2,k}$.
3. **Sequential Flow:** For all $k \in J$, the interval $I_{2,k}$ is positioned entirely after $I_{1,k}$ (specifically, $S_{2,k} \ge C_{1,k}$).
4. **Facility 1 Isolation:** For any two distinct items $k, m \in J$, their intervals on facility 1 do not intersect ($I_{1,k} \cap I_{1,m} = \emptyset$).
5. **Facility 2 Isolation:** For any two distinct items $k, m \in J$, their intervals on facility 2 do not intersect ($I_{2,k} \cap I_{2,m} = \emptyset$).

For every given input, it is guaranteed that no valid schedule exists. You must provide a short certificate proving this impossibility. Exactly one of the following two structural bottlenecks will apply, and you must output the corresponding certificate:

- `JOB i` (where $i \in J$): The system of constraints formed by rules 1, 2, and 3 is intrinsically inconsistent when restricted to the single item $i$. If multiple items fit this description, you may output any one of them.
- `LOAD c` (where $c \in \{1, 2\}$): The system of constraints formed by rules 1, 2, and the isolation rule for facility $c$ (rule 4 for $c=1$, rule 5 for $c=2$) is intrinsically inconsistent when applied to the entire set $J$. If both facilities fit this description, you may output either one.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the processing duration of an item at stage 1 and stage 2, respectively. Items are implicitly numbered 1 to **j**.

## Output

Print a single line containing the certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, **T** = 100. For item 1, the domain is $[1, 101]$. The sequential flow constraint forces $S_{2,1} \ge C_{1,1}$. Given the durations of 70 and 60, satisfying this ordering within the allowed domain is mathematically impossible. Thus, `JOB 1` proves the inconsistency.

In Example 2, **T** = 150. The domain is $[1, 151]$. For facility 1, the isolation constraint requires $I_{1,1}, I_{1,2}, I_{1,3}, I_{1,4}$ to be mutually disjoint. Since each has a duration of 50, no arrangement of these disjoint subsets can exist entirely within a domain of measure 150. Thus, `LOAD 1` proves the inconsistency.
</STATEMENT>
<RATIONALE>
Replaced the explicit relaxed-scenario narratives with formal mathematical constraint-satisfiability queries on sets of half-open intervals. This forces models to deduce the arithmetic implications of interval packing (that the sum of lengths cannot exceed the bounding interval) and sequential ordering, effectively masking the simple `p1+p2 > T` and `sum(p) > T` checks behind semantic constraint logic.
</RATIONALE>
<PRESERVED_ANSWER>
The satisfiability of the isolated job constraints is mathematically identical to $p_1+p_2 \le T$, and the satisfiability of the isolated facility constraints is identical to $\sum p \le T$, preserving all original certificate conditions exactly.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains an impossibility certification task (co-NP style) where the bottlenecks are still found in $O(N)$ time by checking linear sums, unchanged from the seed.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "intrinsically inconsistent" or fail to realize that intervals can be packed back-to-back with zero gaps, though standard mathematical definitions of interval subsets and non-intersection imply this.
</RISK>
