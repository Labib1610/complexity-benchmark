We can check two things:

1. **JOB i**: For a single item, the earliest it can finish on facility 1 is at time `1 + p1`. Then facility 2 must start at or after that, and finish by `T+1`. So we need `1 + p1 + p2 <= T+1`, i.e. `p1 + p2 <= T`. If not, that item is impossible alone.

2. **LOAD c**: For facility 1, the sum of all `p1` must be ≤ T, because they must be disjoint within a window of length T. Similarly for facility 2, sum of all `p2` must be ≤ T.

If any job fails the single-job check, output `JOB i`.  
Otherwise, if the sum for facility 1 exceeds T, output `LOAD 1`.  
Otherwise, if the sum for facility 2 exceeds T, output `LOAD 2`.

Here’s the implementation:

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    p1_list = []
    p2_list = []
    idx = 2
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        p1_list.append(p1)
        p2_list.append(p2)
        if p1 + p2 > T:
            print(f"JOB {i}")
            return

    if sum(p1_list) > T:
        print("LOAD 1")
        return
    if sum(p2_list) > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
