<STATEMENT>
# Problem C — Insufficient Window: Provide Proof

Time limit: 2 s   Memory limit: 256 MB

## Description

An airport must clear **j** flights through exactly **two** facilities. Every flight is processed at the de-icing pad (facility 1) first and then at the runway (facility 2). Each facility can handle only one flight at a time, and a flight reaches facility 2 only after finishing at facility 1. For each flight you are given its required time at facility 1 and at facility 2.

There is a strict weather window **T**: every flight must be completely finished by time **T**.

For every input in this problem it is **guaranteed that the window cannot be met**, no matter how the flights are ordered. 

If some flight's two processing times add up to more than **T**, that flight alone (facility 1 then facility 2, in sequence) cannot finish by **T**. In this case, a single flight is too long.
Alternatively, a facility runs flights one at a time, so it needs at least the sum of all its processing times. If the total work at facility 1 (or facility 2) exceeds **T**, the window is impossible. In this case, a facility is overloaded.

Your task is not to search for a schedule; it is to **prove** the window is impossible with a short certificate that can be checked directly against the input. Exactly one of the reasons above always applies. Print the one that holds:

- `JOB i` — where **i** (1-based) is a flight (logged as a JOB in the system) whose two processing times add up to more than **T**.
- `LOAD c` — where **c** is 1 or 2 and the total processing time at facility **c** exceeds **T**.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the processing times of a flight at facility 1 and facility 2.

## Output

Print a single line: `JOB i` (a flight whose p1 + p2 exceeds T) or `LOAD c` (a facility c whose total load exceeds T).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, flight 1 needs 70 + 60 = 130 > 100 time units in sequence, so `JOB 1` proves the window is impossible. In Example 2 no single flight exceeds 150, but facility 1 must process 50+50+50+50 = 200 > 150 units of work in total, so `LOAD 1` is the certificate.
