# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing facility processes **j** distinct items. The production of each item involves exactly two sequential stages: it must first undergo preparation at stage 1, and upon completion, undergo finishing at stage 2. You are provided the duration required for each stage per item. Equipment at any stage can handle at most one item at any given moment.

The facility operates for a single shift of duration **T**. All items must be completely processed before the shift ends.

You are tasked with auditing production logs from failed facilities. For each log, the required production cannot possibly be completed within the shift, regardless of how the items are ordered. Your objective is to generate a concise certificate that definitively proves the impossibility of the schedule. 

A valid certificate isolates a violation of a physical constraint. The provided logs are structurally guaranteed to exhibit exactly one of the following violations:

- `JOB i` — The **i**-th item (1-indexed) requires a sequential chain of operations whose combined duration strictly exceeds the shift length.
- `LOAD c` — The equipment at stage **c** (where **c** is 1 or 2) is assigned a total active duration across all items that strictly exceeds the shift length.

Identify and print the single certificate that applies to the given log.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the duration required for the item at stage 1 and stage 2, respectively.

## Output

Print a single line containing the applicable certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

<RATIONALE>
Removed the explicit algebraic formulas (`p1 + p2 > T` and `sum(p1) > T`) and the hand-holding "Note" section that provided step-by-step arithmetic for the examples. Models must now map the physical descriptions ("sequential chain of operations whose combined duration", "total active duration across all items") to the correct column and row summations.
</RATIONALE>
<PRESERVED_ANSWER>
The conditions for outputting a `JOB` or `LOAD` certificate remain mathematically identical to checking if a row sum exceeds T or a column sum exceeds T.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains a simple O(N) verification task where the algorithm iterates through the input to check row sums and accumulates column sums.
</PRESERVED_CLASS>
<RISK>
Models or readers might misinterpret "combined duration" as including both stages for all items, but the specification "The i-th item ... sequence of operations" clarifies it applies to a single item's stages.
</RISK>
