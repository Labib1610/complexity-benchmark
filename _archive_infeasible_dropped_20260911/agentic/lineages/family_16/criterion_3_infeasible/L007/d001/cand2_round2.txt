# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A facility must complete **j** commissions. Each commission goes through exactly 2 stages. Every commission must be fully processed in stage 1 before it can proceed to stage 2. The facility can only process one commission at a time per stage. You are provided the duration each commission requires in stage 1 and stage 2.

The facility operates under a strict timeframe: all commissions must be entirely completed by time **T**.

For every input in this problem it is guaranteed that the timeframe cannot be met, regardless of how the commissions are ordered. 

You must output a short certificate proving the timeframe cannot be met. The inputs are structured so that a unique certificate from the options below will demonstrate this impossibility:

- A single commission requires a total duration (stage 1 duration plus stage 2 duration) strictly greater than **T**. Since it must be processed sequentially, this commission alone cannot finish in time. In this case, output `JOB i`, where **i** is the 1-based index of the commission.
- A stage is overloaded. Since a stage processes commissions one by one, it requires at least the sum of all durations assigned to it. If the sum of durations for all commissions in stage 1 (or stage 2) is strictly greater than **T**, output `LOAD c`, where **c** is the stage number (1 or 2).

## Input

The first line provides the number of commissions **j** and the timeframe **T**. The value of **j** is at least 1 and is bounded by the facility's maximum capacity of 200000 commissions. The timeframe **T** is between 1 and a maximum system limit of 1000000000.

This is followed by **j** lines, each containing two integers **p1** and **p2**: the durations for that commission in stage 1 and stage 2, respectively. Each duration is at least 1 and is capped by the stage limit of 1000000.

## Output

Output a single line containing the unique valid certificate for the input: either `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, commission 1 requires 70 + 60 = 130 time units. Since 130 > 100, `JOB 1` proves the timeframe is impossible. In Example 2, no single commission exceeds 150, but stage 1 must process 50+50+50+50 = 200 > 150 units of work in total, so `LOAD 1` is the certificate.
