# Problem C — Impossible Threshold: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A processing facility routes $j$ tasks through exactly two sequential stages. Every task must be fully processed in stage 1 before it can advance to stage 2. For each task, you are provided its required duration in stage 1 and stage 2. Each stage can handle only one task at any given moment, and a task only occupies stage 2 after its stage 1 operations are complete.

A strict temporal threshold $T$ is in effect: every task must completely finish both stages before $T$ time units have elapsed.

For every input evaluated, it is categorically assured that the threshold cannot be met, regardless of how the tasks are sequenced. 

If a task's two durations sum to a value strictly greater than $T$, that task alone (progressing through stage 1 then stage 2) cannot finish within $T$. In this scenario, a single task is too lengthy.
Alternatively, since a stage processes tasks sequentially, it requires an active period at least equal to the sum of all its assigned durations. If the aggregate duration for stage 1 (or stage 2) strictly exceeds $T$, the threshold is impossible. In this scenario, a stage is overburdened.

Your objective is not to search for a valid sequence; it is to prove the threshold is impossible with a concise certificate that can be verified directly against the input. Exactly one of the reasons above always applies. Print the one that holds:

- `JOB i` — where $i$ (1-based) is a task whose two durations add up to more than $T$.
- `LOAD c` — where $c$ is 1 or 2 and the aggregate duration on stage $c$ exceeds $T$.

## Input

The first line provides $j$ and $T$. The maximum number of tasks $j$ is bounded by a facility headcount of 200000, and $T$ by a maximum lifespan of 1000000000 ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the subsequent $j$ lines details a task, providing two integers $p_1$ and $p_2$, bounded by a single-stage endurance limit of 1000000 ($1 \le p_1, p_2 \le 1000000$).

## Output

Print a single line: `JOB i` (a task whose $p_1 + p_2$ exceeds $T$) or `LOAD c` (a stage $c$ whose aggregate load exceeds $T$).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, task 1 requires 70 + 60 = 130 > 100 time units sequentially, so `JOB 1` proves the threshold is impossible. In Example 2, no single task exceeds 150, but stage 1 must process 50+50+50+50 = 200 > 150 units of work in total, so `LOAD 1` is the certificate.
