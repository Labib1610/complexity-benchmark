<STATEMENT>
# Problem C — Impossible Function Spaces: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A mathematical analysis tool must construct $2j$ measurable functions over the real numbers. For each item $i \in \{1 \dots j\}$, the system must find two functions, $f_{i,1}$ and $f_{i,2}$.

Each constructed function $f_{i,c}$ (for $i \in \{1 \dots j\}$ and $c \in \{1, 2\}$) must satisfy $0 \le f_{i,c}(x) \le 1$ for all $x \in \mathbb{R}$. The functions must strictly satisfy three constraints:

1. **Domain and Area:** For all $i$ and $c$, $f_{i,c}(x) = 0$ for all $x \notin [0, T]$. Furthermore, its Lebesgue integral over the real line must exactly equal the required target: $\int_{-\infty}^{\infty} f_{i,c}(x) dx = p_{i,c}$.
2. **Integral Precedence:** For every item $i$, the first function must strictly precede the second in the sense that $\int_{-\infty}^{\infty} f_{i,1}(x) \left( \int_{-\infty}^x f_{i,2}(t) dt \right) dx = 0$.
3. **Pairwise Orthogonality:** For a fixed component index $c \in \{1, 2\}$, the functions across all $j$ items must be orthogonal. That is, for any distinct items $i \neq m$, the product $f_{i,c}(x) \cdot f_{m,c}(x) = 0$ for almost all $x \in \mathbb{R}$ (equivalently, $\int_{-\infty}^{\infty} f_{i,c}(x) f_{m,c}(x) dx = 0$).

You are writing a verification tool that checks certificates of impossibility. A certificate proves that no valid functions can be constructed. Exactly one of the following two types of impossibility certificates will be valid for each input:
- `JOB i` : The target values $p_{i,1}$ and $p_{i,2}$ for item **i** (1-indexed) inherently contradict the Domain and Area and Integral Precedence constraints. No such pair of functions exists for this item in isolation.
- `LOAD c` : The target values $p_{1,c}, \dots, p_{j,c}$ for component **c** inherently contradict the Domain and Area and Pairwise Orthogonality constraints. No such set of $j$ functions exists for this component in isolation.

Output the single valid certificate for the testcase.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required integrals $p_{i,1}$ and $p_{i,2}$ for function 1 and function 2 of the item, respectively.

## Output

Print a single line containing the applicable certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

By mapping the problem to the construction of Lebesgue-measurable functions bounded by 1, the non-overlap constraint becomes orthogonality ($f \cdot g = 0$) and the sequence constraint becomes an integral equation ($\int f_1 F_2 = 0$). Models must now analytically prove that these functional constraints imply the $L^1$ bounds $p_1 + p_2 \le T$ and $\sum p \le T$ rather than triggering on surface-level scheduling keywords.
</RATIONALE>
<PRESERVED_ANSWER>
Because $0 \le f \le 1$, the integral precedence constraint rigorously forces the supports of an item's two functions to be disjoint and ordered, yielding the maximum possible combined integral $T$ (so $p_1 + p_2 \le T$). Similarly, the orthogonality constraint forces the sum of component integrals to be bounded by $T$, maintaining exactly the same impossibility thresholds as the seed.
</PRESERVED_ANSWER>
