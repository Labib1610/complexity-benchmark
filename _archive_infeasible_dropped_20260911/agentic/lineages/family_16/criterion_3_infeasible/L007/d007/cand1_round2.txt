<STATEMENT>
# Problem C — Impossible Domains: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A digital signal processing system must synthesize $2j$ continuous-time signal components. For each item $i \in \{1 \dots j\}$, the system must determine real-valued start times $k_{i,1}$ and $k_{i,2}$ to trigger two components. Once triggered at time $k_{i,c}$, component $c$ of item $i$ outputs a constant power of $s_{i,c}(t) = 1$ until it has emitted exactly $p_{i,c}$ units of energy, after which $s_{i,c}(t) = 0$. Prior to $k_{i,c}$, $s_{i,c}(t) = 0$.

Let $E_{i,c}(t) = \int_{-\infty}^{t} s_{i,c}(x) dx$ denote the cumulative energy delivered by component $c$ of item $i$ up to time $t$. The synthesized signals must strictly satisfy three constraints:

1. **Global Timeframe**: All energy must be delivered within the system's operational window $[0, T]$. Formally, for all $i$ and $c$, $E_{i,c}(0) = 0$ and $E_{i,c}(T) = p_{i,c}$.
2. **Causal Precedence**: For every item $i$, component 2 cannot begin delivering energy until component 1 has fully delivered its energy. Formally, for any time $t$, if $E_{i,2}(t) > 0$, then it must be that $E_{i,1}(t) = p_{i,1}$.
3. **Channel Exclusivity**: For a fixed component $c \in \{1, 2\}$, the instantaneous sum of the signals across all $j$ items cannot exceed 1 at any time $t$. Consequently, for any observation interval $[t_1, t_2]$, the total energy delivered by component $c$ across all items, $\sum_{i=1}^j (E_{i,c}(t_2) - E_{i,c}(t_1))$, cannot exceed $t_2 - t_1$.

You are analyzing logs from failed systems where a valid complete assignment of start times is mathematically impossible. For every provided test case, exactly one of the following isolated conditions is inherently impossible to satisfy. Output the code for the one that applies:
- `JOB i` — It is mathematically impossible to find start times $k_{i,1}$ and $k_{i,2}$ such that the signals for item **i** (1-indexed) simultaneously satisfy Global Timeframe and Causal Precedence, even if we completely ignore Channel Exclusivity and all other items.
- `LOAD c` — It is mathematically impossible to find start times $k_{1,c}, \dots, k_{j,c}$ such that the signals for component **c** (where **c** $\in \{1, 2\}$) simultaneously satisfy Global Timeframe and Channel Exclusivity, even if we completely ignore Causal Precedence and the other component.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required energy totals $p_{i,1}$ and $p_{i,2}$ for component 1 and component 2 of the item, respectively.

## Output

Print a single line containing the applicable certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

<RATIONALE>
Removed the explicit geometric interval notation `[k, k+W]` and direct text about orthogonal multiplexing that allowed models to instantly recognize the problem as trivial 1D interval packing. Instead, the signals are defined implicitly via their cumulative energy delivery over time. The constraints are recast as bounds on these integrals (e.g., causal precedence via $E(t)$ implications, and exclusivity via bounds on energy increments). This forces models to genuinely deduce the underlying `p1 + p2 > T` and `sum(p) > T` inequalities from the continuous integration constraints rather than relying on surface pattern matching of scheduling/interval terminology.
</RATIONALE>
<PRESERVED_ANSWER>
Because a signal outputting a constant power of 1 until $p_{i,c}$ energy is delivered is mathematically identical to a rectangular pulse of width $p_{i,c}$, the conditions under which the integral constraints become impossible are exactly the same as the original Bounded Support, Non-negative Lag, and Orthogonal Multiplexing constraints, ensuring all outputs remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires identifying which of the two linear constraints ($p_{i,1} + p_{i,2} \le T$ or $\sum p_{i,c} \le T$) is violated, keeping it exactly in the same $O(j)$ impossibility certification class.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the constraint "the instantaneous sum of the signals... cannot exceed 1" as allowing fractional signal values, but the statement explicitly defines $s_{i,c}(t)$ as exactly 1 during its active phase and 0 otherwise, making this rigorously unambiguous.
</RISK>
