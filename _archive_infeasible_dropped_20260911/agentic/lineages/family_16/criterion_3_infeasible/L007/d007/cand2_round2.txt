# Problem C — Impossible Projections: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A graphics engine must place $j$ bounding boxes into a 2D space. However, instead of managing full 2D boxes, the engine only manages their 1D projections on the X and Y axes. 

For each item $i \in \{1 \dots j\}$, you must assign a 1D segment on the X-axis of length $p_{i,1}$ (starting at coordinate $x_i$) and a 1D segment on the Y-axis of length $p_{i,2}$ (starting at coordinate $y_i$). 

The placement must strictly satisfy three constraints:
1. **Grid Bounds:** All segments must lie entirely within the coordinate range $[0, T]$. Specifically, for all $i$, the X-segment $[x_i, x_i + p_{i,1}]$ must be within $[0, T]$, and the Y-segment $[y_i, y_i + p_{i,2}]$ must be within $[0, T]$.
2. **Diagonal Separation:** For every item $i$, its Y-segment must be placed sufficiently far along its axis relative to its X-segment. Specifically, the starting coordinate of its Y-segment must be greater than or equal to the ending coordinate of its X-segment ($y_i \ge x_i + p_{i,1}$).
3. **Axis Disjointness:** On the X-axis, no two items' segments can overlap (their interiors must be disjoint). Separately, on the Y-axis, no two items' segments can overlap (their interiors must be disjoint).

You are analyzing logs from failed rendering jobs where a valid placement is mathematically impossible. For every provided test case, exactly one of the following isolated conditions is inherently impossible to satisfy. Output the code for the one that applies:
- `JOB i` — It is mathematically impossible to find coordinates $x_i$ and $y_i$ that simultaneously satisfy Grid Bounds and Diagonal Separation for item **i** (1-indexed), even if we completely ignore Axis Disjointness and all other items.
- `LOAD c` — It is mathematically impossible to find valid coordinates for all $j$ items on axis **c** (where **c**=1 means the X-axis and **c**=2 means the Y-axis) that simultaneously satisfy Grid Bounds and Axis Disjointness, even if we completely ignore Diagonal Separation and the other axis.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required lengths $p_{i,1}$ and $p_{i,2}$ for the X-axis segment and Y-axis segment of the item, respectively.

## Output

Print a single line containing the applicable certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
</STATEMENT>
<RATIONALE>
The problem was reframed from scheduling sequential tasks on a timeline to placing 1D projections on orthogonal axes. The temporal lag constraint is now a geometric diagonal separation constraint ($y_i \ge x_i + p_{i,1}$). This forces the model to genuinely deduce the algebraic lower bounds from the geometric rules rather than relying on surface-level keyword mapping to standard job-shop scheduling sums.
</RATIONALE>
<PRESERVED_ANSWER>
Grid Bounds and Diagonal Separation for a single item algebraically simplify to $p_{i,1} + p_{i,2} \le T$, matching the original `JOB i` check; Grid Bounds and Axis Disjointness algebraically require the sum of lengths on axis $c$ to be $\le T$, matching the original `LOAD c` check.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity remains $O(N)$ as it requires exactly the same linear scan to check sums and maximums against $T$.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "overlap (their interiors must be disjoint)" if they assume endpoints cannot touch, though this does not change the mathematical sum-of-lengths capacity bound.
</RISK>
