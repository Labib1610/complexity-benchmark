# Problem C — Topological Impossibility: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

Let $X$ be the standard metric space of real numbers $\mathbb{R}$ equipped with the distance metric $d(x,y) = |x-y|$. 

For a system of $j$ elements, we must define a specific topological configuration. For each element $i \in \{1 \dots j\}$, we must construct two connected, compact subspaces $K_{i,1}$ and $K_{i,2}$ within $X$. The required metric diameter of $K_{i,1}$ is $p_{i,1}$, and the required metric diameter of $K_{i,2}$ is $p_{i,2}$.

The configuration of these subspaces must strictly satisfy three axioms:
1. **Subspace Confinement:** For all $i \in \{1 \dots j\}$ and $c \in \{1, 2\}$, the subspace must be entirely contained within the closed interval $[0, T]$. That is, $K_{i,c} \subseteq [0, T]$.
2. **Asymmetric Ordering:** For every element $i$, the Cartesian product $K_{i,1} \times K_{i,2}$ must be a subset of the closed half-plane $H = \{ (u, v) \in \mathbb{R}^2 \mid v \ge u \}$.
3. **Interior Disjointness:** For a fixed index $c \in \{1, 2\}$, any two distinct subspaces $K_{i,c}$ and $K_{m,c}$ (where $i \neq m$) must have disjoint topological interiors in $X$.

You are analyzing configuration logs where a valid construction of all subspaces is mathematically impossible. For every provided test case, exactly one of the following isolated conditions is inherently impossible to satisfy. Output the code for the one that applies:
- `JOB i` — It is mathematically impossible to construct $K_{i,1}$ and $K_{i,2}$ for element **i** (1-indexed) such that Subspace Confinement and Asymmetric Ordering are simultaneously satisfied, even if we completely ignore Interior Disjointness and all other elements.
- `LOAD c` — It is mathematically impossible to construct the collection of subspaces $K_{1,c}, \dots, K_{j,c}$ for index **c** (where **c** $\in \{1, 2\}$) such that Subspace Confinement and Interior Disjointness are simultaneously satisfied, even if we completely ignore Asymmetric Ordering and the other index.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required metric diameters $p_{i,1}$ and $p_{i,2}$ for the two subspaces of the element, respectively.

## Output

Print a single line containing the applicable certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

I removed the signal processing terminology (rectangular pulses, negative lag, orthogonal multiplexing) which models easily mapped to 1D interval packing. I replaced it with a point-set topology framing where intervals are "connected compact subspaces", non-overlap is "disjoint topological interiors", and sequencing is enforced by requiring their Cartesian product to lie in a 2D half-plane, forcing models to genuinely decode the mathematical structure rather than pattern match.
</RATIONALE>
<PRESERVED_ANSWER>
The topological constraints rigorously reduce to the exact same 1D interval length and non-overlap conditions: a connected compact subspace of R with diameter p is a closed interval of length p, the half-plane condition forces sequential ordering, and interior disjointness prevents overlapping, making the impossibility conditions identical.
</PRESERVED_ANSWER>
