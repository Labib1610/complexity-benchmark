# Problem C — Impossible Domains: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A digital signal processing system must synthesize $2j$ rectangular pulses over a continuous time domain. Let $P(t; k, W)$ denote a rectangular pulse of width $W$ starting at time $k$. Formally, $P(t; k, W) = 1$ for $t \in [k, k+W]$ and $P(t; k, W) = 0$ otherwise.

For each item $i \in \{1 \dots j\}$, the system must determine real-valued translation parameters $k_{i,1}$ and $k_{i,2}$ to define two signal components:
- Component 1: $s_{i,1}(t) = P(t; k_{i,1}, p_{i,1})$
- Component 2: $s_{i,2}(t) = P(t; k_{i,2}, p_{i,2})$

The synthesized signals must strictly satisfy three constraints:
1. **Bounded Support:** For all $i \in \{1 \dots j\}$ and $c \in \{1, 2\}$, the $L_2$ norm of the signal outside the operational domain $[0, T]$ must be exactly zero. That is, $\int_{\mathbb{R} \setminus [0, T]} |s_{i,c}(t)|^2 dt = 0$.
2. **Non-negative Lag:** For every item $i$, the deterministic cross-correlation function between its two components must evaluate to zero over the strictly negative open ray. That is, $R_i(\tau) = \int_{-\infty}^{\infty} s_{i,1}(t) s_{i,2}(t + \tau) dt = 0$ for all $\tau \in (-\infty, 0)$.
3. **Orthogonal Multiplexing:** For a fixed component $c$ (where $c \in \{1, 2\}$), the set of signals across all $j$ items must form an orthogonal system in $L_2(\mathbb{R})$. That is, for any distinct items $i \neq m$, the inner product $\langle s_{i,c}, s_{m,c} \rangle = \int_{-\infty}^{\infty} s_{i,c}(t) s_{m,c}(t) dt = 0$.

You are analyzing logs from failed systems where a valid complete assignment of translation parameters is mathematically impossible. For every provided test case, exactly one of the following fundamental limiters is the root cause of the failure. Output the code for the one that applies:
- `JOB i` — The projection of the valid configuration space onto the coordinates $(k_{i,1}, k_{i,2})$ becomes strictly empty when constrained solely by the Bounded Support and Non-negative Lag requirements for item **i** (1-indexed).
- `LOAD c` — The projection of the valid configuration space onto the coordinates $(k_{1,c}, \dots, k_{j,c})$ becomes strictly empty when constrained solely by the Bounded Support and Orthogonal Multiplexing requirements for component **c** (where **c** $\in \{1, 2\}$).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required pulse widths $p_{i,1}$ and $p_{i,2}$ for component 1 and component 2 of the item, respectively.

## Output

Print a single line containing the applicable certificate: either `JOB i` or `LOAD c`.

**Output**

```

### Example 2

```

**Output**
```
LOAD 1
```
