    # Since functions are isometries, f_{i,1} maps [0,p1] to some interval [a, a+p1] or [a+p1, a]
    # Similarly for f_{i,2}
    # For pointwise precedence, we need the entire range of f_{i,1} to be <= entire range of f_{i,2}

    # And 0 <= a2 <= a2+p2 <= T  => 0 <= a2 <= T-p2
