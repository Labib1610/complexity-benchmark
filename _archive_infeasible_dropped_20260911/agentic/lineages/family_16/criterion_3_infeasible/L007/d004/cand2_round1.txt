<STATEMENT>
# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing facility processes **j** distinct items. Each item requires processing at stage 1, followed by processing at stage 2. You are provided the duration required for each stage per item.

A valid production schedule assigns a start time for every operation such that:
- **Capacity 1**: The equipment at stage 1 processes at most one item at any given moment.
- **Capacity 2**: The equipment at stage 2 processes at most one item at any given moment.
- **Dependency**: For every item, its processing at stage 2 cannot begin until its processing at stage 1 is completely finished.
- **Window**: All processing must begin at or after time 0, and all processing must be completely finished at or before the shift deadline **T**.

You are tasked with auditing production logs from failed facilities. For each log, the required production cannot possibly be completed, regardless of how the operations are scheduled. Your objective is to generate a concise certificate that definitively proves this impossibility.

Exactly one of the following relaxed scenarios is already impossible. Print the one that holds:
- `JOB i` — It is impossible to schedule the **i**-th item (1-indexed) such that it satisfies the Dependency and Window constraints, even if all other items and constraints are ignored.
- `LOAD c` — It is impossible to schedule all **j** items at stage **c** (where **c** $\in \{1, 2\}$) such that they satisfy the Capacity constraint for stage **c** and the Window constraint, even if the other stage and all other constraints are ignored.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the duration required for the item at stage 1 and stage 2, respectively.

## Output

Print a single line containing the applicable certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
