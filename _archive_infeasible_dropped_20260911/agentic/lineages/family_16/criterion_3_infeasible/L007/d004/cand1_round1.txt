<STATEMENT>
# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing facility processes **j** distinct items. The production of each item involves exactly two sequential stages: it must first undergo preparation at stage 1, and upon completion, undergo finishing at stage 2. You are provided the duration required for each stage per item. Equipment at any stage can handle at most one item at any given moment.

A valid schedule assigns each item $k$ an open time interval $I_{1,k}$ for stage 1 and an open time interval $I_{2,k}$ for stage 2, such that:
1. The length of $I_{1,k}$ is exactly the required preparation duration, and the length of $I_{2,k}$ is exactly the required finishing duration.
2. For each item $k$, the interval $I_{1,k}$ strictly precedes $I_{2,k}$.
3. For each stage $c \in \{1, 2\}$, the intervals $\{I_{c,k}\}_{k=1}^\mathbf{j}$ are mutually disjoint (the equipment processes at most one item at a time).
4. All intervals are subsets of the shift duration $(0, \mathbf{T})$.

You are auditing logs from failed facilities. For each log, no valid schedule exists. Your objective is to generate a concise certificate that pinpoints the fundamental reason for this impossibility.

It is guaranteed that exactly one of the following localized constraint subsets is completely impossible to satisfy within the interval $(0, \mathbf{T})$. Print the one that holds:
- `JOB i` — The requirements for item **i** (1-indexed) cannot be satisfied, even if we drop the disjointness constraints (rule 3) for all equipment and ignore all other items.
- `LOAD c` — The requirements for the equipment at stage **c** ($c \in \{1, 2\}$) cannot be satisfied, even if we drop the precedence constraints (rule 2) and ignore the other stage entirely.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the duration required for the item at stage 1 and stage 2, respectively.

## Output

Print a single line containing the applicable certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

I replaced the explicit descriptions of the violation conditions (which directly gave away the formulas `p1 + p2 > T` and `sum > T`) with formal constraint relaxations. The models can no longer just pattern-match the arithmetic operations from the text; they must now deduce that applying rules 1, 2, and 4 for a single item implies checking `p1 + p2 > T`, and that applying rules 1, 3, and 4 for a single stage implies checking if the sum of durations exceeds `T`.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical condition for the `JOB i` relaxation to be impossible is exactly `p1 + p2 > T`, and for `LOAD c` it is exactly `sum(p) > T`, which are the exact same conditions as the original problem.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
