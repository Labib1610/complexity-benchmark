# Problem C — Matrix Nullification: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A cryptographic system is attempting to generate a family of projection keys. Let $j$ be the number of items. For each item $i \in \{1 \dots j\}$, the system must construct two real-valued matrices, $K_{i,1}$ and $K_{i,2}$.

Specifically, the required dimensions are that $K_{i,1}$ must be a matrix of size $p_{i,1} \times T$, and $K_{i,2}$ must be a matrix of size $p_{i,2} \times T$. Each matrix must have full row rank. That is, the rows of $K_{i,c}$ must form a linearly independent set of vectors in $\mathbb{R}^T$.

The constructed matrices must strictly satisfy three constraints:
1. **Column Bounding:** For all $i \in \{1 \dots j\}$ and $c \in \{1, 2\}$, the matrix $K_{i,c}$ must have exactly $T$ columns.
2. **Intra-item Nullification:** For every item $i$, the matrix product $K_{i,1} K_{i,2}^T$ must be the zero matrix.
3. **Inter-item Nullification:** For a fixed component $c$ (where $c \in \{1, 2\}$), the matrices across all $j$ items must be mutually orthogonal in their rows. That is, for any distinct items $i \neq m$, the product $K_{i,c} K_{m,c}^T$ must be the zero matrix.

You are analyzing logs from failed systems where a valid complete assignment of these matrices is mathematically impossible. For every provided test case, exactly one of the following isolated conditions is inherently impossible to satisfy. Output the code for the one that applies:
- `JOB i` — It is mathematically impossible to find full-row-rank matrices $K_{i,1}$ and $K_{i,2}$ for item **i** (1-indexed) that simultaneously satisfy Column Bounding and Intra-item Nullification, even if we completely ignore Inter-item Nullification and all other items.
- `LOAD c` — It is mathematically impossible to find full-row-rank matrices $K_{1,c}, \dots, K_{j,c}$ for component **c** (where **c** $\in \{1, 2\}$) that simultaneously satisfy Column Bounding and Inter-item Nullification, even if we completely ignore Intra-item Nullification and the other component.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required number of rows $p_{i,1}$ and $p_{i,2}$ for the first and second matrix of the item, respectively.

## Output

Print a single line containing the applicable certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

<RATIONALE>
I completely replaced the geometric framing (isometries, intervals, ranges) with an equivalent linear algebra framing. The constraint that interval lengths sum to at most T is mapped to the constraint that the dimensions of mutually orthogonal subspaces (represented by full-row-rank matrices with $A B^T = 0$) sum to at most the ambient dimension T. This forces models to deduce that orthogonal row spaces limit the sum of matrix ranks to T, rather than simply pattern-matching "interval lengths in [0, T]".
</RATIONALE>
<PRESERVED_ANSWER>
Finding matrices $K_1, K_2$ with full row rank $p_1, p_2$ such that $K_1 K_2^T = 0$ is possible if and only if $p_1 + p_2 \le T$, making the impossibility conditions mathematically identical to the seed problem.
</PRESERVED_ANSWER>

The problem still requires checking if $p_{i,1} + p_{i,2} > T$ or $\sum p_{i,c} > T$, which remains solvable in $O(j)$ time.
</PRESERVED_CLASS>
