We can check each condition separately:

- **JOB i** is impossible if `p1 + p2 > T`, because we need at least `p1` slots on core 1 and `p2` slots on core 2, all strictly ordered (core 1 before core 2), so total distinct slots needed is `p1 + p2`.
- **LOAD c** is impossible if the sum of all `p_i,c` exceeds `T`, because each core has only `T` distinct slots and tasks cannot share slots on the same core.

We check all tasks for JOB first, then check both cores for LOAD. The problem guarantees exactly one condition is impossible, so we can output the first one we find.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    p1_list = []
    p2_list = []
    idx = 2
    for _ in range(j):
        p1 = int(data[idx])
        p2 = int(data[idx+1])
        idx += 2
        p1_list.append(p1)
        p2_list.append(p2)
    
    # Check JOB condition
    for i in range(j):
        if p1_list[i] + p2_list[i] > T:
            print(f"JOB {i+1}")
            return
    
    # Check LOAD condition
    if sum(p1_list) > T:
        print("LOAD 1")
        return
    if sum(p2_list) > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
