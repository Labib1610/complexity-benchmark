# Problem C — Impossible Domains: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A theoretical computer scientist is analyzing the feasibility of embedding certain algebraic structures. Let $j$ be the number of items, and $T$ be a given integer capacity. 
Let $V$ be a $T$-dimensional real inner product space with a fixed orthonormal basis $e_1, e_2, \dots, e_T$.

For any vector $v \in V$, we define its support, denoted $\text{supp}(v)$, as the set of indices $k \in \{1 \dots T\}$ such that the coefficient of $e_k$ is non-zero when $v$ is expressed as a linear combination of the basis vectors. 
For a subspace $W \subseteq V$, its support $\text{supp}(W)$ is defined as the union of $\text{supp}(v)$ for all vectors $v \in W$.

For each item $i \in \{1 \dots j\}$, the system must construct two subspaces of $V$, denoted $W_{i,1}$ and $W_{i,2}$. The constructed subspaces must strictly satisfy three constraints:

1. **Degrees of Freedom:** For all $i \in \{1 \dots j\}$ and $c \in \{1, 2\}$, the dimension of the subspace $W_{i,c}$ must be at least $p_{i,c}$.
2. **Index Precedence:** For every item $i$, if $x \in \text{supp}(W_{i,1})$ and $y \in \text{supp}(W_{i,2})$, the strict inequality $x < y$ must hold.
3. **Inner Product Nullity:** For a fixed component $c$ (where $c \in \{1, 2\}$), the subspaces across all $j$ items must be mutually orthogonal. That is, for any distinct items $i \neq m$, every vector in $W_{i,c}$ must be orthogonal to every vector in $W_{m,c}$.

You are analyzing logs from failed systems where a valid complete assignment of these subspaces is mathematically impossible. For every provided test case, exactly one of the following isolated conditions is inherently impossible to satisfy. Output the code for the one that applies:
- `JOB i` — It is mathematically impossible to find subspaces $W_{i,1}$ and $W_{i,2}$ in $V$ for item **i** (1-indexed) that simultaneously satisfy Degrees of Freedom and Index Precedence, even if we completely ignore Inner Product Nullity and all other items.
- `LOAD c` — It is mathematically impossible to find subspaces $W_{1,c}, \dots, W_{j,c}$ in $V$ for component **c** (where **c** $\in \{1, 2\}$) that simultaneously satisfy Degrees of Freedom and Inner Product Nullity, even if we completely ignore Index Precedence and the other component.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required minimum dimensions $p_{i,1}$ and $p_{i,2}$ for the first and second subspace of the item, respectively.

## Output

Print a single line containing the applicable certificate: either `JOB i` or `LOAD c`.
