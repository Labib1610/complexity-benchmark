# Problem C — Impossible Domains: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A mathematical solver is attempting to construct a family of binary-valued functions. Let $j$ be the number of items. For each item $i \in \{1 \dots j\}$, the solver must construct two functions, $h_{i,1}$ and $h_{i,2}$. Both functions must be defined over the real domain $[0, T]$ and must map exclusively to the codomain $\{0, 1\}$.

Each constructed function must strictly satisfy three structural requirements:
1. **Contiguity:** The set of inputs where the function evaluates to $1$ must form a single contiguous block. That is, for any item $i$ and component $c \in \{1, 2\}$, if $h_{i,c}(u) = 1$ and $h_{i,c}(v) = 1$, then it must be true that $h_{i,c}(w) = 1$ for all real numbers $w$ strictly between $u$ and $v$.
2. **Definite Integral:** The area under the curve of each function over its domain must exactly match its specified quota. Specifically, $\int_{0}^{T} h_{i,1}(x) dx = p_{i,1}$ and $\int_{0}^{T} h_{i,2}(x) dx = p_{i,2}$.
3. **Relational Constraints:**
   - **Intra-Item Ordering:** For every item $i$, any input yielding $1$ for the first function must be less than or equal to any input yielding $1$ for the second function. Formally, for all $x, y \in [0, T]$, if $h_{i,1}(x) = 1$ and $h_{i,2}(y) = 1$, then $x \le y$.
   - **Inter-Item Orthogonality:** For a fixed component $c$ (where $c \in \{1, 2\}$), the functions across all $j$ items must not simultaneously evaluate to $1$ over any region of positive area. That is, for any distinct items $i \neq m$, the integral of their product must evaluate to zero: $\int_{0}^{T} \left( h_{i,c}(x) \cdot h_{m,c}(x) \right) dx = 0$.

You are analyzing logs from failed systems where a valid complete assignment of these functions is mathematically impossible. For every provided test case, exactly one of the following isolated conditions is inherently impossible to satisfy. Output the code for the one that applies:
- `JOB i` — It is mathematically impossible to find functions $h_{i,1}$ and $h_{i,2}$ for item **i** (1-indexed) that simultaneously satisfy Contiguity, Definite Integral, and Intra-Item Ordering, even if we completely ignore Inter-Item Orthogonality and all other items.
- `LOAD c` — It is mathematically impossible to find functions $h_{1,c}, \dots, h_{j,c}$ for component **c** (where **c** $\in \{1, 2\}$) that simultaneously satisfy Contiguity, Definite Integral, and Inter-Item Orthogonality, even if we completely ignore Intra-Item Ordering and the other component.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required definite integrals $p_{i,1}$ and $p_{i,2}$ for the first and second function of the item, respectively.

## Output

Print a single line containing the applicable certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

<RATIONALE>
The seed problem relied on "isometries" from domains $[0, p]$ to $[0, T]$, which models easily mapped to intervals of length $p$ summing to $T$. I replaced this with binary indicator functions over $[0, T]$ whose integrals equal $p$ and whose supports are contiguous. This maintains exact mathematical equivalence (an interval in $[0, T]$ of length $p$) but forces the models to deduce that the integral of a contiguous binary function is its support's length, and that orthogonality/ordering constraints on these functions map to non-overlapping supports, bounding their sum by $T$.
</RATIONALE>

</PRESERVED_ANSWER>
