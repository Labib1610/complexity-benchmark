# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing facility processes **j** distinct items. The production of each item involves exactly two sequential stages: it must first undergo preparation at stage 1, and upon completion, undergo finishing at stage 2. You are provided the duration required for each stage per item. Equipment at any stage can handle at most one item at any given moment.

The facility operates for a single shift of duration **T**. All items must be completely processed before the shift ends.

You are tasked with auditing production logs from failed facilities. For every input log, it is guaranteed that the required production cannot possibly be completed within the shift, regardless of how the items are ordered. Furthermore, exactly one of the following two physical violations is guaranteed to hold, which serves as a definitive certificate of impossibility:

- `JOB i` — The **i**-th item (1-indexed) has a sequential occupation interval (the span from the start of its stage 1 to the end of its stage 2, assuming no delays) that strictly exceeds the shift length **T**.
- `LOAD c` — The equipment at stage **c** (where **c** is 1 or 2) has a machine-occupation ledger (the aggregate of the active processing intervals it must dedicate to the entire batch) that strictly exceeds the shift length **T**.

Because exactly one reason is guaranteed to hold for any given input, output is unambiguous. Your objective is to identify and print the single applicable certificate for the log.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the duration required for the item at stage 1 and stage 2, respectively.

## Output

Print a single line containing the unique applicable certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
