We need to check two conditions:

1. **JOB i**: If any item’s total time (p1 + p2) exceeds T, then that item alone cannot finish even if started at time 0.  
2. **LOAD c**: If the sum of all p1 times exceeds T, then stage 1 is overloaded. If the sum of all p2 times exceeds T, then stage 2 is overloaded.

We must output the first applicable condition in the order:  
- First check all items for JOB condition.  
- Then check LOAD 1, then LOAD 2.

Here’s the implementation:

```python
n, T = map(int, input().split())
p1_sum = 0
p2_sum = 0

for i in range(1, n + 1):
    p1, p2 = map(int, input().split())
    p1_sum += p1
    p2_sum += p2
    if p1 + p2 > T:
        print(f"JOB {i}")
        exit()

if p1_sum > T:
    print("LOAD 1")
    exit()

if p2_sum > T:
    print("LOAD 2")
    exit()
```
