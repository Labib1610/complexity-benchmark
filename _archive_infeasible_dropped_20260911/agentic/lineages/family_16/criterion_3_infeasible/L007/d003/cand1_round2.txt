# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing facility processes **j** distinct items. The production of each item involves exactly two sequential stages: it must first undergo preparation at stage 1, then undergo finishing at stage 2. You are provided the duration required for each stage per item. Equipment at any stage can handle at most one item at any given moment.

The facility operates for a single shift of duration **T**. All items must be completely processed before the shift ends.

You are tasked with auditing production logs from failed facilities. In every provided record, it is physically impossible to complete all items within the shift, regardless of how the items are scheduled. Your objective is to generate a concise certificate that definitively proves this impossibility. 

A valid certificate isolates a violation of a physical constraint. It is guaranteed that for every input, at least one of the following violations is present. The acceptable certificates are:

- `JOB i` — The **i**-th item (1-indexed) dictates a minimal contiguous footprint of presence in the facility—spanning from the moment it begins stage 1 to the moment it concludes stage 2—that cannot physically fit within the single shift's capacity, even if it were the only item being processed.
- `LOAD c` — The ledger of exclusive machine occupation for equipment at stage **c** (where **c** is 1 or 2) accumulates a mandatory active time across the entire batch that overflows the single shift's capacity, regardless of concurrency.

Determine and output an applicable certificate for the given log.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the duration required for the item at stage 1 and stage 2, respectively.

## Output

Print a single line containing an applicable certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

Removed explicit additive keywords ("combined duration", "total active duration") and replaced them with physical audit descriptions ("minimal contiguous footprint of presence", "ledger of exclusive machine occupation accumulates a mandatory active time"). This forces the model to derive the `p1 + p2 > T` and `sum(p_c) > T` inequalities from the physical constraints of the scenario rather than pattern-matching literal addition phrases.
</RATIONALE>
<PRESERVED_ANSWER>
The physical constraints described map exactly to the original threshold conditions, meaning the valid certificates for any input log remain completely unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class is unchanged because the solution still solely requires a single-pass linear time check of individual job times and aggregated stage loads.
</PRESERVED_CLASS>
<RISK>
Readers might misinterpret "minimal contiguous footprint" as involving queueing delays, though the clause "even if it were the only item being processed" clarifies that wait time is zero.
</RISK>
