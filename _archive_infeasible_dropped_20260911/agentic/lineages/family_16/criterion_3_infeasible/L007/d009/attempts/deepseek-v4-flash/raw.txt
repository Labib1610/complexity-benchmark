We need to check two possible failure conditions:

1. **JOB i** — A single graph cannot be placed even alone.  
   For graph \(i\), we need \(p_1\) frontend and \(p_2\) backend stages, all distinct, from 1 to \(T\).  
   The sequential dataflow condition means: if we sort all \(p_1 + p_2\) stages, the first \(p_1\) are frontend, the rest are backend.  
   This is possible if and only if we can pick \(p_1 + p_2\) distinct numbers from 1..T, i.e.,  
   \[
   p_1 + p_2 \le T
   \]
   If not, it's impossible.

2. **LOAD c** — Phase \(c\) is overloaded.  
   For phase \(c\), we need to assign \(p_{i,c}\) distinct stages for each graph \(i\), all from 1..T, and no two graphs share a stage in that phase.  
   This is possible iff the sum of all \(p_{i,c}\) over all graphs is \(\le T\).  
   If not, it's impossible.

We are guaranteed exactly one of these conditions holds.  
So we first check if any graph has \(p_1 + p_2 > T\). If yes, output `JOB i` for the first such graph.  
Otherwise, check if sum of \(p_{i,1} > T\) → `LOAD 1`, else if sum of \(p_{i,2} > T\) → `LOAD 2`.

Let's implement this efficiently.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    j = int(next(it))
    T = int(next(it))
    
    total1 = 0
    total2 = 0
    
    for i in range(1, j+1):
        p1 = int(next(it))
        p2 = int(next(it))
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        total1 += p1
        total2 += p2
    
    if total1 > T:
        print("LOAD 1")
    else:
        print("LOAD 2")

if __name__ == "__main__":
    main()
```
