# Problem C — Infeasible Orthogonal Supports

Time limit: 2 s   Memory limit: 256 MB

## Description

A signal processing module is attempting to synthesize two sequences of binary vectors. Let $j$ be the number of required vector pairs. For each index $i \in \{1 \dots j\}$, the module must construct a vector $V_i$ and a vector $W_i$. Every component of every vector must be exactly $0$ or $1$.

The input specifies the required squared Euclidean norm (which, for binary vectors, is simply the number of non-zero components) for each vector. For each $i \in \{1 \dots j\}$, the squared Euclidean norm of $V_i$ must be exactly $p_{i,1}$, and the squared Euclidean norm of $W_i$ must be exactly $p_{i,2}$.

The synthesized vectors must strictly satisfy three constraints:
1. **Dimensional Bounding:** All vectors $V_i$ and $W_i$ must belong to the vector space $\mathbb{R}^T$, meaning their components are indexed by the discrete integers $1$ through $T$.
2. **Support Precedence:** For every index $i$, all non-zero components of $V_i$ must appear at strictly lower coordinate indices than all non-zero components of $W_i$. Mathematically, if the $r$-th component of $V_i$ is $1$ and the $s$-th component of $W_i$ is $1$, it is strictly required that $r < s$.
3. **Mutual Orthogonality:** Within the first sequence, all $j$ vectors must be pairwise orthogonal (i.e., the dot product $V_i \cdot V_m = 0$ for all distinct $i \neq m$). Similarly, within the second sequence, all $j$ vectors must be pairwise orthogonal ($W_i \cdot W_m = 0$ for all distinct $i \neq m$).

You are analyzing error logs from failed synthesis attempts where a valid assignment of these vectors is mathematically impossible. For every provided test case, exactly one of the following isolated conditions is inherently impossible to satisfy. Output the code for the one that applies:
- `JOB i` — It is mathematically impossible to find binary vectors $V_i$ and $W_i$ for index **i** (1-indexed) that simultaneously satisfy Dimensional Bounding and Support Precedence, even if we completely ignore Mutual Orthogonality and all other indices.
- `LOAD c` — It is mathematically impossible to find a valid sequence of binary vectors for sequence **c** (where **c** $\in \{1, 2\}$, corresponding to the $V$ sequence for $c=1$ and the $W$ sequence for $c=2$) that simultaneously satisfy Dimensional Bounding and Mutual Orthogonality, even if we completely ignore Support Precedence and the other sequence.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required squared Euclidean norms $p_{i,1}$ and $p_{i,2}$ for the $V_i$ and $W_i$ vectors, respectively.

## Output

Print a single line containing the applicable certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

<RATIONALE>
The problem has been completely reframed from a discrete task-scheduling domain into a continuous-space linear algebra domain. "Time slots" are now "vector components", "set cardinalities" are "squared Euclidean norms", and "core exclusivity" is "mutual orthogonality". This forces the model to independently deduce that mutually orthogonal binary vectors must have disjoint supports, meaning the sum of their squared norms cannot exceed the dimension $T$. Models relying on surface pattern matching for scheduling load-balancing will fail to make this connection.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical requirements are identical: finding binary vectors with specific norms and disjoint supports (due to orthogonality or precedence) is mathematically isomorphic to picking disjoint subsets of a fixed size from a set of size $T$.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity remains $O(N)$ because checking if the required norms sum to more than $T$ (for `LOAD`) or if a single pair of norms sums to more than $T$ (for `JOB`) is structurally identical to the original logic.
</PRESERVED_CLASS>
