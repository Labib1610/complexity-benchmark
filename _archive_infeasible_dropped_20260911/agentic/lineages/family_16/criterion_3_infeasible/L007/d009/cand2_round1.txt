# Problem C — Impossible Allocations: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A quantum scheduler is attempting to construct a valid sequence of microwave pulses. Let $j$ be the number of required operations. For each operation $i \in \{1 \dots j\}$, the scheduler must construct two sets of integers, $S_{i,1}$ and $S_{i,2}$, representing time slot allocations on Channel 1 and Channel 2 respectively.

The input specifies the exact number of distinct time slots each set must contain: the cardinality of $S_{i,1}$ must be exactly $p_{i,1}$, and the cardinality of $S_{i,2}$ must be exactly $p_{i,2}$.

The constructed sets must strictly satisfy three constraints:
1. **Window Bounding:** For all $i \in \{1 \dots j\}$ and $c \in \{1, 2\}$, every integer in the set $S_{i,c}$ must be chosen from the discrete interval of available slots $[1, T]$.
2. **Interference Void:** For every operation $i$, let $\alpha_i$ be the minimum integer in $S_{i,2}$, and let $\beta_i$ be the maximum integer in $S_{i,1}$. To prevent phase collision, the system requires that the set $\{x \in \mathbb{Z} \mid \alpha_i \le x \le \beta_i\}$ must have a cardinality of exactly zero.
3. **Channel Monomorphism:** For a fixed channel $c$ (where $c \in \{1, 2\}$), the mapping from the elements of the allocated sets across all $j$ operations to their assigned time slots $x \in [1, T]$ must be strictly injective. That is, there cannot exist any time slot $x$ that is an element of both $S_{i,c}$ and $S_{m,c}$ for any distinct operations $i \neq m$.

You are analyzing logs from failed systems where a valid complete assignment of these sets is mathematically impossible. For every provided test case, exactly one of the following isolated conditions is inherently impossible to satisfy. Output the code for the one that applies:
- `JOB i` — It is mathematically impossible to find valid sets $S_{i,1}$ and $S_{i,2}$ for operation **i** (1-indexed) that simultaneously satisfy Window Bounding and the Interference Void, even if we completely ignore Channel Monomorphism and all other operations.
- `LOAD c` — It is mathematically impossible to find sets $S_{1,c}, \dots, S_{j,c}$ for channel **c** (where **c** $\in \{1, 2\}$) that simultaneously satisfy Window Bounding and Channel Monomorphism, even if we completely ignore the Interference Void and the other channel.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required set cardinalities $p_{i,1}$ and $p_{i,2}$ for the first and second channel allocations of the operation, respectively.

## Output

Print a single line containing the applicable certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

I replaced the temporal "strictly precede" keyword trigger with a topological emptiness constraint on a formally defined interval. By stating that the set of integers between the minimum of the second set and the maximum of the first set must have a cardinality of exactly zero, models are forced to algebraically derive that this requires $\alpha_i > \beta_i$, which in turn bounds the sum of the set cardinalities to $T$. This breaks the semantic pattern-matching that allows models to immediately jump to the `p1 + p2 > T` check.
</RATIONALE>

The condition for a set of integers defined by $\alpha_i \le x \le \beta_i$ to have cardinality zero is exactly $\alpha_i > \beta_i$, which perfectly preserves the original "strictly precede" constraint and therefore leaves all impossibility thresholds identical.
</PRESERVED_ANSWER>
