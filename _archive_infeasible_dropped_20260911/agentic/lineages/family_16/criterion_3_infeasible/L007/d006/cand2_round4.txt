# Problem C — Impossible Domains: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A system configuration requires assigning real-line intervals $S_{i,c}$ for entities $i \in \{1 \dots j\}$ and stages $c \in \{1, 2\}$. You are analyzing configurations that are known to be inherently unsatisfiable. To classify the failure, you must identify a localized obstruction. 

We define two types of localized state spaces and their corresponding valid states:

**Entity State Space ($\Omega_i$):**
For a specific entity $i$, $\Omega_i$ is the set of all interval pairs $(S_{i,1}, S_{i,2})$ where $S_{i,1}$ is a closed interval of length exactly $p_{i,1}$ and $S_{i,2}$ is a closed interval of length exactly $p_{i,2}$.
A pair in $\Omega_i$ is considered *valid* if it satisfies two conditions:
1. **Bounded:** $S_{i,1} \subseteq [0, T]$ and $S_{i,2} \subseteq [0, T]$.
2. **Ordered:** $\max(S_{i,1}) \le \min(S_{i,2})$.

If there does not exist any valid pair in $\Omega_i$, the configuration contains a **`JOB i`** obstruction.

**Stage State Space ($\Omega_c$):**
For a specific stage $c$, $\Omega_c$ is the set of all interval tuples $(S_{1,c}, \dots, S_{j,c})$ where each $S_{k,c}$ is a closed interval of length exactly $p_{k,c}$.
A tuple in $\Omega_c$ is considered *valid* if it satisfies two conditions:
1. **Bounded:** $S_{k,c} \subseteq [0, T]$ for all $k \in \{1 \dots j\}$.
2. **Dispersed:** For any distinct $k$ and $m$, the intersection $S_{k,c} \cap S_{m,c}$ has Lebesgue measure zero (intervals may touch at endpoints, but cannot overlap in their interiors).

If there does not exist any valid tuple in $\Omega_c$, the configuration contains a **`LOAD c`** obstruction.

It is guaranteed that the given configuration contains at least one obstruction of the types defined above. Output the identifier of any obstruction present (e.g., `JOB 1`, `LOAD 2`).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required interval lengths $p_{i,1}$ and $p_{i,2}$ for entity $i$ at stage 1 and stage 2, respectively.

## Output

Print a single line containing the identifier of any applicable obstruction: either `JOB i` (where $i$ is the 1-indexed entity number) or `LOAD c` (where $c \in \{1, 2\}$ is the stage number). If multiple obstructions exist, you may output any one of them.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

<RATIONALE>
Removed the procedural "even if we completely ignore" phrasing that trivially mapped to checking the sequential work of one job or the serial load of one machine. Instead, the impossibility conditions are defined rigorously over localized state spaces ($\Omega_i$ and $\Omega_c$). Models must now deduce that the non-existence of a bounded, ordered pair is equivalent to $p_{i,1} + p_{i,2} > T$, and the non-existence of a bounded, dispersed tuple is equivalent to $\sum p_{k,c} > T$.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical conditions for the non-existence of a valid state in $\Omega_i$ and $\Omega_c$ are exactly equivalent to the total required length exceeding the available span $T$, preserving the exact same thresholds and outputs as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class remains $O(N)$ as checking the sums of lengths against $T$ is mathematically sufficient to identify the guaranteed obstructions.
</PRESERVED_CLASS>
