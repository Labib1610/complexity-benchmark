# Problem C — Impossible Domains: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A system must assign an activation domain $D_{i,c} \subseteq [0, T]$ to each item $i \in \{1 \dots j\}$ and component $c \in \{1, 2\}$. 
Each domain $D_{i,c}$ must be a single contiguous closed interval of length exactly $p_{i,c}$.
A complete assignment is valid if it satisfies two structural rules:
1. **Intra-item Precedence:** For every item $i$, the domains must be ordered such that $\max(D_{i,1}) \le \min(D_{i,2})$.
2. **Inter-item Disjointness:** For a fixed component $c$, the intersection of any two distinct domains $D_{i,c} \cap D_{k,c}$ must have a Lebesgue measure of zero (they may share at most a single boundary point).

You are analyzing logs from failed systems where a valid complete assignment within $[0, T]$ is mathematically impossible. The diagnostic tool evaluates two independent projection metrics to identify the root cause. You are guaranteed that for every provided test case, exactly one of the following evaluated metrics strictly exceeds $T$. Output the certificate for the one that applies:

- `JOB i` — The infimum of the span $\max(D_{i,2}) - \min(D_{i,1})$ across all possible choices of real intervals $D_{i,1}$ and $D_{i,2}$ (not restricted to $[0, T]$) of lengths $p_{i,1}$ and $p_{i,2}$ that satisfy Intra-item Precedence for item $i$ (1-indexed).
- `LOAD c` — The infimum of the total spanned measure $\mu\left(\bigcup_{k=1}^j D_{k,c}\right)$ across all possible choices of real intervals $D_{1,c}, \dots, D_{j,c}$ (not restricted to $[0, T]$) of lengths $p_{1,c}, \dots, p_{j,c}$ that satisfy Inter-item Disjointness for component $c$ (where $c \in \{1, 2\}$ and $\mu$ denotes the Lebesgue measure).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required interval lengths $p_{i,1}$ and $p_{i,2}$ for the item at component 1 and component 2, respectively.

## Output

Print a single line containing the applicable certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
</STATEMENT>
<RATIONALE>
I replaced the explicit "impossible to schedule ignoring X" clauses with rigorous mathematical infimums over unconstrained real intervals. This forces the model to symbolically evaluate the metrics to discover they are equivalent to the original `p1+p2 > T` and `sum > T` checks, breaking any surface-level pattern matching on bottleneck descriptions.
</RATIONALE>
<PRESERVED_ANSWER>
The infimum of the span for `JOB i` mathematically evaluates to exactly $p_{i,1} + p_{i,2}$, and the infimum of the measure for `LOAD c` evaluates to exactly $\sum p_{k,c}$, meaning the exact same inequalities are checked and the same output is produced.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires an $O(n)$ check of per-item sums and per-component sums against $T$, keeping it in the same complexity class.
</PRESERVED_CLASS>
<RISK>
Models might struggle with the term "Lebesgue measure", though it is explicitly clarified in the disjointness rule, and the math notation is standard.
</RISK>
