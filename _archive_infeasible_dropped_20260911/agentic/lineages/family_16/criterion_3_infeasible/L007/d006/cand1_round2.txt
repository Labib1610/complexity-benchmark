# Problem C — Impossible Domains: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing plant must process $j$ jobs. Each job $i$ requires a continuous time interval of exactly $p_{i,1}$ hours on Machine 1, and a continuous time interval of exactly $p_{i,2}$ hours on Machine 2. All operations must be completed within a strict deadline of $T$ hours from startup.

A schedule assigns a continuous time interval of the required length to each job on each machine. We define two forms of partial feasibility for these assignments:
- **Routing-feasible:** For a given job, its assigned interval on Machine 2 begins only after its assigned interval on Machine 1 has completely finished.
- **Capacity-feasible:** For a given machine, its assigned intervals for different jobs do not overlap in time.

A fully valid schedule must be routing-feasible for every job, capacity-feasible for both machines, and have all intervals fit entirely within the $T$-hour deadline. 

You are analyzing edge cases where no fully valid schedule exists. In each provided test case, the failure is mathematically guaranteed to be caused by exactly one of the following isolated bottlenecks. Output the code for the one that applies:
- `JOB i` : It is impossible to assign time intervals for job $i$ (1-indexed) within the $T$-hour deadline such that its operations are routing-feasible.
- `LOAD c` : It is impossible to assign time intervals for all jobs on Machine $c$ (where $c \in \{1, 2\}$) within the $T$-hour deadline such that the operations on this machine are capacity-feasible.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required processing times $p_{i,1}$ and $p_{i,2}$ for job $i$ on Machine 1 and Machine 2, respectively.

## Output

Print a single line containing the applicable bottleneck code: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
