# Problem C — Impossible Domains: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A system must assign an indicator function $\chi_{i,c} : \mathbb{R} \to \{0, 1\}$ to each entity $i \in \{1 \dots j\}$ and dimension $c \in \{1, 2\}$. 
A complete assignment is valid if it satisfies three axioms:
1. **Contiguity & Measure:** For all $i$ and $c$, the support of $\chi_{i,c}$ is a single closed interval contained entirely within $[0, T]$, and its Lebesgue measure $\|\chi_{i,c}\|_1$ equals exactly $p_{i,c}$.
2. **Precedence:** For every entity $i$, the cross-correlation $(\chi_{i,1} \star \chi_{i,2})(t) = \int_{\mathbb{R}} \chi_{i,1}(s)\chi_{i,2}(s+t) \, ds$ is exactly $0$ for all $t < 0$.
3. **Disjointness:** For each dimension $c$, the essential supremum $\|\sum_{i=1}^j \chi_{i,c}\|_\infty \le 1$.

You are analyzing systems where no valid complete assignment exists. For every provided test case, exactly one of the following isolated structural bounds is inherently violated, making assignment mathematically impossible. Output the corresponding certificate:
- `JOB i` — For a specific entity $i$ (1-indexed), the infimum of the Lebesgue measure of the convex hull of the support of $(\chi_{i,1} + \chi_{i,2})$, taken over all pairs of indicator functions on $\mathbb{R}$ satisfying Contiguity & Measure (relaxed to allow support anywhere in $\mathbb{R}$) and Precedence, strictly exceeds $T$.
- `LOAD c` — For a specific dimension $c \in \{1, 2\}$, the infimum of $\|\sum_{i=1}^j \chi_{i,c}\|_1$, taken over all sets of indicator functions on $\mathbb{R}$ satisfying Contiguity & Measure (relaxed to allow support anywhere in $\mathbb{R}$) and Disjointness, strictly exceeds $T$.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required measures $p_{i,1}$ and $p_{i,2}$ for the entity at dimension 1 and dimension 2, respectively.

## Output

Print a single line containing the applicable certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

</RATIONALE>
