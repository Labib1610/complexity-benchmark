# Problem C — Impossible Domains: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A system must schedule $j$ tasks across two timelines. Each task $i \in \{1 \dots j\}$ requires an assigned interval $A_i$ on timeline 1 and an interval $B_i$ on timeline 2. A schedule is considered valid if it satisfies four rules:
1. **Bounds:** Every interval $A_i$ and $B_i$ must be entirely contained within the time window $[0, T]$.
2. **Lengths:** Each $A_i$ must be a closed interval of length exactly $p_{i,1}$, and each $B_i$ must be a closed interval of length exactly $p_{i,2}$.
3. **Precedence:** For every task $i$, the maximum value in $A_i$ must be less than or equal to the minimum value in $B_i$.
4. **Disjointness:** On each timeline $c \in \{1, 2\}$ (where timeline 1 contains all $A_i$ and timeline 2 contains all $B_i$), the intersection of any two distinct intervals must contain at most one real number.

You are analyzing diagnostic logs from failed systems where no valid schedule can be formed. The logs guarantee that the impossibility can always be isolated to at least one of the fundamental conditions below. Output the code for an applicable condition (if multiple apply, outputting any valid one is accepted):
- `JOB i` — There do not exist two closed intervals $A_i, B_i \subseteq [0, T]$ of lengths $p_{i,1}$ and $p_{i,2}$ respectively such that $\max(A_i) \le \min(B_i)$. (Output `JOB i` where **i** is the 1-indexed task).
- `LOAD c` — There does not exist a set of $j$ closed intervals on timeline **c** (where **c** $\in \{1, 2\}$) with lengths $p_{1,c}, \dots, p_{j,c}$ such that all are subsets of $[0, T]$ and any two intersect at most at a single point. (Output `LOAD c`).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required interval lengths $p_{i,1}$ and $p_{i,2}$ for the task on timeline 1 and timeline 2, respectively.

## Output

Print a single line containing the applicable diagnostic code: either `JOB i` or `LOAD c`.

## Examples

```
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150

50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
