We need to check if we can schedule two components for each job within the given time limit, where each job has two pulse widths.  
The key is that we can only do one job at a time, and each job requires both components to be processed sequentially (component 1 then component 2).  
So the total time for a job is `p1 + p2`.  
We need to see if we can fit all jobs within the total time `T`.  

If the sum of all `p1 + p2` is ≤ `T`, we can do all jobs, so we output `JOB 1` (since we start with job 1).  
Otherwise, we need to find the first job that cannot be completed in time, and output `LOAD i` where `i` is that job number.

Let's implement this.

```python
n, T = map(int, input().split())
total_time = 0
for i in range(1, n + 1):
    p1, p2 = map(int, input().split())
    total_time += p1 + p2
    if total_time > T:
        print(f"LOAD {i}")
        break
else:
    print("JOB 1")
```
