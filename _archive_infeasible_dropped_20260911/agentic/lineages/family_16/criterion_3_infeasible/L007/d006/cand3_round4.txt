# Problem C — Impossible Domains: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A system must assign an activation domain $D_{e,c} \subseteq [0, T]$ to each entity $e \in \{1 \dots j\}$ and layer $c \in \{1, 2\}$. 
A complete assignment is valid if it satisfies three axioms:
1. **Contiguity:** Each domain $D_{e,c}$ must be a single contiguous closed interval of length exactly $p_{e,c}$.
2. **Causality:** For every entity $e$, if $x \in D_{e,1}$ and $y \in D_{e,2}$, then $x \le y$.
3. **Exclusivity:** For a fixed layer $c$, and any two distinct entities $e \neq k$, the intersection $D_{e,c} \cap D_{k,c}$ must contain at most one real number.

You are analyzing logs from failed systems where a valid complete assignment is mathematically impossible. Exactly one of the following fundamental limits is guaranteed to be breached in every test case. Output the certificate for the one that applies:
- `JOB i` — The minimum required length of the interval bounding $D_{i,1} \cup D_{i,2}$ to satisfy the Contiguity and Causality axioms for entity **i** (1-indexed) strictly exceeds $T$.
- `LOAD c` — The minimum required length of the interval bounding $\bigcup_{e=1}^j D_{e,c}$ to satisfy the Contiguity and Exclusivity axioms for layer **c** (where **c** $\in \{1, 2\}$) strictly exceeds $T$.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required domain lengths $p_{e,1}$ and $p_{e,2}$ for the entity at layer 1 and layer 2, respectively.

## Output

Print a single line containing the applicable certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

<RATIONALE>
Replaced the explicit "isolated subsystem" descriptions with formal mathematical conditions on the bounding intervals of the domains. Models must now deduce that the minimum bounding interval length under causality and exclusivity directly corresponds to the arithmetic sums $p_{i,1} + p_{i,2}$ and $\sum p_{e,c}$, preventing surface-level pattern matching on the independent checks.
</RATIONALE>
<PRESERVED_ANSWER>
The bounding interval conditions mathematically evaluate to the exact same arithmetic inequalities ($p_{i,1} + p_{i,2} > T$ and $\sum p_{e,c} > T$) as the original independent subsystem checks, ensuring identical outputs for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still only requires a single linear scan to check the two sums against $T$, keeping it in the same $O(N)$ feasibility certification class.
</PRESERVED_CLASS>
<RISK>
Models might overcomplicate the problem by attempting to simulate the interval allocations instead of recognizing the direct sum equivalence, but the mathematical definitions are exact and unambiguous.
