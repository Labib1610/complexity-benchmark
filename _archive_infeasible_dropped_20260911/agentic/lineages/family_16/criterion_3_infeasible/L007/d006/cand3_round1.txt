<STATEMENT>
# Problem C — Impossible Domains: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A recording studio is attempting to master $j$ audio tracks onto a single physical master tape of length $T$ millimeters. 
The tape features two parallel, independent recording channels: channel 1 is reserved exclusively for vocal segments, and channel 2 is reserved exclusively for instrumental segments.

For each track $i$ (from $1$ to $j$), the studio must record a continuous vocal segment of exactly $p_{i,1}$ millimeters on channel 1, and a continuous instrumental segment of exactly $p_{i,2}$ millimeters on channel 2. 

A successful master tape must satisfy the following physical layout rules:
- **Non-overlapping:** On any single channel, segments from different tracks cannot overlap (they may at most touch at their boundaries).
- **Sequentiality:** For any given track $i$, the vocal segment must be physically recorded entirely before its corresponding instrumental segment. Specifically, the ending millimeter coordinate of the vocal segment on channel 1 cannot be strictly greater than the starting millimeter coordinate of the instrumental segment on channel 2.
- **Containment:** All recorded segments must be completely contained within the $0$ to $T$ millimeter marks of the tape.

You are analyzing configurations that are physically impossible to record. For every provided test case, it is guaranteed that the configuration fails due to exactly one of the following uniquely identifiable fundamental limit breaches. You must output the code for the one that applies:
- `JOB i` — Output this (where $i$ is the 1-indexed track number) if the sequentiality requirement for track $i$ inherently demands a spatial span that strictly exceeds the physical length of the tape.
- `LOAD c` — Output this (where $c \in \{1, 2\}$ is the channel number) if the sheer volume of audio assigned to channel $c$ has an aggregate length that strictly exceeds the physical length of the tape.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$): the number of tracks and the physical length of the master tape in millimeters.
Each of the following $j$ lines contains two integers $p_{i,1}$ and $p_{i,2}$ ($1 \le p_{i,1}, p_{i,2} \le 1000000$): the required lengths in millimeters for the vocal and instrumental segments of the $i$-th track, respectively.

## Output

Print a single line containing the applicable error code: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

<RATIONALE>
I replaced the explicit boolean isolation clauses ("even if we completely ignore Exclusivity") with structural limits derived from physical geometry. The LLM must now deduce that the "spatial span" required by sequentiality implies $p_{i,1} + p_{i,2} > T$, and that "aggregate length" implies $\sum p_{i,c} > T$, rather than pattern-matching the explicit subsystem separation from the original text.
</RATIONALE>
<PRESERVED_ANSWER>
The conditions for failure are mathematically identical: a track's sequential segments can't fit if their sum exceeds T, and a channel's segments can't fit if their sum exceeds T.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains solvable by checking each track's sum against T and each channel's total sum against T in O(N) time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "spatial span" if they fail to link the sequentiality constraint to the sum of the two segment lengths, but the geometric description is rigorous.
</RISK>
