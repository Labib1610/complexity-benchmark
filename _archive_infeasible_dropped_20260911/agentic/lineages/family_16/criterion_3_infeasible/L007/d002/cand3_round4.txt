# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A factory needs to manufacture **j** different products. Every product goes through exactly two consecutive phases: assembly at phase 1, followed immediately by finishing at phase 2. The time needed for each phase is given for every product. A machine dedicated to a specific phase can only work on a single product at any time.

The factory runs a single shift lasting exactly **T** units of time. The objective is to complete all products before this shift ends.

You are reviewing production schedules from factories that failed to meet this deadline. In every provided schedule, it is physically impossible to complete the workload within the shift, no matter what order the products are processed in. You must output a short proof explaining why the schedule is impossible.

A valid proof points out a direct violation of the constraints. For every test case, it is guaranteed that exactly one of the following reasons applies:

- `LOAD c` — The machine for phase **c** (where **c** is 1 or 2) has been assigned a total workload across all products that strictly exceeds the shift duration.
- `JOB i` — The **i**-th product (1-indexed) has a total time requirement across both of its phases that strictly exceeds the shift duration.

Determine and output the unique proof that applies to the provided schedule.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the duration required for the product at phase 1 and phase 2, respectively.

## Output

Print a single line containing the applicable proof: either `LOAD c` or `JOB i`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
