# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing facility processes **j** distinct items. The production of each item involves exactly two sequential stages: it must first undergo preparation at stage 1, and only after stage 1 processing of that item is complete can it undergo finishing at stage 2. You are provided the duration required for each stage per item. Equipment at any stage can handle at most one item at any given moment.

The facility operates for a single shift of duration **T**. All items must be completely processed before the shift ends.

You are tasked with auditing production logs from failed facilities. For each set of jobs, the required production cannot possibly be completed within the shift, regardless of how the items are ordered. Your objective is to generate a concise certificate that definitively proves the impossibility of the input instance. 

A valid certificate provides a valid impossibility proof from the two allowed forms. One or more violations may exist in the log:

- `JOB i` — The **i**-th item (1-indexed) requires a sequential chain of operations whose combined duration strictly exceeds the shift length.
- `LOAD c` — The equipment at stage **c** (where **c** is 1 or 2) is assigned a total active duration across all items that strictly exceeds the shift length.

If multiple certificates apply, print `LOAD 2` if applicable; otherwise print `LOAD 1` if applicable; otherwise print `JOB i` for the smallest applicable **i**.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the duration required for the item at stage 1 and stage 2, respectively.

## Output

Print a single line containing the applicable certificate.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
