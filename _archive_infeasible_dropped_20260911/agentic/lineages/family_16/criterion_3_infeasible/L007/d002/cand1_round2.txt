# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing facility processes **j** distinct items. The production of each item involves exactly two sequential stages: it must first undergo preparation at stage 1, and upon completion, undergo finishing at stage 2. You are provided the duration required for each stage per item. Equipment at any stage can handle at most one item at any given moment.

The facility operates for a single shift of duration **T**. All items must be completely processed before the shift ends.

You are analyzing input instances representing processing times for failed facilities. For every instance, it is impossible to complete all items within the shift **T**, no matter what order the items are processed in. You must output a short proof that explains why the deadline cannot be met.

A valid proof points out a direct violation of the physical limits of the facility. Every input instance is constructed such that precisely one of the following proofs is valid:
- `JOB i` — The item at 1-based index **i** has a combined processing time across both stages that strictly exceeds **T**.
- `LOAD c` — The machine at stage **c** (where **c** is either 1 or 2) has a sum of processing times across all items that strictly exceeds **T**.

Output the unique valid proof for the given input instance.

## Input

The first line provides two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
The subsequent **j** lines each provide two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the time required for the item at stage 1 and stage 2, respectively.

## Output

Print a single line containing the valid proof: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
