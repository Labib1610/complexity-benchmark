# Border Crossing Capacity

Time limit: 2 s   Memory limit: 256 MB

## Description

An international border crossing must process **j** distinct traveler groups. Processing any group consists of two mandatory sequential phases: a primary passport control at Desk 1, followed by a secondary customs inspection at Desk 2. A group may only advance to Desk 2 after fully completing its control at Desk 1. You are given the time each group takes at each desk. Neither desk can process more than one group simultaneously.

The border crossing is only open for a strict window of time **T**. Every group must finish both phases of processing before this window expires.

You are reviewing historical data from days where the crossing was overwhelmed. On these days, the total assigned workload was mathematically impossible to finish within the open window, no matter what order the groups were processed in. You must output a short certificate that proves why the timeline could not be met.

A valid certificate pinpoints a strict capacity failure. The provided data is structurally guaranteed to exhibit exactly one of the following violations:

- `JOB i` — The **i**-th group (1-indexed) requires a sequential chain of checks whose total combined time strictly exceeds the open window **T**.
- `LOAD c` — Desk **c** (where **c** is 1 or 2) has been assigned a cumulative active processing time across all groups that strictly exceeds the open window **T**.

Identify and print the single certificate that applies to the given data.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the duration required for the group at Desk 1 and Desk 2, respectively.

## Output

Print a single line containing the applicable certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
