We need to check two possible violations:

1. **JOB i** – if any item has `p1 + p2 > T`, that item alone exceeds the shift length.
2. **LOAD c** – if the sum of all `p1` values exceeds `T` (for stage 1) or the sum of all `p2` values exceeds `T` (for stage 2).

We can check these in order: first check for any job violation, then check for load violations. If both are possible, we can output any valid one. The problem says "an applicable certificate", so we can pick the first found.

Here’s the implementation:

```python
j, T = map(int, input().split())
p1_sum = 0
p2_sum = 0
items = []

for i in range(j):
    p1, p2 = map(int, input().split())
    items.append((p1, p2))
    p1_sum += p1
    p2_sum += p2

# Check JOB violation
for idx, (p1, p2) in enumerate(items, start=1):
    if p1 + p2 > T:
        print(f"JOB {idx}")
        exit()

# Check LOAD violation
if p1_sum > T:
    print("LOAD 1")
    exit()
if p2_sum > T:
    print("LOAD 2")
    exit()
```
