# Problem C — Aborted Launch: Diagnostic Code

Time limit: 2 s   Memory limit: 256 MB

## Description

A space launch facility must process **j** cargo pallets before a launch. Each pallet must pass through two sequential chambers: it first undergoes decontamination in Chamber 1, and immediately upon completion, undergoes pressurization in Chamber 2. You are provided the processing duration each pallet requires in each chamber. A chamber can process at most one pallet at any given moment.

The facility has a strict launch window of duration **T**. All pallets must be completely processed before this window expires.

You are analyzing a data log from an aborted mission. For the given input instance, it is physically impossible to complete all pallets within the launch window, regardless of the order in which they are processed. Your objective is to generate a concise diagnostic code that definitively proves this impossibility.

The provided mission data is structurally guaranteed to exhibit exactly one of the following violation types. Within the applicable type, if there are multiple valid indices, you may output any one of them:

- `JOB i` — The **i**-th pallet (1-indexed) requires a sequential chain of procedures whose combined duration strictly exceeds the launch window.
- `LOAD c` — Chamber **c** (where **c** is 1 or 2) is assigned a total active processing duration across all pallets that strictly exceeds the launch window.

Identify and print a valid diagnostic code for the given data log.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the duration required for the pallet in Chamber 1 and Chamber 2, respectively.

## Output

Print a single line containing the applicable diagnostic code: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
