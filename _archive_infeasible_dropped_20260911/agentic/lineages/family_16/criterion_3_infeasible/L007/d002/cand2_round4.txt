# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A workshop has been contracted to manufacture **j** products. Every product requires a two-step procedure: step 1 (fabrication) followed by step 2 (polishing). The workshop has one machine for step 1 and one machine for step 2. Each machine can work on only one product at a time. 

The workshop has a strict operating window of **T** continuous minutes to finish all products. 

You are analyzing schedules from workshops that failed to meet this deadline. In every case provided, it is mathematically impossible to finish all products within **T** minutes, no matter what schedule is chosen. To document the failure, you must output a proof of impossibility. 

There are two valid formats for the proof:
- `JOB i` : Product **i** (using 1-based indexing) has a combined fabrication and polishing time that is strictly greater than the operating window **T**.
- `LOAD c` : The total time required by all products on machine **c** (where **c** is either 1 or 2) is strictly greater than the operating window **T**.

The test cases are constructed so that exactly one such proof is valid for any given input. You must find and print this unique proof.

## Input

The first line contains two integers, **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
The next **j** lines each provide two integers, **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the time required for the product on machine 1 and machine 2, respectively.

## Output

Print a single line containing the valid proof, which will be exactly one of `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
