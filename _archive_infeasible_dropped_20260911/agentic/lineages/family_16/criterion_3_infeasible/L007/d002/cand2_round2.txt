# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A factory is tasked with manufacturing **j** distinct items. Each item must pass through two sequential work phases: preparation at stage 1, followed immediately by finishing at stage 2. The time required for each phase is provided for every item. The machinery at each stage can process at most one item at any given time.

The factory has a single continuous operating window of duration **T**, during which all items must be fully processed. 

You are reviewing production schedules from facilities that failed to meet their targets. In each provided schedule, it is mathematically impossible to finish all items within the operating window, no matter the processing order. Your goal is to output a short certificate that pinpoints the exact physical limitation causing the failure.

A certificate is valid if it identifies one of the following constraint breaches:

- `JOB i` — The sequential processing time for the **i**-th item (1-indexed) alone strictly exceeds the operating window.
- `LOAD c` — The total active processing time demanded from the machinery at stage **c** (where **c** is 1 or 2) across all items strictly exceeds the operating window.

Analyze the schedule and output the appropriate certificate. The test cases are strictly designed so that every schedule contains exactly one such breach.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the duration required for the item at stage 1 and stage 2, respectively.

## Output

Print a single line containing the applicable certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
