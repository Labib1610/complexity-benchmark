# Problem C — Impossible Clearance: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A border checkpoint processes **j** travellers. The clearance of each traveller involves exactly two sequential stages: they must first undergo document verification at Desk 1, and upon completion, undergo baggage inspection at Desk 2. You are provided the duration required for each stage per traveller. The officer at any desk can handle at most one traveller at any given moment.

The checkpoint operates until a deadline **T**. All travellers must be completely cleared by time **T** (finishing exactly at time **T** is allowed).

You are tasked with auditing clearance logs from failed checkpoints. For every provided log, completing all travellers by the deadline is impossible, regardless of how they are ordered. Your objective is to generate a concise certificate that definitively proves the impossibility of the schedule. 

A valid certificate isolates a violation of a physical constraint. Every log in the test data contains precisely one of the following structural bottlenecks:

- `JOB i` — The **i**-th traveller (1-indexed) requires a sequential chain of checks whose combined duration strictly exceeds **T**.
- `LOAD c` — Desk **c** (where **c** is 1 or 2) is assigned a total active duration across all travellers that strictly exceeds **T**.

Identify and print the single certificate that applies to the given log.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the duration required for the traveller at Desk 1 and Desk 2, respectively.

## Output

Print a single line containing the applicable certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
