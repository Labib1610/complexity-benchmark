# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing facility processes **j** distinct items, where **j** corresponds to a non-empty batch up to the facility's maximum storage capacity of two hundred thousand item records. The production of each item involves exactly two sequential stages: it must first undergo preparation at stage 1, and upon completion, undergo finishing at stage 2. You are provided the duration required for each stage per item. Equipment at any stage can handle at most one item at any given moment.

The facility operates for a single shift of duration **T**. The shift duration **T** is logged in positive discrete ticks up to a hard system limit of one billion ticks. All items must be completely processed before the shift ends.

Each stage's duration per item requires at least one tick, and is capped at the equipment's continuous-operation limit of exactly one million ticks.

You are tasked with auditing production logs from failed facilities. For each log, the required production cannot possibly be completed within the shift, regardless of how the items are ordered. Your objective is to generate a concise certificate that definitively proves the impossibility of the schedule. 

A valid certificate isolates a violation of a physical constraint. The possible violations are:
- `JOB i` — The **i**-th item (1-indexed) requires a sequential chain of operations whose combined duration strictly exceeds the shift length.
- `LOAD c` — The equipment at stage **c** (where **c** is 1 or 2) is assigned a total active duration across all items that strictly exceeds the shift length.

One or more violations may exist. If multiple certificates apply, print `LOAD 2` if applicable; otherwise print `LOAD 1` if applicable; otherwise print `JOB i` for the smallest applicable `i`.

## Input

The first line contains two integers **j** and **T**.
Each of the following **j** lines contains two integers **p1** and **p2**: the duration required for the item at stage 1 and stage 2, respectively.

## Output

Print a single line containing the applicable certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
