We can solve this by checking two conditions:

1. **JOB i** — For each item, we need two intervals of lengths `p1` and `p2` inside `[0, T]` such that all points in the first interval are ≤ all points in the second interval.  
   This is possible if and only if `p1 + p2 <= T`.  
   If any item violates this, output `JOB i`.

2. **LOAD c** — For a given component, we need to place `j` intervals of given lengths inside `[0, T]` such that any two intervals intersect in at most one point.  
   This is possible if and only if the sum of all lengths for that component ≤ `T`.  
   If the sum exceeds `T`, output `LOAD c`.

We check JOB first, then LOAD 1, then LOAD 2.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    p1_list = []
    p2_list = []
    idx = 2
    for i in range(j):
        p1 = int(data[idx])
        p2 = int(data[idx+1])
        idx += 2
        p1_list.append(p1)
        p2_list.append(p2)
    
    # Check JOB condition
    for i in range(j):
        if p1_list[i] + p2_list[i] > T:
            print(f"JOB {i+1}")
            return
    
    # Check LOAD 1
    if sum(p1_list) > T:
        print("LOAD 1")
        return
    
    # Check LOAD 2
    if sum(p2_list) > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
