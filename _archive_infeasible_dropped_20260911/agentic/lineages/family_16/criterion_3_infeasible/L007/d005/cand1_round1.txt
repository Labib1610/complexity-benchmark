# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A fabrication plant needs to process **j** distinct components during a single operational window of **T** time units. For each component, the process consists of two ordered phases: phase 1 (preparation) and phase 2 (finalization). A machine dedicated to a specific phase can process at most one component at any given time.

A processing plan assigns a starting time $S_{i,c} \ge 0$ for each component $i \in \{1 \dots j\}$ at each phase $c \in \{1, 2\}$. A plan is viable if it conforms to all three rules:
1. **Window constraint:** All processing must conclude before the operational window closes. For every component $i$ and phase $c$, $S_{i,c} + p_{i,c} \le T$, where $p_{i,c}$ is the operation's length.
2. **Phase ordering:** A component cannot begin phase 2 until its phase 1 has completely finished. For every component $i$, $S_{i,2} \ge S_{i,1} + p_{i,1}$.
3. **Machine exclusivity:** A phase's machine cannot work on multiple components simultaneously. For any phase $c$, and any two distinct components $x$ and $y$, their active intervals $(S_{x,c}, S_{x,c} + p_{x,c})$ and $(S_{y,c}, S_{y,c} + p_{y,c})$ must be disjoint. (An interval may begin at the exact instant another ends).

You are given data from historical shifts where it was mathematically impossible to create a viable processing plan. 

It is guaranteed that for each input, exactly one of the following hypothetical, highly relaxed planning scenarios is also impossible to satisfy. Output the code for the one that applies:
- `JOB i` — It is impossible to find valid starting times $S_{i,1}$ and $S_{i,2}$ for the **i**-th component (1-indexed) that satisfy Rules 1 and 2. This hypothetical scenario considers only component **i** and completely waives Rule 3.
- `LOAD c` — It is impossible to find valid starting times $S_{1,c}, \dots, S_{j,c}$ for all components on phase **c** (where **c** $\in \{1, 2\}$) that satisfy Rules 1 and 3. This hypothetical scenario considers only phase **c** and completely waives Rule 2.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the duration required for the component at phase 1 and phase 2, respectively.

## Output

Print a single line containing the applicable certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
