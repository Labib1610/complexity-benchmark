<STATEMENT>
# Problem C — Impossible Allocations: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A linear algebra system is attempting to configure $j$ distinct jobs within a $T$-dimensional real vector space equipped with the standard basis $(e_1, e_2, \dots, e_T)$. For each job $i$, the system must assign two projection matrices (i.e., matrices satisfying $P^2 = P$), $P_{i,1}$ (for phase 1) and $P_{i,2}$ (for phase 2), both of size $T \times T$. The trace of $P_{i,1}$ must be exactly $p_{i,1}$, and the trace of $P_{i,2}$ must be exactly $p_{i,2}$.

A valid configuration must satisfy three rules:
1. **Basis Alignment:** Every assigned projector $P_{i,c}$ must be a diagonal matrix.
2. **Internal Ordering:** For any single job $i$, $P_{i,1} P_{i,2} = \mathbf{0}$ (the zero matrix). Furthermore, if $e_x$ and $e_y$ are any standard basis vectors such that $P_{i,1} e_x = e_x$ and $P_{i,2} e_y = e_y$, then their indices must satisfy $x < y$.
3. **Phase Exclusivity:** For a given phase $c \in \{1, 2\}$, the projectors across all jobs must be mutually orthogonal, meaning $P_{x,c} P_{y,c} = \mathbf{0}$ for all jobs $x \neq y$.

You are debugging logs from configuration failures where a valid assignment of matrices is mathematically impossible. For every provided test case, you are guaranteed that exactly one of the following isolated conditions is the root cause. Output the code for the one that applies:
- `JOB i` — Job **i** (1-indexed) cannot be configured. It is mathematically impossible to choose projectors $P_{i,1}$ and $P_{i,2}$ for this job alone that satisfy Basis Alignment and Internal Ordering, even if we completely ignore all other jobs.
- `LOAD c` — Phase **c** (where **c** $\in \{1, 2\}$) is over-constrained. It is mathematically impossible to assign projectors $P_{1,c}, \dots, P_{j,c}$ across all jobs that satisfy Basis Alignment and Phase Exclusivity, even if we completely ignore Internal Ordering and the other phase.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required traces $p_{i,1}$ and $p_{i,2}$ for the job's projectors, respectively.

## Output

Print a single line containing the applicable certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
