 We need to check two possible failure conditions:

1. **JOB i** — For some row, it’s impossible to place `p1` points in S1 and `p2` points in S2 such that every S1 point in that row is strictly left of every S2 point in that row.  
   This is possible only if `p1 + p2 <= T`.  
   If `p1 + p2 > T`, then it’s impossible for that row alone.

2. **LOAD c** — For set S1 or S2, the total number of points required across all rows exceeds the number of columns `T`, because each column can be used at most once per set.  
   So if `sum(p1) > T` → LOAD 1, if `sum(p2) > T` → LOAD 2.

We check JOB first, because if any row is impossible, that’s the first failure.  
If no JOB failure, then check LOAD.

Here’s the implementation:

```python
j, T = map(int, input().split())
total1 = 0
total2 = 0

for i in range(1, j + 1):
    p1, p2 = map(int, input().split())
    if p1 + p2 > T:
        print(f"JOB {i}")
        exit()
    total1 += p1
    total2 += p2

if total1 > T:
    print("LOAD 1")
elif total2 > T:
    print("LOAD 2")
```
