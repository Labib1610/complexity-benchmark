We can check each possible certificate type:

- **JOB i** fails if `p1 + p2 > T`.
- **LOAD 1** fails if the sum of all `p1` values is **greater than** `T` (since total interval length cannot exceed available span).
- **LOAD 2** fails if the sum of all `p2` values is **greater than** `T`.

We just check these in order and output the first valid one.  

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    idx = 2
    p1s = []
    p2s = []
    for _ in range(j):
        p1 = int(data[idx])
        p2 = int(data[idx+1])
        idx += 2
        p1s.append(p1)
        p2s.append(p2)
        if p1 + p2 > T:
            print(f"JOB {_+1}")
            return

    if sum(p1s) > T:
        print("LOAD 1")
        return

    if sum(p2s) > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
