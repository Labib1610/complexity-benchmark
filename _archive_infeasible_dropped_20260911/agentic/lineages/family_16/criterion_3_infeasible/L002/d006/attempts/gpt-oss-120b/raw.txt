**Solution Explanation**

For every element `i`

* `JOB i` is a certificate if the three constraints  

  `S_i ≥ 0 ,  S_i + p1_i ≤ U_i ,  U_i + p2_i ≤ T`  

  cannot be satisfied together.  
  From the last two we obtain `S_i ≤ T – p1_i – p2_i`.  
  If `p1_i + p2_i > T` then the right‑hand side is negative, contradicting `S_i ≥ 0`.  
  Hence any such element gives a valid `JOB` certificate.

If no element violates the above, then for every `i`

```
p1_i + p2_i ≤ T                (1)
```

Now consider the two *load* certificates.

* `LOAD 1` uses only the first stage.  
  The constraints are  

  `S_i ≥ 0 ,  intervals [S_i , S_i+p1_i) are pairwise disjoint ,  S_i + p1_i ≤ T`.

  All intervals lie inside `[0,T]` and are disjoint, therefore the total
  length `Σ p1_i` cannot exceed `T`.  
  If `Σ p1_i > T` the subsystem is impossible → `LOAD 1` is a valid certificate.

* `LOAD 2` is analogous for the second stage, requiring `Σ p2_i ≤ T`.  
  If `Σ p2_i > T` we can output `LOAD 2`.

The problem statement guarantees that the whole system is unsatisfiable,
so at least one of the three checks must succeed.

--------------------------------------------------------------------

#### Algorithm
```
read j, T
for i = 1 .. j
        read p1, p2
        if p1 + p2 > T:
                output "JOB i" and exit
        store p1, p2
sum1 = Σ p1_i
sum2 = Σ p2_i
if sum1 > T:   output "LOAD 1"
else:          output "LOAD 2"
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm always outputs a valid certificate.

---

**Lemma 1**  
If for some element `i` we have `p1_i + p2_i > T`, then `JOB i` is a valid
certificate.

*Proof.*  
From the precedence and threshold constraints we get  
`S_i + p1_i ≤ U_i` and `U_i + p2_i ≤ T` ⇒ `S_i ≤ T – p1_i – p2_i`.  
Because `p1_i + p2_i > T`, the right‑hand side is negative, contradicting
`S_i ≥ 0`. Hence the three constraints cannot be satisfied. ∎



**Lemma 2**  
If `Σ p1_i > T` then `LOAD 1` is a valid certificate.

*Proof.*  
All intervals `[S_i, S_i+p1_i)` must be inside `[0,T]` (by `S_i ≥ 0` and
`S_i+p1_i ≤ T`) and are pairwise disjoint. Their total length is exactly
`Σ p1_i`. A subset of `[0,T]` cannot contain disjoint intervals whose total
length exceeds `T`. Therefore the subsystem is impossible. ∎



**Lemma 3**  
If `Σ p2_i > T` then `LOAD 2` is a valid certificate.

*Proof.* Identical to Lemma&nbsp;2, using the second‑stage constraints. ∎



**Theorem**  
The algorithm always prints a line that is a correct certificate of
unsatisfiability.

*Proof.*  
The algorithm first scans all elements.

* If it finds an index `i` with `p1_i + p2_i > T`, by Lemma&nbsp;1 `JOB i`
  is a valid certificate, and the algorithm outputs it.

* Otherwise condition (1) holds for every element.
  Then the whole system is still unsatisfiable (given by the problem).
  For such a system at least one of the two load subsystems must be
  impossible, i.e. either `Σ p1_i > T` or `Σ p2_i > T`.  
  The algorithm computes both sums and outputs `LOAD 1` if the first sum
  exceeds `T`, otherwise `LOAD 2`. By Lemma&nbsp;2 and Lemma&nbsp;3 the
  printed load certificate is valid.

Thus in all cases the output is a correct certificate. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

The algorithm makes one pass over the `j` elements.

*Time*: `O(j)`  
*Memory*: `O(1)` besides the input values (we only keep running sums).

Both limits satisfy the constraints (`j ≤ 200 000`).

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    j = int(next(it))
    T = int(next(it))

    sum_p1 = 0
    sum_p2 = 0
    for idx in range(1, j + 1):
        p1 = int(next(it))
        p2 = int(next(it))
        if p1 + p2 > T:
            sys.stdout.write(f"JOB {idx}")
            return
        sum_p1 += p1
        sum_p2 += p2

    if sum_p1 > T:
        sys.stdout.write("LOAD 1")
    else:
        sys.stdout.write("LOAD 2")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
