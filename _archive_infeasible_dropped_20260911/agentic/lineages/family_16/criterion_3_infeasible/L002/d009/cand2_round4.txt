<STATEMENT>
# Problem C — System of Inequalities: Certificate of Unsatisfiability

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a target threshold $W$ and a set of $N$ elements. Each element $i$ (from $1$ to $N$) is associated with two positive integers, $A_i$ and $B_i$.

Consider the problem of assigning four real numbers, $L_{1,i}, R_{1,i}, L_{2,i},$ and $R_{2,i}$, to each element $i$. The assignment must satisfy the following five conditions:
1. **Widths:** For every element $i$, $R_{1,i} - L_{1,i} = A_i$ and $R_{2,i} - L_{2,i} = B_i$.
2. **Separation:** For every element $i$, $L_{2,i} \ge R_{1,i}$.
3. **Phase 1 Non-overlap:** For every pair of distinct elements $i$ and $k$, either $L_{1,i} \ge R_{1,k}$ or $L_{1,k} \ge R_{1,i}$.
4. **Phase 2 Non-overlap:** For every pair of distinct elements $i$ and $k$, either $L_{2,i} \ge R_{2,k}$ or $L_{2,k} \ge R_{2,i}$.
5. **Domain:** For every element $i$, $L_{1,i} \ge 0$ and $R_{2,i} \le W$.

For every test case in this problem, it is guaranteed that no such assignment of real numbers exists. Your task is to provide a directly checkable certificate of unsatisfiability by identifying a specific relaxed subsystem of these constraints that is already impossible to satisfy on its own. 

Output a valid certificate of unsatisfiability from one of the two allowed forms below. It is guaranteed that at least one such certificate exists for every test case.

- `JOB i` : For the element at 1-based index $i$, the constraints for its Widths (1), Separation (2), and Domain ($L_{1,i} \ge 0$ and $R_{2,i} \le W$) cannot be simultaneously satisfied (ignoring all other elements and conditions).
- `LOAD c` : where $c \in \{1, 2\}$. 
  - If $c=1$, it certifies that the Phase 1 Widths ($R_{1,i} - L_{1,i} = A_i$), Phase 1 Non-overlap (3), the domain lower bound $L_{1,i} \ge 0$, and a modified domain upper bound $R_{1,i} \le W$ for all $i$, cannot be simultaneously satisfied (ignoring Phase 2 variables, $B_i$, and all other conditions).
  - If $c=2$, it certifies that the Phase 2 Widths ($R_{2,i} - L_{2,i} = B_i$), Phase 2 Non-overlap (4), a modified domain lower bound $L_{2,i} \ge 0$, and the domain upper bound $R_{2,i} \le W$ for all $i$, cannot be simultaneously satisfied (ignoring Phase 1 variables, $A_i$, and all other conditions).

## Input

The first line contains two integers **N** and **W** (1 ≤ N ≤ 200000, 1 ≤ W ≤ 1000000000).
Each of the next **N** lines contains two integers **A_i** and **B_i** (1 ≤ A_i, B_i ≤ 1000000) for the $i$-th element.

## Output

Print a single line containing a valid certificate: `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for element 1, the `JOB` subsystem requires $R_{1,1} - L_{1,1} = 70$, $R_{2,1} - L_{2,1} = 60$, $L_{2,1} \ge R_{1,1}$, along with $L_{1,1} \ge 0$ and $R_{2,1} \le 100$. Combining these inequalities gives $R_{2,1} \ge L_{2,1} + 60 \ge R_{1,1} + 60 \ge L_{1,1} + 70 + 60 \ge 130$. This contradicts the domain bound $R_{2,1} \le 100$. Thus, this subsystem is unsatisfiable for element 1, making `JOB 1` a valid certificate.

In Example 2, no single element violates the `JOB` subsystem. However, for `LOAD 1`, the subsystem requires four pairs of real numbers $(L_{1,i}, R_{1,i})$ to simultaneously satisfy $R_{1,i} - L_{1,i} = 50$, $L_{1,i} \ge 0$, and $R_{1,i} \le 150$. This means all four intervals of length 50 must be confined within the interval $[0, 150]$. The Phase 1 Non-overlap condition requires these intervals to be disjoint. The total length required is $4 \times 50 = 200$, which is strictly greater than the available space of 150. Thus, this subsystem is unsatisfiable, making `LOAD 1` a valid certificate.

<RATIONALE>
The problem was rewritten to use interval endpoints ($L$ and $R$) instead of interval centers ($u$ and $v$) and half-widths. This mathematically perfect isomorphism eliminates the absolute values and the specific algebraic sum $p_1 + p_2$ in the separation condition, breaking the string patterns that models used to blindly map the problem to two-machine flow-shop scheduling. Models must now algebraically evaluate the new system of inequalities to deduce the unsatisfiability criteria.
</RATIONALE>

The mapping $L_{1,i} = (u_i - p_{1,i})/2$, $R_{1,i} = (u_i + p_{1,i})/2$, and $W = T$ forms an exact bijection between the solution spaces of the seed and the rewrite, meaning the threshold for unsatisfiability of any subsystem remains mathematically identical for every input.
</PRESERVED_ANSWER>
