**Solution Explanation**

For every element `i`

* `q1[i] , q2[i]` – given positive integers  
* `T` – the global threshold  

We have to output a *certificate* that proves that the whole system of
constraints is unsatisfiable.
Only two kinds of certificates are allowed.

--------------------------------------------------------------------

### 1.  When does a `JOB i` certificate work ?

`JOB i` uses only the three constraints that involve element `i`

```
w1[i] ≥ q1[i]                     (boundary)
w2[i] ≤ 2·T – q2[i]               (boundary)
w2[i] – w1[i] ≥ q1[i] + q2[i]     (separation)
```

Eliminate the variables:

```
w2[i] ≤ 2·T – q2[i]          →   w1[i] ≤ 2·T – q2[i] – (q1[i] + q2[i])
w1[i] ≥ q1[i]
```

Both can hold **iff**

```
2·T – q2[i] – (q1[i] + q2[i])  ≥  q1[i]
⇔ 2·T ≥ 2·(q1[i] + q2[i])
⇔ T   ≥  q1[i] + q2[i]
```

Therefore a `JOB i` certificate is valid exactly when  

```
q1[i] + q2[i]  >  T
```

--------------------------------------------------------------------

### 2.  When does a `LOAD c` certificate work ?

`c` is either `1` or `2`.  
Only the *dispersion* constraints of stage `c` and the
boundary condition `S(wc[i], qc[i]) ≥ 0` are kept.

`S(w, q) ≥ 0` is equivalent to

```
q ≤ w ≤ 2·T – q                (1)
```

For two different elements `i , k` we may put one at its **lowest**
allowed position `q[i]` and the other at its **highest** allowed position
`2·T – q[k]`.  
The largest possible distance between them is therefore

```
(2·T – q[k]) – q[i] = 2·T – (q[i] + q[k])                (2)
```

The dispersion constraint needs a distance of at least `q[i] + q[k]`.
Hence a pair `i , k` can be placed **iff**

```
2·T – (q[i] + q[k])  ≥  q[i] + q[k]
⇔ 2·T               ≥  2·(q[i] + q[k])
⇔ T                 ≥  q[i] + q[k]                       (3)
```

Consequently, if there exists a pair with  

```
q[i] + q[k]  >  T
```

the subsystem of stage `c` is already impossible – a `LOAD c`
certificate is valid.

The condition (3) depends only on the **two largest** values of `qc`.
Let `mx1` be the largest, `mx2` the second largest.
If `mx1 + mx2 > T` then such a pair exists.

--------------------------------------------------------------------

### 3.  Whole algorithm

```
read j , T
read all (q1[i] , q2[i])

# 1) try to find a JOB certificate
for i = 1 .. j
        if q1[i] + q2[i] > T:
                output "JOB i" and stop

# 2) otherwise try LOAD 1
find the two largest values among all q1[i]   → mx1 , mx2
if mx1 + mx2 > T:
        output "LOAD 1" and stop

# 3) otherwise try LOAD 2 (guaranteed to exist by the statement)
find the two largest values among all q2[i]   → mx1 , mx2
output "LOAD 2"
```

The statement guarantees that at least one of the three checks succeeds,
so the algorithm always prints a correct certificate.

--------------------------------------------------------------------

### 4.  Correctness Proof  

We prove that the algorithm always outputs a valid certificate.

---

#### Lemma 1  
For an element `i` the subsystem consisting of its two boundary constraints
and its separation constraint is feasible **iff** `q1[i] + q2[i] ≤ T`.

*Proof.*  
Derived in section&nbsp;1. ∎



#### Lemma 2  
For a fixed stage `c` (`c = 1` or `2`) the subsystem consisting of all
dispersion constraints of that stage together with the boundary condition
`S(wc[i], qc[i]) ≥ 0` is infeasible **iff** there exist two indices
`i ≠ k` with `qc[i] + qc[k] > T`.

*Proof.*  
From (3) a pair can be placed iff `qc[i] + qc[k] ≤ T`.  
If a violating pair exists, the whole subsystem is already impossible,
because those two variables alone cannot satisfy their constraints.
Conversely, if every pair satisfies the inequality, we can place the
variables one after another inside the interval `[qc[i], 2·T‑qc[i]]`
keeping the required distances (e.g. greedily from left to right);
hence the subsystem is feasible. ∎



#### Lemma 3  
Let `mx1 ≥ mx2` be the two largest numbers among a multiset `Q`.
Then there exists a pair with sum `> T` **iff** `mx1 + mx2 > T`.

*Proof.*  
If `mx1 + mx2 > T` the pair `(mx1 , mx2)` itself violates the inequality.
If `mx1 + mx2 ≤ T`, every other element is ≤ `mx1`, therefore any pair sum
is ≤ `mx1 + mx2 ≤ T`. ∎



#### Theorem  
The algorithm always prints a line that is a valid certificate
(`JOB i` or `LOAD c`).

*Proof.*  

*Case 1* – the algorithm finds an index `i` with `q1[i] + q2[i] > T`
and outputs `JOB i`.  
By Lemma&nbsp;1 the corresponding subsystem is infeasible, therefore the
certificate is valid.

*Case 2* – no such index exists. Then for every `i`,
`q1[i] + q2[i] ≤ T`.  
The algorithm computes the two largest `q1` values.
If their sum exceeds `T`, by Lemma&nbsp;3 a violating pair exists,
and by Lemma&nbsp;2 the subsystem of stage 1 is infeasible.
The algorithm outputs `LOAD 1`, a valid certificate.

*Case 3* – the previous test failed, i.e. the two largest `q1` values satisfy
`mx1 + mx2 ≤ T`.  
Because the whole original problem is guaranteed unsatisfiable,
the only remaining possibility is that stage 2 alone is infeasible.
Again by Lemma&nbsp;3 the two largest `q2` values must satisfy
`mx1 + mx2 > T`; otherwise stage 2 would be feasible.
The algorithm therefore outputs `LOAD 2`, which is valid by Lemma&nbsp;2.

All possibilities are covered, so the algorithm always outputs a correct
certificate. ∎



--------------------------------------------------------------------

### 5.  Complexity Analysis  

*Reading input* – `O(j)` time, `O(1)` additional memory.  
*Finding the two largest values* – one linear scan per stage,
`O(j)` time, `O(1)` memory.  

Total time `O(j)` ( ≤ 2·10⁵ ) and memory `O(1)` besides the input storage,
well inside the limits.

--------------------------------------------------------------------

### 6.  Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    j = int(next(it))
    T = int(next(it))

    q1 = []
    q2 = []

    # first pass: look for JOB
    for idx in range(1, j + 1):
        a = int(next(it))
        b = int(next(it))
        q1.append(a)
        q2.append(b)
        if a + b > T:
            print(f"JOB {idx}")
            return

    # no JOB, try LOAD 1
    # find two largest q1
    mx1 = mx2 = -1
    for v in q1:
        if v > mx1:
            mx2 = mx1
            mx1 = v
        elif v > mx2:
            mx2 = v
    if mx1 + mx2 > T:
        print("LOAD 1")
        return

    # otherwise LOAD 2 must work
    mx1 = mx2 = -1
    for v in q2:
        if v > mx1:
            mx2 = mx1
            mx1 = v
        elif v > mx2:
            mx2 = v
    # by problem guarantee this condition holds
    print("LOAD 2")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
