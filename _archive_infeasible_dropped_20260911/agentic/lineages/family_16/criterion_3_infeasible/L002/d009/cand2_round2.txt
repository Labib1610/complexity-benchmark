<STATEMENT>
# Problem C — System of Inequalities: Certificate of Unsatisfiability

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a target threshold $T$ and a set of $j$ elements. Each element $i$ (from $1$ to $j$) is associated with two positive integers, $p_{1,i}$ and $p_{2,i}$.

Consider the problem of assigning two real numbers, $a_i$ and $b_i$, to each element $i$. The assignment must satisfy the following four conditions:
1. **Coupling:** For every element $i$, $a_i + b_i \le 2T - 2p_{1,i} - 2p_{2,i}$.
2. **A-Dispersion:** For every pair of distinct elements $i$ and $k$, either $a_i - a_k \ge 2p_{1,k}$ or $a_k - a_i \ge 2p_{1,i}$.
3. **B-Dispersion:** For every pair of distinct elements $i$ and $k$, either $b_i - b_k \ge 2p_{2,k}$ or $b_k - b_i \ge 2p_{2,i}$.
4. **Positivity:** For every element $i$, $a_i \ge 0$ and $b_i \ge 0$.

For every test case in this problem, it is guaranteed that no such assignment of $a_i$ and $b_i$ exists. Your task is to provide a directly checkable certificate of unsatisfiability by identifying a specific relaxed subsystem of these constraints that is already impossible to satisfy on its own. 

Output a valid certificate of unsatisfiability from one of the two allowed forms below. It is guaranteed that at least one such certificate exists for every test case.

- `JOB i` : For the element at 1-based index $i$, the constraints $a_i \ge 0$, $b_i \ge 0$, and Coupling (1) cannot be simultaneously satisfied (ignoring all other elements and conditions).
- `LOAD c` : where $c \in \{1, 2\}$. 
  - If $c=1$, it certifies that the constraints $a_i \ge 0$, A-Dispersion (2), and a bounding constraint $a_i \le 2T - 2p_{1,i}$ for all $i$, cannot be simultaneously satisfied (ignoring $b_i$, $p_{2,i}$, and all other conditions). 
  - If $c=2$, it certifies that the constraints $b_i \ge 0$, B-Dispersion (3), and a bounding constraint $b_i \le 2T - 2p_{2,i}$ for all $i$, cannot be simultaneously satisfied (ignoring $a_i$, $p_{1,i}$, and all other conditions).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the values of $p_{1,i}$ and $p_{2,i}$ for the $i$-th element.

## Output

Print a single line containing a valid certificate: `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for element 1, the `JOB` subsystem requires $a_1 \ge 0$, $b_1 \ge 0$, and $a_1 + b_1 \le 2(100) - 2(70) - 2(60) = -60$. Since $a_1 \ge 0$ and $b_1 \ge 0$ implies $a_1 + b_1 \ge 0$, this contradicts $a_1 + b_1 \le -60$. Thus, this subsystem is unsatisfiable for element 1, making `JOB 1` a valid certificate.

In Example 2, no single element violates the `JOB` subsystem (for all $i$, $2T - 2p_{1,i} - 2p_{2,i} = 300 - 100 - 2 = 198 \ge 0$). However, for `LOAD 1`, the subsystem requires four real numbers $a_i$ to simultaneously satisfy $a_i \ge 0$ and $a_i \le 2(150) - 2(50) = 200$. The A-Dispersion condition requires that for any distinct pair $i, k$, either $a_i - a_k \ge 100$ or $a_k - a_i \ge 100$. Sorting the four values $a_i$ in ascending order, say $a_{(1)} \le a_{(2)} \le a_{(3)} \le a_{(4)}$, the A-Dispersion condition forces $a_{(2)} \ge a_{(1)} + 100$, $a_{(3)} \ge a_{(2)} + 100$, and $a_{(4)} \ge a_{(3)} + 100$. This recursively requires $a_{(4)} \ge a_{(1)} + 300 \ge 300$. But the bounding constraint requires $a_{(4)} \le 200$, creating a contradiction. Thus, this subsystem is unsatisfiable, making `LOAD 1` a valid certificate.
