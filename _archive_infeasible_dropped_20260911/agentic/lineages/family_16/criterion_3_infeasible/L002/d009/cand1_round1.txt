# Problem C — System of Inequalities: Certificate of Unsatisfiability

Time limit: 2 s   Memory limit: 256 MB

## Description

You are verifying the design of an integrated circuit with $j$ parallel transmission channels. The total available voltage headroom is $2T$.
For each channel $i$ (from $1$ to $j$), you must assign a steady-state starting voltage $V_{S,i}$ and a terminating voltage $V_{T,i}$.
The input provides two parameters for each channel $i$: the source noise margin $p_{1,i}$ and the terminal noise margin $p_{2,i}$.

To ensure signal integrity, the assignment of $V_{S,i}$ and $V_{T,i}$ must satisfy four rules:
1. **Voltage Drop:** For every channel $i$, $V_{T,i} - V_{S,i} \ge p_{1,i} + p_{2,i}$.
2. **Source Separation:** For every pair of distinct channels $i$ and $k$, $|V_{S,i} - V_{S,k}| \ge p_{1,i} + p_{1,k}$.
3. **Terminal Separation:** For every pair of distinct channels $i$ and $k$, $|V_{T,i} - V_{T,k}| \ge p_{2,i} + p_{2,k}$.
4. **Operating Range:** For every channel $i$, $V_{S,i} \ge p_{1,i}$ and $V_{T,i} \le 2T - p_{2,i}$.

It is a known property of the given test cases that no such assignment of voltages is possible. Your task is to provide a directly checkable error code by identifying a specific relaxed subsystem of these rules that is already impossible to satisfy on its own.

Output a valid error code from one of the two allowed forms below. If multiple error codes are valid, you may output any one of them.

- `JOB i` (Junction Over-Bias): For the channel at 1-based index $i$, the Operating Range bounds ($V_{S,i} \ge p_{1,i}$ and $V_{T,i} \le 2T - p_{2,i}$) and the Voltage Drop rule cannot be simultaneously satisfied, even if all other channels are ignored.
- `LOAD c` (Line Over-Allocation Defect): where $c \in \{1, 2\}$. 
  - If $c=1$, it certifies that the Source Separation rule cannot be satisfied if every starting voltage is restricted to the modified range $p_{1,i} \le V_{S,i} \le 2T - p_{1,i}$, even if $V_{T,i}$, $p_{2,i}$, and all other rules are ignored. 
  - If $c=2$, it certifies that the Terminal Separation rule cannot be satisfied if every terminating voltage is restricted to the modified range $p_{2,i} \le V_{T,i} \le 2T - p_{2,i}$, even if $V_{S,i}$, $p_{1,i}$, and all other rules are ignored.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the values of $p_{1,i}$ and $p_{2,i}$ for the $i$-th channel.

## Output

Print a single line containing a valid error code: `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for channel 1, the `JOB` subsystem requires $V_{S,1} \ge 70$, $V_{T,1} - V_{S,1} \ge 130$, and $V_{T,1} \le 140$. Combining the first two inequalities gives $V_{T,1} \ge 200$, which contradicts $V_{T,1} \le 140$. Thus, this subsystem is unsatisfiable for channel 1, making `JOB 1` a valid error code.

In Example 2, no single channel violates the `JOB` subsystem. However, for `LOAD 1`, the subsystem requires four real numbers $V_{S,i}$ to simultaneously satisfy $V_{S,i} \ge 50$ and $V_{S,i} \le 250$, meaning all $V_{S,i}$ are confined to an interval of length $200$. The Source Separation rule requires $|V_{S,i} - V_{S,k}| \ge 100$ for all distinct pairs. It is mathematically impossible to place four points mutually separated by at least 100 within an interval of length 200. Thus, this subsystem is unsatisfiable, making `LOAD 1` a valid error code.
