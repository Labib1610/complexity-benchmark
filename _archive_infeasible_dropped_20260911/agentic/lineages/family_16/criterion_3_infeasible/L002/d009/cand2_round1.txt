<STATEMENT>
# Problem C — Cryptographic Nonce Allocation: Certificate of Failure

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a shared entropy pool parameter $T$ and a set of $j$ client devices. Each client $i$ (from $1$ to $j$) provides two positive integer entropy requirements: $E_{1,i}$ and $E_{2,i}$.

Consider the problem of assigning two real numbers, a primary nonce $u_i$ and a secondary nonce $v_i$, to each client $i$. The assignment must satisfy the following four protocol conditions:

1. **Intra-Client Entropy:** For every client $i$, the secondary nonce must exceed the primary nonce by at least the sum of their requirements: $v_i - u_i \ge E_{1,i} + E_{2,i}$.
2. **Primary Nonce Sequencing:** There must exist a permutation $\pi$ of all $j$ clients such that for every step $m$ from $1$ to $j-1$, the client $x = \pi[m]$ and the next client $y = \pi[m+1]$ satisfy $u_y - u_x \ge E_{1,x} + E_{1,y}$.
3. **Secondary Nonce Sequencing:** There must exist a permutation $\sigma$ of all $j$ clients (which may be different from $\pi$) such that for every step $m$ from $1$ to $j-1$, the client $x = \sigma[m]$ and the next client $y = \sigma[m+1]$ satisfy $v_y - v_x \ge E_{2,x} + E_{2,y}$.
4. **Pool Boundaries:** For every client $i$, $u_i \ge E_{1,i}$ and $v_i \le 2T - E_{2,i}$.

For every test case in this problem, it is guaranteed that no such assignment of $u_i$ and $v_i$ exists. Your task is to provide a directly checkable certificate of failure by identifying a specific relaxed subsystem of these constraints that is already impossible to satisfy on its own. 

Output a valid certificate of failure from one of the two allowed forms below. It is guaranteed that at least one such certificate exists for every test case.

- `JOB i` : Stands for **J**ustified **O**verreach **B**reach. For the client at 1-based index $i$, the constraints $u_i \ge E_{1,i}$, Intra-Client Entropy (1), and $v_i \le 2T - E_{2,i}$ cannot be simultaneously satisfied (ignoring all other clients and conditions).
- `LOAD c` : Stands for **L**inear **O**rdering **A**nomaly **D**iagnostic, where $c \in \{1, 2\}$. 
  - If $c=1$, it certifies that no permutation $\pi$ and real numbers $u_i$ can simultaneously satisfy $u_i \ge E_{1,i}$, Primary Nonce Sequencing (2), and a modified upper bound $u_i \le 2T - E_{1,i}$ for all $i$ (ignoring $v_i$, $E_{2,i}$, and all other conditions). 
  - If $c=2$, it certifies that no permutation $\sigma$ and real numbers $v_i$ can simultaneously satisfy a modified lower bound $v_i \ge E_{2,i}$, Secondary Nonce Sequencing (3), and $v_i \le 2T - E_{2,i}$ for all $i$ (ignoring $u_i$, $E_{1,i}$, and all other conditions).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **E1** and **E2** (1 ≤ E1, E2 ≤ 1000000): the entropy requirements $E_{1,i}$ and $E_{2,i}$ for the $i$-th client.

## Output

Print a single line containing a valid certificate: `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for client 1, the `JOB` subsystem requires $u_1 \ge 70$, $v_1 - u_1 \ge 130$, and $v_1 \le 140$. Combining the first two inequalities gives $v_1 \ge 200$, which contradicts $v_1 \le 140$. Thus, this isolated subsystem is unsatisfiable for client 1, making `JOB 1` a valid certificate.

In Example 2, no single client violates the `JOB` subsystem. However, for `LOAD 1`, the subsystem requires four real numbers $u_i$ to simultaneously satisfy $u_i \ge 50$ and $u_i \le 250$. The Primary Nonce Sequencing condition requires finding a permutation $\pi$ where each adjacent pair $x, y$ satisfies $u_y - u_x \ge 100$. By chaining these inequalities along any permutation of the 4 clients, the total required difference between the first and last client's nonces is at least $300$. However, the bounds $u_i \ge 50$ and $u_i \le 250$ restrict the maximum possible difference between any two nonces to $200$. Thus, no permutation can satisfy this subsystem, making `LOAD 1` a valid certificate.

<RATIONALE>
Replaced the absolute-value disjointness constraints with a sequence-based adjacent-difference constraint, completely obscuring the 1D interval-packing nature of the original problem. The output strings (JOB/LOAD) were preserved but redefined as arbitrary acronyms to break memorized heuristics from models that recognize the specific output format of the seed. Models are forced to independently deduce that the telescoping sum of the permutation constraints evaluates to a permutation-invariant total sum.
</RATIONALE>
<PRESERVED_ANSWER>
The existence of a valid sequence of adjacent differences is mathematically identical to the absolute-value all-pairs disjointness condition; the telescoping sum evaluates to exactly $2\sum E_1 \le 2T$, making the conditions for the certificates universally identical to the seed.
</PRESERVED_ANSWER>

The complexity class remains unchanged ($O(N)$ linear scan) because the underlying invariant evaluated by the certificates ($\sum E_1 > T$, $\sum E_2 > T$, or $E_1 + E_2 > T$) is perfectly preserved.
