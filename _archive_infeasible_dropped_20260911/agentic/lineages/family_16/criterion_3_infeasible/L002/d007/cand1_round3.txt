<METHOD_NAME>Integral Orthogonality of Indicator Functions</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the "intervals do not intersect" constraints with an equivalent $L_2$ norm condition on the sum of indicator (step) functions: $\int (\sum \phi_i)^2 = \sum p_{1,i}$. This mathematically enforces disjointness (since cross-terms must integrate to zero) without using the words "intersect", "disjoint", or "interval", defeating models that rely on geometric or scheduling keyword triggers. The Note explains the unsatisfiability using Cauchy-Schwarz, further masking the $L_1$ interval-packing shortcut.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem C — System of Inequalities: Certificate of Unsatisfiability

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a target threshold $T$ and a set of $j$ elements. Each element $i$ (from $1$ to $j$) is associated with two positive integers, $p_{1,i}$ and $p_{2,i}$.

Consider the problem of assigning two non-negative real numbers, $x_i$ and $y_i$, to each element $i$. For each element, we define two step functions over the real numbers $t$:
- $\phi_i(t) = 1$ if $x_i \le t < x_i + p_{1,i}$, and $0$ otherwise.
- $\psi_i(t) = 1$ if $y_i \le t < y_i + p_{2,i}$, and $0$ otherwise.

The assignment must satisfy the following four conditions:
1. **Separation:** For every element $i$, $x_i + p_{1,i} \le y_i$.
2. **First-stage orthogonality:** $\int_{-\infty}^{\infty} \left( \sum_{i=1}^j \phi_i(t) \right)^2 dt = \sum_{i=1}^j p_{1,i}$.
3. **Second-stage orthogonality:** $\int_{-\infty}^{\infty} \left( \sum_{i=1}^j \psi_i(t) \right)^2 dt = \sum_{i=1}^j p_{2,i}$.
4. **Threshold:** For every element $i$, $y_i + p_{2,i} \le T$.

For every test case in this problem, it is guaranteed that no such assignment of $x_i$ and $y_i$ exists. Your task is to provide a directly checkable certificate of unsatisfiability by identifying a specific relaxed subsystem of these constraints that is already impossible to satisfy on its own. 

Output a valid certificate of unsatisfiability from one of the two allowed forms below. It is guaranteed that at least one such certificate exists for every test case.

- `JOB i` : For the element at 1-based index $i$, the constraints $x_i \ge 0$, Separation (1), and Threshold (4) cannot be simultaneously satisfied (ignoring all other elements and conditions).
- `LOAD c` : where $c \in \{1, 2\}$. 
  - If $c=1$, it certifies that the constraints $x_i \ge 0$, First-stage orthogonality (2), and a modified threshold $x_i + p_{1,i} \le T$ for all $i$, cannot be simultaneously satisfied (ignoring $y_i$, $p_{2,i}$, and all other conditions). 
  - If $c=2$, it certifies that the constraints $y_i \ge 0$, Second-stage orthogonality (3), and Threshold (4) for all $i$, cannot be simultaneously satisfied (ignoring $x_i$, $p_{1,i}$, and all other conditions).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the values of $p_{1,i}$ and $p_{2,i}$ for the $i$-th element.

## Output

Print a single line containing a valid certificate: `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for element 1, the `JOB` subsystem requires $x_1 \ge 0$, $x_1 + 70 \le y_1$, and $y_1 + 60 \le 100$. This implies $x_1 \le -30$, which contradicts $x_1 \ge 0$. Thus, this subsystem is unsatisfiable for element 1, making `JOB 1` a valid certificate.

In Example 2, no single element violates the `JOB` subsystem. However, for `LOAD 1`, the subsystem requires four step functions $\phi_i$, each integrating to 50, such that $\phi_i(t)=0$ outside $[0, 150]$. Let $f(t) = \sum_{i=1}^4 \phi_i(t)$. We have $\int_0^{150} f(t) dt = 200$. By the Cauchy-Schwarz inequality, $\int_0^{150} f(t)^2 dt \ge \frac{1}{150} \left(\int_0^{150} f(t) dt\right)^2 = \frac{40000}{150} \approx 266.67$. However, the First-stage orthogonality condition strictly requires $\int_0^{150} f(t)^2 dt = \sum_{i=1}^4 p_{1,i} = 200$. Since $266.67 > 200$, this contradicts the requirement. Thus, this subsystem is unsatisfiable, making `LOAD 1` a valid certificate.

<RATIONALE>
The rewrite maintains the exact mathematical structure of the seed but replaces the explicit "intervals do not intersect" language with an equivalent $L_2$ norm condition on the sum of indicator functions. This forces models to deeply analyze the integral constraint to realize it implies disjointness (and thus bounds the sum of lengths), rather than relying on surface-level keyword mapping to interval packing.
</RATIONALE>

The $L_2$ norm condition is mathematically identical to the non-intersecting interval condition, meaning the exact same subsystems are unsatisfiable for exactly the same inputs.
