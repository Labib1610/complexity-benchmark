We can solve this by checking two possible certificate types:

1. **JOB i**: For each element, check if  
   \( x_i \ge 0 \), \( x_i + p_{1,i} \le y_i \), and \( y_i + p_{2,i} \le T \)  
   can all hold.  
   This is possible only if  
   \( p_{1,i} + p_{2,i} \le T \).  
   If any element violates this, output `JOB i`.

2. **LOAD c**:  
   - For `LOAD 1`: We need to check if we can place intervals of lengths \( p_{1,i} \) inside \([0, T]\) such that they are non-overlapping (orthogonality condition).  
     This is possible iff the sum of all \( p_{1,i} \le T \).  
     If sum > T, output `LOAD 1`.  
   - For `LOAD 2`: Similarly, check if sum of all \( p_{2,i} \le T \). If not, output `LOAD 2`.

Since the problem guarantees at least one certificate exists, we can check in this order.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    j = int(data[0])
    T = int(data[1])
    p1 = []
    p2 = []
    idx = 2
    for _ in range(j):
        p1.append(int(data[idx]))
        p2.append(int(data[idx+1]))
        idx += 2

    # Check JOB certificates
    for i in range(j):
        if p1[i] + p2[i] > T:
            print(f"JOB {i+1}")
            return

    # Check LOAD 1
    if sum(p1) > T:
        print("LOAD 1")
        return

    # Check LOAD 2
    if sum(p2) > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
