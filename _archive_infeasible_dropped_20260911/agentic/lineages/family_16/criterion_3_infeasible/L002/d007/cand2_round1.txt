# Problem C — System of Inequalities: Certificate of Unsatisfiability

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a target threshold $T$ and a set of $j$ elements. Each element $i$ (from $1$ to $j$) is associated with two positive integers, $p_{1,i}$ and $p_{2,i}$.

Consider the problem of assigning two non-negative real numbers, $S_i$ and $U_i$, to each element $i$ such that the following four conditions hold:
1. **Intra-element bound:** For every element $i$, $U_i - S_i \ge p_{1,i}$.
2. **Primary relational bound:** For any pair of distinct elements $i$ and $k$,
   $$(S_i - S_k)^2 + (p_{1,i} - p_{1,k})(S_i - S_k) \ge p_{1,i} p_{1,k}$$
3. **Secondary relational bound:** For any pair of distinct elements $i$ and $k$,
   $$(U_i - U_k)^2 + (p_{2,i} - p_{2,k})(U_i - U_k) \ge p_{2,i} p_{2,k}$$
4. **Terminal bound:** For every element $i$, $U_i + p_{2,i} \le T$.

For every test case in this problem, it is guaranteed that no such assignment of $S_i$ and $U_i$ exists. Your task is to provide a directly checkable certificate of unsatisfiability by identifying a specific relaxed subsystem of these constraints that is already impossible to satisfy on its own. 

Output a valid certificate of unsatisfiability from one of the two allowed forms below. It is guaranteed that at least one such certificate exists for every test case.

- `JOB i` : For the element at 1-based index $i$, the constraints $S_i \ge 0$, Intra-element bound (1), and Terminal bound (4) cannot be simultaneously satisfied (ignoring all other elements and conditions).
- `LOAD c` : where $c \in \{1, 2\}$. 
  - If $c=1$, it certifies that the constraints $S_i \ge 0$, Primary relational bound (2), and a modified terminal bound $S_i + p_{1,i} \le T$ for all $i$, cannot be simultaneously satisfied (ignoring $U_i$, $p_{2,i}$, and all other conditions). 
  - If $c=2$, it certifies that the constraints $U_i \ge 0$, Secondary relational bound (3), and Terminal bound (4) for all $i$, cannot be simultaneously satisfied (ignoring $S_i$, $p_{1,i}$, and all other conditions).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the values of $p_{1,i}$ and $p_{2,i}$ for the $i$-th element.

## Output

Print a single line containing a valid certificate: `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for element 1, the `JOB` subsystem requires $S_1 \ge 0$, $U_1 - S_1 \ge 70$, and $U_1 + 60 \le 100$. This implies $S_1 \le -30$, which contradicts $S_1 \ge 0$. Thus, this subsystem is unsatisfiable for element 1, making `JOB 1` a valid certificate.

In Example 2, no single element violates the `JOB` subsystem. However, for `LOAD 1`, the subsystem requires four values $S_1, S_2, S_3, S_4 \ge 0$ satisfying $S_i + 50 \le 150$ for all $i$, and for any distinct $i, k$, the Primary relational bound $(S_i - S_k)^2 + (50 - 50)(S_i - S_k) \ge 2500$, which simplifies to $(S_i - S_k)^2 \ge 2500$, meaning $|S_i - S_k| \ge 50$. Placing four values mutually at least 50 apart requires a spread of at least 150 from the minimum to the maximum. Since the minimum is at least 0, the maximum must be at least 150, meaning $S_i + 50 \ge 200$ for that maximum element, which violates $S_i + 50 \le 150$. Thus, this subsystem is unsatisfiable, making `LOAD 1` a valid certificate.

<RATIONALE>
The explicit condition that "open-ended intervals do not intersect" has been replaced with a mathematically exact quadratic algebraic inequality. Because $(x-y)^2 + (A-B)(x-y) \ge AB$ factors directly to $(x-y+A)(x-y-B) \ge 0$, it strictly enforces that $x \ge y+B$ or $y \ge x+A$, perfectly preserving the 1D packing logic. By hiding the interval disjointness behind a polynomial form, models that rely on surface pattern matching of scheduling/packing keywords will fail to recognize that the sum of the parameters is bounded by $T$, forcing them to actually factor the quadratic to rediscover the underlying structure.
</RATIONALE>
