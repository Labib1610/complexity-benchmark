# Problem C — System of Inequalities: Certificate of Unsatisfiability

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a target threshold $T$ and a set of $j$ elements. Each element $i$ (from $1$ to $j$) is associated with two positive integers, $p_{1,i}$ and $p_{2,i}$.

Consider the problem of assigning two non-negative real numbers, $x_i$ and $y_i$, to each element $i$ such that the following four conditions hold:
1. **Precedence:** For every element $i$, $y_i - x_i \ge p_{1,i}$.
2. **First-stage separation:** For any pair of distinct elements $i$ and $k$, $(x_i - x_k)^2 + (x_i - x_k)(p_{1,i} - p_{1,k}) \ge p_{1,i} p_{1,k}$.
3. **Second-stage separation:** For any pair of distinct elements $i$ and $k$, $(y_i - y_k)^2 + (y_i - y_k)(p_{2,i} - p_{2,k}) \ge p_{2,i} p_{2,k}$.
4. **Threshold:** For every element $i$, $y_i + p_{2,i} \le T$.

For every test case in this problem, it is guaranteed that no such assignment of $x_i$ and $y_i$ exists. Your task is to provide a directly checkable certificate of unsatisfiability by identifying a specific relaxed subsystem of these constraints that is already impossible to satisfy on its own. 

Output a valid certificate of unsatisfiability from one of the two allowed forms below. It is guaranteed that at least one such certificate exists for every test case.

- `JOB i` : For the element at 1-based index $i$, the constraints $x_i \ge 0$, Precedence (1), and Threshold (4) cannot be simultaneously satisfied (ignoring all other elements and conditions).
- `LOAD c` : where $c \in \{1, 2\}$. 
  - If $c=1$, it certifies that the constraints $x_i \ge 0$, First-stage separation (2), and a modified threshold $x_i + p_{1,i} \le T$ for all $i$, cannot be simultaneously satisfied (ignoring $y_i$, $p_{2,i}$, and all other conditions). 
  - If $c=2$, it certifies that the constraints $y_i \ge 0$, Second-stage separation (3), and Threshold (4) for all $i$, cannot be simultaneously satisfied (ignoring $x_i$, $p_{1,i}$, and all other conditions).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the values of $p_{1,i}$ and $p_{2,i}$ for the $i$-th element.

## Output

Print a single line containing a valid certificate: `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for element 1, the `JOB` subsystem requires $x_1 \ge 0$, $y_1 - x_1 \ge 70$, and $y_1 + 60 \le 100$. This implies $x_1 \le -30$, which contradicts $x_1 \ge 0$. Thus, this subsystem is unsatisfiable for element 1, making `JOB 1` a valid certificate.

In Example 2, no single element violates the `JOB` subsystem. However, for `LOAD 1`, the subsystem requires assigning four non-negative variables $x_1, x_2, x_3, x_4$ such that $x_i + 50 \le 150$. The separation condition simplifies to $(x_i - x_k)^2 \ge 2500$ for all distinct pairs. Satisfying this for four variables requires a domain span of at least 150, but the constraints restrict each $x_i$ to the span $[0, 100]$. Thus, this subsystem is unsatisfiable, making `LOAD 1` a valid certificate.

<RATIONALE>
The problem was completely reframed from a task scheduling/interval-packing scenario into a pure algebraic system of inequalities. The critical "non-overlapping intervals" condition was replaced with the strictly mathematically equivalent quadratic inequality $(x_i - x_k)^2 + (x_i - x_k)(p_{1,i} - p_{1,k}) \ge p_{1,i} p_{1,k}$. This forces models to algebraically factor the polynomial to discover the underlying 1D spatial constraints, preventing them from using surface-level text matching to immediately deduce the "sum of lengths > span" heuristic.
</RATIONALE>
<PRESERVED_ANSWER>
The quadratic inequality factors exactly into $(x_i - x_k - p_{1,k})(x_i - x_k + p_{1,i}) \ge 0$, which is mathematically identical to the condition that the open intervals $(x_i, x_i+p_{1,i})$ and $(x_k, x_k+p_{1,k})$ do not intersect, ensuring all unsatisfiability conditions remain identical.
</PRESERVED_ANSWER>

The problem still requires exactly the same $O(N)$ linear scans to sum the parameters and check them against $T$, keeping the time complexity completely unchanged.
</PRESERVED_CLASS>
