<STATEMENT>
# Problem C — System of Inequalities: Certificate of Unsatisfiability

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a target threshold $T$ and a set of $j$ elements. Each element $i$ (from $1$ to $j$) is associated with two positive integers, $p_{1,i}$ and $p_{2,i}$.

Consider the problem of assigning two real numbers, $M_{1,i}$ and $M_{2,i}$, to each element $i$ such that the following four conditions hold:
1. **Precedence:** For every element $i$, $M_{1,i} + \frac{p_{1,i}}{2} \le M_{2,i} - \frac{p_{2,i}}{2}$.
2. **First-stage spacing:** For any pair of distinct elements $i$ and $k$, $|M_{1,i} - M_{1,k}| \ge \frac{p_{1,i} + p_{1,k}}{2}$.
3. **Second-stage spacing:** For any pair of distinct elements $i$ and $k$, $|M_{2,i} - M_{2,k}| \ge \frac{p_{2,i} + p_{2,k}}{2}$.
4. **Upper Bound:** For every element $i$, $M_{2,i} + \frac{p_{2,i}}{2} \le T$.

For every test case in this problem, it is guaranteed that no valid assignment of $M_{1,i}$ and $M_{2,i}$ exists (even when assuming a lower bound of $M_{1,i} - \frac{p_{1,i}}{2} \ge 0$). Your task is to provide a directly checkable certificate of unsatisfiability. 

Exactly one of the following two reason types is guaranteed to apply for every input; print the one that applies:

- `JOB i` : For the element at 1-based index $i$, the constraints $M_{1,i} - \frac{p_{1,i}}{2} \ge 0$, Precedence (1), and Upper Bound (4) cannot be simultaneously satisfied (ignoring all other elements and conditions).
- `LOAD c` : where $c \in \{1, 2\}$. 
  - If $c=1$, it certifies that the constraints $M_{1,i} - \frac{p_{1,i}}{2} \ge 0$, First-stage spacing (2), and a modified bound $M_{1,i} + \frac{p_{1,i}}{2} \le T$ for all $i$, cannot be simultaneously satisfied (ignoring $M_{2,i}$, $p_{2,i}$, and all other conditions). 
  - If $c=2$, it certifies that the constraints $M_{2,i} - \frac{p_{2,i}}{2} \ge 0$, Second-stage spacing (3), and Upper Bound (4) for all $i$, cannot be simultaneously satisfied (ignoring $M_{1,i}$, $p_{1,i}$, and all other conditions).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the values of $p_{1,i}$ and $p_{2,i}$ for the $i$-th element.

## Output

Print a single line containing a valid certificate: `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for element 1, the `JOB` conditions require $M_{1,1} - 35 \ge 0$, $M_{1,1} + 35 \le M_{2,1} - 30$, and $M_{2,1} + 30 \le 100$. This implies $M_{1,1} \le 5$, which contradicts $M_{1,1} \ge 35$. Thus, these conditions are unsatisfiable for element 1, making `JOB 1` the applicable certificate.

In Example 2, no single element violates the `JOB` conditions. However, for `LOAD 1`, the conditions require finding $M_{1,i}$ for four elements such that $M_{1,i} - 25 \ge 0$, $M_{1,i} + 25 \le 150$, and for any distinct pair, $|M_{1,i} - M_{1,k}| \ge 50$. This requires placing four points in the interval $[25, 125]$ such that any two are at least 50 units apart. The maximum number of such points that can fit in a span of 100 is 3 (e.g., at 25, 75, and 125). Thus, placing four points is impossible, making `LOAD 1` the applicable certificate.

<RATIONALE>
The problem has been reformulated from interval scheduling (start times $S_i$ and lengths $p_{1,i}$) into a 1D sphere packing equivalent using midpoints ($M_{1,i}$) and absolute differences. This preserves the exact mathematical logic while removing the keywords and surface structures that trigger models to automatically sum the lengths. The solver must now deduce that the absolute difference constraints on midpoints are isomorphic to bounding the sum of the diameters.
</RATIONALE>

The midpoint-radius formulation is algebraically identical to the original interval formulation via the substitution $S_i = M_{1,i} - p_{1,i}/2$, so the exact same conditions trigger the exact same certificates for all inputs.
