# Problem C — System of Inequalities: Certificate of Unsatisfiability

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a target threshold $T$ and a set of $j$ elements. Each element $i$ (from $1$ to $j$) is associated with two positive integers, $p_{1,i}$ and $p_{2,i}$.

Consider the problem of assigning four real numbers to each element $i$: a primary start $S_i$, a primary end $E_i$, a secondary start $U_i$, and a secondary end $V_i$, such that the following conditions hold simultaneously:
1. **Primary Span:** For every element $i$, $E_i - S_i = p_{1,i}$ and $S_i \ge 0$.
2. **Secondary Span:** For every element $i$, $V_i - U_i = p_{2,i}$.
3. **Sequential Link:** For every element $i$, $E_i \le U_i$.
4. **Primary Separation:** For any pair of distinct elements $i$ and $k$, the open-ended intervals $[S_i, E_i)$ and $[S_k, E_k)$ do not intersect.
5. **Secondary Separation:** For any pair of distinct elements $i$ and $k$, the open-ended intervals $[U_i, V_i)$ and $[U_k, V_k)$ do not intersect.
6. **Threshold Limit:** For every element $i$, $V_i \le T$.

For every test case in this problem, it is guaranteed that no such assignment of variables exists. Your task is to provide a directly checkable certificate of unsatisfiability by identifying a specific relaxed subsystem of these constraints that is already impossible to satisfy on its own.

Output a valid certificate of unsatisfiability from one of the two allowed categories below. Inputs are constructed so you will never have both a valid `JOB`-type and a valid `LOAD`-type certificate. Exactly one of the two certificate categories below is applicable, and you must print the certificate form corresponding to the unique applicable category.

- `JOB i` : For the element at 1-based index $i$, the constraints Primary Span (1), Secondary Span (2), Sequential Link (3), and Threshold Limit (6) cannot be simultaneously satisfied (ignoring all other elements and conditions).
- `LOAD c` : where $c \in \{1, 2\}$. 
  - If $c=1$, it certifies that the constraints Primary Span (1), Primary Separation (4), and a modified threshold limit $E_i \le T$ for all $i$, cannot be simultaneously satisfied (ignoring Secondary Span, Secondary Separation, Sequential Link, and all other conditions). 
  - If $c=2$, it certifies that the constraints $U_i \ge 0$, Secondary Span (2), Secondary Separation (5), and Threshold Limit (6) for all $i$, cannot be simultaneously satisfied (ignoring Primary Span, Primary Separation, Sequential Link, and all other conditions).

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the values of $p_{1,i}$ and $p_{2,i}$ for the $i$-th element.

## Output

Print a single line containing a valid certificate: `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for element 1, the `JOB` subsystem requires $E_1 - S_1 = 70$, $S_1 \ge 0$, $V_1 - U_1 = 60$, $E_1 \le U_1$, and $V_1 \le 100$. This chain implies $S_1 + 70 + 60 \le 100$, so $S_1 \le -30$, which contradicts $S_1 \ge 0$. Thus, this subsystem is unsatisfiable for element 1, making `JOB 1` a valid certificate.

In Example 2, no single element violates the `JOB` subsystem. However, for `LOAD 1`, the subsystem requires placing four disjoint intervals $[S_i, E_i)$ of length $E_i - S_i = 50$ into the bounds $[0, 150]$ (since $S_i \ge 0$ and $E_i \le 150$). This requires a total length of 200, which cannot fit in a span of 150. Thus, this subsystem is unsatisfiable, making `LOAD 1` a valid certificate.
