<STATEMENT>
# Problem C — Impossible Deadline: Certify It

Time limit: 2 s
Memory limit: 256 MB

## Description

A chef is preparing a banquet featuring $j$ special recipes, tracked in the kitchen's order system as `JOB`s. Every `JOB` must be baked in appliance 1 (the oven) first and then finished in appliance 2 (the broiler). For each `JOB`, you are given its required time in appliance 1 and in appliance 2. Each appliance processes only one `JOB` at a time, and a `JOB` reaches appliance 2 only after finishing in appliance 1.

There is a strict time limit $T$: every `JOB` must be completely finished by time $T$.

For every input in this problem, it is guaranteed that the time limit cannot be met, no matter how the chef orders the preparation. Your task is not to search for a schedule; it is to prove the time limit is impossible by providing a short certificate that can be checked directly against the input.

To independently verify the impossibility, a checker requires a valid certificate. Exactly one of the following reasons always applies. Print the certificate that holds:

- **Sequential constraint violated.** The certificate is `JOB i` (where $i$ is the 1-based index of a job). This is valid if and only if the sequential processing time for this specific job strictly exceeds the deadline: $p1_i + p2_i > T$.
- **Capacity constraint violated.** The certificate is `LOAD c` (where $c \in \{1, 2\}$ is the appliance number). This is valid if and only if the sum of all processing times on appliance $c$ strictly exceeds the deadline (i.e., $\sum p1 > T$ for appliance 1, or $\sum p2 > T$ for appliance 2).

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p1$ and $p2$ ($1 \le p1, p2 \le 1000000$): the required times of a `JOB` in appliance 1 and appliance 2.

## Output

Print a single line containing the unique valid certificate for the given input: either `JOB i` (where $i$ is 1-based and satisfies $p1_i + p2_i > T$) or `LOAD c` (where $c \in \{1, 2\}$ and the total load on appliance $c$ strictly exceeds $T$).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for `JOB` 1, the sequential time is $70 + 60 = 130$. Since $130 > 100$, the sequential constraint is violated, making `JOB 1` a valid certificate.
In Example 2, no single `JOB` exceeds $150$ sequentially, but appliance 1 must process $50+50+50+50 = 200$ units of work in total. Since $200 > 150$, the capacity constraint is violated, making `LOAD 1` the valid certificate.
