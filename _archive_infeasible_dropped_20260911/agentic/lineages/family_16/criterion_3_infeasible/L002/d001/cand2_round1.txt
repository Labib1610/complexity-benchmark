# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A chef is preparing a banquet featuring **j** special recipes, tracked in the kitchen's order system as `JOB`s. Every `JOB` must be baked in appliance 1 (the oven) first and then finished in appliance 2 (the broiler). For each `JOB` you are given its required time in appliance 1 and in appliance 2. Each appliance processes only one `JOB` at a time, and a `JOB` reaches appliance 2 only after finishing in appliance 1.

There is a strict time limit **T**: every `JOB` must be completely finished by time **T**.

For every input in this problem it is **guaranteed that the time limit cannot be met**, no matter how the chef orders the preparation. Your task is not to search for a schedule; it is to **prove** the time limit is impossible with a short certificate that isolates the structural bottleneck.

You must output a certificate in one of two formats, depending on the nature of the bottleneck:

- `JOB i` : Use this format if a specific recipe **i** (1-based index) has inherent sequential processing constraints that strictly prevent it from finishing by time **T**, even if it were the only recipe in the kitchen.
- `LOAD c` : Use this format if a specific appliance **c** (1 or 2) has serialized processing constraints that require more active time than the deadline permits, rendering the time limit impossible regardless of the other appliance's schedule.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required times of a `JOB` in appliance 1 and appliance 2.

## Output

Print a single line containing the valid certificate (`JOB i` or `LOAD c`) that proves the deadline is impossible for the given input.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` proves the time limit is impossible because its sequential processing requirement prevents it from finishing by the deadline. In Example 2, appliance 1 proves the impossibility because its required active processing time exceeds the deadline.
