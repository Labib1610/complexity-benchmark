We can check each scenario in order:

1. **Scenario A**: If any single job’s total time `p1 + p2 > T`, then that job alone cannot finish.  
2. **Scenario B**: If the sum of all `p1` times exceeds `T`, then even with zero compute time, the storage array cannot finish in time.  
3. **Scenario C**: If the sum of all `p2` times exceeds `T`, then even with zero storage time, the compute node cannot finish in time.

Since the problem guarantees exactly one scenario fails, we can check in that order.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    p1_list = []
    p2_list = []
    idx = 2
    for i in range(j):
        p1 = int(data[idx])
        p2 = int(data[idx+1])
        idx += 2
        p1_list.append(p1)
        p2_list.append(p2)
    
    # Scenario A
    for i in range(j):
        if p1_list[i] + p2_list[i] > T:
            print(f"JOB {i+1}")
            return
    
    # Scenario B
    if sum(p1_list) > T:
        print("LOAD 1")
        return
    
    # Scenario C
    if sum(p2_list) > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
