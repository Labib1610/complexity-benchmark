# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing the mathematical constraints of a system with **j** processes. The system operates within a continuous domain $D = [0, T]$.
For each process **k** (where **k** is a 1-based index from 1 to **j**), you are given two parameters $p_{1,k}$ and $p_{2,k}$.

You must identify the unique point of failure in the system's constraints. A certificate of impossibility must be produced. The failure is guaranteed to be exactly one of the following three types:

- **Type A (Local Equation Failure):** There exists a process **k** such that the real-valued function $f_k(x) = \min(x, p_{1,k}) + \min(T - x, p_{2,k})$ cannot achieve the value $p_{1,k} + p_{2,k}$ for any real number $x \in D$. If this occurs, print the certificate `JOB k`.
- **Type B (First Measure Failure):** It is geometrically impossible to pack **j** pairwise disjoint open intervals into a 1D segment of length **T** such that their lengths are exactly $p_{1,1}, p_{1,2}, \dots, p_{1,j}$ respectively. If this occurs, print the certificate `LOAD 1`.
- **Type C (Second Measure Failure):** It is geometrically impossible to pack **j** pairwise disjoint open intervals into a 1D segment of length **T** such that their lengths are exactly $p_{2,1}, p_{2,2}, \dots, p_{2,j}$ respectively. If this occurs, print the certificate `LOAD 2`.

It is guaranteed by the hidden test cases that exactly one of these certificates is valid for the given input.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing $p_{1,k}$ and $p_{2,k}$ for the **k**-th process.

## Output

Print a single line containing the unique valid certificate:
- `JOB k` (where **k** is the 1-based index of the process triggering a Type A failure)
- `LOAD 1` (if a Type B failure is triggered)
- `LOAD 2` (if a Type C failure is triggered)

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for process 1, the parameters are $p_{1,1} = 70$ and $p_{2,1} = 60$. The function is $f_1(x) = \min(x, 70) + \min(100 - x, 60)$. We require $f_1(x) = 130$. However, the maximum possible value of $f_1(x)$ on the domain $[0, 100]$ is 100 (achieved, for example, at $x=50$, where $\min(50, 70) + \min(50, 60) = 50 + 50 = 100$). Since 100 < 130, the equation $f_1(x) = 130$ has no real solution in $D$. This is a Type A failure for process 1, so `JOB 1` is the certificate.

In Example 2, no process fails the Type A condition. For instance, for process 1, $f_1(50) = \min(50, 50) + \min(100, 1) = 50 + 1 = 51$, which exactly equals $p_{1,1} + p_{2,1}$. However, the required lengths for the first parameter across all processes are $\{50, 50, 50, 50\}$. It is geometrically impossible to pack 4 pairwise disjoint open intervals of length 50 into a segment of length 150. This triggers a Type B failure, making `LOAD 1` the certificate.
