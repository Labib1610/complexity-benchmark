<STATEMENT>
# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A chef is preparing a banquet featuring **j** special recipes, tracked in the kitchen's order system as `JOB`s. Each `JOB` must be processed in appliance 1 (the oven) and subsequently in appliance 2 (the broiler). For each `JOB` $i$, you are given the exact number of minutes $p_{i,1}$ it must occupy appliance 1, and the exact number of minutes $p_{i,2}$ it must occupy appliance 2.

A valid schedule assigns a start time $S_{i,1}$ for appliance 1 and a start time $S_{i,2}$ for appliance 2 for each recipe $i$ ($1 \le i \le j$), satisfying the following conditions:
(A) $S_{i,1} \ge 0$
(B) $S_{i,1} + p_{i,1} \le S_{i,2}$
(C) $S_{i,2} + p_{i,2} \le T$
(D) For all $i \neq k$, the intervals $[S_{i,1}, S_{i,1} + p_{i,1})$ and $[S_{k,1}, S_{k,1} + p_{k,1})$ are disjoint.
(E) For all $i \neq k$, the intervals $[S_{i,2}, S_{i,2} + p_{i,2})$ and $[S_{k,2}, S_{k,2} + p_{k,2})$ are disjoint.

For every input in this problem, it is **guaranteed that no valid schedule exists** (the deadline **T** cannot be met). Your task is not to search for a schedule; it is to **prove** the deadline is impossible by identifying a specific subset of the constraints that is already unsatisfiable on its own.

Exactly one of the following subsets of constraints is guaranteed to be unsatisfiable. Print the certificate corresponding to the unique unsatisfiable subset:
- `JOB i`: Constraints (A), (B), and (C) restricted to a single recipe $i$.
- `LOAD 1`: Constraint (D), along with the requirement that $[S_{i,1}, S_{i,1} + p_{i,1}) \subseteq [0, T]$ for all recipes $i$.
- `LOAD 2`: Constraint (E), along with the requirement that $[S_{i,2}, S_{i,2} + p_{i,2}) \subseteq [0, T]$ for all recipes $i$.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers $p_{i,1}$ and $p_{i,2}$ (1 ≤ $p_{i,1}$, $p_{i,2}$ ≤ 1000000): the required minutes of `JOB` $i$ in appliance 1 and appliance 2.

## Output

Print a single line: `JOB i` (where $i$ is the 1-based index of the recipe whose (A)-(C) constraints are unsatisfiable) or `LOAD c` (where $c$ is 1 or 2, indicating which appliance's disjoint-interval constraints are unsatisfiable).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for recipe 1, the subset of constraints (A), (B), and (C) is unsatisfiable because any valid assignment of start times for this recipe alone would exceed the deadline of 100. Thus, `JOB 1` is the certificate.

In Example 2, no single recipe violates constraints (A), (B), and (C). However, the subset of constraints for `LOAD 1` is unsatisfiable because it is impossible to schedule all appliance 1 intervals within the 150-minute window without violating constraint (D). Thus, `LOAD 1` is the certificate.
</STATEMENT>
<RATIONALE>
Removed the explicit English descriptions of what causes the bottlenecks ($p_1+p_2 > T$ and $\sum p > T$). Instead, the bottlenecks are defined purely as unsatisfiable subsets of formal scheduling constraints. Models can no longer pattern-match the arithmetic checks from the text and must genuinely deduce what makes those specific sets of inequalities mathematically unsatisfiable.
</RATIONALE>
<PRESERVED_ANSWER>
The subset for `JOB i` is unsatisfiable iff $p_{i,1} + p_{i,2} > T$, and the subset for `LOAD c` is unsatisfiable iff the sum of $p_{i,c}$ exceeds $T$, perfectly mapping to the original certificates.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the same impossibility certification task, checking the exact same single-job and aggregate-load bounds.
</PRESERVED_CLASS>
<RISK>
Models might struggle with the mathematical set notation $[S_{i,1}, S_{i,1} + p_{i,1}) \subseteq [0, T]$, though this is standard notation for interval packing and shouldn't be ambiguous to a competent reader.
</RISK>
