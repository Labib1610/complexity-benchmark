# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A chef is preparing a banquet featuring **j** special recipes, tracked in the kitchen's order system as `JOB`s. Every `JOB` must be processed in appliance 1 (the oven) and subsequently in appliance 2 (the broiler). For each `JOB` you are given the exact number of minutes it must occupy appliance 1, and the exact number of minutes it must occupy appliance 2. Each appliance can only accommodate one `JOB` at any given moment, and a `JOB` can only transition to appliance 2 after its appliance 1 phase is entirely complete.

The kitchen operates under a strict deadline: all processing for all `JOB`s must be completely finished by time **T**.

For every input in this problem, it is **guaranteed that the deadline cannot be met**, no matter how the chef schedules the processing. Your task is not to search for a schedule; it is to **prove** the deadline is impossible with a short certificate that can be checked directly against the input.

A certificate proves impossibility by asserting a lower bound that must hold across **all possible schedules** (even invalid ones that exceed the deadline). You must print a certificate matching one of the following two forms:

- **Isolated Recipe Bottleneck:** `JOB i` (where **i** is a 1-based index). Let $S_i$ be the time recipe **i** begins processing on appliance 1, and $E_i$ be the time it completes processing on appliance 2. This certificate is valid if, across all possible valid orderings and schedules, the minimum possible value of the duration $(E_i - S_i)$ strictly exceeds **T**. Print `JOB i` for any recipe **i** that satisfies this condition.

- **Appliance Saturation Bottleneck:** `LOAD c` (where **c** is 1 or 2). Let $A_c(t)$ be an indicator function that is 1 if appliance **c** is actively processing any recipe at time $t$, and 0 otherwise. This certificate is valid if, across all possible valid schedules, the minimum possible value of the definite integral $\int_0^\infty A_c(t) dt$ strictly exceeds **T**. Print `LOAD c` for any appliance **c** that satisfies this condition.

It is guaranteed that for every input, at least one such valid certificate exists. If multiple certificates are valid, you may print any one of them.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required minutes of the `JOB` in appliance 1 and appliance 2.

## Output

Print a single line: `JOB i` for any valid isolated recipe certificate, or `LOAD c` for any valid appliance saturation certificate.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for `JOB 1`, the appliance 1 phase takes 70 minutes and the appliance 2 phase takes 60 minutes. Since the appliance 2 phase cannot start until the appliance 1 phase finishes, the minimum possible value of $(E_1 - S_1)$ in any schedule is 130. Because 130 > 100, `JOB 1` is a valid certificate.

In Example 2, no single recipe has a minimum $(E_i - S_i)$ exceeding 150. However, for appliance 1, the integral $\int_0^\infty A_1(t) dt$ represents the total active processing time. Since appliance 1 must process four recipes for 50 minutes each, the minimum possible value of this integral across any schedule is 200. Because 200 > 150, `LOAD 1` is a valid certificate.
