We can check both conditions in a single pass:

- For the **sequential bottleneck**, check if `p1 + p2 > T` for any query.
- For the **throughput bottleneck**, sum all `p1` values and all `p2` values separately, and check if either sum exceeds `T`.

Since the problem guarantees exactly one applies, we can output the first one we find.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    j = int(data[0])
    T = int(data[1])
    
    total1 = 0
    total2 = 0
    
    idx = 2
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        
        total1 += p1
        total2 += p2
    
    if total1 > T:
        print("LOAD 1")
    elif total2 > T:
        print("LOAD 2")

if __name__ == "__main__":
    main()
```
