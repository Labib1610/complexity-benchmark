# Problem C — Infeasible Protocol: Deficit Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

A geological survey protocol involves **j** independent target sites (tracked in the system as `JOB`s). At each site, the protocol mandates two sequential operations: extraction and injection. For each `JOB`, you are given the exact volume of fluid required for extraction (**v1**) and the exact volume required for injection (**v2**).

The central reservoir system has a strict operational capacity of **T** total units. For every input provided to this problem, it is mathematically guaranteed that the protocol is infeasible. Your task is to output a short certificate that identifies the exact reason for the failure.

To determine the certificate, evaluate the following three margin formulas:
- **Site Margin:** For each site **i** (1-based), the site margin is defined as $M_{site}(i) = T - (v1_i + v2_i)$.
- **Extraction Margin:** The extraction margin is defined as $M_{ext} = T - \sum_{k=1}^j v1_k$.
- **Injection Margin:** The injection margin is defined as $M_{inj} = T - \sum_{k=1}^j v2_k$.

The input guarantees that exactly one of the following negative-margin conditions will hold. You must print the corresponding certificate:
- If there is a site **i** such that $M_{site}(i) < 0$, print `JOB i`.
- If $M_{ext} < 0$, print `LOAD 1`.
- If $M_{inj} < 0$, print `LOAD 2`.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **v1** and **v2** (1 ≤ v1, v2 ≤ 1000000): the required volumes for extraction and injection for that `JOB`.

## Output

Print a single line containing the exact certificate string: `JOB i` (where **i** is the specific site index whose margin is negative), `LOAD 1` (if the extraction margin is negative), or `LOAD 2` (if the injection margin is negative).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, evaluating the site margin for the first site yields $M_{site}(1) = 100 - (70 + 60) = -30$. Since this margin is strictly less than zero, the certificate is `JOB 1`. All other margins evaluate to non-negative values.

In Example 2, no individual site has a negative site margin. However, the extraction margin evaluates to $M_{ext} = 150 - (50 + 50 + 50 + 50) = -50$. Since this is strictly less than zero, the certificate is `LOAD 1`.

By defining the failure conditions as negative margins (T - demand < 0) rather than standard bottleneck inequalities (demand > T), it disrupts pattern-matching while maintaining mathematical equivalence and perfect clarity.
