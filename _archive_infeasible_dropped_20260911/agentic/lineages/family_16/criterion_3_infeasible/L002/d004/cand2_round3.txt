# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A kitchen must complete **j** orders (`JOB`s) before a strict deadline of **T** minutes. Each `JOB` undergoes two sequential stages: it must first be baked in the oven (Stage 1), and immediately or eventually after baking is complete, it must be finished in the broiler (Stage 2). 

For each `JOB`, you are given the exact number of minutes required in the oven, and the exact number of minutes required in the broiler. An appliance can only process one `JOB` at a time. The deadline **T** is measured from the moment the kitchen begins operating.

For every test case, it is guaranteed that no valid schedule exists to complete all `JOB`s within **T** minutes. You must provide a certificate proving this impossibility. 

It is guaranteed that for every input, exactly one of the following two structural bottlenecks is the unique reason the deadline cannot be met. You must output the corresponding certificate:

- **Individual Sequence Constraint:** There is a specific `JOB` **i** (1-based index) for which its required oven time plus its required broiler time strictly exceeds **T**.
  Print: `JOB i`

- **Resource Capacity Constraint:** There is a specific appliance **c** (where **c** is 1 for the oven, or 2 for the broiler) for which the sum of its required processing times across all **j** orders strictly exceeds **T**.
  Print: `LOAD c`

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **o** and **b** (1 ≤ o, b ≤ 1000000): the required minutes of the `JOB` in the oven and the broiler, respectively.

## Output

Print a single line: `JOB i` (if a `JOB`'s individual sequence fails) or `LOAD c` (if appliance **c**'s total required active time overflows the deadline).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB` 1 requires 70 minutes in the oven and 60 in the broiler. The sum of these times is 130 minutes, which strictly exceeds the 100-minute deadline, so `JOB 1` proves the deadline is impossible.

In Example 2, no single `JOB` violates the individual sequence constraint. However, the oven must be active for 50 minutes for each of the 4 recipes, summing to 200 minutes across all orders. This sum strictly exceeds the 150-minute deadline, making `LOAD 1` the certificate.
