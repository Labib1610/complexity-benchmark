# Problem C — Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A data center is processing a batch of **j** data files. Each file must first be processed by the extraction node (Node 1) and then by the transformation node (Node 2). Each node can only process one file at a time. For each file, you are given the exact time in milliseconds it requires on Node 1, and the exact time it requires on Node 2. A file can only begin processing on Node 2 after its Node 1 processing is fully completed.

The entire batch must be completely processed within a strict operational window of **T** milliseconds. 

For all test cases, it is guaranteed that this deadline cannot be met. Your task is to provide a certificate proving the impossibility. The impossibility always arises from a negative processing margin. The margin is defined as the operational window **T** minus the required processing time for a specific continuous workload. 

You must evaluate the margins for the following workloads and print the certificate for the one that is negative:
- **Isolated File Workload:** The sequential processing of a single file from start to finish (its Node 1 time plus its Node 2 time). If a file has a negative margin, output `JOB i`, where **i** is the 1-based index of the file. (If multiple files have a negative margin, printing any one of their indices is accepted.)
- **Node 1 Aggregate Workload:** The continuous processing of all files on Node 1. If this aggregate workload has a negative margin, output `LOAD 1`.
- **Node 2 Aggregate Workload:** The continuous processing of all files on Node 2. If this aggregate workload has a negative margin, output `LOAD 2`.

It is guaranteed that exactly one of these three certificate categories (`JOB`, `LOAD 1`, or `LOAD 2`) will have a negative margin for any given input.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required time in milliseconds for the file on Node 1 and Node 2 respectively.

## Output

Print a single line containing the valid certificate: `JOB i` (where **i** is any 1-based index of a file with a negative margin), `LOAD 1`, or `LOAD 2`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, the isolated file workload for file 1 requires 70 + 60 = 130 milliseconds. Its margin is 100 - 130 = -30. Since the margin is negative, `JOB 1` is the certificate.

In Example 2, no single file has a negative margin. However, the Node 1 aggregate workload is 50 + 50 + 50 + 50 = 200 milliseconds. Its margin is 150 - 200 = -50. Since this margin is negative, `LOAD 1` is the certificate.
