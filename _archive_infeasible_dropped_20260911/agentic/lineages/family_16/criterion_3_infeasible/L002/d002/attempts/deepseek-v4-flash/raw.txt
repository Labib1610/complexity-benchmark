We can solve this by checking the two conditions in order:

1. First, check if any job fails the timeline check:  
   If `p1 + p2 > T`, then even starting at time 0, the job cannot finish by `T`.  
   The first such job (1-based index) is the certificate.

2. If no job fails that check, check the total load on each appliance:  
   - Sum of all `p1` > `T` → `LOAD 1`  
   - Sum of all `p2` > `T` → `LOAD 2`  

Since the problem guarantees exactly one reason applies, we can check in this order.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    idx = 2
    total1 = 0
    total2 = 0
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        total1 += p1
        total2 += p2
    if total1 > T:
        print("LOAD 1")
    elif total2 > T:
        print("LOAD 2")

if __name__ == "__main__":
    main()
```
