<STATEMENT>
# Problem C — Algebraic Certificates of Overload

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a target parameter $T$ and a dataset of $j$ elements. Each element $i$ (from $1$ to $j$) is associated with two positive integers, $p_{1,i}$ and $p_{2,i}$.

We define three potential "certificates of overload" for this dataset. Your task is to find and output one valid certificate. It is guaranteed that at least one valid certificate exists for every test case.

The certificates are defined by the analytical solutions to specific systems of linear equations in three real variables $u, v,$ and $w$. A certificate is considered **valid** if its corresponding system of equations has a unique solution $(u, v, w)$, and in that unique solution, the value of $w$ is strictly positive ($w > 0$).

The allowed certificates are:
- `JOB i` : For a specific element at 1-based index $i$, the certificate is valid if the following system has a unique solution with $w > 0$:
  $T u + T v = 0$
  $2T u + 3T v + T w = 0$
  $2T u + 4T v + (T + p_{1,i} + p_{2,i}) w = 1$

- `LOAD c` : where $c \in \{1, 2\}$. The certificate is valid if the following system has a unique solution with $w > 0$:
  $T u + T v = 0$
  $2T u + 3T v + T w = 0$
  $2T u + 4T v + (T + S_c) w = 1$
  where $S_c$ is the sum of $p_{c,k}$ over all elements $k$ from $1$ to $j$.

Output a valid certificate of overload from one of the two allowed forms above. If multiple certificates are valid, you may output any of them.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the values of $p_{1,i}$ and $p_{2,i}$ for the $i$-th element.

## Output

Print a single line containing a valid certificate: `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for element 1, the `JOB 1` system of equations is:
$100 u + 100 v = 0$
$200 u + 300 v + 100 w = 0$
$200 u + 400 v + 230 w = 1$
From the first equation, $u = -v$. Substituting this into the second equation gives $200(-v) + 300 v + 100 w = 0 \implies 100 v + 100 w = 0 \implies v = -w$. Thus $u = w$.
Substituting $u = w$ and $v = -w$ into the third equation yields $200(w) + 400(-w) + 230 w = 1 \implies 30 w = 1 \implies w = 1/30$.
Since the system has a unique solution and $w = 1/30 > 0$, `JOB 1` is a valid certificate.

In Example 2, no single element yields a valid `JOB` certificate. However, for `LOAD 1`, the sum of the first integers is $S_1 = 50 + 50 + 50 + 50 = 200$. The `LOAD 1` system of equations is:
$150 u + 150 v = 0$
$300 u + 450 v + 150 w = 0$
$300 u + 600 v + 350 w = 1$
Following the same substitution steps, we get $u = w$ and $v = -w$. The third equation becomes $300(w) + 600(-w) + 350 w = 1 \implies 50 w = 1 \implies w = 1/50$.
Since $w = 1/50 > 0$, `LOAD 1` is a valid certificate.
