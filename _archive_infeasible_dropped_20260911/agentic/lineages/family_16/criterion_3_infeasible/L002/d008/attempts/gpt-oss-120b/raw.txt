**Solution Explanation**

For every element `i`

* `p1[i] , p2[i] > 0`
* the whole system of inequalities is known to be **unsatisfiable**.

We have to output one of the following certificates

* `JOB i` – the three inequalities that involve only element `i`
* `LOAD 1` – the inequalities that involve only the `u`‑variables
* `LOAD 2` – the inequalities that involve only the `v`‑variables  

At least one of them is always valid.



--------------------------------------------------------------------

#### 1.   When does `JOB i` hold ?

`JOB i` uses only  

```
u_i ≥ p1[i]                     (A)
v_i – u_i ≥ p1[i] + p2[i]       (B)
v_i ≤ 2·T – p2[i]               (C)
```

From (A) and (B) we obtain the cheapest possible `v_i`

```
v_i ≥ u_i + p1[i] + p2[i] ≥ p1[i] + p1[i] + p2[i] = 2·p1[i] + p2[i]
```

Together with (C)

```
2·p1[i] + p2[i] ≤ 2·T – p2[i]
⇔ 2·p1[i] + 2·p2[i] ≤ 2·T
⇔ p1[i] + p2[i] ≤ T
```

Hence `JOB i` is *unsatisfiable* **iff**  

```
p1[i] + p2[i] > T
```

The check is O(1) per element.



--------------------------------------------------------------------

#### 2.   When does `LOAD 1` hold ?

`LOAD 1` only talks about the `u`‑variables

```
p1[i] ≤ u_i ≤ 2·T – p1[i]                (1)
|u_i – u_k| ≥ p1[i] + p1[k]   for i≠k   (2)
```

Interpret each element `i` as an interval of length `2·p1[i]`

```
I_i = [ u_i – p1[i] ,  u_i + p1[i] ]
```

* (2) means the intervals must be **pairwise disjoint**,
* (1) guarantees the whole interval stays inside `[0 , 2·T]`.

Therefore we only have to fit all intervals inside a segment of length `2·T`.
If we order them arbitrarily and place them one after another,
the total needed length is  

```
Σ 2·p1[i] = 2· Σ p1[i]
```

`LOAD 1` is impossible **iff** this total length exceeds the available one:

```
 Σ p1[i]  >  T
```

The same reasoning for `LOAD 2` (replace `p1` by `p2`) gives

```
 LOAD 2  unsatisfiable  ⇔  Σ p2[i] > T
```



--------------------------------------------------------------------

#### 3.   Whole algorithm

```
read j, T
read all (p1 , p2)

# 1) try to find a JOB certificate
for i = 1 … j
        if p1[i] + p2[i] > T:
                output "JOB i"
                exit

# 2) no JOB certificate → check LOAD certificates
sum1 = Σ p1[i]
if sum1 > T:
        output "LOAD 1"
        exit

sum2 = Σ p2[i]
if sum2 > T:
        output "LOAD 2"
        exit
```

The statement guarantees that at least one of the three cases occurs,
so the program always terminates with a correct certificate.

*Time complexity* `O(j)` – one linear scan.  
*Memory consumption* `O(1)` besides the input arrays (they can be processed
on the fly, but even storing them fits easily: `j ≤ 2·10⁵`).

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm always outputs a valid certificate.

---

##### Lemma 1  
For an element `i` the subsystem `JOB i` is unsatisfiable **iff**
`p1[i] + p2[i] > T`.

**Proof.**  
The derivation in section&nbsp;1 shows equivalence between the three
inequalities and the condition `p1[i] + p2[i] ≤ T`. ∎



##### Lemma 2  
`LOAD 1` is unsatisfiable **iff** ` Σ p1[i] > T`.

**Proof.**  
Replace each point `u_i` by the interval `I_i = [u_i-p1[i] , u_i+p1[i]]`.

*Condition (2)* of `LOAD 1` is exactly “intervals are disjoint”.
*Condition (1)* forces every `I_i` to lie inside `[0,2T]`.

If ` Σ p1[i] ≤ T` then the total length of all intervals,
`2· Σ p1[i]`, is at most `2T`.  
Place the intervals consecutively starting at `0`; each interval fits,
hence a feasible assignment exists.

Conversely, if ` Σ p1[i] > T` then the total required length exceeds `2T`,
so the intervals cannot all be placed inside `[0,2T]`.  
Thus no feasible assignment exists. ∎



##### Lemma 3  
`LOAD 2` is unsatisfiable **iff** ` Σ p2[i] > T`.

**Proof.** Identical to Lemma&nbsp;2 with `p2`. ∎



##### Lemma 4  
If the algorithm prints `JOB i` then the whole instance is indeed
certified unsatisfiable.

**Proof.** By Lemma&nbsp;1 the three inequalities of `JOB i` cannot be satisfied,
even after removing all other variables and constraints.
Therefore the required certificate is valid. ∎



##### Lemma 5  
If the algorithm prints `LOAD 1` then the whole instance is indeed
certified unsatisfiable.

**Proof.** The algorithm prints `LOAD 1` only when ` Σ p1[i] > T`.
By Lemma&nbsp;2 the subsystem consisting of all `u`‑variables and their
constraints is already impossible, irrespective of the `v`‑variables.
Hence the printed certificate is correct. ∎



##### Lemma 6  
If the algorithm prints `LOAD 2` then the whole instance is indeed
certified unsatisfiable.

**Proof.** Analogous to Lemma&nbsp;5 using Lemma&nbsp;3. ∎



##### Theorem  
For every input instance the algorithm outputs a line that is a
valid certificate (`JOB i` or `LOAD 1` or `LOAD 2`).

**Proof.**  
The algorithm first searches for an index with `p1[i] + p2[i] > T`.
If such an index exists, by Lemma&nbsp;4 the output `JOB i` is valid.

Otherwise `p1[i] + p2[i] ≤ T` for all `i`.  
If additionally ` Σ p1[i] > T`, the algorithm outputs `LOAD 1`,
which is valid by Lemma&nbsp;5.  
If not, then ` Σ p1[i] ≤ T`.  
If ` Σ p2[i] > T`, the algorithm outputs `LOAD 2`,
valid by Lemma&nbsp;6.

The statement of the problem guarantees that the full system is
unsatisfiable, and it is proved in the editorial of the contest that
in this situation at least one of the three conditions above must hold.
Consequently the algorithm always reaches one of the three `exit`
statements and prints a correct certificate. ∎

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    T = int(next(it))

    p1 = []
    p2 = []
    sum1 = 0
    sum2 = 0

    # first pass: look for JOB
    for idx in range(1, n + 1):
        a = int(next(it))
        b = int(next(it))
        if a + b > T:
            print(f'JOB {idx}')
            return
        p1.append(a)
        p2.append(b)
        sum1 += a
        sum2 += b

    # no JOB found
    if sum1 > T:
        print('LOAD 1')
        return
    if sum2 > T:
        print('LOAD 2')
        return

    # According to the problem guarantee this never happens,
    # but we output something safe.
    # (The judge will never reach this line.)
    print('LOAD 1')

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
