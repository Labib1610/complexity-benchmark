We can solve this by checking the conditions for each possible certificate type in order.

**Key observations:**

1. **JOB check:**  
   For element `i`, we need:
   - `u_i >= p1`
   - `v_i - u_i >= p1 + p2`
   - `v_i <= 2T - p2`  
   Combining:  
   From `u_i >= p1` and `v_i - u_i >= p1 + p2`, we get `v_i >= 2*p1 + p2`.  
   For contradiction, we need `2*p1 + p2 > 2T - p2` → `2*p1 + 2*p2 > 2T` → `p1 + p2 > T`.  
   So if any element has `p1 + p2 > T`, we can output `JOB i`.

2. **LOAD 1 check:**  
   We need to see if we can place `j` points `u_i` in `[p1_i, 2T - p1_i]` with pairwise distance at least `p1_i + p1_k`.  
   This is a classic interval packing problem.  
   Sort by `p1_i` descending (largest first) and try to place them greedily from left to right.  
   If at any point we cannot place the next point, it's unsatisfiable.

3. **LOAD 2 check:**  
   Symmetric to LOAD 1 but with `p2_i` and bounds `[p2_i, 2T - p2_i]`.

We check in order: JOB, LOAD 1, LOAD 2.  
It's guaranteed at least one will work.

```python
import sys

def solve():
    input = sys.stdin.readline
    j, T = map(int, input().split())
    p1 = []
    p2 = []
    for i in range(j):
        a, b = map(int, input().split())
        p1.append(a)
        p2.append(b)
    
    # Check JOB
    for i in range(j):
        if p1[i] + p2[i] > T:
            print(f"JOB {i+1}")
            return
    
    # Check LOAD 1
    # Sort by p1 descending
    order = sorted(range(j), key=lambda x: -p1[x])
    pos = -10**30
    ok = True
    for idx in order:
        low = p1[idx]
        high = 2*T - p1[idx]
        # Need to place at position >= pos + p1[idx] + p1[prev]? Actually we need distance >= p1_i + p1_k
        # Greedy: place at max(low, pos + p1[idx] + p1[prev]) but we don't have prev here.
        # Better: sort by p1 descending, place first at its low bound, then each next at max(low, last_pos + p1[last] + p1[current])
        # But we need to track last placed p1 value.
        if pos == -10**30:
            pos = low
            last_p1 = p1[idx]
        else:
            need = pos + last_p1 + p1[idx]
            if need > high:
                ok = False
                break
            pos = need
            last_p1 = p1[idx]
    if not ok:
        print("LOAD 1")
        return
    
    # Check LOAD 2
    order = sorted(range(j), key=lambda x: -p2[x])
    pos = -10**30
    ok = True
    for idx in order:
        low = p2[idx]
        high = 2*T - p2[idx]
        if pos == -10**30:
            pos = low
            last_p2 = p2[idx]
        else:
            need = pos + last_p2 + p2[idx]
            if need > high:
                ok = False
                break
            pos = need
            last_p2 = p2[idx]
    if not ok:
        print("LOAD 2")
        return

if __name__ == "__main__":
    solve()
```
