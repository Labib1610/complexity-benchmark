# Problem C — System Overload: Bottleneck Certificates

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a data pipeline that processes $j$ data streams. Each stream $i$ (from $1$ to $j$) consists of two phases: a metadata phase with size $p_{1,i}$, and a payload phase with size $p_{2,i}$. The pipeline has a target performance index $T$.

You need to evaluate the system's capacity under various continuous load-balancing configurations. We define two types of bottlenecks based on fractional resource allocation:

**Stream Bottleneck (`JOB i`)**:
For a single stream $i$, we can assign two positive scaling factors, $\alpha > 0$ for the metadata phase and $\beta > 0$ for the payload phase. 
Stream $i$ is defined as *unroutable* if, for every possible choice of $\alpha > 0$ and $\beta > 0$, the scaled sizes satisfy:
$$ \alpha \cdot p_{1,i} + \beta \cdot p_{2,i} > T \cdot \min(\alpha, \beta) $$

**Phase Bottleneck (`LOAD c`)**:
For a specific phase $c \in \{1, 2\}$, we can assign a non-negative weight $q_k \ge 0$ to each stream $k \in \{1 \dots j\}$, such that at least one weight is strictly positive. 
Phase $c$ is defined as *overloaded* if there exists at least one valid weight assignment $(q_1, \dots, q_j)$ such that the sum of the weighted sizes for phase $c$ satisfies:
$$ \sum_{k=1}^j q_k \cdot p_{c,k} > T \cdot \max_{1 \le k \le j}(q_k) $$

For every test case in this problem, it is guaranteed that the pipeline cannot meet the target index $T$, meaning at least one bottleneck exists. Your task is to provide a directly checkable certificate identifying one such bottleneck.

Output a valid certificate from one of the two allowed forms below. It is guaranteed that at least one such certificate exists for every test case.
- `JOB i` : Certifies that stream $i$ (at 1-based index $i$) is unroutable.
- `LOAD c` : Certifies that phase $c$ (where $c \in \{1, 2\}$) is overloaded. 

If multiple certificates are valid, you may output any one of them.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the sizes $p_{1,i}$ and $p_{2,i}$ for the $i$-th stream.

## Output

Print a single line containing a valid certificate: `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for stream 1, $p_{1,1} = 70$ and $p_{2,1} = 60$. The `JOB` condition requires checking if $\alpha \cdot 70 + \beta \cdot 60 > 100 \cdot \min(\alpha, \beta)$ for all $\alpha, \beta > 0$. Dividing both sides by $\min(\alpha, \beta)$, this is equivalent to $70 \frac{\alpha}{\min(\alpha, \beta)} + 60 \frac{\beta}{\min(\alpha, \beta)} > 100$. Since $\frac{\alpha}{\min(\alpha, \beta)} \ge 1$ and $\frac{\beta}{\min(\alpha, \beta)} \ge 1$, the minimum possible value of the left side is $70(1) + 60(1) = 130$. Since $130 > 100$, the strict inequality holds for all $\alpha, \beta > 0$. Thus, stream 1 is unroutable, making `JOB 1` a valid certificate.

In Example 2, no single stream is unroutable. However, for `LOAD 1`, we check phase 1 where $p_{1,k} = 50$ for all four streams. If we assign weights $q_1 = q_2 = q_3 = q_4 = 1$, the sum of weighted sizes is $50(1) + 50(1) + 50(1) + 50(1) = 200$. The `LOAD` condition requires this sum to be strictly greater than $150 \cdot \max(1, 1, 1, 1) = 150$, which is true ($200 > 150$). Thus, a valid assignment exists that overloads phase 1, making `LOAD 1` a valid certificate.

I removed the disjoint-interval framing that models used to trivially deduce `p1+p2 > T` and `sum(p) > T`. I replaced it with mathematically equivalent continuous load-balancing inequalities using min/max scaling operators. Models must now genuinely analyze the bounds of these non-additive expressions to discover the underlying $O(N)$ linear checks.
