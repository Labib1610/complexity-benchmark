# Problem C — System of Inequalities: Certificate of Unsatisfiability

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a target threshold $T$ and a set of $j$ elements. Each element $i$ (from $1$ to $j$) is associated with two positive integers, $p_{1,i}$ and $p_{2,i}$.

Consider the problem of assigning two non-negative real numbers, $x_i$ and $y_i$, to each element $i$. For any two elements $k$ and $m$ (where $k$ and $m$ can be the same or different), we define two interaction integrals over the real frequency $f$:
$$J_1(k, m) = \int_{-\infty}^{\infty} \frac{\sin(\pi p_{1,k} f) \sin(\pi p_{1,m} f)}{\pi^2 f^2} \cos(\pi f (2(x_k - x_m) + p_{1,k} - p_{1,m})) \, df$$
$$J_2(k, m) = \int_{-\infty}^{\infty} \frac{\sin(\pi p_{2,k} f) \sin(\pi p_{2,m} f)}{\pi^2 f^2} \cos(\pi f (2(y_k - y_m) + p_{2,k} - p_{2,m})) \, df$$
*(Note: at $f=0$, the integrands are defined by their continuous limits, which evaluate to $p_{1,k} p_{1,m}$ and $p_{2,k} p_{2,m}$ respectively.)*

The assignment must satisfy the following four conditions:
1. **Intra-element separation:** For every element $i$, $x_i + p_{1,i} \le y_i$.
2. **First-stage spectral orthogonality:** $\sum_{k=1}^j \sum_{m=1}^j J_1(k, m) = \sum_{i=1}^j p_{1,i}$.
3. **Second-stage spectral orthogonality:** $\sum_{k=1}^j \sum_{m=1}^j J_2(k, m) = \sum_{i=1}^j p_{2,i}$.
4. **Boundary threshold:** For every element $i$, $y_i + p_{2,i} \le T$.

For every test case in this problem, it is guaranteed that no such assignment of $x_i$ and $y_i$ exists. Your task is to provide a directly checkable certificate of unsatisfiability by identifying a specific relaxed subsystem of these constraints that is already impossible to satisfy on its own. 

Output a valid certificate of unsatisfiability from one of the two allowed forms below. It is guaranteed that at least one such certificate exists for every test case.

- `JOB i` : For the element at 1-based index $i$, the constraints $x_i \ge 0$, Intra-element separation (1), and Boundary threshold (4) cannot be simultaneously satisfied (ignoring all other elements and conditions).
- `LOAD c` : where $c \in \{1, 2\}$. 
  - If $c=1$, it certifies that the constraints $x_i \ge 0$ for all $i$, First-stage spectral orthogonality (2), and a modified threshold $x_i + p_{1,i} \le T$ for all $i$, cannot be simultaneously satisfied (ignoring $y_i$, $p_{2,i}$, and all other conditions). 
  - If $c=2$, it certifies that the constraints $y_i \ge 0$ for all $i$, Second-stage spectral orthogonality (3), and Boundary threshold (4) for all $i$, cannot be simultaneously satisfied (ignoring $x_i$, $p_{1,i}$, and all other conditions).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the values of $p_{1,i}$ and $p_{2,i}$ for the $i$-th element.

## Output

Print a single line containing a valid certificate: `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for element 1, the `JOB` subsystem requires $x_1 \ge 0$, $x_1 + 70 \le y_1$, and $y_1 + 60 \le 100$. This implies $x_1 \le -30$, which contradicts $x_1 \ge 0$. Thus, this subsystem is unsatisfiable for element 1, making `JOB 1` a valid certificate.

In Example 2, no single element violates the `JOB` subsystem. However, for `LOAD 1`, the subsystem requires assigning $x_i \ge 0$ such that $x_i + 50 \le 150$ for all four elements, while satisfying the First-stage spectral orthogonality condition $\sum_{k=1}^4 \sum_{m=1}^4 J_1(k, m) = 200$. It can be shown analytically that for any such assignment within the bounds $[0, 150]$, the double sum of these integrals evaluates to at least $800/3 \approx 266.67$. Since $266.67 > 200$, this contradicts the requirement. Thus, this subsystem is unsatisfiable, making `LOAD 1` a valid certificate.
