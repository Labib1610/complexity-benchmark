# Problem C — System of Inequalities: Certificate of Unsatisfiability

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a target threshold $T$ and a set of $j$ elements. Each element $i$ (from $1$ to $j$) is associated with two positive integers, $w_{A,i}$ and $w_{B,i}$.

Consider the problem of assigning two non-negative real numbers, $x_i$ and $y_i$, to each element $i$. For each element, we define two step functions over the real numbers $t$:
- $\phi_i(t) = 1$ if $x_i \le t < x_i + w_{A,i}$, and $0$ otherwise.
- $\psi_i(t) = 1$ if $y_i \le t < y_i + w_{B,i}$, and $0$ otherwise.

The assignment must satisfy the following four conditions:
1. **Separation:** For every element $i$, $x_i + w_{A,i} \le y_i$.
2. **First-stage weighted orthogonality:** $\int_{-\infty}^{\infty} 2^{-|t|} \left( \sum_{i=1}^j \phi_i(t) \right)^2 dt = \sum_{i=1}^j \int_{-\infty}^{\infty} 2^{-|t|} \phi_i(t) dt$.
3. **Second-stage weighted orthogonality:** $\int_{-\infty}^{\infty} 2^{-|t|} \left( \sum_{i=1}^j \psi_i(t) \right)^2 dt = \sum_{i=1}^j \int_{-\infty}^{\infty} 2^{-|t|} \psi_i(t) dt$.
4. **Threshold:** For every element $i$, $y_i + w_{B,i} \le T$.

For every test case in this problem, it is guaranteed that no such assignment of $x_i$ and $y_i$ exists. Your task is to provide a directly checkable certificate of unsatisfiability by identifying a specific relaxed subsystem of these constraints that is already impossible to satisfy on its own. 

Output a valid certificate of unsatisfiability from one of the two allowed forms below. It is guaranteed that at least one such certificate exists for every test case.

- `JOB i` : For the element at 1-based index $i$, the constraints $x_i \ge 0$, Separation (1), and Threshold (4) cannot be simultaneously satisfied (ignoring all other elements and conditions).
- `LOAD c` : where $c \in \{1, 2\}$. 
  - If $c=1$, it certifies that the constraints $x_i \ge 0$, First-stage weighted orthogonality (2), and a modified threshold $x_i + w_{A,i} \le T$ for all $i$, cannot be simultaneously satisfied (ignoring $y_i$, $w_{B,i}$, and all other conditions). 
  - If $c=2$, it certifies that the constraints $y_i \ge 0$, Second-stage weighted orthogonality (3), and Threshold (4) for all $i$, cannot be simultaneously satisfied (ignoring $x_i$, $w_{A,i}$, and all other conditions).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **w_A** and **w_B** (1 ≤ w_A, w_B ≤ 1000000): the values of $w_{A,i}$ and $w_{B,i}$ for the $i$-th element.

## Output

Print a single line containing a valid certificate: `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for element 1, the `JOB` subsystem requires $x_1 \ge 0$, $x_1 + 70 \le y_1$, and $y_1 + 60 \le 100$. By chaining these inequalities, we find that no non-negative $x_1$ can satisfy them. Thus, this subsystem is unsatisfiable for element 1, making `JOB 1` a valid certificate.

In Example 2, no single element violates the `JOB` subsystem. However, for `LOAD 1`, the subsystem restricts four step functions $\phi_i$, each of length 50, to the domain $[0, 150]$. We can evaluate the integrals for any such functions strictly confined to this domain. Because the weight function $2^{-|t|}$ is strictly positive, satisfying the First-stage weighted orthogonality condition requires the functions to be disjoint almost everywhere. The available domain measure is insufficient to accommodate the required supports simultaneously. Thus, the integral identity cannot hold, making `LOAD 1` a valid certificate.

<RATIONALE>
The shortcut models used was extracting the `sum(p1) > T` bound directly from the explicit Cauchy-Schwarz arithmetic in the Example 2 note and the constant RHS of the original integral constraint. I removed the arithmetic derivations from the notes and replaced the plain integral with a weighted integral identity. This makes the RHS locally dependent on the placement variables $x_i$, breaking the obvious sum pattern, while mathematically still enforcing strict non-overlap (since $\phi_i^2 = \phi_i$, the equality holds if and only if cross-terms vanish).
</RATIONALE>
<PRESERVED_ANSWER>
The weighted integral identity holds if and only if the indicator functions are disjoint almost everywhere, which requires exactly the same total threshold space as the original condition, keeping all valid certificates identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying constraint simplifies to exactly the same linear inequalities (sum of lengths > T or individual length > T), maintaining the $O(N)$ linear scan complexity.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the weighted integral as requiring numerical approximation rather than symbolic simplification, but the step functions are simple enough that a competent solver should recognize the identity implies disjointness.
