# Problem C — System of Inequalities: Layout Unsatisfiability

Time limit: 2 s   Memory limit: 256 MB

## Description

You are building an engine to place UI components on a 1D canvas of length $T$, which starts at coordinate 0 and ends at $T$. 

You must place a set of $j$ components. Each component $i$ (from $1$ to $j$) consists of two parts: a left-pane of width $p_{1,i}$ and a right-pane of width $p_{2,i}$. 

To render correctly, you must assign a starting coordinate $x_i \ge 0$ for the left-pane and $y_i \ge 0$ for the right-pane of each component, satisfying four strict layout rules:
1. **Internal Order:** For every component $i$, its right-pane must be placed entirely to the right of its left-pane. Specifically, $x_i + p_{1,i} \le y_i$.
2. **Left-Pane Isolation:** All $j$ left-panes must be mutually non-overlapping.
3. **Right-Pane Isolation:** All $j$ right-panes must be mutually non-overlapping.
4. **Canvas Boundary:** All components must fit entirely within the canvas. Specifically, for every component $i$, $y_i + p_{2,i} \le T$.

For every test case in this problem, it is guaranteed that no valid layout exists. Your task is to provide a short, directly checkable certificate of impossibility by identifying a specific relaxed subset of these rules that is already impossible to satisfy on its own.

Output a valid certificate of unsatisfiability from one of the two allowed forms below. It is guaranteed that at least one such certificate exists for every test case.

- `JOB i` : For the component at 1-based index $i$, the constraints $x_i \ge 0$, Internal Order (1), and Canvas Boundary (4) cannot be simultaneously satisfied (ignoring all other components and isolation rules).
- `LOAD c` : where $c \in \{1, 2\}$. 
  - If $c=1$, it certifies that the constraints $x_i \ge 0$, Left-Pane Isolation (2), and a modified boundary $x_i + p_{1,i} \le T$ for all $i$, cannot be simultaneously satisfied (ignoring right-panes and the Internal Order rule). 
  - If $c=2$, it certifies that the constraints $y_i \ge 0$, Right-Pane Isolation (3), and the Canvas Boundary (4) for all $i$, cannot be simultaneously satisfied (ignoring left-panes and the Internal Order rule).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the widths of the left-pane ($p_{1,i}$) and right-pane ($p_{2,i}$) for the $i$-th component.

## Output

Print a single line containing a valid certificate: `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for component 1, the `JOB` subsystem requires $x_1 \ge 0$, Internal Order ($x_1 + 70 \le y_1$), and Canvas Boundary ($y_1 + 60 \le 100$). This implies $x_1 \le -30$, which contradicts $x_1 \ge 0$. Thus, this subsystem is unsatisfiable for component 1, making `JOB 1` a valid certificate.

In Example 2, no single component violates the `JOB` subsystem. However, for `LOAD 1`, the subsystem requires placing four non-overlapping left-panes, each of width 50, such that they all finish before coordinate 150. The total width required is 200, which strictly exceeds the available canvas length of 150. Thus, this subsystem is unsatisfiable, making `LOAD 1` a valid certificate.
