<STATEMENT>
# Problem C — System of Inequalities: Certificate of Unsatisfiability

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a target threshold $T$ and a set of $j$ elements. Each element $i$ (from $1$ to $j$) is associated with two positive integers, $p_{1,i}$ and $p_{2,i}$.

Consider the problem of assigning two real numbers, $u_i$ and $v_i$, to each element $i$. The assignment must satisfy the following four conditions:
1. **Separation:** For every element $i$, $v_i - u_i \ge p_{1,i} + p_{2,i}$.
2. **First-stage dispersion:** For every pair of distinct elements $i$ and $k$, $|u_i - u_k| \ge p_{1,i} + p_{1,k}$.
3. **Second-stage dispersion:** For every pair of distinct elements $i$ and $k$, $|v_i - v_k| \ge p_{2,i} + p_{2,k}$.
4. **Domain:** For every element $i$, $u_i \ge p_{1,i}$ and $v_i \le 2T - p_{2,i}$.

For every test case in this problem, it is guaranteed that no such assignment of $u_i$ and $v_i$ exists. Your task is to provide a directly checkable certificate of unsatisfiability by identifying a specific relaxed subsystem of these constraints that is already impossible to satisfy on its own. 

Output a valid certificate of unsatisfiability from one of the two allowed forms below. It is guaranteed that at least one such certificate exists for every test case.

- `JOB i` : For the element at 1-based index $i$, the constraints $u_i \ge p_{1,i}$, Separation (1), and $v_i \le 2T - p_{2,i}$ cannot be simultaneously satisfied (ignoring all other elements and conditions).
- `LOAD c` : where $c \in \{1, 2\}$. 
  - If $c=1$, it certifies that the constraints $u_i \ge p_{1,i}$, First-stage dispersion (2), and a modified domain upper bound $u_i \le 2T - p_{1,i}$ for all $i$, cannot be simultaneously satisfied (ignoring $v_i$, $p_{2,i}$, and all other conditions). 
  - If $c=2$, it certifies that the constraints for a modified domain lower bound $v_i \ge p_{2,i}$, Second-stage dispersion (3), and $v_i \le 2T - p_{2,i}$ for all $i$, cannot be simultaneously satisfied (ignoring $u_i$, $p_{1,i}$, and all other conditions).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the values of $p_{1,i}$ and $p_{2,i}$ for the $i$-th element.

## Output

Print a single line containing a valid certificate: `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for element 1, the `JOB` subsystem requires $u_1 \ge 70$, $v_1 - u_1 \ge 130$, and $v_1 \le 140$. Combining the first two inequalities gives $v_1 \ge 200$, which contradicts $v_1 \le 140$. Thus, this subsystem is unsatisfiable for element 1, making `JOB 1` a valid certificate.

In Example 2, no single element violates the `JOB` subsystem. However, for `LOAD 1`, the subsystem requires four real numbers $u_i$ to simultaneously satisfy $u_i \ge 50$ and $u_i \le 250$, meaning all $u_i$ are confined to an interval of length $200$. The First-stage dispersion condition requires $|u_i - u_k| \ge 100$ for all distinct pairs. It is mathematically impossible to place four points mutually separated by at least 100 within an interval of length 200. Thus, this subsystem is unsatisfiable, making `LOAD 1` a valid certificate.

This removes the surface-level `p1 + p2 > T` and `sum(p1) > T` formulas from the problem description, replacing them with mathematically equivalent scaled bounds (e.g. domain width $2T$). Models that rely on memorized scheduling shortcuts will fail unless they explicitly re-derive the unsat bounds algebraically.
