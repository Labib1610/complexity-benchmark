<STATEMENT>
# Problem C — System of Inequalities: Certificate of Unsatisfiability

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a target threshold $T$ and a set of $j$ elements. Each element $i$ (from $1$ to $j$) is associated with two positive integers, $p_{1,i}$ and $p_{2,i}$.

Consider the problem of assigning two measurable sets of real numbers, $A_i$ and $B_i$, to each element $i$. The assignment must satisfy the following five conditions:

1. **Measure:** The Lebesgue measure (total length) of $A_i$ is exactly $p_{1,i}$, and the Lebesgue measure of $B_i$ is exactly $p_{2,i}$.
2. **Separation:** For every element $i$, the supremum of $A_i$ is less than or equal to the infimum of $B_i$. (That is, every real number in $A_i$ is less than or equal to every real number in $B_i$).
3. **First-stage orthogonality:** For any two distinct elements $i$ and $k$, the intersection $A_i \cap A_k$ has a measure of zero.
4. **Second-stage orthogonality:** For any two distinct elements $i$ and $k$, the intersection $B_i \cap B_k$ has a measure of zero.
5. **Threshold:** For every element $i$, both $A_i$ and $B_i$ are subsets of the interval $[0, T]$.

For every test case in this problem, it is guaranteed that no such assignment of sets $A_i$ and $B_i$ exists. Your task is to provide a directly checkable certificate of unsatisfiability by identifying a specific relaxed subsystem of these constraints that is already impossible to satisfy on its own. 

Output a valid certificate of unsatisfiability from one of the two allowed forms below. It is guaranteed that at least one such certificate exists for every test case.

- `JOB i` : For the element at 1-based index $i$, the Measure (1), Separation (2), and Threshold (5) constraints cannot be simultaneously satisfied (ignoring all other elements and the orthogonality conditions).
- `LOAD c` : where $c \in \{1, 2\}$. 
  - If $c=1$, it certifies that the Measure (1) for sets $A_i$, First-stage orthogonality (3), and Threshold (5) for sets $A_i$ cannot be simultaneously satisfied for the full group of elements (ignoring sets $B_i$, $p_{2,i}$, Separation, and Second-stage orthogonality). 
  - If $c=2$, it certifies that the Measure (1) for sets $B_i$, Second-stage orthogonality (4), and Threshold (5) for sets $B_i$ cannot be simultaneously satisfied for the full group of elements (ignoring sets $A_i$, $p_{1,i}$, Separation, and First-stage orthogonality).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the values of $p_{1,i}$ and $p_{2,i}$ for the $i$-th element.

## Output

Print a single line containing a valid certificate: `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for element 1, the `JOB` subsystem requires $\mu(A_1) = 70$, $\mu(B_1) = 60$, $\sup A_1 \le \inf B_1$, and $A_1, B_1 \subset [0, 100]$. This implies $A_1 \subset [0, \sup A_1]$ and $B_1 \subset [\inf B_1, 100]$. Because $\sup A_1 \le \inf B_1$, the available length for $A_1$ (which is $\sup A_1$) plus the available length for $B_1$ (which is $100 - \inf B_1$) cannot exceed 100. However, the required measures sum to $70 + 60 = 130 > 100$. Thus, this subsystem is unsatisfiable for element 1, making `JOB 1` a valid certificate.

In Example 2, no single element violates the `JOB` subsystem. However, for `LOAD 1`, the subsystem requires four sets $A_i$, each of measure 50, all subsets of $[0, 150]$, such that their pairwise intersections have measure zero. The union of these sets must also be a subset of $[0, 150]$. Since they are essentially disjoint, the measure of their union is the sum of their measures, which is $50 \times 4 = 200$. But a subset of $[0, 150]$ can have a measure of at most 150. Since $200 > 150$, this contradicts the requirement. Thus, this subsystem is unsatisfiable, making `LOAD 1` a valid certificate.
</STATEMENT>
<RATIONALE>
I replaced the explicit variables $x_i, y_i$ and step function integrals with measurable sets $A_i, B_i$ and their Lebesgue measures. This removes the direct algebraic inequalities (like $x_i + p_{1,i} \le y_i$) that models were trivially simplifying to $p_{1,i} + p_{2,i} \le T$. Models must now reason through supremum/infimum bounds and disjoint measure summation to deduce the additive capacity checks.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical conditions for unsatisfiability remain identically equivalent: `JOB i` is invalid exactly when $p_{1,i} + p_{2,i} > T$, and `LOAD c` is invalid exactly when the sum of the respective measures exceeds $T$.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires only a single pass of $O(j)$ time to compute the sums and find the bottleneck, keeping it in the same complexity class.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret 'measurable sets' as allowing fractional or scattered intervals, but the supremum/infimum and measure constraints rigorously ensure the same capacity bounds apply regardless of fragmentation.
</RISK>
