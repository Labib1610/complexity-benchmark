<STATEMENT>
# Infeasible Coordinate Assignments

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a target threshold $T$ and a set of $j$ items. Each item $i$ (from $1$ to $j$) is associated with two positive integers, $q_{1,i}$ and $q_{2,i}$.

Consider the problem of assigning a starting coordinate $S_{c,i}$ and an ending coordinate $E_{c,i}$ to each item $i$ for each stage $c \in \{1, 2\}$. For every item and stage, the length of the coordinate interval must be exactly $q_{c,i}$, meaning $E_{c,i} = S_{c,i} + q_{c,i}$. The assignment must satisfy the following three conditions:
1. **Precedence:** For every item $i$, the stage 2 interval must not begin before the stage 1 interval ends. That is, $S_{2,i} \ge E_{1,i}$.
2. **Disjointness:** For each stage $c \in \{1, 2\}$, the open intervals $(S_{c,i}, E_{c,i})$ for all $j$ items must be pairwise disjoint (they may share endpoints, but cannot overlap in their interiors).
3. **Boundaries:** For every item $i$, the stage 1 interval must not start before 0 (i.e., $S_{1,i} \ge 0$), and the stage 2 interval must not end after $T$ (i.e., $E_{2,i} \le T$).

For every test case, it is guaranteed that no such full assignment of coordinates exists. Your task is to provide a directly checkable certificate of unsatisfiability by identifying a specific relaxed subsystem of these constraints that is already impossible to satisfy on its own. 

You must output a valid certificate of unsatisfiability from one of the two allowed forms below. It is mathematically guaranteed that at least one such certificate is valid for every test case.

- `JOB i` : For the item at 1-based index $i$, the subsystem consisting only of the Precedence constraint for $i$ and the Boundaries constraints for $i$ cannot be simultaneously satisfied (ignoring all other items and conditions).
- `LOAD c` : where $c \in \{1, 2\}$. This certifies that the subsystem consisting only of the Disjointness constraints for stage $c$, along with the requirement that $S_{c,i} \ge 0$ and $E_{c,i} \le T$ for all $i$, cannot be simultaneously satisfied (ignoring the other stage and all other conditions).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **q1** and **q2** (1 ≤ q1, q2 ≤ 1000000): the values of $q_{1,i}$ and $q_{2,i}$ for the $i$-th item.

## Output

Print a single line containing a valid certificate: `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for item 1, the `JOB` subsystem requires the stage 1 interval (length 70) to start at $\ge 0$, the stage 2 interval (length 60) to end at $\le 100$, and the stage 1 interval to completely precede the stage 2 interval. Placing stage 1 as early as possible occupies $[0, 70]$. Stage 2 must then start at $\ge 70$, meaning it would end at $\ge 130$, which contradicts the boundary of 100. Thus, this subsystem is unsatisfiable for item 1, making `JOB 1` a valid certificate.

In Example 2, no single item violates the `JOB` subsystem. However, for `LOAD 1`, the subsystem requires four stage 1 intervals (each of length 50) to be mutually disjoint and all completely contained within the bounds $[0, 150]$. The total length of these intervals is 200. It is mathematically impossible to pack intervals of total length 200 into a bounded space of length 150 without overlap. Thus, this subsystem is unsatisfiable, making `LOAD 1` a valid certificate.

I replaced the center-coordinate system and symmetric margin function with an isomorphic start-end interval system.
