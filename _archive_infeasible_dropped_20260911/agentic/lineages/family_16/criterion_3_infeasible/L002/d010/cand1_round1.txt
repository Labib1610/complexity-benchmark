<STATEMENT>
# Infeasible Coordinate Assignments

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a target threshold $T$ and a set of $j$ elements. Each element $i$ (from $1$ to $j$) is associated with two positive integers, $q_{1,i}$ and $q_{2,i}$.

Consider the problem of assigning a real-valued coordinate $w_{c,i}$ to each element $i$ for each stage $c \in \{1, 2\}$. To define the constraints, we use a family of quadratic polynomials parameterized by two real numbers $u$ and $v$:
$$P(x; u, v) = x^2 + 2ux + v^2$$

We classify these polynomials into two types based on their roots:
- **Admissible:** The polynomial has at least one real root.
- **Strongly Admissible:** The polynomial has at least one real root, and the sum of its roots (counting multiplicity) is strictly negative.

The assignment of coordinates must satisfy the following three conditions:
1. **Separation:** For every element $i$, the polynomial $P(x;\; w_{2,i} - w_{1,i},\; q_{1,i} + q_{2,i})$ is strongly admissible.
2. **Dispersion:** For each stage $c \in \{1, 2\}$ and every pair of distinct elements $i$ and $k$, the polynomial $P(x;\; w_{c,i} - w_{c,k},\; q_{c,i} + q_{c,k})$ is admissible.
3. **Boundary:** For every element $i$, the polynomial $P(x;\; w_{1,i},\; q_{1,i})$ is strongly admissible, and the polynomial $P(x;\; 2T - w_{2,i},\; q_{2,i})$ is strongly admissible.

For every test case, it is guaranteed that no such full assignment of $w_{c,i}$ exists. Your task is to provide a directly checkable certificate of unsatisfiability by identifying a specific relaxed subsystem of these constraints that is already impossible to satisfy on its own. 

You must output a valid certificate of unsatisfiability from one of the two allowed forms below. It is mathematically guaranteed that at least one such certificate is valid for every test case.

- `JOB i` : For the element at 1-based index $i$, the subsystem consisting only of the Separation constraint for $i$ and the Boundary constraints for $i$ cannot be simultaneously satisfied (ignoring all other elements and conditions).
- `LOAD c` : where $c \in \{1, 2\}$. This certifies that the subsystem consisting only of the Dispersion constraints for stage $c$, along with the requirement that both $P(x;\; w_{c,i},\; q_{c,i})$ and $P(x;\; 2T - w_{c,i},\; q_{c,i})$ are strongly admissible for all $i$, cannot be simultaneously satisfied (ignoring the other stage and all other conditions).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **q1** and **q2** (1 ≤ q1, q2 ≤ 1000000): the values of $q_{1,i}$ and $q_{2,i}$ for the $i$-th element.

## Output

Print a single line containing a valid certificate: `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for element 1, the `JOB` subsystem requires $P(x;\; w_{1,1},\; 70)$ to be strongly admissible, meaning it has real roots and their sum is negative. This implies its discriminant is non-negative and $-2w_{1,1} < 0$, yielding $w_{1,1} \ge 70$.
Similarly, $P(x;\; w_{2,1} - w_{1,1},\; 130)$ being strongly admissible requires $w_{2,1} - w_{1,1} \ge 130$.
Finally, $P(x;\; 200 - w_{2,1},\; 60)$ being strongly admissible requires $200 - w_{2,1} \ge 60$, or $w_{2,1} \le 140$.
Combining the first two deductions gives $w_{2,1} \ge 200$, which contradicts $w_{2,1} \le 140$. Thus, this subsystem is unsatisfiable for element 1, making `JOB 1` a valid certificate.

In Example 2, no single element violates the `JOB` subsystem. However, for `LOAD 1`, the subsystem requires that for all $i$, both $P(x;\; w_{1,i},\; 50)$ and $P(x;\; 300 - w_{1,i},\; 50)$ are strongly admissible. By analyzing the roots, this confines all four coordinates to the interval $50 \le w_{1,i} \le 250$, an interval of length 200.
The Dispersion condition requires $P(x;\; w_{1,i} - w_{1,k},\; 100)$ to be admissible for all distinct pairs. For this polynomial to have real roots, its discriminant must be non-negative, which simplifies to $|w_{1,i} - w_{1,k}| \ge 100$.
It is mathematically impossible to place four points mutually separated by at least 100 within an interval of length 200. Thus, this subsystem is unsatisfiable, making `LOAD 1` a valid certificate.

<RATIONALE>
The explicit linear inequalities and absolute value bounds have been perfectly disguised as the non-negativity of discriminants and root sums of parameterized quadratic polynomials. This removes the surface-level interval packing and telescoping sum structure. Models must now correctly perform the symbolic algebraic reduction of the polynomial roots before they can recognize the mathematical isomorphism to the simple threshold sums, forcing genuine multi-hop reasoning.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that $x^2 + 2ux + v^2$ has real roots is exactly $u^2 \ge v^2 \iff |u| \ge |v|$, and adding that the sum of roots ($-2u$) is negative enforces $u \ge |v|$, making the polynomial constraints mathematically identical to the original separation, dispersion, and boundary inequalities.
</PRESERVED_ANSWER>
