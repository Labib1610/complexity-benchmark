<METHOD_NAME>Topological Neighborhood Substitution</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces all explicit algebraic inequalities and margin functions with equivalent topological set relations (disjointness, strict ordering of elements, and subset containment) on open intervals. This forces the model to semantically derive the bounds rather than algebraically simplifying given formulas, defeating models that rely on extracting and summing variables from explicit constraint equations.</METHOD_DESCRIPTION>

<STATEMENT>
# Infeasible Region Assignments

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a target threshold $T$ and a set of $j$ elements. Each element $i$ (from $1$ to $j$) is associated with two positive integers, $q_{1,i}$ and $q_{2,i}$.

Consider the problem of assigning a real-valued center coordinate $w_{c,i}$ to each element $i$ for each stage $c \in \{1, 2\}$. For any chosen coordinate $w_{c,i}$, we define its **active region** $N_{c,i}$ as the open interval of real numbers strictly between $w_{c,i} - q_{c,i}$ and $w_{c,i} + q_{c,i}$.

The assignment of coordinates must satisfy the following three conditions:
1. **Separation:** For every element $i$, every real number in $N_{1,i}$ must be strictly less than every real number in $N_{2,i}$.
2. **Dispersion:** For each stage $c \in \{1, 2\}$, the active regions of any two distinct elements $i$ and $k$ must be disjoint (they cannot share any real numbers).
3. **Boundary:** For every element $i$, all numbers in $N_{1,i}$ must be strictly positive, and all numbers in $N_{2,i}$ must be strictly less than $2T$.

For every test case, it is guaranteed that no such full assignment of $w_{c,i}$ exists. Your task is to provide a directly checkable certificate of unsatisfiability by identifying a specific relaxed subsystem of these constraints that is already impossible to satisfy on its own. 

You must output a valid certificate of unsatisfiability from one of the two allowed forms below. It is mathematically guaranteed that at least one such certificate is valid for every test case.

- `JOB i` : For the element at 1-based index $i$, the subsystem consisting only of the Separation constraint for $i$ and the Boundary constraints for $i$ cannot be simultaneously satisfied (ignoring all other elements and conditions).
- `LOAD c` : where $c \in \{1, 2\}$. This certifies that the subsystem consisting only of the Dispersion constraints for stage $c$, along with the requirement that $N_{c,i} \subset (0, 2T)$ for all $i$, cannot be simultaneously satisfied (ignoring the other stage and all other conditions).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **q1** and **q2** (1 ≤ q1, q2 ≤ 1000000): the values of $q_{1,i}$ and $q_{2,i}$ for the $i$-th element.

## Output

Print a single line containing a valid certificate: `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for element 1, the `JOB` subsystem requires assigning active regions $N_{1,1} = (w_{1,1} - 70, w_{1,1} + 70)$ and $N_{2,1} = (w_{2,1} - 60, w_{2,1} + 60)$. The Boundary conditions require $N_{1,1} \subset (0, \infty)$ and $N_{2,1} \subset (-\infty, 200)$. The Separation condition requires every point in $N_{1,1}$ to be strictly less than every point in $N_{2,1}$. It is mathematically impossible to place these two intervals such that they satisfy these bounds while maintaining the strict ordering. Thus, this subsystem is unsatisfiable, making `JOB 1` a valid certificate.

In Example 2, no single element violates the `JOB` subsystem. However, for `LOAD 1`, the subsystem requires assigning four active regions $N_{1,i} = (w_{1,i} - 50, w_{1,i} + 50)$. The requirement that $N_{1,i} \subset (0, 300)$ forces all elements of all four regions to lie strictly between 0 and 300. The Dispersion condition mandates that no real number can belong to more than one of these regions. It is mathematically impossible to select four such disjoint intervals under these bounds. Thus, this subsystem is unsatisfiable, making `LOAD 1` a valid certificate.
</STATEMENT>
<RATIONALE>
The explicit algebraic inequalities (e.g., $w_{2,i} - w_{1,i} \ge q_{1,i} + q_{2,i}$) and the symmetric margin function have been completely removed. They are replaced by topological set relations (disjointness, strict relative ordering, and subset containment) applied to open intervals. This forces models to geometrically deduce that the constraints dictate interval lengths and bounds, breaking their reliance on algebraically parsing and summing explicitly provided variables.
</RATIONALE>
<PRESERVED_ANSWER>
The topological condition that every point in $N_1$ is strictly less than every point in $N_2$ is mathematically equivalent to $\sup N_1 \le \inf N_2$, which perfectly reconstructs the original separation inequality; similarly, the subset and disjointness conditions exactly reproduce the original boundary and dispersion limits, ensuring all valid certificates remain strictly identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying verification logic still requires checking independent linear invariants ($O(1)$ per job and $O(N)$ overall aggregate sums), maintaining the exact same linear time complexity class.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "every real number in $N_{1,i}$ must be strictly less than every real number in $N_{2,i}$" as requiring an explicit gap between the intervals, but since the intervals are defined as open, $\sup N_1 = \inf N_2$ satisfies the strict inequality for all elements within the sets, making the phrasing mathematically rigorous and unambiguous.
</RISK>
