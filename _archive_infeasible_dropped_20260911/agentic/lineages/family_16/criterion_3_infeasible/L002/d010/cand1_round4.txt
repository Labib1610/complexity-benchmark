<STATEMENT>
# Infeasible Coordinate Assignments

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a target parameter $T$ and a set of $j$ elements. Each element $i$ (from $1$ to $j$) is associated with two positive integers, $q_{1,i}$ and $q_{2,i}$.

Consider the problem of assigning a 2D coordinate $(X_i, Y_i)$ of real numbers to each element $i$. The assignment must satisfy the following four conditions:
1. **Sum Bound:** For every element $i$, $X_i + q_{1,i} + q_{2,i} \le 2T$.
2. **Difference Bounds:** For every element $i$, $X_i + Y_i \ge 2q_{1,i}$ and $X_i - Y_i \ge 2q_{2,i}$.
3. **Stage 1 Separation:** For every pair of distinct elements $i$ and $k$, $|X_i - X_k + Y_i - Y_k| \ge 2(q_{1,i} + q_{1,k})$.
4. **Stage 2 Separation:** For every pair of distinct elements $i$ and $k$, $|X_i - X_k - Y_i + Y_k| \ge 2(q_{2,i} + q_{2,k})$.

For every input instance, it is mathematically guaranteed that no such full assignment of $(X_i, Y_i)$ exists. Your task is to provide a directly checkable certificate of unsatisfiability by identifying a specific relaxed subsystem of these constraints that is already impossible to satisfy on its own.

You must output a valid certificate of unsatisfiability from one of the two allowed forms below. It is guaranteed that exactly one of the two certificate types applies for each input instance.

- `JOB i` : For the element at 1-based index $i$, the isolated subsystem consisting only of the Sum Bound and Difference Bounds for $i$ cannot be simultaneously satisfied (ignoring all other elements and conditions).
- `LOAD c` : where $c \in \{1, 2\}$. This certifies that the isolated subsystem consisting only of the Stage $c$ Separation constraints, along with the requirement that for all $i$, $2q_{1,i} \le X_i + Y_i \le 4T - 2q_{1,i}$ (if $c=1$) or $2q_{2,i} \le X_i - Y_i \le 4T - 2q_{2,i}$ (if $c=2$), cannot be simultaneously satisfied (ignoring the other stage and all other conditions).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **q1** and **q2** (1 ≤ q1, q2 ≤ 1000000): the values of $q_{1,i}$ and $q_{2,i}$ for the $i$-th element.

## Output

Print a single line containing a valid certificate: `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for element 1, the `JOB` subsystem requires $X_1 + Y_1 \ge 140$, $X_1 - Y_1 \ge 120$, and $X_1 \le 200 - 70 - 60 = 70$. Adding the two Difference Bounds gives $2X_1 \ge 260$, so $X_1 \ge 130$, which contradicts the Sum Bound $X_1 \le 70$. Thus, this subsystem is unsatisfiable for element 1, making `JOB 1` a valid certificate.

In Example 2, no single element violates the `JOB` subsystem. However, for `LOAD 1`, the subsystem requires four pairs of real numbers $(X_i, Y_i)$ to simultaneously satisfy $100 \le X_i + Y_i \le 600 - 100 = 500$. This confines the value of $X_i + Y_i$ for all four elements to an interval of length 400. The Stage 1 Separation condition requires $|(X_i + Y_i) - (X_k + Y_k)| \ge 200$ for all distinct pairs. It is mathematically impossible to place four values mutually separated by at least 200 within an interval of length 400. Thus, this subsystem is unsatisfiable, making `LOAD 1` a valid certificate.
