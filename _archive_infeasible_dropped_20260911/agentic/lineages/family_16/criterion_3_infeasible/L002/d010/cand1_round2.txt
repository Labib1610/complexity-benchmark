# Impossible Deadline: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a manufacturing schedule for a plant with two machines, Machine 1 and Machine 2. There is a strict operational deadline of $T$ hours, and a batch of $j$ jobs that must be completed. 

Each job $i$ (from $1$ to $j$) is associated with two positive integers, $q_{1,i}$ and $q_{2,i}$, representing the required total hours of processing on Machine 1 and Machine 2, respectively. Preemption is allowed, meaning a job's processing can be paused and resumed seamlessly.

A schedule is defined by assigning a set of time intervals $E_{c,i} \subseteq [0, T]$ for each job $i$ on each machine $c \in \{1, 2\}$. A valid schedule must satisfy the following three conditions:
1. **Processing Requirement:** For each machine $c$ and job $i$, the total duration (the sum of the lengths of the intervals in $E_{c,i}$) must be exactly $q_{c,i}$.
2. **Sequential Flow:** For every job $i$, all processing on Machine 1 must strictly precede all processing on Machine 2. Mathematically, for any time $x \in E_{1,i}$ and any time $y \in E_{2,i}$, it must hold that $x < y$.
3. **Machine Capacity:** A machine can only process one job at a time. For each machine $c$, the time sets $E_{c,1}, E_{c,2}, \dots, E_{c,j}$ must be mutually disjoint.

For every test case, it is mathematically guaranteed that no full valid schedule exists. Your task is to provide a directly checkable certificate of impossibility by identifying a specific relaxed subsystem of these constraints that is already impossible to satisfy on its own. 

You must output a valid certificate of impossibility from one of the two allowed forms below. It is guaranteed that at least one such certificate is valid for every test case.

- `JOB i` : For the job at 1-based index $i$, the subsystem consisting only of the **Processing Requirement** for job $i$ and the **Sequential Flow** constraint for job $i$ cannot be simultaneously satisfied within the domain $[0, T]$ (ignoring all other jobs and the Machine Capacity conditions).
- `LOAD c` : where $c \in \{1, 2\}$. This certifies that the subsystem consisting only of the **Processing Requirement** for all jobs on machine $c$ and the **Machine Capacity** constraint for machine $c$ cannot be simultaneously satisfied within the domain $[0, T]$ (ignoring the other machine and all Sequential Flow conditions).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **q1** and **q2** (1 ≤ q1, q2 ≤ 1000000): the values of $q_{1,i}$ and $q_{2,i}$ for the $i$-th job.

## Output

Print a single line containing a valid certificate: `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```
