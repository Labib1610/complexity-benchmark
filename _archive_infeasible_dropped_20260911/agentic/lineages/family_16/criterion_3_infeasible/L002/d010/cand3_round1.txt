<STATEMENT>
# Infeasible Bounding Boxes

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a bounding parameter $T$ and a set of $j$ elements. Each element $i$ (from $1$ to $j$) is associated with two positive integers, $q_{1,i}$ and $q_{2,i}$.

Consider the problem of assigning a center point $(x_i, y_i)$ in the real coordinate plane to each element $i$. For each element, we define its associated region $P_i$ as the Cartesian product of two closed intervals:
$$P_i = [x_i - q_{1,i}, x_i + q_{1,i}] \times [y_i - q_{2,i}, y_i + q_{2,i}]$$

The assignment of all $j$ center points must satisfy the following three conditions:
1. **Diagonal Separation:** For every element $i$, every point $(u, v)$ contained in $P_i$ must satisfy $u \le v$.
2. **Orthogonal Non-Overlap:** 
   - The projection of all regions $P_i$ onto the X-axis yields a set of $j$ intervals that are mutually non-overlapping (they may touch at their endpoints, but their interiors must be disjoint).
   - The projection of all regions $P_i$ onto the Y-axis yields a set of $j$ intervals that are mutually non-overlapping.
3. **Bounding Square:** For every element $i$, the entire region $P_i$ is completely contained within the square $[0, 2T] \times [0, 2T]$.

For every test case, it is guaranteed that no such full assignment of center points exists. Your task is to provide a directly checkable certificate of unsatisfiability by identifying a specific relaxed subsystem of these constraints that is already impossible to satisfy on its own.

You must output a valid certificate of unsatisfiability from one of the two allowed forms below. It is mathematically guaranteed that at least one such certificate is valid for every test case.

- `JOB i` : For the element at 1-based index $i$, the subsystem consisting ONLY of the Diagonal Separation condition for $P_i$ and the Bounding Square condition for $P_i$ cannot be simultaneously satisfied (ignoring all other elements and conditions).
- `LOAD c` : where $c \in \{1, 2\}$. For $c=1$, this certifies that the subsystem consisting ONLY of the X-axis Orthogonal Non-Overlap condition, combined with the requirement that the X-axis projection of every $P_i$ is contained within $[0, 2T]$, cannot be simultaneously satisfied. For $c=2$, the identical certification applies to the Y-axis projections instead (ignoring the other axis and all other conditions).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **q1** and **q2** (1 ≤ q1, q2 ≤ 1000000): the values of $q_{1,i}$ and $q_{2,i}$ for the $i$-th element.

## Output

Print a single line containing a valid certificate: `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for element 1, the `JOB` subsystem requires $P_1 \subset [0, 200] \times [0, 200]$, meaning $x_1 - 70 \ge 0$ (so $x_1 \ge 70$) and $y_1 + 60 \le 200$ (so $y_1 \le 140$). The Diagonal Separation condition requires that for all $(u, v) \in P_1$, $u \le v$. The maximum possible $u$ is $x_1 + 70$, and the minimum possible $v$ is $y_1 - 60$. Thus we must have $x_1 + 70 \le y_1 - 60$, or $y_1 - x_1 \ge 130$. Combining $x_1 \ge 70$ with $y_1 - x_1 \ge 130$ gives $y_1 \ge 200$, which contradicts $y_1 \le 140$. Thus, this subsystem is unsatisfiable for element 1, making `JOB 1` a valid certificate.

In Example 2, no single element violates the `JOB` subsystem. However, for `LOAD 1`, the subsystem requires the X-axis projections of all four regions to be mutually non-overlapping and contained within $[0, 300]$. For each element $i$, its X-axis projection is $[x_i - 50, x_i + 50]$. The subsystem requires these four intervals to have disjoint interiors. The distance between the centers of any two such intervals of radius 50 must be at least 100. It is mathematically impossible to place four points mutually separated by at least 100 such that all their surrounding radius-50 intervals are completely contained within the interval $[0, 300]$, which only has a total length of 300. Thus, this subsystem is unsatisfiable, making `LOAD 1` a valid certificate.

<RATIONALE>
The problem was completely reframed from a 1D scheduling/coordinate assignment into a 2D geometric packing problem of Cartesian products of intervals. The explicit algebraic bounds (e.g., $w_{2,i} - w_{1,i} \ge q_{1,i} + q_{2,i}$ and $|w_{c,i} - w_{c,k}| \ge q_{c,i} + q_{c,k}$) have been replaced with topological properties: half-plane inclusion ($u \le v$) and 1D projection disjointness. To succeed, a model can no longer pattern-match the algebraic inequalities to find $q_1+q_2 > T$ and $\sum q > T$; it must genuinely deduce these bounds by reasoning through the maximum extents of the regions and the pigeonhole principle for interval packing.
</RATIONALE>
