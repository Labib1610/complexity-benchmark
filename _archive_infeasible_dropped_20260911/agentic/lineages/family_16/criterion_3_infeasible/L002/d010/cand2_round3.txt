<METHOD_NAME>Set-Theoretic Region Packing</METHOD_NAME>
<METHOD_DESCRIPTION>Translates the explicit coordinate inequalities into strict set-theoretic relations on open neighborhoods defined by quadratic inequalities. This forces the model to geometrically interpret the conditions as an interval packing problem rather than pattern-matching the algebraic sums.</METHOD_DESCRIPTION>

<STATEMENT>
# Infeasible Region Assignments

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a target threshold $T$ and a set of $j$ elements. Each element $i$ (from $1$ to $j$) is associated with two positive integers, $q_{1,i}$ and $q_{2,i}$.

Consider the problem of assigning a real-valued center $w_{c,i}$ to each element $i$ for each stage $c \in \{1, 2\}$. For a given assignment, we define the open regions for each element and stage as:
$$R_{1,i} = \{ x \in \mathbb{R} \mid (x - w_{1,i})^2 < q_{1,i}^2 \}$$
$$R_{2,i} = \{ x \in \mathbb{R} \mid (x - w_{2,i})^2 < q_{2,i}^2 \}$$

A valid full assignment of centers $w_{c,i}$ must satisfy the following three conditions:
1. **Precedence:** For every element $i$, and for all real values $x \in R_{1,i}$ and $y \in R_{2,i}$, it must hold that $y \ge x$.
2. **Exclusivity:** For each stage $c \in \{1, 2\}$ and every pair of distinct elements $i$ and $k$, the intersection $R_{c,i} \cap R_{c,k}$ must be empty.
3. **Confinement:** For every element $i$, $R_{1,i} \subset (0, \infty)$ and $R_{2,i} \subset (-\infty, 2T)$.

For every test case, it is guaranteed that no such full assignment of $w_{c,i}$ exists. Your task is to provide a directly checkable certificate of unsatisfiability by identifying a specific relaxed subsystem of these constraints that is already impossible to satisfy on its own.

You must output a valid certificate of unsatisfiability from one of the two allowed forms below. It is mathematically guaranteed that exactly one such certificate is valid for each test case, meaning precisely one of the following reasons will apply uniquely.

- `JOB i` : For the element at 1-based index $i$, the subsystem consisting only of the Precedence constraint for $i$ and the Confinement constraints for $i$ cannot be simultaneously satisfied by any real values $w_{1,i}$ and $w_{2,i}$ (ignoring all other elements and conditions).
- `LOAD c` : where $c \in \{1, 2\}$. This certifies that the subsystem consisting only of the Exclusivity constraints for stage $c$, along with the requirement that $R_{c,i} \subset (0, 2T)$ for all elements $i$, cannot be simultaneously satisfied by any real values $w_{c,1}, \dots, w_{c,j}$ (ignoring the other stage and all other conditions).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **q1** and **q2** (1 ≤ q1, q2 ≤ 1000000): the values of $q_{1,i}$ and $q_{2,i}$ for the $i$-th element.

## Output

Print a single line containing the unique valid certificate: `JOB i` or `LOAD c` as described above.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for element 1, the `JOB` subsystem requires finding centers $w_{1,1}$ and $w_{2,1}$ such that $R_{1,1} \subset (0, \infty)$, $R_{2,1} \subset (-\infty, 200)$, and for all $x \in R_{1,1}, y \in R_{2,1}$, $y \ge x$. The region $R_{1,1}$ has width 140, and $R_{2,1}$ has width 120. Confining these strict bounds while enforcing the precedence constraint forces a contradiction, making this subsystem unsatisfiable for element 1. Thus, `JOB 1` is the valid certificate.

In Example 2, no single element violates the `JOB` subsystem. However, for `LOAD 1`, the subsystem requires assigning centers $w_{1,i}$ for all four elements such that their regions $R_{1,i}$ (each of width 100) are mutually disjoint (Exclusivity) and all strictly contained within $(0, 300)$. It is mathematically impossible to pack four mutually disjoint regions of width 100 into a bounding domain of width 300. Thus, this subsystem is unsatisfiable, making `LOAD 1` the valid certificate.
</STATEMENT>
<RATIONALE>
Changed the explicit algebraic inequalities (Separation, Dispersion, Boundary) into set-theoretic relations (Precedence, Exclusivity, Confinement) over open regions defined by quadratic inequalities. This forces the model to geometrically interpret the sets as open intervals and deduce the bounding lengths, preventing trivial pattern matching of the isolated sum checks `q1+q2 > T` and `sum(q_c) > T`. Also restored the exclusivity guarantee to satisfy the gate's G3 rejection.
</RATIONALE>
<PRESERVED_ANSWER>
The open regions $R_{c,i}$ correspond exactly to intervals $(w_{c,i} - q_{c,i}, w_{c,i} + q_{c,i})$, making the Exclusivity (disjointness), Precedence (ordering), and Confinement (bounding) conditions mathematically isomorphic to the original Dispersion, Separation, and Boundary inequalities.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The required checks remain mathematically identical to testing if $q_{1,i} + q_{2,i} > T$ for any job or $\sum q_{c,i} > T$ for any stage, preserving the $O(N)$ time complexity.
</PRESERVED_CLASS>
<RISK>
None. The set-builder notation and subset conditions are perfectly standard, rigorously equivalent to the original constraints, and the exclusivity guarantee clarifies the output requirements.
</RISK>
