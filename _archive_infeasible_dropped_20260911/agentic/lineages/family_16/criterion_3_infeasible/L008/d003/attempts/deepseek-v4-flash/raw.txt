We need to determine which diagnostic code is valid.  

The key observations:

- If any single job has `p1 + p2 > T`, then `JOB i` is valid.
- Otherwise, we check if the total time for subsystem 1 or subsystem 2 alone exceeds `T`.  
  - If `sum(p1) > T`, then `LOAD 1` is valid.
  - If `sum(p2) > T`, then `LOAD 2` is valid.

The problem guarantees exactly one of these conditions holds.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    idx = 2
    total1 = 0
    total2 = 0
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        total1 += p1
        total2 += p2
    if total1 > T:
        print("LOAD 1")
    elif total2 > T:
        print("LOAD 2")

if __name__ == "__main__":
    main()
```
