<STATEMENT>
# Problem C — Kinematic Constraints Validation

Time limit: 2 s   Memory limit: 256 MB

## Description

A physics engine must validate a 1D kinematic configuration of $j$ mechanical linkages within a bounding track of length $T$. 

Each linkage $k \in \{1 \dots j\}$ consists of a primary slider of length $p1_k$ and a secondary slider of length $p2_k$. The configuration is defined by assigning a real-valued center coordinate $c1_k$ to each primary slider and $c2_k$ to each secondary slider.

A configuration is physically realizable if and only if it satisfies all of the following algebraic constraints:

1. **Primary Bounds:** For all $k \in \{1 \dots j\}$, $c1_k \ge \frac{p1_k}{2}$ and $c1_k \le T - \frac{p1_k}{2}$.
2. **Secondary Bounds:** For all $k \in \{1 \dots j\}$, $c2_k \ge \frac{p2_k}{2}$ and $c2_k \le T - \frac{p2_k}{2}$.
3. **Linkage Sequence:** For all $k \in \{1 \dots j\}$, $c2_k - c1_k \ge \frac{p1_k + p2_k}{2}$.
4. **Primary Exclusivity:** For any two distinct linkages $u$ and $v$ in $\{1 \dots j\}$, $4(c1_u - c1_v)^2 \ge (p1_u + p1_v)^2$.
5. **Secondary Exclusivity:** For any two distinct linkages $u$ and $v$ in $\{1 \dots j\}$, $4(c2_u - c2_v)^2 \ge (p2_u + p2_v)^2$.

The engine has determined that no physically realizable configuration exists for the current batch of linkages. You must output a diagnostic code identifying the isolated source of this impossibility. 

The input data is guaranteed to trigger exactly one of the following isolated contradictions. Print the corresponding code:
- `JOB i` (where $i$ is the 1-based index of the linkage): It is mathematically impossible to assign coordinates $c1_i$ and $c2_i$ for linkage $i$ that simultaneously satisfy Constraints 1, 2, and 3 (assuming all other linkages are ignored and Constraints 4 and 5 are lifted). If multiple linkages satisfy this, you may output the code for any such linkage.
- `LOAD 1`: It is mathematically impossible to assign coordinates $c1_1 \dots c1_j$ for all $j$ linkages that simultaneously satisfy Constraints 1 and 4 (assuming Constraints 2, 3, and 5 are lifted).
- `LOAD 2`: It is mathematically impossible to assign coordinates $c2_1 \dots c2_j$ for all $j$ linkages that simultaneously satisfy Constraints 2 and 5 (assuming Constraints 1, 3, and 4 are lifted).

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p1$ and $p2$ ($1 \le p1, p2 \le 1000000$): the lengths of the primary and secondary sliders for that linkage.

## Output

Print a single line containing the valid diagnostic code (`JOB i`, `LOAD 1`, or `LOAD 2`).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is triggered because Constraint 1 requires $c1_1 \ge 35$. Constraint 3 requires $c2_1 - c1_1 \ge 65$, which forces $c2_1 \ge c1_1 + 65 \ge 100$. However, Constraint 2 requires $c2_1 \le 100 - 30 = 70$. The bounds $c2_1 \ge 100$ and $c2_1 \le 70$ form a direct contradiction, making it impossible to satisfy Constraints 1, 2, and 3 for linkage 1.

In Example 2, `LOAD 1` is triggered because Constraint 1 requires all four primary sliders to have their centers in $[25, 125]$. Constraint 4 requires the squared distance between any two distinct primary centers to be at least $2500$, meaning the absolute distance is at least 50. This forces the four centers to span a distance of at least $3 \times 50 = 150$. Since the maximum available distance between any two valid centers is $125 - 25 = 100$, it is mathematically impossible to satisfy Constraints 1 and 4 simultaneously.

<RATIONALE>
The interval scheduling constraints were translated into kinematic constraints on the center coordinates of 1D sliders. The non-overlap condition is now expressed as a quadratic lower bound on the distance between centers, and the sequencing rule is a relative distance bound. This requires models to algebraically decode the inequalities to recognize the underlying sum-of-lengths bottleneck, defeating heuristic pattern matching.
</RATIONALE>
