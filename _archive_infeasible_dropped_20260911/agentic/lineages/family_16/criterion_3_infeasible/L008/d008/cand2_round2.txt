# Problem C — Dual-Stage Pipeline Validation

Time limit: 2 s   Memory limit: 256 MB

## Description

A resource controller must allocate segments of a continuous one-dimensional resource block of total capacity $T$ (represented geometrically as the closed real interval $[0, T]$) to a set of $j$ distinct entities.

Each entity $k \in \{1 \dots j\}$ requires exactly two allocations: a primary segment $A_k$ and a secondary segment $B_k$. An allocation configuration is considered valid if and only if it satisfies all of the following geometric and topological properties:

1. **Primary Bounds:** For all $k \in \{1 \dots j\}$, $A_k$ is a contiguous closed interval $[a_k, b_k] \subseteq [0, T]$ such that its length $b_k - a_k$ exactly equals $p1_k$.
2. **Secondary Bounds:** For all $k \in \{1 \dots j\}$, $B_k$ is a contiguous closed interval $[c_k, d_k] \subseteq [0, T]$ such that its length $d_k - c_k$ exactly equals $p2_k$.
3. **Internal Ordering:** For all $k \in \{1 \dots j\}$, the primary segment must fully precede the secondary segment (specifically, $b_k \le c_k$).
4. **Primary Non-Overlap:** For any two distinct entities $u$ and $v$ in $\{1 \dots j\}$, their primary segments $A_u$ and $A_v$ may share at most a single boundary point (their interiors must be disjoint).
5. **Secondary Non-Overlap:** For any two distinct entities $u$ and $v$ in $\{1 \dots j\}$, their secondary segments $B_u$ and $B_v$ may share at most a single boundary point (their interiors must be disjoint).

The system has determined that no valid allocation configuration exists for the current batch of entities. You must output a diagnostic code identifying the isolated source of this impossibility. 

The input data is guaranteed to trigger exactly one of the following isolated contradictions. Print the corresponding code:
- `JOB i` (where $i$ is the 1-based index of the entity): It is mathematically impossible to construct segments $A_i$ and $B_i$ for entity $i$ that simultaneously satisfy Properties 1, 2, and 3 (assuming all other entities are ignored and Properties 4 and 5 are lifted). If multiple entities satisfy this, you may output the code for any such entity.
- `LOAD 1`: It is mathematically impossible to construct primary segments $A_1 \dots A_j$ for all $j$ entities that simultaneously satisfy Properties 1 and 4 (assuming Properties 2, 3, and 5 are lifted, meaning secondary segments and internal ordering are ignored).
- `LOAD 2`: It is mathematically impossible to construct secondary segments $B_1 \dots B_j$ for all $j$ entities that simultaneously satisfy Properties 2 and 5 (assuming Properties 1, 3, and 4 are lifted, meaning primary segments and internal ordering are ignored).

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p1$ and $p2$ ($1 \le p1, p2 \le 1000000$): the required lengths for the primary and secondary segments for that entity.

## Output

Print a single line containing the valid diagnostic code (`JOB i`, `LOAD 1`, or `LOAD 2`).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is triggered because Property 1 requires $A_1$ to be an interval of length 70 within $[0, 100]$. Property 3 requires $A_1$ to fully precede $B_1$, meaning $B_1$ must be placed entirely in the space remaining after $A_1$. The maximum possible length for $B_1$ is thus $100 - 70 = 30$. However, Property 2 requires $B_1$ to have a length of 60. This contradiction makes it mathematically impossible to satisfy Properties 1, 2, and 3 for entity 1.

In Example 2, `LOAD 1` is triggered because Property 1 requires each of the four entities to be assigned a primary interval $A_k$ of length 50 within $[0, 150]$. Property 4 requires these four intervals to be internally disjoint. The total length required for four disjoint intervals of length 50 is $4 \times 50 = 200$. Since this exceeds the available capacity of 150, it is mathematically impossible to satisfy Properties 1 and 4 simultaneously.

<RATIONALE>
The explicit max/min inequalities and job-shop terminology from the seed have been mapped to a 1D geometric interval packing problem. This forces models to deduce that allocating $N$ internally disjoint intervals of given lengths into a bounded space requires their sum to be $\le T$, disabling pattern matching on standard scheduling constraint equations.
</RATIONALE>

The geometric properties are mathematically identical to the original start-time inequalities (contiguous segments map to start times and durations, internal ordering maps to sequential flow, and disjoint interiors map to exclusivity), so the exact same sum and sum-of-parts conditions apply.
</PRESERVED_ANSWER>
