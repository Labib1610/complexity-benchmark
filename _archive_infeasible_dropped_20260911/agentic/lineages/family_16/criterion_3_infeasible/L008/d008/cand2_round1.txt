<STATEMENT>
# Problem C — Dual-Stage Pipeline Validation

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing facility processes a batch of $j$ jobs through a nonpreemptive two-stage pipeline within a strict operational deadline of $T$ seconds. 

The pipeline consists of Machine A (Stage 1) and Machine B (Stage 2). For each job $k \in \{1 \dots j\}$, the production requires exactly $p1_k$ seconds of continuous processing on Machine A, followed later by exactly $p2_k$ seconds of continuous processing on Machine B. 

A schedule is defined by assigning to each job $k \in \{1 \dots j\}$ an execution rank $r_{A,k} \in \{1 \dots j\}$ on Machine A, and an execution rank $r_{B,k} \in \{1 \dots j\}$ on Machine B. Both rank assignments must be bijections (no two jobs may share the same rank on the same machine). 
Additionally, the schedule requires choosing two sequences of real-valued timeline markers:
- $0 = \alpha_0 \le \alpha_1 \le \dots \le \alpha_j \le T$ for Machine A
- $0 = \beta_0 \le \beta_1 \le \dots \le \beta_j \le T$ for Machine B

A schedule is physically executable if and only if it satisfies all of the following algebraic constraints:

1. **Machine A Capacity:** For all $k \in \{1 \dots j\}$, $\alpha_{r_{A,k}} - \alpha_{r_{A,k}-1} \ge p1_k$.
2. **Machine B Capacity:** For all $k \in \{1 \dots j\}$, $\beta_{r_{B,k}} - \beta_{r_{B,k}-1} \ge p2_k$.
3. **Sequential Flow:** For all $k \in \{1 \dots j\}$, $\alpha_{r_{A,k}-1} + p1_k \le \beta_{r_{B,k}-1}$.

The facility's control system has determined that no physically executable schedule exists for the current batch of jobs. You must output a diagnostic code identifying the isolated source of this impossibility. 

The input data is guaranteed to trigger exactly one of the following isolated contradictions. Print the corresponding code:
- `JOB i` (where $i$ is the 1-based index of the job): It is mathematically impossible to assign ranks and timeline markers that simultaneously satisfy Constraints 1, 2, and 3 for job $i$ alone. (This means evaluating the constraints as if $j=1$, meaning the chosen job must be assigned rank 1 on both machines, and the timeline markers are just $\alpha_0, \alpha_1$ and $\beta_0, \beta_1$). If multiple jobs satisfy this, you may output the code for any such job.
- `LOAD 1`: It is mathematically impossible to assign a bijection $r_A$ and timeline markers $\alpha_0 \dots \alpha_j$ for all $j$ jobs that simultaneously satisfy Constraint 1 (assuming Constraints 2, 3, and Machine B variables are completely ignored).
- `LOAD 2`: It is mathematically impossible to assign a bijection $r_B$ and timeline markers $\beta_0 \dots \beta_j$ for all $j$ jobs that simultaneously satisfy Constraint 2 (assuming Constraints 1, 3, and Machine A variables are completely ignored).

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p1$ and $p2$ ($1 \le p1, p2 \le 1000000$): the required processing times on Machine A and Machine B for that job.

## Output

Print a single line containing the valid diagnostic code (`JOB i`, `LOAD 1`, or `LOAD 2`).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is triggered when evaluating job 1 in isolation ($j=1$). Constraint 1 requires $\alpha_1 - \alpha_0 \ge 70$. Constraint 2 requires $\beta_1 - \beta_0 \ge 60$. Constraint 3 requires $\alpha_0 + 70 \le \beta_0$. Since the markers must satisfy $\beta_1 \le 100$, we have $\beta_0 \le 100 - 60 = 40$. However, Constraint 3 forces $\beta_0 \ge \alpha_0 + 70 \ge 70$. The requirements $\beta_0 \ge 70$ and $\beta_0 \le 40$ are contradictory, making it impossible to satisfy the constraints for job 1.

In Example 2, `LOAD 1` is triggered because Constraint 1 requires that for each of the four jobs, the difference between consecutive markers $\alpha_{r_{A,k}} - \alpha_{r_{A,k}-1}$ is at least 50. Since $r_A$ is a bijection, the sum of these four differences must be at least $4 \times 50 = 200$. However, the timeline markers must satisfy $0 = \alpha_0 \le \alpha_1 \le \alpha_2 \le \alpha_3 \le \alpha_4 \le 150$, which means the sum of the four differences is exactly $\alpha_4 - \alpha_0 \le 150$. This contradiction makes it mathematically impossible to satisfy Constraint 1 for all jobs.
</STATEMENT>
<RATIONALE>
I replaced the explicit interval overlap constraints with an equivalent formulation using monotonically non-decreasing timeline markers and rank bijections. This expresses the machine capacity as a telescoping sum of differences, removing the direct algebraic signatures of 1D non-overlapping intervals (`max(x,y) >= min(...)`) that the models were pattern-matching to deduce `sum(p) > T`.
</RATIONALE>
<PRESERVED_ANSWER>
The isolated contradictions evaluate to exactly the same mathematical conditions: `JOB i` reduces to $p1_i + p2_i > T$, and `LOAD 1`/`LOAD 2` reduce to the telescoping sum of differences bounded by $T$, which simplifies exactly to $\sum p1_k > T$ and $\sum p2_k > T$.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks to check three independent O(N) conditions (a single job's sequential sum, and the total sum for each machine), keeping it in the same feasibility-certification class.
</PRESERVED_CLASS>
