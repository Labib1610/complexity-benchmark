# Problem C — Dual-Phase Signal Validation

Time limit: 2 s   Memory limit: 256 MB

## Description

A signal processing facility processes a batch of $j$ signals within a strict operational time window of $T$ seconds. 

For each signal $k \in \{1 \dots j\}$, the processing requires an active transmission in Phase A of duration exactly $p1_k$ seconds, and an active transmission in Phase B of duration exactly $p2_k$ seconds.

A configuration is defined by assigning two indicator functions $\phi_k: \mathbb{R} \to \{0, 1\}$ (representing Phase A activity) and $\psi_k: \mathbb{R} \to \{0, 1\}$ (representing Phase B activity) to each signal $k$. A configuration is physically executable if and only if it satisfies all of the following analytic constraints:

1. **Phase A Domain:** For all $k \in \{1 \dots j\}$, there exists an interval $[a_k, b_k] \subseteq [0, T]$ with $b_k - a_k = p1_k$ such that $\phi_k(t) = 1$ for $t \in (a_k, b_k)$ and $\phi_k(t) = 0$ elsewhere.
2. **Phase B Domain:** For all $k \in \{1 \dots j\}$, there exists an interval $[c_k, d_k] \subseteq [0, T]$ with $d_k - c_k = p2_k$ such that $\psi_k(t) = 1$ for $t \in (c_k, d_k)$ and $\psi_k(t) = 0$ elsewhere.
3. **Centroid Sequencing:** For all $k \in \{1 \dots j\}$, the centers of mass of the two indicator functions must satisfy:
   $$ \frac{\int_0^T t \cdot \phi_k(t) dt}{\int_0^T \phi_k(t) dt} + \frac{\int_0^T \phi_k(t) dt}{2} \le \frac{\int_0^T t \cdot \psi_k(t) dt}{\int_0^T \psi_k(t) dt} - \frac{\int_0^T \psi_k(t) dt}{2} $$
4. **Phase A Interference:** For any two distinct signals $u$ and $v$ in $\{1 \dots j\}$, their Phase A functions are orthogonal: $\int_0^T \phi_u(t) \phi_v(t) dt = 0$.
5. **Phase B Interference:** For any two distinct signals $u$ and $v$ in $\{1 \dots j\}$, their Phase B functions are orthogonal: $\int_0^T \psi_u(t) \psi_v(t) dt = 0$.

The facility's control system has determined that no physically executable configuration exists for the current batch of signals. You must output a diagnostic code identifying the isolated source of this impossibility. 

The input data is guaranteed to trigger exactly one of the following isolated contradictions. Print the corresponding code:
- `JOB i` (where $i$ is the 1-based index of the signal): It is mathematically impossible to construct $\phi_i$ and $\psi_i$ for signal $i$ that simultaneously satisfy Constraints 1, 2, and 3 (assuming all other signals are ignored and Constraints 4 and 5 are lifted). If multiple signals satisfy this, you may output the code for any such signal.
- `LOAD 1`: It is mathematically impossible to construct $\phi_1 \dots \phi_j$ for all $j$ signals that simultaneously satisfy Constraints 1 and 4 (assuming Constraints 2, 3, and 5 are lifted, meaning Phase B is ignored and sequencing is lifted).
- `LOAD 2`: It is mathematically impossible to construct $\psi_1 \dots \psi_j$ for all $j$ signals that simultaneously satisfy Constraints 2 and 5 (assuming Constraints 1, 3, and 4 are lifted, meaning Phase A is ignored and sequencing is lifted).

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p1$ and $p2$ ($1 \le p1, p2 \le 1000000$): the required Phase A and Phase B duration for that signal.

## Output

Print a single line containing the valid diagnostic code (`JOB i`, `LOAD 1`, or `LOAD 2`).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is triggered because Constraint 1 requires $\phi_1$ to be supported on an interval $[a_1, b_1] \subseteq [0, 100]$ with $b_1 - a_1 = 70$. Constraint 2 requires $\psi_1$ to be supported on $[c_1, d_1] \subseteq [0, 100]$ with $d_1 - c_1 = 60$. Constraint 3 requires the center of mass of $\phi_1$ plus half its integral to be less than or equal to the center of mass of $\psi_1$ minus half its integral. For an interval of length 70 starting at $a_1 \ge 0$, this lower-bounds the Phase B interval start at 70. Since the Phase B interval has length 60, it must end at $d_1 \ge 130$. However, Constraint 2 strictly requires $d_1 \le 100$. The bounds $d_1 \ge 130$ and $d_1 \le 100$ form a direct contradiction, making it impossible to satisfy Constraints 1, 2, and 3 for signal 1.

In Example 2, `LOAD 1` is triggered because Constraint 1 requires each $\phi_k$ to be 1 on an interval of length 50 within $[0, 150]$. Constraint 4 requires that the integral of the product of any two distinct functions is 0, meaning their intervals of support can intersect at most at a set of measure zero (their boundaries). Thus, the four functions require a combined domain length of exactly $4 \times 50 = 200$. However, they must all fit within the available domain $[0, 150]$, which has a length of only 150. This contradiction makes it mathematically impossible to satisfy Constraints 1 and 4 simultaneously.

<RATIONALE>
The problem was completely reframed using continuous indicator functions and their integrals instead of algebraic inequalities. The sequential constraint is now expressed as an inequality between the centers of mass of the indicator functions, which models must symbolically integrate to realize it simplifies exactly to $x_k + p1_k \le y_k$. This removes the surface-level affordance of simple summations and explicit bounds.
</RATIONALE>
<PRESERVED_ANSWER>
The integral of an indicator function over its contiguous support is its length, and the center of mass plus half the length evaluates exactly to the upper bound of its interval; thus the constraints mathematically reduce to exactly the same threshold tests as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires exactly O(N) checking of three independent properties (a single job's sequential duration, and the total disjoint duration sum for each phase) to identify the sole contradiction.
</PRESERVED_CLASS>
<RISK>
Models might struggle with the continuous function notation or fail to analytically solve the centroid inequality, leading to confusion over how to check `JOB i`, though the mathematics are rigorous and standard.
</RISK>
