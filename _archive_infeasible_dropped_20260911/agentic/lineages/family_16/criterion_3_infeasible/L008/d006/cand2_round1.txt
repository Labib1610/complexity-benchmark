# Problem C — Measure-Theoretic Obstructions

Time limit: 2 s   Memory limit: 256 MB

## Description

Let $\Omega$ be the real interval $[0, T]$, equipped with the standard Lebesgue measure $\mu$. 
You are given $j$ pairs of positive real numbers, where the $k$-th pair (for $k \in \{1 \dots j\}$) is defined as $(p1_k, p2_k)$.

We define three independent systems of constraints regarding the existence of measurable subsets in $\Omega$. 
For any system, the basic requirement is that for each involved index $k$, we must choose measurable sets $A_k \subseteq \Omega$ and $B_k \subseteq \Omega$ such that $\mu(A_k) = p1_k$ and $\mu(B_k) = p2_k$.

- **System 1 (evaluated for a specific index $i$):** 
  There exist sets $A_i$ and $B_i$ fulfilling the basic requirement such that $\sup(A_i) \le \inf(B_i)$.
  
- **System 2 (evaluated for the full set of $j$ indices):** 
  There exists a collection of sets $\{A_1, \dots, A_j\}$ fulfilling the basic requirement such that for all $a \neq b$, $\mu(A_a \cap A_b) = 0$.

- **System 3 (evaluated for the full set of $j$ indices):** 
  There exists a collection of sets $\{B_1, \dots, B_j\}$ fulfilling the basic requirement such that for all $a \neq b$, $\mu(B_a \cap B_b) = 0$.

You are guaranteed that exactly one of the following logical obstructions is present in the provided input. Determine which one it is and print the corresponding diagnostic code:
- `JOB i` : System 1 is impossible to satisfy for the 1-based index $i$. (If multiple indices $i$ make System 1 impossible, you may output the code for any such $i$).
- `LOAD 1` : System 2 is impossible to satisfy.
- `LOAD 2` : System 3 is impossible to satisfy.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p1$ and $p2$ ($1 \le p1, p2 \le 1000000$), representing the measures $p1_k$ and $p2_k$ for $k = 1, \dots, j$ in order.

## Output

Print a single line containing the exact diagnostic code (`JOB i`, `LOAD 1`, or `LOAD 2`) corresponding to the isolated obstruction.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

<RATIONALE>
The previous versions failed because they maintained the additive "duration" and "overlap" concepts, which models easily pattern-match to subset sum or interval packing inequalities. By translating the entire problem into abstract measure theory over the Lebesgue space [0, T], the model is forced to independently deduce that `sup(A) <= inf(B)` implies `mu(A) + mu(B) <= T`. This removes all heuristic shortcuts while remaining mathematically isomorphic to the original scheduling constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The logical conditions for the three measure-theoretic systems to be impossible are exactly p1_i + p2_i > T, sum(p1_k) > T, and sum(p2_k) > T, which are identical to the original scheduling contradictions.
</PRESERVED_ANSWER>
