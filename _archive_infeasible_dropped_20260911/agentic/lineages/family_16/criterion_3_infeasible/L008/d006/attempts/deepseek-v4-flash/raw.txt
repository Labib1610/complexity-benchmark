We can model this as a feasibility check for a set of linear constraints.  
For each job, we have:

- Required gimbal increase: `p1`
- Required sensor increase: `p2`
- Time window: `T`

We need to check:

1. **Per-job feasibility**:  
   For job `k`, the gimbal must reach `p1` within `T`, and the sensor must reach `p2` within `T`.  
   Since gimbal and sensor can increase at most at rate 1 per unit time, we need `p1 <= T` and `p2 <= T`.

2. **Total gimbal constraint**:  
   Sum of all `p1` must be ≤ `T` (because total gimbal increase across all jobs cannot exceed total time).

3. **Total sensor constraint**:  
   Sum of all `p2` must be ≤ `T`.

4. **Per-job timing constraint**:  
   For each job, the sensor can only start increasing after the gimbal has reached `p1`.  
   So the time left for sensor is `T - p1`, and we need `p2 <= T - p1`.

If any of these fail, we output `LOAD 1` (global contradiction) or `JOB k` (per-job contradiction).  
The problem says:  
- If a single job is impossible due to its own constraints, output `JOB k`.  
- If the sum constraints fail, output `LOAD 1`.

We check per-job first, then global sums.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    idx = 0
    n = int(data[idx]); idx += 1
    T = int(data[idx]); idx += 1
    
    jobs = []
    total_gimbal = 0
    total_sensor = 0
    
    for i in range(n):
        p1 = int(data[idx]); idx += 1
        p2 = int(data[idx]); idx += 1
        jobs.append((p1, p2))
        total_gimbal += p1
        total_sensor += p2
    
    # Check per-job feasibility
    for i, (p1, p2) in enumerate(jobs, start=1):
        if p1 > T or p2 > T or p2 > T - p1:
            print(f"JOB {i}")
            return
    
    # Check global constraints
    if total_gimbal > T or total_sensor > T:
        print("LOAD 1")
        return
    
    # If all pass, no contradiction
    # The problem statement implies there is always a contradiction, but if none, we output nothing?
    # However, based on examples, they always output something. We'll output nothing if all pass.
    # But to be safe, we can output nothing or handle as needed.
    # Since the problem guarantees a contradiction, we can just return.
    
if __name__ == "__main__":
    main()
```
