# Problem C — Telemetry Window: Diagnostic Code

Time limit: 2 s   Memory limit: 256 MB

## Description

An orbital satellite is scheduled to execute $j$ observation jobs before the mission window closes at $t = T$ milliseconds.

Each observation job strictly defines two operational blocks:
1. The targeting gimbal (Subsystem 1) must act on the job for a continuous duration of $p1$ milliseconds.
2. The imaging sensor (Subsystem 2) must act on the job for a continuous duration of $p2$ milliseconds.

For any single job, the imaging sensor's block cannot begin until the targeting gimbal's block has completely finished. Furthermore, a subsystem can only process one job at a time.

Mission control has determined that no valid schedule exists to complete all jobs within the $T$-millisecond window. You must output a diagnostic code that isolates the fundamental mathematical contradiction.

By definition, a successful schedule within $T$ milliseconds requires certain idle times to be non-negative. The telemetry data guarantees that exactly one of the following hypothetical idle-time calculations will result in a strictly negative value. You must identify which one it is and print its corresponding code:

- `JOB i` (where $i$ is the 1-based job index): If job $i$ were the only job scheduled, its *concurrent idle time* would evaluate to a strictly negative number. This metric is defined as $T$ minus the total duration of the union of the active time intervals for Subsystem 1 and Subsystem 2. (Since the sensor strictly waits for the gimbal to finish, the intersection of these two active intervals is guaranteed to be empty).
- `LOAD c` (where $c$ is 1 or 2): The *unallocated time* for Subsystem $c$ would evaluate to a strictly negative number. This metric is defined as $T$ minus the total duration of the union of all active time intervals assigned to Subsystem $c$ across all jobs. (Since a subsystem can only process one job at a time, the pairwise intersection of these active intervals is guaranteed to be empty).

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p1$ and $p2$ ($1 \le p1, p2 \le 1000000$): the duration of the gimbal block and the duration of the sensor block for that observation job.

## Output

Print a single line containing the valid diagnostic code (`JOB i` or `LOAD c`).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, if job 1 were the only job, Subsystem 1 operates for 70 ms and Subsystem 2 operates for 60 ms. Because they operate sequentially, their active intervals are disjoint. Their union spans a total duration that exceeds the 100 ms window. This results in a strictly negative concurrent idle time, making `JOB 1` the correct code.

In Example 2, Subsystem 1 must execute four disjoint blocks of 50 ms each. The total duration of their union exceeds the 150 ms window, resulting in a strictly negative unallocated time, making `LOAD 1` the correct code.

This forces the model to deduce that the total duration of a union of disjoint sets equals the sum of their individual durations, and that `T - sum < 0` is algebraically identical to `sum > T`.
