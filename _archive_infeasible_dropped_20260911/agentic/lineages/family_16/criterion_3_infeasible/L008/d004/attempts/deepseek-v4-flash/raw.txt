We need to check three possible failure modes in order:

1. **JOB i** — For each job, check if `p1 + p2 > T`. If true, that job alone violates Rules A and B, because the gimbal and sensor must be sequential and both fit in the window.  
2. **LOAD 1** — Check if the sum of all `p1` exceeds `T`. If so, gimbal phases cannot all fit without overlap.  
3. **LOAD 2** — Check if the sum of all `p2` exceeds `T`. If so, sensor phases cannot all fit without overlap.

The problem guarantees exactly one of these will trigger.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    
    total_p1 = 0
    total_p2 = 0
    
    idx = 2
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        
        total_p1 += p1
        total_p2 += p2
    
    if total_p1 > T:
        print("LOAD 1")
        return
    
    if total_p2 > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
