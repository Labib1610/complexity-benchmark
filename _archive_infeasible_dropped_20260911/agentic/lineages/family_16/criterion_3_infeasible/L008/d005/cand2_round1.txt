# Problem C — Telemetry Window: Diagnostic Code

Time limit: 2 s   Memory limit: 256 MB

## Description

An orbital satellite is scheduled to execute **j** observation jobs within a mission window represented by the real interval $[0, \mathbf{T}]$.

For each job $k \in \{1 \dots \mathbf{j}\}$, a schedule must specify two contiguous intervals $X_k, Y_k \subset [0, \mathbf{T}]$. The length (Lebesgue measure) of $X_k$ must be exactly $\mathbf{p1}_k$, and the length of $Y_k$ must be exactly $\mathbf{p2}_k$.

Let $\chi_S(t)$ denote the indicator function of the interior of an interval $S$ (evaluating to $1$ if $t$ is strictly inside $S$, and $0$ otherwise). A schedule is valid only if it simultaneously satisfies three conditions:

- **Precedence:** For every job $k$, and for all $x \in X_k$ and $y \in Y_k$, $x \le y$.
- **Gimbal Capacity:** The density function $\rho_X(t) = \sum_{k=1}^{\mathbf{j}} \chi_{X_k}(t)$ satisfies $\rho_X(t) \le 1$ for all $t \in [0, \mathbf{T}]$.
- **Sensor Capacity:** The density function $\rho_Y(t) = \sum_{k=1}^{\mathbf{j}} \chi_{Y_k}(t)$ satisfies $\rho_Y(t) \le 1$ for all $t \in [0, \mathbf{T}]$.

Mission control has determined that a valid schedule is impossible. You must output a diagnostic code that identifies the isolated source of the failure. The telemetry data is guaranteed to trigger exactly one of the following independent failure modes. Print the corresponding code:

- `JOB i` (where **i** is the 1-based job index): There do not exist contiguous intervals $X_i, Y_i \subset [0, \mathbf{T}]$ of lengths $\mathbf{p1}_i$ and $\mathbf{p2}_i$ that satisfy the Precedence condition for job **i**.
- `LOAD 1`: There does not exist a collection of contiguous intervals $X_1 \dots X_{\mathbf{j}} \subset [0, \mathbf{T}]$ of lengths $\mathbf{p1}_1 \dots \mathbf{p1}_{\mathbf{j}}$ that satisfies the Gimbal Capacity condition.
- `LOAD 2`: There does not exist a collection of contiguous intervals $Y_1 \dots Y_{\mathbf{j}} \subset [0, \mathbf{T}]$ of lengths $\mathbf{p2}_1 \dots \mathbf{p2}_{\mathbf{j}}$ that satisfies the Sensor Capacity condition.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required lengths of $X_k$ and $Y_k$ respectively.

## Output

Print a single line containing the valid diagnostic code (`JOB i` or `LOAD c`).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is the correct code. Job 1 requires two contiguous intervals $X_1, Y_1 \subset [0, 100]$ of lengths 70 and 60. The Precedence condition requires all points in $X_1$ to be less than or equal to all points in $Y_1$. This mathematically demands that their union spans at least a measure of 130, which contradicts the domain $[0, 100]$. Thus, no such intervals can exist.

In Example 2, `LOAD 1` is the correct code. The Gimbal Capacity condition requires that the integral of the density function $\rho_X(t)$ over $[0, 150]$ cannot exceed 150. However, the sum of the required lengths for $X_1 \dots X_4$ is $50 \times 4 = 200$. Therefore, no valid collection of intervals $X_1 \dots X_4$ can exist.
</STATEMENT>
<RATIONALE>
The explicit algebraic inequalities (e.g., $G_k + p1_k \le S_k$) and specific rule-pair contradictions have been removed. They are replaced with a measure-theoretic framing where the conditions are defined by indicator functions, density bounds, and subsets of a real interval. To solve the problem, the model must deduce that the existence of intervals satisfying these abstract mathematical conditions reduces to the exact same scalar bounds ($p1+p2 > T$, $\sum p1 > T$, $\sum p2 > T$).
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical conditions for the intervals to exist within $[0, T]$ are identical to the original bounds: ordered intervals fit only if their combined length is $\le T$, and disjoint non-overlapping intervals fit only if their total length is $\le T$.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The solution requires exactly one pass to evaluate $p1+p2 > T$ and accumulate the sums for the two capacities, keeping the complexity class strictly $O(N)$ just as before.
</PRESERVED_CLASS>
