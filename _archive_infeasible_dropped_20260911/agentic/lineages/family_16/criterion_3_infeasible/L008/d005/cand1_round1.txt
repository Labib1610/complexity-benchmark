# Problem C — Telemetry Window: Diagnostic Code

Time limit: 2 s   Memory limit: 256 MB

## Description

An orbital satellite is scheduled to execute **j** observation jobs within a mission window of duration **T**. 

A schedule assigns a contiguous gimbal operation and a contiguous sensor operation to each job $k \in \{1 \dots \mathbf{j}\}$. We can model any such schedule by defining two indicator functions for each job:
- $g_k(t) = 1$ during job $k$'s gimbal operation, and $0$ otherwise. The support of $g_k(t)$ (the set of times where $g_k(t) = 1$) must be a single contiguous interval of length $\mathbf{p1}_k$.
- $s_k(t) = 1$ during job $k$'s sensor operation, and $0$ otherwise. The support of $s_k(t)$ must be a single contiguous interval of length $\mathbf{p2}_k$.

Mission control evaluates the feasibility of the schedule by checking if these indicator functions can satisfy the mission's mathematical constraints. It has been determined that no valid schedule can exist for the given telemetry data. 

An automated verifier has analyzed the subsystem requirements and guarantees that exactly one of the following certificate failures occurs. You must output the diagnostic code corresponding to the unique isolated failure:

- `JOB i` (where **i** is the 1-based job index): There exist no indicator functions $g_i(t)$ and $s_i(t)$ (as defined above) that can simultaneously achieve $\int_{0}^{\mathbf{T}} g_i(t) dt = \mathbf{p1}_i$, $\int_{0}^{\mathbf{T}} s_i(t) dt = \mathbf{p2}_i$, and $g_i(t_1) s_i(t_2) = 0$ for all $t_1 \ge t_2$.
- `LOAD 1`: There exists no set of indicator functions $g_1(t), \dots, g_\mathbf{j}(t)$ (as defined above) that can simultaneously achieve $\int_{0}^{\mathbf{T}} g_k(t) dt = \mathbf{p1}_k$ for all $k$, and bounded instantaneous overlap $\sum_{k=1}^{\mathbf{j}} g_k(t) \le 1$ for all real $t$.
- `LOAD 2`: There exists no set of indicator functions $s_1(t), \dots, s_\mathbf{j}(t)$ (as defined above) that can simultaneously achieve $\int_{0}^{\mathbf{T}} s_k(t) dt = \mathbf{p2}_k$ for all $k$, and bounded instantaneous overlap $\sum_{k=1}^{\mathbf{j}} s_k(t) \le 1$ for all real $t$.

Print the corresponding diagnostic code.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required duration of the gimbal block and the sensor block for that observation job.

## Output

Print a single line containing the valid diagnostic code (`JOB i` or `LOAD c`).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for `JOB 1`, the functions $g_1(t)$ and $s_1(t)$ must have integrals 70 and 60 within $[0, 100]$. This means the interval for $g_1$ occupies 70 units of time and $s_1$ occupies 60 units of time, both fully contained within $[0, 100]$. The condition $g_1(t_1) s_1(t_2) = 0$ for all $t_1 \ge t_2$ requires the $s_1$ interval to be strictly after the $g_1$ interval. The earliest $s_1$ can start is $t=70$, which means it would end at $70+60=130$, exceeding the window limit of $100$. Thus, no such functions can exist.

In Example 2, for `LOAD 1`, the functions $g_1(t) \dots g_4(t)$ must each have an integral of 50 within $[0, 150]$. Their sum cannot exceed 1 at any time $t$. Integrating the sum over $[0, 150]$ requires $\int_0^{150} \sum_{k=1}^{4} g_k(t) dt \le 150$. However, the sum of their individual integrals is $50 \times 4 = 200$. Since $200 > 150$, no such set of functions can exist.

<RATIONALE>
I removed the explicit references to individual scheduling rules and the phrasing that explicitly isolates jobs or rules ("even if all other jobs are completely ignored"). Instead, I formulated the failures as violated mathematical certificates using continuous indicator functions, definite integrals, and bounded sums. This forces the model to deduce the underlying discrete arithmetic constraints (e.g., integrating the bounded sum to derive `sum(p1) <= T`) rather than pattern-matching standard scheduling inequality structures.
</RATIONALE>
<PRESERVED_ANSWER>
The condition for `JOB i` mathematically reduces to $p1_i + p2_i > T$, and the conditions for `LOAD 1` and `LOAD 2` reduce to $\sum p1_k > T$ and $\sum p2_k > T$, exactly matching the seed problem's logic.
</PRESERVED_ANSWER>

The required checks remain three simple O(N) linear scans and sums, preserving the INFEASIBLE certification complexity class.
</PRESERVED_CLASS>
