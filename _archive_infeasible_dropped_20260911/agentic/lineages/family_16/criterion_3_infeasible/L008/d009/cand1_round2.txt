# Problem C — Production Line Bottlenecks

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing plant must process $j$ jobs on a production line consisting of Machine 1 followed by Machine 2. All jobs must be fully completed within a strict deadline of $T$ hours.

Each job $k \in \{1 \dots j\}$ requires $p1_k$ hours of uninterrupted processing on Machine 1, and then $p2_k$ hours of uninterrupted processing on Machine 2. A job cannot start on Machine 2 until it has completely finished on Machine 1. Each machine can process at most one job at a time.

For every input, no valid ordering can meet the deadline $T$. You must output a diagnostic code identifying a reason for this impossibility.

The following impossibility conditions are defined. At least one of these conditions is guaranteed to be true for the given input:
- `JOB i` (where $i$ is the 1-based index of the job): The individual job $i$ cannot possibly be completed within the deadline, because its total processing time across both machines strictly exceeds $T$ (that is, $p1_i + p2_i > T$). If multiple jobs satisfy this, you may output the code for any such job.
- `LOAD 1`: The total processing time required by all $j$ jobs on Machine 1 strictly exceeds the deadline $T$ (that is, $\sum_{k=1}^j p1_k > T$).
- `LOAD 2`: The total processing time required by all $j$ jobs on Machine 2 strictly exceeds the deadline $T$ (that is, $\sum_{k=1}^j p2_k > T$).

If multiple conditions are true, you may output the code for any of them. 

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p1$ and $p2$ ($1 \le p1, p2 \le 1000000$): the processing times on Machine 1 and Machine 2 for that job.

## Output

Print a single line containing a valid diagnostic code (`JOB i`, `LOAD 1`, or `LOAD 2`).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is triggered because job 1 requires 70 hours on Machine 1 and 60 hours on Machine 2. Its total processing time of 130 hours exceeds the deadline of 100 hours.

In Example 2, `LOAD 1` is triggered because all four jobs require 50 hours each on Machine 1. The total processing time on Machine 1 is 200 hours, which exceeds the deadline of 150 hours.
