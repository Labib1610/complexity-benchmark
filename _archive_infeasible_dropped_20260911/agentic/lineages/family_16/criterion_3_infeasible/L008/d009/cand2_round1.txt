# Problem C — Quantum State Vector Validation

Time limit: 2 s   Memory limit: 256 MB

## Description

A quantum simulation requires assigning a 2D state vector $(x_k, y_k) \in \mathbb{R}^2$ to each of $j$ particles within a bounding energy field $T$. 

Each particle $k \in \{1 \dots j\}$ has two intrinsic properties: spin $\alpha_k$ and charge $\beta_k$. The simulation configuration is defined by assigning real-valued coordinates $x_k$ and $y_k$ to each particle.

A state configuration is stable if and only if it satisfies all of the following algebraic conditions:

1. **Excitation bound:** For all $k \in \{1 \dots j\}$, $2y_k \ge \alpha_k + \beta_k$.
2. **Spin bounds:** For all $k \in \{1 \dots j\}$, $y_k + \alpha_k \le x_k \le y_k + 2T - \alpha_k$.
3. **Charge bounds:** For all $k \in \{1 \dots j\}$, $\beta_k - y_k \le x_k \le 2T - \beta_k - y_k$.
4. **Spin exclusion:** For any two distinct particles $u$ and $v$ in $\{1 \dots j\}$, $(x_u - x_v)^2 + (y_u - y_v)^2 \ge (\alpha_u + \alpha_v)^2 + 2(x_u - x_v)(y_u - y_v)$.
5. **Charge exclusion:** For any two distinct particles $u$ and $v$ in $\{1 \dots j\}$, $(x_u - x_v)^2 + (y_u - y_v)^2 \ge (\beta_u + \beta_v)^2 - 2(x_u - x_v)(y_u - y_v)$.

The simulation engine has determined that no stable configuration exists for the current batch of particles. You must output a diagnostic code identifying the isolated source of this instability. 

The input data is guaranteed to trigger exactly one of the following isolated contradictions. Print the corresponding code:
- `JOB i` (where $i$ is the 1-based index of the particle): It is mathematically impossible to assign a state vector $(x_i, y_i)$ for particle $i$ that simultaneously satisfies Conditions 1, 2, and 3 (assuming all other particles are ignored and Conditions 4 and 5 are lifted). If multiple particles satisfy this, you may output the code for any such particle.
- `LOAD 1`: It is mathematically impossible to assign state vectors $(x_1, y_1) \dots (x_j, y_j)$ for all $j$ particles that simultaneously satisfy Conditions 2 and 4 (assuming Conditions 1, 3, and 5 are lifted).
- `LOAD 2`: It is mathematically impossible to assign state vectors $(x_1, y_1) \dots (x_j, y_j)$ for all $j$ particles that simultaneously satisfy Conditions 3 and 5 (assuming Conditions 1, 2, and 4 are lifted).

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $\alpha$ and $\beta$ ($1 \le \alpha, \beta \le 1000000$): the spin and charge parameters for that particle.

## Output

Print a single line containing the valid diagnostic code (`JOB i`, `LOAD 1`, or `LOAD 2`).

## Note

In Example 1, `JOB 1` is triggered because Condition 1 requires $2y_1 \ge 130$, meaning $y_1 \ge 65$. Substituting this into Condition 2 requires $x_1 \ge 65 + 70 = 135$. However, substituting $y_1 \ge 65$ into Condition 3 requires $x_1 \le 200 - 60 - 65 = 75$. The requirements $x_1 \ge 135$ and $x_1 \le 75$ form a direct contradiction, making it impossible to satisfy Conditions 1, 2, and 3 for particle 1.

In Example 2, `LOAD 1` is triggered because Condition 2 tightly restricts the relative coordinates of the four particles. Condition 4 requires that the modified squared distance $(x_u - x_v)^2 + (y_u - y_v)^2 - 2(x_u - x_v)(y_u - y_v)$ between any two distinct particles evaluates to at least $10000$. These combined restrictions force the particles to spread out further than the bounding energy field $T=150$ allows, making it mathematically impossible to satisfy Conditions 2 and 4 simultaneously for all 4 particles.
