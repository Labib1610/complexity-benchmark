<STATEMENT>
# Problem C — Interval Packing Validation

Time limit: 2 s   Memory limit: 256 MB

## Description

A mathematical solver is attempting to construct $2j$ closed real intervals, denoted $P_1, \dots, P_j$ and $Q_1, \dots, Q_j$, satisfying the following properties:

1. **Primary Lengths:** For each $k \in \{1 \dots j\}$, the length of interval $P_k$ is exactly $p1_k$.
2. **Secondary Lengths:** For each $k \in \{1 \dots j\}$, the length of interval $Q_k$ is exactly $p2_k$.
3. **Primary Bounds:** For all $k \in \{1 \dots j\}$, $P_k \subseteq [0, T]$.
4. **Secondary Bounds:** For all $k \in \{1 \dots j\}$, $Q_k \subseteq [0, T]$.
5. **Precedence:** For all $k \in \{1 \dots j\}$, every real number in $P_k$ is less than or equal to every real number in $Q_k$.
6. **Primary Exclusivity:** For any two distinct indices $u$ and $v$ in $\{1 \dots j\}$, the intersection $P_u \cap P_v$ contains at most one point.
7. **Secondary Exclusivity:** For any two distinct indices $u$ and $v$ in $\{1 \dots j\}$, the intersection $Q_u \cap Q_v$ contains at most one point.

The solver has determined that no such collection of intervals can exist for the given parameters. Your task is to output a diagnostic code identifying the isolated source of this impossibility. 

The input data is guaranteed to trigger exactly one of the following isolated contradictions. Print the corresponding code:
- `JOB i` (where $i$ is the 1-based index): It is mathematically impossible to construct $P_i$ and $Q_i$ that simultaneously satisfy properties 1, 2, 3, 4, and 5 for this specific $i$ (assuming all other intervals are ignored and properties 6 and 7 are lifted). If multiple indices satisfy this, you may output the code for any such index.
- `LOAD 1`: It is mathematically impossible to construct the intervals $P_1 \dots P_j$ that simultaneously satisfy properties 1, 3, and 6 (assuming properties 2, 4, 5, and 7 are lifted).
- `LOAD 2`: It is mathematically impossible to construct the intervals $Q_1 \dots Q_j$ that simultaneously satisfy properties 2, 4, and 7 (assuming properties 1, 3, 5, and 6 are lifted).

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p1$ and $p2$ ($1 \le p1, p2 \le 1000000$): the required lengths for $P_k$ and $Q_k$ respectively.

## Output

Print a single line containing the valid diagnostic code (`JOB i`, `LOAD 1`, or `LOAD 2`).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is triggered because property 1 requires $P_1$ to have length 70, and property 3 requires $P_1 \subseteq [0, 100]$. Property 2 requires $Q_1$ to have length 60, and property 4 requires $Q_1 \subseteq [0, 100]$. Property 5 requires every element of $P_1$ to be $\le$ every element of $Q_1$, which implies the maximum element of $P_1$ is $\le$ the minimum element of $Q_1$. Thus, $P_1$ and $Q_1$ can intersect at most at a single point, meaning their union spans a length of at least $70 + 60 = 130$. Since they both must be subsets of $[0, 100]$, this is mathematically impossible, triggering the contradiction for $i=1$.

In Example 2, `LOAD 1` is triggered because property 1 requires all four $P$ intervals to have length 50. Property 6 requires that no two $P$ intervals overlap in more than one point, meaning their combined length must be at least $4 \times 50 = 200$. However, property 3 requires all $P$ intervals to be subsets of $[0, 150]$, which only provides a maximum available length of 150. Therefore, it is mathematically impossible to satisfy properties 1, 3, and 6 simultaneously.
