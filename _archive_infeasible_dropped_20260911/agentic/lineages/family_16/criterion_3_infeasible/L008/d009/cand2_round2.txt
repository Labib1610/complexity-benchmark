# Problem C — Kinematic Constraints Validation

Time limit: 2 s   Memory limit: 256 MB

## Description

A physics engine must validate a 1D kinematic configuration of $j$ mechanical linkages within a bounding track of length $T$. The track extends continuously from coordinate $0$ to coordinate $T$.

Each linkage $k \in \{1 \dots j\}$ consists of a primary slider of length $p1_k$ and a secondary slider of length $p2_k$. 

A configuration is physically realizable if and only if it satisfies all of the following spatial constraints:

1. **Primary Confinement:** For all $k \in \{1 \dots j\}$, the primary slider of linkage $k$ must be positioned entirely within the track's boundaries (between coordinates $0$ and $T$).
2. **Secondary Confinement:** For all $k \in \{1 \dots j\}$, the secondary slider of linkage $k$ must be positioned entirely within the track's boundaries (between coordinates $0$ and $T$).
3. **Linkage Sequence:** For all $k \in \{1 \dots j\}$, the primary slider of linkage $k$ must be positioned entirely to the left of its corresponding secondary slider, with no overlap between the two.
4. **Primary Exclusivity:** For any two distinct linkages $u$ and $v$ in $\{1 \dots j\}$, their primary sliders must not overlap each other.
5. **Secondary Exclusivity:** For any two distinct linkages $u$ and $v$ in $\{1 \dots j\}$, their secondary sliders must not overlap each other.

The engine has determined that no physically realizable configuration exists for the current batch of linkages. You must output a diagnostic code identifying the isolated source of this impossibility. 

The input data is guaranteed to trigger exactly one of the following isolated contradictions. Print the corresponding code:
- `JOB i` (where $i$ is the 1-based index of the linkage): It is mathematically impossible to position the sliders for linkage $i$ to simultaneously satisfy Constraints 1, 2, and 3 (assuming all other linkages are ignored and Constraints 4 and 5 are lifted). If multiple linkages satisfy this, you may output the code for any such linkage.
- `LOAD 1`: It is mathematically impossible to position the primary sliders for all $j$ linkages to simultaneously satisfy Constraints 1 and 4 (assuming Constraints 2, 3, and 5 are lifted).
- `LOAD 2`: It is mathematically impossible to position the secondary sliders for all $j$ linkages to simultaneously satisfy Constraints 2 and 5 (assuming Constraints 1, 3, and 4 are lifted).

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p1$ and $p2$ ($1 \le p1, p2 \le 1000000$): the lengths of the primary and secondary sliders for that linkage.

## Output

Print a single line containing the valid diagnostic code (`JOB i`, `LOAD 1`, or `LOAD 2`).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is triggered because linkage 1 requires a primary slider of length 70 and a secondary slider of length 60. Constraint 3 requires the primary slider to be placed entirely to the left of the secondary slider without overlapping, which means linkage 1 requires a total contiguous span of at least $70 + 60 = 130$. However, Constraints 1 and 2 require both sliders to fit within the track of length $T = 100$. This forms a direct contradiction, making it impossible to satisfy Constraints 1, 2, and 3 for linkage 1.

In Example 2, `LOAD 1` is triggered because there are four primary sliders, each of length 50. Constraint 4 requires that no two primary sliders overlap, meaning they must occupy distinct segments of the track. This requires a total available length of at least $4 \times 50 = 200$. Since Constraint 1 restricts all primary sliders to a track of total length $T = 150$, it is mathematically impossible to satisfy Constraints 1 and 4 simultaneously.
