<STATEMENT>
# Problem C — Kinematic Constraints Validation

Time limit: 2 s   Memory limit: 256 MB

## Description

A physics engine must validate a 1D kinematic configuration of $j$ mechanical linkages within a bounding track of length $T$. 

The configuration is defined by assigning two density functions to each linkage $k \in \{1 \dots j\}$: a primary density $\rho_{1,k}(x)$ and a secondary density $\rho_{2,k}(x)$ over the real line $x$.

A configuration is physically realizable if and only if it satisfies all of the following conditions:

1. **Structural Integrity:** For all $k \in \{1 \dots j\}$, $\rho_{1,k}(x) \in \{0, 1\}$ everywhere, and the set $\{x \mid \rho_{1,k}(x) = 1\}$ is exactly one contiguous interval of length $p1_k$. Similarly, $\rho_{2,k}(x) \in \{0, 1\}$ everywhere, and the set $\{x \mid \rho_{2,k}(x) = 1\}$ is exactly one contiguous interval of length $p2_k$.
2. **Track Confinement:** For all $k \in \{1 \dots j\}$, $\rho_{1,k}(x) = 0$ and $\rho_{2,k}(x) = 0$ for all $x < 0$ and for all $x > T$.
3. **Linkage Sequence:** For all $k \in \{1 \dots j\}$, and for any $x, y \in \mathbb{R}$ such that $\rho_{1,k}(x) \cdot \rho_{2,k}(y) = 1$, it must hold that $y \ge x$.
4. **Primary Exclusivity:** $\int_{0}^{T} \left( \sum_{k=1}^j \rho_{1,k}(x) \right)^2 dx \le \sum_{k=1}^j p1_k$.
5. **Secondary Exclusivity:** $\int_{0}^{T} \left( \sum_{k=1}^j \rho_{2,k}(x) \right)^2 dx \le \sum_{k=1}^j p2_k$.

The engine has determined that no physically realizable configuration exists for the current batch of linkages. You must output a diagnostic code identifying the isolated source of this impossibility. 

The input data is guaranteed to trigger exactly one of the following isolated contradictions. Print the corresponding code:
- `JOB i` (where $i$ is the 1-based index of the linkage): It is mathematically impossible to define $\rho_{1,i}$ and $\rho_{2,i}$ that simultaneously satisfy Constraints 1, 2, and 3 for this specific linkage (assuming all other linkages are ignored and Constraints 4 and 5 are lifted). If multiple linkages satisfy this, you may output the code for any such linkage.
- `LOAD 1`: It is mathematically impossible to define $\rho_{1,1} \dots \rho_{1,j}$ for all $j$ linkages that simultaneously satisfy Constraints 1, 2, and 4 (assuming Constraints 3 and 5 are lifted).
- `LOAD 2`: It is mathematically impossible to define $\rho_{2,1} \dots \rho_{2,j}$ for all $j$ linkages that simultaneously satisfy Constraints 1, 2, and 5 (assuming Constraints 3 and 4 are lifted).

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p1$ and $p2$ ($1 \le p1, p2 \le 1000000$): the target lengths of the primary and secondary intervals for that linkage.

## Output

Print a single line containing the valid diagnostic code (`JOB i`, `LOAD 1`, or `LOAD 2`).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is triggered because for linkage 1, it is impossible to find a primary interval of length 70 and a secondary interval of length 60 within $[0, 100]$ such that the secondary interval lies entirely to the right of the primary interval (as required by Constraint 3).

In Example 2, `LOAD 1` is triggered because it is mathematically impossible to satisfy the integral condition of Constraint 4 for four primary intervals of length 50 confined within the track bounds of $[0, 150]$.
</STATEMENT>
<RATIONALE>
I replaced the algebraic center-coordinate constraints with equivalent functional constraints using indicator density functions. The exclusivity constraint, which previously allowed models to trivially pattern-match a `sum(p1) > T` check, is now expressed as an integral of the squared sum of densities bounded by the sum of lengths. This mathematically forces the intervals to be disjoint almost everywhere without explicitly stating it, requiring the model to analytically deduce the disjointness property to realize it implies a sum bound.
</RATIONALE>
<PRESERVED_ANSWER>
The integral condition $\int (\sum \rho)^2 \le \sum p$ for indicator functions is algebraically satisfied if and only if the intervals have mutually exclusive interiors, which is strictly identical to the original pairwise distance constraint, preserving all impossibility thresholds.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the same linear time check of $p1_i + p2_i > T$, $\sum p1_i > T$, and $\sum p2_i > T$, keeping it in the same INFEASIBLE certification class.
</PRESERVED_CLASS>
<RISK>
Models might struggle with the continuous functional analysis notation if they cannot integrate the square of a sum of indicator functions, but the text is mathematically rigorous and unambiguous.
</RISK>
