We can check the three possible failure modes in order:

1. **JOB i**: For each linkage, if `p1 + p2 > T`, then it’s impossible for that linkage alone to satisfy constraints 1, 2, and 3.  
2. **LOAD 1**: If the sum of all `p1` lengths exceeds `T`, then primary sliders can’t all fit without overlap.  
3. **LOAD 2**: If the sum of all `p2` lengths exceeds `T`, then secondary sliders can’t all fit without overlap.

We check in that order because the problem guarantees exactly one contradiction is triggered.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    
    p1s = []
    p2s = []
    idx = 2
    for i in range(j):
        p1 = int(data[idx])
        p2 = int(data[idx+1])
        idx += 2
        p1s.append(p1)
        p2s.append(p2)
        
        if p1 + p2 > T:
            print(f"JOB {i+1}")
            return
    
    if sum(p1s) > T:
        print("LOAD 1")
        return
    
    if sum(p2s) > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
