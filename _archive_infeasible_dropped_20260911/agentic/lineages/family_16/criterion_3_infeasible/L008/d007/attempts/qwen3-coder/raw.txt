    # No, that's wrong. We can have idle time. The issue is whether there exist start times.
    # Let's re-examine the LOAD 1 condition.
    # We want to see if there exist x_1,...,x_j such that:

    # So indeed, sum(p1) <= T is necessary and sufficient for LOAD 1 feasibility.
