<STATEMENT>
# Problem C — Spectrum Allocation: Diagnostic Code

Time limit: 2 s   Memory limit: 256 MB

## Description

A frequency allocation authority is assigning transmission bands within a continuous spectrum window $[0, \mathbf{T}]$ megahertz. There are $\mathbf{j}$ broadcasters requesting allocations. 

For each broadcaster $k \in \{1 \dots \mathbf{j}\}$, the authority must assign two Lebesgue measurable sets of frequencies: an uplink allocation $U_k \subseteq [0, \mathbf{T}]$ and a downlink allocation $D_k \subseteq [0, \mathbf{T}]$.

A valid allocation must satisfy all of the following constraints:
1. **Bandwidth Quotas:** For every broadcaster $k$, the Lebesgue measure of $U_k$ must be exactly $\mathbf{p1}_k$, and the Lebesgue measure of $D_k$ must be exactly $\mathbf{p2}_k$.
2. **Frequency Separation:** For every broadcaster $k$, all frequencies in their uplink allocation must be strictly lower than all frequencies in their downlink allocation. Formally, for any $x \in U_k$ and $y \in D_k$, it must be true that $x < y$.
3. **Uplink Exclusivity:** The uplink allocations of all broadcasters must be mutually disjoint. That is, for any $a \neq b$, $U_a \cap U_b = \emptyset$.
4. **Downlink Exclusivity:** The downlink allocations of all broadcasters must be mutually disjoint. That is, for any $a \neq b$, $D_a \cap D_b = \emptyset$.

The authority has determined that no valid sets $U_k$ and $D_k$ can exist for the requested quotas. You must output a diagnostic code that identifies the isolated source of the failure.

The request data is guaranteed to trigger exactly one of the following isolated contradictions. Print the corresponding code:
- `JOB i` (where **i** is the 1-based broadcaster index): It is mathematically impossible to define sets $U_i$ and $D_i$ for broadcaster **i** that simultaneously satisfy Conditions 1 and 2 (treating broadcaster **i** in isolation). If multiple broadcasters satisfy this, output the code for any such broadcaster.
- `LOAD 1`: It is mathematically impossible to define sets $U_1 \dots U_j$ for the full group of **j** broadcasters that simultaneously satisfy Conditions 1 and 3 (even if Conditions 2 and 4 are completely ignored).
- `LOAD 2`: It is mathematically impossible to define sets $D_1 \dots D_j$ for the full group of **j** broadcasters that simultaneously satisfy Conditions 1 and 4 (even if Conditions 2 and 3 are completely ignored).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required uplink measure and downlink measure for that broadcaster.

## Output

Print a single line containing the valid diagnostic code (`JOB i` or `LOAD c`).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is triggered because Condition 1 requires the measure of $U_1$ to be $70$ and $D_1$ to be $60$. By Condition 2, all elements of $U_1$ must be strictly less than all elements of $D_1$. This requires the existence of some cutoff frequency $c$ such that $U_1 \subseteq [0, c]$ and $D_1 \subseteq [c, 100]$. Thus, the maximum possible measure for $U_1$ is $c$, and for $D_1$ is $100 - c$. Their combined measure cannot exceed $100$. However, $70 + 60 = 130 > 100$, making it mathematically impossible to satisfy Conditions 1 and 2 simultaneously for broadcaster 1.

In Example 2, `LOAD 1` is triggered because Condition 1 requires the measure of $U_k$ to be $50$ for all four broadcasters. By Condition 3, these four sets must be mutually disjoint subsets of $[0, 150]$. The measure of their union would be the sum of their individual measures, which is $200$. Since the total available spectrum window has a measure of only $150$, it is mathematically impossible to satisfy Conditions 1 and 3 simultaneously for the full group of broadcasters.

<RATIONALE>
I transformed the problem from continuous cumulative functions bounded by real-time into assigning Lebesgue measurable subsets of a given interval. Sequential dependencies became strict inequality between set elements, and aggregate bandwidth became mutual disjointness. This forces the model to independently derive that $x < y$ bounds the sum of measures to $T$, and that disjointness bounds the total measure to $T$, completely defeating pattern-matching on typical continuous-flow or scheduling constraints.
</RATIONALE>

Every diagnostic code maps exactly to the same isolated violations: $p1_i + p2_i > T$ corresponds to the impossibility of separating two sets within $[0, T]$, while $\sum p1_k > T$ and $\sum p2_k > T$ correspond to the impossibility of fitting mutually disjoint sets into $[0, T]$.
