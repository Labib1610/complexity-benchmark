<STATEMENT>
# Problem C — Matrix Evolution: Diagnostic Code

Time limit: 2 s   Memory limit: 256 MB

## Description

A system's state over a window of **T** seconds is modeled by two $j \times j$ diagonal matrices, $X(t)$ and $Y(t)$, defined for $t \in [0, \mathbf{T}]$. 
The diagonal entries of both matrices must be continuous, non-decreasing real-valued functions of $t$.

For a valid evolution, the matrices must satisfy four conditions:
1. **Boundary Limits:** $X(0) = \mathbf{0}$ and $X(\mathbf{T}) = P_1$, where $P_1$ is a diagonal matrix with $(P_1)_{k,k} = \mathbf{p1}_k$. Similarly, $Y(0) = \mathbf{0}$ and $Y(\mathbf{T}) = P_2$, where $P_2$ is a diagonal matrix with $(P_2)_{k,k} = \mathbf{p2}_k$.
2. **Orthogonality of Deficit:** For all $t \in [0, \mathbf{T}]$, the matrix product $Y(t) [P_1 - X(t)]$ must be the zero matrix $\mathbf{0}$.
3. **Trace Rate X:** For any two times $t_a < t_b$ in $[0, \mathbf{T}]$, the trace of the difference satisfies $\text{Tr}(X(t_b) - X(t_a)) \le t_b - t_a$.
4. **Trace Rate Y:** For any two times $t_a < t_b$ in $[0, \mathbf{T}]$, the trace of the difference satisfies $\text{Tr}(Y(t_b) - Y(t_a)) \le t_b - t_a$.

System analysis has determined that no valid matrices $X(t)$ and $Y(t)$ can exist for the given targets $P_1$ and $P_2$. You must output a diagnostic code that identifies the isolated source of the failure. 

The targets are guaranteed to trigger exactly one of the following isolated contradictions. Print the corresponding code:
- `JOB i` (where **i** is the 1-based index): It is mathematically impossible to define the **i**-th diagonal elements $X_{i,i}(t)$ and $Y_{i,i}(t)$ that simultaneously satisfy Conditions 1, 2, 3, and 4 (assuming all other diagonal elements in the matrices are identically zero). If multiple indices satisfy this, you may output the code for any such index.
- `LOAD 1`: It is mathematically impossible to define the full diagonal matrix $X(t)$ that satisfies Conditions 1 and 3 simultaneously (even if Conditions 2 and 4 are completely ignored).
- `LOAD 2`: It is mathematically impossible to define the full diagonal matrix $Y(t)$ that satisfies Conditions 1 and 4 simultaneously (even if Conditions 2 and 3 are completely ignored).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required final diagonal values $(P_1)_{k,k}$ and $(P_2)_{k,k}$ for that index.

## Output

Print a single line containing the valid diagnostic code (`JOB i` or `LOAD c`).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is triggered because Conditions 1 and 2 require $X_{1,1}(t)$ to reach $70$ before $Y_{1,1}(t)$ can begin increasing from $0$. By Condition 3 (applied to index 1 alone), $X_{1,1}(t)$ can increase by at most $t_b - t_a$ over any interval, meaning it cannot reach $70$ before time $t=70$. Thus, $Y_{1,1}(t)$ must remain $0$ for at least the first $70$ units of time. By Condition 4, $Y_{1,1}(t)$ can increase by at most $100 - 70 = 30$ over the remainder of the window. This makes it impossible for $Y_{1,1}(100)$ to reach the required $60$ (Condition 1).

In Example 2, `LOAD 1` is triggered because Condition 1 requires $\text{Tr}(X(150)) - \text{Tr}(X(0)) = 50 \times 4 = 200$. However, Condition 3 requires that the trace of the difference over the interval $[0, 150]$ cannot exceed $150 - 0 = 150$. This contradiction makes it mathematically impossible to satisfy Conditions 1 and 3 simultaneously for the full matrix.

<RATIONALE>
Changed the domain from continuous job scheduling variables to the evolution of diagonal matrices. The shared resource limit is now expressed as a bound on the trace of the matrix difference, and the sequential dependency is encoded as a zero matrix product. This forces models to genuinely analyze the linear algebra properties to derive the scalar inequalities, defeating any surface-level pattern matching of scheduling terminology.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical constraints are perfectly isomorphic: the trace of a diagonal matrix is the sum of its elements (mapping exactly to total system load), and the zero matrix product strictly enforces the sequential dependency of the isolated indices, leading to the exact same failure conditions.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
