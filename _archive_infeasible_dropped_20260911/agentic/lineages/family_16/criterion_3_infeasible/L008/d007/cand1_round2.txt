<STATEMENT>
# Problem C — Interval Subset Allocation

Time limit: 2 s   Memory limit: 256 MB

## Description

A resource allocation planner must assign subsets of a continuous real-time interval $[0, \mathbf{T}]$ to a collection of $\mathbf{j}$ items.

For each item $k \in \{1 \dots \mathbf{j}\}$, the planner must define two measurable sets of real numbers, $A_k$ and $B_k$, both entirely contained within the interval $[0, \mathbf{T}]$. 

A valid allocation must satisfy all of the following structural rules:
1. **Target Sizes:** For every item $k$, the total length (Lebesgue measure) of set $A_k$ must be exactly $\mathbf{p1}_k$, and the total length of set $B_k$ must be exactly $\mathbf{p2}_k$.
2. **Strict Precedence:** For every item $k$, every real number in $A_k$ must be strictly less than every real number in $B_k$.
3. **Phase 1 Capacity:** The sets $A_1, A_2, \dots, A_{\mathbf{j}}$ must be pairwise disjoint (no two of these sets may share any common points).
4. **Phase 2 Capacity:** The sets $B_1, B_2, \dots, B_{\mathbf{j}}$ must be pairwise disjoint.

An automated validation engine has determined that no valid sets $A_k$ and $B_k$ can exist for the requested target sizes. You must output a diagnostic code that identifies the isolated source of the failure.

The input data is guaranteed to trigger exactly one of the following isolated impossibilities. Print the corresponding code:
- `JOB i` (where **i** is the 1-based index of the item): It is mathematically impossible to construct sets $A_i$ and $B_i$ for item **i** that simultaneously satisfy Rules 1 and 2 (even if Rules 3 and 4 are completely ignored, and all other items are ignored). If multiple items satisfy this, you may output the code for any such item.
- `LOAD 1`: It is mathematically impossible to construct sets $A_1 \dots A_{\mathbf{j}}$ for the full collection of items that simultaneously satisfy Rules 1 and 3 (even if Rules 2 and 4 are completely ignored).
- `LOAD 2`: It is mathematically impossible to construct sets $B_1 \dots B_{\mathbf{j}}$ for the full collection of items that simultaneously satisfy Rules 1 and 4 (even if Rules 2 and 3 are completely ignored).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the required total length for set $A$ and set $B$ for that item.

## Output

Print a single line containing the valid diagnostic code (`JOB i` or `LOAD c`).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is triggered because Rule 1 requires $A_1$ to have a length of $70$ and $B_1$ to have a length of $60$. Since both sets must be contained within $[0, 100]$, their combined length ($130$) exceeds the total available length of the interval. Any two sets that satisfy Rule 2 must be completely disjoint, meaning their combined length cannot exceed the length of the bounding interval ($100$). Thus, it is impossible to satisfy Rules 1 and 2 simultaneously for item 1.

In Example 2, `LOAD 1` is triggered because Rule 1 requires each of the four sets $A_1, A_2, A_3, A_4$ to have a length of $50$. The sum of their lengths is $200$. Rule 3 requires these sets to be completely disjoint from one another. It is mathematically impossible to fit four disjoint sets of total length $200$ into the interval $[0, 150]$.
</STATEMENT>
<RATIONALE>
The problem was completely reframed from continuous telemetry functions to the assignment of measurable sets (subsets of a real interval). This removes the differential equations and continuous-function keywords that models were using to surface-match the `p1 + p2 > T` and `sum > T` checks. Models must now genuinely reason that disjoint sets within an interval have a combined length strictly bounded by the interval's length.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical requirements for the sets exactly mirror the original differential bounds: strict precedence requires the two sets for a single item to be disjoint (p1 + p2 > T), and pairwise disjointness requires the sum of set lengths across all items to not exceed the interval (sum(p1) > T and sum(p2) > T).
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class remains exactly $O(N)$ linear scanning to check the three localized sum bottlenecks, identically matching the original impossibility certification.
</PRESERVED_CLASS>
<RISK>
Models might struggle with the term "measurable sets of real numbers" or "Lebesgue measure", though the parenthetical "(total length)" provides a clear, intuitive fallback.
</RISK>
