We need to check two possible violations:

1. **JOB i**: If for some job, `p1 + p2 > T`, then even with no delays, that job can’t finish by `T`.  
   The earliest finish time for job `i` is `p1 + p2` (start gimbal at 0, then sensor immediately after).  
   If `p1 + p2 > T`, output `JOB i`.

2. **LOAD c**: If no job individually exceeds `T`, then check if the total time for subsystem 1 or subsystem 2 exceeds `T`.  
   - For subsystem 1: sum of all `p1` values.  
   - For subsystem 2: sum of all `p2` values.  
   If either sum > `T`, output `LOAD 1` or `LOAD 2` accordingly.

The problem guarantees exactly one violation, so we can check in order.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    idx = 2
    total_p1 = 0
    total_p2 = 0
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        total_p1 += p1
        total_p2 += p2
    if total_p1 > T:
        print("LOAD 1")
    elif total_p2 > T:
        print("LOAD 2")

if __name__ == "__main__":
    main()
```
