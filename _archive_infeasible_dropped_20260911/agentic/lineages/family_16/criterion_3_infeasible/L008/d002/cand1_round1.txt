# Problem C — Telemetry Window: Diagnostic Code

Time limit: 2 s   Memory limit: 256 MB

## Description

An orbital satellite is scheduled to execute a batch of **j** observation jobs before it passes out of communication range. The communication window lasts exactly **T** milliseconds, starting at time 0.

Any valid execution schedule must map each job **i** to a targeting interval $[a_i, a_i + p_{1,i}]$ on Subsystem 1 (the targeting gimbal) and an imaging interval $[b_i, b_i + p_{2,i}]$ on Subsystem 2 (the imaging sensor), subject to the following hardware constraints:
- For every job **i**, the targeting phase must complete before the imaging phase begins: $b_i \ge a_i + p_{1,i}$.
- No two operations can overlap on the targeting gimbal: all intervals on Subsystem 1 must be pairwise disjoint.
- No two operations can overlap on the imaging sensor: all intervals on Subsystem 2 must be pairwise disjoint.
- All operations must conclude within the communication window: $b_i + p_{2,i} \le T$ for all **i**, with $a_i \ge 0$.

Mission control has determined that no valid schedule can satisfy all these constraints simultaneously. Your task is to output a diagnostic code that proves this impossibility by identifying a structural violation.

A valid diagnostic code must be one of the following:
- `JOB i` (where **i** is a 1-based job index). This code certifies that the inherent lower bound for $b_i + p_{2,i}$ strictly exceeds **T**, based solely on the constraints applying to job **i** in isolation.
- `LOAD c` (where **c** is 1 or 2). This code certifies that the sum of the required interval lengths on Subsystem **c** strictly exceeds **T**, ensuring that no set of pairwise disjoint intervals for that subsystem could possibly fit within $[0, T]$.

You are guaranteed that the provided telemetry data will yield exactly one such structural violation. Print the valid code.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the duration $p_{1,i}$ required on Subsystem 1 and the duration $p_{2,i}$ required on Subsystem 2 for that observation job.

## Output

Print a single line containing the valid diagnostic code (`JOB i` or `LOAD c`).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is valid because job 1 requires an interval of length 70 on Subsystem 1, followed by an interval of length 60 on Subsystem 2. Since $b_1 \ge a_1 + 70$ and $a_1 \ge 0$, the earliest possible conclusion time is $b_1 + 60 \ge 130$. This inherent lower bound strictly exceeds the window of 100 milliseconds, independent of any other jobs.

In Example 2, `LOAD 1` is valid because the sum of the required interval lengths on Subsystem 1 is 50+50+50+50 = 200 milliseconds. Since 200 strictly exceeds the window of 150 milliseconds, it is impossible to schedule these disjoint intervals within $[0, 150]$.
