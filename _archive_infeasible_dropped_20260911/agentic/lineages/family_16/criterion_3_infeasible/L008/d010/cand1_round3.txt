# Problem C — Algebraic Feasibility Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a system of constraints over $2j$ real variables $x_1, \dots, x_j$ and $y_1, \dots, y_j$. The system is parameterized by a constant $T$ and $j$ pairs of positive integers $(u_k, v_k)$.

The constraints are defined as follows:
1. **(C1)** For all $k \in \{1 \dots j\}$, $x_k \ge 0$.
2. **(C2)** For all $k \in \{1 \dots j\}$, $y_k + v_k \le T$.
3. **(C3)** For all $k \in \{1 \dots j\}$, $y_k - x_k \ge u_k$.
4. **(C4)** For any two distinct indices $m$ and $n$ in $\{1 \dots j\}$, $\max(x_m, x_n) \ge \min(x_m + u_m, x_n + u_n)$.
5. **(C5)** For any two distinct indices $m$ and $n$ in $\{1 \dots j\}$, $\max(y_m, y_n) \ge \min(y_m + v_m, y_n + v_n)$.

An automated solver has determined that no real numbers $x_1 \dots x_j, y_1 \dots y_j$ can simultaneously satisfy all five constraint families. You must write a diagnostic tool to output a certificate identifying the specific isolated reason for this unsatisfiability.

The input data is guaranteed to trigger exactly one of the following isolated contradictions. Print the corresponding code:
- `JOB i` (where $i$ is the 1-based index of the pair): The subsystem consisting only of (C1), (C2), and (C3) for the specific index $i$ admits no real solution $(x_i, y_i)$. If multiple indices satisfy this, you may output the code for any such index.
- `LOAD 1`: The constraints $x_k \ge 0$ and $x_k + u_k \le T$ for all $k \in \{1 \dots j\}$, together with (C4), admit no real solution $(x_1 \dots x_j)$.
- `LOAD 2`: The constraints $y_k \ge 0$ and $y_k + v_k \le T$ for all $k \in \{1 \dots j\}$, together with (C5), admit no real solution $(y_1 \dots y_j)$.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $u$ and $v$ ($1 \le u, v \le 1000000$): the parameters $u_k$ and $v_k$ for pair $k$ (for $k=1 \dots j$).

## Output

Print a single line containing the valid diagnostic code (`JOB i`, `LOAD 1`, or `LOAD 2`).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is triggered because for $i=1$, we have $u_1=70$ and $v_1=60$. Constraint (C1) requires $x_1 \ge 0$, and (C2) requires $y_1 \le 100 - 60 = 40$. However, (C3) requires $y_1 - x_1 \ge 70$, meaning $y_1 \ge x_1 + 70 \ge 70$. It is mathematically impossible for $y_1$ to be both $\ge 70$ and $\le 40$, so the subsystem for $i=1$ admits no real solution.

In Example 2, `LOAD 1` is triggered because we require $x_k \ge 0$ and $x_k + 50 \le 150$ for all four pairs. Constraint (C4) mathematically ensures that for any two distinct indices $m$ and $n$, the open intervals $(x_m, x_m+50)$ and $(x_n, x_n+50)$ cannot overlap. Fitting four non-overlapping intervals of length 50 requires a total span of at least 200. Since all variables are restricted to a total span of 150, it is mathematically impossible to satisfy these conditions simultaneously.
