<STATEMENT>
# Problem C — Kinematic Constraints Validation

Time limit: 2 s   Memory limit: 256 MB

## Description

A physics engine must validate a 1D kinematic configuration of $j$ mechanical linkages within a bounding track of length $T$. The track extends continuously from coordinate $0$ to coordinate $T$.

Each linkage $k \in \{1 \dots j\}$ consists of a primary slider of mass $m_{A,k}$ and a secondary slider of mass $m_{B,k}$. All sliders are manufactured from a material with a uniform linear density of $1$ mass unit per spatial unit, meaning a slider's spatial length is exactly equal to its mass.

The configuration is defined by two spatial allocation functions over the continuous domain $[0, T]$:
- $M_A: [0, T] \to \{0, 1, \dots, j\}$ assigns each point on the track to the primary slider of a specific linkage, or $0$ if empty.
- $M_B: [0, T] \to \{0, 1, \dots, j\}$ assigns each point on the track to the secondary slider of a specific linkage, or $0$ if empty.

A configuration is physically realizable if and only if it satisfies the following continuous spatial conditions:
1. **Primary Mass Integration:** For each $k \in \{1 \dots j\}$, the spatial region $\{x \in [0, T] \mid M_A(x) = k\}$ must be exactly one continuous interval whose length equals the mass $m_{A,k}$.
2. **Secondary Mass Integration:** For each $k \in \{1 \dots j\}$, the spatial region $\{x \in [0, T] \mid M_B(x) = k\}$ must be exactly one continuous interval whose length equals the mass $m_{B,k}$.
3. **Kinematic Sequence:** For each $k \in \{1 \dots j\}$, the supremum of $\{x \in [0, T] \mid M_A(x) = k\}$ must be less than or equal to the infimum of $\{y \in [0, T] \mid M_B(y) = k\}$.

Because $M_A$ and $M_B$ are single-valued functions, it is inherently guaranteed that no two primary sliders can occupy the same coordinate, and no two secondary sliders can occupy the same coordinate. Furthermore, their strict domain $[0, T]$ inherently enforces that all sliders are confined within the track boundaries.

The engine has determined that no physically realizable configuration exists for the current batch of linkages. You must output a diagnostic code identifying the isolated source of this impossibility. 

The input data is guaranteed to trigger exactly one of the following isolated contradictions. Print the corresponding code:
- `JOB i` (where $i$ is the 1-based index of the linkage): It is mathematically impossible to define $M_A$ and $M_B$ to satisfy Constraints 1, 2, and 3 for linkage $i$ alone (i.e., assuming all other linkages are ignored, allowing $M_A$ and $M_B$ to map exclusively to $i$ or $0$). If multiple linkages satisfy this, you may output the code for any such linkage.
- `LOAD 1`: It is mathematically impossible to define $M_A$ to satisfy Constraint 1 for all $j$ linkages simultaneously.
- `LOAD 2`: It is mathematically impossible to define $M_B$ to satisfy Constraint 2 for all $j$ linkages simultaneously.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $m_A$ and $m_B$ ($1 \le m_A, m_B \le 1000000$): the masses of the primary and secondary sliders for that linkage.

## Output

Print a single line containing the valid diagnostic code (`JOB i`, `LOAD 1`, or `LOAD 2`).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is triggered because linkage 1 requires a primary interval of length 70 and a secondary interval of length 60. Constraint 3 requires the primary interval to be situated at coordinates no greater than the secondary interval. This means linkage 1 requires a total contiguous domain span of at least $70 + 60 = 130$. However, the domain of $M_A$ and $M_B$ is restricted to $[0, 100]$ (length $T = 100$). This forms a direct contradiction, making it impossible to satisfy Constraints 1, 2, and 3 for linkage 1.

In Example 2, `LOAD 1` is triggered because there are four primary sliders, each requiring an interval of length 50. Constraint 1 requires $M_A$ to allocate distinct continuous intervals for each linkage. Because $M_A$ is a single-valued function, these intervals cannot share points, requiring a total domain length of at least $4 \times 50 = 200$. Since the available domain is only $T = 150$, it is mathematically impossible to define $M_A$ to satisfy Constraint 1 for all linkages simultaneously.
