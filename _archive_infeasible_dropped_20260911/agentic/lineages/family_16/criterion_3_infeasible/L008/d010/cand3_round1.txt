<METHOD_DESCRIPTION>Replaces 1D geometric intervals and non-overlap constraints with their function-space dual: non-decreasing Lipschitz continuous cumulative allocations. The "no overlap" condition becomes a bound on the sum of function increments, and the "left of" condition becomes a split point $c_k$ in the domain. This preserves the exact algebraic bounds while stripping all geometric keywords that trigger pattern matching.</METHOD_DESCRIPTION>

# Problem C — Data Stream Bandwidth Validation

Time limit: 2 s   Memory limit: 256 MB

## Description

A network switch must validate a bandwidth allocation configuration for $j$ data streams over a time window of $T$ microseconds. The time window extends continuously from $t=0$ to $t=T$.

Each stream $k \in \{1 \dots j\}$ requires a primary allocation and a secondary allocation. 
- A **primary allocation** for stream $k$ is a non-decreasing real-valued function $f_k(t)$ defined for $t \in [0, T]$ such that $f_k(T) - f_k(0) \ge p1_k$.
- A **secondary allocation** for stream $k$ is a non-decreasing real-valued function $g_k(t)$ defined for $t \in [0, T]$ such that $g_k(T) - g_k(0) \ge p2_k$.

These functions represent the cumulative bytes transferred by stream $k$'s primary and secondary payloads from time $0$ up to time $t$.

A configuration is mathematically valid if and only if it satisfies all of the following constraints:

1. **Primary Confinement:** For all $k \in \{1 \dots j\}$, the primary allocation must not exceed the link speed when considered in isolation. For any time interval $0 \le a < b \le T$, it must hold that $f_k(b) - f_k(a) \le b - a$.
2. **Secondary Confinement:** For all $k \in \{1 \dots j\}$, the secondary allocation must not exceed the link speed when considered in isolation. For any time interval $0 \le a < b \le T$, it must hold that $g_k(b) - g_k(a) \le b - a$.
3. **Payload Sequencing:** For all $k \in \{1 \dots j\}$, there must exist a synchronization time $c_k \in [0, T]$ such that the required primary data is transferred before $c_k$, and the required secondary data is transferred after $c_k$. Specifically, $f_k(c_k) - f_k(0) \ge p1_k$ and $g_k(T) - g_k(c_k) \ge p2_k$.
4. **Primary Exclusivity:** The aggregate primary allocations across all streams must not exceed the link speed. For any time interval $0 \le a < b \le T$, it must hold that $\sum_{k=1}^j (f_k(b) - f_k(a)) \le b - a$.
5. **Secondary Exclusivity:** The aggregate secondary allocations across all streams must not exceed the link speed. For any time interval $0 \le a < b \le T$, it must hold that $\sum_{k=1}^j (g_k(b) - g_k(a)) \le b - a$.

The switch has determined that no mathematically valid configuration exists for the current batch of streams. You must output a diagnostic code identifying the isolated source of this impossibility. 

The input data is guaranteed to trigger exactly one of the following isolated contradictions. Print the corresponding code:
- `JOB i` (where $i$ is the 1-based index of the stream): It is mathematically impossible to find allocations for stream $i$ to simultaneously satisfy Constraints 1, 2, and 3 (assuming all other streams are ignored and Constraints 4 and 5 are lifted). If multiple streams satisfy this, you may output the code for any such stream.
- `LOAD 1`: It is mathematically impossible to find primary allocations for all $j$ streams to simultaneously satisfy Constraints 1 and 4 (assuming Constraints 2, 3, and 5 are lifted).
- `LOAD 2`: It is mathematically impossible to find secondary allocations for all $j$ streams to simultaneously satisfy Constraints 2 and 5 (assuming Constraints 1, 3, and 4 are lifted).

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p1$ and $p2$ ($1 \le p1, p2 \le 1000000$): the required payload sizes $p1_k$ and $p2_k$ for that stream.

## Output

Print a single line containing the valid diagnostic code (`JOB i`, `LOAD 1`, or `LOAD 2`).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is triggered because stream 1 requires a primary allocation with $p1_1 = 70$ and a secondary allocation with $p2_1 = 60$. Constraint 3 requires a synchronization time $c_1$ such that $f_1(c_1) - f_1(0) \ge 70$ and $g_1(T) - g_1(c_1) \ge 60$. However, Constraint 1 limits $f_1(c_1) - f_1(0) \le c_1$, meaning $c_1$ must be at least $70$. Constraint 2 limits $g_1(T) - g_1(c_1) \le T - c_1$, meaning $T - c_1 \ge 60$. For $T = 100$, this requires $c_1 \le 40$. It is mathematically impossible for $c_1$ to be simultaneously $\ge 70$ and $\le 40$. Thus, Constraints 1, 2, and 3 form a direct contradiction for stream 1 isolated.

In Example 2, `LOAD 1` is triggered because there are four streams, each requiring a primary allocation with $p1_k = 50$. By definition, each primary allocation must satisfy $f_k(T) - f_k(0) \ge 50$. Summing this requirement over all 4 streams means any valid set of primary allocations must transfer at least $200$ bytes in total from time $0$ to $T$. However, Constraint 4 requires that the aggregate transfer over the interval from $0$ to $T=150$ cannot exceed $150$. It is mathematically impossible to satisfy the definition of the primary allocations and Constraint 4 simultaneously.
</STATEMENT>
<RATIONALE>
The problem maps 1D geometric intervals and non-overlap constraints into a continuous function space. By defining allocations as non-decreasing Lipschitz continuous functions and bounding the sum of their increments, the "no overlap" condition is obfuscated while preserving the exact mathematical bounds (sum of increments <= total interval length). This forces the model to derive the algebraic bounds from the function definitions rather than relying on standard interval packing keywords.
</RATIONALE>
<PRESERVED_ANSWER>
The Lipschitz constraints exactly mirror the spatial limits: Constraint 3 enforces $p1_k \le c_k$ and $p2_k \le T - c_k$ (meaning $p1_k + p2_k \le T$), while Constraints 4 and 5 telescope over $[0, T]$ to enforce $\sum p1_k \le T$ and $\sum p2_k \le T$, perfectly matching the original thresholds.
</PRESERVED_ANSWER>
