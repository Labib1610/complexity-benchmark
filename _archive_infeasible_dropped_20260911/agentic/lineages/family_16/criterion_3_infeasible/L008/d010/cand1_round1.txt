<METHOD_NAME>Binary Matrix Contiguity Isomorphism</METHOD_NAME>
<METHOD_DESCRIPTION>Transforms the 1D interval packing problem into a 2D binary grid configuration problem. The intervals become contiguous blocks of 1s in the rows of two matrices. The non-overlap constraints become column-sum constraints (<= 1) across the matrices. The left-to-right constraint becomes an index inequality between the 1s in the two matrices. This forces the model to deduce the global sum bounds via double-counting (row sums vs column sums) rather than triggering their simple 1D interval heuristics.</METHOD_DESCRIPTION>

# Problem C — Grid Mapping Validation

Time limit: 2 s   Memory limit: 256 MB

## Description

A computational job requires configuring two independent binary grids, referred to as the Alpha grid and the Beta grid. Both grids have $j$ rows (indexed 1 to $j$) and $T$ columns (indexed 1 to $T$). Each cell in these grids must be assigned a value of exactly 0 or 1.

For each row $k \in \{1 \dots j\}$, you are given two parameters: $p1_k$ and $p2_k$. 

A valid configuration must satisfy all of the following structural constraints:

1. **Alpha Row Contiguity:** In the Alpha grid, row $k$ must contain exactly $p1_k$ cells with a value of 1. Furthermore, these 1s must be contiguous. (That is, if the cells at columns $c_1$ and $c_2$ in row $k$ are both 1, where $c_1 < c_2$, then every cell in row $k$ between columns $c_1$ and $c_2$ must also be 1).
2. **Beta Row Contiguity:** In the Beta grid, row $k$ must contain exactly $p2_k$ cells with a value of 1. These 1s must also be contiguous within row $k$.
3. **Strict Column Precedence:** For any row $k$, if the Alpha grid has a 1 at column $x$ and the Beta grid has a 1 at column $y$ in that same row, it is strictly required that $x < y$.
4. **Alpha Column Sparsity:** For every column $c \in \{1 \dots T\}$, the sum of the values in column $c$ of the Alpha grid (across all $j$ rows) must not exceed 1.
5. **Beta Column Sparsity:** For every column $c \in \{1 \dots T\}$, the sum of the values in column $c$ of the Beta grid (across all $j$ rows) must not exceed 1.

The validation engine has determined that no valid configuration exists for the provided parameters. The input data is guaranteed to trigger exactly one of the following isolated contradictions. You must output a diagnostic code identifying the source of this impossibility:

- `JOB i` (where $i$ is the 1-based index of the row): It is mathematically impossible to satisfy Constraints 1, 2, and 3 for row $i$ individually (assuming Constraints 4 and 5 are ignored and all other rows are entirely 0). If multiple rows satisfy this, you may output the code for any such row.
- `LOAD 1`: It is mathematically impossible to satisfy Constraints 1 and 4 simultaneously for the Alpha grid (assuming the Beta grid and Constraints 2, 3, and 5 are completely ignored).
- `LOAD 2`: It is mathematically impossible to satisfy Constraints 2 and 5 simultaneously for the Beta grid (assuming the Alpha grid and Constraints 1, 3, and 4 are completely ignored).

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p1$ and $p2$ ($1 \le p1, p2 \le 1000000$): the required number of 1s in the Alpha and Beta grids for that row, respectively.

## Output

Print a single line containing the valid diagnostic code (`JOB i`, `LOAD 1`, or `LOAD 2`).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is triggered because row 1 requires 70 contiguous 1s in the Alpha grid and 60 contiguous 1s in the Beta grid. Constraint 3 requires every 1 in the Alpha grid's row 1 to appear at a strictly lower column index than every 1 in the Beta grid's row 1. This means the 70 Alpha 1s and 60 Beta 1s must occupy distinct columns, with the Alpha sequence appearing strictly before the Beta sequence, requiring a total span of at least 130 columns. Since the grids only have $T = 100$ columns, this forms a direct contradiction for row 1.

In Example 2, `LOAD 1` is triggered. The Alpha grid requires four rows, each containing a block of 50 contiguous 1s. By Constraint 4, the column sum cannot exceed 1, meaning these blocks cannot share any columns. The first block must occupy 50 columns, the second must occupy another 50 distinct columns, and so on. Accommodating all four blocks without violating the column sparsity constraint would require 200 distinct columns. Since $T = 150$, this is mathematically impossible.

<RATIONALE>
The 1D spatial packing framing was removed and replaced with a 2D binary grid configuration problem. Continuous interval constraints were mapped to discrete row contiguity and column sparsity constraints, forcing models to deduce global capacity limits via matrix double-counting rather than directly pattern-matching the "sum of lengths > track" heuristic.
</RATIONALE>
