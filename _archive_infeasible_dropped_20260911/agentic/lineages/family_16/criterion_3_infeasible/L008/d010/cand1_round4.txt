<STATEMENT>
# Problem C — Kinematic Constraints Validation

Time limit: 2 s   Memory limit: 256 MB

## Description

A physics engine must validate a 1D kinematic configuration of $j$ mechanical linkages within a bounding domain of length $T$. The spatial domain extends continuously from coordinate $x=0$ to $x=T$.

Each linkage $k \in \{1 \dots j\}$ is characterized by two parameters: a primary scalar $p1_k$ and a secondary scalar $p2_k$.

A configuration is defined by assigning to each linkage $k$ two continuous, piecewise-linear potential functions $V_{k,1}(x)$ and $V_{k,2}(x)$ over the domain $x \in [0, T]$. A configuration is physically realizable if and only if it satisfies all of the following constraints:

1. **Primary Potential:** For all $k \in \{1 \dots j\}$, $V_{k,1}(0) = 0$ and $V_{k,1}(T) = p1_k$. The derivative $V'_{k,1}(x)$ must equal $1$ on exactly one strictly open interval $I_{k,1} \subset (0, T)$, and equal $0$ everywhere else in $[0, T]$ (except at the boundary points of $I_{k,1}$ where the derivative is undefined).
2. **Secondary Potential:** For all $k \in \{1 \dots j\}$, $V_{k,2}(0) = 0$ and $V_{k,2}(T) = p2_k$. The derivative $V'_{k,2}(x)$ must equal $1$ on exactly one strictly open interval $I_{k,2} \subset (0, T)$, and equal $0$ everywhere else in $[0, T]$ (except at the boundary points of $I_{k,2}$ where the derivative is undefined).
3. **Potential Sequence:** For all $k \in \{1 \dots j\}$ and for all $x \in [0, T]$, if $V_{k,1}(x) < p1_k$, then it must be strictly true that $V_{k,2}(x) = 0$.
4. **Primary Interference:** For any two distinct linkages $u$ and $v$ in $\{1 \dots j\}$, their primary derivatives must be orthogonal where defined: $V'_{u,1}(x) \cdot V'_{v,1}(x) = 0$ for all $x \in (0, T)$ excluding boundary points.
5. **Secondary Interference:** For any two distinct linkages $u$ and $v$ in $\{1 \dots j\}$, their secondary derivatives must be orthogonal where defined: $V'_{u,2}(x) \cdot V'_{v,2}(x) = 0$ for all $x \in (0, T)$ excluding boundary points.

The engine has determined that no physically realizable configuration exists for the current batch of linkages. You must output a diagnostic code identifying the isolated source of this impossibility. 

The input data is guaranteed to trigger exactly one of the following isolated contradictions. Print the corresponding code:
- `JOB i` (where $i$ is the 1-based index of the linkage): It is mathematically impossible to construct $V_{i,1}$ and $V_{i,2}$ to simultaneously satisfy Constraints 1, 2, and 3 (assuming all other linkages are ignored and Constraints 4 and 5 are lifted). If multiple linkages satisfy this, you may output the code for any such linkage.
- `LOAD 1`: It is mathematically impossible to construct $V_{k,1}$ for all $j$ linkages to simultaneously satisfy Constraints 1 and 4 (assuming Constraints 2, 3, and 5 are lifted).
- `LOAD 2`: It is mathematically impossible to construct $V_{k,2}$ for all $j$ linkages to simultaneously satisfy Constraints 2 and 5 (assuming Constraints 1, 3, and 4 are lifted).

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p1$ and $p2$ ($1 \le p1, p2 \le 1000000$): the parameters for the primary and secondary potentials for that linkage.

## Output

Print a single line containing the valid diagnostic code (`JOB i`, `LOAD 1`, or `LOAD 2`).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is triggered because linkage 1 requires $V_{1,1}(100) = 70$ and $V_{1,2}(100) = 60$. Constraint 1 dictates that $V'_{1,1}(x) = 1$ on an interval of length 70, meaning $V_{1,1}(x)$ reaches 70 only at some coordinate $x \ge 70$. Constraint 3 requires $V_{1,2}(x) = 0$ for all $x$ where $V_{1,1}(x) < 70$, forcing the interval where $V'_{1,2}(x) = 1$ to start no earlier than $x = 70$. To accumulate a total change of 60 for $V_{1,2}$, the domain must extend to at least $70 + 60 = 130$. Since $T = 100$, it is mathematically impossible to satisfy Constraints 1, 2, and 3 for linkage 1.

In Example 2, `LOAD 1` is triggered because there are four primary potentials, each requiring an interval of length 50 where its derivative is 1. Constraint 4 requires that for any two distinct linkages, their primary derivatives are never simultaneously 1. This means the intervals must be completely disjoint, requiring a total domain length of at least $4 \times 50 = 200$. Since Constraint 1 restricts all potentials to a domain of length $T = 150$, it is mathematically impossible to satisfy Constraints 1 and 4 simultaneously.
</STATEMENT>
<RATIONALE>
The rewrite replaces 1D geometric packing concepts ("positioned entirely to the left", "no overlap") with equivalent conditions on continuous, piecewise-linear potential functions and their derivatives. Constraints on disjointness are expressed as orthogonal derivatives, and sequential ordering is enforced via a conditional threshold on the primary potential. This forces models to mathematically deduce that the integrals of these derivatives impose the same hidden capacity bounds, defeating simple pattern matching.
</RATIONALE>
