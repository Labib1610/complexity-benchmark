# Problem C — Telemetry Window: Diagnostic Code

Time limit: 2 s   Memory limit: 256 MB

## Description

An orbital satellite is scheduled to execute **j** observation jobs before it passes out of communication range in exactly **T** milliseconds.

Each observation job requires two sequential phases:
1. First, the targeting gimbal (Subsystem 1) must orient to the correct coordinates. This takes **p1** milliseconds.
2. Afterward, the imaging sensor (Subsystem 2) must expose the frame. This takes **p2** milliseconds.

The satellite's hardware constraints dictate that:
- The targeting gimbal can only orient for one job at a time.
- The imaging sensor can only expose for one job at a time.
- For any given job, the imaging sensor cannot begin its exposure until the gimbal has completely finished orienting for that specific job.

Mission control has determined that completing all **j** jobs within the **T** millisecond window is impossible, regardless of the execution order. Your task is not to attempt a schedule, but to output a diagnostic code providing a standalone proof of why the timeline is impossible.

A valid diagnostic code demonstrates impossibility using a single, isolated constraint:
- `JOB i` : Certifies that observation job **i** (1-based) is impossible to complete within the communication window, even if it were the only job scheduled.
- `LOAD c` : Certifies that Subsystem **c** (where **c** is 1 or 2) requires an aggregate duration of active operation that strictly exceeds the communication window, even if the other subsystem's requirements were completely ignored.

It is guaranteed that for the provided data, exactly one such diagnostic code is valid. Print that code.

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the orientation duration on Subsystem 1 and the exposure duration on Subsystem 2 for that observation job.

## Output

Print a single line containing the applicable diagnostic code: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, `JOB 1` is the correct diagnostic code because job 1 alone cannot be completed within 100 milliseconds due to the sequential nature of its phases. 

In Example 2, `LOAD 1` is the correct diagnostic code because Subsystem 1 alone requires 200 milliseconds of active operation, which strictly exceeds the 150-millisecond window.
