We can check the two possible diagnostic codes:

1. **JOB i** — if any single job has `p1 + p2 > T`, that job alone cannot finish.
2. **LOAD c** — if the sum of all `p1` > T, then subsystem 1 is overloaded; if the sum of all `p2` > T, then subsystem 2 is overloaded.

Since the problem guarantees exactly one valid assertion, we can check in that order.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    
    total_p1 = 0
    total_p2 = 0
    
    idx = 2
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        total_p1 += p1
        total_p2 += p2
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
    
    if total_p1 > T:
        print("LOAD 1")
    elif total_p2 > T:
        print("LOAD 2")

if __name__ == "__main__":
    main()
```
