# Problem C — Inconsistent Real System

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of algebraic inequalities over the real numbers. For a given set of parameters, the system seeks real variables $X_i, Y_i, U_i, V_i$ for each $i \in \{1 \dots j\}$ satisfying the following constraints:

For all $i \in \{1 \dots j\}$:
1. $Y_i = X_i \cdot 2^{p_{i,1}}$
2. $V_i = U_i \cdot 2^{p_{i,2}}$
3. $X_i \ge 1$
4. $U_i \ge 1$
5. $Y_i \cdot V_i \le 2^T$

For all pairs $i, k \in \{1 \dots j\}$ with $i \neq k$:
6. $Y_i Y_k + X_i X_k \le Y_i X_i + Y_k X_k$
7. $V_i V_k + U_i U_k \le V_i U_i + V_k U_k$

In this specific problem, it is guaranteed that **no real solution exists** for the given inputs. Your task is to output a simple proof (a certificate) demonstrating which structural obstruction makes the system unsolvable.

It is guaranteed that the inconsistency in each test case is caused by exactly one of the following two isolated subsystems having no real solution. You must determine which subsystem is inconsistent and output the corresponding certificate. If the description applies to multiple valid certificates, any single one is acceptable.

- **Local Contradiction:** For a single index $i$, the subsystem consisting only of constraints 1, 2, 3, 4, and 5 for that specific $i$ has no real solution.
  Output format: `JOB i` (where $i$ is the 1-based index of the parameter pair).

- **Global Contradiction:** For a single index $c$ ($c \in \{1, 2\}$), the subsystem formed by the variables $X_1, Y_1, \dots, X_j, Y_j$ (if $c=1$) or $U_1, V_1, \dots, U_j, V_j$ (if $c=2$) subject to the following constraints has no real solution:
  - Constraint 1 (if $c=1$) or Constraint 2 (if $c=2$) applied to all $i \in \{1 \dots j\}$.
  - Constraint 3 (if $c=1$) or Constraint 4 (if $c=2$) applied to all $i \in \{1 \dots j\}$.
  - Constraint 6 (if $c=1$) or Constraint 7 (if $c=2$) applied to all pairs $i \neq k$.
  - The additional bounding constraint $Y_i \le 2^T$ (if $c=1$) or $V_i \le 2^T$ (if $c=2$) for all $i \in \{1 \dots j\}$.
  Output format: `LOAD c` (where $c$ is exactly 1 or 2).

## Input

The first line specifies two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
The subsequent $j$ lines each provide exactly 2 integers $p1$ and $p2$ ($1 \le p1, p2 \le 1000000$), representing the parameters $p_{i,1}$ and $p_{i,2}$ respectively for the $i$-th index.

## Output

Output exactly one line containing a valid certificate from the applicable category: either `JOB i` or `LOAD c`. If printing `LOAD c`, then $c$ must be exactly 1 or 2.

## Note

In Example 1, for index 1, the local subsystem variables $X_1, Y_1, U_1, V_1$ must satisfy:
1. $Y_1 = X_1 \cdot 2^{70}$
2. $V_1 = U_1 \cdot 2^{60}$
3. $X_1 \ge 1$
4. $U_1 \ge 1$
5. $Y_1 \cdot V_1 \le 2^{100}$

From constraints 1 and 3, $Y_1 \ge 2^{70}$. From constraints 2 and 4, $V_1 \ge 2^{60}$. Multiplying these gives $Y_1 \cdot V_1 \ge 2^{130}$. However, constraint 5 requires $Y_1 \cdot V_1 \le 2^{100}$. Since $2^{130} > 2^{100}$, these constraints are mutually inconsistent. Thus `JOB 1` is a valid certificate.

In Example 2, for $c=1$, the global subsystem requires finding four pairs $(X_i, Y_i)$ for $i \in \{1, 2, 3, 4\}$ such that:
- $Y_i = X_i \cdot 2^{50}$
- $X_i \ge 1$
- $Y_i Y_k + X_i X_k \le Y_i X_i + Y_k X_k$ for all $i \neq k$
- $Y_i \le 2^{150}$

By analyzing the pairwise constraints mathematically across all four pairs simultaneously, it can be proven that they force bounds which contradict the requirement that all $Y_i \le 2^{150}$. The subsystem has no real solution. Thus `LOAD 1` is a valid certificate.
