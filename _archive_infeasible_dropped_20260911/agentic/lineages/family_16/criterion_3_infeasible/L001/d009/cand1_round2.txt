# Problem C — Production Deadline

Time limit: 2 s   Memory limit: 256 MB

## Description
You are analyzing a two-stage manufacturing pipeline. A factory must process a batch of $j$ items. Each item must first be processed at the Preparation Station, and immediately afterward at the Finishing Station. 

Both stations process items strictly sequentially (one item at a time). However, the pipeline allows simultaneous operation across stations: the Finishing Station can process item $i$ while the Preparation Station is already processing item $i+1$. 

The factory has a strict deadline of $T$ minutes to complete the entire batch of $j$ items from start to finish. For this specific set of orders, it is guaranteed that **no valid schedule exists** to meet the deadline, regardless of the order in which the items are processed.

Your task is to identify the structural obstruction that makes the deadline impossible. You must output a simple certificate demonstrating the impossibility. It is guaranteed that exactly one of the following three elementary bounds strictly exceeds $T$:

- **Single-Item Bottleneck:** The sum of the Preparation time and Finishing time for a single item $i$ strictly exceeds $T$. 
  Output format: `JOB i` (where $i$ is the 1-based index of the item).

- **Preparation Workload:** The sum of the Preparation times for all $j$ items strictly exceeds $T$. 
  Output format: `LOAD 1`

- **Finishing Workload:** The sum of the Finishing times for all $j$ items strictly exceeds $T$. 
  Output format: `LOAD 2`

## Input
The first line specifies two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
The subsequent $j$ lines each provide exactly 2 integers. For the $i$-th line, the first integer $p_{i,1}$ is the time required at the Preparation Station, and the second integer $p_{i,2}$ is the time required at the Finishing Station ($1 \le p_{i,1}, p_{i,2} \le 1000000$).

## Output
Output exactly one line containing a valid certificate from the applicable category: either `JOB i` or `LOAD c`. If printing `LOAD c`, then $c$ must be exactly 1 or 2.

## Examples

### Example 1
**Input**
```
3 100
70 60
2 2
3 4
```
**Output**
```
JOB 1
```

### Example 2
**Input**
```
4 150
50 1
50 1
50 1
50 1
```
**Output**
```
LOAD 1
```

## Note
In Example 1, item 1 requires 70 minutes at the Preparation Station and 60 minutes at the Finishing Station. Its total sequential processing time is $70 + 60 = 130$ minutes. Since $130 > 100$, the deadline cannot be met even if this were the only item in the pipeline. Thus `JOB 1` is a valid certificate.

In Example 2, the sum of the Preparation times for all items is $50 + 50 + 50 + 50 = 200$ minutes. Since the Preparation Station processes items sequentially, it requires at least 200 minutes just to complete its stage of the work. Since $200 > 150$, the deadline is impossible. Thus `LOAD 1` is a valid certificate.
