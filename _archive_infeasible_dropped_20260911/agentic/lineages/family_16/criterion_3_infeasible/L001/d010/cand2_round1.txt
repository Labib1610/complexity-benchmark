# Problem C — Inconsistent Real System

Time limit: 2 s   Memory limit: 256 MB

## Description

You are tasked with analyzing a specific system of inequalities over the real numbers. For a given set of input parameters, the system attempts to find real-valued center coordinates $M_{i,1}$ and $M_{i,2}$ for each index $i \in \{1 \dots j\}$ that satisfy the following constraints:

For every $i \in \{1 \dots j\}$:
1. $M_{i,1} \ge \frac{p_{i,1}}{2}$
2. $M_{i,2} \ge \frac{p_{i,2}}{2}$
3. $\left(M_{i,1} + \frac{p_{i,1}}{2}\right) + \left(M_{i,2} + \frac{p_{i,2}}{2}\right) \le T$

For all pairs of distinct indices $i, k \in \{1 \dots j\}$ (where $i \neq k$):
4. $|M_{i,1} - M_{k,1}| \ge \frac{p_{i,1} + p_{k,1}}{2}$
5. $|M_{i,2} - M_{k,2}| \ge \frac{p_{i,2} + p_{k,2}}{2}$

For the provided test cases, it is mathematically guaranteed that **no real solution exists**. Your objective is to output a simple proof (a certificate) identifying the structural obstruction that renders the system unsolvable.

The inconsistency in each test case is guaranteed to arise because exactly one of the two following isolated subsystems has no real solution. You must determine which subsystem is inconsistent and output its corresponding certificate. If multiple valid certificates exist within the applicable category, any single correct one is accepted.

- **Local Contradiction:** There is a single index **i** where the subsystem restricted solely to constraints 1, 2, and 3 for that specific $i$ admits no real solution.
  Output format: `JOB i` (where **i** is the 1-based index of the parameters).

- **Global Contradiction:** There is a single index **c** (**c** $\in \{1, 2\}$) where the subsystem formed by the center coordinates $M_{1,c}, \dots, M_{j,c}$ under the following constraints admits no real solution:
  - Constraint 1 (if $c=1$) or Constraint 2 (if $c=2$) applied to all $i \in \{1 \dots j\}$.
  - Constraint 4 (if $c=1$) or Constraint 5 (if $c=2$) applied to all pairs $i \neq k$.
  - The additional bounding constraint $M_{i,c} + \frac{p_{i,c}}{2} \le T$ for all $i \in \{1 \dots j\}$.
  Output format: `LOAD c` (where **c** is exactly 1 or 2).

## Input

The first line contains two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
Each of the following **j** lines contains exactly **2** integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the parameters $p_{i,1}$ and $p_{i,2}$ for the $i$-th index.

## Output

Print exactly one line containing a valid certificate from the applicable category: either `JOB i` or `LOAD c`. When printing `LOAD c`, the value of **c** must be exactly 1 or 2.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for index 1, the local subsystem is:
1. $M_{1,1} \ge \frac{70}{2} = 35$
2. $M_{1,2} \ge \frac{60}{2} = 30$
3. $(M_{1,1} + 35) + (M_{1,2} + 30) \le 100$

By substitution, $(M_{1,1} + 35) + (M_{1,2} + 30) \ge (35 + 35) + (30 + 30) = 70 + 60 = 130$. This contradicts constraint 3, which requires the sum to be $\le 100$. Thus `JOB 1` is a valid certificate.

In Example 2, for $c=1$, the global subsystem requires finding four center coordinates $M_{i,1}$ for $i \in \{1, 2, 3, 4\}$ such that:
- $M_{i,1} \ge 25$
- $|M_{i,1} - M_{k,1}| \ge 50$ for all $i \neq k$
- $M_{i,1} + 25 \le 150$

The condition $|M_{i,1} - M_{k,1}| \ge 50$ dictates that the distance between any two center coordinates is at least 50. This implies that the 1D segments $[M_{i,1} - 25, M_{i,1} + 25]$ of length 50 do not overlap in their interiors. Since constraint 1 implies the left endpoint of each segment is $M_{i,1} - 25 \ge 0$, there must exist some permutation of the indices—let us call them $a, b, c, d$—such that the segments are ordered from left to right. 
The right endpoint of the fourth segment must be at least $0 + 50 + 50 + 50 + 50 = 200$. However, the bounding constraint requires the right endpoint $M_{i,1} + 25 \le 150$ for all $i$. Since $200 > 150$, the subsystem has no real solution. Thus `LOAD 1` is a valid certificate.
