We can solve this by checking two possible contradictions:

1. **Local contradiction**: For each index `i`, if `p1 + p2 > T`, then the product `V1 * V2` would need to be at least `2^(p1+p2)`, but constraint 5 limits it to `2^T`. So if `p1 + p2 > T`, output `JOB i`.

2. **Global contradiction**: For each column `c` (1 or 2), sum all `p_i,c`. If the sum exceeds `T`, then the disjoint intervals cannot fit inside `[1, 2^T]` because the total log-length needed exceeds `T`. Output `LOAD c`.

We check local first, then global.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    p1_list = []
    p2_list = []
    idx = 2
    for i in range(j):
        p1 = int(data[idx])
        p2 = int(data[idx+1])
        idx += 2
        p1_list.append(p1)
        p2_list.append(p2)
        if p1 + p2 > T:
            print(f"JOB {i+1}")
            return

    sum1 = sum(p1_list)
    sum2 = sum(p2_list)
    if sum1 > T:
        print("LOAD 1")
    elif sum2 > T:
        print("LOAD 2")

if __name__ == "__main__":
    main()
```
