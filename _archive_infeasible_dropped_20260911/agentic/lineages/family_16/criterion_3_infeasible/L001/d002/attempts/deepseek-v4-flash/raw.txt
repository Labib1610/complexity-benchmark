We can solve this by checking both conditions directly:

- First, check if any order has `p1 + p2 > T`. If so, output `JOB i`.
- Otherwise, check if the sum of all `p1` values exceeds `T`; if so, output `LOAD 1`.
- Then check if the sum of all `p2` values exceeds `T`; if so, output `LOAD 2`.

Since the problem guarantees exactly one category applies, we can check in this order.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    
    total1 = 0
    total2 = 0
    
    idx = 2
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        
        total1 += p1
        total2 += p2
    
    if total1 > T:
        print("LOAD 1")
        return
    
    if total2 > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
