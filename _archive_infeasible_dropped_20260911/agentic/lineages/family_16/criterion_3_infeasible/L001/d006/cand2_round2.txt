# Problem C — Structural Inconsistency Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a theoretical system with **j** discrete elements. Each element is associated with exactly **2** characteristic values, $v_{i,1}$ and $v_{i,2}$. The system is bounded by a global parameter **T**.

A globally consistent state assigns four real numbers $(x_{i,1}, y_{i,1}, x_{i,2}, y_{i,2})$ to each element $i \in \{1 \dots j\}$ such that:
1. **Span:** $y_{i,1} - x_{i,1} = v_{i,1}$ and $y_{i,2} - x_{i,2} = v_{i,2}$ for all $i$.
2. **Chain:** $x_{i,2} \ge y_{i,1}$ for all $i$.
3. **Exclusivity:** For each index $m \in \{1, 2\}$, if $i \neq k$, the open intervals $(x_{i,m}, y_{i,m})$ and $(x_{k,m}, y_{k,m})$ are strictly disjoint.
4. **Boundaries:** $x_{i,1} \ge 0$ and $y_{i,2} \le T$ for all $i$.

In this specific problem, **no globally consistent state exists** for the given inputs. Your task is to output a simple proof (a certificate) demonstrating why the system is structurally impossible to satisfy.

It is guaranteed that the impossibility in each test case is caused by exactly one of the following two reasons. You must determine which reason applies and output the corresponding certificate. If the applicable reason offers multiple valid certificates, any single one is acceptable.

- **Local Element Contradiction:** For a single element **i**, the subset of constraints 1, 2, and 4 (completely ignoring constraint 3) forms an inconsistent system of inequalities. That is, there exist no four real numbers $(x_{i,1}, y_{i,1}, x_{i,2}, y_{i,2})$ that can simultaneously satisfy:
  - $y_{i,1} - x_{i,1} = v_{i,1}$
  - $y_{i,2} - x_{i,2} = v_{i,2}$
  - $x_{i,2} \ge y_{i,1}$
  - $x_{i,1} \ge 0$
  - $y_{i,2} \le T$
  Output format: `JOB i` (where **i** is the 1-based index of the element).

- **Aggregate Span Contradiction:** For a single index **c** (**c** $\in \{1, 2\}$), the subset of constraints 1, 3, and a relaxed boundary condition (completely ignoring constraint 2) forms an inconsistent system. Specifically, there is no way to choose **j** pairs of real numbers $(x_{i,c}, y_{i,c})$ for all $i \in \{1 \dots j\}$ that simultaneously satisfy:
  - $y_{i,c} - x_{i,c} = v_{i,c}$ for all $i$
  - $(x_{i,c}, y_{i,c}) \cap (x_{k,c}, y_{k,c}) = \emptyset$ for all $i \neq k$
  - $x_{i,c} \ge 0$ and $y_{i,c} \le T$ for all $i$
  Output format: `LOAD c` (where **c** is exactly 1 or 2).

## Input

The first line specifies two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
The subsequent **j** lines each provide exactly **2** integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the characteristic values $v_{i,1}$ and $v_{i,2}$ for that element.

## Output

Output exactly one line containing a valid certificate from the applicable category: either `JOB i` or `LOAD c`. If printing `LOAD c`, then **c** must be exactly 1 or 2.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for the first element, the span constraints dictate interval lengths of 70 and 60. The chain constraint dictates their relative order. It is mathematically impossible to assign coordinates that satisfy these relations while strictly remaining within the boundaries $x_{1,1} \ge 0$ and $y_{1,2} \le 100$. Thus `JOB 1` is a valid certificate.
In Example 2, for index 1, the exclusivity constraint demands 4 strictly disjoint intervals, each of length 50. It is impossible to pack these non-overlapping intervals into the valid domain $[0, 150]$. Thus `LOAD 1` is a valid certificate.
</STATEMENT>
<RATIONALE>
The rewrite replaces the scheduling domain (jobs, machines, processing times) with a formal mathematical system of inequalities and interval packing. This forces models to algebraically deduce that the first system is inconsistent if and only if $v_{i,1} + v_{i,2} > T$, and the second if and only if $\sum v_{i,c} > T$, defeating models that rely on text pattern matching to directly apply the sum heuristics.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical conditions for inconsistency are logically identical to the original scheduling relaxations: the first system lacks a solution exactly when $v_{i,1} + v_{i,2} > T$, and the second lacks a solution exactly when the sum of lengths $\sum v_{i,c} > T$, perfectly preserving all answers.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class remains identical $O(N)$ because the problem still requires only a single sequential pass to evaluate the sum of the two values for each element and the aggregate sum for each index.
</PRESERVED_CLASS>
<RISK>
Models might struggle to parse the formal mathematical notation or mistakenly attempt to write code that invokes an LP solver instead of deducing the $O(1)$ additive bounds, though the text is mathematically unambiguous.
</RISK>
