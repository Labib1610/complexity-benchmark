<STATEMENT>
# Problem C — Inconsistent System

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of inequalities over $4j$ real variables. For each index $i \in \{1 \dots j\}$, there are four variables $a_i, b_i, c_i, d_i$. 
You are given a global parameter $T$ and, for each $i$, two positive constants $X_i$ and $Y_i$.

A complete valid assignment of the $4j$ variables must satisfy all of the following conditions:
1. **Span 1:** For all $i$, $b_i - a_i = X_i$.
2. **Span 2:** For all $i$, $d_i - c_i = Y_i$.
3. **Ordering:** For all $i$, $c_i \ge b_i$.
4. **Boundaries:** For all $i$, $a_i \ge 0$ and $d_i \le T$.
5. **Separation 1:** For all $i \neq k$, $|(a_i + b_i) - (a_k + b_k)| \ge X_i + X_k$.
6. **Separation 2:** For all $i \neq k$, $|(c_i + d_i) - (c_k + d_k)| \ge Y_i + Y_k$.

In this specific problem, it is guaranteed that **no valid assignment exists** that can satisfy all six conditions simultaneously for the given inputs. Your task is to output a simple proof (a certificate) demonstrating the exact structural reason why the system is impossible to satisfy.

It is guaranteed that the impossibility in each test case is caused by exactly one of the following two reasons. You must determine which reason applies and output the corresponding certificate. If the applicable reason offers multiple valid certificates, any single one is acceptable.

- **Local Contradiction:** For a single index **i**, the subsystem consisting *only* of conditions 1, 2, 3, and 4 (ignoring all other variables and conditions) has no real solution.
  Output format: `JOB i` (where **i** is the 1-based index).

- **Global Contradiction:** For a single group **c** (**c** $\in \{1, 2\}$), the subsystem for that group cannot be satisfied.
  - If **c** = 1, the subsystem consists of condition 1 for all $i$, condition 5 for all pairs $i \neq k$, and the relaxed boundaries $a_i \ge 0$ and $b_i \le T$ for all $i$.
  - If **c** = 2, the subsystem consists of condition 2 for all $i$, condition 6 for all pairs $i \neq k$, and the relaxed boundaries $c_i \ge 0$ and $d_i \le T$ for all $i$.
  Output format: `LOAD c` (where **c** is exactly 1 or 2).

## Input

The first line specifies two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
The subsequent **j** lines each provide exactly **2** integers **X** and **Y** (1 ≤ X, Y ≤ 1000000), representing the constants $X_i$ and $Y_i$ respectively for the $i$-th index.

## Output

Output exactly one line containing a valid certificate from the applicable category: either `JOB i` or `LOAD c`. If printing `LOAD c`, then **c** must be exactly 1 or 2.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for index 1, $X_1 = 70$ and $Y_1 = 60$. Conditions 1, 2, and 3 require $d_1 - a_1 \ge 130$. However, condition 4 requires $a_1 \ge 0$ and $d_1 \le 100$. This subsystem has no valid real solution, so `JOB 1` is a valid certificate.

In Example 2, for group 1, we must assign $a_i, b_i$ for 4 indices such that condition 1 ($b_i - a_i = 50$) and condition 5 ($|(a_i + b_i) - (a_k + b_k)| \ge 100$) hold for all pairs. However, the relaxed boundaries restrict all $a_i \ge 0$ and $b_i \le 150$. It is mathematically impossible to find four pairs of real numbers satisfying these mutual separations within this bounded range. Thus the subsystem for group 1 has no solution, making `LOAD 1` a valid certificate.
</STATEMENT>
<RATIONALE>
The problem was completely reframed from a scheduling domain to an abstract system of algebraic inequalities. The non-overlap constraints were mathematically translated into equivalent absolute value inequalities on the sum of the endpoints. This eliminates the semantic affordances of "jobs", "machines", and "durations", forcing the model to genuinely deduce that the absolute value conditions imply disjoint intervals before it can realize the impossibility condition is simply an additive sum.
</RATIONALE>
<PRESERVED_ANSWER>
The absolute value condition `|(a_i + b_i) - (a_k + b_k)| >= X_i + X_k` given `b_i - a_i = X_i` is mathematically identical to the intervals `[a_i, b_i]` and `[a_k, b_k]` being disjoint, preserving the exact same structural requirements and therefore the exact same certificate conditions (`X_i + Y_i > T` and `sum(X) > T`).
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks to identify which of the disjoint interval packing bounds or local span bounds is violated, which is computed with the exact same linear scan and sum operations, maintaining its position in the same complexity class.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the absolute value condition as standard distance rather than interval separation, but the wording is mathematically unambiguous and formally defines the precise subsystem to evaluate.
</RISK>
