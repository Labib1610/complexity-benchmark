**Solution Explanation**

For each index `i` we have to choose four real numbers  

```
x_i , y_i = x_i + p1_i
u_i , v_i = u_i + p2_i
```

with the global bounds `x_i ≥ 0 , v_i ≤ T` and the chain `u_i ≥ y_i`.

--------------------------------------------------------------------

### 1.   When does a *local* contradiction happen ?

From the definitions

```
v_i = u_i + p2_i ≥ y_i + p2_i = x_i + p1_i + p2_i .
```

Because of the bound `x_i ≥ 0` we obtain the *minimal possible* value of `v_i`

```
v_i ≥ p1_i + p2_i .
```

If `p1_i + p2_i > T` then even the smallest admissible `v_i` is larger than the
allowed upper bound `T`.  
Thus no assignment for this single index exists – a **JOB** certificate.

--------------------------------------------------------------------

### 2.   When does a *global* contradiction happen ?

Assume the local test succeeded for every index, i.e. `p1_i + p2_i ≤ T` for all `i`.

Now ignore the chain `u_i ≥ y_i`.  
Consider only the first dimension (`x , y`).  
Each index defines an interval `[x_i , y_i]` of length `p1_i`.  
Condition 4 says that any two intervals must be *disjoint* (they may touch,
the order does not matter).  
Together with the bounds `x_i ≥ 0 , y_i ≤ T` this is exactly the classic
“place non‑overlapping intervals of given lengths into a segment of length `T`”.

The necessary and sufficient condition is

```
sum_i p1_i ≤ T .
```

If it is violated, the first dimension is impossible → **LOAD 1**.

The same reasoning for the second dimension (`u , v`) gives the condition

```
sum_i p2_i ≤ T .
```

If it fails, we output **LOAD 2**.

The statement guarantees that exactly one of the three possibilities occurs.

--------------------------------------------------------------------

### 3.   Algorithm
```
read j , T
for i = 1 .. j
        read p1 , p2
        if p1 + p2 > T and no JOB printed yet:
                answer = "JOB i"
        accumulate sum1 += p1 , sum2 += p2
if answer already set → print it
else if sum1 > T → print "LOAD 1"
else               → print "LOAD 2"
```
All operations are O(j) time, O(1) extra memory.

--------------------------------------------------------------------

### 4.   Correctness Proof  

We prove that the algorithm always prints a valid certificate.

---

#### Lemma 1  
If for some index `i` we have `p1_i + p2_i > T`, then the system is locally
unsatisfiable for this `i`.

*Proof.*  
From the derivation in section&nbsp;1, any feasible assignment must satisfy
`v_i ≥ p1_i + p2_i`. Because `p1_i + p2_i > T`, this contradicts the global bound
`v_i ≤ T`. ∎



#### Lemma 2  
If for every index `i` we have `p1_i + p2_i ≤ T` and `∑ p1_i > T`,
then the first dimension (`x , y`) is globally unsatisfiable.

*Proof.*  
All intervals `[x_i , y_i]` have length `p1_i` and must be pairwise disjoint
(condition 4). Their total length is `∑ p1_i`. Any placement of disjoint intervals
inside `[0 , T]` cannot exceed the length of the container, therefore we need
`∑ p1_i ≤ T`. The opposite inequality makes a placement impossible. ∎



#### Lemma 3  
If for every index `i` we have `p1_i + p2_i ≤ T` and `∑ p2_i > T`,
then the second dimension (`u , v`) is globally unsatisfiable.

*Proof.* Identical to Lemma&nbsp;2 with `p2`. ∎



#### Lemma 4  
If none of the three conditions of Lemma 1–3 holds, then a feasible assignment
exists.

*Proof.*  
All `p1_i + p2_i ≤ T`. Moreover `∑ p1_i ≤ T` and `∑ p2_i ≤ T`.  
Place the `x‑y` intervals consecutively starting at `0`; this respects
`x_i ≥ 0 , y_i ≤ T` and condition 4.  
Place the `u‑v` intervals consecutively starting at `0` as well; this respects
`u_i ≥ 0 , v_i ≤ T` and condition 5.  
Because for each `i` we have `p1_i + p2_i ≤ T`, we can choose the same start
point for both dimensions, e.g. set `x_i = u_i`. Then `u_i ≥ y_i` holds
(because `y_i = x_i + p1_i ≤ x_i + (T - p2_i) = u_i + (T - p2_i) ≤ u_i`),
so condition 3 is also satisfied. Hence a full solution exists. ∎



#### Theorem  
The algorithm outputs

* `JOB i` for some `i` **iff** the system is locally impossible for that `i`;
* `LOAD 1` **iff** the system is globally impossible in the first dimension;
* `LOAD 2` **iff** the system is globally impossible in the second dimension.

*Proof.*  
- If the algorithm prints `JOB i`, it found `p1_i + p2_i > T`. By Lemma 1 this
  is a valid local contradiction. Conversely, if a local contradiction exists,
  Lemma 1 guarantees such an `i`, and the algorithm will encounter it while
  scanning the input and output `JOB i`.

- If no `JOB` is printed, all `p1_i + p2_i ≤ T`.  
  The algorithm then checks the sums.  
  *If* `∑ p1_i > T`, it prints `LOAD 1`. By Lemma 2 this is a correct global
  contradiction. Conversely, if a global contradiction of type 1 holds,
  Lemma 2 gives `∑ p1_i > T`, so the algorithm will output `LOAD 1`.  
  The same argument with Lemma 3 handles `LOAD 2`.

Thus the output is always a correct certificate, and exactly one of the three
cases occurs by the problem guarantee. ∎

### 5.   Complexity Analysis

Reading the input and the single pass over the `j` pairs:

- Time: `O(j)` ( ≤ 2·10⁵ )
- Memory: `O(1)` besides the input buffer.

Both limits satisfy the constraints.

--------------------------------------------------------------------

### 6.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    j = int(next(it))
    T = int(next(it))

    sum1 = 0
    sum2 = 0
    job_idx = None

    for idx in range(1, j + 1):
        p1 = int(next(it))
        p2 = int(next(it))
        if job_idx is None and p1 + p2 > T:
            job_idx = idx
        sum1 += p1
        sum2 += p2

    out = []
    if job_idx is not None:
        out.append(f"JOB {job_idx}")
    elif sum1 > T:
        out.append("LOAD 1")
    else:
        out.append("LOAD 2")

    sys.stdout.write(out[0])

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above.
