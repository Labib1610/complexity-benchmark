We can solve this by checking both possible contradiction types.

First, for a **local contradiction**, we check each index `i`:

- From `y_i - x_i = p1` and `v_i - u_i = p2`, and `u_i >= y_i`, we get:
  \[
  v_i = u_i + p2 \ge y_i + p2 = x_i + p1 + p2
  \]
- Since `x_i >= 0`, we have `v_i >= p1 + p2`.
- If `p1 + p2 > T`, then `v_i > T` is impossible, so we have a local contradiction.

If no local contradiction exists, we check for a **global contradiction**:

For dimension 1:
- We have intervals `[x_i, y_i)` with `y_i - x_i = p1_i`, all `x_i >= 0`, all `y_i <= T`, and they must be non-overlapping.
- The total length of all intervals is `sum(p1)`.  
- To fit them all in `[0, T]` without overlap, we need `sum(p1) <= T`.
- If `sum(p1) > T`, then `LOAD 1`.

For dimension 2:
- Intervals `[u_i, v_i)` with `v_i - u_i = p2_i`, all `u_i >= 0`, all `v_i <= T`, non-overlapping.
- Similarly, if `sum(p2) > T`, then `LOAD 2`.

We check local first, then global.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    p1 = []
    p2 = []
    idx = 2
    for _ in range(j):
        p1.append(int(data[idx]))
        p2.append(int(data[idx+1]))
        idx += 2

    # Check local contradiction
    for i in range(j):
        if p1[i] + p2[i] > T:
            print(f"JOB {i+1}")
            return

    # Check global contradiction for dimension 1
    if sum(p1) > T:
        print("LOAD 1")
        return

    # Check global contradiction for dimension 2
    if sum(p2) > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
