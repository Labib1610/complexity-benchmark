<STATEMENT>
# Problem C — Inconsistent Systems of Inequalities

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of inequalities over $4N$ real variables: $x_{i,1}, y_{i,1}, x_{i,2}, y_{i,2}$ for $i \in \{1 \dots N\}$.
You are provided with a bounding constant $K$ and a set of difference constants $A_i, B_i$ for each index $i$.

The full system is defined by the following four rules:
(R1) For all $i \in \{1 \dots N\}$, $y_{i,1} - x_{i,1} = A_i$ and $y_{i,2} - x_{i,2} = B_i$.
(R2) For all $i \in \{1 \dots N\}$, $x_{i,2} \ge y_{i,1}$.
(R3) For all $m \in \{1, 2\}$ and all pairs $i \neq k$, either $x_{i,m} \ge y_{k,m}$ or $x_{k,m} \ge y_{i,m}$.
(R4) For all $i \in \{1 \dots N\}$ and $m \in \{1, 2\}$, $0 \le x_{i,m}$ and $y_{i,m} \le K$.

For the given inputs, the complete system of inequalities has no real solution. You must output a certificate identifying a specific inconsistent subsystem. It is guaranteed that the inconsistency is localized, meaning exactly one of the following two types of subsystems is inherently inconsistent. (If multiple subsystems of the applicable type are inconsistent, any single one is acceptable).

- **Type Alpha:** The subsystem for a specific index $i$, consisting only of the constraints from (R1), (R2), and (R4) that involve $i$. (Constraints involving other indices, and all constraints from R3, are ignored).
  Output format: `JOB i` (where **i** is the 1-based index).

- **Type Beta:** The subsystem for a specific value $m \in \{1, 2\}$, consisting only of the constraints from (R1), (R3), and (R4) that involve $m$. (Constraints involving the other value of $m$, and all constraints from R2, are ignored).
  Output format: `LOAD m` (where **m** is exactly 1 or 2).

## Input

The first line specifies two integers **N** and **K** (1 ≤ N ≤ 200000, 1 ≤ K ≤ 1000000000).
The subsequent **N** lines each provide exactly **2** integers $A_i$ and $B_i$ (1 ≤ $A_i, B_i$ ≤ 1000000), representing the difference constants for that index.

## Output

Output exactly one line containing a valid certificate from the applicable category: either `JOB i` or `LOAD m`. If printing `LOAD m`, then **m** must be exactly 1 or 2.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, if we restrict our attention to the Type Alpha subsystem for $i=1$, we must simultaneously satisfy $y_{1,1} - x_{1,1} = 70$, $y_{1,2} - x_{1,2} = 60$, and $x_{1,2} \ge y_{1,1}$ within the bounding domain $[0, 100]$. No such real values exist, so `JOB 1` is a valid certificate.
In Example 2, if we examine the Type Beta subsystem for $m=1$, we must find four pairs of variables $(x_{i,1}, y_{i,1})$ that satisfy the difference constraint of 50 and the mutual ordering constraints of (R3) within the bounding domain $[0, 150]$. This is impossible, making `LOAD 1` a valid certificate.
</STATEMENT>
<RATIONALE>
I removed all scheduling context (jobs, machines, durations, overlaps) and reframed the problem as analyzing an inconsistent system of inequalities over real variables. This forces the model to algebraically deduce the impossibility conditions (sum of differences > K) from the rules, preventing it from relying on semantic pattern-matching to known scheduling shortcuts.
</RATIONALE>
<PRESERVED_ANSWER>
The subsystems are mathematically isomorphic to the original scheduling constraints, so Type Alpha is inconsistent exactly when $A_i + B_i > K$ and Type Beta is inconsistent exactly when the sum of $A_i$ or $B_i$ exceeds $K$, identical to the original conditions.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires identifying which of two simple additive bounds is violated in O(N) time, keeping it in the same feasibility-checking class.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the output format keywords `JOB` and `LOAD` as undefined variables, but the instructions explicitly state they are just the required string formats.
</RISK>
