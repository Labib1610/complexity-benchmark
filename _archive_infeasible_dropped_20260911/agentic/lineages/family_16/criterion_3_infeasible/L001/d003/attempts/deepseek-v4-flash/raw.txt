We need to check two conditions:

1. If any item has `p1 + p2 > T`, output `JOB i` (1-based index).
2. Otherwise, if the sum of all `p1` > T, output `LOAD 1`; if sum of all `p2` > T, output `LOAD 2`.

Since it's guaranteed that exactly one of these conditions holds, we can check in order.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    idx = 2
    sum1 = 0
    sum2 = 0
    for i in range(1, j+1):
        p1 = int(data[idx])
        p2 = int(data[idx+1])
        idx += 2
        sum1 += p1
        sum2 += p2
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
    if sum1 > T:
        print("LOAD 1")
    elif sum2 > T:
        print("LOAD 2")

if __name__ == "__main__":
    main()
```
