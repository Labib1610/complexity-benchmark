# Problem C — Impossibility Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a two-stage manufacturing process that must complete **j** distinct projects. Each project requires uninterrupted work in Stage 1, followed immediately by uninterrupted work in Stage 2. A stage can only handle a single project at any given moment. 

The entire batch of projects is subject to a strict global deadline **T**. All projects must be fully processed through both stages before this time limit expires.

In every test case provided, the deadline **T** is unachievable. You do not need to attempt to schedule the projects. Instead, you must output a short proof—a certificate—demonstrating why the schedule is impossible. 

Exactly one of the following two structural reasons always applies. Print the certificate for the reason that holds. If multiple valid certificates for that reason exist, you may print any one of them:

- **Oversized Project:** A specific project **i** requires a combined processing time across both stages that strictly exceeds the deadline **T**. This project could not finish on time even if it were the only item in the facility.
  Print: `JOB i` (where **i** is the 1-based index of the project).

- **Overloaded Stage:** A specific stage **c** (where **c** is either 1 or 2) is assigned a total sum of work across all **j** projects that strictly exceeds the deadline **T**. This stage could not finish its workload on time even if it ran continuously without waiting.
  Print: `LOAD c` (where **c** is the stage number).

## Input

The first line contains two integers, **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
The following **j** lines each contain two integers, **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the time required for that project in Stage 1 and Stage 2, respectively.

## Output

Print a single line containing the exact valid certificate: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, project 1 requires 70 units of time in Stage 1 and 60 units in Stage 2. Because it must be processed sequentially, its combined processing time is 130, which strictly exceeds the 100 time limit even if it runs alone, so `JOB 1` proves the deadline is impossible. 
In Example 2, no single project exceeds 150 on its own, but Stage 1 must process 200 units of work in total (50 for each of the 4 projects). This total sum of work strictly exceeds the 150 time limit, making it impossible for Stage 1 to finish, so `LOAD 1` is a valid certificate.
