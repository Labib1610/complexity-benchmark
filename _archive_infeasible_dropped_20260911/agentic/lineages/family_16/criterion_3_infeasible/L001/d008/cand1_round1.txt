<STATEMENT>
# Problem C — Impossibility Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of continuous signal density functions. For a given set of parameters, the system requires assigning two Lebesgue-measurable functions, $\phi_i(t)$ and $\psi_i(t)$, for each index $i \in \{1 \dots j\}$. All functions must map from the real numbers $\mathbb{R}$ to the closed interval $[0, 1]$.

The functions must simultaneously satisfy all of the following conditions:

1. **Energy 1:** The total integral $\int_{\mathbb{R}} \phi_i(t) dt$ is exactly $p_{i,1}$.
2. **Energy 2:** The total integral $\int_{\mathbb{R}} \psi_i(t) dt$ is exactly $p_{i,2}$.
3. **Bandwidth Capacity:** For each index $i$, let $R(\phi_i) = \inf \{ M \in \mathbb{R} \mid \int_{M}^{\infty} \phi_i(t) dt = 0 \}$ and $R(\psi_i) = \inf \{ M \in \mathbb{R} \mid \int_{M}^{\infty} \psi_i(t) dt = 0 \}$. The sum $R(\phi_i) + R(\psi_i)$ does not exceed $T$.
4. **Interference 1:** For any $i \neq k$, the pointwise product $\phi_i(t) \cdot \phi_k(t) = 0$ for almost all $t$.
5. **Interference 2:** For any $i \neq k$, the pointwise product $\psi_i(t) \cdot \psi_k(t) = 0$ for almost all $t$.
6. **Causality:** All functions must be zero for negative time. Specifically, $\phi_i(t) = 0$ and $\psi_i(t) = 0$ for almost all $t < 0$.

In this specific problem, **no valid assignment of functions exists** that can satisfy the system for the given inputs. Your task is to output a simple proof (a certificate) demonstrating why the system is structurally impossible to solve.

It is guaranteed that the impossibility in each test case is caused by exactly one of the following two reasons. You must determine which reason applies and output the corresponding certificate. If the applicable reason offers multiple valid certificates, any single one is acceptable.

- **Local Contradiction:** For a single index **i**, there exists no pair of functions $\phi_i$ and $\psi_i$ that satisfy conditions 1, 2, 3, and 6. (In other words, the bandwidth capacity cannot be respected for index $i$, even if conditions 4 and 5 are completely ignored for all functions).
  Output format: `JOB i` (where **i** is the 1-based index of the parameter pair).

- **Global Contradiction:** For a single category **c** (**c** $\in \{1, 2\}$), there exist no valid assignments for the $j$ functions in that category that satisfy the energy, interference, and causality bounds. Specifically, if $c=1$, no set of functions $\phi_1 \dots \phi_j$ satisfy condition 1, condition 4, condition 6, and the bound $R(\phi_i) \le T$ for all $i$. If $c=2$, no set of functions $\psi_1 \dots \psi_j$ satisfy condition 2, condition 5, condition 6, and the bound $R(\psi_i) \le T$ for all $i$. (In other words, the interference requirements force the functions to exceed the threshold $T$, even if condition 3 is completely ignored).
  Output format: `LOAD c` (where **c** is exactly 1 or 2).

## Input

The first line specifies two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
The subsequent **j** lines each provide exactly **2** integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the required energies $p_{i,1}$ and $p_{i,2}$ respectively for the $i$-th index.

## Output

Output exactly one line containing a valid certificate from the applicable category: either `JOB i` or `LOAD c`. If printing `LOAD c`, then **c** must be exactly 1 or 2.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for index 1, condition 1 requires $\phi_1$ to have a total integral of 70. Because $\phi_1(t) \le 1$ everywhere and $\phi_1(t) = 0$ for $t < 0$, the essential supremum of its support, $R(\phi_1)$, must be at least 70. Similarly, condition 2 requires $\psi_1$ to have an integral of 60, meaning $R(\psi_1) \ge 60$. Condition 3 demands $R(\phi_1) + R(\psi_1) \le 100$. However, $70 + 60 = 130 > 100$. Thus `JOB 1` is a valid certificate.

In Example 2, for category 1, the interference condition requires the non-zero domains of the functions $\phi_i$ to be disjoint almost everywhere. Their combined integrals sum to 200. Since all functions are bounded by 1, their collective support must span a measure of at least 200. It is therefore impossible to confine them entirely within $[0, 150]$ (which would be required if $R(\phi_i) \le 150$ and $\phi_i(t) = 0$ for $t < 0$). Thus `LOAD 1` is a valid certificate.
