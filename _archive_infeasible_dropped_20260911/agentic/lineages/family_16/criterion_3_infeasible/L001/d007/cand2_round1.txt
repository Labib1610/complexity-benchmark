<STATEMENT>
# Problem C — Impossibility Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of linear inequalities over $2j$ real variables. For a given set of parameters, the system requires assigning two real numbers—$M_{i,1}$ and $M_{i,2}$—for each index $i \in \{1 \dots j\}$ such that all of the following conditions are simultaneously satisfied:

1. **Clearance 1:** For any $i \neq k$, $|M_{i,1} - M_{k,1}| \ge \frac{p_{i,1} + p_{k,1}}{2}$
2. **Clearance 2:** For any $i \neq k$, $|M_{i,2} - M_{k,2}| \ge \frac{p_{i,2} + p_{k,2}}{2}$
3. **Coupling Bound:** $M_{i,1} + M_{i,2} \le T - \frac{p_{i,1} + p_{i,2}}{2}$ for all $i$
4. **Lower Bounds:** $M_{i,1} \ge \frac{p_{i,1}}{2}$ and $M_{i,2} \ge \frac{p_{i,2}}{2}$ for all $i$

In this specific problem, **no valid assignment of variables exists** that can satisfy the system for the given inputs. Your task is to output a simple proof (a certificate) demonstrating why the system is structurally impossible to solve.

It is guaranteed that the impossibility in each test case is caused by exactly one of the following two reasons. You must determine which reason applies and output the corresponding certificate. If the applicable reason offers multiple valid certificates, any single one is acceptable.

- **Local Contradiction:** For a single index **i**, there exist no real values $M_{i,1}$ and $M_{i,2}$ that satisfy conditions 3 and 4. (In other words, the lower bounds and the coupling bound are mutually exclusive for this specific index, even if conditions 1 and 2 are completely ignored).
  Output format: `JOB i` (where **i** is the 1-based index of the parameter pair).

- **Global Contradiction:** For a single dimension **c** (**c** $\in \{1, 2\}$), there exist no values for the $j$ variables $M_{1,c} \dots M_{j,c}$ that satisfy the clearance condition for dimension $c$, the lower bound for dimension $c$, and the upper bound $M_{i,c} \le T - \frac{p_{i,c}}{2}$ for all $i$. (In other words, the clearance requirements force the variables to exceed this upper bound, even if condition 3 is completely ignored).
  Output format: `LOAD c` (where **c** is exactly 1 or 2).

## Input

The first line specifies two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
The subsequent **j** lines each provide exactly **2** integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the parameters $p_{i,1}$ and $p_{i,2}$ respectively for the $i$-th index.

## Output

Output exactly one line containing a valid certificate from the applicable category: either `JOB i` or `LOAD c`. If printing `LOAD c`, then **c** must be exactly 1 or 2.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for index 1, condition 4 gives $M_{1,1} \ge 35$ and $M_{1,2} \ge 30$. Summing these yields $M_{1,1} + M_{1,2} \ge 65$. However, condition 3 requires $M_{1,1} + M_{1,2} \le 100 - \frac{70 + 60}{2} = 35$. The requirement $65 \le 35$ is a contradiction. Thus `JOB 1` is a valid certificate.

In Example 2, for dimension 1, the clearance condition is algebraically equivalent to requiring the intervals $[M_{i,1} - 25, M_{i,1} + 25)$ to be non-overlapping. The sum of their lengths is 200. It is impossible to place non-overlapping intervals of total length 200 such that their lower endpoints are at least 0 (from condition 4) and their upper endpoints are at most 150 (from the upper bound). Thus `LOAD 1` is a valid certificate.
</STATEMENT>
<RATIONALE>
The problem was completely reformulated using midpoints and half-lengths instead of start/end coordinates. This creates an exact algebraic isomorphism to the original interval-packing model, but mathematically obscures the trivial `p1 + p2 > T` check behind absolute value clearance conditions and a coupled bound. Models can no longer rely on superficial "scheduling" pattern matching and must actually perform algebraic deduction to identify the local contradiction.
</RATIONALE>
<PRESERVED_ANSWER>
The midpoint formulation is mathematically identical to the original start/end interval formulation (where $M = start + p/2$), meaning the exact same inputs will trigger the exact same local and global contradictions.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity remains $O(N)$ because the condition for `JOB i` reduces algebraically to $p_{i,1} + p_{i,2} > T$ and `LOAD c` reduces to $\sum p_{i,c} > T$, keeping it in the same feasibility-checking class.
</PRESERVED_CLASS>
