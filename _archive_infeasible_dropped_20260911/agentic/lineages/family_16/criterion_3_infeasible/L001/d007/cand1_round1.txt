# Problem C — Impossibility Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of geometric constraints involving $2j$ continuous 1-dimensional intervals. For a given set of parameters, the system requires assigning two closed intervals, $A_i$ and $B_i$, for each index $i \in \{1 \dots j\}$ such that all of the following conditions are simultaneously satisfied:

1. **Span 1:** The length of interval $A_i$ is exactly $p_{i,1}$.
2. **Span 2:** The length of interval $B_i$ is exactly $p_{i,2}$.
3. **Endpoint Capacity:** For each index $i$, the sum of the rightmost coordinate of $A_i$ and the rightmost coordinate of $B_i$ does not exceed $T$.
4. **Separation 1:** For any $i \neq k$, the intervals $A_i$ and $A_k$ intersect at most at their endpoints (their interiors are disjoint).
5. **Separation 2:** For any $i \neq k$, the intervals $B_i$ and $B_k$ intersect at most at their endpoints (their interiors are disjoint).
6. **Global Bounds:** All intervals must be located entirely within the non-negative half-line. Specifically, the leftmost coordinate of $A_i$ must be $\ge 0$, and the leftmost coordinate of $B_i$ must be $\ge 0$.

In this specific problem, **no valid assignment of intervals exists** that can satisfy the system for the given inputs. Your task is to output a simple proof (a certificate) demonstrating why the system is structurally impossible to solve.

It is guaranteed that the impossibility in each test case is caused by exactly one of the following two reasons. You must determine which reason applies and output the corresponding certificate. If the applicable reason offers multiple valid certificates, any single one is acceptable.

- **Local Contradiction:** For a single index **i**, there exists no pair of intervals $A_i$ and $B_i$ that satisfy conditions 1, 2, 3, and 6. (In other words, the endpoint capacity cannot be respected for index $i$, even if conditions 4 and 5 are completely ignored for all intervals).
  Output format: `JOB i` (where **i** is the 1-based index of the parameter pair).

- **Global Contradiction:** For a single category **c** (**c** $\in \{1, 2\}$), there exist no valid assignments for the $j$ intervals in that category that satisfy the span, separation, and category-specific bounds. Specifically, if $c=1$, no set of intervals $A_1 \dots A_j$ satisfy condition 1, condition 4, and the bounds that their leftmost coordinates are $\ge 0$ and their rightmost coordinates are $\le T$. If $c=2$, no set of intervals $B_1 \dots B_j$ satisfy condition 2, condition 5, and the bounds that their leftmost coordinates are $\ge 0$ and their rightmost coordinates are $\le T$. (In other words, the separation requirements force the intervals out of bounds, even if condition 3 is completely ignored).
  Output format: `LOAD c` (where **c** is exactly 1 or 2).

## Input

The first line specifies two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
The subsequent **j** lines each provide exactly **2** integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the required spans $p_{i,1}$ and $p_{i,2}$ respectively for the $i$-th index.

## Output

Output exactly one line containing a valid certificate from the applicable category: either `JOB i` or `LOAD c`. If printing `LOAD c`, then **c** must be exactly 1 or 2.

## Examples


**Output**
```
JOB 1
```

### Example 2

**Input**
```

```

**Output**
```
LOAD 1
```

## Note

In Example 1, for index 1, condition 1 requires interval $A_1$ to have length 70. Condition 6 requires its leftmost coordinate to be $\ge 0$, so its rightmost coordinate is at least 70. Condition 2 requires interval $B_1$ to have length 60. Condition 6 requires its leftmost coordinate to be $\ge 0$, so its rightmost coordinate is at least 60. Condition 3 requires the sum of their rightmost coordinates to be $\le 100$. However, $70 + 60 = 130$, which exceeds 100. Thus `JOB 1` is a valid certificate.

In Example 2, for category 1, the separation condition requires the intervals $A_i$ to be non-overlapping in their interiors. The sum of their lengths is 200. It is impossible to place non-overlapping intervals of total length 200 such that all leftmost coordinates are $\ge 0$ and all rightmost coordinates are $\le 150$. Thus `LOAD 1` is a valid certificate.
