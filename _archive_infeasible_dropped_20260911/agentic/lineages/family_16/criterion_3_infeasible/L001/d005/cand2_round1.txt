<STATEMENT>
# Problem C — Infeasible Subsystems

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing systems of variables $x_1, \dots, x_j$ and $y_1, \dots, y_j$ over the real numbers.
The constraints are defined by a global parameter $T$ and a set of parameter pairs $(a_k, b_k)$ for $k = 1 \dots j$.

You must identify a specific system of inequalities that is contradictory (meaning there exists no assignment of real numbers to the variables that satisfies all conditions). The input guarantees that at least one of the following systems has no valid solution. You must output its identifier. If multiple systems are contradictory, output the identifier of any one of them.

- **System `JOB i`**: For a specific index $i$ (where $i \in \{1 \dots j\}$), the variables $x_i, y_i$ must satisfy:
  - $x_i \ge 0$
  - $y_i - x_i \ge a_i$
  - $y_i + b_i \le T$
  (Output format: `JOB i`)

- **System `LOAD 1`**: The variables $x_1, \dots, x_j$ must satisfy:
  - $x_k \ge 0$ for all $k \in \{1 \dots j\}$
  - $x_k + a_k \le T$ for all $k \in \{1 \dots j\}$
  - For any $u, v \in \{1 \dots j\}$ with $u \neq v$, either $x_u - x_v \ge a_v$ or $x_v - x_u \ge a_u$
  (Output format: `LOAD 1`)

- **System `LOAD 2`**: The variables $y_1, \dots, y_j$ must satisfy:
  - $y_k \ge 0$ for all $k \in \{1 \dots j\}$
  - $y_k + b_k \le T$ for all $k \in \{1 \dots j\}$
  - For any $u, v \in \{1 \dots j\}$ with $u \neq v$, either $y_u - y_v \ge b_v$ or $y_v - y_u \ge b_u$
  (Output format: `LOAD 2`)

## Input

The first line specifies two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
The subsequent $j$ lines each provide two integers $a_k$ and $b_k$ ($1 \le a_k, b_k \le 1000000$).

## Output

Output exactly one line containing a valid identifier of a contradictory system: either `JOB i` (where $i$ is the 1-based index), `LOAD 1`, or `LOAD 2`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for System `JOB 1`, we require $x_1 \ge 0$, $y_1 - x_1 \ge 70$, and $y_1 + 60 \le 100$. Combining the latter two gives $x_1 + 70 \le y_1 \le 40$, which implies $x_1 \le -30$. This contradicts $x_1 \ge 0$, meaning System `JOB 1` has no solution.

In Example 2, System `LOAD 1` requires four variables $x_1, \dots, x_4$ to each satisfy $0 \le x_k \le 100$ (since $x_k + 50 \le 150$). The third condition requires the absolute difference between any pair of variables to be at least 50 (e.g., $x_1 - x_2 \ge 50$ or $x_2 - x_1 \ge 50$). Placing four values within a span of 100 such that all pairwise differences are at least 50 is mathematically impossible. Therefore, System `LOAD 1` has no solution.

</PRESERVED_ANSWER>
