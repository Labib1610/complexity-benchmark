<STATEMENT>
# Problem C — Impossibility Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

A computational cluster evaluates **j** continuous workloads. The resource utilization of workload **i** over a normalized time parameter $x \in [0, 1]$ is modeled by the linear function:
$f_i(x) = p1_i \cdot x + p2_i \cdot (1-x)$
where $p1_i$ and $p2_i$ are given coefficients for workload **i**.

The cluster operates under a strict capacity parameter **T**. In this specific problem, it is guaranteed that the given workloads will violate the capacity limits in exactly one of the two ways described below. Your task is to identify which violation occurs and output its corresponding error code. If the applicable category offers multiple valid error codes, any single one is acceptable.

- **Individual Workload Overload:** The average resource utilization of a single workload **i** over the continuous interval $[0, 1]$ strictly exceeds $T/2$.
  Output format: `JOB i` (where **i** is the 1-based index of the workload).

- **Endpoint Capacity Exceeded:** Let $F(x) = \sum_{i=1}^j f_i(x)$ be the aggregate resource utilization of all workloads. The aggregate utilization evaluated at the boundaries of the interval must not strictly exceed **T**. 
  If $F(1) > T$, output `LOAD 1`. 
  If $F(0) > T$, output `LOAD 2`.

## Input

The first line specifies two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
The subsequent **j** lines each provide two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the utilization coefficients for that workload.

## Output

Output exactly one line containing a valid error code from the applicable violation category: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, the first workload is modeled by $f_1(x) = 70x + 60(1-x)$. Its average utilization over $x \in [0, 1]$ is $\int_0^1 f_1(x) dx = 65$. This strictly exceeds the allowed threshold of $T/2 = 50$, so `JOB 1` is the correct error code.
In Example 2, no individual workload has an average utilization exceeding $150/2 = 75$. However, the aggregate utilization function is $F(x) = 200x + 4(1-x)$. At the endpoint $x=1$, the aggregate utilization is $F(1) = 200$, which strictly exceeds the capacity $T=150$, making `LOAD 1` a valid error code.

<RATIONALE>
I changed the 2-stage scheduling domain into a mathematical evaluation of linear functions. The conditions `p1+p2 > T` and `sum(p1) > T` are now disguised as the average value of a linear function over `[0, 1]` exceeding `T/2`, and the sum of the functions evaluated at the endpoints `x=1` and `x=0` exceeding `T`. This forces models to perform algebraic translation to discover the same underlying conditional checks, defeating models that rely on keyword-based pattern matching of job scheduling.
</RATIONALE>
<PRESERVED_ANSWER>
The inequality for the average value simplifies exactly to `(p1 + p2)/2 > T/2` which is `p1 + p2 > T`, and evaluating the aggregate sum at `x=1` and `x=0` simplifies exactly to `sum(p1) > T` and `sum(p2) > T`, ensuring all outputs are triggered under the exact same arithmetic conditions.
</PRESERVED_ANSWER>
