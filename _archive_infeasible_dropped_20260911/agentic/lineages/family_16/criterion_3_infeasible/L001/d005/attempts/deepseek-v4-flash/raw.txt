We can solve this by checking two conditions:

1. **Job feasibility**: For any job `i`, check if `p1 + p2 > T`. If true, it can’t be scheduled within time `T`, so output `JOB i`.

2. **Machine load**: If no job individually fails, check for each machine whether the sum of its processing times exceeds `T`. If true, output `LOAD c` for that machine.

Since we only need one certificate rhythmically guaranteed by the problem, this works.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    total1 = 0
    total2 = 0
    idx = 2
    for i in range(1, j+1):
        p1 = int(data[idx])
        p2 = int(data[idx+1])
        idx += 2
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
        total1 += p1
        total2 += p2
    if total1 > T:
        print("LOAD 1")
    elif total2 > T:
        print("LOAD 2")

if __name__ == "__main__":
    main()
```
