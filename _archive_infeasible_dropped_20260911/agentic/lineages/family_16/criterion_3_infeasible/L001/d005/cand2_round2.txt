<STATEMENT>
# Problem C — Impossibility Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a numerical upper bound $T$ and a sequence of $j$ pairs of positive integers, $(x_1, y_1), (x_2, y_2), \dots, (x_j, y_j)$.

We wish to assign two real-valued coordinates, $S_{i,1}$ and $S_{i,2}$, to each index $i \in \{1, \dots, j\}$ such that the following three rules are satisfied:
1. **Sequence and Bounds:** For every index $i$, the coordinates must satisfy $0 \le S_{i,1}$, and $S_{i,1} + x_i \le S_{i,2}$, and $S_{i,2} + y_i \le T$.
2. **Type 1 Disjointness:** For any two distinct indices $i$ and $k$, the open intervals $(S_{i,1}, S_{i,1} + x_i)$ and $(S_{k,1}, S_{k,1} + x_k)$ must not intersect.
3. **Type 2 Disjointness:** For any two distinct indices $i$ and $k$, the open intervals $(S_{i,2}, S_{i,2} + y_i)$ and $(S_{k,2}, S_{k,2} + y_k)$ must not intersect.

(Notice there are exactly 2 types of intervals to separate, corresponding to the $x$ and $y$ values respectively.)

For every provided input, it is guaranteed that no valid assignment of coordinates exists. Your task is to output a simple proof (a certificate) demonstrating why the upper bound $T$ is structurally impossible to satisfy.

It is guaranteed that for every input, the impossibility is caused by exactly one of the two bottleneck categories defined below. You must determine which category applies and output a valid certificate for it. If the applicable category offers multiple valid certificates, any single one is acceptable.

- **Category A (Local Contradiction):** For a single index $i$, the minimum required distance from the start of its first interval ($S_{i,1}$) to the end of its second interval ($S_{i,2} + y_i$) strictly exceeds $T$.
  Output format: `JOB i` (where $i$ is the 1-based index).

- **Category B (Global Contradiction):** The total required length for all $j$ intervals of a single type $c$ ($c \in \{1, 2\}$, where 1 refers to the $x$ values and 2 refers to the $y$ values) strictly exceeds the available space $T$.
  Output format: `LOAD c` (where $c$ is the interval type, either 1 or 2).

## Input

The first line specifies two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
The subsequent $j$ lines each provide two integers $x_i$ and $y_i$ ($1 \le x_i, y_i \le 1000000$), representing the lengths for type 1 and type 2 respectively for the $i$-th pair.

## Output

Output exactly one line containing a valid certificate from the applicable bottleneck category: either `JOB i` or `LOAD c`.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for the first pair ($i=1$), the Sequence and Bounds rule implies that the end of its second interval is at least $0 + 70 + 60 = 130$. This strictly exceeds the bound $T=100$. Thus, `JOB 1` correctly certifies the impossibility.
In Example 2, no individual pair violates the bounds in isolation. However, the intervals of type 1 require a total length of $50 \times 4 = 200$. Since they must be non-intersecting and fit within the domain bound of 150, the Type 1 Disjointness condition is impossible to satisfy. Thus, `LOAD 1` is a valid certificate.
