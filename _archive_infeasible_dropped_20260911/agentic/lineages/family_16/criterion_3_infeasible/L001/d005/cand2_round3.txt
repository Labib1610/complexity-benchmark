<METHOD_DESCRIPTION>Replaces prose descriptions of scheduling bottlenecks with a formal system of inequalities, requiring the model to deduce the algebraic conditions (p1+p2 > T and sum(p) > T) that make the relaxations logically inconsistent.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem C — Impossibility Certificate

Time limit: 2 s   Memory limit: 256 MB

## Description

A factory is tasked with completing **j** distinct items. Each item requires processing through exactly **2** phases, numbered 1 and 2. 

For each item $i \in \{1, \dots, j\}$, let $x_i$ be its start time in phase 1, and $y_i$ be its start time in phase 2. The required processing durations for item $i$ are $p_{i,1}$ in phase 1 and $p_{i,2}$ in phase 2. A valid schedule assigns real numbers $x_i, y_i$ such that all of the following conditions hold:
- $0 \le x_i$
- $x_i + p_{i,1} \le y_i$
- $y_i + p_{i,2} \le T$
- For any two distinct items $i$ and $k$, their phase 1 intervals $[x_i, x_i + p_{i,1})$ and $[x_k, x_k + p_{k,1})$ do not intersect.
- For any two distinct items $i$ and $k$, their phase 2 intervals $[y_i, y_i + p_{i,2})$ and $[y_k, y_k + p_{k,2})$ do not intersect.

In this specific problem, **no valid schedule exists** for the given deadline **T**. Instead of attempting to schedule the items, your task is to output a simple proof (a certificate) demonstrating why the deadline is structurally impossible to meet. 

It is guaranteed that the impossibility in each test case is caused by exactly one of the two relaxations defined below. You must determine which category applies and output a valid certificate for it. If the applicable category offers multiple valid certificates, any single one is acceptable.

- **Isolated Item Contradiction:** There exists an item $i$ for which the basic inequalities $0 \le x_i$, $x_i + p_{i,1} \le y_i$, and $y_i + p_{i,2} \le T$ are logically inconsistent, meaning no real numbers $x_i, y_i$ can satisfy them simultaneously.
  Output format: `JOB i` (where $i$ is the 1-based index of the item).

- **Phase Capacity Contradiction:** There exists a phase $c \in \{1, 2\}$ such that the sum of lengths of the $j$ intervals assigned to phase $c$ strictly exceeds the length of the available window $[0, T]$.
  Output format: `LOAD c` (where $c$ is the phase number, either 1 or 2).

## Input

The first line specifies two integers **j** and **T** (1 ≤ j ≤ 200000, 1 ≤ T ≤ 1000000000).
The subsequent **j** lines each provide two integers $p_{i,1}$ and $p_{i,2}$ (1 ≤ $p_{i,1}$, $p_{i,2}$ ≤ 1000000), representing the processing time required for that item in phase 1 and phase 2, respectively.

## Output

Output exactly one line containing a valid certificate from the applicable category: either `JOB i` or `LOAD c`. If you print `JOB i`, that index must satisfy the Isolated Item Contradiction; if `LOAD c`, phase $c$ must satisfy the Phase Capacity Contradiction.

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, for the first item, the inequalities $0 \le x_1$, $x_1 + 70 \le y_1$, and $y_1 + 60 \le 100$ imply $130 \le 100$, which is impossible. Thus `JOB 1` correctly certifies the impossibility.
In Example 2, the sum of the lengths of the intervals for phase 1 is $50 + 50 + 50 + 50 = 200$. This exceeds the available window length of 150, making `LOAD 1` a valid certificate.
</STATEMENT>
<RATIONALE>
Replaced the plain-English descriptions of the bottlenecks with a formal system of inequalities. By defining the certificates as relaxations of these inequalities that yield logical contradictions, models are forced to mathematically derive the conditions `p1 + p2 > T` and `sum(p) > T` rather than pattern-matching on descriptive keywords.
</RATIONALE>
<PRESERVED_ANSWER>
The logical inconsistency of the isolated item inequalities occurs exactly when `p1 + p2 > T`, and the interval length sum constraint trivially equates to `sum(p) > T`, preserving the identical conditions for each certificate.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class remains identical because finding the certificate still only requires checking linear individual sums and column sums in exactly the same way.
</PRESERVED_CLASS>
<RISK>
Models might struggle to parse the $0 \le x_i$ and interval intersection notation, but the definitions are mathematically completely standard and unambiguous.
</RISK>
