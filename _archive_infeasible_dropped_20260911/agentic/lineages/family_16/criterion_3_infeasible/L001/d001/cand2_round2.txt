# Problem C — Impossible Time Limit: Certify It

Time limit: 2 s   Memory limit: 256 MB

## Description

A system executes $j$ tasks. Each task must first complete stage 1, and only then can it proceed to stage 2. A stage can only process one task at a time. For each task, you receive its required processing time in stage 1 and stage 2.

The system is given a strict deadline $T$ by which all tasks must be fully completed.

For every test case, it is guaranteed that meeting the deadline $T$ is impossible. Your task is to output a certificate that proves this impossibility. You must print exactly one valid certificate. The test cases are constructed such that exactly one of the following two types of certificates can be formed:

- **Task-level sequential bottleneck**:
  The certificate is formatted as `JOB i` (where $1 \le i \le j$).
  This certificate is valid if and only if the strict inequality $p1_i + p2_i > T$ holds, meaning task $i$ alone cannot finish within the deadline even with no other tasks in the system.

- **Stage-level capacity bottleneck**:
  The certificate is formatted as `LOAD c` (where $c \in \{1, 2\}$).
  This certificate is valid if and only if the strict inequality $\sum_{k=1}^j p_{c,k} > T$ holds (where $p_{c,k}$ is the duration of task $k$ in stage $c$), meaning the total volume of work assigned to stage $c$ strictly exceeds the available time.

If multiple valid certificates of the available type exist (e.g., multiple tasks satisfy the condition), outputting any one of them is accepted.

## Input

The first line contains two integers $j$ and $T$ ($1 \le j \le 200000$, $1 \le T \le 1000000000$).
Each of the next $j$ lines contains two integers $p1_i$ and $p2_i$ ($1 \le p1_i, p2_i \le 1000000$), representing the durations of task $i$ in stage 1 and stage 2.

## Output

Print a single line containing a valid certificate: either `JOB i` (where $i$ is a task satisfying $p1_i + p2_i > T$) or `LOAD c` (where $c$ is a stage satisfying the capacity bottleneck inequality).

## Examples

### Example 1

**Input**
```
3 100
70 60
2 2
3 4
```

**Output**
```
JOB 1
```

### Example 2

**Input**
```
4 150
50 1
50 1
50 1
50 1
```

**Output**
```
LOAD 1
```

## Note

In Example 1, task 1 has $70 + 60 = 130$. Since $130 > 100$, the strict inequality holds, making `JOB 1` a valid certificate. In Example 2, no single task satisfies the task-level inequality, but the sum of durations in stage 1 is $50+50+50+50 = 200$. Since $200 > 150$, `LOAD 1` is a valid certificate.
