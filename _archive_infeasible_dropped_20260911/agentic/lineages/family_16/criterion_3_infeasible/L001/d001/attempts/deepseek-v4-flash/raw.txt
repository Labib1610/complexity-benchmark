We can solve this by checking two conditions:

1. **Task bottleneck**: If any task has `p1 + p2 > T`, then that task alone cannot finish in time. We can output `JOB i` for the first such task.

2. **Stage bottleneck**: If the sum of all `p1` values exceeds `T`, then stage 1 is overloaded. Similarly, if the sum of all `p2` values exceeds `T`, then stage 2 is overloaded. We output `LOAD 1` or `LOAD 2` accordingly.

Since the problem guarantees exactly one type applies, we can check in that order.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    T = int(data[1])
    idx = 2
    sum1 = 0
    sum2 = 0
    for i in range(1, j + 1):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        sum1 += p1
        sum2 += p2
        if p1 + p2 > T:
            print(f"JOB {i}")
            return
    if sum1 > T:
        print("LOAD 1")
        return
    if sum2 > T:
        print("LOAD 2")
        return

if __name__ == "__main__":
    main()
```
