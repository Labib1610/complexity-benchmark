**Solution Explanation**

For every coil we store the set of coils that are directly resonant with it.
Because `n ≤ 2000` we can store each set as a bitset inside one Python integer –
bit `k` ( `0‑based` ) tells whether the coil `k+1` is a neighbour.

For a fixed pair of coils `(a,b)` (`a<b`) a third coil `c` forms a triangle iff  

* `c` is a neighbour of `a` **and**
* `c` is a neighbour of `b`.

In bitset form the common neighbours are

```
common = neighbours[a]  AND  neighbours[b]
```

From those we need a vertex larger than `b`.  
All bits `0 … b‑1` are cleared by the mask `~((1<<b)-1)`.

If the resulting integer is non‑zero, the least significant set bit is the
smallest possible `c`. Its index (1‑based) is obtained by
`(lowbit & -lowbit).bit_length()`.

The whole search is performed in lexicographic order:

* `a` increases from `1` to `n`;
* for a fixed `a` the neighbours `b` are examined in increasing order (`b>a`);
* for a fixed `(a,b)` the smallest admissible `c` is taken.

The first triangle found is therefore the lexicographically smallest one,
which is exactly what has to be printed.

The algorithm runs in  

* `O(m)` to read the graph,
* `O(m)` to iterate over all edges (`a,b`) (`m ≤ 2·10⁵`),
* each iteration performs only a few integer operations (`&`, shift, bit‑length).

Memory consumption is `O(n)` integers (≈ 2000 · 2000 bits ≈ 0.5 MiB).

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest triangle.

---

##### Lemma 1  
For any vertices `a<b` the expression  

```
common = neighbours[a] & neighbours[b]
cand   = common & ~((1<<b)-1)
```

has a set bit at position `c-1` (0‑based) **iff** `c>b` and
edges `(a,c)` and `(b,c)` are present.

**Proof.**  
`neighbours[a]` has a 1‑bit exactly at positions of vertices adjacent to `a`,
similarly for `neighbours[b]`. Their bitwise `&` therefore has a 1‑bit exactly
at positions of vertices adjacent to **both** `a` and `b`.  
Mask `~((1<<b)-1)` clears bits `0 … b‑1` and keeps bits `b … n‑1`.  
Thus after masking a bit stays set iff the vertex index `c` satisfies `c>b`
and is adjacent to both `a` and `b`. ∎



##### Lemma 2  
If `cand` is non‑zero, letting `low = cand & -cand` (the least significant
set bit) and `c = low.bit_length()`, then `c` is the smallest vertex `>b`
that together with `a` and `b` forms a triangle.

**Proof.**  
`low` isolates the least significant 1‑bit of `cand`. By definition of the
mask (Lemma&nbsp;1) every 1‑bit of `cand` corresponds to a vertex `c>b`
adjacent to both `a` and `b`. The least significant such bit has the smallest
index, i.e. the smallest vertex number. `low.bit_length()` returns exactly
that index + 1, i.e. the vertex label `c`. ∎



##### Lemma 3  
When the algorithm prints a triple `(a,b,c)`, it is a triangle
(`a<b<c` and all three edges exist).

**Proof.**  
The outer loop ensures `a<b`.  
The inner loop processes only neighbours `b` of `a` with `b>a`,
hence edge `(a,b)` exists.
`cand` is constructed as in Lemma&nbsp;1, therefore any non‑zero `cand`
guarantees edges `(a,c)` and `(b,c)`. By Lemma&nbsp;2 the chosen `c` is
greater than `b`. ∎



##### Lemma 4  
Let `(a₀,b₀,c₀)` be the first triangle printed by the algorithm.
For any triangle `(x,y,z)` with `x<y<z` we have
`(a₀,b₀,c₀)` ≤ₗₑₓ `(x,y,z)`.

**Proof.**  
The algorithm examines `a` increasingly.  
*If `x<a₀`* – then the outer loop would have processed `a = x` before `a₀`.
During that iteration it iterates over all neighbours `b > x` in increasing
order. If a triangle with first vertex `x` existed, the algorithm would have
found it (Lemma&nbsp;3) **before** reaching `a₀`. Contradiction, therefore no
triangle can have first vertex smaller than `a₀`.

Hence any triangle has first vertex `x ≥ a₀`.  

If `x = a₀` the inner loop processes neighbours `b` in increasing order.
If there were a triangle with the same `a₀` and a smaller second vertex
than `b₀`, it would have been found earlier. Thus `y ≥ b₀`.

If also `y = b₀`, Lemma&nbsp;2 shows the algorithm picks the smallest possible
`c` for this pair, so `z ≥ c₀`.

Consequently `(a₀,b₀,c₀)` is lexicographically minimal. ∎



##### Theorem  
The algorithm always outputs the lexicographically smallest triple of
coils that forms a triangle.

**Proof.**  
Existence: the statement guarantees at least one triangle; the algorithm
examines every edge, therefore eventually encounters a triangle and prints it
(Lemmas&nbsp;1‑3).  

Minimality: by Lemma&nbsp;4 the printed triple is not larger than any other
triangle, i.e. it is the lexicographically smallest. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Reading input* – `O(m)` time, `O(n)` memory for the bitsets.  

*Main loops* – each undirected edge `(a,b)` with `a<b` is examined once.
For each edge we perform a constant number of integer operations,
hence `O(m)` time.

Overall  

* **Time:** `O(m)`  ( ≤ 2·10⁵, well below the 2 s limit)  
* **Memory:** `O(n)` integers ≈ 0.5 MiB (far below 256 MiB)

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    # adjacency as bitsets, vertices are 1‑based, bit 0 corresponds to vertex 1
    adj_bits = [0] * (n + 1)
    neigh = [[] for _ in range(n + 1)]

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj_bits[u] |= 1 << (v - 1)
        adj_bits[v] |= 1 << (u - 1)
        neigh[u].append(v)
        neigh[v].append(u)

    # sort neighbour lists to guarantee increasing order of b
    for lst in neigh:
        lst.sort()

    for a in range(1, n - 1):
        bits_a = adj_bits[a]
        for b in neigh[a]:
            if b <= a:
                continue
            # common neighbours of a and b
            common = bits_a & adj_bits[b]
            # keep only vertices > b
            cand = common & ~((1 << b) - 1)
            if cand:
                low = cand & -cand          # least significant 1‑bit
                c = low.bit_length()        # vertex number (1‑based)
                # a < b < c is guaranteed
                print(a, b, c)
                return

if __name__ == "__main__":
    solve()
```

and conforms to the required input‑output format.
