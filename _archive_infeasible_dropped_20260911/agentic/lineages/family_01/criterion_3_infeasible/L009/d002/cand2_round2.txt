# Problem C — Tri-Node Resonance

Time limit: 2 s
Memory limit: 256 MB

An advanced fusion prototype houses $n$ electromagnetic stabilizers, indexed from $1$ up to $n$. Technicians have conducted pairwise resonance tests, documenting $m$ specific pairs that maintain a stable harmonic link.

A stable reaction state demands a "tri-node" setup, which consists of exactly three distinct stabilizers. For the setup to be viable, mutual stability must exist across the entire triad. This means that within the selected trio, each stabilizer must possess a verified harmonic link with each of the other two members.

You must find a valid tri-node setup. It is guaranteed that the test logs contain at least one such setup.

## Input
The first line contains two integers $n$ and $m$. The integer $n$ represents the number of stabilizers, which is at least the minimum number required to form one tri-node setup, and at most the architectural limit of two thousand. The integer $m$ represents the number of documented links, which is at least three, and at most the memory bank limit of two hundred thousand or the total number of distinct pairs that can be formed from the $n$ stabilizers, whichever is smaller.

The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing a verified harmonic link between stabilizer $u$ and stabilizer $v$. These links are bidirectional, and no pair is documented more than once.

It is guaranteed that a valid tri-node setup exists in the provided data.

## Output
Output a single line with three space-separated integers $x$, $y$, and $z$, satisfying $x < y < z$. These are the indices of the three stabilizers forming your chosen tri-node setup. Should multiple valid trios exist, select the one with the smallest possible value for $x$. If ties remain, minimize $y$, and if necessary, minimize $z$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
