**Solution Explanation**

For every module we store the set of its neighbours as a bitset.
`bit i` (0‑based) is `1` iff the module is connected with module `i+1`.

```
adj[v]  – integer, bit i = 1  ⇔  edge (v , i+1) exists
```

`n ≤ 2000`, therefore one integer (≈ 2000 bits) fits easily in memory and all
bit operations are O(1).

A triangle `(x , y , z)` (`x < y < z`) exists iff  

* edge `(x , y)` exists,
* `z` is a common neighbour of `x` and `y`,
* `z > y`.

For a fixed edge `(x , y)` the set of common neighbours is

```
common = adj[x] & adj[y]
```

To keep the lexicographic order we have to ignore vertices `≤ y`.
All bits `0 … y` are cleared:

```
mask = ~((1 << (y+1)) - 1)          # bits > y are 1
common &= mask
```

If `common` is non‑zero, the least set bit gives the smallest possible `z`.
The index of the lowest set bit of a positive integer `v` is

```
z = (v & -v).bit_length() - 1      # 0‑based → vertex number = z+1
```

We iterate `x` from `1` to `n`, and for each `x` we iterate its neighbours
`y` with `y > x` in increasing order.
The first triangle we meet is exactly the required one
(minimum `x`, then `y`, then `z`).

The total work is `O(m)` bit operations, well below the limits
(`m ≤ 2·10⁵`, `n ≤ 2000`).

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest triangle.

---

**Lemma 1**  
For any vertices `x < y`, after the masking step `common` contains exactly the
vertices `z` such that `z > y` and edges `(x , z)` and `(y , z)` exist.

*Proof.*  
`adj[x] & adj[y]` contains all vertices adjacent to both `x` and `y`.  
Mask `~((1 << (y+1)) - 1)` has zeros in positions `0 … y` and ones elsewhere,
so `common &= mask` removes all vertices `≤ y`. ∎



**Lemma 2**  
If `common` is non‑zero, the vertex `z` obtained from the lowest set bit is the
smallest vertex satisfying Lemma&nbsp;1.

*Proof.*  
The lowest set bit of a positive integer corresponds to the smallest index
with value `1`. By Lemma&nbsp;1 the set bits are exactly the admissible `z`,
hence the smallest such `z` is returned. ∎



**Lemma 3**  
When the algorithm prints a triple `(x , y , z)`, it is a triangle
(`x < y < z` and all three edges exist).

*Proof.*  
`y` is taken from the neighbour list of `x`, therefore edge `(x , y)` exists.
`z` is obtained from `common` which, by Lemma&nbsp;1, guarantees edges
`(x , z)` and `(y , z)` and also `z > y`. ∎



**Lemma 4**  
Let `T` be the first triangle output by the algorithm.
For any triangle `(a , b , c)` with `a < b < c` we have
`(a , b , c) ≥_lex (x , y , z)`.

*Proof.*  
The outer loop enumerates `x` in increasing order.
If a triangle has first vertex `a < x`, the algorithm would have examined
`x = a` earlier. Inside that iteration it scans neighbours `y` in increasing
order, so any triangle with the same `x` and a smaller second vertex would be
found earlier. Finally, for the fixed pair `(x , y)` Lemma&nbsp;2 guarantees
that the smallest possible third vertex is chosen. Therefore no triangle can
lexicographically precede the one printed. ∎



**Theorem**  
The algorithm outputs the lexicographically smallest triangle of the given
graph.

*Proof.*  
By Lemma&nbsp;3 the output is a triangle.
By Lemma&nbsp;4 no other triangle is lexicographically smaller.
Hence the printed triple is exactly the required answer. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building bitsets*: `O(m)`  
*Main loops*: each edge `(x , y)` with `x < y` is processed once,
constant‑time bit operations → `O(m)`  

Memory: `n` integers, each ≤ `2ⁿ` → `O(n)` bits ≈ 2000·2000 / 8 ≈ 0.5 MiB.

Both limits satisfy the problem constraints.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj_bits = [0] * (n + 1)          # 1‑based
    neigh = [[] for _ in range(n + 1)]

    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj_bits[u] |= 1 << (v - 1)
        adj_bits[v] |= 1 << (u - 1)
        neigh[u].append(v)
        neigh[v].append(u)

    # sort neighbour lists for deterministic order
    for lst in neigh:
        lst.sort()

    for x in range(1, n + 1):
        bx = adj_bits[x]
        for y in neigh[x]:
            if y <= x:
                continue
            # common neighbours of x and y
            common = bx & adj_bits[y]
            # keep only vertices > y
            mask = ~((1 << (y + 1)) - 1)
            common &= mask
            if common:
                # lowest set bit -> smallest z
                low = common & -common
                z = low.bit_length() - 1   # 0‑based index
                # output sorted (x<y<z)
                sys.stdout.write(f"{x} {y} {z+1}\n")
                return

if __name__ == "__main__":
    solve()
```

to the required input‑output format.
