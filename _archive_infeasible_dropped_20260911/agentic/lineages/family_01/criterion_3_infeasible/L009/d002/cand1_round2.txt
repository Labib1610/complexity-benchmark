# Problem C — Triple-Core Resonance

Time limit: 2 s
Memory limit: 256 MB

An experimental fusion reactor features $n$ magnetic coils, labeled from $1$ to $n$. Engineers have evaluated pairs of these coils, cataloging $m$ specific pairs that display direct magnetic resonance.

Sustained fusion relies on establishing a "triple-core" assembly, which consists of exactly three distinct coils. For this assembly to operate correctly, energy transfer must be uninterrupted across the entire group. This means that each coil in the selected trio must share a confirmed, direct resonance with the other two coils in the trio. 

Your objective is to determine a valid triple-core assembly.

## Input
The first line provides two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$).
The next $m$ lines each contain two integers $u$ and $v$, specifying that coil $u$ and coil $v$ have a confirmed direct resonance. These relationships are symmetric, and no pair is documented more than once.

## Output
Output three space-separated integers $x$, $y$, and $z$ on a single line, ordered such that $x < y < z$. These values must be the labels of the three coils forming your chosen assembly. If multiple valid trios are possible, you must select the one with the smallest value for $x$. If ties remain, minimize $y$, and finally minimize $z$. If no such assembly can be formed, output `-1 -1 -1`.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
