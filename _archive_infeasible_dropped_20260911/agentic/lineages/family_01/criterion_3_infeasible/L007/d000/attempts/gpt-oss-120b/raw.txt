**Solution Explanation**

For the given undirected graph we have to output the lexicographically smallest
triangle  
`a < b < c` (three vertices pairwise connected).

`n ≤ 2000`, therefore a vertex can be represented by one bit inside a Python
integer (`int` has arbitrary length).  
For every vertex `v` we store the bitset of its neighbours:

```
adj[v]  – integer, bit i (0‑based) is 1  ⇔  vertex (i+1) is adjacent to v
```

With bitsets the intersection of two neighbour sets is a single
`&` operation, which is O(1) on the whole word (≈ 2000 / 64 = 32 machine words).

--------------------------------------------------------------------

#### Finding a triangle

Consider an edge `u – v` with `u < v`.  
All vertices that together with `u` and `v` form a triangle are exactly the
vertices belonging to the intersection `adj[u] ∧ adj[v]`.

We need the **smallest** vertex `w` that is larger than `v`
(because the final answer must be ordered `u < v < w`).

```
common = adj[u] & adj[v]          # all common neighbours
# keep only vertices > v
candidate = common >> v            # shift away bits 0 … v‑1
if candidate != 0:
        # lowest set bit of candidate gives the smallest w > v
        low = candidate & -candidate
        w = (low.bit_length() - 1) + v
        triangle (u, v, w) is valid
```

The loop runs over **all edges** (`m ≤ 2·10⁵`).  
For each edge we perform a few integer operations → total time `O(m)`.

While scanning edges we keep the best triangle found so far according to the
required ordering:

```
best = None
if best is None or (u, v, w) < best:   # tuple comparison is lexicographic
        best = (u, v, w)
```

Because edges are processed in arbitrary order we must compare every
candidate with the current best.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
triangle.

---

##### Lemma 1  
For any edge `u‑v` (`u < v`) the algorithm finds the smallest vertex `w`
such that `{u,v,w}` is a triangle and `w > v`, if such a vertex exists.

**Proof.**  
`common = adj[u] ∧ adj[v]` contains precisely the vertices adjacent to both
`u` and `v`.  
Shifting right by `v` removes bits of vertices `≤ v`; the remaining bits
correspond one‑to‑one to vertices `> v`.  
If the shifted value `candidate` is non‑zero, its lowest set bit corresponds
to the smallest remaining vertex.  
The computation of `w` restores the original vertex number.
∎



##### Lemma 2  
Whenever the algorithm updates `best` with a triangle `(u,v,w)`,
the triple is a valid triangle of the graph.

**Proof.**  
`best` is updated only after the test `candidate != 0`, i.e. after Lemma&nbsp;1
has produced a vertex `w`.  
By construction `w` belongs to `adj[u] ∧ adj[v]`, therefore edges
`u‑w` and `v‑w` exist, and the edge `u‑v` is the current processed edge.
Thus all three edges are present – the triple is a triangle. ∎



##### Lemma 3  
At any moment `best` (if not `None`) is the lexicographically smallest
triangle among all triangles examined so far.

**Proof.**  
`best` is initialised `None`.  
When a new triangle `(u,v,w)` is found, we replace `best` only if
`(u,v,w) < best` (tuple comparison).  
Hence after the replacement `best` is the minimum of the previous `best`
and the new triangle, i.e. the minimum of all examined triangles.
Induction over the processed edges yields the claim. ∎



##### Lemma 4  
After all edges have been processed, `best` equals the lexicographically
smallest triangle of the whole graph.

**Proof.**  
Every triangle `{a,b,c}` (with `a<b<c`) contains the edge `a‑b`.  
When the algorithm processes this edge, Lemma&nbsp;1 finds `c` (because it is
the smallest common neighbour larger than `b`).  
Thus the triangle is examined and considered for `best`.  
Consequently *all* triangles are examined, and by Lemma&nbsp;3 the final
`best` is the minimum among them. ∎



##### Theorem  
The algorithm outputs three integers `a<b<c` that form a triangle and are
lexicographically minimal among all triangles of the input graph.

**Proof.**  
By Lemma&nbsp;2 every candidate stored in `best` is a triangle.
By Lemma&nbsp;4 after the loop `best` is the smallest triangle.
The algorithm finally prints `best`, therefore the output satisfies the
specification. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency bitsets* : `O(m)`  
*Processing each edge* : constant time (`&`, shift, bit operations) → `O(m)`  

Total time `O(m) ≤ 2·10⁵`, well below the limit.

Memory: one integer per vertex (`n ≤ 2000`) → at most `2000 * 2000` bits
≈ 0.5 MiB, plus the edge list – far under 256 MiB.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * (n + 1)          # 1‑based
    edges = []

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        if u == v:
            continue
        # store undirected edge
        adj[u] |= 1 << (v - 1)
        adj[v] |= 1 << (u - 1)
        if u < v:
            edges.append((u, v))
        else:
            edges.append((v, u))

    best = None  # tuple (a,b,c)

    for u, v in edges:
        # common neighbours of u and v
        common = adj[u] & adj[v]
        # keep only vertices > v
        cand = common >> v
        if cand:
            low = cand & -cand               # lowest set bit
            w = (low.bit_length() - 1) + v   # restore original index
            tri = (u, v, w)
            if best is None or tri < best:
                best = tri

    # best is guaranteed to exist
    a, b, c = best
    sys.stdout.write(f"{a} {b} {c}")

if __name__ == "__main__":
    solve()
```
