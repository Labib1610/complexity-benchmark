We can solve this by checking all triples in increasing order of IDs and stopping at the first valid triangle.  
Since \( n \le 2000 \), a naive triple loop would be \( O(n^3) \), which is too slow.  
Instead, we can iterate over the smallest vertex `a`, then the second `b`, and check if `c` exists in the adjacency set.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if b not in adj[a]:
                continue
            # find smallest c > b that is connected to both a and b
            for c in range(b + 1, n + 1):
                if c in adj[a] and c in adj[b]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
