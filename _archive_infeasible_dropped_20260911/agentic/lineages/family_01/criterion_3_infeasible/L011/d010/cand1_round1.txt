# Problem C — Synchronized Clusters

Time limit: 2 s   Memory limit: 256 MB

You are analyzing a network of active devices. The network's configuration is defined by a sequence of bidirectional transmissions. 

The headcount of devices, denoted $n$, is at least a trio, but never exceeds two thousand.
The number of recorded transmissions, denoted $m$, is at least three, bounded above by two hundred thousand.
Furthermore, the number of transmissions is guaranteed to be at most the theoretical maximum where every possible pair of devices communicates exactly once.

For each $k$ from $1$ to $m$, the $k$-th transmission specifies two distinct devices $u$ and $v$ that communicate with each other. No two transmissions will specify the exact same pair of devices.

For any device $x$, let its activity level $D_x$ be the total number of transmissions in which device $x$ participates.

For any trio of distinct devices $a, b,$ and $c$, we define their "resonance level". To compute this, look at every transmission $k$ (from $1$ to $m$). Let $S_k$ be the number of devices from the trio $\{a, b, c\}$ that are involved in the $k$-th transmission. The resonance level of the trio is defined as the sum of $3^{S_k}$ over all $m$ transmissions.

Your task is to find a "synchronized cluster". A synchronized cluster is formed by three distinct devices $a, b,$ and $c$ (with $a < b < c$) such that their resonance level satisfies the following equation:

$$ \text{Resonance Level} = m + 2(D_a + D_b + D_c) + 12 $$

## Input
The first line contains two integers $n$ and $m$, representing the number of devices and the number of transmissions, respectively. 

Each of the following $m$ lines corresponds to a transmission. For $k$ from $1$ to $m$, the $k$-th of these lines contains two integers $u$ and $v$ (representing distinct device IDs between $1$ and $n$), indicating the devices involved in transmission $k$. 

It is guaranteed that at least one valid synchronized cluster exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, with $a < b < c$. These integers must form a valid synchronized cluster as described above. 

If there are multiple valid trios, output the one that is lexicographically smallest. This means you should output the trio with the smallest value for $a$; if there is a tie, choose the one with the smallest value for $b$; and if a tie remains, choose the one with the smallest value for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
