<METHOD_NAME>Inclusion-Exclusion Set Union Equivalence</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the artificial pairwise scoring equation with a single set union cardinality condition. By the Principle of Inclusion-Exclusion, since no task is shared by three employees, |A ∪ B ∪ C| = |A| + |B| + |C| - 3 mathematically implies the sum of their pairwise intersections is exactly 3. Since multigraphs are forbidden, this requires the three employees to form a triangle. Models failing to perform this PIE deduction will attempt O(N^3) set unions and TLE.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem C — Task Synergy

Time limit: 2 s   Memory limit: 256 MB

You are analyzing the workload of $n$ employees. There are $m$ distinct tasks, numbered $1$ to $m$. Each task requires collaboration and is assigned to exactly two distinct employees. 

Let $T_i$ represent the set of task indices assigned to employee $i$. The size of this set, denoted as $|T_i|$, is the total number of tasks employee $i$ is involved in. 

For any group of three distinct employees $a$, $b$, and $c$, we can evaluate their combined task footprint. This footprint is defined as the total number of unique tasks assigned to at least one of the three employees, which corresponds to the size of the union of their task sets: $|T_a \cup T_b \cup T_c|$.

Your objective is to identify a "synergistic" trio of employees. A trio of distinct employees $a$, $b$, and $c$ (with $a < b < c$) is considered synergistic if their combined task footprint satisfies the following equation:

$|T_a \cup T_b \cup T_c| = |T_a| + |T_b| + |T_c| - 3$

## Input
The first line contains two integers $n$ and $m$. The integer $n$ ($3 \le n \le 2000$) defines the number of employees. The integer $m$ ($3 \le m \le 200000$) defines the total number of tasks. It is guaranteed that $m \le n(n-1)/2$.

Each of the following $m$ lines corresponds to a task. For $k$ from $1$ to $m$, the $k$-th of these lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating the two employees assigned to task $k$. 

It is guaranteed that no two tasks will specify the exact same pair of employees, and that at least one synergistic trio of employees exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, with $a < b < c$. These integers must represent a valid synergistic trio as described above. 

If there are multiple valid trios, output the one that is lexicographically smallest. This means you should output the trio with the smallest value for $a$; if there is a tie, choose the one with the smallest value for $b$; and if a tie remains, choose the one with the smallest value for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
The problem was reformulated using set union cardinality instead of a pairwise scoring equation. By the Principle of Inclusion-Exclusion, because each task belongs to exactly two employees, the triple intersection is always empty. Thus, the union equation simplifies to requiring the sum of the pairwise intersections to be 3, which strictly forces a triangle. This forces models to deduce the underlying graph structure mathematically rather than pattern-matching a pairwise score sum.
</RATIONALE>
<PRESERVED_ANSWER>
The equation |A ∪ B ∪ C| = |A| + |B| + |C| - 3 evaluates identically to the original pairwise scoring requirement because the lack of duplicate tasks and three-person tasks means it is satisfied if and only if all three pairs share exactly one task.
</PRESERVED_ANSWER>

The problem remains exactly equivalent to finding a triangle (K3) in an undirected graph, maintaining the O(N*M/64) complexity class using bitset intersections or standard triangle-finding algorithms.
