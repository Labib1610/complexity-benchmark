<METHOD_NAME>Linear Independence Substitution</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the search for a graph triangle with the search for a 3-variable subsystem of linear equations that has a unique trivial solution. The coefficient matrix of this subsystem is the adjacency matrix of the 3 vertices, and its determinant is non-zero if and only if all three edges are present. Models that fail to perform this algebraic deduction will attempt to simulate the linear system and TLE.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem C — Rigid Subsystems

Time limit: 2 s   Memory limit: 256 MB

You are analyzing a system of $n$ linear equations over the real numbers. The variables are $x_1, x_2, \ldots, x_n$.

Initially, for each $i$ from $1$ to $n$, the $i$-th equation is simply $0 = 0$.

The system's configuration is defined by a list of $m$ updates. For each $k$ from $1$ to $m$, the $k$-th update specifies two distinct variable indices $u$ and $v$. This update modifies the equations by adding the term $x_v$ to the left-hand side of the $u$-th equation, and adding the term $x_u$ to the left-hand side of the $v$-th equation. No two updates will specify the exact same pair of indices $\{u, v\}$.

Your task is to find a "rigid" triplet of variables. A triplet is formed by three distinct indices $a, b$, and $c$ (with $a < b < c$). 
To determine if a triplet is rigid, we isolate their subsystem: we extract the $a$-th, $b$-th, and $c$-th equations, and we substitute $0$ for all variables other than $x_a, x_b$, and $x_c$. 
This leaves a homogeneous system of 3 linear equations in 3 variables. 
A triplet is considered rigid if this resulting 3x3 system has exactly one solution (which will be the trivial solution $x_a = x_b = x_c = 0$).

## Input
The first line contains two integers $n$ and $m$. The integer $n$ ($3 \le n \le 2000$) defines the number of variables and equations. The integer $m$ ($3 \le m \le 200000$) defines the number of updates. It is guaranteed that $m \le n(n-1)/2$.

Each of the following $m$ lines corresponds to an update. For $k$ from $1$ to $m$, the $k$-th of these lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating the variables involved in update $k$. 

It is guaranteed that at least one rigid triplet exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, with $a < b < c$. These integers must form a rigid triplet as described above. 

If there are multiple valid triplets, output the one that is lexicographically smallest. This means you should output the triplet with the smallest value for $a$; if there is a tie, choose the one with the smallest value for $b$; and if a tie remains, choose the one with the smallest value for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
I transformed the problem into finding a specific property of a system of linear equations. The condition that a 3-variable isolated subsystem has exactly one trivial solution is mathematically equivalent to its coefficient matrix having a non-zero determinant. Since the matrix has 0s on the diagonal and 1s or 0s elsewhere (representing the presence of updates), the determinant is non-zero if and only if all three variables mutually updated each other (forming a triangle). Models that fail to perform this algebraic deduction will attempt to simulate or solve the linear system directly, which will TLE because there are O(n^3) triplets.
</RATIONALE>
<PRESERVED_ANSWER>
The determinant of the 3x3 coefficient matrix for variables a, b, c is exactly 2 * I(a,b) * I(b,c) * I(c,a), where I(u,v) is 1 if an update exists and 0 otherwise; thus, exactly one solution exists if and only if all three updates are present, making it strictly equivalent to finding a triangle.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem is still finding a triangle in an undirected graph, which requires the same O(n * m / 64) bitset intersection algorithm to pass within the time limit.
</PRESERVED_CLASS>
