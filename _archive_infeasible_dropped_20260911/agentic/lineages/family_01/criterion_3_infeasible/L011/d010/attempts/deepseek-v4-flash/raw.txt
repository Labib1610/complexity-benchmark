We can think about the problem in terms of a graph where employees are vertices and tasks are edges.  

A synergistic trio corresponds to a triangle in the graph:  
- If three employees are all pairwise connected by edges (i.e., form a triangle), then each pair shares a task.  
- In that case, the union size is 3 (only the three connecting tasks), and the sum of the individual degrees is 6, giving 6 − 3 = 3.  
This matches the equation exactly.

So the task reduces to:  
Find the lexicographically smallest triangle in the graph.

**Algorithm sketch:**
1. Read `n` and `m`, then build an adjacency set for each vertex.
2. Iterate `a` from 1 to n-2,  
   then `b` from a+1 to n-1,  
   then check if `c` > b exists such that (a,b), (a,c), (b,c) are all edges.
3. Since we want lexicographically smallest, we can stop at the first found.

Completing this naively is O(n³), too large for n=2000.  
We can optimize:  
- For each a, consider only b that are neighbors of a.  
- For each such b, check the intersection of neighbor sets for a common c > b.

Let's implement efficiently using bitsets or sets. With n=2000, adjacency bitmasks as Python integers will make intersection fast.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [0] * (n + 1)
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u] |= (1 << (v-1))
        adj[v] |= (1 << (u-1))
    
    # Look for triangle lexicographically smallest
    for a in range(1, n+1):
        # neighbors of a with index > a
        neigh_a = adj[a] & ~((1 << a) - 1)  # only b > a
        b_mask = neigh_a
        while b_mask:
            lsb = b_mask & -b_mask
            b = lsb.bit_length()  # 1-based
            # common neighbors of a and b
            common = adj[a] & adj[b]
            # only c > b
            common &= ~((1 << b) - 1)
            if common:
                c = (common & -common).bit_length()
                print(a, b, c)
                return
            b_mask ^= lsb

if __name__ == "__main__":
    solve()
```
