<METHOD_NAME>Algebraic Energy Equation Substitution</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the search for a graph triangle with an algebraically equivalent condition E(a,b)+E(b,c)+E(c,a) = 2(a^2+b^2+c^2), where E(x,y)=x^2+y^2 if the pair exists and 0 otherwise. Models must deduce that this equation is strictly equivalent to all three pairs existing; failure to do so leads to O(N^3) brute force and TLE, while success allows the intended O(NM/64) bitset intersection algorithm.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem C — Energy Resonance

Time limit: 2 s   Memory limit: 256 MB

You are analyzing a system of $n$ components, numbered $1$ to $n$. 

The system's configuration is defined by a list of $m$ tested pairs. Each tested pair specifies two distinct components that interact with each other. No two tested pairs will specify the exact same pair of components.

For any two distinct components $x$ and $y$, their *mutual energy* $E(x, y)$ is defined as follows:
- $E(x, y) = x^2 + y^2$ if the unordered pair $\{x, y\}$ is among the $m$ tested pairs.
- $E(x, y) = 0$ if the unordered pair $\{x, y\}$ is not among the $m$ tested pairs.

Your task is to find a "resonance" among the components. A resonance is formed by three distinct component indices $a$, $b$, and $c$ (with $a < b < c$) such that their mutual energies satisfy the following energy conservation equation:

$E(a, b) + E(b, c) + E(c, a) = 2(a^2 + b^2 + c^2)$

## Input
The first line contains two integers $n$ and $m$. The integer $n$ ($3 \le n \le 2000$) defines the number of components. The integer $m$ ($3 \le m \le 200000$) defines the number of tested pairs. It is guaranteed that $m \le n(n-1)/2$.

Each of the following $m$ lines corresponds to a tested pair. For $k$ from $1$ to $m$, the $k$-th of these lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating the components in the tested pair. No two lines will specify the exact same pair of indices $\{u, v\}$.

It is guaranteed that at least one valid resonance exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, with $a < b < c$. These integers must form a valid resonance as described above. 

If there are multiple valid trios, output the one that is lexicographically smallest. This means you should output the trio with the smallest value for $a$; if there is a tie, choose the one with the smallest value for $b$; and if a tie remains, choose the one with the smallest value for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
I removed the graph terminology and replaced the triangle-finding condition with an algebraically equivalent energy equation. Because $E(x,y)$ is either $x^2+y^2$ or $0$, the maximum possible sum $2(a^2+b^2+c^2)$ is achieved if and only if all three pairs are present; models that fail to deduce this structural equivalence will likely implement an $O(N^3)$ brute-force search and Time Out.
</RATIONALE>
<PRESERVED_ANSWER>
The energy conservation equation is mathematically satisfied if and only if all three pairs $(a,b), (b,c), (c,a)$ exist in the input, which is exactly the same condition as the original graph triangle problem.
</PRESERVED_ANSWER>

The problem still requires finding a 3-clique (triangle) in an unweighted graph, which maintains the exact same complexity class and allows the intended bitset intersection algorithm.
</PRESERVED_CLASS>
