We can model the sequences as a graph where each operation adds an edge between two vertices.  
The score condition simplifies to: for a triple \((a,b,c)\), the sum of pairwise scores is \(3m+6\).  

Each pair contributes \(m + 2 \times (\text{number of common 1s})\).  
So the sum over three pairs is:

\[
3m + 2 \times (\text{total common 1s across the three pairs})
\]

We need this to equal \(3m + 6\), so:

\[
\text{total common 1s across the three pairs} = 3
\]

That means the three edges between the three vertices must all exist in the graph.  
So we just need to find the lexicographically smallest triangle in the graph.

We can do this by iterating over possible \(a\), then \(b\), then checking for \(c\) using adjacency sets.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(n):
        for b in adj[a]:
            if b > a:
                common = adj[a] & adj[b]
                if common:
                    c = min(common)
                    if c > b:
                        print(a+1, b+1, c+1)
                        return

if __name__ == "__main__":
    solve()
```
