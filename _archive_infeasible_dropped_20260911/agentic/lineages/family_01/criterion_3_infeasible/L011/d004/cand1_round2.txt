<METHOD_NAME>Quadratic Form Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the graph/triangle-finding description with an equivalent linear algebra constraint ($x^T W x = 6$ for a binary vector $x$ with three $1$s). This forces models to mathematically deduce that this constraint requires three mutually connected indices, defeating those that rely on graph terminology pattern matching or explicit edge-membership checks.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem C — Quadratic Form Anomaly

Time limit: 2 s   Memory limit: 256 MB

You are analyzing a sparse symmetric matrix $W$ of size $n \times n$. Initially, all entries of $W$ are $0$.

You are provided with a list of $m$ coordinate pairs. For each given pair $(u, v)$, the matrix entries $W_{u,v}$ and $W_{v,u}$ are set to $1$. (The diagonal entries $W_{i,i}$ remain $0$).

Your task is to identify a binary column vector $x$ of length $n$ that satisfies a specific quadratic constraint. The vector $x$ must contain exactly three $1$s and $n-3$ $0$s. The constraint is that the scalar value given by $x^T W x$ must equal $6$.

It is guaranteed by the properties of the provided data that at least one such vector $x$ exists. You must find the indices of the three $1$s in this vector.

## Input
The first line provides two integers $n$ and $m$. The dimension of the matrix $n$ is at least 3. The matrix system has exactly 2000 distinct index channels, which imposes a strict maximum limit on $n$ (so $n \le 2000$). The number of provided coordinate pairs $m$ is at least 3. The coordinate database has a hard storage limit of 200000 entries, so $m$ will not exceed 200000, nor will it exceed the maximum possible number of strictly upper-triangular non-zero entries for a matrix of size $n$.

Each of the subsequent $m$ lines contains two integers $u$ and $v$ — the 1-based indices of a coordinate pair where $W_{u,v} = 1$ and $W_{v,u} = 1$. Indices are integers from 1 to $n$.

It is guaranteed that at least one valid vector $x$ satisfying the condition exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line with $a < b < c$, representing the 1-based indices where the vector $x$ contains its three $1$s. If there are multiple valid vectors that satisfy the condition, output the one whose set of indices has the smallest value for $a$; in case of a tie, the one with the smallest value for $b$; and if still tied, the one with the smallest value for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
The problem is reframed from finding a deadlock (triangle in a graph) to finding a sparse binary vector that yields a specific scalar from a quadratic form. Mathematically, for a binary vector with three 1s, $x^T W x = 6$ is exclusively true when all three corresponding nodes are mutually connected in the adjacency matrix $W$. This forces the model to perform the algebraic deduction to recognize the underlying clique structure, preventing simple pattern matching on graph terminology.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $x^T W x = 6$ for a binary vector with exactly three 1s algebraically simplifies to $2(W_{a,b} + W_{a,c} + W_{b,c}) = 6$, which perfectly maps to the requirement that all three pairs exist in the input, preserving the exact same valid triplets.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying computational task remains finding a 3-clique in an undirected graph, maintaining the exact same time complexity requirements to avoid TLE.
</PRESERVED_CLASS>
<RISK>
Models could misinterpret "binary column vector" or the quadratic form $x^T W x$, though both are standard linear algebra terms and the exact sizes/shapes are explicitly constrained.
</RISK>
