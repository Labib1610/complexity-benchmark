<METHOD_DESCRIPTION>Replaces the undirected graph with a dense binary matrix $M$, and the triangle condition with a 'coherence score' $M[x][y]+M[y][z]+M[z][x]=3$. Replaces the lexicographical tie-breaker with a strictly monotonic polynomial signature $S = x \cdot 25000000 + y \cdot 5000 + z$. This defeats models because they fail to recognize the equivalence to finding the lexicographically first triangle, leading them to implement $O(n^3)$ or $O(m \cdot n)$ full-search algorithms that evaluate the polynomial for every valid triplet, which Time Out on the $n=2000, m=200000$ bounds.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem C — Matrix Coherence Signature

Time limit: 2 s   Memory limit: 256 MB

You are analyzing a symmetric $n \times n$ binary matrix $M$. The rows and columns are indexed from $1$ to $n$. Initially, all entries in the matrix are $0$.

You are provided with a list of $m$ active pairs. Each active pair specifies two distinct indices $u$ and $v$. For each active pair, the matrix entries $M[u][v]$ and $M[v][u]$ are set to $1$.

For any configuration of three distinct indices $x, y, z$ (where $x < y < z$), we define its *coherence score* as the sum of the three corresponding matrix entries:
$\text{Coherence} = M[x][y] + M[y][z] + M[z][x]$

You are guaranteed that the given active pairs will create at least one configuration with a coherence score of exactly $3$. Your task is to find such a configuration.

To ensure a unique and deterministic result, if there are multiple configurations with a coherence score of $3$, you must select the one that minimizes the *signature value* $S$, defined as:
$S = x \cdot 25000000 + y \cdot 5000 + z$

## Input
The first line contains two integers $n$ and $m$. The matrix dimension $n$ is at least 3 and at most 2000. The number of active pairs $m$ is at least 3 and at most 200000.

Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), representing an active pair that sets $M[u][v] = 1$ and $M[v][u] = 1$.

It is guaranteed that at least one configuration of three distinct indices will achieve a coherence score of 3.

## Output
Print three integers $x$, $y$, and $z$ on a single line, separated by spaces. These must be the indices of the configuration that achieves a coherence score of 3 and minimizes the signature value $S$. Ensure that $x < y < z$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
The problem is reframed as finding a specific configuration in a binary matrix rather than a triangle in a graph. The lexicographical tie-breaker is replaced by a polynomial signature $S$. This forces models to algebraically deduce that minimizing $S$ is equivalent to lexicographical sorting in order to safely use early-stopping algorithms; models that fail this deduction will implement exhaustive search loops that Time Out.
</RATIONALE>
<PRESERVED_ANSWER>
The base-like polynomial $S = x \cdot 25000000 + y \cdot 5000 + z$ is strictly monotonic with respect to the lexicographical order of $(x, y, z)$ given the bounds $\le 2000$, ensuring the identical configuration is always chosen.
</PRESERVED_ANSWER>

The problem still requires identifying a 3-clique (triangle) in an undirected graph, maintaining the exact same structural complexity.
</PRESERVED_CLASS>
