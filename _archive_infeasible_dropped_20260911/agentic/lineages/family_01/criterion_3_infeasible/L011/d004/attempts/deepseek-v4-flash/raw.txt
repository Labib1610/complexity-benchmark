We can solve this by representing the graph with adjacency sets and then checking each possible triple in lexicographical order until we find a triangle.

Since \( n \leq 2000 \), we can iterate over all pairs \((a, b)\) and check if there is a common neighbor \( c > b \) that is connected to both.  
We can use bitsets for fast intersection checks.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if b not in adj[a]:
                continue
            # Find common neighbors > b
            common = adj[a] & adj[b]
            for c in sorted(common):
                if c > b:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
