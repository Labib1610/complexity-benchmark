```python
import sys
from sys import stdin

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [set() for _ in range(n+1)]
    edges = set()
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        adj[u].add(v)
        adj[v].add(u)
        edges.add((min(u,v), max(u,v)))
    
    best = None
    # For each vertex, check pairs of neighbors
    for c in range(1, n+1):
        neighbors = sorted(adj[c])
        for i in range(len(neighbors)):
            for j in range(i+1, len(neighbors)):
                a, b = neighbors[i], neighbors[j]
                if b in adj[a]:  # edge a-b exists
                    trio = tuple(sorted([a, b, c]))
                    if best is None or trio < best:
                        best = trio
    
    print(best[0], best[1], best[2])

solve()
```

Let me optimize. A better approach: iterate over all edges (u,v), and for each edge, find common neighbors w where w > v (to avoid duplicates) or just find any common neighbor and track the lex smallest trio.

For each edge (u,v) with u < v, common neighbors are adj[u] ∩ adj[v]. For each common neighbor w, the trio is (min(u,v,w), ..., max(u,v,w)).

To find lex smallest, I should process edges in order and for each edge, check common neighbors in sorted order.

Actually, let me think about complexity. Sum over edges of |adj[u] ∩ adj[v]| could be large. But total triangles is bounded. The issue is finding them efficiently.

A standard approach: orient edges from lower degree to higher degree (or lower index to higher index). Then for each vertex, for each out-neighbor, mark it, then for each out-neighbor's out-neighbors, check if marked. This finds each triangle once and has complexity O(m^{3/2}) or O(m × sqrt(m)).

Let me use the degree-based orientation:

```python
import sys

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [set() for _ in range(n+1)]
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        adj[u].add(v)
        adj[v].add(u)
    
    deg = [len(adj[i]) for i in range(n+1)]
    
    # Orient edges: lower degree -> higher degree, tie-break by index
    out_adj = [[] for _ in range(n+1)]
    for u in range(1, n+1):
        for v in adj[u]:
            if deg[u] < deg[v] or (deg[u] == deg[v] and u < v):
                out_adj[u].append(v)
    
    best = None
    marked = [0] * (n + 1)
    mark_val = 0
    
    for u in range(1, n+1):
        mark_val += 1
        for v in out_adj[u]:
            marked[v] = mark_val
        for v in out_adj[u]:
            for w in out_adj[v]:
                if marked[w] == mark_val:
                    trio = tuple(sorted([u, v, w]))
                    if best is None or trio < best:
                        best = trio
    
    print(best[0], best[1], best[2])

solve()
```
