By framing vertices as "components" and edges as "tests", the equation requires the sum of degrees to equal the cut size plus 6, which algebraically forces exactly 3 internal edges. <STATEMENT>
# Component Synergy

Time limit: 2 s   Memory limit: 256 MB

You are analyzing a system of $n$ components. The system is subjected to a series of $m$ tests. Each test activates exactly two distinct components.

For any component $i$, let $D(i)$ be the total number of tests that activate component $i$.

For any trio of distinct components $a, b$, and $c$, we define their "Isolation Boundary" $B(a, b, c)$ as the number of tests that activate exactly one component from the trio $\{a, b, c\}$ (meaning the other activated component is outside the trio).

Your task is to find a "synergistic trio". A trio of distinct components $a, b$, and $c$ (with $a < b < c$) is synergistic if it satisfies the following balance equation:

$D(a) + D(b) + D(c) = B(a, b, c) + 6$

## Input
The first line contains two integers $n$ and $m$. The integer $n$ ($3 \le n \le 2000$) defines the number of components. The integer $m$ ($3 \le m \le 200000$) defines the number of tests. It is guaranteed that $m \le n(n-1)/2$.

Each of the following $m$ lines corresponds to a test. For $k$ from $1$ to $m$, the $k$-th of these lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating the components activated in test $k$. No two tests will specify the exact same pair of components $\{u, v\}$.

It is guaranteed that at least one synergistic trio exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, with $a < b < c$. These integers must form a valid synergistic trio as described above. 

If there are multiple valid trios, output the one that is lexicographically smallest. This means you should output the trio with the smallest value for $a$; if there is a tie, choose the one with the smallest value for $b$; and if a tie remains, choose the one with the smallest value for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
I replaced the sequence-based polynomial equation with a structural balance equation between a component's total activations and the trio's "Isolation Boundary" (cut size). This forces the model to algebraically derive the relationship between degree sums and cut sizes to realize the condition requires exactly 3 internal edges (a triangle).
</RATIONALE>
<PRESERVED_ANSWER>
The balance equation algebraically simplifies to requiring exactly 3 internal edges among the trio, which is identical to the original equation's requirement, so all valid trios remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a triangle (a 3-clique) in an undirected graph, maintaining the exact same computational complexity class and intended algorithm.
</PRESERVED_CLASS>
<RISK>
The phrase "exactly one component from the trio" could be misinterpreted if a reader forgets that a test activates exactly two components in total, though the parenthetical clarification heavily mitigates this risk.
</RISK>
