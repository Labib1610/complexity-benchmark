We can solve this by checking all triples, but that would be too slow for \( n = 2000 \).  
Instead, we can use the fact that if a triangle exists, we can find it efficiently by iterating over edges and checking common neighbors.

Here’s the approach:

1. Store the graph as an adjacency set for fast lookups.
2. Iterate over each edge `(u, v)`.
3. For each neighbor `w` of `u`, check if `(v, w)` is also an edge.
4. If yes, we have a triangle.  
5. Keep track of the lexicographically smallest triangle.

Since we only need the smallest triangle, we can sort the vertices of each found triangle and compare.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
        edges.append((u, v))

    best = None
    for u, v in edges:
        # Check common neighbors of u and v
        if len(adj[u]) > len(adj[v]):
            small, large = v, u
        else:
            small, large = u, v
        for w in adj[small]:
            if w in adj[large]:
                tri = tuple(sorted((u, v, w)))
                if best is None or tri < best:
                    best = tri
        if best is not None and best[0] == 1:
            # Early exit if we found smallest possible a
            pass

    print(*best)

if __name__ == "__main__":
    main()
```
