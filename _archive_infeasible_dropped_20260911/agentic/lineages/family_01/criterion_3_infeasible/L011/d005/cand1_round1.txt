<METHOD_NAME>Incidence Matrix Dot Product</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the graph adjacency list with an incidence matrix representation, where each input pair is treated as a coordinate in an m-dimensional space. Adjacency is redefined as a strictly positive dot product between two sequences, forcing the model to algebraically deduce the graph structure rather than relying on standard graph parsing.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<STATEMENT>
# Problem C — Sequence Resonance

Time limit: 2 s   Memory limit: 256 MB

You are analyzing a system of $n$ sequences, denoted $S_1, S_2, \ldots, S_n$. Each sequence has a length of exactly $m$ elements, and all elements are initially set to $0$.

The system's configuration is defined by a list of $m$ operations. For each $k$ from $1$ to $m$, the $k$-th operation specifies two distinct sequence indices $u$ and $v$. This operation modifies the $k$-th position of the sequences by setting $S_u[k] = 1$ and $S_v[k] = 1$. The $k$-th position of all other sequences remains $0$.

Your task is to find a "resonance" among the sequences. A resonance is formed by three distinct sequence indices $a$, $b$, and $c$ (with $a < b < c$) such that the standard dot product of any two of these three sequences is strictly positive. 

Specifically, you must find $a < b < c$ satisfying:
$S_a \cdot S_b > 0$
$S_a \cdot S_c > 0$
$S_b \cdot S_c > 0$

The dot product of two sequences $X$ and $Y$ of length $m$ is defined as $\sum_{i=1}^m X[i] \times Y[i]$.

## Input
The first line contains two integers $n$ and $m$. The integer $n$ ($3 \le n \le 2000$) defines the number of sequences. The integer $m$ ($3 \le m \le 200000$) defines the length of each sequence and the number of operations. It is guaranteed that $m \le n(n-1)/2$.

Each of the following $m$ lines corresponds to an operation. For $k$ from $1$ to $m$, the $k$-th of these lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that for operation $k$, $S_u[k] = 1$ and $S_v[k] = 1$. No two operations will specify the exact same pair of indices $\{u, v\}$.

It is guaranteed that at least one valid resonance exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, with $a < b < c$. These integers must form a valid resonance as described above. 

If there are multiple valid trios, output the one that is lexicographically smallest. This means you should output the trio with the smallest value for $a$; if there is a tie, choose the one with the smallest value for $b$; and if a tie remains, choose the one with the smallest value for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
Changed the framing from a symmetric boolean function (which models easily map to a graph adjacency matrix) to $n$ sequences of length $m$, where each input pair sets the $k$-th bit of exactly two sequences. The requirement to find a mutually satisfying trio is redefined as finding three sequences that have pairwise strictly positive dot products. This forces the model to algebraically deduce that a positive dot product implies the two sequences were modified together in some operation, requiring it to reconstruct the graph structure from first principles rather than relying on surface-level keyword matching.
</RATIONALE>
<PRESERVED_ANSWER>
Two sequences have a positive dot product if and only if they share a '1' at some index $k$, which exactly corresponds to their indices being provided together in the $k$-th input pair; thus the valid triplets are exactly the triangles in the original graph.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains fundamentally equivalent to finding a triangle (K3) in an undirected graph, which is solvable in polynomial time and retains the exact same time and space complexity.
</PRESERVED_CLASS>
<RISK>
Models might attempt to literally allocate $n$ arrays of size $m$ (which would exceed memory limits) instead of recognizing the underlying graph, but this is an intended penalty for failing to reason abstractly, not an ambiguity in the text.
</RISK>
