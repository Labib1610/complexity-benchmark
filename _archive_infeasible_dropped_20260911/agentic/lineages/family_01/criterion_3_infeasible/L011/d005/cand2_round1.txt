<STATEMENT>
# Problem C — Triadic Resonance

Time limit: 2 s   Memory limit: 256 MB

Consider $n$ variables $x_1, x_2, \ldots, x_n$. You are given an algebraic expression $P$ consisting of a sum of $m$ terms:
$P = \sum_{k=1}^m x_{u_k} x_{v_k}$
where each of the $m$ terms is a product of two distinct variables. All terms have a coefficient of 1, and no two terms have the exact same pair of variables. 

We define a new expression $Q$ by multiplying $P$ by the sum of all $n$ variables:
$Q = P \times (x_1 + x_2 + \ldots + x_n)$

When $Q$ is fully expanded and like terms are combined, the result consists of various terms. Some of these are products of three distinct variables, taking the form $C \cdot x_a x_b x_c$, where $a, b,$ and $c$ are distinct indices and $C$ is the integer coefficient. (As in standard algebra, the order of variables in a product does not matter, so $x_a x_b x_c$ is the same as $x_c x_b x_a$).

Your task is to find three distinct indices $a, b,$ and $c$ such that the coefficient $C$ of the term $x_a x_b x_c$ in the expanded expression $Q$ is exactly 3.

## Input
The first line contains two integers $n$ and $m$. The integer $n$ ($3 \le n \le 2000$) specifies the number of variables. The integer $m$ specifies the number of terms in $P$. The value of $m$ is at least 3 and will never exceed the maximum possible number of distinct pairs that can be formed from $n$ variables (i.e., $m \le n(n-1)/2$). It is guaranteed that $m \le 200000$.

Each of the following $m$ lines contains two integers $u_k$ and $v_k$ ($1 \le u_k, v_k \le n$, $u_k \ne v_k$), indicating that the term $x_{u_k} x_{v_k}$ is present in the expression $P$. 

It is guaranteed that at least one valid combination of three indices exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, with $a < b < c$. These integers must represent the indices of a term $x_a x_b x_c$ in $Q$ that has a coefficient of exactly 3. 

If there are multiple valid sets of indices, output the one that is lexicographically smallest. This means you should output the trio with the smallest value for $a$; if there is a tie, choose the one with the smallest value for $b$; and if a tie remains, choose the one with the smallest value for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
I reframed the problem from finding a triad in a boolean function to finding a term with a coefficient of 3 in the algebraic expansion of a product of two expressions. This forces the model to mathematically deduce that the coefficient equals 3 if and only if all three pairs of variables are present in the initial expression, and then recognize this as equivalent to finding a triangle in a graph to apply the optimal $O(nm/64)$ bitset algorithm instead of an intractable simulation or naive loop.
</RATIONALE>
<PRESERVED_ANSWER>
The coefficient of $x_a x_b x_c$ in $Q$ is exactly the number of pairs among the three variables that are present in $P$, so a coefficient of 3 corresponds exactly to a mutually satisfying trio in the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure is identical (finding a triangle in an undirected graph), meaning the same optimal $O(nm/64)$ bitset intersection algorithm is the intended solution, preserving the complexity class.
</PRESERVED_CLASS>

Models might misinterpret "fully expanded and like terms are combined" if they consider $x_a^2 x_b$ terms, but the prompt explicitly restricts the target to terms with three distinct variables $x_a x_b x_c$, mitigating this risk.
</RISK>
