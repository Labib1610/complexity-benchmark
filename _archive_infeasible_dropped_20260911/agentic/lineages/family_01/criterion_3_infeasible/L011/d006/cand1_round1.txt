Because absolute values cannot be simply algebraically expanded, models must perform case-based reasoning on the possible values at each sequence index to deduce that the equation counts the number of shared operations (edges) and requires exactly 3 of them (a triangle).</METHOD_DESCRIPTION>

<STATEMENT>
# Problem C — Sequence Resonance

Time limit: 2 s   Memory limit: 256 MB

You are analyzing a system of $n$ sequences, denoted $S_1, S_2, \ldots, S_n$. Each sequence has a length of exactly $m$ elements, and all elements are initially set to $0$.

The system's configuration is defined by a list of $m$ operations. For each $k$ from $1$ to $m$, the $k$-th operation specifies two distinct sequence indices $u$ and $v$. This operation modifies the $k$-th position of the sequences by setting $S_{\min(u,v)}[k] = 1$ and $S_{\max(u,v)}[k] = -1$. The $k$-th position of all other sequences remains $0$.

Your task is to find a "resonance" among the sequences. A resonance is formed by three distinct sequence indices $a$, $b$, and $c$ (with $a < b < c$) such that the sequences satisfy the following equation based on their absolute values:

$\sum_{k=1}^m |S_a[k] + S_b[k] + S_c[k]| = \sum_{k=1}^m \left( |S_a[k]| + |S_b[k]| + |S_c[k]| \right) - 6$

## Input
The first line contains two integers $n$ and $m$. The integer $n$ ($3 \le n \le 2000$) defines the number of sequences. The integer $m$ ($3 \le m \le 200000$) defines the length of each sequence and the number of operations. It is guaranteed that $m \le n(n-1)/2$.

Each of the following $m$ lines corresponds to an operation. For $k$ from $1$ to $m$, the $k$-th of these lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating the sequences modified in operation $k$. No two operations will specify the exact same pair of indices $\{u, v\}$.

It is guaranteed that at least one valid resonance exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, with $a < b < c$. These integers must form a valid resonance as described above. 

If there are multiple valid trios, output the one that is lexicographically smallest. This means you should output the trio with the smallest value for $a$; if there is a tie, choose the one with the smallest value for $b$; and if a tie remains, choose the one with the smallest value for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
Changed the operation semantics to assign deterministic 1 and -1 values, and replaced the pairwise positive dot-product requirement with a single absolute value equation over the three sequences. This forces models to step away from pattern-matching "dot product > 0" to "graph edges", and instead perform case-based semantic reasoning to deduce that the equation is satisfied if and only if the three sequences mutually share exactly three operations (i.e., form a triangle).
</RATIONALE>
<PRESERVED_ANSWER>
The absolute value equation's difference evaluates to exactly twice the number of operations shared exclusively between pairs in the triad, meaning it only equals 6 when they form a triangle in the input graph, keeping all valid triads identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying mathematical structure remains exactly finding a triangle in an undirected graph defined by the input pairs, maintaining the identical complexity class and intended bitset algorithm.
</PRESERVED_CLASS>
