<METHOD_NAME>Anti-Symmetric Position-Dependent Assignment</METHOD_NAME>
<METHOD_DESCRIPTION>Instead of assigning 1s to both sequences in an operation (creating an obvious positive dot product), we assign k*(u-v) and k*(v-u). This makes the values signed, dependent on the sequence indices, and dependent on the position k. The target condition is changed from a positive dot product to a strictly negative dot product. This breaks the immediate heuristic that operations simply define undirected positive edges, forcing the model to algebraically deduce that the dot product is -k^2*(u-v)^2 < 0 to realize it's still just finding a triangle in the operation graph.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem C — Sequence Resonance

Time limit: 2 s   Memory limit: 256 MB

You are analyzing a system of $n$ sequences, denoted $S_1, S_2, \ldots, S_n$. Each sequence has a length of exactly $m$ elements, and all elements are initially set to $0$.

The system's configuration is defined by a list of $m$ operations. For each $k$ from $1$ to $m$, the $k$-th operation specifies two distinct sequence indices $u$ and $v$. This operation modifies the $k$-th position of the sequences by setting $S_u[k] = k \times (u - v)$ and $S_v[k] = k \times (v - u)$. The $k$-th position of all other sequences remains $0$.

Your task is to find a "resonance" among the sequences. A resonance is formed by three distinct sequence indices $a$, $b$, and $c$ (with $a < b < c$) such that the standard dot product of any two of these three sequences is strictly negative. 

Specifically, you must find $a < b < c$ satisfying:
$S_a \cdot S_b < 0$
$S_a \cdot S_c < 0$
$S_b \cdot S_c < 0$

The dot product of two sequences $X$ and $Y$ of length $m$ is defined as $\sum_{i=1}^m X[i] \times Y[i]$.

## Input
The first line contains two integers $n$ and $m$. The integer $n$ ($3 \le n \le 2000$) defines the number of sequences. The integer $m$ ($3 \le m \le 200000$) defines the length of each sequence and the number of operations. It is guaranteed that $m \le n(n-1)/2$.

Each of the following $m$ lines corresponds to an operation. For $k$ from $1$ to $m$, the $k$-th of these lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating the indices used in operation $k$. No two operations will specify the exact same pair of indices $\{u, v\}$.

It is guaranteed that at least one valid resonance exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, with $a < b < c$. These integers must form a valid resonance as described above. 

If there are multiple valid trios, output the one that is lexicographically smallest. This means you should output the trio with the smallest value for $a$; if there is a tie, choose the one with the smallest value for $b$; and if a tie remains, choose the one with the smallest value for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
I changed the operation semantics from assigning two `1`s to assigning position- and index-dependent signed values `$k \times (u - v)$` and `$k \times (v - u)$`. I also updated the resonance target from a strictly positive dot product to a strictly negative one. This removes the obvious affordance that every input pair trivially forms a positive edge, forcing models to algebraically deduce that the dot product of two sequences sharing an operation is always strictly negative in order to realize the problem still reduces to finding a triangle in the input graph.
</RATIONALE>
<PRESERVED_ANSWER>
Because any two sequences $a$ and $b$ sharing an operation $k$ receive values $k(a-b)$ and $k(b-a)$, their dot product evaluates exactly to $-k^2(a-b)^2 < 0$, whereas sequences not sharing an operation have a dot product of 0; thus the pairs satisfying the new strictly negative condition are identical to those satisfying the original strictly positive condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically first triangle in an undirected graph, keeping it in the same complexity class.
</PRESERVED_CLASS>
