<STATEMENT>
# Problem C — Sequence Resonance

Time limit: 2 s   Memory limit: 256 MB

You are analyzing a system of $n$ sequences, denoted $S_1, S_2, \ldots, S_n$. Each sequence has a length of exactly $m$ elements, and all elements are initially set to $0$.

The system's configuration is defined by a list of $m$ operations. For each $k$ from $1$ to $m$, the $k$-th operation specifies two distinct sequence indices $u$ and $v$. This operation modifies the $k$-th position of the sequences by setting $S_u[k] = 1$ and $S_v[k] = 1$. The $k$-th position of all other sequences remains $0$.

For any sequence $x$, its *total weight* $D(x)$ is defined as the sum of its elements:
$D(x) = \sum_{i=1}^m S_x[i]$

For any two sequences $x$ and $y$, their *discrepancy* $W(x, y)$ is defined as the sum of the absolute differences of their corresponding elements:
$W(x, y) = \sum_{i=1}^m |S_x[i] - S_y[i]|$

Your task is to find a "resonance" among the sequences. A resonance is formed by three distinct sequence indices $a$, $b$, and $c$ (with $a < b < c$) such that for every pair among these three sequences, the sum of their total weights strictly exceeds their discrepancy.

Specifically, you must find $a < b < c$ satisfying:
$D(a) + D(b) > W(a, b)$
$D(a) + D(c) > W(a, c)$
$D(b) + D(c) > W(b, c)$

## Input
The first line contains two integers $n$ and $m$. The integer $n$ ($3 \le n \le 2000$) defines the number of sequences. The integer $m$ ($3 \le m \le 200000$) defines the length of each sequence and the number of operations. It is guaranteed that $m \le n(n-1)/2$.

Each of the following $m$ lines corresponds to an operation. For $k$ from $1$ to $m$, the $k$-th of these lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that for operation $k$, $S_u[k] = 1$ and $S_v[k] = 1$.

It is guaranteed that at least one valid resonance exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, with $a < b < c$. These integers must form a valid resonance as described above. 

If there are multiple valid trios, output the one that is lexicographically smallest. This means you should output the trio with the smallest value for $a$; if there is a tie, choose the one with the smallest value for $b$; and if a tie remains, choose the one with the smallest value for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
The direct dot product condition was replaced with a mathematically equivalent algebraically obfuscated condition based on total weight and absolute discrepancy. Evaluating this naively takes O(n^2 m) time which will exceed the 2-second time limit, forcing models to perform genuine mathematical reasoning to simplify the condition to $2 \times (\text{shared operations}) > 0$, thereby revealing that they only need to check the sparse input edges. To address the previous gate rejection, the explicit sentence forbidding duplicate operations was removed to strictly adhere to the original I/O contract.
</RATIONALE>
<PRESERVED_ANSWER>
For any binary sequences, $D(a) + D(b) - W(a, b)$ is exactly twice the number of positions where both sequences are 1, meaning the new condition is strictly equivalent to the original positive dot product condition for all possible inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying mathematical task is still exactly finding a 3-clique (triangle) in the graph defined by the input operations, maintaining the identical computational complexity class.
</PRESERVED_CLASS>
