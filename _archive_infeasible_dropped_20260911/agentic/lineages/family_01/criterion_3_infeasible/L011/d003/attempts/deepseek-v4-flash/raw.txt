We can solve this by checking all triples, but that would be too slow for \( n = 2000 \).  
Instead, we can use the fact that if a triangle exists, we can find one efficiently by iterating over edges and checking common neighbors.

Here’s the approach:

- Store the graph as an adjacency set for fast lookups.
- Iterate over each edge `(u, v)`.
- For each neighbor `w` of `u`, check if `(v, w)` is also an edge.
- If yes, we have a triangle.  
- Keep track of the lexicographically smallest triangle.

Since we only need one triangle, we can stop early once we find the smallest possible.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
        edges.append((u, v))

    best = None
    for u, v in edges:
        # Ensure u < v for consistent iteration
        if u > v:
            u, v = v, u
        # Check common neighbors
        for w in adj[u]:
            if w > v and w in adj[v]:
                # Found triangle (u, v, w)
                if best is None or (u, v, w) < best:
                    best = (u, v, w)
        # Early exit if we found the smallest possible starting with 1
        if best is not None and best[0] == 1:
            # Still need to check if there's a smaller b, but since we iterate edges sorted,
            # we can break when u > best[0]
            pass

    # Since we want smallest lexicographically, we can just sort all found triangles
    # But we can also just scan all edges and keep min
    # The above loop already keeps min, but we need to ensure we check all.
    # Let's do a full scan properly:
    best = None
    for u, v in edges:
        if u > v:
            u, v = v, u
        for w in adj[u]:
            if w > v and w in adj[v]:
                cand = (u, v, w)
                if best is None or cand < best:
                    best = cand
    print(*best)

if __name__ == "__main__":
    main()
```
