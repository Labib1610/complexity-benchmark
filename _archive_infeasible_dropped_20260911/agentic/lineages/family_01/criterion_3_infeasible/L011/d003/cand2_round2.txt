<STATEMENT>
# Problem C — Proof of Contradiction

Time limit: 2 s   Memory limit: 256 MB

A specialized facility needs to divide its chemical inventory into two stable storage environments: cold and ambient. However, safety protocols maintain a log of reactive pairs. Each entry in this log specifies exactly two chemicals that will violently react if placed in the same storage environment.

It has been determined that creating a valid two-environment assignment for the entire inventory is impossible due to inherent contradictions in the log. To officially close the allocation attempt, you must provide a specific proof of this impossibility.

Specifically, you need to isolate a three-way deadlock. This occurs when three distinct chemicals are mutually incompatible: checking the log for any two of these three chemicals will reveal they are explicitly listed as a reactive pair. The log is guaranteed to contain at least one such trio of chemicals. You must identify one such group.

## Input
The first line provides two integers $n$ and $m$. The number of chemicals $n$ is at least 3. The facility has exactly 2000 containment units, which imposes a strict maximum limit on $n$ (so $n \le 2000$). The number of logged reactive pairs $m$ is at least 3. The safety database has a hard storage limit of 200000 entries, so $m$ will not exceed 200000, nor will it exceed the maximum possible number of pairs formed by the present chemicals.

Each of the subsequent $m$ lines contains two integers $u$ and $v$ — the ID numbers of the two chemicals in a reactive pair. Chemicals are identified by numbers from 1 to $n$.

It is guaranteed that at least one three-way deadlock involving three chemicals exists in the log.

## Output
Print three integers $a$, $b$, and $c$ on a single line with $a < b < c$, representing the ID numbers of the three chemicals in the deadlock. The log must contain the reactive pairs involving $a$ and $b$, $a$ and $c$, and $b$ and $c$. If there are multiple valid groups, output the one with the smallest value for $a$; in case of a tie, the one with the smallest value for $b$; and if still tied, the one with the smallest value for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
Changed the scenario from employee shifts to chemical storage. Replaced the set-theoretic definition of a "complete deadlock" (2-element subsets) with a natural language description of a "three-way deadlock" where any two of the three distinct items are mutually incompatible. This forces the model to synthesize the requirement of finding a 3-clique from the logical interactions rather than relying on standard set terminology that often triggers graph algorithms. Expressed the numeric bounds as physical containment and database limits to satisfy the strategy while retaining exact numbers to pass explicit bound checks.
</RATIONALE>
<PRESERVED_ANSWER>
The required output is identically the lexicographically smallest three items where all three pairs are present in the input constraints, so the answer for any given input graph remains exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Finding a specific configuration of three mutually constrained elements is exactly equivalent to finding a 3-clique (triangle) in an undirected graph, keeping the time complexity at O(n*m/64) using bitsets, so the complexity class is unchanged.
</PRESERVED_CLASS>
<RISK>
Students might misinterpret "maximum possible number of pairs formed by the present chemicals" if they don't realize it means n(n-1)/2, but the explicit 200000 bound prevents any real issue.
</RISK>
