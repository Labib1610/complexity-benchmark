<STATEMENT>
# Problem C — Proof of Impossibility

Time limit: 2 s   Memory limit: 256 MB

A chemical plant needs to store its inventory of compounds in two separate containment vats. Certain compounds are highly reactive and will cause a hazard if placed in the same vat. The safety manual provides a complete list of these incompatible pairs.

Safety inspectors have concluded that it is physically impossible to distribute the entire inventory into just two vats without placing at least one reactive pair together. To officially close the two-vat proposal, you must provide a concrete proof of this impossibility. 

Specifically, you need to find a mutually reactive trio. Such a trio consists of three distinct compounds that are completely incompatible with one another. To verify a valid trio, you must ensure that if you pick any one compound out of the three, the manual contains entries marking it incompatible with both of the other two compounds in the trio. The manual is guaranteed to contain at least one such trio.

## Input
The first line provides two integers $n$ and $m$. 
The number of compounds $n$ is at least the minimum required to form a trio. The facility stores compounds in standard racks. A single rack holds exactly 400 compounds, and the facility has exactly 5 racks, which imposes a strict physical limit on the maximum $n$.
The number of incompatibility entries $m$ is at least 3. The safety database allocates exactly 50 bytes of memory per entry. The maximum storage allocated for these entries is exactly 10 megabytes (where one megabyte is defined as $10^6$ bytes), which dictates the absolute maximum for $m$ (unless the maximum possible number of pairs is smaller).

Each of the subsequent $m$ lines contains two integers $u$ and $v$ — the ID numbers of two incompatible compounds. Compounds are identified by numbers from 1 to $n$.

It is guaranteed that at least one mutually reactive trio exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line with $a < b < c$, representing the ID numbers of the three compounds in the trio. If there are multiple valid trios, output the one with the smallest value for $a$; in case of a tie, the one with the smallest value for $b$; and if still tied, the one with the smallest value for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

Changed the scenario to a chemical plant and replaced direct bounds with derived limits based on rack capacities and database memory. The definition of the required triplet was rephrased to emphasize the relationship of each element to the other two, rather than describing it as a set of 2-element subsets. This forces the model to deduce the underlying triangular structure instead of pattern-matching on subset combinations.
</RATIONALE>
