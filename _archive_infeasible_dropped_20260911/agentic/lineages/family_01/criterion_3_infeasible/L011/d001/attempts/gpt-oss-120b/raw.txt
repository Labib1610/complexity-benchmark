**Solution Explanation**

For three different employees `a < b < c` we need all three incompatibility
edges  

```
(a , b) , (a , c) , (b , c)
```

i.e. a *triangle* in the undirected graph of incompatibilities.
The input guarantees that at least one triangle exists and we have to output
the lexicographically smallest one.

--------------------------------------------------------------------

#### 1.   Data structure – bitset

`n ≤ 2000`, therefore a 2000‑bit bitset fits into a single Python integer.
For every vertex `v` we store

```
adj[v]  – integer whose i‑th bit (0‑based) is 1  ⇔  edge (v , i+1) exists
```

All operations we need are then O(1) bit operations:

* `adj[u] & adj[v]` – vertices adjacent to **both** `u` and `v`
* `x & -x` – lowest set bit of `x`
* `bit_length()` – index of that bit

--------------------------------------------------------------------

#### 2.   Searching triangles in lexicographic order  

We iterate `a` from `1` to `n`.
For the current `a` we look at its neighbours `b` with `b > a`
(in increasing order – we keep the neighbour list sorted).

For a fixed pair `(a , b)` the vertices that close a triangle are exactly

```
common = adj[a] & adj[b]          # neighbours of both
```

Only vertices larger than `b` are allowed, otherwise the order `a<b<c`
would be violated.  
Mask out the lower bits:

```
mask = ~((1 << (b)) - 1)          # bits b+1 … n-1 are 1, lower bits 0
common &= mask
```

If `common` is non‑zero, the lowest set bit gives the smallest possible `c`
for this `(a , b)`.  
Because we scan `a` increasingly, then `b` increasingly, and finally take the
smallest `c`, the first triangle we encounter is exactly the required
lexicographically minimal one.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest triangle.

---

##### Lemma 1  
For any pair of vertices `a < b` the set `common = adj[a] & adj[b]` contains
exactly the vertices adjacent to **both** `a` and `b`.

**Proof.** By definition of `adj`, bit `i` of `adj[a]` is 1 iff edge `(a,i+1)`
exists, similarly for `adj[b]`. Bitwise AND keeps a bit 1 only when it is 1
in both operands, i.e. when the edge to that vertex exists from both `a` and
`b`. ∎



##### Lemma 2  
After masking `common` with `mask = ~((1 << b) - 1)`,
the remaining set bits correspond precisely to vertices `c` with `c > b`
that together with `a , b` form a triangle.

**Proof.** `mask` has zeros on positions `0 … b-1` and ones elsewhere.
AND-ing removes all vertices `c ≤ b`. By Lemma&nbsp;1 the unmasked bits are
exactly the common neighbours of `a` and `b`. Hence the remaining bits are
exactly the common neighbours larger than `b`. ∎



##### Lemma 3  
If `common` after masking is non‑zero, the vertex `c` obtained from the
lowest set bit is the smallest possible `c` that together with the current
`a , b` forms a triangle.

**Proof.** The lowest set bit of a positive integer corresponds to the smallest
index whose bit is 1. By Lemma&nbsp;2 all set bits are admissible `c` values,
therefore the lowest one is the minimal `c`. ∎



##### Lemma 4  
The algorithm outputs a triangle.

**Proof.** The input guarantees at least one triangle.
Consider the first iteration where the algorithm finds a non‑empty masked
`common`. By Lemma&nbsp;3 we obtain a vertex `c` such that edges
`(a,b) , (a,c) , (b,c)` exist, i.e. a triangle, which is printed. ∎



##### Lemma 5  
Let `(a₀,b₀,c₀)` be the triangle printed by the algorithm.
For any other triangle `(a',b',c')` we have
`(a₀,b₀,c₀)` lexicographically ≤ `(a',b',c')`.

**Proof.** The outer loop enumerates `a` in increasing order.
The first `a` for which a triangle is found is therefore the smallest possible
`a` among all triangles.  
Fix this `a = a₀`. Inside, neighbours `b` are examined in increasing order,
so the first `b` that yields a triangle is the smallest possible `b` among
triangles with `a = a₀`.  
Finally, for this pair `(a₀,b₀)` Lemma&nbsp;3 gives the smallest feasible `c`.
Thus no triangle can have a smaller `a`, nor the same `a` and a smaller `b`,
nor the same `a,b` and a smaller `c`. ∎



##### Theorem  
The algorithm always prints the lexicographically smallest triple
`a < b < c` that forms a triangle in the given graph.

**Proof.** By Lemma&nbsp;4 the algorithm prints a triangle.
By Lemma&nbsp;5 this triangle is lexicographically minimal among all triangles.
∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency* – `O(m)`  
*Neighbour lists* – each edge stored twice, total `O(m)` memory.

Main loops: for every edge `(a,b)` with `a<b` we perform a constant‑time
bitwise AND and a few integer operations.
Thus `O(m)` time.

Memory: `n` integers of at most `n` bits → `O(n² / wordsize)` ≈ `2000·2000 / 64`
≈ 62 KB, plus neighbour lists `O(m)` (≤ 200 000 integers). Well below limits.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * (n + 1)          # 1‑based, bit i‑1 corresponds to vertex i
    neigh = [[] for _ in range(n + 1)]

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        if u == v:
            continue
        # store undirected edge
        adj[u] |= 1 << (v - 1)
        adj[v] |= 1 << (u - 1)
        if u < v:
            neigh[u].append(v)
        else:
            neigh[v].append(u)

    # sort neighbour lists to guarantee increasing order
    for lst in neigh:
        lst.sort()

    full_mask = (1 << n) - 1

    for a in range(1, n + 1):
        for b in neigh[a]:          # b > a by construction
            # common neighbours of a and b
            common = adj[a] & adj[b]
            # keep only vertices > b
            mask = full_mask ^ ((1 << b) - 1)   # bits b .. n-1 are 1
            common &= mask
            if common:
                low = common & -common
                c = low.bit_length()          # 1‑based index
                # c is already > b because of mask
                print(a, b, c)
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
