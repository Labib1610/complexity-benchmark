# Problem C — Shift Assignment Failure

Time limit: 2 s
Memory limit: 256 MB

The manufacturing plant requires all personnel to be assigned to either the morning schedule or the evening schedule. Certain pairs of employees have filed grievances against each other and cannot be placed on the same schedule. 

Management already knows that a valid assignment for everyone is unachievable. Your job is not to attempt an assignment, but to produce the documentation proving it will fail. A fundamental reason such an assignment fails is when three personnel are mutually incompatible—meaning the first cannot work with the second, the second cannot work with the third, and the first cannot work with the third. Since only two schedules exist, placing all three without a conflict is impossible. You must identify one such trio to serve as proof.

## Input
The first line contains two integers $n$ and $m$. The facility operates with a maximum capacity of 2000 personnel, which serves as the upper limit for the headcount $n$. The grievance logging system is hardcoded to accept up to 200000 entries, bounding the grievance count $m$. Both $n$ and $m$ are at least 3, and $m$ will never exceed the maximum possible number of distinct pairs among the personnel.

Each of the following $m$ lines contains two integers $u$ and $v$ — the ID numbers of a pair of employees who cannot share a schedule. Employees are numbered from 1 to $n$.

It is guaranteed that the records contain at least one trio of personnel who are all mutually incompatible.

## Output
Print three integers $a$, $b$, and $c$ on a single line with $a < b < c$, representing the ID numbers of the three personnel who all have grievances with one another. If there are multiple valid trios, output the one with the smallest value for $a$; in case of a tie, the smallest value for $b$; and if still tied, the smallest value for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
