<METHOD_DESCRIPTION>Replaced the L1-norm absolute value equation with the sum of squared determinants of $3 \times 3$ Vandermonde matrices formed by the sequence values. The determinant $(x-y)(y-z)(z-x)$ is non-zero (and squares to 4) if and only if the three values are exactly $\{1, -1, 0\}$, which corresponds to an edge in the operation graph. This forces models to symbolically expand and factor a determinant to discover the column-wise case analysis, breaking the simple algebraic affordance of the previous equation.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem C — Sequence Resonance

Time limit: 2 s   Memory limit: 256 MB

You are analyzing a system of $n$ sequences, denoted $S_1, S_2, \ldots, S_n$. Each sequence has a length of exactly $m$ elements, and all elements are initially set to $0$.

The system's configuration is defined by a list of $m$ operations. For each $k$ from $1$ to $m$, the $k$-th operation specifies two distinct sequence indices $u$ and $v$. This operation modifies the $k$-th position of the sequences by setting $S_{\min(u,v)}[k] = 1$ and $S_{\max(u,v)}[k] = -1$. The $k$-th position of all other sequences remains $0$.

Your task is to find a "resonance" among the sequences. A resonance is formed by three distinct sequence indices $a$, $b$, and $c$ (with $a < b < c$) such that they satisfy a specific algebraic property. 

For any chosen trio $a < b < c$ and for each position $k$ (from $1$ to $m$), define a $3 \times 3$ matrix $M_k$ as follows:

$$M_k = \begin{bmatrix} 1 & 1 & 1 \\ S_a[k] & S_b[k] & S_c[k] \\ S_a[k]^2 & S_b[k]^2 & S_c[k]^2 \end{bmatrix}$$

The trio forms a valid resonance if and only if the sum of the squared determinants of these matrices equals exactly 12:

$$\sum_{k=1}^m (\det M_k)^2 = 12$$

## Input
The first line contains two integers $n$ and $m$. The integer $n$ ($3 \le n \le 2000$) defines the number of sequences. The integer $m$ ($3 \le m \le 200000$) defines the length of each sequence and the number of operations. It is guaranteed that $m \le n(n-1)/2$.

Each of the following $m$ lines corresponds to an operation. For $k$ from $1$ to $m$, the $k$-th of these lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating the sequences modified in operation $k$. No two operations will specify the exact same pair of indices $\{u, v\}$.

It is guaranteed that at least one valid resonance exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, with $a < b < c$. These integers must form a valid resonance as described above. 

If there are multiple valid trios, output the one that is lexicographically smallest. This means you should output the trio with the smallest value for $a$; if there is a tie, choose the one with the smallest value for $b$; and if a tie remains, choose the one with the smallest value for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
The previous L1-norm equation strongly signaled a degree-sum or triangle inequality property, allowing models to easily deduce the graph triangle requirement. By replacing it with the sum of squared determinants of a Vandermonde matrix, the condition now looks like a continuous algebraic invariant. Models must symbolically factor the determinant and analyze the multisets to realize it only evaluates to 4 when all three sequence values are distinct (i.e., exactly {1, -1, 0}), thereby mapping back to an edge in the operation graph.
</RATIONALE>
<PRESERVED_ANSWER>
The squared determinant is exactly 4 if the column contains an operation between two of the three sequences, and 0 otherwise; thus, a sum of 12 enforces exactly 3 operations among the trio, perfectly preserving the original valid triplets.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
