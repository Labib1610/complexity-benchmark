We can model each sequence as a binary vector of length \( m \), where each operation sets two positions to 1.  
For a triple \((a,b,c)\), the sum inside the fourth power is just the number of sequences among \(a,b,c\) that have a 1 at that position. Since each position has exactly two 1s, the possible values for \(S_a[k] + S_b[k] + S_c[k]\) are:

- 0: none of the three have 1 at position \(k\)  
- 1: exactly one of them has 1  
- 2: exactly two of them have 1  
- 3: all three have 1 (impossible because each position has only two 1s)

So the sum can only be 0, 1, or 2.

The equation becomes:

\[
\sum_{k=1}^m (S_a[k] + S_b[k] + S_c[k])^4 = \sum_{k=1}^m (S_a[k] + S_b[k] + S_c[k]) + 42
\]

Let:
- \(x\) = number of positions where exactly one of \(a,b,c\) has 1  
- \(y\) = number of positions where exactly two of them have 1  
- \(z\) = number of positions where none of them have 1  

We have \(x + y + z = m\).

The left side: \(1^4 \cdot x + 2^4 \cdot y = x + 16y\)  
The right side: \(x + 2y + 42\)

So:

\[
x + 16y = x + 2y + 42
\]
\[
14y = 42
\]
\[
y = 3
\]

So the condition is: **exactly 3 positions where exactly two of the three sequences have 1**.

Now, each operation corresponds to an edge between two sequences.  
For a triple \((a,b,c)\), a position contributes to \(y\) if the edge for that position connects two of the three sequences.  
So \(y\) is exactly the number of edges among the triple in the graph.

Thus, we need to find a triple of vertices with exactly 3 edges among them — i.e., a triangle in the graph.

We need the lexicographically smallest triangle.

---

**Approach**:

- Build adjacency sets for each vertex.
- Iterate over \(a\) from 1 to n:
  - For each \(b > a\) that is adjacent to \(a\):
    - For each \(c > b\) that is adjacent to both \(a\) and \(b\):
      - If found, output and exit.

Since \(n \le 2000\), we can do this efficiently with sets.

---

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(n):
        for b in adj[a]:
            if b <= a:
                continue
            for c in adj[a]:
                if c <= b:
                    continue
                if c in adj[b]:
                    print(a+1, b+1, c+1)
                    return

if __name__ == "__main__":
    main()
```
