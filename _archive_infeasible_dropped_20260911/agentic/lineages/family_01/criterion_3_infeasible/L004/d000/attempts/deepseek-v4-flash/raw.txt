We can solve this by representing the graph with an adjacency matrix (or set) and then checking all triples in sorted order until we find a fully connected triangle.  

Since n is up to 2000, a full O(n³) check would be too slow, but we can optimize by only checking triples where the first two vertices are connected, and then checking the third.  

Here’s the implementation:  

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if b in adj[a]:
                for c in range(b + 1, n + 1):
                    if c in adj[a] and c in adj[b]:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    main()
```
