# Problem C — Proof of Impossibility

Time limit: 2 s
Memory limit: 256 MB

The factory's automated rostering system operates with only two shifts. You are given a centralized database of pairwise scheduling conflicts between workers. Because there are only two shifts, certain groups of workers cannot be scheduled. 

Your task is to generate a certificate of impossibility to prove that a valid roster cannot be formed. To process the database, every conflict report between two workers must be normalized into a directed dependency. Specifically, a dependency is established from the worker with the smaller ID to the worker with the larger ID, regardless of the order they appear in the report.

A valid certificate of impossibility is a sequence of three workers $a$, $b$, and $c$ such that $a < b < c$ and the normalized directed dependencies $a \to b$, $a \to c$, and $b \to c$ all exist. It is guaranteed that the database contains at least one such certificate.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n - 1) / 2, 2 \cdot 10^5)$), representing the number of workers and the number of conflict reports. Workers are identified by integers from $1$ to $n$.

Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), representing a conflict report between worker $u$ and worker $v$. Each unordered pair of conflicting workers appears at most once in the input.

## Output
Print three integers $a$, $b$, and $c$ on one line with $a < b < c$ such that the normalized dependencies $a \to b$, $a \to c$, and $b \to c$ all exist. If there are multiple valid certificates, output the lexicographically smallest such triple (smallest $a$; ties broken by smallest $b$; then smallest $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

I reframed the undirected conflict relationship into a normalized directed dependency (always flowing from the smaller ID to the larger ID) and defined the impossibility certificate as a specific directed tournament. This defeats models that rely on surface pattern matching (recognizing "scheduling conflicts" as a standard undirected triangle-finding problem) by forcing them to explicitly implement the normalization step and reason about directed arcs, while mathematically preserving the exact same valid sets of workers. I also removed the extraneous "three stages" narrative to improve clarity and restored the exact formal bounds in the Input section to satisfy strict contractual checks.
</RATIONALE>
<PRESERVED_ANSWER>
Because every undirected triangle between three workers uniquely maps to exactly one valid set of normalized directed dependencies conforming to $a < b < c$, the set of valid certificates remains perfectly identical for every possible input.
</PRESERVED_ANSWER>
