# Problem C — Proof of Impossibility

Time limit: 2 s   Memory limit: 256 MB

The factory's automated rostering system operates in three stages. In the first stage, it gathers directional scheduling dependencies into a centralized database. In the second stage—which is the component you must implement—the system must process a database that is already known to be hopelessly deadlocked. The factory has only two shifts, 1 and 2. Your job is not to assign shifts; rather, it is to generate a certificate of deadlock to pass to the third stage. The third stage will then consume this certificate to automatically trigger an expansion request for a third shift.

A valid certificate of deadlock consists of exactly three workers $a$, $b$, and $c$, with $a < b < c$, such that the database contains all three of the following directional dependencies:
- Worker $a$ must precede worker $b$
- Worker $a$ must precede worker $c$
- Worker $b$ must precede worker $c$

It is guaranteed that the database contains at least one such group of three workers. You must output one such group. If there are multiple valid certificates, you must output the lexicographically smallest such triple (smallest $a$; ties broken by smallest $b$; then smallest $c$).

## Input
The first line contains two integers $n$ and $m$ (3 ≤ n ≤ 2000, 3 ≤ m ≤ min(n·(n−1)/2, 2·10⁵)).
Each of the next $m$ lines contains two integers $u$ and $v$, indicating a directional dependency where worker $u$ must precede worker $v$.
It is guaranteed that at least one valid certificate exists.

## Output
Print three integers $a$, $b$, and $c$ on one line with $a < b < c$ representing the lexicographically smallest valid certificate.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
