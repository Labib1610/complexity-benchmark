We need to find the lexicographically smallest triangle in an undirected graph.  
Since \( n \) can be up to 2000 and \( m \) up to \( 2 \cdot 10^5 \), we can use an adjacency matrix (boolean) for fast edge checks.

We iterate over all triples in sorted order and check if all three edges exist.  
The first found will be the lexicographically smallest.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = adj[v][u] = True

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if not adj[a][b]:
                continue
            for c in range(b + 1, n + 1):
                if adj[a][c] and adj[b][c]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
