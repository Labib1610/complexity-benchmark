# Problem C — Proof of Impossibility

Time limit: 2 s   Memory limit: 256 MB

Management at the factory strictly maintains two working shifts, 1 and 2. A proposed schedule of worker restrictions is definitively invalid if any three workers are entirely mutually incompatible, meaning each individual in the trio cannot share a shift with either of the other two. Your objective is to formally certify that the provided schedule fails by pinpointing one such trio.

## Input
The first line provides two integers n and m (3 ≤ n ≤ 2000, 3 ≤ m ≤ min(n·(n−1)/2, 2·10⁵)), representing the number of workers and the number of restrictions.
The following m lines each contain two integers u v, indicating that worker u and worker v cannot be assigned to the same shift.

## Output
Print three integers a, b, and c on a single line, ordered such that a < b < c, where the pairs a–b, a–c, and b–c all appear in the restrictions. You must output the lexicographically smallest valid trio (prioritizing the smallest a, then the smallest b, and finally the smallest c).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
