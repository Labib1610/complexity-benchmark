# Problem C — Proof of Impossibility

Time limit: 2 s   Memory limit: 256 MB

The factory still has only two shifts, 1 and 2. Because the roster is known to be hopeless, your job is not to schedule. It is to certify the impossibility by finding a specific deadlock: a group of three workers where every worker in the group has a mutual grievance with the other two.

## Input
The first line contains two integers n and m (3 ≤ n ≤ 2000, 3 ≤ m ≤ min(n·(n−1)/2, 2·10⁵)).
Each of the next m lines contains two integers u v — a pair of workers who cannot be on the same shift.
The test data is drawn exclusively from cases that contain at least one such deadlocked group of three.

## Output
Print three integers a b c on one line with a < b < c such that all three pairs a–b, a–c, b–c share mutual grievances. If no such group existed, the correct output would be -1 (though the test data ensures at least one is present). Output the lexicographically smallest such group (smallest a; ties by smallest b; then smallest c).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
