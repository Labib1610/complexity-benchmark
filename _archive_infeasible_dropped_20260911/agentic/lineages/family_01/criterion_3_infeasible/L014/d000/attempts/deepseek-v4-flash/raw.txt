 We need to find the lexicographically smallest triangle in an undirected graph.  
A triangle is three vertices where all three edges exist between them.

We can solve this by iterating over vertices in increasing order and checking pairs of their neighbors.

**Approach:**
1. Read `n` and `m`.
2. Build an adjacency set for each vertex for O(1) edge lookup.
3. For each vertex `a` from 1 to n:
   - For each neighbor `b` of `a` where `b > a`:
     - For each neighbor `c` of `a` where `c > b`:
       - If edge `(b, c)` exists, we found a triangle `(a, b, c)`.
       - Since we iterate in increasing order, the first found is lexicographically smallest.
4. Print and exit.

This is efficient enough for `n ≤ 2000` and `m ≤ 2e5`.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        for b in adj[a]:
            if b > a:
                for c in adj[a]:
                    if c > b and c in adj[b]:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    main()
```
