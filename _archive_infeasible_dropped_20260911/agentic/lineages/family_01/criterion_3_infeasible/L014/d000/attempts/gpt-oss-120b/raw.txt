**Solution Explanation**

For every worker we store the set of workers he/she conflicts with.
Because `n ≤ 2000` we can store each set as a bitset inside a Python
integer – the *i*-th bit (0‑based) tells whether the worker conflicts with
worker `i+1`.

A triangle `a < b < c` exists iff

```
a–b   is an edge
a–c   is an edge
b–c   is an edge
```

If we already know that `a–b` is an edge, the workers that are adjacent to
both `a` and `b` are exactly the intersection of their neighbour sets:

```
common = neighbours[a]  ∧  neighbours[b]
```

From `common` we only need a vertex larger than `b`.  
The smallest such vertex gives the lexicographically smallest triangle,
because we enumerate `a` and `b` in increasing order.

The algorithm

```
for a = 0 … n-1:
    for b = a+1 … n-1:
        if edge a–b exists:
            common = adj[a] & adj[b]                # neighbours of both
            # keep only vertices > b
            mask   = ~((1 << (b+1)) - 1) & ((1 << n) - 1)
            common &= mask
            if common != 0:
                c = index of lowest set bit in common
                output a+1, b+1, c+1 and stop
```

The first triangle found is the lexicographically smallest one.

*Complexities*

* building the bitsets: `O(m)`
* double loop: at most `n·(n-1)/2 ≤ 2·10⁶` iterations, each does only a few
  integer operations → `O(n²)`
* memory: `n` integers, each ≤ `2ⁿ` → `O(n)` (≈ 2000·256 bytes)

Both limits easily satisfy the constraints.

**Reference Implementation (Python 3)**

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * n               # bitset for each vertex, 0‑based
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u] |= 1 << v
        adj[v] |= 1 << u

    full_mask = (1 << n) - 1
    for a in range(n):
        a_mask = adj[a]
        for b in range(a + 1, n):
            if (a_mask >> b) & 1:          # edge a–b ?
                common = a_mask & adj[b]   # neighbours of both
                # keep only vertices with index > b
                mask = full_mask ^ ((1 << (b + 1)) - 1)
                common &= mask
                if common:
                    # lowest set bit -> smallest c
                    low = common & -common
                    c = low.bit_length() - 1
                    print(a + 1, b + 1, c + 1)
                    return

if __name__ == "__main__":
    solve()
```
