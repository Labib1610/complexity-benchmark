# Problem C — Orbital Resonance Conflict

Time limit: 2 s   Memory limit: 256 MB

An orbital command center oversees a constellation of $n$ active satellites. Due to intersecting orbital planes, certain pairs of satellites exert a mutual gravitational resonance. To prevent destabilization, any two resonating satellites must be placed in different altitude bands. However, the center currently operates with exactly two available altitude bands.

The current flight plan is inherently unstable. Embedded within the telemetry data is at least one triplet of distinct satellites in which every satellite resonates with the other two in the triplet. Such a mutually resonating triplet cannot possibly be distributed safely across only two altitude bands.

Your objective is to extract one such triplet of satellites to demonstrate the instability of the flight plan.

The constellation consists of $n$ active satellites. The fleet is large enough to contain at least one triplet, but is constrained by a strict hardware ceiling of two thousand satellites. 

The telemetry logs contain $m$ distinct resonance links. There are at least enough links to form a triplet, but no more than two hundred thousand (or the maximum possible number of distinct pairs of satellites for the given fleet size, whichever is smaller).

Each satellite is designated by a unique registry code. These codes are positive integers. Due to legacy system limits, no registry code will ever exceed the station's hardware ceiling of two thousand. Because satellites are routinely commissioned and decommissioned, the $n$ active registry codes are not guaranteed to form a contiguous sequence starting from 1, nor are they bounded by $n$.

## Input
The first line of the telemetry data contains two integers, $n$ and $m$, representing the number of active satellites and the number of resonance links, respectively. (Their bounds are defined by the physical limits described above).

This is followed by $m$ lines, each containing two integers $u$ and $v$. These are the registry codes of two distinct satellites that share a resonance link.

It is guaranteed that the data contains at least one mutually resonating triplet.

## Output
Output a single line containing three space-separated integers $a$, $b$, and $c$, representing the registry codes of a mutually resonating triplet. These codes must be printed in strictly ascending order ($a < b < c$).

If the telemetry data contains more than one such triplet, you must output the one that is lexicographically smallest. Specifically, minimize $a$; if there is a tie, minimize $b$; and if a tie still remains, minimize $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
