**Solution Explanation**

For every qubit we store the set of qubits it resonates with.
Because `n ≤ 2000` a set can be kept as a *bitset* – a Python integer whose
binary representation has a `1` at position `v` iff the edge `(u , v)` exists.

```
adj[u]  – integer, bit v is 1  ⇔  edge (u , v) is present
```

A triangle `{a,b,c}` (`a<b<c`) exists **iff**

```
edge (a,b) exists                →  bit b in adj[a] is 1
c is adjacent to a and to b     →  bit c is 1 in both adj[a] and adj[b]
```

The lexicographically smallest triangle is obtained by scanning `a` from
`1 … n`, for each `a` scanning `b` from `a+1 … n`,
checking whether the edge `(a,b)` exists and, if it does,
looking for the smallest `c > b` that is adjacent to both `a` and `b`.

The intersection `adj[a] & adj[b]` is a bitset that contains **all**
common neighbours of `a` and `b`.  
Masking away bits `≤ b` leaves only candidates `c > b`.

```
common = adj[a] & adj[b]                # neighbours of both a and b
mask   = common & ~((1 << (b+1)) - 1)    # keep only bits > b
```

If `mask` is non‑zero, the lowest set bit gives the smallest possible `c`.
The index of that bit is obtained by

```
low = mask & -mask               # isolates lowest 1‑bit
c   = low.bit_length() - 1       # position of that bit (0‑based)
```

The first triple found during the ordered scan is exactly the required
lexicographically minimal one.

The algorithm works in  

* **Time**   `O(n²)`  ( ≤ 2 000 · 2 000 / 2 ≈ 2 · 10⁶ iterations, each O(1) )  
* **Memory** `O(n)`   (one integer per vertex)

Both limits satisfy the constraints.

#### Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest triangle.

---

##### Lemma 1  
For any vertices `a < b`, after the statement  

```
mask = (adj[a] & adj[b]) & ~((1 << (b+1)) - 1)
```

`mask` has a `1` at position `c` **iff** `c > b` and edges `(a,c)` and
`(b,c)` are present.

**Proof.**  
`adj[a] & adj[b]` has a `1` exactly at positions that are neighbours of
both `a` and `b`.  
`~((1 << (b+1)) - 1)` has `0` in bits `0 … b` and `1` elsewhere.
The bitwise `&` therefore clears all bits `≤ b` and keeps bits `> b`. ∎



##### Lemma 2  
If `mask ≠ 0` then  

```
c = (mask & -mask).bit_length() - 1
```

is the smallest vertex `c` such that `c > b` and edges `(a,c)`, `(b,c)` exist.

**Proof.**  
`mask & -mask` isolates the lowest set bit of `mask`.  
`bit_length() - 1` returns its index (0‑based).  
Because all set bits of `mask` correspond to vertices `> b` (Lemma&nbsp;1),
the isolated lowest one is the smallest such vertex. ∎



##### Lemma 3  
When the algorithm prints a triple `(a,b,c)` it is a triangle
(`a<b<c` and all three edges exist).

**Proof.**  
The outer loops guarantee `a<b`.  
The inner `if` checks that edge `(a,b)` exists.  
`c` is obtained from `mask` which, by Lemma&nbsp;1, contains only vertices
adjacent to both `a` and `b`.  
Thus edges `(a,c)` and `(b,c)` exist, and Lemma&nbsp;2 ensures `c>b`. ∎



##### Lemma 4  
Let `T = (a₀,b₀,c₀)` be the first triple printed by the algorithm.
For any triangle `T' = (a',b',c')` we have  
`a₀ < a'` or (`a₀ = a'` and `b₀ < b'`) or (`a₀ = a'` and `b₀ = b'` and `c₀ ≤ c'`).

**Proof.**  
The algorithm scans `a` in increasing order.
For a fixed `a` it scans `b` in increasing order.
Therefore the first examined pair `(a,b)` that belongs to any triangle is
lexicographically minimal among all such pairs.
When that pair is examined, `c` is chosen as the smallest possible
(`c > b`) by Lemma&nbsp;2.
Consequently the produced triple is lexicographically minimal among all
triangles. ∎



##### Theorem  
The algorithm outputs exactly the lexicographically smallest triple
`(a,b,c)` (`a<b<c`) that forms a triangle in the given graph.

**Proof.**  
Existence: the input guarantees at least one triangle, so some iteration
finds `mask ≠ 0` and prints a triple. By Lemma&nbsp;3 the printed triple is
indeed a triangle.

Minimality: by Lemma&nbsp;4 no other triangle is lexicographically smaller.
Thus the printed triple is the required answer. ∎

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * n                     # bitset for each vertex

    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u] |= 1 << v
        adj[v] |= 1 << u

    for a in range(n):
        a_adj = adj[a]
        for b in range(a + 1, n):
            # edge (a,b) ?
            if (a_adj >> b) & 1 == 0:
                continue
            common = a_adj & adj[b]
            # keep only vertices > b
            mask = common & ~((1 << (b + 1)) - 1)
            if mask:
                low = mask & -mask               # lowest set bit
                c = low.bit_length() - 1
                # output 1‑based, already a<b<c
                sys.stdout.write(f"{a+1} {b+1} {c+1}")
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
