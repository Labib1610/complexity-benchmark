# Problem C — Orbital Resonance Conflict

Time limit: 2 s   Memory limit: 256 MB

A space agency is managing a constellation of satellites. To prevent collisions and interference, satellites with intersecting flight paths are flagged as having a resonance conflict. To resolve a conflict, the two involved satellites must be placed into distinct operational altitudes. Currently, the agency's control system only supports two operational altitudes.

Engineers have determined that the current flight plan is fundamentally flawed and cannot be resolved using only two altitudes. Specifically, the flight plan contains an underlying contradiction: a triplet of satellites where each satellite in the triplet has a resonance conflict with the other two. Since all three are in mutual conflict, no two can share an altitude, making it impossible to accommodate them within the two available altitudes.

You must write a program to find one such triplet of satellites to serve as a diagnostic proof of the flight plan's failure.

## Input
The first line of input provides two integers $n$ and $m$, which denote the total number of satellites and the total number of recorded resonance conflicts.
The satellite count $n$ is bounded by a minimum of $3$ (the smallest number needed to form a conflicting triplet) and a maximum registry capacity of $2000$.
The conflict count $m$ is bounded by a minimum of $3$ and an upper limit that cannot exceed the smaller of two values: the theoretical maximum of $n \cdot (n-1)/2$ unique pairs, and the telemetry system's hard cap of $2 \cdot 10^5$ records.

Each of the next $m$ lines provides two integers $u$ and $v$, indicating that the satellites with these identifiers share a resonance conflict. Satellites are identified by integers from $1$ to $n$.
The input is guaranteed to contain at least one triplet of satellites where all three mutually conflict with each other.

## Output
Print three space-separated integers $a$, $b$, and $c$ on a single line, ordered such that $a < b < c$. These three satellites must mutually conflict (i.e., the pair $a$ and $b$, the pair $a$ and $c$, and the pair $b$ and $c$ must each appear in the input, in any order, as a conflict). 
If there are multiple such triplets, output the one with the smallest value for $a$. If there is a tie, choose the one with the smallest value for $b$. If a tie still persists, choose the one with the smallest value for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
