# Problem C — Orbital Resonance Conflict

Time limit: 2 s   Memory limit: 256 MB

An orbital monitoring facility is currently tracking a fleet of $n$ satellites. Because of intersecting orbital paths, specific pairs of these satellites undergo gravitational resonance. To prevent orbital decay, any two resonating satellites must be placed into distinct altitude levels. However, the facility's current operational capacity allows for only two altitude levels.

The planned configuration is inherently unstable. Within the telemetry data, there exists at least one triplet of satellites in which each satellite resonates with the other two in the triplet. Since all three are in mutual resonance, they cannot be divided among just two altitude levels without a conflict.

Your objective is to find one such triplet of satellites to demonstrate that the proposed configuration is invalid.

## Input
The first line provides two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$) — the number of tracked satellites and the total count of resonating pairs.
Each of the subsequent $m$ lines contains two integers $u$ and $v$. These are the numeric identifiers of two satellites that resonate with each other. The satellite identifiers are arbitrary positive integers (they are not restricted to the range $1 \dots n$ and might not form a contiguous sequence).
The provided data is guaranteed to include at least one triplet of satellites where all three mutually resonate.

## Output
Print a single line containing three space-separated integers $a$, $b$, and $c$, sorted such that $a < b < c$. These must represent the identifiers of a resonating triplet (i.e., the pair $a$ and $b$, the pair $a$ and $c$, and the pair $b$ and $c$ must all be present as resonating pairs in the input, regardless of the order they were given).
If multiple valid triplets exist, output the one with the minimum value for $a$. In the event of a tie, output the one with the minimum value for $b$. If multiple triplets share the same $a$ and $b$, output the one with the minimum value for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
