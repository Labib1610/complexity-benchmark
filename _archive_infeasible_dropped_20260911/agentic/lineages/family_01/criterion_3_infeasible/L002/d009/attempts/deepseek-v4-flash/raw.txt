We need to find the lexicographically smallest deadlocked trio.  
A trio is deadlocked if:

1. Each vertex in the trio has at least one edge to another vertex in the trio.
2. The internal conflict sets (neighbors within the trio) are all distinct.

We can brute-force all triples since \( n \leq 2000 \), but that would be \( O(n^3) \) which is too slow.  
We need a smarter approach.

---

**Key observation:**  
For a trio `(a, b, c)` with `a < b < c`, the internal conflict sets are:

- For `a`: neighbors among `{b, c}`
- For `b`: neighbors among `{a, c}`
- For `c`: neighbors among `{a, b}`

Each set is a subset of size 0, 1, or 2.  
Condition 1 says each must be non-empty.  
Condition 2 says the three subsets must be distinct.

We can iterate over `a` and `b` and check possible `c` quickly using bitmasks or sets.

---

**Approach:**

- Represent the graph as an adjacency bitmask (using Python integers) for fast intersection checks.
- For each pair `(a, b)` with `a < b`:
  - If there is no edge between `a` and `b`, then `a`'s set cannot contain `b`, but it could still contain `c`.  
    But we need to check all possible `c > b`.
  - For each `c > b`, check:
    - `a` has at least one neighbor among `{b, c}`
    - `b` has at least one neighbor among `{a, c}`
    - `c` has at least one neighbor among `{a, b}`
    - The three sets are distinct.

We can speed up by precomputing adjacency as bitmasks and using bit operations.

---

**Implementation plan:**

- `adj[i]` = bitmask of neighbors of `i`.
- For each `a` from 1 to n-2:
  - For each `b` from a+1 to n-1:
    - For each `c` from b+1 to n:
      - Compute:
        - `mask_a = (adj[a] >> b) & 1` and `(adj[a] >> c) & 1` → but easier:  
          `set_a = (adj[a] & (1<<b)) != 0` and `(adj[a] & (1<<c)) != 0`
        - Similarly for b and c.
      - Check conditions.

This is still \( O(n^3) \) worst-case, but with n=2000, that's 8e9 operations — too slow.

---

**Optimization:**

We can iterate over `a` and `b`, and for each pair, we can precompute possible `c` values that satisfy the conditions using bit operations.

For fixed `a` and `b`:

- Let `mask_ab = (1<<a) | (1<<b)`.
- For `c` to be valid:
  - `a` must have at least one neighbor in `{b, c}` → `(adj[a] & mask_ab) != 0` or `(adj[a] & (1<<c)) != 0`.
  - `b` must have at least one neighbor in `{a, c}` → `(adj[b] & mask_ab) != 0` or `(adj[b] & (1<<c)) != 0`.
  - `c` must have at least one neighbor in `{a, b}` → `(adj[c] & mask_ab) != 0`.

Also, the sets must be distinct.

We can iterate `c` from `b+1` to `n` and check quickly.

---

Given constraints, \( O(n^2 \cdot \text{check}) \) with a fast check is feasible.  
We can precompute for each pair `(a,b)` the possible `c` values that satisfy the "non-empty" condition for `c` (i.e., `c` has an edge to `a` or `b`). That reduces the inner loop.

---

Let's implement:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [0] * (n + 1)
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u] |= (1 << v)
        adj[v] |= (1 << u)
    
    # Iterate over a, b, c in sorted order
    for a in range(1, n - 1):
        for b in range(a + 1, n):
            # Precompute masks for a and b
            mask_ab = (1 << a) | (1 << b)
            # Check if a and b have at least one neighbor among themselves
            a_has_b = (adj[a] >> b) & 1
            b_has_a = (adj[b] >> a) & 1
            for c in range(b + 1, n + 1):
                # Check c has at least one neighbor among a,b
                if not (adj[c] & mask_ab):
                    continue
                # Compute internal sets
                set_a = 0
                if a_has_b:
                    set_a |= 1
                if (adj[a] >> c) & 1:
                    set_a |= 2
                if set_a == 0:
                    continue
                
                set_b = 0
                if b_has_a:
                    set_b |= 1
                if (adj[b] >> c) & 1:
                    set_b |= 2
                if set_b == 0:
                    continue
                
                set_c = 0
                if (adj[c] >> a) & 1:
                    set_c |= 1
                if (adj[c] >> b) & 1:
                    set_c |= 2
                if set_c == 0:
                    continue
                
                if set_a != set_b and set_a != set_c and set_b != set_c:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    solve()
```
