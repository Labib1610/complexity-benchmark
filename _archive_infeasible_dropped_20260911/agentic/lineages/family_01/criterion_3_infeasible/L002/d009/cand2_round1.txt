Algebraic Null-Space Framing
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the graph-theoretic deadlock definition with an equivalent linear algebra condition over the real numbers. A homogeneous subsystem of equations z_u + z_v = 0 on three variables has a unique trivial solution if and only if all three pairwise equations are present, which mathematically forces the underlying structure to be a 3-clique (triangle). This prevents models from pattern-matching graph terminology and forces them to algebraically derive the 3-clique requirement before applying an efficient search.
</METHOD_DESCRIPTION>

yes
</METHOD_NOVEL>
<STATEMENT>
# Root Obstruction Identification

## Time and Memory Limits
Time limit: 2 s
Memory limit: 256 MB

## Description
You are analyzing a system of linear constraints over the real numbers. There are $n$ variables, denoted as $z_1, z_2, \dots, z_n$. You are given a list of $m$ constraint pairs. Each constraint pair $(u, v)$ indicates that the equation $z_u + z_v = 0$ is available to be used.

Your task is to locate a specific structure called a *root obstruction*. A root obstruction is defined as a set of exactly three distinct variable indices $a, b,$ and $c$ (with $a < b < c$) such that if you collect all available equations $z_u + z_v = 0$ where both $u$ and $v$ are in the set $\{a, b, c\}$, this resulting subsystem of equations in the variables $z_a, z_b,$ and $z_c$ has $z_a = z_b = z_c = 0$ as its one and only solution over the real numbers.

Since there may be multiple root obstructions, you must report the one whose indices form the lexicographically smallest sequence when sorted in ascending order. (A sequence $a_1 < b_1 < c_1$ is lexicographically smaller than $a_2 < b_2 < c_2$ if $a_1 < a_2$; or if $a_1 = a_2$ and $b_1 < b_2$; or if $a_1 = a_2$ and $b_1 = b_2$ and $c_1 < c_2$).

## Input
The first line contains two integers $n$ and $m$, representing the number of variables and the number of available constraint pairs. The bounds are $3 \le n \le 2000$ and $3 \le m \le \min(n(n-1)/2, 200000)$.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing an available constraint equation $z_u + z_v = 0$. It is guaranteed that all given pairs are distinct unordered pairs, and that at least one root obstruction exists.

## Output
Output a single line containing three integers $a$, $b$, and $c$, ordered such that $a < b < c$, representing the variable indices of the chosen root obstruction. Among all valid root obstructions, output the lexicographically smallest one (smallest $a$; if tied, smallest $b$; if tied, smallest $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
Replaced the graph-theoretic deadlock definition with a linear algebra condition over the real numbers. A subsystem of equations of the form $z_u + z_v = 0$ on three variables has a unique trivial solution if and only if all three equations are present (forming an odd cycle). This forces models to mathematically deduce that the condition is equivalent to finding a triangle, preventing them from blindly applying standard adjacency checks based on graph terminology.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic condition of having a unique trivial solution for a subsystem of 3 variables is mathematically equivalent to the presence of all three pairwise equations, which corresponds exactly to a triangle (3-clique) in the original graph formulation, preserving all valid triplets.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The fundamental problem remains finding the lexicographically smallest 3-clique in an undirected graph, which maintains the exact same time complexity and feasibility class.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the phrase 'one and only solution' if they fail to recognize that homogeneous systems always have at least the trivial solution, though the wording explicitly specifies the exact unique solution required.
</RISK>
