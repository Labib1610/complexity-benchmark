**Solution Explanation**

For a candidate `v` let  

```
N(v) = { u | (v,u) is a recorded veto }          (neighbours)
```

The *incompatibility domain* of `v` is `{v} ∪ N(v)`.  
A trio `{a,b,c}` is *deadlocked* **iff** every two of its members are
veto‑connected, i.e. the three edges `{a,b}`, `{a,c}`, `{b,c}` are all
present.  
So we only have to find a **triangle** in the undirected graph defined by
the veto pairs and output the lexicographically smallest one.

--------------------------------------------------------------------

#### 1.   Data structure – bitsets

`n ≤ 2000`, therefore a set of vertices fits into a 2000‑bit integer.
For every vertex `v` we store

```
mask[v] : integer, bit i (0‑based) is 1  ⇔  vertex (i+1) is a neighbour of v
```

(we do **not** store the vertex itself, it is not needed for the test).

All operations we need are:

* `mask[u] & mask[v]` – intersection of neighbour sets,
* test whether a particular vertex `x` belongs to the intersection – by
  checking a bit,
* find the smallest vertex `c` larger than a given bound `b` that belongs
  to the intersection – using bit tricks described below.

All of them are `O(1)` on Python integers.

--------------------------------------------------------------------

#### 2.   Searching the smallest triangle

We iterate over all edges `(a,b)` with `a < b` in **lexicographic order**
(`a` increasing, for a fixed `a` `b` increasing).

For the current edge we compute the common neighbours:

```
common = mask[a] & mask[b]          # vertices adjacent to both a and b
```

Only a vertex `c > b` can give a lexicographically larger triple,
therefore we delete all bits `≤ b`:

```
common >>= b                         # now bit 0 corresponds to vertex (b+1)
```

If `common` is zero, no suitable `c` exists for this pair.
Otherwise the lowest set bit gives the smallest possible `c`:

```
low = common & -common                # isolate lowest 1‑bit
idx = low.bit_length() - 1            # its position (0‑based)
c   = b + 1 + idx                     # real vertex number
```

The first triple we encounter during the double loop is the
lexicographically smallest one, because:

* `a` is minimal (outer loop),
* for this `a` the first `b` with an existing triangle is minimal,
* for this pair we explicitly choose the smallest admissible `c`.

The problem guarantees that at least one triangle exists, so the algorithm
will always output a result.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
deadlocked trio.

---

##### Lemma 1  
For any three distinct vertices `a<b<c` the set `{a,b,c}` is a deadlocked
trio **iff** the edges `{a,b}`, `{a,c}`, `{b,c}` are all present in the
input.

**Proof.**  
By definition a deadlocked trio must be contained in the incompatibility
domain of each of its members.  
The domain of a vertex consists of the vertex itself and all its veto
neighbours.  
Thus each of the other two vertices must be a neighbour of the first one,
i.e. all three edges must exist. The converse is immediate. ∎



##### Lemma 2  
When the algorithm processes an edge `(a,b)` (`a<b`) it finds the smallest
vertex `c>b` such that `{a,b,c}` is a triangle, if such a vertex exists.

**Proof.**  
`common = N(a) ∩ N(b)` contains exactly the vertices adjacent to both `a`
and `b`.  
After shifting right by `b`, bit `k` of `common` corresponds to vertex
`c = b+1+k`.  
The operation `low = common & -common` isolates the least significant `1`
‑bit, i.e. the smallest `k` with a `1`. Consequently `c` is the smallest
vertex larger than `b` belonging to the intersection, i.e. the smallest
`c` that together with `a,b` forms a triangle. ∎



##### Lemma 3  
If the algorithm outputs the triple `(a,b,c)`, then `{a,b,c}` is a deadlocked
trio.

**Proof.**  
The algorithm outputs a triple only after it has found an edge `(a,b)` and
a vertex `c` obtained as in Lemma&nbsp;2.  
`c` belongs to `N(a) ∩ N(b)`, therefore edges `(a,c)` and `(b,c)` exist.
Edge `(a,b)` exists because we are iterating over input edges.
By Lemma&nbsp;1 the three edges imply that `{a,b,c}` is a deadlocked trio. ∎



##### Lemma 4  
Let `T* = (a*,b*,c*)` be the lexicographically smallest deadlocked trio.
The algorithm will output `T*`.

**Proof.**  
Consider the outer loop iteration with `a = a*`.  
All edges `(a*,b)` with `b < b*` cannot belong to any triangle that is
lexicographically ≤ `T*`, otherwise `T*` would not be minimal.
Hence the first edge `(a*,b)` examined that participates in a triangle must
have `b = b*`.  
When this edge is processed, Lemma&nbsp;2 returns the smallest `c>b*`
forming a triangle with `a*,b*`. Because `c*` is the smallest possible such
vertex, the algorithm obtains `c = c*`.  
Thus the algorithm outputs exactly `T*`. ∎



##### Theorem  
The algorithm always prints the lexicographically smallest deadlocked trio.

**Proof.**  
Existence of at least one triangle is guaranteed, so the algorithm will
eventually find one and terminate.  
By Lemma&nbsp;3 the printed triple is a deadlocked trio.  
By Lemma&nbsp;4 this triple is the lexicographically smallest one. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building masks* : `O(m)`  
*Main loops* : each input edge is examined once, all operations inside are
`O(1)`.  
Hence total time `O(m) ≤ 2·10⁵`, well below the limit.

Memory consumption: one integer per vertex (`n ≤ 2000`) → `O(n)` bits,
negligible (a few kilobytes).

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    # adjacency bitsets, 0‑based indexing for bits
    masks = [0] * (n + 1)          # masks[vertex]

    edges = []                     # store edges with a<b
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        if u == v:
            continue
        # set bits
        masks[u] |= 1 << (v - 1)
        masks[v] |= 1 << (u - 1)
        if u < v:
            edges.append((u, v))
        else:
            edges.append((v, u))

    # sort edges to guarantee lexicographic order of (a,b)
    edges.sort()

    for a, b in edges:
        # common neighbours of a and b
        common = masks[a] & masks[b]
        # keep only vertices > b
        common >>= b          # now bit 0 corresponds to vertex b+1
        if common == 0:
            continue
        # lowest set bit -> smallest c
        low = common & -common
        idx = low.bit_length() - 1   # position of that bit
        c = b + 1 + idx
        # output sorted triple (a<b<c already)
        sys.stdout.write(f"{a} {b} {c}")
        return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
