We need to find a trio of distinct candidates such that each candidate is in the incompatibility domain of the other two.  
That means for a trio `(a, b, c)`, we need:

- `a` is in the domain of `b` and `c`
- `b` is in the domain of `a` and `c`
- `c` is in the domain of `a` and `b`

Since the domain includes the candidate itself, this condition is equivalent to:  
Every pair among the trio must have a mutual veto (i.e., be connected by an edge in the graph).  
So we are looking for a **triangle** in the graph.

We need the lexicographically smallest triangle.

---

**Approach:**

- Build an adjacency matrix (or set) for fast lookups.
- Iterate over all triples `(i, j, k)` with `i < j < k` in lexicographic order.
- For each triple, check if all three edges exist.
- The first found is the answer.

Since `n ≤ 2000`, checking all triples naively is `O(n^3)` which is too slow (8e9 operations).  
We need a smarter method.

---

**Better approach:**

We can iterate over the smallest vertex `a` from `1` to `n`.  
For each `a`, look at its neighbors (candidates with veto with `a`).  
Among those neighbors, we need to find two `b < c` such that `b` and `c` are also connected.  
We can check this by iterating over pairs of neighbors of `a` and checking if they are connected.

Since we want lexicographically smallest, we can:

- For each `a` from 1 to n:
  - Let `neighbors` be sorted list of vertices `> a` that are connected to `a`.
  - For each pair `(b, c)` in `neighbors` with `b < c`:
    - If `b` and `c` are connected, then `(a, b, c)` is a valid triangle.
    - Since we iterate `a` in increasing order and `b` in increasing order, the first found is the answer.

This is `O(n * deg^2)` worst-case, but with `n=2000` and `m=200000`, it's acceptable.

---

**Implementation details:**

- Use a boolean adjacency matrix of size `n+1` by `n+1` for O(1) edge checks.
- For each `a`, collect neighbors `> a` in sorted order.
- Check pairs.

---

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = True
        adj[v][u] = True

    for a in range(1, n + 1):
        neighbors = [v for v in range(a + 1, n + 1) if adj[a][v]]
        for i in range(len(neighbors)):
            b = neighbors[i]
            for j in range(i + 1, len(neighbors)):
                c = neighbors[j]
                if adj[b][c]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
