**Approach:** Use bitsets for efficient triangle detection. For each vertex u (in ascending order), for each neighbor v > u (in ascending order), compute the intersection of adjacency bitmasks of u and v, then find the smallest vertex w > v in that intersection. The first triangle found in this iteration order is lexicographically smallest.

**Verification with examples:**
- Example 1: Triangle {1,2,3} exists (edges 1-2, 1-3, 2-3) → output "1 2 3" ✓
- Example 2: Triangles {1,2,4} and {3,4,5} exist; lex smallest is {1,2,4} ✓

The bitset approach makes each edge check O(n/64) word operations, giving total complexity O(m·n/64) ≈ 6M operations for worst case.

```python
import sys

def solve():
    data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(data[idx]); idx += 1
    m = int(data[idx]); idx += 1
    
    adj_bits = [0] * (n + 1)
    adj_list = [[] for _ in range(n + 1)]
    
    for _ in range(m):
        u = int(data[idx]); idx += 1
        v = int(data[idx]); idx += 1
        adj_bits[u] |= (1 << v)
        adj_bits[v] |= (1 << u)
        adj_list[u].append(v)
        adj_list[v].append(u)
    
    for i in range(1, n + 1):
        adj_list[i].sort()
    
    for u in range(1, n + 1):
        au = adj_bits[u]
        for v in adj_list[u]:
            if v <= u:
                continue
            common = au & adj_bits[v]
            shifted = common >> (v + 1)
            if shifted:
                w = (shifted & (-shifted)).bit_length() - 1 + v + 1
                print(u, v, w)
                return

solve()
```
