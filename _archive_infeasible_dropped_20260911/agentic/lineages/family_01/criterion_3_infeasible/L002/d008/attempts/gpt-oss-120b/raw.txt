**Solution Explanation**

For three different candidates `a<b<c` we have to decide whether the three
vertices can be split into two independent sets.
A graph on three vertices is *not* bipartite **iff** it contains a triangle,
because the only odd cycle possible on three vertices is a 3‑cycle.
Therefore a *deadlocked trio* is exactly a triangle of the veto‑graph.

So the task reduces to

*find the lexicographically smallest triangle* in an undirected graph
with `n ≤ 2000` vertices and `m ≤ 200 000` edges.
The existence of at least one triangle is guaranteed.



--------------------------------------------------------------------

#### 1.   Data structure – bitsets

`n ≤ 2000`, therefore a 2000‑bit integer fits easily into a Python `int`.
For every vertex `v` we store

```
adj[v] : int               # bit i is 1  ⇔  (v,i) is an edge
```

All operations we need are bitwise `&` (intersection) and finding the
lowest set bit – both are O(1) on a machine word size, i.e. O(1) for us.



--------------------------------------------------------------------

#### 2.   Searching triangles in lexicographic order

We iterate over all edges `(u,v)` with `u < v` in increasing order
(`u` outer loop, `v` inner loop).  
For a fixed edge the third vertex of a triangle must be a common neighbour
of `u` and `v` and must be larger than `v` (to keep `a<b<c`).

```
common = adj[u] & adj[v]          # all common neighbours
mask   = common >> (v+1)          # keep only vertices > v
if mask != 0:
        # the lowest set bit of mask gives the smallest possible w
        low   = mask & -mask
        w     = (low.bit_length() - 1) + v + 1
        answer = (u, v, w)        # first found is lexicographically minimal
        stop
```

Why is the first found triangle the lexicographically smallest?
* `u` grows from `1` to `n`.  
  The first triangle we meet has the smallest possible first element.
* For this `u` we try `v` in increasing order, therefore the second element
  is minimal among triangles with that `u`.
* For a fixed pair `(u,v)` we pick the smallest possible `w>v`,
  hence the third element is minimal.

Consequently the very first triangle discovered by the loops is the required
answer.



--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest triangle.

---

##### Lemma 1  
A set of three vertices is a deadlocked trio **iff** they form a triangle
(i.e. all three edges between them are present).

**Proof.**  
If the three vertices contain all three edges, the induced subgraph is a
3‑cycle, which is odd, therefore not bipartite – the set is deadlocked.  
If at least one of the three possible edges is missing, the induced subgraph
has at most two edges and is a forest, which is bipartite, so the set can be
partitioned into two independent sets. ∎



##### Lemma 2  
When the algorithm examines edges in the order described
(`u` increasing, for each `u` `v` increasing, `u<v`),
the first triangle it discovers has the smallest possible first vertex
among all triangles.

**Proof.**  
All triangles have a smallest vertex `a`.  
The outer loop reaches `u = a` before any larger vertex.
If a triangle with first vertex `< a` existed, it would have been found
earlier, contradicting minimality of `a`. ∎



##### Lemma 3  
Given that the outer loop is at the smallest possible first vertex `a`,
the inner loop finds a triangle whose second vertex is the smallest possible
among all triangles whose first vertex is `a`.

**Proof.**  
For fixed `a` the inner loop enumerates `v > a` increasingly.
If a triangle `(a, b, c)` exists with `b` minimal, the loop reaches `v = b`
before any larger `v`. No triangle with second vertex `< b` exists,
otherwise `b` would not be minimal. Hence the first triangle found for this
`a` uses the minimal possible second vertex. ∎



##### Lemma 4  
For a fixed edge `(a,b)` (`a<b`) the algorithm chooses the smallest possible
third vertex `c>b` that together with `a,b` forms a triangle.

**Proof.**  
`common = adj[a] & adj[b]` contains exactly the vertices adjacent to both
`a` and `b`. After shifting right by `b+1` we keep only vertices `>b`.
If the resulting mask is non‑zero, its lowest set bit corresponds to the
smallest such vertex `c`. ∎



##### Lemma 5  
The triangle output by the algorithm is lexicographically minimal among all
triangles of the graph.

**Proof.**  
By Lemma&nbsp;2 its first vertex `a` is minimal.
Conditioned on this `a`, Lemma&nbsp;3 gives minimal second vertex `b`.
Conditioned on `(a,b)`, Lemma&nbsp;4 gives minimal third vertex `c`.
Thus no other triangle can be lexicographically smaller. ∎



##### Theorem  
The algorithm always outputs three numbers `a<b<c` that form a deadlocked
trio and that are lexicographically smallest among all such trios.

**Proof.**  
If the algorithm outputs a triple, by construction `a,b,c` are pairwise
adjacent, therefore by Lemma&nbsp;1 they form a deadlocked trio.
Existence of at least one triangle guarantees the loops will eventually
find one. By Lemma&nbsp;5 the found triangle is the lexicographically smallest
among all triangles, i.e. among all deadlocked trios. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building bitsets* : `O(m)`  
*Main loops* : each edge is processed once, all operations inside are O(1).  
Hence total time `O(m) ≤ 2·10⁵`, well below the limit.

Memory: `n` integers of at most `n` bits → `n·n/8 ≤ 2000·2000/8 = 0.5 MB`.  
Negligible compared to the 256 MB limit.

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * n          # bitset for each vertex, 0‑based
    edges = []             # list of (u,v) with u<v

    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        if u == v:
            continue
        adj[u] |= 1 << v
        adj[v] |= 1 << u
        if u < v:
            edges.append((u, v))
        else:
            edges.append((v, u))

    # sort edges to guarantee lexicographic order
    edges.sort()

    for u, v in edges:
        # common neighbours of u and v
        common = adj[u] & adj[v]
        # keep only vertices > v
        mask = common >> (v + 1)
        if mask:
            low = mask & -mask               # lowest set bit
            w = (low.bit_length() - 1) + v + 1
            # output 1‑based sorted triple
            a, b, c = u + 1, v + 1, w + 1
            sys.stdout.write(f"{a} {b} {c}")
            return

if __name__ == "__main__":
    solve()
```

to the required input‑output format.
