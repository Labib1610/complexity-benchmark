We can model the problem as a graph where each candidate is a node and each veto is an edge.  
A deadlocked trio is a set of 3 nodes that cannot be split into two groups without having an edge inside one of the groups.  

This means the trio must form a triangle (all three edges present) — because if any edge is missing, we can put those two in different groups and the third anywhere.  

So the task reduces to: find the lexicographically smallest triangle in the graph.

We can do this efficiently by iterating over the first node `a` from 1 to n, then over `b > a` that is connected to `a`, then checking for `c > b` connected to both.  
We stop at the first found triangle because we iterate in lexicographic order.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        for b in sorted(adj[a]):
            if b <= a:
                continue
            for c in sorted(adj[a]):
                if c <= b:
                    continue
                if c in adj[b]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
