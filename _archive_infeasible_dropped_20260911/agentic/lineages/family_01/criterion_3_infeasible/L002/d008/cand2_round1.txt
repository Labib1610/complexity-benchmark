<STATEMENT>
# Committee Deadlock Resolution

## Time and Memory Limits
Time limit: 2 s
Memory limit: 256 MB

## Description
A selection panel is evaluating a roster of candidates, numbered $1$ to $n$. During the vetting process, the panel recorded mutual vetoes. Each veto is an unordered pair of distinct candidates who cannot be placed on the same committee.

The selection panel assigns a *synergy penalty* $P(x, y)$ to every pair of candidates $x$ and $y$:
- $P(x, x) = 0$ for any candidate $x$.
- $P(x, y) = 1$ if the unordered pair $\{x, y\}$ is present in the recorded log of mutual vetoes.
- $P(x, y) = 2$ if the candidates $x$ and $y$ are distinct and their pair is absent from the log.

To formally document a scheduling failure, you must locate a specific obstruction: a deadlocked trio. A trio is defined as a set of exactly three distinct candidates. A trio $\{a, b, c\}$ is considered deadlocked if their total pairwise synergy penalty $P(a, b) + P(b, c) + P(c, a)$ is exactly 3.

You must systematically evaluate the synergy penalties to find a deadlocked trio. If there are multiple deadlocked trios, you must report the trio whose candidate numbers form the lexicographically smallest sequence when sorted in ascending order. (A sequence $a_1 < b_1 < c_1$ is lexicographically smaller than $a_2 < b_2 < c_2$ if $a_1 < a_2$; or if $a_1 = a_2$ and $b_1 < b_2$; or if $a_1 = a_2$ and $b_1 = b_2$ and $c_1 < c_2$).

## Input
The first line contains two integers $n$ and $m$, indicating the candidate headcount and the log size. The headcount $n$ is at least 3 and at most the maximum number of candidates that can be assigned a unique integer ID from 1 to 2000 inclusive. The log size $m$ is at least 3 and goes up to exactly one hundred times the maximum possible headcount, or the total number of unique pairs for $n$ candidates, whichever is fewer.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing a mutual veto between candidate $u$ and candidate $v$. It is guaranteed that at least one deadlocked trio exists.

## Output
Output a single line containing three integers $a$, $b$, and $c$, ordered such that $a < b < c$, representing the candidate numbers in the chosen trio. Among all valid deadlocked trios, output the lexicographically smallest one (smallest $a$; if tied, smallest $b$; if tied, smallest $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
Removed the set-theoretic "incompatibility domain" subset framing that models easily mapped to adjacency lists. Replaced it with a discrete metric space framing where pairs are assigned a "synergy penalty" of 1 (vetoed) or 2 (not vetoed). A deadlocked trio is now defined algebraically as three distinct candidates whose penalty sum is exactly 3, which forces models to either deduce that this implies three mutual vetoes (a triangle) and use bitsets, or write a naive $O(N^3)$ sum check that will exceed the time limit.
</RATIONALE>
<PRESERVED_ANSWER>
Because $a, b, c$ are distinct, their pairwise penalties can only be 1 or 2, meaning their sum is 3 if and only if all three pairs have a penalty of 1 (i.e., they are all recorded mutual vetoes), which exactly preserves the original deadlocked trio (triangle) condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a 3-clique (triangle) in an undirected graph, keeping it in the same complexity class with the identical $O(N \cdot M / 64)$ intended bitset solution.
</PRESERVED_CLASS>
