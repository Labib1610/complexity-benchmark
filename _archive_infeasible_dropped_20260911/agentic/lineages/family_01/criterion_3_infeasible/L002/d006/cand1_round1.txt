<STATEMENT>
# Conflict Resolution Certification

## Time and Memory Limits
Time limit: 2 s
Memory limit: 256 MB

## Description
A manufacturing facility has a roster of technicians, identified by integers starting from 1 up to the total headcount. Over time, there have been documented incompatibilities. Each incompatibility is an unordered pair of distinct technicians who cannot work together.

The management intended to divide the staff into two shifts, but the incompatibilities make this impossible. To formally document this scheduling failure, you must locate a specific obstruction: a completely fractured triad. 

A triad is a subset of exactly three distinct technicians. It is considered completely fractured if no pair of technicians within the triad is compatible. A pair of distinct technicians is considered compatible if and only if there is no documented incompatibility between them.

Because the number of possible triads is large, you must systematically search to find one. If multiple completely fractured triads exist, you must resolve the tie by selecting the triad that has the smallest possible ID for its lowest-numbered member. If there is still a tie, select the one with the smallest ID for its middle-numbered member, and if a tie persists, select the one with the smallest ID for its highest-numbered member. Output these three IDs in ascending order.

## Input
The first line provides the total headcount of technicians and the total count of incompatibilities. The headcount is bounded below by the minimum number of people needed to form a triad, and capped at a maximum facility capacity of two thousand. The count of incompatibilities starts at a minimum of three, and will never exceed the facility's maximum tracking limit of two hundred thousand, nor the theoretical maximum number of distinct pairs of technicians, whichever is smaller.

Each of the following lines describes one incompatibility by providing the two distinct technician IDs involved. These IDs are valid integers starting from 1 up to the total headcount. It is guaranteed that at least one completely fractured triad exists.

## Output
Output a single line containing three integers $a$, $b$, and $c$, ordered such that $a < b < c$, representing the IDs of the three technicians in the chosen triad. 

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

I removed the direct description of a triangle ("all three of its 2-element subsets are present") and replaced it with a double-negative complement framing ("no pair is compatible", where "compatible" means "no incompatibility"). This forces the model to logically resolve the double negation rather than relying on surface-level keyword matching for cliques or common neighbors. I also implemented strategy S07, encoding all numeric bounds exactly through domain constraints (e.g., minimum people for a triad, maximum facility capacity) rather than mathematical inequalities.
</RATIONALE>
<PRESERVED_ANSWER>
A triad has exactly three pairs; if zero pairs are compatible, and compatibility requires the absence of an incompatibility, then all three pairs must have a documented incompatibility, which is exactly a triangle in the graph, keeping all answers identical.
</PRESERVED_ANSWER>

The problem still requires finding a K3 (triangle) in an undirected graph, preserving its polynomial-time complexity class and feasibility via bitset intersection or standard graph traversal.
</PRESERVED_CLASS>

</RISK>
