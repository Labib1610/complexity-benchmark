We can solve this by representing the vetoes in an adjacency matrix (or set) and then checking triples in lexicographic order.  

Since \( n \) can be up to 2000, a full \( O(n^3) \) check is too slow.  
Instead, we iterate over the first candidate `a` from 1 to n, then the second `b` from `a+1` to n, and check if they are connected. If they are, we look for the smallest `c > b` that is connected to both `a` and `b`.  

We can store adjacency in a boolean matrix for fast lookup.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = True
        adj[v][u] = True
    
    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if adj[a][b]:
                for c in range(b + 1, n + 1):
                    if adj[a][c] and adj[b][c]:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    main()
```
