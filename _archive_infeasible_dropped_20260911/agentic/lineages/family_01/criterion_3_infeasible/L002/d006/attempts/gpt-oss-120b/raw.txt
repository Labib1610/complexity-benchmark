**Solution Explanation**

For every candidate we store the set of candidates that veto him.
A triangle (deadlocked trio) is three vertices `a<b<c` such that all three
edges `(a,b) , (a,c) , (b,c)` exist.

`n ≤ 2000`, therefore a bitset of length `n+1` fits into a Python integer
(`2001` bits ≈ 250 bytes).  
All set operations become fast bit operations.

--------------------------------------------------------------------

#### Data structure  

```
adj[i] : Python int, bit j is 1  ⇔  edge (i , j) exists
```

--------------------------------------------------------------------

#### Algorithm  

```
read n , m
adj[1…n] = 0
for each edge (u , v):
        adj[u] |= 1 << v
        adj[v] |= 1 << u

for a = 1 … n:
        for b = a+1 … n:
                if edge (a,b) is not present: continue
                common = adj[a] & adj[b]          # vertices adjacent to both
                # keep only vertices > b, because we need a<b<c
                mask   = ~((1 << (b+1)) - 1) & ((1 << (n+1)) - 1)
                common &= mask
                if common != 0:                    # at least one c exists
                        low = common & -common      # lowest set bit
                        c = low.bit_length() - 1
                        output a b c and finish
```

The outer loops enumerate pairs `(a,b)` in lexicographic order.
The first time we find a suitable `c` we have the lexicographically smallest
triple, because:

* `a` is minimal (outermost loop),
* for this `a` the inner loop gives the minimal possible `b`,
* we pick the smallest `c` (`low` is the lowest set bit).

The existence of at least one triangle is guaranteed, so the algorithm
always terminates.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
triangle.

---

**Lemma 1**  
For any vertices `a<b`, after `common = adj[a] & adj[b]` and masking,
`common` contains exactly the vertices `c` such that `c>b` and edges
`(a,c)` and `(b,c)` exist.

*Proof.*  
`adj[a]` has a 1‑bit at `c` iff `(a,c)` is an edge, similarly for `adj[b]`.
The bitwise AND keeps a 1‑bit only when both edges exist.
The mask clears all bits `≤ b`; therefore remaining 1‑bits correspond
precisely to vertices `c>b` adjacent to both `a` and `b`. ∎



**Lemma 2**  
If the algorithm prints a triple `(a,b,c)`, then it is a triangle
(`V(a,b)=V(a,c)=V(b,c)=1`).

*Proof.*  
The algorithm prints only after confirming that edge `(a,b)` exists
(`if edge (a,b) is not present: continue`).  
By Lemma&nbsp;1 the chosen `c` satisfies that edges `(a,c)` and `(b,c)` exist.
Thus all three edges are present. ∎



**Lemma 3**  
When the algorithm prints `(a,b,c)`, there is no triangle
`(a',b',c')` with lexicographically smaller sorted triple.

*Proof.*  
Pairs `(a,b)` are examined in increasing lexicographic order:
first by `a`, then by `b`.  
Assume a smaller triangle exists.

* If its first element `a' < a`, the algorithm would have examined the
pair `(a',b')` earlier, and by Lemma&nbsp;1 would have found its third
vertex, contradicting that we have not terminated earlier.

* If `a' = a` but `b' < b`, the pair `(a,b')` is examined earlier (same
`a`, smaller `b`). Again the algorithm would have terminated earlier.

* If `a'=a` and `b'=b` but `c' < c`, then after masking only vertices
greater than `b` remain. The algorithm selects the smallest such vertex,
i.e. the minimal `c`. Hence `c'` cannot be smaller than `c`.

All cases contradict the assumption, therefore no smaller triangle exists. ∎



**Lemma 4**  
If a triangle exists, the algorithm will eventually print one.

*Proof.*  
Take the lexicographically smallest triangle `(a,b,c)`.  
When the outer loops reach the pair `(a,b)`, edge `(a,b)` is present,
so the algorithm proceeds to compute `common`.  
By Lemma&nbsp;1, `c` is among the set bits of `common`. Hence `common` is
non‑zero and the algorithm prints a triple (which must be `(a,b,c)` by
Lemma&nbsp;3). ∎



**Theorem**  
The algorithm outputs the lexicographically smallest deadlocked trio.

*Proof.*  
Existence follows from Lemma&nbsp;4.  
The printed triple is a triangle by Lemma&nbsp;2 and is lexicographically
minimal by Lemma&nbsp;3. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency*: `O(m)` bit operations.  
*Main loops*: at most `n·(n-1)/2 ≤ 2·10⁶` iterations (for `n=2000`).  
All operations inside are O(1) bitwise ops on Python integers of size
≈ 2000 bits, which are fast.  
Hence total time `O(n² + m) ≤ 2·10⁶`, well below the limit.

Memory: `n+1` integers, each ≤ `2^{n+1}` → about `n·(n/8)` bytes ≈ 0.5 MB,
far under 256 MB.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [0] * (n + 1)          # 1‑based
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u] |= 1 << v
        adj[v] |= 1 << u

    full_mask = (1 << (n + 1)) - 1   # bits 0..n
    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if (adj[a] >> b) & 1 == 0:
                continue
            common = adj[a] & adj[b]
            # keep only vertices > b
            mask = ~((1 << (b + 1)) - 1) & full_mask
            common &= mask
            if common:
                low = common & -common          # lowest set bit
                c = low.bit_length() - 1
                sys.stdout.write(f"{a} {b} {c}")
                return

if __name__ == "__main__":
    solve()
```

conforms to the required input‑output format.
