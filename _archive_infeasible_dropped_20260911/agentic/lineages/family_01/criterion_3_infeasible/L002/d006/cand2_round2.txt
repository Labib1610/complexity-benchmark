<STATEMENT>
# Component Synergy Verification

## Time and Memory Limits
Time limit: 2 s
Memory limit: 256 MB

## Description
A manufacturing facility has a roster of $n$ component types, identified by integers from $1$ to $n$. Over time, there have been $m$ documented stable pairings. Each stable pairing is an unordered pair of distinct component types that can be assembled together.

The management intended to divide the components into two independent product lines, but the documented stable pairings make this impossible. To formally document this scheduling failure, you must locate a specific obstruction: a complete synergy trio.

A complete synergy trio is a set of exactly three distinct component types for which there exist exactly three distinct stable pairings in the given documentation such that the union of these three pairings is exactly this set of three component types. 

Because the number of possible 3-element subsets is large, you must systematically search the stable pairings to find one such trio. If there are multiple complete synergy trios, you must report the trio whose component IDs, when sorted in increasing order, form the lexicographically smallest sequence. That is, compare the smallest ID of the trios, then the middle ID, and finally the highest ID, selecting the trio with the smallest sequence of values.

## Input
The first line provides two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2\cdot 10^5)$), indicating the total number of component types and the total number of stable pairings.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing a stable pairing between component type $u$ and component type $v$. The stable pairings are distinct, meaning no two lines in the input will represent the same unordered pair of component types. It is guaranteed that at least one complete synergy trio exists.

## Output
Output a single line containing three integers $a$, $b$, and $c$, ordered such that $a < b < c$, representing the IDs of the three component types in the chosen complete synergy trio. The printed trio $\{a, b, c\}$ must be valid according to the definition: there must exist three distinct stable pairings in the input whose union is exactly the set $\{a, b, c\}$. If multiple such valid trios exist, output the one that is lexicographically smallest. (That is, among all valid trios $a < b < c$, choose the one with the smallest $a$; if there is a tie, choose the one with the smallest $b$; and if still tied, choose the one with the smallest $c$.)

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
The problem was completely reframed from finding a complete triad of conflicting technicians to identifying a "complete synergy trio" of components. Crucially, the condition that "all three 2-element subsets are present" has been replaced with the mathematically equivalent condition that "the union of exactly three distinct stable pairings is exactly this set of three component types." This forces models to reason about the implications of set unions of pairs, disrupting standard graph-triangle pattern matching while maintaining exact equivalence.
</RATIONALE>
<PRESERVED_ANSWER>
The only way three distinct 2-element subsets can have a union of exactly three elements is if they are all three possible 2-element subsets of those three elements, making the "complete synergy trio" identical to a triangle (or a completely fractured triad), preserving all answers.
</PRESERVED_ANSWER>
