<METHOD_NAME>
Induced Subgraph Degree Constraint
</METHOD_NAME>
<METHOD_DESCRIPTION>
Instead of defining the target structure directly as a set of 3 elements where all 3 pairs exist (a triangle), this framing defines it as a subset of 3 elements where each element appears in exactly 2 pairs restricted to that subset. This describes a 2-regular induced subgraph on 3 vertices, which is mathematically equivalent to a triangle. Models that pattern-match will likely translate this literally into an O(n^3) naive check and fail the time limit, while models that reason mathematically will deduce it's a triangle and use the optimal O(nm/64) bitset algorithm.
</METHOD_DESCRIPTION>

yes

<STATEMENT>
# Culinary Triad Selection

## Time and Memory Limits
Time limit: 2 s
Memory limit: 256 MB

## Description
A chef is designing a new menu using a catalog of $n$ ingredients, identified by integers from $1$ to $n$. The chef has a cookbook containing $m$ distinct recipes. Each recipe requires exactly two different ingredients.

The chef wants to feature a special menu built around a *closed culinary triad*. A closed culinary triad is a subset of exactly three distinct ingredients that satisfies the following condition: if you consider only the recipes that can be prepared using exclusively ingredients from this subset, each of the three ingredients must be part of exactly two of these recipes. (A recipe can be prepared using exclusively ingredients from a subset if both of its required ingredients are present in that subset).

Because the number of possible three-ingredient subsets is large, you must systematically search the cookbook to find a closed culinary triad. If multiple closed culinary triads exist, you must identify the definitive one. To determine the definitive triad, let the three ingredient IDs of each triad be $x, y,$ and $z$, such that $x < y < z$. The definitive triad is the one that minimizes $x$. If multiple triads share the same minimum $x$, choose the one among them that minimizes $y$. If there is still a tie, choose the one that minimizes $z$.

## Input
The first line provides two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2\cdot 10^5)$), indicating the total number of ingredients and the total number of recipes.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing a recipe that requires ingredient $u$ and ingredient $v$. All $m$ recipes are distinct. It is guaranteed that at least one closed culinary triad exists.

## Output
Output a single line containing three integers $x$, $y$, and $z$, ordered such that $x < y < z$, representing the IDs of the three ingredients in the definitive closed culinary triad.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
Previous versions failed because they described the structure as "all three pairs exist," which models easily map to a triangle and solve using optimal graph algorithms. By redefining the target as a degree-2 constraint on an induced subgraph of 3 elements, models that rely on surface pattern-matching will likely implement a literal, naive $O(n^3)$ check and fail the time limit. Only models that genuinely reason about algorithmic structure will deduce that this condition mathematically guarantees all 3 pairs exist, recognize it as a triangle, and apply the necessary bitset optimization.
</RATIONALE>
<PRESERVED_ANSWER>
Any subset of exactly three elements where each element is part of exactly two pairs within the subset must contain all three possible pairs, making it structurally identical to a completely fractured triad, so the correct output remains exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a 3-clique in an undirected graph, keeping the time complexity, optimal algorithm, and infeasibility certificate nature identical.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret "each of the three ingredients must be part of exactly two of these recipes" as referring to the global count of recipes they appear in, though the preceding clause explicitly restricts the scope to only the recipes within the subset.
</RISK>
