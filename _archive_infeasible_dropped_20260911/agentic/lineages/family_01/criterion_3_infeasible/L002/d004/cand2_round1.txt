# Conflict Resolution Certification

Time limit: 2 s
Memory limit: 256 MB

A manufacturing facility has a roster of $n$ technicians. Over time, there have been $m$ formal grievances logged. Each report is a log entry stating that technician $u$ has filed a grievance against technician $v$. 

To formally document a scheduling failure, you must locate a specific obstruction. We define the conflict state of the facility algebraically. 
Each technician $x$ (from $1$ to $n$) is represented by a state vector $V_x$ of length $m$. Initially, all components of every state vector are $0$.
For the $i$-th grievance report (1-indexed, from $1$ to $m$), where technician $u$ filed against technician $v$:
- The $i$-th component of $u$'s vector is set to $1$ ($V_u[i] = 1$).
- The $i$-th component of $v$'s vector is set to $-1$ ($V_v[i] = -1$).

An obstruction is defined as a triad of three distinct technicians $a, b,$ and $c$ (ordered such that $a < b < c$) where the standard dot product of their state vectors satisfies:
- $V_a \cdot V_b < 0$
- $V_b \cdot V_c < 0$
- $V_a \cdot V_c < 0$

Because the number of possible three-person combinations is large, you must systematically search to find one. If there are multiple qualifying triads of technicians, you must report the triad that is ordered first according to technician ID. That is, select the triad with the lexicographically smallest sequence $(a, b, c)$.

## Input
The first line provides two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2\cdot 10^5)$), indicating the total number of technicians and the total number of grievance reports.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing the $i$-th log entry where technician $u$ filed a grievance against technician $v$. It is guaranteed that at least one such triad of distinct technicians exists.

## Output
Output a single line containing three integers $a$, $b$, and $c$, ordered such that $a < b < c$, representing the IDs of the three technicians in the chosen triad. If multiple such triads exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
Replaced the "symmetric separation" description with an algebraic equivalent: state vectors where each grievance sets a `1` and `-1` at the log's index. The condition for an obstruction is now that the dot products of the technicians' state vectors are strictly negative. This forces the model to mathematically deduce that $V_a \cdot V_b < 0$ is exactly equivalent to an undirected edge, punishing models that attempt to blindly simulate the dense vector operations with Memory Limit Exceeded (1.6GB vs 256MB) or Time Limit Exceeded.
</RATIONALE>
<PRESERVED_ANSWER>
The dot product $V_a \cdot V_b$ accumulates a $-1$ for every log entry involving both $a$ and $b$, and $0$ otherwise, meaning $V_a \cdot V_b < 0$ if and only if there is at least one grievance between them, exactly preserving the original symmetric separation logic.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically first triangle in an undirected graph, keeping the complexity class unchanged.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the 1-indexed vector components if they use 0-indexed arrays, but the problem explicitly says "1-indexed, from 1 to m", making it unambiguous.
</RISK>
