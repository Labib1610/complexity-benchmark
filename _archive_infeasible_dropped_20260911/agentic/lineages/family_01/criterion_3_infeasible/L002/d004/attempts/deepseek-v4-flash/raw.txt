We need to find a completely fractured triad: three distinct technicians such that each pair among them has at least one grievance in either direction.

We can represent the grievance logs as an undirected graph (since the direction doesn’t matter for the condition — we just need at least one edge between each pair).  
Then the problem reduces to finding a triangle in an undirected graph, with the lexicographically smallest triangle.

Since \(n \le 2000\), we can use an adjacency matrix (boolean) for fast edge lookups.

**Approach:**
1. Read input, build adjacency matrix.
2. Iterate over all triples `(i, j, k)` in increasing order, and check if all three edges exist.
3. The first one found in lexicographic order is the answer.

We can optimize by iterating `i` from 1 to n, `j` from i+1 to n, `k` from j+1 to n, and break early when found.

Complexity: \(O(n^3)\) worst case, but with n=2000 that's 8e9 — too slow.  
We need a better approach.

**Better approach:**
We can iterate over pairs `(i, j)` and check for a common neighbor `k` that is larger than `j`.  
We can store adjacency as sets for fast intersection.

Algorithm:
- For each `i` from 1 to n:
  - For each `j` from i+1 to n:
    - If edge(i,j) exists:
      - Find smallest `k > j` such that edge(i,k) and edge(j,k) exist.
      - If found, output (i,j,k) and exit.

This is \(O(n^2)\) pairs, each checking neighbors — with sets it's efficient enough.

Let's implement:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n+1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for i in range(1, n+1):
        for j in range(i+1, n+1):
            if j in adj[i]:
                # find smallest k > j connected to both
                common = adj[i] & adj[j]
                for k in sorted(common):
                    if k > j:
                        print(i, j, k)
                        return

if __name__ == "__main__":
    main()
```
