<METHOD_NAME>INCIDENCE_SET_INTERSECTION</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the direct description of a symmetric relationship (an undirected graph) with the condition that the sets of incident log IDs for three technicians have pairwise non-empty intersections. Models relying on surface keywords to identify graph problems will fail to recognize the equivalence and implement naive set intersections, leading to a Time Limit Exceeded error. Models that reason mathematically will deduce this is exactly equivalent to finding a triangle in an undirected graph and will use an optimized algorithm.</METHOD_DESCRIPTION>

<STATEMENT>
# Conflict Resolution Certification

Time limit: 2 s
Memory limit: 256 MB

A manufacturing facility has a roster of $n$ technicians. Over time, there have been $m$ formal grievance reports logged. Each report is sequentially assigned a unique log ID from $1$ to $m$. A report specifies that one technician filed a grievance against another.

For each technician $x$, we define their involvement set $S_x$ as the set of all log IDs for reports in which technician $x$ is mentioned (either as the one filing the grievance or as the one being complained about).

The management needs to formally document a scheduling failure by locating a specific obstruction triad. An obstruction triad is a sequence of three distinct technician IDs $a$, $b$, and $c$ (with $a < b < c$) such that all three of the following conditions hold simultaneously:
1. The intersection of $S_a$ and $S_b$ is not empty.
2. The intersection of $S_b$ and $S_c$ is not empty.
3. The intersection of $S_a$ and $S_c$ is not empty.

Because the number of possible three-person combinations is large, you must systematically search the grievance logs to find one. If there are multiple qualifying triads, you must report the one that is lexicographically smallest. A triad $(a_1, b_1, c_1)$ is lexicographically smaller than $(a_2, b_2, c_2)$ if $a_1 < a_2$, or if $a_1 = a_2$ and $b_1 < b_2$, or if $a_1 = a_2$ and $b_1 = b_2$ and $c_1 < c_2$.

## Input
The first line provides two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2\cdot 10^5)$), indicating the total number of technicians and the total number of grievance reports.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing a report where technician $u$ filed a grievance against technician $v$. The lines are given in chronological order, corresponding to log IDs $1, 2, \ldots, m$. It is guaranteed that at least one such triad of distinct technicians exists.

## Output
Output a single line containing three integers $a$, $b$, and $c$, representing the IDs of the three technicians in the chosen triad.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
Removed the explicit mention of "symmetric separation" and replaced it with a mathematically equivalent condition based on the intersection of involvement sets (the sets of log IDs a technician appears in). This removes the linguistic affordance that models used to immediately construct an undirected adjacency matrix, forcing them to deduce the graph structure from the set intersection properties to avoid a Time Limit Exceeded verdict from naive implementation.
</RATIONALE>
<PRESERVED_ANSWER>
Because every log entry involves exactly two distinct technicians, the intersection of two technicians' involvement sets is non-empty if and only if there is a log entry involving both of them, which is exactly equivalent to the symmetric separation condition in the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a triangle (K3) in an undirected graph, which maintains the polynomial time complexity and certificate-style infeasibility class of the original.
</PRESERVED_CLASS>
