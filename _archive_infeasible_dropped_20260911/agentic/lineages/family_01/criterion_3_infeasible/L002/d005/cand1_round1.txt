<STATEMENT>
# Conflict Resolution Certification

## Time and Memory Limits
Time limit: 2 s
Memory limit: 256 MB

## Description
A manufacturing facility has a roster of $n$ technicians. Over time, there have been $m$ formal grievances logged. Each grievance is recorded as a log entry (numbered $1$ to $m$ in the order they are given). Each entry specifies that technician $u$ filed a grievance against technician $v$. 

The management intended to divide the staff into two shifts, but the logged grievances make this impossible. To formally document this scheduling failure, you must locate a specific obstruction: a completely fractured triad. 

For any technician, their *involvement dossier* is defined as the set of all log entry indices (from $1$ to $m$) where they appear as either the filer or the receiver.

A completely fractured triad is defined as a group of exactly three distinct technicians such that their involvement dossiers share pairwise commonalities. Specifically, for every pair of technicians within this group of three, the intersection of their dossiers must not be empty.

Because the number of possible three-person combinations is large, you must systematically search the records to find one. If there are multiple completely fractured triads, you must report the triad whose IDs are lexicographically smallest when sorted in increasing numerical order (i.e., compare the lowest ID of the triads, then the middle ID, and finally the highest ID, selecting the triad with the smallest sequence of values).

## Input
The first line provides two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2\cdot 10^5)$), indicating the total number of technicians and the total number of grievance reports.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing a log entry where technician $u$ filed a grievance against technician $v$. It is guaranteed that at least one completely fractured triad exists.

## Output
Output a single line containing three integers $a$, $b$, and $c$, ordered such that $a < b < c$, representing the IDs of the three technicians in the chosen triad. If multiple such triads exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
The suggested S12 strategy (requiring directed edges for x < y) was rejected because it violates the hard IDENTICAL ANSWERS constraint (it would change the expected output for some valid undirected triangles). Instead, using AGGRESSIVE MODE, the problem was reframed using index set intersections. 
The condition for an edge is now presented as a non-empty intersection between two technicians' "involvement dossiers" (sets of log indices). Models that literally translate this into code will build sets of size m and perform O(n^3) set intersections, leading to TLE. Models that reason about the structure will realize that a log index only appears in two dossiers, so the intersection is non-empty if and only if there is a log directly between the two technicians, allowing them to build a standard O(n) adjacency matrix and pass.
</RATIONALE>
<PRESERVED_ANSWER>
Because a log entry only involves two distinct technicians, the intersection of their dossiers is non-empty if and only if there is a log entry directly between them, which is exactly mathematically equivalent to the original undirected triangle condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a 3-clique (triangle) in an undirected graph, keeping it in the same complexity class.
</PRESERVED_CLASS>
