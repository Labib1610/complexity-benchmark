<METHOD_DESCRIPTION>Defines the triad condition based on filtering the entire grievance log down to entries involving only the triad's members, and counting the unique unordered pairs present. This mathematically equates to an undirected triangle, but models translating the text literally via surface pattern matching will write an O(n^3 * m) or O(n^3) filter-and-count loop, resulting in a Time Limit Exceeded failure.</METHOD_DESCRIPTION>

<STATEMENT>
# Conflict Resolution Certification

## Time and Memory Limits
Time limit: 2 s
Memory limit: 256 MB

## Description
A manufacturing facility has a roster of $n$ technicians. Over time, there have been $m$ formal grievances logged. Each report is a log entry stating that technician $u$ has filed a grievance against technician $v$. 

The management intended to divide the staff into two shifts, but the logged grievances make this impossible. To formally document this scheduling failure, you must locate a specific obstruction: a completely fractured triad. 

A triad is a group of exactly three distinct technicians. To determine if a triad is completely fractured, you must evaluate its *internal conflict footprint*. 
First, filter the full grievance log to retain only those entries where both the filer and the receiver are members of this chosen triad. 
Then, for each log entry remaining in the filtered log, identify the unordered pair of technicians involved. 
The triad is completely fractured if and only if exactly 3 unique unordered pairs are identified in this way. (For example, a report from $X$ to $Y$ and a report from $Y$ to $X$ both identify the same unordered pair $\{X, Y\}$).

Because the number of possible three-person combinations is large, you must systematically search to find one. If there are multiple completely fractured triads, you must report the triad that is ordered first according to technician ID. That is, when each triad's IDs are written in increasing numerical order, you must select the one that is lexicographically smallest (compare the lowest ID of the triads, then the middle ID, and finally the highest ID, selecting the triad with the smallest sequence of values).

## Input
The first line provides two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2\cdot 10^5)$), indicating the total number of technicians and the total number of grievance reports.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing a log entry where technician $u$ filed a grievance against technician $v$. It is guaranteed that at least one completely fractured triad exists.

## Output
Output a single line containing three integers $a$, $b$, and $c$, ordered such that $a < b < c$, representing the IDs of the three technicians in the chosen triad. If multiple such triads exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
The definition of the triad was changed from a pairwise connection property to a data-processing task (filtering the log and counting unique unordered pairs). This forces models to genuinely deduce that "3 unique pairs out of 3 members" is mathematically equivalent to an undirected triangle; models that literally implement the described filter-and-count process will fail via Time Limit Exceeded due to O(n^3) complexity.
</RATIONALE>
<PRESERVED_ANSWER>
A group of 3 technicians has exactly 3 possible unordered pairs; the filtered log contains all 3 unique pairs if and only if every pair shares at least one grievance, which is exactly the undirected triangle condition from the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains the detection of an undirected K3 (triangle) in a graph, preserving the certificate-style infeasibility complexity class.
</PRESERVED_CLASS>
