We can model the problem as finding a triangle in an undirected graph where an edge exists if there is at least one grievance between the two technicians (in either direction).  

Since \( n \) can be up to 2000, we can use an adjacency matrix (boolean) for fast edge checks, and then iterate over all triples in lexicographic order until we find a triangle.  

Here’s the implementation:  

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = True
        adj[v][u] = True
    
    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if not adj[a][b]:
                continue
            for c in range(b + 1, n + 1):
                if adj[a][c] and adj[b][c]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
