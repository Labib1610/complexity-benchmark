We need to find a triangle in the graph (three employees with exactly three edges among them).  
Since the graph can have up to 2000 nodes and 200,000 edges, we can use an adjacency matrix or bitsets for fast neighbor checks.

We’ll iterate over possible triples in lexicographic order and check if all three edges exist.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(n):
        for b in range(a + 1, n):
            if b not in adj[a]:
                continue
            for c in range(b + 1, n):
                if c in adj[a] and c in adj[b]:
                    print(a + 1, b + 1, c + 1)
                    return

if __name__ == "__main__":
    main()
```
