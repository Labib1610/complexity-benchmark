**Solution Explanation**

For every employee we store the set of his neighbours (the flagged pairs) as a
bitset.  
`adj[x]` is an integer whose *i‑th* bit (`i = 0 … n‑1`) is `1` iff the pair
`(x , i+1)` is in the log.

A required subset of three employees is exactly a **triangle** in the undirected
graph defined by the log.  
We have to output the lexicographically smallest triangle
`a < b < c`.

--------------------------------------------------------------------

#### Finding the smallest triangle

```
for a = 1 … n
    for b = a+1 … n
        if (a,b) is an edge:
            common = adj[a] & adj[b]          # vertices adjacent to both a and b
            # we need a vertex c > b
            mask = common >> b                # discard bits ≤ b
            if mask != 0:
                # lowest set bit of mask → smallest possible c
                low = (mask & -mask).bit_length() - 1
                c = b + 1 + low
                output a b c
```

*Why does it work?*

* `adj[a] & adj[b]` contains exactly the vertices adjacent to **both** `a`
  and `b`.  
* Shifting right by `b` removes all vertices `≤ b`.  
  If the resulting mask is non‑zero, there exists at least one vertex `c > b`
  forming a triangle with `a` and `b`.  
* The lowest set bit of the mask corresponds to the smallest such `c`,
  therefore the first triangle we encounter while iterating `a` increasingly
  and, for each `a`, `b` increasingly, is the lexicographically smallest one.

The loops examine at most `n·(n‑1)/2 ≤ 2·10⁶` pairs, each iteration performs only
a few integer operations – well inside the limits.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest triangle.

---

**Lemma 1**  
For any vertices `a < b`, after the test `if (a,b) is an edge`,
`mask = (adj[a] & adj[b]) >> b` is non‑zero **iff** there exists a vertex
`c > b` such that `{a,b,c}` is a triangle.

*Proof.*  
`adj[a] & adj[b]` contains exactly the vertices adjacent to both `a` and `b`.  
Shifting right by `b` discards bits for vertices `1 … b`.  
Thus a bit remains set in `mask` exactly when the corresponding vertex `c`
satisfies `c > b` and is adjacent to both `a` and `b`. ∎



**Lemma 2**  
If `mask` is non‑zero, the vertex `c` computed by the algorithm
(`c = b + 1 + low`) is the smallest vertex `> b` that together with `a` and `b`
forms a triangle.

*Proof.*  
`low` is the index of the least significant set bit of `mask`.  
That bit corresponds to the smallest vertex among those represented in `mask`,
i.e. the smallest `c > b` with the required edges. Adding `b+1` restores the
original vertex number. ∎



**Lemma 3**  
When the algorithm prints a triple `(a,b,c)`, it is a triangle and
`a < b < c`.

*Proof.*  
`a < b` by loop construction.  
The edge `(a,b)` is checked before proceeding, so it exists.  
By Lemma&nbsp;1 a vertex `c > b` with edges `(a,c)` and `(b,c)` exists,
and by Lemma&nbsp;2 the algorithm chooses such a `c`. Hence all three edges
are present and `a<b<c`. ∎



**Lemma 4**  
Let `T* = (a*,b*,c*)` be the lexicographically smallest triangle.
The algorithm will output `T*`.

*Proof.*  
Consider the outer loop iteration with `a = a*`.  
All `b < a*` are processed earlier, but any triangle with such `b` would have
first element `< a*`, contradicting minimality of `a*`.  
Now inside this `a*` iteration, the inner loop reaches `b = b*`.  
Since `(a*,b*)` is an edge, the algorithm reaches the mask computation.
By Lemma&nbsp;1 the mask is non‑zero (because `c*` exists) and by Lemma&nbsp;2
the algorithm will pick the smallest possible `c`, which is exactly `c*`
(because any smaller `c` would give a lexicographically smaller triangle).
Thus the algorithm prints `(a*,b*,c*)`. ∎



**Theorem**  
The algorithm always terminates and prints the lexicographically smallest
subset of three employees that forms a triangle.

*Proof.*  
The double loop iterates over a finite number of pairs, therefore terminates.
By Lemma&nbsp;3 any printed triple is a valid triangle.
By Lemma&nbsp;4 the first printed triangle is exactly the lexicographically
smallest one. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency bitsets*: `O(m)`  
*Main loops*: at most `n·(n‑1)/2 ≤ 2·10⁶` iterations, each `O(1)`.

```
Time   : O(n² + m)   ≤ 2·10⁶ operations  (well below 2 s)
Memory : O(n) integers, each ≤ 2ⁿ bits → about n·(n/8) bytes ≈ 0.5 MB
```

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * (n + 1)          # 1‑based
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u] |= 1 << (v - 1)
        adj[v] |= 1 << (u - 1)

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if (adj[a] >> (b - 1)) & 1:          # edge (a,b) exists
                common = adj[a] & adj[b]
                mask = common >> b                # keep only vertices > b
                if mask:
                    low = (mask & -mask).bit_length() - 1
                    c = b + 1 + low
                    sys.stdout.write(f"{a} {b} {c}")
                    return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
