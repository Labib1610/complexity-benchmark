# Problem C — Worker Incompatibilities

Time limit: 2 s   Memory limit: 256 MB

The factory is analyzing its workforce. You are provided with a log of joint assignment prohibitions between employees. Your task is to identify a group of exactly three distinct workers such that every worker in the group possesses a joint assignment prohibition record with both of the other two members. It is guaranteed that the provided log contains at least one such group. Output one such group.

## Input
The first line contains two integers $n$ and $m$. The factory's headcount, $n$, requires a minimum staffing level of three, up to a maximum facility capacity of two thousand. The number of logged records, $m$, is at least three, and reaches a maximum of either the total number of unique worker pairs or the database hard limit of two hundred thousand, whichever is lower.
Each of the next $m$ lines contains two integers $u$ and $v$ — denoting that a joint assignment for worker $u$ and worker $v$ is prohibited.
It is guaranteed that at least one valid group of three workers exists.

## Output
Print three integers $a$, $b$, and $c$ on one line with $a < b < c$ such that the records prohibit $a$ with $b$, $a$ with $c$, and $b$ with $c$. To resolve ties among multiple valid groups, output the one that minimizes $a$; if still tied, minimize $b$; if still tied, minimize $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
I replaced explicit graph-like terms ("conflicts", "mutually conflict") with a scenario about "joint assignment prohibitions" to disrupt simple keyword matching for triangle finding. Additionally, following Strategy S07, the explicit numeric bounds for $n$ and $m$ were removed and replaced with physical and system limits (e.g., minimum staffing, facility capacity, database limits), forcing models to extract these constraints from natural language.
</RATIONALE>
<PRESERVED_ANSWER>
The problem still strictly requires finding the lexicographically smallest set of three entities that are pairwise connected by the provided input pairs, ensuring identical outputs for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying task remains finding a 3-clique (triangle) in an undirected graph, which is solvable in the same polynomial time bounds (e.g., $O(m \sqrt{m})$ or $O(nm/64)$) using adjacency lists or bitsets.
</PRESERVED_CLASS>
<RISK>
The phrase "total number of unique worker pairs" is intended to mean $\binom{n}{2}$, but a model might misinterpret it as $n(n-1)$ if it assumes ordered pairs; however, "unique pairs" standardly implies unordered combinations in this context.
</RISK>
