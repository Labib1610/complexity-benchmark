We need to find three distinct suppliers that form a triangle (three pairwise agreements).  
The lexicographically smallest such triple is required.

We can iterate over all triples in sorted order and check if all three edges exist.  
Since \( n \leq 2000 \), we can use an adjacency matrix for O(1) edge lookup.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = adj[v][u] = True

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if adj[a][b]:
                for c in range(b + 1, n + 1):
                    if adj[a][c] and adj[b][c]:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    main()
```
