This forces models to algebraically deduce that the three distinct sets of size 2 must be the exact pairs of the triad, preventing surface-level pattern-matching to standard triangle-finding algorithms unless they complete this logical deduction.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem C — Linear Formation

Time limit: 2 s
Memory limit: 256 MB

A choreographer is attempting to arrange $N$ drones (identified by integers $1$ through $N$) along a single straight axis in the sky.
The performance requires $M$ strict distance links. Each link is a set of exactly two distinct drones that must be positioned exactly 1 meter apart from each other on the axis.

The choreographer already knows that a valid arrangement on a single straight line is physically impossible for the given links. Your task is to provide a concrete proof of this impossibility.
To do this, you must find a "spatial contradiction". A spatial contradiction is a set of exactly three distinct drones $V = \{a, b, c\}$ such that there exist three distinct links in the input, say $L_1, L_2,$ and $L_3$, whose union is exactly $V$. Mathematically, this requires $L_1 \cup L_2 \cup L_3 = V$. This creates a situation where three drones must all be exactly 1 meter apart from one another, which is impossible on a 1D line.

Output the identifiers of these three drones. It is guaranteed that the input contains at least one such contradiction.

## Input
The first line contains two integers $N$ and $M$ ($3 \le N \le 2000$, $3 \le M \le \min(N \cdot (N-1)/2, 2 \cdot 10^5)$).
Each of the next $M$ lines contains two integers $u$ and $v$ — the two drones comprising a single distance link. Each pair of drones appears at most once in the input.
It is guaranteed that at least one spatial contradiction exists.

## Output
Print three integers $a$, $b$, and $c$ on one line with $a < b < c$, representing the identifiers of the three drones. Output the lexicographically smallest such combination (smallest $a$; ties broken by smallest $b$; then smallest $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
The problem was reframed from a generic organizational grouping task to a 1D geometric embedding task. The core condition (finding a triangle) was changed from asking the model to count internal connections to satisfying a strict set-theoretic equation ($L_1 \cup L_2 \cup L_3 = V$). This forces the model to logically deduce that the only way three distinct sets of size 2 can have a union of size 3 is if they form a complete closed triad, rather than relying on standard graph-theory vocabulary to trigger its triangle-finding heuristics.
</RATIONALE>
<PRESERVED_ANSWER>
The set equation $L_1 \cup L_2 \cup L_3 = V$ uniquely requires the three links to be exactly the three possible pairs among $\{a, b, c\}$, which is mathematically identical to finding a triangle in the original graph.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains a certificate of infeasibility for 2-coloring, as embedding unit distances on a 1D line is structurally identical to bipartite 2-coloring, and a triangle is the minimal proof of impossibility in both domains.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "whose union is exactly V" if they fail to treat the links $L_i$ as mathematical sets of two elements, though the text explicitly defines "Each link is a set of exactly two distinct drones" to prevent this.
</RISK>
