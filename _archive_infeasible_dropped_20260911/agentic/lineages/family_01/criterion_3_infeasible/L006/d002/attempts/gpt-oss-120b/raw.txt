**Solution Explanation**

For three suppliers `a < b < c` we need all three agreements  

`(a,b) , (a,c) , (b,c)` – a *triangle* in the undirected graph.
The required answer is the lexicographically smallest triangle
(the smallest `a`, then smallest `b`, then smallest `c`).

`n ≤ 2000`, therefore a 2000‑bit integer fits easily into a Python `int`.
We store for every vertex `v` a bit mask

```
mask[v]  –  the i‑th bit is 1  ⇔  (v , i) is an agreement
```

With a mask we can test the existence of an edge in *O(1)*
and we can intersect two neighbour sets by a single bitwise **and**.

--------------------------------------------------------------------

#### Algorithm
```
read n , m
mask[0 … n‑1] = 0
adj[0 … n‑1]  = empty list               # adjacency lists, will be sorted

for each input edge (u , v)                # vertices are 1‑based in input
        u-- ; v--
        mask[u] |= 1 << v
        mask[v] |= 1 << u
        adj[u].append(v)
        adj[v].append(u)

for every vertex i : sort(adj[i])          # ascending, needed for lexicographic order

for a = 0 … n‑1
        for b in adj[a]                     # neighbours of a, already sorted
                if b <= a : continue        # we only need a < b
                common = mask[a] & mask[b]  # vertices adjacent to BOTH a and b
                # we need c > b, therefore discard bits ≤ b
                common >>= (b + 1)          # shift right, bit 0 now corresponds to vertex b+1
                if common != 0 :
                        # lowest set bit → smallest possible c
                        lowest = common & -common          # isolates least significant 1
                        pos    = lowest.bit_length() - 1   # its index (0‑based)
                        c = b + 1 + pos
                        output a+1 , b+1 , c+1            # back to 1‑based
                        terminate
```

The outer loops examine edges `(a,b)` in the order required for lexicographic
minimality: first increasing `a`, for a fixed `a` increasing `b`.
For a fixed `(a,b)` we pick the smallest `c > b` that is adjacent to both,
exactly what the definition of the lexicographically smallest triangle demands.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest triangle.

---

##### Lemma 1  
For a fixed pair `a < b` the algorithm, if it finds a vertex `c`,
outputs the smallest possible `c` (`c > b`) such that `{a,b,c}` is a triangle.

**Proof.**  
`common = mask[a] & mask[b]` contains precisely the vertices adjacent to *both*
`a` and `b`. After `common >>= (b+1)` all bits belonging to vertices `≤ b`
are discarded; the remaining least significant `1` corresponds to the smallest
vertex `c > b` still present. The algorithm extracts this least significant `1`,
hence `c` is the smallest feasible one. ∎



##### Lemma 2  
If the algorithm outputs a triple `(a,b,c)`, it is a triangle.

**Proof.**  
`b` is taken from `adj[a]`, therefore edge `(a,b)` exists.  
`c` is obtained from `common = mask[a] & mask[b]`, i.e. the bit for `c`
is set in both `mask[a]` and `mask[b]`. Consequently edges `(a,c)` and `(b,c)`
exist. All three edges are present, so `{a,b,c}` is a triangle. ∎



##### Lemma 3  
Let `(a\*, b\*, c\*)` be the lexicographically smallest triangle
in the whole graph.  
When the outer loops reach `a = a\*` and then `b = b\*`,
the condition `common != 0` holds and the algorithm outputs `(a\*,b\*,c\*)`.

**Proof.**  
Since `(a\*,b\*,c\*)` is a triangle, `b\*` is a neighbour of `a\*`,
so the inner loop iterates over `b = b\*`.  
Vertex `c\*` is adjacent to both `a\*` and `b\*`, therefore its bit is set in
`common = mask[a\*] & mask[b\*]`. Because `c\* > b\*`, this bit survives the
right shift, thus `common != 0`.  
By Lemma&nbsp;1 the algorithm picks the smallest such `c`; if a smaller
`c > b\*` existed, `{a\*,b\*,c}` would be a lexicographically smaller triangle,
contradicting the minimality of `(a\*,b\*,c\*)`. Hence the algorithm returns
exactly `(a\*,b\*,c\*)`. ∎



##### Lemma 4  
No triangle lexicographically smaller than the one output by the algorithm
exists.

**Proof.**  
Assume the algorithm outputs `(a,b,c)`.  
All pairs `(a',b')` examined before `(a,b)` satisfy either `a' < a` or
`a' = a` and `b' < b`. For each such pair Lemma&nbsp;1 guarantees that the
algorithm would have discovered the smallest possible third vertex,
therefore it would have printed a triangle earlier if one existed.
Thus no triangle with a smaller `(a',b')` exists.
If a triangle with the same `(a,b)` but a smaller `c` existed,
Lemma&nbsp;1 would have chosen it instead of `c`. Hence none exists.
∎



##### Theorem  
The algorithm always terminates and prints the lexicographically smallest
triple of distinct suppliers that are pairwise connected.

**Proof.**  
Termination: the outer loops iterate over all `m` edges, a finite number,
and each iteration does only constant‑time work; therefore the algorithm
terminates.  
Existence of output: the statement guarantees at least one triangle, and
by Lemma&nbsp;3 the algorithm will encounter its edges and output it.  
Minimality: Lemma&nbsp;4 shows that no lexicographically smaller triangle can
exist, while Lemma&nbsp;2 guarantees that the printed triple is indeed a
triangle. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building masks and adjacency lists* : `O(n + m)` time, `O(n + m)` memory.  

*Main loops* : each edge `(a,b)` is processed once (`b > a`),  
constant‑time bit operations ⇒ `O(m)` time.  

Overall  

```
Time   :  O(n + m)   ≤  O(2·10^5)
Memory :  O(n + m)   ≤  a few MB      (2000·2000‑bit masks ≈ 0.5 MiB)
```

Both limits satisfy the problem constraints easily.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    # adjacency masks: bit i set ⇔ edge to vertex i
    masks = [0] * n
    # adjacency lists for ordered iteration
    adj = [[] for _ in range(n)]

    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        masks[u] |= 1 << v
        masks[v] |= 1 << u
        adj[u].append(v)
        adj[v].append(u)

    for lst in adj:
        lst.sort()

    for a in range(n):
        ma = masks[a]
        for b in adj[a]:
            if b <= a:
                continue
            # vertices adjacent to both a and b
            common = ma & masks[b]
            # discard vertices <= b
            common >>= (b + 1)
            if common:
                # lowest set bit = smallest possible c
                lowest = common & -common
                pos = lowest.bit_length() - 1
                c = b + 1 + pos
                # output 1‑based indices
                print(a + 1, b + 1, c + 1)
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
