# Problem C — Phase Distortion Proof

Time limit: 2 s
Memory limit: 256 MB

An acoustic engineer is assigning each of $n$ broadcast frequencies to one of two phase channels (alpha or beta). Certain pairs of frequencies produce harmonic distortion if broadcast on the same phase channel, meaning they must be isolated into different channels.

The engineer already knows that a valid two-channel assignment is impossible for the given system. Your task is to pinpoint the core reason by providing a concrete proof of this impossibility. Specifically, you must locate a set of three distinct frequencies where every possible pair within the set produces harmonic distortion. Because each pair within this triplet conflicts, it is logically impossible to divide the three frequencies across only two channels without placing at least one distorting pair in the same channel.

Output these three frequencies. It is guaranteed that the test logs contain at least one such triplet.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the identifiers of two frequencies that produce harmonic distortion when combined.
It is guaranteed that at least one triplet of mutually distorting frequencies exists.

## Output
Print three integers $a$, $b$, and $c$ on one line with $a < b < c$, representing the identifiers of the three frequencies. Output the lexicographically smallest such combination (smallest $a$; ties broken by smallest $b$; then smallest $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
