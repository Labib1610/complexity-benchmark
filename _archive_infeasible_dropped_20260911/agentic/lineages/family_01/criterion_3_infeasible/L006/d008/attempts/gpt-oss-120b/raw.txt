**Solution Explanation**

For every registry `i` we keep the set of registries that are connected to it
(the bits that are `1`).  
The condition  

```
R_{x1}(x2) = R_{x1}(x3) = R_{x2}(x3) = 1
```

means that the three vertices `x1 , x2 , x3` form a triangle in the undirected
graph whose edges are the given pulses.

We have to output the lexicographically smallest triangle
(`x1 < x2 < x3`, smallest `x1`, then `x2`, then `x3`).

--------------------------------------------------------------------

#### 1.   Data structure – bitset

`n ≤ 2000`, therefore a whole adjacency row fits into a 2000‑bit integer.
In Python an `int` can store an arbitrary number of bits, bit operations are
implemented in C and are very fast.

```
adj[i]  – integer, bit (j‑1) is 1  ⇔  edge (i , j) exists
```

Building `adj` is `O(m)`.

--------------------------------------------------------------------

#### 2.   Searching the smallest triangle

```
for x1 = 1 … n-2
    for x2 = x1+1 … n-1
        if edge (x1,x2) does not exist: continue
        inter = adj[x1] & adj[x2]          # vertices adjacent to both
        # we need a vertex larger than x2
        mask = inter >> x2                 # drop bits ≤ x2
        if mask != 0:
            # position of the least significant 1‑bit
            lsb = (mask & -mask).bit_length() - 1
            x3 = x2 + 1 + lsb
            output x1, x2, x3
            stop
```

* `inter` is the set of common neighbours of `x1` and `x2`.
* `mask` removes all vertices `≤ x2`; the remaining bits correspond to
  possible `x3`.
* `mask & -mask` isolates the lowest set bit, `bit_length()-1` gives its
  index – the smallest admissible `x3`.

The loops enumerate `(x1, x2)` in lexicographic order, and for a fixed pair
the smallest possible `x3` is chosen, therefore the first triangle found is
exactly the required answer.

Complexity  

* outer loops – at most `n·(n-1)/2 ≤ 2·10⁶` iterations (`n = 2000`);
* each iteration does only a few integer operations (`&`, `>>`, bit tricks).

Overall time `O(n²)` (well below the 2 s limit) and memory `O(n)`.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest triangle.

---

##### Lemma 1  
For any pair of vertices `a < b` the expression  

```
inter = adj[a] & adj[b]
mask  = inter >> b
```

has a set bit at position `k` (0‑based) **iff** vertex `c = b+1+k` satisfies
`c > b` and edges `(a,c)` and `(b,c)` exist.

**Proof.**  
`adj[a]` has bit `c-1` set exactly when `(a,c)` is an edge, similarly for
`adj[b]`. The bitwise `&` keeps a bit only if it is set in both rows, i.e.
both edges exist. Shifting right by `b` discards bits `0 … b-1`, i.e. vertices
`≤ b`. The remaining bits correspond precisely to vertices `c > b`. ∎



##### Lemma 2  
If `mask ≠ 0` then the vertex  

```
c = b + 1 + ((mask & -mask).bit_length() - 1)
```

is the smallest vertex `c > b` that together with `a , b` forms a triangle.

**Proof.**  
`mask & -mask` isolates the least significant `1`‑bit of `mask`. Its index
(`lsb`) is the smallest index of a set bit, therefore the smallest `c`
represented in `mask`. Adding `b+1` converts the index back to the original
vertex number. By Lemma&nbsp;1 this `c` is adjacent to both `a` and `b`. ∎



##### Lemma 3  
When the algorithm terminates it outputs a triangle.

**Proof.**  
Termination happens only when `mask ≠ 0`. By Lemma&nbsp;2 the computed `x3`
is adjacent to both `x1` and `x2`. The loop condition guarantees that
`(x1,x2)` is an edge, therefore all three edges exist – a triangle. ∎



##### Lemma 4  
Let `T = (p,q,r)` be the triangle output by the algorithm.
For any triangle `T' = (p',q',r')` we have the lexicographic order
`(p,q,r) ≤ (p',q',r')`.

**Proof.**  
The outer loop scans `x1` increasingly; the first time a triangle is found,
its first vertex `p` is the smallest possible among all triangles,
otherwise the loop would have examined a smaller `x1` earlier and found a
triangle there.

Fix this `p`. The inner loop scans `x2` increasingly. The algorithm stops at
the first `x2 = q` for which a suitable `x3` exists, therefore `q` is the
smallest second vertex among triangles whose first vertex equals `p`.

Finally, for this pair `(p,q)` Lemma&nbsp;2 returns the smallest admissible
`x3`, i.e. the smallest third vertex. Hence `r` is minimal for the fixed
`p,q`. Consequently no other triangle can be lexicographically smaller. ∎



##### Theorem  
The algorithm always terminates and prints the lexicographically smallest
triple `x1 < x2 < x3` such that all three corresponding edges are present.

**Proof.**  
Existence of at least one triangle is guaranteed, therefore some iteration
will have `mask ≠ 0` and the algorithm terminates. By Lemma&nbsp;3 the printed
triple is a triangle. By Lemma&nbsp;4 it is the lexicographically smallest
such triangle. ∎

#### 4.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    # adjacency as bitsets, 1‑based indexing
    adj = [0] * (n + 1)
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        # set bits (v-1) in adj[u] and (u-1) in adj[v]
        adj[u] |= 1 << (v - 1)
        adj[v] |= 1 << (u - 1)

    for x1 in range(1, n - 1):
        row1 = adj[x1]
        for x2 in range(x1 + 1, n):
            # edge (x1,x2) ?
            if not (row1 >> (x2 - 1)) & 1:
                continue
            inter = row1 & adj[x2]
            # keep only vertices > x2
            mask = inter >> x2
            if mask:
                # position of least significant 1‑bit
                lsb = (mask & -mask).bit_length() - 1
                x3 = x2 + 1 + lsb
                sys.stdout.write(f"{x1} {x2} {x3}")
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
