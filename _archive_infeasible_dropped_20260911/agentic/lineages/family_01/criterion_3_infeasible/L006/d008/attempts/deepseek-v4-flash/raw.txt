We can model the registries as an undirected graph where each pulse adds an edge between two nodes.  
The condition for a resonance anomaly is that the three nodes form a triangle in the graph.  

We need to find the lexicographically smallest triangle.  

A direct O(n³) check is too slow for n = 2000, but we can use adjacency lists and check only possible triangles efficiently.  

Here’s the implementation:  

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
    
    # Try to find lexicographically smallest triangle
    for i in range(n):
        for j in adj[i]:
            if j > i:
                # Check common neighbors between i and j
                common = adj[i] & adj[j]
                if common:
                    k = min(common)
                    if k > j:
                        print(i + 1, j + 1, k + 1)
                        return

if __name__ == "__main__":
    solve()
```
