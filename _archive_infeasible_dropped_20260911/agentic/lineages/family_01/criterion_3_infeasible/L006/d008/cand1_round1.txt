<STATEMENT>
# Problem C — Registry Resonance

Time limit: 2 s
Memory limit: 256 MB

You are analyzing a system of $n$ independent memory registries, numbered $1$ to $n$. Each registry contains $n$ state bits, all initially set to $0$.

The system receives $m$ synchronization pulses. Each pulse is defined by a pair of registry IDs $(u, v)$. Upon receiving this pulse, registry $u$ sets its $v$-th state bit to $1$, and registry $v$ sets its $u$-th state bit to $1$.

Let $R_i(k)$ denote the integer value of the $k$-th state bit in the $i$-th registry.
A critical resonance anomaly occurs if there exist three registry IDs $x_1, x_2$, and $x_3$ strictly increasing in value ($x_1 < x_2 < x_3$) such that:
$$R_{x_1}(x_2) \cdot R_{x_1}(x_3) \cdot R_{x_2}(x_3) = 1$$

You must find the IDs involved in this anomaly. It is guaranteed that the sequence of pulses produces at least one such configuration.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n(n-1)/2, 200000)$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a synchronization pulse between registry $u$ and registry $v$.
It is guaranteed that at least one resonance anomaly exists.

## Output
Print three integers $x_1$, $x_2$, and $x_3$ on one line with $x_1 < x_2 < x_3$. Output the lexicographically smallest such combination (smallest $x_1$; ties broken by smallest $x_2$; then smallest $x_3$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
I removed the explicit description of a "closed loop", "mutual authorization", and the textual expansion of the three connections. I replaced it with an algebraic product of state variables equaling 1. This forces the model to either deduce the underlying graph triangle structure from the algebraic equation or attempt a direct $O(N^3)$ evaluation which is prone to TLE, preventing reliance on keyword-triggered graph templates.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $R_{x_1}(x_2) \cdot R_{x_1}(x_3) \cdot R_{x_2}(x_3) = 1$ is mathematically identical to the three flags being true in the seed problem, preserving the exact same valid sets of $(x_1, x_2, x_3)$.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a 3-clique (triangle) in an undirected graph, maintaining its INFEASIBLE / triangle-finding complexity class.
</PRESERVED_CLASS>
<RISK>
Models might be confused by the mathematical notation if they don't realize it refers to the 0/1 bit values, though "integer value of the k-th state bit" strongly implies standard 0/1 arithmetic.
</RISK>

This prevents models from textually mapping the structural description to a graph triangle, forcing them to either parse the algebra into a graph structure or implement a naïve equation solver.
