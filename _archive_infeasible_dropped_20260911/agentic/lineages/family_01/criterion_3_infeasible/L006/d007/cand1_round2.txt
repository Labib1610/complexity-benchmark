<STATEMENT>
# System Deadlock Verification

Time limit: 2 s
Memory limit: 256 MB

You are analyzing a system with $n$ processes, identified by integers from $1$ to $n$. The system has a log of $m$ resource-sharing events. Each event is a record of two distinct processes interacting. No two records describe the same pair of processes.

Your task is to identify a "deadlock kernel" to prove that the system cannot be safely divided into two independent execution phases. 

A deadlock kernel is defined as a set of exactly three distinct processes such that, if you filter the entire log of $m$ events to keep only those events where both interacting processes belong to this three-process set, exactly $3$ events remain.

You must output the identifiers of the three processes in the deadlock kernel. It is guaranteed that at least one such kernel exists in the system.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n(n-1)/2, 200000)$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of processes involved in a resource-sharing event.
It is guaranteed that at least one deadlock kernel exists.

## Output
Print three integers $a$, $b$, and $c$ on one line with $a < b < c$, representing the identifiers of the three processes in the deadlock kernel. Output the lexicographically smallest such combination (smallest $a$; ties broken by smallest $b$; then smallest $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
Instead of describing three explicit pairwise connections between $a$, $b$, and $c$, the problem now requires finding a 3-element set that wholly contains exactly 3 input pairs. This forces the model to realize that a 3-element set has exactly 3 possible pairs, so all three must be present, rather than pattern-matching a triangle definition directly.
</RATIONALE>
<PRESERVED_ANSWER>
Any 3-element set containing exactly 3 pairs from a simple graph is a triangle, which is mathematically identical to the original a-b, b-c, a-c requirement, preserving all answers.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core task is still to find a triangle in an undirected graph, maintaining the INFEASIBLE complexity class.
</PRESERVED_CLASS>
<RISK>
A model might misunderstand "both interacting processes belong to this three-process set", though the wording is precise and standard for induced subset filtering.
</RISK>
