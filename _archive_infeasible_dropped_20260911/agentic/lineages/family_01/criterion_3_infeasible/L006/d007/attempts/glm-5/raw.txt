To solve this problem, we need to find three distinct profiles \(a, b, c\) (with \(a < b < c\)) such that:
1. In profile \(a\), flags \(b\) and \(c\) are both true.
2. In profile \(b\), flag \(c\) is true.

This means that the edges \((a, b)\), \((a, c)\), and \((b, c)\) must all exist in the graph formed by the mutual authorizations. Essentially, we are looking for a triangle in the graph where the vertices are ordered \(a < b < c\), and we want the lexicographically smallest such triangle.

### Approach
1. **Graph Representation**: Represent the graph using adjacency lists. For each node, maintain a set of neighbors to allow efficient lookups.
2. **Finding Triangles**: For each node \(a\) (from 1 to \(n\)), iterate over all pairs of its neighbors \(b\) and \(c\) where \(b < c\). Check if there is an edge between \(b\) and \(c\). If such an edge exists, then \(a, b, c\) form a triangle. Since we process nodes in increasing order, the first valid triangle found will be the lexicographically smallest one.
3. **Efficiency**: To ensure efficiency, for each node \(a\), we only consider neighbors \(b\) and \(c\) that are greater than \(a\) (since \(a < b < c\)). This reduces the number of checks needed. Additionally, for each pair \((b, c)\), we check if \(c\) is a neighbor of \(b\) (or vice versa) to confirm the triangle.

### Solution Code
```python
import sys

def solve():
    input = sys.stdin.read().split()
    ptr = 0
    n, m = map(int, input[ptr:ptr+2])
    ptr +=2
    
    adj = [set() for _ in range(n+1)]
    for _ in range(m):
        u, v = map(int, input[ptr:ptr+2])
        ptr +=2
        if u > v:
            u, v = v, u
        adj[u].add(v)
        adj[v].add(u)
    
    # We need to find a < b < c such that a is connected to b and c, and b is connected to c.
    # Iterate a from 1 to n, then for each a, iterate b in adj[a] where b > a, then c in adj[a] where c > b, and check if c is in adj[b].
    for a in range(1, n+1):
        neighbors_a = sorted(adj[a])
        len_a = len(neighbors_a)
        for i in range(len_a):
            b = neighbors_a[i]
            if b <= a:
                continue
            for j in range(i+1, len_a):
                c = neighbors_a[j]
                if c <= b:
                    continue
                if c in adj[b]:
                    print(a, b, c)
                    return
    # Shouldn't reach here per problem statement
    print(-1, -1, -1)

solve()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Graph Construction**: The graph is represented using adjacency sets for each node to allow O(1) lookups for edge existence.
3. **Finding Triangles**: The algorithm iterates over each node \(a\) in ascending order. For each \(a\), it checks all pairs of neighbors \(b\) and \(c\) (where \(b < c\)) to see if \(c\) is also a neighbor of \(b\). The first such triplet found is printed immediately, ensuring the lexicographically smallest solution due to the order of iteration.
4. **Efficiency**: The nested loops are optimized by only considering neighbors \(b\) and \(c\) that are greater than \(a\) and \(b\) respectively, reducing unnecessary checks. The use of sets for adjacency lists ensures that checking for the existence of an edge between \(b\) and \(c\) is done in constant time.

This approach efficiently checks for the presence of triangles in the graph while ensuring the solution is found in lexicographical order, leveraging the constraints to optimize the search process.
