We can model the profiles and their mutual authorizations as an undirected graph.  
A tri-level escalation `(a, b, c)` with `a < b < c` means:

- Edge `(a, b)` exists
- Edge `(a, c)` exists
- Edge `(b, c)` exists

So we are looking for a triangle in the graph, and we need the lexicographically smallest one.

Since `n` can be up to 2000, we can use an adjacency matrix (boolean) for fast edge checks, and iterate over `a`, then `b`, then `c` in increasing order, stopping at the first found triangle.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = True
        adj[v][u] = True

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if not adj[a][b]:
                continue
            for c in range(b + 1, n + 1):
                if adj[a][c] and adj[b][c]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
