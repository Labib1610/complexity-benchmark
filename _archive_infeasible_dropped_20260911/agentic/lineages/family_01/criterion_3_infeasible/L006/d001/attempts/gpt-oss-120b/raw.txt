**Solution Explanation**

For every supplier we know the list of other suppliers it has a non‑compete agreement with.
The required proof is a *triangle* – three vertices `a<b<c` such that all three edges
`(a,b) , (a,c) , (b,c)` exist.

The graph contains at least one triangle.
Among all triangles we have to output the lexicographically smallest sorted triple
`(a,b,c)`.



--------------------------------------------------------------------

#### 1.   Data representation  

`n ≤ 2000`, therefore for every vertex we store its adjacency set as a bitset
inside one Python `int`.

```
bit i (0‑based)  == 1   ⇔   vertex (i+1) is a neighbour
```

For an edge `u – v`

```
adj[u] |= 1 << (v‑1)
adj[v] |= 1 << (u‑1)
```

All bit operations are O(1).

--------------------------------------------------------------------

#### 2.   Searching the smallest triangle  

We iterate over the first two vertices in increasing order – exactly the order
required for lexicographic minimality.

```
for a = 1 … n
    for b = a+1 … n
        if edge (a,b) exists:
            common = adj[a] & adj[b]          # vertices adjacent to both a and b
            keep only vertices > b
            cand = common & mask               # mask has bits b … n‑1 set
            if cand ≠ 0:
                c = index of lowest set bit in cand   (smallest possible c)
                output a b c
                stop
```

*Why does it work?*

* the outer loops enumerate `(a,b)` lexicographically.
* for a fixed `(a,b)` we choose the **smallest** `c` that is adjacent to both,
  i.e. the lowest set bit of `cand`.
* therefore the first triangle we encounter is exactly the lexicographically
  smallest triple.

Finding the lowest set bit:

```
low = cand & -cand                # isolates the lowest 1‑bit
c   = low.bit_length()            # 1‑based vertex number
```

The whole algorithm touches `O(n²)` pairs (`≤ 2·10⁶`) and each step is O(1),
well inside the limits.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest triangle.

---

##### Lemma 1  
For any vertices `a<b` the variable `cand` contains exactly the vertices `c`
such that `{a,b,c}` is a triangle and `c>b`.

**Proof.**  
`common = adj[a] & adj[b]` contains precisely the vertices adjacent to **both**
`a` and `b`.  
`mask` has bits `b … n‑1` set and lower bits cleared, therefore
`cand = common & mask` keeps from `common` only those vertices whose index
is larger than `b`. ∎



##### Lemma 2  
If `cand ≠ 0` then `c = low.bit_length()` is the smallest vertex `c>b`
forming a triangle with `a` and `b`.

**Proof.**  
`low = cand & -cand` isolates the least significant 1‑bit of `cand`,
i.e. the smallest index present in `cand`.  
`low.bit_length()` returns that index plus one (because indices are 0‑based
while vertex numbers are 1‑based).  
By Lemma&nbsp;1 every vertex in `cand` together with `a,b` forms a triangle,
hence the obtained `c` is the smallest such vertex. ∎



##### Lemma 3  
When the algorithm prints a triple `(a,b,c)` it is a triangle and
`a<b<c`.

**Proof.**  
The outer loops guarantee `a<b`.  
The inner `if` checks that edge `(a,b)` exists.  
By Lemma&nbsp;2 the printed `c` satisfies `c>b` and, together with `a` and `b`,
forms a triangle. ∎



##### Lemma 4  
Let `T` be the set of all triangles, each written with sorted vertices.
The algorithm outputs the lexicographically smallest element of `T`.

**Proof.**  
Consider the enumeration order of pairs `(a,b)` in the algorithm:
lexicographic increasing on `a` then `b`.  
Take the first pair `(a₀,b₀)` (in that order) for which a triangle exists.
All earlier pairs have no common neighbour larger than `b`,
otherwise the algorithm would have stopped earlier.
For this `(a₀,b₀)` Lemma&nbsp;2 returns the smallest possible `c₀>b₀`.
Thus `(a₀,b₀,c₀)` belongs to `T` and no triangle with a smaller first element
or the same first element and a smaller second element exists.
Consequently it is the lexicographically smallest triangle. ∎



##### Theorem  
The program always prints three integers `a<b<c` forming a triangle,
and this triple is the lexicographically smallest among all triangles of the
input graph.

**Proof.**  
Existence of at least one triangle is guaranteed by the statement.
During the scan the algorithm will eventually encounter a pair `(a,b)` that
belongs to some triangle, therefore the condition `cand ≠ 0` will become true
and the algorithm terminates.  
By Lemma&nbsp;3 the printed triple is a triangle with increasing order.
By Lemma&nbsp;4 it is the lexicographically smallest such triple. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency bitsets* : `O(m)`  
*Main double loop*          : `O(n²)` ≤ 2·10⁶ operations  
*Memory*                    : `n+1` integers, each ≤ 2ⁿ bits → at most
                              `2001 * 2000 / 8 ≈ 0.5 MiB` (negligible).

Both time (well below 2 s) and memory limits are satisfied.

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * (n + 1)               # bitset for each vertex, 1‑based
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u] |= 1 << (v - 1)
        adj[v] |= 1 << (u - 1)

    all_ones = (1 << n) - 1           # mask with bits 0..n-1 set

    for a in range(1, n + 1):
        a_adj = adj[a]
        for b in range(a + 1, n + 1):
            # edge (a,b) ?
            if (a_adj >> (b - 1)) & 1:
                # vertices adjacent to both a and b
                common = a_adj & adj[b]
                # keep only vertices with index > b (bits b..n-1)
                mask = all_ones ^ ((1 << b) - 1)
                cand = common & mask
                if cand:
                    low = cand & -cand            # lowest set bit
                    c = low.bit_length()          # 1‑based vertex number
                    sys.stdout.write(f"{a} {b} {c}")
                    return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
