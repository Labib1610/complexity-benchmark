We can model the suppliers as vertices, and agreements as edges in an undirected graph.  
We need to find a triangle, i.e., three vertices that are all pairwise connected, and return the lexicographically smallest triangle.

**Approach**:  
- Since `n` can be up to 2000, an `O(n^3)` check might be too slow.  
- We'll use adjacency sets for fast lookup.  
- We iterate over possible first two vertices `a` and `b` (with `a < b`) that are connected. Then we check if there exists a `c > b` that is connected to both `a` and `b`. If found, we immediately return since the scan is in lexicographic order.

Let’s implement this.  

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(n):
        for b in range(a+1, n):
            if b in adj[a]:
                # Intersect neighbors of a and b for c candidates > b
                common = adj[a] & adj[b]
                for c in sorted(common):
                    if c > b:
                        print(a+1, b+1, c+1)
                        return

if __name__ == "__main__":
    solve()
```
