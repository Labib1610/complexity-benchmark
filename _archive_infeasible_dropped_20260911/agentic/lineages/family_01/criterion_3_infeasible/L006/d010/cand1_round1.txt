# Problem C — Registry Resonance

Time limit: 2 s
Memory limit: 256 MB

A network of $n$ isolated memory registries (indexed $1$ through $n$) is being evaluated. During the evaluation, the network is exposed to a chronological series of $m$ synchronization pulses. We denote the sequential index of each incoming pulse as $k$ ($1 \le k \le m$).

Every registry $i$ tracks its own state using an $m$-dimensional vector $V_i$, which is initialized entirely to zeros.

Each pulse $k$ targets a specific pair of registries, given as $(u, v)$. When the $k$-th pulse arrives, registry $u$ and registry $v$ both update the $k$-th coordinate of their respective state vectors to a pulse-dependent weight $W_k$. For the first three pulses ($k \le 3$), this weight is $W_k = 1$. For all subsequent pulses ($k > 3$), the weight is signed and scales with time: $W_k = -k$. No other coordinates in any vector are modified by this pulse.

We evaluate the interference between any two registries $a$ and $b$ using the standard vector dot product, $V_a \cdot V_b = \sum_{k=1}^m V_a[k] \times V_b[k]$.

A critical resonance anomaly is triggered if there is a triplet of registries $x_1 < x_2 < x_3$ whose pairwise interferences satisfy the following strictly positive product condition:
$$ (V_{x_1} \cdot V_{x_2}) \cdot (V_{x_1} \cdot V_{x_3}) \cdot (V_{x_2} \cdot V_{x_3}) > 0 $$

Your task is to identify the registries involved in this anomaly. The input data guarantees that the pulse sequence will form at least one such triplet.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n(n-1)/2, 200000)$).
The following $m$ lines each contain two integers $u$ and $v$, representing the two registries targeted by the $k$-th pulse. The first of these lines describes the pulse at $k=1$, the second describes $k=2$, and so forth.
It is guaranteed that at least one critical resonance anomaly is present.

## Output
Output three integers $x_1$, $x_2$, and $x_3$ separated by spaces, representing the anomaly triplet with $x_1 < x_2 < x_3$. If multiple such anomalies exist, print the one that is lexicographically smallest (minimize $x_1$, then minimize $x_2$, then minimize $x_3$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
Changed the vector update rule to use signed, pulse-dependent weights ($W_k = 1$ for $k \le 3$, $W_k = -k$ for $k > 3$). This makes the dot product appear capable of being negative, tricking pattern-matching models into explicitly simulating the vectors and computing dot products (which causes MLE or TLE). Genuinely reasoning models will realize that since $W_k^2 > 0$, the dot product is still just a strictly positive indicator of edge existence, allowing them to use the intended adjacency list and bitset optimizations.
</RATIONALE>
<PRESERVED_ANSWER>
Because every shared pulse contributes $W_k^2 > 0$ to the dot product, $V_a \cdot V_b > 0$ if and only if $a$ and $b$ share a pulse, making the condition perfectly equivalent to finding a graph triangle, just like the seed.
</PRESERVED_ANSWER>
