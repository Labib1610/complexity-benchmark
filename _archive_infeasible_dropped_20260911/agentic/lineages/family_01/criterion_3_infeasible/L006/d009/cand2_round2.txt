<METHOD_DESCRIPTION>Replaces the condition of three mutually connected vertices with the mathematically equivalent condition that the 3x3 principal submatrix formed by their indices in the binary adjacency matrix has a determinant of 2. <STATEMENT>
# Problem C — Registry Resonance

Time limit: 2 s
Memory limit: 256 MB

You are analyzing a system of $n$ independent memory registries, numbered $1$ to $n$. The system's cross-registry interaction state is captured by an $n \times n$ matrix $Z$, where all entries $Z_{i,j}$ are initially $0$.

The system receives $m$ synchronization pulses. Each pulse is defined by a pair of registry IDs $(u, v)$. Upon receiving this pulse, the system updates the matrix by setting both $Z_{u,v} = 1$ and $Z_{v,u} = 1$. Multiple pulses between the same pair of registries have no additional effect, and a registry never pulses with itself (the main diagonal of $Z$ remains entirely $0$).

A critical resonance anomaly is triggered by a triplet of registries. Specifically, an anomaly occurs if there exist three registry IDs $x_1, x_2$, and $x_3$ strictly increasing in value ($x_1 < x_2 < x_3$) such that the determinant of the $3 \times 3$ matrix $M$, defined by $M_{i,j} = Z_{x_i, x_j}$ for $1 \le i \le 3$ and $1 \le j \le 3$, is exactly $2$.

You must find the IDs involved in this anomaly. It is guaranteed that the sequence of pulses produces at least one such configuration.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n(n-1)/2, 200000)$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a synchronization pulse between registry $u$ and registry $v$.
It is guaranteed that at least one resonance anomaly exists.

## Output
Print three integers $x_1$, $x_2$, and $x_3$ on one line with $x_1 < x_2 < x_3$. Output the lexicographically smallest such combination (smallest $x_1$; ties broken by smallest $x_2$; then smallest $x_3$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
Replaced the direct bitwise anomaly condition with a mathematically equivalent linear algebra condition: the determinant of the 3x3 principal submatrix being exactly 2. To succeed efficiently, the model must symbolically evaluate the determinant of a hollow symmetric 3x3 binary matrix, realize it evaluates to $2abc$, and deduce that the condition simply means $a=b=c=1$ (i.e., finding a triangle in an undirected graph).
</RATIONALE>
<PRESERVED_ANSWER>
The determinant of the 3x3 matrix $M$ with zeros on the diagonal and symmetric $a,b,c \in \{0,1\}$ on the off-diagonals is exactly $2abc$, which equals 2 if and only if $a=b=c=1$, making the condition mathematically identical to the original triangle requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a 3-clique (triangle) in a simple undirected graph, which maintains the identical complexity class and allows the exact same bitset optimization algorithm.
</PRESERVED_CLASS>
