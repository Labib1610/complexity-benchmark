We can model each registry’s state vector as a bitmask of length m.  
The dot product between two registries is the number of pulses they share.  
A resonance anomaly exists if three registries are pairwise connected by at least one common pulse.

We need the lexicographically smallest triple (x1, x2, x3) with x1 < x2 < x3 such that all three pairwise dot products are > 0.

A direct O(n^3) check is too slow for n up to 2000.  
We can instead:

1. Represent each registry’s vector as a Python integer bitmask (since m ≤ 200000, but we can use bitset operations).
2. For each pair (i, j), compute the intersection count using bitwise AND and check if > 0.
3. Store adjacency: for each i, keep a list of j > i such that dot(i, j) > 0.
4. Then iterate i from 1 to n, and for each j in adj[i], check if there exists k > j in adj[i] ∩ adj[j].  
   To do this efficiently, we can precompute adjacency as bitsets (Python integers) and use bitwise AND to find common neighbors.

Since n ≤ 2000, we can store adjacency as a list of Python integers (bitsets) of length n.  
Then for each i, for each j in adj[i], compute common = adj[i] & adj[j], and pick the smallest k > j in common.

Let’s implement this.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    
    # We'll store for each registry a bitmask of pulses it participates in
    masks = [0] * (n + 1)
    
    for k in range(m):
        u, v = map(int, input().split())
        masks[u] |= (1 << k)
        masks[v] |= (1 << k)
    
    # Build adjacency bitsets: adj[i] has bit j set if dot(i,j) > 0
    adj = [0] * (n + 1)
    for i in range(1, n + 1):
        for j in range(i + 1, n + 1):
            if masks[i] & masks[j]:
                adj[i] |= (1 << j)
                adj[j] |= (1 << i)
    
    # Now find lexicographically smallest triple
    for x1 in range(1, n + 1):
        # Get neighbors of x1 with index > x1
        neigh = adj[x1] & ~((1 << (x1 + 1)) - 1)  # clear bits <= x1
        while neigh:
            # get smallest set bit
            lsb = neigh & -neigh
            x2 = lsb.bit_length()  # position of bit (1-indexed)
            # common neighbors of x1 and x2 with index > x2
            common = adj[x1] & adj[x2] & ~((1 << (x2 + 1)) - 1)
            if common:
                lsb2 = common & -common
                x3 = lsb2.bit_length()
                print(x1, x2, x3)
                return
            neigh ^= lsb

if __name__ == "__main__":
    main()
```
