**Solution Explanation**

For every supplier we store the set of suppliers it has an agreement with.
A triangle `a < b < c` exists iff  

* `a` is connected with `b`,
* `a` is connected with `c`,
* `b` is connected with `c`.

The required output is the lexicographically smallest such triple, i.e. the
smallest possible `a`; for that `a` the smallest possible `b`; for that pair the
smallest possible `c`.

--------------------------------------------------------------------

#### 1.   Bitset representation  

`n ≤ 2000`, therefore a set of neighbours fits into a 2000‑bit integer.
For vertex `v` we keep one integer `mask[v]` :

```
bit j of mask[v] = 1   ⇔   edge (v , j) exists
```

All operations on neighbour sets become fast bit operations on Python
integers.

--------------------------------------------------------------------

#### 2.   Searching the triangle  

```
for a = 0 … n-1
    for b = a+1 … n-1
        if edge a‑b exists
            inter = mask[a] & mask[b]          # common neighbours of a and b
            # we need a neighbour larger than b
            shifted = inter >> (b+1)
            if shifted != 0                     # at least one common neighbour > b
                # the least set bit gives the smallest possible c
                lsb = shifted & -shifted
                offset = lsb.bit_length() - 1    # position of that bit (0‑based)
                c = b + 1 + offset
                output a+1, b+1, c+1 and stop
```

*The outer loops enumerate `(a,b)` in increasing order, therefore the first
found triangle already has the smallest possible `a` and, for that `a`,
the smallest possible `b`.  
Inside the inner loop we take the **least** common neighbour larger than `b`,
hence the smallest possible `c`.  
Consequently the produced triple is the lexicographically smallest one.*

All operations inside the loops are O(1) on the size of the integer
(`≈ 2000 / wordsize` machine words), so the whole algorithm runs in  

```
O(n²)   ≤   2·10⁶   iterations
```

well inside the limits.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
triangle.

---

##### Lemma 1  
For any vertices `a < b`, `shifted = (mask[a] & mask[b]) >> (b+1)` is non‑zero
iff there exists a vertex `c > b` that is adjacent to both `a` and `b`.

**Proof.**  
`mask[a] & mask[b]` contains exactly the vertices adjacent to *both* `a` and
`b`. Shifting right by `b+1` discards bits `0 … b`.  
Thus a remaining set bit corresponds to a vertex `c > b` adjacent to both,
and conversely any such vertex creates a set bit after the shift. ∎



##### Lemma 2  
If `shifted` is non‑zero, the vertex `c` computed by the algorithm
(`c = b+1 + offset`) is the smallest vertex `> b` adjacent to both `a` and `b`.

**Proof.**  
`lsb = shifted & -shifted` isolates the least significant set bit of
`shifted`. Its position `offset` (0‑based) is the smallest index where
`shifted` has a 1. Adding `b+1` restores the original vertex number.
Therefore `c` is the smallest common neighbour larger than `b`. ∎



##### Lemma 3  
When the algorithm prints a triple `(a,b,c)`, it is a triangle
(`a<b<c` and all three edges exist).

**Proof.**  
The outer test `if (mask[a] >> b) & 1` guarantees edge `a‑b`.  
By Lemma&nbsp;1 the existence of a non‑zero `shifted` guarantees a vertex
`c > b` adjacent to both `a` and `b`.  
Thus edges `a‑c` and `b‑c` also exist, and the ordering `a<b<c` holds. ∎



##### Lemma 4  
Let `T` be the lexicographically smallest triangle in the graph.
The algorithm will output `T`.

**Proof.**  
Write `T = (a\*, b\*, c\*)` with `a\* < b\* < c\*`.  
During the double loop the pair `(a\*, b\*)` is examined, because the loops
enumerate all `a<b`.  
All earlier pairs `(a,b)` are either

* `a < a\*`, or
* `a = a\*` and `b < b\*`.

For any such earlier pair, either edge `a‑b` is missing, or (by definition of
`T`) there is **no** common neighbour larger than `b` (otherwise a triangle
lexicographically smaller than `T` would exist).  
Hence the algorithm does **not** stop before reaching `(a\*, b\*)`.

When `(a\*, b\*)` is processed, edge `a\*‑b\*` exists, and by Lemma&nbsp;1
`shifted` is non‑zero because `c\*` is a common neighbour larger than `b\*`.
Lemma&nbsp;2 shows that the algorithm chooses the smallest such neighbour,
which is exactly `c\*`.  
Consequently the algorithm prints `(a\*, b\*, c\*)`. ∎



##### Theorem  
The algorithm always terminates and prints the lexicographically smallest
triple of suppliers that form a triangle.

**Proof.**  
Termination follows because the double loop scans a finite number of pairs and
stops as soon as a triangle is found; a triangle is guaranteed to exist.
By Lemma&nbsp;3 any printed triple is a triangle.
By Lemma&nbsp;4 the first printed triangle is the lexicographically smallest
one. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Memory* : `n` integers, each ≤ `2ⁿ` → `O(n)` bits ≈ 2000 · 2000 / 8 ≈ 0.5 MiB.  

*Time* :

```
outer loops : n·(n-1)/2  ≤ 2·10⁶
inside each iteration : a few bitwise operations on ~2000‑bit integers
```

Overall `O(n²)` ≈ a few · 10⁶ elementary operations, well below the 2 s limit.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    n = next(it)
    m = next(it)

    masks = [0] * n          # neighbour bitsets
    for _ in range(m):
        u = next(it) - 1
        v = next(it) - 1
        masks[u] |= 1 << v
        masks[v] |= 1 << u

    for a in range(n):
        mask_a = masks[a]
        for b in range(a + 1, n):
            # edge a-b ?
            if (mask_a >> b) & 1:
                inter = mask_a & masks[b]          # common neighbours
                shifted = inter >> (b + 1)         # keep only > b
                if shifted:
                    # least set bit -> smallest c
                    lsb = shifted & -shifted
                    offset = lsb.bit_length() - 1
                    c = b + 1 + offset
                    # output 1‑based indices
                    sys.stdout.write(f"{a+1} {b+1} {c+1}")
                    return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
