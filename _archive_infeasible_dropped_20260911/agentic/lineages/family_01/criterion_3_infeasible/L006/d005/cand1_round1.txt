# Problem C — Proof of Collusion

Time limit: 2 s
Memory limit: 256 MB

An auditor is reviewing a network of regional suppliers (identified by integers $1$ through $n$). The compliance records contain $m$ bilateral non-compete agreements, each binding a specific pair of suppliers.

The auditor originally intended to divide all suppliers into exactly two independent oversight tiers such that no two suppliers in the same tier share an agreement. However, this two-tier division has been deemed impossible for the current records.

Your task is to extract a concrete proof of this impossibility by identifying a specific deadlock pattern. Define a symmetric boolean function $C(x, y)$ that evaluates to `True` if there is a recorded non-compete agreement between supplier $x$ and supplier $y$, and `False` otherwise. 

To demonstrate the deadlock, you must find a triplet of distinct suppliers $(a, b, c)$ such that the following logical expression evaluates to `True`:
$C(a, b) \text{ AND } C(b, c) \text{ AND } C(c, a)$

Because multiple such triplets might exist in the records, you must output the lexicographically smallest one. A triplet must be ordered such that $a < b < c$. Lexicographical comparison evaluates the first element $a$ first, breaks ties using the second element $b$, and finally resolves any remaining ties using the third element $c$.

## Input
The first line contains two integers $n$ and $m$. The supplier headcount $n$ ranges from a minimum of $3$ up to exactly $2000$. The agreement count $m$ is at least $3$, and is bounded by either the maximum possible number of unique pairs among the $n$ suppliers, or exactly $200000$, whichever is strictly smaller.
Each of the next $m$ lines contains two integers $u$ and $v$ — indicating that $C(u, v)$ and $C(v, u)$ are both `True`. Each pair is listed at most once.
It is guaranteed that at least one triplet satisfying the deadlock condition exists in the provided records.

## Output
Print three integers $a$, $b$, and $c$ on one line with $a < b < c$, representing the identifiers of the lexicographically smallest triplet.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

By replacing this physical description with a boolean expression over a symmetric function, models that rely on surface text matching will likely write a naive $O(n^3)$ loop and fail the time limit. Models that genuinely reason must logically deduce that to satisfy the expression efficiently, they should only iterate over pairs where the function is known to be true (the input edges) and intersect their remaining conditions.
</RATIONALE>
