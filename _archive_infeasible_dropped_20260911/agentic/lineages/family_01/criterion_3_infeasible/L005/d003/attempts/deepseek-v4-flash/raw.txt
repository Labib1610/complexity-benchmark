We need to find a triple \((a,b,c)\) with \(a<b<c\) such that for every choice of one person to be in a different period from the other two, the two who share a period have a friction report between them.

That means:  
For triple \((a,b,c)\), if we put \(a\) alone, then \(b\) and \(c\) must have an edge.  
If we put \(b\) alone, then \(a\) and \(c\) must have an edge.  
If we put \(c\) alone, then \(a\) and \(b\) must have an edge.

So the condition is:  
All three pairs \((a,b)\), \((a,c)\), \((b,c)\) must be edges in the graph.

Thus, we just need to find a triangle in the graph, and output the lexicographically smallest one.

We can do this efficiently with an adjacency matrix (since \(n \le 2000\)) and check all triples in sorted order.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = adj[v][u] = True

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if not adj[a][b]:
                continue
            for c in range(b + 1, n + 1):
                if adj[a][c] and adj[b][c]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
