We need to find three distinct individuals such that among the three logs connecting them, exactly three unique people appear.  
That means the three logs must form a triangle: three edges among three vertices.

So the problem reduces to: find the lexicographically smallest triangle in an undirected graph.

We can do this by iterating over possible smallest vertex `a`, then second smallest `b`, and checking if there is a `c > b` such that edges (a,b), (a,c), (b,c) all exist.

Since n ≤ 2000, we can use an adjacency matrix (boolean) for O(1) edge checks.

We iterate:
- for a from 1 to n:
  - for b from a+1 to n:
    - if edge(a,b) exists:
      - for c from b+1 to n:
        - if edge(a,c) and edge(b,c): output (a,b,c) and exit.

This is O(n^3) worst-case, but n=2000 gives 8e9 which is too large.  
We need a better approach.

We can instead iterate over edges (u,v) and check for a common neighbor w that is larger than both u and v, and pick the smallest such w.  
But we need lexicographically smallest triple, so we should iterate a from smallest to largest, then b, then c.

We can do:
- For each a from 1 to n:
  - For each b > a where edge(a,b) exists:
    - Find smallest c > b such that edge(a,c) and edge(b,c) exist.
    - If found, output and exit.

This is O(m * n) worst-case, but m ≤ 2e5 and n ≤ 2000, so 4e8 operations worst-case, might be borderline but okay in Python with optimizations.

We can precompute adjacency lists as sets for fast intersection.

Implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n+1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n+1):
        for b in sorted(adj[a]):
            if b <= a:
                continue
            # find smallest c > b connected to both a and b
            for c in sorted(adj[a]):
                if c <= b:
                    continue
                if c in adj[b]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    solve()
```
