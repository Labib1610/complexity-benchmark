**Solution Explanation**

For a vertex `v` let  

*`deg[v]`* – its degree (number of incident edges)  

*`Adj[v]`* – the set of its neighbours.

For three different vertices `a , b , c`

```
edges incident to at least one of {a,b,c}
        = deg[a] + deg[b] + deg[c] – (edges inside the set)
```

The statement of the problem requires this number to be  

`deg[a] + deg[b] + deg[c] – 3`.

Therefore the number of edges *inside* `{a,b,c}` must be exactly `3`,
i.e. the three vertices have to be pairwise adjacent – they form a **triangle**.

So the whole task is:

*find the lexicographically smallest triangle in the given undirected simple
graph (it is guaranteed that at least one exists).*

--------------------------------------------------------------------

#### 1.   Data structure – bitsets

`n ≤ 2000`.  
A Python integer can store an arbitrary bitset, therefore we keep for every
vertex `v` a bitset `Adj[v]` (`Adj[v]` has the `i`‑th bit set iff `v` is adjacent
to vertex `i`).  
All operations we need are:

* `Adj[u] & Adj[v]` – intersection of neighbour sets (bitwise **and**)
* test / extract the lowest set bit – `x & -x`
* position of a set bit – `bit_length() - 1`

All of them are `O(1)` for a 2000‑bit integer.

--------------------------------------------------------------------

#### 2.   Searching the smallest triangle

We enumerate the first vertex `a` in increasing order.
For a fixed `a` we enumerate the second vertex `b` (`b > a`) that is adjacent to `a`
also in increasing order.
For the pair `{a,b}` we look for a common neighbour `c` larger than `b`.

```
for a = 0 … n-1
        bits = Adj[a] shifted right by (a+1)          # neighbours > a
        while bits != 0
                b = a+1 + index_of_lowest_set_bit(bits)
                common = Adj[a] & Adj[b]               # neighbours of both
                mask = common shifted right by (b+1)   # keep only > b
                if mask != 0
                        c = b+1 + index_of_lowest_set_bit(mask)
                        output (a+1,b+1,c+1) and stop
                clear the processed lowest bit of bits
```

*Why is the first found triple lexicographically minimal?*

* `a` grows from the smallest possible value.
* for a fixed `a` the loop over `b` extracts the lowest set bit each time,
  i.e. `b` grows from the smallest neighbour larger than `a`.
* for a fixed pair `{a,b}` we again take the lowest set bit of the intersection,
  i.e. the smallest possible `c > b`.

Consequently the first triangle discovered is exactly the lexicographically
smallest one.

The whole algorithm touches every edge at most once (the inner `&` is executed
once per ordered edge `(a,b)` with `a<b`).  
All operations are constant‑time bit operations, therefore the total running
time is `O(m)` ( ≤ 2·10⁵ ) and the memory consumption is `O(n)`.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm always outputs the lexicographically smallest
triangle.

---

##### Lemma 1  
For any three distinct vertices `{a,b,c}` the condition of the statement
holds **iff** the three vertices form a triangle (all three edges are present).

**Proof.**  
The number of edges incident to at least one of the three vertices equals  

`deg[a] + deg[b] + deg[c] – t`, where `t` is the number of edges whose both
endpoints lie inside the set (each such edge is counted twice in the sum of
degrees).  
The required equality is  

`deg[a] + deg[b] + deg[c] – t = deg[a] + deg[b] + deg[c] – 3`,  
hence `t = 3`.  
`0 ≤ t ≤ 3`; `t = 3` means that all three possible edges are present,
i.e. `{a,b,c}` is a triangle. ∎



##### Lemma 2  
When the outer loop of the algorithm processes a vertex `a`,
the inner loop enumerates all neighbours `b` of `a` with `b > a`
exactly once and in strictly increasing order.

**Proof.**  
`Adj[a]` contains a `1` at position `v` iff `v` is a neighbour of `a`.  
Shifting it right by `a+1` discards bits `0 … a`.  
The remaining integer `bits` therefore has a `1` exactly at positions
`b-a-1` for neighbours `b > a`.  
Repeatedly extracting the lowest set bit (`bits & -bits`) yields the smallest
remaining neighbour, which is then cleared.  Hence each neighbour `b>a`
appears once, and the order is increasing. ∎



##### Lemma 3  
For a fixed ordered pair `(a,b)` with `a<b` and edge `ab`,
the algorithm finds the smallest vertex `c>b` that together with `a,b`
forms a triangle, if such a vertex exists.

**Proof.**  
`common = Adj[a] & Adj[b]` contains exactly the vertices adjacent to **both**
`a` and `b`.  
Shifting `common` right by `b+1` removes all vertices `≤ b`.  
If the resulting mask is non‑zero, its lowest set bit corresponds to the
smallest vertex `c>b` belonging to `common`, i.e. the smallest common neighbour
larger than `b`.  This `c` together with `a,b` is a triangle, and any other
triangle with the same `a,b` would have a larger `c`. ∎



##### Lemma 4  
If the algorithm outputs a triple `(a,b,c)`, then `{a,b,c}` is a triangle.

**Proof.**  
The algorithm outputs a triple only after it has found a non‑empty mask in
Lemma&nbsp;3, i.e. a vertex `c` that belongs to `Adj[a] ∩ Adj[b]`.  
Thus edges `ab`, `ac`, `bc` all exist, so `{a,b,c}` is a triangle. ∎



##### Lemma 5  
Let `T* = (a*,b*,c*)` be the lexicographically smallest triangle in the graph.
The algorithm outputs exactly `T*`.

**Proof.**  
Consider the moment the outer loop reaches `a = a*`.  
All earlier values `a < a*` cannot start a triangle lexicographically smaller
than `T*` (otherwise `T*` would not be minimal).  
Inside the outer loop, by Lemma&nbsp;2 the inner loop enumerates neighbours
`b` of `a*` in increasing order.  
The first neighbour `b` that belongs to a triangle with `a*` must be `b*`,
otherwise a triangle `(a*,b',c')` with `b' < b*` would be lexicographically
smaller than `T*`.  
For this pair `(a*,b*)` Lemma&nbsp;3 returns the smallest possible `c>b*`
forming a triangle, which must be `c*`.  
Consequently the algorithm outputs `(a*,b*,c*)` and stops before any later
triple could be considered. ∎



##### Theorem  
The program always prints three integers `a<b<c` that satisfy the condition
of the problem, and among all such triples it prints the lexicographically
smallest one.

**Proof.**  
By Lemma&nbsp;1 a triple satisfies the required condition exactly when it is a
triangle.  
Lemma&nbsp;4 shows that any triple printed by the algorithm is a triangle,
hence it satisfies the condition.  
Lemma&nbsp;5 proves that the printed triangle is the lexicographically smallest
among all triangles, therefore also the smallest among all triples satisfying
the condition. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Memory* : `Adj` – `n` integers, each ≤ 2ⁿ, i.e. `O(n)` bits → `O(n)` memory.  

*Time* :

* building the adjacency bitsets – `O(m)`
* outer loop over `a` (≤ n)  
  inner loop iterates over each edge `(a,b)` with `a<b` exactly once,
  each iteration performs a constant‑time bitwise `&` and a few integer
  operations → `O(m)`

Overall `O(n + m)` ≤ `O(2·10⁵)` operations, well inside the limits.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * n          # bitset of neighbours, 0‑based indices

    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u] |= 1 << v
        adj[v] |= 1 << u

    for a in range(n):
        # neighbours of a that are larger than a
        bits = adj[a] >> (a + 1)
        while bits:
            lsb = bits & -bits
            b_rel = lsb.bit_length() - 1          # position inside shifted bits
            b = a + 1 + b_rel

            # common neighbours of a and b
            common = adj[a] & adj[b]
            # keep only vertices > b
            mask = common >> (b + 1)
            if mask:
                lsb2 = mask & -mask
                c_rel = lsb2.bit_length() - 1
                c = b + 1 + c_rel
                # output 1‑based indices
                sys.stdout.write(f"{a+1} {b+1} {c+1}\n")
                return

            # remove processed b
            bits ^= lsb

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
