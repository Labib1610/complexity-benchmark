We need to find the lexicographically smallest triple \((a, b, c)\) with \(a < b < c\) such that all three edges \((a,b)\), \((a,c)\), \((b,c)\) exist in the graph.

Since \(n \le 2000\), we can use an adjacency matrix (boolean) for \(O(1)\) edge lookups, and iterate over all triples in sorted order until we find one.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = adj[v][u] = True

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if not adj[a][b]:
                continue
            for c in range(b + 1, n + 1):
                if adj[a][c] and adj[b][c]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
