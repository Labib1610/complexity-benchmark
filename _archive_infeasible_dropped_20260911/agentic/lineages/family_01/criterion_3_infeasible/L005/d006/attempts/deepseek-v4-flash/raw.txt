We can solve this by checking all triples, but that would be too slow.  
Instead, we can fix the smallest vertex `a` and iterate over its neighbors, keeping track of which neighbors are connected.  

We want the lexicographically smallest triangle, so we can try vertices in increasing order for `a`.

Here’s the approach in code:  

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
        edges.append((u, v))

    for a in range(1, n + 1):
        for b in adj[a]:
            if b < a:
                continue
            for c in adj[a]:
                if c <= b:
                    continue
                if c in adj[b]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
