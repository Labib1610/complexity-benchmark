We need to find a triple of vertices such that every 2-coloring of them forces at least one edge within the same color class.  

That means: for the triple {a, b, c}, the graph induced by these three vertices must **not** be bipartite. In other words, the three vertices must form a triangle (all three edges present).  

So the problem reduces to: find the lexicographically smallest triangle in the graph.  

We can do this by iterating over `a` from 1 to n, then `b` from a+1 to n, and checking if edge (a,b) exists. If yes, then for each `c` from b+1 to n, check if edges (a,c) and (b,c) exist. The first such triple found is the answer.  

Since n ≤ 2000, we can store adjacency in a boolean matrix for O(1) edge checks.  

Here’s the implementation:  

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = adj[v][u] = True

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if adj[a][b]:
                for c in range(b + 1, n + 1):
                    if adj[a][c] and adj[b][c]:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    main()
```
