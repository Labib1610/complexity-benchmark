**Solution Explanation**

For every person we keep the set of people he/she is incompatible with.
A triple `a<b<c` is a *bad* triple iff the three edges  
`a‑b , a‑c , b‑c` are present – i.e. the three vertices form a triangle in the
undirected graph of incompatibilities.

The input guarantees that at least one triangle exists.
We have to output the lexicographically smallest one
(minimum `a`, then minimum `b`, then minimum `c`).

--------------------------------------------------------------------

#### 1.   Data structure – bitset per vertex  

`n ≤ 2000`, therefore a vertex can be represented by a 2000‑bit integer.
Bit `i` (0‑based) of `adj[v]` is `1` **iff** vertex `v` is incompatible with vertex `i+1`.

* building the bitsets:   for each edge `u v`  

```
adj[u] |= 1 << (v-1)
adj[v] |= 1 << (u-1)
```

* testing the existence of an edge `a‑b`  

```
(adj[a] >> (b-1)) & 1
```

* common neighbours of `a` and `b`  

```
common = adj[a] & adj[b]
```

All operations are O(1) on Python’s big integers.

--------------------------------------------------------------------

#### 2.   Searching the lexicographically first triangle  

```
for a = 1 … n
    for b = a+1 … n
        if edge a‑b exists
            common = adj[a] & adj[b]           # vertices adjacent to both
            # we need c > b, therefore discard bits 0 … b-1
            common >>= b
            if common != 0                     # at least one such c exists
                low = (common & -common).bit_length() - 1   # index of least set bit
                c = b + 1 + low
                output a b c
                stop
```

*Why does it give the required order?*

* the outer loop increases `a` first → smallest possible `a`
* for a fixed `a` the inner loop increases `b` → smallest possible `b`
* after `a,b` are fixed, `common >>= b` removes every vertex `≤ b`.  
  The lowest remaining set bit corresponds to the smallest admissible `c`.

Thus the first triple we meet is exactly the lexicographically smallest triangle.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs the lexicographically minimal triangle.

---

##### Lemma 1  
For any vertices `a<b`, after the statement `common = adj[a] & adj[b]`,
`common` has bit `c-1` set **iff** `c` is adjacent to both `a` and `b`.

*Proof.*  
`adj[a]` has bit `c-1` set exactly when `a‑c` is an edge, similarly for `adj[b]`.
Bitwise AND keeps a bit only when it is set in both operands. ∎



##### Lemma 2  
After `common >>= b`, the lowest set bit (if any) corresponds to the smallest
vertex `c` such that `c>b` and `c` is adjacent to both `a` and `b`.

*Proof.*  
Shifting right by `b` discards bits `0 … b-1`, i.e. vertices `1 … b`.
All remaining bits keep their relative order, therefore the least significant
set bit after the shift is the smallest remaining vertex index `c'`.  
The original vertex number is `c = b + 1 + c'`. ∎



##### Lemma 3  
If the algorithm prints a triple `(a,b,c)`, then it is a triangle
(i.e. all three edges exist).

*Proof.*  
The algorithm prints only after confirming  

* edge `a‑b` exists (explicit test);
* `c` is obtained from Lemma&nbsp;2, therefore `c` is adjacent to both `a` and `b`
  (Lemma&nbsp;1). ∎



##### Lemma 4  
Let `T* = (a*,b*,c*)` be the lexicographically smallest triangle in the
graph. The algorithm will eventually consider the pair `(a*,b*)`.

*Proof.*  
Both `a*` and `b*` are vertices of the graph, with `a*<b*`.  
The outer loop iterates `a` over all vertices, the inner loop iterates `b>a`,
hence the pair `(a*,b*)` is examined. ∎



##### Lemma 5  
When the algorithm examines the pair `(a*,b*)`, it will output the triple
`(a*,b*,c*)`.

*Proof.*  
Because `T*` is a triangle, vertex `c*` is adjacent to both `a*` and `b*`.
By Lemma&nbsp;1, bit `c*-1` is set in `common = adj[a*] & adj[b*]`.  
Since `c* > b*`, after the shift `common >>= b*` the bit remains set.
All vertices `c > b*` that are adjacent to both `a*` and `b*` survive the shift,
and `c*` is the smallest among them (otherwise `T*` would not be lexicographically
minimal). By Lemma&nbsp;2 the algorithm extracts exactly this smallest `c`,
hence `c = c*` and it prints `(a*,b*,c*)`. ∎



##### Lemma 6  
The algorithm stops at the first printed triple and never prints a triangle
lexicographically larger than `T*`.

*Proof.*  
The loops run in increasing order of `a` then `b`.  
If a triangle with a smaller `a` existed, it would have been printed earlier.
If the same `a` but a smaller `b` existed, again it would be printed earlier.
Within the same `a,b` the algorithm chooses the smallest possible `c`
(Lemma&nbsp;2). Therefore any triangle printed before `T*` would be lexicographically
smaller, which contradicts the definition of `T*`. ∎



##### Theorem  
The algorithm terminates and outputs exactly the lexicographically smallest
triangle of the given graph.

*Proof.*  
Termination follows because the double loop examines a finite number of pairs.
By Lemma&nbsp;4 the pair belonging to `T*` is examined.
By Lemma&nbsp;5 the algorithm prints `T*` at that moment.
By Lemma&nbsp;6 no earlier printed triangle can be larger, thus the printed
triple is the lexicographically smallest triangle. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building bitsets* : `O(m)`  

*Main loops* : at most `n·(n-1)/2 ≤ 2·10⁶` iterations (for `n=2000`).  
Each iteration performs a constant‑time integer operation.  

```
Time   : O(n²)   ≤ 4·10⁶ elementary operations   (well below the limit)
Memory : n·(n bits) ≈ 2000·2000 ≈ 4·10⁶ bits ≈ 0.5 MiB
```

Both limits satisfy the problem constraints easily.

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    # adjacency as bitsets, 1‑based vertices, bits are 0‑based
    adj = [0] * (n + 1)
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u] |= 1 << (v - 1)
        adj[v] |= 1 << (u - 1)

    for a in range(1, n + 1):
        a_mask = adj[a]
        for b in range(a + 1, n + 1):
            # edge a‑b ?
            if (a_mask >> (b - 1)) & 1:
                common = a_mask & adj[b]
                # discard vertices ≤ b
                common >>= b
                if common:
                    # position of lowest set bit
                    low = (common & -common).bit_length() - 1
                    c = b + 1 + low
                    # output in increasing order (they already are)
                    sys.stdout.write(f"{a} {b} {c}")
                    return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
