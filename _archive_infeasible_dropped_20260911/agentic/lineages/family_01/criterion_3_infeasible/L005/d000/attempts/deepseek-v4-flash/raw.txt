We need to find a triangle in an undirected graph with up to   2000 nodes and  2·10⁵ edges.  
We can use adjacency sets for fast checks.  
A simple approach: iterate over all triples (a,b,c) in lexicographic order and check edges.  
But n=2000, so O(n³)) is too large.  
We need a more efficient method.

Observation: We only need the lexicographically smallest triangle.  
We can iterate a from 1 to n, then b from a+1 to n, and check if edge(a,b)) exists.  
If yes, then we need the smallest c > b such that edges(a,c) and(b,c) exist.  
We can precompute adjacency sets and for each a,b, iterate over neighbors of a that are > b and check if they are also neighbors of b.  
The worst-case complexity could still be high, but with n=2000 and m=2·10⁵, it's acceptable if we break early.

Let’s implement:

- Read n,m.
- Build adjacency sets (1-indexed).
- For a in 1..n:
    For b in a+1..n:
        if b in adj[a]:
            # find smallest c > b such that c in adj[a] and c in adj[b]
            for c in sorted(adj[a]):
                if c > b and c in adj[b]:
                    print(a,b,c); return
            # If none, continue
- If no triangle found (shouldn't happen), print nothing.

But iterating over sorted(adj[a]) for each b could be heavy.  
We can optimize: for each a, we can precompute sorted list of neighbors > a.  
Then for each b, we iterate over that list and check membership in adj[b].  
Since we break at first found, it's fine.

Let’s code.```python
import sys

def solve():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        # sorted neighbors of a that are > a
        neigh_a = sorted(x for x in adj[a] if x > a)
        for b in range(a + 1, n + 1):
            if b not in adj[a]:
                continue
            # find smallest c > b that is neighbor of both a and b
            for c in neigh_a:
                if c > b and c in adj[b]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    solve()
```
