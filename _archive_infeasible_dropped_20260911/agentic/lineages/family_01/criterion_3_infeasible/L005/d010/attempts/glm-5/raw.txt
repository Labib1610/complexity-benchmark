Looking at this problem, I need to find three edges (logs) such that every person involved in at least one of these edges is involved in at least two of them.

Let me analyze what configurations satisfy this:
- If three edges involve 3 distinct people total, each person must appear in ≥2 edges. With 3 edges and 3 people, each appearing ≥2 times, that's ≥6 appearances but only 6 endpoints total. So each person appears exactly twice. This means the three edges form a triangle (3 people, 3 edges connecting all pairs).

- If three edges involve 4 distinct people, each must appear in ≥2 edges. Total appearances = 6, need ≥8 (4 people × 2). Impossible.

- If three edges involve 5 or 6 distinct people, even more impossible.

- If three edges involve exactly 2 distinct people: impossible since edges are distinct (no repeated pairs).

So the only valid configuration is a **triangle**: three people where all three pairwise edges exist.

The problem reduces to: find the lexicographically smallest triangle in the graph.

**Algorithm:**
- For each vertex `a` (from 1 to n), for each neighbor `b > a`, check if they share a common neighbor `c > b`. The first such triangle found is lexicographically smallest.
- To check efficiently: for vertex `a`, mark all its neighbors. Then for each neighbor `b > a`, iterate through `b`'s neighbors and check if any is marked and `> b`.

**Complexity:** For each vertex `a`, the work is O(sum of degrees of a's neighbors). In the worst case this could be O(n·m), but with the constraint that we stop at the first triangle found, and vertices are processed in order, this is efficient enough for the given constraints.

```python
import sys

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [set() for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        if u > v:
            u, v = v, u
        adj[u].add(v)
        adj[v].add(u)
        edges.append((u, v))
    
    for a in range(1, n + 1):
        neighbors_a = adj[a]
        for b in neighbors_a:
            if b <= a:
                continue
            for c in neighbors_a:
                if c > b and c in adj[b]:
                    print(f"{a} {b} {c}")
                    return
    
    # Should never reach here per problem guarantees
    print("-1 -1 -1")

solve()
```
