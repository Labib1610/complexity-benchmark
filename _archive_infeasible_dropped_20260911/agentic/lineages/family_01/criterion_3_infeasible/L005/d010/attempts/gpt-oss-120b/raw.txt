**Solution Explanation**

For every incompatibility log we have an undirected edge between two people.
We have to choose three *different* edges such that every person that appears in
at least one of the three edges appears in **at least two** of them.

--------------------------------------------------------------------

#### 1.   What can three edges look like?

For a vertex `v` let `deg₃(v)` be the number of the three chosen edges incident to
`v`.  
The condition of the statement is  

```
for every v :  deg₃(v) = 0   or   deg₃(v) ≥ 2
```

The sum of all `deg₃(v)` equals `2·3 = 6` (each edge contributes 2 to the sum).
The only way to write `6` as a sum of numbers `0` or `≥2` is

```
2 + 2 + 2
```

Therefore exactly three vertices are used and each of them has degree `2`.
Consequently the three edges are exactly the three edges of a **triangle**
(3‑cycle) in the graph.

*Finding a suitable triple of edges = finding a triangle.*

--------------------------------------------------------------------

#### 2.   Required output

The three vertices of the triangle have to be printed in increasing order.
If several triangles exist we need the lexicographically smallest triple
`(a,b,c)` (`a<b<c`).  
So we have to find the triangle with the smallest possible first vertex,
if several have the same first vertex – the smallest second vertex, and so on.

--------------------------------------------------------------------

#### 3.   Triangle search for `n ≤ 2000`

`n` is at most `2000`, therefore a bitset of length `n` fits easily into a
Python integer (`2000` bits ≈ 250 bytes).

*Adjacency bitsets*  

```
adj[v]  – integer, bit w is 1  ⇔  edge (v,w) exists
```

For a fixed ordered pair of vertices `a < b` that are adjacent,
the vertices that together with `a` and `b` form a triangle are exactly

```
common = adj[a] & adj[b]          # vertices adjacent to both a and b
```

We need a vertex `c` that is larger than `b` (to keep a<b<c).  
Mask away all bits `≤ b` :

```
mask   = all_bits ^ ((1 << (b+1)) - 1)      # bits with index ≥ b+1
candidates = common & mask
```

If `candidates` is non‑zero, the least set bit gives the smallest possible `c`
and the triple `(a,b,c)` is the lexicographically first triangle,
because we iterate `a` increasingly, inside it `b` increasingly,
and finally take the smallest admissible `c`.

The whole algorithm:

```
for a = 0 … n-1:
        for each neighbour b of a with b > a (in increasing order):
                common = adj[a] & adj[b]
                candidates = common & mask(b)
                if candidates != 0:
                        c = index of lowest set bit in candidates
                        output (a+1, b+1, c+1) and stop
```

`mask(b)` is computed as `full_mask ^ ((1 << (b+1)) - 1)` where
`full_mask = (1 << n) - 1`.

The number of iterations equals the number of edges (`≤ 2·10⁵`);
each iteration performs only a few integer operations on at most 2000‑bit
numbers – easily fast enough.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints exactly the required triple.

---

##### Lemma 1  
A set of three edges satisfies the statement’s condition **iff** the three
edges are the edges of a triangle.

**Proof.**  
Let the three edges involve the vertex set `V`.  
Each vertex in `V` must be incident to at least two of the three edges,
hence its degree inside the three edges is `≥2`.  
The sum of all these degrees equals `2·3 = 6`.  
The only way to write `6` as a sum of numbers each `≥2` is `2+2+2`,
so `|V| = 3` and every vertex has degree exactly `2`.  
A 3‑vertex graph where each vertex has degree `2` is a triangle, and the three
edges are precisely its edges. ∎



##### Lemma 2  
When the algorithm examines a pair `(a,b)` (`a<b`) that is an edge,
`candidates = adj[a] & adj[b]` contains exactly the vertices that together with
`a` and `b` form a triangle.

**Proof.**  
A vertex `x` belongs to `adj[a] & adj[b]` iff edges `(a,x)` and `(b,x)` both
exist, i.e. the three edges `(a,b) , (a,x) , (b,x)` are present – a triangle.
Conversely, any triangle containing `a` and `b` must contain a third vertex
adjacent to both, therefore that vertex lies in the intersection. ∎



##### Lemma 3  
If the algorithm outputs a triple `(a,b,c)`, then `{a,b,c}` is a triangle.

**Proof.**  
The algorithm outputs only after finding `candidates ≠ 0`.  
By Lemma&nbsp;2 every vertex in `candidates` together with `a` and `b` forms a
triangle. The algorithm chooses one such vertex `c`, therefore
`(a,b,c)` is a triangle. ∎



##### Lemma 4  
The first triple output by the algorithm is the lexicographically smallest
triangle of the graph.

**Proof.**  
The outer loop enumerates `a` in increasing order.
For a fixed `a` the inner loop enumerates all neighbours `b>a` also in
increasing order.
For a fixed pair `(a,b)` the algorithm selects the smallest `c>b` that makes a
triangle (the least set bit of `candidates`).  

Consider any triangle `(x,y,z)` with `x<y<z`.  
When the algorithm reaches `a = x` it will later examine `b = y`
(because `y` is a neighbour of `x`).  
At that moment `candidates` contains `z` (Lemma&nbsp;2), therefore the algorithm
will output a triple with first component `x` and second component `y`
and third component at most `z`.  
Thus no triangle with a smaller first component can be missed, and for the
same first component none with a smaller second component can be missed, etc.
Consequently the first produced triple is the lexicographically minimal one. ∎



##### Lemma 5  
If the input graph contains at least one triangle, the algorithm will output
some triple.

**Proof.**  
Take the lexicographically smallest triangle `(a,b,c)`.  
When the outer loop reaches this `a` and the inner loop reaches this `b`,
`c` belongs to `adj[a] & adj[b]` and also satisfies `c>b`.  
Hence `candidates` is non‑empty and the algorithm outputs a triple. ∎



##### Theorem  
The algorithm always terminates and prints three distinct integers
`a<b<c` that are the vertices of a triangle, and among all such triples it
outputs the lexicographically smallest one.

**Proof.**  
Termination follows because the loops run over a finite set of edges.
By Lemma&nbsp;5 a triangle guarantees that the algorithm reaches a point where it
outputs a triple, so it indeed terminates.  
Lemma&nbsp;3 shows the printed triple is a triangle.
Lemma&nbsp;4 shows it is the lexicographically smallest triangle.
Thus the output satisfies the specification. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

* `n ≤ 2000`, `m ≤ 2·10⁵`.

*Building adjacency bitsets* – `O(m)`.

*Main loops* – each edge `(a,b)` with `a<b` is processed once: `O(m)` iterations.  
Every iteration performs a constant number of integer bit operations on
2000‑bit numbers, i.e. `O(1)` time.

```
Time   :  O(m)   ≤ 2·10⁵   (well below the 2 s limit)
Memory :  n integers of ≤2000 bits  →  O(n)  ≤ 2000·250 B ≈ 0.5 MB
```

Both limits are easily satisfied.

#### 6.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * n               # adjacency bitsets
    neigh = [[] for _ in range(n)]   # neighbour lists (sorted later)

    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u] |= 1 << v
        adj[v] |= 1 << u
        neigh[u].append(v)
        neigh[v].append(u)

    # sort neighbour lists to guarantee increasing order
    for lst in neigh:
        lst.sort()

    full_mask = (1 << n) - 1

    for a in range(n):
        for b in neigh[a]:
            if b <= a:
                continue
            # vertices adjacent to both a and b
            common = adj[a] & adj[b]
            # keep only vertices with index > b
            mask = full_mask ^ ((1 << (b + 1)) - 1)
            cand = common & mask
            if cand:
                # lowest set bit -> smallest possible c
                low_bit = cand & -cand
                c = low_bit.bit_length() - 1
                # output 1‑based, sorted
                print(a + 1, b + 1, c + 1)
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
