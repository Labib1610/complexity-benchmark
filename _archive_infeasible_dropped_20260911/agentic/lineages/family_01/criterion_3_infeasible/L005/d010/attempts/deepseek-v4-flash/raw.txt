We need to find three distinct logs (edges) such that every vertex appearing in at least one of them appears in at least two of them.  

That means the three edges must form a triangle (three vertices, each appearing in exactly two edges) or a star with three edges sharing a common vertex (one vertex in all three, three leaves each in one edge — but that fails because leaves appear only once).  

So the only valid configuration is a triangle: three edges among three vertices.  

Thus, we need to find the lexicographically smallest triangle in the graph.  

We can do this by iterating over vertices in increasing order, checking pairs of neighbors to see if they are connected.  

We’ll use an adjacency set for O(1) edge lookup.  

Here’s the implementation:  

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        for b in sorted(adj[a]):
            if b <= a:
                continue
            for c in sorted(adj[a]):
                if c <= b:
                    continue
                if c in adj[b]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
