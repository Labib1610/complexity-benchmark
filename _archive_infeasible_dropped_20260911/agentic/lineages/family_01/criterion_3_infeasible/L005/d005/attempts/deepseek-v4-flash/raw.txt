We can rewrite the condition in a more workable form.

Let:

- \( L_x \) = degree of vertex \( x \) in the graph.
- \( m \) = total number of edges.
- For a triple \( \{a,b,c\} \), let:
  - \( e_{in} \) = number of edges among the three vertices.
  - \( e_{out} \) = number of edges with exactly one endpoint in the triple.
  - \( e_{none} \) = number of edges with no endpoint in the triple.

We have:
\[
L_a + L_b + L_c = 2 e_{in} + e_{out}
\]
Also:
\[
m = e_{in} + e_{out} + e_{none}
\]

The condition given is:
\[
L_a + L_b + L_c + e_{none} = m + 3
\]

Substitute:
\[
(2 e_{in} + e_{out}) + e_{none} = m + 3
\]
But \( e_{out} + e_{none} = m - e_{in} \), so:
\[
2 e_{in} + (m - e_{in}) = m + 3
\]
\[
e_{in} + m = m + 3
\]
\[
e_{in} = 3
\]

So the condition is simply: **the three vertices form a triangle** (all three edges among them exist).

Thus, the problem reduces to finding the lexicographically smallest triangle in the graph.

We can do this by iterating over \( a \) from 1 to n, then \( b > a \), and checking if there is a \( c > b \) such that all three edges exist.  
Since \( n \leq 2000 \), we can use adjacency sets for O(1) edge checks.

We’ll implement:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(n):
        for b in range(a+1, n):
            if b not in adj[a]:
                continue
            # a and b are connected
            # find smallest c > b connected to both
            for c in range(b+1, n):
                if c in adj[a] and c in adj[b]:
                    print(a+1, b+1, c+1)
                    return

if __name__ == "__main__":
    solve()
```
