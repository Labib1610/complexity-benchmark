**Solution Explanation**

For every chemical we store the set of chemicals it reacts with.
`n ≤ 2000`, therefore a set can be stored as a bitset in a Python integer –
bit *i* (0‑based) is `1` iff the chemical reacts with chemical `i+1`.

A triangle `a < b < c` exists iff for some edge `(a,b)` the two chemicals
have a common neighbour `c` larger than `b`.

The lexicographically smallest triangle is obtained by scanning `a` from
`1 … n`, then `b` from the neighbours of `a` that are larger than `a`,
and finally taking the smallest possible `c`.

The operations on bitsets are O(1) (single machine word operations on
integers of at most 2000 bits).

--------------------------------------------------------------------

#### Algorithm
```
read n, m
adj[1…n] = 0                     # integer bitsets
neigh[1…n] = []                  # neighbour lists (sorted)

for each edge (u,v):
        set bit v-1 in adj[u] , bit u-1 in adj[v]
        add v to neigh[u] , u to neigh[v]

for a = 1 … n:
        sort neigh[a]            # only once, O(m log m) ≤ acceptable
        for each b in neigh[a] with b > a:      # already sorted
                common = adj[a] & adj[b]       # all common neighbours
                # keep only vertices > b
                mask = ((1 << n) - 1) ^ ((1 << b) - 1)
                common &= mask
                if common != 0:
                        low = common & -common          # lowest set bit
                        c = low.bit_length()            # 1‑based index
                        output a b c and terminate
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
triangle.

---

**Lemma 1**  
For any pair of vertices `a < b`, after `common = adj[a] & adj[b]`,
`common` contains exactly the vertices that are adjacent to **both** `a`
and `b`.

*Proof.* By construction `adj[x]` has a `1` at position `y-1` iff edge
`(x,y)` exists. Bitwise AND keeps a `1` at position `y-1` iff both
`adj[a]` and `adj[b]` have a `1` there, i.e. iff both edges `(a,y)` and
`(b,y)` exist. ∎



**Lemma 2**  
After `common &= mask` the remaining set consists of the common neighbours
that are larger than `b`.

*Proof.* `mask` has `1`s exactly at positions `b … n-1` (0‑based), i.e.
vertices `b+1 … n`. AND with `mask` clears all bits ≤ `b`. ∎



**Lemma 3**  
If the algorithm prints a triple `(a,b,c)`, then `{a,b,c}` is a triangle.

*Proof.* The algorithm prints only after finding `common ≠ 0`. By Lemma 1
`c` (the vertex represented by the lowest set bit of `common`) is adjacent
to both `a` and `b`. The loop iterates only over neighbours `b` of `a`,
hence edge `(a,b)` exists. Therefore all three edges are present. ∎



**Lemma 4**  
When the algorithm prints `(a,b,c)`, there is **no** triangle
`(a',b',c')` with lexicographically smaller order.

*Proof.* The outer loop examines `a` in increasing order.
If a triangle with smaller `a'` existed, the algorithm would encounter it
while processing that `a'` and would have terminated earlier.

Assume the smallest possible `a` is fixed.
Inside this `a`, neighbours `b` are processed in increasing order.
If a triangle with the same `a` but smaller `b'` existed, it would be found
when that `b'` is examined.

Finally, for the current pair `(a,b)` the algorithm selects the smallest
`c` larger than `b` (the lowest set bit). Hence no triangle with the same
`a,b` and smaller `c` exists.

Thus the printed triple is lexicographically minimal. ∎



**Lemma 5**  
If a triangle exists in the graph, the algorithm will eventually print one.

*Proof.* Let `(a,b,c)` be any triangle with `a<b<c`. While processing vertex
`a` the neighbour list contains `b` (since edge `(a,b)` exists) and `b>a`,
so the inner loop reaches this `b`. By Lemma 1 `c` is in `common`; by
Lemma 2 it survives the mask because `c>b`. Hence `common ≠ 0` and the
algorithm prints a triangle (maybe an even smaller one). ∎



**Theorem**  
The algorithm terminates and outputs the lexicographically smallest
triple of vertices that form a triangle.

*Proof.* By Lemma 5 a triangle is found, so the algorithm terminates.
By Lemma 3 the printed triple is a triangle.
By Lemma 4 it is the lexicographically smallest such triple. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency*: `O(m)`  
*Sorting neighbour lists*: total `O(m log n)` (each list length ≤ n) – with
`n ≤ 2000` this is negligible.  

Main loops: each edge `(a,b)` with `a<b` is examined once.
For each such edge we perform a constant‑time bitwise AND and a mask,
both on integers of ≤2000 bits → `O(1)` in Python.

Hence total time `O(m + n log n)` ≤ `O(2·10⁵)`.  

Memory: `n` integers of ≤2000 bits → ≤ 250 KB, plus neighbour lists
`O(m)` integers → ≤ 2·10⁵ · 4 B ≈ 0.8 MB. Well within limits.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * (n + 1)          # 1‑based
    neigh = [[] for _ in range(n + 1)]

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        if u == v:
            continue
        # set bits
        adj[u] |= 1 << (v - 1)
        adj[v] |= 1 << (u - 1)
        neigh[u].append(v)
        neigh[v].append(u)

    # sort neighbour lists once
    for lst in neigh:
        lst.sort()

    full_mask = (1 << n) - 1

    for a in range(1, n + 1):
        for b in neigh[a]:
            if b <= a:
                continue
            common = adj[a] & adj[b]
            # keep only vertices > b
            mask = full_mask ^ ((1 << b) - 1)   # bits b .. n-1 set
            common &= mask
            if common:
                low = common & -common
                c = low.bit_length()            # 1‑based index
                sys.stdout.write(f"{a} {b} {c}")
                return

if __name__ == "__main__":
    solve()
```
