We need to find the lexicographically smallest triangle in an undirected graph.

A direct approach:  
- Store adjacency as a set for fast lookups.  
- Iterate over all triples in sorted order and check if all three edges exist.  
- Since n ≤ 2000, O(n³) is too slow in the worst case (8e9 operations).  

Better approach:  
- Iterate over each vertex `a` from 1 to n.  
- For each neighbor `b` of `a` (with `b > a`), check neighbors `c` of `a` with `c > b` and see if `b` and `c` are connected.  
- The first found triple is lexicographically smallest because we check in increasing order.

We can implement this efficiently using adjacency sets.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)

    for a in range(1, n + 1):
        for b in adj[a]:
            if b <= a:
                continue
            for c in adj[a]:
                if c <= b:
                    continue
                if c in adj[b]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
