We can solve this by checking each triple in sorted order and stopping at the first valid one.  
Since n can be up to 2000, a naive O(n³) check is too slow.  
Instead, we can iterate over the middle element `b`, and for each `b`, check pairs `(a, c)` with `a < b < c` using an adjacency matrix for O(1) edge lookups.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = adj[v][u] = True

    for b in range(1, n + 1):
        for a in range(1, b):
            if not adj[a][b]:
                continue
            for c in range(b + 1, n + 1):
                if adj[b][c] and adj[a][c]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
