 We need to find a triple (a, b, c) with a < b < c such that all three pairs (a,b), (b,c), (a,c) are in the restricted list.  
The simplest approach is to iterate over all possible triples in increasing order and check the condition. Since n ≤ 2000, we can use a set for O(1) lookups.

Here’s the code:

```python
n, m = map(int, input().split())
edges = set()
for _ in range(m):
    u, v = map(int, input().split())
    edges.add((u, v))
    edges.add((v, u))

for a in range(1, n+1):
    for b in range(a+1, n+1):
        if (a, b) not in edges:
            continue
        for c in range(b+1, n+1):
            if (a, c) in edges and (b, c) in edges:
                print(a, b, c)
                exit()
```
