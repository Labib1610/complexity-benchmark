To solve this problem, we need to maximize the total value obtained from a set of divisible investments given a budget constraint. This problem is analogous to the fractional knapsack problem, where we can take fractions of items to maximize the value.

### Approach
1. **Problem Analysis**: Each investment can be taken in fractions, and the goal is to maximize the total value within the given budget. The optimal strategy is to prioritize investments with the highest value per unit cost ratio.
2. **Key Insight**: By sorting investments based on their value-to-cost ratio in descending order, we can greedily take the most valuable investments first.
3. **Algorithm**:
   - Read the input values.
   - Calculate the value-to-cost ratio for each investment.
   - Sort the investments based on this ratio in descending order.
   - Iterate through the sorted investments, taking as much as possible of each investment until the budget is exhausted.

### Solution Code
```python
n, B = map(int, input().split())
investments = []
for _ in range(n):
    cost, value = map(int, input().split())
    investments.append((cost, value))

# Sort investments by value per cost in descending order
investments.sort(key=lambda x: (x[1]/x[0]), reverse=True)

remaining = B
total = 0.0

for cost, value in investments:
    if remaining <= 0:
        break
    take = min(remaining, cost)
    total += (take / cost) * value
    remaining -= take

print("{0:.6f}".format(total))
```

### Explanation
1. **Reading Input**: The input consists of the number of investments and the budget, followed by the cost and value of each investment.
2. **Sorting Investments**: Investments are sorted by their value-to-cost ratio in descending order. This ensures that we consider the most valuable investments first.
3. **Greedy Selection**: For each investment, we take as much as possible (up to the remaining budget). This involves either taking the entire investment or a fraction of it, depending on the remaining budget.
4. **Output**: The total value obtained is formatted to six decimal places as required.

This approach ensures that we maximize the total value by leveraging the highest value-to-cost ratios first, efficiently solving the problem within the given constraints.
