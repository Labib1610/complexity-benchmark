To solve this problem, we need to determine the smallest index of a fragment that contains a given forbidden string as a contiguous substring. The approach involves checking each fragment in sequence and returning the index of the first fragment that meets the condition.

### Approach
1. **Reading Input**: First, we read the number of fragments and the fragments themselves. Then, we read the forbidden string.
2. **Length Check**: For each fragment, we first check if its length is at least as long as the forbidden string. If not, we skip further checks for that fragment.
3. **Substring Check**: For fragments that meet the length requirement, we check if the forbidden string is a substring of the fragment. The first fragment that meets this condition gives us the required index.

### Solution Code
```python
import sys

def main():
    k = int(sys.stdin.readline())
    fragments = [sys.stdin.readline().strip() for _ in range(k)]
    forbidden = sys.stdin.readline().strip()
    len_f = len(forbidden)
    
    for i in range(k):
        s = fragments[i]
        if len(s) < len_f:
            continue
        if forbidden in s:
            print(i + 1)
            return

if __name__ == "__main__":
    main()
```

### Explanation
- **Reading Input**: The input is read using `sys.stdin.readline()` for efficiency, especially given the potentially large input size.
- **Length Check**: Before checking if the forbidden string is a substring, we ensure the fragment is long enough to possibly contain the forbidden string. This optimization reduces unnecessary checks.
- **Substring Check**: Using Python's `in` operator efficiently checks if the forbidden string is present in the fragment. The first fragment that meets this condition results in immediately printing the 1-based index and exiting, ensuring minimal processing time.

This approach ensures that we efficiently determine the smallest index by leveraging early termination as soon as the first valid fragment is found.
