To solve this problem, we need to determine the minimum total cost to connect all sites in a campus using the minimum spanning tree (MST) approach. The problem can be efficiently solved using Kruskal's algorithm, which leverages a Disjoint Set Union (DSU) structure to manage and merge sets of connected components.

### Approach
1. **Problem Analysis**: The problem is a classic MST problem where we need to connect all nodes (sites) with the minimum total edge weight (cabling cost). Kruskal's algorithm is suitable here due to its efficiency with large graphs, especially when combined with a DSU structure for union-find operations.

2. **Algorithm Selection**: Kruskal's algorithm involves sorting all edges by weight and then iteratively adding the smallest edges that connect disjoint components. This ensures that we form an MST with the minimum total cost.

3. **Complexity Analysis**: Sorting the edges takes O(m log m) time, and each union-find operation takes nearly O(1) time due to path compression and union by rank. Thus, the overall complexity is O(m log m), which is efficient for the given constraints (n, m ≤ 200,000).

### Solution Code
```python
n, m = map(int, input().split())

edges = []
for _ in range(m):
    u, v, w = map(int, input().split())
    edges.append((w, u, v))

edges.sort()

class DSU:
    def __init__(self, n):
        self.parent = list(range(n + 1))
        self.rank = [1] * (n + 1)
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        x_root = self.find(x)
        y_root = self.find(y)
        if x_root == y_root:
            return False
        if self.rank[x_root] < self.rank[y_root]:
            self.parent[x_root] = y_root
        else:
            self.parent[y_root] = x_root
            if self.rank[x_root] == self.rank[y_root]:
                self.rank[x_root] += 1
        return True

total = 0
dsu = DSU(n)
for w, u, v in edges:
    if dsu.find(u) != dsu.find(v):
        total += w
        dsu.union(u, v)

print(total)
```

### Explanation
1. **Reading Input**: The input is read and stored as a list of edges, each represented by a tuple containing the weight and the two nodes it connects.

2. **Sorting Edges**: The edges are sorted by their weights to ensure we always consider the smallest available edge first.

3. **DSU Initialization**: The DSU structure is initialized with each node as its own parent and rank 1. This structure helps efficiently manage merging and finding connected components.

4. **Kruskal's Algorithm**: For each edge in the sorted list, we check if the nodes it connects are already part of the same component. If not, we merge the components and add the edge's weight to the total cost. This ensures we build the MST incrementally without cycles.

5. **Output**: The accumulated total cost of the MST is printed, which represents the minimum cost to connect all sites.
