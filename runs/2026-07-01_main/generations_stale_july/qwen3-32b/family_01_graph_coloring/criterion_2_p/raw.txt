To solve this problem, we need to assign workers to two shifts such that no conflicting pair shares a shift. If a valid assignment exists, we must provide the lexicographically smallest valid assignment. This problem can be modeled as a graph bipartition problem, where we check if the graph is bipartite and then determine the lexicographically smallest valid assignment using BFS.

### Approach
1. **Graph Representation**: Represent the workers and their conflicts using an adjacency list.
2. **Bipartite Check**: Use BFS to check if the graph is bipartite. During BFS, assign colors (1 or 2) to each node such that no two adjacent nodes share the same color.
3. **Lexicographical Order**: To ensure the lexicographically smallest assignment, start BFS from the smallest node in each connected component and assign color 1 to the starting node. This ensures that the earliest nodes in lexicographical order are assigned the smallest possible shift numbers.

### Solution Code
```python
import sys
from collections import deque

def main():
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr])
    ptr += 1
    m = int(input[ptr])
    ptr += 1

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(input[ptr])
        ptr += 1
        v = int(input[ptr])
        ptr += 1
        adj[u].append(v)
        adj[v].append(u)

    color = [0] * (n + 1)
    for u in range(1, n + 1):
        if color[u] == 0:
            queue = deque()
            queue.append(u)
            color[u] = 1
            while queue:
                current = queue.popleft()
                for neighbor in adj[current]:
                    if color[neighbor] == 0:
                        color[neighbor] = 3 - color[current]
                        queue.append(neighbor)
                    elif color[neighbor] != 3 - color[current]:
                        print("NO")
                        return
    print("YES")
    print(' '.join(map(str, color[1:n+1])))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Graph Representation**: The adjacency list `adj` is constructed to represent the conflicts between workers.
2. **Bipartite Check**: Using BFS, we traverse each connected component of the graph. Starting from the smallest node in each component, we assign colors alternately (1 and 2) to ensure no adjacent nodes share the same color.
3. **Conflict Detection**: During BFS traversal, if we find a conflict where adjacent nodes have the same color, we immediately print "NO" and exit.
4. **Lexicographical Order**: By starting BFS from the smallest node in each component and assigning color 1 initially, we ensure the lexicographically smallest valid assignment.

This approach efficiently checks for bipartiteness and ensures the lexicographically smallest valid assignment using BFS, making it suitable for large input sizes as specified in the problem constraints.
