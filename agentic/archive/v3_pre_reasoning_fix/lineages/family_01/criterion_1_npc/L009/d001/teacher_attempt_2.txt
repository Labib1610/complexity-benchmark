<STATEMENT>
# Problem A — Trichrome Shifts

Time limit: 2 s   Memory limit: 256 MB

A factory runs three shifts labeled 1, 2, 3. There are n workers. Some pairs of workers are in conflict and must not be placed on the same shift. Assign every worker to exactly one of the three shifts so that no conflicting pair shares a shift, or report that it is impossible. 

To front-load the schedule, an assignment is evaluated by concatenating the shift numbers s₁, s₂, …, sₙ from left to right to form a single n-digit decimal integer. You must find a valid assignment that minimizes this resulting integer.

## Input
The first line contains two integers n and m — the number of workers and the number of conflict pairs (1 ≤ n ≤ 40, 0 ≤ m ≤ n·(n−1)/2).
Each of the next m lines contains two integers u v — a conflicting pair.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES on the first line. On the second line print n integers s₁ s₂ … sₙ (each in {1,2,3}), where sᵢ is the shift of worker i. Among all valid assignments, output the one that minimizes the n-digit decimal integer described above.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit mention of "lexicographically smallest sequence" and "compare s₁ first" was removed. By reframing the tie-breaker as minimizing an n-digit decimal integer formed by concatenation, models can no longer rely on superficial pattern matching to map the problem directly to ordered backtracking; they must now deduce that minimizing a fixed-length integer is mathematically equivalent to making greedy optimal choices from left to right.
</RATIONALE>
<PRESERVED_ANSWER>
Minimizing the numerical value of a base-10 integer formed by concatenating a sequence of digits from left to right is strictly equivalent to finding the lexicographically smallest sequence.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-coloring with a lexicographical tie-breaker, keeping it in NP-complete.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret the Output section and print the n-digit integer as a single string without spaces, though the instruction "print n integers s₁ s₂ … sₙ" strongly guards against this.
</RISK>
