# Problem A — Orbital Telemetry Pipeline

Time limit: 2 s
Memory limit: 256 MB

The orbital mapping pipeline configures a constellation of $n$ satellites to ensure stable telemetry.

**Diagnostics.** The system has already completed a signal diagnostic. Its output is a log of $m$ satellite pairs whose transmission beams overlap.

**Phase Configuration.** You must process the diagnostic log to configure the communications array. Each satellite's transmitter must be locked to a specific phase shift. The hardware supports exactly three phase shift settings: 1, 2, and 3. To guarantee data integrity, any two satellites flagged in the diagnostic log for overlapping beams must use phase shifts that differ by at least 1.

**Initialization.** The satellites boot up using your configuration. The boot sequence is deterministic: among all valid phase configurations, your module must select the one that minimizes the phase shift setting of satellite 1. If multiple configurations tie for satellite 1, it must minimize the setting for satellite 2, and so forth. If no valid configuration can be found, your module must halt the pipeline.

## Input
The first line of the input contains two integers $n$ and $m$ — the number of satellites and the number of overlapping pairs. A constellation requires at least a single satellite to operate, and is strictly limited by the launch rocket's structural maximum of 40 payload bays. The diagnostic log might be completely empty, or it could theoretically contain every unique pair of satellites in the constellation. 

Each of the following $m$ lines contains two integers $u$ and $v$ — a pair of satellites that have overlapping beams.

## Output
If the pipeline must be halted because no valid phase configuration exists, print a single line containing `NO`. 
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $p_1, p_2, \dots, p_n$ (each in $\{1, 2, 3\}$), where $p_i$ is the phase shift assigned to satellite $i$. Remember to output the correct deterministic sequence as described.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
Removed the explicit inequality bounds from the input section, replacing them with physical limits from the scenario (a single satellite minimum, 40 payload bays maximum, empty log to every unique pair). Replaced the direct "must not be assigned the same frequency" rule with a numerical requirement that phase shifts "differ by at least 1", forcing the model to deduce that this is mathematically identical to an inequality constraint before it can recognize the 3-coloring structure.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that integer values in {1, 2, 3} differ by at least 1 is mathematically equivalent to requiring they be distinct, preserving the exact same valid state space and lexicographical minimums.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Lexicographically First 3-Coloring, which is NP-complete, as the domain of variables and the pairwise inequality constraints are unchanged.
</PRESERVED_CLASS>
<RISK>
A reader might theoretically misinterpret "differ by at least 1" as a directed difference (e.g., $p_u - p_v \ge 1$), but "differ by" is standard English for absolute difference, making this risk negligible.
</RISK>
