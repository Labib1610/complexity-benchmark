<STATEMENT>
# Problem A — Alloy Temperature Bands

Time limit: 2 s   Memory limit: 256 MB

A metallurgy facility is processing $n$ alloy ingots, numbered $1$ to $n$. Each ingot must be assigned to exactly one temperature band for annealing: band $1$, $2$, or $3$.

The quality control system has flagged $m$ pairs of ingots that contain reactive trace elements. To ensure safety during the annealing process, the facility enforces a relative temperature rule for these reactive pairs. For any two ingots $u$ and $v$ in such a pair, their assigned temperature bands $b_u$ and $b_v$ must satisfy the condition that the maximum of their two bands is strictly greater than the minimum of their two bands. This ensures a sufficient thermal gradient between the reactive materials.

The annealing schedule must be listed as a sequence of $n$ integers, where the $i$-th integer is the band of ingot $i$. To standardize operations, if there are multiple valid schedules that satisfy all safety rules, the facility must use the sequence that is lexicographically smallest.

If it is impossible to assign temperature bands to all ingots without violating the safety rules for the reactive pairs, the facility must halt processing.

## Input
The first line contains two integers $n$ and $m$ — the number of ingots and the number of reactive pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the next $m$ lines contains two integers $u$ and $v$ — representing a pair of ingots that are reactive and must satisfy the thermal gradient condition.

## Output
If no valid schedule is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $b_1, b_2, \dots, b_n$ (where each $b_i \in \{1, 2, 3\}$), representing the band assigned to ingot $i$. Among all valid schedules, output the sequence that is lexicographically smallest (compare $b_1$ first, then $b_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the RTOS stage allocation scenario to an alloy temperature band scenario to remove any affordances linked to scheduling or memory separation. Replaced the explicit mathematical inequality `|s_u - s_v| >= 1` with a logical condition requiring the maximum of the two bands to be strictly greater than the minimum. This forces the model to deduce that the assigned values must be distinct, preventing simple pattern matching on the absolute difference inequality that immediately triggers graph-coloring templates.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that max(b_u, b_v) > min(b_u, b_v) is mathematically identical to b_u != b_v, meaning the exact same assignments of 1, 2, and 3 are valid, and the lexicographical tie-breaking remains identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding a valid 3-coloring for a given graph, which is NP-complete, and finding the lexicographically smallest such coloring.
</PRESERVED_CLASS>
<RISK>
Models might find the phrase "maximum is strictly greater than the minimum" slightly unusual for a physical constraint description, but it is mathematically completely unambiguous.
</RISK>
