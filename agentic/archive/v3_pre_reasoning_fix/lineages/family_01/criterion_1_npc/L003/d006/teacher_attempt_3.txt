<STATEMENT>
# Problem A — Acoustic Drone Deployment

Time limit: 2 s   Memory limit: 256 MB

A fleet of $n$ deep-sea mining drones, numbered $1$ to $n$, is being deployed. Each drone must be assigned exactly one operational depth tier, chosen from the integers $1$, $2$, and $3$.

During pre-deployment analysis, the system identified $m$ pairs of drones that will operate in overlapping acoustic zones. To prevent destructive sonar resonance, the mission controller enforces a wave separation rule. For any two drones $u$ and $v$ in an overlapping zone, with assigned depth tiers $d_u$ and $d_v$, the signal interference equations $d_u \cdot x + d_v \cdot y = 0$ and $d_v \cdot x + d_u \cdot y = 0$ must have exactly one unique real solution for $x$ and $y$. This ensures that the acoustic interference does not produce infinite standing wave configurations.

The deployment configuration must be listed as a sequence of $n$ integers, where the $i$-th integer is the depth tier of drone $i$. To standardize deployment logs, if there are multiple valid configurations that satisfy the resonance rule, the system must generate the sequence that is lexicographically smallest.

If it is impossible to assign depth tiers to all drones without violating the resonance rule, the system must abort the deployment.

## Input
The first line contains two integers $n$ and $m$ — the number of drones and the number of pairs in overlapping zones. The number of drones $n$ is at least one and is limited by the deployment vessel's exact capacity of forty drone bays. The value of $m$ is non-negative and will not exceed the maximum possible number of distinct pairs that can be formed from the $n$ drones.
Each of the next $m$ lines contains two integers $u$ and $v$ — representing a pair of drones that share an acoustic zone and therefore must satisfy the resonance condition.

## Output
If no valid depth assignment is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $d_1, d_2, \dots, d_n$ (where each $d_i \in \{1, 2, 3\}$), representing the depth tier assigned to drone $i$. Among all valid assignments, output the sequence that is lexicographically smallest (compare $d_1$ first, then $d_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The small-domain arithmetic condition was replaced with a linear algebra constraint: a homogeneous system of two variables must have a unique real solution. This forces the model to deduce that the determinant $d_u^2 - d_v^2$ must be non-zero, which for positive integers implies $d_u \neq d_v$, rather than simply tabulating the explicit arithmetic formula. Additionally, to implement strategy S07, the numeric bounds for $n$ and $m$ were translated into physical scenario limits (vessel capacity and combinatorial maximums) that exactly imply the original inequalities.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the system of equations has a unique solution is mathematically equivalent to $d_u \neq d_v$ for positive integers, which means the valid assignments and their lexicographical order remain identical to the seed proper-coloring problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding the lexicographically first valid 3-coloring of a graph, which remains NP-complete.
</PRESERVED_CLASS>
<RISK>
A model could potentially misunderstand "unique real solution for $x$ and $y$" if it fails to recognize it as a standard reference to the trivial solution of a non-singular homogeneous linear system, though this phrasing is unambiguous in mathematics.
</RISK>
