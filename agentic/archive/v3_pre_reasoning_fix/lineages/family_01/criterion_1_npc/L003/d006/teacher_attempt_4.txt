# Problem A — Structural Framework Alignment

Time limit: 2 s   Memory limit: 256 MB

A structural framework consists of $n$ load-bearing pillars, numbered $1$ to $n$. Each pillar must be assigned exactly one primary alignment axis: 1 (Longitudinal), 2 (Transverse), or 3 (Vertical).

During the engineering review, the design identified $m$ cross-bracing struts, each connecting a pair of pillars. To ensure stability against shear forces, the building code enforces a dimensional spanning rule. For any two pillars connected by a strut, their assigned alignment axes must together span a 2-dimensional plane. If their axes fail to span a 2-dimensional plane (meaning their combined alignment is restricted to a single 1-dimensional line), the strut provides no lateral support, and the configuration is deemed structurally invalid.

The alignment configuration must be listed as a sequence of $n$ integers, where the $i$-th integer is the alignment axis of pillar $i$. To standardize architectural blueprints, if there are multiple valid configurations that satisfy the spanning rule, the system must generate the sequence that is lexicographically smallest.

If it is impossible to assign alignment axes to all pillars without violating the spanning rule, the design must be rejected.

## Input
The first line contains two integers $n$ and $m$ — the number of pillars and the number of cross-bracing struts ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the next $m$ lines contains two integers $u$ and $v$ — representing a pair of pillars connected by a strut that must satisfy the dimensional spanning condition.

## Output
If no valid alignment assignment is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $d_1, d_2, \dots, d_n$ (where each $d_i \in \{1, 2, 3\}$), representing the alignment axis assigned to pillar $i$. Among all valid assignments, output the sequence that is lexicographically smallest (compare $d_1$ first, then $d_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

Models must now conceptually reason that two orthogonal axes "span a 2-dimensional plane" if and only if they are distinct, forcing structural comprehension over algebraic simplification.
</RATIONALE>

The geometric condition that two axes from the set {Longitudinal, Transverse, Vertical} must span a 2-dimensional plane is logically equivalent to requiring that the two assigned axes are distinct, which exactly matches the inequality requirement of the seed problem, preserving all valid assignments.
</PRESERVED_ANSWER>
