# Problem A — Distributed Portfolio Analysis

Time limit: 2 s   Memory limit: 256 MB

A quantitative trading firm is preparing to run risk simulations on a batch of $n$ financial portfolios, numbered 1 through $n$. The simulation framework requires configuring a state array $S$ of length $n$. For each portfolio $i$, the scheduler must assign a partition code $S[i]$ chosen from the restricted set $\{1, 2, 3\}$.

During pre-processing, the firm extracted $m$ interference conditions based on shared derivative assets. Each condition is represented by two portfolio indices, $u$ and $v$. To prevent memory cache corruption during the simulation, the state array must satisfy the difference constraint $|S[u] - S[v]| \ge 1$ for every given condition.

The scheduler must output the formulated state array $S$. To guarantee deterministic scheduling logs, if multiple valid arrays satisfy all interference conditions, the system must select the sequence that is lexicographically smallest. If no valid configuration exists for the batch, the simulation must be aborted.

## Input
The first line of input contains two integers $n$ and $m$. The integer $n$ (between 1 and 40, inclusive) specifies the number of portfolios. The integer $m$ (between 0 and $n(n-1)/2$, inclusive) specifies the number of interference conditions.
Each of the subsequent $m$ lines provides two integers $u$ and $v$, representing an interference condition between portfolio $u$ and portfolio $v$.

## Output
If no valid state array can be constructed, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print the $n$ integers $S[1], S[2], \dots, S[n]$ representing the partition codes. Among all valid arrays, output the sequence that is lexicographically smallest (comparing $S[1]$ first, then $S[2]$, and so forth).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
To remove the affordance where "small n suggests backtracking", the explicit mathematical inequality bounds (e.g., `1 \le n \le 40`) were embedded naturally into the text. Furthermore, the problem was reframed from "assigning to engines" (which triggers graph coloring associations) to constructing an array that satisfies a system of difference constraints (`|S[u] - S[v]| >= 1`). This baits models into pattern-matching the problem as a shortest-path or 2-SAT difference constraint system, forcing them to genuinely reason about how the restricted domain `{1, 2, 3}` breaks those polynomial-time approaches and necessitates backtracking.
</RATIONALE>
<PRESERVED_ANSWER>
The condition `|S[u] - S[v]| >= 1` over the domain `{1, 2, 3}` is mathematically identical to `S[u] != S[v]`, meaning the exact same outputs remain valid and the lexicographical tie-breaker yields the identical sequence.
</PRESERVED_ANSWER>
