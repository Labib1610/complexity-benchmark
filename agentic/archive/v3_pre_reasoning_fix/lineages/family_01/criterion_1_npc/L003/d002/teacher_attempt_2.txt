<STATEMENT>
# Problem A — Distributed Portfolio Analysis

Time limit: 2 s   Memory limit: 256 MB

A quantitative trading firm is preparing to run risk simulations on $n$ financial portfolios, numbered from $1$ to $n$. The number of portfolios $n$ is at least one, and is capped at the number of quarters in a ten-year period. 

Each portfolio must be assigned exactly one risk tier. The available risk tiers are represented by integers starting from $1$ up to the number of months in a fiscal quarter.

During the pre-processing phase, the firm identified $m$ specific pairs of portfolios that exhibit high cross-asset correlation. The number of such pairs $m$ is non-negative, and will not exceed the total number of unique two-portfolio combinations possible. 

To ensure the variance model converges, any two portfolios in a highly correlated pair must be assigned strictly distinct risk tiers.

The firm's task scheduler requires the configuration plan to be formulated as a sequence of $n$ tier numbers, where the $i$-th number corresponds to the risk tier assigned to portfolio $i$. To ensure reproducibility in the scheduling logs, if there are multiple valid configuration plans that satisfy the variance model, the scheduler must use the sequence that is lexicographically smallest.

If it is impossible to assign risk tiers safely to all portfolios, the system must abort the simulation batch.

## Input
The first line contains two integers $n$ and $m$ — the number of portfolios and the number of highly correlated pairs, respectively. The exact bounds for these values are defined by the scenario constraints detailed in the description.
Each of the next $m$ lines contains two integers $u$ and $v$ — representing a pair of portfolios that exhibit high cross-asset correlation and must receive distinct risk tiers.

## Output
If no safe configuration plan is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $e_1, e_2, \dots, e_n$ (where each $e_i$ is a valid risk tier), representing the tier assigned to portfolio $i$. Among all valid plans, output the lexicographically smallest sequence (compare $e_1$ first, then $e_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The explicit mention of "three independent analysis engines" was removed to prevent models from immediately pattern-matching to "3-coloring." Instead, numeric bounds are expressed indirectly through domain-specific facts (quarters in a ten-year period = 40, months in a fiscal quarter = 3). The constraints are preserved but the model must now deduce the exact number of states and recognize the combinatorial structure from the mutual exclusion rules.
</RATIONALE>
<PRESERVED_ANSWER>
The problem still requires assigning each of the $n$ entities to one of 3 states such that no two conflicting entities share a state, and returning the lexicographically smallest valid assignment, which is identical to the seed's requirements.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying mathematical task remains exactly Lexicographically First 3-Coloring, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
A model with insufficient general knowledge might fail to correctly calculate the number of quarters in a ten-year period (40) or months in a fiscal quarter (3), though these are standard facts.
</RISK>
