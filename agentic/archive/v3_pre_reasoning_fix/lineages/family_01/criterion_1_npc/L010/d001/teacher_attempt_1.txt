# Problem A — Resonance Mitigation

Time limit: 2 s   Memory limit: 256 MB

A quantum computing array consists of multiple processing modules. Each module must be calibrated to a specific operational voltage level, which must be chosen from the values 1, 2, or 3. 

Due to spatial constraints within the hardware, certain specific pairs of modules are magnetically coupled. If any two coupled modules are calibrated to the exact same voltage level, they will experience destructive interference and cause a system failure. You must determine a safe voltage level for every module in the array such that no two coupled modules share a voltage level, or determine that no such safe calibration is possible.

## Input
The first line contains two integers $n$ and $m$ — the number of processing modules and the number of coupled pairs. The array's cryogenic chamber contains 40 hardware slots, meaning the number of modules $n$ can be at most 40, and the system requires at least a single module to boot up. The number of coupled pairs $m$ can be as low as zero, or as high as the theoretical maximum where every distinct pair of installed modules is coupled.

Each of the following $m$ lines provides two integers $u$ and $v$, indicating that module $u$ and module $v$ are magnetically coupled.

## Output
If it is impossible to calibrate the array safely, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $z_1\ z_2 \dots z_n$ (where each $z_i \in \{1, 2, 3\}$), representing the voltage level assigned to module $i$. If multiple safe calibrations exist, output the sequence that is lexicographically smallest (comparing the voltage level of module 1 first, then module 2, and so forth).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
