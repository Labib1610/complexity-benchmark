1. We have n workers and need to assign each to tier 1, 2, or 3.
2. Some pairs of workers are incompatible and cannot have the same tier.
3. We need to find a valid assignment or report it's impossible.
4. If possible, output the lexicographically smallest assignment.

This is essentially a 3-coloring problem on a graph where:
- Nodes are workers
- Edges connect incompatible pairs
- We need to color each node with one of 3 colors such that no edge connects nodes of the same color.

For lexicographically smallest, we should greedily try to assign tier 1 first, then tier 2, then tier 3.

Since n ≤ 40, we can use a backtracking approach with pruning.

Let me think about the algorithm:

1. For each worker from 1 to n:
   - Try to assign tier 1, then 2, then 3
   - A tier is valid if no incompatible worker already assigned has that tier
   - If valid, assign and move to next worker
   - If no tier works, backtrack

This greedy approach should give us the lexicographically smallest solution.

import sys

def solve():
    input_data = sys.stdin.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    # Build adjacency list for incompatible pairs
    incompatible = [set() for _ in range(n)]
    for _ in range(m):
        u = int(input_data[idx]) - 1; idx += 1
        v = int(input_data[idx]) - 1; idx += 1
        incompatible[u].add(v)
        incompatible[v].add(u)
    
    # Assignment array
    assignment = [-1] * n
    
    def can_assign(worker, tier):
        for other in incompatible[worker]:
            if assignment[other] == tier:
                return False
        return True
    
    def backtrack(worker):
        if worker == n:
            return True
        
        for tier in [1, 2, 3]:
            if can_assign(worker, tier):
                assignment[worker] = tier
                if backtrack(worker + 1):
                    return True
                assignment[worker] = -1
        
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, assignment)))
    else:
        print("NO")
