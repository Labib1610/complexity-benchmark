<STATEMENT>
# Problem A — Hopper Allocation

Time limit: 2 s
Memory limit: 256 MB

A pharmaceutical facility employs an automated dispensing system to distribute ingredients into three isolated holding hoppers (numbered 1, 2, and 3). The system processes ingredients from standardized trays, which are designed to hold up to 40 vials per batch. Let $n$ be the number of ingredients in a given batch.

Certain pairs of ingredients are chemically reactive and will degrade if placed into the same hopper. The system must allocate each of the $n$ ingredients to exactly one hopper, ensuring that no reactive pair ends up in the same hopper.

Facility guidelines require the allocation to follow a rigid standard. The sequence of hopper assignments for ingredients $1$ through $n$ must be chosen to be as small as possible in lexicographical order. The system attempts to place ingredient 1 in the lowest-numbered hopper it can, then does the same for ingredient 2, and so on, without violating any safety constraints.

If the ingredients cannot be safely distributed among the three hoppers, the run is aborted.

## Input
The first line provides two integers $n$ and $m$, representing the number of ingredients on the tray and the total number of documented reactive pairs.
The following $m$ lines each contain two integers $u$ and $v$, indicating that ingredient $u$ and ingredient $v$ are reactive and cannot share a hopper.

## Output
If a safe distribution is impossible, output a single line with `NO`.
If a safe distribution is possible, output `YES` on the first line. On the second line, output $n$ integers $h_1, h_2, \dots, h_n$ separated by spaces, where $h_i \in \{1, 2, 3\}$ is the hopper chosen for ingredient $i$. This sequence must be the lexicographically smallest valid allocation.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The bare inequalities in the Input section (`1 <= n <= 40`) operated as a strong signal to models that an exact exponential search was required. This affordance was removed from the Input section and instead woven into the scenario description as the physical capacity of the processing trays ("up to 40 vials"). This forces the model to extract the constraints from the text and rely on algorithmic reasoning rather than pattern-matching standard competitive programming input limits.
</RATIONALE>
<PRESERVED_ANSWER>
The problem still requires finding the lexicographically smallest assignment of $n$ items into 3 categories such that no two conflicting items share a category, keeping all valid outputs identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 3-coloring of a graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might assume $n$ could exceed 40 if they fail to parse the physical tray limit as a hard constraint, though the text states trays "are designed to hold up to 40 vials per batch."
</RISK>
