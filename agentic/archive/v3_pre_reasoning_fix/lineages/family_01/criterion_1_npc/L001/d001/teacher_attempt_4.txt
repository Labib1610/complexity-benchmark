<STATEMENT>
# Problem A — Fluorophore Quenching

Time limit: 2 s
Memory limit: 256 MB

You are configuring an assay for $n$ distinct synthetic RNA strands. The assay requires each strand to be bound to exactly one of three fluorescent fluorophores, which are strictly designated by the system as fluorophore 1, fluorophore 2, and fluorophore 3.

Certain pairs of strands are known to undergo cross-hybridization. If two strands that cross-hybridize are bound to the same fluorophore, their emission spectra will quench, ruining the assay. Therefore, you must ensure that any two strands capable of cross-hybridizing are bound to different fluorophores.

The automated dispensing robot requires a deterministic protocol for assigning fluorophores. The protocol mandates that the entire sequence of fluorophore numbers assigned to strands $1$ through $n$ must be lexicographically minimized. A sequence of assignments $A$ is lexicographically smaller than a valid sequence $B$ if, at the first strand index where their assignments differ, sequence $A$ uses a lower-numbered fluorophore than sequence $B$.

If no valid fluorophore assignment can be found that prevents all quenching, the assay must be aborted.

## Input
The first line contains two integers $n$ and $m$ — the number of RNA strands and the number of known cross-hybridization interactions ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that strand $u$ and strand $v$ cross-hybridize.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $f_1, f_2, \dots, f_n$ (each in $\{1, 2, 3\}$), where $f_i$ is the fluorophore assigned to strand $i$. This sequence must be the lexicographically smallest valid protocol.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
