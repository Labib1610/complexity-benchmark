# Problem A — Storage Allocation

Time limit: 2 s
Memory limit: 256 MB

A distributed database must allocate $n$ data tables across three distinct storage clusters, designated as Cluster 1, Cluster 2, and Cluster 3. The system is designed to manage at least one table, up to a maximum capacity of 40 tables per deployment.

Due to shared resource locks, specific pairs of tables will cause data corruption if they are hosted on the same cluster. The number of such lock conflicts $m$ can range from zero up to the theoretical maximum, which is the total number of unique pairs that can be formed from the $n$ tables. You must assign every table to exactly one of the three clusters such that no two tables that share a lock conflict are assigned to the same cluster.

To ensure reproducible deployments, the system enforces a strict priority rule for valid assignments. The configuration must be chosen such that the sequence of cluster numbers assigned to tables $1$ through $n$ is lexicographically minimized. This means the system prioritizes placing table 1 into the lowest-numbered cluster possible, then table 2 into the lowest-numbered cluster possible, and so forth, while still ensuring a completely conflict-free arrangement for all tables.

If no conflict-free configuration exists for the given tables and lock conflicts, the system must reject the deployment.

## Input
The first line contains two integers $n$ and $m$ — the number of data tables and the number of lock conflicts. The bounds for these values are defined by the system limits described above.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of tables (identified by their indices from 1 to $n$) that share a lock conflict.

## Output
If no conflict-free cluster assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (each being 1, 2, or 3), where $c_i$ is the cluster assigned to table $i$. This sequence must be the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
