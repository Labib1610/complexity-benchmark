        v,c=stack.pop()
        if col[v]!=-1:

Trail-based design:
We have `col` list (length n) and `allowed` list (length n). `propagate(v,c,mask)` assigns and propagates, appending changes to `trail`. Each change: for assignment, record (v, old_allowed) maybe and old_col. For allowed reduction, record (u, old_allowed). At the end, undo by popping trail until length start.

But we also need to record assignment of v: col[v] changes from -1 to c, allowed[v] changes to 1<<c. We can record (v, old_col, old_allowed). Simpler: record (v, old_allowed, old_col). Undo: col[v]=old_col; allowed[v]=old_allowed.

Propagation:
def propagate(v, c, mask):
    stack=[(v,c)]
    while stack:
        v,c=stack.pop()
        if col[v] != -1:
            if col[v] != c: return False
            continue
        trail.append((v, col[v], allowed[v]))
        col[v]=c
        allowed[v]=1<<c
        nb = adj[v] & mask
        while nb:
            lsb=nb&-nb; u=bit-1; nb^=lsb
            if col[u]!=-1:
                if col[u]==c: return False
            else:
                if allowed[u] & (1<<c):
                    trail.append((u, col[u], allowed[u]))
                    allowed[u] &= ~(1<<c)
                    if allowed[u]==0: return False
                    if allowed[u] & (allowed[u]-1)==0:
                        cu = allowed[u].bit_length()-1
                        stack.append((u,cu))
    return True

Undo:
def undo(trail, length):
    while len(trail)>length:
        v, old_col, old_allowed = trail.pop()
        col[v]=old_col
        allowed[v]=old_allowed

                if col[v] != c:

            col[v]=c
            allowed[v]=1<<c
            nb = adj[v] & mask

                u = lsb.bit_length()-1
                nb ^= lsb
                if col[u] != -1:

                        return False
