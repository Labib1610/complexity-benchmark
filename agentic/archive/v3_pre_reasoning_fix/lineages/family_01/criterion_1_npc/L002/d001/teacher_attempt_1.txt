# Problem A — Palate Diversity

Time limit: 2 s   Memory limit: 256 MB

A chef is preparing a menu of $n$ dishes. Each dish must be flavored with exactly one of three distinct spice blends, labeled 1, 2, and 3. Certain pairs of dishes share a dominant base ingredient. To maintain palate diversity, any two dishes that share a base ingredient must not be flavored with the same spice blend. Determine an assignment of every dish to exactly one spice blend such that no two dishes with a shared base ingredient receive the same blend, or report that it cannot be done.

## Input
The first line contains two integers $n$ and $m$ — the number of dishes and the number of shared base ingredient pairs. The number of dishes $n$ is at least 1 and at most the kitchen's maximum capacity of 40 dishes. The number of pairs $m$ is non-negative and does not exceed the total number of unique pairs that can be formed from the $n$ dishes.
Each of the next $m$ lines contains two integers $u$ and $v$ — two dishes that share a base ingredient.

## Output
If no valid flavor assignment exists, print a single line NO.
Otherwise print YES on the first line. On the second line print $n$ integers $s_1, s_2, \dots, s_n$ (each from the set $\{1, 2, 3\}$), where $s_i$ is the spice blend of dish $i$. Among all valid assignments, output the one whose sequence of spice blends is lexicographically smallest (comparing $s_1$ first, then $s_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

</RATIONALE>

The underlying constraint (assign values 1, 2, 3 such that specified pairs have distinct values, minimizing lexicographically) is mathematically identical to the seed problem.
</PRESERVED_ANSWER>

The problem remains exactly equivalent to Graph 3-Coloring, which is NP-complete.
