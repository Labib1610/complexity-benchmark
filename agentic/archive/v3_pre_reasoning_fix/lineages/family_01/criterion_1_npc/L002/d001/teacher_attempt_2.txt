# Problem A — Agricultural Zoning

Time limit: 2 s   Memory limit: 256 MB

An agricultural research facility is conducting trials on $n$ new plant varieties. The facility operates exactly three sealed greenhouses, designated as Greenhouse 1, Greenhouse 2, and Greenhouse 3.

Every plant variety must be cultivated in exactly one of these greenhouses. However, certain pairs of varieties produce airborne compounds that inhibit each other's growth. If two such incompatible varieties are grown in the same greenhouse, they will fail to thrive.

Determine if there is a way to assign all $n$ plant varieties to the three greenhouses without placing any incompatible pairs together.

## Input
The first line contains two integers $n$ and $m$ — the number of plant varieties and the number of incompatible pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the identifiers of two plant varieties that inhibit each other and must not share a greenhouse.

## Output
If there is no safe way to distribute the plant varieties, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, print $n$ integers $g_1, g_2, \dots, g_n$ (where each $g_i \in \{1, 2, 3\}$), with $g_i$ being the greenhouse assigned to variety $i$. If multiple safe distributions exist, provide the one that is lexicographically smallest (comparing the assignment for variety 1 first, then variety 2, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
