# Problem A — Phase Configurations

Time limit: 2 s   Memory limit: 256 MB

A communications array consists of $n$ broadcast nodes. Each node must be configured with a phase shift value of 1, 2, or 3. Due to hardware limitations, certain specific pairs of nodes share a physical bus. If two nodes sharing a bus are configured with the exact same phase shift value, a resonance cascade will occur. You must assign a phase shift value to every node such that no resonance cascades occur, or determine if it is impossible.

## Input
The first line of the input provides two integers $n$ and $m$ — the number of broadcast nodes and the number of shared physical buses. The array requires at least one node, but the system architecture restricts the total node count $n$ to the number of available physical bays, of which there are exactly 40. The number of shared buses $m$ can be as low as zero, and cannot exceed the amount required for every distinct pair of nodes to share exactly one bus.

The following $m$ lines each contain two integers $u$ and $v$ — the identifiers of a pair of nodes that share a bus (nodes are numbered from 1 to $n$).

## Output
If no safe configuration exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (each in $\{1, 2, 3\}$), where $c_i$ is the phase shift value of node $i$. Among all safe configurations, output the lexicographically smallest sequence (compare $c_1$ first, then $c_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
