# Genetic Viability

Time limit: 1 s   Memory limit: 256 MB

You are analyzing a synthetic genome containing $n$ genetic markers, numbered 1 through $n$. There are $m$ epistatic interactions, each linking two specific markers $u$ and $v$.

To create a viable organism, each marker must be engineered to have an expression level of either 1 or 2. The viability of the genome depends on the combined effect of interacting markers. For each epistatic interaction, the system calculates a metabolic load, which is the sum of the squares of the expression levels assigned to its two participating markers.

An interaction is considered stable if and only if its metabolic load is exactly 5. A load of 2 results in cellular starvation, while a load of 8 causes toxic accumulation.

Your task is to determine if there is a complete assignment of expression levels that stabilizes all $m$ epistatic interactions simultaneously. If such a configuration is possible, you must output the lexicographically smallest valid sequence of expression levels. A sequence $s_1, \dots, s_n$ is lexicographically smaller than another valid sequence $t_1, \dots, t_n$ if $s_i < t_i$ at the first index $i$ where the sequences differ.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of genetic markers and the number of epistatic interactions.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the indices of the markers linked by an epistatic interaction.

## Output
If there is no way to assign the expression levels 1 and 2 to all markers such that all $m$ interactions have a metabolic load of exactly 5, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $p_1 \dots p_n$ (each being 1 or 2), representing the lexicographically smallest valid sequence of expression levels.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Changed the scenario from signal amplifiers to genetic markers, and replaced the "arithmetic mean is 1.5" rule with "sum of squares is 5". This forces the model to deduce that the allowed values {1, 2} must be distinct for each pair, independently recognizing the bipartiteness invariant without relying on the specific "mean of 1.5" phrase.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that the sum of squares of two values from {1, 2} equals 5 is mathematically equivalent to requiring one value to be 1 and the other 2, which is exactly the same restriction as the original mean constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains 2-coloring (or bipartiteness testing) on an undirected graph, which is solvable in linear time using BFS/DFS.
</PRESERVED_CLASS>
