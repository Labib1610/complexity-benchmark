# Signal Amplifiers

Time limit: 1 s   Memory limit: 256 MB

You are configuring a network of $n$ signal amplifiers, numbered 1 through $n$. The network contains $m$ critical connections, each linking two specific amplifiers $u$ and $v$.

To operate properly, each amplifier requires a power tier assignment of either 1 or 2. The safety of the network depends on the interaction between connected amplifiers. For each critical connection, the system calculates a stability metric by taking the bitwise XOR of the power tiers assigned to its two endpoints.

A connection is considered stable if and only if its stability metric evaluates to exactly 3. A metric of 0 results in signal interference. 

Your task is to determine if there is a complete assignment of power tiers that stabilizes all $m$ critical connections simultaneously. If such a configuration is possible, you must output the lexicographically smallest valid sequence of power tiers. A sequence $s_1, \dots, s_n$ is lexicographically smaller than another valid sequence $t_1, \dots, t_n$ if $s_i < t_i$ at the first index $i$ where the sequences differ.

## Input
The first line contains two integers $n$ and $m$, representing the number of amplifiers and the number of critical connections. The facility has a maximum capacity of two hundred thousand amplifiers. The actual number of amplifiers $n$ is at least one and at most this maximum capacity. The number of connections $m$ can be as low as zero and will not exceed the facility's maximum amplifier capacity.

Each of the next $m$ lines contains two integers $u$ and $v$, indicating a critical connection between the $u$-th and $v$-th amplifiers. The indices $u$ and $v$ are valid amplifier numbers (at least one and at most $n$).

## Output
If there is no way to assign the power tiers 1 and 2 to all amplifiers such that all $m$ connections have a stability metric of exactly 3, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $p_1 \dots p_n$ (each being 1 or 2), representing the lexicographically smallest valid sequence of power tiers.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

Replaced the arithmetic mean of 1.5 with a bitwise XOR evaluating to 3, and translated the numeric bounds into physical capacity limits. This forces models to evaluate the bitwise operation on the domain {1, 2} to deduce that endpoints must be different, preventing superficial pattern matching on "mean of 1 and 2 is 1.5 means sum is 3".
</RATIONALE>
<PRESERVED_ANSWER>
The bitwise XOR of 1 and 2 is 3, while the XOR of identical tiers is 0, so the set of valid configurations (adjacent nodes must have different tiers) remains mathematically identical to the original mean-based rule.
</PRESERVED_ANSWER>
