# Signal Amplifiers

Time limit: 1 s   Memory limit: 256 MB

You are configuring a network of $n$ signal amplifiers, numbered 1 through $n$. The network contains $m$ critical connections, each linking two specific amplifiers $u$ and $v$.

To operate properly, each amplifier requires a power tier assignment of either 1 or 2. The safety of the network depends on the interaction between connected amplifiers. For each critical connection, the system calculates a stability metric, which is the arithmetic mean of the power tiers assigned to its two endpoints.

A connection is considered stable if and only if its stability metric is exactly 1.5. A metric of 1.0 results in signal dropout, while a metric of 2.0 causes a hardware overload. 

Your task is to determine if there is a complete assignment of power tiers that stabilizes all $m$ critical connections simultaneously. If such a configuration is possible, you must output the lexicographically smallest valid sequence of power tiers. A sequence $s_1, \dots, s_n$ is lexicographically smaller than another valid sequence $t_1, \dots, t_n$ if $s_i < t_i$ at the first index $i$ where the sequences differ.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of amplifiers and the number of critical connections.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the indices of the amplifiers linked by a critical connection.

## Output
If there is no way to assign the power tiers 1 and 2 to all amplifiers such that all $m$ connections have a stability metric of exactly 1.5, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $p_1 \dots p_n$ (each being 1 or 2), representing the lexicographically smallest valid sequence of power tiers.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

I changed the constraint from a product of exactly 2 to an arithmetic mean of exactly 1.5. This removes the "product of 1 and 2 is 2" affordance that models relied on to immediately recognize the bipartite coloring structure, forcing them to deduce that an average of 1.5 for values restricted to {1, 2} implies the two values must be distinct.
</RATIONALE>

The allowed values are still 1 and 2, and the condition that their arithmetic mean equals 1.5 is mathematically identical to their product equaling 2, meaning the set of valid configurations for any input graph remains exactly the same.
</PRESERVED_ANSWER>
