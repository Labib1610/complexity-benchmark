<STATEMENT>
# Signal Amplifiers

Time limit: 1 s   Memory limit: 256 MB

You are configuring a network of $n$ signal amplifiers, numbered 1 through $n$. Each amplifier must be assigned a gain multiplier of either 1 or 2.

The network contains $m$ critical connections. Each connection links two amplifiers, $u$ and $v$. 
To ensure system stability, each critical connection must pass a parity check. For a connection linking $u$ and $v$, the check is evaluated as follows:
1. Calculate the global parity $P_{all}$, which is the bitwise XOR sum of the gain multipliers of all $n$ amplifiers.
2. Calculate the partial parity $P_{ext}$, which is the bitwise XOR sum of the gain multipliers of all amplifiers EXCEPT any amplifier whose index is $u$ or $v$. (If this excludes all amplifiers in the network, $P_{ext}$ is 0).
3. The connection is stable if and only if the bitwise XOR of $P_{all}$ and $P_{ext}$ is exactly 3.

Your task is to determine whether it is possible to assign a gain multiplier to every amplifier such that all $m$ connections are stable.

If a valid configuration exists, you must provide it. Because there may be multiple valid configurations, you must output the lexicographically smallest sequence of gain multipliers. A sequence $s_1, \dots, s_n$ is lexicographically smaller than another valid sequence $t_1, \dots, t_n$ if, at the first index $i$ where they differ, $s_i < t_i$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of amplifiers and the number of critical connections.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the indices of the amplifiers linked by a critical connection.

## Output
If there is no way to assign the multipliers 1 and 2 to all amplifiers such that all $m$ connections are stable, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $g_1 \dots g_n$ (each being 1 or 2), representing the lexicographically smallest valid sequence of gain multipliers.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The original problem allowed models to immediately map "product is exactly 2 from {1, 2}" to "one is 1, one is 2" and thus recognize a bipartite graph, which trivially decomposes into independent connected components for tie-breaking. I replaced the local product condition with an equivalent bitwise XOR condition that references the global state of the array (the XOR sum of all elements). This creates a decoy global dependency that masks the structural independence of the components, forcing models to first algebraically simplify $P_{all} \oplus P_{ext}$ to discover that the constraint is purely local before they can apply the independent color swaps shortcut.
</RATIONALE>
<PRESERVED_ANSWER>
Because $P_{all}$ contains all elements and $P_{ext}$ contains all elements except $u$ and $v$, the condition $P_{all} \oplus P_{ext} = 3$ strictly simplifies to $g_u \oplus g_v = 3$, which for values in $\{1, 2\}$ is true if and only if exactly one multiplier is 1 and the other is 2, perfectly matching the original product condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The simplified condition $g_u \neq g_v$ for exactly two valid states means the problem remains mathematically identical to 2-coloring a graph (bipartiteness testing), keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might simulate the XOR sum literally for every edge, leading to a Time Limit Exceeded verdict, though this is an intended punishment for failing to reason about the mathematical structure of the condition.
</RISK>
