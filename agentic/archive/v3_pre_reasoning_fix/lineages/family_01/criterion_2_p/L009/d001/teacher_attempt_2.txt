# Frequency Interference

Time limit: 1 s
Memory limit: 256 MB

A municipal project involves deploying a network of $n$ field sensors. Each sensor must be programmed to use one of two available transmission frequencies, represented as 1 and 2. 

The physical placement of the sensors creates potential signal collisions. You are provided with a list of $m$ sensor pairs that are situated too close to one another. If any pair on this list is programmed to use the identical frequency, their transmissions will jam. You need to establish if there is a system-wide frequency assignment that completely avoids these collisions.

In cases where the network can be configured safely in more than one way, the firmware uses a specific evaluation metric to determine the preferred setup. Let $s_i$ denote the frequency (1 or 2) assigned to the $i$-th sensor. The system will always adopt the valid configuration that yields the minimum possible value for the following sum:
$$ \sum_{i=1}^n s_i \cdot 2^{n-i} $$

You must find this optimal safe configuration, or determine that no safe configuration is possible.

## Input
The first line provides two integers, $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$, identifying a pair of sensors that are at risk of jamming each other if they share a frequency.

## Output
If it is impossible to assign frequencies 1 and 2 without at least one collision, output `NO`.
If a safe assignment is possible, output `YES` on the first line. On the second line, output $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$) corresponding to the safe configuration that minimizes the required sum.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit "lexicographically smallest" tie-breaking rule with a mathematically equivalent objective function: minimizing the sum of $s_i \cdot 2^{n-i}$. This forces the model to reason about the properties of the sum to realize that it strictly prioritizes smaller values for earlier indices (lexicographical order), preventing it from blindly applying the "ascending component starts" shortcut triggered by pattern-matching the word "lexicographically".
</RATIONALE>
<PRESERVED_ANSWER>
The objective function is uniquely minimized by the lexicographically smallest sequence of 1s and 2s because the weight of each position ($2^{n-i}$) is strictly greater than the sum of all subsequent weights, keeping all required outputs identical to the seed.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
