# Sensor Network Configuration

Time limit: 1 s   Memory limit: 256 MB

You are configuring a network of $n$ sensors. Each sensor must be assigned to one of two frequency bands, designated as band 1 and band 2.

Certain pairs of sensors are placed too close to each other. You are given a list of $m$ such proximity alerts. For each alert involving sensor $u$ and sensor $v$, they must not operate on the same frequency band to prevent interference.

Your task is to determine if all sensors can be assigned a frequency band such that no two interfering sensors share the same band.

If a valid configuration exists, you must provide it. Because there may be multiple valid configurations, you must output the lexicographically smallest sequence of band assignments. A sequence of assignments $s_1, \dots, s_n$ is lexicographically smaller than another valid sequence $t_1, \dots, t_n$ if, at the first sensor index $i$ where they differ, $s_i < t_i$.

## Input
The first line contains two integers $n$ and $m$. The system requires at least a single sensor, but the hardware limits the maximum number of sensors $n$ to the number of cells in a $400 \times 500$ rectangular grid. The number of proximity alerts $m$ can be as low as zero, but is capped at the same maximum limit as the sensors.
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of two sensors that are too close to each other. These indices are guaranteed to correspond to valid sensors in the network, ranging from $1$ up to $n$.

## Output
If there is no way to assign the frequency bands (1 and 2) to all sensors without interference, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers (each being 1 or 2), representing the lexicographically smallest valid band assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
