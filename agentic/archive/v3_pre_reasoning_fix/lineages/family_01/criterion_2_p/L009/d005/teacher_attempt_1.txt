<STATEMENT>
# Signal Amplifiers

Time limit: 1 s
Memory limit: 256 MB

A communication grid consists of $n$ signal amplifiers, indexed from 1 to $n$. Within this grid, there are $m$ critical data links, each operating between a specific pair of amplifiers.

You must assign a power tier to every amplifier in the grid. The available power tiers are strictly 1 and 2. The stability of the grid relies entirely on avoiding interference along the data links. When two amplifiers are joined by a link, their combined signal is processed by a hardware comparator. A link is perfectly stable if and only if the sum of the power tiers assigned to its two endpoints evaluates to exactly 3. Any other sum indicates harmful signal interference, causing the link to drop.

Determine if it is possible to assign a power tier to each of the $n$ amplifiers so that all $m$ data links are stable at the same time. If a valid configuration exists, you must provide the lexicographically smallest assignment sequence. A sequence of power tiers $s_1, \dots, s_n$ is lexicographically smaller than another valid sequence $t_1, \dots, t_n$ if $s_i < t_i$ at the first index $i$ where the two sequences differ.

## Input
The first line provides two integers $n$ and $m$, which denote the total number of amplifiers and the number of data links, respectively. The system allocates a continuous memory block of $200,000$ bytes for amplifier records, where each amplifier requires exactly $1$ byte of storage (there is always at least one amplifier). The routing table is allocated a separate memory region of $1,600,000$ bytes, where each data link record consumes exactly $8$ bytes (the routing table may be empty).

Each of the subsequent $m$ lines contains two integers $u$ and $v$, specifying a data link connecting the amplifier at index $u$ and the amplifier at index $v$. Both indices are guaranteed to represent valid instantiated amplifiers.

## Output
If no valid assignment of power tiers (1 and 2) can make all $m$ links evaluate to a sum of 3, output a single line with the word `NO`.
If a stable configuration is possible, print `YES` on the first line. On the second line, output $n$ integers $p_1 \dots p_n$ (where each $p_i \in \{1, 2\}$), representing the lexicographically smallest valid sequence of power tiers.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit mention of a bitwise AND evaluating to 0 for values 1 and 2 served as a strong keyword trigger for 2-coloring and bipartiteness. This was replaced with the condition that the sum of the two power tiers must equal 3, which is mathematically equivalent for the set {1, 2} but forces the model to deduce the distinct-assignment requirement rather than pattern-matching the bitwise trick. Additionally, numeric bounds were removed from the inequalities and embedded into fictional memory capacity constraints, forcing the model to divide the total bytes by the per-record bytes to derive the $2 \cdot 10^5$ limits.
</RATIONALE>
<PRESERVED_ANSWER>
The allowed values remain strictly 1 and 2, and their sum is exactly 3 if and only if one is 1 and the other is 2, which perfectly mirrors the original condition where their bitwise AND is 0.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires assigning two distinct states to adjacent nodes in a graph without conflicts, which is the classic 2-coloring / bipartiteness testing problem in P.
</PRESERVED_CLASS>
<RISK>
The scenario-based memory limits (200,000 bytes and 1,600,000 bytes) could theoretically be confused with the actual program memory limit (256 MB), though they are clearly contextualised as system capacity bounds for the grid components.
</RISK>
