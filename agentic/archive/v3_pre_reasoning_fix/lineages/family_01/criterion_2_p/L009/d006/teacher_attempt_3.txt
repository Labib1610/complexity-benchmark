<STATEMENT>
# System Amplification

Time limit: 1 s
Memory limit: 256 MB

You are calibrating a control system consisting of $n$ signal amplifiers, numbered 1 to $n$. You must assign each amplifier a gain setting of either 1 or 2.

The system relies on $m$ bidirectional feedback channels to operate. Each channel connects a specific pair of amplifiers. For the system to remain stable, the combined amplification of each channel—calculated as the product of the gain settings of the two amplifiers it connects—must be exactly 2. 
- If the product is 1, the signal attenuates and the channel drops out.
- If the product is 4, the signal overloads and damages the channel.

Determine if it is possible to assign a gain setting (1 or 2) to each of the $n$ amplifiers so that all $m$ feedback channels have a combined amplification of exactly 2. If a valid configuration exists, you must provide the lexicographically smallest sequence of gain assignments. A sequence of assignments $s_1, \dots, s_n$ is lexicographically smaller than another valid sequence $t_1, \dots, t_n$ if $s_i < t_i$ at the first index $i$ where the two sequences differ.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), denoting the total number of amplifiers and the number of feedback channels.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), specifying a feedback channel between amplifier $u$ and amplifier $v$.

## Output
If no valid assignment of gain settings (1 and 2) can make all $m$ channels have a combined amplification of exactly 2, output a single line with the word `NO`.
If a valid configuration is possible, print `YES` on the first line. On the second line, output $n$ integers $p_1 \dots p_n$ (where each $p_i \in \{1, 2\}$), representing the lexicographically smallest valid sequence of gain settings.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The scenario was changed from maintenance window overlaps to amplifier gain products. To satisfy a product of exactly 2 using only the values 1 and 2, connected amplifiers must have different settings. This forces the model to deduce the inequality requirement from an algebraic product rule, removing the affordance of recognizing standard interval overlap patterns that trivially map to bipartiteness.
</RATIONALE>
<PRESERVED_ANSWER>
The constraint that the product of two variables chosen from {1, 2} equals 2 is mathematically identical to requiring the variables to be different, meaning the set of valid assignments and the lexicographically smallest valid assignment remain exactly the same for every input.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains structurally identical to finding the lexicographically smallest 2-coloring of a graph, which is in P and solvable via a component-wise Breadth-First Search.
</PRESERVED_CLASS>
<RISK>
None. The arithmetic product constraint over the set {1, 2} is completely unambiguous and maps perfectly to the original logic without introducing any edge cases.
</RISK>
