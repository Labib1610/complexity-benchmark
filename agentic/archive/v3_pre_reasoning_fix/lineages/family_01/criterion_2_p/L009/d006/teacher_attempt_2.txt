# Maintenance Handoffs

Time limit: 1 s
Memory limit: 256 MB

You are managing the maintenance schedule for a network of $n$ servers, numbered 1 to $n$. You must assign exactly one of two maintenance start times to each server:
- Time 1: The server starts its diagnostic at hour 0. It undergoes a 'Transmit' phase during its first hour (hour 0 to 1), followed immediately by a 'Receive' phase during its second hour (hour 1 to 2).
- Time 2: The server starts its diagnostic at hour 1. It undergoes a 'Transmit' phase during its first hour (hour 1 to 2), followed immediately by a 'Receive' phase during its second hour (hour 2 to 3).

The network requires $m$ critical data handoff protocols to be executed. Each protocol operates between a specific pair of servers. For a handoff to be successful, the two linked servers must have a simultaneous one-hour period where one is in its Transmit phase and the other is in its Receive phase.

Determine if it is possible to assign a start time (1 or 2) to each of the $n$ servers so that all $m$ handoff protocols are successful simultaneously. If a valid schedule exists, you must provide the lexicographically smallest sequence of start time assignments. A sequence of assignments $s_1, \dots, s_n$ is lexicographically smaller than another valid sequence $t_1, \dots, t_n$ if $s_i < t_i$ at the first index $i$ where the two sequences differ.

## Input
The first line provides two integers $n$ and $m$. The facility has exactly two hundred thousand rack slots available, meaning the number of servers $n$ ranges from one up to this maximum capacity. The routing table can store up to the same limit, meaning the number of protocols $m$ ranges from zero up to two hundred thousand.
Each of the following $m$ lines contains two integers $u$ and $v$, specifying a protocol between server $u$ and server $v$. Both $u$ and $v$ are valid server identifiers ranging from one to $n$.

## Output
If no valid assignment of start times (1 and 2) can make all $m$ handoffs successful, output a single line with the word `NO`.
If a valid schedule is possible, print `YES` on the first line. On the second line, output $n$ integers (where each value is either 1 or 2), representing the lexicographically smallest valid sequence of start times.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
