# Problem B — Resonance Modes

Time limit: 1 s   Memory limit: 256 MB

You are calibrating a quantum computing array consisting of $n$ oscillators. Each oscillator must be initialized into a specific resonance mode. The available hardware only supports two stable resonance modes, designated by the integer values 1 and 2. 

The array's layout introduces $m$ interference links between specific pairs of oscillators. To prevent the system from destabilizing, any two oscillators connected by an interference link must achieve destructive interference. This physical requirement is met if and only if the sum of the resonance modes of the two linked oscillators is exactly 3.

You need to determine a valid resonance mode assignment for all oscillators such that every interference link is stabilized. If the array cannot be stabilized under these conditions, you must report that it is impossible.

## Input
The first line provides two integers $n$ and $m$. The system design guarantees at least a single oscillator, and the containment vessel limits the maximum number of oscillators to two hundred thousand. The number of interference links ranges from zero up to two hundred thousand.

Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of oscillators connected by an interference link.

## Output
If no valid mode assignment can stabilize the array, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, output $n$ integers $t_1, \dots, t_n$, where $t_i$ is the resonance mode assigned to oscillator $i$. If multiple valid assignments exist, output the sequence that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit instruction that linked items must take "different" or "opposite" values is a strong trigger for bipartite graph coloring templates. This was replaced with an algebraic condition: since the values are restricted to {1, 2}, requiring their sum to be exactly 3 mathematically forces them to be different without using the word. Additionally, numeric bounds were moved from bare inequalities into the descriptive text describing capacities, satisfying the S07 strategy.
</RATIONALE>
<PRESERVED_ANSWER>
Because the only valid resonance modes are the integers 1 and 2, the only way two modes can sum to 3 is if one is 1 and the other is 2, which perfectly preserves the bipartite constraint and lexicographical tie-breaking rules of the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains mathematically identical to finding the lexicographically first valid 2-coloring of a graph (or detecting an odd cycle), which is solvable in O(n+m) time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
A model might theoretically misinterpret the constraint if it fails to realize the modes are strictly limited to the integers 1 and 2, but the text explicitly states "designated by the integer values 1 and 2", making ambiguity highly unlikely.
</RISK>
