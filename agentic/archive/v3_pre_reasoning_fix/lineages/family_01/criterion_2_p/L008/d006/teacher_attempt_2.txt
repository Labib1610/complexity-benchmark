# Problem B — Distributed Deadlock Avoidance

Time limit: 1 s   Memory limit: 256 MB

A distributed operating system is scheduling $n$ background processes (numbered $1$ to $n$). The system has exactly two physical execution environments, designated as Environment 1 and Environment 2. Every process must be permanently assigned to exactly one of these two environments.

The processes share a set of legacy resources. There are $m$ specific pairs of processes that require access to the same non-reentrant resource. If two processes that share a resource are assigned to the same environment, the local scheduler cannot preempt them, leading to an unrecoverable deadlock. To guarantee system stability, any two processes that share a resource must be separated such that one executes in Environment 1 and the other executes in Environment 2, allowing the global hypervisor to safely manage the lock between the environments.

You must determine an environment assignment for all $n$ processes that satisfies every resource constraint, or conclude that no safe assignment exists.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of processes that share a legacy resource.

## Output
If no safe environment assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $t_1, \dots, t_n$ (each $t_i \in \{1, 2\}$), where $t_i$ is the environment assigned to process $i$. If there are multiple valid assignments, output the sequence that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

</PRESERVED_ANSWER>
