# Problem B — Leverage Compliance

Time limit: 1 s   Memory limit: 256 MB

A financial institution oversees a portfolio of $n$ investment funds. Over the next quarter, every fund must be designated to operate at one of two possible leverage tiers: tier $1$ or tier $2$.

During a recent audit, the risk management system flagged $m$ specific pairs of funds because they possess substantial overlapping assets. To satisfy regulatory requirements regarding cross-exposure, the institution must enforce a strict risk-offset policy for every flagged pair. This policy imposes a tier-dependent condition on the relationship between overlapping funds:
- When a fund is designated at the baseline tier ($1$), any fund it shares an asset overlap with must absorb the corresponding risk, mandating a tier $2$ designation for that partner.
- On the other hand, to avoid compounding vulnerabilities, if a fund is designated at the elevated tier ($2$), every fund it shares an overlap with is strictly capped at tier $1$.

Your task is to find a tier designation for all $n$ funds that fully complies with these cross-exposure rules, or to determine that no such valid configuration exists.

## Input
The first line of the input contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing a flagged pair of funds with overlapping assets.

## Output
If there is no way to assign the leverage tiers without violating the offset policy, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $t_1, \dots, t_n$ (where each $t_i \in \{1, 2\}$), representing the leverage tier assigned to each fund $i$. If multiple valid assignments exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Removed the arithmetic constraint "product ... is exactly 2" which explicitly cued models to realize the values must be 1 and 2 and therefore adjacent nodes must have opposite colors. Replaced it with a logical condition describing how a tier 1 assignment forces a partner to tier 2 and vice versa. Models must now trace these logical implications to reconstruct the bipartiteness requirement instead of relying on the algebraic shortcut.
</RATIONALE>
<PRESERVED_ANSWER>
The new logical rules (tier 1 forces partner to tier 2, tier 2 forces partner to tier 1) are logically equivalent to the original constraint (product of tiers is exactly 2 for values in {1, 2}), meaning the set of valid assignments for any graph remains identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks for a valid 2-coloring of an undirected graph, which is solvable in O(n + m) time using BFS or DFS, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Readers might misinterpret the rules as directed (e.g., applying only from $u$ to $v$) rather than symmetric, though the phrasing "any fund it shares an asset overlap with" strongly implies the undirected nature of the "pairs of funds" mentioned earlier.
</RISK>
