<STATEMENT>
# Problem B — Leverage Compliance

Time limit: 1 s   Memory limit: 256 MB

A financial institution is configuring the risk profiles for $n$ of its investment funds. Each fund $i$ (where $1 \le i \le n$) requires a leverage tier assignment $t_i$, which must be chosen as either $1$ or $2$.

Market analysis has flagged $m$ specific pairs of funds due to their overlapping asset portfolios. To satisfy internal compliance regulations regarding cross-exposure, any two funds in a flagged pair must be assigned leverage tiers whose product equals exactly $2$.

Your task is to find a tier assignment for all $n$ funds that respects every cross-exposure restriction. If no such configuration can be formed, you must report this failure. Should more than one valid configuration exist, you must select the one that minimizes the portfolio's structural risk index, defined by the formula:
$$ \sum_{i=1}^n t_i \cdot 3^{n-i} $$

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of funds and the number of flagged pairs, respectively.
Following this, $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that fund $u$ and fund $v$ share overlapping portfolios.

## Output
If the compliance restrictions cannot be satisfied, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $t_1, t_2, \dots, t_n$ ($t_i \in \{1, 2\}$) representing the assigned leverage tiers. In the event of multiple valid assignments, provide the one that yields the lowest possible structural risk index.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit tie-breaker "lexicographically smallest" was replaced with a mathematical objective function $\sum_{i=1}^n t_i \cdot 3^{n-i}$. Because $t_i \in \{1, 2\}$ and the base $3$ is strictly greater than the maximum difference between possible values ($2 - 1 = 1$), minimizing this sum is mathematically identical to finding the lexicographically smallest sequence. This removes the direct keyword affordance, forcing models to first deduce that the formula prioritizes earlier indices strictly, and only then apply the independent component label swapping strategy.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that flagged pairs must have a product of 2 still forces them to be assigned different tiers (1 and 2), and minimizing the given base-3 polynomial is mathematically equivalent to finding the lexicographically smallest valid assignment, ensuring all outputs remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to checking if a graph is bipartite (2-colorable) and then independently coloring each connected component to minimize the required objective, which is solvable in O(n + m) time using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might attempt to actually compute the structural risk index using big integer arithmetic, which would be too slow or cause overflow, but this is a failure of algorithmic reasoning rather than an ambiguity in the problem statement.
</RISK>
