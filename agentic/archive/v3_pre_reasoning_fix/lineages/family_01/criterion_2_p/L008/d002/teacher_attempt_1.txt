# Problem B — Phase Alignment

Time limit: 1 s   Memory limit: 256 MB

A manufacturing plant is calibrating $n$ robotic actuators. Each actuator must be assigned an operating phase $s_i$, which must be chosen from the set $\{1, 2\}$.

The system includes $m$ critical joints, each forming a physical link between a pair of actuators. To avoid destructive interference, the phase settings of any two actuators $u$ and $v$ that are linked by a joint must satisfy the stability equation:
$$s_u^2 + s_v^2 - s_u s_v = 3$$

You must determine a valid phase assignment for all $n$ actuators that satisfies the condition for every joint, or report that no such configuration is possible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that there is a joint linking actuator $u$ and actuator $v$.

## Output
If no valid phase arrangement exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $s_1, \dots, s_n$ (each $s_i \in \{1, 2\}$), where $s_i$ is the phase assigned to actuator $i$. If there are multiple valid arrangements, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit "sum to 3" constraint with the polynomial equation $s_u^2 + s_v^2 - s_u s_v = 3$. Over the restricted domain $\{1, 2\}$, this equation is satisfied if and only if $s_u \neq s_v$. This removes the surface-level lexical trigger "sum to 3" that models were using to instantly pattern-match the problem to bipartite graph 2-coloring, forcing them to first evaluate the polynomial to discover the underlying logical constraint.
</RATIONALE>
<PRESERVED_ANSWER>
The polynomial equation $s_u^2 + s_v^2 - s_u s_v = 3$ evaluates to 3 for $(1,2)$ and $(2,1)$, but evaluates to 1 for $(1,1)$ and 4 for $(2,2)$, meaning it is logically identical to the original sum constraint over the domain $\{1, 2\}$.
</PRESERVED_ANSWER>
