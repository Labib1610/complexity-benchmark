<STATEMENT>
# Problem B — Phase Alignment

Time limit: 1 s   Memory limit: 256 MB

A manufacturing plant is calibrating a network of $n$ robotic actuators. The facility's power grid requires at least one actuator to be active, but can support no more than two hundred thousand. Each actuator must have its operating phase set to a positive integer strictly less than $3$. 

There are $m$ critical joints (from a minimum of zero up to a structural limit of two hundred thousand), each connecting a pair of actuators. To maintain mechanical stability, the phase values assigned to the two actuators connected at any joint must have an arithmetic mean of exactly $1.5$. 

You must determine a phase assignment for each actuator that satisfies all stability constraints, or report that no such arrangement is possible.

## Input
The first line contains two integers $n$ and $m$.
Each of the next $m$ lines contains two integers $u$ and $v$ — representing a joint connecting the actuators labeled $u$ and $v$ (where labels range from $1$ to $n$).

## Output
If no valid phase arrangement exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $s_1, \dots, s_n$, where $s_i$ is the phase assigned to actuator $i$. If there are multiple valid arrangements, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit set {1, 2} and the sum-of-3 constraint with a requirement for positive integers strictly less than 3 that average to 1.5. This forces models to algebraically deduce that the allowed values are 1 and 2 and that adjacent nodes must have different values, rather than pattern-matching the bipartiteness directly from the sum. I also moved the numeric bounds for $n$ and $m$ out of the Input section and embedded them as spelled-out physical capacities in the text, satisfying the strategy.
</RATIONALE>
<PRESERVED_ANSWER>
The allowed values are still exactly 1 and 2, and the arithmetic mean of 1.5 is mathematically identical to a sum of 3, so every valid assignment and the lexicographical tie-breaker remain completely unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires assigning two distinct values to adjacent vertices, which is exactly 2-coloring (bipartiteness checking) and remains solvable in $O(n+m)$ time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
The phrase "positive integer strictly less than 3" might be misread as allowing 0 if a model does not strictly adhere to the definition of positive integers, though standard mathematical definitions prevent this.
</RISK>
