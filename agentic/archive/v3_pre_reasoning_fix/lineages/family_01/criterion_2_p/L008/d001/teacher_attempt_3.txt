# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

A grid contains $n$ magnetic nodes, indexed from 1 to $n$. The grid is designed to hold a maximum capacity of 200,000 nodes, and will always contain at least one. You must configure each node's polarity to a value of either 1 or 2.

There are $m$ interacting pairs of nodes in the grid. The number of such interactions can range from an absolute minimum of 0 up to a maximum of 200,000 pairs. For the grid to remain stable, the combined polarity of the two nodes in any interacting pair must sum to exactly 3.

You must determine a polarity configuration for all nodes that satisfies all interaction constraints, or report that no such configuration is possible.

## Input
The first line contains two integers $n$ and $m$, representing the number of nodes and the number of interacting pairs respectively. The bounds on $n$ and $m$ correspond to the physical capacities described above.
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of an interacting pair.

## Output
If no stable configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $p_1, \dots, p_n$ (each $p_i \in \{1, 2\}$), where $p_i$ is the polarity assigned to node $i$. If there are multiple valid configurations, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
