# Problem B — Telemetry Frequencies

Time limit: 1 s   Memory limit: 256 MB

A space agency is configuring communication links for $n$ deep-space probes. Each probe must be assigned to transmit its data back to Earth on one of two available channels, designated as channel 1 and channel 2.

There are $m$ specific pairs of probes that are situated such that their signal paths cross. If both probes in such a pair transmit on the same channel, their signals will interfere and the telemetry will be corrupted. Therefore, the two probes in any such pair must be assigned to different channels.

You must determine an assignment of each probe to either channel 1 or channel 2 that prevents all signal interference, or report that no such configuration is possible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of probes whose signal paths cross.

## Output
If no valid channel configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $s_1, \dots, s_n$ (each $s_i \in \{1, 2\}$), where $s_i$ is the channel assigned to probe $i$. If there are multiple valid configurations, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

I changed the real-world scenario from assigning staff to teams due to shared tools, to assigning probes to communication channels due to crossing signal paths. This forces the model to abstract the "must be different" constraint from a novel physical situation rather than relying on familiar "team assignment" problem templates.
</RATIONALE>
<PRESERVED_ANSWER>
The constraint that designated pairs must be assigned different states from a set of two remains structurally identical, preserving all valid assignments and the lexicographically smallest tie-breaker.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to 2-coloring (bipartiteness testing), which is solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
