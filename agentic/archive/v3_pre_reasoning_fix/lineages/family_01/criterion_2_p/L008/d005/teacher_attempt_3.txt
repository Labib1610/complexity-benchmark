# Problem B — Artifact Preservation

Time limit: 1 s   Memory limit: 256 MB

An archivist is organizing a collection of $n$ ancient artifacts. Each artifact must be securely stored in either vault 1 or vault 2.

The collection includes $m$ delicate preservation fields. Each field is generated between a specific pair of artifacts. A field is anchored to a vault if and only if at least one of its two artifacts is stored in that vault. To maintain stability, every preservation field must be anchored to both vault 1 and vault 2 simultaneously. 

You must determine if there is a valid storage assignment for all $n$ artifacts that successfully anchors all $m$ preservation fields to both vaults.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of artifacts that generate a preservation field.

## Output
If no valid storage assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $v_1, \dots, v_n$ (each $v_i \in \{1, 2\}$), where $v_i$ is the vault assigned to artifact $i$. If there are multiple valid assignments, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I completely replaced the mechanical gears and the "product of assigned planes is 2" constraint with a scenario about artifacts, vaults, and preservation fields. The constraint is now framed as a set-coverage requirement: each pair must have at least one item in vault 1 and at least one item in vault 2. This forces the model to logically deduce that the two items must be assigned distinct values, preventing it from pattern-matching a simple arithmetic trigger (like $x \times y = 2$) directly to graph bipartiteness.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that a pair of artifacts anchors a field to both vault 1 and vault 2 means exactly one artifact must be in vault 1 and the other in vault 2, which is mathematically identical to the seed's constraint that the product of their plane numbers is exactly 2.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains computationally equivalent to finding the lexicographically smallest valid 2-coloring of an undirected graph, which is in P and solvable via Breadth-First Search.
</PRESERVED_CLASS>
<RISK>
There is a minor risk that a reader might interpret "anchored to both vault 1 and vault 2 simultaneously" as requiring a single artifact to be in both vaults, but the text explicitly states "Each artifact must be securely stored in either vault 1 or vault 2" and defines anchoring based on the pair, which resolves the ambiguity.
</RISK>
