# Problem B — Horological Strata

Time limit: 1 s   Memory limit: 256 MB

A master watchmaker is designing a complex mechanical timepiece consisting of $n$ distinct gears. The chassis of the watch provides two parallel mounting levels, designated as level 1 and level 2. Each gear must be installed on exactly one of these levels. The watch's mainspring can drive at least a single gear, up to a maximum structural capacity of $200,000$ gears.

The design specifies $m$ pairs of gears that overlap in their two-dimensional projection. The count of these pairs starts from zero and, due to friction tolerances, is capped at the same maximum capacity of $200,000$. When two gears overlap, placing them on the same level will cause their teeth to collide and jam. Therefore, the two gears in any overlapping pair must be installed on different levels.

You must determine a valid level assignment for each of the $n$ gears that satisfies all overlap constraints, or report that the timepiece cannot be assembled as designed.

## Input
The first line contains two integers $n$ and $m$. (Their bounds are determined by the mainspring capacity and friction limits described in the specification.)
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of gears that overlap.

## Output
If no valid level assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $t_1, \dots, t_n$ (each $t_i \in \{1, 2\}$), where $t_i$ is the level assigned to gear $i$. If there are multiple valid assignments, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The direct arithmetic cue ("the product of their assigned plane numbers must be exactly 2") has been replaced with a mechanical constraint ("placing them on the same level will cause their teeth to collide... must be installed on different levels"). This removes the mathematical shortcut and forces the model to independently deduce that the problem requires a 2-coloring. Additionally, the explicit numeric bounds have been integrated into the scenario as physical capacities (structural and friction limits), satisfying the S07 strategy.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that overlapping gears must be on different levels is logically identical to the condition that their level numbers (1 and 2) must multiply to 2, so the set of valid assignments and the lexicographically smallest assignment remain unchanged.
</PRESERVED_ANSWER>

The problem still asks whether the given graph is bipartite (2-colorable) and requires finding the lexicographically smallest valid coloring, which remains solvable in linear time O(n+m) using Breadth-First Search.
</PRESERVED_CLASS>
