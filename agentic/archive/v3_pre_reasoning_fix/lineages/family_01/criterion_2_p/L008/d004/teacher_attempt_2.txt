# Problem B — Horological Strata

Time limit: 1 s   Memory limit: 256 MB

A master watchmaker is designing a complex mechanical timepiece consisting of $n$ distinct gears. The chassis of the watch provides a limited depth profile, meaning each gear must be assigned a depth coordinate of either 1 or 2.

The design specifies $m$ pairs of gears that overlap in their two-dimensional projection. To ensure these gears can interlock and rotate freely without binding, the watchmaker's specification dictates that for every overlapping pair, the depth coordinate of one gear in the pair must be exactly twice the depth coordinate of the other.

You must determine a valid depth assignment for each of the $n$ gears that satisfies all overlap constraints, or report that the timepiece cannot be assembled as designed.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of gears that overlap.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $t_1, \dots, t_n$ (each $t_i \in \{1, 2\}$), where $t_i$ is the depth coordinate assigned to gear $i$. If there are multiple valid assignments, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Changed the overlapping constraint from an additive condition (sum equals 3) to a multiplicative one (one depth coordinate must be exactly twice the other). Models can no longer rely on recognizing the standard "sum is 3 for {1,2}" idiom for opposite boolean assignments, forcing them to deduce that within the domain {1, 2}, this constraint strictly requires the two gears to have different coordinates.
</RATIONALE>
<PRESERVED_ANSWER>
Since the only allowed coordinates are 1 and 2, the only way one coordinate can be exactly twice the other is if one is 2 and the other is 1; this is logically identical to requiring their sum to be 3, thus preserving the validity of exactly the same assignments.
</PRESERVED_ANSWER>

The problem remains exactly equivalent to finding a valid 2-coloring (or determining none exists) on the graph of overlapping gears, keeping it in P.
</PRESERVED_CLASS>
