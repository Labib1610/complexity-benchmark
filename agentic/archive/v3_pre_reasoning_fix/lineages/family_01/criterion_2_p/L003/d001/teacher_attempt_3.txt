# Problem B — Microbiome Cultivation

Time limit: 1 s   Memory limit: 256 MB

A research lab is cultivating $n$ distinct bacterial strains. For the current experiment, every strain must be inoculated into either growth medium 1 or growth medium 2.

The researchers have catalogued $m$ antagonistic pairs among the strains. If both strains from an antagonistic pair are inoculated into the identically numbered growth medium, they will cross-contaminate and ruin the culture.

Determine an inoculation plan for all $n$ strains that prevents all cross-contamination. If no such plan is possible, report this.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of two strains that form an antagonistic pair. Strains are numbered from 1 to $n$.

## Output
If no safe plan exists, print a single line `NO`.
Otherwise print `YES`, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1, 2}), representing the lexicographically smallest safe plan.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

This removes the mechanical vocabulary that models associated with the classic 2-coloring framing, forcing the model to independently deduce that the antagonistic pairs form a graph that must be bipartite.
</RATIONALE>

The entities and constraints map exactly one-to-one with the original problem, and the requirement for the lexicographically smallest sequence of 1s and 2s is identical, ensuring the exact same output for any given input.
</PRESERVED_ANSWER>

The problem remains exactly 2-coloring / bipartiteness testing on an undirected graph, which is in P and solvable in linear time using BFS or DFS.
</PRESERVED_CLASS>
