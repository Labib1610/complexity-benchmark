# Problem B — Calibration Parameters

Time limit: 1 s   Memory limit: 256 MB

A manufacturing process involves $n$ machines. The facility has a strict physical limit of 200,000 machine slots, meaning the operating count $n$ will always be at least 1 and at most this physical limit. 

Each machine must receive a calibration integer, which must be chosen as either 1 or 2. 

The central database records $m$ interference warnings. The database architecture restricts the number of logged warnings $m$ to a maximum of 200,000, though a perfectly clear system might have no warnings at all (a minimum of 0). Each warning specifies a pair of machines. To prevent a critical failure, the sum of the calibration integers for any warned pair must equal exactly 3. 

Determine a calibration integer for each machine so that no warning results in a failure, or report if this cannot be done.

## Input
The first line contains two integers $n$ and $m$, adhering to the physical and database limits described above.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of machines in an interference warning.

## Output
If no safe configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest safe configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
