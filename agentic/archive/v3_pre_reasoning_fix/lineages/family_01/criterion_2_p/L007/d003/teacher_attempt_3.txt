# Problem B — Data Reconciliation

Time limit: 1 s
Memory limit: 256 MB

A distributed storage system contains $n$ database shards. Each shard must be assigned a replication tier of either 1 or 2.

The system features $m$ consistency monitors, each linking a specific pair of shards. A consistency monitor is satisfied if and only if the product of the replication tiers of its two linked shards is exactly 2.

You must determine if there is a valid assignment for all $n$ shards such that all $m$ consistency monitors are satisfied simultaneously.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that a consistency monitor links shard $u$ and shard $v$.

## Output
If no such assignment exists, print a single line NO.
Otherwise, print YES. On the second line, print $n$ integers $t_1 \dots t_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid sequence of replication tiers.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I changed the problem domain from chemical tanks with pressure states to database shards with replication tiers. The relation constraint was changed from "one is exactly twice the other" to "the product is exactly 2". This forces the model to algebraically evaluate the constraint over the domain $\{1, 2\}$ to discover that it strictly enforces inequality, rather than relying on surface-level pattern matching on the word "twice" to trigger a bipartite graph template.
</RATIONALE>
<PRESERVED_ANSWER>
Since the only allowed values are 1 and 2, their product is exactly 2 if and only if one value is 1 and the other is 2, which is logically identical to the seed's requirement that one is twice the other.
</PRESERVED_ANSWER>
