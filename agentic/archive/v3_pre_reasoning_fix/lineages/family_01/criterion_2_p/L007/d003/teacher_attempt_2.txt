# Problem B — Reactive Pipelines

Time limit: 1 s
Memory limit: 256 MB

An industrial plant operates a network of chemical processing tanks. The facility's architectural blueprint defines a maximum capacity of $200,000$ tanks and a separate maximum capacity of $200,000$ transfer valves. 

The plant currently contains $n$ tanks (at least one, up to the maximum tank capacity). Each tank must be configured to operate at a pressure state of either 1 or 2.

The plant also features $m$ transfer valves (from zero up to the maximum valve capacity). Each transfer valve regulates the flow between a specific pair of tanks. A transfer valve achieves stability if and only if the product of the pressure states of its two connected tanks evaluates to exactly 2.

You must determine if there is a valid configuration for all $n$ tanks such that all $m$ transfer valves are stable simultaneously.

## Input
The first line contains the two integers $n$ and $m$. The bounds for these values are defined by the facility's architectural capacities as described above.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that a transfer valve connects tank $u$ and tank $v$.

## Output
If no such configuration exists, print a single line NO.
Otherwise, print YES. On the second line, print $n$ integers $p_1 \dots p_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid sequence of pressure states.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit inequalities for $n$ and $m$ were replaced with physical capacity limits in the scenario, fulfilling the strategy to state bounds indirectly. The core bipartite affordance ("exactly twice the pressure state") was rewritten to a mathematical equivalent ("product of the pressure states evaluates to exactly 2"), which works identically for the domain $\{1,2\}$ but prevents language models from immediately triggering their bipartite-graph recognition templates based on the word "twice".
</RATIONALE>
<PRESERVED_ANSWER>
Since the only allowed states are 1 and 2, the product of two connected tanks' states is 2 if and only if one tank is at state 1 and the other is at state 2, which is functionally identical to one being exactly twice the other.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires assigning one of two states to each node such that no two adjacent nodes share the same state, which is exactly 2-coloring (bipartite checking) and remains in P.
</PRESERVED_CLASS>
