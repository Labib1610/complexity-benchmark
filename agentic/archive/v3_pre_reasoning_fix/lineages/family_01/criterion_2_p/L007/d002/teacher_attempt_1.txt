# Problem B — Differential Comparators

Time limit: 1 s
Memory limit: 256 MB

A weather station operates a network of $n$ sensors. Each sensor must be configured with a power setting, which must be an integer greater than or equal to 1.

The system relies on $m$ differential comparators to filter out noise. Each comparator is wired to two sensors. A comparator functions correctly if and only if the sum of the power settings of its two connected sensors is exactly 3.

You must determine if there is a valid configuration for all $n$ sensors such that all $m$ comparators function correctly simultaneously.

## Input
The first line contains two integers $n$ and $m$. The station requires a minimum of one sensor to boot, and the main board's memory limit supports up to $200,000$ sensors. The number of comparators $m$ can be as low as zero, up to a maximum of $200,000$ constrained by the wiring harness.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that a comparator is wired to sensor $u$ and sensor $v$.

## Output
If no such configuration exists, print a single line NO.
Otherwise, print YES. On the second line, print $n$ space-separated integers representing the lexicographically smallest valid sequence of power settings.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit mention of "levels 1 or 2" and "absolute difference is exactly 1" acts as a strong semantic trigger for bipartite graph recognition. By changing the rule to "integer greater than or equal to 1" and "sum is exactly 3", the model must mathematically deduce that the only valid states for connected sensors are exactly 1 and 2, and that they must be distinct. The bounds were also rewritten as physical hardware limits to satisfy Strategy S07.
</RATIONALE>
<PRESERVED_ANSWER>
Any two integers $\ge 1$ that sum to 3 must be exactly 1 and 2, perfectly mirroring the seed's constraints for connected sensors; while isolated sensors can technically take larger values, the requirement for the lexicographically smallest sequence guarantees they will always be assigned 1, keeping all outputs identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure is identical: every edge enforces that its endpoints take distinct values from a set of two options, which is exactly 2-coloring (bipartiteness checking), solvable in $O(n+m)$ with BFS/DFS.
</PRESERVED_CLASS>
<RISK>
A model might fail to realize that isolated nodes should be assigned 1, but the phrase "lexicographically smallest" standardly implies selecting the minimal available valid integer at each position.
</RISK>
