<STATEMENT>
# Problem B — Reactive Pipelines

Time limit: 1 s
Memory limit: 256 MB

An industrial chemical facility contains $n$ processing tanks. To maintain operational safety, every tank must be assigned a pressure state chosen from the set $\{1, 2\}$.

The facility also includes $m$ transfer valves. Each valve connects a specific pair of tanks. For a valve to remain stable, the sum of the squares of the pressure states of the two tanks it connects must be exactly 5. If this condition is not met, the valve becomes unstable.

Your task is to determine whether it is possible to assign a pressure state to every tank such that all $m$ transfer valves are strictly stable simultaneously.

## Input
The first line provides the tank count $n$ and the valve count $m$. The facility must operate with a minimum of one tank, while the warehouse holds exactly $200,000$ dedicated control modules, capping the maximum possible number of tanks. Similarly, the system's tracking software has memory allocated for up to $200,000$ valves, meaning $m$ can range from zero up to this maximum capacity.

Each of the following $m$ lines contains two integers $u$ and $v$, indicating that a transfer valve connects tank $u$ and tank $v$.

## Output
If it is impossible to stabilize all valves, output a single line containing NO.
Otherwise, output YES on the first line. On the second line, output $n$ integers $p_1 \dots p_n$ (where each $p_i \in \{1, 2\}$), representing the valid sequence of pressure states that appears first in lexicographical order.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the stability condition from "bitwise AND result of 0" to "sum of squares of the pressure states must be exactly 5". This removes the bitwise signature that models reliably associate with bipartiteness, forcing them to deduce the $(1,2)$ and $(2,1)$ allowed pairs algebraically. Additionally, numeric limits were embedded into physical warehouse and memory constraints to satisfy the indirect-bounds strategy.
</RATIONALE>
<PRESERVED_ANSWER>
Given the restricted domain $\{1, 2\}$, the condition $x^2 + y^2 = 5$ is uniquely satisfied when one variable is 1 and the other is 2, which is strictly mathematically equivalent to $x \text{ AND } y = 0$; all answers remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core requirement is still to assign two distinct values to adjacent nodes in a graph (2-coloring), which remains solvable in linear time $O(n+m)$ via Breadth-First Search, keeping it firmly in P.
</PRESERVED_CLASS>
<RISK>
A model might misread the sum-of-squares condition if it forgets the domain is restricted to $\{1, 2\}$, though the text explicitly states the set of available states in the preceding sentence, minimizing this risk.
</RISK>
