# Problem B — Acoustic Calibration

Time limit: 1 s
Memory limit: 256 MB

You are operating an acoustic testing chamber equipped with $n$ directional sound projectors. The chamber requires at least one projector to function, and its power grid can support a maximum of $200,000$ projectors. Every projector must be calibrated to a specific phase state, which is represented by either the integer 1 or the integer 2.

To monitor the chamber's stability, a network of $m$ acoustic sensors is deployed. The sensor network can be entirely absent (zero sensors) or scale up to a hardware limit of $200,000$ sensors. Each sensor is wired to observe exactly two projectors. A sensor will only report a stable resonance if the sum of the phase states of its two observed projectors is exactly 3. Otherwise, the sensor detects a dangerous interference pattern.

You must determine if there is a valid calibration for all projectors such that every deployed sensor reports a stable resonance at the same time.

## Input
The first line contains the projector count $n$ and the sensor count $m$.
The next $m$ lines each contain two integers $u$ and $v$, specifying that a sensor is wired to observe projector $u$ and projector $v$.

## Output
If no such calibration exists that satisfies all sensors, print a single line containing NO.
If a valid calibration is possible, print YES on the first line. On the second line, print a sequence of $n$ integers $f_1, f_2, \dots, f_n$ (where each $f_i \in \{1, 2\}$), representing the lexicographically smallest valid sequence of phase states.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit bounds on $n$ and $m$ were removed and embedded into the physical constraints of the chamber's power grid and hardware limits, forcing the reader to extract the numerical bounds from the scenario text. Additionally, the condition that the product of the two states must be exactly 2 was replaced with the condition that their sum must be exactly 3, removing the specific "product 2" phrasing that models were using as a shortcut to trigger bipartite graph recognition.
</RATIONALE>
<PRESERVED_ANSWER>
Since the phase states are restricted to the set {1, 2}, requiring their sum to be 3 is algebraically equivalent to requiring their product to be 2; both mandate that exactly one projector is in state 1 and the other is in state 2, leaving all valid assignments and the lexicographical tie-breaker identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing), which is solvable in O(n+m) time using BFS or DFS, keeping it in the complexity class P.
</PRESERVED_CLASS>
