# Problem B — Differential Comparators

Time limit: 1 s
Memory limit: 256 MB

A weather station has $n$ sensors. Each sensor must be configured with a sensitivity level of either 1 or 2.

The system relies on $m$ differential comparators to filter out noise. Each comparator is wired to two sensors. A comparator functions correctly if and only if the absolute difference between the sensitivity levels of its two connected sensors is exactly 1.

You must determine if there is a valid configuration for all $n$ sensors such that all $m$ comparators function correctly simultaneously.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that a comparator is wired to sensor $u$ and sensor $v$.

## Output
If no such configuration exists, print a single line NO.
Otherwise, print YES. On the second line, print $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid sequence of sensitivity levels.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

I replaced the "workers and shifts" conflict scenario with "sensors and differential comparators". The constraint that no conflicting pair can share a shift was replaced by the arithmetic condition that the absolute difference between the two sensors' levels must be exactly 1. Since the levels are restricted to 1 and 2, this mathematically forces the two sensors to have different values. This forces the model to deduce the inequality constraint from the arithmetic definition rather than relying on surface-level "conflict" keywords to trigger a bipartite graph template.
</RATIONALE>
<PRESERVED_ANSWER>
Since the only allowed values are 1 and 2, the condition $|s_u - s_v| = 1$ is satisfied if and only if $s_u \neq s_v$, perfectly mirroring the seed's requirement that conflicting workers must have different shifts.
</PRESERVED_ANSWER>
