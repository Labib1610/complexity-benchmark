# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

A manufacturing plant is reorganizing its workforce into two operational divisions, designated as Division 1 and Division 2. The plant employs $n$ individuals, constrained by a minimum of one person up to the maximum fire-code capacity of 200,000 personnel. Over the years, HR has documented $m$ formal grievances between specific pairs of employees. The grievance archive can hold up to 200,000 records, though it may also be completely empty.

To ensure a harmonious work environment, any two employees who have a grievance filed against each other must be assigned to differing divisions. You must determine if such an arrangement is structurally possible.

## Input
The first line provides the integers $n$ and $m$, representing the current headcount and the number of grievance records, respectively.
Each of the subsequent $m$ lines contains two integers $u$ and $v$, indicating a documented grievance between employee $u$ and employee $v$.

## Output
If no valid division assignment can be made without violating the grievance constraints, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1 \dots s_n$ (where each $s_i$ is either 1 or 2), representing the division assigned to each respective employee. If multiple valid assignments exist, output the one that is lexicographically smallest.

## Example 1
**Input:**
```
4 4
1 2
2 3
3 4
1 4
```
**Output:**
```
YES
1 2 1 2
```

## Example 2
**Input:**
```
3 3
1 2
1 3
2 3
```
**Output:**
```
NO
```
