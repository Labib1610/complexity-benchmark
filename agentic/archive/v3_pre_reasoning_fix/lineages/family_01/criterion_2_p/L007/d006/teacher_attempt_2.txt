# Problem B — Optical Orthogonality

Time limit: 1 s
Memory limit: 256 MB

A deep-sea communications grid contains $n$ transceiver stations. When initializing the grid, every station must be assigned a state code from the options $\{1, 2\}$.

The grid is held together by $m$ two-way optical cables, each spliced between a specific pair of stations. For a cable to become operational, the hardware controllers dictate that the states of the two stations it connects must align with the following activation matrix:

| Station A State | Station B State | Cable Status |
| :---: | :---: | :--- |
| 1 | 1 | Inactive |
| 1 | 2 | Operational |
| 2 | 1 | Operational |
| 2 | 2 | Inactive |

You must figure out if there is a valid state assignment for all stations that allows every single cable in the grid to become operational at the same time.

## Input
The first line provides two integers $n$ and $m$. The grid must have at least one station, but physical space limits the total station count $n$ to $2 \cdot 10^5$. The cable count $m$ may range from a completely unlinked grid (zero cables) up to a maximum splicing limit of $2 \cdot 10^5$.

The next $m$ lines each contain two integers $u$ and $v$, specifying that a two-way optical cable is spliced between station $u$ and station $v$.

## Output
If no assignment can make all cables operational, output NO on a single line.

If a fully operational grid is possible, output YES on the first line. On the second line, output $n$ integers $p_1 \dots p_n$ (where each $p_i \in \{1, 2\}$), representing the lexicographically smallest valid sequence of station states.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
