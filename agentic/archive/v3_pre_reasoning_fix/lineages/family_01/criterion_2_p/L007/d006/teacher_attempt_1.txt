<STATEMENT>
# Problem B — Optical Configuration

Time limit: 1 s
Memory limit: 256 MB

A deep-sea optical system consists of $n$ transceivers. Each transceiver must be configured with a polarization mode chosen from the set $\{1, 2\}$. 

The system utilizes $m$ shared frequency channels. Each channel is allocated to a specific pair of transceivers. In order to prevent signal collision on a channel, the hardware controllers monitor the two transceivers sharing it. The controllers verify their configuration by computing the bitwise XOR of the two mode integers. A channel will only clear for data transmission if this bitwise XOR evaluates to exactly 3. If the result is anything else, the channel remains blocked.

Your task is to determine whether it is possible to assign a polarization mode to every transceiver such that all $m$ channels clear simultaneously.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$, indicating that a frequency channel is allocated to transceiver $u$ and transceiver $v$.

## Output
If it is impossible to configure the system so that all channels clear, output a single line containing NO.
Otherwise, output YES on the first line. On the second line, output $n$ integers $p_1 \dots p_n$ (where each $p_i \in \{1, 2\}$), representing the lexicographically smallest valid sequence of polarization modes.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced explicitly graph-theoretic language ("bidirectional fiber links", "endpoints") with a resource-sharing framing ("shared frequency channels", "allocated to a specific pair"). Also removed the word "orthogonal". This forces models to deduce the pairwise mutual-exclusion property from the XOR operation itself rather than pattern-matching standard graph terminology to undirected graph traversals.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical requirements are identical—assigning values 1 or 2 to $n$ variables such that for each of $m$ specified pairs, their XOR is 3—meaning the valid assignments and the lexicographically smallest sequence remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains equivalent to 2-coloring (bipartiteness testing) on an undirected graph, which is solvable in O(n+m) time using standard BFS or DFS.
</PRESERVED_CLASS>
<RISK>
None. The phrase "allocated to transceiver u and transceiver v" unambiguously defines a pairwise constraint that is functionally identical to an undirected edge.
</RISK>
