<STATEMENT>
# Fluid Routing

Time limit: 1 s   Memory limit: 256 MB

The facility's main control board has exactly $2 \cdot 10^5$ available slots for valves. You are provided with $n$ control valves, numbered 1 to $n$. Each valve must be configured with a pressure state of either 1 or 2.

The facility also features a routing chassis that can accommodate a maximum of $2 \cdot 10^5$ cross-link tubes. You are provided with $m$ cross-link tubes. Each cross-link tube joins a specific pair of valves. For a cross-link to function safely and stabilize the system, the sum of the pressure states of the two valves it connects must be exactly 3.

Your task is to determine a pressure state for each valve such that all cross-link requirements are satisfied. When multiple valid configurations exist, you must output the one that produces the lexicographically smallest sequence of pressure states $s_1, s_2, \dots, s_n$ (prioritizing state 1 for lower-numbered valves whenever possible). If no such configuration is physically possible, you must report this.

## Input
The first line contains two integers $n$ and $m$. The number of valves $n$ is at least 1 and at most the total number of control board slots. The number of tubes $m$ is at least 0 and at most the maximum chassis capacity.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of valves joined by a cross-link tube.

## Output
If no valid configuration can be established, print a single line NO.
Otherwise print YES, followed by a second line containing $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1, 2\}$), representing the lexicographically smallest valid pressure state assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Replaced the explicit "different manifolds" wording with a sum constraint (states are 1 or 2, sum must be exactly 3), which masks the two-coloring structure by framing it as a parity/arithmetic requirement. Replaced direct numeric constraints with physical capacities in the scenario to force the reader to derive the bounds.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that the sum of two states from {1, 2} equals exactly 3 is mathematically identical to requiring the two states to be different, maintaining the exact same valid configurations and lexicographical tie-breaking.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically first valid 2-coloring of a graph (or testing bipartiteness) which is solvable in O(n+m) time using Breadth-First Search.
</PRESERVED_CLASS>
