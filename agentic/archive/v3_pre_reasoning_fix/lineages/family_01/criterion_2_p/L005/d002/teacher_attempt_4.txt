<STATEMENT>
# Pressure Calibration

Time limit: 1 s   Memory limit: 256 MB

A chemical plant contains $n$ reactors, numbered 1 to $n$. Each reactor must be calibrated to operate at a continuous pressure level of exactly 1 bar or 2 bar.

The plant's safety system includes $m$ pressure-balancing pipes. Each pipe connects a specific pair of reactors. For the fluid dynamics to remain stable, the combined pressure of the two reactors connected by any balancing pipe must sum to exactly 3 bar.

Your task is to determine a valid pressure calibration for all $n$ reactors such that every balancing pipe functions correctly. When multiple valid configurations exist, you must output the one that produces the lexicographically smallest sequence of pressure choices $s_1, s_2, \dots, s_n$ (prioritizing 1 bar for lower-numbered reactors whenever possible). If no such calibration is physically possible, you must report this.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of reactors connected by a balancing pipe.

## Output
If no valid calibration can be established, print a single line NO.
Otherwise print YES, followed by a second line containing $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1, 2\}$), representing the lexicographically smallest valid pressure assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Changed the scenario to chemical reactors and replaced the explicit "must be different" constraint with an algebraic constraint ($s_u + s_v = 3$ for $s_i \in \{1, 2\}$). This forces the model to deduce that the arithmetic requirement is isomorphic to an inequality constraint, requiring it to reason about the problem's underlying bipartite structure rather than pattern-matching standard graph terminology.
</RATIONALE>
<PRESERVED_ANSWER>
The domain of choices is exactly $\{1, 2\}$, and the constraint $s_u + s_v = 3$ is mathematically identical to $s_u \neq s_v$, ensuring all valid configurations and the lexicographically smallest sequence remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically first 2-coloring of a graph (or checking bipartiteness), which is solvable in O(n+m) time using BFS/DFS, keeping it in P.
</PRESERVED_CLASS>
