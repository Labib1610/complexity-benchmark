<STATEMENT>
# Fluid Routing

Time limit: 1 s   Memory limit: 256 MB

A hydraulic system contains $n$ control valves, numbered 1 to $n$. Each valve must be configured with a pressure rating of either 1 or 2. 

To prevent pressure surges, the installation includes $m$ cross-link tubes. Each cross-link tube joins a specific pair of valves. For a cross-link to function safely, the sum of the pressure ratings of the two valves it joins must be exactly 3. 

Your task is to assign a pressure rating to each valve such that all cross-link requirements are satisfied. When multiple valid routing configurations exist, you must select the one that minimizes the rating of valve 1. If ties remain, minimize the rating of valve 2, and so on, continuing sequentially up to valve $n$. If no valid configuration is physically possible, you must report this.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of valves joined by a cross-link tube.

## Output
If no valid configuration can be established, print a single line NO.
Otherwise print YES, followed by a second line containing $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1, 2\}$), representing the required pressure rating assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the explicit requirement for valves to use "different" manifolds with a mathematical constraint that their ratings must sum to 3, and replaced the keyword "lexicographically" with an explicit sequential tie-breaking rule. This forces the model to deduce the bipartite condition algebraically and manually derive the component-wise greedy choice, bypassing memorized pattern-matching on graph terminology.
</RATIONALE>
<PRESERVED_ANSWER>
Constraining two variables from {1, 2} to sum to 3 is logically identical to requiring them to be different, and sequentially minimizing elements from index 1 to $n$ is the exact definition of lexicographical order, so all valid assignments and tie-breakers remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a valid 2-coloring of a graph (or testing bipartiteness) and greedily assigning the lowest available color to the smallest unvisited index of each connected component, which is solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
