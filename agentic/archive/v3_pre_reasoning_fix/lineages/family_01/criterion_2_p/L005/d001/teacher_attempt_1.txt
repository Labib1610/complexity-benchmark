<STATEMENT>
# Shift Scheduling

Time limit: 1 s   Memory limit: 256 MB

A manufacturing facility runs two daily shifts, labeled 1 and 2. The facility employs $n$ technicians, numbered 1 to $n$. Because they must share a single specialized tool, certain pairs of technicians cannot work during the same shift. There are $m$ such incompatible pairs.

Assign each technician a shift so that no incompatible pair works the same shift. To respect seniority, you must resolve any flexibility in the schedule by favoring shift 1 for the most senior staff. Specifically, start with the set of all valid schedules. First, restrict this set to those schedules where technician 1 is assigned to shift 1, unless no such schedule exists in the set (in which case leave the set unchanged). Then, restrict the remaining set to schedules where technician 2 is assigned to shift 1, again only if at least one such schedule exists in the current set. Repeat this restriction process sequentially for technicians 3 through $n$. If no valid schedule exists initially, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of technicians who cannot share a shift.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the valid assignment that remains after applying the seniority rules described above.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I removed the explicit "lexicographically smallest" terminology, which was acting as a direct trigger for models to retrieve the standard "lexicographically smallest bipartite coloring" algorithm. Instead, I defined the tie-breaking rule operationally as a sequential filtering of the set of all valid schedules. This forces models to logically deduce that this global filtering process is functionally equivalent to greedily assigning shift 1 to the lowest-indexed unvisited node in each independent component.
</RATIONALE>
<PRESERVED_ANSWER>
The sequential restriction process is the exact mathematical definition of finding the lexicographically smallest element in a set of sequences composed of $\{1, 2\}$, so the unique chosen schedule for any input remains identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem remains 2-coloring a graph; the operational tie-breaking rule still resolves to a simple greedy orientation of each bipartite component, keeping it firmly in P.
</PRESERVED_CLASS>
<RISK>
Models might interpret the text as requiring them to actually generate and maintain the set of all valid schedules (which would be exponential) rather than deducing the structural shortcut, leading to Time Limit Exceeded on correct reasoning paths.
</RISK>
