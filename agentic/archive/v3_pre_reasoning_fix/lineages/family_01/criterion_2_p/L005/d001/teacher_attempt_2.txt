# Sensor Polarity Calibration

Time limit: 1 s   Memory limit: 256 MB

A network consists of sensors, numbered 1 to $n$. Each sensor must be calibrated to a polarity state, which takes a value of either 1 or 2. 

Because of magnetic interference, certain pairs of sensors must be calibrated such that the sum of their polarity states is exactly 3. You are provided with $m$ such pairwise requirements.

You need to determine a valid polarity state for each sensor. If multiple configurations satisfy all the pairwise requirements, you must output the configuration that is lexicographically smallest. If no such configuration is possible, you must report that it cannot be done.

## Input
The first line contains two integers $n$ and $m$. The central controller's hardware limit caps the sensor count $n$ at a maximum of $200,000$, with a minimum requirement of $1$. The database capacity limits the number of requirements $m$ to at most $200,000$, with a minimum of $0$.

Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of sensors whose polarity states must sum to 3.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each being 1 or 2), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
