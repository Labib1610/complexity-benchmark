Let me analyze this problem:

1. We have n technicians and m incompatible pairs
2. We need to assign each technician to shift 1 or 2
3. No incompatible pair should work the same shift
4. We need the lexicographically smallest valid assignment

This is essentially a bipartite graph problem - we need to check if the graph formed by technicians (nodes) and incompatible pairs (edges) is bipartite, and if so, find the lexicographically smallest bipartition.

For the lexicographically smallest assignment:
- We want to assign lower-numbered technicians to shift 1 whenever possible
- This means we should try to assign technician 1 to shift 1, then technician 2 to shift 1 if possible, etc.

One approach:
- Use BFS/DFS to check bipartiteness
- For lexicographically smallest, we can use a greedy approach:
  - Process technicians in order from 1 to n
  - For each unassigned technician, try to assign them to shift 1
  - If that causes a conflict, assign them to shift 2
  - If both cause conflicts, it's impossible

Wait, but this greedy approach might not work correctly. Let me think again.

Actually, for bipartite graphs, once we fix one node's assignment, the rest is determined (within each connected component). So the greedy approach should work:
- Process technicians from 1 to n
- For each unassigned technician, assign them to shift 1
- Then propagate the assignment through their connected component (BFS/DFS)
- If we encounter a conflict during propagation, it's impossible

- But 2 and 3 are connected, so they can't both be shift 2

The algorithm:
1. Build adjacency list
2. Initialize all technicians as unassigned
3. For each technician from 1 to n:
   - If unassigned, assign to shift 1
   - BFS/DFS to propagate: for each neighbor, assign opposite shift
   - If conflict found, output NO
4. Output YES and the assignment

```python
import sys
from collections import deque

def solve():
    input = sys.stdin.read().split()
    ptr = 0
    n = int(input[ptr]); ptr += 1
    m = int(input[ptr]); ptr += 1
    
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(input[ptr]); ptr += 1
        v = int(input[ptr]); ptr += 1
        adj[u].append(v)
        adj[v].append(u)
    
    assignment = [0] * (n + 1)  # 0 = unassigned, 1 = shift 1, 2 = shift 2
    
    for start in range(1, n + 1):
        if assignment[start] != 0:
            continue
        # Assign to shift 1
        assignment[start] = 1
        queue = deque([start])
        while queue:
            u = queue.popleft()
            for v in adj[u]:
                if assignment[v] == 0:
                    assignment[v] = 3 - assignment[u]  # opposite shift
                    queue.append(v)
                elif assignment[v] == assignment[u]:
                    print("NO")
                    return
    
    print("YES")
    print(' '.join(map(str, assignment[1:])))

solve()
```
