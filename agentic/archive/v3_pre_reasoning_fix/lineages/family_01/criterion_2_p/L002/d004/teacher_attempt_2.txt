# Deep-Space Array

Time limit: 1 s
Memory limit: 256 MB

An array of $n$ deep-space transceivers must be calibrated. Each transceiver must be assigned a configuration state, either state 1 or state 2.

The telemetry network relies on $m$ continuous data links. Each link acts as a shared resonant conduit connecting a specific pair of transceivers. These conduits are highly sensitive polarity channels that only stabilize when connecting a transceiver in state 1 to another transceiver in state 2. If both endpoints of a conduit are assigned the identical configuration state, they create destructive standing waves that collapse the link. 

For the array to function, every data link must stabilize. If any link collapses, the entire array will fail.

You must determine a valid state assignment for all $n$ transceivers that ensures full functionality. When multiple valid assignments exist, the automated calibration system defaults to the lexicographically smallest sequence (meaning the sequence of states $b_1, b_2, \dots, b_n$ should be as small as possible when evaluated element by element from the first transceiver to the last).

## Input
The first line provides the number of transceivers $n$ and the number of data links $m$. The central command processor's addressing limit enforces that $n$ is at least 1 and at most $2 \cdot 10^5$. Similarly, the routing table's memory capacity restricts $m$ to be at least 0 and at most $2 \cdot 10^5$.
The following $m$ lines each contain two integers $u$ and $v$, representing a data link connecting transceiver $u$ and transceiver $v$.

## Output
If it is impossible to assign the configuration states without the array failing, output a single line with `NO`.
If a viable assignment exists, output `YES` on the first line. On the second line, output $n$ integers $b_1, \dots, b_n$ (where each is 1 or 2), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit cue of "frequency inversion" and signals arriving as the "opposite band" has been removed, replaced with a polarity channel that only stabilizes when endpoints have different states. This prevents models from immediately matching the phrasing to bipartite 2-coloring. Additionally, the bare numeric inequalities for $n$ and $m$ were replaced with narrative hardware capacity limits, satisfying Strategy S07.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that connected transceivers must have different states (1 and 2) is logically identical to the original requirement, meaning the exact same assignments are valid and the lexicographical tie-breaker yields the same sequence.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks for a valid 2-coloring of a graph and the lexicographically smallest one, which remains solvable in O(n+m) time using Breadth-First Search (class P).
</PRESERVED_CLASS>
