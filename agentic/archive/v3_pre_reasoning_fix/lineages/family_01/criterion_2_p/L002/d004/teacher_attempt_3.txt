<STATEMENT>
# Voltage Calibration

Time limit: 1 s
Memory limit: 256 MB

You are configuring a power distribution board consisting of $n$ independent modules. Each module must be set to an operating voltage of either 1 or 2.

The board contains $m$ load balancers. Each load balancer bridges a specific pair of modules. For a load balancer to remain stable, the sum of the operating voltages of the two modules it bridges must be exactly 3. If any load balancer experiences a voltage sum other than 3, the board will trigger a safety shutdown.

You must determine a valid voltage configuration for all $n$ modules that keeps all load balancers stable. When multiple valid configurations exist, the firmware defaults to the lexicographically smallest sequence (meaning the sequence of voltages $b_1, b_2, \dots, b_n$ should be as small as possible when evaluated element by element from the first module to the last).

## Input
The first line provides the number of modules $n$ and the number of load balancers $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$, representing a load balancer bridging module $u$ and module $v$.

## Output
If it is impossible to set the voltages without triggering a shutdown, output a single line with `NO`.
If a stable configuration exists, output `YES` on the first line. On the second line, output $n$ integers $b_1, \dots, b_n$ (where each is 1 or 2), representing the lexicographically smallest valid voltage assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Changed the scenario from transceivers with frequency inversion to power modules with load balancers. The requirement that connected items have different states (bipartite graph) is now mathematically encoded by requiring their assigned values to sum to exactly 3. This forces the model to mathematically deduce that connected modules must have distinct values, preventing it from relying on textual cues like "inverted" or "opposite" to instantly recognize a 2-coloring problem.
</RATIONALE>
<PRESERVED_ANSWER>
Since the only allowed values are 1 and 2, the constraint that two connected items must sum to 3 is algebraically identical to requiring them to have different values, which preserves the exact 2-coloring logic and lexicographical tie-breaking of the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest valid 2-coloring of a graph, which is solvable in linear time using Breadth-First Search (BFS) and thus remains in the P complexity class.
</PRESERVED_CLASS>
