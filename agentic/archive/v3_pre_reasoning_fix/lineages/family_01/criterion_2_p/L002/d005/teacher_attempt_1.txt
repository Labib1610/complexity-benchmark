<STATEMENT>
# Deep-Space Array

Time limit: 1 s
Memory limit: 256 MB

An array of $n$ deep-space transceivers requires configuration. You must assign each transceiver a polarity index chosen from the set $\{1, 2\}$.

The array integrates $m$ continuous data links. Each link establishes a direct telemetry channel between a specific pair of transceivers. For a telemetry channel to remain stable, its two endpoints must maintain phase equilibrium. Specifically, for any link connecting transceiver $u$ and transceiver $v$, the bitwise XOR of their assigned polarity indices must evaluate to exactly 3. If this bitwise operation yields any other value for any link, the channel collapses and the entire array goes offline.

Your task is to find a valid assignment of polarity indices for all $n$ transceivers that keeps every link stable. If several valid configurations are possible, the system requires the lexicographically smallest sequence of indices (meaning the sequence $b_1, b_2, \dots, b_n$ must be as small as possible when compared element by element from the first transceiver to the last).

## Input
The first line provides the number of transceivers $n$ and the number of data links $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$, indicating a data link between transceiver $u$ and transceiver $v$.

## Output
If no valid assignment can prevent the array from failing, output a single line containing `NO`.
If a stable configuration exists, output `YES` on the first line. On the second line, output $n$ integers $b_1, b_2, \dots, b_n$ (each being 1 or 2), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the "sum is exactly 3" condition with the requirement that "the bitwise XOR of their assigned polarity indices must evaluate to exactly 3." Since the domain of indices is restricted to {1, 2}, this mathematically enforces the exact same constraint ($1 \oplus 2 = 3$, while $1 \oplus 1 = 0$ and $2 \oplus 2 = 0$). This removes the arithmetic sum affordance that models easily pattern-match to graph components, forcing them to evaluate the bitwise logic to discover the mutual exclusivity.
</RATIONALE>
<PRESERVED_ANSWER>
The bitwise XOR of 1 and 2 is 3, while the XOR of identical values from the set {1, 2} is 0, making the new condition mathematically equivalent to the original sum condition for all possible assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires assigning one of two states to each node such that no two adjacent nodes share the same state, which is exactly graph 2-coloring (bipartiteness testing).
</PRESERVED_CLASS>
<RISK>
Models might fail to evaluate the bitwise XOR for the small domain and incorrectly assume the operation allows for other values, though the explicit restriction to {1, 2} makes this unlikely for a competent reader.
</RISK>
