# Deep-Space Array

Time limit: 1 s
Memory limit: 256 MB

An array of $n$ deep-space transceivers must be calibrated. Each transceiver must be configured to a phase state, represented by either the integer 1 or 2.

The array relies on $m$ continuous data links. Each link directly connects a specific pair of transceivers, allowing them to exchange telemetry. To maintain stable telemetry across a link, the two connected transceivers must maintain a phase differential. If any two linked transceivers are configured to the same phase state (both 1 or both 2), the lack of differential will cause destructive interference, and the entire array will go offline.

You must determine a valid phase state assignment for all $n$ transceivers that ensures full functionality. When multiple valid configurations exist, the automated calibration system requires the sequence of integer states $b_1, b_2, \dots, b_n$ to be lexicographically smallest (meaning the sequence should be as small as possible when evaluated element by element from the first transceiver to the last).

## Input
The first line provides the number of transceivers $n$ and the number of data links $m$. The physical limits of the array mandate a minimum of one transceiver and a maximum capacity of exactly two hundred thousand transceivers. The system's routing architecture allows anywhere from zero up to two hundred thousand data links inclusive.
The following $m$ lines each contain two integers $u$ and $v$, representing a data link connecting transceiver $u$ and transceiver $v$.

## Output
If it is impossible to assign the phase states without the array failing, output a single line with `NO`.
If a viable configuration exists, output `YES` on the first line. On the second line, output $n$ integers $b_1, \dots, b_n$ (where each is 1 or 2), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
