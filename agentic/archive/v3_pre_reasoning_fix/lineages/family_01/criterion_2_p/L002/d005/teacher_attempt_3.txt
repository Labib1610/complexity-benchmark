<STATEMENT>
# Support Columns

Time limit: 1 s
Memory limit: 256 MB

A construction project requires the installation of $n$ structural beams. Each beam must be manufactured with a thickness of either 1 or 2 units.

The structural integrity of the building relies on $m$ load-bearing intersections. Each intersection is formed by joining two specific beams at a right angle, creating a rectangular support column. The cross-sectional area of this column is calculated as the product of the thicknesses of the two joined beams. 

To meet the architectural safety code, the cross-sectional area of every support column must be exactly 2 square units. If the area of any intersection is smaller, it will not support the roof; if it is larger, it will exceed the space allocated in the floor plan.

You must determine a valid thickness assignment for all $n$ beams that satisfies the safety code. When multiple valid assignments exist, the factory's automated system defaults to the lexicographically smallest sequence (meaning the sequence of thicknesses $b_1, b_2, \dots, b_n$ should be as small as possible when evaluated element by element from the first beam to the last).

## Input
The first line provides the number of beams $n$ and the number of intersections $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$, representing an intersection formed by beam $u$ and beam $v$.

## Output
If it is impossible to assign the beam thicknesses without violating the safety code, output a single line with `NO`.
If a viable assignment exists, output `YES` on the first line. On the second line, output $n$ integers $b_1, \dots, b_n$ (where each is 1 or 2), representing the lexicographically smallest valid thickness sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The scenario was changed from transceivers with a sum constraint to structural beams with a product constraint. This removes the "sum to 3" affordance that models successfully mapped to "opposite colors", forcing them to independently deduce that for values in {1,2}, a product of exactly 2 mathematically requires the two variables to be different.
</RATIONALE>
<PRESERVED_ANSWER>
For variables restricted to {1, 2}, the condition that their product is exactly 2 is algebraically identical to the condition that their sum is exactly 3, meaning the set of valid assignments is precisely the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest valid 2-coloring of a graph, which is solvable in O(n + m) time using Breadth-First Search.
</PRESERVED_CLASS>
