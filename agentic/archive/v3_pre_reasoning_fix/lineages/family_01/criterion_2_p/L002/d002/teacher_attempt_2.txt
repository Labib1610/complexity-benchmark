<STATEMENT>
# Magnetic Resonance Equilibrium

Time limit: 1 s
Memory limit: 256 MB

A high-energy physics facility operates $n$ magnetic containment fields. The facility's primary power grid has a maximum capacity of 200,000 kilowatts, providing exactly one kilowatt per active field (ensuring at least one field is active, up to the grid's maximum limit). To safely run an experiment, every field must be tuned to a resonance level of either 1 or 2.

The facility's safety system relies on $m$ interference monitors. The monitor network uses a data bus capable of handling a maximum of 200,000 concurrent sensor feeds, dedicating exactly one feed to each monitor. The number of monitors can range from none up to the maximum capacity of the data bus. Each monitor connects a specific pair of fields and continuously checks their relative states. For the containment grid to remain stable, every monitor must verify that one of its connected fields operates at the lower resonance level, while its other connected field operates at the higher resonance level. If any monitor detects both of its connected fields operating at the same level, the resulting interference will cause an immediate system halt.

You must find a valid resonance tuning for all $n$ fields that satisfies every monitor. In cases where more than one valid tuning is possible, the facility's automated systems default to the lexicographically smallest sequence (meaning the sequence of resonance levels $s_1, s_2, \dots, s_n$ should be as small as possible when evaluated element by element from the first field to the last).

## Input
The first line provides the number of fields $n$ and the number of monitors $m$. The bounds for $n$ and $m$ are given by the physical limits described above.
The following $m$ lines each contain two integers $u$ and $v$, representing a monitor connecting field $u$ and field $v$.

## Output
If it is impossible to tune the fields without halting the system, output a single line with `NO`.
If a stable tuning exists, output `YES` on the first line. On the second line, output $n$ integers $s_1, \dots, s_n$ (where each is 1 or 2), representing the lexicographically smallest valid tuning.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit numeric bounds with physical capacities (power grid kilowatts and data bus feeds) to force the reader to derive the bounds for $n$ and $m$. I also removed the explicit "sum to 3" constraint, replacing it with a requirement that connected fields operate at the lower and higher resonance levels respectively, avoiding the direct arithmetic trigger for bipartite graph recognition while preserving the exact same logic.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement for connected fields to have different resonance levels from the available set {1, 2} is mathematically identical to requiring their sum to be exactly 3, so all valid assignments and the lexicographical tie-breaker remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a valid 2-coloring of the components and choosing the lexicographically smallest valid assignment, which remains solvable in $O(n+m)$ time using Breadth-First Search.
</PRESERVED_CLASS>
<RISK>
Some models might misinterpret "lower" and "higher" as relative to each other rather than the absolute values 1 and 2, but since only 1 and 2 are allowed, these interpretations are logically identical.
</RISK>
