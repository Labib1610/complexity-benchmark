<STATEMENT>
# Magnetic Resonance Equilibrium

Time limit: 1 s
Memory limit: 256 MB

A high-energy physics facility operates $n$ magnetic containment fields. To safely run an experiment, every field must be tuned to a resonance state of either 1 or 2.

The facility's safety system relies on $m$ interference monitors. Each monitor connects a specific pair of fields and continuously measures their interference. The interference generated by two connected fields is the absolute difference between the squares of their resonance states. For the containment grid to remain stable, every monitor must detect an interference of exactly 3. If any monitor detects a different interference value, the system will immediately halt.

You must find a valid resonance tuning for all $n$ fields that satisfies every monitor. If multiple stable tunings exist, the safety protocol selects the tuning that assigns the lowest possible resonance state to field 1. If there are still multiple candidate tunings, it selects those that assign the lowest possible state to field 2, and so on, evaluating field by field up to field $n$ until a single tuning remains.

## Input
The first line provides the number of fields $n$ and the number of monitors $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$, representing a monitor connecting field $u$ and field $v$.

## Output
If it is impossible to tune the fields without halting the system, output a single line with `NO`.
If a stable tuning exists, output `YES` on the first line. On the second line, output $n$ integers $s_1, \dots, s_n$ (where each is 1 or 2), representing the correct tuning as dictated by the safety protocol.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit "sum to 3" condition with the mathematically equivalent "absolute difference of squares equals 3", forcing models to algebraically deduce that connected fields must have different states rather than pattern-matching the sum. I also replaced the term "lexicographically smallest sequence" with an operational field-by-field tie-breaking description, preventing models from blindly triggering independent connected-component templates without reasoning about why the global tie-breaker allows local independence.
</RATIONALE>
<PRESERVED_ANSWER>
The set of valid tunings is identical because $|x^2 - y^2| = 3$ for $x,y \in \{1,2\}$ is true if and only if $x+y=3$, and the chosen tuning is identical because the sequential tie-breaking rules exactly define lexicographical order.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph (or testing bipartiteness), which is solvable in O(n+m) time using BFS/DFS, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the sequential tie-breaking as a greedy assignment process that could fail to find a globally valid tuning, though the text "If multiple stable tunings exist, the safety protocol selects the tuning that..." clearly indicates the filtering applies only to already valid tunings.
</RISK>
