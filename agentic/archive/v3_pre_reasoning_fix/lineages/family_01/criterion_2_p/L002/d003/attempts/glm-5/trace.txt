Let me analyze this problem step by step.

We have n transceivers and m data links. Each transceiver must be assigned band 1 or band 2.

For a link between transceivers u and v:
- If u transmits on band 1, it arrives as band 2 at v, so v must be on band 2 to receive
- If u transmits on band 2, it arrives as band 1 at v, so v must be on band 1 to receive
- Similarly for v transmitting to u

For two-way communication on a link between u and v:
- If u is on band 1, then v must be on band 2 (to receive u's signal)
- If u is on band 2, then v must be on band 1 (to receive u's signal)
- If v is on band 1, then u must be on band 2 (to receive v's signal)
- If v is on band 2, then u must be on band 1 (to receive v's signal)

So for a link between u and v, u and v must be on different bands!

This is exactly a bipartite graph problem! We need to check if the graph is bipartite and find a valid 2-coloring.

For the lexicographically smallest assignment:
- We want to minimize the sequence b_1, b_2, ..., b_n
- This means we want b_1 to be as small as possible, then b_2, etc.

For a bipartite graph, each connected component can have two possible colorings (swap 1 and 2). We need to choose the coloring for each component that gives the lexicographically smallest overall sequence.
