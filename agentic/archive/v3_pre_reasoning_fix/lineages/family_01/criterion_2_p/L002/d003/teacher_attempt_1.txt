<STATEMENT>
# Symbiotic Colony

Time limit: 1 s
Memory limit: 256 MB

A research team is studying a colony of $n$ symbiotic organisms. In a controlled environment, each organism must be induced into a metabolic state, encoded as either the integer 1 or 2.

The colony relies on $m$ nutrient exchange channels. Each channel directly connects a specific pair of organisms, allowing them to continuously share nutrients. However, the channels contain a biological filter that regulates the nutrients passing through them based on the states of the endpoints. 

For the colony to survive, every established exchange channel must be viable. A channel is viable if and only if the sum of the metabolic states of the two organisms it connects is exactly 3. If any channel connects a pair of organisms whose combined metabolic state evaluates to any other sum, the entire colony will collapse.

You must determine a valid metabolic state assignment for all $n$ organisms that ensures survival. When multiple valid assignments exist, the laboratory's induction protocol dictates using the lexicographically smallest sequence (meaning the sequence of states $s_1, s_2, \dots, s_n$ should be as small as possible when evaluated element by element from the first organism to the last).

## Input
The first line provides the number of organisms $n$ and the number of exchange channels $m$. The colony requires a minimum of one organism. The facility is equipped with exactly $200,000$ containment units, which serves as the strict upper limit for $n$. The number of channels $m$ may be as low as zero, with its upper limit restricted to the same capacity of $200,000$.

The following $m$ lines each contain two integers $u$ and $v$, representing an exchange channel connecting organism $u$ and organism $v$.

## Output
If it is impossible to assign the metabolic states without the colony collapsing, output a single line with `NO`.
If a viable assignment exists, output `YES` on the first line. On the second line, output $n$ integers $s_1, \dots, s_n$ (where each is 1 or 2), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

Changed the condition for viable channels from explicit state-matching ("state 1 requires state 2") to an algebraic equivalent (the sum of the states must be 3). This forces the model to algebraically deduce that adjacent nodes must have different states, rather than relying on explicit textual cues for bipartite coloring. The numeric bounds were also embedded indirectly within the facility's physical constraints.
</RATIONALE>
