# Magnetic Resonance Equilibrium

Time limit: 1 s
Memory limit: 256 MB

A high-energy physics facility operates $n$ magnetic containment fields. To safely run an experiment, every field must be tuned to a resonance level of either 1 or 2.

The facility's safety system relies on $m$ interference monitors. Each monitor connects a specific pair of fields and continuously measures their combined resonance. For the containment grid to remain stable, every monitor must read a total combined resonance of exactly 3 across its two connected fields. If any monitor detects a sum other than 3, the resulting interference will cause an immediate system halt.

You must find a valid resonance tuning for all $n$ fields that satisfies every monitor. In cases where more than one valid tuning is possible, the facility's automated systems default to the lexicographically smallest sequence (meaning the sequence of resonance levels $s_1, s_2, \dots, s_n$ should be as small as possible when evaluated element by element from the first field to the last).

## Input
The first line provides the number of fields $n$ and the number of monitors $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$, representing a monitor connecting field $u$ and field $v$.

## Output
If it is impossible to tune the fields without halting the system, output a single line with `NO`.
If a stable tuning exists, output `YES` on the first line. On the second line, output $n$ integers $s_1, \dots, s_n$ (where each is 1 or 2), representing the lexicographically smallest valid tuning.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
