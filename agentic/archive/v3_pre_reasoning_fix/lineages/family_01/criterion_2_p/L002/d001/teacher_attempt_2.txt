<STATEMENT>
# Signal Frequency Assignment

Time limit: 1 s
Memory limit: 256 MB

You are configuring a network of $n$ signal transmitters. Each transmitter $i$ (for $1 \le i \le n$) must be assigned a transmission band $b_i$, which can only be chosen as band $1$ or band $2$.

The network's topology imposes $m$ coupling constraints. Each constraint links a pair of transmitters $u$ and $v$. To prevent harmonic resonance, the assigned bands for any coupled pair must satisfy the equation $b_u \cdot b_v = 2$.

Your task is to determine whether it is possible to assign a valid band to all $n$ transmitters. If multiple valid assignments exist, the system requires the one that minimizes the band of transmitter 1. If there are still multiple valid assignments, it must minimize the band of transmitter 2, then transmitter 3, and so on, comparing the sequence of bands element by element.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$, indicating a coupling constraint between transmitter $u$ and transmitter $v$.

## Output
If no such band assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $b_1, b_2, \dots, b_n$ (each being 1 or 2) representing the required band assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The original problem explicitly described states that must be different, which models easily mapped to bipartite graph 2-coloring and solved by greedily assigning the smaller label to the earliest vertex of each connected component. I replaced the "different states" logic with the algebraic constraint $b_u \cdot b_v = 2$ over the domain $\{1, 2\}$. This forces the model to deduce that the algebraic equation is equivalent to inequality, hiding the graph structure and the connected-component shortcut behind a system of non-linear equations.
</RATIONALE>
<PRESERVED_ANSWER>
Since the variables are restricted to the set {1, 2}, the equation $b_u \cdot b_v = 2$ is satisfied if and only if one variable is 1 and the other is 2, which is exactly the same as requiring them to be different.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in O(n + m) time using Breadth-First Search.
</PRESERVED_CLASS>
