# Viscosity Stabilization

Time limit: 1 s
Memory limit: 256 MB

You are formulating a complex industrial solvent composed of $n$ distinct chemical compounds. To prepare the batch, each compound must be assigned a final viscosity level of either 1 or 2.

The formulation process is constrained by $m$ specific pairwise interactions. Each interaction involves mixing equal parts of compound $u$ and compound $v$. 
The viscosity of such a mixture is mathematically defined as exactly the arithmetic mean of the individual viscosities of the two compounds. For the solvent to remain stable, every specified interaction must yield a mixture with a viscosity of exactly 1.5. If any of the $m$ interactions yields a mixture with a viscosity of 1.0 or 2.0, the solvent will separate and the batch will be ruined.

Your task is to determine whether it is possible to assign a viscosity level (1 or 2) to each of the $n$ compounds such that all $m$ interactions stabilize at a viscosity of 1.5. If multiple valid assignments exist, standard protocol dictates using the lexicographically smallest configuration (i.e., the sequence of viscosity levels $c_1, c_2, \dots, c_n$ must be as small as possible when compared element by element starting from the first compound).

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$, indicating an interaction between compound $u$ and compound $v$.

## Output
If no stable assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, \dots, c_n$ (each being 1 or 2) representing the lexicographically smallest stable viscosity assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
