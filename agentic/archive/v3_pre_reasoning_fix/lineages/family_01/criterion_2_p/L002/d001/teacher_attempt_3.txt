<STATEMENT>
# Magnetic Resonance Equilibrium

Time limit: 1 s
Memory limit: 256 MB

A particle accelerator contains $n$ magnetic containment fields. The facility was built with exactly $200,000$ installation bays, establishing the maximum possible number of fields $n$ (a minimum of one field is required for operation). Each field must be assigned a positive integer frequency tier.

The accelerator is equipped with $m$ phase comparators. The facility's inventory contains $200,000$ fiber-optic cables, which sets the strict upper limit on the number of comparators $m$ (a configuration may use any number of them, including none). Each comparator links two specific fields. To prevent resonance cascades, the hardware requires that for any two fields linked by a comparator, the sum of their frequency tiers must be exactly 3.

Your task is to determine whether there is a valid tier assignment for all $n$ fields. If multiple valid assignments exist, the safety override protocol requires the one that is lexicographically smallest (i.e., the sequence of tiers $s_1, s_2, \dots, s_n$ must be as small as possible when compared element by element starting from the first field).

## Input
The first line contains two integers $n$ and $m$.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that a phase comparator links field $u$ and field $v$.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ representing the lexicographically smallest valid tier assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the requirement of choosing "position 1 or 2" with different adjacent values to choosing "positive integer frequency tiers" that "sum to exactly 3" for adjacent fields. This forces the model to mathematically deduce that the only valid positive integers summing to 3 are 1 and 2, and that adjacent fields must take opposite values, effectively obscuring the standard bipartite 2-coloring phrasing. Additionally, numerical bounds were moved from bare inequalities in the input section to physical constraints described in the scenario.
</RATIONALE>
<PRESERVED_ANSWER>
The only positive integers that sum to 3 are 1 and 2, so the domain of values and the requirement that adjacent fields have different values are mathematically identical to the seed problem, preserving all valid assignments and their lexicographical ordering.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring on a graph (which is equivalent to checking bipartiteness), solvable in O(N+M) time using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might incorrectly consider non-integer values or zero if they fail to carefully read "positive integer", but the mathematical phrasing is standard and strictly unambiguous.
</RISK>
