<STATEMENT>
# Deep-Space Array

Time limit: 1 s
Memory limit: 256 MB

A deep-space communication array consists of $n$ transceivers. To initialize the network, you must calibrate each transceiver by assigning it a polarity state selected from the options $\{1, 2\}$.

The network architecture includes $m$ dedicated telemetry channels, each establishing a direct connection between a specific pair of transceivers. For a telemetry channel to operate without interference, its two endpoints must be in phase equilibrium. This requires that the product of the polarity states assigned to the two connected transceivers evaluates to exactly 2. If the multiplication of their states results in any other value, the channel will suffer catastrophic interference and the entire communication array will fail.

Your objective is to determine a valid polarity assignment for all $n$ transceivers that ensures every telemetry channel operates successfully. If multiple valid assignments exist, the automated system requires the lexicographically smallest sequence of states (meaning the sequence of assignments $b_1, b_2, \dots, b_n$ must be as small as possible when compared element by element from transceiver 1 to transceiver $n$).

## Input
The first line contains the number of transceivers $n$ and the number of telemetry channels $m$. The physical payload constraints of the launch vehicle dictate that the array can have at most $200,000$ transceivers, while at least a single transceiver is required for the array to exist. Additionally, the system's power budget limits the number of telemetry channels to a maximum of $200,000$, though it is entirely possible for the array to operate with zero channels.
Each of the following $m$ lines provides two integers $u$ and $v$, representing a telemetry channel connecting transceiver $u$ and transceiver $v$.

## Output
If it is impossible to calibrate the system without causing interference, output a single line containing `NO`.
If a stable calibration is achievable, output `YES` on the first line. On the second line, provide $n$ space-separated integers $b_1, b_2, \dots, b_n$ (where each $b_i \in \{1, 2\}$), representing the lexicographically smallest valid polarity assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

This removes the surface-level pattern match to typical 2-SAT or bipartite graph problem statements while preserving the underlying bipartite structure. Additionally, the numeric bounds in the input section were rewritten as physical limits rather than bare inequalities.
</RATIONALE>
