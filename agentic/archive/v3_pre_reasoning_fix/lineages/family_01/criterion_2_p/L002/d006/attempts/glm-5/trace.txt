from collections import deque

def solve():

    if not data:

    it = iter(data)

No, because the first vertex is the earliest in its component. Any later vertex in the same component has a larger index. So making the earliest vertex 1 is more important than making a later vertex 1. Lexicographic order compares from left to right. The earliest position where two sequences differ determines the order. If we have two colorings for a component, they differ at the smallest index of that component (since one has 1 and the other has 2). So the one with 1 at that index is smaller, regardless of what happens at larger indices. So the choice is clear.

But what if the component has multiple vertices with the same smallest index? Not possible, indices are distinct.

So the greedy algorithm is correct.
