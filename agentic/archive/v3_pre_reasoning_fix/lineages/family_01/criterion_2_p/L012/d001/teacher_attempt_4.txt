# Problem B — Portfolio Hedging Regulations

Time limit: 1 s   Memory limit: 256 MB

You are developing an automated risk-management system for a quantitative trading firm. The firm trades $n$ distinct financial assets (numbered 1 through $n$).

For the upcoming trading session, the system must assign exactly one trading posture to each asset: either a Short position (represented by 1) or a Long position (represented by 2).

The risk-management model has identified $m$ pairs of assets that are critically cointegrated. To comply with strict hedging regulations, the system must ensure that for every cointegrated pair, the two assets are assigned opposing postures (if one asset in the pair is assigned Short, the other must be assigned Long).

To ensure reproducibility in the firm's backtesting environment, the final posture assignment must be deterministic. Specifically, the system must output the lexicographically smallest valid posture sequence. (A posture sequence is a list of $n$ integers where the $i$-th integer is the posture of asset $i$. Sequence $A$ is lexicographically smaller than sequence $B$ if it has a smaller value at the first position where they differ).

If the cointegration constraints form a logical contradiction such that no valid hedging strategy exists, the system must reject the portfolio.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of assets and the number of cointegrated pairs.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a pair of assets that are critically cointegrated.

## Output
If no valid posture sequence exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers (each either 1 or 2)—the lexicographically smallest valid posture sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
