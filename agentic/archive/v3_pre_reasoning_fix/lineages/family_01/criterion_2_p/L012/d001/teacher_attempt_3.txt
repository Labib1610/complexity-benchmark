# Problem B — Database Redundancy Sharding

Time limit: 1 s
Memory limit: 256 MB

You are migrating a legacy database. The database consists of a positive number of distinct partitions, $n$, numbered consecutively starting from 1. The data center contains exactly two hundred thousand server racks, ensuring the number of partitions will never exceed this physical limit. 

You must assign each partition to exactly one of two available storage shards, identified as Shard 1 and Shard 2.

During the analysis phase, the system generated a diagnostic log of $m$ redundancy warnings. This log has a strict capacity of two hundred thousand warning entries, meaning the number of warnings can be anywhere from zero up to this maximum. Each warning specifies two partitions that share overlapping indexes. To ensure high availability, every time a warning links two partitions, exactly one of those partitions must be assigned to Shard 1, and the other must be assigned to Shard 2.

Because the routing engine requires deterministic placement, if there are multiple valid ways to assign the partitions to the two shards, you must choose the assignment that is lexicographically smallest. An assignment is represented as a sequence of $n$ integers, where the $i$-th integer is the shard identifier (1 or 2) for partition $i$. A sequence is lexicographically smaller than another if it contains a smaller value at the first position where they differ.

If the redundancy warnings contradict each other such that no valid placement is possible, you must halt the migration.

## Input
The first line contains two integers $n$ and $m$, representing the number of partitions and the number of redundancy warnings, respectively. 
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a pair of partitions linked by a redundancy warning.

## Output
If no valid placement exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers (each either 1 or 2)—the lexicographically smallest valid shard assignment for the partitions.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
