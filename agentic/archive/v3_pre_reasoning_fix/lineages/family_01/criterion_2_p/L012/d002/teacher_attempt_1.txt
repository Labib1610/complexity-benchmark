# Problem B — Pipeline Segregation Phase

Time limit: 1 s   Memory limit: 256 MB

The Aegis distributed architecture relies on an automated deployment pipeline divided into three sequential steps: telemetry gathering, module segregation, and binary distribution. Your objective is to manage the module segregation step.

The telemetry step monitors $n$ service modules, indexed from 1 to $n$. It outputs a log of $m$ hardware contention alerts. Each alert highlights a pair of modules that attempt to utilize the same physical resources simultaneously.

In the segregation step, you must assign a deployment channel to every module. The system supports exactly two channels, designated by the integers 1 and 2. To ensure stability, whenever an alert links a pair of modules, those two modules must be assigned distinct channels.

To guarantee reproducibility during the final binary distribution step, the pipeline mandates a deterministic assignment. If there are several valid ways to assign the channels, you must provide the one that evaluates as lexicographically smallest. (An assignment is expressed as an $n$-element integer sequence where the $i$-th element is the channel of module $i$. A sequence $X$ is lexicographically smaller than $Y$ if $X$ contains a smaller integer at the first index where the two sequences diverge).

Should the hardware alerts create a situation where it is impossible to assign channels safely, your step must abort the deployment.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), the number of service modules and the number of hardware contention alerts, respectively.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a pair of modules mentioned in an alert.

## Output
If no safe channel assignment can be found, output a single line with `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers (each either 1 or 2) representing the lexicographically smallest safe channel assignment for the modules.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
