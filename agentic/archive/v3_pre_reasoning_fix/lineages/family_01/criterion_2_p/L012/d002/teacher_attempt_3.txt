# Problem B — Pipeline Segregation Phase

Time limit: 1 s   Memory limit: 256 MB

In the automated deployment pipeline for the Aegis distributed architecture, the deployment process is divided into three distinct phases: telemetry gathering, module segregation, and binary distribution. You are responsible for implementing the module segregation phase.

During the initial telemetry phase, the system monitors a set of independent service modules and generates a list of interference warnings. The physical hardware limits the Aegis cluster to a maximum capacity of 200,000 service modules, with at least one module always active. The telemetry buffer can hold up to 200,000 interference warnings, though it is possible for a completely clean run to produce zero warnings. Each warning specifies two module IDs (which can be any integer from 1 to the total number of modules) that compete for identical hardware resources.

In your segregation phase, you must assign an operational mode to each module. The available modes are identified by the integers 1 and 2. Any two module IDs flagged in a single interference warning will suffer from cross-talk if they operate identically. Therefore, you must assign a mode to every module such that the two IDs in any warning are assigned distinct modes.

The final binary distribution phase requires a strictly deterministic configuration to route requests. Because there may be multiple valid ways to assign the modes, the distribution phase expects the sequence of mode assignments that is lexicographically smallest. (An assignment plan is represented as a sequence of integers, where the $i$-th integer is the mode chosen for module $i$. Sequence $A$ is lexicographically smaller than sequence $B$ if $A$ has a smaller value at the first position where they differ).

If the telemetry constraints are inherently contradictory and no valid assignment exists, your phase must halt the pipeline by rejecting the configuration.

## Input
The first line contains two integers $n$ and $m$, representing the number of modules and the number of interference warnings, respectively.
Each of the following $m$ lines contains two integers $u$ and $v$, representing the two module IDs flagged in a warning.

## Output
If no valid assignment plan exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers (each either 1 or 2)—the lexicographically smallest valid assignment plan for the modules.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

This removes the most obvious bipartite pattern-matching trigger, forcing models to deduce the graph structure from the mutual exclusion of binary states. I also translated the bare inequalities from the Input section into physical capacities in the scenario text to fulfill the S07 strategy.
</RATIONALE>
