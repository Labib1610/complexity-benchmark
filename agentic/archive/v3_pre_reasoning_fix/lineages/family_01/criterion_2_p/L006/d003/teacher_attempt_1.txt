# Problem B — Signal Synchronization

Time limit: 1 s
Memory limit: 256 MB

A wildlife tracking project manages a network of $n$ automated monitoring stations. The stations are identified by sequential integers starting from 1. The central server's hardware restricts the total deployment such that there is always at least one station, up to a maximum of two hundred thousand stations.

Each station must be configured with a transmission delay of either 1 millisecond or 2 milliseconds. Because of the terrain and high transmission power, certain pairs of stations are at risk of causing signal interference. The engineers have recorded $m$ such pairs. The logging system may contain no records at all, but it can store up to a maximum number of records equal to the server's absolute station capacity. 

To prevent data loss from overlapping signals, any two stations that are at risk of interfering with each other must be configured such that their combined transmission delays sum to exactly 3 milliseconds.

Your task is to determine if it is possible to assign a transmission delay to each of the $n$ stations to satisfy all interference constraints. If multiple valid configurations exist, the central controller requires the configuration whose sequence of delays is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ — the number of monitoring stations and the number of interfering pairs, respectively. The bounds for these values are defined by the physical system limits described above.
Each of the next $m$ lines contains two integers $u$ and $v$ indicating that station $u$ and station $v$ are at risk of interfering with each other.

## Output
If no valid delay assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$), representing the lexicographically smallest valid sequence of transmission delays.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit bounds in the input section were replaced with indirect descriptions embedded in the scenario, requiring the model to extract and derive the limits (S07). To disrupt the "two-band conflict" surface pattern, the requirement that interfering stations use "different bands" was changed to require their transmission delays (1 or 2) to sum to exactly 3. This forces the model to realize that the arithmetic constraint is equivalent to a difference constraint.
</RATIONALE>
<PRESERVED_ANSWER>
The values assigned to stations remain 1 or 2, and the constraint that adjacent stations must sum to 3 exactly enforces that they must be assigned different values, preserving the exact same valid configurations and lexicographical ordering.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains bipartite 2-coloring, which is solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might struggle to parse the indirect bounds for $n$ and $m$, but since the maximum values ($200,000$) are explicitly written out in words, the bounds are unambiguous.
</RISK>
