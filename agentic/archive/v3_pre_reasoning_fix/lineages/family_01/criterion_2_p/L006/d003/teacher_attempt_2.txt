# Problem B — Crop Rotation

Time limit: 1 s   Memory limit: 256 MB

A large farming cooperative manages $n$ fields, numbered 1 to $n$. For the upcoming season, each field must be planted with one of two crop categories: Legumes (Category 1) or Cereals (Category 2).

The local agricultural board has conducted a soil analysis and identified $m$ pairs of fields that share underground water runoff. To prevent specific nutrient depletion in the shared runoff, any two fields in an identified pair must be planted with different crop categories.

Your task is to determine if it is possible to assign a crop category to each of the $n$ fields such that all nutrient constraints are satisfied. If multiple valid planting plans exist, the cooperative requires the plan whose sequence of category assignments is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$) — the number of fields and the number of shared runoff pairs, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ indicating that field $u$ and field $v$ share water runoff.

## Output
If no valid planting plan exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$), representing the lexicographically smallest valid sequence of category assignments.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
