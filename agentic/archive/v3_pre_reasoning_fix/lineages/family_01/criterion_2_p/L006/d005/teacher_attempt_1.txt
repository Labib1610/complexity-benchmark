# Problem B — Security Profiles

Time limit: 1 s   Memory limit: 256 MB

A parliamentary body consists of $n$ delegates, numbered 1 to $n$. The grand hall features exactly 200,000 seats, establishing the maximum possible number of delegates (there is always at least one). The administration is rolling out a new digital voting system. Each delegate $i$ must be configured with a security profile $s_i$ chosen from the set $\{1, 2\}$.

The ethics office has reviewed historical records and generated a database of $m$ sensitive interactions. The database capacity limits the number of tracked interactions to a maximum of 200,000 (though there might be none). Each interaction specifies two delegates $u$ and $v$. To prevent synchronized tampering, the system enforces the constraint that the logical condition $s_u \neq s_v$ must hold true for every listed pair.

Your task is to determine if there exists a valid sequence of security profiles $s_1, s_2, \dots, s_n$ that satisfies all constraints. If multiple sequences are valid, the administration requires the sequence that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ — the number of delegates and the number of tracked interactions, respectively. (The bounds for these variables are determined by the physical and database limits described above).
Each of the next $m$ lines contains two integers $u$ and $v$ indicating an interaction between delegate $u$ and delegate $v$.

## Output
If no valid sequence exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$), representing the lexicographically smallest valid sequence of security profiles.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

This forces the model to recognize the bipartite coloring structure from logical inequalities rather than relying on "two groups" keyword association, and to parse the text to extract the input constraints.
</RATIONALE>
