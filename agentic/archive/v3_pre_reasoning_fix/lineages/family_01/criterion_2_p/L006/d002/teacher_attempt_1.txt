<STATEMENT>
# Problem B — Reversible Garments

Time limit: 1 s   Memory limit: 256 MB

A fashion designer is constructing a garment from $n$ fabric panels, which are numbered from 1 to $n$. Each panel requires a specific orientation before it can be cut. You must assign each panel an orientation value of either 1 or 2.

The garment's design includes $m$ seams, where each seam connects a specific pair of panels. The sewing machine requires a consistent material thickness across every seam. To achieve this, the sum of the orientation values of the two panels joined by any seam must equal exactly 3.

You need to find out if there is at least one valid way to assign the orientation values to all $n$ panels so that every seam constraint is met. Because the automated cutting machine processes panels in numerical order, if multiple valid assignments exist, you must output the one whose sequence of orientation values is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$) — the number of fabric panels and the number of seams, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ indicating that a seam connects panel $u$ and panel $v$.

## Output
If no valid assignment of orientation values exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$), representing the lexicographically smallest valid sequence of orientation values.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit "opposite finishes" constraint with an algebraic equivalent: the sum of the two assigned values must equal exactly 3. This removes the semantic cue that triggers bipartite-graph and 2-coloring pattern matching, forcing the model to independently deduce that the algebraic constraint implies adjacent nodes must take different values.
</RATIONALE>
<PRESERVED_ANSWER>
Since the only allowed values for each panel are 1 and 2, the only way their sum can be exactly 3 is if one is 1 and the other is 2, which is mathematically identical to requiring them to be different.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still reduces to checking whether a graph is bipartite and finding the lexicographically first valid 2-coloring, which remains solvable in linear time using BFS or DFS.
</PRESERVED_CLASS>
