# Problem B — Memory Routing

Time limit: 1 s   Memory limit: 256 MB

You are configuring a dual-channel memory controller for a high-performance computing cluster. The system contains $n$ memory banks, numbered $1$ to $n$. Each memory bank must be assigned a phase state, designated as either state 1 or state 2.

The dense physical layout of the motherboard creates $m$ interference zones. Each zone strictly bounds a specific pair of memory banks. To achieve signal integrity through destructive interference, any two memory banks sharing an interference zone must be configured to operate in different phase states.

Your task is to determine if there is a valid phase state assignment for all $n$ memory banks that stabilizes all interference zones. If multiple valid assignments are possible, the initialization firmware requires the configuration whose sequence of phase states is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ — the number of memory banks and the number of interference zones, respectively. 

The cluster's addressing hardware uses an 18-bit index ($262,144$ possible values) for memory banks, but exactly $62,144$ of these values are reserved for diagnostics, defining the absolute maximum number of memory banks. The hardware buffer for interference zones has a capacity equal to this maximum number of memory banks. At least one memory bank is always present, and the number of interference zones can be as low as zero.

Each of the next $m$ lines contains two integers $u$ and $v$ indicating that memory bank $u$ and memory bank $v$ share an interference zone.

## Output
If no valid configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$), representing the lexicographically smallest valid sequence of phase states.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The problem description was updated to remove the overly explicit wording ("exactly one bank must be assigned to channel 1, and the other must be assigned to channel 2") that acts as a surface-level trigger for bipartite matching/2-coloring algorithms. It now requires the model to deduce that assigning "different phase states" from a pool of exactly two states is equivalent to 2-coloring. The numeric bounds were also replaced with a hardware constraint description that requires simple arithmetic ($262,144 - 62,144$) to derive the limit of $200,000$.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement for any two bounded banks to operate in "different phase states" out of two possible states is logically identical to the original constraint, ensuring the valid configurations and the lexicographically smallest sequence remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains graph 2-coloring (bipartiteness checking), which can be solved with Breadth-First Search or Depth-First Search in $O(n+m)$ time, keeping it in the P complexity class.
</PRESERVED_CLASS>
<RISK>
A reader might theoretically misunderstand whether the reserved diagnostic values should be subtracted to find the maximum capacity, though the phrasing "defining the absolute maximum" strongly points to a capacity of $262,144 - 62,144 = 200,000$.
</RISK>
