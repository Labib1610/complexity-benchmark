# Problem B — Phase Harmonics

Time limit: 1 s   Memory limit: 256 MB

The facility upgrade requires connecting exactly $n$ workstations. Each workstation must be wired to exactly one of two electrical phases, designated as phase 1 and phase 2. The safety inspectors have identified $m$ pairs of workstations that generate dangerous resonant frequencies if they draw power from the identical phase. Your task is to determine whether a safe wiring plan exists for all workstations, and if so, to provide it.

## Input
The first line provides the number of workstations $n$ and the number of harmonic pairs $m$. The value of $n$ is at least 1 and will not exceed the total number of seconds in 55 hours, 33 minutes, and 20 seconds. The value of $m$ can be zero and is bounded by the exact same maximum as $n$.
Following this, $m$ lines each contain two integers $u$ and $v$ representing a pair of workstations that cannot share the same electrical phase.

## Output
If no safe wiring plan can be formed, print a single line `NO`.
Otherwise, print `YES`. On the subsequent line, output $n$ integers $s_1 \dots s_n$ (each being 1 or 2) representing the phase assigned to each workstation. If multiple safe plans exist, provide the one whose sequence of phase assignments is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the "workers and shifts" framing with "workstations and electrical phases" to remove the obvious bipartite-coloring context that models were matching against. I also applied strategy S07 by replacing the bare numeric bound of $2 \cdot 10^5$ with the equivalent number of seconds in 55 hours, 33 minutes, and 20 seconds, forcing the model to execute basic arithmetic to recover the maximum input size instead of reading it directly.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to assign each workstation to one of two phases without putting harmonic pairs on the same phase is logically identical to assigning workers to two shifts without putting conflicting pairs together, maintaining identical outputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains a 2-coloring problem on an undirected graph, which is solvable in polynomial time using Breadth-First or Depth-First Search.
</PRESERVED_CLASS>
<RISK>
The indirect bound calculation relies on the model correctly converting hours and minutes to seconds, which could theoretically result in a wrong bound if the model's arithmetic reasoning fails, though the math itself is unambiguous.
</RISK>
