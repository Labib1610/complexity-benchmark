# Problem B — Watering Schedules

Time limit: 1 s
Memory limit: 256 MB

A large farming cooperative manages $n$ fields, numbered 1 to $n$. For the upcoming season, each field must be assigned to one of two watering schedules: Schedule 1 or Schedule 2.

The local agricultural board has conducted a soil analysis and identified $m$ pairs of fields that share underground water lines. To prevent water pressure from dropping too low in these shared lines, any two fields in an identified pair must be assigned to different watering schedules.

Your task is to determine if it is possible to assign a schedule to each of the $n$ fields such that all pressure constraints are satisfied. If multiple valid schedule assignments exist, the cooperative requires the assignment whose sequence of schedule numbers is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$. 
The cooperative's land spans up to 200,000 acres. Since each field is allocated exactly one acre, the number of fields $n$ is at least 1 and bounded by this maximum acreage. The board's database has a hard cap of 200,000 entries for logging these connections, meaning the number of shared lines $m$ can be anything from 0 up to this database limit.

Each of the next $m$ lines contains two integers $u$ and $v$ indicating that field $u$ and field $v$ share an underground water line.

## Output
If no valid schedule assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$), representing the lexicographically smallest valid sequence of schedule assignments.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
