# Clockwork Configuration

Time limit: 1 s
Memory limit: 256 MB

You are designing the internal mechanism of a large clockwork engine. The blueprint specifies $n$ gears, numbered sequentially starting from 1. A functional engine requires at least one gear, while the engine's chassis has a hard physical capacity of $200,000$ gear slots.

Each installed gear must be tuned to a specific resonance frequency band. The available tuning bands are strictly band 1 and band 2.

The design also specifies $m$ mechanical linkages. The chassis can support anywhere from zero up to a maximum of $200,000$ linkages. Each linkage directly engages two specific gears. By the laws of mechanics, any two gears that are directly engaged must be tuned to frequency bands that sum to exactly 3 to prevent destructive interference.

You need to determine if it is possible to assign a frequency band to every gear such that no linkages cause interference. If multiple valid configurations exist, you must provide the one where the sequence of frequency bands, ordered from gear 1 to gear $n$, is lexicographically smallest.

## Input
The first line of the input contains two integers $n$ and $m$, representing the number of gears and the number of linkages. The bounds on these values are determined by the physical limits of the chassis described above.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of directly engaged gears, referenced by their valid gear numbers (from 1 to $n$).

## Output
If there is no way to assign frequency bands without interference, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $s_1, \dots, s_n$ (where each $s_i \in \{1, 2\}$) representing the lexicographically smallest valid sequence of frequency bands.

## Example 1
**Input:**
```
4 4
1 2
2 3
3 4
1 4
```
**Output:**
```
YES
1 2 1 2
```

## Example 2
**Input:**
```
3 3
1 2
1 3
2 3
```
**Output:**
```
NO
```

<RATIONALE>
The explicit bounds as bare inequalities in the input section have been removed and replaced with physical capacities and limits integrated into the scenario description (Strategy S07). Additionally, the affordance of "spinning in opposite directions" has been removed; instead, connected gears must have frequency bands from {1, 2} that "sum to exactly 3", forcing the model to algebraically deduce the inequality condition required for bipartiteness.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that two variables from {1, 2} must sum to 3 is mathematically identical to requiring them to be distinct, meaning the valid assignments and lexicographical tie-breaking are exactly identical to the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding a valid 2-coloring (checking if a graph is bipartite) and selecting the lexicographically smallest assignment, which is solved in O(n+m) time using Breadth-First Search.
</PRESERVED_CLASS>
