# Telemetry Calibration

Time limit: 1 s
Memory limit: 256 MB

You are calibrating a telemetry system that manages a cluster of sensors, numbered 1 through $n$. The facility's hardware restricts the cluster size to a maximum of 200,000 sensors, and there is always at least one sensor active. Each sensor must be configured to operate on a specific frequency multiplier. Due to hardware standards, this multiplier must be chosen as exactly 1 or exactly 2.

During testing, the diagnostic system generated a list of $m$ interference records. The diagnostic buffer has a hard limit of 200,000 records, meaning the number of logged interferences can be anywhere from zero up to this maximum. Each record identifies a pair of sensors that are experiencing signal overlap. 

To resolve the overlap, the configuration must be adjusted such that for every recorded pair of sensors, the sum of their assigned frequency multipliers equals exactly 3. If a sensor pair in a record has a sum other than 3, the entire cluster will fail to synchronize.

Determine if there is a valid configuration for all $n$ sensors that resolves all $m$ interference records. If multiple configurations are possible, you must output the one where the ordered sequence of multipliers (from sensor 1 to $n$) is lexicographically smallest.

## Input
The first line of the input contains two integers $n$ and $m$, representing the number of sensors and the number of interference records, respectively. The values of $n$ and $m$ are bounded by the facility's hardware capacity and diagnostic buffer limit as described above.

Each of the following $m$ lines contains two integers $u$ and $v$, identifying the specific sensors involved in a single interference record. These identifiers are guaranteed to be valid sensor numbers between 1 and $n$ inclusive.

## Output
If no valid configuration exists that resolves all interferences, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $f_1, \dots, f_n$ (where each $f_i \in \{1, 2\}$) representing the lexicographically smallest valid sequence of frequency multipliers.

## Example 1
**Input:**
```
4 4
1 2
2 3
3 4
1 4
```
**Output:**
```
YES
1 2 1 2
```

## Example 2
**Input:**
```
3 3
1 2
1 3
2 3
```
**Output:**
```
NO
```

Additionally, all bare inequalities for numeric bounds were replaced with physical capacities in the scenario text, forcing the model to read and derive the constraints rather than parse standard mathematical notation.
