# Clockwork Synchronization

Time limit: 1 s
Memory limit: 256 MB

You are designing a complex clockwork mechanism consisting of $n$ gears, numbered 1 through $n$. Each gear will be driven to rotate continuously in exactly one of two states: clockwise (State 1) or counter-clockwise (State 2).

The design specifies $m$ direct mechanical linkages. Each linkage involves exactly two specific gears whose teeth mesh together. Basic mechanics dictate that for the machine to operate without jamming, any two gears that mesh must rotate in opposite directions—one must be in State 1 and the other in State 2. If two meshing gears are driven in the same state, the mechanism will lock up and fail.

You need to determine whether it is possible to assign a rotation state to every gear such that all linkages operate smoothly. If there are multiple safe configurations, you must determine the one where the sequence of states, ordered from gear 1 to gear $n$, is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of gears and the number of meshing linkages.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) indicating that gear $u$ and gear $v$ mesh together.

## Output
If the mechanism will inevitably jam because no valid assignment of rotation states exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $f_1, \dots, f_n$ (where each $f_i \in \{1, 2\}$) representing the lexicographically smallest valid sequence of rotation states.

## Example 1
**Input:**
```
4 4
1 2
2 3
3 4
1 4
```
**Output:**
```
YES
1 2 1 2
```

## Example 2
**Input:**
```
3 3
1 2
1 3
2 3
```
**Output:**
```
NO
```
