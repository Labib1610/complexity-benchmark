# Chemical Storage Plan

Time limit: 1 s
Memory limit: 256 MB

You are preparing a chemical storage plan for $n$ distinct compounds, numbered 1 through $n$. There are exactly two available stabilizing solvents: Solvent 1 and Solvent 2. Each compound must be suspended in exactly one of these two solvents.

The safety guidelines include $m$ hazardous interactions. Each interaction involves exactly two specific compounds. To prevent a reaction, the two compounds involved in an interaction must be isolated from each other by being placed in different solvents—one in Solvent 1 and the other in Solvent 2. If both compounds in an interaction are placed in the same solvent, the mixture will destabilize.

You must determine if there is a valid assignment of compounds to solvents such that all $m$ interactions are safely isolated. If multiple valid assignments exist, you must provide the one where the sequence of solvent choices, ordered from compound 1 to compound $n$, is lexicographically smallest.

## Input
The first line of the input contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of compounds and the number of hazardous interactions.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — a pair of compounds involved in a single interaction.

## Output
If there is no way to assign solvents to compounds such that all safety guidelines are satisfied, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $f_1, \dots, f_n$ (where each $f_i \in \{1, 2\}$) representing the lexicographically smallest valid sequence of solvent assignments.

## Example 1
**Input:**
```
4 4
1 2
2 3
3 4
1 4
```
**Output:**
```
YES
1 2 1 2
```

## Example 2
**Input:**
```
3 3
1 2
1 3
2 3
```
**Output:**
```
NO
```
