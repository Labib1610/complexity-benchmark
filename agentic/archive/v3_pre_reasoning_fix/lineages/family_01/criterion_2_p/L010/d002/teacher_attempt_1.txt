# Cargo Prioritization Manifests

Time limit: 1 s
Memory limit: 256 MB

You are organizing the processing schedule for $n$ cargo vessels, numbered 1 through $n$. Each vessel must be assigned a processing priority level. The only available priority levels are exactly 1 and 2.

The logistics operation includes $m$ cross-vessel transfer manifests. Each manifest involves exactly two specific vessels. To execute a manifest safely without system conflicts, the sum of the priority levels assigned to the two involved vessels must be exactly 3. If their priority levels sum to any other value, the transfer cannot be processed.

You must determine if there is a valid assignment of priority levels to all vessels such that all $m$ manifests can be executed. If multiple valid assignments exist, you must provide the one where the sequence of priority levels, ordered from vessel 1 to vessel $n$, is lexicographically smallest.

## Input
The first line of the input contains two integers $n$ and $m$. The port is divided into $200$ zones, each with a strict maximum capacity of $1,000$ vessels. The total number of vessels $n$ is at least $1$ and will not exceed the port's total combined capacity. The number of manifests $m$ ranges from $0$ up to the port's total vessel capacity.

Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of vessels involved in a single manifest. The vessels are identified by their numbers, which are between $1$ and $n$.

## Output
If there is no way to assign priority levels to vessels such that all manifests can be executed, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $p_1, \dots, p_n$ (where each $p_i \in \{1, 2\}$) representing the lexicographically smallest valid sequence of priority level assignments.

## Example 1
**Input:**
```
4 4
1 2
2 3
3 4
1 4
```
**Output:**
```
YES
1 2 1 2
```

## Example 2
**Input:**
```
3 3
1 2
1 3
2 3
```
**Output:**
```
NO
```
