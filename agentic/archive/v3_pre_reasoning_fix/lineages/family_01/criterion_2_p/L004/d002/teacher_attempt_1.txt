<STATEMENT>
# Actuator Synchronization

Time limit: 1 s   Memory limit: 256 MB

A factory floor contains a set of actuators that must be synchronized into a two-stroke cycle. You must configure the stroke phase for each actuator by writing a single integer to its control register: either a 1 or a 2.

To maintain structural balance, certain pairs of actuators are mechanically linked. If a linked pair is configured to fire in the same stroke phase, the resulting vibration will damage the mounting brackets. You must ensure that every linked pair is assigned distinct stroke phases.

You need to determine if a safe configuration is possible for the entire set of actuators. If it is, you must output the exact configuration. The initialization sequence programs the actuators in numerical order. Therefore, if multiple safe configurations exist, the firmware requires the one that forms the lexicographically smallest sequence of phase integers.

## Input
The first line contains two integers $n$ and $m$. The total number of actuators $n$ is constrained by the factory's maximum chassis capacity of two hundred thousand, with at least one actuator always installed. The number of mechanical linkages $m$ is limited by the diagnostic memory buffer to two hundred thousand, though a system might have zero linkages.
The following $m$ lines each contain two integers $u$ and $v$, indicating that actuator $u$ and actuator $v$ are mechanically linked. Actuators are identified by integers from 1 to $n$.

## Output
If a safe configuration is impossible, print `NO` on a single line.
If it is possible, print `YES` on the first line. On the second line, print $n$ integers (each being 1 or 2) representing the stroke phase assigned to each actuator, in order from 1 to $n$. This sequence must be the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I changed the scenario from isolating microservices in virtual environments to assigning stroke phases (1 or 2) to factory actuators. This removes the "separated into different environments" phrasing that strongly triggers bipartite graph recall, forcing the model to recognize the structural constraint (assigning two alternating values across linked pairs) on its own. Additionally, the bare numeric inequalities for $n$ and $m$ were replaced with physical capacities written in prose, fulfilling the strategy requirement.
</RATIONALE>
<PRESERVED_ANSWER>
The task is still to assign the values 1 or 2 to $n$ items such that $m$ specified pairs have different values, outputting the lexicographically smallest valid sequence, which maps exactly to the seed problem's logic and output format.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in O(n+m) time using BFS or DFS component by component.
</PRESERVED_CLASS>
<RISK>
Models might struggle to parse numeric limits written as English words ("two hundred thousand"), but the text is exact and unambiguous for any competent reader.
</RISK>
