# Sensor Calibration

Time limit: 1 s   Memory limit: 256 MB

You are calibrating a large-scale system consisting of $n$ sensor units. Each unit must be configured with a polarity setting, which must be chosen as either 1 or 2.

The system relies on $m$ active point-to-point data connections. Each connection links a specific pair of units. To prevent signal reflection and ensure successful data transmission, every data connection requires its two connected units to have polarities that sum to exactly 3. If a connection links two units whose polarities do not sum to 3, the transmission fails.

Your task is to determine whether it is possible to assign a polarity to every unit such that all $m$ data connections operate without failure. If a valid configuration is possible, you must provide the assignment. Because the configuration is applied sequentially, if multiple valid assignments exist, you must output the one that is lexicographically smallest when written as a sequence of polarities from unit 1 to unit $n$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of sensor units and the number of data connections, respectively.
The following $m$ lines each contain two integers $u$ and $v$, indicating that a data connection exists between unit $u$ and unit $v$. Units are identified by integers from 1 to $n$.

## Output
If it is impossible to configure the system without transmission failures, print `NO` on a single line.
If it is possible, print `YES` on the first line. On the second line, print $n$ integers (each being 1 or 2) representing the polarity assigned to each unit, from unit 1 to unit $n$. This sequence must be the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
