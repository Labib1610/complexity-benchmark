# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

A factory employs $n$ workers, and there are $m$ interaction records between pairs of workers. Each worker must be assigned a safety clearance level, which is an integer chosen from $\{1, 2\}$.

To prevent security breaches, any two workers who share an interaction record must be assigned clearance levels that sum to exactly 3. If no such assignment of clearance levels can be made for all workers, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of workers with an interaction record.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the "two shifts" and "different shifts" terminology with assigning a clearance level from {1, 2} where interacting workers must have levels that sum to exactly 3. This forces the model to deduce that the sum constraint on binary values implies strict inequality, preventing it from relying on surface-level keywords to immediately trigger bipartite graph recognition.
</RATIONALE>
<PRESERVED_ANSWER>
For values strictly restricted to {1, 2}, the condition that two values sum to 3 is mathematically equivalent to them being different, meaning the set of valid assignments remains exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is still equivalent to checking whether a graph is 2-colorable (bipartite) and finding the lexicographically smallest coloring, which remains in P.
</PRESERVED_CLASS>
