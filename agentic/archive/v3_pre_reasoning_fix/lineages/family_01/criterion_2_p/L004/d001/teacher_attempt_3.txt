# Problem B — Safety Protocols

Time limit: 1 s   Memory limit: 256 MB

The facility requires each employee to wear exactly one of two distinct uniform colors, designated by the codes 1 and 2. The factory operates 200 production blocks, each containing exactly 1,000 employee lockers. This establishes the absolute maximum workforce size $n$, while operations require at least a single individual. The internal safety log tracks pairs of employees who operate the same heavy machinery. The IT system restricts this log to a maximum entry count $m$ identical to the total number of lockers, though the log may contain zero entries.

To ensure clear visibility and prevent accidents, any two employees registered together in the safety log must be assigned different uniform colors.

Determine if a valid distribution of uniform colors is possible. If it is impossible to satisfy the safety rules, report it.

## Input
The first line contains two integers $n$ and $m$, representing the current workforce size and the number of safety log entries. The values conform to the capacity limits described above.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ — the IDs of a pair of employees who operate the same heavy machinery. Employees are identified by integers from 1 to $n$.

## Output
If no valid distribution of uniform colors can be made, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (each being 1 or 2), representing the uniform color assigned to each employee. If multiple valid distributions exist, print the one that forms the lexicographically smallest sequence $s_1 \dots s_n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the concept of "shifts" with "uniform colors" to prevent pattern-matching on workforce scheduling problems that often map directly to bipartite graphs. To fulfill the S07 strategy, I removed the explicit numeric bounds and replaced them with physical limits: 200 blocks of 1,000 lockers imply the $2\cdot 10^5$ limit for both $n$ and $m$, forcing the model to read and derive these constraints from the text.
</RATIONALE>
<PRESERVED_ANSWER>
The core logic remains assigning one of two labels to nodes such that no adjacent nodes share a label, breaking ties with the lexicographically smallest sequence, meaning the output for any given input is identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a valid 2-coloring of an undirected graph (or determining if it is bipartite), which is solvable in O(n+m) time using BFS or DFS, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the constraints derivation if they fail to multiply 200 by 1,000, though this is a very simple arithmetic step and unlikely to cause ambiguity for a competent reader.
</RISK>
