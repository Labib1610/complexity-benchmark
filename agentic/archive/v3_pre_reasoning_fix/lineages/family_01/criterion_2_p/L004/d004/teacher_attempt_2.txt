<STATEMENT>
# Assembly Line Configuration

Time limit: 1 s   Memory limit: 256 MB

You are configuring a factory with $n$ assembly stations. Each station must be equipped with a robotic arm. You can install either a Type 1 or a Type 2 robotic arm at each station.

The factory floor contains $m$ transfer tracks. Each track facilitates the exchange of parts between a specific pair of stations. Due to the track's asymmetrical loading mechanism, it can only operate if it interfaces with a Type 1 arm at one end and a Type 2 arm at the other. If both stations connected by a track are equipped with the same type of arm, the transfer mechanism will jam and the track will fail.

You must determine if it is possible to assign an arm type to every station such that zero transfer tracks jam. If such an assignment exists, you must also provide it. Since the procurement system processes the stations in numerical order, you must provide the lexicographically smallest sequence of arm types (from station 1 up to station $n$) if there is more than one valid way to configure the factory.

## Input
The first line provides two integers, $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), which denote the total number of assembly stations and the total number of transfer tracks.
Each of the subsequent $m$ lines contains two integers $u$ and $v$, meaning there is a transfer track connecting station $u$ and station $v$. The stations are numbered using integers from 1 to $n$.

## Output
If no valid arm assignment can prevent all track failures, output `NO` on a single line.
If a valid assignment can be found, output `YES` on the first line. On the second line, output $n$ space-separated integers (all 1s or 2s) indicating the arm type for each station from 1 to $n$. If there are multiple working assignments, this sequence must be the lexicographically smallest one.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
