<STATEMENT>
# Assembly Line Calibration

Time limit: 1 s   Memory limit: 256 MB

You are configuring an industrial assembly line consisting of $n$ robotic workstations. The facility's master hub supports a maximum of $200,000$ workstations, and you are guaranteed that at least one workstation is installed. The workstations are interconnected by $m$ transfer belts. The routing mesh can handle a maximum of $200,000$ transfer belts, though a completely unlinked setup (zero belts) is also possible.

For each workstation, you must assign a calibration factor. Hardware restrictions limit this factor to be either 1 or 2.

A transfer belt connects a specific pair of workstations. The belts rely on a resonance effect to move materials. For any transfer belt to function properly, the calibration factor of one of its connected workstations must be exactly twice the calibration factor of the other. If this condition is not met on any belt, the materials will jam, causing a system-wide halt.

You must determine if there is a way to assign a calibration factor to all $n$ workstations such that no transfer belts jam. If such an assignment exists, you must provide it. Because the configuration is flashed to the workstations in ascending numerical order, if there are multiple valid assignments, you must provide the lexicographically smallest sequence of calibration factors (from workstation 1 to workstation $n$).

## Input
The first line contains two integers, $n$ and $m$, representing the number of workstations and the number of transfer belts. The bounds on these values are determined by the facility limits described above.
Each of the following $m$ lines contains two integers $u$ and $v$, indicating a transfer belt between workstation $u$ and workstation $v$. Workstations are identified by integers from 1 to $n$.

## Output
If no valid configuration can prevent all belts from jamming, output `NO` on a single line.
If a valid configuration exists, output `YES` on the first line. On the second line, output $n$ space-separated integers (all 1s or 2s) representing the calibration factor for each workstation from 1 to $n$. If there are multiple valid sequences, output the lexicographically smallest one.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Changed the domain from sensor power settings to assembly line calibration factors. Replaced the "product must be 2" constraint with a "one factor must be exactly twice the other" constraint to prevent simple pattern matching on binary products triggering bipartite graph recognition. Moved the numeric inequality bounds into the scenario description as physical facility capacities, forcing the reader to extract $1 \le n \le 200,000$ and $0 \le m \le 200,000$ from the text.
</RATIONALE>
<PRESERVED_ANSWER>
The allowed values are still {1, 2} and the new ratio constraint still strictly requires adjacent nodes to have different values, so the valid assignments and lexicographical tie-breaking remain exactly identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring of a graph (or determining if it is bipartite), which is solvable in linear time using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might fail to parse the numeric bounds from the text since they are no longer presented as explicit algebraic inequalities in the Input section, but the wording is unambiguous enough that this risk is minimal.
</RISK>
