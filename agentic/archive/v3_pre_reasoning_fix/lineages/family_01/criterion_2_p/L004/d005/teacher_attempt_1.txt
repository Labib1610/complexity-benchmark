# Factory Synchronization

Time limit: 1 s   Memory limit: 256 MB

You are configuring a factory with $n$ assembly stations. The factory floor is an open area of 400 by 500 meters, and each assembly station occupies exactly one square meter. The total number of stations $n$ must be at least 1, and cannot exceed the maximum number of stations that can fit in this total area. 

Each station must be assigned a calibration setting, which must be the integer 1 or the integer 2. 

The factory also contains $m$ transfer tracks. The factory employs 10 maintenance teams, each capable of servicing a maximum of 20,000 tracks. The total number of tracks $m$ can be zero, but cannot exceed the combined capacity of all maintenance teams. Each track facilitates the exchange of parts between a specific pair of stations. 

For a transfer track to synchronize properly, the sum of the calibration settings of the two stations it connects must be exactly 3. If this sum is anything other than 3, the synchronization mechanism will fail. 

You must determine if it is possible to assign a calibration setting to every station such that zero transfer tracks fail. If such an assignment exists, you must also provide it. Since the central controller initializes the stations in numerical order, you must provide the lexicographically smallest sequence of calibration settings (from station 1 up to station $n$) if there is more than one valid way to configure the factory.

## Input
The first line provides two integers, $n$ and $m$, which denote the total number of assembly stations and the total number of transfer tracks. Their valid ranges are determined by the physical space and maintenance team capacities described above.
Each of the subsequent $m$ lines contains two integers $u$ and $v$, meaning there is a transfer track connecting station $u$ and station $v$. The stations are numbered using integers from 1 to $n$.

## Output
If no valid calibration assignment can prevent all track failures, output `NO` on a single line.
If a valid assignment can be found, output `YES` on the first line. On the second line, output $n$ space-separated integers (all 1s or 2s) indicating the calibration setting for each station from 1 to $n$. If there are multiple working assignments, this sequence must be the lexicographically smallest one.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I removed the explicit mention of assigning different types to endpoints, replacing it with the mathematical constraint that the sum of the two assigned settings (which are restricted to 1 or 2) must equal exactly 3. This forces the model to algebraically deduce that the endpoints must differ, rather than triggering a direct text pattern match for bipartite graph coloring. I also replaced the direct numeric bounds with physical dimensions and team capacities, forcing the model to calculate the limits.
</RATIONALE>
<PRESERVED_ANSWER>
Since the only allowed calibration settings are 1 and 2, the only way for two connected stations to sum to 3 is if one is assigned 1 and the other is assigned 2, which is logically identical to the original requirement of assigning different arm types to connected stations.
</PRESERVED_ANSWER>

The core problem remains finding a valid 2-coloring of an undirected graph (or determining that none exists), which is solvable in linear time using Breadth-First Search or Depth-First Search, keeping it in P.
</PRESERVED_CLASS>

There is a minor risk that a model might misinterpret "maximum number of stations that can fit in this total area" if it assumes stations can have different shapes or overlapping layouts, but stating "each assembly station occupies exactly one square meter" leaves essentially no room for alternative arithmetic.
</RISK>
