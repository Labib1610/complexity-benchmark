<STATEMENT>
# Data Center Synchronization

Time limit: 1 s   Memory limit: 256 MB

You are configuring a network of $n$ servers. Each server must be assigned an operational mode: either mode 1 or mode 2.

The network includes $m$ synchronization links, each connecting a pair of servers. Due to bandwidth allocation protocols, a synchronization link operates correctly only if the product of the operational modes of the two connected servers is exactly 2. If the product is 1, the link suffers from under-provisioning. If the product is 4, the link suffers from interference.

You must determine if it is possible to assign an operational mode to every server such that all synchronization links operate correctly. If such an assignment exists, you must also provide it. 

Let $S$ be the set of servers assigned to mode 1. If there is more than one valid configuration, you must output the configuration that yields the most preferred set $S$. Given two distinct valid sets $S_A$ and $S_B$, we say $S_A$ is preferred over $S_B$ if the lowest-numbered server present in exactly one of the two sets belongs to $S_A$.

## Input
The first line provides two integers, $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), which denote the total number of servers and the total number of synchronization links.
Each of the subsequent $m$ lines contains two integers $u$ and $v$, meaning there is a synchronization link connecting server $u$ and server $v$. The servers are numbered using integers from 1 to $n$.

## Output
If no valid mode assignment can make all links operate correctly, output `NO` on a single line.
If a valid assignment can be found, output `YES` on the first line. On the second line, output $n$ space-separated integers (all 1s or 2s) indicating the operational mode for each server from 1 to $n$. If there are multiple working assignments, output the sequence that corresponds to the most preferred set $S$ as defined above.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Removed the keyword "lexicographically smallest" which allowed models to immediately trigger a memorized heuristic ("assign 1 to the smallest vertex in each component"). Replaced it with an equivalent set-preference rule based on the symmetric difference of the sets of servers assigned to mode 1. This forces the model to mathematically deduce that this global preference rule logically decomposes into the same local greedy choice per component.
</RATIONALE>
<PRESERVED_ANSWER>
The set-preference rule is logically isomorphic to lexicographical comparison (the first index where two sequences differ will have a 1 in the lexicographically smaller sequence, meaning that index is in its mode-1 set and not the other), so the unique maximum remains identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem is still finding a valid 2-coloring of a graph (checking bipartiteness), which remains solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might struggle to parse "present in exactly one of the two sets" as the symmetric difference, though this phrasing is mathematically standard and unambiguous.
</RISK>
