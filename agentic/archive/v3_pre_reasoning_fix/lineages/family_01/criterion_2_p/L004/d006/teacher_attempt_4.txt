<STATEMENT>
# Satellite Phase Synchronization

Time limit: 1 s   Memory limit: 256 MB

You are calibrating a network of $n$ orbital relays. Each relay must be assigned to one of two operational bands: band 1 or band 2.

The network relies on $m$ phase-locked links, each connecting a pair of relays. For a link to establish a stable connection, the phase offset between the two relays must be exactly 3. The calibration hardware calculates the phase offset across a link as the bitwise XOR of the operational bands assigned to its two endpoints. If the bitwise XOR evaluates to any value other than 3, the link will fail to synchronize.

You must determine if it is possible to assign an operational band to every relay such that all phase-locked links successfully synchronize. If a valid assignment exists, you must provide it. Since the firmware updates the relays in numerical order, if multiple valid band assignments exist, you must output the sequence of bands (from relay 1 to relay $n$) that is lexicographically smallest.

## Input
The first line provides two integers, $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), which denote the total number of relays and the total number of phase-locked links.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), meaning there is a phase-locked link connecting relay $u$ and relay $v$. The relays are numbered using integers from 1 to $n$.

## Output
If no valid band assignment can make all links synchronize, output `NO` on a single line.
If a valid assignment can be found, output `YES` on the first line. On the second line, output $n$ space-separated integers (all 1s or 2s) indicating the operational band for each relay from 1 to $n$. If there are multiple working assignments, this sequence must be the lexicographically smallest one.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the scenario from servers and tier products to relays and bitwise XOR phase offsets. This removes the "product is exactly 2" trigger for 2-coloring, forcing the model to evaluate the XOR condition (`1 ^ 2 == 3`) to deduce that connected nodes must have different assignments.
</RATIONALE>
<PRESERVED_ANSWER>
The condition `x ^ y == 3` for $x, y \in \{1, 2\}$ is mathematically identical to `x * y == 2`, meaning the exact same assignments are valid and invalid for every possible input.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains fundamentally equivalent to finding the lexicographically first valid 2-coloring of a graph, keeping it solvable in O(n+m) via BFS/DFS (P).
</PRESERVED_CLASS>
<RISK>
Models might overthink the phrase "phase offset" if they assume it implies a physical distance, though the explicit definition as "bitwise XOR" firmly resolves any ambiguity.
</RISK>
