# Data Center Synchronization

Time limit: 1 s   Memory limit: 256 MB

You are configuring a network of servers. The deployment requires assigning an operational tier—either tier 1 or tier 2—to each server.

The facility contains synchronization links, each of which establishes a connection between a specific pair of servers. Bandwidth allocation protocols define how a link behaves based on the tiers of the servers it connects. The outcomes are defined as follows:
- When both connected servers are set to tier 1, the link suffers from under-provisioning.
- When both connected servers are set to tier 2, the link suffers from interference.
- When the link connects one tier 1 server and one tier 2 server, it achieves stable operation.

Your task is to verify whether it is possible to configure the operational tiers of all servers so that every single synchronization link achieves stable operation. If a valid configuration exists, you must output it. The system processes the servers sequentially by their numerical ID (from 1 up to the total number of servers). Thus, if multiple valid assignments exist, you must output the lexicographically smallest sequence of tiers.

## Input
The first line contains two integers, $n$ and $m$. These represent the number of servers and the number of synchronization links, respectively. The data center's floor plan allows for a minimum of a single server and a maximum capacity of two hundred thousand servers. The cable management infrastructure can support anywhere from zero up to two hundred thousand synchronization links.
The following $m$ lines each contain two integers $u$ and $v$, indicating a synchronization link between server $u$ and server $v$. Servers are identified by integers from 1 through $n$.

## Output
If there is no way to assign tiers such that all links operate stably, print `NO` on a single line.
If a valid assignment exists, print `YES` on the first line. On the second line, print $n$ space-separated integers (each being 1 or 2) representing the operational tier of each server from 1 to $n$. To satisfy the sequential processing rule, this sequence must be the lexicographically smallest one among all working assignments.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
