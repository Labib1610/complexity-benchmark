# Bio-Sample Incubation

Time limit: 1 s   Memory limit: 256 MB

You are managing a laboratory with $n$ biological samples, numbered 1 through $n$. Each sample must be placed into one of two available thermal incubators. The incubators are designated by the values 1 and 2. 

Certain samples contain reactive enzymes. There are $m$ documented interactions between specific pairs of samples. If two interacting samples are placed in the same incubator, the shared atmosphere will cause a reaction that ruins both samples. To prevent this, for every documented interaction between a sample $u$ and a sample $v$, their assigned incubator values must sum to exactly 3.

Determine if there is a valid assignment of all $n$ samples to the incubators that prevents all reactions. If there are multiple valid ways to assign the samples, the automated loading system requires the assignment that is lexicographically smallest when the incubator values for samples 1 through $n$ are written as a sequence.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing a documented interaction between sample $u$ and sample $v$.

## Output
If no safe assignment is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \ldots, c_n$ (where each $c_i \in \{1, 2\}$) representing the lexicographically smallest valid sequence of incubator assignments.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
