# Orbital Array Calibration

Time limit: 1 s   Memory limit: 256 MB

An orbital observatory is built from $n$ mirror segments, indexed sequentially starting from 1. To stabilize the image, every segment must be assigned a phase state, chosen from the values 1 and 2.

Vibrations propagate through the chassis. Engineers have identified $m$ pairs of segments that share a mechanical linkage, causing them to resonate. To suppress this interference, any two segments connected by a linkage must have phase states that sum to exactly 3.

You need to determine if a valid phase state assignment exists for the entire observatory. When multiple valid assignments are possible, the automated system defaults to the one that is lexicographically smallest when reading the phase states of segments 1 through $n$ in order.

## Input
The first line provides the integers $n$ and $m$. The segment count $n$ begins at a minimum of 1 and cannot exceed the maximum chassis payload of 200,000 units. The linkage count $m$ may be zero, but will not surpass the telemetry storage limit of 200,000 records.
Each of the subsequent $m$ lines contains two integers $u$ and $v$, representing a mechanical linkage between segment $u$ and segment $v$.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \ldots, c_n$ (where each $c_i \in \{1, 2\}$) representing the lexicographically smallest valid phase state sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the requirement of "different calibration modes" to "phase states that sum to exactly 3" for values chosen from 1 and 2. This removes the direct "different" keyword that triggers bipartite graph recall, forcing the model to deduce that the sum constraint on two binary values is equivalent to an inequality constraint. Numeric bounds were also replaced with system limits to satisfy the indirect bounds strategy.
</RATIONALE>
<PRESERVED_ANSWER>
Because the only allowed values are 1 and 2, any pair summing to 3 must consist of one 1 and one 2, which is mathematically identical to requiring them to be different.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem remains 2-coloring a graph (or testing bipartiteness) to find the lexicographically smallest valid assignment, which is in P.
</PRESERVED_CLASS>
