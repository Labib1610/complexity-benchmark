# Problem B — Magnetic Conduits

Time limit: 1 s
Memory limit: 256 MB

A research facility is testing a network of servers. Each server must be configured with a specific polarity, represented by either the value 1 or 2.

The servers are connected by a series of magnetic conduits. If two servers connected by a conduit are configured with the exact same polarity, they will repel each other and damage the conduit. Consequently, any two servers sharing a conduit must be assigned different polarities.

The facility has a maximum physical capacity of two hundred thousand servers, and there is always at least one server under test. The system's blueprint logs the conduits between servers; this blueprint can contain up to two hundred thousand conduit records, or it might be completely empty.

You must determine if it is possible to assign a polarity to every server without causing any damage. If it is possible, you must output the valid configuration. If there are multiple safe ways to assign the polarities, you must provide the one that results in the lexicographically smallest sequence of values when listed from the first server to the last.

## Input
The first line provides the total number of servers $n$ and the number of conduits $m$.
The following $m$ lines each detail a conduit by listing the two servers it connects. Servers are identified by integers from 1 to $n$.

## Output
If no safe configuration can be established, output a single line with the word `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers (each either 1 or 2), representing the polarities assigned to servers 1 through $n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
