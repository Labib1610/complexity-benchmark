We need bipartite graph 2-color. Lexicographically smallest assignment sequence: we want minimal s_i values (1 or 2) lexicographically over array. That means we want each position as small as possible, but must satisfy bipartite constraints. Since 1 < 2, we want to assign 1 whenever possible. However, due to components, colors may be swapped. For each connected component, if we color arbitrarily we can choose to flip colors. To get lexicographically smallest overall, we should choose orientation that gives minimal sequence when considering all nodes in increasing order.

Simpler: For each component, we can compute two possible colorings: original and flipped. We need to pick orientation that leads to minimal sequence lexicographically overall across all components. Since components are independent, we can decide orientation per component based on minimal effect on indices within component sorted ascending. Since lexicographic comparison: we iterate i=1..n, check color[i]. If for a component, the first index in that component that differs between orientations determines which orientation is better. So we can choose for each component: look at its nodes sorted ascending; find first node i where the two orientations would differ: orientation1 gives color c, orientation2 gives 3-c. Since 1<2, we choose orientation that gives 1 at that position. So algorithm: For each component, store nodes list. Do BFS to assign provisional colors 0/1. For each component, find minimal node index among its nodes. At that node, provisional color is 0 or 1. Orientation1: color=provisional; orientation2: flipped. Compare provisional color to flipped: if provisional==0 (i.e., 1) orientation1 gives 1; orientation2 gives 2. So choose orientation1. If provisional==1, orientation1 gives 2, orientation2 gives 1, choose orientation2. So essentially choose orientation such that minimal node gets 1. That yields lexicographically smallest sequence because at the earliest differing index across components, the component that contains that index will have chosen orientation giving 1.

Proof: Because we process components independently, lexicographic minimization reduces to ensuring that for each component, the smallest index in that component gets color 1. That ensures that at the first index among all components, its color is 1. For later indices, if component's smallest index already determined orientation, subsequent indices will follow accordingly; but could there be case where component A's smallest index is 2, component B's smallest index is 1. We process component containing 1: orientation ensures 1 at 1. Then component with 2 orientation ensures 1 at 2 etc. Works.

Edge case: components may have multiple nodes with same minimal index? No.

Thus algorithm:

- For each node not visited:
    - BFS/DFS to assign provisional colors.
    - If conflict -> not bipartite: output NO.
    - Store component nodes list.
    - After BFS, determine min node index in component (0-based). If color[min]==1 (provisional 1) meaning provisional color 2? Wait provisional colors 0/1, mapping to labs 1/2: color 0 -> lab 1, color 1 -> lab 2. So if provisional color of min node is 0 -> already 1, we keep. If 1 -> need flip. So we set final lab array: for each node in component, final_lab = color[node] (0 or 1) if not flipped else 1-color[node]. So basically determine flip_flag = (color[min]==1). Then final_lab[node] = color[node] ^ flip_flag. Then convert to 1/2 by +1.
