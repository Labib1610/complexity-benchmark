The problem asks us to assign each of the $n$ personnel to one of two work slots (1 or 2) such that no incompatible pair is assigned to the same slot. We are given $m$ pairs of incompatible personnel. If a valid assignment exists, we need to find the lexicographically smallest assignment sequence $s_1, s_2, \ldots, s_n$, where $s_i$ is the slot assigned to person $i$. If no valid assignment exists, we output "NO".

This problem can be modeled as checking if a graph is bipartite. The personnel are vertices, and the incompatibilities are edges. If the graph is bipartite, a valid assignment exists (assigning vertices in one partition to slot 1 and the other partition to slot 2). If it is not bipartite, no valid assignment exists.

However, there is a second requirement: the assignment must be lexicographically smallest. This means we want to minimize $s_1$, then $s_2$, and so on. Since $s_i \in \{1, 2\}$, we want $s_1$ to be 1 if possible. If $s_1$ is fixed to 1, we want $s_2$ to be 1 if possible, etc.

Wait, simply checking bipartiteness isn't enough because a bipartite graph can have multiple valid 2-colorings. A connected component with $V_c$ vertices and $E_c$ edges has exactly two valid colorings (swapping colors). We need to choose the coloring for each component such that the resulting sequence $s_1, \ldots, s_n$ is lexicographically smallest.

Let's break down the constraints: $n, m \le 200,000$. An $O(n+m)$ solution is required.

The strategy would be:
1. Represent the graph using an adjacency list.
2. Iterate through all vertices $i$ from 1 to $n$.
3. If vertex $i$ has not been visited yet, it belongs to a new connected component.
4. Perform a BFS or DFS on this component to check for bipartiteness and to establish the two possible colorings.
5. Since we want the lexicographically smallest result, we need to decide which of the two colorings to apply for each component.
6. Let the two possible colorings for a component be $C_1$ and $C_2$. $C_2$ is just $C_1$ with 1s and 2s swapped.
7. We need to compare the partial sequences formed by $C_1$ and $C_2$ restricted to the indices present in this component. However, we process components in some order. To make the global sequence lexicographically smallest, we must greedily pick the assignment that makes the first available (unassigned) person have slot 1 if possible.

Wait, simply iterating 1 to $n$ and assigning 1 if possible works?
Suppose we are at vertex $i$. If $i$ is already assigned a color, we just continue. If $i$ is not assigned, we start a traversal (BFS/DFS) from $i$.
In the traversal, we assign $i$ to 1. Then we propagate the constraints to neighbors.
If we encounter a conflict (neighbor already assigned same color), then the graph is not bipartite $\to$ output NO.
If the component is bipartite, we have fixed the colors for all vertices in this component based on the decision that $i$ gets color 1.
Is it always optimal to assign color 1 to the first unvisited vertex $i$?
Yes, because we want $s_i$ to be as small as possible. Since $i$ is the smallest index in this component (because we iterate $1$ to $n$ and pick unvisited), picking $s_i=1$ is better than $s_i=2$ for the lexicographical comparison of the full sequence.
Since the component is disjoint from all previously processed components (which are fully assigned), and $i$ is smaller than any other unassigned vertex in the component, fixing $s_i=1$ forces a specific assignment for all other vertices in the component.
Wait, does fixing $s_i=1$ force the assignment for the *entire* component?
Yes, in a connected component, once the color of one node is fixed, the colors of all other nodes are determined if the graph is bipartite.
So the algorithm is:
1. Initialize `colors` array of size $n+1$ with 0 (unassigned).
2. Iterate $i$ from 1 to $n$:
    a. If `colors[i]` is not 0, continue.
    b. Start BFS/DFS from $i$. Assign `colors[i] = 1`.
    c. During traversal, if we find a neighbor $v$ with `colors[v] == colors[u]`, then it's impossible. Return NO.
    d. If neighbor $v$ is unassigned, assign `colors[v] = 3 - colors[u]` (swapping 1 and 2).
    e. If `colors[v]` is already assigned and valid, continue.
3. If loop finishes without conflicts, print YES and the `colors` array.

Let's double check the "lexicographically smallest" requirement.
We want the sequence $s_1, s_2, \dots, s_n$ to be minimized.
The first element $s_1$ is determined by the component containing 1.
If 1 is unvisited, we must assign it. To minimize $s_1$, we *must* assign 1 to slot 1.
Once $s_1$ is fixed to 1, the colors of all other nodes in the component of 1 are determined (up to bipartiteness check).
Then we move to $s_2$. If 2 is already visited (in 1's component), its color is fixed. If not, we are at the start of a new component. To minimize $s_2$, we must assign 2 to slot 1.
This logic holds because the decision for a component is constrained only by the bipartition property within that component. There are no edges between components, so the choice of coloring for one component does not affect the feasibility of another.
Within a component, there are exactly two valid colorings: $A$ and $\bar{A}$ (where $\bar{A}$ is $A$ with 1s and 2s swapped).
Suppose the vertices in a component are $v_1, v_2, \dots, v_k$ in increasing order of index. We encounter the smallest index $v_{min}$ when iterating 1 to $n$.
If we assign $v_{min}$ color 1, we get coloring $A$. If we assign $v_{min}$ color 2, we get coloring $\bar{A}$.
Since $v_{min}$ is the smallest index in this component, and all indices smaller than $v_{min}$ belong to other components (already processed), the value of $s_{v_{min}}$ is the first point of difference between the two options for this component in the global sequence.
Since we want to minimize the global sequence, we must choose the option that makes $s_{v_{min}}$ smaller.
Thus, we must assign $s_{v_{min}} = 1$.
This confirms the greedy strategy: whenever we encounter an unvisited node $i$, we treat it as the "root" of a new component traversal and assign it slot 1.

Wait, is it possible that assigning $s_i=1$ leads to a conflict later in the component, but assigning $s_i=2$ would work?
No. If a valid coloring exists, both colorings $A$ and $\bar{A}$ are valid (they are just color swaps). If one leads to a conflict (e.g., an edge between two nodes of same color), the other will also lead to a conflict because the conflict is structural (odd cycle). If the graph is not bipartite, neither coloring works. If it is bipartite, both work, and we just pick the one where the root is 1.

    input_data = sys.stdin.read().split()
