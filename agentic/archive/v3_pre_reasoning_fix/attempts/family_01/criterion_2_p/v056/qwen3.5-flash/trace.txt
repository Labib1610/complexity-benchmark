The problem asks us to assign a mode (either 1 or 2) to each of $n$ transceiver units such that for $m$ given pairs $(u, v)$, the units $u$ and $v$ have different modes. We need to check if such an assignment exists. If it does, we need to output "YES" followed by the lexicographically smallest assignment sequence. If not, output "NO".

This problem can be modeled as a graph problem. Let the transceiver units be vertices in a graph. Each interference condition corresponds to an edge between two vertices. We need to color the vertices with two colors (1 and 2) such that no two adjacent vertices share the same color. This is exactly the problem of checking if a graph is bipartite.

If the graph is bipartite, a valid 2-coloring exists. If it is not bipartite, then no valid assignment exists.

Since the graph might not be connected, we need to check each connected component. For each component, we can perform a BFS or DFS to verify the bipartite property and determine the colors.

import sys

# Increase recursion depth just in case, though we will use iterative
sys.setrecursionlimit(300000)

def solve():
    input_data = sys.stdin.read().split()
    if not input_data:
        return

    iterator = iter(input_data)
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(iterator))
        v = int(next(iterator))
        adj[u].append(v)
        adj[v].append(u)

    colors = [0] * (n + 1)
    
    # To avoid deque overhead if not needed, simple list with pointer is fine
    # But deque is standard for BFS.
    from collections import deque
    
    for i in range(1, n + 1):
        if colors[i] == 0:
            colors[i] = 1
            # BFS
            q = deque([i])
            while q:
                u = q.popleft()
                c = colors[u]
                next_c = 3 - c
                for v in adj[u]:
                    if colors[v] == 0:
                        colors[v] = next_c
                        q.append(v)
                    elif colors[v] != next_c:
                        print("NO")
                        return

    print("YES")
    print(*(colors[1:]))

if __name__ == '__main__':
    solve()

        if colors[i] == 0:
            # Start BFS from node i

            colors[i] = 1
            queue = deque([i])

                        print("NO")
                        return

    print("YES")
    # Output the colors for 1 to n
    print(*(colors[1:]))
