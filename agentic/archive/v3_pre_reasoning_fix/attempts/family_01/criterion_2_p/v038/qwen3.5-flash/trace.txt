The problem asks us to assign each of $n$ staff members to one of two duty periods, 1 or 2. We are given $m$ constraints, where each constraint is a pair of staff members $(u, v)$ who cannot be assigned to the same duty period. This means if $u$ is assigned to 1, $v$ must be assigned to 2, and vice versa. This is a classic 2-SAT or Bipartite Graph Coloring problem. Specifically, we need to determine if the graph formed by the incompatibility constraints is bipartite. If it is, we need to find a valid 2-coloring.

If the graph is bipartite, there are potentially multiple valid colorings. We need to find the lexicographically smallest sequence of assignments $(s_1, s_2, \dots, s_n)$.
The assignment $s_i$ can be either 1 or 2. We want the sequence to be as small as possible in lexicographical order. This means we prefer $s_1=1$ if possible. If not, $s_1=2$. Then, given $s_1$, we prefer $s_2=1$ if possible, and so on.

Let's model this as a graph problem. The staff members are nodes $1, \dots, n$. The incompatibility pairs are edges. We need to color the nodes with colors 1 and 2 such that no two adjacent nodes have the same color. This is exactly finding a 2-coloring of the graph. If the graph is not bipartite (contains an odd cycle), no solution exists, and we output `NO`.

If the graph is bipartite, it consists of one or more connected components. Within each connected component, once the color of one node is fixed, the colors of all other nodes in that component are determined (up to swapping 1 and 2).
For a connected component, let's say we pick a node $u$ and assign it color $c \in \{1, 2\}$. Then all neighbors of $u$ must get color $3-c$, their neighbors must get $c$, and so on.
Essentially, for a component $C$, there are exactly two valid assignments: $A$ and $B$, where $A$ is the inverse of $B$ (swapping 1s and 2s).
Let the sequence of colors for the nodes in component $C$ according to assignment $A$ be $(a_1, \dots, a_k)$ and according to assignment $B$ be $(b_1, \dots, b_k)$, where indices correspond to the sorted indices of nodes in $C$. Note that $a_i + b_i = 3$.

We need to construct the full sequence $(s_1, \dots, s_n)$ to be lexicographically smallest.
Since we want $s_1$ to be 1 if possible, then $s_2$ to be 1 if possible, etc., we can iterate through the nodes $i = 1$ to $n$.

```python
import sys

# Increase recursion depth just in case, though we will use BFS
sys.setrecursionlimit(200005)

def solve():
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    iterator = iter(input_data)
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    adj = [[] for _ in range(n + 1)]
    
    for _ in range(m):
        u = int(next(iterator))
        v = int(next(iterator))
        adj[u].append(v)
        adj[v].append(u)
        
    color = [0] * (n + 1)
    
    # BFS queue
    # We can reuse a list as a queue or use collections.deque
    # Since we need to process nodes, let's use a list and an index pointer or deque
    
    from collections import deque
    
    for i in range(1, n + 1):
        if color[i] == 0:
            # Start BFS
            color[i] = 1
            q = deque([i])
            
            while q:
                u = q.popleft()
                c_u = color[u]
                c_v_req = 3 - c_u
                
                for v in adj[u]:
                    if color[v] == 0:
                        color[v] = c_v_req
                        q.append(v)
                    elif color[v] != c_v_req:
                        # Conflict found
                        print("NO")
                        return

    # If we reach here, a valid coloring exists
    print("YES")
    # Construct output string
    # s_1 ... s_n
    # color array is 1-indexed, so slice [1:]
    print(*(color[1:]))
```

```python
import sys
from collections import deque

def solve():
    # Read all input from stdin
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return

    iterator = iter(input_data)
    
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    adj = [[] for _ in range(n + 1)]
    
    for _ in range(m):
        u = int(next(iterator))
        v = int(next(iterator))
        adj[u].append(v)
        adj[v].append(u)
        
    color = [0] * (n + 1)
    
    # Iterate through all nodes to handle disconnected components
    for i in range(1, n + 1):
        if color[i] == 0:
            # Start BFS for the component
            # To ensure lexicographically smallest sequence, we assign color 1 to the 
            # first uncolored node we encounter in this component.
            # Since we iterate i from 1 to n, the first time we see a node in a component,
            # it is the node with the smallest index in that component.
            # Thus, setting color[i] = 1 is the correct greedy choice.
            
            color[i] = 1
            q = deque([i])
            
            while q:
                u = q.popleft()
                current_color = color[u]
                required_color = 3 - current_color
                
                for v in adj[u]:
                    if color[v] == 0:
                        color[v] = required_color
                        q.append(v)
                    elif color[v] != required_color:
                        # Conflict detected: bipartite check failed
                        print("NO")
                        return

    # If we successfully colored all nodes
    print("YES")
    # Print the colors for 1 to n
    # Using sys.stdout.write for efficiency
    sys.stdout.write(" ".join(map(str, color[1:])) + "\n")

if __name__ == '__main__':
    solve()
```

```python
    # Read all input from standard input at once for efficiency
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return

    for _ in range(m):
        u = int(next(iterator))
        v = int(next(iterator))
        adj[u].append(v)
        adj[v].append(u)
        
    # Array to store the assigned duty period for each staff member
    # 0: unassigned, 1: period 1, 2: period 2
    color = [0] * (n + 1)
    
    # Iterate through each staff member to handle connected components
    for i in range(1, n + 1):
        if color[i] == 0:
            # Start BFS for the connected component containing i
            # To ensure the lexicographically smallest sequence, we assign period 1
            # to the first unassigned member of the component (which is i).
            color[i] = 1
            q = deque([i])
            
            while q:
                u = q.popleft()

                required_color = 3 - current_color # 1 -> 2, 2 -> 1

                        color[v] = required_color
                        q.append(v)
                    elif color[v] != required_color:
                        # If a neighbor already has the same color as required, 
                        # it's a conflict (odd cycle).
                        print("NO")
                        return

    # If we successfully assigned colors to all nodes without conflict
    print("YES")
    # Print the sequence s_1, s_2, ..., s_n
    sys.stdout.write(" ".join(map(str, color[1:])) + "\n")
```
