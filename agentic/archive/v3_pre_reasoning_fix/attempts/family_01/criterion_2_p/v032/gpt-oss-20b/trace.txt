We can assign colors arbitrarily within component. To get lexicographically smallest overall, we should choose for each component a coloring that yields minimal lexicographic sequence when considered from left to right.

Observation: For each component, we have two possible color assignments: one is complement of other. We need to decide which to use to minimize sequence. But components may interleave indices. So we can process vertices in order 1..n; when encountering a vertex whose component hasn't been assigned yet, we need to choose an orientation for all nodes in that component that gives minimal sequence from that point onward.

Edge case: graph may have multiple components overlapping indices; but this approach ensures global lexicographic minimal.

Proof: Because lexicographic order compares first different index. For component with earliest vertex i, orientation that gives 1 at i is minimal. For later components, orientation decisions don't affect earlier indices. So this greedy works.
