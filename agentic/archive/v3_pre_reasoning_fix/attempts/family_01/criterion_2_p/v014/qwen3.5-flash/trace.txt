The problem asks us to assign each of $n$ staff members to one of two periods (labeled 1 and 2) such that for every pair of incompatible staff members, they are assigned to different periods. If no such assignment exists, output "NO". If it exists, output "YES" followed by the assignment $s_1, s_2, \dots, s_n$. We need to find the lexicographically smallest assignment.

This is a classic 2-coloring problem on a graph. The staff members are vertices, and the incompatibility constraints are edges. We need to color the vertices with two colors (1 and 2) such that no two adjacent vertices have the same color. If the graph is not bipartite, no such assignment exists.

The graph can have multiple connected components. For each connected component, we can determine the 2-coloring independently. However, within a connected component, once we fix the color of one vertex, the colors of all other vertices in that component are determined (assuming the component is bipartite). If we flip the colors of all vertices in a connected component (swapping 1 and 2), it remains a valid coloring.

To minimize the lexicographical value of the sequence $s_1, s_2, \dots, s_n$, we want $s_1$ to be 1 if possible, then $s_2$ to be 1 if possible given $s_1$, and so on.
Since we process staff members from 1 to $n$, for any unassigned staff member $i$, we should try to assign $s_i = 1$. If assigning $s_i = 1$ leads to a valid coloring for the component containing $i$, we do so. If assigning $s_i = 1$ forces a contradiction (i.e., the component is not bipartite), then the whole problem is unsolvable. If assigning $s_i = 1$ is valid, we must stick with it because choosing $s_i = 2$ would make the sequence lexicographically larger at index $i$. If $s_i$ was already assigned (due to a previous neighbor being processed), we check consistency.

Wait, let's refine this. We iterate $i$ from 1 to $n$.
1. If staff member $i$ is already assigned a period, we move to $i+1$.
2. If staff member $i$ is not assigned, it belongs to a connected component that hasn't been visited yet. Let this component be $C$.
3. We attempt to 2-color the component $C$ such that $i$ gets color 1.
   - We can use BFS or DFS to traverse the component.
   - Set $s_i = 1$.
   - For any neighbor $v$ of $i$, set $s_v = 2$.
   - Continue propagating. If we find an edge connecting two vertices of the same color, the graph is not bipartite, so output "NO".
   - If the coloring is successful, we have fixed the assignment for all vertices in $C$.
   - Note: Since we want the lexicographically smallest sequence, fixing $s_i=1$ is always the greedy choice. Why? Because $s_i$ is the first unassigned variable in the sequence. Any valid assignment where $s_i=2$ will be lexicographically larger than any valid assignment where $s_i=1$ (assuming $s_1, \dots, s_{i-1}$ are fixed). Since $i$ is the current index, previous assignments are fixed. If $i$ is unassigned, it means it's not connected to any $1, \dots, i-1$ (otherwise it would be assigned). Thus, the choice of color for $i$ does not affect the validity of previous choices (which are already fixed or don't exist). The only constraints are within the component. Once $s_i$ is fixed, the rest of the component is determined. If $s_i=1$ works, it's better than $s_i=2$. Is it possible that $s_i=1$ works but leads to a contradiction later? No, because 2-coloring is consistent or inconsistent based on the parity of cycles. If a component is bipartite, there are exactly two valid colorings (up to swapping colors). One has $s_i=1$, the other has $s_i=2$. So if a valid coloring exists, setting $s_i=1$ is valid and optimal for index $i$.

Algorithm:
1. Read $n, m$.
2. Build adjacency list for the graph.
3. Initialize an array `assignment` of size $n+1$ with 0 (meaning unassigned).
4. Iterate $i$ from 1 to $n$:
   - If `assignment[i]` is not 0, continue.
   - Start a traversal (BFS/DFS) from $i$.
   - Set `assignment[i] = 1`.
   - Use a queue/stack for traversal.
   - While queue is not empty:
     - Pop vertex $u$.
     - Current color $c = \text{assignment}[u]$.
     - For each neighbor $v$ of $u$:
       - If `assignment[v]` is 0:
         - `assignment[v] = 3 - c` (if $c=1 \to 2$, if $c=2 \to 1$)
         - Push $v$ to queue.
       - Else if `assignment[v] == c`:
         - Graph is not bipartite. Print "NO" and exit.
5. If the loop finishes without issues, print "YES".
6. Print the `assignment` array from index 1 to $n$.

```python
import sys
from collections import deque

def solve():
    input_data = sys.stdin.read().split()
    if not input_data:
        return

    iterator = iter(input_data)
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(iterator))
        v = int(next(iterator))
        adj[u].append(v)
        adj[v].append(u)

    assignment = [0] * (n + 1)
    
    # To handle large inputs efficiently, we might want to avoid appending to list if not needed,
    # but standard list append is amortized O(1).
    # Given constraints 2*10^5, standard lists are fine.

    for i in range(1, n + 1):
        if assignment[i] != 0:
            continue
        
        # Start BFS for component
        assignment[i] = 1
        queue = deque([i])
        
        while queue:
            u = queue.popleft()
            current_color = assignment[u]
            next_color = 3 - current_color # 1 -> 2, 2 -> 1
            
            for v in adj[u]:
                if assignment[v] == 0:
                    assignment[v] = next_color
                    queue.append(v)
                elif assignment[v] == current_color:
                    print("NO")
                    return

    print("YES")
    print(*(assignment[1:]))

if __name__ == '__main__':
    solve()
```

```python
import sys
from collections import deque

def solve():
    input_data = sys.stdin.read().split()
    if not input_data:
        return

    iterator = iter(input_data)
    n = int(next(iterator))
    m = int(next(iterator))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(iterator))
        v = int(next(iterator))
        adj[u].append(v)
        adj[v].append(u)

    assignment = [0] * (n + 1)
    
    for i in range(1, n + 1):
        if assignment[i] != 0:
            continue
        
        assignment[i] = 1
        queue = deque([i])
        
        while queue:
            u = queue.popleft()
            c = assignment[u]
            nc = 3 - c
            
            for v in adj[u]:
                if assignment[v] == 0:
                    assignment[v] = nc
                    queue.append(v)
                elif assignment[v] == c:
                    print("NO")
                    return

    print("YES")
    sys.stdout.write(" ".join(map(str, assignment[1:])) + "\n")

if __name__ == '__main__':
    solve()
```
