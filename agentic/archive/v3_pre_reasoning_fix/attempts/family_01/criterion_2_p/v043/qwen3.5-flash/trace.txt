The problem asks us to assign each of $n$ personnel to one of two shifts (Shift 1 or Shift 2) such that no two incompatible personnel are assigned to the same shift. This is a classic 2-coloring problem on a graph. The personnel are nodes, and the incompatibility conditions are edges. We need to determine if the graph is bipartite. If it is, we need to find the lexicographically smallest assignment of shifts $(s_1, s_2, \dots, s_n)$ where $s_i \in \{1, 2\}$.

First, let's consider the bipartite check. A graph is bipartite if and only if it contains no odd cycles. We can use Breadth-First Search (BFS) or Depth-First Search (DFS) to check this. We can maintain an array `color` where `color[i]` stores the shift assigned to node $i$ (1 or 2, or 0 if unvisited).

Since we want the lexicographically smallest sequence, we want $s_1$ to be 1 if possible, then $s_2$ to be 1 if possible, and so on. However, the constraints are coupled. If we assign $s_1 = 1$, then all neighbors of 1 must be 2. Their neighbors must be 1, etc.

Wait, the problem asks for the lexicographically smallest sequence $s_1, s_2, \dots, s_n$. This means we prioritize minimizing $s_1$, then $s_2$, etc.
If the graph is bipartite, the connected components are independent of each other. For each connected component, once we fix the color of one node, the colors of all other nodes in that component are determined. Specifically, if node $u$ is in component $C$, and we assign $s_u = 1$, then for any $v \in C$, $s_v$ is determined based on the parity of the distance from $u$ to $v$. If we assign $s_u = 2$, then all colors in $C$ flip ($1 \to 2, 2 \to 1$).
So, for each connected component, there are exactly two valid colorings (unless the graph is not bipartite, in which case there are none).
Let a component be $C$. Let $C_1$ be the coloring where the smallest index node $u \in C$ gets color 1. Let $C_2$ be the coloring where $u$ gets color 2 (which is the inverse of $C_1$).

Actually, it's slightly more complex because the sequence is $(s_1, s_2, \dots, s_n)$. The choice for component $C$ affects $s_i$ for all $i \in C$. from collections import deque

def solve():
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    iterator = iter(input_data)
    n = int(next(iterator))
    m = int(next(iterator))

        v -= 1

        adj[v].append(u)

            colors[i] = 1

                        return
    
    print("YES")
    print(" ".join(map(str, colors)))
