The problem asks us to assign one of two frequency bands (1 or 2) to $n$ relay devices such that for $m$ given pairs of devices, they are not assigned the same band. We need to determine if such an assignment is possible. If it is, we need to output the lexicographically smallest sequence of assignments.

This problem can be modeled as a graph coloring problem where each device is a node and each mutual interference condition is an edge between two nodes. We need to color the graph with 2 colors (bands 1 and 2) such that no two adjacent nodes have the same color. This is exactly the 2-coloring problem, or checking if a graph is bipartite. If the graph is bipartite, a valid assignment exists. If not, it's impossible.

The constraints are $n, m \le 2 \cdot 10^5$. A standard BFS or DFS approach to check bipartiteness and find a valid coloring runs in $O(n+m)$ time, which fits well within the 1 second time limit.

The problem also asks for the lexicographically smallest sequence of frequencies $s_1, s_2, \dots, s_n$.
Lexicographically smallest means we want $s_1$ to be as small as possible (ideally 1). If $s_1$ is fixed, we want $s_2$ to be as small as possible, and so on.
Since each connected component of the graph is independent of others (constraints only exist within components), we can solve the problem for each component separately.
Within a connected component, once we fix the color of one node, the colors of all other nodes in that component are determined (because it's a bipartite graph, there are exactly two valid colorings for a connected component: let's call them $C_0$ and $C_1$, where $C_1$ is the "inverse" of $C_0$).
Specifically, if node $u$ has color $c$, then all neighbors must have color $3-c$, neighbors of neighbors $c$, etc.
So for each connected component, we have two candidate color sequences. We need to choose the one that contributes to the lexicographically smallest global sequence.
Wait, "lexicographically smallest sequence" refers to the sequence $s_1, s_2, \dots, s_n$. This means we should prioritize $s_1$, then $s_2$, etc.
However, the components are disjoint sets of indices.
Let's consider the indices $i$ from 1 to $n$. If $i$ is in a component that hasn't been processed yet, we must decide the color for this component. To minimize the sequence lexicographically, when we encounter the smallest index $i$ in a new component, we should try to set $s_i = 1$. If setting $s_i = 1$ leads to a valid coloring for the component, that is preferred over $s_i = 2$. Since the component is bipartite, setting $s_i=1$ forces the rest of the component. Setting $s_i=2$ forces the rest.
Actually, it's simpler: for any connected component, there are exactly two ways to color it (unless it's a single isolated node, which is also bipartite, with two ways). Let the two colorings be $A$ and $B$. $A$ has color 1 at index $i$ and $B$ has color 2 at index $i$ (where $i$ is the smallest index in the component).
Wait, if we process nodes $1, \dots, n$ in order:
If node $i$ is already colored (visited), we do nothing.
If node $i$ is not colored, it belongs to a new component. To ensure lexicographically smallest output, we want $s_i$ to be 1 if possible. Since it's a bipartite graph, we can always color it such that $s_i=1$. We just start a traversal (BFS/DFS) from $i$, assign $s_i=1$, and propagate colors. If we find a conflict (adjacent nodes forced to be same color), then the graph is not bipartite, and we output NO.
If we successfully color the component with $s_i=1$, that is the best choice for $s_i$. Since $s_i$ appears earlier in the sequence than any other node in this component, making $s_i=1$ is always strictly better than making $s_i=2$ for the lexicographical order.
So the strategy is:
Iterate $i$ from 1 to $n$.
If $i$ is uncolored:
  Start BFS/DFS from $i$.
  Assign $color[i] = 1$.
  Propagate. If conflict found, return NO.
  If no conflict, the component is colored. Since we started with 1, this component's contribution is fixed optimally for the first element of the component.
After processing all nodes, if no conflicts, output YES and the colors.

Wait, is it always optimal to set the first node of the component to 1?
Yes. Suppose the component contains indices $u_1 < u_2 < \dots < u_k$.
We are at step $u_1$ (since we iterate 1 to $n$). $u_1$ is the first node in the sequence belonging to this component.
The choice for $u_1$ determines the choice for all other nodes in the component.
Option 1: $s_{u_1} = 1$. Then $s_{u_2}, \dots, s_{u_k}$ are fixed.
Option 2: $s_{u_1} = 2$. Then $s_{u_2}, \dots, s_{u_k}$ are fixed (inverted).
Since we want to minimize the sequence $s_1, \dots, s_n$, minimizing $s_{u_1}$ is the most important. So we must choose 1.
So the greedy strategy works: for each unvisited component, force the smallest index node in that component to be 1. If that's impossible (conflict), then output NO.

Algorithm:
1. Read $n, m$.
2. Build adjacency list.
3. Initialize `color` array of size $n+1$ with 0 (unvisited).
4. Loop `i` from 1 to $n$:
    If `color[i]` is 0:
        Perform BFS/DFS starting at `i`.
        Set `color[i] = 1`.
        Check for conflicts.
        If conflict, print "NO" and exit.
5. If loop completes, print "YES".
6. Print `color[1]` to `color[n]`.

Data structures:
- Adjacency list: `adj = [[] for _ in range(n + 1)]`
- Color array: `colors = [0] * (n + 1)`
- Queue for BFS or recursion stack for DFS. Since $N$ is up to $2 \cdot 10^5$, recursion depth might be an issue in Python (default limit 1000). Iterative BFS or DFS is safer. BFS is easy.

Complexity:
- Building graph: $O(N + M)$.
- Traversal: Each node and edge visited once. $O(N + M)$.
- Total time: $O(N + M)$.
- Space: $O(N + M)$ for graph and arrays.
This fits within limits.

Corner cases:
- $m=0$: all 1s.
- Disconnected graph: handled by loop 1 to $n$.
- Cycles: odd cycles cause NO.
- $n=1$: YES 1.

```python
import sys
from collections import deque

def solve():
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    iterator = iter(input_data)
    n = int(next(iterator))
    m = int(next(iterator))
    
    adj = [[] for _ in range(n + 1)]
    
    for _ in range(m):
        u = int(next(iterator))
        v = int(next(iterator))
        adj[u].append(v)
        adj[v].append(u)
        
    colors = [0] * (n + 1)
    
    # Iterate 1 to n to ensure lexicographically smallest
    for i in range(1, n + 1):
        if colors[i] == 0:
            # Start BFS for this component
            colors[i] = 1
            queue = deque([i])
            
            while queue:
                u = queue.popleft()
                current_color = colors[u]
                next_color = 3 - current_color # 1->2, 2->1
                
                for v in adj[u]:
                    if colors[v] == 0:
                        colors[v] = next_color
                        queue.append(v)
                    elif colors[v] == current_color:
                        # Conflict detected
                        print("NO")
                        return
                        
    print("YES")
    print(*(colors[1:]))

if __name__ == '__main__':
    solve()
```

```python
import sys
from collections import deque

# Increase recursion depth just in case, though we use BFS.
sys.setrecursionlimit(200005)

def solve():
    # Read all input from stdin
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return

    iterator = iter(input_data)
    
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    # Adjacency list
    adj = [[] for _ in range(n + 1)]
    
    for _ in range(m):
        try:
            u = int(next(iterator))
            v = int(next(iterator))
            adj[u].append(v)
            adj[v].append(u)
        except StopIteration:
            break
            
    colors = [0] * (n + 1)
    
    # Iterate through each node to handle disconnected components
    # and ensure lexicographically smallest result by starting 
    # each new component with color 1.
    for i in range(1, n + 1):
        if colors[i] == 0:
            # Start BFS for the component containing i
            colors[i] = 1
            queue = deque([i])
            
            while queue:
                u = queue.popleft()
                current_c = colors[u]
                next_c = 3 - current_c  # flips 1 to 2, 2 to 1
                
                for v in adj[u]:
                    if colors[v] == 0:
                        colors[v] = next_c
                        queue.append(v)
                    elif colors[v] == current_c:
                        # If neighbor has same color, impossible to 2-color
                        print("NO")
                        return

    # If we reach here, a valid configuration exists
    print("YES")
    # Output the configuration for nodes 1 to n
    # Using join for efficiency with large output
    print(' '.join(map(str, colors[1:])))

if __name__ == '__main__':
    solve()
```
