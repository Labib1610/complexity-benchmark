2. We need to assign each worker to one of 3 shifts (1, 2, or 3)
3. Incompatible workers cannot be on the same shift
4. We need to find if a valid assignment exists
5. If yes, output the lexicographically smallest assignment

This is essentially a 3-coloring problem on a graph where:
- Vertices are workers
- Edges represent incompatible pairs
- Colors represent shifts (1, 2, 3)

Since n ≤ 40, we need an efficient algorithm. A simple DFS/backtracking approach should work, especially if we try to find the lexicographically smallest assignment.

For lexicographically smallest, we should:
- Try shift 1 first for each worker
- If that doesn't work, try shift 2
- If that doesn't work, try shift 3

import sys

def solve():
    input_data = sys.stdin.read().split()
    idx = 0
    n = int(input_data[idx])
    m = int(input_data[idx + 1])
    idx += 2
    
    # Build adjacency list for incompatible pairs
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(input_data[idx])
        v = int(input_data[idx + 1])
        idx += 2
        adj[u].append(v)
        adj[v].append(u)
    
    # Assignment array (1-indexed, 0 means unassigned)
    assignment = [0] * (n + 1)
    
    def is_valid(worker, shift):
        """Check if assigning worker to shift is valid"""
        for neighbor in adj[worker]:
            if assignment[neighbor] == shift:
                return False
        return True
    
    def dfs(worker):
        """Try to assign shifts starting from worker"""
        if worker > n:
            return True
        
        # Try shifts 1, 2, 3 in order for lexicographically smallest
        for shift in range(1, 4):
            if is_valid(worker, shift):
                assignment[worker] = shift
                if dfs(worker + 1):
                    return True
                assignment[worker] = 0  # Backtrack
        
        return False
    
    if dfs(1):
        print("YES")
        print(" ".join(map(str, assignment[1:])))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
