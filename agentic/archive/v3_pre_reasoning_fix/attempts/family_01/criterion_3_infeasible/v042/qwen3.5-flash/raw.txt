The problem asks us to find a triangle (a set of 3 vertices where every pair is connected by an edge) in a given undirected graph with $n$ vertices and $m$ edges. We need to output the lexicographically smallest triple $(a, b, c)$ such that $a < b < c$ and $(a, b), (b, c), (a, c)$ are edges. We are guaranteed that at least one such triangle exists.

Constraints:
$n \le 2000$
$m \le 2 \cdot 10^5$
Time limit: 2 seconds.

Since we need the lexicographically smallest triple, we should iterate through possible values of $a$ starting from 1 up to $n$. For a fixed $a$, we should iterate through possible values of $b$ starting from $a+1$ up to $n$. If $a$ and $b$ are connected, we then look for a $c > b$ such that $b$ and $c$ are connected AND $a$ and $c$ are connected. The first such triple we find will be the lexicographically smallest.

Let's analyze the algorithm complexity.
We can iterate $a$ from $1$ to $n$.
Then iterate $b$ from $a+1$ to $n$.
Check if edge $(a, b)$ exists.
If it does, iterate $c$ from $b+1$ to $n$.
Check if edges $(a, c)$ and $(b, c)$ exist.
If both exist, we found the answer $(a, b, c)$ and can terminate.

The worst-case complexity of this approach is roughly $O(n^3)$ if we just use an adjacency matrix to check edges in $O(1)$. With $n=2000$, $n^3 = 8 \cdot 10^9$, which is too slow for a 2-second time limit.
However, we only iterate $c$ if $(a, b)$ is an edge. Also, we stop as soon as we find the first valid triple.
In the worst case where we have to search extensively, we need a faster way to check for the existence of $c$.

```python
import sys

# Increase recursion depth just in case, though not used here.
sys.setrecursionlimit(2000)

def solve():
    # Read all input from stdin
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return

    iterator = iter(input_data)
    
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    # Adjacency bitmasks
    adj = [0] * n
    # Adjacency lists for iteration
    adj_list = [[] for _ in range(n)]
    
    # Read edges
    for _ in range(m):
        try:
            u = int(next(iterator)) - 1
            v = int(next(iterator)) - 1
            adj[u] |= (1 << v)
            adj[v] |= (1 << u)
            adj_list[u].append(v)
            adj_list[v].append(u)
        except StopIteration:
            break
            
    # Sort adjacency lists to process neighbors in increasing order
    for i in range(n):
        adj_list[i].sort()
        
    # Iterate to find the lexicographically smallest triangle (a, b, c)
    # with a < b < c.
    # We iterate a from 0 to n-1.
    # For each a, we iterate b from neighbors of a such that b > a.
    # Since adj_list is sorted, we iterate in increasing order of b.
    # For the first valid b, we find the smallest c > b.
    
    for a in range(n):
        for b in adj_list[a]:
            if b <= a:
                continue
            
            # We have edge (a, b).
            # We need to find a neighbor c of both a and b such that c > b.
            # c must be in adj[a] and adj[b].
            # Intersection of neighbors:
            common = adj[a] & adj[b]
            
            # We need bits in common that are > b.
            # Mask out bits 0 to b.
            # (1 << (b + 1)) - 1 creates a mask with bits 0..b set to 1.
            # ~(...) inverts it, clearing bits 0..b.
            # Alternatively, use (-1) << (b + 1) which is a mask with 0s at 0..b and 1s elsewhere.
            mask = common & ~((1 << (b + 1)) - 1)
            
            if mask:
                # Find the lowest set bit in mask.
                # (mask & -mask) extracts the lowest set bit as a power of 2.
                # .bit_length() - 1 gives the index of that bit.
                c = (mask & -mask).bit_length() - 1
                
                # Found the lexicographically smallest triple
                print(f"{a + 1} {b + 1} {c + 1}")
                return
```

```python
import sys
```

```python
sys.setrecursionlimit(2000)

def solve():
    # Use fast I/O
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return

    iterator = iter(input_data)
    
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    # Adjacency bitmasks
    adj = [0] * n
    # Adjacency lists
    adj_list = [[] for _ in range(n)]
    
    # Read edges
    for _ in range(m):
        try:
            u = int(next(iterator)) - 1
            v = int(next(iterator)) - 1
            adj[u] |= (1 << v)
            adj[v] |= (1 << u)
            adj_list[u].append(v)
            adj_list[v].append(u)
        except StopIteration:
            break
            
    # Sort adjacency lists to process neighbors in increasing order
    for i in range(n):
        adj_list[i].sort()
        
    # Iterate to find the lexicographically smallest triangle (a, b, c)
    # with a < b < c.
    # We iterate a from 0 to n-1.
    for a in range(n):
        # Iterate b in neighbors of a.
        # Since adj_list is sorted, we process b in increasing order.
        for b in adj_list[a]:
            if b <= a:
                continue
            
            # We have edge (a, b).
            # We need to find a neighbor c of both a and b such that c > b.
            # Intersection of neighbors:
            common = adj[a] & adj[b]
            
            # We need bits in common that are > b.
            # Mask out bits 0 to b.
            # -(1 << (b + 1)) has bits 0..b set to 0 and others to 1.
            mask = common & -(1 << (b + 1))
            
            if mask:
                # Find the lowest set bit in mask.
                # (mask & -mask) extracts the lowest set bit as a power of 2.
                # .bit_length() - 1 gives the index of that bit.
                c = (mask & -mask).bit_length() - 1
                
                # Found the lexicographically smallest triple
                print(f"{a + 1} {b + 1} {c + 1}")
                return

if __name__ == '__main__':
    solve()
```

```python
import sys

# Increase recursion depth just in case (though not strictly needed here)
sys.setrecursionlimit(2000)

def solve():
    # Use fast I/O
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return

    iterator = iter(input_data)
    
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    # Adjacency bitmasks for O(1) edge checks and set operations
    adj = [0] * n
    # Adjacency lists to iterate over neighbors
    adj_list = [[] for _ in range(n)]
    
    # Read edges
    for _ in range(m):
        try:
            u = int(next(iterator)) - 1
            v = int(next(iterator)) - 1
            adj[u] |= (1 << v)
            adj[v] |= (1 << u)
            adj_list[u].append(v)
            adj_list[v].append(u)
        except StopIteration:
            break
            
    # Sort adjacency lists to ensure we process neighbors in increasing order.
    # This is crucial for finding the lexicographically smallest triple.
    for i in range(n):
        adj_list[i].sort()
        
    # Iterate to find the lexicographically smallest triangle (a, b, c)
    # with 1 <= a < b < c <= n.
    # We iterate a from 0 to n-1 (corresponding to 1 to n).
    for a in range(n):
        # Iterate b in neighbors of a.
        # Since adj_list is sorted, we process b in increasing order.
        # We only consider b > a to satisfy the ordering constraint.
        for b in adj_list[a]:
            if b <= a:
                continue
            
            # We have edge (a, b).
            # We need to find a neighbor c of both a and b such that c > b.
            # Intersection of neighbors of a and b:
            common = adj[a] & adj[b]

            # Mask out bits 0 to b.
            # (1 << (b + 1)) - 1 creates a mask with bits 0..b set to 1.

                c = (mask & -mask).bit_length() - 1
                
                # Found the lexicographically smallest triple (a, b, c)
                # Output 1-based indices
                print(f"{a + 1} {b + 1} {c + 1}")
```
