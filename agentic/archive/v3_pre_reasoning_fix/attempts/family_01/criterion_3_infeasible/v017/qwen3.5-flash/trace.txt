The problem asks us to find the lexicographically smallest triple of employees $(a, b, c)$ such that $a < b < c$ and each pair $(a, b)$, $(a, c)$, and $(b, c)$ has a restriction. In graph theory terms, this is finding the lexicographically smallest triangle (3-clique) in a graph where nodes represent employees and edges represent restrictions.

Input constraints:
$n \le 2000$
$m \le \min(n(n-1)/2, 2 \cdot 10^5)$
Time limit: 2 seconds
Memory limit: 256 MB

We are guaranteed that at least one triangle exists.
We need to output the smallest $a$, then smallest $b$, then smallest $c$.

Since $n$ is up to 2000, an $O(n^3)$ algorithm checking all triples is roughly $8 \cdot 10^9$ operations, which is too slow.

        # Node indices are 1-based, so we set bit v for node u, etc.
        adj_masks[u] |= (1 << v)
        adj_masks[v] |= (1 << u)
    
    # Sort edges lexicographically.
    # This ensures we check pairs (a, b) in increasing order of a, then b.
    # This is crucial for finding the lexicographically smallest triangle (a, b, c).
    edges.sort()
    
    # Iterate through edges to find the first valid triangle
    for u, v in edges:
        # We consider edge (u, v) as the first two vertices of the triangle.
        # We need to find a vertex c > v such that c is connected to both u and v.
        # We compute the intersection of neighbors of u and v.
        common_neighbors = adj_masks[u] & adj_masks[v]
        
        # We are only interested in neighbors c > v.
        # We create a mask to clear bits corresponding to nodes <= v.
        # (1 << (v + 1)) - 1 has bits 0 to v set.
        # ~mask_clear has bits 0 to v as 0, and bits > v as 1 (conceptually).
        mask_clear = (1 << (v + 1)) - 1
        potential_c_mask = common_neighbors & ~mask_clear
        
        if potential_c_mask:
            # We found at least one valid c > v.
            # To satisfy lexicographical requirement, we need the smallest such c.
            # This corresponds to the lowest set bit in potential_c_mask.
            
            # Isolate the lowest set bit
            lowest_bit = potential_c_mask & -potential_c_mask
            
            # Calculate the bit index. bit_length() returns the number of bits required to represent the integer.
            # For a power of 2, 2^k, bit_length is k+1. So index k = bit_length - 1.
            c = lowest_bit.bit_length() - 1
            
            # Print the result and exit
            print(f"{u} {v} {c}")
            return
