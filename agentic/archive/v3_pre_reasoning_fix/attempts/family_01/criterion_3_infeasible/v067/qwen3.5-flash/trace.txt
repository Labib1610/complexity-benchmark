Let me understand the problem:
1. We have n nodes and m edges in a network
2. We need to find a triangle (3 nodes that are all connected to each other)
3. We want the lexicographically smallest triangle (a, b, c) where a < b < c
4. We're guaranteed at least one triangle exists

This is the classic "triangle finding" problem in a graph.

Given the constraints:
- n ≤ 2000
- m ≤ 200000

A naive approach would be to check all triplets, which would be O(n³) - too slow for n=2000.

A better approach:
1. For each edge (u, v), check if there's a node w that connects to both u and v
2. This is O(m * n) in worst case, but with proper data structures it can be O(m * d) where d is average degree

Even better:
1. For each node u, iterate over pairs of its neighbors (v, w)
2. Check if v and w are connected
3. This is O(∑ deg(u)²) which in worst case is O(n * m)

For the lexicographically smallest triangle:
- We should iterate through nodes in order 1, 2, 3, ..., n
- For each node a, we look for the smallest b > a such that (a, b) is an edge
- Then for each such b, look for the smallest c > b such that (b, c) and (a, c) are both edges
- Return the first valid (a, b, c) we find

Let me implement this:

```python
import sys
from collections import defaultdict

def solve():
    data = sys.stdin.read().split()
    idx = 0
    n = int(data[idx]); idx += 1
    m = int(data[idx]); idx += 1
    
    # Build adjacency list and set for fast lookup
    adj = defaultdict(set)
    edges = []
    
    for _ in range(m):
        u = int(data[idx]); idx += 1
        v = int(data[idx]); idx += 1
        adj[u].add(v)
        adj[v].add(u)
        edges.append((u, v))
    
    # For lexicographically smallest, iterate a from 1 to n
    for a in range(1, n + 1):
        # For each neighbor b of a where b > a
        for b in sorted(adj[a]):
            if b <= a:
                continue
            # For each neighbor c of b where c > b
            for c in sorted(adj[b]):
                if c <= b:
                    continue
                # Check if a and c are connected
                if c in adj[a]:
                    print(f"{a} {b} {c}")
                    return

solve()
```

The algorithm systematically explores node connections, ensuring we find the smallest valid triangle by carefully iterating through potential nodes. By sorting neighbors and checking connections strategically, we can minimize computational complexity.
