The problem asks us to find the lexicographically smallest triplet $(a, b, c)$ such that $1 \le a < b < c \le n$ and there are edges (conflicting pairs) between $(a, b)$, $(b, c)$, and $(a, c)$. We are given $n$ vertices and $m$ edges, where $n \le 2000$ and $m \le 2 \cdot 10^5$. We are guaranteed that at least one such triangle exists.

This is essentially the problem of finding a triangle in a graph. Specifically, we want to find a triangle $\{a, b, c\}$ that minimizes the tuple $(a, b, c)$ lexicographically. Since we need to output $a < b < c$, we are looking for the smallest $a$, then the smallest $b$ for that $a$, then the smallest $c$ for that $a, b$.

Let's represent the graph using an adjacency matrix or adjacency lists. Given $n \le 2000$, an adjacency matrix of size $2000 \times 2000$ takes about 4MB of memory (if using booleans/integers) or 16MB if using 8-byte integers, which fits easily within 256MB. An adjacency list is also fine. Checking if an edge exists takes $O(1)$ with an adjacency matrix and $O(\text{degree})$ with an adjacency list.

Since we want the lexicographically smallest triple $(a, b, c)$ with $a < b < c$, we should iterate through possible values of $a$ from $1$ to $n$. For a fixed $a$, we should iterate through possible values of $b$ from $a+1$ to $n$. If there is an edge between $a$ and $b$, we then look for a $c$ such that $b < c \le n$ and edges $(a, c)$ and $(b, c)$ exist. To minimize $c$, we should iterate $c$ from $b+1$ to $n$. The first time we find such a triple, we can return it immediately because any subsequent triple will either have a larger $a$, or the same $a$ and larger $b$, or the same $a, b$ and larger $c$.

import sys

# Increase integer string conversion limit just in case, though not needed for this logic
sys.set_int_max_str_digits(100000)

def solve():
    # Read all input from stdin
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return

    iterator = iter(input_data)
    
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    # Adjacency bitmasks
    # adj_mask[u] has bit v set if there is an edge between u and v
    # We use 1-based indexing for bits to match node numbers
    adj_mask = [0] * (n + 1)
    
    # Adjacency lists to iterate neighbors
    adj_list = [[] for _ in range(n + 1)]
    
    for _ in range(m):
        u = int(next(iterator))
        v = int(next(iterator))
        
        # Update bitmasks
        adj_mask[u] |= (1 << v)
        adj_mask[v] |= (1 << u)
        
        # Update adjacency lists
        adj_list[u].append(v)
        adj_list[v].append(u)
        
    # Sort adjacency lists to ensure we process smaller indices first
    # This is crucial for finding the lexicographically smallest triple
    for i in range(1, n + 1):
        adj_list[i].sort()
        
    # Iterate through all possible values of a
    for a in range(1, n + 1):
        # Iterate through neighbors of a (potential b's)
        # We only consider b > a to satisfy a < b < c
        for b in adj_list[a]:
            if b <= a:
                continue
            
            # We need to find a c such that c > b, and edges (a, c) and (b, c) exist.
            # This means c must be in the intersection of neighbors of a and neighbors of b.
            # We can find common neighbors using bitwise AND of their masks.
            
            common = adj_mask[a] & adj_mask[b]
            
            # We need the smallest common neighbor c > b.
            # We can shift the common mask to the right by (b + 1) to discard bits <= b.
            # The new mask will have bit k set if original mask had bit k + b + 1 set.
            shifted = common >> (b + 1)
            
            if shifted:
                # Find the lowest set bit in shifted
                # This corresponds to the smallest c > b
                lowest_bit = shifted & -shifted
                
                # Calculate the bit index (node number)
                # bit_length() of 2^k is k + 1. So k = bit_length() - 1.
                # The bit index in 'shifted' is relative to the shift amount.
                # The actual node index is (bit_index_in_shifted) + (b + 1).
                c_idx = (lowest_bit.bit_length() - 1) + (b + 1)
                
                # We found the lexicographically smallest triple
                print(f"{a} {b} {c_idx}")
                return

if __name__ == '__main__':
    solve()
