We need to output a<b<c. Lexicographically smallest: minimal a, then b, then c. So we can iterate a from 1..n; for each a, we need to find smallest b> a such that b adjacent to a, and there exists c > b such that c adjacent to a, b, and also c > b. Among such triangles, choose the smallest c. Since we want lexicographically smallest overall, we can for each a find minimal b, then minimal c. But minimal b may not yield minimal c overall? Suppose there are two triangles with same a but different b: e.g., a=1, triangles (1,2,5) and (1,3,4). Lexicographic order: compare b: 2 vs 3. So choose b=2. So minimal b suffices to get lexicographically smallest for given a. Since a is minimal possible, we just need to check a in increasing order. For each a, find minimal b> a such that a-b edge exists and there is some c> b such that edges a-c, b-c exist. But we need to choose minimal c for that b.

import sys

def solve():
    input = sys.stdin.readline
    n,m = map(int,input().split())
    adj_bits = [0]*n
    adj_list = [[] for _ in range(n)]
    for _ in range(m):
        u,v = map(int,input().split())
        u-=1; v-=1
        adj_bits[u] |= 1<<v
        adj_bits[v] |= 1<<u
        adj_list[u].append(v)
        adj_list[v].append(u)
    for i in range(n):
        adj_list[i].sort()
    for a in range(n):
        for b in adj_list[a]:
            if b <= a: continue
            # intersection
            common = adj_bits[a] & adj_bits[b]
            mask = (~0) << (b+1)
            common_masked = common & mask
            if common_masked:
                c = (common_masked & -common_masked).bit_length() - 1
                print(a+1, b+1, c+1)
                return
