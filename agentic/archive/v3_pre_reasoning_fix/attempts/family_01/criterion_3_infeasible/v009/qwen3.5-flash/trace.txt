The problem asks us to find the lexicographically smallest triple of workers $(a, b, c)$ such that $a < b < c$ and all three pairs $(a, b)$, $(a, c)$, and $(b, c)$ represent conflicting pairs. We are given $n$ workers and $m$ conflicting pairs. We are guaranteed that such a triple exists. The constraints are $n \le 2000$ and $m \le 2 \cdot 10^5$. The time limit is 2 seconds.

This is essentially finding the lexicographically smallest triangle (clique of size 3) in a graph where edges represent conflicts. The vertices are labeled $1$ to $n$.

A naive approach would be to iterate over all possible triples $(a, b, c)$ with $1 \le a < b < c \le n$ and check if they form a triangle. This would take $O(n^3)$ time, which is too slow since $n$ can be up to 2000. $2000^3 = 8 \cdot 10^9$, which exceeds the operations limit for 2 seconds.

import sys
from bisect import bisect_right

# Set recursion limit just in case, though not used
sys.setrecursionlimit(2000)

def solve():
    # Read all input from stdin
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return

    iterator = iter(input_data)
    
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    # Adjacency matrix using bytearray for efficiency
    # 1-based indexing, so size n+1
    adj = [bytearray(n + 1) for _ in range(n + 1)]
    
    # Adjacency lists
    adj_list = [[] for _ in range(n + 1)]
    
    for _ in range(m):
        u = int(next(iterator))
        v = int(next(iterator))
        adj[u][v] = 1
        adj[v][u] = 1
        adj_list[u].append(v)
        adj_list[v].append(u)
        
    # Sort adjacency lists and remove duplicates
    for i in range(1, n + 1):
        if adj_list[i]:
            adj_list[i] = sorted(list(set(adj_list[i])))
            
    # Array to mark elements in L
    in_L = [False] * (n + 1)
    
    # Iterate through each worker a
    for a in range(1, n + 1):
        # Get neighbors of a that are greater than a
        # Since adj_list[a] is sorted, we can find the start index
        # bisect_right returns insertion point after all elements <= a
        idx_a = bisect_right(adj_list[a], a)
        L = adj_list[a][idx_a:]
        
        if not L:
            continue
        
        # Mark elements of L in in_L for fast lookup
        for x in L:
            in_L[x] = True
            
        len_L = len(L)
        
        # Iterate through b in L
        # We want to find the smallest b first
        # Since L is sorted, we iterate in order
        for i in range(len_L):
            b = L[i]
            
            # We need to find smallest c > b such that (b, c) is an edge
            # and c is in L.
            # Optimization: Iterate over the smaller set of neighbors
            
            deg_b = len(adj_list[b])
            
            if deg_b < len_L:
                # Iterate over neighbors of b
                # We need c > b and c in L
                # Find first neighbor > b
                idx_b = bisect_right(adj_list[b], b)
                
                # Iterate through the slice
                # Slicing creates a copy, but size is deg_b which is small (< len_L)
                # and len_L <= n. Copying small lists is fast.
                for c in adj_list[b][idx_b:]:
                    if in_L[c]:
                        print(f"{a} {b} {c}")
                        return
            else:
                # Iterate over neighbors in L that are > b
                # Since L is sorted, these are L[i+1:]
                # We iterate using index to avoid slicing L
                for j in range(i + 1, len_L):
                    c = L[j]
                    if adj[b][c]:
                        print(f"{a} {b} {c}")
                        return
        
        # Clean up in_L for the next iteration of a
        for x in L:
            in_L[x] = False

if __name__ == '__main__':
    solve()
