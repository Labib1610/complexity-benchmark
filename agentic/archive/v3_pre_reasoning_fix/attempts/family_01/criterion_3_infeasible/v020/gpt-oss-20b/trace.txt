Approach: iterate over a from 1..n; for each a, iterate over neighbors b > a; for each b, find common neighbors c > b that are connected to both a and b. Lexicographic minimal: we want smallest a, then b, then c. So we can break when found first triangle.

Implementation: adjacency matrix as list of bitset: use Python's builtin set or boolean list. For speed, maybe use bitarray or Python's int bitset: for each node, create integer bitmask of neighbors. Since n <= 2000, need 2000 bits, fits in Python int.
