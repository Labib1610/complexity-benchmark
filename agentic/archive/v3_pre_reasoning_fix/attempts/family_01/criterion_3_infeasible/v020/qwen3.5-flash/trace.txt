The problem asks us to find the lexicographically smallest triplet of workers $(a, b, c)$ such that $a < b < c$ and there are conflicts between $(a, b)$, $(a, c)$, and $(b, c)$. This is essentially finding the lexicographically smallest 3-clique (triangle) in a graph where nodes are workers and edges are conflicts. The graph is undirected. We are guaranteed that at least one such triangle exists. The constraints are $n \le 2000$ and $m \le 2 \cdot 10^5$.

A brute-force approach would check all triplets, which takes $O(n^3)$ time. With $n=2000$, $n^3 = 8 \cdot 10^9$, which is too slow for a 2-second time limit.
We need something faster. Since $m$ is relatively small compared to $n^2$ (max edges $\approx 2 \cdot 10^6$), maybe we can iterate over edges.

Let the adjacency list be $G$. For each edge $(u, v)$, we want to find a node $w$ such that $w$ is connected to both $u$ and $v$. If we find such a $w$, then $\{u, v, w\}$ forms a triangle. To satisfy the lexicographical requirement $a < b < c$, we need to iterate through triplets in a specific order or check candidates in that order. However, finding *any* triangle is easy, but finding the specific lexicographically smallest one requires care.

Let's consider the properties of lexicographical order. We want to minimize $a$, then $b$, then $c$.
So, the smallest possible value for $a$ is 1. If there exists a triangle containing 1, then the answer starts with 1. If not, the answer starts with 2, and so on.
For a fixed $a$, we want to minimize $b$. This means we should look for neighbors of $a$. Let $N(a)$ be the set of neighbors of $a$. We iterate $b \in N(a)$ such that $b > a$. Then we look for a common neighbor $c$ of $a$ and $b$ such that $c > b$.
If we iterate $a$ from 1 to $n$, and for each $a$, iterate $b$ in $N(a)$ with $b > a$ in increasing order, and then check for $c \in N(a) \cap N(b)$ with $c > b$, the first time we find such a $c$, we have found the lexicographically smallest triplet.

def solve():
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    iterator = iter(input_data)
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    adj = [0] * (n + 1)
    edges = []
    
    # Read edges
    for _ in range(m):
        u = int(next(iterator))
        v = int(next(iterator))
        if u > v:
            u, v = v, u
        
        # Update adjacency bitmasks
        # Since n <= 2000, 1 << v is fine
        adj[u] |= (1 << v)
        adj[v] |= (1 << u)
        
        edges.append((u, v))
    
    # Sort edges to iterate in lexicographical order of (a, b)
    edges.sort()
    
    # Iterate through edges
    for u, v in edges:
        # We are looking for c such that c > v
        # and c is connected to u and v.
        # Common neighbors are adj[u] & adj[v]
        common = adj[u] & adj[v]
        
        # We only care about bits set at positions > v
        # Shift right by v + 1
        shifted_common = common >> (v + 1)
        
        if shifted_common > 0:

            lsb = shifted_common & -shifted_common

            # index of LSB is bit_length - 1
            # The actual index in original common was shifted index + (v + 1)
            c = (lsb.bit_length() - 1) + (v + 1)
            
            print(f"{u} {v} {c}")
            return

import sys

# Increase recursion depth just in case, though not used here
sys.setrecursionlimit(2000)

def solve():
    # Read all input from stdin at once
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return

    iterator = iter(input_data)
    
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    # Adjacency list represented as bitmasks
    # adj[u] will have the v-th bit set if there is an edge between u and v
    adj = [0] * (n + 1)
    edges = []
    
    # Read edges
    # We assume the input is well-formed as per description
    for _ in range(m):
        try:
            u = int(next(iterator))
            v = int(next(iterator))
        except StopIteration:
            break
            
        # Ensure u < v for consistent sorting and logic
        if u > v:
            u, v = v, u
        
        # Set bits in adjacency bitmasks
        # Note: 1 << v sets the bit at index v.
        # Since node indices are 1-based, bit 0 is unused, which is fine.
        adj[u] |= (1 << v)
        adj[v] |= (1 << u)
        
        edges.append((u, v))
    
    # Sort edges. We want to find the lexicographically smallest triplet (a, b, c).
    # This corresponds to minimizing a, then b, then c.
    # Our loop iterates over pairs (a, b) in increasing order of a, then b.
    # For each pair, we find the smallest c > b that completes the triangle.
    # The first such triplet found will be the lexicographically smallest.
    edges.sort()
    
    for u, v in edges:
        # We need to find a neighbor c such that c > v and c is connected to u.
        # Common neighbors of u and v are given by adj[u] & adj[v].
        common = adj[u] & adj[v]
        
        # We only care about bits set at positions > v.
        # Shift right by v + 1 to discard bits <= v.
        shifted_common = common >> (v + 1)
        
        if shifted_common > 0:
            # Find the lowest set bit in shifted_common.
            # (x & -x) isolates the lowest set bit.
            lsb = shifted_common & -shifted_common
            
            # bit_length() returns the number of bits required to represent an integer.
            # For a power of 2 (2^k), bit_length is k + 1.
            # The index of the bit is bit_length - 1.
            # This index corresponds to the position relative to the shift.
            # So the original bit index is (bit_length - 1) + (v + 1).
            c = lsb.bit_length() - 1 + (v + 1)
            
            print(f"{u} {v} {c}")
            return
