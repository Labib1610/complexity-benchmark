The problem asks us to assign each of $n$ modules to either Bus 1 or Bus 2 such that for every given constraint $(u, v)$, the modules $u$ and $v$ are assigned to different buses. We need to determine if such an assignment exists. If it does, we must output "YES" followed by the assignment that is lexicographically smallest. If not, output "NO".

This is a classic 2-coloring problem on a graph. The modules are vertices, and the constraints are edges. We need to check if the graph is bipartite. If it is bipartite, we need to find a specific valid 2-coloring.

The graph is bipartite if and only if it contains no odd cycles. If it is bipartite, the connected components can be 2-colored in exactly two ways (swapping the colors).

We are asked for the lexicographically smallest assignment. The assignment is a sequence $s_1, s_2, \dots, s_n$ where $s_i \in \{1, 2\}$. We want to minimize this sequence lexicographically. This means we want $s_1$ to be 1 if possible. If $s_1$ is fixed to 1, we want $s_2$ to be 1 if possible, and so on.

Let's consider the connected components of the graph. For a connected component, if we fix the color of one vertex, the colors of all other vertices in that component are determined (since it's bipartite). For example, if we assign Bus 1 to vertex $u$, then all neighbors of $u$ must be Bus 2, their neighbors Bus 1, etc.
There are two possible valid colorings for a connected component: let's call them $C$ and $C'$. In $C'$, every vertex that has color 1 in $C$ has color 2, and vice versa.
To get the lexicographically smallest overall assignment, we need to make choices for the vertices $1, 2, \dots, n$ in order.

Let's process vertices $i$ from 1 to $n$. If vertex $i$ has already been colored in a previous step (because it belongs to a component where we colored some $j < i$), then we just keep that color. If vertex $i$ has not been colored yet, it belongs to a new connected component. We have a choice here: we can assign Bus 1 to $i$, or Bus 2 to $i$.
To minimize the sequence lexicographically, we should try to assign Bus 1 to $i$ if possible. Since $i$ is the first vertex of its component to be encountered in the loop $1 \dots n$, this is the most significant vertex in that component. If we set $s_i = 1$, the colors of the rest of the component are fixed. If we set $s_i = 2$, the colors of the rest are swapped (relative to the $s_i=1$ case). Since $1 < 2$, choosing $s_i = 1$ is always better for the lexicographical order at index $i$. There is no conflict in the choice of $s_i$ with previous choices because $i$ was uncolored. The only constraint is that a valid 2-coloring must exist for the component. If the component is not bipartite, then no assignment exists at all, output "NO".

import sys
from collections import deque

def solve():
    # Read all input from stdin
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return
    
    iterator = iter(input_data)
    
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    # Adjacency list for the graph
    # Using 1-based indexing for convenience
    adj = [[] for _ in range(n + 1)]
    
    # Read m edges
    for _ in range(m):
        u = int(next(iterator))
        v = int(next(iterator))
        adj[u].append(v)
        adj[v].append(u)
    
    # Array to store the color (bus assignment) of each module
    # 0: unassigned, 1: Bus 1, 2: Bus 2
    colors = [0] * (n + 1)
    
    # Iterate through all modules 1 to n
    for i in range(1, n + 1):
        if colors[i] == 0:
            # If module i is unassigned, it belongs to a new connected component.
            # To achieve the lexicographically smallest assignment, we assign Bus 1 to the 
            # first available module in the component (which is i, since we iterate 1..n).
            colors[i] = 1
            queue = deque([i])
            
            while queue:
                u = queue.popleft()
                current_color = colors[u]
                # The neighbor must be assigned the other bus
                next_color = 3 - current_color
                
                for v in adj[u]:
                    if colors[v] == 0:
                        colors[v] = next_color
                        queue.append(v)
                    else:
                        # If neighbor is already assigned, check for conflict
                        if colors[v] != next_color:
                            print("NO")
                            return

    # If we successfully assign all modules without conflict
    print("YES")
    # Print the assignment for modules 1 to n
    sys.stdout.write(" ".join(map(str, colors[1:])) + "\n")

if __name__ == '__main__':
    solve()
