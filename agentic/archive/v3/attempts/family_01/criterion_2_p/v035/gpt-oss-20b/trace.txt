We want to choose for each component a coloring that, when concatenated, gives lexicographically smallest overall vector. Since components are independent, we can choose orientation per component to minimize the vector.

Observation: For each connected component, we have two possible colorings: assign one partition 1 and other 2, or vice versa. The lexicographically smallest overall assignment can be found by, for each component, choosing orientation that yields smaller lexicographic order on the subvector of indices belonging to that component, since components are disjoint sets of indices. However, the order of indices across components matters because indices are sorted overall. Suppose component A has indices [1,3,5], component B [2,4]. The vector's order interleaves them. To get lexicographically smallest, we should process components in order of smallest index? Since indices are fixed. For each component, we can choose orientation that gives smaller value at the first index of component when sorted. Because earlier indices are considered first.

def solve():
    import sys
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data: return
    it = iter(data)
    n = next(it); m = next(it)
    g = [[] for _ in range(n)]
    for _ in range(m):
        u = next(it)-1; v = next(it)-1
        g[u].append(v); g[v].append(u)
    color = [-1]*n
    shift = [0]*n
    from collections import deque
    for i in range(n):
        if color[i] == -1:
            q = deque([i])
            color[i] = 0
            comp = [i]
            min_idx = i
            while q:
                v = q.popleft()
                for nb in g[v]:
                    if color[nb] == -1:
                        color[nb] = color[v]^1
                        q.append(nb)
                        comp.append(nb)
                        if nb < min_idx:
                            min_idx = nb
                    elif color[nb] == color[v]:
                        print("NO")
                        return
            # orientation
            if color[min_idx] == 0:
                # parity 0 -> shift 1, parity 1 -> shift 2
                for v in comp:
                    shift[v] = 1 if color[v]==0 else 2
            else:
                for v in comp:
                    shift[v] = 2 if color[v]==0 else 1
    print("YES")
    print(' '.join(map(str, shift)))
