Lexicographically smallest means we want as many 1's as early as possible. Equivalent to assign each component minimal labeling: choose orientation that gives smallest lexicographic for that component relative to indices.

We can think: For each connected component, we have two possible colorings (swap colors). We need to choose orientation that yields lexicographically smallest overall sequence. Since components are independent, we can process each component and decide orientation that results in smaller sequence within that component relative to index ordering. But lexicographic of entire n sequence is determined by earliest index where they differ.

Strategy: For each component, compute its bipartition sets A and B (colors 0/1). Then we need to decide whether to assign color 0 -> 1, color 1 -> 2, or swapped. We must choose such that resulting global sequence is lexicographically minimal. Since components are disjoint and indices are fixed, the decision for earlier indices dominates.

Thus we can process components in order of minimal vertex index. For each component, we consider the minimal index vertex in that component; its color (0 or 1) determines orientation. To get lexicographically smallest, we should set the color of that minimal index vertex to 1 (since we want smallest at that position). So we orient so that minimal index vertex gets chamber 1. That will guarantee lexicographically minimal overall because earlier vertices are fixed.

Proof: Suppose we have two components C1 and C2 with minimal indices i1 < i2. For component C1, orientation that sets s[i1] = 1 gives smaller lexicographic than orientation with s[i1] = 2. So we must choose that orientation. For component C2, its minimal index i2 > i1, but its orientation cannot affect earlier indices. So we choose orientation to minimize within its component, i.e., set minimal vertex to 1. That yields lexicographically minimal overall.
