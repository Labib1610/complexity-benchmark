We need bipartite graph coloring with lexicographically smallest assignment of 1/2. n up to 2e5, m up to 2e5. Graph may be disconnected. We need to assign each component a bipartition (two colors). But lexicographically smallest: we want sequence s1..sn minimal in lexicographic order over all valid assignments. That means we want as many early indices to be 1 as possible. Since colors can be swapped per component, we can choose orientation (which side gets 1) per component to minimize lexicographic order.

Essential approach: For each component, after BFS, we obtain two sets: color 0 and color 1 (relative). We need to decide whether to assign color0->1 or color1->1. For lexicographic minimality, we consider nodes sorted by index; for each component we need to decide orientation to minimize lexicographic order of the overall assignment.

Observation: Since components are independent, and lexicographic comparison goes left to right, we can process nodes 1..n in order. At each node i, if it's uncolored, we need to color its component. But orientation choice may affect future nodes. However, we can preprocess components: for each component, we have list of nodes. We can decide orientation by looking at the smallest node index in the component: if we set that node to 1, that yields lexicographically smaller assignment than setting it to 2. Because earlier nodes in component will be minimal. But what if another component has earlier node but orientation might choose 2? Wait lexicographic order compares whole sequence. Suppose component A has nodes {1,5} and component B has nodes {2,3}. For component A, smallest index 1. If we set node 1 to 1, that's minimal. For component B, smallest index 2. We can set node 2 to 1 to minimize. So basically for each component we set the smallest-index node to 1. That yields global lexicographically minimal assignment because any assignment that sets a component's smallest node to 2 would be lexicographically larger at that index.

Proof: Suppose we process components sorted by smallest node. For each component, the earliest index where it differs from another assignment is the smallest node in that component. If we set that node to 2, we get larger value at that index. So minimal is to set to 1. That yields lexicographically minimal.

- For i in 0..n-1:
    if color[i]==-1:
        # BFS
        stack=[i]
        color[i]=0
        comp_nodes=[i]
        bip=True
        while stack:
            u=stack.pop()
            for v in adj[u]:

                    comp_nodes.append(v)
                elif color[v]==color[u]:
                    bip=False; break
            if not bip: break
        if not bip: print NO, return
        # determine orientation
        min_node=min(comp_nodes)
        min_color=color[min_node]
        # assign
        for node in comp_nodes:
            if color[node]==min_color:
                result[node]=1
            else:
                result[node]=2
