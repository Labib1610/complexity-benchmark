The problem asks us to partition $n$ researchers into two groups (labeled 1 and 2) such that for $m$ given pairs $(u, v)$, researchers $u$ and $v$ are in different groups. This is a classic Bipartite Graph Coloring problem. We need to color the vertices of a graph with 2 colors such that no two adjacent vertices have the same color. If the graph is not bipartite, we output `NO`. If it is bipartite, we need to find an assignment that minimizes the sequence $(s_1, s_2, \dots, s_n)$ lexicographically.

The sequence $(s_1, s_2, \dots, s_n)$ is lexicographically smaller if $s_1$ is smaller, or if $s_1$ is the same, then $s_2$ is smaller, and so on. Since the values are $\{1, 2\}$, we want $s_1=1$ if possible. If $s_1$ must be 2, then we take it. If $s_1$ can be 1 or 2, we prefer 1. Then we want $s_2=1$ if possible given $s_1$, and so on.

The constraints are $n, m \le 2 \cdot 10^5$. The time limit is 1 second.

Let's represent the incompatibilities as edges in a graph. We need to check if the graph is bipartite. A graph is bipartite if and only if it contains no odd cycles. We can use BFS or DFS to check this and color the graph.

However, simply checking if it's bipartite isn't enough. We need the lexicographically smallest sequence.
Consider a connected component. If we fix the color of one node in the component, the colors of all other nodes in that component are determined (up to swapping the two colors).
Specifically, if node $u$ is in group 1, then all its neighbors must be in group 2, their neighbors in group 1, etc. This is a two-coloring.
If we swap the colors of all nodes in a connected component (1 becomes 2, 2 becomes 1), the constraints are still satisfied because if $u, v$ have different colors, swapping them makes them different.
So for each connected component, there are exactly two possible valid colorings. Let's call them "option A" and "option B". Option B is the inverse of Option A.

To minimize the sequence lexicographically $(s_1, s_2, \dots, s_n)$, we process nodes $i$ from 1 to $n$.
If node $i$ has not been assigned a group yet, it means it belongs to a new connected component. We need to decide which of the two options for this component to pick.
Let the component be $C$. We can arbitrarily assign node $i$ to group 1 and calculate the colors for all nodes in $C$. Let this assignment be $A$. Then the alternative assignment $B$ will have $i$ in group 2.
Since we want to minimize the sequence, we look at $s_i$. Since $i$ is the first node in this component that we encounter (because we iterate $1 \dots n$ and skip visited ones), we have a choice: assign $i$ to 1 or assign $i$ to 2.
Wait, if we assign $i$ to 1, then $s_i = 1$. If we assign $i$ to 2, then $s_i = 2$.
Since we want the lexicographically smallest sequence, and $s_i$ is the first component of the sequence that hasn't been fixed by previous choices (since previous choices only affect nodes $j < i$ which are not in this component), we should just pick the option that makes $s_i$ as small as possible.
Since $1 < 2$, we should always try to make $s_i = 1$.
So, for the first unvisited node $i$, we force it to be in group 1. Then we run BFS/DFS to color the rest of the component. If we encounter a conflict, then the graph is not bipartite, and we output `NO`.
If we successfully color the component, we record the colors.

import sys
from collections import deque

def solve():
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    
    iterator = iter(input_data)
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    adj = [[] for _ in range(n + 1)]
    
    for _ in range(m):
        u = int(next(iterator))
        v = int(next(iterator))
        adj[u].append(v)
        adj[v].append(u)
    
    colors = [0] * (n + 1)
    
    for i in range(1, n + 1):
        if colors[i] == 0:
            # Start BFS for this component
            colors[i] = 1
            queue = deque([i])
            
            while queue:
                u = queue.popleft()
                c = colors[u]
                next_c = 3 - c
                
                for v in adj[u]:
                    if colors[v] == 0:
                        colors[v] = next_c
                        queue.append(v)
                    elif colors[v] == c:
                        print("NO")
                        return
    
    print("YES")
    print(*(colors[1:]))

if __name__ == '__main__':
    solve()

import sys
from collections import deque

# Increase recursion depth just in case, though we use BFS
sys.setrecursionlimit(200005)

def solve():
    # Read all input from stdin
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return

    iterator = iter(input_data)
    
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    # Adjacency list
    adj = [[] for _ in range(n + 1)]
    
    for _ in range(m):
        try:
            u = int(next(iterator))
            v = int(next(iterator))
            adj[u].append(v)
            adj[v].append(u)
        except StopIteration:
            break
            
    # Color array: 0 = unvisited, 1 = group 1, 2 = group 2
    colors = [0] * (n + 1)
    
    # Iterate through all nodes to handle disconnected components
    for i in range(1, n + 1):
        if colors[i] == 0:
            # Start BFS for the component containing i
            # To ensure lexicographically smallest sequence, we assign group 1 to the
            # smallest index node in the component (which is i in this loop).
            colors[i] = 1
            queue = deque([i])
            
            while queue:
                u = queue.popleft()
                c = colors[u]
                next_c = 3 - c  # If c is 1, next_c is 2. If c is 2, next_c is 1.
                
                for v in adj[u]:
                    if colors[v] == 0:
                        colors[v] = next_c
                        queue.append(v)
                    elif colors[v] == c:
                        # Conflict found: adjacent nodes have same color
                        print("NO")
                        return

    # If we reach here, a valid assignment exists
    print("YES")
    # Output the colors for nodes 1 to n
    # Using join is safer for large outputs than unpacking *args
    print(' '.join(map(str, colors[1:])))
