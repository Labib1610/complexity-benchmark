We need to determine if a graph is bipartite. If yes, find lexicographically smallest assignment of colors 1 or 2. Lexicographically smallest sequence means we want minimal s_1, then s_2, etc. Since colors are 1 or 2, lexicographically smallest means we want as many 1s as possible early. But we must respect bipartiteness.

Essentially we can color each connected component; for each component we can choose to flip colors (swap 1/2) to get lexicographically smallest global sequence. Since lexicographic order depends on positions, we need to decide for each component which orientation yields smaller assignments when considering indices in order.

Goal: minimize sequence s_1..s_n lexicographically. Equivalent to: for each component, we can choose orientation; we want to choose orientation that gives minimal sequence in lexicographic order overall. This is similar to: process vertices in increasing order; when you encounter an uncolored vertex, you need to decide orientation of its component? But orientation choice may affect later vertices too.

We can think: For each component, we can compute two possible colorings: original and flipped. We need to choose for each component the one that leads to lexicographically smallest overall. Since components are disjoint, we can decide orientation independently but consider indices: The earliest vertex index in a component will determine which orientation is better if it has color 1 or 2. Because lexicographic comparison is dominated by first differing index across entire sequence.

Thus strategy: For each component, find the smallest vertex index in that component. For that vertex v, we know its color in the initial BFS (e.g., 0/1). We have two options: keep as is or flip. We choose orientation that gives smaller color at that vertex (i.e., 1 if possible). Because the earliest vertex in component will be the first differing index inside that component compared to flipping. If we make that vertex 1, it's lexicographically smaller. But if both orientations give same color at that vertex? Not possible because flipping swaps 1/2. So the vertex will have color either 1 or 2. So we choose orientation that sets that vertex to 1, if possible. But what if the vertex's color originally is 2 and flipping makes it 1? Then we choose flipped orientation. That ensures that at the minimal index of each component, s_i=1. That will guarantee lexicographically smallest overall because each component's earliest vertex is set to 1. However, if the component's earliest vertex is 1 in both orientations? Not possible. So we can always set earliest vertex to 1.

But wait: Suppose we have component where earliest vertex has color 1 originally. If we keep orientation, earliest is 1. If we flip, earliest becomes 2. So we choose keep. So yes, orientation that gives earliest vertex 1.

Thus algorithm: BFS/DFS to color graph, detect bipartite. While coloring, also record component list. After BFS, for each component, find minimal vertex index; check its color; if color==1 already, keep; else flip colors for all vertices in component.

Thus final array out[i] = 1 + (color[i] ^ flip[comp]) where flip[comp] indicates whether we flipped component.
