The problem asks us to assign each of $n$ workers to one of two zones, Zone 1 or Zone 2. We are given $m$ pairs of workers who have "friction" and cannot be in the same zone. We need to find if a valid assignment exists. If it does, we need to output "YES" and the assignment that forms the lexicographically smallest sequence $s_1, s_2, \dots, s_n$, where $s_i$ is the zone of worker $i$. If no valid assignment exists, we output "NO".

This problem can be modeled as checking if a graph is bipartite. The workers are vertices, and the friction pairs are edges. An edge between $u$ and $v$ means $u$ and $v$ must have different colors (zones). This is exactly the condition for a graph to be 2-colorable, which is equivalent to the graph being bipartite.

If the graph is bipartite, there are two possible ways to color each connected component (up to swapping the two colors). For a connected component, once we fix the color of one node, the colors of all other nodes in that component are determined. Since we want the lexicographically smallest sequence $s_1, s_2, \dots, s_n$, we need to be careful about how we choose the colors. Specifically, for each node $i$, we want $s_i$ to be as small as possible. Since $s_i \in \{1, 2\}$, we prefer 1 over 2.

```python
import sys
from collections import deque

# Set recursion limit just in case, though we use iterative BFS.
sys.setrecursionlimit(200005)

def solve():
    # Read all input at once
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return

    iterator = iter(input_data)
    
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    # Adjacency list for the graph
    adj = [[] for _ in range(n + 1)]
    
    for _ in range(m):
        try:
            u = int(next(iterator))
            v = int(next(iterator))
            adj[u].append(v)
            adj[v].append(u)
        except StopIteration:
            break
            
    # Colors array: 0 = unvisited, 1 = Zone 1, 2 = Zone 2
    colors = [0] * (n + 1)
    
    # Iterate through all nodes to handle disconnected components
    for i in range(1, n + 1):
        if colors[i] == 0:
            # Start a new component
            # To get lexicographically smallest assignment, the first node 
            # encountered (which is the smallest index in this component) 
            # should be assigned 1.
            colors[i] = 1
            queue = deque([i])
            
            while queue:
                u = queue.popleft()
                c = colors[u]
                # The other zone must be 3 - c (since 3-1=2, 3-2=1)
                next_c = 3 - c
                
                for v in adj[u]:
                    if colors[v] == 0:
                        colors[v] = next_c
                        queue.append(v)
                    elif colors[v] == c:
                        # Conflict found: u and v are adjacent but have same color
                        print("NO")
                        return

    # If no conflicts found
    print("YES")
    # Output the colors for 1 to n
    # Using sys.stdout.write for potentially faster output
    sys.stdout.write(" ".join(map(str, colors[1:])))
    sys.stdout.write("\n")

if __name__ == '__main__':
    solve()
```

```python
import sys
from collections import deque

# Increase recursion depth just in case, though we use iterative approach.
sys.setrecursionlimit(200005)

def solve():
    # Read all input from standard input
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return
        
    iterator = iter(input_data)
    
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    # Build adjacency list
    # Using 1-based indexing for convenience
    adj = [[] for _ in range(n + 1)]
    
    for _ in range(m):
        u = int(next(iterator))
        v = int(next(iterator))
        adj[u].append(v)
        adj[v].append(u)
        
    # Array to store zone assignments: 0 = unvisited, 1 = Zone 1, 2 = Zone 2
    colors = [0] * (n + 1)
    
    # Iterate through each worker to handle disconnected components
    for i in range(1, n + 1):
        if colors[i] == 0:
            # Found a new component.
            # To achieve the lexicographically smallest sequence, we assign 
            # the smallest index node in the component to Zone 1.
            # Since we iterate i from 1 to n, 'i' is the smallest index 
            # in this component that hasn't been visited yet.
            colors[i] = 1
            
            queue = deque([i])
            
            while queue:
                u = queue.popleft()
                current_color = colors[u]
                next_color = 3 - current_color  # 3-1=2, 3-2=1
                
                for v in adj[u]:
                    if colors[v] == 0:
                        colors[v] = next_color
                        queue.append(v)
                    elif colors[v] == current_color:
                        # Bipartite check failed
                        print("NO")
                        return

    # If we successfully colored all components
    print("YES")
    # Output the assignment for workers 1 to n
    sys.stdout.write(" ".join(map(str, colors[1:])) + "\n")

if __name__ == '__main__':
    solve()
```
