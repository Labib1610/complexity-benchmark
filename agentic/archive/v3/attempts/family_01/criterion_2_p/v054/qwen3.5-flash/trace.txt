The problem asks us to assign each of $n$ personnel to one of two slots (Slot 1 or Slot 2) such that no two conflicting personnel are assigned to the same slot. We are given $m$ pairs of conflicts. This is a classic 2-coloring problem on a graph where nodes are personnel and edges represent conflicts. If the graph is not bipartite, no solution exists. If it is bipartite, we need to find a valid 2-coloring that is lexicographically smallest. The output should be the slots assigned to each person from 1 to $n$.

Let's represent the personnel as vertices in a graph $G = (V, E)$ where $V = \{1, \dots, n\}$ and $E$ contains the conflict pairs. We want to assign a color $c_i \in \{1, 2\}$ to each vertex $i$ such that for every edge $(u, v) \in E$, $c_u \neq c_v$.

The lexicographical requirement means we want $c_1$ to be as small as possible, then $c_2$ as small as possible given $c_1$, and so on. Since the domain is $\{1, 2\}$, this means we prefer $c_i = 1$ over $c_i = 2$ whenever possible. Specifically, we compare sequences $s = (s_1, \dots, s_n)$ and $t = (t_1, \dots, t_n)$ by finding the first index $k$ where $s_k \neq t_k$ and choosing the one with the smaller value. Since the values are 1 and 2, we prefer 1.

This is a bipartite checking problem. We can use Breadth-First Search (BFS) or Depth-First Search (DFS) to check bipartiteness and assign colors. However, the standard coloring algorithm simply visits connected components and picks a color for the starting node arbitrarily (usually 1). This does not guarantee the lexicographically smallest result for the entire sequence $s_1, \dots, s_n$.

Consider the components. For a connected component, once the color of one node is fixed, the colors of all other nodes in that component are determined (since there are only 2 colors). There are exactly two possible valid colorings for a connected component: coloring $C$ and its complement $\bar{C}$ (where every color is flipped, $1 \leftrightarrow 2$).
To minimize the sequence lexicographically, we need to decide for each component whether to use coloring $C$ or $\bar{C}$.
