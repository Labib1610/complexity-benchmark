Thus algorithm:

- Read n,m
- adjacency_bit = [0]*(n+1)
- For each edge u,v:
    adjacency_bit[u] |= 1 << (v-1)
    adjacency_bit[v] |= 1 << (u-1)

- For a in range(1, n+1):
    for b in range(a+1, n+1):
        if (adjacency_bit[a] >> (b-1)) & 1:  # edge a-b exists
            common = adjacency_bit[a] & adjacency_bit[b]
            # we need c > b
            tmp = common >> b  # shift by b positions
            if tmp:
                low = tmp & -tmp
                pos = low.bit_length() - 1
                c = pos + b + 1
                print(a,b,c)
                return
