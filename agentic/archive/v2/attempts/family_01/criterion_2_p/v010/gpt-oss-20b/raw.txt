**Solution Explanation**

For every vertex `i` we have to choose a colour  
`c[i] ∈ {1 , 2}`

```
c[u] = 1  <=>  c[v] = 2      for every edge (u , v)
```

The graph is a simple undirected graph, `n ≤ 2·10^5`, `m ≤ 2·10^5`.

For the whole graph we have to

* check if such a colouring exists – the graph must be bipartite,
* output the lexicographically smallest colouring that satisfies the rule.



--------------------------------------------------------------------

#### 1.  Observations

* In a bipartite graph every connected component has exactly two
  *sides* – we can give colour **1** to all vertices of one side,
  colour **2** to the other side.
* In one connected component the vertex with the smallest number
  `x` decides the first position where the final colour sequence can
  differ from another valid colouring of this component.
  The lexicographically smallest sequence must give `x` colour **1**.
* Because all vertices of a component are larger than the smallest
  vertex of the next component, the choice of colours in one component
  never influences the order inside another component.



--------------------------------------------------------------------

#### 2.  Algorithm
```
colour[v]   = -1   (not visited)
side[v]     = -1   (0 or 1 – the two sides of a component)
answer[v]   = 0

for every vertex s = 1 .. n
    if colour[s] == -1
        // start a new component
        side[s] = 0
        queue   = [s]
        component_vertices = [s]
        min_vertex = s
        while queue not empty
            u = pop front of queue
            for every neighbour v of u
                if side[v] == -1
                    side[v] = 1 - side[u]          // opposite side
                    push v into queue
                    add v to component_vertices
                    if v < min_vertex : min_vertex = v
                else
                    if side[v] == side[u]          // odd cycle
                        output "NO" and terminate

        // after the whole component is processed
        // give colour 1 to the smallest vertex of the component
        if side[min_vertex] == 0
            for every vertex x in component_vertices
                answer[x] = side[x] + 1      // 0 -> 1 , 1 -> 2
        else
            for every vertex x in component_vertices
                answer[x] = 2 - side[x]      // swap the colours

output "YES"
output answer[1] … answer[n]
```

--------------------------------------------------------------------

#### 3.  Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest
valid colouring if it exists, otherwise it outputs **NO**.

---

##### Lemma 1  
During the breadth‑first search of a component the algorithm
detects a conflict (odd cycle) exactly when the component is not
bipartite.

**Proof.**

*If the component is not bipartite.*  
An odd cycle exists.  
During the BFS the two endpoints of one edge of this cycle belong to
the same side.  
The algorithm checks all edges and finds `side[u] == side[v]`,
therefore it outputs **NO**.

*If the component is bipartite.*  
No edge connects vertices of the same side.
The algorithm never finds `side[u] == side[v]`, thus it never
terminates with **NO**. ∎



##### Lemma 2  
After finishing the BFS of one component, let `x` be its smallest
vertex number.
If `side[x] = 0` the colouring  
`c[v] = side[v] + 1` (0→1, 1→2) is a valid bipartite colouring.
If `side[x] = 1` the colouring  
`c[v] = 2 - side[v]` (1→1, 0→2) is also a valid bipartite colouring.

**Proof.**

For a bipartite component all edges connect vertices of different
`side`.  
Colouring `side 0` with 1 and `side 1` with 2 obviously respects the
edge rule.  
If we exchange the two colours, vertices with `side 0` get 2 and
those with `side 1` get 1 – again all edges connect different
colours. ∎



##### Lemma 3  
For a fixed component the colouring that gives colour 1 to its
smallest vertex is lexicographically smallest among all valid
colourings of this component.

**Proof.**

Let `x` be the smallest vertex of the component.  
All other vertices of the component have larger numbers.
The colour sequence of this component starts with `c[x]`.  
If `c[x] = 1` the sequence is smaller than any other colouring,
because the alternative would start with 2.
Hence assigning colour 1 to the smallest vertex gives the
lexicographically smallest possible sequence for this component. ∎



##### Lemma 4  
The algorithm assigns, for every component, the lexicographically
smallest possible colouring.

**Proof.**

During BFS the algorithm keeps the smallest vertex `x` of the
component and its side `side[x]`.

* If `side[x] = 0` it assigns colour 1 to this side  
  (formula `c[v] = side[v] + 1`).  
  So `c[x] = 1`.

* If `side[x] = 1` it assigns colour 1 to the other side  
  (formula `c[v] = 2 - side[v]`).  
  Again `c[x] = 1`.

Thus the algorithm always chooses the orientation that gives
colour 1 to the smallest vertex – by Lemma&nbsp;3 this orientation
is lexicographically minimal for the component. ∎



##### Lemma 5  
The colouring output by the algorithm is lexicographically smallest
among **all** valid colourings of the whole graph.

**Proof.**

Vertices are processed in increasing order `1 … n`.  
Let components be `K1 , K2 , … , Kt` in the order of appearance in
the input processing loop.
All vertices of `Kj` are larger than every vertex of `Kj+1`.

The final colour sequence is the concatenation of the colour
sequences of the components in that order.
Because the algorithm uses the lexicographically smallest sequence
for every component (Lemma&nbsp;4), the whole sequence is the
lexicographically smallest among all global valid colourings. ∎



##### Theorem  
If the input graph admits a colouring that satisfies the edge rule,
the algorithm outputs **YES** followed by the lexicographically
smallest such colouring.
Otherwise it outputs **NO**.

**Proof.**

*If the graph is not bipartite.*  
Some component is not bipartite.
By Lemma&nbsp;1 the BFS of that component detects the conflict and
the algorithm outputs **NO**.

*If the graph is bipartite.*  
All components are bipartite, so the BFS of each component
finishes without conflict (Lemma&nbsp;1).  
For every component the algorithm applies Lemma&nbsp;4 and therefore
produces a valid colouring.  
By Lemma&nbsp;5 the whole colouring is lexicographically smallest.
The algorithm outputs **YES** and the colouring. ∎



--------------------------------------------------------------------

#### 4.  Complexity Analysis

*Breadth‑first search*

* every vertex is visited once,
* every edge is examined once.

```
Time   :  O(n + m)
Memory :  O(n + m)     (adjacency lists + arrays)
```

Both limits are well inside the required constraints.



--------------------------------------------------------------------

#### 5.  Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    n = next(it)
    m = next(it)

    graph = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = next(it)
        v = next(it)
        graph[u].append(v)
        graph[v].append(u)

    side = [-1] * (n + 1)       # 0 or 1
    ans = [0] * (n + 1)

    for s in range(1, n + 1):
        if side[s] != -1:
            continue

        # new component
        side[s] = 0
        q = deque([s])
        comp = [s]
        min_v = s

        while q:
            u = q.popleft()
            for v in graph[u]:
                if side[v] == -1:
                    side[v] = 1 - side[u]
                    q.append(v)
                    comp.append(v)
                    if v < min_v:
                        min_v = v
                else:
                    if side[v] == side[u]:
                        sys.stdout.write("NO\n")
                        return

        # colouring that gives colour 1 to the smallest vertex
        if side[min_v] == 0:
            for x in comp:
                ans[x] = side[x] + 1      # 0->1 , 1->2
        else:
            for x in comp:
                ans[x] = 2 - side[x]      # 1->1 , 0->2

    out_lines = ["YES"] + [str(ans[i]) for i in range(1, n + 1)]
    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and satisfies all required constraints.
