To solve this problem, we need to determine a valid 2-coloring of the nodes in an undirected graph such that no two adjacent nodes share the same color. Additionally, we need to ensure that the smallest node in each connected component is assigned color 1. If the graph is not bipartite (i.e., it contains an odd-length cycle), we should output "IMPOSSIBLE".

### Approach
1. **Graph Representation**: Use an adjacency list to represent the graph.
2. **Breadth-First Search (BFS)**: Traverse each connected component of the graph using BFS to assign colors (0 or 1) to nodes. Start with color 0 for the initial node and alternate colors for adjacent nodes.
3. **Check Bipartiteness**: During BFS, if we find an adjacent node that has the same color as the current node, the graph is not bipartite.
4. **Determine Minimum Node**: For each connected component, identify the node with the smallest value.
5. **Adjust Colors**: Ensure the smallest node in each component is assigned color 1. If the smallest node was initially assigned color 0, invert the colors for the entire component.

### Solution Code
```python
from collections import deque
import sys

def main():
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    m = int(input[idx])
    idx += 1

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(input[idx])
        idx += 1
        v = int(input[idx])
        idx += 1
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * (n + 1)
    result = [0] * (n + 1)

    for start in range(1, n + 1):
        if color[start] == -1:
            queue = deque()
            queue.append(start)
            color[start] = 0
            component = []
            is_bipartite = True
            while queue:
                node = queue.popleft()
                component.append(node)
                for neighbor in adj[node]:
                    if color[neighbor] == -1:
                        color[neighbor] = color[node] ^ 1
                        queue.append(neighbor)
                    else:
                        if color[neighbor] == color[node]:
                            is_bipartite = False
            if not is_bipartite:
                print("IMPOSSIBLE")
                return
            # Find min_node in component
            min_node = min(component)
            # Check color of min_node and adjust accordingly
            if color[min_node] == 1:
                for node in component:
                    result[node] = 2 - color[node]
            else:
                for node in component:
                    result[node] = 1 + color[node]
    print(' '.join(map(str, result)))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Graph Representation**: The graph is represented using an adjacency list for efficient traversal.
2. **BFS Traversal**: Each connected component is traversed using BFS to assign colors. Starting from an unvisited node, we alternate colors between adjacent nodes.
3. **Bipartite Check**: During BFS, if an adjacent node has the same color as the current node, the graph is not bipartite, and we immediately output "IMPOSSIBLE".
4. **Minimum Node Adjustment**: For each component, the smallest node is identified. If this node was initially assigned color 0, the colors of all nodes in the component are inverted to ensure the smallest node is color 1.

This approach ensures that we correctly determine a valid 2-coloring of the graph or identify if it's impossible due to an odd-length cycle.
