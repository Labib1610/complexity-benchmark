**Solution Explanation**

For every vertex `v` we store

* `adj_mask[v]` – a bit mask, the *k*-th bit (`0`‑based) is `1`
  iff vertex `k+1` is a neighbour of `v`;
* `neigh[v]` – a sorted list of the neighbours of `v`.

For a vertex pair `(a , b)` a vertex `c` belongs to a triangle  
`a – b – c` **iff**

```
c is a neighbour of a   AND   c is a neighbour of b   AND   c > b
```

All neighbours of `a` are already stored in `adj_mask[a]`,
all neighbours of `b` are stored in `adj_mask[b]`.  
The set of vertices that are neighbours of **both** `a` and `b` is

```
common = adj_mask[a] & adj_mask[b]
```

We need only those common vertices that are larger than `b`.
Bits with index `< b` correspond to vertices `≤ b`, they must be
cleared:

```
mask = common & (~((1 << b) - 1))
```

If `mask` is zero – no common neighbour larger than `b` exists,
otherwise the lowest set bit of `mask` gives the smallest such `c`.

```
sub   = mask >> b          # shift, so that vertex b+1 becomes bit 0
low   = sub & -sub         # lowest set bit of sub
pos   = low.bit_length() - 1    # position of that bit
c     = b + pos + 1           # vertex number of the triangle
```

We iterate all vertices `a` in increasing order.
For each `a` we iterate over all neighbours `b` that are larger than
`a` – this guarantees that the pair `(a , b)` is examined in the
lexicographic order.  
For the current pair `(a , b)` we look for the smallest `c` as
described above.  
The first triangle that is found in this order is exactly the
lexicographically smallest triangle of the whole graph.

The number of examined pairs is the number of edges `m`  
(≤ 200 000).  
All operations inside the loops are constant‑time bit operations,
therefore the program is easily fast enough.

#### Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest
triangle of the input graph.

---

##### Lemma 1  
For fixed vertices `a` and `b` (`a < b`) the algorithm finds the
smallest vertex `c` (`c > b`) such that  
`a – b – c` is a triangle.

**Proof.**

* `c` must be a neighbour of `a`, therefore it appears in
  `adj_mask[a]` and also in `adj_mask[b]` (otherwise the edge `ac`
  does not exist).
* The algorithm computes `mask = adj_mask[a] & adj_mask[b]`
  – exactly the bit positions of all common neighbours of `a` and
  `b`.  
  After masking out all bits `< b`, only vertices `> b` remain.
* `sub = mask >> b` re‑indexes the remaining bits so that
  vertex `b+1` corresponds to bit `0`.  
  The lowest set bit of `sub` is therefore the vertex with the
  smallest index larger than `b`.  
  The algorithm recovers this vertex as `c`.

Hence the produced `c` is the smallest possible for the fixed pair
`(a , b)`. ∎



##### Lemma 2  
The algorithm examines all vertex pairs `(a , b)` with `a < b`
exactly once and in increasing lexicographic order
(`a` increasing, for each `a` the neighbours `b` are processed
in increasing order).

**Proof.**

`neigh[a]` is sorted increasingly.
During the outer loop `a` runs from `1` to `n`.  
Inside we iterate over all `b` in `neigh[a]` that satisfy `b > a`.
Thus each unordered edge `{a , b}` is considered once, when the
smaller vertex is the outer loop variable `a`.  
Because `b` runs in the order of the sorted neighbour list,
for a fixed `a` the values of `b` appear increasingly.
Consequently the overall order of examined pairs is lexicographic. ∎



##### Lemma 3  
Let `(a₀ , b₀ , c₀)` be the first triangle found by the algorithm.
Then for any triangle `(a , b , c)` of the graph  
`(a , b , c) ≽ (a₀ , b₀ , c₀)` in lexicographic order.

**Proof.**

Suppose the contrary: there exists a triangle
`(a , b , c)` that is lexicographically smaller than
`(a₀ , b₀ , c₀)`.

* By Lemma&nbsp;2, the pair `(a , b)` would be examined
  **before** the pair `(a₀ , b₀)`, because pairs are processed in
  lexicographic order.
* By Lemma&nbsp;1, for the pair `(a , b)` the algorithm would
  find the smallest possible third vertex.
  Thus the triangle `(a , b , c)` would be discovered during the
  processing of `(a , b)`.
* Consequently the algorithm would terminate earlier with
  `(a , b , c)`, contradicting the assumption that the first
  output is `(a₀ , b₀ , c₀)`.

Hence no lexicographically smaller triangle exists. ∎



##### Theorem  
The algorithm outputs the lexicographically smallest triangle of
the input graph.

**Proof.**

The algorithm terminates at the first triangle it finds.
Let the output be `(a₀ , b₀ , c₀)`.  
By Lemma&nbsp;3 no triangle smaller than this exists.
Therefore `(a₀ , b₀ , c₀)` is exactly the lexicographically smallest
triangle. ∎

#### Complexity Analysis

Let `deg(v)` be the degree of vertex `v`.

*Building masks and adjacency lists*  
`O(n + m)` time and `O(n + m)` memory.

*Main loops*  
Each edge `{a , b}` is examined once.  
All operations inside the loop are constant‑time bit operations.  
Hence total running time `O(m)`  
(≤ 200 000 operations), memory `O(n)` (the masks) plus the
adjacency lists `O(n + m)`.

Both time and memory easily satisfy the limits.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj_mask = [0] * (n + 1)
    neigh = [[] for _ in range(n + 1)]

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        bit_u = 1 << (u - 1)
        bit_v = 1 << (v - 1)
        adj_mask[u] |= bit_v
        adj_mask[v] |= bit_u
        neigh[u].append(v)
        neigh[v].append(u)

    for lst in neigh:
        lst.sort()

    # helper mask with all 1..n bits set
    all_ones = (1 << n) - 1

    for a in range(1, n + 1):
        mask_a = adj_mask[a]
        for b in neigh[a]:
            if b <= a:
                continue
            # common neighbours of a and b that are > b
            mask = mask_a & adj_mask[b] & (~((1 << b) - 1))
            if mask:
                sub = mask >> b          # shift so that node b+1 becomes bit 0
                low = sub & -sub         # lowest set bit
                pos = low.bit_length() - 1
                c = b + pos + 1
                print(a, b, c)
                return

if __name__ == "__main__":
    solve()
```
