**Solution Explanation**

For every vertex `v` let

* `adj_bit[v]` – a 2000‑bit integer,  
  bit *i* (0‑based) is set iff `v` is connected with vertex `i+1`.
* `adj_list[v]` – the list of all neighbours of `v`, sorted increasingly.

For a triangle `a < b < c`

```
a and b are connected   →   bit b is set in adj_bit[a]
a and c are connected   →   bit c is set in adj_bit[a]
b and c are connected   →   bit c is set in adj_bit[b]
```

So

```
c is a common neighbour of a and b
```

--------------------------------------------------------------------

#### 1.  Searching the smallest triangle

We scan the vertices in increasing order – first `a = 1`, then `a = 2`, …

For the current `a` we look only at neighbours `b` with `b > a`
(the pair `(a , b)` is examined only once, `a < b`).

For such a pair `a , b`

```
common = adj_bit[a] & adj_bit[b]     (common neighbours of a and b)
```

If `common` contains a vertex `c` with `c > b`,
`a , b , c` is a triangle.
The first one that appears while scanning `a` in this order
is the lexicographically smallest one, because

* the outer loop gives the smallest possible `a`;
* inside the loop we visit `b` increasingly – the first `b`
  that produces a `c` is the smallest possible `b`;
* for this `b` the bit operations give the smallest possible `c`.

The first found triangle is printed.

--------------------------------------------------------------------

#### 2.  Obtaining the smallest `c`

`common` is a 2000‑bit integer.
Only the bits larger than `b` are useful.
Let

```
shifted = common >> b
```

`shifted` now has

```
bit 0  ⇔  c = b + 1
bit 1  ⇔  c = b + 2
...
```

The least significant set bit of `shifted` is the smallest possible `c`.

```
pos = (shifted & -shifted).bit_length() - 1   # position of the first 1 bit
c   = b + pos + 1
```

--------------------------------------------------------------------

#### 3.  Correctness Proof  

We prove that the algorithm prints exactly the lexicographically smallest
triangle.

---

##### Lemma 1  
During the search the algorithm never skips a triangle
with the current vertex `a`.

**Proof.**

For a fixed `a` all neighbours `b` with `b > a` are iterated.
For each such `b` the algorithm checks every common neighbour `c`
(i.e. `c` such that `adj_bit[a] & adj_bit[b]` contains the bit `c`).
If `c > b` the algorithm prints the triangle immediately.
Thus no triangle with the current `a` is missed. ∎



##### Lemma 2  
For a fixed `a` the algorithm prints the triangle with the smallest
possible `b` and the smallest possible `c` among all triangles containing
this `a`.

**Proof.**

The neighbours of `a` are processed in increasing order.
Let `b₀` be the first neighbour for which a common neighbour `c > b₀`
exists.  
The algorithm stops at this `b₀` – any smaller `b` would have produced no
triangle (otherwise the algorithm would have stopped earlier).
For this `b₀` the bit operations choose the smallest possible `c`
(the least significant set bit after shifting).
Hence the printed triangle is the minimal one for this `a`. ∎



##### Lemma 3  
Let `T` be the triangle printed by the algorithm
(`T = a , b , c`).
For every other triangle `T'` we have  
`a' > a` or (`a' = a` and `b' > b`) or (`a' = a`, `b' = b` and `c' > c`).

**Proof.**

The algorithm scans `a` increasingly.
If there existed a triangle with a smaller first vertex than `a`,
the algorithm would have stopped earlier – contradiction.
If the first vertex equals `a` and the second vertex were smaller than `b`,
Lemma&nbsp;2 would have made the algorithm stop earlier.
If `a` and `b` equal the algorithm’s values but a smaller `c`
 existed, Lemma&nbsp;2 would again stop earlier.
Thus no triangle with lexicographically smaller triple exists. ∎



##### Theorem  
The algorithm outputs exactly the lexicographically smallest
triangle of the graph.

**Proof.**

*Existence:*  
If the graph contains at least one triangle, by Lemma&nbsp;1 the algorithm
will find a triangle for some `a`.  
*Minimality:*  
Let the algorithm output triangle `T`.  
By Lemma&nbsp;3 no triangle is lexicographically smaller than `T`.  
Hence `T` is the lexicographically smallest triangle. ∎



--------------------------------------------------------------------

#### 4.  Complexity Analysis

*Precomputation*

* building the bitsets and lists – `O(m)` time, `O(n + m)` memory
  (`n ≤ 2000`, `m` – number of edges).

*Search*

Each unordered edge `(a , b)` with `a < b` is examined once.
For every such pair we perform a constant number of bit operations
(`&`, `>>`, finding the first set bit).

```
Time   :  O(m)
Memory :  O(n + m)   (adjacency lists + bitsets)
```

With `n ≤ 2000` the bitsets are only 2000 bits (≈ 250 bytes),
so the program easily fits into memory limits.

#### 5.  Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    n = next(it)
    m = next(it)

    # 1‑based vertices
    adj_bit = [0] * (n + 1)           # bitsets
    adj_list = [[] for _ in range(n + 1)]  # neighbour lists

    for _ in range(m):
        u = next(it)
        v = next(it)
        if u == v:
            continue            # ignore self loops, if any
        # set bits (vertices are 1‑based)
        adj_bit[u] |= 1 << (v - 1)
        adj_bit[v] |= 1 << (u - 1)
        adj_list[u].append(v)
        adj_list[v].append(u)

    # sort neighbour lists
    for lst in adj_list:
        lst.sort()

    # search the smallest triangle
    for a in range(1, n + 1):
        bit_a = adj_bit[a]
        for b in adj_list[a]:
            if b <= a:
                continue          # only a < b
            # common neighbours of a and b
            common = bit_a & adj_bit[b]
            if common == 0:
                continue
            # we need a neighbour > b
            shifted = common >> b
            if shifted == 0:
                continue
            # least significant set bit of shifted
            # pos = index of that bit
            pos = (shifted & -shifted).bit_length() - 1
            c = b + pos + 1
            # output the triangle
            sys.stdout.write(f"{a} {b} {c}\n")
            return

if __name__ == "__main__":
    solve()
```
