To solve this problem, we need to find the lexicographically smallest triangle (three nodes forming a cycle) in an undirected graph. The approach involves checking each node's neighbors to determine if they form a triangle with the node itself.

### Approach
1. **Graph Representation**: Use an adjacency list to represent the graph, where each node points to a set of its neighbors for efficient lookups.
2. **Sorted Neighbors**: For each node, sort its neighbors to ensure we check potential triangles in lexicographical order.
3. **Triangle Check**: For each node, iterate through all pairs of its sorted neighbors. If both neighbors are connected to each other, a triangle is found. The triangle is then sorted to ensure the result is lexicographically smallest.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    m = int(input[idx])
    idx += 1
    
    # Initialize adjacency list with sets
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u = int(input[idx])
        idx += 1
        v = int(input[idx])
        idx += 1
        adj[u].add(v)
        adj[v].add(u)
    
    # Check each node's neighbors for a triangle
    for u in range(1, n + 1):
        sorted_neighbors = sorted(adj[u])
        len_neighbors = len(sorted_neighbors)
        for i in range(len_neighbors):
            for j in range(i + 1, len_neighbors):
                v = sorted_neighbors[i]
                w = sorted_neighbors[j]
                if w in adj[v]:
                    # Found a triangle, output sorted
                    res = sorted([u, v, w])
                    print(f"{res[0]} {res[1]} {res[2]}")
                    return

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of nodes (n) and edges (m). The adjacency list is populated using sets for efficient membership checks.
2. **Sorting Neighbors**: For each node, its neighbors are sorted to ensure we check pairs in lexicographical order.
3. **Checking for Triangles**: For each node, all pairs of its sorted neighbors are checked. If both neighbors are connected to each other, a triangle is found. The result is sorted to ensure the smallest lexicographical order and printed immediately.

This approach ensures that we find the smallest lexicographical triangle efficiently by leveraging sorted neighbor checks and early termination upon finding the first valid triangle.
