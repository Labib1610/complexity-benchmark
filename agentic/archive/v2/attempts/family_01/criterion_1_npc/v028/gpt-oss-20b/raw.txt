**Solution Explanation**

For every vertex we have to choose a colour `1 , 2 or 3`

```
two adjacent vertices are not allowed to have the same colour
```

The graph is simple (no loops, no parallel edges) and can be
undirected.  
We have to find **one** colouring that satisfies the rule, otherwise we
have to say that it is impossible.



--------------------------------------------------------------------

#### 1.  Observations

* When a vertex is coloured, only its neighbours lose one possible
  colour – the colour that the vertex itself uses.
* If an uncoloured vertex already has all three colours used by its
  neighbours, then it can never be coloured later – no colour is
  available for it.  
  In this situation the whole branch of the search can be discarded.
* For vertices that are not neighbours of the currently coloured
  vertex nothing changes, therefore we only have to look at the
  (uncoloured) neighbours of the just coloured vertex.

These two facts allow a very small forward‑checking test after every
colour assignment.



--------------------------------------------------------------------

#### 2.  Data structures

* `adj[u]` – adjacency bitmask of vertex `u`
  (`bit v` is set ⇔ there is an edge `u – v`)
* `colour[u]` – current colour of vertex `u` (`0` = not coloured)
* `mask_col[c]` – bitmask of all vertices that already use colour `c`
  (`c = 0,1,2` corresponds to colours `1,2,3`)

With the bitmasks all operations are `O(1)`.



--------------------------------------------------------------------

#### 3.  Forward checking

After we give a vertex `v` the colour `c`

```
for every uncoloured neighbour u of v
        used = 0
        if mask_col[0] & adj[u]   used |= 1
        if mask_col[1] & adj[u]   used |= 2
        if mask_col[2] & adj[u]   used |= 4
        if used == 7      # all three colours are already used
                return False        # impossible to colour u later
```

Only neighbours of `v` have to be checked – their neighbourhood
has changed, all other vertices are untouched.



--------------------------------------------------------------------

#### 4.  Backtracking

```
DFS(idx)   # idx = number of already coloured vertices
    if idx == N:          # all vertices coloured
            return True
    v = idx
    try colours 1, 2, 3 in this order
        if v has a neighbour with the same colour
                continue
        colour[v] = that colour
        update mask_col[that colour]
        if forward_check(v) and DFS(idx+1):
                return True
        undo the colour and the mask          # backtrack
    return False
```

The depth of the recursion is at most `N (≤ 40)`,  
the work inside one level is only proportional to the degree of the
current vertex – well below the limits.



--------------------------------------------------------------------

#### 5.  Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
During the execution of `DFS(idx)` the data structures
`colour[ ]` and `mask_col[ ]` are always consistent:
for every vertex `u`

```
colour[u] ≠ 0   ⇔   bit u is set in mask_col[colour[u]-1]
```

**Proof.**

* Initially all vertices are uncoloured, all masks are `0`.
* When a vertex `v` is coloured with colour `c`
  `colour[v]` is set to `c+1` and the bit `v` is added to
  `mask_col[c]`.  
  Afterwards the equivalence holds for `v` and all other vertices are
  unchanged.
* When backtracking the colour of `v` is set to `0` again and the bit
  `v` is removed from the mask.  
  The equivalence holds for all vertices again. ∎



##### Lemma 2  
Immediately after a recursive call `DFS(idx)` finishes
and returns **true**, the current partial colouring is extendable
to a complete valid colouring of all vertices `0 … idx-1`.

**Proof.**

`DFS(idx)` returns `true` only if either

1. `idx == N` – all vertices are coloured, thus the colouring is
   complete and valid, or

2. a colour `c` was chosen for vertex `v = idx`,
   the forward checking succeeded and the recursive call
   `DFS(idx+1)` returned `true`.  
   By the induction hypothesis the partial colouring of
   vertices `0 … idx` is extendable to a valid colouring of the
   remaining vertices.  
   Adding the colour of `v` does not create a conflict
   (it was checked) and the forward check guarantees that every
   uncoloured neighbour still has at least one free colour.  
   Therefore the whole colouring up to vertex `idx` is still
   extendable to a complete valid colouring. ∎



##### Lemma 3  
If `DFS(idx)` returns **false** then **no** valid colouring exists
for the vertices `0 … idx-1` together with the current assignments of
vertices `0 … idx-1`.

**Proof.**

`DFS(idx)` explores all colours for vertex `v = idx` in
the order `1,2,3`:

* A colour is skipped if some neighbour already uses the same colour –
  then this colour would violate the problem statement.
* If a colour is tried, forward checking is performed.
  Forward checking rejects the branch **iff** there is an
  uncoloured neighbour that already has all three colours used by its
  neighbours.  
  In this case no colour can ever be given to that neighbour,
  consequently no valid completion exists for this branch.
* For every colour that is allowed and passes the forward check the
  algorithm recurses.  
  By the induction hypothesis the recursive call returns `false`
  exactly when the rest of the graph cannot be coloured
  consistently with the current partial colouring.

Therefore every possible colour assignment for vertex `v` is examined,
and a branch is discarded **only** if it is really impossible to
continue.  
Consequently if `DFS(idx)` returns `false`, no completion exists. ∎



##### Lemma 4  
If a valid colouring exists for the whole graph,
`DFS(0)` eventually returns **true**.

**Proof.**

Take any valid colouring `C`.  
During the search `DFS(0)` always tries the three colours in the same
order as `C` uses them – because every colour is tried,
`DFS(0)` will eventually try the colour that `C` uses for vertex `0`.  
This colour is accepted (no neighbour has it),
forward checking succeeds (otherwise `C` would already be impossible),
and the recursion continues with vertex `1`.  
Inductively the same argument applies to every vertex.
Thus the branch that follows exactly the colouring `C` is never pruned
and reaches the base case `idx == N`.  
Consequently `DFS(0)` returns `true`. ∎



##### Theorem  
The algorithm outputs

* “`1 2 3 …`” – a sequence of colours for all vertices –  
  iff this sequence is a valid colouring,  
* or “`-1`” – iff no valid colouring exists.

**Proof.**

*If the algorithm prints a colouring.*  
`DFS(0)` has returned `true`.  
By Lemma&nbsp;2 the partial colouring at the leaf of the recursion
is extendable to a complete valid colouring.  
The algorithm outputs exactly the colours of this complete
colouring, therefore the output is correct.

*If the algorithm prints `-1`.*  
`DFS(0)` returned `false`.  
By Lemma&nbsp;3 no valid colouring exists that agrees with the current
partial assignments (there were none), therefore no valid colouring
exists at all.  
The printed answer is therefore correct.

Both directions hold – the algorithm is correct. ∎



--------------------------------------------------------------------

#### 6.  Complexity Analysis

`N ≤ 40 , M ≤ 600`

* `adj[u]` and the masks are `O(N)` integers.
* In one recursion level only the uncoloured neighbours of the current
  vertex are examined – at most its degree (`≤ N`).
* The search depth is `N`.  

Worst‑case time complexity:  
`O( N * average_degree )  ≤  O( 40 * 40 )` – far below the limits.  
Memory usage: `O(N)`.



--------------------------------------------------------------------

#### 7.  Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1000000)

# -------------------------------------------------------------

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    # adjacency bitmasks
    adj = [0] * n
    for _ in range(m):
        a = int(next(it)) - 1
        b = int(next(it)) - 1
        adj[a] |= 1 << b
        adj[b] |= 1 << a

    colour = [0] * n                     # 0 = not coloured
    mask_col = [0, 0, 0]                 # colours 1,2,3 -> indices 0,1,2

    # ----- forward checking -------------------------------------------------
    def forward_check(v: int) -> bool:
        """After giving v a colour, are all neighbours still colourable?"""
        neigh = adj[v]
        while neigh:
            u = (neigh & -neigh).bit_length() - 1   # lowest set bit
            neigh &= neigh - 1                      # remove the bit
            if colour[u] == 0:                      # u is still uncoloured
                used = 0
                if mask_col[0] & adj[u]:
                    used |= 1
                if mask_col[1] & adj[u]:
                    used |= 2
                if mask_col[2] & adj[u]:
                    used |= 4
                if used == 7:                       # all three colours used
                    return False
        return True

    # ----- backtracking ------------------------------------------------------
    def dfs(idx: int) -> bool:
        if idx == n:          # all vertices coloured
            return True
        v = idx
        for c in range(3):    # try colours 1,2,3
            # skip if neighbour already has the same colour
            if (mask_col[c] & adj[v]) != 0:
                continue
            colour[v] = c + 1
            mask_col[c] |= 1 << v
            if forward_check(v) and dfs(idx + 1):
                return True
            # backtrack
            colour[v] = 0
            mask_col[c] &= ~(1 << v)
        return False

    # -----------------------------------------------------------------------
    if dfs(0):
        print(' '.join(str(colour[i]) for i in range(n)))
    else:
        print(-1)


# -------------------------------------------------------------
if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input / output format.
