To solve this problem, we need to assign shifts to workers such that no two incompatible workers are assigned the same shift. The solution involves systematically checking each worker's incompatible predecessors and assigning the lowest possible shift that avoids conflicts.

### Approach
1. **Input Reading**: Read the number of workers (n) and the number of incompatible pairs (m).
2. **Incompatibility Tracking**: Maintain a list where each entry at index `i` contains all predecessors (workers with indices less than `i`) that are incompatible with worker `i`.
3. **Shift Assignment**: For each worker, starting from the first, check each possible shift (1, 2, 3) in order. For each shift, verify if it causes any conflict with the shifts of incompatible predecessors. Assign the first valid shift found.
4. **Conflict Handling**: If no valid shift can be found for any worker, print "IMPOSSIBLE" and exit.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    m = int(input[idx])
    idx += 1
    
    incompat_prev = [[] for _ in range(n + 1)]
    
    for _ in range(m):
        u = int(input[idx])
        idx += 1
        v = int(input[idx])
        idx += 1
        a = min(u, v)
        b = max(u, v)
        incompat_prev[b].append(a)
    
    shifts = [0] * (n + 1)
    
    for i in range(1, n + 1):
        for s in [1, 2, 3]:
            conflict = False
            for j in incompat_prev[i]:
                if shifts[j] == s:
                    conflict = True
                    break
            if not conflict:
                shifts[i] = s
                break
        else:
            print("IMPOSSIBLE")
            return
    
    print(' '.join(map(str, shifts[1:n+1])))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of workers (n) and the number of incompatible pairs (m).
2. **Tracking Incompatibilities**: For each incompatible pair, we ensure that the smaller index is stored as an incompatible predecessor for the larger index. This helps in efficiently checking conflicts during shift assignment.
3. **Shift Assignment**: For each worker, starting from the first, we check each possible shift (1, 2, 3). For each shift, we check if it causes a conflict with any of the worker's incompatible predecessors. The first valid shift that does not cause a conflict is assigned.
4. **Conflict Handling**: If at any point a worker cannot be assigned a valid shift without conflict, the solution immediately prints "IMPOSSIBLE" and exits, ensuring efficient termination.

This approach ensures that we efficiently assign shifts while adhering to the constraints of incompatibility, using a systematic check for each worker.
