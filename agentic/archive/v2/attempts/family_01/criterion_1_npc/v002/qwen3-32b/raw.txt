To solve the problem of determining whether a given undirected graph can be 3-colored, we can use a recursive backtracking approach. The key idea is to assign one of the three colors (1, 2, or 3) to each node in the graph such that no two adjacent nodes share the same color. If such an assignment is possible, we print the color for each node; otherwise, we print "No".

---

### **Approach Overview**

1. **Graph Representation**:
   - The graph is represented using an adjacency list.
   - We preprocess the adjacency list to store only those neighbors of each node that have a smaller index. This allows us to efficiently check only the already processed nodes during the backtracking step.

2. **Backtracking Algorithm**:
   - We recursively attempt to assign a color to each node starting from node 1 up to node `n`.
   - For each node, we check if the current color assignment is valid (i.e., no adjacent node with a smaller index has the same color).
   - If valid, we proceed to the next node. If all nodes are successfully colored, we return `True`.

3. **Optimization**:
   - We preprocess the adjacency lists to include only neighbors with smaller indices. This avoids unnecessary checks and improves performance.

---

### **Python Implementation**

```python
def main():
    import sys
    input = sys.stdin.read
    data = input().split()
    
    n = int(data[0])
    m = int(data[1])
    
    adj = [[] for _ in range(n + 1)]
    idx = 2
    for _ in range(m):
        u = int(data[idx])
        v = int(data[idx + 1])
        adj[u].append(v)
        adj[v].append(u)
        idx += 2
    
    # Preprocess: store only neighbors with smaller indices
    adj_less = [[] for _ in range(n + 1)]
    for i in range(1, n + 1):
        for neighbor in adj[i]:
            if neighbor < i:
                adj_less[i].append(neighbor)
    
    color = [0] * (n + 1)
    
    def backtrack(i):
        if i > n:
            return True
        for c in [1, 2, 3]:
            valid = True
            for neighbor in adj_less[i]:
                if color[neighbor] == c:
                    valid = False
                    break
            if not valid:
                continue
            color[i] = c
            if backtrack(i + 1):
                return True
            color[i] = 0
        return False
    
    if backtrack(1):
        print("Yes")
        print(' '.join(map(str, color[1:])))
    else:
        print("No")

if __name__ == "__main__":
    main()
```

---

### **Example**

**Input**:
```
3 3
1 2
2 3
1 3
```

**Output**:
```
Yes
1 2 3
```

---

### **Complexity Analysis**

- **Time Complexity**: Worst-case is exponential in `n` due to backtracking, but in practice, it performs well for sparse graphs or graphs where many color choices are invalid early.
- **Space Complexity**: `O(n)` for the color array and adjacency lists.

This solution is efficient for moderate-sized graphs and leverages backtracking with pruning to avoid unnecessary computations.
