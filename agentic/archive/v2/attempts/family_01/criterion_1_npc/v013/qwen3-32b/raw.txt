To solve this problem, we need to determine if it's possible to assign each worker to one of three shifts such that no two conflicting workers are assigned to the same shift. If possible, we also need to provide the lexicographically smallest valid assignment.

### Approach
1. **Graph Representation**: Represent the conflicts between workers using an adjacency list. Each worker will have a set of workers they conflict with.
2. **Greedy Assignment**: For each worker, starting from the first, try to assign them to the earliest possible shift (1, 2, or 3) that does not conflict with any previously assigned workers. This ensures the lexicographically smallest valid assignment.
3. **Conflict Check**: For each worker, check if any of their conflicting workers (who have already been assigned a shift) are in the same shift. If not, assign the current shift to the worker.

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    m = int(input[idx])
    idx += 1
    
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u = int(input[idx])
        idx += 1
        v = int(input[idx])
        idx += 1
        adj[u].add(v)
        adj[v].add(u)
    
    shifts = [0] * (n + 1)
    
    for u in range(1, n + 1):
        for s in [1, 2, 3]:
            conflict = False
            for v in adj[u]:
                if v < u:
                    if shifts[v] == s:
                        conflict = True
                        break
            if not conflict:
                shifts[u] = s
                break
        if shifts[u] == 0:
            print("NO")
            return
    
    print("YES")
    print(' '.join(map(str, shifts[1:])))

if __name__ == "__main__":
    main()
```

### Explanation
1. **Reading Input**: The input is read and parsed into the number of workers (n) and the number of conflicts (m). The adjacency list `adj` is built to keep track of conflicts between workers.
2. **Shift Assignment**: For each worker from 1 to n, we attempt to assign them to the earliest possible shift (1, 2, or 3). This is done by checking each conflicting worker who has already been assigned a shift to ensure there is no conflict.
3. **Conflict Check**: For each potential shift assignment, we check all previously assigned conflicting workers. If no conflict is found, the shift is assigned, ensuring the smallest lexicographical order.
4. **Output**: If all workers can be assigned shifts without conflicts, the result is printed. If any worker cannot be assigned a valid shift, "NO" is printed.

This approach ensures that we efficiently check for valid shift assignments while maintaining the lexicographical order, leveraging a greedy strategy to minimize conflicts.
