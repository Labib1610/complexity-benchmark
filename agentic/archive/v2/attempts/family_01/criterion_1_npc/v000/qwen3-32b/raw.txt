To solve this problem, we need to determine a valid 3-coloring of a graph such that no two adjacent nodes share the same color, and the solution is lexicographically smallest. The approach involves using a backtracking algorithm to explore possible color assignments while ensuring the lexicographically smallest solution is found.

### Approach
1. **Graph Representation**: Represent the graph using an adjacency list where each node points to its neighbors.
2. **Backtracking**: Use a backtracking approach to assign colors to each node sequentially from 1 to n. For each node, attempt to assign the smallest possible color (1, 2, or 3) that does not conflict with previously colored adjacent nodes.
3. **Validation Check**: For each color assignment, check if any of the node's neighbors (which have already been processed) have the same color. If a valid color is found, proceed to the next node recursively.
4. **Termination**: If all nodes are successfully colored without conflicts, print the color assignments. If no valid coloring is found, print "IMPOSSIBLE".

### Solution Code
```python
def main():
    import sys
    input = sys.stdin.read().split()
    idx = 0
    n = int(input[idx])
    idx += 1
    m = int(input[idx])
    idx += 1
    
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(input[idx])
        idx += 1
        v = int(input[idx])
        idx += 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * (n + 1)
    
    def backtrack(pos):
        if pos > n:
            return True
        for c in [1, 2, 3]:
            valid = True
            for neighbor in adj[pos]:
                if neighbor < pos and color[neighbor] == c:
                    valid = False
                    break
            if valid:
                color[pos] = c
                if backtrack(pos + 1):
                    return True
                color[pos] = 0
        return False
    
    if backtrack(1):
        print(' '.join(map(str, color[1:])))
    else:
        print("IMPOSSIBLE")

if __name__ == "__main__":
    main()
```

### Explanation
1. **Graph Representation**: The graph is stored as an adjacency list where each node's neighbors are listed.
2. **Backtracking Function**: The `backtrack` function attempts to color each node starting from 1 up to n. For each node, it tries colors 1 through 3 in order to ensure the lexicographically smallest solution.
3. **Validation Check**: For each color assignment, the function checks if any previously processed neighbor has the same color. If valid, it proceeds to the next node.
4. **Recursion and Termination**: The recursion continues until all nodes are processed. If a valid coloring is found, it is printed; otherwise, "IMPOSSIBLE" is printed.

This approach ensures that we explore all possible valid colorings in a systematic manner, leveraging backtracking to efficiently find the lexicographically smallest valid solution.
