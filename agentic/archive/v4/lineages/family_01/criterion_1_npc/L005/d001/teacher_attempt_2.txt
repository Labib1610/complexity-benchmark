# Problem A — Network Channel Allocation

Time limit: 2 s   Memory limit: 256 MB

A distributed computing system consists of $n$ processing nodes, numbered $1$ to $n$. Certain pairs of nodes have direct communication conflicts. There are $m$ such conflict pairs in total.

To avoid transmission interference, each node must be assigned an operating channel from the set $\{1, 2, 3\}$. Two nodes that share a conflict pair cannot be assigned the same operating channel.

If a valid channel configuration exists, the system requires the lexicographically smallest sequence of channel assignments $s_1, s_2, \dots, s_n$. That is, when comparing two valid assignment sequences, preference is given to the sequence with the smaller value at the first index where they differ.

Determine if a valid channel assignment exists for all nodes. If so, output `YES` followed by the lexicographically smallest assignment sequence. Otherwise, output `NO`.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le \frac{n(n-1)}{2}$) — the number of nodes and the number of conflict pairs.
Each of the next $m$ lines contains two distinct integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating a conflict pair between node $u$ and node $v$.

## Output
If no valid channel assignment exists, print `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1 \ s_2 \ \dots \ s_n$ ($s_i \in \{1, 2, 3\}$), representing the assigned channel for each node $1$ through $n$, such that $s_1, s_2, \dots, s_n$ is lexicographically smallest.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
