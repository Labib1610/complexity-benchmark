# Memory Register Configuration

Time limit: 2 s   Memory limit: 256 MB

An electronic system contains $n$ configuration registers, indexed sequentially from 1 to $n$. Each register must be assigned a single integer state from the set $\{1, 2, 3\}$.

The system specifies $m$ hardware constraints between pairs of registers. Each constraint links two distinct registers $u$ and $v$, requiring that register $u$ and register $v$ hold different states (i.e., $s_u \neq s_v$).

Find a state assignment $s_1, s_2, \dots, s_n$ for all $n$ registers that satisfies every hardware constraint. If multiple valid assignments exist, choose the lexicographically smallest state sequence $s_1, s_2, \dots, s_n$ (comparing $s_1$ first, then $s_2$, and so on). If no assignment satisfies all constraints, report that it is impossible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of registers and the number of hardware constraints.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), specifying that register $u$ and register $v$ must have different states.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (each in $\{1, 2, 3\}$), where $s_i$ denotes the state assigned to register $i$. Output the lexicographically smallest sequence among all valid assignments.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
