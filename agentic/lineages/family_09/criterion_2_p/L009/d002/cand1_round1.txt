# Problem B — Interference-Free Group

Time limit: 2 s   Memory limit: 256 MB

## Description

You are evaluating a sensor network containing **n** devices, identified by integers from 1 to **n**, and **m** bi-directional interference links. Each link indicates that two specific devices disrupt each other's signals.

Every device in the network was supplied by one of exactly two competing vendors. Because of proprietary shielding, devices from the same vendor will never interfere with each other. Consequently, an interference link can physically only exist between a device from the first vendor and a device from the second vendor. The vendor of each individual device is not recorded.

Your task is to select an **interference-free** group of exactly **k** devices. A group is considered interference-free if no two devices chosen for the group have an interference link between them. 

Determine if such a group of size **k** is possible, and if it is, provide one valid selection.

## Input

The first line provides the integers **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
Following this are **m** lines, each containing two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing an interference link between device **u** and device **v**. 
All links are unique, and the network configuration is guaranteed to adhere to the two-vendor rule explained in the description.

## Output

If it is possible to find an interference-free group of exactly **k** devices, output `YES` on the first line. On the second line, output the **k** distinct device identifiers that make up this group, separated by spaces. If multiple such groups exist, any valid one is acceptable.

If achieving a group of this exact size is impossible, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

## Note

In Example 1, devices 1 and 2 do not share an interference link. In Example 3, the largest possible interference-free group consists of only 2 devices, making a target size of 3 impossible.
