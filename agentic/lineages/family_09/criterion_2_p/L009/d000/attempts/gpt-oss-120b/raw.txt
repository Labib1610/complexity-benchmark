**Solution Explanation**

The interference graph is bipartite – every edge connects a device of type A with a device of type B.
For a bipartite graph

* size of a minimum vertex cover = size of a maximum matching   (Kőnig’s theorem)
* size of a maximum independent set = `n – size(minimum vertex cover)`

So an independent set of size `k` exists **iff** the maximum matching has size `≤ n‑k`.

The algorithm

1. **bipartition** – colour the graph with two colours by BFS/DFS.
2. **maximum matching** – Hopcroft‑Karp (`O(m·√n)`).
3. **minimum vertex cover** – from the matching:
   * start from all *free* left vertices (unmatched left side)
   * follow alternating paths  
     left → (non‑matching edge) → right → (matching edge) → left …
   * let `Lvis` / `Rvis` be the visited vertices.
   * minimum vertex cover = `(Left \ Lvis) ∪ Rvis`
4. **maximum independent set** = complement of the cover = `Lvis ∪ (Right \ Rvis)`.
   Its size is `n – matching_size`.  
   If it is at least `k`, output any `k` vertices from it, otherwise answer `NO`.

All steps are linear or `O(m·√n)`, well inside the limits.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct set exactly when such a set exists.

---

##### Lemma 1  
The colouring step produces a bipartition `(L,R)` such that every edge connects a vertex of `L` with a vertex of `R`.

**Proof.** The input guarantees the graph is bipartite. BFS/DFS colours each visited vertex opposite to its predecessor; because the graph is bipartite, no conflict occurs. ∎



##### Lemma 2  
`matching` returned by Hopcroft‑Karp is a maximum matching of the bipartite graph.

**Proof.** Hopcroft‑Karp is a classic algorithm that repeatedly augments along shortest augmenting paths until none exist; at that point the matching is maximum (Berge’s theorem). ∎



##### Lemma 3  
Let `M` be a maximum matching, `Lvis,Rvis` the vertices reachable from free left vertices by alternating
(non‑matching, matching, …) edges.
Then `C = (L \ Lvis) ∪ Rvis` is a minimum vertex cover.

**Proof.** This is the standard construction from König’s theorem.
*Every edge* is either
* matched and its left endpoint is not in `Lvis` (hence in `C`), or
* unmatched and its left endpoint is in `Lvis`; then its right endpoint is visited via a non‑matching edge, thus belongs to `Rvis ⊆ C`.
Hence `C` covers all edges.
Its size equals `|M|` (one can show `|C| = |M|`), and by König’s theorem any vertex cover has size at least `|M|`. Therefore `C` is minimum. ∎



##### Lemma 4  
`I = (Lvis) ∪ (R \ Rvis)` is a maximum independent set, and `|I| = n – |M|`.

**Proof.** `I` is the complement of the minimum vertex cover `C`, thus it is independent.
Since `C` is minimum, `I` is maximum.  
`|I| = n – |C| = n – |M|`. ∎



##### Lemma 5  
If `|I| ≥ k` the algorithm outputs a set of `k` vertices that is independent.

**Proof.** The algorithm selects the first `k` vertices from `I`.  
All selected vertices belong to `I`, which is independent by Lemma&nbsp;4, therefore the output set is independent. ∎



##### Lemma 6  
If the algorithm outputs `NO` then no independent set of size `k` exists.

**Proof.** `NO` is printed exactly when `|I| < k`.  
By Lemma&nbsp;4, `|I|` is the size of a *maximum* independent set.  
Hence any independent set has size ≤ `|I| < k`; a set of size `k` cannot exist. ∎



##### Theorem  
The algorithm prints `YES` and a correct interference‑free group of size `k`
iff such a group exists; otherwise it prints `NO`.

**Proof.**  
*If* the algorithm prints `YES`, by Lemma&nbsp;5 the printed vertices form an independent set of size `k`.  
*Only if*: suppose an independent set of size `k` exists. Then the maximum independent set size is at least `k`, i.e. `|I| ≥ k`. The algorithm therefore does not print `NO` (Lemma&nbsp;6) and proceeds to output `YES` and a subset of `I` of size `k` (Lemma&nbsp;5). ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Colouring*: `O(n + m)`  
*Hopcroft‑Karp*: `O(m·√n)`  
*Cover / independent set construction*: `O(n + m)`  

Overall time `O(m·√n)` ≤ `4·10⁵·√10⁵` ≈ `1.3·10⁸` operations, fast enough in 2 s (Python implementation is well‑optimized).  
Memory: adjacency lists (`2·m` integers) + a few arrays of size `n` → `O(n + m)` ≤ about 5 MB.

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); k = int(next(it))
    adj = [[] for _ in range(n)]
    edges = []
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
        edges.append((u, v))

    # 1. bipartition
    color = [-1] * n          # 0 = left, 1 = right
    from collections import deque
    for start in range(n):
        if color[start] != -1:
            continue
        color[start] = 0
        q = deque([start])
        while q:
            v = q.popleft()
            for to in adj[v]:
                if color[to] == -1:
                    color[to] = color[v] ^ 1
                    q.append(to)

    left = [i for i in range(n) if color[i] == 0]
    right = [i for i in range(n) if color[i] == 1]
    L_id = {v: i for i, v in enumerate(left)}
    R_id = {v: i for i, v in enumerate(right)}
    nl = len(left)
    nr = len(right)

    # build adjacency from left to right indices
    G = [[] for _ in range(nl)]
    for u, v in edges:
        if color[u] == 0:
            G[L_id[u]].append(R_id[v])
        else:
            G[L_id[v]].append(R_id[u])

    # 2. Hopcroft‑Karp
    from collections import deque
    INF = 10 ** 9

    pairU = [-1] * nl
    pairV = [-1] * nr
    dist = [0] * nl

    def bfs() -> bool:
        q = deque()
        for u in range(nl):
            if pairU[u] == -1:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        reachable = False
        while q:
            u = q.popleft()
            for v in G[u]:
                pu = pairV[v]
                if pu != -1 and dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    q.append(pu)
                elif pu == -1:
                    reachable = True
        return reachable

    def dfs(u: int) -> bool:
        for v in G[u]:
            pu = pairV[v]
            if pu == -1 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(nl):
            if pairU[u] == -1 and dfs(u):
                matching += 1

    # 3. minimum vertex cover via alternating BFS
    Lvis = [False] * nl
    Rvis = [False] * nr
    q = deque()
    for u in range(nl):
        if pairU[u] == -1:
            q.append(('L', u))
            Lvis[u] = True
    while q:
        side, idx = q.popleft()
        if side == 'L':
            for v in G[idx]:
                if not Rvis[v] and pairU[idx] != v:   # non‑matching edge
                    Rvis[v] = True
                    q.append(('R', v))
        else:  # side == 'R'
            pu = pairV[idx]
            if pu != -1 and not Lvis[pu]:
                Lvis[pu] = True
                q.append(('L', pu))

    # 4. independent set = Lvis ∪ (Right \ Rvis)
    independent = []
    for i, v in enumerate(left):
        if Lvis[i]:
            independent.append(v + 1)
    for i, v in enumerate(right):
        if not Rvis[i]:
            independent.append(v + 1)

    if len(independent) >= k:
        print("YES")
        print(' '.join(map(str, independent[:k])))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
