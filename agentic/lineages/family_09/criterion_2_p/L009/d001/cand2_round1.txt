# Problem B — Interference-Free Group

Time limit: 2 s   Memory limit: 256 MB

## Description

A sensor network has **n** devices (numbered 1..n) and **m** interference links. Each link joins two devices that interfere with each other.

Due to the network's frequency configuration, it is guaranteed that the interference links never form a cycle of odd length.

A group of devices is **interference-free** if no two devices in the group interfere.

Given a target size **k**, decide whether an interference-free group of exactly **k** devices exists, and if so report one.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v): an interference link. No link is listed twice, and the network is guaranteed to contain no odd-length cycles.

## Output

If an interference-free group of **k** devices exists, print `YES` on the first line, then on the second line print **k** distinct device numbers forming such a group, separated by spaces. Any group in which no two devices are linked is accepted.

If no such group exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

## Note

In Example 1, devices 1 and 2 do not interfere. In Example 3, the largest interference-free group has only 2 devices, so a target size of 3 is impossible.

<RATIONALE>
Removed the explicit "two types" wording from the title and description, replacing it with the equivalent structural guarantee of having "no odd-length cycles". This removes the direct semantic trigger for bipartition coloring, forcing the model to mathematically deduce that the absence of odd cycles implies the graph is bipartite before it can apply the required matching algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The set of valid input graphs is identical because a graph has no odd-length cycles if and only if it can be partitioned into two independent sets, meaning the exact same interference-free groups exist.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains finding an independent set of size k in a bipartite graph, which is solvable in polynomial time via maximum bipartite matching and König's theorem.
</PRESERVED_CLASS>
