We can model the microservices as a bipartite graph.  
The two tiers are the two color classes of the bipartition.  
A safe set is any set of vertices with no edges between them — i.e., an independent set.  

In a bipartite graph, the largest independent set is the complement of a minimum vertex cover, which by König’s theorem equals the size of a maximum matching.  

But here we only need to check if there exists an independent set of size exactly `k`.  
Since the graph is bipartite, we can find the two color classes.  
Any independent set can be formed by taking some vertices from one side and some from the other, but we must avoid edges.  

The simplest approach:  
- Color the graph (BFS/DFS).  
- Let `cnt0` = number of vertices in color 0, `cnt1` = number in color 1.  
- If `k <= max(cnt0, cnt1)`, we can just pick `k` vertices from the larger side — that’s always safe.  
- If `k > max(cnt0, cnt1)`, we need to take some from both sides. But if we take from both sides, we must ensure no edge between chosen vertices.  
  In a bipartite graph, if we take all of one side and some of the other, we might create conflicts.  
  However, if the graph is complete bipartite, we can’t mix.  
  But the problem guarantees the graph is bipartite, not necessarily complete.  

We can check:  
- If `k <= max(cnt0, cnt1)`, output `YES` with `k` from the larger side.  
- Else, we need to see if we can pick `k` vertices with no edges.  
  The maximum independent set size = `n - maximum_matching_size`.  
  If `k <= n - matching_size`, then possible.  
  We can find a maximum independent set via König’s theorem:  
    - Find maximum matching.  
    - Find minimum vertex cover.  
    - Independent set = all vertices not in the cover.  
  Then if `k <= size_of_independent_set`, we can pick any `k` from it.  

But since n up to 100k and m up to 400k, we can run Hopcroft–Karp for maximum matching.  

Let’s implement that.  

```python
import sys
from collections import deque

input = sys.stdin.readline

def hopcroft_karp(n, adj, U):
    # U: list of vertices on left side (0-indexed)
    # adj: adjacency list for left vertices to right vertices (0-indexed)
    INF = 10**9
    pairU = [-1] * n
    pairV = [-1] * n
    dist = [0] * n

    def bfs():
        q = deque()
        for u in U:
            if pairU[u] == -1:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        found = False
        while q:
            u = q.popleft()
            for v in adj[u]:
                pu = pairV[v]
                if pu == -1:
                    found = True
                elif dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    q.append(pu)
        return found

    def dfs(u):
        for v in adj[u]:
            pu = pairV[v]
            if pu == -1 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in U:
            if pairU[u] == -1 and dfs(u):
                matching += 1
    return matching, pairU, pairV

def main():
    n, m, k = map(int, input().split())
    adj = [[] for _ in range(n)]
    edges = []
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
        edges.append((u, v))

    # Bipartite coloring
    color = [-1] * n
    for i in range(n):
        if color[i] == -1:
            color[i] = 0
            q = deque([i])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = color[u] ^ 1
                        q.append(v)

    left = [i for i in range(n) if color[i] == 0]
    right = [i for i in range(n) if color[i] == 1]

    # Build adjacency for left side only
    left_adj = [[] for _ in range(n)]
    for u, v in edges:
        if color[u] == 0:
            left_adj[u].append(v)
        else:
            left_adj[v].append(u)

    matching_size, pairU, pairV = hopcroft_karp(n, left_adj, left)

    # Maximum independent set size = n - matching_size
    max_independent = n - matching_size
    if k > max_independent:
        print("NO")
        return

    # Find minimum vertex cover via König's theorem
    # From unmatched left vertices, BFS alternating paths
    visited_left = [False] * n
    visited_right = [False] * n
    q = deque()
    for u in left:
        if pairU[u] == -1:
            visited_left[u] = True
            q.append(u)
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[u] == 0:
                if not visited_right[v]:
                    visited_right[v] = True
                    if pairV[v] != -1 and not visited_left[pairV[v]]:
                        visited_left[pairV[v]] = True
                        q.append(pairV[v])
            else:
                if not visited_right[v]:
                    visited_right[v] = True
                    if pairV[v] != -1 and not visited_left[pairV[v]]:
                        visited_left[pairV[v]] = True
                        q.append(pairV[v])

    # Minimum vertex cover: left not visited + right visited
    cover = set()
    for u in left:
        if not visited_left[u]:
            cover.add(u)
    for v in right:
        if visited_right[v]:
            cover.add(v)

    # Independent set = all vertices not in cover
    independent = [i for i in range(n) if i not in cover]

    # Pick any k from independent
    chosen = independent[:k]
    print("YES")
    print(" ".join(str(x+1) for x in chosen))

if __name__ == "__main__":
    main()
```
