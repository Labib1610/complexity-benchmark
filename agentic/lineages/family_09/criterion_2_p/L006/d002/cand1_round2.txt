# Problem B — Interference-Free Monitoring

Time limit: 2 s   Memory limit: 256 MB

## Description

You are tasked with installing diagnostic sensors on an intricate clockwork assembly. The assembly consists of **n** gears, identified by integers from 1 to **n**, and **m** engagement points. Each engagement point acts as a direct physical link between a specific pair of gears.

Because the diagnostic sensors generate powerful magnetic fields, placing them on gears that are directly linked will cause critical interference. Therefore, you must select exactly **k** distinct gears to receive sensors such that no two selected gears share an engagement point.

The manufacturer provides a strict formal guarantee regarding the assembly's layout: there exists a valid way to assign one of two possible states (for example, "State A" and "State B") to every single gear in the system, such that every engagement point exclusively links a gear in State A to a gear in State B. As a direct result, no engagement point ever connects two gears that share the same state. Note that this state assignment is an underlying property of the design; it is not provided to you in the input, and you must derive it yourself if your solution relies on it.

Your objective is to determine whether a safe installation of exactly **k** sensors is possible and, if so, to provide a valid selection of gears.

## Input

The first line provides three integers: **n** (the number of gears), **m** (the number of engagement points), and **k** (the required number of sensors). The bounds are 1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, and 1 ≤ k ≤ n.

This is followed by **m** lines, each containing two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v). Each line specifies an engagement point connecting gear **u** and gear **v**. 

All engagement points are unique (no duplicates). The input configurations are guaranteed to adhere to the manufacturer's structural property (i.e., the entire network of gears supports the two-state assignment described above).

## Output

If there is a way to select exactly **k** distinct gears without any two sharing an engagement point, print `YES` on the first line. On the second line, print the **k** chosen gear identifiers separated by spaces. If multiple valid selections exist, any of them will be accepted.

If it is impossible to find exactly **k** non-interfering gears, print `NO` on a single line.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```
