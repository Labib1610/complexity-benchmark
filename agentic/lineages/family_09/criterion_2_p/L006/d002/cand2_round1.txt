# Problem B — Interference-Free Monitoring

Time limit: 2 s   Memory limit: 256 MB

## Description

An intricate clockwork assembly contains **n** gears (numbered 1 to **n**) and **m** engagement points. Each engagement point links two specific gears. 

The manufacturer guarantees a specific structural property of this assembly: any cycle formed by a sequence of distinct gears (where each touches the next, and the last touches the first) always consists of an even number of gears.

Your task is to install diagnostic sensors on exactly **k** of these gears. Since the sensors emit strong magnetic fields, they will interfere with one another if placed on gears that physically touch. Thus, no two gears selected for sensors can share an engagement point.

Given the target number **k**, determine if it is possible to choose exactly **k** distinct gears for sensor installation without any interference. If it is possible, output a valid selection.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
Each of the following **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing an engagement point between gear **u** and gear **v**. No engagement point is listed more than once. The assembly is guaranteed to satisfy the structural property described above.

## Output

If exactly **k** gears can be successfully selected, print `YES` on the first line. On the second line, print the **k** distinct gear numbers that form your selection, separated by spaces. Any valid selection of **k** mutually non-engaging gears will be accepted.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit "two distinct categories" description with the equivalent graph-theoretic property of having only even-length cycles. This forces the model to independently deduce that the graph is bipartite and apply the correct matching algorithm, rather than relying on the explicit two-category hint to take a shortcut via simple BFS coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The answers are unchanged because the structural property (no odd cycles) is mathematically identical to the original property (bipartite), meaning the exact same graphs are valid inputs and the valid sensor sets remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class is unchanged (Polynomial Time) because the graph is still bipartite, allowing the maximum independent set to be found in polynomial time via Hopcroft-Karp and König's theorem.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret the length of the cycle if it considers the start and end gear to be duplicated in the count, although "sequence of distinct gears" strongly implies counting the unique vertices in the cycle.
</RISK>
