# Problem B — Interference-Free Monitoring

Time limit: 2 s   Memory limit: 256 MB

## Description

An intricate clockwork assembly contains **n** gears (numbered 1 to **n**) and **m** engagement points. Each engagement point links two specific gears. 

Your task is to install diagnostic sensors on exactly **k** of these gears. Since the sensors emit strong magnetic fields, they will interfere with one another if placed on gears that physically touch. The requirement is to find exactly a set of **k** gears with no engagement point between any two selected gears.

The manufacturer guarantees a specific structural property of this assembly: any sequence of engagement points that forms a simple cycle (a closed loop with no repeated gears other than the start and end) will always consist of an even number of engagement points. (You may use this structural guarantee in your method if your solution relies on it.)

Given the target number **k**, determine if it is possible to choose exactly **k** distinct gears for sensor installation without any interference. Selected gears may be located anywhere in the assembly, provided no two are linked; the selection is not restricted to any specific structural grouping. If it is possible, output a valid selection.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
Each of the following **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing an engagement point between gear **u** and gear **v**. No engagement point is listed more than once. The assembly is guaranteed to satisfy the structural property described above.

## Output

If exactly **k** gears can be successfully selected, print `YES` on the first line. On the second line, print the **k** distinct gear numbers that form your selection, separated by spaces. Any valid set of **k** distinct identifiers with no connecting engagement point is accepted.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

<RATIONALE>
I replaced the explicit "two distinct categories" guarantee with its mathematical equivalent: the guarantee that all simple cycles have an even length. This removes the surface-level wording that models used to trigger bipartite-specific shortcuts, forcing them to independently deduce that a graph with no odd cycles is bipartite in order to apply the correct polynomial-time algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The task remains finding a set of exactly k non-adjacent vertices, and the underlying input graphs still possess the exact same structure, so all valid selections and YES/NO existences remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The graph is guaranteed to have no odd cycles, which is the exact definition of a bipartite graph, so finding a maximum independent set remains in P via König's theorem.
</PRESERVED_CLASS>
<RISK>
Some models might fail to recognize that "no odd cycles" implies bipartiteness and attempt an exponential-time general independent set algorithm, but this leads to a Time Limit Exceeded error (the intended failure mode) rather than indicating ambiguity in the problem itself.
</RISK>
