# Problem B — Interference-Free Monitoring

Time limit: 2 s   Memory limit: 256 MB

## Description

An intricate clockwork assembly contains **n** gears (numbered 1 to **n**) and **m** engagement points. Each engagement point links two specific gears. 

The manufacturer guarantees a specific structural property of this assembly: for any connected network of gears, if you select an arbitrary reference gear and count the minimum number of engagement points to reach every other gear, no engagement point exists between any two gears that are equidistant from the reference gear (i.e., requiring the same minimum number of steps to reach). 

Your task is to activate diagnostic sensors on exactly **k** of these gears. The sensors will create destructive interference if placed on gears that are directly linked by an engagement point. Therefore, no two gears chosen for sensor activation can share an engagement point.

A valid sensor set is not restricted to taking only gears at even distances or only gears at odd distances from a reference; solutions may mix gears regardless of their distance parity. In fact, some assemblies allow a maximum number of non-interfering sensors strictly larger than the total number of even-distance gears or the total number of odd-distance gears. Feasibility must therefore be evaluated from the exact engagement structure, not merely from distance parity counts.

Given the target number **k**, determine if it is possible to choose exactly **k** distinct gears for sensor activation without any interference. If it is possible, output a valid selection.

## Input

The first line contains three integers **n**, **m**, and **k**. The number of gears **n** is a positive integer bounded by the number of centimeters in one kilometer. The number of engagement points **m** is a non-negative integer that will not exceed four times the maximum possible gear limit. The target **k** is between 1 and **n** inclusive.
Each of the following **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing an engagement point between gear **u** and gear **v**. No engagement point is listed more than once. The assembly is guaranteed to satisfy the structural property described above.

## Output

If exactly **k** gears can be successfully selected, print `YES` on the first line. On the second line, print the **k** distinct gear numbers that form your selection, separated by spaces. Any valid selection of **k** mutually non-engaging gears will be accepted.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

<METHOD_DESCRIPTION>Replaced the explicit "two camps" (bipartite) guarantee with its BFS-level equivalent: the property that no two vertices at the same shortest-path distance from any reference node share an edge. Models relying on keyword matching for "bipartite" or "two sets" will fail to trigger their König's theorem templates and likely fallback to exponential General MIS algorithms.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<RATIONALE>
The seed problem explicitly stated the graph could be divided into "two camps", acting as a direct trigger for bipartite matching algorithms. I removed this terminology entirely and replaced it with a structural guarantee based on BFS distances (no edges between vertices at the same shortest-path distance from a reference), which is mathematically equivalent to being bipartite (no odd cycles) but requires the model to actively deduce the graph class. I also applied S07 to obfuscate the numeric bounds using the physical constant of centimeters in a kilometer.
</RATIONALE>
<PRESERVED_ANSWER>
The structural guarantee is mathematically identical to a bipartite graph, and the goal remains finding an independent set of size exactly k, ensuring all valid solutions are unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying graph remains bipartite, so the problem is still solvable in polynomial time using Hopcroft-Karp and König's theorem to find the maximum independent set.
</PRESERVED_CLASS>
<RISK>
Models or readers might fail to realize that "centimeters in one kilometer" equals exactly 100,000, though it is a standard conversion.
