# Problem B — Interference-Free Monitoring

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a complex clockwork mechanism consisting of **n** cogs (labeled 1 through **n**) and **m** contact mechanisms. Each contact mechanism directly meshes two distinct cogs together.

By design, this mechanism adheres to a strict structural division: the cogs can be partitioned into two distinct groups such that every contact mechanism only ever meshes a cog from the first group with a cog from the second group. There are never any contacts between two cogs within the same group. (This grouping is a guaranteed property of the hardware, though the explicit group assignments are not provided to you).

You need to mount diagnostic probes onto exactly **k** cogs. Probes are highly sensitive; if two cogs are meshed together by a contact mechanism, they cannot both host a probe without causing signal interference. Consequently, you must select a set of **k** cogs where no two selected cogs are directly meshed. 

Crucially, a valid probe configuration is not required to equal or be restricted to a single group. Solutions may contain cogs from both groups, and some mechanisms have a maximum interference-free set strictly larger than either group. Feasibility must therefore be determined from the precise meshing network, not from group sizes alone.

Determine whether exactly **k** cogs can be safely instrumented. If such a configuration exists, provide one valid selection.

## Input

The initial line provides three integers: **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
The subsequent **m** lines each contain two integers, **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), indicating a contact mechanism between cog **u** and cog **v**. No contact mechanism is duplicated in the input. The mechanism is guaranteed to satisfy the two-group property mentioned above.

## Output

If it is possible to mount exactly **k** probes without interference, output `YES` on the first line. On the next line, output the **k** distinct cog labels that make up your chosen set, separated by spaces. Any valid subset of **k** mutually non-meshing cogs is acceptable.

If no such subset exists, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```
