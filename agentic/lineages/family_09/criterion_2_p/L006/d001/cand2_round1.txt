# Problem B — Interference-Free Monitoring

Time limit: 2 s   Memory limit: 256 MB

## Description

A large mechanical assembly contains **n** toothed wheels (numbered 1 to **n**) and **m** contact points. At each contact point, the teeth of two specific wheels interlock.

The engineers who designed the assembly guarantee that it is fully operational: when power is applied, all wheels can spin continuously without the mechanism binding or seizing up. 

Your objective is to mount monitoring devices on exactly **k** of these wheels. These devices are highly sensitive to proximity. If devices are placed on two wheels that interlock, their signals will distort. Consequently, you cannot mount devices on any two wheels that share a contact point.

Given the required number of devices **k**, determine if there is a way to choose exactly **k** wheels such that no two chosen wheels interlock. If such a configuration exists, you must provide one valid choice of wheels.

## Input

The first line provides three integers **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
Each of the subsequent **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing that wheel **u** and wheel **v** interlock at a contact point. No contact point is given more than once, and the assembly is guaranteed to be fully operational as outlined in the description.

## Output

If it is possible to mount **k** devices without signal distortion, output `YES` on the first line. On the second line, output the **k** distinct wheel numbers you have chosen, separated by spaces. If there are multiple valid configurations, any of them will be accepted.

If no such configuration is possible, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

The graph is strictly guaranteed to be bipartite by the physical non-binding constraint, so finding the maximum independent set remains solvable in polynomial time via maximum bipartite matching.
</PRESERVED_CLASS>
<RISK>
A model might fail to realize that gear networks without binding are mathematically equivalent to bipartite graphs, causing it to misjudge the problem as a general (NP-hard) independent set problem.
