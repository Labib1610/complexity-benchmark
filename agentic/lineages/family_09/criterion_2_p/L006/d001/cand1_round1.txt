# Problem B — Interference-Free Monitoring

Time limit: 2 s   Memory limit: 256 MB

## Description

You are inspecting a complex clockwork apparatus built from **n** gears (labeled 1 through **n**) and **m** engagement points. At each engagement point, the teeth of two specific gears interlock.

The manufacturer has certified that this gear assembly is fully operational: when power is applied, the entire mechanism turns freely without locking up.

Your objective is to mount diagnostic probes onto exactly **k** gears. These probes generate intense magnetic fields, which will disrupt one another if they are mounted on gears that are in direct physical contact. Consequently, you must ensure that no two probed gears interlock.

Given the required number of probes **k**, determine if you can find a valid set of exactly **k** gears to monitor. If such a configuration exists, provide it.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
The next **m** lines each contain two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing an engagement point between gear **u** and gear **v**. No pair of gears is listed more than once, and the assembly is guaranteed to be fully operational as described.

## Output

If exactly **k** gears can be safely monitored, output `YES` on the first line. On the second line, output **k** distinct gear labels separated by spaces. Any valid subset where no two chosen gears interlock is acceptable.

If it is impossible to choose **k** non-interlocking gears, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```
