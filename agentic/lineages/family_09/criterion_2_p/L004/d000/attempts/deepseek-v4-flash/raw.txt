We can model the microservices as a bipartite graph:  
- The two tiers are the two sides of the graph.  
- Conflicts are edges between the two sides.  
- A safe batch is an independent set in this graph.  

Since the graph is bipartite, the maximum independent set size is `n - size_of_minimum_vertex_cover`, which by König’s theorem equals `n - size_of_maximum_matching`.  

But here we don’t need the maximum — we just need to check if we can pick `k` nodes with no edges between them.  

We can find the two color classes (tiers) using BFS/DFS.  
If we pick all nodes from one tier, that’s always safe.  
So the largest safe batch is `max(size_of_tier1, size_of_tier2)`.  
If `k` is ≤ that, we can just output any `k` nodes from the larger tier.  

If `k` is larger than the largest tier, it’s impossible.  

Let’s implement this.  

```python
import sys
from collections import deque

def solve():
    input = sys.stdin.readline
    n, m, k = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    tier0 = []
    tier1 = []
    
    for i in range(n):
        if color[i] == -1:
            color[i] = 0
            q = deque([i])
            tier0.append(i)
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = color[u] ^ 1
                        if color[v] == 0:
                            tier0.append(v)
                        else:
                            tier1.append(v)
                        q.append(v)
    
    if len(tier0) >= k:
        print("YES")
        print(" ".join(str(x+1) for x in tier0[:k]))
    elif len(tier1) >= k:
        print("YES")
        print(" ".join(str(x+1) for x in tier1[:k]))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
