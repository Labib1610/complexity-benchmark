**Solution Explanation**

For the given graph

* vertices `1 … n`
* edges are *conflicts*
* it is guaranteed that the graph has **no odd cycle** – therefore it is **bipartite**

We have to choose exactly `k` vertices such that no two chosen vertices are adjacent
(an *independent set*).  
If it is possible we have to output one such set.



--------------------------------------------------------------------

#### 1.   Observations

* In a bipartite graph the vertices can be coloured with two colours
  (`0` and `1`) – every edge connects vertices of different colours.
* For a bipartite graph the classical theorem of König‑Egérváry holds  

  `size(minimum vertex cover) = size(maximum matching)`

  and  

  `size(maximum independent set) = n – size(maximum matching)`

  (the complement of a minimum vertex cover is a maximum independent set).

* From a **maximum** independent set we can take any `k` of its vertices,
  therefore a solution exists **iff**  

  `k ≤ size(maximum independent set)`.

Consequently we only have to

1. colour the graph,
2. build a bipartite representation,
3. find a **maximum matching** (Hopcroft‑Karp, `O(E·√V)`),
4. from the matching obtain a **minimum vertex cover**,
5. the complement is a **maximum independent set**,
6. output any `k` vertices of that set.



--------------------------------------------------------------------

#### 2.   Algorithm
```
read n , m , k
read all edges
-------------------------------------------------
1) colour the graph (BFS/DFS)
   colour[v] = 0 or 1
   store two lists
        left_vertices  = all vertices with colour 0
        right_vertices = all vertices with colour 1
   also store mapping original_id -> index inside its side
-------------------------------------------------
2) build adjacency list from the left side only
   for each edge (u , v)
        if colour[u] == 0 :   add edge left_idx[u] -> right_idx[v]
        else                :   add edge left_idx[v] -> right_idx[u]
-------------------------------------------------
3) Hopcroft‑Karp
        pairU[0 … L-1] = matched right index or -1
        pairV[0 … R-1] = matched left  index or -1
        returns maximum matching size
-------------------------------------------------
4) minimum vertex cover
   BFS/DFS on the *alternating* graph
        start from every unmatched left vertex
        from a left vertex follow **non‑matched** edges to the right
        from a right vertex follow the **matched** edge back to the left
   visitedL , visitedR  – vertices reached by this search
   minimum vertex cover = (left not visited) ∪ (right visited)
-------------------------------------------------
5) maximum independent set = complement
        independent = (left visited) ∪ (right not visited)
-------------------------------------------------
6) if |independent| ≥ k
        print "YES"
        output first k vertices of the set
   else
        print "NO"
```

All steps are linear or `O(E·√V)` – well inside the limits.



--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
The colouring step produces a proper bipartition of the whole graph.

**Proof.**  
The graph contains no odd cycle, therefore it is bipartite.
A BFS/DFS that colours a start vertex `0` and always gives the opposite colour
to neighbours never meets a conflict, because an odd cycle would be required
to force a vertex to obtain two different colours. ∎



##### Lemma 2  
`pairU , pairV` after the Hopcroft‑Karp phase constitute a **maximum matching**
of the bipartite graph.

**Proof.**  
Hopcroft‑Karp is a well‑known algorithm that repeatedly augments the current
matching along a set of shortest augmenting paths.
It terminates exactly when no augmenting path exists, which is equivalent
to maximality of the matching (Berge’s theorem).  
The algorithm is proven to find a *maximum* matching. ∎



##### Lemma 3  
The BFS described in step&nbsp;4 marks exactly the vertices reachable from
unmatched left vertices by alternating paths
(`non‑matched` edge – `matched` edge – …).

**Proof.**  
The search starts with all unmatched left vertices (alternating path of length 0).  
* From a left vertex it traverses only edges **not** belonging to the matching,
  which is the required first step of an alternating path.
* From a right vertex it traverses only the **matched** edge back to the left,
  which is the second step of an alternating path.
Repeating these two rules yields precisely all vertices that can be reached by
alternating paths, and no other vertex can be reached because any alternating
path must obey the same two rules. ∎



##### Lemma 4  
Let  

`C = (left \ visitedL) ∪ (right ∩ visitedR)`  

be the set built in step&nbsp;4.  
`C` is a **minimum vertex cover** of the graph.

**Proof.**  
König’s theorem gives a constructive way to obtain a minimum vertex cover
from a maximum matching: the set described exactly matches the construction
using the alternating‑path reachable vertices (see e.g. standard textbooks).
By Lemma&nbsp;3 the algorithm computes the same reachable sets, therefore `C`
is a minimum vertex cover. ∎



##### Lemma 5  
`I = (left ∩ visitedL) ∪ (right \ visitedR)` (step&nbsp;5) is a **maximum
independent set**.

**Proof.**  
`I` is the complement of `C`.  
Since `C` is a vertex cover, every edge has at least one endpoint in `C`,
hence no edge has both endpoints in `I`; therefore `I` is independent.  
Because `C` is *minimum*, its complement `I` is *maximum* (König‑Egérváry
theorem). ∎



##### Lemma 6  
If the algorithm prints `YES` and outputs `k` vertices, those vertices form a
valid safe batch.

**Proof.**  
The algorithm prints `YES` only when `|I| ≥ k`.  
It then outputs any `k` vertices taken from `I`.  
By Lemma&nbsp;5 `I` is an independent set, thus any subset of it is also
independent. Consequently the printed vertices contain no conflicting pair. ∎



##### Lemma 7  
If the algorithm prints `NO`, no safe batch of size `k` exists.

**Proof.**  
`NO` is printed only when `|I| < k`.  
`I` is a *maximum* independent set (Lemma&nbsp;5), therefore every independent
set of the graph has size at most `|I|`.  
Hence no independent set of size `k` exists, i.e. a safe batch of size `k`
is impossible. ∎



##### Theorem  
The algorithm always outputs

* `YES` and a correct set of `k` micro‑services **iff** such a set exists,
* otherwise `NO`.

**Proof.**  
*If a set exists.*  
Then the size of a maximum independent set is at least `k`.  
The algorithm computes a maximum independent set `I` (Lemma&nbsp;5) with
`|I| ≥ k` and therefore prints `YES` and a valid subset (Lemma&nbsp;6).

*If no set exists.*  
Then every independent set has size `< k`.  
The algorithm’s `I` is maximum, so `|I| < k` and it prints `NO`
(Lemma&nbsp;7).

Both directions hold, completing the proof. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Colouring* – `O(n + m)`  
*Building adjacency* – `O(m)`  
*Hopcroft‑Karp* – `O(m·√n)` ( ≤ `4·10⁵·316 ≈ 1.3·10⁸` elementary operations)  
*BFS for vertex cover* – `O(n + m)`  

Memory consumption  

* adjacency list (only from left side) – `O(m)`  
* several integer arrays of size `n` – `O(n)`  

Both fit easily into the limits (`256 MiB`).

#### 5.   Reference Implementation  (Python 3)

```python
import sys
import collections

sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))

    edges = [(int(next(it)) - 1, int(next(it)) - 1) for _ in range(m)]

    # ------------------------------------------------------------
    # 1) bipartite colouring
    colour = [-1] * n
    left_vertices = []   # colour 0
    right_vertices = []  # colour 1
    for start in range(n):
        if colour[start] != -1:
            continue
        colour[start] = 0
        q = collections.deque([start])
        while q:
            v = q.popleft()
            for (a, b) in []:  # placeholder, will use edges later
                pass
        # we will colour using adjacency built later (more efficient)
    # Instead of scanning edges repeatedly, build adjacency first (undirected)
    adj_und = [[] for _ in range(n)]
    for u, v in edges:
        adj_und[u].append(v)
        adj_und[v].append(u)

    for start in range(n):
        if colour[start] != -1:
            continue
        colour[start] = 0
        q = collections.deque([start])
        while q:
            v = q.popleft()
            for nb in adj_und[v]:
                if colour[nb] == -1:
                    colour[nb] = colour[v] ^ 1
                    q.append(nb)

    for v in range(n):
        if colour[v] == 0:
            left_vertices.append(v)
        else:
            right_vertices.append(v)

    L = len(left_vertices)
    R = len(right_vertices)

    left_id = [-1] * n
    right_id = [-1] * n
    for idx, v in enumerate(left_vertices):
        left_id[v] = idx
    for idx, v in enumerate(right_vertices):
        right_id[v] = idx

    # ------------------------------------------------------------
    # 2) adjacency from left to right (indices)
    adj = [[] for _ in range(L)]
    for u, v in edges:
        if colour[u] == 0:
            adj[left_id[u]].append(right_id[v])
        else:
            adj[left_id[v]].append(right_id[u])

    # ------------------------------------------------------------
    # 3) Hopcroft‑Karp
    INF = 10 ** 9

    pairU = [-1] * L
    pairV = [-1] * R
    dist = [0] * L

    from collections import deque

    def bfs() -> bool:
        q = deque()
        for u in range(L):
            if pairU[u] == -1:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        reachable = False
        while q:
            u = q.popleft()
            for v in adj[u]:
                pu = pairV[v]
                if pu != -1 and dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    q.append(pu)
                elif pu == -1:
                    reachable = True
        return reachable

    sys.setrecursionlimit(1 << 25)

    def dfs(u: int) -> bool:
        for v in adj[u]:
            pu = pairV[v]
            if pu == -1 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    while bfs():
        for u in range(L):
            if pairU[u] == -1:
                dfs(u)

    # ------------------------------------------------------------
    # 4) minimum vertex cover via alternating BFS
    visL = [False] * L
    visR = [False] * R
    q = deque()
    for u in range(L):
        if pairU[u] == -1:
            visL[u] = True
            q.append(('L', u))

    while q:
        side, idx = q.popleft()
        if side == 'L':
            u = idx
            for v in adj[u]:
                if pairU[u] != v and not visR[v]:
                    visR[v] = True
                    q.append(('R', v))
        else:  # side == 'R'
            v = idx
            pu = pairV[v]
            if pu != -1 and not visL[pu]:
                visL[pu] = True
                q.append(('L', pu))

    # ------------------------------------------------------------
    # 5) maximum independent set = (L visited) ∪ (R not visited)
    independent = []
    for i, v in enumerate(left_vertices):
        if visL[i]:
            independent.append(v + 1)          # back to 1‑based
    for i, v in enumerate(right_vertices):
        if not visR[i]:
            independent.append(v + 1)

    if len(independent) >= k:
        out = ['YES', ' '.join(map(str, independent[:k]))]
        sys.stdout.write('\n'.join(out))
    else:
        sys.stdout.write('NO')


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
