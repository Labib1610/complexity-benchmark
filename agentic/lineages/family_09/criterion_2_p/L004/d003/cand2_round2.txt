# Phase II: Secure Cohort Assembly

Time limit: 2 s   Memory limit: 256 MB

## Description

During our system's automated integration cycle, deploying software modules to the sandbox environment occurs in three distinct phases.

**Phase I: Interference Detection.** A static analyzer evaluates **n** candidate modules (indexed 1 through **n**) and isolates **m** pairs that attempt concurrent writes to the same memory space. These are designated as interfering pairs. Interference is inherently symmetric: if module **u** interferes with **v**, then **v** interferes with **u**. Due to the strict request-response architecture of the modules, it is guaranteed that the resulting network of interferences contains absolutely no cycles of odd length.

**Phase II: Secure Cohort Assembly (Your Objective).** The deployment orchestrator takes the module list and the interference pairs from Phase I. Its goal is to isolate exactly **k** distinct modules to form a "secure cohort". A cohort is deemed secure if and only if absolutely no two modules within it interfere with one another. You must determine whether such a cohort can be successfully assembled, and if so, provide the selection. If multiple secure cohorts of size **k** are possible, providing any one of them is sufficient.

**Phase III: Stress Testing.** The secure cohort verified in Phase II is pushed to an isolated cluster for load testing.

Your implementation is strictly responsible for executing **Phase II**. You will receive the interference report from Phase I and must output a valid cohort selection.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
Each of the subsequent **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing an interfering pair of modules. No pair is listed more than once. It is guaranteed that the interference network formed by these pairs contains no odd-length cycles.

## Output

If a secure cohort of exactly **k** modules can be assembled, output `YES` on the first line. On the second line, output the **k** distinct module indices comprising this cohort, separated by spaces. If multiple valid cohorts of size **k** exist, any one is accepted.

If it is impossible to assemble a secure cohort of size **k**, output `NO`.
