We can model the relays as a bipartite graph:  
- One side is grid A, the other is grid B.  
- Conflicts are edges between the two sides.  

We need to pick exactly `k` vertices with no edges between them — that means we pick some from A and some from B, but we must avoid picking both endpoints of any edge.

A safe set is equivalent to choosing an independent set in a bipartite graph.  
We can check if it’s possible by trying all possible numbers `a` of relays from grid A and `b = k - a` from grid B, and checking if there exists such a selection.

---

**Key idea:**  
If we pick `a` vertices from A, we cannot pick any of their neighbors in B.  
So the maximum number we can pick from B is `|B| - |N(S)|` where `S` is the chosen A-set and `N(S)` is its neighbor set.  
We want to see if we can pick exactly `b` from B.

We can solve this by:
1. Finding the connected components of the bipartite graph.
2. For each component, we know the sizes of its A-side and B-side.
3. We can choose to take some vertices from A-side and some from B-side, but we must avoid conflicts — in a connected component, if we take any A vertex, we cannot take any of its B neighbors, and vice versa.

Actually, in a bipartite graph, the maximum independent set size is `n - maximum matching size` (Kőnig's theorem).  
But here we need *exactly* `k`, not maximum.

---

**Approach:**
- Since the graph is bipartite, we can color it (grid A = color 0, grid B = color 1).
- For each connected component, we know:
  - `cnt0` = number of vertices of color 0
  - `cnt1` = number of vertices of color 1
- In a component, we can choose any number from 0 to `cnt0` from color 0, and any number from 0 to `cnt1` from color 1, **but** if we choose from both sides, we must ensure no edge between chosen vertices.  
  However, in a connected component, if we choose at least one from each side, we might create a conflict.  
  The safe way:  
  - Either take only from color 0 (up to `cnt0`),  
  - Or only from color 1 (up to `cnt1`),  
  - Or take some from both sides but only if the component is a single vertex (no edges).

Actually, in a connected component with at least one edge, you cannot take from both sides without risking a conflict unless you take all from one side and none from the other.  
But you can take *some* from both sides if you carefully avoid edges — but that’s equivalent to finding an independent set in that component, which is not trivial for exact size.

---

**Simpler approach:**  
We can use DP over components:  
For each component, the possible numbers of vertices we can pick are:
- `0` (pick none)
- `1` to `cnt0` (pick only from color 0)
- `1` to `cnt1` (pick only from color 1)

But we can also pick a mix if the component is a single vertex (no edges) — then we can pick 0 or 1.

For components with edges, the only safe choices are:
- Pick only from color 0 (any number from 0 to cnt0)
- Pick only from color 1 (any number from 0 to cnt1)

We cannot mix because any edge would connect a chosen A to a chosen B.

---

So the problem reduces to:  
We have several components, each offering a set of possible sizes we can pick.  
We need to see if we can sum to exactly `k`.

We can do a bitset DP over possible sums.

---

**Implementation steps:**
1. Read input, build adjacency list.
2. Color the graph (0/1) using BFS/DFS.
3. For each component, count `cnt0` and `cnt1`.
4. If `cnt0 + cnt1 == 1` (isolated vertex), possible sizes: {0, 1}.
5. Else possible sizes: {0..cnt0} ∪ {0..cnt1}.
6. Use bitset DP to see if `k` is reachable.
7. If yes, reconstruct the selection.

---

Here’s the code:

```python
import sys
from collections import deque

def solve():
    input = sys.stdin.readline
    n, m, k = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    comps = []
    
    for i in range(n):
        if color[i] == -1:
            # BFS to color component
            q = deque([i])
            color[i] = 0
            cnt0 = 0
            cnt1 = 0
            verts = []
            while q:
                u = q.popleft()
                verts.append(u)
                if color[u] == 0:
                    cnt0 += 1
                else:
                    cnt1 += 1
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = color[u] ^ 1
                        q.append(v)
            comps.append((cnt0, cnt1, verts))
    
    # DP bitset
    possible = 1  # bit 0 set
    for cnt0, cnt1, verts in comps:
        if cnt0 + cnt1 == 1:
            # isolated vertex: can pick 0 or 1
            possible = (possible << 1) | possible
        else:
            # can pick any from 0..cnt0 or 0..cnt1
            mask1 = (1 << (cnt0 + 1)) - 1
            mask2 = (1 << (cnt1 + 1)) - 1
            new_possible = 0
            # shift by each possible pick size
            for s in range(cnt0 + 1):
                new_possible |= (possible << s)
            for s in range(cnt1 + 1):
                new_possible |= (possible << s)
            possible = new_possible
    
    if k > n or not (possible >> k) & 1:
        print("NO")
        return
    
    # Reconstruct
    chosen = []
    # We'll go backwards
    # We need to know which component contributed what
    # So we store the possible states after each component
    dp_states = []
    possible = 1
    for cnt0, cnt1, verts in comps:
        dp_states.append(possible)
        if cnt0 + cnt1 == 1:
            possible = (possible << 1) | possible
        else:
            new_possible = 0
            for s in range(cnt0 + 1):
                new_possible |= (possible << s)
            for s in range(cnt1 + 1):
                new_possible |= (possible << s)
            possible = new_possible
    
    target = k
    for idx in range(len(comps) - 1, -1, -1):
        cnt0, cnt1, verts = comps[idx]
        prev_possible = dp_states[idx]
        if cnt0 + cnt1 == 1:
            # can take 0 or 1
            if target >= 1 and (prev_possible >> (target - 1)) & 1:
                chosen.append(verts[0])
                target -= 1
            # else take 0
        else:
            # try to find s such that prev_possible has bit (target - s)
            found = False
            # try from cnt0 side
            for s in range(cnt0, -1, -1):
                if target >= s and (prev_possible >> (target - s)) & 1:
                    # take s vertices from color 0
                    cnt_taken = 0
                    for v in verts:
                        if color[v] == 0 and cnt_taken < s:
                            chosen.append(v)
                            cnt_taken += 1
                    target -= s
                    found = True
                    break
            if not found:
                for s in range(cnt1, -1, -1):
                    if target >= s and (prev_possible >> (target - s)) & 1:
                        cnt_taken = 0
                        for v in verts:
                            if color[v] == 1 and cnt_taken < s:
                                chosen.append(v)
                                cnt_taken += 1
                        target -= s
                        break
    
    print("YES")
    print(" ".join(str(x + 1) for x in chosen))

if __name__ == "__main__":
    solve()
```
