# Subsystem Activation Protocol

Time limit: 2 s   Memory limit: 256 MB

## Description

You are tasked with safely initializing a network of **n** communication relays, which are identified by integers from 1 to **n**. Your goal is to select exactly **k** of these relays to activate, leaving the remaining relays powered down.

The system's power distribution is imperfect, resulting in **m** known hardware conflicts. Each conflict is a specific pair of relays that share a delicate power bus. If you activate both relays in a conflicting pair at the same time, the bus will overload. Consequently, your chosen group of **k** active relays must be completely free of these conflicts.

Given the large number of relays, testing every possible combination of size **k** will exceed the time limit. You need an efficient way to find a safe activation set, if one exists.

The occurrence of conflicts is dictated by the internal hardware design. Each relay is permanently aligned to one of four magnetic orientations: North, South, East, or West. A power bus overload can only happen between two relays if their magnetic orientations are strictly orthogonal (for instance, a North-oriented relay might conflict with an East-oriented or West-oriented relay). Relays whose orientations are collinear (falling on the same North-South or East-West axis) are fundamentally incapable of interfering with each other. The exact magnetic orientation of each individual relay is hidden from you, but you are guaranteed that all **m** provided conflicts strictly obey this physical limitation.

## Input

The first line provides three integers: **n** (the number of relays), **m** (the number of potential conflicts), and **k** (the target number of relays to activate), where 1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, and 1 ≤ k ≤ n.

Following this, there are **m** lines. Each line contains two distinct integers **u** and **v** (1 ≤ u, v ≤ n), indicating that activating relay **u** and relay **v** simultaneously will cause an overload. The list of conflicts contains no duplicates and is guaranteed to be consistent with the magnetic orientation rules explained above.

## Output

If there is at least one way to safely activate exactly **k** relays, output `YES` on the first line. On the second line, output **k** distinct integers representing the relays to activate, separated by spaces. If multiple valid selections exist, you may output any of them.

If it is impossible to find a safe set of exactly **k** relays, output `NO`.

## Examples

### Example 1

**Input**

```

**Output**

```

```

```

**Output**
```

```
