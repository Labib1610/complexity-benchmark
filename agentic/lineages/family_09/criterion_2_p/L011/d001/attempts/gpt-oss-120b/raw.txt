**Solution Explanation**

For every edge `{u , v}` the two ends must obtain opposite polarities `+1 , -1`.
Therefore the whole graph is *bipartite* – it can be coloured with two colours
`0` and `1` such that every edge connects vertices of different colours.
The required polarity assignment is exactly such a 2‑colouring, it is only
guaranteed to exist, we have to find it.

--------------------------------------------------------------------

#### 1.   Independent set in a bipartite graph  

In a bipartite graph all vertices of the same colour are pairwise non‑adjacent,
hence any colour class is an *independent* (interference‑free) set.
For one connected component let  

* `C0` – vertices coloured `0`, size `a`
* `C1` – vertices coloured `1`, size `b`

From this component we may take **either** the whole `C0` **or** the whole `C1`
(and nothing else), both choices are independent.
For the whole graph we have to decide, component after component, which colour
class we keep.

--------------------------------------------------------------------

#### 2.   Reducing the problem to a subset sum  

If we always keep the larger colour class of each component we obtain the
*maximum* possible independent set size  

```
MAX = Σ  max(a_i , b_i)
```

If `MAX < k` the answer is impossible.

Otherwise we have to **shrink** this set to exactly `k` vertices.
For component `i`

```
larger side size = L_i = max(a_i , b_i)
smaller side size = S_i = min(a_i , b_i)
difference          d_i = L_i - S_i   ( ≥ 0 )
```

Starting from the maximal set (all larger sides) we may *switch* component `i`
to its smaller side and lose exactly `d_i` vertices.
We have to lose

```
R = MAX - k
```

vertices, i.e. we need a subset of the numbers `d_i` whose sum is `R`.
That is the classic **subset‑sum** problem.

--------------------------------------------------------------------

#### 3.   Subset sum with a bitset and reconstruction  

`R ≤ n ≤ 100 000`, therefore a bitset of `R+1` bits fits easily into a Python
integer (`int` has arbitrary length).

```
dp   – integer, bit s is 1  ⇔  sum s is reachable
from – array[0..R] , from[s] = index of the component that first created sum s
```

initially `dp = 1` (only sum 0 reachable).

For every component `i` with difference `d = d_i` :

```
shifted = dp << d                # all previously reachable sums increased by d
new     = shifted & ~dp          # sums that become reachable *now*
while new != 0:
        low = new & -new         # lowest set bit
        s   = low.bit_length() - 1
        from[s] = i
        new -= low
dp |= shifted
```

Each sum is written exactly once, therefore the total work of the inner loop
is `O(R)` over the whole algorithm.

After processing all components `R` is reachable iff bit `R` of `dp` is set.
If not – answer `NO`.

Otherwise we reconstruct the chosen components by walking backwards:

```
cur = R
while cur > 0:
        i   = from[cur]          # component i must be switched
        take_small[i] = True
        cur -= d_i
```

`take_small[i]` tells whether we finally keep the smaller colour class of
component `i`.

--------------------------------------------------------------------

#### 4.   Building the answer  

* colour the graph (BFS/DFS) – O(n+m)
* store for every component the two colour lists `C0 , C1`
* compute `L_i , S_i , d_i`
* run the subset‑sum DP described above
* if possible, compose the final independent set  

```
for each component i:
        if take_small[i]:
                add all vertices of the smaller side
        else:
                add all vertices of the larger side
```

The set size is exactly `k`.  
Any order of the vertices is acceptable.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct set iff such a set
exists.

---

##### Lemma 1  
The input graph is bipartite and the BFS/DFS colouring produces a proper
2‑colouring.

**Proof.**  
The statement of the problem guarantees the existence of a polarity
assignment with opposite signs on every edge, i.e. a 2‑colouring.
A graph that admits a 2‑colouring is bipartite, and any BFS/DFS that colours
neighbouring vertices with opposite colours yields such a colouring. ∎



##### Lemma 2  
For a connected component `i` the two colour classes `C0 , C1` are both
independent sets, and any independent set contained in the component is a
subset of one of them.

**Proof.**  
All edges go between the two colour classes, never inside a class, therefore
each class is independent.  
If an independent set contained vertices of both colours, two of them would be
adjacent (by definition of a component), contradiction. ∎



##### Lemma 3  
Let `MAX = Σ max(|C0|,|C1|)`.  
There exists an independent set of size `k` **iff** `k ≤ MAX` and the number
`R = MAX - k` can be expressed as a sum of the differences `d_i = |C0|-|C1|` (absolute
value) of some components.

**Proof.**  

*If* part:  
Take for every component the larger colour class – we have `MAX` vertices.
Switch exactly the components whose differences sum to `R`; each switch reduces
the total size by its `d_i`. After all switches the size is `MAX - R = k`.
By Lemma&nbsp;2 the set stays independent.

*Only‑if* part:  
Consider any independent set `I` of size `k`.  
Inside each component `i` it is contained wholly in one colour class, say the
smaller one for some components and the larger one for the others.
Hence  

```
k = Σ (chosen side size) = Σ L_i  - Σ_{switched} d_i = MAX - Σ_{switched} d_i
```

Thus `R = MAX - k = Σ_{switched} d_i` is a sum of a subset of the differences. ∎



##### Lemma 4  
The DP with bitset marks exactly the sums that can be obtained as a sum of a
subset of the differences `d_i`.

**Proof.**  
Induction over processed components.  
Base: before any component only sum `0` is reachable – true.  
Induction step: assume after processing first `t` components `dp` marks precisely
the sums achievable with those `t` differences.
Adding component `t+1` with difference `d` creates exactly the sums
`previous_sum + d`. The operation `shifted = dp << d` represents this set,
and `dp | shifted` adds them to the reachable sums.
No other sums are added. ∎



##### Lemma 5  
If bit `R` is set after the DP, the reconstruction using the `from` array
produces a subset of components whose differences sum to `R`.

**Proof.**  
`from[s]` is stored exactly when sum `s` becomes reachable for the first time,
and it records the component that contributed the last added difference `d`.
Therefore `s = previous + d` with `previous` already reachable before this
component. Walking backwards subtracts the stored `d` and moves to the previous
sum, repeating until `0` is reached. The collected components are exactly those
used to build `R`. ∎



##### Lemma 6  
If the algorithm outputs a set, it is independent and has size `k`.

**Proof.**  
Construction uses for each component either its larger or its smaller colour
class, never mixing colours inside a component. By Lemma&nbsp;2 each chosen
class is independent, and different components have no edges between them,
so the union is independent.

The number of taken vertices equals  

```
Σ L_i  - Σ_{switched} d_i = MAX - R = k
```

by Lemma&nbsp;5. ∎



##### Lemma 7  
If an independent set of size `k` exists, the algorithm prints `YES`.

**Proof.**  
Existence implies `k ≤ MAX` and, by Lemma&nbsp;3, `R` is a sum of a subset of
the differences. By Lemma&nbsp;4 the DP marks sum `R`, therefore the algorithm
finds it reachable and reconstructs a suitable subset, finally printing `YES`. ∎



##### Theorem  
The program prints  

* `YES` and a correct interference‑free set of exactly `k` nodes  
  **iff** such a set exists,
* otherwise prints `NO`.

**Proof.**  
*If* the program prints `YES`, Lemma&nbsp;6 guarantees the printed set is
independent and of size `k`.  

*Only‑if* an independent set of size `k` exists, Lemma&nbsp;7 shows the program
will find the required subset of differences and therefore output `YES`.  
If the program prints `NO`, the DP did not reach sum `R`; by Lemma&nbsp;4 no
subset of differences yields `R`, and by Lemma&nbsp;3 no independent set of
size `k` can exist. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Colouring* : `O(n + m)` time, `O(n + m)` memory.  
*DP* : bitset length `R ≤ n`, each component causes one shift and a constant
number of integer operations → `O((n/word) * number_of_components)` which is
`O(n·(n/64))` in the worst theoretical sense, but in practice a single shift
on a Python `int` of ≤ 100 000 bits is `O(n/word)` ≈ 1500 elementary operations.
Overall time `O(n + m + n·(n/word))` ≤ `O( n·(n/64) )` ≈ `2·10⁶` operations,
well inside the limits.  

Memory: adjacency list `O(n + m)`, colour lists `O(n)`, DP bitset `O(n/8)`
≈ 12 KB, `from` array `O(n)` integers. Total well below 256 MB.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); k = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * n
    comps = []          # list of (list0, list1)
    from collections import deque
    for start in range(n):
        if color[start] != -1:
            continue
        q = deque([start])
        color[start] = 0
        list0 = []
        list1 = []
        while q:
            v = q.popleft()
            if color[v] == 0:
                list0.append(v)
            else:
                list1.append(v)
            for to in adj[v]:
                if color[to] == -1:
                    color[to] = color[v] ^ 1
                    q.append(to)
        comps.append((list0, list1))

    # compute maximal independent set size and differences
    diffs = []          # d_i
    larger = []         # list of vertices of larger side
    smaller = []        # list of vertices of smaller side
    max_sum = 0
    for c0, c1 in comps:
        if len(c0) >= len(c1):
            larger.append(c0)
            smaller.append(c1)
            d = len(c0) - len(c1)
        else:
            larger.append(c1)
            smaller.append(c0)
            d = len(c1) - len(c0)
        diffs.append(d)
        max_sum += len(larger[-1])

    if k > max_sum:
        print("NO")
        return

    R = max_sum - k          # amount to reduce
    if R == 0:
        # take all larger sides
        ans = []
        for lst in larger:
            ans.extend(lst)
        print("YES")
        print(' '.join(str(v + 1) for v in ans[:k]))
        return

    # subset sum DP with reconstruction info
    dp = 1                   # bit 0 set
    from_idx = [-1] * (R + 1)   # which component created this sum
    for idx, d in enumerate(diffs):
        if d == 0:
            continue
        shifted = dp << d
        new = shifted & ~dp
        # iterate over set bits of new
        while new:
            low = new & -new
            s = low.bit_length() - 1
            if s <= R:
                from_idx[s] = idx
            new -= low
        dp |= shifted
        # early stop if R already reachable
        if (dp >> R) & 1:
            break

    if (dp >> R) & 1 == 0:
        print("NO")
        return

    # reconstruct which components to switch to smaller side
    take_small = [False] * len(comps)
    cur = R
    while cur:
        idx = from_idx[cur]
        take_small[idx] = True
        cur -= diffs[idx]

    # build answer
    ans = []
    for i, (big, small) in enumerate(zip(larger, smaller)):
        if take_small[i]:
            ans.extend(small)
        else:
            ans.extend(big)
    ans = ans[:k]   # just in case (should be exactly k)
    print("YES")
    print(' '.join(str(v + 1) for v in ans))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
