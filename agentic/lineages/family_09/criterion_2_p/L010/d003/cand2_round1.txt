# Problem B — Disconnected Assembly

Time limit: 2 s   Memory limit: 256 MB

## Description

You are tasked with configuring a system of **n** modules, numbered 1 through **n**. The system contains **m** bidirectional conflict channels. If two modules are connected by a conflict channel, they cannot both be activated at the same time.

The system's architecture guarantees a specific structural property: it is mathematically possible to assign a non-zero real number to each module such that for every conflict channel, the values assigned to its two endpoints sum to exactly zero. These internal values are not provided to you, only the guarantee of their existence.

You need to activate exactly **k** modules such that no two activated modules share a conflict channel. Such a selection is called a **conflict-free** configuration.

Determine whether a conflict-free configuration of exactly **k** modules is possible, and if so, identify one valid configuration.

## Input

The first line provides three integers: **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
Following this are **m** lines, each containing two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing a conflict channel between module **u** and module **v**. It is guaranteed that no channel appears more than once, and that the entire system adheres to the value cancellation property described.

## Output

If it is possible to select exactly **k** modules that form a conflict-free configuration, output `YES` on the first line. On the second line, output the **k** distinct module identifiers of your chosen configuration, separated by single spaces. If multiple conflict-free configurations of size **k** exist, any valid one will be accepted.

If no such configuration can be formed, output `NO` on a single line.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```
