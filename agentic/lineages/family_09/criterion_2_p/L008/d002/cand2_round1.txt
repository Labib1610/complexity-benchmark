# Problem B — Mutually Disconnected Collection

Time limit: 2 s   Memory limit: 256 MB

## Description

A system has **n** elements (numbered 1..n) and **m** bidirectional links. Each link joins two elements.

The system's architecture guarantees that there exists a valid assignment of an integer energy level to each element such that for every link, the two connected elements have energy levels that differ by exactly 1. (These energy levels are not provided in the input; you only know such an assignment exists).

A collection of elements is **mutually disconnected** if no two elements in the collection share a link.

Given a target size **k**, decide whether a mutually disconnected collection of exactly **k** elements exists, and if so report one.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v): a link. No link is listed twice, and the links are guaranteed to be consistent with the energy level property described above.

## Output

If a mutually disconnected collection of **k** elements exists, print `YES` on the first line, then on the second line print **k** distinct element numbers forming such a collection, separated by spaces. Any collection in which no two elements are linked is accepted.

If no such collection exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

## Note

In Example 1, elements 1 and 2 (which could for instance both be assigned energy level 0 while 3 and 4 are assigned 1) are not linked. In Example 3, the largest mutually disconnected collection has only 2 elements, so a target of 3 is impossible.

<RATIONALE>
The surviving model relied on the explicit "boolean state" and "opposite states" keywords to immediately recognize the graph as bipartite and apply bipartite-specific algorithms (like BFS two-coloring and Hopcroft-Karp). To remove this affordance without changing the actual inputs or complexity class, I replaced the boolean state guarantee with an integer energy level guarantee where linked elements must differ by exactly 1. This forces the model to mathematically deduce that such an assignment implies the graph has no odd cycles (since parity must alternate), and thus is bipartite, before it can safely use a polynomial-time matching algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that linked elements have integer values differing by exactly 1 is mathematically equivalent to the graph being bipartite, meaning the underlying graphs and valid independent sets are exactly the same as in the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains Maximum Independent Set on bipartite graphs (which is in P via König's theorem), as the structural guarantee of bipartiteness is preserved through the integer difference property.
</PRESERVED_CLASS>
