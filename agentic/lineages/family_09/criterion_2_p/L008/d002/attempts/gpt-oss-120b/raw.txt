**Solution Explanation**

For every cable we have to decide a direction (one‑way signal).  
The statement guarantees that this can be done so that each node is

* either a **transmitter** – all incident cables go out of it,
* or a **receiver** – all incident cables go into it.

For a cable `{u,v}` the direction must be from a transmitter to a receiver,
therefore the two ends of every cable belong to different groups.
Consequently the whole graph is *bipartite* and the converse is also true:
any bipartite graph can be oriented from the left side to the right side.
So the given graph is bipartite (maybe disconnected).

--------------------------------------------------------------------

#### 1.   Independent set in a bipartite graph
In a bipartite graph the two colour classes contain **no edges inside**.
Hence **any subset of one colour class is an independent set**.
For a connected component let  

* `C0` – vertices coloured `0`, size `a`
* `C1` – vertices coloured `1`, size `b`

Choosing the whole larger class (`max(a,b)`) gives the biggest independent
set inside this component.
For the whole graph we may do this independently for every component,
obtaining an independent set of size  

```
S = Σ  max(size(C0), size(C1))          (over all components)
```

If `S < k` we can never reach `k` vertices – answer `NO`.

Otherwise `S ≥ k`.  
Take the vertices of the larger colour class of each component
(the set we built above).  
Removing arbitrary vertices from an independent set keeps it independent,
therefore we can delete `S‑k` vertices and obtain a set of exactly `k`
vertices.

So the whole problem reduces to

* colour the graph (BFS/DFS),
* for each component keep the larger colour class,
* if the total number of kept vertices is at least `k` output any `k` of them,
  otherwise output `NO`.

--------------------------------------------------------------------

#### 2.   Algorithm
```
read n, m, k
build adjacency list
colour[1…n] = -1
answer = empty list

for each vertex v = 1 … n
    if colour[v] == -1
        BFS from v
        collect vertices of colour 0 in list L0, colour 1 in L1
        if |L0| >= |L1|
               answer.extend(L0)
        else   answer.extend(L1)

if len(answer) < k
        print "NO"
else
        print "YES"
        print first k numbers of answer
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
The input graph is bipartite.

**Proof.**  
The statement says that the edges can be oriented so that each vertex is
either a pure source or a pure sink.
Every oriented edge goes from a source to a sink, therefore its two ends
belong to different groups (sources vs. sinks).  
Thus the undirected graph has a 2‑colouring – it is bipartite. ∎



##### Lemma 2  
For a connected component `C` with colour classes `C0, C1`,
any subset of `C0` (or of `C1`) is an independent set in the whole graph.

**Proof.**  
All edges of a bipartite graph join vertices of different colour classes,
so there is no edge whose both ends lie inside `C0` (or inside `C1`).
Consequently any subset of one class contains no adjacent pair. ∎



##### Lemma 3  
Let `S` be the set built by the algorithm (the larger colour class of each
component).  
`S` is an independent set and `|S| = Σ  max(|C0|,|C1|)`.

**Proof.**  
Inside each component we take only vertices of a single colour class,
hence by Lemma&nbsp;2 they are pairwise non‑adjacent.
Different components have no edges between them, therefore the union
`S` is also independent.
The size formula follows directly from the construction. ∎



##### Lemma 4  
If `|S| ≥ k` then the algorithm can output an independent set of size exactly
`k`.

**Proof.**  
Remove arbitrarily `|S|-k` vertices from `S`.  
Removing vertices cannot create new edges, so the remaining set is still
independent and its size is `k`. ∎



##### Lemma 5  
If `|S| < k` then **no** independent set of size `k` exists in the graph.

**Proof.**  
For each component the maximum size of an independent set is
`max(|C0|,|C1|)` (any larger set would contain two vertices of different
colour classes and thus an edge).  
Summing over all components gives an absolute upper bound `|S|` for any
independent set in the whole graph.
If `|S| < k` this bound is smaller than `k`; therefore a set of size `k`
cannot exist. ∎



##### Theorem  
The algorithm prints  

* `NO` iff the graph has no independent set of size `k`,
* otherwise prints `YES` and a list of `k` vertices forming an independent
  set.

**Proof.**  

*If the algorithm prints `NO`.*  
That happens exactly when `|S| < k`.  
By Lemma&nbsp;5 no independent set of size `k` exists, so the answer `NO`
is correct.

*If the algorithm prints `YES`.*  
Then `|S| ≥ k`.  
By Lemma&nbsp;4 the algorithm can (and does) output `k` vertices from `S`,
which form an independent set (Lemma&nbsp;3).  
Thus the printed set is valid.

Both directions are proved, completing the theorem. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*BFS/DFS* visits every vertex and edge once: `O(n + m)` time.  
All other operations are linear in `n`.  

Memory consumption: adjacency list `O(n + m)`, colour array `O(n)`,
temporary lists for one component at a time `O(size of component) ≤ O(n)`.  
Overall `O(n + m)` memory, well below the limits.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 = unvisited, 0/1 = colour
    answer = []                     # vertices of the larger colour class per component

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        q = deque([start])
        colour[start] = 0
        part = [[], []]              # vertices of colour 0 and 1 in this component
        part[0].append(start)

        while q:
            v = q.popleft()
            cv = colour[v]
            for to in adj[v]:
                if colour[to] == -1:
                    colour[to] = cv ^ 1
                    part[colour[to]].append(to)
                    q.append(to)
                # the input guarantees bipartiteness, no conflict check needed

        # keep the larger colour class
        if len(part[0]) >= len(part[1]):
            answer.extend(part[0])
        else:
            answer.extend(part[1])

    if len(answer) < k:
        sys.stdout.write("NO\n")
    else:
        sys.stdout.write("YES\n")
        sys.stdout.write(' '.join(map(str, answer[:k])) + '\n')


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
