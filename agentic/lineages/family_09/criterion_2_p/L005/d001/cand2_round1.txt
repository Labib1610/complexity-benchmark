# Problem B — Safe Antenna Activation

Time limit: 2 s
Memory limit: 256 MB

## Description

An installation features **n** transmission antennas, identified by integers from 1 to **n**. When powered on concurrently, specific pairs of these antennas interact to cause destructive interference. A comprehensive registry of **m** such interacting pairs is provided.

The installation incorporates an underlying phase-shift mechanism. Every antenna possesses an innate, immutable phase parameter fixed at either $+1$ or $-1$. The physical constraints of the array dictate that destructive interference can only manifest between a pair of antennas if the sum of their phase parameters evaluates to exactly zero. While the individual phase parameters are not disclosed, you are guaranteed that at least one valid global assignment of these parameters exists for the given array.

You must determine whether there is a way to power on exactly **k** antennas such that the selected group is entirely free of destructive interference. If a valid group can be formed, you must also output the identifiers of the chosen antennas.

## Input

The first line provides three integers **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
The subsequent **m** lines each contain two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), denoting a pair of antennas that produce destructive interference. No pair is duplicated in the input. The provided network of pairs is strictly guaranteed to adhere to the phase-shift mechanism outlined above.

## Output

If a safe combination of exactly **k** antennas exists, print `YES` on the first line. On the second line, print **k** distinct, space-separated integers corresponding to the antennas in your combination. Any valid combination is acceptable if several exist.

If it is impossible to find exactly **k** antennas without interference, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

<RATIONALE>
I removed the explicit mention of partitioning the array into two distinct bands, which acted as a direct keyword trigger for identifying a bipartite graph. Instead, the bipartite structure is presented algebraically: each antenna has an undisclosed phase parameter of +1 or -1, and interference only occurs when the sum of parameters for a pair is exactly zero. This forces the model to logically deduce the two-colorable structure rather than relying on surface-level pattern matching of the word "partition".
</RATIONALE>
<PRESERVED_ANSWER>
The problem still asks for an independent set of size exactly k in the identical interference graph, so any valid set of non-interfering antennas remains exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The graph is still structurally guaranteed to be bipartite (as edges only connect +1 to -1), so finding a maximum independent set remains solvable in polynomial time via König's theorem and maximum bipartite matching.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "can only manifest if the sum is exactly zero" as implying that *every* pair summing to zero interferes, rather than just the pairs explicitly provided in the input, though the text mitigates this by clarifying the input acts as a "comprehensive registry".
</RISK>
