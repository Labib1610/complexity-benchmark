**Solution Explanation**

For the given graph

* there is **no odd cycle** → the graph is *bipartite*,
* we have to choose exactly `k` vertices with no edge inside the chosen set
  (an *independent set*).

--------------------------------------------------------------------

#### 1.   From bipartite graph to maximum independent set  

For a bipartite graph `G = (L ∪ R , E)`

```
size(maximum independent set) = |V| – size(minimum vertex cover)
```

and by **Kőnig’s theorem**

```
size(minimum vertex cover) = size(maximum matching)
```

Therefore

```
maxInd = n – size(maximum matching)
```

If `k > maxInd` the answer is impossible.

If `k ≤ maxInd` we only have to **produce any independent set of size k**.
From a maximum matching we can obtain a *minimum vertex cover* in linear time,
hence also a *maximum independent set* (the complement of the cover).
Taking any `k` vertices from that set is a valid answer.

--------------------------------------------------------------------

#### 2.   Algorithm
```
1. read the graph
2. colour it with two colours (0 / 1) by BFS – the graph is guaranteed bipartite
   → left part = colour 0, right part = colour 1
3. run Hopcroft‑Karp on the bipartite graph, obtain a maximum matching M
4. from M build a minimum vertex cover C
        (standard BFS/DFS from all unmatched left vertices,
         using alternating non‑matched / matched edges)
5. independent = V \ C                # maximum independent set
6. if k > |independent| → print "NO"
   else
        print "YES"
        output any k vertices from `independent`
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
The colouring step produces a bipartition `L,R` of the whole graph.

**Proof.**  
The graph contains no odd cycle, therefore it is bipartite.  
BFS colours each visited vertex opposite to its predecessor; because there is
no odd cycle, no conflict appears and every edge connects vertices of different
colours. ∎



##### Lemma 2  
`M` returned by Hopcroft‑Karp is a maximum matching of the bipartite graph.

**Proof.**  
Hopcroft‑Karp is a classic algorithm that repeatedly augments along a set of
shortest augmenting paths. It terminates exactly when no augmenting path
exists, which is equivalent to maximality of the matching (Berge’s theorem).
Its correctness is well‑known. ∎



##### Lemma 3  
The set `C` constructed in step&nbsp;4 is a minimum vertex cover.

**Proof.**  
Let `U` be the set of unmatched vertices on the left side.
Perform a DFS/BFS from `U` using  

* non‑matched edges from left to right,
* matched edges from right to left.

Let `Z` be the set of all visited vertices.
Standard König’s theorem proof shows that  

```
C = (L \ Z) ∪ (R ∩ Z)
```

covers every edge and has size `|M|`.  
Since any vertex cover has size at least the size of a maximum matching,
`C` is minimum. ∎



##### Lemma 4  
`I = V \ C` is an independent set of size `n – |M|`.

**Proof.**  
`C` is a vertex cover, therefore every edge has at least one endpoint in `C`.
Consequently no edge has both endpoints in `I = V \ C`; thus `I` is independent.
`|I| = n – |C| = n – |M|`. ∎



##### Lemma 5  
If `k ≤ |I|` the algorithm outputs an independent set of size exactly `k`.

**Proof.**  
The algorithm selects any `k` vertices from `I`.  
By Lemma&nbsp;4 `I` is independent, any subset of an independent set is also
independent, hence the printed set is independent and its size is `k`. ∎



##### Lemma 6  
If `k > |I|` no independent set of size `k` exists.

**Proof.**  
`|I| = n – |M|` is the size of a *maximum* independent set (Kőnig’s theorem).
No independent set can be larger. ∎



##### Theorem  
The algorithm prints  

* “YES” and a correct set of `k` antennas **iff** such a set exists,
* otherwise prints “NO”.

**Proof.**  

*If the algorithm prints “YES”.*  
It happened because `k ≤ |I|`. By Lemma&nbsp;5 the printed vertices form an
independent set of size `k`. Hence a feasible selection exists.

*If a feasible selection exists.*  
Let `S` be any independent set of size `k`. By Lemma&nbsp;6 we must have
`k ≤ |I|`. The algorithm therefore reaches the “YES” branch and outputs a
valid set. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*BFS colouring* : `O(n + m)`  
*Hopcroft‑Karp* : `O(m √n)` ( ≤ 4·10⁵·√10⁵ ≈ 1.3·10⁸ operations, fits 2 s)  
*Cover construction* : `O(n + m)`  
*Output* : `O(k)`

Memory consumption: adjacency lists `O(n + m)` plus a few integer arrays,
well below 256 MB.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); k = int(next(it))
    adj = [[] for _ in range(n)]
    edges = []
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
        edges.append((u, v))

    # 1. bipartition by BFS
    colour = [-1] * n
    left = []
    right = []
    for start in range(n):
        if colour[start] != -1:
            continue
        dq = deque([start])
        colour[start] = 0
        while dq:
            v = dq.popleft()
            for to in adj[v]:
                if colour[to] == -1:
                    colour[to] = colour[v] ^ 1
                    dq.append(to)
    for v in range(n):
        if colour[v] == 0:
            left.append(v)
        else:
            right.append(v)

    # build adjacency from left to right
    L = len(left)
    R = len(right)
    idL = [-1] * n
    idR = [-1] * n
    for i, v in enumerate(left):
        idL[v] = i
    for i, v in enumerate(right):
        idR[v] = i

    g = [[] for _ in range(L)]
    for u, v in edges:
        if colour[u] == 0:
            g[idL[u]].append(idR[v])
        else:
            g[idL[v]].append(idR[u])

    # 2. Hopcroft‑Karp
    INF = 10 ** 9
    pairU = [-1] * L
    pairV = [-1] * R
    dist = [0] * L

    def bfs() -> bool:
        dq = deque()
        for u in range(L):
            if pairU[u] == -1:
                dist[u] = 0
                dq.append(u)
            else:
                dist[u] = INF
        reachable = False
        while dq:
            u = dq.popleft()
            for v in g[u]:
                pu = pairV[v]
                if pu != -1 and dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    dq.append(pu)
                if pu == -1:
                    reachable = True
        return reachable

    def dfs(u: int) -> bool:
        for v in g[u]:
            pu = pairV[v]
            if pu == -1 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(L):
            if pairU[u] == -1 and dfs(u):
                matching += 1

    # 3. minimum vertex cover from the matching
    # start from unmatched left vertices
    visL = [False] * L
    visR = [False] * R
    dq = deque()
    for u in range(L):
        if pairU[u] == -1:
            dq.append(u)
            visL[u] = True
    while dq:
        u = dq.popleft()
        for v in g[u]:
            if not visR[v]:
                visR[v] = True
                pu = pairV[v]
                if pu != -1 and not visL[pu]:
                    visL[pu] = True
                    dq.append(pu)

    # cover = (L \ visited) ∪ (R ∩ visited)
    independent = []
    for i, v in enumerate(left):
        if not visL[i]:
            independent.append(v + 1)
    for i, v in enumerate(right):
        if visR[i]:
            independent.append(v + 1)

    if k > len(independent):
        print("NO")
        return
    print("YES")
    print(' '.join(map(str, independent[:k])))

if __name__ == "__main__":
    solve()
```
