# Problem B — Interference-Free Cluster (Phase Alternation)

Time limit: 2 s   Memory limit: 256 MB

## Description

You are evaluating a communication network consisting of **n** devices (labeled 1 through n) and **m** bidirectional interference links. When two devices share a link, they disrupt each other's signals.

The hardware operates using signal phase shifts. Because of how these phase shifts align, the network topology is strictly alternating: any closed loop of interference links in the network will always contain an even number of links. 

Your objective is to identify a silent cluster of devices. A cluster is considered **interference-free** if absolutely no interference links exist between any pair of devices within the cluster.

Given a desired cluster size **k**, determine if it is possible to select exactly **k** devices that are completely interference-free with respect to each other, and if so, output one such selection.

## Input

The first line provides three integers: **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n).
Following this are **m** lines, each containing two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing an interference link between device **u** and device **v**. 
No link appears more than once. It is guaranteed that the provided network adheres to the even-loop phase property described above.

## Output

If you can form an interference-free cluster of exactly **k** devices, output `YES` on the first line. On the second line, print the **k** distinct device labels that make up the cluster, separated by spaces. Any valid cluster of size **k** is acceptable.

If no such cluster can be formed, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

## Note

This task shares its core objective with Problem A, but the network's strictly alternating phase structure (ensuring only even-length loops) enables an efficient exact solution. In Example 1, devices 1 and 2 do not share a link and thus do not interfere. In Example 3, the largest possible interference-free cluster contains exactly 2 devices, meaning a target of 3 is impossible.
