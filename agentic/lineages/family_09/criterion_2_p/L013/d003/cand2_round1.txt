# Problem B — Component Activation

Time limit: 2 s
Memory limit: 256 MB

## Description

You are in charge of bringing a distributed sensor array online. The array contains **n** modules, indexed from 1 to **n**. The system requires exactly **k** modules to be powered on to reach its operational threshold.

Some modules cannot be active at the same time due to destructive resonance. You have a diagnostic report detailing **m** pairs of modules that will resonate destructively if both are powered on. An acceptable configuration must strictly avoid activating any two modules that appear together in this report.

The structural constraints of the array prevent asymmetric resonance cascades. The diagnostic report guarantees that if you trace any continuous path of resonance links that forms a closed loop (starting and ending at the identical module), the total number of links traversed in that loop is always an even number.

You must establish whether a safe configuration of exactly **k** modules exists and, if so, identify one.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n), representing the number of modules, the number of resonance links, and the target number of modules to power on.

Each of the following **m** lines provides two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), meaning that module **u** and module **v** will resonate destructively. No pair is repeated. All resonance links strictly comply with the even-length loop guarantee described above.

## Output

If a safe configuration of exactly **k** modules is possible, print `YES` on the first line. On the second line, print **k** distinct integers separated by spaces, denoting the modules to power on. If multiple such configurations exist, you may output any single one.

If no such configuration is possible, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

<RATIONALE>
The previous framing explicitly stated that modules were divided into "two separate containment zones" and links only crossed between them, which models easily mapped to the definition of a bipartite graph. I replaced this with the equivalent graph-theoretic property that any closed loop of resonance links has an even length, forcing the model to deduce bipartiteness from the absence of odd cycles rather than pattern-matching the "two sets" keyword.
</RATIONALE>
<PRESERVED_ANSWER>
The problem still requires finding an independent set of size k in the provided graph, so all valid module configurations and their existences remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
A graph where all closed loops have an even number of edges is exactly a bipartite graph, so the problem remains Maximum Independent Set on bipartite graphs, which is solvable in polynomial time via König's theorem.
</PRESERVED_CLASS>
<RISK>
Models might interpret "any continuous path that forms a closed loop" as referring exclusively to simple cycles, but since a graph lacks odd closed walks if and only if it lacks odd simple cycles, the structural guarantee is mathematically identical and unambiguous.
</RISK>
