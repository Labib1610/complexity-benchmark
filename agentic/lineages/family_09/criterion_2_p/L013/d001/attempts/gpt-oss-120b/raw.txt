**Solution Explanation**

For every pair `(u , v)` given in the input the two modules resonate only if the
difference of their (hidden) frequencies is odd.
Therefore the two modules have opposite parity of the frequency, i.e. the whole
graph is *bipartite*.
The task is to find an independent set (no edge inside) of exactly `k`
vertices or to decide that it does not exist.



--------------------------------------------------------------------

#### 1.   From independent set to vertex cover  

For a graph `G`

```
|maximum independent set| = |V| – |minimum vertex cover|
```

In a bipartite graph the size of a minimum vertex cover equals the size of a
*maximum matching* (Kőnig’s theorem).

Consequences  

* let `M` be a maximum matching, `|M| = mm`.
* the smallest possible vertex cover has size `mm`.
* therefore the largest possible independent set has size `n – mm`.

So a set of `k` safe modules exists **iff**  

```
mm ≤ n – k          (1)
```

If (1) holds we can obtain a minimum vertex cover from the maximum matching,
take its complement – that is a maximum independent set – and output any `k`
vertices from it.



--------------------------------------------------------------------

#### 2.   Building the bipartition  

The input does not tell us which vertex belongs to which side.
We colour the graph with two colours by a BFS/DFS (standard bipartite check).
Because the input is guaranteed to be bipartite the colouring always succeeds.
All vertices with colour `0` are put into the *left* part, colour `1` into the
*right* part.



--------------------------------------------------------------------

#### 3.   Maximum matching – Hopcroft‑Karp  

`n ≤ 10⁵ ,  m ≤ 4·10⁵`.  
Hopcroft‑Karp runs in `O( m √n )`, easily fast enough.

Implementation details  

* adjacency list `g[left]` – only edges from left to right are stored.
* arrays `pairU` (size `n+1`) and `pairV` – matched partner or `0`.
* BFS builds distance layers, DFS augments along shortest alternating paths.



--------------------------------------------------------------------

#### 4.   Minimum vertex cover from a maximum matching  

Standard construction:

```
Z = set of vertices reachable from an unmatched left vertex
    by alternating paths (edges not in M, then edges in M, …)

minimum vertex cover = (Left \ Z) ∪ (Right ∩ Z)
```

We run a BFS/DFS on the *alternating* graph using the already built matching.



--------------------------------------------------------------------

#### 5.   Construct the answer  

* `cover` = vertices of the minimum vertex cover.
* `indep` = all vertices `1 … n` not in `cover`.
* `|indep| = n – mm`  (by theorem).

If `|indep| ≥ k` we output `YES` and the first `k` vertices of `indep`,
otherwise `NO`.



--------------------------------------------------------------------

#### 6.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
The colouring step produces a bipartition `(L,R)` of the whole graph.

**Proof.**  
All edges connect vertices whose frequency difference is odd, i.e. vertices of
different parity. Hence the graph is bipartite. A BFS that colours a start
vertex `0` and always gives the opposite colour to neighbours never meets a
conflict, because such a conflict would be an odd cycle, impossible in a
bipartite graph. ∎



##### Lemma 2  
`mm` returned by Hopcroft‑Karp equals the size of a maximum matching of the
graph.

**Proof.**  
Hopcroft‑Karp is a known algorithm that repeatedly finds a maximal set of
shortest augmenting paths; it terminates exactly when no augmenting path
exists, i.e. when the current matching is maximum (Berge’s theorem). ∎



##### Lemma 3  
The set `cover` constructed in step&nbsp;4 is a minimum vertex cover.

**Proof.**  
For bipartite graphs the classical König construction states exactly the set
described above is a minimum vertex cover when the matching used is maximum.
The algorithm follows that construction, therefore `cover` is minimum. ∎



##### Lemma 4  
`indep = V \ cover` is a maximum independent set and `|indep| = n – mm`.

**Proof.**  
In any graph a vertex cover and an independent set are complementary:
no edge can have both ends outside a cover, therefore the complement of a
cover is independent.  
Because `cover` is minimum, its complement is maximum independent.
By Lemma&nbsp;3 `|cover| = mm`, hence `|indep| = n – mm`. ∎



##### Lemma 5  
If the algorithm outputs `YES` and a set `S` of `k` vertices, then `S` is a
valid configuration (no resonating pair).

**Proof.**  
`S` is taken from `indep`, which is an independent set (Lemma&nbsp;4).  
Thus no edge of the graph has both ends in `S`; consequently no resonating
pair is activated. ∎



##### Lemma 6  
If the algorithm outputs `NO` then no safe configuration of size `k` exists.

**Proof.**  
`NO` is printed exactly when `mm > n – k`.  
Assume a safe configuration `T` of size `k` existed.
`T` is an independent set, therefore its complement `V\T` is a vertex cover of
size `n – k`.  
A minimum vertex cover cannot be larger, so `mm = |minimum cover| ≤ n – k`,
contradicting `mm > n – k`. ∎



##### Theorem  
The algorithm prints `YES` and a correct set of `k` modules
iff such a set exists; otherwise it prints `NO`.

**Proof.**  

*If the algorithm prints `YES`*: by Lemma&nbsp;5 the printed set is safe,
hence a solution exists.

*If a solution exists*: let `T` be any independent set of size `k`.  
Then `mm ≤ n – k` (argument of Lemma&nbsp;6).  
The algorithm therefore does **not** output `NO`.  
Since `|indep| = n – mm ≥ k`, it can select `k` vertices from `indep` and
outputs `YES`.  

Thus the output is correct in both directions. ∎



--------------------------------------------------------------------

#### 7.   Complexity Analysis  

*Colouring* : `O(n + m)`  
*Hopcroft‑Karp* : `O( m √n )`  
*Building the cover* : `O(n + m)`  

Overall time `O( m √n )` ≤ `4·10⁵·√10⁵ ≈ 1.3·10⁸` operations, well inside 2 s
in PyPy / CPython with optimised code.

Memory: adjacency list `O(n + m)`, several integer arrays `O(n)`.  
Total ≤ `~ 5·10⁵` integers → < 10 MB.



--------------------------------------------------------------------

#### 8.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); k = int(next(it))

    adj = [[] for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)
        edges.append((u, v))

    # 1. bipartition
    color = [-1] * (n + 1)
    left = []
    right = []
    for start in range(1, n + 1):
        if color[start] != -1:
            continue
        q = deque([start])
        color[start] = 0
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
        # no need to check conflict, guaranteed bipartite

    for v in range(1, n + 1):
        if color[v] == 0:
            left.append(v)
        else:
            right.append(v)

    # map vertex id to index in left/right arrays
    left_id = {v: i for i, v in enumerate(left)}
    right_id = {v: i for i, v in enumerate(right)}

    L = len(left)
    R = len(right)
    g = [[] for _ in range(L)]
    for u, v in edges:
        if color[u] == 0:
            g[left_id[u]].append(right_id[v])
        else:
            g[left_id[v]].append(right_id[u])

    # 2. Hopcroft‑Karp
    INF = 10 ** 9
    pairU = [-1] * L
    pairV = [-1] * R
    dist = [0] * L

    def bfs() -> bool:
        q = deque()
        for u in range(L):
            if pairU[u] == -1:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        found = False
        while q:
            u = q.popleft()
            for v in g[u]:
                pu = pairV[v]
                if pu != -1 and dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    q.append(pu)
                if pu == -1:
                    found = True
        return found

    def dfs(u: int) -> bool:
        for v in g[u]:
            pu = pairV[v]
            if pu == -1 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(L):
            if pairU[u] == -1 and dfs(u):
                matching += 1

    # 3. minimum vertex cover
    # start from unmatched left vertices, follow alternating paths
    visited_left = [False] * L
    visited_right = [False] * R
    q = deque()
    for u in range(L):
        if pairU[u] == -1:
            q.append(('L', u))
            visited_left[u] = True
    while q:
        side, idx = q.popleft()
        if side == 'L':
            for v in g[idx]:
                if not visited_right[v] and pairU[idx] != v:  # edge not in matching
                    visited_right[v] = True
                    if pairV[v] != -1 and not visited_left[pairV[v]]:
                        visited_left[pairV[v]] = True
                        q.append(('L', pairV[v]))
        else:  # right side, we only reach right via non‑matching edges, so no further moves
            pass

    cover = set()
    # left not visited
    for i, v in enumerate(left):
        if not visited_left[i]:
            cover.add(v)
    # right visited
    for i, v in enumerate(right):
        if visited_right[i]:
            cover.add(v)

    indep = [v for v in range(1, n + 1) if v not in cover]

    if len(indep) >= k:
        print("YES")
        print(' '.join(map(str, indep[:k])))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
