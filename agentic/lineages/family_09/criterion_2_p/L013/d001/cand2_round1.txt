# Problem B — Component Activation

Time limit: 2 s
Memory limit: 256 MB

## Description

You are tasked with configuring a large-scale distributed array consisting of **n** components (numbered 1 to **n**). To meet the operational threshold, your monitoring system must select exactly **k** components to activate.

However, certain pairs of components are known to cause destructive interference if activated simultaneously. You are provided with a list of **m** interference links. A valid operational configuration must not contain any pair of components that interfere with each other. 

The array's main registry allocates exactly 100,000 memory slots for components, establishing the maximum possible number of components. There must be at least one component in the array. The interference logging module is built with a maximum capacity of exactly 400,000 link records, meaning the number of logged links can be anywhere from zero up to this limit. The target number of components to activate, **k**, must be at least one and cannot exceed the total number of components **n**. 

With the array at maximum capacity, the number of possible **k**-component combinations is $\binom{n}{k}$. This search space grows immensely and can easily exceed $10^{5000}$ for the given limits, meaning brute-force enumeration of subsets is impossible. You must find a way to determine if a collision-free subset of size **k** exists without exhaustively checking combinations.

Additionally, the array is built using a dual-architecture design. While the manufacturer did not provide the internal specifications of each component in the input, it is guaranteed by the physical design that any sequence of consecutive interference links that starts and ends at the same component will always consist of an even number of links.

Given **k**, determine if there is a valid configuration of exactly **k** components, and if so, output one such configuration.

## Input

The first line contains three integers **n**, **m**, and **k**, representing the number of components, the number of interference links, and the target number of components to activate. The valid ranges for these variables are strictly defined by the physical limits of the registry and logging module described above.

Each of the next **m** lines contains two integers **u** and **v**, indicating that component **u** and component **v** interfere with each other. All component identifiers are valid numbers from 1 to **n**, and a component will never be listed as interfering with itself. No interference link is listed more than once. It is guaranteed that the interference links adhere to the structural property described above.

## Output

If a valid configuration of exactly **k** components exists, print `YES` on the first line. On the second line, print **k** distinct integers separated by spaces, representing the component numbers to activate. If there are multiple valid subsets, you may output any of them.

If no such configuration is possible, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```
5 0 5
```

**Output**
```
YES
1 2 3 4 5
```

### Example 3

**Input**
```
4 4 3
1 3
1 4
2 3
2 4
```

**Output**
```
NO
```

<RATIONALE>
Removed the explicit mention of "opposite polarities" which directly spoon-fed the bipartite property to the model, replacing it with the structural definition of bipartite graphs (all closed sequences of interference links are of even length). The suggestion to explicitly permit odd cycles was ignored, as doing so would change the complexity class to NP-complete, violating Hard Constraint 3. Additionally, applied Strategy S07 to define all numeric bounds through physical registry limits rather than direct inequalities, forcing the model to extract the constraints from the text.
</RATIONALE>
<PRESERVED_ANSWER>
The problem still asks for an independent set of size k in exactly the same graphs, so the valid outputs remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The graph is still guaranteed to have no odd cycles (making it bipartite), so finding a maximum independent set remains solvable in polynomial time via Hopcroft-Karp and König's theorem.
</PRESERVED_CLASS>
<RISK>
The phrase "sequence of consecutive interference links" could theoretically be misinterpreted if a reader doesn't realize it applies to all possible paths that form a cycle, but it is the standard non-jargon translation of "no odd cycles".
</RISK>
