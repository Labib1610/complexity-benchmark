**Solution Explanation**

For every component we have to decide whether it is activated (`chosen`) or not.
The given interference links form a graph `G`.  
The statement guarantees that `G` is *bipartite*: all edges join vertices of
different (unknown) polarities.  
In a bipartite graph an **independent set** (no two chosen vertices are joined
by an edge) is exactly the complement of a **vertex cover**
(every edge has at least one endpoint in the cover).

--------------------------------------------------------------------

#### 1.   From independent set to matching  

For a bipartite graph

```
size(minimum vertex cover) = size(maximum matching)          (Kőnig)
size(maximum independent set) = n – size(maximum matching)
```

Therefore a set of `k` vertices without interference exists **iff**

```
maximum matching size ≤ n – k .
```

So we only have to compute a maximum matching.

--------------------------------------------------------------------

#### 2.   Building the bipartition  

The graph is guaranteed bipartite, but the two sides are not given.
A simple BFS/DFS colours every connected component with colours `0 / 1`.
All edges go between different colours – we keep the colour `0` vertices as
the *left* side, colour `1` as the *right* side.

During this step we also store for every original vertex its index inside
its side (`left_id[v]` or `right_id[v]`).  
Later we build the adjacency list **only from left to right** – this is the
input needed by the Hopcroft‑Karp algorithm.

--------------------------------------------------------------------

#### 3.   Hopcroft‑Karp – maximum matching in `O(E·√V)`  

`L = |left| , R = |right| , V = L+R = n , E = m`.

The classic Hopcroft‑Karp implementation is used:

* `pairU[u]` – right vertex matched with left `u` (`-1` = free)
* `pairV[v]` – left vertex matched with right `v`
* BFS builds distance layers from all free left vertices,
  stopping when a free right vertex is reached.
* DFS (recursive, depth ≤ length of an augmenting path) augments
  along the layered graph.

The algorithm finishes with a maximum matching `Msize`.

--------------------------------------------------------------------

#### 4.   Minimum vertex cover and a maximum independent set  

From a *maximum* matching we obtain a *minimum* vertex cover
by the standard alternating‑path construction:

```
Z = vertices reachable from a free left vertex
    by alternating   (non‑matched edge left→right, matched edge right→left)
minimum vertex cover = (Left \ Z) ∪ (Right ∩ Z)
maximum independent set = (Left ∩ Z) ∪ (Right \ Z)
```

The independent set has exactly `n – Msize` vertices,
the largest possible one.

--------------------------------------------------------------------

#### 5.   Answer  

*If* `n – Msize ≥ k` we output **YES** and any `k` vertices of the
independent set (the first `k` are enough).  
Otherwise no independent set of size `k` exists – output **NO**.

--------------------------------------------------------------------

#### 6.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
The colouring step produces a bipartition `(L,R)` of the whole graph.

**Proof.**  
The input graph is bipartite (given).  
BFS colours each connected component with two colours, never assigning the
same colour to the two ends of an edge.  
All vertices receive a colour, therefore the two colour classes together
contain every vertex and every edge connects different colours. ∎



##### Lemma 2  
`Msize` returned by Hopcroft‑Karp equals the size of a maximum matching of `G`.

**Proof.**  
Hopcroft‑Karp is a well‑known algorithm that repeatedly finds a maximal set
of shortest augmenting paths and augments along all of them.
It terminates exactly when no augmenting path exists, i.e. when the current
matching is maximum (Berge’s theorem). ∎



##### Lemma 3  
The set `I = (Left ∩ Z) ∪ (Right \ Z)` constructed in step&nbsp;4 is an
independent set of size `n – Msize`.

**Proof.**  
Standard theorem for bipartite graphs (Kőnig) states that the construction
above yields a *minimum* vertex cover `C = (Left \ Z) ∪ (Right ∩ Z)`.
Every edge has at least one endpoint in `C`, therefore no edge has both
endpoints in its complement `V \ C`.  
`I = V \ C`, so `I` is independent.
Because `|C| = Msize` (minimum vertex cover size equals maximum matching size),
`|I| = n – Msize`. ∎



##### Lemma 4  
If `n – Msize ≥ k` the algorithm outputs a valid set of `k` vertices.

**Proof.**  
By Lemma&nbsp;3 the independent set `I` has at least `k` vertices.
The algorithm prints the first `k` vertices of `I`.  
All printed vertices belong to `I`, thus no printed pair is joined by an
interference edge – the set is independent and has exactly `k` vertices. ∎



##### Lemma 5  
If `n – Msize < k` no independent set of size `k` exists.

**Proof.**  
`n – Msize` is the size of a *maximum* independent set (Lemma&nbsp;3).
If this maximum is smaller than `k`, any independent set is smaller than `k`,
hence a set of size `k` cannot exist. ∎



##### Theorem  
The program prints  

* “YES” and a list of `k` component numbers **iff** a collision‑free
  configuration of exactly `k` components exists;  

* otherwise prints “NO”.

**Proof.**  

*If the program prints “YES”.*  
It happened because `n – Msize ≥ k`.  
By Lemma&nbsp;4 the printed vertices form an independent set of size `k`,
hence a valid configuration exists.

*If a valid configuration of size `k` exists.*  
Then an independent set of size `k` exists, therefore the maximum independent
set size is at least `k`.  
By Lemma&nbsp;3 this maximum size equals `n – Msize`, so `n – Msize ≥ k`.
Consequently the program will enter the “YES” branch and output a set of
`k` vertices.

*If the program prints “NO”.*  
It means `n – Msize < k`.  
By Lemma&nbsp;5 no independent set of size `k` exists, thus no valid
configuration exists.

Both directions hold, completing the proof. ∎



--------------------------------------------------------------------

#### 7.   Complexity Analysis  

*Colouring* – `O(n + m)` time, `O(n + m)` memory.  
*Hopcroft‑Karp* – `O(m·√n)` time, `O(m + n)` memory.  
*Construction of the independent set* – `O(n + m)` time, `O(n)` memory.

Overall  

```
Time   : O(m·√n)   ≤ 4·10⁵·√10⁵  ≈ 1.3·10⁸ elementary operations
Memory : O(n + m)  ≤ 5·10⁵ integers  (well below 256 MiB)
```

Both satisfy the limits.

#### 8.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

sys.setrecursionlimit(1_000_000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))

    adj_all = [[] for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj_all[u].append(v)
        adj_all[v].append(u)
        edges.append((u, v))

    # 1. colour the graph (bipartition)
    colour = [-1] * (n + 1)          # 0 = left, 1 = right
    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        colour[start] = 0
        q = deque([start])
        while q:
            u = q.popleft()
            cu = colour[u]
            for v in adj_all[u]:
                if colour[v] == -1:
                    colour[v] = cu ^ 1
                    q.append(v)

    # 2. build left/right lists and mapping to indices
    left_vertices = []
    right_vertices = []
    left_id = [-1] * (n + 1)
    right_id = [-1] * (n + 1)

    for v in range(1, n + 1):
        if colour[v] == 0:
            left_id[v] = len(left_vertices)
            left_vertices.append(v)
        else:
            right_id[v] = len(right_vertices)
            right_vertices.append(v)

    L = len(left_vertices)
    R = len(right_vertices)

    # adjacency from left to right (by indices)
    adj = [[] for _ in range(L)]
    for u, v in edges:
        if colour[u] == 0:
            lu = left_id[u]
            rv = right_id[v]
        else:
            lu = left_id[v]
            rv = right_id[u]
        adj[lu].append(rv)

    # 3. Hopcroft‑Karp
    INF = 10 ** 9
    pairU = [-1] * L
    pairV = [-1] * R
    dist = [0] * L

    def bfs() -> bool:
        q = deque()
        for u in range(L):
            if pairU[u] == -1:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        reachable_free = False
        while q:
            u = q.popleft()
            for v in adj[u]:
                pu = pairV[v]
                if pu != -1 and dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    q.append(pu)
                elif pu == -1:
                    reachable_free = True
        return reachable_free

    def dfs(u: int) -> bool:
        for v in adj[u]:
            pu = pairV[v]
            if pu == -1 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(L):
            if pairU[u] == -1 and dfs(u):
                matching += 1

    # 4. Build Z (vertices reachable from free left vertices via alternating paths)
    visitedL = [False] * L
    visitedR = [False] * R
    q = deque()
    for u in range(L):
        if pairU[u] == -1:
            visitedL[u] = True
            q.append(('L', u))

    while q:
        typ, idx = q.popleft()
        if typ == 'L':
            u = idx
            for v in adj[u]:
                if pairU[u] == v:          # matched edge, skip
                    continue
                if not visitedR[v]:
                    visitedR[v] = True
                    q.append(('R', v))
        else:  # 'R'
            v = idx
            pu = pairV[v]
            if pu != -1 and not visitedL[pu]:
                visitedL[pu] = True
                q.append(('L', pu))

    # 5. Independent set = (Left ∩ Z) ∪ (Right \ Z)
    independent = []
    for i, v in enumerate(left_vertices):
        if visitedL[i]:
            independent.append(v)
    for i, v in enumerate(right_vertices):
        if not visitedR[i]:
            independent.append(v)

    if len(independent) >= k:
        print("YES")
        print(' '.join(map(str, independent[:k])))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
