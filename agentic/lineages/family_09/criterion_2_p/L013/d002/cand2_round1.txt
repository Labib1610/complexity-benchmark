<STATEMENT>
# Problem B — Component Activation

Time limit: 2 s
Memory limit: 256 MB

## Description

You are in charge of bringing a distributed sensor array online. The array contains **n** modules, indexed from 1 to **n**. The system requires exactly **k** modules to be powered on to reach its operational threshold.

Some modules cannot be active at the same time due to destructive resonance. You have a diagnostic report detailing **m** pairs of modules that will resonate destructively if both are powered on. An acceptable configuration must strictly avoid activating any two modules that appear together in this report.

The modules were engineered to run on various integer frequency bands, which are hidden from you. However, the system's physical constraints guarantee that destructive resonance is only possible between two modules if the area of a right-angled triangle with leg lengths equal to $|f_u + f_v|$ and $|f_u - f_v|$ is not a whole number, where $f_u$ and $f_v$ are their respective frequency bands.

Because **n** can be as large as 100,000, the number of ways to choose **k** modules is astronomically large (upwards of $10^{5000}$). Exhaustive search is completely unfeasible. You must establish whether a safe configuration of exactly **k** modules exists and, if so, identify one.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 100000, 0 ≤ m ≤ 400000, 1 ≤ k ≤ n), representing the number of modules, the number of resonance links, and the target number of modules to power on.

Each of the following **m** lines provides two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), meaning that module **u** and module **v** will resonate destructively. No pair is repeated. The resonance links strictly follow the triangle area rule described above.

## Output

If a safe configuration of exactly **k** modules is possible, print `YES` on the first line. On the second line, print **k** distinct integers separated by spaces, denoting the modules to power on. If multiple such configurations exist, you may output any single one.

If no such configuration is possible, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 2
1 3
1 4
2 3
2 4
```

**Output**
```
YES
1 2
```

### Example 2

**Input**
```

```

**Output**
```
YES

```

### Example 3

**Input**
```
4 4 3
1 3

2 4
```

**Output**
```
NO
```

<RATIONALE>
The original statement explicitly noted that destructive resonance only occurs when the difference between frequency bands is an odd integer. Models easily recognized this as a bipartite graph guarantee, since edges only exist between even and odd frequencies. Because this rule defines the input structure, removing it entirely would change the stated complexity class to NP-hard (Maximum Independent Set on general graphs). Instead, I re-presented the bipartite guarantee geometrically: resonance only occurs if a right-angled triangle with legs $|f_u + f_v|$ and $|f_u - f_v|$ has a non-integer area. This mathematically requires $f_u$ and $f_v$ to have different parities (since Area = $0.5 |f_u^2 - f_v^2|$), preserving the exact same bipartite structure while forcing models to genuinely deduce the parity relationship rather than pattern-match the word "odd".
</RATIONALE>
<PRESERVED_ANSWER>
The exact same pairs of modules resonate because the condition that the triangle's area is not a whole number is mathematically equivalent to the original condition that the frequency difference is an odd integer, leaving the conflict graph identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The graph remains strictly bipartite (edges only exist between modules with even and odd frequencies), so finding the maximum independent set remains in P via König's theorem.
</PRESERVED_CLASS>
<RISK>
Models might fail to deduce the parity relationship from the triangle area condition and assume the graph is general, leading them to attempt NP-hard algorithms or heuristics that time out or fail.
</RISK>
