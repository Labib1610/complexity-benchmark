# Problem A — Neural Layer Configuration

Time limit: 5 s   Memory limit: 256 MB

## Description

You are optimizing a discrete neural layer consisting of **n** binary neurons (labeled 1 to **n**). You must configure the layer by setting exactly **k** neurons to the active state ($x = 1$). The remaining **n** − **k** neurons must be set to the resting state ($x = 0$).

The layer contains **m** interference bounds. Each bound restricts the joint activation of a specific pair of neurons. During the forward pass, a bound between neuron **u** and neuron **v** generates an error penalty calculated via a squared shifted-ReLU function:

$\mathcal{L}_{u,v} = \max(0, x_u + x_v - 1)^2$

The total network loss is the sum of the error penalties from all **m** interference bounds. A layer configuration is considered valid if the total network loss is exactly 0.

Determine whether you can activate exactly **k** neurons to achieve a valid layer configuration. If so, output one valid set of active neurons.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ **n** ≤ 46, 0 ≤ **m** ≤ **n**·(**n**−1)/2, 1 ≤ **k** ≤ **n**).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), specifying the two neurons involved in an interference bound. No pair of neurons is restricted by more than one bound.

## Output

If a valid configuration of exactly **k** active neurons is possible, print `YES` on the first line. On the second line, print the **k** distinct neuron labels that form this configuration, separated by spaces. If multiple valid configurations exist, you may print any one of them (in any order).

If no such configuration is possible, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

In Example 2, activating neurons 1, 3, and 5 results in a valid layer. For the bound on (1, 2), the sum of their states is $x_1 + x_2 = 1 + 0 = 1$, giving a penalty of $\max(0, 1 - 1)^2 = 0$. For the bound on (3, 4), the sum is $x_3 + x_4 = 1 + 0 = 1$, giving a penalty of 0. The total network loss is 0. In Example 1, any configuration of 3 active neurons will cause at least one bound to evaluate to $\max(0, 1 + 1 - 1)^2 = 1$, resulting in a positive total loss.

The squared shifted-ReLU function evaluates to 1 if both neurons are active and 0 otherwise, which perfectly mirrors the original collision fault logic, ensuring all valid configurations remain exactly the same.
