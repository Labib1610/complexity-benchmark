# Problem A — Network Asymmetry Stability

Time limit: 5 s   Memory limit: 256 MB

## Description

A software system consists of **n** modules (labeled 1 to **n**). You need to configure a deployment by upgrading exactly **k** of these modules. Modules that are not upgraded remain in their standard state.

The system architecture includes **m** critical links. Each link connects a specific pair of modules. 
For any module, its *link capacity* is a fixed value defined as the total number of critical links connected to it in the architecture.

Each module has an assigned *power factor* based on its state:
- An upgraded module has a power factor of 2.
- A standard module has a power factor of 1.

For each critical link, its *link load* is the product of the power factors of the two modules it connects.
The *total system load* is the sum of the link loads of all **m** critical links.

To ensure system stability, the configuration must satisfy a strict load-balancing equation: the total system load must be exactly equal to **m** plus the sum of the link capacities of all upgraded modules.

Determine whether you can upgrade exactly **k** modules to achieve a stable configuration. If so, output one valid set of upgraded modules.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ **n** ≤ 46, 0 ≤ **m** ≤ **n**·(**n**−1)/2, 1 ≤ **k** ≤ **n**).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), specifying the two modules connected by a critical link. No pair of modules is connected by more than one link.

## Output

If a stable configuration of exactly **k** modules is possible, print `YES` on the first line. On the second line, print the **k** distinct module labels that form this configuration, separated by spaces. If multiple stable configurations exist, you may print any one of them (in any order).

If no such configuration is possible, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

In Example 2, upgrading modules 1, 3, and 5 yields a stable configuration. The upgraded modules have link capacities of 1, 1, and 0 respectively, summing to 2. The link between 1 and 2 has a load of 2 (power factors 2 and 1), and the link between 3 and 4 has a load of 2 (power factors 2 and 1). The total system load is 4. This exactly matches **m** (2) plus the sum of the capacities (2). 

In Example 1, any combination of three modules will result in a total system load strictly greater than **m** plus the sum of the link capacities of the chosen modules, failing the stability condition.
</STATEMENT>
<RATIONALE>
The direct equation `asymmetric_links == sum(capacities)` was a known standard form that models easily mapped to the cut-size property of an independent set. I replaced it with a weighted product sum over all edges (`total_load == m + sum(capacities)`). This new equation is mathematically identical to requiring zero edges between upgraded modules, but forcing models to derive this equivalence through algebraic substitution rather than pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The total system load expands to 4*E(U,U) + 2*E(U,S) + 1*E(S,S), which equals m + 3*E(U,U) + E(U,S); equating this to m + sum(capacities) simplifies exactly to E(U,U) = 0, meaning the solution set is still exactly the independent sets of size k.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying mathematical requirement remains finding an independent set of size k in a general graph, which is NP-complete.
</PRESERVED_CLASS>
