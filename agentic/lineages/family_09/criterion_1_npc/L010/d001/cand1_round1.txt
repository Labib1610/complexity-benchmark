# Problem A — Isolated Monitoring Array

Time limit: 5 s   Memory limit: 256 MB

## Description

A facility deploys a network of **n** monitoring devices (labeled 1 through n). Due to overlapping transmission frequencies, there are **m** known signal conflicts. Each conflict indicates that a specific pair of devices cannot be active simultaneously without disrupting each other's readings.

An isolated monitoring array is a subset of devices chosen such that no two devices in the subset share a signal conflict.

Your task is to determine if it is possible to activate an isolated monitoring array consisting of exactly **k** devices. If it is possible, identify the devices that form it.

## Input

The first line provides the integers **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
Following this are **m** lines, each containing two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v) representing a signal conflict between device **u** and device **v**. The input will not list the same conflict more than once.

## Output

If an isolated monitoring array of exactly **k** devices can be formed, output `YES` on the initial line. On the subsequent line, output the **k** distinct labels of the devices included in the array, separated by a space. 

If it is impossible to form such an array, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```
