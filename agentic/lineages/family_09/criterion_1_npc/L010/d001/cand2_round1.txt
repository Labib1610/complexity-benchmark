<STATEMENT>
# Problem A — Isolated Chamber Selection

Time limit: 5 s   Memory limit: 256 MB

## Description

A research facility has **n** testing chambers, numbered sequentially starting from 1. The facility's capacity **n** is a strictly positive integer, bounded above by the atomic number of the chemical element Palladium.

Some pairs of chambers share a ventilation duct, causing potential cross-contamination. There are **m** such ducts in total. The value of **m** can be as low as zero, and extends up to the theoretical limit where every distinct pair of chambers shares exactly one duct.

An upcoming experiment requires a perfectly isolated group of exactly **k** chambers. The target size **k** is at least one and cannot exceed the total number of chambers **n**. A group of chambers is considered perfectly isolated if no two chambers within the group share a ventilation duct.

Given the target size **k**, you must determine whether a perfectly isolated group of exactly **k** chambers exists. If there are multiple valid groups of this size, you are required to report the lexicographically smallest group (comparing the groups after sorting their chamber numbers in ascending order).

## Input

The first line contains three integers **n**, **m**, and **k**, whose valid ranges are defined by the physical and theoretical limits described above.
Each of the next **m** lines contains two integers **u** and **v**, representing a ventilation duct that connects chamber **u** and chamber **v**. Each duct connects two distinct chambers (their identifiers are distinct integers from 1 to **n**). No duct is listed more than once in the input.

## Output

If a perfectly isolated group of exactly **k** chambers exists, print `YES` on the first line. On the second line, print the **k** distinct chamber numbers forming the lexicographically smallest such group, sorted in ascending order and separated by spaces.
If no such group exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

In Example 2, chambers 1, 3, and 5 do not share any ventilation ducts among themselves, and `1 3 5` is the lexicographically smallest such group. In Example 1, no three of the four chambers are mutually perfectly isolated.

I replaced the explicit numeric bounds with indirect facts (e.g., the atomic number of Palladium for 46) to force the model to derive the constraints itself rather than pattern-matching on bare inequalities. Following the suggested removal, I also changed the output requirement from accepting any valid collection to strictly requiring the lexicographically smallest one; this removes the affordance of terminating the search immediately upon finding the first arbitrary valid set, forcing a more rigorous search or branch-and-bound exploration.
</RATIONALE>
