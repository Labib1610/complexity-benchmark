**Solution Explanation**

For every pair `{u , v}` given in the input the product `x_u·x_v` is a term of the
function.  
The function is `0` **iff** the chosen vertices contain **no** such pair,
i.e. the chosen vertices form an **independent set** of the graph whose edges are
the given pairs.

The task is therefore:

*given a graph with `n ≤ 46` vertices, does it contain an independent set of
exact size `k` ?*  
If it exists we have to output one such set.



--------------------------------------------------------------------

#### 1.   Meet‑in‑the‑middle

`n` is too large for a naïve `O(2^n)` enumeration, but `2^{23}` is easily
manageable.
We split the vertex set into two halves  

```
left  : vertices 0 … L-1          (L = n//2,   L ≤ 23)
right : vertices L … n-1          (R = n-L,    R ≤ 23)
```

All edges are of three kinds  

* inside the left half,
* inside the right half,
* between the halves.

For each half we enumerate **all** its independent subsets.
For the left half we will later try to combine each of its subsets with a
compatible subset of the right half.



--------------------------------------------------------------------

#### 2.   Independent subsets of one half – DP over bitmasks  

For a half with `h` vertices (`h ≤ 23`) we store for every mask `M (0 ≤ M < 2^h)`

```
size[M] = size of the independent set represented by M,
          or -1 if M is NOT independent
```

The recurrence is

```
let b = lowest set bit of M
let v = index of b                (0 … h-1)
let P = M without b   (= M ^ b)

M is independent  ⇔  P is independent  AND  (adj[v] & P) == 0
```

`adj[v]` is a bitmask of vertices of the same half that are adjacent to `v`.
The whole table is built in `O(2^h)` time.



--------------------------------------------------------------------

#### 3.   From right‑side subsets to a “maximum inside a mask” table  

For the right half we need, for **any** set of allowed vertices `A`,
the largest independent subset that lies completely inside `A`.

We first fill two arrays for the right half

```
bestSize[mask] = size[mask]   if mask is independent, else -1
bestMask[mask] = mask         if independent, else 0
```

Then we run a classic SOS‑DP (subset‑over‑superset DP)

```
for each bit i:
    for each mask:
        if mask has bit i:
            sub = mask ^ (1<<i)
            if bestSize[sub] > bestSize[mask]:
                bestSize[mask] = bestSize[sub]
                bestMask[mask] = bestMask[sub]
```

After the loops `bestSize[A]` is the maximum size of an independent right‑side
subset contained in `A`, and `bestMask[A]` is one concrete subset achieving it.
Complexity `O(R·2^R)` ≤ `23·2^23` ≈ `2·10^8` elementary operations – fast enough
in PyPy / CPython with simple integer operations.



--------------------------------------------------------------------

#### 4.   Trying all left subsets  

For every left mask `Lmask` that is independent

```
szL   = size[Lmask]
need  = k - szL                (how many vertices still required)
if need < 0 : continue
```

All right vertices that are **forbidden** because of edges from the chosen left
vertices are collected in a mask `forbidden`.  
The allowed vertices are

```
allowed = allRightMask ^ forbidden
```

If `bestSize[allowed] ≥ need` we have found a solution:

* left part = `Lmask`
* right part = any independent subset of size `need` inside `allowed`,
  obtained from `bestMask[allowed]` (maybe larger – we can simply drop
  arbitrary vertices to reach exactly `need`).

The total size becomes exactly `k`.  
We stop at the first found solution.



--------------------------------------------------------------------

#### 5.   Reconstructing the answer  

`bestMask[allowed]` may be larger than `need`.  
We iterate over its bits and keep the first `need` vertices – any subset works
because all of them are independent and also independent from the left part.

Finally we translate the internal 0‑based indices back to the required
1‑based vertex numbers and output them.



--------------------------------------------------------------------

#### 6.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct set iff such a set
exists.

---

##### Lemma 1  
For each half the table `size[mask]` computed in Section&nbsp;2 equals the
cardinality of the vertex set represented by `mask` if and only if that set is
independent; otherwise it is `-1`.

**Proof.** Induction over the number of bits of `mask`.

*Base*: `mask = 0`. Empty set is independent, `size[0]=0` by initialization.

*Step*: let `mask ≠ 0`, `b` its lowest set bit, `v` its vertex, `P = mask\{b}`.
By induction hypothesis `size[P]` is correct.
`mask` is independent exactly when `P` is independent **and** `v` has no
neighbour inside `P`, i.e. `(adj[v] & P) == 0`. The recurrence implements
exactly this condition and stores `size[P]+1` in that case, otherwise `-1`. ∎



##### Lemma 2  
After the SOS‑DP of Section&nbsp;3, for every mask `A` of right vertices  

* `bestSize[A]` equals the maximum size of an independent right‑side subset
  contained in `A`;
* `bestMask[A]` is a mask of such a maximum subset.

**Proof.** SOS‑DP is a standard dynamic programming over the lattice of
subsets. Initially `bestSize` is correct for masks that are themselves
independent and `-1` otherwise. The transition considers removing one element
(`sub = mask \ {i}`) and keeps the better of the two possibilities.
Induction over the number of bits shows that after processing all bits,
`bestSize[mask]` is the optimum among **all** sub‑masks of `mask`. The same
argument holds for `bestMask`. ∎



##### Lemma 3  
When the algorithm examines a left independent mask `Lmask` and computes
`allowed`, any right mask `Rmask ⊆ allowed` is independent from `Lmask`.

**Proof.** `allowed` was defined as the set of right vertices that have **no**
edge to any vertex selected in `Lmask`. By construction, for every `v` in
`Rmask ⊆ allowed` and every `u` in `Lmask` the edge `{u,v}` does not exist.
Thus the union of the two sets contains no cross edge, i.e. the two parts are
compatible. ∎



##### Lemma 4  
If the algorithm outputs a set `S`, then `|S| = k` and `S` is independent.

**Proof.** The output consists of the left vertices of `Lmask` (size `szL`) and
the first `need = k-szL` vertices taken from `bestMask[allowed]`.  
By Lemma&nbsp;2 `bestMask[allowed]` is independent, and any subset of an
independent set is also independent, therefore the chosen right part is
independent. By Lemma&nbsp;3 the two parts have no cross edges, hence the whole
union is independent. Its size is `szL + need = k`. ∎



##### Lemma 5  
If there exists an independent set `T` of size `k`, the algorithm will find
one and output “YES”.

**Proof.** Split `T` into `T_L = T ∩ left` and `T_R = T ∩ right`.  
Both are independent in their halves, therefore their masks appear in the
enumerations and have `size[·] ≠ -1`.  
When the algorithm processes `Lmask = mask(T_L)`, we have `szL = |T_L|` and
`need = k - szL = |T_R|`.  
All vertices of `T_R` are allowed because none of them is adjacent to a vertex
of `T_L` (otherwise `T` would not be independent). Hence `T_R ⊆ allowed`.  
Consequently `bestSize[allowed] ≥ |T_R| = need`. The algorithm will accept this
left mask and output a solution. ∎



##### Lemma 6  
If the algorithm finishes the loop without finding a solution, no independent
set of size `k` exists.

**Proof.** Assume the contrary: an independent set `T` of size `k` exists.
By Lemma&nbsp;5 the algorithm would have found a solution while processing
`Lmask = mask(T_L)`. Since it did not, such a set cannot exist. ∎



##### Theorem  
The program prints

* “YES” and a valid set of `k` vertices **iff** such a set exists,
* otherwise prints “NO”.

**Proof.**  
*If* part: existence ⇒ algorithm finds it (Lemma&nbsp;5) and the printed set
is valid (Lemma&nbsp;4).  
*Only‑if* part: algorithm prints “YES” ⇒ it found a set, which is valid
(Lemma&nbsp;4). If it prints “NO”, it terminated without finding a set,
hence none exists (Lemma&nbsp;6). ∎



--------------------------------------------------------------------

#### 7.   Complexity Analysis  

```
L = n//2   ( ≤ 23 )
R = n-L    ( ≤ 23 )
```

*Enumeration of left masks*: `O(2^L)`  
*Enumeration of right masks*: `O(2^R)`  

*SOS‑DP on right side*: `O(R·2^R)`  

*Main loop over left masks*: `O(2^L)` (constant work per mask)

Overall time   `O( 2^{max(L,R)} · max(L,R) ) ≤ O(23·2^23) ≈ 2·10^8` elementary
operations – fits easily into the 5 s limit in PyPy.

Memory consumption:

* arrays of size `2^L` and `2^R` with small integers → at most
  `2·2^23·8 bytes ≈ 128 MiB`, well below the 256 MiB limit.

#### 8.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))

    edges = [0] * n          # adjacency as bitmask (full graph)
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges[u] |= 1 << v
        edges[v] |= 1 << u

    L = n // 2
    R = n - L
    left_adj = [0] * L
    right_adj = [0] * R
    cross_left = [0] * L          # edges from left vertex to right side
    cross_right = [0] * R         # edges from right vertex to left side

    for i in range(L):
        mask = edges[i]
        left_adj[i] = mask & ((1 << L) - 1)
        cross_left[i] = (mask >> L) & ((1 << R) - 1)

    for i in range(R):
        v = L + i
        mask = edges[v]
        right_adj[i] = (mask >> L) & ((1 << R) - 1)
        cross_right[i] = mask & ((1 << L) - 1)

    # ---------- independent subsets of left ----------
    size_left = [-1] * (1 << L)
    size_left[0] = 0
    for mask in range(1, 1 << L):
        b = mask & -mask
        v = (b.bit_length() - 1)
        prev = mask ^ b
        if size_left[prev] != -1 and (left_adj[v] & prev) == 0:
            size_left[mask] = size_left[prev] + 1

    # ---------- independent subsets of right ----------
    size_right = [-1] * (1 << R)
    size_right[0] = 0
    for mask in range(1, 1 << R):
        b = mask & -mask
        v = (b.bit_length() - 1)
        prev = mask ^ b
        if size_right[prev] != -1 and (right_adj[v] & prev) == 0:
            size_right[mask] = size_right[prev] + 1

    # bestSize / bestMask for right side (SOS DP)
    bestSize = [-1] * (1 << R)
    bestMask = [0] * (1 << R)
    for mask in range(1 << R):
        if size_right[mask] != -1:
            bestSize[mask] = size_right[mask]
            bestMask[mask] = mask

    for i in range(R):
        bit = 1 << i
        for mask in range(1 << R):
            if mask & bit:
                sub = mask ^ bit
                if bestSize[sub] > bestSize[mask]:
                    bestSize[mask] = bestSize[sub]
                    bestMask[mask] = bestMask[sub]

    all_right = (1 << R) - 1

    # ---------- try all left independent masks ----------
    for Lmask in range(1 << L):
        szL = size_left[Lmask]
        if szL == -1:
            continue
        need = k - szL
        if need < 0:
            continue
        # compute forbidden right vertices caused by chosen left vertices
        forbid = 0
        tmp = Lmask
        while tmp:
            b = tmp & -tmp
            v = (b.bit_length() - 1)
            forbid |= cross_left[v]
            tmp ^= b
        allowed = all_right ^ forbid
        if bestSize[allowed] < need:
            continue
        # we have a solution
        Rmask = bestMask[allowed]
        # possibly shrink Rmask to exactly 'need' vertices
        chosen_right = []
        cnt = need
        tmp = Rmask
        while cnt and tmp:
            b = tmp & -tmp
            v = (b.bit_length() - 1)
            chosen_right.append(v)
            cnt -= 1
            tmp ^= b
        # build answer list (1‑based)
        ans = []
        tmp = Lmask
        while tmp:
            b = tmp & -tmp
            v = (b.bit_length() - 1)
            ans.append(v + 1)          # left vertices are 0‑based
            tmp ^= b
        for v in chosen_right:
            ans.append(L + v + 1)       # shift by L for right side
        # output
        sys.stdout.write("YES\n")
        sys.stdout.write(" ".join(map(str, ans)) + "\n")
        return

    sys.stdout.write("NO\n")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
