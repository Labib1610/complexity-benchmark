# Problem A — Zero Sum Assignment

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing a mathematical function $f(x_1, x_2, \dots, x_n)$ where each variable $x_i$ is restricted to taking a value of either $0$ or $1$. All operations are over ordinary integers (not modulo 2, and not XOR).

The function is defined as the sum of $m$ specific terms. Each term is the product of two distinct variables, $x_u \cdot x_v$. (If $m=0$, the function has no terms and evaluates to $0$ for all assignments.) 

Since each term $x_u \cdot x_v \in \{0, 1\}$, the sum evaluates to exactly $0$ if and only if no listed pair has both of its endpoints set to $1$. Thus, the chosen variables set to $1$ must form a set with no listed pair completely contained within it.

You need to determine if there exists an assignment of values to the $n$ variables such that exactly $k$ variables are set to $1$, and the overall function evaluates to exactly $0$.

## Input

The first line contains three integers $n$, $m$, and $k$ ($1 \le n \le 46$, $0 \le m \le n(n-1)/2$, $1 \le k \le n$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that the product $x_u \cdot x_v$ is one of the terms in the sum. Each unordered pair $\{u, v\}$ appears at most once.

## Output

If a valid assignment exists, print `YES` on the first line. On the second line, print a valid set of $k$ distinct indices of the variables that are set to $1$, separated by spaces.
If no such assignment exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```
*(Note: In Example 2, the chosen indices are 1, 3, and 5. Neither the pair {1, 2} nor {3, 4} has both endpoints selected, so the sum evaluates to 0.)*

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```
