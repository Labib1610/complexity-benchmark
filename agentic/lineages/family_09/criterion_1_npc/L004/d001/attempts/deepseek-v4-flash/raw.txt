We need to find a subset of exactly \( k \) vertices such that no edge has both endpoints in the subset.  

That means we are looking for an **independent set of size exactly \( k \)** in an undirected graph with \( n \leq 46 \).  

We can solve this using a **meet-in-the-middle** approach:

- Split the vertices into two halves (size about \( n/2 \)).
- For each half, enumerate all possible subsets and record:
  - The subset size.
  - Whether it is an independent set.
  - A bitmask of the subset.
- Then combine: for each independent subset from the left half of size \( s \), we need an independent subset from the right half of size \( k - s \) that has no edges to the left subset.

We can precompute for each right subset the set of left vertices that are forbidden (adjacent to any vertex in the right subset). Then for each left subset, we check if there exists a right subset of the needed size that is independent and avoids those forbidden vertices.

We can store right subsets by size and by a bitmask of forbidden left vertices, using a dictionary mapping `(size, forbidden_mask)` to a right subset bitmask.

Let's implement it.

```python
import sys
from collections import defaultdict

def solve():
    input = sys.stdin.readline
    n, m, k = map(int, input().split())
    adj = [0] * n
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u] |= (1 << v)
        adj[v] |= (1 << u)
    
    # Split vertices into two halves
    n1 = n // 2
    n2 = n - n1
    left_vertices = list(range(n1))
    right_vertices = list(range(n1, n))
    
    # Enumerate all subsets of left half
    left_subsets = []  # list of (size, mask, is_independent)
    for mask in range(1 << n1):
        size = bin(mask).count('1')
        # check independence
        ok = True
        for i in range(n1):
            if mask >> i & 1:
                # check edges to other selected in left
                if adj[left_vertices[i]] & mask & ~(1 << i):
                    ok = False
                    break
        if ok:
            left_subsets.append((size, mask))
    
    # Enumerate all subsets of right half
    right_subsets = []  # list of (size, mask, forbidden_left_mask)
    for mask in range(1 << n2):
        size = bin(mask).count('1')
        ok = True
        forbidden = 0
        for j in range(n2):
            if mask >> j & 1:
                v = right_vertices[j]
                # check edges to other selected in right
                if adj[v] & (mask << n1) & ~(1 << (n1 + j)):
                    ok = False
                    break
                # collect left neighbors
                forbidden |= (adj[v] & ((1 << n1) - 1))
        if ok:
            right_subsets.append((size, mask, forbidden))
    
    # Group right subsets by size and forbidden mask
    right_map = defaultdict(list)  # (size, forbidden) -> list of right masks
    for size, mask, forbidden in right_subsets:
        right_map[(size, forbidden)].append(mask)
    
    # Try to combine
    for lsize, lmask in left_subsets:
        rsize = k - lsize
        if rsize < 0 or rsize > n2:
            continue
        # For this left subset, we need right subset with no edges to it
        # That means forbidden mask of right subset must not intersect lmask
        # So we need right subsets with forbidden & lmask == 0
        # We'll iterate over all right subsets of size rsize and check
        for rsize2, rmask, rforbidden in right_subsets:
            if rsize2 != rsize:
                continue
            if rforbidden & lmask:
                continue
            # Found
            ans = []
            for i in range(n1):
                if lmask >> i & 1:
                    ans.append(i + 1)
            for j in range(n2):
                if rmask >> j & 1:
                    ans.append(n1 + j + 1)
            print("YES")
            print(" ".join(map(str, ans)))
            return
    
    print("NO")

if __name__ == "__main__":
    solve()
```
