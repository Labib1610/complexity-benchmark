# Problem A — Data Center Workload Allocation

Time limit: 5 s   Memory limit: 256 MB

## Description

You are configuring a data center that contains **n** servers, identified by integers 1 through **n**. The facility is built around a single primary chassis with exactly 46 physical slots, establishing the maximum possible number of servers, while ensuring at least one server is always present. Your objective is to designate exactly **k** of these servers (where **k** is at least 1 and no greater than **n**) to run a new high-intensity workload.

The facility's power infrastructure includes **m** specialized transformers. The total number of transformers ranges from zero up to the theoretical maximum where every distinct pair of servers shares exactly one transformer. Each transformer is wired to bridge exactly two specific servers. 

The new workload generates severe thermal resonance. If assigned to a server, the workload propagates a resonance wave across its connected transformers. If this wave reaches another server that is also running the high-intensity workload, a catastrophic thermal runaway occurs. Consequently, your allocation must ensure that no two servers running the workload share a transformer.

You must determine whether it is possible to select exactly **k** servers such that no thermal runaway can occur. Given the wiring layout of the transformers, find a valid set of **k** servers, or determine that no such set exists.

## Input

The first line provides three integers: **n**, **m**, and **k**. Their valid ranges correspond exactly to the physical and theoretical limits detailed in the description.
The following **m** lines each contain two integers **u** and **v** (where both are valid server identifiers, and **u** is not equal to **v**), representing a transformer that bridges server **u** and server **v**. No two transformers bridge the exact same pair of servers.

## Output

If it is possible to safely allocate the workload to exactly **k** servers, output `YES` on the first line. On the second line, output the **k** distinct server identifiers that should be selected, separated by spaces. If multiple valid configurations exist, any one is acceptable.

If no safe allocation of exactly **k** servers is possible, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```

```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```
