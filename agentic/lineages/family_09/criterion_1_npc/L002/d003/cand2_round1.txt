# Problem A — Genomic Marker Selection

Time limit: 5 s   Memory limit: 256 MB

## Description

You are designing a diagnostic assay that analyzes a genome using a pool of **n** candidate markers, identified by integers 1 through **n**. Your objective is to select exactly **k** of these markers to form the diagnostic panel.

Clinical trials have identified **m** cross-reactivity profiles. Each profile is defined by a specific set of exactly two candidate markers. 

To ensure the assay is highly specific, the panel must not fully encompass any cross-reactivity profile. Specifically, for every profile, the subset of its markers that are included in your selected panel must be a proper subset of the profile's markers (meaning your panel cannot contain the entire two-marker set of the profile).

You must determine whether it is possible to select exactly **k** markers such that this specificity condition is satisfied for all **m** cross-reactivity profiles.

Given the list of cross-reactivity profiles, find a valid set of **k** markers, or determine that no such set exists.

## Input

The first line provides three integers: **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
The following **m** lines each contain two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing a cross-reactivity profile defined by marker **u** and marker **v**. No two profiles are defined by the exact same pair of markers.

## Output

If it is possible to safely select exactly **k** markers, output `YES` on the first line. On the second line, output the **k** distinct marker identifiers that should be selected, separated by spaces. If multiple valid configurations exist, any one is acceptable.

If no safe selection of exactly **k** markers is possible, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```
