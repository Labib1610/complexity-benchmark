# Problem A — Data Center Workload Allocation

Time limit: 5 s   Memory limit: 256 MB

## Description

You are configuring a data center that contains **n** servers, identified by integers 1 through **n**. Your objective is to designate exactly **k** of these servers to run a new high-intensity workload.

The facility's power infrastructure includes **m** specialized transformers. Each transformer is wired to supply power to exactly two specific servers. Because the new workload draws a massive amount of current, running it simultaneously on both servers connected to the same transformer will cause that transformer to overload and fail. 

To maintain facility stability, any given transformer can support at most one server running the high-intensity workload. You must determine whether it is possible to select exactly **k** servers such that no transformer is overloaded. 

Given the wiring layout of the transformers, find a valid set of **k** servers, or determine that no such set exists.

## Input

The first line provides three integers: **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
The following **m** lines each contain two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing a transformer that is wired to server **u** and server **v**. No two transformers are wired to the exact same pair of servers.

## Output

If it is possible to safely allocate the workload to exactly **k** servers, output `YES` on the first line. On the second line, output the **k** distinct server identifiers that should be selected, separated by spaces. If multiple valid configurations exist, any one is acceptable.

If no safe allocation of exactly **k** servers is possible, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

The scenario was changed from selecting people with no prior relationships (a very common trope for Independent Set, often seen in "Party Problem" tutorials) to selecting servers that share power transformers. This forces the model to analytically deduce that the "shared transformer" constraint acts exactly as an edge in an Independent Set formulation, rather than relying on memorized semantic triggers related to social networks or focus groups.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical constraint that a transformer cannot have both of its connected servers selected is identical to the constraint that an edge cannot have both of its endpoints in an independent set.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Independent Set problem on a general graph, which is NP-complete.
</PRESERVED_CLASS>
