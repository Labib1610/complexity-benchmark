# Problem A — Hardware Configuration

Time limit: 5 s   Memory limit: 256 MB

## Description

A hardware testing facility is configuring an experimental unregulated bus. The setup involves a pool of **n** available modules, identified by integers 1 through **n**.

During preliminary diagnostics, the engineers compiled a log of **m** interference events. Each interference event lists exactly two modules that draw too much power and destabilize the bus if they operate simultaneously.

Your task is to configure the final system by activating exactly **k** modules. To ensure stable operation, for every interference event in the log, your chosen configuration must not include both of the modules listed. 

Given the diagnostic log of interference events and the target size **k**, determine if it is possible to configure the system. If it is, identify the modules to activate.

## Input

The first line provides three integers: **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n). The physical capacity of the testbed limits **n** to no more than 46 modules.
The following **m** lines each contain two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing an interference event between module **u** and module **v**. No pair is listed more than once.

## Output

If a configuration of exactly **k** modules can be formed safely, output `YES` on the first line. On the second line, output the **k** distinct module identifiers that make up the configuration, separated by spaces. If multiple valid configurations exist, any one is acceptable.

If no such configuration of exactly **k** modules can be formed, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```
