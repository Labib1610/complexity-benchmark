# Problem A — Thermal Test Vector

Time limit: 5 s   Memory limit: 256 MB

## Description

You are preparing a thermal diagnostic test for a newly fabricated microchip. The microchip's physical package limits the design to a maximum of 46 input pins, and every valid chip has at least one. The chip under test exposes exactly **n** input pins (numbered 1 to **n**). Internally, the chip contains **m** diagnostic differential voltage comparators. The number of comparators can be zero, or it can be as large as the configuration where every unique pair of pins is bridged by exactly one comparator.

Each comparator is bridged between two distinct input pins. A comparator will trigger a thermal fault state if it receives an elevated voltage on both of its connected pins simultaneously. If at least one of its connected pins remains at the baseline voltage, the comparator remains stable.

To successfully execute the diagnostic test, the circuit must remain entirely stable, meaning zero comparators can enter a fault state. At the same time, to draw enough power to verify the thermal dissipation network, you must apply an elevated voltage to exactly **k** of the input pins, while leaving the remaining pins at the baseline voltage. The target power level requires **k** to be at least 1, but it cannot exceed the total number of available pins **n**.

Given the bridging of the comparators, determine if there is a valid test configuration. If one exists, report it by listing the **k** pins that should receive an elevated voltage.

## Input

The first line contains three integers **n**, **m**, and **k**. The values of these integers are guaranteed to fall within the physical limits and capacities described above.

Each of the next **m** lines contains two distinct integers **u** and **v**, identifying the 1-based indices of the pins that are bridged by a single comparator. No two comparators are bridged between the exact same pair of pins.

## Output

If a valid test configuration exists, print `YES` on the first line. On the second line, print the numbers of the **k** distinct input pins that should receive an elevated voltage, separated by spaces. If there are multiple valid sets of pins, any configuration that keeps all comparators stable is accepted.

If no such configuration is possible, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

<RATIONALE>
The direct reference to "NAND gates" and their truth table has been replaced with "differential voltage comparators" that trigger a "fault state" if both inputs are elevated. This shifts the framing from satisfying a boolean logic formula to avoiding a physical collision, removing the most obvious keyword trigger for SAT/Independent Set solvers. Additionally, all numeric bounds have been removed from the Input section and embedded as physical limits in the prose (Strategy S07), forcing the model to read and comprehend the scenario to determine the constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that no two elevated pins can share a comparator is logically identical to the requirement that no two HIGH pins share a NAND gate, so the set of valid configurations for any input is exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Independent Set problem on a graph with $n$ vertices and $m$ edges, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might struggle to parse the exact upper bound for $m$ from the phrase "every unique pair of pins is bridged by exactly one comparator", though mathematically this unambiguously describes $n(n-1)/2$.
</RISK>
