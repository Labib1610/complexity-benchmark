# Problem A — Inert Formulation

Time limit: 5 s   Memory limit: 256 MB

## Description

A chemical facility maintains an inventory of reagents. Over time, technicians have documented specific pairs of reagents that produce an exothermic reaction when combined. 

A client has requested a custom solution containing a precise number of distinct reagents. The formulation process requires that the final solution is completely inert. A solution is inert if and only if no two reagents within it are documented as an exothermic pair. If even one documented pair is included together, the solution is unsafe.

You must determine whether it is possible to select the requested number of reagents to form an inert solution, and if so, identify one such valid selection.

## Input

The first line of input contains three integers: the inventory size, the number of documented exothermic pairs, and the target number of reagents for the solution. 

The inventory size is at least 1 and is capped by the facility's 46 isolation chambers. The number of documented pairs is non-negative and will not exceed the maximum possible number of distinct pairs that can be formed from the inventory. The target number of reagents is at least 1 and will not exceed the inventory size.

Each of the following lines contains two distinct integers representing the identifiers of a documented exothermic pair. Reagents are identified by integers from 1 up to the inventory size. No pair is listed more than once.

## Output

If an inert solution can be formulated with exactly the target number of reagents, output `YES` on the first line. On the second line, output the identifiers of the selected reagents, separated by spaces. If multiple valid formulations exist, any of them is acceptable.

If no such formulation is possible, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

In Example 2, reagents 1, 3, and 5 have no documented exothermic reactions among them. In Example 1, no three of the four reagents can be safely combined.
