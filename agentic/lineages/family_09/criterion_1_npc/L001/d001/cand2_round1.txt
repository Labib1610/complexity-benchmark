# Problem A — Parallel Sessions

Time limit: 5 s   Memory limit: 256 MB

## Description

A conference organizer is finalizing the schedule for **n** proposed workshops (numbered 1 to n). Attendees have submitted their preliminary registration preferences. Analyzing these preferences, the organizer has identified **m** scheduling conflicts. A conflict consists of a specific pair of workshops that share at least one registered attendee.

The organizer intends to host exactly **k** workshops simultaneously during the prime-time slot. A prime-time schedule is considered **accessible** if every scheduling conflict involves at least one workshop that is deferred to a different time slot. In other words, it is strictly forbidden to include both workshops from any known conflict pair in the prime-time slot.

Given the target size **k**, determine whether an accessible prime-time schedule of exactly **k** workshops exists, and if so, report one.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v): a scheduling conflict. No conflict is listed twice.

## Output

If an accessible prime-time schedule of **k** workshops exists, print `YES` on the first line, then on the second line print **k** distinct workshop numbers forming such a schedule, separated by spaces. Any schedule in which no two selected workshops conflict is accepted.

If no such schedule exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

In Example 2, workshops 1, 3, and 5 can be scheduled together because all conflicts (1-2 and 3-4) involve at least one deferred workshop (2 and 4 are deferred). In Example 1, it is impossible to select three workshops without including both halves of at least one conflict.
