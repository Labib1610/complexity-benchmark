# Problem A — Interference-Free Broadcast

Time limit: 5 s   Memory limit: 256 MB

## Description

A telecommunications provider is configuring a new broadcast system using a pool of **n** candidate transmission channels (numbered 1 through **n**). Harmonic resonance causes certain pairs of channels to be incompatible; activating both simultaneously leads to catastrophic signal degradation. The engineers have documented **m** such incompatible pairs.

A safe broadcast array is a set of channels where absolutely no two selected channels are incompatible.

You must determine if it is possible to activate exactly **k** channels that form a safe broadcast array, and if so, report one valid selection. 

*Performance Note:* The evaluation data contains adversarial test cases. Many scenarios feature dense, near-half-target conflict structures specifically designed to defeat search strategies that rely on sorting by conflict counts or hoping to find an early valid combination without full exploration.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v): an incompatible pair of channels. No pair is listed twice.

## Output

If a safe broadcast array of exactly **k** channels exists, print `YES` on the first line, then on the second line print **k** distinct channel numbers forming such an array, separated by spaces. Any array in which no two channels are incompatible is accepted.

If no such array exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

In Example 2, channels 1, 3 and 5 have no interference conflicts among them. In Example 1, no three of the four channels are mutually compatible.
