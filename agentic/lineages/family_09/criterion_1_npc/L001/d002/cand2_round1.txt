# Problem A — Interference-Free Broadcast

Time limit: 5 s   Memory limit: 256 MB

## Description

A telecommunications company is configuring a new broadcast array. There is a pool of candidate transmission channels available (numbered consecutively starting from 1). However, due to harmonic resonance, certain pairs of channels are completely incompatible; deploying them simultaneously will cause catastrophic signal degradation. There are several such documented interference conflicts.

An interference-free broadcast array is a selection of channels where absolutely no two selected channels share an interference conflict.

Given a target array size, determine if it is possible to select exactly that many channels to form an interference-free broadcast array, and if so, report one such selection.

*System Warning:* The test data includes highly adversarial interference patterns. These patterns have been specifically engineered to simulate worst-case resonance structures, intended to defeat approaches that rely on finding an early valid configuration or that attempt to optimize by sorting channels based on their total number of conflicts. Your method must be robust against such worst-case evaluations.

## Input

The first line contains three integers: the number of candidate channels, the number of documented conflicts, and the target array size.
- The main broadcasting chassis has exactly 46 hardware slots and requires at least one active module, so the number of candidate channels is bounded by these physical limits.
- The number of documented conflicts ranges from none at all up to the theoretical limit where every candidate channel interferes with every other candidate channel.
- The target array size is at least one and cannot exceed the total number of candidate channels.

Each of the following lines (one for each documented conflict) contains two distinct integers representing a pair of incompatible channels. No conflict is listed twice.

## Output

If an interference-free broadcast array of exactly the target size exists, print `YES` on the first line, then on the second line print the target number of distinct channel numbers forming such an array, separated by spaces. Any array in which no two channels conflict is accepted.

If no such array exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```
