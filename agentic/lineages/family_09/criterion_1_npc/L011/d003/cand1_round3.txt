# Problem A — Panel Selection

Time limit: 5 s   Memory limit: 256 MB

## Description

A social network tracks **n** member profiles, identified by numbers from 1 to **n**. The system has recorded **m** bilateral interaction events, each representing an exchange between two distinct members. 

A research initiative requires partitioning all **n** members into two mutually exclusive sets: a focus panel containing exactly **k** members, and a control group consisting of the remaining **n** - **k** members. 

The study's design dictates that the control group must act as a comprehensive activity buffer. Each member naturally accounts for all interaction events in which they participated. The partition is considered valid if and only if the combined set of events accounted for by the members of the control group includes all **m** recorded interaction events.

Your objective is to evaluate whether it is possible to construct a valid focus panel of exactly **k** members under these constraints. If such a panel can be formed, you must also provide a list of its members.

## Input

The first line provides three integers **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
Following this are **m** lines, each containing two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v). These indicate an interaction event between member **u** and member **v**. The records are strictly unique: no unordered pair of members is listed more than once.

## Output

If a valid focus panel of exactly **k** members can be formed, output `YES` on the first line. On the next line, output the **k** distinct member numbers that constitute the panel, separated by spaces. Any valid panel will be accepted if more than one exists.

If forming such a panel is impossible, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

<RATIONALE>
Replaced the direct vertex-cover condition ("control group includes at least one participant from every single recorded interaction event") with a set-coverage framing ("the combined set of events accounted for by the members of the control group includes all m recorded interaction events"). This forces the model to deduce that the focus panel must be an independent set rather than triggering on the explicit "at least one endpoint" phrasing. Clarified the simple-graph constraint to resolve the previous ambiguity.
</RATIONALE>
<PRESERVED_ANSWER>
A control group whose members collectively account for all events is precisely a vertex cover, meaning its complement (the focus panel of size k) must be an independent set, exactly as in the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains NP-complete as it is formally equivalent to finding an Independent Set of size k (or a Vertex Cover of size n-k) in a given graph.
</PRESERVED_CLASS>
<RISK>
None; the definition of how a member accounts for events and how the control group covers them is mathematically precise and aligns perfectly with standard set coverage.
</RISK>
