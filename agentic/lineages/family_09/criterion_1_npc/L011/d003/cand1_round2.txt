# Problem A — Panel Selection

Time limit: 5 s   Memory limit: 256 MB

## Description

A social network tracks **n** member profiles, identified by numbers from 1 to **n**. The system has recorded **m** bilateral interaction events, each representing an exchange between two distinct members.

A research initiative requires dividing the **n** members into two mutually exclusive groups: a focus panel containing exactly **k** members, and an oversight committee consisting of the remaining **n** - **k** members.

The study's design dictates that the oversight committee must successfully audit the network's activity. The committee is tasked with collectively accounting for all **m** recorded events. Because an interaction event can only be audited by a member who personally participated in it, the chosen **k** panel members must leave behind a set of auditors capable of handling every single interaction. A partition is valid if and only if such a complete audit is possible—meaning no recorded event is left without a qualified auditor in the oversight committee.

Your objective is to evaluate whether it is possible to select exactly **k** members for the focus panel such that the remaining members form a valid oversight committee. If such a panel can be formed, you must also provide a list of its members.

## Input

The first line provides three integers **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
Following this are **m** lines, each containing two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v). These indicate an interaction event between member **u** and member **v**. Each interaction event is listed at most once.

## Output

If a valid focus panel of exactly **k** members can be formed, output `YES` on the first line. On the next line, output the **k** distinct member numbers that constitute the panel, separated by spaces. Any valid panel will be accepted if more than one exists.

If forming such a panel is impossible, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

<RATIONALE>
Removed the direct graph-theoretic cue ("the control group includes at least one participant from every single recorded interaction event") that allowed models to trivially map the problem to Independent Set / Vertex Cover. Replaced it with an operational audit obligation, forcing models to deduce the structural requirement from the mechanics of the scenario.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that every event must have a qualified auditor in the oversight committee is mathematically identical to requiring that no interaction occurs strictly within the focus panel, preserving all valid partitions.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem requires finding an independent set of size k (or equivalently a vertex cover of size n-k), keeping it NP-complete.
</PRESERVED_CLASS>
<RISK>
The phrase "collectively accounting for" could be seen as slightly abstract, though the subsequent clarification ("meaning no recorded event is left without a qualified auditor") resolves any ambiguity.
</RISK>
