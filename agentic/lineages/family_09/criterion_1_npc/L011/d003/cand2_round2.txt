<STATEMENT>
# Problem A — Panel Selection

Time limit: 5 s
Memory limit: 256 MB

## Description

An online community database maintains records for $n$ distinct user profiles, numbered 1 through $n$. Historical data reveals $m$ specific bilateral interactions, where each interaction involves exactly two different users. The dataset is strictly non-redundant: any given pair of users will have at most one interaction recorded between them, irrespective of order.

Data analysts need to divide the $n$ users into two separate categories: a primary focus panel of exactly $k$ users, and a background control pool containing the other $n - k$ users. Each user must be assigned to exactly one category.

To ensure the integrity of the analysis, the background control pool must oversee all historical activity. A categorization is considered strictly valid if, for every one of the $m$ recorded interactions, at least one of the two participating users is placed into the background control pool. 

You must evaluate whether there is any valid way to select exactly $k$ users for the primary focus panel such that the background control pool fulfills this oversight requirement. If a valid selection exists, you are to output the users who will form the primary focus panel.

## Input

The first line contains three integers $n$, $m$, and $k$ ($1 \le n \le 46$, $0 \le m \le n(n-1)/2$, $1 \le k \le n$).
The next $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing a historical interaction between user $u$ and user $v$. It is guaranteed that each unordered pair $\{u, v\}$ is provided at most once.

## Output

If a valid primary focus panel of exactly $k$ users can be successfully formed, output `YES` on the first line. On the second line, output the $k$ distinct user numbers comprising the panel, separated by spaces. If multiple valid panels are possible, any one of them is acceptable.

If it is impossible to form such a panel, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```
</STATEMENT>
<RATIONALE>
The rewrite removes the explicit structural cues that lead models directly to the "independent set" algorithmic template. Instead, it frames the constraint as an "oversight requirement" on the complementary group (the background control pool). By requiring that the control pool contains at least one participant from every interaction, the model is forced to perform the logical deduction that no two users in the focus panel can share an interaction, before it can confidently apply independent set or clique-complement optimizations.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that every interaction has at least one user in the control pool mathematically strictly means that no interaction can have both users in the focus panel, making the valid focus panels exactly the independent sets of size k in the interaction graph, preserving all valid outputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the NP-complete Independent Set problem (or equivalently Vertex Cover on the remaining vertices), with no changes to the structural requirements or bounds.
</PRESERVED_CLASS>
