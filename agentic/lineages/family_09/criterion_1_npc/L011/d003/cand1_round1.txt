<STATEMENT>
# Problem A — Panel Selection

Time limit: 5 s   Memory limit: 256 MB

## Description

A social network tracks **n** member profiles, identified by numbers from 1 to **n**. The system has recorded **m** bilateral interaction events, each representing an exchange between two distinct members.

A research initiative requires partitioning all **n** members into two mutually exclusive sets: a focus panel containing exactly **k** members, and a control group consisting of the remaining **n** - **k** members. 

The control group is tasked with reviewing the interaction logs. Every recorded interaction event must be reviewed by a member who was personally involved in that exchange. However, members assigned to the focus panel are exempt from all review duties. Consequently, every event must be successfully allocated to a reviewer who is both a participant in that event and a member of the control group. A single control group member is capable of reviewing any number of their own events.

The partition is considered valid if and only if such an allocation can cover all **m** recorded events.

Your objective is to evaluate whether it is possible to construct a valid focus panel of exactly **k** members under these constraints. If such a panel can be formed, you must also provide a list of its members.

## Input

The first line provides three integers **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
Following this are **m** lines, each containing two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v). These indicate an interaction event between member **u** and member **v**. Each interaction event is listed at most once.

## Output

If a valid focus panel of exactly **k** members can be formed, output `YES` on the first line. On the next line, output the **k** distinct member numbers that constitute the panel, separated by spaces. Any valid panel will be accepted if more than one exists.

If forming such a panel is impossible, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```
</STATEMENT>
<RATIONALE>
Changed the validity condition from requiring the control group to "include at least one participant" to requiring events to be "allocated to a reviewer" who is a participant and in the control group. This forces the model to logically deduce that the unbounded allocation capacity reduces to a simple set intersection requirement (Vertex Cover), rather than pattern-matching the original direct phrasing to an Independent Set.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that each event must be allocated to a participant in the control group is mathematically identical to requiring the control group to intersect every event's participant set, meaning the valid focus panels remain exactly the independent sets of size k.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding an independent set of size k (or a vertex cover of size n-k) in a graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "allocated to a reviewer" as implying a one-to-one or capacity-constrained assignment (like bipartite matching), though the statement explicitly clarifies that a member can review "any number of their own events".
</RISK>
