**Solution Explanation**

For the required panel no two members may have an interaction,
otherwise that edge would be completely inside the panel and the
condition would be violated.
So we have to find an **independent set** of exactly `k` vertices in the
given undirected graph.

`n ≤ 46`, therefore a simple depth‑first search with good pruning is
fast enough.

--------------------------------------------------------------------

#### 1.   Bitset representation  

Vertex `i (0‑based)` is represented by the bit `1 << i`.
For every vertex we store the bitset of its neighbours (including itself
is convenient later).

```
adj[i] : int   # bitmask of neighbours of i (i itself is also set)
```

All sets of vertices are also stored as bitmasks (`int`).

--------------------------------------------------------------------

#### 2.   Recursive search  

```
search(cur, cand)  ->  bitmask of a solution or None
cur   : vertices already chosen (independent)
cand  : vertices that may still be taken
```

* `cur_size = popcount(cur)`
* if `cur_size == k` → success, return `cur`
* if `cur_size + popcount(cand) < k` → even taking all candidates is not
  enough, backtrack
* pick an arbitrary vertex `v` from `cand`
* **branch 1 – take `v`**  
  new candidates = `cand` without `v` and without any neighbour of `v`  

  `new_cand = cand & ~adj[v]`
* recurse with `cur | (1<<v) , new_cand`
* if it succeeds → propagate the answer
* **branch 2 – skip `v`**  
  `new_cand = cand & ~(1<<v)`
* recurse with the same `cur`

The first branch tries to enlarge the independent set, the second one
explores the possibility that `v` does not belong to the final panel.
The pruning condition (`cur_size + |cand| < k`) cuts huge parts of the
search tree.

Because each recursive call removes at least one vertex from `cand`,
the depth is at most `n = 46`.  
The worst case number of visited states is far below `2^46` and easily
fits into the limits.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct panel
iff such a panel exists.

---

##### Lemma 1  
During the whole execution `cur` is always an independent set.

**Proof.**  
Initially `cur = 0` (empty set) – independent.  
When we branch *take `v`*, we add `v` to `cur` and remove from `cand`
all neighbours of `v` (including `v` itself). Therefore no later vertex
added to `cur` can be adjacent to `v`. By induction `cur` stays
independent. ∎



##### Lemma 2  
If the recursive call `search(cur, cand)` returns a bitmask `S`,
then `S` is an independent set, `cur ⊆ S`, `S ⊆ cur ∪ cand`
and `|S| = k`.

**Proof.**  
The function returns only in two places:

* when `|cur| = k` – then it returns `cur`, which satisfies all
  properties.
* when a recursive call returns a set `S`. By the induction hypothesis
  that `S` satisfies the properties for the deeper call.
  The deeper call’s `cur` is either `cur` (branch *skip*) or
  `cur ∪ {v}` (branch *take*), both subsets of `S`.  
  The deeper call’s candidate set is a subset of the current `cand`,
  therefore `S ⊆ cur ∪ cand`.  
  Independence follows from Lemma&nbsp;1. ∎



##### Lemma 3  
If there exists an independent set `I` with `|I| = k` and
`I ⊆ cur ∪ cand`, then `search(cur, cand)` will eventually return a
solution.

**Proof.**  
Induction on `|cand|`.

*Base*: `cand = 0`. Then `I ⊆ cur`. Because `|I| = k`, we have `|cur| = k`
and the algorithm returns `cur`.

*Step*: `cand ≠ 0`. Let `v` be the vertex chosen by the algorithm.
Two cases.

1. `v ∈ I`.  
   The *take* branch keeps `v` and discards all its neighbours.
   Since `I` is independent, none of the discarded vertices belong to `I`,
   therefore `I ⊆ (cur∪{v}) ∪ (cand ∩ ¬adj[v])`.  
   The recursive call on that branch satisfies the induction hypothesis,
   thus returns a solution.

2. `v ∉ I`.  
   Then `I ⊆ cur ∪ (cand \ {v})`. The *skip* branch is exactly this
   sub‑problem, again satisfying the induction hypothesis.

In both cases a recursive call returns a solution, which is propagated
upwards. ∎



##### Lemma 4  
If `search(0, AllVertices)` returns `None`, no independent set of size `k`
exists.

**Proof.**  
Assume the contrary: there is an independent set `I` of size `k`.
Apply Lemma&nbsp;3 with `cur = 0, cand = AllVertices`. The lemma guarantees
that the call must return a solution, contradicting the assumption.
∎



##### Theorem  
The program outputs  

* `YES` and a list of `k` members forming a valid panel **iff**
  such a panel exists,
* otherwise outputs `NO`.

**Proof.**  

*If part*:  
When the algorithm finds a set `S` (Lemma&nbsp;2) it is independent,
has size `k`, therefore satisfies the problem condition, and the program
prints it with `YES`.

*Only‑if part*:  
If the program prints `NO`, it means `search` returned `None`. By
Lemma&nbsp;4 no independent set of size `k` exists, i.e. no valid panel
exists. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

`n ≤ 46`.

*Each recursive call* removes at least one vertex from `cand`,
so the recursion depth ≤ `n`.
The total number of visited states is bounded by the number of subsets
explored, which in practice is far below `2^n`.  
The worst‑case time is `O( 2^{n/2} )` for this size, well inside the
5 seconds limit.

All operations on bitsets are O(1) (Python big integers, but with ≤ 46
bits).

Memory consumption: only a few integers, `O(1)`.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(1000000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))

    adj = [0] * n
    for i in range(n):
        adj[i] = 1 << i          # self‑loop, convenient for removal

    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u] |= 1 << v
        adj[v] |= 1 << u

    ALL = (1 << n) - 1

    from functools import lru_cache

    @lru_cache(maxsize=None)
    def popcnt(x: int) -> int:
        return x.bit_count()

    # recursive search
    def dfs(cur: int, cand: int):
        cur_sz = popcnt(cur)
        if cur_sz == k:
            return cur
        if cur_sz + popcnt(cand) < k:
            return None
        # choose a vertex v from cand (least significant bit)
        v = (cand & -cand).bit_length() - 1  # index of lsb
        # branch 1: take v
        new_cand = cand & ~adj[v]
        res = dfs(cur | (1 << v), new_cand)
        if res is not None:
            return res
        # branch 2: skip v
        return dfs(cur, cand & ~(1 << v))

    ans_mask = dfs(0, ALL)
    if ans_mask is None:
        print("NO")
    else:
        print("YES")
        res = []
        for i in range(n):
            if ans_mask >> i & 1:
                res.append(str(i + 1))
        print(" ".join(res))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
