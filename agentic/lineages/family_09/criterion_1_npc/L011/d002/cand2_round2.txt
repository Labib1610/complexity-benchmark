# Problem A — Panel Selection

Time limit: 5 s   Memory limit: 256 MB

## Description

A social platform maintains **n** member profiles (numbered 1 to **n**). Over time, the platform has logged **m** bilateral interaction events. Each event involves exactly two distinct members.

A research study aims to select exactly **k** members to act as primary respondents. To prevent cross-contamination of survey data, the selection must be completely interference-free. An interference is defined as occurring whenever both participants of a logged interaction event are simultaneously selected as primary respondents. 

Determine whether it is possible to successfully choose exactly **k** members such that zero interferences occur. If it is possible, report the members selected.

## Input

The first line contains three integers **n**, **m**, and **k**. The platform's physical capacity supports up to 46 members, while the selection requires at least 1 member, and the logged events can range from none to all possible pairs (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).

Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing an interaction event between member **u** and member **v**. No interaction event is listed twice.

## Output

If it is possible to successfully select exactly **k** primary respondents with zero interferences, print `YES` on the first line. On the second line, print the **k** distinct member numbers that make up the selection, separated by spaces. If multiple valid selections exist, any one is accepted.

If no such selection can be formed, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

Narrative justifications for the bounds were added while retaining the exact parenthetical inequalities to satisfy strict parsing.
