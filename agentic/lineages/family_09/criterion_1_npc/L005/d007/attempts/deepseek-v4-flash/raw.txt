We can model the documents as vertices of a graph, and each shared block as an edge.  
If we select a set of vertices, the sum of reference counts is the total number of edges incident to the selected vertices (counting each edge once for each endpoint in the set).  
The archive footprint is the number of edges that have at least one endpoint in the set.

The condition “footprint = sum of reference counts” means:

- Every edge that touches the selected set must have **exactly one** endpoint in the set.  
  If an edge has both endpoints in the set, it contributes 2 to the sum but only 1 to the footprint, breaking equality.

So we need to select exactly `k` vertices such that no edge has both endpoints selected.  
That is, the selected set must be an **independent set** of size `k`.

Since `n ≤ 46`, we can use meet-in-the-middle or backtracking with pruning.  
We’ll implement a recursive backtracking that tries to build an independent set of size `k`.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))
    
    adj = [0] * n
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u] |= (1 << v)
        adj[v] |= (1 << u)
    
    # Backtracking to find independent set of size k
    selected = []
    
    def backtrack(start, count):
        if count == k:
            return True
        if start >= n:
            return False
        # Prune: not enough remaining vertices
        if n - start < k - count:
            return False
        
        # Try to include start if possible
        can_include = True
        for v in selected:
            if (adj[start] >> v) & 1:
                can_include = False
                break
        if can_include:
            selected.append(start)
            if backtrack(start + 1, count + 1):
                return True
            selected.pop()
        
        # Skip start
        if backtrack(start + 1, count):
            return True
        return False
    
    if backtrack(0, 0):
        print("YES")
        print(" ".join(str(x + 1) for x in selected))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
