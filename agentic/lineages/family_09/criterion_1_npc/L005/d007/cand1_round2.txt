<STATEMENT>
# Problem A — Signal Dissipation Network

Time limit: 5 s   Memory limit: 256 MB

## Description

You are configuring a network of **n** nodes.
You are provided a list of **m** distinct interference links. Each link connects two distinct nodes **u** and **v**.

Your task is to activate exactly **k** nodes to achieve a stable configuration.

When a node is activated, it emits one unit of signal along every interference link connected to it (regardless of whether the node at the other end is active or inactive). Let **S** be the total amount of signal emitted by all **k** activated nodes combined.

A link acts as a *dissipation boundary* if it connects exactly one activated node and one inactive node. Let **B** be the total number of dissipation boundaries. Links connecting two inactive nodes receive no signal, and links connecting two active nodes do not act as boundaries.

A configuration of exactly **k** activated nodes is *stable* if the total signal emitted **S** is exactly equal to the number of dissipation boundaries **B**.

If such a configuration exists, report it by listing the 1-based indices of the activated nodes.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ **n** ≤ 46, 0 ≤ **m** ≤ **n**·(**n**−1)/2, 1 ≤ **k** ≤ **n**).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), representing an interference link between node **u** and node **v**. The input will never list the same pair of nodes more than once.

## Output

If a valid configuration exists, print `YES` on the first line, then on the second line print the **k** distinct indices of the activated nodes, separated by spaces. If multiple valid configurations exist, any valid configuration is accepted. Print only the **k** activated indices.

If no such configuration exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

In Example 2, if we activate nodes 1, 3, and 5:
- Node 1 is connected to link (1, 2). It emits 1 unit of signal.
- Node 3 is connected to link (3, 4). It emits 1 unit of signal.
- Node 5 is connected to no links. It emits 0 units of signal.
The total signal emitted **S** = 1 + 1 + 0 = 2.
The dissipation boundaries are the links connecting one active and one inactive node:
- Link (1, 2) connects active node 1 and inactive node 2.
- Link (3, 4) connects active node 3 and inactive node 4.
There are exactly 2 dissipation boundaries (**B** = 2).
Since **S** equals **B**, this configuration is stable.

In Example 1, if we were to activate nodes 1, 2, and 3:
- Node 1 emits 2 units (links to 2 and 3).
- Node 2 emits 2 units (links to 1 and 3).
- Node 3 emits 3 units (links to 1, 2, and 4).
The total signal emitted **S** = 7.
The only dissipation boundary is link (3, 4), which connects active node 3 and inactive node 4, so **B** = 1.
Since 7 does not equal 1, this configuration is not stable. It turns out no combination of exactly 3 active nodes can achieve **S** = **B** for this network. Thus, no valid configuration exists.
</STATEMENT>
<RATIONALE>
Removed the explicit algebraic equation `5^c = m + 4T` which models easily pattern-matched and simplified to discover the independent set reduction. Replaced it with a natural domain property (signal emitted equals dissipation boundaries) that mathematically enforces the exact same condition (Internal Edges = 0) but requires logical deduction from the scenario rather than algebraic manipulation.
</RATIONALE>
<PRESERVED_ANSWER>
The total signal S is 2*I + B, where I is the number of links between two active nodes and B is the number of boundary links; setting S = B requires 2*I = 0, which means no two active nodes can share a link, preserving the exact independent set requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Independent Set problem since the stability condition is satisfied if and only if the selected nodes form an independent set of size k.
</PRESERVED_CLASS>
