<STATEMENT>
# Problem A — Aggregate Values

Time limit: 5 s   Memory limit: 256 MB

## Description

You are given $n$ binary variables $x_1, x_2, \ldots, x_n \in \{0, 1\}$. 

You are provided a list of $m$ aggregation rules. The $j$-th rule consists of two distinct indices $u_j$ and $v_j$, which defines an aggregate value $y_j = x_{u_j} + x_{v_j}$. 

Your task is to find an assignment for the vector $x \in \{0, 1\}^n$ containing exactly $k$ ones (and $n - k$ zeros) such that the sum of the squares of the aggregate values equals the sum of the aggregate values. That is, the assignment must satisfy:
$$ \sum_{j=1}^m y_j^2 = \sum_{j=1}^m y_j $$

If such an assignment exists, report it by listing the 1-based indices $i$ where $x_i = 1$.

## Input

The first line contains three integers $n$, $m$, and $k$ (1 ≤ $n$ ≤ 46, 0 ≤ $m$ ≤ $n(n-1)/2$, 1 ≤ $k$ ≤ $n$).
Each of the next $m$ lines contains two integers $u$ and $v$ (1 ≤ $u, v$ ≤ $n$, $u \neq v$), representing the indices used to compute one of the aggregate values. The input will never list the same pair of indices more than once.

## Output

If a valid assignment exists, print `YES` on the first line, then on the second line print the $k$ distinct indices where $x_i = 1$, separated by spaces. If multiple valid assignments exist, any valid selection is accepted. Print only the $k$ selected indices.

If no such assignment exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

In Example 2, if we choose the assignment where $x_1 = 1$, $x_3 = 1$, $x_5 = 1$ and $x_2 = x_4 = 0$, it contains exactly 3 ones.
The $m=2$ aggregate values are computed as:
- $y_1 = x_1 + x_2 = 1 + 0 = 1$
- $y_2 = x_3 + x_4 = 1 + 0 = 1$
The sum of the squares is $1^2 + 1^2 = 2$.
The sum of the values is $1 + 1 = 2$.
Since $2 = 2$, this assignment satisfies the condition. The indices where $x_i = 1$ are 1, 3, and 5.

In Example 1, for any assignment with exactly 3 ones, the computed aggregate values will result in the sum of their squares being strictly greater than their sum. Thus, no valid assignment exists.
</STATEMENT>
<RATIONALE>
The previous problem framed the constraint as a bilinear form $x^T A x = k$ with an identity matrix and symmetric pair updates, which models easily mapped to an Independent Set graph problem. This rewrite completely removes all matrix and graph terminology, replacing the constraint with an algebraically equivalent polynomial equation ($\sum y_j^2 = \sum y_j$). To achieve the necessary pruning for $n=46$, models are now forced to algebraically expand the equation to deduce that $x_u x_v = 0$ for all pairs, discovering the mutual exclusion structure from scratch rather than relying on structural pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
Because $x_i \in \{0, 1\}$, the aggregate values $y_j = x_u + x_v$ are non-negative integers; the equation $\sum y_j^2 = \sum y_j$ holds if and only if every $y_j \in \{0, 1\}$, which is mathematically identical to requiring that no two selected variables share a rule (the exact same Independent Set condition as the original bilinear form).
</PRESERVED_ANSWER>

The problem remains exactly the NP-complete Independent Set problem (or Clique on the complement graph), merely presented through an equivalent algebraic constraint.
</PRESERVED_CLASS>
