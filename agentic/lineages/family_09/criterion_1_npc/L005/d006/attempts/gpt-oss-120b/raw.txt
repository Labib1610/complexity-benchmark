**Solution Explanation**

For a set `S` of selected vertices let  

* `c(e)` – number of selected endpoints of an edge `e` (`0,1,2`);
* `score(e) = 5^{c(e)}` ;
* `T = Σ_{v∈S} deg(v)` – sum of degrees of the selected vertices
  (an edge contributes `1` to `T` if exactly one of its ends is in `S`,
  `2` if both ends are in `S`, `0` otherwise).

The required equality is  

```
 Σ score(e) = m + 4·T                (1)
```

--------------------------------------------------------------------

#### 1.   Transforming the condition

For the whole graph let  

* `e0` – number of edges with `c(e)=0`,
* `e1` – number of edges with `c(e)=1`,
* `e2` – number of edges with `c(e)=2`.

Obviously `e0+e1+e2 = m`.

```
 Σ score(e) = e0·1 + e1·5 + e2·25                (2)
 T          = e1·1 + e2·2                       (3)
```

Insert (2) and (3) into (1):

```
e0 + 5·e1 + 25·e2 = m + 4·(e1 + 2·e2)
e0 + 5·e1 + 25·e2 = (e0+e1+e2) + 4·e1 + 8·e2
```

Cancel `e0` on both sides and simplify:

```
5·e1 + 25·e2 = 5·e1 + 9·e2   →   16·e2 = 0   →   e2 = 0
```

`e2 = 0` means **no edge has both ends selected** – the selected
vertices must form an *independent set*.
If `e2 = 0` the equality (1) is automatically satisfied for any `e1`.

So the whole problem reduces to:

> **Find an independent set of exactly `k` vertices.**

--------------------------------------------------------------------

#### 2.   Finding an independent set of size `k`

`n ≤ 46`, therefore a simple back‑tracking search with pruning is fast
enough.

*Represent the graph* – for every vertex `v` we store a 64‑bit integer
`adj[v]` whose bits are the neighbours of `v`.

*Search state*

```
chosen      – list of already selected vertices
candidates  – bitmask of vertices that may still be taken
```

*Pruning*

```
if len(chosen) + popcount(candidates) < k :   # not enough vertices left
        backtrack
```

*Branching* – pick any vertex `v` from `candidates`

```
1) take v
   new_candidates = candidates & ~adj[v] & ~(1<<v)
2) skip v
   new_candidates = candidates & ~(1<<v)
```

The recursion stops as soon as `len(chosen) == k`; the found set is
output.

The search explores at most the size of a typical maximum‑independent‑set
branching tree; with the strong pruning above it finishes well within
the limits for `n = 46`.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct set iff such a
set exists.

---

##### Lemma 1  
For any vertex set `S` the equality  

```
 Σ_{edges} 5^{c(e)} = m + 4· Σ_{v∈S} deg(v)
```

holds **iff** `S` is an independent set.

**Proof.** The derivation in Section&nbsp;1 shows that the equality is
equivalent to `e2 = 0`, i.e. no edge has both ends in `S`. ∎



##### Lemma 2  
During the search, `candidates` always contains exactly the vertices
that are not yet chosen and are not adjacent to any already chosen
vertex.

**Proof.** Initially `candidates` is the set of all vertices, the
property holds.  
When we *take* a vertex `v`, we remove `v` itself and all its neighbours
(`~adj[v]`). When we *skip* `v`, we only remove `v`. Both operations keep
the invariant. ∎



##### Lemma 3  
If the recursive call is entered with `|chosen| = t` and
`popcount(candidates) = r`, then any independent superset of `chosen`
has size at most `t+r`.

**Proof.** By Lemma&nbsp;2 every vertex that could be added to `chosen`
must belong to `candidates`. There are only `r` such vertices. ∎



##### Lemma 4  
If the algorithm reaches a leaf with `|chosen| = k`, the printed set
is an independent set of size `k`.

**Proof.** By Lemma&nbsp;2 no two vertices in `chosen` are adjacent,
hence it is independent. Its size is `k` by the leaf condition. ∎



##### Lemma 5  
If an independent set of size `k` exists, the algorithm will eventually
reach a leaf with `|chosen| = k`.

**Proof.** Consider any such set `I`. Follow the recursion:
whenever the current vertex `v` belongs to `I` we take the branch
“take `v`”; otherwise we may take the “skip `v`” branch.
Because `I` is independent, taking `v` never removes another vertex of
`I` from `candidates`. Hence after processing all vertices of `I`,
`chosen` contains exactly `I`. The pruning condition never discards this
branch because Lemma&nbsp;3 guarantees `|chosen| + |candidates| ≥ k`
along it. Therefore the recursion reaches the leaf `|chosen| = k`. ∎



##### Lemma 6  
If the algorithm finishes without finding a leaf of size `k`, no
independent set of size `k` exists.

**Proof.** Assume the contrary: an independent set `I` of size `k`
exists. By Lemma&nbsp;5 the recursion would have a branch leading to a
leaf with `|chosen| = k`, contradicting the assumption that the algorithm
exhausted all branches without success. ∎



##### Theorem  
The program outputs

* “YES” and a list of `k` vertices **iff** there exists a selection of
  `k` items satisfying the original arithmetic condition,
* otherwise it outputs “NO”.

**Proof.** By Lemma&nbsp;1 the original condition is equivalent to the
existence of an independent set of size `k`.  
If the program prints “YES”, by Lemma&nbsp;4 the printed vertices form an
independent set of size `k`, thus satisfy the condition.  
If it prints “NO”, by Lemma&nbsp;6 no independent set of size `k` exists,
hence no selection satisfies the condition. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

`n ≤ 46`.

*Bit operations* are O(1).  
The recursion explores at most the number of nodes of a typical
branch‑and‑bound tree for maximum independent set; in the worst case it
is bounded by `O(1.618^n)` (the Fibonacci bound for this problem) which
is far below the limit for `n = 46`.  
Memory consumption is `O(n)` for the adjacency masks and the recursion
stack (`≤ n` depth).

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))

    adj = [0] * n
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u] |= 1 << v
        adj[v] |= 1 << u

    ALL = (1 << n) - 1
    answer = []

    # depth‑first search with pruning
    def dfs(chosen_mask: int, candidates_mask: int, chosen_list: list) -> bool:
        nonlocal answer
        if len(chosen_list) == k:
            answer = chosen_list[:]
            return True
        # not enough vertices left
        if len(chosen_list) + candidates_mask.bit_count() < k:
            return False
        # pick a vertex (least significant bit)
        v = (candidates_mask & -candidates_mask).bit_length() - 1

        # branch 1: take v
        new_chosen = chosen_mask | (1 << v)
        new_cand = candidates_mask & ~adj[v] & ~(1 << v)
        if dfs(new_chosen, new_cand, chosen_list + [v]):
            return True

        # branch 2: skip v
        candidates_mask &= ~(1 << v)
        if dfs(chosen_mask, candidates_mask, chosen_list):
            return True

        return False

    if dfs(0, ALL, []):
        print("YES")
        # convert to 1‑based indices
        print(' '.join(str(x + 1) for x in answer))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
