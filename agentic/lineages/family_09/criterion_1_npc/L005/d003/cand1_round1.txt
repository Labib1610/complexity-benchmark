# Problem A — Operational Synergy

Time limit: 5 s   Memory limit: 256 MB

## Description

A corporate department needs to assemble a specialized task force from its staff. The department's open-plan office contains exactly 46 desks, meaning the total staff count, **n**, can be any integer from 1 up to this physical maximum. Each employee is assigned a sequential identification number starting from 1 up to **n**.

Human resources maintains a log of **m** documented communication barriers. Each barrier specifically names two distinct employees who cannot effectively collaborate. The number of such logs can range from zero up to the theoretical maximum where every possible unique pair of employees has a record.

Your objective is to form a task force of exactly **k** employees. The required size **k** will be at least 1 and cannot exceed the total staff count **n**. To ensure operational synergy, the chosen task force must be structured such that for every documented communication barrier, at least one of the two named individuals is excluded from the task force.

Determine if such a task force can be assembled, and if so, identify its members.

## Input

The first line provides three integers: the staff count **n**, the number of communication barriers **m**, and the required task force size **k**. The exact bounds on these values are dictated by the physical and logical limits detailed in the description.

Each of the subsequent **m** lines contains two distinct integers representing a pair of employees with a documented communication barrier. No pair of employees is logged more than once in the input, regardless of the order in which they are listed.

## Output

If it is possible to assemble a task force of exactly **k** employees meeting the criteria, output `YES` on the first line. On the second line, output the **k** distinct employee identification numbers that make up the task force, separated by spaces. Any valid task force configuration is acceptable. Output only the selected members.

If no such task force can be formed, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

```

```


### Example 3

**Input**
```

1 2
2 3
1 3
```

**Output**
```
YES
1
```
