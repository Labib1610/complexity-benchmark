<METHOD_NAME>Symmetric Difference Equality</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the condition "no two selected vertices share an edge" with the mathematically equivalent "the symmetric difference between the selected set and any edge's endpoints has size at least k". This masks the Independent Set structure while preserving exact semantics, preventing pattern-matching models from instantly mapping it to standard graph algorithms.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Zero-Interference Cluster

Time limit: 5 s   Memory limit: 256 MB

## Description

A scientific observatory is equipped with **n** telemetry sensors (numbered 1 to **n**). 
During initial calibration, engineers catalogued **m** potential interference patterns. Each interference pattern is defined by exactly two specific sensors.

The observatory needs to activate a focused cluster of exactly **k** sensors for a delicate measurement. 
For any chosen cluster of sensors $C$ and any interference pattern $P$ (which consists of exactly two sensors), the *divergence score* is defined as the number of sensors that are present in exactly one of the two sets (either in $C$ or in $P$, but not in both).

A cluster configuration $C$ of size exactly **k** is considered **clean** if, for every one of the **m** listed interference patterns, its divergence score with respect to $C$ is at least **k**.

Given the total number of sensors **n**, the number of known interference patterns **m**, and the target cluster size **k**, determine whether a clean cluster of exactly **k** sensors can be configured, and if so, report one.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing the two sensors that make up a specific interference pattern. The input will never list the same pair of sensors more than once.

## Output

If a clean cluster of **k** sensors exists, print `YES` on the first line, then on the second line print the **k** distinct sensor numbers to be activated, separated by spaces. If multiple clean clusters exist, any valid configuration is accepted. Print only the **k** activated sensors.

If no such cluster exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

In Example 2, activating sensors 1, 3, and 5 forms a clean cluster. For the first pattern {1, 2}, the sensors present in exactly one of the cluster or the pattern are 2, 3, and 5 (a total of 3 sensors, which is at least k=3). For the second pattern {3, 4}, the sensors present in exactly one of the two sets are 1, 4, and 5 (a total of 3). Thus, the condition is met for all patterns.
In Example 1, any choice of 3 sensors will fail the condition for at least one pattern. For instance, if sensors 1, 2, and 3 are chosen, the pattern {1, 2} yields only sensor 3 as being in exactly one of the sets, giving a divergence score of 1 (which is less than k=3).
</STATEMENT>
<RATIONALE>
The direct constraint "zero interference patterns are generated" trivially mapped to an Independent Set solver because it prohibited both endpoints of an edge from being in the chosen set. I replaced this with an equivalent property based on symmetric differences: the size of the symmetric difference between a chosen set of size k and any edge of size 2 is at least k if and only if the chosen set contains at most one endpoint of the edge. This forces models to algebraically deduce the independent set condition rather than pattern-matching the wording.
</RATIONALE>
<PRESERVED_ANSWER>
The symmetric difference between a size-k set and a size-2 set is k+2 if they are disjoint, k if they intersect at one element, and k-2 if the size-2 set is fully contained in the size-k set; thus requiring the difference to be at least k is perfectly equivalent to forbidding both elements of any pattern from being in the cluster.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem is still finding an Independent Set of size k in an undirected graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "present in exactly one of the two sets" if they do not correctly identify that the sets being compared are the entire chosen cluster $C$ and the specific 2-sensor pattern $P$, but the mathematical definition given is standard and unambiguous.
</RISK>
