<STATEMENT>
# Problem A — Zero-Valued Quadratic Assignment

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing a homogeneous quadratic polynomial $P(x_1, x_2, \dots, x_n)$ over $n$ variables.
The polynomial is the sum of $m$ distinct terms (if $m=0$, then $P=0$). Each term is the product of two distinct variables $x_u \cdot x_v$, and every term has a coefficient of 1. 

You need to find an assignment of values to the variables $x_1, \dots, x_n$ such that:
1. Every variable $x_i$ is assigned a value from the set $\{0, 1\}$.
2. Exactly $k$ variables are assigned the value 1.
3. The polynomial $P(x_1, \dots, x_n)$ evaluates to exactly 0.

Given the total number of variables $n$, the number of terms $m$, and the target sum $k$, determine whether such an assignment exists. If a valid assignment is possible, report one by listing the indices of the variables that should be set to 1.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing a term $x_u \cdot x_v$ in the polynomial. The input will never list the same term more than once.

## Output

If a valid assignment of exactly **k** ones exists that makes the polynomial evaluate to 0, print `YES` on the first line, then on the second line print the **k** distinct indices of the variables to be set to 1, separated by spaces. If multiple valid assignments exist, any of them is accepted. Print only the **k** indices.

If no such assignment exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

In Example 2, setting $x_1 = 1$, $x_3 = 1$, and $x_5 = 1$ (with $x_2 = 0$ and $x_4 = 0$) is valid. The polynomial is $P = x_1 x_2 + x_3 x_4$. Substituting the values gives $1 \cdot 0 + 1 \cdot 0 = 0$. Thus, exactly 3 variables are set to 1 and the polynomial evaluates to 0.
In Example 1, the polynomial is $P = x_1 x_2 + x_1 x_3 + x_2 x_3 + x_3 x_4$. Any choice of setting exactly 3 variables to 1 will cause at least one of the terms in the polynomial to evaluate to 1, meaning the total sum will be strictly greater than 0.

<RATIONALE>
The problem was completely reframed from a scenario about sensors and interference conflicts into finding a specific root for a homogeneous quadratic polynomial over a pseudo-boolean domain. This removes all graph-related vocabulary and structural hints, forcing the model to either deduce that $x_u x_v = 0$ implies a mutual-exclusion graph that requires Bron-Kerbosch/bitset pruning, or fail by attempting a generic backtracking approach that Time Limits on $N=46$.
</RATIONALE>
<PRESERVED_ANSWER>
Because variables must be 0 or 1 and all coefficients are 1, the polynomial evaluates to 0 if and only if no two variables in any given term are simultaneously set to 1, exactly preserving the mutual-exclusion logic of the original interference patterns.
</PRESERVED_ANSWER>
