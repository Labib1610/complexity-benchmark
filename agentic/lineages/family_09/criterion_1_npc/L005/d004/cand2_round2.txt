# Problem A — Zero-Penalty Binary Assignment

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing a system of **n** binary variables, $x_1, x_2, \dots, x_n$, where each variable must be assigned a value of either 0 or 1.
The system requires exactly **k** variables to be set to 1, while the remaining **n** − **k** variables must be set to 0.

You are provided with a list of **m** unordered pairs of indices. Each pair $\{u, v\}$ in the list represents a potential penalty. For a given assignment of the variables, a pair $\{u, v\}$ contributes 1 to the total "penalty score" if and only if both $x_u = 1$ and $x_v = 1$. If either variable is 0, the pair contributes 0. The total penalty score is the sum of the contributions from all **m** listed pairs.

Your task is to determine whether there exists an assignment of exactly **k** ones such that the total penalty score evaluates to exactly 0. If such an assignment exists, you must report the indices of the variables that are set to 1.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing a pair of indices in the penalty list. No unordered pair $\{u, v\}$ will appear more than once in the input.

## Output

If a valid assignment exists, print `YES` on the first line, then on the second line print the **k** distinct indices of the variables that are set to 1, separated by spaces. If multiple valid assignments exist, any of them is accepted. Print only the **k** indices.

If no such assignment exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

In Example 2, setting variables 1, 3, and 5 to 1 (and variables 2 and 4 to 0) yields a total penalty score of 0. For the first pair $\{1, 2\}$, $x_2 = 0$, so it contributes 0. For the second pair $\{3, 4\}$, $x_4 = 0$, so it contributes 0. Thus, the total penalty score is exactly 0.
In Example 1, any assignment containing three 1s will result in both variables of at least one listed pair being set to 1, making the total penalty score strictly greater than 0.
</STATEMENT>
<RATIONALE>
The problem is reframed from a physical sensor network to a binary constraint satisfaction problem (CSP). This forces the model to recognize the structural isomorphism between a 0-penalty binary assignment and an independent set. Models relying on surface-level keywords will likely attempt to write a generic backtracking CSP solver, which lacks the graph-specific bitmask pruning heuristics required to pass the tight 5-second time limit for n=46.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that exactly k variables are set to 1 and no listed pair has both variables set to 1 is mathematically identical to selecting k vertices such that no two share an edge.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Independent Set problem (or equivalently, the clique problem on the complement graph), preserving its NP-complete status.
</PRESERVED_CLASS>
