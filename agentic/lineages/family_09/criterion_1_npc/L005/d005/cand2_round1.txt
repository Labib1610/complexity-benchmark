# Problem A — Quantum State Stabilization

Time limit: 5 s   Memory limit: 256 MB

## Description

You are configuring a quantum computing array consisting of **n** distinct qubits (numbered 1 to **n**). Due to thermal constraints, you must excite exactly **k** qubits to the $|1\rangle$ state, while the remaining **n - k** qubits must remain in the $|0\rangle$ state. Let $s_i \in \{0, 1\}$ represent the state of the $i$-th qubit.

The system features **m** entanglement channels. Each channel links a specific pair of qubits, **u** and **v**. 
For the quantum array to remain stable, the states of the qubits connected by each entanglement channel must satisfy the following stability equation:

$3^{s_u + s_v} - 2^{s_u + s_v} = s_u + s_v$

If even a single entanglement channel violates this equation, the entire array will decohere.

Given the total number of qubits **n**, the number of entanglement channels **m**, and the required number of excited qubits **k**, determine if a stable configuration of exactly **k** excited qubits exists, and if so, report one.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing two qubits linked by an entanglement channel. The input will never list the same channel more than once.

## Output

If a stable configuration of **k** excited qubits exists, print `YES` on the first line, then on the second line print the **k** distinct qubit numbers that are excited to the $|1\rangle$ state, separated by spaces. If multiple stable configurations exist, any valid selection is accepted. Print only the **k** excited qubits.

If no such configuration exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

In Example 2, exciting qubits 1, 3, and 5 means $s_1=1, s_3=1, s_5=1$, and $s_2=0, s_4=0$.
For the first channel (1, 2), $s_1+s_2 = 1+0 = 1$. The equation evaluates to $3^1 - 2^1 = 3 - 2 = 1$, which exactly equals the right-hand side of $1$. This channel is stable.
For the second channel (3, 4), $s_3+s_4 = 1+0 = 1$. The equation evaluates to $3^1 - 2^1 = 1$, which equals $1$. This channel is stable.
Since all channels are stable and exactly 3 qubits are excited, this is a valid configuration.

In Example 1, any configuration of 3 excited qubits will force at least one channel to have both its qubits excited ($s_u=1$ and $s_v=1$). For such a channel, $s_u+s_v = 2$. The stability equation evaluates to $3^2 - 2^2 = 9 - 4 = 5$, which does not equal the right-hand side of $2$. Thus, the array decoheres, making it impossible to form a stable configuration.
