<STATEMENT>
# Problem A — Gene Regulation Network

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing a genetic regulation network containing **n** genes. 
In this network, there are **m** known regulatory pathways. Each pathway is controlled by exactly two distinct genes. 
For any gene, its *pathway count* is defined as the number of regulatory pathways it controls.

You need to select exactly **k** genes to stimulate. 
When a set of genes is stimulated, the system's behavior is characterized by two metrics:
1. The *Total Pathway Count*: the sum of the pathway counts of all the stimulated genes.
2. The *System Resonance*: for each of the **m** pathways, let $c$ be the number of stimulated genes that control it (so $c$ can be 0, 1, or 2). The *resonance* of that pathway is calculated as $2^c - 1$. The *System Resonance* is the sum of the resonances of all **m** pathways.

Your task is to select exactly **k** genes from the **n** available genes such that the *System Resonance* is exactly equal to the *Total Pathway Count*.

If such a selection exists, report it by listing the 1-based indices of the selected genes.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ **n** ≤ 46, 0 ≤ **m** ≤ **n**·(**n**−1)/2, 1 ≤ **k** ≤ **n**).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), indicating that a regulatory pathway is controlled by gene **u** and gene **v**. The input will never list the same pair of genes more than once.

## Output

If a valid selection exists, print `YES` on the first line, then on the second line print the **k** distinct indices of the selected genes, separated by spaces. If multiple valid selections exist, any valid selection is accepted. Print only the **k** selected indices.

If no such selection exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

In Example 2, if we stimulate genes 1, 3, and 5:
- Gene 1 controls one pathway (shared with 2). Its pathway count is 1.
- Gene 3 controls one pathway (shared with 4). Its pathway count is 1.
- Gene 5 controls zero pathways. Its pathway count is 0.
The Total Pathway Count is 1 + 1 + 0 = 2.
For the pathways:
- Pathway (1, 2) is controlled by 1 stimulated gene (gene 1). Its resonance is $2^1 - 1 = 1$.
- Pathway (3, 4) is controlled by 1 stimulated gene (gene 3). Its resonance is $2^1 - 1 = 1$.
The System Resonance is 1 + 1 = 2.
Since 2 equals 2, this selection is valid.

In Example 1, consider selecting exactly 3 genes, for instance 1, 2, and 4.
- Gene 1 controls two pathways: (1, 2) and (1, 3).
- Gene 2 controls two pathways: (1, 2) and (2, 3).
- Gene 4 controls one pathway: (3, 4).
The Total Pathway Count is 2 + 2 + 1 = 5.
For the pathways:
- Pathway (1, 2) is controlled by 2 stimulated genes (1 and 2). Its resonance is $2^2 - 1 = 3$.
- Pathway (1, 3) is controlled by 1 stimulated gene (1). Its resonance is $2^1 - 1 = 1$.
- Pathway (2, 3) is controlled by 1 stimulated gene (2). Its resonance is $2^1 - 1 = 1$.
- Pathway (3, 4) is controlled by 1 stimulated gene (4). Its resonance is $2^1 - 1 = 1$.
The System Resonance is 3 + 1 + 1 + 1 = 6.
Since 6 ≠ 5, this selection is invalid. In fact, no selection of exactly 3 genes will make these two metrics equal.
</STATEMENT>
<RATIONALE>
The previous footprint-based affordance allowed models to easily pattern-match the independent set condition. This rewrite uses an algebraic identity: a pathway with $c$ selected endpoints contributes $c$ to the total degree sum but $2^c - 1$ to the system resonance. The equality $\sum c = \sum (2^c - 1)$ holds if and only if $c \le 1$ for all pathways, which forces the model to perform this specific algebraic deduction before it can recognize the underlying algorithmic structure.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $\sum (2^c - 1) = \sum c$ simplifies algebraically to $N_1 + 3N_2 = N_1 + 2N_2 \implies N_2 = 0$, meaning no pathway has two selected endpoints, which perfectly preserves the original independent set requirement.
</PRESERVED_ANSWER>

The problem still asks for an independent set of exactly size $k$ in an undirected graph, maintaining its status as an NP-complete problem solvable via branch-and-bound on the complement graph.
</PRESERVED_CLASS>
