# Problem A — Harmonious Committee

Time limit: 5 s   Memory limit: 256 MB

## Description

A corporate department has **n** employees (numbered 1..n) and a record of **m** formal grievances. Each grievance indicates that one specific employee has filed a complaint against another.

A project committee is **harmonious** if it avoids any internal friction. Specifically, for every grievance listed in the records, it is forbidden for the committee to contain both the employee who filed the grievance and the employee who is the subject of the grievance. 

Given a target committee size **k**, decide whether a harmonious committee of exactly **k** employees exists, and if so report one.

## Input

The first line contains three integers **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
Each of the next **m** lines contains two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v): employee **u** filed a grievance against employee **v**. No grievance is listed twice.

## Output

If a harmonious committee of **k** employees exists, print `YES` on the first line, then on the second line print **k** distinct employee numbers forming such a committee, separated by spaces. Any committee satisfying the condition is accepted.

If no such committee exists, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

A harmonious committee ensures that no two chosen employees correspond to the filer and subject of a grievance. In Example 2, employees 1, 3 and 5 can be selected because no grievance exists involving both members of any pair among them. In Example 1, no three of the four employees can be selected without including both the filer and the subject of at least one grievance.
</STATEMENT>
<RATIONALE>
The problem was modified to present the input relationships as directed (employee `u` filing a grievance against employee `v`) rather than as mutual, undirected conflicts. This removes the immediate pattern match to undirected graph concepts. Models must now deduce that the exclusion rule ("forbidden to contain both") applies symmetrically regardless of the grievance's direction, thereby reconstructing the undirected independent set logic on their own.
</RATIONALE>
<PRESERVED_ANSWER>
The condition for a valid committee remains exactly the same: if a pair {u, v} appears in the input (in either order), the committee cannot contain both u and v, making all valid outputs identical to the seed.
</PRESERVED_ANSWER>

The underlying mathematical problem is still Independent Set on an undirected graph, which is NP-complete, because the presence of an ordered pair `u v` in the input translates directly to an undirected edge {u, v} that cannot be fully included in the chosen subset.
</PRESERVED_CLASS>
