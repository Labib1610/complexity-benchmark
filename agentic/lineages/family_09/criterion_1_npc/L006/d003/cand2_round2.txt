# Problem A — Multiplex Assay Design

Time limit: 5 s   Memory limit: 256 MB

## Description

A bioinformatics facility is developing a new multiplex diagnostic panel from a library of **n** distinct biological probes, indexed 1 through **n**.

To achieve the required detection sensitivity, the panel must incorporate exactly **k** distinct probes. However, due to molecular interference, certain probes cannot be combined. The facility has documented **m** cross-reactivity pairs. Each pair indicates two specific probes that will bind to each other rather than their target sequences; if a diagnostic panel contains both, the entire mixture fails.

You must determine if it is possible to isolate a subset of exactly **k** probes such that the panel remains completely functional. A panel is functional if and only if no two probes within the chosen subset appear together in any of the **m** documented cross-reactivity pairs.

## Input

The first line provides three integers: **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
Following this are **m** lines, each containing two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), which represent a cross-reactivity pair between probe **u** and probe **v**. Each mutually incompatible pair of probes is listed at most once.

## Output

If a functional panel of exactly **k** probes can be constructed, print `YES` on the first line. On the second line, print the **k** index numbers of the chosen probes, separated by spaces. The testing framework will validate your submission by checking if the **k** probes are completely free of cross-reactivity. Should there be several qualifying subsets of size **k**, providing any single one is sufficient.

If no such panel can be constructed, print `NO`.
