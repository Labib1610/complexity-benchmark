# Problem A — Multiplex Assay Design

Time limit: 5 s   Memory limit: 256 MB

## Description

To configure a new custom diagnostic panel, a biotechnology facility must isolate a precise number of genetic probes. The facility is provided with a batch of **n** candidate probes, which are labeled sequentially starting from 1.

Preliminary chemical screenings have revealed that certain pairs of probes will cross-react if mixed in the same reaction phase, which invalidates the panel's results. A total of **m** such cross-reactive pairs have been documented.

You must determine if it is possible to finalize a panel of exactly **k** distinct probes that achieves absolute chemical stability. For the panel to be stable, no two probes within your selection can be documented as a cross-reactive pair.

## Input

The first line of input provides three integers: **n**, **m**, and **k**.
The facility processes candidates using standard 48-well microtiter plates. Because two wells are strictly reserved for calibration controls, the total number of candidate probes **n** will never exceed the remaining available wells. At least one candidate probe will always be provided.
The number of cataloged reactive pairs **m** ranges from zero up to the maximum possible number of unique pairs that can be formed from the **n** candidates.
The target panel size **k** will be at least one and will not exceed **n**.

The next **m** lines specify the cross-reactive pairs. Each line contains two integers **u** and **v**, representing the identifiers of the two reacting probes. Probe identifiers are integers from 1 to **n**. Every line lists two distinct probes (**u** ≠ **v**), and no cross-reactive pair is documented more than once.

## Output

If a stable panel of exactly **k** probes can be formed, print `YES` on the first line. On the second line, print the **k** distinct identifiers of the selected probes, separated by spaces. The automated evaluation system will verify that your chosen set contains no cross-reactive pairs.

If no such stable panel is possible, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```

```

**Output**
```
YES

```

### Example 3

**Input**
```

1 2
2 3
1 3
```

**Output**
```
YES
1
```
