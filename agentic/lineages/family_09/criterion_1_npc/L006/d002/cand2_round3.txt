# Problem A — Multiplex Assay Design

Time limit: 5 s   Memory limit: 256 MB

## Description

A genetics laboratory needs to finalize a multiplex assay by filtering a pool of **n** candidate genetic markers, which are identified by integers from 1 up to **n**.

During testing, certain pairs of these markers experience primer interference. The research team has cataloged **m** such hazardous pairs. To ensure a stable reaction, you must neutralize all **m** interferences. An interference is neutralized if at least one of the two markers involved is discarded from the pool.

Your objective is to determine whether it is feasible to discard exactly **n** - **k** markers (thereby retaining exactly **k** distinct markers for the assay) such that every cataloged interference is neutralized by the discarded group.

## Input

The initial line provides three integers: **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n). These represent the candidate count (limited by the equipment's 46 physical slots), the interference count, and the retention target.

Following this, there are **m** lines. Each line specifies two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), indicating a pair of markers that interfere with one another. Each interfering pair is listed at most once.

## Output

When a successful configuration is possible, print `YES` on the first line. On the next line, print the **k** distinct identifiers of the markers you have chosen to retain, separated by spaces. The automated evaluation system will verify that the discarded markers successfully neutralize all interferences.

When no such configuration is possible, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

<RATIONALE>
I reframed the independent set problem (choosing $k$ non-interfering markers) as a vertex cover problem (discarding $n-k$ markers to neutralize all interferences). This forces models relying on hardcoded independent set branch-and-bound templates to adapt their state representations and pruning logic to cover all edges, rather than just checking for adjacency among selected vertices.
</RATIONALE>
<PRESERVED_ANSWER>
Any valid independent set of size $k$ leaves exactly $n-k$ markers that cover all edges, meaning the set of $k$ retained markers is mathematically identical in both formulations.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains NP-complete, as it is a direct Karp reduction (complement) from Independent Set to Vertex Cover.
</PRESERVED_CLASS>
<RISK>
Models might quickly misread the prompt and output the discarded markers instead of the retained ones, although the text explicitly states "print the k distinct identifiers of the markers you have chosen to retain".
</RISK>
