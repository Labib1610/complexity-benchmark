# Problem A — Multiplex Assay Design

Time limit: 5 s   Memory limit: 256 MB

## Description

A genetics laboratory is finalizing the configuration for a new multiplex assay intended to simultaneously test multiple genetic markers. The candidate pool consists of **n** distinct markers, indexed from 1 to **n**.

During the chemical synthesis phase, specific marker pairs exhibit primer interference, making them mutually incompatible in the same assay. Extensive testing has cataloged **m** such incompatible pairs.

The laboratory's testing apparatus must be configured with a payload of exactly **k** distinct markers. A proposed payload is strictly viable only if it contains absolutely no primer interference among any of its constituent markers.

You must determine whether a viable payload of exactly **k** markers can be constructed from the candidate pool. If such a configuration is possible, you must provide a sequence of markers that demonstrates a viable payload.

## Input

The first line provides three integers: **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).
The subsequent **m** lines each contain two integers, **u** and **v** (1 ≤ u, v ≤ n, u ≠ v). Each line specifies that marker **u** and marker **v** are mutually incompatible due to primer interference. The list contains no duplicate pairs.

## Output

If a viable payload of exactly **k** markers exists, print `YES` on the first line. On the second line, print the **k** distinct indices of the markers included in your payload, separated by spaces. The laboratory's verification system will authenticate the payload; you may supply whichever viable configuration you have constructed.

If no viable payload is possible, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```
