# Problem A — Unacquainted Cohort

Time limit: 5 s   Memory limit: 256 MB

## Description

Within a digital community, there are **n** registered accounts, identified by integers from 1 to **n**. The platform's database contains **m** records of mutual acquaintance, where each record indicates that two specific accounts have interacted and are thus known to one another.

We wish to select a cohort of exactly **k** accounts to participate in a blind study. For the study's integrity, it is strictly required that no two accounts in the chosen cohort are acquainted. In other words, there must not be any record of interaction between any pair of accounts included in the selection.

Determine if it is possible to form such a completely unacquainted cohort of size exactly **k**, and if so, identify its members.

## Input

The first line provides three space-separated integers: **n**, **m**, and **k** (1 ≤ n ≤ 46, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ k ≤ n).

Following this are **m** lines, each containing two integers **u** and **v** (1 ≤ u, v ≤ n, u ≠ v), representing a record of mutual acquaintance between account **u** and account **v**. No pair of accounts will appear in the records more than once.

## Output

If there is a valid cohort of exactly **k** accounts where no two accounts are acquainted, output `YES` on the first line. On the second line, output the **k** distinct account identifiers that make up this cohort, separated by spaces. If there are multiple valid cohorts, any one of them is accepted.

If no such cohort can be formed, output `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```

## Note

A completely unacquainted cohort requires that no two chosen accounts have a record of interaction. In Example 2, accounts 1, 3, and 5 have no mutual acquaintances among them. In Example 1, no three of the four accounts are mutually unacquainted.
