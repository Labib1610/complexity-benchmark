# Problem A — Safe Concurrent Execution

Time limit: 5 s   Memory limit: 256 MB

## Description

A server environment has **n** background processes available, numbered 1 through **n**. The system administrator needs to select exactly **k** distinct processes to run concurrently.

The server's architecture includes **m** two-endpoint data buses. Each bus physically connects exactly two distinct processes. When a process is activated, it sends a high-voltage signal across all buses connected to it. A bus can safely absorb the voltage from one active process. However, if both processes connected to a bus are activated simultaneously, the combined voltage will cause the bus to overload and fail. 

A concurrent execution configuration is safe if and only if no bus receives a high-voltage signal from both of its endpoints.

The system is housed in a mainframe with 46 process bays, establishing the strict upper limit on the number of processes **n** (which is at least 1). The number of buses **m** ranges from none up to the maximum possible count where every process shares a dedicated bus with every other process. The target batch size **k** is at least 1 and naturally cannot exceed **n**.

Given the **n** processes and the layout of the **m** buses, determine whether it is possible to select exactly **k** processes for safe concurrent execution. If a safe configuration is possible, you must provide one valid selection of processes.

## Input

The first line of the input contains three integers **n**, **m**, and **k**. The physical limits and valid ranges for these values are defined by the mainframe's architecture as described above.
The next **m** lines each contain two integers **u** and **v**, representing the distinct process numbers connected by a specific bus.
The order of the two processes on a line does not matter, and no bus's pair of processes is listed more than once.

## Output

If a safe concurrent execution of exactly **k** processes can be configured, print `YES` on the first line. On the second line, print **k** distinct integers representing the process numbers to execute, separated by spaces. If there are multiple valid selections, any one will be accepted.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```
