# Problem A — Secure Audit Scheduling

Time limit: 5 s   Memory limit: 256 MB

## Description

A financial institution maintains **n** accounts, indexed from 1 to **n**. Today's auditing schedule requires the team to isolate exactly **k** distinct accounts for review.

The system's integrity relies on **m** reconciliation channels, each forming a direct bridge between two specific accounts. Running simultaneous audits on bridged accounts causes immediate database deadlocks. Therefore, a strict exclusion protocol applies: for any given reconciliation channel, at most one of the two connected accounts may be included in the audit. 

Given the total number of accounts and the specific pairs linked by the **m** reconciliation channels, you must determine if it is possible to securely schedule exactly **k** accounts for today's audit. If a valid schedule exists, output one such selection.

*Performance note:* Hidden test cases include adversarial configurations at the maximum size bounds and specific **k** values designed to defeat standard recursive search and unoptimized subset enumeration. A tightly bounded search method is required to succeed within the time limit.

## Input

The first line of the input contains three integers **n**, **m**, and **k** (1 ≤ **n** ≤ 46, 0 ≤ **m** ≤ **n**·(**n**−1)/2, 1 ≤ **k** ≤ **n**).
The next **m** lines each contain two integers **u** and **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), representing the two accounts bridged by a specific reconciliation channel.
The order of the two accounts on a line does not matter, and no channel's pair of accounts is listed more than once.

## Output

If a safe audit of exactly **k** accounts can be configured, print `YES` on the first line. On the second line, print **k** distinct integers representing the account numbers to audit, separated by spaces. If there are multiple valid selections, any one will be accepted.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
4 4 3
1 2
1 3
2 3
3 4
```

**Output**
```
NO
```

### Example 2

**Input**
```
5 2 3
1 2
3 4
```

**Output**
```
YES
1 3 5
```

### Example 3

**Input**
```
3 3 1
1 2
2 3
1 3
```

**Output**
```
YES
1
```
