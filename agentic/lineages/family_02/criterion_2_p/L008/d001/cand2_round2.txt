# Problem B — Paired Window Constraints

Time limit: 1 s   Memory limit: 256 MB

## Description

A control panel consists of $n$ relays. Each relay must be configured to either Mode 1 or Mode 0 before operation. 

The system's safety protocol defines $m$ interlocks. Each interlock identifies exactly two target settings (a target setting being a specific relay and a required mode). An interlock is violated if a configuration matches **neither** of its two target settings. 

Determine if there is a global configuration of all $n$ relays that violates zero interlocks. If such a configuration exists, provide it; otherwise, report that it is impossible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$). If $m = 0$, no interlocks are given and any configuration is valid.

Each of the next $m$ lines describes one interlock using two non-zero integers $l_1$ and $l_2$ ($|l_i| \le n$). 
A positive integer $x$ represents a target setting of Mode 1 for relay $|x|$. 
A negative integer $x$ represents a target setting of Mode 0 for relay $|x|$. 

An interlock may specify the same relay twice (with the same or opposite modes), and identical interlocks may appear multiple times.

## Output
If no valid configuration exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) representing the mode of each relay from 1 to $n$ in your valid configuration. Any valid configuration that violates zero interlocks will be accepted.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit disjunctive phrasing "passes when at least one of the two targets is met" was removed. Instead, the problem defines a failure condition where an interlock is violated if "neither of its two target settings" is matched. This forces the model to logically invert the NOR condition into an OR condition (or build the implication graph directly from the failure state) rather than pattern-matching a textbook 2-SAT description. Exact numeric bounds were restored in mathematical notation to pass strict extraction checks.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that an interlock is violated if neither target is matched is logically identical to the seed's condition that an interlock passes if at least one target is matched, preserving all valid configurations.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, asking for a satisfying assignment to a set of boolean variables constrained by clauses of size 2, which is solvable in O(n+m) time.
</PRESERVED_CLASS>
