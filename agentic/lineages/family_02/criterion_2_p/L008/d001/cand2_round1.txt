<STATEMENT>
# Problem B — Interlock Equilibrium

Time limit: 1 s   Memory limit: 256 MB

## Description

A control panel contains `n` relays. Each relay must be permanently wired to either Mode 1 or Mode 0. The system's stability is governed by `m` safety interlocks. 

Each interlock couples two relay-mode dependencies. A dependency is a specific relay paired with a designated mode. If the system's configuration rejects the first dependency (by setting the relay to the opposite mode), it triggers a strict requirement that the second dependency must be adopted. Because this mechanism is symmetric, rejecting the second dependency similarly forces the first to be adopted. A configuration is only stable if no interlock is left with both of its dependencies rejected.

Determine if there is a single global configuration for all relays that maintains stability across all interlocks. If so, provide one such configuration; otherwise, report that it is impossible.

## Input

The first line contains two integers `n` and `m`. The control panel is built on a physical chassis that requires at least 1 relay to function and can accommodate a maximum of 100,000 relays, defining the exact limits for `n`. The system's diagnostic buffer is capable of recording anywhere from an empty log of 0 up to 200,000 safety interlocks, establishing the precise range for `m`.

Each of the following `m` lines describes an interlock using two non-zero integers $l_1$ and $l_2$. The absolute value of each integer corresponds to a valid relay index on the chassis (from 1 up to `n`). A positive integer represents a dependency on Mode 1 for that relay, and a negative integer represents a dependency on Mode 0 for that relay.

## Output

If there is no way to wire the relays to maintain stability, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output `n` space-separated integers (each either `0` or `1`) representing the mode of each relay from 1 to `n` in a valid configuration.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note

Any configuration that maintains stability across all interlocks is acceptable. The same dependency may be referenced in multiple interlocks.
</STATEMENT>
<RATIONALE>
Removed the explicit disjunctive phrasing "passes when at least one of the two targets is met". Replaced it with a description of mutual implications (rejecting one dependency forces the other) and a prohibition on rejecting both. This prevents models from immediately pattern-matching textbook 2-SAT clause descriptions, forcing them to derive the $A \lor B$ logic from the described interlock mechanics. Numeric bounds were also moved into physical descriptions of chassis limits and buffer capacities.
</RATIONALE>
<PRESERVED_ANSWER>
The logical requirement that at least one dependency per interlock must be met is preserved through the rule that rejecting one forces the other, meaning the set of satisfying assignments is identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT (finding a satisfying assignment for a 2-CNF formula), solvable in linear time using strongly connected components on an implication graph.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "rejecting the first dependency forces the second" as an exclusive OR or a directed implication rather than a symmetric constraint, although the text explicitly states "this mechanism is symmetric" and "no interlock is left with both of its dependencies rejected".
</RISK>
