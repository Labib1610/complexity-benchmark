We can model this as a **2-SAT** problem.  

Each relay has two possible states: Mode 1 or Mode 0.  
Each interlock forbids a certain combination of two states.  

For example, `1 2` means:  
- It is forbidden that relay 1 is **not** in Mode 1 (i.e., relay 1 = 0) **and** relay 2 is **not** in Mode 1 (i.e., relay 2 = 0).  
So the forbidden combination is `(relay1=0, relay2=0)`.  

Similarly, `-1 -2` means:  
- Forbidden: relay 1 = 1 and relay 2 = 1.  

We can convert each forbidden pair into two implications (clauses) in 2-SAT form.  

Let’s define for each relay `i`:  
- `x_i` = true means relay i is Mode 1  
- `x_i` = false means relay i is Mode 0  

For a forbidden pair `(a, b)`:  
- If `a > 0`, then `a` means `x_a` must be true.  
- If `a < 0`, then `a` means `x_|a|` must be false.  

The forbidden condition is:  
`(not condition_a) AND (not condition_b)` is forbidden.  
So we must have:  
`condition_a OR condition_b` is true.  

That gives us the clause:  
`(literal_a OR literal_b)`  

Where literal is either `x_i` or `¬x_i`.  

We then solve the 2-SAT using implication graph and SCC (Tarjan or Kosaraju).  

Here’s the implementation:  

```python
import sys
sys.setrecursionlimit(1 << 20)
input = sys.stdin.readline

n, m = map(int, input().split())
N = 2 * n  # nodes: 2*i for x_i false, 2*i+1 for x_i true

def node(var):
    # var > 0: x_var true, var < 0: x_var false
    if var > 0:
        return 2 * (var - 1) + 1
    else:
        return 2 * (-var - 1)

def neg_node(u):
    return u ^ 1

g = [[] for _ in range(N)]
gr = [[] for _ in range(N)]

for _ in range(m):
    a, b = map(int, input().split())
    u = node(a)
    v = node(b)
    # clause: u OR v
    # implications: not u -> v, not v -> u
    g[neg_node(u)].append(v)
    g[neg_node(v)].append(u)
    gr[v].append(neg_node(u))
    gr[u].append(neg_node(v))

# Kosaraju SCC
visited = [False] * N
order = []

def dfs1(u):
    visited[u] = True
    for w in g[u]:
        if not visited[w]:
            dfs1(w)
    order.append(u)

for i in range(N):
    if not visited[i]:
        dfs1(i)

comp = [-1] * N
def dfs2(u, cid):
    comp[u] = cid
    for w in gr[u]:
        if comp[w] == -1:
            dfs2(w, cid)

cid = 0
for u in reversed(order):
    if comp[u] == -1:
        dfs2(u, cid)
        cid += 1

# Check satisfiability
for i in range(n):
    if comp[2*i] == comp[2*i+1]:
        print("NO")
        sys.exit()

print("YES")
res = []
for i in range(n):
    # If comp[true] > comp[false], assign true (1)
    if comp[2*i+1] > comp[2*i]:
        res.append('1')
    else:
        res.append('0')
print(' '.join(res))
```
