# Problem B — Paired Window Constraints

Time limit: 1 s   Memory limit: 256 MB

## Description

An industrial control panel features **n** two-position toggle switches. Before initiating a manufacturing cycle, every switch must be locked into either the UP or DOWN position. The system's safety protocol consists of **m** distinct operational constraints. Each constraint highlights exactly two target switch states (for example, switch 3 being UP, or switch 7 being DOWN). For the system to clear the safety inspection, every single constraint must have at least one of its two target states active in the final configuration.

Your task is to determine whether it is possible to assign a global UP/DOWN configuration to all **n** switches such that all **m** safety constraints are satisfied at the same time. If such a configuration exists, you must output one. If the constraints are inherently incompatible, you must report this.

## Input
The first line contains two integers n and m (1 ≤ n ≤ 10^5, 0 ≤ m ≤ 2·10^5).
Each of the following m lines contains two non-zero signed integers l1 and l2, where |li| ≤ n. A positive integer signifies that the target state for the given switch index is UP, while a negative integer signifies that the target state for the absolute value of the index is DOWN. For every line, the final configuration must achieve at least one of the two target states.

## Output
If it is impossible to satisfy all constraints, output a single line containing NO.
Otherwise, output YES on the first line. On the second line, output n space-separated integers s1 s2 … sn (where each si ∈ {0, 1}) detailing a valid configuration. Use 1 to represent UP and 0 to represent DOWN.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any one is accepted. The same switch index may appear in multiple constraints.
