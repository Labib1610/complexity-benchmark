<STATEMENT>
# Problem B — Power Grid Feed Interlocks

Time limit: 1 s   Memory limit: 256 MB

## Description

A power grid consists of $n$ independent feed lines. Prior to commissioning, every feed line must be assigned exactly one of two operational modes: ENERGIZED or ISOLATED.

The grid is safeguarded by $m$ fault-prevention relays. Each relay acts as an activation guard linking two specific target modes across the network. It enforces a strict operational dependency: if the grid configuration rejects the first target mode (by setting its corresponding feed line to the alternative mode), it strictly mandates adopting the second target mode to prevent a system-wide fault. Symmetrically, rejecting the second target mode mandates adopting the first. A full grid configuration is deemed secure if zero relays trip.

Determine whether there exists a global configuration of all $n$ feed lines that is secure, and if so, report one; otherwise, report that the safety requirements are irreconcilable.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two non-zero signed integers $l_1$ and $l_2$, with $|l_i| \le n$. A positive integer $x$ denotes the target mode where feed line $x$ is ENERGIZED, while a negative integer $-x$ denotes the target mode where feed line $x$ is ISOLATED. Each line defines a single relay's dependency: rejecting the target mode denoted by $l_1$ mandates adopting the target mode denoted by $l_2$, and vice versa.

## Output
If no secure configuration exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \ s_2 \ \dots \ s_n$ (each in $\{0, 1\}$) representing any secure configuration, where 1 denotes ENERGIZED and 0 denotes ISOLATED.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple secure configurations may exist; any one is accepted. The same feed line index may appear in multiple relays. The two target modes monitored by a single relay may even refer to the identical mode or opposite modes of the same feed line.
</STATEMENT>
<RATIONALE>
The description of the relay condition was rewritten from "omits both target modes" to an explicit mutual dependency (if the first is rejected, the second is mandated, and vice versa). This removes the direct de Morgan's law shortcut to a standard 2-SAT CNF clause, forcing the model to explicitly parse the implications and build the correct directional edges for the graph rather than relying on boilerplate DIMACS parsing.
</RATIONALE>
<PRESERVED_ANSWER>
The condition "rejecting A mandates adopting B" is logically strictly equivalent to "A OR B", which is exactly the same as the seed's "not simultaneously omitting A and B", preserving all valid configurations.
</PRESERVED_ANSWER>
