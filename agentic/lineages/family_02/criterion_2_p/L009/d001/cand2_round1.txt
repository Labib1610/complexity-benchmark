# Problem B — Grid Interlock Constraints

Time limit: 1 s   Memory limit: 256 MB

## Description

A regional power grid contains **n** distribution sectors. Each sector must be connected to exactly one of two supply feeds: the primary feed (indicated by 1) or the reserve feed (indicated by 0).

To maintain grid stability, engineers have installed **m** interlock mechanisms. Each interlock monitors exactly two specific feed connections. A monitored connection is identified by a non-zero signed integer: a positive value $+i$ means sector $i$ is connected to the primary feed, whereas a negative value $-i$ means sector $i$ is connected to the reserve feed.

An interlock successfully stabilizes that part of the grid as long as at least one of its two monitored connections is active. 

Determine whether a single network-wide configuration of all $n$ sectors can satisfy every interlock simultaneously. If a stable configuration exists, report one; otherwise, report that the interlock requirements are mutually contradictory.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two non-zero signed integers $l_1$ $l_2$, with $|l_i| \le n$. At least one of the two monitored connections must be active for that interlock.

## Output
If no valid configuration exists, print a single line `NO`.
Otherwise print `YES` on the first line. On the second line print $n$ integers $s_1 s_2 \dots s_n$ (each in $\{0, 1\}$) forming any valid configuration.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any one is accepted. The same sector index may appear in multiple interlock requirements.
