We can model each hub as a boolean variable, and each assessment as a constraint on two literals.  

The condition  
\[
E(l_1) + E(l_2) \le 1
\]  
means:  
- If both literals are true (i.e., match their target), sum = 0 → OK.  
- If exactly one is true, sum = 1 → OK.  
- If both are false, sum = 2 → NOT OK.  

So the forbidden case is when both literals are false.  
That is equivalent to: at least one of the two literals must be true.  

This is exactly a **2-SAT** clause:  
\[
(x_{|l_1|} = t_{l_1}) \lor (x_{|l_2|} = t_{l_2})
\]  

We can solve 2-SAT with implication graph and SCC (Kosaraju or Tarjan).  

Here’s the implementation:  

```python
import sys
sys.setrecursionlimit(1 << 20)
input = sys.stdin.readline

n, m = map(int, input().split())
N = 2 * n  # each variable has two nodes: 2*i = false, 2*i+1 = true

def node(var, val):
    # var: 1-based index, val: 0 or 1
    return 2 * (var - 1) + val

g = [[] for _ in range(N)]
gr = [[] for _ in range(N)]

for _ in range(m):
    a, b = map(int, input().split())
    va = 1 if a > 0 else 0
    vb = 1 if b > 0 else 0
    u = node(abs(a), va)
    v = node(abs(b), vb)
    # clause: u or v
    # implications: not u -> v, not v -> u
    g[u ^ 1].append(v)
    g[v ^ 1].append(u)
    gr[v].append(u ^ 1)
    gr[u].append(v ^ 1)

# Kosaraju SCC
visited = [False] * N
order = []

def dfs1(u):
    visited[u] = True
    for w in g[u]:
        if not visited[w]:
            dfs1(w)
    order.append(u)

for i in range(N):
    if not visited[i]:
        dfs1(i)

comp = [-1] * N
def dfs2(u, cid):
    comp[u] = cid
    for w in gr[u]:
        if comp[w] == -1:
            dfs2(w, cid)

cid = 0
for u in reversed(order):
    if comp[u] == -1:
        dfs2(u, cid)
        cid += 1

# Check satisfiability
for i in range(n):
    if comp[2*i] == comp[2*i+1]:
        print("NO")
        sys.exit()

print("YES")
res = []
for i in range(n):
    # if true node has higher comp id, assign true
    res.append('1' if comp[2*i+1] > comp[2*i] else '0')
print(' '.join(res))
```
