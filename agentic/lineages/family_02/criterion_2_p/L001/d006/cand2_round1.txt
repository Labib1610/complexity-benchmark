# Problem B — Logistics Safeguards

Time limit: 1 s   Memory limit: 256 MB

## Description

Management of a logistics network must finalize the operational schedule for its $n$ transit hubs. Every hub $i$ must be assigned a phase state $s_i \in \{0, 1\}$.

Safety inspectors have completed $m$ vulnerability assessments. Each assessment provides two non-zero integer parameters $l_1$ and $l_2$. 

For each assessment, a two-dimensional target vector $(t_1, t_2)$ is defined based on its parameters:
- The first component is $t_1 = 1$ if $l_1 > 0$, and $t_1 = 0$ if $l_1 < 0$.
- The second component is $t_2 = 1$ if $l_2 > 0$, and $t_2 = 0$ if $l_2 < 0$.

The scheduled configuration for this assessment is the two-dimensional vector $(s_{|l_1|}, s_{|l_2|})$. 

An assessment is considered *stable* if the squared Euclidean distance between its scheduled configuration vector and its target vector is strictly less than 2.

A critical failure occurs if there is at least one assessment that is not stable. Your task is to determine whether it is possible to assign a phase state $s_i \in \{0, 1\}$ to every hub such that zero critical failures occur (i.e., all $m$ assessments are stable). If such a schedule can be formed, you must provide one.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$). For clarity, $n$ is up to 100000 and $m$ is up to 200000.

Each of the following $m$ lines provides two non-zero integers $l_1$ and $l_2$ ($1 \le |l_i| \le n$), representing the two parameters of a vulnerability assessment. 

Note that $l_1$ and $l_2$ in an assessment may refer to the same hub, with the same or opposite signs. A hub may appear in any number of assessments, and identical assessments may repeat.

## Output
If no safe schedule is possible, print a single line NO.

Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each being 0 or 1, representing the phase state $s_i$ for hub $i$) that form a valid schedule. Multiple valid schedules may exist; any one is accepted.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit algebraic formula ($q_i = 2s_i - 1$ and sum $\ge 0$) with a geometric constraint: the squared Euclidean distance between a state vector and a target vector must be strictly less than 2. This removes the affordance that allowed models to instantly map $\pm 1$ variables to a 2-SAT OR clause. To succeed, models must now genuinely reason that over a $\{0,1\}$ domain, squared Euclidean distance is equivalent to Hamming distance, and bounding it below 2 implies at least one component must match, thereby rediscovering the 2-SAT structure.
</RATIONALE>
<PRESERVED_ANSWER>
The squared Euclidean distance between two boolean vectors is exactly their Hamming distance; requiring it to be strictly less than 2 means at most 1 component can mismatch, which is mathematically identical to the original requirement that at least one parameter's condition is satisfied.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, solvable in $O(N+M)$ time using strongly connected components on the implication graph.
</PRESERVED_CLASS>
