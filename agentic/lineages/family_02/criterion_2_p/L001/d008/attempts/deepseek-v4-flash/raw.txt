We can model each hub as a boolean variable and each assessment as a constraint.  

Let’s analyze the update rules:

- If `v > 0` and `s = 0` → `Z = 2Z + 1`  
- If `v > 0` and `s = 1` → `Z = Z`  
- If `v < 0` and `s = 1` → `Z = 2Z + 1`  
- If `v < 0` and `s = 0` → `Z = Z`

So the code increases only when the sign of `v` and the state `s` are “mismatched” in a certain way:  
- Positive `v` increases when `s = 0`  
- Negative `v` increases when `s = 1`

We start with `Z = 0`, process `l1`, then `l2`.  
We need final `Z < 3`.  

Since each step can at most double and add 1, the only way to stay `< 3` is to avoid two increments.  
Possible final `Z` values:  
- 0 (no increments)  
- 1 (one increment)  
- 2 (two increments: 0→1→3? Wait: 0→1 then 1→3, so 3 is not allowed)  

Actually:  
- 0 → increment → 1  
- 1 → increment → 3 (not allowed)  

So we can have at most **one** increment across both steps.  

Thus, for each assessment, at least one of the two parameters must **not** cause an increment.  

Define for each parameter `v`:  
- If `v > 0`, increment happens when `s = 0`  
- If `v < 0`, increment happens when `s = 1`  

So for each assessment `(l1, l2)`, we must have:  
`(l1 causes increment) AND (l2 causes increment)` is **false**.  

That is:  
`NOT (increment(l1) AND increment(l2))`  

This is a 2-SAT clause:  
`(¬increment(l1) OR ¬increment(l2))`  

Now, `increment(v)` is a literal depending on the variable `s[|v|]`:  
- If `v > 0`: increment = `¬s[|v|]`  
- If `v < 0`: increment = `s[|v|]`  

So `¬increment(v)` is:  
- If `v > 0`: `s[|v|]`  
- If `v < 0`: `¬s[|v|]`  

Thus each clause becomes:  
`(lit1 OR lit2)` where each lit is either `s[x]` or `¬s[x]`.  

We can solve with standard 2-SAT (implication graph + SCC).  

Implementation plan:  
- Variables: `1..n` for `s[i] = true`, `n+1..2n` for `s[i] = false`.  
- For each assessment, add clause `(lit1 OR lit2)` as two implications.  
- Run Kosaraju or Tarjan SCC.  
- If a variable and its negation are in same SCC → NO.  
- Else assign values by topological order of SCCs.  

Let’s code it.  

```python
import sys
sys.setrecursionlimit(1 << 20)

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    N = 2 * n
    g = [[] for _ in range(N)]
    gr = [[] for _ in range(N)]

    def add_imp(u, v):
        g[u].append(v)
        gr[v].append(u)

    def node(var, val):
        # var: 1..n, val: True/False
        if val:
            return var - 1
        else:
            return var - 1 + n

    for _ in range(m):
        l1, l2 = map(int, input().split())
        # lit1 = not increment(l1)
        # if l1 > 0: increment = not s[|l1|] => not increment = s[|l1|]
        # if l1 < 0: increment = s[|l1|] => not increment = not s[|l1|]
        if l1 > 0:
            lit1 = node(l1, True)
        else:
            lit1 = node(-l1, False)
        if l2 > 0:
            lit2 = node(l2, True)
        else:
            lit2 = node(-l2, False)
        # clause: lit1 OR lit2
        # ¬lit1 -> lit2
        add_imp(lit1 ^ 1, lit2)
        # ¬lit2 -> lit1
        add_imp(lit2 ^ 1, lit1)

    # Kosaraju
    visited = [False] * N
    order = []
    def dfs1(u):
        visited[u] = True
        for w in g[u]:
            if not visited[w]:
                dfs1(w)
        order.append(u)

    for i in range(N):
        if not visited[i]:
            dfs1(i)

    comp = [-1] * N
    def dfs2(u, cid):
        comp[u] = cid
        for w in gr[u]:
            if comp[w] == -1:
                dfs2(w, cid)

    cid = 0
    for u in reversed(order):
        if comp[u] == -1:
            dfs2(u, cid)
            cid += 1

    for i in range(n):
        if comp[i] == comp[i + n]:
            print("NO")
            return

    # Assign values: comp[x] > comp[x+n] => true
    ans = []
    for i in range(n):
        if comp[i] > comp[i + n]:
            ans.append('1')
        else:
            ans.append('0')
    print("YES")
    print(" ".join(ans))

if __name__ == "__main__":
    solve()
```
