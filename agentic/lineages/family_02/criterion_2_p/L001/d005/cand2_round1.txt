<STATEMENT>
# Problem B — Logistics Safeguards

Time limit: 1 s   Memory limit: 256 MB

## Description

Management of a logistics network must finalize the operational schedule for its $n$ transit hubs. Every hub $i$ (for $1 \le i \le n$) must be assigned a state $s_i \in \{0, 1\}$. We define the operational multiplier of hub $i$ as $W_i = 2 s_i - 1$.

Safety inspectors have completed $m$ vulnerability assessments. Each assessment provides two non-zero integers $l_1$ and $l_2$. The projected value of any parameter $v$ under the current schedule is defined as $v \times W_{|v|}$, where $|v|$ is the absolute value of $v$.

An assessment triggers a critical failure if the sum of the projected values of its two parameters $l_1$ and $l_2$ is exactly $-(|l_1| + |l_2|)$. 

Your task is to determine whether it is possible to assign a state $s_i$ to every hub such that zero critical failures occur across all $m$ assessments. If such a schedule can be formed, you must provide one.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$). 

Each of the following $m$ lines provides two non-zero integers $l_1$ and $l_2$ ($1 \le |l_i| \le n$), representing the two parameters of a vulnerability assessment. 

Note that $l_1$ and $l_2$ in an assessment may refer to the same hub, with the same or opposite signs. A hub may appear in any number of assessments, and identical assessments may repeat.

## Output
If no safe schedule is possible, print a single line NO.

Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each being 0 or 1, representing the state $s_i$ for hub $i$) that form a valid schedule. Multiple valid schedules may exist; any one is accepted.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

<RATIONALE>
The previous version used explicit target requirements and boolean logic wording (AND, NOT matching) that models trivially mapped to DIMACS 2-SAT clauses. This rewrite replaces the boolean condition with an algebraically equivalent extreme-value condition: a sum reaching its minimum possible bound. Models must now mathematically deduce that the sum equals $-(|l_1| + |l_2|)$ if and only if both terms are negative, which corresponds exactly to both literals being false, before they can recognize the 2-SAT structure.
</RATIONALE>
<PRESERVED_ANSWER>
Because $W_i \in \{-1, 1\}$, the projected value $v \times W_{|v|}$ is either $|v|$ or $-|v|$, meaning the sum reaches $-(|l_1| + |l_2|)$ strictly when both terms are negative, which perfectly matches the original condition of both parameters failing their target requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, as the algebraic condition translates 1-to-1 into a standard disjunction of two boolean literals, solvable in linear time via strongly connected components on an implication graph.
</PRESERVED_CLASS>
