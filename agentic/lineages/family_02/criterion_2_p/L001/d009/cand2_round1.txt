# Problem B — Logistics Safeguards

Time limit: 1 s   Memory limit: 256 MB

## Description
Management of a logistics network must finalize the operational schedule for its $n$ transit hubs. Every hub $i$ must be assigned a phase state $s_i \in \{0, 1\}$.

Safety inspectors have completed $m$ vulnerability assessments. Each assessment provides two non-zero integer parameters $l_1$ and $l_2$. 

For each assessment, a diagnostic sequence is executed to compute a final integer code $Z$. The code $Z$ starts at $1$. The sequence processes the first parameter $l_1$, then the second parameter $l_2$.

When processing a parameter $v$, an amplification factor $A_v$ is determined based on the current phase $s_{|v|}$ of its designated hub $|v|$. The rule is:
- If $v > 0$, $A_v = 5 - 3s_{|v|}$.
- If $v < 0$, $A_v = 2 + 3s_{|v|}$.

The diagnostic code $Z$ is updated by multiplying it by $A_v$ modulo 25. That is, $Z \leftarrow (Z \cdot A_v) \bmod 25$.

An assessment is considered *stable* if its final diagnostic code $Z$ after processing both parameters is not equal to $0$. A critical failure occurs if there is at least one assessment that is not stable. 

Your task is to determine whether it is possible to assign a phase state $s_i \in \{0, 1\}$ to every hub such that zero critical failures occur (i.e., all $m$ assessments are stable). If such a schedule can be formed, you must provide one.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$). For clarity, $n$ is up to 100000 and $m$ is up to 200000.

Each of the following $m$ lines provides two non-zero integers $l_1$ and $l_2$ ($1 \le |l_i| \le n$), representing the two parameters of a vulnerability assessment. 

Note that $l_1$ and $l_2$ in an assessment may refer to the same hub, with the same or opposite signs. A hub may appear in any number of assessments, and identical assessments may repeat.

## Output
If no safe schedule is possible, print a single line NO.

Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each being 0 or 1, representing the phase state $s_i$ for hub $i$) that form a valid schedule. Multiple valid schedules may exist; any one is accepted.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

<METHOD_NAME>Zero-Divisor Modular Encoding</METHOD_NAME>
<METHOD_DESCRIPTION>Replaced the explicit if/else state machine with an algebraic expression modulo 25. The parameters map to factors of 2 or 5, and the assessment fails iff the product is 0 mod 25, which occurs exactly when both factors are 5. This preserves the 2-SAT logic perfectly while requiring the model to deduce the zero-divisor property rather than directly reading a boolean threshold.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<RATIONALE>
The previous version used an explicit `Z <- 2Z + 1` branching structure that models trivially executed symbolically to map bounds to boolean logic. This rewrite replaces the branching with a single algebraic recurrence modulo 25. To recover the 2-SAT clause, the model must deduce that the state variables map to the domain {2, 5} and that their product is congruent to 0 mod 25 if and only if both factors are 5, hiding the boolean logic behind a modular zero-divisor property.
</RATIONALE>
<PRESERVED_ANSWER>
The amplification factors $A_v$ evaluate to exactly 5 for the original "triggered" state and 2 for the "untriggered" state; since $Z = (A_{l_1} \cdot A_{l_2}) \bmod 25$, $Z=0$ if and only if both parameters are triggered ($5 \times 5 = 25 \equiv 0$), matching the exact same failure condition as the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem requires satisfying a set of constraints where each constraint forbids exactly one combination of two boolean variables, which is exactly the canonical definition of 2-SAT.
</PRESERVED_CLASS>
