# Problem B — Logistics Safeguards

Time limit: 1 s   Memory limit: 256 MB

## Description

A logistics network relies on $n$ transit hubs. For the upcoming shift, every hub must be permanently assigned exactly one of two operational states: ACTIVE or DORMANT.

The network management has identified $m$ potential breakdown scenarios. Each scenario is tied to a pair of operational expectations. An expectation specifies a particular hub and the state it is expected to be in.

A breakdown scenario is triggered if and only if the final network configuration fails to match both of its paired expectations simultaneously. To maintain network integrity, you must ensure that no breakdown scenarios are triggered.

Determine whether there is a single, global assignment of states to all $n$ hubs that preserves network integrity. If a valid configuration exists, provide one; otherwise, report that the requirements are mutually contradictory.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$).

Each of the following $m$ lines provides two non-zero integers $l_1$ and $l_2$ ($1 \le |l_i| \le n$), representing the two expectations associated with a breakdown scenario. 

A positive integer $k$ means the expectation is for hub $k$ to be ACTIVE. A negative integer $-k$ means the expectation is for hub $k$ to be DORMANT. 

Note that $l_1$ and $l_2$ for a given scenario may refer to the same hub, and may have the same or opposite signs.

## Output
If no valid configuration exists, print a single line NO.

Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each being 0 or 1, representing DORMANT and ACTIVE respectively) that form a valid configuration. Multiple valid configurations may exist; any one is accepted.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Removed the explicit "at least one" affordance that allowed models to trivially map the problem to standard 2-SAT clauses. By framing the constraints purely around avoiding simultaneous failures, models must now logically deduce the disjunction (or the corresponding implication edges) rather than relying on surface-level keyword matching.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that a scenario fails if and only if both expectations are unmet is logically identical to requiring at least one expectation to be met, so the valid configurations remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires satisfying a conjunction of clauses where each clause forbids two specific state assignments, which is the exact definition of 2-SAT and thus solvable in linear time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "fails to match both" as "fails to match at least one," though the addition of the word "simultaneously" strongly guards against this ambiguity.
</RISK>
