# Problem B — Paired Hub Constraints

Time limit: 1 s   Memory limit: 256 MB

## Description

A logistics network consists of **n** transit hubs. Before each shift, every hub must be configured as either ACTIVE or DORMANT. The network's operation is governed by **m** routing protocols. 

Each protocol specifies exactly two requirements regarding the state of specific hubs. A protocol is considered satisfied if at least one of its two requirements is met. A requirement consists of a hub identifier and the desired state (ACTIVE or DORMANT) for that hub.

Your task is to determine if there exists a global configuration of all **n** hubs that simultaneously satisfies all **m** protocols. If such an arrangement is possible, provide one valid configuration. If no such configuration can exist, indicate that the requirements are contradictory.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines describes a protocol using two non-zero signed integers $l_1$ and $l_2$, with $|l_i| \le n$. A positive integer $x$ represents a requirement that hub $x$ is ACTIVE, while a negative integer $-x$ represents a requirement that hub $x$ is DORMANT. For each protocol, at least one of its two requirements must be satisfied.

## Output
If no valid configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each either `0` or `1`) representing any valid configuration, where `1` means ACTIVE and `0` means DORMANT.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any one is accepted. The same hub index may appear in multiple requirements.
