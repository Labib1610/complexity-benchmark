<STATEMENT>
# Problem B — Configuration State Search

Time limit: 1 s   Memory limit: 256 MB

## Description

A control panel has **n** binary switches. Commissioning supplies **m** hardware interlocks that must all be respected simultaneously to prevent system faults. 

Each interlock imposes a conditional requirement on the system's global configuration. It links a target mode of a primary switch to a target mode of a secondary switch. The rule strictly dictates that if the primary switch is not set to its target mode, the configuration must have the secondary switch set to its target mode. Given the vast number of possible global states, engineers need to know if a valid state exists without an exhaustive search. 

Decide whether a single global ON/OFF setting of all **n** switches satisfies all interlock requirements at once. If such a configuration exists, report one; otherwise, report that the interlocks are mutually contradictory.

## Input
The first line contains two integers **n** and **m** (1 ≤ n ≤ 10^5, 0 ≤ m ≤ 2·10^5).
Each of the next **m** lines contains two non-zero signed integers $l_1$ and $l_2$, with $|l_i| \le n$. 

The absolute value $|l_i|$ identifies a switch. A positive value designates ON as the target mode, while a negative value designates OFF as the target mode. The first integer $l_1$ represents the primary switch and its target mode, while the second integer $l_2$ represents the secondary switch and its target mode. The interlock establishes the conditional requirement between them as described above.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise print `YES` on the first line. On the second line print **n** integers $s_1 \ s_2 \dots s_n$ (each in {0, 1}) forming any valid assignment, where 1 represents ON and 0 represents OFF.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid assignments may exist; any one is accepted. The same switch may appear in multiple interlocks.
</STATEMENT>
<RATIONALE>
Changed the presentation of the rule from a symmetric forbidden combination (NOT A AND NOT B) to an asymmetric conditional requirement (IF NOT A THEN B). This forces the model to genuinely reason about the logical equivalence to 2-SAT (recognizing that the constraint inherently implies the contrapositive) rather than pattern-matching the symmetric "forbidden opposites" directly into a standard OR clause.
</RATIONALE>
<PRESERVED_ANSWER>
The truth table for "if A is not target then B must be target" is mathematically identical to "A and B cannot both simultaneously be opposite to their targets", so the exact same set of global configurations is valid for every input.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, which is solvable in linear time using strongly connected components on the implication graph, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might interpret the asymmetric text as implying a dynamic, one-way state change rather than a static constraint, though the prompt explicitly states it is a requirement on the "global configuration" and asks if a setting "satisfies all interlock requirements at once".
</RISK>
