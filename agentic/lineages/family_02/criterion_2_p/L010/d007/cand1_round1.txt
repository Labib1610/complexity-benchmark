# Problem B — Frequency Filter Tuning

Time limit: 1 s   Memory limit: 256 MB

## Description

A radio facility contains **n** transmitters. Each transmitter must be tuned to a frequency of either 0 MHz or 1 MHz. 
The facility is equipped with **m** filters to prevent interference. Each filter monitors a pair of transmitters, specified by two non-zero integers $l_1$ and $l_2$. 

The absolute value $|l_i|$ identifies which transmitter is being monitored by the $i$-th connection of the filter. The sign of $l_i$ defines the expected phase $s_i$ for that connection: $s_i = 1$ if $l_i > 0$, and $s_i = -1$ if $l_i < 0$.

For a given tuning of the transmitters, each filter calculates its stability based on the actual phases of the monitored transmitters. If a transmitter is tuned to a frequency $f \in \{0, 1\}$, its actual phase is defined as $q = 2f - 1$. 

Let $q_1$ and $q_2$ be the actual phases of the transmitters monitored by the first and second connections of a filter, respectively. The filter computes two physical quantities:
- The concordant signal $C = s_1 s_2 + q_1 q_2$
- The cross signal $X = s_1 q_2 + s_2 q_1$

A filter operates stably if and only if its concordant signal perfectly balances its cross signal ($C = X$). If $C \neq X$, a system fault occurs.

You must determine whether there exists a single global tuning of all **n** transmitters (each set to 0 or 1) such that all **m** filters operate stably simultaneously. If such a tuning exists, report one; otherwise, report that the filter requirements are mutually contradictory.

## Input
The first line contains two integers **n** and **m** (1 ≤ n ≤ 10^5, 0 ≤ m ≤ 2·10^5).
Each of the next **m** lines contains two non-zero signed integers $l_1$ and $l_2$. For each integer, $1 \le |l_i| \le n$. 
The two integers in a filter may have the same absolute value (meaning the filter monitors the same transmitter twice, potentially with the same or opposite signs).

## Output
If no valid tuning exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print **n** integers $f_1 \ f_2 \dots f_n$ (each in {0, 1}) forming any valid tuning, where the $i$-th integer represents the frequency of transmitter $i$.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid tunings may exist; any one is accepted. The same transmitter may appear in multiple filters, and even twice within the same filter.
</STATEMENT>
<RATIONALE>
The transparent linear inequality $R \ge B$ was replaced with a non-linear polynomial identity $C = X$ (where $C = s_1 s_2 + q_1 q_2$ and $X = s_1 q_2 + s_2 q_1$). This forces models to either algebraically factor the equation into $(s_1 - q_1)(s_2 - q_2) = 0$ or exhaustively evaluate its state space to realize it encodes a standard boolean OR gate. Pattern-matching against typical linear threshold formulations of 2-SAT will no longer work.
</RATIONALE>
<PRESERVED_ANSWER>
The polynomial identity $s_1 s_2 + q_1 q_2 = s_1 q_2 + s_2 q_1$ is algebraically equivalent to $(s_1 - q_1)(s_2 - q_2) = 0$, which exactly matches the logic of the original linear threshold, meaning a filter faults if and only if both connections are tuned to their opposite expected phases, leaving all valid tunings identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, as each filter still independently enforces a standard two-variable disjunctive clause, solvable in O(n+m) time via an implication graph.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the definition of actual phase $q = 2f - 1$ if they assume $f$ can take values other than 0 or 1, though the text explicitly restricts $f \in \{0, 1\}$.
</RISK>
