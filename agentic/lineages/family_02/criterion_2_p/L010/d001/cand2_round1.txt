<STATEMENT>
# Problem B — Configuration State Search

Time limit: 1 s   Memory limit: 256 MB

## Description

A control panel has **n** binary switches, which can each be set to 1 (ON) or 0 (OFF). Commissioning supplies **m** safety interlock rules that must not be violated.

For the purpose of these rules, a non-zero integer $x$ specifies a target state for switch $|x|$: state 1 if $x > 0$, and state 0 if $x < 0$. The *opposite* of this target state is 0 if $x > 0$, and 1 if $x < 0$.

Each interlock rule provides two non-zero integers $l_1$ and $l_2$. The rule indicates a forbidden combination: a critical system failure will occur if switch $|l_1|$ is set to the opposite of the target state for $l_1$ **and simultaneously** switch $|l_2|$ is set to the opposite of the target state for $l_2$. 

Given the vast number of possible configurations, engineers fear that finding a safe state requires an exhaustive search of the entire state space. Decide whether a single global setting of all $n$ switches exists that avoids all such forbidden combinations. If so, report one; otherwise, report that the rules inevitably lead to a failure.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two non-zero signed integers $l_1$ and $l_2$, with $|l_i| \le n$, defining an interlock rule as described above.

## Output
If no valid assignment exists that avoids all failures, print a single line NO.
Otherwise print YES on the first line. On the second line print $n$ integers $s_1 s_2 \dots s_n$ (each in {0, 1}) forming any valid assignment.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid assignments may exist; any one is accepted. The same switch may appear in multiple rules.
</STATEMENT>
<RATIONALE>
Changed the explicit 2-CNF "at least one condition is met" framing into a "forbidden combination" framing where a failure occurs if both variables take their negated states. This forces the model to recognize the logical equivalence to a disjunction and construct the implication graph from mutual exclusions, preventing an immediate pattern match to textbook 2-SAT wording.
</RATIONALE>
<PRESERVED_ANSWER>
By De Morgan's laws, avoiding the state where both condition negations are true is logically identical to satisfying at least one condition, so the exact same switch configurations are valid.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, which can be solved in $O(n+m)$ time using strongly connected components on the implication graph.
</PRESERVED_CLASS>
