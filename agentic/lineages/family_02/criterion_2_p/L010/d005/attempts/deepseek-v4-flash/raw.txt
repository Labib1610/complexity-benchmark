We can model this as a 2-SAT problem.  

Each transmitter can be 0 or 1.  
Each filter gives a constraint on the two transmitters it monitors.  

Let’s analyze the possible cases for a filter with values `a` and `b`:

- If `a > 0` and `b > 0`:  
  Target is 1 for both.  
  Stable if `(x_a + x_b) < 2` → at least one is 0.  
  So constraint: `(not a) or (not b)`.

- If `a < 0` and `b < 0`:  
  Target is 0 for both.  
  Stable if `( (1-x_a) + (1-x_b) ) < 2` → at least one is 1.  
  So constraint: `a or b`.

- If `a > 0` and `b < 0`:  
  Target is 1 for a, 0 for b.  
  Stable if `(x_a + (1-x_b)) < 2` → `x_a - x_b < 1` → `x_a <= x_b`.  
  So constraint: `(not a) or b`.

- If `a < 0` and `b > 0`:  
  Target is 0 for a, 1 for b.  
  Stable if `((1-x_a) + x_b) < 2` → `x_b - x_a < 1` → `x_b <= x_a`.  
  So constraint: `a or (not b)`.

- If `a` and `b` refer to the same transmitter:  
  We handle it as a special case:  
  - If both positive: `(not a) or (not a)` → `not a`.  
  - If both negative: `a or a` → `a`.  
  - If one positive, one negative: `(not a) or a` → always true (no constraint).

We can solve this with implication graph and SCC (Tarjan or Kosaraju).  

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(1 << 20)
input = sys.stdin.readline

n, m = map(int, input().split())
N = 2 * n  # each variable has two nodes: i*2 = false, i*2+1 = true

def node(var):
    # var is positive for true, negative for false
    if var > 0:
        return (var - 1) * 2 + 1
    else:
        return (-var - 1) * 2

def neg_node(u):
    return u ^ 1

g = [[] for _ in range(N)]
gr = [[] for _ in range(N)]

def add_imp(u, v):
    g[u].append(v)
    gr[v].append(u)

def add_clause(a, b):
    # clause: a or b
    # implication: not a -> b, not b -> a
    add_imp(neg_node(node(a)), node(b))
    add_imp(neg_node(node(b)), node(a))

for _ in range(m):
    a, b = map(int, input().split())
    if a > 0 and b > 0:
        add_clause(-a, -b)
    elif a < 0 and b < 0:
        add_clause(a, b)
    elif a > 0 and b < 0:
        add_clause(-a, b)
    else:  # a < 0 and b > 0
        add_clause(a, -b)

# Kosaraju SCC
visited = [False] * N
order = []

def dfs1(u):
    visited[u] = True
    for v in g[u]:
        if not visited[v]:
            dfs1(v)
    order.append(u)

for i in range(N):
    if not visited[i]:
        dfs1(i)

comp = [-1] * N
def dfs2(u, cid):
    comp[u] = cid
    for v in gr[u]:
        if comp[v] == -1:
            dfs2(v, cid)

cid = 0
for u in reversed(order):
    if comp[u] == -1:
        dfs2(u, cid)
        cid += 1

# Check satisfiability
for i in range(n):
    if comp[2*i] == comp[2*i+1]:
        print("NO")
        sys.exit()

print("YES")
res = []
for i in range(n):
    # if true node comes after false node in topological order, assign true
    if comp[2*i] > comp[2*i+1]:
        res.append(1)
    else:
        res.append(0)
print(' '.join(map(str, res)))
```
