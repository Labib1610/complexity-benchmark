<STATEMENT>
# Problem B — Configuration State Search

Time limit: 1 s   Memory limit: 256 MB

## Description

A control panel has **n** binary switches. Commissioning supplies **m** hardware interlocks that enforce dependency rules between switches to prevent system faults. 

Each interlock connects two switches and designates a target mode for each. The interlock acts as a failure-prevention mechanism. Specifically, each interlock dictates a strictly forbidden combination: a system fault occurs if and only if neither switch attains its specified target state. In all other scenarios, the interlock remains stable. Given the vast number of possible global states, engineers need to know if a valid state exists without an exhaustive search. 

Decide whether a single global ON/OFF setting of all **n** switches prevents all system faults at once. If such a configuration exists, report one; otherwise, report that the interlocks are mutually contradictory.

## Input
The first line contains two integers **n** and **m** (1 ≤ n ≤ 10^5, 0 ≤ m ≤ 2·10^5).
Each of the next **m** lines contains two non-zero signed integers $l_1$ and $l_2$, with $|l_i| \le n$. 

The absolute value $|l_i|$ identifies a switch. A positive value indicates a target mode of ON, while a negative value indicates a target mode of OFF. An interlock ensures that the system will fault if the switch identified by $|l_1|$ and the switch identified by $|l_2|$ both simultaneously fail to match their designated target modes. 

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise print `YES` on the first line. On the second line print **n** integers $s_1 \ s_2 \dots s_n$ (each in {0, 1}) forming any valid assignment, where 1 represents ON and 0 represents OFF.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid assignments may exist; any one is accepted. The same switch may appear in multiple interlocks.
</STATEMENT>
<RATIONALE>
Removed the explicit bidirectional conditional sentences ("if opposite then target mode"). Replaced them with a failure-prevention clause stating that a fault occurs if and only if both switches fail to attain their target states. This forces models to derive the 2-SAT implications (or clauses) from the definition of the forbidden state rather than directly transcribing provided conditional logic.
</RATIONALE>
<PRESERVED_ANSWER>
The condition "fault occurs if and only if both switches fail to match their targets" is logically identical to "if one fails to match its target, the other must match its target", meaning exactly the same switch configurations are valid.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks for a satisfying assignment to a set of 2-variable boolean constraints, making it 2-SAT (solvable in linear time).
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "neither switch attains its specified target state" as an exclusive-or or some other constraint, though the phrasing "if and only if neither ... attains" is standard and logically precise for a NAND of the negations.
</RISK>
