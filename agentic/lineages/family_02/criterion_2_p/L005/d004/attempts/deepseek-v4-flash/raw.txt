We can model each route as a forbidden pattern on the subset \( S \).  

A route with positive set \( P \) and negative set \( N \) forbids any \( S \) such that  
\[
P \subseteq S \subseteq N^c
\]  
which means:  
- All qubits in \( P \) must be in \( S \) (state 0).  
- No qubit in \( N \) can be in \( S \) (state 1).  

So each route gives constraints:  
- For each \( p \in P \), \( s_p = 0 \)  
- For each \( n \in N \), \( s_n = 1 \)  

If any qubit is forced to be both 0 and 1, it’s impossible.  

We can solve by:  
1. Initialize arrays `must0` and `must1` as False.  
2. For each route, set must0 for all in P, must1 for all in N.  
3. If any qubit has both must0 and must1 → NO.  
4. Otherwise, assign states: 0 if must0, 1 if must1, else arbitrary (say 0).  

Let’s implement.  

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    must0 = [False] * (n + 1)
    must1 = [False] * (n + 1)
    
    for _ in range(m):
        l1, l2 = map(int, input().split())
        for l in (l1, l2):
            if l > 0:
                must0[l] = True
            else:
                must1[-l] = True
    
    for i in range(1, n + 1):
        if must0[i] and must1[i]:
            print("NO")
            return
    
    res = []
    for i in range(1, n + 1):
        if must0[i]:
            res.append('0')
        elif must1[i]:
            res.append('1')
        else:
            res.append('0')
    
    print("YES")
    print(' '.join(res))

if __name__ == "__main__":
    solve()
```
