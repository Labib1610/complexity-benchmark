# Problem B — Quantum Array Calibration

Time limit: 1 s   Memory limit: 256 MB

## Description

You are tasked with finding a valid operating state for a quantum computing array consisting of $n$ qubits. Each qubit $i$ ($1 \le i \le n$) must be calibrated into a basis state, represented as $S_i \in \{0, 1\}$.

The system's error-correction protocol monitors a rigid set of $m$ entanglement routes. Each route is defined by two non-zero signed integers $l_1$ and $l_2$.

To evaluate the stability of the array, the protocol uses a phase-extraction function $V(x, S)$ for any non-zero integer $x$. Letting $k = |x|$, the extracted phase is defined as:
$$V(x, S) = S_k \oplus \frac{x + k}{2k}$$
where $\oplus$ denotes the bitwise XOR operation.

The array is considered stable if and only if, for every one of the $m$ entanglement routes, the product of the phases extracted from $l_1$ and $l_2$ is exactly zero. That is, for each route $(l_1, l_2)$, the calibration must satisfy:
$$V(l_1, S) \times V(l_2, S) = 0$$

Write a program to evaluate the configuration space to determine if a stable global calibration exists, and if so, output one.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines describes an entanglement route using two non-zero signed integers $l_1$ and $l_2$, where $|l_1|, |l_2| \le n$. 

These integers specify the parameters for the phase-extraction function for that route.

## Output
If no valid calibration exists in the state space, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $S_1, S_2, \ldots, S_n$ (each either 0 or 1) representing the state of each qubit in a valid calibration.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid calibrations may exist; any one is accepted. The same qubit may appear in multiple routes.

<RATIONALE>
Removed all directional implication phrasing and boolean logic terminology. Replaced the "target does not fire if source fires" affordance with a purely algebraic condition and an XOR-based phase extraction formula. This forces models to symbolically deduce the underlying clauses rather than relying on NLP pattern matching of logic puzzles.
</RATIONALE>
<PRESERVED_ANSWER>
The formula evaluates to 1 exactly when the original problem's trigger would fire (state 0 for positive x, state 1 for negative x), and the product equalling zero strictly prevents both from firing simultaneously, perfectly matching the original fault condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, as the algebraic constraint on boolean variables is mathematically isomorphic to a NAND clause, maintaining the required linear-time solvability.
</PRESERVED_CLASS>
<RISK>
Models might struggle to parse the fraction in the inline math or misinterpret the bitwise XOR on integers, though both are standard mathematical notations.
</RISK>
