# Problem B — Quantum Array Calibration

Time limit: 1 s   Memory limit: 256 MB

## Description

You are tasked with finding a valid operating state for a quantum computing array consisting of $n$ qubits. Each qubit must be calibrated into one of two basis states: state 1 or state 0. The configuration space contains $2^n$ possible global calibrations.

The system's error-correction protocol enforces a rigid set of $m$ joint-entanglement constraints. The array is considered stable if and only if it avoids all critical faults defined by these constraints. 

Due to the hardware's pairwise entanglement routing, each constraint identifies exactly two basis targets. A basis target is a specific state assignment for a specific qubit. The protocol dictates that a critical fault occurs if and only if a global calibration simultaneously contradicts both basis targets of a constraint. To maintain stability, your calibration must ensure no constraint experiences this simultaneous contradiction.

Write a program to evaluate the $2^n$ configuration space to determine if a stable global calibration exists, and if so, output one.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines describes a joint-entanglement constraint using two non-zero signed integers $l_1$ and $l_2$, where $|l_1|, |l_2| \le n$. A positive integer $x$ specifies a basis target where qubit $x$ is calibrated to state 1. A negative integer $-x$ specifies a basis target where qubit $x$ is calibrated to state 0. A basis target is contradicted if its specified qubit is calibrated to the opposite state.

## Output
If no valid calibration exists in the state space, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \ldots, s_n$ (each either 0 or 1) representing the state of each qubit in a valid calibration.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid calibrations may exist; any one is accepted. The same qubit may appear in multiple constraints.

<RATIONALE>
Replaced the explicit OR-clause wording ("at least one of the two conditions must be met") with a negated AND-clause framing ("simultaneously contradicts both basis targets"). This removes the direct textual mapping to standard 2-SAT templates, forcing the model to apply De Morgan's laws or derive the implication logic independently.
</RATIONALE>
<PRESERVED_ANSWER>
Avoiding the simultaneous contradiction of two states is logically equivalent to satisfying at least one of those states, so every valid calibration remains perfectly identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying boolean structure is unchanged, meaning the problem is still 2-SAT and solvable in linear time via strongly connected components on an implication graph.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "simultaneously contradicts" as needing to contradict all targets across all constraints, though "both basis targets of a constraint" makes the scope explicit.
</RISK>
