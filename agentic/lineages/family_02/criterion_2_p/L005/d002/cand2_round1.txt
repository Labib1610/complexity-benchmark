# Problem B — Quantum Array Calibration

Time limit: 1 s   Memory limit: 256 MB

## Description

You are tasked with finding a valid operating state for a quantum computing array consisting of $n$ qubits. Each qubit must be calibrated into one of two basis states: state 1 or state 0. The configuration space contains $2^n$ possible global calibrations.

The system's error-correction protocol monitors a rigid set of $m$ dependencies. The array is considered stable if and only if no dependency triggers a critical fault. Due to the hardware's pairwise entanglement routing, every dependency in this specific protocol monitors exactly two specific qubit settings that are incompatible. A fault is triggered when the global calibration simultaneously matches both of the incompatible settings monitored by that dependency. 

Write a program to evaluate the $2^n$ configuration space to determine if a stable global calibration exists, and if so, output one.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines describes a dependency using two non-zero signed integers $l_1$ and $l_2$, where $|l_1|, |l_2| \le n$. These two integers represent the pair of incompatible settings that trigger a fault if they are both present in the calibration:
- A positive integer $v$ represents the setting where qubit $v$ is in state 0.
- A negative integer $v$ represents the setting where qubit $|v|$ is in state 1.

A valid calibration must never simultaneously match both settings specified by any single dependency.

## Output
If no valid calibration exists in the state space, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \ldots, s_n$ (each either 0 or 1) representing the state of each qubit in a valid calibration.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid calibrations may exist; any one is accepted. The same qubit may appear in multiple dependencies.
</STATEMENT>
<RATIONALE>
I changed the description of the dependencies from "two conditions that must not both be violated" to "two incompatible settings that must not both be present", and inverted the mapping of positive/negative integers to the qubit states they represent. This forces the model to carefully trace the logic of the fault conditions rather than blindly applying a standard DIMACS 2-CNF parsing template where positive integers always map to a "true" literal.
</RATIONALE>

The logical conditions for a valid calibration remain mathematically identical, as the forbidden state combinations correspond exactly to violating both conditions in the original formulation.
