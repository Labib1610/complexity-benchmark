<STATEMENT>
# Problem B — Array Calibration

Time limit: 1 s   Memory limit: 256 MB

## Description

You are tasked with finding a valid operating state for an array consisting of $n$ components, numbered 1 to $n$. A global calibration of the array requires assigning a state $s_i \in \{0, 1\}$ to each component $i$.

The system's stability is governed by a set of $m$ structural invariants. Each invariant imposes a restriction on the states of two components (which may be the same component).

An invariant is defined by two non-zero integers $v_1$ and $v_2$. For any non-zero integer $v$, the stress $E(v)$ induced by parameter $v$ on component $|v|$ depends on its assigned state $s_{|v|}$, and is calculated as follows:
- If $v > 0$, $E(v) = (s_{|v|} - 1)^2$.
- If $v < 0$, $E(v) = s_{|v|}^2$.

An invariant is considered stable if the sum of the stresses from its two parameters does not exceed 1. Mathematically, an invariant defined by $v_1$ and $v_2$ requires that the calibration satisfies:
$E(v_1) + E(v_2) \le 1$

The array is fully stable if all $m$ invariants are stable. Write a program to determine if a fully stable global calibration exists, and if so, output one.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines describes an invariant using two non-zero integers $v_1$ and $v_2$, where $|v_1|, |v_2| \le n$. 

## Output
If no valid calibration exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \ldots, s_n$ (each either 0 or 1) representing the state of each component in a valid calibration.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid calibrations may exist; any one is accepted. The same component may appear in multiple invariants.

<METHOD_NAME>
Quadratic Stress Formulation
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaced the set-theoretic boolean logic conditions with a system of quadratic inequalities over binary variables. By defining a "stress" function that evaluates to 0 or 1 based on the state, the stability condition perfectly encodes a 2-SAT clause. This forces the model to algebraically evaluate the function and recognize the resulting bounded sum as a logical disjunction, defeating models that rely on keyword pattern matching for boolean satisfiability.
</METHOD_DESCRIPTION>

The previous formulation allowed models to easily map the subsets $P$ and $N$ directly to positive and negative literals in a 2-SAT implication graph. I completely removed all set-theoretic and boolean vocabulary, replacing it with a quadratic stress calculation ($E(v_1) + E(v_2) \le 1$). To succeed, a model must now reason through the algebraic properties of binary variables to deduce that the constraint prevents both terms from simultaneously equaling 1, which exactly mirrors a 2-SAT clause.
</RATIONALE>
<PRESERVED_ANSWER>
Because $s_i \in \{0, 1\}$, the stress $E(v)$ is always exactly 0 or 1; the condition $E(v_1) + E(v_2) \le 1$ precisely forbids the single assignment where both $E(v_1)=1$ and $E(v_2)=1$, which perfectly matches the fault conditions of the original logical literals.
</PRESERVED_ANSWER>
