Looking at this problem, we have n binary switches and m rules. Each rule says "at least one of two conditions must hold" where a condition is a switch with a polarity (positive means ON=1, negative means OFF=0).

This is exactly 2-SAT. Each rule `(l1, l2)` means: condition l1 OR condition l2 must hold. 

For a condition `l`:
- If `l > 0`: switch `l` must be ON (value 1)
- If `l < 0`: switch `|l|` must be OFF (value 0)

The negation of condition `l`:
- If `l > 0`: negation is `-l` (switch OFF)
- If `l < 0`: negation is `|l|` (switch ON)

So the implication graph has edges: `¬l1 → l2` and `¬l2 → l1` for each rule.

We can solve 2-SAT using SCC (Kosaraju's algorithm) and then assign values.

Let me map variables: condition `l` where `l != 0` maps to a node. Positive `l` → node `2*(l-1)`, negative `l` → node `2*(|l|-1)+1`. The negation flips the last bit.

```python
import sys
from sys import setrecursionlimit

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    # node for condition l: if l>0 -> 2*(l-1), if l<0 -> 2*((-l)-1)+1
    # negation: XOR 1
    def node(l):
        if l > 0:
            return 2*(l-1)
        else:
            return 2*((-l)-1) + 1
    
    N = 2 * n
    adj = [[] for _ in range(N)]
    radj = [[] for _ in range(N)]
    
    for _ in range(m):
        l1 = int(input_data[idx]); idx += 1
        l2 = int(input_data[idx]); idx += 1
        a = node(l1)
        b = node(l2)
        # not a -> b, not b -> a
        na = a ^ 1
        nb = b ^ 1
        adj[na].append(b)
        adj[nb].append(a)
        radj[b].append(na)
        radj[a].append(nb)
    
    # Kosaraju
    visited = [False] * N
    order = []
    
    # Use iterative DFS to avoid recursion limit
    for i in range(N):
        if not visited[i]:
            stack = [(i, 0)]
            while stack:
                v, ei = stack[-1]
                if ei == 0:
                    visited[v] = True
                if ei < len(adj[v]):
                    stack[-1] = (v, ei + 1)
                    w = adj[v][ei]
                    if not visited[w]:
                        stack.append((w, 0))
                else:
                    stack.pop()
                    order.append(v)
    
    comp = [-1] * N
    cid = 0
    for i in reversed(order):
        if comp[i] == -1:
            stack = [i]
            comp[i] = cid
            while stack:
                v = stack.pop()
                for w in radj[v]:
                    if comp[w] == -1:
                        comp[w] = cid
                        stack.append(w)
            cid += 1
    
    # Check consistency
    for i in range(n):
        if comp[2*i] == comp[2*i+1]:
            print("NO")
            return
    
    # Assign: if comp[x] > comp[not x], x is true
    assignment = [0] * n
    for i in range(n):
        if comp[2*i] > comp[2*i+1]:
            assignment[i] = 1  # switch i+1 is ON
        else:
            assignment[i] = 0  # switch i+1 is OFF
    
    print("YES")
    print(' '.join(map(str, assignment)))

solve()
```
