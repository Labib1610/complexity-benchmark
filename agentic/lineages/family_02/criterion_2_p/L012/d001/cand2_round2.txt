# Problem B — Paired Window Constraints

Time limit: 1 s   Memory limit: 256 MB

## Description
A configuration parser processes automated system requirements into a standardized intermediate format. This format governs $n$ binary switches, each of which must be set to either ON or OFF prior to the system run. The parser outputs $m$ acceptance rules. Every rule lists exactly two conditions, where each condition specifies a required state (ON or OFF) for a particular switch. A rule is satisfied if at least one of its two conditions is satisfied by the chosen global setting.

Your task is to evaluate this intermediate format. Determine whether there exists a single global setting for all $n$ switches that satisfies every rule simultaneously. If such a setting exists, you must report one; otherwise, report that the rules are mutually contradictory.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two non-zero signed integers $l_1$ and $l_2$, with $|l_i| \le n$. 
A positive integer $x$ represents the condition "switch $x$ is ON", while a negative integer $-x$ represents the condition "switch $x$ is OFF". 
At least one of the two conditions on each line must be satisfied. 
The two conditions on a line may refer to different switches, but they may also refer to the same switch, be identical, or contradict each other (for example, `1 -1`, which is always satisfied).

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES on the first line. On the second line print $n$ integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) forming any valid assignment, where $1$ means ON and $0$ means OFF.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid assignments may exist; any one is accepted. The same task index may appear in multiple requirements.
