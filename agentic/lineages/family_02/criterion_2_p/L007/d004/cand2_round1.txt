Algebraic Disguise of Logical Clauses
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the explicit pairwise negative yield condition (which strongly signals a 2-SAT OR clause) with a continuous-looking algebraic inequality I(l_1) + I(l_2) > 0. The boolean variables are mapped to ±1 coefficients. The forbidden state is the unique minimizer of the algebraic expression, making the satisfiability condition emergent and forcing algebraic deduction before the 2-SAT structure can be recognized.
</METHOD_DESCRIPTION>

yes

<STATEMENT>
# Problem B — Acoustic Levitation Patterns

Time limit: 1 s   Memory limit: 256 MB

## Description
An acoustic levitation chamber contains $n$ transducer arrays. Each array $i$ must be driven in one of two phase states, represented by $s_i \in \{0, 1\}$. 

The chamber operates under a set of $m$ harmonic interference constraints. Each constraint is specified by two non-zero integers, $l_1$ and $l_2$, which represent focal points in the chamber.

For any non-zero integer $v$, the *constructive interference* at its corresponding focal point depends on the phase state of array $|v|$. We define the interference value $I(v)$ as:
$$I(v) = v \cdot (2 s_{|v|} - 1) + |v|$$

To maintain levitation stability, every constraint $(l_1, l_2)$ must satisfy the following strict inequality:
$$I(l_1) + I(l_2) > 0$$

Determine whether there exists a global phase assignment for all $n$ arrays that satisfies all $m$ interference constraints.

## Input
The first line contains two integers $n$ and $m$ ($n \ge 1$, $m \ge 0$), representing the number of transducer arrays and harmonic constraints. The facility's hardware limit is one hundred thousand arrays, and its controller memory can store up to two hundred thousand harmonic constraints.

Each of the next $m$ lines contains two non-zero integers $l_1$ and $l_2$, representing the parameters for a single constraint. The absolute values of $l_1$ and $l_2$ will be between $1$ and $n$, inclusive.

## Output
If no valid phase assignment exists, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) forming any valid assignment.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid assignments may exist; any one is accepted. The same constraint parameters may appear in multiple constraints.
</STATEMENT>
<RATIONALE>
The previous versions failed because they still explicitly stated the "not both negative" condition, which models directly map to a 2-SAT OR clause based on DIMACS formats. By replacing this with the algebraic inequality $I(l_1) + I(l_2) > 0$, the model must algebraically deduce that $I(v)$ only takes values $0$ and $2|v|$, and therefore the inequality is equivalent to forbidding both terms from being zero simultaneously. This forces algebraic reasoning before the 2-SAT structure can be recognized. Numeric bounds were also restated as text constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic expression $I(v) = v(2s_{|v|} - 1) + |v|$ evaluates to $0$ if and only if the original problem's "yield" is strictly negative, meaning $I(l_1) + I(l_2) > 0$ is mathematically identical to the original rule that both yields cannot be strictly negative.
</PRESERVED_ANSWER>

The problem remains identically reducible to 2-SAT (which is in P) since the algebraic inequality still simply forbids exactly one out of the four possible state assignments for the two variables in each constraint.
</PRESERVED_CLASS>
