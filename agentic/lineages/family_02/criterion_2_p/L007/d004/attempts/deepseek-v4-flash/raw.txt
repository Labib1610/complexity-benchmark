We can model each constraint as a logical condition on the phase variables.  
Let’s analyze the resonance index formula:

\[
I(v) = v \cdot (2s_{|v|} - 1) + |v|
\]

If \(v > 0\):  
\(I(v) = v(2s_v - 1) + v = v \cdot 2s_v\)  
So \(I(v) > 0\) iff \(s_v = 1\).

If \(v < 0\):  
\(I(v) = v(2s_{|v|} - 1) + |v| = -|v|(2s_{|v|} - 1) + |v| = |v|(2 - 2s_{|v|}) = 2|v|(1 - s_{|v|})\)  
So \(I(v) > 0\) iff \(s_{|v|} = 0\).

Thus each constraint \((l_1, l_2)\) becomes:

- If \(l_1 > 0\): requires \(s_{l_1} = 1\)  
- If \(l_1 < 0\): requires \(s_{|l_1|} = 0\)  
Same for \(l_2\).

The sum \(I(l_1) + I(l_2) > 0\) means at least one of them is positive.  
So the constraint is:  
\[
(\text{condition on } l_1) \lor (\text{condition on } l_2)
\]

This is a 2-SAT problem.  
We can solve it with implication graph and SCC.

Let’s implement:

```python
import sys
sys.setrecursionlimit(1 << 20)
input = sys.stdin.readline

n, m = map(int, input().split())
N = 2 * n  # variables: 0..n-1 for s_i = false, n..2n-1 for s_i = true

# implication graph
g = [[] for _ in range(N)]
gr = [[] for _ in range(N)]

def add_imp(u, v):
    g[u].append(v)
    gr[v].append(u)

def add_or(a, b):
    # a or b
    # ~a -> b, ~b -> a
    add_imp(a ^ 1, b)
    add_imp(b ^ 1, a)

for _ in range(m):
    l1, l2 = map(int, input().split())
    # variable index for |v|
    def var(v):
        idx = abs(v) - 1
        if v > 0:
            return 2 * idx + 1  # true
        else:
            return 2 * idx      # false

    a = var(l1)
    b = var(l2)
    add_or(a, b)

# Kosaraju SCC
visited = [False] * N
order = []

def dfs1(u):
    visited[u] = True
    for w in g[u]:
        if not visited[w]:
            dfs1(w)
    order.append(u)

for i in range(N):
    if not visited[i]:
        dfs1(i)

comp = [-1] * N
def dfs2(u, cid):
    comp[u] = cid
    for w in gr[u]:
        if comp[w] == -1:
            dfs2(w, cid)

cid = 0
for u in reversed(order):
    if comp[u] == -1:
        dfs2(u, cid)
        cid += 1

# Check satisfiability
for i in range(n):
    if comp[2*i] == comp[2*i+1]:
        print("NO")
        sys.exit()

print("YES")
res = []
for i in range(n):
    # if true node has higher comp id, assign true
    if comp[2*i+1] > comp[2*i]:
        res.append(1)
    else:
        res.append(0)
print(' '.join(map(str, res)))
```
