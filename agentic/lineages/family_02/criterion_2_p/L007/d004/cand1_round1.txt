<METHOD_NAME>
Algebraic Clause Obfuscation
</METHOD_NAME>
<METHOD_DESCRIPTION>
Translates the DIMACS 2-SAT clause condition (not both literals false) into a single algebraic inequality: x * s_{|x|} + y * s_{|y|} > min(x, 0) + min(y, 0). This removes all textual hints of boolean logic, signs, and satisfiability, forcing the model to algebraically deduce the minimum bounds of the terms to recognize the underlying 2-SAT structure.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<STATEMENT>
# Problem B — Warehouse Zone Configurations

Time limit: 1 s   Memory limit: 256 MB

## Description
An automated warehouse manages $n$ storage zones. Each zone $i$ must be configured to a state $s_i \in \{0, 1\}$.

The facility must comply with $m$ load-balancing protocols. Each protocol is defined by a pair of non-zero integers $l_1$ and $l_2$. 

For any non-zero integer $x$, we define two values based on the configuration:
- Its *baseline requirement*, which is a constant equal to $\min(x, 0)$.
- Its *allocated capacity*, which is equal to $x \cdot s_{|x|}$, where $s_{|x|}$ is the state of zone $|x|$.

To prevent a system fault, a valid global configuration must ensure that for every protocol $(l_1, l_2)$, the sum of the allocated capacities for $l_1$ and $l_2$ is strictly greater than the sum of their baseline requirements.

Determine whether a global configuration for all $n$ zones exists that safely resolves all $m$ protocols.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of zones and load-balancing protocols.
Each of the next $m$ lines contains two non-zero integers $l_1$ and $l_2$ ($|l_i| \le n$), representing the parameters for a single protocol.

## Output
If no valid global configuration exists, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) forming any valid configuration.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any one is accepted. The same constraint parameters may appear in multiple protocols.
</STATEMENT>
<RATIONALE>
Models were previously bypassing the need to analyze the problem by recognizing the DIMACS-style 2-SAT framing ("yield of v is -v if state is 0", "not both strictly negative"). This revision encodes the exact same logical clause into a continuous-looking algebraic inequality. To solve it efficiently, models must now algebraically deduce that the term `x * s_{|x|}` achieves its minimum `min(x, 0)` exactly when the corresponding logical literal is false, thereby reconstructing the underlying 2-SAT graph.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic inequality `x*s_{|x|} + y*s_{|y|} > min(x,0) + min(y,0)` is mathematically satisfied if and only if at least one of the terms exceeds its minimum possible value, which corresponds exactly to the original condition that not both yields are strictly negative.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, solvable in O(n+m) time using Tarjan's or Kosaraju's algorithm for Strongly Connected Components on the implication graph.
</PRESERVED_CLASS>
