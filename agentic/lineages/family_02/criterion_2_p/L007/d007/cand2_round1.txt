<METHOD_NAME>Independent Set on Paired Vertices</METHOD_NAME>
<METHOD_DESCRIPTION>Transforms the 2-SAT problem into finding an independent set of size n on a graph with 2n vertices, where n edges form a perfect matching (forcing one choice per variable) and the m interlocks form additional edges between the "false" literal nodes. Models relying on surface pattern matching will see a generic independent set problem and write an exponential backtracking solver, failing the time limit. Models that genuinely reason will notice the perfect matching forces exactly one choice per pair, reducing it to 2-SAT and solving it in O(n+m) via SCC.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem B — Acoustic Levitation Arrays

Time limit: 1 s
Memory limit: 256 MB

## Description
An acoustic levitation chamber contains a network of $2n$ resonance nodes. These nodes are identified by non-zero integers from $-n$ to $n$ (i.e., $\{-n, \dots, -1, 1, \dots, n\}$).

To stabilize the acoustic field, you must select exactly $n$ of these nodes to be activated. However, the system is constrained by a set of interference links. If an interference link exists between node $u$ and node $v$, you cannot activate both $u$ and $v$ simultaneously. (If a link connects a node to itself, that node cannot be activated at all).

The interference links are formed by two mechanisms:
1. **Fundamental Physics:** For every integer $i$ from $1$ to $n$, there is a fundamental interference link between node $i$ and node $-i$.
2. **Safety Interlocks:** The chamber is equipped with $m$ safety interlocks. Each interlock is specified by two non-zero integers $l_1$ and $l_2$, which creates an additional interference link between node $l_1$ and node $l_2$. 

Determine whether there exists a valid set of exactly $n$ activated nodes that violates no interference links.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of positive node indices and the number of safety interlocks.
Each of the next $m$ lines contains two non-zero integers $l_1$ and $l_2$ ($1 \le |l_1|, |l_2| \le n$), representing the two nodes connected by a single safety interlock.

## Output
If no valid activation exists, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) representing your chosen activation. For each $i$ from $1$ to $n$:
- Print $s_i = 1$ if node $-i$ is activated.
- Print $s_i = 0$ if node $i$ is activated.

*(Note: Since you must activate exactly $n$ nodes and no two activated nodes can share a fundamental link, exactly one of $i$ or $-i$ will be activated for each $i$.)*

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid assignments may exist; any one is accepted. The same node index may appear in multiple interlocks, and it is possible that $l_1 = l_2$ or $|l_1| = |l_2|$ within a single interlock. Duplicate links between the same pair of nodes have the same effect as a single link.
</STATEMENT>
<RATIONALE>
I reframed the problem as finding an independent set of size $n$ on a graph with $2n$ vertices. The base edges form a perfect matching $(i, -i)$, forcing exactly one choice per pair, which maps to the boolean variable assignment. The interlock edges form NAND constraints between specific nodes. I inverted the mapping ($s_i = 1$ means $-i$ is chosen) so that the NAND constraint on the nodes algebraically simplifies back to the original OR constraint $(l_1 \lor l_2)$ on the variables. Models using surface pattern matching will either write an exponential independent set solver and TLE, or blindly map the NAND constraint to $(\neg l_1 \lor \neg l_2)$ and fail. Models must genuinely derive the algebraic mapping to discover the standard 2-SAT structure.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to choose exactly one of $i$ or $-i$ defines the boolean state, and avoiding the interlock link between $l_1$ and $l_2$ is mathematically identical to avoiding the assignment where literal $l_1$ is false and literal $l_2$ is false, which perfectly preserves the $(l_1 \lor l_2)$ constraint and its satisfying assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem requires finding an independent set of size $n$ on a graph composed of $n$ disjoint edges plus additional arbitrary edges, which is a known P-time exact reduction to 2-SAT.
</PRESERVED_CLASS>
<RISK>
Models might be slightly confused by the inverted mapping ($s_i = 1$ means $-i$ is activated), but this is explicitly defined in the Output section and mathematically unambiguous.
</RISK>
