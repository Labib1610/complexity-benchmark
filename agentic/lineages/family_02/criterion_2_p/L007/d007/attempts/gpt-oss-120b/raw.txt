**Solution Explanation**

For every array `i` we have to choose a phase `s_i ∈ {0,1}`.
Define  

```
x_i = 2·s_i – 1          (x_i ∈ {‑1 , +1})
```

For an interlock we are given two non‑zero integers `l1 , l2`.
Let  

```
a = |l1| ,  b = |l2|
sgn1 = sign(l1)   ( = +1 if l1>0 else –1 )
sgn2 = sign(l2)
```

The interference condition is  

```
l1·x_a + l2·x_b  >  –(a+b)
```

Insert `l1 = sgn1·a , l2 = sgn2·b`

```
sgn1·a·x_a + sgn2·b·x_b + a + b > 0
a·(sgn1·x_a + 1) + b·(sgn2·x_b + 1) > 0                (1)
```

Because `a , b > 0`, the left side is `0` **iff**

```
sgn1·x_a = –1   and   sgn2·x_b = –1
```

Therefore the inequality is violated **only** when both equal `–1`.
Consequently each interlock requires

```
(sgn1·x_a = +1)  OR  (sgn2·x_b = +1)                (2)
```

--------------------------------------------------------------------

#### 1.   From (2) to a 2‑SAT clause  

Introduce a Boolean variable  

```
z_i  =  (x_i = +1)          (true  ⇔  s_i = 1)
```

`sgn·x = +1` is equivalent to

```
sgn = +1  →  x = +1  →  z_i is true
sgn = –1  →  x = –1  →  z_i is false   (i.e. ¬z_i is true)
```

Thus each literal in (2) is either `z_i` (if the sign is `+`) or `¬z_i`
(if the sign is `–`).  
The whole condition becomes a **2‑SAT clause**

```
(L1  ∨  L2)          where Lk is  z_i  or  ¬z_i
```

All interlocks give a set of clauses of this form.

--------------------------------------------------------------------

#### 2.   Solving the 2‑SAT instance  

Standard 2‑SAT algorithm:

* for each variable `i` we have two nodes  
  `i·2`   –  “z_i is false” (`¬z_i`)  
  `i·2+1` –  “z_i is true”   (`z_i`)
* a clause `(A ∨ B)` adds two implications  

```
¬A → B
¬B → A
```

All implications are stored in a directed graph ( ≤ 2·m edges ).
The graph is processed with Kosaraju’s algorithm (or Tarjan) to obtain
strongly connected components (SCCs).

If a variable and its negation belong to the same SCC the instance is
unsatisfiable → answer `NO`.

Otherwise the assignment is obtained by the topological order of SCCs:
a variable is true iff its SCC comes **after** the SCC of its negation.

The algorithm works in `O(n + m)` time and memory.

--------------------------------------------------------------------

#### 3.   Constructing the required output  

If satisfiable we have the Boolean values `z_i`.
Recall `z_i = (x_i = +1) = (s_i = 1)`.  
So we output `s_i = 1` for true, `0` for false.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct assignment
iff such an assignment exists.

---

##### Lemma 1  
For a single interlock the condition `E > C` is equivalent to the
clause `(L1 ∨ L2)` constructed in the algorithm.

**Proof.**  
From the derivation above, `E > C` fails exactly when
`sgn1·x_a = –1` **and** `sgn2·x_b = –1`.  
Rewriting `sgn·x = +1` as a literal (`z` if `sgn=+1`, `¬z` if `sgn=-1`)
gives the logical condition “at least one of the two literals is true”,
i.e. `(L1 ∨ L2)`. ∎



##### Lemma 2  
An assignment of the Boolean variables `z_i` satisfies all clauses
iff the corresponding phases `s_i` satisfy all interlock inequalities.

**Proof.**  
By Lemma&nbsp;1 each clause is exactly the logical form of the inequality
for its interlock.  Therefore a set of `z_i` makes every clause true
iff it makes every inequality true.  The mapping `s_i = z_i` is bijective,
so the statement follows. ∎



##### Lemma 3  
If the SCC test declares the 2‑SAT instance unsatisfiable,
no assignment of phases can satisfy all interlocks.

**Proof.**  
Unsatisfiability of the 2‑SAT instance means that for some variable `i`
the nodes representing `z_i` and `¬z_i` lie in the same SCC, i.e.
`z_i ⇒ ¬z_i` and `¬z_i ⇒ z_i` are both reachable.
Hence any truth assignment would force `z_i` to be both true and false,
which is impossible.  By Lemma&nbsp;2 this implies no phase assignment
can satisfy all interlocks. ∎



##### Lemma 4  
If the SCC test declares the instance satisfiable, the assignment
produced by the SCC topological order satisfies all clauses.

**Proof.**  
Standard property of the 2‑SAT SCC algorithm:
when no variable collides with its negation, setting a variable true
exactly when its SCC has a larger post‑order number than that of its
negation yields a model of all implications, hence of all clauses.
∎



##### Lemma 5  
The phase vector printed by the algorithm satisfies every interlock.

**Proof.**  
The printed phases are `s_i = z_i` from Lemma&nbsp;4, which satisfy all
clauses.  By Lemma&nbsp;2 this is equivalent to satisfying all
interlock inequalities. ∎



##### Theorem  
The program outputs  

* `NO` iff no global phase assignment avoids all halts,  
* otherwise `YES` and a concrete assignment that avoids all halts.

**Proof.**  

*If the program prints `NO`.*  
That happens only when the SCC test finds a variable together with its
negation in the same SCC.  By Lemma&nbsp;3 the 2‑SAT instance is
unsatisfiable, therefore by Lemma&nbsp;2 no phase assignment exists.

*If the program prints `YES`.*  
Then the SCC test found the instance satisfiable.
By Lemma&nbsp;4 the derived Boolean values satisfy all clauses,
and by Lemma&nbsp;5 the printed phases satisfy all interlocks.
Thus a valid assignment exists and is output.

Both directions hold, completing the proof. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Building the graph* – `2` edges per interlock → `O(m)` time, `O(n+m)` memory.  
*Kosaraju (or Tarjan) SCC* – linear in vertices + edges → `O(n+m)` time,
`O(n+m)` memory.  
*Assignment construction* – linear → `O(n)`.

Overall  

```
Time   :  O(n + m)   ≤ 3·10⁵
Memory :  O(n + m)   ≤ 3·10⁵  (fits easily into 256 MB)
```

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    N = n * 2                     # each variable: false node = 2*i, true node = 2*i+1
    g = [[] for _ in range(N)]
    rg = [[] for _ in range(N)]

    def add_imp(u, v):
        g[u].append(v)
        rg[v].append(u)

    for _ in range(m):
        l1 = int(next(it))
        l2 = int(next(it))
        # literal for l1
        idx1 = abs(l1) - 1
        if l1 > 0:
            lit1 = idx1 * 2 + 1          # z_i (true)
        else:
            lit1 = idx1 * 2              # ¬z_i (false)
        # literal for l2
        idx2 = abs(l2) - 1
        if l2 > 0:
            lit2 = idx2 * 2 + 1
        else:
            lit2 = idx2 * 2

        # clause (lit1 ∨ lit2)  =>  (¬lit1 → lit2) , (¬lit2 → lit1)
        not_lit1 = lit1 ^ 1
        not_lit2 = lit2 ^ 1
        add_imp(not_lit1, lit2)
        add_imp(not_lit2, lit1)

    # Kosaraju
    visited = [False] * N
    order = []

    def dfs(v):
        visited[v] = True
        for to in g[v]:
            if not visited[to]:
                dfs(to)
        order.append(v)

    for v in range(N):
        if not visited[v]:
            dfs(v)

    comp = [-1] * N
    cur = 0

    def rdfs(v, k):
        comp[v] = k
        for to in rg[v]:
            if comp[to] == -1:
                rdfs(to, k)

    for v in reversed(order):
        if comp[v] == -1:
            rdfs(v, cur)
            cur += 1

    assignment = [0] * n
    for i in range(n):
        if comp[2*i] == comp[2*i+1]:
            print("NO")
            return
        # true component has larger number (comes earlier in topological order)
        assignment[i] = 1 if comp[2*i] < comp[2*i+1] else 0

    print("YES")
    print(' '.join(map(str, assignment)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
