<STATEMENT>
# Problem B — Warehouse Zone Configurations

Time limit: 1 s   Memory limit: 256 MB

## Description
An automated warehouse manages $n$ storage zones. Each zone must be configured for either high-density storage (represented as 1) or rapid-retrieval storage (represented as 0).

The facility must comply with $m$ contingency plans. Each plan consists of two directives, where a directive specifies a zone and its baseline storage type. A plan triggers a critical instability (and thus fails) if and only if the zone from the first directive deviates from its specified baseline AND the zone from the second directive also deviates from its specified baseline. If at least one directive's zone matches its baseline, the plan avoids instability and is satisfied. 

Directives are provided as non-zero integers. A positive integer $x$ indicates that zone $x$ has a baseline of high-density (1). A negative integer $-x$ indicates that zone $x$ has a baseline of rapid-retrieval (0). For example, if a plan's directives are $a$ and $b$, the plan fails only when zone $|a|$ is not set to the baseline of $a$, and zone $|b|$ is not set to the baseline of $b$. 

Determine whether a global configuration for all $n$ zones exists that satisfies every contingency plan simultaneously (i.e., no plan triggers a critical instability).

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of zones and contingency plans.
Each of the next $m$ lines contains two non-zero integers $l_1$ and $l_2$ ($1 \le |l_i| \le n$), representing the two directives for a single contingency plan.

## Output
If no valid global configuration exists, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) forming any valid configuration.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any one is accepted. The same zone may appear in multiple contingency plans, and a plan's two directives may name the same zone.
