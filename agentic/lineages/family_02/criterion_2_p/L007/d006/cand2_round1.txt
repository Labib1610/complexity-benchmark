<STATEMENT>
# Problem B — Vector Resonance Control

Time limit: 1 s   Memory limit: 256 MB

## Description
A vector resonance chamber contains $n$ field generators. Each generator $i$ ($1 \le i \le n$) must be assigned a polarity state $s_i \in \{0, 1\}$.
The polarity state determines the generator's phase coefficient $c_i$:
- If $s_i = 0$, then $c_i = 1$.
- If $s_i = 1$, then $c_i = -1$.

The chamber is equipped with $m$ resonance monitors to prevent destructive feedback. Each monitor observes a specific interference channel defined by two non-zero integers $l_1$ and $l_2$. A monitor trips if the sum of the projected resonances from its two parameters reaches its theoretical maximum. Specifically, a monitor defined by $(l_1, l_2)$ will trip if and only if the following equation holds:
$$c_{|l_1|} \cdot l_1 + c_{|l_2|} \cdot l_2 = |l_1| + |l_2|$$

A valid global configuration must ensure that no monitor trips.

Determine whether there exists a global assignment of polarity states for all $n$ generators that prevents any of the $m$ monitors from tripping.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of field generators and the number of resonance monitors.
Each of the next $m$ lines contains two non-zero integers $l_1$ and $l_2$ ($1 \le |l_1|, |l_2| \le n$), representing the parameters for a single monitor.

## Output
If no valid global assignment exists, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) forming any valid assignment.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid assignments may exist; any one is accepted. The same generator index may appear in multiple monitors, and it is possible that $l_1 = l_2$ or $|l_1| = |l_2|$ within a single monitor.
</STATEMENT>

Previous versions failed because they either preserved the boolean nature (e.g., "evaluates to 1") or didn't fully mask the independent evaluation of the two literals, allowing models to immediately map the input to 2-SAT clauses. By combining the two conditions into a single scalar sum equation ($c_{|l_1|} l_1 + c_{|l_2|} l_2 = |l_1| + |l_2|$), the problem no longer presents as a logical conjunction of two independent boolean states. The model must algebraically deduce that the sum is maximized if and only if both terms are independently maximized, thereby reconstructing the boolean conjunction from first principles before applying standard graph algorithms.
</RATIONALE>
<PRESERVED_ANSWER>
Because $c_k \in \{1, -1\}$, the term $c_{|l|} \cdot l$ can only equal $|l|$ or $-|l|$; thus the sum equals $|l_1| + |l_2|$ if and only if both $c_{|l_1|} = \text{sgn}(l_1)$ and $c_{|l_2|} = \text{sgn}(l_2)$, which maps exactly to the seed's condition of both boolean states being simultaneously present.
</PRESERVED_ANSWER>

The condition mathematically simplifies to a forbidden pair of states for two boolean variables, meaning the problem is exactly 2-SAT and remains solvable in $O(n+m)$ via an implication graph and SCCs.
</PRESERVED_CLASS>
