<STATEMENT>
# Problem B — Warehouse Zone Configurations

Time limit: 1 s   Memory limit: 256 MB

## Description
An automated warehouse manages $n$ storage zones. Each zone must be configured to operate in either state 1 (active) or state 0 (standby).

Each zone $i$ ($1 \le i \le n$) contains two environmental control devices:
- A cooling unit, designated by the positive integer $i$, which draws auxiliary power whenever zone $i$ is configured to state 0.
- A heating unit, designated by the negative integer $-i$, which draws auxiliary power whenever zone $i$ is configured to state 1.

The facility's power grid has $m$ limited supply lines. Each supply line connects exactly two devices, represented by non-zero integers $l_1$ and $l_2$. To prevent a grid failure, a valid global configuration must ensure that for every supply line, its two connected devices do not simultaneously draw auxiliary power. (It is perfectly safe if only one device draws power, or if neither device draws power).

Determine whether a global configuration for all $n$ zones exists that safely resolves all $m$ supply line limits.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of zones and the number of supply lines.
Each of the next $m$ lines contains two non-zero integers $l_1$ and $l_2$ ($1 \le |l_i| \le n$), representing the two devices connected to a single supply line.

## Output
If no valid global configuration exists, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) forming any valid configuration.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any one is accepted. The same device may appear in multiple supply lines. A single supply line might connect a device to itself ($l_1 = l_2$), or connect the cooling and heating units of the same zone ($l_1 = -l_2$).
</STATEMENT>
