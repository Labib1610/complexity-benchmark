**Solution Explanation**

For every zone `i` we have a binary variable  

```
x_i = 1   – zone i works in state 1
x_i = 0   – zone i works in state 0
```

For a *parameter* `v` (non‑zero integer, `|v| ≤ n`) the *yield* is

```
yield(v) =  v   if x_|v| = 1
yield(v) = -v   if x_|v| = 0
```

A protocol `(l1 , l2)` is **bad** only when *both* yields are negative.
We have to choose the `x_i` so that no protocol is bad.



--------------------------------------------------------------------

#### 1.   From yields to a Boolean condition  

Consider a single parameter `v`.

* `v > 0`  
  `yield(v) < 0`  ⇔  `x_|v| = 0`
* `v < 0`  
  `yield(v) < 0`  ⇔  `x_|v| = 1`

Define  

```
neg(v) = 0   if v > 0
neg(v) = 1   if v < 0
```

Then  

```
yield(v) is negative   ⇔   x_|v| = neg(v)
```

For a protocol `(l1 , l2)` the forbidden situation is  

```
x_|l1| = neg(l1)   AND   x_|l2| = neg(l2)
```

Negating it we obtain the required condition

```
(x_|l1| ≠ neg(l1))  OR  (x_|l2| ≠ neg(l2))                (1)
```

--------------------------------------------------------------------

#### 2.   Turning (1) into a 2‑SAT clause  

Introduce a Boolean variable `y_i` that is **true** exactly when `x_i = 1`
(the same variable, just a different name).

* `x_i = 1`  ⇔  literal `y_i`
* `x_i = 0`  ⇔  literal `¬y_i`

In (1) the expression `x_i ≠ neg` is a literal:

```
if neg = 0   (i.e. v > 0)   →   x_i ≠ 0   →   x_i = 1   →   y_i
if neg = 1   (i.e. v < 0)   →   x_i ≠ 1   →   x_i = 0   →   ¬y_i
```

Therefore each protocol gives a clause  

```
A  OR  B
```

where `A` and `B` are ordinary Boolean literals (`y_i` or `¬y_i`).
That is exactly a **2‑SAT** instance.

--------------------------------------------------------------------

#### 3.   2‑SAT solving (implication graph)  

For a clause `(A ∨ B)` we add the two implications  

```
¬A → B
¬B → A
```

The implication graph has `2·n` vertices (literal and its negation).
A classic linear‑time algorithm (Kosaraju / Tarjan) finds its strongly
connected components (SCC).

*If a variable and its negation belong to the same SCC the instance is
unsatisfiable.*

Otherwise the SCCs form a DAG.  
Processing the components in reverse topological order gives a satisfying
assignment:

```
variable i is true  ⇔  component( y_i )  comes before component( ¬y_i )
```

(When using Kosaraju, the component numbers obtained in the second DFS are
already in topological order, so we can simply compare them.)

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct configuration
iff such a configuration exists.

---

##### Lemma 1  
For any parameter `v` the statement “yield(v) is negative” is equivalent to
`x_|v| = neg(v)`.

*Proof.* Directly from the definition of the yield (see section&nbsp;1). ∎



##### Lemma 2  
For a protocol `(l1 , l2)` the condition “the protocol is **not** bad”
is equivalent to the Boolean clause  

```
(x_|l1| ≠ neg(l1))  OR  (x_|l2| ≠ neg(l2))
```

*Proof.* The protocol is bad exactly when both yields are negative.
By Lemma&nbsp;1 this is `x_|l1| = neg(l1) ∧ x_|l2| = neg(l2)`. Negating gives the
clause. ∎



##### Lemma 3  
The clause of Lemma&nbsp;2 is a standard 2‑SAT clause over the Boolean
variables `y_i` (`y_i` true ⇔ `x_i = 1`).

*Proof.*  
`x_i ≠ 0` is the literal `y_i`; `x_i ≠ 1` is the literal `¬y_i`.  
Thus each side of the clause is either `y_i` or `¬y_i`. ∎



##### Lemma 4  
The implication graph built by the algorithm is exactly the implication
graph of the 2‑SAT instance consisting of all clauses from Lemma&nbsp;3.

*Proof.* For each clause `(A ∨ B)` the algorithm adds the two edges
`¬A → B` and `¬B → A`, which is the definition of the 2‑SAT implication
graph. ∎



##### Lemma 5  
If the algorithm reports “NO”, the original problem has no feasible
configuration.

*Proof.* “NO” is printed only when some variable and its negation lie in the
same SCC of the implication graph. By Lemma&nbsp;4 this means the 2‑SAT
instance is unsatisfiable, i.e. there is no assignment of the `y_i` that
satisfies all clauses. By Lemma&nbsp;3 each clause corresponds to a protocol,
so no assignment of the zones avoids a bad protocol. ∎



##### Lemma 6  
If the algorithm reports “YES” and outputs the assignment `x_i`,
then every protocol satisfies the required condition.

*Proof.* When “YES” is printed, the SCC test succeeded, therefore the
2‑SAT instance is satisfiable. The algorithm extracts a satisfying assignment
for the `y_i` (standard SCC‑ordering rule). Because the assignment satisfies
all clauses, by Lemma&nbsp;3 it satisfies all clauses of Lemma&nbsp;2,
hence by Lemma&nbsp;2 no protocol is bad. The printed `x_i` are exactly the
values of `y_i` (0/1), so the configuration is valid. ∎



##### Lemma 7  
If a feasible configuration exists, the algorithm never prints “NO”.

*Proof.* Any feasible configuration gives values for the `x_i`, thus for the
`y_i`. By Lemma&nbsp;2 each protocol’s clause is satisfied, therefore all
2‑SAT clauses are satisfied. Hence the 2‑SAT instance is satisfiable, which
implies no variable and its negation share an SCC (standard 2‑SAT theory).
Consequently the algorithm will not output “NO”. ∎



##### Theorem  
The algorithm outputs “YES” and a correct configuration exactly when such a
configuration exists; otherwise it outputs “NO”.

*Proof.*  
- If the algorithm outputs “YES”, Lemma&nbsp;6 guarantees the configuration
  is correct.  
- If it outputs “NO”, Lemma&nbsp;5 shows no configuration can exist.  
- Conversely, if a configuration exists, Lemma&nbsp;7 ensures the algorithm
  cannot output “NO”, therefore it outputs “YES”. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

* `n ≤ 10^5`, `m ≤ 2·10^5`
* Vertices: `2·n`
* Edges: `2·m` (two per clause)

Kosaraju (or Tarjan) runs in `O(V + E)` time and memory.

```
Time   :  O(n + m)   ≤ 3·10^5
Memory :  O(n + m)   ≤ a few MB
```

Both are well inside the limits.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    N = 2 * n                     # literal count
    g = [[] for _ in range(N)]
    rg = [[] for _ in range(N)]

    def lit(var: int, val: bool) -> int:
        """return literal id for (x_var == val) where val is True/False"""
        return 2 * var + (0 if val else 1)

    for _ in range(m):
        l1 = int(next(it))
        l2 = int(next(it))
        a = abs(l1) - 1
        b = abs(l2) - 1
        neg1 = l1 < 0          # neg(v) as defined
        neg2 = l2 < 0

        # clause: (x_a != neg1) OR (x_b != neg2)
        # which is (x_a == not neg1) OR (x_b == not neg2)
        valA = not neg1
        valB = not neg2
        A = lit(a, valA)
        B = lit(b, valB)

        # add implications ¬A → B , ¬B → A
        NA = A ^ 1
        NB = B ^ 1
        g[NA].append(B)
        g[NB].append(A)
        rg[B].append(NA)
        rg[A].append(NB)

    # Kosaraju
    visited = [False] * N
    order = []

    def dfs(v: int):
        stack = [v]
        while stack:
            node = stack[-1]
            if visited[node]:
                stack.pop()
                continue
            visited[node] = True
            for to in g[node]:
                if not visited[to]:
                    stack.append(to)
            # after exploring children, will be added to order later
            # we simulate recursion by second pass
            # use separate marker
            if stack and stack[-1] == node:
                stack.pop()
                order.append(node)

    for v in range(N):
        if not visited[v]:
            dfs(v)

    comp = [-1] * N
    cur = 0
    for v in reversed(order):
        if comp[v] != -1:
            continue
        stack = [v]
        while stack:
            node = stack.pop()
            if comp[node] != -1:
                continue
            comp[node] = cur
            for to in rg[node]:
                if comp[to] == -1:
                    stack.append(to)
        cur += 1

    assignment = [0] * n
    for i in range(n):
        if comp[2 * i] == comp[2 * i + 1]:
            print("NO")
            return
        # component number larger => earlier in topological order
        assignment[i] = 1 if comp[2 * i] > comp[2 * i + 1] else 0

    print("YES")
    print(' '.join(map(str, assignment)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
