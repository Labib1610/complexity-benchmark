<STATEMENT>
# Problem B — Warehouse Climate Configurations

Time limit: 1 s   Memory limit: 256 MB

## Description
An automated warehouse oversees $n$ storage zones. The facility's architectural limit guarantees there is always at least one zone, but never more than one hundred thousand. Each zone must be permanently set to either an active state (1) or a passive state (0).

Each zone has two climate devices: a cooling unit and a heating unit. These devices draw power based on the zone's state:
- The cooling unit of zone $z$ draws power if zone $z$ is in the passive state (0).
- The heating unit of zone $z$ draws power if zone $z$ is in the active state (1).

The warehouse electrical grid contains $m$ shared power supplies. Depending on the configuration, the number of power supplies can be zero, up to a maximum grid capacity of two hundred thousand. Each supply is wired to exactly two climate devices. These devices are identified by a non-zero integer $v$:
- A positive integer $v > 0$ refers to the cooling unit of zone $v$.
- A negative integer $v < 0$ refers to the heating unit of zone $-v$.

A shared power supply $(l_1, l_2)$ has a strict limitation: it cannot provide power to both of its connected devices simultaneously. If both devices draw power at the same time, the supply will overload. (It is perfectly fine if only one device, or neither device, draws power).

Determine whether there is a global state assignment for all $n$ zones that prevents any of the $m$ shared power supplies from overloading.

## Input
The first line contains two integers $n$ and $m$, representing the number of active zones and the number of power supplies.
Each of the next $m$ lines contains two non-zero integers $l_1$ and $l_2$, representing the two devices connected to a single power supply. The magnitude of any device identifier will never exceed the number of zones $n$.

## Output
If no safe global state assignment exists, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each being 0 or 1) representing any valid state assignment for the zones.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid assignments may exist; any one is accepted. The same device identifier may appear in multiple power supplies, and a single power supply might connect a device to itself.
</STATEMENT>
<RATIONALE>
The DIMACS-like formulation of variable strains was removed and replaced with a physical scenario involving heating and cooling units drawing power. Bare numeric inequalities were replaced with textual descriptions of architectural and grid capacities, forcing the model to read the scenario text to determine the constraints and structure.
</RATIONALE>
<PRESERVED_ANSWER>
The conditions for a unit drawing power perfectly mirror the original strain conditions (cooling/positive draws on state 0; heating/negative draws on state 1), and preventing simultaneous power draw exactly matches preventing simultaneous strain, preserving all valid assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains an instance of 2-SAT where each power supply acts as a disjunctive clause between two boolean literals, which can still be solved in O(n+m) time using strongly connected components on an implication graph.
</PRESERVED_CLASS>
