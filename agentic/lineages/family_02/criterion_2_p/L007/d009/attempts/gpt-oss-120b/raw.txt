**Solution Explanation**

For every node `i` we have a binary variable  

```
xi = 0   or   xi = 1
```

A constraint is given by two non‑zero integers `l1 , l2`.

```
i = |l1| ,   j = |l2|
t1 = 1  if l1 > 0 else 0          (the required value of xi)
t2 = 1  if l2 > 0 else 0          (the required value of xj)
```

The constraint is satisfied iff the squared Euclidean distance between the
projection `(xi , xj)` and the target point `(t1 , t2)` is **strictly smaller**
than `2`.

Because `xi , xj , t1 , t2` are all `0` or `1`

```
dist² = (xi‑t1)² + (xj‑t2)²   ∈ {0,1,2}
```

`dist² < 2`  ⇔  `dist²` is `0` or `1` ⇔ **it is forbidden that both coordinates differ**
from the target simultaneously.

```
¬(xi ≠ t1  AND  xj ≠ t2)   ⇔   (xi = t1)  OR  (xj = t2)
```

So each constraint is exactly a **2‑SAT clause**

```
( xi == t1 )  ∨  ( xj == t2 )
```

* if `t = 1` the literal is the variable itself (`xi`);
* if `t = 0` the literal is the negation (`¬xi`).

The whole problem is therefore a 2‑SAT instance with `n` variables and `m`
clauses.



--------------------------------------------------------------------

#### 2‑SAT background  

For a variable `i`

```
node 2*i     :  xi = 0   (¬xi)
node 2*i + 1 :  xi = 1   ( xi )
```

The negation of a node is `node ^ 1`.

A clause `(a ∨ b)` is transformed into two implications

```
¬a → b
¬b → a
```

All implications are stored in a directed graph (the *implication graph*).
The instance is satisfiable **iff** for every variable `i` the two nodes
`2*i` and `2*i+1` belong to different strongly connected components (SCCs).

If it is satisfiable, the SCCs give a topological order.
Assign the variable the value whose node belongs to the *later* SCC
(i.e. larger component number in the order produced by Kosaraju).

The algorithm runs in `O(n + m)` time and memory.



--------------------------------------------------------------------

#### Algorithm
```
read n , m
create adjacency lists G (2*n vertices) and GR (reversed graph)

for each constraint (l1 , l2):
        i = abs(l1) - 1          # 0‑based index
        j = abs(l2) - 1
        t1 = 1 if l1 > 0 else 0
        t2 = 1 if l2 > 0 else 0

        a = node(i , t1)        # literal (xi == t1)
        b = node(j , t2)        # literal (xj == t2)

        add edge (a^1) → b   to G and b → (a^1) to GR
        add edge (b^1) → a   to G and a → (b^1) to GR

run Kosaraju:
        1st pass – DFS on G, store vertices by finishing time
        2nd pass – DFS on GR in reverse finishing order, assign component id

if for some i   comp[2*i] == comp[2*i+1]:
        print "NO"
else:
        for each i:
                xi = 1  if comp[2*i+1] > comp[2*i] else 0
        print "YES" and the list xi
```

`node(i , val)` returns `2*i + val` (`val` is `0` or `1`).

The algorithm also works when `i == j` (same variable appears twice):
* if `t1 == t2` the clause forces that variable,
* if `t1 != t2` the clause becomes `(xi==0) ∨ (xi==1)` – always true,
  which is correctly represented by the two implications that are both
  self‑loops and do not affect satisfiability.



--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints **YES** and a correct assignment
iff such an assignment exists.

---

##### Lemma 1  
For any constraint `(l1 , l2)` the clause  
`( xi == t1 ) ∨ ( xj == t2 )` is satisfied exactly when the original
distance condition ` (xi‑t1)² + (xj‑t2)² < 2 ` holds.

**Proof.**  
Both sides are Boolean statements.

*If the distance condition holds.*  
The sum of the two squared differences is `0` or `1`.  
Therefore at least one of the two differences is `0`, i.e. at least one
coordinate equals its target: `xi = t1` or `xj = t2`. The clause is true.

*If the distance condition does not hold.*  
Then the sum equals `2`, meaning both differences are `1`:
`xi ≠ t1` **and** `xj ≠ t2`. Both literals of the clause are false,
so the clause is false.

∎



##### Lemma 2  
The implication graph built by the algorithm is exactly the standard
implication graph of the 2‑SAT instance consisting of all clauses from
Lemma&nbsp;1.

**Proof.**  
For a clause `(a ∨ b)` the standard transformation adds edges
`¬a → b` and `¬b → a`.  
The algorithm computes the two literals `a = (xi == t1)` and `b = (xj == t2)`,
maps them to nodes `aNode` and `bNode`, and inserts precisely the two
edges `(aNode^1) → bNode` and `(bNode^1) → aNode`.  
Thus the graph coincides with the standard construction. ∎



##### Lemma 3  
If the algorithm outputs **NO**, the original system of constraints is
unsatisfiable.

**Proof.**  
The algorithm outputs **NO** only when for some variable `i`
`comp[2*i] == comp[2*i+1]`.  
In the implication graph this means there is a directed cycle containing
both a literal and its negation, i.e. `xi` implies `¬xi` and vice‑versa.
Hence any assignment would have to satisfy `xi = 0` and `xi = 1`
simultaneously – impossible.  
Because the graph is exactly the implication graph of the 2‑SAT instance
(Lemma&nbsp;2), the 2‑SAT instance is unsatisfiable, and by Lemma&nbsp;1
the original constraints are unsatisfiable. ∎



##### Lemma 4  
If the algorithm outputs **YES** and the assignment `xi` constructed
from the SCC order, then every clause (hence every original constraint)
is satisfied.

**Proof.**  
Standard property of Kosaraju‑based 2‑SAT solving:
for each variable `i` the algorithm sets `xi = 1` iff the SCC of node
`2*i+1` appears **after** the SCC of node `2*i` in the topological order.
Because SCCs are contracted, there is **no** edge from a later SCC to an
earlier one.

Consider a clause `(a ∨ b)`. Its two implication edges are
`¬a → b` and `¬b → a`.  
If `a` is false in the assignment, then node `a` belongs to an earlier SCC
than its negation `¬a`. The edge `¬a → b` goes from a later SCC (¬a) to the
SCC of `b`. Since edges never go from later to earlier SCCs, `b` cannot be
in an earlier SCC; therefore `b` is true. Thus at least one literal is true.
The same reasoning holds symmetrically. Consequently every clause is true,
and by Lemma&nbsp;1 every original distance constraint holds. ∎



##### Lemma 5  
If the original system of constraints is satisfiable, the algorithm never
outputs **NO**.

**Proof.**  
Assume a satisfying assignment `X` exists. By Lemma&nbsp;1 it satisfies all
clauses, i.e. it is a satisfying assignment of the 2‑SAT instance.
A 2‑SAT instance has a satisfying assignment **iff** no variable and its
negation belong to the same SCC of its implication graph (standard
2‑SAT theory). Since the instance is satisfiable, for every `i`
`2*i` and `2*i+1` lie in different SCCs, therefore the algorithm will not
detect a conflict and will not output **NO**. ∎



##### Theorem  
The algorithm prints

* `NO` **iff** the given constraints are unsatisfiable;
* otherwise prints `YES` and a binary vector that satisfies all constraints.

**Proof.**  

*If the algorithm prints `NO`* – by Lemma&nbsp;3 the constraints are
unsatisfiable.

*If the algorithm prints `YES`* – it produced an assignment.
By Lemma&nbsp;4 this assignment satisfies every clause, hence every original
constraint (Lemma&nbsp;1). So a solution exists.

*Conversely*, if a solution exists, Lemma&nbsp;5 guarantees the algorithm
does not output `NO`; therefore it outputs `YES` and, by Lemma&nbsp;4,
a correct solution.

Thus the theorem holds. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Vertices*: `2 n`  
*Edges*: `2 m` (two per clause)

Both adjacency lists store `O(n + m)` integers.

Kosaraju runs two depth‑first searches, each `O(V + E) = O(n + m)`.

Memory: `O(n + m)`.

Both limits satisfy the problem constraints (`n ≤ 10⁵`, `m ≤ 2·10⁵`).

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    N = 2 * n                     # number of nodes in implication graph
    G = [[] for _ in range(N)]
    GR = [[] for _ in range(N)]

    def node(idx: int, val: int) -> int:
        """return node number for literal (x_idx == val)"""
        return 2 * idx + val      # val = 0 -> false node, 1 -> true node

    for _ in range(m):
        l1 = int(next(it))
        l2 = int(next(it))
        i = abs(l1) - 1
        j = abs(l2) - 1
        t1 = 1 if l1 > 0 else 0
        t2 = 1 if l2 > 0 else 0

        a = node(i, t1)
        b = node(j, t2)

        na = a ^ 1          # negation of a
        nb = b ^ 1          # negation of b

        # ¬a → b
        G[na].append(b)
        GR[b].append(na)
        # ¬b → a
        G[nb].append(a)
        GR[a].append(nb)

    # ---------- Kosaraju ----------
    visited = [False] * N
    order = []

    sys.setrecursionlimit(1 << 25)

    def dfs(v: int):
        visited[v] = True
        for to in G[v]:
            if not visited[to]:
                dfs(to)
        order.append(v)

    for v in range(N):
        if not visited[v]:
            dfs(v)

    comp = [-1] * N
    cur = 0

    def rdfs(v: int, label: int):
        comp[v] = label
        for to in GR[v]:
            if comp[to] == -1:
                rdfs(to, label)

    for v in reversed(order):
        if comp[v] == -1:
            rdfs(v, cur)
            cur += 1

    # ---------- check satisfiability ----------
    assignment = [0] * n
    for i in range(n):
        if comp[2 * i] == comp[2 * i + 1]:
            print("NO")
            return
        # later component (larger number) means true
        assignment[i] = 1 if comp[2 * i + 1] > comp[2 * i] else 0

    print("YES")
    print(' '.join(map(str, assignment)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input / output format.
