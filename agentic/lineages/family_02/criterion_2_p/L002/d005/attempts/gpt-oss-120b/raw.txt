**Solution Explanation**

For a machine `i`

```
mode s_i ∈ {0,1}
polarity p_i = 2·s_i – 1   ∈ { -1 , +1 }
```

For a safety interlock we are given two non‑zero integers `c1 , c2`.
Let  

```
a = |c1| ,   sign1 = sign(c1)   ( +1 or –1 )
b = |c2| ,   sign2 = sign(c2)
```

The stability condition is  

```
c1·p_a + c2·p_b  >  – ( a + b )
```

--------------------------------------------------------------------
### 1.   From the inequality to a logical clause
```
c1·p_a + a   = a·( sign1·p_a + 1 )
c2·p_b + b   = b·( sign2·p_b + 1 )
```

`p_a` is `±1`, therefore `sign1·p_a` is also `±1` and

```
sign1·p_a + 1   = 0   or   2
```

The same for the second feed.  
The whole left side becomes

```
a·(0 or 2) + b·(0 or 2)
```

It is **strictly positive** iff at least one of the two brackets equals `2`,
i.e. iff at least one of the following holds

```
sign1·p_a = 1          (1)
sign2·p_b = 1          (2)
```

Now replace `p_a = 2·s_a – 1` :

```
sign·(2·s – 1) = 1   →   2·sign·s = 1 + sign
```

* if `sign = +1` (the feed integer is positive) → `s = 1`
* if `sign = –1` (the feed integer is negative) → `s = 0`

Thus each feed corresponds to a **literal**

```
c > 0   →   variable i must be true   (s_i = 1)
c < 0   →   variable i must be false  (s_i = 0)
```

The whole interlock requires **at least one** of its two literals to be
true, i.e. a clause  

```
(literal1)  OR  (literal2)
```

All interlocks together form a 2‑SAT instance.



--------------------------------------------------------------------
### 2.   2‑SAT solving (implication graph)

For every variable `i` we create two vertices

```
i_false  = 2*i          (represents s_i = 0)
i_true   = 2*i + 1      (represents s_i = 1)
```

A clause `(A ∨ B)` is equivalent to the two implications

```
¬A → B
¬B → A
```

We add directed edges for all clauses, obtaining a graph with `2·n`
vertices and `2·m` edges ( ≤ 4·10⁵ ).

A 2‑SAT formula is satisfiable **iff** no variable and its negation belong to
the same strongly connected component (SCC).  
We compute SCCs with Kosaraju’s algorithm (linear time).

If satisfiable, the usual assignment rule is:

```
process SCCs in reverse topological order
variable i is true  iff  component(i_true) comes before component(i_false)
```

--------------------------------------------------------------------
### 3.   Correctness Proof  

We prove that the algorithm outputs “YES” and a correct assignment
iff such an assignment exists.

---

#### Lemma 1  
For a feed integer `c` with machine index `i` the statement  
`sign(c)·p_i = 1` is equivalent to the literal  

```
c > 0   →   s_i = 1
c < 0   →   s_i = 0
```

*Proof.*  
`p_i = 2·s_i – 1`.  
If `c>0` (`sign=+1`): `+1·(2·s_i-1)=1 ⇔ 2·s_i = 2 ⇔ s_i = 1`.  
If `c<0` (`sign=-1`): `-1·(2·s_i-1)=1 ⇔ -2·s_i+1 = 1 ⇔ s_i = 0`. ∎



#### Lemma 2  
An interlock with feeds `c1 , c2` is stable **iff** the clause  
`L1 ∨ L2` (where `Lk` is the literal from Lemma&nbsp;1) is satisfied.

*Proof.*  
From the derivation in Section&nbsp;1 the inequality holds exactly when
`sign1·p_a = 1` or `sign2·p_b = 1`. By Lemma&nbsp;1 each equality is
identical to the corresponding literal being true. ∎



#### Lemma 3  
The implication graph built by the algorithm is exactly the standard
implication graph of the 2‑SAT formula consisting of all clauses from
Lemma&nbsp;2.

*Proof.*  
For each clause `(L1 ∨ L2)` the algorithm adds edges `¬L1 → L2` and
`¬L2 → L1`, which are precisely the definition of the implication graph. ∎



#### Lemma 4  
If the algorithm reports “NO”, the original problem has no feasible
configuration.

*Proof.*  
“NO” is reported when some variable `i` and its negation belong to the same
SCC. By properties of implication graphs this implies that both
`i_true → i_false` and `i_false → i_true` are reachable, i.e. the formula
forces `s_i = 1` and `s_i = 0` simultaneously, which is impossible.
By Lemma&nbsp;2 any feasible configuration would satisfy all clauses,
contradiction. ∎



#### Lemma 5  
If the algorithm reports “YES” and outputs assignment `s`,
then every clause (hence every interlock) is satisfied.

*Proof.*  
The assignment follows the standard SCC‑ordering rule:
if component(`i_true`) precedes component(`i_false`) we set `s_i = 1`,
otherwise `0`. For any edge `u → v` in the implication graph,
the component of `u` cannot be after the component of `v`
(otherwise there would be a path back, merging the SCCs).
Consequently, if `¬L` is true then `L` must also be true.
Thus no implication is violated, which means the whole 2‑SAT formula is
satisfied. By Lemma&nbsp;2 each satisfied clause makes the corresponding
interlock stable. ∎



#### Lemma 6  
If a feasible configuration exists, the algorithm never reports “NO”.

*Proof.*  
A feasible configuration satisfies all clauses, therefore the 2‑SAT
formula is satisfiable. A satisfiable 2‑SAT instance never has a variable
and its negation in the same SCC (otherwise the formula would be
unsatisfiable). Hence the algorithm will not encounter that situation
and will output “YES”. ∎



#### Theorem  
The algorithm outputs “YES” and a correct list of modes `s_1…s_n`
iff such a list exists; otherwise it outputs “NO”.

*Proof.*  
- If the algorithm outputs “YES”, by Lemma&nbsp;5 the produced assignment
  satisfies every clause, therefore by Lemma&nbsp;2 all interlocks are
  stable – a valid configuration.
- If the algorithm outputs “NO”, by Lemma&nbsp;4 no configuration can
  satisfy all interlocks.
- By Lemma&nbsp;6 the algorithm cannot output “NO” when a configuration
  exists.

Thus the output is correct in all cases. ∎



--------------------------------------------------------------------
### 4.   Complexity Analysis  

```
Vertices : 2·n          ≤ 2·10⁵
Edges    : 2·m          ≤ 4·10⁵
Kosaraju (two DFS passes) : O(V + E)
Memory   : O(V + E)
```

Both time (≈ 5·10⁵ operations) and memory fit easily into the limits.



--------------------------------------------------------------------
### 5.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    N = 2 * n                     # total vertices
    g = [[] for _ in range(N)]
    rg = [[] for _ in range(N)]

    def var_true(i):   # i is 0‑based
        return 2 * i + 1
    def var_false(i):
        return 2 * i

    def add_imp(u, v):
        g[u].append(v)
        rg[v].append(u)

    for _ in range(m):
        c1 = int(next(it))
        c2 = int(next(it))

        # literal for c: (var, is_true)
        def lit(c):
            idx = abs(c) - 1
            if c > 0:
                return var_true(idx)   # need true
            else:
                return var_false(idx)  # need false

        a = lit(c1)
        b = lit(c2)

        # clause (a OR b)  ->  (¬a → b) , (¬b → a)
        na = a ^ 1   # toggle last bit: true<->false
        nb = b ^ 1
        add_imp(na, b)
        add_imp(nb, a)

    # Kosaraju
    visited = [False] * N
    order = []

    def dfs(v):
        visited[v] = True
        for to in g[v]:
            if not visited[to]:
                dfs(to)
        order.append(v)

    for v in range(N):
        if not visited[v]:
            dfs(v)

    comp = [-1] * N
    cur = 0

    def rdfs(v, k):
        comp[v] = k
        for to in rg[v]:
            if comp[to] == -1:
                rdfs(to, k)

    for v in reversed(order):
        if comp[v] == -1:
            rdfs(v, cur)
            cur += 1

    assignment = [0] * n
    for i in range(n):
        if comp[var_true(i)] == comp[var_false(i)]:
            print("NO")
            return
        # component with larger number is earlier in topological order
        assignment[i] = 1 if comp[var_true(i)] > comp[var_false(i)] else 0

    print("YES")
    print(' '.join(map(str, assignment)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
