<METHOD_DESCRIPTION>Replaced the logical NAND description of the 2-SAT clauses with an equivalent algebraic inequality over variables in {-1, 1} derived from the {0, 1} states. Models must algebraically evaluate the four discrete state combinations to recover the boolean clause structure, defeating direct pattern matching on "two feeds... shutdown if both active".</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Production Line Configuration

Time limit: 1 s   Memory limit: 256 MB

## Description

A manufacturing facility runs $n$ distinct machines, indexed from 1 to $n$. You must assign each machine a state $s_i$, which is exactly 0 or 1.

The facility's power grid is safeguarded by $m$ safety interlocks. Each interlock is defined by two non-zero integers $c_1$ and $c_2$. These values act as signed machine indices; the stability criterion below uses them exactly as written. (It is possible for both values in a pair to refer to the same machine index, with the same or opposite signs).

To evaluate the stability of the grid, we first define a polarity factor for each machine $i$ based on its assigned state:
$f_i = 1 - 2s_i$

An interlock operates safely if and only if its two parameters $c_1$ and $c_2$ satisfy the following algebraic condition:
$f_{|c_1|} \cdot c_1 \cdot |c_2| + f_{|c_2|} \cdot c_2 \cdot |c_1| \le 0$

A catastrophic shutdown is triggered if the sum evaluates to a value strictly greater than zero for any interlock. To keep the facility running, you must determine a facility-wide configuration such that all $m$ interlocks are safe simultaneously. 

Determine if such a configuration exists, and if so, output the required state for each machine.

## Input
The first line of the input provides two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of machines and the number of safety interlocks, respectively.

The next $m$ lines each contain two non-zero integers $c_1$ and $c_2$ ($|c_i| \le n$), detailing the two parameters for that interlock. 

## Output
If it is impossible to configure all $n$ machines without causing a shutdown, output a single line with the word `NO`.

If a safe configuration is possible, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ to specify the chosen state for each machine from 1 to $n$. Each value must be in {0, 1}.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
There might be several safe configurations; outputting any valid one is correct. A single machine can provide parameters to multiple interlocks.
</STATEMENT>
<RATIONALE>
Replaced the boolean logic formulation with an algebraic inequality. The inequality mathematically evaluates to >0 if and only if both underlying boolean conditions are met, mirroring the seed's NAND condition exactly. Models must manually derive the four cases to recognize this as a 2-SAT clause, defeating direct translation heuristics. The explicit set notation {0, 1} was restored as plain text outside of math delimiters to satisfy automated bounds checking.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic condition $f_{|c_1|} c_1 |c_2| + f_{|c_2|} c_2 |c_1| \le 0$ is exactly equivalent to the seed's condition that both feeds cannot be high voltage simultaneously, meaning any configuration valid in the seed is valid here.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT because the algebraic inequality over two discrete variables with two states each perfectly encodes a negative binary clause (NAND).
</PRESERVED_CLASS>
<RISK>
Models might struggle with the absolute values in the subscripts ($|c_1|$) if they don't read carefully, but this is standard mathematical notation and perfectly well-defined.
</RISK>
