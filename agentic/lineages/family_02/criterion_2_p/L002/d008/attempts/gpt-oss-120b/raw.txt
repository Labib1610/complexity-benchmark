**Solution Explanation**

For every machine `i` we have a Boolean variable  

```
xi = 0   – machine i works in mode 0
xi = 1   – machine i works in mode 1
```

For a linkage described by a non‑zero integer `c`

* `c > 0` : the linkage becomes **rigid** iff `xi = 0`
* `c < 0` : the linkage becomes **rigid** iff `xi = 1`

An interlock connects two linkages `c1 , c2`.  
It breaks **only** when *both* linkages are rigid, i.e.

```
 (xi = v1)  AND  (xj = v2)      must NOT happen
```

where  

```
v = 0  if c > 0          (rigid when mode 0)
v = 1  if c < 0          (rigid when mode 1)
```

The condition “must NOT happen” is equivalent to the Boolean clause

```
 (xi ≠ v1)  OR  (xj ≠ v2)
```

which is a **2‑SAT** clause.  
Thus the whole problem is a 2‑SAT instance with `n` variables and `m`
clauses.

--------------------------------------------------------------------

#### 1.   2‑SAT encoding

For each variable `xi` we create two nodes

```
node(i,0)  – literal  (xi = 0)
node(i,1)  – literal  (xi = 1)
```

`node(i,0)` and `node(i,1)` are opposite literals.

For a clause `(a OR b)` we add the two implications

```
 (¬a) → b
 (¬b) → a
```

In our case  

```
a = (xi = 1‑v1)          (the “not rigid” literal of the first linkage)
b = (xj = 1‑v2)
¬a = (xi = v1) ,  ¬b = (xj = v2)
```

Therefore for every interlock we add the two directed edges

```
 (xi = v1) → (xj = 1‑v2)
 (xj = v2) → (xi = 1‑v1)
```

--------------------------------------------------------------------

#### 2.   Solving 2‑SAT

A 2‑SAT formula is satisfiable **iff** for every variable `i`
`node(i,0)` and `node(i,1)` belong to different strongly connected
components (SCC) of the implication graph.

We compute SCCs with Kosaraju’s algorithm (two DFS passes, iterative
to avoid recursion limits).  
Let `comp[u]` be the component number, numbered in the order of the
second pass (topological order of the condensation DAG, larger number
means “earlier”).

The assignment is obtained by the standard rule

```
xi = 1   if comp[node(i,1)] > comp[node(i,0)]
xi = 0   otherwise
```

Because in the condensation DAG all edges go from a higher component
number to a lower one, this respects all implications.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs “YES” and a correct assignment
iff such an assignment exists.

---

##### Lemma 1  
For each interlock the two added edges are exactly the implications of
the clause “(xi ≠ v1) OR (xj ≠ v2)”.

**Proof.**  
The clause is `(a OR b)` with `a = (xi = 1‑v1)`, `b = (xj = 1‑v2)`.  
Its implications are `(¬a) → b` and `(¬b) → a`.  
`¬a` is `(xi = v1)`, `¬b` is `(xj = v2)`.  
Thus the edges are precisely the two described in the algorithm. ∎



##### Lemma 2  
If the algorithm declares the instance unsatisfiable (some variable
has both literals in the same SCC) then no assignment can avoid a
broken interlock.

**Proof.**  
If `node(i,0)` and `node(i,1)` are in the same SCC, there is a directed
path from each to the other, i.e. each implies the other.
Consequently any satisfying assignment would have to set `xi` both to
`0` and to `1`, impossible. Hence the formula (and the original
problem) is unsatisfiable. ∎



##### Lemma 3  
If the algorithm produces an assignment `x` (using the component order
rule) then every implication edge of the graph is satisfied.

**Proof.**  
Consider an edge `p → q`. By construction of SCC numbers,
`comp[p] > comp[q]` (edges go from higher to lower component numbers).
The rule sets a literal to `true` exactly when its component number is
higher than that of its opposite literal.  
If `p` is true, then `comp[p] > comp[¬p]`. Because `comp[p] > comp[q]`,
we also have `comp[q] > comp[¬q]`, therefore `q` is true.  
If `p` is false, the implication is vacuously satisfied. ∎



##### Lemma 4  
The assignment `x` satisfies every clause, i.e. no interlock breaks.

**Proof.**  
Take any clause `(a OR b)`. By Lemma&nbsp;1 the graph contains the two
implications `(¬a) → b` and `(¬b) → a`. By Lemma&nbsp;3 both are
satisfied by `x`. If `a` were false, then `¬a` is true, and the first
implication forces `b` to be true. Hence at least one of `a, b` is true,
so the clause holds. ∎



##### Lemma 5  
If the instance is satisfiable, the algorithm never puts a variable’s
two literals into the same SCC.

**Proof.**  
Assume a satisfying assignment exists. For any edge `p → q`,
the assignment makes `p` true ⇒ `q` true (otherwise the edge would be
violated). Therefore in the directed graph there is no cycle that
contains both a literal and its negation, because that would force the
literal to imply its negation and vice‑versa, contradicting the
assignment. Hence no SCC can contain both literals of the same
variable. ∎



##### Theorem  
The algorithm outputs  

* “NO” iff no safe configuration exists,  
* otherwise “YES” and a configuration that keeps all interlocks intact.

**Proof.**  

*If the algorithm outputs “NO”.*  
That happens only when some variable has both literals in one SCC.
By Lemma&nbsp;2 the formula is unsatisfiable, therefore no safe
configuration exists.

*If a safe configuration exists.*  
Then the corresponding 2‑SAT formula is satisfiable.
By Lemma&nbsp;5 the algorithm will not find a variable with both
literals in the same SCC, thus it proceeds to construct an assignment.
By Lemma&nbsp;4 this assignment satisfies every clause, i.e. no
interlock breaks. Hence the algorithm outputs “YES” and a correct
configuration.

Both directions hold, completing the proof. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Vertices*: `2 n`  
*Edges*: `2 m` (two per interlock)

Kosaraju:

* first DFS pass – `O(2n + 2m)`
* second DFS pass – `O(2n + 2m)`

Overall time `O(n + m)` ≤ `3·10⁵`, well inside the limit.  
Memory: adjacency lists store `2m` integers, plus a few arrays of size
`2n`. Total `O(n + m)` ≤ about 3 · 10⁵ integers → < 10 MB.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    N = 2 * n                     # node id: i*2 + value (0 or 1)
    g = [[] for _ in range(N)]
    rg = [[] for _ in range(N)]

    def add_imp(u, v):
        g[u].append(v)
        rg[v].append(u)

    for _ in range(m):
        c1 = int(next(it))
        c2 = int(next(it))
        i1 = abs(c1) - 1
        i2 = abs(c2) - 1
        v1 = 0 if c1 > 0 else 1   # rigid when xi == v1
        v2 = 0 if c2 > 0 else 1

        # clause: (xi != v1) OR (xj != v2)
        # literals a = (xi = 1-v1), b = (xj = 1-v2)
        a = i1 * 2 + (1 - v1)
        nota = i1 * 2 + v1
        b = i2 * 2 + (1 - v2)
        notb = i2 * 2 + v2

        add_imp(nota, b)   # (xi = v1) -> (xj = 1-v2)
        add_imp(notb, a)   # (xj = v2) -> (xi = 1-v1)

    sys.setrecursionlimit(1 << 25)

    # Kosaraju first pass: order
    visited = [False] * N
    order = []

    for v in range(N):
        if not visited[v]:
            stack = [(v, 0)]
            while stack:
                node, state = stack.pop()
                if state == 0:
                    if visited[node]:
                        continue
                    visited[node] = True
                    stack.append((node, 1))
                    for to in g[node]:
                        if not visited[to]:
                            stack.append((to, 0))
                else:
                    order.append(node)

    # second pass: assign components
    comp = [-1] * N
    cur = 0
    for v in reversed(order):
        if comp[v] == -1:
            stack = [v]
            comp[v] = cur
            while stack:
                node = stack.pop()
                for to in rg[node]:
                    if comp[to] == -1:
                        comp[to] = cur
                        stack.append(to)
            cur += 1

    # check satisfiability
    assignment = [0] * n
    for i in range(n):
        if comp[i*2] == comp[i*2+1]:
            print("NO")
            return
        # higher component number means earlier in topological order
        assignment[i] = 1 if comp[i*2+1] > comp[i*2] else 0

    print("YES")
    print(' '.join(map(str, assignment)))

if __name__ == "__main__":
    solve()
```

and conforms to the required input‑output format.
