<METHOD_NAME>Algebraic Threshold Formulation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces standard boolean satisfiability clauses (l1 OR l2) with an algebraic constraint where the sum of two 0/1 relay signals must be strictly greater than 0. This forces models to algebraically deduce the equivalence to a disjunction rather than pattern-matching logical keywords.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Production Line Configuration

Time limit: 1 s   Memory limit: 256 MB

## Description

A manufacturing facility runs $n$ distinct machines, indexed from $1$ to $n$. Each machine must be tuned to exactly one of two operational phases: phase 1 or phase 0.

The facility's power grid is safeguarded by $m$ safety interlocks. Each interlock is wired to exactly two relays, which monitor the phases of specific machines. 
When a relay monitors machine $k$ ($1 \le k \le n$), its signal value is determined by the machine's phase and the relay's polarity:
- A positive-polarity relay on machine $k$ emits a signal of 1 if machine $k$ is in phase 1, and 0 if it is in phase 0.
- A negative-polarity relay on machine $k$ emits a signal of 1 if machine $k$ is in phase 0, and 0 if it is in phase 1.

An interlock remains stable if and only if the arithmetic sum of the signals from its two relays is strictly greater than 0 (meaning at least one of its relays emits a signal of 1). If the sum of the two signals evaluates to 0, the interlock trips and halts the facility.

Determine if there exists a facility-wide phase assignment for all $n$ machines such that every interlock remains stable.

## Input
The first line of the input provides two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of machines and the number of safety interlocks, respectively.

Each of the next $m$ lines contains two non-zero integers $c_1$ and $c_2$ ($|c_i| \le n$), identifying the two relays for that interlock. 
- If $c_i > 0$, it represents a positive-polarity relay monitoring machine $c_i$.
- If $c_i < 0$, it represents a negative-polarity relay monitoring machine $|c_i|$.

Note that an interlock's two relays may monitor the same machine (either with the same or opposite polarities). The stability rule applies exactly as stated regardless of the relay targets.

## Output
If it is impossible to assign a phase to all $n$ machines such that all $m$ interlocks remain stable, output a single line with the word `NO`.

If a stable assignment is possible, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{0, 1\}$) specifying the assigned phase for each machine from 1 to $n$. If there are multiple valid assignments, outputting any of them is accepted.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
A single machine can be monitored by relays from multiple different interlocks.
</STATEMENT>
<RATIONALE>
The explicit boolean logic ("fails to match c1 while simultaneously failing to match c2") has been removed. Instead, the condition is framed algebraically: each literal evaluates to a 0/1 signal, and the sum of the two signals for an interlock must be strictly greater than 0. Models must recognize that this arithmetic threshold sum exactly corresponds to a logical OR in a 2-SAT formulation. The exact bounds have been restored to the input section to satisfy constraint checks.
</RATIONALE>
<PRESERVED_ANSWER>
The threshold sum of two 0/1 variables being strictly greater than 0 is mathematically identical to a boolean OR, meaning the exact same variable assignments are valid for the given inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains 2-SAT, which is solvable in O(n+m) time by constructing an implication graph and finding strongly connected components, keeping it safely in P.
</PRESERVED_CLASS>
