<METHOD_NAME>Inverse State Mapping via Double Negation</METHOD_NAME>
<METHOD_DESCRIPTION>Defines the input integers as triggers for a failure state using the opposite of standard DIMACS semantics (positive triggers on 0, negative triggers on 1). Because the goal is to avoid simultaneous triggers, the logic double-negates back to standard DIMACS. Models that pattern-match will map positive to 0 without resolving the double negation, causing them to solve the inverse 2-SAT problem and fail.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Production Line Configuration

Time limit: 1 s   Memory limit: 256 MB

## Description

A manufacturing facility runs $n$ distinct machines. Each machine must be securely locked into one of two states: mode 0 or mode 1. The facility's power grid is safeguarded by $m$ safety interlocks. Each interlock receives two signal feeds from the machines. 

A signal feed is defined by a non-zero integer $c$. The feed carries a high voltage depending on the mode of machine $|c|$:
- If $c > 0$, the feed carries a high voltage when machine $c$ is set to mode 0.
- If $c < 0$, the feed carries a high voltage when machine $|c|$ is set to mode 1.

A catastrophic shutdown is triggered by an interlock if and only if both of its signal feeds carry a high voltage at the exact same time. To keep the facility running, you must determine a facility-wide configuration (assigning mode 0 or mode 1 to each machine) such that no interlock receives two high voltage feeds simultaneously. 

Determine if a safe configuration exists, and if so, output the required mode for each machine.

## Input
The first line of the input provides two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of machines and the number of safety interlocks, respectively.

The next $m$ lines each contain two non-zero integers $c_1$ and $c_2$ ($|c_i| \le n$), detailing the two signal feeds for that interlock. 

## Output
If it is impossible to configure all $n$ machines without causing a shutdown, output a single line with the word `NO`.

If a safe configuration is possible, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{0, 1\}$) to specify the chosen mode for each machine from 1 to $n$.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
There might be several safe configurations; outputting any valid one is correct. A single machine can provide signal feeds to multiple interlocks.
</STATEMENT>
<RATIONALE>
Removed the explicit clarification that mapped positive/negative values directly to their required safe modes. Instead, the integers are defined as signal feeds that carry high voltage on the *opposite* mode (positive -> high on 0, negative -> high on 1). Since the shutdown occurs when *both* feeds are high, avoiding shutdown requires at least one feed to be low, which naturally double-negates back to standard DIMACS 2-SAT logic (positive -> want 1, negative -> want 0). Models that lazily pattern-match will map positive to 0 and negative to 1 without resolving the double-negation, resulting in them solving the inverse 2-SAT problem and failing.
</RATIONALE>
<PRESERVED_ANSWER>
Avoiding simultaneous high voltages on the feeds exactly reproduces the original logical clauses (e.g., avoiding mode 0 means requiring mode 1), so exactly the same assignments remain valid for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains a 2-SAT instance mathematically identical to the seed, solvable in O(n+m) time via strongly connected components on an implication graph.
</PRESERVED_CLASS>
<RISK>
Models might output a valid but different satisfying assignment for Example 1 (like `0 1`) and fail a strict string-matching test, but the problem explicitly notes "outputting any valid one is correct", so a proper checker will accept it.
</RISK>
