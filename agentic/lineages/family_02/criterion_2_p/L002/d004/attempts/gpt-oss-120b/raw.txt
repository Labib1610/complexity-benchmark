**Solution Explanation**

For every machine `i` we have a Boolean variable  

```
xi = True   ⇔   machine i is set to mode 1
xi = False  ⇔   machine i is set to mode 0
```

For a signal feed `c`

* `c > 0` – the feed is *high* exactly when `xi = False`  (literal `¬xi`)
* `c < 0` – the feed is *high* exactly when `xi = True`   (literal ` xi`)

An interlock receives two feeds `c1 , c2`.  
It causes a shutdown **iff** both feeds are high, i.e.

```
high(c1)  ∧  high(c2)
```

We have to avoid this, therefore for every interlock we need

```
¬high(c1)  ∨  ¬high(c2)                (1)
```

Formula (1) is a 2‑CNF clause, thus the whole problem is a **2‑SAT** instance.



--------------------------------------------------------------------

#### 1.   From clauses to implications

For a literal `L` let `¬L` be its opposite literal.
Clause `(¬high1 ∨ ¬high2)` is equivalent to the two implications

```
high1  →  ¬high2
high2  →  ¬high1
```

So for each interlock we add two directed edges to the implication graph.



--------------------------------------------------------------------

#### 2.   Graph representation

For each variable `i` we create two vertices

```
2*(i-1)     :  xi = False   (mode 0)
2*(i-1)+1   :  xi = True    (mode 1)
```

The opposite literal of vertex `v` is `v ^ 1` (flip the last bit).

For a feed `c`

```
if c > 0 :   high literal vertex = 2*(c-1)          # xi = False
else      :   high literal vertex = 2*(|c|-1)+1    # xi = True
```

For each interlock we add the two edges described above.



--------------------------------------------------------------------

#### 3.   Solving 2‑SAT

We run Kosaraju’s algorithm (two DFS passes) to obtain the
strongly connected components (SCC) of the implication graph.

*If a variable and its negation belong to the same SCC the instance is unsatisfiable.*

Otherwise the SCCs form a DAG.  
Processing SCCs in reverse topological order gives a satisfying assignment:

```
value[xi] = True   if   comp[vertex_true] > comp[vertex_false]
                else False
```

(`comp` is the order number of the SCC, larger means earlier in the reverse topological order.)

Finally we output `1` for `True` (mode 1) and `0` for `False` (mode 0).

The algorithm works in `O(n + m)` time and memory.



--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm outputs “YES” and a correct configuration
iff such a configuration exists.

---

##### Lemma 1  
For every interlock the two edges added to the implication graph are
logically equivalent to the clause `¬high(c1) ∨ ¬high(c2)`.

**Proof.**  
Let `A = high(c1)`, `B = high(c2)`.  
The clause is `¬A ∨ ¬B`.  
`¬A ∨ ¬B` is equivalent to the pair of implications `A → ¬B` and `B → ¬A`.  
The algorithm adds exactly these two directed edges, each representing one
implication. ∎



##### Lemma 2  
Any assignment that satisfies all clauses of the 2‑SAT instance also
satisfies the original problem (no interlock receives two high feeds).

**Proof.**  
By Lemma&nbsp;1 each clause corresponds exactly to the condition that an
interlock does **not** have both feeds high.  
If all clauses are true, for every interlock at least one of the two
feeds is not high, i.e. the interlock never triggers. ∎



##### Lemma 3  
If the algorithm declares the instance unsatisfiable (some variable and
its negation lie in the same SCC) then no safe configuration exists.

**Proof.**  
In any implication graph, if a variable `v` and its negation `¬v` are in
the same SCC, there is a directed path `v →* ¬v` and also `¬v →* v`.
Thus any truth assignment would force `v` to be both true and false,
which is impossible. Hence the original 2‑SAT formula is unsatisfiable,
and by Lemma&nbsp;2 no safe configuration exists. ∎



##### Lemma 4  
If the algorithm produces an assignment, it satisfies all clauses.

**Proof.**  
Kosaraju’s algorithm gives a topological order of SCCs.
For each variable we set it to `True` iff its `True` vertex belongs to a
SCC that appears earlier (has larger order number) than the SCC of its
`False` vertex.
Standard 2‑SAT theory shows that this rule never violates an implication:
if there were an edge `u → v` with `comp[u] > comp[v]` (i.e. `u` assigned
True, `v` False) the edge would go from a later SCC to an earlier one,
contradicting the topological order. Therefore all implications hold,
hence all clauses hold. ∎



##### Lemma 5  
The assignment output by the algorithm is a safe configuration for the
original problem.

**Proof.**  
By Lemma&nbsp;4 the assignment satisfies all 2‑SAT clauses.
By Lemma&nbsp;2 this implies that no interlock receives two high feeds.
Thus the configuration is safe. ∎



##### Theorem  
The algorithm outputs  

* “NO” iff no safe configuration exists,  
* otherwise “YES” and a configuration that is safe.

**Proof.**  

*If the algorithm outputs “NO”* – this happens only when a variable and
its negation share an SCC. By Lemma&nbsp;3 no safe configuration exists.

*If a safe configuration exists* – the corresponding assignment satisfies
all clauses, therefore the 2‑SAT instance is satisfiable.
Consequently no variable collides with its negation in an SCC, the
algorithm proceeds to the second phase and produces an assignment.
By Lemma&nbsp;5 this assignment is safe, and the algorithm outputs “YES”.
∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis

*Vertices*: `2·n`  
*Edges*: `2·m` (two per interlock)

Kosaraju runs in `O(V + E) = O(n + m)` time and uses the same amount of
memory for adjacency lists and auxiliary arrays.

Both limits satisfy the problem constraints (`n ≤ 10⁵`, `m ≤ 2·10⁵`).

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    N = 2 * n
    g = [[] for _ in range(N)]
    rg = [[] for _ in range(N)]

    def lit(c: int) -> int:
        """return vertex index of the literal that is high for feed c"""
        if c > 0:
            return 2 * (c - 1)          # xi = False
        else:
            return 2 * (-c - 1) + 1    # xi = True

    for _ in range(m):
        c1 = int(next(it)); c2 = int(next(it))
        a = lit(c1)
        b = lit(c2)
        na = a ^ 1
        nb = b ^ 1
        # a -> not b
        g[a].append(nb)
        rg[nb].append(a)
        # b -> not a
        g[b].append(na)
        rg[na].append(b)

    visited = [False] * N
    order = []

    def dfs(v: int):
        stack = [(v, 0)]
        while stack:
            v, state = stack.pop()
            if state == 0:
                if visited[v]:
                    continue
                visited[v] = True
                stack.append((v, 1))
                for to in g[v]:
                    if not visited[to]:
                        stack.append((to, 0))
            else:
                order.append(v)

    for v in range(N):
        if not visited[v]:
            dfs(v)

    comp = [-1] * N
    label = 0
    for v in reversed(order):
        if comp[v] == -1:
            stack = [v]
            comp[v] = label
            while stack:
                cur = stack.pop()
                for to in rg[cur]:
                    if comp[to] == -1:
                        comp[to] = label
                        stack.append(to)
            label += 1

    assignment = [0] * n
    for i in range(n):
        f = 2 * i
        t = f + 1
        if comp[f] == comp[t]:
            print("NO")
            return
        # higher component number = earlier in topological order
        assignment[i] = 1 if comp[t] > comp[f] else 0

    print("YES")
    print(' '.join(map(str, assignment)))

if __name__ == "__main__":
    solve()
```

and conforms to the required input‑output format.
