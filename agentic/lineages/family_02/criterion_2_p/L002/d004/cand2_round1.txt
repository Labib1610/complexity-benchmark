<STATEMENT>
# Problem B — Production Line Configuration

Time limit: 1 s   Memory limit: 256 MB

## Description

A manufacturing facility runs $n$ distinct machines. Each machine must be securely locked into one of two operational phases: phase 1 or phase 0. The facility's power grid is safeguarded by $m$ safety interlocks.

Each interlock has two machine connections: a primary relay and a secondary relay. The energy transmitted by a relay depends on the phase of the machine it monitors. 
- A relay designated by a positive integer $c$ outputs 1 unit of energy if machine $c$ is assigned phase 1, and 0 units if it is assigned phase 0. 
- A relay designated by a negative integer $c$ outputs 1 unit of energy if machine $|c|$ is assigned phase 0, and 0 units if it is assigned phase 1.

During a safety audit, each interlock calculates the sum of the energy units output by its primary and secondary relays. If this sum equals zero, the interlock enters a critical fault state and triggers a catastrophic facility-wide shutdown. 

To keep the facility running, the overall phase configuration must ensure that no interlock triggers a shutdown. Determine if a safe facility-wide configuration exists, and if so, output the required phase for each machine.

## Input
The first line of the input provides two integers $n$ and $m$. The facility is divided into one hundred sectors, each capable of housing up to one thousand distinct machines, establishing the strict maximum capacity for $n$. The safety grid's central processor can handle a total number of interlocks up to twice this maximum machine capacity, setting the upper limit for $m$. Assume $n \ge 1$ and $m \ge 0$.

The next $m$ lines each contain two non-zero integers $c_1$ and $c_2$ ($|c_i| \le n$), detailing the designations for the primary and secondary relays of that interlock. 

## Output
If it is impossible to configure all $n$ machines without causing a shutdown, output a single line with the word `NO`.

If a safe configuration is possible, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{0, 1\}$) to specify the chosen phase for each machine from 1 to $n$.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
There might be several safe configurations; outputting any valid one is correct. A single machine can have relays from multiple interlocks attached to it.
</STATEMENT>
<RATIONALE>
I removed the explicit description of "simultaneous violation" that was triggering 2-SAT pattern matching in the models. Instead, I reframed the shutdown condition algebraically as a sum of energy units equaling zero. I also applied S07 by describing the maximum bounds through sector capacities rather than bare inequalities. This forces the model to mathematically deduce that $e_1 + e_2 = 0$ is the only failure state, which is equivalent to $\neg(c_1 \lor c_2)$, meaning they must conceptually bridge the gap from a linear inequality back to a boolean implication graph.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the sum of energy units equals zero is mathematically identical to both reference conditions being violated simultaneously, so the set of valid phase assignments remains exactly the same.
</PRESERVED_ANSWER>

The core problem remains 2-SAT, which is solvable in O(n+m) time using strongly connected components on an implication graph.
