We can model each machine as a boolean variable, and each interlock as a clause that must not have both conditions false.  
That means for an interlock with conditions \( c_1 \) and \( c_2 \), we must have at least one of them true.  
This is exactly a **2-SAT** problem.

We’ll build an implication graph:

- For a condition \( x \) (positive literal), we have node \( x \).  
- For a condition \( \neg x \) (negative literal), we have node \( \neg x \).

For each clause \((a \lor b)\), we add implications:
- \(\neg a \rightarrow b\)
- \(\neg b \rightarrow a\)

Then we run SCC (Tarjan or Kosaraju) to check satisfiability.  
If a variable and its negation are in the same SCC, it’s unsatisfiable.  
Otherwise, we assign values based on SCC order.

```python
import sys
sys.setrecursionlimit(1 << 25)

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    # 2-SAT: variable i -> 2*i for true, 2*i+1 for false
    N = 2 * n
    g = [[] for _ in range(N)]
    rg = [[] for _ in range(N)]

    def node(lit):
        # lit > 0: machine lit is 1 -> true
        # lit < 0: machine -lit is 0 -> false
        v = abs(lit) - 1
        if lit > 0:
            return 2 * v
        else:
            return 2 * v + 1

    def neg_node(idx):
        return idx ^ 1

    for _ in range(m):
        c1, c2 = map(int, input().split())
        a = node(c1)
        b = node(c2)
        # (a or b) => (!a -> b) and (!b -> a)
        na = neg_node(a)
        nb = neg_node(b)
        g[na].append(b)
        rg[b].append(na)
        g[nb].append(a)
        rg[a].append(nb)

    # Kosaraju SCC
    visited = [False] * N
    order = []
    def dfs1(u):
        visited[u] = True
        for v in g[u]:
            if not visited[v]:
                dfs1(v)
        order.append(u)

    for i in range(N):
        if not visited[i]:
            dfs1(i)

    comp = [-1] * N
    def dfs2(u, cid):
        comp[u] = cid
        for v in rg[u]:
            if comp[v] == -1:
                dfs2(v, cid)

    cid = 0
    for u in reversed(order):
        if comp[u] == -1:
            dfs2(u, cid)
            cid += 1

    # Check satisfiability
    for i in range(n):
        if comp[2*i] == comp[2*i+1]:
            print("NO")
            return

    # Assign values: in Kosaraju, comp id order gives topological order of SCCs
    # If comp[true] > comp[false], then true is reachable from false -> set false
    assignment = [0] * n
    for i in range(n):
        # comp[2*i] is true node, comp[2*i+1] is false node
        assignment[i] = 1 if comp[2*i] > comp[2*i+1] else 0

    print("YES")
    print(" ".join(map(str, assignment)))

if __name__ == "__main__":
    main()
```
