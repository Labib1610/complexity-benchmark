<STATEMENT>
# Problem B — Production Line Configuration

Time limit: 1 s   Memory limit: 256 MB

## Description

A manufacturing plant operates $n$ distinct machines, each requiring calibration to either mode 1 or mode 0. The plant is divided into 10 identical halls, each capable of housing up to $10,000$ machines, which sets the absolute upper limit for $n$ (though the plant always operates at least one machine). 

To guarantee operational stability, the plant uses $m$ safety interlocks. These interlocks are procured in crates of $40,000$ units. The plant's budget allows for purchasing anywhere from zero up to exactly five full crates, establishing the maximum possible number of interlocks.

Each interlock connects two reference conditions. A reference condition is described by a non-zero integer $l$. If $l > 0$, the condition is that the machine identified by $l$ operates in mode 1. If $l < 0$, the condition is that the machine identified by $|l|$ operates in mode 0. 

An interlock trips a plant-wide shutdown if and only if both of its monitored reference conditions are simultaneously violated. Safe operation requires avoiding any such simultaneous violation across all $m$ interlocks.

Determine if there is a way to calibrate all $n$ machines such that no interlock trips a shutdown. If such a plant-wide calibration is possible, provide one. Otherwise, indicate that a safe configuration is impossible.

## Input
The first line contains two integers $n$ and $m$. The bounds for $n$ and $m$ are exactly those derived from the facility capacity and budget limits described above.
Each of the following $m$ lines contains two non-zero integers $l_1$ and $l_2$. The absolute value of each integer identifies one of the $n$ machines. These describe the two reference conditions for an interlock.

## Output
If there is no valid way to calibrate the machines without triggering a shutdown, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) representing the chosen mode for each machine from 1 to $n$.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid calibrations may exist; any one is accepted. The same machine may be monitored by multiple interlocks.
</STATEMENT>
