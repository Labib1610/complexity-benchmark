<METHOD_NAME>Diagonal Matrix Encoding of Boolean Logic</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces boolean states with 2x2 diagonal matrices where values $s$ and $1-s$ are on the diagonal. The logical negation operation is represented as a matrix similarity transformation that swaps the diagonals. The logical NOR condition (which triggers the failure state) is represented as the product of two signal matrices evaluating to a specific constant matrix. This completely removes any semantic trace of boolean logic, forcing models to algebraically prove that the matrix product condition is equivalent to a 2-SAT clause before they can apply the correct graph algorithm.</METHOD_DESCRIPTION>

<STATEMENT>
# Dual-Manifold Chemical Routing

Time limit: 1 s   Memory limit: 256 MB

## Description
A chemical processing plant contains $n$ flow distributors. Each distributor $i$ ($1 \le i \le n$) is controlled by a binary toggle $s_i \in \{0, 1\}$.

The configuration of a distributor defines its emission state, which is modeled rigorously as a $2 \times 2$ diagonal matrix $M_i$:
$$ M_i = \begin{pmatrix} s_i & 0 \\ 0 & 1 - s_i \end{pmatrix} $$

The plant's safety system includes $m$ reaction detectors. Each detector observes exactly two signals, specified by two non-zero integers $l_1$ and $l_2$. 
For any observed signal $l$:
- The absolute value $|l|$ identifies the distributor index generating the signal.
- The signal matrix $V$ delivered to the detector depends on the sign of $l$:
  - If $l > 0$, the signal passes through a direct channel, meaning $V = M_{|l|}$.
  - If $l < 0$, the signal passes through an inversion channel, which applies a transformation to the matrix. Specifically, $V = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix} M_{|l|} \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}$.

Inside each detector, the two arriving signal matrices, $V_1$ (derived from $l_1$) and $V_2$ (derived from $l_2$), are multiplied using standard matrix multiplication to form a product matrix $P = V_1 V_2$.

A detector will trigger a catastrophic shutdown if and only if the product matrix evaluates exactly to:
$$ P = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix} $$
If $P$ results in any other matrix, the detector remains dormant.

Your task is to determine whether there is a configuration of toggles $s_1, s_2, \dots, s_n$ such that all $m$ detectors remain dormant. If it is possible, you must provide the configuration. If no such configuration exists, report that the plant is unconfigurable.

## Input
The first line contains two integers $n$ and $m$. The number of distributors $n$ is at least 1 and at most the total number of centimeters in one kilometer. The number of detectors $m$ is at least 0 and at most the total number of centimeters in two kilometers.

Each of the following $m$ lines contains two non-zero integers $l_1$ and $l_2$ ($1 \le |l_i| \le n$), detailing the two signals observed by a single detector. The two signals observed by a detector may originate from the same distributor, and may even be the exact same signal.

## Output
If no valid configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{0, 1\}$) representing a valid configuration.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any one of them is accepted. The same distributor may be observed by multiple detectors.
</STATEMENT>
<RATIONALE>
The problem's underlying 2-SAT structure was previously exposed through boolean-equivalent language ("contains Isotope-0 and is completely devoid of Isotope-1"). This rewrite replaces the boolean states with 2x2 diagonal matrices and the negation/NOR logic with matrix multiplication and similarity transformations. Models must now algebraically prove that the matrix product condition is equivalent to a 2-SAT clause before they can apply the correct graph algorithm, defeating pure pattern matching. Additionally, numeric bounds are stated indirectly via physical conversions (centimeters in a kilometer) to satisfy constraint S07.
</RATIONALE>
<PRESERVED_ANSWER>
The matrix transformation perfectly maps $s_i$ to boolean literals and $P = \text{diag}(0, 1)$ strictly occurs if and only if both input signals correspond to a logical FALSE, maintaining the exact same valid configurations for every input.
</PRESERVED_ANSWER>

The underlying mathematical constraints simplify directly back to a 2-SAT instance where each detector represents a disjunctive clause, solvable in $O(n+m)$ time using strongly connected components.
</PRESERVED_CLASS>
