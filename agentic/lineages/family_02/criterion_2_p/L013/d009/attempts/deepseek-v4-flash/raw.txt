We can model each strut as a boolean variable, and each brace as a constraint that forbids a certain combination.  

Let’s define for each strut \( i \):  
- \( s_i = 1 \) means heating (expansion +1)  
- \( s_i = 0 \) means cooling (contraction -1)  

For a connection \( l \):  
- If \( l > 0 \), displacement = \( +1 \) if \( s_{|l|}=1 \), else \(-1\)  
- If \( l < 0 \), displacement = \(-1\) if \( s_{|l|}=1 \), else \(+1\)  

So effectively, the displacement for connection \( l \) is:  
\[
d(l) = 
\begin{cases}
s_{|l|} & \text{if } l > 0 \\
1 - s_{|l|} & \text{if } l < 0
\end{cases}
\]
where \( s_i \in \{0,1\} \).

A brace fractures if the sum of its two displacements is exactly \(-2\).  
That happens only when both displacements are \(-1\).  

So for each brace \((l_1, l_2)\), we must avoid the case where both connections give \(-1\).  

We can convert this into a 2-SAT problem:  
- For each strut \( i \), create two literals:  
  - \( x_i \) = true means \( s_i = 1 \)  
  - \( \neg x_i \) = true means \( s_i = 0 \)  

For a connection \( l \):  
- If \( l > 0 \), displacement = \(-1\) when \( s_{|l|}=0 \) → literal \( \neg x_{|l|} \)  
- If \( l < 0 \), displacement = \(-1\) when \( s_{|l|}=1 \) → literal \( x_{|l|} \)  

So for each brace, we must forbid the combination where both literals are true.  
That is a clause:  
\[
(\neg A \lor \neg B)
\]
where \( A \) and \( B \) are the literals that cause \(-1\).  

This is a 2-SAT instance. We can solve it with implication graph and SCC.

Let’s implement it.

```python
import sys
sys.setrecursionlimit(1 << 20)
input = sys.stdin.readline

n, m = map(int, input().split())
N = 2 * n  # each variable has two nodes: 2*i for false, 2*i+1 for true

def node(var, val):
    # var: 0..n-1, val: True/False
    return 2 * var + (1 if val else 0)

def neg(node_idx):
    return node_idx ^ 1

g = [[] for _ in range(N)]
gr = [[] for _ in range(N)]

def add_imp(u, v):
    g[u].append(v)
    gr[v].append(u)

def add_clause(a, b):
    # clause (a or b)
    add_imp(neg(a), b)
    add_imp(neg(b), a)

for _ in range(m):
    l1, l2 = map(int, input().split())
    # literal that causes -1 for each connection
    def lit(l):
        idx = abs(l) - 1
        if l > 0:
            return node(idx, False)  # s=0 -> -1
        else:
            return node(idx, True)   # s=1 -> -1
    A = lit(l1)
    B = lit(l2)
    # forbid A and B both true: clause (not A or not B)
    add_clause(neg(A), neg(B))

# Kosaraju SCC
visited = [False] * N
order = []
def dfs1(u):
    visited[u] = True
    for v in g[u]:
        if not visited[v]:
            dfs1(v)
    order.append(u)

for i in range(N):
    if not visited[i]:
        dfs1(i)

comp = [-1] * N
def dfs2(u, cid):
    comp[u] = cid
    for v in gr[u]:
        if comp[v] == -1:
            dfs2(v, cid)

cid = 0
for u in reversed(order):
    if comp[u] == -1:
        dfs2(u, cid)
        cid += 1

# Check satisfiability
for i in range(n):
    if comp[2*i] == comp[2*i+1]:
        print("NO")
        sys.exit()

print("YES")
res = []
for i in range(n):
    # if true node comes after false node in topological order, assign true
    if comp[2*i+1] > comp[2*i]:
        res.append(1)
    else:
        res.append(0)
print(' '.join(map(str, res)))
```
