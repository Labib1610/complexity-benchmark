- If switch 2 is NOT in expected position, switch 1 MUST be in expected position

Let me define:

For each interlock (l1, l2): `x_a OR x_b` must be true (where a, b are the switch indices).

This is a 2-SAT problem! The clause is `x_a ∨ x_b`.

Converting to implications:
- `¬x_a → x_b` (if switch a not in expected, switch b must be in expected)
- `¬x_b → x_a`

I'll use the standard 2-SAT algorithm with SCC (Kosaraju's or Tarjan's).

For each switch i, I have a variable `x_i` (in expected position or not).
- Variable `x_i` = True: node `2*i`
- Variable `¬x_i` = True: node `2*i+1`

For clause `x_a ∨ x_b`:
- Add edge `¬x_a → x_b` (i.e., `2*a+1 → 2*b`)
- Add edge `¬x_b → x_a` (i.e., `2*b+1 → 2*a`)

Then find SCCs and check if `x_i` and `¬x_i` are in different SCCs. If `x_i`'s SCC > `¬x_i`'s SCC (in topological order), set `x_i` to True.

Once I have the `x_i` values, I convert back to switch positions:
- If `x_i = 1`: switch i is in expected position (ON if l>0, OFF if l<0)
- If `x_i = 0`: switch i is NOT in expected position

        add_imp(u ^ 1, v)
        add_imp(v ^ 1, u)

        add_clause(u, v)

    visited = [False] * (2 * n)
    order = []

        visited[v] = True
        while stack:

            if i < len(adj[node]):

                nxt = adj[node][i]
                if not visited[nxt]:
                    visited[nxt] = True
                    stack.append((nxt, 0))

                order.append(node)
                stack.pop()

            dfs1(i)

                    stack.append(nxt)
    
    c = 0
    for i in reversed(order):
        if comp[i] == -1:
            dfs2(i, c)
            c += 1
