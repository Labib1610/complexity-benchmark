<STATEMENT>
# Framework Resonance Stability

Time limit: 1 s   Memory limit: 256 MB

## Description
A structural framework contains $n$ tunable struts. Each strut $i$ ($1 \le i \le n$) is controlled by a binary mode $s_i \in \{0, 1\}$.

The framework is reinforced by $m$ rigid braces. Each brace spans exactly two connections across the framework. A brace's connections are specified by two non-zero integers $l_1$ and $l_2$. For any connection $l$:
- The absolute value $|l|$ identifies the strut index it attaches to.
- The sign of $l$ dictates its mechanical coupling. We define the transmission factor $t_l$ for the connection as follows:
  - If $l > 0$, it is a direct coupling, and $t_l = 1 - s_{|l|}$.
  - If $l < 0$, it is an inverted coupling, and $t_l = s_{|l|}$.

Inside each brace, the two connections create a mechanical feedback loop. For a brace with connections $l_1$ and $l_2$, the internal forces $x$ and $y$ (which are real numbers) must satisfy the following equilibrium system:
$$x + t_{l_1} y = 0$$
$$t_{l_2} x + y = 0$$

A brace operates safely if and only if the only valid internal forces that satisfy this system are the trivial solution $x = 0$ and $y = 0$. If there exists any solution where at least one of $x$ or $y$ is non-zero, the feedback loop resonates infinitely, and the brace will catastrophically fracture.

Your task is to determine whether there is a configuration of modes $s_1, s_2, \dots, s_n$ such that all $m$ braces remain intact (i.e., no brace fractures). If it is possible, you must provide the configuration. If no such configuration exists, print a single line containing `NO`.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of struts and the number of braces, respectively.

Each of the following $m$ lines contains two non-zero integers $l_1$ and $l_2$ ($1 \le |l_i| \le n$), detailing the two connections for a single brace. The two connections for a brace may attach to the same strut, may be the exact same connection ($l_1 = l_2$), or may be the same strut with opposite signs ($l_1 = -l_2$). The same pair of connections may also appear on multiple braces. 

## Output
If no valid configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{0, 1\}$) representing a valid configuration.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any one of them is accepted. If $m = 0$, there are no braces to fracture, so any combination of $n$ valid modes is acceptable.
</STATEMENT>
<RATIONALE>
I removed the arithmetic threshold condition (sum of displacements == -2) that all surviving models used to instantly recognize the 2-SAT OR-clauses. Instead, the failure condition is now framed as the existence of non-trivial solutions to a 2x2 linear system. To find the boolean clause, a model must compute the determinant ($1 - t_{l_1} t_{l_2}$), set it to zero, and deduce that fracture occurs if and only if both transmission factors equal 1.
</RATIONALE>
<PRESERVED_ANSWER>
The linear system has non-trivial solutions if and only if its determinant is zero, meaning $t_{l_1} t_{l_2} = 1$; since $t_l \in \{0, 1\}$, this exactly matches the original condition where both connections are in the state that contributes to failure.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, solvable in O(n+m) time, because the non-singularity requirement for each brace logically simplifies to an OR-clause on two boolean literals.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the variables $x$ and $y$ as quantities they need to compute or output, though the text explicitly defines the output format as just the array of binary modes $s_i$.
</RISK>
