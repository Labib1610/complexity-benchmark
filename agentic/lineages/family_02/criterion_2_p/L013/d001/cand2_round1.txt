# Problem B — Paired Window Constraints

Time limit: 1 s   Memory limit: 256 MB

## Description
A control panel features $n$ binary switches, each of which must be locked into either an ON or OFF position prior to operation. The commissioning team has established $m$ acceptance criteria for the panel. Every criterion lists exactly two switch-conditions—where a condition is defined as a specific switch and its required state. For a criterion to pass, the panel's configuration must fulfill at least one of those two conditions.

You must determine whether it is possible to find a single, global configuration for all $n$ switches that simultaneously passes all $m$ criteria. If a valid configuration exists, output it; otherwise, report that the criteria cannot be jointly satisfied.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two non-zero signed integers $l_1$ and $l_2$, with $|l_i| \le n$. A positive integer $x$ represents the condition that switch $x$ is ON, and a negative integer $-x$ represents the condition that switch $x$ is OFF. For each line, at least one of the two stated conditions must be met.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each in $\{0, 1\}$) forming any valid assignment, where $1$ denotes ON and $0$ denotes OFF.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid assignments may exist; any one is accepted. The same switch may appear in multiple criteria.
