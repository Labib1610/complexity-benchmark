# Problem B — Quantum Interference Calibration

Time limit: 1 s   Memory limit: 256 MB

## Description
A quantum computing array consists of $n$ qubits. Each qubit $i$ must be calibrated to a basis state $s_i \in \{0, 1\}$. This state defines its physical phase angle $\phi_i = s_i \pi$ radians.

The array is equipped with $m$ two-qubit coherence checks to ensure stability. Each check monitors two signals, described by two non-zero integers $c_1$ and $c_2$. 

For any non-zero integer $c$, the absolute value $|c|$ indicates the qubit being measured. The sign of $c$ determines the reference angle for that signal: $\theta_c = \pi$ if $c > 0$, and $\theta_c = 0$ if $c < 0$.

The check computes the interference amplitude $M$ of its two monitored signals:
$$M = \cos(\phi_{|c_1|} - \theta_{c_1}) + \cos(\phi_{|c_2|} - \theta_{c_2})$$

A coherence check fails and triggers a system reset if its interference amplitude is strictly negative (i.e., $M < 0$). As long as $M \ge 0$, the check passes.

Your task is to determine whether there exists a global basis configuration $s_1, s_2, \dots, s_n$ such that all $m$ coherence checks pass. If such a configuration exists, you must provide it. If no such configuration is possible, you must report that the system is unconfigurable.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of qubits and the number of checks, respectively.

Each of the following $m$ lines contains two non-zero integers $c_1$ and $c_2$ ($1 \le |c_i| \le n$). For each integer, the absolute value indicates the qubit index. A positive integer sets a reference angle of $\pi$, while a negative integer sets a reference angle of $0$. The two signals monitored by a check may refer to the same qubit, and may be identical or opposite.

## Output
If no valid configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{0, 1\}$) representing a valid basis configuration.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any one of them is accepted. The same qubit may be monitored by multiple checks.
</STATEMENT>
<RATIONALE>
Removed the explicit logical mapping of inputs to boolean targets and the explicit OR-clause ("at least one is actually held"). Instead, boolean states are mapped to phase angles (0 or pi), and the clause is replaced by a trigonometric inequality (sum of cosines >= 0). Models must now algebraically evaluate the four possible phase combinations to deduce that the inequality is mathematically identical to a 2-SAT OR-clause.
</RATIONALE>
<PRESERVED_ANSWER>
Because angles are restricted to 0 and pi, the cosine of the difference is exactly 1 when the phase matches the reference, and -1 when it mismatches; the sum is >= 0 if and only if at least one phase matches, preserving the exact 2-SAT logic of the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, solvable in O(n+m) time using standard implication graph and SCC algorithms once the trigonometric inequality is translated back to boolean logic.
</PRESERVED_CLASS>
<RISK>
Models might attempt to solve the problem using floating-point math or numerical optimization instead of recognizing it as a discrete logic problem, leading to precision bugs or TLE, though the definition of states as {0, 1} and exact multiples of pi makes the discrete intent unambiguous to a careful reader.
</RISK>
