<METHOD_NAME>Algebraic Zero-Product Formulation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit boolean mutual exclusion condition "not both active" with a mathematically equivalent algebraic equation $|A - B| = A + B$ over binary amplitude variables. This forces the model to algebraically deduce that $A \cdot B = 0$ (at least one amplitude must be zero) rather than pattern-matching textbook 2-SAT descriptions.</METHOD_DESCRIPTION>

<STATEMENT>
# Photonic Interference Routing

Time limit: 1 s   Memory limit: 256 MB

## Description
A photonic computing facility contains $n$ laser modulators. Each modulator $i$ ($1 \le i \le n$) is configured by a state $s_i \in \{0, 1\}$.
- State $1$ means the modulator is active.
- State $0$ means the modulator is inactive.

Each modulator emits two distinct frequency bands, and their output amplitudes depend on the modulator's state $s_i$:
- The lower-band emission has an amplitude equal to $s_i$.
- The upper-band emission has an amplitude equal to $1 - s_i$.

The facility is monitored by $m$ interference sensors. Each sensor receives exactly two emission bands. A sensor evaluates the amplitudes $A$ and $B$ of the two bands it receives. The sensor remains stable if and only if the amplitudes satisfy the equation:
$|A - B| = A + B$
If this equation is not satisfied, the sensor destabilizes the system.

Your task is to determine whether there is a configuration of states $s_1, s_2, \dots, s_n$ such that all $m$ sensors remain stable. If it is possible, you must provide the configuration. If no such configuration exists, report that the facility is unconfigurable.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of modulators and the number of sensors, respectively.

Each of the following $m$ lines contains two non-zero signed integers $l_1$ and $l_2$ ($1 \le |l_i| \le n$), detailing the two emission bands received by a single sensor. For each integer $l$:
- The absolute value $|l|$ identifies the modulator index.
- A negative integer ($l < 0$) specifies that the sensor receives the lower-band emission of modulator $|l|$.
- A positive integer ($l > 0$) specifies that the sensor receives the upper-band emission of modulator $|l|$.

The two emission bands received by a sensor may belong to the same modulator, and may even be the exact same emission band.

## Output
If no valid configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{0, 1\}$) representing a valid configuration.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any one of them is accepted. The same modulator may be monitored by multiple sensors.
</STATEMENT>
<RATIONALE>
The explicit boolean logic (a detector triggers if and only if both manifolds are active) was replaced with an algebraic equation over binary variables. The equation $|A - B| = A + B$ holds for $A, B \in \{0, 1\}$ if and only if at least one of $A$ or $B$ is zero. This forces the model to deduce the logic gate semantics algebraically rather than triggering on standard 2-SAT keywords. The bounds have been explicitly restored to $2 \cdot 10^5$ to satisfy the hard constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $|A - B| = A + B$ over binary variable amplitudes evaluates to true exactly when $A \cdot B = 0$, which perfectly corresponds to the seed's "at most one active" restriction, preserving all satisfying assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, as every sensor still enforces a logical NAND constraint between two literal states, solvable in $O(n+m)$ time.
</PRESERVED_CLASS>
