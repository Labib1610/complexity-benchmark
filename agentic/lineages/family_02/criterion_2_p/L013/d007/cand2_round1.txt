<METHOD_DESCRIPTION>Replaces the direct boolean pairwise exclusion condition (NOT (A and B)) with the algebraic equality |A - B| = A + B over {0, 1} variables. Since this equation simplifies to A * B = 0, it perfectly preserves the NAND logic of the original 2-SAT clauses, but models relying on pattern matching will fail to recognize it as a standard implication graph generator, instead likely attempting to use numeric constraint solvers or failing to identify the P-time graph structure.</METHOD_DESCRIPTION>

<STATEMENT>
# Photonic Interference Alignment

Time limit: 1 s   Memory limit: 256 MB

## Description
A photonic facility operates $n$ phase modulators. Each modulator $i$ (for $i$ from $1$ to $n$) is controlled by a binary toggle $s_i \in \{0, 1\}$, where $1$ denotes ON and $0$ denotes OFF.

The system generates $2n$ distinct signal beams. For each modulator $i$, two beams are emitted depending on its toggle state:
- The **lower-band** beam (denoted by index $-i$) has an amplitude equal to $s_i$.
- The **upper-band** beam (denoted by index $+i$) has an amplitude equal to $1 - s_i$.

The facility's stability is monitored by $m$ interference sensors. Each sensor takes exactly two beams as input. For the system to safely operate, every sensor must observe perfect constructive-destructive balance. Specifically, if a sensor receives a beam with amplitude $A$ and another beam with amplitude $B$, the system requires that the absolute difference between their amplitudes exactly equals their sum:
$|A - B| = A + B$.

Your task is to determine whether there is a configuration of toggles $s_1, s_2, \dots, s_n$ such that all $m$ sensors are satisfied. If such a configuration exists, you must provide it. If no such configuration is possible, report that the facility is unconfigurable.

## Input
The first line contains two integers $n$ and $m$. The number of modulators $n$ is at least $1$ and cannot exceed $100,000$ due to facility spatial limits. The number of sensors $m$ can be as low as $0$, and at most twice the maximum allowed number of modulators.

Each of the following $m$ lines contains two non-zero signed integers $l_1$ and $l_2$, detailing the indices of the two beams fed into a single sensor. For each integer $l$:
- The absolute value $|l|$ identifies a valid modulator currently in operation (an integer from $1$ to $n$).
- A negative integer ($l < 0$) specifies the lower-band beam of modulator $|l|$.
- A positive integer ($l > 0$) specifies the upper-band beam of modulator $|l|$.

The two beams fed into a sensor may belong to the same modulator, and may even be the exact same beam.

## Output
If no valid configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{0, 1\}$) representing a valid configuration, where $1$ denotes ON and $0$ denotes OFF.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```

## Note
Multiple valid configurations may exist; any one of them is accepted. The same beam may be fed into multiple sensors.
</STATEMENT>
<RATIONALE>
The explicit 2-SAT exclusion phrasing ("at most one active", "not both") has been entirely removed. It is replaced with the algebraic equality `|A - B| = A + B` over amplitudes in `{0, 1}`. This equation simplifies to `A * B = 0`, which is logically identical to the original NAND constraint, but forces the model to perform algebraic deduction before it can recognize the underlying 2-SAT structure. Numeric bounds were also restated indirectly per strategy S07 to further disrupt pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
For any variables A, B in {0, 1}, the equation |A - B| = A + B holds true if and only if A and B are not both 1, exactly mirroring the original constraint that two sampled manifolds cannot both be active simultaneously.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-SAT, solvable in O(n+m) time by constructing an implication graph and finding strongly connected components, because the algebraic constraint still reduces purely to pairwise boolean exclusions.
</PRESERVED_CLASS>
