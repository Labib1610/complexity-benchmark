We can model this as a graph problem where components are vertices and links are edges.  
We need to assign each vertex a distinct position from 1 to N (the number of components) such that the sum over all edges of the absolute difference in positions is ≤ K.

This is equivalent to finding a linear arrangement of the graph minimizing the sum of edge lengths.  
The optimal arrangement for minimizing the sum of absolute differences is to place vertices in order of their degree (or more precisely, by a known result: for trees, placing by BFS/DFS from a centroid works; for general graphs, it’s NP-hard, but here we can try a greedy approach).

Since N is not given explicitly in the statement, but constraints are not huge (likely small enough for brute force or greedy), we can try:

- If N is small (≤ 8), brute force all permutations.
- Otherwise, use a greedy: sort vertices by degree descending and place them in the middle, then place neighbors around them.

Let’s implement a solution that:
1. Reads input.
2. Builds adjacency list.
3. Tries a greedy placement.
4. Checks if the sum ≤ K.
5. If yes, prints YES and the arrangement; else NO.

We’ll also try a few heuristics to increase chance of success.

```python
import sys
from itertools import permutations

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))
    edges = []
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges.append((u, v))
        adj[u].append(v)
        adj[v].append(u)
    
    # Try brute force for small n
    if n <= 8:
        best_perm = None
        best_cost = float('inf')
        for perm in permutations(range(n)):
            pos = [0]*n
            for idx, node in enumerate(perm):
                pos[node] = idx+1
            cost = sum(abs(pos[u]-pos[v]) for u,v in edges)
            if cost <= k:
                print("YES")
                print(" ".join(str(pos[i]) for i in range(n)))
                return
        print("NO")
        return
    
    # Greedy: place high-degree nodes in middle
    deg = [len(adj[i]) for i in range(n)]
    order = sorted(range(n), key=lambda x: -deg[x])
    pos = [0]*n
    used = [False]*(n+1)
    # Place first node in middle
    mid = (n+1)//2
    pos[order[0]] = mid
    used[mid] = True
    left = mid-1
    right = mid+1
    for node in order[1:]:
        # place near already placed neighbors if possible
        placed = False
        for nb in adj[node]:
            if pos[nb] != 0:
                # try left or right of that neighbor
                for cand in (pos[nb]-1, pos[nb]+1):
                    if 1 <= cand <= n and not used[cand]:
                        pos[node] = cand
                        used[cand] = True
                        placed = True
                        break
                if placed:
                    break
        if not placed:
            # place at nearest free slot from middle
            for cand in range(mid, 0, -1):
                if not used[cand]:
                    pos[node] = cand
                    used[cand] = True
                    break
            else:
                for cand in range(mid+1, n+1):
                    if not used[cand]:
                        pos[node] = cand
                        used[cand] = True
                        break
    
    cost = sum(abs(pos[u]-pos[v]) for u,v in edges)
    if cost <= k:
        print("YES")
        print(" ".join(str(pos[i]) for i in range(n)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
