**Solution Explanation**

For every component we have to choose a distinct station number `1 … n`.
If component `u` is placed on station `p[u]` and component `v` on station `p[v]`,
the length of the fibre that connects them equals `|p[u]‑p[v]|`.

For a permutation `π` (the order in which the stations are filled) we have  

```
p[π[i]] = i          (i = 1 … n)
```

so the total length of all required fibres is  

```
F(π) = Σ_{(u,v)∈E} |pos[u] – pos[v]|
```

where `pos[x]` is the position of `x` inside the permutation.
The problem is to find a permutation whose total length does not exceed the
given limit `K`.

The problem is the *minimum linear arrangement* problem, which is NP‑hard in
general. The limits of the original contest are small (the official solution
uses exhaustive search), therefore a back‑tracking search with good pruning
is sufficient.



--------------------------------------------------------------------

#### 1.   Data structures

* `adj[v]` – list of neighbours of `v`.
* `edges` – list of all edges `(u,v)` (each edge once, `u < v`).
* `placed[v]` – `True` iff `v` already has a station.
* `pos[v]` – the station number of `v` (filled while searching).
* `order` – current permutation being built (`order[idx] = vertex placed at
  station idx`).

Additional counters used for pruning

* `cur_sum` – total length contributed by edges whose both ends are already placed.
* `placed_edges` – number of edges already counted in `cur_sum`.

--------------------------------------------------------------------

#### 2.   Back‑tracking

We fill the stations from left to right (`idx = 1 … n`).

```
search(idx, cur_sum, placed_edges):
    if idx > n:                     # all stations are filled
         if cur_sum ≤ K:  solution found
         return

    for each vertex v not yet placed (ordered by degree, descending):
         # add v at station idx
         added = 0
         newly = 0
         for each neighbour u of v:
                if placed[u]:
                     added += idx - pos[u]          # distance contribution
                     newly += 1                     # one more edge becomes counted
         new_sum = cur_sum + added
         new_placed_edges = placed_edges + newly

         # lower bound for the still unknown part:
         # every not‑yet‑counted edge will need at least length 1
         min_possible = new_sum + (m - new_placed_edges) * 1
         if min_possible > K:      # cannot succeed, prune
                continue

         # commit
         placed[v] = True
         pos[v] = idx
         order[idx] = v
         search(idx+1, new_sum, new_placed_edges)
         if solution already found: return
         # undo
         placed[v] = False
```

*Why the bound works* – an edge whose at least one endpoint is still free can
always be realised with distance `1` (by putting the two endpoints on two
consecutive still empty stations). Therefore the smallest total length that
can still be added is `remaining_edges * 1`.

The search order (high degree first) makes the bound tight early and reduces
the tree size dramatically.

The recursion stops as soon as a feasible permutation is found.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct permutation iff such a
permutation exists.

---

##### Lemma 1  
During the search, `cur_sum` equals the sum of `|pos[u]-pos[v]|` over all edges
whose both endpoints are already placed.

**Proof.**  
Initially no vertex is placed, `cur_sum = 0`, the statement holds.
When a vertex `v` is placed at station `idx`, the algorithm adds for every
already placed neighbour `u` the value `idx - pos[u]`, which is exactly the
distance of edge `(u,v)`. No other edge changes its contribution.
∎



##### Lemma 2  
For any recursive call `search(idx, cur_sum, placed_edges)` the value  

```
lower = cur_sum + (m - placed_edges) * 1
```

is a lower bound on the total fibre length of **any** completion of the
partial permutation.

**Proof.**  
`cur_sum` is already fixed (Lemma&nbsp;1).  
`m - placed_edges` is the number of edges whose length is still unknown.
Every such edge will connect two distinct stations, therefore its length is at
least `1`. Adding `1` for each of them yields a lower bound. ∎



##### Lemma 3  
If the algorithm prunes a branch because `lower > K`, then **no**
completion of that branch can satisfy the limit `K`.

**Proof.** Directly from Lemma&nbsp;2: any completion has total length ≥ `lower`,
hence > `K`. ∎



##### Lemma 4  
If the algorithm reaches `idx = n` and outputs the current permutation,
its total length is ≤ `K`.

**Proof.** At that moment all vertices are placed, therefore `placed_edges = m`
and `cur_sum` equals the total length (Lemma&nbsp;1). The algorithm checks
`cur_sum ≤ K` before accepting, so the condition holds. ∎



##### Lemma 5  
If a feasible permutation exists, the algorithm will eventually find one.

**Proof.**  
Consider any feasible permutation `π`. The recursive search tries every
possible vertex for the next free station (the loop iterates over all not yet
placed vertices). Hence there is a unique path in the recursion tree that
places the vertices exactly in the order of `π`.  
Along this path the algorithm never prunes, because for every prefix the
partial sum is ≤ the total sum of `π` (which ≤ `K`), and the lower bound computed
by Lemma&nbsp;2 is ≤ that total sum as well, therefore ≤ `K`. Consequently the
search reaches the leaf `idx = n` and accepts `π` (Lemma&nbsp;4). ∎



##### Lemma 6  
If the algorithm outputs `NO`, no feasible permutation exists.

**Proof.** The algorithm explores the whole recursion tree except for branches
removed by the pruning rule. By Lemma&nbsp;3 every pruned branch cannot lead to a
solution. All non‑pruned leaves have been examined and none satisfied the
limit, therefore no feasible permutation exists. ∎



##### Theorem  
The program prints  

* `YES` and a permutation whose total fibre length ≤ `K` **iff** such a
  permutation exists,
* otherwise prints `NO`.

**Proof.**  
*If* part: by Lemma&nbsp;5 a feasible permutation is eventually found and,
by Lemma&nbsp;4, satisfies the limit, so the program prints `YES` and that
permutation.  

*Only‑if* part: if the program prints `YES`, the printed permutation was
produced at a leaf and therefore respects the limit (Lemma&nbsp;4).  
If the program prints `NO`, Lemma&nbsp;6 guarantees that no feasible
permutation exists. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

`n` – number of components, `m` – number of edges.

The algorithm is exponential in the worst case (enumerates all `n!`
permutations).  
The pruning dramatically reduces the explored nodes for the intended test
data (the official limits are small, e.g. `n ≤ 10`).  

Memory consumption:  

* adjacency lists – `O(n + m)`  
* recursion stack – `O(n)`  

Both well below the limits.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    K = int(next(it))

    adj = [[] for _ in range(n)]
    edges = []
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        if u > v:
            u, v = v, u
        edges.append((u, v))
        adj[u].append(v)
        adj[v].append(u)

    # order vertices by degree descending for better branching
    vertices = list(range(n))
    vertices.sort(key=lambda x: -len(adj[x]))

    placed = [False] * n
    pos = [0] * n          # station number (1‑based)
    order = [0] * (n + 1)  # order[idx] = vertex at station idx
    answer = None

    # pre‑compute total edges for bound
    total_edges = m

    def dfs(idx: int, cur_sum: int, placed_edges: int):
        nonlocal answer
        if answer is not None:
            return
        if idx > n:
            if cur_sum <= K:
                # build answer in required format (stations for component 1..n)
                ans = [0] * n
                for v in range(n):
                    ans[v] = pos[v]
                answer = ans
            return

        # try every not yet placed vertex, in the order defined above
        for v in vertices:
            if placed[v]:
                continue
            added = 0
            newly = 0
            for u in adj[v]:
                if placed[u]:
                    added += idx - pos[u]
                    newly += 1
            new_sum = cur_sum + added
            new_placed_edges = placed_edges + newly

            # lower bound: each remaining edge needs at least length 1
            min_possible = new_sum + (total_edges - new_placed_edges)
            if min_possible > K:
                continue

            placed[v] = True
            pos[v] = idx
            order[idx] = v
            dfs(idx + 1, new_sum, new_placed_edges)
            if answer is not None:
                return
            placed[v] = False

    dfs(1, 0, 0)

    out = []
    if answer is None:
        out.append("NO")
    else:
        out.append("YES")
        out.append(" ".join(str(x) for x in answer))
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
