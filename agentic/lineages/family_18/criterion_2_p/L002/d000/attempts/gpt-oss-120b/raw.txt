**Solution Explanation**

For the given `n` modules the `m = n‑1` cables form a tree.
For a placement `p[1…n]` ( `p[i]` – bay of module `i` ) the total length is  

```
cost(p) = Σ | p[u] – p[v] |   over all tree edges (u,v)
```

--------------------------------------------------------------------

#### 1.   Minimum possible total length  

For an edge `(u,v)` let `s` be the size of the component that contains `u`
after deleting the edge, `t = n‑s` the size of the other component.
In any linear order the vertices of the two components occupy two
intervals, therefore the distance of the two endpoints is at least the
size of the smaller interval, i.e. `min(s,t)`.  
Consequently

```
cost(p) ≥ Σ  min(s_e , n‑s_e)          (1)
```

The bound is *tight* for trees: it can be achieved by a special ordering
obtained from a **centroid decomposition** (proved below).  
Hence the minimum possible total length is

```
MIN = Σ  min(s_e , n‑s_e)            (over all edges)
```

--------------------------------------------------------------------

#### 2.   Constructing an ordering that reaches the bound  

A **centroid** of a tree (or of a connected component) is a vertex whose
removal leaves only components of size `≤ size/2`.  
Take any component, find its centroid `c`, remove `c` and recurse on each
remaining component.  
While returning from the recursion we output the vertices in the order

```
c , (ordering of first component) , (ordering of second component) , …
```

*Why does it work?*  
Consider an edge `(c, x)` where `x` belongs to a component `C` of size `|C|`.
All vertices of `C` appear **consecutively** after `c` in the final order,
therefore the distance between `c` and `x` equals `|C|`.  
Because `c` is a centroid, `|C| = min(|C| , n‑|C|)`.  
For an edge completely inside a component the same argument holds
inductively (the component itself is processed by the same rule).  
Thus every edge contributes exactly `min(s_e , n‑s_e)` and the total cost
equals `MIN`.

--------------------------------------------------------------------

#### 3.   Algorithm  

```
read n, m, B
read the tree edges, build adjacency list
DFS once (root = 1) to obtain subtree sizes
MIN = Σ  min(subtree_size, n‑subtree_size) over all edges
if B < MIN :  print "NO" and finish

# otherwise construct an ordering using centroid decomposition
removed[1…n] = False
answer = empty list

function decompose(start):
        # collect all vertices of the current component
        comp = list of vertices reachable from start without using removed vertices
        sz = len(comp)

        # find centroid of this component
        # run a DFS inside comp to compute sizes
        centroid = find_centroid(comp)

        removed[centroid] = True
        answer.append(centroid)

        for each neighbour v of centroid:
                if not removed[v]:
                        decompose(v)          # the neighbour belongs to a new component

call decompose(1)

print "YES"
print the permutation answer (bay numbers)   # answer[i] is the bay of module i
```

`find_centroid` works in linear time on the component:
during the DFS we know for every vertex the size of its subtree inside the
component and the size of the “outside” part (`sz - subtree`).  
The vertex whose maximal part size is ≤ `sz/2` is a centroid.

All traversals together touch each vertex `O(log n)` times (once per level
of the centroid decomposition), therefore the whole algorithm is `O(n)`.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
For any tree edge `e` with component sizes `s` and `n‑s`,
every linear ordering of the vertices satisfies  
`|position(u) – position(v)| ≥ min(s , n‑s)`.

**Proof.**  
Removing `e` splits the vertices into two sets `A` (size `s`) and `B`
(size `n‑s`). In any permutation the vertices of `A` occupy a contiguous
segment of length `|A|` and the vertices of `B` another segment.
The two endpoints of `e` lie in different segments, therefore the distance
between them is at least the length of the smaller segment,
i.e. `min(s , n‑s)`. ∎



##### Lemma 2  
Let a component `C` be processed by the recursive procedure described in
section&nbsp;2 and let `c` be its centroid.  
All vertices of each child component of `c` appear consecutively **after**
`c` in the final order, and the distance between `c` and the vertex of the
edge connecting them equals the size of that child component.

**Proof.**  
When `c` is output, the recursion immediately processes each neighbour
`v` that is not removed. The call `decompose(v)` works only inside the
connected component that contains `v` after deleting `c`.  
Thus all vertices reachable from `v` without passing `c` are placed
*after* the whole output of `decompose(v)`. No vertex of another child
component can be interleaved, because the recursion for a child finishes
before the next child is started. Consequently the vertices of a child
form a contiguous block after `c`. The block length is exactly the size of
that component, which is the distance between `c` and `v`. ∎



##### Lemma 3  
For every tree edge `e` the distance contributed by the ordering produced
by the algorithm equals `min(s_e , n‑s_e)`.

**Proof.**  
Consider edge `e = (u,v)`. Let `c` be the centroid that is the first among
`u` and `v` removed by the decomposition (the recursion removes vertices
in the order they are output). At that moment `c` separates the tree into
components, one of which contains `u` and the other contains `v`.  
By Lemma&nbsp;2 the whole component containing `v` (say) appears as a single
block after `c`, therefore the distance between `c` and `v` equals the
size of that component, which is exactly the smaller side of `e`
(because `c` is a centroid, each component size ≤ total/2).  
All deeper edges lie completely inside one of the components and the same
argument applies recursively. Hence every edge contributes the minimum
possible value. ∎



##### Lemma 4  
The total length of the ordering returned by the algorithm equals  

```
MIN = Σ  min(s_e , n‑s_e)
```

**Proof.** Directly from Lemma&nbsp;3 by summation over all edges. ∎



##### Lemma 5  
If `B ≥ MIN` the algorithm outputs a permutation whose total cable length
does not exceed `B`.

**Proof.** By Lemma&nbsp;4 the produced permutation has total length `MIN`.
Since `B ≥ MIN`, the length is ≤ `B`. ∎



##### Lemma 6  
If `B < MIN` no permutation satisfies the bound.

**Proof.** By Lemma&nbsp;1 every permutation has total length at least `MIN`.
Thus a bound smaller than `MIN` is impossible. ∎



##### Theorem  
The program prints  

* “YES” and a valid assignment of modules to bays **iff** such an assignment
  exists (i.e. `B ≥ MIN`);
* otherwise prints “NO”.

**Proof.**  
The program computes `MIN` exactly (Lemma&nbsp;1).  
*If `B < MIN`* it prints “NO”. By Lemma&nbsp;6 this is correct.  
*If `B ≥ MIN`* it runs the centroid‑decomposition construction and prints
the obtained permutation. By Lemma&nbsp;5 its total length ≤ `B`, therefore
the printed assignment is valid. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Computing `MIN`* – one DFS: `O(n)`.  
*Centroid decomposition* – each vertex is visited in the component of its
current level, total `O(n)`.  
Memory consumption: adjacency list `O(n)`, several auxiliary arrays
`O(n)`.  

Overall: **Time `O(n)`, Memory `O(n)`**, well within the limits.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    B = int(next(it))
    adj = [[] for _ in range(n)]
    edges = []
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
        edges.append((u, v))

    # 1. compute subtree sizes from an arbitrary root to get MIN
    parent = [-1] * n
    order = [0]
    parent[0] = -2
    for v in order:
        for to in adj[v]:
            if parent[to] == -1:
                parent[to] = v
                order.append(to)
    sub = [1] * n
    for v in reversed(order):
        for to in adj[v]:
            if to != parent[v]:
                sub[v] += sub[to]

    MIN = 0
    for u, v in edges:
        s = sub[u] if parent[v] == u else sub[v]
        MIN += min(s, n - s)

    if B < MIN:
        print("NO")
        return

    # 2. centroid decomposition and ordering
    removed = [False] * n
    answer = []

    from collections import deque

    def collect_component(start):
        comp = []
        dq = deque([start])
        removed[start] = True  # temporary mark to avoid revisiting
        while dq:
            v = dq.popleft()
            comp.append(v)
            for to in adj[v]:
                if not removed[to]:
                    removed[to] = True
                    dq.append(to)
        # unmark for later use
        for v in comp:
            removed[v] = False
        return comp

    def find_centroid(comp):
        sz = len(comp)
        # map vertex -> index in comp for fast lookup
        in_comp = set(comp)
        # compute sizes inside this component
        stack = [(comp[0], -1, 0)]  # (node, parent, state) state 0=first,1=post
        order = []
        while stack:
            v, p, state = stack.pop()
            if state == 0:
                stack.append((v, p, 1))
                for to in adj[v]:
                    if to != p and not removed[to] and to in in_comp:
                        stack.append((to, v, 0))
            else:
                order.append((v, p))
        subc = {}
        for v, p in order:
            cur = 1
            for to in adj[v]:
                if to != p and not removed[to] and to in in_comp:
                    cur += subc[to]
            subc[v] = cur

        centroid = None
        for v, p in order:
            max_part = sz - subc[v]  # part outside
            for to in adj[v]:
                if to != p and not removed[to] and to in in_comp:
                    max_part = max(max_part, subc[to])
            if max_part * 2 <= sz:
                centroid = v
                break
        return centroid

    sys.setrecursionlimit(1 << 25)

    def decompose(start):
        comp = collect_component(start)
        c = find_centroid(comp)
        removed[c] = True
        answer.append(c + 1)          # store 1‑based bay number
        for nb in adj[c]:
            if not removed[nb]:
                decompose(nb)

    decompose(0)

    print("YES")
    print(' '.join(map(str, answer)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input‑output format.
