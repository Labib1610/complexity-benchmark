Looking at this problem, we need to place a tree's nodes on positions 1..n such that the sum of |pos[u] - pos[v]| over all edges is ≤ B.

**Key insight:** The minimum possible total length for a tree on n nodes placed on a line is n-1 (achieved when the tree is a path placed consecutively). For a general tree, the minimum is achieved by a DFS-like layout where we recursively place subtrees in contiguous blocks.

**Minimum stretch formula:** For a tree, the minimum total stretch equals n-1. This is because:
- Each edge contributes at least 1 to the total
- We can achieve exactly n-1 by placing nodes so that each edge connects adjacent or nearby positions within contiguous subtree blocks

**Algorithm:** Root the tree at any node. Recursively assign positions: the root gets some position, and each subtree gets a contiguous block. Using a DFS preorder-like assignment where each subtree occupies consecutive positions, every edge has stretch equal to the size of the subtree below it minus... actually, let me think more carefully.

With a DFS layout: root at position p, first subtree in positions p+1..p+s1, etc. The edge to the first child has stretch 1, to the second child has stretch s1, to the third has stretch s1+s2, etc. Summing over all edges, each node (except root) contributes exactly 1 to the total (it's counted once as the "entry point" of its subtree block). So total = n-1.

Since minimum is n-1, if B ≥ n-1, answer YES with this layout. Otherwise NO.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    B = int(input_data[idx]); idx += 1
    
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        adj[u].append(v)
        adj[v].append(u)
    
    if B < n - 1:
        print("NO")
        return
    
    # DFS layout: assign positions so total stretch = n-1
    pos = [0] * (n + 1)
    visited = [False] * (n + 1)
    counter = [1]
    
    stack = [(1, 0)]  # (node, state) where state 0 = first visit
    while stack:
        node, state = stack.pop()
        if state == 0:
            visited[node] = True
            pos[node] = counter[0]
            counter[0] += 1
            # Push children in reverse order so they process left to right
            children = [c for c in adj[node] if not visited[c]]
            for c in reversed(children):
                stack.append((c, 0))
    
    print("YES")
    print(' '.join(str(pos[i]) for i in range(1, n + 1)))

solve()
```
