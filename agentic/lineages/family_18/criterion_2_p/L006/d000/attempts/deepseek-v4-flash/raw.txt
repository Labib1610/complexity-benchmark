 We need to assign workstations to slots such that the sum of edge lengths in the tree is at most B.  
This is essentially: given a tree, assign distinct integers 1..n to nodes to minimize the sum of |pos[u] - pos[v]| over all edges, and check if that minimum ≤ B.

This is a known problem: the minimum linear arrangement of a tree.  
We can solve it with a DFS + DP approach.

**Key idea**:  
For each edge, the number of times it is crossed is equal to `size_subtree * (n - size_subtree)`, where `size_subtree` is the number of nodes on one side of the edge.  
The minimum possible sum of edge lengths is achieved by placing nodes in DFS order (or any order that keeps each subtree contiguous).  
The minimal sum is:

\[
\text{min\_cost} = \sum_{\text{edges}} \text{size\_subtree} \times (n - \text{size\_subtree})
\]

If `min_cost > B`, output `NO`.  
Otherwise, output `YES` and any assignment that achieves this minimum (e.g., DFS order).

We can produce the assignment by doing a DFS and assigning slots in preorder.

Let's implement:

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, B = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    # Compute subtree sizes and min cost
    size = [0] * n
    min_cost = 0
    
    def dfs1(u, parent):
        nonlocal min_cost
        size[u] = 1
        for v in adj[u]:
            if v != parent:
                dfs1(v, u)
                size[u] += size[v]
                min_cost += size[v] * (n - size[v])
    
    dfs1(0, -1)
    
    if min_cost > B:
        print("NO")
        return
    
    # Assign slots via DFS preorder
    pos = [0] * n
    cur = 1
    def dfs2(u, parent):
        nonlocal cur
        pos[u] = cur
        cur += 1
        for v in adj[u]:
            if v != parent:
                dfs2(v, u)
    
    dfs2(0, -1)
    
    print("YES")
    print(" ".join(str(pos[i]) for i in range(n)))

if __name__ == "__main__":
    solve()
```
