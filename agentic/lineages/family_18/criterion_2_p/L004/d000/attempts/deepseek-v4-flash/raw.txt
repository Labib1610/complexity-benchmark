We can model the modules and cables as a tree.  
The problem asks if we can assign the nodes to positions 1..n such that the sum of edge lengths (absolute differences in positions) is ≤ B.

A key observation:  
For a tree, the minimum possible sum of edge lengths is achieved by placing nodes in a **DFS order** (or any order that keeps connected subtrees contiguous).  
The minimum total length is **n − 1** (when the tree is a path and we place nodes in order).  
But for a general tree, the minimum is achieved by a **contiguous ordering** of subtrees.

We can compute the minimum possible total length by a DFS that returns the size of each subtree, and then sum over edges the size of the smaller side.  
This is because each edge contributes the number of nodes on one side times the distance gap, and the minimum is achieved when each subtree is placed contiguously.

So:
1. Build adjacency list.
2. Compute subtree sizes via DFS.
3. For each edge (u, v), if we root the tree at 1, the contribution is `min(size[u], size[v])` if we consider the edge between parent and child.  
   Actually, the minimum total length is `sum(min(subtree_size, n - subtree_size))` over all edges.
4. If this minimum ≤ B, we can output YES and a valid ordering (DFS order works).
5. Otherwise, output NO.

Let’s implement this.  

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    n, m, B = map(int, sys.stdin.readline().split())
    adj = [[] for _ in range(n)]
    edges = []
    for _ in range(m):
        u, v = map(int, sys.stdin.readline().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
        edges.append((u, v))

    parent = [-1] * n
    order = []
    stack = [0]
    parent[0] = 0
    while stack:
        u = stack.pop()
        order.append(u)
        for v in adj[u]:
            if v == parent[u]:
                continue
            parent[v] = u
            stack.append(v)

    size = [1] * n
    for u in reversed(order):
        for v in adj[u]:
            if v == parent[u]:
                continue
            size[u] += size[v]

    min_cost = 0
    for u, v in edges:
        if parent[u] == v:
            min_cost += min(size[u], n - size[u])
        else:
            min_cost += min(size[v], n - size[v])

    if min_cost > B:
        print("NO")
        return

    # Build a valid ordering: DFS preorder
    pos = [0] * n
    order2 = []
    stack = [0]
    visited = [False] * n
    visited[0] = True
    while stack:
        u = stack.pop()
        order2.append(u)
        for v in adj[u]:
            if not visited[v]:
                visited[v] = True
                stack.append(v)

    for i, node in enumerate(order2):
        pos[node] = i + 1

    print("YES")
    print(" ".join(map(str, pos)))

if __name__ == "__main__":
    solve()
```
