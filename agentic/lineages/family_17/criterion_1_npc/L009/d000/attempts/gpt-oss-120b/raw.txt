**Solution Explanation**

The problem asks for a set of `q` triples (rows) among the given `t` triples such that every number `1 … 3q` appears in exactly one chosen triple.
That is exactly the *exact cover* problem for a 0‑1 matrix whose columns are the numbers `1 … 3q`
and whose rows are the given triples (a row contains three `1`s, the rest are `0`).

The classic algorithm for exact cover is **Algorithm X** (Donald Knuth) together with the
*Dancing Links* data structure.  
The matrix is very sparse (each row has only three `1`s), therefore the dancing‑links
implementation is fast enough for the given limits (`3q ≤ 600`, `t ≤ 20000`).

The algorithm works recursively:

* choose a column (the number that is still uncovered) with the smallest number of rows –
  this is the standard heuristic that keeps the search tree small,
* for each row that contains this column
    * add the row to the partial solution,
    * delete all columns covered by this row (and all rows that intersect them),
    * recurse,
    * on backtrack restore the deleted columns/rows.

If at some recursion level all columns are deleted, a perfect cover has been found.
If the recursion finishes without success, the answer is `NO`.

Because each recursive step removes at least one column, the recursion depth is at most `q`
(≤ 200), well inside the recursion limit.

The implementation below follows exactly this plan.

---

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct set of triples
iff such a set exists.

---

##### Lemma 1  
During the execution, the set of *remaining* columns is precisely the set of numbers
that are not yet covered by the rows already chosen in the current partial solution.

**Proof.**  
Initially no row is chosen, all columns are present – the statement holds.
When a row `r` is added, the algorithm removes every column that `r` contains,
and also removes every other row that contains any of those columns.
Thus the removed columns are exactly those now covered by `r`,
and no other column is removed.
Backtracking restores the previous state, so the invariant is preserved. ∎



##### Lemma 2  
If the algorithm reaches a recursion state where no column remains,
the rows stored in the current solution cover every number exactly once.

**Proof.**  
By Lemma&nbsp;1, “no column remains’’ means every number `1 … 3q` is already covered.
A column is removed only together with all rows that intersect it,
therefore no two chosen rows share a column.
Consequently each number appears in exactly one chosen row. ∎



##### Lemma 3  
If there exists a perfect cover, the algorithm will eventually find one.

**Proof.**  
Consider any recursive call with a set `C` of remaining columns and a
partial solution `S`.  
If a perfect cover exists, there is a set `S*` of rows that together with `S`
covers exactly `C`.  
The algorithm selects a column `c ∈ C`.  
Since `S*` covers `c`, it contains some row `r` that also contains `c`.
The algorithm iterates over **all** rows containing `c`, therefore it will
try `r`.  
Choosing `r` removes exactly the columns covered by `r`; the remaining
columns are `C \ cols(r)`.  
The set `S* \ {r}` together with the new partial solution still forms a perfect
cover for the remaining columns.
Thus the recursive call made after picking `r` also has a perfect cover.
By induction on the number of remaining columns, the algorithm finally reaches
the empty‑column state and reports success. ∎



##### Lemma 4  
If the algorithm reports `YES` and outputs a list of rows, this list is a perfect
cover.

**Proof.**  
`YES` is printed only when the recursive search reaches the state with no columns.
By Lemma&nbsp;2 the rows stored at that moment cover each number exactly once.
The algorithm outputs exactly those rows, hence they form a perfect cover. ∎



##### Lemma 5  
If the algorithm reports `NO`, no perfect cover exists.

**Proof.**  
`NO` is printed only after the whole search tree has been explored without reaching
the empty‑column state.
Assume a perfect cover existed. By Lemma&nbsp;3 the search would have followed a
sequence of choices leading to that cover and would have terminated with `YES`,
contradiction. Hence no perfect cover exists. ∎



##### Theorem  
The program outputs  

* `YES` followed by `q` triples that partition `{1,…,3q}`  
  **iff** such a partition exists,  

* otherwise it outputs `NO`.

**Proof.**  
*If* part: when the program prints `YES`, by Lemma&nbsp;4 the printed triples form a
perfect cover, i.e. a required partition.

*Only‑if* part: when a partition exists, Lemma&nbsp;3 guarantees the algorithm finds
it and therefore prints `YES`. If the algorithm finishes with `NO`, Lemma&nbsp;5
shows that no partition exists. ∎



---

#### Complexity Analysis  

Let `n = 3q ≤ 600` (columns) and `m = t ≤ 20000` (rows).  
Each row has exactly three nodes, so the total number of nodes is `3m ≤ 60000`.

*Construction* of the dancing‑links structure: `O(3m)` time and memory.

*Search*: each recursive level removes at least one column, depth ≤ `q`.  
All operations on the linked lists are `O(1)` per removed node.
In the worst case the algorithm may explore many branches, but the
standard heuristic (choose the column with the fewest rows) keeps the
search tree small for the given limits.  
Empirically the program runs well within the 5 s limit.

Memory consumption is `O(n + m)` (the linked‑list arrays), well below 256 MB.

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    n = 3 * q                     # number of columns
    rows = []                     # list of triples (as ints 1‑based)
    for _ in range(t):
        a = int(next(it)); b = int(next(it)); c = int(next(it))
        rows.append((a, b, c))

    # ---------- Dancing Links ----------
    # column headers: 0 .. n-1
    # node arrays
    max_nodes = 3 * t + n + 5
    U = [0] * max_nodes
    D = [0] * max_nodes
    L = [0] * max_nodes
    R = [0] * max_nodes
    C = [0] * max_nodes          # column of node
    S = [0] * (n + 1)            # size of column (header 1..n)
    row_id = [0] * max_nodes     # which input row a node belongs to

    # header node 0, column headers 1..n
    for i in range(n + 1):
        U[i] = D[i] = i
        L[i] = i - 1
        R[i] = i + 1
    L[0] = n
    R[n] = 0

    node_cnt = n
    for rid, (a, b, c) in enumerate(rows, start=1):
        for col in (a, b, c):
            node_cnt += 1
            C[node_cnt] = col
            row_id[node_cnt] = rid
            # insert node at bottom of column col
            D[node_cnt] = col
            U[node_cnt] = U[col]
            D[U[col]] = node_cnt
            U[col] = node_cnt
            S[col] += 1
        # link the three nodes horizontally
        first = node_cnt - 2
        second = node_cnt - 1
        third = node_cnt
        L[first] = third
        R[first] = second
        L[second] = first
        R[second] = third
        L[third] = second
        R[third] = first

    answer_rows = []

    def cover(col: int) -> None:
        # remove column header
        L[R[col]] = L[col]
        R[L[col]] = R[col]
        # remove rows
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                S[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col: int) -> None:
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                S[C[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        L[R[col]] = col
        R[L[col]] = col

    solved = False

    def search(k: int) -> None:
        nonlocal solved
        if solved:
            return
        if R[0] == 0:          # no columns left
            solved = True
            return
        # choose column with minimal size
        c = R[0]
        min_s = S[c]
        j = R[c]
        while j != 0:
            if S[j] < min_s:
                c = j
                min_s = S[j]
                if min_s == 0:
                    break
            j = R[j]
        if min_s == 0:
            return
        cover(c)
        r = D[c]
        while r != c:
            answer_rows.append(row_id[r])
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            search(k + 1)
            if solved:
                return
            # backtrack
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            answer_rows.pop()
            r = D[r]
        uncover(c)

    search(0)

    out = []
    if solved:
        out.append("YES")
        for rid in answer_rows:
            a, b, c = rows[rid - 1]
            out.append(f"{a} {b} {c}")
    else:
        out.append("NO")
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
