**Solution Explanation**

The problem asks for a set of `q` triples (cells) that together contain every number  
`1 … 3·q` exactly once.  
Each given triple may be used at most once.  
This is the classic *exact cover* problem for a 3‑uniform hypergraph.

The well‑known algorithm for exact cover is **Algorithm X** (Donald Knuth) together
with the **Dancing Links** data structure (DLX).  
It works efficiently for the given limits (`≤ 600` columns, `≤ 20000` rows).

--------------------------------------------------------------------

#### 1.   Modelling as Exact Cover
* **Columns** – one column for each operator `1 … 3·q`.  
  A column must be covered exactly once.
* **Rows** – one row for each pre‑cleared triple `{a,b,c}`.  
  The row contains the three columns `a, b, c`.

A solution of Algorithm X is a set of rows whose columns together are all
different and cover every column – exactly what we need.

--------------------------------------------------------------------

#### 2.   Dancing Links (DLX)

The structure consists of doubly linked lists:

```
column header  <->  node  <->  node  <-> … (all nodes belonging to this column)
row header     <->  node  <->  node  <-> … (all nodes belonging to this row)
```

Each node stores:
* `col` – pointer to its column header,
* `up, down, left, right` – the four neighbours,
* `row_id` – the index of the original triple (for output).

The column header also stores `size` – how many nodes are still present in the
column.

Operations needed:

* **cover(col)** – removes a column and all rows that contain it.
* **uncover(col)** – restores them (exact inverse).

Both are `O(number of removed nodes)` and are performed by pointer manipulation
only.

--------------------------------------------------------------------

#### 3.   Search (Algorithm X)

```
search():
    if no column left → all columns covered → success
    choose column c with minimal size (heuristic)
    cover(c)
    for each row r in column c:
        add r to current solution
        for each node j in row r (except the column c node):
            cover(j.col)
        if search() succeeds → propagate success
        for each node j in row r (reverse order):
            uncover(j.col)
        remove r from current solution
    uncover(c)
    return failure
```

Depth of recursion ≤ `q` (≤ 200), well inside the recursion limit.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct set of triples
iff such a set exists.

---

##### Lemma 1  
During the execution of `search`, the set of uncovered columns is exactly the
set of operators that are not yet assigned to any selected row.

**Proof.**  
Initially all columns are uncovered, no operator is assigned.  
`cover(col)` removes `col` and all rows containing `col`.  
Removing a row means that none of its three operators can be used later,
so those operators are considered already assigned (by the row that caused the
cover).  
Conversely, `uncover(col)` restores the column and all rows that were removed,
undoing the assignment. ∎



##### Lemma 2  
When `search` reaches the base case “no column left”, the rows stored in the
current solution form a collection of triples that covers every operator exactly
once.

**Proof.**  
By Lemma&nbsp;1, “no column left” means every column (operator) has been covered.
A column can be covered only by selecting a row that contains it, and each row
covers three distinct columns.  
Because a column is removed from the structure as soon as it is covered,
no later row can contain the same column. Hence each operator appears in exactly
one selected row. ∎



##### Lemma 3  
If a set of `q` triples covering all operators exists, `search` will eventually
find it.

**Proof.**  
Consider any fixed solution `S`.  
At each recursive level the algorithm chooses a column `c`.  
Since `S` covers all columns, `c` belongs to some row `r∈S`.  
Row `r` appears in the list of rows of column `c`; the algorithm iterates over
all those rows, therefore it will eventually try `r`.  
When `r` is chosen, the algorithm covers the other two columns of `r`.  
All rows of `S` that intersect those columns are removed, but the remaining rows
of `S` stay present because they are disjoint.  
Thus the recursive call works on a smaller exact‑cover instance that still has
a solution (`S \ {r}`). By induction on the number of remaining columns,
the recursion can reach the base case. ∎



##### Lemma 4  
If `search` reports failure, no exact‑cover solution exists.

**Proof.**  
`search` explores **all** possibilities: for the chosen column `c` it tries
every row containing `c`, and for each such row it recursively explores all
possibilities for the remaining columns.  
If none of those branches leads to the base case, then there is no way to
cover column `c` while also covering the rest, i.e. no solution exists for the
current instance. Since the initial call represents the original problem,
failure means the original problem has no solution. ∎



##### Theorem  
The program outputs  

* `YES` followed by `q` triples that partition `{1,…,3q}`  
  **iff** such a partition can be formed from the given list; otherwise it
  outputs `NO`.

**Proof.**  

*If the program prints `YES`*:  
It printed the rows stored when `search` reached the base case.
By Lemma&nbsp;2 these rows form a partition of all operators, therefore a valid
plan.

*If a valid plan exists*:  
By Lemma&nbsp;3 `search` will eventually find a solution, thus the program will
reach the base case and output `YES` with that solution.

*If the program prints `NO`*:  
That happens only when `search` returns failure. By Lemma&nbsp;4 no exact‑cover
solution exists, i.e. no required plan exists.

Hence the output is correct in all cases. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Let* `n = 3q ≤ 600` (columns) and `m = t ≤ 20000` (rows).

* Building the DLX structure: `O(3·m)` nodes → `O(m)`.
* Each recursive step covers a column and at most three rows per selected row.
  The total work over the whole search is proportional to the number of
  removed/added nodes, i.e. `O( (size of solution) · 3 ) = O(q·3) = O(q)`,
  plus the overhead of exploring dead branches.
* In the worst case the algorithm may explore many branches, but for the given
  limits DLX solves typical instances well within the 5 s limit (empirically
  fast for `n ≤ 600, m ≤ 20000`).

Memory consumption: one node per occurrence → `3·m ≤ 60000` nodes,
each node stores a few integers → well below the 256 MB limit.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    triples = []
    for _ in range(t):
        a = int(next(it)); b = int(next(it)); c = int(next(it))
        triples.append((a, b, c))

    n = 3 * q                     # number of columns
    # ---------- DLX structures ----------
    class Node:
        __slots__ = ('up', 'down', 'left', 'right', 'col', 'row_id')
        def __init__(self):
            self.up = self.down = self.left = self.right = self
            self.col = None
            self.row_id = -1

    # column headers: 0..n-1, plus a root header at index n
    size = [0] * (n + 1)
    col_head = [Node() for _ in range(n + 1)]
    root = col_head[n]
    # link column headers horizontally
    for i in range(n + 1):
        col_head[i].col = i
        col_head[i].up = col_head[i].down = col_head[i]
        col_head[i].left = col_head[i - 1] if i > 0 else root
        col_head[i].right = col_head[i + 1] if i < n else root
    root.left = col_head[n - 1]
    root.right = col_head[0]

    # add rows
    row_nodes = []   # one node per row (any of its three nodes) to retrieve row_id
    for rid, (a, b, c) in enumerate(triples):
        cols = (a - 1, b - 1, c - 1)   # zero‑based
        first = None
        prev = None
        for col in cols:
            node = Node()
            node.col = col
            node.row_id = rid
            # vertical link
            header = col_head[col]
            node.down = header
            node.up = header.up
            header.up.down = node
            header.up = node
            size[col] += 1
            # horizontal link
            if first is None:
                first = node
            else:
                node.left = prev
                prev.right = node
            prev = node
        # close the row circle
        first.left = prev
        prev.right = first
        row_nodes.append(first)

    # ---------- DLX operations ----------
    def cover(col):
        # remove column header
        col_head[col].right.left = col_head[col].left
        col_head[col].left.right = col_head[col].right
        # remove rows
        i = col_head[col].down
        while i != col_head[col]:
            j = i.right
            while j != i:
                j.down.up = j.up
                j.up.down = j.down
                size[j.col] -= 1
                j = j.right
            i = i.down

    def uncover(col):
        i = col_head[col].up
        while i != col_head[col]:
            j = i.left
            while j != i:
                size[j.col] += 1
                j.down.up = j
                j.up.down = j
                j = j.left
            i = i.up
        col_head[col].right.left = col_head[col]
        col_head[col].left.right = col_head[col]

    solution_rows = []

    # ---------- recursive search ----------
    def search():
        # if no columns left -> success
        if root.right == root:
            return True
        # choose column with minimal size
        c = root.right
        min_sz = size[c.col]
        col = c
        while c != root:
            if size[c.col] < min_sz:
                min_sz = size[c.col]
                col = c
                if min_sz == 0:
                    break
            c = c.right
        if min_sz == 0:
            return False
        col_idx = col.col
        cover(col_idx)
        r = col.down
        while r != col:
            solution_rows.append(r.row_id)
            # cover other columns of this row
            j = r.right
            while j != r:
                cover(j.col)
                j = j.right
            if search():
                return True
            # backtrack
            j = r.left
            while j != r:
                uncover(j.col)
                j = j.left
            solution_rows.pop()
            r = r.down
        uncover(col_idx)
        return False

    possible = search()
    out = []
    if possible:
        out.append("YES")
        for rid in solution_rows:
            a, b, c = triples[rid]
            out.append(f"{a} {b} {c}")
    else:
        out.append("NO")
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
