We can model this as an exact cover problem: we have 3q elements (operators) and t available triples (cells). We need to select q triples that cover all elements exactly once.

Since q ≤ 200, 3q ≤ 600, and t ≤ 20000, we can use a backtracking with bitmasks and pruning. We’ll represent each triple as a bitmask of 3 bits set. We’ll also precompute for each operator the list of triples containing it, to speed up the search.

We’ll use recursion with the following optimizations:
- Choose the operator with the fewest available triples (minimum remaining values heuristic).
- If any operator has zero available triples, backtrack.
- Use bitmasks for the covered set.

Here’s the implementation:

```python
import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    n = 3 * q
    triples = []
    for _ in range(t):
        a = int(next(it)) - 1
        b = int(next(it)) - 1
        c = int(next(it)) - 1
        mask = (1 << a) | (1 << b) | (1 << c)
        triples.append((mask, (a+1, b+1, c+1)))
    
    # For each operator, list of triple indices
    op_to_triples = [[] for _ in range(n)]
    for idx, (mask, _) in enumerate(triples):
        for i in range(n):
            if mask & (1 << i):
                op_to_triples[i].append(idx)
    
    # Precompute triple masks
    masks = [m for m, _ in triples]
    
    # We'll use recursion with bitmask of covered operators
    full_mask = (1 << n) - 1
    chosen = []
    
    # For pruning: if any operator has no available triple, fail
    # We'll maintain a set of available triple indices for each recursion step
    # But we can just check on the fly.
    
    # To speed up, we can sort triples by something? Not necessary.
    
    # We'll use a recursive function with current covered mask and available triple indices.
    # But maintaining available triple indices as a set is expensive.
    # Instead, we'll use the heuristic: pick the uncovered operator with fewest triples that don't overlap current covered.
    
    # We'll implement a recursive search with memoization? State is (covered_mask, remaining_triples) but too big.
    # So we'll do backtracking with pruning.
    
    # We'll keep a list of used triple indices.
    
    # To speed up, we can precompute for each operator the list of triples, and filter by checking overlap.
    
    # We'll implement a recursive function:
    # def dfs(covered):
    #   if covered == full_mask: return True
    #   find uncovered operator with min number of triples that don't overlap covered
    #   for each such triple, try it.
    
    # To find min, we need to iterate over all operators not in covered.
    # n <= 600, t <= 20000, so it's okay.
    
    # We'll also keep a list of chosen triple indices.
    
    sys.setrecursionlimit(1000000)
    
    def dfs(covered):
        if covered == full_mask:
            return True
        # Find best operator
        best_op = -1
        best_count = float('inf')
        # Iterate over all operators not covered
        # We can iterate over bits
        # But n=600, so we can loop
        for op in range(n):
            if not (covered >> op) & 1:
                cnt = 0
                # Count triples that contain op and don't overlap covered
                for idx in op_to_triples[op]:
                    if masks[idx] & covered == 0:
                        cnt += 1
                if cnt == 0:
                    return False
                if cnt < best_count:
                    best_count = cnt
                    best_op = op
                    if cnt == 1:
                        break
        # Now try triples for best_op
        for idx in op_to_triples[best_op]:
            if masks[idx] & covered == 0:
                chosen.append(idx)
                if dfs(covered | masks[idx]):
                    return True
                chosen.pop()
        return False
    
    if dfs(0):
        print("YES")
        for idx in chosen:
            print(*triples[idx][1])
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
