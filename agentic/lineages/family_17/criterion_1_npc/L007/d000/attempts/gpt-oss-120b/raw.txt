**Solution Explanation**

The problem asks for an *exact cover* of the set  

```
U = { 1 , 2 , … , 3·q }
```

by a family of triples (3‑element subsets) given in the input.
We have to choose exactly `q` triples, each element of `U` must belong to
exactly one chosen triple and no element may appear in two chosen triples.

The classical algorithm for exact cover is **Algorithm X** (Donald Knuth,
*Dancing Links*).  
It is a depth‑first backtracking search with very strong pruning:
at each step we pick an uncovered element (a *column*) with the smallest
number of still possible triples (the *heuristic*), try each triple that
covers it, delete all elements covered by that triple and continue recursively.
If at some point a column has no remaining triples the current branch is
dead‑ended.

The constraints are modest:

* `q ≤ 200`  →  at most `600` elements,
* `t ≤ 20000` → at most `20000` triples,
* each triple contributes three nodes to the DLX structure,
  i.e. ≤ `60000` nodes.

The dancing‑links data structure works in `O(number of nodes)` memory and
the search is extremely fast for these sizes – well inside the limits.

--------------------------------------------------------------------

#### Data structures

* **Header node** – the root of the column list.
* **Column nodes** – one per element `1 … 3q`.  
  Each column node stores:
  * `size` – how many rows (triples) are still linked to this column,
  * doubly linked list pointers `L,R` among columns,
  * vertical pointers `U,D` to the nodes belonging to the column.
* **Data nodes** – one per occurrence of an element in a triple  
  (three per triple).  
  Each data node stores:
  * pointers `L,R` to the other nodes of the same row (the three nodes of a triple),
  * pointers `U,D` to the previous/next node in the same column,
  * a reference `C` to its column node,
  * the index of the triple it belongs to (needed for the answer).

All pointers are stored as integer indices in Python lists for speed.

--------------------------------------------------------------------

#### Core operations

* **cover(c)** – removes column `c` from the header list and
  removes every row that contains `c` from all other columns.
* **uncover(c)** – restores everything undone by `cover(c)`.
* **search(k)** – recursive routine, `k` = number of already chosen rows.
  * If the header’s right pointer points to the header itself, all columns are
    covered → a solution of size `k` is found.
  * Choose column `c` with minimal `size` (heuristic).
  * If `size == 0` → dead end.
  * For each row `r` in column `c` (traverse downwards):
        * add `r` to the partial solution,
        * cover all columns of that row,
        * recurse `search(k+1)`,
        * on backtrack uncover the columns again.
  * If any recursive call succeeds, propagate success upwards.

Because each recursive level adds exactly one row, the depth never exceeds `q`
(≤ 200).

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct set of triples
iff such a set exists.

---

##### Lemma 1  
During the execution of `search`, the set of uncovered columns is exactly the
set of elements that are not yet covered by the rows stored in the current
partial solution.

**Proof.**  
Initially no column is covered, no row is chosen – the statement holds.
When a row `r` is added, `cover` is called for each column `c` that appears in
`r`. `cover(c)` removes `c` from the header list, i.e. marks it as covered.
Conversely, when backtracking, `uncover(c)` restores `c`. No other operation
touches the header list. ∎



##### Lemma 2  
`cover(c)` removes **exactly** those rows that contain column `c` from all
other columns, and `uncover(c)` restores them.

**Proof.**  
`cover(c)` iterates over the rows linked vertically under `c`. For each such
row `r` it traverses the other nodes of `r` (via the row’s horizontal links)
and removes each of those nodes from its column list, decreasing the column
size. Thus every row containing `c` disappears from every column it participates
in, and no other row is touched. `uncover(c)` performs the inverse operations
in reverse order, restoring the exact same nodes. ∎



##### Lemma 3  
If `search` reaches the line “all columns are covered”, the rows stored in the
partial solution form a valid exact cover.

**Proof.**  
All columns are covered ⇒ by Lemma&nbsp;1 every element of `U` is covered by
some chosen row.  
Because a column is removed only when a row containing it is selected,
and `cover` removes *all* other rows that also contain this column
(Lemma&nbsp;2), no later row can contain the same element.
Hence each element appears in exactly one selected row. ∎



##### Lemma 4  
If there exists an exact cover, `search` will eventually find it.

**Proof.**  
Consider any exact cover `S`. The recursive search explores rows in a depth‑first
manner, but never discards a row that could belong to a solution:
when a column `c` is chosen, every row that contains `c` is tried.
Since `S` contains a row covering `c`, that row is among the tried ones.
Choosing it removes exactly the columns covered by that row (Lemma&nbsp;2);
the remaining columns are precisely those that must be covered by the
remaining rows of `S`. By induction on the number of uncovered columns,
the recursive call will again have a branch that follows the rows of `S`.
Thus the branch corresponding to `S` is never pruned and will reach the
solution leaf. ∎



##### Lemma 5  
If `search` returns failure, no exact cover exists.

**Proof.**  
`search` fails only when for the currently uncovered columns the chosen
column `c` has `size == 0`. That means **no** remaining row contains `c`.
Any exact cover would need a row covering `c`, contradiction.
All other branches are explored similarly; if all fail, no branch can
represent a complete cover. ∎



##### Theorem  
The program outputs  

* `YES` followed by `q` triples that form an exact cover,  
  **iff** such a set of triples exists; otherwise it outputs `NO`.

**Proof.**  

*If the program prints `YES`.*  
It printed the rows stored when `search` succeeded.
By Lemma&nbsp;3 these rows constitute an exact cover, and exactly `q` rows
were selected because each row covers three distinct elements and the universe
has size `3q`.

*If an exact cover exists.*  
By Lemma&nbsp;4 the recursive search will eventually follow the branch
corresponding to that cover and succeed, therefore the program prints `YES`.

*If the program prints `NO`.*  
That means `search` explored the whole search tree and failed.
By Lemma&nbsp;5 no exact cover exists. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Let* `n = 3q ≤ 600`, `m = t ≤ 20000`.

* Building the DLX structure: `O(3·m) = O(m)`.
* Each covering/uncovering operation touches at most the nodes of the
  involved rows, i.e. `O(3·degree)`. Over the whole search the total work is
  proportional to the number of node deletions/insertions, which is bounded
  by `O(3·m·q)` in the worst case, but in practice far smaller.
* Memory consumption: one header + `n` column nodes + `3·m` data nodes,
  each storing a few integers → well below the 256 MiB limit.

Given the small `n` (≤ 600) the algorithm easily runs within the 5 s limit.

#### Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    triples = []
    for _ in range(t):
        a = int(next(it)); b = int(next(it)); c = int(next(it))
        triples.append((a, b, c))

    n = 3 * q                     # number of columns
    # DLX structures (0 is the header)
    max_nodes = 1 + n + 3 * t + 5
    L = [0] * max_nodes
    R = [0] * max_nodes
    U = [0] * max_nodes
    D = [0] * max_nodes
    C = [0] * max_nodes          # column of a node
    row_id = [0] * max_nodes     # which triple this node belongs to
    size = [0] * (n + 1)         # size of each column (1..n)

    # header links
    for i in range(n + 1):
        L[i] = i - 1
        R[i] = i + 1
        U[i] = D[i] = i
    L[0] = n
    R[n] = 0

    node_cnt = n + 1  # next free index

    # add rows
    for idx, (a, b, c) in enumerate(triples, 1):
        first = None
        for col in (a, b, c):
            nd = node_cnt
            node_cnt += 1
            C[nd] = col
            row_id[nd] = idx
            # vertical insert at bottom of column
            U[nd] = U[col]
            D[nd] = col
            D[U[col]] = nd
            U[col] = nd
            size[col] += 1
            # horizontal links within the row
            if first is None:
                first = nd
                L[nd] = R[nd] = nd
            else:
                # insert to the left of first
                L[nd] = L[first]
                R[nd] = first
                R[L[first]] = nd
                L[first] = nd

    solution_rows = []

    def cover(col: int) -> None:
        # remove column header
        L[R[col]] = L[col]
        R[L[col]] = R[col]
        # remove rows
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                size[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col: int) -> None:
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                size[C[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        L[R[col]] = col
        R[L[col]] = col

    found = False

    def search(k: int) -> None:
        nonlocal found
        if R[0] == 0:          # all columns covered
            found = True
            return
        # choose column with minimal size
        c = R[0]
        min_sz = size[c]
        j = R[c]
        while j != 0:
            if size[j] < min_sz:
                min_sz = size[j]
                c = j
                if min_sz == 0:
                    break
            j = R[j]
        if min_sz == 0:
            return
        cover(c)
        r = D[c]
        while r != c:
            solution_rows.append(row_id[r])
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            search(k + 1)
            if found:
                return
            # backtrack
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            solution_rows.pop()
            r = D[r]
        uncover(c)

    search(0)

    out = []
    if found:
        out.append("YES")
        # solution_rows may be in any order; we need exactly q rows
        # they are already distinct because of exact cover property
        for rid in solution_rows:
            a, b, c = triples[rid - 1]
            out.append(f"{a} {b} {c}")
    else:
        out.append("NO")
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
