We can model this as an exact cover problem: we have `3q` operators and a list of triples, and we need to select `q` triples that cover all operators exactly once.

Since `q` can be up to 200, the total number of operators is at most 600. The number of triples can be up to 20000. We can solve this with backtracking + pruning, or use Algorithm X (Dancing Links), but a simpler recursive backtracking with bitmasks will work because 600 bits fit in Python integers.

We’ll represent each triple as a bitmask of its three members. We’ll also precompute for each operator the list of triples containing it, to speed up the search.

Here’s the plan:

1. Read `q` and `t`.
2. Read all triples, convert each to a bitmask.
3. Use backtracking:
   - Keep track of which operators are already covered.
   - At each step, pick the first uncovered operator (smallest index).
   - Try each triple that contains that operator and doesn’t overlap with already covered ones.
   - Recurse.
4. If we find a full cover, output `YES` and the triples.
5. If no solution, output `NO`.

We’ll also add pruning: if at any point an uncovered operator has no available triple, backtrack.

Let’s write the code.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    q = int(next(it))
    t = int(next(it))
    
    triples = []
    for _ in range(t):
        a = int(next(it)) - 1
        b = int(next(it)) - 1
        c = int(next(it)) - 1
        mask = (1 << a) | (1 << b) | (1 << c)
        triples.append(mask)
    
    n = 3 * q
    full_mask = (1 << n) - 1
    
    # For each operator, list of triple indices containing it
    by_operator = [[] for _ in range(n)]
    for idx, mask in enumerate(triples):
        for i in range(n):
            if mask & (1 << i):
                by_operator[i].append(idx)
    
    chosen = []
    
    def backtrack(covered):
        if covered == full_mask:
            return True
        # find first uncovered operator
        # we can use bit trick: ~covered & full_mask gives uncovered bits
        uncovered = (~covered) & full_mask
        # get lowest set bit
        first = (uncovered & -uncovered).bit_length() - 1
        for idx in by_operator[first]:
            mask = triples[idx]
            if mask & covered:
                continue
            chosen.append(idx)
            if backtrack(covered | mask):
                return True
            chosen.pop()
        return False
    
    if backtrack(0):
        sys.stdout.write("YES\n")
        for idx in chosen:
            mask = triples[idx]
            # extract the three numbers
            nums = []
            for i in range(n):
                if mask & (1 << i):
                    nums.append(str(i + 1))
            sys.stdout.write(" ".join(nums) + "\n")
    else:
        sys.stdout.write("NO\n")

if __name__ == "__main__":
    solve()
```
