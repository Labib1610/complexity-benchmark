**Solution Explanation**

The problem asks for an exact cover of the set `{1,…,3q}` by triples taken from a given list.
It is a classic *exact cover* problem and can be solved efficiently with
Donald Knuth’s **Algorithm X** together with the **Dancing Links** data structure
(DLX).  
The universe has at most `3·200 = 600` elements, each row (triple) contains exactly
three elements and there are at most `20000` rows – well within the limits for DLX.

The algorithm works as follows  

* build a sparse matrix with one column for every operator (`1 … 3q`) and one
  row for every given triple; a `1` is placed at the three columns belonging to the
  triple;
* repeatedly choose a column with the smallest number of remaining rows,
  try each row that covers this column, recursively continue after
  removing all columns covered by that row;
* if all columns are removed we have found a solution (exactly `q` rows).

Because each recursive step removes at least one column, the recursion depth is
at most `q ≤ 200`. The total number of node operations is bounded by
`O(number_of_ones) = O(3·t) ≤ 60000`, easily fitting into the limits.

If the search finishes without covering all columns, the answer is `NO`.

The implementation below follows the standard DLX representation with four
integer arrays `L,R,U,D` (left, right, up, down links) and an array `C` that
stores the column of each node.  
Column headers also store the current size (`S[col]`) – the number of rows still
available in that column – which is used for the heuristic “choose the smallest
column”.

The program prints any found exact cover, one triple per line, in the order
they were selected during the search.

**Correctness Proof**

We prove that the algorithm outputs `YES` and a valid schedule iff such a
schedule exists.

*Lemma 1*  
During the execution, the set of columns that are still present corresponds
exactly to the operators that are not yet covered by the already selected rows.

*Proof.*  
Initially all columns are present, none are covered.  
When a row `r` is chosen, the algorithm removes every column `c` that has a `1`
in `r`. This corresponds to covering the operators of `r`. No other columns are
removed, and no column is ever added back. ∎



*Lemma 2*  
At any recursive call, the set of rows still present are precisely those rows
that do not contain any already covered operator.

*Proof.*  
When a row `r` is chosen, the algorithm removes **all** rows that intersect any
column removed together with that column (the inner loop over `i = D[col]`).
Thus any remaining row shares no element with already selected rows.
Conversely, rows that do not intersect removed columns are untouched. ∎



*Lemma 3* (Invariant)  
The partial solution stored in the recursion stack is always a set of pairwise
disjoint triples.

*Proof.*  
By Lemma&nbsp;2 each newly added row shares no column with previously chosen rows,
hence the triples are disjoint. ∎



*Lemma 4*  
If the algorithm reaches a state with no remaining columns, the collected
rows form a valid schedule covering every operator exactly once.

*Proof.*  
No columns left ⇒ by Lemma&nbsp;1 every operator is covered.
By Lemma&nbsp;3 the rows are disjoint, therefore each operator appears in exactly
one selected triple. ∎



*Lemma 5*  
If a valid schedule exists, the algorithm will eventually find one.

*Proof.*  
Consider any valid schedule `S`. At the first recursive step the algorithm
chooses some column `c`. Since `S` covers all columns, there is a row `r∈S`
containing `c`. The algorithm tries **all** rows covering `c`, therefore it
will eventually try `r`. After choosing `r`, by Lemma&nbsp;2 the remaining
rows of `S` are still present, and the remaining columns are exactly those not
covered by `r`. Repeating the argument inductively, the algorithm can follow the
rows of `S` down to the leaf where all columns are removed, where it will accept
the solution. ∎



*Lemma 6*  
If the algorithm outputs `NO`, no valid schedule exists.

*Proof.*  
`NO` is printed only after the exhaustive recursive search has backtracked from
every possible choice without ever reaching the “no columns left” state.
Assume a schedule existed. By Lemma&nbsp;5 the search would have found it,
contradiction. ∎



*Theorem*  
The program prints `YES` followed by a collection of `q` triples that partition
`{1,…,3q}` iff such a collection exists; otherwise it prints `NO`.

*Proof.*  
If the program prints `YES`, it did so after reaching a state with no columns,
hence by Lemma&nbsp;4 the printed triples form a valid schedule.  
If it prints `NO`, by Lemma&nbsp;6 no schedule exists. ∎



---

**Complexity Analysis**

Let `n = 3q ≤ 600` and `m = t ≤ 20000`.

* Building the structure: `O(3m)` nodes.
* Each recursive step removes at least one column, depth ≤ `q`.
* The total number of node deletions/insertions over the whole search is
  `O(3m)` (standard DLX bound).

Hence time complexity is `O(3m) = O(t)` in practice, well below the 5 s limit.
Memory consumption is `O(n + 3m) ≤ 600 + 60000` integers → far under 256 MB.

def solve():
    import sys
    sys.setrecursionlimit(10000)
    data = sys.stdin.read().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it)); t = int(next(it))
    n = 3 * q
    triples = [tuple(map(int, (next(it), next(it), next(it)))) for _ in range(t)]

    # DLX structures
    max_nodes = 1 + n + 3 * t
    L = [0] * max_nodes
    R = [0] * max_nodes
    U = [0] * max_nodes
    D = [0] * max_nodes
    C = [0] * max_nodes
    S = [0] * (n + 1)
    row_of = [0] * max_nodes

    header = 0
    for i in range(n + 1):
        L[i] = i - 1
        R[i] = i + 1
    L[0] = n
    R[n] = 0
    for i in range(1, n + 1):
        U[i] = D[i] = i

    node = n + 1
    first_in_row = []   # store first node index of each row
    for rid, (a, b, c) in enumerate(triples, start=1):
        cols = (a, b, c)
        first = None
        prev = None
        for col in cols:
            cur = node
            node += 1
            C[cur] = col
            row_of[cur] = rid
            # vertical insert
            U[cur] = U[col]
            D[cur] = col
            D[U[col]] = cur
            U[col] = cur
            S[col] += 1
            # horizontal insert
            if first is None:
                first = cur
                L[cur] = R[cur] = cur
            else:
                # insert cur to the left of first
                L[cur] = L[first]
                R[cur] = first
                R[L[first]] = cur
                L[first] = cur
        first_in_row.append(first)

    solution_rows = []

    def cover(col):
        # remove column header
        L[R[col]] = L[col]
        R[L[col]] = R[col]
        # remove rows
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                S[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col):
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                S[C[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        L[R[col]] = col
        R[L[col]] = col

    def search(k):
        if R[header] == header:   # all columns covered
            return True
        # choose column with minimal S
        c = R[header]
        min_s = S[c]
        col = c
        j = R[c]
        while j != header:
            if S[j] < min_s:
                min_s = S[j]
                col = j
                if min_s == 0:
                    break
            j = R[j]
        if min_s == 0:
            return False
        cover(col)
        r = D[col]
        while r != col:
            solution_rows.append(row_of[r])
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            if search(k + 1):
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            solution_rows.pop()
            r = D[r]
        uncover(col)
        return False

    ok = search(0)
    out = []
    if ok:
        out.append("YES")
        # retrieve triples in order of solution_rows
        for rid in solution_rows:
            a, b, c = triples[rid - 1]
            out.append(f"{a} {b} {c}")
    else:
        out.append("NO")
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
