**Solution Explanation**

The problem asks for a perfect matching in a bipartite graph  

* left side – controllers `1 … q`  
* right side – platforms `q+1 … 2q`  

Only the given `t` edges may be used.  
We have to decide whether a matching of size `q` exists and, if it does,
output one such matching.

The classic algorithm for maximum bipartite matching in `O(E·√V)` is
Hopcroft‑Karp.  
With `V = 2·q ≤ 2·10⁵` and `E ≤ 4·10⁵` it easily fits into the limits.



--------------------------------------------------------------------

#### Algorithm
```
read q, t
build adjacency list G[1…q]   // only from left to right (store right vertex id)

run Hopcroft‑Karp
    pairU[u] – matched right vertex of left u   (0 = free)
    pairV[v] – matched left vertex of right v   (0 = free)
    dist[u]  – BFS distance layer

    while BFS builds distance layers from all free left vertices:
          DFS tries to augment along edges respecting the layers
          each successful DFS increases the matching size

if matching size == q:
        print "YES"
        for each left u = 1 … q:
                print u, pairU[u]
else:
        print "NO"
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct set of channels
iff such a set exists.

---

##### Lemma 1  
During Hopcroft‑Karp, `pairU` and `pairV` always represent a matching
(i.e. no vertex appears in more than one edge).

**Proof.**  
Initially all pairs are `0` – empty matching.  
Both BFS and DFS never create a pair that conflicts with an existing one:
*When DFS adds an edge (u,v) it first checks that `pairV[v]` is either `0`
or can be recursively reassigned via an augmenting path; the recursion
removes the old edge before adding the new one. Hence each vertex is
incident to at most one stored edge.* ∎



##### Lemma 2  
Each BFS layer construction finds the length `L` of the shortest
augmenting path (if any) from a free left vertex to a free right vertex.

**Proof.**  
BFS starts from all free left vertices (distance 0) and follows only
edges that belong to the current matching in the direction right→left,
and non‑matching edges left→right. This is exactly the alternating‑path
graph used in the standard proof of Hopcroft‑Karp. The first time a free
right vertex is reached, the path length is minimal, because BFS explores
in increasing distance order. ∎



##### Lemma 3  
Each DFS phase finds a set of vertex‑disjoint augmenting paths,
all of length `L` (the minimal length from Lemma&nbsp;2), and augments
the matching along all of them.

**Proof.**  
DFS is only allowed to follow edges that respect the distance labels
(`dist[next] = dist[cur] + 1`). Therefore any discovered path has length
`L`. When a free right vertex is reached, the recursion unwinds,
flipping the matched/unmatched status of every edge on that path,
which augments the matching. Because after a successful augmentation the
right vertex becomes matched, subsequent DFS calls cannot reuse any
vertex of that path, guaranteeing vertex‑disjointness. ∎



##### Lemma 4  
After each outer iteration (BFS + all DFS calls) the size of the matching
increases by at least one, and no augmenting path shorter than the
previous `L` exists.

**Proof.**  
If BFS finds at least one free right vertex, there exists an augmenting
path of length `L`. Lemma&nbsp;3 augments along a maximal set of
vertex‑disjoint such paths, therefore the matching size grows.
Because all augmenting paths of length `< L` would have been discovered
in an earlier BFS layer, none remain. ∎



##### Lemma 5  
When the algorithm terminates, the matching is maximum.

**Proof.**  
Termination happens when BFS cannot reach any free right vertex, i.e.
no augmenting path exists. By the classic theorem of Berge, a matching
without augmenting paths is maximum. ∎



##### Lemma 6  
If the algorithm outputs `YES`, the printed edges form a perfect
matching (every vertex appears exactly once).

**Proof.**  
`YES` is printed only when the matching size equals `q`.  
By Lemma&nbsp;1 the stored edges are a matching, thus each left vertex is
matched to exactly one right vertex, and because there are `q` left
vertices, all `q` right vertices are also matched (otherwise the size
would be `< q`). Hence every of the `2q` modules participates exactly
once. ∎



##### Lemma 7  
If a perfect matching exists, the algorithm outputs `YES`.

**Proof.**  
A perfect matching has size `q`. Hopcroft‑Karp always finds a maximum
matching (Lemma&nbsp;5). Therefore the size it obtains is at least `q`,
but cannot exceed `q` (the left side size). Hence it equals `q` and the
algorithm prints `YES`. ∎



##### Theorem  
The program prints `YES` followed by a valid set of `q` channels
iff such a set exists; otherwise it prints `NO`.

**Proof.**  
*If* the program prints `YES`, by Lemma&nbsp;6 the printed edges are a
perfect matching, thus a valid configuration exists.  
*Only if* a valid configuration exists, Lemma&nbsp;7 guarantees the
algorithm finds a matching of size `q` and prints `YES`.  
If no perfect matching exists, the maximum size is `< q`; the program
therefore prints `NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*`BFS`* runs in `O(E)` time.  
*`DFS`* visits each edge at most once per outer iteration, also `O(E)`.  
The number of outer iterations is `O(√V)` for Hopcroft‑Karp.  

Total time: `O(E·√V) ≤ 4·10⁵·√(2·10⁵) ≈ 1.8·10⁸` operations, well within
2 seconds in Python with an efficient implementation.

Memory usage: adjacency list `O(E)`, plus a few arrays of size `O(V)`.  
Overall ≤ a few tens of MB, far below the 256 MB limit.

#### Reference Implementation  (Python 3)

```python
import sys
import collections

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    n_left = q
    n_right = q  # vertices q+1 .. 2q, we will index them 1..q as well
    G = [[] for _ in range(n_left + 1)]  # 1‑based left
    for _ in range(t):
        a = int(next(it))
        b = int(next(it)) - q          # map platform id to 1..q
        G[a].append(b)

    # Hopcroft‑Karp
    INF = 10 ** 9
    pairU = [0] * (n_left + 1)
    pairV = [0] * (n_right + 1)
    dist = [0] * (n_left + 1)

    def bfs() -> bool:
        qd = collections.deque()
        for u in range(1, n_left + 1):
            if pairU[u] == 0:
                dist[u] = 0
                qd.append(u)
            else:
                dist[u] = INF
        found = False
        while qd:
            u = qd.popleft()
            for v in G[u]:
                pu = pairV[v]
                if pu == 0:
                    found = True          # we can reach a free right vertex
                elif dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    qd.append(pu)
        return found

    sys.setrecursionlimit(1 << 25)
    def dfs(u: int) -> bool:
        for v in G[u]:
            pu = pairV[v]
            if pu == 0 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, n_left + 1):
            if pairU[u] == 0 and dfs(u):
                matching += 1

    out = []
    if matching == q:
        out.append(b"YES")
        for u in range(1, n_left + 1):
            v = pairU[u] + q          # restore original platform id
            out.append(f"{u} {v}".encode())
    else:
        out.append(b"NO")
    sys.stdout.buffer.write(b"\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input‑output format.
