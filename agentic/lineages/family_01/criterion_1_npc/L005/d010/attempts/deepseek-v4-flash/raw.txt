We can model this as a graph coloring problem with 3 colors, where each edge requires that the sum of the two frequencies is a perfect square.  

First, let’s check which pairs of packages are allowed:

- Package 1: 5409  
- Package 2: 5616  
- Package 3: 5200  

Sums:  
- 1+1 = 10818 → not square  
- 1+2 = 11025 → 105² = 11025 → allowed  
- 1+3 = 10609 → 103² = 10609 → allowed  
- 2+2 = 11232 → not square  
- 2+3 = 10816 → 104² = 10816 → allowed  
- 3+3 = 10400 → not square  

So allowed pairs: (1,2), (1,3), (2,3).  
That means **no two adjacent buoys can have the same package**.  

So the problem reduces to: can we 3-color the graph such that adjacent nodes have different colors?  
Since n ≤ 40, we can use backtracking with pruning.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    n = int(input_data[0])
    m = int(input_data[1])
    edges = []
    idx = 2
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(input_data[idx]) - 1
        v = int(input_data[idx+1]) - 1
        idx += 2
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    
    def backtrack(node):
        if node == n:
            return True
        # Try colors 1,2,3
        for c in (1,2,3):
            ok = True
            for nb in adj[node]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[node] = c
                if backtrack(node+1):
                    return True
                color[node] = -1
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(str(color[i]) for i in range(n)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
