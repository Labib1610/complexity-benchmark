# Problem A — The Tri-Position Lock

Time limit: 2 s
Memory limit: 256 MB

A mechanical vault is secured by a system of $n$ dials (numbered 1 through $n$). To disengage the lock, each dial must be set to a tension level of 1, 2, or 3.

The internal machinery includes $m$ rigid crossbars, each of which establishes a physical linkage between a specific pair of dials. These crossbars act as physical constraints by measuring the absolute difference between the tension levels of the two dials they link. If this difference evaluates to zero for any crossbar, the mechanism will bind and permanently jam the vault. You must find a configuration for all $n$ dials such that no crossbars bind.

The vault's primary access panel requires at least one dial to function, and its chassis is built around a standard 8-by-5 matrix of sockets, meaning the total number of dials $n$ will never exceed 40. The number of crossbars $m$ can range from none at all up to one for every possible unique pair among the installed dials.

If no such configuration exists, you must indicate that the vault cannot be opened. If multiple valid configurations exist, the system requires the sequence of tension levels that appears mathematically first when compared element-by-element from dial 1 upward. That is, if two valid sequences are compared and first differ at dial index $k$, the sequence with the lower tension level at dial $k$ is the required one.

## Input
The first line contains two integers $n$ and $m$ — the number of dials and the number of crossbars.
The following $m$ lines each contain two integers $u$ and $v$, representing the identifiers of two dials that are linked by a crossbar.

## Output
If the vault cannot be opened without jamming, output a single line with `NO`.
If a valid configuration exists, output `YES` on the first line. On the second line, output $n$ integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the tension level for each dial $i$. This sequence must be the valid configuration that meets the tie-breaking rule described above.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The numeric bounds for $n$ and $m$ were removed from the Input section and embedded into the problem description as physical constraints of the vault (an 8-by-5 matrix for $n$, and pairwise combinations for $m$). The equality constraint for the dials was also rephrased as an absolute difference evaluating to zero. This forces models to parse the scenario text to establish the exact constraints, rather than pattern-matching standard inequality notation.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that connected dials cannot share a value (their absolute difference cannot be zero) and the lexicographical tie-breaking rule remain logically identical, ensuring the exact same output for any input.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is still equivalent to finding the lexicographically smallest proper 3-coloring of a graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
The phrase "mathematically first when compared element-by-element" could be slightly less standard than "lexicographically smallest," though the explicit definition provided immediately after clarifies it unambiguously.
</RISK>
