# Factory Voltage Configuration

Time limit: 2 s   Memory limit: 256 MB

A manufacturing plant operates $n$ distinct industrial units, labeled from $1$ to $n$. Due to electrical resonance interference, certain pairs of units cannot operate at the same voltage level. There are $m$ such interfering pairs specified.

Each unit must be set to one of three available operating voltage levels: $1$, $2$, or $3$. If two units form an interfering pair, they must be configured with different voltage levels.

If at least one valid voltage configuration exists for all units, output `YES` along with the configuration $s_1, s_2, \dots, s_n$ that is lexicographically smallest. That is, if multiple valid voltage settings exist, choose the one that minimizes $s_1$; if there are still ties, minimize $s_2$, and so on. If no valid configuration exists, output `NO`.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le \frac{n(n-1)}{2}$) — the number of industrial units and the number of interfering pairs.
Each of the next $m$ lines contains two distinct integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that unit $u$ and unit $v$ interfere with each other.

## Output
If no valid voltage configuration exists, print `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1 \ s_2 \ \dots \ s_n$ ($s_i \in \{1, 2, 3\}$), representing the assigned voltage level for each unit from $1$ through $n$, such that $s_1, s_2, \dots, s_n$ is lexicographically smallest.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
