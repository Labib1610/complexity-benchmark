# Problem A — Harmonic Grid Calibration

Time limit: 2 s
Memory limit: 256 MB

A quantum communication grid is composed of $n$ active signal emitters, identified by integers from 1 up to $n$. The installation is physically constrained to a maximum of 40 emitter bays. 

During the initialization phase, every emitter must be calibrated with a specific tuning frequency. The available frequency parameters are exactly 1, 2, and 3.

The grid utilizes $m$ direct transmission conduits, which can range in quantity from 0 up to $n(n-1)/2$. Each conduit links exactly two distinct emitters. To maintain stability, the system continuously monitors a $2 \times 2$ interference matrix for every active conduit. 

For a conduit linking emitters $u$ and $v$, the interference matrix $M$ is constructed as follows (the order in which the two endpoints are assigned to $u$ and $v$ does not affect whether the determinant is zero):
- The first row is formed by adding the identifier $u$ to the assigned frequencies of both emitters, yielding $[p_u + u, p_v + u]$.
- The second row is formed by adding the identifier $v$ to the assigned frequencies of both emitters, yielding $[p_u + v, p_v + v]$.

There is a critical safety threshold: the determinant of this matrix $M$ must be strictly non-zero. If the determinant evaluates to zero on any conduit, a resonance cascade will occur. Your task is to find a frequency calibration for all $n$ emitters that avoids a cascade.

Should the grid be impossible to safely initialize, your program must report this failure. Given that multiple stable calibrations might exist, the system demands the lexicographically smallest sequence of frequencies. (A frequency sequence $A$ is lexicographically smaller than sequence $B$ if $A$ contains a lower frequency value at the first emitter index where the two sequences differ).

## Input
The first line provides two integers $n$ and $m$ (1 ≤ $n$ ≤ 40, 0 ≤ $m$ ≤ $n(n−1)/2$) — the number of active emitters and the number of active conduits.
The following $m$ lines each provide two integers $u$ and $v$ (1 ≤ $u, v$ ≤ $n$, $u \neq v$), indicating the identifiers of two emitters connected by a conduit.

## Output
If it is impossible to initialize the grid without causing a resonance cascade, output a single line containing `NO`.
If a valid calibration sequence exists, output `YES` on the first line. On the second line, output $n$ integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the assigned frequency for each emitter from 1 to $n$. This sequence must be the lexicographically smallest valid calibration.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

The divisibility condition was replaced with a $2 \times 2$ matrix determinant condition that incorporates the endpoint identifiers $u$ and $v$. This forces the model to either algebraically prove that the determinant simplifies to $(u-v)(p_v-p_u)$ (thus reducing back to $p_u \neq p_v$), or implement the matrix check directly, breaking the surface-level pattern match to standard graph coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The determinant of the matrix evaluates to $(u-v)(p_v-p_u)$; since $u \neq v$, this is zero if and only if $p_u = p_v$, meaning the valid frequency assignments remain exactly those of proper 3-colorings.
</PRESERVED_ANSWER>
