We need to assign each emitter a frequency from {1, 2, 3} such that for every edge (u, v), the determinant condition is satisfied.

The determinant of  
\[
\begin{pmatrix}
1 & p_u & p_u^2 \\
1 & p_v & p_v^2 \\
1 & 4 & 16
\end{pmatrix}
\]  
is zero when \(p_u\) or \(p_v\) equals 4, or when \(p_u = p_v\).  
Since frequencies are only 1, 2, 3, the only way the determinant is zero is if \(p_u = p_v\).

So the condition is: **No two connected emitters can have the same frequency.**

That means the graph must be 3-colorable, and we need the lexicographically smallest 3-coloring.

We can solve this with backtracking, trying colors 1, 2, 3 in order for each node, checking constraints.

Since \(n \leq 40\), backtracking with pruning is fine.

Here’s the implementation:

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n

def is_safe(node, c):
    for nb in adj[node]:
        if color[nb] == c:
            return False
    return True

def solve(idx):
    if idx == n:
        return True
    for c in range(1, 4):
        if is_safe(idx, c):
            color[idx] = c
            if solve(idx + 1):
                return True
            color[idx] = 0
    return False

if solve(0):
    print("YES")
    print(" ".join(map(str, color)))
else:
    print("NO")
```
