 We need to assign each node a shard ID from {1, 2, 3} such that for every given edge (u, v), the sum of their shard IDs squared is not divisible by the sum of their shard IDs.  

Let’s analyze the condition:  
For two shard IDs a and b (each in {1,2,3}), we need  
(a² + b²) % (a + b) != 0.  

Let’s check all possible pairs:  
- (1,1): (1+1)=2, (1+1)=2 → 2 % 2 = 0 → collision  
- (1,2): (1+4)=5, (1+2)=3 → 5 % 3 = 2 → OK  
- (1,3): (1+9)=10, (1+3)=4 → 10 % 4 = 2 → OK  
- (2,2): (4+4)=8, (2+2)=4 → 8 % 4 = 0 → collision  
- (2,3): (4+9)=13, (2+3)=5 → 13 % 5 = 3 → OK  
- (3,3): (9+9)=18, (3+3)=6 → 18 % 6 = 0 → collision  

So the only forbidden pairs are (1,1), (2,2), (3,3). That means:  
**No edge can connect two nodes with the same shard ID.**  

Thus the problem reduces to: Can we 3-color the graph such that no two adjacent nodes share the same color?  
That’s exactly the 3-coloring problem, which is NP-hard in general, but with n ≤ 40 we can use backtracking with pruning.

We’ll implement a backtracking search assigning colors 1,2,3 to nodes, checking constraints.

```python
n, m = map(int, input().split())
edges = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    edges[u].append(v)
    edges[v].append(u)

color = [-1] * n

def is_safe(node, c):
    for nb in edges[node]:
        if color[nb] == c:
            return False
    return True

def solve(node):
    if node == n:
        return True
    for c in range(1, 4):
        if is_safe(node, c):
            color[node] = c
            if solve(node + 1):
                return True
            color[node] = -1
    return False

if solve(0):
    print("YES")
    print(" ".join(str(c) for c in color))
else:
    print("NO")
```
