<METHOD_NAME>Asymmetric Congruence Masking</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the symmetric equality check (c_u != c_v) with an asymmetric algebraic condition (c_u + 2*c_v not divisible by 3) that is mathematically equivalent over the domain {1,2,3}. This breaks graph-coloring pattern matching and discourages standard undirected degree-ordered backtracking, while preserving the exact semantics.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Museum Curation

Time limit: 2 s
Memory limit: 256 MB

You are configuring a network of $n$ interactive installations for a museum exhibition. Every installation $i$ must be assigned exactly one frequency tier $c_i \in \{1, 2, 3\}$. 

Certain installations are connected by data links. You are given a list of $m$ such links. Each link connects a pair of installations. The input lists each link as a pair of integers $u$ and $v$, representing a connection from installation $u$ to installation $v$. 

To ensure the network operates without signal distortion, a specific algebraic rule must be satisfied across every link. For a link from $u$ to $v$, you must take the frequency tier assigned to $u$, and add twice the frequency tier assigned to $v$. The network is stable if and only if this resulting sum is not a multiple of 3. If the sum is a multiple of 3, the link fails and the assignment is invalid.

You must determine whether it is possible to assign a frequency tier to all $n$ installations such that this stability condition is strictly satisfied for all $m$ given links.

## Input
The first line contains two integers $n$ and $m$ — the number of installations and the number of links. The venue's floor plan consists of an $8 \times 5$ grid of individual display zones, and $n$ is at least 1 but cannot exceed the total number of these zones. The value of $m$ is at least 0 and at most the maximum possible number of unique pairs among the $n$ installations. No link connects an installation to itself, and no pair of installations is connected by more than one link.

Each of the subsequent $m$ lines contains two integers $u$ and $v$, representing a data link from installation $u$ to installation $v$. Installations are indexed from 1 to $n$.

## Output
If no such assignment is possible, output NO on a single line.
Otherwise, output YES on the first line. On the second line, output $n$ integers $c_1 \ c_2 \dots c_n$ (each being 1, 2, or 3), where $c_i$ is the frequency tier assigned to installation $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the symmetric "perfect square" product rule with an asymmetric algebraic condition: $c_u + 2c_v \not\equiv 0 \pmod 3$. This forces models to treat the problem as a generic constraint satisfaction problem rather than instantly recognizing it as undirected 3-coloring, which should prevent them from applying graph-specific heuristics like degree-ordered pruning. I also encoded the $N \le 40$ bound indirectly as an $8 \times 5$ grid.
</RATIONALE>
<PRESERVED_ANSWER>
For variables in $\{1, 2, 3\}$, the sum $c_u + 2c_v$ is a multiple of 3 if and only if $c_u = c_v$, making this condition mathematically perfectly equivalent to the seed's implicit $c_u \neq c_v$ constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Because the underlying constraint is equivalent to 3-coloring on a graph, the complexity class remains exactly NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "multiple of 3" as including 0, but since the minimum possible sum is $1 + 2(1) = 3$, the sum is always strictly positive, so 0 is practically impossible anyway.
</RISK>
