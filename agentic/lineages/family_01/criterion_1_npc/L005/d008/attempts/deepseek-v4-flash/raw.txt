We can model this as a constraint satisfaction problem.  
For each pair \((u, v)\), the condition is:

\[
(7 \cdot c_u + 13 \cdot c_v) \bmod 20 \neq 0
\]

Since \(c_u, c_v \in \{1,2,3\}\), we can precompute which pairs of shard IDs are allowed.

Let’s check:

- If \(c_u = 1\):  
  \(7 \cdot 1 = 7\)  
  Need \(7 + 13 c_v \not\equiv 0 \pmod{20}\)  
  → \(13 c_v \not\equiv 13 \pmod{20}\)  
  → \(c_v \neq 1\) (since \(13 \cdot 1 = 13\), \(13 \cdot 2 = 26 \equiv 6\), \(13 \cdot 3 = 39 \equiv 19\))  
  So if \(c_u=1\), \(c_v\) cannot be 1.

- If \(c_u = 2\):  
  \(7 \cdot 2 = 14\)  
  Need \(14 + 13 c_v \not\equiv 0\)  
  → \(13 c_v \not\equiv 6\)  
  → \(c_v \neq 2\) (since \(13\cdot 2 = 26 \equiv 6\))

- If \(c_u = 3\):  
  \(7 \cdot 3 = 21 \equiv 1\)  
  Need \(1 + 13 c_v \not\equiv 0\)  
  → \(13 c_v \not\equiv 19\)  
  → \(c_v \neq 3\) (since \(13\cdot 3 = 39 \equiv 19\))

So the rule is: **For every edge \((u,v)\), \(c_u \neq c_v\)**.  
That means the graph must be 3-colorable.

Since \(n \le 40\), we can use backtracking with pruning.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    colors = [0] * n
    
    def backtrack(node):
        if node == n:
            return True
        # Try colors 1,2,3
        for c in (1, 2, 3):
            ok = True
            for nb in adj[node]:
                if colors[nb] == c:
                    ok = False
                    break
            if ok:
                colors[node] = c
                if backtrack(node + 1):
                    return True
                colors[node] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, colors)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
