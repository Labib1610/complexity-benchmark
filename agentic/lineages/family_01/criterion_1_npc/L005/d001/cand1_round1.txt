# Problem A — Atmospheric Preservation

Time limit: 2 s
Memory limit: 256 MB

An archive is preparing $n$ historical documents for indefinite storage. Chemical analysis has found $m$ pairs of documents that have reactive ink compositions; if placed in the same atmospheric conditions, these pairs will deteriorate.

The archive relies on three specialized preservation vaults, labeled 1, 2, and 3. You must assign the documents based on these constraints:
- Each document must be placed in exactly one vault.
- No two reactive documents may share the same vault.

You must determine if such a storage plan can be created. If multiple valid storage plans exist, you must output the lexicographically smallest sequence of vault labels (comparing the assigned vault labels starting from document 1 up to document $n$).

## Input
The first line contains two integers $n$ and $m$ — the total number of documents and the number of reactive pairs ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
The next $m$ lines each contain two integers $u$ and $v$, indicating that document $u$ and document $v$ are reactive and cannot share a vault.

## Output
If it is impossible to safely store all documents, print NO on a single line.
Otherwise, print YES on the first line. On the second line, print $n$ integers $v_1 \ v_2 \dots v_n$ (where each $v_i \in \{1, 2, 3\}$), with $v_i$ being the vault assigned to document $i$. The sequence of $n$ vault labels must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I changed the acceptance criteria from allowing any valid arrangement to strictly requiring the lexicographically smallest valid sequence of vault labels. This forces models to abandon heuristics like descending-degree vertex ordering (which quickly finds an arbitrary valid coloring but not necessarily the lexicographically smallest) and instead implement an exact lexicographical backtracking search, matching the intended algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The reference solution already implements lexicographically-smallest backtracking over 3 colors to find its output, so its output remains perfectly correct and unchanged under this stricter requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 3-coloring of a graph, which is NP-complete; enforcing a specific tie-breaking rule (lexicographically smallest) on the output of an NP-complete problem restricts the solution space but preserves the underlying NP-completeness of the search.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "lexicographically smallest sequence" if they are unsure whether it applies to the vault labels ordered by document index or some other ordering, though the text explicitly clarifies "(comparing the assigned vault labels starting from document 1 up to document n)".
</RISK>
