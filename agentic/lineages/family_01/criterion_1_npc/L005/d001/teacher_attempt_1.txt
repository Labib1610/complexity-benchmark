# Problem A — Operational Band Configuration Protocol

Time limit: 2 s   Memory limit: 256 MB

A telecom routing pipeline is configuring channel allocations across a network of $n$ transmitter nodes, numbered $1$ through $n$.

Certain pairs of nodes suffer from mutual signal interference. There are $m$ such interfering pairs. If two nodes form an interfering pair, they cannot operate on the same channel.

Every node $i$ ($1 \le i \le n$) must be assigned an operational channel $s_i$ selected from the set $\{1, 2, 3\}$.

To ensure downstream system determinism, if multiple valid channel allocation sequences $s_1, s_2, \dots, s_n$ are possible, the system selects the sequence according to a strict priority rule: between any two distinct valid sequences, preference is given to the one that assigns a smaller channel number to the lowest-indexed node $i$ where the two assignments differ.

Determine whether a collision-free channel configuration exists, and if so, determine the preferred allocation sequence $s_1, s_2, \dots, s_n$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le \frac{n(n-1)}{2}$) — the number of transmitter nodes and the number of interfering pairs.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that node $u$ and node $v$ form an interfering pair.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1 \ s_2 \ \dots \ s_n$ ($s_i \in \{1, 2, 3\}$), representing the channel assigned to each node $i$. Among all valid assignments, output the one matching the priority rule.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I reworded the tie-breaking criterion to define lexicographical ordering operationally ("assigns a smaller channel number to the lowest-indexed node $i$ where the two assignments differ") without using the specific phrase "lexicographically smallest". This prevents models from immediately triggering a template search heuristic based on textbook phrasing while forcing them to explicitly deduce the backtrack search order from the formal preference rule.
</RATIONALE>
