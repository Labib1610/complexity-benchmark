# Problem A — Atmospheric Preservation

Time limit: 2 s   Memory limit: 256 MB

An archive is preparing $n$ historical documents for long-term storage. Through chemical analysis, researchers have found $m$ pairs of documents with reactive material compositions. If any such pair is stored in the same atmospheric environment, they will degrade.

The facility has exactly three climate-controlled vaults, designated by the codes 1, 2, and 3. The storage protocols dictate the following:
- Reactive pairs must never be placed in the same vault.
- Each of the $n$ documents must be placed in exactly one of the three vaults.

You need to determine if there is a way to assign the documents to the vaults without violating these protocols. If a safe assignment is possible, you must output one. To maintain a standardized cataloging system, if there are multiple safe assignments, you must choose the one that assigns the lowest possible vault codes to the documents in their indexed order. That is, the resulting sequence of vault codes $v_1, v_2, \dots, v_n$ must be the lexicographically smallest valid assignment.

## Input
The first line provides two integers $n$ and $m$ — the total number of documents and the number of reactive pairs ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
The following $m$ lines each contain two integers $u$ and $v$, representing a pair of documents that cannot share a vault.

## Output
If no safe assignment can be made, output NO on a single line.
If a safe assignment is possible, output YES on the first line. On the second line, output $n$ integers $v_1 \ v_2 \dots v_n$ (where each $v_i \in \{1, 2, 3\}$), representing the vault assigned to document $i$. The sequence of vault codes must be the lexicographically smallest among all valid assignments.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The affordance allowing "any valid arrangement" was removed and replaced with a strict requirement to output the lexicographically smallest valid assignment. This prevents models from using a greedy descending-degree heuristic to find an early feasible solution, forcing them to either search the full space or correctly backtrack in index order to guarantee the minimal sequence.
</RATIONALE>
<PRESERVED_ANSWER>
The intended algorithm is a standard backtracking search that naturally explores colors in numerical order across vertices in index order, meaning the reference solution already inherently produces the lexicographically smallest assignment.
</PRESERVED_ANSWER>

The core problem remains identical to 3-COLORING, which is NP-complete, and restricting the output to the lexicographically smallest valid coloring maintains this complexity.
