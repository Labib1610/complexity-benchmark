# Problem A — The Tri-Position Lock

Time limit: 2 s   Memory limit: 256 MB

You are attempting to open a complex mechanical vault. The locking mechanism consists of $n$ sequential dials, numbered 1 to $n$. Each dial must be rotated to lock into exactly one of three distinct states, indicated by the numbers 1, 2, and 3.

Inside the vault door, there are $m$ rigid crossbars. Each crossbar links a specific pair of dials. The physical constraint imposed by each crossbar is strict: the two dials it links must be set to different states. If any crossbar connects two dials that share the exact same state, the crossbar will seize and the lock will jam. The vault will only open if every dial is assigned a state such that no crossbar seizes.

You must determine a combination of states for all $n$ dials that successfully opens the vault, or report that the mechanism is permanently jammed.

## Input
The first line contains two integers $n$ and $m$ — the number of dials and the number of crossbars ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the identifiers of two dials linked by a crossbar. Dials are identified by integers from 1 to $n$.

## Output
If there is no combination of dial states that avoids jamming, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each $s_i \in \{1, 2, 3\}$), where $s_i$ is the state of dial $i$. Among all combinations that open the vault, you must output the one that is lexicographically smallest. (A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index where their states differ, sequence $A$ has a smaller state number than sequence $B$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
