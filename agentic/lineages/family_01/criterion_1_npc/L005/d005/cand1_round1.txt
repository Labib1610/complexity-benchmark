<STATEMENT>
# Problem A — Museum Curation

Time limit: 2 s   Memory limit: 256 MB

You are organizing a highly anticipated exhibition featuring $n$ interactive installations. The venue supports exactly three distinct frequency multipliers for the installations' audio elements, designated as 1, 2, and 3.

Every installation $i$ must be assigned exactly one frequency multiplier $c_i \in \{1, 2, 3\}$. However, certain pairs of installations interact. You have compiled a list of $m$ interacting pairs. 

To ensure the exhibition's acoustic stability, the frequencies must be balanced according to the interactive pairs. For any interacting pair of installations $(u, v)$, we define their *resonance check* based on the final frequency assignments of the entire exhibition:
- Let $X$ be the total number of installations (out of all $n$) whose assigned frequency multiplier is equal to $c_u$.
- Let $Y$ be the total number of installations (out of all $n$) whose assigned frequency multiplier is equal to $c_v$.
- Let $Z$ be the total number of installations (out of all $n$) whose assigned frequency multiplier is equal to $c_u$ or equal to $c_v$.

The pair $(u, v)$ is considered *acoustically stable* if and only if $Z = X + Y$.

You must determine whether it is possible to assign a frequency multiplier to all $n$ installations such that every given interacting pair is acoustically stable.

## Input
The first line contains two integers $n$ and $m$ — the number of installations and the number of interacting pairs ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$, representing an interacting pair of installations. Installations are indexed from 1 to $n$.

## Output
If no such assignment is possible, output NO on a single line.
Otherwise, output YES on the first line. On the second line, output $n$ integers $c_1 \ c_2 \dots c_n$ (each being 1, 2, or 3), where $c_i$ is the frequency multiplier assigned to installation $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The previous mathematical condition ($c_u^2 + c_u c_v + c_v^2 \not\equiv 0 \pmod 3$) allowed models to write simple local scripts to precompute the valid pairs of colors, instantly revealing the 3-coloring constraints. I replaced this with a global counting condition ($Z = X + Y$) that requires the entire assignment array to evaluate. Because the condition cannot be evaluated locally by a script, models must use symbolic mathematical deduction to prove it is equivalent to $c_u \neq c_v$, forcing genuine reasoning over simple code-based pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $Z = X + Y$ holds if and only if $c_u \neq c_v$, because the sets of installations assigned $c_u$ and $c_v$ are only disjoint when the multipliers are distinct (and neither set can be empty), making the valid assignments exactly the proper 3-colorings of the interaction graph.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Graph 3-Coloring, which is NP-complete, as the global constraint mathematically simplifies to requiring different colors for all adjacent vertices.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "equal to $c_u$ or equal to $c_v$" as a multiset sum rather than a set union (i.e., counting an item twice if $c_u = c_v$), though standard English phrasing implies a boolean predicate union.
</RISK>
