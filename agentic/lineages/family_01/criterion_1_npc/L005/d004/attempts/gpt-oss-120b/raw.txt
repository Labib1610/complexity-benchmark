**Solution Explanation**

For every edge the product of the two incident numbers must not be a perfect square.
The only perfect squares among the possible products are  

* `1·1 = 1`  
* `2·2 = 4`  
* `3·3 = 9`

Therefore the condition is exactly **“adjacent vertices must receive different numbers”**.
The task is to 3‑colour the given undirected graph and output the lexicographically
smallest colour sequence (colours are `1,2,3`).

`n ≤ 40`, so an exponential backtracking search is fast enough if we prune
early.  
We colour the vertices **in the natural order `1 … n`** – this guarantees that the
first found solution is the lexicographically smallest one, because at each
position we try the colours `1,2,3` in increasing order and never skip a feasible
colour.

During the search we keep for every vertex the set of colours already forbidden
by already coloured neighbours.  
If for the current vertex all three colours are forbidden, we backtrack
immediately.

The algorithm:

```
col[1…n] = 0                     # 0 = not coloured yet
forbidden[v] = 0 (bitmask)       # bit i set → colour i+1 is forbidden

def dfs(v):
    if v == n+1:                 # all vertices coloured
        return True
    for c in 1..3:
        if colour c not forbidden for v:
            col[v] = c
            # update neighbours
            changed = []
            for each neighbour u of v with col[u]==0:
                if not (forbidden[u] has bit c):
                    forbidden[u] |= bit(c)
                    changed.append(u)
            if dfs(v+1):
                return True
            # undo updates
            for u in changed:
                forbidden[u] &= ~bit(c)
            col[v] = 0
    return False
```

If `dfs(1)` succeeds we output the colours, otherwise `NO`.

The search tree size is at most `3^n`, but the pruning is very strong:
as soon as a vertex sees all three colours among its already coloured neighbours
the whole branch is cut. For `n = 40` this runs easily within the limits.

---

**Correctness Proof**

We prove that the algorithm outputs `YES` and the lexicographically smallest
valid colouring iff such a colouring exists.

*Lemma 1*  
During the execution, `forbidden[v]` contains exactly the colours used by already
coloured neighbours of `v`.

*Proof.*  
Initially no vertex is coloured, all masks are `0`.  
When we colour a vertex `v` with colour `c`, we iterate over all uncoloured
neighbours `u` and set the bit of `c` in `forbidden[u]`. No other bits are
changed. When we backtrack, we clear exactly the bits we set. Hence the invariant
holds at every recursive call. ∎



*Lemma 2*  
When the algorithm tries colour `c` for vertex `v`, `c` is allowed
(i.e. does not create a forbidden edge) **iff** `c` is not present in
`forbidden[v]`.

*Proof.*  
By Lemma&nbsp;1 `forbidden[v]` contains precisely the colours of coloured neighbours.
If `c` is in the mask, some neighbour already has colour `c`, so using `c` on `v`
would make an edge with equal colours – forbidden. Conversely, if `c` is not in
the mask, no neighbour has colour `c`, therefore all incident edges satisfy the
requirement. ∎



*Lemma 3*  
If the recursive call `dfs(v)` returns `True`, then the array `col[1…n]`
is a proper 3‑colouring of the whole graph.

*Proof.*  
Induction on `v`.  
Base `v = n+1`: all vertices are coloured, and by Lemma&nbsp;2 every coloured edge
connects vertices with different colours, so the colouring is proper.  
Induction step: `dfs(v)` returns `True` only after choosing a colour `c` for `v`
that is not forbidden (Lemma&nbsp;2) and after a recursive call `dfs(v+1)` that
by induction hypothesis yields a proper colouring of the remaining vertices.
Thus all edges incident to `v` are proper and together with the induction
hypothesis the whole graph is properly coloured. ∎



*Lemma 4*  
If a proper 3‑colouring exists, `dfs(1)` eventually returns `True`.

*Proof.*  
Consider any proper colouring `C`. The recursion explores colours for vertex `1`
in order `1,2,3`. Since `C[1]` is allowed (no coloured neighbours yet), the branch
choosing `C[1]` is taken. By Lemma&nbsp;1 the forbidden masks after this choice are
exactly those induced by `C[1]`. Repeating the argument for vertices `2,3,…`,
the recursion can follow the sequence of colours of `C`. Because `C` never
assigns a forbidden colour, the recursion never backtracks on this path and
reaches `v = n+1`, returning `True`. ∎



*Lemma 5*  
The first solution found by the algorithm is the lexicographically smallest
proper colouring.

*Proof.*  
The search processes vertices in increasing order and, for each vertex,
tries colours `1,2,3` in that order. Therefore the recursion explores all colour
sequences in lexicographic order. By Lemma&nbsp;4 the first sequence that is a
proper colouring is exactly the smallest one. ∎



*Theorem*  
The program outputs  

* `YES` and the lexicographically smallest proper colouring if such a colouring
  exists;
* `NO` otherwise.

*Proof.*  
If a proper colouring exists, Lemma&nbsp;4 guarantees `dfs(1)` returns `True`,
and by Lemma&nbsp;3 the stored `col` array is a proper colouring.
Lemma&nbsp;5 shows it is the lexicographically smallest, so the program prints
`YES` and this array.  
If no proper colouring exists, every branch eventually hits a vertex whose
three colours are forbidden, causing backtracking until the initial call fails.
Thus `dfs(1)` returns `False` and the program prints `NO`. ∎



---

**Complexity Analysis**

Let `b(v)` be the number of colours forbidden for vertex `v` when it is processed.
The algorithm explores at most `∏_{v=1}^{n} (3 - b(v))` nodes; each node processes
all neighbours of the current vertex, i.e. `O(m)` over the whole run.
In the worst case the bound is `3^n`, but for `n ≤ 40` and the strong pruning the
actual number of visited nodes is far smaller.  
Memory usage: adjacency list `O(n + m)`, colour array `O(n)`, masks `O(n)`,
recursion depth `O(n)`. All well within the limits.

**Reference Implementation (Python 3)**

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    col = [0] * (n + 1)          # 0 = uncoloured
    forbid = [0] * (n + 1)       # bitmask, bit 0 -> colour 1, etc.

    BIT = [1, 2, 4]              # 1<<0,1<<1,1<<2

    def dfs(v: int) -> bool:
        if v == n + 1:
            return True
        mask = forbid[v]
        for c in range(3):      # c = 0,1,2 corresponds to colour c+1
            if not (mask & BIT[c]):
                col[v] = c + 1
                changed = []
                bit = BIT[c]
                for nb in adj[v]:
                    if col[nb] == 0 and not (forbid[nb] & bit):
                        forbid[nb] |= bit
                        changed.append(nb)
                if dfs(v + 1):
                    return True
                # undo
                for nb in changed:
                    forbid[nb] &= ~bit
                col[v] = 0
        return False

    if dfs(1):
        out = ['YES', ' '.join(str(col[i]) for i in range(1, n + 1))]
        sys.stdout.write('\n'.join(out))
    else:
        sys.stdout.write('NO')

if __name__ == "__main__":
    solve()
```
