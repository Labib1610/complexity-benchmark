<METHOD_NAME>Algebraic Obfuscation of Equality</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces a direct inequality constraint (or bitwise XOR condition) with a mathematically equivalent algebraic property (such as the non-zero determinant of a symmetric 2x2 matrix). This prevents models from immediately mapping the problem to graph coloring via pattern matching, forcing them to either perform symbolic deduction or implement computationally expensive linear algebra checks within their search space.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<STATEMENT>
# Problem A — Tensor Configuration Protocol

Time limit: 2 s
Memory limit: 256 MB

A high-performance computing cluster consists of $n$ tensor processing units (TPUs), numbered 1 through $n$. The cluster can support up to 40 TPUs.

To initialize the cluster, each TPU must be assigned a discrete alignment scalar: 1, 2, or 3. 

The system enforces $m$ pairwise configuration constraints to prevent data collision. Each constraint specifies a pair of TPUs, $u$ and $v$, whose alignment scalars $s_u$ and $s_v$ must form a non-singular interaction matrix. Specifically, for every constraint between TPU $u$ and TPU $v$, the 2-by-2 matrix 
$$ \begin{pmatrix} s_u & s_v \\ s_v & s_u \end{pmatrix} $$
must have a non-zero determinant. You must determine an alignment scalar assignment for all $n$ TPUs that satisfies this condition for every constraint.

If no valid assignment is possible, you must indicate that the cluster cannot be initialized. If multiple valid assignments exist, the protocol requires you to select the one that is lexicographically smallest. (Assignment $A$ is lexicographically smaller than assignment $B$ if, at the lowest TPU index where they differ, $A$ has a lower alignment scalar than $B$).

## Input
The first line contains two integers $n$ and $m$ (1 ≤ $n$ ≤ 40, 0 ≤ $m$ ≤ $n(n−1)/2$) — the number of TPUs and the number of configuration constraints.
The following $m$ lines each contain two integers $u$ and $v$ (1 ≤ $u, v$ ≤ $n$, $u \neq v$), representing the identifiers of two TPUs involved in a configuration constraint.

## Output
If the cluster cannot be initialized, output a single line containing `NO`.
If a valid assignment exists, output `YES` on the first line. On the second line, output $n$ integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the alignment scalar for each TPU from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit bitwise XOR inequality constraint with a mathematically equivalent matrix determinant condition. I also shifted the domain from physical network routing (emitters/conduits) to abstract system configuration (TPUs/constraints). This forces the model to symbolically reduce the linear algebra constraint to a simple inequality to recognize the underlying graph coloring structure, preventing simple keyword matching from triggering standard graph algorithms.
</RATIONALE>
<PRESERVED_ANSWER>
The determinant of the 2-by-2 matrix is $s_u^2 - s_v^2$, which is non-zero for positive integers if and only if $s_u \neq s_v$; this is perfectly equivalent to the seed's $s_u \oplus s_v > 0$ condition, ensuring all valid assignments remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Lexicographically-First 3-Coloring on a general graph, which is NP-complete.
</PRESERVED_CLASS>
