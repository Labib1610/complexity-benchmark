We can model the problem as a graph coloring problem.  
The condition that \(I(u,v)\) is not a multiple of 3 restricts which frequencies can be adjacent.

Let’s check the possible pairs:

- \(p_u = 1, p_v = 1\): \(1+1+1=3\) → invalid  
- \(p_u = 1, p_v = 2\): \(1+2+4=7\) → valid  
- \(p_u = 1, p_v = 3\): \(1+3+9=13\) → valid  
- \(p_u = 2, p_v = 2\): \(4+4+4=12\) → invalid  
- \(p_u = 2, p_v = 3\): \(4+6+9=19\) → valid  
- \(p_u = 3, p_v = 3\): \(9+9+9=27\) → invalid  

So valid pairs are: (1,2), (1,3), (2,1), (2,3), (3,1), (3,2).  
That means:  
- 1 can connect to 2 or 3  
- 2 can connect to 1 or 3  
- 3 can connect to 1 or 2  

So the graph must be 3-colorable with no edge having the same color, and also no edge between 1 and 1, 2 and 2, 3 and 3.  
This is exactly a proper 3-coloring problem.

We also need the lexicographically smallest sequence in terms of the potential \(V_n\), which is equivalent to minimizing the base-4 number formed by the sequence \(p_1 p_2 \dots p_n\) (with digits 1,2,3).  
So we want the smallest possible sequence in lexicographic order.

We can do backtracking with pruning: assign frequencies from 1 to 3 in order, checking constraints, and pick the first complete assignment found.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    colors = [0] * n
    
    def is_valid(idx, c):
        for nb in adj[idx]:
            if colors[nb] == c:
                return False
        return True
    
    def backtrack(idx):
        if idx == n:
            return True
        for c in (1, 2, 3):
            if is_valid(idx, c):
                colors[idx] = c
                if backtrack(idx + 1):
                    return True
                colors[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, colors)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
