<STATEMENT>
# Problem A — Network Frequency Calibration

Time limit: 2 s
Memory limit: 256 MB

You are configuring a communication network consisting of $n$ nodes, numbered 1 through $n$. Each node must be assigned a frequency parameter $p_i$ chosen from the set $\{1, 2, 3\}$.

The network contains $m$ direct links. Each link connects two distinct nodes $u$ and $v$. To avoid interference, the overall network must satisfy a specific energy balance equation. Let $E$ be the total interference energy, defined as the sum of the squared differences of the frequencies over all $m$ links:
$$ E = \sum_{\text{all links } (u,v)} (p_u - p_v)^2 $$
Let $K$ be the number of links that connect a node assigned frequency 1 and a node assigned frequency 3.

A frequency assignment is valid if and only if it satisfies the equation:
$$ E = m + 3K $$

If it is impossible to find a valid assignment for the network, your program must report this failure. Given that multiple valid assignments might exist, you must output the lexicographically smallest sequence of frequencies. (A sequence $A$ is lexicographically smaller than sequence $B$ if $A$ contains a smaller value at the first index where the two sequences differ).

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of nodes and the number of links.
The following $m$ lines each provide two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating a link between node $u$ and node $v$.

## Output
If it is impossible to find a valid assignment for the network, output a single line containing `NO`.
If a valid assignment exists, output `YES` on the first line. On the second line, output $n$ integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the assigned frequency for each node from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
