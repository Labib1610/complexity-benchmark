# Problem A — Distributed Shard Routing

Time limit: 2 s   Memory limit: 256 MB

You are configuring a distributed database with $n$ storage nodes. To ensure stable load distribution, each node must be assigned to exactly one of 3 available data shards. The shards are identified by the integer IDs 1, 2, and 3.

You are given a list of $m$ high-frequency query patterns. Each pattern involves a specific pair of nodes $(u, v)$ that are frequently accessed together.

To prevent routing bottlenecks, the hash-based router evaluates these pairs using a subset-cardinality check. For any given high-frequency pair of nodes $(u, v)$, let $S_{u,v}$ be the set containing their assigned shard IDs, meaning $S_{u,v} = \{c_u, c_v\}$. A routing collision occurs if the cardinality of $S_{u,v}$ is exactly 1. 

To maintain system stability, you must assign a shard ID (1, 2, or 3) to each of the $n$ nodes such that strictly zero collisions occur among all $m$ given query patterns. This means every pair $(u, v)$ in the input must yield $|S_{u,v}| = 2$.

## Input
The first line contains two integers $n$ and $m$ — the number of storage nodes and the number of high-frequency query patterns ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$, representing a pair of nodes involved in a high-frequency query pattern. Nodes are indexed from 1 to $n$.

## Output
If no such assignment is possible, output NO on a single line.
Otherwise, output YES on the first line. On the second line, output $n$ integers $c_1 \ c_2 \dots c_n$ (each being 1, 2, or 3), where $c_i$ is the shard ID assigned to node $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
Removed the algebraic divisibility condition that allowed models to trivially build a static allowed-pair table by evaluating the formula. Replaced it with a direct set-theoretic rule (cardinality of the assigned IDs set must be 2), which forces the model to understand the constraint semantically rather than algebraically, while adhering strictly to the expert review's demand for a direct, non-derived rule.
</RATIONALE>
<PRESERVED_ANSWER>
The set {c_u, c_v} has a cardinality of 2 if and only if c_u != c_v, which is mathematically identical to the seed's condition for values in {1, 2, 3}, ensuring all valid assignments remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Graph 3-Coloring, preserving its NP-complete complexity.
</PRESERVED_CLASS>
