# Problem A — Harmonic Grid Calibration

Time limit: 2 s
Memory limit: 256 MB

A quantum communication grid is composed of $n$ active signal emitters, identified by integers from 1 up to $n$. The installation is physically constrained to a maximum capacity of emitter bays. This maximum capacity is exactly the number of individuals in a gathering where if every pair shakes hands exactly once, there would be exactly 780 handshakes.

During the initialization phase, every emitter must be calibrated with a specific tuning frequency. The available frequency parameters are exactly the positive integers strictly less than 4.

The grid utilizes $m$ direct transmission conduits, which can range in quantity from 0 up to the theoretical maximum where every distinct pair of the $n$ active emitters is connected by exactly one conduit. Each conduit links exactly two emitters. To maintain stability, there is a critical safety threshold: whenever two emitters $u$ and $v$ are linked by a conduit, their tuning frequencies $p_u$ and $p_v$ must satisfy the following modular resonance condition:
$$ (p_u \times p_v) \bmod 4 \ge 2 $$
If this condition evaluates to false on any conduit, a resonance cascade will occur. Your task is to find a frequency calibration for all $n$ emitters that avoids a cascade.

Each emitter $i$ (from $1$ to $n$) draws power from the grid based on its assigned frequency. The power draw of emitter $i$ is calculated as $E_i = p_i \cdot 4^{n-i}$. The total power draw of the grid is the sum of $E_i$ for all $i = 1, \dots, n$. 

Should the grid be impossible to safely initialize, your program must report this failure. Given that multiple stable calibrations might exist, the system demands the specific valid calibration that strictly minimizes the total power draw of the grid.

## Input
The first line provides two integers $n$ and $m$ — the number of active emitters and the number of active conduits. (You may assume $n$ is at least 1 and at most the maximum capacity derived above, and $m$ is within its valid range).
The following $m$ lines each provide two integers $u$ and $v$, indicating the identifiers of two distinct emitters connected by a conduit. It is guaranteed that $u$ and $v$ are valid active emitter identifiers.

## Output
If it is impossible to initialize the grid without causing a resonance cascade, output a single line containing `NO`.
If a valid calibration sequence exists, output `YES` on the first line. On the second line, output $n$ integers $p_1, p_2, \dots, p_n$, representing the assigned frequency for each emitter from 1 to $n$. This sequence must be the one that minimizes the total power draw as described.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The matrix determinant condition was replaced with the mathematically equivalent `(pu * pv) % 4 >= 2`, perfectly separating $pu \neq pv$ from $pu = pv$ for values in {1, 2, 3} while hiding the equality check. The lexicographical tie-breaker was replaced with minimizing a base-4 polynomial cost function, structurally baiting models into attempting dynamic programming or shortest-path algorithms instead of the required combinatorial backtracking. Numeric bounds were hidden via S07 using a handshake combination puzzle.
</RATIONALE>
<PRESERVED_ANSWER>
The modulo condition evaluates to false exactly when $p_u = p_v$ and true otherwise, preserving the valid states; minimizing the base-4 polynomial cost strictly enforces lexicographical order because the coefficients (1, 2, 3) are smaller than the base, heavily weighting earlier indices.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-coloring on a graph with up to 40 vertices, which is NP-complete.
</PRESERVED_CLASS>
