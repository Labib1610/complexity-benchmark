# Problem A — Phase Resonance Protocol

Time limit: 2 s
Memory limit: 256 MB

A quantum communication grid contains $n$ signal emitters, indexed from 1 up to $n$. Initializing this grid requires tuning each emitter to one of three discrete phase states: 1, 2, or 3.

The grid is wired with $m$ physical conduits, each bridging a specific pair of emitters. These conduits enforce a strict safety rule: any two emitters connected by a conduit must be tuned to different phase states. In other words, the absolute difference between their assigned states must be strictly greater than zero. If they share the same state, a resonance cascade will occur. Your task is to find a phase state configuration for all $n$ emitters that respects this rule across every conduit.

If no such configuration is possible, you must report that initialization cannot proceed. When multiple valid configurations exist, protocol dictates choosing the lexicographically smallest one. (A configuration $A$ is lexicographically smaller than $B$ if, at the lowest emitter index where their assigned states differ, $A$ uses a smaller phase state value than $B$.)

*Performance Note:* The supplied tests deliberately contain adversarial grid layouts at the maximum allowed $n$. These layouts are designed to force evaluation methods that assign states in a fixed numerical sequence (from 1 to $n$) to explore an overwhelming number of invalid partial combinations and exceed the time limit. Your approach must efficiently circumvent these structural traps to deduce the correct configuration.

## Input
The first line provides two integers $n$ and $m$ — the total number of emitters and the total number of conduits (1 ≤ $n$ ≤ 40, 0 ≤ $m$ ≤ $n(n−1)/2$).
The next $m$ lines each contain two integers $u$ and $v$ (1 ≤ $u, v$ ≤ $n$, $u \neq v$), identifying a pair of emitters bridged by a conduit.

## Output
If the grid cannot be initialized without triggering a resonance cascade, print a single line containing `NO`.
If a safe configuration exists, print `YES` on the first line. On the second line, print $n$ integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the phase state for each emitter from 1 to $n$. This sequence must be the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
