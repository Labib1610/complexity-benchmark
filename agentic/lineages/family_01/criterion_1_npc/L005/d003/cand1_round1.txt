# Problem A — Atmospheric Preservation

Time limit: 2 s   Memory limit: 256 MB

You are responsible for archiving historical artifacts in a secure facility. Through chemical analysis, you have identified pairs of artifacts that react poorly with each other; if placed in the same climate environment, they will degrade.

The facility contains exactly 40 secure containment bays, meaning the total number of artifacts $n$ is at least 1 and cannot exceed this capacity. The number of documented reactive pairs $m$ can range from zero up to the theoretical maximum where every artifact reacts with every other artifact.

The facility operates using exactly three distinct climate profiles, designated as Profile 1, Profile 2, and Profile 3. To ensure complete preservation:
- Every artifact must be allocated to exactly one of these three profiles.
- Artifacts that react poorly together must never share the same profile.

Please note that the test data deliberately includes adversarial reaction networks, featuring both solvable and unsolvable configurations. These networks are specifically engineered to trap allocation methods in an astronomical number of dead ends, particularly those that rely on processing items with the highest number of conflicts first, strategies that dynamically select the item with the fewest remaining valid profiles, techniques that track remaining options using parallel bitwise operations, or approaches that sequentially explore paths until the first valid configuration is found. You must determine if a safe allocation exists under these conditions. If it does, output a valid configuration.

## Input
The first line contains two integers $n$ and $m$ — the number of artifacts and the number of reactive pairs. The bounds for $n$ and $m$ are dictated by the facility capacities described above.
Each of the subsequent $m$ lines contains two integers $u$ and $v$, identifying a pair of artifacts that cannot be stored together.

## Output
If no safe allocation is possible, output NO on a single line.
Otherwise, output YES on the first line. On the second line, output $n$ integers $c_1 \ c_2 \dots c_n$ (each being 1, 2, or 3), where $c_i$ is the profile allocated to artifact $i$. If multiple safe allocations exist, providing any one of them is acceptable.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
