<STATEMENT>
# Problem A — HR Workflow Automation

Time limit: 2 s
Memory limit: 256 MB

A manufacturing plant is updating its employee onboarding workflow. The process is divided into several stages:

1. **Recruitment:** Human resources finalizes the hiring of $n$ employees. The employees are assigned IDs from $1$ to $n$. The facility's maximum onboarding capacity ensures there are no more than 40 new hires per cycle, and a cycle only runs if there is at least one hire.
2. **Vetting:** The security team reviews the new hires. They identify $m$ pairs of employees who have prior disputes. The number of such pairs can range from zero up to the maximum possible number of distinct pairs among the $n$ employees.
3. **Scheduling:** Operations must assign every employee a shift code. A shift code is an integer value from 1 to 3 inclusive. To maintain a secure environment, for any two employees who were flagged as a pair in the Vetting stage, the absolute difference between their assigned shift codes must be strictly greater than zero.
4. **Badge Generation:** The IT system requires a complete sequence of shift codes for employees $1$ through $n$. If there are multiple ways to assign shift codes that satisfy all security requirements, the system requires the sequence that is lexicographically smallest. If no such sequence can be formed, the system must be notified to halt the onboarding process.

Your task is to implement the software module that generates the shift codes.

## Input
The first line contains two integers $n$ and $m$ — the number of employees and the number of flagged pairs. The values of $n$ and $m$ are guaranteed to fall within the limits described in the Recruitment and Vetting stages.
Each of the next $m$ lines contains two integers $u$ and $v$ — representing a flagged pair of employees.

## Output
If the workflow must halt because no valid assignment is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2, 3\}$), representing the shift code of employee $i$. Output the lexicographically smallest sequence of shift codes (comparing $s_1$ first, then $s_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit variable bounds were removed from the Input section and embedded as physical constraints in the scenario description, forcing the model to read and comprehend the text to deduce limits (Strategy S07). Additionally, the core graph-coloring constraint "cannot be assigned to the same work period" was reframed as a numerical inequality ("absolute difference ... strictly greater than zero"). This prevents simple keyword matching to graph coloring while keeping the logical requirements mathematically identical.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the absolute difference between two integers is strictly greater than zero is mathematically equivalent to stating that the integers are not equal, preserving the exact same valid shift assignments and lexicographical tie-breaking as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically first valid 3-coloring of a graph, which is NP-complete, as the variables still take one of three distinct values and constrained pairs must be assigned different values.
</PRESERVED_CLASS>
<RISK>
The phrase "maximum possible number of distinct pairs" could theoretically be misunderstood if a reader forgets that pairs are unordered, but in context of $n$ employees, it standardly maps to $n(n-1)/2$.
</RISK>
