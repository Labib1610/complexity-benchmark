# Problem A — HR Workflow Automation

Time limit: 2 s   Memory limit: 256 MB

A manufacturing plant is deploying an automated system to assign workstation shifts. The process involves several steps:

First, a cohort of $n$ personnel is registered. The onboarding facility has a strict maximum capacity of 40 individuals, meaning the cohort size $n$ will be at least a single person and at most this facility limit. Each person receives a unique registration integer from $1$ up to $n$.

Second, a background screening system flags $m$ specific pairs of personnel who cannot be placed together due to past disputes. The total count of these flagged pairs, $m$, can range from none up to the theoretical maximum where every distinct pair of individuals in the cohort is flagged.

Third, the automated system must allocate exactly one shift code to each person. There are exactly three available shift codes, designated as 1, 2, and 3. To maintain workplace harmony, whenever two individuals are flagged as a disputed pair, they must be allocated different shift codes.

Finally, the system compiles the allocations into a single sequence of $n$ shift codes, ordered by the personnel registration integers from $1$ to $n$. To ensure the resulting database entry is strictly deterministic, if there is more than one way to validly allocate the shift codes, the system selects the sequence that appears earliest in standard dictionary order (comparing the first person's code, then the second's, and so on). If no valid allocation of shift codes is possible for the cohort, the system must trigger a halt sequence.

Your task is to write the module that processes the screening data and produces the required shift code sequence, or determines that a halt is necessary.

## Input
The first line contains two integers $n$ and $m$ — the cohort size and the number of flagged pairs. 
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that the personnel with these registration integers have a dispute and cannot receive the same shift code.

## Output
If no valid allocation can be found, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers (each being 1, 2, or 3) representing the shift codes allocated to the personnel, ordered from person $1$ to person $n$. This sequence must be the one that comes first in dictionary order among all valid allocations.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

I removed the explicit numeric inequality bounds from the Input section and instead embedded them within the scenario description (Strategy S07). The bounds are now expressed as a physical facility capacity and a theoretical maximum of distinct pairs, forcing the model to read and comprehend the scenario text to determine the constraints for its search algorithms. I also rephrased "lexicographically smallest" to "earliest in standard dictionary order" to disrupt superficial pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The required output is still the lexicographically first valid assignment of values 1, 2, and 3 such that no two conflicting individuals share a value, which exactly matches the seed problem's logic.
</PRESERVED_ANSWER>

The underlying computational task remains finding the lexicographically first valid 3-coloring of a graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
The phrase "theoretical maximum where every distinct pair of individuals in the cohort is flagged" could theoretically be misunderstood if a reader does not realize this equates to $n(n-1)/2$, though any competent programmer will recognize it as the maximum number of edges in a simple graph.
</RISK>
