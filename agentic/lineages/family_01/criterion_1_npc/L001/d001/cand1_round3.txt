# Problem A — Shift Scheduling

Time limit: 2 s   Memory limit: 256 MB

A production facility needs to assign its workers to three distinct daily shifts, numbered 1, 2, and 3. The workers are identified by integers from 1 to $n$. 

The safety department has compiled a list of incompatible worker pairs based on past incidents. If two workers are in an incompatible pair, they cannot be assigned to the same shift. 

You must find a valid shift assignment for all $n$ workers. If multiple valid assignments exist, you must output the lexicographically smallest sequence of shifts (comparing the shift of worker 1 first, then worker 2, and so on). If it is impossible to assign the workers without violating the safety rules, you must report that no valid assignment exists.

## Input
The first line provides $n$ and $m$, representing the total worker count and the number of incompatible pairs. The worker count $n$ is at least 1 and is capped by the facility's maximum equipment capacity of 40. The number of pairs $m$ can be as low as 0 and as high as the maximum possible number of unique pairs among the workers, $n(n-1)/2$.
Each of the following $m$ lines contains two integers $u$ and $v$, indicating that worker $u$ and worker $v$ are incompatible.

## Output
If no valid assignment exists, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2, 3\}$), representing the shift assigned to worker $i$. Among all valid assignments, output the lexicographically smallest sequence.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
