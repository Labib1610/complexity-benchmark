# Problem A — HR Workflow Automation

Time limit: 2 s   Memory limit: 256 MB

A manufacturing plant is updating its employee onboarding workflow, which consists of four sequential stages:

1. **Recruitment:** Human resources finalizes the hiring of $n$ employees, assigning each an index from $1$ to $n$.
2. **Vetting:** The security team conducts background checks and outputs a list of $m$ interference constraints. Each constraint specifies two indices $u$ and $v$.
3. **Scheduling:** The operations department must construct a shift configuration array $S$ of length $n$. Each element $S_i$ must be chosen from the set $\{1, 2, 3\}$. To satisfy the safety invariant, every interference constraint must be met: for each given constraint between indices $u$ and $v$, the absolute difference between their assigned values must be strictly greater than zero (i.e., $|S_u - S_v| > 0$).
4. **Badge Generation:** The IT department uses the array $S$ to generate access badges. To maintain a deterministic database, if multiple valid arrays can be constructed, the system mandates the array that is lexicographically smallest (comparing $S_1$ first, then $S_2$, and so on). If no valid array can be formed that satisfies all constraints, the HR system must be notified to halt the onboarding process.

Your task is to implement the software module that bridges Stage 2 and Stage 4. Given the number of employees and the $m$ interference constraints from Stage 2, you must determine the configuration array required for Stage 4, or determine that the workflow must be halted.

## Input
The first line contains two integers $n$ and $m$ — the number of employees from Stage 1 and the number of interference constraints from Stage 2 ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the next $m$ lines contains two integers $u$ and $v$ — representing a constraint between these two indices.

## Output
If the workflow must halt because no valid assignment is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $S_1, S_2, \dots, S_n$ (where each $S_i \in \{1, 2, 3\}$), representing the array values. Among all valid arrays, output the lexicographically smallest sequence (compare $S_1$ first, then $S_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
Replaced the "incompatible / different work periods" phrasing with an algebraic constraint ($|S_u - S_v| > 0$) on an integer array. This prevents models from immediately pattern-matching the problem to graph coloring and reflexively applying graph-specific optimizations like connected-component decomposition, forcing them to reason about the constraints structurally.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic constraint $|S_u - S_v| > 0$ for integers $S_i \in \{1, 2, 3\}$ is mathematically identical to $S_u \neq S_v$, preserving the exact same valid assignments and lexicographical tie-breaking behavior.
</PRESERVED_ANSWER>
