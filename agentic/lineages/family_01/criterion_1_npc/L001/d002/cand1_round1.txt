# Problem A — Hazardous Material Containment

Time limit: 2 s
Memory limit: 256 MB

A research facility is processing a collection of $n$ distinct hazardous materials, indexed from $1$ to $n$. To ensure site safety, the facility relies on three isolated containment chambers, designated as Chamber 1, Chamber 2, and Chamber 3. Every material must be deposited into exactly one of these three chambers.

The number of materials $n$ is at least 1. The maximum value of $n$ is strictly bounded by the capacity of the facility's transport vehicle, which is equipped with exactly 8 storage racks that each hold exactly 5 secure canisters. 

During initial testing, the safety team identified $m$ pairs of materials that are highly reactive with one another. The number of reactive pairs $m$ can be as low as 0, or as high as the total number of unique pairs that can be formed from the $n$ materials. If any two reactive materials are deposited into the same containment chamber, a catastrophic thermal event will occur. Consequently, such pairs must never share a chamber.

The automated storage system requires a manifest sequence to proceed. A valid manifest is an ordered list of $n$ integers, where the $i$-th integer indicates the chamber (1, 2, or 3) assigned to material $i$. To maintain a deterministic audit trail, if multiple safe manifests can be formed, the system mandates the manifest that is lexicographically smallest (comparing the chamber assignment for material 1 first, then material 2, and so forth). If no safe manifest exists, the system must trigger an abort protocol.

The safety-audit framework arranges material labels and reactive-pair instances adversarially. Specifically, the configurations are designed to maximize the number of partial manifests that appear valid but fail only when assigning the final few materials, deliberately exploiting systems that rely on fixed-index sequential assignment. Your solution must successfully process these cases within the time limit.

## Input
The first line contains two integers $n$ and $m$ — the number of hazardous materials and the number of reactive pairs.
Each of the next $m$ lines contains two integers $u$ and $v$ — representing a pair of materials that are reactive and cannot share a chamber.

## Output
If the abort protocol must be triggered because no safe manifest is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$), representing the chamber assigned to material $i$. Among all valid manifests, output the lexicographically smallest sequence.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
