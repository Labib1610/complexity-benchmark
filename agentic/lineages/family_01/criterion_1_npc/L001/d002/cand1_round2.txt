# Problem A — Hazardous Material Containment

Time limit: 2 s   Memory limit: 256 MB

A research facility is processing $n$ distinct hazardous materials, indexed from $1$ to $n$. To ensure site safety, the facility relies on three isolated containment chambers, designated as Chamber 1, Chamber 2, and Chamber 3. Every material must be deposited into exactly one of these three chambers.

During initial testing, the safety team identified $m$ pairs of materials that are highly reactive with one another. If any two reactive materials are deposited into the same containment chamber, a catastrophic thermal event will occur. Consequently, such pairs must never share a chamber.

The automated storage system requires a safe assignment to proceed. A valid assignment allocates each of the $n$ materials to one of the three chambers (1, 2, or 3). To maintain a deterministic audit trail, if multiple safe assignments can be formed, the system mandates the assignment that prioritizes placing lower-indexed materials into lower-numbered chambers. Specifically, you must find the valid assignment that minimizes the chamber number for material 1; if there are multiple such assignments, you must choose from them the one that minimizes the chamber number for material 2, and so forth up to material $n$. If no safe assignment exists, the system must trigger an abort protocol.

## Input
The first line contains two integers $n$ and $m$ — the number of hazardous materials and the number of reactive pairs. The facility has a strict maximum processing capacity of $40$ materials per cycle, so $1 \le n \le 40$. The number of reactive pairs ranges from none up to all possible pairs, meaning $0 \le m \le n(n-1)/2$.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$) — representing a pair of materials that are reactive and cannot share a chamber.

## Output
If the abort protocol must be triggered because no safe assignment is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$), representing the chamber assigned to material $i$. Among all valid assignments, output the one that is deterministically chosen as described above.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
