# Problem A — Acoustic Levitation Calibration

Time limit: 2 s   Memory limit: 256 MB

An acoustic levitation array consists of $n$ ultrasonic transducers, numbered $1$ to $n$. To manipulate delicate samples in mid-air, each transducer must be assigned a frequency band, represented by an integer. The power supply limits the available options to exactly the bands 1, 2, and 3.

The geometry of the levitation chamber creates $m$ distinct interference zones. Each zone receives direct emissions from exactly two specific transducers. If both contributing transducers are operating on the identical frequency band, the resulting acoustic resonance will destabilize and destroy the sample. A safe configuration ensures this never happens in any interference zone.

Your task is to determine a safe band assignment for all $n$ transducers. Because the array's controller firmware loads the configuration sequentially, it requires a deterministic setup: if there are multiple safe configurations, you must provide the one that is lexicographically smallest (comparing the band of transducer 1 first, then transducer 2, and so on). If there is no way to configure the transducers without causing destructive resonance in at least one interference zone, the calibration sequence must be aborted.

## Input
The first line contains two integers $n$ and $m$. The system requires at least 1 transducer, but cannot exceed the 40 independent hardware channels provided by the controller. The number of interference zones $m$ can be as low as 0, and reaches its physical maximum if every unique pair of transducers shares a zone.
Each of the next $m$ lines contains two integers $u$ and $v$, identifying the two distinct transducers that emit into a shared interference zone. Transducers are numbered starting from 1 up to $n$.

## Output
If the calibration must be aborted because no safe assignment is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$), representing the frequency band of transducer $i$. Among all valid assignments, output the lexicographically smallest sequence.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The explicit inequalities for the input bounds were removed and replaced with physical constraints describing the hardware's capacity and the geometric limits of the interference zones. The wording surrounding the color assignment was shifted from "phase modes" that must be "distinct" to "frequency bands" that cause resonance if they are "identical", forcing the model to infer the conflict-avoidance structure rather than pattern-matching standard graph coloring descriptions.
</RATIONALE>
<PRESERVED_ANSWER>
The problem still asks for an assignment of values 1, 2, or 3 to items such that no two items sharing a constraint have the same value, and breaks ties lexicographically, so the expected output sequence identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly lexicographically-first 3-coloring on a graph with max 40 vertices, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
The phrasing "reaches its physical maximum if every unique pair of transducers shares a zone" might be slightly misinterpreted if a model fails to recognize it implies exactly $m \le n(n-1)/2$, though the exact numeric limit is physically unambiguously defined.
</RISK>
