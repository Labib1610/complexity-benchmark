<STATEMENT>
# Problem A — Acoustic Levitation Calibration

Time limit: 2 s   Memory limit: 256 MB

An acoustic levitation platform contains $n$ emission channels, indexed from $1$ to $n$. Each channel must be tuned to exactly one of three available frequencies, denoted by the values 1, 2, and 3.

The geometry of the chamber produces $m$ focal points. Each focal point receives direct acoustic waves from exactly two specific channels. If both channels directed at a focal point are tuned to the same frequency, the resulting standing wave will shatter the sample. Thus, any two channels converging on a focal point must be assigned different frequencies.

The system controller loads the tuning parameters as a single sequence. To ensure deterministic behavior, if multiple safe tunings exist, you must select the one that minimizes the sequence's value when interpreted as an $n$-digit base-4 integer (where the frequency of channel 1 is the most significant digit and channel $n$ is the least significant). If no safe tuning avoids shattering the sample at all focal points, the process must be aborted.

## Input
The first line provides $n$ and $m$ — the number of channels and the number of focal points ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
The following $m$ lines each contain two integers $u$ and $v$, indicating that channel $u$ and channel $v$ converge on a shared focal point ($1 \le u, v \le n$, $u \neq v$).

## Output
If no safe tuning is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$), representing the frequency assigned to channel $i$. This sequence must represent the smallest possible base-4 value among all valid tunings.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the explicit "lexicographically smallest" tie-break rule with the mathematically equivalent requirement of minimizing the sequence's value when interpreted as a base-4 integer. This forces the model to reason about positional number systems to realize it can still use a greedy prefix search or backtracking, bypassing models that merely pattern-match the word "lexicographical" to trigger standard graph routines.
</RATIONALE>
<PRESERVED_ANSWER>
Minimizing the value of an $n$-digit number in a base strictly greater than its maximum digit (base 4 for digits 1, 2, 3) is mathematically identical to finding the lexicographically smallest sequence of those digits.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core constraints still map exactly to the NP-complete 3-coloring problem on a graph with up to 40 vertices.
</PRESERVED_CLASS>
<RISK>
A model might misread the output requirements and attempt to print the decimal value of the base-4 integer instead of the sequence of digits, although the Output section explicitly asks for the $n$ space-separated integers.
</RISK>
