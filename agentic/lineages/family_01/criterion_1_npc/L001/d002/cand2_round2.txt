# Problem A — Artifact Exhibition

Time limit: 2 s
Memory limit: 256 MB

A museum curator is preparing a gallery for $n$ historical items. The gallery features three distinct exhibition wings, numbered 1, 2, and 3. 

Due to historical sensitivities, specific pairs of items have conflicting backgrounds and must be kept separated. The curator's task is to assign each of the $n$ items to exactly one of the three exhibition wings in such a way that no two conflicting items end up in the same wing. It is not mandatory to populate all three wings; an arrangement that leaves one or more wings empty is permitted, provided all separation requirements are met.

## Input
The first line contains two integers $n$ and $m$ — the number of historical items and the number of separation requirements, respectively ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
The following $m$ lines each contain two integers $u$ and $v$, representing a pair of items that must be placed in different wings.

## Output
If it is impossible to satisfy all separation requirements, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $z_1, z_2, \dots, z_n$ (where each $z_i \in \{1, 2, 3\}$), with $z_i$ denoting the wing assignment for the $i$-th item. If multiple valid exhibition layouts exist, outputting any single valid layout is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
