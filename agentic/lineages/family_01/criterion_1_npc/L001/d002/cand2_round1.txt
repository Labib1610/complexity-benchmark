# Problem A — Infrastructure Migration

Time limit: 2 s   Memory limit: 256 MB

A cloud provider is migrating $n$ virtual machines (VMs), numbered $1$ through $n$, to a new regional infrastructure. The new region is divided into three physically isolated availability zones, designated as Zone 1, Zone 2, and Zone 3. Every VM must be deployed into exactly one of these three zones.

To guarantee high availability, the architecture team has identified $m$ pairs of VMs that host redundant microservices. If any two redundant VMs are deployed into the same availability zone, a single localized power failure could take down both instances, violating the service level agreement. Consequently, any two VMs forming a redundant pair must be placed in different zones.

The deployment engine accepts a configuration array of $n$ integers, where the $i$-th integer specifies the zone (1, 2, or 3) for VM $i$. To ensure reproducible provisioning, if multiple valid arrays exist, the engine evaluates them by comparing the assigned zone for VM 1, then VM 2, and so on. It strictly mandates the configuration array that features the smaller zone number at the earliest VM index where they differ. If no deployment satisfies all redundancy constraints, the migration must be aborted.

Your task is to generate the required configuration array or determine that the migration must be aborted.

## Input
The first line contains two integers $n$ and $m$ — the number of VMs and the number of redundant VM pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the following $m$ lines contains two integers $u$ and $v$ — indicating that VM $u$ and VM $v$ are a redundant pair and cannot share a zone.

## Output
If no valid configuration array is possible, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $z_1, z_2, \dots, z_n$ (where each $z_i \in \{1, 2, 3\}$), representing the zone assigned to VM $i$. This sequence must be the one that satisfies the deterministic provisioning rule described above.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
