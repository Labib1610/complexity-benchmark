# Problem A — Orbital Network Frequency Coordination

Time limit: 2 s   Memory limit: 256 MB

A telecommunications agency is configuring a network of $n$ satellite transmitters, numbered $1$ through $n$. Each transmitter must be assigned an operating band from the set $\{1, 2, 3\}$.

Geospatial analysis has identified $m$ pairs of transmitters with overlapping coverage areas. To prevent signal collision, any two transmitters in a listed pair must be assigned different operating bands.

A configuration is a sequence of $n$ band assignments, where the $i$-th value is the band assigned to transmitter $i$. The agency will only consider configurations that are completely free of signal collisions. If no such configuration exists, the setup is aborted.

If valid configurations do exist, the agency must deploy the single configuration that minimizes the network's total interference metric. 

The interference metric $M$ for a configuration is evaluated by analyzing the collective noise from all possible non-empty subsets of the $n$ transmitters. 
For each non-empty subset $S$, the primary source of noise is the transmitter in $S$ with the lowest ID (i.e., the minimum index among all transmitters in $S$). Let this primary transmitter be $k$. 
The interference generated by the subset $S$ is given by $b_k \times 3^{|S|-1}$, where $b_k$ is the band assigned to transmitter $k$, and $|S|$ is the total number of transmitters in the subset.

The final interference metric $M$ is the sum of the interference generated by all $2^n - 1$ non-empty subsets of transmitters.

## Input
The first line contains two integers $n$ and $m$ — the number of satellite transmitters and the number of overlapping coverage pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the next $m$ lines contains two integers $u$ and $v$ — representing a pair of transmitters that have overlapping coverage and must use different bands.

## Output
If no collision-free configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $b_1, b_2, \dots, b_n$ (where each $b_i \in \{1, 2, 3\}$), representing the band allocated to transmitter $i$. Output the configuration that minimizes the total interference metric.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
Replaced the explicit base-4 polynomial metric with an equivalent combinatorial sum over all non-empty subsets. This forces the model to mathematically simplify the sum over $2^n$ subsets to discover the $b_k 4^{n-k}$ coefficients via the binomial theorem. Without this reasoning step, the model cannot realize the objective is simply lexicographical minimization and will either TLE by evaluating subsets naively or fail to optimize correctly.
</RATIONALE>
<PRESERVED_ANSWER>
The total metric mathematically simplifies to exactly the same base-4 positional value $\sum b_k 4^{n-k}$ as the original problem, meaning the unique minimum remains the lexicographically smallest valid assignment.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem remains finding a valid 3-coloring of a graph, which is NP-complete, and the objective can still be optimized via the same polynomial-space backtracking.
</PRESERVED_CLASS>
