# Problem A — Orbital Network Frequency Coordination

Time limit: 2 s   Memory limit: 256 MB

An orbital telecommunications agency is deploying a constellation of $n$ satellite transmitters, indexed $1$ to $n$. Every transmitter requires a frequency band allocation chosen from $\{1, 2, 3\}$.

Due to spatial overlap, $m$ pairs of transmitters have intersecting broadcast footprints. To avoid destructive interference, any two transmitters sharing a footprint must operate on distinct frequency bands.

A deployment plan is defined as an ordered sequence of $n$ band choices, where the $i$-th element is the band given to transmitter $i$. The agency strictly requires a plan with zero footprint conflicts. If no such plan is possible, the mission is scrubbed.

When multiple conflict-free plans are possible, the agency selects the one that minimizes the network's structural interference score $S$. This score is calculated by modeling a virtual propagation graph based on the deployment plan:
1. The graph contains a root node $A$, a sink node $Z$, and $n$ intermediate relays $V_1, V_2, \dots, V_n$.
2. For each relay index $i$ from $1$ to $n-1$, there are exactly $4$ distinct directed edges from $V_i$ to $V_{i+1}$.
3. There is exactly $1$ directed edge from $V_n$ to $Z$.
4. For each index $i$ from $1$ to $n$, there are exactly $b_i$ distinct directed edges from $A$ to $V_i$, where $b_i$ is the band assigned to transmitter $i$.

The score $S$ is the total number of unique directed paths from $A$ to $Z$ in this graph. (Paths using different parallel edges between the same two nodes are counted as unique). The agency deploys the conflict-free plan with the absolute minimum score $S$.

## Input
The first line contains two integers $n$ and $m$ — the number of satellite transmitters and the number of intersecting footprint pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the next $m$ lines contains two integers $u$ and $v$ — representing a pair of transmitters that share a footprint and must use different bands.

## Output
If no conflict-free plan exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $b_1, b_2, \dots, b_n$ (where each $b_i \in \{1, 2, 3\}$), representing the band allocated to transmitter $i$ in the plan that minimizes the structural interference score.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The explicit telescoping sum that evaluated to a base-4 positional polynomial was replaced with a multigraph path-counting problem. This mathematically evaluates to the exact same polynomial, but forces models to either abstract the graph's path combinations mathematically or naively evaluate the objective on all valid configurations (which leads to a Time Limit Exceeded since they will no longer realize they can stop at the first valid lexicographical assignment).
</RATIONALE>
<PRESERVED_ANSWER>
The number of paths in the graph evaluates exactly to $\sum_{i=1}^n b_i 4^{n-i}$, which provides the same total order as lexicographical comparison, perfectly preserving the unique optimal assignment.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem remains finding the lexicographically first valid 3-coloring of a graph, which is NP-hard.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret how paths are counted in a multigraph, though standard graph theory conventions and the explicit parenthetical clarification make this unlikely.
</RISK>
