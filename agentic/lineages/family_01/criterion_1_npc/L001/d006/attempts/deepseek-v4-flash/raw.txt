We need to assign bands 1, 2, or 3 to each transmitter such that no two connected transmitters share the same band, and among all valid assignments, minimize the given metric.

The metric is:

For a sequence \( b_1, b_2, \dots, b_n \):

- \( C = 0 \), \( M = 0 \)
- For \( k = 1 \) to \( n \):
  - \( C += b_k \)
  - If \( k < n \): \( M += 3 \cdot C \cdot 4^{n-k-1} \)
- Finally \( M += C \)

We can rewrite this as:

\[
M = \sum_{k=1}^{n-1} 3 \cdot 4^{n-k-1} \cdot \left( \sum_{i=1}^k b_i \right) + \sum_{i=1}^n b_i
\]

This is a weighted sum of prefix sums. The weights are huge powers of 4, so the earlier positions have much larger weight. Specifically, the weight for \( b_i \) is:

For \( b_i \), it appears in all prefix sums for \( k \ge i \), so:

- For \( k = i \) to \( n-1 \): weight \( 3 \cdot 4^{n-k-1} \)
- Plus final \( +1 \) from the final \( C \).

So total coefficient for \( b_i \):

\[
w_i = 1 + \sum_{k=i}^{n-1} 3 \cdot 4^{n-k-1}
\]

Let \( j = n-k-1 \), then \( k = n-1-j \), \( j \) from 0 to \( n-1-i \):

\[
w_i = 1 + 3 \sum_{j=0}^{n-1-i} 4^j = 1 + 3 \cdot \frac{4^{n-i} - 1}{3} = 1 + (4^{n-i} - 1) = 4^{n-i}
\]

So:

\[
M = \sum_{i=1}^n b_i \cdot 4^{n-i}
\]

That’s a base-4 number with digits \( b_i \) (each 1,2,3). So minimizing \( M \) is equivalent to lexicographically minimizing the sequence \( b_1, b_2, \dots, b_n \) (since 4 is larger than any digit difference, earlier digits dominate).

Thus the problem reduces to: assign each vertex a color from {1,2,3} such that adjacent vertices have different colors, and the sequence \( b_1, b_2, \dots, b_n \) is lexicographically smallest.

This is a graph coloring problem with 3 colors, but we want the lexicographically smallest coloring.

Since \( n \le 40 \), we can do backtracking with pruning. We assign colors in order 1..n, trying smallest color first, and check constraints with already assigned neighbors. If we can color all vertices, we have the lexicographically smallest solution.

If at any point we cannot color a vertex with any of the 3 colors, we backtrack.

We also need to check if the graph is 3-colorable at all. If not, output NO.

Implementation:

- Read n, m.
- Build adjacency list.
- Use backtracking:
  - colors = [0]*n
  - recursive function assign(pos):
    - if pos == n: return True
    - for c in 1,2,3:
      - check all neighbors < pos: if colors[neighbor] == c, skip
      - set colors[pos] = c
      - if assign(pos+1): return True
      - reset colors[pos] = 0
    - return False
- If assign(0) returns True, print YES and colors.
- Else print NO.

This is fine for n=40 because 3-coloring is NP-hard in general, but with n=40 and m up to 780, backtracking might be heavy in worst case. However, the problem likely expects this approach because the lexicographic constraint forces early decisions, and the graph is small enough.

We can add some pruning: if a vertex has degree >= 3 and all its neighbors already colored with all 3 colors, then no color left. But the simple backtracking should pass for n=40 in most cases, especially since we try smallest color first.

Let's code it.

Edge case: m=0, then all can be 1, so output 1 1 ... 1.

Let's write the solution```python
import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n
    
    def backtrack(pos):
        if pos == n:
            return True
        # Try colors 1, 2, 3 in increasing order for lexicographic minimality
        for c in (1, 2, 3):
            ok = True
            for nb in adj[pos]:
                if nb < pos and color[nb] == c:
                    ok = False
                    break
            if ok:
                color[pos] = c
                if backtrack(pos + 1):
                    return True
                color[pos] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
