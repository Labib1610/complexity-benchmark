# Problem A — Orbital Network Frequency Coordination

Time limit: 2 s   Memory limit: 256 MB

An aerospace consortium is preparing the initialization profile for a network of orbital uplink stations, numbered $1$ through $n$. The number of stations, $n$, will not exceed 40 (the maximum payload capacity of the launch vehicle), and there is at least one station. Each station must be assigned a frequency value from the set $\{1, 2, 3\}$.

Spatial analysis has identified $m$ pairs of stations whose broadcast footprints intersect. The number of intersecting pairs $m$ can be anywhere from zero up to the maximum possible number of unique pairs between the deployed stations. For each listed pair, the two stations must receive different frequencies to avoid interference.

A complete profile is a sequence of $n$ frequencies, where the $i$-th value is the frequency allocated to station $i$. The consortium evaluates all interference-free profiles. If the set of valid profiles is empty, the deployment cannot proceed. 

Otherwise, the system must select the single valid profile that maximizes the network's efficiency score. The efficiency score $E$ of a profile is calculated exactly as:

$$ E = \sum_{i=1}^{n} (4 - f_i) \cdot W_i $$

where $f_i$ is the frequency allocated to station $i$. The weights $W_i$ are determined by their position in the sequence. For the final station, $W_n = 1$. If there are at least two stations, the second-to-last station has $W_{n-1} = 4$. For any station $i \le n-2$, its weight is given by the exact recurrence relation:

$$ W_i = 5 W_{i+1} - 4 W_{i+2} $$

## Input
The first line contains two integers $n$ and $m$ — the number of uplink stations and the number of intersecting footprint pairs.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — representing a pair of stations that have intersecting footprints and must use different frequencies.

## Output
If no interference-free profile exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $f_1, f_2, \dots, f_n$ (where each $f_i \in \{1, 2, 3\}$), representing the frequency allocated to station $i$. Output the profile that maximizes the efficiency score.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The seed's objective was a direct base-4 polynomial minimization, which trivially aligns with a greedy lexicographical search (trying colors 1, 2, 3 in order and stopping at the first valid assignment). I transformed the objective into a maximization problem using complementary values $(4 - f_i)$ and obfuscated the base-4 weights $4^{n-i}$ using the linear recurrence $W_i = 5 W_{i+1} - 4 W_{i+2}$. This breaks the naive monotonic pruning that accidentally makes minimization fast, forcing models that fail to recognize the mathematical equivalence to explore the entire search space and time out.
</RATIONALE>
<PRESERVED_ANSWER>
The recurrence $W_i = 5 W_{i+1} - 4 W_{i+2}$ with bases 1 and 4 resolves exactly to $W_i = 4^{n-i}$, and maximizing $\sum (4 - f_i) 4^{n-i}$ is algebraically identical to minimizing $\sum f_i 4^{n-i}$, ensuring the optimal frequency sequence is exactly the same for all inputs.
</PRESERVED_ANSWER>
