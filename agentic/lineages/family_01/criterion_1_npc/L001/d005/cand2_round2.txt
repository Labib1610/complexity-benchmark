<METHOD_DESCRIPTION>Instead of explicitly describing the lexicographical comparison which models easily map to "first solution found by index-ordered DFS", we define the tie-breaking rule as minimizing the scalar value $\sum_{i=1}^n t_i \cdot 4^{n-i}$. Because $t_i \in \{1, 2, 3\}$, this sum is strictly minimized by the lexicographically smallest sequence. Models that don't recognize this equivalence might try to find all valid assignments and evaluate the sum, which will TLE on $n=40$.</METHOD_DESCRIPTION>

# Problem A — Distributed Processing Array Configuration

Time limit: 2 s   Memory limit: 256 MB

A computing facility is configuring a distributed array of $n$ processing nodes, numbered $1$ through $n$. Each node must be assigned a tier level from the set $\{1, 2, 3\}$.

Because of shared memory bottlenecks, certain pairs of nodes cannot operate at the same tier. The facility has identified $m$ such pairs of nodes; for each identified pair, the two nodes must be assigned strictly different tier levels.

A complete configuration is a sequence $t_1, t_2, \dots, t_n$, where $t_i$ is the tier level assigned to node $i$. The facility will only accept a configuration if it satisfies all $m$ pair constraints. If no such configuration is possible, the array cannot be initialized.

If multiple valid configurations exist, the facility will select the single configuration that minimizes the structural metric $S$, defined as:
$$S = \sum_{i=1}^{n} t_i \cdot 4^{n-i}$$

Your task is to determine if a valid configuration exists, and if so, to output the sequence of tier levels for the configuration that minimizes $S$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of processing nodes and the number of constrained pairs.
Each of the next $m$ lines contains two integers $u$ and $v$ — representing a pair of nodes that share a memory bottleneck and must receive different tier levels.

## Output
If no valid configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $t_1, t_2, \dots, t_n$ (where each $t_i \in \{1, 2, 3\}$), representing the tier level assigned to each node in the configuration that minimizes $S$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit "lexicographically smallest" tie-break text with a mathematically equivalent scalar objective function $S = \sum t_i \cdot 4^{n-i}$. This forces the model to realize that since $t_i \in \{1, 2, 3\}$, minimizing $S$ is strictly equivalent to finding the lexicographically smallest assignment. Models that fail this algebraic reasoning step will likely attempt to compute $S$ for all valid configurations, resulting in a Time Limit Exceeded error given $n=40$.
</RATIONALE>
<PRESERVED_ANSWER>
The scalar metric $S$ is a base-4 polynomial evaluation; because the maximum digit is $3 < 4$, the sum is strictly minimized by the lexicographically smallest sequence of digits, leaving the target output identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a valid 3-coloring of a graph with maximum degree constraints, which remains NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might encounter precision issues if they attempt to compute $S$ using floating-point types, though this is a natural consequence of choosing the wrong algorithm rather than an ambiguity in the text.
</RISK>
