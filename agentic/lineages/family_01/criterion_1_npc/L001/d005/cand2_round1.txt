# Problem A — Resonant Energy Minimization

Time limit: 2 s   Memory limit: 256 MB

An experimental reactor contains $n$ containment cells, numbered $1$ through $n$. Each cell must be tuned to one of three distinct quantum states, which correspond to energy coefficients of $1, 2,$ or $3$.

Due to spatial proximity, certain pairs of cells exhibit resonant interference. Spatial analysis has identified $m$ such pairs. For each identified pair, the two cells must be tuned to different energy coefficients to prevent a cascade failure.

A complete tuning profile is a sequence of $n$ coefficients, where the $i$-th value is the coefficient allocated to cell $i$. The system evaluates all interference-free profiles. If the set of valid profiles is empty, the reactor cannot be activated.

Otherwise, the system must select the single valid profile that minimizes the reactor's asymmetric energy signature $E$, which is calculated exactly as the infinite-precision sum:
$E = \sum_{i=1}^n f_i \cdot 4^{-i}$
where $f_i \in \{1, 2, 3\}$ is the energy coefficient of cell $i$. 

The evaluation data includes dense topologies designed to maximize the state space explored by sequential index-based assignments.

## Input
The first line contains two integers $n$ and $m$. The number of cells $n$ is at least 1 and will not exceed the central angle, in degrees, of a regular nonagon. The number of interference pairs $m$ ranges from $0$ up to the maximum possible number of distinct pairs among the $n$ cells.
Each of the next $m$ lines contains two integers $u$ and $v$ — representing a pair of cells that have resonant interference and must use different coefficients.

## Output
If no interference-free profile exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $f_1, f_2, \dots, f_n$ (where each $f_i \in \{1, 2, 3\}$), representing the energy coefficient allocated to cell $i$. Output the profile that strictly minimizes the energy signature $E$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
