**Solution Explanation**

For every transmitter we have to choose a band `1 … 3`.
For each given pair `(u , v)` the two transmitters must obtain different
bands – the problem is exactly a *3‑colouring* of an undirected graph.

Among all proper colourings we need the **lexicographically smallest**
one, i.e. the smallest possible colour for transmitter 1,
if several colourings have that, the smallest possible colour for
transmitter 2, and so on.

`n ≤ 40`, therefore a depth‑first search that tries the colours
`1,2,3` in this order for the transmitters `1 … n`
is fast enough when we prune impossible partial assignments.



--------------------------------------------------------------------

#### 1.   Data structures
* `adj[i]` – list of neighbours of vertex `i` (0‑based indices).
* `col[i]` – current colour of vertex `i` (`0` = not coloured yet).

--------------------------------------------------------------------

#### 2.   Feasibility test for a partial assignment  

When we have already coloured vertices `0 … idx`,
vertex `v > idx` can still be coloured **iff**
not all three colours are already used by its coloured neighbours.
The test is performed in `future_ok(idx)` :

```
for every v > idx
        forbidden = colours already used by neighbours of v (only neighbours ≤ idx)
        if forbidden == {1,2,3} :   # all three colours blocked
                return False
return True
```

If the test fails we backtrack immediately – this is a classic
*forward checking* pruning and cuts huge parts of the search tree.

--------------------------------------------------------------------

#### 3.   Depth‑first search (lexicographic order)

```
dfs(idx):
        if idx == n:                # all vertices coloured
                return True
        # colours already forbidden for idx by coloured neighbours
        forbidden = set()
        for each neighbour u of idx with col[u] != 0:
                forbidden.add(col[u])

        for colour in 1,2,3 (in this order):
                if colour not in forbidden:
                        col[idx] = colour
                        if future_ok(idx) and dfs(idx+1):
                                return True
                        col[idx] = 0          # undo
        return False
```

Because colours are tried `1 → 2 → 3` and vertices are processed
`0 → 1 → … → n‑1`, the first complete solution found is exactly the
lexicographically smallest one.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `NO` iff the graph is not 3‑colourable,
otherwise it prints `YES` and the lexicographically smallest proper
colouring.

---

##### Lemma 1  
During the execution of `dfs(idx)` the array `col` is a proper partial
colouring of the vertices `0 … idx‑1`.

**Proof.**  
Initially all entries are `0` – a proper partial colouring.
When `dfs` assigns a colour to vertex `idx` it first checks that this
colour is not used by any already coloured neighbour, therefore the
property stays true.  Undoing the assignment restores the previous
state, which was also proper. ∎



##### Lemma 2  
`future_ok(idx)` returns `True` **iff** there exists at least one proper
extension of the current partial colouring to the vertices `idx+1 … n‑1`.

**Proof.**  
If `future_ok` finds a vertex `v > idx` whose coloured neighbours already
use the three different colours, then *any* colour for `v` would clash,
hence no extension exists – the function correctly returns `False`.

Conversely, assume `future_ok` returns `True`.  
For every `v > idx` at most two colours are blocked, therefore at least
one colour remains available for `v`.  Assigning any available colour to
each such vertex (order does not matter) yields a proper full colouring,
so an extension exists. ∎



##### Lemma 3  
If `dfs(idx)` returns `True`, the array `col` after the return is a
proper colouring of the whole graph.

**Proof.**  
By Lemma&nbsp;1 the partial colouring is proper at every recursion level.
`dfs` returns `True` only when the recursive call for `idx+1` returns
`True`, i.e. when the deeper level finally reaches `idx == n`.
Thus all vertices become coloured and, by Lemma&nbsp;1, the final
colouring is proper. ∎



##### Lemma 4  
If a proper colouring exists, `dfs(0)` eventually returns `True`.

**Proof.**  
Consider any proper colouring `C`.  
We show by induction on `idx` that the search can follow the colours of
`C` without being cut off.

*Base* `idx = 0` : the colour `C[0]` is not forbidden (no neighbour is
coloured yet), therefore the loop tries it and proceeds.

*Induction step* : assume the recursion has already matched `C` on
vertices `0 … idx‑1`.  
All neighbours of vertex `idx` that are already coloured have exactly
the colours `C` gives them, so `C[idx]` is not forbidden.
Consequently the loop will try `C[idx]`.  
After assigning it, Lemma&nbsp;2 guarantees `future_ok(idx)` is `True`
(because the whole colouring `C` is an extension), therefore the recursive
call continues. ∎



##### Lemma 5  
The first complete colouring found by the algorithm is the
lexicographically smallest proper colouring.

**Proof.**  
The search processes vertices in increasing order and, for each vertex,
tries colours `1,2,3` in that order.
Thus the recursion explores the space of colourings in exactly the
lexicographic order.
When the first leaf (all vertices coloured) is reached, no earlier leaf
exists, i.e. no lexicographically smaller proper colouring exists. ∎



##### Theorem  
The program outputs  

* `NO`  **iff** the input graph is not 3‑colourable;
* otherwise `YES` and the lexicographically smallest proper colouring.

**Proof.**  

*If part* – graph not 3‑colourable.  
Assume the program would output `YES`. Then `dfs(0)` returned `True`,
and by Lemma&nbsp;3 a proper 3‑colouring would exist – contradiction.
Hence it must output `NO`.

*Only‑if part* – graph 3‑colourable.  
By Lemma&nbsp;4 `dfs(0)` returns `True`. Lemma&nbsp;3 gives a proper
colouring, and Lemma&nbsp;5 guarantees it is the lexicographically
smallest one. The program therefore prints `YES` and this colouring. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

`n ≤ 40`.

*For each recursive call*  

* computing the forbidden colours of the current vertex – `O(deg)`,
  at most `O(n)`;
* `future_ok` scans all still uncoloured vertices and their already coloured
  neighbours – `O(n²)` in the worst case.

The depth of recursion is `n`, so the total work is  
`O(number_of_visited_nodes · n²)`.  
Because of the strong pruning (`future_ok`) the number of visited nodes
is tiny for all realistic inputs; the program easily fits into the
2 seconds limit.

Memory consumption: adjacency lists `O(n + m)` and the colour array
`O(n)`, well below the 256 MB limit.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    col = [0] * n                     # 0 = uncoloured, else 1..3

    # forward checking: are all still uncoloured vertices still feasible?
    def future_ok(idx: int) -> bool:
        # vertices > idx are still uncoloured
        for v in range(idx + 1, n):
            forbidden = 0
            for nb in adj[v]:
                c = col[nb]
                if c:
                    forbidden |= 1 << (c - 1)
            if forbidden == 0b111:   # all three colours blocked
                return False
        return True

    def dfs(idx: int) -> bool:
        if idx == n:
            return True
        # colours already used by coloured neighbours
        forbidden = 0
        for nb in adj[idx]:
            c = col[nb]
            if c:
                forbidden |= 1 << (c - 1)

        for colour in (1, 2, 3):
            if not (forbidden & (1 << (colour - 1))):
                col[idx] = colour
                if future_ok(idx) and dfs(idx + 1):
                    return True
                col[idx] = 0
        return False

    if dfs(0):
        out = ['YES', ' '.join(str(c) for c in col)]
    else:
        out = ['NO']
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input / output format.
