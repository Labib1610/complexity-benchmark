# Problem A — Orbital Network Frequency Coordination

Time limit: 2 s   Memory limit: 256 MB

A telecommunications agency is configuring a network of $n$ satellite transmitters, numbered $1$ through $n$. Each transmitter must be assigned an operating band from the set $\{1, 2, 3\}$.

Geospatial analysis has identified $m$ pairs of transmitters with overlapping coverage areas. To prevent signal collision, any two transmitters in a listed pair must be assigned different operating bands.

A configuration is a sequence of $n$ band assignments, where the $i$-th value is the band assigned to transmitter $i$. The agency will only consider configurations that are completely free of signal collisions. If no such configuration exists, the setup is aborted.

If valid configurations do exist, the agency must deploy the one that minimizes the network's total data routing load metric. 

To evaluate a configuration's routing load, the agency simulates a packet relay process. The network relays data through a sequence of $n$ orbital stages. A data packet generated at stage $i$ must pass through stages $i+1, i+2, \dots, n$. 

At each stage transition, the network's redundancy protocol replaces every incoming packet with 4 identical copies before transmitting them to the next stage. Transmitter $i$ injects exactly $b_i$ initial packets at stage $i$, where $b_i \in \{1, 2, 3\}$ is its assigned band. 

The metric $M$ is the total number of packets that arrive at stage $n$ across all transmitters. (Packets injected directly at stage $n$ arrive without duplication).

The agency must deploy the valid configuration that minimizes $M$. If multiple valid configurations yield the exact same minimum $M$, output the one that is lexicographically smallest (i.e., compare the band of transmitter 1 first, then transmitter 2, etc., preferring smaller bands).

## Input
The first line contains two integers $n$ and $m$ — the number of satellite transmitters and the number of overlapping coverage pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the next $m$ lines contains two integers $u$ and $v$ — representing a pair of transmitters that have overlapping coverage and must use different bands.

## Output
If no collision-free configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $b_1, b_2, \dots, b_n$ (where each $b_i \in \{1, 2, 3\}$), representing the band allocated to transmitter $i$. Output the configuration that minimizes the metric $M$ (with ties broken lexicographically).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

I replaced the explicit arithmetic cascade (which models easily parsed into positional weights) with a combinatorial packet duplication process that is mathematically identical (base-4 polynomial evaluation). I also explicitly restored the numeric bounds and added a lexicographical tie-breaker to satisfy the strict Gate constraints, ensuring the problem remains completely unambiguous and identical in answer set while hiding the polynomial nature of the objective from surface pattern matchers.
</RATIONALE>
<PRESERVED_ANSWER>
The packet duplication process multiplies the initial $b_i$ packets by 4 for every stage transition, resulting in exactly $b_i 4^{n-i}$ packets at stage $n$, making the metric $M$ mathematically identical to the original cascade's sum and thus preserving the lexicographically smallest optimal configuration.
</PRESERVED_ANSWER>
