<STATEMENT>
# Problem A — Orbital Network Frequency Coordination

Time limit: 2 s   Memory limit: 256 MB

A telecommunications agency is configuring a network of $n$ satellite transmitters, numbered $1$ through $n$. Each transmitter must be assigned an operating band from the set $\{1, 2, 3\}$.

Geospatial analysis has identified $m$ pairs of transmitters with overlapping coverage areas. To prevent signal collision, any two transmitters in a listed pair must be assigned different operating bands.

A configuration is a sequence of $n$ band assignments, where the $i$-th value is the band assigned to transmitter $i$. The agency will only consider configurations that are completely free of signal collisions. If no such configuration exists, the setup is aborted.

If valid configurations do exist, the agency must deploy the single configuration that minimizes the network's total interference metric. 

The interference metric $M$ for a configuration is evaluated using an $n \times n$ signal transfer matrix $T$. The entry $T_{r, c}$ (for row $r$ and column $c$, where $1 \le r, c \le n$) is defined mathematically as follows:
- For $r > c$, $T_{r, c} = 0$.
- For $r = c$, $T_{r, c} = 1$.
- For $r < c$, $T_{r, c}$ is the sum of the weights of all valid relay sequences from $r$ to $c$. A valid relay sequence is defined as a strictly increasing sequence of transmitter indices $(i_1, i_2, \dots, i_k)$ such that $i_1 = r$ and $i_k = c$. The weight of such a sequence is $3^{k-1}$, where $k$ is the number of indices in the sequence.

Once the matrix $T$ is determined, the total interference metric $M$ is computed as:
$$M = \sum_{r=1}^n \sum_{c=1}^n b_r \times T_{r, c}$$
where $b_r$ is the band assigned to transmitter $r$.

## Input
The first line contains two integers $n$ and $m$ — the number of satellite transmitters and the number of overlapping coverage pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the next $m$ lines contains two integers $u$ and $v$ — representing a pair of transmitters that have overlapping coverage and must use different bands.

## Output
If no collision-free configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $b_1, b_2, \dots, b_n$ (where each $b_i \in \{1, 2, 3\}$), representing the band allocated to transmitter $i$. Output the configuration that minimizes the total interference metric.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```

1 2
1 3
1 4
2 3

3 4
```
Output:
```
NO
```

<RATIONALE>
Replaced the sequential noise cascade with an equivalent signal transfer matrix whose entries are defined by summing weights of strictly increasing index sequences. This forces the model to either symbolically recognize that the row sums collapse to $4^{n-r}$ via the binomial theorem, or attempt a naive path evaluation which will TLE given $n=40$.
</RATIONALE>
<PRESERVED_ANSWER>
The transfer matrix row sums mathematically evaluate to exactly $4^{n-r}$, meaning the metric $M$ remains identical to the original $\sum b_i 4^{n-i}$, preserving the exact lexicographical dominance and thus the same optimal configuration.
</PRESERVED_ANSWER>

The problem remains NP-Complete as it is still structurally equivalent to finding the lexicographically first valid 3-coloring of a graph.
</PRESERVED_CLASS>
