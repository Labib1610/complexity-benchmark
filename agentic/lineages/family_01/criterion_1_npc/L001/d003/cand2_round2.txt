# Problem A — Rover Phase Scheduling

Time limit: 2 s   Memory limit: 256 MB

A planetary base operates $n$ automated rovers, indexed from $1$ to $n$. To maintain safe operations, every rover must be scheduled into exactly one of three distinct operational phases, designated as Phase 1, Phase 2, and Phase 3.

During site mapping, planners identified $m$ pairs of rovers that share narrow navigation corridors. If any two such rovers are active during the same operational phase, a collision will occur. Therefore, these specific pairs must never be scheduled in the same phase.

The base's central scheduler evaluates proposed schedules as complete deployment states. A valid deployment state is represented by a sequence of $n$ integers, where the $i$-th integer indicates the phase (1, 2, or 3) assigned to rover $i$. To ensure determinism in the automated system, the controller policy mandates evaluating all possible complete, collision-free deployment states and selecting the single state that is lexicographically smallest. If no collision-free deployment state can be achieved, the scheduler must abort.

Your task is to determine the mandated deployment state or identify if the schedule must be aborted.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of rovers and the number of shared-corridor pairs.
Each of the next $m$ lines contains two integers $u$ and $v$ — an overlapping pair of rovers that must be assigned different phases.

## Output
If the schedule must be aborted because no collision-free deployment state is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the phase assigned to rover $i$. Among all valid assignments, output the lexicographically smallest sequence $p_1, p_2, \dots, p_n$ (compare $p_1$ first, then $p_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
