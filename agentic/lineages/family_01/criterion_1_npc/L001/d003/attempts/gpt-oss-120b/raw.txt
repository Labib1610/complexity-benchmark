**Solution Explanation**

For every station we have to choose a frequency `1,2,3` such that adjacent stations
receive different frequencies.
Among all feasible assignments we need the lexicographically smallest one
(earliest station gets the smallest possible frequency, then the next station,
…).

`n ≤ 40`, therefore a depth‑first search that tries the frequencies for the
stations **in the natural order `1 … n`** is sufficient:

* at station `i` we try the colors `1,2,3` in this order,
* a color is accepted only if none of the already coloured neighbours has the
  same color,
* if a choice leads to a dead end we backtrack and try the next color,
* the first complete assignment we reach is automatically the lexicographically
  smallest one, because we never skip a smaller color for a smaller index.

The only difficulty is to prune the search fast enough.
If a partial assignment already violates a constraint we stop exploring that
branch – this is exactly the colour‑conflict test described above.
With `n = 40` the recursion depth is at most `40`; the branching factor is at
most `3`, and many branches are cut early, so the program easily fits into the
limits.

The graph is stored as an adjacency list (`neighbors[i]` – list of vertices
adjacent to `i`).  
During the search we keep an array `col[1…n]` (`0` = not coloured yet).

The algorithm:

```
dfs(v):
    if v == n+1:               # all vertices coloured
        solution found
    for c in 1,2,3:
        if c is compatible with already coloured neighbours of v:
            col[v] = c
            if dfs(v+1): return True
            col[v] = 0          # backtrack
    return False                # no colour works for v
```

The first call is `dfs(1)`.  
If it returns `True` we output the array `col`; otherwise we output `NO`.

The algorithm is correct because:

* it explores **all** colourings that respect the constraints,
* it tries colours in increasing order for each vertex,
* the first complete colouring found therefore has the smallest possible colour
  at the first position where any feasible colouring can differ – i.e. it is
  lexicographically minimal.

The running time is exponential in the worst case (`O(3^n)`), but with `n ≤ 40`
and strong pruning it runs comfortably within the limits.

**Reference Implementation (Python 3)**

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    neighbors = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        neighbors[u].append(v)
        neighbors[v].append(u)

    col = [0] * (n + 1)          # 0 = uncoloured

    def dfs(v: int) -> bool:
        if v == n + 1:
            return True
        for c in (1, 2, 3):
            ok = True
            for nb in neighbors[v]:
                if col[nb] == c:
                    ok = False
                    break
            if not ok:
                continue
            col[v] = c
            if dfs(v + 1):
                return True
            col[v] = 0
        return False

    if dfs(1):
        out = ['YES', ' '.join(str(col[i]) for i in range(1, n + 1))]
        sys.stdout.write('\n'.join(out))
    else:
        sys.stdout.write('NO')

if __name__ == "__main__":
    solve()
```

the required input‑output format.
