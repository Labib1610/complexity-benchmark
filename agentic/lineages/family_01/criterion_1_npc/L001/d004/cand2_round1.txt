Globalized Local Constraints
</METHOD_NAME>
<METHOD_DESCRIPTION>
We obfuscate the local condition $f_u \neq f_v$ by adding the sum of all frequencies $S$ to both sides, expressing it as $S - f_u - f_v \neq S - 2f_u$. To an LLM translating text to code literally, this appears to be a global constraint that cannot be checked until all $n$ stations are assigned. Evaluating it only at the leaves of the DFS tree destroys early pruning, causing a Time Limit Exceeded on $3^{40}$ states. Only models that algebraically simplify the constraint back to $f_u \neq f_v$ will successfully prune the search space and pass.
</METHOD_DESCRIPTION>

yes

# Problem A — Orbital Network Frequency Coordination

Time limit: 2 s   Memory limit: 256 MB

An aerospace consortium is preparing the initialization profile for $n$ orbital uplink stations, numbered $1$ through $n$. The hardware supports exactly three operational frequencies, labeled 1, 2, and 3. Every station must be allocated exactly one of these frequencies.

Spatial analysis has identified $m$ pairs of stations whose broadcast footprints intersect. To prevent destructive interference, the allocation must satisfy a specific network-wide load condition for each intersecting pair. For any pair of stations with intersecting footprints, consider the total frequency load of the entire orbital network (which is the sum of the frequencies allocated to all $n$ stations). If you subtract the frequencies of both stations in the pair from this total load, the remaining value must strictly differ from the value obtained by subtracting twice the frequency of the first station in the given pair from the total load.

The initialization profile is expressed as a complete sequence of $n$ integers, where the $i$-th value is the frequency (1, 2, or 3) allocated to station $i$. The consortium evaluates all possible complete, interference-free profiles as a set. From this set of valid configurations, the automated deployment policy mandates selecting the profile that is lexicographically smallest. This means that when comparing two valid profiles, the system evaluates the entire sequence and selects the one with the smaller frequency value at the first station index where the two configurations differ (comparing the frequency for station 1 first, then station 2, and so forth).

If the set of profiles satisfying this condition for all intersecting pairs is empty, the procedure must be aborted.

## Input
The first line contains two integers $n$ and $m$ — the number of uplink stations and the number of intersecting footprint pairs. The value of $n$ is at least $1$ and at most the atomic number of Zirconium. The value of $m$ is at least $0$ and at most $n(n-1)/2$.
Each of the next $m$ lines contains two integers $u$ and $v$ — representing a pair of stations that have intersecting footprints.

## Output
If the deployment must be aborted because no profile satisfies the network-wide condition, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $f_1, f_2, \dots, f_n$ (where each $f_i \in \{1, 2, 3\}$), representing the frequency allocated to station $i$. Among all valid profiles, output the lexicographically smallest sequence (comparing $f_1$ first, then $f_2$, and so forth).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I transformed the local interference constraint into a mathematically equivalent global constraint by adding the sum of all frequencies to both sides. Models that rely on surface-level translation will place this constraint check at the base case of their backtracking search because it appears to require the complete array to compute the total load. This completely destroys DFS early pruning, forcing an intractable search that will Time Limit Exceeded. Only models that genuinely reason about the algebra will simplify it back to a local check and restore pruning. I also indirectly stated the $n \le 40$ bound using the atomic number of Zirconium.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic condition $S - f_u - f_v \neq S - 2f_u$ simplifies exactly to $f_u \neq f_v$, meaning the set of valid frequency profiles and their lexicographical ordering remains completely unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Graph 3-Coloring, which is NP-complete, as the disguised constraint is functionally identical to the standard graph coloring conflict check.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "the first station in the given pair" if they forget the input order, but since the mathematical equivalence holds symmetrically regardless of which station is chosen, this ambiguity has no effect on correctness.
</RISK>
