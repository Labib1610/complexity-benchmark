We need to assign frequencies 1, 2, or 3 to each station such that no two connected stations share the same frequency, and among all valid assignments, we pick the lexicographically smallest sequence.

This is essentially a graph coloring problem with 3 colors, and we want the lexicographically smallest coloring.

We can solve it with backtracking, trying colors from 1 to 3 for each node in order, and checking constraints.

Here’s the implementation:

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n
found = False

def backtrack(idx):
    global found
    if idx == n:
        found = True
        return True
    for c in range(1, 4):
        ok = True
        for nb in adj[idx]:
            if color[nb] == c:
                ok = False
                break
        if ok:
            color[idx] = c
            if backtrack(idx + 1):
                return True
            color[idx] = 0
    return False

if backtrack(0):
    print("YES")
    print(" ".join(map(str, color)))
else:
    print("NO")
```
