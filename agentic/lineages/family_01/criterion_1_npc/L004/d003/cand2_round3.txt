# Orbital Frequency Routing

**Time limit:** 2 s  
**Memory limit:** 256 MB  

An orbital satellite operates $n$ electronic modules, labeled with integers from 1 to $n$. Each module requires exactly one active frequency band to operate. There are exactly three available bands, designated as Band 1, Band 2, and Band 3.

Due to severe electromagnetic interference, certain pairs of modules exhibit resonant interference. A module is considered locally safe if its assigned frequency band differs from the frequency band of every other module it has a resonant interference report with. You are given a comprehensive list of these resonant pairs. Your objective is to determine whether there exists a valid band assignment for all $n$ modules such that every module is locally safe.

The satellite's interconnected design means these interference constraints are distributed across the system, forming a dense network of dependencies.

## Input
The first line contains two integers $n$ and $m$, representing the number of modules and the number of resonant pairs, respectively. Due to power constraints, the satellite operates at least 1 and at most 40 modules. The number of resonant reports $m$ can be as low as 0 and as high as the maximum possible number of distinct pairs, $n \cdot (n-1)/2$.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that module $u$ and module $v$ form a resonant pair and must be assigned different bands to remain locally safe.

## Output
If no safe frequency routing exists, print `NO` on a single line.
If a valid routing is possible, print `YES` on the first line. On the second line, output a sequence of $n$ integers $b_1, b_2, \dots, b_n$ (where each $b_i \in \{1, 2, 3\}$) indicating the band assigned to module $i$. Should multiple valid routings exist, output the one that is lexicographically first (evaluating the band choice for module 1 first, then module 2, and so on).

## Example 1
**Input:**
```
4 5
1 2
1 3
2 3
1 4
2 4
```
**Output:**
```
YES
1 2 3 3
```

## Example 2
**Input:**
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
**Output:**
```
NO
```

I reframed the coloring constraints around an implicit local safety predicate (a module is safe if its frequency differs from all resonating partners) rather than directly describing a global partition, to abstract away the direct 3-coloring terminology. I stated the numeric bounds in prose tied to physical and logical limits ("power constraints", "maximum possible distinct pairs") rather than bare inequalities, forcing the model to parse the text to extract the exact limits while preserving the numbers to satisfy strict bound-checking.
</RATIONALE>

</PRESERVED_ANSWER>
