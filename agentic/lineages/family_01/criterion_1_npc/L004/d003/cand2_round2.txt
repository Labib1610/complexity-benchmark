# Orbital Power Routing

**Time limit:** 2 s  
**Memory limit:** 256 MB  

An orbital satellite operates a set of electronic modules, labeled with integers from 1 to $n$. To function, every module must draw its power from exactly one of three distinct, isolated power buses (Bus 1, Bus 2, or Bus 3).

Due to severe electromagnetic interference, modules are governed by a local safety predicate: a module operates safely if and only if it does not share its power bus with any of its specific interfering counterparts. You are provided the pairs that trigger this safety violation. Your objective is to determine whether there exists a valid bus assignment for all $n$ modules such that the safety predicate holds for every module simultaneously.

The satellite's interconnected design means these interference constraints are distributed across the system, forming a dense network of dependencies. Please note that the hidden tests contain adversarial 40-module instances specifically designed to exhaust the time limit if your approach relies on fixed module-order, bus-order backtracking.

## Input
The first line specifies two integers $n$ and $m$, representing the number of modules and the number of interfering pairs. The satellite's physical chassis has exactly 40 slots, meaning the number of modules $n$ is between 1 and 40. The number of constraints $m$ ranges from 0 up to the theoretical maximum of $n \cdot (n-1)/2$.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that module $u$ and module $v$ trigger the local safety predicate if placed on the same bus.

## Output
If no valid bus assignment exists that satisfies all safety predicates, output `NO` on a single line.
If a valid assignment is possible, output `YES` on the first line. On the second line, provide a sequence of $n$ integers $b_1, b_2, \dots, b_n$ (where each $b_i \in \{1, 2, 3\}$) representing the bus assigned to module $i$. If there are multiple valid assignments, output the one that is lexicographically first (evaluating the bus choice for module 1 first, then module 2, and so on).

## Example 1
**Input:**
```
4 5
1 2
1 3
2 3
1 4
2 4
```
**Output:**
```
YES
1 2 3 3
```

## Example 2
**Input:**
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
**Output:**
```
NO
```
