**Solution Explanation**

For an edge `(u,v)` let  

```
d = b_u – b_v          ( b_i ∈ {1,2,3} )
f(d) = 5·d² – d⁴
```

The required total energy is  

```
 Σ f(b_u – b_v)  = 4·m                (1)
```

All possible differences are `d = 0, ±1, ±2`.

```
d = 0 : f = 0
d = ±1: f = 5·1 – 1 = 4
d = ±2: f = 5·4 – 16 = 4
```

So an edge contributes **4** iff its ends have *different* values,
otherwise it contributes **0**.
Equation (1) therefore means that **every edge must connect two different
values**.
Consequently we have to colour the given graph with three colours
`1,2,3` such that adjacent vertices receive different colours – the classic
*3‑colourability* problem.

`n ≤ 40`, therefore an exponential back‑tracking search with good pruning
solves it easily.



--------------------------------------------------------------------

#### 1.  Data structures

* `adj[v]` – list of neighbours of vertex `v` (0‑based indices)
* `deg[v]` – degree of `v`
* `color[v]` – `0` = not coloured yet, otherwise `1..3`
* `forbid[v]` – 3‑bit mask, bit `c‑1` is set iff a neighbour of `v`
  already uses colour `c`.  
  (`forbid[v] == 7` means *no colour left*).

All masks fit into a normal Python integer.



--------------------------------------------------------------------

#### 2.  Recursive search (DSATUR heuristic)

```
dfs(coloured_cnt):
    if coloured_cnt == n:   success
    choose an uncoloured vertex v
          with maximal saturation = popcount(forbid[v])
          (ties broken by larger degree)
    try every colour c not forbidden for v
          assign colour c to v
          for each still uncoloured neighbour u:
                 if colour c was not yet forbidden for u:
                        set the bit in forbid[u]   (remember u)
          if no neighbour became completely blocked (forbid == 7)
                 recurse
          undo all changes
    if none of the colours works → failure
```

The *saturation* (how many different colours are already present among the
already coloured neighbours) is the classic DSATUR rule; it dramatically
reduces the search tree.

Whenever a vertex obtains `forbid == 7` we can prune immediately – the
partial colouring can never be extended.



--------------------------------------------------------------------

#### 3.  Correctness Proof  

We prove that the algorithm prints `YES` and a valid assignment
iff such an assignment exists.

---

##### Lemma 1  
For any edge `(u,v)` the contribution to the total energy equals `4`
iff `b_u ≠ b_v`, otherwise it equals `0`.

**Proof.** Direct calculation of `f(d)` for `d = 0,±1,±2` (the only
possible differences) shows the values `0,4,4`. ∎



##### Lemma 2  
A colour assignment satisfies the required total energy `4·m`
iff it is a proper 3‑colouring of the graph (adjacent vertices have
different colours).

**Proof.** By Lemma&nbsp;1 each edge contributes `4` exactly when its ends
are coloured differently. The total sum is therefore `4·(#edges with
different colours)`. Equality with `4·m` forces *all* `m` edges to have
different colours, i.e. the colouring is proper. The converse is
obvious. ∎



##### Lemma 3  
During the execution of `dfs` the invariant holds:

*All already coloured vertices have pairwise different colours on every
edge among them, and `forbid[v]` correctly records the colours used by
their coloured neighbours.*

**Proof.** Initially no vertex is coloured and all masks are `0`,
so the invariant holds.
When a vertex `v` receives colour `c`, the algorithm updates `forbid[u]`
for each uncoloured neighbour `u` by setting the bit of `c`.  
Thus after the update `forbid[u]` contains exactly the colours of all
coloured neighbours of `u`.  
No edge between two coloured vertices can have equal colours because we
never assign a colour that is already forbidden for the vertex.
Therefore the invariant is preserved. ∎



##### Lemma 4  
If the recursive call `dfs(coloured_cnt)` returns *True*, the current
partial assignment can be extended to a full proper 3‑colouring.

**Proof.** Induction on the recursion depth.  
Base: when `coloured_cnt == n` the assignment is already complete and
proper (by Lemma&nbsp;3).  
Induction step: the call succeeded because for some colour `c` the
algorithm assigned it to vertex `v`, performed recursive call
`dfs(coloured_cnt+1)` which returned *True*, and afterwards never
undid that assignment. By the induction hypothesis the deeper call can
be completed to a proper colouring; together with the colour of `v`
the whole graph is properly coloured. ∎



##### Lemma 5  
If a proper 3‑colouring exists, `dfs(0)` eventually returns *True*.

**Proof.** Consider any fixed proper colouring `C`.  
The search always chooses an uncoloured vertex `v`.  
Because `C` is proper, the colour `C(v)` is not forbidden for `v`
(Lemma&nbsp;3). Hence the algorithm will try `C(v)` among its colour
options. When it does, the updates of `forbid` are exactly those induced
by `C`. Consequently the recursive sub‑problem still admits the
restriction of `C` to the remaining vertices. Repeating this argument
along the recursion path that always picks the colour prescribed by `C`
leads to the leaf where all vertices are coloured, so the algorithm
finds a successful leaf and returns *True*. ∎



##### Lemma 6  
If `dfs(0)` returns *False*, no proper 3‑colouring exists.

**Proof.** Assume the contrary: a proper colouring `C` exists.
By Lemma&nbsp;5 the algorithm would have a successful recursion branch
following `C`, contradicting the return value *False*. ∎



##### Theorem  
The program outputs  

* `YES` and a list `b_1 … b_n`  **iff**  there exists an assignment with
  total energy `4·m`;
* otherwise it outputs `NO`.

**Proof.**  
By Lemma&nbsp;2 the existence of a required assignment is equivalent to the
existence of a proper 3‑colouring.
The program runs `dfs(0)`.  
If it returns *True*, by Lemma&nbsp;4 the obtained `color` array is a proper
3‑colouring, therefore a valid assignment – the program prints `YES`
and this array.  
If it returns *False*, Lemma&nbsp;6 shows that no proper 3‑colouring (hence
no required assignment) exists, and the program prints `NO`. ∎



--------------------------------------------------------------------

#### 4.  Complexity Analysis  

`n ≤ 40`.

*Each recursive step*  
* selects a vertex – `O(n)`  
* tries at most 3 colours, and for each colour updates all its neighbours –
  `O(deg(v))`.

Overall the work is `O( 3^k )` where `k` is the number of vertices that
must actually be guessed; the DSATUR heuristic and early pruning keep
`k` far below `n` for all practical inputs.  
In the worst theoretical case (`3^40`) the program would be too slow,
but for `n = 40` the exponential back‑track with these strong prune
conditions easily finishes within the given limits (the problem is
designed for this approach).

Memory consumption: adjacency lists (`O(n+m)`) and a few integer arrays,
well below the 256 MiB limit.

#### 5.  Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n)]
    deg = [0] * n
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        if u == v:
            continue
        adj[u].append(v)
        adj[v].append(u)
        deg[u] += 1
        deg[v] += 1

    color = [0] * n          # 0 = uncoloured, else 1..3
    forbid = [0] * n         # bitmask of forbidden colours

    # -----------------------------------------------------------------
    def dfs(coloured_cnt: int) -> bool:
        if coloured_cnt == n:
            return True

        # choose vertex with maximal saturation, tie by degree
        best_v = -1
        best_sat = -1
        best_deg = -1
        for v in range(n):
            if color[v] == 0:
                sat = (forbid[v] & 1) + ((forbid[v] >> 1) & 1) + ((forbid[v] >> 2) & 1)
                d = deg[v]
                if sat > best_sat or (sat == best_sat and d > best_deg):
                    best_sat = sat
                    best_deg = d
                    best_v = v
        v = best_v

        # try every allowed colour
        for c in range(1, 4):
            mask = 1 << (c - 1)
            if forbid[v] & mask:
                continue

            # assign colour
            color[v] = c
            changed = []          # neighbours whose forbid mask really changed
            for u in adj[v]:
                if color[u] == 0 and not (forbid[u] & mask):
                    forbid[u] |= mask
                    changed.append(u)

            # early failure detection
            dead = False
            for u in adj[v]:
                if color[u] == 0 and forbid[u] == 7:
                    dead = True
                    break

            if not dead and dfs(coloured_cnt + 1):
                return True

            # undo
            for u in changed:
                forbid[u] &= ~mask
            color[v] = 0

        return False
    # -----------------------------------------------------------------

    possible = dfs(0)

    out = []
    if possible:
        out.append("YES")
        out.append(" ".join(str(c) for c in color))
    else:
        out.append("NO")
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
