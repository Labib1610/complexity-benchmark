<STATEMENT>
# Protocol Synchronization

Time limit: 2 s   Memory limit: 256 MB

You are tasked with configuring the synchronization protocols for a distributed network consisting of $n$ server nodes.
For each node $i$, you must assign a protocol version $b_i$. This version must be an integer selected from the set $\{1, 2, 3\}$.

The network topology is defined by $m$ communication links connecting various pairs of nodes. For the network to function correctly, every linked pair of nodes $(u, v)$ must be able to exchange data without interruption. However, a known hardware quirk affects the signal stability across these links. Specifically, the continuous signal interference between two linked nodes $u$ and $v$ over a standard transmission cycle is proportional to the value of the following definite integral:

$$ \int_{0}^{\pi} \sin(b_u x) \sin(b_v x) dx $$

If this integral evaluates to a value strictly greater than zero, the resulting interference will cause the link to drop packets and fail. 

Your objective is to determine whether there is a valid protocol assignment for all $n$ nodes that ensures zero communication links fail. If such an assignment exists, you must output it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of server nodes and the number of communication links.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), representing a communication link between node $u$ and node $v$.

## Output
If there is no valid protocol assignment, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $b_1, b_2, \dots, b_n$ (each in $\{1, 2, 3\}$), where $b_i$ is the protocol version assigned to node $i$. If there are multiple valid assignments, any valid assignment is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the algebraic packet-drop rule (sum of squares is a multiple of their product) with an equivalent calculus-based rule involving the orthogonality of sine functions. This forces the model to correctly evaluate the definite integral to discover that it acts as a strict equality check, preventing immediate pattern-matching to standard graph 3-coloring. (Note: I deliberately ignored the prompt's suggested "global parity requirement" because requiring the number of valid links to be odd would change the output to `NO` for 3-colorable networks with an even number of edges, violating Hard Constraint 1).
</RATIONALE>
<PRESERVED_ANSWER>
For integers in {1, 2, 3}, the integral of sin(b_u*x)*sin(b_v*x) over [0, pi] evaluates to pi/2 if b_u == b_v and 0 if b_u != b_v, meaning the new interference condition drops packets for exactly the same protocol pairs as the original arithmetic rule.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains mathematically identical to checking if a given graph can be strictly 3-colored, keeping it in the NP-complete complexity class.
</PRESERVED_CLASS>
<RISK>
Models with weak symbolic math capabilities might struggle to evaluate the integral correctly, leading them to misinterpret which pairs of protocol versions are allowed to share a link.
</RISK>
