# Orbital Power Routing

**Time limit:** 2 s  
**Memory limit:** 256 MB  

An orbital satellite operates a set of electronic modules, labeled with integers starting from 1 up to the total number of modules. To function, every module must draw its power from exactly one of three distinct, isolated power buses (Bus 1, Bus 2, or Bus 3).

Due to severe electromagnetic interference, certain pairs of modules will fail if they draw power from the identical bus. You are provided with a log of these interference readings. A system configuration is considered safe if and only if no two modules that appear together in a reading are assigned to the same power bus. Your objective is to determine whether there exists a valid bus assignment for all modules that satisfies this safety condition.

The satellite's interconnected design means these interference constraints are distributed across the system, forming a dense network of dependencies. Note that the evaluation suite includes adversarial configurations utilizing the maximum possible number of modules, specifically constructed to exhaust the time limit of programs that attempt to find a solution by merely guessing bus assignments in a fixed numerical sequence without deeper structural analysis.

## Input
The first line contains two integers $n$ and $m$, representing the number of modules and the number of interference readings, respectively. The satellite's main chassis provides exactly 40 hardware bays, meaning the total number of modules $n$ will never exceed this structural limit, and there is always at least one module installed. The value $m$ ranges from zero up to the maximum possible number of distinct pairs that can be formed from the $n$ modules.

Each of the next $m$ lines contains two integers $u$ and $v$, indicating a reading where module $u$ and module $v$ interfere and therefore must be connected to different buses.

## Output
If no safe power routing exists, print `NO` on a single line.
If a valid routing is possible, print `YES` on the first line. On the second line, output a sequence of $n$ integers $b_1, b_2, \dots, b_n$ (where each $b_i \in \{1, 2, 3\}$) indicating the bus assigned to module $i$. Should multiple valid routings exist, output the one that is lexicographically first (evaluating the bus choice for module 1 first, then module 2, and so on).

## Example 1
**Input:**
```
4 5
1 2
1 3
2 3
1 4
2 4
```
**Output:**
```
YES
1 2 3 3
```

## Example 2
**Input:**
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
**Output:**
```
NO
```
