# Banquet Preparation

Time limit: 2 s   Memory limit: 256 MB

A chef is preparing a banquet featuring $n$ distinct dishes, labeled 1 through $n$. Each dish must be assigned to exactly one of three serving phases, denoted by the integers 1, 2, and 3.

The chef has evaluated the flavor profiles and found $m$ flavor clashes. Each clash involves two specific dishes. If these two dishes are served during the same phase, their combined flavors will overwhelm the palate. Therefore, for every clash, the two dishes must be assigned to different serving phases.

Your task is to determine whether it is possible to assign a serving phase to every dish such that no clashing dishes are served in the same phase.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$), representing the number of dishes and the number of flavor clashes.
Each of the following $m$ lines contains two integers $u$ and $v$ denoting a flavor clash between dish $u$ and dish $v$.

## Output
If no valid phase assignment exists, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $b_1, b_2, \dots, b_n$, where $b_i \in \{1, 2, 3\}$ is the serving phase for dish $i$. If multiple valid assignments exist, output the sequence that is lexicographically smallest (i.e., compare $b_1$ first, then $b_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
