# Phase 2: Signal Phase Configuration

Time limit: 2 s   Memory limit: 256 MB

You are developing a module for a satellite communications pipeline. The pipeline operates in three sequential phases:

**Phase 1: Telemetry Ingestion**
The system receives raw data streams from monitoring satellites. An interference analysis is performed to determine which specific pairs of data streams exhibit harmonic overlap.

**Phase 2: Signal Phase Configuration (Your Task)**
To prepare for downlink transmission, your module must assign exactly one phase shift profile to each data stream. The hardware supports exactly three distinct profiles, which are designated by the integers 1, 2, and 3. 

To ensure data integrity, whenever Phase 1 identifies two streams as having a harmonic overlap, those two streams must be assigned distinct phase shift profiles. If no valid configuration exists for the entire batch of streams, the batch must be rejected.

**Phase 3: Downlink and Decoding**
The ground station receives the signals, applies the corresponding demodulation profiles, and archives the telemetry.

Your task is to implement the logic for Phase 2. Given the output from Phase 1, determine a valid profile configuration for all $n$ streams, or report that the batch cannot be processed.

## Input
The first line contains two integers $n$ and $m$. The value $n$ represents the number of data streams (numbered 1 through $n$). The hardware guarantees at least one stream, up to a maximum constellation capacity of 40 satellites. The value $m$ represents the total count of harmonic overlaps, ranging from zero up to the theoretical maximum where every stream overlaps with every other stream.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that data streams $u$ and $v$ exhibit a harmonic overlap.

## Output
If there is no way to configure the profiles without violating the safety conditions, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $p_1, p_2, \dots, p_n$ (each being 1, 2, or 3), where $p_i$ is the phase shift profile assigned to data stream $i$. If there are multiple valid configurations, any valid configuration is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
