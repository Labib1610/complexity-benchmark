# Orbital Power Routing

Time limit: 2 s   Memory limit: 256 MB

An orbital satellite contains $n$ electronic modules, numbered 1 through $n$. Each module must be assigned a power frequency multiplier, which must be chosen from the values 1, 2, or 3.

Due to electromagnetic harmonic resonance, certain pairs of modules will experience severe crosstalk if the product of their assigned frequency multipliers is a perfect square. You are provided with a list of all such interacting module pairs. Your task is to determine whether it is possible to assign a frequency multiplier to every module such that no interacting pair produces a perfect square product.

## Input
The first line contains two integers $n$ and $m$ — the number of modules and the number of interacting pairs ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of modules that will crosstalk if their multiplier product is a perfect square.

## Output
If no safe configuration exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $b_1, b_2, \dots, b_n$ (each in $\{1,2,3\}$), where $b_i$ is the frequency multiplier for module $i$. Among all valid assignments, output the lexicographically smallest sequence (compare $b_1$ first, then $b_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I replaced the direct "cannot share the same bus" constraint with the mathematical condition that "the product of their assigned frequency multipliers is a perfect square". Since the domain of multipliers is restricted to {1, 2, 3}, a product of any two choices is a perfect square if and only if the two choices are identical. This forces the model to evaluate the constraint over the domain and deduce the equivalence to an equality check, preventing it from blindly applying bitmask propagation for graph coloring without first reasoning through the mathematical structure.
</RATIONALE>
<PRESERVED_ANSWER>
The possible values are 1, 2, and 3; the only perfect square products formed by pairs from this set are 1×1=1, 2×2=4, and 3×3=9, meaning the condition exactly enforces that interacting modules receive different assignments, preserving all valid configurations and the lexicographically smallest tie-break.
</PRESERVED_ANSWER>
