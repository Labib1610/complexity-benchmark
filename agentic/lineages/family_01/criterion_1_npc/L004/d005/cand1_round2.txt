# Protocol Synchronization

Time limit: 2 s   Memory limit: 256 MB

You are configuring the synchronization protocols for a distributed network of $n$ server nodes. Each node $i$ must be assigned a protocol version $b_i$, which must be exactly one integer chosen from the set $\{1, 2, 3\}$.

You are given a list of $m$ communication links between pairs of nodes. For each link $(u, v)$, the network hardware requires the connection to be asymmetric to avoid signal collision. Specifically, the link operates successfully if and only if the ordered pair of protocol versions assigned to node $u$ and node $v$, denoted as $(b_u, b_v)$, is one of the following authorized pairs:
- $(1, 2)$
- $(2, 1)$
- $(1, 3)$
- $(3, 1)$
- $(2, 3)$
- $(3, 2)$

If the ordered pair $(b_u, b_v)$ is not in this authorized list, the link fails to operate. 

Your objective is to determine if there exists an assignment of protocol versions for all $n$ nodes such that every communication link successfully operates. If a valid assignment exists, output it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of server nodes and the number of communication links.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), representing a communication link between node $u$ and node $v$.

## Output
If there is no valid protocol assignment, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $b_1, b_2, \dots, b_n$ (each in $\{1, 2, 3\}$), where $b_i$ is the protocol version assigned to node $i$. If there are multiple valid assignments, any valid assignment is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

This addresses the expert's feedback by providing an exact, unambiguous equivalent to the seed's inequality rule without introducing new arithmetic formulas, while still forcing the model to process the constraint as a generic binary CSP relation.
</RATIONALE>
<PRESERVED_ANSWER>
The extensional list of authorized pairs contains exactly those pairs where b_u and b_v are distinct values from {1, 2, 3}, which perfectly matches the original channel interference rule.
</PRESERVED_ANSWER>

The problem remains exactly Graph 3-Coloring, which is NP-complete, because the constraint between any two linked nodes is strictly that they must receive different values from a domain of size 3.
