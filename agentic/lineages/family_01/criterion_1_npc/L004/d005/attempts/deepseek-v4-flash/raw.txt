We can model this as a graph coloring problem with 3 colors, where adjacent nodes must have different colors.  

The allowed pairs are exactly all pairs where the two values are different. So the condition is simply:  
**For every edge (u, v), b_u ≠ b_v.**

That means we need to check if the graph is 3-colorable. Since n ≤ 40, we can use backtracking with pruning.

Here’s the code:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)

    colors = [0] * n  # 0 = uncolored, 1,2,3 = colors

    def backtrack(node):
        if node == n:
            return True
        # Try colors 1,2,3
        for c in (1, 2, 3):
            ok = True
            for nb in adj[node]:
                if colors[nb] == c:
                    ok = False
                    break
            if ok:
                colors[node] = c
                if backtrack(node + 1):
                    return True
                colors[node] = 0
        return False

    if backtrack(0):
        print("YES")
        print(" ".join(map(str, colors)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
