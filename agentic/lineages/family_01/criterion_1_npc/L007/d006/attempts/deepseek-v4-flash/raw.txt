We can simplify the energy formula first.

Given:

\[
\Delta E(u,v) = (c_u - c_v)^2 \cdot ((c_u - c_v)^2 - 5) + (-4)(-1)
\]
\[
= (c_u - c_v)^4 - 5(c_u - c_v)^2 + 4
\]

Let \( d = c_u - c_v \). Possible values for \( d \) are \(-2, -1, 0, 1, 2\).

Compute:

- \( d = 0 \): \( 0 - 0 + 4 = 4 \)
- \( d = \pm 1 \): \( 1 - 5 + 4 = 0 \)
- \( d = \pm 2 \): \( 16 - 20 + 4 = 0 \)

So \(\Delta E = 0\) unless the two modules have the same access level.  
If they are equal, \(\Delta E = 4\).

Thus, the total energy is zero **if and only if** no two connected modules have the same access level.

So the problem reduces to:  
We have a graph with \(n\) vertices, and we must assign each vertex a value from \(\{1,2,3\}\) such that adjacent vertices have different values.  
We need the lexicographically smallest such assignment, or report impossible.

This is exactly a **3-coloring** problem.  
Since \(n \le 40\), we can solve it with backtracking + pruning.

We'll implement a backtracking search that tries colors 1, 2, 3 in order for each vertex, checking constraints with already-colored neighbors.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n
    
    def backtrack(idx):
        if idx == n:
            return True
        # Try colors 1,2,3 in order for lexicographic smallest
        for c in (1, 2, 3):
            ok = True
            for nb in adj[idx]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[idx] = c
                if backtrack(idx + 1):
                    return True
                color[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
