# Problem A — Resonant Frequency Synchronization

Time limit: 2 s   Memory limit: 256 MB

A secure communications array consists of $n$ transmitter nodes. Each node must be configured to operate on one of three available frequency bands, represented by the values $\{1, 2, 3\}$.

The array's structural integrity is monitored by a network of $m$ interference sensors. Each sensor monitors a specific pair of nodes. If the nodes are not properly configured, they generate harmonic interference. For any two nodes $u$ and $v$ monitored by a sensor, with assigned frequency bands $c_u$ and $c_v$, their pairwise interference metric $I(u, v)$ is determined by first computing two intermediate resonance values:

$$ R_1 = c_u^2 + c_v^2 $$
$$ R_2 = c_u c_v $$

The interference metric is then calculated as:

$$ I(u, v) = R_1^2 - 4 R_1 R_2 + 4 R_2^2 - 5 R_1 + 10 R_2 + 4 $$

The total interference of the array is defined as the sum of $I(u, v)$ across all $m$ sensors. The array is considered perfectly synchronized if and only if its total interference is exactly zero.

Your task is to determine if there exists a complete frequency band assignment for all nodes such that the array is perfectly synchronized. If at least one valid assignment exists, you must identify the one that is lexicographically smallest.

## Input
The first line of the input provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). These represent the total number of transmitter nodes and the number of interference sensors, respectively.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that a sensor monitors the pair of nodes $u$ and $v$.

## Output
If no perfectly synchronized assignment can be found, print `NO` on a single line.
If a synchronized assignment is possible, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$) representing the frequency band assigned to each respective node. Among all valid synchronized configurations, the sequence of frequency bands you output must be the lexicographically smallest (i.e., comparing the band of node 1 first, then node 2, and so forth).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
