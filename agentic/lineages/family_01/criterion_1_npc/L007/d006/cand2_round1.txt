# Problem A — Thermal Resonance Tuning

Time limit: 2 s   Memory limit: 256 MB

A reactor core contains $n$ thermal modules. To maintain stability, each module must be calibrated to a resonance state, represented by an integer $s_i \in \{1, 2, 3\}$.

The diagnostic system has identified $m$ critical interactions. Each interaction specifies two modules, $u$ and $v$, which are physically positioned such that they will cause catastrophic feedback if their combined quantum interference factor exhibits perfect resonance.

Specifically, for every recorded interaction between module $u$ and module $v$, the interference factor is calculated as the total number of positive integer divisors of the value $12^{s_u} \cdot 18^{s_v}$. To prevent core failure, the calibration sequence must ensure that this factor is **not** a perfect square.

Your task is to determine whether there exists a valid state assignment for all modules $1 \dots n$ such that every critical interaction is mitigated. If such an assignment exists, you must provide one.

## Input
The first line contains two integers $n$ and $m$ — the number of thermal modules and the number of critical interactions ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the following $m$ lines contains two integers $u$ and $v$, indicating a critical interaction between module $u$ and module $v$.

## Output
If it is impossible to calibrate the modules safely, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2, 3\}$), with $s_i$ representing the resonance state assigned to module $i$. Any valid assignment is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The explicit quadratic modulo-3 condition was replaced with a number-theoretic property: checking if the number of divisors of 12^{s_u} * 18^{s_v} is a perfect square. This completely removes the obvious algebraic symmetry and modular arithmetic that allowed models to immediately map the condition to a generic inequality (s_u != s_v). Models must now either symbolically deduce or programmatically evaluate this new predicate to discover the underlying constraint graph, forcing genuine algorithmic reasoning rather than surface-level pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The number of positive integer divisors of 12^{s_u} * 18^{s_v} is (2s_u + s_v + 1)(s_u + 2s_v + 1), which evaluates to a perfect square if and only if s_u = s_v for s_u, s_v in {1, 2, 3}, making the condition strictly equivalent to the original s_u != s_v constraint.
</PRESERVED_ANSWER>
