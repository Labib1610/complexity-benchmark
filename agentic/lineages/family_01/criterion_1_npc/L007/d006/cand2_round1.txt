# Problem A — Resonant Frequency Allocation

Time limit: 2 s   Memory limit: 256 MB

A secure facility is configuring the frequency bands for a network of $n$ interdependent transmission modules. Each module must receive exactly one frequency band from the set $\{1, 2, 3\}$.

To prevent critical signal interference, the facility evaluates the entire network's configuration using a global resonance metric based on $m$ separation protocols. Each protocol specifies a pair of interacting modules. 

The global resonance $R$ of the network is calculated as the product of the interaction scores of all $m$ protocols. For any two modules $u$ and $v$ linked by a protocol, their interaction score is given by the polynomial:
$$ S(u, v) = c_u^2 + c_v^2 + c_u c_v $$
where $c_u$ and $c_v$ are their assigned frequency bands.

The total global resonance $R$ is defined as the product of $S(u, v)$ across all $m$ separation protocols. (If $m=0$, there are no protocols, and $R$ is considered to be 1). The network is deemed completely stable if and only if its global resonance $R$ is not a multiple of 3.

Please take note: the test suite contains instances specifically designed to be adversarial. Maximum-size test cases are structured such that attempting to resolve the configuration by simply generating assignments and calculating the global resonance $R$ at the end will result in an astronomical number of dead ends before a stable state is found or proven impossible.

Your task is to determine if there exists a complete frequency assignment that makes the network completely stable. If at least one valid assignment exists, you must identify the one that is lexicographically smallest.

## Input
The first line of the input provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). These represent the total number of modules and the number of separation protocols, respectively.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that module $u$ and module $v$ are linked by a separation protocol.

## Output
If no completely stable assignment can be found, print `NO` on a single line.
If a stable assignment is possible, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$) representing the frequency band assigned to each respective module. Among all valid stable configurations, the sequence of frequency bands you output must be the lexicographically smallest (i.e., comparing the frequency band of module 1 first, then module 2, and so forth).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The seed problem used an energy sum that equalled zero. LLMs easily recognize that a sum of non-negative terms equals zero if and only if all terms are zero, allowing them to implement local forward-checking optimizations automatically. I replaced this with a global product of the polynomial $c_u^2 + c_v^2 + c_u c_v$ that must not be a multiple of 3. This requires the model to deduce a number-theoretic property (a product is not divisible by a prime iff none of its factors are) to unlock the local forward-checking optimization, otherwise it will implement a naive global check at the leaves and TLE.
</RATIONALE>
<PRESERVED_ANSWER>
For any $c_u, c_v \in \{1, 2, 3\}$, the polynomial evaluates to a multiple of 3 (3, 12, 27) if $c_u = c_v$, and a non-multiple of 3 (7, 13, 19) if $c_u \neq c_v$; thus the global product is not a multiple of 3 if and only if all pairs are strictly unequal, preserving the exact same valid assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Lexicographically Smallest 3-Coloring, which is NP-complete.
</PRESERVED_CLASS>
