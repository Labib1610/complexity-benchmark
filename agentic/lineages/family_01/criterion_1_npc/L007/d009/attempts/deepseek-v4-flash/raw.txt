We have three possible channel vectors:

- \( w_1 = (-1, \sqrt{3}) \)
- \( w_2 = (-1, -\sqrt{3}) \)
- \( w_3 = (2, 0) \)

The squared length of the sum of two vectors \( w_a + w_b \) is:

\[
\| w_a + w_b \|^2 = \|w_a\|^2 + \|w_b\|^2 + 2 w_a \cdot w_b
\]

First, compute \(\|w_i\|^2\):

- \(\|w_1\|^2 = (-1)^2 + (\sqrt{3})^2 = 1 + 3 = 4\)
- \(\|w_2\|^2 = 1 + 3 = 4\)
- \(\|w_3\|^2 = 2^2 + 0^2 = 4\)

So all have norm squared 4.

Now compute dot products:

- \( w_1 \cdot w_2 = (-1)(-1) + (\sqrt{3})(-\sqrt{3}) = 1 - 3 = -2 \)
- \( w_1 \cdot w_3 = (-1)(2) + (\sqrt{3})(0) = -2 \)
- \( w_2 \cdot w_3 = (-1)(2) + (-\sqrt{3})(0) = -2 \)

So all distinct pairs have dot product \(-2\).

Thus for any two different channels \(a \neq b\):

\[
\|w_a + w_b\|^2 = 4 + 4 + 2(-2) = 8 - 4 = 4
\]

For the same channel \(a = b\):

\[
\|w_a + w_a\|^2 = 4 + 4 + 2(4) = 8 + 8 = 16
\]

So the stress is 4 if the two nodes have different channels, and 16 if they have the same channel.

We need the sum over all edges to be exactly \(4m\).

If all edges connect different channels, each contributes 4, sum = \(4m\).  
If any edge connects same channels, that edge contributes 16, making sum > \(4m\).

Thus the condition is: **No edge may connect two nodes with the same channel**.

So the problem reduces to:  
Given a graph, can we 3-color it (with colors 1,2,3) such that adjacent vertices have different colors?  
If yes, output the lexicographically smallest such coloring.

This is exactly graph 3-coloring, which is NP-hard in general, but \(n \le 40\) is small enough for backtracking with pruning.

We can solve with backtracking: assign colors to vertices in order, try smallest color first, check constraints.

Implementation:

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def backtrack(idx):
    if idx == n:
        return True
    for c in range(3):
        ok = True
        for nb in adj[idx]:
            if color[nb] == c:
                ok = False
                break
        if ok:
            color[idx] = c
            if backtrack(idx + 1):
                return True
            color[idx] = -1
    return False

if backtrack(0):
    print("YES")
    print(" ".join(str(c + 1) for c in color))
else:
    print("NO")
```
