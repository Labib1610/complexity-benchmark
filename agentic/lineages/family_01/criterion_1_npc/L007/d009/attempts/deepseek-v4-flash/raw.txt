We can model the three frequency bands as the vertices of an equilateral triangle.  
The dot product between two distinct bands is always \(-\frac12\), and between a band and itself is \(1\).  

From the formula:

\[
D_{u,v} = \frac{2}{3}(1 - \mathbf{p}_{s_u} \cdot \mathbf{p}_{s_v})
\]

- If \(s_u = s_v\): dot = 1 → \(D = 0\)  
- If \(s_u \neq s_v\): dot = \(-\frac12\) → \(D = 1\)

So the total drift \(W\) equals the number of struts connecting *different* bands.  
We need \(W = m\), meaning **every strut must connect different bands**.  

Thus the problem reduces to:  
Can we 3-color the graph such that no edge has the same color on both ends?  
That is exactly checking if the graph is 3-colorable.

Since \(n \le 40\), we can use backtracking with pruning.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * n

    def backtrack(node):
        if node == n:
            return True
        # Try colors 0,1,2 (mapped to 1,2,3)
        for c in range(3):
            ok = True
            for nb in adj[node]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[node] = c
                if backtrack(node + 1):
                    return True
                color[node] = -1
        return False

    if backtrack(0):
        print("YES")
        print(" ".join(str(c + 1) for c in color))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
