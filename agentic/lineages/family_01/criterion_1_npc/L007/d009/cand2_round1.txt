<METHOD_NAME>Vector Dot-Product Minimum Bounding</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the easily recognized modular arithmetic formula with a dot product of specific 3D vectors. The vectors are chosen such that their dot product is 2 for identical assignments and 1 for distinct assignments. Because the sum of $m$ terms (each $\ge 1$) must exactly equal $m$, the model must deduce that every term must be exactly 1, which forces a proper 3-coloring. This breaks surface-level pattern matching and requires multi-step deductive reasoning to realize it is a graph coloring problem, preventing the automatic application of MRV/degree ordering heuristics needed to pass within the time limit.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Orbital Resonance Alignment

Time limit: 2 s   Memory limit: 256 MB

A space station's main stabilizing ring has exactly 40 mounting bays. Currently, $n$ of these bays contain an active gyroscope, with at least one gyroscope always operational to maintain basic telemetry. To maintain operational equilibrium, each gyroscope $i$ (for $1 \le i \le n$) must be tuned to a frequency band $s_i \in \{1, 2, 3\}$.

Each band corresponds to a specific 3-dimensional phase vector:
- Band 1: $V_1 = (1, 1, 0)$
- Band 2: $V_2 = (0, 1, 1)$
- Band 3: $V_3 = (1, 0, 1)$

The station's structural integrity is maintained by $m$ critical load-bearing struts. Each strut connects a distinct pair of gyroscopes. The number of struts $m$ can be any valid count from zero up to a fully interconnected network where every active gyroscope is connected to every other active gyroscope.

The interaction between connected gyroscopes generates a resonance drift. For a strut connecting gyroscope $u$ and gyroscope $v$, the resonance drift $D_{u,v}$ is the standard dot product of their assigned phase vectors:
$D_{u,v} = V_{s_u} \cdot V_{s_v}$

The total system drift $W$ is the sum of the resonance drifts across all $m$ struts:
$W = \sum_{j=1}^m D_{u_j, v_j}$

To achieve perfect structural stability, the total system drift must be exactly equal to the number of struts (that is, $W = m$).

Your task is to determine whether there exists a valid frequency assignment for all gyroscopes $1 \dots n$ such that the total system drift $W$ is exactly $m$. If such an assignment exists, you must provide one.

## Input
The first line contains two integers $n$ and $m$ — the number of active gyroscopes and the number of struts.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating a strut connecting gyroscope $u$ and gyroscope $v$. Each strut is listed at most once.

## Output
If it is impossible to align the gyroscopes to the required drift state, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2, 3\}$), with $s_i$ representing the frequency band assigned to gyroscope $i$. Any valid assignment is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```
*Explanation for Example 1:*
Assigning frequency bands 1, 2, 3, 3 yields the following phase vectors:
- Gyroscope 1 (Band 1): $V_1 = (1, 1, 0)$
- Gyroscope 2 (Band 2): $V_2 = (0, 1, 1)$
- Gyroscope 3 (Band 3): $V_3 = (1, 0, 1)$
- Gyroscope 4 (Band 3): $V_3 = (1, 0, 1)$

Resonance drifts for each strut:
- Strut (1, 2): $V_1 \cdot V_2 = (1)(0) + (1)(1) + (0)(1) = 1$
- Strut (1, 3): $V_1 \cdot V_3 = (1)(1) + (1)(0) + (0)(1) = 1$
- Strut (2, 3): $V_2 \cdot V_3 = (0)(1) + (1)(0) + (1)(1) = 1$
- Strut (1, 4): $V_1 \cdot V_3 = (1)(1) + (1)(0) + (0)(1) = 1$
- Strut (2, 4): $V_2 \cdot V_3 = (0)(1) + (1)(0) + (1)(1) = 1$

The total system drift $W$ is $1 + 1 + 1 + 1 + 1 = 5$. Since $m = 5$, the configuration achieves the target drift and is stable.

<RATIONALE>
I replaced the modular arithmetic formula with a 3D vector dot product that evaluates to 2 for identical bands and 1 for distinct bands. I also moved the explicit numeric bounds for $n$ and $m$ into the scenario description (Strategy S07). This forces the model to mathematically deduce that a sum of $m$ terms (each $\ge 1$) can only equal $m$ if every single term is exactly 1, thereby hiding the graph coloring nature of the problem and preventing the automatic application of MRV/degree heuristics.
</RATIONALE>
<PRESERVED_ANSWER>
The dot product of the phase vectors evaluates to 2 for equal bands and 1 for distinct bands; since the sum of $m$ such terms must exactly equal $m$, every term must be exactly 1, meaning no two connected gyroscopes can share the same band, which is exactly the proper 3-coloring requirement of the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains mathematically identical to determining whether the underlying graph can be properly 3-colored, keeping it NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might struggle to extract the exact numerical bounds ($1 \le n \le 40$ and $0 \le m \le n(n-1)/2$) from the text description, though the phrasing strictly and unambiguously implies them.
</RISK>
