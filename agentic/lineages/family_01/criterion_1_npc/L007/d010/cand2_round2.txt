# Problem A — Quantum Decoherence Stabilization

Time limit: 2 s   Memory limit: 256 MB

A quantum computing array consists of $n$ qubits. To maintain coherence, each qubit must be initialized into one of three quantum states, denoted by $s_i \in \{1, 2, 3\}$.

The array's stability is constrained by $m$ entanglement links, each connecting a specific pair of qubits. The interaction between connected qubits generates a quantum decoherence penalty.

For a link connecting qubit $u$ and qubit $v$, the decoherence penalty $I_{u,v}$ is determined by their assigned states according to the following polynomial:
$I_{u,v} = s_u^4 + s_v^4 - 4s_u^3 s_v - 4s_u s_v^3 + 6s_u^2 s_v^2 - 5s_u^2 - 5s_v^2 + 10s_u s_v + 4$

To achieve fault-tolerant quantum computation, every entanglement link must be perfectly stabilized. That is, for every link in the system, its decoherence penalty must be exactly $I_{u,v} = 0$.

Your task is to determine whether there exists a valid state assignment for all qubits $1 \dots n$ such that every link achieves a decoherence penalty of exactly $0$. If such an assignment exists, you must provide one.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of qubits and the number of entanglement links.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating a link connecting qubit $u$ and qubit $v$. Each link is listed at most once.

## Output
If it is impossible to initialize the qubits to achieve the required state, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2, 3\}$), with $s_i$ representing the state assigned to qubit $i$. Any valid assignment is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```
*Explanation for Example 1:*
Assigning states 1, 2, 3, 3 yields the following:
- Link (1, 2) with states 1 and 2: $I_{1,2} = 1 + 16 - 8 - 32 + 24 - 5 - 20 + 20 + 4 = 0$.
- Link (1, 3) with states 1 and 3: $I_{1,3} = 1 + 81 - 12 - 108 + 54 - 5 - 45 + 30 + 4 = 0$.
- Link (2, 3) with states 2 and 3: $I_{2,3} = 16 + 81 - 96 - 216 + 216 - 20 - 45 + 60 + 4 = 0$.
- Link (1, 4) with states 1 and 3: $I_{1,4} = 0$.
- Link (2, 4) with states 2 and 3: $I_{2,4} = 0$.

Every link achieves a decoherence penalty of exactly 0. The configuration is valid.

Output:
