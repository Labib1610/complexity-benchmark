<STATEMENT>
# Problem A — Magnetic Levitation Network

Time limit: 2 s   Memory limit: 256 MB

A transport network has $n$ levitation nodes. To maintain operational equilibrium, each node must be configured to a polarity mode $s_i \in \{1, 2, 3\}$.

The network's structural integrity depends on $m$ load-bearing rails, each connecting a specific pair of nodes. The interaction between connected nodes generates an orthogonal tension.

Each polarity mode $s_i$ emits a 3-dimensional signature vector $\mathbf{v}_{s_i}$:
- Mode 1: $\mathbf{v}_1 = (1, 0, 0)$
- Mode 2: $\mathbf{v}_2 = (0, 1, 0)$
- Mode 3: $\mathbf{v}_3 = (0, 0, 1)$

For a rail connecting node $u$ and node $v$, we construct a $3 \times 3$ matrix $M_{u,v}$ whose first row is $\mathbf{v}_{s_u}$, second row is $\mathbf{v}_{s_v}$, and third row is the all-ones vector $(1, 1, 1)$. 
The orthogonal tension $T_{u,v}$ generated by this rail is calculated as the square of the determinant of this matrix:
$T_{u,v} = (\det M_{u,v})^2$

The total network tension $W$ is the sum of the orthogonal tensions across all $m$ rails:
$W = \sum_{j=1}^m T_{u_j, v_j}$

To achieve optimal levitation, the total network tension must be exactly equal to the number of rails. (That is, $W = m$).

Your task is to determine whether there exists a valid polarity assignment for all nodes $1 \dots n$ such that the total network tension $W$ is exactly $m$. If such an assignment exists, you must provide one.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of levitation nodes and the number of rails.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating a rail connecting node $u$ and node $v$. Each rail is listed at most once.

## Output
If it is impossible to configure the nodes to the required tension state, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2, 3\}$), with $s_i$ representing the polarity mode assigned to node $i$. Any valid assignment is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```
*Explanation for Example 1:*
Assigning polarity modes 1, 2, 3, 3 yields the following:
- Rail (1, 2) with modes 1 and 2: $M_{1,2}$ has rows $(1, 0, 0)$, $(0, 1, 0)$, and $(1, 1, 1)$. $\det M_{1,2} = 1$. $T_{1,2} = 1^2 = 1$.
- Rail (1, 3) with modes 1 and 3: $M_{1,3}$ has rows $(1, 0, 0)$, $(0, 0, 1)$, and $(1, 1, 1)$. $\det M_{1,3} = -1$. $T_{1,3} = (-1)^2 = 1$.
- Rail (2, 3) with modes 2 and 3: $M_{2,3}$ has rows $(0, 1, 0)$, $(0, 0, 1)$, and $(1, 1, 1)$. $\det M_{2,3} = 1$. $T_{2,3} = 1^2 = 1$.
- Rail (1, 4) with modes 1 and 3: $M_{1,4}$ has rows $(1, 0, 0)$, $(0, 0, 1)$, and $(1, 1, 1)$. $\det M_{1,4} = -1$. $T_{1,4} = (-1)^2 = 1$.
- Rail (2, 4) with modes 2 and 3: $M_{2,4}$ has rows $(0, 1, 0)$, $(0, 0, 1)$, and $(1, 1, 1)$. $\det M_{2,4} = 1$. $T_{2,4} = 1^2 = 1$.

The total network tension $W$ is $1 + 1 + 1 + 1 + 1 = 5$. Since $m = 5$, the configuration achieves the target tension.

<RATIONALE>
Replaced the explicit dot-product equation from the seed with a mathematically equivalent linear algebra formulation. By computing the squared determinant of a matrix built from standard basis vectors, the interaction exactly maps to 1 for distinct modes and 0 for identical modes. This forces the model to evaluate the matrix determinant rather than pattern-matching the seed's formula to graph coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The squared determinant of the specified matrix evaluates to 1 if the assigned modes are distinct and 0 if they are identical; therefore, achieving a total tension equal to the number of rails requires all connected pairs to have distinct modes, exactly preserving the proper 3-coloring logic of the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem requires assigning one of 3 states to each vertex such that no edge connects variables of the same state, which is precisely the NP-complete 3-COLORING problem.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the row ordering in the matrix construction, but since the determinant is squared, the sign change from swapping rows does not affect the tension value, leaving no ambiguity in the final calculation.
</RISK>
