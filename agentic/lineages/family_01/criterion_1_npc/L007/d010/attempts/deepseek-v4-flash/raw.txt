We can model the problem as a graph coloring problem with 3 colors, where the score of an edge depends on the colors of its endpoints.  

The matrices are permutation matrices, and the trace of \(A_{c_u} A_{c_v}^T\) is 1 if the colors are the same, and 0 otherwise.  
So the total score is the number of edges whose endpoints have the same color.  
We need this sum to be 0, meaning no edge can have endpoints with the same color.  

Thus, the problem reduces to: can we 3-color the graph such that adjacent nodes have different colors?  
If yes, output the lexicographically smallest such coloring.

We can solve this with backtracking, trying colors 1, 2, 3 in order for each node, and pruning when a conflict occurs.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n
    
    def backtrack(idx):
        if idx == n:
            return True
        for c in range(1, 4):
            ok = True
            for nb in adj[idx]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[idx] = c
                if backtrack(idx + 1):
                    return True
                color[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
