# Frequency Band Partitioning

**Time limit:** 2 s  
**Memory limit:** 256 MB

## Description
A signal processing platform manages $n$ active transmitter units numbered $1$ through $n$. To avoid cross-talk, each unit must be set to transmit on one of three available frequency bands, labeled $1$, $2$, and $3$.

Certain pairs of transmitters interfere with each other when operating on the same frequency band. You are given a list of all interfering pairs.

Your goal is to determine if every transmitter can be assigned one of the three frequency bands such that no two interfering transmitters share the same band. If a valid configuration exists, determine the assignment sequence $(s_1, s_2, \dots, s_n)$ that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ — the number of active transmitters and the number of pair interference constraints, respectively. A single chassis accommodates at most 40 transmitters, so $1 \le n \le 40$. The total number of pairwise interference links satisfies $0 \le m \le \frac{n(n-1)}{2}$.

Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$) indicating that transmitter $u$ and transmitter $v$ interfere with each other.

## Output
If no valid band assignment exists, print `NO` on a single line.

Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ ($s_i \in \{1, 2, 3\}$), where $s_i$ denotes the frequency band assigned to transmitter $i$. If multiple valid assignments exist, output the lexicographically smallest sequence $(s_1, s_2, \dots, s_n)$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
