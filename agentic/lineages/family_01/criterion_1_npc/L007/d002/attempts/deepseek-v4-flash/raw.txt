We can check the condition for each pair of shifts:

- (1,1): (1+1)=2, (1+1)=2, remainder 0 → invalid  
- (1,2): (1+4)=5, (1+2)=3, remainder 2 → valid  
- (1,3): (1+9)=10, (1+3)=4, remainder 2 → valid  
- (2,2): (4+4)=8, (2+2)=4, remainder 0 → invalid  
- (2,3): (4+9)=13, (2+3)=5, remainder 3 → valid  
- (3,3): (9+9)=18, (3+3)=6, remainder 0 → invalid  

So the only invalid pairs are when both are assigned the same shift.  
Thus, the problem reduces to: can we assign each person a shift 1, 2, or 3 such that no dependency edge connects two people with the same shift?  
That is exactly a 3-coloring problem on a graph with up to 40 nodes.

We can solve it with backtracking.

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n

def dfs(node):
    for c in range(1, 4):
        ok = True
        for nei in adj[node]:
            if color[nei] == c:
                ok = False
                break
        if ok:
            color[node] = c
            if node == n - 1:
                return True
            if dfs(node + 1):
                return True
            color[node] = 0
    return False

if dfs(0):
    print("YES")
    print(" ".join(map(str, color)))
else:
    print("NO")
```
