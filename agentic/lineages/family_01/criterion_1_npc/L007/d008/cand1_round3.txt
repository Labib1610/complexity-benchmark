# Problem A — Thermal Resonance Tuning

Time limit: 2 s   Memory limit: 256 MB

A reactor core contains $n$ thermal modules. To maintain stability, every module must receive exactly one resonance state $s_i$ from the set $\{1, 2, 3\}$.

The overall state of the core is represented by a symmetric interaction matrix $M$ of size $n \times n$. The matrix element at row $i$ and column $j$ is defined by the sum of their respective states: $M_{i,j} = s_i + s_j$.

The diagnostic system has identified $m$ critical interactions between specific pairs of modules. To prevent core failure, every critical interaction must satisfy a strict localized stability condition.

For each critical interaction between module $u$ and module $v$, consider the $2 \times 2$ principal submatrix of $M$ formed by intersecting rows $u$ and $v$ with columns $u$ and $v$. The determinant of this $2 \times 2$ submatrix is calculated as $(M_{u,u} \times M_{v,v}) - (M_{u,v} \times M_{v,u})$. The core is stable if and only if, for every critical interaction, this determinant is strictly negative (less than zero).

Your task is to determine whether there exists a valid state assignment for all modules $1 \dots n$ such that the determinant condition is satisfied for all $m$ critical interactions. If such an assignment exists, you must provide one.

## Input
The first line contains two integers $n$ and $m$ — the number of thermal modules and the number of critical interactions ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating a critical interaction between module $u$ and module $v$. Each interaction is listed at most once.

## Output
If it is impossible to calibrate the modules to the required energy state, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2, 3\}$), with $s_i$ representing the resonance state assigned to module $i$. Any valid assignment is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```
*Explanation for Example 1:*
Assigning states 1, 2, 3, 3 yields the following:
- Interaction (1, 2): The submatrix for modules 1 and 2 has $M_{1,1} = 1+1=2$, $M_{2,2} = 2+2=4$, and $M_{1,2} = M_{2,1} = 1+2=3$. Its determinant is $(2 \times 4) - (3 \times 3) = 8 - 9 = -1$. Since $-1 < 0$, the condition is satisfied.
- Interaction (1, 3): $M_{1,1} = 2$, $M_{3,3} = 6$, $M_{1,3} = 4$. Determinant is $(2 \times 6) - (4 \times 4) = 12 - 16 = -4 < 0$.
- Interaction (2, 3): $M_{2,2} = 4$, $M_{3,3} = 6$, $M_{2,3} = 5$. Determinant is $(4 \times 6) - (5 \times 5) = 24 - 25 = -1 < 0$.
- Interaction (1, 4): Modules 1 and 4 have states 1 and 3. Determinant is $-4 < 0$.
- Interaction (2, 4): Modules 2 and 4 have states 2 and 3. Determinant is $-1 < 0$.
All critical interactions satisfy the condition.

Following the expert review, the global polynomial summation was removed entirely to eliminate task drift and contradiction. Instead, a direct pairwise rule is applied to every listed interaction. To prevent the model from immediately pattern-matching this to graph 3-coloring and applying degree-ordered backtracking, the inequality constraint is disguised as a linear algebra property. The condition is framed as requiring a strictly negative determinant for a 2x2 principal submatrix of a state-sum matrix. This forces the model to either blindly implement a continuous/matrix solver or expend reasoning steps to prove the equivalence, potentially missing the graph heuristics required to pass the time limit on dense instances.
</RATIONALE>
<PRESERVED_ANSWER>
The determinant of the 2x2 submatrix for modules u and v is (2*s_u)*(2*s_v) - (s_u + s_v)^2, which simplifies exactly to -(s_u - s_v)^2; this value is strictly negative if and only if s_u ≠ s_v, preserving the exact set of valid assignments (proper 3-colorings).
</PRESERVED_ANSWER>
