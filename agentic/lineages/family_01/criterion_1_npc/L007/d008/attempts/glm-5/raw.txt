Looking at this problem:

- Channels 1,2,3 have signatures 3,5,6 (binary 011,101,110)
- XOR popcount between different channels is always 2, same channel is 0
- Sum of scores = 2m means every link must connect different channels
- This is exactly graph 3-coloring

For n≤40, I use a meet-in-the-middle approach: split nodes into two halves, enumerate valid colorings of each half, then combine. To find lexicographically smallest, I process the first half in increasing order and the second half in decreasing order, using binary search to find the smallest valid second-half coloring.

    # Rebuild second half: for each valid coloring, precompute for each first-half node
    # the set of forbidden colors (as a 3-bit mask per first-half node, packed in base-8)
    second_colorings = []
