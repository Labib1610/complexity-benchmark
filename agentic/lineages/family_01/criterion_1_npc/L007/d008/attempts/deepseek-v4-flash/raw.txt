We can model this as a graph coloring problem with 3 colors, but with a twist: the separation score for each edge must be exactly 2 (since each edge contributes 2 to the total sum of `2m`).  

The signatures are:
- Channel 1 → `011` (3)
- Channel 2 → `101` (5)
- Channel 3 → `110` (6)

The XOR popcount between two channels:
- 1 and 2: `011 XOR 101 = 110` → popcount 2  
- 1 and 3: `011 XOR 110 = 101` → popcount 2  
- 2 and 3: `101 XOR 110 = 011` → popcount 2  

So **any two different channels** give exactly a score of 2.  
If the channels are the same, XOR = 0 → score 0.  

Thus, the condition “sum of separation scores = 2m” means **every edge must connect nodes with different channels**.  

So the problem reduces to:  
**Is the graph 3-colorable?**  
If yes, output the lexicographically smallest 3-coloring (channels 1,2,3).

We can solve it with backtracking since n ≤ 40.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    colors = [0] * n  # 0 = uncolored, 1..3 = channels
    
    def backtrack(node):
        if node == n:
            return True
        # Try colors 1,2,3 in order for lexicographic smallest
        for c in (1, 2, 3):
            ok = True
            for nb in adj[node]:
                if colors[nb] == c:
                    ok = False
                    break
            if ok:
                colors[node] = c
                if backtrack(node + 1):
                    return True
                colors[node] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(str(c) for c in colors))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
