<METHOD_DESCRIPTION>Replaces the explicit pairwise energy summation with a global matrix trace equation that mathematically evaluates to a specific constant if and only if the underlying graph is properly 3-colored, forcing multi-step algebraic deduction to uncover the local pruning condition.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Security Clearance Resolution

Time limit: 2 s   Memory limit: 256 MB

A secure facility is configuring the access levels for a network of $n$ interdependent modules. Each module must receive exactly one access level from the set $\{1, 2, 3\}$.

To prevent critical vulnerabilities, the facility evaluates the entire network's configuration using a global state matrix based on $m$ separation protocols. Each protocol specifies a pair of interacting modules. 

The evaluation process assigns a 3-dimensional state vector $V_j$ to each module $j$ based on its chosen access level:
- Level 1: $V_j = (1, 1, -2)$
- Level 2: $V_j = (1, -2, 1)$
- Level 3: $V_j = (-2, 1, 1)$

Let $X$ be an $n \times 3$ matrix where the $j$-th row is the state vector $V_j$ of module $j$. 
Let $M$ be the $n \times n$ symmetric protocol matrix, where $M_{u,v} = 1$ if there is a separation protocol linking module $u$ and module $v$, and $M_{u,v} = 0$ otherwise. (Note that $M_{u,u} = 0$ for all $u$).

The network is deemed completely stable if and only if the trace of the matrix product $X^T M X$ is exactly $-6m$.

The test suite contains maximum-size adversarial instances. Naive generation of all assignments will result in an astronomical number of dead ends and will exceed the time limit before a stable state is found or proven impossible.

Your task is to determine if there exists a complete access assignment that makes the network completely stable. If at least one valid assignment exists, you must identify the one that is lexicographically smallest.

## Input
The first line of the input provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). These represent the total number of modules and the number of separation protocols, respectively.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that module $u$ and module $v$ are linked by a separation protocol.

## Output
If no completely stable assignment can be found, print `NO` on a single line.
If a stable assignment is possible, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$) representing the access level assigned to each respective module. Among all valid stable configurations, the sequence of access levels you output must be the lexicographically smallest (i.e., comparing the access level of module 1 first, then module 2, and so forth).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The pairwise interference formula was replaced with a global matrix trace condition ($\text{Tr}(X^T M X) = -6m$). This forces the model to perform a multi-step algebraic deduction (expanding the trace into a sum of dot products, evaluating the dot products for equal/unequal vectors, and proving that the trace sum reaches exactly $-6m$ if and only if no two linked modules share a state) rather than simply reading a pairwise zero-energy condition.
</RATIONALE>
<PRESERVED_ANSWER>
The trace of $X^T M X$ algebraically expands to exactly $2 \sum_{(u,v) \in E} (V_{c_u} \cdot V_{c_v})$, which evaluates to $-6m$ if and only if all connected modules have distinct access levels, preserving the exact same valid configurations.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically first valid 3-coloring of a graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the row assignment of matrix $X$ if they are unfamiliar with 1-based vs 0-based indexing in matrix construction, though the description "the $j$-th row is the state vector $V_j$" is mathematically standard.
</RISK>
