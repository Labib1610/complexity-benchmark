We can simplify the coupling energy formula first.  
For states in {1, 2, 3}, the formula simplifies to:

- (1,1): 0  
- (1,2): 0  
- (1,3): 0  
- (2,2): 0  
- (2,3): 0  
- (3,3): 0  

So **every pair gives 0 energy** regardless of states.  
That means the total energy is always 0 for any assignment.  

Thus the answer is always `YES` with any valid assignment (e.g., all 1s), except when there are no modules? But n ≥ 1, so always possible.

```python
n, m = map(int, input().split())
for _ in range(m):
    input()
print("YES")
print(" ".join(["1"] * n))
```
