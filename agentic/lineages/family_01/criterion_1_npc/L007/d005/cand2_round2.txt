<STATEMENT>
# Problem A — Security Clearance Resolution

Time limit: 2 s   Memory limit: 256 MB

A secure facility is configuring the access tiers for a network of $n$ interdependent modules. Each module must receive exactly one access tier from the set $\{1, 2, 3\}$.

To prevent critical vulnerabilities, the facility has established $m$ separation protocols. Each protocol specifies a pair of interacting modules. When two distinct modules $u$ and $v$ are linked by a protocol, their assigned access tiers $c_u$ and $c_v$ must satisfy a specific algebraic safety condition: the value $(c_u - c_v)^2$ must not be a multiple of 3. The interacting constraints of these protocols create complex, system-wide dependencies.

Please take note: the test suite contains instances specifically designed to be adversarial. Maximum-size test cases are structured such that attempting to resolve the configuration by simply iterating through modules in numerical order and testing tiers 1, 2, 3 sequentially will result in an astronomical number of dead ends before a valid state is found or proven impossible.

Your task is to determine if there exists a complete access assignment that respects all separation protocols. If at least one valid assignment exists, you must identify the one that is lexicographically smallest.

## Input
The first line of the input provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). These represent the total number of modules and the number of separation protocols, respectively.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that module $u$ and module $v$ are linked by a separation protocol.

## Output
If no valid assignment can satisfy all protocols, print `NO` on a single line.
If a valid assignment is possible, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$) representing the access tier assigned to each respective module. Among all valid configurations, the sequence of access tiers you output must be the lexicographically smallest (i.e., comparing the access tier of module 1 first, then module 2, and so forth).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

For values restricted to {1, 2, 3}, this is mathematically equivalent to requiring `c_u != c_v`. The explicit numerical bounds have been fully restored in the Input section to ensure strict contract checking passes.
</RATIONALE>
