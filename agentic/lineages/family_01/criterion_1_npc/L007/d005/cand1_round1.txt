<METHOD_DESCRIPTION>Replaces the explicit "strictly different states" condition with a mathematical equivalence: the polynomial s_u^2 + s_u * s_v + s_v^2 must not be a multiple of 3. For variables in {1, 2, 3}, this is exactly true if and only if s_u != s_v. By framing the exclusion as an arithmetic property of an "interaction energy", models are prevented from immediately recognizing the problem as Graph 3-Coloring. This breaks their reliance on graph-specific heuristics like bitmask adjacency and degree-based variable ordering (MRV), forcing a generic backtracking approach that will time out on adversarial NP-complete instances.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Thermal Resonance Tuning

Time limit: 2 s   Memory limit: 256 MB

A reactor core contains $n$ thermal modules. To maintain stability, each module must be calibrated to a resonance state, represented by an integer $s_i \in \{1, 2, 3\}$.

The diagnostic system has identified $m$ critical interactions. Each interaction specifies two modules, $u$ and $v$, which are physically positioned such that they will cause catastrophic feedback if their combined quantum interference factor is a multiple of 3.

Specifically, for every recorded interaction between module $u$ and module $v$, the interference factor is calculated as $s_u^2 + s_u \cdot s_v + s_v^2$. To prevent core failure, the calibration sequence must ensure that this factor is **not** a multiple of 3.

Your task is to determine whether there exists a valid state assignment for all modules $1 \dots n$ such that every critical interaction is mitigated. If such an assignment exists, you must provide one.

## Input
The first line contains two integers $n$ and $m$ — the number of thermal modules and the number of critical interactions ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the following $m$ lines contains two integers $u$ and $v$, indicating a critical interaction between module $u$ and module $v$.

## Output
If it is impossible to calibrate the modules safely, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2, 3\}$), with $s_i$ representing the resonance state assigned to module $i$. Any valid assignment is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit "strictly different states" condition with a mathematically equivalent polynomial condition: $s_u^2 + s_u s_v + s_v^2$ must not be a multiple of 3. For variables in $\{1, 2, 3\}$, this expression is a multiple of 3 if and only if $s_u = s_v$. This algebraic framing prevents models from immediately recognizing the problem as Graph 3-Coloring, stopping them from applying graph-specific heuristics like bitmask adjacency and degree-based ordering (MRV) which are necessary to pass the 2-second time limit on adversarial instances.
</RATIONALE>
<PRESERVED_ANSWER>
For any two states in {1, 2, 3}, the value of s_u^2 + s_u*s_v + s_v^2 is a multiple of 3 if and only if s_u = s_v (yielding 3, 12, or 27), whereas distinct states yield 7, 13, or 19; thus, the valid assignments are exactly identical to the original "strictly different" requirement.
</PRESERVED_ANSWER>
