<STATEMENT>
# Problem A — Modular Resonance

Time limit: 2 s   Memory limit: 256 MB

A series of $n$ harmonic oscillators must be calibrated. You must assign each oscillator $i$ a resonance state $s_i$, which must be an integer chosen from $\{1, 2, 3\}$.

You are provided with $m$ interference records. Each record specifies two oscillators $u$ and $v$ that are spatially coupled.

To prevent destructive feedback, every coupled pair must satisfy a specific phase condition. For each record $(u, v)$, the combined energy factor, calculated as $s_u^2 + s_v^2 + s_u s_v$, must not be a multiple of 3.

Your task is to assign exactly one resonance state to each oscillator such that this safety condition is satisfied for all $m$ records, or determine that no such calibration exists.

## Input
The first line provides two integers $n$ and $m$ — the total number of oscillators and the number of interference records ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the subsequent $m$ lines provides two integers $u$ and $v$, representing a pair of coupled oscillators.

## Output
If there is no valid calibration, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2, 3\}$), with $s_i$ representing the resonance state assigned to oscillator $i$. Any valid calibration is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The direct inequality constraint ($s_u \neq s_v$) was replaced with an algebraic condition ($s_u^2 + s_v^2 + s_u s_v \not\equiv 0 \pmod 3$). Because this condition is mathematically identical to $s_u \neq s_v$ exclusively over the domain $\{1, 2, 3\}$, the problem logic remains identical. However, by removing the semantic trigger of "strictly different", the model is forced to either evaluate the formula's truth table to rediscover the graph coloring structure, or implement a naive backtracking search that will time out without the degree-descending heuristics.
</RATIONALE>
<PRESERVED_ANSWER>
Over the domain {1, 2, 3}, the expression $s_u^2 + s_v^2 + s_u s_v$ is a multiple of 3 if and only if $s_u = s_v$, meaning the new condition restricts pairs in exactly the same way as the original inequality.
</PRESERVED_ANSWER>
