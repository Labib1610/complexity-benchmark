# Problem A — Thermal Resonance

Time limit: 2 s   Memory limit: 256 MB

A satellite chassis houses $n$ internal modules. The thermal dissipation capacity of the chassis strictly limits the total module count to a maximum of 40 (with a minimum of 1). 

Each module $i$ must be calibrated with a frequency state $s_i$. To ensure compatibility with the onboard oscillators, the assigned frequency state $s_i$ must be an integer that satisfies the polynomial equation:
$(s_i - 1)(s_i - 2)(s_i - 3) = 0$

You are given $m$ electromagnetic interference reports. The number of reports $m$ is non-negative and will not exceed the total number of unique two-module combinations possible within the chassis. Each report specifies two modules $u$ and $v$ that are mounted in close proximity.

To prevent thermal resonance cascades, any two modules listed in a report must have their frequency states assigned such that they satisfy the absolute difference inequality:
$|s_u - s_v| \ge 1$

Your task is to determine if there exists a valid sequence of frequency states for all $n$ modules that satisfies every interference report, or to determine that no such sequence exists.

## Input
The first line provides the two integers $n$ and $m$.
Each of the following $m$ lines provides two integers $u$ and $v$, representing an interference report between module $u$ and module $v$.

## Output
If no valid calibration exists, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ separated by spaces, where $s_i$ is the frequency state assigned to module $i$. Any sequence of states that satisfies all conditions is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
