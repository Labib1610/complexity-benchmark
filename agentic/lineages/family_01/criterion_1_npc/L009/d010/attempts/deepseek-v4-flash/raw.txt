We need to check when the harmonic mean  
\[
H(u,v) = \frac{2 c_u c_v}{c_u + c_v}
\]  
is an integer.  

Let’s analyze the possible pairs of values from {1,2,3}:

- (1,1): \( \frac{2}{2} = 1 \) → integer → **not allowed**
- (1,2): \( \frac{4}{3} \) → not integer → allowed
- (1,3): \( \frac{6}{4} = 1.5 \) → not integer → allowed
- (2,2): \( \frac{8}{4} = 2 \) → integer → **not allowed**
- (2,3): \( \frac{12}{5} = 2.4 \) → not integer → allowed
- (3,3): \( \frac{18}{6} = 3 \) → integer → **not allowed**

So the only forbidden pairs are (1,1), (2,2), (3,3).  
That means: **No two connected vertices may have the same value.**

Thus the problem reduces to:  
Given a graph with n ≤ 40, color each vertex with 1, 2, or 3 such that no edge connects two vertices of the same color. Find the lexicographically smallest such coloring, or report NO.

This is exactly the **graph 3-coloring** problem, which is NP-hard in general, but n ≤ 40 is small enough for backtracking with pruning.

We can solve with backtracking:  
- Assign colors in order from vertex 1 to n.  
- At each step, try color 1, then 2, then 3, and check if it conflicts with already colored neighbors.  
- If we reach the end, we have a valid coloring.  
- Since we try colors in increasing order, the first found solution is lexicographically smallest.

We must also handle m=0 (no edges) — then all 1’s is valid.

Complexity: worst-case exponential, but n=40 with 3 colors and pruning is feasible for typical constraints.

Let’s implement.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n
    
    def backtrack(idx):
        if idx == n:
            return True
        for c in (1, 2, 3):
            ok = True
            for nb in adj[idx]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[idx] = c
                if backtrack(idx + 1):
                    return True
                color[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
