# Problem A — Sequence Properties

Time limit: 2 s
Memory limit: 256 MB

You need to formulate a linear sequence of $n$ chemical additives. For each additive $i$ in the sequence, you must choose a concentration level $c_i$ from the set $\{1, 2, 3\}$.

The formulation is subject to $m$ known reactivity constraints. Each constraint is given as a pair of distinct positions $(u, v)$, indicating that the additives at these two indices will interact. To maintain overall structural stability, every interacting pair must pass a specific resonance check based on their chosen concentration levels.

When the additive at index $u$ and the additive at index $v$ interact, they produce two interference resonance values, calculated as:
$R_1(u, v) = 11 c_u + 2 c_v$
$R_2(u, v) = 2 c_u + 11 c_v$

To guarantee that the pair does not destabilize the sequence, the greatest common divisor (GCD) of these two resonance values must not exceed 5. If $\gcd(R_1(u, v), R_2(u, v)) > 5$, the interaction causes a critical failure.

Your task is to find a valid assignment of concentration levels that satisfies all $m$ constraints. If multiple valid assignments exist, you must output the lexicographically smallest one. A sequence of concentration levels $A$ is lexicographically smaller than sequence $B$ if $A$ contains a smaller value than $B$ at the first position where they differ. If it is impossible to satisfy all constraints simultaneously, you must indicate that no such sequence exists.

## Input
The first line of the input contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$) — the number of additives in the sequence and the number of reactivity constraints.
The next $m$ lines each contain two distinct integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing a constraint between the additive at index $u$ and the additive at index $v$.

## Output
If no valid sequence of concentration levels can be formed, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, output $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$), representing the lexicographically smallest valid sequence.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
