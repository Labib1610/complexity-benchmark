<STATEMENT>
# Problem A — Sensor Network Telemetry

Time limit: 2 s   Memory limit: 256 MB

A research team is deploying a network of $n$ telemetry sensors. Each sensor $i$ must be assigned a configuration factor $c_i$. To integrate with the receiver system, each of these factors must be chosen from the set $\{1, 2, 3\}$.

Due to physical proximity, certain pairs of sensors will interact. You are provided with a complete list of these $m$ interacting pairs. When two interacting sensors $u$ and $v$ broadcast, their combined signal harmonic is the product of their configuration factors, $c_u \times c_v$. To prevent severe resonance overlap, this product must not be a perfect square (i.e., it cannot be the square of any integer).

Your task is to assign a valid configuration factor to every sensor such that no interacting pair creates a perfect square product. If no valid configuration exists, you must determine that a safe configuration is impossible.

## Input
The first line contains two integers $n$ and $m$ — the number of sensors and the number of interaction conditions ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$). The sensors are numbered from 1 to $n$.
Each of the following $m$ lines contains two integers $u$ and $v$ — denoting that sensor $u$ and sensor $v$ interact with each other and their product must not be a perfect square.

## Output
If no valid configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$), with $c_i$ representing the factor allocated to sensor $i$. Among all valid configurations, output the lexicographically smallest sequence (compare $c_1$ first, then $c_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit "must not share the same channel" constraint with a mathematical condition where the product of the two assigned factors $c_u \times c_v$ must not be a perfect square. This removes the obvious phrasing of graph coloring, forcing the model to deduce that for values in $\{1, 2, 3\}$, a product is a perfect square if and only if the two values are equal.
</RATIONALE>
<PRESERVED_ANSWER>
The only perfect squares obtainable by multiplying two numbers from $\{1, 2, 3\}$ are 1, 4, and 9, which occur if and only if the two numbers are identical; thus, the constraint is logically equivalent to $c_u \neq c_v$, keeping all valid assignments and the lexicographical tie-break identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains exactly the lexicographically smallest 3-coloring problem on a graph with $n \le 40$, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
None. The mathematical definition of a perfect square is standard, and checking the finite set of possible products leaves no room for ambiguity.
</RISK>
