 We need to check the geometric condition: points \( P = (c_u, c_u^2, c_u^3) \), \( Q = (c_v, c_v^2, c_v^3) \), and \( R = (0,0,0) \) must not be collinear.  

Since \( R \) is the origin, collinearity means \( P \) and \( Q \) are scalar multiples of each other.  
For \( c_u, c_v \in \{1,2,3\} \), the vectors are:  
- 1 → (1,1,1)  
- 2 → (2,4,8)  
- 3 → (3,9,27)  

Check if any two are scalar multiples:  
- (1,1,1) and (2,4,8): not multiples.  
- (1,1,1) and (3,9,27): not multiples.  
- (2,4,8) and (3,9,27): not multiples.  

So any two distinct values from {1,2,3} are fine. The only invalid case is when \( c_u = c_v \), because then P and Q are identical (or scalar multiple with factor 1), making them collinear with origin.  

Thus the constraint is: **No edge can have both endpoints with the same value.**  

This is a graph coloring problem with 3 colors, where adjacent vertices must have different colors. We need the lexicographically smallest coloring.

We can solve with backtracking or greedy with checking. Since n ≤ 40, backtracking with pruning is fine.

We'll assign colors from 1 to 3 in order, checking constraints.

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n

def backtrack(idx):
    if idx == n:
        return True
    for c in range(1, 4):
        ok = True
        for nb in adj[idx]:
            if color[nb] == c:
                ok = False
                break
        if ok:
            color[idx] = c
            if backtrack(idx + 1):
                return True
            color[idx] = 0
    return False

if backtrack(0):
    print("YES")
    print(" ".join(map(str, color)))
else:
    print("NO")
```
