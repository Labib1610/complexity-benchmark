# Problem A — Schedule Constraints

Time limit: 2 s   Memory limit: 256 MB

A factory runs shifts labeled 1, 2, and 3. The factory employs a roster of workers. Certain workers have a restriction and must not be placed on the same shift as each other. The restrictions can form any arbitrary arrangement; no simplifying structure is guaranteed, and the test cases include adversarial configurations of conflicts that are specifically designed to be difficult to resolve.

Assign every worker to exactly one of the available shifts so that no restricted workers share a shift, or report that it is impossible.

## Input
The first line contains two integers n and m. The value n represents the number of workers; it is at least 1 and is capped at a maximum factory headcount of four full groups of ten workers each. The value m represents the number of restrictions, which ranges from zero up to the theoretical maximum where every worker conflicts with every other worker.
Each of the next m lines contains two integers u and v — two workers that cannot share a shift.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES on the first line. On the second line print n integers s₁ s₂ … sₙ (each in {1,2,3}), where sᵢ is the shift of worker i. Among all valid assignments output the lexicographically smallest sequence (compare s₁ first, then s₂, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

The problem description now explicitly warns that the restriction configurations can be adversarial and lack simplifying structure, forcing models to recognize the need for a search algorithm that can handle worst-case scenarios rather than relying on naive, unpruned backtracking. Additionally, the bare numeric bounds for `n` and `m` were replaced with scenario-based descriptions (four groups of ten; maximum possible pairwise conflicts) to require indirect derivation of the constraints.
</RATIONALE>
