# Problem A — Sensor Network Telemetry

Time limit: 2 s   Memory limit: 256 MB

A research team is deploying a network of $n$ telemetry sensors. The central receivers are configured to operate on exactly three distinct frequency channels, designated as channel 1, channel 2, and channel 3.

Due to physical proximity, certain pairs of sensors will cause severe signal overlap if they both broadcast on the exact same channel. You are provided with a complete list of these interfering pairs. Your task is to allocate every sensor to exactly one of the three available channels such that no two sensors in an interfering pair share a channel. If no valid allocation exists, you must determine that a safe configuration is impossible.

## Input
The first line contains two integers $n$ and $m$ — the number of sensors and the number of interference conditions ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$). The sensors are numbered from 1 to $n$.
Each of the following $m$ lines contains two integers $u$ and $v$ — denoting that sensor $u$ and sensor $v$ interfere with each other and must not be allocated the same channel.

## Output
If no valid channel allocation exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$), with $c_i$ representing the channel allocated to sensor $i$. Among all valid channel allocations, output the lexicographically smallest sequence (compare $c_1$ first, then $c_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
