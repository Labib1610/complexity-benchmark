# Problem A — Shift Allocation

Time limit: 2 s
Memory limit: 256 MB

A manufacturing plant operates three daily shifts, designated as 1, 2, and 3. The plant employs a total of $n$ personnel. Due to personal disputes or specialized equipment overlap, specific pairs of employees cannot be assigned to the same shift. 

Your task is to allocate each of the $n$ personnel to exactly one of the three shifts such that no conflicting pair works during the same period. If it is impossible to resolve all conflicts, you must report this.

Please note that the conflict structure is entirely arbitrary. No simplifying patterns are guaranteed, and the evaluation includes adversarial 40-personnel instances with dense and complex overlapping restrictions designed to be challenging to resolve.

## Input
The first line provides two integers $n$ and $m$ — the total number of personnel and the number of conflicts, respectively ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), representing a pair of personnel who must be scheduled on different shifts.

## Output
If no valid shift allocation can be found, output a single line containing NO.
If a valid allocation exists, output YES on the first line. On the second line, output $n$ integers $s_1 s_2 \dots s_n$ (where each $s_i \in \{1, 2, 3\}$), with $s_i$ representing the shift assigned to person $i$. If there are multiple valid allocations, you must output the lexicographically smallest sequence (comparing $s_1$ first, then $s_2$, and so forth).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
