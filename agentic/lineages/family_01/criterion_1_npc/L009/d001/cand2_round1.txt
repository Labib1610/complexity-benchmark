# Problem A — Frequency Allocation

Time limit: 2 s   Memory limit: 256 MB

A regional communications network consists of $n$ transmission nodes. The regulatory authority has licensed exactly three frequency bands, designated as 1, 2, and 3. 

Certain pairs of transmission nodes have overlapping coverage areas. If two overlapping nodes broadcast on the same frequency band, they will cause destructive interference. Your task is to assign exactly one of the three frequency bands to each transmission node such that no interference occurs. 

If there are multiple ways to safely allocate the bands, the regulatory authority prefers lower-numbered bands to be used by the lowest-numbered nodes. Specifically, among all interference-free allocations, you must find the one that assigns the lowest possible band number to node 1. If there are still ties, resolve them by choosing the lowest possible band number for node 2, then node 3, and so on, continuing this priority order up to node $n$.

## Input
The first line contains two integers $n$ and $m$ — the number of transmission nodes and the number of overlapping pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the following $m$ lines contains two integers $u$ and $v$ — two nodes that overlap and cannot share a frequency band.

## Output
If it is impossible to assign bands without causing interference, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $b_1, b_2, \dots, b_n$ (each being 1, 2, or 3), where $b_i$ is the frequency band assigned to node $i$. This sequence must be the valid allocation that satisfies the priority rules described above.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
