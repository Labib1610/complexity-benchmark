 We need to assign each vertex a value from {1, 2, 3} such that for every edge (u, v),  
gcd(c_u, c_v) < lcm(c_u, c_v).  

Let’s check when this condition fails:  
- If c_u == c_v, then gcd = lcm, so condition fails.  
- If one is 1 and the other is something else, gcd = 1, lcm = other value, so 1 < other value holds.  
- If values are (2,3), gcd=1, lcm=6, holds.  
- If values are (2,2) or (3,3), fails.  

So the only forbidden case is when two connected vertices have the same value.  
Thus, the problem reduces to: assign each vertex a value from {1,2,3} such that no edge connects two vertices with the same value. This is exactly a graph coloring problem with 3 colors.  

We need the lexicographically smallest assignment.  
We can do a greedy coloring:  
- For each vertex from 1 to n, try the smallest color (1, then 2, then 3) that is not used by any already-colored neighbor.  
- If at some point no color is available, output "NO".  

This works because the graph is small (n ≤ 40) and greedy with smallest available color gives lexicographically smallest valid coloring for this constraint (since we only need to avoid same colors on edges).  

Here’s the implementation:  

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    adj[u-1].append(v-1)
    adj[v-1].append(u-1)

colors = [0] * n

for i in range(n):
    used = set()
    for nb in adj[i]:
        if colors[nb] != 0:
            used.add(colors[nb])
    for c in (1, 2, 3):
        if c not in used:
            colors[i] = c
            break
    else:
        print("NO")
        exit()

print("YES")
print(" ".join(map(str, colors)))
```
