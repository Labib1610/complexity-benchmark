# Problem A — Resonant Foundation

Time limit: 2 s   Memory limit: 256 MB

You are designing the foundation for a large facility, which requires $n$ load-bearing pillars. Each pillar $i$ (for $1 \le i \le n$) must be assigned a structural density rating $c_i \in \{1, 2, 3\}$.

To provide lateral stability, the design includes rigid horizontal beams. Each beam connects two pillars, $u$ and $v$. A known engineering constraint is that any two pillars connected by a beam must not have the exact same density rating, otherwise destructive resonance occurs. Note that a listed beam may connect a pillar to itself ($u=v$ is permitted). In such a case, the pillar is connected to a pillar with its own exact density rating, which guarantees resonance and structural failure regardless of the rating chosen.

You are given the layout of all horizontal beams. Your task is to determine a safe sequence of density ratings $c_1, c_2, \dots, c_n$ for the pillars such that no resonance occurs. 
If multiple safe sequences exist, you must choose the one that minimizes the foundation's total structural index, defined exactly by the formula:
$\sum_{i=1}^{n} c_i \cdot 4^{n-i}$

If it is impossible to assign ratings without causing resonance, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$) — the number of pillars and the number of horizontal beams. The pillars are numbered from $1$ to $n$.
Each of the following $m$ lines contains two integers $u$ and $v$ — indicating that a horizontal beam connects pillar $u$ and pillar $v$.

## Output
If no safe assignment of density ratings exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$), representing the density rating assigned to each pillar. If there is more than one valid sequence, output the one that minimizes the structural index defined above.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
