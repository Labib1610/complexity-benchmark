# Problem A — Gear Synchronization

Time limit: 2 s   Memory limit: 256 MB

You are tasked with configuring a mechanical system consisting of $n$ axles. Each axle must be fitted with a single gear. You have three types of gears available, each defined by its number of teeth:
- **Type 1:** 5 teeth
- **Type 2:** 6 teeth
- **Type 3:** 7 teeth

You must output a sequence $c_1, c_2, \dots, c_n$ where each element $c_i \in \{1, 2, 3\}$ represents the gear type chosen for axle $i$.

You are provided with $m$ mechanical constraints. Each constraint is defined by a pair of distinct axles $(u, v)$ indicating that the gear on axle $u$ and the gear on axle $v$ are enmeshed directly together. 

For the overall system to be valid, every enmeshed pair must independently satisfy the **uniform wear property**. This property requires that as the two gears rotate continuously against each other, every individual tooth on the gear at axle $u$ must eventually make contact with every individual tooth on the gear at axle $v$. If the gears only ever touch a restricted subset of each other's teeth, the configuration is invalid and will jam.

If there are multiple valid sequences of gear types that satisfy all $m$ constraints, you must determine the one that is lexicographically smallest. A sequence $A$ is lexicographically smaller than sequence $B$ if at the first index where they differ, sequence $A$ has a smaller value than sequence $B$. 
If no sequence can satisfy all constraints, you must report that it is impossible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$) — the number of axles and the number of enmeshed pairs.
Each of the following $m$ lines contains two distinct integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$) — indicating that the gears on axle $u$ and axle $v$ are enmeshed.

## Output
If no valid configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$), representing the lexicographically smallest valid sequence.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I replaced the mathematical gcd/lcm inequality with a physical gear-meshing requirement ("uniform wear") using gear sizes 5, 6, and 7. This forces the model to deduce that the condition requires the gear sizes to be coprime, which for these specific sizes means they must be distinct. By completely removing the mathematical inequality, models are prevented from immediately pattern-matching the problem to standard graph 3-coloring, which disables their ability to blindly apply coloring-specific optimizations like forward checking.
</RATIONALE>
<PRESERVED_ANSWER>
Every answer is unchanged because the gear sizes 5, 6, and 7 are pairwise coprime but not coprime with themselves; thus, the uniform wear property (which requires $\gcd(T_u, T_v) = 1$) is mathematically identical to requiring $c_u \neq c_v$.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly lexicographically-smallest 3-coloring, which is NP-complete, and the solution space and valid assignments are structurally identical to the seed problem.
</PRESERVED_CLASS>
<RISK>
The phrase "rotate continuously" could theoretically be misinterpreted as requiring a global simulation of all gears turning simultaneously, but the explicit phrasing "every enmeshed pair must independently satisfy" clearly restricts the evaluation to pairwise interactions.
</RISK>
