**Solution Explanation**

For every pair `(u , v)` we have to make the matrix  

```
| 1   1   1 |
| cu  cv  4 |
| cu² cv² 16|
```

invertible.  
The determinant of a Vandermonde matrix

```
| 1  1  1 |
| a  b  c |
| a² b² c²|
```

equals  

`(b‑a)·(c‑a)·(c‑b)` (up to sign).  
Here `a = cu , b = cv , c = 4`.  
Because `c = 4` is different from all possible values `1,2,3`,
the determinant is non‑zero **iff** `cu ≠ cv`.

So each constraint simply says *the two positions must obtain different
numbers*.
We have to colour the vertices of an undirected graph with three colours
`{1,2,3}` such that adjacent vertices have different colours
and we need the lexicographically smallest colouring.

`n ≤ 40` – tiny.  
A depth‑first search that tries the colours `1,2,3` in this order for
positions `1 … n` finds the lexicographically smallest solution.
The search is heavily pruned by forward checking: for each still uncoloured
vertex we keep a bit mask of still possible colours.
Whenever we colour a vertex we delete this colour from the masks of all
still uncoloured neighbours.
If a mask becomes empty the current branch is impossible and we backtrack.

The first complete assignment reached by the DFS is already the smallest
one, therefore we can stop immediately.

--------------------------------------------------------------------

#### Algorithm
```
read n , m
build adjacency list Adj[0 … n-1]

mask[i] = 0b111  (all three colours possible)      // integer, bit 0 → colour 1, …
col[i]  = 0      (not coloured yet)

DFS(pos):
    if pos == n:                // all vertices coloured
         answer = col[:]        // copy result
         return True

    for colour in 1,2,3 (in this order):
        bit = 1 << (colour-1)
        if mask[pos] does not contain bit: continue

        // try to assign this colour
        col[pos] = colour
        changed = empty list
        ok = True

        for each neighbour v of pos:
            if col[v] == 0:                 // still uncoloured
                 if mask[v] contains bit:
                       changed.append( (v, mask[v]) )
                       mask[v] &= ~bit      // delete this colour
                       if mask[v] == 0:
                             ok = False
                             break

        if ok and DFS(pos+1): return True   // solution found

        // revert all modifications of this trial
        for (v, old) in reversed(changed):
              mask[v] = old
        col[pos] = 0

    return False

run DFS(0)
if a solution was found:
     print "YES" and the sequence
else:
     print "NO"
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints **YES** and a lexicographically smallest
valid sequence iff such a sequence exists.

---

##### Lemma 1  
During the execution of `DFS`, for every vertex `i`
`mask[i]` contains exactly the colours that are still possible for `i`
with respect to the colours already fixed for vertices `< i`.

**Proof.**  
Initially all three colours are possible, so the statement holds.
Assume it holds before assigning vertex `pos`.
When we assign colour `c` to `pos`, for each still uncoloured neighbour `v`
the colour `c` becomes impossible, therefore we delete it from `mask[v]`.
No other vertex is affected.
Thus after the updates the statement still holds.
When we backtrack we restore the old masks, restoring the invariant.
∎



##### Lemma 2  
If `DFS` reaches `pos == n`, the array `col[0…n-1]` is a proper 3‑colouring
(i.e. all constraints are satisfied).

**Proof.**  
By construction we only assign a colour that is contained in the current
`mask[pos]`. By Lemma&nbsp;1 this colour does not appear among already coloured
neighbours, otherwise it would have been removed from the mask.
Consequently every edge connects vertices with different colours.
All vertices are coloured, hence the whole sequence is proper. ∎



##### Lemma 3  
If there exists a proper colouring extending the partial assignment
made before the call `DFS(pos)`, then `DFS(pos)` returns *True*.

**Proof.**  
Consider any such extending colouring `C`.  
At vertex `pos` the colour `C[pos]` is allowed, otherwise `C` would conflict
with an already coloured neighbour, contradicting its validity.
Therefore the loop in `DFS` will try this colour.
When it does, the recursive call `DFS(pos+1)` receives exactly the
partial assignment that `C` also induces (by Lemma&nbsp;1).
By induction on the remaining positions the recursive call will finally
reach `pos == n` and succeed (Lemma&nbsp;2).
Thus `DFS(pos)` returns *True*. ∎



##### Lemma 4  
If `DFS(pos)` returns *True*, the returned sequence is the lexicographically
smallest proper colouring among all colourings that extend the already fixed
prefix `col[0…pos-1]`.

**Proof.**  
The loop tries colours `1,2,3` in increasing order.
The first colour that leads to a successful recursive call is the smallest
colour that can be extended to a full solution (Lemma&nbsp;3).
Consequently the whole sequence built by the first successful branch is the
lexicographically smallest among all extensions of the current prefix. ∎



##### Lemma 5  
If a proper colouring of the whole graph exists, the initial call
`DFS(0)` returns *True* and outputs the lexicographically smallest proper
colouring of the entire graph.

**Proof.**  
`DFS(0)` has an empty prefix, so Lemma&nbsp;3 guarantees that it finds a
solution if any exists.  
By Lemma&nbsp;4 the first complete solution discovered is the smallest among
all solutions, because the empty prefix imposes no restriction. ∎



##### Theorem  
The program prints

* “YES” and the lexicographically smallest sequence `c₁…cₙ` satisfying all
  constraints, iff such a sequence exists;
* otherwise it prints “NO”.

**Proof.**  

*If the program prints “YES”.*  
It has found a complete assignment via `DFS`.  
By Lemma&nbsp;2 this assignment satisfies every edge, i.e. all constraints.
The algorithm stops at the first complete assignment, which is
lexicographically smallest by Lemma&nbsp;5.

*If a satisfying sequence exists.*  
By Lemma&nbsp;5 the initial call `DFS(0)` succeeds, therefore the program prints
“YES” and the smallest one.

*If no satisfying sequence exists.*  
Assume the program would print “YES”. Then `DFS(0)` would have succeeded,
contradicting Lemma&nbsp;3 (no extension exists). Hence it must print “NO”. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*`n ≤ 40`, `m ≤ n·(n‑1)/2`.*

For each vertex we try at most three colours.
When a colour is tried, we touch each incident edge once
(to delete the colour from the neighbour’s mask).  
Therefore the work of a single recursive level is `O(deg(v))`,
and the total work of a complete branch is `O(m)`.

In the worst case the search explores all possible colourings,
`3ⁿ` branches, giving `O(3ⁿ · m)` time – exponential,
which is inevitable for 3‑colourability.
With `n = 40` the pruning from forward checking makes the search
practically instantaneous (the official limits guarantee this).

Memory consumption:

* adjacency list: `O(m)`
* `mask` and `col` arrays: `O(n)`
* recursion stack depth `n`

Overall `O(n + m)` ≤ a few kilobytes, far below the limit.

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1000000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        if u == v:
            continue
        adj[u].append(v)
        adj[v].append(u)

    mask = [0b111] * n          # bits 0,1,2 -> colours 1,2,3
    col = [0] * n               # 0 = not assigned yet
    answer = None               # will hold the final sequence

    def dfs(pos: int) -> bool:
        nonlocal answer
        if pos == n:
            answer = col.copy()
            return True

        # try colours 1,2,3 in order
        for colour in (1, 2, 3):
            bit = 1 << (colour - 1)
            if not (mask[pos] & bit):
                continue

            # assign
            col[pos] = colour
            changed = []          # list of (vertex, old_mask)
            ok = True

            for nb in adj[pos]:
                if col[nb] == 0:
                    if mask[nb] & bit:
                        old = mask[nb]
                        new = old & ~bit
                        changed.append((nb, old))
                        mask[nb] = new
                        if new == 0:
                            ok = False
                            break

            if ok and dfs(pos + 1):
                return True

            # revert
            for v, old in reversed(changed):
                mask[v] = old
            col[pos] = 0

        return False

    if dfs(0):
        out = ['YES', ' '.join(str(x) for x in answer)]
    else:
        out = ['NO']
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```

and conforms to the required input and output format.
