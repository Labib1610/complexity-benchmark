<STATEMENT>
# Problem A — Quantum Oscillator Calibration

Time limit: 2 s   Memory limit: 256 MB

You are tasked with calibrating a network of $n$ quantum oscillators. Each oscillator $i$ must be assigned a real-valued frequency multiplier $f_i$.

Due to the quantization of stable energy states, every valid parameter $f_i$ must act as a fixed point for the system's local feedback loop:
$f_i = \frac{6}{f_i^2 - 6f_i + 11}$

(You may algebraically verify that the only real numbers satisfying this condition are positive integers).

The network contains $m$ interference channels. Each channel connects a pair of distinct oscillators $(u, v)$. 
For the network to remain coherent, the harmonic interaction between connected oscillators must not reach absolute symmetry. Specifically, for every channel connecting oscillator $u$ and oscillator $v$, their frequency multipliers must satisfy the strict geometric inequality:
$\frac{f_u}{f_v} + \frac{f_v}{f_u} > 2$

If the sum of their relative frequency ratios is exactly 2 (or less), the channel will experience symmetric resonance and destabilize the entire network.

Your goal is to find a valid sequence of frequency multipliers $f_1, f_2, \dots, f_n$ that satisfies the feedback loop equation for all $n$ oscillators and the strict inequality for all $m$ channels.

If there are multiple valid sequences, you must output the one that is lexicographically smallest. A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index where they differ, the multiplier in $A$ is strictly less than the multiplier in $B$.
If no sequence can satisfy all constraints, you must report that it is impossible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$) — the number of oscillators and the number of interference channels.
Each of the following $m$ lines contains two distinct integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$) — indicating a channel between oscillator $u$ and oscillator $v$.

## Output
If no valid sequence exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $f_1, f_2, \dots, f_n$, representing the lexicographically smallest valid sequence of frequency multipliers.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was completely reframed from a discrete assignment with a quadratic energy function to a continuous calibration with a rational fixed-point equation and a rational inequality. This forces the model to perform algebraic reasoning to deduce that the domain is strictly {1, 2, 3} and the constraint is strictly $f_u \neq f_v$. Models relying on pattern matching will likely misinterpret this as a continuous optimization problem and fail to write the required discrete lexicographical backtracking algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The roots of the fixed-point equation are exactly 1, 2, and 3, preserving the domain, and the ratio inequality $x/y + y/x > 2$ is mathematically true for positive integers if and only if $x \neq y$, perfectly preserving the constraints and the answers.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still identically requires finding a lexicographically smallest 3-coloring of a graph, keeping it in the exact same NP-complete complexity class.
</PRESERVED_CLASS>
