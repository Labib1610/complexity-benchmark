# Problem A — Valid Configuration

Time limit: 2 s   Memory limit: 256 MB

You are tasked with assigning a configuration level to each of $n$ components in a system. The components are indexed from 1 to $n$. The system has a maximum capacity of exactly 40 components, so $n$ will never exceed this number.

Each component must be assigned a configuration level, which must be a positive integer. Due to hardware limitations, the maximum allowed configuration level is 3.

You are provided with $m$ compatibility constraints. The number of constraints $m$ can be anything from 0 up to the maximum possible number of distinct pairs of components. Each constraint is defined by a pair of distinct components $(u, v)$ that are directly linked. 

For the system to be valid, every linked pair must satisfy a specific mathematical property regarding their assigned levels. Specifically, for each linked pair $(u, v)$, let $L_u$ and $L_v$ be their assigned configuration levels. The product of these two levels, $L_u \times L_v$, must have an even number of positive integer divisors. If the product has an odd number of positive integer divisors, the linked pair will cause a system error.

If there are multiple valid assignments of configuration levels that satisfy all $m$ constraints, you must determine the one that is lexicographically smallest. An assignment $A$ is lexicographically smaller than assignment $B$ if, at the first component index where they differ, $A$ has a smaller configuration level than $B$.
If no assignment can satisfy all constraints, you must report that it is impossible.

## Input
The first line contains two integers $n$ and $m$ — the number of components and the number of constraints.
Each of the following $m$ lines contains two distinct integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$) — indicating a constraint between component $u$ and component $v$.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $L_1, L_2, \dots, L_n$ (where each $L_i \in \{1, 2, 3\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
