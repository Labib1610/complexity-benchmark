We can analyze the condition:  

\( F(u,v) = c_u^2 + c_u c_v + c_v^2 \) must not be divisible by 3.  

Checking modulo 3:  
- If \( c_u \equiv c_v \pmod{3} \), then \( F \equiv 3c^2 \equiv 0 \pmod{3} \) → invalid.  
- If \( c_u \neq c_v \pmod{3} \), then \( F \equiv 1 \pmod{3} \) → valid.  

So the condition is: **adjacent (constrained) additives must have different values modulo 3**.  
Since values are in {1,2,3}, modulo 3 they are {1,2,0}.  

Thus, the problem reduces to:  
- We have a graph with n nodes and m edges.  
- We must assign each node a value from {0,1,2} (mod 3) such that adjacent nodes have different values.  
- This is exactly a **3-coloring** problem.  
- We need the lexicographically smallest assignment in terms of original values {1,2,3} (which correspond to mod values {1,2,0}).  

Since n ≤ 40, we can use backtracking with pruning.  

We’ll try values in order 1,2,3 for each node, and check constraints.  

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n  # 0 = unassigned, 1,2,3 = values
    
    def backtrack(idx):
        if idx == n:
            return True
        for val in (1, 2, 3):
            # check constraints
            ok = True
            for nb in adj[idx]:
                if color[nb] != 0 and color[nb] % 3 == val % 3:
                    ok = False
                    break
            if ok:
                color[idx] = val
                if backtrack(idx + 1):
                    return True
                color[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
