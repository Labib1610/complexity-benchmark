# Problem A — Sequence Properties

Time limit: 2 s   Memory limit: 256 MB

You are tasked with determining the properties of a sequence of $n$ chemical additives. The laboratory's testing rack has exactly four rows of ten slots each, meaning the sequence length $n$ can be anywhere from 1 up to the total capacity of the rack. Each additive $i$ in the sequence must be assigned a concentration level $c_i$, which must be a positive integer no greater than the total number of atoms in a single water molecule.

You are provided with a list of $m$ interacting pairs of indices $(u, v)$. 

To determine if a fully assigned sequence of concentration levels is stable, the laboratory uses the following global evaluation procedure:
1. Construct the complete sequence $C = [c_1, c_2, \dots, c_n]$.
2. For each pair $(u, v)$ in the list of interacting pairs:
   a. Construct three points in 3D space based on their concentrations: $P_1 = (1, c_u, c_u^2)$, $P_2 = (1, c_v, c_v^2)$, and $P_3 = (1, 4, 16)$.
   b. Consider the tetrahedron formed by these three points and the origin $(0,0,0)$.
   c. If these four points are perfectly coplanar (meaning the volume of their tetrahedron is exactly zero), the entire sequence immediately undergoes a catastrophic reaction and is marked as unstable.
3. If the procedure checks all $m$ pairs without a catastrophic reaction, the sequence is marked as stable.

If there are multiple stable sequences, you must find the one that is lexicographically smallest. A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index where they differ, sequence $A$ has a smaller concentration level than $B$. If no stable sequence exists, report that it is impossible.

## Input
The first line contains two integers $n$ and $m$ — the length of the sequence and the number of interacting pairs. As described, $n$ is at least 1 and at most the testing rack's capacity, and $m$ is at least 0 and at most the maximum number of unique pairs of additives.
Each of the following $m$ lines contains two distinct integers $u$ and $v$ (between 1 and $n$), representing an interacting pair.

## Output
If no stable sequence exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i$ is a valid concentration level), representing the lexicographically smallest stable sequence.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The easily factored quadratic energy function was replaced with a geometric condition (tetrahedron volume) that mathematically evaluates to the same $c_u \neq c_v$ requirement but resists immediate symbolic algebraic simplification. Additionally, the sequence validation is deliberately framed as a monolithic, global procedure operating on a complete sequence. This baits surface pattern-matching models into writing a generate-and-test approach ($O(3^{40})$) that will fail via Time Limit Exceeded. Models that genuinely reason about algorithmic structure will recognize that the failure condition depends only on two variables and can be evaluated early, allowing standard CSP backtracking with pruning to succeed. Numeric bounds were also stated indirectly as per Strategy S07.
</RATIONALE>
<PRESERVED_ANSWER>
The volume of the tetrahedron formed by the origin and the points $(1, c_u, c_u^2)$, $(1, c_v, c_v^2)$, and $(1, 4, 16)$ is proportional to the Vandermonde determinant $(c_v - c_u)(4 - c_u)(4 - c_v)$; since $c_u, c_v \in \{1, 2, 3\}$, this volume is exactly zero if and only if $c_u = c_v$, perfectly preserving the original constraint logic.
</PRESERVED_ANSWER>

The problem remains exactly Graph 3-Coloring, as the geometric constraint strictly enforces inequality between adjacent nodes in a graph of up to 40 vertices.
</PRESERVED_CLASS>
