<METHOD_DESCRIPTION>Replaces the explicit matrix invertibility condition with the geometrically equivalent condition that three points on a parabola must not be collinear. This removes the explicit Vandermonde matrix that models easily simplify algebraically, forcing them to reason about intersections of lines and parabolas to deduce that c_u must not equal c_v.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Sequence Properties

Time limit: 2 s   Memory limit: 256 MB

You are tasked with finding an integer sequence $c_1, c_2, \dots, c_n$ where each element must be chosen from the set $\{1, 2, 3\}$.

You are provided with $m$ constraints. Each constraint is defined by a pair of distinct indices $(u, v)$. For the sequence to be valid, every given pair must satisfy the following geometric property regarding their assigned values:
The three 2D points $P = (c_u, c_u^2)$, $Q = (c_v, c_v^2)$, and $R = (4, 16)$ must form a non-degenerate triangle (i.e., the three points must not be collinear).

If there are multiple valid sequences that satisfy all $m$ constraints, you must determine the one that is lexicographically smallest. A sequence $A$ is lexicographically smaller than sequence $B$ if at the first index where they differ, sequence $A$ has a smaller value than sequence $B$.
If no sequence can satisfy all constraints, you must report that it is impossible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$) — the length of the sequence and the number of constraints.
Each of the following $m$ lines contains two distinct integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$) — indicating a constraint between the elements at index $u$ and index $v$.

## Output
If no valid sequence exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$), representing the lexicographically smallest valid sequence.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit matrix invertibility condition was replaced with the geometrically equivalent requirement that three points on a parabola must not be collinear. This removes the recognizable Vandermonde determinant that models previously simplified algebraically, forcing them to deduce the incompatibility condition ($c_u \neq c_v$) via geometric reasoning.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that points $(c_u, c_u^2)$, $(c_v, c_v^2)$, and $(4, 16)$ are not collinear is mathematically identical to the determinant of the seed's matrix being non-zero, ensuring all valid sequences remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to lexicographically-smallest 3-coloring on a graph, which is NP-complete.
</PRESERVED_CLASS>
