We can solve this by first understanding the geometric condition.

The points are:

- \( P = (c_u, c_u^2) \)
- \( Q = (c_v, c_v^2) \)
- \( R = (4, 16) \)

These three points are collinear if the slope between \( P \) and \( R \) equals the slope between \( Q \) and \( R \).

The slope between \( (x_1, y_1) \) and \( (x_2, y_2) \) is:

\[
\frac{y_2 - y_1}{x_2 - x_1}
\]

For \( P \) and \( R \):

\[
\frac{16 - c_u^2}{4 - c_u}
\]

For \( Q \) and \( R \):

\[
\frac{16 - c_v^2}{4 - c_v}
\]

They are collinear if:

\[
\frac{16 - c_u^2}{4 - c_u} = \frac{16 - c_v^2}{4 - c_v}
\]

Note that \( 16 - c^2 = (4 - c)(4 + c) \), so:

\[
\frac{(4 - c_u)(4 + c_u)}{4 - c_u} = 4 + c_u
\]
(since \( c_u \neq 4 \), which is true because \( c_u \in \{1,2,3\} \))

Similarly for \( c_v \), we get \( 4 + c_v \).

So collinearity condition becomes:

\[
4 + c_u = 4 + c_v \quad \Rightarrow \quad c_u = c_v
\]

Thus, the three points are collinear **if and only if** \( c_u = c_v \).

So the constraint means:  
**For every given pair (u, v), we must have \( c_u \neq c_v \).**

This is exactly a graph coloring problem with 3 colors (values 1, 2, 3), where edges mean "different colors".

We need to find the lexicographically smallest assignment of colors 1, 2, 3 to vertices 1..n such that adjacent vertices have different colors.

Since \( n \le 40 \), we can do a backtracking search with pruning.

---

**Approach:**
- Build adjacency list from constraints.
- Try to assign values 1, 2, 3 to each vertex in order from 1 to n.
- At each step, pick the smallest possible value that doesn't conflict with already assigned neighbors.
- If we reach the end, we have a valid sequence.
- If at some point no value works, backtrack.

Because we try smallest first, the first complete assignment found is lexicographically smallest.

---

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    n = int(input_data[0])
    m = int(input_data[1])
    adj = [[] for _ in range(n)]
    idx = 2
    for _ in range(m):
        u = int(input_data[idx]) - 1
        v = int(input_data[idx+1]) - 1
        idx += 2
        adj[u].append(v)
        adj[v].append(u)
    
    colors = [0] * n
    
    def backtrack(pos):
        if pos == n:
            return True
        for c in (1, 2, 3):
            ok = True
            for nb in adj[pos]:
                if colors[nb] == c:
                    ok = False
                    break
            if ok:
                colors[pos] = c
                if backtrack(pos + 1):
                    return True
                colors[pos] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, colors)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
