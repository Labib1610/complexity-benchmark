# Problem A — Stability Constraints

Time limit: 2 s   Memory limit: 256 MB

You are tasked with finding an integer sequence $c_1, c_2, \dots, c_n$. Each element must be assigned a positive integer strictly less than the number of seasons in a standard calendar year.

You are provided with $m$ constraints. Each constraint is defined by a pair of distinct indices $(u, v)$. For the sequence to be valid, every given pair must satisfy the following algorithmic property regarding their assigned values:
Initialize a counter at zero. Add the value $c_u$ to the counter exactly $c_u$ times. Then, add the value $c_v$ to the counter exactly $c_v$ times. The configuration of the pair is satisfied if and only if the final value of the counter cannot be divided evenly by the sum of $c_u$ and $c_v$.

If there are multiple valid sequences that satisfy all $m$ constraints, you must determine the one that is lexicographically smallest. A sequence $A$ is lexicographically smaller than sequence $B$ if at the first index where they differ, sequence $A$ has a smaller value than sequence $B$.
If no sequence can satisfy all constraints, you must report that it is impossible.

## Input
The first line contains two integers $n$ and $m$. The value $n$ is at least 1 and at most the total number of spaces on a standard Monopoly board. The value $m$ is at least 0 and at most the maximum possible number of unique pairs among $n$ elements. These represent the length of the sequence and the number of constraints, respectively.
Each of the following $m$ lines contains two distinct integers $u$ and $v$ (between 1 and $n$, inclusive) — indicating a constraint between the elements at index $u$ and index $v$.

## Output
If no valid sequence exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$, representing the lexicographically smallest valid sequence.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
