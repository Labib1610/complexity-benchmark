# Problem A — Hardware Frequency Alignment

Time limit: 2 s   Memory limit: 256 MB

You are aligning a hardware array consisting of a certain quantity of transmitters. Each transmitter must be tuned to exactly one of three frequency channels: channel 1, channel 2, or channel 3. It is perfectly acceptable if some channels end up with no transmitters tuned to them.

The array is restricted by interference conditions. Each condition dictates that a specific pair of transmitters interfere and therefore must be tuned to different frequency channels to prevent signal degradation. The interference conditions are completely unrestricted. Hidden test cases contain dense configurations designed so that evaluating channel sequences in a naive, fixed order without bypassing invalid partial states will exceed the time limit.

A complete tuning configuration is represented by a sequence of channel choices for the transmitters, ordered by their hardware index. If multiple valid tuning configurations exist, you must select the configuration that prioritizes the lowest possible channel number for the first transmitter. If ties remain, you must prioritize the lowest possible channel number for the second transmitter, and so forth, resolving ties transmitter by transmitter in index order until a single configuration is isolated.

Determine if a valid tuning configuration exists, and if so, output the optimal one.

## Input
The first line contains two integers $n$ and $m$. The integer $n$ represents the quantity of transmitters (bounded below by 1, and bounded above by the 40 available hardware slots). The integer $m$ represents the number of interference conditions (ranging from 0 up to the precise maximum of one condition per distinct pair of transmitters).
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that transmitter $u$ and transmitter $v$ interfere.

## Output
If no valid tuning configuration can be found, output `NO` on a single line.
If a valid tuning configuration exists, output `YES` on the first line. On the second line, output exactly $n$ integers, where the $i$-th integer (which must be 1, 2, or 3) represents the channel assigned to transmitter $i$. This sequence must be the optimal configuration as defined by the tie-breaking rules.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I added an explicit warning that naive fixed-order evaluation will exceed the time limit on hidden dense configurations. This baits the model into using advanced variable ordering heuristics (like MRV) which, unless carefully adapted, will break the strict lexicographical tie-breaking rule and yield incorrect sequences. Furthermore, I applied S07 by describing the bounds on $n$ and $m$ indirectly through physical constraints (40 hardware slots, maximum distinct pairs).
</RATIONALE>
