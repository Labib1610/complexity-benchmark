We can model each component’s state as one of three vectors.  
The dot product condition between two components restricts which pairs of states are allowed.

Let’s list the dot products:

- A = (1,1,0)  
- B = (1,0,1)  
- C = (0,1,1)  

Dot products:

- A·A = 2  
- A·B = 1  
- A·C = 1  
- B·B = 2  
- B·C = 1  
- C·C = 2  

So the only forbidden pairs are when both components have the same state.  
Thus, for every edge (u,v), we must have different states.

This becomes a graph coloring problem with 3 colors, where adjacent vertices must have different colors.  
We need the lexicographically smallest coloring (1,2,3) possible.

Since n ≤ 40, we can use backtracking with pruning.

We’ll assign colors in order from 1 to n, trying smallest color first, and check constraints.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n
    
    def backtrack(idx):
        if idx == n:
            return True
        for c in (1, 2, 3):
            ok = True
            for nb in adj[idx]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[idx] = c
                if backtrack(idx + 1):
                    return True
                color[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
