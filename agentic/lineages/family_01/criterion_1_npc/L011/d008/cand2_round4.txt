<STATEMENT>
# Problem A — Component Configuration

Time limit: 2 s   Memory limit: 256 MB

You are configuring a system of $n$ components, numbered $1$ to $n$. You must assign each component to exactly one of 3 operating modes: 1, 2, or 3.

There are $m$ conflict rules between certain pairs of components. A valid configuration ensures that for every conflict rule between component $u$ and component $v$, the two components are assigned to different operating modes.

If there are multiple valid configurations, you must output the one that is lexicographically smallest. Specifically, consider each valid configuration as a sequence of $n$ integers $c_1, c_2, \ldots, c_n$. When comparing two distinct valid configurations, find the smallest index $i$ ($1 \le i \le n$) where their mode assignments differ; the configuration with the smaller value at position $i$ is strictly preferred.

Your task is to find a valid configuration for all $n$ components that best satisfies this rule. If it is impossible to form a valid configuration, report that no solution exists.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$), representing the number of components and the number of conflict rules.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that component $u$ and component $v$ have a conflict.

## Output
If no valid configuration can be formed, print a single line containing `NO`.
If a valid configuration is possible, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \ldots, c_n$, where $c_i \in \{1, 2, 3\}$ is the mode assigned to component $i$. If there are multiple valid configurations, you must output the lexicographically smallest one.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The seed problem's verbose explanation of the tie-breaking rule ("minimizing the team number for player 1 takes absolute precedence") strongly hinted at a greedy, fixed-order prefix search. By replacing this with a concise definition of lexicographical sequence comparison, models must independently deduce that sequential variable assignment in standard depth-first search naturally satisfies the objective. The input bounds have been fully restored to exactly match the seed's numeric contract.
</RATIONALE>
<PRESERVED_ANSWER>
The conditions for a valid assignment (no two conflicting elements share the same mode) and the tie-breaking rule (lexicographically smallest sequence) are mathematically identical to the seed problem.
</PRESERVED_ANSWER>
