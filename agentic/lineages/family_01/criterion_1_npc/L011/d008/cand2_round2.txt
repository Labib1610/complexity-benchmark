<METHOD_NAME>
Sequential Candidate Filtering
</METHOD_NAME>
<METHOD_DESCRIPTION>
Describes the lexicographical tie-breaking rule as a sequence of filtering steps on the set of all valid assignments. This encourages models to naively generate and filter all valid assignments (causing a Time Limit Exceeded), whereas models that understand the algorithmic structure will realize this is mathematically equivalent to stopping at the first valid assignment found via ordered DFS.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<STATEMENT>
# Problem A — Team Roster

Time limit: 2 s   Memory limit: 256 MB

You are organizing a tournament with $n$ players, numbered $1$ to $n$. You must assign each player to exactly one of 3 teams: Team 1, Team 2, or Team 3.

There are $m$ rivalries among the players. A valid tournament roster ensures that for every rivalry between player $u$ and player $v$, the two players are assigned to different teams.

It is possible that many valid rosters exist. To determine the ultimate roster, you must apply a rigorous elimination process to the set of all valid rosters:
1. First, determine the minimum possible team number that player 1 is assigned to across all valid rosters. Eliminate any roster that assigns player 1 to a higher team number.
2. Next, among the remaining rosters, determine the minimum possible team number that player 2 is assigned to. Eliminate any roster that assigns player 2 to a higher team number.
3. Continue this elimination process sequentially for player 3, player 4, and so on up to player $n$. 

After evaluating all $n$ players, exactly one preferred valid roster will remain. Your task is to find this specific valid roster. If it is impossible to form a valid roster initially, report that no solution exists.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$), representing the number of players and the number of rivalries.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that player $u$ and player $v$ have a rivalry. Each rivalry is an unordered pair of distinct players, and no pair appears more than once.

## Output
If no valid roster can be formed, print a single line containing `NO`.
If a valid roster is possible, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \ldots, c_n$, where $c_i \in \{1, 2, 3\}$ is the team assigned to player $i$ in the roster that survives the elimination process.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The description of the tie-breaking mechanism was rewritten from a direct lexicographical comparison to a sequential filtering process over the set of all valid rosters. This forces models to reason that filtering sets of rosters by sequential minimums is mathematically identical to finding the lexicographically first valid assignment, penalizing models that naively translate the filtering instructions into an exhaustive search.
</RATIONALE>
<PRESERVED_ANSWER>
The sequential elimination process exactly defines the lexicographically smallest sequence of team assignments, so the unique correct output for any input remains identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-coloring with lexicographical tie-breaking, preserving its NP-complete status.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the elimination process as implying that they must literally find all valid rosters first, which could be seen as an algorithmic constraint rather than a purely functional specification, though it is carefully phrased as a definition of the "ultimate roster" to avoid this.
</RISK>
