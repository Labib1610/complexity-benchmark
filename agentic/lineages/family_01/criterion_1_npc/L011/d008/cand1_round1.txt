# Problem A — Team Roster

Time limit: 2 s   Memory limit: 256 MB

You are in charge of distributing $n$ participants (identified by integers from $1$ to $n$) into exactly three distinct squads, designated as Squad 1, Squad 2, and Squad 3.

To guarantee fair play, $m$ known personality clashes must be respected. Whenever two participants have a clash, they cannot be placed in the same squad. A valid distribution satisfies this condition for all $m$ clashes.

When more than one valid distribution is possible, you must select the one that favors smaller squad numbers for participants with lower identification numbers. The assignment for participant 1 is the most critical: minimizing their squad number overrides all other considerations. If this still leaves multiple options, minimizing the squad number for participant 2 overrides the remaining participants, and this hierarchy continues down to participant $n$. To put it plainly, if you compare two valid distributions, identify the lowest participant ID that receives a different squad number in each; the distribution assigning the smaller squad number to that specific participant is the single correct answer.

Your goal is to determine a valid distribution that perfectly adheres to this hierarchical preference, or state that no valid distribution can be made.

**Implementation Note:** The hidden test cases include adversarial configurations of clashes designed such that naive fixed-order prefix testing and step-by-step sequential construction will explore a vast number of branches before finding a solution or proving none exists. Any solver relying solely on straightforward sequential trial-and-error to assign the up to 40 participants will exceed the time limit.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the total number of participants and the total number of clashes.
The subsequent $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), showing that participant $u$ and participant $v$ have a clash.

## Output
If a valid distribution is impossible, output a single line with `NO`.
If a valid distribution exists, output `YES` on the first line. On the second line, output $n$ integers $c_1, c_2, \ldots, c_n$, where $c_i \in \{1, 2, 3\}$ indicates the squad for participant $i$. If multiple valid distributions exist, you must output the exact one dictated by the hierarchical preference rules.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
