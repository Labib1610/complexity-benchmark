# Problem A — Channel Allocation

Time limit: 2 s   Memory limit: 256 MB

A telecommunications engineer is deploying a wireless infrastructure that utilizes three distinct transmission frequencies, labeled 1, 2, and 3. There are $n$ broadcasting beacons to configure. Certain pairs of beacons have intersecting signal radii and must not operate on the same frequency in order to prevent interference.

The central networking switch features exactly 40 hardware slots, ensuring the total number of installed beacons $n$ is at least 1 and never exceeds this physical capacity. 

Your task is to assign each beacon to exactly one of the three frequencies such that no two beacons with intersecting radii share the same frequency. If no such configuration is possible, you must report it.

*Important Notice: The evaluation system includes adversarial beacon configurations deliberately constructed so that a naive beacon-by-beacon enumeration of all $3^n$ potential frequency combinations will exceed the time limit. Your approach must be sufficiently optimized.*

## Input
The first line provides two integers $n$ and $m$ — the number of broadcasting beacons and the number of intersecting signal pairs. As dictated by the physical hardware, $n$ will be between 1 and the total number of switch slots. The value $m$ ranges from zero up to the maximum theoretical number of unique pairs of beacons.
The following $m$ lines each contain two integers $u$ and $v$, representing a pair of beacons (identified by integers from 1 to $n$) that have intersecting signal radii.

## Output
If no valid frequency configuration exists, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $f_1, f_2, \ldots, f_n$ (each being 1, 2, or 3), where $f_i$ represents the frequency assigned to beacon $i$. If multiple valid configurations exist, you must output the sequence that is lexicographically smallest (comparing $f_1$ first, then $f_2$, and so forth).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

I applied Strategy S07 by expressing the bounds indirectly: $n \le 40$ is derived from a 40-slot physical switch capacity, and $m$ is bounded by the maximum theoretical unique pairs. I also added a prominent warning against naive $3^n$ enumeration, neutralizing the shortcut where models assumed simple unoptimized backtracking would pass the time limit, forcing them to balance search optimization with the strict lexicographical requirement.
</RATIONALE>
<PRESERVED_ANSWER>
The problem still requires a valid assignment of 3 frequencies to $n$ beacons avoiding interference on given pairs, outputting the lexicographically smallest solution.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Lexicographically First 3-Coloring, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "maximum theoretical number of unique pairs" as something other than $n(n-1)/2$, but in the context of distinct pairs of $n$ items, it is mathematically unambiguous.
</RISK>
