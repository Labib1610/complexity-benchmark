# Problem A — Frequency Tuning

Time limit: 2 s   Memory limit: 256 MB

A facility is deploying a network of sensors. To transmit data, each sensor must be tuned to exactly one of three available frequency bands, labeled 1, 2, and 3. There are $n$ sensors in total. 

Certain pairs of sensors are physically located too close to each other. If a pair of adjacent sensors operates on the same frequency band, their signals will interfere. You are given a list of all such interfering pairs. Your task is to assign a frequency band to every sensor so that no two interfering sensors are assigned the same band, or determine that it is impossible.

*Performance note: The test suite includes dense collision structures with $n=40$ specifically designed so that naive sequential trial-and-error of all possible band combinations will exceed the time limit. Your solution must efficiently bypass invalid configurations.*

## Input
The first line contains two integers $n$ and $m$ — the number of sensors and the number of interfering pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that sensor $u$ and sensor $v$ interfere with each other and cannot share a frequency band.

## Output
If it is impossible to assign the frequency bands without interference, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $b_1, b_2, \ldots, b_n$ (each being 1, 2, or 3), where $b_i$ represents the frequency band assigned to sensor $i$. If there are multiple valid assignments, you must output the lexicographically smallest sequence (compare $b_1$ first, then $b_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
