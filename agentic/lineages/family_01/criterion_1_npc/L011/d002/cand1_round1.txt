# Problem A — Channel Allocation

Time limit: 2 s   Memory limit: 256 MB

A telecommunications company is configuring a new wireless infrastructure. Every access point must broadcast on exactly one of three designated frequencies, numbered 1, 2, and 3. Because of physical proximity, specific pairs of access points have intersecting signal ranges. To maintain network integrity, whenever two access points share an overlapping range, they must be assigned distinct frequencies. You must find a valid frequency configuration for the entire infrastructure, or determine that no such configuration exists.

*Important:* The access-point numbering in the evaluation data is deliberately arranged so that evaluating frequency assignments in strict sequential order will repeatedly construct long partial configurations that cannot be completed, even when a valid full configuration exists. Approaches relying solely on this traversal will explore too many configurations and exceed the time limit.

## Input
The first line provides two integers $n$ and $m$. The number of access points, $n$, is at least 1 and at most the absolute maximum capacity of a facility consisting of exactly 4 sectors that hold up to 10 access points each. The number of intersecting signal pairs, $m$, ranges from 0 up to the maximum possible number of distinct pairs among the $n$ access points.
The following $m$ lines each contain two integers $u$ and $v$ (where $u$ and $v$ are distinct integers between 1 and $n$ inclusive), indicating that access point $u$ and access point $v$ have an intersecting signal range.

## Output
If it is impossible to configure the network without interference, output a single line containing `NO`.
If a configuration is possible, output `YES` on the first line. On the second line, output $n$ integers $c_1, c_2, \ldots, c_n$, where $c_i \in \{1, 2, 3\}$ is the frequency assigned to access point $i$. If multiple valid configurations exist, you must output the one that is lexicographically smallest (i.e., comparing the sequence of assignments starting from $c_1$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit numeric limits for $n$ and $m$ with scenario-based capacities (4 sectors of 10 access points, and the maximum distinct pairs) to follow the S07 strategy. I also replaced the generic worst-case warning with a precise mechanical description of how the adversarial tests penalize simple sequential assignment. This forces the model to derive the input constraints carefully and recognize that it must implement more robust pruning or variable-ordering strategies than naive lexicographical backtracking.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to assign exactly one of three frequencies to each access point without overlaps, favoring the lexicographically smallest sequence, remains logically identical to the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 3-coloring of a graph, which is inherently NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the indirect bound "4 sectors that hold up to 10 access points each" if they assume the points must be strictly bound to sectors in the graph structure, though "absolute maximum capacity" clarifies it is just a bound on the total $n$.
</RISK>
