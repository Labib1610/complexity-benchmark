# Problem A — Artifact Preservation

Time limit: 2 s   Memory limit: 256 MB

A museum is preparing a new exhibition featuring $n$ delicate artifacts. The curators have prepared three distinct climate-controlled galleries, designated as Gallery 1, Gallery 2, and Gallery 3. Every artifact must be displayed in exactly one of these three galleries.

Due to chemical off-gassing, certain pairs of artifacts are mutually reactive. If a reactive pair is placed in the same gallery, the shared atmosphere will cause both items to deteriorate. Consequently, any two artifacts that are mutually reactive must be housed in strictly different galleries. 

Your objective is to determine a safe gallery assignment for all $n$ artifacts, or to conclude that no such assignment exists.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$), representing the number of artifacts and the number of reactive pairs, respectively.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that artifact $u$ and artifact $v$ are mutually reactive.

## Output
If it is impossible to safely display all artifacts without deterioration, output a single line containing `NO`.
If a safe arrangement is possible, output `YES` on the first line. On the second line, output $n$ integers $g_1, g_2, \ldots, g_n$, where $g_i \in \{1, 2, 3\}$ is the gallery assigned to artifact $i$. If multiple safe arrangements exist, you must output the one that is lexicographically smallest (i.e., comparing the sequence of assignments starting from $g_1$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
