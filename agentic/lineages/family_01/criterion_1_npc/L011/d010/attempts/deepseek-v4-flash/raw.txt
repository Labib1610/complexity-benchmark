 We can model this as a graph coloring problem with 3 colors, where each edge means the two tasks must have different profiles.  
Since each profile is a permutation of (1,2,3), two profiles conflict if they are identical at any step.  
Checking the three profiles:

- Profile 1: (1,2,3)  
- Profile 2: (2,3,1)  
- Profile 3: (3,1,2)  

Two profiles conflict if they share a number in the same position.  
Let’s check:

- 1 vs 2: (1,2,3) vs (2,3,1) → position 1: 1≠2, pos2: 2≠3, pos3: 3≠1 → no conflict.  
- 1 vs 3: (1,2,3) vs (3,1,2) → pos1: 1≠3, pos2: 2≠1, pos3: 3≠2 → no conflict.  
- 2 vs 3: (2,3,1) vs (3,1,2) → pos1: 2≠3, pos2: 3≠1, pos3: 1≠2 → no conflict.  

So actually any two different profiles are compatible.  
That means the only constraint is that connected tasks must have different profiles.  
So the problem reduces to: is the graph 3-colorable? If yes, output the lexicographically smallest coloring (assign smallest possible profile to each task in order).

We can solve with backtracking or greedy with backtracking for lexicographically smallest.

Here’s the implementation:

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

colors = [0] * n

def is_safe(node, c):
    for nb in adj[node]:
        if colors[nb] == c:
            return False
    return True

def solve(idx):
    if idx == n:
        return True
    for c in range(1, 4):
        if is_safe(idx, c):
            colors[idx] = c
            if solve(idx + 1):
                return True
            colors[idx] = 0
    return False

if solve(0):
    print("YES")
    print(" ".join(map(str, colors)))
else:
    print("NO")
```
