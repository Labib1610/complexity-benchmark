The recurrence $X_k = 3X_{k-1} - 2X_{k-2}$ simplifies to $X_k = X_0 + (X_1 - X_0)(2^k - 1)$, meaning $X_k \neq X_0$ is strictly mathematically equivalent to $X_1 \neq X_0$ (i.e., distinct colors). Models relying on surface pattern matching will attempt to simulate the recurrence iteratively or use matrix exponentiation without a modulo, resulting in TLE or OOM. # Problem A — System State Configuration

Time limit: 2 s   Memory limit: 256 MB

You are configuring a system with $n$ components, indexed from $1$ to $n$. Each component $i$ must be assigned a configuration integer $c_i \in \{1, 2, 3\}$.

The system is subject to $m$ interference constraints. Each constraint specifies a pair of components that interact. To ensure system stability, the configuration integers assigned to any interacting pair must satisfy a specific divergence condition.

For each constraint between an interacting pair, let $x$ be the integer assigned to one component and $y$ be the integer assigned to the other. We define an infinite sequence $X$ for this interaction as follows:
- $X_0 = x$
- $X_1 = y$
- $X_k = 3 X_{k-1} - 2 X_{k-2}$ for all $k \ge 2$

The interaction is considered stable if and only if $X_{10^{100}} \neq X_0$. (Note that the choice of which component's value is $x$ and which is $y$ does not affect whether this stability condition is met). All interacting pairs must be stable for the entire system configuration to be valid.

If there are multiple stable system configurations, you must select the one whose configuration sequence $c_1, c_2, \ldots, c_n$ is lexicographically smallest. That is, when comparing two valid sequences, the one with the smaller integer value at the first index where they differ is strictly preferred.

Determine if a stable configuration exists, and if so, output the optimal configuration sequence.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$), representing the number of components and the number of interference constraints.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that component $u$ and component $v$ interact and their assigned integers must satisfy the divergence condition.

## Output
If no stable configuration is possible, print a single line containing `NO`.
If a stable configuration is possible, print `YES` on the first line. On the second line, print exactly $n$ integers $c_1, c_2, \ldots, c_n$, where $c_i \in \{1, 2, 3\}$ is the configuration integer assigned to component $i$. Among all stable configurations, you must output the lexicographically smallest sequence $c_1, c_2, \ldots, c_n$ (compare $c_1$ first, then $c_2$, etc.).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit vector dot-product condition with a linear recurrence evaluated at an index ($10^{100}$) too large to compute without algebraic simplification. Because $X_k = X_0 + (X_1 - X_0)(2^k - 1)$, the condition $X_{10^{100}} \neq X_0$ forces the model to deduce that the stability constraint is simply $c_u \neq c_v$. This breaks any superficial pattern-matching to a graph coloring template, forcing the model to either reason mathematically to recover the $O(1)$ check or write a naive implementation that will inevitably crash or time out.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $X_{10^{100}} \neq X_0$ algebraically simplifies to $x \neq y$, which is logically identical to the original distinct-vector dot-product requirement, ensuring all valid configurations remain exactly the same.
</PRESERVED_ANSWER>
