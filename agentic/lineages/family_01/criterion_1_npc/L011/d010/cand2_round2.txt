<STATEMENT>
# Problem A — System State Configuration

Time limit: 2 s   Memory limit: 256 MB

You are configuring a system with $n$ components, indexed from $1$ to $n$. Each component $i$ must be assigned a discrete frequency multiplier $c_i$, chosen from exactly one of three available values: $1$, $2$, or $3$.

The system is subject to $m$ interference constraints. Each constraint specifies a pair of components $u$ and $v$ that interact. To ensure system stability, the frequency multipliers assigned to any interacting pair must satisfy a specific harmonic condition. Specifically, the value of the expression $c_u^2 + c_v^2 + c_u c_v$ must not be evenly divisible by 3. 

For reporting purposes, the complete configuration of the system is represented by the sequence of $n$ integers $c_1, c_2, \ldots, c_n$. 

If there are multiple stable configurations, you must select the one whose configuration sequence $c_1, c_2, \ldots, c_n$ is lexicographically smallest. That is, when comparing two valid sequences, the one with the smaller integer value at the first index where they differ is strictly preferred.

Determine if a stable configuration exists, and if so, output the optimal configuration sequence.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$), representing the number of components and the number of interference constraints.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that component $u$ and component $v$ interact and their assigned frequency multipliers must satisfy the harmonic condition.

## Output
If no stable configuration is possible, print a single line containing `NO`.
If a stable configuration is possible, print `YES` on the first line. On the second line, print exactly $n$ integers $c_1, c_2, \ldots, c_n$, where $c_i \in \{1, 2, 3\}$ is the integer representation of the frequency multiplier assigned to component $i$. Among all stable configurations, you must output the lexicographically smallest sequence $c_1, c_2, \ldots, c_n$ (compare $c_1$ first, then $c_2$, etc.).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit vector dot-product rule from the seed problem acts as a glaring fingerprint for graph 3-coloring, because models instantly recognize that three vectors satisfying mutual dot-product constraints correspond to distinct colors. I replaced this with an equivalent polynomial invariant $c_u^2 + c_v^2 + c_u c_v \not\equiv 0 \pmod 3$, which evaluates to true if and only if $c_u \neq c_v$ for values in $\{1, 2, 3\}$. This forces the model to actually analyze the condition rather than immediately mapping the problem to a standard graph algorithm template.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $c_u^2 + c_v^2 + c_u c_v \not\equiv 0 \pmod 3$ fails if $c_u = c_v$ (since $3x^2 \equiv 0 \pmod 3$) and succeeds if $c_u \neq c_v$ for any distinct pair from $\{1, 2, 3\}$ (evaluating to either 7, 13, or 19, none of which are divisible by 3), meaning the valid assignments perfectly match the seed's valid assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly lexicographically-first 3-coloring on a graph, preserving its NP-completeness.
</PRESERVED_CLASS>
