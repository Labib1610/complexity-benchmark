<STATEMENT>
# Problem A — Configuration Synthesis

Time limit: 2 s   Memory limit: 256 MB

You are synthesizing a configuration for a network of $n$ active nodes. Each node must be assigned a state value from the set $\{1, 2, 3\}$. There are $m$ pairwise dependencies in the network. 

For each dependency between node $u$ and node $v$, the assigned state values $c_u$ and $c_v$ must satisfy the following stability condition:
$c_u^2 + c_v^2 > 2 c_u c_v$

A complete configuration is a sequence of $n$ integers $C = (c_1, c_2, \ldots, c_n)$. If multiple valid configurations exist, you must output the sequence that is lexicographically smallest. Specifically, given two distinct valid configurations $C$ and $C'$, configuration $C$ is strictly smaller than $C'$ if $c_k < c'_k$ at the lowest index $k$ where the two sequences differ. If no valid configuration can be synthesized, you must report that no solution exists.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$), representing the number of active nodes and the number of dependencies, respectively.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating a dependency between node $u$ and node $v$.

## Output
If no valid configuration can be formed, print a single line containing `NO`.
If a valid configuration is possible, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \ldots, c_n$, where $c_i \in \{1, 2, 3\}$ is the state value assigned to node $i$. If there are multiple valid assignments, output the lexicographically smallest sequence.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit graph coloring "must not share the same frequency band" constraint with an algebraic inequality $c_u^2 + c_v^2 > 2 c_u c_v$. This forces the model to mathematically deduce that the stability condition is strictly equivalent to $c_u \neq c_v$ over real numbers, preventing surface-level pattern matching on graph coloring terminology.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic condition $c_u^2 + c_v^2 > 2 c_u c_v$ is equivalent to $(c_u - c_v)^2 > 0$, which holds if and only if $c_u \neq c_v$, keeping the valid configurations identical to the seed's valid assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly lexicographically-smallest 3-coloring on a given graph, which is NP-complete.
</PRESERVED_CLASS>
