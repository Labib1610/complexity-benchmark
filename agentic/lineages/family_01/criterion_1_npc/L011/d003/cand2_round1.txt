# Problem A — Operational Modes

Time limit: 2 s   Memory limit: 256 MB

You are configuring a wireless network. There are three available operational modes, denoted by the integers 1, 2, and 3. Every access point must be assigned exactly one of these modes.

Due to physical proximity, certain pairs of access points are in interfering range. If two access points that are in interfering range are assigned the identical mode, they will disrupt each other's signals. A valid network configuration is one where no two such access points share the same mode.

Your task is to find a valid configuration for the entire network. If there are multiple valid configurations, you must evaluate them as complete sequences. By treating each valid configuration as a full sequence of $n$ integers (where the first integer is the mode of access point 1, the second is the mode of access point 2, and so on), you must select the one that would appear first if all valid sequences were sorted in dictionary order.

Warning: The test data contain adversarial network layouts on which basic fixed-order exhaustive backtracking will exceed the time limit. You must employ nontrivial pruning or an optimized search strategy to find the optimal configuration. If no valid configuration exists, you must report that it is impossible.

## Input
The first line contains two integers $n$ and $m$. The total number of access points $n$ is strictly positive and cannot exceed the controller's hardware limit of 40 connected devices. The number of interfering pairs $m$ can be as low as zero, and cannot exceed the theoretical limit where every access point interferes with all other access points.

Each of the next $m$ lines contains two integers $u$ and $v$, representing the 1-based identifiers of two distinct access points that are in interfering range and thus cannot operate on the same mode.

## Output
If it is impossible to configure the network without disruption, output a single line containing `NO`.
If a valid configuration exists, output `YES` on the first line. On the second line, output $n$ integers $c_1, c_2, \ldots, c_n$, where each $c_i \in \{1, 2, 3\}$ represents the mode assigned to access point $i$. Remember to output the dictionary-first sequence if multiple exist.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
