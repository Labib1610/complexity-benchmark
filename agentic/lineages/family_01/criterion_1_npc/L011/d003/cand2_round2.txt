# Problem A — Operational Modes

Time limit: 2 s   Memory limit: 256 MB

You are configuring a wireless network consisting of $n$ access points. There are three available operational modes, denoted by the integers 1, 2, and 3. Every access point must be assigned exactly one of these modes.

Due to physical proximity, certain pairs of access points are in interfering range. If two access points that are in interfering range are assigned the identical mode, they will disrupt each other's signals. A valid network configuration is one where no two such access points share the same mode.

Your task is to find a valid configuration for the entire network. If there are multiple valid configurations, you must choose the one that is lexicographically smallest overall. (To compare two configurations, evaluate them as complete sequences of exactly $n$ integers. The sequence that has a smaller integer at the earliest index of difference is deemed lexicographically smaller.) If no valid configuration exists, you must report that it is impossible.

## Input
The first line contains two integers $n$ and $m$. The number of access points $n$ is at least 1 and capped at a maximum of 40. The number of interfering pairs $m$ ranges from a minimum of 0 up to a maximum of $n(n-1)/2$.
Each of the next $m$ lines contains two distinct integers $u$ and $v$ (both at least 1 and at most $n$, with $u \neq v$), indicating that access point $u$ and access point $v$ are in interfering range and thus cannot operate on the same mode.

## Output
If it is impossible to configure the network without disruption, output a single line containing `NO`.
If a valid configuration exists, output `YES` on the first line. On the second line, output $n$ integers $c_1, c_2, \ldots, c_n$, where each $c_i \in \{1, 2, 3\}$ represents the mode assigned to access point $i$. Remember to output the lexicographically smallest sequence if multiple exist.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
