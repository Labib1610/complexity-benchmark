 We can solve this by trying to assign colors 1, 2, or 3 to each node while respecting the constraint that connected nodes have different colors.  
Since n ≤ 40, we can use backtracking with pruning, but we also need the lexicographically smallest configuration in terms of the objective function (which is equivalent to lexicographically smallest sequence when read from left to right, because 4^(n-i) heavily weights earlier positions).

We can do a DFS that tries color 1 first, then 2, then 3, and checks constraints.  
If we find a valid assignment, we stop immediately because the first found will be the smallest.

Here’s the implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    colors = [0] * n
    found = False
    
    def dfs(idx):
        nonlocal found
        if idx == n:
            return True
        for c in (1, 2, 3):
            ok = True
            for nb in adj[idx]:
                if colors[nb] == c:
                    ok = False
                    break
            if ok:
                colors[idx] = c
                if dfs(idx + 1):
                    return True
                colors[idx] = 0
        return False
    
    if dfs(0):
        print("YES")
        print(" ".join(map(str, colors)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
