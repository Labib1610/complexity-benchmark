<METHOD_NAME>Matrix Exponentiation Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit base-4 positional sum with a product of 2x2 matrices. The top-right element of the resulting matrix algebraically expands to a base-7 positional sum. Models that pattern-match will fail to recognize the lexicographical equivalence and will likely attempt exhaustive search, leading to TLE. Models that genuinely reason will expand the product, recognize the strict positional weighting, and correctly implement a greedy lexicographical DFS.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Global Energy State

Time limit: 2 s   Memory limit: 256 MB

You are analyzing a discrete system consisting of $n$ particles. Each particle $i$ (from $1$ to $n$) must be assigned an energy level $c_i \in \{1, 2, 3\}$. 

The system contains $m$ interacting pairs of particles. A complete configuration of the system $C = (c_1, c_2, \ldots, c_n)$ is considered stable if and only if for every interacting pair of particles $u$ and $v$, their assigned energy levels are different (that is, $c_u \neq c_v$).

Your objective is to determine a stable configuration for all $n$ particles. If multiple stable configurations exist, you must output the valid configuration $C$ that strictly minimizes the value in the first row and second column (the top-right element) of the system's $2 \times 2$ cascade matrix $M(C)$.

The matrix $M(C)$ is defined by the ordered product (using standard matrix multiplication):
$$M(C) = B_n \cdot B_{n-1} \cdot \ldots \cdot B_1$$
where each $B_i$ is a $2 \times 2$ matrix corresponding to particle $i$:
$$B_i = \begin{pmatrix} 7 & c_i \\ 0 & 1 \end{pmatrix}$$

If it is impossible to find a stable configuration, report that no solution exists.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$), representing the number of particles and the number of interacting pairs, respectively.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that particle $u$ and particle $v$ form an interacting pair.

## Output
If no stable configuration can be formed, print a single line containing `NO`.
If a stable configuration is possible, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \ldots, c_n$, where $c_i \in \{1, 2, 3\}$ is the energy level assigned to particle $i$. If there are multiple stable configurations, you must output the sequence that minimizes the specified matrix element.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit base-4 summation from the seed problem was removed because it allowed models to immediately pattern-match the objective to lexicographical minimization. It has been replaced with a product of 2x2 matrices. When expanded algebraically, the top-right element of this matrix product evaluates exactly to $\sum_{i=1}^n c_i 7^{n-i}$. This forces the model to perform the algebraic expansion and deduce the positional weighting to realize that early-stopping ordered DFS is still the optimal approach, heavily penalizing models that attempt a naive exhaustive search.
</RATIONALE>
<PRESERVED_ANSWER>
The top-right element of the matrix evaluates to a base-7 positional sum where the coefficient of $c_1$ is the largest; because $7$ is strictly greater than the maximum possible value of $c_i$ (which is 3), this sum perfectly preserves the exact same lexicographical ordering as the original base-4 sum.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core requirement remains finding a valid assignment of 3 states to nodes such that no interacting pair shares a state, which is exactly the NP-complete 3-COLORING problem.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the order of matrix multiplication, though the text explicitly states $M(C) = B_n \cdot B_{n-1} \cdot \ldots \cdot B_1$ and specifies standard matrix multiplication to minimize this risk.
</RISK>
