<STATEMENT>
# Problem A — Global Energy State

Time limit: 2 s   Memory limit: 256 MB

You are analyzing a discrete system consisting of $n$ particles. Each particle $i$ (from $1$ to $n$) must be assigned an energy level from the set $\{1, 2, 3\}$. 

The system contains interacting pairs of particles. A complete configuration of the system is considered stable if and only if for every interacting pair of particles, their assigned energy levels are different.

Your objective is to determine a stable configuration for all $n$ particles. If multiple stable configurations exist, the optimal one is selected through a sequential elimination process:
- Initially, all valid stable configurations are placed in a candidate pool.
- The process evaluates the particles in stages, starting from particle $1$ and proceeding step-by-step up to particle $n$.
- In stage $i$, the system identifies the absolute minimum energy level assigned to particle $i$ among all configurations currently surviving in the candidate pool.
- Any configuration in the pool that assigns an energy level to particle $i$ strictly greater than this identified minimum is permanently eliminated.
- The single configuration that survives after all $n$ stages is the optimal one you must output.

If it is impossible to find a stable configuration, report that no solution exists.

## Input
The first line provides two integers $n$ and $m$, representing the number of particles (at least $1$ and at most the product of eight and five) and the number of interacting pairs (at least $0$ and at most the total number of distinct pairs of particles), respectively.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that particle $u$ and particle $v$ form an interacting pair.

## Output
If no stable configuration can be formed, print a single line containing `NO`.
If a stable configuration is possible, print `YES` on the first line. On the second line, print $n$ integers, where the $i$-th integer (from $\{1, 2, 3\}$) is the energy level assigned to particle $i$ in the optimal stable configuration.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit base-4 objective function was removed and replaced with a sequential elimination process that filters a hypothetical pool of all valid configurations. This exactly preserves the lexicographical tie-breaker but frames it as a multi-stage filtering algorithm rather than a mathematical formula, forcing the model to deduce that it can still be solved using a standard backtracking search that assigns colors in ascending order. The numeric bound for $n$ was also replaced with an indirect arithmetic description.
</RATIONALE>
<PRESERVED_ANSWER>
The sequential elimination process filters out configurations that have higher energy levels at earlier indices, which is mathematically identical to minimizing the original base-4 polynomial objective function, ensuring the exact same configuration is always chosen.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a valid assignment from a set of 3 values subject to inequality constraints between pairs, which is exactly graph 3-coloring and remains NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the elimination process as a dynamic system that changes over time rather than a static tie-breaking rule, though the phrase "candidate pool" and "stable configurations" strongly anchors it as a selection among complete static assignments.
</RISK>
