# Problem A — Acoustic Resonance

Time limit: 2 s
Memory limit: 256 MB

You are calibrating a network of $n$ acoustic sensors, numbered 1 through $n$. Each sensor must be assigned a discrete sensitivity multiplier of 1, 2, or 3.

The network contains $m$ critical sensor pairs. When a critical pair of sensors operates simultaneously, their assigned sensitivity multipliers (let's call them $a$ and $b$) produce a combined acoustic field modeled by the quadratic function:
$f(x) = a x^2 + (a + b) x + b$

To avoid destructive interference (resonance), the acoustic field function for every critical pair must have two distinct real roots. Note that the order in which the two multipliers are assigned to $a$ and $b$ in the function does not affect whether the roots are distinct and real.

You are given the total number of sensors and the specific critical pairs. Determine a valid sensitivity assignment for all $n$ sensors that ensures no critical pair experiences resonance, or report that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$ — the number of sensors and the number of critical pairs ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a critical pair of sensors.

## Output
If no valid sensitivity assignment can be found, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $v_1, v_2, \dots, v_n$ (where each $v_i \in \{1, 2, 3\}$), representing the sensitivity multiplier assigned to each sensor $i$. Any valid assignment will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

The problem was completely reframed from circuit voltages to acoustic resonance, hiding the simple $a \neq b$ constraint behind the algebraic properties of a quadratic function. To succeed, a model must genuinely reason through the mathematics (calculating the discriminant $\Delta = (a-b)^2$) to discover that the continuous-sounding requirement logically reduces to a discrete graph coloring constraint. Models relying on surface pattern matching will likely misinterpret this as a continuous optimization problem or fail to apply standard constraint satisfaction heuristics.
</RATIONALE>
<PRESERVED_ANSWER>
The discriminant of the given quadratic function is $(a+b)^2 - 4ab = (a-b)^2$, which is strictly positive (yielding two distinct real roots) if and only if $a \neq b$, making the constraint mathematically identical to the original requirement that connected components have different values.
</PRESERVED_ANSWER>

The problem remains exactly equivalent to Graph 3-Coloring since it requires assigning one of 3 distinct values to each node such that no two connected nodes share the same value, keeping it completely within its original complexity class.
</PRESERVED_CLASS>
