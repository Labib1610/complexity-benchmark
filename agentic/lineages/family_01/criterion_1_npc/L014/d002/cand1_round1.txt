# Problem A — Circuit Voltage Levels

Time limit: 2 s
Memory limit: 256 MB

You are in charge of tuning a custom integrated circuit that contains $n$ logic components, which are identified by integers from $1$ to $n$. Your task is to supply each component with one of three discrete operating voltage levels: 1, 2, or 3.

The circuit features a network of data links built between specific pairs of components. A data link will only transmit signals properly if it connects two components operating at different voltage levels, meaning a non-zero potential difference is required across the link. Consequently, no two components joined by a data link can be tuned to the exact same voltage level.

The circuit blueprints used for evaluation feature topologies where local link density does not correlate with global assignment constraints. In these layouts, attempting to assign voltages by following a static numerical sequence, or by prioritizing components with the highest number of data links, will force your process to repeatedly undo and redo earlier decisions. To successfully process these structures within the time limit, your method must dynamically deduce forced choices and systematically avoid traversing redundant invalid configurations rather than relying on simple ordering rules.

Given the component count and the specific data links present in the circuit, you must find a valid tuning of voltage levels for all $n$ components so that every data link is functional. If it is impossible to satisfy all links, you must report that as well.

## Input
The first line of the input provides two integers $n$ and $m$ — the total number of logic components and the number of data links, respectively ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
This is followed by $m$ lines, each containing two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a data link exists between component $u$ and component $v$.

## Output
If there is no valid way to tune the circuit, output a single line with the word `NO`.
If a valid tuning exists, output `YES` on the first line. On the second line, output $n$ space-separated integers $v_1, v_2, \dots, v_n$, where each $v_i$ is either 1, 2, or 3. Here, $v_i$ represents the voltage level assigned to the $i$-th component. If multiple valid tunings exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
