# Problem A — Circuit Voltage Levels

Time limit: 2 s
Memory limit: 256 MB

You are configuring a custom integrated circuit consisting of $n$ logic components. The components are assigned sequential identification numbers starting from 1. Each component must be supplied with a discrete operating voltage level. There are exactly three available voltage levels: 1, 2, and 3.

The circuit contains data links between specific pairs of components. For a data link to function correctly, there must be a non-zero potential difference between the two components it connects. Therefore, the two components sharing a link cannot be supplied with the identical voltage level. 

You are given the total number of components and the specific pairs that are connected by data links. Determine a valid voltage assignment for all $n$ components that ensures every data link is functional, or report that no such assignment exists.

The evaluation suite includes topologies specifically structured to maximize the number of locally valid partial assignments that cannot be completed. Code that processes components in a static sequence or prioritizes them purely by their total number of connections will explore too many dead ends.

## Input
The first line contains two integers $n$ and $m$ — the number of logic components and the number of data links. The custom circuit board provides exactly 40 component slots. Thus, the number of components $n$ is at most the total number of slots, and at least one component is always present. The number of data links $m$ ranges from zero up to the theoretical maximum where every distinct pair of components is directly linked exactly once.

Each of the following $m$ lines contains two integers $u$ and $v$, representing a pair of components connected by a data link. Both $u$ and $v$ are valid component identification numbers.

## Output
If no valid voltage assignment can be found, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $v_1, v_2, \dots, v_n$ (where each $v_i \in \{1, 2, 3\}$), representing the voltage level assigned to component $i$. Any valid assignment will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
