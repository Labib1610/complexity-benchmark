# Problem A — Independent Audits

Time limit: 2 s   Memory limit: 256 MB

You are coordinating the annual compliance review for a corporate headquarters. Each department must be assigned to exactly one of three external auditing firms, which are identified by the integers 1, 2, and 3.

To prevent conflicts of interest, the review must account for internal dependencies. There are several known joint ventures, each involving a specific pair of departments. If two departments engaged in a joint venture are reviewed by the identical auditing firm, their shared financials cannot be properly cross-examined. Therefore, for every joint venture, the two participating departments must be assigned to strictly different auditing firms. 

Be advised that the joint ventures may be presented in an adversarial sequence. The compliance scenarios you process include dense, highly interconnected department structures that have no valid assignment. These are specifically constructed to severely penalize any checking system that relies on naive, unoptimized exhaustive assignment searches.

## Input
The first line contains two integers $n$ and $m$ — the number of departments and the number of joint ventures.
A headquarters must have at least one department, and due to a strict physical limit on available suites, it can house a maximum of 40 departments. The number of joint ventures can be zero, or it can be as large as the scenario where every distinct pair of departments shares exactly one venture.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of departments involved in a joint venture.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise print `YES` on the first line. On the second line print $n$ integers $f_1, f_2, \dots, f_n$ (each in $\{1, 2, 3\}$), where $f_i$ is the auditing firm assigned to department $i$. Among all valid assignments, output the one that is lexicographically smallest (compare $f_1$ first, then $f_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
