# Problem A — Distributed Sensor Tiers

Time limit: 2 s
Memory limit: 256 MB

You are configuring an array of sensor units. Each unit must be assigned to exactly one of three processing tiers, labeled 1, 2, and 3. Due to shared hardware resources, certain specific pairs of sensor units are interdependent. To maintain redundancy, interdependent units must never be assigned to the same processing tier. 

The equipment chassis has slots for exactly 40 sensor units, establishing a strict upper capacity on the total number of units $n$ (ensuring at least 1 and at most 40 units). The count of interdependencies $m$ can range from a minimum of 0 up to the maximum possible scenario where every unit is interdependent with every other unit, which is exactly $n \cdot (n-1)/2$. You are provided with the total number of sensor units and the list of interdependent pairs. 

Determine a valid tier assignment for all units that respects the redundancy rules, or report that no such arrangement exists.

## Input
The first line contains two integers $n$ and $m$ — the number of sensor units and the number of interdependencies ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that unit $u$ and unit $v$ are interdependent and must be assigned to different processing tiers.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $t_1, t_2, \dots, t_n$ (where each $t_i \in \{1, 2, 3\}$), representing the processing tier assigned to unit $i$. Any valid configuration will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
