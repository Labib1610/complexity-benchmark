# Problem A — Technician Roster

Time limit: 2 s
Memory limit: 256 MB

A manufacturing plant runs nonstop, dividing its 24-hour day into three equal-length operational phases labeled 1, 2, and 3. The company employs a staff of $n$ technicians, each of whom must be permanently assigned to exactly one of these phases. 

Due to past workplace friction, HR has compiled a registry of incompatible technician pairs. If a pair is registered, those two individuals cannot share the same phase assignment. 

The facility has exactly 40 employee lockers, which imposes a strict upper limit on the staff size $n$ (the facility always employs at least one technician). The number of registry entries $m$ can be anything from zero up to the theoretical maximum where every possible unique pair of technicians is incompatible. Technicians are identified by integers from 1 to $n$.

Given the staff size and the registry, determine if a valid phase assignment exists, and if so, provide one.

## Input
The first line contains two integers $n$ and $m$ — the number of technicians and the number of registry entries.
Each of the following $m$ lines contains two integers $u$ and $v$, representing a pair of technicians who are incompatible.

## Output
If no valid assignment is possible, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers separated by spaces, where the $i$-th integer (which must be 1, 2, or 3) is the phase assigned to technician $i$. Any valid configuration is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
