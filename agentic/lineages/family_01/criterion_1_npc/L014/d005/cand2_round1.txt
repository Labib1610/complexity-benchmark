<METHOD_DESCRIPTION>The explicit set of allowed voltage pairs ({1,2}, {1,3}, {2,3}) is replaced with the algebraic condition that a_u^2 + a_w^2 + a_u*a_w is not divisible by 3. <STATEMENT>
# Problem A — Circuit Voltage Levels

Time limit: 2 s
Memory limit: 256 MB

An integrated circuit is being designed with $n$ logic components, labeled 1 through $n$. Each component added to the board increases the base thermal load by exactly $1.5^\circ\text{C}$. The board's cooling system can safely dissipate up to, but strictly less than, $61.5^\circ\text{C}$ of increased temperature. Thus, the number of components $n$ is a positive integer strictly limited by this cooling capacity.

Your task is to assign each component a discrete operating voltage. The available voltage options for any component are 1, 2, and 3.

Certain pairs of components communicate via bidirectional data links. The number of data links $m$ ranges from 0 up to the theoretical maximum where every component is directly linked to every other component.

For communication to be successful across a link, the voltages assigned to the two connected components must form a permitted configuration. Specifically, if a data link connects component $u$ and component $w$, their assigned voltages $a_u$ and $a_w$ must satisfy the condition that the value $(a_u^2 + a_w^2 + a_u a_w)$ is not divisible by 3.

You are provided with the number of components and the exact pairs that share a data link. You must output a fully functional voltage assignment for the circuit, or indicate if it is impossible.

## Input
The first line contains two integers $n$ and $m$ — the number of logic components and the number of data links.
Each of the following $m$ lines contains two distinct integers $u$ and $w$, representing a pair of components connected by a data link (where $u$ and $w$ are valid component labels). It is guaranteed that each unordered pair of components appears at most once in the input.

## Output
If no valid voltage assignment can be found, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $a_1, a_2, \dots, a_n$ (where each $a_i \in \{1, 2, 3\}$), representing the voltage assigned to component $i$. Any valid assignment will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit set of allowed pairs with an algebraic condition, and the explicit bounds with a physical thermal limit (Strategy S07). By expressing the validity of a link as `(u^2 + w^2 + u*w) % 3 != 0`, models are forced to evaluate the constraint rather than pattern-matching the problem to Graph 3-Coloring. Without recognizing the graph coloring structure, they will fail to apply degree-ordering heuristics and will TLE on complex graphs.
</RATIONALE>
<PRESERVED_ANSWER>
For values in {1, 2, 3}, the expression a_u^2 + a_w^2 + a_u*a_w is a multiple of 3 if and only if a_u = a_w (evaluating to 3, 12, or 27), perfectly matching the original requirement that adjacent components must have distinct voltages.
</PRESERVED_ANSWER>

The problem remains exactly Graph 3-Coloring, preserving its NP-complete status and identical solution space.
</PRESERVED_CLASS>
