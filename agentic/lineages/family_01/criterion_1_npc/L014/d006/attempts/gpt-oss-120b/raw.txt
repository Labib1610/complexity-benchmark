**Solution Explanation**

For a pair of nodes with speeds `x , y ∈ {1,2,3}` the link is safe iff  

```
(x³ + y³ + x·y) mod 10 = 1
```

The values `x³ mod 10` are  

```
1 → 1 , 2 → 8 , 3 → 7
```

Evaluating all nine possibilities gives  

| x | y | (x³+y³+x·y) mod 10 | safe? |
|---|---|-------------------|-------|
|1|1|3|no|
|1|2|1|yes|
|1|3|1|yes|
|2|1|1|yes|
|2|2|0|no|
|2|3|1|yes|
|3|1|1|yes|
|3|2|1|yes|
|3|3|3|no|

The only unsafe pairs are the three *identical* pairs `(1,1) , (2,2) , (3,3)`.  
Therefore a link is safe **iff its two ends have different speeds**.

Consequently the problem is exactly:

*Is the given graph 3‑colorable?*  
If yes, output any proper 3‑coloring; otherwise output `NO`.

`n ≤ 40`, so exponential backtracking with good ordering is fast enough.

--------------------------------------------------------------------

#### Algorithm
1. Read the graph, store adjacency lists.
2. Order vertices by decreasing degree (heuristic for faster pruning).
3. Depth‑first search `dfs(pos)`  
   * `pos` – index in the ordered list.  
   * If `pos == n` → all vertices colored → success.  
   * Try colors `1,2,3`. For a color `c` check all already colored neighbours;
     if none has color `c`, assign it and recurse.
   * If none of the three colors works → backtrack (return `False`).
4. If the initial call succeeds, rebuild the answer in the original vertex order
   and print `YES` and the colors.  
   Otherwise print `NO`.

The recursion depth is at most `n = 40`.  
The worst‑case number of visited states is `3^n`, but the degree ordering
and early conflict detection prune the search dramatically; for `n = 40`
the program easily fits into the limits.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs `YES` with a valid assignment
iff such an assignment exists.

---

**Lemma 1**  
A speed assignment satisfies the link condition for every edge
iff it is a proper vertex coloring (adjacent vertices have different colors).

*Proof.*  
From the table above a link is unsafe exactly when the two incident speeds are equal.
Thus the condition “all links are safe” is equivalent to “no edge connects equal speeds”,
i.e. a proper coloring. ∎



**Lemma 2**  
During `dfs(pos)` the partial assignment of the first `pos` vertices
is always a proper coloring of the induced subgraph.

*Proof.*  
The algorithm assigns a color to a vertex only after verifying that none of its
already colored neighbours (which are among the first `pos` vertices) has the same
color. Hence no edge inside the processed part is monochromatic. ∎



**Lemma 3**  
If `dfs(pos)` returns `True`, the colors stored at that moment form a proper
3‑coloring of the whole graph.

*Proof.*  
By Lemma&nbsp;2 the partial coloring is proper.
`dfs` returns `True` only when `pos == n`, i.e. every vertex has been assigned a
color, so the partial coloring is a complete proper coloring. ∎



**Lemma 4**  
If a proper 3‑coloring exists, `dfs(0)` eventually returns `True`.

*Proof.*  
Consider any fixed proper coloring `C`. The recursion explores colors for each
vertex in the order chosen. When processing vertex `v`, if the algorithm tries
the color `C(v)`, all already colored neighbours (a subset of earlier vertices)
have colors different from `C(v)` because `C` is proper. Hence `C(v)` passes the
conflict test and the recursion can follow the branch that matches `C`.
Inductively, the algorithm can follow the entire sequence of colors of `C`
and reaches the leaf where all vertices are colored, returning `True`. ∎



**Lemma 5**  
If `dfs(0)` returns `False`, no proper 3‑coloring exists.

*Proof.*  
Assume a proper coloring existed. By Lemma&nbsp;4 the algorithm would have a
successful branch, contradicting the return value `False`. Hence no proper
coloring exists. ∎



**Theorem**  
The program prints  

* `YES` and a list of speeds that makes every link safe **iff** such a list exists;  
* otherwise prints `NO`.

*Proof.*  
- If the program prints `YES`, it obtained the colors from a successful call
  of `dfs`, which by Lemma&nbsp;3 is a proper 3‑coloring. By Lemma&nbsp;1 this
  satisfies the required condition, so a valid assignment exists.
- If the program prints `NO`, `dfs(0)` returned `False`. By Lemma&nbsp;5 no
  proper 3‑coloring exists, and by Lemma&nbsp;1 no valid assignment exists.

Thus the output is correct in both cases. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

Let `T` be the number of recursive states actually visited.
Each state tries at most three colors and checks at most `deg(v)` neighbours,
so the work per state is `O(deg(v)) ≤ O(n)`.

```
Time   : O(T · n)   (worst‑case T = 3^n, but n ≤ 40 → fits easily)
Memory : O(n) for recursion stack + O(n + m) for the graph
```

Both limits satisfy the given constraints.

#### Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    # order vertices by decreasing degree
    order = sorted(range(n), key=lambda x: -len(adj[x]))
    pos_in_order = [0] * n
    for idx, v in enumerate(order):
        pos_in_order[v] = idx

    colors = [0] * n  # 0 = uncolored, else 1..3

    def dfs(pos: int) -> bool:
        if pos == n:
            return True
        v = order[pos]
        # try colors 1..3
        for c in (1, 2, 3):
            ok = True
            for nb in adj[v]:
                if colors[nb] == c:
                    ok = False
                    break
            if ok:
                colors[v] = c
                if dfs(pos + 1):
                    return True
                colors[v] = 0
        return False

    if dfs(0):
        print("YES")
        print(' '.join(str(colors[i]) for i in range(n)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
