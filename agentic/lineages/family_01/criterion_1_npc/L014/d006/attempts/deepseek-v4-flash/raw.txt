 We need to assign each department one of three agencies (1, 2, or 3) such that the sum of dot products over all edges equals `-4m`.  

Let’s first compute the possible dot products between the three agency vectors:

- Agency 1: (2, 2, 2)  
- Agency 2: (-2, 2, -2)  
- Agency 3: (2, -2, -2)  

Dot products:

- 1·1 = 2*2 + 2*2 + 2*2 = 12  
- 1·2 = 2*(-2) + 2*2 + 2*(-2) = -4 + 4 - 4 = -4  
- 1·3 = 2*2 + 2*(-2) + 2*(-2) = 4 - 4 - 4 = -4  
- 2·2 = (-2)*(-2) + 2*2 + (-2)*(-2) = 4 + 4 + 4 = 12  
- 2·3 = (-2)*2 + 2*(-2) + (-2)*(-2) = -4 - 4 + 4 = -4  
- 3·3 = 2*2 + (-2)*(-2) + (-2)*(-2) = 4 + 4 + 4 = 12  

So:  
- Same agency → 12  
- Different agencies → -4  

We need sum over all edges = -4m.  

If we have `k` edges where the two endpoints have the same agency, and `m - k` edges where they differ, then:  
Sum = 12k + (-4)(m - k) = 12k - 4m + 4k = 16k - 4m.  

We need:  
16k - 4m = -4m → 16k = 0 → k = 0.  

So **no edge may connect two departments with the same agency**.  

Thus, the problem reduces to:  
Can we 3-color the graph (with colors 1, 2, 3) such that adjacent vertices have different colors?  
If yes, output the lexicographically smallest coloring.  

This is exactly graph 3-coloring, which is NP-hard in general, but with n ≤ 40 we can use backtracking with pruning.  

We’ll implement a backtracking search that tries colors in order 1, 2, 3 for each vertex, checking constraints, and stops at the first solution (which will be lexicographically smallest because we try smallest first).  

Here’s the code:  

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def dfs(idx):
    if idx == n:
        return True
    for c in range(3):
        ok = True
        for nb in adj[idx]:
            if color[nb] == c:
                ok = False
                break
        if ok:
            color[idx] = c
            if dfs(idx + 1):
                return True
            color[idx] = -1
    return False

if dfs(0):
    print("YES")
    print(" ".join(str(c + 1) for c in color))
else:
    print("NO")
```
