We can check the condition for each pair of speeds 1, 2, 3:

- (1,1): 1+1+1 = 3 → ends in 3 → fail  
- (1,2): 1+8+2 = 11 → ends in 1 → ok  
- (1,3): 1+27+3 = 31 → ends in 1 → ok  
- (2,2): 8+8+4 = 20 → ends in 0 → fail  
- (2,3): 8+27+6 = 41 → ends in 1 → ok  
- (3,3): 27+27+9 = 63 → ends in 3 → fail  

So valid pairs are: (1,2), (1,3), (2,3).  
That means any two connected nodes must have different speeds.  
So the problem reduces to: can we 3-color the graph?  
Since n ≤ 40, we can use backtracking with pruning.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    colors = [0] * n  # 0 = uncolored, 1,2,3 = speeds
    
    def backtrack(node):
        if node == n:
            return True
        # Try colors 1,2,3
        for c in (1,2,3):
            ok = True
            for nb in adj[node]:
                if colors[nb] == c:
                    ok = False
                    break
            if ok:
                colors[node] = c
                if backtrack(node + 1):
                    return True
                colors[node] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(str(colors[i]) for i in range(n)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
