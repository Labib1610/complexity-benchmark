# Problem A — Grid Harmonic Resonance

Time limit: 2 s
Memory limit: 256 MB

You are deploying a computational grid consisting of $n$ processing nodes, labeled 1 through $n$. Your task is to configure the clock speed for each node. The available clock speed options for any node are 1, 2, and 3 GHz.

Each node processes a continuous stream of 3-channel data packets. A packet contains three distinct data segments residing in slot 1, slot 2, and slot 3. The clock speed assigned to a node dictates how it rearranges these segments:
- A clock speed of 1 GHz causes the node to swap the segments currently in slot 1 and slot 2 of the packet.
- A clock speed of 2 GHz causes the node to swap the segments currently in slot 2 and slot 3 of the packet.
- A clock speed of 3 GHz causes the node to swap the segments currently in slot 1 and slot 3 of the packet.

Certain pairs of nodes share a direct synchronization link. When two linked nodes communicate, a packet is routed through one node and then immediately through the other. Due to a hardware flaw, if this two-step routing sequence (regardless of which of the two nodes processes it first) leaves the data segments in their exact original slots (effectively acting as if no routing occurred), the link will experience harmonic resonance and fail. 

To ensure the grid is fully operational, every synchronization link must connect two nodes such that their combined sequential routing does NOT return a packet's segments to their original starting slots.

You are provided with the number of nodes and the exact pairs that share a synchronization link. You must output a fully functional clock speed assignment for the grid, or indicate if it is impossible.

## Input
The first line contains two integers $n$ and $m$ — the number of processing nodes and the number of synchronization links ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
Each of the following $m$ lines contains two distinct integers $u$ and $w$ ($1 \le u, w \le n$, $u \neq w$), representing a pair of nodes connected by a synchronization link. It is guaranteed that each unordered pair of nodes appears at most once in the input.

## Output
If no valid clock speed assignment can be found, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $a_1, a_2, \dots, a_n$ (where each $a_i \in \{1, 2, 3\}$), representing the clock speed assigned to node $i$. Any valid assignment will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
Replaced the "perfect square product" condition with a permutation sequence condition. Speeds now act as transpositions on a 3-element array, and a link fails if the combined effect of two nodes is the identity permutation. This forces the model to either implement the simulation directly (which will likely TLE without graph-coloring heuristics) or independently deduce the isomorphism to inequality.
</RATIONALE>
<PRESERVED_ANSWER>
The transpositions in the symmetric group S3 are involutions, meaning their product is the identity if and only if the two transpositions are identical, which perfectly preserves the implicit constraint that linked nodes must have different values.
</PRESERVED_ANSWER>
