# Problem A — Processor Phase Alignment

Time limit: 2 s
Memory limit: 256 MB

You are designing the power distribution for a prototype microprocessor. The processor contains $n$ processing cores, indexed from 1 up to $n$. Each core requires an assignment to exactly one of three stable power phases, labeled 1, 2, and 3.

The architecture includes $m$ high-speed communication buses, each establishing a direct connection between a pair of cores. A bus relies on a logical differential to transmit data. Consequently, the two cores connected by any given bus are strictly prohibited from sharing the same power phase. 

Note that the test data includes configurations specifically structured such that evaluation approaches which process cores in numerical order, or sort them solely by their number of connections, will explore too many invalid states.

You are given the core count and the bus connections. Determine a valid phase assignment for all $n$ cores that ensures every bus operates correctly, or report that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$. The number of cores $n$ is bounded by a minimum of 1 and the socket's physical limit of 40. The number of buses $m$ can range from 0 up to the theoretical maximum of $n \cdot (n-1)/2$.

Each of the following $m$ lines contains two distinct integers $u$ and $w$ (both valid core indices from 1 to $n$, with $u \neq w$), representing a pair of cores connected by a bus. It is guaranteed that each unordered pair of cores appears at most once in the input.

## Output
If no valid phase assignment can be found, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $a_1, a_2, \dots, a_n$ (where each $a_i \in \{1, 2, 3\}$), representing the power phase assigned to core $i$. Any valid assignment will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
