# Problem A — Circuit Voltage Levels

Time limit: 2 s
Memory limit: 256 MB

You are configuring a custom integrated circuit consisting of a number of logic components. Components are identified by sequential positive integers starting from one. The circuit chassis has forty hardware slots, establishing the absolute maximum capacity for the total number of components.

Each component must receive a discrete operating voltage level. These levels are positive integers. The system features a set of three independent power rails, limiting the maximum assignable voltage level to exactly the total number of rails.

The circuit contains data links between certain pairs of components. For a data link to function correctly, there must be a non-zero potential difference between the two components it connects. Therefore, the two components sharing a link cannot be supplied with the identical voltage level. 

Note that the test data includes configurations specifically structured such that evaluation approaches which process components in numerical order, or sort them solely by their number of connections, will explore too many invalid states.

You are given the total number of components and the specific pairs that are connected by data links. Determine a valid voltage assignment for all components that ensures every data link is functional, or report that no such assignment exists.

## Input
The first line contains two integers: the number of logic components and the number of data links. The number of components is at least one and does not exceed the chassis slot capacity. The number of links can range from an empty layout up to a fully saturated layout where every component links to every other component.
Each of the subsequent lines describes a single data link by providing the two distinct component identifiers it connects. It is guaranteed that each unordered pair of components appears at most once in the input.

## Output
If no valid voltage assignment can be found, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print a sequence of integers representing the assigned voltage levels for the components, ordered from component 1 to the final component. Each level must be a valid positive integer as restricted by the power supply. Any valid assignment will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
