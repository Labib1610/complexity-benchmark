<STATEMENT>
# Problem A — Independent Audits

Time limit: 2 s
Memory limit: 256 MB

You are coordinating the annual compliance review for $n$ corporate departments. The corporate headquarters has a physical capacity of exactly 40 department suites; $n$ is a positive integer that will never exceed this structural limit.

Each department must be allocated to exactly one external auditing firm. The authorized auditing firms are identified by positive integers starting from 1 up to the smallest odd prime number.

To prevent conflicts of interest, the review must account for internal dependencies. There are $m$ known joint ventures, each involving a specific pair of departments. The value of $m$ is non-negative and can be up to the theoretical maximum where every department partners with every other distinct department. If a single auditing firm is assigned to review multiple departments, it is strictly prohibited for any two of those departments to be engaged in a joint venture with each other. Therefore, each firm's allocated portfolio of departments must be completely free of internal joint ventures.

Be aware that the test suite contains arbitrary, dense compliance networks, and the joint ventures may be presented in an adversarial sequence.

Determine if there is a valid firm allocation for all $n$ departments that satisfies these compliance rules.

## Input
The first line contains two integers $n$ and $m$ — the number of departments and the number of joint ventures. (The bounds for $n$ and $m$ are derived from the building capacity and the maximum number of unique pairs, as described).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of departments involved in a joint venture. Departments are numbered 1 through $n$.

## Output
If no valid allocation exists, print a single line `NO`.
Otherwise print `YES` on the first line. On the second line print $n$ integers $f_1, f_2, \dots, f_n$ (each being a valid firm ID), where $f_i$ is the auditing firm allocated to department $i$. Among all valid allocations, output the one that is lexicographically smallest (compare $f_1$ first, then $f_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I changed how the bounds and constraints are presented to apply strategy S07 and break the survivors' affordance. Instead of explicit numeric limits, bounds are derived from physical capacities (40 suites) and mathematical properties (smallest odd prime, max unique pairs). To prevent models from instantly mapping the problem to standard 3-coloring via local pairwise inequality constraints, I reframed the conflict rule as a global property of the auditing firms' assigned portfolios: each firm's set of departments must be entirely free of internal joint ventures (effectively describing independent sets instead of edge-wise inequality).
</RATIONALE>
<PRESERVED_ANSWER>
The constraint that no firm's portfolio contains a joint venture is mathematically identical to requiring that no two departments sharing a joint venture are assigned the same firm, so the set of valid assignments and the lexicographically smallest one remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Graph 3-Coloring, as finding a valid assignment of 3 firm IDs such that no two adjacent departments share an ID is famously NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "smallest odd prime number" if they hallucinate that 1 is prime, though this is rare; otherwise, the independent set phrasing is standard and unambiguous.
</RISK>
