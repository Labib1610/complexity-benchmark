# Problem A — Circuit Voltage Levels

Time limit: 2 s
Memory limit: 256 MB

You are configuring a custom integrated circuit consisting of $n$ logic components, numbered sequentially starting from 1. Each component must be supplied with a discrete operating voltage level. The allowed voltage levels are the positive integers up to 3.

The circuit contains data links between certain pairs of components. For a data link to function correctly, the absolute difference between the voltage levels of the two components it connects must be strictly positive. 

Note that the test data includes configurations specifically structured such that evaluation approaches which process components in numerical order, or sort them solely by their number of connections, will explore too many invalid states.

You are given the total number of components and the specific pairs that are connected by data links. Determine a valid voltage assignment for all $n$ components that ensures every data link is functional, or report that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$ — the number of logic components and the number of data links. The number of logic components $n$ is bounded below by the 1 mandatory primary controller and bounded above by the board's thermal limit of 40. The number of data links $m$ is bounded below by a completely disconnected state of 0 and bounded above by a fully connected topology of $n \cdot (n-1)/2$.

Each of the following $m$ lines contains two distinct integers $u$ and $w$ ($1 \le u, w \le n$, $u \neq w$), representing a pair of components connected by a data link. It is guaranteed that each unordered pair of components appears at most once in the input.

## Output
If no valid voltage assignment can be found, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $a_1, a_2, \dots, a_n$ (where each $a_i \in \{1, 2, 3\}$), representing the voltage level assigned to component $i$. Any valid assignment will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit "1, 2, or 3" and "cannot be identical" phrases with "positive integers up to 3" and "absolute difference must be strictly positive". This removes the exact textual pattern that models use to instantly recognize 3-coloring, forcing them to deduce the inequality constraint from the mathematical phrasing. I also integrated the limits for $n$ and $m$ into the physical constraints of the scenario to satisfy the indirect bounds strategy.
</RATIONALE>
<PRESERVED_ANSWER>
The allowed values are still exactly {1, 2, 3}, and the strictly positive absolute difference constraint is mathematically identical to a simple inequality constraint, preserving the exact same valid assignments.
</PRESERVED_ANSWER>
