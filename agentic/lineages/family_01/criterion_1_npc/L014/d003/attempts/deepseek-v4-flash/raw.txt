 We need to assign each department one of three firms (1, 2, or 3) such that for every edge (u, v), the product of their assigned numbers is not a perfect square.

Let’s analyze the condition:  
The numbers 1, 2, 3 have products:
- 1×1=1 (perfect square) → invalid
- 1×2=2 (not square) → valid
- 1×3=3 (not square) → valid
- 2×2=4 (perfect square) → invalid
- 2×3=6 (not square) → valid
- 3×3=9 (perfect square) → invalid

So the only invalid pairs are when both vertices get the same number.  
Thus, the problem reduces to: can we color the graph with 3 colors such that no two adjacent vertices share the same color?  
That’s exactly the 3-coloring problem, which is NP-hard in general.  
But here n ≤ 40, so we can use backtracking with pruning.

We need the lexicographically smallest assignment, so we try colors 1, 2, 3 in order for each vertex.

We’ll implement a backtracking search.

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n

def is_safe(v, c):
    for u in adj[v]:
        if color[u] == c:
            return False
    return True

def solve(v):
    if v == n:
        return True
    for c in range(1, 4):
        if is_safe(v, c):
            color[v] = c
            if solve(v + 1):
                return True
            color[v] = 0
    return False

if solve(0):
    print("YES")
    print(" ".join(map(str, color)))
else:
    print("NO")
```
