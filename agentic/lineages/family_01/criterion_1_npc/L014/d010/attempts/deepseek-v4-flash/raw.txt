We can model this as a graph coloring problem with 3 colors, where the load formula determines which color pairs are allowed.

First, let’s compute the load for each possible pair of agency values:

- (1,1): 0  
- (1,2): (1-2)^4 - 5(1-2)^2 + 10 = 1 - 5 + 10 = 6  
- (1,3): (1-3)^4 - 5(1-3)^2 + 10 = 16 - 20 + 10 = 6  
- (2,2): 0  
- (2,3): (2-3)^4 - 5(2-3)^2 + 10 = 1 - 5 + 10 = 6  
- (3,3): 0  

So the load is 0 if same agency, 6 if different.  
The total load must be ≤ 6m.  
If we have k edges with different agencies, total load = 6k.  
We need 6k ≤ 6m → k ≤ m.  
That means **all edges must have the same agency on both ends**.  

So the problem reduces to: can we color the graph with 3 colors such that every edge connects same-colored vertices?  
That means each connected component must be monochromatic.  

Thus, if the graph has any edge, all vertices in that connected component must share the same color.  
We can assign colors to components independently.  
To get lexicographically smallest assignment, we assign color 1 to component containing vertex 1, then for the next uncolored vertex, assign color 1 if possible, else 2, else 3.

Implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    comp_id = [-1] * n
    comps = []
    
    # Find connected components
    for i in range(n):
        if comp_id[i] == -1:
            cid = len(comps)
            stack = [i]
            comp_id[i] = cid
            nodes = []
            while stack:
                u = stack.pop()
                nodes.append(u)
                for v in adj[u]:
                    if comp_id[v] == -1:
                        comp_id[v] = cid
                        stack.append(v)
            comps.append(nodes)
    
    # Assign colors to components
    used_color = [False] * len(comps)
    for cid, nodes in enumerate(comps):
        # Try colors 1,2,3 in order
        for c in range(1, 4):
            if not used_color[c-1]:
                # Assign this color to all nodes in component
                for u in nodes:
                    color[u] = c
                used_color[c-1] = True
                break
    
    # Since each component is monochromatic, any assignment works
    # But we need lexicographically smallest: assign smallest possible color to each component in order of first occurrence
    # We already did that by iterating components in order of first vertex index.
    
    print("YES")
    print(" ".join(map(str, color)))

if __name__ == "__main__":
    solve()
```
