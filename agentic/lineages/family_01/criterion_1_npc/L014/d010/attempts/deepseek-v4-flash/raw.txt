We can simplify the condition first.  

For a link between nodes \(u\) and \(w\) with speeds \(x\) and \(y\):

\[
V = 4x^2 + 3xy + 4y^2 + 11(u+w)(x+y)
\]

We need \(V \not\equiv 0 \pmod{11}\).  
Since \(11(u+w)(x+y)\) is always divisible by 11, we only need:

\[
4x^2 + 3xy + 4y^2 \not\equiv 0 \pmod{11}
\]

Now, \(x, y \in \{1,2,3\}\). Let’s check all pairs:

- (1,1): \(4+3+4=11 \equiv 0\) → bad  
- (1,2): \(4+6+16=26 \equiv 4\) → ok  
- (1,3): \(4+9+36=49 \equiv 5\) → ok  
- (2,1): \(16+6+4=26 \equiv 4\) → ok  
- (2,2): \(16+12+16=44 \equiv 0\) → bad  
- (2,3): \(16+18+36=70 \equiv 4\) → ok  
- (3,1): \(36+9+4=49 \equiv 5\) → ok  
- (3,2): \(36+18+16=70 \equiv 4\) → ok  
- (3,3): \(36+27+36=99 \equiv 0\) → bad  

So the only forbidden pairs are (1,1), (2,2), (3,3).  
That means: **linked nodes cannot have the same speed**.

Thus the problem reduces to:  
Can we assign each node a value from {1,2,3} such that no edge connects two nodes with the same value?  
That’s exactly a **3-coloring** problem. Since \(n \le 40\), we can use backtracking.

We’ll implement a backtracking search with pruning.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n  # 0 = uncolored, 1,2,3 = speeds
    
    def backtrack(node):
        if node == n:
            return True
        # Try colors 1,2,3
        for c in (1,2,3):
            ok = True
            for nb in adj[node]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[node] = c
                if backtrack(node + 1):
                    return True
                color[node] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
