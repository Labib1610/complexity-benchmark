# Problem A — Grid Harmonic Resonance

Time limit: 2 s
Memory limit: 256 MB

You are deploying a computational grid consisting of $n$ processing nodes. Your task is to configure the clock speed for each node. The available clock speed options for any node are 1, 2, and 3 GHz.

Certain pairs of nodes share a direct synchronization link. For any two linked nodes $u$ and $w$ assigned clock speeds $x$ and $y$ respectively (where $x$ is the speed of $u$ and $y$ is the speed of $w$), the synchronization controller evaluates the link's stability by constructing a diagnostic equation for each endpoint.

Node $u$ constructs the function $F_u(\lambda)$ over the complex numbers:
$F_u(\lambda) = \lambda^4 + (4 - x)\lambda^3 + (6 - 3x + u)\lambda^2 + (5 - 3x + 2u - u \cdot x)\lambda + (2 - 2x + u - u \cdot x)$

Node $w$ constructs its function $F_w(\lambda)$ symmetrically, using its own node label $w$ and clock speed $y$:
$F_w(\lambda) = \lambda^4 + (4 - y)\lambda^3 + (6 - 3y + w)\lambda^2 + (5 - 3y + 2w - w \cdot y)\lambda + (2 - 2y + w - w \cdot y)$

Due to hardware limitations, if there exists any complex number $\lambda$ such that both $F_u(\lambda) = 0$ and $F_w(\lambda) = 0$, the nodes will experience harmonic resonance and the link will fail. To ensure the grid is fully operational, every synchronization link must connect two nodes that do not experience harmonic resonance.

You are provided with the number of nodes and the exact pairs that share a synchronization link. You must output a fully functional clock speed assignment for the grid, or indicate if it is impossible.

## Input
The first line contains two integers $n$ and $m$ — the number of processing nodes and the number of synchronization links. The grid is housed in a server chassis that supports up to 40 nodes, so there is always at least one node and at most 40. The number of links can be anything from zero up to the theoretical maximum where every node is directly linked to every other node.
Each of the following $m$ lines contains two distinct integers $u$ and $w$, representing a pair of nodes connected by a synchronization link. Nodes are identified by integers from 1 to $n$. It is guaranteed that each unordered pair of nodes appears at most once in the input.

## Output
If no valid clock speed assignment can be found, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $a_1, a_2, \dots, a_n$ (where each $a_i \in \{1, 2, 3\}$), representing the clock speed assigned to node $i$. Any valid assignment will be accepted.

## Example 1

1 4
2 4
```
Output:
```
YES
1 2 3 3
```

```

<RATIONALE>
The resonance condition $V_u = V_w$ was replaced with the condition that two 4th-degree equations share a complex root. The equations are mathematically constructed such that they share a root if and only if $x=y$, but the factorization is deliberately obscured via a variable substitution ($\lambda = z-1$). This forces the model to either symbolically compute the resultant of two generic quartics (which is computationally infeasible without a code interpreter) or conceptually deduce the underlying graph coloring structure without algebraic proof. I also applied Strategy S07 to reword the input bounds into physical scenario constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The equations $F_u(\lambda)=0$ and $F_w(\lambda)=0$ are algebraically equivalent to $(\lambda-(x-1))((\lambda+1)^3+u(\lambda+1)+1)=0$ and $(\lambda-(y-1))((\lambda+1)^3+w(\lambda+1)+1)=0$; since the cubic factors have no positive integer roots and share no roots for distinct $u \neq w$, the only shared root occurs when $x=y$, preserving the exact same valid clock speed assignments.
</PRESERVED_ANSWER>
