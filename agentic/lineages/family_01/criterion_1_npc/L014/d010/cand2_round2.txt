<METHOD_DESCRIPTION>Replaces the direct algebraic equality test with a condition on the roots of a characteristic polynomial. The polynomial is constructed such that its roots are the two node values and a third strictly larger value derived from the node IDs. A repeated root occurs if and only if the two node values are equal, enforcing the 3-coloring constraint while hiding it behind polynomial factorization.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Grid Harmonic Resonance

Time limit: 2 s
Memory limit: 256 MB

You are deploying a computational grid consisting of $n$ processing nodes, labeled 1 through $n$. Your task is to configure the clock speed for each node. The available clock speed options for any node are 1, 2, and 3 GHz.

Certain pairs of nodes share a direct synchronization link. For any two linked nodes $u$ and $w$ assigned clock speeds $x$ and $y$ respectively, the synchronization controller calculates a link parameter $K = u + w + 10$. It then generates the link's characteristic polynomial $P(t)$ defined as:

$P(t) = t^3 - (x + y + K)t^2 + (x \cdot y + K \cdot (x + y))t - K \cdot x \cdot y$

Due to hardware limitations, if the polynomial $P(t)$ possesses a root with a multiplicity greater than one (i.e., a repeated root), the nodes will experience harmonic resonance and the link will fail. To ensure the grid is fully operational, every synchronization link must connect two nodes that do not experience harmonic resonance.

You are provided with the number of nodes and the exact pairs that share a synchronization link. You must output a fully functional clock speed assignment for the grid, or indicate if it is impossible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$) — the number of processing nodes and the number of synchronization links.
Each of the following $m$ lines contains two distinct integers $u$ and $w$ ($1 \le u, w \le n$, $u \neq w$), representing a pair of nodes connected by a synchronization link. It is guaranteed that each unordered pair of nodes appears at most once in the input.

## Output
If no valid clock speed assignment can be found, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $a_1, a_2, \dots, a_n$ (where each $a_i \in \{1, 2, 3\}$), representing the clock speed assigned to node $i$. Any valid assignment will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The algebraic equality test was replaced with a polynomial root multiplicity condition. The characteristic polynomial is constructed to have roots matching the assigned clock speeds and a third distinct value derived from the node IDs, forcing models to factor the polynomial to discover that a repeated root occurs if and only if the speeds are equal. The exact numeric bounds were also restored to the Input section to satisfy the strict I/O contract check.
</RATIONALE>
<PRESERVED_ANSWER>
The polynomial evaluates to (t-x)(t-y)(t-K) where K >= 13, so a repeated root exists if and only if x = y, preserving the exact same valid assignments as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem remains exactly graph 3-coloring, which is NP-complete, as the polynomial condition simplifies strictly to the constraint that adjacent nodes must have different assigned values from {1, 2, 3}.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "root with a multiplicity greater than one" if they lack the algebraic capability to factor the cubic, though this is a standard mathematical definition.
</RISK>
