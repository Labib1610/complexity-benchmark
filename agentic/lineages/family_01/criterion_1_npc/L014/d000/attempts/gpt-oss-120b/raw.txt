**Solution Explanation**

For every technician we have to choose one of three blocks.
Two technicians that are given as a *conflict pair* are not allowed to obtain the
same block.
The problem is exactly the **graph 3‑colouring** problem:

* vertices – technicians `1 … n`
* edges    – conflict pairs  
* colour   – block `1,2,3`

`n ≤ 40`, therefore a complete exponential search with good pruning is fast
enough.



--------------------------------------------------------------------

#### 1.   Data structures
* `adj[v]` – list of neighbours of vertex `v` (0‑based indices)
* `order` – vertices sorted by decreasing degree, this ordering reduces the
  branching factor.
* `col[v]` – current colour of vertex `v` (`0` = not coloured yet, otherwise `1,2,3`)

--------------------------------------------------------------------

#### 2.   Backtracking

```
dfs(pos):
    if pos == n:               # all vertices coloured
        return True
    v = order[pos]              # next vertex to colour
    for colour in (1,2,3):
        if colour is compatible with already coloured neighbours of v:
            col[v] = colour
            if dfs(pos+1):
                return True
            col[v] = 0          # undo
    return False                # no colour works
```

*Compatibility test* – iterate over `adj[v]`; if a neighbour already has the
same colour, the colour is forbidden.

The recursion depth is at most `n = 40`.  
The worst case is `3^40`, but the degree ordering and the early conflict test
prune the tree dramatically; for the given limits the program finishes well
within the time limit.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `YES` and a valid schedule iff such a
schedule exists.

---

##### Lemma 1  
During the execution of `dfs(pos)` the array `col` is a **partial proper
colouring** of the vertices already processed (`order[0 … pos‑1]`).

**Proof.**  
Induction over `pos`.

*Base*: `pos = 0`. No vertex is coloured – the statement holds.

*Step*: assume it holds for `pos`.  
When trying a colour `c` for vertex `v = order[pos]` the algorithm checks all
already coloured neighbours. If any neighbour has colour `c` the colour is
rejected. Therefore the colour that is finally assigned to `v` does not clash
with any coloured neighbour, and the invariant stays true for `pos+1`. ∎



##### Lemma 2  
If `dfs(pos)` returns `True`, the array `col` after the call is a **complete
proper 3‑colouring** of the whole graph.

**Proof.**  
`True` is returned only when either `pos == n` (all vertices coloured) or a
recursive call returned `True`. By Lemma&nbsp;1 the partial colouring is proper.
When `pos == n` every vertex has a colour, therefore the colouring is complete
and proper. The recursive case propagates the same complete colouring upwards.
∎



##### Lemma 3  
If a proper 3‑colouring exists, `dfs(0)` returns `True`.

**Proof.**  
Consider any proper 3‑colouring `C`. The recursion explores colours for each
vertex in the order `order`.  
When processing vertex `v = order[pos]`, the colour `C(v)` is compatible with
all already coloured neighbours (they already have the same colours as in `C`,
hence no conflict). Consequently the algorithm will **not** reject `C(v)`.  
Thus there is at least one branch of the search tree that follows exactly the
colouring `C` and reaches depth `n`, where it returns `True`. Hence the initial
call also returns `True`. ∎



##### Lemma 4  
If `dfs(0)` returns `False`, no proper 3‑colouring exists.

**Proof.**  
Assume a proper colouring existed. By Lemma&nbsp;3 the algorithm would have found
a successful branch and returned `True`, contradiction. ∎



##### Theorem  
The program outputs  

* `YES` and a schedule that satisfies all constraints **iff** such a schedule
  exists,
* otherwise it outputs `NO`.

**Proof.**  

*If part*: when `dfs(0)` returns `True`, by Lemma&nbsp;2 `col` is a complete
proper colouring, i.e. a valid schedule. The program prints `YES` and this
schedule.

*Only‑if part*: when the program prints `YES`, it must have obtained `True`
from `dfs(0)`, therefore a proper schedule exists (Lemma&nbsp;2).  
When the program prints `NO`, `dfs(0)` returned `False`; by Lemma&nbsp;4 no
proper schedule exists. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*`n ≤ 40`*  

Let `T` be the number of recursive calls actually performed.
Each call tries at most three colours and checks all neighbours of the current
vertex (degree ≤ n‑1).

```
Time   :  O( T · n )
Memory :  O( n )          (adjacency lists, colour array, recursion stack)
```

In the worst theoretical case `T = 3^n`, but for `n = 40` the degree ordering
and early conflict detection keep `T` far below this bound; the program runs
comfortably within the 2 seconds limit.

#### 5.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        if u == v:
            continue
        adj[u].append(v)
        adj[v].append(u)

    # order vertices by decreasing degree
    order = sorted(range(n), key=lambda x: -len(adj[x]))
    col = [0] * n                     # 0 = uncoloured, else 1..3

    def dfs(pos: int) -> bool:
        if pos == n:
            return True
        v = order[pos]
        # try colours 1,2,3
        for c in (1, 2, 3):
            ok = True
            for nb in adj[v]:
                if col[nb] == c:
                    ok = False
                    break
            if not ok:
                continue
            col[v] = c
            if dfs(pos + 1):
                return True
            col[v] = 0
        return False

    if dfs(0):
        out = ['YES', ' '.join(str(col[i]) for i in range(n))]
        sys.stdout.write('\n'.join(out))
    else:
        sys.stdout.write('NO')

if __name__ == "__main__":
    solve()
```
