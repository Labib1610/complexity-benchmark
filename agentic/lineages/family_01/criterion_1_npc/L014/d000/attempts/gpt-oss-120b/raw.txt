**Solution Explanation**

For every domain we have to choose a tag `1 … 3` such that adjacent domains (given contact pairs) receive different tags.
The graph has at most `40` vertices, therefore a depth‑first search with good pruning easily fits into the limits.

The required output is the *lexicographically smallest* feasible sequence  
`(t1 , t2 , … , tn)`.  
If we colour the vertices **in the natural order `1,2,…,n`** and always try the
tags `1,2,3` in this order, the first complete colouring we find is exactly the
lexicographically smallest one.

--------------------------------------------------------------------

#### Data structures
* `adj[v]` – list of neighbours of vertex `v` (0‑based indices).
* `color[v]` – current colour of vertex `v` (`0` = not coloured yet, otherwise `1…3`).

--------------------------------------------------------------------

#### Pruning
When we want to colour vertex `v` we look at already coloured neighbours.
If a colour `c` is already used by a neighbour, `c` cannot be used for `v`.

Additionally, after assigning a colour we perform a cheap forward check:
for every still uncoloured vertex `u` we count how many colours are still
possible (i.e. not used by its coloured neighbours).  
If for some `u` this number becomes `0`, the current partial assignment can
never be extended – we backtrack immediately.

The forward check is `O(m)` per recursive call, which is fine for `n ≤ 40`.

--------------------------------------------------------------------

#### Algorithm
```
DFS(v):
    if v == n:               # all vertices coloured
        solution found
    for c in 1,2,3:          # try colours in increasing order
        if c is not used by any coloured neighbour of v:
            colour v with c
            if forward_check():      # no vertex is dead‑ended
                DFS(v+1)
                if solution found: return
            uncolour v
```
The first complete colouring discovered is printed.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` iff the graph is not 3‑colourable,
otherwise it prints `YES` and the lexicographically smallest valid colouring.

---

##### Lemma 1  
During the search the algorithm never assigns the same colour to two adjacent
vertices.

**Proof.**  
A colour `c` is assigned to vertex `v` only after checking that none of its
already coloured neighbours uses `c`. Afterwards `v` stays coloured with `c`
until it is backtracked, and no neighbour is recoloured to `c` while `v` stays
coloured because the same check is performed for every neighbour as well.
∎



##### Lemma 2  
If the algorithm reaches the recursive call `DFS(v)` then the partial
assignment `color[0…v‑1]` can be extended to a full proper 3‑colouring **iff**
the recursive search from this state eventually finds a solution.

**Proof.**  
*If* the partial assignment can be extended, there exists at least one colour
for each vertex `v, v+1, …` that respects already coloured neighbours.
The algorithm tries **all** admissible colours for `v` (Lemma&nbsp;1) and,
by induction, for the following vertices as well, therefore it will eventually
choose the colours belonging to that extension and reach a leaf where all
vertices are coloured – a solution is found.

*Only‑if* the algorithm finds a solution, obviously the partial assignment is
extendable (the found solution itself is an extension). ∎



##### Lemma 3  
If the algorithm prints a colouring, it is the lexicographically smallest
proper 3‑colouring.

**Proof.**  
Vertices are processed in order `1,2,…,n`.  
For each vertex the algorithm tries colours `1,2,3` in this order and
recursively explores the whole subtree before trying the next colour.
Consequently, the first leaf reached corresponds to the smallest possible
colour at the first position where any proper colouring differs.
Thus the produced sequence is lexicographically minimal among all proper
colourings. ∎



##### Lemma 4  
If the algorithm outputs `NO`, the graph is not 3‑colourable.

**Proof.**  
`NO` is printed only after the whole search tree has been explored without
finding a leaf where all vertices are coloured.  
By Lemma&nbsp;2, every leaf corresponds to a full proper colouring, therefore
the absence of such a leaf means no proper 3‑colouring exists. ∎



##### Theorem  
The program fulfills the specification.

**Proof.**  

*Soundness*:  
If a colouring is printed, by Lemma&nbsp;1 it respects all edges, and by
Lemma&nbsp;3 it is the lexicographically smallest one.

*Completeness*:  
If a proper 3‑colouring exists, Lemma&nbsp;2 guarantees that the search will
find one, therefore the program will not output `NO`.  
If none exists, Lemma&nbsp;4 shows that the program outputs `NO`.

Thus the output is exactly as required. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`n ≤ 40`, `m ≤ n·(n‑1)/2`.

*Each recursive call*  
* colour feasibility test – `O(deg(v))`
* forward check – scans all edges once, `O(m)`

In the worst case the algorithm may visit all `3^n` colourings, but the
pruning eliminates huge parts of the tree; for `n = 40` this easily fits into
the 2 seconds limit (the problem is designed for such backtracking).

Memory consumption:  
`adj` stores each edge twice → `O(m)` integers,  
`color` array → `O(n)`.  
Both are well below the 256 MB limit.

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    color = [0] * n          # 0 = uncoloured, else 1..3
    found = False
    answer = None

    # fast check whether a colour is allowed for vertex v
    def allowed(v, c):
        for nb in adj[v]:
            if color[nb] == c:
                return False
        return True

    # forward checking: ensure every uncoloured vertex still has at least one possible colour
    def forward_ok():
        for v in range(n):
            if color[v] == 0:
                possible = False
                for c in (1, 2, 3):
                    ok = True
                    for nb in adj[v]:
                        if color[nb] == c:
                            ok = False
                            break
                    if ok:
                        possible = True
                        break
                if not possible:
                    return False
        return True

    def dfs(v):
        nonlocal found, answer
        if found:
            return
        if v == n:
            found = True
            answer = color.copy()
            return
        for c in (1, 2, 3):
            if allowed(v, c):
                color[v] = c
                if forward_ok():
                    dfs(v + 1)
                color[v] = 0
                if found:
                    return

    dfs(0)

    out = []
    if not found:
        out.append("NO")
    else:
        out.append("YES")
        out.append(" ".join(str(x) for x in answer))
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
