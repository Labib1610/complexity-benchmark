# Problem A — Sequential Pipeline Allocation

Time limit: 2 s
Memory limit: 256 MB

You are configuring a sequential processing pipeline that handles $n$ discrete tasks, numbered sequentially from 1 to $n$. The pipeline processes the tasks strictly in order of their ID, from 1 up to $n$. As each task enters the pipeline, it must be assigned to one of 3 parallel execution threads, labeled 1, 2, and 3.

You are provided with a list of $m$ retrospective conflict rules. Each rule specifies two distinct tasks, $u$ and $w$. The pipeline's safety monitor enforces these rules dynamically: whenever the pipeline processes the task with the larger ID in a conflict rule, it immediately checks the thread that was assigned to the task with the smaller ID. If both tasks were assigned to the exact same thread, the monitor flags a collision and halts the entire pipeline.

Your objective is to pre-compute a complete assignment of threads for all $n$ tasks such that the pipeline can process every task from 1 to $n$ without triggering any collisions.

## Input
The first line contains two integers $n$ and $m$ — the number of tasks and the number of conflict rules ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
Each of the following $m$ lines contains two distinct integers $u$ and $w$ ($1 \le u, w \le n$, $u \neq w$), representing a pair of tasks involved in a conflict rule. It is guaranteed that each unordered pair of tasks appears at most once in the input.

## Output
If no valid thread assignment can be found, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $a_1, a_2, \dots, a_n$ (where each $a_i \in \{1, 2, 3\}$), representing the thread assigned to task $i$. Any valid assignment will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
