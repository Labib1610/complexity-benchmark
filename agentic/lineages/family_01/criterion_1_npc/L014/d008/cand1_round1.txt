<METHOD_NAME>
Algebraic Identity Disguise
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaced the explicit extremal target (-4m) and the uniform polynomial with a non-extremal, assignment-dependent global target ("total system risk"). The per-edge polynomial now includes a node-based term ($f_u^2 + f_v^2$) which globally sums to exactly the total system risk, leaving a hidden positive-definite polynomial that evaluates to 0 if and only if $f_u \neq f_v$. This defeats models that rely on surface pattern matching of the constant minimum target to deduce the 3-coloring constraint, forcing them to either perform the algebraic simplification or write an unpruned brute-force search that will TLE.
</METHOD_DESCRIPTION>

yes

<STATEMENT>
# Problem A — Independent Audits

Time limit: 2 s   Memory limit: 256 MB

You are managing the annual compliance audit for a corporation with $n$ departments. The company requires each department to be audited by exactly one of three external agencies, labeled 1, 2, and 3.

Because departments collaborate, there are $m$ joint ventures between specific pairs of departments. The audit must be structured to meet a strict regulatory metric across these collaborations.

For each department $i$, its *baseline risk* is calculated as the square of its assigned agency label ($f_i^2$) multiplied by the number of joint ventures involving department $i$. The *total system risk* is the sum of the baseline risks across all $n$ departments.

For every joint venture between two departments $u$ and $v$ (assigned agencies $f_u$ and $f_v$), a *collaborative load* is computed using the following expression:
$$ f_u^2 + f_v^2 + 2(f_u - f_v)^4 - 10(f_u - f_v)^2 + 8 $$

An assignment of agencies to all $n$ departments is legally compliant if and only if the total sum of the collaborative loads over all $m$ joint ventures is exactly equal to the total system risk.

The corporate network can be highly interconnected, and the list of joint ventures is provided in no particular order. You must determine whether a compliant assignment exists.

## Input
The first line provides $n$ and $m$ — the number of departments and joint ventures, respectively ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
The following $m$ lines each contain two integers $u$ and $v$, representing a joint venture between department $u$ and department $v$. Departments are indexed from 1 to $n$.

## Output
If there is no way to assign agencies to satisfy the compliance metric, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $f_1, f_2, \dots, f_n$ (where $f_i \in \{1, 2, 3\}$ is the agency for department $i$). If multiple valid assignments exist, you must provide the one that is lexicographically smallest (comparing the agency of department 1 first, then department 2, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The models were shortcutting the problem by noticing that the polynomial evaluated to -4 for unequal labels and the global target was exactly -4m, making it obvious that every edge must hit the minimum possible value (different labels). I removed this affordance by shifting the target to an assignment-dependent sum (Total System Risk) and embedding an algebraic identity $\sum (f_u^2 + f_v^2) = \sum d_i f_i^2$ into the condition. To succeed, the model must now perform the non-trivial mathematical simplification to realize the residual polynomial forces $f_u \neq f_v$; otherwise, its unpruned backtracking will TLE.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $\sum (f_u^2 + f_v^2) = \sum d_i f_i^2$ is a graph identity, so the compliance requirement simplifies to $\sum (2(f_u - f_v)^4 - 10(f_u - f_v)^2 + 8) = 0$; since this polynomial equals 0 for $x \neq y$ and 8 for $x = y$, the sum is 0 if and only if every joint venture has different agencies, preserving the exact same valid assignments as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains strictly equivalent to finding the lexicographically smallest 3-coloring of a graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
The phrase "number of joint ventures involving department $i$" could theoretically be misinterpreted if a reader doesn't realize it means the degree of the vertex, but standard context makes this the only sensible interpretation.
</RISK>
