We can model this as a graph coloring problem with 3 colors (agencies 1, 2, 3).  

First, let’s analyze the interaction value formula:

\[
2(f_u - f_v)^4 - 10(f_u - f_v)^2 + 4
\]

Let \( d = f_u - f_v \). Possible values of \( d \) are \(-2, -1, 0, 1, 2\).

Compute:

- \( d = 0 \): \( 0 - 0 + 4 = 4 \)
- \( d = \pm 1 \): \( 2(1) - 10(1) + 4 = 2 - 10 + 4 = -4 \)
- \( d = \pm 2 \): \( 2(16) - 10(4) + 4 = 32 - 40 + 4 = -4 \)

So the interaction value is:
- \( 4 \) if same agency
- \( -4 \) if different agencies

We need total sum = \(-4m\).  
That means every edge must contribute \(-4\), i.e., **no two connected departments can have the same agency**.

So the problem reduces to:  
Can we 3-color the graph such that adjacent vertices have different colors?  
And we need the lexicographically smallest coloring.

Since \( n \le 40 \), we can use backtracking with pruning.

---

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n  # 0 = uncolored, 1,2,3 = agencies
    
    def backtrack(idx):
        if idx == n:
            return True
        for c in range(1, 4):
            ok = True
            for nb in adj[idx]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[idx] = c
                if backtrack(idx + 1):
                    return True
                color[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
