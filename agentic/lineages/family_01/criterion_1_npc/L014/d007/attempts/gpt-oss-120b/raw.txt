**Solution Explanation**

For an edge `{u,v}` let  

```
d = f[u] – f[v]          ( f[i] ∈ {1,2,3} )
value = 2·d⁴ – 10·d² + 4
```

`d` can only be `-2,-1,0,1,2`.

```
d = 0 : value = 4
|d| = 1 or 2 : value = -4
```

The required total over all `m` edges is `-4·m`.  
Therefore **every edge must contribute `-4`**, i.e. `d ≠ 0`.  
Consequently adjacent vertices must receive *different* numbers.

So the whole problem is exactly:

*Is the given graph 3‑colourable?*  
If yes, output the lexicographically smallest proper 3‑colouring
(colours are `1,2,3`).

`n ≤ 40`, therefore a simple depth‑first search with backtracking is
fast enough.

--------------------------------------------------------------------

#### Backtracking

Vertices are processed in the natural order `1 … n`.  
For the current vertex we try colours `1,2,3` in this order.
A colour is allowed iff none of the already coloured neighbours has the
same colour.

If we reach vertex `n+1` all vertices are coloured – we have found the
lexicographically smallest solution (the first one found).

The recursion depth is at most `40`; the branching factor is at most `3`,
and many branches are cut early by the adjacency test, so the program
runs well within the limits.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise prints `YES` and the lexicographically smallest valid
assignment.

---

##### Lemma 1  
For any edge `{u,v}` the expression  
`2(f_u-f_v)^4 - 10(f_u-f_v)^2 + 4` equals `-4` **iff** `f_u ≠ f_v`.

**Proof.**  
The possible differences are `-2,-1,0,1,2`. Direct calculation gives
`4` for `0` and `-4` for the other four values. ∎



##### Lemma 2  
An assignment satisfies the required total `-4m` **iff** it is a proper
3‑colouring of the graph (adjacent vertices have different colours).

**Proof.**  
By Lemma&nbsp;1 each edge contributes `-4` exactly when its ends have
different colours, otherwise it contributes `4`.  
The total is `-4m` precisely when every edge contributes `-4`,
i.e. when no edge has equal colours. ∎



##### Lemma 3  
During the search, when the algorithm assigns a colour to a vertex,
the partial assignment is always proper (no coloured edge has equal
colours).

**Proof.**  
A colour is chosen only after checking all already coloured neighbours;
the colour is rejected if any neighbour has the same colour.
Thus the invariant holds after each assignment. ∎



##### Lemma 4  
If the algorithm reaches depth `n+1` (all vertices coloured) the
produced assignment is a valid solution.

**Proof.**  
By Lemma&nbsp;3 the full assignment is proper, therefore by Lemma&nbsp;2
it satisfies the required total. ∎



##### Lemma 5  
If a valid assignment exists, the algorithm will eventually find one.

**Proof.**  
Consider any valid proper 3‑colouring `C`.  
Processing vertices in order `1…n`, at each vertex `v` the colour
`C(v)` is among the three tried colours and is not forbidden,
because all neighbours of `v` that appear earlier in the order already
have the same colours as in `C` (induction hypothesis) and differ from
`C(v)`. Hence the recursive call that follows `C(v)` is never pruned.
Thus the recursion can follow the whole sequence of colours of `C` and
reaches depth `n+1`. ∎



##### Lemma 6  
The first complete assignment found by the algorithm is the
lexicographically smallest among all valid assignments.

**Proof.**  
The search explores vertices in increasing order and, for each vertex,
tries colours `1,2,3` in increasing order.
Therefore the recursion tree is ordered exactly like lexicographic
comparison of the colour sequences.
Depth‑first search visits leaves (complete assignments) in that order.
Consequently the first leaf that is a valid assignment is the smallest
lexicographically. ∎



##### Theorem  
The program outputs  

* `NO` iff no assignment satisfies the required total,  

* otherwise `YES` and the lexicographically smallest satisfying
  assignment.

**Proof.**  

*If the program prints `YES`*: by Lemma&nbsp;4 the printed assignment is
valid. By Lemma&nbsp;6 it is the smallest one.

*If the program prints `NO`*: this happens only after the whole search
has been exhausted without reaching depth `n+1`. By Lemma&nbsp;5,
if a valid assignment existed the search would have found one.
Hence no valid assignment exists.

Conversely, if no valid assignment exists, the search cannot reach a
complete proper colouring, so the program prints `NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`n ≤ 40`, `m ≤ n·(n-1)/2`.

*Each recursive step* checks at most `deg(v) ≤ n-1` neighbours,
so `O(n)` time.

In the worst case the algorithm explores all `3^n` colourings,
giving `O(3^n · n)` time, but for `n = 40` the pruning is strong
and the actual number of visited nodes is far smaller; it easily fits
into the 2 s limit.

Memory consumption: adjacency lists `O(n + m)` and recursion stack
`O(n)`, well below the 256 MB limit.

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    colors = [0] * n          # 0 = unassigned, else 1..3
    found = False

    def dfs(v: int):
        nonlocal found
        if found:
            return
        if v == n:
            # all vertices coloured
            found = True
            return
        for c in (1, 2, 3):
            ok = True
            for nb in adj[v]:
                if colors[nb] == c:
                    ok = False
                    break
            if not ok:
                continue
            colors[v] = c
            dfs(v + 1)
            if found:
                return
            colors[v] = 0

    dfs(0)

    out = []
    if not found:
        out.append("NO")
    else:
        out.append("YES")
        out.append(" ".join(str(x) for x in colors))
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
