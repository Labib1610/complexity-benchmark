# Problem A — Grid Harmonic Resonance

Time limit: 2 s
Memory limit: 256 MB

You are deploying a computational grid consisting of $n$ processing nodes, labeled 1 through $n$. Your task is to configure the clock speed for each node. The available clock speed options for any node are 1, 2, and 3 GHz.

Certain pairs of nodes share a direct synchronization link. Due to hardware limitations, each link has a specific stability condition. For a synchronization link between node $u$ (with assigned clock speed $x$) and node $w$ (with assigned clock speed $y$), the hardware controller computes a stability metric as follows:

1. It defines a link parameter $z = u + w + 3$.
2. It calculates a sequence of five power sums $S_0, S_1, S_2, S_3, S_4$, where $S_k = x^k + y^k + z^k$. (Note that $S_0 = x^0 + y^0 + z^0 = 3$).
3. It constructs a $3 \times 3$ matrix $M$:
$$ M = \begin{pmatrix} S_0 & S_1 & S_2 \\ S_1 & S_2 & S_3 \\ S_2 & S_3 & S_4 \end{pmatrix} $$

The link will experience harmonic resonance and fail if the determinant of $M$ is exactly zero. To ensure the grid is fully operational, every synchronization link must have a strictly positive determinant.

You are provided with the number of nodes and the exact pairs that share a synchronization link. You must output a fully functional clock speed assignment for the grid, or indicate if it is impossible.

## Input
The first line contains two integers $n$ and $m$ — the number of processing nodes and the number of synchronization links ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
Each of the following $m$ lines contains two distinct integers $u$ and $w$ ($1 \le u, w \le n$, $u \neq w$), representing a pair of nodes connected by a synchronization link. It is guaranteed that each unordered pair of nodes appears at most once in the input.

## Output
If no valid clock speed assignment can be found, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $a_1, a_2, \dots, a_n$ (where each $a_i \in \{1, 2, 3\}$), representing the clock speed assigned to node $i$. Any valid assignment will be accepted.

## Example 1
Input:

1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

```

<RATIONALE>
The surviving model bypassed the intended search difficulty by recognizing the arithmetic rule as a simple `x != y` constraint, allowing it to reduce the problem to standard 3-coloring and apply powerful degree-ordered backtracking. To defeat this, the `x != y` condition was replaced with a mathematically equivalent but heavily obfuscated determinant of a Gram matrix of power sums. By incorporating the node indices into the parameter $z$, the constraint falsely appears to be edge-dependent, preventing the model from recognizing the uniform global structure required to trigger its optimized graph-coloring templates.
</RATIONALE>
<PRESERVED_ANSWER>
The matrix $M$ is the product of a Vandermonde matrix and its transpose, meaning its determinant is exactly $(x-y)^2(x-z)^2(y-z)^2$; since $z = u+w+3 \ge 6$ and $x, y \in \{1, 2, 3\}$, the determinant is strictly positive if and only if $x \neq y$, preserving all valid assignments exactly.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
