<STATEMENT>
# Quantum Resonance Synthesis

Time limit: 2 s   Memory limit: 256 MB

You are configuring a network of $n$ quantum resonance emitters. Each emitter $i$ (where $1 \le i \le n$) must be assigned an excitation state $e_i$, chosen from the discrete energy levels $\{1, 2, 3\}$.

The network's stability is constrained by $m$ proximity conditions. Each condition specifies two distinct emitters, identified by their indices $u$ and $v$, which share a quantum entanglement channel. To avoid destructive interference, their assigned states must satisfy a specific non-harmonic requirement.

Specifically, for each condition specifying emitters $u$ and $v$, you must evaluate the channel's stability using the following procedure:
Calculate the primary flux $F_1 = u \cdot e_v$
Calculate the cross flux $F_2 = v \cdot e_u$
The entanglement channel remains stable if and only if the total flux $(F_1 + F_2)$ is NOT a multiple of $(u + v)$. That is, $(F_1 + F_2) \pmod{u + v} \neq 0$. You must ensure this requirement holds for all $m$ conditions.

Your task is to determine whether there exists a global assignment of excitation states for all $n$ emitters such that all $m$ proximity conditions are satisfied simultaneously. If such an assignment exists, you must provide one. Providing any single valid assignment is sufficient, even if multiple exist.

## Input
The first line contains two integers $n$ and $m$ — the total number of emitters and the number of proximity conditions ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$, indicating a condition that the emitters $u$ and $v$ must satisfy the non-harmonic requirement.

## Output
If it is impossible to assign excitation states to all emitters such that every condition is satisfied, print a single line containing `NO`.
If it is possible, print `YES` on the first line. On the second line, print $n$ integers $e_1, e_2, \dots, e_n$ separated by spaces, where each $e_i \in \{1, 2, 3\}$ indicates the excitation state assigned to emitter $i$. You only need to supply one valid assignment, even if multiple are possible.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<METHOD_NAME>Barycentric Non-Integrality</METHOD_NAME>
<METHOD_DESCRIPTION>The pairwise inequality `e_u != e_v` is replaced by checking if the weighted sum `(u*e_v + v*e_u)` is a multiple of `(u+v)`. Because the states are restricted to `{1, 2, 3}` and `u != v`, this sum is a multiple of `(u+v)` if and only if `e_u == e_v`. This prevents the model from trivially factoring an algebraic expression to recover the graph coloring structure. Without explicitly recognizing the problem as proper 3-coloring, models will fall back to naive constraint satisfaction, losing the degree-descending search heuristic required to solve the NP-complete instances within the time limit.</METHOD_DESCRIPTION>

<PRESERVED_ANSWER>
The condition `(u*e_v + v*e_u) % (u+v) == 0` implies the weighted average `(u*e_v + v*e_u)/(u+v)` is an integer. For `e_u, e_v` in `{1, 2, 3}` and `u != v`, this strict convex combination can never be an integer unless `e_u == e_v`, making the new condition logically equivalent to `e_u != e_v` for all valid inputs.
</PRESERVED_ANSWER>

Since the local constraint evaluates to exactly `e_u != e_v`, the problem remains identical to proper 3-coloring on a graph, preserving its NP-complete complexity class.
