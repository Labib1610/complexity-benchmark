<METHOD_DESCRIPTION>Replaced the seed's modular arithmetic with an unfactored algebraic equation (u*e_u + v*e_v != u*e_v + v*e_u). This is mathematically identical to e_u != e_v, but it prevents the model from pattern-matching the problem to standard graph coloring. As a result, the model fails to deploy the degree-descending heuristic necessary to pass the time limit on 40-vertex instances, falling back to naive CSP backtracking which TLEs.</METHOD_DESCRIPTION>

<STATEMENT>
# Quantum Resonance Synthesis

Time limit: 2 s
Memory limit: 256 MB

You are configuring a network of $n$ quantum resonance emitters. Each emitter $i$ (where $1 \le i \le n$) must be assigned an excitation state, chosen from the discrete energy levels $\{1, 2, 3\}$.

The network's stability is constrained by $m$ proximity conditions. Each condition specifies two distinct emitters, identified by their indices $u$ and $v$, which share a quantum entanglement channel. To avoid destructive interference, their assigned excitation states $e_u$ and $e_v$ must satisfy a specific phase-balance equation. 

Specifically, for each of the $m$ conditions, the cross-weighted phase sum from $u$'s perspective must not equal the cross-weighted phase sum from $v$'s perspective. You must ensure that:
$u \cdot e_u + v \cdot e_v \neq u \cdot e_v + v \cdot e_u$

Your task is to determine whether there exists a global assignment of excitation states for all $n$ emitters such that all $m$ proximity conditions are satisfied simultaneously. If such an assignment exists, you must provide one. Providing any single valid assignment is sufficient, even if multiple exist.

## Input
The first line contains two integers $n$ and $m$ — the total number of emitters and the number of proximity conditions ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$, indicating a condition that the emitters $u$ and $v$ must satisfy the phase-balance requirement.

## Output
If it is impossible to assign excitation states to all emitters such that every condition is satisfied, print a single line containing `NO`.
If it is possible, print `YES` on the first line. On the second line, print $n$ integers $e_1, e_2, \dots, e_n$ separated by spaces, where each $e_i \in \{1, 2, 3\}$ indicates the excitation state assigned to emitter $i$. You only need to supply one valid assignment, even if multiple are possible.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the seed's modular arithmetic formula with an unfactored algebraic inequality `u * e_u + v * e_v != u * e_v + v * e_u`. While this evaluates exactly to `e_u != e_v`, it presents as a generic index-dependent CSP constraint. This prevents the survivor model from recognizing the standard graph coloring structure, thereby disabling its degree-descending backtracking heuristic. Without this heuristic, its fallback naive backtracking will TLE on dense 40-vertex instances.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic inequality simplifies to (u - v)(e_u - e_v) != 0, and since u and v are distinct emitters (u != v), this is strictly equivalent to e_u != e_v, maintaining the exact same valid assignments as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Vertex 3-Coloring on a general graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
A model might misread `u` and `v` as the states rather than the indices, though the text explicitly defines them as indices and `e_u`, `e_v` as the states.
</RISK>
