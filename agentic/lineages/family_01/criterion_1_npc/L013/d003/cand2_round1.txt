# Task Delegation

Time limit: 2 s
Memory limit: 256 MB

A software architecture comprises several interacting modules. During extensive testing, engineers have documented specific pairs of modules that suffer from critical operational interference if they share the same hardware resources. To maintain stability, safety protocols mandate that any two modules forming an interference pair must be physically separated during execution.

The deployment hardware is a specialized tri-core processor. This provides exactly three isolated processing units: the primary core, the secondary core, and the tertiary core. Every module must be delegated to exactly one of these cores.

The architectural framework is constrained by the main diagnostic board, which has exactly 40 hardware slots. Consequently, the total number of modules present in any deployment will never exceed 40, though there will always be at least one. The number of documented interference pairs can be anywhere from zero up to the maximum possible scenario where every module interferes with every other module.

Your objective is to process these constraints and determine if it is feasible to delegate all modules across the available cores without violating the interference protocols. If a valid configuration exists, you must provide one.

## Input
The first line contains two integers $n$ and $m$ — the total number of modules (numbered 1 to $n$) and the number of interference pairs. The values of $n$ and $m$ are guaranteed to respect the physical hardware limits described above.
Each of the subsequent $m$ lines contains two integers $u$ and $v$, indicating that module $u$ and module $v$ must be delegated to different cores.

## Output
If it is impossible to delegate all modules to the cores without violating the interference protocols, print a single line containing `NO`.
If it is possible, print `YES` on the first line. On the second line, print $n$ integers $e_1, e_2, \dots, e_n$ separated by spaces, where each $e_i \in \{1, 2, 3\}$ designates the core assigned to module $i$ (1 for the primary core, 2 for the secondary core, 3 for the tertiary core). You only need to supply one valid delegation, even if multiple are possible.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
