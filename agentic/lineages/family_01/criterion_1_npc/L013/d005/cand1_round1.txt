<STATEMENT>
# Spectral Configuration

Time limit: 2 s   Memory limit: 256 MB

You are configuring a system of $n$ discrete parameters. The maximum possible number of parameters $n$ is equal to the number of cells on the perimeter of an $11 \times 11$ square grid. Each parameter $e_i$ (where $1 \le i \le n$) must be assigned an integer state. The valid states are the positive integers strictly less than 4.

The system's stability is governed by $m$ spectral conditions. The number of conditions $m$ can be any integer from 0 up to the maximum number of unique pairs that can be formed from the $n$ parameters. Each condition specifies two parameters, $u$ and $v$. For the condition to be satisfied, the $2 \times 2$ matrix constructed from their states:
$$ \begin{pmatrix} e_u & 1 \\ 0 & e_v \end{pmatrix} $$
must possess exactly two distinct eigenvalues.

Your task is to evaluate whether there exists a global configuration for all $n$ parameters such that all $m$ spectral conditions are satisfied simultaneously. If a valid configuration is possible, you must provide one. Providing any single valid configuration is sufficient, even if multiple solutions exist.

## Input
The first line contains two integers $n$ and $m$ — the total number of parameters and the number of conditions.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ (where $1 \le u, v \le n$), indicating a condition that the parameters $e_u$ and $e_v$ must satisfy.

## Output
If it is impossible to assign values to all parameters such that every condition is satisfied, print a single line containing `NO`.
If it is possible, print `YES` on the first line. On the second line, print $n$ integers $e_1, e_2, \dots, e_n$ separated by spaces, where each $e_i$ indicates the state assigned to parameter $i$. You only need to supply one valid assignment.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit numeric bounds with derived combinatorial and geometric properties (the perimeter of an 11x11 grid naturally yields 40). I also completely removed the direct algebraic inequality `(e_u - e_v)^2 >= 1` and replaced it with a spectral condition on a triangular matrix. This forces the model to mathematically deduce that the eigenvalues are simply the diagonal entries, and that distinct eigenvalues mean the states must be unequal.
</RATIONALE>
<PRESERVED_ANSWER>
The characteristic polynomial of the upper triangular matrix gives eigenvalues exactly equal to the states $e_u$ and $e_v$, meaning the matrix has two distinct eigenvalues if and only if $e_u \neq e_v$, which perfectly matches the original inequality constraint.
</PRESERVED_ANSWER>

The problem remains exactly equivalent to 3-coloring on a graph with up to 40 vertices, which is NP-complete.
</PRESERVED_CLASS>
