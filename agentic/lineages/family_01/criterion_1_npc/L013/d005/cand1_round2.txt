<METHOD_NAME>Linear System Uniqueness Constraint</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit inequality (e_u - e_v)^2 >= 1 with a requirement that a 2x2 system of linear equations parameterized by s_u and s_v has a unique solution. This perfectly encodes s_u != s_v via the matrix determinant (s_u - s_v != 0), forcing models to algebraically deduce the disequality constraint rather than pattern-matching a graph coloring inequality.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Linear State Configuration

Time limit: 2 s   Memory limit: 256 MB

You are given a system consisting of $n$ discrete components. Each component $i$ (where $1 \le i \le n$) must be assigned a state value $s_i$ chosen from the set $\{1, 2, 3\}$.

The system's stability is determined by $m$ interaction conditions. Each condition specifies two components, $u$ and $v$. For the system to be stable, the state values assigned to these components must ensure that the following system of linear equations in variables $X$ and $Y$ has a unique solution:
$s_u X + Y = s_v$
$s_v X + Y = s_u$

Your task is to determine whether there exists a global state configuration for all $n$ components such that all $m$ interaction conditions are satisfied simultaneously. If a valid configuration is possible, you must provide one. Providing any single valid configuration is sufficient, even if multiple solutions exist.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the total number of components and the number of conditions.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating a condition involving components $u$ and $v$. It is guaranteed that each unordered pair $\{u, v\}$ appears at most once in the input.

## Output
If it is impossible to assign state values to all components such that every condition is satisfied, print a single line containing `NO`.
If it is possible, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ separated by spaces, where each $s_i \in \{1, 2, 3\}$ indicates the value assigned to component $i$. You only need to supply one valid assignment, even if multiple are possible.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit mathematical inequality `(e_u - e_v)^2 >= 1` from the seed immediately flags the problem as a graph coloring disequality constraint (`!=`) to language models. To defeat this, the disequality logic is embedded into the condition for a linear system to have a unique solution. Since the determinant of the coefficient matrix is `s_u - s_v`, the system has a unique solution if and only if `s_u != s_v`. This requires the model to perform a step of algebraic deduction to recover the underlying graph structure.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the linear system has a unique solution is mathematically equivalent to its determinant (s_u - s_v) being non-zero, which over integers exactly matches the seed's (e_u - e_v)^2 >= 1 constraint; thus, all valid assignments remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Vertex 3-Coloring, preserving its NP-complete complexity.
</PRESERVED_CLASS>
