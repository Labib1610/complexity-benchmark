We need to analyze the matrix equation:

\[
C = X^2 A + A X^2 + X A X - 6(X A + A X) + 11 A
\]

Since \(X\) is diagonal with entries \(e_i \in \{1,2,3\}\), we can simplify entry-wise.

Let’s compute the \((u,v)\) entry of each term:

- \(X^2 A\): \((X^2 A)_{u,v} = e_u^2 A_{u,v}\)
- \(A X^2\): \((A X^2)_{u,v} = A_{u,v} e_v^2\)
- \(X A X\): \((X A X)_{u,v} = e_u A_{u,v} e_v\)
- \(X A\): \((X A)_{u,v} = e_u A_{u,v}\)
- \(A X\): \((A X)_{u,v} = A_{u,v} e_v\)
- \(A\): \((A)_{u,v} = A_{u,v}\)

So for each edge \((u,v)\) with \(A_{u,v}=1\), the entry of \(C\) is:

\[
C_{u,v} = e_u^2 + e_v^2 + e_u e_v - 6(e_u + e_v) + 11
\]

We need this to be 0 for every edge.

So the condition is:

\[
e_u^2 + e_v^2 + e_u e_v - 6e_u - 6e_v + 11 = 0
\]

Let’s check possible values for \(e_u, e_v \in \{1,2,3\}\):

- (1,1): 1+1+1 -6-6+11 = 2 ≠ 0  
- (1,2): 1+4+2 -6-12+11 = 0 → works  
- (1,3): 1+9+3 -6-18+11 = 0 → works  
- (2,1): same as (1,2) → works  
- (2,2): 4+4+4 -12-12+11 = -1 ≠ 0  
- (2,3): 4+9+6 -12-18+11 = 0 → works  
- (3,1): same as (1,3) → works  
- (3,2): same as (2,3) → works  
- (3,3): 9+9+9 -18-18+11 = 2 ≠ 0  

So the only allowed pairs are:  
(1,2), (1,3), (2,1), (2,3), (3,1), (3,2).  
That means:  
- 1 can connect to 2 or 3  
- 2 can connect to 1 or 3  
- 3 can connect to 1 or 2  

So no two adjacent vertices can have the same value, and also (2,2) is forbidden, but that's already covered by "same value".  
Also (1,1) and (3,3) are forbidden. So the rule is: **adjacent vertices must have different values**.

Thus the problem reduces to:  
Can we 3-color the graph such that adjacent vertices have different colors?  
Since we have 3 colors and the graph is arbitrary, this is the 3-coloring problem. For n ≤ 40, we can use backtracking.

We just need to find any proper 3-coloring. If none exists, output NO.

Let's implement backtracking with pruning.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    colors = [0] * n  # 0 = uncolored, 1,2,3 = colors
    
    def backtrack(idx):
        if idx == n:
            return True
        # Try colors 1,2,3
        for c in (1,2,3):
            ok = True
            for nb in adj[idx]:
                if colors[nb] == c:
                    ok = False
                    break
            if ok:
                colors[idx] = c
                if backtrack(idx+1):
                    return True
                colors[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, colors)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
