# Quantum Resonance Synthesis

Time limit: 2 s   Memory limit: 256 MB

You are configuring a network of $n$ quantum resonance emitters. Each emitter $i$ (where $1 \le i \le n$) must be assigned an excitation state $e_i$, chosen from the discrete energy levels $\{1, 2, 3\}$.

The network contains $m$ entanglement channels, each connecting a specific pair of emitters $u$ and $v$. 
For any active channel between emitters $u$ and $v$, their interaction is governed by the expanded potential function:
$W(e_u, e_v) = e_u^4 - 4e_u^3 e_v + 6e_u^2 e_v^2 - 4e_u e_v^3 + e_v^4 - 5e_u^2 + 10e_u e_v - 5e_v^2 + 7$

The overall stability of the quantum network is determined by its total interaction energy, which is the sum of the potentials across all $m$ channels. For the network to achieve perfect resonance, this total interaction energy must be no greater than $3m$.

Your task is to determine whether there exists a global assignment of excitation states for all $n$ emitters such that the total interaction energy is no greater than $3m$. If such an assignment exists, you must provide one. Providing any single valid assignment is sufficient, even if multiple exist.

## Input
The first line contains two integers $n$ and $m$ — the total number of emitters and the number of entanglement channels ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n, u \neq v$), indicating a channel between emitters $u$ and $v$.

## Output
If it is impossible to assign excitation states to all emitters such that the total energy is no greater than $3m$, print a single line containing `NO`.
If it is possible, print `YES` on the first line. On the second line, print $n$ integers $e_1, e_2, \dots, e_n$ separated by spaces, where each $e_i \in \{1, 2, 3\}$ indicates the excitation state assigned to emitter $i$. You only need to supply one valid assignment.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I replaced the factored potential function with its fully expanded algebraic form and changed the global constraint from an exact equality to an inequality (`<= 3m`). This mathematically preserves the 3-coloring requirement (since the minimum channel energy is 3), but hides the $(e_u - e_v)$ dependence. Models can no longer immediately deduce the $e_u \neq e_v$ equivalence by eye, forcing them to implement a generic backtracking solver with a running sum instead of applying degree-ordered graph coloring heuristics.
</RATIONALE>
<PRESERVED_ANSWER>
The minimum value of the expanded polynomial for states in {1, 2, 3} is 3 (achieved when states differ), so a total energy no greater than 3m is only possible if every channel contributes exactly 3, preserving the exact same valid assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to proper 3-coloring on the given graph, which is NP-complete.
</PRESERVED_CLASS>
