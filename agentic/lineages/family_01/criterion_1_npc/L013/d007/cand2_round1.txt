<STATEMENT>
# Quantum Resonance Synthesis

Time limit: 2 s   Memory limit: 256 MB

You are configuring a network of $n$ quantum resonance emitters. Each emitter $i$ (where $1 \le i \le n$) must be assigned an excitation state $e_i$. The available states are positive integers up to the number of macroscopic spatial dimensions (which is exactly 3).

The network's stability is constrained by $m$ proximity conditions. Each condition specifies two emitters, identified by their indices $u$ and $v$, which share a quantum entanglement channel. 

To avoid destructive interference, their assigned states must satisfy a resonance constraint. Specifically, for each condition specifying emitters $u$ and $v$, you must calculate two interference values: $A = 2 e_u + e_v$ and $B = e_u + 2 e_v$. For the entanglement channel to remain stable, the greatest common divisor (GCD) of $A$ and $B$ must not be a multiple of the maximum possible excitation state (which is 3). You must ensure this requirement holds for all $m$ conditions.

Your task is to determine whether there exists a global assignment of excitation states for all $n$ emitters such that all $m$ proximity conditions are satisfied simultaneously. If such an assignment exists, you must provide one. Providing any single valid assignment is sufficient, even if multiple exist.

## Input
The first line contains two integers $n$ and $m$ — the total number of emitters and the number of proximity conditions. The network is installed in a specialized chassis with exactly 40 hardware slots, so $n$ is at least 1 and will never exceed this physical capacity. The number of conditions $m$ is at least 0 and can be up to the maximum possible number of unique pairs of emitters in the network.
Each of the subsequent $m$ lines contains two integers $u$ and $v$, indicating a condition that the emitters $u$ and $v$ must satisfy the resonance constraint.

## Output
If it is impossible to assign excitation states to all emitters such that every condition is satisfied, print a single line containing `NO`.
If it is possible, print `YES` on the first line. On the second line, print $n$ integers $e_1, e_2, \dots, e_n$ separated by spaces, where each $e_i$ is a positive integer no greater than 3 indicating the excitation state assigned to emitter $i$. You only need to supply one valid assignment, even if multiple are possible.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I replaced the matrix determinant condition with a mathematically equivalent but highly obscure greatest common divisor (GCD) constraint, and integrated Strategy S07 by expressing the numeric bounds indirectly through physical limits. By checking if `gcd(2x+y, x+2y)` is a multiple of 3, the model is forced to either deduce the underlying algebraic identity or rely on a generic, unoptimized CSP solver that lacks graph-coloring heuristics (like degree-based vertex ordering) and will fail to scale.
</RATIONALE>
<PRESERVED_ANSWER>
For any $x, y \in \{1, 2, 3\}$, the value of $\gcd(2x+y, x+2y)$ is a multiple of 3 if and only if $x = y$, meaning the new condition is strictly equivalent to requiring distinct states on adjacent nodes, preserving all valid assignments exactly.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to graph 3-coloring (an NP-complete problem), as the underlying constraint between any two connected nodes still algebraically simplifies to $e_u \neq e_v$.
</PRESERVED_CLASS>
<RISK>
Models might theoretically misinterpret "maximum possible number of unique pairs" if they fail to map it to the standard $n(n-1)/2$ complete graph edge count, though this is unlikely for competent readers.
</RISK>
