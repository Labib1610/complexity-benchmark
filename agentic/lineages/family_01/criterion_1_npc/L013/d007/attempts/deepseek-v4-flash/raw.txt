We can solve this by brute force over all \(3^n\) assignments, but \(n \le 40\) makes that impossible.  
Instead, we can reduce the problem to a 2-SAT or graph coloring style check.

First, let's analyze the condition:

We need \(e_u^3 + e_v^3 \not\equiv 0 \pmod{e_u^2 + e_v^2}\).

Let’s check all pairs of states from \(\{1,2,3\}\):

- (1,1): \(1+1=2\), \(1+1=2\), \(2 \bmod 2 = 0\) → invalid  
- (1,2): \(1+8=9\), \(1+4=5\), \(9 \bmod 5 = 4\) → valid  
- (1,3): \(1+27=28\), \(1+9=10\), \(28 \bmod 10 = 8\) → valid  
- (2,2): \(8+8=16\), \(4+4=8\), \(16 \bmod 8 = 0\) → invalid  
- (2,3): \(8+27=35\), \(4+9=13\), \(35 \bmod 13 = 9\) → valid  
- (3,3): \(27+27=54\), \(9+9=18\), \(54 \bmod 18 = 0\) → invalid  

So the only invalid pairs are when both emitters have the same state.  
Thus the condition is simply: **adjacent emitters must have different states**.

So the problem reduces to:  
Given a graph with \(n \le 40\) vertices, can we color it with 3 colors such that no two adjacent vertices share the same color?

This is the 3-coloring problem, which is NP-complete in general, but with \(n \le 40\) we can use backtracking with pruning.

We'll implement a backtracking search that assigns colors 1,2,3 to vertices, checking constraints.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n
    
    def backtrack(idx):
        if idx == n:
            return True
        # Try colors 1,2,3
        for c in (1,2,3):
            ok = True
            for nb in adj[idx]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[idx] = c
                if backtrack(idx+1):
                    return True
                color[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
