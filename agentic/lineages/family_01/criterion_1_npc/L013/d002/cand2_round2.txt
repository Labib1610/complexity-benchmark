# Roster Deconfliction

Time limit: 2 s   Memory limit: 256 MB

A manufacturing facility operates with a crew of $n$ personnel. The human resources department has flagged $m$ specific pairs of workers who have severe interpersonal conflicts. To ensure a harmonious environment, company policy strictly dictates that any two personnel involved in a flagged conflict must never be assigned to the same operational period.

The facility's daily operations are split into exactly three separate periods: period 1, period 2, and period 3.

Your task is to determine if there is a valid way to assign every single crew member to exactly one of these three periods such that no conflict rules are violated. If such a roster can be formed, you must provide it. Providing just one valid roster is sufficient, even if multiple correct arrangements exist.

Note that the flagged conflict pairs may be adversarially arranged to force exhaustive search, with both satisfiable and unsatisfiable hard instances present.

## Input
The first line contains two integers $n$ and $m$. The integer $n$ represents the total personnel count, which is at least 1 and at most 40 due to the facility's maximum workstation capacity. The integer $m$ represents the number of conflict pairs, which can range from 0 up to $n(n-1)/2$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
The following $m$ lines each contain two integers $u$ and $v$, indicating that personnel $u$ and personnel $v$ are in conflict and must work during different periods.

## Output
If no valid assignment exists that satisfies all conflict constraints, output a single line with the word `NO`.
If a valid assignment is possible, output `YES` on the first line. On the second line, output $n$ space-separated integers $s_1, s_2, \dots, s_n$, where each $s_i \in \{1, 2, 3\}$ denotes the period assigned to personnel $i$. Any valid roster is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
