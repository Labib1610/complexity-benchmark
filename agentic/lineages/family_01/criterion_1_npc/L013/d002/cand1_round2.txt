# Task Delegation

Time limit: 2 s   Memory limit: 256 MB

A software system consists of $n$ modules. Testing has revealed $m$ pairs of modules that exhibit critical interference when executed in the same environment. To ensure system stability, safety protocols dictate that the two modules in any identified interference pair must never be assigned to the same execution environment.

The system provides exactly three distinct execution environments: environment 1, environment 2, and environment 3.

The interference constraints can form complex, interlocking dependencies. Your solution must correctly process any configuration of constraints within the specified limits, verifying whether an allocation is possible or not.

You must determine whether it is feasible to allocate every module to exactly one of these three environments without violating the interference protocols. If a valid allocation is possible, you must provide one. You only need to supply one valid allocation, even if multiple are possible.

## Input
The first line contains two integers $n$ and $m$ — the total number of modules and the number of interference pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$, indicating that module $u$ and module $v$ must be allocated to different environments.

## Output
If it is impossible to allocate all modules to the environments without violating the interference protocols, print a single line containing `NO`.
If it is possible, print `YES` on the first line. On the second line, print $n$ integers $e_1, e_2, \dots, e_n$ separated by spaces, where each $e_i \in \{1, 2, 3\}$ indicates the environment assigned to module $i$. You only need to supply one valid allocation, even if multiple are possible.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
