We need to assign each microservice one of three tiers (1, 2, 3) such that no edge connects two nodes with the same tier.  
This is equivalent to a graph 3-coloring problem. Since n ≤ 40, we can use backtracking with pruning.

We want the lexicographically smallest assignment (comparing tier of node 1, then node 2, etc.).  
We can do DFS assigning nodes in order 1..n, trying tier 1 first, then 2, then 3, and checking constraints.

If we ever reach a dead end, backtrack.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n  # 0 = unassigned, 1..3 = tier

    def backtrack(idx):
        if idx == n:
            return True
        for c in (1, 2, 3):
            # check neighbors
            ok = True
            for nb in adj[idx]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[idx] = c
                if backtrack(idx + 1):
                    return True
                color[idx] = 0
        return False

    if backtrack(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
