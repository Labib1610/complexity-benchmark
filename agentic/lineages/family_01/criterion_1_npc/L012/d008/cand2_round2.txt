# Problem A — Antenna Allocation

Time limit: 2 s
Memory limit: 256 MB

You are deploying a network of $n$ antennas, indexed sequentially from $1$ to $n$. Each antenna must be assigned a frequency band. There are exactly three frequency bands available, represented by the integers 1, 2, and 3.

To prevent signal interference, certain pairs of antennas cannot operate on the same frequency band. You are given a list of $m$ interference constraints. For each constrained pair of antennas $u$ and $v$, they must be assigned different frequency bands.

Your objective is to find a valid frequency assignment for all $n$ antennas. If there are multiple valid assignments, you must select the optimal one based on the following priority rules:
1. Priority is given to using frequency band 1 for antennas with smaller indices. Specifically, between any two valid assignments, compare their usage of band 1. Find the smallest antenna index $i$ where one assignment uses band 1 and the other does not. The assignment that uses band 1 for antenna $i$ is strictly preferred.
2. If multiple valid assignments use frequency band 1 for the exact same subset of antennas, apply the identical logic for frequency band 2. Among those tied assignments, find the smallest antenna index $j$ where one uses band 2 and the other does not. The assignment that uses band 2 for antenna $j$ is strictly preferred.

If there is no way to assign the frequency bands without violating an interference constraint, you must report that it is impossible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of antennas and the number of interference constraints.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that antenna $u$ and antenna $v$ must be assigned different frequency bands.

## Output
If a valid assignment is impossible, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers from the set $\{1, 2, 3\}$, representing the frequency bands for antennas $1$ through $n$ in the optimal valid assignment.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
