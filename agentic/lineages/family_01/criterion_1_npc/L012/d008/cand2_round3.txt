# Problem A — Risk Audit

Time limit: 2 s
Memory limit: 256 MB

You are conducting a risk audit on a sequential ledger of financial transactions. The ledger contains $n$ transactions, processed in order and indexed from $1$ to $n$. Your task is to assign a risk tier, denoted as $c_i$, to each transaction $i$. The only permitted risk tiers are the scalar values $1$, $2$, and $3$.

The ledger is subject to regulatory rules defined by $m$ dependency links. Each link connects a pair of transactions $u$ and $v$. To prevent compliance violations, the risk tiers of any linked pair must be linearly independent when augmented with a unit vector. Specifically, for every link between transaction $u$ and transaction $v$, their assigned risk tiers $c_u$ and $c_v$ must satisfy the following determinant condition:
$$ \det \begin{pmatrix} c_u & c_v \\ 1 & 1 \end{pmatrix} \ne 0 $$
An assignment is compliant only if this condition holds for all $m$ links.

If multiple compliant assignments exist, you must identify the one that minimizes the final audit hash. The audit hash is derived by sequentially updating a state vector. Let the state after evaluating transaction $i$ be a column vector $V_i = \begin{pmatrix} H_i \\ 1 \end{pmatrix}$. The process begins with an initial state $V_0 = \begin{pmatrix} 0 \\ 1 \end{pmatrix}$. For each transaction $i$ from $1$ to $n$, the state is updated using the transformation matrix:
$$ V_i = \begin{pmatrix} 4 & c_i \\ 0 & 1 \end{pmatrix} V_{i-1} $$
You must output the compliant assignment that yields the minimum possible value for the top element of the final state vector $V_n$. If no compliant assignment is possible, you must report that it is impossible.

## Input
The first line contains two integers $n$ and $m$. The number of transactions $n$ is at least $1$ and at most the number of hours in a standard full-time workweek (40). The number of dependency links $m$ is at least $0$ and at most the maximum number of distinct unordered pairs of transactions.
The next $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), specifying a dependency link between transaction $u$ and transaction $v$.

## Output
If a compliant assignment is impossible, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers from the set $\{1, 2, 3\}$, representing the assigned risk tiers for transactions $1$ through $n$ that minimize the final audit hash.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2

```

1 3
1 4

3 4
```
Output:
```
NO
```
