**Solution Explanation**

For every microservice `i (1 … n)` we have to choose a tier `c[i] ∈ {1,2,3}`.
For every given pair `(u , v)` the two tiers must be different, i.e.

```
c[u] ≠ c[v] .
```

The task is exactly the *graph 3‑colouring* problem.
`n ≤ 40`, therefore a complete exponential search is still feasible
if strong pruning is used.

--------------------------------------------------------------------

#### 1.   Data structures  

* `adj[i]` – list of neighbours of vertex `i` (0‑based indices).  
* `col[i]` – current colour of vertex `i` (`0` = not coloured yet).  
* `mask[i]` – bitmask of still possible colours for vertex `i`  

```
bit 0 (value 1)  → colour 1 is still possible
bit 1 (value 2)  → colour 2 is still possible
bit 2 (value 4)  → colour 3 is still possible
```

Initially `mask[i] = 0b111` for all vertices.

--------------------------------------------------------------------

#### 2.   Backtracking in lexicographic order  

Vertices are processed **exactly** in the order `1,2,…,n`.
For vertex `v` we try the still possible colours `1,2,3` (in this order).
If a colour conflicts with an already coloured neighbour we skip it.
If it is compatible we

* fix `col[v]` to this colour,
* remove this colour from the masks of all *uncoloured* neighbours,
* abort the branch as soon as some neighbour’s mask becomes `0`,
* recurse to `v+1`,
* on backtracking restore all modified masks.

Because colours are tried increasingly, the first complete assignment found
is the lexicographically smallest one.

--------------------------------------------------------------------

#### 3.   Efficient undo of changes  

During one recursive call we have to remember which neighbour masks were
changed, otherwise they cannot be restored.
For every neighbour `to` whose mask is altered we push a pair
`(to, old_mask)` onto a local list `changed`.
After the recursive call (or after an early abort) we walk through this list
backwards and restore the saved masks.
The colour array `col` is also reset to `0`.

The whole algorithm works in `O( n + m )` memory  
(`adj` holds all edges, the other arrays have size `n`).

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints

*“YES” and the lexicographically smallest feasible tier assignment*  
or prints **NO** iff no feasible assignment exists.

---

##### Lemma 1  
During the search `mask[v]` always equals the set of colours that can still be
assigned to vertex `v` without immediately violating an already fixed edge.

**Proof.**  
Initially all three colours are possible → `mask[v]=0b111`.  
Whenever a neighbour `u` obtains colour `c`, colour `c` is removed from
`mask[v]` (if `v` is still uncoloured). No other operation changes `mask[v]`.
Thus `mask[v]` contains exactly those colours that are still compatible with
all already coloured neighbours. ∎



##### Lemma 2  
If the algorithm reaches recursion depth `k` (vertices `0 … k‑1` are coloured)
then the partial assignment `col[0 … k‑1]` satisfies all constraints that involve
only these vertices.

**Proof.**  
Induction over `k`.

*Base `k=0`*: empty assignment trivially satisfies everything.

*Induction step*: assume true for depth `k`.  
When the algorithm colours vertex `k` with colour `c`,
it first checks all already coloured neighbours – a conflict would abort the
branch. Therefore `c` differs from every coloured neighbour.
All edges that involve vertex `k` and an uncoloured vertex stay untouched,
hence the invariant holds for depth `k+1`. ∎



##### Lemma 3  
Whenever the algorithm backtracks from a recursive call,
the exact state (`col` and all `mask`) that existed before the call is
restored.

**Proof.**  
All modifications done inside the call are recorded in `changed`:
for each neighbour its mask before modification is stored.
After the recursive call (or after an early abort) the algorithm iterates
through `changed` and writes back the saved old masks, thereby undoing every
single change. The colour of the current vertex is also reset to `0`.
No other variable is altered. ∎



##### Lemma 4  
If a complete feasible colouring exists, the recursive search will eventually
reach it.

**Proof.**  
Consider any feasible colouring `C`.  
The algorithm processes vertices in order `0 … n‑1`.  
At vertex `v` the algorithm tries colours `1,2,3` in this order.
Because `C` is feasible, colour `C[v]` is still allowed by `mask[v]`
(Lemma&nbsp;1) and does not conflict with already coloured neighbours
(Lemma&nbsp;2). Hence the algorithm will **not** prune the branch that follows
exactly the colours of `C`. Recursively the same argument holds for all later
vertices, therefore the leaf representing `C` is visited. ∎



##### Lemma 5  
The first complete assignment output by the algorithm is the lexicographically
smallest feasible assignment.

**Proof.**  
Depth‑first search with the fixed vertex order and with colour choices tried
in increasing order enumerates all colourings in *lexicographic* order:
the first decision where two colourings differ is the colour of the smallest
index vertex where they differ, and the algorithm tries the smaller colour
first.  
Consequently, when the algorithm outputs the first leaf that satisfies all
edges, no earlier leaf (lexicographically smaller) can be feasible, otherwise
the algorithm would have stopped there. ∎



##### Lemma 6  
If the algorithm prints **NO**, then no feasible colouring exists.

**Proof.**  
The algorithm explores **every** leaf of the search tree that is not pruned
by an empty mask.  
By Lemma&nbsp;1 a mask becomes empty exactly when the current partial assignment
already forces a contradiction for some still uncoloured vertex,
hence no extension of this partial assignment can be feasible.
Thus pruning never discards a potentially feasible complete colouring.
If after exhaustive search no leaf is reached, there is no feasible colouring
at all. ∎



##### Theorem  
The program prints  

* “YES” followed by the lexicographically smallest tier assignment
  that satisfies all given pair constraints, **iff** such an assignment exists;
* otherwise it prints “NO”.

**Proof.**  

*Existence* – If a feasible assignment exists, Lemma&nbsp;4 guarantees that the
search reaches it, and Lemma&nbsp;5 shows that the first leaf found is the
lexicographically smallest one, which is printed after “YES”.

*Non‑existence* – If the algorithm finishes without finding a leaf,
by Lemma&nbsp;6 no feasible assignment exists, therefore it correctly prints
“NO”. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

`n ≤ 40`, `m ≤ n·(n‑1)/2`.

*Each recursive step* touches all neighbours of the current vertex  
(`deg(v)` operations).  
All modifications are undone in `O(deg(v))` as well.

In the worst case the algorithm may explore the whole search tree,
size `3^n`.  
However `n = 40` and the strong pruning (`empty mask`) cut the search
dramatically in practice; the worst‑case exponential bound is unavoidable
for an NP‑complete problem.

Memory consumption:

* adjacency list `O(n + m)`,
* colour array `O(n)`,
* masks `O(n)`,
* recursion stack depth `n`.

Overall `O(n + m)` ≤ `O( n² )` ≤ `1600` integers → far below the 256 MiB limit.

#### 6.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        if u == v:
            continue
        adj[u].append(v)
        adj[v].append(u)

    # 0 = uncoloured, otherwise 1,2,3
    col = [0] * n
    # bit mask of still possible colours, bits 0,1,2 = colours 1,2,3
    mask = [0b111] * n

    # depth‑first search respecting lexicographic order
    def dfs(v: int) -> bool:
        if v == n:
            return True

        # possible colours for this vertex, respecting current mask
        possible = []
        msk = mask[v]
        for c in (1, 2, 3):
            if msk & (1 << (c - 1)):
                # conflict with already coloured neighbours?
                conflict = False
                for nb in adj[v]:
                    if col[nb] == c:
                        conflict = True
                        break
                if not conflict:
                    possible.append(c)

        for c in possible:
            col[v] = c
            changed = []          # list of (vertex, old_mask)
            ok = True
            bit = 1 << (c - 1)

            # remove colour c from masks of uncoloured neighbours
            for nb in adj[v]:
                if col[nb] == 0:
                    old = mask[nb]
                    if old & bit:
                        new = old & ~bit
                        if new == 0:
                            ok = False
                        changed.append((nb, old))
                        mask[nb] = new
            if ok and dfs(v + 1):
                return True

            # backtrack: restore masks
            for nb, old in reversed(changed):
                mask[nb] = old
            col[v] = 0

        return False

    if dfs(0):
        sys.stdout.write("YES\n")
        sys.stdout.write(" ".join(str(c) for c in col) + "\n")
    else:
        sys.stdout.write("NO\n")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
