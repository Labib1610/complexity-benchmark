<STATEMENT>
# Problem A — Risk Audit

Time limit: 2 s
Memory limit: 256 MB

You are conducting a regulatory review on a sequential ledger of financial operations. The ledger contains $n$ operations, numbered sequentially from $1$ up to $n$. You must classify every operation $i$ by assigning it a security level $c_i$. The only permitted security levels are exactly the first three positive integers.

The audit data includes $m$ regulatory constraints between specific pairs of operations. To maintain strict compliance, no two operations connected by a constraint can share the same security level. Equivalently, for any constrained pair of operations, the set of their assigned security levels must have a cardinality of exactly two. Any violation of this condition results in an immediate audit failure.

You must determine a fully compliant security level classification for all $n$ operations. If multiple valid classifications exist, regulations require you to provide the one that is sequentially minimal. A classification sequence $A = (a_1, a_2, \dots, a_n)$ is defined to be sequentially minimal compared to another valid sequence $B = (b_1, b_2, \dots, b_n)$ if, at the first operation index $k$ (starting from $1$) where their assigned security levels differ, the level in $A$ is strictly less than the level in $B$.

If it is impossible to classify all operations without violating at least one constraint, you must declare the audit impossible.

## Input
The first line contains two integers $n$ and $m$. The operations are processed by a regulatory department that has a strict headcount of exactly forty compliance officers. Each operation requires a dedicated officer. Thus, the total number of operations $n$ is at least one and never exceeds this maximum headcount. The number of constraints $m$ is at least zero and at most the number of unique pairs that can be formed from the $n$ operations.

Following this, there are $m$ lines. Each line provides two integers $u$ and $v$ (which are strictly between $1$ and $n$ inclusive, and are never equal to each other), indicating that a regulatory constraint exists between operation $u$ and operation $v$.

## Output
If no compliant classification can be formed, output exactly one line containing the word `NO`.
If a valid classification exists, output `YES` on the first line. On the second line, output $n$ space-separated integers from the set $\{1, 2, 3\}$, representing the security levels assigned to operations $1$ through $n$ in the sequentially minimal valid classification.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
