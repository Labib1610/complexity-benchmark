<METHOD_NAME>Coupled Recurrence Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaced the explicit exponential weights in the objective function with a coupled linear recurrence that mathematically evaluates to the exact same values ($4^k$). This prevents models from immediately recognizing the objective as a simple lexicographical order. Without this deduction, models will write algorithms that attempt to exhaustively search all valid configurations to find the minimum, which will cause a Time Limit Exceeded (TLE) on $N=40$ for sparse graphs, rather than efficiently stopping at the first valid leaf. The graph coloring constraint is also disguised as a non-square product property.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Quantum Phase Amplification

Time limit: 2 s   Memory limit: 256 MB

You are engineering the support framework for a new quantum amplification circuit. The circuit consists of $n$ sequential amplification stages, indexed from $1$ to $n$. For each stage, you must choose a phase mode. There are exactly three phase modes available, represented by the integer values $1$, $2$, and $3$.

To ensure circuit stability, the stages are entangled by $m$ quantum links. Each link connects a specific pair of stages. Due to phase interference, if two stages connected by a link are assigned phase modes such that their product is a perfect square, the resulting resonance will destabilize the link. Therefore, any two connected stages must be configured to avoid this condition.

Your objective is to determine a safe phase configuration for the entire circuit. Let $c_i$ denote the phase mode assigned to stage $i$. If there is more than one safe configuration, you must output the one that yields the minimum possible value for the total system stress.

The total system stress is calculated as:
$$ \sum_{i=1}^{n} c_i \cdot W_{n-i} $$
where the weight sequence $W$ is defined by a coupled recurrence relation alongside an auxiliary sequence $V$:
- $W_0 = 1$
- $V_0 = 2$

For all $k \ge 1$:
- $W_k = 3 V_{k-1} - 2 W_{k-1}$
- $V_k = 7 V_{k-1} - 6 W_{k-1}$

If there is no way to assign the phase modes without destabilizing a link, you must report that the configuration is impossible.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of stages and the number of links, respectively.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that a link connects stage $u$ and stage $v$.

## Output
If a safe configuration is impossible, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers from the set $\{1, 2, 3\}$, representing the phase modes for stages $1$ through $n$ that minimize the total system stress.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The explicit base-4 formula was replaced with a coupled linear recurrence that mathematically guarantees $W_k = 4^k$. This breaks the immediate affordance of a lexicographical objective, forcing models that fail to dynamically analyze the sequence's growth to attempt an exhaustive search over all valid configurations instead of stopping at the first valid assignment. Additionally, the standard inequality constraint was recast as a perfect square check on the product of the two values, which evaluates identically for the domain {1, 2, 3} but obscures the graph coloring nature of the problem.
</RATIONALE>
<PRESERVED_ANSWER>
For values strictly in {1, 2, 3}, the product of two values is a perfect square if and only if the values are identical, perfectly preserving the inequality constraint; furthermore, the coupled recurrence mathematically yields $W_k = 4^k$, preserving the exact objective function and therefore the identical optimal sequence.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest valid 3-coloring of a graph, keeping it NP-complete.
</PRESERVED_CLASS>
