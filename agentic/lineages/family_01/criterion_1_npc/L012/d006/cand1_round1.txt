<STATEMENT>
# Problem A — Frequency Allocation

Time limit: 2 s   Memory limit: 256 MB

You are engineering the support framework for a new pavilion. The framework consists of $n$ vertical load-bearing columns, which are indexed from $1$ to $n$. For each column, you must choose a material density class. The available density classes are represented by the strictly positive integers whose squares are strictly less than $10$.

To ensure structural integrity, the columns are braced by $m$ horizontal struts. Each strut links a specific pair of columns. Due to acoustic resonance, if two columns linked by a strut share the exact same density class, the resulting vibrations will fracture the strut. Therefore, any two columns connected by a strut must be configured with strictly different density classes.

Your objective is to determine a safe density configuration for the entire framework. Let $c_i$ denote the density class assigned to column $i$. If there is more than one safe configuration, you must output the one that yields the minimum possible value for the resonance potential, which is calculated as:
$$ \sum_{i=1}^{n} c_i \cdot 2^{2(n-i)} $$
If there is no way to assign the density classes without causing a fracture, you must report that the configuration is impossible.

Please note: The test data include frameworks with structural patterns specifically tailored to cause any evaluation strategy that processes columns in a strict index sequence to explore an excessive number of invalid partial assignments.

## Input
The first line provides two integers $n$ and $m$. The site's footprint restricts the number of columns $n$ to be at least $1$ and at most the atomic number of Zirconium. The number of struts $m$ can range from $0$ up to the maximum possible number of distinct pairs that can be formed from the $n$ columns.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that a strut connects column $u$ and column $v$.

## Output
If a safe configuration is impossible, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers representing the density classes for columns $1$ through $n$ that minimize the resonance potential.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The problem's objective function is mathematically equivalent to finding the lexicographically smallest 3-coloring. Naive fixed-index DFS naturally finds this optimum on its first valid assignment. By adding a mechanical warning that index-sequential processing will explore an excessive number of invalid partial assignments, the model is baited into implementing dynamic variable ordering (like MRV) to avoid a timeout. This destroys the lexicographical guarantee, forcing the model into either a Wrong Answer or an exhaustive search that results in a Time Limit Exceeded.
</RATIONALE>
<PRESERVED_ANSWER>
The available density classes are exactly 1, 2, and 3, and the objective function $c_i \cdot 2^{2(n-i)}$ is mathematically identical to $c_i \cdot 4^{n-i}$, ensuring the same configuration minimizes the potential.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-coloring on a general graph with a positional objective function, preserving its NP-complete status.
</PRESERVED_CLASS>
<RISK>
Models might struggle to parse the atomic number of Zirconium as exactly 40, though this is a standard scientific fact well within their training data.
</RISK>
