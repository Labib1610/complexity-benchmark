We can model this as a graph coloring problem with 3 colors, where each edge requires the two endpoints to have different colors (exactly two distinct values among the two).  

That means:  
- No edge can have both endpoints the same color.  
- Also, no edge can have both endpoints using all three colors (impossible anyway since only two nodes).  

So the constraint is simply: adjacent nodes must have different colors.  

We need to find the lexicographically smallest (in terms of the hash) assignment of colors 1, 2, 3.  

Since \( n \le 40 \), we can use backtracking with pruning, or we can use a greedy approach with constraint propagation.  

The hash formula:  
\[
\sum_{i=1}^n c_i \cdot 2^{2n - 2i}
\]
This is like a base-4 number where each digit is \(c_i\) (1, 2, or 3).  
To minimize it, we want the earliest positions (small i) to have the smallest possible values.  

So we can do a DFS over nodes in order 1..n, trying colors 1, 2, 3 in that order, and checking constraints with already colored neighbors.  

We also need to handle disconnected components — each component can be colored independently, but we still process nodes in index order.  

Let’s implement this.  

```python
import sys

sys.setrecursionlimit(10000)

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n
    found = False
    
    def dfs(idx):
        nonlocal found
        if idx == n:
            found = True
            return True
        for c in (1, 2, 3):
            ok = True
            for nb in adj[idx]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[idx] = c
                if dfs(idx + 1):
                    return True
                color[idx] = 0
        return False
    
    if dfs(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
