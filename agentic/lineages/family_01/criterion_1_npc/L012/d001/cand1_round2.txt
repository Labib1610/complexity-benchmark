# Problem A — Environment Provisioning

Time limit: 2 s   Memory limit: 256 MB

You are configuring a network of $n$ deployment modules, which are identified by integers from 1 to $n$. Each module must be assigned to an operational environment. There are exactly three possible environments, represented by the integer values 1, 2, and 3.

Extensive testing has revealed interference between certain pairs of modules. If two modules that interfere are placed into the exact same environment, the network will fail. To guarantee stability, you must ensure that for every known interference, the two modules involved are assigned to different environments.

You need to determine a valid environment assignment for all $n$ modules. In cases where multiple valid assignments exist, you must prioritize the configuration that assigns the smallest possible environment value to module 1. If ties remain, break them by minimizing the environment value for module 2, continuing this sequential element-by-element comparison up to module $n$. If no valid assignment can be found, you must report this failure.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of deployment modules and the number of interfering pairs.
The following $m$ lines each contain two distinct integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that module $u$ and module $v$ interfere with each other.

## Output
If the network cannot be stabilized, output a single line containing the word NO.
Otherwise, output YES on the first line. On the second line, output $n$ space-separated integers (each being 1, 2, or 3), representing the environments assigned to modules 1 through $n$ respectively, strictly following the tie-breaking rules described above.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
