# Problem A — Deployment Tiers

Time limit: 2 s   Memory limit: 256 MB

A software architecture contains $n$ microservices, indexed from 1 to $n$. You are required to allocate each microservice to exactly one security tier. The available tiers are exactly 1, 2, and 3.

Certain pairs of microservices have known parallel execution flaws. For any such pair, the two microservices must be allocated to different security tiers to maintain system stability.

Your task is to find a valid tier allocation for all $n$ microservices. When multiple valid allocations exist, you must select the one that minimizes the tier of microservice 1. If there are still multiple options, minimize the tier of microservice 2, and so on, comparing element by element up to microservice $n$. If no valid allocation can be found, you must indicate this.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of microservices and the number of flawed pairs.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), specifying a pair of microservices that share a flaw.

## Output
If no stable allocation is possible, output NO on a single line.
Otherwise, output YES on the first line. On the second line, output $n$ space-separated integers representing the tiers of microservices 1 through $n$ in the optimally chosen allocation.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
