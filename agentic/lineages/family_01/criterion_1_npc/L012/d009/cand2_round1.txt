<METHOD_NAME>Global Product of Definite Integrals</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the local $u \neq v$ inequality with a global constraint: the product of definite integrals over a strictly positive polynomial must be non-zero. The integral $\int_{u}^{v} (3t^2 - 2t + 1)dt$ evaluates to 0 if and only if $u=v$. By requiring the global product of these integrals across all links to be non-zero, the problem mathematically demands that $u \neq v$ for all given pairs. However, presenting it as a single global product obscures the independence of the conditions, tricking models into evaluating the constraint only on fully populated configurations. This prevents early pruning in backtracking and forces an $O(3^{40})$ Time Limit Exceeded, or causes logic failures if the model cannot symbolically evaluate the integral.</METHOD_DESCRIPTION>

# Problem A — Quantum-Thermal Stability

Time limit: 2 s
Memory limit: 256 MB

You are tasked with configuring the initial state of a quantum-thermal network consisting of $n$ isolated chambers, indexed from $1$ to $n$. Each chamber $i$ must be assigned a discrete state variable $s_i$. Due to hardware constraints, each state variable must be chosen from the set $\{1, 2, 3\}$.

The network features $m$ bidirectional thermal conduits. The $k$-th conduit connects chamber $u_k$ and chamber $v_k$. The state variables of the connected chambers determine the thermal flux across each conduit. For a conduit connecting $u_k$ and $v_k$, the flux $F_k$ is defined by the definite integral of the medium's specific heat capacity function:
$$F_k = \int_{s_{u_k}}^{s_{v_k}} (3t^2 - 2t + 1) \, dt$$

The network's global resonance $\Omega$ is defined as the product of the flux values across all $m$ conduits:
$$\Omega = \prod_{k=1}^m F_k$$
(If $m=0$, the network has no conduits, and the empty product $\Omega$ is defined as $1$).

The network is considered strictly stable if and only if its global resonance $\Omega$ is non-zero.

Your objective is to determine a valid configuration of state variables for all $n$ chambers such that the network is strictly stable. If there is more than one stable configuration, you must output the one that is lexicographically smallest. A configuration sequence $A = (a_1, a_2, \dots, a_n)$ is lexicographically smaller than sequence $B = (b_1, b_2, \dots, b_n)$ if, at the first index $i$ where they differ, $a_i < b_i$.

If it is impossible to achieve a strictly stable configuration, you must report that it is impossible.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of chambers and the number of conduits.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that a bidirectional conduit connects chamber $u$ and chamber $v$.

## Output
If a stable configuration is impossible, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers from the set $\{1, 2, 3\}$, representing the assigned state variables for chambers $1$ through $n$ in the lexicographically smallest stable configuration.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

I completely removed the graph coloring and ledger terminology, replacing it with a quantum-thermal network scenario. The core constraint $a_i \neq b_i$ is now mathematically disguised as a definite integral of a strictly positive quadratic function, which evaluates to 0 if and only if the bounds are equal. Furthermore, instead of applying this constraint locally to each pair, it is aggregated into a single global product $\Omega$ that must be non-zero. This forces the model to either symbolically prove that the global product being non-zero implies all local pairs must have distinct states (enabling early pruning), or fall into the trap of evaluating the condition only at the leaves of the search tree, which will inevitably Time Out on $3^{40}$ configurations.
</RATIONALE>
<PRESERVED_ANSWER>
The polynomial $3t^2 - 2t + 1$ is strictly positive for all real $t$, meaning its definite integral is 0 if and only if the upper and lower bounds are identical; thus the global product $\Omega \neq 0$ is mathematically identical to requiring $s_u \neq s_v$ for every linked pair, preserving all valid configurations.
