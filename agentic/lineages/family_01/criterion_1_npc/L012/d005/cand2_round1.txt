<STATEMENT>
# Problem A — Quantum State Calibration

Time limit: 2 s   Memory limit: 256 MB

You are calibrating a quantum array of $n$ qubits, numbered sequentially from $1$ to $n$. Each qubit must be initialized to a basis state represented by an integer from the set $\{1, 2, 3\}$.

The array features $m$ entanglement links, each connecting a pair of qubits. Stability tests reveal a critical constraint: if any two qubits connected by a link are assigned basis states such that the product of their states is a perfect square, the link will immediately collapse. Consequently, for every pair of qubits joined by a link, the product of their assigned states must not result in a perfect square.

Your task is to find a valid initialization for all $n$ qubits. To ensure the system remains at the lowest possible overall energy level, you must apply a specific preference rule if multiple valid initializations exist. Imagine the sequence of assigned states as an $n$-digit decimal integer, where the state of qubit $1$ forms the most significant digit, the state of qubit $2$ forms the next most significant digit, and so on, down to qubit $n$ as the least significant digit. You must select the valid initialization that forms the strictly smallest possible $n$-digit integer. If no valid initialization can be found, you must state that it is impossible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of qubits and the number of entanglement links.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), representing an entanglement link between qubit $u$ and qubit $v$.

## Output
If no valid initialization exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers from the set $\{1, 2, 3\}$, representing the basis states for qubits $1$ through $n$, adhering to the specified preference rule.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The problem domain was changed to quantum state calibration to remove structural engineering terminology. The inequality constraint (u != v) was replaced with a mathematically equivalent condition: for values in {1,2,3}, their product is a perfect square if and only if they are equal. The lexicographical tie-breaking rule was replaced with minimizing the equivalent n-digit decimal integer. This forces models to deduce the equivalence to inequality and ordered backtracking; models that naively attempt to collect all solutions and minimize the integer will fail due to time limits.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the product is not a perfect square exactly maps to the states being strictly different, and minimizing the n-digit integer exactly maps to lexicographically smallest tie-breaking, ensuring identical valid assignments and identical outputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically first valid 3-coloring of a graph, preserving its NP-Complete complexity.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "decimal integer" as requiring a base-10 conversion from binary, but the definition explicitly states the states (1, 2, 3) form the digits directly, making the numerical interpretation unambiguous.
</RISK>
