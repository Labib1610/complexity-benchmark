<STATEMENT>
# Problem A — Frequency Allocation

Time limit: 2 s   Memory limit: 256 MB

You are engineering the support framework for a new pavilion. The framework consists of $n$ vertical load-bearing columns, which are indexed from $1$ to $n$. For each column, you must choose a material density class. There are exactly three density classes available, represented by the values $1$, $2$, and $3$.

To ensure structural integrity, the columns are braced by $m$ horizontal struts. Each strut links a specific pair of columns. Due to acoustic resonance, if two columns linked by a strut share the exact same density class, the resulting vibrations will fracture the strut. Therefore, any two columns connected by a strut must be configured with strictly different density classes.

Your objective is to determine a safe density configuration for the entire framework. Let $c_i$ denote the density class assigned to column $i$. If there is more than one safe configuration, you must output the one that yields the minimum possible value for the resonance potential, which is calculated using the formula:
$$ \sum_{i=1}^{n} c_i \cdot 4^{n-i} $$
If there is no way to assign the density classes without causing a fracture, you must report that the configuration is impossible.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of columns and the number of struts, respectively.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that a strut connects column $u$ and column $v$.

## Output
If a safe configuration is impossible, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers from the set $\{1, 2, 3\}$, representing the density classes for columns $1$ through $n$ that minimize the resonance potential.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>

<RATIONALE>
I replaced the explicit procedural instruction for lexicographical tie-breaking with a mathematically equivalent objective function (evaluating the sequence as a base-4 polynomial). This forces the model to either analytically deduce that the function perfectly maps to lexicographical order, or naively implement a global minimum search over all valid configurations, which will time out on $n=40$.
</RATIONALE>

<PRESERVED_ANSWER>
Because $c_i \in \{1, 2, 3\}$ and the base is $4$, the polynomial's value strictly preserves the lexicographical ordering of the sequences, meaning the minimum cost configuration is exactly the lexicographically smallest valid assignment.
</PRESERVED_ANSWER>

<PRESERVED_CLASS>
The problem remains exactly 3-coloring on a graph with $n$ vertices and $m$ edges, which is NP-complete.
</PRESERVED_CLASS>

<RISK>
Models using languages with strict 64-bit integer limits (like C++) might attempt to compute the $4^{40}$ term directly and encounter overflow, leading to runtime errors or incorrect comparisons instead of a clean algorithmic timeout.
</RISK>
