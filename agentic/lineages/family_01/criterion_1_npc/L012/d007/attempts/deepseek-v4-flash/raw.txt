We need to assign each transaction a value from {1, 2, 3} such that for every edge (u, v), the determinant condition holds:

\[
\det \begin{pmatrix} c_u & c_v \\ 1 & 1 \end{pmatrix} = c_u - c_v \neq 0
\]

So the condition simply means **c_u ≠ c_v** for every edge.  
Thus, the problem reduces to a **graph coloring problem** with 3 colors, where adjacent nodes must have different colors.

We also need to minimize:

\[
\sum_{i=1}^n c_i \cdot 2^{2n - 2i}
\]

Since \(2^{2n-2i}\) is a decreasing power of 4 as \(i\) increases, the earlier positions have much higher weight.  
So we want the lexicographically smallest sequence \(c_1, c_2, \dots, c_n\) among all valid 3-colorings.

---

### Approach

- Build the graph from edges.
- Try to color nodes 1..n in order, assigning the smallest possible color (1, then 2, then 3) that doesn't conflict with already colored neighbors.
- If at some point no color works, backtrack.
- Since n ≤ 40, we can use backtracking with pruning.  
  But we can also use a greedy + backtracking approach because the search space is small enough with 3 colors and n=40 in practice.

We'll implement a backtracking search that tries colors in order 1, 2, 3 for each node, and stops at the first complete valid coloring (which will be lexicographically smallest).

---

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    colors = [0] * n
    
    def backtrack(idx):
        if idx == n:
            return True
        for c in (1, 2, 3):
            ok = True
            for nb in adj[idx]:
                if colors[nb] == c:
                    ok = False
                    break
            if ok:
                colors[idx] = c
                if backtrack(idx + 1):
                    return True
                colors[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, colors)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
