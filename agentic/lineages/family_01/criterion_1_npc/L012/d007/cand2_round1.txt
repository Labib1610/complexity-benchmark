<METHOD_DESCRIPTION>I embedded the objective function (which strictly enforces lexicographical order) into the sum of the components of a matrix-vector product. By applying a change of basis to a simple upper-triangular scaling matrix, the resulting matrix $M_i$ looks mathematically opaque. The LLM will no longer recognize that the objective is minimized by the lexicographically smallest sequence, forcing it to evaluate all valid assignments rather than stopping at the first one, which will cause a Time Limit Exceeded on sparse graphs.</METHOD_DESCRIPTION>

# Problem A — Optical Network Tuning

Time limit: 2 s
Memory limit: 256 MB

You are tuning a sequence of $n$ optical filters, indexed from $1$ to $n$. For each filter $i$, you must assign a polarization mode $c_i$. There are exactly three available modes, represented by the values $1$, $2$, and $3$.

The network contains $m$ interference constraints. Each constraint specifies a pair of filters. To prevent resonance failure, for every such pair, the two filters must be assigned strictly distinct modes (i.e., if a constraint connects filter $u$ and filter $v$, then $c_u \ne c_v$). If this condition fails for any constraint, the network becomes unstable.

The optical transfer matrix of filter $i$ is defined as:
$$ M_i = \begin{pmatrix} 5+c_i & -3-c_i \\ -3+c_i & 5-c_i \end{pmatrix} $$

The total transfer matrix of the system is the product of these matrices in sequence:
$$ F = M_1 \times M_2 \times \dots \times M_n $$

A test signal, represented by the column vector $V_{in} = \begin{pmatrix} 1 \\ 0 \end{pmatrix}$, is injected into the first filter. The output signal is given by $V_{out} = F \times V_{in}$. The total output intensity of the network is defined as the sum of the two components of the column vector $V_{out}$.

Your objective is to determine a valid mode configuration for all $n$ filters that prevents resonance failure. If there are multiple valid configurations, you must output the one that yields the minimum possible total output intensity. (It is guaranteed that for any valid network, the sequence of modes that minimizes the intensity is unique). If there is no way to assign the modes without a resonance failure, you must report that the configuration is impossible.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of optical filters and the number of interference constraints.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that an interference constraint exists between filter $u$ and filter $v$.

## Output
If a valid configuration is impossible, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers from the set $\{1, 2, 3\}$, representing the polarization modes for filters $1$ through $n$ that minimize the total output intensity.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The models previously succeeded by recognizing that the original objective function strictly enforced a lexicographical minimum, allowing them to stop their backtracking search at the first valid assignment found. I converted the objective function into a matrix chain multiplication using a change of basis. This preserves the exact mathematical minimum but completely obfuscates the lexicographical property, forcing models to exhaustively evaluate all valid assignments and causing a Time Limit Exceeded on sparse graphs.
</RATIONALE>
<PRESERVED_ANSWER>
The total output intensity evaluates exactly to $2^n (1 + \sum_{i=1}^n c_i 4^{n-i})$, which is a strictly increasing function of the original objective, ensuring the unique minimum configuration remains perfectly identical.
</PRESERVED_ANSWER>
