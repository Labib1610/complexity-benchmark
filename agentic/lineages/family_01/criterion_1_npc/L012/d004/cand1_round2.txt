<STATEMENT>
# Problem A — Resonant Frequencies

Time limit: 2 s   Memory limit: 256 MB

You are finalizing the architectural plans for a large pavilion supported by $n$ load-bearing pillars. The pillars are sequentially numbered from 1 to $n$. For each pillar, you must specify a material density grade. There are exactly three allowed density grades, represented by the numeric values 1, 2, and 3.

To provide horizontal stability, the design includes $m$ rigid cross-beams. Each cross-beam connects two specific pillars. However, wind tunnel testing has revealed a critical flaw: if any two pillars connected by a cross-beam are constructed using the exact same density grade, they will share the same resonant frequency. Under high winds, this resonance will amplify and shatter the cross-beam. Therefore, the two pillars connected by any cross-beam must always be built with differing density grades.

You must determine a safe density grade assignment for all $n$ pillars. If there are several safe ways to assign the grades, you must evaluate them by imagining the sequence of $n$ assigned grades written consecutively to form a single $n$-digit integer in base 10. In this integer, the grade of pillar 1 is the most significant (leading) digit, the grade of pillar 2 is the next most significant, and so on, down to the grade of pillar $n$, which is the least significant (trailing) digit. You must output the specific safe configuration that corresponds to the smallest possible $n$-digit integer. If no safe configuration is possible, you must report this failure.

Be aware that the structural constraints can be highly deceptive. In many cases, a very large number of partial grade assignments that successfully avoid resonance among the first several pillars will ultimately fail due to geometric restrictions appearing only at the final few pillars.

## Input
The first line provides $n$ and $m$ — the number of pillars and the number of cross-beams ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that a rigid cross-beam connects pillar $u$ and pillar $v$.

## Output
If the structure cannot be stabilized, output a single line with the word NO.
Otherwise, output YES on the first line. On the second line, output $n$ integers separated by spaces, where each integer is 1, 2, or 3, representing the density grades assigned to pillars 1 through $n$ respectively, following the minimization rule described above.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The explicit element-by-element lexicographical tie-breaking rule was replaced with a requirement to minimize the $n$-digit integer formed by concatenating the sequence of assignments. This is mathematically identical but avoids standard terminology, breaking pattern matching for fixed-order backtracking search templates. Models must now deduce that integer minimization is equivalent to lexicographical search.
</RATIONALE>
<PRESERVED_ANSWER>
Minimizing a sequence of identical-length integers formed by digits is mathematically identical to finding the lexicographically smallest sequence of those digits, meaning the exact same assignments remain valid and optimal.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically first valid 3-coloring of a graph, preserving its NP-completeness.
</PRESERVED_CLASS>
<RISK>
Models might interpret the $n$-digit integer requirement as necessitating arbitrary-precision arithmetic or string-based sorting of all valid configurations, potentially leading to Time Limit Exceeded if they fail to map it back to early-pruning lexicographical search.
</RISK>
