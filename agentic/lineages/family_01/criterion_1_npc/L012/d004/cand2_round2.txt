# Problem A — Resonant Frequencies

Time limit: 2 s   Memory limit: 256 MB

You are designing a pavilion supported by $n$ pillars, numbered sequentially from $1$ to $n$. Each pillar must be assigned one of three available density grades, denoted by the integers $1$, $2$, and $3$.

The structure is reinforced by $m$ rigid cross-beams, each connecting a pair of pillars. Wind tunnel tests show that if two pillars connected by a cross-beam are assigned the identical density grade, they will resonate at the same frequency and cause the cross-beam to shatter. Consequently, any two pillars joined by a cross-beam must be assigned strictly different density grades.

Your task is to find a valid density assignment for all $n$ pillars. If multiple valid assignments exist, you must select the one that assigns the smallest possible grade to pillar $1$. If there are still multiple candidates, choose the one that minimizes the grade for pillar $2$, and so forth, checking pillar by pillar up to pillar $n$. If no valid assignment can be found, you must state that it is impossible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of pillars and the number of cross-beams.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), representing a cross-beam connecting pillar $u$ and pillar $v$.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers from the set $\{1, 2, 3\}$, representing the density grades for pillars $1$ through $n$, adhering to the specified tie-breaking rule.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

I also restored the exact numeric bounds and simplified the text to ensure perfect clarity as requested by the gate.
</RATIONALE>
