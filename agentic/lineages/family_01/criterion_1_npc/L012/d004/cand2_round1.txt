# Problem A — Resonant Frequencies

Time limit: 2 s   Memory limit: 256 MB

You are finalizing the architectural plans for a large pavilion supported by $n$ load-bearing pillars. The pillars are sequentially numbered starting from 1 up to $n$. For each pillar, you must specify a material density grade. There are exactly three allowed density grades, represented by the values 1, 2, and 3.

To provide horizontal stability, the design includes $m$ rigid cross-beams. Each cross-beam connects two specific pillars. However, wind tunnel testing has revealed a critical flaw: if any two pillars connected by a cross-beam are constructed using the exact same density grade, they will share the same resonant frequency. Under high winds, this resonance will amplify and shatter the cross-beam. Therefore, the two pillars connected by any cross-beam must always be built with differing density grades.

You must determine a safe density grade assignment for all $n$ pillars. If there are several safe ways to assign the grades, you must prefer the configuration that assigns the lowest possible grade to pillar 1. If ties remain, you must break them by minimizing the grade assigned to pillar 2, continuing this element-by-element comparison up to pillar $n$. If no such configuration is possible, you must report this failure.

Be aware that the structural constraints can be highly deceptive. Proceeding to assign grades strictly in numerical order from pillar 1 to $n$ often leads to a massive number of dead ends, where assignments seem perfectly valid until the final few pillars. To navigate these geometric restrictions efficiently, architects prioritize determining the grades for the most heavily constrained pillars first. However, regardless of the sequence in which you evaluate the pillars to find a safe configuration, your final submitted assignment must strictly adhere to the numerical tie-breaking rules described above.

## Input
The first line provides $n$ and $m$. The number of pillars, $n$, is at least 1 and at most the number of degrees in exactly one-ninth of a full circle. The number of cross-beams, $m$, is bounded between 0 and the maximum number of distinct pairs that can be formed from the $n$ pillars.
The following $m$ lines each contain two integers $u$ and $v$ (between 1 and $n$ inclusive, with no cross-beam connecting a pillar to itself), indicating that a rigid cross-beam connects pillar $u$ and pillar $v$.

## Output
If the structure cannot be stabilized, output a single line with the word NO.
Otherwise, output YES on the first line. On the second line, output $n$ integers separated by spaces, where each integer is 1, 2, or 3, representing the density grades assigned to pillars 1 through $n$ respectively, following the tie-breaking rules described above.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2

```
4 6
1 2
1 3
1 4
2 3

3 4
```
Output:
```
NO
```
