# Acoustic Levitation Arrays

Time limit: 2 s   Memory limit: 256 MB

You are tasked with tuning an acoustic levitation array consisting of $n$ wave emitters. The acoustic chamber is equipped with a maximum of 40 mounting slots, so the number of emitters will never exceed this capacity. For the system to function, every emitter must be assigned a phase offset mode. The hardware allows exactly three distinct offset modes, identified by the numeric codes 1, 2, and 3.

Each offset mode $k \in \{1, 2, 3\}$ generates a specific acoustic signature, represented by the vector $V_k = (k, k^2, k^3)$. The testing chamber also maintains a constant ambient reference vector $W = (1, 0, 0)$.

Due to the geometry of the system, certain pairs of emitters project sound waves that converge at shared focal points. In total, there are $m$ such pairs. When a pair of emitters targets the same focal point, their acoustic outputs interact.

The hardware safety threshold requires that for any two emitters sharing a focal point, their acoustic interference must not collapse into a planar state. Specifically, if the two interacting emitters are assigned offset modes $x$ and $y$, the signature vectors $V_x$, $V_y$, and the reference vector $W$ must be linearly independent. This means they must span a full 3-dimensional space (the volume of the parallelepiped they define must be strictly non-zero). If this condition is not met, the focal point experiences a localized pressure spike that destroys the levitated specimen. 

The endpoints $u$ and $v$ representing an interacting pair are allowed to be equal. A pair where $u = v$ is still a strict constraint; in this case, the vectors $V_x$ and $V_x$ are evaluated together with $W$. Because a vector cannot be linearly independent from itself, such a constraint inherently makes a safe tuning impossible.

Finally, the array's total base activation energy, defined as $\sum_{i=1}^n (p_i^4 - p_i^2)$ where $p_i$ is the mode of emitter $i$, must not exceed a critical threshold of $E_{max} = 4000$ to prevent chamber overheating. Any configuration exceeding this threshold will trigger an automatic shutdown, rendering the tuning invalid.

You must determine whether it is possible to assign a safe phase offset mode to all $n$ emitters given the list of interacting pairs, such that both the spatial interference condition for every shared focal point and the global activation energy limit are satisfied.

## Input
The first line contains two integers $n$ and $m$ — the number of emitters and the number of interacting emitter pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). Emitters are indexed from $1$ to $n$.
Each of the subsequent $m$ lines provides two integers $u$ and $v$ ($1 \le u, v \le n$), specifying that emitter $u$ and emitter $v$ share a focal point. Every listed pair represents a strict interference constraint.

## Output
If a safe tuning is impossible, output a single line containing NO.
If a valid tuning exists, output YES on the first line. On the second line, output $n$ space-separated integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the offset mode assigned to emitter $i$. Any valid array configuration will be accepted.
