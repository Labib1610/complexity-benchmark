Explicitly defines the constraint evaluation for u=v to enforce that x != x is required, meaning self-loops strictly fail the condition. Models that blindly use standard graph coloring libraries or heuristics often discard self-loops (`if u == v: continue`), which will yield false positives (YES instead of NO).
</METHOD_DESCRIPTION>

yes

<STATEMENT>
# Acoustic Levitation Arrays

Time limit: 2 s   Memory limit: 256 MB

You are tasked with tuning an acoustic levitation array consisting of $n$ wave emitters. The acoustic chamber is equipped with a maximum of 40 mounting slots, meaning $n$ will never exceed this capacity. For the system to function, every emitter must be assigned a phase offset mode. The hardware allows exactly three distinct offset modes, identified by the numeric codes 1, 2, and 3.

During operation, acoustic projections interact at various spatial coordinates. You are provided with $m$ such interference links. Each link involves the acoustic outputs of an emitter $u$ and an emitter $v$.

The hardware safety threshold requires that for any listed interference link, the interacting projections must not create resonant feedback. Specifically, if the two involved outputs are assigned offset modes $x$ and $y$, their acoustic interference is modeled by the localized resonance matrix:

$$ R = \begin{pmatrix} x & y \\ y & x \end{pmatrix} $$

To maintain stability, the matrix $R$ must have full rank (meaning its determinant must be strictly non-zero). If this condition is not met, the system experiences a localized pressure spike that destroys the levitated specimen. 

Crucially, an interference link may represent a self-reflection where an emitter's output interacts with itself. Consequently, $u$ and $v$ are permitted to be equal. A self-interaction link (where $u = v$) is evaluated using the exact same resonance matrix requirement, and failure to satisfy it makes a safe tuning impossible.

You must determine whether it is possible to assign a safe phase offset mode to all $n$ emitters given the list of interference links, such that the resonant feedback condition is satisfied simultaneously for every link.

## Input
The first line contains two integers $n$ and $m$ — the number of emitters and the number of interference links ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). Emitters are indexed from $1$ to $n$.
Each of the subsequent $m$ lines provides two integers $u$ and $v$ ($1 \le u, v \le n$), specifying that the outputs of emitter $u$ and emitter $v$ interact. Every listed link represents a strict stability constraint, even if $u$ and $v$ refer to the same emitter.

## Output
If a safe tuning is impossible, output a single line containing NO.
If a valid tuning exists, output YES on the first line. On the second line, output $n$ space-separated integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the offset mode assigned to emitter $i$. Any valid array configuration will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
Targeted the explicit `if u == v: continue` bypass used by the surviving models. By explicitly stating that $u$ and $v$ can be equal and that such self-interactions are subject to the exact same matrix determinant rule (which mathematically cannot be satisfied since det($[[x,x],[x,x]]$)=0), the models are forced to evaluate self-loops rather than blindly discarding them as they would in standard graph coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical condition $x^2 - y^2 \neq 0$ simplifies exactly to $x \neq y$ (since $x, y \in \{1, 2, 3\}$), which is identical to the original graph coloring constraint, and self-loops inherently result in NO as they did implicitly in the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to 3-Coloring on a graph of up to 40 vertices, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
The bound $m \le n(n-1)/2$ is traditionally the maximum number of edges in a simple graph, which might confuse a reader into thinking self-loops are impossible despite the text; however, the text explicitly permits self-loops and mathematically $m$ is just a bound, so there is no formal contradiction.
</RISK>
