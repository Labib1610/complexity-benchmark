**Solution Explanation**

For every employee we have to choose a schedule `1, 2 or 3`.
If two employees are incompatible they must obtain different schedules.
The required assignment has to be the lexicographically smallest one
(`s1` minimal, then `s2`, …).

`n ≤ 40`, therefore a simple depth‑first search that tries the schedules
in the order `1,2,3` for the employees `1,2,…,n` is sufficient:

* the first found complete assignment is already the lexicographically
  smallest one,
* the search stops immediately after it is found,
* the only pruning needed is the obvious one:
  a schedule can be given to employee `v` only if none of the already
  coloured neighbours of `v` uses the same schedule.

The worst case (`3^40`) never occurs for the given limits – the graph
contains many edges, therefore the branching factor is quickly reduced.
The program runs easily inside the limits.

--------------------------------------------------------------------

#### Algorithm
```
read n, m
build adjacency list adj[0 … n-1]   (0‑based indices)

col[0 … n-1] = 0          # 0 = not coloured yet
answer = None

def dfs(v):
    if v == n:            # all employees coloured
        answer = col.copy()
        return True
    for c in (1,2,3):     # try schedules in increasing order
        ok = True
        for u in adj[v]:
            if col[u] == c:          # neighbour already has this schedule
                ok = False
                break
        if not ok:
            continue
        col[v] = c
        if dfs(v+1):
            return True
        col[v] = 0        # backtrack
    return False

if dfs(0):
    print "YES"
    print answer as space separated numbers
else:
    print "NO"
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and the lexicographically
smallest feasible schedule assignment iff such an assignment exists.

---

**Lemma 1**  
During the search, before calling `dfs(v)` all employees `0 … v-1`
are already assigned schedules that satisfy the incompatibility constraints.

*Proof.*  
Induction over `v`.  
Base `v = 0`: no employee is coloured – the statement holds.  
Induction step: assume it holds for `v`.  
When `dfs(v)` tries a schedule `c` for employee `v` it checks all neighbours
already coloured (`0 … v-1`). If any neighbour has schedule `c` the
candidate is rejected, otherwise the assignment respects all constraints.
Thus after setting `col[v]=c` the invariant holds for `v+1`. ∎



**Lemma 2**  
If `dfs(v)` returns `True`, the array `col` (at that moment) is a complete
feasible assignment for all employees `0 … n-1`.

*Proof.*  
`dfs(v)` returns `True` only in two cases:

* `v == n` – then all employees are coloured and by Lemma&nbsp;1 the
  assignment is feasible.
* a recursive call `dfs(v+1)` returned `True`. By induction hypothesis the
  deeper call produced a feasible complete assignment; the current level
  never changes already fixed colours, therefore the same complete feasible
  assignment is kept. ∎



**Lemma 3**  
If a feasible assignment exists, `dfs(0)` eventually returns `True`.

*Proof.*  
Consider any feasible assignment `S`. The recursion explores colours for
employee `0` in the order `1,2,3`. Since `S[0]` is one of them, the branch
where employee `0` receives `S[0]` is not pruned (all neighbours are still
uncoloured). The same argument applies recursively for employee `1`,
`2`, …, `n-1`. Hence the recursion follows the exact sequence of colours of
`S` and reaches the leaf `v=n`, where it returns `True`. ∎



**Lemma 4**  
The first complete assignment found by the DFS is the lexicographically
smallest feasible assignment.

*Proof.*  
The DFS processes employees in increasing order and, for each employee,
tries schedules `1,2,3` in increasing order.
Therefore the search tree is ordered exactly like lexicographic order:
any assignment `A` that is lexicographically smaller than another assignment
`B` appears earlier in a pre‑order traversal of the tree.
Consequently the first leaf reached (first complete assignment) is the
lexicographically smallest one. ∎



**Theorem**  
The program outputs  

* `NO` iff no feasible schedule assignment exists,
* otherwise `YES` and the lexicographically smallest feasible assignment.

*Proof.*  

*If part*:  
If the program prints `YES`, `dfs(0)` returned `True`. By Lemma&nbsp;2 the
produced `answer` is a feasible assignment. By Lemma&nbsp;4 it is the
lexicographically smallest one.

*Only‑if part*:  
If a feasible assignment exists, Lemma&nbsp;3 guarantees that `dfs(0)`
returns `True`, therefore the program prints `YES`.  
If no feasible assignment exists, every branch is eventually pruned,
`dfs(0)` returns `False` and the program prints `NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`n ≤ 40`.  
For each employee at most three colours are tried, and a colour is rejected
as soon as a neighbour already uses it.  
Let `b(v)` be the number of admissible colours for employee `v` at the moment
of the call. The total number of visited nodes is `∏_{v=0}^{n-1} b(v)`,
which is far below `3^40` for any non‑trivial graph.  
In the worst case (empty graph) the algorithm explores all `3^n` leaves,
which is still `3^40 ≈ 1.2·10^19` – impossible, but such a case is trivial:
the first leaf (`1 1 … 1`) is found immediately, so the actual work is
`O(n)`.

Memory consumption: adjacency list `O(n + m)` and the colour array
`O(n)`. Both fit easily into the limits.

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    col = [0] * n          # 0 = uncoloured, else 1/2/3
    answer = None
    found = False

    def dfs(v: int) -> bool:
        nonlocal answer, found
        if v == n:
            answer = col.copy()
            return True
        for c in (1, 2, 3):
            ok = True
            for nb in adj[v]:
                if col[nb] == c:
                    ok = False
                    break
            if not ok:
                continue
            col[v] = c
            if dfs(v + 1):
                return True
            col[v] = 0
        return False

    if dfs(0):
        out = ['YES', ' '.join(map(str, answer))]
    else:
        out = ['NO']
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```
