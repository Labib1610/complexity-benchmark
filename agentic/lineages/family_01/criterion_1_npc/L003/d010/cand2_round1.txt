<STATEMENT>
# Antenna Alignment

Time limit: 2 s   Memory limit: 256 MB

You are tasked with configuring a network of $n$ communication antennas. Every antenna in the network requires exactly one operational index, which must be selected from the integers 1, 2, and 3.

Each operational index corresponds to a specific $3 \times 3$ configuration matrix:

Index 1:
```
 1  0  0
 0  1 -3
 0  3  1
```

Index 2:
```
 1  0  3
 0  1  0
-3  0  1
```

Index 3:
```
 1 -3  0
 3  1  0
 0  0  1
```

The terrain contains $m$ direct line-of-sight links between specific pairs of antennas. When two antennas share a line-of-sight link, their signals interact. For a link between antenna $u$ and antenna $v$, assigned matrices $A$ and $B$ respectively, we define their skewness matrix as $S_{u,v} = A B - B A$. 
The interference value of that single link is defined as the sum of the squares of all 9 elements in $S_{u,v}$.

To guarantee reliable communication, the network must be perfectly stabilized. This requires the total network interference—calculated as the sum of the interference values across all $m$ line-of-sight links—to operate at absolute peak saturation. Peak saturation is achieved if and only if the total interference exactly matches the network's theoretical maximum capacity. The theoretical maximum capacity of the network is defined as $m$ times the maximum possible interference a single link could theoretically generate under any possible pair of operational indices.

Your objective is to determine if there exists a complete assignment of operational indices to all $n$ antennas that stabilizes the network.

## Input
The first line contains two integers $n$ and $m$ — the number of antennas and the number of line-of-sight links ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). The antennas are indexed from $1$ to $n$.
Each of the subsequent $m$ lines provides two distinct integers $u$ and $v$ ($1 \le u, v \le n$), indicating that antenna $u$ and antenna $v$ share a direct line-of-sight link. 

## Output
If a stabilized configuration is impossible, output a single line containing NO.
If a valid configuration exists, output YES on the first line. On the second line, output $n$ space-separated integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the operational index assigned to antenna $i$. Any valid configuration will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The explicit dot-product equality that models pattern-matched to 3-coloring was removed. It is replaced with a matrix commutator norm evaluation (which requires algebraic computation just to find the edge costs) combined with an indirectly derived target bound (S07). The model must now extract the matrices, compute the commutator norms to discover they evaluate to 0 for identical indices and 162 for different indices, identify 162 as the theoretical maximum single-link capacity, deduce the global target sum is $162m$, and finally reason that achieving this maximum sum forces a strict inequality constraint across every edge.
</RATIONALE>
<PRESERVED_ANSWER>
The matrix commutator norm is 0 for matching indices and 162 for different indices, meaning the target sum of exactly $162m$ is achieved if and only if every linked pair has different indices, which is mathematically identical to the original proper 3-coloring condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to determining if the input graph is 3-colorable, preserving its NP-complete status.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "assigned matrices A and B respectively" as being order-dependent, but since $AB - BA = -(BA - AB)$, the sum of squares of elements is identical regardless of which antenna is A and which is B, making the interference symmetric and unambiguous.
</RISK>

<METHOD_DESCRIPTION>Replaces a simple vector dot-product interaction with the squared Frobenius norm of the commutator of $3 \times 3$ matrices ($||AB - BA||_F^2$). The matrices are constructed from generators of SO(3) such that the norm evaluates to a constant positive value for any pair of distinct matrices, and 0 for identical matrices. Combined with an indirectly stated maximum capacity bound, it forces the model to perform matrix algebra to discover the underlying binary relation before it can even formulate the constraint.</METHOD_DESCRIPTION>
