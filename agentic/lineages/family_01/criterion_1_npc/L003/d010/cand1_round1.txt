<STATEMENT>
# Antenna Alignment

Time limit: 2 s   Memory limit: 256 MB

You are tasked with configuring a network of $n$ communication antennas. Every antenna in the network requires exactly one operational mode, which must be selected from the integers 1, 2, and 3.

The terrain contains $m$ direct line-of-sight links between specific pairs of antennas. When two antennas $u$ and $v$ share a line-of-sight link, their phase interaction is modeled by a $3 \times 3$ interference matrix $M_{u,v}$ defined as:

$$M_{u,v} = \begin{pmatrix} 1 & p_u & p_u^2 \\ 1 & p_v & p_v^2 \\ 1 & 4 & 16 \end{pmatrix}$$

where $p_u$ and $p_v$ are the operational modes assigned to antennas $u$ and $v$.

To guarantee reliable communication, the network must be perfectly stabilized. The network is stabilized if and only if, for every line-of-sight link in the terrain, its corresponding interference matrix $M_{u,v}$ is non-singular (i.e., has a non-zero determinant).

Your objective is to determine if there exists a complete assignment of operational modes to all $n$ antennas that stabilizes the network.

## Input
The first line contains two integers $n$ and $m$ — the number of antennas and the number of line-of-sight links ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). The antennas are indexed from $1$ to $n$.
Each of the subsequent $m$ lines provides two distinct integers $u$ and $v$ ($1 \le u, v \le n$), indicating that antenna $u$ and antenna $v$ share a direct line-of-sight link. 

## Output
If a stabilized configuration is impossible, output a single line containing NO.
If a valid configuration exists, output YES on the first line. On the second line, output $n$ space-separated integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the operational mode assigned to antenna $i$. Any valid configuration will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The previous version allowed models to bypass reasoning by recognizing that a global sum of dot products evaluating to an extreme value (-3m) trivially reduced to a constant equality check (proper 3-coloring). I removed the vectors, the dot products, and the global sum entirely. Instead, I introduced a local condition where each line-of-sight link is modeled by a 3x3 Vandermonde matrix parameterized by the modes, requiring every such matrix to be non-singular. This forces the model to either algebraically analyze the determinant or write a script to evaluate the truth table, completely removing the direct linear equation affordance.
</RATIONALE>
<PRESERVED_ANSWER>
The determinant of the 3x3 interference matrix evaluates to $(p_v - p_u)(4 - p_u)(4 - p_v)$, which is non-zero if and only if $p_u \neq p_v$ (since $p_u, p_v \in \{1, 2, 3\}$), making the acceptance condition mathematically identical to proper 3-coloring for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Graph 3-Coloring, which is NP-complete, as the non-singularity constraint strictly enforces that adjacent vertices have distinct colors.
</PRESERVED_CLASS>
<RISK>
Models might find the order of $u$ and $v$ in the matrix definition ambiguous, but since swapping $u$ and $v$ only swaps two rows (negating the determinant), the non-singularity condition is perfectly symmetric and unambiguous.
</RISK>
