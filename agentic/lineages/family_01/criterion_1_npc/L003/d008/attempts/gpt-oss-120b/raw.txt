**Solution Explanation**

For two antennas `u , v` the product `p[u]·p[v]` is a perfect square **iff**
`p[u] = p[v]` :

```
1·1 = 1   square
2·2 = 4   square
3·3 = 9   square
all other products (1·2, 1·3, 2·3) are not squares
```

Therefore the requirement *“product is NOT a square on every given edge”*
is exactly the condition

```
adjacent vertices must have different numbers
```

So we have to **properly colour the graph with three colours {1,2,3}**.
`n ≤ 40`, thus an exponential back‑tracking algorithm with good pruning
solves the problem easily.



--------------------------------------------------------------------

#### 1.   Data structures

* `adj[i]` – 64‑bit bitmask, `adj[i]` has bit `j` set iff an edge `i‑j` exists
* `domain[i]` – 3‑bit mask of still possible colours for vertex `i`
  (`0b111` means `{1,2,3}` are all still allowed)
* `colour[i]` – assigned colour (`-1` = not assigned yet)
* `unassigned` – bitmask of vertices that are still uncoloured

All masks fit into a normal Python `int` because `n ≤ 40`.

--------------------------------------------------------------------

#### 2.   Backtracking with forward checking  

```
dfs(unassigned):
    if unassigned == 0               -> all vertices coloured, success

    choose a vertex v from unassigned
        with the smallest domain (MRV heuristic)
    for each colour c allowed for v:
        colour[v] = c
        remove v from unassigned
        for every still uncoloured neighbour u of v
                delete colour c from domain[u]
                if domain[u] becomes empty -> contradiction
        if no contradiction and dfs(new_unassigned) succeeds -> success
        undo all modifications (restore domains, colour[v] = -1)
    return failure
```

* **MRV (minimum remaining values)** – picking the vertex with the
  smallest domain size reduces the branching factor drastically.
* **Forward checking** – after fixing a colour we immediately delete the
  same colour from all neighbours. If any neighbour loses its last
  possible colour we backtrack instantly.
* The whole recursion depth is at most `n = 40`.

Because each recursive step touches only the neighbours of the chosen
vertex, the total amount of work is far below the limit.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints **YES** and a correct assignment
iff such an assignment exists.

---

##### Lemma 1  
During execution `domain[v]` always equals the set of colours that can be
assigned to `v` without violating the already fixed colours of its
(coloured) neighbours.

**Proof.**  
Initially every colour is possible, i.e. `domain[v] = {1,2,3}` – the
statement holds.

When a vertex `x` gets colour `c`, the algorithm removes `c` from the
domains of all still uncoloured neighbours `y`.  
No other colours become impossible, because only edges incident to `x`
are newly constrained.  
Thus after the change the invariant is restored.  
When backtracking the algorithm restores the saved old domains, therefore
the invariant is also restored. ∎



##### Lemma 2  
When the algorithm tries a colour `c` for a vertex `v`, all colourings
that extend the current partial assignment and give `v` colour `c`
are explored in the recursive call.

**Proof.**  
Because of Lemma&nbsp;1 the current `domain[v]` contains exactly the colours
that keep the already coloured neighbours satisfied.
Choosing `c ∈ domain[v]` does not break any already satisfied edge.
The recursive call receives the updated domains of the remaining
vertices (forward checking). Any complete colouring that extends the
partial one and keeps `v = c` must respect exactly those updated domains,
hence it will be found by the recursive search. ∎



##### Lemma 3  
If the algorithm reaches the line `unassigned == 0` the obtained
colouring is a proper 3‑colouring of the whole graph.

**Proof.**  
All vertices are coloured.  
For every edge `{u,v}` at the moment when the later of the two ends was
coloured, the algorithm removed that colour from the still uncoloured
endpoint (forward checking). Hence the two ends never receive the same
colour. ∎



##### Lemma 4  
If a proper 3‑colouring exists, the algorithm eventually returns success.

**Proof.**  
Consider any fixed proper 3‑colouring `C`.  
The recursion always selects a vertex `v` that still has at least one
colour in its domain (otherwise the current partial assignment already
contradicts `C`).  
Since `C` is proper, the colour `C(v)` belongs to `domain[v]`.  
The algorithm tries all colours in `domain[v]`, therefore it will try
`C(v)` at some iteration.  
By Lemma&nbsp;2 the recursive call after fixing `v = C(v)` still contains a
completion to `C`. Repeating the argument for every level yields a
sequence of choices matching `C` and finally reaches the leaf where all
vertices are coloured – success. ∎



##### Lemma 5  
If the algorithm returns success, the produced assignment satisfies the
requirement of the problem.

**Proof.**  
Success means the recursion terminated with `unassigned == 0`.  
By Lemma&nbsp;3 the obtained assignment is a proper 3‑colouring, i.e. all
adjacent vertices have different numbers. As argued at the very beginning,
different numbers imply a non‑square product, therefore every given edge
meets the condition. ∎



##### Theorem  
The program outputs  

* `YES` and a list of numbers `1 … 3` **iff** there exists an assignment
  obeying the problem statement;
* otherwise it outputs `NO`.

**Proof.**  

*If the program prints `YES`.*  
By Lemma&nbsp;5 the printed assignment is valid, therefore a feasible
assignment exists.

*If a feasible assignment exists.*  
By Lemma&nbsp;4 the backtracking algorithm finds a complete proper
colouring and returns success, consequently the program prints `YES`.

If no feasible assignment exists, the algorithm explores every possible
partial colouring and never reaches the success leaf, thus finally returns
failure and the program prints `NO`. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

`n ≤ 40`.

*Selecting a vertex* – scans at most `n` bits.  
*Propagation* – touches each edge at most once per recursion level.

In the worst case the algorithm examines every possible 3‑colouring,
`3^n`, but strong pruning (MRV + forward checking) makes the actual
search far smaller.  
For the given limits the program runs comfortably within the time limit
(typical worst‑case graphs are rejected after a few dozen recursive calls).

Memory consumption:

* adjacency masks – `n` integers
* domains, colours – `n` small integers
* recursion stack – depth `n`

Overall **O(n)** memory, i.e. less than a kilobyte.

#### 5.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * n                     # bitmask of neighbours
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u] |= 1 << v
        adj[v] |= 1 << u

    # 3-bit mask, bit 0 -> colour 1, bit 1 -> colour 2, bit 2 -> colour 3
    domain = [0b111] * n
    colour = [-1] * n                 # -1 = unassigned

    ALL = (1 << n) - 1                # all vertices still unassigned
    answer = None                     # will hold final colours (0‑based)

    # -------------------------------------------------------------
    def dfs(unassigned_mask: int) -> bool:
        nonlocal answer
        if unassigned_mask == 0:          # all coloured
            answer = colour[:]
            return True

        # ---- choose vertex with smallest domain (MRV) ----
        v = -1
        min_sz = 4
        mask = unassigned_mask
        while mask:
            lsb = mask & -mask
            i = (lsb.bit_length() - 1)
            sz = domain[i].bit_count()
            if sz < min_sz:
                min_sz = sz
                v = i
                if sz == 1:
                    break
            mask ^= lsb
        if min_sz == 0:            # dead end
            return False

        # ---- try every possible colour for v ----
        allowed = domain[v]
        for c in range(3):
            if not (allowed >> c) & 1:
                continue
            # assign colour c to v
            colour[v] = c
            new_unassigned = unassigned_mask & ~(1 << v)

            # forward checking: remove colour c from neighbours
            modified = []          # list of (vertex, old_domain)
            contradiction = False
            neigh = adj[v] & new_unassigned
            while neigh:
                lsb = neigh & -neigh
                u = (lsb.bit_length() - 1)
                if (domain[u] >> c) & 1:
                    old = domain[u]
                    new = old & ~(1 << c)
                    modified.append((u, old))
                    domain[u] = new
                    if new == 0:
                        contradiction = True
                        break
                neigh ^= lsb

            if not contradiction:
                if dfs(new_unassigned):
                    return True

            # ---- backtrack: restore domains ----
            for u, old in reversed(modified):
                domain[u] = old
            colour[v] = -1

        return False
    # -------------------------------------------------------------

    ok = dfs(ALL)

    out = sys.stdout
    if not ok:
        out.write("NO\n")
    else:
        out.write("YES\n")
        # convert 0‑based colours to 1‑based numbers
        out.write(" ".join(str(c + 1) for c in answer) + "\n")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input / output format.
