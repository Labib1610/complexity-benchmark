# Problem A — Frequency Allocation

Time limit: 2 s
Memory limit: 256 MB

A communications network consists of $n$ transmitter nodes. To prevent signal overlap, the network utilizes exactly three distinct frequency bands, numbered 1, 2, and 3. Every transmitter must be tuned to exactly one of these three bands.

Due to geographic proximity, certain pairs of transmitters will experience interference if tuned to the same band. You are provided with a complete list of all such interfering pairs. If two transmitters are on this list, they must be assigned to different frequency bands. The interference records are derived from tightly coupled environmental topologies. A local choice of frequency band for one transmitter structurally restricts the available bands for multiple distant transmitters, creating a network of cascading dependencies across all $n$ nodes.

Your objective is to determine if a valid frequency assignment exists for all $n$ transmitters. If a valid configuration is possible, you must find the one that minimizes the network configuration cost. The cost is calculated by taking the band number $s_i$ assigned to each transmitter $i$, multiplying it by $4^{n-i}$, and summing these values over all $1 \le i \le n$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). The integer $n$ represents the total number of transmitters, and $m$ represents the number of interference records.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$) denoting a pair of transmitters that cannot share the same frequency band.

## Output
If there is no valid way to assign the frequency bands, output a single line containing `NO`.
If a valid assignment is possible, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ ($s_i \in \{1, 2, 3\}$), where $s_i$ is the frequency band assigned to transmitter $i$. If multiple valid assignments exist, output the sequence $s_1, s_2, \dots, s_n$ that minimizes the value of $\sum_{i=1}^n s_i \cdot 4^{n-i}$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
