# Acoustic Levitation Arrays

Time limit: 2 s   Memory limit: 256 MB

You are tasked with tuning an acoustic levitation array consisting of $n$ wave emitters. For the system to function, every emitter must be assigned a phase offset. The hardware allows exactly three distinct offset modes, identified by the numeric codes 1, 2, and 3.

Due to the geometry of the system, certain pairs of emitters project sound waves that converge at shared focal points. In total, there are $m$ such pairs. When a pair of emitters targets the same focal point, their acoustic outputs interfere. The stability of this interference is determined by the linear system:

$x \cdot p_u + y \cdot p_v = 1$  
$x \cdot p_v + y \cdot p_u = 1$  

where $p_u$ and $p_v$ are the numeric codes assigned to the two interacting emitters. If this system fails to have a unique solution for the variables $x$ and $y$, the interference becomes perfectly constructive. This causes a localized pressure spike that destroys the levitated specimen. Therefore, for the system to operate safely, the linear system for any two emitters that share a focal point must have a unique solution.

Be aware that the evaluation data includes highly interconnected emitter arrangements. These test cases are specifically designed to maximize the number of seemingly valid partial configurations, causing naive trial-and-error assignments to exceed the time limit.

You must determine whether it is possible to assign a safe phase offset code to all $n$ emitters given the list of interacting pairs.

## Input
The first line contains two integers $n$ and $m$ — the number of emitters and the number of interacting emitter pairs. The acoustic chamber has exactly 40 mounting slots, which establishes the maximum possible number of emitters, and at least one emitter will always be present. The number of interacting pairs $m$ ranges from zero up to the theoretical maximum where every emitter interacts with every other emitter. Emitters are indexed from $1$ to $n$.
Each of the subsequent $m$ lines provides two integers $u$ and $v$, specifying that emitter $u$ and emitter $v$ share a focal point.

## Output
If a safe tuning is impossible, output a single line containing NO.
If a valid tuning exists, output YES on the first line. On the second line, output $n$ space-separated integers $p_1, p_2, \dots, p_n$ (where each code is 1, 2, or 3), representing the offset code assigned to emitter $i$. Any valid array configuration will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The interference condition was changed from "the product is a perfect square" to an equivalent linear system constraint that fails to have a unique solution when $p_u = p_v$. This forces the model to mathematically deduce that the uniqueness constraint is exactly equivalent to $p_u \neq p_v$, breaking the immediate pattern-matching to graph 3-coloring. Additionally, I applied S07 by moving the numeric bounds into natural-language descriptions of the testing facility's physical capacities.
</RATIONALE>
<PRESERVED_ANSWER>
The linear system has a determinant of $p_u^2 - p_v^2$, which is zero if and only if the assigned strictly positive codes $p_u$ and $p_v$ are equal; thus the constraint remains exactly equivalent to assigning different codes to interacting emitters, keeping all valid assignments identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Graph 3-Coloring, which is NP-complete, because the new interference condition is mathematically equivalent to the original constraint that adjacent vertices must receive different colors from a palette of size 3.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the linear system as requiring them to output the values of $x$ and $y$, although the output format explicitly asks only for the offset codes $p_i$.
</RISK>
