# Facility Automation Control: Tri-State Channel Configuration

Time limit: 2 s   Memory limit: 256 MB

## Description
A central controller manages $n$ field devices numbered from $1$ to $n$. Each device must be assigned to operate on one of three available signal frequencies, indexed as 1, 2, or 3. 

Certain pairs of devices cause physical signal interference if they operate on the exact same frequency simultaneously. You are given a list of $m$ pairs of mutually interfering devices. An assignment of frequencies to devices is valid if no interfering pair shares the same frequency index.

To maintain system stability and deterministic startup order, the controller requires the lexicographically smallest sequence of assigned frequencies $s_1, s_2, \dots, s_n$. If it is impossible to assign frequencies 1, 2, or 3 to all devices without causing interference, the system cannot initialize.

Determine if a valid frequency assignment exists. If so, output `YES` along with the lexicographically smallest frequency sequence. Otherwise, report `NO`.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le \frac{n(n-1)}{2}$) — the number of devices and the number of interference constraints.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n, u \neq v$), indicating that device $u$ and device $v$ cannot share the same operating frequency.

## Output
If no valid frequency configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ where $s_i \in \{1, 2, 3\}$ represents the frequency assigned to device $i$. If multiple valid assignments exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
