 We need to assign each vertex a value from {1, 2, 3} such that for every edge (u, v), the product p[u] * p[v] is **not** a perfect square.

Let’s analyze when a product of two numbers from {1, 2, 3} is a perfect square:

- 1*1 = 1 → perfect square (bad)
- 1*2 = 2 → not square (ok)
- 1*3 = 3 → not square (ok)
- 2*2 = 4 → perfect square (bad)
- 2*3 = 6 → not square (ok)
- 3*3 = 9 → perfect square (bad)

So the forbidden pairs are: (1,1), (2,2), (3,3).  
That means: **No two adjacent vertices can have the same value.**

So the problem reduces to: Can we 3-color the graph?  
Since n ≤ 40, we can use backtracking with pruning.

We’ll implement a simple backtracking 3-coloring.

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n

def is_safe(v, c):
    for u in adj[v]:
        if color[u] == c:
            return False
    return True

def solve(v):
    if v == n:
        return True
    for c in range(1, 4):
        if is_safe(v, c):
            color[v] = c
            if solve(v + 1):
                return True
            color[v] = 0
    return False

if solve(0):
    print("YES")
    print(" ".join(str(c) for c in color))
else:
    print("NO")
```
