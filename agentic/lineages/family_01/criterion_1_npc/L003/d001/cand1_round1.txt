# Problem A — Schedule Allocation

Time limit: 2 s
Memory limit: 256 MB

A manufacturing facility employs $n$ employees. The facility's operations are organized into three distinct daily schedules, designated by the numbers 1, 2, and 3. Management requires that every employee must be placed into exactly one of these three schedules.

However, allocating these schedules is governed by a known list of incompatibility records. Each record specifies two employees, $u$ and $v$. The facility enforces a strict policy: for every incompatibility record involving employee $u$ and employee $v$, the schedule assigned to $u$ must be strictly different from the schedule assigned to $v$. Note that an incompatibility record may list the same employee twice ($u = v$). If an employee has a record with themselves, they would need a schedule different from their own, which is impossible and immediately means no valid schedule assignment can exist.

Your task is to determine whether it is possible to distribute all $n$ employees according to these rules. If it is possible, you must find the specific valid distribution that is lexicographically smallest when represented as a sequence of schedule numbers (meaning the schedule number for employee 1 is minimized first, then employee 2 is minimized, and so on).

## Input
The first line contains two integers $n$ and $m$ — the number of employees and the number of incompatibility records ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the employees involved in an incompatibility record (it is possible that $u = v$).

## Output
If there is no way to assign schedules that satisfies all rules, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2, 3\}$), representing the schedule assigned to employee $i$. If there are multiple valid assignments, output the one whose sequence $s_1, s_2, \dots, s_n$ is lexicographically smallest.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
