# Acoustic Levitation Arrays

Time limit: 2 s   Memory limit: 256 MB

You are calibrating a set of acoustic levitation emitters. The testing chamber has mounting hardpoints to support anywhere from a single emitter up to a maximum capacity of 40 emitters. 

Each emitter must be assigned to exactly one of three available phase configuration codes, which are represented by the integers 1, 2, and 3. 

Due to the spatial arrangement of the array, certain specific pairs of emitters have overlapping focal points. The number of such pairs can be zero, or it can be as large as the total number of distinct pairs that can be formed from the installed emitters. When two emitters share a focal point, their acoustic waves interact. To maintain safe and stable levitation, any two emitters that share a focal point must be assigned different phase configuration codes. If they are assigned the same code, their waves will perfectly synchronize, doubling the local pressure and shattering the levitated sample.

Given the list of emitter pairs that share a focal point, determine if there is a valid phase configuration for all installed emitters.

## Input
The first line contains two integers $n$ and $m$ — the number of installed emitters and the number of overlapping focal points. The values of $n$ and $m$ are constrained by the physical limits described above.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that emitter $u$ and emitter $v$ share a focal point.

## Output
If no safe configuration exists, print a single line NO.
Otherwise print YES on the first line. On the second line print $n$ integers $p_1, p_2, \dots, p_n$ (each in $\{1, 2, 3\}$), where $p_i$ is the phase configuration code for emitter $i$. If there are multiple valid configurations, any of them is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
