# Problem A — Tier Allocation

Time limit: 2 s
Memory limit: 256 MB

A facility employs $n$ staff members, each identified by a number from 1 to $n$. To maintain operational stability, the facility uses three distinct working tiers, designated by the values 1, 2, and 3. Each staff member must be placed into exactly one of these three tiers.

Certain pairs of staff members have documented friction. You are given a log of these historical friction events between distinct staff members. If two staff members have friction, they must not be placed into the same tier.

Your task is to determine if there is a valid tier placement for all $n$ staff members. If a valid placement is possible, you must identify the optimal one. To compare two different valid placements, look at the lowest-numbered staff member who receives a different tier in the two placements; the placement that gives this staff member a smaller tier value is considered better. You must output the best valid placement according to this rule.

## Input
The first line contains two integers $n$ and $m$. The staff count $n$ is bounded by 1 and 40 (inclusive) because the facility is equipped with exactly 40 safety harnesses. The number of logs $m$ is bounded by 0 and $n(n-1)/2$ (inclusive).
Each of the subsequent $m$ lines contains two integers $u$ and $v$ — a pair of distinct staff members who cannot share a tier.

## Output
If no valid placement exists, output a single line containing `NO`.
If a valid placement is possible, output `YES` on the first line. On the second line, output $n$ integers $t_1, t_2, \dots, t_n$, where $t_i \in \{1, 2, 3\}$ represents the tier assigned to staff member $i$. This sequence must represent the best valid placement as defined above.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The problem was rewritten to describe the lexicographical tie-breaking rule procedurally ("To compare two different valid placements...") rather than using the term "lexicographically smallest". This forces the model to deduce that fixed-order backtracking automatically yields the optimal solution. Models that rely on surface pattern matching might attempt to generate all valid placements and sort them, which will result in a Time Limit Exceeded error. The bounds are presented in prose, tied to a physical constraint (safety harnesses), satisfying the strategy while preserving exact numeric limits.
</RATIONALE>
<PRESERVED_ANSWER>
The procedural comparison rule describes a strict total order that is mathematically identical to lexicographical comparison, ensuring the exact same assignment is selected as the optimal answer.
</PRESERVED_ANSWER>
