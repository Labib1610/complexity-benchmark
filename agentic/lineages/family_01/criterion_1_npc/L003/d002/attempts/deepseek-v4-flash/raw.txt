We can model this as a graph coloring problem with 3 colors, where certain color pairs are forbidden.  

The forbidden pairs are those whose product is a perfect square:  
- 1×1 = 1 (square) → forbidden  
- 1×2 = 2 (not square) → allowed  
- 1×3 = 3 (not square) → allowed  
- 2×2 = 4 (square) → forbidden  
- 2×3 = 6 (not square) → allowed  
- 3×3 = 9 (square) → forbidden  

So the only allowed edges are between different colors, except that 2 and 3 are allowed together.  
Thus, the graph must be 3-colorable with the constraint that no two adjacent vertices share the same color, and also 1 cannot be adjacent to 1, 2 cannot be adjacent to 2, 3 cannot be adjacent to 3.  

This is exactly the standard 3-coloring problem (no two adjacent same color). Since n ≤ 40, we can use backtracking with pruning.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    n, m = int(input_data[0]), int(input_data[1])
    adj = [[] for _ in range(n)]
    idx = 2
    for _ in range(m):
        u = int(input_data[idx]) - 1
        v = int(input_data[idx+1]) - 1
        idx += 2
        adj[u].append(v)
        adj[v].append(u)
    
    colors = [0] * n  # 0 = uncolored, 1,2,3 = colors
    
    # Sort vertices by degree for better pruning
    order = sorted(range(n), key=lambda x: len(adj[x]), reverse=True)
    pos = [0] * n
    for i, v in enumerate(order):
        pos[v] = i
    
    # Build adjacency in new order
    adj_ordered = [[] for _ in range(n)]
    for u in range(n):
        for v in adj[u]:
            adj_ordered[pos[u]].append(pos[v])
    
    def backtrack(i):
        if i == n:
            return True
        v = order[i]
        used = [False] * 4
        for nb in adj_ordered[i]:
            if colors[nb] != 0:
                used[colors[nb]] = True
        for c in (1, 2, 3):
            if not used[c]:
                colors[i] = c
                if backtrack(i + 1):
                    return True
                colors[i] = 0
        return False
    
    if backtrack(0):
        # Map back to original order
        result = [0] * n
        for i, v in enumerate(order):
            result[v] = colors[i]
        print("YES")
        print(" ".join(map(str, result)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
