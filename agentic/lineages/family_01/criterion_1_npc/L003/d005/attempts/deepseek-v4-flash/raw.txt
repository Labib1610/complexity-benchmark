We can solve this by trying all possible assignments of modes (1, 2, or 3) to each emitter, but since n ≤ 40, brute force over 3^n is impossible.  

Instead, we can use a backtracking approach with pruning, or reduce it to a graph coloring problem with 3 colors where certain color pairs are forbidden.  

First, we need to determine which pairs of modes are allowed.  
For modes x and y in {1,2,3}, we check if gcd(2^x + y, 2^y + x) == 1.  

Let’s compute allowed pairs:

- (1,1): gcd(2+1, 2+1) = gcd(3,3)=3 → not allowed  
- (1,2): gcd(2+2, 4+1)=gcd(4,5)=1 → allowed  
- (1,3): gcd(2+3, 8+1)=gcd(5,9)=1 → allowed  
- (2,2): gcd(4+2, 4+2)=gcd(6,6)=6 → not allowed  
- (2,3): gcd(4+3, 8+2)=gcd(7,10)=1 → allowed  
- (3,3): gcd(8+3, 8+3)=gcd(11,11)=11 → not allowed  

So allowed distinct pairs are: (1,2), (1,3), (2,3).  
That means:  
- Same mode on connected vertices is forbidden.  
- All different modes are allowed.

So the problem reduces to: Can we 3-color the graph such that adjacent vertices have different colors?  
That’s exactly graph 3-coloring, which is NP-hard in general, but n ≤ 40 and m can be large.  
We can use backtracking with constraint propagation (like DSATUR) to solve it efficiently for n=40.

We'll implement a backtracking search with the most constrained variable heuristic.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    colors = [-1] * n
    
    # Check if we can color with backtracking
    def backtrack(idx):
        if idx == n:
            return True
        # Choose uncolored vertex with most colored neighbors (DSATUR)
        best = -1
        best_deg = -1
        for v in range(n):
            if colors[v] == -1:
                # count distinct colors among neighbors
                neigh_colors = set()
                for nb in adj[v]:
                    if colors[nb] != -1:
                        neigh_colors.add(colors[nb])
                sat_deg = len(neigh_colors)
                if sat_deg > best_deg or (sat_deg == best_deg and len(adj[v]) > len(adj[best])):
                    best_deg = sat_deg
                    best = v
        v = best
        # Try colors 1,2,3
        for c in range(1, 4):
            ok = True
            for nb in adj[v]:
                if colors[nb] == c:
                    ok = False
                    break
            if ok:
                colors[v] = c
                if backtrack(idx + 1):
                    return True
                colors[v] = -1
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(str(colors[i]) for i in range(n)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
