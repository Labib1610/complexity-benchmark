<STATEMENT>
# Facility Automation Control: Module Execution Scheduling

Time limit: 2 s   Memory limit: 256 MB

## Description
A central controller manages $n$ processing units numbered from $1$ to $n$. Every unit must be configured to operate on one of three available signal channels, indexed as 1, 2, or 3.

To prevent physical signal interference, certain pairs of units must never be assigned to the same operational channel. You are given $m$ signal separation rules. Each rule identifies two distinct units that cannot share a channel index. A configuration is valid if all $n$ units are assigned channels such that no signal separation rule is violated.

To ensure a deterministic startup sequence, if more than one valid configuration exists, the system picks the unique setup that prioritizes lower channel numbers starting from unit 1. Specifically, it breaks ties by preferring the smallest valid channel index for unit 1; if a tie remains, it prefers the smallest valid channel index for unit 2, and so on through unit $n$. If no configuration allows all units to operate on channels 1, 2, or 3 without violating any separation rule, the system cannot start.

Determine whether a valid channel configuration exists. If one exists, print `YES` followed by the chosen channel sequence. Otherwise, output `NO`.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le \frac{n(n-1)}{2}$) — the number of units and the number of signal separation rules.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n, u \neq v$), indicating that unit $u$ and unit $v$ cannot operate on the same channel.

## Output
If no valid channel configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ where $s_i \in \{1, 2, 3\}$ represents the channel assigned to unit $i$. If multiple valid assignments exist, output the one selected by the controller's tie-breaking rule described above.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
