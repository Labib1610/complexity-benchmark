# Acoustic Levitation Arrays

Time limit: 2 s   Memory limit: 256 MB

You are tasked with tuning an acoustic levitation array consisting of one or more wave emitters. The acoustic chamber is equipped with exactly 40 mounting slots, strictly limiting the maximum number of active emitters. The number of interacting emitter pairs depends on the spatial configuration, ranging from none up to the theoretical maximum where every emitter interacts with every other.

For the system to function, every emitter must be assigned a phase offset mode. The hardware allows exactly three distinct offset modes, identified by the numeric codes 1, 2, and 3.

Due to the geometry of the system, certain pairs of emitters project sound waves that converge at shared focal points. When a pair of emitters targets the same focal point, their acoustic outputs interact. The resonance energy of this interaction is calculated using the numeric codes assigned to the two emitters. For a pair of emitters with codes $u$ and $v$, the resonance energy is exactly $u^v + v^u + (u \cdot v)$. 

If this resonance energy is perfectly divisible by 3, the waves resonate constructively. This causes a localized pressure spike that destroys the levitated specimen. Therefore, for the system to operate safely, the resonance energy for any two emitters that share a focal point must not be a multiple of 3.

You must determine whether it is possible to assign a safe phase offset code to all emitters given the list of interacting pairs.

## Input
The first line contains two integers $n$ and $m$ — the number of active emitters and the number of interacting emitter pairs. Emitters are indexed from $1$ to $n$.
Each of the subsequent $m$ lines provides two integers $u$ and $v$, specifying that emitter $u$ and emitter $v$ share a focal point.

## Output
If a safe tuning is impossible, output a single line containing `NO`.
If a valid tuning exists, output `YES` on the first line. On the second line, output $n$ space-separated integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the offset code assigned to emitter $i$. Any valid array configuration will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

The previous matrix invertibility condition was easily simplified by models to `u != v`, allowing them to pattern-match the problem to graph coloring and apply heuristics like degree-ordered backtracking. </PRESERVED_ANSWER>
