# Problem A — Resonance Avoidance

Time limit: 2 s   Memory limit: 256 MB

An acoustic testing facility is configuring a linear array of $n$ sound emitters. Each emitter $i$ must be tuned to a frequency multiplier $f_i$ chosen from the set $\{1, 2, 3\}$.

During calibration, the engineers identified $m$ pairs of emitters that are physically coupled. For each coupled pair, the product of their two assigned frequency multipliers must not be a perfect square. If the product is a perfect square, their combined harmonic frequencies will create a destructive resonance and damage the array. 

Your task is to determine whether it is possible to assign a frequency multiplier to each of the $n$ emitters such that no destructive resonance is created among any of the $m$ coupled pairs. If it is possible, provide a valid assignment for all emitters.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of emitters and the number of coupled pairs.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing that emitter $u$ and emitter $v$ are physically coupled.

## Output
If there is no way to assign the frequency multipliers without creating destructive resonance, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $f_1, f_2, \dots, f_n$, where each $f_i \in \{1, 2, 3\}$ is the frequency multiplier assigned to emitter $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
