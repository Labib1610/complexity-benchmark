We can model this as a graph coloring problem.  
The product of two numbers from {1, 2, 3} is a perfect square only in these cases:

- 1×1 = 1 (perfect square)
- 2×2 = 4 (perfect square)
- 3×3 = 9 (perfect square)

So, two connected emitters cannot have the same value.  
Thus, we need to 3-color the graph such that no two adjacent vertices share the same color.

Since n ≤ 40, we can use backtracking with pruning.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)

    colors = [0] * n

    def backtrack(idx):
        if idx == n:
            return True
        # Try colors 1, 2, 3
        for c in (1, 2, 3):
            ok = True
            for nb in adj[idx]:
                if colors[nb] == c:
                    ok = False
                    break
            if ok:
                colors[idx] = c
                if backtrack(idx + 1):
                    return True
                colors[idx] = 0
        return False

    if backtrack(0):
        print("YES")
        print(" ".join(map(str, colors)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
