# Tri-Slot Execution Assignment

Time limit: 2 s   Memory limit: 256 MB

An industrial processing system must schedule $n$ tasks, indexed from $1$ to $n$, across three available operational time windows labeled $1$, $2$, and $3$. Every task must be assigned to exactly one of these three time windows.

Certain pairs of tasks share physical equipment and cannot run concurrently. Consequently, any two tasks that share a resource dependency must be assigned to different time windows.

Determine whether there exists a valid schedule for all $n$ tasks such that no two conflicting tasks share the same time window. If valid schedules exist, output `YES` on the first line and choose the schedule that forms the lexicographically smallest sequence of window assignments $(s_1, s_2, \dots, s_n)$ on the second line, where $s_i \in \{1, 2, 3\}$ denotes the window assigned to task $i$. If no valid schedule exists, output `NO`.

## Input
The first line contains two space-separated integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le \frac{n(n-1)}{2}$), representing the number of tasks and the number of resource conflict pairs, respectively.

Each of the following $m$ lines contains two space-separated integers $u$ and $v$ ($1 \le u, v \le n, u \neq v$), indicating a conflict between task $u$ and task $v$.

## Output
If no valid task schedule exists, print a single line containing `NO`.

Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1 s_2 \dots s_n$ (where each $s_i \in \{1, 2, 3\}$), representing the window assigned to task $i$. If multiple valid schedules exist, output the lexicographically smallest sequence.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
