<STATEMENT>
# Problem A — Hopper Allocation

Time limit: 2 s
Memory limit: 256 MB

An automated dispensing system processes $n$ distinct pharmaceutical ingredients. The system distributes these ingredients among three isolated holding hoppers, which are mechanically designated as hopper 1, hopper 2, and hopper 3.

Due to cross-contamination risks, specific pairs of ingredients will degrade if they are loaded into the same holding hopper. You must assign every ingredient to exactly one of the three hoppers such that no two ingredients that pose a mutual cross-contamination risk share a hopper.

To standardize loading procedures across multiple facilities, the system enforces a strict priority rule for valid assignments based on mechanical strain. For a given valid assignment, let $h_i \in \{1, 2, 3\}$ be the hopper assigned to ingredient $i$. The system calculates the configuration's total mechanical strain as:
$$ \sum_{i=1}^n h_i \cdot 4^{n-i} $$
The system must choose the valid configuration that yields the strictly minimum possible total mechanical strain.

If no safe configuration exists for the given ingredients and contamination risks, the system must reject the batch.

## Input
The first line contains two integers $n$ and $m$ — the number of ingredients and the number of cross-contamination risks ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of ingredients that pose a cross-contamination risk.

## Output
If no safe hopper assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $h_1, h_2, \dots, h_n$ (each in $\{1, 2, 3\}$), where $h_i$ is the hopper assigned to ingredient $i$, representing the configuration with the minimum mechanical strain.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Removed the explicit description of "lexicographically smallest" and replaced it with an equivalent mathematical penalty function using a base-4 polynomial. This forces models to algebraically deduce that the highest-order terms dominate, making the objective identical to finding the lexicographically first valid assignment, rather than relying on the surface keyword to structure their backtracking search.
</RATIONALE>
<PRESERVED_ANSWER>
Because the maximum value of $h_i$ is 3, the coefficient $4^{n-i}$ strictly dominates the sum of all subsequent terms, making the minimum total mechanical strain mathematically identical to the lexicographically smallest sequence of hopper numbers.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem remains identical to 3-COLORING on a graph with $n$ vertices and $m$ edges, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models that fail to recognize the equivalence might attempt to evaluate the formula directly using 64-bit integers and suffer overflow errors for $n=40$, or they may enumerate all valid configurations to find the minimum and exceed the time limit.
</RISK>
