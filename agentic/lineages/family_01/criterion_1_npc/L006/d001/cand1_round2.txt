# Problem A — Operational Cycles

Time limit: 2 s   Memory limit: 256 MB

A facility employs a number of personnel, denoted as $n$, who must each be assigned to exactly one of three available operational cycles. These cycles are identified by the numbers 1, 2, and 3. Due to operational constraints, certain pairs of personnel have conflicts and cannot be assigned to the same cycle. 

The conflict networks formed by these pairs are unrestricted simple graphs. Test data deliberately include adversarial configurations, so naive backtracking and degree-order heuristics are not sufficient. Your task is to determine an assignment for every individual such that no two conflicting personnel share the same cycle identifier, or report that no such assignment is possible.

## Input
The first line of input provides two integers: the number of personnel $n$ and the number of conflict records $m$. The facility has a strict capacity limit, ensuring the headcount $n$ is between 1 and 40 inclusive. The number of conflict records $m$ is between 0 and the theoretical maximum for simple pairs, $n(n-1)/2$ inclusive.

Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing a conflict between person $u$ and person $v$. Each conflicting pair is listed at most once.

## Output
If it is impossible to assign cycles without violating the constraints, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ separated by spaces, where each $s_i \in \{1, 2, 3\}$ represents the cycle identifier assigned to person $i$. Any valid assignment will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
