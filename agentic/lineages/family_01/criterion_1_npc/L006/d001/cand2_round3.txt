# Problem A — Hopper Allocation

Time limit: 2 s
Memory limit: 256 MB

An automated dispensing system processes a batch of distinct pharmaceutical ingredients. The system distributes these ingredients among three isolated holding hoppers, which are mechanically designated as hopper 1, hopper 2, and hopper 3.

Due to cross-contamination risks, specific pairs of ingredients will degrade if they are loaded into the same holding hopper. You must assign every ingredient to exactly one of the three hoppers such that no two ingredients that pose a mutual cross-contamination risk share a hopper.

To standardize loading procedures across multiple facilities, the system enforces a strict priority rule for valid assignments. When comparing two completely safe arrangements, the system prefers the one that assigns a lower-numbered hopper to the lowest-indexed ingredient (between ingredient $1$ and the total number of ingredients) where the two arrangements differ. The chosen configuration must be the most preferred one among all possible safe arrangements.

If no safe arrangement exists for the given ingredients and contamination risks, the system must reject the batch.

## Input
The first line contains two integers representing the number of ingredients and the number of cross-contamination risks. The facility's loading bay accommodates up to the number of slots in a standard 8-by-5 processing grid (meaning the number of ingredients is at least $1$ and at most this total grid capacity). The number of recorded risks can be anywhere from zero up to the maximum possible number of unique pairs among the ingredients.

Each of the subsequent lines (the number of which equals the number of risks) contains two integers — a pair of ingredients that pose a mutual cross-contamination risk.

## Output
If no safe hopper assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print a sequence of integers (each in $\{1, 2, 3\}$), where the $i$-th integer represents the hopper assigned to ingredient $i$. This sequence must be the most preferred valid configuration according to the priority rule described above.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
Removed the direct use of "lexicographically smallest" and replaced it with an explicit definition of the priority rule to prevent keyword-based template matching. Implemented strategy S07 by defining the maximum number of ingredients as the capacity of an 8-by-5 processing grid, requiring the solver to derive the upper bound of 40.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to assign ingredients to three hoppers without conflicting pairs while finding the configuration that minimizes the assigned values in index order is logically identical to the seed problem's lexicographically smallest assignment.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 3-coloring of a given graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
The phrase "lowest-indexed ingredient ... where the two arrangements differ" could be slightly misunderstood if a reader doesn't immediately recognize it as standard dictionary order, though it is a precise definition.
</RISK>
