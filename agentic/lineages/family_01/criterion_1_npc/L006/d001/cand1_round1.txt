# Problem A — Component Routing

Time limit: 2 s
Memory limit: 256 MB

An automated pharmaceutical facility manages the distribution of $n$ distinct chemical components. The infrastructure contains exactly three isolated containment units, mechanically identified as unit 1, unit 2, and unit 3. Every component must be routed to exactly one of these three units.

Certain pairs of components exhibit mutual instability and will degrade if placed inside the same containment unit. A valid routing plan must ensure that no two interacting components are ever assigned to the same unit.

To ensure consistency across facilities, routing plans must adhere to a strict numerical priority. Among all valid routing plans, the facility must implement the one where the sequence of unit numbers assigned to components $1$ through $n$ is lexicographically minimized. In practice, this means component 1 is placed in the lowest possible unit number, then component 2 is placed in the lowest possible unit number, and so on, without violating any stability constraints. If no valid routing plan can be formed, the entire batch must be aborted.

The facility's logic is tested against standardized regulatory certification batches. These synthetic batches, which can reach the maximum capacity of components, feature mutual instability restrictions that form deeply interlocking dependency structures. Because of how these structures are generated, a basic sequential trial-and-error evaluation will be mechanically forced to process almost the entirety of the combination space before the strictly prioritized sequence can be finalized or the batch definitively aborted.

## Input
The first line specifies two integers $n$ and $m$ — the total number of components and the number of mutual instability pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
The following $m$ lines each provide two integers $u$ and $v$ — a pair of components that cannot share a containment unit.

## Output
If the components cannot be safely routed, output a single line with `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $h_1, h_2, \dots, h_n$ (each being 1, 2, or 3), where $h_i$ denotes the containment unit for component $i$. This sequence must represent the lexicographically smallest valid routing plan.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
