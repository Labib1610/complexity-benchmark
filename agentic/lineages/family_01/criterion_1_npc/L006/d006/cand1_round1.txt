# Problem A — Harmonic Resonance

Time limit: 2 s
Memory limit: 256 MB

You are installing a system of acoustic resonators in a concert hall. Each resonator must be tuned to a harmonic tier $c_i$, which must be exactly 1, 2, or 3.

The hall's primary power grid requires at least a single resonator and can support a maximum of 40 resonators. The acoustics team performs interference tests on pairs of resonators. They may conduct any number of tests, from zero up to the theoretical maximum where every distinct pair of resonators is tested exactly once.

When a pair of resonators $u$ and $v$ interact during a test, they may form directed interference channels based on their tuned tiers. Specifically, for each tested pair $u$ and $v$:
- A directed channel forms from $u$ to $v$ if $c_u^2 c_v + c_v^3 + 12c_u + 10c_v = 6c_u^2 + 6c_v^2 + 12$.
- A directed channel forms from $v$ to $u$ if $c_v^2 c_u + c_u^3 + 12c_v + 10c_u = 6c_v^2 + 6c_u^2 + 12$.
(If both conditions are met, channels form in both directions simultaneously).

To avoid destructive acoustic feedback, the resulting network of transmission channels must never form any directed cycles (a path of one or more channels that starts and ends at the same resonator, following the direction of the channels).

Your task is to determine whether it is possible to assign a harmonic tier $c_i \in \{1, 2, 3\}$ to every resonator $i$ (from $1$ to the number of resonators) such that the network contains no directed cycles among the specified tested pairs. If it is possible, provide a valid assignment.

## Input
The first line contains two integers $n$ and $m$ — the number of resonators and the number of tested pairs.
Each of the following $m$ lines contains two integers $u$ and $v$ (valid resonator identifiers from $1$ to $n$, with $u \neq v$), representing that resonator $u$ and resonator $v$ are tested together. It is guaranteed that each unordered pair $\{u, v\}$ appears at most once in the input.

## Output
If there is no valid assignment, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $c_1, c_2, \dots, c_n$, where each $c_i \in \{1, 2, 3\}$ is the harmonic tier assigned to resonator $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
