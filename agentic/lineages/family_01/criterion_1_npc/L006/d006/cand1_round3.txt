<METHOD_NAME>Algebraic Constraint Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaced the divisibility-based directed cycle condition (which models easily recognize as a proper 3-coloring constraint since unequal values in {1,2,3} cannot form cycles) with a mathematically equivalent algebraic condition: the sum of their squares is an integer multiple of their product. For values in {1,2,3}, this is true if and only if the values are equal. This prevents models from pattern-matching the problem to graph coloring and using optimized DSATUR/degree-ordered solvers, forcing them to use naive backtracking which will likely time out.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Harmonic Resonance

Time limit: 2 s
Memory limit: 256 MB

You are configuring a network of $n$ signal emitters. Each emitter must be assigned a base frequency multiplier, which must be exactly 1, 2, or 3.

The network is tested under $m$ interference conditions. Each condition involves a specific pair of emitters. When a pair of emitters $u$ and $v$ interact, their frequency multipliers dictate the stability of their connection.

Specifically, a connection suffers from destructive harmonic resonance if the sum of the squares of their assigned multipliers is an integer multiple of the product of their multipliers. To ensure network stability, you must assign a multiplier to each emitter such that **no** interacting pair experiences destructive harmonic resonance.

Your task is to determine whether it is possible to assign a frequency multiplier $c_i \in \{1, 2, 3\}$ to every emitter $i$ (from $1$ to $n$) such that all $m$ specified interacting pairs remain stable. If it is possible, provide a valid assignment.

The system architecture supports at least 1 emitter and has a hard physical limit of 40 emitters. The number of interacting pairs $m$ can range from zero up to the theoretical maximum where every emitter interacts with every other emitter.

## Input
The first line contains two integers $n$ and $m$ — the number of emitters and the number of interacting pairs. The values of $n$ and $m$ will respect the physical limits described above.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing that emitter $u$ and emitter $v$ interact. It is guaranteed that each unordered pair $\{u, v\}$ appears at most once in the input.

## Output
If there is no valid assignment, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $c_1, c_2, \dots, c_n$, where each $c_i \in \{1, 2, 3\}$ is the frequency multiplier assigned to emitter $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the divisibility-based directed cycle condition with an algebraic condition: a pair is invalid if the sum of their squared values is an integer multiple of their product. For values in {1, 2, 3}, this condition is mathematically identical to checking if the values are equal, preserving the exact 3-coloring logic. This forces the model to evaluate the algebraic expression rather than pattern-matching to proper graph coloring, which bypasses optimized heuristics like DSATUR and leads to timeouts on naive backtracking.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic condition `(c_u^2 + c_v^2) % (c_u * c_v) == 0` evaluates to true if and only if `c_u == c_v` for any values in {1, 2, 3}, which is exactly equivalent to the seed's implicit proper 3-coloring constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to proper 3-coloring on a given graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "integer multiple" if they attempt to perform floating-point division instead of modulo arithmetic, though the phrasing is standard mathematical terminology.
</RISK>
