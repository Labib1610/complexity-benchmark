<METHOD_DESCRIPTION>Replaced the 'product is not a perfect square' rule (which trivially maps to $c_u \neq c_v$ for domain {1,2,3}) with an algebraic condition: $(c_u + c_v)^2 \pmod{c_u \times c_v} \neq 0$. This mathematically evaluates to exactly the same truth table, but prevents LLMs from pattern-matching the problem to Graph 3-Coloring, thereby disabling their specific DSATUR/degree-pruning heuristics and forcing naive backtracking which TLEs.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Harmonic Resonance

Time limit: 2 s
Memory limit: 256 MB

You are configuring a network of $n$ signal emitters. Each emitter must be assigned a base frequency multiplier, which must be exactly 1, 2, or 3.

The network is tested under $m$ interference conditions. Each condition involves a specific pair of emitters. When a pair of emitters $u$ and $v$ interact, their signal processors calculate a resonance metric to ensure wave stability. This metric is computed by taking the square of the sum of their two frequency multipliers, and finding the remainder when this squared sum is divided by the product of their two frequency multipliers.

To avoid destructive structural feedback, this remainder must be strictly greater than 0. If the remainder is exactly 0, the pair will cause a resonance failure.

Your task is to determine whether it is possible to assign a frequency multiplier $c_i \in \{1, 2, 3\}$ to every emitter $i$ (from $1$ to $n$) such that no resonance failures occur among the $m$ specified interacting pairs. If it is possible, provide a valid assignment.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of emitters and the number of interacting pairs.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing that emitter $u$ and emitter $v$ interact. It is guaranteed that each unordered pair $\{u, v\}$ appears at most once in the input.

## Output
If there is no valid assignment, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $c_1, c_2, \dots, c_n$, where each $c_i \in \{1, 2, 3\}$ is the frequency multiplier assigned to emitter $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was previously solved by models recognizing that the "product is not a perfect square" rule over the domain {1, 2, 3} is a direct proxy for $c_u \neq c_v$, making it recognizable as Graph 3-Coloring. They applied highly optimized graph coloring heuristics (like DSATUR or degree ordering) to pass the tight time limit. By replacing the condition with $(c_u + c_v)^2 \pmod{c_u \times c_v} > 0$, the exact same truth table is preserved (equal pairs yield a remainder of 0, unequal pairs yield a remainder of 1), but the graph coloring nature is deeply obfuscated. Models will likely implement a naive constraint solver without degree pruning, which will TLE on $N=40$.
</RATIONALE>
<PRESERVED_ANSWER>
For any two values $x, y \in \{1, 2, 3\}$, the remainder of $(x+y)^2$ divided by $(x \times y)$ is exactly 0 if $x = y$, and exactly 1 if $x \neq y$, making the new mathematical condition logically identical to the original.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains exactly Graph 3-Coloring, which is NP-complete, as the structure, domain size, and boolean feasibility constraints have not changed.
</PRESERVED_CLASS>
