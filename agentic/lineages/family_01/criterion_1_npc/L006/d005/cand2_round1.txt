<STATEMENT>
# Problem A — Harmonic Resonance

Time limit: 2 s
Memory limit: 256 MB

You are configuring a network of $n$ signal emitters. The number of emitters $n$ is at least 1 and at most the number of spaces on a classic Monopoly board. Each emitter must be assigned a base frequency multiplier, which must be exactly 1, 2, or 3.

The network is tested under $m$ interference conditions. The number of conditions $m$ ranges from 0 up to the maximum possible number of unique pairs among the $n$ emitters. Each condition involves a specific pair of emitters. When a pair of emitters $u$ and $v$ interact, they generate a structural feedback metric $S = c_u^2 + c_v^2$. 

To maintain system stability, this metric $S$ must never be perfectly divisible by the product of their frequency multipliers, $c_u \times c_v$. If $S$ is a multiple of $c_u \times c_v$, the pair will cause a resonance failure.

Your task is to determine whether it is possible to assign a frequency multiplier $c_i \in \{1, 2, 3\}$ to every emitter $i$ (from 1 to $n$) such that no resonance failures occur among the $m$ specified interacting pairs. If it is possible, provide a valid assignment.

## Input
The first line contains two integers $n$ and $m$ — the number of emitters and the number of interacting pairs.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing that emitter $u$ and emitter $v$ interact. It is guaranteed that each unordered pair $\{u, v\}$ appears at most once in the input.

## Output
If there is no valid assignment, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $c_1, c_2, \dots, c_n$, where each $c_i \in \{1, 2, 3\}$ is the frequency multiplier assigned to emitter $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

This forces the model to either mathematically prove this is equivalent to `c_u == c_v`, or implement it as a generic constraint. I also changed the numeric bounds to be derived from a real-world fact (Monopoly board spaces) following Strategy S07.
</RATIONALE>
