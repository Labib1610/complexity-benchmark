We can model this as a graph problem.  
Each emitter gets a value from {1, 2, 3}.  
A directed edge forms from u to v if c_v is a multiple of c_u.  

Since values are only 1, 2, 3:
- 1 divides everything → edges from 1 to all others.
- 2 divides 2 and 4 (but 4 not allowed), so 2 → 2 only (no self-loop) and 2 → nothing else except itself.
- 3 divides 3 only, so no edges from 3 except to itself.

Thus:
- If c_u = 1, then u has outgoing edges to all neighbors.
- If c_u = 2, then u has outgoing edges only to neighbors with c = 2 (but that would be a self-loop in the undirected sense, so no edges unless both are 2, which would create a 2-cycle).
- If c_u = 3, no outgoing edges to others.

So the only way to avoid cycles is to ensure that no two connected nodes both have value 1 (because then they'd have edges both ways), and no node with value 1 is connected to a node with value 2 or 3 in a way that creates a cycle.

Actually, let's think more carefully:

If we assign 1 to a node, it will have outgoing edges to all its neighbors.  
If any neighbor also has 1, we get a 2-cycle → invalid.  
If a neighbor has 2, then 1 → 2 edge exists, but 2 does not divide 1, so no edge back → fine.  
If a neighbor has 3, same → fine.

If we assign 2 to a node, it has outgoing edges only to neighbors with value 2 (since 2 divides 2). That would create a 2-cycle if two connected nodes both have 2. So we cannot have two adjacent nodes both with 2.

If we assign 3 to a node, it has no outgoing edges to others (since 3 only divides 3, and no one else has 3 except itself). So 3 is safe with anyone.

Thus the constraints are:
- No edge between two nodes both assigned 1.
- No edge between two nodes both assigned 2.
- Nodes with 3 can be adjacent to anyone.

So the problem reduces to: Can we color the graph with 3 colors (1,2,3) such that no edge connects two nodes of color 1 or two nodes of color 2?  
That means color 1 and color 2 each form an independent set.  
Color 3 can be used anywhere.

Equivalently: The graph induced by colors 1 and 2 must be bipartite (since edges only allowed between 1 and 2).  
So we can assign each node either 1, 2, or 3.  
We can simply try to 2-color the graph with colors 1 and 2, and if that fails, use 3 for some nodes.

But since n ≤ 40, we can brute force with backtracking or use a smarter approach.

Observation:  
We can assign 3 to all nodes first, then try to change some to 1 or 2 while respecting constraints.  
Actually, the simplest:  
We can try to find a valid assignment by trying all possibilities for nodes with degree > 0? That's too big.

Better:  
We can treat it as:  
- Choose a subset S1 of nodes to be 1, S2 to be 2, rest 3.  
- S1 must be an independent set.  
- S2 must be an independent set.  
- No edge between S1 and S2? Actually edges between 1 and 2 are fine (1→2 only). So no restriction there.

So we just need to partition the graph into two independent sets (S1 and S2) and the rest can be 3.  
That means the graph induced by S1 ∪ S2 must be bipartite.  
So we can try to find a bipartite subgraph covering as many nodes as possible, but we don't need maximum — we just need any valid assignment.

Simplest:  
We can assign all nodes 3. That's always valid?  
Check: If all are 3, then no edges form because 3 doesn't divide 3? Wait, 3 divides 3, so if two adjacent nodes both have 3, then edge forms both ways → cycle of length 2!  
Oh! That's a problem. So we cannot have adjacent nodes both with 3 either.

So actually, no two adjacent nodes can have the same value, because if they have the same value, then each divides the other → 2-cycle.  
Thus the graph must be properly colored with 3 colors (1,2,3) such that adjacent nodes have different colors.  
That's exactly a 3-coloring problem!

So the problem reduces to: Can we 3-color the given graph?  
If yes, output the coloring.  
If no, output NO.

n ≤ 40, so we can use backtracking with pruning.

Let's implement a simple backtracking 3-coloring.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    
    def backtrack(node):
        if node == n:
            return True
        # Try colors 1,2,3
        for c in (1,2,3):
            ok = True
            for nb in adj[node]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[node] = c
                if backtrack(node+1):
                    return True
                color[node] = -1
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
