<METHOD_NAME>
Global Acyclicity Disguise
</METHOD_NAME>
<METHOD_DESCRIPTION>
Transforms a local pairwise inequality constraint (graph coloring) into a global directed acyclicity constraint by defining edge directions based on divisibility. Equal values create 2-cycles, while unequal values strictly orient edges from 1 to {2,3} or create no edges at all, making cycles impossible. This prevents models from recognizing the problem as graph coloring and applying DSATUR or max-degree heuristics, forcing them to use naive backtracking with cycle detection which will TLE on hard instances.
</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Harmonic Resonance

Time limit: 2 s
Memory limit: 256 MB

You are configuring a network of $n$ signal emitters. Each emitter must be assigned a base frequency multiplier, which must be exactly 1, 2, or 3.

The network is tested under $m$ interference conditions. Each condition involves a specific pair of emitters. When a pair of emitters $u$ and $v$ interact, they may form directed transmission channels based on their assigned multipliers. 

Specifically, for each interacting pair $u$ and $v$:
- A directed channel forms from $u$ to $v$ if $c_v$ is a multiple of $c_u$.
- A directed channel forms from $v$ to $u$ if $c_u$ is a multiple of $c_v$.
(If both conditions are met, channels form in both directions simultaneously).

To avoid destructive structural feedback, the resulting network of transmission channels must never form any directed cycles (a path of one or more channels that starts and ends at the same emitter, following the direction of the channels).

Your task is to determine whether it is possible to assign a frequency multiplier $c_i \in \{1, 2, 3\}$ to every emitter $i$ (from $1$ to $n$) such that the network contains no directed cycles among the $m$ specified interacting pairs. If it is possible, provide a valid assignment.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of emitters and the number of interacting pairs.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing that emitter $u$ and emitter $v$ interact. It is guaranteed that each unordered pair $\{u, v\}$ appears at most once in the input.

## Output
If there is no valid assignment, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $c_1, c_2, \dots, c_n$, where each $c_i \in \{1, 2, 3\}$ is the frequency multiplier assigned to emitter $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was completely reframed from a local pairwise constraint ("product is not a perfect square") to a global structural constraint ("network contains no directed cycles" based on divisibility). This breaks the immediate logical deduction to graph 3-coloring, which prevents models from deploying specialized graph-coloring heuristics like DSATUR or max-degree sorting. Models will instead likely write a generic backtracking solver with a DFS-based cycle detector, which will Time Limit Exceed on the NP-complete test cases.
</RATIONALE>
<PRESERVED_ANSWER>
If any interacting pair has equal multipliers, they divide each other, forming a 2-cycle and invalidating the assignment; if all interacting pairs have unequal multipliers, edges only ever point from 1 to 2 or 1 to 3, forming a strict partial order where cycles are mathematically impossible, making the condition perfectly equivalent to the original inequality constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Graph 3-Coloring, preserving its NP-completeness and all associated computational hardness properties.
</PRESERVED_CLASS>
