<METHOD_NAME>Global Product Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the independent pairwise constraint wording with a single global product constraint modulo a prime. To achieve the early pruning necessary to pass within the time limit, models must algebraically deduce that a product is non-zero modulo a prime if and only if all individual pairwise factors are non-zero.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Quantum Interference

Time limit: 2 s
Memory limit: 256 MB

You are tuning a network of $n$ quantum resonators. Each resonator must be assigned a discrete energy state, which must be exactly 1, 2, or 3.

The network is tested under $m$ coupling conditions. Each condition involves a specific pair of resonators. When a pair of resonators $u$ and $v$ are coupled, they generate an interference factor $F(u, v) = s_u^3 + s_v^3 - s_u^2 s_v - s_u s_v^2$, based on their assigned states $s_u$ and $s_v$.

To avoid destructive feedback and achieve stable network resonance, the network's overall interference coefficient $\Pi$, defined as the product of $F(u, v)$ over all $m$ coupled pairs, must not be divisible by 7. (If $m=0$, the network is inherently stable).

Your task is to determine whether it is possible to assign an energy state $s_i \in \{1, 2, 3\}$ to every resonator $i$ (from $1$ to $n$) such that the network achieves stable resonance. If it is possible, provide a valid assignment.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of resonators and the number of coupled pairs.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing that resonator $u$ and resonator $v$ are coupled. It is guaranteed that each unordered pair $\{u, v\}$ appears at most once in the input.

## Output
If there is no valid assignment, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$, where each $s_i \in \{1, 2, 3\}$ is the energy state assigned to resonator $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The previous wording explicitly stated that "absolutely no coupled pair" may satisfy the constraint, handing the model the independent pairwise nature of the problem on a silver platter. By replacing this with a global product constraint over all edges, models that rely on surface pattern matching will attempt to evaluate the entire product at the end of the assignment, leading to Time Limit Exceeded on $n=40$. To succeed, the model must mathematically deduce that because 7 is prime, the global product is non-zero modulo 7 if and only if every pairwise factor is non-zero, recovering the independent constraints needed for early pruning.
</RATIONALE>
<PRESERVED_ANSWER>
The overall product is not divisible by 7 if and only if none of the individual factors $F(u, v)$ are divisible by 7, which exactly matches the original constraint that no single pair satisfies the resonance collision equation.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-COLORING, as the mathematical condition $F(u, v) \not\equiv 0 \pmod 7$ for $s_i \in \{1,2,3\}$ simplifies strictly to $s_u \neq s_v$, preserving the NP-complete graph coloring structure.
</PRESERVED_CLASS>
