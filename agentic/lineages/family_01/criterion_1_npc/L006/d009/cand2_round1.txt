<METHOD_NAME>Global Polynomial Sum Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Replaced the independent pairwise inequality with a global sum constraint over a carefully constructed polynomial. The polynomial evaluates to 4 if the states differ and 0 if they are the same. Thus the global sum equals 4m if and only if all coupled pairs have different states. Models that translate this directly into a backtracking solver without mathematically deducing the maximum value of the polynomial will fail to prune the search space and TLE, while SMT solvers may struggle with the non-linear global sum.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Quantum Interference

Time limit: 2 s
Memory limit: 256 MB

You are tuning a network of $n$ quantum resonators. Each resonator must be assigned a discrete energy state, which must be exactly 1, 2, or 3.

The network is tested under $m$ coupling conditions. Each condition involves a specific pair of resonators. When a pair of resonators $u$ and $v$ are coupled, they generate an interference score based on their assigned states $s_u$ and $s_v$, given by the formula:

$I(u, v) = (s_u - s_v)^2 (5 - (s_u - s_v)^2)$

The network's total resonance metric $W$ is the sum of the interference scores of all $m$ coupled pairs. To avoid destructive feedback and achieve stable resonance, the network must be tuned such that its total resonance metric is exactly $W = 4m$.

Your task is to determine whether it is possible to assign an energy state $s_i \in \{1, 2, 3\}$ to every resonator $i$ (from $1$ to $n$) such that the network achieves stable resonance. If it is possible, provide a valid assignment.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of resonators and the number of coupled pairs.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing that resonator $u$ and resonator $v$ are coupled. It is guaranteed that each unordered pair $\{u, v\}$ appears at most once in the input.

## Output
If there is no valid assignment, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$, where each $s_i \in \{1, 2, 3\}$ is the energy state assigned to resonator $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem previously presented independent pairwise constraints, allowing models to easily build a constraint graph and apply standard graph coloring algorithms. By replacing this with a global sum over a specific polynomial, the constraint appears holistic rather than pairwise. To prune a search tree efficiently, the model must now mathematically deduce that the polynomial evaluates to exactly 4 for any unequal states and 0 for equal states, meaning the sum reaches $4m$ if and only if all edges have different states.
</RATIONALE>
<PRESERVED_ANSWER>
For any $s_u, s_v \in \{1, 2, 3\}$, the expression $(s_u - s_v)^2 (5 - (s_u - s_v)^2)$ evaluates to 4 if $s_u \neq s_v$ and 0 if $s_u = s_v$; thus the sum over $m$ pairs reaches exactly $4m$ if and only if $s_u \neq s_v$ for all coupled pairs, which is identical to the original requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to 3-coloring on a graph with $n$ vertices and $m$ edges, preserving its NP-complete status.
</PRESERVED_CLASS>
