# Problem A — Quantum Interference

Time limit: 2 s
Memory limit: 256 MB

You are tuning a network of $n$ quantum resonators. Each resonator must be assigned a discrete energy state, which must be exactly 1, 2, or 3.

The network is tested under a sequence of $m$ coupling conditions. The $j$-th condition (for $j = 1 \dots m$) involves a specific pair of resonators $u_j$ and $v_j$. 
When a sequence of states is assigned to the network, interference propagates cumulatively through the coupling conditions. We define the network's interference state $Z_j$ after the $j$-th coupling as follows:
- The initial interference state is $Z_0 = 1$.
- For each $j$ from $1$ to $m$, the coupling generates a local factor:
  $W_j = s_{u_j}^3 + s_{v_j}^3 - s_{u_j}^2 s_{v_j} - s_{u_j} s_{v_j}^2$
  The interference state is then updated as:
  $Z_j = (Z_{j-1} \cdot W_j) \pmod 7$

To avoid destructive feedback and achieve stable network resonance, the final interference state of the network must not collapse to zero; that is, we require $Z_m > 0$.

Your task is to determine whether it is possible to assign an energy state $s_i \in \{1, 2, 3\}$ to every resonator $i$ (from $1$ to $n$) such that the network achieves stable resonance. If it is possible, provide a valid assignment.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of resonators and the number of coupling conditions.
Each of the following $m$ lines contains two integers $u_j$ and $v_j$ ($1 \le u_j, v_j \le n$, $u_j \neq v_j$), representing the $j$-th coupled pair. It is guaranteed that each unordered pair appears at most once in the input.

## Output
If there is no valid assignment, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$, where each $s_i \in \{1, 2, 3\}$ is the energy state assigned to resonator $i$. If multiple valid assignments exist, you may output any of them.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
