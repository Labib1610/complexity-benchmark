<METHOD_NAME>Euler's Totient Inequality on Prime Map</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the cubic equation that explicitly sets roots at $0, f_u, f_v$ with an inequality involving Euler's totient function on the product of characteristic primes mapped from the values 1, 2, 3. The inequality $\phi(p \times q) < p \times q - \sqrt{p \times q}$ holds strictly if and only if $p \neq q$. This completely obfuscates the $f_u \neq f_v$ condition behind number theory properties, preventing LLMs from pattern-matching it to graph 3-coloring.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Resonant Loop Prevention

Time limit: 2 s
Memory limit: 256 MB

You are configuring a system of $n$ signal relays, numbered 1 to $n$. Each relay must be assigned a frequency multiplier chosen from the values 1, 2, and 3. This configuration is expressed as a sequence $f_1, f_2, \dots, f_n$.

You are provided with a list of $m$ pairs of relays that are in physical proximity. Proximity is a symmetric relationship. 

To analyze stability, we map each frequency multiplier to a characteristic prime number: $P_1 = 2$, $P_2 = 3$, and $P_3 = 5$. Thus, the prime assigned to relay $i$ is $P_{f_i}$.

For each pair of relays $u$ and $v$ that are in physical proximity, their combined resonance value $K$ is the product of their characteristic primes:
$$K = P_{f_u} \times P_{f_v}$$

The system is perfectly stable if and only if, for every pair of relays in physical proximity, Euler's totient function $\phi(K)$ satisfies the strict inequality:
$$\phi(K) < K - \sqrt{K}$$
(Euler's totient function $\phi(x)$ counts the number of positive integers up to $x$ that are relatively prime to $x$.)

Your task is to determine if there exists a valid sequence of multipliers such that the system is perfectly stable. If such a sequence exists, you must output it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that relay $u$ and relay $v$ are in physical proximity.

## Output
If there is no valid sequence of multipliers that makes the system stable, print a single line containing `NO`.
If at least one such sequence exists, print `YES` on the first line. On the second line, print the $n$ integers $f_1, f_2, \dots, f_n$ representing the multipliers assigned to the relays. 
If there are multiple valid sequences, you must output the one that is lexicographically smallest. (A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index $i$ where they differ, $A_i < B_i$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit factorable cubic equation from the seed with a condition based on Euler's totient function acting on the product of characteristic primes. The inequality $\phi(K) < K - \sqrt{K}$ is mathematically equivalent to $f_u \neq f_v$, but it removes the obvious equality check that solvers use to recognize graph 3-coloring. The exact numeric bounds were restored to ensure strict compliance with the I/O contract check.
</RATIONALE>
<PRESERVED_ANSWER>
The inequality $\phi(K) < K - \sqrt{K}$ holds exactly when the characteristic primes (and therefore the assigned multipliers) are distinct, meaning the set of valid configurations is identical to the seed's requirement that adjacent relays have different values.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to lexicographically-smallest graph 3-coloring, which is NP-complete, since the underlying constraint graph and the number of available states per vertex (3) are unchanged.
</PRESERVED_CLASS>
