<STATEMENT>
# Problem A — Resonant Loop Prevention

Time limit: 2 s
Memory limit: 256 MB

You are configuring a system of $n$ signal relays, numbered 1 to $n$. Each relay must be assigned a frequency multiplier chosen from the values 1, 2, and 3. This configuration is expressed as a sequence $f_1, f_2, \dots, f_n$.

You are provided with a list of $m$ pairs of relays that are in physical proximity. Proximity is a symmetric relationship. 

When the system is activated, each relay $i$ will physically resonate at a continuous actual frequency $x_i$. Because of environmental noise, you cannot know the exact value of $x_i$ in advance. However, the hardware guarantees that the actual frequency will always remain within $\frac{1}{3}$ of its assigned multiplier. In other words, $x_i$ can be any real number satisfying $f_i - \frac{1}{3} \le x_i \le f_i + \frac{1}{3}$.

The system is perfectly stable if and only if, regardless of how the actual frequencies $x_1, \dots, x_n$ drift within their guaranteed bounds, every pair of relays $u$ and $v$ in physical proximity maintains a resonance separation $|x_u - x_v|$ that is strictly greater than $\frac{1}{4}$.

Your task is to determine if there exists a valid sequence of multipliers such that the system is guaranteed to be perfectly stable. If such a sequence exists, you must output it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that relay $u$ and relay $v$ are in physical proximity.

## Output
If there is no valid sequence of multipliers that makes the system stable, print a single line containing `NO`.
If at least one such sequence exists, print `YES` on the first line. On the second line, print the $n$ integers $f_1, f_2, \dots, f_n$ representing the multipliers assigned to the relays. 
If there are multiple valid sequences, you must output the one that is lexicographically smallest. (A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index $i$ where they differ, $A_i < B_i$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the direct algebraic inequality with a physical scenario involving continuous frequency drift and a worst-case separation bound. Models that rely on surface pattern matching will attempt to simulate the continuous drift or formulate it as a complex constraint satisfaction problem, failing to integrate it with the lexicographical DFS. Models that genuinely reason will deduce the worst-case bound ($|f_u - f_v| - 2/3 > 1/4$) and realize it simplifies exactly to the discrete constraint $f_u \neq f_v$.
</RATIONALE>
<PRESERVED_ANSWER>
The worst-case separation between two frequencies drifting by at most 1/3 is $|f_u - f_v| - 2/3$; requiring this to be strictly greater than 1/4 is mathematically equivalent to $|f_u - f_v| > 11/12$, which for integers means $f_u \neq f_v$, exactly matching the original stability condition for every possible input.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains exactly finding the lexicographically smallest valid 3-coloring of a graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
The phrase "regardless of how the actual frequencies ... drift" could be misinterpreted as a dynamic process over time, rather than a static worst-case analysis, though both interpretations lead to the exact same mathematical bound.
</RISK>
