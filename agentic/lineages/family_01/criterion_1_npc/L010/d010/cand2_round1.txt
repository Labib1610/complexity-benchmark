<METHOD_NAME>Global Polynomial Equality Constraint</METHOD_NAME>
<METHOD_DESCRIPTION>Transforms the local inequality constraints ($f_u \neq f_v$) into a single global equality $\sum (f_u - f_v)^4 = 5 \sum (f_u - f_v)^2 - 4m$. Because the implied polynomial terms $(d^4 - 5d^2 + 4)$ are strictly non-negative for $d \in \{0,1,2\}$ and zero only when $d \neq 0$, the global equation holds if and only if the graph is properly 3-colored. Models that blindly translate this global condition will fail to prune the search tree and time out, defeating solvers that rely on surface pattern matching to precompute edge compatibility. Additionally, the explicit domain $\{1, 2, 3\}$ is replaced with an indirect bound (positive integers whose cube is $< 30$) to prevent naive iteration over the domain.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Harmonic Network Equilibrium

Time limit: 2 s
Memory limit: 256 MB

You are configuring a system of $n$ signal relays, numbered 1 to $n$. Each relay must be assigned a frequency multiplier. To comply with hardware limitations, each multiplier must be a positive integer whose cube is strictly less than 30. This configuration is expressed as a sequence $f_1, f_2, \dots, f_n$.

You are provided with a list of $m$ pairs of relays that are in physical proximity. Proximity is a symmetric relationship.

We define two network-wide metrics based on the differences in multipliers across all proximity pairs:
The **Quartic Stress** $D$ is the sum of the fourth powers of the differences in multipliers for all proximity pairs:
$$D = \sum_{(u,v) \in \text{proximity}} (f_u - f_v)^4$$
The **Quadratic Stress** $S$ is the sum of the squares of the differences in multipliers for all proximity pairs:
$$S = \sum_{(u,v) \in \text{proximity}} (f_u - f_v)^2$$

Note that each of the $m$ given proximity pairs is counted exactly once in these sums.

The system achieves **perfect harmonic equilibrium** if and only if the network-wide metrics satisfy the following exact balance equation:
$$D = 5S - 4m$$

Your task is to determine if there exists a valid sequence of multipliers such that the system achieves perfect harmonic equilibrium. If such a sequence exists, you must output it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that relay $u$ and relay $v$ are in physical proximity.

## Output
If there is no valid sequence of multipliers that brings the system into equilibrium, print a single line containing `NO`.
If at least one such sequence exists, print `YES` on the first line. On the second line, print the $n$ integers $f_1, f_2, \dots, f_n$ representing the multipliers assigned to the relays. 
If there are multiple valid sequences, you must output the one that is lexicographically smallest. (A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index $i$ where they differ, $A_i < B_i$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The discrete domain $\{1, 2, 3\}$ was replaced with an indirect algebraic bound (positive integers whose cube is $< 30$). The local edge-by-edge stability condition was replaced with a single global equality condition $D = 5S - 4m$. This forces the model to mathematically analyze the global sum to prove that it is equivalent to the local constraint $f_u \neq f_v$; models that merely translate the problem statement into code will fail to prune the search tree and will time out on $N=40$.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $D = 5S - 4m$ algebraically simplifies to $\sum ((f_u - f_v)^4 - 5(f_u - f_v)^2 + 4) = 0$, and since the terms are non-negative for $f_i \in \{1,2,3\}$ and zero only when $f_u \neq f_v$, it perfectly enforces the original stability constraint.
</PRESERVED_ANSWER>
