# Problem A — Cryptographic Key Distribution

Time limit: 2 s   Memory limit: 256 MB

A distributed computing environment consists of $n$ microservices. The system uses exactly three distinct cryptographic keys, identified by the integers 1, 2, and 3. Each microservice must be configured to operate using exactly one of these three keys.

Due to shared memory constraints, certain pairs of microservices are incompatible if they operate using the same key. You are provided with a list of these incompatible pairs. Your task is to determine if there is a valid key configuration for all $n$ microservices such that no two incompatible microservices share the same key.

If a valid configuration is possible, you must output the one that is lexicographically smallest. When comparing two valid configurations, compare the key assigned to microservice 1, then microservice 2, and so forth. The lexicographically smaller configuration is the one that assigns a smaller key identifier at the first microservice where the two configurations differ.

## Input
The first line provides two integers $n$ and $m$ — the total number of microservices and the number of incompatible pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the following $m$ lines contains two integers $u$ and $v$, indicating that microservice $u$ and microservice $v$ cannot be assigned the same key.

## Output
If there is no way to assign the keys without violating the constraints, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $k_1, k_2, \dots, k_n$ (where each $k_i \in \{1, 2, 3\}$), representing the key assigned to microservice $i$. This sequence must be the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
