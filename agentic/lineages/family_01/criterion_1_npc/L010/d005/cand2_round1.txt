<METHOD_NAME>Quadratic Discriminant Encoding</METHOD_NAME>
<METHOD_DESCRIPTION>Encodes the graph coloring inequality constraint (u != v) by requiring that a quadratic equation constructed from the assigned variables has two distinct real roots. The discriminant simplifies to (u - v)^2 > 0, which is exactly u != v, hiding the discrete combinatorics structure behind continuous algebra.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Quadratic Configuration

Time limit: 2 s
Memory limit: 256 MB

You are given an integer $n$. You must construct a sequence $A = (a_1, a_2, \dots, a_n)$ where each element $a_i$ is chosen from the set $\{1, 2, 3\}$.

You are also provided with a list of $m$ index pairs. 
For the sequence $A$ to be considered *valid*, it must satisfy the following condition for every given pair $(u, v)$:
The quadratic equation in variable $x$:
$$a_u x^2 + (a_u + a_v) x + a_v = 0$$
must have two distinct real roots.

Your task is to determine if there exists a valid sequence $A$. If such a sequence exists, you must output it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), representing a given index pair.

## Output
If no valid sequence exists, print a single line containing `NO`.
If at least one valid sequence exists, output `YES` on the first line. On the second line, output the $n$ integers $a_1, a_2, \dots, a_n$ representing the sequence.
If there are multiple valid sequences, output the one that is lexicographically smallest. (A sequence $P$ is lexicographically smaller than $Q$ if, at the first index $i$ where they differ, $P_i < Q_i$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was completely reframed from a discrete "zero-conflict" assignment to a continuous algebraic property. The disequality constraint ($g_u \neq g_v$) is now encoded as requiring a specific quadratic equation to have two distinct real roots. Models that rely on surface pattern matching to detect graph 3-coloring will fail to recognize the underlying structure and may attempt to use continuous numerical solvers or fail to simplify the math. Models that genuinely reason will check the discriminant $\Delta = (a_u + a_v)^2 - 4a_u a_v = (a_u - a_v)^2 > 0$, deduce that it simply means $a_u \neq a_v$, and write a standard backtracking search.
</RATIONALE>
<PRESERVED_ANSWER>
The discriminant of the quadratic equation is $(a_u - a_v)^2$; requiring two distinct real roots means the discriminant must be strictly positive, which is mathematically identical to requiring $a_u \neq a_v$ since the domain is $\{1, 2, 3\}$.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding a 3-coloring of a graph, which is NP-complete.
</PRESERVED_CLASS>
