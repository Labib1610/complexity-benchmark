**Solution Explanation**

For a relay `i` we choose a multiplier `f_i ∈ {1,2,3}`.
For an edge `(u,v)` the diagonal entry of `Sᵀ·P·S` that corresponds to
multiplier `c` counts how many edges have both ends coloured `c`.
The system is *perfectly stable* iff every diagonal entry is `0`,
i.e. **no edge connects two relays with the same multiplier**.

So the problem is exactly:

*Find a proper 3‑colouring of the given undirected graph.
If several colourings exist output the lexicographically smallest one
(colours are compared as numbers 1 < 2 < 3).*

`n ≤ 40`, therefore a simple depth‑first search in the natural order
`1,2,…,n` is fast enough:
as soon as a colour conflicts with an already coloured neighbour we backtrack.
The first complete colouring found is automatically the lexicographically
smallest one because we try colours `1,2,3` in this order for each vertex.

The search tree is heavily pruned:
as soon as a vertex has a coloured neighbour with colour `c`,
colour `c` is forbidden for it.
For dense graphs the conflict appears very early,
for sparse graphs the branching factor stays small.
With `n = 40` the program finishes well within the limits.



--------------------------------------------------------------------

#### Algorithm
```
read n, m
build adjacency list adj[1…n]

col[1…n] = 0                     # 0 = uncoloured

def dfs(v):
    if v == n+1:                 # all vertices coloured
        return True
    for colour in (1,2,3):       # try in increasing order
        ok = True
        for to in adj[v]:
            if col[to] == colour:
                ok = False
                break
        if not ok: continue
        col[v] = colour
        if dfs(v+1):
            return True
        col[v] = 0                # backtrack
    return False                  # no colour works for vertex v

if dfs(1):
    print "YES"
    print colours col[1] … col[n] separated by spaces
else:
    print "NO"
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a lexicographically smallest
proper 3‑colouring iff such a colouring exists, otherwise prints `NO`.

---

**Lemma 1**  
During the execution of `dfs(v)` the array `col[1…v‑1]` contains a proper
partial colouring: no edge whose both ends are among `{1,…,v‑1}` has equal
colours.

*Proof.*  
Initially `v = 1` and the statement is vacuously true.
When the algorithm assigns a colour to vertex `v` it checks all neighbours
already coloured (they are among `{1,…,v‑1}`) and rejects the colour if any
neighbour has the same colour. Hence after a successful assignment the
property holds for `{1,…,v}`. ∎



**Lemma 2**  
If `dfs(v)` returns `True`, then `col[1…n]` is a proper 3‑colouring of the
whole graph.

*Proof.*  
`dfs(v)` returns `True` only after a recursive call `dfs(v+1)` returned
`True`, or when `v = n+1`. By induction on the recursion depth,
all vertices `v,…,n` have been assigned colours that never conflict with
already coloured neighbours (Lemma&nbsp;1). When the recursion finishes,
every vertex is coloured and no edge has equal colours on its ends. ∎



**Lemma 3**  
If a proper 3‑colouring exists, `dfs(1)` returns `True`.

*Proof.*  
Consider any proper colouring `C`. The DFS explores colours for vertex 1
in the order `1,2,3`. If the colour chosen by `C` for vertex 1 is tried,
it is compatible with the (still empty) coloured set, so the recursion
continues with vertex 2. Inductively, whenever the recursion reaches vertex
`v`, the colours of vertices `1…v‑1` equal those of `C` (because the
algorithm never backtracks on a colour that can be extended to a full
solution). Since `C` is proper, the colour of `v` in `C` is allowed and will
be tried, leading to vertex `v+1`. Thus the recursion can follow the whole
colouring `C` and finally succeeds. ∎



**Lemma 4**  
If `dfs(1)` returns `True`, the produced colouring is the lexicographically
smallest proper 3‑colouring.

*Proof.*  
The search processes vertices in increasing index order and, for each
vertex, tries colours `1,2,3` in that order.
The first complete colouring found is therefore the first leaf of the
search tree visited in a depth‑first left‑to‑right order.
Any other proper colouring differs from the found one at the first index
where the colour is larger (otherwise the DFS would have taken that branch
earlier). Hence the found colouring is lexicographically minimal. ∎



**Theorem**  
The program outputs  

* `YES` and the lexicographically smallest proper 3‑colouring
  iff such a colouring exists;
* `NO` otherwise.

*Proof.*  
If a proper colouring exists, Lemma&nbsp;3 guarantees `dfs(1)` returns
`True`; Lemma&nbsp;2 shows the resulting `col` is a proper colouring,
and Lemma&nbsp;4 gives its minimality, so the program prints `YES` and it.
If no proper colouring exists, every recursive call eventually tries all
three colours and backtracks, thus `dfs(1)` returns `False` and the program
prints `NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`n ≤ 40`.  
In the worst case the algorithm explores the whole 3‑ary recursion tree,
i.e. `O(3^n)` states, but pruning eliminates the vast majority.
For each recursive step we check at most `deg(v) ≤ n-1` neighbours,
so the work per node is `O(n)`.  
In practice the running time is far below the limit; the memory usage is
`O(n + m)` for the adjacency list and the colour array.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    col = [0] * (n + 1)
    sys.setrecursionlimit(10000)

    def dfs(v: int) -> bool:
        if v == n + 1:
            return True
        for c in (1, 2, 3):
            ok = True
            for nb in adj[v]:
                if col[nb] == c:
                    ok = False
                    break
            if not ok:
                continue
            col[v] = c
            if dfs(v + 1):
                return True
            col[v] = 0
        return False

    if dfs(1):
        out = ['YES', ' '.join(str(col[i]) for i in range(1, n + 1))]
        sys.stdout.write('\n'.join(out))
    else:
        sys.stdout.write('NO')

if __name__ == "__main__":
    solve()
```
