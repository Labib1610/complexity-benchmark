<STATEMENT>
# Problem A — Resonant Loop Prevention

Time limit: 2 s
Memory limit: 256 MB

You are configuring a system of $n$ signal relays, numbered 1 to $n$. Each relay must be assigned a frequency multiplier chosen from the values 1, 2, and 3. This configuration is expressed as a sequence $f_1, f_2, \dots, f_n$, where $f_i \in \{1, 2, 3\}$ is the multiplier for relay $i$.

You are provided with a list of $m$ pairs of relays that are in physical proximity. When two relays $u$ and $v$ are in proximity, their signals interact over continuous time $t$. Their joint interference waveform is modeled by the function:
$$W_{u,v}(t) = 2t^3 - 3(f_u + f_v)t^2 + 6f_u f_v t$$

The two relays will create a destructive resonant loop if and only if their joint interference waveform $W_{u,v}(t)$ contains a stationary point of inflection. A stationary point of inflection is defined as a point $t$ where the first derivative with respect to $t$ is zero ($W'_{u,v}(t) = 0$) and the second derivative $W''_{u,v}(t)$ changes sign.

Your task is to determine if there exists a valid sequence of multipliers such that absolutely no resonant loops are created among any of the given proximity pairs. If such a sequence exists, you must output it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that relay $u$ and relay $v$ are in physical proximity.

## Output
If there is no valid sequence of multipliers that avoids all resonant loops, print a single line containing `NO`.
If at least one such sequence exists, print `YES` on the first line. On the second line, print the $n$ integers $f_1, f_2, \dots, f_n$ (each in $\{1, 2, 3\}$) representing the multipliers assigned to the relays. 
If there are multiple valid sequences, you must output the one that is lexicographically smallest. (A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index $i$ where they differ, $A_i < B_i$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The explicit cross-product condition from the seed was replaced with a calculus-based condition on a cubic function. The first derivative of the given function is $6(t-f_u)(t-f_v)$, meaning a stationary point of inflection (where the first derivative is zero and the second derivative changes sign) occurs if and only if $f_u = f_v$. This forces the model to perform symbolic differentiation and root analysis to deduce the equivalence, preventing simple pattern matching to graph coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical condition for a destructive resonant loop (a stationary point of inflection in the waveform) is algebraically identical to the original cross-product condition ($f_u = f_v$), so the set of valid multiplier assignments and the lexicographically smallest tie-break remains exactly the same for all inputs.
</PRESERVED_ANSWER>
