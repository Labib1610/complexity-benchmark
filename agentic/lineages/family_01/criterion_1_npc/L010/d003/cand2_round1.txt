# Problem A — Harmonic Resonance Mitigation

Time limit: 2 s   Memory limit: 256 MB

A smart grid operates using three distinct power sources, identified by the codes 1, 2, and 3. The system supplies power to a collection of industrial facilities, which are numbered sequentially starting from 1. The minimum number of facilities is one. The maximum number of facilities is exactly thirteen more than the cube of the number of distinct power sources. 

Due to harmonic resonance, certain pairs of facilities will experience severe voltage fluctuations if they draw power from the same source. The number of such resonating pairs can be as low as zero, and as high as the total number of unique pairs that can be chosen from the present facilities.

To guarantee stability, you must connect each facility to exactly one of the three power sources such that no two resonating facilities share a source. The input includes resonance networks structured with cascading dependencies. In these arrangements, the resonance pairs are organized so that the validity of early power source assignments is heavily constrained by, and only confirmed after, the assignments of many subsequent facilities in the sequence.

Your objective is to determine whether a stable configuration exists for all facilities, and if so, to find the optimal valid connection layout.

## Input
The first line contains two integers — the number of facilities and the number of resonating facility pairs.
Each of the following lines contains two integers, representing a pair of facilities that exhibit harmonic resonance with each other.

## Output
If no stable configuration is possible, print a single line containing `NO`.
If a stable configuration is possible, print `YES` on the first line. On the second line, print a sequence of integers (each chosen from {1, 2, 3}), where the $i$-th integer is the source code assigned to facility $i$.
If multiple stable configurations exist, you must resolve ties by preferring the configuration that assigns the lowest possible source code to facility 1; if still tied, prefer the lowest possible source code for facility 2, and continue this tie-breaking process sequentially up to the last facility.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

Removed the explicit $1 \le n \le 40$ bounds and replaced them with a derived bound based on the number of power sources ($3^3 + 13 = 40$). Added a mechanical description of the input structures that feature deep cascading dependencies, which forces models to recognize that naive sequential assignment will encounter deep search trees and thus requires more sophisticated pruning, rather than relying on the small maximum $n$ to justify naive exhaustive search.
</RATIONALE>
