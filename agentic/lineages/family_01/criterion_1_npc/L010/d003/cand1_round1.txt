# Problem A — Harmonic Resonance Mitigation

Time limit: 2 s
Memory limit: 256 MB

A central control system coordinates three independent power networks, identified by the integer codes 1, 2, and 3. The infrastructure supplies $n$ industrial facilities, labeled from 1 to $n$. Because of harmonic resonance, specific pairs of facilities will trigger severe voltage fluctuations if they draw power from the exact same network. To maintain safe operations, every facility must be allocated to exactly one of the three networks in such a way that no two resonating facilities share a network.

Your goal is to determine if a completely stable allocation is achievable for all $n$ facilities, and to output the preferred valid layout if it is. Note that the evaluation suite includes maximum-capacity layouts specifically structured so that sequential evaluation encounters many incomplete allocations that remain conflict-free until the final facilities are considered. Your approach must be capable of resolving these highly intertwined configurations within the time limit.

## Input
The first line provides two integers $n$ and $m$ — the total number of facilities and the number of resonating pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$, indicating a pair of facilities that exhibit harmonic resonance with one another.

## Output
If a stable allocation is impossible, output a single line containing `NO`.
If a stable allocation is achievable, output `YES` on the first line. On the second line, output $n$ integers $g_1, g_2, \dots, g_n$ (each being 1, 2, or 3), where $g_i$ represents the network code assigned to facility $i$.
If there is more than one stable allocation, you must break ties by selecting the allocation that assigns the lowest possible network code to facility 1. If a tie remains, select the lowest possible network code for facility 2, and proceed with this sequential tie-breaking rule up to facility $n$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
