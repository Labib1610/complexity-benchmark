<STATEMENT>
# Problem A — Resonant Loop Prevention

Time limit: 2 s
Memory limit: 256 MB

You are configuring a system of $n$ signal relays, numbered 1 to $n$. Each relay must be assigned a frequency multiplier chosen from the values 1, 2, and 3. This configuration is expressed as a sequence $f_1, f_2, \dots, f_n$.

You are provided with a list of $m$ pairs of relays that are in physical proximity. Proximity is a symmetric relationship. 

When two relays $u$ and $v$ are in physical proximity, their combined signal is characterized by the interference polynomial in terms of a variable $x$:
$$P(x) = x^3 - (f_u + f_v)x^2 + (f_u \cdot f_v)x$$

The link between relay $u$ and relay $v$ is perfectly stable if and only if this polynomial has exactly three distinct real roots. The entire system is perfectly stable if and only if the links between all pairs of proximate relays are perfectly stable.

Your task is to determine if there exists a valid sequence of multipliers such that the system is perfectly stable. If such a sequence exists, you must output it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that relay $u$ and relay $v$ are in physical proximity.

## Output
If there is no valid sequence of multipliers that makes the system stable, print a single line containing `NO`.
If at least one such sequence exists, print `YES` on the first line. On the second line, print the $n$ integers $f_1, f_2, \dots, f_n$ representing the multipliers assigned to the relays. 
If there are multiple valid sequences, you must output the one that is lexicographically smallest. (A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index $i$ where they differ, $A_i < B_i$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit matrix multiplication condition (which models easily recognized as a standard graph coloring adjacency constraint) with a characteristic interference polynomial for each pair of proximate relays. The polynomial $P(x) = x^3 - (f_u + f_v)x^2 + (f_u f_v)x$ factors to $x(x - f_u)(x - f_v)$, so requiring three distinct real roots is mathematically equivalent to requiring $f_u \neq f_v$. This forces models to perform symbolic algebraic reasoning to simplify the condition; failure to do so will lead them to implement numerical root-finding inside their search loop, which will likely TLE.
</RATIONALE>
<PRESERVED_ANSWER>
The polynomial has roots $0$, $f_u$, and $f_v$, which are distinct if and only if $f_u \neq f_v$ (since multipliers are chosen from $\{1,2,3\}$), maintaining the exact same pairwise inequality constraint and thus identical solutions.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically first valid 3-coloring of a graph, preserving its NP-completeness.
</PRESERVED_CLASS>
<RISK>
Models might attempt to use floating-point root finders and fail due to precision issues, testing their implementation choices rather than algorithmic logic, though a reasoning model will bypass this by factoring.
</RISK>
