<STATEMENT>
# Problem A — Resonant Loop Prevention

Time limit: 2 s
Memory limit: 256 MB

You are configuring a system of $n$ signal relays, numbered 1 to $n$. Each relay must be assigned a frequency multiplier. The available multipliers are the integers 1, 2, and 3. This configuration is expressed as a sequence $f_1, f_2, \dots, f_n$.

You are provided with a list of $m$ pairs of relays that are in physical proximity. For any pair of relays $u$ and $v$ in proximity, they will create a destructive resonant loop if the definite integral of the signal function $g(t) = e^t$ with respect to $t$, evaluated from a lower limit of $f_u$ to an upper limit of $f_v$, is exactly equal to zero. 

Your task is to determine if there exists a valid sequence of multipliers such that absolutely no resonant loops are created among any of the given proximity pairs. If such a sequence exists, you must output it.

If there are multiple valid sequences, you must output the sequence $f_1, f_2, \dots, f_n$ that strictly minimizes the system's baseline footprint, defined mathematically by the sum:
$W = \sum_{i=1}^n f_i \cdot 10^{n-i}$

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that relay $u$ and relay $v$ are in physical proximity.

## Output
If there is no valid sequence of multipliers that avoids all resonant loops, print a single line containing `NO`.
If at least one such sequence exists, print `YES` on the first line. On the second line, print the $n$ integers $f_1, f_2, \dots, f_n$ representing the multipliers assigned to the relays. 

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The modular arithmetic constraint was replaced with a definite integral of $e^t$, which evaluates to zero if and only if the upper and lower limits are identical. The explicit "lexicographically smallest" tie-breaker was replaced with an equivalent mathematical objective function that treats the sequence as base-10 digits. This removes all standard graph-coloring vocabulary, forcing models to deduce both the equality constraint and the search-order optimization from mathematical first principles.
</RATIONALE>
<PRESERVED_ANSWER>
The integral evaluates to exactly zero iff $f_u = f_v$, which perfectly matches the original modular constraint; minimizing the base-10 sum $W$ is strictly equivalent to finding the lexicographically smallest sequence since the digits are bounded to $\{1, 2, 3\}$.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Graph 3-Coloring, as the domain is still 3 values and the forbidden condition on edges is still strict equality.
</PRESERVED_CLASS>
<RISK>

</RISK>
