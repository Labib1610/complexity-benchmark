 We need to assign each node a value from {1, 2, 3} such that for every edge (u, v), the sum 2^s_u + 2^s_v is **not** a power of two.

Let’s check when 2^a + 2^b is a power of two:

- If a = b, then 2^a + 2^a = 2^(a+1), which is a power of two. So equal values are forbidden on an edge.
- If a ≠ b, then 2^a + 2^b = 2^min(a,b) * (1 + 2^|a-b|).  
  For this to be a power of two, the factor (1 + 2^|a-b|) must be a power of two.  
  The only possibility is |a-b| = 1, because 1 + 2^1 = 3 (not power of two), 1 + 2^2 = 5 (not), etc.  
  Actually, 1 + 2^k is a power of two only if k = 0, but that’s the equal case.  
  So for a ≠ b, it’s never a power of two.

Thus the only forbidden case is when two connected nodes have the same value.

So the problem reduces to:  
Can we 3-color the graph such that no two adjacent nodes have the same color?  
We need the lexicographically smallest assignment (in base-4 with digits 1,2,3) that is a valid 3-coloring.

Since n ≤ 40, we can use backtracking with pruning.

We’ll try assigning values 1, 2, 3 in order for each node, checking constraints with already assigned neighbors.

If we find a valid assignment, we output it. If none, output NO.

Here’s the implementation:

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n

def dfs(idx):
    if idx == n:
        return True
    for c in (1, 2, 3):
        ok = True
        for nb in adj[idx]:
            if color[nb] == c:
                ok = False
                break
        if ok:
            color[idx] = c
            if dfs(idx + 1):
                return True
            color[idx] = 0
    return False

if dfs(0):
    print("YES")
    print(" ".join(map(str, color)))
else:
    print("NO")
```
