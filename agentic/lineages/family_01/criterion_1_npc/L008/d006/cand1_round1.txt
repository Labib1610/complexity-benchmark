<STATEMENT>
# Problem A — Oscillator Tuning

Time limit: 2 s   Memory limit: 256 MB

A control system consists of $n$ precision oscillators. Each oscillator requires a frequency multiplier to operate correctly. You must assign each oscillator a multiplier chosen from the set $\{1, 2, 3\}$.

Within the system, certain pairs of oscillators are connected by coupling links. If oscillators $u$ and $v$ are linked, and they are assigned multipliers $s_u$ and $s_v$ respectively, their interaction generates a resonance signature $R = 2^{s_u} + 2^{s_v}$. 

To ensure system stability, this signature must not be a perfect power of 2 (i.e., there must be no integer $k$ such that $R = 2^k$). If any linked pair produces a resonance signature that evaluates to a power of 2, the system undergoes resonance collapse and fails. 

You must determine whether a stable configuration of multipliers exists for the given system.

## Input
The first line provides two integers $n$ and $m$ — the total number of oscillators and the number of coupling links ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), signifying that oscillator $u$ and oscillator $v$ are linked. It is guaranteed that each unordered pair of linked oscillators appears at most once in the input.

## Output
If there is no way to configure the multipliers without inducing resonance collapse, output a single line containing `NO`.
If a stable configuration is achievable, output `YES` on the first line. On the second line, provide $n$ integers $s_1 s_2 \dots s_n$ ($s_i \in \{1, 2, 3\}$), where $s_i$ represents the multiplier assigned to oscillator $i$. If multiple stable configurations exist, you must output the one that minimizes the structural signature $S = \sum_{i=1}^n s_i \cdot 4^{n-i}$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<METHOD_NAME>Semantic Disconnect via Exponentiation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaced the trivially factorable quadratic equation with an exponential sum condition (2^{s_u} + 2^{s_v} != 2^k). This defeats models that rely on surface pattern matching of polynomials to instantly recognize the s_u != s_v constraint, forcing them to genuinely evaluate the new mathematical predicate.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<RATIONALE>
The previous version used a characteristic equation that trivially factored into (t - s_u)(t - s_v) = 0, allowing models to instantly recognize the distinct roots requirement as s_u != s_v. I removed this affordance by replacing it with a genuinely different predicate involving powers of 2, which evaluates to the exact same constraint but cannot be solved by simple polynomial factorization.
</RATIONALE>
<PRESERVED_ANSWER>
The condition 2^{s_u} + 2^{s_v} != 2^k is violated if and only if s_u = s_v (since 2^x + 2^x = 2^{x+1}), meaning the set of valid multiplier assignments remains exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 3-coloring of a graph, preserving its NP-complete status.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "perfect power of 2", but the explicit clarification "(i.e., there must be no integer k such that R = 2^k)" removes any ambiguity.
</RISK>
