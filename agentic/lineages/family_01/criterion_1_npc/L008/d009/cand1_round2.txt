The summand is a polynomial modulo 3 that evaluates to 1 if the endpoints differ and 0 if they are the same. By requiring the global sum to equal the number of edges, the model is forced to either mathematically deduce that the summand is bounded by 1 (thus factoring it back into local pruning conditions) or write a naive unpruned backtracking search that evaluates the condition globally, which will inevitably Time Limit Exceed on the 3^40 search space.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Oscillator Tuning

Time limit: 2 s   Memory limit: 256 MB

A control system consists of $n$ precision oscillators, numbered $1$ through $n$. Each oscillator requires a frequency multiplier to operate correctly. You must assign each oscillator a multiplier chosen from the set $\{1, 2, 3\}$.

Within the system, certain pairs of oscillators are connected by coupling links. When oscillator $u$ and oscillator $v$ are linked, their interaction generates a continuous bidirectional pulse. The stability of the entire system is evaluated globally by calculating its total stability index $G$. 

For any single link between oscillator $u$ and oscillator $v$, its individual phase value $P_{u,v}$ is determined by their assigned multipliers $s_u$ and $s_v$, and is calculated as:
$$P_{u,v} = (s_u^2 + s_u s_v + s_v^2) \bmod 3$$

The global stability index $G$ is the standard integer sum of the phase values of all $m$ coupling links in the system. To ensure system stability, this total global stability index must be exactly equal to $m$ ($G = m$). If $G \neq m$, the system undergoes resonance collapse and the entire system fails.

You must determine whether a stable configuration of multipliers exists for the given system.

## Input
The first line provides two integers $n$ and $m$ — the total number of oscillators and the number of coupling links ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), signifying that oscillator $u$ and oscillator $v$ are linked. It is guaranteed that each unordered pair of linked oscillators appears at most once in the input.

## Output
If there is no way to configure the multipliers without inducing resonance collapse, output a single line containing `NO`.
If a stable configuration is achievable, output `YES` on the first line. On the second line, provide $n$ integers $s_1 s_2 \dots s_n$ ($s_i \in \{1, 2, 3\}$), where $s_i$ represents the multiplier assigned to oscillator $i$. 

If multiple stable configurations exist, you must output the one that minimizes the final system signature $V_n$. This signature is computed sequentially: starting with an initial value $V_0 = 0$, for each oscillator $i$ from $1$ to $n$ in order, the signature updates according to the rule $V_i = 4 \cdot V_{i-1} + s_i$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The explicit local pairwise failure condition was removed. Instead, the validity of the graph is framed as a global sum of a polynomial evaluated over all edges. To pass within the time limit, the model must deduce that the polynomial $(s_u^2 + s_u s_v + s_v^2) \bmod 3$ is bounded by 1, and therefore the sum equals $m$ if and only if every local edge evaluates to 1, factoring the global condition back into a local pruning constraint.
</RATIONALE>
<PRESERVED_ANSWER>
For $s_u, s_v \in \{1, 2, 3\}$, the expression $(s_u^2 + s_u s_v + s_v^2) \bmod 3$ evaluates to 0 if $s_u = s_v$ and 1 if $s_u \neq s_v$; thus the sum over $m$ edges equals $m$ if and only if $s_u \neq s_v$ for all edges, preserving the exact same valid configurations.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The valid configurations remain precisely the valid 3-colorings of the graph, keeping the problem in NP-complete.
</PRESERVED_CLASS>
