Semantic Inversion of Tie-Breaker + Adversarial Decoy
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaced the explicit "lexicographically smallest" requirement with a mathematically equivalent but structurally disguised tie-breaker: minimizing the concatenated n-digit base-10 integer. Combined this with a strong decoy warning that naive 1-to-n sequential evaluation will encounter massive dead-ends and exceed the time limit. This tempts models to abandon the mandatory 1-to-n search order in favor of dynamic variable ordering (like Minimum Remaining Values), which breaks the tie-breaker requirement and leads to a Wrong Answer. Alternatively, models writing in C++ that attempt to evaluate the tie-breaker explicitly will overflow 64-bit integers on n=40 and fail.
</METHOD_DESCRIPTION>

yes
</METHOD_NOVEL>
<STATEMENT>
# Problem A — Quantum State Alignment

Time limit: 2 s   Memory limit: 256 MB

A quantum computing facility is preparing $n$ entangled qubits for a complex computation. Before initialization, each qubit must be stabilized by assigning it exactly one of three fundamental spin states, denoted by the integers 1, 2, and 3.

Within the quantum register, certain pairs of qubits are physically adjacent and subject to strong interference. If any two adjacent qubits are assigned the identical spin state, their combined resonance will cause a decoherence cascade, destroying the quantum information and rendering the entire system useless. Therefore, no two adjacent qubits can share the same spin state.

The facility's verification system tests your algorithm against highly adversarial configurations on the full 40 qubits. These layouts are deliberately constructed with permuted qubit identifiers and dense interference patterns. They are engineered specifically to trap algorithms that blindly assign states in the naive 1-to-$n$ numerical sequence, causing them to explore an astronomical number of nearly complete but invalid state prefixes before detecting a failure. To succeed within the time limit, your search logic cannot rely solely on simple fixed-order trial and error; it must actively prune the search space by immediately detecting when a partial configuration cannot possibly be completed.

You must determine whether a stable state assignment exists for the given quantum register.

## Input
The first line contains two integers $n$ and $m$ — the number of qubits and the number of adjacent pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that qubit $u$ and qubit $v$ are adjacent and subject to interference.

## Output
If there is no way to assign the spin states without causing a decoherence cascade, output a single line containing `NO`.
If a stable assignment is possible, output `YES` on the first line. On the second line, output $n$ integers $s_1 s_2 \dots s_n$ ($s_i \in \{1, 2, 3\}$), where $s_i$ is the spin state assigned to qubit $i$.
If multiple stable assignments are possible, evaluate each valid sequence $s_1, s_2, \dots, s_n$ by concatenating its digits into a single $n$-digit base-10 integer. You must output the sequence that produces the smallest possible integer value.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit "lexicographically smallest" tie-breaker was rewritten as minimizing the concatenated n-digit integer. This obscures the fact that a strict 1-to-n search order naturally satisfies the tie-breaker. By adding a strong warning that naive 1-to-n sequential search will explore dead-ends and fail, models are heavily incentivized to use dynamic variable ordering (like MRV) to avoid a Time Limit Exceeded. However, MRV does not guarantee finding the smallest integer solution first, forcing a Wrong Answer. Genuine algorithmic reasoners will recognize that minimizing the integer is equivalent to lexicographical order, meaning they *must* maintain the 1-to-n search order and rely on forward-checking for pruning instead of changing the evaluation sequence.
</RATIONALE>
<PRESERVED_ANSWER>
Because the allowed states are strictly from {1, 2, 3}, concatenating the sequence into an n-digit base-10 integer creates no leading zeros, and minimizing this integer's value is mathematically identical to finding the lexicographically smallest sequence.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Coloring on a general graph with a lexicographical tie-breaker, preserving its NP-complete status.
</PRESERVED_CLASS>
<RISK>
Models might output the result as a single concatenated string rather than space-separated integers, though the output instructions explicitly specify "output n integers s1 s2 ... sn".
</RISK>
