# Problem A — Assembly Tolerances

Time limit: 2 s   Memory limit: 256 MB

A complex mechanical device is manufactured from $n$ machined parts. Before the device can be assembled, every part must be coated with one of three chemical sealants, labeled 1, 2, and 3. 

Certain pairs of parts are designed to interlock flush against each other. If two interlocking components are coated with the same sealant, a chemical cross-linking reaction will permanently fuse them, ruining the device. Therefore, strictly distinct sealants must be applied to any two parts that share an interlocking connection.

These requirements create a highly constrained three-state compatibility system. The test data includes adversarial configurations deliberately constructed to defeat naive fixed-order exhaustive search. To find a valid assignment—or to prove that none is possible—within the time limit, your approach will require aggressive state propagation, dynamic branching heuristics, or equivalent pruning techniques.

Given the number of parts and the list of all interlocking connections, determine if a safe sealant configuration is possible.

## Input
The first line provides two integers $n$ and $m$ — the total number of machined parts and the number of interlocking connections ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that part $u$ and part $v$ interlock.

## Output
If no safe sealant configuration is possible, print a single line containing NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1 s_2 \dots s_n$ (where each $s_i \in \{1, 2, 3\}$), representing the sealant applied to part $i$. If there are multiple valid configurations, you must output the lexicographically smallest sequence (comparing $s_1$ first, then $s_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
