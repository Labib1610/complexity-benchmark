# Problem A — Oscillator Tuning

Time limit: 2 s   Memory limit: 256 MB

A control system consists of $n$ precision oscillators, numbered $1$ through $n$. Each oscillator requires a frequency multiplier to operate correctly. You must assign each oscillator a multiplier chosen from the set $\{1, 2, 3\}$.

Within the system, certain pairs of oscillators are connected by coupling links. For a link between oscillator $u$ and oscillator $v$, their interaction is governed by the $3 \times 3$ characteristic matrix:

$$
C_{u, v} = \begin{pmatrix} 
s_u & s_v & s_u^2 + u + v + 10 \\ 
1 & 1 & s_v \\ 
s_v & s_u & s_u s_v 
\end{pmatrix}
$$

where $s_u$ and $s_v$ are their assigned multipliers. 

To ensure system stability, the characteristic matrix of every coupling link must be non-singular (i.e., its determinant must be non-zero). If any linked pair produces a singular matrix, the link undergoes resonance collapse and the entire system fails. 

You must determine whether a stable configuration of multipliers exists for the given system.

## Input
The first line provides two integers $n$ and $m$ — the total number of oscillators and the number of coupling links ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), signifying that a coupling link connects oscillator $u$ and oscillator $v$. It is guaranteed that each unordered pair of linked oscillators appears at most once in the input.

## Output
If there is no way to configure the multipliers without inducing resonance collapse, output a single line containing `NO`.
If a stable configuration is achievable, output `YES` on the first line. On the second line, provide $n$ integers $s_1 s_2 \dots s_n$ ($s_i \in \{1, 2, 3\}$), where $s_i$ represents the multiplier assigned to oscillator $i$. 

If multiple stable configurations exist, you must output the one that minimizes the final system signature $V_n$. This signature is computed sequentially: starting with an initial value $V_0 = 0$, for each oscillator $i$ from $1$ to $n$ in order, the signature updates according to the rule $V_i = 4 \cdot V_{i-1} + s_i$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
Changed the characteristic matrix to an asymmetric version whose determinant evaluates to `(s_u - s_v)(s_u^2 - s_v^2 + u + v + 10)`. By injecting the node indices `u` and `v` into the matrix, models can no longer precompute a simple 3x3 compatibility table of allowed colors. Furthermore, the explicit note about symmetry was removed. This forces models to either perform correct algebraic bounding (realizing the second factor is strictly positive) or embed the full determinant evaluation into their backtracking loop, significantly increasing the likelihood of TLE or logic errors.
</RATIONALE>
<PRESERVED_ANSWER>
The determinant of the new matrix evaluates to zero if and only if $s_u = s_v$, perfectly preserving the valid configurations and their tie-breaking order.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains identically equivalent to proper 3-coloring, keeping it NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might wonder if evaluating $C_{u,v}$ versus $C_{v,u}$ yields different stability requirements, but since both matrices are singular if and only if $s_u = s_v$, any interpretation leads to the exact same constraint.
</RISK>
