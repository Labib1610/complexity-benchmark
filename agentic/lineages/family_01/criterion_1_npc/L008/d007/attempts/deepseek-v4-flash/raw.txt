We can model this as a graph coloring problem with 3 colors (multipliers 1, 2, 3).  
The condition for a link \((u, v)\) is:

\[
s_u \cdot v + s_v \cdot u \neq s_v \cdot v + s_u \cdot u
\]

Simplifying:

\[
s_u(v - u) \neq s_v(v - u)
\]

If \(u \neq v\), this reduces to:

\[
s_u \neq s_v
\]

So each connected pair must have different multipliers.  
Thus, the problem is: can we 3-color the graph such that adjacent nodes have different colors, and among all valid colorings, pick the one with the smallest base-4 number formed by the sequence of colors.

Since \(n \leq 40\), we can use backtracking with pruning, trying colors in increasing order to get the lexicographically smallest signature.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    colors = [0] * n
    found = False

    def backtrack(idx):
        nonlocal found
        if idx == n:
            found = True
            return True
        for c in (1, 2, 3):
            ok = True
            for nb in adj[idx]:
                if colors[nb] == c:
                    ok = False
                    break
            if ok:
                colors[idx] = c
                if backtrack(idx + 1):
                    return True
                colors[idx] = 0
        return False

    if not backtrack(0):
        print("NO")
    else:
        print("YES")
        print(" ".join(map(str, colors)))

if __name__ == "__main__":
    solve()
```
