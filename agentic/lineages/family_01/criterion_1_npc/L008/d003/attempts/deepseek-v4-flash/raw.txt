 We can solve this by checking if the graph is 3-colorable.  
Since \( n \leq 40 \), we can use backtracking with pruning to assign colors 1, 2, or 3 to each vertex, ensuring adjacent vertices have different colors. We also want the lexicographically smallest coloring, so we try colors in order.

Here’s the Python solution:

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

colors = [0] * n

def is_safe(v, c):
    for u in adj[v]:
        if colors[u] == c:
            return False
    return True

def solve(v):
    if v == n:
        return True
    for c in range(1, 4):
        if is_safe(v, c):
            colors[v] = c
            if solve(v + 1):
                return True
            colors[v] = 0
    return False

if solve(0):
    print("YES")
    print(" ".join(map(str, colors)))
else:
    print("NO")
```
