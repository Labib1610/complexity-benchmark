<STATEMENT>
# Problem A — Assembly Tolerances

Time limit: 2 s   Memory limit: 256 MB

A specialized manufacturing facility produces a complex device comprising $n$ machined components. Prior to final assembly, every single component must be coated with one of three distinct chemical sealants. These sealants are identified by the numeric codes 1, 2, and 3.

Due to the extreme precision of the manufacturing tolerances, specific pairs of components will sit flush against each other within the assembled device. If any two interlocking components receive the exact same sealant, their identical chemical properties will trigger a cross-linking reaction. This reaction permanently fuses the components together, which ruins the internal mechanics of the device. To prevent this critical failure, any two components that interlock must never share the same sealant.

The blueprints you will evaluate are heavily intertwined. Many configurations are arranged so that cross-linking reactions only become inevitable after the vast majority of components have been assigned a sealant, meaning conflicts will often emerge deep into the assignment process.

Given the total number of components and the comprehensive list of interlocking pairs, determine if a safe sealant assignment exists for the entire device.

## Input
The first line contains two integers $n$ and $m$. The value $n$ represents the number of machined components. The facility processes components in batches that correspond to the 40 testing slots available on the assembly line, ensuring $n$ is at least 1 and at most a full batch. The value $m$ represents the number of interlocking pairs, ranging from 0 up to the maximum possible number of pairs (which would occur if every component interlocked with all others).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) indicating that component $u$ and component $v$ interlock.

## Output
If it is impossible to assign sealants without causing a fusion reaction, print a single line containing `NO`.
If a safe assignment is possible, print `YES` on the first line. On the second line, print $n$ integers $s_1 s_2 \dots s_n$ (where each $s_i \in \{1, 2, 3\}$), with $s_i$ being the sealant code for component $i$. Among all safe assignments, output the lexicographically smallest sequence (compare $s_1$ first, then $s_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
Replaced the direct mathematical inequality bounds with scenario-based constraints (40 testing slots, full batch) to require the model to extract the bounds from the text. Added a structural note about the intertwined nature of the configurations to warn against naive sequential assignment, forcing the model to consider search optimization without explicitly naming algorithmic concepts.
</RATIONALE>
<PRESERVED_ANSWER>
The requirements for valid sealant assignments and the lexicographical tie-breaking rule remain identical, ensuring the exact same output for any given input.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 3-coloring of a graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "maximum possible number of pairs" as a strict complete graph requirement rather than an upper bound on $m$, though "ranging from 0 up to" should clarify it's a bound.
</RISK>
