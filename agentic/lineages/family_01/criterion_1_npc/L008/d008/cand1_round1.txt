<STATEMENT>
# Problem A — Oscillator Tuning

Time limit: 2 s   Memory limit: 256 MB

A control system consists of $n$ precision oscillators, numbered $1$ through $n$. Each oscillator requires a frequency multiplier to operate correctly. You must assign each oscillator a multiplier chosen from the set $\{1, 2, 3\}$.

Each oscillator $i$, once assigned its multiplier $s_i$, emits a 3D polarization vector defined as $\mathbf{p}_i = (i, i \cdot s_i, i \cdot s_i^2)$.

Within the system, certain pairs of oscillators are connected by coupling links. When oscillator $u$ and oscillator $v$ are linked, their vectors interact. The stability of this link depends on the cross product of their polarization vectors, $\mathbf{p}_u \times \mathbf{p}_v$. If this cross product evaluates to the zero vector $(0, 0, 0)$, the link undergoes resonance collapse and the entire system fails. For the system to be stable, every coupling link must produce a non-zero cross product.

You must determine whether a stable configuration of multipliers exists for the given system.

## Input
The first line provides two integers $n$ and $m$ — the total number of oscillators and the number of coupling links ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), signifying that oscillator $u$ and oscillator $v$ are linked. It is guaranteed that each unordered pair of linked oscillators appears at most once in the input.

## Output
If there is no way to configure the multipliers without inducing resonance collapse, output a single line containing `NO`.
If a stable configuration is achievable, output `YES` on the first line. On the second line, provide $n$ integers $s_1 s_2 \dots s_n$ ($s_i \in \{1, 2, 3\}$), where $s_i$ represents the multiplier assigned to oscillator $i$. 

If multiple stable configurations exist, you must output the one that minimizes the system's residual energy. The residual energy is defined exactly by the rational value $R = \sum_{j=1}^n \frac{s_j}{4^j}$. (Note: This is a mathematical exact value, not a floating-point approximation).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The edge stability condition was changed to a 3D vector cross product requirement ($\mathbf{p}_u \times \mathbf{p}_v \neq \mathbf{0}$). Because the vectors are structured as scaled Vandermonde rows, their cross product is zero if and only if $s_u = s_v$. This forces the model to either algebraically expand the cross product to discover the graph-coloring constraint or natively simulate it. The tie-breaker was converted to an infinite-precision rational series sum to penalize naive float-based translation and reward exactly recognizing the lexicographical DFS structure.
</RATIONALE>
<PRESERVED_ANSWER>

</PRESERVED_ANSWER>
