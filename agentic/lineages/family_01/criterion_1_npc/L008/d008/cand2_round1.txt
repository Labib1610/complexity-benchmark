<METHOD_NAME>Global Sum of Non-Trivial Modulo</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the local inequality constraint with a global sum constraint: the sum over all edges of (s_u^2 + s_v^2) % (s_u * s_v) must equal the number of edges m. For the domain {1,2,3}, this term evaluates to 1 if s_u != s_v, and 0 if s_u == s_v. A pattern-matching model will likely implement this as a global sum check or fail to deduce the maximum term value is 1, thus failing to prune early when a term evaluates to 0, leading to a Time Limit Exceeded on n=40.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Oscillator Tuning

Time limit: 2 s   Memory limit: 256 MB

A control system consists of a strictly positive number of precision oscillators, $n$, numbered $1$ through $n$. The system's maximum capacity is designed such that the total number of unordered pairs of distinct oscillators cannot exceed 780. 

Each oscillator $i$ requires a frequency multiplier $s_i$ to operate correctly. These multipliers are strictly positive integers. To prevent hardware overflow, the factorial of any chosen multiplier must be strictly less than 10.

Within the system, there are $m$ coupling links between certain pairs of oscillators. The number of links $m$ can be any non-negative integer up to the theoretical maximum for $n$ oscillators. When oscillator $u$ and oscillator $v$ are linked, their interaction generates a stability factor $F_{u,v}$. This factor is calculated by taking the sum of the squares of their multipliers, and finding the remainder when divided by the product of their multipliers. Mathematically, $F_{u,v} = (s_u^2 + s_v^2) \pmod{s_u \cdot s_v}$.

To ensure system stability, the total sum of the stability factors across all $m$ coupling links must be exactly equal to $m$. If the sum deviates from $m$, the system undergoes resonance collapse and fails.

You must determine whether a stable configuration of multipliers exists for the given system.

## Input
The first line provides two integers $n$ and $m$ — the total number of oscillators and the number of coupling links.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), signifying that oscillator $u$ and oscillator $v$ are linked. It is guaranteed that each unordered pair of linked oscillators appears at most once in the input.

## Output
If there is no way to configure the multipliers without inducing resonance collapse, output a single line containing `NO`.
If a stable configuration is achievable, output `YES` on the first line. On the second line, provide $n$ integers $s_1 s_2 \dots s_n$, where $s_i$ represents the multiplier assigned to oscillator $i$. 

If multiple stable configurations exist, you must output the one that minimizes the final system signature $V_n$. This signature is computed sequentially: starting with an initial value $V_0 = 0$, for each oscillator $i$ from $1$ to $n$ in ascending order, the signature updates according to the rule $V_i = 4 \cdot V_{i-1} + s_i$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
Converted the direct edge inequality `s_u != s_v` into a global sum constraint where the sum of `(s_u^2 + s_v^2) % (s_u * s_v)` over all links must equal `m`. Also applied S07 by hiding the bounds `n <= 40` and `s_i in {1, 2, 3}` behind a maximum unordered pair count and a factorial limit. This forces the model to mathematically deduce that each term's maximum value is 1 in order to implement the early pruning necessary to pass within the time limit.
</RATIONALE>
<PRESERVED_ANSWER>
For any linked pair from the set {1, 2, 3}, the term `(s_u^2 + s_v^2) % (s_u * s_v)` evaluates to exactly 1 if `s_u != s_v` and 0 if `s_u == s_v`, meaning the sum over `m` links equals `m` if and only if every link satisfies `s_u != s_v`, preserving the exact same valid configurations.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest 3-coloring of a graph, keeping it in NP-Complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the modulo operation if they assume floating-point division, but the phrase "finding the remainder when divided by" strictly implies integer arithmetic.
</RISK>
