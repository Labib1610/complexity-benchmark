We can simplify the condition:  

The quadratic  
\[
z^2 - (C[u] + C[v])z + C[u]C[v] = 0
\]  
factors as  
\[
(z - C[u])(z - C[v]) = 0
\]  
So its roots are exactly \(C[u]\) and \(C[v]\).  

For the equation to have **exactly two distinct real roots**, we need  
\[
C[u] \neq C[v]
\]  

Thus, each condition \((u, v)\) means:  
**C[u] and C[v] must be different.**  

So the problem reduces to:  
We have \(n\) variables, each can be 1, 2, or 3, and we have constraints that certain pairs must be different. This is a graph coloring problem with 3 colors. Since \(n \le 40\), we can use backtracking with pruning.

We can solve it with DFS assigning colors and checking constraints.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n  # 0 = uncolored, 1,2,3 = colors
    
    def dfs(node):
        if node == n:
            return True
        for c in (1, 2, 3):
            ok = True
            for nb in adj[node]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[node] = c
                if dfs(node + 1):
                    return True
                color[node] = 0
        return False
    
    if dfs(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
