# Emitter Network Stability

Time limit: 2 s   Memory limit: 256 MB

You are configuring a network of $n$ signal emitters. Each emitter $i$ must be assigned a discrete power level $P[i]$ chosen from the set $\{1, 2, 3\}$.

The network contains $m$ critical interference links, each connecting a pair of emitters $u$ and $v$. When two emitters are linked, their combined signal is governed by the characteristic polynomial:
$R(x) = x^2 - (P[u] + P[v])x + P[u]P[v]$

For the link to remain stable, the equation $R(x) = 0$ must yield two distinct real roots. If the roots are identical, the link will experience resonant collapse.

Your task is to determine whether there exists an assignment of power levels to all $n$ emitters such that every critical link in the network is stable.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). 
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating a critical interference link between emitter $u$ and emitter $v$. 

## Output
If no such assignment is possible, output `NO` on a single line.
If a valid assignment exists, output `YES` on the first line. On the second line, output $n$ integers representing the valid power levels $P[1], P[2], \dots, P[n]$. If there are multiple valid assignments, any of them will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
