We can model this as a graph coloring problem.  
Each element can be 1, 2, or 3.  
The condition says:

- If both are 1: gcd(1!,1!) = 1, max = 1 → 1 < 1 is false → invalid.
- If one is 1 and other is 2: gcd(1,2)=1, max=2 → 1<2 true → valid.
- If one is 1 and other is 3: gcd(1,6)=1, max=3 → valid.
- If both are 2: gcd(2,2)=2, max=2 → 2<2 false → invalid.
- If 2 and 3: gcd(2,6)=2, max=3 → 2<3 true → valid.
- If both are 3: gcd(6,6)=6, max=3 → 6<3 false → invalid.

So the only invalid pairs are (1,1), (2,2), (3,3).  
That means: for every condition (u,v), we must have C[u] != C[v].  

So the problem reduces to: can we color the graph with 3 colors such that no edge connects two vertices of the same color?  
That’s exactly the 3-coloring problem, which is NP-complete in general, but n ≤ 40, so we can use backtracking with pruning.

We’ll implement a backtracking search with constraint propagation.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    
    # Sort vertices by degree for better pruning
    order = sorted(range(n), key=lambda x: len(adj[x]), reverse=True)
    
    def backtrack(idx):
        if idx == n:
            return True
        v = order[idx]
        used = [False] * 4
        for nei in adj[v]:
            if color[nei] != -1:
                used[color[nei]] = True
        for c in range(1, 4):
            if not used[c]:
                color[v] = c
                if backtrack(idx + 1):
                    return True
                color[v] = -1
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(str(color[i]) for i in range(n)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
