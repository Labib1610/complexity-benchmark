<STATEMENT>
# Harmonic Containment

Time limit: 2 s   Memory limit: 256 MB

A grid of $n$ experimental energy cores requires calibration. Each core must be locked into one of three distinct operational frequencies, labeled 1, 2, and 3.

During preliminary testing, an automated diagnostics system generated a list of $m$ critical interference pairs. Each record indicates two specific cores that will trigger a catastrophic cascade if they are locked into the exact same frequency. To ensure containment, any two cores involved in a recorded interference pair must operate on strictly different frequencies.

The logs are generated by a stress-testing framework that produces interlocking interference topologies. These configurations are engineered to maximize the number of dead-end states and deeply nested dependency chains, encompassing both strictly impossible configurations and those with highly constrained valid states. Bare trial-and-error evaluations without structural pruning will exhaust available time.

You must determine if a safe calibration state exists for the entire grid. If it is possible to lock all cores without triggering a cascade, you must provide one such valid frequency assignment.

## Input
The first line contains two integers $n$ and $m$, denoting the number of cores and the number of critical interference pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). 
Each of the subsequent $m$ lines provides two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing a pair of cores that interfere with one another. 

## Output
If no safe calibration state can be achieved, output a single line with the word NO.
If a valid state is possible, print YES on the first line. On the second line, provide $n$ space-separated integers $p_1, p_2, \dots, p_n$, where $p_i \in \{1, 2, 3\}$ is the frequency assigned to core $i$. If multiple valid states exist, any of them is acceptable.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
