<STATEMENT>
# Problem A — System Stabilization

Time limit: 2 s   Memory limit: 256 MB

A diagnostic system consists of $n$ processing modules. Each module must be assigned a configuration code chosen from $\{1, 2, 3\}$.

The system contains $m$ bidirectional monitoring links, each connecting a specific pair of modules. For a link connecting module $u$ and module $v$ to operate correctly, the square of the sum of their assigned codes must be strictly greater than four times their product. If the pair of codes fails to satisfy this condition, the link will transmit an error flag.

To achieve system stability, every module must be assigned a configuration code such that absolutely no error flags are transmitted across any link.

Determine whether a stable configuration exists. If it does, find the valid assignment of configuration codes that is lexicographically smallest when listed from module 1 to module $n$.

## Input
The first line provides two integers $n$ and $m$ — the number of modules and the number of monitoring links. 
The system is designed for a physical chassis with 40 module bays, meaning $n$ will be between 1 and the chassis capacity. The number of links $m$ can be anything from 0 up to the number of links required to connect every module to every other module directly.

Each of the subsequent $m$ lines contains two integers $u$ and $v$, specifying a monitoring link between module $u$ and module $v$.

## Output
If no stable configuration is possible, print a single line containing `NO`.
If a stable configuration exists, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each $s_i \in \{1, 2, 3\}$), representing the configuration code of each module $i$. If there are multiple stable configurations, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit list of six valid pairs with an algebraic protocol rule: $(c_u + c_v)^2 > 4 c_u c_v$. This is mathematically equivalent to $(c_u - c_v)^2 > 0$, meaning the two codes must be distinct, but it prevents models from instantly pattern-matching the task to graph 3-coloring. I also replaced the direct numeric bounds with scenario-based limits (a 40-bay chassis and a fully connected mesh network) to force the model to derive the capacities itself.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic condition $(c_u + c_v)^2 > 4 c_u c_v$ is satisfied if and only if $c_u \neq c_v$, which exactly matches the original requirement that connected modules have different configuration codes.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest valid 3-coloring of a graph, keeping it firmly NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the phrasing "number of links required to connect every module to every other module directly" as a requirement rather than an upper bound, though "can be anything from 0 up to" should make the range clear.
</RISK>
