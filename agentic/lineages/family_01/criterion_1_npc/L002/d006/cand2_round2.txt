# Sequence Configuration

Time limit: 2 s   Memory limit: 256 MB

You are tasked with generating an integer sequence $C$ of length $n$. Each element in the sequence must be chosen from the set $\{1, 2, 3\}$.

The sequence must satisfy a structural constraint defined by $m$ given pairs of 1-based indices. 
First, construct an $n \times n$ symmetric matrix $A$, initially filled with zeros. For each given pair of indices $(u, v)$, set $A_{u, v} = 1$ and $A_{v, u} = 1$.

Next, based on your sequence $C$, construct an $n \times 3$ indicator matrix $X$. For each row $i \in \{1, \dots, n\}$ and column $k \in \{1, 2, 3\}$, set $X_{i, k} = 1$ if $C[i] = k$, and $X_{i, k} = 0$ otherwise.

The sequence $C$ is considered valid if and only if the $3 \times 3$ matrix product $M = X^T A X$ has the property that every entry on its main diagonal is exactly zero. (Here, $X^T$ denotes the transpose of $X$).

Your objective is to determine if at least one such sequence $C$ can be constructed that satisfies this matrix condition.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). 
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing a pair of indices used to construct the matrix $A$. 

## Output
If no such sequence can be constructed, output `NO` on a single line.
If a valid sequence exists, output `YES` on the first line. On the second line, output $n$ integers representing the valid sequence $C[1], C[2], \dots, C[n]$. If there are multiple valid sequences, any of them will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

I replaced the local pairwise inequality constraint with a global matrix product equation that evaluates to exactly the same truth value. This forces models to prove the algebraic equivalence between the matrix diagonal being zero and the local constraint $C[u] \neq C[v]$; those that fail will write a naive global checker that times out on N=40.
</RATIONALE>
<PRESERVED_ANSWER>
The main diagonal entry $M_{k, k}$ of $X^T A X$ is exactly twice the number of pairs $(u, v)$ in the input where $C[u] = k$ and $C[v] = k$; thus, having only zeros on the diagonal is perfectly equivalent to $C[u] \neq C[v]$ for all given pairs, matching the seed exactly.
</PRESERVED_ANSWER>
