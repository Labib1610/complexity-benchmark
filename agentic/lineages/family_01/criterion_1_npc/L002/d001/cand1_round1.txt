# Problem A — Phase Containment

Time limit: 2 s   Memory limit: 256 MB

A laboratory is evaluating $n$ experimental energy cores. Each core must be tuned to exactly one frequency band, represented by the integers 1, 2, and 3.

During stress tests, $m$ hazardous resonance events were logged. Each logged event specifies identifiers $u$ and $v$ for the cores involved. To prevent catastrophic failure, for every logged resonance event between core $u$ and core $v$, the frequency band assigned to $u$ must be strictly different from the frequency band assigned to $v$. 

Note that an event log might record a core resonating with itself (where $u = v$). In such cases, the exact same restriction applies: the frequency band of $u$ must be strictly different from the frequency band of $v$. 

Determine whether there is a safe tuning configuration for all $n$ cores. If a safe configuration exists, output one.

## Input
The first line contains two integers $n$ and $m$ — the number of cores and the number of logged events ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the following $m$ lines contains two integers $u$ and $v$ — the identifiers of the cores involved in a resonance event.

## Output
If no safe configuration is possible, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $p_1, p_2, \dots, p_n$ (each in $\{1, 2, 3\}$), where $p_i$ is the frequency band assigned to core $i$. Any valid configuration is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The reference to "two modules" was changed to "identifiers $u$ and $v$" to remove the implication that $u$ and $v$ must be distinct. An explicit rule was added stating that if $u = v$, the requirement that their assigned states be different still applies. This forces models to properly evaluate self-interactions as impossible constraints rather than bypassing them with `if u == v: continue`.
</RATIONALE>
<PRESERVED_ANSWER>
The original problem mathematically required $p_u \neq p_v$ for any recorded interaction, meaning a self-interaction ($u=v$) would render the system unsolvable; making this consequence explicit does not change the valid outputs for any input.
</PRESERVED_ANSWER>
