We can model this as a graph coloring problem with 3 colors, where each edge must connect two different colors, and the allowed color pairs are exactly those where the two colors are different.  
That means: no two connected nodes can have the same color.  

So the problem reduces to:  
- Check if the graph is 3-colorable.  
- If yes, find the lexicographically smallest coloring (assign smallest possible color to node 1, then node 2, etc.).  

We can solve it with backtracking, trying colors 1, 2, 3 in order for each node, and checking constraints.  

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

colors = [0] * n

def is_safe(node, color):
    for nei in adj[node]:
        if colors[nei] == color:
            return False
    return True

def solve(node):
    if node == n:
        return True
    for c in range(1, 4):
        if is_safe(node, c):
            colors[node] = c
            if solve(node + 1):
                return True
            colors[node] = 0
    return False

if solve(0):
    print("YES")
    print(" ".join(map(str, colors)))
else:
    print("NO")
```
