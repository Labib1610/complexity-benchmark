**Solution Explanation**

For every core we have to choose a colour `1,2,3`.  
Two cores that appear together in the log must obtain different colours.
The problem is exactly the *graph 3‑colouring* problem for a graph with  
`n ≤ 40` vertices.

`n` is small, therefore a simple depth‑first search with good ordering
(and immediate pruning) is fast enough.

--------------------------------------------------------------------

#### 1.   Data structures
* `adj[v]` – list of neighbours of vertex `v` (0‑based indices).
* `order` – vertices sorted by decreasing degree, the order in which we
  colour them.
* `col[v]` – current colour of vertex `v` (`0` = not coloured yet).

--------------------------------------------------------------------

#### 2.   Backtracking

```
dfs(pos):
    if pos == n:               # all vertices coloured
        return True
    v = order[pos]            # vertex to colour now
    forbidden = set(col[u] for u in adj[v] if col[u] != 0)
    for c in (1,2,3):
        if c not in forbidden:
            col[v] = c
            if dfs(pos+1):
                return True
            col[v] = 0        # undo
    return False
```

*When we try a colour we only have to check already coloured neighbours,
because uncoloured ones cannot cause a conflict yet.*

The recursion depth is at most `n = 40`.  
The branching factor is at most `3`, but the degree ordering makes the
search tree very small for typical inputs.  
In the worst case (complete graph `K_40`) the algorithm stops after trying
the first two colours for the first vertex – the third colour already
fails, so the whole search finishes instantly.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs **YES** and a valid colouring
iff such a colouring exists.

---

##### Lemma 1  
During the execution of `dfs`, the partial assignment stored in `col`
never violates the constraint “adjacent vertices have different colours”.

**Proof.**  
A colour `c` is assigned to a vertex `v` only if `c` is not present among
already coloured neighbours of `v` (the `forbidden` set).  
All neighbours that are still uncoloured have colour `0`, which is not a
real colour. Hence after the assignment all coloured edges are proper. ∎



##### Lemma 2  
If `dfs(pos)` returns `True`, then the array `col` is a proper 3‑colouring
of the whole graph.

**Proof.**  
`True` is returned only when `pos == n`, i.e. every vertex received a colour.
By Lemma&nbsp;1 the invariant “no coloured edge is monochromatic” holds for
all steps, therefore it also holds after the last step. ∎



##### Lemma 3  
If a proper 3‑colouring exists, `dfs(0)` eventually returns `True`.

**Proof.**  
Consider any fixed proper colouring `C`.  
We show by induction on `pos` that the recursive search can follow `C`.

*Base `pos = 0`*: the first vertex `v = order[0]` receives in `C` some colour
`c`. Since `C` is proper, none of `v`'s already coloured neighbours (none)
uses `c`, therefore `c` is allowed and the algorithm will try it
(at the latest among the three possibilities).

*Induction step*: assume the recursion has already coloured the first
`pos` vertices exactly as in `C`. For vertex `v = order[pos]` the colour
`C(v)` is different from all already coloured neighbours (they are coloured
as in `C` and `C` is proper). Hence `C(v)` is not forbidden and will be
tried by the algorithm. When it is tried, the recursion proceeds to
`pos+1`, preserving the induction hypothesis.

Thus the branch that follows `C` is never cut off and reaches `pos = n`,
making `dfs` return `True`. ∎



##### Lemma 4  
If `dfs(0)` returns `False`, no proper 3‑colouring exists.

**Proof.**  
Assume a proper colouring existed. By Lemma&nbsp;3 the algorithm would find
a branch leading to `True`, contradicting the return value `False`. ∎



##### Theorem  
The program prints  

* “YES” and a list of colours that satisfies all constraints  
  **iff** such a colouring exists,
* otherwise prints “NO”.

**Proof.**  

*If the program prints “YES”*: it did so because `dfs(0)` returned `True`.
By Lemma&nbsp;2 the produced `col` array is a proper 3‑colouring.

*If a proper colouring exists*: by Lemma&nbsp;3 `dfs(0)` returns `True`,
so the program prints “YES” and a valid assignment.

*If the program prints “NO”*: `dfs(0)` returned `False`. By Lemma&nbsp;4
no proper 3‑colouring exists. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*`n ≤ 40`, `m ≤ n(n-1)/2`.*

* Pre‑processing (building adjacency lists, sorting): `O(n + m)`.
* In the worst case the backtracking explores at most `3^n` states,
  but the degree ordering and early pruning make the explored part tiny.
  For the given limits the program runs well within the 2 s time limit.
* Memory consumption: adjacency lists `O(n + m)` and a few arrays of size
  `O(n)`, well below 256 MB.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    # order vertices by decreasing degree
    order = sorted(range(n), key=lambda x: -len(adj[x]))
    col = [0] * n          # 0 = uncoloured, else 1..3

    def dfs(pos: int) -> bool:
        if pos == n:
            return True
        v = order[pos]
        # collect colours of already coloured neighbours
        forbidden = set()
        for nb in adj[v]:
            c = col[nb]
            if c:
                forbidden.add(c)
        for c in (1, 2, 3):
            if c not in forbidden:
                col[v] = c
                if dfs(pos + 1):
                    return True
                col[v] = 0
        return False

    if dfs(0):
        out = ['YES', ' '.join(str(col[i]) for i in range(n))]
        sys.stdout.write('\n'.join(out))
    else:
        sys.stdout.write('NO')

if __name__ == "__main__":
    solve()
```
