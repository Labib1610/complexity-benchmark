<STATEMENT>
# Problem A — Phase Containment

Time limit: 2 s
Memory limit: 256 MB

In a high-energy physics lab, a batch of experimental energy modules is undergoing calibration. The testing chamber's cooling system dictates that the batch size $n$ must be at least a single module and no more than forty modules. Modules are identified by integers from 1 to $n$. Every module must be tuned to exactly one of three operational frequencies, identified by the values 1, 2, and 3.

During preliminary trials, unstable feedback events were detected. The recording system logs a total of $m$ events. This number is never negative, and its upper limit is exactly the number of unique pairs of distinct modules that can be formed from the batch of $n$. Each logged event specifies two module identifiers, $u$ and $v$, which were involved in the instability.

To prevent a catastrophic resonance, the tuning must satisfy a strict safety protocol: for every logged event between $u$ and $v$, the frequency assigned to $u$ and the frequency assigned to $v$ must be strictly different. Occasionally, a recorded event might list the same module at both ends of the feedback loop (that is, $u = v$). The safety protocol applies universally to all records. Consequently, any module involved in an internal feedback loop is required by the protocol to operate at a frequency strictly different from its own.

Your task is to determine whether there is a valid frequency assignment for all $n$ modules that satisfies every logged constraint. If it is possible, provide one such assignment.

## Input
The first line contains two integers $n$ and $m$ — the number of modules and the number of recorded events. (The limits for these values are defined by the physical and system capacities described above.)
Each of the subsequent $m$ lines contains two integers $u$ and $v$ — the identifiers of the modules involved in a specific unstable event.

## Output
If there is no way to assign frequencies safely, output a single line containing `NO`.
If a safe assignment is possible, output `YES` on the first line. On the second line, output $n$ integers separated by spaces, where the $i$-th integer represents the frequency (1, 2, or 3) assigned to the $i$-th module. If multiple safe assignments exist, any of them will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
