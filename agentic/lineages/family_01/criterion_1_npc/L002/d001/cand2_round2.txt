# Problem A — Frequency Allocation

Time limit: 2 s   Memory limit: 256 MB

A communications array consists of several transmitter nodes. Each node must be tuned to exactly one operational frequency band. The available frequency bands are labeled 1, 2, and 3.

During environmental testing, certain pairs of distinct nodes were found to cause destructive interference when active simultaneously. Specifically, if two such nodes are tuned to the exact same frequency band, their signals will overlap and crash the array. To guarantee stable communications, for every identified interfering pair of nodes, they must be assigned strictly different frequency bands.

You must determine if there is a valid frequency assignment for all nodes in the array. If such an assignment is possible, output one valid configuration.

## Input
The first line contains two integers $n$ and $m$. The headcount of transmitter nodes, $n$, requires at least 1 active unit and is constrained by the array's maximum capacity of 40. The count of recorded interference events, $m$, can be as low as 0 and as high as the theoretical limit of $n(n-1)/2$ unique pairs.

Each of the subsequent $m$ lines provides two integers $u$ and $v$. These represent the identifiers of two distinct nodes that interfere with each other (meaning $u$ and $v$ are integers from 1 to $n$, and $u \neq v$). Each interfering pair is listed at most once.

## Output
If no safe frequency assignment exists, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $f_1, f_2, \dots, f_n$ (each in $\{1, 2, 3\}$), where $f_i$ is the frequency band assigned to node $i$. Any valid assignment is accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
