<STATEMENT>
# Problem A — Phase Containment

Time limit: 2 s
Memory limit: 256 MB

A research facility is running diagnostics on a series of experimental energy modules. Every module must be locked into exactly one operational phase state. The permitted phase states are represented by the integers 1, 2, and 3.

Monitoring has revealed a set of unstable resonance links between certain modules. When a resonance link exists between module $u$ and module $v$, configuring both of them to the same phase state will cause a critical array failure. To guarantee stability, the endpoints of every resonance link must be locked into completely different phase states.

Your task is to figure out whether all modules can be safely configured. If a safe configuration exists, you must also supply one.

## Input
The first line provides two integers $n$ and $m$. The integer $n$ represents the number of modules. Since the testing array is built as a rigid 8-by-5 physical matrix, $n$ is at least 1 and will never exceed the total capacity of this matrix. The integer $m$ represents the number of observed resonance links. This value is non-negative and is at most the total number of distinct pairs that can be chosen from the $n$ modules.

Each of the following $m$ lines contains two integers $u$ and $v$, identifying the endpoints of a resonance link. 

## Output
If it is impossible to safely configure the modules, output NO on a single line.
If it is possible, output YES on the first line. On the next line, output $n$ integers separated by spaces, where the $i$-th integer is the phase state (1, 2, or 3) assigned to the $i$-th module. If there are multiple safe configurations, any of them will be accepted.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The numeric bounds have been rewritten indirectly: the maximum number of modules (40) is derived from the capacity of an 8-by-5 physical matrix, and the maximum number of interactions is described as the total number of distinct pairs. Additionally, phrasing that explicitly labelled the endpoints as "two modules" was changed to "endpoints of a resonance link" to prevent models from using that wording as a shortcut to justify skipping self-interaction checks.
</RATIONALE>
<PRESERVED_ANSWER>
The core requirement that any linked pair of modules must be assigned different phase states remains exactly the same, so all valid calibrations are identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks for an assignment of 3 states to vertices such that no two adjacent vertices share a state, which is exactly the NP-complete 3-Coloring problem.
</PRESERVED_CLASS>
<RISK>
The derivation of the module limit from an 8-by-5 matrix might be considered slightly unusual, but 8 times 5 is unambiguous arithmetic.
</RISK>
