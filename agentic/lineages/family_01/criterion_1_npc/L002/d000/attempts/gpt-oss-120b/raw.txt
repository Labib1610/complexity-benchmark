**Solution Explanation**

For every module we have to choose a phase `1 , 2 , 3`.
For each recorded interaction `(u , v)` the two modules must obtain
different phases.
The problem is exactly the *graph 3‑colouring* problem:

* vertices – modules `1 … n`  
* edges    – recorded interactions  

We have to decide whether the graph is 3‑colourable and output one
colouring.



--------------------------------------------------------------------

#### 1.  Observations  

* `n ≤ 40` – small enough for an exponential backtracking algorithm,
  but we still need good pruning.
* The only restriction is *different colours on the ends of an edge*,
  i.e. a binary inequality constraint.
* While searching we can keep for every still uncoloured vertex the set
  of colours that are still possible – its **domain**.
  Initially every domain is `{1,2,3}`.
* When a vertex receives a colour, that colour disappears from the
  domains of all its neighbours (forward checking).
* If a neighbour’s domain becomes a singleton, the neighbour is forced
  to that colour – we can assign it immediately (unit propagation).

These are the standard techniques for solving a binary CSP and are
more than enough for `n = 40`.

--------------------------------------------------------------------

#### 2.  Data structures  

* `adj[v]` – list of neighbours of vertex `v` (0‑based indices).
* `domains[v]` – 3‑bit mask, bit `c` (`c = 0,1,2`) is set iff colour
  `c+1` is still possible.
  `0b111 == 7` means *all three colours*.
* `col[v]` – already fixed colour (`0` = not fixed, otherwise `1,2,3`).

All masks fit into a normal Python `int`.  
`popcount` = `mask.bit_count()` (Python 3.8+).

--------------------------------------------------------------------

#### 3.  Propagation  

```
propagate(queue, domains, col):
    while queue not empty:
        v = queue.pop()
        colour = the only bit set in domains[v]          # 0,1,2
        col[v] = colour + 1
        for each neighbour u of v with col[u] == 0:
            if domains[u] contains this colour:
                domains[u] &= ~(1 << colour)            # delete it
                if domains[u] == 0: return False        # dead end
                if domains[u] has exactly one bit:
                    queue.append(u)                     # forced assignment
    return True
```

The queue initially contains the vertex we have just coloured.
All forced assignments are processed automatically.

--------------------------------------------------------------------

#### 4.  Backtracking search  

```
search(domains, col):
    # 1. check for already solved / dead end
    if every vertex coloured:   return col
    if some uncoloured vertex has empty domain:   return None

    # 2. choose a vertex – MRV heuristic (minimum remaining values)
    v = uncoloured vertex with smallest popcount(domains[v])  ( > 0 )

    # 3. try every colour still possible for v
    for each colour c in domains[v]:
        new_domains = domains copy
        new_col      = col copy
        new_domains[v] = 1 << c                # fix the colour
        queue = [v]
        if propagate(queue, new_domains, new_col):
            result = search(new_domains, new_col)
            if result is not None: return result
    return None
```

The recursion depth never exceeds `n = 40`.  
Copying the two length‑`n` lists costs only a few microseconds.

--------------------------------------------------------------------

#### 5.  Correctness Proof  

We prove that the algorithm prints **YES** and a correct colouring
iff such a colouring exists, otherwise prints **NO**.

---

##### Lemma 1  
`propagate` never removes a colour from a vertex that could belong to
*some* proper 3‑colouring extending the current partial assignment.

**Proof.**  
A colour is removed from a neighbour `u` only because an already fixed
neighbour `v` received that colour.
In any proper colouring `v` and `u` must have different colours,
therefore `u` cannot keep the removed colour.
∎



##### Lemma 2  
If after a call of `propagate` a vertex obtains a singleton domain,
the colour in that domain is forced in *every* proper extension of the
current partial assignment.

**Proof.**  
All colours except the single one are already forbidden by Lemma&nbsp;1,
hence the remaining colour is the only possible one. ∎



##### Lemma 3  
`search` explores **exactly** all colourings that are consistent with
the constraints and the decisions made on the recursion path.

**Proof.**  
At a recursion node the algorithm
* chooses an uncoloured vertex `v`,
* iterates over *all* colours still present in its domain,
* for each colour creates a copy of the current state,
  fixes the colour, and runs `propagate`.

Because of Lemma&nbsp;1 the propagation step never discards a colour that
could belong to a valid extension, therefore every colour that can be
extended is tried.
Conversely, any colour that is tried obviously respects all already
fixed colours, and propagation only removes colours that would violate
the inequality edges, so the recursive call receives a *consistent*
state.
Thus the recursion tree contains precisely the set of all consistent
partial colourings. ∎



##### Lemma 4  
If `search` returns a complete assignment, it is a proper 3‑colouring.

**Proof.**  
A complete assignment means every vertex has a colour.
During the whole execution colours are only removed from neighbours
when a neighbour already has that colour (Lemma&nbsp;1), therefore no
edge ever connects two equal colours.
All colours belong to `{1,2,3}` by construction. ∎



##### Lemma 5  
If a proper 3‑colouring exists, `search` eventually returns one.

**Proof.**  
Consider any proper colouring `C`.  
Follow the recursion tree: at each node the algorithm picks a vertex
`v`. In `C` vertex `v` has some colour `c`. Because `C` respects all
edges, `c` is still present in `v`’s domain (otherwise `C` would have been
invalidated earlier, contradicting Lemma&nbsp;1).  
The branch where the algorithm tries colour `c` is therefore taken.
Propagation cannot delete any colour used by `C` (Lemma&nbsp;1), so the
state after propagation is still compatible with `C`.  
Repeating the argument along the path, we never backtrack away from the
branch that follows `C`. After at most `n` steps all vertices become
coloured, the algorithm returns this colouring. ∎



##### Lemma 6  
If `search` returns `None`, no proper 3‑colouring exists.

**Proof.**  
`search` returns `None` only after exploring *all* branches of the
recursion tree and finding each of them inconsistent.
By Lemma&nbsp;3 every possible consistent partial colouring appears in the
tree. Hence no consistent total colouring exists. ∎



##### Theorem  
The program prints  

* “YES” and a list of `n` numbers in `{1,2,3}` that satisfies all
  interactions **iff** such a list exists,
* otherwise prints “NO”.

**Proof.**  

*If the program prints “YES”.*  
It obtained the list from `search`. By Lemma&nbsp;4 the list is a proper
3‑colouring, therefore a valid calibration exists.

*If a valid calibration exists.*  
By Lemma&nbsp;5 `search` finds a complete assignment and returns it,
so the program prints “YES”.

*If the program prints “NO”.*  
That happens only when `search` returns `None`. By Lemma&nbsp;6 no
proper 3‑colouring exists, i.e. no valid calibration exists.

Thus the output is correct in all cases. ∎



--------------------------------------------------------------------

#### 6.  Complexity Analysis  

`n ≤ 40`.

*Propagation* touches each edge at most once per recursive call  
`O(m)` time, `O(n)` memory.

*Search* – worst case exponential, `O(3^n)` in theory,
but with forward checking and MRV the explored part of the tree is
tiny for all graphs of size 40 (well inside the 2 s limit).

Memory consumption: two copies of `domains` and `col` per recursion
level → `O(n·depth) = O(n²) ≤ 1600` integers, negligible.

#### 7.  Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        if u == v:
            continue
        adj[u].append(v)
        adj[v].append(u)

    ALL = 0b111  # bits 0,1,2 -> colours 1,2,3
    domains = [ALL] * n
    col = [0] * n          # 0 = uncoloured, else 1..3

    # ---------- propagation ----------
    def propagate(queue, dom, col):
        while queue:
            v = queue.pop()
            mask = dom[v]
            # mask is guaranteed to be a power of two
            colour = (mask & -mask).bit_length() - 1   # 0,1,2
            col[v] = colour + 1
            for u in adj[v]:
                if col[u]:
                    continue
                if dom[u] & (1 << colour):
                    dom[u] &= ~(1 << colour)
                    if dom[u] == 0:
                        return False
                    if dom[u].bit_count() == 1:
                        queue.append(u)
        return True

    # ---------- backtracking ----------
    def search(dom, col):
        # check for completion / dead end
        unassigned = -1
        min_sz = 4
        for i in range(n):
            if col[i]:
                continue
            sz = dom[i].bit_count()
            if sz == 0:
                return None
            if sz < min_sz:
                min_sz = sz
                unassigned = i
                if sz == 1:
                    break
        if unassigned == -1:          # all coloured
            return col

        v = unassigned
        possible = dom[v]
        # try colours in arbitrary order
        for c in range(3):
            if not (possible & (1 << c)):
                continue
            ndom = dom[:]
            ncol = col[:]
            ndom[v] = 1 << c
            queue = [v]
            if not propagate(queue, ndom, ncol):
                continue
            res = search(ndom, ncol)
            if res is not None:
                return res
        return None

    answer = search(domains, col)
    out = sys.stdout
    if answer is None:
        out.write("NO\n")
    else:
        out.write("YES\n")
        out.write(" ".join(str(x) for x in answer) + "\n")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
