We need to find a triangle (3 mutually connected nodes) in an undirected graph, and among all triangles, pick the one with the smallest sequence trace:  
`a * 10^8 + b * 10^4 + c` where `a < b < c`.

Since `n` can be up to 2000 and `m` up to 200,000, we need an efficient approach.

A direct O(n^3) triangle check is too slow.  
We can use adjacency sets and iterate over edges, checking for common neighbors.

**Approach:**
- Build adjacency sets for each node.
- Iterate over each edge `(u, v)` with `u < v`.
- For each common neighbor `w` of `u` and `v` where `w > v`, we have a triangle `(u, v, w)`.
- Keep track of the minimum trace.

We need to be careful with ordering:  
For a triangle `(a, b, c)` with `a < b < c`, we can generate it by iterating edges `(u, v)` with `u < v` and then checking neighbors `w > v`.

Complexity:  
For each edge, we check intersection of adjacency sets. Using Python sets, intersection is O(min(deg(u), deg(v))). In the worst case, this could be O(m * n) but with n=2000 and m=200k, it's acceptable if we optimize.

We can also use bitsets for adjacency to speed up intersection.

Let's implement with bitsets (Python integers as bitmasks) for speed.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [0] * (n + 1)
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u] |= (1 << (v - 1))
        adj[v] |= (1 << (u - 1))
    
    best = None
    best_trace = None
    
    # Iterate over edges
    for u in range(1, n + 1):
        for v in range(u + 1, n + 1):
            if (adj[u] >> (v - 1)) & 1:
                # common neighbors > v
                common = adj[u] & adj[v]
                # mask out nodes <= v
                mask = ((1 << n) - 1) ^ ((1 << v) - 1)
                common &= mask
                while common:
                    # get lowest set bit
                    lsb = common & -common
                    w = lsb.bit_length()  # 1-indexed
                    trace = u * 10**8 + v * 10**4 + w
                    if best_trace is None or trace < best_trace:
                        best_trace = trace
                        best = (u, v, w)
                    common ^= lsb
    
    print(*best)

if __name__ == "__main__":
    main()
```
