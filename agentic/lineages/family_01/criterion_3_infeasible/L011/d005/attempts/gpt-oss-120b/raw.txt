**Solution Explanation**

For every pair of steps `(u , v)` we are given that they *collide*,
i.e. they **cannot** be placed on the same production line.
A set of three steps is an *unresolvable bottleneck* iff every two of them
collide – in graph terms it is a **triangle** (a 3‑clique).

The task is therefore:

*Given an undirected graph with `n ≤ 2000` vertices, find the lexicographically
smallest triangle*  
(`a < b < c`, minimise `a`, then `b`, then `c`).

--------------------------------------------------------------------

#### 1.   Data structure – bitsets

`n ≤ 2000`, so a vertex’s adjacency set fits into a 2000‑bit integer.
Python’s arbitrary length integers are perfect for this:

```
adj[v]  – integer whose i‑th bit (0‑based) is 1  ⇔  edge (v , i+1) exists
```

All edges are stored symmetrically (`adj[u] |= 1 << (v-1)` and vice‑versa).

With bitsets the intersection of two neighbour sets is a single
`&` operation, and testing whether a particular vertex is present is a bit test.

--------------------------------------------------------------------

#### 2.   Searching triangles in lexicographic order

We iterate over possible first two vertices `a , b` in the required order:

```
for a = 1 … n:
    for b = a+1 … n:
        if edge (a,b) exists:
            common = adj[a] & adj[b]          # vertices adjacent to both
            # we need c > b
            mask   = ~((1 << b) - 1)           # bits with index ≥ b
            cand   = common & mask
            if cand != 0:
                c = (cand & -cand).bit_length()   # index of lowest set bit
                output a,b,c
                return
```

Explanation of the mask:

* vertices are numbered `1 … n`, bit indices are `0 … n-1`
* we need `c > b`, i.e. bit index `≥ b`
* `((1 << b) - 1)` has ones in positions `0 … b-1`; negating it leaves ones from `b` upwards.

Finding the lowest set bit of `cand` gives the smallest possible `c`,
hence the first triangle discovered is exactly the lexicographically smallest one.

The outer loops run `O(n²)` ( ≤ 4·10⁶ iterations for `n = 2000` ), each iteration does only a few integer operations – easily fast enough.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest triangle.

---

##### Lemma 1  
For any vertices `a < b`, after the test `if edge (a,b) exists`,
`cand = (adj[a] & adj[b]) & mask` contains exactly the vertices `c` such that
`c > b` and edges `(a,c)` and `(b,c)` exist.

**Proof.**  
`adj[a] & adj[b]` is the set of vertices adjacent to **both** `a` and `b`.  
`mask` has ones precisely at bit indices `≥ b` (i.e. vertices `c ≥ b+1`).  
Intersection keeps a vertex iff it belongs to both sets, i.e. it is a common
neighbour and its number is larger than `b`. ∎



##### Lemma 2  
If `cand` is non‑zero, `c = (cand & -cand).bit_length()` is the smallest vertex
`c` (numerically) satisfying the conditions of Lemma&nbsp;1.

**Proof.**  
`cand & -cand` isolates the lowest set bit of `cand`.  
`bit_length()` of that power‑of‑two equals its index + 1, i.e. the vertex number.
Since the isolated bit is the lowest one, the obtained `c` is minimal. ∎



##### Lemma 3  
When the algorithm prints a triple `(a,b,c)`, it is a triangle
(`a<b<c` and all three edges exist).

**Proof.**  
`a<b` by loop construction.  
The edge `(a,b)` exists because the inner loop proceeds only after the
corresponding test succeeded.  
By Lemma&nbsp;1, `c` is a common neighbour of `a` and `b`; therefore edges
`(a,c)` and `(b,c)` exist.  
Finally Lemma&nbsp;2 guarantees `c>b`. ∎



##### Lemma 4  
Let `T` be the set of all triangles in the graph.
The algorithm outputs the triangle with the smallest `a`; among those,
the smallest `b`; and among those, the smallest `c`.

**Proof.**  
The outer loops enumerate all ordered pairs `(a,b)` with `a<b` in increasing
lexicographic order.  
For a fixed pair `(a,b)`, if any triangle with this prefix exists,
Lemma&nbsp;1 ensures `cand` is non‑empty, and Lemma&nbsp;2 picks the smallest
possible `c`.  
Consequently the first printed triple is the lexicographically smallest
triangle in `T`. ∎



##### Theorem  
The algorithm always terminates and prints exactly the required answer:
the lexicographically smallest set of three steps such that every two
require the same tool (i.e. a triangle).

**Proof.**  
*Termination*: `n` is finite, loops are bounded, and each iteration performs
constant‑time integer operations.  
*Existence*: the statement guarantees at least one triangle, so some
iteration will find a non‑empty `cand` and output a triple.  
*Correctness*: By Lemma&nbsp;3 the printed triple is a triangle.
By Lemma&nbsp;4 it is the lexicographically smallest triangle.
Thus it satisfies the problem specification. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency bitsets*: `O(m)` time, `O(n)` integers → `O(n²/word)` memory  
(≈ 2000 · 2000 bits ≈ 0.5 MiB).

*Search*: outer loops `O(n²)` ≈ 4·10⁶ iterations, each does a few bitwise
operations → `O(n²)` time.

Overall  

```
Time   :  O(n²)   ≤ 4·10⁶ operations  (well below 2 s)
Memory :  O(n² / 8)  ≤ 0.5 MiB
```

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * (n + 1)          # 1‑based, each is an int bitset

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        bit_u = 1 << (v - 1)
        bit_v = 1 << (u - 1)
        adj[u] |= bit_u
        adj[v] |= bit_v

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if not (adj[a] >> (b - 1)) & 1:
                continue          # edge (a,b) missing
            common = adj[a] & adj[b]
            # keep only vertices with index >= b (i.e. number > b)
            mask = ~((1 << b) - 1)
            cand = common & mask
            if cand:
                # lowest set bit -> smallest c
                low = cand & -cand
                c = low.bit_length()   # gives index+1
                sys.stdout.write(f"{a} {b} {c}")
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
