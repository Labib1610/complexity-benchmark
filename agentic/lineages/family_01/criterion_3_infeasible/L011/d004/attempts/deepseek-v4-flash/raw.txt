We need to find a triangle in the graph (three mutually connected nodes) with the smallest lexicographic order by the given formula.  

We can do this efficiently by iterating over possible smallest node `a`, then checking pairs `(b, c)` with `b > a`, `c > b`, and checking if all three edges exist.  

Since `n` can be up to 2000 and `m` up to 200,000, we can use adjacency sets for O(1) edge checks.  

We’ll iterate `a` from 1 to n, then `b` from `a+1` to n, and for each `b`, check neighbors of `a` that are greater than `b` and also connected to `b`.  

The first found triplet in this order will be the minimum by the given trace formula.  

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if b not in adj[a]:
                continue
            # find c > b such that c in adj[a] and c in adj[b]
            for c in range(b + 1, n + 1):
                if c in adj[a] and c in adj[b]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    solve()
```
