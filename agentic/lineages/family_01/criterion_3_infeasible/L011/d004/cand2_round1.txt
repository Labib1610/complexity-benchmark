# Production Line Diagnostics

Time limit: 2 s   Memory limit: 256 MB

A manufacturing facility operates continuously using exactly two production lines. Certain pairs of manufacturing steps require a shared specialized calibration tool and therefore cannot be assigned to the same production line. The current batch of manufacturing steps cannot be distributed across the two lines without causing at least one tool collision.

Your diagnostic software must isolate a root cause of this allocation failure by identifying an inherently un-allocatable configuration of exactly three steps. Specifically, you must find a group of three distinct steps such that, even if all other steps were removed from the facility, it would still be impossible to assign these three steps to the two production lines without placing a conflicting pair on the same line.

To ensure deterministic logging, if multiple such groups of three steps exist, the system must output the group whose step identifiers are sequentially lowest.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), representing the total number of manufacturing steps and the number of tool collision pairs. Steps are numbered from $1$ to $n$.

Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that step $u$ and step $v$ cannot be assigned to the same production line.

It is guaranteed that at least one such group of three steps exists in the provided data.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, with $a < b < c$, representing the identifiers of the three steps. Output the combination that is sequentially lowest (the smallest possible value for $a$; in case of a tie, the smallest possible value for $b$; and finally the smallest possible value for $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
Removed the explicit description of the three steps mutually conflicting. Instead, the target is defined as a subset of three steps that cannot be validly partitioned into two conflict-free sets. This forces the model to deduce that a 3-vertex subgraph is not 2-colorable if and only if it is a triangle.
</RATIONALE>
<PRESERVED_ANSWER>
By the Pigeonhole Principle, any subset of 3 vertices that cannot be 2-colored must contain 3 edges (a triangle), making the target mathematically identical to the original.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a triangle (K3) in a graph, preserving the original complexity class and intended algorithm.
</PRESERVED_CLASS>
<RISK>
Models might overthink the impossibility condition and attempt to write a 2-SAT or bipartite checking algorithm for subsets of size 3, missing the direct equivalence to a triangle, though the wording is completely unambiguous.
</RISK>
