We need to find a triangle (3-clique) in an undirected graph with the lexicographically smallest vertex set.

A direct brute force over all triples would be O(n³), which is too slow for n up to 2000.  
We can instead iterate over the first vertex `a` from 1 to n, then over the second vertex `b` from a+1 to n, and check if `b` is adjacent to `a`. If yes, we then look for the smallest `c > b` that is adjacent to both `a` and `b`.  

To make adjacency checks fast, we store the graph as a set of neighbors for each vertex.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if b in adj[a]:
                # find smallest c > b adjacent to both a and b
                for c in range(b + 1, n + 1):
                    if c in adj[a] and c in adj[b]:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    main()
```
