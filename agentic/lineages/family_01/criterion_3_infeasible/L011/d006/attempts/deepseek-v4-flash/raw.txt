We can model the problem as finding a triangle in the graph that is “unresolvable” — meaning every 2-coloring of its three vertices causes at least one edge within the triple to have both endpoints the same color.  

For three vertices, the only way to avoid a collision is to color them alternately, which is only possible if the three vertices form no triangle (i.e., they are not all pairwise connected). If they form a triangle, then any 2-coloring will have at least one monochromatic edge.  

So the task reduces to finding the lexicographically smallest triangle in the graph.  

Here’s the Python solution:  

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    edges = []
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
        edges.append((u, v))

    # Try all triples in lexicographic order
    for a in range(n):
        for b in range(a + 1, n):
            if b not in adj[a]:
                continue
            for c in range(b + 1, n):
                if c in adj[a] and c in adj[b]:
                    print(a + 1, b + 1, c + 1)
                    return

if __name__ == "__main__":
    main()
```
