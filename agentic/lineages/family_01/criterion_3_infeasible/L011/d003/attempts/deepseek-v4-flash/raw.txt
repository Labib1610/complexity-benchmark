We need to find the smallest triangle (in terms of the given trace formula) in an undirected graph.  
Since n can be up to 2000, we can use an adjacency matrix for O(1) edge checks and iterate over all triples in O(n^3), but that would be too slow for n=2000 (8e9 operations).  

We can instead iterate over edges and check for a common neighbor, which is O(m * n) in the worst case, but with m up to 2e5 and n=2000, that’s 4e8 operations, which might be borderline but feasible in Python with optimizations.  

We can also use bitsets for adjacency to speed up the common neighbor check.  

Here’s the approach:  
- Represent adjacency as a list of Python integers (bitmask) for each vertex.  
- For each edge (u, v), compute the intersection of adjacency[u] and adjacency[v].  
- The smallest vertex in that intersection gives the smallest triangle containing that edge.  
- Keep track of the minimum trace.  

We must ensure we only consider triangles with u < v < w.  

Let’s implement it.  

```python
n, m = map(int, input().split())
adj = [0] * (n + 1)
edges = []

for _ in range(m):
    u, v = map(int, input().split())
    edges.append((u, v))
    adj[u] |= 1 << v
    adj[v] |= 1 << u

best = None
best_trace = None

for u, v in edges:
    common = adj[u] & adj[v]
    # We need a w such that u < v < w or u < w < v etc.
    # Since we iterate all edges, we can just check all w in common
    # and ensure ordering u < v < w or u < w < v etc.
    # But to avoid duplicates, we can enforce u < v and w > v
    if u > v:
        u, v = v, u
    # Now u < v
    # Find smallest w > v in common
    # We can iterate over bits
    while common:
        lsb = common & -common
        w = lsb.bit_length()  # gives index+1
        if w > v:
            trace = u * 10**8 + v * 10**4 + w
            if best_trace is None or trace < best_trace:
                best_trace = trace
                best = (u, v, w)
            break  # smallest w > v found for this edge
        common ^= lsb

print(best[0], best[1], best[2])
```
