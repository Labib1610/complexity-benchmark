We need to find the lexicographically smallest triple of vertices whose associated 3×3 matrix is invertible (linearly independent rows).  

The matrix for a triple \((a,b,c)\) is:

\[
\begin{bmatrix}
0 & a+b & a+c \\
a+b & 0 & b+c \\
a+c & b+c & 0
\end{bmatrix}
\]

We need to check if its determinant is non-zero.  

The determinant of this symmetric matrix is:

\[
\det = 2(a+b)(b+c)(c+a)
\]

Wait — let’s verify. For a matrix of the form:

\[
\begin{bmatrix}
0 & p & q \\
p & 0 & r \\
q & r & 0
\end{bmatrix}
\]

The determinant is \(2pqr\).  

Here:
- \(p = a+b\)
- \(q = a+c\)
- \(r = b+c\)

So determinant = \(2(a+b)(a+c)(b+c)\).  

Since \(a,b,c\) are positive integers, this is zero only if one of the sums is zero, which is impossible. So **every** triple is linearly independent?  

That can’t be right — the problem says at least one exists, implying not all triples work. Let’s check more carefully.

Actually, the matrix is:

\[
\mathbf{v}_1 = (0, a+b, a+c)
\]
\[
\mathbf{v}_2 = (a+b, 0, b+c)
\]
\[
\mathbf{v}_3 = (a+c, b+c, 0)
\]

The determinant is:

\[
\det = 0 \cdot (0 \cdot 0 - (b+c)(b+c)) - (a+b)((a+b)\cdot 0 - (b+c)(a+c)) + (a+c)((a+b)(b+c) - 0 \cdot (a+c))
\]

Simplify:

First term: 0  
Second term: \(-(a+b)( - (b+c)(a+c)) = (a+b)(b+c)(a+c)\)  
Third term: \((a+c)(a+b)(b+c)\)  

Sum = \(2(a+b)(b+c)(a+c)\).

So indeed determinant is always positive for positive integers.  

That means **every** triple is a bottleneck. So the answer is simply the lexicographically smallest triple: \(1, 2, 3\).  

But wait — the problem says “at least one exists” and asks for lexicographically smallest. If all triples work, then the answer is always `1 2 3`.  

Let’s test with examples:  
Example 1: output is `1 2 3` — matches.  
Example 2: output is `1 2 4` — but if all triples work, why not `1 2 3`?  

So maybe the graph structure matters — the matrix entries are zero if there is no edge. So the matrix is not always full of sums; missing edges give zeros.  

Thus the determinant is not always \(2(a+b)(b+c)(c+a)\) — that formula only holds if all three edges exist. If some edges are missing, some entries are zero, and the determinant can be zero.  

So we need to find the lexicographically smallest triple where the determinant is non-zero.  

We can brute force over triples in lexicographic order and check the determinant.  
n ≤ 2000, so O(n³) is too big. But we can stop early — the first valid triple is the answer.  

We can check triples in lexicographic order:  
for a in 1..n-2:  
  for b in a+1..n-1:  
    for c in b+1..n:  
      check determinant  

But worst-case could be large if the first valid triple is late. However, the problem guarantees at least one exists, and we can stop early.  

We can precompute adjacency in a set for O(1) edge checks.  

Determinant for triple (a,b,c):  

Matrix:
\[
\begin{bmatrix}
0 & e_{ab}(a+b) & e_{ac}(a+c) \\
e_{ab}(a+b) & 0 & e_{bc}(b+c) \\
e_{ac}(a+c) & e_{bc}(b+c) & 0
\end{bmatrix}
\]
where \(e_{uv} = 1\) if edge exists, else 0.

Determinant = \(2 \cdot e_{ab} e_{ac} e_{bc} (a+b)(a+c)(b+c)\).  

So it's non-zero iff all three edges exist.  

Thus the problem reduces to: find the lexicographically smallest triangle in the graph.  

So we just need to find the smallest triple (a,b,c) such that edges (a,b), (a,c), (b,c) all exist.  

We can do this efficiently:  
- For each a from 1 to n-2:  
  - For each b > a that is adjacent to a:  
    - For each c > b that is adjacent to both a and b:  
      - If found, output and exit.  

We can store adjacency as sets for O(1) checks.  

Complexity: worst-case O(n * deg(a) * deg(b)) but we stop early.  

Let's implement.  

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n+1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n-1):
        for b in adj[a]:
            if b <= a:
                continue
            for c in adj[b]:
                if c <= b:
                    continue
                if c in adj[a]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
