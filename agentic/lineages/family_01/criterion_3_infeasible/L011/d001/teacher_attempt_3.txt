# Cross-Pollination Incompatibilities

Time limit: 2 s   Memory limit: 256 MB

A greenhouse cultivates rare orchids, which must be planted in exactly two isolated climate zones to prevent cross-pollination. However, certain pairs of orchid varieties produce sterile hybrids if their pollen mixes, meaning they cannot be placed in the same climate zone. The current inventory of orchid varieties cannot be divided into the two zones without risking at least one sterile hybrid.

Your agricultural software must isolate a root cause of this planting failure by identifying a set of three orchid varieties where every pair within the set produces sterile hybrids. Such a trio forms an unresolvable planting bottleneck, as no two of these three varieties can be safely placed in the same zone.

To ensure deterministic logging, if multiple such unresolvable trios exist, the system must output the one whose variety identifiers are sequentially lowest.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), representing the total number of orchid varieties and the number of incompatible pairs. Varieties are numbered from $1$ to $n$.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that variety $u$ and variety $v$ cannot be placed in the same climate zone.
It is guaranteed that at least one set of three varieties, where every pair is incompatible, exists in the provided data.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, with $a < b < c$, representing the identifiers of the three varieties where every pair is incompatible. Output the combination that is sequentially lowest (the smallest possible value for $a$; in case of a tie, the smallest possible value for $b$; and finally the smallest possible value for $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
