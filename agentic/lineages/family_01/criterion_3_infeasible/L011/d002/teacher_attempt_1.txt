<STATEMENT>
# Process Isolation Analysis

Time limit: 2 s   Memory limit: 256 MB

A manufacturing control system dispatches queued tasks to exactly two execution threads. Certain pairs of tasks require exclusive access to the same hardware register and therefore collide if assigned to the same thread. The current batch of tasks cannot be safely partitioned across the two threads without at least one collision.

Your diagnostic routine must isolate a root cause of this scheduling failure by identifying a deadlock trio. A deadlock trio consists of three distinct tasks that are entirely mutually incompatible—each task in the trio collides with both of the other two. Because there are only two threads, assigning these three tasks without a collision is impossible.

To ensure deterministic logging, if multiple such deadlock trios exist, the system must output the trio $a, b, c$ (arranged such that $a < b < c$) that strictly minimizes the deadlock signature, calculated as: $a \cdot 10^8 + b \cdot 10^4 + c$.

## Input
The first line contains two integers $n$ and $m$. The first integer represents the total number of tasks. The system handles batches containing up to two thousand tasks, with a minimum of three required to form a deadlock. Tasks are numbered from $1$ to $n$.
The second integer represents the number of recorded collision pairs. The logging system records at least three such pairs, up to a maximum of two hundred thousand (or the theoretical maximum number of distinct pairs for the given tasks, whichever is smaller).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that task $u$ and task $v$ collide if assigned to the same thread.
It is guaranteed that at least one deadlock trio exists in the provided data.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, with $a < b < c$, representing the identifiers of the three tasks forming the deadlock trio. Output the combination that minimizes the deadlock signature defined above.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
