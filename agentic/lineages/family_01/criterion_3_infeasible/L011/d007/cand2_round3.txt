<STATEMENT>
# Logic Circuit Diagnostics

Time limit: 2 s   Memory limit: 256 MB

A complex logic circuit contains many processing nodes. Certain pairs of nodes are "entangled." 

Your diagnostic software must isolate a root cause of instability by identifying a group of exactly three nodes that form a "critical triplet." 

A group of exactly three distinct nodes is classified as a critical triplet if, no matter how each of the three nodes is assigned either a High or Low state, there will always be two entangled nodes within the group that receive the same state.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), representing the total number of processing nodes and the number of entangled pairs. Nodes are numbered from $1$ to $n$.

Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that node $u$ and node $v$ are an entangled pair.

It is guaranteed that at least one critical triplet exists in the provided data.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, with $a < b < c$, representing the identifiers of the three nodes. Output the combination that is sequentially lowest (the smallest possible value for $a$; in case of a tie, the smallest possible value for $b$; and finally the smallest possible value for $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
The explicit mention of $2^3 = 8$ assignments and two production lines was removed, as it acts as a strong trigger for LLMs to recognize a 2-coloring/bipartite impossibility condition (which trivially reduces to finding a triangle). By reframing the condition as exploring all High/Low state assignments, models must now independently deduce that the pigeonhole principle forces any 3 nodes to have at least two in the same state, meaning the triplet is only "critical" if all three possible pairs are entangled. Exact bounds from the seed were fully restored.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that any High/Low assignment results in two entangled nodes sharing a state is logically identical to the seed's condition that any Line A/Line B allocation results in a tool collision; both strictly define a triangle (K3) in the graph.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding the lexicographically first triangle in a graph, preserving the $O(n \cdot m / 64)$ bitset adjacency intersection complexity.
</PRESERVED_CLASS>
