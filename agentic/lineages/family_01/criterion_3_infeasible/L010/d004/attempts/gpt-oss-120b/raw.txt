**Solution Explanation**

For three different reports (edges)  

```
{a,b} , {a,c} , {b,c}
```

the symmetric difference is empty, because every worker appears in exactly two
reports.  
So we only have to find a *triangle* in the given undirected graph.
Among all triangles we must output the lexicographically smallest ordered
triple `a < b < c`.

`n ≤ 2000`, therefore a bitset of length `n` fits into a single Python integer
(≈ 2000 bits).  
With bitsets we can test the existence of a common neighbour of two vertices
in O(1) time.



--------------------------------------------------------------------

#### Data structures

* `adj[v]` – Python `int`, bit `u‑1` is `1` iff edge `v‑u` exists.
* `higher[v]` – bitmask whose bits are `1` for all vertices `> v`
  (used to enforce the ordering `a < b < c`).

--------------------------------------------------------------------

#### Algorithm
```
read n , m
build adj[1..n]                     # undirected
pre‑compute higher[0..n]            # higher[v] = bits of vertices > v

for a = 1 .. n:
        # neighbours of a that are larger than a, in increasing order
        nb = adj[a] & higher[a]
        while nb != 0:
                # smallest b > a with edge a‑b
                low = nb & -nb
                b = bit_index(low) + 1
                nb ^= low            # remove this b

                # common neighbours of a and b that are larger than b
                common = adj[a] & adj[b] & higher[b]
                if common != 0:
                        lowc = common & -common
                        c = bit_index(lowc) + 1
                        output a b c and finish
```

`bit_index(x)` is `x.bit_length() - 1` (position of the only set bit, 0‑based).

The outer loop tries `a` from `1` upwards, the inner loop tries `b` from the
smallest possible neighbour upwards, and `c` is the smallest possible common
neighbour larger than `b`.  
Consequently the first triangle found is exactly the lexicographically
smallest one.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest triangle.

---

##### Lemma 1  
For any vertices `a < b`, `common = adj[a] & adj[b] & higher[b]` contains exactly
the vertices `c` such that `c > b` and edges `{a,c}` and `{b,c}` exist.

**Proof.**  
`adj[a]` has a `1` at position `c‑1` iff `{a,c}` is an edge.  
`adj[b]` has a `1` at the same position iff `{b,c}` is an edge.  
`higher[b]` has a `1` at that position iff `c > b`.  
The bitwise AND is `1` exactly when all three conditions hold. ∎



##### Lemma 2  
When the algorithm processes a fixed pair `(a,b)` (`a<b` and edge `{a,b}` exists)
and `common` is non‑empty, the vertex `c` chosen by the algorithm is the
smallest vertex `c > b` that together with `a,b` forms a triangle.

**Proof.**  
By Lemma&nbsp;1, `common` contains precisely all such `c`.  
`lowc = common & -common` extracts the least‑significant set bit, i.e. the
smallest index in `common`. Converting the index back to a vertex number gives
the smallest possible `c`. ∎



##### Lemma 3  
If the algorithm outputs a triple `(a,b,c)`, it is a triangle.

**Proof.**  
`b` is taken from `adj[a]`, therefore edge `{a,b}` exists.  
`c` is taken from `common = adj[a] & adj[b] & higher[b]`; by Lemma&nbsp;1,
edges `{a,c}` and `{b,c}` exist. Hence all three edges are present – a
triangle. ∎



##### Lemma 4  
Let `T* = (a*,b*,c*)` be the lexicographically smallest triangle
(`a*<b*<c*`). The algorithm will output `T*`.

**Proof.**  
The outer loop reaches `a = a*` before any larger `a`.  
When `a = a*`, the inner loop iterates over all neighbours `b > a*` in increasing
order. Since `b* > a*` and edge `{a*,b*}` exists, the iteration will eventually
consider `b = b*`.  

All neighbours `b < b*` are examined earlier, but none of them can belong to a
triangle with `a*` and a vertex `c > b` that is ≤ `c*`, otherwise that triangle
would be lexicographically smaller than `T*`, contradicting the definition of
`T*`. Therefore when `b = b*` is processed, `common` is non‑empty (it contains
`c*`). By Lemma&nbsp;2 the algorithm picks the smallest such `c`, which is
exactly `c*`. Consequently the algorithm outputs `(a*,b*,c*)`. ∎



##### Theorem  
The algorithm always terminates and prints the lexicographically smallest
triple of workers that form a deadlock (i.e. a triangle).

**Proof.**  
Termination: the loops run over a finite set of vertices and edges; each
iteration removes at least one processed neighbour, so they finish.  
Existence of output: the statement guarantees at least one triangle, and by
Lemma&nbsp;4 the algorithm will find the smallest one, thus it certainly reaches
a `common ≠ 0` and returns.  
Correctness follows from Lemma&nbsp;3 (output is a triangle) and Lemma&nbsp;4
(minimality). ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency bitsets*: `O(m)`.

For each edge `{a,b}` we may examine it once (when `a` is the smaller endpoint)
and perform only constant‑time bit operations.  
Thus total time is `O(m)` ( ≤ 2·10⁵ ), well within the limit.

Memory: `n` integers of ≤ 2000 bits → `O(n)` ≈ a few kilobytes.

--------------------------------------------------------------------

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * (n + 1)          # 1‑based
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        bit_u = 1 << (u - 1)
        bit_v = 1 << (v - 1)
        adj[u] |= bit_v
        adj[v] |= bit_u

    # higher[v] = bits of vertices > v
    full = (1 << n) - 1
    higher = [0] * (n + 1)
    for v in range(n + 1):
        higher[v] = full ^ ((1 << v) - 1)   # bits v, v+1, ... (0‑based)

    for a in range(1, n + 1):
        nb = adj[a] & higher[a]            # neighbours > a
        while nb:
            low = nb & -nb
            b = low.bit_length()           # 1‑based vertex number
            nb ^= low                       # remove this b

            common = adj[a] & adj[b] & higher[b]
            if common:
                lowc = common & -common
                c = lowc.bit_length()
                # a < b < c holds by construction
                sys.stdout.write(f"{a} {b} {c}")
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
