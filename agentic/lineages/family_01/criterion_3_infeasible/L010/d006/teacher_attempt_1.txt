# Tri-Core Amalgamation

Time limit: 2 s   Memory limit: 256 MB

A materials science laboratory handles a collection of $n$ distinct base metals, identified by integers starting from $1$ up to $n$. The facility's safety protocol mandates a minimum inventory of three base metals, while its physical storage capacity restricts this number to at most two thousand.

Through experimentation, researchers have documented $m$ successful two-metal fusions. The digital archive system is designed to hold up to two hundred thousand fusion records, but will naturally contain no more than the absolute maximum number of distinct combinations of two metals possible given the current inventory. The archive is guaranteed to always contain a minimum of three fusion records.

The objective is to identify exactly three distinct base metals that can form a stable tri-core amalgam. A tri-core amalgam is considered stable if and only if each constituent metal in the trio has a documented fusion with both of the other two metals in the amalgam. The laboratory guarantees that the provided records will always contain at least one valid tri-core amalgam.

## Input
The first line provides $n$ and $m$, the total count of base metals and the number of documented fusions, respectively.
Following this are $m$ lines. Each line provides two integers $u$ and $v$, identifying a pair of base metals that have a documented fusion. No fusion is documented more than once, and a metal is never documented fusing with itself.

## Output
Produce a single line containing three space-separated integers $a$, $b$, and $c$ (arranged such that $a < b < c$) representing the identifiers of the metals in the stable tri-core amalgam. If several different valid amalgams meet the stability criteria, you must output the one that is lexicographically smallest (first minimize $a$, then minimize $b$, then minimize $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
I embedded all numerical bounds into the narrative as physical capacities and safety limits, removing bare inequalities from the Input section. I also rephrased the stability condition—instead of removing an element to leave a valid pair (which strongly hints at a subset property), I described it as each constituent metal requiring a fusion with the other two. This forces the model to deduce the mutual pairwise structure from local requirements rather than matching the global definition of a 3-clique.
</RATIONALE>
<PRESERVED_ANSWER>
The required output is still the lexicographically smallest set of three elements that are all mutually compatible, meaning the correct answer for any given input remains identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Finding a set of three mutually compatible elements is structurally identical to finding a triangle (K3) in an undirected graph, preserving the original algorithmic requirements and complexity class.
</PRESERVED_CLASS>
<RISK>
The phrase "absolute maximum number of distinct combinations of two metals possible" relies on the reader translating this to n(n-1)/2, which could theoretically be misunderstood if they misinterpret "combinations", though it is standard combinatorial terminology.
</RISK>
