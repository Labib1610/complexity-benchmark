We need to find a triangle in the graph (three mutual connections) such that the tuple `(a, b, c)` with `a < b < c` is lexicographically smallest.

The straightforward approach is to iterate over all possible triples and check if all three edges exist.  
Since \(n\) can be up to 2000, \(O(n^3)\) is too slow.  
But we can loop over the first vertex `a` in increasing order)Skip. For each `a`, we try `b > a` such that edge `(a, b)` exists. Then the smallest `c > b` that is connected to both `a` and `b` gives the lexicographically smallest triple starting with `a` and `b`.

We can store the adjacency as a set for fast edge existence checks.

Here’s the implementation:  

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)

    for a in range(n):
        for b in sorted(adj[a]):
            if b <= a:
                continue
            # Find smallest c > b adjacent to both a and b
            for c in sorted(adj[a]):
                if c <= b:
                    continue
                if c in adj[b]:
                    print(a+1, b+1, c+1)
                    return

if __name__ == "__main__":
    solve()
```
