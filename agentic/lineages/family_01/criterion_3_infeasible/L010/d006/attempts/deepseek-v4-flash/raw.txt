We need to find a "deadlock": three distinct reports (edges) such that for any two of them, the symmetric difference of their endpoints equals the endpoints of the third report.

This is equivalent to finding a triangle in the graph: three vertices where all three edges exist.  
Because if we have edges (a,b), (b,c), (a,c), then:

- For (a,b) and (b,c): symmetric difference = {a,c} → third edge (a,c)  
- For (a,b) and (a,c): symmetric difference = {b,c} → third edge (b,c)  
- For (b,c) and (a,c): symmetric difference = {a,b} → third edge (a,b)

So the problem reduces to finding the lexicographically smallest triangle (sorted vertex IDs) in an undirected graph.

We can do this efficiently:

- n ≤ 2000, m ≤ 2e5  
- We can iterate over all edges (u,v) with u < v, and check for a common neighbor w > v that is connected to both u and v.  
- To get lexicographically smallest sorted triple, we iterate u from 1 to n, then v from u+1 to n, then w from v+1 to n, and check if all three edges exist.  
- Use adjacency matrix (boolean) for O(1) edge lookup.

Complexity: O(n^3) worst-case if we naively triple loop, but n=2000 → 8e9 too big.  
We can instead iterate over edges (u,v) and for each, check neighbors of u that are > v and also connected to v.  
We can store adjacency lists sorted, and for each edge (u,v), intersect neighbor lists of u and v (both > v) to find smallest w.  
This is O(m * degree) worst-case, but with n=2000 and m=2e5, it's fine.

We'll implement:

- adjacency list for each vertex (sorted)
- adjacency matrix for O(1) checks
- iterate u from 1..n, v from u+1..n, if edge exists, then for each w in neighbors of u (sorted) with w > v, check if edge(v,w) exists. First found gives smallest triple.

Let's code it.```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n + 1)]
    mat = [[False] * (n + 1) for _ in range(n + 1)]
    
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].append(v)
        adj[v].append(u)
        mat[u][v] = mat[v][u] = True
    
    for i in range(1, n + 1):
        adj[i].sort()
    
    # Find lexicographically smallest triangle
    for u in range(1, n + 1):
        for v in adj[u]:
            if v <= u:
                continue
            for w in adj[u]:
                if w <= v:
                    continue
                if mat[v][w]:
                    print(u, v, w)
                    return

if __name__ == "__main__":
    solve()
