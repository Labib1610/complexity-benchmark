We can solve this by checking each possible triple in sorted order and stopping at the first valid one.  
Since n can be up to 2000, we need an efficient check for whether two nodes are connected.

We’ll use an adjacency matrix (as a set of bitsets) to make the “are they connected?” check O(1).

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(n):
        for b in range(a + 1, n):
            if b not in adj[a]:
                continue
            for c in range(b + 1, n):
                if c in adj[a] and c in adj[b]:
                    print(a + 1, b + 1, c + 1)
                    return

if __name__ == "__main__":
    main()
```
