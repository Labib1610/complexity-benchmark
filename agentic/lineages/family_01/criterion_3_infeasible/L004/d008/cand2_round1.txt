<STATEMENT>
# Critical Interference

Time limit: 2 s
Memory limit: 256 MB

A proposed communications standard attempts to allocate $n$ transceivers (labeled 1 through $n$) into a network. However, testing has revealed $m$ specific bidirectional interference links between pairs of transceivers. Each link connects two distinct transceivers, and no two links connect the same pair.

To diagnose the core issue in the network's topology, engineers analyze the *cross-talk isolation matrix* of transceiver triplets. For any chosen subset of exactly three transceivers, we order them by their labels as $u_1 < u_2 < u_3$. 
We then construct a $3 \times 3$ matrix $Z$ as follows:
- The main diagonal entries are all $1$: $Z_{1,1} = Z_{2,2} = Z_{3,3} = 1$.
- The off-diagonal entries are assigned values based on the presence of interference links:
  - $Z_{1,2}$ and $Z_{2,1}$ are set to $u_3^3$ if testing has revealed an interference link between $u_1$ and $u_2$, and $0$ otherwise.
  - $Z_{2,3}$ and $Z_{3,2}$ are set to $u_1^3$ if testing has revealed an interference link between $u_2$ and $u_3$, and $0$ otherwise.
  - $Z_{1,3}$ and $Z_{3,1}$ are set to $u_2^3$ if testing has revealed an interference link between $u_1$ and $u_3$, and $0$ otherwise.

The *stability characteristic* of the triplet is defined as the determinant of this matrix $Z$.

Your objective is to isolate a subset of exactly three transceivers whose stability characteristic is exactly $1 + 2(u_1 \cdot u_2 \cdot u_3)^3 - u_1^6 - u_2^6 - u_3^6$. The existence of such a subset proves a critical flaw in the network. It is guaranteed that at least one such subset is present.

## Input
The first line contains the transceiver count $n$ and the interference link count $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$).
The following $m$ lines each detail a pair of transceivers $u$ and $v$ that share a mutual interference link.
At least one subset of three transceivers satisfying the stability condition is guaranteed to exist.

## Output
Provide the labels of the three transceivers forming the subset, printed on a single line in ascending numerical order.
In the event that several such subsets exist, you must resolve the ambiguity by selecting the subset that includes the transceiver with the absolute lowest label. Should multiple subsets share this lowest-labeled transceiver, further narrow your selection to those whose second-lowest label is as small as possible. If ambiguity still persists, choose the subset whose highest label is minimal.

## Example 1
### Input
```
4 5
1 2
1 3
2 3
2 4
3 4
```
### Output
```
1 2 3
```

## Example 2
### Input
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
### Output
```
1 2 4
```

<RATIONALE>
The previous trace-based formulation evaluated to a constant independent of the node labels, allowing models to deduce the triangle requirement by simply checking the 4 isomorphism classes of a 3-node graph. To defeat this, the new formulation embeds the node labels directly into the matrix entries. The determinant evaluates to the target polynomial if and only if all three edges are present, which forces the model to either attempt a complex algebraic reduction (often failing to substitute $E^2=E$ for the boolean edge indicators) or fall back to an $O(n^3)$ naive simulation that will TLE.
</RATIONALE>
<PRESERVED_ANSWER>
The determinant of the defined matrix algebraically simplifies to the target value if and only if all three interference links exist between the chosen transceivers, meaning the problem still asks for the exact same lexicographically first triangle.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the detection of a 3-clique (triangle) in an undirected graph, keeping it in the same complexity class with the exact same intended $O(nm/64)$ bitset algorithm.
</PRESERVED_CLASS>
<RISK>
Models attempting the naive $O(n^3)$ simulation in languages with fixed-width integers may encounter 64-bit overflow since $u_i^6$ can reach $2000^6 \approx 6.4 \times 10^{19}$, but this is a natural consequence of failing to find the intended algorithmic reduction and does not make the mathematical statement ambiguous.
</RISK>
