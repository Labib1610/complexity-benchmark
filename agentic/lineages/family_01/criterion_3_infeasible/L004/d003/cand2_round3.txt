# Critical Interference

Time limit: 2 s
Memory limit: 256 MB

A regional authority is attempting to configure a network of $n$ broadcast towers, assigning each tower to one of two available frequencies. The towers are assigned identifiers from 1 to $n$. However, due to geographical overlap, there are $m$ specific bidirectional interference links between pairs of towers. If two linked towers use the same frequency, they will disrupt each other's signals.

The authority's goal of safely assigning all towers to just two frequencies is fundamentally flawed. Your task is to provide definitive proof of this flaw. You must find a set of three distinct towers where every tower in the set has an interference link with both of the other two towers in the set. 

Finding any such set of three mutually interfering towers is sufficient to prove that two frequencies cannot resolve all conflicts. The network configuration guarantees that at least one such set of three towers exists.

## Input

The first line contains two integers $n$ and $m$. The number of towers $n$ ranges from a minimum of 3 up to a hardware limit of exactly 2000. The number of interference links $m$ is at least 3, and is bounded by the strict system capacity: it will not exceed the total possible number of distinct pairs of towers, nor will it exceed a hard limit of 200000.

Each of the following $m$ lines contains two integers $u$ and $v$, indicating a bidirectional interference link between tower $u$ and tower $v$. 

It is guaranteed that the input contains at least one set of three mutually linked towers.

## Output

Print three integers $a$, $b$, and $c$ on a single line, representing the identifiers of three distinct towers that form a mutually interfering set. You must ensure that $a < b < c$, and that the input contains an interference link between $a$ and $b$, between $a$ and $c$, and between $b$ and $c$.

If there are multiple valid sets of three towers in the input, output the lexicographically smallest valid triple $(a, b, c)$ (meaning the smallest $a$; in case of a tie, the smallest $b$; and if still tied, the smallest $c$).

## Example 1
### Input
```
4 5
1 2
1 3
2 3
2 4
3 4
```
### Output
```
1 2 3
```

## Example 2
### Input
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
### Output
```
1 2 4
```
