To solve this problem, we need to find a triangle (three mutually interfering nodes) in a given graph. The solution should efficiently find the lexicographically smallest such triangle.

### Approach
1. **Graph Representation**: Represent the graph using an adjacency list or adjacency matrix. Given the constraints (n up to 2000 and m up to 200,000), an adjacency matrix might be feasible (2000x2000 is 4 million entries, which is manageable in Python with bitsets or a list of sets).
2. **Finding Triangles**: The key observation is that a triangle exists if there are three nodes where each pair is connected. To find the lexicographically smallest triangle, we can iterate through each node in order, and for each node, check pairs of its neighbors to see if they are also connected. The first such triplet found will be the lexicographically smallest because we check nodes in ascending order.
3. **Efficiency**: For each node `a`, we check all pairs of its neighbors `b` and `c` (where `b < c`). If `b` and `c` are connected, then `a, b, c` form a triangle. Since we process nodes in order, the first valid triangle found will be the lexicographically smallest.

For each node, the bitmask is an integer where the i-th bit is 1 if node i is a neighbor.
