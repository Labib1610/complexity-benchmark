 We need to find the lexicographically smallest triangle (three nodes all pairwise connected) in an undirected graph.

A direct brute force over all triples would be O(n³), which is too slow for n up to 2000.  
We can instead iterate over each node `a` from 1 to n, and for each `a`, look at its neighbors.  
For each pair of neighbors `(b, c)` of `a`, if `b` and `c` are also connected, we have a triangle.  
We want the lexicographically smallest, so we check in increasing order of `a`, then `b`, then `c`.

We can store the adjacency as a set for fast lookup.

Here’s the implementation:

```python
n, m = map(int, input().split())
adj = [set() for _ in range(n + 1)]

for _ in range(m):
    u, v = map(int, input().split())
    adj[u].add(v)
    adj[v].add(u)

# Iterate over smallest possible a
for a in range(1, n + 1):
    neighbors = sorted(adj[a])
    for i in range(len(neighbors)):
        b = neighbors[i]
        if b <= a:
            continue
        for j in range(i + 1, len(neighbors)):
            c = neighbors[j]
            if c <= b:
                continue
            if c in adj[b]:
                print(a, b, c)
                exit()
```
