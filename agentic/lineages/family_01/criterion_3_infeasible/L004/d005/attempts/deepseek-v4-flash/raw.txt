We need to find a set of three assets such that no matter how we assign Long/Short, at least one co-dependent pair gets the same assignment.  

That means the three assets must form a **triangle** in the graph (all three pairs are edges).  
If all three pairs are connected, then by the pigeonhole principle, with two labels (Long/Short) and three nodes, at least two will share a label, and since they are connected, that violates the rule.

So the task reduces to: find the lexicographically smallest triangle in an undirected graph.

We can do this by iterating over possible first vertex `a` from 1 to n, then over possible second vertex `b` from `a+1` to n, and if edge exists, check for `c` from `b+1` to n where both `(a,c)` and `(b,c)` are edges. The first found is the answer.

Complexity: O(n^3) worst-case, but n ≤ 2000, so we need to be careful.  
We can optimize by using adjacency sets and breaking early.

Here’s the code:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n+1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n+1):
        for b in range(a+1, n+1):
            if b in adj[a]:
                for c in range(b+1, n+1):
                    if c in adj[a] and c in adj[b]:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    main()
```
