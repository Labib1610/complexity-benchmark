We need to find a triple of vertices that cannot be 2-colored without conflict — which means they form an odd cycle, and specifically for a triple, they must be a **triangle** (all three pairwise connected), because only then in any 2-coloring two must share an edge.

So, the task reduces to:  
Find the lexicographically smallest triangle in the graph.

**Approach:**
1. Read the graph as an adjacency matrix (since `n ≤ 2000`, 4 million booleans is okay).
2. Iterate over `a` from 1 to n:
   - For each `b > a` that is adjacent to `a`:
     - For each `c > b` that is adjacent to `b` and `a`:
       - If found, output immediately (since we iterate `a` increasing, first found is lexicographically smallest).

This is O(n³) worst-case, but with a fast check via adjacency matrix it might pass if we optimize:  
We won’t actually loop over all triples fully; we break early once found.not

We’ll use bitsets for speed:  
- Store adjacency as Python integers where bit `i` means edge to node `i`.
- For given `a, b`, the common neighbors greater than `b` are `adj[a] & adj[b] & mask_gt_b`. Pick smallest bit.

Let’s code that.  

```python
import sys

def solve():
    input_data = sys.stdin.buffer.read().split()
    n = int(input_data[0])
    m = int(input_data[1])
    
    adj = [0] * (n + 1)
    
    idx = 2
    for _ in range(m):
        u = int(input_data[idx])
        v = int(input_data[idx + 1])
        idx += 2
        adj[u] |= (1 << v)
        adj[v] |= (1 << u)
    
    full_mask = (1 << (n + 1)) - 1
    
    for a in range(1, n + 1):
        # neighbors of a with index > a
        set_b = adj[a] & (full_mask ^ ((1 << (a + 1)) - 1))
        while set_b:
            # get lowest set bit
            lsb = set_b & -set_b
            b = lsb.bit_length() - 1
            # common neighbors > b
            set_c = adj[a] & adj[b] & (full_mask ^ ((1 << (b + 1)) - 1))
            if set_c:
                lsb_c = set_c & -set_c
                c = lsb_c.bit_length() - 1
                print(a, b, c)
                return
            set_b ^= lsb
    
if __name__ == "__main__":
    solve()
```
