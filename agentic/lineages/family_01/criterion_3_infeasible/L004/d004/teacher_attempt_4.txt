# Mechanism Jam

Time limit: 2 s
Memory limit: 256 MB

A clockwork mechanism contains $n$ gears, numbered 1 through $n$. 
The design specifies $m$ meshing pairs. Each pair indicates two gears that are directly engaged with each other. 
Because engaged gears must rotate in opposite directions, certain configurations can cause conflicting rotational forces, jamming the entire mechanism.

You must identify a minimal jamming configuration: a set of exactly three distinct gears that are mutually engaged. Specifically, the design must contain a meshing pair for the first and second gear, a meshing pair for the second and third gear, and a meshing pair for the third and first gear. This closed loop of three gears forces a rotational paradox, making movement impossible.

## Input
The first line provides two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$, representing a meshing pair of gears. 
It is guaranteed that the design contains at least one such set of three mutually engaged gears.

## Output
Output the three integer identifiers of your chosen gears on a single line, ordered from lowest to highest. 
If more than one such set of three gears exists, evaluate each set by its sorted identifiers. Choose the set that minimizes the first (lowest) identifier. If there is a tie, choose the set that minimizes the second (middle) identifier. If a tie still remains, minimize the third (highest) identifier.

## Example 1
### Input
```
4 5
1 2
1 3
2 3
2 4
3 4
```
### Output
```
1 2 3
```

## Example 2
### Input
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
### Output
```
1 2 4
```
