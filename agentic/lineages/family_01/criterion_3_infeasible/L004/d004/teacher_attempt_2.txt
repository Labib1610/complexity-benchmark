# Environment Allocation

Time limit: 2 s
Memory limit: 256 MB

A system administrator must deploy $n$ software modules (labeled 1 to $n$) across two isolated execution contexts. The deployment registry lists $m$ historical conflict reports. If a pair of modules appears in a report, they are strictly prohibited from sharing a context, as doing so leads to immediate resource exhaustion.

The administrator suspects that two contexts are insufficient and wants to authorize a third. To secure authorization, they must isolate a specific failure pattern: three distinct modules where every possible pair among them is listed in the conflict reports. With such a pattern, distributing these three modules across only two contexts guarantees a prohibited overlap.

Multiple such failure patterns might exist. To standardize reporting, each pattern of three modules $x, y, z$ (where $x < y < z$) is assigned a unique resolution code evaluated as $x \cdot 10^8 + y \cdot 10^4 + z$. The administrator must submit the exact pattern that produces the lowest possible resolution code.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$).
Each of the following $m$ lines provides two integers $u$ and $v$, identifying a pair of modules involved in a conflict report.
It is guaranteed that at least one failure pattern of three mutually conflicting modules exists in the registry.

## Output
Output the three module labels for the pattern with the lowest resolution code. Print them on a single line, separated by spaces, in ascending order.

## Example 1
### Input
```
4 5
1 2
1 3
2 3
2 4
3 4
```
### Output
```
1 2 3
```

## Example 2
### Input
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
### Output
```
1 2 4
```

<RATIONALE>
The previous tie-breaking rule explicitly spelled out lexicographic minimization, which nudged models to use ascending edge/vertex enumeration strategies. By replacing the lexicographic description with a base-10,000 polynomial scalar ("resolution code"), the text obscures the step-by-step sequential nature of the tie-breaking while keeping the mathematical result identical. This forces models to derive the optimal traversal order from the scalar function rather than simply matching the keyword "lexicographical".
</RATIONALE>
<PRESERVED_ANSWER>
Because the module IDs $x, y, z$ are bounded by $n \le 2000$, evaluating $x \cdot 10^8 + y \cdot 10^4 + z$ guarantees no overlap between the "digits" of each variable, making the minimization of this scalar mathematically identical to lexicographic minimization.
</PRESERVED_ANSWER>
