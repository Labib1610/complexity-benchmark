# Critical Interference

Time limit: 2 s
Memory limit: 256 MB

A network administrator is attempting to partition $n$ communication terminals (numbered 1 through $n$) into two separate operational frequencies. The system log provides $m$ records of terminal pairs that will trigger a severe interference event if they are forced to broadcast on the exact same frequency.

Due to the distribution of these interference records, it is known to be impossible to achieve a safe two-frequency partition. To formally document the failure, you must output a minimal proof of impossibility consisting of three distinct terminals. Specifically, you must identify a set of exactly three distinct terminals such that the system log contains three separate records where both terminals in each of these records belong to your chosen set.

## Input
The first line contains two integers $n$ and $m$. The number of terminals $n$ is dictated by a minimum facility requirement of three active units, up to a maximum power array capacity of two thousand units. The number of records $m$ starts at a minimum of three, and is restricted by a storage limit of two hundred thousand entries (or the maximum possible number of distinct terminal pairs among the $n$ units, if that is smaller).

Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of terminals that experience interference if on the same frequency. 
It is guaranteed that at least one valid set of three terminals exists.

## Output
Print the three integer identifiers of these terminals on one line, sorted in ascending order. 
If there are multiple valid sets, output the one that is lexicographically smallest (smallest first integer; resolving ties by the second integer, then the third).

## Example 1
### Input
```
4 5
1 2
1 3
2 3
2 4
3 4
```
### Output
```
1 2 3
```

## Example 2
### Input
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
### Output
```
1 2 4
```

<RATIONALE>
Removed the explicit description of a terminal connecting to two others that also connect to each other, which served as a direct cue for finding a triangle. Instead, the requirement is framed as finding three distinct terminals that completely enclose three interference records. The numeric bounds were also rewritten into facility and storage limits as per the strategy, forcing the reader to derive the constraints rather than reading bare inequalities.
</RATIONALE>
<PRESERVED_ANSWER>
The condition of finding three terminals that enclose three interference records is mathematically identical to finding a triangle (a 3-clique) in the interference graph, meaning the correct output for any input remains exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a triangle (K3) in a graph to provide a certificate of non-bipartiteness, keeping the time complexity and structural task identical.
</PRESERVED_CLASS>

</RISK>
