<STATEMENT>
# Critical Interference

Time limit: 2 s
Memory limit: 256 MB

A proposed security protocol attempts to assign $n$ communication nodes (numbered 1 to $n$) to one of two distinct channels. However, there are $m$ specific pairs of nodes that will experience severe interference if they are placed in the same channel. 

The protocol's requirements are known to be fundamentally impossible to satisfy. Your task is to certify this impossibility by locating a specific failure pattern called a complete forward cascade. 

We define a strict one-way projection: for any two nodes $x$ and $y$ where $x < y$, we say $x$ *projects to* $y$ if they interfere with each other (meaning their pair is given in the input in either order).

You must identify a sequence of three nodes $a$, $b$, and $c$ such that:
- $a < b < c$
- $a$ projects to $b$
- $a$ projects to $c$
- $b$ projects to $c$

Any such sequence demonstrates that two channels are insufficient. It is guaranteed that at least one such sequence exists.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of nodes that interfere with each other. 
It is guaranteed that at least one complete forward cascade exists.

## Output
Print three integers $a$, $b$, and $c$ on one line with $a < b < c$, representing the identifiers of the three nodes in the cascade. 
Output the lexicographically smallest such sequence (smallest $a$; ties by smallest $b$; then smallest $c$).

## Example 1
### Input
```
4 5
1 2
1 3
2 3
2 4
3 4
```
### Output
```
1 2 3
```

## Example 2
### Input
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
### Output
```
1 2 4
```
</STATEMENT>
<RATIONALE>
The problem was reframed to define a strict one-way "projection" based on the numerical order of the node identifiers, requiring the output to satisfy a specific directed structure ($a \to b$, $a \to c$, $b \to c$). This removes the affordance of implicitly treating the problem as purely undirected, forcing models to explicitly reason about the directional logic rather than blindly applying symmetrization and standard undirected triangle-finding algorithms.
</RATIONALE>
<PRESERVED_ANSWER>
Because a complete forward cascade requires $a < b < c$ and projections between all three pairs, it is mathematically identical to a set of three mutually interfering nodes, ensuring every valid undirected triangle corresponds to exactly one valid cascade, preserving all answers and tie-breaks.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying computational task remains equivalent to finding a 3-clique (triangle) in a graph, preserving the O(n*m/64) intended complexity and the infeasibility certificate nature of the problem.
</PRESERVED_CLASS>
