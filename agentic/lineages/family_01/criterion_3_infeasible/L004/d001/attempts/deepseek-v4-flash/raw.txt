We can model each connection as a directed edge from the smaller node to the larger node.  
We are looking for three nodes \(a < b < c\) such that edges \(a \to b\), \(a \to c\), and \(b \to c\) all exist.

Here’s the approach:

1. Store adjacency in a set for fast lookup.
2. Iterate over possible \(a\) in increasing order.
3. For each \(a\), consider possible \(b\) (in increasing order) that are connected from \(a\).
4. For each such \(b\), check if there exists a \(c\) such that both \(a \to c\) and \(b \to c\) exist.  
   Instead of brute forcing over all nodes for every pair, we can intersect the neighbor lists:  
   `common = adj[a] & adj[b]`.  
   The smallest element in that intersection that is > b is our \(c\).

We stop as soon as we find a valid triple, since we are scanning \(a\) and \(b\) in increasing order.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        if u > v:
            u, v = v, u
        adj[u].add(v)
    
    for a in range(1, n + 1):
        for b in sorted(adj[a]):
            if b <= a:
                continue
            common = adj[a] & adj[b]
            for c in sorted(common):
                if c > b:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    solve()
```
