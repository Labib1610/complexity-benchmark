# Frequency Contradiction

Time limit: 2 s
Memory limit: 256 MB

A communications array is attempting to partition its active transmitters into two distinct frequency bands. The array requires a minimum of 3 transmitters to be operational, and its physical chassis can accommodate a maximum of 2000 transmitters. Each active transmitter is assigned a unique integer identifier starting from 1.

There are specific pairs of transmitters that produce severe feedback if they operate on the same frequency band. The conflict monitoring system has logged these overlapping pairs. The system requires at least 3 such logs to begin analysis, and its memory buffer is capped at exactly 200,000 logs (or the maximum possible number of distinct transmitter pairs, whichever is smaller).

The current deployment is fundamentally impossible to partition into just two frequency bands. To prove this to the diagnostic system, you must isolate a trio of transmitters where each individual transmitter produces feedback with both of the other two. Finding one such trio serves as proof that two bands are insufficient. It is guaranteed that the logs contain at least one such trio.

## Input
The first line contains two integers $n$ and $m$, representing the number of active transmitters and the number of feedback logs, respectively. Their values are restricted by the physical chassis and memory buffer limits described above.
Each of the following $m$ lines contains two distinct integers $u$ and $v$, indicating that transmitter $u$ and transmitter $v$ produce feedback if assigned to the same band. 
It is guaranteed that at least one trio of mutually conflicting transmitters exists.

## Output
Print three integers $a$, $b$, and $c$ on one line with $a < b < c$, representing the identifiers of the three transmitters that all conflict with each other. 
If there are multiple valid trios, output the one that is lexicographically first (the one with the smallest $a$; in case of a tie, the smallest $b$; then the smallest $c$).

## Example 1
### Input
```
4 5
1 2
1 3
2 3
2 4
3 4
```
### Output
```
1 2 3
```

## Example 2
### Input
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
### Output
```
1 2 4
```
