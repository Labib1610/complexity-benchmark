 We need to find a triplet of nodes whose “interference capacity” equals 18.  

Let’s break down the definition:  
For a triplet \( U = \{a,b,c\} \), we consider all 8 subsets \( S \subseteq U \).  
For each subset \( S \), \( k(S) \) is the number of edges with both endpoints in \( S \).  
Then we sum \( 2^{k(S)} \) over all 8 subsets.

We can compute this for a given triplet by checking the 3 possible edges among them.

Let’s denote:
- \( e \) = number of edges among the triplet (0, 1, 2, or 3).

For each subset \( S \):
- If \( |S| = 0 \): \( k=0 \) → contribution \( 2^0 = 1 \)
- If \( |S| = 1 \): \( k=0 \) → contribution \( 1 \) each, 3 subsets → 3
- If \( |S| = 2 \):  
  - If the two nodes are connected, \( k=1 \) → contribution 2  
  - If not connected, \( k=0 \) → contribution 1  
  There are 3 such subsets.
- If \( |S| = 3 \): \( k = e \) → contribution \( 2^e \)

So total =  
\( 1 + 3 + (\text{sum over 2-node subsets}) + 2^e \)

The sum over 2-node subsets = (number of edges among triplet) * 2 + (3 - number of edges) * 1  
= \( 2e + (3 - e) = e + 3 \)

Thus total = \( 1 + 3 + (e+3) + 2^e = 7 + e + 2^e \).

We need this to equal 18:  
\( 7 + e + 2^e = 18 \)  
\( e + 2^e = 11 \)

Check possible e:
- e=0: 0+1=1  
- e=1: 1+2=3  
- e=2: 2+4=6  
- e=3: 3+8=11 ✅

So we need a triplet with exactly 3 edges among them, i.e., a triangle.

Thus the problem reduces to: find the lexicographically smallest triangle in the graph.

We can do this by iterating over all triples in sorted order and checking if all three edges exist.  
Given constraints (n up to 2000, m up to 200k), a naive O(n^3) is too slow.  
We can instead iterate over edges and check for common neighbors.

Approach:
- Store adjacency as sets for fast lookup.
- Iterate over all edges (u,v) with u < v.
- For each such edge, find common neighbors w > v (to avoid duplicates and keep sorted order).
- The first such found (in sorted order of u, v, w) is the answer.

We can sort edges by u then v, and for each, check neighbors in increasing order.

Implementation:

```python
n, m = map(int, input().split())
adj = [set() for _ in range(n)]
edges = []
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].add(v)
    adj[v].add(u)
    if u > v:
        u, v = v, u
    edges.append((u, v))

edges.sort()

for u, v in edges:
    # find common neighbor w > v
    common = adj[u] & adj[v]
    for w in sorted(common):
        if w > v:
            print(u+1, v+1, w+1)
            exit()
```
