We need to find three vertices that form a **triangle** in the graph (i.e., all three edges exist among them).  
The problem guarantees at least one triangle exists.

We can solve it by iterating over possible smallest vertex `a`, then over possible middle vertex `b > a`, and checking if there is a common neighbor `c > b` that is connected to both `a` and `b`.  
To make this fast, we can use adjacency sets for O(1) edge checks.

Since `n ≤ 2000`, an O(n³) worst-case is too slow, but we can do O(n²) by using bitsets or adjacency sets and early exit.

Here’s the plan:
- Build adjacency sets.
- For each `a` from 1 to n:
  - For each `b > a` that is adjacent to `a`:
    - Find the smallest `c > b` that is adjacent to both `a` and `b`.
    - If found, output and exit.

We can speed up the inner search by iterating over neighbors of `a` that are greater than `b` and checking if they are also neighbors of `b`.

Let’s implement it.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        for b in sorted(adj[a]):
            if b <= a:
                continue
            for c in sorted(adj[a]):
                if c <= b:
                    continue
                if c in adj[b]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
