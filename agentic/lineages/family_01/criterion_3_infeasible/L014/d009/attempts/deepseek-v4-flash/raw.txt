We need to find the lexicographically smallest triple `(a, b, c)` such that the three vertices form a triangle in the complement graph — meaning in the original graph, none of the three edges between them are present.  

That’s because a deadlock configuration means:  
- We have 3 materials.  
- If we try to split them into two vessels, at least one pair must be together.  
- That happens exactly when all three pairs are prohibited (i.e., all three edges exist in the original graph).  

So we are looking for a triangle in the original graph, and among all triangles, we want the lexicographically smallest.

We can do this efficiently:

- Use an adjacency matrix (boolean) for O(1) edge checks.
- Iterate `a` from 1 to n, then `b` from a+1 to n, then `c` from b+1 to n.
- Check if all three edges exist.
- First found is the answer.

Given constraints (n ≤ 2000, m ≤ 2e5), an O(n³) check would be too slow.  
But we can optimize:  
- For each `a`, iterate over its neighbors as `b` (only those with index > a).  
- For each such `b`, iterate over neighbors of `b` with index > b, and check if `a` and `c` are connected.  

This is O(n + m + sum of degrees²) which is fine for n=2000.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = adj[v][u] = True

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if adj[a][b]:
                for c in range(b + 1, n + 1):
                    if adj[a][c] and adj[b][c]:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    main()
```
