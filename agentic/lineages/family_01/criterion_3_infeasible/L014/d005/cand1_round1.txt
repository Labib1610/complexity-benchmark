<STATEMENT>
# Problem C — Cargo Prohibition Protocol

Time limit: 2 s   Memory limit: 256 MB

A logistics firm operates a dual-vessel shipping route for hazardous materials. Certain pairs of these materials are highly reactive and are strictly prohibited from sharing a vessel.

The proposed loading schedule is structurally impossible to fulfill. You must produce a definitive proof of this impossibility to trigger an automatic schedule rejection.

To establish this proof, you are required to isolate a "deadlock" configuration of exactly three materials. Suppose we extract three materials and evaluate all $2^3 = 8$ possible ways to place each of them into either the first or the second vessel. A specific trio of materials forms a deadlock if every single one of these 8 placements fails. A placement fails if it puts a prohibited pair together in the first vessel, or puts a prohibited pair together in the second vessel. (You only consider the prohibitions that exist strictly among your three chosen materials.)

Because the automated auditing system requires deterministic reporting, it will not accept an arbitrary deadlock configuration. The system demands the canonical proof, meaning you must systematically ensure no earlier configuration could have been reported.

## Input
The first line provides two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n(n-1)/2, 2 \cdot 10^5)$), indicating the number of hazardous materials and the number of prohibited pairs. The materials are identified by integers from $1$ to $n$.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$) — a pair of materials that are prohibited from sharing a vessel. 
It is guaranteed that the input contains at least one deadlock configuration of three materials.

## Output
Output a single line containing three integers $a$, $b$, and $c$ ($a < b < c$), representing the identifiers of the materials in the deadlock configuration.
To satisfy the deterministic auditing system, if more than one such configuration exists, you must output the lexicographically earliest one. This means you must minimize $a$; if there is a tie, minimize $b$; and if still tied, minimize $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
The definition of a deadlock was changed from a direct statement about impossible assignments to an exhaustive state-space condition checking all 8 possible distributions of 3 materials. This forces the model to either deduce via the Pigeonhole Principle that this is equivalent to a triangle (all 3 pairs prohibited), or literally implement the 8-state check inside an $O(n^3)$ loop which will result in a Time Limit Exceeded error.
</RATIONALE>
<PRESERVED_ANSWER>
By the Pigeonhole Principle, assigning 3 materials to 2 vessels always places at least 2 materials in the same vessel; therefore, all 8 assignments fail if and only if all 3 pairs are prohibited (a triangle), keeping the valid configurations identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding the lexicographically first triangle in an undirected graph, preserving its certificate-style infeasibility class.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "every single one of these 8 placements fails" as implying a condition on the global assignment rather than just the isolated three materials, though the parenthetical explicitly restricts the scope.
</RISK>
