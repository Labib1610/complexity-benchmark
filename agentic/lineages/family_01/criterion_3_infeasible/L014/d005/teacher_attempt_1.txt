# Problem C — Oceanic Facility Stabilization

Time limit: 2 s   Memory limit: 256 MB

You are tasked with anchoring a triangular observation platform. The facility has $n$ potential anchor points. A geological survey identifies $m$ pairs of anchor points that are mutually stable enough to be linked directly by a tension cable.

To install the observation platform, you must choose exactly three distinct anchor points. The installation requires that each chosen anchor point must have a surveyed tension cable connecting it directly to both of the other two chosen points.

Determine three anchor points that meet this requirement.

## Input
The first line contains two integers $n$ and $m$.
The number of anchor points $n$ is bounded below by the exact number of points needed for a single platform (3), and bounded above by the hardware controller's maximum capacity of 2000 points.
The number of stable pairs $m$ is bounded below by the exact number of tension cables required to connect a valid platform (3). It is bounded above by the survey system's maximum storage limit of 200,000 records, or the maximum possible number of distinct pairs among the $n$ points, whichever is smaller.

Each of the following $m$ lines contains two distinct integers $u$ and $v$, representing the IDs of two anchor points that can be connected by a tension cable. Anchor point IDs are numbered sequentially from 1 up to $n$.
It is guaranteed that the input contains at least one valid set of three anchor points for the platform.

## Output
Print three integers $a$, $b$, and $c$ on a single line with $a < b < c$, representing the IDs of the chosen anchor points.
If there are multiple valid sets of three anchor points, output the one where the first ID $a$ is as small as possible. If there is still a tie, minimize the second ID $b$, and finally minimize the third ID $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
