We can solve this by checking each possible triple, but that would be too slow for large n.  
Instead, we can iterate over the middle vertex and check for common neighbors.

Here’s the approach:

- Store the graph as an adjacency set for fast lookups.
- For each vertex `b` from 1 to n:
  - For each neighbor `a` of `b` where `a < b`:
    - For each neighbor `c` of `b` where `c > b`:
      - If `a` and `c` are connected, we found a triangle.
      - Since we iterate in increasing order of `a`, then `b`, then `c`, the first found triangle is lexicographically smallest.

We can optimize by iterating over pairs of neighbors of `b` and checking if they are connected.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for b in range(1, n + 1):
        neighbors = sorted(adj[b])
        for i in range(len(neighbors)):
            a = neighbors[i]
            if a >= b:
                break
            for j in range(i + 1, len(neighbors)):
                c = neighbors[j]
                if c <= b:
                    continue
                if c in adj[a]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
