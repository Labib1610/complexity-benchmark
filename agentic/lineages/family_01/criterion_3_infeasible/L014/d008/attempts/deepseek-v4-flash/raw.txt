We can solve this by checking all triples in lexicographic order and verifying the deadlock condition.  

Since \( n \leq 2000 \), checking all triples naively would be \( O(n^3) \), which is too slow.  
Instead, we can iterate over the first two elements and check the third efficiently using adjacency sets.

Here’s the implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if b not in adj[a]:
                continue
            # Find smallest c > b such that c is connected to both a and b
            common = adj[a] & adj[b]
            for c in sorted(common):
                if c > b:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    solve()
```
