# Problem C — Ternary Alloy Certification

Time limit: 2 s   Memory limit: 256 MB

A metallurgy lab is cataloguing pure metals to create new alloys. The lab's storage vault has a maximum capacity of two thousand pure metals, and currently houses a working set of at least three.

The lab's research grant funded a series of compatibility tests between pairs of these metals. They conducted at least three tests, up to a maximum of two hundred thousand tests, bounded inherently by the total number of possible distinct pairs. Each test confirmed that a specific pair of distinct metals safely forms a stable bond.

The lab now needs to identify a candidate for a ternary (three-metal) alloy. The manufacturing process introduces metals one by one into a crucible. A new metal can only be added if it is certified to form a stable bond with every metal already present in the crucible. A valid ternary alloy is formed by successfully adding a base metal, a second metal, and a third metal.

You must find a valid set of three metals to form this ternary alloy.

## Input
The first line contains two integers $n$ and $m$, representing the exact number of metals in the working set and the number of certified tests, respectively, adhering to the vault and grant limits described above. Metals are identified by integers from $1$ to $n$.
Each of the next $m$ lines contains two distinct integers $u$ and $v$, indicating that the mixture of metal $u$ and metal $v$ is certified as stable.
It is guaranteed that the data contains at least one set of three metals that can be successfully mixed.

## Output
Print three integers $a$, $b$, and $c$ on a single line with $a < b < c$, representing the IDs of the three metals.
If there are multiple valid sets of three metals, output the one that is lexicographically smallest (i.e., smallest $a$; ties broken by smallest $b$; then smallest $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
I replaced the explicit pairwise requirement ("every possible two-metal combination chosen from those three") with a sequential addition process where each new metal must bond with all previously added metals. This forces the model to deduce that adding three metals sequentially requires all three to be mutually compatible (a triangle), rather than relying on the direct definition of a complete subgraph. I also moved the numeric bounds into the scenario text as physical capacities and limits.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to sequentially add three metals such that each new metal is compatible with all existing ones logically demands that all three metals are pairwise compatible, preserving the exact same valid sets of metals.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a 3-clique (triangle) in an undirected graph, which maintains the same algorithmic structure and complexity.
</PRESERVED_CLASS>
<RISK>
The phrase "bounded inherently by the total number of possible distinct pairs" might be slightly less formal than an algebraic expression, though it unambiguously refers to the combination n choose 2.
</RISK>
