# Problem C — Flight Manifest Audit

Time limit: 2 s   Memory limit: 256 MB

A cargo company relies on two transport planes to ship various industrial chemicals. Many of these chemicals are volatile when mixed, meaning certain pairs will react dangerously and must be transported on different planes.

The current shipping manifest is fundamentally flawed. To prove this, the automated safety system conducts a strict sequential audit of all possible three-chemical combinations to find a 'locked' group. A group of three chemicals is considered locked if, no matter which one of the three chemicals you exclude, the other two chemicals in the group form a reactive pair explicitly listed in the input.

The safety system evaluates every possible combination of three distinct chemicals $(a, b, c)$ with $a < b < c$. It does this in a strict sequential order: it starts with the lowest possible ID for $a$, then the lowest possible ID for $b$, and finally the lowest possible ID for $c$. For example, it checks $(1, 2, 3)$, then $(1, 2, 4)$, and so on.

The audit terminates and generates a rejection report the very first time it encounters a locked group. Any locked group that would appear later in this sequence is never evaluated. Your task is to determine the exact three chemicals that will trigger the generation of this report.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n(n-1)/2, 2 \cdot 10^5)$), representing the number of chemicals and the number of reactive pairs. Chemicals are numbered from $1$ to $n$.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$) — a pair of chemicals that react dangerously with each other. 
It is guaranteed that at least one locked group of three chemicals exists in the given data.

## Output
Print three integers $a$, $b$, and $c$ on a single line with $a < b < c$, representing the IDs of the three chemicals that trigger the rejection report.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
