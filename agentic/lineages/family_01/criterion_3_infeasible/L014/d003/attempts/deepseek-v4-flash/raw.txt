We can solve this by checking each possible triple in increasing order and stopping at the first valid one.  
Since the graph is dense enough and we only need the lexicographically smallest triangle, we can iterate over `a` from 1 to n, then `b` from `a+1` to n, then `c` from `b+1` to n, and check if all three edges exist.

To make the edge check fast, we store the graph as a set of frozensets or as an adjacency matrix using bitsets.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(n):
        for b in range(a + 1, n):
            if b not in adj[a]:
                continue
            for c in range(b + 1, n):
                if c in adj[a] and c in adj[b]:
                    print(a + 1, b + 1, c + 1)
                    return

if __name__ == "__main__":
    main()
```
