# Problem C — Flight Manifest Rejection

Time limit: 2 s
Memory limit: 256 MB

A cargo company relies on two transport planes to ship various industrial chemicals. Many of these chemicals are volatile when mixed, meaning certain pairs will react dangerously and must be transported on different planes.

The current shipping manifest is fundamentally flawed: it is impossible to divide all the chemicals between just two planes without risking a reaction. Your task is to generate an automated safety rejection report. You do not need to attempt a safe allocation; you only need to prove that no such allocation exists.

To provide this proof, you must identify a rejection certificate consisting of exactly three chemicals. A valid certificate requires three chemicals such that no two of them can be safely placed on the same plane. Because any pair chosen from these three chemicals is documented in the hazard log as dangerously reactive, distributing them across two planes will always force at least one reactive pair to share a plane. This inherently proves the overall two-plane plan is impossible.

## Input
The first line details the manifest size (the number of chemicals) and the length of the hazard log.
A manifest always contains a minimum of three chemicals, up to the warehouse's total capacity of two thousand. Chemicals are assigned sequential integer IDs starting from one.
The hazard log contains a minimum of three entries. The central server allocates memory for up to two hundred thousand entries, which serves as a hard limit, though the log will never contain more entries than the absolute number of possible unique pairs for the manifest.

Each of the subsequent lines contains two chemical identifiers, representing a pair of chemicals that react dangerously with each other. A pair is never listed more than once, and a chemical never reacts with itself.
It is guaranteed that at least one valid rejection certificate exists in the given data.

## Output
Print three integers on a single line, separated by spaces, ordered from lowest to highest, representing the IDs of the three chemicals in the rejection certificate.
If there are multiple valid certificates, you must output the one that is lexicographically smallest (i.e., the one with the lowest first ID; in case of a tie, the lowest second ID; and if still tied, the lowest third ID).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
