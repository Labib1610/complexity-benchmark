**Solution Explanation**

For three chemicals `a < b < c` to be a *locked* group every two of them must be a
reactive pair.
So the three edges `{a,b}`, `{a,c}`, `{b,c}` must all be present – the three
vertices form a **triangle** in the undirected graph given by the input.

The task is therefore:

*find the lexicographically smallest triangle*.

`n ≤ 2000`, therefore an `n × n` adjacency matrix (≈ 4 · 10⁶ booleans) easily fits
into memory.
With a matrix we can test the existence of an edge in `O(1)` time.

--------------------------------------------------------------------

#### 1.   Data representation  

For every vertex `v` we store a bit mask `adj[v]` (`int` in Python) whose
`i`‑th bit (`i` from `1` to `n`) is `1` iff the edge `{v,i}` exists.

```
adj[v] = Σ (1 << i)   over all neighbours i of v
```

The whole adjacency matrix is therefore `adj[1 … n]`.

--------------------------------------------------------------------

#### 2.   Searching the smallest triangle  

We iterate over all ordered pairs `(a,b)` with `a < b`.

```
for a = 1 … n
    for b = a+1 … n
        if edge a‑b does not exist: continue
        common = adj[a] & adj[b]          # vertices adjacent to both a and b
        # we need a vertex c > b
        low = common & ~((1 << (b+1)) - 1) # clear bits ≤ b
        if low != 0:
                c = low.bit_length() - 1   # index of the lowest set bit
                output a b c
                terminate
```

* `adj[a] & adj[b]` gives all vertices adjacent to **both** `a` and `b`.
* `~((1 << (b+1)) - 1)` is a mask whose bits `0 … b` are `0` and the rest are `1`,
  therefore `low` keeps only vertices `> b`.
* `low.bit_length() - 1` returns the index of the most‑significant set bit,
  but because all bits `≤ b` are cleared, the most‑significant bit is also the
  **smallest** vertex `c > b` (there is no larger bit set before it).

The outer loops enumerate `(a,b)` in lexicographic order, and for a fixed
pair we pick the smallest possible `c`.  
Consequently the first triangle we encounter is the lexicographically smallest
one, which we output immediately.

The algorithm runs in `O(n²)` time:
* the double loop runs at most `n·(n-1)/2 ≤ 2·10⁶` iterations,
* each iteration performs only a few bit operations (`O(1)`).

Memory consumption is `O(n)` integers (`≈ 2000` integers, each up to `2ⁿ`).

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
locked group (triangle).

---

##### Lemma 1  
For any vertices `a < b`, after the statement  
`low = common & ~((1 << (b+1)) - 1)`  
`low` is non‑zero **iff** there exists a vertex `c > b` adjacent to both `a` and `b`.

**Proof.**  
`common = adj[a] & adj[b]` has a `1`‑bit exactly at those vertices adjacent to
both `a` and `b`.  
The mask `~((1 << (b+1)) - 1)` has `0` on positions `0 … b` and `1` elsewhere.
Bitwise‑and therefore clears all bits `≤ b` and keeps bits `> b`.  
Thus `low ≠ 0` precisely when some vertex `c > b` belongs to `common`. ∎



##### Lemma 2  
If `low ≠ 0` then `c = low.bit_length() - 1` is the smallest vertex `c > b`
adjacent to both `a` and `b`.

**Proof.**  
All bits `≤ b` are zero in `low`.  
`low.bit_length()` returns the index of the most‑significant `1`‑bit plus one.
Because there is no `1`‑bit at a smaller index (all smaller indices are `≤ b`
and cleared), this most‑significant bit is also the smallest index with a `1`.
Subtracting one yields that index, i.e. the smallest admissible `c`. ∎



##### Lemma 3  
When the algorithm prints `a b c`, the three edges `{a,b}`, `{a,c}`, `{b,c}`
are all present in the input.

**Proof.**  
*Edge `{a,b}`*: the algorithm checks it before proceeding (`if not edge: continue`).
*Edges `{a,c}` and `{b,c}`*: by Lemma&nbsp;1 vertex `c` belongs to `common`,
hence `c` is adjacent to both `a` and `b`. ∎



##### Lemma 4  
The first printed triple `(a,b,c)` is the lexicographically smallest triangle
in the graph.

**Proof.**  
The outer loops enumerate all ordered pairs `(a,b)` with `a<b` in increasing
lexicographic order.  
For a fixed pair the algorithm (Lemma&nbsp;2) chooses the smallest possible
`c > b`.  
Therefore any triangle `(a',b',c')` with `(a',b')` lexicographically smaller than
the printed `(a,b)` would have been examined earlier and would have caused an
output.  
If `(a',b') = (a,b)` but `c' < c`, Lemma&nbsp;2 guarantees the algorithm would
have selected `c'` instead of `c`.  
Hence no triangle precedes the printed one lexicographically. ∎



##### Theorem  
The algorithm always terminates and outputs three integers `a<b<c` that form a
locked group, and this triple is the lexicographically smallest among all
locked groups.

**Proof.**  
*Termination*: the input guarantees at least one triangle. The double loop
covers all `a<b`; when the first triangle is found the algorithm returns,
so it certainly terminates.

*Correctness of output*: by Lemma&nbsp;3 the printed triple is a triangle,
i.e. a locked group.

*Minimality*: by Lemma&nbsp;4 the printed triple is the lexicographically
smallest triangle, therefore the required answer. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Time* : `O(n²)` ≤ `4·10⁶` elementary operations, well below the 2 s limit.  
*Memory*: `O(n)` integers (`≈ 2000`), far below the 256 MB limit.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * (n + 1)          # bit masks, 1‑based
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u] |= 1 << v
        adj[v] |= 1 << u

    for a in range(1, n + 1):
        mask_a = adj[a]
        for b in range(a + 1, n + 1):
            if not (mask_a >> b) & 1:   # edge a‑b missing
                continue
            common = mask_a & adj[b]    # neighbours of both a and b
            # keep only vertices > b
            low = common & ~((1 << (b + 1)) - 1)
            if low:
                c = low.bit_length() - 1
                sys.stdout.write(f"{a} {b} {c}")
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
