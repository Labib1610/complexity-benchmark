We can solve this by checking all triples, but that would be too slow for \( n = 2000 \).  
Instead, we can use the fact that a locked triple means every pair among the three is an edge.  
So we need to find a triangle in the graph, and among all triangles, pick the lexicographically smallest.

We can do this efficiently by iterating over possible smallest vertex `a`, then over possible second vertex `b > a`, and checking if there exists `c > b` such that all three edges exist.  
We can store adjacency as a set for fast lookup.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(n):
        for b in adj[a]:
            if b <= a:
                continue
            for c in adj[b]:
                if c <= b:
                    continue
                if c in adj[a]:
                    print(a + 1, b + 1, c + 1)
                    return

if __name__ == "__main__":
    main()
```
