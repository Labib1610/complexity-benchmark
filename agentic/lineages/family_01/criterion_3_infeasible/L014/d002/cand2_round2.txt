# Problem C — Flight Manifest Rejection

Time limit: 2 s   Memory limit: 256 MB

A cargo company uses exactly two transport planes to ship industrial chemicals. Certain pairs of chemicals are volatile and must be isolated from each other on different planes.

The provided shipping manifest is fundamentally flawed: no valid assignment of all chemicals to the two planes exists. You must generate an automated safety rejection report to prove this flaw. You do not need to process the entire manifest or attempt an allocation.

Instead, your report must pinpoint a localized contradiction. You must identify three distinct chemicals, $a$, $b$, and $c$. The rejection is only accepted if the list of chemicals volatile with $a$ includes both $b$ and $c$, and additionally, the list of chemicals volatile with $b$ includes $c$. Because any two planes can accommodate at most two mutually volatile chemicals, presenting three such chemicals formally proves the manifest cannot be fulfilled.

## Input
The first line contains two integers $n$ and $m$. The integer $n$ dictates the number of chemicals involved, bounded by a minimum flight requirement of 3 and a maximum payload capacity of 2000. The integer $m$ dictates the number of volatile pairs logged, which has a minimum of 3 and is capped by the system limit of $2 \cdot 10^5$ or the physical maximum of $n(n-1)/2$, whichever is smaller. Chemicals are assigned sequential IDs from $1$ to $n$.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$) — a pair of chemicals that react dangerously with each other. 
It is guaranteed that at least one valid trio of chemicals exists in the given data.

## Output
Print three integers $a$, $b$, and $c$ on a single line with $a < b < c$, representing the IDs of the three chemicals that form the rejection proof.
If there are multiple such groups, output the one that is lexicographically smallest (i.e., smallest $a$; ties broken by smallest $b$; then smallest $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
I replaced the scenario-based description of the two-plane obstruction ("every possible way of assigning these three... forces a listed reactive pair") with a direct mechanical specification of the adjacency lists ("volatile with $a$ includes both $b$ and $c$, and... volatile with $b$ includes $c$"). This removes the semantic hint that points models toward recognizing it as a triangle/clique, forcing them to derive the graph structure from the intersection logic. I also applied the S07 strategy by embedding the strict numeric bounds into the physical constraints of the problem description while retaining the exact digits to pass the gate.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that $a$ is volatile with $b$ and $c$, and $b$ is volatile with $c$, is mathematically identical to finding a clique of size 3 (a triangle), which is the exact same certificate required by the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks to find a triangle in an undirected graph, which remains solvable in $O(nm/64)$ using bitsets or $O(m \sqrt{m})$ using standard triangle finding, keeping it in the same complexity class.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "list of chemicals volatile with $a$ includes both $b$ and $c$" as requiring directed edges, though the input explicitly describes them as "a pair of chemicals that react dangerously with each other", which implies an undirected relationship.
</RISK>
