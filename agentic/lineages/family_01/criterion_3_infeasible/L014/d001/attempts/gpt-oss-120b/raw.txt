**Solution Explanation**

For three chemicals `a < b < c` we have to prove that *any* division of the three
into two planes creates a conflict.
The only way this can happen is that the three chemicals form a **triangle**
in the conflict graph:

```
a – b , a – c , b – c   are all reactive pairs
```

Indeed, a triangle is not 2‑colourable, therefore every 2‑colouring (plane
assignment) contains a monochromatic edge.

Consequently the task is:

*find the lexicographically smallest triangle in the given undirected graph*.

`n ≤ 2000`, `m ≤ 2·10⁵`.  
`n` is small enough to store the whole adjacency matrix, and we can also keep
for each vertex a bitset (`int`) of its neighbours – this makes the search for
the third vertex of a triangle very fast.



--------------------------------------------------------------------

#### Data structures

* `adj_bit[i]` – Python `int`, bit `v` ( `1 ≤ v ≤ n` ) is `1` iff edge `i‑v`
  exists.
* `adj_mat[i][j]` – `True/False` adjacency matrix, used only to iterate over
  pairs `a < b` in increasing order ( `O(n²)` = 4·10⁶ operations, easily fast).

--------------------------------------------------------------------

#### Algorithm
```
read n, m
build adj_bit[1..n] and adj_mat

full_mask = (1 << (n+1)) - 1          # bits 0..n set, we never use bit 0

for a = 1 .. n:
    for b = a+1 .. n:
        if not adj_mat[a][b]: continue          # not an edge, cannot be a triangle

        # vertices adjacent to both a and b
        common = adj_bit[a] & adj_bit[b]

        # we need c > b, so delete bits ≤ b
        mask = full_mask ^ ((1 << (b+1)) - 1)    # bits > b are 1
        common &= mask

        if common != 0:                          # at least one suitable c
            # lowest set bit gives the smallest possible c
            low = common & -common
            c = low.bit_length() - 1
            output a, b, c (already a<b<c)
            exit
```

The outer loops enumerate all pairs `(a,b)` in lexicographic order.
For the first pair that belongs to a triangle we immediately obtain the
smallest possible `c` (the lowest set bit after `b`).  
Therefore the first triangle found is exactly the lexicographically smallest
one required by the statement.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest triple
`(a,b,c)` that forms a triangle.

---

##### Lemma 1  
If the algorithm outputs a triple `(a,b,c)`, then `{a,b,c}` is a triangle.

**Proof.**  
The algorithm outputs only after the condition `adj_mat[a][b]` is true,
so edge `a‑b` exists.  
`common = adj_bit[a] & adj_bit[b]` contains exactly the vertices adjacent to
both `a` and `b`. After masking we keep only vertices `c > b`.  
If `common` is non‑zero, we pick a vertex `c` from it, therefore edges
`a‑c` and `b‑c` also exist. ∎



##### Lemma 2  
For a fixed pair `(a,b)` with `a<b` and edge `a‑b`, the algorithm chooses the
smallest possible `c` (`c > b`) that together with `a,b` forms a triangle.

**Proof.**  
`common` after masking contains *all* vertices `c>b` adjacent to both `a` and
`b`. The expression `common & -common` isolates the lowest set bit, i.e. the
minimum such `c`. ∎



##### Lemma 3  
Let `T` be the set of all triangles in the graph.
The algorithm outputs the lexicographically smallest element of `T`.

**Proof.**  
The double loop enumerates all ordered pairs `(a,b)` with `a<b` in increasing
lexicographic order.  
Consider the first pair `(a₀,b₀)` for which a triangle exists, i.e. there is a
`c₀` with `{a₀,b₀,c₀} ∈ T`. By Lemma&nbsp;2 the algorithm will output the
smallest such `c₀`.  
For any triangle `{a',b',c'}` with `(a',b')` lexicographically smaller than
`(a₀,b₀)` we would have found it earlier, contradicting the choice of
`(a₀,b₀)`. Hence no triangle is lexicographically smaller than the one output,
and the output triangle is the smallest in `T`. ∎



##### Lemma 4  
The graph is guaranteed to contain at least one triangle, therefore the
algorithm always finds and outputs one.

**Proof.** Directly from the problem statement. ∎



##### Theorem  
The algorithm always prints three integers `a<b<c` that form a triangle and
are the lexicographically smallest such triple in the given graph.

**Proof.**  
By Lemma&nbsp;4 a triangle exists, so the algorithm terminates with an output.
Lemma&nbsp;1 shows the output vertices indeed form a triangle.
Lemma&nbsp;3 shows this triangle is the lexicographically smallest one.
Thus the theorem holds. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building structures*: `O(m)` time, `O(n²/8)` ≈ 0.5 MB memory for the matrix,
plus `O(n)` integers for bitsets.

*Main loops*: at most `n·(n-1)/2 ≤ 2·10⁶` iterations.
All operations inside are bitwise `O(1)`.  
Hence total time `O(n²) ≤ 4·10⁶` operations, well below the 2 s limit.

Memory: adjacency matrix `n·n` booleans → ≤ 4 MB, plus bitsets negligible.
Fits into 256 MB.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    # adjacency matrix for fast pair iteration
    adj_mat = [[False] * (n + 1) for _ in range(n + 1)]
    # bitset per vertex
    adj_bit = [0] * (n + 1)

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        if u > v:
            u, v = v, u
        adj_mat[u][v] = adj_mat[v][u] = True
        adj_bit[u] |= 1 << v
        adj_bit[v] |= 1 << u

    full_mask = (1 << (n + 1)) - 1  # bits 0..n set, bit 0 unused

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if not adj_mat[a][b]:
                continue
            common = adj_bit[a] & adj_bit[b]
            # keep only vertices > b
            mask = full_mask ^ ((1 << (b + 1)) - 1)
            common &= mask
            if common:
                low = common & -common
                c = low.bit_length() - 1
                sys.stdout.write(f"{a} {b} {c}")
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
