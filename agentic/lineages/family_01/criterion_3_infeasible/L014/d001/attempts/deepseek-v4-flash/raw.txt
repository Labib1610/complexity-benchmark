We need to find the lexicographically smallest triangle in an undirected graph.  
Since \( n \) can be up to 2000 and \( m \) up to \( 2 \cdot 10^5 \), we can use an adjacency matrix (boolean) for fast edge checks.

We’ll iterate over possible smallest vertex `a` from 1 to n, then over `b > a`, and if edge exists, check for `c > b` with both edges present.  
To keep it efficient, we can use bitsets for adjacency.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [0] * (n + 1)
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u] |= (1 << v)
        adj[v] |= (1 << u)
    
    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if (adj[a] >> b) & 1:
                common = adj[a] & adj[b]
                # find smallest c > b in common
                c = b + 1
                while c <= n:
                    if (common >> c) & 1:
                        print(a, b, c)
                        return
                    c += 1

if __name__ == "__main__":
    main()
```
