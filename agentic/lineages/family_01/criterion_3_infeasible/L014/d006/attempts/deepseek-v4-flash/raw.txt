We need to find the lexicographically smallest triple \((a,b,c)\) such that the induced subgraph on these three vertices is not bipartite (i.e., contains a triangle).  

A triple is a deadlock if the three materials cannot be split into two holds without putting a prohibited pair together. That means the three vertices form a triangle in the graph.

So the problem reduces to: find the lexicographically smallest triangle in an undirected graph.

We can do this by iterating over possible smallest vertex `a` from 1 to n, then over possible second vertex `b` from `a+1` to n, and check if there is a `c > b` such that all three edges exist. To make it efficient, we can use adjacency sets.

Since n ≤ 2000, we can afford O(n^3) in the worst case if optimized, but we can do better:  
For each pair (a,b) that is an edge, we check intersection of their neighbor sets to find smallest common neighbor > b.

We'll use bitsets for fast intersection.

```python
n, m = map(int, input().split())
adj = [set() for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].add(v)
    adj[v].add(u)

for a in range(n):
    for b in range(a+1, n):
        if b in adj[a]:
            # find smallest c > b such that c in adj[a] and c in adj[b]
            common = adj[a] & adj[b]
            for c in sorted(common):
                if c > b:
                    print(a+1, b+1, c+1)
                    exit()
```
