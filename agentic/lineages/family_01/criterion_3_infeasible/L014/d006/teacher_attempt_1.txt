# Problem C — Signature Blend

Time limit: 2 s   Memory limit: 256 MB

You are developing a new fragrance using a library of $n$ distinct aromatic extracts. Due to chemical interactions, only specific pairs of extracts blend stably without degrading each other's scent profile. You have a laboratory report detailing $m$ such stable pairs.

You need to formulate a core accord. This accord must consist of exactly three distinct extracts. To ensure the fragrance does not separate over time, any extract included in the accord must be chemically stable with every other extract in the accord. This means that if you take any two extracts from your chosen three, they must appear as a stable pair in your laboratory report.

Find a set of three extracts that can form the core accord.

## Input
The first line contains two integers $n$ and $m$. The number of extracts $n$ must be enough to form an accord (at least 3) but is limited by the storage vault's 2000-vial capacity. The number of stable pairs $m$ starts from a minimum of 3 and is capped either by the theoretical maximum of all possible pairs among the $n$ extracts, or by the laboratory's $200,000$ record limit, whichever is smaller. Extracts are numbered from $1$ to $n$.

Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that extract $u$ and extract $v$ form a stable pair.

It is guaranteed that the input contains at least one valid set of three extracts for the accord.

## Output
Print three integers $a$, $b$, and $c$ on a single line with $a < b < c$, representing the IDs of the three extracts.
If there are multiple valid sets of three extracts, output the one that is lexicographically smallest (i.e., smallest $a$; ties broken by smallest $b$; then smallest $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

Applied strategy S07 to express the numeric bounds as physical limits (vial capacity, record limit) rather than bare inequalities, forcing the model to extract the constraints from the text.
</RATIONALE>

The problem still requires finding three items where every pair among them is valid, and breaking ties lexicographically, so the output for any input remains exactly the same.
</PRESERVED_ANSWER>

The core task is still finding a 3-clique (triangle) in an undirected graph, which maintains the same computational complexity and certificate-style infeasibility structure.
