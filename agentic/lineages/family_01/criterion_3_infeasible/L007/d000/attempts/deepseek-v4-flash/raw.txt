We can solve this efficiently by leveraging the fact that we only need to find any triangle, and we want the lexicographically smallest one.

A direct triple loop is too slow for \(n = 2000\), but we can represent the graph with adjacency sets and search smartly:

1. Iterate over the smallest vertex `a` from 1 to n.
2. For each vertex `b > a` that is connected to `a`, check whether any `c > b` is connected to both `a` and `b`.
3. Use adjacency sets for O(1) lookups.
4. The first match will be the lexicographically smallest because we check in sorted order.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        for b in sorted(adj[a]):
            if b > a:
                for c in sorted(adj[b]):
                    if c > b and c in adj[a]:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    main()
```
