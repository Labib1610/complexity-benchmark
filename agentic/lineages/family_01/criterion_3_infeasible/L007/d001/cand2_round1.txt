<STATEMENT>
# Problem C — Fatal Configuration

Time limit: 2 s   Memory limit: 256 MB

A complex system contains a number of modules. During stress testing, specific combinations of two modules were flagged as interfering with each other when operated simultaneously. 

The system administrator needs to isolate a fatal configuration. To do this, you must select exactly three distinct modules from the available ones. A configuration of three modules is fatal if they form a closed loop of incompatibilities—that is, the first interferes with the second, the second with the third, and the third with the first. 

You must search this space to find a fatal configuration. It is guaranteed that the system is flawed and at least one such configuration exists.

## Input
The first line contains two integers: the number of modules and the number of logged interference events. 

The system's hardware supports a maximum capacity of two thousand modules, numbered consecutively starting from one. A baseline of three modules is always installed. The diagnostic log has a maximum storage of two hundred thousand entries, and the number of events never exceeds the total number of distinct pairs that can be formed by the installed modules. At least three logs are always generated.

Each of the following lines contains two integers representing the IDs of two modules that interfere with each other. 

## Output
Print three integers on one line representing the IDs of the modules in the fatal configuration, sorted in ascending order. 
If multiple fatal configurations exist, order the three modules in each configuration from smallest to largest ID, and output the configuration that appears first in lexicographical order.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
Replaced the direct definition of a triangle ("every pair... interferes") with a description of a closed loop of size three, forcing the model to deduce that this is equivalent to finding a 3-clique. Numeric bounds were rewritten into system capacities and minimum baselines to fulfill the S07 strategy.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that three modules form a closed loop of incompatibilities is logically identical to every pair among the three interfering, maintaining the exact same valid configurations and lexicographical tie-breaking.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically first triangle (3-clique) in an undirected graph, preserving the $O(nm/64)$ bitset approach and complexity class.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "first, second, third" as implying the output must be ordered by the loop's sequence rather than sorted ascending, though the output format explicitly requires printing them sorted in ascending order.
</RISK>
