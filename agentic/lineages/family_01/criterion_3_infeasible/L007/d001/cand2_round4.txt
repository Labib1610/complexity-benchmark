# Problem C — Fatal Configuration

Time limit: 2 s   Memory limit: 256 MB

A complex system contains $n$ modules. During stress testing, $m$ specific combinations of two modules were flagged as interfering with each other when operated simultaneously. 

The system administrator needs to isolate a fatal configuration. To do this, you must select exactly three distinct modules from the $n$ available. A configuration of three modules is considered fatal if every module in the triplet is flagged as interfering with the other two modules in the triplet. 

You must search this space to find a fatal selection. It is guaranteed that the system is flawed and at least one such fatal configuration of three modules exists.

## Input
The first line contains two integers $n$ and $m$. The system requires a minimum of 3 modules to boot, and the hardware chassis provides exactly 2000 physical slots, meaning $n$ is between 3 and 2000 inclusive. The system logs a minimum of 3 interference events. The event logger has a strict storage capacity of 200,000 entries, so $m$ cannot exceed the minimum of this capacity and the total number of possible distinct module pairs.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n, u \neq v$), indicating that module $u$ and module $v$ interfere with each other. 
It is guaranteed that at least one fatal selection of three modules exists.

## Output
Print three integers $a$, $b$, and $c$ on one line with $a < b < c$ representing the modules in a fatal configuration. 
If multiple fatal configurations exist, output the one with the smallest value for $a$; if there is a tie, choose the one with the smallest value for $b$; and if still tied, the smallest value for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
