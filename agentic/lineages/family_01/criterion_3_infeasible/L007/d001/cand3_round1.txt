# Syndicate Core

Time limit: 2 s   Memory limit: 256 MB

An auditing firm is investigating a complex ledger containing $n$ corporate entities. During the preliminary sweep, $m$ specific pairs of entities were found to have perfectly reconciled cross-border transactions.

The lead investigator suspects a hidden "syndicate core". To prove this, the audit must identify exactly three distinct entities from the ledger. A selection of three entities forms a syndicate core if and only if every pair of entities within that group of three has perfectly reconciled transactions between them.

Given the volume of entities, evaluating every possible group of three is computationally demanding. You must write a program to search the audit logs and pinpoint a syndicate core. The ledger is known to be compromised, guaranteeing that at least one such group of three entities exists.

## Input
The first line provides two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$, indicating that entity $u$ and entity $v$ have perfectly reconciled transactions. 
It is guaranteed that at least one syndicate core exists.

## Output
Output three integers $a$, $b$, and $c$ on a single line, ordered such that $a < b < c$, representing the entity IDs involved in a syndicate core. 
If the ledger contains multiple syndicate cores, you must report the one with the lowest ID for $a$. If a tie remains, choose the one with the lowest ID for $b$, and if still tied, the lowest for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
