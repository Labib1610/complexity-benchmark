# Problem C — Fatal Configuration

Time limit: 2 s   Memory limit: 256 MB

A complex system is built from $n$ modules, identifying each by an integer from 1 to $n$. The hardware chassis provides exactly 2000 module bays; the system uses at least 3 modules and never exceeds the chassis capacity.

During stress testing, certain pairs of modules cause mutual interference. The testing log records $m$ such unordered pairs. The log contains at least 3 records, and its size is limited by the total number of possible pairs among the deployed modules or a strict database cap of exactly 200,000 records, whichever is smaller.

A critical failure is triggered when three distinct modules are activated together, provided that the first module interferes with the second, the second interferes with the third, and the third interferes with the first. You are guaranteed that at least one such trio exists.

Your task is to isolate a critical failure trio.

## Input
The first line contains two integers $n$ and $m$.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that module $u$ and module $v$ interfere with each other. 
It is guaranteed that at least one critical failure trio exists.

## Output
Print three integers $a$, $b$, and $c$ on one line with $a < b < c$ such that modules $a$, $b$, and $c$ form a critical failure trio. 
If multiple such trios exist, output the one with the smallest value for $a$; if there is a tie, choose the one with the smallest value for $b$; and if still tied, the smallest value for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
The description of "every pair within that selection" was replaced with a cyclic sequence of three interferences to obscure the immediate recognition of a clique. The numeric bounds were rewritten as physical chassis and database capacities to satisfy the strategy of stating bounds indirectly.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that module 1 interferes with 2, 2 with 3, and 3 with 1 under mutual interference is logically identical to all three mutually interfering, preserving the exact set of valid trios and the lexicographical tie-breaking.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the task of finding a triangle (a 3-clique) in an undirected graph, requiring the same time complexity and algorithmic approach.
</PRESERVED_CLASS>
<RISK>
The phrasing "first, second, and third" might be read as implying the output must be ordered by the cycle path rather than strictly ascending, but the Output section explicitly overrides this by mandating $a < b < c$.
</RISK>
