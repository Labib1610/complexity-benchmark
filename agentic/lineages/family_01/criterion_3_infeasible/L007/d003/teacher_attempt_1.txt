# Acoustic Resonance

Time limit: 2 s   Memory limit: 256 MB

An acoustic testing facility is evaluating $n$ tuning forks. Over the course of testing, the system generated $m$ pairwise interference reports. Each report flags two tuning forks that undergo destructive resonance when activated simultaneously.

To properly calibrate the dampening fields, the technicians must isolate a fundamental resonance triplet. Such a triplet is defined as a collection of exactly three distinct tuning forks where every combination of two forks within the collection is flagged by an interference report. 

You must analyze the logs and pinpoint a fundamental resonance triplet. Let the triplet's tuning forks be identified by their indices $a$, $b$, and $c$, ordered such that $a < b < c$. At least one such triplet is guaranteed to exist.

## Input
The first line provides $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), representing the number of tuning forks and the number of interference reports.
The following $m$ lines each contain two integers $u$ and $v$, representing a pair of tuning forks that generated an interference report.
At least one fundamental resonance triplet is guaranteed to be present.

## Output
Provide three integers $a$, $b$, and $c$ on a single line, ordered $a < b < c$, representing the forks in the fundamental resonance triplet.
If there is more than one valid triplet, output the one that minimizes $a$. If there is still a tie, minimize $b$, and if necessary, minimize $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
The original problem explicitly defined a triad as forks $a, b$ resonating, and $c$ resonating with both $a$ and $b$. This asymmetric phrasing directly suggested iterating over an edge $(a, b)$ and looking for a common neighbor $c$, which naturally leads to bitset intersections. The rewrite changes the definition to a symmetric requirement ("every combination of two forks within the collection"), forcing the model to recognize the complete subgraph structure without structural hints.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that every pair within a set of three forks has an interference report is mathematically identical to finding a 3-clique, preserving all valid triplets and tie-breakers.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a triangle in an undirected graph, which preserves the certificate-style infeasibility complexity class.
</PRESERVED_CLASS>
