# Stellar Resonances

Time limit: 2 s   Memory limit: 256 MB

An astronomical survey has cataloged $n$ celestial bodies, assigning each a unique identification number from $1$ to $n$. Analysis of their trajectories has revealed $m$ pairs of bodies that maintain a stable orbital resonance with each other.

To classify a formation as a "Ternary Resonance Cluster", astrophysicists require a set of exactly three distinct bodies $a$, $b$, and $c$, where every pair within this set is in stable orbital resonance. That means a confirmed resonance must exist between $a$ and $b$, between $b$ and $c$, and between $a$ and $c$. For cataloging purposes, the bodies in a cluster are always listed in ascending order of their IDs ($a < b < c$).

Given the large number of observations (up to 2000 bodies), manually searching the catalog is impractical. It is guaranteed that the data contains at least one Ternary Resonance Cluster. You must develop a procedure to find it.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$).
Each of the following $m$ lines contains two integers $u$ and $v$, indicating that body $u$ and body $v$ are in stable orbital resonance. 
It is guaranteed that at least one valid Ternary Resonance Cluster exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line with $a < b < c$, representing the IDs of the bodies in the cluster. 
If there is more than one valid cluster, output the one with the smallest value for $a$. If there is a tie, select the one with the smallest value for $b$. If still tied, select the one with the smallest value for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
