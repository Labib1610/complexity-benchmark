We can model the locks as an undirected graph where keys are vertices and each lock is an edge.  
We need to find a triangle (three mutually connected vertices) with the smallest lexicographic order.

A direct O(n³) check is too slow for n=2000.  
Instead, we can use adjacency sets and iterate over possible `a` and `b`, then check for a common neighbor `c > b`.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if b in adj[a]:
                # find smallest c > b that is connected to both a and b
                for c in range(b + 1, n + 1):
                    if c in adj[a] and c in adj[b]:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    main()
```
