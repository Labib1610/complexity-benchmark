# Acoustic Resonance

Time limit: 2 s   Memory limit: 256 MB

An acoustic testing chamber contains $n$ tuning forks. During testing, $m$ specific pairs of forks were found to resonate destructively when struck together. 

The engineers need to identify a destructive triad to calibrate the dampening fields. A triad is defined by three distinct tuning forks $a$, $b$, and $c$ (with $a < b < c$) where $a$ and $b$ are recorded as resonating destructively, and $c$ is recorded as resonating destructively with both $a$ and $b$.

With up to 2000 tuning forks, there are many combinations to evaluate. It is guaranteed that at least one destructive triad is present in the test data. You must process the records to find it.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$).
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that fork $u$ and fork $v$ resonate destructively. 
It is guaranteed that at least one destructive triad exists.

## Output
Print three integers $a$, $b$, and $c$ on one line with $a < b < c$ that form a destructive triad. 
If multiple destructive triads exist, output the one with the smallest value for $a$; if there is a tie, choose the one with the smallest value for $b$; and if still tied, the smallest value for $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
The models were using the phrases "every possible pair formed by these three forks" and the explicit pair listing "{a, b}, {a, c}, and {b, c}" to pattern-match the problem as "triangle finding", which immediately triggered their template for bitset adjacency intersection. By rewording the condition as "$a$ and $b$ resonate, and $c$ resonates with both", we present the exact same mathematical requirement but remove the symmetry that triggers the clique/triangle template. Models that rely on surface pattern matching will likely translate this verbatim into an $O(n^3)$ or $O(m \cdot n)$ nested loop and fail the time limit, while models that genuinely reason about algorithmic structure will still deduce that they are looking for a common neighbor and apply the $O(n \cdot m / 64)$ bitset optimization.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that $a$ and $b$ resonate, and $c$ resonates with both $a$ and $b$, is logically identical to requiring all three pairs among $a, b, c$ to resonate, so the set of valid triads and the chosen output are completely unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the task of finding a K3 subgraph (triangle) in an undirected graph, keeping it in the same complexity class.
</PRESERVED_CLASS>
