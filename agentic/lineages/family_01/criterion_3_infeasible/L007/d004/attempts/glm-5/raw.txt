To solve this problem efficiently, we need to find a triangle (3-clique) in an undirected graph with up to 2000 nodes and 200,000 edges. The key insight is that if we process nodes in increasing order and for each node `a`, we look at its neighbors `b > a`, then for each such `b`, we check if `b` shares a common neighbor `c > b` that is also a neighbor of `a`. 

To make this efficient, we can use bitsets. Since `n ≤ 2000`, we can represent the adjacency list of each node as a Python integer (bitset), where the `i`-th bit is set if there's an edge to node `i`. Then, for a candidate `a`, we iterate over its neighbors `b > a`, and compute the intersection of `adj[a]` and `adj[b]` restricted to nodes `> b`. If the intersection is non-empty, the smallest set bit gives us `c`, and since we process `a` in increasing order and `b` in increasing order, the first valid `(a, b, c)` found will be the lexicographically smallest triangle.

Here is the Python 3 solution:

```python
import sys

def solve():
    input_data = sys.stdin.read().split()
    if not input_data:
        return
    n = int(input_data[0])
    m = int(input_data[1])
    
    # Using bitsets for adjacency lists. Node indices are 1-based.
    adj = [0] * (n + 1)
    
    idx = 2
    for _ in range(m):
        u = int(input_data[idx])
        v = int(input_data[idx+1])
        idx += 2
        adj[u] |= (1 << v)
        adj[v] |= (1 << u)
        
    for a in range(1, n + 1):
        # We only consider neighbors b > a
        # To iterate over set bits in adj[a] that are > a:
        # We can mask out bits <= a
        mask_a = adj[a] & ~((1 << (a + 1)) - 1)
        
        b = a + 1
        while mask_a:
            # Get the lowest set bit in mask_a
            # This corresponds to the smallest b > a adjacent to a
            lowest_bit = mask_a & -mask_a
            b = lowest_bit.bit_length() - 1
            
            # We need c > b such that c is adjacent to both a and b
            # So we look at adj[b] & adj[a], and mask out bits <= b
            common = adj[b] & adj[a] & ~((1 << (b + 1)) - 1)
            
            if common:
                # The smallest c is the lowest set bit in common
                c = (common & -common).bit_length() - 1
                print(f"{a} {b} {c}")
                return
            
            # Remove b from mask_a to continue searching for the next b
            mask_a &= ~lowest_bit

if __name__ == "__main__":
    solve()
```
