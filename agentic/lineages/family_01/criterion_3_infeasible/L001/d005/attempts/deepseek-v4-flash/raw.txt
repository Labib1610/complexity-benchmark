We need to find the lexicographically smallest triangle in an undirected graph where vertices are compounds and edges are inert pairs.

A direct brute force over all triples would be O(n³), which is too slow for n up to 2000.  
We can instead iterate over the first vertex `a` from 1 to n, then over the second vertex `b` from `a+1` to n, and check if there is a common neighbor `c > b` that is connected to both.  
To do this efficiently, we can store adjacency as sets for O(1) neighbor checks.

Since we want the lexicographically smallest, we can break early once we find a valid triple.

Here’s the implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if b in adj[a]:
                # find smallest c > b connected to both a and b
                for c in range(b + 1, n + 1):
                    if c in adj[a] and c in adj[b]:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    solve()
```
