<STATEMENT>
# Problem C — Tri-Region Junction

Time limit: 2 s
Memory limit: 256 MB

A cartographer is analyzing a complex conceptual map divided into $n$ distinct territories. The map's layout is documented by a list of $m$ boundary records. Each record indicates that two specific territories share a direct border. 

The cartographer needs to locate a "tri-junction" — a location where exactly three territories meet. According to the rules of this map, a tri-junction is formed by a set of three territories where each territory in the set shares a direct border with both of the other two.

You are provided with the complete list of boundary records. It is guaranteed that the map contains the necessary borders to form at least one tri-junction. Your task is to identify the three territories that meet at this junction.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), representing the number of territories and the number of boundary records, respectively. Territories are assigned ID numbers from $1$ to $n$.

Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that territory $u$ and territory $v$ share a border.

It is guaranteed that at least one tri-junction can be identified.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, representing the ID numbers of the territories that form a tri-junction. The ID numbers must be printed in strictly increasing order ($a < b < c$).

If multiple tri-junctions exist, output the one that is lexicographically smallest (i.e., minimize $a$; in case of a tie, minimize $b$; and if still tied, minimize $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
Changed the scenario from magnetic modules to a map with territories and shared borders. Removed the concept of checking "every possible pair" and instead defined the required structure as a set of three territories where each shares a border with the other two. This prevents models from immediately pattern-matching to "common neighbors" or "clique" by forcing them to recognize that this mutual boundary relationship describes a triangle in the underlying graph.
</RATIONALE>
<PRESERVED_ANSWER>
The definition of three territories where each shares a border with the other two is mathematically identical to a 3-clique, so the exact same sets of three elements are valid solutions.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a $K_3$ subgraph (triangle) in an undirected graph, which has the exact same complexity class and algorithmic requirements.
</PRESERVED_CLASS>
