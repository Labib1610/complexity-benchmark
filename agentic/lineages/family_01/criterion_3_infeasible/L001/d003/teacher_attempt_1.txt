# Problem C — Synchronization Redundancy

Time limit: 2 s
Memory limit: 256 MB

A data center maintains a set of servers. Over time, bilateral synchronization operations occur between distinct servers. Each operation is recorded as a log entry linking two specific servers. Synchronization is inherently a two-way process.

To ensure minimal fault tolerance for a new distributed database, the administrators must designate a primary cluster. A primary cluster consists of exactly three servers. The group is considered valid if and only if there is no pair of servers within the group that lacks a synchronization log between them.

You are given the complete history of synchronization logs. The system guarantees that the history contains enough records to form at least one valid primary cluster. Your task is to determine the server IDs for such a cluster.

## Input
The first line contains two integers representing the total number of servers and the total number of synchronization logs, respectively. The server count is at least three, bounded by a facility capacity of two thousand. The log count is at least three, and cannot exceed the physical limit of two hundred thousand (or the theoretical maximum of one log per distinct pair of servers, if that is smaller). Servers are assigned sequential integer IDs starting from one up to the total server count.

Each of the subsequent lines corresponds to a single log and contains two distinct server IDs, indicating the two servers that synchronized.

It is guaranteed that at least one valid primary cluster exists.

## Output
Print three integers on a single line, separated by spaces, representing the IDs of the servers in the primary cluster. The IDs must be printed in strictly increasing order.

If multiple valid primary clusters exist, output the one that is lexicographically smallest (i.e., minimize the first ID; in case of a tie, minimize the second ID; and if still tied, minimize the third).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
