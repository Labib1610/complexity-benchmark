# Problem C — Containment Breach Loop

Time limit: 2 s
Memory limit: 256 MB

In a hazardous materials storage facility, certain pairs of chemical compounds are highly reactive when placed in close proximity. While the facility can manage isolated pairs of reactive compounds using specialized dual-containment bins, this system completely fails if there is a "containment breach loop". A breach loop consists of three distinct compounds, let's call them A, B, and C, such that A and B are reactive, B and C are reactive, and C and A are reactive.

Your task is to identify such a set of three compounds to demonstrate that the current storage protocols are insufficient. You are given a list of all reactive pairs.

## Input
The first line contains two integers n and m. The facility holds compounds in up to 40 identical storage units, each with a capacity of 50 compounds, so the total number of compounds n will never exceed the combined capacity of these units. The minimum possible value for n is the exact number of compounds involved in a single breach loop.
The system logs m reactive relationships. The minimum number of logged relationships is the exact number required to form a single breach loop. The maximum number of logged relationships is two hundred thousand, or the theoretical maximum number of distinct unordered pairs among the n compounds, whichever is smaller.
Compounds are assigned integer identifiers from 1 to n.
Each of the following m lines contains two distinct integers u and v, representing the identifiers of two compounds that are reactive. A compound is never listed as reactive with itself, and all identifiers are within the valid range of 1 to n.
It is guaranteed that at least one breach loop exists in the log.

## Output
Print three integers representing the identifiers of the compounds in a breach loop on a single line, separated by spaces. The identifiers must be printed in increasing order.
If there are multiple such sets, output the one that is lexicographically smallest (i.e., minimize the first identifier; in case of a tie, minimize the second; and if still tied, minimize the third).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
Changed "critical triad" to "containment breach loop" and defined it using explicit pairwise relationships (A and B, B and C, C and A) to avoid the phrase "every single pair among the three", which acts as a strong keyword trigger for graph-triangle recognition. Replaced bare numerical constraints with physical limits (e.g., 40 storage units of 50 capacity for N) and structural minimums (the size of a loop) to force the solver to derive the bounds. This forces the model to recognize the triangle structure from the pairwise mechanism rather than relying on surface patterns.
</RATIONALE>
<PRESERVED_ANSWER>
The required output is still the lexicographically smallest set of 3 mutually reactive compounds, and the input/output formats and examples are strictly unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding a triangle (K3) in a graph, which requires the same algorithmic approach and complexity.
</PRESERVED_CLASS>
<RISK>
Students might misinterpret the 40x50 storage capacity as implying a spatial grid where reactions only happen adjacently, though the wording explicitly ties it only to the total compound count `n`.
</RISK>
