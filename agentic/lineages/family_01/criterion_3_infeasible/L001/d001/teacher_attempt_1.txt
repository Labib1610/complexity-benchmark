# Problem C — Containment Breach

Time limit: 2 s
Memory limit: 256 MB

In a hazardous materials storage facility, certain pairs of chemical compounds are highly reactive when placed in close proximity. The facility manages these interactions by assigning any mutually reactive pair of compounds to a specialized dual-containment protocol. This protocol is compromised if a runaway condition occurs: a scenario where both compounds in a mutually reactive pair are also highly reactive with a third, distinct compound.

Your task is to identify a set of three compounds that create this runaway condition to demonstrate that the current storage protocols are insufficient. You are given a list of all reactive pairs. It is guaranteed that the inventory contains at least one such set of three compounds.

## Input
The first line contains two integers n and m (3 ≤ n ≤ 2000, 3 ≤ m ≤ min(n·(n−1)/2, 2·10⁵)), representing the number of compounds and the number of reactive pairs, respectively. Compounds are numbered from 1 to n.
Each of the following m lines contains two integers u and v (1 ≤ u, v ≤ n, u ≠ v), indicating that compound u and compound v are highly reactive.
It is guaranteed that at least one runaway condition exists.

## Output
Print three integers a, b, and c on a single line, separated by spaces, representing the identifiers of the three compounds involved in a runaway condition. The identifiers must be printed in increasing order (a < b < c).
If there are multiple such sets of three compounds, output the one that is lexicographically smallest (i.e., minimize a; in case of a tie, minimize b; and if still tied, minimize c).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
