# Problem C — Containment Breach

Time limit: 2 s
Memory limit: 256 MB

The chemical storage depot uses dual-containment modules to isolate pairs of volatile substances. A known vulnerability in this system is a "containment breach"—a specific configuration of three distinct substances where any two of the three are mutually volatile. If such a configuration forms, the dual-containment modules are bypassed, leading to a system failure.

A recent audit concluded that the depot's current layout is structurally compromised. Specifically, the auditors confirmed that the conditions for a containment breach are actively met within the facility. Your objective is to process the volatility logs and pinpoint the exact three substances responsible for this breach.

## Input
The first line provides two integers, $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), which represent the total number of substances and the total number of mutually volatile pairs, respectively. The substances are indexed from $1$ to $n$.
Following this are $m lines, each containing two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$). This indicates a mutual volatility between substance $u$ and substance $v$. The logs correspond to a compromised state, meaning the failure configuration described above is definitely present.

## Output
Provide a single line containing three space-separated integers $a$, $b$, and $c$, representing the indices of the three substances forming the breach. These indices must be ordered from lowest to highest ($a < b < c$).
If more than one such breach configuration exists, select the one where the primary substance index ($a$) is as small as possible. Should multiple configurations share the same primary index, minimize the secondary index ($b$), and finally the tertiary index ($c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
