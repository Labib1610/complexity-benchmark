# Problem C — Ternary Cascade

Time limit: 2 s
Memory limit: 256 MB

A chemical warehouse stores various compounds. Due to volatility, certain pairs of these compounds interact dangerously if stored in the same sector. The warehouse uses isolated dual-containment units to safely house any two interacting compounds. However, this isolation method breaks down entirely if a "ternary cascade" occurs—this happens when three distinct compounds are present such that all three mutually interact with each other (each compound interacts with the other two).

You must analyze the interaction logs to find a ternary cascade, proving the storage system is compromised. You will receive a comprehensive list of all interacting pairs.

## Input
The first line provides two integers, $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), which denote the total number of distinct compounds and the number of interacting pairs. The compounds are assigned identifiers from 1 to $n$.
The next $m$ lines each contain two integers, $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), meaning that compound $u$ and compound $v$ interact dangerously.

## Output
If a ternary cascade is present, output three space-separated integers $a$, $b$, and $c$ corresponding to the identifiers of the three compounds involved. These must be ordered such that $a < b < c$.
In the event that several ternary cascades can be formed, provide the one that is lexicographically smallest (meaning you should minimize $a$; if there is a tie, minimize $b$; and if still tied, minimize $c$).
If no ternary cascade exists in the facility, output `0 0 0`.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
