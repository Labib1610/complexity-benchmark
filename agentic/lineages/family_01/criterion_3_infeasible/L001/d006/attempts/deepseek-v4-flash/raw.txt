We can solve this by checking all triples in lexicographical order and stopping at the first valid one.  
Since `n` can be up to 2000, checking all triples naively would be too slow (`O(n^3)`).  
Instead, we can use an adjacency matrix (or bitsets) to quickly check if a triple forms a triangle.

Here’s the implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = adj[v][u] = True

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if not adj[a][b]:
                continue
            for c in range(b + 1, n + 1):
                if adj[a][c] and adj[b][c]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    solve()
```
