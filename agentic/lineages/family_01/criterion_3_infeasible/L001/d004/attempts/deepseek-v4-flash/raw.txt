We can solve this by checking each possible triple in increasing order and stopping at the first valid one.  
Since we need the lexicographically smallest, we iterate `a` from 1 to n, then `b` from `a+1` to n, then `c` from `b+1` to n, and check if all three edges exist.

To make edge checks fast, we store the graph as an adjacency matrix using bitsets (Python integers as bitmasks).

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [0] * (n + 1)
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u] |= (1 << v)
        adj[v] |= (1 << u)
    
    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if not (adj[a] >> b) & 1:
                continue
            common = adj[a] & adj[b]
            # find smallest c > b in common
            mask = common & ~((1 << (b + 1)) - 1)
            if mask:
                c = (mask & -mask).bit_length() - 1
                print(a, b, c)
                return

if __name__ == "__main__":
    main()
```
