# Problem C — Stable Core Assembly

Time limit: 2 s
Memory limit: 256 MB

A robotics factory produces $n$ different hardware modules. Through testing, they have identified $m$ pairs of modules that are magnetically compatible with each other. Magnetic compatibility is a symmetric property between two distinct modules.

To build a "stable core" for a new robot, the engineers must select exactly three modules such that all three are mutually compatible. This means within the chosen selection of three modules, every possible pair among them must be a magnetically compatible pair.

You are given the complete list of magnetically compatible pairs. It is guaranteed that the factory has enough compatible pairs to form at least one stable core. Your task is to determine the selection of modules for a stable core.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), representing the number of modules and the number of magnetically compatible pairs, respectively. Modules are assigned ID numbers from $1$ to $n$.

Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that module $u$ and module $v$ are magnetically compatible.

It is guaranteed that at least one stable core can be formed.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, representing the ID numbers of the modules in a stable core. The ID numbers must be printed in strictly increasing order ($a < b < c$).

If multiple stable cores exist, output the one that is lexicographically smallest (i.e., minimize $a$; in case of a tie, minimize $b$; and if still tied, minimize $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
