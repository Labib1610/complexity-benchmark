# Problem C — Mechanical Jam

Time limit: 2 s   Memory limit: 256 MB

You are analyzing the schematics of a prototype gearbox containing $n$ rotary modules. The schematic lists $m$ contact points where a specific pair of modules mesh together.

In a functional system, meshing modules must spin in opposite directions. However, this prototype is flawed and jammed. Your objective is to isolate the jam's source. The schematic is guaranteed to contain at least one trio of modules that form a closed mechanical loop of length three—meaning the first meshes with the second, the second with the third, and the third meshes back with the first. This creates a mechanical paradox, halting the entire system. You must identify one such trio.

## Input
The first line provides the integers $n$ and $m$. The number of rotary modules $n$ is bounded by the chassis design, which requires at least 3 modules and provides a maximum capacity equal to the total cells in a 40 by 50 grid. The number of meshing pairs $m$ is at least 3. The data logger's memory buffer restricts $m$ to at most two hundred thousand, or the mathematical maximum of distinct pairs for $n$ modules, whichever is smaller.

The following $m$ lines each contain two integers $u$ and $v$, indicating that module $u$ and module $v$ mesh together. 
The input will always contain at least one trio of modules forming a closed loop of length three.

## Output
Output three integers $a$, $b$, and $c$ on a single line, separated by spaces, with $a < b < c$. These must represent a trio where the contacts $a$–$b$, $a$–$c$, and $b$–$c$ are all present in the input. If there are multiple such trios, provide the one that is lexicographically first (prioritizing the lowest value for $a$, then the lowest for $b$, and finally $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
