# Problem C — Proof of Impossibility

Time limit: 2 s   Memory limit: 256 MB

Management is attempting to divide the factory workers into exactly two shifts, Shift 1 and Shift 2. However, the current roster of incompatible workers makes this division impossible. 

Your task is not to attempt a schedule, but to provide a certificate of this impossibility. The incompatibility data is guaranteed to contain at least one trio of workers in which every worker is incompatible with the other two. The existence of such a trio definitively proves that two shifts are not enough. You must find and output one such trio.

## Input
The first line contains two integers n and m (3 ≤ n ≤ 2000, 3 ≤ m ≤ min(n·(n−1)/2, 2·10⁵)), representing the number of workers and the number of incompatibility records, respectively.
Each of the next m lines contains two integers u v — a pair of incompatible workers.
It is guaranteed that at least one such trio of mutually incompatible workers exists.

## Output
Print the three worker IDs of the trio on a single line, separated by spaces, in ascending order. If there are multiple valid trios, you must output the trio that yields the minimum possible value for $X \cdot 10^8 + Y \cdot 10^4 + Z$, where $X, Y,$ and $Z$ are the trio's worker IDs sorted such that $X < Y < Z$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
