# Problem C — Proof of Impossibility

Time limit: 2 s   Memory limit: 256 MB

The factory still has only two shifts, 1 and 2, but the roster is known to be hopeless. Your job is not to schedule — it is to certify the impossibility. A known proof that two shifts cannot suffice is a set of three distinct conflict records that, collectively, involve exactly three distinct workers. It is guaranteed that the data contains at least one such configuration. Output the identifiers of the three workers.

## Input
The first line contains two integers n and m (3 ≤ n ≤ 2000, 3 ≤ m ≤ min(n·(n−1)/2, 2·10⁵)).
Each of the next m lines contains two integers u v — a conflicting pair. The given pairs are unique (no duplicate or reversed records are present).
It is guaranteed that at least one valid configuration of three workers exists.

## Output
Print three integers a b c on one line with a < b < c representing the identifiers of the three workers. These three workers must have the property that the input contains three distinct conflict records such that both individuals in each of those three records belong to the set {a, b, c}. Output the lexicographically smallest such triplet (smallest a; ties by smallest b; then smallest c).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
Changed the explicit requirement that "each worker conflicts with both of the other two" to an indirect structural definition: "three distinct conflict records that collectively involve exactly three distinct workers." This forces the model to deduce that three edges among three vertices in a simple graph form a triangle, removing the surface-level wording that triggers memorised triangle-finding templates.
</RATIONALE>
<PRESERVED_ANSWER>
Any set of exactly three distinct conflict records involving exactly three distinct workers in a graph with unique edges must form a triangle, which is exactly the same condition as the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a 3-clique in a graph to certify non-2-colorability, preserving the INFEASIBLE complexity class and making the bitset adjacency approach optimal.
</PRESERVED_CLASS>
<RISK>
Models might be confused about whether conflict records are directed or undirected, but the added clarification that pairs are unique regardless of order resolves this.
</RISK>
