# Stable Ternary Blend

Time limit: 2 s   Memory limit: 256 MB

You are formulating a new liquid solution from a catalog of distinct chemical compounds, identified by integers starting from 1 up to $n$. The catalog inventory is stored across up to 20 shelves, each capable of holding exactly 100 distinct compounds, meaning the total number of compounds $n$ never exceeds full capacity, though there are always at least 3. You are provided with experimental data documenting $m$ specific pairs of compounds that are compatible (they mix perfectly without separating). The database system allocates memory for up to 200 blocks of 1,000 compatibility records each, capping the total number of records $m$ at this combined physical limit (or the theoretical limit of all possible pairs, whichever is smaller), and always contains at least 3 records.

Your goal is to create a stable ternary blend, which must consist of exactly three distinct compounds. For the blend to succeed, any compound you include must have a verified compatibility with any other compound you include in the blend. If even one pair among the chosen three lacks a compatibility record, the blend fails.

You must identify a valid combination of three compounds to form this blend. If multiple valid combinations exist, you must prioritize the one with the smallest identifier for the first compound; in case of a tie, the smallest for the second; and finally the smallest for the third, when the three identifiers are listed in ascending order.

## Input
The first line contains two integers $n$ and $m$, representing the total number of chemical compounds and the number of verified compatible pairs. The bounds for $n$ and $m$ correspond to the physical limits of the inventory and database described above.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that compound $u$ and compound $v$ are compatible.
It is guaranteed that at least one stable ternary blend can be formed.

## Output
Print three integers $a$, $b$, and $c$ on a single line, ordered such that $a < b < c$. These must represent three compounds that form a stable blend according to the rules above. If there are multiple valid blends, output the one with the smallest $a$; if there is a tie, the smallest $b$; and finally the smallest $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

Additionally, the phrase "every possible pair must be listed" was replaced with "any compound you include must have a verified compatibility with any other compound you include in the blend," removing the explicit pairwise graph-clique affordance while preserving the logical requirement.
</RATIONALE>
