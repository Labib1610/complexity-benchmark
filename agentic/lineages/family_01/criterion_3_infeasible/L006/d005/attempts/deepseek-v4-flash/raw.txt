We can solve this by iterating over possible first sensor `a` from `1` to `n`, then checking its neighbors for possible `b` and `c`.  

We can store the graph as an adjacency matrix (since `n ≤ 2000`, a 2D boolean list is fine) and also as adjacency sets for fast intersection checks.

Here’s the implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)

    for a in range(1, n + 1):
        for b in adj[a]:
            if b <= a:
                continue
            common = adj[a] & adj[b]
            if common:
                c = min(common)
                if c > b:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    solve()
```
