# Rigid Structural Node

Time limit: 2 s   Memory limit: 256 MB

You are constructing a space frame using a set of $n$ unique structural struts, which are identified by integers from 1 to $n$. An engineering chart provides $m$ pairs of struts that are permitted to share a connection.

Your objective is to build a rigid central hub by selecting exactly three distinct struts. The hub design incorporates three separate locking pins, with one pin dedicated to each of the three possible pairs formed by the chosen struts. A pin can only be secured if the specific pair of struts it holds is listed in the engineering chart. The central hub is considered rigid if and only if all three pins are successfully secured.

Determine a valid combination of three struts that can form this hub. Should there be more than one viable combination, you must select the one that appears first lexicographically.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), representing the total number of struts and the number of permitted pairs.
The following $m$ lines each contain two integers $u$ and $v$, specifying a pair of struts that appear in the engineering chart.
It is guaranteed that at least one valid combination of three struts exists.

## Output
Output three integers $a$, $b$, and $c$ on a single line, sorted such that $a < b < c$. These integers must represent a combination of three struts capable of forming the rigid hub. If multiple combinations are valid, output the one with the smallest $a$; if tied, the smallest $b$; and finally the smallest $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
The phrase "mutually compatible" and the explicit statement that each strut must connect to both others allowed models to immediately map the problem to finding a triangle (a clique of size 3). I replaced this with an explanation of a physical hub mechanism requiring three pins, one for each pair, which forces the model to construct the pairwise relationship from the physical constraints rather than matching a standard graph theory definition.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that all three possible pairs among the three chosen struts must appear in the input list is mathematically identical to the original mutual compatibility condition, ensuring the exact same triples are considered valid.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a 3-clique in an undirected graph, maintaining the $O(nm/w)$ complexity using bitsets.
</PRESERVED_CLASS>
<RISK>
Models might misunderstand "one pin dedicated to each of the three possible pairs" if they fail to recognize that exactly three distinct pairs are formed by three elements, though the wording specifies this as clearly as possible without using combinatorial jargon.
</RISK>
