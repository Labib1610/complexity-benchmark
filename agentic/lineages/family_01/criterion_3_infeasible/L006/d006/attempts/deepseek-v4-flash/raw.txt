We need to find the lexicographically smallest triangle in an undirected graph.  
Since \( n \leq 2000 \), we can afford an \( O(n^2) \) approach with adjacency sets for fast lookups.

We’ll iterate over possible smallest vertex `a` from 1 to n, then over possible `b > a`, and check if there is a `c > b` such that all three edges exist.  
To keep it efficient, we use adjacency sets and break early when we find the first valid triangle.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if b not in adj[a]:
                continue
            # find smallest c > b connected to both a and b
            for c in range(b + 1, n + 1):
                if c in adj[a] and c in adj[b]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    solve()
```
