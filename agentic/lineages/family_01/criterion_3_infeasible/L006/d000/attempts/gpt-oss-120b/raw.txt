**Solution Explanation**

For every artifact we keep the set of artifacts that are incompatible with it.
`n ≤ 2000`, therefore a set can be stored as a bit mask inside one Python integer
(2000 bits < 2 KB).

A triangle `a<b<c` exists **iff**

* `a` is incompatible with `b`
* `c` is incompatible with both `a` and `b`

For a fixed pair `(a,b)` the common neighbours are

```
common = neighbours[a] ∧ neighbours[b]
```

All vertices in `common` are incompatible with both `a` and `b`.
If `common` contains a vertex `c>b` we have found a required triangle.

To obtain the lexicographically smallest triangle we simply try the pairs
`(a,b)` in increasing order:

```
for a = 1 … n‑2
    for b = a+1 … n‑1
        if edge (a,b) exists
            common = neighbours[a] & neighbours[b]
            erase all vertices ≤ b from common
            if something remains -> the smallest remaining vertex is the wanted c
```

The first triangle discovered this way is the answer, because

* `a` is minimal (outer loop)
* for this `a`, `b` is minimal (inner loop)
* for this `(a,b)`, the smallest possible `c` is chosen.

`n = 2000` ⇒ at most ~2 · 10⁶ pairs, each processed by a few bit operations – well
inside the limits.



--------------------------------------------------------------------

#### Algorithm
```
read n , m
neigh[1…n] = 0                         // integer bit masks, bit i‑1 corresponds to vertex i

for each edge (u,v):
        neigh[u] |= 1 << (v-1)
        neigh[v] |= 1 << (u-1)

for a = 1 … n-2:
        mask_a = neigh[a]
        for b = a+1 … n-1:
                if not (mask_a >> (b-1)) & 1:            // edge a‑b does not exist
                        continue
                common = mask_a & neigh[b]                // vertices adjacent to both
                # erase vertices ≤ b
                common >>= b                               // now bit 0 corresponds to vertex b+1
                if common != 0:
                        # lowest set bit = smallest c > b
                        low = common & -common
                        offset = low.bit_length() - 1    # zero‑based inside shifted mask
                        c = b + 1 + offset
                        output a, b, c
                        exit
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
triangle.

---

##### Lemma 1  
For any vertices `a<b`, after the statement  
`common = neighbours[a] & neighbours[b]`  
the set of vertices represented by `common` equals  
`{ v | v is adjacent to both a and b }`.

**Proof.**  
Bit `v-1` is set in `neighbours[a]` iff edge `(a,v)` exists, likewise for `b`.  
Bitwise `AND` keeps a bit only if it is set in both masks, i.e. iff both edges
exist. ∎



##### Lemma 2  
After `common >>= b` the bits that remain set correspond exactly to the vertices
`c` such that `c>b` and `c` is adjacent to both `a` and `b`.

**Proof.**  
Right shift by `b` discards bits `0 … b‑1`, i.e. vertices `1 … b`.  
All higher bits keep their relative order, now representing vertices `b+1, b+2,
…`. By Lemma&nbsp;1 those bits are set precisely for vertices adjacent to both
`a` and `b`. ∎



##### Lemma 3  
If `common` is non‑zero after the shift, the algorithm’s computation of `c`
returns the smallest vertex `c>b` adjacent to both `a` and `b`.

**Proof.**  
`low = common & -common` isolates the least‑significant set bit of `common`,
which corresponds to the smallest remaining vertex.  
`low.bit_length()‑1` gives its zero‑based index inside the shifted mask,
i.e. `c-(b+1)`. Adding `b+1` yields exactly that minimal vertex `c`. ∎



##### Lemma 4  
When the algorithm outputs a triple `(a,b,c)`, it is a triangle
(`a<b<c` and all three edges are present).

**Proof.**  
`b` is selected only if edge `(a,b)` exists (explicit test).  
By Lemma&nbsp;3, `c>b` and `c` belongs to the set `common` after the shift,
hence (by Lemma&nbsp;2) edge `(a,c)` and edge `(b,c)` both exist. ∎



##### Lemma 5  
Let `T` be the triangle output by the algorithm and `T'` any triangle in the
graph. Then `T` is lexicographically not larger than `T'`.

**Proof.**  
Consider the outer loop: the algorithm examines `a = 1,2,…`.  
If a triangle with first vertex `a₀` exists, the algorithm will reach `a=a₀`
before any larger first vertex.  

Inside this `a₀`, the inner loop checks `b = a₀+1, a₀+2,…`.  
For a triangle with vertices `(a₀,b₀,c₀)` we have `b₀ ≥ a₀+1`.  
The algorithm reaches `b=b₀` no later than any larger `b`.  

When the pair `(a₀,b₀)` is processed, Lemma&nbsp;3 yields the smallest possible
`c` larger than `b₀` that forms a triangle with `a₀,b₀`. Therefore the produced
triple `(a₀,b₀,c)` satisfies `c ≤ c₀`.  

Consequently the first triple found (the algorithm’s output) is ≤ any other
triangle in lexicographic order. ∎



##### Theorem  
The algorithm always outputs the lexicographically smallest triple
`a<b<c` such that all three edges exist.

**Proof.**  
Existence: the statement guarantees at least one triangle; by Lemma&nbsp;4
the algorithm outputs a triangle whenever it finds one, and the loops eventually
examine the pair of its first two vertices, so it will output something.

Minimality: by Lemma&nbsp;5 the produced triangle is not larger than any other
triangle, i.e. it is the lexicographically smallest. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building masks*: `O(m)` bit operations.  
*Search*: outer loop `n` (`≤2000`), inner loop up to `n` → `O(n²)` iterations.
Each iteration does a constant number of integer operations (`>>`, `&`, etc.).
Thus total time `O(n² + m) ≤ O(4·10⁶)` – well below 2 s.

Memory: `n+1` integers, each ≤ 2ⁿ bits → `< 2000·2000 / 8 ≈ 0.5 MB`.  
Overall memory `O(n)`.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    # neighbour masks, 1‑based indexing, bit i‑1 corresponds to vertex i
    neigh = [0] * (n + 1)

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        bit_u = 1 << (v - 1)
        bit_v = 1 << (u - 1)
        neigh[u] |= bit_u
        neigh[v] |= bit_v

    for a in range(1, n - 1):
        mask_a = neigh[a]
        for b in range(a + 1, n):
            # check edge a‑b
            if not (mask_a >> (b - 1)) & 1:
                continue
            common = mask_a & neigh[b]   # vertices adjacent to both a and b
            # keep only vertices > b
            common >>= b
            if common:
                # lowest set bit -> smallest c
                low = common & -common
                offset = low.bit_length() - 1
                c = b + 1 + offset
                sys.stdout.write(f"{a} {b} {c}")
                return

if __name__ == "__main__":
    solve()
```

to the required input‑output format.
