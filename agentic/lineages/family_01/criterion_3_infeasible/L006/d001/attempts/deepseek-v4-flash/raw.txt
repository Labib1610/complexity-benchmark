We can solve this by checking each possible triple in lexicographic order and verifying if all three edges exist. Since n ≤ 2000, a direct O(n³) check is too slow, but we can use an adjacency matrix (or set) to check edges in O(1).

We iterate over `a` from 1 to n, then `b` from `a+1` to n, then `c` from `b+1` to n, and check if all three edges exist. The first found triple is the lexicographically smallest.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = adj[v][u] = True

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if not adj[a][b]:
                continue
            for c in range(b + 1, n + 1):
                if adj[a][c] and adj[b][c]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
