**Solution Explanation**

For every employee we keep the set of his/her neighbours (the employees with
which a grievance is filed).  
A *trilateral impasse* is a triangle in this undirected graph.

The required triangle has to be the lexicographically smallest one,
i.e. the smallest possible `a`, then `b`, then `c` (`a < b < c`).

--------------------------------------------------------------------

#### 1.   Data structure – bitset

`n ≤ 2000`, therefore a whole adjacency row fits into a 2000‑bit integer.
For a vertex `v`

```
adj_bit[v]  – integer, bit i is 1  ⇔  (v , i) is an edge
```

All operations on a whole row are done by a single CPU instruction
(`&`, `>>`, …) and are therefore very fast.

In addition we store for every vertex a **sorted list** of its neighbours,
needed to iterate `b` in increasing order.

--------------------------------------------------------------------

#### 2.   Searching the smallest triangle

```
for a = 0 … n-1
        for every neighbour b of a with b > a   (list is sorted)
                common = adj_bit[a] & adj_bit[b]          # vertices adjacent to both
                # we need a vertex c > b
                t = common >> (b+1)                       # delete bits ≤ b
                if t != 0:
                        low = t & -t                       # lowest set bit of t
                        c = (b+1) + (low.bit_length() - 1)
                        output (a+1, b+1, c+1) and stop
```

*Why does the first found triangle satisfy the lexicographic order?*

* `a` grows from the smallest possible value.
* for a fixed `a` the neighbours `b` are processed increasingly,
  therefore the first `b` that can be completed to a triangle is the smallest
  possible `b`.
* for this pair `(a,b)` we explicitly take the smallest `c > b`.

Hence the algorithm returns exactly the required triangle.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest triangle.

---

##### Lemma 1  
For fixed vertices `a < b` the expression  

```
t = (adj_bit[a] & adj_bit[b]) >> (b+1)
```

has a set bit at position `k` (0‑based) **iff** vertex `c = b+1+k` is adjacent
to both `a` and `b` and `c > b`.

**Proof.**  
`adj_bit[a] & adj_bit[b]` has a 1 exactly at positions of common neighbours.
Shifting right by `b+1` discards bits `0 … b`.  
Thus a remaining 1 at position `k` corresponds to original position `b+1+k`,
i.e. a vertex `c > b` adjacent to both `a` and `b`. ∎



##### Lemma 2  
If `t ≠ 0` then  

```
c = (b+1) + ( (t & -t).bit_length() - 1 )
```

is the smallest vertex `c > b` adjacent to both `a` and `b`.

**Proof.**  
`low = t & -t` isolates the lowest set bit of `t`.  
`low.bit_length() - 1` equals its index `k`.  
By Lemma&nbsp;1 the vertex `c = b+1+k` is a common neighbour and any smaller
index would correspond to a cleared bit, i.e. no such vertex. ∎



##### Lemma 3  
When the algorithm prints a triple `(a,b,c)` it is a triangle
(`a<b<c` and all three edges exist).

**Proof.**  
`b` is taken from the neighbour list of `a`, therefore edge `(a,b)` exists.
`c` is obtained as in Lemma&nbsp;2, hence it is adjacent to both `a` and `b`.
All three vertices are distinct and ordered because `a<b<c`. ∎



##### Lemma 4  
Let `T* = (a*,b*,c*)` be the lexicographically smallest triangle.
The algorithm will output a triangle and the first printed triangle equals `T*`.

**Proof.**  
Consider the outer loop iteration with `a = a*`.  
All smaller `a` cannot start a triangle (otherwise that triangle would be
lexicographically smaller than `T*`).  
Inside this iteration the inner loop processes neighbours `b` of `a*` in
increasing order.  
All `b < b*` cannot be completed to a triangle, otherwise `(a*,b,·)` would be
lexicographically smaller than `T*`.  
When `b = b*` is examined, Lemma&nbsp;1 guarantees that `c*` appears in the
bitset of common neighbours, therefore `t ≠ 0`.  
By Lemma&nbsp;2 the algorithm chooses the smallest possible `c`,
which is exactly `c*`.  
Thus the first printed triangle is `(a*,b*,c*)`. ∎



##### Theorem  
The algorithm always terminates and prints the lexicographically smallest
triangle of the given graph.

**Proof.**  
The graph contains at least one triangle, so during the double loop a pair
`(a,b)` belonging to some triangle will be reached, making `t ≠ 0` and causing
termination (Lemma&nbsp;3).  
By Lemma&nbsp;4 the triangle printed at that moment is the lexicographically
smallest one. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building the structures*  

```
O(m)   – reading edges, setting bits
O(n + m log m) – sorting neighbour lists (total size 2m)
```

`n ≤ 2000`, `m ≤ 2·10⁵`, easily fits.

*Search*  

For every edge `(a,b)` with `a<b` we perform a constant‑time bitwise `&`
and a few integer operations.  
Number of such directed pairs ≤ `m`.  

```
Time   :  O(m)
Memory :  n integers (≈ 2000·2000/8  ≈ 0.5 MiB) + adjacency lists
```

Both limits satisfy the problem constraints.

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj_bits = [0] * n          # bitset for each vertex
    neigh = [[] for _ in range(n)]

    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        # set bits
        adj_bits[u] |= 1 << v
        adj_bits[v] |= 1 << u
        neigh[u].append(v)
        neigh[v].append(u)

    for i in range(n):
        neigh[i].sort()

    for a in range(n):
        ba = adj_bits[a]
        for b in neigh[a]:
            if b <= a:
                continue
            common = ba & adj_bits[b]
            # delete bits <= b
            t = common >> (b + 1)
            if t:
                low = t & -t               # lowest set bit
                c = (b + 1) + (low.bit_length() - 1)
                # output in 1‑based, increasing order
                sys.stdout.write(f"{a+1} {b+1} {c+1}")
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
