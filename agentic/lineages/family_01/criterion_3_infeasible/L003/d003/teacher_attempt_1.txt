<STATEMENT>
# Tripartite Association Discovery

Time limit: 2 s   Memory limit: 256 MB

You are analyzing a dataset of symmetric associations between items. The items are identified by contiguous integers starting from 1 up to a maximum item ID of $n$. The system architecture guarantees that the item count $n$ is at least 3, and is capped by a hard internal limit of two thousand items.

The dataset contains $m$ records, where each record specifies an unordered pair of items that are associated with each other. The record count $m$ is at least 3. To prevent storage overflow, the database enforces a strict upper limit of two hundred thousand records (naturally, the number of records will not exceed the maximum possible number of distinct pairs for the given $n$). 

Your objective is to locate exactly three distinct items such that every possible pair formed from these three items is present as a record in the dataset. Previous analysis confirms that the dataset contains at least one such group of three items.

## Input
The first line of input provides the item count $n$ and the record count $m$.
This is followed by $m$ lines, each containing two integers $u$ and $v$ representing an associated pair of items.
It is guaranteed that a valid group of three items exists.

## Output
Output a single line containing three integers $a$, $b$, and $c$, sorted in ascending order ($a < b < c$), representing the three items. If there are multiple valid groups, output the one that is lexicographically smallest (i.e., smallest $a$; in case of a tie, smallest $b$; then smallest $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
