We need to find three distinct vertices that form a triangle in the graph, and among all such triangles, output the lexicographically smallest sorted triple.

A direct approach: iterate over all possible triples in sorted order and check if they form a triangle. Since n ≤ 2000, O(n³) is too slow. But we can iterate over the first vertex `a` from 1 to n, then the second `b` from a+1 to n, and check if there is a common neighbor `c > b` that is connected to both. To keep it efficient, we can use adjacency sets for O(1) edge checks.

We want the lexicographically smallest triple, so we can break early as soon as we find one.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if b not in adj[a]:
                continue
            # find smallest c > b such that a-c and b-c exist
            for c in range(b + 1, n + 1):
                if c in adj[a] and c in adj[b]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
