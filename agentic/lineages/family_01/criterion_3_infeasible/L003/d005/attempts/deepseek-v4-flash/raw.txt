We need to find a triangle in the graph, and among all triangles, output the lexicographically smallest one.

A triangle is a set of three vertices where each pair is connected by an edge.  
We can iterate over all possible triples in increasing order and check if they form a triangle.  
Since \( n \) can be up to 2000, checking all triples naively would be \( O(n^3) \), which is too slow.

Instead, we can use an adjacency matrix (or set) to check edges in \( O(1) \), and iterate over edges to find a triangle efficiently.

**Approach:**
- Build an adjacency matrix (boolean) for \( O(1) \) edge checks.
- Iterate over all edges \((u, v)\) with \( u < v \).
- For each such edge, check if there exists a vertex \( w > v \) such that both \((u, w)\) and \((v, w)\) are edges.
- The first such triple found (in increasing order of \( u, v, w \)) will be the lexicographically smallest triangle.

Since we iterate edges in increasing order of \( u \) then \( v \), and for each we check \( w \) in increasing order, the first found is the answer.

**Complexity:**  
- Building adjacency matrix: \( O(n^2) \)  
- Checking edges: \( O(m \cdot n) \) worst-case, but with early exit it's fine for \( n \leq 2000, m \leq 2\cdot 10^5 \).

Here’s the implementation:

```python
n, m = map(int, input().split())
adj = [[False] * (n + 1) for _ in range(n + 1)]
edges = []

for _ in range(m):
    u, v = map(int, input().split())
    adj[u][v] = adj[v][u] = True
    if u > v:
        u, v = v, u
    edges.append((u, v))

edges.sort()

for u, v in edges:
    for w in range(v + 1, n + 1):
        if adj[u][w] and adj[v][w]:
            print(u, v, w)
            exit()
```
