**Solution Explanation**

For every worker we store the set of his opponents as a bit mask.
Vertex `v` corresponds to bit `v‑1` (0‑based).

```
adj[v]  – integer, bit i is 1  ⇔  there is an edge (v , i+1)
```

A triangle `{a,b,c}` (`a<b<c`) exists iff  

* edge (a,b) exists,
* there is a vertex `c` that is adjacent to **both** `a` and `b`,
* `c > b`.

For a fixed ordered pair `(a,b)` the set of common neighbours is

```
common = adj[a] & adj[b]                # bitwise AND
```

We need the smallest `c > b`.  
All bits with index `< b` are cleared by the mask `-1 << b`
(`…111000` with the first `b` zeroes).  

```
candidate = common & (-1 << b)
```

If `candidate` is non‑zero, its lowest set bit is the wanted `c`.

```
low = candidate & -candidate            # lowest 1‑bit
c   = low.bit_length()                 # 1‑based vertex number
```

The algorithm scans all ordered pairs `(a,b)` in lexicographic order
(`a = 1 … n`, `b = a+1 … n`).  
The first triangle found is therefore the lexicographically smallest
one required by the statement.

`n ≤ 2000`, thus the double loop runs at most `n·(n-1)/2 ≈ 2·10⁶`
iterations – easily fast enough.  
All operations inside the loop are O(1) bitwise integer operations.

#### Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically
smallest triangle.

---

##### Lemma 1  
For any ordered pair of vertices `(a,b)` with `a<b` the algorithm
detects a vertex `c` (if it exists) such that `{a,b,c}` is a triangle and
`c` is the smallest vertex larger than `b` that forms a triangle with
`a` and `b`.

**Proof.**  
`common = adj[a] & adj[b]` contains precisely the vertices adjacent to
both `a` and `b`.  
`candidate = common & (-1 << b)` removes all vertices whose index
`≤ b-1`, i.e. all vertices `≤ b`.  
If `candidate ≠ 0`, its lowest set bit corresponds to the smallest
remaining vertex `c`.  
Since `c` belongs to `common`, edges `(a,c)` and `(b,c)` exist, therefore
`{a,b,c}` is a triangle. ∎



##### Lemma 2  
If the algorithm prints a triple `(a,b,c)`, then `{a,b,c}` is a triangle
and `a<b<c`.

**Proof.**  
The outer loops guarantee `a<b`.  
By Lemma&nbsp;1 the printed `c` is taken from `candidate`,
hence `c>b`.  
Again by Lemma&nbsp;1 edges `(a,b)`, `(a,c)`, `(b,c)` all exist,
so the three vertices form a triangle. ∎



##### Lemma 3  
Let `T = (a₀,b₀,c₀)` be the lexicographically smallest triangle in the
graph. The algorithm will output `T`.

**Proof.**  
Consider the moment the outer loops reach the pair `(a₀,b₀)`.  
Since `(a₀,b₀)` is an edge of `T`, the inner test succeeds.
By Lemma&nbsp;1 the algorithm finds the smallest `c>b₀` that together
with `a₀,b₀` forms a triangle. Because `T` is the lexicographically
smallest triangle, this `c` must be exactly `c₀`.  
Consequently the algorithm prints `(a₀,b₀,c₀)` and terminates before
any later pair is examined. ∎



##### Lemma 4  
The algorithm never prints a triangle that is lexicographically larger
than the smallest one.

**Proof.**  
Assume it prints a triangle `T' = (a',b',c')` with
`(a',b')` lexicographically larger than `(a₀,b₀)` of the smallest
triangle `T`.  
Since the loops examine pairs in increasing order, they would have
already processed `(a₀,b₀)` earlier. By Lemma&nbsp;1 a triangle would have
been found at that moment (namely `T`), causing the algorithm to stop
before reaching `(a',b')`. Contradiction. ∎



##### Theorem  
The algorithm outputs exactly the lexicographically smallest triple of
workers that mutually conflict.

**Proof.**  
Existence: the input guarantees at least one triangle, so the loops will
eventually encounter its smallest edge pair and, by Lemma&nbsp;1,
output a triangle.  
Uniqueness & minimality: by Lemma&nbsp;2 the printed triple is a
triangle; by Lemma&nbsp;3 it is the smallest one; by Lemma&nbsp;4 no
larger triangle can be printed. ∎

#### Complexity Analysis  

*Building adjacency masks* – `O(m)`  
*Double loop* – at most `n·(n-1)/2 ≤ 2·10⁶` iterations, each O(1)  

```
Time   :  O(n² + m)   ≤ 2·10⁶  operations  (well below 2 s)
Memory :  O(n)        (n+1 integers, each ≤ 2ⁿ⁰⁰⁰)
```

Both limits satisfy the problem constraints.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    # adjacency bit masks, 1‑based indexing
    adj = [0] * (n + 1)

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u] |= 1 << (v - 1)
        adj[v] |= 1 << (u - 1)

    for a in range(1, n + 1):
        mask_a = adj[a]
        for b in range(a + 1, n + 1):
            # edge (a,b) ?
            if (mask_a >> (b - 1)) & 1:
                common = mask_a & adj[b]
                # keep only vertices with index >= b  (i.e. vertex number > b)
                candidate = common & (-1 << b)
                if candidate:
                    low = candidate & -candidate          # lowest set bit
                    c = low.bit_length()                  # vertex number (1‑based)
                    # a < b < c holds automatically
                    sys.stdout.write(f"{a} {b} {c}")
                    return

if __name__ == "__main__":
    solve()
```
