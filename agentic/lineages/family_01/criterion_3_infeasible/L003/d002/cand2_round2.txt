# Problem C — Shift Feasibility Certificate

Time limit: 2 s   Memory limit: 256 MB

The factory management is attempting to divide its workforce into two non-overlapping shifts. However, this division is impossible, and management requires a formal certificate of this infeasibility. You are provided with a list of recorded disputes between pairs of workers. Two workers with a recorded dispute cannot be placed in the same shift. 

To prove that a two-shift schedule cannot be formed, you must locate a specific dysfunction pattern: a set of three workers such that each pair among them conflicts. Because each of the three conflicts with the other two, they cannot be split across only two shifts. 

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), representing the number of workers and the number of recorded disputes, respectively.
Each of the following $m$ lines contains two integers $u$ and $v$, indicating a dispute between worker $u$ and worker $v$.
It is guaranteed that the provided records contain at least one such set of three mutually conflicting workers.

## Output
Print three integers $a$, $b$, and $c$, separated by spaces, on a single line such that $a < b < c$. These three workers must form a set where all three pairwise disputes exist. If multiple valid sets exist, output the lexicographically smallest sequence (the one with the smallest $a$; in case of a tie, the smallest $b$; and if still tied, the smallest $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
