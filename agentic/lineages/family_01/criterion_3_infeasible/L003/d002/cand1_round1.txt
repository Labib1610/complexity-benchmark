# Problem C — Roster Evaluation

Time limit: 2 s   Memory limit: 256 MB

The factory management is reviewing the worker roster to detect a particular pattern of dysfunction. You are given a log of documented conflicts between specific pairs of workers. Your objective is to analyze these records and identify a three-person deadlock. This occurs when exactly three workers are involved in a situation where each individual in the trio has a documented conflict with both of the other members of that same trio.

Your job is to find and output the members of such a group. If no such group can be found in the provided records, you must output `0 0 0`.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), which stand for the total number of factory workers and the number of documented conflicts, respectively.
Each of the subsequent $m$ lines provides two integers $u$ and $v$, showing that a conflict is documented between worker $u$ and worker $v$.

## Output
Output three space-separated integers $a$, $b$, and $c$ on a single line, ordered such that $a < b < c$. These integers must represent the IDs of three workers forming a three-person deadlock. If there is more than one such trio, provide the one that is lexicographically smallest (first minimizing $a$, then $b$, and finally $c$). If the records do not contain any three-person deadlocks, output `0 0 0`.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
