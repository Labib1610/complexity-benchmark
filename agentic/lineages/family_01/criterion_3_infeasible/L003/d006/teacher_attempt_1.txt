# Redundant Storage Cell

Time limit: 2 s   Memory limit: 256 MB

A cloud infrastructure provider operates $n$ data vaults, identified by integers from 1 to $n$. To facilitate rapid data transfer, they have laid $m$ direct secure fiber links. Each link physically connects a specific pair of vaults.

The provider needs to establish a "redundant storage cell". A cell is formed by selecting exactly three distinct vaults. To ensure robust data synchronization, the cell must support internal indirect routing: for any two vaults within the chosen cell, they must be able to synchronize data by routing it through the third vault in the cell. This requires that the third vault possesses a direct secure fiber link to each of those two vaults. This indirect routing requirement must be met for every possible pair of vaults within the cell.

System logs indicate that at least one valid cell configuration is possible. Your objective is to process the fiber link records and identify one such cell.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n(n-1)/2, 2 \cdot 10^5)$).
Each of the following $m$ lines contains two integers $u$ and $v$ — a pair of vaults connected by a secure fiber link.
It is guaranteed that at least one redundant storage cell can be formed.

## Output
Print three integers $a$, $b$, and $c$ on a single line with $a < b < c$, representing the vaults in the cell. Output the lexicographically smallest such set (smallest $a$; ties broken by smallest $b$; then smallest $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
Changed the fault-tolerance condition from "if one vault goes offline, the remaining two must be connected" to "any two vaults must be able to route data through the third vault". This removes the immediate surface-level mapping to a 3-clique, forcing the model to logically deduce that applying this routing requirement to all three pairs symmetrically mandates the existence of all three pairwise links.
</RATIONALE>
<PRESERVED_ANSWER>
The routing condition requires that for every pair in the 3-vault cell, the third vault connects to both; applying this to all three pairs requires all three edges to exist, which is exactly the same triangle condition as the original.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a triangle (a 3-clique) in an undirected graph, keeping it in the same complexity class.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "routing it through the third vault" as prohibiting a direct link between the two synchronizing vaults, though the text explicitly defines the requirement as simply possessing links to the third vault.
</RISK>
