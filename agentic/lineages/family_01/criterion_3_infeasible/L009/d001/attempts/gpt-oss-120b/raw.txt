**Solution Explanation**

For three materials `a < b < c` the statement  

*“no matter how they are divided between the two units, at least two
materials placed in the same unit will be volatile together”*  

means that the induced sub‑graph on `{a,b,c}` is **not bipartite**.
A graph on three vertices is bipartite unless it contains all three edges,
i.e. it is a **triangle**.  
Therefore we have to output the lexicographically smallest triangle
(`a<b<c`) of the given undirected graph.  
The existence of at least one triangle is guaranteed.



--------------------------------------------------------------------

#### 1.   Data structure – bitset adjacency

`n ≤ 2000`, therefore a 2000‑bit integer fits easily into a Python `int`.
For every vertex `v` we store an integer `adj[v]` whose `i`‑th bit
(`i = 0 … n‑1`) is `1` iff the edge `v – (i+1)` exists.

* building the bitsets – `O(m)`  
* testing the existence of an edge – `O(1)` (bit test)  

--------------------------------------------------------------------

#### 2.   Searching the smallest triangle

We enumerate the first two vertices of the triangle in increasing order:

```
for a = 0 … n-1:
    for b = a+1 … n-1:
        if edge a‑b exists:
            common = adj[a] & adj[b]          # vertices adjacent to both
            # we need a vertex c > b
            mask = ~((1 << (b+1)) - 1)        # bits 0 … b are cleared
            common &= mask
            if common != 0:
                c = index of least significant 1‑bit of common
                output a+1, b+1, c+1
                terminate
```

* `common` contains exactly the vertices that together with `a` and `b`
  form a triangle.
* By clearing bits `≤ b` we guarantee `c > b`.
* The first found `(a,b,c)` is automatically the lexicographically
  smallest one because the loops increase `a`, then `b`, and we pick the
  smallest possible `c`.

The inner work is only a few integer operations, therefore the total
complexity is `O(n²)` ≤ `4·10⁶` operations, easily fast enough.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest
triangle.

---

##### Lemma 1  
For any vertices `a < b`, after the statement  

`common = adj[a] & adj[b]`  

`common` has a `1`‑bit at position `c` (0‑based) **iff**
edges `a‑c` and `b‑c` are present.

**Proof.**  
`adj[a]` has a `1` at `c` exactly when `a‑c` exists, similarly for `adj[b]`.
The bitwise AND is `1` only when both bits are `1`. ∎



##### Lemma 2  
After `mask = ~((1 << (b+1)) - 1)` and `common &= mask`,
`common` contains a `1`‑bit at position `c` **iff**
`c > b` and edges `a‑c`, `b‑c` exist.

**Proof.**  
`(1 << (b+1)) - 1` is a number whose low `b+1` bits are `1`. Its bitwise
negation has `0` on those bits and `1` elsewhere.
AND‑ing with it clears exactly bits `0 … b`. ∎



##### Lemma 3  
If the algorithm prints `(a,b,c)`, then `{a,b,c}` is a triangle.

**Proof.**  
Printing happens only when `common != 0`. By Lemma&nbsp;2 there exists a
`c` with `c > b` such that edges `a‑c` and `b‑c` exist.
The outer `if` guarantees edge `a‑b` exists.
Thus all three edges are present – a triangle. ∎



##### Lemma 4  
If a triangle `{x,y,z}` with `x<y<z` exists, the algorithm will eventually
print some triangle.

**Proof.**  
When the outer loops reach `a = x` and `b = y`, the edge `x‑y` exists,
so the inner block is executed.
By Lemma&nbsp;1 `adj[x] & adj[y]` has a `1` at position `z`.
Since `z > y`, Lemma&nbsp;2 keeps this bit, therefore `common != 0`
and the algorithm prints a triangle (maybe the same, maybe another with
the same `a,b`). ∎



##### Lemma 5  
The first printed triangle is the lexicographically smallest triangle.

**Proof.**  
The loops enumerate pairs `(a,b)` in increasing lexicographic order.
For a fixed `(a,b)` we choose the smallest possible `c` because we take
the least significant `1`‑bit of `common`.  
Hence any triangle printed later has either a larger `a`, or the same `a`
and larger `b`, or same `a,b` and larger `c`. ∎



##### Theorem  
The algorithm outputs exactly the lexicographically smallest
certificate of impossibility, i.e. the smallest triangle of the graph.

**Proof.**  
Existence: by Lemma&nbsp;4 a triangle will be printed.
Validity: by Lemma&nbsp;3 the printed triple is a triangle,
hence a certificate.
Minimality: by Lemma&nbsp;5 it is the lexicographically smallest triangle.
∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency bitsets* : `O(m)` time, `O(n)` memory (one `int` per
vertex).  

*Search* : two nested loops over `a<b` → `O(n²)` iterations,
each doing a constant number of integer operations.  

Overall  

* **Time** `O(n² + m) ≤ 4·10⁶ + 2·10⁵`  (well below 2 s)  
* **Memory** `O(n)` (≈ 2000 · 8 bytes)  

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [0] * n
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u] |= 1 << v
        adj[v] |= 1 << u

    full_mask = (1 << n) - 1
    for a in range(n):
        a_adj = adj[a]
        for b in range(a + 1, n):
            if not (a_adj >> b) & 1:   # edge a-b absent
                continue
            common = a_adj & adj[b]    # vertices adjacent to both a and b
            # clear bits <= b
            mask = full_mask ^ ((1 << (b + 1)) - 1)
            common &= mask
            if common:
                # least significant 1-bit
                c = (common & -common).bit_length() - 1
                print(a + 1, b + 1, c + 1)
                return

if __name__ == "__main__":
    solve()
```
