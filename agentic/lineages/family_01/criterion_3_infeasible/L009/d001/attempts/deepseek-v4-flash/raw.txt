 We need to find three vertices that form a triangle in the graph, because that means any two-way split will put two of them together, and they are volatile together.  
The problem guarantees at least one triangle exists.  
We just need the lexicographically smallest triangle.

We can do this by checking all triples in increasing order and stopping at the first triangle.

```python
n, m = map(int, input().split())
adj = [[False] * (n + 1) for _ in range(n + 1)]

for _ in range(m):
    u, v = map(int, input().split())
    adj[u][v] = adj[v][u] = True

for a in range(1, n + 1):
    for b in range(a + 1, n + 1):
        if adj[a][b]:
            for c in range(b + 1, n + 1):
                if adj[a][c] and adj[b][c]:
                    print(a, b, c)
                    exit()
```
