# Problem C — Proof of Impossibility

Time limit: 2 s   Memory limit: 256 MB

The laboratory still has only two storage units available for all chemicals, but a valid allocation is known to be strictly impossible under the current registry. Your job is not to attempt an assignment — it is to certify the breakdown of the two-unit system.

To provide this certification, you must find a minimal subset of chemicals that inherently requires three units. In this specific registry, the impossibility is always caused by a trio of chemicals where each individual chemical in the trio is incompatible with the other two. Output the identifiers of the chemicals in one such trio.

## Input
The first line contains two integers $n$ and $m$. 
The value $n$ is the number of chemical types. The laboratory has exactly 50 storage racks, each designed to hold 40 distinct chemical types, setting the maximum possible number of chemical types to the total capacity of these racks. Because a certification involves a trio of chemicals, $n$ is at least this minimum, and at most the maximum rack capacity.
The value $m$ is the number of logged incompatibilities. The registry uses a fixed-size memory buffer of 800,000 bytes, and each logged pair requires exactly 4 bytes of memory. Since the certification requires three pairwise interactions, $m$ is at least this minimum, and at most the buffer's maximum pair capacity (or the theoretical maximum number of distinct pairs among the $n$ chemicals, whichever is smaller).

Each of the following $m$ lines contains two integers $u$ and $v$ (1 ≤ $u$, $v$ ≤ $n$, $u \neq v$), representing a pair of chemicals that cannot share a unit. The pairs are unordered and all pairs are distinct.
It is guaranteed that the impossibility can be demonstrated as described.

## Output
Output three integers on a single line, representing the identifiers of the three chemicals forming the certification. The three identifiers must be sorted in ascending order. If there are multiple valid trios, you must output the one that is lexicographically first (prioritizing the smallest first identifier, then the smallest second identifier, and finally the smallest third identifier).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
