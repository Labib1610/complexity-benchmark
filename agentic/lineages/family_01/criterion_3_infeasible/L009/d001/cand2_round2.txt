# Problem C — Proof of Impossibility

Time limit: 2 s   Memory limit: 256 MB

The laboratory is equipped with two isolated storage units. However, it has been determined that the current registry of chemical reactions cannot be safely partitioned between just these two units without a reaction occurring. Your task is not to attempt an allocation, but rather to provide a certificate of this impossibility. 

It is guaranteed that the provided registry cannot be partitioned into two safe storage units. To certify this impossibility, you must locate three distinct chemical types that all mutually react with one another. Since three mutually reacting chemicals cannot be divided between two units without at least two sharing a unit, this configuration serves as a valid certificate.

## Input
The first line contains two integers n and m. The integer n represents the number of chemical types, which is at least 3 and at most the total capacity of 40 racks holding 50 vials each. Thus, 3 ≤ n ≤ 2000.
The integer m represents the number of reacting pairs. The value of m is at least 3, and at most the minimum of the total number of possible pairs among n chemicals and the database limit of two hundred thousand. Thus, 3 ≤ m ≤ min(n·(n−1)/2, 2·10⁵).

Each of the next m lines contains two integers u v — a reacting pair.
It is guaranteed that at least one such triple exists.

## Output
Print three integers a b c on one line with a < b < c such that all three pairs a–b, a–c, b–c are reactions. Output the lexicographically smallest such triple (smallest a; ties by smallest b; then smallest c).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
