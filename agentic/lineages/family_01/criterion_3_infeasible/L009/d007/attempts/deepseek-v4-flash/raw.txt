 We need to find a trio of distinct vertices where the product of their degrees within the trio equals 8.  

In a trio of 3 vertices, each vertex can be connected to 0, 1, or 2 of the other two.  
The possible degree combinations (within the trio) and their products:

- (2, 2, 2) → product = 8 → all three edges present (triangle)
- (2, 2, 1) → product = 4 → not 8
- (2, 1, 1) → product = 2 → not 8
- (1, 1, 1) → product = 1 → not 8
- (2, 2, 0) → product = 0 → not 8
- etc.

So the only way to get product 8 is if each vertex has degree 2 within the trio, meaning it’s a triangle (all three edges present).  

Thus, we just need to find the lexicographically smallest triangle in the graph.

We can do this by iterating over all triples in sorted order and checking if all three edges exist.  
Since n ≤ 2000, O(n³) is too slow (8e9 operations).  
We can instead iterate over edges and check for a common neighbor.

Approach:
- Store adjacency as sets for O(1) edge lookup.
- Iterate over all edges (u, v) with u < v.
- For each such edge, look for a vertex w > v such that both (u, w) and (v, w) are edges.
- The first such found (in sorted order) is the answer.

We need to ensure lexicographically smallest:  
We can iterate u from 1 to n, v from u+1 to n, w from v+1 to n, but that’s O(n³).  
Better: iterate over edges sorted by (u, v), and for each, check neighbors of u that are > v and also connected to v.  
Since we want smallest (u, v, w), we can iterate u from 1 to n, then v from u+1 to n, and if edge exists, check w from v+1 to n. But that’s still O(n³) in worst case.

We can optimize:  
For each u, iterate over its neighbors v > u. For each such v, iterate over neighbors w of u that are > v, and check if (v, w) is an edge.  
This is O(sum over edges of degree) which is O(nm) worst-case, but with n=2000, m=200000, that’s 4e8, might be borderline but okay in Python with sets.

We can also do:  
For each u, for each v in adj[u] with v > u, for each w in adj[u] with w > v, check if w in adj[v].  
First found is answer.

Let’s implement that.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n+1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for u in range(1, n+1):
        for v in sorted(adj[u]):
            if v <= u:
                continue
            for w in sorted(adj[u]):
                if w <= v:
                    continue
                if w in adj[v]:
                    print(u, v, w)
                    return

if __name__ == "__main__":
    main()
```
