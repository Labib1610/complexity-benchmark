**Solution Explanation**

For three different vertices `a < b < c`

* the internal degree of a vertex = number of neighbours inside the triple  
* the product of the three internal degrees has to be `8`

The only possible internal degrees are `0, 1, 2`.  
`2·2·2 = 8` and any other combination gives a different product, therefore

```
a,b,c form a certificate  ⇔  every pair among them is an edge
                           ⇔  they form a triangle
```

So we only have to output the lexicographically smallest triangle of the
undirected graph.



--------------------------------------------------------------------

#### Data structure – bitset

`n ≤ 2000`, therefore a 2000‑bit integer fits easily into a Python `int`.
For every vertex `v` we store

```
adj[v] : int
bit i (0‑based) is 1  ⇔  edge (v, i+1) exists
```

All operations we need are:

* `adj[u] & adj[v]` – intersection of neighbours of `u` and `v`
* mask away vertices `≤ b` – `common & ~((1 << (b+1)) - 1)`
* obtain the smallest set bit – `lsb = common & -common`,
  its index `c = lsb.bit_length() - 1 + 1` (back to 1‑based)

All are `O(1)` on the size of the integer.



--------------------------------------------------------------------

#### Algorithm
```
read n, m
adj = [0] * (n+1)

for each edge (u,v):
        set the bits in both adj[u] and adj[v]

for a = 1 .. n-2:
        for b = a+1 .. n-1:
                if edge (a,b) does NOT exist: continue
                common = adj[a] & adj[b]                # neighbours of both
                # keep only vertices larger than b
                common &= ~((1 << (b+1)) - 1)
                if common != 0:
                        lsb = common & -common
                        c = lsb.bit_length()            # 0‑based index
                        print a, b, c
                        exit
```

The double loop visits edges in lexicographic order (`a` increasing,
inside it `b` increasing).  
The first triangle found is therefore the lexicographically smallest one.



--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
triangle.

---

**Lemma 1**  
For any three vertices `a<b<c` the product of their internal degrees equals
`8` **iff** the three edges `(a,b) , (a,c) , (b,c)` are all present.

*Proof.*  
Internal degrees are `0,1,2`. The only way to obtain product `8` is
`2·2·2`. Hence each vertex must have degree `2` inside the triple,
i.e. it is adjacent to the other two vertices – exactly the three edges of a
triangle. ∎



**Lemma 2**  
When the algorithm reaches a pair `(a,b)` with `a<b` and the edge `(a,b)`
exists, `common = adj[a] & adj[b]` contains exactly the vertices that are
adjacent to **both** `a` and `b`.

*Proof.*  
`adj[a]` has a `1` at position `x` iff `(a,x)` is an edge, similarly for
`adj[b]`. Bitwise `&` keeps a `1` only when both bits are `1`, i.e. when both
edges exist. ∎



**Lemma 3**  
After masking `common` with `~((1 << (b+1)) - 1)` the remaining set bits are
precisely the common neighbours `c` with `c > b`.

*Proof.*  
The mask has `1`s for positions `0 … b` and `0`s afterwards; negating it
produces `0`s for `0 … b` and `1`s for larger positions. Bitwise `&` therefore
clears all bits `≤ b` and leaves higher bits unchanged. ∎



**Lemma 4**  
If the algorithm prints `(a,b,c)`, then `{a,b,c}` is a triangle.

*Proof.*  
Printing happens only when `common` after masking is non‑zero, i.e. there is a
vertex `c>b` that is a common neighbour of `a` and `b`. By construction
edges `(a,b)`, `(a,c)`, `(b,c)` exist, thus by Lemma&nbsp;1 the triple is a
triangle. ∎



**Lemma 5**  
The first printed triple is the lexicographically smallest triangle.

*Proof.*  
The outer loop enumerates `a` in increasing order, the inner loop enumerates
`b` in increasing order for each fixed `a`. For a given `(a,b)` the algorithm
chooses the smallest possible `c` (the least set bit). Therefore triples are
examined in strict lexicographic order, and the first one that is a triangle
is the smallest. ∎



**Theorem**  
The algorithm always outputs three integers `a<b<c` that form a certificate
(i.e. a triangle) and among all certificates it outputs the lexicographically
smallest one.

*Proof.*  

*Existence*: the statement guarantees at least one triangle, so some
iteration will satisfy the condition and the algorithm will print.

*Validity*: by Lemma&nbsp;4 the printed triple is a triangle, and by
Lemma&nbsp;1 a triangle is exactly a certificate.

*Optimality*: by Lemma&nbsp;5 the first printed triangle is the smallest in
lexicographic order, which the algorithm outputs. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`n ≤ 2000`, `m ≤ 200 000`.

*Building adjacency*: `O(m)`  
*Main loops*: at most `n·(n-1)/2 ≤ 2·10⁶` iterations, each does only constant‑time
bit operations.  
Overall time `O(n² + m) ≤ 2·10⁶`, well below the limit.

Memory: one integer per vertex → `O(n)` bits ≈ 2000 bits ≈ 250 bytes,
plus a few auxiliary variables – far under 256 MB.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * (n + 1)          # 1‑based
    edge_exists = [set() for _ in range(n + 1)]

    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        # set bits (0‑based index)
        adj[u] |= 1 << (v - 1)
        adj[v] |= 1 << (u - 1)
        edge_exists[u].add(v)
        edge_exists[v].add(u)

    for a in range(1, n - 1):
        for b in range(a + 1, n):
            if b not in edge_exists[a]:
                continue
            common = adj[a] & adj[b]
            # keep only vertices > b
            mask = ~((1 << (b + 1)) - 1)
            common &= mask
            if common:
                lsb = common & -common
                c = lsb.bit_length()          # 0‑based index -> vertex id
                # c is already 1‑based because bit 0 corresponds to vertex 1
                print(a, b, c)
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
