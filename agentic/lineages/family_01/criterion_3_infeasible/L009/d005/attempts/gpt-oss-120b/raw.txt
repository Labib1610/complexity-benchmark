**Solution Explanation**

For three different vertices `a < b < c` we have to decide whether they can be put into
two containers so that inside each container there is no edge.
That is exactly the definition of a *bipartite* graph.
A graph with three vertices is **not** bipartite **iff** the three vertices form a
triangle (a 3‑cycle).

So the required certificate is simply the lexicographically smallest triangle
in the given undirected graph.

--------------------------------------------------------------------

#### 1.   Data representation  

`n ≤ 2000`, therefore an adjacency bitset of length `n` fits easily into a Python
integer (`int` has arbitrary length).

```
adj[v] : integer
bit (u-1) of adj[v] is 1  ⇔  edge (v , u) exists
```

All edges are inserted symmetrically.

Additionally we pre‑compute  

```
mask_up_to[i] = (1 << i) - 1          # bits 0 … i-1 are 1
```

--------------------------------------------------------------------

#### 2.   Searching the smallest triangle  

The vertices are scanned in lexicographic order:

```
for a = 1 … n
    for b = a+1 … n
        if edge a–b exists:
            common = adj[a] & adj[b]        # vertices adjacent to BOTH a and b
            # we need a vertex c > b
            common &= ~mask_up_to[b]        # delete bits ≤ b
            if common != 0:
                c = index of the lowest set bit in common
                output a b c
                stop
```

*Why does this give the lexicographically smallest triangle?*

* the outer loop enumerates `a` increasingly,
* for a fixed `a` the inner loop enumerates `b` increasingly,
* for a fixed pair `(a,b)` we take the smallest possible `c` (`lowest set bit`),
  and we also require `c > b`.

Therefore the first triangle we meet is the lexicographically smallest one.

All operations are O(1) on Python integers, the double loop runs `n·(n‑1)/2 ≤ 2·10⁶`
iterations – easily fast enough.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
triangle.

---

##### Lemma 1  
A set of three vertices cannot be partitioned into two independent sets  
*iff* the three vertices induce a triangle.

**Proof.**  
A graph on three vertices is bipartite unless it contains an odd cycle.
The only possible odd cycle with three vertices is the triangle.
If there is no triangle, the graph is either empty, a single edge, or a path of
length two – all are bipartite (assign the middle vertex to a different side).
∎



##### Lemma 2  
When the algorithm reaches a pair `a < b` with an edge `a–b`,
`common = adj[a] & adj[b]` contains exactly the vertices adjacent to **both**
`a` and `b`.

**Proof.**  
Bit `v-1` of `adj[a]` is 1 iff `a–v` is an edge.  
Similarly for `adj[b]`.  
`&` keeps a bit set only when it is set in both operands, i.e. when both edges
exist. ∎



##### Lemma 3  
After `common &= ~mask_up_to[b]` the remaining set bits correspond precisely to
the vertices `c` with `c > b` that are adjacent to both `a` and `b`.

**Proof.**  
`mask_up_to[b]` has bits `0 … b‑1` set, i.e. vertices `1 … b`.  
Negating it makes those bits 0 and all higher bits 1.
The `&=` therefore clears every bit ≤ `b` and leaves higher bits unchanged.
∎



##### Lemma 4  
If the algorithm prints `(a,b,c)`, the three vertices form a triangle.

**Proof.**  
The algorithm prints only when
* edge `a–b` exists (checked before),
* after the masking step `common` is non‑zero, therefore there exists a vertex
  `c` (> `b`) belonging to `common`.  
By Lemma&nbsp;2 `c` is adjacent to both `a` and `b`.  
Thus edges `a–b`, `a–c`, `b–c` are present – a triangle. ∎



##### Lemma 5  
If a triangle `(x,y,z)` (`x<y<z`) exists, the algorithm will eventually print a
triangle no larger than it in lexicographic order.

**Proof.**  
Consider the outer loops.
When `a = x` the inner loop will reach `b = y` because `y > x`.
Edge `x–y` exists, so the algorithm examines this pair.
All vertices adjacent to both `x` and `y` are exactly `{z, …}`.
Masking removes all vertices `≤ y`; `z` stays because `z > y`.
Therefore `common` is non‑empty and the algorithm finds the smallest such `c`,
which is `z`.  
Consequently it prints `(x,y,z)`.  
Since the loops enumerate `(a,b)` in increasing order, any earlier printed
triangle would have a smaller `a`, or the same `a` and a smaller `b`, or the
same `a,b` and a smaller `c`. Hence the printed triangle is lexicographically
minimal. ∎



##### Lemma 6  
The algorithm always prints a triangle.

**Proof.**  
The input guarantees that at least one triangle exists.
By Lemma&nbsp;5 the algorithm will encounter the smallest one and print it. ∎



##### Theorem  
The algorithm outputs the lexicographically smallest triple of vertices that
cannot be split into two containers without a volatile pair (i.e. the smallest
certificate).

**Proof.**  
By Lemma&nbsp;1 such a triple is exactly a triangle.
Lemma&nbsp;4 shows any output of the algorithm is a triangle.
Lemma&nbsp;6 guarantees the algorithm outputs a triangle.
Lemma&nbsp;5 guarantees that the output triangle is the lexicographically
smallest one. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Memory*  
`adj` – `n+1` integers, each up to `2^n` → `O(n)` bits ≈ 250 KB for `n=2000`.  
`mask_up_to` – same size.  
Overall `O(n)` memory.

*Time*  
Double loop over all unordered pairs `a<b`: `n·(n‑1)/2 ≤ 2·10⁶` iterations.  
Inside each iteration only a few bit operations (`>>`, `&`, `|`, masking, a
constant‑time `bit_length`).  
Hence total time `O(n²)`, well below the limits.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    # adjacency as bitsets, vertex i uses bit (i-1)
    adj = [0] * (n + 1)
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        bit_u = 1 << (v - 1)
        bit_v = 1 << (u - 1)
        adj[u] |= bit_u
        adj[v] |= bit_v

    # mask_up_to[i] = bits 0..i-1 set (i.e., vertices 1..i)
    mask_up_to = [(1 << i) - 1 for i in range(n + 1)]

    out = []
    for a in range(1, n + 1):
        a_bits = adj[a]
        for b in range(a + 1, n + 1):
            # edge a-b ?
            if (a_bits >> (b - 1)) & 1:
                common = a_bits & adj[b]
                # keep only vertices > b
                common &= ~mask_up_to[b]
                if common:
                    # lowest set bit
                    low = common & -common
                    c_idx = low.bit_length() - 1      # 0‑based index
                    c = c_idx + 1
                    sys.stdout.write(f"{a} {b} {c}\n")
                    return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
