<METHOD_NAME>
Bipartite Impossibility Framing
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the independent set condition (max independent set = 1) with an equivalent 2-coloring impossibility condition (cannot partition into 2 independent sets). Since the set size is exactly 3, being non-2-colorable is equivalent to being a triangle. This forces models to deduce the triangle equivalence rather than pattern-matching it.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<STATEMENT>
# Problem C — Proof of Impossibility

Time limit: 2 s   Memory limit: 256 MB

The laboratory protocol requires isolating reactive materials to prevent hazards. Certain pairs of materials are documented as mutually volatile.

Your task is to identify a certificate of instability. A certificate consists of exactly three distinct materials with the following property: it is impossible to distribute these three materials into two separate containers (one of which may be empty) such that within each container, no two materials are mutually volatile.

It is guaranteed that the provided registry contains at least one such certificate.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a mutually volatile pair.
It is guaranteed that a certificate of three materials exists.

## Output
Print three integers $a$, $b$, and $c$ on one line with $a < b < c$ representing the materials of a certificate. Output the lexicographically smallest such certificate (smallest $a$; ties by smallest $b$; then smallest $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
The problem was reframed from finding a trio with a maximum independent set of 1 to finding a trio that cannot be partitioned into two independent sets (i.e., is not 2-colorable). For a subgraph of exactly 3 nodes, being non-2-colorable is logically identical to being a triangle. This forces the model to deduce the equivalence instead of relying on surface-level keyword matching for triangles or cliques, while fully respecting the gate's strict fidelity requirements.
</RATIONALE>
<PRESERVED_ANSWER>
A set of 3 nodes cannot be partitioned into 2 independent sets if and only if it is a triangle, which is the exact same condition as the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a triangle in a graph, preserving the $O(NM/64)$ bitset intersection complexity class.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "two separate containers (one of which may be empty)" as allowing materials to be discarded, but "distribute these three materials into" implies all three must be placed.
</RISK>
