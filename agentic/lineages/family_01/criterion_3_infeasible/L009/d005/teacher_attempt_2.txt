# Problem C — Volatile Mixtures

Time limit: 2 s   Memory limit: 256 MB

An industrial facility manages an inventory of $n$ reactive agents, indexed from 1 to $n$. The facility stores these agents in an automated rack containing exactly 20 shelves, where each shelf can hold up to 100 agent containers. Each agent occupies exactly one container, which establishes a strict upper limit on the total number of agents.

Certain pairs of these agents are documented to react violently upon contact. The facility's monitoring system allocates a fixed database table with exactly 200,000 rows for hazard logs, and each known reactive pair occupies precisely one row. 

The safety team is investigating a critical vulnerability: a combination of exactly three agents that are completely mutually reactive. In such a trio, if any two of the three agents are brought together, they will trigger a violent reaction according to the logs. A breach involving this specific configuration would result in a self-sustaining chain reaction.

You are provided with the comprehensive log of reactive agent pairs. Your objective is to locate one such trio of agents.

## Input
The first line provides two integers $n$ and $m$. The value of $n$ is at least 3 and is bounded above by the total container capacity of the automated rack. The value of $m$ is at least 3 and is bounded above by the database row limit (or the maximum number of possible pairs among the $n$ agents, whichever is smaller).
The following $m$ lines each contain two integers $u$ and $v$ — representing a distinct pair of agents that react violently.
It is guaranteed that there is at least one trio of agents meeting the hazard criteria.

## Output
Output three integers $a$ $b$ $c$ on a single line, ordered such that $a < b < c$, representing the agents in the trio. If multiple such trios exist, output the one that is lexicographically smallest (the one with the smallest $a$; in case of a tie, the smallest $b$; and finally the smallest $c$).

## Example 1
Input:
4 5
1 2
1 3
2 3
2 4
3 4

Output:
1 2 3

## Example 2
Input:
5 6
1 2
1 4
2 4
3 4
3 5
4 5

Output:
1 2 4
