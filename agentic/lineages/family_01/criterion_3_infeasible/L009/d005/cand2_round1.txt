<METHOD_DESCRIPTION>Frames the requirement of a 3-clique as the impossibility of partitioning the 3 vertices into two non-empty independent sets. This forces the model to deduce that all 3 edges must exist by analyzing the subsets, rather than pattern-matching the "maximum safe set is 1" phrasing to a clique.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem C — Proof of Impossibility

Time limit: 2 s   Memory limit: 256 MB

The laboratory protocol requires isolating reactive materials to prevent hazards. You are provided with a registry of material pairs that are *mutually volatile*. 

Your task is to identify a minimal certificate of instability. A certificate consists of exactly three distinct materials with the following property: if you attempt to distribute these three specific materials into two separate containers (such that each container receives at least one material), it is guaranteed that for every possible valid distribution, at least one container will end up holding a mutually volatile pair.

It is guaranteed that the provided registry contains at least one such certificate.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), representing the number of materials (numbered $1$ to $n$) and the number of mutually volatile pairs in the registry.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$) — a mutually volatile pair. Each pair is listed at most once.
It is guaranteed that a certificate of three materials exists.

## Output
Print three integers $a$, $b$, and $c$ on one line with $a < b < c$ representing the materials of a minimal certificate. Output the lexicographically smallest such certificate (smallest $a$; ties broken by smallest $b$; then smallest $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
The previous wording ("maximum number of materials you can select... to form a safe set is exactly one") was easily recognized by models as "the independent set number of this trio is 1", which trivially means the trio is a 3-clique (triangle). I changed the definition to an equivalent partition constraint: any 2-partition of the trio must contain a volatile pair. To succeed, models must now logically deduce that the only way every 2-partition of 3 items contains a volatile pair is if all 3 pairs are volatile.
</RATIONALE>
<PRESERVED_ANSWER>
There are exactly 3 ways to partition 3 items into two non-empty containers; each puts a different pair of items together in one container, so requiring every partition to fail means all 3 pairs must be mutually volatile, which is exactly the same triangle condition as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding the lexicographically first triangle (3-clique) in an undirected graph, which remains solvable in $O(N \cdot M / 64)$ time using bitsets.
</PRESERVED_CLASS>
