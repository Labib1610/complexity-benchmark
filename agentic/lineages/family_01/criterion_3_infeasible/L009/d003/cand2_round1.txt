# Problem C — Proof of Impossibility

Time limit: 2 s   Memory limit: 256 MB

The laboratory protocol requires isolating reactive materials. You are provided with a registry of $m$ distinct records, where each record is a set of exactly two materials that are mutually volatile. 

Your task is to identify a minimal certificate of instability. A certificate is defined as a set $S$ of exactly three distinct materials such that exactly three of the records in the registry are subsets of $S$. It is guaranteed that the provided registry contains at least one such certificate.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), representing the number of available materials and the number of records. Materials are identified by integers from $1$ to $n$.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$) — the two materials that make up a single record. It is guaranteed that no two records contain the exact same set of two materials.
It is guaranteed that at least one valid certificate of three materials exists.

## Output
Print three integers $a$, $b$, and $c$ on one line with $a < b < c$ representing the materials of a minimal certificate. Output the lexicographically smallest such certificate (smallest $a$; ties by smallest $b$; then smallest $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
The previous statement described the certificate using a procedural condition ("if you place any one... the remaining two..."), which models easily translated into "for each node, its two neighbors must be connected." I replaced this with a declarative, set-theoretic condition ("exactly three of the records in the registry are subsets of $S$"). This removes the direct translation affordance, forcing models to mathematically deduce that a 3-element set containing exactly three 2-element subsets from the registry is equivalent to a triangle, rather than relying on a surface-level mapping to graph traversal steps.
</RATIONALE>
<PRESERVED_ANSWER>
Every answer is unchanged because a set $S$ of size 3 has exactly three possible subsets of size 2; for exactly three records to be subsets of $S$, all three possible pairs of those materials must be present in the registry, which is mathematically identical to the original requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class is unchanged because the condition still dictates finding a 3-clique (triangle) in the graph defined by the records, requiring the exact same algorithmic approach and complexity.
</PRESERVED_CLASS>
