We need to find the lexicographically smallest triple of vertices that cannot be 2-colored without having an edge inside one of the color classes.  

That means the triple must contain a triangle (three mutually connected vertices) — because if there is no triangle, we can always 2-color the triple without conflict.  

So the problem reduces to: find the lexicographically smallest triangle in the graph.  

We can do this by iterating over vertices in increasing order, and for each vertex `a`, check pairs `(b, c)` with `a < b < c` such that all three edges exist. The first found is the answer.  

We can store edges in an adjacency matrix (since n ≤ 2000, that’s fine) and check quickly.  

Here’s the implementation:  

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = adj[v][u] = True

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if adj[a][b]:
                for c in range(b + 1, n + 1):
                    if adj[a][c] and adj[b][c]:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    main()
```
