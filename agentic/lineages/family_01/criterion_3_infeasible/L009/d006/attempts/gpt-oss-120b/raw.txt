**Solution Explanation**

For three different vertices `a < b < c`

```
a – b   edge ?
a – c   edge ?
b – c   edge ?
```

The required certificate has to satisfy  

* at least one of the three edges exists,
* for every vertex, if it is incident to at least one of the three edges,
  then it must be incident to **both** other vertices.

The only possible configuration that fulfills the second rule is the
complete triangle – all three edges are present.
(If a vertex is incident to exactly one edge, the rule would force a second
edge that does not exist.)

Therefore we only have to output the lexicographically smallest triangle
in the given undirected graph.



--------------------------------------------------------------------

#### 1.   Data structure – bitset

`n ≤ 2000`, so a 2000‑bit integer easily fits into a Python `int`.
For every vertex `v` we store a bit mask

```
adj[v]  –  bit i is 1  ⇔  (v , i) is an edge   (0‑based indices)
```

All set operations (`&`, `|`, `>>`) are performed on whole 2000‑bit blocks
in C speed, i.e. O(1).

--------------------------------------------------------------------

#### 2.   Searching the smallest triangle

We iterate over all edges `(a,b)` with `a < b` in increasing order of `a`
and then `b`.  
For a fixed edge the third vertex must be a common neighbour of `a` and
`b` and also larger than `b` (to keep `a < b < c`).  

```
common = adj[a] & adj[b]          # all common neighbours
common >>= b                      # discard vertices ≤ b
if common != 0:
        # the lowest set bit gives the smallest possible c
        low = common & -common
        idx = low.bit_length() - 1          # position of that bit
        c = b + idx
        answer = (a+1, b+1, c+1)            # back to 1‑based
        output and stop
```

Because we examine edges in lexicographic order and always take the
smallest possible `c`, the first triangle we find is exactly the required
lexicographically smallest one.

The loop runs over all `m` edges, each iteration does only a few integer
operations → `O(m)` time, `O(n)` memory.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest
certificate.

---

##### Lemma 1  
A triple of distinct vertices satisfies the two rules of the statement
iff the three edges among them are all present (i.e. it is a triangle).

**Proof.**  
*If* the three edges are present, every vertex is incident to two edges,
hence “if it has at least one incident edge then it has both” holds,
and the triple is not empty, so both rules are satisfied.

*Only‑if*: assume a triple satisfies the rules and is not a triangle.
Then at least one of the three possible edges is missing.
Take a vertex `x` that is incident to an existing edge (such a vertex
exists because the triple is not empty).  
`x` is incident to exactly one of the other two vertices, contradicting
the second rule which demands incident edges to both other vertices.
∎



##### Lemma 2  
When the algorithm processes an edge `(a,b)` (`a<b`) it finds the
smallest `c>b` such that `{a,b,c}` is a triangle, if such a `c` exists.

**Proof.**  
`common = adj[a] & adj[b]` contains precisely the vertices adjacent to both
`a` and `b`. After shifting right by `b` all vertices `≤ b` are removed.
If the resulting integer is non‑zero, its lowest set bit corresponds to the
minimum index `c'` with `c' > b` that belongs to `common`. Adding `b`
restores the original vertex number `c`. Hence `c` is the smallest possible
third vertex forming a triangle with `a` and `b`. ∎



##### Lemma 3  
The first triangle output by the algorithm is the lexicographically
smallest triangle in the whole graph.

**Proof.**  
Edges are examined in increasing order of `a`, and for equal `a` in
increasing order of `b`.  
For a fixed `(a,b)` Lemma&nbsp;2 guarantees that the algorithm would output
the smallest possible `c`.  
Therefore any triangle discovered later has either a larger `a`, or the
same `a` and larger `b`, or the same `a,b` and larger `c`.  
Thus the first output triangle is lexicographically minimal. ∎



##### Theorem  
The algorithm always outputs three integers `a<b<c` that form a
certificate, and this certificate is the lexicographically smallest
among all possible certificates.

**Proof.**  
Because the input guarantees existence of a certificate, by Lemma&nbsp;1 a
triangle exists. While scanning edges the algorithm will eventually
process an edge belonging to some triangle; at that moment Lemma&nbsp;2
finds the third vertex and outputs a triangle, which by Lemma&nbsp;1 is a
valid certificate. Lemma&nbsp;3 shows that this triangle is the
lexicographically smallest one. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis

*Memory* : `n` integers of at most 2000 bits → `O(n)`.

*Time*    : one pass over all `m` edges, each iteration does a constant
number of bit operations → `O(m)` ≤ `2·10⁵`. Well within limits.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * n          # bit masks, 0‑based vertices
    edges = []             # list of edges with a<b (0‑based)

    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        if u == v:
            continue
        adj[u] |= 1 << v
        adj[v] |= 1 << u
        if u < v:
            edges.append((u, v))
        else:
            edges.append((v, u))

    # sort edges to guarantee lexicographic order of (a,b)
    edges.sort()

    for a, b in edges:
        # common neighbours of a and b
        common = adj[a] & adj[b]
        # keep only vertices > b
        common >>= b + 1
        if common:
            low = common & -common          # lowest set bit
            idx = low.bit_length() - 1      # position of that bit
            c = b + 1 + idx                  # back to original index
            # output 1‑based and sorted
            print(a + 1, b + 1, c + 1)
            return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input‑output format.
