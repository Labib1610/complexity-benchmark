 We need to find three distinct vertices that form a triangle (all three edges present) or a "V" shape where the middle vertex connects to both others but the two others are not connected — but the condition says:  

If a vertex is connected to at least one of the other two, it must be connected to both.  

That means:  
- If all three edges exist → valid.  
- If exactly two edges exist and they share a vertex → the shared vertex is connected to both, but the other two are not connected to each other. For the shared vertex, it's connected to both, so fine. For the other two, each is connected to only one of the others, which violates the rule. So that's invalid.  
- If exactly one edge exists → the two connected vertices each have only one connection among the trio, violating the rule.  
- If zero edges → not allowed because we need at least one edge.  

So the only valid configuration is a triangle (all three edges present).  

Thus, we just need to find the lexicographically smallest triangle in the graph.  

We can iterate over all triples in increasing order and check if all three edges exist.  

Given n ≤ 2000, O(n³) is too slow (8e9). We can instead iterate over edges and check for a common neighbor.  

Approach:  
- Store adjacency as a set for O(1) lookups.  
- For each edge (u, v) with u < v, look for a w > v such that both (u, w) and (v, w) exist.  
- The first found (smallest u, then v, then w) is the answer.  

We can iterate u from 1 to n, v from u+1 to n, and if edge exists, check w from v+1 to n.  

This is O(n² * degree) worst-case, but with n=2000 and m ≤ 2e5, it's fine.  

Let's implement.  

```python
n, m = map(int, input().split())
adj = [set() for _ in range(n + 1)]
for _ in range(m):
    a, b = map(int, input().split())
    adj[a].add(b)
    adj[b].add(a)

for u in range(1, n + 1):
    for v in range(u + 1, n + 1):
        if v in adj[u]:
            for w in range(v + 1, n + 1):
                if w in adj[u] and w in adj[v]:
                    print(u, v, w)
                    exit()
```
