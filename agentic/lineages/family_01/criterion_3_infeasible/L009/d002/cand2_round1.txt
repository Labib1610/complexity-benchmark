# Problem C — Proof of Impossibility

Time limit: 2 s   Memory limit: 256 MB

The laboratory protocol requires identifying hazardous combinations, focusing on a specific interaction where a third element bridges an existing conflict. 

Your task is to isolate a minimal certificate of this hazard. A minimal certificate consists of exactly three materials. Within this trio, two of the materials must form a volatile pair, and the third material must act as a catalyst, meaning the registry shows it is mutually volatile with both of the other two. It is guaranteed that the provided registry contains at least one such certificate.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a volatile pair.
It is guaranteed that a certificate of three materials exists.

## Output
Print three integers $a$, $b$, and $c$ on one line with $a < b < c$ representing the materials of a minimal certificate. Output the lexicographically smallest such certificate (smallest $a$; ties by smallest $b$; then smallest $c$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

Removed the "division into two storage units" framing which models were using as a shortcut to trigger 2-coloring/bipartite failure templates. Replaced it with a structural definition (a volatile pair plus a third element volatile with both) that mathematically describes the exact same complete 3-subgraph without invoking partition logic.
</RATIONALE>
<PRESERVED_ANSWER>
The condition requires two materials to be a volatile pair and a third to be volatile with both, which is logically identical to requiring all three pairs among the three materials to be volatile (a triangle), preserving all answers.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly triangle detection (finding a 3-clique), keeping the time complexity and intended bitset or edge-intersection algorithm identical.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the output format as requiring them to identify or order the "catalyst" specifically, but the explicit instruction to print the three materials as $a < b < c$ mitigates this risk.
</RISK>
