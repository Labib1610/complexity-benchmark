We need to find a triangle in an undirected graph where edges represent contradictory pairs.  
The graph has up to 2000 nodes, so an O(n²) approach is feasible.

We can use an adjacency matrix for fast edge checks, then iterate over all triples in lexicographical order and stop at the first triangle.

```python
n, m = map(int, input().split())
adj = [[False] * n for _ in range(n)]

for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u][v] = adj[v][u] = True

for a in range(n):
    for b in range(a + 1, n):
        if adj[a][b]:
            for c in range(b + 1, n):
                if adj[a][c] and adj[b][c]:
                    print(a + 1, b + 1, c + 1)
                    exit()
```
