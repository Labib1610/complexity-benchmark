**Solution Explanation**

For three different materials `a < b < c` the required property is

* the pair `{a,b}` is volatile,
* the pair `{a,c}` is volatile,
* the pair `{b,c}` is volatile.

So we have to output a *triangle* of the undirected graph whose vertices are the
materials and whose edges are the volatile pairs.
The answer must be the lexicographically smallest triangle
(first smallest `a`, then `b`, then `c`).

`n ≤ 2000`, therefore a bitset of `n` bits fits easily into a Python integer
(`2000` bits ≈ `250` bytes).  
With a bitset we can test adjacency and intersect neighbour sets in *O(1)*
time (the whole integer is processed at once).

--------------------------------------------------------------------

#### Data structures
* `adj[i]` – integer whose `j`‑th bit (`0 ≤ j < n`) is `1`
  iff there is an edge `i – j`.  
  `adj[i]` is the neighbour set of vertex `i`.

--------------------------------------------------------------------

#### Algorithm
```
read n, m
adj = [0] * n
for each edge (u,v):
        u-- ; v--                     # to 0‑based
        adj[u] |= 1 << v
        adj[v] |= 1 << u

for a = 0 … n-1:
        for b = a+1 … n-1:
                if edge a‑b does not exist: continue
                inter = adj[a] & adj[b]          # common neighbours
                # keep only vertices larger than b
                inter &= ~((1 << (b+1)) - 1)
                if inter != 0:                    # at least one c exists
                        low = inter & -inter       # lowest set bit
                        c = low.bit_length() - 1
                        output a+1, b+1, c+1
                        terminate
```

*The outer loops enumerate all ordered pairs `a < b` in increasing order.
The first triangle found is therefore the lexicographically smallest one,
because for a fixed `a,b` we also choose the smallest possible `c > b`.*

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
triangle.

---

##### Lemma 1  
For any vertices `a < b` the expression  

```
inter = adj[a] & adj[b]   (after masking bits ≤ b)
```

contains exactly the vertices `c` such that `c > b` and edges
`a‑c` and `b‑c` are present.

**Proof.**  
`adj[a]` has a `1` at position `c` iff edge `a‑c` exists.
`adj[b]` has a `1` at position `c` iff edge `b‑c` exists.
The bitwise `&` keeps a `1` only when both edges exist.
Masking removes all bits `≤ b`, therefore only vertices `c > b` remain. ∎



##### Lemma 2  
If the algorithm prints a triple `(a,b,c)` then `{a,b,c}` is a triangle.

**Proof.**  
The algorithm prints only after confirming three conditions:

1. edge `a‑b` exists (checked before the intersection);
2. `c` is taken from `inter`, therefore by Lemma&nbsp;1 edges `a‑c` and `b‑c`
   exist;
3. `a < b < c` holds by construction (`c` is taken from bits `> b`).

Thus all three edges of the triple are present – it is a triangle. ∎



##### Lemma 3  
If a triangle `{x,y,z}` with `x<y<z` exists, the algorithm will eventually
consider the pair `(a,b) = (x,y)` and will find `c = z`.

**Proof.**  
When the outer loops reach `a = x` and `b = y` the edge `x‑y` is present,
so the algorithm proceeds to compute `inter`.  
Because `{x,y,z}` is a triangle, `z` is a common neighbour of `x` and `y`,
hence `z`'s bit is set in `inter`.  
Since `z > y`, the masking does not delete it, therefore `inter ≠ 0`
and the algorithm extracts the smallest such `c`.  
Consequently `c = z` (or a smaller common neighbour, if any). ∎



##### Lemma 4  
The first triangle output by the algorithm is the lexicographically smallest
triangle of the graph.

**Proof.**  
The outer loops enumerate pairs `(a,b)` in increasing lexicographic order:
first by `a`, then by `b`.  
For a fixed pair `(a,b)` the algorithm chooses the smallest possible `c`
(because it extracts the lowest set bit of `inter`).  
Therefore any triangle with a smaller `a` would have been examined earlier,
and any triangle with the same `a` but smaller `b` would also have been
examined earlier.  
If a triangle has the same `a` and `b` but a smaller `c`,
the algorithm would have found that `c` instead of a larger one.
Hence the first printed triangle is the minimal one. ∎



##### Theorem  
The algorithm always terminates and prints the lexicographically smallest
triple of vertices that forms a triangle.

**Proof.**  
Termination: there are finitely many pairs `(a,b)` (`≤ n·(n-1)/2`);
the loops finish or stop earlier when a triangle is found.

Existence: the statement guarantees at least one triangle,
so by Lemma&nbsp;3 the algorithm will find a triangle for some pair
and therefore will output one.

By Lemma&nbsp;2 the output is a triangle.
By Lemma&nbsp;4 it is the lexicographically smallest triangle.
∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency bitsets* – `O(m)` operations.  

*Main loops* – at most `n·(n-1)/2 ≤ 2·10⁶` iterations.
Each iteration performs a constant‑time integer `&`, a mask, and a few
bit operations on a 2000‑bit integer, all `O(1)` in Python.

Hence  

```
Time   :  O(n²)   ≤ 2·10⁶   (well below the 2 s limit)
Memory :  O(n)    (n integers of ≤2000 bits ≈ 250 KB)
```

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * n          # bitset of neighbours for each vertex

    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u] |= 1 << v
        adj[v] |= 1 << u

    for a in range(n):
        mask_a = adj[a]
        for b in range(a + 1, n):
            if (mask_a >> b) & 1 == 0:          # edge a‑b missing
                continue
            inter = mask_a & adj[b]             # common neighbours
            # delete vertices ≤ b
            inter &= ~((1 << (b + 1)) - 1)
            if inter:
                low = inter & -inter             # lowest set bit
                c = low.bit_length() - 1
                # output 1‑based, sorted
                sys.stdout.write(f"{a+1} {b+1} {c+1}")
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
