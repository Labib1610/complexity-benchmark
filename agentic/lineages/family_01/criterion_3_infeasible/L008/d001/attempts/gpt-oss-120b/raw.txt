**Solution Explanation**

For every employee we store the set of his enemies as a bitset.
`adj[v]` is an integer whose *i*-th bit (0‑based) is `1` iff employees `v` and `i`
dislike each other.

A triangle `{a,b,c}` (`a<b<c`) exists **iff**

* edge `(a,b)` exists,
* there is a vertex `c>b` that is adjacent to both `a` and `b`.

So we can enumerate all ordered pairs `(a,b)` with `a<b` in lexicographic order,
test whether the edge exists and, if it does, look for the smallest common
neighbour larger than `b`.  
The first triple we find is exactly the required minimal one.

`n ≤ 2000`, therefore `n²/2 ≈ 2·10⁶` iterations – easily fast enough.
All operations on the bitsets are O(1) because Python integers support
bitwise operations on arbitrarily many bits.

--------------------------------------------------------------------

#### Algorithm
```
read n, m
adj = [0] * n
for each (u,v):
        u-- ; v--
        adj[u] |= 1 << v
        adj[v] |= 1 << u

fullMask = (1 << n) - 1          # bits 0 … n-1 are 1

for a = 0 … n-1:
        for b = a+1 … n-1:
                if ((adj[a] >> b) & 1) == 0:        # edge (a,b) missing
                        continue
                common = adj[a] & adj[b]            # neighbours of both
                # keep only vertices > b
                mask   = fullMask ^ ((1 << (b+1)) - 1)
                common_high = common & mask
                if common_high != 0:
                        # index of least set bit
                        c = (common_high & -common_high).bit_length() - 1
                        output a+1, b+1, c+1
                        return
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs the lexicographically smallest triangle.

---

**Lemma 1**  
For fixed `a<b`, after the test `if ((adj[a]>>b)&1)==0` the variable `common`
contains exactly the vertices adjacent to **both** `a` and `b`.

*Proof.*  
`adj[a]` has a `1` at position `x` iff `a`–`x` is an edge.
Bitwise `&` keeps a `1` at `x` only when both operands have `1` there,
i.e. when both edges `a`–`x` and `b`–`x` exist. ∎



**Lemma 2**  
`common_high` is the set of vertices `c` such that `c>b` and `{a,b,c}` is a
triangle.

*Proof.*  
`mask` has `1`s exactly for indices `>b`.  
`common_high = common & mask` therefore keeps precisely those vertices that
are common neighbours of `a` and `b` **and** larger than `b`.  
By Lemma&nbsp;1 each such vertex `c` is adjacent to both `a` and `b`; together
with the already known edge `(a,b)` they form a triangle. ∎



**Lemma 3**  
If `common_high ≠ 0`, the computed `c` is the smallest vertex `>b` that
together with `a,b` forms a triangle.

*Proof.*  
`common_high & -common_high` isolates the least‑significant set bit of
`common_high`. Its index is exactly the smallest element of the set. ∎



**Lemma 4**  
The first triple printed by the algorithm is the lexicographically smallest
triangle in the whole graph.

*Proof.*  
The outer loops enumerate all ordered pairs `(a,b)` with `a<b` in increasing
lexicographic order.  
For a given pair the algorithm, by Lemma&nbsp;3, chooses the smallest possible
`c>b`.  
Hence any triangle `{a',b',c'}` with `(a',b')` lexicographically larger than the
current `(a,b)` cannot be printed earlier.  
If a triangle has the same `(a,b)` but a larger `c`, Lemma 3 guarantees we output
the one with the smallest `c`.  
Therefore the first printed triple is minimal w.r.t. `(a,b,c)`. ∎



**Theorem**  
The algorithm always outputs three distinct employee numbers `a<b<c` that form
a triangle, and among all such triangles it outputs the one with minimal
lexicographic order.

*Proof.*  
Existence of at least one triangle is guaranteed by the statement.
When the loops reach the pair `(a,b)` belonging to the lexicographically
smallest triangle, Lemma 2 ensures `common_high` is non‑empty, Lemma 3 gives its
correct third vertex, and the algorithm prints it and terminates.
By Lemma 4 this triangle is the minimal one. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency*: `O(m)`  
*Main loops*: at most `n·(n-1)/2 ≤ 2·10⁶` iterations, each O(1).  

Total time `O(n² + m) ≤ 2·10⁶ + 2·10⁵` → well below the limit.  

Memory: `n` integers of up to `n` bits → `O(n)` ≈ 2000·(2000/8) ≈ 0.5 MiB.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * n
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u] |= 1 << v
        adj[v] |= 1 << u

    full_mask = (1 << n) - 1

    for a in range(n):
        for b in range(a + 1, n):
            if ((adj[a] >> b) & 1) == 0:          # edge (a,b) missing
                continue
            common = adj[a] & adj[b]              # neighbours of both
            mask = full_mask ^ ((1 << (b + 1)) - 1)   # bits > b
            common_high = common & mask
            if common_high:
                # index of least set bit
                c = (common_high & -common_high).bit_length() - 1
                sys.stdout.write(f"{a+1} {b+1} {c+1}")
                return

if __name__ == "__main__":
    solve()
```
