# Problem C — Tripartite Trust Quorum

Time limit: 2 s   Memory limit: 256 MB

You are auditing a secure communication network comprising $n$ distinct server terminals. The system relies on bilateral trust channels established between specific pairs of terminals. 

A "tripartite trust quorum" is required to authorize a high-level system update. This quorum is formed by exactly three distinct terminals if and only if all three possible two-terminal combinations among them have a pre-established bilateral trust channel. 

Your task is to identify one such quorum. The network configuration guarantees that at least one tripartite trust quorum exists.

## Input
The first line provides two integers, $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n(n-1)/2, 2 \cdot 10^5)$), representing the number of server terminals and the number of bilateral trust channels, respectively. Terminals are identified by integers from $1$ to $n$.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n, u \neq v$), indicating that a bilateral trust channel exists between terminal $u$ and terminal $v$.
It is guaranteed that the provided records contain at least one tripartite trust quorum.

## Output
Output three integers $a$, $b$, and $c$ on a single line, ordered such that $a < b < c$, representing the three terminals that form a tripartite trust quorum (meaning the bilateral channels $a$–$b$, $a$–$c$, and $b$–$c$ are all present in the input). If there is more than one such set of three terminals, you must output the one that minimizes the quorum authorization code, defined as $a \cdot 10^8 + b \cdot 10^4 + c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
