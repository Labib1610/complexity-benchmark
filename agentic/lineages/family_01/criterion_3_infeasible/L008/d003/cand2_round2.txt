# Problem C — Proof of Impossibility

Time limit: 2 s
Memory limit: 256 MB

Management insists on dividing the computing cluster into exactly two non-overlapping networks. However, the system administrator knows this plan is doomed. You must provide undeniable proof of this failure.

The administrator has a collection of interference logs, where each log lists two specific servers that cannot be placed on the same network. 

It is a known fact that the cluster contains at least one triad of servers that mutually conflict. That is, within this triad, the first server interferes with the second, the second interferes with the third, and the third interferes with the first. The existence of such a triad mathematically guarantees that two networks are inadequate. Your task is to identify and report one such triad to the administrator.

## Input
The first line of the log provides the server count $n$ and the total interference count $m$. The server count $n$ is bounded below by the required triad size of 3 and bounded above by the rack capacity of 2000. The interference count $m$ is at least 3, and is capped by either the theoretical maximum of $n(n-1)/2$ distinct combinations, or the archival capacity of $2 \cdot 10^5$, whichever is smaller. Servers are identified by integers from 1 to $n$.

Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), identifying the two servers involved in a single interference log.

It is guaranteed that at least one valid triad of servers exists.

## Output
Output three space-separated integers $a$, $b$, and $c$ representing the IDs of the three servers in the triad. They must be printed such that $a < b < c$.

To ensure a unique valid response when multiple such triads exist, you must select the triad that minimizes the value of $a$. If there is a tie, minimize the value of $b$ among the tied triads, and if a tie still persists, minimize $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
