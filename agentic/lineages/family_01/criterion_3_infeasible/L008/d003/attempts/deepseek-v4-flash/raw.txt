We need to find a triangle in the graph where each pair is connected, and among all such triangles, pick the one with the smallest lexicographic-like score:  
\( a \cdot 10^8 + b \cdot 10^4 + c \) with \( a < b < c \).

Since \( n \leq 2000 \), we can use adjacency sets for fast lookups.  
We can iterate over all edges and check for a common neighbor that forms a triangle, while keeping track of the best (smallest score) triangle.

Here’s the implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    edges = []
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
        edges.append((u, v))
    
    best = None
    best_score = None
    
    for u, v in edges:
        # Find common neighbors
        common = adj[u] & adj[v]
        for w in common:
            a, b, c = sorted([u+1, v+1, w+1])
            score = a * 10**8 + b * 10**4 + c
            if best_score is None or score < best_score:
                best_score = score
                best = (a, b, c)
    
    print(*best)

if __name__ == "__main__":
    solve()
```
