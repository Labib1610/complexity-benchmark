We need to find three distinct workers such that among the three incident files connecting them, exactly three distinct workers appear.  

That means: we are looking for a triangle in the graph (three workers all pairwise connected by edges).  

The problem guarantees at least one triangle exists. We need the lexicographically smallest triangle (a < b < c).  

We can solve this by iterating over all possible triples in sorted order and checking if all three edges exist.  

Since n ≤ 2000, checking all triples naively is O(n³) = 8e9, too slow.  
We can instead iterate over a and b, and check for c > b such that edges (a,b), (a,c), (b,c) exist.  

We can store edges in a boolean matrix or set for O(1) lookup.  

We iterate a from 1 to n, b from a+1 to n, and if edge (a,b) exists, we check c from b+1 to n.  
The first found triple is the answer because we iterate in lexicographic order.  

Here’s the implementation:  

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = adj[v][u] = True

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if adj[a][b]:
                for c in range(b + 1, n + 1):
                    if adj[a][c] and adj[b][c]:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    main()
```
