We need to find three distinct workers such that there are exactly three incident files among them, and each worker appears in exactly two of those files.  

That means the three files form a triangle in the graph: three edges among three vertices.  

We need the lexicographically smallest triangle (a < b < c) in terms of vertex IDs.  

We can iterate over possible smallest vertex `a`, then `b`, then check if `c` exists such that edges (a,b), (a,c), (b,c) are all present.  

We’ll use an adjacency set for O(1) edge lookups.  

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if b not in adj[a]:
                continue
            # Find smallest c > b such that a-c and b-c exist
            for c in range(b + 1, n + 1):
                if c in adj[a] and c in adj[b]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    solve()
```
