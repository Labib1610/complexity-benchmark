<METHOD_NAME>
Induced Subgraph Degree Formulation
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the explicit description of a triangle (three files among three workers) with a degree condition on an induced subset of size 3. By requiring that each worker in a 3-person subset appears in exactly two of the files completely contained within that subset, models must deduce that all three possible pairs exist, preventing simple pattern-matching on "triangle" or "three interconnected nodes".
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<STATEMENT>
# Problem C — Proof of Impossibility

Time limit: 2 s
Memory limit: 256 MB

Management insists on dividing the workforce into exactly two non-overlapping shifts. However, the HR department knows this plan is doomed. You must provide undeniable proof of this failure.

HR has a collection of incident files. Each file lists two specific workers who cannot be placed on the same shift. 

To demonstrate that a valid two-shift assignment is mathematically impossible, you must find a specific configuration of workers. Specifically, you need to identify a subset of exactly three distinct workers that satisfies the following internal condition: if you filter the archives to isolate only those incident files where both listed individuals belong to this subset, each of the three workers will appear in exactly two of those isolated files.

Your task is to find one such group of three workers and report them to HR. It is guaranteed that the archives contain at least one valid configuration.

## Input
The first line of the input provides the workforce size n and the total incident count m. The workforce size n is at least 3 and at most 2000. The incident count m is at least 3, and does not exceed the theoretical maximum of n·(n−1)/2 distinct pairs, nor the archival limit of 2·10⁵. Workers are identified by integers from 1 to n.

Each of the next m lines contains two integers u and v (1 ≤ u, v ≤ n, u ≠ v), identifying the two workers involved in a single incident. No two incident files list the exact same pair of workers.

## Output
Output three space-separated integers a, b, and c representing the IDs of the three workers in the group. They must be printed such that a < b < c.

To ensure a unique valid response when multiple such groups of workers exist, you must select the group that minimizes the value of a. If there is a tie, minimize the value of b among the tied groups, and if a tie still persists, minimize c.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
</STATEMENT>
<RATIONALE>
The explicit mention of three files featuring exactly three workers was removed to prevent models from immediately recognizing a triangle. Instead, the condition is framed as an induced subgraph degree property: within a subset of three workers, each worker must be part of exactly two fully internal incident files. This forces the model to logically deduce that this configuration is structurally equivalent to a 3-clique.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that a subset of 3 workers has each worker appearing in exactly 2 internal files is mathematically identical to a triangle (3-clique), meaning the exact same subset of workers will be selected for any given input.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a triangle (a K3 subgraph) to prove the graph is not bipartite, keeping it in the INFEASIBLE class with the identical algorithmic complexity and solution structure.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "isolate only those incident files where both listed individuals belong to this subset" as a complex global filtering task rather than a simple induced subgraph restriction, but a careful reading unambiguously defines the required condition.
</RISK>
