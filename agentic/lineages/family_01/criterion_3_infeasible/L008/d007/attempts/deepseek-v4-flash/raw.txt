We need to find a triple of workers such that the induced subgraph on those three vertices is not bipartite — i.e., it contains a triangle.  

The condition “impossible to divide into two shifts” for three workers means the three pairwise incident files form a triangle (all three edges present).  

So the problem reduces to: find the lexicographically smallest triangle in the graph.  

We can do this by iterating over all triples in sorted order and checking if all three edges exist. Since n ≤ 2000, O(n³) is too slow in the worst case (8e9 operations).  

We can instead iterate over edges and check for a common neighbor, but we need lexicographic order.  

A better approach:  
- Sort vertices by ID.  
- For each a from 1 to n:  
  - For each b > a that is adjacent to a:  
    - For each c > b that is adjacent to both a and b:  
      - If found, output (a, b, c) and stop.  

We can store adjacency in a boolean matrix for O(1) checks.  

Complexity: O(n²) in practice if we break early, but worst-case O(n³) if dense. However, n=2000 and m ≤ 2e5, so we can use adjacency sets and iterate only over existing edges.  

Implementation:  

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        for b in sorted(adj[a]):
            if b <= a:
                continue
            for c in sorted(adj[a]):
                if c <= b:
                    continue
                if c in adj[b]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
