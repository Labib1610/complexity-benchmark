 We can solve this by iterating over all triples of workers and checking the condition directly.  
Since \( n \) can be up to 2000, checking all triples naively would be \( O(n^3) \), which is too slow.  
We need a smarter approach.

We can precompute the degree of each worker (number of incident files they appear in).  
For a triple \((a,b,c)\):
- \( T = \deg(a) + \deg(b) + \deg(c) \)
- \( E \) = number of edges from the triple to outside.  
  This can be computed as:  
  \( E = (\deg(a) + \deg(b) + \deg(c)) - 2 \times (\text{edges inside the triple}) \)  
  because each internal edge contributes 2 to the sum of degrees but should not be counted in \( E \).

So condition \( T = E + 6 \) becomes:  
\( \deg(a)+\deg(b)+\deg(c) = (\deg(a)+\deg(b)+\deg(c) - 2 \times \text{internal\_edges}) + 6 \)  
Simplify:  
\( 0 = -2 \times \text{internal\_edges} + 6 \)  
So:  
\( \text{internal\_edges} = 3 \)

That means the triple must form a triangle (all three edges present).  

So the problem reduces to: find the lexicographically smallest triangle in the graph.

We can do this by iterating over \( a \) from 1 to n, then \( b > a \), and checking if edge (a,b) exists. If yes, then for each \( c > b \) that is connected to both a and b, we have a triangle. The first one found in this order is the answer.

Complexity:  
- Checking adjacency is O(1) with a set or boolean matrix.  
- Worst case: O(n^3) if many edges, but with n=2000 and m up to 2e5, we can still do it efficiently if we only iterate over existing edges for b and c.

We can store adjacency lists and iterate over neighbors.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(n):
        for b in adj[a]:
            if b > a:
                for c in adj[b]:
                    if c > b and c in adj[a]:
                        print(a+1, b+1, c+1)
                        return

if __name__ == "__main__":
    main()
```
