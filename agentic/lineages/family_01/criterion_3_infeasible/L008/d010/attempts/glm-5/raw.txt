Looking at this problem, I need to find three workers $a, b, c$ such that $S + U = m + 3$.

Let me analyze what this means:
- $S = d(a) + d(b) + d(c)$ where $d(x)$ is the degree of worker $x$
- $U = m - |E(a) \cup E(b) \cup E(c)|$ where $E(x)$ is the set of edges incident to $x$

So $S + U = m + 3$ becomes:
$$d(a) + d(b) + d(c) - |E(a) \cup E(b) \cup E(c)| = 3$$

By inclusion-exclusion:
$$|E(a) \cup E(b) \cup E(c)| = d(a) + d(b) + d(c) - |E(a) \cap E(b)| - |E(a) \cap E(c)| - |E(b) \cap E(c)| + |E(a) \cap E(b) \cap E(c)|$$

Substituting:
$$|E(a) \cap E(b)| + |E(a) \cap E(c)| + |E(b) \cap E(c)| - |E(a) \cap E(b) \cap E(c)| = 3$$

The intersection $E(a) \cap E(b)$ consists of edge $(a,b)$ if it exists, plus edges from $a$ or $b$ to common neighbors. The triple intersection is edges from $a$, $b$, and $c$ to a common vertex.

Let me define:
- $e_{ab} = 1$ if edge $(a,b)$ exists, else 0
- $c_{ab}$ = number of common neighbors of $a$ and $b$ (excluding $c$)
- $t$ = number of common neighbors of all three

The condition becomes:
$$(e_{ab} + c_{ab}) + (e_{ac} + c_{ac}) + (e_{bc} + c_{bc}) - t = 3$$

**Key insight:** If $a, b, c$ form a triangle, then $e_{ab} = e_{ac} = e_{bc} = 1$, and the common neighbors of any pair (excluding the third vertex) don't include the third vertex. The triple intersection counts common neighbors of all three.

For a triangle with no other common neighbors: $1 + 1 + 1 - 0 = 3$ ✓

If there's a common neighbor $w$ of all three, it contributes 1 to each pair intersection and 1 to the triple intersection, net contribution = $3 - 1 = 2$. This would make the sum $> 3$.

So the condition is: **$a, b, c$ form a triangle AND they have no common neighbor.**

I can iterate over all edges $(a, b)$ with $a < b$, then for each common neighbor $c > b$ of $a$ and $b$, check if $a, b, c$ have no common neighbor other than themselves.

To check efficiently: for each pair $(a, b)$, precompute common neighbors. For the triple check, I iterate over the smaller adjacency list among $a, b, c$ and verify no vertex is common to all three (excluding $a, b, c$ themselves).

```python
import sys

def main():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [set() for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        if u > v:
            u, v = v, u
        adj[u].add(v)
        adj[v].add(u)
        edges.append((u, v))
    
    best = None
    
    for a, b in edges:
        common = adj[a] & adj[b]
        for c in common:
            if c > b:
                # Check no common neighbor of all three (excluding a, b, c)
                # Iterate over smallest adjacency list
                if len(adj[a]) <= len(adj[b]) and len(adj[a]) <= len(adj[c]):
                    smallest, other1, other2 = adj[a], adj[b], adj[c]
                elif len(adj[b]) <= len(adj[c]):
                    smallest, other1, other2 = adj[b], adj[a], adj[c]
                else:
                    smallest, other1, other2 = adj[c], adj[a], adj[b]
                
                ok = True
                for w in smallest:
                    if w != a and w != b and w != c and w in other1 and w in other2:
                        ok = False
                        break
                
                if ok:
                    if best is None or (a, b, c) < best:
                        best = (a, b, c)
    
    print(f"{best[0]} {best[1]} {best[2]}")

main()
```

The complexity: iterating over edges and common neighbors is $O(m \cdot d_{\max})$ in the worst case, but with the set intersection optimization it's efficient. The triple check iterates over the smallest adjacency list, which is bounded by $O(n)$ per triangle candidate. Given the constraints ($n \le 2000$, $m \le 2 \times 10^5$), this should be efficient enough.
