We need to find a triplet of workers (a, b, c) such that there exist three incident files:

- Primary: (a, x)  
- Secondary: (b, x)  
- Closing: (a, b)  

Where x is some worker different from a and b, and the closing file is exactly the pair (a, b).  

That means:  
- We need two edges (a, x) and (b, x) sharing exactly one worker x.  
- And an edge (a, b) must exist.  

So the deadlock is a triangle in the graph: three workers a, b, x such that all three edges (a,b), (a,x), (b,x) exist.  

We need to output the three workers sorted, with minimal a, then b, then c.

We can solve by iterating over all possible a < b < c and checking if all three edges exist.  
Since n ≤ 2000, we can store edges in a boolean matrix or set for O(1) lookup.

We’ll iterate a from 1 to n, b from a+1 to n, c from b+1 to n, and check if (a,b), (a,c), (b,c) are all in the edge set. The first found is the answer.

Complexity: O(n³) worst-case, but n=2000 → 8e9 too big. We need a better approach.

Better:  
For each pair (a, b) that has an edge, we look for a common neighbor c such that (a,c) and (b,c) exist.  
We can store adjacency sets.  
For each edge (a,b), we intersect adjacency[a] and adjacency[b]. If intersection non-empty, pick smallest c in intersection.  
Then we have a candidate (a,b,c).  
We need to pick the minimal (a,b,c) lexicographically.

We can iterate a from 1..n, b from a+1..n, if edge exists, find smallest c in intersection.  
Since we iterate a in increasing order, and b in increasing order, the first found will be minimal.

Implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n+1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n+1):
        for b in range(a+1, n+1):
            if b in adj[a]:
                # find smallest c in intersection
                common = adj[a] & adj[b]
                if common:
                    c = min(common)
                    if c > b:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    solve()
```
