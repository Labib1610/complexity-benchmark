We need to find a triangle in an undirected graph, and among all triangles, pick the one with the smallest lexicographic order based on the given scoring formula.  

Since the scoring formula is essentially lexicographic ordering of `(a, b, c)` with `a < b < c`, we can just search for the smallest triangle in that order.

A direct brute force over all triples would be too slow for `n = 2000` and `m = 2e5`.  
We can instead iterate over each edge `(u, v)` and check common neighbors, but we need to be careful to find the smallest triangle.

A practical approach:
- Sort vertices by index.
- For each vertex `a` from 1 to n:
  - For each neighbor `b` of `a` with `b > a`:
    - For each neighbor `c` of `b` with `c > b`:
      - If `c` is also a neighbor of `a`, we found a triangle.
      - Since we iterate in increasing order, the first triangle found is the smallest.

We can speed up neighbor checks using sets.

Let’s implement this.  

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        for b in adj[a]:
            if b > a:
                for c in adj[b]:
                    if c > b and c in adj[a]:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    main()
```
