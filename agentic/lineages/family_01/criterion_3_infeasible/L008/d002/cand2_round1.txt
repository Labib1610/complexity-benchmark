# Problem C — Planetary Lock

Time limit: 2 s
Memory limit: 256 MB

You are designing a complex clockwork mechanism using a new set of standardized gear types. 

Through extensive testing, the engineering team has compiled a catalog of valid meshing configurations. Each configuration confirms that a specific pair of gear types can be placed in direct contact to transmit rotation. Meshing is bidirectional: if type $u$ can mesh with type $v$, then type $v$ can mesh with type $u$.

A critical design flaw known as a "planetary lock" occurs if a mechanism contains a subset of exactly three distinct gear types where every possible pair drawn from that subset is capable of meshing. If such a combination is assembled, the gears will physically jam and fail to rotate. 

It is a known fact that the provided catalog contains at least one such combination of three gear types that will cause a planetary lock. Your task is to identify one such triplet to include in the safety report.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), representing the number of gear types and the number of valid meshing configurations, respectively. Gear types are identified by integers from $1$ to $n$.

Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing a pair of gear types that can mesh together.

It is guaranteed that at least one planetary lock (a set of three mutually meshing gear types) exists in the catalog.

## Output
Print three integers $a$, $b$, and $c$, separated by spaces, representing the integer codes of the gear types in the lock. You must list them in ascending order ($a < b < c$).

To ensure a unique valid response when multiple such locks exist, you must select the lock that minimizes the value of $a$. If there is a tie, minimize the value of $b$ among the tied locks, and if a tie still persists, minimize $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
