We need to find a triangle in an undirected graph with up to 2000 vertices and 200,000 edges, and among all triangles, output the one with the smallest lexicographic-like score:  
`a*10^8 + b*10^4 + c` with `a < b < c`.

Since `n` is up to 2000, we can use an adjacency matrix (boolean) for O(1) edge checks, and iterate over possible triangles efficiently.

A straightforward triple loop over all combinations would be O(n^3) = 8e9, too slow.  
We need a smarter approach.

We can iterate over each edge `(u, v)` and check for a common neighbor `w` such that `u < v < w` (to avoid duplicates and ensure ordering).  
For each edge, we can check all vertices `w` from `v+1` to `n` and see if both `(u,w)` and `(v,w)` exist.  
That would be O(m * n) in worst case = 200,000 * 2000 = 4e8, which might be borderline but likely okay in Python if optimized with bitsets or early exit.

We can use Python’s `int` bitmask for adjacency: each vertex has an integer where bit `j` is 1 if edge to vertex `j` exists.  
Then for edge `(u,v)`, the common neighbors are `adj[u] & adj[v]`.  
We can iterate over set bits of that intersection, pick the smallest `w > v`, and that gives the smallest triangle for that edge.  
Then we take the overall minimum score.

Since we need `a < b < c`, we can iterate edges with `u < v`, and for each, find smallest `w > v` in the intersection.

Complexity: O(m * (number of set bits in intersection)) but we can break early after finding the first `w` for each edge.  
Worst case still O(m * n) but with bit operations it's fast.

Let's implement:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [0] * (n + 1)
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u] |= (1 << v)
        adj[v] |= (1 << u)
    
    best = None
    best_score = None
    
    for u in range(1, n + 1):
        for v in range(u + 1, n + 1):
            if (adj[u] >> v) & 1:
                common = adj[u] & adj[v]
                # find smallest w > v
                # mask out bits <= v
                mask = common & ~((1 << (v + 1)) - 1)
                if mask:
                    # get lowest set bit
                    w = (mask & -mask).bit_length() - 1
                    score = u * 10**8 + v * 10**4 + w
                    if best_score is None or score < best_score:
                        best_score = score
                        best = (u, v, w)
    
    print(*best)

if __name__ == "__main__":
    main()
```
