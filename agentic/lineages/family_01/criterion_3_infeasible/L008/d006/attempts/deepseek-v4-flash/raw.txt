We need to find a set of exactly three incident files that involve exactly three distinct workers.  
That means we’re looking for a triangle in the graph where edges are the incident files.  

We need the lexicographically smallest triangle (a < b < c).  

A direct approach:  
- Iterate over all possible smallest vertex `a` from 1 to n.  
- For each `a`, iterate over possible `b > a` that is connected to `a`.  
- For each such `b`, iterate over possible `c > b` that is connected to both `a` and `b`.  
- The first found is the answer because we iterate in sorted order.  

We can store adjacency as sets for O(1) lookups.  

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(1, n + 1):
        for b in sorted(adj[a]):
            if b <= a:
                continue
            for c in sorted(adj[a]):
                if c <= b:
                    continue
                if c in adj[b]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    solve()
```
