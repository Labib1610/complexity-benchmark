We can solve this by representing the complement pairs as an adjacency list and then checking all triples in increasing order until we find a triangle.  

Since the score is minimized by the lexicographically smallest triple `(a, b, c)` with `a < b < c`, we can iterate `a` from 1 to n, then `b` from `a+1` to n, then `c` from `b+1` to n, and check if all three edges exist. The first found triple is the answer.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = True
        adj[v][u] = True

    for a in range(1, n - 1):
        for b in range(a + 1, n):
            if not adj[a][b]:
                continue
            for c in range(b + 1, n + 1):
                if adj[a][c] and adj[b][c]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
