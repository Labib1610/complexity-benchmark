Looking at this problem, I need to find a triangle in a graph where all three vertices are mutually connected. Among all triangles, I need to find the one that minimizes the score `a * 10^8 + b * 10^4 + c` where `a < b < c`.

Since the score is essentially a lexicographic ordering on (a, b, c), I want to find the triangle with the smallest first vertex, then smallest second vertex, then smallest third vertex.

**Approach:**
- For each vertex `a` from 1 to n (trying to minimize a first):
  - For each neighbor `b` of `a` where `b > a` (trying to minimize b):
    - For each neighbor `c` of `a` where `c > b`:
      - Check if `b` and `c` are connected. If yes, we found our triangle.

To make the inner check efficient, I store neighbors as sets. For each `a`, I iterate through pairs of neighbors `(b, c)` with `b < c` both greater than `a`, and check if edge `(b, c)` exists.

The complexity is O(n * d^2) where d is the max degree. With n up to 2000 and m up to 2*10^5, in the worst case d could be ~2000, giving ~8*10^9 operations which might be too slow. However, the problem guarantees at least one triangle exists, so we'll likely find one early.

To optimize, I process vertices in order and return as soon as I find the first valid triangle. Since we want minimum (a, b, c) lexicographically, the first triangle found this way is the answer.

Let me also add an optimization: sort neighbors and use early termination when possible.

```python
import sys
from sys import stdin

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [set() for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        adj[u].add(v)
        adj[v].add(u)
        edges.append((u, v))
    
    # Try to find triangle with minimum (a, b, c) lexicographically
    for a in range(1, n + 1):
        neighbors_a = sorted(x for x in adj[a] if x > a)
        for i in range(len(neighbors_a)):
            b = neighbors_a[i]
            for j in range(i + 1, len(neighbors_a)):
                c = neighbors_a[j]
                if c in adj[b]:
                    print(f"{a} {b} {c}")
                    return

solve()
```

Actually, let me use a hybrid approach. For each edge (u, v) with u < v, find common neighbors w where w > v. The first such (u, v, w) in lexicographic order is the answer.

To iterate edges in lexicographic order of (u, v), I sort edges. Then for each edge, I find the smallest common neighbor > v.

```python
import sys

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [set() for _ in range(n + 1)]
    edge_list = []
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        if u > v:
            u, v = v, u
        adj[u].add(v)
        adj[v].add(u)
        edge_list.append((u, v))
    
    edge_list.sort()
    
    for u, v in edge_list:
        # Find smallest w > v that is neighbor of both u and v
        common = adj[u] & adj[v]
        candidates = [w for w in common if w > v]
        if candidates:
            w = min(candidates)
            print(f"{u} {v} {w}")
            return

solve()
```

This is O(m * d) in the worst case for the set intersection, but Python set intersection is efficient. With m = 2*10^5 and d up to 2000, this could be 4*10^8 operations in the worst case, but set operations in Python are implemented in C and quite fast.

This should be efficient enough. The key optimizations are:
1. Processing edges in sorted order ensures we find the lexicographically smallest triangle first.
2. Iterating over the smaller adjacency set for the common neighbor check.
3. Early termination once we find a valid triangle.

The time complexity is O(m log m) for sorting plus O(sum over edges of min(deg(u), deg(v))) for the triangle search, which is efficient given the constraints.
