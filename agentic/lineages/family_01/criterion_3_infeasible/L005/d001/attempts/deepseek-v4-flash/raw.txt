We need to find a triangle in the graph where every pair among the three nodes is directly connected.  
That’s simply a clique of size 3.  

We can iterate over all possible triples in lexicographic order and check if all three edges exist.  
Since \( n \leq 2000 \), checking all triples naively would be \( O(n^3) \), which is too slow.  

We can instead iterate over each edge \((u, v)\) and check for a common neighbor \(w\) that is connected to both.  
To get the lexicographically smallest triple, we can iterate \(a\) from 1 to \(n\), then \(b\) from \(a+1\) to \(n\), and check if edge \((a,b)\) exists, then find the smallest \(c > b\) connected to both.  

We can store adjacency as a set for fast lookup.  

Here’s the implementation:  

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(n):
        for b in range(a+1, n):
            if b in adj[a]:
                for c in range(b+1, n):
                    if c in adj[a] and c in adj[b]:
                        print(a+1, b+1, c+1)
                        return

if __name__ == "__main__":
    solve()
```
