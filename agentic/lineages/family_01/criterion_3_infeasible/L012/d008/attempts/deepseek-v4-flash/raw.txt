 We can interpret the problem as follows:  

A triple is *locked* if, for every way to assign 0 or 1 to its three elements, at least one edge inside the triple connects two vertices with the same assigned value.  

That means:  
- If the triple has 0 edges → not locked (all assignments possible with no same-value edges).  
- If the triple has 1 edge → not locked (assign the two connected vertices different values, third arbitrary).  
- If the triple has 2 edges → not locked (assign the two connected vertices different values, third can be anything).  
- If the triple has 3 edges (a triangle) → locked, because any 2-coloring of a triangle forces two adjacent vertices to have the same color.  

So the problem reduces to: **Find the lexicographically smallest triangle in the graph.**  

We can do this by iterating over all triples in increasing order and checking if all three edges exist. Since \( n \leq 2000 \), we can use an adjacency matrix for O(1) edge checks.  

Here’s the implementation:  

```python
n, m = map(int, input().split())
adj = [[False] * n for _ in range(n)]

for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u][v] = adj[v][u] = True

for a in range(n - 2):
    for b in range(a + 1, n - 1):
        if not adj[a][b]:
            continue
        for c in range(b + 1, n):
            if adj[a][c] and adj[b][c]:
                print(a + 1, b + 1, c + 1)
                exit()
```
