We need to find the lexicographically smallest triple of sensors that cannot be assigned to two phases without conflict.  

That means the three sensors must form a triangle (all three pairwise connected), because only then is it impossible to 2-color them without conflict.  

So the problem reduces to: find the lexicographically smallest triangle in an undirected graph.  

We can do this by iterating over possible smallest node `a`, then over possible second node `b > a`, and checking if there is a `c > b` connected to both.  

To make it efficient, we can use adjacency sets for O(1) neighbor checks.  

Here’s the implementation:  

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(n):
        for b in range(a+1, n):
            if b in adj[a]:
                # find smallest c > b connected to both a and b
                common = adj[a] & adj[b]
                for c in sorted(common):
                    if c > b:
                        print(a+1, b+1, c+1)
                        return

if __name__ == "__main__":
    solve()
```
