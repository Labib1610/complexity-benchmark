**Solution Explanation**

For three sensors `a < b < c` the induced subgraph is *not* bipartite **iff**
the three edges `(a,b) , (a,c) , (b,c)` are all present – i.e. the three
sensors form a triangle.
The task is therefore:

*find the lexicographically smallest triangle in the given undirected graph.*

--------------------------------------------------------------------

#### 1.   Data structures  

* `adj_bool` – `n+1` × `n+1` boolean matrix (`bytearray`)  
  `adj_bool[u][v] = 1`  ⇔  edge `u‑v` exists.  
  Needed for the cheap test “is there an edge (a,b)?”.

* `adj_mask[u]` – Python `int` whose binary representation has a `1` at
  position `v` (`0`‑based) exactly when edge `u‑v` exists.  
  With bit operations we can intersect neighbour sets of two vertices
  in **O(1)** time.

Both structures need `O(n²)` memory, at most `2000² = 4·10⁶` bits
(~0.5 MiB) – well inside the limits.

--------------------------------------------------------------------

#### 2.   Searching the smallest triangle  

We iterate `a` from `1` to `n`.  
For each `a` we iterate `b` from `a+1` to `n`.

```
if edge a‑b does not exist: continue
common = neighbours(a) ∩ neighbours(b)          # bitwise AND
# we need a vertex c > b, therefore discard bits ≤ b
common >>= b                                      # shift right b positions
if common == 0: continue
# lowest set bit gives the smallest possible c
lsb = common & -common
pos = lsb.bit_length() - 1        # 0‑based position inside the shifted mask
c = b + 1 + pos                     # restore original vertex number
output a b c
```

Why does this give the lexicographically smallest triangle?

* The outer loops increase `a` first, then `b`.  
  The first time we discover a triangle we have the smallest possible `a`,
  and for this `a` the smallest possible `b`.
* Inside the inner loop we take the **lowest** vertex `c > b`
  that is adjacent to both `a` and `b`.  
  Hence `c` is minimal as well.

Because the problem guarantees that at least one triangle exists,
the algorithm will always terminate with an answer.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
triangle.

---

##### Lemma 1  
For any pair of vertices `a < b` the expression  

```
common = adj_mask[a] & adj_mask[b]
common >>= b
```

contains a `1` at position `k` (0‑based) **iff** vertex `c = b+1+k`
is adjacent to **both** `a` and `b` and satisfies `c > b`.

**Proof.**  
`adj_mask[a] & adj_mask[b]` has a `1` exactly at positions of vertices
adjacent to both `a` and `b`. Shifting right by `b` discards bits
for vertices `≤ b`. The remaining bits correspond bijectively to vertices
`c > b`. ∎



##### Lemma 2  
If `common` (after the shift) is non‑zero, the vertex  

```
c = b + 1 + (common & -common).bit_length() - 1
```

is the smallest vertex `c > b` adjacent to both `a` and `b`.

**Proof.**  
`common & -common` isolates the least‑significant `1` of `common`,
i.e. the smallest index `k` with a `1`.  
`bit_length() - 1` yields that index `k`.  
By Lemma&nbsp;1 the corresponding vertex is `c = b+1+k`, the smallest
possible one. ∎



##### Lemma 3  
When the algorithm prints a triple `(a,b,c)`, the three edges
`ab, ac, bc` are present, i.e. the three vertices form a triangle.

**Proof.**  
The algorithm prints only after confirming `adj_bool[a][b] = 1`.  
By Lemma&nbsp;2 the chosen `c` satisfies `adj_bool[a][c] = 1` and
`adj_bool[b][c] = 1`. Hence all three edges exist. ∎



##### Lemma 4  
Let `(a₀,b₀,c₀)` be the first triple printed by the algorithm.
Then no triangle `(a',b',c')` exists with
`a' < a₀`, or `a' = a₀` and `b' < b₀`, or `a' = a₀, b' = b₀` and `c' < c₀`.

**Proof.**  
The outer loops enumerate pairs `(a,b)` in increasing lexicographic order.
For a fixed `(a,b)` Lemma&nbsp;2 yields the smallest possible `c`.
Therefore the first printed triple is the minimal one among all
triangles whose first two vertices are `(a,b)`.  
Since the enumeration of `(a,b)` itself is lexicographically ordered,
no earlier pair can belong to a triangle that the algorithm missed.
∎



##### Theorem  
The algorithm outputs the lexicographically smallest triangle of the
input graph.

**Proof.**  
By Lemma&nbsp;3 the output is a triangle.
By Lemma&nbsp;4 no triangle is lexicographically smaller.
Thus the output is exactly the required triangle. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building the structures* : `O(n²)` time for the boolean matrix,
`O(m)` for the bit masks – overall `O(n² + m)` ≤ `4·10⁶`.

*Search* : two nested loops over `a` and `b` → `O(n²)` iterations,
each performing only constant‑time bit operations.  
`n ≤ 2000` ⇒ at most `4·10⁶` iterations, easily under the 2 s limit.

*Memory* :  
`adj_bool` – `(n+1)·(n+1)` bytes ≈ 4 MiB,  
`adj_mask` – `n+1` Python integers (each ≤ 2ⁿ) – negligible.  
Total well below 256 MiB.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    # adjacency boolean matrix (bytearray for speed)
    adj_bool = [bytearray(n + 1) for _ in range(n + 1)]
    # adjacency bit masks
    adj_mask = [0] * (n + 1)

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        if u > v:
            u, v = v, u
        adj_bool[u][v] = adj_bool[v][u] = 1
        adj_mask[u] |= 1 << v
        adj_mask[v] |= 1 << u

    for a in range(1, n + 1):
        mask_a = adj_mask[a]
        for b in range(a + 1, n + 1):
            if not adj_bool[a][b]:
                continue
            # vertices adjacent to both a and b
            common = mask_a & adj_mask[b]
            # keep only vertices > b
            common >>= b
            if not common:
                continue
            # lowest set bit -> smallest c
            lsb = common & -common
            pos = lsb.bit_length() - 1   # 0‑based inside shifted mask
            c = b + 1 + pos
            # output in ascending order (already a<b<c)
            sys.stdout.write(f"{a} {b} {c}")
            return

if __name__ == "__main__":
    solve()
```

and conforms to the required input‑output format.
