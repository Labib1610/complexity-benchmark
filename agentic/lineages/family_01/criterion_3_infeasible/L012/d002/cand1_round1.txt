<STATEMENT>
# Problem C — System Instability

Time limit: 2 s
Memory limit: 256 MB

You are analyzing a continuous-state system consisting of $n$ components. Certain pairs of components are linked by a bidirectional balance channel. 

The system operates by assigning each component $i$ a non-zero real number $x_i$ representing its operating state. A safety rule dictates that if two components are linked by a channel, their states must perfectly balance each other out, meaning they must sum to exactly zero ($x_u + x_v = 0$). 

The current network configuration contains a structural flaw. You do not need to attempt a full assignment of the network. Instead, you must find a specific localized failure: a subset of exactly three distinct components which, when considered in isolation, cannot operate under these rules. Specifically, you must find a subset of three components such that, if you only enforce the balancing rules for channels connecting two components strictly within this subset, the only mathematically valid state assignment forces $x_i = 0$ for all three components (violating the non-zero requirement).

It is guaranteed that the provided configuration contains at least one such subset of three components. Your task is to find and report one.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), representing the number of components and the number of channels, respectively. Components are numbered from $1$ to $n$.

Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that component $u$ and component $v$ are linked by a channel. Channels are bidirectional. It is guaranteed that no pair is listed more than once, and that at least one structural failure of three components exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line, representing the identifiers of the three components that form the structural failure. 

The identifiers must be printed in ascending order ($a < b < c$). If there are multiple valid subsets of three components, you must output the one that is lexicographically smallest. This means you should first minimize $a$; if there are ties, minimize $b$ among those ties; and if there are still ties, minimize $c$.

## Example 1
**Input:**
```
4 5
1 2
1 3
2 3
2 4
3 4
```
**Output:**
```
1 2 3
```

## Example 2
**Input:**
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
**Output:**
```
1 2 4
```
</STATEMENT>
<RATIONALE>
Changed the assignment model from "two alternating phases" (which models readily map to 2-coloring and thus triangles) to a continuous state system where linked components must sum to 0 ($x_u + x_v = 0$). To succeed, the model must now mathematically deduce that a 3-variable system of such equations only forces $x_i = 0$ if all three pairs are linked (an odd cycle), breaking the direct semantic shortcut to triangle-finding.
</RATIONALE>
<PRESERVED_ANSWER>
The linear system $x_u + x_v = 0$ on 3 variables forces all variables to 0 if and only if all three pairs are linked, which is exactly the same structural failure (a triangle) as the original 2-coloring formulation.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding the lexicographically smallest triangle in a graph, which can be solved in $O(nm/64)$ using bitsets.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "strictly within this subset" as requiring the components to have no external connections, though "when considered in isolation" and "if you only enforce" should clarify that external channels are simply ignored for this check.
</RISK>
