We need to find the lexicographically smallest triple (a, b, c) such that every pair among them is connected by an edge — i.e., a triangle in the graph.  

Since n can be up to 2000 and m up to 200,000, we can use an adjacency matrix (boolean) for O(1) edge checks, and iterate over triples in lexicographic order until we find a triangle.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = adj[v][u] = True

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if not adj[a][b]:
                continue
            for c in range(b + 1, n + 1):
                if adj[a][c] and adj[b][c]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    solve()
```
