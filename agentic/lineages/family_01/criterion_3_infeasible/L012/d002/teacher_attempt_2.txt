# Problem C — Core Thrash Loop

Time limit: 2 s
Memory limit: 256 MB

You are writing a scheduler for an embedded system that runs $n$ background processes. Certain pairs of these processes attempt to lock the same hardware registers, creating a "resource conflict." 

The system architecture has exactly two processing cores. To prevent race conditions, the scheduler must assign every process to one of the two cores such that no two processes with a resource conflict share the same core. However, the current set of processes cannot be scheduled under these constraints.

To trigger the fallback execution mode, the scheduler must identify a "core thrash loop." This is defined as a set of exactly three distinct processes where every possible pair among the three has a resource conflict. Because all three processes conflict with one another, they cannot be distributed across only two cores without a conflict occurring.

It is guaranteed that the system's process list contains at least one core thrash loop. Your task is to find and report one.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), representing the number of processes and the number of resource conflicts, respectively. Processes are numbered from $1$ to $n$.

Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that process $u$ and process $v$ have a resource conflict. A conflict applies equally to both processes. It is guaranteed that no conflict is listed more than once, and that at least one core thrash loop exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line, representing the identifiers of the three processes that form the loop. 

The identifiers must be printed in ascending order ($a < b < c$). If there are multiple valid loops, you must output the one that is lexicographically smallest. This means you should first minimize $a$; if there are ties, minimize $b$ among those ties; and if there are still ties, minimize $c$.

## Example 1
**Input:**
```
4 5
1 2
1 3
2 3
2 4
3 4
```
**Output:**
```
1 2 3
```

## Example 2
**Input:**
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
**Output:**
```
1 2 4
```
