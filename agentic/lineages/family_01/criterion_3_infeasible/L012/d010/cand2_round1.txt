# Problem C — Triadic Configurations

Time limit: 2 s
Memory limit: 256 MB

You are given a configuration of $n$ modules and a set of $m$ distinct bidirectional communication buses. Each bus connects a unique pair of modules. No bus connects a module to itself.

For any candidate triplet of distinct modules $T = \{a, b, c\}$ (with $a < b < c$), we can evaluate its stability by considering all possible assignments of a binary state $v_x \in \{0, 1\}$ to each module $x \in T$. 
An assignment $(v_a, v_b, v_c)$ is considered *stable* if it satisfies the following three conditions simultaneously:
- $\max(v_a, v_b) = \text{bus}(a, b)$
- $\max(v_b, v_c) = \text{bus}(b, c)$
- $\max(v_c, v_a) = \text{bus}(c, a)$

where $\text{bus}(x, y)$ is $1$ if there is a bus connecting module $x$ and module $y$, and $0$ otherwise.

A triplet is classified as *unresolvable* if there are exactly 4 distinct stable assignments for it.

Your task is to identify the unresolvable triplet of modules. If multiple unresolvable triplets exist, you must report the lexicographically smallest one.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), representing the number of modules and the number of buses. Modules are numbered from $1$ to $n$.

Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing a bus between module $u$ and module $v$. It is guaranteed that all $m$ unordered pairs $\{u, v\}$ are distinct, and that at least one unresolvable triplet exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line, representing the identifiers of the modules that form the unresolvable triplet. 

The identifiers must be printed in ascending order ($a < b < c$). If there are multiple valid triplets, output the one that is lexicographically smallest. This means you should first minimize $a$; if there are ties, minimize $b$ among those ties; and if there are still ties, minimize $c$.

## Example 1
**Input:**
```
4 5
1 2
1 3
2 3
2 4
3 4
```
**Output:**
```
1 2 3
```

## Example 2
**Input:**
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
**Output:**
```
1 2 4
```

The seed problem was a thinly veiled request to find a triangle ($K_3$) in a graph, which models easily recognized and solved using efficient $O(m \sqrt{m})$ or bitset algorithms. 
To defeat models that rely on surface pattern matching, I replaced the original condition with a system of boolean constraint equations ($\max(v_i, v_j) = \text{bus}(i, j)$) over the triplet's states. This system has exactly 4 solutions if and only if all three buses exist (a triangle), and $\le 1$ solution otherwise. Models that genuinely reason mathematically will symbolically reduce this to the triangle condition and use an efficient algorithm. Models that skim or pattern-match will take the condition literally, implementing an 8-state check inside an $O(N^3)$ brute-force loop, which will result in a Time Limit Exceeded (TLE) error.
