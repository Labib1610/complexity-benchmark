We need to find a triangle in an undirected graph, and specifically the lexicographically smallest one.  

Since \( n \le 2000 \), we can afford an \( O(n^2) \) approach.  
We can iterate over possible smallest vertex `a` from 1 to n, then over `b` from `a+1` to n, and check if there is a `c > b` connected to both `a` and `b`.  
To make this efficient, we can store adjacency as sets for O(1) neighbor checks.

Here’s the implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(n):
        for b in range(a + 1, n):
            if b in adj[a]:
                # find smallest c > b connected to both a and b
                common = adj[a] & adj[b]
                for c in sorted(common):
                    if c > b:
                        print(a + 1, b + 1, c + 1)
                        return

if __name__ == "__main__":
    solve()
```
