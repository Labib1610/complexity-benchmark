**Solution Explanation**

For every sensor we store the set of sensors it is linked to.
A *structural failure* is exactly a triangle in this undirected graph.
We have to output the lexicographically smallest triangle  
`a < b < c`.

`n ≤ 2000`, therefore a bitset of length `n` fits into a single Python
integer (`2000` bits ≈ 250 bytes).  
With bitsets the intersection of two neighbour sets is a single
`&` operation and the lowest set bit can be obtained in `O(1)`.

--------------------------------------------------------------------

#### Data structures
* `adj_int[i]` – Python `int`, bit `j‑1` is `1` iff there is an edge `i – j`.
* `adj_list[i]` – sorted list of neighbours of `i` (needed to iterate
  `b` in increasing order).

--------------------------------------------------------------------

#### Algorithm
```
read n, m
build adj_int[1..n] and adj_list[1..n]

for a = 1 .. n-2:
        for each b in adj_list[a] with b > a (already sorted):
                common = adj_int[a] & adj_int[b]          # neighbours of both
                # we need c > b, mask away bits ≤ b
                mask = ~((1 << b) - 1)                    # bits b+1 .. n are 1
                common &= mask
                if common != 0:                           # a triangle exists
                        lowest = common & -common         # lowest set bit
                        c = lowest.bit_length()           # 1‑based index
                        output a, b, c
                        exit
```

*Why does it give the lexicographically smallest triangle?*  
The outer loop increases `a`. For a fixed `a` the inner loop scans `b`
in increasing order, and for a fixed pair `(a,b)` we take the smallest
possible `c` (`lowest` bit). The first triangle found therefore has the
minimal possible `a`; among those the minimal `b`; and among those the
minimal `c`.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
triangle.

---

**Lemma 1**  
For any vertices `a < b`, after `common = adj_int[a] & adj_int[b]`,
`common` has a `1` at position `c‑1` iff edges `a‑c` and `b‑c` exist.

*Proof.* By construction `adj_int[x]` contains exactly the neighbours of `x`.
Bitwise `&` keeps a bit set only when it is set in both operands, i.e. when
both edges exist. ∎



**Lemma 2**  
After `common &= mask` (where `mask` has `1`s only for indices `> b`),
`common` has a `1` at position `c‑1` iff `c > b` and edges `a‑c`, `b‑c`
exist.

*Proof.* `mask` clears all bits `≤ b`. Therefore a remaining `1` corresponds
to a vertex `c` with `c > b` that is adjacent to both `a` and `b`. ∎



**Lemma 3**  
If the algorithm prints `(a,b,c)`, then `{a,b,c}` is a triangle.

*Proof.* The algorithm prints only when `common != 0`. By Lemma&nbsp;2 there
exists a vertex `c > b` such that edges `a‑c` and `b‑c` exist.
`b` is taken from `adj_list[a]`, therefore edge `a‑b` exists.
Thus all three edges are present – a triangle. ∎



**Lemma 4**  
When the algorithm prints `(a,b,c)`, there is no triangle
`(a',b',c')` with lexicographically smaller triple.

*Proof.* The outer loop examines `a` in increasing order.
If a triangle with smaller `a'` existed, the algorithm would have processed
that `a'` earlier and printed a triangle then – contradiction.
Assume the smallest possible `a` is the current one.
Inside this `a`, `b` is scanned in increasing order.
If a triangle with the same `a` and a smaller `b'` existed, it would be
found earlier.
Finally, for the current pair `(a,b)` we choose the smallest possible `c`
(`lowest` set bit), so no triangle with the same `a,b` and smaller `c`
exists. ∎



**Lemma 5**  
If the input graph contains at least one triangle, the algorithm will
find one.

*Proof.* Let `(a*,b*,c*)` be the lexicographically smallest triangle.
When the outer loop reaches `a = a*`, the inner loop will eventually
consider `b = b*` because `b*` is a neighbour of `a*` and `b* > a*`.
At that moment, by Lemma&nbsp;1 and Lemma&nbsp;2, `c*` is present in
`common`. Hence `common != 0` and the algorithm prints a triangle. ∎



**Theorem**  
The algorithm terminates and outputs the lexicographically smallest
triangle of the given graph.

*Proof.* By Lemma&nbsp;5 a triangle is found, so the algorithm terminates.
By Lemma&nbsp;3 the printed triple is a triangle.
By Lemma&nbsp;4 it is the lexicographically smallest one. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building the structures*: `O(m)` time, `O(n)` integers (≈ n·2000 bits).

*Main loops*: each edge `(a,b)` with `a<b` is examined once.
For each such edge we perform a constant‑time bitwise `&`, a mask, and
a few integer operations.  
Total time `O(m) ≤ 2·10⁵`.  

Memory consumption: `n` integers of at most `n` bits → `O(n² / wordsize)`
≈ 250 KB for `n = 2000`, well below the limit.

--------------------------------------------------------------------

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj_int = [0] * (n + 1)          # 1‑based
    adj_list = [[] for _ in range(n + 1)]

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        # set bits (0‑based inside the int)
        adj_int[u] |= 1 << (v - 1)
        adj_int[v] |= 1 << (u - 1)
        adj_list[u].append(v)
        adj_list[v].append(u)

    # sort neighbour lists for increasing order iteration
    for lst in adj_list:
        lst.sort()

    for a in range(1, n - 1):
        a_bits = adj_int[a]
        for b in adj_list[a]:
            if b <= a:
                continue
            # neighbours common to a and b
            common = a_bits & adj_int[b]
            # keep only vertices > b
            mask = ~((1 << b) - 1)          # bits b+1 .. n are 1
            common &= mask
            if common:
                # lowest set bit gives smallest c
                lowest = common & -common
                c = lowest.bit_length()     # 1‑based index
                # output in ascending order (already a<b<c)
                sys.stdout.write(f"{a} {b} {c}")
                return

if __name__ == "__main__":
    solve()
```
