# Problem C — Resonance Cascades

Time limit: 2 s
Memory limit: 256 MB

You are analyzing a resonance testing facility. A minimum of $3$ modules are required for the facility to operate. The modules are housed in a grid of testing bays measuring exactly 40 by 50, with each bay capable of holding exactly one module. The facility currently houses $n$ modules, where $n$ is at most the total number of bays.

The system logs bidirectional resonance links between certain pairs of modules. To initiate a test, the log must contain at least $3$ link records. The log uses a fixed-size memory buffer of exactly $800,000$ bytes, where each link record occupies exactly $4$ bytes, defining the absolute maximum capacity for links. The total number of links $m$ will never exceed this capacity, nor will it exceed the theoretical maximum of one link per distinct pair of modules.

We define the *resonance profile* of a module $x$, denoted as $P(x)$, to be the set of all modules that share a direct resonance link with $x$.

Your task is to identify a *cascade triplet*: a set of three distinct modules $a$, $b$, and $c$, ordered by their numerical identifiers such that $a < b < c$, which satisfies the following conditions:
1. $b \in P(a)$
2. $c \in P(a) \cap P(b)$

It is guaranteed that the provided configuration contains at least one such cascade triplet. 

## Input
The first line contains two integers $n$ and $m$, representing the number of modules and the number of resonance links, respectively. Modules are numbered consecutively starting from $1$.

Each of the subsequent $m$ lines contains two integers $u$ and $v$, indicating that module $u$ and module $v$ share a resonance link. It is guaranteed that $u$ and $v$ are valid distinct module identifiers.

## Output
Print three integers $a$, $b$, and $c$ on a single line, representing the identifiers of the three modules that form the cascade triplet. 

The identifiers must be printed in ascending order ($a < b < c$). If there are multiple valid triplets that satisfy the conditions, you must output the one that is lexicographically smallest. This means you should first minimize $a$; if there are ties, minimize $b$ among those ties; and if there are still ties, minimize $c$.

## Example 1
**Input:**
```
4 5
1 2
1 3
2 3
2 4
3 4
```
**Output:**
```
1 2 3
```

## Example 2
**Input:**
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
**Output:**
```
1 2 4
```

<RATIONALE>
The problem was rewritten to remove the "two frequency bands" and "flawed assignment" framing, which models easily mapped to testing for bipartite graphs (and thus finding an odd cycle/triangle). Instead, the condition is presented purely algebraically using set intersections. Additionally, all numeric bounds were converted to indirect physical constraints (e.g., a 40x50 grid for 2000 modules, 800,000 bytes at 4 bytes/record for 200,000 links) to satisfy S07. This forces models to genuinely parse the intersection logic rather than pattern-matching a graph coloring contradiction.
</RATIONALE>
<PRESERVED_ANSWER>
The conditions $a < b < c$, $b \in P(a)$, and $c \in P(a) \cap P(b)$ logically demand that $a, b, c$ are mutually linked (a triangle), and the lexicographical tie-breaking rule is identical to the seed, ensuring the exact same output for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying computational task remains finding a 3-clique (triangle) in an undirected graph, preserving the original time complexity and algorithmic requirements.
</PRESERVED_CLASS>
