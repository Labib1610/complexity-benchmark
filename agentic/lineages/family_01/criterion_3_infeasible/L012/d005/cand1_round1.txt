# Problem C — System Redundancy

Time limit: 2 s
Memory limit: 256 MB

You are analyzing the redundancy of a distributed monitoring network consisting of $n$ sensors. The provided configuration lists $m$ hardware interlocks between pairs of sensors. 

Your task is to identify a minimal redundant unit, specifically a *Fault-Tolerant Triplet*. A Fault-Tolerant Triplet is a group of exactly three distinct sensors that satisfies both of the following conditions:
1. There is at least one internal interlock present among the three sensors. (An internal interlock is an interlock where both connected sensors belong to the triplet).
2. If you were to temporarily ignore ANY single internal interlock within the triplet, every sensor in the triplet would still be connected to at least one other sensor in the triplet via a remaining internal interlock.

It is guaranteed that the provided configuration contains at least one such group of three sensors. Your task is to find and report one.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), representing the number of sensors and the number of interlocks, respectively. Sensors are numbered from $1$ to $n$.

Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that sensor $u$ and sensor $v$ share an interlock. It is guaranteed that at least one Fault-Tolerant Triplet exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line, representing the identifiers of the three sensors that form the Fault-Tolerant Triplet. 

The identifiers must be printed in ascending order ($a < b < c$). If there are multiple valid groups of three sensors, you must output the one that is lexicographically smallest. This means you should first minimize $a$; if there are ties, minimize $b$ among those ties; and if there are still ties, minimize $c$.

## Example 1
**Input:**
```
4 5
1 2
1 3
2 3
2 4
3 4
```
**Output:**
```
1 2 3
```

## Example 2
**Input:**
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
**Output:**
```
1 2 4
```

The seed problem relied on a 2-coloring contradiction (allocating 3 sensors into 2 bands) which models easily pattern-matched to a triangle (3-clique). I replaced this with a structural redundancy requirement: a 3-node subgraph that remains fully incident after any single edge is removed. Models must now genuinely reason that for a 3-node graph to survive any edge removal without isolating a vertex, its minimum degree must be 2, which mathematically proves it must be a triangle.
</RATIONALE>

The only 3-node graph that satisfies the fault-tolerance condition is a triangle (since a path of length 2 leaves an isolated node when an edge is removed), meaning the valid triplets are exactly the same as in the original problem.
</PRESERVED_ANSWER>
