# Problem C — Processor Allocation Audit

Time limit: 2 s
Memory limit: 256 MB

You are evaluating a dual-core task dispatcher. There are $n$ pending tasks, and the dispatcher has been given $m$ strict separation rules. Each rule flags two specific tasks that interfere with each other and therefore cannot share the same core.

An audit has revealed that the current set of separation rules cannot be satisfied using only two cores. Your objective is to isolate a minimal contradictory group of exactly three tasks to prove this scheduling failure.

You must identify three distinct tasks where every task in the trio interferes with the other two (i.e., all three pairs among the three tasks have a separation rule). Since there are only two cores available, any attempt to allocate these three tasks will inevitably force at least one interfering pair onto the same core, violating the rules.

*System Note on Testing:* The automated evaluation tests include adversarial worst-case configurations. In these stress tests, the vast majority of lower-numbered tasks are arranged in a dense, perfectly dual-core-compatible structure containing no contradictory trios. The actual contradictory groups are artificially hidden exclusively among the highest-numbered tasks. A standard search that simply checks combinations in ascending numeric order may evaluate millions of safe combinations before reaching the targets, exceeding the time limit. Your extraction method must be optimized to handle these distributions efficiently, while still rigorously enforcing the output tie-breaking criteria when more than one contradictory trio exists.

It is guaranteed that at least one such trio exists in the input.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), representing the number of tasks and the number of separation rules. The tasks are identified by integers from $1$ to $n$.

Each of the subsequent $m$ lines provides two integers $u$ and $v$ ($1 \le u, v \le n$), declaring a separation rule between task $u$ and task $v$. At least one contradictory trio of tasks is guaranteed to be present.

## Output
Output a single line containing three integers $a$, $b$, and $c$, representing the identifiers of the three tasks in the contradictory group.

The three identifiers must be sorted in ascending order ($a < b < c$). In the event that multiple such trios exist in the scheduling rules, you must output the lexicographically smallest trio. This requires you to first minimize $a$; if there are multiple valid trios with the same $a$, minimize $b$; and if ties still remain, minimize $c$.

## Example 1
**Input:**
```
4 5
1 2
1 3
2 3
2 4
3 4
```
**Output:**
```
1 2 3
```

## Example 2
**Input:**
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
**Output:**
```
1 2 4
```
