<STATEMENT>
# Problem C — System Instability

Time limit: 2 s
Memory limit: 256 MB

You are analyzing a distributed monitoring network consisting of $n$ sensors. The configuration lists $m$ bidirectional hardware interlocks between pairs of sensors. 

During a diagnostic test, you must select exactly three distinct sensors. The testing protocol requires you to evaluate every possible way of assigning each of your three selected sensors to either 'Set A' or 'Set B'. Since each of the three sensors can independently be placed in Set A or Set B, there are exactly $2^3 = 8$ possible assignments to evaluate.

For a specific assignment to be considered 'stable', there must be no hardware interlock between any two sensors placed in Set A, and no hardware interlock between any two sensors placed in Set B. 

A trio of sensors is considered 'critically flawed' if every single one of the 8 possible assignments turns out to be unstable. Because it is impossible to find even one stable assignment for them, this trio represents a fundamental flaw in the network.

It is guaranteed that the provided configuration contains at least one such critically flawed trio of sensors. Your task is to find and report one.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), representing the number of sensors and the number of interlocks, respectively. Sensors are numbered from $1$ to $n$.

Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that sensor $u$ and sensor $v$ are linked by an interlock. It is guaranteed that at least one critically flawed trio of three sensors exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line, representing the identifiers of the three sensors that form the critically flawed trio. 

The identifiers must be printed in ascending order ($a < b < c$). If there are multiple valid critically flawed trios, you must output the one that is lexicographically smallest. This means you should first minimize $a$; if there are ties, minimize $b$ among those ties; and if there are still ties, minimize $c$.

## Example 1
**Input:**
```
4 5
1 2
1 3
2 3
2 4
3 4
```
**Output:**
```
1 2 3
```

## Example 2
**Input:**
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
**Output:**
```
1 2 4
```

<RATIONALE>
The explicit condition "completely lack any compatible pairs" was removed because it directly handed the models the triangle-finding shortcut. It was replaced with a logically equivalent requirement that all 8 possible assignments of the three sensors into two sets must fail. To pass without a Time Limit Exceeded (TLE) error, the model must now genuinely reason through the state space to deduce that this condition is perfectly equivalent to the three sensors being mutually interlocked (a triangle).
</RATIONALE>
<PRESERVED_ANSWER>
For any three sensors, all 8 assignments into two sets are unstable if and only if all three pairs of those sensors are interlocked, making the target structure exactly the same as the seed's requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a 3-clique (triangle) in the graph defined by the interlocks, keeping it in the exact same complexity class with the same intended bitset adjacency algorithm.
</PRESERVED_CLASS>
