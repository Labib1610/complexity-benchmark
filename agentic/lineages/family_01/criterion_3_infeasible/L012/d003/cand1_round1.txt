# Problem C — System Instability

Time limit: 2 s
Memory limit: 256 MB

You are analyzing a distributed monitoring network consisting of $n$ sensors. Certain pairs of sensors are linked by a hardware interlock. 

The network is designed to operate by assigning each sensor to one of two available frequency bands. A safety rule dictates that if two sensors are linked by an interlock, they must not be assigned to the same frequency band. 

However, the current configuration is fundamentally flawed. To demonstrate this flaw, you must find a specific combination: a subset of exactly three distinct sensors such that, considering only the interlocks between these three sensors, it is impossible to assign them to the two available frequency bands without violating the safety rule.

It is guaranteed that the provided configuration contains at least one such subset of three sensors. Your task is to find and report one.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), representing the number of sensors and the number of interlocks, respectively. Sensors are numbered from $1$ to $n$.

Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that sensor $u$ and sensor $v$ are linked by an interlock. Interlocks are bidirectional. It is guaranteed that no pair is listed more than once, and that at least one such subset of three sensors exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line, representing the identifiers of the three sensors that form the flaw. 

The identifiers must be printed in ascending order ($a < b < c$). If there are multiple valid subsets of three sensors, you must output the one that is lexicographically smallest. This means you should first minimize $a$; if there are ties, minimize $b$ among those ties; and if there are still ties, minimize $c$.

## Example 1
**Input:**
```
4 5
1 2
1 3
2 3
2 4
3 4
```
**Output:**
```
1 2 3
```

## Example 2
**Input:**
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
**Output:**
```
1 2 4
```

<RATIONALE>
Removed the explicit description of the structural properties of the target subset ("if any single sensor is excluded... the remaining two are linked"). Instead, the target is defined purely by its inability to be validly assigned to the two frequency bands. This forces the model to logically deduce that a 3-vertex subgraph is not 2-colorable if and only if it is a triangle, preventing superficial pattern matching to clique/triangle detection.
</RATIONALE>
<PRESERVED_ANSWER>
A subset of exactly three vertices cannot be 2-colored (assigned to two frequency bands without linked endpoints sharing a band) if and only if all three possible edges are present among them, which is mathematically identical to a triangle (3-clique).
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core computational task is still finding the lexicographically smallest triangle in an undirected graph, which remains solvable in $O(nm/64)$ using bitsets.
</PRESERVED_CLASS>
