<STATEMENT>
# Problem C — System Instability

Time limit: 2 s
Memory limit: 256 MB

You are analyzing a distributed monitoring network consisting of $n$ sensors. Certain pairs of sensors are linked by a hardware interlock. 

The network operates by assigning each sensor to one of two available frequency bands. A safety rule dictates that if two sensors are linked by an interlock, they must not be assigned to the same frequency band. 

For any sensor $k$, let $L(k)$ be the set of all sensors linked to $k$ by an interlock. A critical flaw in the network is formed by a subset of exactly three distinct sensors $x$, $y$, and $z$ such that $y \in L(x)$ and $z \in L(x) \cap L(y)$. Because of these mutual interlocks, it is impossible to validly assign these three sensors to the two frequency bands.

It is guaranteed that the provided configuration contains at least one such subset of three sensors. Your task is to find and report one.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n \cdot (n-1)/2, 2 \cdot 10^5)$), representing the number of sensors and the number of interlocks, respectively. Sensors are numbered from $1$ to $n$.

Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that sensor $u$ and sensor $v$ are linked by an interlock. Interlocks are bidirectional. It is guaranteed that no pair is listed more than once, and that at least one such subset of three sensors exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line, representing the identifiers of the three sensors that form the flaw. 

The identifiers must be printed in ascending order ($a < b < c$). If there are multiple valid subsets of three sensors, you must output the one that is lexicographically smallest. This means you should first minimize $a$; if there are ties, minimize $b$ among those ties; and if there are still ties, minimize $c$.

## Example 1
**Input:**
```
4 5
1 2
1 3
2 3
2 4
3 4
```
**Output:**
```
1 2 3
```

## Example 2
**Input:**
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
**Output:**
```
1 2 4
```
</STATEMENT>
<RATIONALE>
Changed the description of the mutual conflict from graph-like wording to a set-membership and intersection formulation ($z \in L(x) \cap L(y)$). This forces models to reason about the intersection of adjacency sets rather than relying on surface-level "triangle" or "clique" pattern matching, while actively guiding them toward the intended bitset intersection algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $y \in L(x)$ and $z \in L(x) \cap L(y)$ for three distinct sensors is mathematically equivalent to all three sensors being mutually linked, preserving the exact same valid subsets and lexicographical output as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a 3-clique (triangle) in an undirected graph, which remains solvable in O(n*m/64) using bitsets, keeping it in the INFEASIBLE complexity class.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the set intersection condition as directed if they fail to note that interlocks are bidirectional, though the input section explicitly guarantees bidirectionality.
</RISK>
