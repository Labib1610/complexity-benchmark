We can model the sensors as vertices of a graph, where an edge means the two sensors are **not compatible**.  
We need to find a triangle (three mutually connected vertices) that is lexicographically smallest.

Since \( n \leq 2000 \), we can use an adjacency matrix (boolean) for fast checks.  
We iterate over all triples in sorted order and stop at the first triangle.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = adj[v][u] = True

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if not adj[a][b]:
                continue
            for c in range(b + 1, n + 1):
                if adj[a][c] and adj[b][c]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
