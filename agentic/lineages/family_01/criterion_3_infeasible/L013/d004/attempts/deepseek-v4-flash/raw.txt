We need to find the lexicographically smallest triangle (3-cycle) in an undirected graph.  

A direct approach:  
- Iterate over vertices in increasing order as the first vertex `a`.  
- For each neighbor `b` of `a` (with `b > a`), check if there is a common neighbor `c` with `c > b`.  
- The first such triple found will be lexicographically smallest because we check `a` in increasing order, then `b` in increasing order, then `c` in increasing order.

We can use adjacency sets for fast intersection checks.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(n):
        for b in sorted(adj[a]):
            if b <= a:
                continue
            for c in sorted(adj[b]):
                if c <= b:
                    continue
                if c in adj[a]:
                    print(a + 1, b + 1, c + 1)
                    return

if __name__ == "__main__":
    main()
```
