# Problem C — Ventilation Citation

Time limit: 2 s   Memory limit: 256 MB

An industrial warehouse contains $n$ storage zones, numbered 1 through $n$. The architectural plans include $m$ direct ventilation shafts, each connecting a specific pair of zones. 

Strict safety regulations mandate that all storage zones must be partitioned into exactly two independent fire-suppression networks. To prevent rapid hazard spread, if two zones are connected by a direct ventilation shaft, they are strictly prohibited from being assigned to the same suppression network.

The current layout proposal, however, cannot satisfy this regulation. The blueprint data guarantees a structural non-compliance: there exists a specific trio of storage zones where each zone in the trio is directly connected by a ventilation shaft to both of the other two. Consequently, it is impossible to divide this trio into only two networks without at least one connected pair ending up in the same network.

To automatically generate the rejection report for the layout, you must provide a formal certificate of this flaw by identifying one such trio of zones.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n(n-1)/2, 2 \cdot 10^5)$).
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), representing a pair of storage zones connected by a direct ventilation shaft. Each pair is listed at most once.
It is guaranteed that at least one non-compliant trio of zones exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, representing the numbers of the three storage zones in the trio. The numbers must be printed in ascending order ($a < b < c$).
If there are multiple such trios, you must output the one that is lexicographically smallest. That is, minimize $a$; if there is a tie, minimize $b$; and if there is still a tie, minimize $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```
