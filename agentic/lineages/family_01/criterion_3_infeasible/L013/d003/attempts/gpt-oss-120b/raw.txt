**Solution Explanation**

For every pair of cogs we know whether they are linked.
A *defect* is a set `{a,b,c}` (`a<b<c`) such that all three links  
`(a,b) , (a,c) , (b,c)` exist – i.e. a triangle in the undirected graph.

We have to output the lexicographically smallest triangle.

--------------------------------------------------------------------

#### 1.   Observations  

* `n ≤ 2000`.  
  The whole adjacency matrix fits into a bitset of `n` bits (`2000` bits ≈
  250 bytes).  
  In Python an integer can store an arbitrary‑size bitset and bitwise
  operations on it are O(1) on this size.

* If we already know that `(a,b)` is an edge, the third vertex `c`
  must belong to the **intersection** of the neighbour sets of `a` and `b`.

* While scanning vertices in increasing order,
  the first triangle we meet is automatically the lexicographically
  smallest one:
  ```
  for a = 1 .. n
      for b = a+1 .. n   (only if (a,b) is an edge)
          find smallest c > b belonging to N(a) ∩ N(b)
  ```

--------------------------------------------------------------------

#### 2.   Data structures  

* `adj_int[v]` – integer whose `i`‑th bit (`i` from `0`) is `1`
  iff vertex `v` is linked with vertex `i+1`.  
  (`adj_int` size `n+1`, 1‑based).

* `adj_list[v]` – sorted list of neighbours of `v`.  
  Used to iterate over `b` for a fixed `a` without testing all `n`
  possibilities.

--------------------------------------------------------------------

#### 3.   Algorithm  

```
read n, m
initialise adj_int[1..n] = 0
initialise empty adjacency lists

for each edge (u,v):
        set bit (v-1) in adj_int[u]   and bit (u-1) in adj_int[v]
        add v to adj_list[u] , u to adj_list[v]

for a = 1 .. n:
        for b in adj_list[a] (already sorted):
                if b <= a: continue          # we need a < b
                common = adj_int[a] & adj_int[b]          # N(a) ∩ N(b)

                # keep only vertices > b
                mask = ((1 << n) - 1) ^ ((1 << b) - 1)     # bits b .. n-1
                common &= mask

                if common != 0:            # at least one c exists
                        lowest = common & -common          # lowest set bit
                        c = (lowest.bit_length() - 1) + 1  # back to 1‑based
                        output a, b, c
                        exit
```

* `common & -common` isolates the least significant `1` bit.
* `bit_length()` returns position of the highest set bit (1‑based), therefore
  `lowest.bit_length() - 1` is the zero‑based index of the isolated bit.

The loops guarantee `a < b < c`.  
Because `a` grows first, then `b`, the first found triangle is the
lexicographically smallest one.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
triangle.

---

##### Lemma 1  
For any vertices `a` and `b` the set `common = N(a) ∩ N(b)` computed by the
algorithm equals the set of vertices adjacent to **both** `a` and `b`.

**Proof.**  
`adj_int[x]` has a `1` exactly on neighbours of `x`.  
Bitwise `&` keeps a `1` only where both operands have `1`. ∎



##### Lemma 2  
After masking, `common` contains exactly the vertices `c` such that  
`c > b` and `c` is adjacent to both `a` and `b`.

**Proof.**  
The mask has `1` on positions `b … n-1` (zero‑based) and `0` elsewhere.
`common &= mask` removes all bits `< b`. ∎



##### Lemma 3  
If the algorithm prints a triple `(a,b,c)`, then `{a,b,c}` is a triangle.

**Proof.**  
`b` is taken from `adj_list[a]` → edge `(a,b)` exists.  
By Lemma&nbsp;2, `c` is in `common`, therefore adjacent to both `a` and `b`.  
Thus all three edges exist. ∎



##### Lemma 4  
If a triangle `{x,y,z}` with `x<y<z` exists, the algorithm will eventually
consider the pair `(a,b) = (x,y)` and will find `c = z`.

**Proof.**  
When the outer loop reaches `a = x`, the inner loop iterates over all
neighbours `b` of `x` larger than `x`, therefore it will reach `b = y`
(because `(x,y)` is an edge).  
For this pair, by Lemma&nbsp;1 `common` contains `z`.  
Since `z > y`, Lemma&nbsp;2 guarantees `z` survives the mask, so the
algorithm will detect it. ∎



##### Lemma 5  
The first triangle output by the algorithm is the lexicographically smallest
triangle of the graph.

**Proof.**  
Consider any triangle `{a,b,c}` with `a<b<c`.  
By Lemma&nbsp;4 the algorithm will output some triangle when processing the
pair `(a,b)`.  
All pairs examined earlier have either a smaller first vertex `a' < a`,
or the same `a` and a smaller second vertex `b' < b`.  
Any triangle discovered earlier would therefore have a lexicographically
smaller ordered triple.  
Consequently the very first printed triangle is the minimal one. ∎



##### Theorem  
The algorithm always terminates and prints the lexicographically smallest
triple of mutually linked cogs.

**Proof.**  
Termination: the loops run over a finite number of vertices and edges,
and the program exits immediately after printing a triangle, which is
guaranteed to exist by the problem statement.

Correctness: By Lemma&nbsp;3 every printed triple is a triangle.
By Lemma&nbsp;5 the first printed triangle is the lexicographically smallest
among all triangles. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Building the structures* – `O(m)` time, `O(n + m)` memory.  

*Main loops* – each edge `(a,b)` with `a<b` is examined once.
For each such edge we perform a constant‑time bitwise `&` and a few integer
operations: `O(1)`.  
Hence total time `O(m)`.  

Memory: `adj_int` stores `n` integers of ≤ 2000 bits → `O(n)` bits,
`adj_list` stores `2m` integers → `O(m)`.  
Both fit easily into the limits (`n ≤ 2000`, `m ≤ 2·10⁵`).

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj_int = [0] * (n + 1)          # 1‑based
    adj_list = [[] for _ in range(n + 1)]

    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        # set bits
        adj_int[u] |= 1 << (v - 1)
        adj_int[v] |= 1 << (u - 1)
        adj_list[u].append(v)
        adj_list[v].append(u)

    # sort neighbour lists for deterministic order
    for lst in adj_list:
        lst.sort()

    full_mask = (1 << n) - 1

    for a in range(1, n + 1):
        for b in adj_list[a]:
            if b <= a:
                continue
            common = adj_int[a] & adj_int[b]
            # keep only vertices > b
            mask = full_mask ^ ((1 << b) - 1)   # bits b .. n-1 are 1
            common &= mask
            if common:
                lowest = common & -common        # isolate lowest set bit
                c = lowest.bit_length()          # 1‑based index of that bit
                # c is already 1‑based because bit_length gives position (1..n)
                sys.stdout.write(f"{a} {b} {c}\n")
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input‑output format.
