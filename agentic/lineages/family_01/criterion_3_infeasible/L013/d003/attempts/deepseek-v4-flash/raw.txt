We can solve this by checking each possible triple in lexicographic order and verifying if all three edges exist.  
Since \( n \) can be up to 2000, checking all triples naively would be too slow (\( O(n^3) \)).  
Instead, we can iterate over the first vertex \( a \), then over its neighbors \( b > a \), and then check if there is a common neighbor \( c > b \) that is connected to both \( a \) and \( b \).  

We can store the graph as an adjacency matrix (boolean) for fast lookups.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = True
        adj[v][u] = True

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if adj[a][b]:
                for c in range(b + 1, n + 1):
                    if adj[a][c] and adj[b][c]:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    main()
```
