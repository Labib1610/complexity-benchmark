# Problem C — Mechanical Jam

Time limit: 2 s   Memory limit: 256 MB

A clockwork mechanism consists of $n$ cogs, numbered 1 through $n$. The design specifies $m$ direct mechanical links, where the teeth of two specific cogs interlock. Whenever two cogs interlock, they are forced to rotate in opposite directions.

The designers intended for the entire mechanism to rotate continuously. However, the prototype is completely seized. An inspection reveals a fatal structural flaw: a localized parity conflict. Such a conflict arises from a completely mutually constrained subset of exactly three cogs. Within this specific subset, any chosen pair of cogs is directly interlocked. In this arrangement, rotation is physically impossible, as the alternating rotation directions cannot be simultaneously satisfied.

To authorize a redesign, the lead engineer requires a formal defect report identifying the components involved in one of these minimal conflicting configurations. Your task is to find a completely interconnected trio of cogs.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n(n-1)/2, 2 \cdot 10^5)$).
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), representing that cog $u$ and cog $v$ interlock. Each pair is listed at most once.
It is guaranteed that at least one such subset of three cogs exists.

## Output
Print three integers on a single line, separated by spaces, representing the IDs of the three cogs that form the described arrangement. The IDs must be printed in ascending order.
If there are multiple such subsets, you must output the one whose elements, when sorted, appear first in dictionary order. This means you should first minimize the smallest cog ID in the subset. If there are ties, minimize the second smallest cog ID, and if there is still a tie, minimize the largest cog ID.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
Removed the sequential description of a cycle ("first with second, second with third, third with first") which strongly triggers "triangle finding" templates in the models. Replaced it with a combinatorial description ("subset of exactly three cogs... any chosen pair is directly interlocked"). This forces the model to deduce that a 3-clique is equivalent to a 3-cycle in this context before applying the optimal triangle-finding algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The condition of finding three cogs where every pair is interlocked is mathematically identical to finding a triangle (a 3-cycle) in the corresponding graph, so the target subsets and their tie-breaking order remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a 3-clique (triangle) in an undirected graph, keeping it in the same complexity class with the identical $O(m \sqrt{m})$ or bitset-optimized $O(n m / 64)$ bounds.
</PRESERVED_CLASS>
