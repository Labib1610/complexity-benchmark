# Problem C — System Gridlock

Time limit: 2 s   Memory limit: 256 MB

A heavy-duty gearbox contains a set of $n$ rotating components, identified by integers starting from 1 up to $n$. The mechanics have installed $m$ transmission belts, each coupling two specific components together. Whenever two components are coupled, their rotation must be synchronized in opposite phases.

The system is currently completely gridlocked. A diagnostic check reveals a specific structural fault: there is at least one instance of a "phase deadlock." A phase deadlock occurs when there is a trio of distinct components where every component in the trio is directly coupled to both of the other two components in that same trio. Because each coupling demands opposing phases, this mutual configuration is physically impossible to satisfy, causing the entire gearbox to freeze.

Your task is to identify three components that constitute one of these deadlocked trios.

## Input
The first line contains the integers $n$ and $m$. The workshop inventory dictates that the number of components $n$ is at least three, and the facility can house at most two thousand components. The number of transmission belts $m$ is at minimum three. The maximum number of belts is bounded by either the total number of possible unique pairs among the $n$ components, or exactly two hundred thousand, whichever is smaller.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), representing that component $u$ and component $v$ are coupled. Each pair is listed at most once.
It is guaranteed that at least one such deadlocked trio exists in the system.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, representing the identifiers of three components that form the described deadlock. The identifiers must be printed in ascending order ($a < b < c$).
If there are multiple such combinations, you must output the one that is lexicographically smallest. That is, minimize $a$; if there is a tie, minimize $b$; and if there is still a tie, minimize $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
The description of the required structure was changed from a sequential 3-cycle ("first interlocks with second, second with third, third back to first") to a 3-clique ("trio where every component is directly coupled to both of the other two"). This prevents models from pattern-matching the sequential cycle description and forces them to deduce that a mutually connected trio of size three is structurally identical to a triangle. The numeric bounds for $n$ and $m$ were also indirected into mechanical limits to satisfy the strategy constraint.
</RATIONALE>
<PRESERVED_ANSWER>
The condition exactly describes a 3-clique (triangle) in an undirected graph, which is mathematically identical to the 3-cycle requested in the seed, ensuring the same output is required for any given input.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Finding a 3-clique in an undirected graph is exactly the same computational problem as finding a 3-cycle, keeping the time complexity and algorithm identical.
</PRESERVED_CLASS>
