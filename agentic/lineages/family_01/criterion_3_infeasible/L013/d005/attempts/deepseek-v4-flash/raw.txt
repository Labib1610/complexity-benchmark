We need to find a triangle (three mutually connected nodes) in the graph.  
Since the graph is undirected and we just need any triangle, we can iterate over edges and check for a common neighbor.  

We can do this efficiently by storing adjacency sets and checking for each edge (u, v) if there exists a node w that is connected to both u and v.  
To get the lexicographically smallest triangle, we can iterate over nodes in increasing order and check their neighbors in increasing order.  

Here’s the implementation:  

```python
n, m = map(int, input().split())
adj = [set() for _ in range(n)]
edges = []

for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].add(v)
    adj[v].add(u)
    edges.append((u, v))

# Sort edges by node indices to find lexicographically smallest triangle
edges.sort()

for u, v in edges:
    # Find common neighbor
    common = adj[u] & adj[v]
    if common:
        w = min(common)
        # Output in sorted order
        a, b, c = sorted([u+1, v+1, w+1])
        print(a, b, c)
        break
```
