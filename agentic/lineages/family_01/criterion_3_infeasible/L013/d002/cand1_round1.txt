# Problem C — Mechanical Jam

Time limit: 2 s   Memory limit: 256 MB

A clockwork mechanism consists of $n$ cogs, numbered 1 through $n$. The design specifies $m$ direct mechanical links, where the teeth of two specific cogs interlock. Whenever two cogs interlock, they are forced to rotate in opposite directions.

The designers intended for the entire mechanism to rotate continuously. However, the prototype is completely seized. An inspection reveals a fatal structural flaw: a localized parity conflict. Specifically, there exists at least one triplet of distinct cogs where the first interlocks with the second, the second interlocks with the third, and the third interlocks directly back with the first. In this arrangement, rotation is physically impossible, as the alternating rotation directions cannot be simultaneously satisfied around the loop.

To authorize a redesign, the lead engineer requires a formal defect report identifying the components involved in one of these minimal conflicting loops. Your task is to find three cogs that form this exact configuration.

## Input
The first line contains two integers $n$ and $m$ ($3 \le n \le 2000$, $3 \le m \le \min(n(n-1)/2, 2 \cdot 10^5)$).
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), representing that cog $u$ and cog $v$ interlock. Each pair is listed at most once.
It is guaranteed that at least one such triplet of cogs exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, representing the IDs of three cogs that form the described loop. The IDs must be printed in ascending order ($a < b < c$).
If there are multiple such combinations, you must output the one that is lexicographically smallest. That is, minimize $a$; if there is a tie, minimize $b$; and if there is still a tie, minimize $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
Removed the phrasing "mutually mesh" and "every cog meshes directly with the other two", which acts as a strong semantic trigger for "clique". Replaced it with a sequential description of a 3-cycle (first interlocks with second, second with third, third back to first). This forces the model to synthesize the loop structure rather than relying on the keyword-like definition of a complete subgraph.
</RATIONALE>
<PRESERVED_ANSWER>
The target configuration (a 3-cycle in an undirected graph) is mathematically identical to a 3-clique (triangle), so the lexicographically smallest set of three such vertices remains exactly the same.
</PRESERVED_ANSWER>
