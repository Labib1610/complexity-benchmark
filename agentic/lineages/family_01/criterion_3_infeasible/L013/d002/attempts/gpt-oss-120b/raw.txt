**Solution Explanation**

For three different cogs `a < b < c` we need all three links  

```
a – b ,  a – c ,  b – c
```

i.e. a triangle in the undirected graph.
The required answer is the lexicographically smallest triangle
(`a` minimal, then `b`, then `c`).

--------------------------------------------------------------------

#### 1.   Data structures  

* `adj_bool[i][j]` – `True` iff edge `i‑j` exists.  
  `n ≤ 2000`, therefore a `n × n` boolean matrix (list of `bytearray`)
  needs at most 4 MB.

* `adj_bits[i]` – an integer whose binary representation is the adjacency
  set of vertex `i`.  
  Bit `k` (0‑based) is `1` iff there is an edge `i – (k+1)`.  
  With Python integers bitwise operations are performed on whole
  machine words, so the intersection of two adjacency sets is **O(1)**
  (the constant is the number of machine words, at most 2000/64 = 32).

--------------------------------------------------------------------

#### 2.   Searching the smallest triangle  

We iterate over all ordered pairs `(a,b)` with `a < b` in increasing order.
For a fixed pair we need the smallest `c > b` that is adjacent to **both**
`a` and `b`.

```
common = adj_bits[a] & adj_bits[b]          # vertices adjacent to both
common >>= b                                 # delete vertices ≤ b
if common != 0:
        low = common & -common               # lowest set bit
        offset = low.bit_length() - 1        # its index (0‑based)
        c = b + 1 + offset
        answer = (a,b,c)                     # first found → lexicographically minimal
```

The first pair `(a,b)` for which `common` is non‑empty yields the required
triangle, because we scan `a` then `b` in increasing order and always pick
the smallest possible `c`.

The total work:

* building the structures – `O(m)`
* the double loop – at most `n·(n-1)/2 ≤ 2·10⁶` iterations,
  each doing a few constant‑time operations.

Both time (`≈ 2·10⁶` operations) and memory limits are easily satisfied.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs exactly the lexicographically smallest
triangle.

---

##### Lemma 1  
For any vertices `a < b`, after the statement  

```
common = adj_bits[a] & adj_bits[b]
common >>= b
```

`common` contains a `1` at position `k` (0‑based) **iff**
vertex `c = b + 1 + k` is adjacent to both `a` and `b` and `c > b`.

**Proof.**  
`adj_bits[a] & adj_bits[b]` has a `1` exactly at positions of vertices
adjacent to **both** `a` and `b`. Shifting right by `b` discards bits
for vertices `1 … b`. The remaining bit at index `k` corresponds to vertex
`b+1+k`. ∎



##### Lemma 2  
If `common != 0` then the algorithm computes  

```
c = b + 1 + offset
```

where `c` is the smallest vertex `> b` adjacent to both `a` and `b`.

**Proof.**  
`low = common & -common` isolates the lowest set bit of `common`. Its
index `offset` is the smallest `k` with a `1`. By Lemma&nbsp;1 this `k`
corresponds to the smallest admissible vertex `c = b+1+k`. ∎



##### Lemma 3  
When the algorithm terminates, the printed triple `(a,b,c)` is a triangle
(i.e. all three edges exist).

**Proof.**  
The outer loops guarantee `a < b`. By the `if` condition we have
`adj_bool[a][b] == True`. Lemma&nbsp;2 gives a `c > b` that is adjacent to
both `a` and `b`. Hence edges `a‑b`, `a‑c`, `b‑c` all exist. ∎



##### Lemma 4  
Let `T = (a₀,b₀,c₀)` be the triangle output by the algorithm.
For any triangle `T' = (a',b',c')` with `a' < b' < c'` we have
`a₀ ≤ a'`. If `a₀ = a'` then `b₀ ≤ b'`. If also `b₀ = b'` then `c₀ ≤ c'`.

**Proof.**  
The algorithm scans pairs `(a,b)` in lexicographic order.
The first pair for which a common neighbor `c` exists is `(a₀,b₀)`.
Therefore no earlier pair `(a,b)` with `a < a₀` or `a = a₀, b < b₀`
has a common neighbor, i.e. no triangle can start with a smaller `a`
or with the same `a` and a smaller `b`.  
When `(a₀,b₀)` is fixed, Lemma&nbsp;2 chooses the smallest possible `c`,
hence `c₀` is minimal among triangles with this `a₀,b₀`. ∎



##### Theorem  
The algorithm prints the lexicographically smallest triangle of the graph.

**Proof.**  
By Lemma&nbsp;3 the output is a triangle.
Lemma&nbsp;4 shows that no other triangle is lexicographically smaller.
Thus the printed triangle is exactly the required one. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Memory*  

* adjacency matrix `n × n` bytes  → ≤ 4 MB  
* `n` integers for bitsets          → ≤ 2000·(2000/8) ≈ 0.5 MB  

Total < 5 MB.

*Time*  

* building structures: `O(m)` ( ≤ 2·10⁵ )
* double loop over pairs: `n·(n-1)/2` ≤ 2·10⁶ iterations,
  each `O(1)`.

Overall `O(n² + m)` ≤ 2·10⁶ operations, well inside the 2 s limit.

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    # adjacency matrix for O(1) edge test
    adj_bool = [bytearray(n) for _ in range(n)]
    # adjacency bitsets
    adj_bits = [0] * n

    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj_bool[u][v] = 1
        adj_bool[v][u] = 1
        adj_bits[u] |= 1 << v
        adj_bits[v] |= 1 << u

    for a in range(n):
        row_a = adj_bits[a]
        for b in range(a + 1, n):
            if not adj_bool[a][b]:
                continue
            common = row_a & adj_bits[b]
            # keep only vertices > b
            common >>= b
            if common:
                low = common & -common          # lowest set bit
                offset = low.bit_length() - 1   # its index (0‑based)
                c = b + 1 + offset
                # output in 1‑based, sorted order
                print(a + 1, b + 1, c + 1)
                return

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
