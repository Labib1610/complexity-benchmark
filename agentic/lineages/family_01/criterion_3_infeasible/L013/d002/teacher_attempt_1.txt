# Problem C — Altitude Plan Rejection

Time limit: 2 s
Memory limit: 256 MB

A logistics company manages a fleet of $n$ delivery drones. Each drone is assigned a unique integer label starting from 1 up to the fleet size $n$. The fleet size $n$ is at least 3. The local airspace regulations allow a maximum of 2000 registered drones per operator, so the fleet size will never exceed this limit.

The safety system has logged $m$ pairs of drones that have overlapping flight trajectories. The number of such pairs $m$ is at least 3, and will not exceed the total number of possible unique pairs of drones in the fleet, nor will it exceed a database limit of 200,000. 

Two drones with overlapping trajectories cannot be assigned to the same cruising altitude. The operations team initially proposed restricting the entire fleet to exactly two cruising altitudes. However, this proposal is fundamentally unworkable due to the presence of *deadlocks*. 

A deadlock is a set of exactly three drones such that every possible way to assign those three drones to two available cruising altitudes results in at least one altitude containing a pair of drones with overlapping trajectories. 

To finalize the rejection of the two-altitude proposal, you must provide a formal certificate of its failure by identifying one such deadlock.

## Input
The first line contains two integers $n$ and $m$, representing the fleet size and the number of overlapping pairs, bounded as described above.
The following $m$ lines each contain two integers $u$ and $v$ ($u \ne v$), representing that the drone labeled $u$ and the drone labeled $v$ have overlapping trajectories. Each pair is listed at most once.
It is guaranteed that at least one deadlock exists.

## Output
Print three integers $a$, $b$, and $c$ on a single line, separated by spaces, representing the labels of three drones that form a deadlock. The labels must be printed in ascending order ($a < b < c$).
If there are multiple deadlocks, you must output the one that is lexicographically smallest. That is, minimize $a$; if there is a tie, minimize $b$; and if there is still a tie, minimize $c$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
2 4
3 4
```
Output:
```
1 2 3
```

## Example 2
Input:
```
5 6
1 2
1 4
2 4
3 4
3 5
4 5
```
Output:
```
1 2 4
```

<RATIONALE>
I replaced the explicit description of a "mutually path-crossing trio" with the concept of a "deadlock" – defined as a set of three drones that cannot be partitioned into two altitudes without a conflict. This forces the model to logically deduce via the Pigeonhole Principle that a deadlock is exactly a triangle in the conflict graph, rather than triggering on explicit graph-theoretic hints. In addition, numeric bounds were removed from the Input section and embedded naturally into the scenario description (Strategy S07).
</RATIONALE>
<PRESERVED_ANSWER>
A set of three items cannot be partitioned into two conflict-free sets if and only if all three items mutually conflict, meaning every valid output for the seed is exactly a valid output for this rewrite.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a 3-clique (triangle) in an undirected graph, preserving the original algorithmic complexity.
</PRESERVED_CLASS>
