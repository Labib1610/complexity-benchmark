We can solve this by checking each possible triple in a smart way.  
Since we need the lexicographically smallest triangle, we can iterate over the first vertex `a` from 1 to n, then the second vertex `b` from `a+1` to n, and check if they are connected. If they are, we look for the smallest `c > b` that is connected to both `a` and `b`.  

We can store the adjacency in a set for fast lookup.  

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].add(v)
        adj[v].add(u)

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if b in adj[a]:
                for c in range(b + 1, n + 1):
                    if c in adj[a] and c in adj[b]:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    main()
```
