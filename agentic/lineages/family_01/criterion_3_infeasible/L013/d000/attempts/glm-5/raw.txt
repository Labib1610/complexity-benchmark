Looking at this problem, I need to find the lexicographically smallest triangle (3-clique) in an undirected graph.

**Approach:**
- For each vertex `a` in ascending order, try to find the smallest `b > a` that's a neighbor of `a`, then the smallest `c > b` that's a neighbor of both `a` and `b`.
- To check if `c` is a neighbor of both, I can use a hash set for one vertex's neighbors and iterate through the other's neighbors in sorted order.

**Key optimization:** For each `a`, I iterate through its neighbors `b` in ascending order. For each such `b`, I need the smallest `c > b` that's in both `adj[a]` and `adj[b]`. Using a set for `adj[a]` allows O(1) lookup, and iterating `adj[b]` in sorted order finds the first valid `c` quickly.

Since we want lexicographically smallest (a, b, c), iterating `a` from 1 to n, then `b` from smallest neighbor > a, then `c` from smallest neighbor > b that's common to both, gives the correct answer on the first valid triple found.

**Complexity:** For each `a`, we look at pairs of its neighbors. The sum over all `a` of (number of neighbor pairs) could be O(n·m) in worst case, but with n ≤ 2000 and m ≤ 2·10^5, and early termination, this should be fast enough.

```python
import sys

def main():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        adj[u].append(v)
        adj[v].append(u)
    
    # Sort adjacency lists and create sets for fast lookup
    adj_set = [None] * (n + 1)
    for i in range(1, n + 1):
        adj[i].sort()
        adj_set[i] = set(adj[i])
    
    for a in range(1, n + 1):
        sa = adj_set[a]
        for b in adj[a]:
            if b <= a:
                continue
            sb = adj_set[b]
            # Find smallest c > b in both sa and sb
            # Iterate through adj[a] (sorted) for c > b
            for c in adj[a]:
                if c <= b:
                    continue
                if c in sb:
                    print(a, b, c)
                    return
    
    # Should never reach here per problem guarantee
    print(-1)

main()
```
