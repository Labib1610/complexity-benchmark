We need to find a triangle (3 mutually connected nodes) in the graph, and among all triangles, output the lexicographically smallest one.

Since n ≤ 2000 and m ≤ 2·10^5, we can use an adjacency matrix (boolean) for O(1) edge checks, and iterate over all triples in increasing order until we find the first triangle.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = adj[v][u] = True

    # Iterate over all triples in lexicographic order
    for a in range(1, n - 1):
        for b in range(a + 1, n):
            if not adj[a][b]:
                continue
            for c in range(b + 1, n + 1):
                if adj[a][c] and adj[b][c]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    main()
```
