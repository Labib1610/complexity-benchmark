<STATEMENT>
# Problem B — Shift Allocations

Time limit: 1 s
Memory limit: 256 MB

A manufacturing plant must assign its employees to one of two operating shifts, designated 1 and 2.

The facility is divided into exactly 200 zones, each containing 1,000 individual workstations. Every employee requires a workstation, so the total headcount $n$ is at least 1 and cannot exceed the total number of workstations across all zones.

Certain pairs of employees share a specialized tool kit. The maintenance ledger contains 400 pages, each with exactly 500 lines for recording these tool-sharing agreements. The total number of agreements $m$ can be 0 up to the maximum number of lines in the ledger.

Because a tool kit is passed between users at the shift changeover, any two employees who share a kit must be placed on opposite shifts. Specifically, for every agreement, one employee must be assigned to shift 1 and the other to shift 2.

Determine if there is a valid shift assignment for all $n$ employees. If multiple valid assignments exist, you must find the one that forms the lexicographically smallest sequence of shift numbers.

## Input
The first line contains two integers $n$ and $m$ — the number of employees and the total number of tool-sharing agreements. The bounds for these values are determined by the physical limits described above.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of employees who share a tool kit.

## Output
If no valid shift assignment exists, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1, 2\}$) representing the shift assigned to each employee, ensuring the overall sequence is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was reframed around allocating shifts based on tool-sharing agreements. To implement strategy S07, explicit bounds on $n$ and $m$ were replaced with physical capacities (200 zones of 1,000 workstations, and a 400-page ledger with 500 lines per page). This forces the model to read and perform arithmetic to size its data structures correctly, rather than relying on standard $10^5$ limit templates. Additionally, the "incompatible pair" phrasing was replaced with an indirect coverage constraint (one employee on shift 1, the other on shift 2) to prevent models from immediately pattern-matching to graph coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical requirements are identical: assign each variable one of two values such that specified pairs have different values, and return the lexicographically smallest valid assignment or NO if none exists.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically first 2-coloring of a graph, which is solvable in polynomial time (P) using Breadth-First Search.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "lexicographically smallest sequence of shift numbers" if they assume it refers to something other than the sequence $s_1 \dots s_n$, but the Output section explicitly ties the sequence to the $s_i$ values to prevent this.
</RISK>
