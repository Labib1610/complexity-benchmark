# Frequency Allocation

Time limit: 1 s   Memory limit: 256 MB

A communications satellite broadcasts on two frequency bands, labeled 1 and 2. The network manages $n$ transmitters, numbered 1 to $n$. Due to signal overlap, certain pairs of transmitters will interfere if they broadcast on the exact same band. The network has identified $m$ such interfering pairs.

You must assign each transmitter a frequency band so that no interfering pair shares the same band. If multiple valid assignments exist, you must output the one that is lexicographically smallest (meaning you compare the full assignment sequence $s_1, s_2, \dots, s_n$ in index order and prefer the sequence that assigns band 1 to lower-numbered transmitters as early as possible). If no valid allocation exists, you must report that it is impossible.

## Input
The first line contains two integers $n$ and $m$. The hardware constraints dictate that the transmitter count $n$ is bounded by a minimum of $1$ active unit and a maximum deployment of $2 \cdot 10^5$ units. The system can process a number of interference logs $m$ ranging from a completely empty log of $0$ up to a storage limit of $2 \cdot 10^5$ entries.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of transmitters that cannot share a frequency band.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
