# Radio Configuration

Time limit: 1 s   Memory limit: 256 MB

A manufacturing facility issues communication radios to its technicians. Each radio must be tuned to one of two channels, channel 1 or channel 2. Due to hardware limitations, specific pairs of technicians working in close proximity will experience feedback if their radios share a channel. 

The facility employs a workforce of technicians, assigned sequential ID numbers starting from 1. The HR system guarantees a headcount of up to two hundred thousand, with at least one technician always on staff. An interference log lists pairs of technicians that cause feedback. The logging system has a maximum capacity of two hundred thousand records, though it might contain no records at all.

Your task is to assign a channel to each technician to eliminate all feedback. To maintain a standardized setup, if there are multiple valid ways to configure the radios, you must provide the lexicographically smallest valid assignment (assigning channel 1 to lower-ID technicians whenever possible). If it is impossible to resolve all feedback, report this.

## Input
The first line contains two integers $n$ and $m$, representing the exact number of technicians and the number of interference records, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ — the IDs of a pair of technicians whose radios will experience feedback if tuned to the same channel.

## Output
If no feedback-free assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each being 1 or 2), representing the lexicographically smallest valid channel assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
