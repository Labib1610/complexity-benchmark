<STATEMENT>
# Problem B — Factory Schedules

Time limit: 1 s   Memory limit: 256 MB

A production facility operates using two distinct time blocks, coded as $1$ and $2$. You must assign exactly one time block code to each of the $n$ active personnel.

There are $m$ separation contracts. Each contract specifies two personnel who must work on alternative blocks to ensure continuous coverage. Specifically, if a contract involves person $u$ and person $v$, the time block code assigned to $u$ and the time block code assigned to $v$ must sum to exactly $3$.

Determine if there is a valid assignment of time block codes to all $n$ personnel that satisfies every separation contract. If multiple valid assignments exist, you must find the one that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$, representing the active headcount (from a minimum of $1$ up to a facility capacity of $2\cdot 10^5$) and the number of contracts (from $0$ up to a limit of $2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of personnel bound by a separation contract.

## Output
If no valid arrangement exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), the lexicographically smallest valid arrangement.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit graph-coloring terminology ("no incompatible pair shares a schedule") was replaced with an algebraic condition ("must sum to exactly 3"). Since the only valid codes are 1 and 2, this logically forces the assignments to be distinct, but models that rely purely on pattern-matching bipartite-graph keywords will fail to recognize the equivalence. Additionally, the constraints were integrated into the scenario description as physical and systemic limits, as required by S07.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that two values from the set {1, 2} sum to 3 is mathematically identical to requiring that the two values are different, preserving the exact same valid arrangements and tie-breaking as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a 2-coloring of an undirected graph (or determining bipartiteness), which is solvable in O(n + m) time using BFS or DFS.
</PRESERVED_CLASS>
