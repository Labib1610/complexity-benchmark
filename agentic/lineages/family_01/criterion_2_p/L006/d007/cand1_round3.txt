<METHOD_NAME>Physical Domain Equation Camouflage</METHOD_NAME>
<METHOD_DESCRIPTION>Replaced explicit logical implications with a physical domain equation (reaction rate = product of concentrations) that mathematically enforces the same bipartite constraint. This forces the model to deduce the discrete inequality from a continuous-looking physical law, disrupting pattern matching to graph coloring.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem B — Chemical Equilibrium

Time limit: 1 s   Memory limit: 256 MB

You are simulating a chemical system with $n$ distinct reactants to find a stable configuration. For the system to reach equilibrium, each reactant $i$ must be assigned a steady-state concentration $c_i \in \{1, 2\}$ (in mol/L).

The system log contains $m$ elementary bimolecular reactions. Each reaction involves two reactants $u$ and $v$.
According to the law of mass action, the rate of a reaction between $u$ and $v$ is equal to the product of their concentrations, $c_u \times c_v$.

To achieve equilibrium, every logged reaction must proceed at a rate of exactly 2.
(Note: If a logged reaction involves the same reactant twice, meaning $u = v$, its rate would be $c_u^2$, which can only be 1 or 4. This immediately violates the equilibrium requirement and destabilizes the system).

If there are multiple valid concentration assignments that satisfy all logged reactions, you must output the sequence $c_1 \dots c_n$ that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the indices of the two reactants involved in the $j$-th logged reaction. The reactions are given in order for $j = 1, 2, \dots, m$.

## Output
If no such assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1 \dots c_n$ (where each $c_i \in \{1,2\}$) representing the elements of the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The four explicit implication rules were replaced with a single physical domain equation: the product of the two concentrations must equal 2. Since concentrations are restricted to {1, 2}, this mathematically enforces that the two values must be different, preserving the bipartite graph structure while completely removing the explicit logic that models were using to pattern-match the coloring algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $c_u \times c_v = 2$ for $c_i \in \{1, 2\}$ is satisfied if and only if one value is 1 and the other is 2, which is exactly the same requirement as the original problem, ensuring all valid assignments and the lexicographically smallest one remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph (or determining if it is bipartite), keeping it in P and solvable in O(n+m) time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "proceed at a rate of exactly 2" as a global sum of rates rather than a per-reaction requirement, although the phrasing "every logged reaction must proceed at..." strongly implies it applies individually to each reaction.
</RISK>
