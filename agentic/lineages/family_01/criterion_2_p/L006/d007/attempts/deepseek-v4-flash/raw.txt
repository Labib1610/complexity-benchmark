We can model this as a graph problem.  
Each reactant is a node, and each reaction is an edge.  
The condition \( c_u \times c_v = 2 \) means one must be 1 and the other 2.  
So the graph must be bipartite, and we need the lexicographically smallest 1/2 assignment.

We can solve it with BFS/DFS coloring, trying to assign 1 whenever possible.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n  # -1 uncolored, 0 -> concentration 1, 1 -> concentration 2

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
