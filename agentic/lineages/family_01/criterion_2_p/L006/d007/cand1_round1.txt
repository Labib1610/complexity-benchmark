<STATEMENT>
# Orbital Reflection Synchrony

Time limit: 1 s   Memory limit: 256 MB

A satellite network consists of $n$ orbital modules, numbered $1$ through $n$. You must assign each module an operating mode, represented by the integer $1$ or $2$. 

The network's synchronization is governed by $m$ telemetry channels. Each channel connects a specific pair of modules. For a channel to function correctly, the two connected modules must generate a stable synchronization sequence. 

For a channel connecting module $u$ and module $v$, the sequence $A$ is defined as follows:
- The zeroth term is the mode of the first module: $A_0 = p_u$
- The first term is the mode of the second module: $A_1 = p_v$
- Each subsequent term is the modulo 3 sum of the two preceding terms: $A_k = (A_{k-1} + A_{k-2}) \bmod 3$ for all $k \ge 2$.

The telemetry channel is considered stable and functions correctly if and only if the sum of the first 82 terms of this sequence (that is, $\sum_{k=0}^{81} A_k$) is exactly 93. Because of the sequence's properties, the stability of the channel does not depend on which of the two connected modules is considered $u$ and which is considered $v$.

Your task is to assign an operating mode ($1$ or $2$) to each of the $n$ modules so that every telemetry channel functions correctly. If multiple valid assignments are possible, you must output the lexicographically smallest valid sequence of modes. If no such assignment is possible, you must report that it cannot be done.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), representing the indices of a pair of modules connected by a telemetry channel.

## Output
If it is impossible to configure the modules to satisfy all channels, output a single line with NO.
If it is possible, output YES on the first line. On the second line, output $n$ integers $p_1 \dots p_n$ (where each $p_i \in \{1,2\}$) giving the lexicographically smallest valid sequence of modes.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit state transformations with a condition based on the sum of a Fibonacci-like sequence modulo 3. This forces the model to analytically deduce or simulate the sequence to discover that the condition is satisfied if and only if the two modules have different modes, preventing surface-level pattern matching of "opposite states" to bipartite graph coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The sequence sum is exactly 93 if and only if the two modes are different (1 and 2), which is mathematically identical to the original problem's requirement that connected modules have different states, preserving all valid assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in O(N+M) time using Breadth-First Search, keeping it in P.
</PRESERVED_CLASS>
<RISK>
None. The sequence generation and the exact sum required are mathematically unambiguous and deterministic.
</RISK>
