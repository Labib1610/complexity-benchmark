# Problem B — System Equilibrium

Time limit: 1 s   Memory limit: 256 MB

You are tasked with finding a state vector $S = \begin{pmatrix} s_1 \\ s_2 \\ \vdots \\ s_n \end{pmatrix}$ such that each particle's spin state is $s_i \in \{1, 2\}$ for all $1 \le i \le n$.

The system consists of $n$ particles and a log of $m$ interactions. Each interaction involves two particles $u$ and $v$.
To maintain equilibrium, the interactions impose strict geometric constraints on the particles' states.

For each particle $i$, we define its characteristic spinor as a 2D vector $\psi_i = \begin{pmatrix} s_i \\ 3 - s_i \end{pmatrix}$.
For every logged interaction between particle $u$ and particle $v$, their spinors must satisfy the following entanglement condition:
$\langle \psi_u, \psi_v \rangle = 4$
where $\langle \psi_u, \psi_v \rangle$ denotes the standard dot product (inner product) of the two vectors.

If any interaction in the log fails to satisfy this condition, the system fails to reach equilibrium. Note that if an interaction logs the same particle twice (i.e., $u = v$), the condition $\langle \psi_u, \psi_u \rangle = 4$ must hold, which may immediately destabilize the system.

If there are multiple valid state vectors $S$ that satisfy all conditions, you must find the one that minimizes the system's total energy potential, defined as:
$E(S) = \sum_{i=1}^n s_i \cdot 3^{n-i}$

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the indices of the two particles involved in the $j$-th interaction. The interactions are given in order for $j = 1, 2, \dots, m$.

## Output
If no such vector $S$ exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$) representing the elements of the valid vector $S$ that minimizes the total energy potential $E(S)$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
