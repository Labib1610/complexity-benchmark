# Orbital Reflection Synchrony

Time limit: 1 s   Memory limit: 256 MB

A satellite network consists of $n$ orbital modules, numbered $1$ through $n$. You must assign each module an operating mode, represented by the integer $1$ or $2$.

The network's synchronization is governed by $m$ telemetry channels. Each channel connects a specific pair of modules. For a channel to function correctly, its two connected modules must create a stable resonance. 

Resonance stability is determined by a mathematical game played independently on each channel. For a given channel connecting modules $u$ and $v$, consider a counter initially set to 0. Two virtual technicians alternate turns. On a technician's turn, they must choose one of the two modules ($u$ or $v$) and add its assigned operating mode ($1$ or $2$) to the counter. A module may be chosen any number of times during the game. 

A technician loses the game immediately if their move causes the counter to become 17 or strictly greater. The channel is considered stable if and only if the technician who takes the first turn has a winning strategy in this game (assuming optimal play from both sides).

Your task is to assign an operating mode ($1$ or $2$) to each of the $n$ modules so that every telemetry channel is stable. If multiple valid assignments are possible, you must output the lexicographically smallest valid sequence of modes. If no such assignment is possible, you must report that it cannot be done.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), representing the indices of a pair of modules connected by a telemetry channel.

## Output
If it is impossible to configure the modules to satisfy all channels, output a single line with NO.
If it is possible, output YES on the first line. On the second line, output $n$ integers $p_1 \dots p_n$ (where each $p_i \in \{1,2\}$) giving the lexicographically smallest valid sequence of modes.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I changed the local disequality constraint into a combinatorial game (a variant of Bachet's game) played independently on each edge, where the allowed moves are the modes of the endpoints. This forces the model to correctly evaluate the game's truth table to discover that the first player wins if and only if the modes are different, bridging game theory and structural graph properties.
</RATIONALE>
<PRESERVED_ANSWER>
The combinatorial game evaluates to a first-player win if and only if the two chosen modes are different, which perfectly preserves the original constraint that connected modules must have different modes, leaving all valid assignments identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest orientation of an undirected graph with no equal adjacent values, which is solvable in linear time using Breadth-First Search, keeping it firmly in P.
</PRESERVED_CLASS>
<RISK>
A model might mistakenly assume the game is played globally across all channels at once rather than independently on each edge, though the text explicitly states it is played "independently on each channel".
</RISK>
