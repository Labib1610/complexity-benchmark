# Calibration Valves

Time limit: 1 s   Memory limit: 256 MB

A fluid transport network contains $n$ calibration valves, numbered $1$ to $n$. Each valve must be configured to an operating pressure level of either $1$ or $2$.

The network is monitored by $m$ differential sensors. Each sensor bridges a specific pair of valves. The hardware calibration dictates that a sensor can only stabilize and yield a valid reading if the total combined pressure level of the two valves it bridges is exactly 3. If the combined pressure level of the bridged valves is anything else, the sensor experiences a calibration fault.

The facility's architectural limit allows a maximum capacity of 200,000 valves, and the same upper bound applies to the number of sensors.

You must determine a pressure level for each of the $n$ valves such that every sensor in the network yields a valid reading. If there are multiple valid configurations, you must output the one that is lexicographically smallest (assigning pressure level $1$ to lower-numbered valves whenever possible). If no valid configuration exists, report impossibility.

## Input
The first line contains two integers $n$ and $m$. The number of valves $n$ is at least $1$, and the number of sensors $m$ is at least $0$. Neither $n$ nor $m$ exceeds the facility's architectural maximum capacity.
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of a pair of valves bridged by a sensor.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $p_1 \dots p_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
