<STATEMENT>
# Problem B — System Equilibrium

Time limit: 1 s   Memory limit: 256 MB

A fluid control facility contains $n$ automated valves, labeled 1 through $n$. The system's protocol dictates that every valve must be assigned an operational tier of either 1 or 2.

The network is supervised by $m$ pressure monitors. Each monitor is linked to a specific pair of valves. For the network to achieve equilibrium, every monitor must confirm that the tier of one of its linked valves is exactly twice the tier of the other linked valve.

You must determine whether a configuration exists that satisfies all monitors. If there are several valid configurations for the $n$ valves, you must output the sequence of tiers $s_1 \dots s_n$ that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$. The facility is divided into 200 sectors, each with a strict capacity of 1000 units. The number of valves $n$ is at least 1 and at most the total unit capacity of all sectors combined. The number of monitors $m$ is non-negative and is bounded by the same total capacity.

Each of the following $m$ lines contains two integers $u$ and $v$ — the labels of the two valves linked to a single monitor.

## Output
If no such configuration is possible, print a single line containing NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$) representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit bounds for $n$ and $m$ ($2 \cdot 10^5$) were replaced with a derivation from facility sectors and unit capacities (200 sectors $\times$ 1000 units). More importantly, the explicit equation `sum = 3` which heavily primed models to recognize opposite colors was replaced with the physical constraint that one valve's tier must be exactly twice the other's. Since the tiers are restricted to $\{1, 2\}$, this logically requires exactly the same assignments (one valve at 1, the other at 2) but breaks simple pattern-matching for bipartite coloring templates.
</RATIONALE>
<PRESERVED_ANSWER>
Because the only possible values are 1 and 2, the condition that one value is exactly twice the other is satisfied if and only if one value is 1 and the other is 2, which is mathematically identical to their sum being exactly 3.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding a valid 2-coloring of a graph (testing bipartiteness) and choosing the lexicographically smallest assignment for each connected component.
</PRESERVED_CLASS>
<RISK>
Models might mistakenly attempt to implement a division or multiplication check in their logic rather than recognizing the underlying graph structure, though the problem text is completely clear about the mathematical requirement.
</RISK>
