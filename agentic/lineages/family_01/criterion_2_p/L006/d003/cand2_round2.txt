# Problem B — System Equilibrium

Time limit: 1 s   Memory limit: 256 MB

A fluid control facility contains $n$ automated valves, labeled 1 through $n$. The system's protocol dictates that every valve must be assigned an operational tier of either 1 or 2.

The network is supervised by $m$ pressure monitors. Each monitor is linked to a specific pair of valves. For the network to achieve equilibrium, every monitor must verify that the operational tier of one of its linked valves is exactly twice the tier of the other.

You must determine whether a configuration exists that satisfies all monitors. If there are several valid configurations for the $n$ valves, you must output the sequence of tiers $s_1 \dots s_n$ that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ — the labels of the two valves linked to a single monitor.

## Output
If no such configuration is possible, print a single line containing NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$) representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the monitor condition from "sum ... is exactly 3" to "one ... is exactly twice ... the other". This removes the explicit arithmetic equation that models used to trigger opposite-color logic, forcing them to deduce that the only compatible pairs from {1, 2} are (1, 2) and (2, 1). The exact seed bounds were restored to comply with strict numeric checks while keeping the scenario uncluttered.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that one tier is twice the other for values in {1, 2} is satisfied if and only if one valve is 1 and the other is 2, exactly equivalent to their sum being 3.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a lexicographically smallest 2-coloring of a graph, which is solvable in linear time using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
None, the condition "exactly twice" is mathematically precise and unambiguous for the given domain {1, 2}.
</RISK>
