<STATEMENT>
# Fragrance Formulation

Time limit: 1 s   Memory limit: 256 MB

A master perfumer is dividing $n$ essential extracts, numbered 1 through $n$, between two distinct product lines: Formulation 1 and Formulation 2. Each extract must be assigned to exactly one of these two lines.

Because of chemical volatility, certain pairs of extracts will undergo a destructive reaction if assigned to the same product line. The perfumer has documented $m$ specific pairs of mutually reactive extracts.

You must determine if the extracts can be divided safely without triggering any reactions. If multiple safe divisions exist, the perfumer applies a strict sequential filtering process to select the final plan:
1. Start with the set of all possible safe divisions.
2. For each extract $i$ from 1 to $n$ in increasing order: check if any of the currently remaining safe divisions assign extract $i$ to Formulation 1. If at least one does, discard all divisions that assign extract $i$ to Formulation 2. (If none do, keep the current set of divisions).

Your objective is to find the single safe division that survives this filtering process. If no safe division is possible at all, the entire batch must be discarded.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
The next $m$ lines each contain two integers $u$ and $v$ — a reactive pair of extracts that must be kept in separate formulations.

## Output
If no safe division exists, output a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $f_1, f_2, \dots, f_n$ (where each $f_i \in \{1, 2\}$) representing the formulation assigned to each extract in the division that survives the filtering process.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Removed the "concatenating the sequence of choices to form a single n-digit integer" phrasing which acts as a direct keyword trigger for "lexicographical minimization". Replaced it with a step-by-step mechanical filtering process that describes the exact same outcome. This forces the model to either recognize the equivalence conceptually or attempt to simulate the filtering process (which is too slow if done naively).
</RATIONALE>
<PRESERVED_ANSWER>
The mechanical filtering process exactly replicates lexicographical minimization, always preferring Formulation 1 for the lowest-indexed available extract, resulting in the exact same output array.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains 2-coloring/bipartiteness testing, which is solvable in O(n+m) time by assigning color 1 to the lowest-indexed unvisited node of each connected component.
</PRESERVED_CLASS>
