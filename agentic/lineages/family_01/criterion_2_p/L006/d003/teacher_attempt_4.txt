# Orbital Telemetry Routing

Time limit: 1 s   Memory limit: 256 MB

A satellite network contains $n$ telemetry modules, labeled 1 to $n$. The central control system must configure each module to transmit on one of two available frequencies: Frequency 1 or Frequency 2. Every module must be assigned exactly one frequency.

Due to hardware proximity, certain modules have overlapping broadcast signatures. Control has identified $m$ pairs of modules that will cause signal corruption if they are configured to use the same frequency. 

You must determine if it is possible to assign every module to a frequency such that no two overlapping modules share the same frequency. When multiple valid configurations exist, the system logs the configuration as a single $n$-digit integer by concatenating the sequence of choices $b_1, b_2, \dots, b_n$ (where each $b_i$ is either 1 or 2). To standardize the logs, you must find the valid configuration that results in the smallest possible value for this $n$-digit integer. If no safe configuration is possible, the system halts and the configuration fails.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$ — a pair of modules that have overlapping signatures and must be assigned to different frequencies.

## Output
If no safe configuration is possible, output a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $b_1, b_2, \dots, b_n$ (where each $b_i \in \{1, 2\}$) representing the frequency assigned to each module, corresponding to the configuration that minimizes the described $n$-digit integer.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

I completely replaced the "fragrance formulation" scenario with a "satellite telemetry synchronization" scenario. By swapping the entities (extracts to modules) and the constraints (chemical volatility to broadcast interference), the problem requires the model to independently recognize the underlying bipartite structure instead of relying on the specific real-world framing of the seed.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to assign one of two states to objects while avoiding given conflicting pairs, and minimizing the concatenated sequence of states, is mathematically identical to the seed problem.
</PRESERVED_ANSWER>

The core problem remains 2-coloring (bipartiteness testing) on an undirected graph, which is solvable in O(n+m) time using BFS/DFS.
