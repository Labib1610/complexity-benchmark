# Fragrance Formulation

Time limit: 1 s   Memory limit: 256 MB

A master perfumer is working with a set of essential extracts, labeled from 1 to $n$. Because of chemical volatility, certain extracts will neutralize each other if they share an environment. The perfumer has documented $m$ such volatile pairs that must be separated.

To achieve this, every extract must be assigned a storage tier. There are exactly two tiers available: tier 1 and tier 2. For every documented volatile pair, the two extracts must be assigned to different tiers.

In cases where more than one valid tier assignment exists, the laboratory evaluates the assignment by concatenating the sequence of choices $t_1, t_2, \dots, t_n$ to form a single $n$-digit integer (where each digit $t_i$ is either 1 or 2). Your objective is to find a valid assignment that minimizes the value of this integer. If it is impossible to separate the extracts safely into the two tiers, the entire batch must be discarded.

The laboratory stores extracts in cases of 1,000. The facility can accommodate up to 200 such cases of extracts in total, and the perfumer must work with at least one extract. The digital logbook for volatile pairs has a strict storage quota of 4,000 pages, with each page capable of holding exactly 50 pair entries, though the logbook may be completely empty.

## Input
The first line provides two integers $n$ and $m$, representing the number of extracts and the number of volatile pairs. The bounds for these values are defined by the laboratory capacities described above.
The next $m$ lines each contain two integers $u$ and $v$ — a volatile pair of extracts that must be kept separated.

## Output
If no valid separation exists, output a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $t_1, t_2, \dots, t_n$ (where each $t_i \in \{1, 2\}$) representing the tier assigned to each extract in the separation that minimizes the $n$-digit integer described above.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
