<METHOD_DESCRIPTION>
Replaces the XOR condition with a requirement that a parameterized cubic function's concavity changes exactly at x=1. This forces models to perform symbolic calculus to deduce that the sum of the variables must be 3, and then recognize this as a bipartiteness constraint.
</METHOD_DESCRIPTION>

yes

<STATEMENT>
# Signal Resonance Tuning

Time limit: 1 s   Memory limit: 256 MB

A communication network consists of $n$ transmission nodes, numbered $1$ through $n$. You must configure each node to operate at a primary frequency multiplier of either $1$ or $2$.

The network contains $m$ resonance channels. Each channel connects a specific pair of nodes. The stability of a channel depends on the combined waveform of the two nodes it connects. Specifically, if a channel connects node $u$ (with frequency multiplier $p_u$) and node $v$ (with frequency multiplier $p_v$), their interaction is modeled by the cubic waveform function:

$$W(x) = x^3 - (p_u + p_v)x^2 + (p_u \cdot p_v)x$$

For the channel to stabilize and transmit data without interference, the concavity of the function $W(x)$ must change exactly at $x = 1$. If the inflection point of $W(x)$ occurs at any other value of $x$, the channel destabilizes.

Your task is to assign a frequency multiplier (either $1$ or $2$) to each of the $n$ nodes so that every resonance channel in the network correctly stabilizes. If multiple valid assignments exist, output the **lexicographically smallest** sequence $p_1,\dots,p_n$. (Among two valid assignments, the one with a smaller value at the first node index where they differ is considered smaller). If no such assignment is possible, you must report that it cannot be done.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$, representing the indices of a pair of nodes connected by a resonance channel.

## Output
If it is impossible to configure the nodes to satisfy all channels, output a single line with `NO`.
If it is possible, output `YES` on the first line. On the second line, output $n$ integers $p_1 \dots p_n$ (where each $p_i \in \{1,2\}$) giving the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I completely replaced the bitwise XOR constraint with a continuous calculus property: the inflection point of a parameterized cubic function must occur exactly at x=1. This forces models to perform symbolic differentiation to find the inflection point, yielding the equation $(p_u + p_v)/3 = 1$. Only after bridging this continuous math domain back to the discrete domain $\{1, 2\}$ can they recognize the underlying bipartite graph structure. I also strictly restored the explicit lexicographical tie-break wording as requested by the expert critique.
</RATIONALE>
<PRESERVED_ANSWER>
The inflection point of $W(x)$ occurs where its second derivative is zero, which is at $x = (p_u + p_v)/3$; setting this to 1 requires $p_u + p_v = 3$, which over the domain $\{1, 2\}$ is exactly equivalent to the seed's requirement that $p_u \oplus p_v = 3$ (i.e., $p_u \neq p_v$).
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains finding the lexicographically smallest 2-coloring of an undirected graph, which is solvable in linear time $O(n+m)$ using Breadth-First Search.
</PRESERVED_CLASS>
<RISK>
Models might fail to recognize that the calculus condition simplifies to a discrete graph constraint and attempt to implement a continuous optimization algorithm, leading to a Time Limit Exceeded error.
</RISK>
