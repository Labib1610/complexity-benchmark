# Problem B — System Equilibrium

Time limit: 1 s   Memory limit: 256 MB

You are tasked with finding a sequence of discrete states $s_1, s_2, \dots, s_n$ such that $s_i \in \{1, 2\}$ for all $1 \le i \le n$.

The system's constraints are defined by a sequence of $m$ index pairs. For the $j$-th pair $(u, v)$, we define a cubic polynomial $P_j(x)$ via the following definite integral:

$$ P_j(x) = \int_{0}^x (t - s_u)(t - s_v) \, dt $$

The system is considered to be in equilibrium if, for every $j \in \{1, 2, \dots, m\}$, the polynomial $P_j(x)$ has a point of inflection exactly at $x = 1.5$.

If there are multiple valid state sequences $s_1 \dots s_n$ that place the system in equilibrium, you must output the sequence that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the pair of indices used to construct the $j$-th polynomial constraint. The pairs are given in order for $j = 1, 2, \dots, m$.

## Output
If no such sequence of states exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$) representing the lexicographically smallest valid sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit matrix construction (which models easily pattern-matched to graph adjacency and bipartiteness) with a calculus-based equilibrium condition. By defining a cubic polynomial via an integral and requiring its point of inflection to be at $x = 1.5$, models are forced to perform algebraic derivation ($P''(x) = 0 \implies s_u + s_v = 3$) to discover the underlying 2-coloring constraint, disrupting immediate shortcut recognition.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the point of inflection of $\int_0^x (t-s_u)(t-s_v) dt$ occurs at $x = 1.5$ simplifies exactly to $s_u + s_v = 3$, which is identical to the original $MS = \mathbf{3}$ matrix constraint, ensuring all valid state vectors remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires assigning two values (1 or 2) to elements such that specified pairs sum to 3 (i.e., must be different), which is exactly 2-coloring (bipartiteness testing) solvable in $O(n+m)$ time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the calculus terminology if they lack strong algebraic reasoning, but mathematically the definition of a point of inflection for a cubic polynomial is standard and unambiguous.
</RISK>
