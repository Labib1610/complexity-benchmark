We can model this as a graph problem.  
Each qubit is a node, and each link is an edge.  
The condition “product of codes equals 2” means one endpoint must be 1 and the other must be 2.  
So the graph must be bipartite. If it’s not bipartite, output `NO`.  

For the tie-breaker, we want the lexicographically smallest assignment of 1s and 2s.  
We can do a BFS/DFS coloring, but when a node is uncolored, we try assigning 1 first (to get smaller number), and propagate. If that leads to a conflict, we try 2.  

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n  # -1 uncolored, 0 for code 1, 1 for code 2

def bfs(start):
    # try color 0 (code 1) first
    q = deque([start])
    color[start] = 0
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        if not bfs(i):
            print("NO")
            sys.exit()

print("YES")
print(' '.join(str(c + 1) for c in color))
```
