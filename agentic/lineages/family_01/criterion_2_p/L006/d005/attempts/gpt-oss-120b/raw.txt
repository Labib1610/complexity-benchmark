**Solution Explanation**

For a module we have two possible transformations  

* mode **1** : `(x , y) → (‑x , y)` – horizontal reflection  
* mode **2** : `(x , y) → ( x ,‑y)` – vertical   reflection  

For a channel connecting modules `u , v` the composition

```
apply transformation of u
then transformation of v
```

has to be the point reflection through the origin

```
(x , y) → (‑x ,‑y)
```

--------------------------------------------------------------------

#### 1.   Algebraic formulation

A transformation is a diagonal matrix  

```
mode 1 :  (-1 , 1)
mode 2 :  ( 1 ,-1)
```

( first component changes the sign of `x`, second the sign of `y` ).

Applying `u` then `v` multiplies the two diagonal matrices component‑wise:

```
(x , y) → ( sx[u]·sx[v]·x ,  sy[u]·sy[v]·y )
```

`sx[i] , sy[i]` are the signs of the two coordinates produced by the
chosen mode of module `i`.

The required result `(-x , -y)` means  

```
sx[u]·sx[v] = -1            (1)
sy[u]·sy[v] = -1            (2)
```

For both modes we always have `sy = - sx` :

```
mode 1 : sx = -1 , sy =  1
mode 2 : sx =  1 , sy = -1
```

Therefore condition (2) is automatically satisfied when (1) holds.
So the whole problem reduces to the single requirement

```
sx[u] = - sx[v]          for every edge (u , v)                (★)
```

--------------------------------------------------------------------

#### 2.   Graph interpretation

Give each module a binary value

```
b[i] = 0   →  mode 1   (sx = -1)
b[i] = 1   →  mode 2   (sx =  1)
```

Equation (★) becomes

```
b[u] ≠ b[v]          for every edge
```

Exactly the definition of a **proper 2‑colouring** of the graph,
i.e. the graph must be *bipartite*.

If the graph is not bipartite → answer `NO`.

--------------------------------------------------------------------

#### 3.   Lexicographically smallest colouring

A bipartite connected component has **two** possible colourings
(the second one is obtained by swapping 0 ↔ 1 everywhere).
For the whole graph we may choose independently for every component
which of the two colourings to use.

The lexicographically smallest sequence of modes is obtained by the
following simple rule:

*process the vertices in increasing order `1 … n`*  
*whenever we meet an uncoloured vertex, start a BFS from it and colour it `0`*  

The start vertex is the **smallest index inside its component**, therefore it
gets colour `0` (mode 1). Any other possible orientation would give it colour `1`
(mode 2) and would be lexicographically larger.
Consequently this greedy rule yields the global optimum.

--------------------------------------------------------------------

#### 4.   Algorithm
```
read n , m
build adjacency list
colour[1…n] = -1                     // -1 = not visited yet
for v = 1 … n
        if colour[v] == -1
                colour[v] = 0
                queue ← [v]
                while queue not empty
                        x = queue.pop()
                        for each neighbour y of x
                                if colour[y] == -1
                                        colour[y] = colour[x] xor 1
                                        queue.append(y)
                                else if colour[y] == colour[x]
                                        print "NO" and exit
// bipartite, lexicographically minimal
print "YES"
for i = 1 … n
        print 1 if colour[i]==0 else 2
```

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints `YES` and a lexicographically smallest
valid assignment **iff** such an assignment exists.

---

##### Lemma 1  
For any assignment of modes, condition “the composition on every edge is
point reflection” holds **iff** adjacent vertices receive different modes
(1 ↔ 2).

**Proof.**  
From Section&nbsp;1 we derived the equivalent condition `sx[u] = -sx[v]`.
Because `sx = -1` corresponds to mode 1 and `sx = 1` to mode 2,
`sx[u] = -sx[v]` is exactly “the two modes are different”. ∎



##### Lemma 2  
During the BFS the algorithm never assigns the same colour to two
adjacent vertices *iff* the graph is bipartite.

**Proof.**  
The BFS colours a connected component by the rule
`colour[neighbour] = colour[current] xor 1`.  
If the graph contains an odd cycle, when the last edge of the cycle is
examined both its ends already have the same colour → conflict,
algorithm aborts.  
Conversely, if the graph is bipartite, a proper 2‑colouring exists.
Starting from any vertex and applying the rule above reproduces exactly
that colouring, therefore no conflict appears. ∎



##### Lemma 3  
If the algorithm finishes without conflict, the produced assignment
satisfies all channels.

**Proof.**  
Finishing without conflict means every edge connects vertices of
different colours. By Lemma&nbsp;1 this is precisely the required condition,
hence all channels work. ∎



##### Lemma 4  
For each connected component the algorithm assigns mode 1 to the vertex
with the smallest index inside that component.

**Proof.**  
Components are processed by the outer loop from `v = 1` upwards.
The first visited vertex of a component is the vertex with minimal index.
The algorithm sets its colour to `0`, i.e. mode 1,
and all other colours are forced relative to it.
Thus the claim holds. ∎



##### Lemma 5  
Among all valid assignments the one produced by the algorithm is
lexicographically smallest.

**Proof.**  
Consider any component `C`.  
All valid assignments must colour `C` either exactly as the algorithm does
or the opposite (swap 0 ↔ 1), because a component is bipartite and has only
two colourings.

Let `p` be the smallest index belonging to `C`.  
By Lemma&nbsp;4 the algorithm gives `p` mode 1.  
Any other valid assignment gives `p` either mode 1 (identical) or mode 2
(the opposite orientation).  
If it gives mode 2, the whole sequence becomes lexicographically larger,
because the first position where the two sequences may differ is `p`.  

Since this argument holds for every component independently, no other
valid assignment can be lexicographically smaller. ∎



##### Lemma 6  
If a valid assignment exists, the algorithm never reports “NO”.

**Proof.**  
A valid assignment implies the graph is bipartite (Lemma&nbsp;1).  
By Lemma&nbsp;2 a BFS on a bipartite graph never encounters a conflict,
hence the algorithm does not output “NO”. ∎



##### Theorem  
The algorithm outputs  

* “NO” **iff** no assignment of modes satisfying all channels exists;  

* otherwise “YES” followed by the lexicographically smallest valid
  assignment.

**Proof.**  

*If part*:  
If the algorithm prints “NO”, a conflict was found during BFS.
By Lemma&nbsp;2 the graph is not bipartite, therefore by Lemma&nbsp;1 no
assignment can satisfy all edges.

*Only‑if part*:  
Assume a satisfying assignment exists.
By Lemma&nbsp;6 the algorithm never prints “NO”.  
It finishes, and by Lemma&nbsp;3 the produced assignment is valid.
Lemma&nbsp;5 shows it is the lexicographically smallest among all valid
assignments. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Building adjacency list* – `O(n + m)` memory and time.  
*BFS over all vertices* – each vertex and edge examined once: `O(n + m)` time.  

Total  

```
Time   :  O(n + m)      ≤ 4·10⁵ operations
Memory :  O(n + m)
```

Both satisfy the limits.

#### 7.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 = unvisited, 0 = mode1, 1 = mode2
    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        colour[start] = 0
        q = deque([start])
        while q:
            v = q.popleft()
            cv = colour[v]
            for to in adj[v]:
                if colour[to] == -1:
                    colour[to] = cv ^ 1
                    q.append(to)
                elif colour[to] == cv:
                    sys.stdout.write("NO")
                    return

    # successful
    out = ["YES\n"]
    modes = ['1' if colour[i] == 0 else '2' for i in range(1, n + 1)]
    out.append(' '.join(modes))
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
