<STATEMENT>
# Entanglement Initialization

Time limit: 1 s   Memory limit: 256 MB

You are configuring a quantum register composed of $n$ qubits, indexed from 1 up to $n$. Your task is to assign an initial state code to each qubit. There are two valid state codes, each corresponding to a specific basis projection:
- Code 1 assigns a projection of $+\frac{1}{2}$.
- Code 2 assigns a projection of $-\frac{1}{2}$.

The architecture of the register includes $m$ fixed entanglement links, each connecting a pair of qubits. The system is subject to a strict conservation of angular momentum. Consequently, any two qubits joined by an entanglement link must have a net projection of exactly $0$ (i.e., the sum of their individual projection values must vanish).

Your objective is to determine whether it is possible to assign a state code to every qubit such that the angular momentum conservation rule is satisfied across all $m$ links.

When multiple valid configurations are possible, the compiler resolves the ambiguity by evaluating a global configuration score. For a given assignment of state codes $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2\}$), the score is defined mathematically as $S = \sum_{i=1}^n c_i \cdot 2^{n-i}$. The compiler will strictly accept the initialization that minimizes this score $S$. If no valid assignment exists, the compilation process halts with an error.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the subsequent $m$ lines provides two integers $u$ and $v$, specifying an entanglement link between qubit $u$ and qubit $v$.

## Output
If the qubits cannot be initialized without violating the conservation rule, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, provide $n$ space-separated integers $c_1, c_2, \dots, c_n$ (each $c_i \in \{1, 2\}$). These integers must represent the state codes of the valid initialization that yields the absolute minimum score $S$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Changed the presentation of the tie-breaking rule from minimizing an $n$-digit concatenated integer to minimizing a weighted sum of powers of 2. This forces the model to mathematically deduce that the sum is uniquely minimized by the lexicographically smallest sequence, bypassing the direct keyword match to "smallest integer" which triggers a greedy component-wise assignment in standard solutions.
</RATIONALE>
<PRESERVED_ANSWER>
The function $S = \sum_{i=1}^n c_i \cdot 2^{n-i}$ with $c_i \in \{1, 2\}$ is strictly monotonic with respect to the lexicographical order of the sequence $c$, meaning the exact same unique configuration is always selected as the original tie-breaker.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem requires finding a valid 2-coloring of a graph and selecting the lexicographically first valid coloring, which is solvable in linear time using BFS.
</PRESERVED_CLASS>
<RISK>
Models might assume they need to compute the score $S$ using arbitrary-precision arithmetic and encounter overflow issues, rather than realizing it purely defines a lexicographical preference, but this represents a failure of algorithmic reasoning rather than an ambiguity in the wording.
</RISK>
