We can model this as a graph problem. Each qubit is a node, and each bridge is an edge. The condition that XOR of two connected nodes equals 3 means that if one is 1, the other must be 2, and vice versa. So the graph must be bipartite, and we assign values 1 and 2 to the two partitions.

To get the lexicographically smallest assignment, we can use BFS/DFS and assign 1 to the starting node of each connected component, then alternate. If a conflict occurs, output `NO`.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    # color 0 -> 1, color 1 -> 2
    res = [1 if c == 0 else 2 for c in color]
    print(" ".join(map(str, res)))
```
