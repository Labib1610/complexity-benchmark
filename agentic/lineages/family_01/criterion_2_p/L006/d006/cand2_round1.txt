<METHOD_DESCRIPTION>
Replaced the explicit geometric reflections with affine transformations modulo 31 that are inverses of each other but not self-inverses. This preserves the exact XOR constraint (adjacent nodes must have different modes) while completely hiding the bipartite graph structure behind modular arithmetic. A diagnostic example using a fixed point ($x=2$) is strategically included to trap models that lazily extrapolate from a single test case instead of rigorously applying the universal quantifier.
</METHOD_DESCRIPTION>

yes

<STATEMENT>
# Telemetry Payload Synchronization

Time limit: 1 s   Memory limit: 256 MB

A satellite network consists of $n$ orbital modules, numbered $1$ through $n$. You must assign each module an operating mode, represented by the integer $1$ or $2$.

The modes determine how a module transforms incoming telemetry payloads, which are represented by an integer $x$ ($0 \le x < 31$):
- Mode 1 applies the transformation: $x$ becomes $(13x + 7) \bmod 31$.
- Mode 2 applies the transformation: $x$ becomes $(12x + 9) \bmod 31$.

(For example, a diagnostic payload $x=2$ processed by Mode 1 becomes $(13(2) + 7) \bmod 31 = 33 \bmod 31 = 2$. Processed by Mode 2, it becomes $(12(2) + 9) \bmod 31 = 33 \bmod 31 = 2$.)

The network's synchronization is governed by $m$ telemetry channels. Each channel connects a specific pair of modules. For a channel to function correctly, the chained effect of the two modules' transformations must leave the payload unchanged. That is, if you take any integer $x$ ($0 \le x < 31$), apply the transformation for the mode assigned to one module, and then apply the transformation for the mode assigned to the other module, the final result must always be exactly $x$. If the combined transformations yield any other result for even a single value of $x$, the channel fails. (Note that because of the transformations used, the order in which the two connected modules apply their transformations does not affect the final result.)

Your task is to assign an operating mode ($1$ or $2$) to each of the $n$ modules so that every telemetry channel functions correctly. If multiple valid assignments are possible, you must output the lexicographically smallest valid sequence of modes. If no such assignment is possible, you must report that it cannot be done.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), representing the indices of a pair of modules connected by a telemetry channel.

## Output
If it is impossible to configure the modules to satisfy all channels, output a single line with NO.
If it is possible, output YES on the first line. On the second line, output $n$ integers $p_1 \dots p_n$ (where each $p_i \in \{1,2\}$) giving the lexicographically smallest valid sequence of modes.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was previously solved by models matching the geometric reflection composition to a standard XOR/bipartite constraint. By replacing the geometry with modular affine transformations, the underlying constraint remains identical (Mode 1 and Mode 2 are inverses, but neither is an involution), but it forces the model to either perform rigorous algebraic deduction or write a correct simulation loop to discover the bipartite nature of the graph. The inclusion of the fixed point $x=2$ traps models that test only one value.
</RATIONALE>
<PRESERVED_ANSWER>
The modular transformations chosen guarantee that Mode 1 + Mode 2 yields exactly $x$ for all $x$, while Mode 1 + Mode 1 and Mode 2 + Mode 2 fail for some $x$ (e.g., $x=0$), making the valid configurations isomorphic to the original XOR constraint, thus preserving all outputs including lexicographical order.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a valid 2-coloring of a graph (or identifying an odd cycle), which remains in P and is solvable in linear time using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the diagnostic example as implying that $x=2$ is the only payload that matters, despite the explicit wording "for even a single value of x, the channel fails" and "any integer x".
</RISK>
