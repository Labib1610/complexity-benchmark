<METHOD_DESCRIPTION>Replaces the explicit edge-by-edge constraints with a single global algebraic equation summing over all edges and vertices. The equation is constructed such that the difference between the sides is a sum of non-negative terms per edge, which only equals zero when every edge connects different values. <STATEMENT>
# Problem B — Sequence Equation

Time limit: 1 s   Memory limit: 256 MB

You are given $n$ variables $s_1, s_2, \dots, s_n$ and a list of $m$ index pairs. You need to assign a value of either $1$ or $2$ to each variable to satisfy a specific equation.

Let $d_i$ be the total number of times the index $i$ appears across all $m$ pairs. If a pair consists of the same index twice (e.g., $u = v$), it contributes $2$ to the count $d_u$.

An assignment is considered valid if it satisfies the following condition:
$$ 2 \sum_{j=1}^m s_{u_j} s_{v_j} + 5m = 3 \sum_{i=1}^n d_i s_i $$
where the first sum is over all $m$ given pairs $(u_j, v_j)$, and the second sum is over all $n$ variables.

If there are multiple valid assignments $s_1 \dots s_n$ that satisfy the condition, you must output the one that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the indices for the $j$-th pair.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$) representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Removed the contrived physics narrative entirely in favor of a neutral, standard competitive-programming array assignment framing. The equilibrium condition is compressed into a single global algebraic equation. By separating the sum over edges from the sum over vertices (weighted by degree), models are forced to algebraically deduce that the global equation strictly requires $s_u \neq s_v$ for every pair, defeating models that rely on surface-level bipartiteness keywords or fail to recognize the local non-negativity of the reduced terms.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $2 \sum s_{u_j} s_{v_j} + 5m = 3 \sum d_i s_i$ mathematically rewrites to $\sum (2s_u s_v - 3s_u - 3s_v + 5) = 0$; for $s \in \{1,2\}$, each term is $\ge 0$ and equals $0$ if and only if $s_u \neq s_v$, perfectly preserving the original bipartite coloring constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing), solvable in O(n+m) using BFS/DFS.
</PRESERVED_CLASS>
