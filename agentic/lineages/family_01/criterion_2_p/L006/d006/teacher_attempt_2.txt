<STATEMENT>
# Entanglement Initialization

Time limit: 1 s   Memory limit: 256 MB

A quantum register consists of $n$ qubits, sequentially labeled from 1 to $n$. You are tasked with initializing this register by assigning a configuration code to each qubit. Each configuration code must be chosen from the set {1, 2}.

The register's architecture includes $m$ hardware entanglement links, each connecting a specific pair of qubits. The system requires operational stability across all these connections. Specifically, an entanglement link is stable if and only if the product of the configuration codes assigned to its two endpoints evaluates to exactly 2.

Your objective is to find an assignment of configuration codes for all $n$ qubits such that every single entanglement link in the circuit is stable.

In cases where multiple valid assignments exist, the compiler applies a deterministic tie-breaker based on signal prioritization. Each qubit $i$ ($1 \le i \le n$) has a priority weight of $2^{-i}$. The compiler will always choose the valid assignment that maximizes the sum of the priority weights of all qubits that receive configuration code 1. If it is impossible to stabilize all links simultaneously, the compilation process aborts.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of qubits and the number of entanglement links.
Each of the subsequent $m$ lines provides two integers $u$ and $v$, specifying that an entanglement link connects qubit $u$ and qubit $v$.

## Output
If the register cannot be fully stabilized, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2\}$). These integers must represent the configuration codes of the assignment that maximizes the total priority weight as described above.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the tie-breaker from a concatenated minimum integer (which directly hints at lexicographical order and greedy assignment) to maximizing a sum of exponentially decaying weights ($2^{-i}$). This forces the model to mathematically deduce that the sum is strictly dominated by the smallest index, structurally reducing to the same lexicographical preference without giving away the logic through surface phrasing.
</RATIONALE>
<PRESERVED_ANSWER>
Because $2^{-i} > \sum_{j=i+1}^n 2^{-j}$, maximizing the sum of weights for qubits assigned 1 is mathematically identical to lexicographically minimizing the sequence of configuration codes, ensuring the optimal assignment remains exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core constraints still require assigning values from {1, 2} such that adjacent nodes have different values, which is exactly 2-coloring (bipartite testing) and remains solvable in $O(n+m)$ time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the weight $2^{-i}$ as requiring actual floating-point computation and fail due to precision limits for $n=200,000$, though a competent reader will recognize the structural dominance.
</RISK>
