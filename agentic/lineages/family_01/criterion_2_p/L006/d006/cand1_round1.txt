<METHOD_DESCRIPTION>Replaces a global algebraic sum with a per-node local balance equation F_i = C_i. The capacity C_i is chosen to be the extreme bound of F_i (maximum when s_i=1, minimum when s_i=2), forcing all neighbors to take the opposite state. <STATEMENT>
# Problem B — System Equilibrium

Time limit: 1 s   Memory limit: 256 MB

You are tasked with finding a state vector $S = \begin{pmatrix} s_1 \\ s_2 \\ \vdots \\ s_n \end{pmatrix}$ such that $s_i \in \{1, 2\}$ for all $1 \le i \le n$, which puts a simulated particle system into equilibrium.

The system consists of $n$ particles and a log of $m$ interactions. Each interaction involves two particles $u$ and $v$. Let $d_i$ be the total number of times particle $i$ appears across all $m$ interactions. (If an interaction involves the same particle twice, i.e., $u = v$, it contributes 2 to the count $d_u$).

The system is in equilibrium if and only if, for every particle $i$ in the system, its incoming kinetic flux $F_i$ exactly matches its theoretical capacity $C_i$.

The incoming kinetic flux $F_i$ is defined as the sum of the cubes of the states of the interacting partners across all interactions involving particle $i$. Formally, for each of the $m$ logged interactions between particles $u$ and $v$:
- If $u \neq v$, the interaction adds $s_v^3$ to $F_u$ and $s_u^3$ to $F_v$.
- If $u = v$, the interaction adds $2 \cdot s_u^3$ to $F_u$.
(If a particle has no interactions, its flux is $0$.)

The theoretical capacity of particle $i$ is defined as $C_i = d_i (9 - s_i^3)$.

If there are multiple valid vectors $S$ that satisfy the equilibrium condition for all particles, you must output the sequence $s_1 \dots s_n$ that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the indices of the two particles involved in the $j$-th interaction. The interactions are given in order for $j = 1, 2, \dots, m$.

## Output
If no such vector $S$ exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$) representing the elements of the lexicographically smallest valid vector $S$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I changed the global algebraic energy equation into a per-particle local flux balance condition. The new condition uses the cubes of the states and sets the required capacity for each particle to exactly the extreme bound of its possible incoming flux. This forces models to reason about minimum and maximum possible sums to deduce that all interacting particles must take the opposite state, preventing them from bypassing the reasoning by simply simplifying a quadratic equation.
</RATIONALE>
<PRESERVED_ANSWER>
Because the capacity C_i equals the maximum possible flux when s_i=1 and the minimum possible flux when s_i=2, satisfying F_i = C_i mathematically requires every interacting partner to have the opposite state, enforcing exactly the same bipartiteness constraint on all edges as the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest proper 2-coloring of a graph, which is solvable in O(n+m) time using Breadth-First Search, keeping it in the polynomial time class P.
</PRESERVED_CLASS>
