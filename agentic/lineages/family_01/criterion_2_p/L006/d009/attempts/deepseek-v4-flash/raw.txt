We can model this as a graph problem where each module is a node, and each connection imposes a constraint between the assignments of the two modules.

Let’s analyze the permutations:

- Assignment 1: swaps (A,B) and (C,D)  
- Assignment 2: swaps (A,C) and (B,D)

If we apply assignment 1 twice, we get identity. Same for assignment 2.  
If we apply assignment 1 then assignment 2, the result is a 4-cycle:  
A→B→D→C→A, so no channel stays in place.  
Similarly, assignment 2 then assignment 1 also gives a 4-cycle.

So the condition “no channel maps to itself” is satisfied **if and only if** the two modules have **different** assignments.

Thus, each connection (u, v) requires `s_u != s_v`.

This becomes a bipartite coloring problem. If the graph is bipartite, we can assign 1 and 2 accordingly.  
For lexicographically smallest, we do BFS/DFS and assign 1 whenever possible.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(' '.join(str(c + 1) for c in color))
```
