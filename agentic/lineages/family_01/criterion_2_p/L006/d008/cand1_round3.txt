<METHOD_DESCRIPTION>
Replaces the seed's recognizable matrix trace condition with a quadratic Diophantine equation $2p_u^2 - 5p_u p_v + 2p_v^2 = 0$. Over the allowed domain $\{1, 2\}$, this equation evaluates to $0$ if and only if $p_u \neq p_v$. This algebraically disguises the "different modes" constraint (bipartite coloring) without using the recognizable matrix traces from the seed, forcing models to algebraically deduce the inequality constraint instead of relying on memorized matrix properties.
</METHOD_DESCRIPTION>

<STATEMENT>
# Orbital Reflection Synchrony

Time limit: 1 s   Memory limit: 256 MB

A satellite network consists of $n$ orbital modules, numbered $1$ through $n$. You must assign each module an operating mode, represented by the integer $1$ or $2$.

The network's synchronization is governed by $m$ telemetry channels. Each channel connects a specific pair of modules. For a telemetry channel connecting module $u$ and module $v$ to function correctly, their assigned modes $p_u$ and $p_v$ must satisfy the following stability equation:

$2p_u^2 - 5p_u p_v + 2p_v^2 = 0$

Your task is to assign an operating mode ($1$ or $2$) to each of the $n$ modules so that every telemetry channel functions correctly. If multiple valid assignments are possible, you must output the lexicographically smallest valid sequence of modes (comparing sequences from index $1$ to $n$). If no such assignment is possible, you must output a specific failure message.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), representing the indices of a pair of modules connected by a telemetry channel.

## Output
If it is impossible to configure the modules to satisfy all channels, output a single line containing `NO`.
If it is possible, output `YES` on the first line. On the second line, output $n$ integers $p_1 \dots p_n$ (where each $p_i \in \{1,2\}$) giving the lexicographically smallest valid sequence of modes.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I removed the matrix trace condition completely as it was being recognized by models as a standard bipartite coloring trigger. I replaced it with the quadratic equation $2p_u^2 - 5p_u p_v + 2p_v^2 = 0$. Since $p_i \in \{1, 2\}$, this equation is satisfied if and only if $p_u \neq p_v$. This forces models to algebraically analyze the equation to deduce the inequality constraint before they can recognize the underlying graph coloring problem.
</RATIONALE>
<PRESERVED_ANSWER>
The stability equation $2p_u^2 - 5p_u p_v + 2p_v^2 = 0$ holds for $p_u, p_v \in \{1, 2\}$ exactly when $p_u \neq p_v$, which perfectly matches the original constraint that connected modules must have different modes, leaving all valid configurations unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in $O(V+E)$ time using Breadth-First Search, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might fail to evaluate the quadratic equation over the restricted discrete domain $\{1, 2\}$, leading them to incorrectly assume the problem requires a general non-linear constraint solver rather than standard graph algorithms.
</RISK>
