<STATEMENT>
# Orbital Reflection Synchrony

Time limit: 1 s   Memory limit: 256 MB

A satellite network consists of $n$ orbital modules, numbered $1$ through $n$. You must assign each module an operating mode, represented by the integer $1$ or $2$.

Let $V$ be the vector space of polynomials in $x$ of degree at most 2 with real coefficients. We define two linear operators on $V$:
- $\mathcal{D}$, which maps a polynomial $P(x)$ to its formal derivative $P'(x)$.
- $\mathcal{J}$, a truncated integration operator, defined on the standard basis as $\mathcal{J}(1) = x$, $\mathcal{J}(x) = \frac{1}{2}x^2$, and $\mathcal{J}(x^2) = 0$, and extended linearly to all of $V$.

Each mode assigns a specific linear transformation to the module:
- Mode 1 assigns the transformation $T_1 = \mathcal{I} + 2\mathcal{D}$, where $\mathcal{I}$ is the identity operator.
- Mode 2 assigns the transformation $T_2 = \mathcal{I} + 2\mathcal{J}$.

The network's synchronization is governed by $m$ telemetry channels. Each channel connects a specific pair of modules. For a channel to function correctly, the composition of the two modules' assigned transformations must have a trace exactly equal to $11$. (The trace of a linear operator on $V$ is the sum of the diagonal elements of its matrix representation in any basis).

Because the trace of a composition of two operators is independent of the order of application (i.e., $\text{Tr}(A \circ B) = \text{Tr}(B \circ A)$), the order in which the two modules' transformations are composed does not matter. If the trace of their composition evaluates to any value other than $11$, the telemetry channel fails.

Your task is to assign an operating mode ($1$ or $2$) to each of the $n$ modules so that every telemetry channel functions correctly. If multiple valid assignments are possible, you must output the lexicographically smallest valid sequence of modes. If no such assignment is possible, you must report that it cannot be done.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), representing the indices of a pair of modules connected by a telemetry channel.

## Output
If it is impossible to configure the modules to satisfy all channels, output a single line with NO.
If it is possible, output YES on the first line. On the second line, output $n$ integers $p_1 \dots p_n$ (where each $p_i \in \{1,2\}$) giving the lexicographically smallest valid sequence of modes.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I removed the explicit $3 \times 3$ matrices that allowed models to trivially pattern-match the trace values. Instead, I redefined the exact same transformations as linear operators (derivative and truncated integral) on a polynomial vector space. This forces the model to mathematically construct the operator compositions and evaluate their traces to discover that the channel constraint still strictly requires opposite modes, preventing a bypass of the bipartite-checking logic.
</RATIONALE>
<PRESERVED_ANSWER>
The trace of the composed operators evaluates to 11 if and only if the modes are different (and 3 otherwise), which is exactly the same binary inequality constraint as the original matrix formulation, ensuring all valid assignments and the lexicographical tie-breaking remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains logically equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in linear time using Breadth-First Search (P).
</PRESERVED_CLASS>
<RISK>
Some models might fail to correctly construct the matrix representation of the operators on the basis $\{1, x, x^2\}$, leading to an arithmetic error rather than an algorithmic failure. However, the exact mapping of basis elements is explicitly provided, leaving no ambiguity for a competent reader.
</RISK>
