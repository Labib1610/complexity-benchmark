# Orbital Reflection Synchrony

Time limit: 1 s   Memory limit: 256 MB

A satellite network consists of $n$ orbital modules, numbered $1$ through $n$. You must assign each module an operating mode, represented by the integer $1$ or $2$.

The network's synchronization is governed by $m$ telemetry channels. Each channel connects a specific pair of modules. For a channel connecting module $u$ and module $v$ to function correctly without signal interference, the modes $p_u$ and $p_v$ assigned to these modules must satisfy the following congruence relation:

$$(p_u^3 \cdot p_v + p_u \cdot p_v^3) \equiv 0 \pmod 5$$

Because the relation is symmetric, the order in which the two modules are evaluated does not matter. If the congruence evaluates to any non-zero value modulo 5, the telemetry channel fails.

Your task is to assign an operating mode ($1$ or $2$) to each of the $n$ modules so that every telemetry channel functions correctly. If multiple valid assignments are possible, you must output the valid sequence of modes $p_1 \dots p_n$ that minimizes the numerical value of the sequence when interpreted as a base-3 integer. If no such assignment is possible, you must report that it cannot be done.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), representing the indices of a pair of modules connected by a telemetry channel.

## Output
If it is impossible to configure the modules to satisfy all channels, output a single line with NO.
If it is possible, output YES on the first line. On the second line, output $n$ integers $p_1 \dots p_n$ (where each $p_i \in \{1,2\}$) giving the valid sequence of modes that minimizes the base-3 value.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
