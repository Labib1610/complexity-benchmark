# Resonant Centrifugation

Time limit: 1 s   Memory limit: 256 MB

A laboratory is processing $n$ essential extracts, numbered 1 through $n$. The batch size $n$ is at least one. The facility contains exactly 400 storage racks, each capable of holding 500 extract vials, establishing the maximum possible value for $n$.

Each extract must be loaded into exactly one of two available centrifuges: centrifuge 1 or centrifuge 2.

Due to matching resonance frequencies, certain pairs of extracts will cause a catastrophic vibration if loaded into the identical centrifuge. The laboratory's database contains $m$ such resonant pairs. The database might be empty (zero pairs). The database system allocates exactly 24 bytes per interaction record, and the maximum allowed allocation for these records is 4,800,000 bytes, dictating the upper limit for $m$.

Your task is to find a safe way to distribute all $n$ extracts between the two centrifuges such that no two extracts from a resonant pair are placed in the same centrifuge.

If multiple safe distributions exist, standard operating procedure dictates that lower-numbered extracts should be prioritized for centrifuge 1. Specifically, you must output the valid sequence of centrifuge choices (for extracts 1 through $n$) that is lexicographically smallest. If no safe distribution is possible, the batch must be discarded.

## Input
The first line contains two integers $n$ and $m$. The bounds for these values are derived from the physical storage and memory allocation limits described above.
Each of the following $m$ lines contains two integers $u$ and $v$ — a resonant pair of extracts that cannot share a centrifuge.

## Output
If there is no safe way to distribute the extracts, output a single line containing NO.
Otherwise, output YES on the first line. On the second line, output $n$ space-separated integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2\}$) representing the centrifuge assigned to each extract in the lexicographically smallest valid distribution.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

The scenario was changed from fragrance formulations to assigning extracts to centrifuges, preserving the core two-group conflict structure. The explicit numeric bounds for $n$ and $m$ were replaced with physical limitations (400 racks of 500 vials) and database allocation limits (4.8 MB at 24 bytes per record), forcing the model to read and comprehend the text to derive the standard $2 \cdot 10^5$ constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to partition items into two sets while avoiding specified conflicting pairs remains identical, as does the tie-breaking rule of finding the lexicographically smallest sequence of 1s and 2s.
</PRESERVED_ANSWER>

The problem still maps directly to 2-coloring / bipartiteness testing on a graph, which is solvable in linear time using BFS or DFS.
</PRESERVED_CLASS>
