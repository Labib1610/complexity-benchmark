# Problem B — System Equilibrium

Time limit: 1 s   Memory limit: 256 MB

A fluid control board manages a network of $n$ automated valves, numbered 1 to $n$. The board's architecture requires at least one valve, with a maximum hardware limit of 200,000 valves. Each valve must be programmed with an operational state of either 1 or 2.

The network is overseen by $m$ pressure monitors. The system can support anywhere from zero up to 200,000 monitors. Each monitor bridges a specific pair of valves. To maintain equilibrium, a monitor enforces an asymmetric flow between its bridged valves: they are strictly forbidden from operating in the same state.

Determine if there is a valid arrangement of states for all $n$ valves. If multiple valid arrangements exist, you must find the one that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ — the number of valves and the number of monitors, respectively, subject to the hardware limits described above.
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of the two valves bridged by a monitor.

## Output
If no valid arrangement exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid arrangement.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit explanation that "one valve must be state 1 and the other state 2" with the requirement that bridged valves are "strictly forbidden from operating in the same state," removing the immediate XOR phrasing. I also applied S07 by removing the bare inequalities from the Input section and instead embedding the exact limits of $n$ and $m$ as hardware capacities within the scenario text, forcing the model to extract the bounds from prose.
</RATIONALE>
<PRESERVED_ANSWER>
Because there are only two available states (1 and 2), forbidding two bridged valves from operating in the same state is logically identical to requiring one to be 1 and the other to be 2, leaving the set of valid arrangements completely unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core task is still assigning one of two states to nodes in a graph such that no adjacent nodes share a state, which is exactly graph 2-coloring (bipartiteness testing) and remains in P.
</PRESERVED_CLASS>
<RISK>
Models might struggle to parse the physical hardware limits as absolute constraints for $n$ and $m$, though the wording "minimum of one", "maximum hardware limit of 200,000", and "zero up to 200,000" is exact.
</RISK>
