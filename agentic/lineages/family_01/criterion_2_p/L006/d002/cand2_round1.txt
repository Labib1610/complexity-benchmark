<STATEMENT>
# Calibration Valves

Time limit: 1 s   Memory limit: 256 MB

A fluid transport network contains $n$ calibration valves, numbered $1$ to $n$. Each valve must be configured to an operating pressure level of either $1$ or $2$.

The network is monitored by $m$ differential sensors. Each sensor bridges a specific pair of valves. For a sensor to yield a valid reading, the pressure levels of the two valves it bridges must be compatible. Specifically, if a sensor bridges two valves assigned pressure levels $x$ and $y$, the reading is valid if and only if the entry $C_{x,y}$ in the system's compatibility matrix is $1$. The matrix $C$, with row and column indices $1$ and $2$, is given by:
- $C_{1,1} = 0$
- $C_{1,2} = 1$
- $C_{2,1} = 1$
- $C_{2,2} = 0$

You must determine a pressure level for each of the $n$ valves such that every sensor in the network yields a valid reading. If there are multiple valid configurations, you must output the one that is lexicographically smallest (assigning pressure level $1$ to lower-numbered valves whenever possible). If no valid configuration exists, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of a pair of valves bridged by a sensor.

## Output
If no valid configuration exists, print a single line `NO`.
Otherwise print `YES`, then a second line with $n$ integers $p_1 \dots p_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Re-presented the sensor compatibility condition from an explicit algebraic sum to a 2-by-2 lookup matrix. This removes the direct semantic trigger for 2-coloring, forcing the model to evaluate the matrix entries to deduce that bridged valves must have different values.
</RATIONALE>
<PRESERVED_ANSWER>
The compatibility matrix exactly encodes the requirement that bridged valves must have different pressure levels (1 and 2), which is mathematically identical to their sum being 3.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically first 2-coloring of an undirected graph, which is solvable in O(n+m) time using BFS.
</PRESERVED_CLASS>
<RISK>
Models might be confused about whether the matrix lookup requires an ordered pair of valves, though the matrix is symmetric so the order of $x$ and $y$ does not affect the outcome.
</RISK>
