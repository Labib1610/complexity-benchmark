# Redundant Power Grids

Time limit: 1 s   Memory limit: 256 MB

A deep space observatory has $n$ sensor arrays, numbered 1 through $n$. To ensure failsafe operation, each array must be hardwired to exactly one of two primary power buses: Bus 1 or Bus 2.

Due to electromagnetic interference, certain pairs of sensor arrays will suffer signal degradation if they draw power from the same bus simultaneously. The engineering team has compiled a list of $m$ such conflicting pairs.

Your task is to determine if it is possible to wire all $n$ sensor arrays to the two buses such that no two conflicting arrays share the same bus. If multiple valid configurations are possible, the automated wiring system always prefers to place lower-numbered arrays on Bus 1. Specifically, you must output the valid configuration whose sequence of assignments is lexicographically smallest. If no such configuration exists without causing signal degradation, the system must abort.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of sensor arrays that conflict if placed on the same bus.

## Output
If there is no valid way to wire the arrays without conflicts, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $b_1, b_2, \dots, b_n$ (where each $b_i \in \{1, 2\}$) representing the bus assigned to each array in the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
