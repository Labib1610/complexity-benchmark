# Problem B — System Equilibrium

Time limit: 1 s   Memory limit: 256 MB

A modern industrial plant operates a network of $n$ automated valves, indexed from 1 up to $n$. The control system requires every single valve to be locked into one of two operational modes: mode 1 or mode 2.

To guarantee safe pressure distribution, the plant is equipped with $m$ diagnostic monitors. A monitor is permanently attached to a specific pair of valves. For the system to remain in stable equilibrium, a monitor's safety protocol dictates that the two valves it oversees must always be locked into distinct operational modes. 

Your task is to determine whether it is possible to configure the modes of all $n$ valves such that every monitor's safety protocol is satisfied. Should there be more than one way to achieve this stable configuration, you must supply the sequence of modes that is lexicographically smallest.

## Input
The first line specifies two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$) representing the number of valves and diagnostic monitors, respectively.
Each of the subsequent $m$ lines provides two integers $u$ and $v$ ($1 \le u, v \le n$) indicating that a monitor oversees the valves with these indices.

## Output
If it is impossible to satisfy all safety protocols simultaneously, output a single line containing NO.
If a valid configuration is possible, print YES on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (each being either 1 or 2) that denote the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
