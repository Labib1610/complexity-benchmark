**Solution Explanation**

For every sensor the two connected valves must have different pressure levels.
Therefore we have to 2‑colour the undirected graph whose vertices are the valves
and whose edges are the sensors.

* a colour `0` corresponds to pressure `1`
* a colour `1` corresponds to pressure `2`

The graph must be **bipartite**.  
If it is not bipartite no assignment is possible.

For a bipartite connected component there are exactly two possible assignments:
the colours can be kept or all of them can be flipped.
We have to choose the orientation that yields the lexicographically smallest
whole sequence `p1 … pn`.

--------------------------------------------------------------------

#### Greedy choice for the lexicographically smallest assignment  

Process the valves in increasing order `1 … n`.

*When we meet the first vertex of a component* its colour (`0` or `1`) is already
fixed by BFS.  
We may decide whether colour `0` or colour `1` becomes pressure `1`.
Choosing the colour of this first vertex to become `1` makes the current
position as small as possible, and later positions cannot influence it.
Hence this greedy choice is optimal.

Consequences  

* the smallest index of a component is forced to pressure `1`
* all other vertices of the same component obtain their pressures uniquely
  (the opposite colour becomes pressure `2`).

--------------------------------------------------------------------

#### Algorithm
```
read n , m
build adjacency list

col[v] = -1 for all v                # provisional colour (0/1)
comp[v] = -1                         # component id
orientation[comp] = -1              # which colour of this component is pressure 1
components = 0

# 1. check bipartiteness and colour each component
for every vertex v:
    if col[v] == -1:
        start BFS from v
        col[v] = 0 , comp[v] = components
        while queue not empty:
            u = pop
            for each neighbour w of u:
                if col[w] == -1:
                    col[w] = 1 - col[u]
                    comp[w] = components
                    push w
                elif col[w] == col[u]:
                    print "NO" and exit          # not bipartite
        components += 1

# 2. construct lexicographically smallest assignment
answer = array of size n
for i = 0 … n‑1 (valve i+1):
    c = comp[i]
    if orientation[c] == -1:                # first vertex of its component
        orientation[c] = col[i]             # make this colour become pressure 1
    answer[i] = 1 if col[i] == orientation[c] else 2

print "YES"
print answer
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `"NO"` iff no valid assignment exists,
otherwise it prints `"YES"` and the lexicographically smallest valid assignment.

---

##### Lemma 1  
If the algorithm prints `"NO"` then the graph is not bipartite, therefore
no assignment satisfying all sensors exists.

**Proof.**  
`"NO"` is printed only when during BFS an edge connects two vertices with the
same provisional colour. That is exactly a violation of the bipartite condition.
If a graph is not bipartite it contains an odd cycle, which forces two adjacent
vertices to have equal pressure – impossible because the sensor requires different
pressures. ∎



##### Lemma 2  
If the graph is bipartite the algorithm never prints `"NO"`.

**Proof.**  
In a bipartite graph a proper 2‑colouring exists.  
The BFS always assigns the opposite colour to a neighbour,
therefore it never meets an edge whose endpoints already have the same colour.
Thus the conflict test never triggers. ∎



##### Lemma 3  
Assume the graph is bipartite.
For each connected component `C` the algorithm assigns pressures
exactly one of the two possible valid colour‑to‑pressure mappings
(and both possibilities are feasible).

**Proof.**  
BFS fixes a provisional colour `col[v] ∈ {0,1}` for every vertex of `C`.
All edges connect vertices of different colours, so both mappings

* colour 0 → pressure 1, colour 1 → pressure 2
* colour 0 → pressure 2, colour 1 → pressure 1  

produce a valid assignment for `C`.  
The algorithm stores `orientation[C]` = the colour that shall become pressure 1,
hence it selects precisely one of those two mappings. ∎



##### Lemma 4 (Greedy optimality)  
Let the vertices be processed in increasing order.
When the algorithm meets the first vertex `v` of a component `C`,
choosing `orientation[C] = col[v]` (i.e. making `v` pressure 1)
produces a lexicographically smallest overall assignment among all
valid assignments.

**Proof.**  
All vertices with index `< v` belong to other components, already fixed.
The current position `v` is the first index where assignments can still differ.
Any valid assignment must give either pressure 1 or pressure 2 to `v`,
and both are attainable (by the two possible orientations of `C`).
Choosing pressure 1 is strictly smaller than pressure 2 and cannot be
undone by later choices, because later vertices have larger indices.
Therefore any assignment with pressure 2 at `v` is lexicographically larger,
so the greedy choice is optimal. ∎



##### Lemma 5  
After processing all vertices, the array `answer` produced by the algorithm
is the lexicographically smallest valid assignment.

**Proof.**  
Consider the first index `i` where `answer` could differ from any other valid
assignment `B`.  
`i` belongs to some component `C`.  
When the algorithm processed `i`, it was the first vertex of `C`,
so by Lemma&nbsp;4 it set pressure 1 there, which is the minimal possible value.
Thus `B_i` cannot be smaller than `answer_i`.  
If `B_i` were equal, the first differing index would be later, contradicting the
choice of `i`. Hence no valid assignment is lexicographically smaller than
`answer`. ∎



##### Lemma 6  
If the graph is bipartite, the algorithm outputs a valid assignment.

**Proof.**  
By Lemma&nbsp;3 each component receives a consistent colour‑to‑pressure mapping,
and every edge of the component connects vertices of opposite colours,
hence opposite pressures. All sensors are satisfied, so the whole assignment
is valid. ∎



##### Theorem  
The algorithm prints  

* `"NO"` **iff** no assignment satisfying all sensors exists;  
* otherwise `"YES"` followed by the lexicographically smallest such assignment.

**Proof.**  

*If the algorithm prints `"NO"`* – by Lemma&nbsp;1 no assignment exists.  

*If a valid assignment exists* – the graph is bipartite, therefore BFS never
fails (Lemma&nbsp;2). The algorithm prints `"YES"` and, by Lemma&nbsp;6,
produces a valid assignment. Lemma&nbsp;5 shows this assignment is the
lexicographically smallest possible. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list* – `O(n + m)` memory and time.  
*BFS over all components* – each vertex and edge examined once: `O(n + m)`.  
*Final pass to build the answer* – `O(n)`.  

Total time `O(n + m)` ≤ `4·10⁵`, well below the limit.  
Memory consumption `O(n + m)` (adjacency list, a few integer arrays).

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    col = [-1] * n            # provisional colour 0/1
    comp = [-1] * n           # component id
    comp_cnt = 0

    # BFS for bipartiteness and colouring
    for start in range(n):
        if col[start] != -1:
            continue
        dq = deque([start])
        col[start] = 0
        comp[start] = comp_cnt
        while dq:
            u = dq.popleft()
            cu = col[u]
            for w in adj[u]:
                if col[w] == -1:
                    col[w] = 1 - cu
                    comp[w] = comp_cnt
                    dq.append(w)
                elif col[w] == cu:
                    # not bipartite
                    sys.stdout.write("NO")
                    return
        comp_cnt += 1

    orientation = [-1] * comp_cnt   # which colour (0/1) becomes pressure 1
    ans = [0] * n

    for i in range(n):
        cid = comp[i]
        if orientation[cid] == -1:
            orientation[cid] = col[i]          # make this colour = 1
        ans[i] = 1 if col[i] == orientation[cid] else 2

    out = ["YES", " ".join(map(str, ans))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
