**Solution Explanation**

For every monitor we have an edge `(u , v)` and the condition  

```
state[u] + state[v] = 3 ,   state[i] ∈ {1,2}
```

Therefore the two ends of an edge must receive *different* values
(`1` opposite to `2`).  
The whole graph has to be **bipartite**.  
If it is not bipartite there is no assignment – answer `NO`.

If the graph is bipartite, each connected component has exactly two
possible assignments: we may give value `1` to the left colour class and
`2` to the right one, or we may swap them.
We have to choose the orientation that yields the lexicographically
smallest whole sequence `s1 … sn`.

--------------------------------------------------------------------

#### Lemma  
In a bipartite component the lexicographically smallest assignment is
obtained by giving value `1` to the vertex with the smallest index inside
the component (and consequently to its colour class).

*Proof.*  
All vertices of the component are forced to have the same relative
ordering: either colour‑0 = `1` and colour‑1 = `2`, or the opposite.
Let `p` be the smallest index of the component.
If we give `p` the value `2`, the whole sequence is larger at position `p`
than any assignment that gives `p` the value `1`.  
Thus the optimal orientation is the one that puts `1` on `p`. ∎



--------------------------------------------------------------------

#### Algorithm
```
read n , m
build adjacency list
colour[1…n] = -1          # -1 = unvisited, 0/1 = two sides
answer[1…n] = 0

for each vertex v = 1 … n
    if colour[v] == -1
        # start new component
        queue ← [v]; colour[v] = 0
        component_vertices = []
        while queue not empty
            x = pop
            component_vertices.append(x)
            for each neighbour y of x
                if colour[y] == -1
                    colour[y] = colour[x] ^ 1
                    push y
                else if colour[y] == colour[x]
                    print "NO" and exit   # not bipartite
        # orientation of this component
        p = min(component_vertices)          # smallest index
        if colour[p] == 0:   # colour 0 should become 1
            for u in component_vertices:
                answer[u] = 1 if colour[u]==0 else 2
        else:                # colour 1 should become 1
            for u in component_vertices:
                answer[u] = 1 if colour[u]==1 else 2

print "YES"
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` iff no feasible assignment exists,
otherwise prints `YES` and the lexicographically smallest feasible
assignment.

---

##### Lemma 1  
If the algorithm prints `NO`, the instance has no feasible assignment.

*Proof.*  
`NO` is printed only when during BFS an edge `(x,y)` with
`colour[x] == colour[y]` is found. That means the graph contains an odd
cycle, i.e. it is not bipartite. Any feasible assignment would have to give
different values to the two ends of every edge, which is impossible on an
odd cycle. Hence no assignment exists. ∎



##### Lemma 2  
If the algorithm finishes without printing `NO`, the produced `answer`
satisfies all monitors.

*Proof.*  
For every edge `(u,v)` the BFS assigned opposite colours, because otherwise
the algorithm would have stopped earlier (Lemma 1).  
In the final step each component is oriented consistently:
all vertices of colour `c` receive the same value (`1`), the opposite colour
receives `2`. Therefore `answer[u] ≠ answer[v]` and
`answer[u] + answer[v] = 1 + 2 = 3`. ∎



##### Lemma 3  
For each connected component the algorithm assigns the lexicographically
smallest possible values among all feasible assignments of that component.

*Proof.*  
By Lemma the orientation is chosen so that the smallest index `p` of the
component receives value `1`. Any feasible assignment of the component must
give the same value to all vertices of the colour class of `p`. If `p`
received `2`, the whole sequence would be larger at position `p`. Hence the
algorithm’s choice is optimal for the component. ∎



##### Lemma 4  
The whole sequence `answer[1…n]` is lexicographically minimal among all
feasible global assignments.

*Proof.*  
Consider the first position `i` where some feasible assignment `B`
differs from `answer`. Vertex `i` belongs to a certain component `C`.
All vertices with index `< i` are identical in both assignments, therefore
the orientation of `C` in `answer` is already fixed by the algorithm.
By Lemma 3 the orientation chosen by the algorithm gives the smallest
possible value to the smallest index of `C`, which is exactly `i`.  
Thus `answer[i] = 1` and any other feasible assignment must have `B[i] = 2`,
so `answer` is lexicographically smaller. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff the instance has no feasible assignment;  
* otherwise `YES` and the lexicographically smallest feasible assignment.

*Proof.*  
If the algorithm prints `NO`, by Lemma 1 no assignment exists.
If it does not print `NO`, Lemma 2 guarantees the produced assignment is
feasible, and Lemma 4 shows it is the lexicographically smallest one.
Conversely, if a feasible assignment exists the graph is bipartite, so the
algorithm never encounters a colour conflict and therefore does not print
`NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all vertices*: each vertex and edge is processed once → `O(n + m)`.  
*Additional loops over component vertices*: total `O(n)`.  

Overall time `O(n + m)` ≤ `4·10⁵`, well inside the limit.  
Memory consumption `O(n + m)` for adjacency list, colours and answer.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 unvisited, 0/1 two sides
    ans = [0] * (n + 1)

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp = []
        while q:
            x = q.popleft()
            comp.append(x)
            for y in adj[x]:
                if colour[y] == -1:
                    colour[y] = colour[x] ^ 1
                    q.append(y)
                elif colour[y] == colour[x]:
                    sys.stdout.write("NO")
                    return
        # orientation: smallest index gets value 1
        p = min(comp)
        if colour[p] == 0:
            for v in comp:
                ans[v] = 1 if colour[v] == 0 else 2
        else:
            for v in comp:
                ans[v] = 1 if colour[v] == 1 else 2

    out = ["YES", " ".join(str(ans[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
