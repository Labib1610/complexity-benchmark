# Problem B — Network Configuration

Time limit: 1 s   Memory limit: 256 MB

You are configuring a network of $n$ modules. Each module $i$ must be assigned a configuration state $s_i \in \{1, 2\}$.

The modules process data payloads structured as a $2 \times 2$ matrix of four quadrants: Top-Left, Top-Right, Bottom-Left, and Bottom-Right.
- State 1 configures the module to swap the quadrants within each row. (The Top-Left quadrant swaps with the Top-Right, and the Bottom-Left swaps with the Bottom-Right).
- State 2 configures the module to swap the quadrants within each column. (The Top-Left quadrant swaps with the Bottom-Left, and the Top-Right swaps with the Bottom-Right).

The system log contains $m$ active connections. Each connection links two modules $u$ and $v$. 
When a connection is active, data is transformed by the operations assigned to both modules. To ensure safe data transfer, the combined application of these two operations must not leave any data quadrant in its starting position. That is, for every quadrant (Top-Left, Top-Right, Bottom-Left, and Bottom-Right), its final position in the matrix after passing through both modules must be strictly different from its initial position.

If there are multiple valid state assignments that satisfy all logged connections, you must output the sequence $s_1 \dots s_n$ that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) representing a logged connection between these two modules.

## Output
If no such assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$) representing the elements of the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
