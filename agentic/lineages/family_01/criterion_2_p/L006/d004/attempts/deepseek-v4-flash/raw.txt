We can model each equation as:

For row \( j \) with pair \((u, v)\):
\[
s_u + s_v = 3
\]
Since \( s_i \in \{1, 2\} \), this means \( s_u \) and \( s_v \) must be different.

So the problem reduces to:  
We have a graph with \( n \) vertices and \( m \) edges. Each edge \((u, v)\) means \( s_u \neq s_v \).  
We need to assign 1 or 2 to each vertex such that adjacent vertices have different values.  
This is exactly a bipartite graph check, and if possible, we want the lexicographically smallest assignment (1 before 2).

We can solve with BFS/DFS coloring, trying to assign 1 whenever possible.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    print(" ".join(str(color[i]) for i in range(n)))
```
