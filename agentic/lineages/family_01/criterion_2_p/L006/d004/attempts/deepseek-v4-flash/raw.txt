 We need to assign values 1 or 2 to each node such that for every edge (u, v), the XOR of their values is 3.  
Since 1 XOR 2 = 3, this means every connected pair must have different values.  
So the problem reduces to checking if the graph is bipartite, and if so, output the lexicographically smallest coloring.

We can solve it with BFS/DFS, assigning colors 1 and 2, and for lexicographically smallest, we try to assign 1 whenever possible.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start):
    q = deque([start])
    color[start] = 1
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 3 - color[u]  # 1 <-> 2
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        if not bfs(i):
            print("NO")
            sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
