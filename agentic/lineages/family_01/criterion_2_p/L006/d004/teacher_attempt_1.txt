# Fragrance Formulation

Time limit: 1 s   Memory limit: 256 MB

A master perfumer is formulating a new fragrance from a collection of essential extracts. The laboratory's main centrifuge has 200,000 slots, meaning a batch consists of $n$ extracts where $n$ is between 1 and this total capacity. The extracts are labeled sequentially starting from 1. 

The perfumer has identified a set of volatile interactions between certain pairs of extracts. The interaction database allocates memory for up to 200,000 records, so the number of interactions $m$ will be between 0 and this memory limit.

To prevent degradation, each extract must be stabilized by adding an acidity regulator. The dispensing equipment is calibrated to provide a dose of either 1 ml or 2 ml to each extract. Crucially, if a volatile interaction exists between two extracts, their combined regulator dosage must equal exactly 3 ml to maintain chemical equilibrium.

You need to determine if there is a valid dosage assignment for all extracts in the batch. When multiple valid dosage assignments exist, they are compared by concatenating the dosage amounts $f_1, f_2, \dots, f_n$ into a single $n$-digit integer (where each $f_i \in \{1, 2\}$). You must find the assignment that results in the smallest possible integer. If no valid assignment can be found, the batch is ruined.

## Input
The first line provides the two integers $n$ and $m$, representing the batch size and the number of recorded interactions, bounded by the physical limits of the centrifuge and database.
The next $m$ lines each contain two integers $u$ and $v$ — a pair of extracts that have a volatile interaction.

## Output
If no valid dosage assignment exists, output a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $f_1, f_2, \dots, f_n$ (where each $f_i \in \{1, 2\}$) representing the dosage assigned to each extract in the valid configuration that minimizes the $n$-digit integer described above.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Replaced the direct inequality bounds with physical limits (centrifuge slots and database memory) that imply the exact same values. Removed the explicit "must be different" wording that triggered bipartiteness matching, replacing it with an equivalent algebraic constraint (the sum of the 1 or 2 ml doses must equal 3 ml) to force the model to deduce the mutual exclusion requirement.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic requirement that two variables from the set {1, 2} sum to 3 is mathematically identical to requiring that their values be different, so all valid assignments and the tie-breaking rule remain exactly the same.
</PRESERVED_ANSWER>
