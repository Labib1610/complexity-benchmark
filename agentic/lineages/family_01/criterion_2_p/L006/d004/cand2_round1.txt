<STATEMENT>
# Non-Singular Routing

Time limit: 1 s   Memory limit: 256 MB

A computational grid consists of $n$ processing nodes, numbered $1$ through $n$. You must assign a configuration parameter $p_i$ to each node. Hardware constraints require that every $p_i$ must be set to either $1$ or $2$.

The network's reliability is tested across $m$ bidirectional data links. Each link connects a specific pair of nodes, $u$ and $v$. For the link to successfully route packets, the $2 \times 2$ routing matrix $M$ associated with the link must be non-singular (invertible). The matrix for the link between node $u$ and node $v$ is defined as:

$$
M = \begin{pmatrix} p_u & p_v \\ p_v & p_u \end{pmatrix}
$$

A matrix is non-singular if and only if its determinant is not equal to zero. If the determinant is exactly zero, the link fails to route data.

Your task is to assign a parameter $p_i$ to each of the $n$ nodes so that all $m$ data links are functional. If multiple valid assignments are possible, you must output the lexicographically smallest one (assigning parameter $1$ to lower-numbered nodes whenever possible). If no such assignment is possible, you must report that it cannot be done.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$, representing the indices of a pair of nodes connected by a data link.

## Output
If it is impossible to configure the nodes to satisfy all links, output a single line with `NO`.
If it is possible, output `YES` on the first line. On the second line, output $n$ integers $p_1 \dots p_n$ (where each $p_i \in \{1,2\}$) giving the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit condition that the values must "exactly match 3" has been replaced with a linear algebra constraint requiring a 2x2 matrix to be non-singular. To solve this, the model must evaluate the determinant ($p_u^2 - p_v^2$) and deduce that over the domain {1, 2}, a non-zero determinant strictly implies $p_u \neq p_v$. This forces symbolic reasoning before the underlying bipartite structure can be recognized.
</RATIONALE>
<PRESERVED_ANSWER>
The determinant of the matrix is $p_u^2 - p_v^2$; since $p_i \in \{1, 2\}$, this determinant is zero if and only if $p_u = p_v$, meaning the non-singular condition perfectly enforces that connected nodes have different values, exactly like the seed's sum constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest valid 2-coloring of a graph, which is solvable in O(n+m) time using Breadth-First Search.
</PRESERVED_CLASS>
