<METHOD_DESCRIPTION>
Replaces the direct inequality constraint with an algebraic property of a quadratic function parameterized by the two satellite states. By requiring the parabola I(x) = (x - s_u)(x - s_v) to have its global minimum at x = 1.5, we mathematically force (s_u + s_v)/2 = 1.5, which simplifies to s_u + s_v = 3. Given s_i in {1, 2}, this strictly requires s_u != s_v. This forces the model to perform algebraic deduction before it can recognize the underlying 2-coloring structure, defeating models that rely on keyword-based pattern matching to trigger graph algorithms.
</METHOD_DESCRIPTION>

<STATEMENT>
# Orbital Resonance

Time limit: 1 s
Memory limit: 256 MB

A deep space communications network consists of $n$ relay satellites, numbered 1 through $n$. Within this network, there are $m$ known proximity hazards. Each hazard involves a specific pair of satellites that are physically too close to one another.

To stabilize the network, every satellite $i$ must be assigned a tuning parameter $s_i \in \{1, 2\}$. 

When a signal passes between two satellites $u$ and $v$ involved in a proximity hazard, it generates an interference profile modeled by the quadratic function:
$I(x) = (x - s_u)(x - s_v)$
where $x$ is the continuous signal frequency. 

For the network to be safe, the assignments must satisfy a strict interference rule: for every listed hazard pair $(u, v)$, their resulting interference profile $I(x)$ must achieve its global minimum at exactly $x = 1.5$.

Your task is to determine if there is a valid configuration of tuning parameters for all $n$ satellites that prevents any system-wide failures. If such a configuration is possible, you must output it. 

Among all valid assignments $s_1, s_2, \dots, s_n$, output the lexicographically smallest sequence. (A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index $i$ where they differ, $A_i < B_i$).

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a proximity hazard between satellite $u$ and satellite $v$.

## Output
If no safe configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being either 1 or 2), representing the tuning parameter assigned to each satellite from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit `s_u != s_v` requirement was removed. It is replaced by the condition that the quadratic function `(x - s_u)(x - s_v)` reaches its global minimum at `x = 1.5`. To solve the problem optimally, the model must deduce that the vertex of this parabola is at `(s_u + s_v)/2`, meaning `s_u + s_v = 3`, which for values in `{1, 2}` is equivalent to `s_u != s_v`. This forces an intermediate algebraic reasoning step before the bipartiteness structure becomes visible.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that `(x - s_u)(x - s_v)` has a minimum at 1.5 is mathematically identical to `s_u != s_v` for `s_i \in \{1, 2\}`, meaning the set of valid configurations is exactly the same as in the seed problem.
</PRESERVED_ANSWER>

The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in O(n+m) time using BFS/DFS, keeping it in P.
</PRESERVED_CLASS>
