<STATEMENT>
# Orbital Resonance

Time limit: 1 s
Memory limit: 256 MB

A deep space communications network consists of $n$ relay satellites, numbered 1 through $n$. Within this network, there are $m$ known proximity hazards. Each hazard involves a specific pair of satellites that are physically too close to one another.

To stabilize the network, every satellite $i$ must be assigned a tuning parameter $s_i \in \{1, 2\}$. 

For the network to be safe, the assignments must satisfy a strict global resonance condition. For each of the $m$ listed hazard pairs $(u, v)$, we define its interference weight as $s_u^2 + s_v^2$. The entire network configuration is considered safe if and only if the product of the interference weights across all $m$ hazards is exactly $5^m$. (If $m=0$, the network is safe by default).

Your task is to determine if there is a valid configuration of tuning parameters for all $n$ satellites that prevents any system-wide failures. If such a configuration is possible, you must output it. 

Among all valid assignments $s_1, s_2, \dots, s_n$, output the lexicographically smallest sequence. (A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index $i$ where they differ, $A_i < B_i$).

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a proximity hazard between satellite $u$ and satellite $v$.

## Output
If no safe configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being either 1 or 2), representing the tuning parameter assigned to each satellite from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the direct local inequality constraint ($s_u \neq s_v$) with a global product condition over all edges: $\prod (s_u^2 + s_v^2) = 5^m$. This forces models to use prime factorization logic to deduce that every individual edge must have a weight of exactly 5, which in turn means $s_u \neq s_v$, effectively hiding the bipartite graph coloring cue.
</RATIONALE>
<PRESERVED_ANSWER>
Since $s_i \in \{1, 2\}$, the terms $s_u^2 + s_v^2$ can only take the values 2, 5, or 8; by unique prime factorization, their product is $5^m$ if and only if every term is exactly 5, which precisely enforces $s_u \neq s_v$ for all hazards just like the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains mathematically identical to finding the lexicographically smallest 2-coloring of a graph, which is solvable in O(n + m) time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the global product as requiring literal large-integer arithmetic and fail due to perceived computational limits rather than logic flaws, though the constraints ($m \le 2\cdot 10^5$) should make it clear to a reasoning engine that a mathematical simplification is intended.
</RISK>
