# Problem B — Power Asymmetry

Time limit: 1 s
Memory limit: 256 MB

You are deploying a network of sensor nodes. The hardware supports a maximum capacity of $200,000$ nodes, and there is always at least one node present. The nodes are identified by integer IDs starting from $1$ up to the total number of deployed nodes. Within this network, there are mutual interference zones, each affecting a specific pair of nodes. The network can have as few as zero such zones, but due to memory limits, the controller tracks at most $200,000$ of them.

Each node must be assigned a discrete power state of either $1$ or $2$. To ensure stable communication, you must adhere to a strict asymmetry rule: for any two nodes sharing a mutual interference zone, their assigned power states must be chosen such that one state is strictly greater than the other.

Your goal is to determine if there is a valid configuration for the entire network. If multiple valid configurations are possible, you must select the one that minimizes the power state of node 1. If there are still multiple valid configurations, you must minimize the power state of node 2, and so forth, proceeding in ascending order of the node IDs.

## Input
The first line provides two integers $n$ and $m$, denoting the number of deployed nodes and the number of mutual interference zones, respectively.
The next $m$ lines each contain two integers $u$ and $v$, indicating that node $u$ and node $v$ share an interference zone.

## Output
If there is no way to configure the network without violating the asymmetry rule, output `NO` on a single line.
If a valid configuration exists, output `YES` on the first line. On the second line, print $n$ space-separated integers $z_1, z_2, \dots, z_n$, where $z_i \in \{1, 2\}$ is the power state for the $i$-th node. If there are multiple valid configurations, output the unique one that satisfies the minimization rule described above.

## Example 1
**Input:**
```
4 4
1 2
2 3
3 4
1 4
```
**Output:**
```
YES
1 2 1 2
```

## Example 2
**Input:**
```
3 3
1 2
1 3
2 3
```
**Output:**
```
NO
```

<RATIONALE>
The problem domain was changed from signal relays with bitwise-AND rules to sensor nodes with an asymmetry rule (one state strictly greater than the other). All bare inequalities were removed from the Input section, moving the numeric bounds into the scenario description as physical and memory capacities (Strategy S07). This forces the model to deduce the $u \neq v$ requirement from the strict inequality condition rather than pattern-matching bitwise operations to bipartite graph coloring, and requires it to parse the text to find the constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that one state must be strictly greater than the other, given that the only available states are 1 and 2, is mathematically identical to requiring that the two states be different, preserving the exact set of valid configurations and the tie-breaking rule.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring of an undirected graph (or determining that none exists) and selecting the lexicographically smallest valid assignment, which is solvable in linear time.
</PRESERVED_CLASS>
