# Problem B — Acoustic Array Calibration

Time limit: 1 s
Memory limit: 256 MB

You are calibrating an underwater acoustic array composed of $n$ hydrophones. Each hydrophone must be assigned a discrete frequency multiplier, which can be either $1$ or $2$.

The array operates in a reverberant environment, which creates $m$ acoustic resonance channels. Each channel strongly couples a specific pair of hydrophones.

To eliminate the resonance, the system requires that for any two hydrophones coupled by a channel, the product of their frequency multipliers must be exactly $2$.

Your task is to determine whether a valid calibration state exists for the entire array. If multiple valid states exist, the system defaults to the state that minimizes the frequency multiplier of hydrophone 1. If ambiguities remain, it minimizes the multiplier of hydrophone 2, and so on, sequentially prioritizing the lowest possible multiplier for hydrophones in ascending index order.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), denoting the number of hydrophones and the number of resonance channels.
The next $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a resonance channel couples hydrophone $u$ and hydrophone $v$.

## Output
If there is no way to assign the multipliers without violating the resonance constraint, output `NO` on a single line.
If a valid assignment exists, output `YES` on the first line. On the second line, print $n$ space-separated integers $z_1, z_2, \dots, z_n$, where $z_i \in \{1, 2\}$ is the frequency multiplier for the $i$-th hydrophone. If there are multiple valid assignments, output the unique one that satisfies the system's default minimization protocol.

## Example 1
**Input:**
```
4 4
1 2
2 3
3 4
1 4
```
**Output:**
```
YES
1 2 1 2
```

## Example 2
**Input:**
```
3 3
1 2
1 3
2 3
```
**Output:**
```
NO
```
