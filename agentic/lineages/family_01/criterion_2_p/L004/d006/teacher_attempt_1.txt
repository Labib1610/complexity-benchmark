# Problem B — Amplification Factors

Time limit: 1 s
Memory limit: 256 MB

You are tasked with tuning a communication grid that contains $n$ signal relays. Within this network, there are $m$ sensitive links, each establishing a connection between a specific pair of relays.

You must assign a discrete amplification factor to every relay in the grid. The hardware restricts this factor to be either $1$ or $2$. To maintain signal integrity, a strict non-interference policy applies: whenever two relays share a sensitive link, the product of their amplification factors must be exactly $2$. 

Your objective is to determine whether a valid grid configuration exists. If more than one valid configuration is possible, you must choose the one that minimizes the amplification factor of relay 1. If ties remain, you must minimize the factor of relay 2, and continue this tie-breaking process in ascending order of the relay identifiers.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of relays and the number of sensitive links, respectively.
Each of the subsequent $m$ lines provides two integers $u$ and $v$ ($1 \le u, v \le n$), specifying that a sensitive link exists between relay $u$ and relay $v$.

## Output
If it is impossible to configure the relays without breaking the non-interference policy, print `NO` on a single line.
If a valid configuration can be achieved, print `YES` on the first line. On the second line, output $n$ space-separated integers $z_1, z_2, \dots, z_n$, where $z_i \in \{1, 2\}$ is the assigned amplification factor for the $i$-th relay. If multiple valid configurations exist, output the single configuration that satisfies the tie-breaking minimization rule.

## Example 1
**Input:**
```
4 4
1 2
2 3
3 4
1 4
```
**Output:**
```
YES
1 2 1 2
```

## Example 2
**Input:**
```
3 3
1 2
1 3
2 3
```
**Output:**
```
NO
```

<RATIONALE>
The previous version used a bitwise AND condition (`factors must equal 0`) which immediately triggered bipartite graph/2-coloring recognition for models, as seen in their traces. I replaced this with the condition that the product of their factors must be exactly 2. Since the only allowed factors are 1 and 2, this mathematically forces the factors to be different (1 and 2), preserving the exact same logic while requiring the model to deduce the mutual exclusion rather than pattern-matching a bitwise operation.
</RATIONALE>
<PRESERVED_ANSWER>
The allowed factors are restricted to {1, 2}, and the only way two such numbers can have a product of 2 is if one is 1 and the other is 2, which perfectly mirrors the original constraint that they cannot be the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) on an undirected graph, keeping it in P and solvable in O(n+m) time using BFS or DFS.
</PRESERVED_CLASS>
