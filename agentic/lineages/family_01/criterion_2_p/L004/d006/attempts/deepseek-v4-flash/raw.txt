We can model this as a graph problem.  

For each edge \((u, v)\):  
- If \(z_u = z_v\), resonance = \(1 + 1 = 2\).  
- If \(z_u \neq z_v\), resonance = \(2 + 0.5 = 2.5\).  

We need total resonance = \(2.5 \times m\), which means **every edge must connect different values** (1 and 2).  
So the graph must be bipartite.  

We can assign values via BFS/DFS coloring.  
To get the lexicographically smallest sequence, we start with node 1 assigned 1, and propagate.  

If the graph is not bipartite, output `NO`.  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
color[0] = 1  # 1 means z=1, 0 means z=2

for start in range(n):
    if color[start] == -1:
        color[start] = 1
        q = deque([start])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
