# Problem B — Amplification Factors

Time limit: 1 s
Memory limit: 256 MB

You are configuring a communication grid consisting of $n$ signal relays. Within this grid, there are $m$ sensitive links, each connecting a specific pair of relays.

Every relay must be configured with a discrete amplification factor, which can only be set to either $1$ or $2$. To ensure signal integrity, you must adhere to a strict non-interference rule: for any two relays joined by a sensitive link, the bitwise AND of their amplification factors must equal $0$.

Your goal is to determine if there is a valid configuration for the entire grid. If multiple valid configurations are possible, you must select the one that minimizes the network's total tuning score. The tuning score is mathematically defined as $\sum_{i=1}^n z_i \cdot 2^{n-i}$, where $z_i$ is the amplification factor assigned to relay $i$. Because this score can be exceptionally large, you do not need to print it; only output the configuration itself.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), denoting the number of relays and the number of sensitive links.
The next $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a sensitive link between relay $u$ and relay $v$.

## Output
If there is no way to configure the grid without violating the non-interference rule, output `NO` on a single line.
If a valid configuration exists, output `YES` on the first line. On the second line, print $n$ space-separated integers $z_1, z_2, \dots, z_n$, where $z_i \in \{1, 2\}$ is the amplification factor for the $i$-th relay. If there are multiple valid configurations, output the unique one that minimizes the tuning score described above.

## Example 1
**Input:**
```
4 4
1 2
2 3
3 4
1 4
```
**Output:**
```
YES
1 2 1 2
```

## Example 2
**Input:**
```
3 3
1 2
1 3
2 3
```
**Output:**
```
NO
```

<RATIONALE>
Removed the explicit instruction to minimize factors sequentially by index (which directly mapped to lexicographical sorting and assigning 1 to the first node of each component in student traces). Replaced it with a mathematical penalty sum weighted by descending powers of 2. This forces the model to mathematically deduce that the sum is strictly dominated by earlier indices, requiring it to rediscover lexicographical minimization rather than relying on surface pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The sum $\sum_{i=1}^n z_i \cdot 2^{n-i}$ is strictly minimized by the lexicographically smallest sequence of $z_i \in \{1, 2\}$, ensuring the exact same tie-breaking behavior and identical outputs for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) with lexicographical tie-breaking, keeping it solvable via BFS/DFS in linear time, so it stays in P.
</PRESERVED_CLASS>
<RISK>
Models might mistakenly attempt to compute the massive score using arbitrary-precision integers or floats instead of recognizing the structural property, though the description explicitly states they only need to output the configuration to mitigate this.
</RISK>
