<STATEMENT>
# Problem B — Zone Isolation

Time limit: 1 s
Memory limit: 256 MB

A data center contains $n$ servers. You must assign a security tier to each server. The only permitted tiers are 1 and 2. 

The system has $m$ active synchronization links. Each link connects a specific pair of servers. To prevent interference, the tiers assigned to any two servers connected by a synchronization link must sum to exactly 3.

Determine if a valid tier assignment exists for all $n$ servers.

## Input
The first line contains two integers $n$ and $m$. Due to hardware capacity and physical space limits, the number of servers $n$ is at least $1$ and at most $2\cdot 10^5$. The number of links $m$ is at least $0$ and at most $2\cdot 10^5$.
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of a pair of servers connected by a synchronization link.

## Output
If no valid tier assignment is possible, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $z_1 \dots z_n$ (where each $z_i \in \{1,2\}$) representing the valid assignment. If multiple valid assignments exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit mention of "different parities" was replaced with the arithmetic requirement that the tiers on connected servers must sum to exactly 3. Since the only allowed tiers are 1 and 2, this enforces the exact same condition (one server must be 1, the other 2) but requires the model to deduce this structural property from the arithmetic constraint rather than matching the "parity" keyword to bipartiteness. The bounds were also rewritten into prose to follow the strategy without dropping the numeric limits.
</RATIONALE>
<PRESERVED_ANSWER>
The answers are identical because the condition that tiers from {1, 2} sum to 3 is mathematically equivalent to the condition that they have different parities.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring (testing for bipartiteness) of a graph, which is in P and solvable in linear time using BFS or DFS.
</PRESERVED_CLASS>
