# Problem B — Frequency Allocation

Time limit: 1 s
Memory limit: 256 MB

A facility contains $n$ compute modules. You must assign an operational frequency channel to each module. The only supported channels are 1 and 2.

The system utilizes $m$ active data exchange interfaces. Each interface bridges a specific pair of modules. To prevent signal interference, the sum of the channels assigned to any two modules bridged by an interface must be exactly 3.

Determine if a valid channel assignment exists for all $n$ modules.

## Input
The first line contains two integers $n$ and $m$. The facility's power infrastructure limits the number of modules $n$ to at most two hundred thousand, and there is always at least one module. The number of interfaces $m$ is constrained by a hardware inventory of two hundred thousand cables; it is possible for a system to operate with zero interfaces or any amount up to the inventory limit.

Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of a pair of modules bridged by an interface.

## Output
If no valid channel assignment is possible, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $z_1 \dots z_n$ (where each $z_i \in \{1,2\}$) representing the valid assignment. If multiple valid assignments exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
