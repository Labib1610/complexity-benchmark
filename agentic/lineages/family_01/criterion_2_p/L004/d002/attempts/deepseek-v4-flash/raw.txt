We can model this as a bipartite graph problem.  
Each relay gets value 1 or 2, and for every edge, the product must be 2, meaning one endpoint must be 1 and the other 2.  
So the graph must be bipartite. If it is, we can assign values by coloring.

To get the lexicographically smallest assignment, we try to assign 1 to as many low-index nodes as possible, using BFS/DFS with a greedy choice.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n  # 0 -> value 1, 1 -> value 2

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(' '.join(str(c + 1) for c in color))
```
