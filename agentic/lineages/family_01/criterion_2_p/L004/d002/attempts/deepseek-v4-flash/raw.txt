We can model this as a bipartite graph problem.  
The condition “product of bands = 2” means one server must have band 1 and the other band 2.  
So the graph must be bipartite.  

We’ll do BFS/DFS coloring, and to get the lexicographically smallest assignment, we try to assign 1 to the smallest-index uncolored node first.  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 0
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
