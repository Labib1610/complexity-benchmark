# Problem B — Conduit Load

Time limit: 1 s
Memory limit: 256 MB

A data center contains $n$ servers. You must configure the load tier for each server. A load tier must be a positive integer whose square does not exceed four.

There are $m$ pairs of servers that share a local conduit. To maintain strict load balancing, the arithmetic mean of the load tiers of the two servers in any such pair must be exactly 1.5.

Assign each server a load tier to satisfy this condition, or report impossibility.

## Input
The data center floor consists of exactly 200 rows, each capable of housing exactly 1000 servers. 

The first line contains two integers $n$ and $m$. The number of servers $n$ is at least 1 and at most the total facility capacity. The number of conduits $m$ is non-negative and is bounded by the same maximum.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of servers sharing a conduit.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise print `YES`, then a second line with $n$ integers $z_1 \dots z_n$, representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
