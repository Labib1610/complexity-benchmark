<STATEMENT>
# Problem B — Zone Isolation

Time limit: 1 s
Memory limit: 256 MB

A data center contains $n$ servers. You must assign a transmission band to each server. The only permitted bands are 1 and 2. 

The system has $m$ active synchronization links. Each link connects a specific pair of servers. For the network to remain stable, the product of the bands assigned to any two servers connected by a synchronization link must be exactly 2.

Determine if a valid band configuration exists for all $n$ servers.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of a pair of servers connected by a synchronization link.

## Output
If no valid band configuration is possible, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $z_1 \dots z_n$ (where each $z_i \in \{1,2\}$) representing the valid assignment. If multiple valid assignments exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Removed the phrase "different parities" which was acting as a direct trigger for bipartite graph coloring templates. Replaced it with the arithmetic constraint that the product of the assigned bands must be exactly 2, which over the domain {1, 2} is mathematically identical but forces the model to deduce the mutual exclusion rather than pattern-matching it.
</RATIONALE>
<PRESERVED_ANSWER>
Because the only permitted values are 1 and 2, the product of two selections is 2 if and only if one is 1 and the other is 2, perfectly preserving the requirement that adjacent servers receive different values.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring of a graph (or determining none exists) and selecting the lexicographically smallest, keeping it in P.
</PRESERVED_CLASS>
