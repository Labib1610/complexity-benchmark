<STATEMENT>
# Problem B — Zone Isolation

Time limit: 1 s
Memory limit: 256 MB

A data center contains $n$ servers. You must assign a transmission band to each server. The only permitted bands are 1 and 2. 

The system has $m$ active synchronization links. Each link connects a specific pair of servers. For the network to remain stable, the sum of the cubes of the bands assigned to any two servers connected by a synchronization link must be exactly 9.

Determine if a valid band configuration exists for all $n$ servers.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of a pair of servers connected by a synchronization link.

## Output
If no valid band configuration is possible, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $z_1 \dots z_n$ (where each $z_i \in \{1,2\}$) representing the valid assignment. If multiple valid assignments exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The observed shortcut relied on models immediately recognizing "product is exactly 2" over the domain {1,2} as a bipartite coloring condition. I replaced this local link rule with an equivalent polynomial constraint ($z_u^3 + z_v^3 = 9$). Because the domain is restricted to {1,2}, this mathematically enforces $z_u \neq z_v$ just as before, forcing models to evaluate the domain rather than pattern-matching the text. (The prompt's suggestion to add a global sum constraint was discarded because it would alter the validity of some inputs like `1 0`, violating the Identical Answers constraint.)
</RATIONALE>
<PRESERVED_ANSWER>
The condition $z_u^3 + z_v^3 = 9$ for variables restricted to $\{1,2\}$ is satisfied only by the pairs (1,2) and (2,1), making it strictly equivalent to the original product condition $z_u z_v = 2$.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in O(n+m) time using BFS.
</PRESERVED_CLASS>
