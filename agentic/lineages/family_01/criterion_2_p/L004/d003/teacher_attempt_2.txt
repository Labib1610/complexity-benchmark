# Problem B — Configuration Tiers

Time limit: 1 s
Memory limit: 256 MB

You are configuring a network of $n$ signal relays. You must assign each relay a configuration tier, choosing between tier 1 and tier 2.

The network contains $m$ critical links, each connecting a pair of relays. To prevent signal distortion, the tier assignments across any critical link must be strictly regulated. Specifically, the configuration of the two relays sharing a critical link must consist of exactly one relay at tier 1 and one relay at tier 2.

Determine if it is possible to assign a configuration tier to every relay such that all critical link constraints are satisfied.

## Input
The first line contains two integers $n$ and $m$. The physical infrastructure requires at least a single relay to be present, and has a strict capacity limit of two hundred thousand relays. The number of critical links $m$ can range from zero up to a maximum of two hundred thousand links.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of relays connected by a critical link.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $z_1 \dots z_n$ (where each $z_i \in \{1, 2\}$) representing the configuration tiers for relays $1$ through $n$. If there are multiple valid assignments, output the one that is lexicographically smallest.

## Example 1
**Input:**
```
4 4
1 2
2 3
3 4
1 4
```
**Output:**
```
YES
1 2 1 2
```

## Example 2
**Input:**
```
3 3
1 2
1 3
2 3
```
**Output:**
```
NO
```
