<STATEMENT>
# Orbital Resonance

Time limit: 1 s
Memory limit: 256 MB

A deep space communications network consists of $n$ relay satellites, numbered 1 through $n$. Within this network, there are $m$ known proximity hazards. Each hazard involves a specific pair of satellites that are physically too close to one another.

Every satellite in the network must be assigned a tuning parameter, which is an integer chosen from $\{1, 2\}$. Whenever two satellites are involved in a proximity hazard, their tuning parameters must satisfy a specific resonance equation to maintain orbital equilibrium. Specifically, if the two satellites are assigned parameters $x$ and $y$, the expression $x^3 + y^3 + (x \cdot y)^2$ must equal exactly 13. If this expression evaluates to any other value, their resonance will cause a system-wide failure.

Your task is to determine if there is a valid configuration of tuning parameters for all $n$ satellites that prevents any system-wide failures. If such a configuration is possible, you must output it. If there are multiple valid ways to assign the parameters, you must choose the one whose sequence of assignments $s_1, s_2, \dots, s_n$ is lexicographically smallest.

## Input
The first line of input provides the network size: two integers $n$ and $m$. The satellite count $n$ is bounded by a minimum of 1 operational unit and a maximum system capacity of $2\cdot 10^5$. The hazard log $m$ can be completely empty (0) or contain up to the maximum limit of $2\cdot 10^5$ entries.
Each of the next $m$ lines contains two integers $u$ and $v$ — representing a proximity hazard between satellite $u$ and satellite $v$.

## Output
If no safe configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being either 1 or 2), representing the tuning parameter assigned to each satellite from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The absolute difference condition $|a^3 - b^3| = 7$ was a direct giveaway for the inequality constraint $a \ne b$ over the domain $\{1, 2\}$. I replaced it with the algebraically equivalent but structurally obfuscated equation $x^3 + y^3 + (x \cdot y)^2 = 13$. This forces the model to actually evaluate the equation over the permitted domain to deduce the underlying 2-coloring requirement, rather than pattern-matching the difference constraint. The numeric bounds were also rephrased as system capacities to satisfy the S07 strategy while retaining exact values.
</RATIONALE>
<PRESERVED_ANSWER>
The equation $x^3 + y^3 + (x \cdot y)^2 = 13$ evaluates to 13 if and only if one parameter is 1 and the other is 2, perfectly preserving the requirement that adjacent nodes must have different assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem remains identical to finding the lexicographically smallest 2-coloring of a graph, which is solvable in $O(n + m)$ time using BFS or DFS.
</PRESERVED_CLASS>
