# Problem B — Vertical Separation

Time limit: 1 s
Memory limit: 256 MB

You are managing a fleet of $n$ autonomous drones. You must assign each drone a cruising altitude level of exactly 1 or 2.

The designated routes contain $m$ intersection points. Each intersection is shared by a specific pair of drones. To guarantee safe vertical separation during flight, the two drones meeting at any intersection must be assigned different altitude levels.

Determine if it is possible to assign an altitude level to every drone such that all intersection constraints are satisfied.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of drones that share an intersection.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $a_1 \dots a_n$ (where each $a_i \in \{1, 2\}$) representing the altitude levels for drones $1$ through $n$. If there are multiple valid assignments, output the one that is lexicographically smallest.

## Example 1
**Input:**
```
4 4
1 2
2 3
3 4
1 4
```
**Output:**
```
YES
1 2 1 2
```

## Example 2
**Input:**
```
3 3
1 2
1 3
2 3
```
**Output:**
```
NO
```
