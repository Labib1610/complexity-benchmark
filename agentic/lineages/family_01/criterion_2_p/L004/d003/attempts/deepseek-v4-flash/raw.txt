We can model this as a bipartite graph problem.  
Each relay must be assigned 1 or 2, and for every edge, one endpoint must be exactly twice the other.  
That means if one is 1, the other must be 2, and vice versa.  
So the graph must be bipartite, and the two partitions correspond to gain levels 1 and 2.

We also need the lexicographically smallest assignment.  
We can do BFS/DFS coloring, always trying to assign 1 first when possible.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    # color 0 -> gain 1, color 1 -> gain 2
    print(' '.join(str(1 if c == 0 else 2) for c in color))
```
