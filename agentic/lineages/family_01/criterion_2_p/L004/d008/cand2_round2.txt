<STATEMENT>
# Orbital Resonance

Time limit: 1 s
Memory limit: 256 MB

A deep space communications network consists of $n$ relay satellites, numbered 1 through $n$. Within this network, there are $m$ known proximity hazards. Each hazard involves a specific pair of satellites that are physically too close to one another.

To stabilize the network, every satellite $i$ must be assigned a tuning parameter $s_i \in \{1, 2\}$. 

When a satellite is involved in one or more hazards, its tuning parameter must harmonize with the satellites it is in conflict with. For each satellite $i$, let $d_i$ be the number of hazards it is involved in. If $d_i > 0$, let $H_i$ be the collection of tuning parameters of the other satellites involved in those $d_i$ hazards (if satellite $i$ has multiple hazards with the same satellite, that satellite's parameter appears multiple times in $H_i$).

We define the local resonance average $A_i$ as the arithmetic mean of the values in $H_i$:
$A_i = \frac{1}{d_i} \sum_{v \in H_i} v$

For the network to be safe, every satellite $i$ that is involved in at least one hazard must satisfy the resonance equation:
$A_i + s_i = 3$

Your task is to determine if there is a valid configuration of tuning parameters for all $n$ satellites that achieves this safe state. If such a configuration is possible, you must output it. 

Among all valid assignments $s_1, s_2, \dots, s_n$, output the lexicographically smallest sequence. (A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index $i$ where they differ, $A_i < B_i$).

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a proximity hazard between satellite $u$ and satellite $v$.

## Output
If no safe configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being either 1 or 2), representing the tuning parameter assigned to each satellite from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the global sum of interference vectors with a local average condition. For each satellite, the arithmetic mean of its neighbors' tuning parameters plus its own parameter must equal 3. Since parameters are restricted to {1, 2}, this mathematically forces every neighbor to have the opposite parameter, but models relying on surface pattern matching will likely fail to deduce this discrete bipartiteness property and instead attempt to solve it as a continuous linear system or general CSP.
</RATIONALE>
<PRESERVED_ANSWER>
The condition A_i + s_i = 3 with s_i in {1, 2} is satisfied if and only if all elements in H_i exactly equal 3 - s_i, meaning every hazard connects satellites with different tuning parameters, which is logically identical to the seed's interference condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring / bipartiteness testing on the hazard graph, which is solvable in O(n+m) time using standard BFS or DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the handling of multiple hazards between the same pair of satellites, though the term "collection" and the parenthetical clarification make it rigorous.
</RISK>
<METHOD_NAME>
Local Extremal Average Constraint
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces a global sum that trivially bounds edge contributions with a local arithmetic mean constraint. The mean of neighbors' values must equal the exact opposite of the vertex's value. Due to the restricted domain {1, 2}, this forces proper 2-coloring, but hides the discrete graph property behind continuous-looking algebra.
</METHOD_DESCRIPTION>
