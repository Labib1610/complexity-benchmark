**Solution Explanation**

For an edge `{u,v}` the resonance factor is  

```
R = s_u² + s_u·s_v + s_v² ,   s_u , s_v ∈ {1,2}
```

All possible pairs:

| s_u | s_v | R |
|-----|-----|---|
| 1   | 1   | 3 |
| 1   | 2   | 7 |
| 2   | 1   | 7 |
| 2   | 2   | 12|

The required total product is `7^m`.  
Therefore **every edge must contribute exactly `7`**, i.e. its ends must have
different values.  
So the whole graph has to be *bipartite* and we have to colour it with the two
colours `{1,2}` such that adjacent vertices receive different colours.

--------------------------------------------------------------------

#### 1.   Bipartite check and component handling
We run a BFS/DFS over every not‑yet‑visited vertex.

* `col[v] = 0/1` – the parity inside the component.
* While traversing, if we ever see an edge joining two vertices with the same
  parity → the graph is not bipartite → answer `NO`.

During the BFS we also store all vertices of the current component
(`comp` list). After the BFS finishes the component is bipartite.

--------------------------------------------------------------------

#### 2.   Lexicographically smallest assignment
The whole answer is a sequence `s_1 … s_n` with `1 < 2`.  
Consider one connected component.
Let `x` be the smallest index inside this component (the first vertex we meet
while scanning `1 … n`).  
If we could give `s_x = 1` we would obtain a lexicographically smaller whole
sequence than any assignment with `s_x = 2`, because all earlier positions are
identical.

Hence for each component we **force the smallest indexed vertex to obtain
value `1`**.  
All other vertices of the component are forced by the parity:
* if a vertex has the same parity as `x` → also `1`
* otherwise → `2`

Implementation:
```
if col[x] == 0:   # parity 0 corresponds to value 1
        for v in comp:
                ans[v] = 1 if col[v]==0 else 2
else:             # parity 1 corresponds to value 1, swap
        for v in comp:
                ans[v] = 1 if col[v]==1 else 2
```

Processing components in increasing order of their smallest vertex guarantees
the global lexicographically smallest sequence.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `YES` and the lexicographically smallest
valid assignment iff such an assignment exists.

---

##### Lemma 1  
For any edge `{u,v}` the resonance factor equals `7` **iff** `s_u ≠ s_v`.

*Proof.* Direct calculation of the four possible pairs (table above). ∎



##### Lemma 2  
A valid assignment exists **iff** the given graph is bipartite.

*Proof.*  
*If* the graph is bipartite, colour its two parts with `1` and `2`. By Lemma 1
every edge connects different colours, thus each edge contributes `7` and the
total product is `7^m`.  

*Only‑if*: suppose a valid assignment exists. By Lemma 1 every edge connects
different values, therefore the vertices coloured `1` and those coloured `2`
form a bipartition of the graph. ∎



##### Lemma 3  
For a bipartite connected component, among the two possible colourings
(the two ways to map the two sides to `{1,2}`) the one that gives value `1` to
the smallest indexed vertex of the component is lexicographically smaller
than the other.

*Proof.* All vertices with index smaller than that smallest vertex belong to
previous components and are identical in both colourings. At the smallest
vertex the two colourings differ (`1` vs `2`). Since `1 < 2`, the colouring with
`1` is lexicographically smaller. ∎



##### Lemma 4  
The algorithm assigns to every vertex a value `1` or `2` that satisfies all
edges.

*Proof.*  
During BFS we enforce opposite parities for adjacent vertices, therefore the
parity assignment is a proper 2‑colouring of the component. Afterwards we map
parities to `{1,2}` consistently inside the component, so adjacent vertices get
different final values. By Lemma 1 each edge contributes `7`. ∎



##### Lemma 5  
The sequence produced by the algorithm is the lexicographically smallest
among all valid assignments.

*Proof.*  
Consider components ordered by their smallest vertex index (the order the
algorithm processes them). By Lemma 3, for the first component the algorithm
chooses the smallest possible prefix. The choice does not affect later
components because they involve only larger indices. Repeating the argument
inductively over all components shows that no other valid assignment can be
lexicographically smaller. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no valid assignment exists;  
* otherwise `YES` and the lexicographically smallest valid assignment.

*Proof.*  
If the algorithm detects a parity conflict, the graph is not bipartite, and by
Lemma 2 no assignment exists → prints `NO`.  

If the algorithm finishes without conflict, the graph is bipartite, thus a
valid assignment exists (Lemma 2). By Lemma 4 the produced assignment is
valid, and by Lemma 5 it is the lexicographically smallest one. Hence it prints
`YES` and that assignment. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis
*BFS over all vertices and edges*: `O(n + m)` time.  
All auxiliary arrays store `O(n)` integers.  
Memory usage `O(n + m)` (adjacency list). Both satisfy the limits.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    col = [-1] * (n + 1)          # parity 0/1, -1 = unvisited
    ans = [0] * (n + 1)           # final values 1/2

    from collections import deque

    for start in range(1, n + 1):
        if col[start] != -1:
            continue
        # new component
        q = deque([start])
        col[start] = 0
        comp = [start]
        ok = True
        while q:
            v = q.popleft()
            for to in adj[v]:
                if col[to] == -1:
                    col[to] = col[v] ^ 1
                    q.append(to)
                    comp.append(to)
                elif col[to] == col[v]:
                    print("NO")
                    return
        # decide mapping so that smallest index gets value 1
        smallest = min(comp)
        if col[smallest] == 0:
            for v in comp:
                ans[v] = 1 if col[v] == 0 else 2
        else:
            for v in comp:
                ans[v] = 1 if col[v] == 1 else 2

    # all good
    print("YES")
    print(' '.join(str(ans[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
