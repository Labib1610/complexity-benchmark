We need to check if the product of resonance factors equals \(7^m\).  

The resonance factor is:  
\[
R_{u,v} = s_u^2 + s_u s_v + s_v^2
\]  
For \(s_u, s_v \in \{1,2\}\), possible values are:  

- (1,1): \(1+1+1=3\)  
- (1,2) or (2,1): \(1+2+4=7\)  
- (2,2): \(4+4+4=12\)  

We need the product to be exactly \(7^m\).  
That means every edge must have factor 7, i.e., every edge must connect a 1 and a 2.  

So the graph must be bipartite, with the two parts being satellites with value 1 and value 2.  

If the graph is not bipartite, output `NO`.  
If it is bipartite, we assign values 1 and 2 to the two parts.  
For lexicographically smallest, we try to assign 1 to as many early vertices as possible.  

We can do BFS/DFS coloring, but when a vertex is uncolored, we try color 1 first, and if that leads to a conflict, we try color 2.  

Here’s the implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start):
    q = deque([start])
    color[start] = 1
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 3 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        # try color 1 first
        color[i] = 1
        q = deque([i])
        ok = True
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    ok = False
                    break
            if not ok:
                break
        if not ok:
            # try color 2 instead
            color[i] = 2
            q = deque([i])
            ok = True
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = 3 - color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        ok = False
                        break
                if not ok:
                    break
            if not ok:
                print("NO")
                sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
