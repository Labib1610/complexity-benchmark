<STATEMENT>
# Orbital Resonance

Time limit: 1 s
Memory limit: 256 MB

A deep space communications network consists of $n$ relay satellites, numbered 1 through $n$. Within this network, there are $m$ known proximity hazards. Each hazard involves a specific pair of satellites that are physically too close to one another.

To stabilize the network, you must establish a directional calibration link for each hazard. For each hazard between satellite $u$ and satellite $v$, you must designate exactly one of them as the 'source' for that link, and the other as the 'sink'.

A system-wide failure will occur unless every satellite achieves functional uniformity. A satellite is functionally uniform if it acts as a source for all of the hazards it is involved in, or if it acts as a sink for all of the hazards it is involved in.

If a safe configuration of links is possible, every satellite $i$ must be assigned a tuning parameter $s_i$ based on its uniform state:
- If satellite $i$ acts as a source for all its hazards, it is assigned $s_i = 1$. (Note: isolated satellites are not involved in any hazards, so they satisfy this condition and receive $s_i = 1$).
- If satellite $i$ acts as a sink for all its hazards and is involved in at least one hazard, it is assigned $s_i = 2$.

Your task is to determine if there is a valid configuration of links for all $m$ hazards that prevents any system-wide failures. If such a configuration is possible, you must output it. If there are multiple valid ways to assign the parameters, you must choose the one whose sequence of assignments $s_1, s_2, \dots, s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a proximity hazard between satellite $u$ and satellite $v$.

## Output
If no safe configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being either 1 or 2), representing the tuning parameter assigned to each satellite from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The algebraic affordance `|C_i| = d_i` directly mapped to traditional bipartite coloring in the models' training data. By replacing this explicit formula with its exact logical equivalent in natural text ("acts as a source for all... or acts as a sink for all"), models are forced to reason through the implication that endpoints of a hazard must take opposite states, without relying on surface pattern matching of the equation.
</RATIONALE>
<PRESERVED_ANSWER>
The condition to act exclusively as a source or exclusively as a sink for all incident hazards is mathematically identical to the seed's requirement that the absolute net balance equals the degree, guaranteeing the exact same valid assignments and lexicographically smallest result.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing), solvable in O(n+m) time using Breadth-First Search, keeping it firmly in P.
</PRESERVED_CLASS>
