# Problem B — Amplification Factors

Time limit: 1 s
Memory limit: 256 MB

You are tasked with tuning a network of $n$ signal relays. The facility is designed to house up to two hundred thousand relays, and its main conduit can support up to the same number of critical connections. Currently, the system includes $m$ such critical connections, each bridging a pair of relays.

To prevent signal distortion, you must assign a digital gain setting to every relay in the network. The only permitted settings are $1$ and $2$. However, the network must satisfy a strict interference constraint: whenever two relays are joined by a critical connection, the gain setting of one of the joined relays must be exactly double the gain setting of the other.

Your objective is to find a network-wide assignment of gain settings that satisfies this requirement, or to determine that no such assignment is possible.

## Input
The first line contains two integers $n$ and $m$, representing the number of relays and the number of critical connections, respectively. The value of $n$ is at least one, the value of $m$ is at least zero, and neither exceeds the facility's maximum capacities.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), specifying that a critical connection bridges relay $u$ and relay $v$.

## Output
If no valid assignment of gain settings exists, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $z_1, z_2, \dots, z_n$, where each $z_i \in \{1, 2\}$ represents the gain setting for relay $i$. If multiple valid assignments exist, you must output the one that is lexicographically smallest.

## Example 1
**Input:**
```
4 4
1 2
2 3
3 4
1 4
```
**Output:**
```
YES
1 2 1 2
```

## Example 2
**Input:**
```
3 3
1 2
1 3
2 3
```
**Output:**
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the description of the edge constraint from "bitwise AND evaluates to 0" to "one setting must be exactly double the other". Expressed numeric bounds for $n$ and $m$ as physical capacities of the facility rather than bare inequalities. This forces models to deduce that the condition for values $\{1, 2\}$ is equivalent to $z_u \neq z_v$ without relying on bipartite or bitwise operation triggers.
</RATIONALE>
<PRESERVED_ANSWER>
The only permitted values are 1 and 2, and the condition that one value is double the other is satisfied if and only if one is 1 and the other is 2, perfectly mirroring the original bitwise AND constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring of a graph (or determining none exists) and choosing the lexicographically smallest, which is solvable in polynomial time (O(V+E)) using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "the gain setting of one of the relays must be exactly double the gain setting of the other" as allowing continuous values or other integers, but the text explicitly restricts permitted settings to exactly 1 and 2.
</RISK>
