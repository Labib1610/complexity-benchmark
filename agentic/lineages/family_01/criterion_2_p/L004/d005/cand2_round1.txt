<STATEMENT>
# Orbital Resonance

Time limit: 1 s
Memory limit: 256 MB

A deep space communications network consists of $n$ relay satellites, numbered 1 through $n$. The network is built on a 200,000-slot mainframe, meaning $n$ is at least 1 and can use up to all of these slots. Within this network, there are $m$ known proximity hazards. The hazard registry can store a number of hazards up to the exact same 200,000 maximum, or it can be completely empty. Each hazard involves a specific pair of satellites that are physically too close to one another.

To stabilize the network, you must tune the connection for each hazard. Every hazard provides exactly two frequency multipliers: it assigns a multiplier of $1$ to one of its endpoints, and a multiplier of $2$ to its other endpoint.

Let $k_i$ be the total number of frequency multipliers satellite $i$ receives from all hazards. Let $P_i$ be the net frequency multiplier of satellite $i$, calculated as the product of all $k_i$ of these multipliers. For a satellite that receives no multipliers, its net frequency multiplier is defined as $1$.

A system-wide failure will occur unless every satellite $i$ achieves absolute calibration resonance, defined as the condition that $P_i$ is either exactly $1$ or exactly $2^{k_i}$.

If a safe configuration of multipliers is possible, every satellite must be assigned a tuning parameter $s_i$ based on its resonance state:
- If $P_i = 1$, the satellite is assigned $s_i = 1$.
- If $P_i = 2^{k_i}$ and $k_i > 0$, the satellite is assigned $s_i = 2$.

Your task is to determine if there is a valid configuration of multipliers for all $m$ hazards that prevents any system-wide failures. If such a configuration is possible, you must output it. If there are multiple valid ways to assign the parameters, you must choose the one whose sequence of assignments $s_1, s_2, \dots, s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$.
Each of the next $m$ lines contains two integers $u$ and $v$ — a proximity hazard between satellite $u$ and satellite $v$.

## Output
If no safe configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being either 1 or 2), representing the tuning parameter assigned to each satellite from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the node-centric extremal balance condition ($|C_i| = d_i$ with $+1/-1$ contributions) with a mathematically equivalent multiplicative condition ($P_i \in \{1, 2^{k_i}\}$ with $1/2$ multipliers). This hides the graph-theoretic vocabulary and the recognizable bipartite formulation, forcing the model to deduce that the strict product bounds require all incident edges to assign the identical multiplier to a given node. I also applied S07 by moving the numeric bounds for $n$ and $m$ into the descriptive text as physical mainframe capacities.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $P_i \in \{1, 2^{k_i}\}$ is satisfied if and only if all multipliers a node receives are $1$ or all are $2$, which perfectly maps to the original requirement that all incident edges have the same orientation.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains identical to bipartite 2-coloring, solvable in $O(n+m)$ time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret $k_i$ for self-loops, but the wording explicitly defines $k_i$ as the total number of multipliers received (which correctly counts a self-loop twice), avoiding any ambiguity.
</RISK>
