<METHOD_DESCRIPTION>Replaces a logical inequality constraint (x != y for coloring) with an equivalent algebraic equation (x * y = 2 where x, y in {1, 2}). This masks the graph bipartiteness property behind a numerical product rule, forcing models to algebraically deduce the mutual exclusivity rather than pattern-matching graph-coloring keywords.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Microservice Capacity Scaling

Time limit: 1 s
Memory limit: 256 MB

A backend architecture consists of $n$ microservices. You must assign each microservice a replication factor of either 1 or 2.

The system processes $m$ synchronous workflows. Each workflow depends on a specific pair of microservices. The total capacity of a workflow is calculated as the product of the replication factors of the two microservices involved.

To meet strict latency requirements without causing resource contention, every workflow must have a total capacity of exactly 2.

Determine if it is possible to assign a valid replication factor to all $n$ microservices such that all $m$ workflows have a capacity of exactly 2.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of the two microservices that a workflow depends on.

## Output
If no valid assignment is possible, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $z_1 \dots z_n$ (where each $z_i \in \{1,2\}$) representing the valid assignment. If multiple valid assignments exist, output the lexicographically smallest sequence $z_1 \dots z_n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I transformed the problem from assigning categories with a mutual exclusion constraint to assigning numerical factors with a product constraint. By requiring the product of two variables from $\{1, 2\}$ to be exactly 2, it algebraically forces them to be distinct, hiding the bipartiteness property behind arithmetic. This defeats models that rely on keyword pattern-matching for graph coloring.
</RATIONALE>
<PRESERVED_ANSWER>
Since the only allowed values are 1 and 2, their product is exactly 2 if and only if one value is 1 and the other is 2, which perfectly mirrors the original requirement that connected nodes must have different assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains exactly 2-coloring (bipartiteness testing) on an undirected graph, which is solvable in $O(n+m)$ time using BFS or DFS.
</PRESERVED_CLASS>
