We can model this as a bipartite graph problem.  
The condition “bitwise AND equals 0” means that connected relays must have different values (1 and 2).  
So the graph must be bipartite.  

If it is bipartite, we assign 1 to one side and 2 to the other.  
To get the lexicographically smallest assignment, we start with relay 1 set to 1, then BFS/DFS assign alternating values.  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

# color 0 -> 1, color 1 -> 2
res = [1 if c == 0 else 2 for c in color]
print("YES")
print(" ".join(map(str, res)))
```
