# Problem B — Clock Multipliers

Time limit: 1 s
Memory limit: 256 MB

You are configuring the power distribution for a cluster of $n$ processors. The architecture includes $m$ synchronization buses, each directly linking a specific pair of processors.

You must assign a clock multiplier to every processor in the cluster. The hardware only supports two multiplier settings: $1$ and $2$. 

To ensure stable data transfer, every synchronization bus must connect two processors with compatible settings. Specifically, for any two processors linked by a bus, the integer division of their maximum assigned multiplier by their minimum assigned multiplier (discarding any remainder) must evaluate to exactly $2$. 

Your objective is to find a system-wide assignment of clock multipliers that satisfies this requirement for all $m$ buses, or to determine that no such assignment is possible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of processors and the number of synchronization buses, respectively.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), specifying that a synchronization bus links processor $u$ and processor $v$.

## Output
If no valid assignment of clock multipliers exists, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $z_1, z_2, \dots, z_n$, where each $z_i \in \{1, 2\}$ represents the clock multiplier for processor $i$. If multiple valid assignments exist, you must output the one that is lexicographically smallest.

## Example 1
**Input:**
```
4 4
1 2
2 3
3 4
1 4
```
**Output:**
```
YES
1 2 1 2
```

## Example 2
**Input:**
```
3 3
1 2
1 3
2 3
```
**Output:**
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the scenario from signal relays and gain settings to processors and clock multipliers. Replaced the bitwise AND constraint with a relative frequency constraint (integer division of maximum by minimum equals 2), which forces the model to mathematically deduce that linked nodes must have different values rather than relying on the common pattern-matching of bitwise operations to inequality.
</RATIONALE>
<PRESERVED_ANSWER>
The allowed values are still 1 and 2, and the condition `max(a, b) // min(a, b) == 2` holds if and only if one value is 2 and the other is 1, exactly mirroring the original `a & b == 0` constraint, leaving all valid assignments and the lexicographical tie-breaker unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring (bipartite verification) on an undirected graph, which is solvable in O(V+E) time using BFS or DFS.
</PRESERVED_CLASS>
