# Problem B — Power Balancing

Time limit: 1 s   Memory limit: 256 MB

A data center contains $n$ servers. Each server must be assigned a power state, designated by the integer value 1 or 2.

There are $m$ pairs of servers that share a local power bank. To maintain electrical stability, the two servers in any such pair must be assigned power states that sum to an odd number. 

Determine if there is a valid power state assignment for all $n$ servers. If multiple valid assignments exist, you must find the one that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of servers sharing a local power bank.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $z_1 \dots z_n$ (each in {1,2}), the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Removed the vocabulary of "zones" and "interference pairs not sharing a zone", which act as direct keywords for graph coloring. Instead, the problem uses power states of 1 and 2 with an odd-sum constraint, forcing models to deduce that the states must be distinct (parity reasoning) before they can apply a standard bipartite coloring algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
Because the only allowed values are 1 and 2, their sum is odd if and only if one value is 1 and the other is 2, which is mathematically identical to requiring the two servers to have different assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure is still exactly 2-coloring (bipartiteness testing), solvable in O(n+m) time using standard BFS or DFS.
</PRESERVED_CLASS>
