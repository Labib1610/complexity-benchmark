<STATEMENT>
# Telemetry Synchronization

Time limit: 1 s   Memory limit: 256 MB

An orbital satellite network contains $n$ telemetry relays, numbered 1 to $n$. Each relay must be calibrated to operate on one of two available polarizations, denoted as 1 and 2.

Due to intersecting orbital trajectories, $m$ specific pairs of relays will occasionally align. If a pair aligns while operating on the same polarization, they will corrupt each other's signals. You are provided with the list of these $m$ alignment pairs.

Your goal is to determine if there is a valid calibration state for all $n$ relays such that no two relays in an alignment pair use the same polarization. If a valid setup is possible, you must find the one that prioritizes polarization 1 for the lowest-indexed relays. Specifically, among all valid setups, output the one whose sequence of polarizations $p_1, p_2, \dots, p_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of relays that align and therefore cannot share the same polarization.

## Output
If no valid calibration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $p_1 \dots p_n$ (each in $\{1,2\}$), the lexicographically smallest valid calibration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
