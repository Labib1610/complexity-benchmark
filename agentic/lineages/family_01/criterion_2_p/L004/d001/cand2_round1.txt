<STATEMENT>
# Orbital Resonance

Time limit: 1 s
Memory limit: 256 MB

A deep space communications network contains $n$ relay satellites, indexed from 1 to $n$. The network is threatened by $m$ proximity hazards, where each hazard is a pair of satellites situated too close to each other.

To manage interference, every satellite features a phase modulator that must be permanently calibrated to either phase state 1 or phase state 2. Catastrophic resonance will occur across the network unless every pair of satellites implicated in a proximity hazard achieves destructive interference. This safety condition is met if and only if the sum of the phase states assigned to the two hazardous satellites is exactly 3.

You must determine whether a network-wide phase calibration exists that avoids all resonance failures. If a safe calibration is possible, you must provide it. In cases where multiple valid calibrations exist, output the one where the sequence of phase states $s_1, s_2, \dots, s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines provides two integers $u$ and $v$, indicating a proximity hazard between satellite $u$ and satellite $v$.

## Output
If a safe calibration cannot be achieved, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, output $n$ integers $s_1, \dots, s_n$ (each being either 1 or 2), representing the phase state for each satellite from 1 to $n$. If there are multiple valid sequences, provide the lexicographically smallest one.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Changed the explicit prohibition of identical states (which strongly cues "graph coloring" and "bipartite" pattern matching) to an algebraic constraint where the sum of the two states on the domain {1, 2} must be exactly 3. This forces the model to mathematically recognize that the constraint requires the two states to be different, meaning it must derive the 2-coloring reduction itself rather than relying on surface phrasing.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that the sum of two variables from the set {1, 2} equals 3 is logically equivalent to requiring that the two variables take different values, preserving the exact same valid configurations and lexicographical tie-breaking.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring (or identifying an odd cycle) on an undirected graph, which is solvable in O(n+m) time using BFS or DFS.
</PRESERVED_CLASS>
