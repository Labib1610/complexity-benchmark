<STATEMENT>
# Problem B — Equilibrium Configuration

Time limit: 1 s   Memory limit: 256 MB

A data center houses $n$ servers. Each server must be configured with an operation mode that outputs a value of either 1 or 2.

To maintain thermal equilibrium, certain pairs of servers are linked. For every linked pair, the sum of their two output values must be exactly 3. 

The data center must have at least one server, and its physical capacity is capped at 200,000 server bays. The diagnostic logs contain $m$ linked pair records, which can range from zero up to a maximum of 200,000 logged pairs.

You must determine if it is possible to assign a mode to every server such that all equilibrium conditions are satisfied.

## Input
The first line contains $n$ and $m$.
Each of the next $m$ lines contains two integers $u$ and $v$, representing a linked pair of servers.

## Output
If there is no way to assign the modes, output a single line containing NO.
Otherwise, output YES on the first line. On the second line, output $n$ integers (each 1 or 2) representing the assigned mode for servers 1 through $n$. If there are multiple valid assignments, output the one that forms the lexicographically smallest sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the "two zones" and "cannot share a zone" phrasing with an algebraic condition: each server outputs 1 or 2, and linked pairs must sum to 3. This forces the model to deduce that $x+y=3 \implies x \neq y$ before it can recognize the underlying 2-coloring/bipartite structure. Bounds were rewritten into physical capacities (server bays and log limits) to satisfy strategy S07.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that two values from {1, 2} sum to 3 is mathematically identical to requiring that the two values be different, meaning any valid assignment exactly matches a valid 2-coloring from the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in linear time using BFS or DFS, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the bounds description as implying additional constraints on the graph structure or physical layout, though the wording explicitly ties the numbers only to the maximum values of $n$ and $m$.
</RISK>
