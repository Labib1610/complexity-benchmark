**Solution Explanation**

For every satellite we have to choose a number `1` or `2`.
For every hazard `(u , v)` the sum `s_u + s_v` must be odd,
therefore the two satellites have to obtain **different** numbers.
The whole problem is exactly the problem of 2‑colouring a graph
(bipartite graph checking).

If the graph is not bipartite there is no assignment – answer `NO`.

If it is bipartite, each connected component has **exactly two**
valid colourings – they are each other’s complement
(`1 ↔ 2`).  
The global lexicographically smallest assignment is obtained by the
following rule:

*For every connected component give colour `1` to the vertex with the
smallest index belonging to this component.*

Why is this optimal?
Consider the vertices in increasing order `1 … n`.
When we first meet a vertex of a not yet fixed component, all earlier
positions are already minimal.
Choosing the orientation that makes this first vertex `1` is the only
possibility to keep the whole sequence lexicographically smallest.
Later vertices of the same component are forced, later components are
independent, so the rule can be applied component‑wise independently.



--------------------------------------------------------------------

#### Algorithm
```
read n , m
build adjacency list G[1…n]

par[1…n] = -1          # parity of the bipartite colouring, 0 / 1
ans[1…n]  = 0          # final numbers 1 / 2

for v = 1 … n
    if par[v] == -1                      # new component
        BFS/DFS starting from v
            set par[v] = 0
            collect all vertices of this component in list comp
            during search:
                for each edge (x , y)
                    if par[y] == -1   set par[y] = par[x] xor 1
                    else if par[y] == par[x]   # same side -> odd cycle
                        print "NO" and exit

        minv = minimum vertex in comp
        # we want ans[minv] = 1
        if par[minv] == 0               # current parity 0 already gives 1
            for u in comp
                ans[u] = 1 if par[u] == 0 else 2
        else                            # need to invert the mapping
            for u in comp
                ans[u] = 2 if par[u] == 0 else 1

print "YES"
print ans[1] … ans[n] separated by blanks
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise prints `YES` and the lexicographically smallest assignment.

---

##### Lemma 1  
During the BFS/DFS, if an edge `(x , y)` is found with `par[x] = par[y]`,
the graph contains an odd cycle and therefore no assignment satisfies
the condition.

**Proof.**  
All already visited vertices are coloured with parity `0`/`1` such that
adjacent vertices have opposite parity.
If an edge connects two vertices with the same parity, the path inside
the component between `x` and `y` (following tree edges) has even length,
adding the edge `(x , y)` creates an odd cycle.
On an odd cycle a 2‑colouring is impossible. ∎



##### Lemma 2  
If the algorithm finishes the BFS/DFS of a component without violating
Lemma&nbsp;1, the component is bipartite and the array `par` gives a
proper 2‑colouring (parities `0` and `1` are opposite on every edge).

**Proof.**  
The algorithm starts with a vertex coloured `0` and always assigns the
opposite parity to an unvisited neighbour.
Induction on BFS depth shows that any visited vertex receives the parity
equal to the distance from the start modulo 2.
Thus every edge connects vertices of different parity.
Since no conflict of Lemma&nbsp;1 occurred, no odd cycle exists, i.e. the
component is bipartite. ∎



##### Lemma 3  
For a processed component `C` let `c_min` be its smallest index.
The algorithm sets `ans[c_min] = 1` and the whole assignment on `C`
satisfies the edge condition.

**Proof.**  
`par[c_min]` is either `0` or `1`.

*If `par[c_min] = 0`* we map parity `0 → 1`, parity `1 → 2`.  
Then `ans[c_min] = 1`.  

*If `par[c_min] = 1`* we map parity `0 → 2`, parity `1 → 1`.  
Again `ans[c_min] = 1`.  

The mapping is a bijection, therefore two vertices that had different
parities keep different numbers, i.e. every edge still connects different
numbers. ∎



##### Lemma 4  
Let `S` be the sequence produced by the algorithm.
For any other feasible sequence `T` we have `S ≤lex T`.

**Proof.**  
Consider the first index `i` where `S` and `T` differ.
Vertex `i` belongs to some component `C`.  
All vertices `< i` belong to components already processed earlier,
hence `S` and `T` are equal on them.

`i` is the smallest index of component `C` (otherwise a smaller vertex
of `C` would already differ).  
By Lemma&nbsp;3 the algorithm forces `S_i = 1`.  
In any feasible assignment `T`, the two possible colourings of `C` are
exactly the two opposite colourings. One of them gives `T_i = 1`,
the other gives `T_i = 2`.  
Since `S_i = 1`, the only way to have `T_i < S_i` is impossible.
Thus `S_i = 1 ≤ T_i`.  
If `T_i = 1` then `S` and `T` coincide at `i`; otherwise `S_i < T_i`
and `S` is lexicographically smaller. ∎



##### Lemma 5  
If the algorithm prints `YES`, the produced sequence satisfies all
hazard constraints.

**Proof.**  
By Lemma&nbsp;2 every component is bipartite and `par` is a correct parity
colouring.  
Lemma&nbsp;3 shows that the final mapping from parity to `{1,2}` keeps
different colours on the ends of every edge, for every component.
Hence all edges satisfy the required odd sum condition. ∎



##### Theorem  
The algorithm outputs  

* `NO` **iff** no assignment of `1/2` to all satellites satisfies every
  hazard,
* otherwise `YES` followed by the lexicographically smallest valid
  assignment.

**Proof.**  

*If the algorithm outputs `NO`.*  
That happens only when Lemma&nbsp;1 detects an edge whose ends have the
same parity, i.e. an odd cycle. An odd cycle cannot be 2‑coloured, therefore
no assignment exists.

*If a valid assignment exists.*  
The graph is bipartite, so Lemma&nbsp;1 never triggers and the algorithm
finishes all components, printing `YES`. By Lemma&nbsp;5 the produced
assignment is feasible. By Lemma&nbsp;4 it is lexicographically minimal
among all feasible assignments.

Thus the statements hold in both directions. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building the adjacency list*: `O(n + m)` memory and time.  
*BFS/DFS over all vertices and edges*: each vertex and edge processed
once → `O(n + m)` time.  
*Additional work* (finding minimum vertex of a component, filling the
answer) is linear in component size, summed over all components still
`O(n + m)`.

Total time `O(n + m)` ≤ `4·10⁵`, easily under 1 s.  
Memory usage `O(n + m)` ≤ about 3 · 10⁶ integers, well inside 256 MB.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    n = next(it)
    m = next(it)

    g = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = next(it); v = next(it)
        g[u].append(v)
        g[v].append(u)

    parity = [-1] * (n + 1)          # 0 / 1
    ans = [0] * (n + 1)              # final 1 / 2

    for start in range(1, n + 1):
        if parity[start] != -1:
            continue
        # new component
        q = deque([start])
        parity[start] = 0
        comp = []
        while q:
            u = q.popleft()
            comp.append(u)
            pu = parity[u]
            for v in g[u]:
                if parity[v] == -1:
                    parity[v] = pu ^ 1
                    q.append(v)
                elif parity[v] == pu:
                    # not bipartite
                    sys.stdout.write("NO")
                    return
        # decide orientation: smallest index gets colour 1
        minv = min(comp)
        if parity[minv] == 0:
            for v in comp:
                ans[v] = 1 if parity[v] == 0 else 2
        else:
            for v in comp:
                ans[v] = 2 if parity[v] == 0 else 1

    out = ["YES", " ".join(str(ans[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
