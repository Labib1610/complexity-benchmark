We need to assign each satellite a value of 1 or 2 such that for every edge (u, v), the sum is odd.  
That means the two endpoints must have different values — this is exactly a bipartite graph check.

If the graph is not bipartite, output `NO`.  
If it is bipartite, we want the lexicographically smallest assignment.

We can do a BFS/DFS over each connected component, assigning values greedily:  
- Start with 1 for the smallest unvisited node in each component.  
- Alternate 1 and 2 along edges.  
- If a conflict occurs, it’s not bipartite.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0  # 0 means value 1, 1 means value 2
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    print(" ".join(str(c + 1) for c in color))
```
