We can model this as a bipartite graph problem: each server is a node, and each conduit pair is an edge.  
The condition “sum of power draws = 3” means one server must be 1 and the other 2.  
So we need to 2-color the graph (bipartite check). If it’s not bipartite, output `NO`.  
If it is, we assign 1 to one color and 2 to the other.  
To get the lexicographically smallest assignment, we start BFS/DFS from node 1 with color 1, and assign colors accordingly.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for start in range(n):
    if color[start] == -1:
        color[start] = 0
        q = deque([start])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    # color 0 -> 1, color 1 -> 2
    res = [1 if c == 0 else 2 for c in color]
    print(" ".join(map(str, res)))
```
