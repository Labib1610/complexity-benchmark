We can model this as a bipartite graph problem: each server is a node, and each link is an edge.  
We need to assign tier 1 or 2 such that connected nodes have different tiers — this is exactly a 2-coloring problem.

If the graph is not bipartite, output `NO`.  
Otherwise, we can color it with BFS/DFS, and to get the lexicographically smallest assignment, we start with tier 1 for the smallest-index node in each component.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
