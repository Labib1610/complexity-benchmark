**Solution Explanation**

For an edge `{u,v}` the interference multiplier is  

```
Muv = (su OR sv) + 2
```

`su , sv ∈ {1,2}`  

```
1 = 01₂ , 2 = 10₂
```

`su OR sv = 3` (binary `11`) **iff** the two vertices have *different* values
(one is `1`, the other `2`).  
If they are equal the OR is `1` or `2` and `Muv` is `3` or `4`, never `5`.

The required total product is `5^m`.  
Therefore **every edge must contribute the factor `5`**, i.e.

```
(su OR sv) + 2 = 5   →   su OR sv = 3   →   su ≠ sv
```

So the graph must be *bipartite* and the assignment is exactly a proper
2‑colouring with colours `{1,2}`.

--------------------------------------------------------------------

#### 1.   When does a solution exist ?

* The undirected graph formed by the `m` edges must be bipartite.
* If any connected component contains an odd cycle → impossible.

--------------------------------------------------------------------

#### 2.   Lexicographically smallest assignment

In a bipartite component there are exactly two possible colourings
(the two colour classes can be swapped).
Let `c(v) ∈ {0,1}` be the colour obtained by a normal BFS/DFS (starting root colour `0`).

Consider one component and let `p` be the **smallest vertex index** inside it.
The two feasible final assignments are

```
c(p)=0 → 1 , c(p)=1 → 2          (no flip)
c(p)=0 → 2 , c(p)=1 → 1          (flipped)
```

The first one makes `sp = 1`, the second makes `sp = 2`.  
Since `p` is the first position where the two assignments can differ,
the lexicographically smaller whole sequence is the one with `sp = 1`.

Hence for every component we simply **force the smallest indexed vertex
to receive value `1`**; the rest follows uniquely.

--------------------------------------------------------------------

#### 3.   Algorithm
```
read n,m
build adjacency list
if m == 0:
        output YES and n times 1
        exit

visited[1..n] = false
colour[1..n]   = -1          # 0 or 1
answer[1..n]   = 0

for each vertex v = 1 .. n:
        if not visited[v]:
                BFS from v
                collect all vertices of this component in list comp
                keep min_vertex = smallest index in comp
                during BFS check bipartite condition
                if conflict → print NO and stop

                # decide whether to flip colours in this component
                if colour[min_vertex] == 0:
                        # 0 → 1 , 1 → 2
                        for x in comp:
                                answer[x] = 1 if colour[x]==0 else 2
                else:
                        # flip: 0 → 2 , 1 → 1
                        for x in comp:
                                answer[x] = 2 if colour[x]==0 else 1

print YES
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise prints the lexicographically smallest valid assignment.

---

##### Lemma 1  
For any edge `{u,v}` the condition `Muv = 5` holds **iff** `su ≠ sv`.

*Proof.*  
`Muv = (su OR sv) + 2 = 5` ⇔ `su OR sv = 3`.  
The only way two numbers from `{1,2}` have OR equal to `3` is when one is `1`
(`01₂`) and the other is `2` (`10₂`). Hence they are different. ∎



##### Lemma 2  
A global assignment satisfies the required product `5^m` **iff** it is a proper
2‑colouring of the graph (adjacent vertices have different values).

*Proof.*  
By Lemma&nbsp;1 each edge contributes factor `5` exactly when its endpoints differ.
If all edges differ, the product of `m` factors `5` equals `5^m`.  
Conversely, if any edge has equal endpoints, its factor is `3` or `4`,
so the product cannot be `5^m`. ∎



##### Lemma 3  
The algorithm outputs `NO` exactly when the graph is not bipartite.

*Proof.*  
During BFS the algorithm checks that every visited edge connects vertices
with opposite BFS colours. This is the standard bipartite test.
If a conflict is found, the graph contains an odd cycle, i.e. is not bipartite,
and the algorithm prints `NO`.  
If the algorithm finishes without conflict, every component is bipartite. ∎



##### Lemma 4  
If the algorithm finishes with a sequence `answer`, then `answer` is a valid
assignment.

*Proof.*  
For each component the algorithm assigns values according to a BFS 2‑colouring,
possibly flipped. In both cases vertices of different BFS colour receive
different numbers (`1` vs `2`). Hence every edge connects different values,
so by Lemma&nbsp;2 the assignment is valid. ∎



##### Lemma 5  
For each connected component the algorithm produces the lexicographically
smallest possible values on the vertices of that component, assuming all
previous components (with smaller indices) are already fixed.

*Proof.*  
Let `p` be the smallest index in the component.
The two feasible assignments differ first at position `p`:
one gives `1`, the other gives `2`.  
The algorithm chooses the one with `sp = 1`.  
Any other feasible global assignment must agree with the algorithm on all
vertices with index `< p` (they belong to earlier components).  
If it differed at `p` by using `2`, its whole sequence would be lexicographically
larger. Therefore the algorithm’s choice is optimal for this component. ∎



##### Lemma 6  
The whole sequence `answer` is the lexicographically smallest valid assignment.

*Proof.*  
Components are processed in increasing order of their smallest vertex.
By Lemma&nbsp;5, after fixing components `1..k-1` the algorithm chooses the
smallest possible values for component `k` without affecting earlier positions.
Induction over components yields that no other valid assignment can be
lexicographically smaller. ∎



##### Theorem  
The program prints `NO` iff no assignment satisfying the problem statement
exists; otherwise it prints `YES` followed by the lexicographically smallest
valid assignment.

*Proof.*  
If the program prints `NO`, by Lemma&nbsp;3 the graph is not bipartite,
hence by Lemma&nbsp;2 no valid assignment exists.  
If the program prints `YES`, it produced a sequence `answer`.
By Lemma&nbsp;4 this sequence is valid.
By Lemma&nbsp;6 it is the lexicographically smallest among all valid ones.
Thus the output satisfies the specification. ∎

#### 5.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once → `O(n + m)`.  
*Overall*:  

```
Time   : O(n + m)   ≤ 4·10⁵ operations
Memory : O(n + m)   ≤ 4·10⁵ integers
```

Both fit easily into the limits.

#### 6.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    if m == 0:
        # all 1s is lexicographically smallest
        print("YES")
        print(" ".join(["1"] * n))
        return

    visited = [False] * (n + 1)
    colour = [-1] * (n + 1)          # 0 or 1
    answer = [0] * (n + 1)

    for start in range(1, n + 1):
        if visited[start]:
            continue
        # BFS this component
        q = deque([start])
        visited[start] = True
        colour[start] = 0
        comp = [start]
        min_vertex = start

        while q:
            v = q.popleft()
            if v < min_vertex:
                min_vertex = v
            for to in adj[v]:
                if not visited[to]:
                    visited[to] = True
                    colour[to] = colour[v] ^ 1
                    q.append(to)
                    comp.append(to)
                else:
                    if colour[to] == colour[v]:
                        print("NO")
                        return

        # decide mapping so that min_vertex gets value 1
        if colour[min_vertex] == 0:
            # 0 -> 1, 1 -> 2
            for x in comp:
                answer[x] = 1 if colour[x] == 0 else 2
        else:
            # flip
            for x in comp:
                answer[x] = 2 if colour[x] == 0 else 1

    print("YES")
    print(" ".join(str(answer[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
