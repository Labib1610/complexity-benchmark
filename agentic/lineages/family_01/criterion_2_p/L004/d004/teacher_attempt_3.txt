# Problem B — Gear Synchronization

Time limit: 1 s
Memory limit: 256 MB

You are assembling a mechanical clockwork consisting of $n$ synchronization gears. Each gear must be configured to rotate at a speed of either 1 RPM or 2 RPM.

The assembly includes $m$ direct contact points, each engaging a specific pair of gears. To prevent the teeth from grinding, gears that are in direct contact must mesh perfectly. This requires a strict mechanical ratio: for every contact point, the product of the rotation speeds of the two engaged gears must be exactly 2.

Your task is to determine whether it is possible to configure the rotation speed of every gear in the assembly to satisfy all meshing constraints.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of gears and the number of contact points.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a contact point between gear $u$ and gear $v$.

## Output
If there is no valid configuration for the assembly, print `NO` on a single line.
If a valid configuration is possible, print `YES` on the first line. On the second line, output $n$ space-separated integers $s_1 \dots s_n$ (where each $s_i \in \{1, 2\}$) representing the rotation speeds for gears $1$ through $n$. If multiple valid configurations exist, output the sequence that is lexicographically smallest.

## Example 1
**Input:**
```
4 4
1 2
2 3
3 4
1 4
```
**Output:**
```
YES
1 2 1 2
```

## Example 2
**Input:**
```
3 3
1 2
1 3
2 3
```
**Output:**
```
NO
```
