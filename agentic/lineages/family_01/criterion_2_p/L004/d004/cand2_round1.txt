<STATEMENT>
# Problem B — Zone Isolation

Time limit: 1 s
Memory limit: 256 MB

A data center contains $n$ servers. You must assign a transmission band to each server. The only permitted bands are 1 and 2. 

Each band configures the server's signal processor with a specific $2 \times 2$ transformation matrix:
- Band 1 uses the matrix $M_1 = \begin{pmatrix} 1 & 2 \\ 0 & 1 \end{pmatrix}$.
- Band 2 uses the matrix $M_2 = \begin{pmatrix} 1 & 0 \\ 2 & 1 \end{pmatrix}$.

The system has $m$ active synchronization links. Each link connects a specific pair of servers. For the network to remain stable, the interference between any two servers connected by a synchronization link must be strictly controlled. Specifically, the trace (the sum of the elements on the main diagonal) of the matrix product of their assigned matrices (in either order) must be exactly 6.

Determine if a valid band configuration exists for all $n$ servers.

## Input
The first line contains two integers $n$ and $m$. The facility's power infrastructure supports a maximum of 200,000 servers, and there is always at least one server. The fiber optic conduits can accommodate up to 200,000 synchronization links, though it is possible for a configuration to have zero links.

Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of a pair of servers connected by a synchronization link.

## Output
If no valid band configuration is possible, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $z_1 \dots z_n$ (where each $z_i \in \{1,2\}$) representing the valid assignment. If multiple valid assignments exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The link-stability condition was completely rewritten from a scalar cube-sum equation to a matrix trace property. To recognize that this is still a bipartite coloring problem, the model must manually evaluate the trace of the matrix products for identical bands (trace is 2) and differing bands (trace is 6), forcing genuine mathematical reasoning instead of pattern-matching standard arithmetic formulas.
</RATIONALE>
<PRESERVED_ANSWER>
The trace of $M_1 M_2$ and $M_2 M_1$ is exactly 6, while the trace of $M_1 M_1$ and $M_2 M_2$ is 2; thus, the new condition enforces exactly the same requirement that connected servers must be assigned different bands.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring (testing bipartiteness) and picking the lexicographically smallest valid assignment per connected component, which is solvable in $O(n+m)$ time using BFS or DFS.
</PRESERVED_CLASS>
