<STATEMENT>
# Orbital Resonance

Time limit: 1 s
Memory limit: 256 MB

A deep space communications network consists of $n$ relay satellites. Within this network, there are $m$ known proximity hazards. Each hazard involves a specific pair of satellites that are physically too close to one another.

Every satellite $i$ (for $1 \le i \le n$) must be assigned a state polynomial $P_i(x)$. To maintain system stability, you must choose $P_i(x)$ to be one of the two monic polynomials of degree 1 with real coefficients that perfectly divide $x^2 - 1$. 

Whenever two satellites $u$ and $v$ are involved in a proximity hazard, their assigned polynomials must neutralize their interference. Specifically, their polynomials must satisfy:

$P_u(x) \times P_v(x) = x^2 - 1$

If this product evaluates to any other polynomial, their resonance will cause a system-wide failure.

Your task is to determine if there is a valid configuration of state polynomials for all $n$ satellites that prevents any system-wide failures. If such a configuration is possible, you must output it by mapping each polynomial to a tuning parameter $s_i$:
- If $P_i(x) = x - 1$, then $s_i = 1$.
- If $P_i(x) = x + 1$, then $s_i = 2$.

If there are multiple valid ways to assign the polynomials, you must output the lexicographically smallest valid assignment $(s_1, \dots, s_n)$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — a proximity hazard between satellite $u$ and satellite $v$.

## Output
If no safe configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being either 1 or 2), representing the tuning parameter assigned to each satellite from 1 to $n$. This sequence must be the lexicographically smallest valid assignment $(s_1, \dots, s_n)$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The binary domain {1, 2} and the algebraic integer equation from the seed have been replaced with an isomorphic domain of degree-1 polynomials {x-1, x+1} and a polynomial multiplication constraint. This defeats models that rely on evaluating integer combinations to discover the 2-coloring reduction, forcing them to perform symbolic reasoning to map the polynomials back to the {1, 2} domain and recognize the bipartiteness constraint. The explicit numeric bounds have been restored to the Input section to pass the strict gate checks.
</RATIONALE>
<PRESERVED_ANSWER>
The monic degree-1 polynomials dividing x^2-1 are exactly x-1 and x+1; their product is x^2-1 if and only if they are different, which perfectly preserves the original s_u != s_v constraint and produces the exact same lexicographically smallest sequence of 1s and 2s.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring of a graph (or determining if it is bipartite), which is solvable in O(n + m) time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
Models might struggle to parse the phrase "monic polynomials of degree 1 with real coefficients that perfectly divide x^2 - 1", but mathematically it is completely unambiguous and yields exactly two valid choices.
</RISK>
