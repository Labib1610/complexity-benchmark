**Solution Explanation**

For every hazard (edge) `{u , v}` we have to choose a direction.
If `u` is the emitter and `v` the absorber the contribution of `u` is `+1`,
of `v` is `-1`.  
For a satellite `i`

```
C_i = (#edges where i is emitter) – (#edges where i is absorber)
d_i = total incident edges
```

The required condition is `|C_i| = d_i`.  
That is possible only when **all incident edges of `i` have the same direction** :

* either `i` is emitter for all its edges → `C_i =  d_i`
* or `i` is absorber for all its edges → `C_i = –d_i`

So every vertex must be either

* **source** – all incident edges go out of it,
* **sink**   – all incident edges go into it.

Consequently every edge must be oriented from a source to a sink.
If we write `s_i = 1` for a source and `s_i = 2` for a sink,
the whole graph has to be **bipartite** and the two colour classes are exactly
the sets of sources and sinks.

--------------------------------------------------------------------

#### 1.   Reducing to bipartite checking

* Build the undirected graph of the `m` hazards.
* Run a BFS/DFS on each not‑visited vertex, colour it `0` and propagate
  opposite colours along edges.
* If we ever meet an already coloured vertex with the same colour as the
  current one → odd cycle → not bipartite → answer `NO`.

During the search we store for the current component

* the list of its vertices,
* the colour (`0` or `1`) of each vertex.

--------------------------------------------------------------------

#### 2.   Lexicographically smallest `s_1 … s_n`

For a component we may swap the meaning of the two colours:

```
colour 0 → source (s = 1) , colour 1 → sink (s = 2)
or
colour 0 → sink   (s = 2) , colour 1 → source (s = 1)
```

The whole answer is the concatenation of the components (they are disjoint).
Lexicographic order is decided by the first index where two possible answers differ.
Therefore for each component we only have to look at its **smallest vertex index**.
If we give that vertex `s = 1` we obtain the smallest possible prefix,
hence the globally lexicographically smallest answer.

Implementation:

```
for each component:
        v0 = smallest vertex in the component
        if colour[v0] == 0:
                map colour 0 → 1 , colour 1 → 2
        else:
                map colour 0 → 2 , colour 1 → 1
        write the mapped values into the answer array
```

Isolated vertices are components of size 1, colour `0`,
the rule above gives them `s = 1` – also optimal.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `NO` iff no safe configuration exists,
otherwise prints the lexicographically smallest valid sequence.

---

##### Lemma 1  
In any safe configuration every vertex is either source for all its incident
edges or sink for all its incident edges.

**Proof.**  
`|C_i| = d_i`.  
`C_i = (#emitters) – (#absorbers)`.  
`d_i = (#emitters) + (#absorbers)`.  
The only integer solutions of these two equations are  
`(#emitters, #absorbers) = (d_i,0)` or `(0,d_i)`. ∎



##### Lemma 2  
A safe configuration exists **iff** the undirected graph is bipartite.

**Proof.**  
*If* the graph is bipartite with parts `A,B`.  
Make all vertices of `A` sources, all of `B` sinks.
Every edge connects a source to a sink, therefore it can be oriented from the
source to the sink, satisfying Lemma&nbsp;1.

*Only‑if* a safe configuration exists.
By Lemma&nbsp;1 each vertex is source or sink, and every edge joins a source with a
sink, i.e. the vertices can be coloured by `source / sink`.  
Thus the graph is 2‑colourable → bipartite. ∎



##### Lemma 3  
For a bipartite connected component the two possible assignments of
`s_i ∈ {1,2}` are exactly the two colour‑to‑value mappings described above.

**Proof.**  
All vertices of colour `0` must receive the same value (all source or all sink)
and the opposite colour the opposite value, otherwise an edge would have both
ends as source or both as sink, contradicting Lemma&nbsp;1.
The two possibilities are the two swaps. ∎



##### Lemma 4  
Choosing, for each component, the mapping that gives its smallest indexed
vertex value `1` yields the lexicographically smallest global sequence.

**Proof.**  
Consider components ordered by their minimal vertex index.
When processing the first component, any global answer must agree on all
indices smaller than its minimal vertex (they belong to earlier components).
Among the two possible local assignments the one with `s = 1` at that minimal
vertex is strictly smaller at that position, therefore any answer using the
other mapping would be lexicographically larger, regardless of later positions.
Induction over the components gives the claim. ∎



##### Lemma 5  
If the algorithm outputs `YES` and a sequence `s`, then `s` is a safe
configuration.

**Proof.**  
The algorithm only outputs `YES` after a successful bipartite check,
so the graph is bipartite.  
For each component it assigns values according to a colour‑to‑value mapping,
hence by Lemma&nbsp;3 every edge is oriented from a vertex with `s=1` to a vertex
with `s=2`.  
Thus each vertex is source (all incident edges outgoing) or sink (all incoming),
so Lemma&nbsp;1 holds, i.e. the configuration is safe. ∎



##### Lemma 6  
If a safe configuration exists, the algorithm never prints `NO`.

**Proof.**  
By Lemma&nbsp;2 a safe configuration implies the graph is bipartite.
The BFS/DFS bipartite test succeeds on bipartite graphs, therefore the
algorithm does not encounter a conflict and does not output `NO`. ∎



##### Theorem  
The algorithm prints `NO` exactly when no safe configuration exists.
Otherwise it prints `YES` and the lexicographically smallest valid sequence
`s_1 … s_n`.

**Proof.**  
*Impossible case*: by Lemma&nbsp;6 a safe configuration would make the algorithm
accept, therefore printing `NO` means none exists.

*Possible case*: the algorithm accepts, builds a sequence `s`.
By Lemma&nbsp;5 `s` is safe.
By Lemma&nbsp;4 the construction is lexicographically minimal among all safe
sequences. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency list* : `O(n + m)` memory and time.  
*BFS/DFS over all vertices* : each edge examined once → `O(n + m)` time.  
*Choosing mappings* : linear in total vertices → `O(n)`.

Overall  

```
Time   : O(n + m)   ≤ 4·10^5 operations
Memory : O(n + m)   ≤ 4·10^5 integers
```

Both satisfy the limits.

#### 5.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 = unvisited, 0/1 = bipartite colour
    answer = [0] * (n + 1)           # final s_i (1 or 2)

    from collections import deque

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # start a new component
        q = deque([start])
        colour[start] = 0
        comp_vertices = [start]
        ok = True
        while q:
            v = q.popleft()
            cv = colour[v]
            for to in adj[v]:
                if colour[to] == -1:
                    colour[to] = cv ^ 1
                    q.append(to)
                    comp_vertices.append(to)
                elif colour[to] == cv:
                    # conflict -> not bipartite
                    print("NO")
                    return
        # choose mapping so that smallest index gets s=1
        min_v = min(comp_vertices)
        if colour[min_v] == 0:
            # colour 0 -> 1, colour 1 -> 2
            for v in comp_vertices:
                answer[v] = 1 if colour[v] == 0 else 2
        else:
            # swap
            for v in comp_vertices:
                answer[v] = 2 if colour[v] == 0 else 1

    # all components processed
    print("YES")
    print(' '.join(str(answer[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```

to the required input‑output format.
