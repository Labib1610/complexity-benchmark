We need to assign each node either 1 or 2 such that for every edge, the bitwise AND of the two endpoints is 0.  

Since the only allowed values are 1 (binary `01`) and 2 (binary `10`), their AND is 0 only if one is 1 and the other is 2.  
So the problem reduces to:  
- Color the graph with two colors (1 and 2) such that adjacent nodes have different colors.  
- This is exactly checking if the graph is bipartite.  
- If it is bipartite, we need the lexicographically smallest assignment.  

To get lexicographically smallest, we assign node 1 as 1, then BFS/DFS, assigning the opposite color to neighbors. If a conflict occurs, output `NO`.  

Here’s the implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
color[0] = 1  # start with 1 for lexicographically smallest

for start in range(n):
    if color[start] == -1:
        color[start] = 1
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 3 - color[u]  # 1 -> 2, 2 -> 1
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
