# Problem B — Phase Shift Coefficients

Time limit: 1 s
Memory limit: 256 MB

You are tasked with tuning a network of $n$ signal relays. The facility requires a minimum of one relay and has a maximum capacity of two hundred thousand relays. The system includes $m$ critical links, each joining two relays. The maintenance budget allows for anywhere from zero up to two hundred thousand such links. Relays are identified by valid IDs, which are integers from 1 up to $n$ inclusive.

Each relay must be configured with a phase shift coefficient chosen from the set $\{1, 2\}$. To avoid signal distortion, the configuration must obey a strict interaction rule across these connections: for any critical link, the product of the phase shift coefficients of the two connected relays must evaluate to exactly 2.

Your goal is to determine whether a valid configuration exists for the entire network.

## Input
The first line provides two integers $n$ and $m$, representing the number of relays and the number of critical links, respectively.
The following $m$ lines each contain two integers $u$ and $v$ representing valid IDs, indicating a critical link between the relay identified by $u$ and the relay identified by $v$.

## Output
If it is impossible to configure the network according to the rules, print `NO` on a single line.
If a valid configuration is possible, print `YES` on the first line. On the second line, provide $n$ space-separated integers $z_1 \dots z_n$ (where each $z_i \in \{1, 2\}$) to indicate the assigned phase shift coefficients for relays $1$ to $n$. If more than one valid configuration exists, output the sequence that is lexicographically smallest.

## Example 1
**Input:**
```
4 4
1 2
2 3
3 4
1 4
```
**Output:**
```
YES
1 2 1 2
```

## Example 2
**Input:**
```
3 3
1 2
1 3
2 3
```
**Output:**
```
NO
```

<RATIONALE>
I changed the relationship constraint from "one is exactly twice the other" to "their product is exactly 2". This obscures the fact that the two values must be different, masking the 2-coloring (bipartite) nature of the problem behind what looks like a non-linear algebraic equation. I also moved the numeric bounds out of the input section and into the scenario description as physical capacities and budget limits, fulfilling the S07 strategy.
</RATIONALE>
<PRESERVED_ANSWER>
Since the only allowed values are 1 and 2, the condition that their product equals 2 is mathematically identical to one being exactly twice the other (forcing the pair to be exactly one 1 and one 2), keeping all valid configurations identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying graph structure and the requirement that adjacent nodes have different assignments remain unchanged, so the problem is still solvable in linear time using BFS/DFS for 2-coloring.
</PRESERVED_CLASS>
