<STATEMENT>
# Orbital Resonance

Time limit: 1 s
Memory limit: 256 MB

A deep space communications network consists of $n$ relay satellites, numbered 1 through $n$. Within this network, there are $m$ known proximity hazards. Each hazard involves a specific pair of satellites that are physically too close to one another.

Every satellite in the network must be assigned a tuning parameter, which is an integer chosen from $\{1, 2\}$. Whenever two satellites $u$ and $v$ are involved in a proximity hazard, their tuning parameters $s_u$ and $s_v$ dictate a joint resonance signature. This signature is conceptually a sequence consisting of exactly $s_u$ identical alpha pulses and exactly $s_v$ identical beta pulses. To avoid a system-wide failure, the tuning parameters must be chosen such that the total number of distinct sequences that can be formed by arranging these $s_u + s_v$ pulses in a line is exactly 3. If the number of distinct arrangements evaluates to any other value, their resonance will destabilize the network.

Your task is to determine if there is a valid configuration of tuning parameters for all $n$ satellites that prevents any system-wide failures. If such a configuration is possible, you must output it. If there are multiple valid ways to assign the parameters, you must choose the one whose sequence of assignments $(s_1, s_2, \dots, s_n)$ appears first in standard dictionary order.

## Input
The first line contains two integers $n$ and $m$. The central registry allocates exactly 200,000 memory slots for satellite records, meaning the number of satellites $n$ can be anywhere from 1 up to this capacity. Similarly, the hazard tracking system can monitor up to 200,000 hazards, so $m$ ranges from 0 up to this limit.
Each of the next $m$ lines contains two integers $u$ and $v$ — a proximity hazard between satellite $u$ and satellite $v$.

## Output
If no safe configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being either 1 or 2), representing the tuning parameter assigned to each satellite from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit algebraic equation for the pairwise constraint with an isomorphic combinatorial condition: the number of unique permutations of $s_u$ alpha pulses and $s_v$ beta pulses must be exactly 3. This forces models to dynamically evaluate the constraint rather than relying on surface pattern matching, while strictly preserving the local pairwise nature of the seed problem that was missing in the rejected global-equation draft. I also embedded the input bounds into the scenario description using Strategy S07.
</RATIONALE>
<PRESERVED_ANSWER>
The combinatorial condition evaluates to exactly 3 if and only if one tuning parameter is 1 and the other is 2 (since 3!/(1!2!) = 3, while 2!/(1!1!) = 2 and 4!/(2!2!) = 6), which perfectly mirrors the truth table of the seed's algebraic equation, ensuring all valid assignments remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains logically equivalent to finding a valid 2-coloring of a graph and selecting the lexicographically smallest assignment per connected component, keeping it firmly in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret 'arranging these pulses in a line' as a sequence construction task rather than a simple combinatorics formula, though the math is standard and unambiguous.
</RISK>
