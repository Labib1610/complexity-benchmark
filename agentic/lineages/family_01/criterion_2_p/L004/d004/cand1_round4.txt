<STATEMENT>
# Orbital Resonance

Time limit: 1 s
Memory limit: 256 MB

A deep space communications network consists of $n$ relay satellites, numbered 1 through $n$. The network accommodates a minimum of $1$ and a maximum of $200,000$ satellites. The hazard tracking system can log anywhere from $0$ up to a maximum of $200,000$ proximity hazards. Currently, there are $m$ known proximity hazards logged. Each hazard involves a specific pair of satellites that are physically too close to one another.

Every satellite in the network must be assigned a continuous tuning function $T_i(x)$, chosen from exactly two available types:
- Type 1: $T_i(x) = x$
- Type 2: $T_i(x) = |x|$

Whenever two satellites $u$ and $v$ are involved in a proximity hazard, their assigned tuning functions must satisfy the orbital equilibrium equation over the interval $[-1, 1]$:

$\int_{-1}^{1} T_u(x) T_v(x) \, dx = 0$

If this integral evaluates to any other value, their resonance will cause a system-wide failure.

Your task is to determine if there is a valid configuration of tuning function types for all $n$ satellites that prevents any system-wide failures. If such a configuration is possible, you must output it. If there are multiple valid ways to assign the types, you must choose the one whose sequence of assigned types (using the integers 1 and 2) $t_1, t_2, \dots, t_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ (bounds are determined by the network capacity and hazard log limits described above).
Each of the next $m$ lines contains two integers $u$ and $v$ — a proximity hazard between satellite $u$ and satellite $v$.

## Output
If no safe configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $t_1, \dots, t_n$ (each being either 1 or 2), representing the tuning function type assigned to each satellite from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit bounds were replaced with narrative constraints describing system capacities, forcing the reader to extract the limits from the text (Strategy S07). The algebraic equation was replaced with a definite integral constraint over odd and even functions. Evaluating the integral reveals that identical assignments yield $2/3$, while differing assignments yield $0$, exactly preserving the original disequality requirement while defeating models that rely on recognizing the specific cubic integer equation.
</RATIONALE>
<PRESERVED_ANSWER>
The integral evaluates to 0 if and only if the two assigned functions are different (since x|x| is an odd function over a symmetric interval), which perfectly maps to the original requirement that adjacent satellites must have different types (1 and 2).
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring (bipartiteness check) and assigning the lexicographically smallest valid colors, which is solvable in O(n + m) time using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might struggle to evaluate the integral symbolically, but the math is standard elementary calculus and leaves no ambiguity about the required conditions.
</RISK>
