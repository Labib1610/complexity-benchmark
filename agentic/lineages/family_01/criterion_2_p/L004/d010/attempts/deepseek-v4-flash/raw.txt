We can model this as a graph problem.  
Each satellite has two possible states, and the penalty for an edge depends on the states of its endpoints.  

Let’s compute the dot products:

- If both are state 1:  
  \( (1,2,3,4) \cdot (1,2,3,4) = 1+4+9+16 = 30 \)
- If both are state 2:  
  \( (4,-3,-2,1) \cdot (4,-3,-2,1) = 16+9+4+1 = 30 \)
- If one is state 1 and the other state 2:  
  \( (1,2,3,4) \cdot (4,-3,-2,1) = 4 - 6 - 6 + 4 = -4 \)

So the penalty is:
- \(30\) if same state
- \(-4\) if different states

We need total penalty = \(-4m\).  
That means every edge must contribute \(-4\), i.e., every edge must connect satellites with different states.

Thus, the graph must be bipartite.  
If it is bipartite, we assign states 1 and 2 to the two partitions.  
For lexicographically smallest, we assign state 1 to the first partition (starting from node 1) and state 2 to the other.

If the graph is not bipartite, output `NO`.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    # color 0 -> state 1, color 1 -> state 2
    print(' '.join(str(c + 1) for c in color))
```
