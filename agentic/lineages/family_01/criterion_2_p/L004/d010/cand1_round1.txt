<STATEMENT>
# Orbital Resonance

Time limit: 1 s
Memory limit: 256 MB

A deep space communications network consists of $n$ relay satellites, numbered 1 through $n$. Within this network, there are $m$ known proximity hazards. Each hazard involves a specific pair of satellites that are physically too close to one another.

To stabilize the network, every satellite $i$ must be assigned a phase state $s_i \in \{1, 2\}$. 

Depending on its assigned phase state, a satellite is configured with a specific 4-dimensional calibration vector:
- If $s_i = 1$, its calibration vector is $C_i = (1, 2, 3, 4)$.
- If $s_i = 2$, its calibration vector is $C_i = (4, -3, -2, 1)$.

When a signal passes between two satellites $u$ and $v$ involved in a proximity hazard, their calibration vectors interact to produce a *resonance penalty* for that hazard. This penalty is calculated as the standard dot product of their calibration vectors (i.e., the sum of the products of their corresponding components).

The *total network penalty* is defined as the sum of the resonance penalties across all $m$ listed hazards. (If there are no hazards, meaning $m=0$, this sum is defined to be 0).

For the network to be safe, the total network penalty must be exactly $-4m$.

Your task is to determine if there is a valid configuration of phase states for all $n$ satellites that achieves this exact total network penalty. If such a configuration is possible, you must output it. 

Among all valid assignments $s_1, s_2, \dots, s_n$, output the lexicographically smallest sequence. (A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index $i$ where they differ, $A_i < B_i$).

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a proximity hazard between satellite $u$ and satellite $v$.

## Output
If no safe configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being either 1 or 2), representing the phase state assigned to each satellite from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the bitwise arithmetic condition with a geometric one: the interaction between two satellites is now the dot product of 4D calibration vectors. The vectors are carefully chosen so that same-state interactions yield a penalty of 30, while different-state interactions yield -4. By setting the global target to exactly -4m, the model is forced to compute the possible interaction values, recognize that -4 is the absolute minimum, and deduce that the target can only be achieved if every single hazard connects satellites with different states.
</RATIONALE>
<PRESERVED_ANSWER>
The dot product is 30 for same-state pairs and -4 for different-state pairs, so the sum of m penalties is exactly -4m if and only if every pair has different states, which is mathematically identical to the original requirement that every pair evaluates to 5.
</PRESERVED_ANSWER>
