We can rewrite the given expression:

\[
\frac{z_u}{z_v} + \frac{z_v}{z_u}
\]

Since \( z_i \in \{1, 2\} \):

- If \( z_u = z_v \), then \(\frac{z_u}{z_v} + \frac{z_v}{z_u} = 1 + 1 = 2\).
- If \( z_u \neq z_v \), then \(\frac{z_u}{z_v} + \frac{z_v}{z_u} = \frac{1}{2} + 2 = \frac{5}{2}\).

So the sum over all pairs is:

\[
2 \cdot (\text{number of equal pairs}) + \frac{5}{2} \cdot (\text{number of different pairs})
\]

We want this to equal \(\frac{5m}{2}\).

Let \(x\) = number of equal pairs, \(y\) = number of different pairs.  
We have \(x + y = m\).  
The equation becomes:

\[
2x + \frac{5}{2}y = \frac{5}{2}m
\]

Multiply by 2:

\[
4x + 5y = 5m
\]

Substitute \(y = m - x\):

\[
4x + 5(m - x) = 5m
\]
\[
4x + 5m - 5x = 5m
\]
\[
-x = 0 \quad \Rightarrow \quad x = 0
\]

So **all pairs must be different**.  
That means the graph must be bipartite, with all edges connecting vertices of different values.

Thus the problem reduces to:  
Check if the graph is bipartite. If yes, output the lexicographically smallest bipartition (assign 1 to the first part, 2 to the second).  
If not, output `NO`.

We can do BFS/DFS coloring.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    # Lexicographically smallest: assign 1 to color 0, 2 to color 1
    res = [1 if c == 0 else 2 for c in color]
    print(" ".join(map(str, res)))
```
