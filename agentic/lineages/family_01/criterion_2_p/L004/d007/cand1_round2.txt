# Problem B — Microservice Resonance Scaling

Time limit: 1 s
Memory limit: 256 MB

You are optimizing a backend architecture containing $n$ microservices. Each microservice requires a designated scaling factor, denoted as $z_i$, which you must set to either 1 or 2.

The architecture handles $m$ synchronous workflows. Every workflow acts as a connection between two specific microservices. For a workflow connecting microservice $u$ and microservice $v$, the operational resonance generated by this connection is defined as the exact value of $\frac{z_u^3 + z_v^3}{z_u z_v (z_u + z_v)} + 1$.

The system's total resonance is the aggregate of the operational resonances from all $m$ workflows. To satisfy strict latency constraints without introducing resource contention, the total resonance across the entire system must equal exactly $2.5 \times m$.

Determine whether there is a valid assignment of scaling factors to the $n$ microservices that achieves a total resonance of exactly $2.5 \times m$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines provides two integers $u$ and $v$ — the indices of the two microservices connected by a workflow.

## Output
If no valid assignment is possible, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $z_1 \dots z_n$ (where each $z_i \in \{1,2\}$) representing the valid scaling factors. If there are multiple valid assignments, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
