# Problem B — Distributed Remainder Allocation

Time limit: 1 s
Memory limit: 256 MB

A cloud environment contains $n$ server nodes. You must assign each server $i$ a compute tier $t_i$, which must be either 1 or 2.

The environment manages $m$ background jobs. Each job is linked to a specific pair of servers. 
When a job is linked to server $u$ and server $v$, its resource metric is defined as the remainder when 5 is divided by the sum of their compute tiers. In programming terms, this is evaluated as `5 % (t_u + t_v)`.

The total metric of the environment is the sum of the resource metrics of all $m$ background jobs. To ensure optimal load balancing without bottlenecks, the total metric must be exactly $2 \times m$.

Determine if it is possible to assign a valid compute tier to all $n$ servers such that the total metric is exactly $2 \times m$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of the two servers that a background job is linked to.

## Output
If no valid tier assignment is possible, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $t_1 \dots t_n$ (where each $t_i \in \{1,2\}$) representing the valid assignment. If multiple valid assignments exist, output the lexicographically smallest sequence $t_1 \dots t_n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
