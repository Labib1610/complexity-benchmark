We can model this as a graph problem.  
For each machine, the condition depends on its own mode and the sum of its neighbors’ modes.

Let’s define:

- If machine \( u \) has mode 1, then sum of neighbors’ modes = \( 2 \cdot \deg(u) \).
- If machine \( u \) has mode 2, then sum of neighbors’ modes = \( \deg(u) \).

Since each neighbor’s mode is either 1 or 2, the sum of neighbors’ modes is:

\[
\text{sum} = (\text{number of neighbors with mode 1}) \cdot 1 + (\text{number of neighbors with mode 2}) \cdot 2
\]

Let \( d = \deg(u) \), and let \( x \) be the number of neighbors with mode 2.  
Then sum = \( (d - x) \cdot 1 + x \cdot 2 = d + x \).

So:

- If \( u \) has mode 1: \( d + x = 2d \) → \( x = d \) → all neighbors must be mode 2.
- If \( u \) has mode 2: \( d + x = d \) → \( x = 0 \) → all neighbors must be mode 1.

Thus the rule is:

- Mode 1 nodes must have all neighbors in mode 2.
- Mode 2 nodes must have all neighbors in mode 1.

This means the graph must be bipartite, with the two parts being mode 1 and mode 2.  
If the graph is not bipartite, output NO.

If it is bipartite, we can assign modes.  
For lexicographically smallest, we try to assign mode 1 to as many early-index nodes as possible.  
We can do a BFS/DFS coloring, but with a twist: we try to set node 1 to mode 1, then propagate. If conflict, try node 1 as mode 2.  
If both fail, NO.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

def try_assign(start_mode):
    color = [-1] * n
    color[0] = start_mode
    q = deque([0])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                return None
    # Check isolated nodes (if any) — they can be mode 1
    for i in range(n):
        if color[i] == -1:
            color[i] = 0
    return color

# Try starting with mode 1 (0) for node 1
res = try_assign(0)
if res is None:
    res = try_assign(1)

if res is None:
    print("NO")
else:
    print("YES")
    print(" ".join(str(c + 1) for c in res))
```
