<STATEMENT>
# Problem B — Frequency Calibration

Time limit: 1 s
Memory limit: 256 MB

An industrial facility manages a network of $n$ automated machines. Each machine must be configured to use one of two specific operational modes, which are designated by the values 1 and 2.

The facility's monitoring system has flagged $m$ adjacency pairs. Each pair indicates two machines that are physically close enough to risk signal overlap. To guarantee safe operation, the system enforces a strict interference protocol: for each adjacency pair given in the input as machine $u$ and machine $v$, if their configured modes are $x$ and $y$ respectively, it must be possible to find real numbers $p$ and $q$ that satisfy the following system of equations:

$p \cdot x + q \cdot y = u$
$p \cdot y + q \cdot x = -v$

Your task is to determine a mode configuration for all $n$ machines that satisfies this protocol for every adjacency pair, or determine that no such configuration is possible.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$ — a pair of machines listed in an adjacency pair.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The previous simple polynomial constraint (`x^2 + 3xy + y^2 = 11`) allowed models to easily evaluate the 4 possible mode combinations globally and trivially deduce the `x != y` bipartiteness requirement. I replaced this with a parameterized linear system whose right-hand side depends on the specific machine indices `u` and `v`. To realize this still universally reduces to `x != y`, a model must now analyze the system's determinant (`x^2 - y^2`) and prove that it is non-zero iff `x != y` (and that `u = -v` is impossible for positive indices). Models relying on surface pattern matching will likely fail to simplify this globally and instead attempt to check the constraints per-edge in a generic CSP solver, leading to a Time Limit Exceeded on $N=2\cdot 10^5$.
</RATIONALE>
<PRESERVED_ANSWER>
The linear system has a solution for $p$ and $q$ if and only if the determinant $x^2 - y^2$ is non-zero, which for $x, y \in \{1, 2\}$ is exactly when $x \neq y$ (since $u=-v$ is impossible for $u, v \ge 1$), making the valid configurations identical to the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains exactly 2-coloring (testing bipartiteness and finding the lexicographically smallest coloring), which is solvable in O(n+m) time using BFS, keeping it in the P complexity class.
</PRESERVED_CLASS>
