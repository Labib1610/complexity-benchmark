# Problem B — Molecular Assembly

Time limit: 1 s   Memory limit: 256 MB

A synthetic biology lab is calibrating a molecular structure. This structure is composed of $n$ distinct protein building blocks, which are numbered from 1 to $n$. The assembly is held together by $m$ contact points, each forming a direct link between a specific pair of protein blocks.

To achieve structural stability, every individual building block must be assigned a resonance state, chosen from the values 1 and 2. The interlocking mechanism at each contact point is highly sensitive: two linked blocks will only bind correctly if their assigned resonance states add up to exactly 3. 

The lab's goal is to find a system-wide assignment of resonance states such that every single contact point successfully binds. If no such assignment exists, the calibration fails. 

Furthermore, the lab requires a deterministic result. If there is more than one way to stabilize the structure, you must select the configuration that prioritizes lower states for lower-numbered blocks. Specifically, whenever you compare two different valid assignments, find the lowest block number where their states differ; the assignment that gives state 1 to this block is the preferred one. You must output the single assignment that is preferred over all other valid alternatives.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of protein blocks and the number of contact points.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ — a pair of blocks connected by a contact point.

## Output
If it is impossible to stabilize the assembly, print `NO` on a single line.
If stabilization is possible, print `YES` on the first line. On the second line, print $n$ integers separated by spaces, representing the states (1 or 2) assigned to blocks 1 through $n$ in the optimally preferred configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

Removed the keyword "lexicographically smallest" which acts as a trigger for models to blindly assign the smaller value to the earliest unvisited vertex in a component. Replaced it with an operational definition of lexicographical comparison (comparing two sequences and favoring state 1 at the earliest differing index). This forces the model to logically deduce how this sequential preference translates to the component-wise greedy choice, rather than relying on pattern matching to the term.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to favor state 1 at the lowest index where two valid assignments differ is mathematically identical to finding the lexicographically smallest sequence of 1s and 2s, so the correct output remains exactly the same.
</PRESERVED_ANSWER>
