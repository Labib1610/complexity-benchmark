# Problem B — Molecular Assembly

Time limit: 1 s   Memory limit: 256 MB

A synthetic biology lab is calibrating a molecular structure composed of $n$ distinct protein building blocks. The structure contains $m$ contact points, each connecting a specific pair of blocks.

To ensure stability, the lab must configure the resonance of the entire assembly. Every building block requires a resonance setting of either 1 or 2. Whenever two blocks meet at a contact point, their interlocking behavior is governed by a biochemical lookup table based on their settings. If the settings of the two connected blocks are $x$ and $y$, the contact point is considered 'stable' if the pair $(x, y)$ is either (1, 2) or (2, 1). Conversely, if the pair $(x, y)$ is (1, 1) or (2, 2), the contact point is 'unstable' and fails to interlock. The blocks will only interlock properly if their settings yield a 'stable' connection.

You must find a configuration for all blocks that allows every contact point to interlock. If the structure cannot be stabilized in this way, indicate that it is impossible.

## Input
The first line provides $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), the number of building blocks and contact points, respectively.
The following $m$ lines each contain two integers $u$ and $v$ — a pair of blocks that share a contact point.

## Output
If the assembly cannot be stabilized, output NO on a single line.
If it can, output YES on the first line. On the second line, output $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Removed the arithmetic "sum to exactly 3" condition and replaced it with a biochemical lookup table that explicitly lists the valid and invalid setting pairs. This prevents models from immediately pattern-matching the arithmetic constraint to a bipartite graph coloring step, forcing them to deduce the structural incompatibility of identical settings from the table.
</RATIONALE>
<PRESERVED_ANSWER>
The lookup table specifies that only the pairs (1, 2) and (2, 1) are valid, which is mathematically identical to requiring that the settings sum to exactly 3, ensuring all valid configurations remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires assigning one of two states to each node such that no two adjacent nodes share the same state, which is the exact definition of 2-coloring a graph (bipartiteness testing).
</PRESERVED_CLASS>
