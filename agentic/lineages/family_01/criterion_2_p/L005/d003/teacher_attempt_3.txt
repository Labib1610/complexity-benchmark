# Problem B — Molecular Assembly

Time limit: 1 s   Memory limit: 256 MB

A synthetic biology lab is calibrating a molecular structure composed of distinct protein building blocks. The structure contains contact points, each connecting a specific pair of blocks.

To ensure stability, the lab must configure the resonance of the entire assembly. Every building block requires a resonance setting chosen from the values 1 and 2. Whenever two blocks meet at a contact point, they will only interlock properly if the product of their resonance settings is exactly 2. You must find a configuration for all blocks that allows every contact point to interlock. If the structure cannot be stabilized in this way, indicate that it is impossible.

## Input
The first line provides $n$ and $m$, the number of building blocks and contact points, respectively. The lab's synthesis chamber has a physical capacity of $200,000$ slots, meaning the structure can have up to that many blocks (with a minimum of one). The monitoring system can track up to an identical maximum number of contact points, though a structure might have none.
The following $m$ lines each contain two integers $u$ and $v$ — a pair of blocks that share a contact point.

## Output
If the assembly cannot be stabilized, output NO on a single line.
If it can, output YES on the first line. On the second line, output $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The compatibility rule was changed from "sum to exactly 3" to "product is exactly 2". This removes the recognizable phrasing that often triggers bipartite graph 2-coloring pattern matching, forcing the model to deduce the relationship from the restricted {1,2} domain. Additionally, the bare numeric bounds for $n$ and $m$ were removed and instead embedded into the scenario as physical capacities of the lab equipment, fulfilling the S07 strategy.
</RATIONALE>
<PRESERVED_ANSWER>
Because the resonance settings are strictly constrained to the values 1 and 2, the condition that their product must be 2 is mathematically identical to their sum being 3; both require exactly one block to be 1 and the other to be 2, preserving all valid configurations and the lexicographical tie-breaker.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains discovering the lexicographically smallest valid 2-coloring of an undirected graph, which is solvable in $O(n+m)$ time using Breadth-First Search and remains in P.
</PRESERVED_CLASS>
