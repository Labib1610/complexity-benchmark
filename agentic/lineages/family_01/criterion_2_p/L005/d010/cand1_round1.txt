<STATEMENT>
# Problem B — Power Calibration

Time limit: 1 s
Memory limit: 256 MB

An industrial facility operates a network of $n$ automated machines. Each machine must be calibrated to a power mode of either 1 or 2.

The facility's safety system has identified $m$ critical pairs of machines. These pairs share a power bus, and their modes must be carefully balanced. 

To comply with the safety protocol and prevent dangerous harmonic cascades, the configuration must satisfy a strict local equilibrium condition for every machine in the network. For each machine $i$, let $d_i$ be the number of critical pairs it belongs to. The safety system calculates an equilibrium score for machine $i$ by taking the sum of the power modes of its partners across all $d_i$ of its critical pairs, and adding $d_i$ times the power mode of machine $i$ itself. 

The overall calibration is deemed safe if and only if, for every machine $i$, this equilibrium score equals exactly $3 d_i$.

Your task is to find a calibration for all $n$ machines that satisfies this requirement, or determine that no such calibration exists.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of machines and the number of critical pairs, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a critical pair of machines. Machines are numbered from $1$ to $n$.

## Output
If it is impossible to safely calibrate the machines, print NO on a single line.
Otherwise, print YES on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2\}$) representing the lexicographically smallest valid calibration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

Removed the global bitwise-OR sum constraint which was easily recognized as forcing independent edge bipartiteness. Replaced it with a system of local equilibrium equations for each vertex. To discover that this forces a bipartite coloring, the model must now perform a multi-step bounding argument on the discrete domain {1, 2} for the local neighborhood sum.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $S_i + d_i c_i = 3 d_i$ with $c_i \in \{1, 2\}$ forces $S_i = 2 d_i$ (all neighbors 2) when $c_i = 1$, and $S_i = d_i$ (all neighbors 1) when $c_i = 2$, making it exactly equivalent to all edges connecting opposite modes.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness checking), which is solved in O(n+m) using BFS/DFS, placing it squarely in P.
</PRESERVED_CLASS>

<METHOD_NAME>Local Equilibrium Equation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces a global sum of independent edge constraints with a system of local vertex constraints. For each vertex, a linear combination of its neighbors' values and its own value is constrained. Because the variables are restricted to the discrete domain {1, 2}, this local equation forces the sum of neighbors to an extreme bound, strictly requiring all neighbors to have the opposite value of the vertex. LLMs will likely attempt to solve it as a continuous linear system, use numeric relaxation, or fail to deduce the discrete bounding argument needed to map it to graph coloring.</METHOD_DESCRIPTION>
