Functional Composition Obfuscation
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces a numerical adjacency constraint (sum of neighbors) with a functional composition constraint. By mapping the two valid states to mutually inverse, non-involutory functions (left and right cyclic shifts of a 3-element array), the requirement that adjacent nodes have different states is perfectly preserved. This forces the model to evaluate the compositions to discover that $s_u \neq s_v$, completely removing any graph coloring, parity, or arithmetic vocabulary that the surviving models rely on for pattern matching.
</METHOD_DESCRIPTION>

yes

<STATEMENT>
# Problem B — Pipeline Synchronization

Time limit: 1 s
Memory limit: 256 MB

A distributed computing cluster consists of $n$ processors. Each processor must be configured with exactly one of two data-routing protocols, labeled 1 and 2.

Protocol 1 performs a cyclic left-shift on any 3-element data packet. For example, it transforms the packet `[X, Y, Z]` into `[Y, Z, X]`.
Protocol 2 performs a cyclic right-shift on any 3-element data packet. For example, it transforms the packet `[X, Y, Z]` into `[Z, X, Y]`.

The cluster contains $m$ bidirectional data links. Each link connects a pair of processors. To maintain data integrity, every individual link must act as a neutral transformation step. Specifically, for each of the $m$ data links, applying the protocol of one connected processor and then immediately applying the protocol of the other connected processor to a packet `[X, Y, Z]` must yield exactly the original packet `[X, Y, Z]`.

Your task is to assign protocol 1 or 2 to each of the $n$ processors such that this requirement is satisfied for all $m$ data links. If there are multiple valid assignments, you must output the one that is lexicographically smallest. If no such assignment is possible, you must determine this.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$ — a pair of processors connected by a data link.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The seed problem explicitly used sums to enforce that adjacent nodes must have opposite assignments. The surviving models recognized this arithmetic parity constraint and immediately mapped it to bipartite graph coloring. I removed all arithmetic and graph terminology, replacing it with a functional composition requirement. Because two identical cyclic shifts of order 3 do not yield the identity, but two opposite shifts do, this enforces exactly the same $s_u \neq s_v$ constraint across all edges, forcing models to genuinely reason about the properties of the operations rather than pattern-matching the boilerplate.
</RATIONALE>
<PRESERVED_ANSWER>
Applying Protocol 1 twice yields a right-shift, and applying Protocol 2 twice yields a left-shift; only applying Protocol 1 and Protocol 2 together yields the identity transformation, meaning every linked pair must be assigned different protocols, exactly matching the seed's bipartite constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires assigning one of two values to each node such that no two connected nodes share the same value (2-coloring), which is solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
