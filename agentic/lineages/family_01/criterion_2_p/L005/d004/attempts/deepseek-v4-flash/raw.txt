We need to assign each machine a power setting of 1 or 2 such that for every edge (u, v), the product of their settings is exactly 2.  

That means:  
- If one is 1, the other must be 2.  
- If one is 2, the other must be 1.  

So this is a **bipartite graph** problem:  
- Color one side with 1, the other side with 2.  
- If the graph is not bipartite, output NO.  
- If it is bipartite, we need the lexicographically smallest assignment.  

To get lexicographically smallest:  
- We can try to assign 1 to node 1 if possible, then propagate.  
- If a conflict occurs, try assigning 2 to node 1 and propagate.  
- If both fail, output NO.  

We’ll use BFS/DFS for coloring.  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

def try_color(start_color):
    color = [-1] * n
    color[0] = start_color
    q = deque([0])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                return None
    # If some nodes are disconnected, color them with 1 if possible
    for i in range(n):
        if color[i] == -1:
            color[i] = 1
            q = deque([i])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = 1 - color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        return None
    return color

# Try starting with 1
res = try_color(1)
if res is None:
    res = try_color(0)
if res is None:
    print("NO")
else:
    print("YES")
    print(" ".join(str(c + 1) for c in res))
```
