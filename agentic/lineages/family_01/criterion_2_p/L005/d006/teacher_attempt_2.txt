# Problem B — Orbital Platform Balance

Time limit: 1 s   Memory limit: 256 MB

An orbital platform consists of $n$ storage modules. The platform contains $m$ load-bearing struts, each connecting a specific pair of modules.

To maintain perfect structural balance, engineers must configure the internal pressure state of each module. Every module must be permanently pressurized to a state of either 1 or 2.

When a strut connects two modules $u$ and $v$, it creates an acoustic resonance based on their pressure states $p_u$ and $p_v$. For the strut to properly bear the load without buckling, this resonance, calculated exactly as $p_u^{p_v} + p_v^{p_u}$, must equal 3.

You must determine a pressure state for all modules that ensures every strut safely bears its load. If the platform cannot be configured under these rules, indicate that it is impossible.

## Input
The first line provides $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), the number of modules and struts, respectively.
The following $m$ lines each contain two integers $u$ and $v$ — a pair of modules connected by a strut.

## Output
If the platform cannot be configured safely, output NO on a single line.
If it can, output YES on the first line. On the second line, output $n$ integers $p_1 \dots p_n$ (each in {1,2}), representing the lexicographically smallest valid sequence of pressure states for modules $1$ through $n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

The previous statement explicitly asked for the sum of two states to be exactly 3, which trivially pattern-matches to standard 2-coloring where models immediately deploy a component-wise BFS/DFS. I changed the constraint to the algebraic expression $p_u^{p_v} + p_v^{p_u} = 3$. This forces the model to algebraically deduce that connected nodes must have different states, breaking the immediate pattern-match that trivially leads to a full-graph traversal.
</RATIONALE>
<PRESERVED_ANSWER>
The equation $p_u^{p_v} + p_v^{p_u} = 3$ for $p \in \{1, 2\}$ is satisfied if and only if one variable is 1 and the other is 2, which is exactly equivalent to the original requirement that their sum is 3, leaving all valid assignments and the lexicographical tie-breaker identical.
</PRESERVED_ANSWER>
