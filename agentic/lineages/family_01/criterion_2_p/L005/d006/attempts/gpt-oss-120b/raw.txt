**Solution Explanation**

For a critical pair `{u , v}` the matrix  

```
S = | 0  x  y |
    | x  0  0 |
    | y  0  0 |
```

has eigenvalues `0 , ± sqrt(x² + y²)`.  
The required largest eigenvalue is `√5`, therefore

```
x² + y² = 5
```

`x , y` can only be `1` or `2`.  
The only possibilities are `{1,2}` or `{2,1}`.  
Hence **the two machines of every critical pair must have different
calibration values**.

So the whole problem is exactly:

*Is the given graph bipartite?*  
If yes, output the lexicographically smallest 2‑colouring with colours
`1` and `2`.

--------------------------------------------------------------------

#### 1.   Bipartite check and component handling  

We run a BFS/DFS over all vertices.

* `col[v] = -1` – not visited yet  
* during the search we assign temporary colours `0` and `1`
  (the two sides of the bipartition).

If we ever need to give a vertex a colour different from the one already
stored, the graph is **not bipartite** → answer `NO`.

While exploring one connected component we store all its vertices in a
list `comp`. After the component is finished we know which vertices belong
to side `0` and which to side `1`.

--------------------------------------------------------------------

#### 2.   Lexicographically smallest colouring  

Inside a component we may flip the two sides:
* side `0` → value `1`, side `1` → value `2`
* or the opposite.

To obtain the smallest possible global sequence we look at the **smallest
vertex index of the component** (`min_v`).  
If we give `min_v` the value `1` the whole sequence becomes lexicographically
smaller than any solution where `min_v` receives `2` (all earlier positions
are identical).  
Therefore we simply choose the side that contains `min_v` to be colour `1`.

Implementation:

```
if min_v in side0:   # side0 is the list of vertices with temporary colour 0
        assign value 1 to side0, 2 to side1
else:
        assign value 1 to side1, 2 to side0
```

Processing components in any order works because the decision for each
component depends only on its own smallest vertex, which is the first
position where the two possible colourings differ.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `NO` iff no valid calibration exists,
otherwise prints `YES` and the lexicographically smallest calibration.

---

##### Lemma 1  
For a pair `{u,v}` the condition “largest eigenvalue of `S` equals `√5`”
holds **iff** `u` and `v` receive different values (one `1`, the other `2`).

**Proof.**  
From the determinant calculation in the statement we have eigenvalues
`0, ± sqrt(x²+y²)`.  
The largest eigenvalue is `sqrt(x²+y²)`.  
With `x,y ∈ {1,2}` the equality `sqrt(x²+y²)=√5` is equivalent to
`x²+y² = 5`. The only unordered pair of numbers from `{1,2}` satisfying this
is `{1,2}`. ∎



##### Lemma 2  
A calibration satisfying all pairs exists **iff** the graph is bipartite.

**Proof.**  
By Lemma&nbsp;1 every edge must connect vertices of different values,
exactly the definition of a proper 2‑colouring of the graph.
A graph admits a proper 2‑colouring ⇔ it is bipartite. ∎



##### Lemma 3  
For a bipartite connected component, among the two possible assignments of
values `1` and `2` to its two sides, the one that gives value `1` to the
smallest‑indexed vertex of the component is lexicographically smaller than
the other.

**Proof.**  
Both assignments are identical on all vertices whose index is smaller than
that smallest vertex (they belong to other components).  
At the smallest vertex `v` the two assignments differ: one gives `1`,
the other `2`. Since `1 < 2`, the assignment with `1` at `v` is lexicographically
smaller. ∎



##### Lemma 4  
The algorithm outputs the lexicographically smallest valid calibration
when the graph is bipartite.

**Proof.**  
The algorithm processes each connected component independently.
For a component it chooses exactly the assignment described in Lemma&nbsp;3,
hence the smallest possible values for that component given the already
fixed earlier vertices (which belong to other components).  
Induction over the components ordered by their smallest vertex index shows
that after handling the first *k* components the prefix of length
`max_index_of_these_components` is the smallest achievable among all
valid colourings. Adding the *(k+1)*‑st component with the rule of Lemma&nbsp;3
keeps the whole prefix minimal. After all components are processed the
entire sequence is minimal. ∎



##### Lemma 5  
If the algorithm prints `NO` then no valid calibration exists.

**Proof.**  
`NO` is printed only when during BFS an edge connects two vertices that
already have the same temporary colour. This is exactly a detection of an
odd cycle, i.e. the graph is not bipartite. By Lemma&nbsp;2 a valid
calibration would require bipartiteness, therefore none exists. ∎



##### Theorem  
The program

* prints `NO` iff the required calibration does not exist,
* otherwise prints `YES` and the lexicographically smallest calibration.

**Proof.**  
*If the program prints `NO`*: by Lemma&nbsp;5 the graph is not bipartite,
hence by Lemma&nbsp;2 no calibration exists.

*If the program prints `YES`*: the BFS never found a conflict, so the
graph is bipartite. Using the construction described, the program assigns
values `1` and `2` to the two sides of every component, therefore all edges
connect different values – a valid calibration (Lemma&nbsp;1).  
By Lemma&nbsp;4 this calibration is the lexicographically smallest one. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*BFS/DFS* visits each vertex once and each edge once.

```
Time   :  O(n + m)
Memory :  O(n + m)   (adjacency list + colour array + queue)
```

Both limits satisfy the constraints (`n,m ≤ 2·10⁵`).

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    col = [-1] * n          # temporary bipartite colour 0/1
    answer = [0] * n        # final values 1/2
    q = deque()

    for start in range(n):
        if col[start] != -1:
            continue
        # new component
        comp = []
        side0 = []
        side1 = []
        col[start] = 0
        q.append(start)
        while q:
            v = q.popleft()
            comp.append(v)
            if col[v] == 0:
                side0.append(v)
            else:
                side1.append(v)
            for to in adj[v]:
                if col[to] == -1:
                    col[to] = col[v] ^ 1
                    q.append(to)
                elif col[to] == col[v]:
                    print("NO")
                    return
        # decide which side gets value 1
        min_v = min(comp)
        if min_v in side0:
            for v in side0:
                answer[v] = 1
            for v in side1:
                answer[v] = 2
        else:
            for v in side1:
                answer[v] = 1
            for v in side0:
                answer[v] = 2

    print("YES")
    print(' '.join(map(str, answer)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input‑output format.
