We need to analyze the eigenvalue condition first.

For  
\[
S = \begin{pmatrix}
0 & x & y \\
x & 0 & 0 \\
y & 0 & 0
\end{pmatrix}
\]
the eigenvalues are \(0\) and \(\pm \sqrt{x^2 + y^2}\).

We require the largest eigenvalue to be exactly \(\sqrt{5}\), so:

\[
\sqrt{x^2 + y^2} = \sqrt{5} \quad\Rightarrow\quad x^2 + y^2 = 5
\]

Since \(x, y \in \{1, 2\}\), the only possibilities are:

- \(1^2 + 2^2 = 5\)  
- \(2^2 + 1^2 = 5\)

So each critical pair must have **different** modes: one is 1 and the other is 2.

Thus, the problem reduces to:  
We have a graph, and we must assign each vertex a value 1 or 2 such that every edge connects vertices of different values.  
That’s exactly a **bipartite graph** check and coloring.

If the graph is not bipartite → output NO.  
If it is bipartite → we need the lexicographically smallest assignment (with 1 < 2).  
We can do BFS/DFS coloring, starting with 1 for the smallest uncolored vertex each time.

---

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
