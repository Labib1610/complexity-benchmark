We need to assign each node a value of 1 or 2 such that for every edge (u, v), the product is exactly 2.  
That means one endpoint must be 1 and the other must be 2.  

So this is a **bipartite graph** problem:  
- If the graph is bipartite, we can color it with two colors (1 and 2).  
- If not, it’s impossible.  

We also need the **lexicographically smallest** assignment, so we try to assign 1 to as many early nodes as possible.  
We can do a BFS/DFS and assign colors greedily, starting with 1 for the first unvisited node.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]  # 1 -> 2, 2 -> 1
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
