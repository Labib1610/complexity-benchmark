# Problem B — Dual Protocol

Time limit: 1 s
Memory limit: 256 MB

The manufacturing plant is transitioning to a dual-protocol workflow. Every personnel member (numbered 1 through $n$) must be assigned exactly one protocol, designated as either 1 or 2.

The HR department has compiled $m$ friction reports. Each report identifies a pair of personnel members who cannot collaborate effectively. Consequently, any two individuals named together in a friction report must be assigned distinct protocols. 

Your objective is to find a valid protocol designation for all personnel. If it cannot be done, report the failure. Otherwise, if there are multiple valid ways to designate the protocols, output the sequence of designations (for personnel 1 to $n$) that is lexicographically smallest.

## Input
The first line provides the active personnel headcount $n$ and the total number of friction reports $m$. The facility requires at least one active personnel member, and its maximum safety capacity restricts the headcount to exactly two hundred thousand. The reporting database can hold a minimum of zero reports and a maximum of two hundred thousand reports.

Each of the subsequent $m$ lines contains two integers $u$ and $v$ — the ID numbers of the personnel involved in a single friction report.

## Output
If no valid protocol designation exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers (each either 1 or 2) representing the lexicographically smallest valid protocol designation sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

</RATIONALE>
