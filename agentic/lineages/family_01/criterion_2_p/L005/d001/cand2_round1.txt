<STATEMENT>
# Problem B — Safety Equilibrium

Time limit: 1 s
Memory limit: 256 MB

The facility was built with a maximum capacity of two hundred thousand personnel. It currently employs $n$ workers, where there is always at least one worker. The safety department has logged $m$ interaction events between pairs of workers, though it is possible for there to be zero events. Neither $n$ nor $m$ will ever exceed the facility's maximum capacity.

Each worker must be assigned a schedule code of either 1 or 2. When two workers are involved in an interaction event, they must share a specialized safety module. To maintain system equilibrium and avoid overloading the module, the product of the schedule codes of any two interacting workers must be exactly 2.

If there is no way to assign schedule codes to all workers such that every interaction event's requirement is met, the facility cannot operate safely.

## Input
The first line contains two integers $n$ and $m$.
Each of the following $m$ lines contains two integers $u$ and $v$, indicating an interaction event between the worker with ID $u$ and the worker with ID $v$. Workers are identified by integers from 1 to $n$.

## Output
If no valid assignment of schedule codes exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers representing the schedule codes for workers 1 through $n$. If multiple valid assignments exist, output the assignment that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the explicit requirement that interacting workers must be in "different shifts" with the algebraic constraint that the product of their schedule codes must be exactly 2. This forces the model to deduce that the constraint is equivalent to assigning distinct values, preventing simple pattern-matching on bipartite graph terminology. Bounds were also expressed indirectly via a facility capacity limit to satisfy the S07 strategy.
</RATIONALE>
<PRESERVED_ANSWER>
Since the only way to multiply two numbers from the set {1, 2} to get exactly 2 is if one is 1 and the other is 2, the pairwise constraint is logically identical to requiring different shifts.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) on an undirected graph, solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
