<STATEMENT>
# Problem B — Power Calibration

Time limit: 1 s
Memory limit: 256 MB

An industrial facility operates a network of $n$ automated machines. Each machine must be calibrated to a power mode of either 1 or 2.

The facility's safety system has identified $m$ critical pairs of machines. These pairs share a power bus, and their modes must be carefully balanced to prevent surges. 

For any critical pair with assigned modes $x$ and $y$, the pair's resonance factor is defined as $x^3 + y^3$. The total system resonance is the product of the resonance factors of all $m$ critical pairs. 

To comply with the safety protocol and prevent dangerous harmonic cascades, the total system resonance must be exactly $9^m$. 

Your task is to find a calibration for all $n$ machines that satisfies this requirement, or determine that no such calibration exists.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of machines and the number of critical pairs, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a critical pair of machines. Machines are numbered from $1$ to $n$.

## Output
If it is impossible to safely calibrate the machines, print NO on a single line.
Otherwise, print YES on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2\}$) representing the lexicographically smallest valid calibration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<METHOD_NAME>Global Prime Factorization Constraint</METHOD_NAME>
<METHOD_DESCRIPTION>Replaced the local matrix eigenvalue constraint with a global product of polynomials (x^3 + y^3). The target product is 9^m, which by prime factorization forces every pair to evaluate to 9, meaning one must be 1 and the other 2. This completely removes the local evaluation affordance and forces a number-theoretic deduction.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<RATIONALE>
Models previously recognized that the largest eigenvalue of the given matrix evaluated to `sqrt(x^2 + y^2)`, and its equality to `sqrt(5)` trivially meant `x != y`, prompting a bipartite check. By changing this to a global product constraint equal to `9^m`, the local evaluation affordance is removed. Models must now use prime factorization logic (since 1^3+1^3=2 and 2^3+2^3=16 introduce prime factors of 2, which cannot divide 9^m) to deduce that every edge must be assigned (1, 2).
</RATIONALE>
<PRESERVED_ANSWER>
The product of m factors chosen from {2, 9, 16} can only equal 9^m if every single factor is exactly 9, which requires {x, y} = {1, 2} for every critical pair, perfectly preserving the exact same valid assignments as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying constraint remains exactly "endpoints of every critical pair must be different," making it identical to 2-coloring a graph, which is solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might theoretically struggle with the empty product convention if m=0, though standard mathematical definitions dictate it equals 1 (which correctly matches 9^0).
</RISK>
