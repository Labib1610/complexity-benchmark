# Problem B — Configuration Certification

Time limit: 1 s
Memory limit: 256 MB

An automated testing facility validates the configuration of $n$ interacting components. Each component must be assigned a configuration mode of either 1 or 2.

The facility's certification software checks $m$ critical pairs of components. For any critical pair, the software requires the modes to pass a specific numerical check to be certified as safe. 

Specifically, if a critical pair is assigned modes $x$ and $y$, the certification software constructs the following $3 \times 3$ validation matrix $W$:
$$W = \frac{1}{9} \begin{pmatrix} 4x+4y & 5x+2y & 2x+5y \\ 5x+2y & 4x-8y & -2x-2y \\ 2x+5y & -2x-2y & -8x+4y \end{pmatrix}$$
This matrix formula is a fixed internal requirement of the testing protocol, and it is computed identically for every critical pair. The software certifies the pair if and only if the largest eigenvalue of $W$ is exactly $\sqrt{5}$.

Your task is to find a mode assignment for all $n$ components that passes this certification for all $m$ critical pairs, or determine that no such assignment exists. All constraints and required outputs remain exactly as specified below.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of components and the number of critical pairs, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a critical pair of components. Components are numbered from $1$ to $n$.

## Output
If it is impossible to assign modes such that all critical pairs are certified, print NO on a single line.
Otherwise, print YES on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2\}$) representing the valid assignment. If there are multiple valid assignments, output the one where the sequence $(c_1, c_2, \dots, c_n)$ is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The models sidestepped the intended graph reduction because the sparse matrix made its characteristic polynomial trivially recognizable, exposing the hidden x^2+y^2=5 condition. By applying an orthogonal transformation, the matrix becomes dense but retains the exact same eigenvalues, forcing models to manually compute the characteristic polynomial of a 3x3 matrix to discover the bipartiteness constraint. The narrative was adjusted to frame the matrix as a formal software compliance check, satisfying the naturalness requirement (G4) by giving the math a plausible in-world justification.
</RATIONALE>
<PRESERVED_ANSWER>
The dense matrix W has exactly the same eigenvalues as the original matrix S for any x,y, so the condition that the largest eigenvalue is exactly sqrt(5) still uniquely forces x and y to be distinct values in {1, 2}, preserving all valid assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in O(n+m) time using BFS/DFS, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might fail to algebraically expand the characteristic polynomial of the dense matrix correctly, which is a desired difficulty increase in reasoning but could be perceived by some as tedious algebra rather than algorithmic insight.
</RISK>
