# Problem B — Molecular Assembly

Time limit: 1 s   Memory limit: 256 MB

A synthetic biology lab is designing a complex molecular structure using $n$ distinct protein building blocks, numbered 1 through $n$. Each block $i$ must be assigned a frequency multiplier $s_i$, which must be chosen from the set $\{1, 2\}$.

The lab has identified $m$ critical stability conditions based on spatial overlaps between certain pairs of blocks. Each condition is formulated as a strict mathematical requirement. Specifically, for each overlapping pair of blocks $u$ and $v$, their assigned frequency multipliers must satisfy the equation:
$s_u + s_v = 3$

Determine if there exists an assignment of frequency multipliers to all $n$ blocks such that all $m$ conditions are simultaneously satisfied. If no such assignment is possible, report impossibility. If multiple valid assignments exist, you must output the one that is lexicographically smallest as a sequence $s_1, s_2, \dots, s_n$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that blocks $u$ and $v$ are subject to the condition $s_u + s_v = 3$.

## Output
If no valid assignment exists, print a single line containing NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was reframed from assigning distinct chiral states to interacting pairs (which strongly cues graph coloring) to solving a system of pairwise linear equations ($s_u + s_v = 3$) over a restricted domain. This removes the obvious graph/edge-list affordance, forcing models to deduce that the algebraic constraint is equivalent to an inequality constraint and that the system can be efficiently resolved by traversing the constraint network rather than using algebraic solvers.
</RATIONALE>
<PRESERVED_ANSWER>
The equation $s_u + s_v = 3$ for variables restricted to $\{1, 2\}$ is algebraically identical to the requirement that $s_u \neq s_v$, meaning the set of valid assignments and the lexicographically smallest tie-breaker remain mathematically identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains exactly equivalent to evaluating bipartiteness and finding a lexicographically minimal 2-coloring of an undirected graph, which is solvable in O(n+m) time.
</PRESERVED_CLASS>
