We can model this as a graph coloring problem.  
For each edge (u, v), the condition is:

\[
x^2 + 3xy + y^2 = 11
\]

If we test possible values (1 or 2):

- (1,1): 1 + 3 + 1 = 5 → not valid  
- (1,2): 1 + 6 + 4 = 11 → valid  
- (2,1): 4 + 6 + 1 = 11 → valid  
- (2,2): 4 + 12 + 4 = 20 → not valid  

So each edge must connect two machines with **different modes** (one 1, one 2).  
That means the graph must be **bipartite**.

We can solve with BFS/DFS coloring.  
For lexicographically smallest, we assign 1 to the first uncolored node when starting a new component, and alternate.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
