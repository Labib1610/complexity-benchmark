<STATEMENT>
# Problem B — Orbital Platform Balance

Time limit: 1 s   Memory limit: 256 MB

An orbital platform consists of $n$ storage modules. The platform contains $m$ load-bearing struts, each connecting a specific pair of modules.

To maintain perfect structural balance, engineers must configure the internal pressure of each module. Every module must be permanently pressurized to one of two levels: 1 atm or 2 atm.

For a structural strut to properly bear the load without buckling, the sum of the pressures in the two modules it connects must be exactly 3 atm. 

You must determine a pressure level for all modules that ensures every strut safely bears its load. If the platform cannot be configured under these rules, indicate that it is impossible.

## Input
The first line provides $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), the number of modules and struts, respectively.
The following $m$ lines each contain two integers $u$ and $v$ — a pair of modules connected by a strut.

## Output
If the platform cannot be configured safely, output NO on a single line.
If it can, output YES on the first line. On the second line, output $n$ integers $p_1 \dots p_n$ (each in {1,2}), representing the lexicographically smallest valid sequence of pressure levels for modules $1$ through $n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The scenario was changed from a power grid requiring "different phase alignments" to an orbital platform where pressure levels must sum to exactly 3. This forces the model to algebraically deduce that $p_u + p_v = 3$ for $p_i \in \{1, 2\}$ implies $p_u \neq p_v$, removing the immediate linguistic trigger for "bipartite coloring" while preserving the exact mathematical constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The domain of valid assignments for each module remains {1, 2}, and the condition that their sum equals 3 is strictly logically equivalent to requiring them to be different, meaning the set of valid configurations and the lexicographically smallest sequence are strictly identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains structurally identical to 2-coloring a graph (bipartiteness testing) and finding the lexicographically smallest coloring, which is solvable in O(n+m) time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
Models might be confused by the physical unit "atm" and attempt to treat the problem as continuous or involving real numbers, but the statement explicitly restricts the pressures to "one of two levels: 1 atm or 2 atm" and the output to "integers ... each in {1,2}", making the discrete nature unambiguous.
</RISK>
