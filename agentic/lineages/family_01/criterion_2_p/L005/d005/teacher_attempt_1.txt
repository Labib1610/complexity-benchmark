# Problem B — Noise Cancellation Array

Time limit: 1 s
Memory limit: 256 MB

A radio telescope facility operates an array of satellite dishes. The facility's power grid allocates a strict budget of two hundred thousand hardware ports, which serves as the absolute upper limit for the number of dishes. The array will always have at least one dish installed. The system also maintains synchronization channels between specific pairs of dishes. The central routing switch can handle up to two hundred thousand active channels, though it is possible to have zero.

To filter out atmospheric interference, the engineers must calibrate the signal processor of each dish. Every dish must be assigned a calibration mode, which must be chosen as exactly 1 or 2.

The synchronization channels act as interference filters. For a channel to successfully cancel out background noise, the sum of the calibration modes of the two dishes it connects must be exactly 3.

You must determine a valid calibration mode for all dishes in the array. If no such assignment is possible under these rules, indicate that it is impossible.

## Input
The first line provides $n$ and $m$, the actual number of dishes and channels, respectively. The bounds for these values are defined by the facility's physical limits described above.
The following $m$ lines each contain two integers $u$ and $v$ — a pair of dishes (identified by integers from $1$ to $n$) connected by a synchronization channel.

## Output
If the array cannot be correctly calibrated, output `NO` on a single line.
If it can, output `YES` on the first line. On the second line, output $n$ integers $r_1 \dots r_n$ (each being 1 or 2), representing the lexicographically smallest valid sequence of calibration modes for dishes $1$ through $n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
