We need to assign each machine a value of 1 or 2.  
For each edge (u, v), the token is `c_u | c_v`.  
The sum of all tokens must equal `3m`.

Since values are only 1 or 2:

- If both are 1 → token = 1  
- If one is 1 and the other is 2 → token = 3  
- If both are 2 → token = 2  

We need the sum of tokens over all edges to be exactly `3m`.  
That means every edge must produce a token of 3.  
So for every edge, one endpoint must be 1 and the other must be 2.

Thus, the graph must be bipartite, with machines in one part set to 1 and the other part set to 2.

We also need the lexicographically smallest assignment.  
That means we try to assign as many 1s as possible at the start, so we do a BFS/DFS coloring starting with 1 for the first uncolored node, and alternate.

If the graph is not bipartite, output NO.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
