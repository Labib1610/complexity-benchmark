**Solution Explanation**

For every vertex we have to choose a value `1` or `2`.
For an edge `{u,v}` the token is  

```
token = value[u] OR value[v]
```

`1 = 01₂ , 2 = 10₂`.  
The possible results of the OR are

| value[u] | value[v] | OR |
|----------|----------|----|
| 1        | 1        | 1 |
| 2        | 2        | 2 |
| 1        | 2        | 3 |
| 2        | 1        | 3 |

The required total sum is `3·m`.  
Therefore **every edge must give token = 3**, i.e. its ends must have
different values.  
So we have to 2‑colour the whole graph (a proper bipartition) and output the
lexicographically smallest colour assignment (`1 < 2`).

--------------------------------------------------------------------

#### 1.   Bipartite test and component data

We run BFS/DFS over all vertices.

* `col[v] = 0/1` – temporary colour inside the component.
* While traversing we detect a conflict (`col[neighbor]` already set to the
  same colour) → the graph is **not bipartite** → answer `NO`.

For each connected component we store

* `nodes0` – vertices with temporary colour `0`
* `nodes1` – vertices with temporary colour `1`
* `min_vertex` – the smallest index inside the component
* `min_colour` – temporary colour of `min_vertex`

All this is collected during the BFS, O(number of vertices + edges).

--------------------------------------------------------------------

#### 2.   Lexicographically smallest final colours

Inside one component we may keep the temporary colours as they are
(`0 → 1 , 1 → 2`) **or** swap them (`0 → 2 , 1 → 1`).
Only the orientation matters.

The first (smallest) vertex of the component is `min_vertex`.
To obtain the smallest possible whole array we must give this vertex the
value `1` (if we could give it `2`, the array would be larger at the first
different position).  
Thus we choose the orientation that maps `min_colour` to `1`.

Implementation:

```
if min_colour == 0:
        colour 0 -> 1 , colour 1 -> 2
else:
        colour 1 -> 1 , colour 0 -> 2
```

Isolated vertices are a component of size 1, `min_colour = 0`,
so they become `1` – also optimal.

Processing components independently yields the globally lexicographically
smallest assignment, because the first position where two possible global
assignments differ belongs to the component whose smallest vertex is that
position, and we have already forced this vertex to be `1`.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `YES` and the lexicographically smallest
valid assignment iff such an assignment exists.

---

##### Lemma 1  
If the algorithm outputs `YES`, every edge connects vertices with different
final values.

**Proof.**  
During BFS we ensured the graph is bipartite, i.e. for each edge the
temporary colours differ. The final values are obtained from the temporary
colours by either keeping the order or swapping it inside each component.
Both operations preserve the property “different temporary colours ⇒
different final values”. ∎



##### Lemma 2  
If the algorithm outputs `YES`, the sum of all tokens equals `3·m`.

**Proof.**  
By Lemma&nbsp;1 each edge has endpoints with different values, therefore its
OR is `3`. Summing over the `m` edges gives `3·m`. ∎



##### Lemma 3  
If the input graph is not bipartite, no assignment satisfies the required
sum.

**Proof.**  
Assume an assignment satisfies the sum. Then every edge must have OR = 3,
hence its ends have different values, i.e. the graph is properly 2‑coloured.
A non‑bipartite graph cannot be 2‑coloured – contradiction. ∎



##### Lemma 4  
For a bipartite connected component, among the two possible orientations the
one chosen by the algorithm (making the smallest‑indexed vertex equal to `1`)
is lexicographically smaller than the other orientation.

**Proof.**  
Both orientations are identical on all vertices except that they swap the
values `1` and `2`. The smallest index where they differ is exactly the
component’s smallest vertex `v`. The algorithm gives `v` value `1`,
the other orientation gives `2`. Since `1 < 2`, the algorithm’s orientation
is lexicographically smaller. ∎



##### Lemma 5  
The whole array produced by the algorithm is the lexicographically smallest
valid assignment.

**Proof.**  
Consider any other valid assignment `A`. Scan vertices from `1` to `n`.
Let `p` be the first position where `A` and the algorithm’s array differ.
Vertex `p` belongs to some component `C`. All vertices `< p` are equal in
both arrays, therefore the orientation of `C` in `A` must differ from the
algorithm’s orientation (otherwise they would coincide on `p`).  
By Lemma&nbsp;4 the algorithm’s orientation gives vertex `p` value `1`,
while `A` gives `2`. Hence the algorithm’s array is lexicographically
smaller than `A`. ∎



##### Lemma 6  
If the graph is bipartite, the algorithm always produces a valid assignment.

**Proof.**  
BFS succeeds (no conflict). For each component we output values according to
the orientation fixed in Lemma&nbsp;4, which is a proper 2‑colouring.
Thus by Lemma&nbsp;2 the sum condition holds. ∎



##### Theorem  
The algorithm prints  

* `NO` iff no calibration satisfying the condition exists;  
* otherwise `YES` and the lexicographically smallest calibration.

**Proof.**  

*If the algorithm prints `NO`.*  
That happens only when a conflict is found, i.e. the graph is not bipartite.
By Lemma&nbsp;3 no solution exists.

*If a solution exists.*  
Then the graph is bipartite. The algorithm does not encounter a conflict,
outputs `YES`, and by Lemma&nbsp;6 the produced assignment is valid.
By Lemma&nbsp;5 it is the lexicographically smallest among all valid
assignments.

Thus the statements hold in both directions. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*BFS over all vertices and edges*: `O(n + m)` time, `O(n + m)` memory for
adjacency lists, colour array and component data.  
All other steps are linear in the size of the components.  

Both limits satisfy the problem constraints (`n,m ≤ 2·10⁵`).

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    col = [-1] * (n + 1)          # temporary 0/1 colours
    answer = [0] * (n + 1)        # final values 1/2
    visited = [False] * (n + 1)

    for start in range(1, n + 1):
        if visited[start]:
            continue
        # BFS this component
        q = deque([start])
        col[start] = 0
        visited[start] = True
        nodes0 = []
        nodes1 = []
        min_vertex = start
        min_colour = 0

        while q:
            v = q.popleft()
            if col[v] == 0:
                nodes0.append(v)
            else:
                nodes1.append(v)
            if v < min_vertex:
                min_vertex = v
                min_colour = col[v]
            for nb in adj[v]:
                if not visited[nb]:
                    visited[nb] = True
                    col[nb] = col[v] ^ 1
                    q.append(nb)
                else:
                    if col[nb] == col[v]:
                        print("NO")
                        return

        # decide orientation: make min_vertex value 1
        if min_colour == 0:
            for v in nodes0:
                answer[v] = 1
            for v in nodes1:
                answer[v] = 2
        else:
            for v in nodes0:
                answer[v] = 2
            for v in nodes1:
                answer[v] = 1

    # output
    print("YES")
    print(' '.join(str(answer[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```

to the required input‑output format.
