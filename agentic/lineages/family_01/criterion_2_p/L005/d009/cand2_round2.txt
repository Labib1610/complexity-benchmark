<STATEMENT>
# Problem B — System Calibration

Time limit: 1 s
Memory limit: 256 MB

An industrial facility manages a network of $n$ automated machines and a safety log of $m$ critical pairs. There is at least one machine, up to a physical infrastructure limit of two hundred thousand machines. The safety log may be empty, or contain up to a maximum capacity of two hundred thousand pair entries.

Each machine must be assigned a state of either 1 or 2.

The safety protocol dictates a strict local stability requirement. For every machine $i$ that appears at least once in the log, consider the sequence of states of the machines it is paired with (counting each time a pair involving machine $i$ appears in the log). The arithmetic mean of this sequence of partner states, when added to the state of machine $i$ itself, must equal exactly 3.

Your task is to find an assignment of states for all $n$ machines that satisfies this requirement, or determine that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$, representing the number of machines and the number of critical pair entries, respectively. 
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a critical pair in the log. Machines are numbered from $1$ to $n$.

## Output
If it is impossible to safely assign the states, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2\}$) representing the valid assignment. If there are multiple valid assignments, output the one that is lexicographically smallest (i.e., the sequence that has the smaller value at the first index where they differ).

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The numeric bounds are now spelled out as physical and storage capacities (Strategy S07), requiring the model to extract them from text rather than inequalities. The core constraint has been mathematically reframed: instead of a total sum equation, it uses the arithmetic mean of partner states. Because states are restricted to {1, 2}, a mean plus the machine's own state equaling 3 algebraically forces every partner to have the opposite state. This preserves the exact mechanics of bipartiteness testing while removing the specific algebraic signature the models previously recognized. Multiplicity of pairs is explicitly handled to ensure exact equivalence with the seed.
</RATIONALE>
<PRESERVED_ANSWER>
The arithmetic mean condition exactly forces adjacent machines to have opposite states (if a machine is 1, its mean partner state must be 2, forcing all partners to be 2; and vice versa), which perfectly matches the seed's sum condition, including handling of multi-edges, self-loops, and isolated vertices.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph (or detecting an odd cycle), which is solved in O(n+m) time using BFS/DFS, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "arithmetic mean" as requiring floating-point output or continuous states, though the text explicitly restricts states to {1, 2} and states the mean plus the machine's state must exactly equal 3.
</RISK>
