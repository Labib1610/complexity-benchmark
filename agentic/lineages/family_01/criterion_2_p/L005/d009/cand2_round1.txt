<METHOD_NAME>Global Cut-Size Obfuscation via Local Stability Scores</METHOD_NAME>
<METHOD_DESCRIPTION>Transforms the local bipartite constraint (neighbors must have different colors) into a global sum constraint. By defining a local "stability score" for each vertex that algebraically expands to the sum of squared differences along its incident edges, the total system score evaluates to exactly the size of the cut. Requiring this sum to equal m strictly enforces proper 2-coloring. Models typically fail to symbolically reduce this global sum back into a local edge constraint, causing them to abandon BFS 2-coloring in favor of generic (and hopelessly slow) solvers.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Power Calibration

Time limit: 1 s
Memory limit: 256 MB

An industrial facility operates a network of $n$ automated machines. The facility's safety system has identified $m$ critical pairs of machines that share a power bus.

Each machine must be calibrated to a power mode of either 1 or 2. We denote the chosen power mode for machine $i$ as $c_i \in \{1, 2\}$.

For each machine $i$, let $k_i$ be the total number of critical pairs that include machine $i$. The safety system calculates a local stability score $v_i$ for each machine using the following formula:

$$v_i = c_i \times \left( c_i k_i - \sum c_j \right)$$

where the sum is taken over the power modes $c_j$ of the machines paired with machine $i$ across all $k_i$ of its critical pairs.

To comply with the safety protocol and prevent dangerous harmonic cascades, the total system stability score—defined as the sum of $v_i$ for all $n$ machines—must equal exactly $m$.

Your task is to find a calibration for all $n$ machines that satisfies this requirement, or determine that no such calibration exists.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of machines and the number of critical pairs, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a critical pair of machines. Machines are numbered from $1$ to $n$.

## Output
If it is impossible to safely calibrate the machines, print NO on a single line.
Otherwise, print YES on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2\}$) representing the lexicographically smallest valid calibration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Removed the local vertex-neighborhood equation and replaced it with a global sum constraint over locally computed "stability scores". This forces the model to perform a non-trivial algebraic reduction (recognizing that the sum of these scores equals the size of the cut) to discover the underlying bipartite structure, defeating surface-level pattern matching to 2-coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The total stability score algebraically simplifies to the number of edges with differently assigned endpoints; requiring it to equal the total number of edges m is mathematically equivalent to requiring a proper 2-coloring, preserving all valid assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in O(n+m) time using Breadth-First Search.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the sum over c_j as being over distinct neighbors rather than over all critical pairs (which matters only for multigraphs, but standard CP conventions and the phrase "across all k_i of its critical pairs" resolve this).
</RISK>
