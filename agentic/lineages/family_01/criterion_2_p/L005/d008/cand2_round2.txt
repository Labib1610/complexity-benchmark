# Problem B — Power Calibration

Time limit: 1 s
Memory limit: 256 MB

A manufacturing plant controls a grid of $n$ heavy-duty machines. Each machine requires a baseline operational setting, which must be chosen as either 1 or 2.

The plant's engineers have mapped out $m$ sensitive connections between specific pairs of machines that draw from the same electrical junction. To maintain grid stability, the settings across these connections must be strictly regulated.

For any sensitive connection between two machines operating at settings $x$ and $y$, the connection's structural stress is calculated using the formula $(x+3)^y + (y+3)^x$. The cumulative stress on the grid is the product of the structural stress values from all $m$ sensitive connections.

Safety regulations mandate that the cumulative stress on the grid must equal exactly $21^m$ to avoid a catastrophic overload. 

You must determine a valid operational setting for every machine in the grid that meets this safety regulation, or report that it is impossible.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of machines and the number of sensitive connections.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), identifying a pair of machines that share a sensitive connection. Machines are indexed from $1$ to $n$.

## Output
If no safe configuration exists, output NO on a single line.
Otherwise, output YES on the first line. On the second line, output $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2\}$) representing the lexicographically smallest valid sequence of operational settings.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

The models were succeeding by instantly recognizing the $x^3+y^3=9$ arithmetic cue as a standard encoding for $x \neq y$ (2-coloring). I replaced this with the formula $(x+3)^y + (y+3)^x$ and a target product of $21^m$. Because the possible values for $x, y \in \{1, 2\}$ are 8, 21, and 50, unique prime factorization guarantees the global product can only be $21^m$ if every single connection evaluates to 21 (i.e., $x \neq y$). This forces the models to genuinely evaluate the new function over the domain rather than pattern-matching a known shortcut.
</RATIONALE>
