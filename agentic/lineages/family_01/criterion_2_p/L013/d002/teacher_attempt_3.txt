# Structural Dampening

Time limit: 1 s
Memory limit: 256 MB

A new architectural design relies on $n$ load-bearing pillars. To manage structural vibrations, each pillar must be fitted with a dampener. The inventory only contains dampeners of size 1 and size 2.

The framework's stability is tested by $m$ horizontal cross-beams. Each cross-beam rests on a specific pair of pillars. For a cross-beam to remain perfectly level and absorb vibrations correctly, the total size of the dampeners on its two supporting pillars must equal exactly 3. If the combined size is 2 or 4, the cross-beam will tilt, causing the structural inspection to fail.

You must determine if there is a valid assignment of dampener sizes to all $n$ pillars such that every cross-beam remains level. If there are multiple valid ways to outfit the pillars, the architectural guidelines dictate choosing the configuration that yields the lexicographically smallest sequence of dampener sizes (meaning the sequence $s_1, s_2, \dots, s_n$ is minimized element by element, starting with the first pillar).

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that a cross-beam rests on pillar $u$ and pillar $v$.

## Output
If no valid dampener assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being 1 or 2) representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
