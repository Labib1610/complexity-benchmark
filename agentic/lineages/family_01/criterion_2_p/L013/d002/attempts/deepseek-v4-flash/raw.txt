We need to assign each node either 1 or 2 such that for every edge (u, v), the bitwise AND of their values is 0.  

Since the only allowed values are 1 and 2:  
- 1 in binary is `01`  
- 2 in binary is `10`  
Their AND is 0 only if one is 1 and the other is 2.  
So the problem reduces to:  
- Color the graph with two colors (1 and 2) such that adjacent nodes have different colors.  
This is exactly checking if the graph is bipartite.  

If it’s not bipartite, output `NO`.  
If it is, we need the lexicographically smallest assignment.  
We can do BFS/DFS, assigning 1 to the first node, then alternate.  
But to get lexicographically smallest, we should try to assign 1 whenever possible, which means we process nodes in order and if a node is uncolored, assign 1 and BFS from there.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]  # 1 -> 2, 2 -> 1
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
