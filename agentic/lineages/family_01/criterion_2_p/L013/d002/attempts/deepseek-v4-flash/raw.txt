 We need to assign each field either 1 or 2 such that for every edge (u, v), one endpoint is exactly twice the other.  
That means the only allowed pairs are (1, 2) or (2, 1).  
So the graph must be bipartite, with one side having value 1 and the other side having value 2.

We also need the lexicographically smallest assignment.  
That means we should try to assign 1 to as many early nodes as possible, which suggests a BFS/DFS coloring where we prefer 1 when possible.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start):
    q = deque([start])
    color[start] = 1  # try 1 first
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 3 - color[u]  # alternate 1 <-> 2
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        if not bfs(i):
            print("NO")
            sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
