**Solution Explanation**

For every comparator (edge) the two linked fields must have different
positions and the larger one has to be `2`.
With only the values `1` and `2` this means:

* for each edge `{u,v}` we need `{s_u , s_v} = {1,2}`.

So the whole graph has to be **bipartite** – we can colour every vertex
with colour `0` or `1` such that adjacent vertices have different colours.
After a bipartition is found we may decide which colour receives the value
`1` and which receives `2`.

--------------------------------------------------------------------

#### Lexicographically smallest assignment  

Consider one connected component.
If we flip the whole component (exchange the meaning of colour `0` and `1`)
the set of feasible assignments does not change.
To obtain the lexicographically smallest global sequence we process the
vertices in increasing order `1 … n`.

When we meet the first vertex `i` of a still unprocessed component,
we are free to choose the orientation of this component.
Choosing the colour of `i` to be `1` makes the whole prefix
`[s_1 … s_i]` as small as possible, because any other orientation would give
`s_i = 2` while all earlier positions are already fixed.
Therefore the optimal rule is:

* for each component, orient it so that its smallest‑index vertex gets value `1`.

--------------------------------------------------------------------

#### Algorithm
```
read n, m
build adjacency list
colour[1…n] = -1          # -1 = unvisited, 0/1 = bipartite colour
answer[1…n] = 0

for v = 1 … n:
    if colour[v] == -1:
        # start a new component, BFS
        queue = [v]
        colour[v] = 0
        comp0 = []          # vertices with colour 0
        comp1 = []          # vertices with colour 1
        while queue not empty:
            x = pop queue
            if colour[x] == 0: comp0.append(x)
            else:               comp1.append(x)
            for each neighbour y of x:
                if colour[y] == -1:
                    colour[y] = colour[x] ^ 1
                    push y
                elif colour[y] == colour[x]:
                    print "NO" and exit   # not bipartite

        # orient the component:
        # the start vertex v is the smallest index in this component
        # (because we iterate v increasingly)
        # give colour 0 (the colour of v) value 1, colour 1 value 2
        for x in comp0: answer[x] = 1
        for x in comp1: answer[x] = 2

print "YES"
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` iff no feasible configuration
exists, otherwise prints `YES` and the lexicographically smallest one.

---

##### Lemma 1  
If the algorithm prints `NO`, the graph is not bipartite, therefore no
assignment satisfies all comparators.

**Proof.** `NO` is printed only when during BFS an edge connects two vertices
with the same colour. That is exactly the definition of a non‑bipartite
graph. Any assignment must give different values to the two ends of this
edge, which is impossible with only two values. ∎



##### Lemma 2  
If the graph is bipartite, the algorithm finishes without printing `NO`
and produces a valid assignment.

**Proof.** In a bipartite graph a BFS can colour every vertex with `0/1`
without conflict, so the conflict test never triggers.
For each edge `{u,v}` the BFS guarantees `colour[u] ≠ colour[v]`.
The algorithm finally sets all vertices of colour `0` to value `1`
and colour `1` to value `2`. Hence each edge connects a `1` with a `2`,
exactly the required condition. ∎



##### Lemma 3  
For each connected component the algorithm assigns value `1` to the
smallest‑index vertex of that component.

**Proof.** Components are started when the outer loop reaches the first
(unvisited) vertex `v`. Because the loop runs in increasing order,
`v` is the smallest index in its component.
During BFS `v` receives colour `0`. Afterwards the algorithm gives colour
`0` the value `1`. Thus `s_v = 1`. ∎



##### Lemma 4  
Among all feasible assignments, the one produced by the algorithm is
lexicographically minimal.

**Proof.** Consider the first position `i` where two feasible assignments
differ. Let `C` be the component containing `i`. All vertices with index
`< i` belong to components already processed, therefore they have the same
value in every feasible assignment (by Lemma&nbsp;3 they must be `1`).  
Inside component `C` there are exactly two possible orientations:
either the colour of `i` gets value `1` or value `2`.  
The algorithm chooses the orientation with value `1` for `i`
(Lemma&nbsp;3). Hence any other feasible assignment has `s_i = 2`,
so its prefix up to `i` is lexicographically larger.
Thus no feasible assignment is lexicographically smaller than the algorithm’s
output. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no stable configuration exists;  
* otherwise `YES` and the lexicographically smallest stable configuration.

**Proof.**  
*If the algorithm prints `NO`*: by Lemma&nbsp;1 no configuration exists.  

*If the algorithm prints `YES`*: the graph is bipartite, Lemma&nbsp;2 gives a
valid configuration, and Lemma&nbsp;4 shows it is the lexicographically
smallest one.  

Conversely, if a configuration exists the graph must be bipartite,
so the algorithm never encounters a conflict and therefore prints `YES`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once → `O(n + m)`.  
*Overall*: `O(n + m)` time, `O(n + m)` memory, well within the limits
(`n, m ≤ 2·10⁵`).

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 unvisited, 0/1 bipartite colour
    ans = [0] * (n + 1)

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp0 = []
        comp1 = []
        while q:
            x = q.popleft()
            if colour[x] == 0:
                comp0.append(x)
            else:
                comp1.append(x)
            for y in adj[x]:
                if colour[y] == -1:
                    colour[y] = colour[x] ^ 1
                    q.append(y)
                elif colour[y] == colour[x]:
                    print("NO")
                    return
        # orient: colour of start (0) gets value 1
        for v in comp0:
            ans[v] = 1
        for v in comp1:
            ans[v] = 2

    # all done
    out = ["YES", " ".join(str(ans[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
