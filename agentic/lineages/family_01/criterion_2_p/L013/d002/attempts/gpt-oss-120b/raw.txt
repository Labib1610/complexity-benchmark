**Solution Explanation**

For every flagged pair `{u , v}` we must have  

```
vehicle(u) + vehicle(v) = 3
```

The only possible values are `1` and `2`, therefore the condition is exactly

```
vehicle(u) != vehicle(v)
```

So the assets and the flagged pairs form an undirected graph that has to be
**bipartite**.  
If the graph is not bipartite the answer is `NO`.

If it is bipartite we have to output the lexicographically smallest
`1/2`‑string among all proper colourings.
For a connected component there are exactly two colourings – the two sides of
the bipartition can be swapped.
Let `c` be the smallest vertex index inside the component.
Choosing the side that contains `c` to be colour `1` makes the whole string
as small as possible, because all earlier positions ( `< c` ) belong to
previous components already fixed, and at position `c` we obtain the smallest
possible digit (`1` instead of `2`).  
Doing this for every component yields the globally lexicographically minimal
assignment.

--------------------------------------------------------------------

#### Algorithm
```
read n, m
build adjacency list

colour[1…n] = -1          # -1 = unvisited, 0 / 1 = two sides of bipartition
answer[1…n] = 0

for v = 1 … n:
    if colour[v] != -1: continue
    # start a new component
    stack = [v]
    colour[v] = 0
    component = []        # vertices of this component
    min_vertex = v

    while stack not empty:
        x = stack.pop()
        component.append(x)
        if x < min_vertex: min_vertex = x
        for each neighbour y of x:
            if colour[y] == -1:
                colour[y] = colour[x] ^ 1
                stack.append(y)
            elif colour[y] == colour[x]:
                print "NO" and exit   # not bipartite

    # decide orientation: side containing min_vertex gets vehicle 1
    side_of_min = colour[min_vertex]          # 0 or 1
    for u in component:
        if colour[u] == side_of_min:
            answer[u] = 1
        else:
            answer[u] = 2

print "YES"
print answer[1] … answer[n] separated by spaces
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` iff no feasible assignment exists,
otherwise prints the lexicographically smallest feasible assignment.

---

##### Lemma 1  
During the DFS of a component the algorithm assigns colours `0/1` such that
adjacent vertices always receive opposite colours **iff** the component is
bipartite.

**Proof.**  
The DFS starts with an arbitrary vertex coloured `0`. Every time we traverse an
edge `(x, y)` we set `colour[y] = colour[x] xor 1`. If we ever encounter an
already coloured neighbour with the same colour, an odd cycle exists, i.e.
the component is not bipartite, and the algorithm detects it.  
Conversely, if the component is bipartite, a proper 2‑colouring exists; the
DFS exactly constructs one of them, never meeting a conflict. ∎



##### Lemma 2  
If the algorithm finishes without printing `NO`, the produced `answer`
satisfies all constraints.

**Proof.**  
By Lemma&nbsp;1 each component is bipartite and the DFS gave a proper
`0/1` colouring, i.e. every edge connects vertices of different colours.
The algorithm then maps one colour to vehicle `1` and the other to vehicle
`2`. Hence for every edge the two vehicles differ, i.e. sum to `3`. ∎



##### Lemma 3  
For a fixed component, among all feasible assignments the algorithm’s
assignment is lexicographically minimal on the positions belonging to this
component, assuming all earlier positions (indices `< min_vertex`) are already
fixed.

**Proof.**  
Let `c = min_vertex` be the smallest index in the component.
Any feasible assignment must give opposite vehicles to the two sides of the
bipartition. Exactly one of the two sides contains `c`.  
If we assign vehicle `2` to that side, the digit at position `c` becomes `2`,
while assigning vehicle `1` makes it `1`. Since `1 < 2`, the latter is
lexicographically smaller, and it does not affect earlier positions.
Thus the algorithm’s choice (vehicle `1` to the side of `c`) is optimal. ∎



##### Lemma 4  
Processing components in increasing order of their minimal vertex and applying
the rule of Lemma&nbsp;3 yields the globally lexicographically smallest feasible
assignment.

**Proof.**  
Consider the first index where two feasible assignments differ.
That index belongs to some component `C`. All earlier indices lie in components
with smaller minimal vertices, therefore they are identical in both assignments
by construction. Inside `C` the two assignments differ exactly on which side
gets vehicle `1`. By Lemma&nbsp;3 the algorithm chooses the side that gives the
smaller digit at the smallest index of `C`, i.e. the overall smallest possible
digit at the first differing position. Hence no other feasible assignment can
be lexicographically smaller. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no assignment satisfying all mandates exists;  
* otherwise `YES` and the lexicographically smallest assignment.

**Proof.**  

*If the algorithm prints `NO`.*  
That happens only when a component contains an edge whose endpoints received
the same colour, i.e. the component is not bipartite. A non‑bipartite graph
cannot be 2‑coloured, therefore no feasible assignment exists.

*If a feasible assignment exists.*  
Then every component is bipartite, so the DFS never meets a conflict and the
algorithm does not print `NO`. By Lemma&nbsp;2 the produced `answer` satisfies
all constraints. By Lemma&nbsp;4 it is the lexicographically smallest among
all feasible assignments. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*DFS over all vertices*: each vertex and edge is processed once → `O(n + m)`  
*Overall*: `O(n + m)` time, `O(n + m)` memory, well within the limits
(`n, m ≤ 2·10⁵`).

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 unvisited, 0/1 bipartite colours
    ans = [0] * (n + 1)

    stack = []
    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # new component
        component = []
        min_vertex = start
        colour[start] = 0
        stack.append(start)

        while stack:
            x = stack.pop()
            component.append(x)
            if x < min_vertex:
                min_vertex = x
            cx = colour[x]
            for y in adj[x]:
                if colour[y] == -1:
                    colour[y] = cx ^ 1
                    stack.append(y)
                elif colour[y] == cx:
                    sys.stdout.write("NO")
                    return

        side_of_min = colour[min_vertex]
        for v in component:
            ans[v] = 1 if colour[v] == side_of_min else 2

    out = ["YES\n", " ".join(str(ans[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
