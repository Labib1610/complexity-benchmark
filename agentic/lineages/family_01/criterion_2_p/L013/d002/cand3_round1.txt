# Problem B — Harmonic Oscillator Tuning

Time limit: 1 s   Memory limit: 256 MB

You are tuning a system of $n$ coupled oscillators. To establish a baseline resonance, each of the $n$ oscillators must be configured with a discrete frequency multiplier of either 1 or 2.

The system's overall stability is governed by $m$ harmonic interference constraints. Each constraint applies to a specific pair of oscillators. For the system to operate without destructive interference, the product of the frequency multipliers of the two oscillators involved in any given constraint must be exactly 2.

Determine if there exists a valid configuration of frequency multipliers for all $n$ oscillators that satisfies every harmonic interference constraint. If a valid configuration exists, provide it. If there are multiple valid configurations, you must output the one that is lexicographically smallest when expressed as a sequence of the $n$ multipliers.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of oscillators and the number of harmonic constraints. Oscillators are numbered from 1 to $n$.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a pair of oscillators subject to a harmonic constraint.

## Output
If no valid configuration exists that satisfies all constraints, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $f_1, f_2, \dots, f_n$ (where each $f_i \in \{1, 2\}$) representing the frequency multipliers for oscillators 1 through $n$. If there are multiple valid configurations, output the sequence that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
