# Magnetic Resonance Equilibrium

Time limit: 1 s
Memory limit: 256 MB

A particle accelerator must maintain equilibrium across $n$ magnetic containment fields. To achieve this, each field's calibration dial must be locked to a setting of either 1 or 2.

The system's integrity is monitored by $m$ load balancers. Rather than tracking individual fields, each balancer is wired to a specific pair of fields. If a balancer measures a difference of zero between the settings of its two assigned fields, it causes an immediate system halt. Stability is maintained only when every balancer detects a non-zero difference.

You must find a valid assignment of calibration settings to all $n$ fields such that no balancer destabilizes. In the event that several valid assignments are possible, the system defaults to the lexicographically smallest sequence of settings (meaning the sequence $s_1, s_2, \dots, s_n$ is minimized element by element, starting with the first field).

## Input
The first line contains two integers $n$ and $m$. The accelerator's infrastructure limits the total number of containment fields $n$ to a maximum of two hundred thousand, with at least one field required to operate. The wiring grid can support any non-negative number of load balancers $m$ up to a hard physical limit of two hundred thousand.

Each of the next $m$ lines contains two integers $u$ and $v$ (representing valid field identifiers between $1$ and $n$), indicating that a load balancer is wired to field $u$ and field $v$.

## Output
If no stable assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being 1 or 2) representing the lexicographically smallest stable configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit "sum of 3" constraint was replaced with the requirement that a balancer must detect a "non-zero difference" between the two fields it monitors. This forces the model to realize that, restricted to settings of 1 and 2, a non-zero difference is equivalent to the fields having strictly different values, without triggering the surface-level pattern recognition of algebraic sums equaling 3. Additionally, the numeric constraints in the input section were rewritten as physical limits of the facility, adhering to the S07 strategy.
</RATIONALE>
<PRESERVED_ANSWER>
A non-zero difference between two variables that can only take the values 1 or 2 means the variables must be assigned different values, which is mathematically identical to requiring their sum to be 3.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of an undirected graph, keeping it firmly in P.
</PRESERVED_CLASS>
