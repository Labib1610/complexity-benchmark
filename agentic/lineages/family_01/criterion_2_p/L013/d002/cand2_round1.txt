# Magnetic Resonance Equilibrium

Time limit: 1 s
Memory limit: 256 MB

A particle accelerator contains $n$ magnetic containment fields. Each field features a phase switch that must be set to position 1 or position 2. 

The accelerator is equipped with $m$ phase comparators. Each comparator links two specific fields and continuously monitors their switch positions. To maintain equilibrium, a comparator requires a strict harmonic ratio between its endpoints. It remains stable if and only if the switch position of one of its linked fields is exactly twice the switch position of the other. If the monitored fields fail to form this ratio, the comparator triggers a system halt.

Your task is to determine whether there is a switch configuration for all $n$ fields that keeps every comparator stable. If multiple such configurations exist, the safety override protocol requires the one that is lexicographically smallest (i.e., the sequence of switch positions $s_1, s_2, \dots, s_n$ must be as small as possible when compared element by element starting from the first field).

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that a phase comparator links field $u$ and field $v$.

## Output
If no stable configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being 1 or 2) representing the lexicographically smallest stable switch configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Models were pattern-matching the explicit listing of the two failure cases ("both 1" and "both 2") to immediately recognize a 2-coloring/bipartiteness constraint. I replaced this with a harmonic ratio rule ("one position is exactly twice the other") which mathematically evaluates to the exact same inequality constraint since the only valid positions are 1 and 2, forcing models to deduce the valid pairs before realizing it's a bipartite coloring problem.
</RATIONALE>
<PRESERVED_ANSWER>
The condition "one position is exactly twice the other" for variables restricted to {1, 2} is satisfied if and only if one variable is 1 and the other is 2, which exactly replicates the original logic where a comparator is stable only when its endpoints differ.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest valid 2-coloring of a graph, meaning it is still solvable in linear time using BFS/DFS.
</PRESERVED_CLASS>
