<STATEMENT>
# Magnetic Resonance Equilibrium

Time limit: 1 s
Memory limit: 256 MB

A particle accelerator contains $n$ magnetic containment fields. Each field features a phase switch that must be set to position 1 or position 2. 

The accelerator is equipped with $m$ phase comparators. Each comparator links two specific fields and continuously evaluates them using a two-step internal state cycle. At the start of a cycle, a comparator is in an 'Idle' state. It first processes the switch position of one of its linked fields: reading a position of 1 shifts the comparator into the 'Alpha' state, while reading a position of 2 shifts it into the 'Beta' state. It then processes the switch position of its other linked field. If the comparator is currently in the 'Alpha' state, reading a position of 1 shifts it into a 'Low-Halt' state, whereas reading a position of 2 shifts it into a 'Stable' state. Alternatively, if the comparator is in the 'Beta' state, reading a position of 1 shifts it into the 'Stable' state, whereas reading a position of 2 shifts it into a 'High-Halt' state. (Because the cycle's logic is symmetric, the order in which a comparator processes its two linked fields does not affect the final state).

Your task is to determine whether there is a switch configuration for all $n$ fields such that every comparator's cycle terminates in the 'Stable' state. If multiple such configurations exist, the safety override protocol requires the one that is lexicographically smallest (i.e., the sequence of switch positions $s_1, s_2, \dots, s_n$ must be as small as possible when compared element by element starting from the first field).

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that a phase comparator links field $u$ and field $v$.

## Output
If no stable configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being 1 or 2) representing the lexicographically smallest stable switch configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the direct rule that endpoints with the same position cause a halt with an indirect state-transition cycle. This forces the model to trace the state machine logic (which evaluates to "stable only if inputs are different") rather than immediately pattern-matching the description to bipartite graph inequality constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The state machine terminates in 'Stable' if and only if the two linked fields have different switch positions (1 and 2, or 2 and 1), which is mathematically identical to the original halt conditions.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in linear time using BFS or DFS, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the order of field processing as directional, but this is mitigated by explicitly stating that the logic is symmetric and the order does not matter.
</RISK>
