<STATEMENT>
# Equilibrium States

Time limit: 1 s
Memory limit: 256 MB

A network consists of $n$ nodes and $m$ links. Each link connects two specific nodes. Each node $i$ must be assigned a state $s_i \in \{1, 2\}$. 

Let $s$ be a column vector of size $n$ containing these assigned states.
Let $A$ be the $n \times n$ adjacency matrix of the network, where $A_{ij} = 1$ if there is a link between node $i$ and node $j$, and $0$ otherwise.
Let $D$ be the $n \times n$ diagonal degree matrix, where $D_{ii}$ is the number of links connected to node $i$, and $D_{ij} = 0$ for $i \neq j$.

The network is considered to be in equilibrium if and only if the following matrix equation holds exactly:
$(A + D) s = 3 D \mathbf{1}$
where $\mathbf{1}$ is a column vector of size $n$ with all elements equal to 1.

Your task is to determine whether there is an assignment of states (either 1 or 2) to all $n$ nodes such that the network is in equilibrium. If multiple valid assignments exist, you must output the one that minimizes the sequence of assigned states $s_1, s_2, \dots, s_n$ lexicographically.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a link connects node $u$ and node $v$.

## Output
If no equilibrium assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \ldots, s_n$ (each being 1 or 2) representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The previous local edge constraint (affine transformations) allowed models to exhaustively evaluate the 4 possible state pairs $(s_u, s_v) \in \{1, 2\}^2$ and trivially deduce that $s_u \neq s_v$. This rewrite replaces the local condition with a global matrix equation $(A+D)s = 3D\mathbf{1}$. To recognize the bipartite structure, the model must now extract the row-wise equation $\sum_{j \sim i} s_j + d_i s_i = 3 d_i$ and use extremal bounding arguments to prove that adjacent nodes must have different states, forcing genuine algebraic and algorithmic reasoning.
</RATIONALE>
<PRESERVED_ANSWER>
The row-wise expansion of the matrix equation is $\sum_{j \sim i} s_j = d_i(3 - s_i)$; since $s_j \in \{1, 2\}$, if $s_i=1$ the sum is $2d_i$ (forcing all neighbors to 2), and if $s_i=2$ the sum is $d_i$ (forcing all neighbors to 1), making it strictly equivalent to the original bipartite constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The valid assignments remain exactly the proper 2-colorings of the graph, preserving the problem as bipartite graph checking / 2-coloring.
</PRESERVED_CLASS>
