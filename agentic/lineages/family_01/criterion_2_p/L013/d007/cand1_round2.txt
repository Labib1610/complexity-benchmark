<STATEMENT>
# Interference Polynomials

Time limit: 1 s
Memory limit: 256 MB

A distributed system consists of $n$ nodes. Each node $i$ (for $1 \le i \le n$) must be assigned a frequency multiplier $k_i \in \{1, 2\}$.

The system contains $m$ pairwise interference channels. Each channel connects a node $u$ and a node $v$. It is possible for a channel to connect a node to itself, and multiple channels may connect the same pair of nodes. 

For each channel connecting $u$ and $v$, the interference polynomial is defined as:
$H(x) = (x - k_u)(x - k_v)$

A channel is considered *constructive* if the first derivative of its interference polynomial, evaluated at $x = 0$, is exactly $-3$. That is, $H'(0) = -3$. If $H'(0) \neq -3$ for any channel, that channel is destructive and the entire system configuration is invalid.

Your task is to determine whether there is an assignment of frequency multipliers (either 1 or 2) to all $n$ nodes such that every channel in the system is constructive. If multiple valid assignments exist, you must output the one that minimizes the sequence of assigned multipliers $k_1, k_2, \dots, k_n$ lexicographically.

(Recall that sequence $A$ is lexicographically smaller than sequence $B$ if at the first index where they differ, the value in $A$ is strictly less than the value in $B$.)

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that an interference channel connects node $u$ and node $v$.

## Output
If no valid assignment exists that makes all channels constructive, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $k_1, \ldots, k_n$ (each being 1 or 2) representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit matrix affine transformation constraint with a polynomial derivative constraint, $H'(0) = -3$. This requires models to algebraically evaluate the derivative of $H(x) = (x-k_u)(x-k_v)$ at $x=0$, which simplifies to $-(k_u + k_v) = -3$. This forces genuine mathematical reasoning to uncover the underlying $k_u \neq k_v$ constraint, defeating models that rely on memorized bipartite graph keywords or affine transformation patterns.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $H'(0) = -3$ simplifies to $k_u + k_v = 3$, which for values $k_i \in \{1, 2\}$ strictly requires $k_u \neq k_v$, exactly mirroring the behavior of the seed's fixed-point constraint for every valid or invalid input, including self-loops and repeated edges.
</PRESERVED_ANSWER>
