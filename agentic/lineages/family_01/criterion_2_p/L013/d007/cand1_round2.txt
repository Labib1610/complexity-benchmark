# Problem B — Failover States

Time limit: 1 s   Memory limit: 256 MB

You are configuring a server cluster with $n$ distinct nodes. Each node $i$ must be assigned an operational state $s_i$, which must be chosen as either 1 or 2.

There are $m$ potential failover links defined in the network. The $k$-th link connects node $u_k$ and node $v_k$.

To ensure the cluster is resilient, every failover link must be "active". A link between node $u$ and node $v$ is considered active if and only if overriding the operational state of node $u$ with the current state of node $v$ would result in a modified global state sequence $s_1, s_2, \dots, s_n$.

Your objective is to determine if there exists an initial state assignment for all $n$ nodes such that all $m$ failover links are active. If such an assignment exists, you must output it. In cases where multiple valid assignments exist, you must choose the one whose sequence of states $s_1, s_2, \dots, s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of nodes and the number of failover links.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), specifying the 1-based indices of the two nodes connected by that link.

## Output
If no valid state assignment can make all links active, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$) denoting the states. If there are multiple valid sequences, output the sequence that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit "at least one tier 1 and at least one tier 2" rule with a functional mutability test: overriding node u's state with node v's state must modify the global sequence. This forces models to deduce that the states must be different, breaking simple pattern matching while remaining mathematically identical and fully natural within the system-design theme.
</RATIONALE>
<PRESERVED_ANSWER>
Overriding $s_u$ with $s_v$ modifies the sequence if and only if $s_u \neq s_v$; since states are restricted to $\{1, 2\}$, this is perfectly isomorphic to the original requirement that each pair contains exactly one 1 and one 2, ensuring all valid assignments and the lexicographical tie-breaker remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding a valid 2-coloring of an undirected graph (and orienting components for the tie-break), which is solvable in $O(n+m)$ using Breadth-First Search, keeping it firmly in P.
</PRESERVED_CLASS>
