**Solution Explanation**

For a node we have to choose one of the two matrices  

```
M1 = |2 1|
     |1 1|

M2 = | 1 -1|
     |-1  2|
```

For a link `{u,v}` the link is *stable* iff the composition of the two
transformations (in any order) is the identity matrix `I`.

```
M1·M2 = I ,   M2·M1 = I
```

so the two matrices are inverses of each other.
Therefore a link is stable **iff the two incident nodes use different
transformations**.

Consequences  

* the whole network is stable ⇔ the graph is *bipartite*;
* we have to colour the vertices with two colours `1` and `2`
  such that every edge connects vertices of different colours.

If the graph is not bipartite the answer is `NO`.

--------------------------------------------------------------------

#### Lexicographically smallest colouring

All bipartite components are independent – we may swap the two colours
inside a component.
For the whole sequence `s1 … sn` we want the lexicographically smallest
binary string (`1 < 2`).

Consider one connected component `C`.  
Let `vmin` be the smallest vertex index belonging to `C`.
If we colour `vmin` with `1`, the whole sequence becomes smaller than
any colouring where `vmin` gets `2`, because `vmin` appears earlier than
any other vertex of `C`.  
Thus the optimal rule is:

*For every component colour it so that its smallest index vertex receives
colour `1`.*

The rule is sufficient: after fixing the colour of `vmin` the rest of
the component is forced (the bipartite colouring is unique up to a
global swap).

--------------------------------------------------------------------

#### Algorithm
```
read n,m
build adjacency list
colour[1…n] = -1   // -1 = unvisited, 0/1 = temporary bipartite colours
answer[1…n] = 0

for each vertex v = 1 … n
    if colour[v] == -1
        // start a new component
        bfs queue ← v
        colour[v] = 0
        component_vertices = []
        while queue not empty
            x = pop
            component_vertices.append(x)
            for each neighbour y of x
                if colour[y] == -1
                    colour[y] = colour[x] ^ 1
                    push y
                else if colour[y] == colour[x]
                    print "NO" and exit   // not bipartite
        // decide orientation
        vmin = min(component_vertices)
        if colour[vmin] == 0
            // keep mapping 0→1 , 1→2
            for each u in component_vertices
                answer[u] = 1 if colour[u]==0 else 2
        else
            // swap mapping
            for each u in component_vertices
                answer[u] = 2 if colour[u]==0 else 1

print "YES"
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a lexicographically minimal
valid assignment iff such an assignment exists.

---

##### Lemma 1  
For any edge `{u,v}` the link is stable **iff** the assigned
transformations are different (one node uses `M1`, the other `M2`).

**Proof.**  
`M1·M2 = I` and `M2·M1 = I`.  
If both endpoints use the same matrix, the composition equals `M1·M1`
or `M2·M2`, which is not `I`.  
If they use different matrices, the composition equals `I`. ∎



##### Lemma 2  
A configuration of transformations is valid **iff** the graph is
bipartite with colours `1` and `2`.

**Proof.**  
By Lemma&nbsp;1 each edge must connect vertices with different
transformations, i.e. different colours. This is exactly the definition
of a proper 2‑colouring, i.e. bipartiteness. ∎



##### Lemma 3  
If the algorithm finishes the BFS of a component without detecting a
conflict, the component is bipartite and the array `colour` contains a
proper 2‑colouring (values `0` and `1`).

**Proof.**  
BFS assigns opposite temporary colours to the two ends of every traversed
edge. A conflict is reported precisely when an edge connects two vertices
already having the same temporary colour. Absence of conflict means no
such edge exists, therefore the temporary colours form a proper
2‑colouring. ∎



##### Lemma 4  
For a component `C` the algorithm outputs a colouring that satisfies the
edge condition and makes the smallest index vertex of `C` coloured `1`.

**Proof.**  
From Lemma&nbsp;3 we have a temporary bipartite colouring `colour`.
If `colour[vmin]=0` we map `0→1,1→2`; otherwise we swap the mapping.
Both mappings keep opposite temporary colours mapped to opposite final
colours, therefore every edge still connects different final colours.
By construction `vmin` receives colour `1`. ∎



##### Lemma 5  
The whole assignment produced by the algorithm (if it reaches the end)
satisfies all edges.

**Proof.**  
Each edge lies inside a single connected component.
By Lemma&nbsp;4 the two endpoints of that edge receive different final
colours, hence by Lemma&nbsp;1 the link is stable. ∎



##### Lemma 6  
Among all valid assignments, the algorithm’s assignment is
lexicographically smallest.

**Proof.**  
Consider the vertices in increasing order.
Take the first vertex `p` where the algorithm’s assignment could differ
from another valid assignment `A`.  
`p` belongs to some component `C`.  
Both assignments must respect the bipartite structure, therefore inside
`C` the two possible colourings are exactly the two orientations
considered by the algorithm.  
The algorithm chooses the orientation that gives colour `1` to the
smallest index vertex of `C`, which is `p` (otherwise a smaller vertex
of `C` would appear earlier).  
Thus the algorithm gives `1` to `p`, while any other valid assignment
must give `2` to `p`. Consequently the algorithm’s whole sequence is
lexicographically smaller. ∎



##### Lemma 7  
If the algorithm prints `NO` then no valid assignment exists.

**Proof.**  
`NO` is printed only when during BFS an edge is found whose endpoints
already have the same temporary colour. This means the graph contains an
odd cycle, i.e. it is not bipartite. By Lemma&nbsp;2 a valid assignment
requires bipartiteness, therefore none exists. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no stable assignment exists;  
* otherwise `YES` and the lexicographically smallest stable assignment.

**Proof.**  
*If the algorithm prints `NO`* – by Lemma&nbsp;7 no assignment exists.  

*If the algorithm finishes* – by Lemma&nbsp;5 the produced assignment
is stable. By Lemma&nbsp;6 it is the lexicographically smallest among
all stable assignments. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once,
`O(n + m)` time.  
*Additional work* (finding minima, building answer) is linear in the
size of each component, overall `O(n)`.  

Total time `O(n + m)` ≤ `4·10⁵`, well inside the limit.  
Memory consumption `O(n + m)` for adjacency lists and arrays.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # temporary 0/1
    answer = [0] * (n + 1)           # final 1/2

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp = []
        while q:
            x = q.popleft()
            comp.append(x)
            for y in adj[x]:
                if colour[y] == -1:
                    colour[y] = colour[x] ^ 1
                    q.append(y)
                elif colour[y] == colour[x]:
                    print("NO")
                    return
        # decide orientation: smallest index gets colour 1
        vmin = min(comp)
        if colour[vmin] == 0:
            for v in comp:
                answer[v] = 1 if colour[v] == 0 else 2
        else:
            for v in comp:
                answer[v] = 2 if colour[v] == 0 else 1

    # all good
    print("YES")
    sys.stdout.write(' '.join(str(answer[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
