We can model this as a graph problem.  
Each dependency requires that the two commodities have different pricing tiers (since the average must be 1.5, and only 1 and 2 are allowed).  

So the graph must be bipartite.  
If it’s not bipartite, output `NO`.  

If it is bipartite, we have two possible colorings (swap 1 and 2).  
We need to choose the one that maximizes:

\[
\sum_{i \in S} \frac{1}{i!}
\]

Since \(1/i!\) decreases very fast, the optimal choice is to put the **smallest indices** into tier 1 as much as possible.  

We can do this by:  
- BFS/DFS to color the graph.  
- For each connected component, we have two possible assignments.  
- Choose the one that puts the smaller indices into tier 1.  

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
ok = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    ok = False
                    break
            if not ok:
                break
    if not ok:
        break

if not ok:
    print("NO")
else:
    # For each component, decide orientation
    visited = [False] * n
    assignment = [0] * n
    for i in range(n):
        if not visited[i]:
            # collect component
            comp = []
            q = deque([i])
            visited[i] = True
            while q:
                u = q.popleft()
                comp.append(u)
                for v in adj[u]:
                    if not visited[v]:
                        visited[v] = True
                        q.append(v)
            # two possible assignments: color as is, or flipped
            # compute score for each
            score1 = 0.0
            score2 = 0.0
            for u in comp:
                if color[u] == 0:
                    score1 += 1 / __import__('math').factorial(u + 1)
                else:
                    score2 += 1 / __import__('math').factorial(u + 1)
            # choose better
            if score1 >= score2:
                for u in comp:
                    assignment[u] = 1 if color[u] == 0 else 2
            else:
                for u in comp:
                    assignment[u] = 1 if color[u] == 1 else 2

    print("YES")
    print(" ".join(map(str, assignment)))
```
