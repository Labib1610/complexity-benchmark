 We need to assign each node a value of 1 or 2 such that for every edge (u, v):

\[
s_u \cdot s_v + s_u + s_v = 5
\]

Let’s check possible pairs:

- If both are 1: \(1 \cdot 1 + 1 + 1 = 3\) → not valid  
- If both are 2: \(2 \cdot 2 + 2 + 2 = 8\) → not valid  
- If one is 1 and the other is 2: \(1 \cdot 2 + 1 + 2 = 5\) → valid  

So the condition is: every edge must connect nodes with different values.  
That means the graph must be bipartite.

We can solve by BFS/DFS coloring. If the graph is not bipartite, output `NO`.  
If it is bipartite, we need the lexicographically smallest assignment.  
We can try to assign 1 to node 1 if possible, and propagate.  
If a conflict occurs, we flip the coloring of the entire component.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n  # -1 uncolored, 0 and 1 are the two colors

def bfs(start):
    q = deque([start])
    color[start] = 0
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = color[u] ^ 1
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

# Try to color with node 0 as color 0
for i in range(n):
    if color[i] == -1:
        if not bfs(i):
            print("NO")
            sys.exit()

# Now we have a valid bipartite coloring, but we need lexicographically smallest.
# We can try to flip components if it makes earlier nodes 1.
# Since we started with node 0 as 0, we check if flipping any component gives smaller lexicographic order.

# Build component ids
comp_id = [-1] * n
comp_count = 0
for i in range(n):
    if comp_id[i] == -1:
        q = deque([i])
        comp_id[i] = comp_count
        while q:
            u = q.popleft()
            for v in adj[u]:
                if comp_id[v] == -1:
                    comp_id[v] = comp_count
                    q.append(v)
        comp_count += 1

# For each component, decide whether to flip to get lexicographically smaller
# We compare the two possible assignments for each component.
# Since components are independent, we can decide per component.
# For each component, we have two possible colorings: original or flipped.
# We choose the one that makes the smallest index in that component have value 1 if possible.

# First, find the smallest node index in each component
min_node_in_comp = [n] * comp_count
for i in range(n):
    cid = comp_id[i]
    if i < min_node_in_comp[cid]:
        min_node_in_comp[cid] = i

# For each component, if the smallest node currently has color 1, we keep; if 0, we flip to make it 1? 
# Actually we want lexicographically smallest overall, so for each component we check both options and pick the one that gives smaller sequence.
# Since components are independent, we can just check: if flipping makes the smallest node in that component become 1 while it was 0, we flip.
# But careful: flipping changes all nodes in that component.

# Let's just build final assignment by trying to set each node to 1 if possible.
# We can do a BFS/DFS that tries to assign 1 to node 0, and if conflict, flip entire component.

# Simpler: we already have a valid coloring. We can try to flip each component if it improves lexicographic order.
# Compare the two options for each component by looking at the smallest index in that component.
# If the smallest index in the component currently has color 0, flipping makes it 1, which is larger, so we don't flip.
# If it has color 1, flipping makes it 0, which is smaller, so we flip.

# Wait: color 0 means we will output 1, color 1 means output 2.
# So we want smallest lexicographic: prefer 1 at earlier positions.
# So if smallest node in component has color 0 (output 1), keep. If color 1 (output 2), flip to make it 1.

for cid in range(comp_count):
    mn = min_node_in_comp[cid]
    if color[mn] == 1:  # currently outputs 2, flip to output 1
        for i in range(n):
            if comp_id[i] == cid:
                color[i] ^= 1

# Now output
res = [1 if color[i] == 0 else 2 for i in range(n)]
print("YES")
print(" ".join(map(str, res)))
```
