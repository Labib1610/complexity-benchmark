We can model this as a graph problem where each asset is a node and each flagged pair is an edge.  
The condition “exactly one from each pair in Vehicle 1” means the graph must be bipartite:  
we can color nodes with 1 or 2 such that every edge connects different colors.

If the graph is not bipartite, output `NO`.  
If it is bipartite, we need the lexicographically smallest assignment.  
We can do a BFS/DFS, assigning colors greedily:  
- Start with node 1 assigned to 1.  
- For each unvisited node, assign the smallest possible color (1 if possible, else 2) while maintaining bipartiteness.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 1
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 3 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
