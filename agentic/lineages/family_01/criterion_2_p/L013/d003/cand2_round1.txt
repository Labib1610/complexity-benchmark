# Quantum Coherence Calibration

Time limit: 1 s
Memory limit: 256 MB

A quantum computing matrix consists of $n$ qubits. Each qubit must be calibrated to operate in either energy state 1 or energy state 2.

The matrix contains $m$ entanglement bridges. Each bridge continuously couples two specific qubits. The baseline energy emitted by a qubit is equal to the square of its energy state (i.e., a state of 1 emits 1 unit of energy, and a state of 2 emits 4 units). To maintain stable quantum coherence, a bridge requires the total combined energy emitted by its two coupled qubits to be exactly 5 units. If the total energy across a bridge is 2 units or 8 units, the bridge will immediately collapse and halt the system.

Your task is to determine whether there is a valid calibration configuration for all $n$ qubits that keeps every entanglement bridge stable. If multiple such configurations exist, the control software defaults to the one that is lexicographically smallest (i.e., the sequence of energy states $s_1, s_2, \dots, s_n$ must be as small as possible when compared element by element, starting from the first qubit).

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that an entanglement bridge couples qubit $u$ and qubit $v$.

## Output
If no stable configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being 1 or 2) representing the lexicographically smallest stable calibration configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
