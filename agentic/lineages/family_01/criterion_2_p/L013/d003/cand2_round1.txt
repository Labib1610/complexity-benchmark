# Problem B — Asset Hedging

Time limit: 1 s   Memory limit: 256 MB

A wealth management firm must distribute a pool of $n$ financial assets into two distinct investment vehicles, designated as Vehicle 1 and Vehicle 2. Every single asset must be placed into exactly one of these two vehicles.

Quantitative analysts have identified $m$ specific pairs of assets that exhibit extreme correlation. To manage market volatility, the firm requires a strict hedging protocol for these flagged pairs. Specifically, to prevent concentrated exposure, the protocol demands that within each flagged pair, exactly one of the two assets must be placed into Vehicle 1.

Your task is to determine whether it is possible to distribute all $n$ assets in a way that perfectly respects every hedging protocol constraint. If such a distribution is possible, you must output it. In cases where multiple valid distributions exist, you must output the one that produces the lexicographically smallest sequence of $n$ vehicle identifiers (using 1s and 2s).

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of assets and the number of correlated pairs. Assets are numbered from 1 to $n$.
Each of the subsequent $m$ lines contains two integers $u$ and $v$, representing a pair of assets subject to the hedging protocol.

## Output
If no valid distribution exists, print a single line with `NO`.
If a valid distribution is possible, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$), representing the vehicle assignments for assets 1 through $n$. If there are multiple satisfactory distributions, print the sequence of identifiers that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

I replaced the explicit mathematical formula ("sum of their assigned vehicle identifiers must equal exactly 3") with a scenario-based constraint ("within each flagged pair, exactly one of the two assets must be placed into Vehicle 1"). This forces models to logically deduce that the other asset must go to Vehicle 2, removing the direct affordance for `color[v] = 3 - color[u]` while preserving the exact same bipartite structure.
</RATIONALE>
<PRESERVED_ANSWER>
Because every asset must go to exactly one of the two vehicles, requiring exactly one asset from a pair to be in Vehicle 1 inherently forces the other asset to be in Vehicle 2, which is mathematically identical to requiring their identifiers to sum to 3.
</PRESERVED_ANSWER>
