We can model each commodity as a variable \( p_i \in \{1,2\} \).  
Let’s transform to \( x_i = p_i - 1 \), so \( x_i \in \{0,1\} \).  

Then:

- \( p_i = x_i + 1 \)
- \( W = \sum d_i (x_i+1) = \sum d_i x_i + \sum d_i \)
- \( U = \sum (x_u+1)(x_v+1) = \sum x_u x_v + \sum (x_u + x_v) + m \)

Also note:  
\(\sum d_i = 2m\) because each dependency contributes 1 to degree of each of its two endpoints.

So:

\( W = \sum d_i x_i + 2m \)  
\( U = \sum x_u x_v + \sum (x_u + x_v) + m \)

But \(\sum (x_u + x_v)\) over edges = \(\sum d_i x_i\).

Thus:

\( U = \sum x_u x_v + \sum d_i x_i + m \)

Now the equilibrium condition:

\( 3W - 2U = 5m \)

Substitute:

\( 3(\sum d_i x_i + 2m) - 2(\sum x_u x_v + \sum d_i x_i + m) = 5m \)

Simplify:

\( 3\sum d_i x_i + 6m - 2\sum x_u x_v - 2\sum d_i x_i - 2m = 5m \)

\( \sum d_i x_i - 2\sum x_u x_v + 4m = 5m \)

So:

\( \sum d_i x_i - 2\sum x_u x_v = m \)

Now, note that for each edge \((u,v)\):

- If \(x_u = x_v = 1\), contribution to LHS: \(d_u + d_v - 2\)  
- If exactly one is 1, contribution: \(d_u\) or \(d_v\)  
- If both 0, contribution: 0

But this is messy. Let’s try another approach.

---

We can rewrite the condition in terms of \(p_i\) directly.

Let \(p_i \in \{1,2\}\).  
Define \(y_i = 2p_i - 3\), so \(y_i \in \{-1, 1\}\).  
Then \(p_i = (y_i + 3)/2\).

But maybe easier:  
Let’s set \(q_i = p_i - 1 \in \{0,1\}\).

We already derived:

\[
\sum d_i q_i - 2\sum q_u q_v = m
\]

Now, note that \(\sum d_i q_i = \sum_{\text{edges}} (q_u + q_v)\).  
So:

\[
\sum_{\text{edges}} (q_u + q_v) - 2\sum_{\text{edges}} q_u q_v = m
\]

But \(q_u + q_v - 2q_u q_v = q_u(1-q_v) + q_v(1-q_u)\).  
This is 1 if exactly one endpoint is 1, 0 otherwise.

So the condition becomes:

\[
\#\{\text{edges with exactly one endpoint having } q=1\} = m
\]

That means **every edge must have exactly one endpoint with \(q=1\)** (i.e., one endpoint with \(p=2\) and the other with \(p=1\)).

So the graph must be bipartite, with the two parts being the \(p=1\) and \(p=2\) commodities.

Thus the problem reduces to:  
Check if the graph is bipartite. If yes, output a valid 2-coloring with lexicographically smallest assignment of 1/2.

---

To get lexicographically smallest:  
We want \(p_1\) as small as possible (1), then \(p_2\), etc.  
So we can do BFS/DFS coloring, but when we start from each unvisited node, we try assigning color 1 first if possible, and propagate.

Implementation:

- Build adjacency list.
- color array: -1 = uncolored, 0 = p=1, 1 = p=2.
- For each node i from 1..n:
  - If uncolored, try color 0 (p=1). BFS/DFS assign alternating colors.
  - If conflict → NO.
- Output colors as p = color+1.

---

Let’s code it.  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(' '.join(str(c + 1) for c in color))
```
