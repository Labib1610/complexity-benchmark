# Problem B — Phase Correlation

Time limit: 1 s   Memory limit: 256 MB

You are calibrating a quantum sensing array consisting of $n$ independent signal generators. For the array to function correctly, each generator $i$ must be assigned a discrete phase factor $s_i$ chosen from the set $\{1, 2\}$.

The array's geometry imposes $m$ interference constraints. Each constraint specifies a pair of generators $u$ and $v$ that have overlapping fields. To achieve perfect destructive interference and prevent signal saturation, the cross-correlation coefficient for each specified pair must be exactly 2. The cross-correlation coefficient of a pair of generators is defined as the product of their assigned phase factors, $s_u \times s_v$.

Your objective is to find a complete sequence of phase factors $S = (s_1, s_2, \dots, s_n)$ such that every interference constraint is perfectly satisfied.

If there are multiple valid sequences that satisfy all constraints, you must choose the one whose sequence of elements $s_1, s_2, \dots, s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of signal generators and the number of interference constraints, respectively.

The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), specifying the 1-based indices of the two generators involved in that constraint.

## Output
If no sequence of phase factors can satisfy all interference constraints under the given conditions, print a single line containing `NO`.

Otherwise, print `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$) denoting the phase factors assigned to each generator. If there are multiple valid sequences, output the sequence that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

Replaced the explicit linear matrix-vector equation ($AS = \mathbf{3}$) with a non-linear product constraint ($s_u \times s_v = 2$) on a restricted domain ($\{1, 2\}$). This mathematically enforces the exact same inequality ($s_u \neq s_v$) required for 2-coloring, but removes any mention of matrices, sums, or rows, forcing models to deduce the bipartite nature from the arithmetic properties of the domain.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $s_u \times s_v = 2$ for $s_i \in \{1, 2\}$ is satisfied if and only if one value is 1 and the other is 2, which is exactly equivalent to the seed's condition $s_u + s_v = 3$, meaning all valid assignments and the lexicographical tie-breaker remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to checking bipartiteness and finding the lexicographically smallest 2-coloring of a graph, which is solvable in $O(n+m)$ time using Breadth-First Search.
