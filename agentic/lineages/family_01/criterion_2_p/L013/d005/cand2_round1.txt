<METHOD_NAME>Functional Composition State Encoding</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces a direct bitwise or arithmetic state comparison (XOR > AND) with a requirement that the functional composition of two assigned continuous functions equals a specific target function. This forces the model to symbolically evaluate the 4 possible compositions to discover that the endpoints must be assigned different states, rather than pattern-matching a known bitwise idiom for 2-coloring.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Orbital Array Equilibrium

Time limit: 1 s
Memory limit: 256 MB

An orbital array contains $n$ synchronization nodes. Each node must be configured with a signal transformation protocol. There are two available protocols:
Protocol 1: $T(x) = x$
Protocol 2: $T(x) = 5 - x$

The array is stabilized by $m$ harmonic tethers. Each tether connects two specific nodes and continuously feeds the output of one node's protocol into the other's. To maintain equilibrium, a tether requires that the composition of its two endpoints' protocols perfectly inverts the signal around 2.5. Specifically, for a tether connecting node $u$ and node $v$, the combined effect must be exactly $T_u(T_v(x)) = 5 - x$ for all real inputs $x$ (note that for these specific protocols, the order of composition does not matter). If any tether detects that its monitored nodes do not satisfy this condition, it triggers a system halt.

Your task is to determine whether there is an assignment of protocols for all $n$ nodes that keeps every tether balanced. If multiple valid assignments exist, the safety override protocol requires the one that minimizes the sequence of assigned protocol numbers $s_1, s_2, \dots, s_n$ lexicographically (i.e., the sequence must be as small as possible when compared element by element starting from the first node).

## Input
The first line contains two integers $n$ and $m$. The array requires a strictly positive number of nodes to function, and may have zero or more tethers. Both the node count $n$ and the tether count $m$ are limited by the system's maximum addressing capacity, which is exactly equal to the total number of seconds in 55 hours, 33 minutes, and 20 seconds.
Each of the next $m$ lines contains two node identifiers $u$ and $v$ (where identifiers are integers from 1 to $n$), indicating that a harmonic tether connects node $u$ and node $v$.

## Output
If no balanced assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being 1 or 2) representing the lexicographically smallest balanced assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit bitwise condition (XOR > AND) was replaced with a functional composition requirement where $T_u(T_v(x)) = 5 - x$. Because $T_1(T_1(x))=x$, $T_2(T_2(x))=x$, and $T_1(T_2(x))=5-x$, the solver must symbolically evaluate these compositions to discover that the endpoints must have different protocols. Additionally, the maximum bounds were restated dynamically as a time conversion (55 hours, 33 minutes, 20 seconds = 200,000) to strip numerical giveaways.
</RATIONALE>
<PRESERVED_ANSWER>
The functional composition $T_u(T_v(x)) = 5 - x$ is true if and only if $u$ and $v$ are assigned different protocols (one gets 1, the other gets 2), which is exactly mathematically equivalent to the seed's requirement that the XOR of their states is greater than the AND.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring / bipartite graph testing, solvable in O(n+m) time using BFS or DFS, as the underlying constraint graph and required component orientations are identical.
</PRESERVED_CLASS>
