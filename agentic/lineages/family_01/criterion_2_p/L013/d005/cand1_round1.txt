# Orbital Array Equilibrium

Time limit: 1 s
Memory limit: 256 MB

An orbital array contains $n$ synchronization nodes. Each node must be configured with a resonance tier of either 1 or 2. 

The array is stabilized by $m$ harmonic tethers. Each tether connects two specific nodes and continuously monitors their resonance tiers. To maintain equilibrium, a tether requires a precise phase relationship between its endpoints. Specifically, if the two connected nodes have resonance tiers $x$ and $y$, the tether's internal processor constructs the phase matrix $P = \begin{pmatrix} x & 2 \\ 2 & y \end{pmatrix}$. The tether remains balanced if and only if all eigenvalues of this matrix $P$ are irrational numbers. If any tether detects that its phase matrix has at least one rational eigenvalue, it triggers a system halt.

Your task is to determine whether there is an assignment of resonance tiers for all $n$ nodes that keeps every tether balanced. If multiple valid assignments exist, the safety override protocol requires the one that minimizes the sequence of resonance tiers $s_1, s_2, \dots, s_n$ lexicographically (i.e., the sequence must be as small as possible when compared element by element starting from the first node).

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a harmonic tether connects node $u$ and node $v$.

## Output
If no balanced assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being 1 or 2) representing the lexicographically smallest balanced assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

Replaced the direct bitwise XOR > AND condition with an equivalent algebraic property: the rationality of the eigenvalues of a specific 2x2 matrix. This removes the obvious logic-gate pattern that models were using to immediately recognize the bipartite coloring constraint, forcing them to first correctly evaluate the characteristic polynomial for all tier combinations.
</RATIONALE>
<PRESERVED_ANSWER>
The eigenvalues of the matrix are irrational if and only if x and y are different (since the discriminant is 17 for x!=y and 16 for x=y), preserving the exact same valid assignments as the XOR > AND condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, keeping it in P and solvable via BFS.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret "irrational numbers" if it hallucinates that complex roots could occur and doesn't know how to classify them, though the discriminant is always positive here so the roots are strictly real.
</RISK>
