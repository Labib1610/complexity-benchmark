<STATEMENT>
# Problem B — Traceless Tensor Configurations

Time limit: 1 s
Memory limit: 256 MB

You are configuring a network of $n$ quantum-optical components. Each component must be calibrated to one of two phase states. We represent these states using $2 \times 2$ matrices:
* State 1 is represented by $M_1 = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}$.
* State 2 is represented by $M_2 = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}$.

The network contains $m$ critical interference channels. Each channel connects two components, $u$ and $v$. For the network to operate safely, the signals from these two components must perfectly destructively interfere. Mathematically, this requires that the matrix product of their assigned states is traceless. That is, if component $u$ is assigned matrix $A_u \in \{M_1, M_2\}$ and component $v$ is assigned matrix $A_v \in \{M_1, M_2\}$, then the sum of the main diagonal elements of the product $A_u A_v$ must be exactly zero (i.e., $\text{Tr}(A_u A_v) = 0$).

Your objective is to assign State 1 or State 2 to each of the $n$ components such that every one of the $m$ channels is stable.

If there are multiple valid assignments, the system will default to the one whose sequence of state identifiers (a sequence of $n$ integers, each either 1 or 2) is lexicographically smallest. 

The control system is limited by a strict hardware memory budget. Each component and each interference channel consumes exactly 5 bytes of addressing memory. The hardware enforces a maximum of 1,000,000 bytes for component addressing and, independently, a maximum of 1,000,000 bytes for channel addressing. The system will always contain at least one component, though it might have zero interference channels.

## Input
The first line contains two integers $n$ and $m$, representing the number of components and the number of interference channels.
The following $m$ lines each contain two integers $u$ and $v$, specifying the 1-based indices of the two components connected by that interference channel.

## Output
If no valid assignment of states can make all channels stable, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$) denoting the state assigned to each component. If there are multiple valid assignments, output the sequence that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The direct vector sum constraint ($s_u + s_v = 3$) was replaced with an algebraic matrix trace condition. Models must now symbolically evaluate the matrix products to deduce that the trace is zero if and only if the two assigned matrices are different, forcing them to derive the hidden 2-coloring structure through reasoning rather than recognizing bipartite keywords. Numeric bounds were also translated into hardware memory constraints to satisfy S07.
</RATIONALE>
<PRESERVED_ANSWER>
The matrix trace condition $\text{Tr}(A_u A_v) = 0$ is mathematically equivalent to $A_u \neq A_v$, which maps identically to the original $s_u + s_v = 3$ for $s_i \in \{1, 2\}$, preserving all valid assignments and the lexicographical tie-breaker.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains isomorphic to bipartite graph 2-coloring, which is solvable in linear time using BFS, keeping it strictly in P.
</PRESERVED_CLASS>
<RISK>
Some models might overthink the "quantum-optical" flavor and attempt to simulate the matrices using floating-point approximations, but the discrete integer matrices make exact symbolic evaluation unambiguous.
</RISK>

</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the direct combinatorial constraint with a matrix trace condition. Two states are represented by $2 \times 2$ matrices, and the constraint is satisfied if and only if their product is traceless. This perfectly encodes the inequality requirement ($A_u \neq A_v$) but forces the model to symbolically evaluate the matrix products to discover the bipartite coloring structure, defeating models that rely on textual pattern matching for graph coloring.
</METHOD_DESCRIPTION>
