# Problem B — Database Tuning

Time limit: 1 s   Memory limit: 256 MB

You are tuning a database containing $n$ tables. Each table $i$ must be assigned a storage format $f_i$, which must be chosen as either 1 or 2.

The workload includes $m$ cross-table queries. The $k$-th query joins tables $u_k$ and $v_k$. 

The query engine calculates a hash penalty for each query $k$, defined by the formula:
$$ (f_{u_k} \bmod f_{v_k}) + (f_{v_k} \bmod f_{u_k}) $$
where $a \bmod b$ denotes the remainder of integer division of $a$ by $b$.

The system is considered optimally balanced if and only if the sum of the hash penalties across all $m$ queries is exactly $m$. 

Your objective is to determine whether there exists a storage format assignment for all $n$ tables that achieves this optimal balance. If such an assignment exists, you must output it.

If there are multiple valid format assignments, concatenate the assigned formats into a string $f_1 f_2 \dots f_n$. You must choose the assignment that makes this string lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of tables and the number of queries.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), specifying the 1-based indices of the two tables joined by that query.

## Output
If no valid storage format assignment can achieve optimal balance, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, output $n$ integers $f_1, f_2, \dots, f_n$ (where each $f_i \in \{1, 2\}$) denoting the assigned storage formats. If there are multiple valid sequences, output the sequence that produces the lexicographically smallest string.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit rational function and target with a modular arithmetic sum $(f_u \bmod f_v) + (f_v \bmod f_u) = m$. Since the domain is restricted to $\{1, 2\}$, this expression evaluates to 1 when the values differ and 0 when they are the same. Achieving a sum of exactly $m$ across $m$ pairs forces every pair to have different values, preserving the exact bipartite coloring requirement while completely masking the mathematical signature that models previously recognized. The tie-break rule was also translated from a factorial series to a mathematically identical lexicographical string comparison.
</RATIONALE>
<PRESERVED_ANSWER>
The modular equation is satisfied if and only if every edge connects a 1 and a 2, making the valid configurations identical to the seed's bipartite 2-colorings, and the lexicographical string tie-break selects the exact same assignment as the seed's factorial-weighted sum.
</PRESERVED_ANSWER>
