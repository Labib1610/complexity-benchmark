<METHOD_NAME>Geometric Stability Area</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit algebraic ratio and target sum with the area of a triangle formed by the pricing tiers in the Cartesian plane. The area evaluates to 0 for equal tiers and 3/4 for unequal tiers, so a target sum of 3m/4 identically forces the graph to be bipartite. This hides the 2-coloring constraint behind geometric evaluation, preventing algebraic pattern-matching.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem B — Market Equilibrium

Time limit: 1 s   Memory limit: 256 MB

You are analyzing a market with $n$ commodities. Each commodity $i$ must be assigned a pricing tier $p_i$, which must be chosen as either 1 or 2.

There are $m$ observed dependencies. The $k$-th dependency is an undirected pair involving commodities $u_k$ and $v_k$. 

For each dependency $k$, its stability index $I_k$ is the area of the triangle in the standard Cartesian plane with vertices at $(0,0)$, $(p_{u_k}, \frac{1}{p_{u_k}})$, and $(p_{v_k}, \frac{1}{p_{v_k}})$. If the two commodities are assigned the same pricing tier, these points are collinear and the triangle is degenerate with an area of $0$.

To maintain market equilibrium, the sum of the stability indices across all $m$ dependencies must be exactly $\frac{3m}{4}$.

Your objective is to determine if there exists a pricing tier assignment for all $n$ commodities that satisfies this equilibrium condition. If such an assignment exists, you must output it. 

Among assignments satisfying the equilibrium condition, output one maximizing the market confidence score. The market confidence score of an assignment is defined as:
$$ \sum_{i=1}^n \frac{2 - p_i}{i!} $$
where $i!$ denotes the factorial of $i$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of commodities and the number of dependencies.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), specifying the 1-based indices of the two commodities involved in that dependency.

## Output
If no valid pricing tier assignment can achieve equilibrium, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, output $n$ integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2\}$) denoting the pricing tiers. If there are multiple valid sequences, output the sequence that maximizes the market confidence score.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit algebraic ratio was replaced with a geometric area calculation. Since the area of the defined triangle is 0 when $p_u = p_v$ and 3/4 when $p_u \neq p_v$, forcing the sum across $m$ dependencies to be exactly $3m/4$ mathematically requires every dependency to have unequal tiers. This forces the model to evaluate the geometric area and deduce the strict maximum bound per edge to realize it is a bipartiteness check.
</RATIONALE>
<PRESERVED_ANSWER>
The triangle area evaluates to 3/4 if and only if $p_u \neq p_v$, and 0 otherwise; therefore, the sum of $3m/4$ is achievable if and only if every dependency has $p_u \neq p_v$, which is identical to the seed's constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) on the given graph, which is solvable in $O(n+m)$ time using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
None. The area of a triangle given its Cartesian coordinates is a standard, unambiguous mathematical definition, and the target sum perfectly and uniquely constrains the system without ambiguity.
</RISK>
