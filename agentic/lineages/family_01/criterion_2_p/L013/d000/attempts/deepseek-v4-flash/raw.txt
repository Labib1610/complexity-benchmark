We can model this as a graph bipartiteness problem.  
Each person is a node, and each separation rule is an edge that must connect nodes of different periods.  
This is exactly a 2-coloring problem.

We need to:

1. Build an adjacency list from the input.
2. Try to 2-color the graph using BFS/DFS.
3. If we find a conflict, output `NO`.
4. Otherwise, output `YES` and the lexicographically smallest assignment.

To get the lexicographically smallest assignment, we should assign period `1` whenever possible.  
We can do this by processing nodes in order and, when we start a new component, assign it color `1`.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 0  # 0 means period 1, 1 means period 2
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
# Convert 0 -> 1, 1 -> 2
print(' '.join(str(c + 1) for c in color))
```
