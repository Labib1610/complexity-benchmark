# Magnetic Resonance Equilibrium

Time limit: 1 s
Memory limit: 256 MB

A particle accelerator contains $n$ magnetic containment fields. Each field features a phase switch that must be set to position 1 or position 2. 

The accelerator is equipped with $m$ phase comparators. Each comparator monitors a specific pair of fields. A comparator measures the interaction between its two monitored fields by calculating the product of their switch positions. To maintain equilibrium and remain stable, this interaction product must be exactly 2. If the product evaluates to 1 or 4, the comparator destabilizes and triggers a system halt.

Your task is to determine whether there is a switch configuration for all $n$ fields that keeps every comparator stable. If multiple such configurations exist, the safety override protocol requires the one that is lexicographically smallest (i.e., the sequence of switch positions $s_1, s_2, \dots, s_n$ must be as small as possible when compared element by element starting from the first field).

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that a phase comparator monitors field $u$ and field $v$.

## Output
If no stable configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being 1 or 2) representing the lexicographically smallest stable switch configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

Removed the explicit statement that linked fields must have a "phase difference" or cannot be set to the "same switch position". Replaced this with a mathematical rule: the product of their switch positions must be exactly 2. This forces the model to deduce that the two positions must be different (since the only available values are 1 and 2), rather than relying on surface-level phrases like "difference" or "same" to pattern-match to bipartite graph 2-coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that the product of two values from {1, 2} equals 2 is mathematically identical to requiring that the two values are distinct, preserving all stable configurations and the lexicographical tie-break rule.
</PRESERVED_ANSWER>
