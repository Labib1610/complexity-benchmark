# Problem B — Independent Audits

Time limit: 1 s   Memory limit: 256 MB

You are overseeing the financial compliance process for a corporation with $n$ distinct ledgers. The regulatory framework requires that every ledger be reviewed by exactly one of two external oversight agencies: Agency 1 or Agency 2.

During the preliminary review, the regulators identified $m$ high-risk financial transfers between specific pairs of ledgers. To ensure strict independent verification and prevent conflicts of interest, any two ledgers involved in a high-risk transfer must be reviewed by different agencies. Specifically, if one ledger in the pair is assigned to Agency 1, the other must be assigned to Agency 2, and vice versa.

You need to determine whether it is possible to allocate all $n$ ledgers to the two agencies without violating this compliance rule. If a valid allocation exists, you must provide it. In the event that multiple valid allocations are possible, you must select the one that is lexicographically smallest when formatted as a sequence of $n$ integers (where each integer is either 1 or 2).

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of ledgers and the number of high-risk transfers, respectively. Ledgers are indexed from 1 to $n$.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a pair of ledgers connected by a high-risk transfer.

## Output
If there is no way to allocate the ledgers while satisfying all compliance rules, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $a_1, a_2, \dots, a_n$ (where each $a_i \in \{1, 2\}$) representing the assigned agency for ledgers 1 through $n$. If there are multiple valid allocations, output the sequence that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
