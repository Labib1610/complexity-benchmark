# Signal Routing Network

Time limit: 1 s
Memory limit: 256 MB

A network consists of $n$ routing modules. Each module must be assigned exactly one of two internal pin configurations. Each configuration maps an 8-pin input to an 8-pin output:
- Configuration 1: Pin 1 routes to 2, 2 to 3, 3 to 4, 4 to 1, 5 to 6, 6 to 7, 7 to 8, 8 to 5.
- Configuration 2: Pin 1 routes to 5, 2 to 8, 3 to 7, 4 to 6, 5 to 3, 6 to 2, 7 to 1, 8 to 4.

There are $m$ bidirectional links in the network. Each link connects two specific modules $u$ and $v$. When a signal passes through a link, it undergoes the configuration of one module followed immediately by the configuration of the other. 

Let $c(x)$ be the function that represents a signal passing through a link, meaning $c(x)$ is the final pin position after applying $u$'s configuration followed by $v$'s configuration to an initial pin $x$. 
A link is considered stable if and only if applying $c$ repeatedly requires exactly 4 applications to yield the original pin $x$ for all 8 pins. That is, $c(c(c(c(x)))) = x$ for all $x \in \{1 \dots 8\}$, and for any $k \in \{1, 2, 3\}$, there is at least one pin where applying $c$ exactly $k$ times does not yield $x$. (The stability result is identical whether the signal passes from $u$ to $v$ or $v$ to $u$).

If a link produces a different cycle length (for example, returning all pins to their starting positions in 2 applications), the link is unstable and the entire network configuration is invalid.

Your task is to determine whether there is an assignment of configurations (either 1 or 2) to all $n$ modules such that every link in the network is stable. If multiple valid assignments exist, you must output the one that minimizes the sequence of assigned configuration numbers $s_1, s_2, \dots, s_n$ lexicographically.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a link connects module $u$ and module $v$.

## Output
If no stable assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \ldots, s_n$ (each being 1 or 2) representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
