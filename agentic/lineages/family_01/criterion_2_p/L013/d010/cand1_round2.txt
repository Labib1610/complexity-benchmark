# Problem B — Grid Phase Configuration

Time limit: 1 s   Memory limit: 256 MB

You are configuring the properties of an $n \times n$ data grid. To do this, you must assign a single phase array $p$ of length $n$, where each element $p_i \in \{1, 2\}$ for $1 \le i \le n$.
This array simultaneously dictates the phases of the grid's rows and columns: the phase of row $i$ is defined as $p_i$, and the phase of column $i$ is also defined as $p_i$.

You are given a list of $m$ conflict cells within the grid. The $k$-th conflict cell is located at row $u_k$ and column $v_k$.
For each conflict cell, let $x$ be the phase of its row (so $x = p_{u_k}$) and $y$ be the phase of its column (so $y = p_{v_k}$).
A phase configuration is valid if and only if, for every conflict cell, the determinant of the following $3 \times 3$ matrix is exactly 0:
$$ \begin{pmatrix} x & 1 & 0 \\ 1 & y & 1 \\ 0 & 1 & x \end{pmatrix} $$

Your objective is to determine if there exists a valid phase configuration for the entire grid. If there are multiple valid configurations, you must output the one whose sequence $p_1, p_2, \dots, p_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the size of the phase array and the number of conflict cells.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), specifying the 1-based row and column indices of a conflict cell.

## Output
If no valid phase configuration is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, output $n$ integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2\}$) denoting the phase array. Among all valid assignments, you must output the lexicographically smallest sequence.

## Example 1
Input:
4 4
1 2
2 3
3 4
1 4
Output:
YES
1 2 1 2

## Example 2
Input:
3 3
1 2
1 3
2 3
Output:
NO
</STATEMENT>
<RATIONALE>
I replaced the direct "different from" inequality constraint with a mathematically equivalent condition requiring the determinant of a specific 3x3 matrix to be exactly 0. This forces the model to perform algebraic simplification (deducing that $x^2y - 2x = 0 \implies x \neq y$ for values in $\{1, 2\}$) before it can recognize the underlying bipartite graph structure, breaking surface-level pattern matching while strictly adhering to the seed's formal semantics.
</RATIONALE>
<PRESERVED_ANSWER>
The determinant of the given matrix evaluates to $x^2y - 2x$. For $x, y \in \{1, 2\}$, this expression equals 0 if and only if $x \neq y$, making the constraint mathematically identical to the seed's inequality for every possible input.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains exactly 2-coloring (bipartiteness testing) on an undirected graph, which is solvable in O(n+m) time using BFS, keeping it in class P.
</PRESERVED_CLASS>
