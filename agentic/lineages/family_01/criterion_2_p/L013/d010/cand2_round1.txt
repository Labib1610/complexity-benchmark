# Problem B — Signal Modulator Configuration

Time limit: 1 s
Memory limit: 256 MB

You are configuring a series of $n$ signal modulators. Each modulator $i$ must be assigned a frequency multiplier $p_i$, which can only be chosen from the set $\{1, 2\}$.
This choice dictates the modulator's wave alignment, defined by the exact mathematical value $W_i = \cos(\pi \cdot p_i)$.

The system contains $m$ critical interference channels. The $k$-th channel links modulator $u_k$ and modulator $v_k$. To maintain system stability, these channels must experience destructive interference. Specifically, for every interference channel, the sum of the wave alignments of its two connected modulators must be exactly $0$. That is, the configuration is only valid if $W_{u_k} + W_{v_k} = 0$ for all channels $k$.

Your objective is to determine if a valid configuration exists. If multiple valid configurations exist, you must output the one where the sequence of frequency multipliers $p_1, p_2, \dots, p_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$. The hardware chassis can accommodate up to $200,000$ modulators, meaning $n$ is at least $1$ and at most this chassis capacity. The diagnostic system can track up to $200,000$ interference channels, so $m$ ranges from $0$ up to this tracking limit.
The following $m$ lines each contain two integers $u$ and $v$. These represent the 1-based indices of the modulators linked by a channel, and are guaranteed to be valid indices bounded by $1$ and $n$.

## Output
If no valid configuration is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, output $n$ integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2\}$) denoting the assigned frequency multipliers. Among all valid configurations, output the lexicographically smallest sequence of multipliers.

## Example 1
Input:
4 4
1 2
2 3
3 4
1 4
Output:
YES
1 2 1 2

## Example 2
Input:
3 3
1 2
1 3
2 3
Output:
NO

</PRESERVED_ANSWER>
