<STATEMENT>
# Operator Network

Time limit: 1 s
Memory limit: 256 MB

A network consists of $n$ nodes. Each node must be assigned exactly one of two linear differential operators:
- Operator 1: $T_1(f)(x) = f'(x) + f(x)$
- Operator 2: $T_2(f)(x) = f'(x) - f(x)$

where $f$ is any twice continuously differentiable function with compact support on the real line.

There are $m$ links in the network. Each link connects two specific nodes $u$ and $v$. A link is considered stable if and only if the composed operator $T_{u,v} = T_u \circ T_v$ (applied in either order, as they commute) is formally self-adjoint. 

Specifically, the combined operator $T_{u,v}$ must satisfy the following integral equation for all twice continuously differentiable functions $f$ and $g$ with compact support:

$$ \int_{-\infty}^\infty g(x) T_{u,v}(f)(x) dx = \int_{-\infty}^\infty T_{u,v}(g)(x) f(x) dx $$

If there exists even one pair of functions $f, g$ where this equality fails, the link is unstable and the entire configuration is invalid.

Your task is to determine whether there is an assignment of operators (either 1 or 2) to all $n$ nodes such that every link in the network is stable. If multiple valid assignments exist, you must output the one that minimizes the sequence of assigned operator numbers $s_1, s_2, \dots, s_n$ lexicographically.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a link connects node $u$ and node $v$.

## Output
If no stable assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \ldots, s_n$ (each being 1 or 2) representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I changed the transformations from matrix multiplications to linear differential operators, and replaced the fixed-point condition with a formal self-adjointness integral equality. This forces models to perform symbolic integration by parts or recognize the adjoints of differential operators mathematically, preventing them from writing simple Python code to evaluate the combinations numerically.
</RATIONALE>
<PRESERVED_ANSWER>
The composed operator is self-adjoint if and only if the two assigned operators are different (since the adjoint of the derivative is its negative), so stable links still exactly correspond to edges connecting nodes with different assignments, preserving all valid configurations.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying constraint remains exactly $s_u \neq s_v$ for every edge, which is equivalent to finding the lexicographically smallest 2-coloring of a bipartite graph, solvable in O(n+m) time using Breadth-First Search, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "compact support" or attempt to plug in specific functions that coincidentally satisfy the integral, but the universal quantifier "for all" makes the mathematical requirement unambiguous.
</RISK>
<METHOD_NAME>
Differential Operator Self-Adjointness
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the matrix multiplication and vector fixed-point condition with the composition of linear differential operators and a formal self-adjointness condition (integral equality). This perfectly preserves the XOR logic (1 and 2 commute to a self-adjoint operator, while 1-1 and 2-2 do not) while moving the domain from linear algebra to functional analysis. It defeats models that write simple Python scripts to test transformations, because evaluating definite integrals of abstract functions over the real line is extremely difficult for LLM-generated sympy scripts.
</METHOD_DESCRIPTION>
