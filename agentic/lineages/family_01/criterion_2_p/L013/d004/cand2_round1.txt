# Orbital Array Equilibrium

Time limit: 1 s
Memory limit: 256 MB

An orbital array contains $n$ synchronization nodes. Each node must be configured with a resonance tier of either 1 or 2. 

The array is stabilized by $m$ harmonic tethers. Each tether connects two specific nodes and continuously monitors their resonance tiers. To maintain equilibrium, a tether evaluates a stability polynomial $P(x) = x^3 + a x^2 + b x + 1$, where $a$ and $b$ are the resonance tiers of its two connected nodes. (The order in which $a$ and $b$ are assigned to the coefficients does not affect whether the polynomial has rational roots). The tether remains balanced if and only if the equation $P(x) = 0$ has no rational solutions. If any tether detects a rational root in its stability polynomial, it triggers a system halt.

Your task is to determine whether there is an assignment of resonance tiers for all $n$ nodes that keeps every tether balanced. If multiple such assignments exist, the safety override protocol requires the one that is lexicographically smallest (i.e., the sequence of resonance tiers $s_1, s_2, \dots, s_n$ must be as small as possible when compared element by element starting from the first node).

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a harmonic tether connects node $u$ and node $v$.

## Output
If no balanced assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being 1 or 2) representing the lexicographically smallest balanced assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The direct arithmetic condition `a*b + a + b = 5` was replaced with a bespoke algebraic condition: the polynomial `x^3 + ax^2 + bx + 1 = 0` having no rational roots. By the Rational Root Theorem, the only possible rational roots are 1 and -1. Substituting x=1 gives `a+b+2=0` (impossible for tiers 1 or 2), and x=-1 gives `a-b=0`. Thus, the polynomial has no rational roots if and only if `a != b`. This forces models to perform a symbolic deduction step before they can recognize the bipartite graph coloring structure, defeating models that rely on surface pattern matching of explicit equations.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the polynomial has no rational roots is mathematically equivalent to the nodes having different resonance tiers (since a=b yields the rational root x=-1), which exactly mirrors the original `a*b + a + b = 5` constraint for values restricted to {1, 2}.
</PRESERVED_ANSWER>

The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in O(n + m) time using Breadth-First Search.
</PRESERVED_CLASS>
