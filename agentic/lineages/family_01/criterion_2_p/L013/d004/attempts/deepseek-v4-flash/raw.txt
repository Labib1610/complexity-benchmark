We can model each row as a constraint: if a row has 1s in columns \(u\) and \(v\), then  
\(s_u + s_v = 3\), meaning one must be 1 and the other 2.  

This is a **2-coloring problem** on a graph where columns are vertices and rows are edges.  
We need to assign each vertex a value from {1, 2} such that adjacent vertices have different values.  
If the graph is bipartite, a solution exists; otherwise, it doesn’t.

To get the lexicographically smallest assignment, we run BFS/DFS and assign the smallest possible value (1) when we start a new component.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n  # 0 = uncolored, 1 or 2
possible = True

for i in range(n):
    if color[i] == 0:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == 0:
                    color[v] = 3 - color[u]  # 1 -> 2, 2 -> 1
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    print(" ".join(map(str, color)))
```
