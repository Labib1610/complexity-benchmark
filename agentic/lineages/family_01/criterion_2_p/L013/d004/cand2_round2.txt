<STATEMENT>
# Orbital Array Equilibrium

Time limit: 1 s
Memory limit: 256 MB

An orbital array contains $n$ synchronization nodes. Each node must be configured with a resonance tier of either 1 or 2. 

The array is stabilized by $m$ harmonic tethers. Each tether connects two specific nodes and continuously monitors their resonance tiers. To maintain equilibrium, a tether requires a precise relationship between its endpoints. It remains balanced if and only if a right-angled triangle, whose two perpendicular legs have lengths equal to the resonance tiers of its two connected nodes, has an area of exactly 1. If any tether detects that its monitored nodes do not satisfy this condition, it triggers a system halt.

Your task is to determine whether there is an assignment of resonance tiers for all $n$ nodes that keeps every tether balanced. If multiple such assignments exist, the safety override protocol requires the one that is lexicographically smallest (i.e., the sequence of resonance tiers $s_1, s_2, \dots, s_n$ must be as small as possible when compared element by element starting from the first node).

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a harmonic tether connects node $u$ and node $v$.

## Output
If no balanced assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \dots, s_n$ (each being 1 or 2) representing the lexicographically smallest balanced assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The previous version used an algebraic equation ($ab+a+b=5$) that models easily recognized as equivalent to an opposite-value constraint, leading them straight to bipartite graph coloring. I replaced this with a geometric condition: the area of a right-angled triangle formed by the two tiers must be exactly 1. Since Area = 0.5 * base * height, this requires tier1 * tier2 = 2. Given the tiers can only be 1 or 2, this strictly requires one tier to be 1 and the other to be 2. This forces the model to perform a step of geometric deduction before it can discover the structural requirement for the nodes.
</RATIONALE>
<PRESERVED_ANSWER>
The geometric condition (Area = 0.5 * tier1 * tier2 = 1) is mathematically true if and only if the tiers are exactly 1 and 2, which is identical to the original constraint, ensuring all valid assignments and the lexicographical tie-breaker remain exactly identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks for a valid assignment of two values across a graph such that adjacent nodes have different values, which remains identically equivalent to 2-coloring (bipartiteness testing) and is solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
