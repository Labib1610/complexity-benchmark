<STATEMENT>
# Render Contrast

Time limit: 1 s
Memory limit: 256 MB

A visual synthesis engine is rendering a scene with $n$ material layers, numbered 1 through $n$. The engine's architecture limits scenes to a maximum capacity of 200,000 material layers, while always requiring at least one. Each layer must be configured with a transparency mode, which takes an integer value of either 1 or 2.

The engine must enforce $m$ contrast constraints to prevent visual artifacts. The engine's constraint buffer can hold up to 200,000 contrast constraints, though it is possible for a scene to have none. Each constraint involves exactly two specific layers. To satisfy a constraint, the larger of the two assigned transparency modes must be exactly double the smaller one.

Determine if there exists a valid configuration of transparency modes for all $n$ layers that satisfies every contrast constraint.

## Input
The first line contains two integers $n$ and $m$, representing the number of layers and constraints respectively.
Each of the following $m$ lines contains two integers $u$ and $v$ (valid layer numbers between 1 and $n$), representing two layers involved in a single contrast constraint.

## Output
If no valid configuration exists, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers representing the lexicographically smallest valid sequence of transparency modes for layers 1 through $n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit product-two condition was replaced with a requirement that the larger of the two assigned modes must be exactly double the smaller one. Since the only valid modes are 1 and 2, this enforces exactly the same constraint (that the two layers must receive different modes) but requires the model to deduce the relationship rather than matching a well-known bipartite checking pattern. The bare inequalities for the bounds were also replaced with descriptive architectural limits and buffer capacities to satisfy the strategy.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the larger mode must be double the smaller mode is only satisfied when one layer is assigned 1 and the other is assigned 2, which is mathematically identical to their product being exactly 2.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to checking if a graph is bipartite (2-colorable) and returning the lexicographically first valid coloring, keeping it firmly in P and solvable in O(n+m) via BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "the larger of the two assigned transparency modes" if they fail to realize that if both layers are assigned the same mode (e.g., both 1), the "larger" and "smaller" are both 1, which fails the "exactly double" condition.
</RISK>
