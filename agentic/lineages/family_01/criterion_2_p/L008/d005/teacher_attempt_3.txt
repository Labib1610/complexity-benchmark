# Laser Routing

Time limit: 1 s
Memory limit: 256 MB

A space agency is deploying a constellation of $n$ satellites, numbered 1 through $n$. Each satellite must be placed into a circular orbit with a radius of either 1 or 2 (measured in standardized units).

The constellation's routing protocol requires $m$ continuous laser communication links to be established. Each link connects two specific satellites. To maintain optical focus without recalibration, the geometry of the network demands that the sum of the squares of the orbital radii for any two linked satellites must evaluate to exactly 5.

Determine if there exists a valid assignment of orbital radii for all $n$ satellites such that all $m$ communication links satisfy this geometric requirement.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing two satellites that must be connected by a laser link.

## Output
If no valid orbital assignment exists, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers representing the lexicographically smallest valid sequence of orbital radii for satellites 1 through $n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
