<STATEMENT>
# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

A factory employs $n$ workers, with $m$ synchronization links established among them. You must assign a shift code $s_i \in \{1, 2\}$ to each worker $i$. 

To maintain proper timing, each worker's machine generates two diagnostic signals based on their shift code: a primary signal of $s_i$ and a secondary signal of $2s_i$. 

When two workers $u$ and $v$ are connected by a synchronization link, their machines exchange data to form two combined cross-signals: $(s_u + 2s_v)$ and $(2s_u + s_v)$. The synchronization link is stable if and only if these two cross-signals are coprime (i.e., their greatest common divisor is exactly 1).

Determine if there is a valid assignment of shift codes for all workers such that every synchronization link in the factory is stable.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of workers connected by a synchronization link.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \ldots, s_n$ (each in $\{1,2\}$) representing the valid assignment. If there are multiple valid assignments, output the one that is lexicographically smallest as a full sequence of $n$ integers.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Removed the explicit gear teeth values and the symmetry note that directly spelled out the need for complementary states. Replaced it with a diagnostic signal condition using the greatest common divisor of linear combinations, forcing the model to evaluate the condition over the domain {1, 2} to discover it is equivalent to a strict inequality constraint.
</RATIONALE>
<PRESERVED_ANSWER>
Evaluating gcd(s_u + 2s_v, 2s_u + s_v) for s_i in {1, 2} yields 1 if and only if s_u != s_v (since gcd(5, 4) = 1, while gcd(3, 3) = 3 and gcd(6, 6) = 6), which is exactly the same bipartite constraint as the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of a graph, keeping it in P and solvable in linear time using BFS/DFS.
</PRESERVED_CLASS>
