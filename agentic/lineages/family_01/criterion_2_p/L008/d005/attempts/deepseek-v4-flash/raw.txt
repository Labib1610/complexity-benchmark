We can model this as a graph problem.  
For each edge \((u, v)\), the value is:

\[
x^2 + y^2 - xy
\]

If \(x, y \in \{1, 2\}\), the possible values are:

- \(1,1 \to 1+1-1 = 1\)
- \(1,2 \to 1+4-2 = 3\)
- \(2,1 \to 4+1-2 = 3\)
- \(2,2 \to 4+4-4 = 4\)

We need the product over all edges to be \(3^m\).  
That means every edge must contribute exactly 3, so every edge must connect a 1 and a 2.  
Thus, the graph must be bipartite, with one part assigned 1 and the other 2.

We also need the lexicographically smallest assignment.  
We can do BFS/DFS, assigning 1 to the first node, and alternating.  
If a conflict occurs, output `NO`.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
