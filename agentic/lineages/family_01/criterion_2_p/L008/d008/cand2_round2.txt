<STATEMENT>
# Problem B — Harmonic Resonance

Time limit: 1 s   Memory limit: 256 MB

A factory employs $n$ workers, with $m$ synchronization links established among them. You must assign a shift $s_i \in \{1, 2\}$ to each worker $i$. 

To maintain proper timing, the system must satisfy a local equilibrium for every worker. For any worker $i$, let $d_i$ be the total number of synchronization links connected to them. Let $v_{i,1}, v_{i,2}, \ldots, v_{i,d_i}$ be the workers at the other end of each of these links. The assignment is valid if and only if every worker $i$ satisfies the following equation:

$$s_i \sum_{k=1}^{d_i} s_{v_{i,k}} = 2 d_i$$

(If a worker has no synchronization links, i.e., $d_i = 0$, the sum is considered to be $0$.)

Determine if there is a valid assignment of shifts for all workers such that this equation holds for all $1 \le i \le n$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — representing a synchronization link between worker $u$ and worker $v$.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \ldots, s_n$ (each in $\{1,2\}$) representing the valid assignment. If there are multiple valid assignments, output the lexicographically smallest sequence $s_1, s_2, \ldots, s_n$. (Lexicographic order compares $s_1$, then $s_2$, etc.)

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit pairwise inequality constraint with a mathematically equivalent vertex-centric equation. Because the states are restricted to {1, 2}, the equation is satisfied if and only if all neighbors of a vertex have the opposite state. This forces the model to perform algebraic deduction to recover the bipartite coloring condition, disrupting simple pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The equation with states in {1, 2} strictly requires neighbors to be 2 when the worker is 1, and 1 when the worker is 2, which is mathematically identical to the original inequality condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains exactly 2-coloring (checking bipartiteness and assigning alternating colors), which is solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
