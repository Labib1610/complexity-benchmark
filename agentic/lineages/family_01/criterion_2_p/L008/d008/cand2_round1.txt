# Problem B — Harmonic Resonance

Time limit: 1 s
Memory limit: 256 MB

A factory operates with a workforce of $n$ employees. The system is designed with a strict capacity: the workforce size $n$ is at least one, and the number of active synchronization links $m$ is at least zero. The infrastructure guarantees that neither $n$ nor $m$ will ever exceed two hundred thousand.

You must assign a resonance state $s_i \in \{1, 2\}$ to each worker $i$. 

The factory's network has $m$ synchronization links between specific pairs of workers. To maintain stability, the network's global energy must satisfy a precise equilibrium equation. 
Let $d_i$ be the total number of synchronization links connected to worker $i$. 
Calculate the network's total weighted state $W = \sum_{i=1}^n d_i s_i$. 
Calculate the cross-link sum $C = \sum_{j=1}^m s_{u_j} s_{v_j}$, where $(u_j, v_j)$ are the two workers connected by the $j$-th synchronization link.

An assignment of resonance states is valid if and only if the following equation holds exactly:
$$3W - 2C = 5m$$

Determine if there is a valid assignment of states for all workers. 

## Input
The first line contains two integers $n$ and $m$ — the number of workers and the number of synchronization links. 
Each of the next $m$ lines contains two integers $u$ and $v$, indicating a synchronization link between worker $u$ and worker $v$.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \ldots, s_n$ (each in $\{1,2\}$) representing the valid state assignment. If there are multiple valid assignments, output the lexicographically smallest sequence $s_1, s_2, \ldots, s_n$. (Lexicographic order compares $s_1$, then $s_2$, etc.)

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

I replaced the local binary constraint ("connected workers cannot operate on the same shift") with a global algebraic equation. Models that rely on pattern-matching text like "different shifts" or "opposite colors" will no longer recognize the problem as a standard graph coloring or bipartiteness test. </RATIONALE>
<PRESERVED_ANSWER>
The term for each edge in the global sum evaluates to 5 if the endpoints have different states, and 4 if they have the same state; since the target sum is exactly $5m$, the equation holds if and only if every edge connects different states, making it mathematically identical to the original bipartite constraint.
</PRESERVED_ANSWER>
