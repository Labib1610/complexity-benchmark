We can model this as a bipartite graph problem.  
Since \( s_u^2 + s_v^2 = 5 \) and \( s \in \{1,2\} \), the only valid pairs are (1,2) or (2,1).  
So each edge must connect nodes of different types — this is exactly a bipartite graph check.

We also need the lexicographically smallest assignment, so we try to assign 1 whenever possible during BFS/DFS.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    print(" ".join(str(color[i]) for i in range(n)))
```
