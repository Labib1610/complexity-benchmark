# Botanical Equilibrium

Time limit: 1 s   Memory limit: 256 MB

A botanical research facility is cultivating $n$ distinct plant species, sequentially numbered starting from 1 up to $n$. The facility requires at least one species to operate, and its maximum capacity is two hundred thousand species.

The head botanist must assign a nutrient dosage level to each species. The assigned dosage level for each species must be a positive integer. Due to toxicity constraints, no dosage level can exceed 2.

The facility features an irrigation network consisting of $m$ hydroponic tubes. The network can be completely absent (zero tubes) or contain up to two hundred thousand tubes. Each tube forms a direct link between exactly two specific species. To maintain chemical equilibrium within the irrigation network and prevent filter blockages, any two species that share a direct tube link must be assigned distinct dosage levels.

Determine if it is possible to assign a dosage level to all $n$ species such that chemical equilibrium is maintained across all tubes.

## Input
The first line contains two integers $n$ and $m$, representing the number of species and the number of tubes. The limits on these values are defined by the facility's capacities described above.
Each of the following $m$ lines contains two integers $u$ and $v$. These values are valid species identifiers (from 1 up to $n$, inclusive) representing a pair of species linked by a hydroponic tube.

## Output
If no valid assignment of dosage levels exists, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1 \dots s_n$ (each being a valid dosage level), representing the lexicographically smallest valid assignment of dosage levels.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
