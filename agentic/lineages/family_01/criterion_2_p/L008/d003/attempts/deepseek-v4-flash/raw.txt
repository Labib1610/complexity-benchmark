We need to check if we can assign each worker a shift code 1 or 2 such that for every edge (u, v), the two-digit number `10*s_u + s_v` is divisible by 3.

Let’s analyze the condition:

- If `s_u = 1` and `s_v = 1` → 11 → 1+1=2 → not divisible by 3.
- If `s_u = 1` and `s_v = 2` → 12 → 1+2=3 → divisible by 3.
- If `s_u = 2` and `s_v = 1` → 21 → 2+1=3 → divisible by 3.
- If `s_u = 2` and `s_v = 2` → 22 → 2+2=4 → not divisible by 3.

So the only valid pairs are (1,2) and (2,1).  
That means every edge must connect two workers with **different** shift codes.

Thus, the graph must be bipartite.  
If it’s not bipartite, output `NO`.  
If it is, we can color it with 1 and 2.  
We also need the lexicographically smallest assignment, so we start coloring from node 1 with 1, and BFS/DFS assign alternating colors.

Let’s implement it.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
