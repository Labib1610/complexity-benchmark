We need to assign each species a dosage of either 1 or 2, such that for every edge (u, v), the product of their dosages is exactly 2.  

That means:  
- If one is 1, the other must be 2.  
- If one is 2, the other must be 1.  

So this is exactly a **bipartite graph** problem:  
- Color one side as 1, the other as 2.  
- If the graph is not bipartite, it’s impossible.  

We also need the **lexicographically smallest** assignment.  
That means we should try to assign 1 to the smallest-index node whenever possible.  
We can do this with BFS/DFS, starting from each unvisited node in increasing order, and assigning it 1 if possible.  

Here’s the implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n  # -1 = uncolored, 0 = dosage 1, 1 = dosage 2

def bfs(start):
    q = deque([start])
    color[start] = 0  # try to assign 1
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        if not bfs(i):
            print("NO")
            sys.exit()

print("YES")
print(" ".join(str(color[i] + 1) for i in range(n)))
```
