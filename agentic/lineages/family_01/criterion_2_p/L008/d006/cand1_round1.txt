# Problem B — Anti-Glare Arrays

Time limit: 1 s   Memory limit: 256 MB

An optical instrument contains $n$ crystal lenses. Each lens must be assigned a polarization axis, which must be an integer value of either 1 or 2.

The instrument is equipped with $m$ calibration tubes. Each tube connects a pair of lenses.

The instrument's diagnostic system validates the configuration by computing a *resonance* for each lens. For any lens $i$, let $d_i$ be the number of tube endpoints attached to it. For each of these $d_i$ endpoints, consider the lens attached to the *other* endpoint of the same tube. The resonance of lens $i$ is defined as its own polarization axis multiplied by the sum of the polarization axes of those $d_i$ lenses. (If $d_i = 0$, the sum is 0, so the resonance is 0).

To successfully filter out glare, every lens $i$ must have a resonance exactly equal to $2 d_i$.

Determine an assignment of polarization axes for all $n$ lenses that satisfies this requirement, or report that the hardware configuration is flawed.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the two lenses connected by that calibration tube.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES`, followed by a second line with $n$ integers $c_1 \dots c_n$ (each in $\{1,2\}$). This sequence must represent the valid calibration assignment. If multiple valid assignments exist, output the lexicographically smallest sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The previous version used an edge-based product formula that models easily pattern-matched to $x \neq y$, bypassing any reasoning. I replaced this with a node-centric aggregate condition: a lens's value multiplied by the sum of its neighbors' values must equal twice its degree. This forces the model to mathematically deduce that if $c_i=1$, its neighbors must sum to $2d_i$ (so they are all 2), and if $c_i=2$, they must sum to $d_i$ (so they are all 1). This deduction step breaks surface-level pattern matching while preserving the underlying structure.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $c_i \sum_{j \in N(i)} c_j = 2 d_i$ with $c_k \in \{1, 2\}$ algebraically forces $c_j = 2$ when $c_i = 1$ and $c_j = 1$ when $c_i = 2$, making it exactly equivalent to proper 2-coloring, so all valid assignments remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The valid configurations are exactly the proper 2-colorings of the graph, which means the problem remains solvable by bipartite checking via BFS/DFS in O(V+E) time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret how self-loops or multiple edges are counted, though the explicit definition using "tube endpoints" makes the graph-theoretic degree rigorous and unambiguous.
</RISK>
