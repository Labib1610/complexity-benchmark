<STATEMENT>
# Problem B — Anti-Glare Arrays

Time limit: 1 s   Memory limit: 256 MB

An optical instrument contains $n$ crystal lenses. Each lens must be assigned a polarization axis, which must be an integer value of either 1 or 2.

The instrument is equipped with $m$ calibration tubes, each routing light directly between a pair of lenses. The diagnostic system validates the configuration by evaluating its structural energy.

First, the system constructs an $n \times n$ matrix $L$, initially filled with zeros. For each of the $m$ calibration tubes, if the tube connects lens $u$ and lens $v$, the system updates $L$ by adding $1$ to $L_{u,u}$, adding $1$ to $L_{v,v}$, subtracting $1$ from $L_{u,v}$, and subtracting $1$ from $L_{v,u}$. 

Next, let $C$ be an $n \times 1$ column vector where the $i$-th entry is the assigned polarization axis $c_i \in \{1, 2\}$ for lens $i$. 

To successfully filter out glare, the scalar value resulting from the matrix multiplication $C^T L C$ (where $C^T$ is the transpose of $C$) must evaluate to exactly $m$.

Determine an assignment of polarization axes for all $n$ lenses that satisfies this requirement, or report that the hardware configuration is flawed.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the two lenses connected by that calibration tube.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES`, followed by a second line with $n$ integers $c_1 \dots c_n$ (each in $\{1,2\}$). This sequence must represent the valid calibration assignment. If multiple valid assignments exist, output the lexicographically smallest sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem is reframed using the Laplacian matrix quadratic form $C^T L C$. Because $c_i \in \{1, 2\}$, the quadratic form expands to the sum of $(c_u - c_v)^2$ over all tubes, which can only equal $m$ if every single tube connects different assignments. This completely replaces the per-edge local evaluation loop with a global linear algebra operation, forcing the models to deduce the maximum bound of the quadratic form to discover the bipartiteness requirement.
</RATIONALE>
<PRESERVED_ANSWER>
The sum of $m$ terms of $(c_u - c_v)^2$ where $c_i \in \{1, 2\}$ equals $m$ if and only if every term is exactly 1, meaning $c_u \neq c_v$ for every tube, which perfectly matches the seed's conflict logic including on self-loops (which contribute 0).
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying condition remains exactly equivalent to finding a valid 2-coloring of the graph, keeping it in the polynomial time class P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the updates to $L$ for self-loops ($u=v$), but the explicit instruction to add 1 twice and subtract 1 twice mathematically guarantees a net change of 0, making it strictly unambiguous.
</RISK>
