<STATEMENT>
# Render Contrast

Time limit: 1 s
Memory limit: 256 MB

A rendering system processes a composite scene consisting of $n$ distinct material layers, indexed from 1 to $n$. Every individual layer requires a specific transparency setting, which must be chosen as either the integer 1 or the integer 2.

To avoid rendering artifacts, the system is subject to $m$ interference restrictions. Every restriction links a specific pair of material layers. For a restriction to be successfully resolved, the sum of the squares of the transparency settings chosen for the two linked layers must evaluate to exactly 5.

You need to establish whether a complete assignment of transparency settings exists for the $n$ layers such that all interference restrictions are resolved.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$). These represent a pair of layers that are bound by a single interference restriction.

## Output
If it is impossible to find a valid assignment of settings, output a single line with `NO`.
Otherwise, print `YES` on the first line. On the second line, provide $n$ integers denoting the valid sequence of transparency settings $s_1, s_2, \ldots, s_n$ that minimizes the mathematical value of the sum $\sum_{i=1}^n s_i \cdot 3^{n-i}$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the interference restriction from "bitwise XOR to exactly 3" to "sum of the squares must evaluate to exactly 5", preventing direct pattern matching to bipartite coloring. Replaced the "lexicographically smallest" tie-break rule with an equivalent mathematical formulation (minimizing a base-3 polynomial sum), forcing the model to deduce that this prioritizes minimizing earlier indices.
</RATIONALE>
<PRESERVED_ANSWER>
The sum of squares of two variables chosen from {1, 2} is 5 if and only if one is 1 and the other is 2, matching the previous XOR condition; the polynomial sum minimization is strictly equivalent to finding the lexicographically smallest sequence.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring on an undirected graph, which is solvable in O(n+m) time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
Models might incorrectly attempt to compute the polynomial sum explicitly and fail due to integer overflow, though the problem only asks for the sequence that minimizes it mathematically.
</RISK>
