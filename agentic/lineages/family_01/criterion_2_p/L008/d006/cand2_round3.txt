# Problem B — Device Modes

Time limit: 1 s   Memory limit: 256 MB

You are configuring a network of $n$ devices. Each device must be set to one of two modes, represented by the integer 1 or 2.

The network has $m$ communication links, each connecting a pair of devices. To ensure stable communication, any two devices connected by a link must have their modes $x$ and $y$ chosen such that the value $x^3 + y^3 - (x \cdot y)^2$ is a prime number. 

Determine if there is a valid mode assignment for all $n$ devices. If multiple valid assignments exist, output the lexicographically smallest sequence of modes.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a link between device $u$ and device $v$.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line with $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1,2\}$). This sequence represents the mode assigned to each device from 1 to $n$. If there are multiple valid sequences, output the lexicographically smallest one.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The optical instrument narrative was replaced with a much more natural "devices and modes" setting to avoid reading like an artificial puzzle. The global product constraint $3^m$ was replaced with a local primality check on the symmetric polynomial $x^3 + y^3 - (x \cdot y)^2$. For the domain $\{1, 2\}$, this evaluates to 5 (prime) when $x \neq y$, and 1 or 0 (not prime) when $x = y$. This forces models to manually evaluate the condition for all combinations of 1 and 2 rather than pattern-matching a known bipartite graph reduction.
</RATIONALE>

</PRESERVED_ANSWER>
