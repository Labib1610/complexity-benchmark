# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

The factory operates continuously. Its daily cycle is split into two halves, encoded as schedule rotation 1 and schedule rotation 2. 

The factory employs $n$ workers and houses $m$ workstations. The workforce size $n$ is strictly positive. Due to safety regulations, neither the workforce size nor the number of workstations can exceed two hundred thousand. It is possible for the factory to have an empty floor with zero workstations. Each workstation has exactly two specific authorized operators from the workforce.

For a workstation to be fully operational, it must be staffed during both halves of the daily cycle. The payroll system enforces this by requiring that the sum of the schedule rotation codes assigned to its two authorized operators equals exactly 3.

Determine a valid schedule rotation (1 or 2) for every worker such that all workstations are fully operational, or report that no such configuration is possible.

## Input
The first line contains the two integers $n$ and $m$. The limits on these values are dictated by the safety regulations and minimum bounds described previously.
Each of the following $m$ lines provides two integers $u$ and $v$ — the identifiers of the two authorized operators for a single workstation.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
