# Cargo Dispatch

Time limit: 1 s   Memory limit: 256 MB

A logistics firm is organizing $n$ cargo shipments, numbered 1 through $n$. The operations manager must assign exactly one of two available dispatch periods, designated as 1 and 2, to each shipment.

The firm's schedule contains $m$ resource overlaps. Each overlap involves a pair of shipments that require the same specialized loading equipment. Because the equipment can only process one shipment at a time, if two shipments sharing an overlap are assigned to the same dispatch period, a severe bottleneck will occur. Consequently, any two shipments involved in a resource overlap must be assigned to different dispatch periods.

Determine if it is possible to assign a dispatch period to all $n$ shipments without causing any bottlenecks.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — a pair of shipments involved in a resource overlap.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise print `YES`, then a second line with $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

The problem was completely reframed from botany to logistics. By replacing "tubes connecting species" with "resource overlaps between shipments," models can no longer rely on obvious graph-theoretic keywords like "connected" to immediately recognize the structure as an adjacency list for 2-coloring.
</RATIONALE>

</PRESERVED_CLASS>
