# Botanical Treatments

Time limit: 1 s   Memory limit: 256 MB

A botanical research facility is cultivating $n$ distinct plant species, numbered 1 through $n$. Each species must be scheduled for a primary growth phase, recorded as either phase 1 or phase 2.

The facility has $m$ shared fluid conduits. Each conduit links exactly two specific species. Because of metabolite exchange, if two linked species are active in the same primary growth phase, a toxic reaction will ruin the water supply. Consequently, any two species connected by a conduit must be scheduled for differing phases.

The facility's soil reserves total exactly 2,000,000 cubic centimeters, and every cultivated species strictly requires 10 cubic centimeters. This physical constraint establishes the maximum possible value for $n$, while every experiment must include at least one species. Similarly, the plumbing inventory holds 400,000 meters of piping, and each fluid conduit consumes exactly 2 meters of it, establishing the maximum possible value for $m$, which can be as small as zero.

Determine if it is possible to assign a primary growth phase to all $n$ species without causing any toxic reactions.

## Input
The first line contains two integers $n$ and $m$.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of species connected by a fluid conduit. Since they identify specific species, $u$ and $v$ are guaranteed to be positive integers no larger than the total number of species in the experiment.

## Output
If no safe schedule exists, print a single line `NO`.
Otherwise print `YES`, then a second line with $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid schedule.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

I replaced the direct numeric bounds with physical constraints (total soil volume and piping length divided by per-item requirements) that evaluate exactly to the original limits. I also disguised the "nutrient blends" as "growth phases" to slightly obscure the bipartite coloring nature. This forces the model to read and comprehend the descriptive text to extract the constraints rather than relying on standard parenthetical inequalities.
</RATIONALE>
<PRESERVED_ANSWER>
The core requirement of assigning one of two mutually exclusive states to each node in a graph, such that no two adjacent nodes share a state, remains identical, preserving the lexicographically smallest 2-coloring output.
</PRESERVED_ANSWER>

The problem is still fundamentally asking for the lexicographically smallest 2-coloring of a graph, which is solvable in O(n+m) using BFS/DFS, keeping it in P.
</PRESERVED_CLASS>
