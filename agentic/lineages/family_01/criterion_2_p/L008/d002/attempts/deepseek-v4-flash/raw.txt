We need to assign each worker a shift code 1 or 2 such that for every edge (u, v), the pair [s_u, s_v] is a contiguous subarray of [1, 2, 1].  

The possible contiguous subarrays of length 2 are:  
- [1, 2]  
- [2, 1]  

So for every edge, the two endpoints must have different shift codes.  

That means the graph must be bipartite. If it is, we can color it with two colors (1 and 2).  
We also need the lexicographically smallest assignment, so we start with worker 1 assigned 1, and BFS/DFS color the graph, assigning the opposite color to neighbors. If a conflict occurs, output NO.  

Here’s the implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
