<METHOD_NAME>Non-negative Matrix Monoid Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>
Maps each link's state pair to a 2x2 matrix with non-negative integer entries. Valid pairs (opposite states) map to the Identity matrix. Invalid pairs (same states) map to matrices with a positive off-diagonal entry. The global footprint is the product of these matrices, required to be the Identity. Because the matrices are non-negative and have 1s on the diagonal, their product can only be the Identity if every factor is the Identity. This forces all pairs to have opposite states, preserving the bipartite coloring requirement. It defeats the model by replacing a simple scalar product with a matrix product over a monoid where the monotonicity of off-diagonal elements is not immediately obvious, preventing the model from using simple prime factorization or bounding arguments to deduce the local condition.
</METHOD_DESCRIPTION>

# Problem B — Harmonic Resonance

Time limit: 1 s   Memory limit: 256 MB

A facility operates $n$ resonance generators. There are $m$ interference testing links, each connecting a specific pair of generators. You must configure the facility by assigning each generator $i$ a state $s_i \in \{1, 2\}$.

For any configuration, the system's overall resonance footprint is represented by a $2 \times 2$ transformation matrix $M$. Initially, $M$ is the identity matrix $\begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}$.

The footprint is evaluated by processing the $m$ links sequentially as they appear in the input. For each link connecting generators $u$ and $v$, an interference matrix $T$ is generated:

$T = \begin{pmatrix} 1 & 4 - 2s_u - 2s_v + s_u s_v \\ s_u s_v - s_u - s_v + 1 & 1 \end{pmatrix}$

The system's footprint is then updated by right-multiplying the current matrix $M$ by $T$ (that is, $M \leftarrow M \times T$). If $m=0$, no updates occur and the footprint remains the identity matrix.

To ensure system stability, a configuration is only valid if its final overall resonance footprint is exactly the identity matrix $\begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}$.

Determine if there is a valid configuration for all $n$ generators.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of generators connected by an interference testing link.

## Output
If no valid configuration exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \ldots, s_n$ (each in $\{1,2\}$) representing the valid configuration. If there are multiple valid configurations, output the one that minimizes the state $s_1$. If there is still a tie, minimize $s_2$, and so on sequentially up to $s_n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The previous scalar product condition allowed models to trivially deduce the local edge constraint using unique prime factorization ($3^m$). This rewrite replaces the scalar product with a product of non-negative $2 \times 2$ matrices. To solve the problem efficiently, a model must now deduce the monotonicity of off-diagonal elements in this specific matrix monoid—realizing that the product can only be the Identity if every individual matrix is the Identity. This requires genuine mathematical reasoning about matrix multiplication semantics rather than pattern-matching a known algebraic shortcut.
</RATIONALE>
<PRESERVED_ANSWER>
The matrix $T$ evaluates to the Identity matrix if and only if $s_u \neq s_v$; otherwise, it has a strictly positive off-diagonal entry, which permanently increases the off-diagonal entries of the running product, ensuring the final matrix is the Identity if and only if every link has $s_u \neq s_v$.
</PRESERVED_ANSWER>
