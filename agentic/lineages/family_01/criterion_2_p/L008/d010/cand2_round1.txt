<METHOD_NAME>Matrix Anti-Commutator Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the scalar LCM arithmetic with the anti-commutator of two carefully chosen nilpotent matrices. Evaluating the anti-commutator yields the zero matrix when the modes are identical, and a scaled identity matrix when they differ. This strictly enforces the "opposite assignment" condition required for 2-coloring without relying on easily recognizable scalar inequalities, prime factors, or parity checks, forcing the model to execute matrix algebra to uncover the graph structure.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Anti-Glare Arrays

Time limit: 1 s
Memory limit: 256 MB

An optical instrument contains $n$ crystal lenses. Each lens must be assigned a polarization mode, which must be an integer value of either $1$ or $2$.
The physical chassis requires at least $1$ lens and limits $n$ to at most the number of seconds in $55$ hours, $33$ minutes, and $20$ seconds.

The instrument is equipped with $m$ calibration tubes, each routing data between a pair of lenses. The number of tubes $m$ can be as low as $0$, and its maximum possible value is exactly the same as the absolute maximum capacity for lenses.
The instrument's diagnostic system validates the configuration by checking the local resonance at each tube.

Each polarization mode corresponds to a specific $2 \times 2$ transformation matrix:
Mode $1$ corresponds to the matrix $M_1 = \begin{pmatrix} 1 & -1 \\ 1 & -1 \end{pmatrix}$.
Mode $2$ corresponds to the matrix $M_2 = \begin{pmatrix} 1 & 1 \\ -1 & -1 \end{pmatrix}$.

For a calibration tube connecting lens $u$ and lens $v$, its local resonance is determined by evaluating the matrix expression:
$$R_{u,v} = M_u M_v + M_v M_u$$
where $M_u$ and $M_v$ are the transformation matrices corresponding to the polarization modes assigned to lens $u$ and lens $v$, respectively.

To successfully filter out glare, there must exist some valid assignment of polarization modes to all $n$ lenses such that for every single calibration tube, its local resonance matrix $R_{u,v}$ is exactly equal to $\begin{pmatrix} 4 & 0 \\ 0 & 4 \end{pmatrix}$.

Determine an assignment of polarization modes for all $n$ lenses that makes such a configuration possible, or report that the hardware configuration is flawed.

## Input
The first line contains two integers $n$ and $m$, representing the number of lenses and calibration tubes respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the two lenses connected by that calibration tube.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES`, followed by a second line with $n$ integers $c_1 \dots c_n$ (each in $\{1,2\}$). This sequence must represent the valid assignment. If multiple valid assignments exist, output the lexicographically smallest sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The direct LCM arithmetic condition was completely replaced with a matrix anti-commutator constraint. The matrices are designed so that identical modes yield the zero matrix, while different modes yield the required $4I$ matrix. This forces the model to evaluate the matrix products to uncover the underlying bipartite requirement, preventing simple pattern matching on complementary scalar factors. The bounds were also rewritten indirectly using a physical time-based summation.
</RATIONALE>
<PRESERVED_ANSWER>
The anti-commutator $M_u M_v + M_v M_u$ evaluates to the required matrix if and only if $M_u \neq M_v$, maintaining the exact same constraint that connected lenses must have different polarization modes.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains identically equivalent to finding the lexicographically smallest valid 2-coloring of an undirected graph, which is solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
