**Solution Explanation**

For a generator we choose a state  

* `1`  → complex number `c₁ = 1 + i`  
* `2`  → complex number `c₂ = 1 – i`

For an edge `{u,v}` we compute  

```
imag( c_{s_u} * c_{s_v} )
```

and add its square to the total footprint.
The footprint must be `0`.  
Since a square is never negative, every single term has to be `0`.

--------------------------------------------------------------------

#### 1.   When is the imaginary part zero ?

```
c₁ * c₁ = (1+i)² = 2 i          → imag =  2
c₂ * c₂ = (1-i)² = -2 i         → imag = -2
c₁ * c₂ = (1+i)(1-i) = 2        → imag =  0
c₂ * c₁ = 2                     → imag =  0
```

The imaginary part is `0` **iff the two endpoints have different states**.
Therefore a valid configuration is exactly a *proper 2‑colouring* of the
graph: adjacent vertices must receive opposite colours (`1` and `2`).

So the problem reduces to

*Is the given graph bipartite?*  
If yes, output a bipartite colouring that is lexicographically minimal
(`s₁` as small as possible, then `s₂`, …).

--------------------------------------------------------------------

#### 2.   Lexicographically minimal bipartite colouring

A connected bipartite component has exactly two colourings – they are
each other’s colour swap.
When we process vertices in increasing order `1 … n` and start a BFS/DFS
whenever we meet an *unvisited* vertex `v`, `v` is the **smallest index**
in its component (all smaller vertices are already processed).

To obtain the smallest possible `s_v` we simply force `v` to colour `1`.
All other vertices of the component receive the forced colour
(`1` for the same parity as `v`, `2` for the opposite parity).

Thus the greedy rule

```
start vertex of each component → colour 1
```

produces the globally lexicographically minimal assignment.

--------------------------------------------------------------------

#### 3.   Algorithm
```
read n, m
build adjacency list
state[1..n] = 0   // 0 = unvisited, 1 or 2 = final state
parity[1..n] = -1 // temporary 0/1 inside a component

for v = 1 .. n
    if state[v] == 0
        // new component, start BFS with parity 0
        queue ← [v]
        parity[v] = 0
        while queue not empty
            x = pop queue
            for each neighbour y of x
                if parity[y] == -1
                    parity[y] = 1 - parity[x]
                    push y
                else if parity[y] == parity[x]
                    print "NO" and exit   // not bipartite
        // component finished, decide final states
        // parity 0 → state 1, parity 1 → state 2
        for each vertex u with parity[u] != -1 in this component
            state[u] = (parity[u] == 0) ? 1 : 2
            parity[u] = -1   // reset for next component
print "YES"
print state[1] … state[n]
```

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `NO` iff no valid configuration exists,
otherwise prints `YES` and the lexicographically smallest valid
configuration.

---

##### Lemma 1  
For any edge `{u,v}` the imaginary part of the product of the two emitted
complex numbers is zero **iff** the states of `u` and `v` are different.

*Proof.* Direct computation shown in the table above. ∎



##### Lemma 2  
A configuration has total footprint `0` **iff** the underlying graph is
bipartite and the configuration is a proper 2‑colouring (adjacent vertices
receive different states).

*Proof.* By Lemma&nbsp;1 each edge contributes `0` exactly when its endpoints
have different states. The total sum of squares is `0` exactly when every
edge contributes `0`. Hence all edges must connect vertices of different
states, i.e. the graph is bipartite and the assignment is a proper
2‑colouring. ∎



##### Lemma 3  
During the BFS of a component the algorithm assigns a parity (`0` or `1`)
to every vertex such that adjacent vertices obtain opposite parity
*iff* the component is bipartite. If a conflict is detected, the component
is not bipartite.

*Proof.* Standard BFS bipartiteness test: we start with an arbitrary vertex
(parity 0) and always give an unvisited neighbour the opposite parity.
If we ever encounter an already visited neighbour with the same parity,
there exists an odd cycle, i.e. the component is not bipartite.
Conversely, if the component is bipartite, a 2‑colouring exists and the
BFS will never meet a same‑parity edge. ∎



##### Lemma 4  
If the algorithm finishes without printing `NO`, the produced `state`
array is a proper 2‑colouring of the whole graph.

*Proof.* By Lemma&nbsp;3 each component is bipartite and the BFS assigned a
consistent parity. Afterwards we set `state = 1` for parity 0 and `state = 2`
for parity 1, therefore adjacent vertices (different parity) receive different
states. ∎



##### Lemma 5  
For every component the algorithm chooses the orientation (which parity
maps to state 1) that gives the smallest possible state for the smallest
vertex index of that component.

*Proof.* When a component is first encountered, its smallest vertex `v`
is the start vertex of the BFS and receives parity 0.
The algorithm maps parity 0 → state 1, thus `s_v = 1`. The alternative
orientation would map parity 0 → state 2, giving `s_v = 2 > 1`. Hence the
chosen orientation is optimal for `v`. ∎



##### Lemma 6  
The whole `state` array output by the algorithm is lexicographically
minimal among all valid configurations.

*Proof.* Consider the first index `k` where any valid configuration differs
from the algorithm’s output.
All vertices `< k` belong to components already processed earlier, and by
Lemma&nbsp;5 each of those components already has the smallest possible
states for its smallest vertex, therefore any other configuration must have
identical states on those vertices.
Vertex `k` is the smallest vertex of its component (otherwise an earlier
vertex of the same component would differ). By Lemma&nbsp;5 the algorithm
assigns `s_k = 1`, the minimal possible value. Any other valid configuration
must have `s_k = 2`. Hence the algorithm’s sequence is lexicographically
smaller. ∎



##### Theorem  
The algorithm prints  

* `NO` **iff** no valid configuration exists;  
* otherwise `YES` followed by the lexicographically smallest valid
  configuration.

*Proof.*  
- If the algorithm prints `NO`, it detected a same‑parity edge inside a
  component, i.e. the component is not bipartite (Lemma&nbsp;3). By
  Lemma&nbsp;2 no valid configuration exists.
- If the algorithm finishes, every component is bipartite, therefore a
  proper 2‑colouring exists (Lemma&nbsp;2). Lemma&nbsp;4 shows the produced
  `state` array is a proper 2‑colouring, hence a valid configuration.
  Lemma&nbsp;6 proves it is the lexicographically smallest one.

Thus the theorem holds. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once →  
`O(n + m)` time, `O(n)` additional memory for queues and arrays.

Overall: **Time `O(n + m)`**, **Memory `O(n + m)`**, well within limits.

#### 6.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    state = [0] * (n + 1)          # final answer, 0 = unassigned, 1 or 2
    parity = [-1] * (n + 1)       # temporary 0/1 inside current component
    q = deque()

    for start in range(1, n + 1):
        if state[start]:
            continue
        # new component, start BFS with parity 0
        parity[start] = 0
        q.append(start)
        component_vertices = [start]

        while q:
            u = q.popleft()
            pu = parity[u]
            for v in adj[u]:
                if parity[v] == -1:
                    parity[v] = 1 - pu
                    q.append(v)
                    component_vertices.append(v)
                elif parity[v] == pu:
                    # not bipartite
                    sys.stdout.write("NO")
                    return

        # assign final states: parity 0 -> 1, parity 1 -> 2
        for v in component_vertices:
            state[v] = 1 if parity[v] == 0 else 2
            parity[v] = -1          # reset for next component

    # all good
    out = ["YES\n"]
    out.append(' '.join(str(state[i]) for i in range(1, n + 1)))
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
