 We need to assign each generator a state of either 1 or 2.  
Let’s map state 1 → value +1, state 2 → value -1 (or vice versa).  

The complex signatures are:  
- State 1: \(1 + i\)  
- State 2: \(1 - i\)  

For an edge between u and v, the product is:  
- If both same state: \((1+i)(1+i) = 1 + 2i + i^2 = 1 + 2i - 1 = 2i\) → imaginary part = 2  
- If both state 2: \((1-i)(1-i) = 1 - 2i + i^2 = 1 - 2i - 1 = -2i\) → imaginary part = -2  
- If different states: \((1+i)(1-i) = 1 - i^2 = 1 - (-1) = 2\) → imaginary part = 0  

So the imaginary part is zero only when the two endpoints have different states.  
The sum of squares of imaginary parts is zero if and only if every edge connects different states.  

That means the graph must be bipartite.  

So the problem reduces to:  
- Check if the graph is bipartite.  
- If yes, output a valid 2-coloring with state 1 for one side and state 2 for the other, choosing lexicographically smallest assignment (state 1 preferred for lower indices).  

We can do BFS/DFS coloring, and if a conflict occurs, output NO.  

Here’s the implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n  # -1 uncolored, 0 and 1 are the two sides

def bfs(start):
    q = deque([start])
    color[start] = 0
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        if not bfs(i):
            print("NO")
            sys.exit()

# Lexicographically smallest: prefer state 1 for lower indices
# color 0 -> state 1, color 1 -> state 2
res = [1 if c == 0 else 2 for c in color]
print("YES")
print(" ".join(map(str, res)))
```
