We can analyze the local stability index formula:

\[
3c_u + 3c_v - 2c_u c_v
\]

Since \( c_u, c_v \in \{1,2\} \):

- If both are 1: \( 3+3-2 = 4 \)
- If one is 1 and the other is 2: \( 3+6-4 = 5 \)
- If both are 2: \( 6+6-8 = 4 \)

So the index is 5 exactly when the two lenses have different polarization modes, and 4 when they are the same.

We need the total sum to be \( 5m \), meaning every edge must have different modes on its endpoints.  
That means the graph must be bipartite.

So the problem reduces to:  
Check if the graph is bipartite, and if so, output the lexicographically smallest 1/2 coloring.

For lexicographically smallest, we assign 1 to the first node, then BFS/DFS coloring, and if a conflict occurs, it's not bipartite.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
color[0] = 1
q = deque([0])

while q:
    u = q.popleft()
    for v in adj[u]:
        if color[v] == -1:
            color[v] = 3 - color[u]  # 1 -> 2, 2 -> 1
            q.append(v)
        elif color[v] == color[u]:
            print("NO")
            sys.exit()

# If graph is disconnected, color remaining components
for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(map(str, color)))
```
