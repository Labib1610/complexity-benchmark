<STATEMENT>
# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

A factory employs $n$ workers, with $m$ synchronization links established among them. You must assign a shift code $s_i \in \{1, 2\}$ to each worker $i$. 

To maintain proper timing, the network of machines must be locally balanced. For each worker $i$, let $d_i$ be the total number of synchronization links connected to them. The system is stable if and only if, for every worker $i$, the sum of the shift codes of the workers at the other end of each of their $d_i$ links, plus $d_i$ times worker $i$'s own shift code $s_i$, equals exactly $3 \times d_i$.

Determine if there is a valid assignment of shift codes for all workers.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of workers connected by a synchronization link.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \ldots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The original problem used a simple edge-wise divisibility rule to force $s_u \neq s_v$, allowing models to evaluate the 4 possible pairs for a single edge and immediately reduce the problem to bipartite coloring. By converting this into a vertex-neighborhood sum constraint, the edge-wise nature of the restriction is hidden. Models must now algebraically analyze the bounds of the local sum to deduce that the only way to satisfy the equation with variables in $\{1, 2\}$ is if every neighbor has the opposite shift code, enforcing genuine mathematical reasoning over surface pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic equation $d_i s_i + \sum s_j = 3 d_i$ with variables restricted to $\{1, 2\}$ is mathematically satisfied if and only if $s_j = 3 - s_i$ for every adjacent vertex, which is exactly the same $s_u \neq s_v$ requirement as the original problem, yielding the exact same valid assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains exactly 2-coloring (bipartiteness testing) on the given graph, which is solvable in $O(n+m)$ time using standard BFS or DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret how self-loops or multiple edges are counted in $d_i$, although the phrase "each of their $d_i$ links" makes the multiset sum well-defined.
</RISK>
<METHOD_NAME>Local-to-Global Constraint Transformation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaced an explicit edge-wise constraint with an algebraically equivalent vertex-neighborhood constraint (degree * x + sum(neighbors) = 3 * degree). This prevents models from trivially pattern-matching the edge condition to bipartite coloring, forcing them to algebraically deduce that the local sum bounds strictly require x != y for all edges.</METHOD_DESCRIPTION>
