# Botanical Equilibrium

Time limit: 1 s   Memory limit: 256 MB

A botanical research facility is cultivating $n$ distinct plant species, each identified by a unique integer from 1 up to $n$. The head botanist must assign a nutrient dosage level to each species. The facility's automated dispensers require each dosage to be a positive integer, but due to hardware constraints, they cannot dispense a dosage of 3 or higher.

The facility features an irrigation network consisting of $m$ hydroponic tubes. Each tube forms a direct link between exactly two specific species. To maintain chemical equilibrium within the irrigation network, the combined dosage levels of the two species connected by any single tube must sum to exactly 3.

Determine if it is possible to assign a dosage level to all $n$ species such that chemical equilibrium is maintained across all tubes. The facility has exactly two hundred thousand incubation chambers available for species, and an equal number of standardized tube connectors in stock.

## Input
The first line contains two integers $n$ and $m$, representing the actual number of species and tubes used in the current experiment. The value of $n$ is at least one, the value of $m$ is at least zero, and neither will exceed the facility's available inventory of chambers or connectors.
Each of the following $m$ lines contains two integers $u$ and $v$, representing a pair of species linked by a hydroponic tube. Both $u$ and $v$ will be valid identifiers between 1 and $n$ inclusive.

## Output
If no valid assignment of dosage levels exists, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1 \dots s_n$, representing the lexicographically smallest valid assignment of dosage levels.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
