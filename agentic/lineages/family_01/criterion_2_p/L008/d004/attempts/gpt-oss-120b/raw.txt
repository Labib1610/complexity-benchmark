**Solution Explanation**

For a worker  

* shift `1` → primary `5`, secondary `10`  
* shift `2` → primary `10`, secondary `5`

For a link `{u,v}` we need  

```
primary(u) = secondary(v)
```

The only possibilities are  

* `u` shift `1` (primary `5`) and `v` shift `2` (secondary `5`)  
* `u` shift `2` (primary `10`) and `v` shift `1` (secondary `10`)

So the two workers must have **different** shift codes.
All links therefore require the graph to be *bipartite*.
If the graph is not bipartite there is no assignment.

If it is bipartite, each connected component has exactly two possible
assignments – we may exchange the two colour classes.
We have to output the lexicographically smallest whole sequence
`(s1,…,sn)`.

--------------------------------------------------------------------

#### Lemma 1  
In a bipartite component, the lexicographically smallest assignment is
obtained by giving shift `1` to the colour class that contains the
smallest‑indexed vertex of this component.

*Proof.*  
Inside a component the two possible assignments are opposite:
every vertex of colour `0` gets `1` and colour `1` gets `2`,
or the reverse.
Let `p` be the smallest vertex index of the component.
The two assignments differ at `p` (one gives `1`, the other `2`);
all earlier positions belong to other components and are already fixed.
Since `1 < 2`, the assignment that gives `1` to `p` is lexicographically
smaller, and no later choice can improve it. ∎



--------------------------------------------------------------------

#### Algorithm
```
read n,m
build adjacency list
answer[1..n] = 0
colour[1..n] = -1          # -1 = unvisited, 0/1 = bipartite colour

for each vertex v = 1 .. n
    if colour[v] == -1
        # start a new component
        bfs queue with v, colour[v]=0
        store all vertices of this component in list comp
        while bfs
            for each neighbour to
                if colour[to] == -1: colour[to] = colour[cur] ^ 1, push
                elif colour[to] == colour[cur]:   # not bipartite
                        print "NO" and exit

        # component is bipartite
        min_v = min(comp)
        # which colour does min_v have?
        if colour[min_v] == 0:
                # colour 0 → shift 1, colour 1 → shift 2
                for x in comp:
                        answer[x] = 1 if colour[x]==0 else 2
        else:
                # opposite
                for x in comp:
                        answer[x] = 1 if colour[x]==1 else 2

print "YES"
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise prints `YES` and the lexicographically smallest valid assignment.

---

##### Lemma 2  
If the algorithm prints `NO`, the graph is not bipartite, therefore no
assignment satisfies all links.

*Proof.*  
`NO` is printed only when during BFS an edge connects two vertices with
the same colour. That is exactly a violation of bipartiteness.
If the graph is not bipartite, any 2‑colouring (hence any shift
assignment) would give equal colours to the ends of some edge, i.e. the
two workers would receive the same shift, contradicting the required
different shifts. ∎



##### Lemma 3  
If the algorithm finishes without printing `NO`, the produced `answer`
satisfies every link.

*Proof.*  
For each component BFS assigned colours `0/1` such that adjacent vertices
have opposite colours (otherwise we would have stopped with `NO`).
Later we set shift `1` to one colour class and shift `2` to the other.
Thus every edge connects a vertex with shift `1` and a vertex with shift
`2`, which is exactly the required condition. ∎



##### Lemma 4  
For each component the algorithm assigns shift `1` to the colour class
containing its smallest‑indexed vertex.

*Proof.*  
The algorithm computes `min_v = min(comp)`.  
If `colour[min_v]==0` it maps colour `0 → 1`, otherwise colour `1 → 1`.  
Hence the colour class of `min_v` receives shift `1`. ∎



##### Lemma 5  
The whole sequence `answer` is the lexicographically smallest among all
valid assignments.

*Proof.*  
Consider the components ordered by their smallest vertex index.
By Lemma&nbsp;4 the algorithm gives shift `1` to that smallest vertex of
each component.  
Take any other valid assignment `B`.  
Let `c` be the first component (in that order) where `B` differs from
our assignment. Their smallest vertex `p` belongs to `c`.  
Our assignment gives `1` to `p`; `B` must give `2` (otherwise the two
assignments would be identical on `c`).  
All positions before `p` are equal in both assignments, therefore our
sequence is lexicographically smaller. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no feasible shift assignment exists;  
* otherwise `YES` and the lexicographically smallest feasible assignment.

*Proof.*  
If the algorithm prints `NO`, by Lemma&nbsp;2 no assignment exists.
If it does not print `NO`, Lemma&nbsp;3 guarantees the produced
assignment is feasible, and Lemma&nbsp;5 shows it is the smallest
lexicographically. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all vertices*: each vertex and edge is processed once →  
`O(n + m)` time, `O(n)` extra memory for colours, queue, component list.  

Overall: **Time `O(n + m)`**, **Memory `O(n + m)`**, well within limits
(`n,m ≤ 2·10⁵`).

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 unvisited, 0/1 colours
    ans = [0] * (n + 1)

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        while q:
            v = q.popleft()
            cv = colour[v]
            for to in adj[v]:
                if colour[to] == -1:
                    colour[to] = cv ^ 1
                    q.append(to)
                    comp.append(to)
                elif colour[to] == cv:
                    print("NO")
                    return
        # decide orientation: give shift 1 to colour of smallest vertex
        min_v = min(comp)
        if colour[min_v] == 0:
            for x in comp:
                ans[x] = 1 if colour[x] == 0 else 2
        else:
            for x in comp:
                ans[x] = 1 if colour[x] == 1 else 2

    # all components processed
    print("YES")
    sys.stdout.write(' '.join(str(ans[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
