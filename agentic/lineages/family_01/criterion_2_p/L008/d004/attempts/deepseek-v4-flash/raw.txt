We can model each layer as a node in a graph, and each constraint as an edge requiring the two endpoints to have different transparency modes (since the product must be 2, and modes are only 1 or 2).  

This becomes a **bipartite graph checking** problem:  
- If the graph is bipartite, we can assign 1 and 2 alternately.  
- For lexicographically smallest assignment, we try to assign 1 whenever possible, using BFS/DFS with coloring.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n  # -1 uncolored, 0 -> mode 1, 1 -> mode 2

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
