We need to assign each lens a value of 1 or 2 such that for every edge (u, v), the sum c_u + c_v equals 3.  

That means:  
- If c_u = 1, then c_v must be 2.  
- If c_u = 2, then c_v must be 1.  

So the graph must be bipartite, with the two parts corresponding to values 1 and 2.  
If the graph is not bipartite, output `NO`.  
If it is bipartite, we can assign values by BFS/DFS coloring, and to get the lexicographically smallest sequence, we should try to assign 1 to the smallest-index node first, and propagate.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start):
    q = deque([start])
    color[start] = 1
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 3 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        if not bfs(i):
            print("NO")
            sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
