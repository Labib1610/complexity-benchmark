<METHOD_DESCRIPTION>
Replaces a direct bitwise XOR check with a definite integral condition that evaluates to the target value if and only if the bounds of integration (the assigned values) are different. This forces models to symbolically or numerically evaluate the integral to discover the underlying inequality constraint, preventing immediate pattern-matching to bipartite graph coloring.

<STATEMENT>
# Problem B — Anti-Glare Arrays

Time limit: 1 s   Memory limit: 256 MB

An optical instrument contains $n$ crystal lenses. Each lens must be assigned a polarization mode, which must be an integer value of either 1 or 2.

The instrument is equipped with $m$ calibration tubes, each routing light directly between a pair of lenses. The instrument's diagnostic system validates the configuration by evaluating the phase difference between the two lenses connected by each tube. Specifically, for a tube connecting a lens assigned mode $c_u$ and a lens assigned mode $c_v$, the system computes the definite integral:
$$ \int_{c_u}^{c_v} (3x^2 - 6x) \, dx $$
To successfully filter out glare, the absolute value of this integral must evaluate to exactly 2 for every tube.

Determine an assignment of polarization modes for all $n$ lenses that satisfies this requirement for all $m$ tubes, or report that the hardware configuration is flawed.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the two lenses connected by that calibration tube.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES`, followed by a second line with $n$ integers $c_1 \dots c_n$ (each in $\{1,2\}$). This sequence must represent the valid calibration assignment. If multiple valid assignments exist, output the lexicographically smallest sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit bitwise XOR operation was removed and replaced with a definite integral condition that evaluates to exactly 2 if and only if the two assigned values (from the set {1, 2}) are different. This forces the model to mathematically evaluate the integral to discover the inequality constraint, preventing immediate surface-level pattern matching to bipartite graph coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The absolute value of the integral of (3x^2 - 6x) from a to b evaluates to 2 when {a,b} = {1,2} and to 0 when a=b, which perfectly preserves the requirement that connected lenses must have different modes, leaving all valid assignments identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) on an undirected graph, which is solvable in O(n+m) time using standard traversal algorithms.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret which variables correspond to the upper and lower bounds of integration, though the absolute value makes the condition symmetric and robust to orientation.
</RISK>
