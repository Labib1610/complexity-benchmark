# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

A factory employs $n$ workers, numbered $1$ to $n$, with $m$ synchronization links established among them. You must assign a shift code $s_i \in \{1, 2\}$ to each worker $i$. 

To maintain proper timing, the machines operated by any two workers $u$ and $v$ connected by a synchronization link must be carefully calibrated. The calibration system computes two values based on the workers' identifiers $u$ and $v$:
- The **direct alignment**, defined as $s_u (u + v^2) + s_v (v + u^2)$.
- The **cross alignment**, defined as $s_v (u + v^2) + s_u (v + u^2)$.

The link is only stable if the direct alignment and the cross alignment leave strictly different remainders when divided by the sum of their identifiers ($u+v$).

Determine if there is a valid assignment of shift codes for all workers such that every synchronization link is stable.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of workers connected by a synchronization link.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \ldots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

The uniform condition `10s_u + s_v divisible by 3` trivially revealed that adjacent nodes must have different values. I replaced it with a polynomial modulo condition that incorporates the node identifiers `u` and `v`. Models must now perform non-trivial algebraic reduction (or exhaustive case-checking modulo `u+v`) to discover that the condition mathematically simplifies to `s_u != s_v`, forcing genuine reasoning over pattern matching.
</RATIONALE>

The difference between the direct and cross alignments is $(s_u - s_v)(u - v)(1 - (u + v))$; taken modulo $u+v$, this simplifies to $(s_u - s_v)(u - v)$, which is non-zero if and only if $s_u \neq s_v$, perfectly preserving the original edge constraints.
</PRESERVED_ANSWER>
