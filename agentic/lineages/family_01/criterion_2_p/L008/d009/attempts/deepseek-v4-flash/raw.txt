 We need to assign each vertex a value of 1 or 2 such that for every edge (u, v), the sum s_u + s_v equals 3.  
That means if one endpoint is 1, the other must be 2, and vice versa.  
This is exactly a bipartite graph condition: the graph must be bipartite, and the two color classes correspond to values 1 and 2.

If the graph is not bipartite, output `NO`.  
If it is bipartite, we can color it with BFS/DFS, and then assign 1 to one part and 2 to the other.  
For lexicographically smallest assignment, we should try to assign 1 to vertex 1 if possible, which means starting BFS from vertex 1 with color 1.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
ok = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    ok = False
                    break
            if not ok:
                break
    if not ok:
        break

if not ok:
    print("NO")
else:
    # color 0 -> 1, color 1 -> 2
    # But we want lexicographically smallest: try to make vertex 0 = 1
    # If color[0] == 1, swap colors
    if color[0] == 1:
        for i in range(n):
            color[i] ^= 1
    print("YES")
    print(' '.join(str(1 if c == 0 else 2) for c in color))
```
