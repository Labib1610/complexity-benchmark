**Solution Explanation**

For a lens `i`

```
focal(i) = 3·c_i + 1 ,   c_i ∈ {1,2}
```

```
c_i = 1 → focal = 4
c_i = 2 → focal = 7
```

For a tube `(u , v)` we need  

```
lcm( focal(u) , focal(v) ) = 28
```

The only possible pairs of focal values are

```
(4,4) → lcm = 4      (invalid)
(7,7) → lcm = 7      (invalid)
(4,7) → lcm = 28     (valid)
```

Hence **every tube must connect a lens with `c = 1` to a lens with `c = 2`**.
The whole graph therefore has to be *bipartite* and the two parts correspond to
`c = 1` and `c = 2`.

If the graph is not bipartite the answer is `NO`.
Otherwise each connected component has exactly two possible colourings
(the two parts may be swapped).  
We have to output the lexicographically smallest sequence `c_1 … c_n`.

Observation  
In a component the smallest indexed vertex decides the whole component:
choosing its colour `1` makes the whole sequence smaller than choosing `2`,
because all earlier positions are already fixed.  
Therefore for every component we orient the bipartition so that the
minimum‑index vertex receives colour `1`.

The algorithm is straightforward:

```
for every vertex not visited:
        BFS/DFS, colour with 0/1, check bipartite
        store all vertices of this component
        let v0 = minimum index in the component
        if colour[v0] == 0:   # 0 will become c = 1
                map 0 → 1 , 1 → 2
        else:                 # need to flip
                map 0 → 2 , 1 → 1
        write the mapped colours into answer array
```

If any conflict appears during BFS the graph is not bipartite → `NO`.

Complexities  

*Time* `O(n + m)` – one BFS over the whole graph.  
*Memory* `O(n + m)` – adjacency lists and colour array.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a lexicographically smallest
valid assignment iff such an assignment exists.

---

##### Lemma 1  
For any tube `(u,v)` the condition `lcm(3c_u+1, 3c_v+1)=28` holds **iff**
`c_u ≠ c_v`.

**Proof.**  
`c ∈ {1,2}` gives focal values `{4,7}`.
`lcm(4,7)=28`, while `lcm(4,4)=4` and `lcm(7,7)=7`. ∎



##### Lemma 2  
A valid assignment exists **iff** the given graph is bipartite.

**Proof.**  
*If* the graph is bipartite, colour its two parts `A,B`.  
Assign `c=1` to all vertices of `A` and `c=2` to all vertices of `B`.  
Every edge joins different parts, thus by Lemma&nbsp;1 its lcm is 28.

*Only‑if*: suppose a valid assignment exists.
By Lemma&nbsp;1 every edge connects vertices with different `c`,
hence the vertices with `c=1` and with `c=2` form a bipartition of the graph.
∎



##### Lemma 3  
For a connected component `C` let `v₀` be its smallest index.
Among the two possible colourings of `C` the one with `c_{v₀}=1`
is lexicographically smaller than the one with `c_{v₀}=2`,
independently of the colours of other components.

**Proof.**  
All positions before `v₀` belong to other components and are already fixed.
At position `v₀` the two colourings differ (`1` vs `2`);
the rest of the component appears later, therefore the sequence with `1`
at `v₀` is strictly smaller. ∎



##### Lemma 4  
The algorithm produces a valid assignment whenever the graph is bipartite.

**Proof.**  
During BFS each edge connects vertices of opposite BFS colours,
otherwise a conflict would be detected and the algorithm would output `NO`.
Thus the BFS colours form a bipartition.
The algorithm possibly flips the mapping `0/1 → 1/2` inside a component,
but flipping preserves the property that adjacent vertices receive different
`c`. Consequently every edge connects different `c` values, and by Lemma&nbsp;1
its lcm equals 28. ∎



##### Lemma 5  
The assignment output by the algorithm is lexicographically smallest among
all valid assignments.

**Proof.**  
Consider the components in increasing order of their minimal vertex.
For each component the algorithm chooses the orientation with `c=1` on that
minimal vertex (Lemma&nbsp;3).  
Any other valid assignment must, for the first component where it differs,
have `c=2` on its minimal vertex, making the whole sequence larger.
Thus no other valid assignment is lexicographically smaller. ∎



##### Theorem  
The program prints  

* `NO` iff no assignment of `c_i ∈ {1,2}` satisfies the required lcm condition;
* otherwise `YES` and the lexicographically smallest such assignment.

**Proof.**  
If the program prints `NO`, it must have detected a non‑bipartite component.
By Lemma&nbsp;2 no valid assignment exists.

If the program prints `YES`, the graph was bipartite.
By Lemma&nbsp;4 the produced assignment is valid.
By Lemma&nbsp;5 it is the lexicographically smallest among all valid ones.

Conversely, if a valid assignment exists, the graph is bipartite
(Lemma&nbsp;2), the program never aborts with `NO`, and by the previous
paragraph it outputs the required answer. ∎

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # 0 / 1 bipartite colour
    answer = [0] * (n + 1)           # final c_i (1 or 2)

    from collections import deque

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        while q:
            v = q.popleft()
            for to in adj[v]:
                if colour[to] == -1:
                    colour[to] = colour[v] ^ 1
                    q.append(to)
                    comp.append(to)
                elif colour[to] == colour[v]:
                    print("NO")
                    return
        # decide orientation: smallest index gets c=1
        v0 = min(comp)
        flip = (colour[v0] == 1)   # if its colour is 1 we need to flip
        for v in comp:
            if flip:
                answer[v] = 1 if colour[v] == 1 else 2
            else:
                answer[v] = 1 if colour[v] == 0 else 2

    # output
    print("YES")
    print(' '.join(str(answer[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
