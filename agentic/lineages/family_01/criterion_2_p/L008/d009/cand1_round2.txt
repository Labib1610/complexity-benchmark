<METHOD_NAME>
Pure Source/Sink Direction Assignment
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the arithmetic endpoint sums with a requirement to orient edges such that every vertex is either a pure source (no incoming edges) or a pure sink (no outgoing edges). This removes the numeric min/max affordance that models used to pattern-match bipartiteness, while logically forcing exactly the same 2-coloring structure.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<STATEMENT>
# Problem B — Traffic Flow Design

Time limit: 1 s
Memory limit: 256 MB

A region has $n$ cities and $m$ bidirectional roads. Each road connects two cities (or connects a city to itself).
To improve traffic safety, the transportation department wants to convert every road into a one-way street by assigning it a single direction.

Furthermore, they want to standardize the traffic flow at each city by assigning each city $i$ a zoning type $c_i$, which must be either $1$ or $2$:
- Type $1$ (Source Zone): No road connected to city $i$ may be directed towards city $i$.
- Type $2$ (Sink Zone): No road connected to city $i$ may be directed away from city $i$.

(If a city has no roads connected to it, both conditions are automatically satisfied.)

You must determine if it is possible to assign a direction to every road and a zoning type to every city such that all conditions are met. If such a configuration exists, you must output the valid sequence of zoning types $c_1, c_2, \dots, c_n$. If multiple valid sequences exist, you must find the lexicographically smallest sequence.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the two cities connected by that road. A road may connect a city to itself, and there may be multiple roads between the same pair of cities.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES`, followed by a second line with $n$ integers $c_1 \dots c_n$ (each in $\{1,2\}$). This sequence must represent the assigned zoning types. If multiple valid assignments exist, output the lexicographically smallest sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Removed the arithmetic resonance conditions that allowed models to deduce bipartiteness by matching target sums to minimum/maximum endpoint values. Replaced it with a natural requirement to orient edges such that every vertex is either a pure source or a pure sink, forcing models to independently deduce that this requires a bipartite graph.
</RATIONALE>
<PRESERVED_ANSWER>
Since every directed edge must have exactly one source (which must be Type 1) and one sink (which must be Type 2), the valid zoning types directly correspond to a valid 2-coloring of the graph, keeping all possibilities and the lexicographical rule identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in O(n+m) using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might overthink the self-loop case, though the logical consequence (a self-loop forces a city to have both an incoming and outgoing edge, making Type 1 and Type 2 both impossible) is mathematically unambiguous.
</RISK>
