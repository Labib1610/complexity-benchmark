# Problem B — Harmonic Resonance

Time limit: 1 s   Memory limit: 256 MB

A facility operates $n$ resonance generators. There are $m$ interference testing links, each connecting a specific pair of generators. You must configure the facility by assigning each generator $i$ a state $s_i \in \{1, 2\}$. 

To maintain system stability, every interference testing link must be balanced. The balance of a link connecting generator $u$ and generator $v$ is determined by a virtual photon simulation inside a 2D perfectly reflective rectangular cavity of width $s_u$ nanometers and height $s_v$ nanometers (spanning $x \in [0, s_u]$ and $y \in [0, s_v]$). 

In this simulation, a virtual photon is emitted from the origin $(0,0)$ at a $45^\circ$ angle (moving in the $+x$ and $+y$ directions). It travels through the cavity, reflecting perfectly off the walls (where the angle of incidence equals the angle of reflection). The photon is immediately absorbed the first time it reaches any of the four corners of the cavity.

A link is considered balanced if and only if the photon reflects off the walls exactly one time before being absorbed.

Determine if there is a valid configuration for all $n$ generators such that every link is balanced. 

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$) — a pair of generators connected by an interference testing link.

## Output
If no valid configuration exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \ldots, s_n$ (each in $\{1,2\}$) representing the valid configuration. If there are multiple valid configurations, output the lexicographically smallest sequence $s_1, s_2, \ldots, s_n$. (Lexicographic order compares $s_1$, then $s_2$, etc.)

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
