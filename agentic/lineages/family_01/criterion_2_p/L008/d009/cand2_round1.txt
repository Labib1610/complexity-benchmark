# Problem B — Anti-Glare Arrays

Time limit: 1 s
Memory limit: 256 MB

An optical instrument contains $n$ crystal lenses. Each lens must be assigned a polarization mode, which must be an integer value of either $1$ or $2$.

The instrument is equipped with $m$ calibration tubes, each routing data between a pair of lenses. The instrument's diagnostic system validates the configuration by checking the local resonance at each lens.

First, every calibration tube must be configured by designating one of its two endpoints as the 'anode' and the other as the 'cathode'. These endpoints inject resonance into their connected lenses. An anode endpoint injects a base resonance of $3$ into its lens. A cathode endpoint injects a base resonance of $8$ into its lens.

For each lens $i$, let $d_i$ be the total number of tube endpoints connected to it. Let $S_i$ be the sum of the base resonances of all endpoints connected to lens $i$. Let $Q_i$ be the sum of the squared base resonances of all endpoints connected to lens $i$ (that is, square each endpoint's base resonance first, then sum those values).

(If a tube connects a lens to itself, it provides two endpoints to that lens. Because every tube has exactly one anode and one cathode, a self-loop naturally provides one anode endpoint and one cathode endpoint to its lens, contributing $11$ to its sum $S_i$ and $3^2 + 8^2 = 73$ to its sum of squares $Q_i$).

To successfully filter out glare, there must exist some valid configuration of all $m$ tubes such that for every lens $i$ (from $1$ to $n$), the following diagnostic equation holds exactly:
$10 S_i - Q_i = d_i \cdot (26 - 5 c_i)$
where $c_i$ is the assigned polarization mode of lens $i$.

Determine an assignment of polarization modes for all $n$ lenses that makes such a configuration possible, or report that the hardware configuration is flawed.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the two lenses connected by that calibration tube.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES`, followed by a second line with $n$ integers $c_1 \dots c_n$ (each in $\{1,2\}$). This sequence must represent the valid calibration assignment. If multiple valid assignments exist, output the lexicographically smallest sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<METHOD_DESCRIPTION>Replaced the linear resonance sum target with a fake quadratic condition $10 S_i - Q_i = d_i(26 - 5c_i)$ that leverages the universal identity $v^2 - 11v + 24 = 0$ for $v \in \{3, 8\}$. This completely hides the fact that the target is simply the minimum/maximum possible sum, forcing the model to algebraically solve the quadratic system to discover the uniform endpoint role requirement (bipartiteness) rather than relying on surface pattern-matching of extreme values.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<RATIONALE>
The surviving models succeeded by recognizing that the original target formula $d_i(5c_i - 2)$ exactly equaled the minimum ($3d_i$) and maximum ($8d_i$) possible sums, which trivially forces all endpoints to be identical and reduces the problem to standard bipartiteness. By replacing the linear sum with a condition involving both the sum $S_i$ and the sum of squares $Q_i$, the relationship is obfuscated. The new equation $10 S_i - Q_i = d_i(26 - 5c_i)$ still exclusively forces uniform endpoint types, but requires rigorous algebraic deduction to prove this, breaking the min/max heuristic shortcut.
</RATIONALE>
<PRESERVED_ANSWER>
The equation $10 S_i - Q_i = d_i(26 - 5c_i)$ is mathematically satisfied if and only if all incident endpoints are anodes (when $c_i=1$) or all are cathodes (when $c_i=2$), enforcing the exact same physical configuration constraints on the tubes as the original problem, meaning the set of valid mode assignments remains identical.
</PRESERVED_ANSWER>
