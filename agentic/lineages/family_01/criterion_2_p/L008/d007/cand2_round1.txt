# Problem B — Harmonic Resonance

Time limit: 1 s   Memory limit: 256 MB

A factory employs $n$ workers, with $m$ synchronization links established among them. You must assign a shift code $s_i \in \{1, 2\}$ to each worker $i$. 

To maintain proper timing, the machines of connected workers must resonate at compatible frequencies. We define two resonance matrices:
$$A_1 = \begin{pmatrix} 1 & 2 \\ 0 & 1 \end{pmatrix} \quad \text{and} \quad A_2 = \begin{pmatrix} 1 & 0 \\ 2 & 1 \end{pmatrix}$$

A synchronization link between two workers $u$ and $v$ is stable if and only if the trace of the matrix product $A_{s_u} A_{s_v}$ is exactly $6$. 

Additionally, to prevent harmonic buildup, any valid assignment of shift codes $s_1, \dots, s_n$ must be compatible with at least one valid auxiliary harmonic configuration. A harmonic configuration is a sequence of integers $h_1, h_2, \ldots, h_n$ where each $h_i \in \{1, 2, \ldots, 10\}$. It is valid if and only if it satisfies two properties:
1. For every synchronization link between worker $u$ and worker $v$, the product $h_u \cdot h_v$ leaves a remainder of $1$ when divided by $11$.
2. For every worker $i$, $h_i \equiv s_i \pmod 3$.

Determine if there is a valid assignment of shift codes for all workers such that every synchronization link is stable and a valid harmonic configuration exists.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of workers connected by a synchronization link.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \ldots, s_n$ (each in $\{1,2\}$) representing the valid assignment. (You do not need to output the harmonic configuration). If there are multiple valid assignments, output the one that minimizes the structural weight of the sequence, defined as $\sum_{i=1}^n s_i \cdot 3^{n-i}$. Print this assignment as a full sequence of $n$ integers.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

This configuration is a modular arithmetic CSP ($h_u h_v \equiv 1 \pmod{11}$ and $h_i \equiv s_i \pmod 3$). This completely removes the concept of cycles and equal counts, destroying the shortcut where models recognize that bipartite coloring inherently satisfies the cycle balance. The new condition forces the model to either deduce the hidden satisfying mapping ($1 \to 7, 2 \to 8$) or attempt to solve the CSP explicitly.
</RATIONALE>

</PRESERVED_ANSWER>
