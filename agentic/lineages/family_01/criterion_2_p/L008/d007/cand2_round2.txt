# Problem B — Anti-Glare Arrays

Time limit: 1 s
Memory limit: 256 MB

An optical instrument contains $n$ crystal lenses. Each lens must be assigned a polarization axis, which must be an integer value of either $1$ or $2$.

The instrument is equipped with $m$ calibration tubes, each routing light directly between a pair of lenses. The instrument's diagnostic system validates the configuration by checking the interference across all tubes. 

For each of the $m$ tubes connecting a lens $u$ and a lens $v$, the system calculates a diagnostic value using the formula $3(c_u + c_v) - 2 c_u c_v$, where $c_u$ and $c_v$ are the assigned axes of the two lenses at its endpoints. (If a tube connects a lens to itself, $u$ and $v$ refer to the same lens, and its axis is used for both $c_u$ and $c_v$).

To successfully filter out glare, every single calibration tube must register a diagnostic value of exactly $5$.

Determine an assignment of polarization axes for all $n$ lenses that satisfies this requirement, or report that the hardware configuration is flawed.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the two lenses connected by that calibration tube.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by exactly $n$ integers $c_1 \dots c_n$ (each in $\{1,2\}$) on the second line. This sequence must represent the valid calibration assignment. If multiple valid assignments exist, output the lexicographically smallest sequence among all valid assignments.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

The seed problem's neighborhood summation equation was replaced with a pairwise algebraic formula $3(c_u + c_v) - 2 c_u c_v = 5$. This forces the model to evaluate the formula for the domain $\{1, 2\}$, realize it only holds when $c_u \neq c_v$, and subsequently reduce the problem to bipartite graph coloring, defeating models that exploit syntactic affordances like neighborhood sums or difference constraints without explicitly reasoning about the domain.
</RATIONALE>
<PRESERVED_ANSWER>
For variables in the domain $\{1, 2\}$, the equation $3(c_u + c_v) - 2 c_u c_v = 5$ is satisfied if and only if $c_u \neq c_v$, which perfectly matches the exact constraint space of the seed problem's summation equation, guaranteeing identical answers for all inputs (including self-loops and multi-edges).
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains mathematically equivalent to finding the lexicographically smallest valid 2-coloring of a graph, which is verifiable and solvable in linear time using Breadth-First Search, keeping it in the complexity class P.
</PRESERVED_CLASS>
