We can model this as a graph coloring problem with two colors (shifts 1 and 2), where conflicting pairs are edges.  
Since each edge means the two workers must be in different shifts, we can try a **bipartite check** with BFS/DFS.

The graph may not be connected, so we must check each component.  
For the lexicographically smallest assignment, we start by assigning worker 1 to shift 1, then BFS and always try to assign the smaller possible shift if not yet fixed.

Here’s the implementation:

```python
from collections import deque
import sys

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start):
    q = deque([start])
    color[start] = 0  # 0 represents shift 1, 1 represents shift 2
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = color[u] ^ 1
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        if not bfs(i):
            print("NO")
            sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
