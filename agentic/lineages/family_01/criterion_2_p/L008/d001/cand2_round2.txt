# Problem B — Day and Night

Time limit: 1 s
Memory limit: 256 MB

A facility employs a number of staff members, each of whom must be assigned a schedule code of either 1 or 2. 

To maintain operational balance, certain pairs of staff members are bound by a coverage requirement. Specifically, for each such pair, their assigned schedule codes must sum to exactly 3.

You must determine if there is a valid assignment of schedule codes to all staff members that satisfies all coverage requirements. If multiple valid assignments exist, you must find the one that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the headcount of staff members and the number of coverage requirements. Staff members are indexed from 1 to $n$.

Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of staff members subject to a coverage requirement.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (each in $\{1, 2\}$), representing the lexicographically smallest valid assignment of schedule codes.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Replaced the explicit "conflict" condition (where assigned shifts must differ) with an algebraic "coverage requirement" where schedule codes must sum to 3. This forces the model to deduce that for variables restricted to {1, 2}, summing to 3 is logically identical to inequality, requiring it to recognize the bipartite coloring structure from the math rather than from standard keywords.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that two variables chosen from {1, 2} sum to exactly 3 is satisfied if and only if they are distinct, making the constraints perfectly identical to the original problem's requirement that conflicting pairs receive different assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure is unchanged; it remains a 2-coloring problem on an undirected graph, solvable in O(n+m) time using Breadth-First Search to find the lexicographically smallest connected component orientations.
</PRESERVED_CLASS>
