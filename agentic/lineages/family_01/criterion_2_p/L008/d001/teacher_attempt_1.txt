# Problem B — Circuit Equilibrium

Time limit: 1 s   Memory limit: 256 MB

There are n components in a circuit, and m wires connecting certain pairs of them. You must configure each component to operate at a voltage level of either 1 or 2.

To maintain equilibrium, any two components connected by a wire must have voltage levels that sum to exactly 3. 

Determine if such a configuration is possible.

## Input
The first line contains two integers n and m (1 ≤ n ≤ 2·10⁵, 0 ≤ m ≤ 2·10⁵).
Each of the next m lines contains two integers u v — the indices of a pair of components connected by a wire.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with n integers s₁ … sₙ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Removed the explicit mention of assigning "two shifts" with "conflicts", which directly triggers bipartite graph coloring recall. Instead, the constraint is phrased algebraically: values from the set {1, 2} must sum to 3 across every edge. This forces the model to deduce that the values must be strictly different before it can recognize the underlying graph structure.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that two values chosen from {1, 2} must sum to 3 is mathematically equivalent to requiring that they are not equal, meaning the set of valid configurations and the lexicographically smallest tie-breaker remain completely unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a valid 2-coloring of an undirected graph (or reporting an odd cycle), which is solved in O(n+m) time via BFS or DFS.
</PRESERVED_CLASS>
<RISK>
None. The domain {1, 2} and the target sum 3 leave exactly one way to satisfy the constraint for any connected pair (one must be 1, the other 2), making the translation mathematically exact and unambiguous.
</RISK>
