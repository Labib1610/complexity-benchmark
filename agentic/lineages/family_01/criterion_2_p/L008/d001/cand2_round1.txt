# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

The factory operates continuously using exactly two production shifts, labeled 1 and 2. There are $n$ workers, and there are $m$ workstations, each shared by a specific pair of workers. 

Because a workstation must remain active throughout the entire production cycle, the two workers sharing it must collectively cover all available shifts. Assign each worker exactly one shift so that all workstation requirements are satisfied, or report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of workers who share a workstation.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the explicit instruction to assign different shifts with a scenario-based requirement that pairs sharing a workstation must "collectively cover all available shifts". This removes the direct keyword trigger for graph coloring or bipartiteness, forcing the model to logically deduce that covering two shifts with two workers requires opposite assignments.
</RATIONALE>
<PRESERVED_ANSWER>
Because there are exactly two shifts and two workers per workstation, the requirement to cover all shifts mandates that one worker takes shift 1 and the other takes shift 2, which is logically identical to the original "different shifts" constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in O(n+m) using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret "collectively cover all available shifts" as allowing a single worker to cover both shifts, but the instruction "Assign each worker exactly one shift" combined with the output format explicitly requiring a single integer in {1,2} per worker eliminates this ambiguity.
</RISK>
