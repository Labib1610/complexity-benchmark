# Problem B — Shipment Routing

Time limit: 1 s   Memory limit: 256 MB

A logistics company needs to route a batch of shipments. Each shipment must be dispatched via one of two available carrier networks, designated as network 1 and network 2. Due to shared transport legs and combined weight limits, certain pairs of shipments are incompatible and will cause delays if they are dispatched via the identical carrier network. You must determine if there is a routing plan that avoids all such delays.

The facility processes shipments by numbering them sequentially starting from 1. Since every valid batch contains at least one shipment and the warehouse floor can hold a maximum of 200,000 items at a time, the total number of shipments is physically constrained by these limits. Additionally, the tracking system maintains a log of incompatibility rules; this log might have no entries at all, or it might be filled up to its hardcoded limit of 200,000 records.

## Input
The first line contains two integers $n$ and $m$ — the actual number of shipments and the number of incompatibility records for the current batch. The limits on $n$ and $m$ strictly follow the warehouse capacity and tracking system limits described above.
Each of the next $m$ lines contains two integers $u$ and $v$, representing the ID numbers of a pair of shipments that cannot be dispatched via the identical carrier network.

## Output
If no valid routing plan exists that avoids all delays, print a single line `NO`.
Otherwise, print `YES`, then a second line with $n$ integers $s_1 \dots s_n$ (each being either 1 or 2), representing the carrier network assigned to each shipment. If there are multiple valid routing plans, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
