# Problem B — Power Scaling

Time limit: 1 s   Memory limit: 256 MB

A manufacturing facility manages a fleet of robotic welders. Each welder is assigned a unique integer identifier starting from 1 up to the total number of welders. The control system requires every welder to operate on a specific frequency multiplier, which must be chosen as exactly 1 or 2.

To coordinate operations, the facility has deployed several communication links. Each link establishes a direct connection between two specific welders. The safety protocol mandates that any two welders sharing a communication link must not interfere with each other. Specifically, the bitwise XOR of their chosen frequency multipliers must evaluate to exactly 3.

Your objective is to determine if it is possible to configure the frequency multipliers for all welders such that every communication link satisfies the safety protocol. If a valid configuration exists, you must find the one that is lexicographically smallest when listed as a sequence of multipliers corresponding to welders 1 through the maximum ID. If no such valid assignment is possible, you must report the failure.

## Input
The physical limits of the facility cap the fleet size at two hundred thousand welders, while ensuring at least one is always operational. The networking hardware can support a maximum of two hundred thousand communication links, though it is possible for none to be installed.

The first line of the input provides two integers, the exact fleet size and the number of active communication links, respectively. 
Following this, there is one line for each communication link, containing two integers that represent the identifiers of the connected welders.

## Output
If the safety protocol cannot be satisfied for all links simultaneously, output a single line with the word NO.
Otherwise, output YES on the first line. On the second line, output the frequency multipliers (each either 1 or 2) for all welders, ordered by their identifiers from 1 upwards, separated by spaces. This sequence must be the lexicographically smallest among all safe configurations.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
