<STATEMENT>
# Vessel Calibration

Time limit: 1 s
Memory limit: 256 MB

A fleet of $n$ autonomous surveying vessels must each be assigned a calibration state, represented by an integer $s_i \in \{1, 2\}$. The fleet's data integration system evaluates $m$ pairwise stability criteria to ensure accurate readings. Each criterion involves two vessels, $u$ and $v$, and requires that their assigned states satisfy the stability equation:

$$s_u^{s_v} + s_v^{s_u} = 3$$

Your task is to determine a valid calibration state for every vessel, or report if it is impossible. If there are multiple valid configurations, you must output the configuration that produces the lexicographically smallest sequence of states for vessels 1 through $n$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of vessels and the number of stability criteria.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that the criterion applies to vessel $u$ and vessel $v$.

## Output
If no valid configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \ldots, s_n$ (each $s_i \in \{1, 2\}$), representing the lexicographically smallest valid sequence of calibration states.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Replaced the physical graph framing ("operate in close proximity") and the obvious bipartiteness condition ("sum to exactly 3") with a system of non-linear equations. By defining the constraint as $s_u^{s_v} + s_v^{s_u} = 3$, models can no longer trigger a graph-coloring template from the text alone. They must now evaluate the equation over the domain $\{1, 2\}$ to deduce $s_u \neq s_v$, and then independently realize that the criteria form a graph requiring component-wise BFS/DFS to achieve the lexicographically smallest assignment.
</RATIONALE>
<PRESERVED_ANSWER>
Over the domain $\{1, 2\}$, the equation $s_u^{s_v} + s_v^{s_u} = 3$ is satisfied if and only if one variable is 1 and the other is 2, making it logically identical to the original "sum to exactly 3" condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring on an undirected graph, which is solvable in O(n+m) time using BFS/DFS to find the lexicographically smallest valid assignment per connected component.
</PRESERVED_CLASS>
