<STATEMENT>
# Problem B — Pressure Equalization

Time limit: 1 s   Memory limit: 256 MB

A city's water distribution network contains $n$ pressure zones, numbered from 1 to $n$. The water authority must configure the operating pressure of each zone to be exactly 1 unit or 2 units.

The network includes $m$ equalization valves, each connecting a pair of zones. The safety regulations for these valves require a specific pressure differential to prevent backflow stagnation. Specifically, for any two zones connected by a valve, the ratio of their assigned pressures (calculated by dividing the larger assigned pressure by the smaller assigned pressure) must be exactly 2.

Your task is to determine whether it is possible to assign a pressure of 1 or 2 to every zone such that all valve safety regulations are satisfied. If a valid configuration exists, you must output the sequence of pressures $p_1, p_2, \dots, p_n$ (where $p_i \in \{1, 2\}$ is the pressure of zone $i$) that is lexicographically smallest. If no such configuration is possible, you must report that it cannot be done.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — representing two pressure zones connected by an equalization valve.

## Output
If there is no way to assign the pressures without violating the safety regulations, print a single line containing NO.
Otherwise, print YES on the first line. On the second line, print $n$ space-separated integers $p_1, p_2, \dots, p_n$ (each either 1 or 2), representing the lexicographically smallest valid configuration sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The scenario was entirely rebuilt, moving from robotic welders with a "product is exactly 2" constraint to a water network with a "larger divided by smaller is exactly 2" constraint. This eliminates the overt mathematical trigger of factors multiplying to 2, forcing models to deduce from scratch that connected entities must take opposite values from the set {1, 2}.
</RATIONALE>
<PRESERVED_ANSWER>
Because the only allowed values are 1 and 2, the ratio of the larger to the smaller is 2 if and only if one value is 1 and the other is 2, which is mathematically identical to their product being exactly 2.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of an undirected graph, which is solvable in linear time using Breadth-First Search (class P).
</PRESERVED_CLASS>
