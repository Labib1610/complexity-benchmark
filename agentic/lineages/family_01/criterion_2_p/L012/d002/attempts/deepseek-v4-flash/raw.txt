We can model this as a bipartite graph problem.  
Each sensor can be mode `1` or `2`, and the constraint `s_u & s_v = 0` means:

- If one is `1`, the other must be `2`.
- If one is `2`, the other must be `1`.

So the graph must be bipartite.  
For the lexicographically smallest assignment, we try to assign `1` as early as possible, using BFS/DFS with coloring.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n  # -1 uncolored, 0 -> mode 1, 1 -> mode 2

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
