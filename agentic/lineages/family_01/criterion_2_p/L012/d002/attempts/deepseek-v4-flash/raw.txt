We can model this as a graph problem.  
The condition says: for every edge (u, v), we need `s[u] XOR s[v] = 3`.  
Since `s[i]` is either 1 or 2, the only way to get XOR = 3 is if one is 1 and the other is 2.  

So the graph must be bipartite:  
- Color one side with 1, the other with 2.  
- If the graph is not bipartite, output `NO`.  

To get the lexicographically smallest sequence, we assign colors starting from node 1, preferring 1 when possible.  

We can do BFS/DFS with two colors, and if a conflict occurs, output `NO`.  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
