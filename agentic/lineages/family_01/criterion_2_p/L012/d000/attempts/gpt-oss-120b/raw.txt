**Solution Explanation**

For every pair `(u , v)` the two workers must work in different shifts.
The workers are the vertices of a graph, the pairs are its edges.
The required assignment is exactly a *2‑coloring* of the graph
(`1` ↔ shift 1, `2` ↔ shift 2).

* If a component of the graph is **not bipartite** (an odd cycle exists)  
  no assignment is possible.
* If it is bipartite there are exactly two possible colorings – they are
  each other’s complement (swap `1` and `2`).

The lexicographically smallest whole assignment is obtained by the
following rule:

*For each connected component we choose the orientation that gives the
smallest numbered vertex of this component shift `1`.*

Why?  
Consider the first vertex (smallest index) that is still unassigned.
All earlier vertices belong to other components, therefore they are already
fixed and cannot be changed any more.
If we could give the current vertex shift `1` we certainly obtain a
lexicographically smaller whole sequence than giving it shift `2`,
independently of the later vertices.  
Because the two possible orientations differ exactly on this vertex,
choosing the orientation with shift `1` is optimal.
Repeating the argument for the next still unassigned vertex proves the
global optimality.

So the algorithm is:

1. Build the adjacency list.
2. Run BFS/DFS on every not yet visited vertex  
   * colour the component with colours `0 / 1`  
   * if a conflict appears → graph not bipartite → answer `NO`.
3. After a component is coloured, find its smallest vertex `vmin`.  
   If `colour[vmin] == 1` flip the whole component (`colour[x] ^= 1`).
   Now `vmin` has colour `0` → shift `1`.
4. Write the answer (`shift = colour + 1`) for all vertices.

The whole work is linear in the size of the graph.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a lexicographically smallest
valid assignment iff such an assignment exists.

---

##### Lemma 1  
If the algorithm prints `NO`, the graph is not bipartite.

**Proof.**  
`NO` is printed only when during BFS an edge `(u,v)` with
`colour[u] == colour[v]` is found.
That edge belongs to an odd cycle, therefore the component (and the whole
graph) is not bipartite. ∎



##### Lemma 2  
If the algorithm finishes without printing `NO`, the produced assignment
satisfies all constraints.

**Proof.**  
During BFS each visited edge connects vertices of opposite colours
(`colour[v] = colour[u] xor 1`).  
After possibly flipping a whole component, the relation between the two
endpoints of every edge stays opposite, because flipping changes both
endpoints simultaneously.  
Finally we output `shift = colour + 1`, therefore adjacent vertices receive
different shifts. ∎



##### Lemma 3  
For every connected component the algorithm assigns shift `1` to its
smallest numbered vertex.

**Proof.**  
After BFS the component is coloured arbitrarily, i.e. the smallest vertex
`vmin` has colour either `0` or `1`.  
If it is `0` we keep the colouring, otherwise we flip all colours in the
component. Flipping changes `0 ↔ 1`, therefore after the possible flip
`colour[vmin] = 0`.  
Output shift = `colour+1`, hence `vmin` receives shift `1`. ∎



##### Lemma 4  
Let the components be processed in increasing order of their smallest
vertex. The assignment built by the algorithm is lexicographically minimal
among all valid assignments.

**Proof.**  
Consider the first index `i` where any valid assignment can differ.
`i` belongs to some component `C`. All vertices with index `< i` lie in
components whose smallest vertex is `< i`; by Lemma&nbsp;3 those vertices
already have shift `1` in our assignment, which is the smallest possible
value.  
Inside component `C` the two possible colourings are exact complements.
Thus the only way to give vertex `i` shift `1` is to choose the orientation
used by the algorithm (Lemma&nbsp;3). Any other valid assignment would give
shift `2` to vertex `i`, which is lexicographically larger, regardless of
later vertices. ∎



##### Lemma 5  
If a valid assignment exists, the algorithm never prints `NO`.

**Proof.**  
A valid assignment exists ⇔ the graph is bipartite.  
During BFS the algorithm only prints `NO` when it discovers an edge whose
endpoints have equal colour, i.e. when the component contains an odd cycle.
That would contradict bipartiteness. Hence for a bipartite graph the
algorithm never prints `NO`. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no feasible assignment exists;  
* otherwise `YES` and the lexicographically smallest feasible assignment.

**Proof.**  

*If the algorithm prints `NO`*: by Lemma&nbsp;1 the graph is not bipartite,
hence no feasible assignment exists.

*If the algorithm prints `YES`*: by Lemma&nbsp;5 the graph is bipartite,
so a feasible assignment exists. Lemma&nbsp;2 shows the produced
assignment is feasible. Lemma&nbsp;4 proves it is lexicographically minimal.

Thus the statement holds in both directions. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once →  
`O(n + m)` time, `O(n)` extra memory for colour array and a temporary list
of vertices of the current component.  

Overall: **`O(n + m)` time**, **`O(n + m)` memory**, well within the limits
(`n, m ≤ 2·10⁵`).

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # 0 or 1, -1 = unvisited
    answer = [0] * (n + 1)          # final shifts (1 or 2)

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue

        # BFS for this component
        q = deque([start])
        colour[start] = 0
        comp = [start]

        while q:
            u = q.popleft()
            cu = colour[u]
            for v in adj[u]:
                if colour[v] == -1:
                    colour[v] = cu ^ 1
                    q.append(v)
                    comp.append(v)
                elif colour[v] == cu:
                    # not bipartite
                    sys.stdout.write("NO")
                    return

        # orient component so that its smallest vertex gets shift 1
        vmin = min(comp)
        if colour[vmin] == 1:          # need to flip
            for v in comp:
                colour[v] ^= 1

        for v in comp:
            answer[v] = colour[v] + 1   # 1 or 2

    # all components processed successfully
    out = ["YES", " ".join(str(answer[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
