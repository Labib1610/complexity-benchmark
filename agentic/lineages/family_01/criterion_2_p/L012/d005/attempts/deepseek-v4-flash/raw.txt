We can model this as a bipartite graph problem.  
Each task is a node, and each contention is an edge.  
We need to assign each node to one of two threads such that no edge connects two nodes of the same thread — that’s exactly a 2-coloring problem.

If the graph is not bipartite, output `NO`.  
If it is bipartite, we need the lexicographically smallest assignment in terms of the hash formula.

The hash formula:  
Start with `H = 0`, for each `i` from 1 to n:  
`H = 2*H + (t_i - 1)`  
This means earlier assignments have more weight in the final hash.  
To minimize the hash, we want `t_i = 1` as early as possible, and only use `2` when forced.

So we do a BFS/DFS coloring, but with a greedy rule:  
- For each unvisited node, start with color 1.  
- When we traverse, if a neighbor is uncolored, assign the opposite color.  
- If a neighbor is already colored and conflicts, it’s impossible.

This greedy starting with 1 for each component gives the minimal hash because we always try to assign 1 unless forced otherwise.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 0  # 0 means thread 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(' '.join(str(c + 1) for c in color))
```
