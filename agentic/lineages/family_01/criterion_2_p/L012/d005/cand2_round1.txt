# Problem B — Power Scaling

Time limit: 1 s   Memory limit: 256 MB

A manufacturing facility employs $n$ robotic welders, identified by integers from 1 to $n$. The facility requires each welder to be configured with a calibration mode of exactly 1 or 2.

Over time, management has installed $m$ shared power buses. Each bus connects two specific welders. A strict operational rule dictates that to prevent electrical overload, the entire network must maintain a specific energy balance. Specifically, for any welder $i$, let $s_i \in \{1, 2\}$ be its assigned calibration mode. For each shared power bus connecting welder $u$ and welder $v$, its local energy is calculated as $3(s_u + s_v) - 2(s_u \cdot s_v)$. A configuration of all $n$ welders is considered compliant if and only if the sum of the local energies across all $m$ power buses is exactly $5m$.

Your task is to determine whether the entire set of welders can be configured in complete compliance with this operational rule. If a compliant configuration exists, you must provide the specific configuration sequence $s_1, s_2, \dots, s_n$. If multiple such compliant sequences exist, you must output the one that produces the smallest possible value when evaluated as the sum $\sum_{i=1}^n s_i \cdot 3^{n-i}$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$, representing the two welders connected by a shared power bus.

## Output
If there is no way to assign the calibration modes without violating the operational rule, print a single line containing NO.
Otherwise, print YES on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (each either 1 or 2), representing the valid configuration sequence that minimizes the required sum.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<METHOD_DESCRIPTION>Replaces the local per-edge condition with a global sum over all edges. The target sum is exactly the theoretical maximum of the expression over the valid domain, meaning the global condition can only be satisfied if every individual edge achieves the maximum. This defeats pattern-matching models by presenting as a global optimization or subset-sum problem, forcing the model to explicitly evaluate the expression's bounds to deduce the underlying local bipartite constraint.</METHOD_DESCRIPTION>

To solve the problem efficiently, models must now explicitly evaluate the expression $3(s_u + s_v) - 2(s_u \cdot s_v)$ over the domain $\{1, 2\}$, discover that its maximum value is 5 (achieved only when $s_u \neq s_v$), and deduce that a sum of $5m$ across $m$ edges strictly requires every edge to be assigned opposing values.
</RATIONALE>
<PRESERVED_ANSWER>
The expression $3(s_u + s_v) - 2(s_u \cdot s_v)$ evaluates to 4 if $s_u = s_v$, and 5 if $s_u \neq s_v$; thus, a sum of $5m$ is algebraically equivalent to requiring $s_u \neq s_v$ for all edges, preserving the exact same valid configurations and tie-breaker as the seed.
</PRESERVED_ANSWER>
