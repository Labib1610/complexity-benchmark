<STATEMENT>
# Vessel Calibration

Time limit: 1 s
Memory limit: 256 MB

You oversee a fleet of $n$ autonomous surveying vessels. Each vessel must be assigned an operational mode $s_i \in \{1, 2\}$. During the mission, there are $m$ proximity events where a pair of vessels will operate in close quarters. To ensure their navigation systems do not interfere, any two vessels involved in a proximity event must be assigned different operational modes.

Your task is to determine a valid operational mode assignment for all $n$ vessels, or report if it is impossible. If multiple valid assignments exist, you must choose the one that yields the minimum overall system cost. The system cost is determined by treating the sequence of assigned modes as coefficients in a polynomial $P(x) = \sum_{i=1}^n s_i x^{n-i}$. The final cost is the exact integer value of $P(3)$. You must choose a valid assignment that minimizes this cost.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of vessels and the number of proximity events.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a proximity event between vessel $u$ and vessel $v$.

## Output
If there is no valid mode assignment, output a single line containing `NO`.
If a valid assignment exists, output `YES` on the first line. On the next line, output $n$ space-separated integers $s_1, \ldots, s_n$ ($s_i \in \{1, 2\}$), representing the operational modes that minimize the final system cost.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Removed the binary-cost recurrence that models were using to immediately recognize the problem required a lexicographically smallest assignment. Replaced it with a polynomial evaluation at x=3, which mathematically enforces the exact same lexicographical ordering but forces the model to deduce this dominance property rather than pattern-matching a standard CP idiom.
</RATIONALE>
<PRESERVED_ANSWER>
Because the coefficients are restricted to {1, 2} and the base is 3, the i-th term strictly dominates the maximum possible sum of all subsequent terms, meaning minimizing P(3) is mathematically identical to finding the lexicographically smallest valid sequence.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest valid 2-coloring of a graph, which is solvable in O(n+m) using BFS.
</PRESERVED_CLASS>
<RISK>
Models might attempt to compute P(3) directly and fail due to integer overflow, but this is an intended trap for models that simulate blindly rather than mathematically analyzing the cost function's properties.
</RISK>
