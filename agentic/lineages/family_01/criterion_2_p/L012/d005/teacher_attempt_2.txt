# Vessel Calibration

Time limit: 1 s
Memory limit: 256 MB

You oversee a fleet of $n$ autonomous surveying vessels. Each vessel $i$ must be configured with a frequency multiplier $s_i \in \{1, 2\}$. During the mission, there are $m$ proximity events where a specific pair of vessels will operate in close quarters. To establish a valid synchronization link and avoid interference, any two vessels involved in a proximity event must have frequency multipliers that sum to exactly 3.

Your task is to determine a valid frequency configuration for all $n$ vessels, or report if it is impossible. If multiple valid configurations exist, you must choose the one that yields the minimum overall system cost. The cost is computed through a sequential evaluation process: start with an initial cost $C_0 = 0$. For each vessel $i$ from 1 to $n$ in increasing order of their ID, the cumulative cost is updated as $C_i = 2 \cdot C_{i-1} + s_i - 1$. The final system cost is the value of $C_n$.

## Input
The first line contains two integers $n$ and $m$. The fleet size $n$ is at least one, limited by the registry system's maximum capacity of two hundred thousand vessels. The mission log can record up to two hundred thousand proximity events, so $m$ ranges from zero to this maximum capacity.
Each of the following $m$ lines contains two vessel IDs $u$ and $v$ (both from $1$ to $n$ inclusive), indicating a proximity event between vessel $u$ and vessel $v$.

## Output
If there is no valid configuration, output a single line containing `NO`.
If a valid configuration exists, output `YES` on the first line. On the next line, output $n$ space-separated integers $s_1, \ldots, s_n$ ($s_i \in \{1, 2\}$), representing the frequency multipliers that minimize the final system cost.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
