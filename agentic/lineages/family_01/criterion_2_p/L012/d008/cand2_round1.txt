<METHOD_NAME>Tensor Determinant Constraint</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the geometric bounding box perimeter constraint with a matrix determinant constraint. The local stress tensor of a strut is defined as a 2x2 matrix with the slider states on the main diagonal and (u - v) on the antidiagonal. Requiring its determinant to be exactly 2 - (u - v)^2 algebraically simplifies to forcing the product of the states to be 2. Given the domain {1, 2}, this strictly requires the states to be different, perfectly preserving the bipartite 2-coloring structure while masking it behind linear algebra terminology and edge-dependent variables that appear to require complex arithmetic.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Linkage Configuration

Time limit: 1 s   Memory limit: 256 MB

You are designing a mechanical linkage with $n$ vertical sliders, identified by integers from 1 to $n$. Your task is to lock each slider $i$ at a discrete configuration state $h_i$, which must be exactly 1 or 2.

The linkage contains $m$ rigid struts. Each strut connects slider $u$ and slider $v$. To prevent the mechanism from binding under thermal expansion, the internal stress between connected sliders must be carefully balanced. For each strut connecting slider $u$ and slider $v$, we define its local stress tensor as the $2 \times 2$ symmetric matrix:

$$
T = \begin{pmatrix} h_u & u - v \\ u - v & h_v \end{pmatrix}
$$

For the assembly to pass inspection, the determinant of this stress tensor must be exactly $2 - (u - v)^2$ for every strut in the linkage. (Recall that the determinant of a $2 \times 2$ matrix $\begin{pmatrix} a & b \\ c & d \end{pmatrix}$ is calculated as $ad - bc$).

If a slider is not connected to any struts, its configuration state does not affect the assembly of other components.

Your task is to determine whether all sliders can be assigned valid configuration states such that every strut's stress tensor meets the determinant requirement. If a valid assignment exists, you must provide the sequence of states $h_1, h_2, \dots, h_n$ (where each $h_i \in \{1, 2\}$). If multiple valid sequences exist, you must output the one that produces the smallest possible value when the sequence of digits $h_1 h_2 \dots h_n$ is read as a single $n$-digit number in base 3.

## Input
The first line contains two integers $n$ and $m$. The testing facility contains a $400$ by $500$ storage grid, and neither the number of sliders $n$ nor the number of struts $m$ will exceed the total number of cells in this grid. It is guaranteed that $n \ge 1$ and $m \ge 0$.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a strut connecting slider $u$ and slider $v$.

## Output
If there is no way to assign the states without violating the stress tensor requirement, print a single line containing NO.
Otherwise, print YES on the first line. On the second line, print $n$ space-separated integers $h_1, h_2, \dots, h_n$ (each either 1 or 2), representing the valid configuration sequence that minimizes the required base-3 value.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the geometric bounding box perimeter constraint with a local stress tensor determinant constraint. By defining a matrix whose determinant evaluates to $h_u h_v - (u - v)^2$ and requiring it to equal $2 - (u - v)^2$, the condition simplifies algebraically to $h_u h_v = 2$. With $h_i \in \{1, 2\}$, this forces $h_u \neq h_v$. This forces models to perform algebraic simplification rather than relying on surface pattern matching of bipartite graphs or 2-coloring, while strictly preserving the underlying mathematical structure. I also applied S07 by expressing the bounds through the area of a physical storage grid.
</RATIONALE>
<PRESERVED_ANSWER>
The matrix determinant equation simplifies exactly to $h_u h_v = 2$, which over the domain $\{1, 2\}$ is logically identical to the original $|h_u - h_v| = 1$ condition, preserving the exact same valid state assignments for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains mathematically identical to finding a valid 2-coloring of a graph (or confirming none exists) and selecting the lexicographically smallest valid assignment, which is solvable in linear time using BFS or DFS, keeping it in P.
</PRESERVED_CLASS>
