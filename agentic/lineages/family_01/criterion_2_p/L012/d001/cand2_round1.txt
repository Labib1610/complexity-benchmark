<STATEMENT>
# Problem B — Sensor Calibration

Time limit: 1 s   Memory limit: 256 MB

A monitoring network consists of $n$ sensors, identified by integers from 1 to $n$. Each sensor must be calibrated to operate on one of two available frequency bands, denoted as band 1 and band 2.

Over time, network administrators have identified $m$ specific pairs of sensors that share an overlapping coverage zone. To ensure reliable data collection without signal interference, a strict operational rule dictates that for every identified pair of sensors $u$ and $v$, the product of their assigned frequency bands must evaluate to exactly 2.

Your task is to determine whether the entire network of sensors can be calibrated in complete compliance with this operational rule. If a compliant configuration exists, you must provide the specific calibration sequence $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$ is the band assigned to sensor $i$) that is lexicographically smallest. If no such configuration is possible, you must report that it cannot be done.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — representing a pair of sensors that share an overlapping coverage zone.

## Output
If there is no way to assign the frequency bands without violating the operational rule, print a single line containing NO.
Otherwise, print YES on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (each either 1 or 2), representing the lexicographically smallest valid assignment of bands.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit instruction that pairs must be assigned "completely different work periods" directly triggered bipartite graph coloring templates. This affordance was removed by replacing it with the mathematical constraint that the product of their assigned bands (which are strictly 1 or 2) must be exactly 2. Models must now deduce that this product condition is functionally identical to requiring distinct assignments before they can map it to a 2-coloring algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
Since the variables $s_i$ are restricted to the set {1, 2}, the product $s_u \times s_v = 2$ is satisfied if and only if one variable is 1 and the other is 2, exactly preserving the original requirement that the pair must receive different assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding a valid 2-coloring of a graph (or determining if it is bipartite), which is solvable in linear time using Breadth-First Search, keeping it in P.
</PRESERVED_CLASS>
