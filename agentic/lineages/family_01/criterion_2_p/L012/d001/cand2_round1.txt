<STATEMENT>
# Phase Alignment

Time limit: 1 s
Memory limit: 256 MB

You are managing a fleet of $n$ autonomous surveying vessels. Each vessel must be configured into one of two operational phase states, represented by the values 1 and 2. 

The vessels will conduct a survey where $m$ specific pairs of vessels will navigate in close proximity. To maintain signal integrity, any two vessels operating near each other must be set to strictly different phase states. 

You need to find a valid phase configuration for the entire fleet that satisfies all $m$ proximity requirements. If no such configuration exists, you must report it. In cases where more than one valid configuration is possible, you must select the one that minimizes the fleet's structural footprint $F$, calculated as:
$$F = \sum_{i=1}^n s_i \cdot 2^{n-i}$$
where $s_i$ is the phase state (1 or 2) assigned to vessel $i$.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$) — the size of the fleet and the number of proximity constraints, respectively.
Following this are $m$ lines, each containing two integers $u$ and $v$ ($1 \le u, v \le n$). These indicate that vessel $u$ and vessel $v$ will be near each other and thus require different phase states.

## Output
If it is impossible to configure the fleet without signal interference, output `NO` on a single line.
If a valid configuration exists, output `YES` on the first line. On the second line, output $n$ space-separated integers $s_1, s_2, \ldots, s_n$ ($s_i \in \{1, 2\}$) denoting the phase states of the vessels in the configuration that minimizes $F$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

Instead, to attack the shortcut where models independently color each component without global reasoning, the explicit "lexicographically smallest" tie-breaker was replaced with an equivalent global polynomial sum $F$. Surface-level pattern matchers will attempt to evaluate or optimize this sum globally (often failing due to the massive scale of $2^{200000}$), while models that genuinely reason will recognize that minimizing this polynomial is mathematically identical to a greedy lexicographical assignment.
</RATIONALE>
<PRESERVED_ANSWER>
Minimizing the given polynomial sum is mathematically identical to finding the lexicographically smallest sequence because the weight of each index strictly dominates the sum of all subsequent weights, leaving the valid assignments and optimal selection exactly the same.
</PRESERVED_ANSWER>
