We can model this as a bipartite graph problem.  
Each vessel is a node, and each proximity record is an edge.  
The condition “states sum to 3” means one vessel must be 1 and the other 2 — i.e., a proper 2-coloring.

We need to check if the graph is bipartite.  
If it is, we assign colors (1 or 2) and choose the lexicographically smallest assignment.

To get the lexicographically smallest sequence, we can try to assign 1 to the smallest uncolored node whenever possible, then BFS/DFS to color its component.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 1
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 3 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
