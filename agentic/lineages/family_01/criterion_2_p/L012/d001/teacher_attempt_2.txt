# Channel Allocation

Time limit: 1 s
Memory limit: 256 MB

A fleet of $n$ autonomous surveying vessels must each be configured to operate on one of two communication frequencies, denoted by the values 1 and 2. During the survey, certain pairs of vessels will operate in close proximity. You are provided with $m$ records of such vessel pairs.

If two vessels in close proximity broadcast on the same frequency, they will cause a critical signal collision. Your task is to assign a frequency $s_i \in \{1, 2\}$ to every vessel $i$ (for $1 \le i \le n$) such that no two vessels in any of the $m$ records share the same frequency. 

If there are multiple valid configurations that avoid all collisions, you must output the configuration that minimizes the network's priority-weighted frequency sum, defined as:
$$ \sum_{i=1}^n s_i \cdot 2^{n-i} $$
If no such configuration is possible, you must determine this.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of vessels and the number of proximity records.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that vessel $u$ and vessel $v$ will operate in close proximity.

## Output
If no configuration can prevent all signal collisions, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \ldots, s_n$ (each $s_i \in \{1, 2\}$), representing the valid frequency assignment that minimizes the priority-weighted frequency sum.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Replaced the explicit "lexicographically smallest" requirement with an equivalent mathematical objective function: minimizing $\sum s_i \cdot 2^{n-i}$. This forces models to genuinely analyze the properties of the sum to deduce that it requires assigning 1 to the lowest-indexed node of each independent component, rather than relying on memorized pattern matching for lexicographical graph coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The positional weights $2^{n-i}$ strictly dominate all subsequent terms, making the minimization of this sum mathematically identical to finding the lexicographically smallest sequence.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a valid 2-coloring of an undirected graph, which is in P and solvable in O(n+m) time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
Models might attempt to literally compute the sum using arbitrary-precision arithmetic and exceed time or memory limits, though this is a failure of algorithmic reasoning rather than an ambiguity in the prompt.
</RISK>
