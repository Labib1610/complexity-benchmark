<STATEMENT>
# Vessel Calibration

Time limit: 1 s
Memory limit: 256 MB

You are managing a fleet of $n$ autonomous surveying vessels. Each vessel must be configured with a calibration state, which is an integer $s_i \in \{1, 2\}$. Throughout the operation, specific pairs of vessels will navigate in close proximity. For these pairs to successfully synchronize and merge their data streams, their configured calibration states must differ by exactly 1. There are $m$ such proximity records.

Your objective is to find a valid calibration state assignment for all $n$ vessels, or determine if no such assignment exists. When multiple valid configurations are possible, you must provide the one that minimizes the total system penalty. The penalty is calculated as $\sum_{i=1}^n (s_i - 1) \cdot 2^{n-i}$.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), denoting the number of vessels and the number of proximity records, respectively.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), specifying that vessel $u$ and vessel $v$ will operate close to each other.

## Output
If no valid state assignment is possible, output a single line with `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $s_1, \ldots, s_n$ (where each $s_i \in \{1, 2\}$), representing the valid sequence of calibration states that minimizes the total system penalty.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit instruction to find the "lexicographically smallest sequence" with a mathematical penalty function $\sum_{i=1}^n (s_i - 1) \cdot 2^{n-i}$ that must be minimized. This forces the model to deduce that minimizing this sum is mathematically equivalent to prioritizing $s_i = 1$ for the lowest possible indices (i.e., lexicographical order), preventing it from relying on the memorized "lexicographically smallest means lowest-index gets 1" shortcut.
</RATIONALE>
<PRESERVED_ANSWER>
Minimizing the given penalty function is strictly equivalent to finding the lexicographically smallest sequence of states, because the weight $2^{n-i}$ for any position $i$ is strictly greater than the sum of all subsequent weights, uniquely prioritizing smaller indices.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem is still 2-coloring a graph (bipartiteness testing) and choosing the lexicographically smallest valid coloring for each connected component, which remains solvable in $O(n+m)$ time using Breadth-First Search.
</PRESERVED_CLASS>
<RISK>
Models might attempt to literally compute and compare the penalty values using large integers (BigInt), which would result in a Time Limit Exceeded (TLE) error given $n \le 2 \cdot 10^5$.
</RISK>
