# Framework Assembly

Time limit: 1 s
Memory limit: 256 MB

You are designing a structural framework consisting of $n$ modular struts. Each strut must be manufactured with a specific thickness profile, represented by an integer $p_i \in \{1, 2\}$.

The framework design includes $m$ critical joints. At each joint, two specific struts connect. To maintain structural integrity and ensure the joint closes flush, the combined thickness profiles of the two connecting struts must sum to exactly 3.

Your task is to determine a valid thickness profile assignment for all $n$ struts, or conclude that the design cannot be assembled. If there are multiple valid assignments, you must output the one that produces the lexicographically smallest sequence of profiles for struts 1 through $n$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of struts and the number of joints.
The next $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that strut $u$ and strut $v$ connect at a joint.

## Output
If no valid profile assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $p_1, \ldots, p_n$ (where each $p_i \in \{1, 2\}$), representing the lexicographically smallest valid sequence of thickness profiles.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

I replaced the vessel calibration scenario with a structural framework assembly scenario. The explicit constraint that states must "differ by exactly 1" was changed to an algebraic constraint that the two profiles must "sum to exactly 3". This forces the model to deduce the mutually exclusive relationship between connected elements rather than pattern-matching the standard graph-coloring phrasing.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that two variables from the set {1, 2} sum to 3 is mathematically identical to the condition that they differ by exactly 1; therefore, the set of valid assignments and the lexicographically smallest tie-breaker remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure is still 2-coloring an undirected graph, which tests for bipartiteness and can be solved in O(n+m) time using BFS or DFS.
</PRESERVED_CLASS>
