<STATEMENT>
# Vessel Calibration

Time limit: 1 s
Memory limit: 256 MB

You are managing a fleet of autonomous surveying vessels. The fleet management system requires at least one commissioned vessel and has a strict architectural limit of 200,000 vessels. The proximity logging database can store anywhere from zero up to 200,000 records.

Each vessel must be configured to operate in a specific calibration mode. The hardware supports exactly two modes, which are logged in the system as the integers 1 and 2. 

Throughout the operation, specific pairs of vessels will navigate in close proximity. To successfully synchronize and merge their data streams without interference, any two vessels listed in a proximity record must not share the same calibration mode. 

Your objective is to find a valid mode assignment for all vessels, or determine if no such assignment exists. When multiple valid configurations are possible, you must provide the one that yields the lexicographically smallest sequence of mode integers for the vessels, ordered by their fleet ID from 1 to the total number of commissioned vessels.

## Input
The first line provides two integers $n$ and $m$, denoting the number of commissioned vessels and the number of proximity records, respectively. Their possible values span the full range of the system limits described earlier.
The following $m$ lines each contain two integers $u$ and $v$, specifying that vessel $u$ and vessel $v$ will operate close to each other. The IDs $u$ and $v$ represent valid vessels currently in the system, meaning they take values starting from 1 up to $n$.

## Output
If no valid mode assignment is possible, output a single line with `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers (where each integer is either 1 or 2), representing the lexicographically smallest valid sequence of calibration modes.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

The explicit difference constraint `|s_u - s_v| = 1` was a direct mathematical cue for bipartite coloring. This was removed and replaced with a logical incompatibility requirement ("must not share the same calibration mode") over a set of exactly two choices, forcing the model to deduce the structural equivalence. Additionally, numerical bounds were removed from the Input section and embedded as physical system limits in the scenario description to satisfy Strategy S07.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that adjacent vessels cannot share a mode from a set of two possible modes (1 and 2) is logically identical to requiring their state values to differ by exactly 1, preserving all valid assignments and the lexicographical tie-breaker.
</PRESERVED_ANSWER>
