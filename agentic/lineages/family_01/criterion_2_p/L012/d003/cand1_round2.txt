<STATEMENT>
# Orbital Resonance Calibration

Time limit: 1 s
Memory limit: 256 MB

You are operating an orbital array consisting of $n$ satellite relays. Each relay must be locked into one of two phase states, represented by an integer $s_i \in \{1, 2\}$.

The array features $m$ resonance bridges, each syncing a specific pair of relays. To maintain stable orbit, any two relays $u$ and $v$ connected by a resonance bridge must have their phase states configured such that the determinant of their joint stability matrix $M_{u,v}$ is exactly zero. The matrix is defined as:

$$M_{u,v} = \begin{pmatrix} s_u + s_v & 3 \\ 3 & s_u + s_v \end{pmatrix}$$

You must determine if there exists a complete phase assignment for all $n$ relays that satisfies the stability matrix condition across every bridge. If multiple valid assignments exist, you must output the one where the sequence of phase states $(s_1, s_2, \dots, s_n)$ is lexicographically smallest. (A sequence $A$ is lexicographically smaller than $B$ if $A$ has a smaller value at the first index where the two sequences differ.)

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of relays and the number of resonance bridges.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a resonance bridge between relay $u$ and relay $v$. Both $u$ and $v$ are 1-based indices.

## Output
If no valid phase assignment can stabilize all bridges, output a single line with the word `NO`.
If a valid assignment exists, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \ldots, s_n$ (where each $s_i \in \{1, 2\}$), representing the lexicographically smallest valid sequence of phase states.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Replaced the direct bitwise AND condition with a matrix determinant equation. Models can no longer trigger a bipartite coloring template from `s_u & s_v = 0`. Instead, they must independently evaluate the determinant to $(s_u+s_v)^2 - 9 = 0$, deduce that this strictly requires $s_u \neq s_v$ for values in $\{1, 2\}$, and only then recognize the underlying structure.
</RATIONALE>
<PRESERVED_ANSWER>
For domain $\{1, 2\}$, the determinant is zero exactly when $s_u + s_v = 3$, meaning one relay is in state 1 and the other is in state 2, which is mathematically identical to the original requirement that $s_u \& s_v = 0$.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying graph structure and the constraint that connected nodes must have opposite states are preserved, keeping the problem identical to 2-coloring / bipartiteness testing, which is in P.
</PRESERVED_CLASS>
