We can model this as a bipartite graph problem: each vessel is a node, and each proximity record is an edge.  
The condition that two connected vessels must have states differing by exactly 1 means the graph must be bipartite (2-colorable).  

If it’s not bipartite, output `NO`.  
If it is, we have two possible colorings (swap colors).  
We need to choose the one that minimizes:

\[
\sum_{i=1}^n (s_i - 1) \cdot 2^{n-i}
\]

Since \(2^{n-i}\) is huge for small \(i\), the penalty is lexicographic: we want the earliest possible vessels to have state 1 (since \(s_i - 1 = 0\) for state 1, and 1 for state 2).  
So we should try both colorings and pick the one that is lexicographically smaller when comparing the state sequence from vessel 1 to n.

We can do BFS/DFS to color the graph, then compare the two possible assignments.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
ok = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    ok = False
                    break
            if not ok:
                break
    if not ok:
        break

if not ok:
    print("NO")
else:
    # color is 0/1, we can map 0->1, 1->2 or 0->2, 1->1
    # We want lexicographically smaller sequence
    assign1 = [1 if c == 0 else 2 for c in color]
    assign2 = [2 if c == 0 else 1 for c in color]
    # Compare lexicographically
    if assign1 < assign2:
        best = assign1
    else:
        best = assign2
    print("YES")
    print(" ".join(map(str, best)))
```
