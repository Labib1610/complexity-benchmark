# Problem B — Linkage Configuration

Time limit: 1 s   Memory limit: 256 MB

You are engineering a mechanical linkage system consisting of $n$ vertical sliders, numbered 1 through $n$. Each slider $i$ is mounted at a fixed horizontal position $x = i$. You must lock each slider into one of two valid vertical positions: $h_i = 1$ or $h_i = 2$.

The assembly is held together by $m$ rigid struts. Each strut connects a starting slider $u$ to a receiving slider $v$, strictly in the direction given by the blueprint.

To ensure the mechanism operates without jamming, every strut must pass a dynamic torque calibration based on the heights of its endpoints. The calibration follows this exact sequence of calculations:
1. The starting slider $u$ generates an initial force $F = 3 \cdot h_u + u$.
2. The receiving slider $v$ amplifies this force to $A = F \cdot h_v$.
3. The strut experiences a baseline interference $I = u \cdot h_v + 2 \cdot h_v$.
4. The final checksum is calculated as $C = 2 \cdot (A - I)$.

For the assembly to pass inspection, the bitwise AND of $C$ and 12 must be strictly greater than 0. (Note: Sliders not connected to any struts do not affect the calibration of other components).

Your task is to determine if there exists a valid height assignment for all $n$ sliders such that every strut passes the calibration. If a valid configuration exists, you must output the sequence of heights $h_1, h_2, \dots, h_n$. If multiple valid sequences exist, output the one that produces the smallest possible decimal value when the sequence of digits $h_1 h_2 \dots h_n$ is evaluated as a single $n$-digit number in base 3.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a strut connecting starting slider $u$ to receiving slider $v$.

## Output
If there is no way to assign the heights without violating the calibration requirement, print a single line containing NO.
Otherwise, print YES on the first line. On the second line, print $n$ space-separated integers $h_1, h_2, \dots, h_n$ (each either 1 or 2), representing the valid configuration sequence that minimizes the required base-3 value.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
