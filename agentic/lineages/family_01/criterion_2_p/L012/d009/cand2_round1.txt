# Problem B — Linkage Configuration

Time limit: 1 s   Memory limit: 256 MB

You are engineering a kinetic art installation consisting of $n$ vertical guide rails, numbered 1 through $n$. Each rail $i$ is positioned at horizontal coordinate $x = i$ and contains a sliding mount. You must permanently lock each mount at a vertical elevation $h_i$ of either 1 or 2.

The structure is reinforced by $m$ directional support rods. Each rod connects a source rail $u$ to a target rail $v$, exactly as specified in the architectural plans. 

To ensure structural stability, every installed rod must satisfy a strict mathematical tension calibration. This calibration depends on the elevations and positions of the rod's endpoints. Specifically, for a rod directed from rail $u$ to rail $v$, the system's diagnostic software constructs a $3 \times 3$ tension matrix $M$:
- The top row is $[h_u, u, 0]$.
- The middle row is $[0, h_v, v]$.
- The bottom row is $[1, 0, u \cdot v]$.

A rod is considered perfectly calibrated if and only if the determinant of its tension matrix $M$ is exactly equal to $3 \cdot u \cdot v$. (Rails that are not attached to any rods do not influence the calibration of other parts).

Your objective is to deduce if there is a complete assignment of elevations that calibrates all $m$ rods simultaneously. If such an assignment is possible, output the sequence of elevations $h_1, h_2, \dots, h_n$ (with each $h_i \in \{1, 2\}$). Should there be more than one valid configuration, you must select the one yielding the minimum decimal integer when the sequence $h_1 h_2 \dots h_n$ is interpreted as an $n$-digit number in base 3.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a rod installed from source rail $u$ to target rail $v$.

## Output
If there is no way to assign the elevations without violating the calibration requirement, print a single line containing NO.
Otherwise, print YES on the first line. On the second line, print $n$ space-separated integers $h_1, h_2, \dots, h_n$ (each either 1 or 2), representing the valid configuration sequence that minimizes the required base-3 value.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

To defeat this, I embedded the local heights into a $3 \times 3$ matrix that heavily incorporates the edge's specific endpoints $u$ and $v$. The condition $\det(M) = 3uv$ forces models to either evaluate the determinant symbolically or wrap the entire matrix in a SAT solver. Because the matrix explicitly uses $u$ and $v$, the constraint appears asymmetric and edge-dependent, preventing models from recognizing the universal symmetry required to reduce the problem to bipartite graph coloring.
</RATIONALE>

The determinant of the matrix evaluates to $h_u \cdot h_v \cdot u \cdot v + u \cdot v = uv(h_u h_v + 1)$; equating this to $3uv$ simplifies (since $uv \ge 1$) to $h_u h_v = 2$, which for $h \in \{1, 2\}$ is exactly equivalent to $h_u \neq h_v$, meaning every valid assignment remains identically constrained.
</PRESERVED_ANSWER>
