We are given n sliders at integer positions, heights either 1 or 2.  

Each strut connecting u and v has a clearance perimeter requirement:  

\[
2|u-v| + 2
\]

The axis-aligned bounding box of points (u, h_u) and (v, h_v) has:
- width = |u - v|
- height = |h_u - h_v|  

Perimeter = \( 2|u-v| + 2|h_u - h_v| \).

Requirement:
\[
2|u-v| + 2|h_u - h_v| = 2|u-v| + 2
\]
which implies:
\[
|h_u - h_v| = 1
\]

Since heights are only 1 or 2, this means:  
For any strut (u, v), u and v must have different heights.

So the problem reduces to:  
We have a graph on vertices 1..n, edges are struts. We need to 2-color the vertices (with heights 1 and 2) such that every edge connects vertices of different colors.

If the graph is not bipartite → impossible → output NO.  

If bipartite, we assign 1 and 2 accordingly.

But we must pick the lexicographically smallest sequence when read as base-3 number.  

Since digits are 1 or 2, comparing base-3 values:  
Smaller number means earlier positions should be as small as possible: prefer 1 over 2 at earlier indices.

We can do BFS/DFS coloring, starting from vertex 1 with color 1 (height=1) and propagate, giving smaller color to smaller index when possible.  

Because if there is a bipartition, there are only two possible colorings (swap colors). We pick the one where vertex 1 has height 1. If the graph is connected, this fixes all. For disconnected components, we can also orient each component so the smallest vertex in that component gets height 1.

Then all conditions are satisfied.

Implementation:
- Build adjacency.
- Color array: 0 = uncolored, 1 = height1, 2 = height2.
- For each uncolored vertex (start from smallest index), BFS assign colors with starting color 1.  
  - For each edge, neighbor must have opposite color. If conflict → NO.

Complexity O(n+m).

Now write the Python code.  

Note: The answer must be space-separated heights.  
Also, if n=0 problem doesn't happen.

Let’s code```python
import sys
from collections import deque

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)

    color = [0] * n  # 0 uncolored, 1 or 2

    for start in range(n):
        if color[start] == 0:
            color[start] = 1
            q = deque([start])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == 0:
                        color[v] = 3 - color[u]  # 1<->2
                        q.append(v)
                    elif color[v] == color[u]:
                        print("NO")
                        return

    print("YES")
    print(" ".join(map(str, color)))

if __name__ == "__main__":
    solve()
