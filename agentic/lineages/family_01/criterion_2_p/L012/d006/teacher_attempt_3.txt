# Crystal Lattice Synthesis

Time limit: 1 s
Memory limit: 256 MB

You are simulating the self-assembly of a new crystalline material composed of $n$ molecules. Each molecule must be stabilized in one of two distinct structural conformations, designated as conformation 1 and conformation 2.

Due to the spatial constraints of the lattice, certain pairs of molecules are in close proximity, leading to $m$ steric interactions. If two molecules involved in a steric interaction are stabilized in the exact same conformation, their electron clouds will repel and destabilize the entire structure. Therefore, any two molecules sharing a steric interaction must be forced into different conformations.

Your objective is to determine a valid conformation assignment for all $n$ molecules, or report that the lattice cannot be stabilized. 

If multiple valid assignments are possible, the synthesis process will naturally settle into the state with the minimum overall dipole index. The dipole index is evaluated sequentially: starting with a base index $D_0 = 0$, the index is updated for each molecule $i$ from 1 to $n$ in increasing order using the formula $D_i = 2 \cdot D_{i-1} + c_i - 1$, where $c_i \in \{1, 2\}$ is the conformation assigned to molecule $i$. The final dipole index of the crystal is $D_n$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of molecules and the number of steric interactions.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a steric interaction between molecule $u$ and molecule $v$.

## Output
If there is no valid conformation assignment that stabilizes the lattice, output a single line containing `NO`.
If a valid assignment exists, output `YES` on the first line. On the next line, output $n$ space-separated integers $c_1, \ldots, c_n$ ($c_i \in \{1, 2\}$), representing the sequence of conformations that minimizes the final dipole index.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
