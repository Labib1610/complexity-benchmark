# Phase State Configuration

Time limit: 1 s
Memory limit: 256 MB

You are optimizing a software engine that executes a set of background tasks. The engine accommodates a minimum of 1 background task and has a maximum hardware capacity of 200,000 tasks. Each task is indexed sequentially starting from 1 and must be assigned a phase state of either 1 or 2.

Due to shared dependencies, certain pairs of tasks are mutually incompatible. The diagnostic system allocates memory for a maximum of 200,000 incompatible pairs, though it is possible for 0 such pairs to exist. If two tasks are mutually incompatible, their phase states cannot be identical.

Your objective is to determine a valid phase state assignment for all tasks, or report if it is impossible to resolve all incompatibilities. If multiple valid assignments exist, you must choose the one that yields the minimum deterministic state hash. The state hash is computed sequentially: start with an initial hash $H_0 = 0$. For each task $i$ from 1 to the total number of tasks in increasing order, the hash is updated as $H_i = 2 \cdot H_{i-1} + p_i - 1$, where $p_i \in \{1, 2\}$ is the phase state assigned to task $i$. The final state hash evaluated is $H_n$.

## Input
The first line contains two integers $n$ and $m$, representing the number of background tasks and the number of incompatible pairs. The values of $n$ and $m$ are guaranteed to fall within the engine capacities described above.
Each of the following $m$ lines contains two valid task indices $u$ and $v$, indicating that task $u$ and task $v$ are mutually incompatible.

## Output
If there is no valid phase state assignment, output a single line containing `NO`.
If a valid assignment exists, output `YES` on the first line. On the next line, output $n$ space-separated integers $p_1, \ldots, p_n$ ($p_i \in \{1, 2\}$), representing the phase states that minimize the final state hash.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
