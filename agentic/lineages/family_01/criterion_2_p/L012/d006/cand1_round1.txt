# Problem B — Power Scaling

Time limit: 1 s   Memory limit: 256 MB

A manufacturing facility employs $n$ robotic welders, identified by integers from 1 to $n$. The facility requires each welder to be configured with a calibration mode of exactly 1 or 2.

Over time, management has installed $m$ shared power buses. Each bus connects two welders. To prevent electrical overload, the system must maintain global equilibrium. We model the facility's topology using two matrices:
- Let $M$ be the $n \times n$ adjacency matrix of the power buses, where $M_{i,j}$ is the number of buses connecting welder $i$ and welder $j$.
- Let $D$ be the $n \times n$ diagonal matrix where $D_{i,i}$ is the degree of welder $i$ (the total number of buses connected to it).
- Let $\mathbf{d}$ be the $n \times 1$ column vector containing the diagonal elements of $D$ (i.e., $\mathbf{d}_i = D_{i,i}$).

A configuration of the facility is defined by an $n \times 1$ column vector $S = \begin{pmatrix} s_1 \\ s_2 \\ \vdots \\ s_n \end{pmatrix}$, where each $s_i \in \{1, 2\}$ is the calibration mode of welder $i$.

A strict operational rule dictates that a configuration is only compliant if it satisfies the following matrix equation:
$(M + D) S = 3 \mathbf{d}$

Your task is to determine whether there exists a compliant configuration vector $S$. If one exists, you must provide the sequence $s_1, s_2, \dots, s_n$. If multiple compliant sequences exist, you must output the one that produces the smallest possible value when evaluated as the sum $\sum_{i=1}^n s_i \cdot 3^{n-i}$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a power bus connecting welder $u$ and welder $v$.

## Output
If there is no way to assign the calibration modes without violating the operational rule, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (each either 1 or 2), representing the valid configuration sequence that minimizes the required sum.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
