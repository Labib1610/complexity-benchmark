# Problem B — Quantum Interference Configurations

Time limit: 1 s
Memory limit: 256 MB

You are analyzing a theoretical quantum system consisting of a set of particles and their entanglement links. 
The simulation hardware limits the scale of the system: neither the number of particles nor the number of links will ever exceed the number of bytes in $200$ kilobytes (using the SI definition where $1$ kilobyte = $1000$ bytes). There is always at least one particle, and there may be zero links.

You are given $n$ particles. Each particle $k$ (for $1 \le k \le n$) must collapse into one of two quantum spin states, represented by the integer values $h_k \in \{1, 2\}$.

The system is restricted by $m$ entanglement links. Each link is specified by a pair of particles $(u, v)$. For the system to be stable, every linked pair must exhibit destructive wave interference. Specifically, their assigned states must satisfy the following complex magnitude equation:
$$ \left| i^{h_u} + i^{h_v} \right| = \sqrt{2} $$
where $i$ is the imaginary unit ($i = \sqrt{-1}$).

Your task is to determine whether there exists a global state assignment $h_1, h_2, \dots, h_n$ that stabilizes all $m$ entanglement links simultaneously. 

If there are multiple stable configurations, the system will naturally settle into the one that minimizes the total ground-state potential energy $E$, defined by the polynomial:
$$ E = \sum_{k=1}^n h_k \cdot 4^{n-k} $$
You must output this specific configuration.

## Input
The first line contains two integers $n$ and $m$, representing the number of particles and the number of entanglement links.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing an entanglement link between particle $u$ and particle $v$.

## Output
If there is no stable configuration that satisfies all links, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $h_1, h_2, \dots, h_n$ (each either `1` or `2`), representing the stable configuration that minimizes the potential energy $E$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit Boolean formula was replaced with a complex magnitude equation that mathematically enforces $h_u \neq h_v$. The "lexicographically smallest" tie-break rule was replaced with an algebraically equivalent exponential objective function. This forces solvers to deduce that minimizing this sum is identical to the standard greedy lexicographical choice; models that attempt to explicitly compute and compare the energy values will TLE due to large integer arithmetic limits.
</RATIONALE>
<PRESERVED_ANSWER>
The complex magnitude equation $|i^{h_u} + i^{h_v}| = \sqrt{2}$ evaluates to true if and only if $h_u \neq h_v$, and minimizing the given exponential sum mathematically guarantees selecting the exact same lexicographically smallest sequence, ensuring all valid outputs remain strictly identical.
</PRESERVED_ANSWER>

The problem remains equivalent to finding the lexicographically smallest 2-coloring of a bipartite graph, which is solvable in O(n+m) time using BFS, keeping it in P.
