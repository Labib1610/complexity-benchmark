<STATEMENT>
# Quantum Sensor Calibration

Time limit: 1 s
Memory limit: 256 MB

You are calibrating a network of $n$ quantum sensors. Each sensor $i$ must be assigned a discrete energy state $s_i \in \{1, 2\}$.

The network contains $m$ entanglement links, each connecting a specific pair of sensors. For any two sensors $u$ and $v$ connected by a link, their joint quantum system is described by the $2 \times 2$ symmetric matrix:
$$ M = \begin{pmatrix} s_u & 1 \\ 1 & s_v \end{pmatrix} $$

To maintain network stability, the joint system matrix for every entanglement link must have an eigenvalue exactly equal to $\frac{3 + \sqrt{5}}{2}$.

You need to determine if it is possible to assign a valid state to every sensor in the network without violating the eigenvalue constraint on any link. If there are multiple valid ways to configure the network, you must output the configuration where the sequence of states $(s_1, s_2, \dots, s_n)$ is lexicographically smallest. (A sequence $A$ is lexicographically smaller than $B$ if $A$ has a smaller value at the first index where the two sequences differ.)

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), which denote the total number of sensors and the number of entanglement links, respectively.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), specifying an entanglement link between sensor $u$ and sensor $v$.

## Output
If there is no way to assign states that satisfies all link constraints, output a single line with the word `NO`.
If a valid calibration exists, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \ldots, s_n$ (where each $s_i \in \{1, 2\}$), representing the lexicographically smallest valid assignment of states.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The problem was completely reframed from electromagnetic dipoles to quantum sensor matrices. The previously obvious "one is twice the other" condition (which trivially means $s_u \neq s_v$) has been replaced by a requirement that a $2 \times 2$ matrix formed by the states has a specific irrational eigenvalue. This forces the model to either mathematically evaluate the characteristic polynomial for all 4 discrete combinations to discover it is an XOR constraint, or fail by attempting to use numerical matrix solvers.
</RATIONALE>
<PRESERVED_ANSWER>
The matrix $M$ has the eigenvalue $(3 + \sqrt{5})/2$ if and only if $\{s_u, s_v\} = \{1, 2\}$, which is exactly the same $s_u \neq s_v$ constraint as the seed problem's dipole condition.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
