<STATEMENT>
# Foundation Resonance

Time limit: 1 s
Memory limit: 256 MB

You are designing the foundation for a large structure supported by $n$ load-bearing pillars. Each pillar must be cast using one of two concrete blends, designated as blend 1 and blend 2. 

To maintain structural integrity, certain pairs of pillars are linked by rigid steel stabilizers. Because the stabilizers are designed to anchor into dissimilar micro-structures to prevent resonant vibrations, any two pillars connected by a stabilizer must be cast using different blends. If they are cast with the same blend, the resonance will fracture the stabilizer. You are given the blueprints detailing $m$ such stabilizer connections.

Your task is to determine if there is a valid assignment of concrete blends to all $n$ pillars. If multiple valid assignments exist, you must find the one that minimizes the total construction penalty. 

The pillars are indexed from $1$ to $n$ based on their structural priority. Using blend 2 incurs a penalty based on the pillar's index, while blend 1 incurs no penalty. Specifically, the total penalty for the foundation is calculated as $\sum_{i=1}^n (b_i - 1) \cdot 2^{n-i}$, where $b_i \in \{1, 2\}$ is the blend chosen for pillar $i$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of pillars and the number of stabilizers, respectively.
The next $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a stabilizer connects pillar $u$ and pillar $v$.

## Output
If no valid blend assignment can be found that prevents stabilizer fractures, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $b_1, \ldots, b_n$ (where each $b_i \in \{1, 2\}$), representing the blend assignment that minimizes the total penalty.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
