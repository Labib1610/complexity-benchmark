<STATEMENT>
# Resonant Amplitude Tuning

Time limit: 1 s
Memory limit: 256 MB

You are configuring an array of $n$ electromagnetic emitters, numbered 1 to $n$. You must assign each emitter a base amplitude $s_i$, which must be a strictly positive integer.

The system contains $m$ resonance links, each connecting a specific pair of emitters. To maintain a stable standing wave, any two emitters $u$ and $v$ connected by a link must satisfy the following harmonic condition: the sum of the reciprocals of their amplitudes must evaluate to exactly $1.5$. That is, $\frac{1}{s_u} + \frac{1}{s_v} = \frac{3}{2}$.

You need to determine if it is possible to assign a valid positive integer amplitude to every emitter in the array without violating the harmonic condition on any link. If there are multiple valid ways to configure the array, you must output the configuration where the sequence of amplitudes $(s_1, s_2, \dots, s_n)$ appears first in dictionary (lexicographical) order. (A sequence $A$ comes before $B$ in dictionary order if $A$ has a smaller value at the first index where the two sequences differ.)

## Input
The first line provides two integers $n$ and $m$. The value of $n$ is at least 1 and at most the number of square centimeters in $20$ square meters. The value of $m$ is at least 0 and at most the total number of seconds in $55$ hours, $33$ minutes, and $20$ seconds.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), specifying a resonance link between emitter $u$ and emitter $v$.

## Output
If there is no way to assign strictly positive integer amplitudes that satisfies all link conditions, output a single line with the word `NO`.
If a valid configuration exists, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \ldots, s_n$, representing the lexicographically smallest valid assignment of base amplitudes.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit domain `{1, 2}` and the direct relational constraint ("one is exactly twice the other") were removed. They were replaced with an algebraically equivalent condition: `1/su + 1/sv = 1.5` for strictly positive integers, which inherently restricts connected nodes to the values `{1, 2}` and forces them to be distinct. The bounds were also obfuscated using physical unit conversions (S07) to prevent trivial bounding box matching. This forces the model to algebraically deduce the allowed domain and recognize the underlying graph 2-coloring structure, rather than relying on explicit keywords.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic equation `1/su + 1/sv = 1.5` over positive integers has exactly two solutions: `(1, 2)` and `(2, 1)`, which perfectly preserves the original `{1, 2}` domain constraint and the requirement that adjacent nodes have different values, ensuring all valid assignments and the lexicographically smallest tie-breaker remain completely identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding a valid 2-coloring (bipartite check) on the given graph, which is solvable in O(n + m) time using BFS or DFS, keeping it in the P complexity class.
</PRESERVED_CLASS>
