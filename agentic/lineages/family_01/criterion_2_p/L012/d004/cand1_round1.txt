# Problem B — Power Scaling

Time limit: 1 s   Memory limit: 256 MB

A manufacturing facility employs $n$ robotic welders, identified by integers from 1 to $n$. The facility requires each welder to be configured with a calibration mode of exactly 1 or 2.

Over time, management has installed $m$ shared power buses. Each bus connects two specific welders. A strict operational rule dictates that to prevent electrical overload, any two welders connected by a shared bus must have harmonized modes. Specifically, if a bus connects welder $u$ and welder $v$, the remainder when $s_u$ is divided by $s_v$, added to the remainder when $s_v$ is divided by $s_u$, must evaluate to exactly 1.

Your task is to determine whether the entire set of welders can be configured in complete compliance with this operational rule. If a compliant configuration exists, you must provide the specific configuration sequence $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$ is the calibration mode assigned to welder $i$). If multiple such compliant sequences exist, you must output the one that produces the smallest possible value when evaluated as the sum $\sum_{i=1}^n s_i \cdot 3^{n-i}$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$, representing the two welders connected by a shared power bus.

## Output
If there is no way to assign the calibration modes without violating the operational rule, print a single line containing NO.
Otherwise, print YES on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (each either 1 or 2), representing the valid configuration sequence that minimizes the required sum.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the "product is exactly 2" edge rule with a modulo arithmetic condition ((u%v) + (v%u) == 1) that evaluates to the same truth table for domain {1,2} but avoids simple equality or product checks. Replaced the "lexicographically smallest" tie-breaker with its mathematical equivalent: minimizing the sequence evaluated as a base-3 polynomial sum. This forces models to algebraically deduce the local constraint and recognize the global optimization as a standard greedy choice, rather than relying on pattern-matching bipartite coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The modulo condition equals 1 if and only if the two modes are different (1 and 2), perfectly matching the original product condition, and minimizing the base-3 polynomial sum is mathematically identical to finding the lexicographically smallest sequence.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to checking if a graph is bipartite (2-colorable) and assigning colors to minimize the first node's color in each component, which is solvable in O(N+M) time via BFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the base-3 sum tie-breaker as requiring them to compute and compare huge integers rather than recognizing it as equivalent to lexicographical order, potentially leading to Time Limit Exceeded if they implement it naively.
</RISK>
