We can model the problem as a graph coloring problem.  
The condition says: for an edge (u, v),  
`(s_u % s_v) + (s_v % s_u) = 1`.  

If both are 1 or both are 2, the sum is 0 or 2, not 1.  
If one is 1 and the other is 2:  
- 1 % 2 = 1, 2 % 1 = 0 → sum = 1.  
So the condition is satisfied exactly when the two nodes have different modes.  

Thus, the graph must be bipartite. If it is, we assign 1 and 2 to the two partitions.  
To get the lexicographically smallest sequence (in base-3 sense), we want as many 1’s as possible at the start.  
We can do a BFS/DFS coloring, starting with 1 for the first node, and propagate.  

Here’s the implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    print(" ".join(str(c) for c in color))
```
