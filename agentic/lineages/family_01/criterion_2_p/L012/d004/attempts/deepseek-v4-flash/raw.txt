We can model each emitter as a binary variable with values 1 or 2.  
The condition “at least one 1 and at least one 2” on an edge means the two endpoints must have different values.  

So the problem reduces to checking if the graph is bipartite, and if so, outputting the lexicographically smallest bipartition labeling with values 1 and 2.

We’ll use BFS/DFS coloring, but for lexicographically smallest, we try to assign 1 to the smallest-index vertex whenever possible, and propagate.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n  # 0 -> amplitude 1, 1 -> amplitude 2

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 0
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
# Convert colors to 1 and 2
res = [1 if c == 0 else 2 for c in color]
print(' '.join(map(str, res)))
```
