# Vessel Calibration

Time limit: 1 s
Memory limit: 256 MB

You are managing a fleet of $n$ autonomous surveying vessels, numbered sequentially starting from 1. The central management system requires at least one vessel and can handle a maximum capacity of 200,000 vessels. Each vessel must be configured with a calibration mode, which is an integer $s_i \in \{1, 2\}$.

Throughout the operation, specific pairs of vessels will navigate in close proximity. The mission log system records $m$ such proximity events. This log can be completely empty or store up to a maximum of 200,000 events. For a pair of vessels to successfully synchronize and merge their data streams during a proximity event, they must be assigned complementary modes: a Mode 1 vessel can only synchronize with a Mode 2 vessel, and vice versa.

Your objective is to find a valid calibration mode assignment for all $n$ vessels, or determine if no such assignment exists. When multiple valid configurations are possible, you must provide the one that minimizes the total system penalty. The penalty is calculated as $\sum_{i=1}^n (s_i - 1) \cdot 2^{n-i}$.

## Input
The first line provides two integers $n$ and $m$, denoting the number of vessels and the number of proximity records, respectively. The constraints on $n$ and $m$ correspond to the minimum requirements and maximum capacities described in the system overview.
The following $m$ lines each contain two integers $u$ and $v$, representing the identifiers of the vessels that will operate close to each other.

## Output
If no valid state assignment is possible, output a single line with `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $s_1, \ldots, s_n$ (where each $s_i \in \{1, 2\}$), representing the valid sequence of calibration modes that minimizes the total system penalty.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
