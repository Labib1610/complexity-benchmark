# Problem B — Operational Windows

Time limit: 1 s   Memory limit: 256 MB

A manufacturing facility tracks a workforce of individuals, numbered sequentially starting from 1. During a standard production cycle, exactly two operational windows are available, designated as window 1 and window 2. A roster configuration consists of an assigned operational window (1 or 2) for each person in the workforce.

The facility's safety protocols include a registry of paired personnel. To ensure balanced oversight, the safety guidelines mandate that for every pair recorded in the registry, the two individuals involved must be distributed across both operational windows—meaning one must be assigned to window 1 and the other to window 2.

Your task is to construct such a roster configuration. If the safety guidelines cannot be satisfied under these conditions, you must report this failure. Should there be more than one configuration that meets all the mandates, you must output the sequence that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$, representing the active headcount and the number of registry logs. The facility's maximum capacity allows for a headcount of up to two hundred thousand personnel, though it will always have at least one active employee. The registry logs up to two hundred thousand historical pairs, or none at all if the facility is new.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ (each between 1 and $n$ inclusive), indicating that person $u$ and person $v$ are logged together in the registry.

## Output
If no roster configuration can satisfy the safety mandates, output a single line containing `NO`.
Otherwise, output a line containing `YES`. On the following line, output $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$) representing the allocated window for each person. This sequence must be the lexicographically smallest among all valid configurations.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
