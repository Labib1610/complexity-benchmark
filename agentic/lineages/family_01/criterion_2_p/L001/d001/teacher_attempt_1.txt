# Problem B — Operational Windows

Time limit: 1 s   Memory limit: 256 MB

A manufacturing facility coordinates a workforce of $n$ individuals, numbered 1 through $n$. The facility's safety protocols include a registry of $m$ interacting pairs among the workforce. 

During a standard production cycle, management must formulate a roster configuration. This configuration consists of a sequence of $n$ integer values, where each individual is assigned an operational code of either 1 or 2. To comply with safety guidelines, the roster must ensure that for every pair recorded in the registry, the sum of the two operational codes assigned to the individuals involved is exactly 3.

Your task is to construct such a roster configuration. If the safety guidelines cannot be satisfied under these conditions, you must report this failure. Should there be more than one configuration that meets all the mandates, you must output the sequence that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of personnel and the number of interacting pairs.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that person $u$ and person $v$ are recorded in the registry as an interacting pair.

## Output
If no roster configuration can satisfy the safety guidelines, output a single line containing `NO`.
Otherwise, output a line containing `YES`. On the following line, output $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$) representing the operational code for each person. This sequence must be the lexicographically smallest among all valid configurations.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit instruction to assign "different values" from "exactly two operational windows" with a requirement to assign an operational code of {1, 2} such that the sum for any registered pair is exactly 3. This removes the surface-level phrasing that triggers bipartite coloring recall, forcing the model to algebraically deduce that the sum constraint is equivalent to an inequality constraint before recognizing the underlying graph structure.
</RATIONALE>
<PRESERVED_ANSWER>
The sum of two values from the set {1, 2} is exactly 3 if and only if one value is 1 and the other is 2, making the constraint mathematically identical to the original requirement of assigning different values.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains a graph 2-coloring (bipartite checking) task, which is solvable in linear time O(n+m) using BFS or DFS.
</PRESERVED_CLASS>
