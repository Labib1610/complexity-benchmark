# Problem B — Frequency Alignment

Time limit: 1 s   Memory limit: 256 MB

An orbital station consists of $n$ life-support modules. To ensure stable operation, each module must be configured with a frequency multiplier of exactly $1$ or exactly $2$.

The station's safety protocol defines $m$ interference links. Each link specifies a pair of modules that interact. To prevent resonance cascades, the product of the frequency multipliers assigned to the two modules in any interference link must be exactly $2$.

Determine if it is possible to configure each module's frequency multiplier in a way that respects all interference links. If there are multiple valid configurations, the automated diagnostic system requires the one that is lexicographically smallest when the frequency multipliers ($1$ or $2$) are listed in order of the module numbers from $1$ to $n$.

## Input
The first line of the input contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — an interference link between module $u$ and module $v$.

## Output
If there is no way to configure the frequency multipliers without violating the safety protocol, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers separated by spaces, where the $i$-th integer is the frequency multiplier ($1$ or $2$) assigned to the $i$-th module, representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

The explicit graph-coloring terminology ("assigned to different buses") was replaced with a numerical constraint: the product of the two variables must be exactly 2. Because the variables are strictly constrained to the domain {1, 2}, this product condition is mathematically identical to an inequality condition (x != y), forcing the model to algebraically deduce the bipartite nature of the constraints rather than matching surface patterns.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the product of two values from {1, 2} equals 2 is uniquely satisfied when one value is 1 and the other is 2; thus, it is perfectly isomorphic to the original requirement that connected modules receive different assignments.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
