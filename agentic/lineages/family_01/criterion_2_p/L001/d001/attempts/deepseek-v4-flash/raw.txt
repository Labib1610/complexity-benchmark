We can treat the problem as a graph coloring problem on a bipartite graph. Each equity is a node, and each cointegrated pair is an edge that requires different colors (postures 1 and 2).  
A valid assignment is possible if and only if the graph is bipartite.  
We also need to output the lexicographically smallest assignment.

To get the lexicographically smallest assignment, we should attempt to assign posture 1 to the smallest possible node whenever possible, which means doing BFS/DFS with a rule to prefer 1.

A common solution method:

- Build adjacency list.
- Maintain an array `color` with -1 for unvisited.
- For each component starting with an unvisited node, BFS with starting color = 1 (smallest possible), ensuring the graph’s bipartiteness.
- If an edge connects two nodes of same color → impossible → output "NO".
- Else output the colors: 1 and 2.

Important: All nodes are in a connected component, we handle each component. If we always start with color=1 this yields the lexicographically smallest valid result (because node 1 will get color 1).

Implementation in Python:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
g = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    g[u].append(v)
    g[v].append(u)

color = [-1] * n  # posture: 1 or 2, colored as 0 or 1 internally?

# Use 0 and 1 for coloring, then final mapping: color0 → 1, color1 → 2.

def bfs(start):
    q = deque([start])
    color[start] = 0
    while q:
        u = q.popleft()
        for v in g[u]:
            if color[v] == -1:
                color[v] = color[u] ^ 1
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

for i in range(n):
    if color[i] == -1:
        color color[i] = 0  # typically the smallest
        bfs(i) # or manage queue

# If we get here, the graph is bipartite
# convert colors: color=0 -> post=1, color=1-> post2
result = [1 if color[c] == color 0 else 1 for c in range(n)]

sys.stdout.write("YES\n")
sys.stdout.write(' ' . join(map(str, result)))
```
