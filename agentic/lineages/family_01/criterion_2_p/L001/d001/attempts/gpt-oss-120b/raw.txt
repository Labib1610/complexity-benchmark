**Solution Explanation**

For every logged pair `{u , v}` we must have  

```
value[u] + value[v] = 3 ,   value[x] ∈ {1 , 2}
```

so the two values must be different.  
The whole set of constraints is therefore exactly the condition *“the graph is
bipartite”* – we have to colour every vertex with two colours, neighbours having
different colours.

If the graph is not bipartite the answer is `NO`.  
Otherwise each connected component can be coloured in two ways
(the two colour classes may be swapped).  
We have to output the **lexicographically smallest** sequence
`value[1] … value[n]`.

--------------------------------------------------------------------

#### 1.   Observations

* In a component the two colour classes are fixed up to a global swap.
* Lexicographic order is decided by the first position where two sequences differ.
  Therefore for each component we only have to decide which colour class receives
  `1` and which receives `2` **based on the smallest vertex index inside the
  component**:
  * let `c` be that smallest vertex,
  * let `col[c]` be its colour (`0` or `1`) obtained by a BFS/DFS,
  * if `col[c] == 0` we keep the orientation (`colour 0 → 1`, `colour 1 → 2`);
    otherwise we flip it (`colour 1 → 1`, `colour 0 → 2`).

  This makes the smallest index of the component equal to `1`, which is the
  best possible choice for the whole sequence, because any later vertex cannot
  influence earlier positions.

* Isolated vertices are components of size 1, they receive `1`.

Thus the problem reduces to:

1. check bipartiteness,
2. for each component remember its vertices and the colour of each vertex,
3. decide orientation as described,
4. output the values.

All steps are linear in `n + m`.

--------------------------------------------------------------------

#### 2.   Algorithm
```
read n, m
build adjacency list G (undirected)

colour[1…n] = -1          # -1 = unvisited, 0/1 = bipartite colour
answer[1…n] = 0

for v = 1 … n:
    if colour[v] != -1: continue
    # start new component
    queue = [v]; colour[v] = 0
    component_vertices = [v]
    bfs while queue not empty:
        x = pop
        for each y in G[x]:
            if colour[y] == -1:
                colour[y] = colour[x] ^ 1
                queue.append(y)
                component_vertices.append(y)
            elif colour[y] == colour[x]:
                print "NO" and exit   # not bipartite

    # decide orientation
    min_vertex = min(component_vertices)
    if colour[min_vertex] == 0:
        # orientation as is: colour 0 → 1, colour 1 → 2
        for u in component_vertices:
            answer[u] = 1 if colour[u] == 0 else 2
    else:
        # flip
        for u in component_vertices:
            answer[u] = 1 if colour[u] == 1 else 2

print "YES"
print answer[1] … answer[n] separated by spaces
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `NO` iff no feasible assignment exists,
otherwise prints `YES` and the lexicographically smallest feasible assignment.

---

##### Lemma 1  
During BFS, if an edge `(x, y)` is found with `colour[x] == colour[y]`,
the graph is not bipartite, hence no assignment satisfies all constraints.

**Proof.** In any assignment neighbours must have different values (1 vs 2),
which corresponds exactly to different colours in a bipartition.
If two adjacent vertices receive the same colour, a 2‑colouring is impossible,
so the constraints cannot be satisfied. ∎



##### Lemma 2  
If the algorithm finishes BFS without contradiction, the obtained `colour`
is a proper 2‑colouring of the whole graph.

**Proof.** BFS starts each component with an arbitrary vertex coloured `0`
and always assigns the opposite colour to every newly discovered neighbour.
Thus every processed edge connects vertices of opposite colours.
All vertices are visited, so the property holds for all edges. ∎



##### Lemma 3  
For a connected component `C`, let `c` be its smallest index vertex.
Among the two possible assignments of `{1,2}` to the colour classes,
the algorithm chooses the one that gives `value[c] = 1`.

**Proof.** The algorithm checks `colour[c]`.  
If it is `0`, it maps colour 0 → 1, colour 1 → 2, giving `value[c]=1`.  
If it is `1`, it flips the mapping, again giving `value[c]=1`. ∎



##### Lemma 4  
The assignment produced by the algorithm is lexicographically minimal among
all feasible assignments.

**Proof.** Consider the components ordered by their smallest vertex.
Processing components in increasing order of that vertex is exactly the order
in which the final sequence is examined lexicographically.

For the first component `C₁` (its smallest vertex is `c₁`), by Lemma&nbsp;3 the
algorithm forces `value[c₁]=1`. Any feasible assignment must give either `1` or
`2` to `c₁`; if it gave `2` the whole sequence would be lexicographically larger.
Thus every lexicographically minimal feasible sequence must also have
`value[c₁]=1`. The algorithm’s choice for the remaining vertices of `C₁`
is forced (the opposite colour receives `2`), so the prefix up to the last
vertex of `C₁` is minimal.

Inductively, assume the algorithm has produced the minimal possible prefix up
to the end of component `C_{k-1}`. For component `C_k` the first index not yet
fixed is its smallest vertex `c_k`. Again Lemma&nbsp;3 forces `value[c_k]=1`,
which is necessary for any globally minimal sequence. The rest of `C_k`
is then uniquely determined. Hence after processing `C_k` the prefix remains
minimal.

By induction the whole sequence is lexicographically minimal. ∎



##### Lemma 5  
If the algorithm outputs `YES` and a sequence, that sequence satisfies all
constraints.

**Proof.** By Lemma&nbsp;2 the colours form a proper bipartition, i.e. every edge
joins vertices of different colours. The algorithm maps the two colours to the
different numbers `1` and `2`. Therefore for every edge `{u,v}` we have
`value[u] ≠ value[v]`, equivalently `value[u] + value[v] = 3`. ∎



##### Theorem  
The algorithm prints `NO` iff the instance has no feasible roster.
Otherwise it prints `YES` and the lexicographically smallest feasible roster.

**Proof.**  
*If* the algorithm prints `NO`, it discovered an edge with equal colours.
By Lemma&nbsp;1 the graph is not bipartite, thus no assignment exists.

*If* a feasible assignment exists, the graph is bipartite, so BFS never meets
a contradiction; the algorithm reaches the end and prints `YES`.  
By Lemma&nbsp;5 the printed sequence is feasible.  
By Lemma&nbsp;4 it is the lexicographically smallest feasible sequence.

Hence the statement holds. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once → `O(n + m)`.  
*Additional loops* over component vertices are also linear.

Total time `O(n + m)` ≤ `4·10⁵`, well inside the 1 s limit.  
Memory consumption `O(n + m)` ≤ about 3 MB for the adjacency list plus arrays,
well below 256 MB.

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    g = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        g[u].append(v)
        g[v].append(u)

    colour = [-1] * (n + 1)          # -1 unvisited, 0/1 bipartite colour
    ans = [0] * (n + 1)

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        while q:
            x = q.popleft()
            cx = colour[x]
            for y in g[x]:
                if colour[y] == -1:
                    colour[y] = cx ^ 1
                    q.append(y)
                    comp.append(y)
                elif colour[y] == cx:
                    print("NO")
                    return
        # decide orientation
        min_v = min(comp)
        if colour[min_v] == 0:
            for v in comp:
                ans[v] = 1 if colour[v] == 0 else 2
        else:
            for v in comp:
                ans[v] = 1 if colour[v] == 1 else 2

    # all done
    print("YES")
    sys.stdout.write(' '.join(str(ans[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
