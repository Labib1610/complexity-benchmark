We can model this as a graph problem.  
Each server must be either a transmitter (1) or receiver (2).  
If a server is a transmitter, all its incident edges must point away from it.  
If a server is a receiver, all its incident edges must point toward it.  

This means:  
- If two servers are connected by an edge, they **cannot** have the same mode.  
  Because if both were transmitters, the edge would need to point away from both — impossible.  
  If both were receivers, the edge would need to point toward both — impossible.  

So the graph must be **bipartite**.  
We can check bipartiteness with BFS/DFS and assign modes accordingly.  
For lexicographically smallest assignment, we start with server 1 as mode 1 (transmitter) and propagate.

If the graph is not bipartite, output `NO`.  
Otherwise, output `YES` and the assignment.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

mode = [-1] * n
possible = True

for i in range(n):
    if mode[i] == -1:
        mode[i] = 1  # start as transmitter
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if mode[v] == -1:
                    mode[v] = 3 - mode[u]  # opposite mode
                    q.append(v)
                elif mode[v] == mode[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    print(" ".join(str(mode[i]) for i in range(n)))
```
