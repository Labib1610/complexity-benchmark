# Problem B — Micro-Robotic Assembly

Time limit: 1 s   Memory limit: 256 MB

You are configuring a swarm of $n$ micro-robots, indexed from 1 to $n$, to form a stable structure. The assembly chamber can support a swarm size $n$ ranging from a single prototype up to a maximum capacity of two hundred thousand units. 

Each robot features a polarity switch that must be set to either state 1 or state 2. The structural blueprint provides $m$ magnetic linkages, where this count $m$ can range from zero up to the chamber's maximum robot capacity. Each linkage specifies that robot $u$ and robot $v$ are connected by a strut. To maintain the magnetic bond, any two robots joined by a linkage must be configured to opposite polarity states.

You must determine if there is a valid polarity configuration for the entire swarm. If it is impossible to satisfy all linkage requirements simultaneously, you must report this. If there are multiple valid configurations, the system defaults to the sequence of states that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$, representing the number of robots and the number of magnetic linkages. The bounds on these values are defined by the chamber's capacities as described.
Each of the subsequent $m$ lines contains two integers $u$ and $v$, corresponding to valid robot indices, indicating that a magnetic linkage connects robot $u$ and robot $v$.

## Output
If no valid configuration is possible, output a single line containing `NO`.
Otherwise, output a line containing `YES`. On the following line, output $n$ space-separated integers $x_1, x_2, \dots, x_n$ (where each $x_i \in \{1, 2\}$) representing the assigned polarity state for each robot. This sequence must be the lexicographically smallest among all valid configurations.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

Replaced explicit bare inequalities for $n$ and $m$ with descriptive chamber capacity limits. This forces the model to synthesize the bipartite condition from the logical constraints of the scenario and to parse numeric bounds from natural language rather than relying on standard mathematical notation.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to assign states 1 and 2 such that linked robots have opposite states is mathematically identical to assigning values 1 and 2 with an absolute difference of exactly 1, ensuring the exact same lexicographically smallest valid sequence or 'NO' if impossible.
</PRESERVED_ANSWER>

The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of a graph (or testing for bipartiteness), which is solvable in linear time using Breadth-First Search.
</PRESERVED_CLASS>
