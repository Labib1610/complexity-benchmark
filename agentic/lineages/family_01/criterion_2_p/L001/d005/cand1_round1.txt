<STATEMENT>
# Problem B — Polymer Resonance Tuning

Time limit: 1 s
Memory limit: 256 MB

A synthetic polymer consists of $n$ monomers, indexed from 1 to $n$. A tuning configuration assigns each monomer a resonance level $r_i$, which must be chosen as either 1 or 2.

To analyze the stability of the polymer, we define its normalized state vector $\mathbf{s}$ of length $n$, where each element is given by the transformation $s_i = r_i - 1.5$.

The laboratory maintains a record of $m$ covalent bonds between these monomers. This record is represented by an $m \times n$ bonding matrix $M$. Each of the $m$ rows corresponds to a single documented bond. Specifically, if the $k$-th bond connects monomers $u$ and $v$, then the $k$-th row of $M$ has a 1 in column $u$ and a 1 in column $v$ (if $u = v$, column $u$ contains a 2 instead), with all other entries in that row being 0.

To ensure molecular resonance, the normalized state vector $\mathbf{s}$ must lie in the null space of the bonding matrix $M$. That is, it must satisfy the matrix equation:
$M \mathbf{s} = \mathbf{0}$
where $\mathbf{0}$ is the zero column vector of length $m$.

Your task is to determine a valid tuning configuration (the sequence of resonance levels $r_1, r_2, \dots, r_n$) that satisfies this requirement. If multiple valid configurations exist, you must output the one that is lexicographically smallest. (A sequence $r$ is lexicographically smaller than $r'$ if $r_i < r'_i$ at the first index $i$ where they differ). If no configuration can satisfy the matrix equation, you must report the failure.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), identifying the bonded monomers $u$ and $v$ used to construct the corresponding row of the matrix $M$.

## Output
If no valid tuning configuration exists, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $r_1, r_2, \dots, r_n$ (where each $r_i \in \{1, 2\}$) representing the resonance level assigned to each respective monomer. This sequence must be the lexicographically smallest possible valid sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Removed the explicit constraints "cannot both be 1" and "cannot both be 2", which models easily recognized as a bipartite coloring condition. Replaced them with a mathematically identical linear algebra formulation: finding a vector in the null space of an incidence matrix, with variables shifted to {-0.5, 0.5}. This forces the models to symbolically deduce that the row equation $s_u + s_v = 0$ over this domain means $r_u \neq r_v$, and to resist the trap of applying costly matrix algorithms ($O(N^3)$) to a problem that requires $O(N+M)$ graph traversal.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $M \mathbf{s} = \mathbf{0}$ means $s_u + s_v = 0$ for every bond; since $s_i \in \{-0.5, 0.5\}$, this strictly requires $s_u \neq s_v$, which is identical to the original requirement that $r_u \neq r_v$.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains exactly 2-coloring (bipartiteness testing) on an undirected graph, which is solvable in $O(N+M)$ time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the matrix equation as requiring a continuous or real-valued solution space, but the domain $r_i \in \{1, 2\}$ is firmly stated in the first paragraph and output format.
</RISK>

<METHOD_DESCRIPTION>Transforms local graph constraints into a global linear algebra constraint ($M \mathbf{s} = \mathbf{0}$). It embeds the boolean choices into real numbers ($s_i = r_i - 1.5$) and frames the problem as finding a vector in the null space of an incidence matrix. This distracts LLMs with continuous mathematics and linear algebra terminology, forcing them to either incorrectly apply expensive matrix algorithms or successfully deduce the equivalent discrete graph structure.</METHOD_DESCRIPTION>
