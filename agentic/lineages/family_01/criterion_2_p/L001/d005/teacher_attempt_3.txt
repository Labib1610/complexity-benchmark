<STATEMENT>
# Problem B — Isotope Bonding

Time limit: 1 s   Memory limit: 256 MB

You are synthesizing a novel polymer consisting of $n$ molecular nodes, numbered 1 to $n$. Each node must be populated with one of two stable isotopes, which provide either 1 or 2 active binding sites. 

The polymer structure is defined by $m$ covalent linkages. Each linkage connects node $u$ and node $v$. For the bond to be stable, the sum of the active binding sites provided by node $u$ and node $v$ must be exactly 3. 

You must determine if there is a valid isotope assignment for all $n$ nodes that stabilizes all $m$ linkages simultaneously. If it is impossible, you must report this. If there are multiple valid assignments, the synthesis protocol defaults to the sequence of binding site counts that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of molecular nodes and the number of linkages.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a linkage between node $u$ and node $v$.

## Output
If no stable assignment is possible, output a single line containing `NO`.
Otherwise, output a line containing `YES`. On the following line, output $n$ space-separated integers $x_1, x_2, \dots, x_n$ (where each $x_i \in \{1, 2\}$) representing the number of active binding sites assigned to each node. This sequence must be the lexicographically smallest among all valid assignments.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The scenario was completely reframed from positioning robots on a 1D track (where absolute difference equals 1) to assigning isotopes in a polymer (where the sum of binding sites equals 3). This removes spatial and difference-based affordances, forcing the model to algebraically deduce that for values restricted to {1, 2}, a sum of 3 implies the values must be distinct, thereby recognizing the bipartite/2-coloring structure from first principles.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $x_i \in \{1, 2\}$ combined with $x_u + x_v = 3$ is mathematically identical to $|x_u - x_v| = 1$, preserving all valid assignments, including the impossibility of self-loops, so the lexicographically smallest sequence remains identical for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in linear time using Breadth-First Search.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "sum of the active binding sites provided by node u and node v" in the presence of multiple edges, but the phrasing applies per linkage and the condition $x_u + x_v = 3$ is idempotent for identical pairs, so ambiguity is minimal.
</RISK>
