# Problem B — Polymer Resonance Tuning

Time limit: 1 s
Memory limit: 256 MB

A synthetic polymer consists of $n$ monomers, indexed from 1 to $n$. A tuning configuration assigns each monomer a resonance level $r_i$, which must be strictly chosen from the set $\{1, 2\}$.

The laboratory maintains a record of $m$ covalent bonds between these monomers. To ensure molecular stability, a strict structural rule applies to any pair of monomers connected by a documented bond. For every recorded bonded pair of monomers $u$ and $v$, their assigned resonance levels must satisfy the following equation:
$r_u^3 + r_v^3 = 9$

Your task is to determine a valid tuning configuration for all $n$ monomers. If multiple valid configurations exist, you must output the sequence of resonance levels that is the lexicographically smallest. This means the configuration must prioritize assigning level 1 to monomer 1 if any valid configuration allows it; then, among those valid configurations, prioritize assigning level 1 to monomer 2, and so on sequentially up to monomer $n$. If no configuration can satisfy the structural rule for all recorded bonds simultaneously, you must report the failure.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$, identifying a bonded pair of monomers in the record. Both monomer identifiers $u$ and $v$ are at least 1 and at most $n$.

## Output
If no valid tuning configuration exists, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $r_1, r_2, \dots, r_n$ (where each $r_i \in \{1, 2\}$) representing the resonance level assigned to each respective monomer from 1 to $n$. This sequence must be the lexicographically smallest possible valid sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The problem requires exactly the same logic as the seed, but the bipartite coloring constraint is disguised using the cubic equation $r_u^3 + r_v^3 = 9$. Since the variables are strictly in $\{1, 2\}$, this equation is only satisfied when one variable is 1 and the other is 2. This forces models to algebraically derive the difference constraint rather than pattern-matching "cannot both be 1, cannot both be 2" to standard bipartite graph coloring. The bounds have been restored to their exact inequality format to satisfy the contract checker.
</RATIONALE>
<PRESERVED_ANSWER>
The equation $r_u^3 + r_v^3 = 9$ on the domain $\{1, 2\}$ perfectly restricts the assigned levels for bonded pairs to be distinct, which is logically identical to the seed's constraints, leaving the solution space and lexicographical tie-breaker completely unchanged.
</PRESERVED_ANSWER>
