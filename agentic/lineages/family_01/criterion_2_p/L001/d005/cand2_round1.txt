<METHOD_DESCRIPTION>
Replaced the explicit algebraic bounds (divisors) and equations (sum of cubes) with a combinatorial grid-path predicate that implicitly and uniquely restricts the values to the same binary set {1, 2} and enforces the bipartite relation cross-edge. This prevents models from immediately translating the constraints into a 2-coloring problem without first solving the non-trivial combinatorial Diophantine equation to discover the valid assignments.
</METHOD_DESCRIPTION>

# Problem B — Interferometry Array

Time limit: 1 s   Memory limit: 256 MB

An observatory operates an interferometry array consisting of $n$ radio telescope dishes. To calibrate the array for a new observation run, the control system must assign a configuration value to each dish. The hardware requires every configuration value to be a positive integer.

The array relies on $m$ baseline connections, each linking a specific pair of dishes that act as a single synthetic aperture. For the interferometry to function correctly across a baseline, the signals from the two linked dishes must be offset. The control system enforces this through a strict routing constraint derived from the assigned values. 

For any two dishes connected by a baseline, let their assigned configuration values be $u$ and $v$. Imagine a 2D grid where a routing path starts at $(0,0)$ and ends at $(u, v)$. A path consists only of unit steps in the positive x-direction (East) and positive y-direction (North). The baseline configuration is valid if and only if there is **exactly one** such path from $(0,0)$ to $(u, v)$ that never visits the coordinate $(1, 1)$.

You need to determine if there is a valid calibration that satisfies all baseline connections. If there are multiple valid ways to assign the configuration values across the array, the control system must select the one that yields the lexicographically smallest sequence of values when listed in order from dish $1$ to dish $n$.

## Input
The first line of the input contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $a$ and $b$ — a baseline connection between dish $a$ and dish $b$.

## Output
If there is no way to assign the configuration values without violating the baseline requirements, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers separated by spaces, where the $i$-th integer is the configuration value assigned to the $i$-th dish, representing the lexicographically smallest valid assignment ordered by dish indices from $1$ to $n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Removed the explicit divisor condition and cube-sum equation, replacing them with a single combinatorial routing predicate on a 2D grid. The new predicate (exactly 1 path avoiding the coordinate (1,1)) mathematically restricts the configuration values to exactly the set {1, 2} and forces every edge to connect a 1 and a 2. This forces the model to solve a non-trivial combinatorial Diophantine equation before it can recognize the underlying bipartite graph structure, breaking the immediate pattern-matching shortcut.
</RATIONALE>
<PRESERVED_ANSWER>
For every input, the combinatorial predicate uniquely restricts the valid configuration assignments to exactly the same bipartite {1, 2} colorings as the original problem, and the lexicographical tie-breaker is identically preserved, ensuring identical outputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains reducible to 2-coloring (bipartite checking) in O(V+E) time, which is in P, since the only valid values are 1 and 2 and they must alternate across edges.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret 'exactly one such path' or 'never visits the coordinate (1,1)' if they fail to understand standard lattice path definitions, though the wording is mathematically standard and precise.
</RISK>
