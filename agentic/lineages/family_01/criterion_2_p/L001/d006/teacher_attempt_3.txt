# Problem B — Acoustic Sensor Array

Time limit: 1 s   Memory limit: 256 MB

You are configuring an array of $n$ acoustic sensors, sequentially designated from 1 to $n$. Each sensor must be calibrated to operate at a continuous transmission power of either 1 watt or 2 watts.

The operational environment requires establishing $m$ synchronization channels. Each channel synchronizes a specific pair of sensors, $u$ and $v$. To prevent signal distortion, the combined transmission power of the two sensors sharing a channel must equal exactly 3 watts.

Your task is to determine if there is a power configuration for all $n$ sensors that successfully stabilizes every synchronization channel. If no such configuration can be found, you must report the failure. If multiple valid configurations are possible, the system protocol requires you to select the one where the sequence of assigned wattages (from sensor 1 to $n$) forms the numerically smallest $n$-digit integer when the wattages are written in order.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of sensors and the number of synchronization channels.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a synchronization channel operates between sensor $u$ and sensor $v$.

## Output
If it is impossible to configure the sensors to satisfy all channel requirements, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $x_1, x_2, \dots, x_n$ (where each $x_i \in \{1, 2\}$) representing the transmission power assigned to each sensor. This sequence must be the one that forms the smallest $n$-digit integer among all valid configurations.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
