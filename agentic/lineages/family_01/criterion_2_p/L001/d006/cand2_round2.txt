# Problem B — Module Synchronization Index

Time limit: 1 s
Memory limit: 256 MB

A distributed system consists of $n$ identical modules, numbered from 1 to $n$. A configuration assigns each module a discrete operating mode, which must be chosen as either 1 or 2.

The system topology is defined by $m$ bidirectional data links connecting various pairs of modules. To ensure operational stability, the configuration must satisfy a precise global synchronization condition. For each of the $m$ links, we calculate a link weight equal to the sum of the operating modes of the two modules it connects. The overall synchronization index of the system is the product of these link weights across all $m$ links.

A configuration is deemed stable if its synchronization index is exactly equal to $3^m$. If $m=0$, the empty product of link weights evaluates to 1 by convention, which matches $3^0$, making any configuration valid under this convention.

Your task is to determine a stable configuration for all $n$ modules. If multiple stable configurations exist, you must output the sequence of modes that is lexicographically smallest. This means the configuration must prioritize mode 1 for module 1 if any valid configuration permits it; then, among those valid configurations, prioritize mode 1 for module 2, and so forth sequentially up to module $n$. If no configuration can achieve a synchronization index of exactly $3^m$, you must report the failure.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$, identifying a pair of modules connected by a data link. Both module identifiers $u$ and $v$ are at least 1 and at most $n$.

## Output
If no configuration can satisfy the synchronization condition, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $r_1, r_2, \dots, r_n$ (where each $r_i \in \{1, 2\}$) representing the mode assigned to each respective module from 1 to $n$. This sequence must be the lexicographically smallest possible valid sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The problem was completely reframed from polymer resonance to network module synchronization. The critical change is replacing the sum of squared differences with a product of sums. Since the variables are 1 or 2, their sum is 2, 3, or 4. The requirement that the product of $m$ such sums equals $3^m$ forces every single sum to be exactly 3 (as 2 and 4 introduce prime factors of 2). This mathematically forces every connected pair to have distinct values, preserving the exact 2-coloring requirement of the seed while requiring the model to deduce this via prime factorization. The flagged word "trivially" was removed and replaced with neutral, formal wording.
</RATIONALE>
<PRESERVED_ANSWER>
The product of sums equals $3^m$ if and only if every edge connects a 1 and a 2, which is mathematically identical to the seed's constraint that the sum of squared differences equals $m$, thus preserving all valid configurations and the lexicographically smallest result.
</PRESERVED_ANSWER>
