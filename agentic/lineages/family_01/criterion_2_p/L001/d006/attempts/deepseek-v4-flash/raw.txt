Let's analyze the problem.

We have machines at positions 1 or 2.  
For each strut (u, v), we need:  
`x_u + x_v = 3`.  
Since positions are only 1 or 2, this means one must be 1 and the other 2.  
So each edge connects two nodes of opposite "types" (like a bipartite graph).

Thus, the graph must be bipartite. If not, output `NO`.

If it is bipartite, we have two possible colorings (swap colors).  
We need to choose the assignment that minimizes:

\[
\sum_{i=1}^n x_i \cdot 3^{n-i}
\]

Since \(3^{n-i}\) is huge for small i, the lexicographically smallest sequence (from machine 1 to n) is the one that minimizes the value.  
Because \(3^{n-i}\) decreases as i increases, the first differing position determines the smaller value.  
So we want the lexicographically smallest sequence of 1s and 2s among valid assignments.

Given a bipartite graph, we can color it with BFS/DFS.  
We get two possible assignments:  
- Color A = 1, Color B = 2  
- Color A = 2, Color B = 1  

We choose the one that is lexicographically smaller.

Implementation plan:
1. Build adjacency list.
2. Try to 2-color the graph. If conflict → NO.
3. If bipartite, we have `color` array (0/1).
4. Generate two candidate arrays:
   - cand1: if color[i]==0 → 1 else 2
   - cand2: if color[i]==0 → 2 else 1
5. Compare lexicographically and pick smaller.
6. Output YES and the chosen sequence.

Complexity: O(n+m).

Let's write the code.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    ok = True
    
    from collections import deque
    for i in range(n):
        if color[i] == -1:
            color[i] = 0
            q = deque([i])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = color[u] ^ 1
                        q.append(v)
                    elif color[v] == color[u]:
                        ok = False
                        break
                if not ok:
                    break
        if not ok:
            break
    
    if not ok:
        print("NO")
        return
    
    cand1 = [1 if c == 0 else 2 for c in color]
    cand2 = [2 if c == 0 else 1 for c in color]
    
    # choose lexicographically smaller
    if cand1 < cand2:
        ans = cand1
    else:
        ans = cand2
    
    print("YES")
    print(" ".join(map(str, ans)))

if __name__ == "__main__":
    solve()
```
