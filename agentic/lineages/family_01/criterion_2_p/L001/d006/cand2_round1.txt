<STATEMENT>
# Problem B — Quantum State Synchronization

Time limit: 1 s
Memory limit: 256 MB

A quantum computing cluster consists of $n$ qubits, indexed from 1 to $n$. Each qubit must be calibrated to a state index, which must be chosen as either 1 or 2.

The cluster's entanglement topology is defined by a log of $m$ pairwise links between these qubits. To ensure stable operation, the entire cluster must satisfy a global synchronization equation. Specifically, for any link connecting qubit $u$ and qubit $v$ with assigned state indices $s_u$ and $s_v$, the local interference cost is defined as $2(s_u^2 + s_v^2)$, and the target harmonic capacity is defined as $5 s_u s_v$.

The system is considered perfectly synchronized if the global product of the interference costs across all $m$ links is exactly equal to the global product of the harmonic capacities across all $m$ links. That is, a valid calibration must satisfy:

$$ \prod_{i=1}^{m} 2\left( s_{u_i}^2 + s_{v_i}^2 \right) = \prod_{i=1}^{m} 5 s_{u_i} s_{v_i} $$

(Note: If $m=0$, both empty products evaluate to 1 by convention, making any calibration trivially valid.)

Your task is to determine a valid state calibration for all $n$ qubits. If multiple valid calibrations exist, you must output the sequence of state indices that is lexicographically smallest. This means the calibration must prioritize assigning state 1 to qubit 1 if any valid calibration allows it; then, among those valid calibrations, prioritize assigning state 1 to qubit 2, and so on sequentially up to qubit $n$. If no calibration can satisfy the global synchronization equation, you must report the failure.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$, identifying a linked pair of qubits in the topology. Both qubit identifiers $u$ and $v$ are at least 1 and at most $n$.

## Output
If no state calibration can satisfy the synchronization equation, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$) representing the state index assigned to each respective qubit from 1 to $n$. This sequence must be the lexicographically smallest possible valid sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I transformed the global sum-of-squares constraint into a global product equation. The assigned values are still constrained to {1, 2}. The left side of the equation is the product of $2(s_u^2 + s_v^2)$ and the right side is the product of $5s_u s_v$. Because $2(s_u^2 + s_v^2) \le 5s_u s_v$ for all $s_u, s_v \in \{1, 2\}$ with equality holding strictly when $s_u \neq s_v$, the global product condition is satisfied if and only if every link connects a 1 and a 2. This completely masks the bipartite coloring structure behind an algebraic inequality lock, forcing the model to mathematically deduce the per-edge requirement rather than pattern-matching a graph property.
</RATIONALE>
<PRESERVED_ANSWER>
The product equality holds if and only if every linked pair is assigned different values (1 and 2), which is mathematically identical to the seed's sum of squared differences constraint, ensuring all valid assignments and the lexicographically smallest tie-breaker remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in O(n + m) time using Breadth-First Search.
</PRESERVED_CLASS>
