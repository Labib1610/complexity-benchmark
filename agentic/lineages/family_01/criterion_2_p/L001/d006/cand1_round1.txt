<STATEMENT>
# Problem B — Polymer Resonance Tuning

Time limit: 1 s
Memory limit: 256 MB

A synthetic polymer consists of $n$ monomers, indexed from 1 to $n$. A tuning configuration assigns each monomer a resonance level, which must be chosen as either 1 or 2.

The laboratory maintains a record of $m$ covalent bonds between these monomers. To ensure molecular stability, the entire polymer must satisfy a global kinetic constraint. Specifically, the global interaction score of the configuration must be exactly equal to $9m$. This score is calculated across all $m$ recorded bonds by taking 5 times the sum of the resonance levels of the bonded monomers, and subtracting 3 times the product of their resonance levels. That is, a valid configuration must satisfy:

$$ \sum_{i=1}^{m} \left( 5(r_{u_i} + r_{v_i}) - 3(r_{u_i} r_{v_i}) \right) = 9m $$

where $r_{u_i}$ and $r_{v_i}$ are the resonance levels assigned to the two monomers connected by the $i$-th recorded bond.

Your task is to determine a valid tuning configuration for all $n$ monomers. If multiple valid configurations exist, you must output the sequence of resonance levels that is lexicographically smallest. This means the configuration must prioritize assigning level 1 to monomer 1 if any valid configuration allows it; then, among those valid configurations, prioritize assigning level 1 to monomer 2, and so on sequentially up to monomer $n$. If no configuration can achieve a global interaction score of exactly $9m$, you must report the failure.

## Input
The first line contains two integers $n$ and $m$, representing the number of monomers and the number of bonds. The laboratory guarantees at least one monomer is present. Due to equipment limits, the number of monomers will not exceed two hundred thousand. Similarly, the number of recorded bonds can be as low as zero and will not exceed two hundred thousand.
Each of the following $m$ lines contains two integers $u$ and $v$, identifying a bonded pair of monomers in the record. Both monomer identifiers $u$ and $v$ are at least 1 and at most $n$.

## Output
If no tuning configuration can satisfy the global kinetic constraint, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $r_1, r_2, \dots, r_n$ (where each $r_i \in \{1, 2\}$) representing the resonance level assigned to each respective monomer from 1 to $n$. This sequence must be the lexicographically smallest possible valid sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The problem was completely reframed by replacing the sum of squared differences with a custom asymmetric polynomial equation: $5(x+y) - 3xy$. This polynomial evaluates to 7 for (1,1), 8 for (2,2), and 9 for (1,2) or (2,1). By requiring the global sum over $m$ bonds to equal exactly $9m$, the model must deduce that every single bond must achieve the absolute maximum of 9, forcing the endpoints to be different. This forces a genuine algebraic reasoning step to uncover the bipartite coloring requirement, defeating pattern-matching on the familiar $(x-y)^2$ constraint. The bounds were also rewritten into prose using the S07 strategy.
</RATIONALE>
<PRESERVED_ANSWER>
Because the maximum possible value of $5(r_u+r_v) - 3r_ur_v$ for $r \in \{1, 2\}$ is 9 (achieved only when $r_u \neq r_v$), a sum of exactly $9m$ over $m$ bonds is only mathematically possible if every bond has different endpoint values, preserving the exact same valid configurations and lexicographical priority as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in $O(n+m)$ time using Breadth-First Search, keeping it in the polynomial time class P.
</PRESERVED_CLASS>
