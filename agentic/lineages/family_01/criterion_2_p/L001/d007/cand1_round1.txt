<METHOD_DESCRIPTION>Replaces a local edge-wise polynomial evaluation with a vertex-wise linear equation that holds true for a trivial continuous solution (r=1.5), but whose discrete domain bounds (r in {1, 2}) strictly force the bipartite property. This defeats pattern-matching models because evaluating discrete combinations on a vertex-wise sum of arbitrary degree is structurally harder than on a single edge, and generic linear solvers will fail due to the trivial continuous solution not being valid.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Polymer Resonance Tuning

Time limit: 1 s
Memory limit: 256 MB

A synthetic polymer consists of $n$ monomers, indexed from 1 to $n$. A tuning configuration assigns each monomer a resonance level $r_i$, which must be chosen as either 1 or 2.

The laboratory maintains a record of $m$ covalent bonds between these monomers. To ensure molecular stability, the polymer must achieve a state of perfect resonance balance. 

In this model, each bond acts as a bidirectional resonance channel. For any monomer $i$, let $d_i$ be the number of bond endpoints attached to it (each of the $m$ recorded bonds provides exactly two endpoints, one to each of the connected monomers). The total incoming resonance pressure on monomer $i$ is the sum of the resonance levels of the monomers at the other end of each of its $d_i$ endpoints. 

The global kinetic constraint dictates that for *every* monomer $i$ in the polymer, its total incoming resonance pressure must be exactly equal to:
$$ d_i \times (3 - r_i) $$

Your task is to determine a valid tuning configuration for all $n$ monomers. If multiple valid configurations exist, you must output the sequence of resonance levels that is lexicographically smallest. This means the configuration must prioritize assigning level 1 to monomer 1 if any valid configuration allows it; then, among those valid configurations, prioritize assigning level 1 to monomer 2, and so on sequentially up to monomer $n$. If no configuration can satisfy the stability constraint, you must report the failure.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$, identifying a bonded pair of monomers in the record. Both monomer identifiers $u$ and $v$ are at least 1 and at most $n$.

## Output
If no tuning configuration can satisfy the stability constraint, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $r_1, r_2, \dots, r_n$ (where each $r_i \in \{1, 2\}$) representing the resonance level assigned to each respective monomer from 1 to $n$. This sequence must be the lexicographically smallest possible valid sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The problem was rewritten to replace the global polynomial sum with a per-vertex linear equation. While the equation has a trivial continuous solution ($r_i = 1.5$), satisfying it with discrete values $r_i \in \{1, 2\}$ requires the sum of a vertex's neighbors to exactly equal its theoretical maximum or minimum based on its own state. This strictly forces opposite states across every bond (bipartiteness). Models must now deduce this structural property by analyzing the domain bounds of the vertex-wise sum rather than trivially evaluating three discrete cases of a single edge's polynomial.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $\sum r_{neighbors} = d_i(3 - r_i)$ with $r_i \in \{1, 2\}$ is mathematically equivalent to requiring $r_u \neq r_v$ for all edges, exactly matching the valid configurations and lexicographical tie-breaking of the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The valid configurations still correspond exactly to valid 2-colorings of the graph, which can be found or proven impossible in $O(n+m)$ time using Breadth-First Search.
</PRESERVED_CLASS>
