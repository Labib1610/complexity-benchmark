<METHOD_NAME>
Number-Theoretic Domain Masking
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the easily-recognized algebraic polynomial constraint with a number-theoretic function (divisor count of LCM) over a discrete domain. This defeats models that rely on symbolic simplification or pattern-matching polynomials to bipartite graphs, forcing them to explicitly evaluate the function's domain to discover the underlying 2-coloring structure.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<STATEMENT>
# Problem B — Polymer Resonance Tuning

Time limit: 1 s
Memory limit: 256 MB

A synthetic polymer consists of $n$ monomers, indexed from 1 to $n$. A tuning configuration assigns each monomer a resonance level $r_i$, which must be chosen as either 1 or 2.

To evaluate the configuration, each resonance level is mapped to a characteristic frequency $f(r)$: level 1 corresponds to $10\text{ THz}$ (so $f(1) = 10$), and level 2 corresponds to $15\text{ THz}$ (so $f(2) = 15$).

The laboratory maintains a record of $m$ covalent bonds between these monomers. For any bond connecting monomers $u$ and $v$ with resonance levels $r_u$ and $r_v$, its interference score is calculated as $d(\operatorname{lcm}(f(r_u), f(r_v)))$, where $\operatorname{lcm}(x, y)$ is the least common multiple of $x$ and $y$, and $d(x)$ is the total number of positive integer divisors of $x$.

To ensure molecular stability, the entire polymer must satisfy a global kinetic constraint: the total interference score, summed across all $m$ recorded bonds, must be exactly $8m$. That is, a valid configuration must satisfy:

$$ \sum_{i=1}^{m} d(\operatorname{lcm}(f(r_{u_i}), f(r_{v_i}))) = 8m $$

where $u_i$ and $v_i$ are the two monomers connected by the $i$-th recorded bond.

Your task is to determine a valid tuning configuration for all $n$ monomers. If multiple valid configurations exist, you must output the sequence of resonance levels that is lexicographically smallest. This means the configuration must prioritize assigning level 1 to monomer 1 if any valid configuration allows it; then, among those valid configurations, prioritize assigning level 1 to monomer 2, and so on sequentially up to monomer $n$. If no configuration can achieve a total interference score of exactly $8m$, you must report the failure.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$, identifying a bonded pair of monomers in the record. Both monomer identifiers $u$ and $v$ are at least 1 and at most $n$.

## Output
If no tuning configuration can satisfy the stability constraint, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $r_1, r_2, \dots, r_n$ (where each $r_i \in \{1, 2\}$) representing the resonance level assigned to each respective monomer from 1 to $n$. This sequence must be the lexicographically smallest possible valid sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The original problem used a simple polynomial $3(r_u + r_v) - 2r_u r_v = 5$ to encode the condition $r_u \neq r_v$. Models easily recognized this algebraic structure and mapped it to bipartite graph coloring. By changing the constraint to a number-theoretic function (the divisor count of the LCM of mapped frequencies), the algebraic shortcut is removed. Models must now genuinely evaluate the discrete domain ($d(\operatorname{lcm}(10, 10)) = 4$, $d(\operatorname{lcm}(15, 15)) = 4$, $d(\operatorname{lcm}(10, 15)) = 8$) to deduce that achieving the maximum score of 8 per bond requires alternating resonance levels.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical condition remains identical because the maximum possible score for any single bond is 8 (achieved only when $r_u \neq r_v$), meaning the sum over $m$ bonds equals $8m$ if and only if every single bond connects a 1 and a 2, exactly preserving the original bipartite constraint and tie-breaking rules.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem is still determining if the graph formed by the bonds is bipartite (2-colorable) and finding the lexicographically smallest valid coloring, which remains solvable in $O(n+m)$ time using BFS/DFS.
</PRESERVED_CLASS>
