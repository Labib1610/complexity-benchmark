**Solution Explanation**

For a link `{u , v}` we have to choose a polarity `Duv ∈ {‑1 , 1}`.
For a server `i` its type `Ti ∈ {1 , 2}` must satisfy  

```
Ti = (3 + Di,j) / 2          (1)
```

for **every** neighbour `j`.

--------------------------------------------------------------------

#### 1.   What does (1) mean ?

```
Ti = 1  →  Di,j = -1
Ti = 2  →  Di,j =  1
```

So the polarity *leaving* a vertex is completely determined by the
type of this vertex, it does **not** depend on the neighbour.

For the same edge we also have `Dvj,i = -Duv,i`.  
Using the two formulas above:

```
2·Tj – 3 = -(2·Ti – 3)
⇔ Ti + Tj = 3
```

Therefore every edge must connect a vertex of type `1` with a vertex of
type `2`.  
The whole graph has to be **bipartite** and the two colour classes are
exactly the two types.

--------------------------------------------------------------------

#### 2.   When is a configuration possible ?

*The answer is “YES” iff the given graph is bipartite.*

During a BFS/DFS we colour the vertices `0 / 1`.  
If we ever meet an already coloured vertex with the same colour as the
current one, the graph is not bipartite → answer “NO”.

--------------------------------------------------------------------

#### 3.   Lexicographically smallest assignment

Different components are independent – we may swap the meaning of the
two colours inside each component.
The lexicographically smallest whole sequence is obtained by the
following greedy rule:

*For every connected component, give type `1` to the colour class that
contains the smallest‑indexed vertex of this component.*

Why is it optimal?
The first position where two global assignments can differ belongs to the
component that contains the smallest index among all still‑undecided
components.  
Choosing type `1` for that vertex makes the whole sequence smaller,
and later components cannot influence earlier positions.

Implementation:

```
for each component:
        collect its vertices, remember the smallest index s
        during BFS we already have a colour (0/1) for every vertex
        if colour[s] == 0:   colour 0 → type 1, colour 1 → type 2
        else:                colour 1 → type 1, colour 0 → type 2
```

Isolated vertices are a component of size `1`; the rule gives them
type `1`.

--------------------------------------------------------------------

#### 4.   Algorithm
```
read n, m
build adjacency list
answer = array of size n (filled later)
visited = [False]*n
colour  = [0]*n          # 0 or 1 inside a component

for v = 0 … n-1:
        if not visited[v]:
                BFS/DFS from v
                during search:
                        assign colours, check bipartite
                        store all vertices of this component
                if conflict → print "NO" and exit
                s = smallest vertex index in this component
                if colour[s] == 0:
                        map 0 → 1 , 1 → 2
                else:
                        map 0 → 2 , 1 → 1
                write mapped types into answer[]
print "YES"
print answer (1‑based indices)
```

`n, m ≤ 2·10⁵`, the BFS touches each vertex and edge once → `O(n+m)`
time, `O(n+m)` memory.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints “NO” iff no valid configuration exists,
otherwise prints “YES” and the lexicographically smallest valid type
assignment.

---

##### Lemma 1  
For any edge `{u,v}` a pair of types `(Tu,Tv)` can satisfy the required
equations **iff** `Tu + Tv = 3` (i.e. one is `1`, the other `2`).

**Proof.**  
From (1) we have `Duv = 2·Tu – 3` and `Dvu = 2·Tv – 3`.  
Because `Dvu = -Duv` we get `2·Tv – 3 = -(2·Tu – 3)`,
which simplifies to `Tu + Tv = 3`. The converse direction is immediate
by setting the polarities accordingly. ∎



##### Lemma 2  
A type assignment for all vertices exists **iff** the graph is bipartite.

**Proof.**  
*If* the graph is bipartite, colour its two parts `A,B`.  
Assign type `1` to all vertices of `A` and type `2` to all vertices of
`B`. Every edge connects a vertex of `A` with a vertex of `B`,
hence by Lemma&nbsp;1 the condition holds.

*Only‑if*: suppose a type assignment exists.
By Lemma&nbsp;1 each edge connects vertices of different types,
so the set of vertices of type `1` and the set of type `2` form a
bipartition of the graph. ∎



##### Lemma 3  
During the BFS of a component the algorithm detects a conflict
iff the component is not bipartite.

**Proof.**  
BFS colours a vertex with `0` or `1` and forces all neighbours to the
opposite colour. This is exactly the standard 2‑colouring test.
If an edge joins two vertices with the same colour, an odd cycle exists,
hence the component is not bipartite, and the algorithm reports a
conflict. Conversely, if the component is not bipartite, it contains an
odd cycle, and the BFS will eventually try to assign the same colour
to both ends of an edge, detecting the conflict. ∎



##### Lemma 4  
For a bipartite component the algorithm assigns type `1` to the colour
class that contains the smallest‑indexed vertex of the component.

**Proof.**  
The algorithm records the smallest index `s`.  
If `colour[s] == 0` it maps colour `0 → 1`, otherwise it swaps the mapping.
Thus exactly the colour class of `s` receives type `1`. ∎



##### Lemma 5  
The whole vector produced by the algorithm is the lexicographically
smallest among all valid assignments.

**Proof.**  
Consider the components ordered by their smallest vertex index.
Let `C` be the first component (smallest such index `s`).  
All vertices with index `< s` belong to earlier components, which are
identical in every assignment because they are already fixed.
By Lemma&nbsp;4 the algorithm gives type `1` to `s`. Any other valid
assignment must give either `1` or `2` to `s`. If it gives `2`, the
resulting vector is lexicographically larger at position `s`.  
If it also gives `1`, the two assignments coincide on `C`.  
Proceeding inductively over the components shows that no other valid
assignment can be lexicographically smaller. ∎



##### Lemma 6  
If the algorithm prints “YES”, the printed types satisfy all required
equations.

**Proof.**  
By Lemma&nbsp;3 every component is bipartite, therefore the whole graph
is bipartite. The algorithm assigns opposite types to the two colour
classes of each component (Lemma&nbsp;4). Hence every edge connects a
type‑`1` vertex with a type‑`2` vertex, and by Lemma&nbsp;1 the equation
holds for both ends. ∎



##### Theorem  
The algorithm outputs  

* “NO” **iff** no valid configuration exists;  

* otherwise “YES” and the lexicographically smallest valid type
  assignment.

**Proof.**  

*If* the algorithm outputs “NO”, it found a conflict in some component.
By Lemma&nbsp;3 that component is not bipartite, thus by Lemma&nbsp;2
no configuration exists.

*If* a configuration exists, the graph is bipartite (Lemma&nbsp;2), so
no conflict is found and the algorithm outputs “YES”.  
By Lemma&nbsp;6 the produced assignment is valid, and by Lemma&nbsp;5
it is the lexicographically smallest one. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis

*Time* : each vertex and each edge is processed once → `O(n + m)`.

*Memory*: adjacency list `O(n + m)`, plus a few `O(n)` arrays → `O(n + m)`.

Both satisfy the limits.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    visited = [False] * n
    colour = [0] * n          # 0 / 1 inside component
    answer = [0] * n

    from collections import deque

    for start in range(n):
        if visited[start]:
            continue
        # BFS this component
        q = deque([start])
        visited[start] = True
        colour[start] = 0
        comp = [start]
        ok = True
        while q:
            v = q.popleft()
            cv = colour[v]
            for to in adj[v]:
                if not visited[to]:
                    visited[to] = True
                    colour[to] = cv ^ 1
                    q.append(to)
                    comp.append(to)
                else:
                    if colour[to] == cv:
                        ok = False
                        break
            if not ok:
                break
        if not ok:
            print("NO")
            return
        # decide mapping for this component
        s = min(comp)          # smallest index
        if colour[s] == 0:
            # colour 0 -> type 1, colour 1 -> type 2
            for v in comp:
                answer[v] = 1 if colour[v] == 0 else 2
        else:
            # swap
            for v in comp:
                answer[v] = 1 if colour[v] == 1 else 2

    # all components processed
    print("YES")
    print(' '.join(map(str, answer)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input‑output format.
