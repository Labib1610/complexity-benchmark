We can model each monomer as a node in a graph, and each bond as an edge.  
The condition that two intervals intersect at exactly one point means:

- If monomer `u` is assigned interval `[0,1]` (choice 1) and monomer `v` is assigned `[1,2]` (choice 2), they intersect at exactly `1`.
- If both are assigned the same interval, they overlap over a range of length 1, which is invalid.

So the problem reduces to:  
Assign each node a value in `{1, 2}` such that every edge connects nodes with different values.  
This is exactly a **bipartite graph** check. If the graph is not bipartite, output `NO`.  
If it is bipartite, we need the lexicographically smallest assignment.

To get the lexicographically smallest assignment, we can do a BFS/DFS coloring, but with a greedy priority:  
We try to assign `1` to node 1 if possible, then node 2, etc.  
This can be done by processing nodes in order and if a node is uncolored, assign it `1` and BFS/DFS to color its component consistently.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start):
    q = deque([start])
    color[start] = 0
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = color[u] ^ 1
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        # Try to assign 0 (choice 1) to this node
        # But we must check if assigning 0 leads to conflict
        # We'll do a temporary BFS with color[i]=0
        # If conflict, try color[i]=1
        # Since we process in order, this gives lexicographically smallest
        tmp_color = color[:]
        tmp_color[i] = 0
        q = deque([i])
        ok = True
        while q:
            u = q.popleft()
            for v in adj[u]:
                if tmp_color[v] == -1:
                    tmp_color[v] = tmp_color[u] ^ 1
                    q.append(v)
                elif tmp_color[v] == tmp_color[u]:
                    ok = False
                    break
            if not ok:
                break
        if ok:
            color = tmp_color
        else:
            # assign 1
            color[i] = 1
            q = deque([i])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = color[u] ^ 1
                        q.append(v)
                    elif color[v] == color[u]:
                        print("NO")
                        sys.exit()

# If we reach here, graph is bipartite
print("YES")
print(' '.join(str(c + 1) for c in color))
```
