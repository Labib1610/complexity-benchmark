<METHOD_DESCRIPTION>
The constraint that two connected nodes must have different values (1 and 2) is disguised as a linear algebra property. Each link defines a 2x2 symmetric matrix using the state values of its endpoints. The requirement that the matrix be invertible (non-zero determinant) mathematically simplifies to the difference of their squares being non-zero, which for values in {1, 2} strictly enforces that the two states must be different. This forces models to perform algebraic reasoning to deduce the bipartite coloring structure.
</METHOD_DESCRIPTION>

# Problem B — Coupling Matrix Tuning

Time limit: 1 s
Memory limit: 256 MB

A system consists of $n$ signal processors, indexed from 1 to $n$. A tuning configuration assigns each processor a specific state value. For each processor, you must choose its state value to be either the integer 1 or the integer 2.

The laboratory maintains a record of $m$ data links between these processors. To avoid resonance, the system must satisfy a local stability condition for every link: for any recorded link connecting processor $u$ and processor $v$, we define the link's coupling matrix as the $2 \times 2$ matrix
$$ \begin{pmatrix} r_u & r_v \\ r_v & r_u \end{pmatrix} $$
where $r_u$ and $r_v$ are the state values assigned to processors $u$ and $v$. The stability condition requires that this coupling matrix must be invertible (i.e., its determinant must not be zero). Every recorded link must strictly satisfy this condition without exception.

Your task is to determine a valid tuning configuration for all $n$ processors. If multiple valid configurations exist, you must output the one that produces a sequence of $n$ integers $r_1, r_2, \dots, r_n$ (where each $r_i \in \{1, 2\}$) that is lexicographically smallest among all valid full sequences. This means the globally valid sequence must prioritize assigning 1 to processor 1 if possible; then prioritize assigning 1 to processor 2, and so on sequentially.

If no configuration can satisfy the stability constraint for all $m$ recorded links, you must report the failure.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$, identifying a linked pair of processors in the record. Both identifiers $u$ and $v$ are at least 1 and at most $n$.

## Output
If no tuning configuration can satisfy the stability constraint, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $r_1, r_2, \dots, r_n$ (where each $r_i \in \{1, 2\}$) representing the state value assigned to each respective processor from 1 to $n$. This sequence must be the lexicographically smallest possible valid sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Removed the interval intersection constraint that directly revealed an XOR/bipartite relationship. Replaced it with a 2x2 matrix determinant condition. Models must now algebraically evaluate the determinant ($r_u^2 - r_v^2 \neq 0$) and realize that since the domain is {1, 2}, this strictly requires $r_u \neq r_v$, forcing them to deduce the bipartite graph structure rather than pattern-matching it.
</RATIONALE>
<PRESERVED_ANSWER>
The determinant of the coupling matrix is $r_u^2 - r_v^2$; for $r_u, r_v \in \{1, 2\}$, this is non-zero if and only if $r_u \neq r_v$, which is exactly equivalent to the seed's condition that the intervals intersect at exactly one point, preserving all valid configurations and the lexicographically smallest answer.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem remains finding a valid 2-coloring of a graph and selecting the lexicographically first valid assignment, which is solvable in $O(n + m)$ using Breadth-First Search, keeping it firmly in P.
</PRESERVED_CLASS>
