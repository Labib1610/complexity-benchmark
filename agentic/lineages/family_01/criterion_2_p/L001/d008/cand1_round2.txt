This transforms the bipartite reduction equation into a continuous-looking trigonometric constraint, forcing models to symbolically evaluate the cosine parity rather than pattern-matching standard directed-edge equations.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Phase Synchronizers

Time limit: 1 s
Memory limit: 256 MB

You are designing a synchronization grid for a quantum computing cluster. The grid consists of $n$ processing units and $m$ phase-coupling links. Each link connects a specific pair of processing units.

To stabilize the grid, each processing unit must be assigned an operating mode $M \in \{1, 2\}$. 

Additionally, each phase-coupling link must be calibrated by assigning it a relative phase shift. For any link connecting unit $u$ and unit $v$, the phase shift evaluated from $u$ to $v$, denoted $\theta_{u,v}$, must be chosen from the set $\{0, \pi\}$. By the laws of wave mechanics, the phase shift of that same link evaluated in the reverse direction is $\theta_{v,u} = (\theta_{u,v} + \pi) \bmod 2\pi$.

A grid configuration is considered stable if it is possible to assign the phase shifts such that for every processing unit $i$, its assigned mode $M_i$ satisfies the following wave equation for every link connecting unit $i$ to a unit $j$:
$$M_i = \frac{3 + \cos(\theta_{i,j})}{2}$$
where $\theta_{i,j}$ is the phase shift of that specific link evaluated from $i$ to $j$. 

If a unit has no links connected to it, the wave equation is vacuously satisfied for both operating modes, but you must still assign it exactly one mode.

You must determine if there is a stable grid configuration. If there are multiple valid mode assignments, you must choose the assignment that yields the lexicographically smallest sequence of modes when listed in order from unit $1$ to unit $n$.

## Input
The first line of the input contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — representing a phase-coupling link between unit $u$ and unit $v$.

## Output
If there is no stable grid configuration, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers separated by spaces, where the $i$-th integer is the mode ($1$ or $2$) assigned to the $i$-th unit, representing the lexicographically smallest stable assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The discrete polarity variables $D_{u,v} \in \{1, -1\}$ have been replaced with phase angles $\theta_{u,v} \in \{0, \pi\}$ and a cosine function. This preserves the exact mathematical constraints of the bipartite reduction but masks the standard graph-theory formulation behind continuous-looking trigonometric operations, forcing models to symbolically evaluate the parity of the cosine function.
</RATIONALE>
<PRESERVED_ANSWER>
Because $\cos(0) = 1$ and $\cos(\pi) = -1$, the term $\cos(\theta_{i,j})$ perfectly maps to the original $D_{i,j} \in \{1, -1\}$ variable, preserving all valid assignments exactly.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains mathematically equivalent to checking bipartiteness and finding the lexicographically first valid 2-coloring, which is solvable in $O(n+m)$ time using standard graph traversal.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the modulo operation or trigonometric function as requiring floating-point arithmetic, though the discrete constraint $\theta_{u,v} \in \{0, \pi\}$ makes it strictly integer-equivalent.
</RISK>
