<STATEMENT>
# Problem B — Quantum Entanglement States

Time limit: 1 s   Memory limit: 256 MB

A quantum computer consists of $n$ qubits. To initialize the system, the control software must assign an energy state to each qubit. The hardware requires that each assigned energy state is a positive real root of the equation $x^3 - 3x^2 + 2x = 0$.

The system relies on $m$ entanglement links, each connecting a specific pair of qubits. For the system to remain stable, the energy states of any two qubits connected by a link must satisfy a strict conservation rule: the sum of the squares of their energy states must equal exactly $5$. 

You need to determine if there is a valid initialization that satisfies all entanglement links. If there are multiple valid ways to assign the energy states across the system, the control software must select the one that yields the lexicographically smallest sequence of states when listed in order from qubit $1$ to qubit $n$.

## Input
The first line of the input contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — an entanglement link between qubit $u$ and qubit $v$.

## Output
If there is no way to assign the energy states without violating the entanglement requirements, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers separated by spaces, where the $i$-th integer is the energy state ($1$ or $2$) assigned to the $i$-th qubit, representing the lexicographically smallest valid assignment ordered by qubit indices from $1$ to $n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit {1,2} domain and product-equals-2 condition with positive roots of a cubic equation ($x=1, x=2$) and a sum-of-squares constraint ($s_u^2 + s_v^2 = 5$). This forces the model to algebraically deduce the allowed values and the fact that adjacent nodes must have different states, bypassing surface-level pattern matching for 2-coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The positive roots of $x^3 - 3x^2 + 2x = 0$ are exactly 1 and 2, and the condition $s_u^2 + s_v^2 = 5$ on these values exactly enforces that one is 1 and the other is 2, preserving all valid assignments from the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in $O(n+m)$ time using BFS or DFS.
</PRESERVED_CLASS>
