# Problem B — Satellite Constellation

Time limit: 1 s   Memory limit: 256 MB

A space agency operates a constellation of $n$ satellites. To calibrate the communication array for a new mission, the control system must assign a telemetry frequency $f_i$ to each satellite $i$. The hardware only supports frequencies that are strictly positive real roots of the polynomial equation $f^3 - 3f^2 + 2f = 0$.

The constellation relies on $m$ cross-link communication channels. Each channel links a specific pair of satellites $u$ and $v$. Due to phase interference, a cross-link between satellite $u$ and satellite $v$ is only stable if their assigned frequencies, $f_u$ and $f_v$, allow the following system of equations to have at least one real solution for $(x, y)$ such that $(x, y) \neq (0, 0)$:

$f_u \cdot x + y = 0$  
$2 \cdot x + f_v \cdot y = 0$

You need to determine if there is a valid frequency calibration that stabilizes all $m$ cross-link channels simultaneously. If there are multiple valid ways to assign the frequencies across the constellation, the control system must select the one that yields the lexicographically smallest sequence of frequencies when listed in order from satellite $1$ to satellite $n$.

## Input
The first line of the input contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a cross-link channel between satellite $u$ and satellite $v$.

## Output
If there is no way to assign the frequencies without destabilizing at least one cross-link, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers separated by spaces, where the $i$-th integer is the frequency assigned to the $i$-th satellite, representing the lexicographically smallest valid assignment ordered by satellite indices from $1$ to $n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

The problem's domain and constraints have been entirely replaced with mathematically equivalent algebraic conditions. Instead of explicitly choosing from {1, 2}, frequencies must be strictly positive roots of $f^3 - 3f^2 + 2f = 0$ (which evaluates exactly to 1 and 2). Instead of explicitly stating the product must be 2, the edge constraint requires a 2x2 homogeneous linear system to have non-trivial solutions, which occurs if and only if its determinant is zero ($f_u f_v - 2 = 0$). This forces the model to perform algebraic deduction before it can recognize the underlying 2-coloring graph structure.
</RATIONALE>
