Looking at this problem, I need to find positive integers where the number of divisors equals the number itself, and pairs connected by edges must have cubes summing to 9.

Let me find such numbers:
- 1: divisors = {1}, count = 1 ✓
- 2: divisors = {1,2}, count = 2 ✓
- 3: divisors = {1,3}, count = 2 ✗
- 4: divisors = {1,2,4}, count = 3 ✗
- 6: divisors = {1,2,3,6}, count = 4 ✗
- 8: divisors = {1,2,4,8}, count = 4 ✗
- 9: divisors = {1,3,9}, count = 3 ✗
- 12: divisors = {1,2,3,4,6,12}, count = 6 ✗
- 24: divisors = {1,2,3,4,6,8,12,24}, count = 8 ✗
- 36: divisors = {1,2,3,4,6,9,12,18,36}, count = 9 ✗
- 48: divisors = {1,2,3,4,6,8,12,16,24,48}, count = 10 ✗

For larger numbers, the divisor count grows much slower than the number itself. The only valid values are 1 and 2.

Check: 1³ + 2³ = 1 + 8 = 9 ✓

So this is a 2-coloring problem where connected dishes must have different values (1 and 2). For lexicographically smallest, I want to assign 1 where possible.

For bipartite graphs, I do BFS from each unvisited node, assigning 1 to the start. If a node is already visited, I check consistency. If inconsistent, output NO.

For lexicographically smallest: when processing a node, if unvisited, assign it 1 (the smaller value). This greedy approach works because in BFS, earlier nodes get smaller values, and the constraint only requires neighbors to differ.

Wait, but I need to be careful. If I process nodes in order 1 to n, and for each unvisited node I start BFS assigning it 1, this gives lexicographically smallest because:
- Node 1 gets 1 (smallest possible)
- Node 2: if connected to node 1, must be 2; otherwise gets 1
- etc.

This is exactly what BFS from each unvisited node in order 1..n does.

```python
import sys
from collections import deque

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * (n+1)
    
    for start in range(1, n+1):
        if color[start] == 0:
            color[start] = 1
            q = deque([start])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == 0:
                        color[v] = 3 - color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        print("NO")
                        return
    
    print("YES")
    print(' '.join(str(color[i]) for i in range(1, n+1)))

solve()
```
