We need to find positive integers \( x \) such that the number of positive divisors \( d(x) = x \).  
The only known positive integers satisfying this are \( 1 \) and \( 2 \):

- \( d(1) = 1 \)
- \( d(2) = 2 \)

No other positive integer satisfies \( d(x) = x \).  

So each dish can only be assigned value \( 1 \) or \( 2 \).

The condition for each edge \((u, v)\) is:

\[
a_u^3 + a_v^3 = 9
\]

Since \( a_u, a_v \in \{1, 2\} \):

- \( 1^3 + 2^3 = 1 + 8 = 9 \) → valid
- \( 2^3 + 1^3 = 9 \) → valid
- \( 1^3 + 1^3 = 2 \) → invalid
- \( 2^3 + 2^3 = 16 \) → invalid

So each edge must connect a 1 and a 2.  
This means the graph must be bipartite, with one part assigned 1 and the other 2.

We need the lexicographically smallest assignment.  
We can do a BFS/DFS coloring, starting from node 1 with value 1, and propagate alternating values.  
If a conflict occurs, output `NO`.  
If multiple components exist, we start each new component with value 1 to keep lexicographic order minimal.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n  # -1 unassigned, 0 -> value 1, 1 -> value 2

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 0
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
print(' '.join(str(c + 1) for c in color))
```
