<METHOD_DESCRIPTION>Replaces explicit sets and parity/product constraints with mathematically equivalent algebraic conditions (divisor counting and sum of cubes) to prevent pattern matching to 2-coloring and bipartiteness.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Interferometry Array

Time limit: 1 s   Memory limit: 256 MB

An observatory operates an interferometry array consisting of $n$ radio telescope dishes. To calibrate the array for a new observation run, the control system must assign a phase multiplier to each dish. The hardware only supports phase multipliers that are strictly positive integers $k$ such that the total count of distinct positive integers dividing $k$ evenly is exactly equal to $k$.

The array relies on $m$ baseline connections, each linking a specific pair of dishes that act as a single synthetic aperture. For the interferometry to function correctly across a baseline, the signals from the two linked dishes must be offset. The control system enforces this by requiring that for any two dishes connected by a baseline, the sum of the cubes of their assigned phase multipliers is exactly $9$. 

You need to determine if there is a valid calibration that satisfies all baseline connections. If there are multiple valid ways to assign the phase multipliers across the array, the control system must select the one that yields the lexicographically smallest sequence of multipliers when listed in order from dish $1$ to dish $n$.

## Input
The first line of the input contains two integers $n$ and $m$. The system architecture limits the number of dishes $n$ to a maximum of $200,000$ (with at least $1$ dish required), and the number of baselines $m$ can range from $0$ up to $200,000$.
Each of the next $m$ lines contains two integers $u$ and $v$ — a baseline connection between dish $u$ and dish $v$.

## Output
If there is no way to assign the phase multipliers without violating the baseline requirements, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers separated by spaces, where the $i$-th integer is the phase multiplier assigned to the $i$-th dish, representing the lexicographically smallest valid assignment ordered by dish indices from $1$ to $n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I removed the direct references to "dividing 2" and "product is 2", which strongly suggested the values 1 and 2 and a bipartite coloring constraint. Instead, I defined the allowed values as positive integers equalling their own divisor count, and the edge constraint as a sum of cubes equalling 9. This forces the model to mathematically deduce the domain {1, 2} and the mutual exclusion condition rather than relying on surface-level pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The only positive integers $k$ with exactly $k$ divisors are 1 and 2, and the only positive integer solutions to $x^3 + y^3 = 9$ are $\{1, 2\}$, which exactly preserves the original domain $\{1, 2\}$ and the opposite-value edge constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a valid assignment of two values to vertices such that adjacent vertices have different values (2-coloring), which remains solvable in $O(n+m)$ time using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "total count of distinct positive integers dividing $k$ evenly" or fail to deduce the exact set $\{1, 2\}$, leading to incorrect assumptions about the domain.
</RISK>
