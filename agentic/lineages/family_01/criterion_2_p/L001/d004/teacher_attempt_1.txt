# Problem B — Museum Calibration

Time limit: 1 s   Memory limit: 256 MB

A museum curator is setting up an exhibition of historical artifacts, sequentially cataloged from 1 to $n$. The museum can accommodate between $1$ and $200,000$ artifacts on display, and the curator's log will register anywhere from $0$ up to $200,000$ sensitive circuit connections.

Each artifact must be assigned a polarity setting, which is restricted to either 1 or 2. During the planning phase, the curator identified $m$ specific pairs of artifacts that are wired to the same sensitive power circuit. To maintain electrical stability and prevent surges, safety guidelines dictate that any two artifacts sharing a circuit must be configured to differing polarity settings. If they are assigned identical settings, the circuit will overload.

Your task is to assign a valid polarity setting to each artifact. If it is impossible to satisfy all the conditions without overloading a circuit, you must report this. In cases where multiple valid assignments exist, the museum's automated system requires you to output the sequence of settings that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$, representing the number of artifacts and the number of circuit-sharing pairs, respectively (the limits for these values are defined by the museum's capacity and log size).
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that artifact $u$ and artifact $v$ share a circuit.

## Output
If no valid assignment is possible, output a single line containing `NO`.
Otherwise, output a line containing `YES`. On the following line, output $n$ space-separated integers $h_1, h_2, \dots, h_n$ (where each $h_i \in \{1, 2\}$) representing the assigned polarity setting for each artifact. This sequence must be the lexicographically smallest among all valid assignments.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
