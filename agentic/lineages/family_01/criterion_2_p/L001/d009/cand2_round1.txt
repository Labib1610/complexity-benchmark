<METHOD_NAME>Laplacian Quadratic Form Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the local pairwise inequality constraint (x != y) with a global structural constraint equivalent to the Laplacian quadratic form of the graph. By requiring the sum of "local synchronization scores" to equal exactly m, the problem mathematically demands that every edge connects different modes, because the maximum possible value of the sum of squared differences on edges is m. This forces the LLM to either perform a non-trivial algebraic reduction over the entire graph to discover the bipartiteness, or fail by attempting to simulate or solve the system directly.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Signal Pipeline Synchronization

Time limit: 1 s   Memory limit: 256 MB

You are configuring a data processing pipeline consisting of $n$ transformation filters. You must configure each filter into exactly one of two operational modes, represented by the integer $1$ or $2$. Let $c_i \in \{1, 2\}$ be the mode assigned to filter $i$.

The pipeline design includes $m$ synchronization pairs. Each pair specifies two filters $u$ and $v$ that are linked. 

To evaluate the stability of a configuration, we define the **local synchronization score**, $K_i$, for each filter $i$ as follows:
$$K_i = c_i \times (c_i \cdot d_i - \Sigma_i)$$
where:
* $d_i$ is the number of synchronization pairs that include filter $i$.
* $\Sigma_i$ is the sum of the modes of the other filters in those pairs. Specifically, for each of the $d_i$ synchronization pairs containing filter $i$ and some filter $j$, we add $c_j$ to the sum $\Sigma_i$. (If a filter is not part of any pair, $d_i = 0$ and $\Sigma_i = 0$).

A configuration of modes for all $n$ filters is valid if and only if the total sum of the local synchronization scores across all $n$ filters is exactly $m$. That is:
$$\sum_{i=1}^n K_i = m$$

You must determine if there is a valid configuration of modes for all $n$ filters. If there are multiple valid configurations, you must choose the one that yields the lexicographically smallest sequence of modes (where each mode is represented as $1$ or $2$) when listed in order from filter $1$ to filter $n$.

## Input
The first line of the input contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — indicating a synchronization pair between filter $u$ and filter $v$.

## Output
If there is no valid configuration, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers separated by spaces, where the $i$-th integer is the mode ($1$ or $2$) assigned to the $i$-th filter, representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit local constraint (f_u(f_v(x)) = -x) was replaced with a global sum of local synchronization scores. Mathematically, the sum of these scores is exactly the Laplacian quadratic form $\sum_{(u,v)} (c_u - c_v)^2$. Since $c_i \in \{1, 2\}$, the maximum possible value of this sum is $m$, which is achieved if and only if $c_u \neq c_v$ for every pair. This forces models to algebraically prove this global maximum property before they can recognize the underlying graph bipartiteness, defeating simple pattern matching on local pair constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The total sum evaluates to exactly the number of pairs $m$ if and only if every pair is assigned different modes, which is mathematically identical to the original requirement that linked filters have opposite modes.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The valid configurations are exactly the valid 2-colorings of the graph, meaning the problem is still solvable in $O(n+m)$ time using BFS/DFS to check bipartiteness and assign the lexicographically smallest colors.
</PRESERVED_CLASS>
