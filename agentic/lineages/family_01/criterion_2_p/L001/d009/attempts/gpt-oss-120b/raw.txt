**Solution Explanation**

For every station we have to choose a frequency `1` or `2`.
For a recorded link `(u,v)` we need  

```
r_u * r_v = 2          (1)
```

Because `r_u , r_v ∈ {1,2}` the only possibilities are  

```
( r_u , r_v ) = (1,2)  or  (2,1)
```

So the two endpoints of each link must obtain *different* frequencies.
If a link connects a station with itself (`u = v`) condition (1) would require
`r_u² = 2`, impossible – such an input is immediately rejected.

Consequently the whole problem is exactly the classical **bipartite‑graph
checking** :

* vertices = stations  
* edges    = recorded links  

A feasible assignment exists **iff** the graph is bipartite.
If it is bipartite each connected component has exactly two possible
assignments – we may decide which colour gets frequency `1` and which gets
`2`.

--------------------------------------------------------------------

#### Lexicographically smallest assignment  

The required order is: first minimise `r₁`, then `r₂`, …  

Consider one connected component.
Let `c(v) ∈ {0,1}` be the colour obtained by a usual BFS/DFS
(start colour `0` for the first visited vertex).
All feasible assignments for this component are

```
   (c(v) = 0 → r_v = 1 , c(v) = 1 → r_v = 2)    or
   (c(v) = 0 → r_v = 2 , c(v) = 1 → r_v = 1)
```

The first station of the component in the global order is its **smallest
index** `p`.  
To obtain the smallest possible value at position `p`
we simply give it frequency `1`.  
Therefore we choose the mapping

```
if c(p) == 0 :   colour 0 → 1 , colour 1 → 2
else            : colour 1 → 1 , colour 0 → 2
```

Because components are independent, fixing the smallest index of every
component to `1` yields the globally lexicographically minimal sequence.

--------------------------------------------------------------------

#### Algorithm
```
read graph
if any self‑loop → NO

colour[1…n] = -1                         # not visited yet
answer[1…n] = 0

for v = 1 … n (in increasing order)
    if colour[v] == -1
        BFS starting from v
            assign alternating colours 0/1
            if an edge joins two vertices with same colour → NOT bipartite → NO
            collect all vertices of this component in list comp
        p = smallest vertex in comp            # actually p == v
        col_p = colour[p]
        for each x in comp
            answer[x] = 1  if colour[x] == col_p else 2

output YES and answer
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` iff no assignment exists,
otherwise prints `YES` and the lexicographically smallest feasible sequence.

---

##### Lemma 1  
If the input contains a self‑loop, no feasible assignment exists.

**Proof.**  
For a self‑loop `(u,u)` condition (1) becomes `r_u·r_u = 2`,
i.e. `r_u² = 2`. No integer `r_u ∈ {1,2}` satisfies it. ∎



##### Lemma 2  
During BFS, if an edge connects two vertices of the same colour,
the graph is not bipartite and no feasible assignment exists.

**Proof.**  
BFS colours vertices so that every traversed edge connects vertices of opposite
colours. Encountering an edge whose ends already have the same colour creates an
odd cycle, which contradicts bipartiteness. In a non‑bipartite graph some edge
must connect equal colours, therefore any 2‑colouring (and thus any assignment
satisfying (1)) is impossible. ∎



##### Lemma 3  
If BFS finishes without conflict, the component is bipartite and the colours
`c(v)` satisfy `c(u) ≠ c(v)` for every edge `(u,v)` of the component.

**Proof.**  
Induction over the BFS order: the start vertex receives colour `0`.
Whenever we visit an uncoloured neighbour, we assign the opposite colour,
hence the invariant holds for the newly coloured vertex.
Because we never meet an edge joining equal colours (Lemma&nbsp;2), the invariant
remains true for all processed edges. ∎



##### Lemma 4  
For a bipartite component `C` let `p` be its smallest index and `c(p)` its
colour. The assignment  

```
r_v = 1   if c(v) = c(p)
r_v = 2   otherwise
```

satisfies condition (1) for every edge of `C` and gives the smallest possible
value to vertex `p`.

**Proof.**  
By Lemma&nbsp;3 any edge `(u,v)` of `C` has `c(u) ≠ c(v)`. Consequently exactly
one endpoint receives colour `c(p)`, the other receives the opposite colour,
hence their frequencies are `(1,2)` in some order and their product is `2`.  

Vertex `p` itself obtains frequency `1` by construction.
Any other feasible assignment for `C` must give `p` either `1` or `2`.
If it gave `2`, the sequence would be lexicographically larger at position `p`.
Thus the described assignment is optimal for this component. ∎



##### Lemma 5  
The algorithm outputs a feasible assignment whenever it prints `YES`.

**Proof.**  
If it prints `YES`, all components were processed without conflict,
hence each component is bipartite (Lemma&nbsp;3).  
For every component we use the assignment of Lemma&nbsp;4,
which satisfies (1) for all its edges.  
All edges belong to some component, therefore every edge of the whole graph
satisfies the required product. ∎



##### Lemma 6  
The assignment produced by the algorithm is lexicographically minimal among
all feasible assignments.

**Proof.**  
Consider the vertices in increasing order.
Let `p₁ < p₂ < …` be the smallest indices of the successive connected
components (the algorithm processes components exactly in this order).
For component of `p₁` the algorithm gives `r_{p₁}=1` (Lemma&nbsp;4), which is the
minimum possible value at the first position of any feasible sequence.
All assignments sharing this prefix must also have `r_{p₁}=1`.  
Now we look at the next component. Its smallest vertex `p₂` is the first
position where the current prefix can differ. Again the algorithm gives it
value `1`, the smallest attainable value compatible with the already fixed
prefix. Repeating this argument component by component shows that no other
feasible sequence can be lexicographically smaller. ∎



##### Lemma 7  
If the algorithm prints `NO`, no feasible assignment exists.

**Proof.**  
`NO` is printed only in two situations

1. a self‑loop is present – impossible by Lemma&nbsp;1;
2. during BFS an edge connects equal colours – then the component is not
   bipartite, and by Lemma&nbsp;2 no assignment exists.

Thus in both cases the instance is unsatisfiable. ∎



##### Theorem  
The algorithm is correct:
* it prints `NO` **iff** the instance has no feasible frequency assignment;
* otherwise it prints `YES` followed by the lexicographically smallest feasible
  assignment.

**Proof.**  
*If* the algorithm prints `YES`, Lemma&nbsp;5 guarantees feasibility,
and Lemma&nbsp;6 guarantees optimality.

*Only if* the algorithm prints `NO`, Lemma&nbsp;7 shows infeasibility.

Together the statements prove the theorem. ∎

#### Complexity Analysis  

*Building the adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and each edge is examined once  
 → `O(n + m)` time, `O(n)` additional memory for colour/queue.  

Total  

```
Time   : O(n + m)   ≤ 4·10⁵ operations
Memory : O(n + m)   ≤ about 2·10⁵ integers
```

Both easily satisfy the limits.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    n = next(it)
    m = next(it)

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = next(it) - 1
        v = next(it) - 1
        if u == v:          # self‑loop -> impossible
            print("NO")
            return
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * n          # -1 = unvisited, else 0/1
    ans = [0] * n

    for start in range(n):
        if colour[start] != -1:
            continue
        # BFS of this component
        q = deque([start])
        colour[start] = 0
        comp = [start]

        while q:
            v = q.popleft()
            cv = colour[v]
            for nb in adj[v]:
                if colour[nb] == -1:
                    colour[nb] = cv ^ 1
                    q.append(nb)
                    comp.append(nb)
                elif colour[nb] == cv:
                    print("NO")
                    return

        # smallest index in component = start (because we iterate increasingly)
        p = min(comp)          # defensive, actually equals start
        col_p = colour[p]
        for v in comp:
            ans[v] = 1 if colour[v] == col_p else 2

    print("YES")
    print(' '.join(map(str, ans)))

if __name__ == "__main__":
    solve()
```

and conforms to the required input / output format.
