**Solution Explanation**

For every filter we have to choose one of the two matrices  

* `I = [[1,0],[0,1]]`   – mode **1**  
* `S = [[0,1],[1,0]]`   – mode **2**

For a pair `(u , v)` the required condition is  

```
M_u · M_v = S
```

The multiplication table of the two matrices is

|   | I | S |
|---|---|---|
| I | I | S |
| S | S | I |

Therefore `M_u·M_v = S` is satisfied **iff** the two matrices are different.
Consequently every pair forces the two involved filters to have *different*
modes:

```
mode_u != mode_v
```

The whole set of constraints is exactly a graph‑colouring problem with two
colours – the graph must be *bipartite*.



--------------------------------------------------------------------

#### 1.   Detecting impossibility  

Perform a BFS/DFS on every connected component.

* give the start vertex colour `0`
* each traversed edge forces the neighbour colour `colour[parent] xor 1`

If we ever meet an already coloured vertex with the *same* colour as the
current one, the graph is not bipartite → answer `NO`.

The BFS also stores for every vertex

* `comp[v]` – id of its connected component
* `base_colour[v]` – colour `0 / 1` obtained from the BFS (with the start vertex coloured `0`)

and for each component remembers its smallest vertex index `min_node[comp]`.

Complexities: `O(n+m)` time, `O(n+m)` memory.



--------------------------------------------------------------------

#### 2.   Lexicographically smallest assignment  

For a component we may keep the obtained colouring **or** flip all colours –
both satisfy all edges.  
The lexicographically smallest global sequence is built greedily:

*look at the vertices in increasing order `1 … n`.  
The first vertex belonging to a still undecided component can be forced to
mode **1** by choosing the appropriate orientation of this component.*

Thus the optimal rule is:

```
For every component C
    orient it so that its smallest index vertex gets colour 0
```

If `base_colour[min_node[C]]` already is `0` we keep the colouring,
otherwise we flip it.

Let `flip[C] = base_colour[min_node[C]]` (0 → keep, 1 → flip).

The final mode of a vertex `v` is

```
effective_colour = base_colour[v] xor flip[ comp[v] ]
mode = 1   if effective_colour == 0
        2   otherwise
```

All isolated vertices are also handled – they form a component of size one,
their smallest index is themselves, they receive mode `1`.



--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise prints `YES` and the lexicographically smallest valid sequence.

---

##### Lemma 1  
For any edge `{u,v}` the condition `M_u·M_v = S` is equivalent to
`mode_u ≠ mode_v`.

**Proof.** Directly from the multiplication table shown above:
`I·I = I`, `S·S = I`, `I·S = S·I = S`. The product is `S` exactly when the
two factors differ. ∎



##### Lemma 2  
A configuration of modes satisfying all pairs exists **iff** the graph is
bipartite.

**Proof.** By Lemma&nbsp;1 the requirement for every edge is that its
endpoints have different modes, i.e. a proper 2‑colouring of the graph.
A graph admits such a colouring exactly when it is bipartite. ∎



##### Lemma 3  
During the BFS the algorithm detects a conflict **iff** the graph is not
bipartite.

**Proof.** BFS colours every visited vertex according to the parity of the
path length from the start vertex.  
If an edge connects two vertices of equal colour, the edge lies on an odd
cycle, therefore the component is not bipartite.  
Conversely, in a bipartite component every edge connects opposite colours,
so BFS never meets equal colours. ∎



##### Lemma 4  
For a connected component `C` let `v_min` be its smallest indexed vertex.
Among the two possible orientations of the component the lexicographically
smaller overall sequence is obtained by the orientation that gives
`mode_{v_min}=1`.

**Proof.** The values of vertices with index `< v_min` belong to other
components and are already fixed when we decide the orientation of `C`.
All later vertices (`> v_min`) are less significant in lexicographic order.
Thus the first position where the two orientations may differ is exactly
`v_min`.  
Choosing the orientation with `mode_{v_min}=1` makes the whole sequence
lexicographically smaller (or equal, if both give `1`). ∎



##### Lemma 5  
The algorithm chooses for every component the orientation described in
Lemma&nbsp;4.

**Proof.** The algorithm sets `flip[C] = base_colour[v_min]`.  
If `base_colour[v_min]=0` (the vertex already has colour `0`) the orientation
is kept, giving `mode_{v_min}=1`.  
If it equals `1` the orientation is flipped, turning colour `1` into `0`,
again yielding `mode_{v_min}=1`. ∎



##### Lemma 6  
The sequence output by the algorithm is the lexicographically smallest
among all feasible assignments.

**Proof.** By Lemma&nbsp;2 a feasible assignment exists (otherwise the algorithm
already printed `NO`).  
Consider the vertices in increasing order.  
When the first vertex of a component `C` appears, all earlier vertices belong
to other components whose orientations are already fixed.
By Lemma&nbsp;5 the algorithm makes this first vertex have mode `1`, which is
optimal by Lemma&nbsp;4.  
Proceeding inductively over the index order, no later decision can improve
any earlier position, therefore the whole sequence is lexicographically
minimal. ∎



##### Lemma 7  
If the algorithm prints `YES` the produced sequence satisfies all constraints.

**Proof.** The BFS succeeded, i.e. the graph is bipartite (Lemma&nbsp;3).
Thus the base colouring already respects every edge (`base_colour[u] ≠
base_colour[v]`). Flipping colours of a whole component preserves inequality,
so after applying `flip[C]` all edges still join vertices of different
effective colours, i.e. different modes. ∎



##### Theorem  
The algorithm

* prints `NO` **iff** no valid configuration exists,
* otherwise prints `YES` and the lexicographically smallest valid
  configuration of modes.

**Proof.**  
*If* the algorithm prints `NO`, a conflict was found during BFS, meaning the
graph is not bipartite (Lemma&nbsp;3). By Lemma&nbsp;2 no configuration exists.

*If* a configuration exists, the graph is bipartite, BFS finishes without
conflict, the algorithm prints `YES`.  
By Lemma&nbsp;7 the printed assignment satisfies all constraints.
By Lemma&nbsp;6 it is the lexicographically smallest among all feasible
assignments.

Thus both statements hold. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency lists* : `O(n+m)` time, `O(n+m)` memory  
*BFS over all components*   : `O(n+m)` time, `O(n)` extra memory  
*Final answer construction* : `O(n)` time, `O(n)` memory  

Overall  

```
Time   : O(n + m)   ≤ 4·10^5 operations
Memory : O(n + m)   ≤ 4·10^5 integers   (well below limits)
```

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    comp = [-1] * (n + 1)          # component id of each vertex
    colour = [0] * (n + 1)        # base colour 0 / 1
    min_node_of_comp = []         # smallest index in each component
    cid = 0
    ok = True

    for start in range(1, n + 1):
        if comp[start] != -1:
            continue
        # BFS of a new component
        q = deque([start])
        comp[start] = cid
        colour[start] = 0
        cur_min = start

        while q and ok:
            v = q.popleft()
            if v < cur_min:
                cur_min = v
            cv = colour[v]
            for nb in adj[v]:
                if comp[nb] == -1:
                    comp[nb] = cid
                    colour[nb] = cv ^ 1
                    q.append(nb)
                else:
                    # edge inside component, must connect different colours
                    if colour[nb] == cv:
                        ok = False
                        break
        if not ok:
            break
        min_node_of_comp.append(cur_min)
        cid += 1

    if not ok:
        sys.stdout.write("NO")
        return

    # decide orientation: flip if smallest vertex has colour 1
    flip = [0] * cid
    for c in range(cid):
        flip[c] = colour[min_node_of_comp[c]]   # 0 -> keep, 1 -> flip

    ans = [0] * (n + 1)
    for v in range(1, n + 1):
        effective = colour[v] ^ flip[comp[v]]
        ans[v] = 1 if effective == 0 else 2

    out = ["YES", " ".join(str(ans[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
