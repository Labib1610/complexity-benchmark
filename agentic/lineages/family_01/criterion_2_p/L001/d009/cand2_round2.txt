# Problem B — Signal Pipeline Synchronization

Time limit: 1 s   Memory limit: 256 MB

You are configuring a data processing pipeline consisting of $n$ transformation filters. Each filter $i$ must be assigned a base scaling factor $s_i$.

You must configure each filter into exactly one of two operational modes:
* **Mode 1**: The filter has a base scaling factor of $s_i = 1$.
* **Mode 2**: The filter has a base scaling factor of $s_i = 2$.

The pipeline design includes $m$ synchronization links. Each link connects two filters $u$ and $v$ to form an amplification stage. 
The gain of a single amplification stage is the sum of the base scaling factors of its two filters, $(s_u + s_v)$. 
Because the $m$ stages operate in sequence on the synchronization bus, the total synchronization gain of the pipeline is the product of the gains of all $m$ stages.

To prevent signal distortion, the pipeline must be perfectly balanced. A configuration is valid if and only if the total synchronization gain is exactly $3^m$. 
Specifically, if the $m$ links are $(u_1, v_1), (u_2, v_2), \dots, (u_m, v_m)$, the validity condition is:
$$ \prod_{j=1}^m (s_{u_j} + s_{v_j}) = 3^m $$
If $m = 0$, the total gain is considered to be $1$ (which equals $3^0$), and the condition is vacuously satisfied. Filters not part of any link must still be assigned exactly one mode.

You must determine if there is a valid configuration of modes for all $n$ filters. If there are multiple valid configurations, you must choose the one that yields the lexicographically smallest sequence of modes (where each mode is represented as $1$ or $2$) when listed in order from filter $1$ to filter $n$.

## Input
The first line of the input contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — indicating a synchronization link between filter $u$ and filter $v$.

## Output
If there is no valid configuration, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers separated by spaces, where the $i$-th integer is the mode ($1$ or $2$) assigned to the $i$-th filter, representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit function composition constraint with a global product equation. To solve this efficiently, the model must deduce via unique prime factorization that since the terms $(s_u + s_v)$ can only be 2, 3, or 4, a product of $3^m$ rigorously forces every single term to be exactly 3. This forces the model to perform a non-trivial mathematical deduction to reveal the underlying bipartiteness graph structure, defeating naive template matching while keeping the core task identical.
</RATIONALE>
<PRESERVED_ANSWER>
Because $s_i \in \{1, 2\}$, the sum $s_u + s_v$ is strictly in $\{2, 3, 4\}$; by the fundamental theorem of arithmetic, their product equals $3^m$ if and only if every single pair sums to 3, which is logically identical to requiring $s_u \neq s_v$ for every edge as in the seed.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
