# Problem B — Museum Exhibition Planning

Time limit: 1 s   Memory limit: 256 MB

A museum curator is organizing an exhibition featuring $n$ historical artifacts, sequentially cataloged from 1 to $n$. The exhibition space is divided into two distinct climate zones: Zone 1 and Zone 2. Each artifact requires placement in exactly one zone.

During the planning phase, the curator identified $m$ specific pairs of artifacts that emit competing frequencies of radiation. If two such artifacts share a climate zone, their frequencies will interfere. Thus, for each recorded pair of interfering artifacts, they must not share a zone.

The museum's environmental systems can support a minimum of one artifact and a maximum capacity of two hundred thousand artifacts. The curator's database can store anywhere from zero up to two hundred thousand interference records.

Your task is to assign the artifacts to the two zones in a way that avoids all interference. If it is impossible to satisfy all the conditions, you must report this. In cases where multiple valid arrangements exist, the museum's cataloging system requires you to output the sequence of zone assignments that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$, representing the number of artifacts and the number of interfering pairs. The values of $n$ and $m$ respect the minimums and maximum capacities described above.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ (ranging from 1 up to the total number of artifacts $n$), indicating that artifact $u$ and artifact $v$ interfere.

## Output
If no valid arrangement is possible, output a single line containing `NO`.
Otherwise, output a line containing `YES`. On the following line, output $n$ space-separated integers $h_1, h_2, \dots, h_n$ (where each $h_i \in \{1, 2\}$) representing the assigned zone for each artifact. This sequence must be the lexicographically smallest among all valid arrangements.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
