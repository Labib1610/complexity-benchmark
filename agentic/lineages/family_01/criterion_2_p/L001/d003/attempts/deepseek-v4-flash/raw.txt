We can model this as a graph problem where each artifact is a node, and each pair is an edge.  
The constraint “sum of levels = 3” means if one is 1, the other must be 2, and vice versa.  
So it’s a bipartite coloring problem with two colors (1 and 2).  

If the graph is not bipartite, output `NO`.  
Otherwise, we need the lexicographically smallest assignment.  
We can do a BFS/DFS over each connected component, trying to assign the smallest possible value (1) to the smallest-index node in that component, then propagate the alternating colors.  

Here’s the implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
