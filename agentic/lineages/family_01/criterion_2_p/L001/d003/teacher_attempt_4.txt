<STATEMENT>
# Drone Synchronization Beacons

Time limit: 1 s   Memory limit: 256 MB

A logistics network manages $n$ autonomous delivery drones, indexed from 1 to $n$. Each drone is equipped with a collision-avoidance beacon that must be configured to operate in either State 1 or State 2.

The flight control system has identified $m$ pairs of drones whose trajectories will cross. When two drones cross paths, their beacons must perform a mutual handshake to coordinate a safe pass. The hardware is designed such that a handshake is only successful if the sum of the two drones' beacon states is exactly 3. If the sum is anything else, the handshake fails and a collision risk occurs.

You need to determine a configuration of beacon states for all $n$ drones that ensures successful handshakes for all $m$ crossing pairs. If no such configuration is possible, you must report this. In cases where multiple valid configurations exist, the network's diagnostic logging requires you to output the sequence of beacon states that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of drones and the number of crossing pairs.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that drone $u$ and drone $v$ will cross paths.

## Output
If no valid configuration is possible, output a single line containing `NO`.
Otherwise, output a line containing `YES`. On the following line, output $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$) representing the configured beacon state for each drone. This sequence must be the lexicographically smallest among all valid configurations.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the domain from museum artifacts in halls to drone beacons in operational states. Replaced the explicit "must be in different halls" constraint with an arithmetic property: "the sum of the two states is exactly 3". Because states are restricted to {1, 2}, this forces the model to deduce that the states must be different, requiring it to recognize the bipartite constraint through algebraic reasoning rather than surface pattern matching on the word "different".
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic constraint $s_u + s_v = 3$ for $s_u, s_v \in \{1, 2\}$ is mathematically identical to $s_u \neq s_v$, meaning the set of all valid configurations and the exact lexicographical tie-breaking remain perfectly identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing), which is solvable in linear time using BFS/DFS to traverse components, keeping the complexity class in P.
</PRESERVED_CLASS>
