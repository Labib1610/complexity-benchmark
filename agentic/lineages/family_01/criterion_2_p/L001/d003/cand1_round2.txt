# Problem B — Monomer Spin States

Time limit: 1 s   Memory limit: 256 MB

A synthetic polymer is built from $n$ distinct monomers, indexed from 1 to $n$. A synthesis configuration requires tuning each monomer to a specific spin state, chosen from the set $\{1, 2\}$.

The laboratory has documented $m$ covalent bonds between specific monomer pairs. To prevent structural degradation, a strict stability criterion applies across every recorded bond: if you take the spin states assigned to the two bonded monomers and apply a bitwise XOR operation between them, the evaluated result must be exactly 3.

You must find a complete synthesis configuration that successfully assigns a spin state to every monomer. If there are multiple valid configurations, you must output the one that is lexicographically smallest. If no configuration can satisfy the stability criterion for all documented bonds at the same time, you must report that it is impossible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), identifying a pair of monomers in the record.

## Output
If no valid synthesis configuration exists, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$) representing the spin state assigned to each respective monomer from 1 to $n$. This sequence must be the lexicographically smallest possible valid sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The previous version allowed models to trivially recognize the bipartiteness/2-coloring constraint because "sum to 3" for values $\{1, 2\}$ is a very common textbook framing for bipartite coloring. To force models to actually evaluate the constraint mathematically rather than pattern-matching the phrase, I replaced the addition operation with a bitwise XOR operation. Since $1 \oplus 2 = 3$ and $1 \oplus 1 = 0$ and $2 \oplus 2 = 0$, the constraint remains logically identical but the typical graph-coloring keywords are removed. I also restored the exact mathematical bound inequalities to ensure the automated checker reliably parses them.
</RATIONALE>
<PRESERVED_ANSWER>
The domain of spin states remains strictly $\{1, 2\}$, and the requirement that their bitwise XOR evaluates to 3 is mathematically equivalent to requiring their sum to be 3 (which forces opposite states on bonded pairs), meaning all valid assignments and tie-breakers are identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring (or detecting an odd cycle) in an undirected graph, which is solvable in $O(n+m)$ time using Breadth-First Search, keeping it in P.
</PRESERVED_CLASS>
