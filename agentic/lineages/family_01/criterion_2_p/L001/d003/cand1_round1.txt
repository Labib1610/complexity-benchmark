# Problem B — Power Bus Redundancy

Time limit: 1 s   Memory limit: 256 MB

An orbital station contains $n$ life-support modules. The station's central manifest accommodates a minimum of one module and has a structural maximum capacity of two hundred thousand modules. The automated diagnostic system must configure the backup network by assigning a redundancy tier to each module. Each module's tier must be a positive integer whose square is no greater than $4$.

The safety protocol includes $m$ critical links. The backup registry can store anywhere from zero up to two hundred thousand such links. Each link identifies two modules that serve as mutual backups. To guarantee operational stability, the configuration must satisfy a strict numerical condition: for any two modules $u$ and $v$ connected by a critical link, the sum of the squares of their assigned tier values must evaluate to exactly $5$.

You must determine whether a valid tier assignment exists for all modules. When multiple valid assignments are possible, the diagnostic system mandates selecting the configuration that produces the lexicographically smallest sequence of tier values, ordered by module number from $1$ to $n$.

## Input
The first line of the input contains two integers $n$ and $m$ — the number of modules and the number of critical links. The values of $n$ and $m$ conform to the station's structural capacity and storage limits described above.
Each of the next $m$ lines contains two integers $u$ and $v$ — a redundancy link between module $u$ and module $v$.

## Output
If there is no way to assign the tier values without violating the safety protocol, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers separated by spaces, where the $i$-th integer is the tier value assigned to the $i$-th module, representing the lexicographically smallest valid assignment ordered by indices from $1$ to $n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was modified to remove the explicit references to a 2-value domain and bitwise XOR, which immediately triggered bipartite graph templates in the models. Instead, the tier values are constrained algebraically (positive integers with squares ≤ 4), and the edge condition requires the sum of squares to be 5, forcing models to deduce that the only valid combinations are strictly {1, 2} and mutually exclusive across edges. Additionally, numeric bounds for $n$ and $m$ were moved into the scenario description following Strategy S07.
</RATIONALE>
<PRESERVED_ANSWER>
A positive integer whose square is at most 4 can only be 1 or 2, and the only way two such integers can have squares summing to 5 is if one is 1 and the other is 2, perfectly mirroring the original "XOR to 3" constraint on the domain {1, 2}.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically first valid 2-coloring (bipartite coloring) of a graph, which is solvable in linear time using BFS.
</PRESERVED_CLASS>
