# Problem B — Pairs Trading Strategy

Time limit: 1 s   Memory limit: 256 MB

A quantitative hedge fund is configuring an automated trading algorithm for a universe of $n$ equities, numbered 1 through $n$. The system's market-neutral constraint relies on balancing risk allocations across specific linked assets.

The fund's market analysis has identified $m$ pairs of equities that are strongly cointegrated. For the algorithm to function correctly, every equity $i$ must be given a fixed risk allocation $p_i$, which must be either 1 or 2. Furthermore, for any two equities $u$ and $v$ that form a cointegrated pair, their combined risk allocation $p_u + p_v$ must equal exactly 3.

Your task is to determine a valid risk allocation for the entire universe of $n$ equities. If no such allocation can satisfy the combined risk requirement for all $m$ pairs simultaneously, you must report this failure. If multiple valid allocations exist, you must provide the one where the sequence of allocations $p_1, p_2, \dots, p_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of equities and the number of cointegrated pairs.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that equity $u$ and equity $v$ form a cointegrated pair.

## Output
If no valid assignment of risk allocations is possible, output a single line containing `NO`.
Otherwise, output a line containing `YES`. On the following line, output $n$ space-separated integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2\}$) representing the assigned allocation for each equity. This sequence must be the lexicographically smallest among all valid assignments.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit phrasing "assigned different postures" directly triggered bipartite graph and 2-coloring templates in the models. This affordance was removed by replacing the difference constraint with an algebraically equivalent sum constraint ($p_u + p_v = 3$) for variables restricted to $\{1, 2\}$. This forces the model to deduce the mutual exclusivity of the assignments rather than relying on surface-level keyword matching.
</RATIONALE>
<PRESERVED_ANSWER>
The domain of each variable is still strictly $\{1, 2\}$, and the constraint $p_u + p_v = 3$ is satisfied if and only if $p_u \neq p_v$, making the valid configurations identical to the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring (or identifying an odd cycle) in an undirected graph, which is solvable in $O(n+m)$ time using BFS or DFS.
</PRESERVED_CLASS>
