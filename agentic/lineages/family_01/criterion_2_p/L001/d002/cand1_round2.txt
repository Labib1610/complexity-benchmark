<STATEMENT>
# Problem B — Operational Windows

Time limit: 1 s   Memory limit: 256 MB

A manufacturing facility employs a workforce of $n$ individuals, identified by integers starting from 1 up to $n$. A roster configuration assigns each worker an operational window, which must be chosen as an integer value of either 1 or 2.

The safety system maintains a log of $m$ incompatible pairs. To prevent hazards, the system enforces a strict non-linear separation rule for any pair of workers listed in the log: when the assigned window values of the two workers in a logged pair are each cubed and then added together, the resulting sum must be exactly 9.

Your task is to determine a valid roster configuration for all $n$ workers. If multiple valid configurations exist, you must provide the one that is lexicographically smallest. If it is impossible to satisfy the separation rule for all logged pairs simultaneously, you must report the failure.

## Input
The first line provides two integers $n$ and $m$. The facility requires a minimum headcount $n$ of $1$ and its physical limit sets a maximum capacity of $2 \cdot 10^5$ personnel. The safety log can contain an absolute minimum of $0$ entries, or up to a maximum of $2 \cdot 10^5$ entries, represented by $m$.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), identifying a pair of workers in the log.

## Output
If no valid roster configuration exists, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$) representing the operational window assigned to each respective worker from 1 to $n$. This sequence must be the lexicographically smallest possible valid sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit exact-sum-3 rule over {1,2} was a direct giveaway for 2-coloring/bipartite graph checking. I replaced it with a cubed-sum condition ($x^3 + y^3 = 9$). Because the values are restricted to {1, 2}, this condition is mathematically identical to requiring opposite assignments, but it forces models to analyze the algebraic constraint rather than immediately mapping the linear sum to standard bipartite coloring templates. The bounds have also been explicitly restored to satisfy the verification gate.
</RATIONALE>
<PRESERVED_ANSWER>
The allowed values are strictly {1, 2}, and the only pair of these values whose cubes sum to 9 is {1, 2}, exactly preserving the requirement that logged pairs receive different values.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring (bipartite check) of an undirected graph, which is solvable in O(n+m) time using BFS or DFS.
</PRESERVED_CLASS>
