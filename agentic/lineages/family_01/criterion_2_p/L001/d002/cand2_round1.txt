# Problem B — Harmonic Multipliers

Time limit: 1 s   Memory limit: 256 MB

A deep-space observatory consists of $n$ sensor arrays, numbered 1 through $n$. To calibrate the system, each array must be assigned a harmonic multiplier, which must be chosen as either the integer 1 or the integer 2.

The observatory's telemetry system includes $m$ resonance conduits, each linking a specific pair of sensor arrays. To prevent destructive interference, the multipliers assigned to any pair of arrays linked by a conduit must be harmonically distinct: specifically, the multiplier assigned to one array in the pair must be exactly twice the multiplier assigned to the other array in that pair.

Your objective is to determine a valid calibration for all $n$ arrays. If multiple valid calibrations exist, you must output the one that is lexicographically smallest. If no calibration can satisfy the conduit constraints across the entire system, you must report the failure.

## Input
The first line contains two integers $n$ and $m$. The number of sensor arrays $n$ is at least $1$ and at most $2 \cdot 10^5$. The number of resonance conduits $m$ is between $0$ and $2 \cdot 10^5$, inclusive.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a conduit linking array $u$ and array $v$.

## Output
If no valid calibration is possible, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2\}$) representing the harmonic multiplier assigned to each respective array from 1 to $n$. This sequence must be the lexicographically smallest possible valid sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
