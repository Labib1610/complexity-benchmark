# Problem B — Equities Calibration

Time limit: 1 s   Memory limit: 256 MB

A quantitative hedge fund is tuning a trading model for a portfolio of $n$ equities, indexed 1 to $n$. The model requires each equity to be assigned a discrete calibration factor, which must be chosen as either 1 or 2.

Through statistical analysis, the fund has isolated $m$ specific dependencies between certain pairs of equities. To ensure stability across the portfolio, the trading model enforces a strict structural requirement: for any two equities that share a dependency, the product of their assigned calibration factors must evaluate to exactly 2.

You need to determine a valid configuration of calibration factors for the entire set of $n$ equities. If no such configuration can satisfy the product constraint for all dependencies, you must indicate that it cannot be done. If multiple valid configurations exist, you must supply the one whose sequence of factors is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), denoting the number of equities and the number of dependencies.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a dependency between equity $u$ and equity $v$.

## Output
If no valid configuration is possible, print a single line containing `NO`.
Otherwise, print a line containing `YES`. On the following line, print $n$ space-separated integers $p_1, p_2, \dots, p_n$ ($p_i \in \{1, 2\}$) representing the calibration factor for each equity. This sequence must be the lexicographically smallest among all valid configurations.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit requirement that linked equities must have "different postures" with the mathematical equivalent that their assigned values (which are strictly 1 or 2) must multiply to exactly 2. This removes the obvious phrasing of graph coloring, forcing the model to deduce that the product constraint over {1, 2} is isomorphic to an inequality constraint and therefore requires a bipartiteness check.
</RATIONALE>
<PRESERVED_ANSWER>
Because the only allowed values are 1 and 2, their product is 2 if and only if one equity is assigned 1 and the other 2; this is logically identical to requiring different values for every edge, preserving all valid assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, keeping it in P and solvable in O(n + m) time using BFS/DFS.
</PRESERVED_CLASS>
