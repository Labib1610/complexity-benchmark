# Problem B — Operational Windows

Time limit: 1 s   Memory limit: 256 MB

A manufacturing facility employs a workforce of $n$ individuals, identified by integers starting from 1 up to $n$. A roster configuration assigns each worker an operational window, which must be an integer value of either 1 or 2.

The safety system maintains a log of $m$ interacting pairs. To prevent hazards, the system enforces a strict non-linear separation rule for any pair of workers listed in the log: when the operational window values assigned to the two workers in a logged pair are each cubed and then added together, the resulting sum must be exactly 9.

Your task is to determine a valid roster configuration for all $n$ workers. If multiple valid configurations exist, you must provide the one that is lexicographically smallest. If it is impossible to satisfy the separation rule for all logged pairs simultaneously, you must report the failure.

## Input
The first line provides two integers $n$ and $m$. The facility operates with a minimum headcount $n$ of a single worker. The maximum personnel capacity is established by the facility's physical architecture, which consists of twenty sectors that each accommodate exactly ten thousand people. The safety log can be completely empty, or it can store a number of entries up to the facility's maximum personnel capacity, establishing the upper limit for $m$.
Each of the following $m$ lines contains two integers $u$ and $v$, identifying a pair of workers in the log. Both worker identifiers $u$ and $v$ are strictly positive and will not exceed the actual headcount $n$.

## Output
If no valid roster configuration exists, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$) representing the operational window assigned to each respective worker from 1 to $n$. This sequence must be the lexicographically smallest possible valid sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

I replaced the "sum to exactly 3" condition with the mathematically equivalent constraint that the sum of their cubes must be exactly 9. This forces the model to algebraically evaluate the constraint over the domain {1, 2} to realize it enforces inequality, preventing a superficial pattern match to bipartite coloring. I also applied S07 by replacing the raw bound of 200,000 with a physical derivation based on twenty sectors of ten thousand people each.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that $x^3 + y^3 = 9$ for $x, y \in \{1, 2\}$ is exclusively satisfied by the set $\{1, 2\}$, which is logically identical to the original constraint that $x + y = 3$, so all valid assignments remain exactly the same.
</PRESERVED_ANSWER>
