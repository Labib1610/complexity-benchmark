 We need to assign each monomer a spin of 1 or 2 such that for every bond (u, v), the spins are different (since 1+2=3, 1+1=2, 2+2=4).  
This is exactly a bipartite graph check problem. If the graph is not bipartite, output `NO`.  
If it is bipartite, we can assign 1 to one side and 2 to the other.  
For lexicographically smallest assignment, we can do BFS/DFS and assign 1 to the first node we encounter in each component, then alternate.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    adj[u-1].append(v-1)
    adj[v-1].append(u-1)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    # color 0 -> spin 1, color 1 -> spin 2
    print(' '.join('1' if c == 0 else '2' for c in color))
```
