# Problem B — Brokerage Routing

Time limit: 1 s   Memory limit: 256 MB

A quantitative hedge fund is configuring its automated execution system for a universe of equities, indexed consecutively starting from 1. Due to regulatory limits on the number of distinct tickers a single entity can hold, the portfolio size $n$ is at least 1 and cannot exceed 200,000. 

The execution system mandates that each equity be routed to exactly one of two available clearing brokerages: brokerage 1 or brokerage 2. 

The fund's risk model has flagged $m$ pairs of equities that exhibit extreme correlation. To prevent concentrated exposure at a single clearinghouse, the system requires that for every flagged pair, the two equities involved must never be routed to the same brokerage. Due to fixed memory allocations in the risk engine, the number of flagged pairs $m$ ranges from 0 up to a maximum of 200,000.

Your task is to determine a routing assignment for all $n$ equities that satisfies these conditions. If it is impossible to separate all flagged pairs across the two brokerages, you must report this failure. If there are multiple valid routing assignments, you must output the one that is lexicographically smallest when represented as a sequence of brokerage numbers (1s and 2s).

## Input
The first line contains $n$ and $m$, representing the number of equities and the number of flagged pairs. 
Each of the subsequent $m$ lines contains two integers $u$ and $v$ (where both are valid equity numbers between 1 and $n$), indicating that equity $u$ and equity $v$ form a flagged pair.

## Output
If no valid routing assignment is possible, output a single line containing `NO`.
Otherwise, output a line containing `YES`. On the following line, output $n$ space-separated integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2\}$) representing the assigned brokerage for each equity. This sequence must be the lexicographically smallest among all valid assignments.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
