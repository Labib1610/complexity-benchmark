We can model this as a graph problem: each emitter is a node, and each intersection is an edge.  
We need to assign each node a value of 1 or 2 such that adjacent nodes have different values — this is exactly checking if the graph is bipartite.

To get the lexicographically smallest assignment, we run BFS/DFS from each unvisited node, always trying to assign the smallest possible value (1) to the starting node, and alternate for neighbors.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
