# Portfolio Diversification Strategy

Time limit: 1 s   Memory limit: 256 MB

You are a quantitative analyst constructing investment vehicles from a pool of $n$ distinct financial assets, numbered 1 through $n$. Your firm offers exactly two investment funds, designated by the integers 1 and 2. Every asset must be allocated to exactly one of these two funds.

Risk analysis has identified $m$ structural dependencies within the asset pool. To maintain regulatory compliance, these dependencies are modeled as strict separation constraints on the assignments. Specifically, for each identified dependency involving two assets, they must be assigned to different funds.

The firm's automated trading system requires the final asset allocation to be strictly deterministic. If there are multiple valid ways to allocate the assets while satisfying all $m$ separation constraints, the system requires the lexicographically smallest allocation. (An allocation is represented as a sequence of $n$ integers, where the $i$-th integer is the fund, 1 or 2, assigned to asset $i$. A sequence $A$ is lexicographically smaller than sequence $B$ if $A$ has a smaller value at the first position where they differ.)

If the dependencies are so entangled that no valid allocation exists, you must reject the pool entirely.

## Input
The first line contains two integers $n$ and $m$ — the number of assets and the number of structural dependencies. The portfolio database has a strict capacity of two hundred thousand assets, with at least one asset always required. The compliance engine can track up to a matching maximum of two hundred thousand dependencies, or it can be completely empty.

Each of the next $m$ lines contains two integers $u$ and $v$ (representing valid assets from the pool of $n$), indicating that asset $u$ and asset $v$ must be allocated to different funds.

## Output
If no valid allocation is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers (each either 1 or 2) — the lexicographically smallest valid allocation.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

The requirement for two assets to sum to 3 using values from {1, 2} is mathematically identical to requiring them to have different values from {1, 2}, preserving all valid allocations and the lexicographical tie-breaker.
</PRESERVED_ANSWER>
