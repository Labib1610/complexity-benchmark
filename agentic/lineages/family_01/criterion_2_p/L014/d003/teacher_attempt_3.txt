# Drone Triangulation Protocol

Time limit: 1 s   Memory limit: 256 MB

You are configuring a fleet of $n$ autonomous drones, numbered 1 through $n$. The flight controller requires each drone to be assigned exactly one operational altitude level, designated by the integers 1 and 2.

The mission requires $m$ specific pairs of drones to perform synchronized vertical scanning. To achieve the correct perspective differential, each of these designated pairs must be separated in a specific way. Specifically, for each designated pair of drones, the product of their assigned altitude levels must equal exactly 2.

The fleet's navigation system requires the final altitude configuration to be strictly deterministic. If there are multiple valid ways to assign the altitude levels while satisfying all $m$ synchronization constraints, the system requires the lexicographically smallest configuration. (A configuration is represented as a sequence of $n$ integers, where the $i$-th integer is the altitude level, 1 or 2, assigned to drone $i$. A sequence $A$ is lexicographically smaller than sequence $B$ if $A$ has a smaller value at the first position where they differ.)

If the synchronization constraints conflict such that no valid configuration exists, you must abort the launch.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$) — the number of drones and the number of synchronized scanning pairs.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that the product of the altitude levels assigned to drone $u$ and drone $v$ must equal exactly 2.

## Output
If no valid configuration is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers (each either 1 or 2) — the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The scenario was changed from financial asset allocation to drone altitude configuration. The arithmetic constraint "sum to 3" was replaced with "product is 2". This forces the model to deduce that $a \times b = 2$ for $a,b \in \{1,2\}$ implies $a \neq b$, bypassing surface-level pattern matching on the original phrasing.
</RATIONALE>
<PRESERVED_ANSWER>
The variables are restricted to the set {1, 2}, so the constraint $a \times b = 2$ is mathematically identical to $a + b = 3$; both require exactly one variable to be 1 and the other to be 2, preserving all valid assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically first valid 2-coloring of a graph, which is solvable in O(n+m) time using breadth-first or depth-first search.
</PRESERVED_CLASS>
