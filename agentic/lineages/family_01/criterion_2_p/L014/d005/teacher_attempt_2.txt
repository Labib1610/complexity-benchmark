# Portfolio Diversification Strategy

Time limit: 1 s   Memory limit: 256 MB

You are a quantitative analyst configuring an array of $n$ financial assets. Each asset $i$ (for $i$ from 1 to $n$) must be assigned a state variable $s_i \in \{1, 2\}$.

Risk analysis dictates that certain pairs of assets have correlated volatilities. You are given $m$ such correlation constraints. For each constraint involving asset $u$ and asset $v$, their assigned state variables must satisfy the equation $s_u + s_v = 3$.

Because the firm's trading algorithms require a strictly deterministic initialization, the system applies a sequential elimination process to the set of all valid state arrays $(s_1, s_2, \dots, s_n)$ that satisfy all $m$ equations:
1. The system evaluates the state variables index by index, starting from $i=1$ up to $i=n$.
2. At each index $i$, if the pool of still-valid arrays contains some arrays with $s_i = 1$ and others with $s_i = 2$, the system permanently discards all arrays where $s_i = 2$.
3. This process continues until exactly one definitive array remains.

If the system of constraints is logically inconsistent such that no valid array of state variables can be formed, the portfolio must be rejected.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$) — the number of assets and the number of correlation constraints.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a constraint between asset $u$ and asset $v$.

## Output
If no valid array of state variables is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers (each either 1 or 2, separated by spaces) — the valid array $s_1, s_2, \dots, s_n$ that satisfies the system's deterministic tie-breaking rule.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit logical constraint "exactly one of those two assets must be assigned the index 1" with the algebraic equation "$s_u + s_v = 3$". This removes the obvious prompt for 2-coloring/bipartite graph traversal, forcing the model to first deduce that the equation implies $s_u \neq s_v$ and then recognize that this system of equations over $\{1, 2\}$ is equivalent to finding the lexicographically first valid coloring of connected components.
</RATIONALE>
<PRESERVED_ANSWER>
Since the state variables are restricted to the set {1, 2}, the equation $s_u + s_v = 3$ is exactly equivalent to requiring that one variable is 1 and the other is 2, which matches the original constraint perfectly.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring (or detecting odd cycles) and choosing the lexicographically smallest valid assignment per connected component, which is solvable in $O(n+m)$ time.
</PRESERVED_CLASS>
