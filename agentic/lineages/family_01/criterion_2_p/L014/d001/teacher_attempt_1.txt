# Problem B — Phase Equilibrium Protocol

Time limit: 1 s   Memory limit: 256 MB

In the automated deployment pipeline for the Aegis distributed architecture, the deployment process is divided into three distinct phases: telemetry gathering, module segregation, and binary distribution. You are responsible for implementing the module segregation phase.

During the initial telemetry phase, the system monitors $n$ independent service modules (numbered sequentially starting from 1). The Aegis architecture's main chassis provides slots for a maximum of 200,000 modules, and a deployment always contains at least one. The telemetry phase also generates a list of $m$ interference warnings. The hardware diagnostic buffer storing these warnings has a capacity of exactly 200,000 entries, though a perfectly clean run might result in zero warnings. 

In your segregation phase, you must assign a base operating frequency to each module. The only available frequencies are designated by the integers 1 and 2. To maintain phase equilibrium and prevent signal cancellation, any two modules flagged together in an interference warning must have their assigned frequency values sum to exactly 3.

The final binary distribution phase requires a strictly deterministic configuration to route requests. Because there may be multiple valid frequency assignments, the distribution phase expects the assignment plan that is lexicographically smallest. (An assignment plan is represented as a sequence of $n$ integers, where the $i$-th integer is the frequency chosen for module $i$. Sequence $A$ is lexicographically smaller than sequence $B$ if $A$ has a smaller value at the first position where they differ).

If the telemetry constraints are inherently contradictory and no valid assignment exists, your phase must halt the pipeline by rejecting the configuration.

## Input
The first line contains two integers $n$ and $m$, representing the number of modules and the number of interference warnings, respectively. (The bounds for these values are determined by the main chassis slots and diagnostic buffer capacity described above).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a pair of modules flagged in a warning.

## Output
If no valid assignment plan exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers (each either 1 or 2)—the lexicographically smallest valid assignment plan for the modules.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

The explicit "must not be assigned to the same environment" trigger for bipartite graph matching was replaced with the mathematical equivalent "assigned frequency values sum to exactly 3". Since the only available values are 1 and 2, this forces the values to be different. Bounds for $n$ and $m$ were removed from the Input section and integrated into the descriptive text as physical limits of the system chassis and diagnostic buffer, forcing the model to extract them via reading comprehension.
</RATIONALE>
<PRESERVED_ANSWER>
Assigning values from {1, 2} such that conflicting pairs sum to 3 is algebraically identical to assigning them to two distinct sets, so the exact same lexicographically smallest assignment is produced for all inputs.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
