# Problem B — Phase Resonators

Time limit: 1 s   Memory limit: 256 MB

A particle accelerator contains a sequence of $n$ magnetic resonators, numbered 1 through $n$. Each resonator must be configured with a harmonic multiplier of either 1 or 2.

The system is stabilized by $m$ flux tethers. Each tether links a specific pair of resonators. For a tether to maintain equilibrium, the sum of the harmonic multipliers of the two resonators it links must be exactly 3. If the sum is anything else, the tether will rupture.

You need to determine a configuration of harmonic multipliers for all $n$ resonators such that all $m$ tethers maintain equilibrium. The diagnostic system requires a strictly deterministic configuration. If there are multiple valid configurations, you must output the one that is lexicographically smallest. (A configuration is represented as a sequence of $n$ integers, where the $i$-th integer is the multiplier for resonator $i$. Sequence $A$ is lexicographically smaller than sequence $B$ if $A$ has a smaller value at the first position where they differ).

If the tether layout is inherently unstable and no such configuration exists, the diagnostic system must halt.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of resonators and the number of flux tethers, respectively.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a pair of resonators linked by a tether.

## Output
If no valid configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers (each either 1 or 2)—the lexicographically smallest valid configuration for the resonators.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Changed the real-world scenario from allocating modules to two environments to assigning harmonic multipliers (1 or 2) to resonators. Replaced the inequality constraint ("must not be assigned to the same environment") with an algebraic one ("sum of multipliers must be exactly 3"). This forces the model to deduce the inequality structurally rather than triggering on bipartite keywords like "segregation" or "two environments".
</RATIONALE>
<PRESERVED_ANSWER>
The domain of values is identical ({1, 2}), the constraint $x+y=3$ is mathematically identical to $x \neq y$ for these values, and the lexicographical tie-breaking rule is exactly the same, ensuring identical outputs for all inputs.
</PRESERVED_ANSWER>
