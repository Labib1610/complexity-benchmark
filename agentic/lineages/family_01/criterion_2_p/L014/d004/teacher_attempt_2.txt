<STATEMENT>
# Portfolio Diversification Strategy

Time limit: 1 s   Memory limit: 256 MB

You are a quantitative analyst constructing investment vehicles from a pool of $n$ distinct financial assets, numbered 1 through $n$. Your firm offers exactly two investment funds, designated by the integers 1 and 2. Every asset must be placed into exactly one of these two funds.

Risk analysis has identified $m$ structural dependencies within the asset pool. To maintain regulatory compliance, these dependencies are modeled as strict arithmetic constraints on the assignments: for each identified dependency involving two assets, the sum of their assigned fund numbers must be an odd integer.

The firm's automated trading system requires the final asset allocation to be strictly deterministic. To resolve situations where multiple valid allocations satisfy all dependencies, the system evaluates them using a theoretical cost model. In this model, each asset $i$ carries a penalty weight of $2^{n-i}$. The total penalty of an allocation is defined as the sum of the penalty weights of all assets that are placed into fund 2. The system mandates the unique valid allocation that strictly minimizes this total penalty.

If the dependencies are so entangled that no valid allocation exists, you must reject the pool entirely.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$) — the number of assets and the number of structural dependencies.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a dependency between asset $u$ and asset $v$.

## Output
If no valid allocation is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers (each either 1 or 2, separated by spaces) — the valid allocation that satisfies the system's deterministic tie-breaking rule.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the description of the tie-breaking rule from a sequential filtering process to a mathematical penalty function using powers of 2. This removes the obvious procedural hint to iterate sequentially and assign fund 1 to the first unassigned asset, forcing the model to deduce that minimizing this sum of powers of 2 is equivalent to lexicographical preference.
</RATIONALE>
<PRESERVED_ANSWER>
Because the sum of all subsequent penalty weights is strictly less than the current weight ($2^{n-i} > \sum_{j=i+1}^n 2^{n-j}$), avoiding fund 2 at the smallest possible index $i$ strictly dominates all later choices, making the minimum penalty allocation exactly identical to the lexicographically first valid allocation.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains 2-coloring (bipartite checking), solvable in linear time by running BFS/DFS and aggressively assigning color 1 to the lowest-indexed unvisited node of each component.
</PRESERVED_CLASS>
<RISK>
Models might mistakenly attempt to compute the $2^{n-i}$ penalties using arbitrary-precision arithmetic and encounter memory or time limits, but this is a failure of algorithmic reasoning, not an ambiguity in the problem text.
</RISK>
