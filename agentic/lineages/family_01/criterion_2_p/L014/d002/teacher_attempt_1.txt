# Portfolio Diversification Strategy

Time limit: 1 s   Memory limit: 256 MB

You are a quantitative analyst constructing investment vehicles from a pool of $n$ distinct financial assets, numbered 1 through $n$. Your firm requires every asset to be assigned a leverage factor, which must be chosen as either 1 or 2.

Risk analysis has highlighted $m$ pairs of assets that exhibit extreme market correlation. To ensure proper diversification and mitigate catastrophic losses, the combined risk of these pairs must be strictly controlled. Specifically, for every highlighted pair, the sum of the leverage factors assigned to the two assets must be exactly 3.

The firm's automated trading system requires the final leverage assignment to be strictly deterministic. If there are multiple valid ways to assign leverage factors while controlling the risk of all highlighted pairs, the system requires the lexicographically smallest assignment. (An assignment is represented as a sequence of $n$ integers, where the $i$-th integer is the leverage factor assigned to asset $i$. A sequence $A$ is lexicographically smaller than sequence $B$ if $A$ has a smaller value at the first position where they differ.)

If the correlation constraints are so entangled that no valid assignment exists, you must reject the pool entirely.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$) — the number of assets and the number of highly correlated pairs.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that asset $u$ and asset $v$ are highly correlated and their combined leverage factor must be exactly 3.

## Output
If no valid assignment is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers (each either 1 or 2) — the lexicographically smallest valid leverage assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit mention of "two funds" and assets being "separated" or "not in the same fund" immediately triggered bipartite coloring templates for the models. I replaced this with an algebraic constraint: assets are assigned a value of 1 or 2, and constrained pairs must sum to exactly 3. This forces the model to deduce that the values must be different, breaking the surface-level keyword association with graph coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The domain of allowed values is {1, 2}, and the only way two variables from this domain can sum to 3 is if they are distinct (1 and 2), making the constraint logically identical to "cannot be assigned to the same fund".
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a valid 2-coloring of the graph (or determining it is not bipartite) and outputting the lexicographically smallest valid state, which remains solvable in O(n + m) time using BFS or DFS.
</PRESERVED_CLASS>
