# Magnetic Flux Stabilisation

Time limit: 1 s   Memory limit: 256 MB

You are programming the master control system for a prototype fusion reactor. The reactor contains $n$ magnetic confinement modules, numbered 1 through $n$. Each module must be calibrated to one of two polarities: 1 (positive) or 2 (negative).

The reactor's design includes $m$ flux tethers, each connecting a pair of modules. To prevent destructive interference, any two modules connected by a tether must operate with opposite polarities (one must be 1, and the other must be 2).

Because the tethers strictly constrain the system, there may be multiple valid ways to calibrate the entire reactor, or there may be none. The master control system requires a strictly deterministic calibration procedure. If multiple valid global configurations exist, the system filters them as follows:
It evaluates the modules in ascending order from 1 to $n$. For each module $i$, it looks at the pool of all currently remaining valid configurations. If this pool contains configurations where module $i$ is assigned polarity 1, and also configurations where module $i$ is assigned polarity 2, the system permanently discards all configurations where module $i$ has polarity 2. It continues this filtering process for each module in turn until a single, definitive configuration remains.

If the arrangement of tethers makes it impossible to assign polarities without violating the interference rule, you must trigger an abort sequence.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$) — the number of confinement modules and the number of flux tethers.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a tether between module $u$ and module $v$.

## Output
If no valid configuration is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers (each either 1 or 2, separated by spaces) — the final calibration configuration that satisfies the master control system's deterministic filtering.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
