# Portfolio Diversification Strategy

Time limit: 1 s   Memory limit: 256 MB

You are a quantitative analyst configuring a portfolio from a pool of $n$ distinct financial assets, numbered 1 through $n$. Each asset must be assigned a configuration state, output as either 1 or 2.

Risk analysis has flagged $m$ structural dependencies between certain pairs of assets. Regulatory rules dictate that any two assets linked by a dependency must be assigned asymmetric states. A dependency requires that if one asset is assigned state 1, the other must be assigned state 2. Any configuration where dependent assets share the same state is a regulatory violation.

The firm's automated trading system demands a strictly deterministic portfolio configuration. If multiple valid configurations satisfy all regulatory rules, the system filters them sequentially: it evaluates the assets in ascending order from 1 to $n$. For each asset $i$, if the pool of remaining valid configurations contains both state 1 and state 2 for asset $i$, the system permanently discards all configurations where asset $i$ is assigned state 2. This filtering proceeds through all $n$ assets until a single definitive configuration remains.

If the dependencies make it impossible to assign states without violating a rule, you must reject the pool entirely.

## Input
The first line contains two integers $n$ and $m$ — the number of assets and the number of structural dependencies. 
The firm operates exactly 200 server racks, each capable of hosting up to 1,000 asset profiles. The number of assets $n$ is a positive integer that will not exceed this total combined capacity. The dependency log is limited to the same maximum number of entries, meaning $m$ can range from zero up to this total capacity.
Each of the next $m$ lines contains two integers $u$ and $v$ (positive integers no greater than $n$), indicating a dependency between asset $u$ and asset $v$.

## Output
If no valid configuration is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers (each either 1 or 2, separated by spaces) — the valid configuration that satisfies the system's deterministic tie-breaking rule.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
