# Portfolio Diversification Strategy

Time limit: 1 s   Memory limit: 256 MB

You are a quantitative analyst structuring a portfolio from a pool of $n$ distinct financial instruments, identified by IDs 1 through $n$. Each instrument must be assigned a risk category of either 1 or 2.

Market analysis has revealed $m$ volatility linkages between specific pairs of instruments. To ensure balanced exposure, compliance mandates that any two instruments connected by a linkage must have their risk categories sum to exactly 3.

The firm's automated execution engine requires a strictly deterministic portfolio allocation. When multiple valid allocations satisfy all compliance mandates, the engine generates a signature for each by concatenating the assigned risk categories of instruments 1 through $n$ in order, forming a single $n$-digit integer. It then definitively selects the allocation that produces the smallest possible integer.

If the volatility linkages make it impossible to assign risk categories without violating a mandate, you must discard the instrument pool entirely.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$) — the number of instruments and the number of volatility linkages.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a linkage between instrument $u$ and instrument $v$.

## Output
If no valid allocation is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers (each either 1 or 2, separated by spaces) — the valid allocation that satisfies the engine's deterministic selection rule.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The previous statement explicitly described a sequential tie-breaking process looping from 1 to $n$, which models easily mapped to orienting connected components starting from their lowest-indexed node. I replaced this with a global minimization of an $n$-digit integer formed by concatenating the assignments. This forces models to deduce for themselves that minimizing the overall integer is equivalent to greedily minimizing the assignment for the lowest-indexed unvisited instrument.
</RATIONALE>
<PRESERVED_ANSWER>
Minimizing an $n$-digit integer where the most significant digits correspond to the lowest-indexed instruments is mathematically equivalent to the original lexicographical tie-breaking rule, ensuring the exact same configurations are selected.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem remains finding a valid assignment of 1s and 2s where linked elements differ, which is exactly 2-coloring/bipartite testing (solvable in O(n+m) time).
</PRESERVED_CLASS>
<RISK>
Models might struggle with the concept of an $n$-digit integer when $n=200,000$, but conceptually and mathematically it is perfectly well-defined and unambiguous for specifying a lexicographical ordering.
</RISK>
