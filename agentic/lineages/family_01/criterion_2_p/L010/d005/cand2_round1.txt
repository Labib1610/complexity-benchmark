# Problem B — Quadratic Resonance Configuration

Time limit: 1 s
Memory limit: 256 MB

A manufacturing plant operates a network of robotic assembly arms. The facility's control architecture requires at least 1 robotic arm and is designed to support up to 200,000 robotic arms. Each arm must be configured to an integer operational mode $s_i$, which must be chosen from the set $\{1, 2\}$. 

The facility has identified a number of directional workspace overlaps. The diagnostic system's buffer can store anywhere from 0 up to 200,000 overlap records. To avoid collisions, every overlap must pass a one-way diagnostic check. The diagnostic system evaluates an overlap from arm $u$ into the operating zone of arm $v$ using an asymmetric verification protocol. It analyzes the quadratic stability equation $s_u x^2 + s_v x + k = 0$. The overlap is considered safe if and only if there exists some odd integer $k$ (which can be positive or negative) such that this equation has at least one rational root $x$. Because the protocol is directional, the system strictly assigns the mode of the intruding arm to the $x^2$ coefficient and the mode of the receiving arm to the $x$ coefficient.

Determine a valid operational mode for each assembly arm so that all directional diagnostic checks are passed. If no such configuration exists, you must report it.

## Input
The first line contains two integers $n$ and $m$, representing the actual number of assembly arms and the number of directional overlaps, respectively. The bounds for these values are defined by the facility's control architecture and diagnostic buffer capacity described above.
Each of the next $m$ lines contains two integers $u$ and $v$ — indicating that the workspace of arm $u$ overlaps into the zone of arm $v$.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, followed by a second line containing $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$), representing the operational mode assigned to each arm. If multiple valid configurations exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
