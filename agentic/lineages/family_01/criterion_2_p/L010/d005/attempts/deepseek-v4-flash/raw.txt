We can model this as a graph problem. Each slot is a node, and each critical pair is an edge.  
The condition “combined mass must be exactly 300 grams” means that if one slot has type 1 (100g), the other must have type 2 (200g), and vice versa.  
So the graph must be bipartite, and the two parts correspond to type 1 and type 2.

We need to find the lexicographically smallest assignment of 1/2 to nodes such that every edge connects different types.

**Approach:**
- Build adjacency list.
- Try to 2-color the graph (BFS/DFS).
- If conflict → print `NO`.
- For lexicographically smallest, we assign colors greedily:  
  For each unvisited node, start with color 1, then propagate.  
  But if a node already has a color from a previous component, keep it.  
  This ensures smallest possible values at earliest indices.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]  # 1 -> 2, 2 -> 1
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
