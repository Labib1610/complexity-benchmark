We can model this as a bipartite graph problem.  
Each arm must be assigned mode 1 or 2, and for every edge (u, v), we need:

\[
s_u^2 + s_v^2 = 5
\]

Since \(s_u, s_v \in \{1, 2\}\), the only way to get 5 is one arm = 1 and the other = 2.  
So the graph must be bipartite, with one side all 1’s and the other all 2’s.

We also need the lexicographically smallest assignment, so we try to assign 1 as early as possible.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    # color 0 -> mode 1, color 1 -> mode 2
    # To get lexicographically smallest, we try to assign 1 to as many early nodes as possible.
    # Since bipartite coloring is unique per component up to swapping, we can choose orientation per component.
    # For each component, if the first node can be 1, do that.
    visited = [False] * n
    res = [0] * n
    for i in range(n):
        if not visited[i]:
            # BFS to collect component
            comp = []
            q = deque([i])
            visited[i] = True
            color[i] = 0
            comp.append(i)
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if not visited[v]:
                        visited[v] = True
                        color[v] = color[u] ^ 1
                        q.append(v)
                        comp.append(v)
            # Decide orientation: try to make smallest index in comp = 0 (mode 1)
            # If color[i] == 1, swap colors in this component
            if color[i] == 1:
                for node in comp:
                    color[node] ^= 1
    for i in range(n):
        res[i] = 1 if color[i] == 0 else 2
    print("YES")
    print(" ".join(map(str, res)))
```
