<STATEMENT>
# Gyroscopic Centrifuge Calibration

Time limit: 1 s   Memory limit: 256 MB

A research facility is setting up a high-speed centrifuge featuring $n$ sample chambers, indexed 1 to $n$. Every chamber requires the installation of a single balancing mass. Two variants of balancing masses are kept in stock: Variant 1 (weighing 100 grams) and Variant 2 (weighing 200 grams).

Because the equipment is vulnerable to harmonic oscillations, the vendor supplies a safety manifest containing $m$ interacting chamber pairs. To neutralize rotational resonance, the two balancing masses placed in any interacting pair must have a combined weight of precisely 300 grams. 

Your task is to find out whether a full assignment of balancing masses exists that respects all interaction requirements.

Whenever multiple safe assignments are possible, the system resolves the ambiguity using a sequential commitment protocol. Starting at chamber 1, the protocol checks if there is at least one entirely safe assignment where chamber 1 receives the lighter Variant 1 mass. If such an assignment exists, Variant 1 is permanently committed to chamber 1; if not, Variant 2 is committed. Proceeding to chamber 2, it again commits to Variant 1 if a completely safe assignment remains possible given the previous commitments. This chamber-by-chamber commitment process repeats in ascending index order until all $n$ chambers are locked in.

## Input
The first line provides the integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), indicating the number of sample chambers and the number of interacting pairs.
The subsequent $m$ lines each contain two integers $u$ and $v$ — a pair of chambers that must hold a combined mass of exactly 300 grams.

## Output
Print a single line containing `NO` if no safe balancing mass assignment exists.
If a safe assignment is possible, print `YES` on the first line. On the next line, output $n$ integers (each being either 1 or 2), specifying the variant numbers of the balancing masses chosen by the sequential commitment protocol.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit mention of "lexicographically smallest" acts as a strong pattern-matching trigger for models to just orient the first unvisited node of each component to 1. I removed this terminology, replacing it with a "sequential commitment protocol" that defines the exact same tie-breaking logic mechanically. To succeed efficiently, a model must now deduce that this sequential mechanism is mathematically equivalent to starting a component's traversal with Variant 1 at its lowest-indexed chamber.
</RATIONALE>
<PRESERVED_ANSWER>
The sequential commitment protocol iteratively prefers Variant 1 at the lowest available index, which is mathematically identical to finding the lexicographically smallest sequence of 1s and 2s.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem remains 2-coloring an undirected graph (since interacting pairs must have different masses to sum to 300), which requires linear time bipartiteness testing.
</PRESERVED_CLASS>
<RISK>
Models could misinterpret the commitment protocol as requiring a literal $O(n^2)$ sequential check rather than recognizing it as a structural property of the independent components, leading to Time Limit Exceeded, but the description of the rules itself is completely unambiguous.
</RISK>
