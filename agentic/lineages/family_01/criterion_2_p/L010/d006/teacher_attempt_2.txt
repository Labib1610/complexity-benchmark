# Gyroscopic Centrifuge Calibration

Time limit: 1 s   Memory limit: 256 MB

A laboratory is configuring a high-speed centrifuge with $n$ sample slots, numbered 1 through $n$. Each slot must be equipped with exactly one phase modulator. There are two available modulator modes: Mode 1 and Mode 2.

The centrifuge is highly sensitive to harmonic vibrations. The manufacturer has provided a list of $m$ critical slot pairs. For each critical pair of slots, their installed modulators must be configured to different modes to cancel out rotational resonance. 

You need to determine if there is a valid configuration of modulator modes for all $n$ slots that satisfies every critical pair requirement.

If a valid configuration exists, you must provide it. The configuration software prioritizes Mode 1 to conserve power. Specifically, it requires the configuration that is lexicographically smallest when represented as a sequence of modes (1s and 2s). A sequence $s_1, \dots, s_n$ is lexicographically smaller than another valid sequence $t_1, \dots, t_n$ if, at the first slot index $i$ where they differ, $s_i < t_i$.

## Input
The first line contains two integers $n$ and $m$. The physical design of the rotor dictates that the number of sample slots is at least one and at most two hundred thousand. The resonance diagnostic log can contain anywhere from zero to two hundred thousand critical pairs.
Each of the next $m$ lines contains two integers $u$ and $v$ — a critical pair of slots whose modulators must be set to different modes.

## Output
If there is no way to configure the centrifuge without violating the resonance constraints, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (each either 1 or 2), representing the lexicographically smallest valid modulator configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
