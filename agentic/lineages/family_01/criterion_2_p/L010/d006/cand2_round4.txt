# Day and Night Shifts

Time limit: 1 s
Memory limit: 256 MB

A factory employs $n$ workers. Each worker must be assigned to exactly one operational shift, chosen from the set $\{1, 2\}$.

The factory manager has identified $m$ pairs of workers who have a strict workspace conflict. To maintain a safe and peaceful working environment, any two workers involved in a conflict must be assigned to different shifts.

Determine a valid shift assignment for each worker so that all $m$ conflicts are avoided. If no such configuration exists, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of workers and the number of conflicts, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ — indicating that worker $u$ and worker $v$ have a conflict.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, followed by a second line containing $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$), representing the shift assigned to each worker. If multiple valid assignments exist, output the lexicographically smallest sequence $s_1\dots s_n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
