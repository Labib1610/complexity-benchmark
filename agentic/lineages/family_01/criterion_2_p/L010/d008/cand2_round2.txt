# Problem B — Harmonized Frequencies

Time limit: 1 s
Memory limit: 256 MB

A manufacturing plant operates $n$ robotic assembly arms, numbered $1$ to $n$. Each arm must be configured to an operational mode $s_i$, which must be chosen from the set $\{1, 2\}$.

The facility has identified $m$ instances of workspace overlap. Each overlap involves two arms $u$ and $v$. To avoid collisions, every overlap must pass a safety check. The diagnostic system evaluates the resonance between the overlapping arms. An overlap is considered safe if and only if their assigned modes satisfy the resonance condition:

$s_u^2 + 3s_us_v + s_v^2 = 11$

Determine a valid operational mode for each assembly arm so that all $m$ safety checks are passed. If no such configuration exists, you must report it.

To optimize the power grid's phase balance, the plant prioritizes assigning mode 1 to lower-numbered arms. Specifically, if multiple valid configurations exist, they are compared as follows:
Given two different valid configurations $A$ and $B$, let $M_A$ and $M_B$ be the sets of arm indices assigned to mode 1 in configurations $A$ and $B$, respectively. Identify the smallest arm index $k$ that is present in one set but not the other. The configuration that includes $k$ in its mode-1 set is strictly preferred. This comparison defines a strict preference between any two different valid configurations. You must output the single valid configuration that is preferred over all others.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of assembly arms and the number of overlaps, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that the workspace of arm $u$ overlaps with the workspace of arm $v$. The safety check applies to each listed overlap pair exactly once, and depends only on the assigned modes of that pair.

## Output
If no valid configuration exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$), representing the operational mode assigned to each arm. If there are multiple valid configurations, you must output the exact configuration that is preferred according to the phase balance rule described above.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The seed problem's objective (minimizing a base-3 polynomial) was exactly equivalent to finding the lexicographically smallest sequence of modes. Models recognized the polynomial structure and immediately used a greedy shortcut: orienting each bipartite component such that its lowest-indexed vertex gets mode 1. I replaced this objective with a set-symmetric-difference comparison rule that is mathematically identical to lexicographical minimization but avoids positional math triggers. This forces models to either deduce the lexicographical equivalence to apply the shortcut, or simulate the comparison on all valid states (which will TLE). I also obfuscated the $s_u \neq s_v$ condition using a quadratic form that evaluates to 11 only for distinct modes in $\{1, 2\}$.
</RATIONALE>
<PRESERVED_ANSWER>
The new resonance equation is satisfied if and only if $s_u \neq s_v$ for $s_i \in \{1, 2\}$, matching the seed's constraint, and the set-comparison tie-break rule is mathematically identical to selecting the lexicographically smallest mode sequence, preserving the exact target configuration.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartite checking) with the same greedy component-orientation tie-break, keeping it firmly in P.
</PRESERVED_CLASS>
<RISK>
Models might theoretically misinterpret "smallest arm index $k$" as applying to the size of the set rather than the integer identifier of the arm, though "arm index" strongly implies the assigned number $1 \dots n$.
</RISK>
