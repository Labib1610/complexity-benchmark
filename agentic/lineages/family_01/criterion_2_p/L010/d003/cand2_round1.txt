<STATEMENT>
# Problem B — Harmonized Frequencies

Time limit: 1 s
Memory limit: 256 MB

A manufacturing plant operates $n$ robotic assembly arms. The facility has exactly 200 production lines, each capable of housing up to 1,000 arms, meaning the total number of arms $n$ can be anywhere from $1$ up to full capacity.

Each arm $i$ (where $1 \le i \le n$) must be configured to an integer operational frequency multiplier $s_i$. The safety protocol mandates that each multiplier must be a positive integer root of the equation $x^2 - 3x + 2 = 0$.

The facility has identified $m$ specific pairs of arms that share physical workspace. The collision-detection system allocates memory for these shared workspace pairs. It reserves 8 bytes per pair, and its buffer size is exactly 1,600,000 bytes, allowing it to track anywhere from $0$ up to the maximum number of pairs that fit in the buffer.

To avoid resonant vibrations that lead to collisions, the calibration matrix for any two arms sharing a workspace (with multipliers $a$ and $b$) is defined as a $2 \times 2$ grid with the first row being $[a, b]$ and the second row being $[b, a]$. The setup is considered stable if and only if this calibration matrix is invertible.

Determine a valid frequency multiplier for each assembly arm so that all shared workspace constraints are satisfied. If no such configuration exists, you must report it.

## Input
The first line contains two integers $n$ and $m$, representing the number of assembly arms and the number of shared workspace pairs, respectively. The values of $n$ and $m$ will not exceed the full capacity limits derived from the facility's production lines and memory buffer.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of arms that share physical workspace.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, followed by a second line containing $n$ integers $s_1 \dots s_n$, representing the frequency multiplier assigned to each arm. If multiple valid configurations exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit set $\{1, 2\}$ was replaced with the roots of $x^2 - 3x + 2 = 0$. The direct arithmetic interference rule ($a^b + b^a = 3$) was replaced with the invertibility of the matrix $[[a,b],[b,a]]$. This forces the solver to evaluate the matrix determinant ($a^2 - b^2 \neq 0$) over the allowed roots to deduce that sharing arms must have different multipliers ($a \neq b$). Furthermore, explicit numerical bounds were removed and replaced with physical and memory capacities that precisely multiply and divide out to $2 \cdot 10^5$.
</RATIONALE>
<PRESERVED_ANSWER>
The allowed multipliers are still exactly 1 and 2, and the invertibility requirement mathematically simplifies to $a \neq b$, meaning every valid assignment and the lexicographical tie-breaking rule are completely unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness checking) of an undirected graph, which is solvable in $O(n+m)$ time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
A model might fail to deduce the exact $2 \cdot 10^5$ bounds from the capacity text, though the arithmetic ($200 \times 1000$ and $1600000 / 8$) is standard and unambiguous.
</RISK>
