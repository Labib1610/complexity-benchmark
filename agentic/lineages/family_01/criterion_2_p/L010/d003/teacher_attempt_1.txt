# Synchronous Telemetry Routing

Time limit: 1 s   Memory limit: 256 MB

A hardware designer is configuring routing paths for a set of distinct telemetry signals, numbered sequentially starting from 1. The hardware architecture supports a maximum capacity of two hundred thousand telemetry signals. A deployment will consist of $n$ signals, where $n$ is at least 1 and bounded by this maximum capacity. Each signal must be assigned to either routing path 1 or routing path 2.

Due to physical trace layouts, certain pairs of signals are cross-linked. The number of such cross-linked pairs, $m$, can be anywhere from zero up to the same maximum capacity limit. To ensure signal integrity, any two signals that are cross-linked must be configured such that the sum of their assigned routing path identifiers is exactly 3. You are provided with the list of these cross-linked pairs.

Your objective is to determine if a valid path assignment can be established for all $n$ signals.

If a valid configuration is possible, you must output the specific path assigned to each signal. The firmware defaults to prioritizing path 1 for lower-numbered signals. Formally, you must output the lexicographically smallest sequence of path assignments. A sequence of assignments $s_1, \dots, s_n$ is lexicographically smaller than another valid sequence $t_1, \dots, t_n$ if, at the first signal index $i$ where they differ, $s_i < t_i$.

## Input
The first line contains two integers $n$ and $m$, representing the number of telemetry signals and the number of cross-linked pairs. The values of $n$ and $m$ conform to the hardware limits described above.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of signals that are cross-linked.

## Output
If it is impossible to assign routing paths to all signals under these conditions, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid sequence of path assignments.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

Additionally, removed the bare numeric inequalities for $n$ and $m$, instead defining them through the system's spelled-out physical capacity limit of two hundred thousand. This forces the model to read the text carefully to extract the bounds and deduce that the sum constraint is functionally a strict inequality check.
</RATIONALE>
<PRESERVED_ANSWER>
Constraining two variables chosen from {1, 2} to sum to 3 is mathematically identical to requiring that they take different values, meaning the set of valid assignments and the lexicographically smallest valid sequence are exactly unchanged.
