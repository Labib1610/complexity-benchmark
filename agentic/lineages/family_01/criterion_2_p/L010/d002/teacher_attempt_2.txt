# Synchronous Telemetry Routing

Time limit: 1 s   Memory limit: 256 MB

A hardware designer is configuring a synchronous data bus for $n$ distinct telemetry signals, numbered 1 to $n$. The system operates using a double data rate architecture, meaning every signal must be scheduled to transmit on either the primary clock phase (Phase 1) or the secondary clock phase (Phase 2).

Due to physical trace layouts, certain pairs of signals share a multiplexer channel. If two signals sharing a channel are scheduled for the same clock phase, a data collision will occur. Therefore, they must be scheduled on different clock phases. You are provided with $m$ such channel-sharing pairs.

Your objective is to determine if a collision-free schedule can be established for all $n$ signals.

If a valid configuration is possible, you must output the specific phase assignment for each signal. The firmware defaults to prioritizing the primary clock phase for lower-numbered signals. Formally, you must output the lexicographically smallest sequence of phase assignments. A sequence of assignments $s_1, \dots, s_n$ is lexicographically smaller than another valid sequence $t_1, \dots, t_n$ if, at the first signal index $i$ where they differ, $s_i < t_i$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of telemetry signals and the number of channel-sharing pairs.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of signals that share a multiplexer channel and thus require different clock phases.

## Output
If it is impossible to schedule all signals without a collision, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid phase schedule.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

I changed the scenario from storing chemical compounds in two facilities to scheduling telemetry signals on two clock phases in a double data rate architecture. This removes the "two groups/sets" framing commonly associated with bipartiteness and replaces it with a scheduling constraint, forcing the model to deduce that mutually exclusive temporal assignments form a 2-coloring problem.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to assign each item one of two states and ensure given pairs have different states is logically identical to the seed, and the tie-breaking rule uses the exact same lexicographical comparison, guaranteeing identical outputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring of an undirected graph and picking the lexicographically smallest valid assignment, which is solved in O(n+m) time using Breadth-First Search.
</PRESERVED_CLASS>
