# Reactive Compound Storage

Time limit: 1 s   Memory limit: 256 MB

A pharmaceutical company is managing $n$ newly synthesized chemical compounds, numbered 1 to $n$. The central inventory database accommodates a maximum of 200,000 compounds, and there is always at least one compound to manage.

To ensure stability, each compound must be configured with a specific magnetic polarity, taking a value of either 1 or 2.

Through preliminary testing, the safety team has identified $m$ pairs of compounds that are highly reactive with each other. The testing log can record up to 200,000 reactive interactions, though it is possible for the log to be completely empty. To maintain equilibrium, any two compounds that form a reactive pair must be assigned strictly different polarities.

Your task is to determine whether it is possible to assign a polarity to every compound such that no reactive pair shares the same polarity.

If a safe configuration exists, you must provide it. Because there are multiple ways to distribute the polarities safely, the logistics department prefers the plan that assigns as many low-numbered compounds to polarity 1 as possible. Formally, you must output the lexicographically smallest sequence of polarity assignments. A sequence of assignments $s_1, \dots, s_n$ is lexicographically smaller than another valid sequence $t_1, \dots, t_n$ if, at the first compound index $i$ where they differ, $s_i < t_i$.

## Input
The first line contains two integers $n$ and $m$, representing the number of compounds and the number of reactive pairs. The values of $n$ and $m$ are guaranteed to respect the database and testing log capacities described above.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of compounds that will react if configured with the same polarity.

## Output
If there is no way to safely assign all compounds to polarity 1 and polarity 2, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
