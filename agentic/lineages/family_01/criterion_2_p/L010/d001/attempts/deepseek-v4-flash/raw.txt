We can model this as a bipartite graph problem: each arm is a node, and each shared workspace pair is an edge.  
The condition “product of frequencies is exactly 2” means one arm must be 1 and the other 2.  
So we need to 2-color the graph (bipartite check). If it’s not bipartite, output `NO`.  
For lexicographically smallest assignment, we assign 1 to the smallest-index node in each connected component, then BFS/DFS to color the rest.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    print(" ".join(str(c) for c in color))
```
