We can model this as a bipartite graph problem.  
If the graph is not bipartite, it’s impossible → print `NO`.  
Otherwise, we need the lexicographically smallest assignment, meaning we try to assign as many low-numbered nodes as possible to Facility 1.

We can do this by running BFS/DFS with a greedy coloring:  
- For each unvisited node, start by assigning it to Facility 1.  
- Then color its neighbors with the opposite facility, and so on.  
- If a conflict occurs, the graph is not bipartite.

This greedy approach gives the lexicographically smallest assignment because we always try to put the smallest unassigned node into Facility 1.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 0
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
