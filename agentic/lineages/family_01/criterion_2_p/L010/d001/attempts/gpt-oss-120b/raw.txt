**Solution Explanation**

For every arm we have to choose a frequency multiplier `1` or `2`.
For every given pair `(u , v)` the product must be `2`, therefore the two
multipliers have to be different:

```
            1 • 2   or   2 • 1
```

So the whole problem is exactly the same as

*colour the vertices of an undirected graph with two colours
(1 and 2) such that every edge connects vertices of different colours.*

That is the classic *bipartite‑graph* test.



--------------------------------------------------------------------

#### 1.   Graph model
* vertices – arms `1 … n`
* edges    – the `m` given pairs

The graph must be bipartite, otherwise the answer is **NO**.



--------------------------------------------------------------------

#### 2.   Lexicographically smallest feasible assignment
In a bipartite connected component the two colourings are unique up to a
global swap (`1 ↔ 2`).  
Let  

```
C = set of vertices of one component,
i = smallest vertex index in C          ( i = min(C) )
```

At position `i` the answer can be only `1` or `2`.  
Choosing `1` is always better for the whole lexicographic order,
because all earlier positions are fixed already
(they belong to other components).

Hence for **each component** we simply orient the two colour classes
so that the smallest index vertex gets colour `1`.  
All other vertices of this component are forced then.

Isolated vertices are components of size `1`; they receive colour `1` as
well – the optimal choice.



--------------------------------------------------------------------

#### 3.   Algorithm
```
read n , m
build adjacency list

color[v] = -1 for all v                # temporary 0/1 parity
answer[v] = 0                          # final 1/2 values

for v = 1 … n
        if color[v] already set : continue
        start BFS/DFS from v
                set color[v] = 0
                collect all vertices of this component in list comp
                while queue not empty
                        cur = pop
                        for each neighbour nxt of cur
                                if color[nxt] == -1
                                        color[nxt] = color[cur] xor 1
                                        push nxt
                                else if color[nxt] == color[cur]
                                        graph is not bipartite → print NO

        # component finished, decide orientation
        i = min(comp)                     # smallest index in this component
        parity_i = color[i]               # 0 or 1
        for each vertex x in comp
                if color[x] == parity_i   # same side as i
                        answer[x] = 1
                else
                        answer[x] = 2

print YES
print answer[1] … answer[n] separated by blanks
```

*BFS* (or DFS) visits each vertex once, each edge twice → `O(n+m)` time,  
`O(n+m)` memory for the adjacency list and the auxiliary arrays.



--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints **NO** iff a feasible assignment does
not exist, otherwise it prints **YES** and the lexicographically smallest
assignment.

---

##### Lemma 1  
During the BFS of a component the algorithm assigns a parity `0/1` to every
visited vertex and never assigns the same parity to the two ends of an edge
iff the component is bipartite.

**Proof.**  
The BFS colours the start vertex `0`. Every traversed edge
`(a,b)` forces `color[b] = color[a] xor 1`.  
If an already coloured neighbour has the same colour as the current vertex,
an odd cycle is discovered – the component is not bipartite.
If the BFS finishes without such a conflict, every edge connects opposite
parities, i.e. the component is bipartite. ∎



##### Lemma 2  
If the algorithm prints **NO**, no assignment satisfying the constraints
exists.

**Proof.**  
**NO** is printed only when Lemma&nbsp;1 finds an edge whose ends would obtain
the same parity, i.e. the graph contains a non‑bipartite component.
Any feasible assignment would need two different numbers (`1` and `2`) on
both ends of this edge, which is impossible because only two numbers are
available. Hence no feasible assignment exists. ∎



##### Lemma 3  
Assume the graph is bipartite.  
For a processed component `C` let `i = min(C)` and `p = color[i]`
(the parity obtained by the BFS).  
Setting `answer[x]=1` for all vertices `x` with `color[x]=p` and `2`
otherwise satisfies all constraints inside `C`.

**Proof.**  
All edges of `C` connect vertices of opposite BFS parity.  
By the definition above both ends receive different final values (`1` vs `2`);
therefore the product on every edge equals `2`. ∎



##### Lemma 4  
For a bipartite graph the assignment produced by the algorithm is
lexicographically smallest among all feasible assignments.

**Proof.**  
Consider the components in increasing order of their smallest vertex.
Take a component `C` with smallest vertex `i`.  
All vertices with index `< i` belong to earlier components, already fixed.
In any feasible global assignment vertex `i` can only be `1` or `2`
(because its neighbour(s) must have the opposite value).
The algorithm chooses the orientation that gives `answer[i]=1`.
Thus at the first position where any feasible assignment can differ from the
algorithm’s assignment, the algorithm has the smaller value.
Consequently no other feasible assignment can be lexicographically smaller. ∎



##### Lemma 5  
If the graph is bipartite, the algorithm outputs **YES** and a feasible
assignment.

**Proof.**  
Bipartiteness guarantees that Lemma&nbsp;1 never aborts, therefore the
algorithm reaches the end and prints **YES**.
By Lemma&nbsp;3 each component’s internal edges are satisfied.
Since components are disjoint, all edges of the whole graph are satisfied.
All assigned numbers belong to `{1,2}`. ∎



##### Theorem  
The algorithm

* prints **NO** iff no feasible assignment exists,
* otherwise prints **YES** followed by the lexicographically smallest
  feasible assignment.

**Proof.**  
*If* the algorithm prints **NO**, by Lemma&nbsp;2 no feasible assignment
exists.  
*If* it prints **YES**, the graph is bipartite, Lemma&nbsp;5 gives a feasible
assignment, and Lemma&nbsp;4 guarantees its lexicographic minimality. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis

*Time* : each vertex and each edge is processed a constant number of times  

```
O(n + m)      ≤ 4·10⁵   (well inside 1 s)
```

*Memory* : adjacency list `O(n + m)` plus three integer arrays of size `n+1`

```
O(n + m)      ≤ about 5·10⁵ integers  ( < 256 MB )
```

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    n = next(it)
    m = next(it)

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = next(it); v = next(it)
        adj[u].append(v)
        adj[v].append(u)

    parity = [-1] * (n + 1)          # temporary 0/1 colours
    answer = [0] * (n + 1)           # final 1/2 values

    for start in range(1, n + 1):
        if parity[start] != -1:
            continue
        # BFS of one component
        q = deque([start])
        parity[start] = 0
        comp = [start]
        while q:
            v = q.popleft()
            pv = parity[v]
            for to in adj[v]:
                if parity[to] == -1:
                    parity[to] = pv ^ 1
                    q.append(to)
                    comp.append(to)
                elif parity[to] == pv:
                    # not bipartite
                    sys.stdout.write("NO")
                    return

        # orient so that smallest index gets value 1
        min_v = min(comp)
        want = parity[min_v]          # parity that must become 1
        for v in comp:
            answer[v] = 1 if parity[v] == want else 2

    # all components processed successfully
    out_lines = ["YES", " ".join(str(answer[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
