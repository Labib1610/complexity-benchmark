# Voltage Balancing

Time limit: 1 s   Memory limit: 256 MB

A power facility is deploying a network of modules. Each module must be assigned a continuous voltage state, which must be set to either 1 or 2.

Certain pairs of modules are connected by a load balancer. To prevent an overload, any load balancer requires the two modules it connects to have a combined voltage state of exactly 3. If their combined voltage state is not 3, the balancer will fail.

You are given a list of pairs of modules connected by balancers. Your task is to determine whether it is possible to assign a voltage state to every module such that all balancers are stable. 

If a valid configuration exists, you must provide it. Because there may be multiple stable configurations, the facility requires the lexicographically smallest sequence of voltage states. A sequence of voltage states $s_1, \dots, s_n$ is lexicographically smaller than another valid sequence $t_1, \dots, t_n$ if, at the first module index $i$ where they differ, $s_i < t_i$.

The facility contains a positive number of modules, $n$. The maximum physical capacity of the facility is two hundred thousand modules, meaning $n$ will never exceed this maximum capacity. The number of balancers, $m$, can be as low as zero, and its upper limit is exactly equal to the facility's maximum module capacity.

## Input
The first line contains two integers $n$ and $m$, representing the number of modules and the number of balancers. The values of $n$ and $m$ conform to the facility limits described above.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of modules connected by a balancer.

## Output
If there is no way to assign voltage states 1 and 2 to all modules without causing balancer failures, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid voltage assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Removed the direct mention of "interfering" and "sharing the same channel". Instead, the problem is framed as assigning values 1 or 2 such that connected pairs sum to 3. This forces the model to deduce that $x+y=3$ with $x,y \in \{1,2\}$ implies inequality, masking the standard 2-coloring/bipartite graph affordances. Additionally, numeric constraints are moved from bare inequalities in the Input section to descriptive text in the prose.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that two connected values in {1,2} sum to 3 is mathematically identical to requiring them to be unequal, preserving the exact same valid configurations and lexicographical tie-breaking.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in linear time using BFS/DFS, placing it in P.
</PRESERVED_CLASS>
