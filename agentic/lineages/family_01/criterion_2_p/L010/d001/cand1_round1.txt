<STATEMENT>
# Problem B — Assembly Calibration

Time limit: 1 s   Memory limit: 256 MB

A manufacturing plant operates $n$ robotic assembly arms. Each arm must be assigned a frequency multiplier of either $1$ or $2$. 

There are $m$ pairs of arms that have overlapping physical motion ranges. To avoid resonant interference, any pair of arms with overlapping ranges must be calibrated such that the product of the frequency multipliers of those two arms is exactly $2$. 

Assign a frequency multiplier to each assembly arm such that this condition is satisfied for all overlapping pairs, or report that no such assignment exists. 

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of assembly arms and the number of overlapping pairs, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of arms with overlapping motion ranges.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, followed by a second line containing $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$), representing the frequency multiplier assigned to each arm. If multiple valid assignments exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit requirement to assign "different" states from a pool of two was replaced with an arithmetic constraint: the product of the two states must be exactly 2, where states are drawn from {1, 2}. This removes the linguistic affordance that models use to pattern-match the problem directly to 2-coloring/bipartite checking, forcing them to deduce that $a \times b = 2$ over the domain $\{1, 2\}$ implies $a \neq b$.
</RATIONALE>
<PRESERVED_ANSWER>
Constraining the values to exactly 1 or 2 and requiring their pairwise product to be 2 is mathematically identical to requiring that the two values be different, meaning the set of valid assignments and the lexicographically smallest assignment remain unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains identically equivalent to 2-coloring an undirected graph (which is solvable in $O(n+m)$ via BFS/DFS), as each connected component can still be independently validated and assigned alternating states.
</PRESERVED_CLASS>
