# Sensor Network Calibration

Time limit: 1 s   Memory limit: 256 MB

A municipal grid contains $n$ environmental monitoring stations. Each station must be calibrated to broadcast its data on exactly one of two available frequencies: band 1 or band 2.

Because of physical proximity, specific pairs of stations share overlapping broadcast radii. If any such pair is calibrated to the exact same band, their transmissions will overlap and corrupt the data. You are given a registry of $m$ overlapping station pairs. Your task is to find out if it is possible to calibrate the entire grid so that no two overlapping stations broadcast on the same band.

If a safe calibration exists, you must provide it. Since there can be multiple safe ways to calibrate the grid, the system requires the lexicographically smallest sequence of band assignments. A sequence of band assignments $s_1, \dots, s_n$ is lexicographically smaller than another safe sequence $t_1, \dots, t_n$ if, at the first station index $i$ where they differ, $s_i < t_i$.

## Input
The first line contains two integers $n$ and $m$. The number of stations $n$ represents a headcount of at least $1$ up to the grid's maximum capacity of $2 \cdot 10^5$. The registry size $m$ contains anywhere from $0$ up to a hard limit of $2 \cdot 10^5$ overlapping pairs.
Each of the next $m$ lines contains two integers $u$ and $v$ (valid station IDs from $1$ to $n$) — a pair of stations whose signals will corrupt each other if assigned the same band.

## Output
If there is no way to assign band 1 and band 2 to all stations without causing data corruption, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest safe band assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
