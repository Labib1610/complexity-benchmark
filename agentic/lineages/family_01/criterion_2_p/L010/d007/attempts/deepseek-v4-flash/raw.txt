We need to find modes for every node (1 or 2) that satisfy:  

For every edge (u, v),  

s_u³ + s_v³ = 9  

Since s can be 1 or 2:  
- 1³ + 2³ = 1 + 8 = 9  
- 2³ + 1³ = 9  
- 1 + 1 = 2 ≠ 9  
- 8 + 8 = 16 ≠ 9  

So every edge must connect one node with mode 1 and one with mode 2.  
That means the graph must be bipartite: assign 1 to one part, 2 to the other.  

If the graph is not bipartite → NO.  

If bipartite, there are two possible colorings (swap colors). We choose the one with minimum E = sum(s_i * 3^{n-i}), which means high-index nodes (near end) get smaller weights in the sum, so we want as many 1s at the end as possible.  

Actually, we need to minimize ∑ s_i * 3^{n-i}; this is equivalent to interpreting bits s_1 s_2 ... s_n as a base-3 number where digits are 1 or 2 (with position weights 3^{n-i}). The smaller E corresponds to choosing the coloring that has 1 for earlier nodes (smaller index) where possible, or to compare numeric values directly.

Comparing two assignments with same structure: Since positions at early i have huge weight, lexicographic comparison of the string (1 vs 2) from i=1 to n (in numeric sense because weight decreases with i) is correct: the first position where they differ decides.

But since in bipartite there are exactly two assignments, we can compute both with string compare to pick the lexicographically smaller (with 1 < 2), because 3^{n-i} for earlier i dominates all later combined (since 3^{n-i} > sum_{j>i} 3*3^{n-j}? Actually sum of later weights is less than a single earlier weight since 3^{n-i} > sum_{k=i+1}^n 2*3^{n-k}? Might check: 3^{n-i} vs sum: geometric with ratio 3, terms: maximum sum later with 2 each: sum_{k=i+1} ∞ ≤ 2* (3^{n-i-1} + 3^{n-i-2}+...) = 2*3^{n-i-1}/(1 - 1/3) = 3^{n-i} exact? Actually sum = 2 * (3^{n-i-1})/(1-1/3)=2*3^{n-i-1}/(2/3)=3^{n-i}. So earlier dominates: if a position differs, the earlier decides regardless of later.

So we just pick the coloring that has s_1 as small as possible (1) if coloring allows; if s_1 = 1 in one coloring and 2 in the other, we pick that with 1. If both equal → same. So simply: choose coloring where node 1 gets 1 if possible; if not, then the opposite necessarily gives node 1 = 1? Actually bipartite has two components: for connected graph, swapping colors changes 1 to 2. For disconnected, each component has two possible swappings; to minimize lexicographically we want as many early nodes as possible to be 1. So we can independently choose for each connected component the part that gets 1 based on smallest index in that component. Because different components don't affect each other's coloring.

Algorithm:
- Build adjacency.
- BFS/DFS color each component with alternating 1/2.
- If conflict → NO.
- For each component, collect nodes; find the minimum index node in the component. If it got color 2 in initial arbitrary coloring, invert all colors in that component.
- Output colors.

Complexities O(n+m).

Now checking lexicographic: Since weights decrease exponentially, choosing the smallest min-index in component to have 1 yields minimum numeric E. Because earliest index among all components determines the most significant digit; similarly for each subsequent.

Thus solution:

```python
import sys
from collections import deque

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * n
    for i in range(n):
        if color[i] == -1:
            color[i] = 0
            q = deque([i])
            comp = [i]
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = color[u] ^ 1
                        q.append(v)
                        comp.append(v)
                    elif color[v] == color[u]:
                        print("NO")
                        return
            # decide orientation: smallest node in component should be 0
            mn = min(comp)
            if color[mn] == 1:
                for node in comp:
                    color[node] ^= 1

    print("YES")
    print(' '.join(str(c + 1) for c in color))

if __name__ == "__main__":
    solve()

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):

        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * n
    for start in range(n):
        if color[start] != -1:
            continue
        color[start] = 0
        q = deque([start])
        comp = [start]
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                    comp.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    return

        # Ensure the smallest index in this component is colored 0.
        # This yields the lexicographically smallest assignment.
        mn = min(comp)
        if color[mn] == 1:
            for node in comp:
                color[node] ^= 1

    print("YES")
    print(' '.join(str(c + 1) for c in color))

if __name__ == "__main__":
    solve()
