# Problem B — Harmonized Frequencies

Time limit: 1 s
Memory limit: 256 MB

A manufacturing plant operates $n$ robotic assembly arms. Each arm must be configured to an integer operational mode $s_i$, which must be chosen from the set $\{1, 2\}$. 

The facility has identified $m$ instances of workspace projection. To avoid collisions, every projection must pass a safety check. The diagnostic system evaluates the stability of the projection from arm $u$ into arm $v$ by computing a stability score $E$ using the formula:

$E = s_u^{s_v} + s_v$

A projection from arm $u$ into arm $v$ is considered safe if and only if its stability score $E$ is exactly 3. 

Determine a valid operational mode for each assembly arm so that all $m$ safety checks are passed. If no such configuration exists, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of assembly arms and the number of projections, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ — indicating that the workspace of arm $u$ projects into the workspace of arm $v$.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, followed by a second line containing $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$), representing the operational mode assigned to each arm. If multiple valid configurations exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

By framing the symmetric workspace overlaps as directional "projections" and using an algebraically asymmetric condition ($s_u^{s_v} + s_v = 3$), it baits models into representing the constraints as a directed graph. Models relying on surface pattern matching will perform directed traversals and fail to correctly propagate constraints across weakly connected components, missing the lexicographical minimization or falsely reporting NO. Models that genuinely analyze the equation will realize the valid pairs over $\{1, 2\}$ are purely $(1, 2)$ and $(2, 1)$, meaning the constraint is perfectly symmetric ($s_u \neq s_v$) and requires standard undirected bipartite coloring.
