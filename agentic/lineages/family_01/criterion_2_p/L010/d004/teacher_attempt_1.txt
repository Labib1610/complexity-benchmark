# Reactive Compound Storage

Time limit: 1 s   Memory limit: 256 MB

A logistics coordinator must assign $n$ industrial chemical compounds, numbered 1 through $n$, to one of two containment modes: Mode 1 and Mode 2. The inventory system allocates exactly 200,000 tracking slots, of which $n$ are currently active (there is always at least one active compound).

Due to off-gassing, certain pairs of compounds will create hazardous atmospheric conditions if they share the same containment mode. You are provided with a hazard registry logging $m$ such reactive pairs. The registry memory block supports up to 200,000 pair entries, and currently logs $m$ pairs (the registry may be completely empty). To maintain safety, any two compounds listed in a pair must be assigned differing containment modes.

Your task is to determine whether it is possible to securely configure all $n$ compounds without violating any safety restrictions.

If a safe configuration exists, you must provide the exact mode assignment for each compound. Company policy strongly prefers utilizing Mode 1 whenever possible, especially for compounds with lower identification numbers. Formally, you must output the lexicographically smallest valid sequence of mode assignments. A sequence of assignments $s_1, \dots, s_n$ is lexicographically smaller than another valid sequence $t_1, \dots, t_n$ if, at the first compound index $i$ where they differ, $s_i < t_i$.

## Input
The first line contains two integers $n$ and $m$, representing the number of compounds and the number of hazardous pairs.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of compounds that cannot share the same containment mode.

## Output
If it is impossible to securely configure all compounds, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid mode assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
