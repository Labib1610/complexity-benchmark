# Problem B — Harmonized Frequencies

Time limit: 1 s
Memory limit: 256 MB

A manufacturing plant operates $n$ robotic assembly arms. Each arm must be configured to an integer operational mode $s_i$, which must be chosen from the set $\{1, 2\}$. 

The facility has identified $m$ specific directed transmission protocols. Each protocol involves a laser emitter on arm $u$ sending a synchronization beam to a sensor on arm $v$. To prevent frequency interference, the transmitting arm and the receiving arm of every protocol must pass a joint diagnostic check.

The diagnostic system runs a digital handshake for each protocol. It initializes a test registry with the value 29. First, the emitting arm takes its operational mode, multiplies it by 14, and bitwise XORs the result into the registry. Then, the receiving arm takes its operational mode, multiplies it by 14, and bitwise XORs that result into the registry. The diagnostic check passes if and only if the final value of the registry is exactly 15.

Determine a valid operational mode for each assembly arm so that all $m$ directed transmission diagnostic checks are passed. If no such configuration exists, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of assembly arms and the number of directed transmission protocols, respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ — indicating a protocol where the emitter on arm $u$ transmits to the sensor on arm $v$.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, followed by a second line containing $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1,2\}$), representing the operational mode assigned to each arm. If multiple valid configurations exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

I replaced the explicit divisibility condition with a sequential bitwise XOR diagnostic check that evaluates to exactly the same bipartite constraint ($s_u \neq s_v$). More importantly, I reframed the shared workspace pairs as "directed transmission protocols" (emitter to sensor). Models that rely on surface pattern matching will parse the "directed" terminology and sequential wording to build a directed graph. Consequently, they will fail to propagate the symmetric constraints backwards during their graph traversal, leading to incorrect assignments or false negatives on hidden tests. Genuinely reasoning models will recognize that the XOR check is commutative, making the constraint symmetric, and will correctly build an undirected graph.
