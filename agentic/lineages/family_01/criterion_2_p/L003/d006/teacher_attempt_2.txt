# Problem B — Orbital Relays

Time limit: 1 s   Memory limit: 256 MB

An orbital communications grid consists of $n$ satellites, numbered 1 through $n$. Each satellite requires a transmission mode, which must be selected from two available options, designated by the integers 1 and 2.

The grid includes $m$ sectors of spatial overlap. Each sector is a region where the broadcast areas of two distinct satellites intersect. To prevent signal resonance, a vital operational constraint applies to any two satellites sharing an overlap sector: the product of their chosen mode integers must be exactly 2.

Your task is to find a valid mode selection for all $n$ satellites that respects this constraint across all $m$ sectors. If the grid cannot be configured safely, you must indicate that it is impossible.

The grid's infrastructure limits the total number of satellites to two hundred thousand. The number of overlap sectors can reach the same upper limit. The grid will always contain at least one satellite, though it might have zero overlap sectors.

## Input
The first line contains two integers $n$ and $m$, representing the number of satellites and the number of overlap sectors. These values conform to the infrastructure limits mentioned above.
Following this are $m$ lines, each containing two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that satellite $u$ and satellite $v$ share an overlap sector.

## Output
If it is impossible to configure the grid safely, output a single line containing NO.
If a valid configuration is possible, print YES on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1, 2\}$), representing the lexicographically smallest sequence of modes that satisfies the operational constraint.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit "sum to 3" rule was replaced with "product must be exactly 2". This is mathematically equivalent over the domain {1, 2} but evades surface-level pattern matching for bipartite coloring. Additionally, numeric bounds are now described through textual infrastructure limits (Strategy S07), forcing the model to read and derive the constraints rather than simply parsing inequalities.
</RATIONALE>
<PRESERVED_ANSWER>
Because the only possible values assigned to a satellite are 1 and 2, the requirement that the product of two adjacent satellites is exactly 2 strictly forces one to be 1 and the other to be 2, which is logically identical to requiring their sum to be 3.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) on an undirected graph, solvable in O(n+m) using BFS or DFS.
</PRESERVED_CLASS>
