# Problem B — Loom Layering

Time limit: 1 s
Memory limit: 256 MB

An industrial loom produces a composite mesh using $n$ continuous warp fibers, indexed from 1 to $n$. To ensure structural integrity, the loom operates exactly two tension layers, designated as layer 1 and layer 2. Each fiber must be permanently routed through exactly one of these two layers for its entire length.

The mesh design specifies $m$ crossing points. Each crossing point defines a location where two specific fibers must interlock. An interlock is only physically possible if the two crossing fibers are separated vertically. Specifically, for every crossing point involving fiber $u$ and fiber $v$, they must be assigned to different layers.

You must determine if there is a valid layer routing for all $n$ fibers that successfully forms all $m$ crossing points. If no such routing exists, the design is invalid.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of fibers and the number of crossing points.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating a crossing point between fiber $u$ and fiber $v$.

## Output
If the design cannot be woven, print `NO` on a single line.
If a valid routing exists, print `YES` on the first line. On the second line, print $n$ integers $r_1 \dots r_n$ (where each $r_i \in \{1, 2\}$), representing the lexicographically smallest sequence of layer assignments that satisfies all interlock requirements.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
