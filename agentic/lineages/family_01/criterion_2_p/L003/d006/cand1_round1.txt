# Problem B — System Configuration

Time limit: 1 s   Memory limit: 256 MB

A cloud provider must configure the operation mode for $n$ database instances. The configuration requires assigning each instance $i$ ($1 \le i \le n$) an operation mode $s_i$, which must be chosen from the set $\{1, 2\}$.

Based on its chosen mode, each instance $i$ configures a 3-dimensional state vector $\vec{w}_i$:
- If $s_i = 1$, $\vec{w}_i = (3i - 1, 2i, 2)$.
- If $s_i = 2$, $\vec{w}_i = (3i + 5, 2i, 4)$.

Certain pairs of instances share a dedicated backup storage array. When two instances $u$ and $v$ share a backup array, the array synchronizes them. Let $x = \min(u, v)$ and $y = \max(u, v)$. The synchronization process uses a reference vector $\vec{r}_{x,y} = (3(x+y), 2(x+y), 0)$, and builds the $3 \times 3$ combined state matrix $C_{x,y}$ whose columns are exactly $\vec{w}_x$, $\vec{w}_y$, and $\vec{r}_{x,y}$ (in that order).

To maintain system stability, the backup array's resonance detector requires that the determinant of this combined matrix $C_{x,y}$ must not be equal to $0$. Specifically, if $\det(C_{x,y}) = 0$, the array will experience a feedback loop and synchronization will fail.

You must assign a mode to each instance to satisfy all stability constraints, or determine that no such configuration exists. If multiple valid configurations exist, the automated deployment system requires the configuration whose sequence of mode assignments $s_1 \dots s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of database instances and the number of shared backup arrays.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that instances $u$ and $v$ share a backup array.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The seed problem used an explicit involution matrix ($A^2 = I$), allowing models to trivially deduce that $M_u M_v = I$ is equivalent to $s_u = s_v$, instantly reducing the problem to bipartite graph coloring. This rewrite replaces the constant matrix with 3D state vectors that depend on the instance index, and defines the constraint via a $3 \times 3$ determinant. The determinant evaluates to exactly $0$ if the modes are the same, and $\pm 28(x+y)$ if they differ. To succeed, models must now either flawlessly expand a parameterized $3 \times 3$ determinant symbolically or write a dynamic constraint evaluator, forcing genuine algorithmic modeling rather than surface pattern matching.
</RATIONALE>
