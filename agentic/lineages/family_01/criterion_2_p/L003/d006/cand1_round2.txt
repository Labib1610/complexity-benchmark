# Problem B — System Configuration

Time limit: 1 s   Memory limit: 256 MB

A cloud provider must configure the operation mode for $n$ database instances. The configuration requires assigning each instance $i$ an operation mode $s_i$, which must be chosen from the set $\{1, 2\}$.

Each instance $i$ maintains a state transformation matrix $M_i$. Depending on its chosen mode $s_i$, the matrix is defined as:
- If $s_i = 1$, $M_i = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}$
- If $s_i = 2$, $M_i = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}$

Certain pairs of instances share a dedicated backup storage array. When two instances $u$ and $v$ share a backup array, the array synchronizes them by computing the product of their matrices.

To maintain system stability, the backup array's resonance detector requires that the product of their matrices (in either multiplication order, $M_u \times M_v$ or $M_v \times M_u$) must not be equal to the $2 \times 2$ zero matrix $Z = \begin{pmatrix} 0 & 0 \\ 0 & 0 \end{pmatrix}$. Specifically, if the product is $Z$, the array will experience a feedback loop and synchronization will fail.

You must assign a mode to each instance to satisfy all stability constraints, or determine that no such configuration exists. If multiple valid configurations exist, the automated deployment system requires the configuration whose sequence of mode assignments $s_1 \dots s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of database instances and the number of shared backup arrays.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that instances $u$ and $v$ share a backup array.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

I replaced the seed's involution base matrix with explicitly defined nilpotent matrices. This preserves the exact 2-coloring constraint ($C_{u,v} = Z \iff s_u = s_v$) while removing the $A^2 = I$ shortcut and matrix exponentiation that models relied on. It forces models to manually evaluate the new matrix products to discover the bipartite structure, defeating those that hardcode the seed's math, without introducing new linear algebra concepts that cause task drift.
</RATIONALE>
<PRESERVED_ANSWER>
The product of the matrices is the zero matrix if and only if the two instances have the same mode, exactly preserving the constraint that connected instances must have different modes.
</PRESERVED_ANSWER>
