Looking at this problem, I need to understand when the product of two matrices equals zero.

**Matrix analysis:**
- Mode 1: $M = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}$ — has nonzero entry at position (0,1)
- Mode 2: $M = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}$ — has nonzero entry at position (1,0)

For the product $M_u \times M_v$:
- The (i,j) entry is $\sum_k M_u[i][k] \cdot M_v[k][j]$
- This is nonzero only if there exists k where $M_u[i][k] \neq 0$ and $M_v[k][j] \neq 0$

**Case 1: Both mode 1** — $M_u$ has nonzero at (0,1), $M_v$ has nonzero at (0,1). For product, need $M_u[0][k] \cdot M_v[k][j] \neq 0$. Only $M_u[0][1]=1$, but $M_v[1][j]=0$ for all j. **Product = Z.**

**Case 2: Both mode 2** — Similarly, $M_u[1][0]=1$ but $M_v[0][j]=0$ for all j. **Product = Z.**

**Case 3: u mode 1, v mode 2** — $M_u[0][1]=1$ and $M_v[1][0]=1$, so product[0][0]=1. **Product ≠ Z.**

**Case 4: u mode 2, v mode 1** — $M_u[1][0]=1$ and $M_v[0][1]=1$, so product[1][1]=1. **Product ≠ Z.**

So the constraint is: **connected instances must have different modes**. This is a bipartite graph problem.

For lexicographically smallest: assign mode 1 to uncolored nodes, then mode 2 to neighbors, alternating. This greedy BFS/DFS approach gives the lexicographically smallest valid 2-coloring.

```python
import sys
from collections import deque

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * (n + 1)
    
    for start in range(1, n + 1):
        if color[start] == 0:
            color[start] = 1
            q = deque([start])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == 0:
                        color[v] = 3 - color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        print("NO")
                        return
    
    print("YES")
    print(' '.join(str(color[i]) for i in range(1, n + 1)))

solve()
```
