**Solution Explanation**

For a vertex `i` we have to choose a mode `s_i ∈ {1,2}`.
The two possible matrices are  

```
M(1) = [ [0,1],
         [0,0] ]

M(2) = [ [0,0],
         [1,0] ]
```

```
M(1)·M(1) = 0   (zero matrix)
M(2)·M(2) = 0
M(1)·M(2) = [ [1,0],
             [0,0] ] ≠ 0
M(2)·M(1) = [ [0,0],
             [0,1] ] ≠ 0
```

Therefore for every given edge `{u,v}` we must **avoid**
` s_u = s_v `.  
The problem becomes:

* colour the vertices of the given undirected graph with two colours
  (1 and 2) such that adjacent vertices have different colours,
* output the lexicographically smallest colour sequence,
* or report that it is impossible.

That is exactly the classic *bipartite graph* problem.



--------------------------------------------------------------------

#### 1.   Lexicographically smallest 2‑colouring

A connected component of a bipartite graph has exactly two valid
colourings – they are each other’s colour swap.
Let the vertices of a component be ordered increasingly.
If we colour the smallest vertex with colour **1**, the whole component
is forced (the other colouring would give colour **2** to that vertex,
which is larger lexicographically).
Thus the globally lexicographically smallest solution is obtained by

* processing the components in increasing order of their smallest vertex,
* in each component fixing the smallest vertex to colour **1**,
* propagating the colours by BFS/DFS.

If the graph is not bipartite, no solution exists.



--------------------------------------------------------------------

#### 2.   Algorithm
```
read n,m
build adjacency list
colour[1..n] = -1   // -1 = unvisited, 0 = colour 1, 1 = colour 2
for v = 1 .. n:
    if colour[v] == -1:
        start BFS from v
        colour[v] = 0                     // smallest vertex gets colour 1
        queue = [v]
        while queue not empty:
            x = pop()
            for each neighbour y of x:
                if colour[y] == -1:
                    colour[y] = colour[x] ^ 1
                    push y
                else if colour[y] == colour[x]:
                    print "NO" and exit   // not bipartite
print "YES"
output for i=1..n : 1 if colour[i]==0 else 2
```

`^ 1` flips between `0` and `1`.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints **YES** and the lexicographically
smallest valid assignment iff such an assignment exists.

---

##### Lemma 1  
During BFS of a component, if the algorithm never detects a conflict,
the obtained colours form a proper 2‑colouring of that component.

**Proof.**  
BFS starts with an arbitrary vertex coloured `0`.  
Whenever an edge `{x,y}` is examined, the algorithm assigns `y` the opposite
colour of `x` if `y` is uncoloured.
Thus every processed edge connects vertices of different colours.
If later the same edge is examined again, both ends are already coloured;
the algorithm checks they differ, otherwise it would abort.
Hence all edges of the component satisfy the colour condition. ∎



##### Lemma 2  
If the algorithm aborts with “NO”, the input graph is not bipartite.

**Proof.**  
The only abort condition is finding an edge `{x,y}` with
`colour[x] == colour[y]`.  
Both vertices have already been assigned colours along some paths from the
BFS start vertex. Those two paths together form an odd cycle
(because the two vertices have the same parity distance from the start).
A graph containing an odd cycle is not bipartite. ∎



##### Lemma 3  
If the algorithm finishes without abort, the produced assignment is a
valid configuration for the whole graph.

**Proof.**  
By Lemma&nbsp;1 each component is properly coloured, i.e. adjacent vertices
receive different colours.
Since the whole graph is the disjoint union of its components,
the condition holds for every edge of the graph. ∎



##### Lemma 4  
For each connected component the algorithm assigns colour 1 to its
smallest‑indexed vertex.

**Proof.**  
When the outer loop reaches the smallest vertex `v` of a component,
`colour[v]` is still `-1`. The algorithm sets `colour[v]=0`,
which corresponds to mode 1. All later vertices of the same component are
reached only via this BFS, therefore the smallest vertex keeps colour 1. ∎



##### Lemma 5  
Among all valid colourings, the algorithm’s output is lexicographically
minimum.

**Proof.**  
Consider any component `C`.  
All valid colourings of `C` are exactly the two colourings that differ by a
global swap of colours (standard property of bipartite components).
By Lemma&nbsp;4 the algorithm chooses the one where the smallest vertex of
`C` gets colour 1.  
Any other valid global colouring must either

* give the same colour to that vertex – then both colourings coincide on
  the whole component, or
* give colour 2 to that vertex – then at the first position belonging to
  `C` the algorithm’s sequence has `1` while the other has `2`,
  hence the algorithm’s sequence is lexicographically smaller.

Components are processed in increasing order of their smallest vertex,
so earlier components are fixed before later ones.
Therefore no later decision can affect the lexicographic order at an
earlier position. Consequently the whole sequence is the smallest possible. ∎



##### Theorem  
The algorithm outputs  

* “NO” iff no valid configuration exists,  
* otherwise “YES” followed by the lexicographically smallest valid
  configuration.

**Proof.**  

*If the algorithm prints “NO”.*  
By Lemma&nbsp;2 the graph is not bipartite, thus no 2‑colouring exists,
hence no valid configuration exists.

*If the algorithm prints “YES”.*  
It terminated without conflict, so by Lemma&nbsp;3 the produced assignment
satisfies all edge constraints.  
By Lemma&nbsp;5 it is the lexicographically smallest among all such
assignments.

*Conversely*, if a valid configuration exists, the graph is bipartite.
BFS never meets a same‑colour edge, so the algorithm never aborts and
outputs “YES”. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once,
`O(n + m)` time.  

Total time `O(n + m)` ≤ `4·10⁵`, well inside the limits.  
Memory consumption `O(n + m)` for adjacency lists and colour array,
also within the 256 MB limit.

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 unvisited, 0 -> mode 1, 1 -> mode 2
    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # start new component, give smallest vertex colour 0 (mode 1)
        colour[start] = 0
        q = deque([start])
        while q:
            x = q.popleft()
            cx = colour[x]
            for y in adj[x]:
                if colour[y] == -1:
                    colour[y] = cx ^ 1
                    q.append(y)
                elif colour[y] == cx:
                    sys.stdout.write("NO")
                    return

    # all good
    out = ["YES\n"]
    out.append(' '.join('1' if colour[i] == 0 else '2' for i in range(1, n + 1)))
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```

conforms to the required input‑output format.
