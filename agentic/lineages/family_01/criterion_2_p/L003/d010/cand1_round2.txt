<METHOD_DESCRIPTION>Replaces the local per-edge determinant condition with a global sum over all edges: $\sum (2s_u - 3)(2s_v - 3) = -m$. Since $s \in \{1, 2\}$, each term is $\ge -1$, so the sum equals $-m$ if and only if every term is exactly $-1$, which strictly requires $s_u \neq s_v$ for every edge. This defeats models by requiring a multi-step algebraic deduction (global sum of bounded terms achieves theoretical minimum $\implies$ all local terms are minimized) to uncover the underlying bipartite graph structure, preventing immediate pattern matching to graph coloring.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — System Configuration

Time limit: 1 s   Memory limit: 256 MB

A cloud provider must configure the operation mode for $n$ database instances. The configuration requires assigning each instance $i$ (for $1 \le i \le n$) an operation mode $s_i$, which must be chosen from the set $\{1, 2\}$.

The system includes $m$ shared backup storage arrays. Each array connects two specific database instances. 
To ensure fault tolerance against concurrent mode-failures, the assignment of modes must satisfy a strict global stability condition. 
Specifically, a configuration is valid if and only if the total stability index over all $m$ backup arrays equals exactly $-m$. The stability index is computed as:
$$ \sum_{j=1}^m (2s_{u_j} - 3)(2s_{v_j} - 3) $$
where $u_j$ and $v_j$ are the two instances connected by the $j$-th backup array. 

The sum is evaluated over all $m$ arrays exactly as they appear in the input. If multiple backup arrays connect the same pair of instances, each array contributes a separate term to the sum. If an array connects an instance to itself ($u=v$), it contributes a term where $u_j = v_j$.

You must assign a mode to each instance to satisfy this stability condition (so the sum equals $-m$), or determine that no such configuration exists. 

If multiple valid configurations exist, the automated deployment system requires the configuration that minimizes the total network energy score $E$, defined as:
$$E = \sum_{i=1}^n s_i \cdot 2^{n-i}$$
(Note: minimizing this energy score is mathematically equivalent to finding the lexicographically smallest valid sequence $s_1, \dots, s_n$.)

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of database instances and the number of shared backup arrays.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that instances $u$ and $v$ share a backup array. 

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the valid configuration with the minimum energy score.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit matrix invertibility condition was replaced with a global algebraic sum condition. Because $s_i \in \{1, 2\}$, the term $(2s_i - 3)$ maps to $\{-1, 1\}$, meaning each term in the sum is at least $-1$. The sum can only equal $-m$ if every single term is $-1$, which strictly forces $s_u \neq s_v$ for every backup array. This forces models to logically deduce the local constraint from a global bound rather than pattern-matching the matrix determinant directly to bipartiteness.
</RATIONALE>

</PRESERVED_ANSWER>
