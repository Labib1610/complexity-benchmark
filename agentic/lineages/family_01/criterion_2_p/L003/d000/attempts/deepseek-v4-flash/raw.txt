We can model this as a bipartite graph problem: each machine is a node, and each warning is an edge.  
We need to assign each node to one of two modes such that no edge connects two nodes of the same mode.  
That’s exactly checking if the graph is bipartite, and if so, output the lexicographically smallest assignment.

Here’s the Python solution:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    # Lexicographically smallest: prefer mode 1 (0) when possible
    # We already have a valid coloring; but we can flip components if it makes it smaller
    # Since we start each component with 0, it's already lexicographically smallest
    print("YES")
    print(" ".join(str(c + 1) for c in color))
```
