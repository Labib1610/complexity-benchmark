 We can model this as a bipartite graph problem.  
Each instance is a node, and each constraint (edge) means the two nodes must be in different windows (colors).  
So we need to check if the graph is bipartite, and if so, assign colors 1 and 2 with the lexicographically smallest assignment.

We can do a BFS/DFS coloring, always starting with color 1 for the first uncolored node, and when we encounter a conflict, it’s not bipartite.

Here’s the implementation:

```python
from collections import deque

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start):
    q = deque([start])
    color[start] = 0  # 0 means window 1, 1 means window 2
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = color[u] ^ 1
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

possible = True
for i in range(n):
    if color[i] == -1:
        if not bfs(i):
            possible = False
            break

if not possible:
    print("NO")
else:
    print("YES")
    print(" ".join(str(c + 1) for c in color))
```
