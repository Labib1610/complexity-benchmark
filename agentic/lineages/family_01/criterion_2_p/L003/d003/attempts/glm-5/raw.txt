To solve this problem, we need to assign each instance a mode (1 or 2) such that for every shared backup array (edge between instances u and v), the merged sequence of their pulses (which is s_u + s_v identical 'sync' pulses) cannot be split into two identical consecutive halves. 

The merged sequence has length s_u + s_v. For it to be splittable into two identical consecutive halves, the length must be even and the two halves must be identical. Since all pulses are identical, the only condition is that the length s_u + s_v is even. Therefore, the constraint is that s_u + s_v must be odd, meaning s_u ≠ s_v for every edge (u, v).

This reduces the problem to a bipartite graph check (2-coloring) where adjacent nodes must have different colors (1 and 2). If the graph is bipartite, we can find a valid 2-coloring. To get the lexicographically smallest configuration, we should assign 1 to nodes whenever possible, which means during BFS/DFS, we should prefer assigning 1 to unvisited nodes.

Here's the approach:
1. Check if the graph is bipartite using BFS or DFS, assigning colors 1 and 2 such that adjacent nodes have different colors.
2. If the graph is not bipartite (contains an odd-length cycle), output "NO".
3. If it is bipartite, output "YES" followed by the color assignments, ensuring the lexicographically smallest sequence by preferring 1 for nodes when possible.

To ensure lexicographically smallest, we can process nodes in order from 1 to n, and for each unvisited node, assign it 1 and then assign 2 to its neighbors, and so on. This greedy approach ensures that earlier nodes get the smallest possible value (1) whenever possible.

```python
import sys
from collections import deque

def solve():
    input = sys.stdin.read().split()
    ptr = 0
    n, m = map(int, input[ptr:ptr+2])
    ptr += 2
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v = map(int, input[ptr:ptr+2])
        ptr += 2
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * (n + 1)
    
    for i in range(1, n+1):
        if color[i] == 0:
            queue = deque([i])
            color[i] = 1
            while queue:
                u = queue.popleft()
                for v in adj[u]:
                    if color[v] == 0:
                        color[v] = 3 - color[u]
                        queue.append(v)
                    elif color[v] == color[u]:
                        print("NO")
                        return
    
    print("YES")
    print(' '.join(map(str, color[1:n+1])))

solve()
```
