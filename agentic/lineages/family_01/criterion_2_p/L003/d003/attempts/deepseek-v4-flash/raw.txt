We can model this as a graph problem.  
Each instance is a node, and each shared backup array is an edge.  
The condition that the merged sequence cannot be split into two identical halves means:

- If two connected instances have the same mode (both 1 or both 2), the total pulse count is even and can be split into equal halves → invalid.
- So connected instances must have **different** modes.

Thus, the graph must be **bipartite**.  
We assign modes 1 and 2 to the two sides.  
To get the lexicographically smallest assignment, we run BFS/DFS, assigning 1 whenever possible.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    # color 0 -> mode 1, color 1 -> mode 2
    print(' '.join(str(c + 1) for c in color))
```
