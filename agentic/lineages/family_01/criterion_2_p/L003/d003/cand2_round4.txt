# Problem B — System Configuration

Time limit: 1 s
Memory limit: 256 MB

A cloud provider must configure the operation mode for $n$ database instances. The maximum capacity of the provider's data center allows up to two hundred thousand such instances, and there is always at least one deployed. The configuration requires assigning each instance $i$ an operation mode $s_i$, which must be chosen from the set $\{1, 2\}$.

Certain pairs of distinct instances share a dedicated backup storage array. The infrastructure supports anywhere from zero up to two hundred thousand shared backup arrays. To maintain system stability, any two instances $u$ and $v$ that share a backup array cannot be configured with the same operation mode, as this would cause a synchronization fault.

You must assign a mode to each instance to satisfy all stability constraints, or determine that no such configuration exists. If multiple valid configurations exist, the automated deployment system requires the configuration whose sequence of mode assignments $s_1 \dots s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$, representing the number of database instances and the number of shared backup arrays, subject to the facility limits described above.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that instances $u$ and $v$ share a backup array.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
