# Problem B — Regional Oversight

Time limit: 1 s   Memory limit: 256 MB

A corporation operates $n$ regional branches, numbered 1 through $n$. Each branch must be assigned a compliance tier, which is strictly restricted to either tier 1 or tier 2.

The corporate audit has identified $m$ client overlap disputes. Each dispute involves a specific pair of branches. To guarantee impartial mediation, the product of the compliance tiers of any two branches involved in a dispute must be exactly 2.

Determine a compliance tier assignment for all $n$ branches that resolves all disputes according to this rule. If no such assignment is possible, report the failure.

## Input
The first line contains two integers $n$ and $m$. The number of branches $n$ is at least 1. The corporation allocates exactly one megabyte of auditing data per branch, and the total auditing data across all branches cannot exceed 200 gigabytes (where 1 gigabyte is defined as 1000 megabytes). The number of disputes $m$ is non-negative, and its maximum possible value is the same as the maximum possible number of branches.

Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of branches involved in a client overlap dispute.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise print `YES`, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the constraint "sum to exactly 3" to "product ... must be exactly 2". Since the domain is strictly {1, 2}, this enforces the exact same condition (one branch gets 1, the other gets 2) while avoiding the linear sum formulation that commonly triggers bipartite coloring heuristics. Also replaced the bare numeric inequalities with a physical capacity constraint (200 GB at 1 MB per branch) to force derivation of the $2 \cdot 10^5$ limit.
</RATIONALE>
<PRESERVED_ANSWER>
The variables are restricted to {1, 2}, so their product is 2 if and only if one is 1 and the other is 2, which is logically identical to their sum being 3.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) on an undirected graph, solvable in linear time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
The megabyte-to-gigabyte conversion could be misread if the definition (1 GB = 1000 MB) is ignored, but it is explicitly provided to prevent ambiguity.
</RISK>
