<STATEMENT>
# Problem B — Lens Calibration

Time limit: 1 s   Memory limit: 256 MB

An optical engineering firm is designing a compound imaging system with $n$ lens modules. Each module $i$ must be assigned a focal multiplier $f_i$, which must be chosen from the set $\{1, 2\}$.

Certain pairs of modules share an internal light path. To ensure the final image focuses correctly on the sensor, any two modules $u$ and $v$ that share a light path must have a combined magnification of exactly 2. The combined magnification of two modules is calculated as the product of their focal multipliers.

You must assign a focal multiplier to each module to satisfy all focus constraints, or determine that no such configuration exists. If multiple valid configurations are possible, the manufacturing control system requires the configuration whose sequence of multipliers $f_1 \dots f_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of lens modules and the number of shared light paths.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that modules $u$ and $v$ share a light path.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $f_1 \dots f_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The scenario was changed from database backup modes to optical lens multipliers. The constraint was changed from an absolute difference matching a minimum, to a product equaling exactly 2. This removes the explicit arithmetic signature of the previous version, forcing the model to independently evaluate the Diophantine equation over the domain {1, 2} to realize it mandates distinct assignments.
</RATIONALE>
<PRESERVED_ANSWER>
For variables restricted to {1, 2}, the condition that their product equals 2 is mathematically identical to the condition that they are not equal, which exactly preserves the constraint logic and identical valid assignments of the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains fundamentally equivalent to finding the lexicographically first valid 2-coloring of a graph, which is solvable in O(n+m) time using Breadth-First Search, keeping it firmly in P.
</PRESERVED_CLASS>
