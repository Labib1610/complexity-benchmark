The determinant is $s_u(3-s_v) - s_v(3-s_u) = 3s_u - s_us_v - 3s_v + s_us_v = 3(s_u - s_v)$.

For this to be non-zero, we need $s_u \neq s_v$.

import sys
from collections import deque

def solve():

    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * (n + 1)  # 0 = uncolored, 1 or 2
    
    for start in range(1, n + 1):

                elif color[v] == color[u]:

For a connected component, there are exactly 2 valid 2-colorings (if bipartite). Let the smallest index in the component be $j$. The two colorings differ by swapping 1↔2 for all vertices. In coloring A, $s_j = 1$; in coloring B, $s_j = 2$.

The difference in energy: $E_A - E_B = \sum_{k \in C} (s_k^A - s_k^B) \cdot 2^{n-k}$.

Since $s_k^A - s_k^B = \pm 1$ (specifically, if $s_k^A = 1$ then $s_k^B = 2$, so difference is $-1$; if $s_k^A = 2$ then $s_k^B = 1$, so difference is $+1$).

So $E_A - E_B = \sum_{k: s_k^A=1} (-1) \cdot 2^{n-k} + \sum_{k: s_k^A=2} (+1) \cdot 2^{n-k}$.

Hmm, this isn't simply determined by the smallest index. Let me reconsider.

Actually, let me think about it differently. We want to minimize $E = \sum s_i \cdot 2^{n-i}$. Since $s_i \in \{1,2\}$, we can write $E = \sum 2^{n-i} + \sum (s_i - 1) \cdot 2^{n-i} = \text{const} + \sum (s_i - 1) \cdot 2^{n-i}$.

So minimizing $E$ is equivalent to minimizing $\sum (s_i - 1) \cdot 2^{n-i}$, where $(s_i - 1) \in \{0, 1\}$.

This is like a binary number where bit $i$ (with weight $2^{n-i}$) is $(s_i - 1)$. To minimize this, we want the most significant bits (smallest $i$) to be 0, i.e., $s_i = 1$.

So the greedy of processing from $i=1$ to $n$ and trying $s_i = 1$ first is correct, because:
- For each connected component, when we first encounter it (at its smallest-index vertex), we set that vertex to 1.
- This is a lexicographic minimization: we want $s_1$ as small as possible, then $s_2$, etc.
- For the smallest-index vertex $j$ in a component, setting $s_j = 1$ is better than $s_j = 2$ (since $2^{n-j}$ is the largest weight in the component).
- Once $s_j = 1$ is fixed, all other vertices in the component are determined.

But is it always optimal to set the smallest-index vertex to 1? What if setting it to 2 allows more vertices with small indices to be 1?

No! In a connected bipartite graph, once you fix one vertex's color, ALL vertices' colors are determined. So the choice is binary: either the smallest-index vertex is 1 (and all others follow), or it's 2 (and all others are swapped). Since the smallest-index vertex has the highest weight, setting it to 1 is always at least as good.

More formally: Let $j$ be the smallest index in component $C$. 
- Coloring A: $s_j = 1$, energy contribution from $C$ is $\sum_{k \in C} s_k^A \cdot 2^{n-k}$.
- Coloring B: $s_j = 2$, energy contribution is $\sum_{k \in C} s_k^B \cdot 2^{n-k} = \sum_{k \in C} (3 - s_k^A) \cdot 2^{n-k}$.

$E_B - E_A = \sum_{k \in C} (3 - 2s_k^A) \cdot 2^{n-k}$.

Since $s_j^A = 1$, the term for $k=j$ is $(3-2) \cdot 2^{n-j} = 2^{n-j}$.

For other terms, $(3 - 2s_k^A) \in \{-1, +1\}$.

So $E_B - E_A = 2^{n-j} + \sum_{k \in C, k \neq j} (3 - 2s_k^A) \cdot 2^{n-k}$.

The sum of absolute values of the other terms is $\sum_{k \in C, k \neq j} 2^{n-k} < 2^{n-j}$ (since $j$ is the smallest index, all other $k > j$, so $2^{n-k} \leq 2^{n-j-1}$, and the sum is at most $2^{n-j-1} + 2^{n-j-2} + \ldots < 2^{n-j}$).

Therefore $E_B - E_A > 0$, so coloring A (with $s_j = 1$) is always better. The greedy is correct.
