# Problem B — Regional Oversight

Time limit: 1 s   Memory limit: 256 MB

A corporation operates $n$ regional branches, numbered 1 through $n$. A recent restructuring requires that every branch $i$ be placed under the direct oversight of exactly one of two senior executives. This is represented by assigning each branch an executive code $s_i \in \{1, 2\}$.

The corporate audit has identified $m$ client overlap disputes. Each dispute involves a specific pair of branches $u$ and $v$ that are aggressively competing for the same local accounts. To guarantee impartial mediation and prevent internal conflict, the executive codes for any disputed pair must satisfy the following parity condition:

$s_u + s_v \equiv 1 \pmod 2$

You must determine an executive code assignment for all $n$ branches that resolves all disputes according to this rule. If no such assignment is possible, you must report the failure.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of branches involved in a client overlap dispute.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was reframed from a direct assignment conflict ("must report to different executives") into a system of linear congruences modulo 2. To avoid the TLE of generic Gaussian elimination ($O(n^3)$), models can no longer just pattern-match the scenario to graph coloring; they must genuinely deduce that this specific sparse system of equations is structurally equivalent to 2-coloring and thus admits a linear-time BFS/DFS solution.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $s_u + s_v \equiv 1 \pmod 2$ for variables restricted to $\{1, 2\}$ is mathematically identical to $s_u \neq s_v$, so the set of valid assignments and the lexicographically smallest tie-break remains exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring of a graph (or identifying an odd cycle), which is in P and solvable in $O(n+m)$ time.
</PRESERVED_CLASS>
