We can model this as a bipartite graph problem: each branch is a node, and each dispute is an edge.  
The condition that two connected branches must have tiers summing to 3 means one must be tier 1 and the other tier 2.  
So the graph must be bipartite. If it is, we can assign tiers via BFS/DFS coloring.  
To get the lexicographically smallest assignment, we try to assign tier 1 to the smallest-index node in each connected component, then propagate.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    print(" ".join(str(c) for c in color))
```
