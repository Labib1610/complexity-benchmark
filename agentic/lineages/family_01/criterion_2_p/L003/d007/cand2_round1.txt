# Problem B — System Configuration

Time limit: 1 s   Memory limit: 256 MB

A cloud provider must configure the operation mode for $n$ database instances. The configuration requires assigning each instance $i$ an operation mode $s_i$, which must be chosen from the set $\{1, 2\}$.

Each instance $i$ (where $1 \le i \le n$) maintains a state transformation matrix $M_i$. Depending on its chosen mode $s_i$, the matrix is defined as:
- If $s_i = 1$, $M_i = \begin{pmatrix} 42 & -30 \\ 56 & -40 \end{pmatrix}$
- If $s_i = 2$, $M_i = \begin{pmatrix} -60 & 45 \\ -84 & 63 \end{pmatrix}$

Certain pairs of instances share a dedicated backup storage array. When two instances $u$ and $v$ share a backup array, the array synchronizes them by computing their combined configuration matrix $C_{u,v} = u \cdot M_{s_u} + v \cdot M_{s_v}$, where $u$ and $v$ are the integer IDs (from $1$ to $n$) of the two instances.

To maintain system stability, the backup array's resonance detector requires that the determinant of $C_{u,v}$ must not be equal to zero. If the determinant is zero, the array will experience a feedback loop and synchronization will fail.

You must assign a mode to each instance to satisfy all stability constraints, or determine that no such configuration exists. If multiple valid configurations exist, the automated deployment system requires the configuration whose sequence of mode assignments $s_1 \dots s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of database instances and the number of shared backup arrays.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that instances $u$ and $v$ share a backup array.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the simple matrix product with a determinant constraint on a linear combination of the matrices weighted by the node indices $u$ and $v$. The matrices were crafted via a similarity transform such that $\det(C_{u,v})$ evaluates to $0$ if $s_u = s_v$, and $6uv$ if $s_u \neq s_v$. This forces the model to either mathematically prove the global invariant (that validity is exactly $s_u \neq s_v$) or implement a custom dynamic evaluation in its graph traversal, breaking templates that rely on recognizing static 2-coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The determinant of the combined matrix evaluates to 0 when the modes are identical and 6uv when they differ; since u and v are strictly positive integer IDs, the synchronization succeeds if and only if the modes are different, which is exactly the same condition as the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in O(N+M) time using Breadth-First Search, keeping it in P.
</PRESERVED_CLASS>
<RISK>
A model might mistakenly think that $u$ and $v$ can be 0 or negative, though the statement explicitly defines them as integer IDs from $1$ to $n$.
</RISK>
