We can view each instance’s mode as a binary choice (1 or 2).  
The critical observation is that for a given pair of instances,  
whether the product is zero depends only on whether their chosen modes produce a zero product or not.

By testing the matrices:

If both are mode 1:  
The product is not zero.

If both are mode 2:  
The product is not zero.

If one is mode 1 and the other mode 2:  
The product can be zero.

We check mode 1 × mode 2 yields zero, mode 2 × mode 1 also zero.  
Hence, **the constraint is: for each edge (u,v), s_u != s_v**.  
So the problem reduces to a graph bipartite check and lexicographically smallest coloring.

Thus the algorithm:

1. Build adjacency list.  
2. Attempt to color each connected component with 2 colors (1 and 2) such that adjacent nodes differ.  
   Use BFS/DFS with color 1 for start but to get lexicographically smallest, we must be careful:  
   For each component, when starting from the smallest index uncolored, we try assigning color 1 first if possible;  
   if it leads to conflict in that component, assign color 2 first.  
   We compare the resulting configurations lexicographically.  
   (Only need to consider both assignments if the first fails, otherwise keep first).

3. If any conflict → NO.

4. Otherwise, output.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n  # 0 = uncolored, 1 or 2
possible = True

for start in range(n):
    if color[start] != 0:
        continue
    # try assigning color 1 to start
    color[start] = 1
    q = deque([start])
    ok = True
    comp_nodes = [start]
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == 0:
                color[v] = 3 - color[u]
                comp_nodes.append(v)
                q.append(v)
            elif color[v] == color[u]:
                ok = False
                break
        if not ok:
            break
    if ok:
        continue
    # conflict with starting color 1, reset component and try starting color 2
    for node in comp_nodes:
        color[node] = 0
    color[start] = 2
    q = deque([start])
    ok = True
    comp_nodes = [start]
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == 0:
                color[v] = 3 - color[u]
                comp_nodes.append(v)
                q.append(v)
            elif color[v] == color[u]:
                ok = False
                break
        if not ok:
            break
    if not ok:
        possible = False
        break

if not possible:
    print("NO")
else:
    print("YES")
    print(' '.join(str(c) for c in color))
```
