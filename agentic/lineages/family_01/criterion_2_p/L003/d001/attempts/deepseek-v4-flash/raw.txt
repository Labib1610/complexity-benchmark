We can model this as a bipartite graph problem. If the graph is bipartite, we can assign executives 1 and 2 to the two partitions. To get the lexicographically smallest assignment, we should try to assign 1 to as many early nodes as possible, which means we should do a BFS/DFS coloring starting from node 1 with color 1, and whenever we encounter an uncolored node, assign it the opposite color of its neighbor. If a conflict occurs, the graph is not bipartite.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] == -1:
        color[start] = 0
        q = deque([start])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
