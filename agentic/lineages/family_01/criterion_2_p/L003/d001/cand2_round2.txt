<STATEMENT>
# Problem B — Synchronization States

Time limit: 1 s   Memory limit: 256 MB

A cloud provider must configure synchronization states for $n$ database instances. The configuration process requires assigning each instance a state value, which must be either 1 or 2.

Certain pairs of instances are linked by a dedicated phase channel. To ensure stable phase alignment across the network, any two instances that share a phase channel must be configured such that the product of their state values is exactly 2.

You must assign a state to each instance to satisfy all phase alignment constraints, or determine that no such configuration exists. If multiple valid configurations exist, the automated deployment system requires the configuration whose sequence of state assignments $s_1 \dots s_n$ (where $s_i$ is the state assigned to instance $i$) is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of database instances and the number of phase channels.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that instances $u$ and $v$ are linked by a phase channel.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1, 2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit "cannot undergo maintenance during the same window" constraint was replaced with the mathematical condition that "the product of their state values is exactly 2" for states in {1, 2}. This masks the standard 2-coloring/bipartite graph pattern, forcing the model to algebraically deduce that linked instances must have different states rather than triggering memorized graph algorithms from keywords.
</RATIONALE>
<PRESERVED_ANSWER>
For state values restricted to {1, 2}, their product is exactly 2 if and only if one value is 1 and the other is 2, making this mathematically identical to the seed's requirement that linked instances receive different assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding a 2-coloring of an undirected graph and selecting the lexicographically smallest valid assignment per connected component, which is solvable in O(n+m) time.
</PRESERVED_CLASS>
