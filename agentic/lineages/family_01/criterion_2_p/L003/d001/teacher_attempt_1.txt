# Problem B — Grid Assignments

Time limit: 1 s   Memory limit: 256 MB

A manufacturing facility contains $n$ machines, numbered from 1 to $n$. The facility's floor plan accommodates at least one and up to 200,000 machines. Each machine must be connected to exactly one of two available power grids, designated as grid 1 and grid 2.

The safety system has logged $m$ transformer alerts. The alert database can be completely empty or hold up to 200,000 records. Each alert lists two specific machines that share a single transformer. To prevent a catastrophic overload, any two machines listed in a single alert must be connected to different power grids.

You must determine a grid assignment for every machine such that no transformer overloads, or report if this is impossible.

## Input
The first line contains two integers $n$ and $m$, the exact headcount of machines and the tally of alerts.
Each of the next $m$ lines contains two integers $u$ and $v$, representing a pair of machines listed in a single alert.

## Output
If no safe grid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each either 1 or 2), representing the grid assignment for each machine. If there are multiple safe assignments, provide the sequence that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Changed the framing from "modes that fail if identical" to "power grids that must be different", which expresses the exact same constraint while avoiding the phrasing that frequently triggers rote bipartite-coloring recall. Replaced explicit inequality bounds with physical constraints in the scenario (floor plan capacity, database size) to force the model to extract and formalise the numeric limits itself.
</RATIONALE>
<PRESERVED_ANSWER>
The necessity to assign one of two states to each machine such that specified pairs have different states is logically identical to the original problem, preserving all valid assignments and the lexicographical tie-breaker.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains strictly equivalent to finding a valid 2-coloring of an undirected graph, which is solvable in O(n+m) time using BFS/DFS, thus remaining in P.
</PRESERVED_CLASS>
