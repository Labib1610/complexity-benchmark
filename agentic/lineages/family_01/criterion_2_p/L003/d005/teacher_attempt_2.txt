<STATEMENT>
# Problem B — Orbital Relays

Time limit: 1 s   Memory limit: 256 MB

A communications network consists of $n$ orbital relays, numbered 1 through $n$. You must assign each relay exactly one of two available phase signatures, represented by the integers 1 and 2. 

The network includes $m$ interference zones, each representing a spatial region where the signals from two specific relays overlap. To avoid catastrophic signal cancellation, any two relays whose signals overlap in a zone must operate with distinct phase signatures. 

Find a valid phase assignment for all $n$ relays such that the signal separation requirement is met across all interference zones. If the network cannot be safely configured, you must report this.

## Input
The first line provides two integers $n$ and $m$. The central registry sets a combined maximum capacity of $400,000$ records, split evenly to define the individual upper limits for relays and interference zones. The actual number of relays, $n$, is at least 1, while the actual number of zones, $m$, can be as low as 0. 

The following $m$ lines each contain two distinct integers $u$ and $v$ (both valid relay identifiers from 1 to $n$), indicating that the broadcasts of relay $u$ and relay $v$ overlap in an interference zone.

## Output
If it is impossible to assign phase signatures safely, output a single line containing NO.
If a valid assignment exists, output YES on the first line. On the second line, output $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1, 2\}$), representing the lexicographically smallest sequence of phase signatures that satisfies all requirements.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Removed the explicit `(1, 2)` and `(2, 1)` ordered-pair notation, replacing it with a physical requirement that overlapping signals must use distinct phase signatures. This removes the surface-level pattern that triggers bipartite graph recall, forcing the model to infer the 2-coloring structure from the exclusion rule. Additionally, the explicit numeric upper bounds were replaced with a combined capacity that must be halved, satisfying the strategy constraint.
</RATIONALE>
<PRESERVED_ANSWER>
The rule that overlapping relays must have distinct phase signatures from the set {1, 2} is logically identical to restricting adjacent nodes to the pairs (1, 2) or (2, 1), so all valid assignments and the lexicographical tie-breaker remain exactly identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a valid 2-coloring for an undirected graph (or detecting an odd cycle), which can be solved in linear time using Breadth-First Search.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the evenly split capacity as a restriction that the inputs $n$ and $m$ must be equal, rather than just their upper bounds being derived from an equal split, though the phrasing "individual upper limits" heavily mitigates this.
</RISK>
