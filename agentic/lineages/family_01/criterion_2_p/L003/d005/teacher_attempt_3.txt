# Problem B — Thermal Stabilization

Time limit: 1 s   Memory limit: 256 MB

A laboratory is processing $n$ chemical reagents, numbered 1 through $n$. Each reagent must be stabilized by applying exactly one of two thermal treatments, designated by the integers 1 and 2.

The laboratory has identified $m$ reactive pairs. Each pair consists of two specific reagents that will cause a hazardous reaction if their treatments are not properly balanced. To ensure complete safety, any two reagents that form a reactive pair must be assigned treatments that offset each other. Specifically, for every reactive pair, the sum of the treatment identifiers assigned to its two reagents must be exactly 3.

You must determine a valid treatment assignment for all $n$ reagents such that the safety requirement is met across all $m$ reactive pairs. If the reagents cannot be safely stabilized under these conditions, you must report this.

## Input
The first line of the input provides two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of reagents and the number of reactive pairs, respectively.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that reagent $u$ and reagent $v$ form a reactive pair.

## Output
If it is impossible to stabilize the reagents safely, output a single line containing NO.
If a valid assignment exists, output YES on the first line. On the second line, output $n$ integers $s_1 \dots s_n$ (where each $s_i \in \{1, 2\}$), representing the lexicographically smallest sequence of treatments that satisfies all requirements.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The scenario was completely rewritten from orbital relays to chemical reagents to eliminate any familiar bipartite-graph framing. The explicit constraint that adjacent pairs must be configured as (1,2) or (2,1) was replaced with the algebraic constraint that their treatment identifiers must sum to exactly 3. This forces the model to deduce the structural implication (that connected nodes must have different values) rather than relying on surface-level pattern matching of 2-coloring descriptions.
</RATIONALE>
<PRESERVED_ANSWER>
The available values are still restricted to 1 and 2, and the only way two such integers can sum to 3 is if one is 1 and the other is 2, making the valid pairwise assignments identical to the original compatibility matrix.
</PRESERVED_ANSWER>

The problem remains fundamentally equivalent to 2-coloring a graph (or testing bipartiteness), which is solvable in $O(n+m)$ time using BFS or DFS, keeping it firmly in P.
</PRESERVED_CLASS>
