We need to assign each relay either 1 or 2 such that for every edge (u, v), the sum is exactly 3.  
That means if one is 1, the other must be 2, and vice versa. This is exactly a bipartite graph check.

We can solve it with BFS/DFS coloring:

- If the graph is not bipartite → output `NO`.
- If it is bipartite, we need the lexicographically smallest assignment.  
  That means we should try to assign 1 as early as possible (smallest index) whenever possible.

We can do BFS/DFS over all components, and for each unvisited node, try assigning it 1 first, then propagate.  
If a conflict occurs, try assigning it 2 first.  
If both fail → `NO`.

Here’s the implementation:

```python
import sys
from collections import deque

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * n

    def bfs(start, first_color):
        # Try coloring with start = first_color
        c = color[:]
        c[start] = first_color
        q = deque([start])
        ok = True
        while q:
            u = q.popleft()
            for v in adj[u]:
                if c[v] == -1:
                    c[v] = 1 - c[u]
                    q.append(v)
                elif c[v] == c[u]:
                    ok = False
                    break
            if not ok:
                break
        return ok, c

    for i in range(n):
        if color[i] == -1:
            # Try 1 first
            ok1, c1 = bfs(i, 1)
            if ok1:
                color = c1
            else:
                ok2, c2 = bfs(i, 0)
                if not ok2:
                    print("NO")
                    return
                color = c2

    print("YES")
    print(' '.join(str(x + 1) for x in color))

if __name__ == "__main__":
    solve()
```
