**Solution Explanation**

For the given matrix  

```
A = | 3  -4 |
    | 2  -3 |
```

```
A² = I
```

so `A` has order `2`.  
For a vertex `i`

```
s_i = 1  ->  M_i = A
s_i = 2  ->  M_i = I
```

For an edge `{u,v}` we need `M_u·M_v ≠ I`.

```
I·I = I          (forbidden)
A·A = I          (forbidden)
I·A = A ≠ I
A·I = A ≠ I
```

Therefore **the two endpoints of every edge must receive different values**,
i.e. `s_u ≠ s_v`.  
The problem becomes:

*Is the given undirected graph bipartite?*  
If yes, output the lexicographically smallest proper 2‑colouring with colours
`1` and `2`.

--------------------------------------------------------------------

#### 1.   Bipartite checking and component handling
We run a BFS/DFS over all vertices.

* `col[v] = 0/1` – the bipartite colour inside its component.
* While traversing we detect a conflict (`col[neighbour]` already set to the
  same colour) → graph not bipartite → answer `NO`.

During the BFS we also store all vertices of the current component in a list
`comp`. After the component is finished we decide which bipartite colour maps to
the required output value `1`.

The smallest vertex index inside the component is `root = min(comp)`.
If `col[root] == 0` we map `0 → 1 , 1 → 2`; otherwise we flip the mapping
(`0 → 2 , 1 → 1`).  
Thus the smallest index of the component receives value `1`, which is exactly
what is needed for the globally lexicographically smallest sequence.

All components are processed independently, the final array `ans[1…n]` is built
by these mappings.

--------------------------------------------------------------------

#### 2.   Correctness Proof  

We prove that the algorithm prints `YES` and the lexicographically smallest
valid assignment iff such an assignment exists.

---

##### Lemma 1  
For any edge `{u,v}` the condition `M_u·M_v ≠ I` is equivalent to `s_u ≠ s_v`.

**Proof.**  
`M_i` is either `A` (`s_i=1`) or `I` (`s_i=2`).  
The product of two matrices equals `I` exactly in the two cases
`I·I` and `A·A`. All other products are `A`. ∎



##### Lemma 2  
A labeling `s_1…s_n` satisfies all constraints **iff** it is a proper 2‑colouring
of the graph (adjacent vertices have different colours).

**Proof.** Directly from Lemma&nbsp;1. ∎



##### Lemma 3  
If the algorithm finishes without conflict, the produced array `ans`
is a proper 2‑colouring.

**Proof.**  
During BFS we assign bipartite colours `col` such that every traversed edge
connects vertices of opposite `col`. The algorithm aborts on any edge that would
violate this, therefore after a successful BFS all edges satisfy
`col[u] ≠ col[v]`. The final mapping `col → ans` is a bijection (`0↔1` or
`1↔0`), hence also `ans[u] ≠ ans[v]`. ∎



##### Lemma 4  
For each connected component the algorithm chooses the unique assignment that
makes the smallest vertex index of this component receive value `1`.

**Proof.**  
Let `r` be the smallest index in the component and `c = col[r]`.  
If `c = 0` we map `0→1,1→2`; then `ans[r]=1`.  
If `c = 1` we map `0→2,1→1`; again `ans[r]=1`.  
Both possibilities are the only two colour‑to‑value bijections, so the
algorithm picks the one with `ans[r]=1`. ∎



##### Lemma 5  
The whole array `ans` is the lexicographically smallest proper 2‑colouring.

**Proof.**  
Consider the vertices in increasing order.
When the first vertex of a component appears (its smallest index), by Lemma 4
the algorithm forces its value to `1`. Any other proper colouring must assign
either `1` or `2` to this vertex; assigning `2` would be lexicographically larger.
After fixing this component, the next untouched vertex belongs to a different
component, and the same argument applies. Hence no other proper colouring can
be lexicographically smaller. ∎



##### Lemma 6  
If the graph is not bipartite, the algorithm outputs `NO`.

**Proof.**  
A non‑bipartite graph contains an odd cycle. While traversing that cycle,
BFS inevitably meets an edge whose endpoints already have the same `col`,
detects the conflict and aborts with `NO`. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no assignment satisfying all constraints exists;  
* otherwise `YES` and the lexicographically smallest valid assignment.

**Proof.**  

*If the algorithm prints `NO`*: by Lemma 6 the graph is not bipartite, thus by
Lemma 2 no valid assignment exists.

*If the algorithm prints `YES`*: it finished without conflict, therefore the
graph is bipartite. By Lemma 3 the produced `ans` is a proper 2‑colouring,
hence a valid assignment (Lemma 2). By Lemma 5 it is the lexicographically
smallest among all valid assignments.

Conversely, if a valid assignment exists, the graph must be bipartite
(Lemma 2), so the algorithm never aborts and prints `YES`. ∎



--------------------------------------------------------------------

#### 3.   Complexity Analysis  

*BFS over all vertices and edges*: `O(n + m)` time.  
*Memory*: adjacency list `O(n + m)`, colour and answer arrays `O(n)`.  
Both satisfy the limits (`n, m ≤ 2·10⁵`).

--------------------------------------------------------------------

#### 4.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    g = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        g[u].append(v)
        g[v].append(u)

    col = [-1] * (n + 1)          # 0 / 1 bipartite colour
    ans = [0] * (n + 1)           # final 1 / 2 values
    from collections import deque

    for start in range(1, n + 1):
        if col[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        col[start] = 0
        comp = [start]
        ok = True
        while q:
            v = q.popleft()
            for to in g[v]:
                if col[to] == -1:
                    col[to] = col[v] ^ 1
                    q.append(to)
                    comp.append(to)
                elif col[to] == col[v]:
                    print("NO")
                    return
        # decide orientation: smallest index gets value 1
        root = min(comp)
        flip = (col[root] == 1)   # if root colour is 1 we need to flip
        for v in comp:
            if flip:
                ans[v] = 1 if col[v] == 1 else 2
            else:
                ans[v] = 1 if col[v] == 0 else 2

    print("YES")
    print(' '.join(str(ans[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
