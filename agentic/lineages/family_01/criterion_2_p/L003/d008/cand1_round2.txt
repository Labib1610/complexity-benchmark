<METHOD_NAME>Scalar Multiplier Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces globally fixed matrices with instance-dependent matrices by applying a variable scalar multiplier $c_i$. This forces models that hard-code a fixed 2-matrix compatibility table to fail, while leaving the underlying mathematical constraint (and complexity class) perfectly unchanged since scalar multiplication does not alter whether a matrix product is zero.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — System Configuration

Time limit: 1 s
Memory limit: 256 MB

You are given $n$ items, numbered $1$ to $n$. Each item $i$ must be assigned a state $s_i \in \{1, 2\}$.

Each item $i$ has an associated $4 \times 4$ matrix $M_i$, which depends on its index $i$ and its assigned state $s_i$. To define the matrix, let $c_i = 1$ if $i \le 4$, and $c_i = i$ if $i > 4$.

If $s_i = 1$:
$$M_i = \begin{pmatrix} -8c_i & -5c_i & 4c_i & 5c_i \\ -10c_i & -6c_i & 5c_i & 6c_i \\ -16c_i & -10c_i & 8c_i & 10c_i \\ -10c_i & -6c_i & 5c_i & 6c_i \end{pmatrix}$$

If $s_i = 2$:
$$M_i = \begin{pmatrix} 6c_i & c_i & -2c_i & -2c_i \\ 10c_i & -4c_i & -2c_i & 0 \\ 10c_i & 13c_i & -6c_i & -10c_i \\ 13c_i & -12c_i & -c_i & 4c_i \end{pmatrix}$$

You are also given $m$ pairs of items. For each given pair $(u, v)$, the matrices of these two items must satisfy two conditions:
1. $M_u \times M_v \neq Z$
2. $M_v \times M_u \neq Z$
where $Z$ is the $4 \times 4$ zero matrix (the matrix where all 16 elements are 0).

Your task is to assign a state to each item such that all $m$ pair constraints are satisfied. If there are multiple valid assignments, find the one where the sequence $s_1, s_2, \dots, s_n$ is lexicographically smallest. If no valid assignment exists, determine that it is impossible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of items and the number of pairs.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating a pair of items $(u, v)$ that must satisfy the matrix conditions.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise print `YES`, followed by a second line containing $n$ integers $s_1 \dots s_n$ (each in $\{1, 2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The surviving models bypassed the algorithmic reasoning by hard-coding the two fixed matrices and computing their pairwise products to discover the bipartite graph structure. I introduced an index-dependent scalar multiplier $c_i$ to the matrix definitions. This forces the models to either recognize that the scalar factors out (requiring deeper mathematical reasoning) or dynamically compute the products for every edge, which breaks their hard-coded 2-matrix assumptions.
</RATIONALE>
<PRESERVED_ANSWER>
Because $c_i \ge 1$ for all $i$, $M_u \times M_v = Z$ if and only if the original base matrices multiply to $Z$, ensuring the exact same constraints and lexicographically smallest assignment are preserved.
</PRESERVED_ANSWER>
