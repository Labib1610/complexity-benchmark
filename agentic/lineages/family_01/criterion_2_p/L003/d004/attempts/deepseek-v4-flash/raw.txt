We can model this as a bipartite graph problem: each relay is a node, and each interference zone is an edge.  
The condition that connected relays must have different configurations (1 and 2) means the graph must be bipartite.  

If the graph is bipartite, we can color it with two colors.  
To get the lexicographically smallest sequence, we assign color 1 to node 1, then BFS/DFS to color the rest, and if a conflict occurs, it’s impossible.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    print(" ".join(str(c + 1) for c in color))
```
