# Problem B — System Configuration

Time limit: 1 s   Memory limit: 256 MB

A cloud provider must configure the operation mode for a number of database instances. The datacenter's physical racks guarantee space for up to $200,000$ instances, and there is always at least one instance deployed ($n$). The configuration requires assigning each instance $i$ an operation mode $s_i$, which must be chosen from the set $\{1, 2\}$.

Certain pairs of instances share a dedicated backup storage array. The network topology has the capacity to support up to $200,000$ such shared arrays, though a deployment might have none at all ($m$). For every shared backup array connecting instances $u$ and $v$, a frequency parameter is computed for each of the two instances by adding 1 to its assigned mode (yielding $s_u + 1$ and $s_v + 1$). 

To maintain system stability, the greatest common divisor (GCD) of these two frequency parameters must be exactly 1. If the GCD is strictly greater than 1 for any shared array, the system's synchronization will fail.

You must assign a mode to each instance to satisfy all stability constraints, or determine that no such configuration exists. If multiple valid configurations exist, output the configuration whose sequence of mode assignments $s_1 \dots s_n$ is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$, representing the number of database instances and the number of shared backup arrays.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that instances $u$ and $v$ share a backup array.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<METHOD_DESCRIPTION>Replaces the parity-based string concatenation check with a greatest common divisor condition on transformed variables (s_i + 1). On the domain {1, 2}, this mathematically requires s_u != s_v, mapping exactly to bipartite coloring while completely obscuring the graph structure.</METHOD_DESCRIPTION>

<RATIONALE>
The problem was rewritten to remove the string concatenation and parity checks that immediately mapped to graph bipartiteness. Instead, it uses a GCD condition on `s_i + 1` which, for the domain `{1, 2}`, evaluates to exactly the same requirement (`s_u != s_v`) but forces models to analyze the mathematical properties of the constraint rather than relying on surface pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The condition `gcd(s_u + 1, s_v + 1) = 1` for `s_i in {1, 2}` is satisfied if and only if `s_u != s_v`, perfectly matching the seed's constraint.
</PRESERVED_ANSWER>
