 We can model this as a graph problem.  
Each equation \( x_u + x_v = 3 \) means that if one is 1, the other must be 2, and vice versa.  
So each edge forces the two endpoints to have different values.  
This is exactly a bipartite check problem: if the graph is bipartite, we can assign values; otherwise, it's impossible.  

To get the lexicographically smallest assignment, we can do a BFS/DFS starting from the smallest unassigned node, assigning it 1, and then alternating 1 and 2.  

Here’s the implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start):
    q = deque([start])
    color[start] = 0  # 0 means value 1, 1 means value 2
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

possible = True
for i in range(n):
    if color[i] == -1:
        if not bfs(i):
            possible = False
            break

if not possible:
    print("NO")
else:
    print("YES")
    print(" ".join(str(color[i] + 1) for i in range(n)))
```
