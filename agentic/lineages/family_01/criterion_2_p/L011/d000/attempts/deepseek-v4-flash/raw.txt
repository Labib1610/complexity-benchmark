We can model this as a graph problem. Each equation \( x_u + x_v = 3 \) means that \( x_u \) and \( x_v \) must be different (one is 1, the other is 2).  

So the constraints form a bipartite graph: if we color the graph with two colors, each edge must connect nodes of different colors. If the graph is not bipartite, it’s impossible.  

For the lexicographically smallest solution, we assign 1 to the smallest-index node in each connected component, then propagate the alternating values.  

Here’s the implementation:  

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    ans = [0] * n
    
    for start in range(n):
        if color[start] != -1:
            continue
        # BFS to color component
        stack = [start]
        color[start] = 0
        comp = [start]
        while stack:
            u = stack.pop()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    stack.append(v)
                    comp.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    return
        # Assign values: color 0 -> 1, color 1 -> 2
        for u in comp:
            ans[u] = 1 if color[u] == 0 else 2
    
    print("YES")
    print(" ".join(map(str, ans)))

if __name__ == "__main__":
    solve()
```
