**Solution Explanation**

For every variable `x_i` we may choose only the values `1` or `2`.
For a constraint `(u , v)` we need  

```
x_u + x_v = 3   ⇔   (x_u , x_v) is (1,2) or (2,1)
```

Thus the two variables must obtain *different* values.
If we view the variables as vertices of a graph and each constraint as an
undirected edge, the condition is exactly:

*adjacent vertices must have different colours*.

So the problem is:

*Is the graph bipartite?*  
If yes, output the lexicographically smallest 2‑colouring where colour `0`
means value `1` and colour `1` means value `2`.

--------------------------------------------------------------------

#### 1.   Bipartite check and component information  

We run a BFS/DFS over all vertices.

For each not yet visited vertex `s`

* start BFS, assign `colour[s] = 0`
* store all vertices of this connected component in a list `comp`
* remember the smallest index `min_v` inside the component
* while expanding an edge `(v , to)`  
    * if `to` is unvisited → `colour[to] = colour[v] ^ 1`
    * else if `colour[to] == colour[v]` → **odd cycle**, impossible

If any component is not bipartite we output `NO`.

--------------------------------------------------------------------

#### 2.   Lexicographically smallest feasible vector  

Inside one component the whole colouring can be flipped:
`0 ↔ 1`.  
All components are independent, therefore we can decide the flip
separately for each component.

To obtain the smallest possible whole vector we look at the **first**
(vertex with smallest index) of the component, call it `min_v`.

*If we colour `min_v` with value `1` (i.e. colour `0`) the whole vector
becomes lexicographically smaller than the opposite choice,
because all earlier positions are already fixed.*

Hence for every component we choose the orientation that maps the colour
of `min_v` to value `1`.

Implementation:

```
if colour[min_v] == 0:   # already 0 → keep mapping 0→1, 1→2
        pass
else:                    # colour[min_v] == 1 → flip whole component
        for v in comp: colour[v] ^= 1
```

After the possible flip, the answer for vertex `i` is `1 + colour[i]`.

Isolated vertices (components of size 1, no edges) are handled the same
way – they receive colour `0` → value `1`, which is obviously optimal.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `NO` iff the system has no solution,
otherwise prints `YES` and the lexicographically smallest feasible vector.

---

##### Lemma 1  
During BFS the algorithm assigns a colour to a vertex exactly when a
2‑colouring of the already explored part exists, and detects a conflict
iff the graph contains an odd cycle.

**Proof.**  
BFS starts with an arbitrary vertex coloured `0`. Every traversed edge
requires the opposite colour for its other endpoint, which is exactly the
definition of a proper 2‑colouring.  
If we ever meet an already coloured neighbour with the same colour,
the two vertices are connected by a path of even length (the already
coloured path) plus the current edge, forming an odd cycle – a graph with
an odd cycle is not bipartite. Conversely, if the graph is not bipartite,
any BFS will eventually encounter such a conflict. ∎



##### Lemma 2  
If the algorithm finishes without reporting a conflict, the obtained
colouring (after possible flips) satisfies all constraints.

**Proof.**  
By Lemma&nbsp;1 every edge connects vertices of opposite colours.
After a possible component flip the two colours are still opposite,
therefore for each edge `(u,v)` we have `colour[u] ≠ colour[v]`.
Consequently `x_u = 1+colour[u]` and `x_v = 1+colour[v]` are `{1,2}` and
their sum is `3`. ∎



##### Lemma 3  
For a connected component `C` let `p` be its smallest index vertex.
Among the two feasible assignments of `C` the one that gives `x_p = 1`
is lexicographically smaller than the one with `x_p = 2`,
independently of the values of vertices outside `C`.

**Proof.**  
All vertices with index `< p` belong to earlier components, already fixed.
The first position where the two assignments differ is exactly `p`,
and `1 < 2`. Hence the assignment with `x_p = 1` is lexicographically
smaller. ∎



##### Lemma 4  
The algorithm chooses for each component the assignment with
`x_{min_v}=1`.

**Proof.**  
If `colour[min_v]` is `0` we keep the current mapping `0→1`.  
If it is `1` we flip every colour in the component, turning `1` into `0`,
so after the flip `colour[min_v]=0`. In both cases the final colour of
`min_v` is `0`, i.e. value `1`. ∎



##### Lemma 5  
The vector produced by the algorithm is the lexicographically smallest
feasible vector.

**Proof.**  
Consider components ordered by their minimal vertex index.
By Lemma&nbsp;4 the algorithm sets the smallest vertex of each component to
value `1`. By Lemma&nbsp;3 no other feasible assignment can have a smaller
value at that position while keeping earlier positions unchanged.
Proceeding component by component, the whole vector is minimal. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff the system of equations has no solution,  
* otherwise `YES` and the lexicographically smallest feasible state vector.

**Proof.**  

*If the algorithm prints `NO`.*  
That happens only when a conflict is detected during BFS.
By Lemma&nbsp;1 this means the graph contains an odd cycle, i.e. is not
bipartite, therefore no 2‑colouring exists and the system is unsatisfiable.

*If the system is unsatisfiable.*  
Then the graph is not bipartite, so any BFS must encounter a conflict,
hence the algorithm prints `NO`.

*If the algorithm prints `YES`.*  
No conflict occurred, thus the graph is bipartite.
By Lemma&nbsp;2 the produced vector satisfies all constraints.
By Lemma&nbsp;5 it is the lexicographically smallest among all feasible
vectors.

Thus the theorem holds. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency lists*: `O(n + m)` memory and time.  
*BFS over all vertices*: each edge examined once → `O(n + m)` time.  
*Flipping colours inside a component*: total work over all components is
`O(n)` (each vertex flipped at most once).  

Overall  

```
Time   : O(n + m)   ≤ 4·10^5
Memory : O(n + m)
```

Both fit easily into the limits.

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 = unvisited, 0/1 = colour
    answer = [0] * (n + 1)

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        min_v = start
        while q:
            v = q.popleft()
            if v < min_v:
                min_v = v
            for to in adj[v]:
                if colour[to] == -1:
                    colour[to] = colour[v] ^ 1
                    q.append(to)
                    comp.append(to)
                elif colour[to] == colour[v]:
                    print("NO")
                    return
        # orient component so that min_v gets value 1 (colour 0)
        if colour[min_v] == 1:
            for v in comp:
                colour[v] ^= 1

    # build answer
    for i in range(1, n + 1):
        answer[i] = 1 + colour[i]   # colour 0 -> 1, colour 1 -> 2

    print("YES")
    print(' '.join(str(answer[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```

conforms to the required input‑output format.
