<STATEMENT>
# Singular Network Configuration

Time limit: 1 s
Memory limit: 256 MB

A research facility operates a network of $n$ acoustic projectors, indexed from 1 to $n$. To maintain operational stability, every projector $i$ in the network must be assigned a scaling factor $f_i \in \{1, 2\}$.

The facility's layout contains $m$ interference thresholds, each connecting a specific pair of projectors. For the network assignment to be viable, any two projectors $u$ and $v$ connected by an interference threshold must have their scaling factors satisfy a specific resonance condition. Specifically, the interference matrix defined as:
$$M_{u,v} = \begin{pmatrix} f_u & 1 \\ 2 & f_v \end{pmatrix}$$
must be strictly singular (i.e., its determinant must be exactly zero). A configuration is only valid if this condition is satisfied across every threshold in the entire network.

Your objective is to determine if a viable assignment of scaling factors exists. If multiple valid assignments are possible, you must output the sequence of $n$ scaling factors that minimizes the network's impedance signature, which is defined by the sum:
$$Z = \sum_{i=1}^n f_i \cdot 3^{n-i}$$
Because the network may consist of multiple disconnected segments, this optimization applies globally across all projectors.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 200,000$, $0 \le m \le 200,000$), representing the number of projectors and the number of thresholds, respectively.

Each of the subsequent $m$ lines provides two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that an interference threshold connects the projector indexed $u$ and the projector indexed $v$.

## Output
If it is impossible to find a viable assignment, output `NO` on a single line.
If a viable assignment exists, output `YES` on the first line. On the second line, output $n$ space-separated integers (each being either 1 or 2) representing the scaling factor $f_i$ assigned to each projector from 1 to $n$. This sequence must be the one that strictly minimizes the impedance signature $Z$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit graph coloring constraint was replaced with a 2x2 matrix singularity condition, and the lexicographical tie-breaker was replaced by a base-3 weighted sum. This forces the model to algebraically deduce that the determinant condition ($f_u f_v = 2$) over the domain $\{1, 2\}$ strictly requires $f_u \neq f_v$, and mathematically recognize that minimizing the base-3 sum is exactly equivalent to finding the lexicographically smallest sequence.
</RATIONALE>
<PRESERVED_ANSWER>
The determinant condition $f_u f_v - 2 = 0$ for $f_i \in \{1, 2\}$ is satisfied if and only if one value is 1 and the other is 2, perfectly mirroring the original "different pulse cycles" constraint, and minimizing the base-3 sum $Z$ mathematically guarantees the exact same lexicographically smallest sequence as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains solvable in O(n + m) time using BFS to 2-color each connected component and greedily assigning the smaller value to the lowest-indexed unvisited node, keeping it in P.
</PRESERVED_CLASS>
