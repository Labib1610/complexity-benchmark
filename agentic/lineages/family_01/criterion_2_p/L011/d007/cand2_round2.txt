<STATEMENT>
# Harmonic Interference Resolution

Time limit: 1 s
Memory limit: 256 MB

A research facility operates a network of $n$ acoustic projectors. To maintain operational stability, every projector $i$ ($1 \le i \le n$) must be assigned a fixed power multiplier $p_i$, which must be chosen from the set $\{1, 2\}$.

The facility's layout dictates $m$ harmonic balance requirements. Each requirement specifies two projectors $u$ and $v$. To prevent interference, the product of the power multipliers assigned to these two projectors must be exactly 2. That is, for every specified pair, the condition $p_u \cdot p_v = 2$ must be satisfied. A configuration is only valid if this condition holds for all $m$ requirements simultaneously.

Your objective is to determine if a viable sequence of power multipliers $(p_1, p_2, \dots, p_n)$ exists. If multiple valid sequences are possible, you must output the lexicographically smallest one. (A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index where they differ, $A$ has a smaller value than $B$. This prioritization applies globally across the entire sequence of $n$ projectors.)

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 200,000$, $0 \le m \le 200,000$), representing the number of projectors and the number of requirements, respectively.

Each of the next $m$ lines provides two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that the requirement $p_u \cdot p_v = 2$ must hold for projectors $u$ and $v$.

## Output
If it is impossible to find a viable assignment of power multipliers, output `NO` on a single line.
If a viable assignment exists, output `YES` on the first line. On the second line, output $n$ space-separated integers representing the sequence $p_1, p_2, \dots, p_n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit instruction that connected projectors must have "different" values has been replaced with the algebraic constraint $p_u \cdot p_v = 2$ over the domain $\{1, 2\}$. Since the only way to satisfy this equation with these values is to assign 1 to one variable and 2 to the other, the problem remains exactly identical to 2-coloring a graph. However, models relying on surface-level pattern matching for graph coloring will fail to recognize the equivalence without first performing the mathematical deduction. Exact numeric bounds and original formatting have been restored to ensure compliance.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $p_u \cdot p_v = 2$ with $p_i \in \{1, 2\}$ is mathematically identical to $p_u \neq p_v$, ensuring every valid configuration and the lexicographically smallest tie-break remains exactly the same as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a valid 2-coloring of a graph (or determining none exists), which remains solvable in $O(n+m)$ time using Breadth-First Search, keeping it firmly in P.
</PRESERVED_CLASS>
