 We need to assign each node a value of 1 or 2 such that for every edge (u, v), the sum x_u + x_v is either 2 or 4, and the product of all these sums equals 3^m.  

Since each edge sum is either 2 or 4, the product is 2^k * 4^(m-k) = 2^(k + 2(m-k)) = 2^(2m - k).  
We need this to equal 3^m, which is impossible because 3^m is odd, while 2^(2m - k) is a power of 2 (even).  

Thus, no assignment can satisfy the condition unless m = 0.  
If m = 0, the product is 1 (empty product), which equals 3^0 = 1, so any assignment works. The lexicographically smallest is all 1's.

So the solution is:
- If m == 0: print YES and all 1's.
- Else: print NO.

```python
n, m = map(int, input().split())
for _ in range(m):
    input()
if m == 0:
    print("YES")
    print(" ".join(["1"] * n))
else:
    print("NO")
```
