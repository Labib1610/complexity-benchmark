Eigenvalue Bipartite Encoding
</METHOD_NAME>
<METHOD_DESCRIPTION>
This method replaces the explicit combinatorial path-counting condition with an algebraically equivalent condition based on the eigenvalues of a 2x2 coupling matrix. By forcing the model to evaluate the characteristic polynomial and check for irrational roots for the domain {1, 2}, it hides the simple inequality constraint behind a continuous mathematics concept (irrationality of matrix spectrum), preventing surface-level pattern matching on integer parity or subset sums.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<STATEMENT>
# Server Synchronization States

Time limit: 1 s
Memory limit: 256 MB

You are configuring a network of $n$ server nodes. Each node $i$ operates at a frequency multiplier $x_i$. To maintain synchronization with the base clock, $x_i$ must be a positive integer divisor of $2$.

The network contains $m$ bidirectional sync channels. To prevent data collisions, every channel imposes a routing balance requirement on its endpoints. Specifically, if a channel connects node $u$ and node $v$, define its coupling matrix as:
$$ C = \begin{pmatrix} x_u & 1 \\ 1 & x_v \end{pmatrix} $$
The channel is considered balanced if and only if the eigenvalues of $C$ are irrational numbers.

Your task is to determine a valid frequency multiplier assignment for all $n$ nodes such that every channel in the network is balanced. If multiple valid configurations exist, the system requires the one that yields the lexicographically smallest sequence of multipliers $x_1, x_2, \dots, x_n$. If it is impossible to balance all channels simultaneously, report that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$. The number of nodes $n$ is at least 1, and the number of channels $m$ is at least 0. Both are bounded by the datacenter's strict capacity ceiling of $200,000$.
Each of the following $m$ lines contains two integers $u$ and $v$ (valid node IDs ranging from 1 to $n$), indicating that a channel exists between node $u$ and node $v$.

## Output
If there is no valid multiplier assignment, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $x_1, x_2, \dots, x_n$, representing the lexicographically smallest valid sequence of frequency multipliers.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit binomial combinatorial path-counting with an algebraically equivalent condition based on the eigenvalues of a 2x2 coupling matrix. The domain {1, 2} is indirectly specified as 'positive integer divisors of 2'. This forces the model to evaluate the characteristic polynomial for the domain to discover that irrational roots only occur when $x_u \neq x_v$, preventing surface pattern matching on the number 3 or explicit bipartiteness.
</RATIONALE>
<PRESERVED_ANSWER>
The domain of $x_i$ is restricted to {1, 2} (positive integer divisors of 2), and the eigenvalue condition is mathematically equivalent to $x_u \neq x_v$, so the set of valid assignments and the lexicographical tie-breaking remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is still equivalent to finding the lexicographically first valid 2-coloring of a graph, solvable in $O(n+m)$ using Breadth-First Search.
</PRESERVED_CLASS>
<RISK>
Models might struggle if they cannot symbolically evaluate the eigenvalues of the matrix for the small domain, or if they misinterpret 'irrational numbers' as allowing complex numbers (though the discriminant is strictly positive for all valid inputs, ensuring real roots).
</RISK>
