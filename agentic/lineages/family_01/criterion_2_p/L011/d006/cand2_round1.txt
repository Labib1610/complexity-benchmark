<METHOD_DESCRIPTION>Replaces the direct algebraic polynomial with a small algorithmic process (Collatz sequence steps) whose step count for the possible domain values strictly maximizes at the desired heterogeneous assignment, preserving the identical mathematical reduction while breaking algebraic pattern matching.</METHOD_DESCRIPTION>

<STATEMENT>
# Harmonic Interference Resolution

Time limit: 1 s
Memory limit: 256 MB

A research facility operates a network of acoustic projectors. To maintain operational stability, every projector in the network must be assigned a fixed pulse cycle of either 1 microsecond or 2 microseconds.

The facility's layout contains multiple interference thresholds, each connecting a specific pair of projectors. A cycle assignment is only viable if it resolves the interference across the entire network. 

For any threshold connecting projector $u$ and projector $v$, their combined resonance $R$ is calculated as $p_u^2 + p_v^2$, where $p_u$ and $p_v$ are their assigned pulse cycles. The synchronization score of this threshold is determined by the number of steps required to reduce $R$ to 1 using the following sequence of operations:
- If $R$ is even, replace $R$ with $R / 2$.
- If $R$ is odd, replace $R$ with $3R + 1$.

This operation is repeated, and the total number of operations performed until $R$ equals 1 is the threshold's synchronization score.

For the network assignment to be viable, the total sum of the synchronization scores across all $m$ thresholds must equal exactly $5m$.

Your objective is to determine if a viable cycle assignment exists for the entire network. If multiple valid assignments are possible, the diagnostic system requires a single deterministic configuration. Among all valid assignments, output the lexicographically smallest sequence of $n$ pulse cycles (ordered from projector 1 to projector $n$). This means selecting the sequence that features the shorter pulse cycle (1 instead of 2) at the earliest projector index where the assignments differ.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 200,000$, $0 \le m \le 200,000$), representing the number of projectors and the number of thresholds, respectively.

Each of the subsequent $m$ lines provides two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that an interference threshold connects the projector indexed $u$ and the projector indexed $v$.

## Output
If it is impossible to find a viable cycle assignment, output `NO` on a single line.
If a viable assignment exists, output `YES` on the first line. On the second line, output $n$ space-separated integers (each being either 1 or 2) representing the pulse cycle assigned to each projector from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit algebraic formula $6(p_u+p_v) - (p_u+p_v)^2 = 9$ allowed models to trivially deduce $p_u+p_v=3$ via equation solving, bypassing the need to analyze the constraint's structure. This rewrite replaces the formula with a procedural sequence (Collatz steps) on the sum of squares. Models must now evaluate the procedure for the domain $\{1, 2\}^2$, observe that the step counts are 1, 3, and 5, and logically deduce that a global sum of $5m$ strictly requires every threshold to achieve the maximum score of 5, which only occurs when $p_u \neq p_v$.
</RATIONALE>
<PRESERVED_ANSWER>
The Collatz step counts for the possible values of $p_u^2 + p_v^2$ are 1 (for 1,1), 3 (for 2,2), and 5 (for 1,2 or 2,1); since the maximum possible score is 5, a total sum of $5m$ is achievable if and only if every threshold is assigned distinct pulse cycles, making the viable assignments mathematically identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains a pure bipartiteness (2-coloring) check on an undirected graph, which is solvable in $O(n+m)$ time using BFS/DFS, keeping it in class P.
</PRESERVED_CLASS>
