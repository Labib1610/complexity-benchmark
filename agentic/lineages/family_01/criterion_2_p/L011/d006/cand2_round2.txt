<METHOD_NAME>Matrix Eigenvalue Condition</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the grid path combinatorics with a condition on the eigenvalues of a 2x2 matrix defined by the endpoint states. The matrix has irrational eigenvalues if and only if the states are different. This hides the bipartiteness check behind a linear algebra property, forcing models to analyze the characteristic polynomial.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Server Synchronization States

Time limit: 1 s   Memory limit: 256 MB

You are configuring a network of $n$ server nodes. Each node $i$ must be assigned an operational state $x_i$. The hardware restricts each node's state such that $x_i \in \{1, 2\}$.

The nodes are connected by a set of $m$ bidirectional sync channels. To prevent data collisions during synchronization, every channel imposes a routing balance requirement on its endpoints. Specifically, if a channel connects node $u$ and node $v$, we define its characteristic synchronization matrix as:
$$ M(x_u, x_v) = \begin{pmatrix} x_u & 1 \\ 1 & x_v \end{pmatrix} $$
The channel is considered balanced if and only if the matrix $M(x_u, x_v)$ has irrational eigenvalues.

Your task is to determine a valid state assignment for all $n$ nodes such that every channel is balanced. If there are multiple valid ways, you must output the assignment that produces the lexicographically smallest sequence of operational states $x_1, x_2, \dots, x_n$. If it is impossible to satisfy all channel requirements simultaneously, report that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$. The number of nodes $n$ is at least 1 and bounded by a network maximum of $2\cdot 10^5$. The number of channels $m$ is at least 0 and at most $2\cdot 10^5$.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u \le n$ and $1 \le v \le n$), indicating that a channel exists between node $u$ and node $v$.

## Output
If there is no valid state assignment, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $x_1, x_2, \dots, x_n$, representing the lexicographically smallest valid sequence of operational states.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem replaces the explicit monotone-grid path counting with an algebraic condition on the eigenvalues of a 2x2 matrix formed by the endpoint states. Since the states are restricted to {1, 2}, calculating the characteristic polynomial shows that the roots are irrational if and only if the states are distinct. This prevents models from pattern-matching the path count to a simple inequality, forcing them to derive the $x_u \neq x_v$ requirement from the matrix properties.
</RATIONALE>
<PRESERVED_ANSWER>
The matrix condition evaluates to irrational eigenvalues exactly when $x_u \neq x_v$, which perfectly preserves the opposite-state constraint of the original path-counting formulation.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains checking if the graph is 2-colorable (bipartite) and finding the lexicographically smallest coloring, which is still solvable in linear time using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might struggle to correctly evaluate the eigenvalues for all four possible combinations of {1, 2} due to algebraic reasoning failures, but the mathematical definition is unambiguous.
</RISK>
