# Server Synchronization States

Time limit: 1 s   Memory limit: 256 MB

You are configuring a network of $n$ server nodes. Each node $i$ must be assigned an operational state $x_i$, which can be any strictly positive integer. 

The nodes are connected by a set of $m$ bidirectional sync channels. To prevent data corruption during synchronization, every channel imposes a strict balance requirement on its endpoints: if a channel connects node $u$ and node $v$, their operational states must satisfy the equation $3x_u x_v = 2(x_u + x_v)$.

Your task is to determine a valid state assignment for all $n$ nodes. If there are multiple valid ways to assign the states, you must output the assignment that is lexicographically smallest when written as the sequence $x_1, x_2, \dots, x_n$. If it is impossible to satisfy all channel requirements simultaneously, you must report that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$. The number of nodes $n$ is at least 1 and bounded by a network maximum of $2\cdot 10^5$. The number of channels $m$ is at least 0 and at most $2\cdot 10^5$.
Each of the following $m$ lines contains two integers $u$ and $v$ (valid node IDs ranging from 1 to $n$), indicating that a channel exists between node $u$ and node $v$.

## Output
If there is no valid state assignment, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $x_1, x_2, \dots, x_n$, representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was reframed to remove the explicit $\{1, 2\}$ domain restriction and the direct sum-of-squares equation that models recognized as a fixed binary relation. Instead, the state domain is opened to all strictly positive integers, and the edge constraint is changed to $3x_u x_v = 2(x_u + x_v)$. This forces models to first solve the Diophantine equation to deduce that the only valid positive integer states for connected nodes are exactly $\{1, 2\}$, before they can recognize the underlying bipartiteness structure.
</RATIONALE>
<PRESERVED_ANSWER>
The Diophantine equation $3xy = 2(x+y)$ for positive integers only has the solutions $(1, 2)$ and $(2, 1)$, meaning constrained nodes are forced into the exact same $\{1, 2\}$ alternating states as the seed; isolated nodes, completely unconstrained, will still take the value 1 to minimize the lexicographical sequence, matching the seed perfectly.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem remains 2-coloring (bipartiteness checking) and finding the lexicographically smallest orientation for each component, which is solvable in $O(n+m)$ time using Breadth-First Search.
</PRESERVED_CLASS>
