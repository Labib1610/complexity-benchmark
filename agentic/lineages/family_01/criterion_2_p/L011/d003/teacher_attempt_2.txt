# Hazardous Cargo Transport

Time limit: 1 s   Memory limit: 256 MB

You are coordinating the transport of $n$ cargo containers, numbered $1$ through $n$. Each container must be loaded onto one of two available cargo ships: ship 1 or ship 2.

The safety regulations include $m$ hazard manifests. Each manifest identifies a specific pair of containers that hold mutually reactive materials. To prevent accidents during transit, the two containers listed in a manifest must be separated by being loaded onto different ships. If one container is placed on ship 1, the other must be placed on ship 2.

Your task is to determine if there is a valid loading plan for all $n$ containers that strictly follows all $m$ hazard manifests. If there are multiple valid plans, you must provide the one that is lexicographically smallest. A plan $A$ is lexicographically smaller than plan $B$ if, at the first container $i$ where they differ, plan $A$ places container $i$ on ship 1 while plan $B$ places it on ship 2.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a hazard manifest involving container $u$ and container $v$.

## Output
If no valid loading plan is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each either 1 or 2) representing the assigned ship for each container in the lexicographically smallest valid loading plan.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I changed the mechanical linkage scenario to a logistics scenario involving cargo containers and hazard manifests. This removes the mechanical framing that might have aligned with standard bipartite graph examples (like gears or levers) and forces the model to recognize the 2-coloring structure purely from the abstract constraint of separating pairs of items onto two ships.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to assign each item to one of two states and ensure specified pairs have different states is logically identical, as is the lexicographical tie-breaking rule, ensuring the exact same output for any input.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring of an undirected graph (or checking for bipartiteness), which is solvable in O(n+m) time using breadth-first or depth-first search, keeping it in the P complexity class.
</PRESERVED_CLASS>
