# Mechanical Linkage Calibration

Time limit: 1 s   Memory limit: 256 MB

You are calibrating a complex mechanical engine consisting of $n$ control levers, numbered $1$ through $n$. Each lever must be locked into one of two available modes: mode 1 or mode 2.

The engine contains $m$ pivot rods. Each pivot rod links a specific pair of levers. Due to the fixed linkage mechanics, any two levers connected by a rod must be configured such that the arithmetic sum of their modes is exactly 3.

Your task is to determine if there is a valid configuration for all $n$ levers that respects the constraints of all $m$ pivot rods. If there are multiple valid configurations, you must provide the one that prioritizes mode 1 for the lowest-numbered levers. Specifically, if two valid configurations differ, the preferred one assigns mode 1 to the lever with the smallest index where the two configurations disagree.

## Input
The first line contains two integers $n$ and $m$. The engine's chassis is built from up to 200 modular panels, each capable of housing exactly 1000 levers. The total number of levers $n$ will be at least 1 and will not exceed the combined capacity of these 200 panels. The number of installed pivot rods $m$ can be as low as 0 and is capped at the same combined maximum capacity.

Each of the following $m$ lines contains two integers $u$ and $v$, representing a pivot rod connecting lever $u$ and lever $v$. Both $u$ and $v$ are guaranteed to be valid lever indices from 1 to $n$.

## Output
If no valid configuration is physically possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each either 1 or 2) representing the mode for each lever in the preferred valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the "opposite slots" condition with an algebraic constraint ("arithmetic sum of their modes is exactly 3") to prevent models from reflexively triggering bipartite coloring based on the keyword "opposite". I also removed the bare inequalities in the input bounds, replacing them with a physical capacity description (200 panels of 1000 levers) that the reader must multiply to derive the $2 \cdot 10^5$ limit, forcing step-by-step reading comprehension.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic constraint $x+y=3$ for $x,y \in \{1,2\}$ is logically identical to $x \neq y$, keeping all valid configurations exactly the same, and the tie-breaking rule explicitly defines standard lexicographical comparison.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in linear time using BFS or DFS (P).
</PRESERVED_CLASS>
<RISK>
A reader might skim the tie-breaking rule and assume it asks for the maximum total number of 1s instead of a strict left-to-right preference, though the explicit definition ("smallest index where the two configurations disagree") heavily mitigates this risk.
</RISK>
