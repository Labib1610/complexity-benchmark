We can model each transmitter as a binary variable:  
- Interval `[0,1]` → right endpoint `1`  
- Interval `[1,2]` → right endpoint `2`  

The condition “union of two intervals is an interval of length 2” means the two intervals must be different.  
So each requirement `(u, v)` means `value[u] != value[v]`.  

This becomes a **bipartite graph coloring** problem.  
If the graph is not bipartite, output `NO`.  
Otherwise, we want the lexicographically smallest assignment of `1`/`2` over all nodes.

We can do BFS/DFS, assigning `1` to the first unvisited node, and propagate alternating values.  
This gives the lexicographically smallest because we always try to assign `1` when possible.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(' '.join(str(c + 1) for c in color))
```
