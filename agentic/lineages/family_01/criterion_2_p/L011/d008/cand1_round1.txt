<STATEMENT>
# Harmonic Interference Resolution

Time limit: 1 s
Memory limit: 256 MB

A research facility operates a network of $n$ acoustic projectors. To maintain operational stability, every projector $i$ ($1 \le i \le n$) must be assigned a fixed power multiplier $p_i$, which must be chosen from the set $\{1, 2\}$.

The facility's layout dictates $m$ harmonic balance requirements. Each requirement specifies two projectors $u$ and $v$ that interact. 

A configuration of power multipliers $(p_1, p_2, \dots, p_n)$ is only viable if the network's total interference resonance is perfectly balanced by its baseline damping capacity. 

The **total interference resonance** $R$ is defined by the pairwise interactions across all $m$ requirements:
$$R = 2 \sum_{j=1}^m (p_{u_j} \cdot p_{v_j}) + 9m$$
where $u_j$ and $v_j$ are the two projectors specified in the $j$-th requirement.

The **baseline damping capacity** $D$ is defined by the individual loads on each projector:
$$D = \sum_{i=1}^n d_i (6p_i - p_i^2)$$
where $d_i$ is the number of times projector $i$ appears across all $m$ requirements. (For example, if a projector is specified in three different requirements, its $d_i = 3$. If a requirement specifies the same projector twice, it contributes 2 to that projector's count.)

To prevent interference, the condition $R = D$ must be satisfied.

Your objective is to determine if a viable sequence of power multipliers $(p_1, p_2, \dots, p_n)$ exists. If multiple viable sequences are possible, you must output the one that prioritizes smaller multipliers for lower-indexed projectors. Specifically, when comparing any two viable sequences, the correct sequence is the one that has a smaller value at the first index where the two sequences differ.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 200,000$, $0 \le m \le 200,000$), representing the number of projectors and the number of requirements, respectively.

Each of the next $m$ lines provides two integers $u$ and $v$ ($1 \le u, v \le n$), indicating a requirement specifying projectors $u$ and $v$.

## Output
If it is impossible to find a viable assignment of power multipliers, output `NO` on a single line.
If a viable assignment exists, output `YES` on the first line. On the second line, output $n$ space-separated integers representing the sequence $p_1, p_2, \dots, p_n$. This sequence must be the correctly prioritized valid assignment as described above.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The pairwise bipartite constraint ($p_u \cdot p_v = 2$) was replaced with a mathematically equivalent global equation $R = D$. To solve this efficiently, a model must perform algebraic manipulation—rewriting the node-weighted sum as an edge sum and completing the square—to discover that the equation simplifies to $\sum (p_u + p_v - 3)^2 = 0$. This forces the model to genuinely reason through the math to uncover the hidden graph-coloring structure, rather than pattern-matching on local pairwise inequalities.
</RATIONALE>
<PRESERVED_ANSWER>
The equation $R = D$ is algebraically identical to $\sum_{j=1}^m (p_{u_j} + p_{v_j} - 3)^2 = 0$, which, given $p_i \in \{1, 2\}$, is satisfied if and only if $p_{u_j} \neq p_{v_j}$ for every requirement, making it exactly equivalent to the original constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in $O(N+M)$ time using BFS or DFS.
</PRESERVED_CLASS>
