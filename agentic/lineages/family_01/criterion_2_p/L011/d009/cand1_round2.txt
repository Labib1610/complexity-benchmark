<METHOD_NAME>Laplacian Quadratic Form</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the determinant product condition with the quadratic form of the graph Laplacian matrix. Since the variables are restricted to {1, 2}, the quadratic form x^T H x exactly computes the number of edges with different endpoint assignments. Equating it to m forces a proper 2-coloring, while naturally handling multigraphs and self-loops, completely avoiding graph terminology.</METHOD_DESCRIPTION>

<STATEMENT>
# Server Synchronization States

Time limit: 1 s
Memory limit: 256 MB

You are configuring a network of $n$ servers. Each server $i$ must be assigned an operational tier $x_i \in \{1, 2\}$.

The servers are connected by a sequence of $m$ bidirectional sync channels. Based on these channels, we construct an $n \times n$ symmetric configuration matrix $H$. Initially, all entries of $H$ are $0$. 
Then, for each of the $m$ channels in the sequence:
Suppose the channel connects server $u$ and server $v$.
If $u \neq v$, we apply exactly these four updates to $H$:
- Add $1$ to $H_{u, u}$
- Add $1$ to $H_{v, v}$
- Subtract $1$ from $H_{u, v}$
- Subtract $1$ from $H_{v, u}$
(If $u = v$, no updates are made to $H$ for this channel.)

Let $x$ be an $n \times 1$ column vector where the $i$-th element is $x_i$. The network's energetic footprint is evaluated using the quadratic form:
$$E(x) = x^T H x$$

To prevent data bottlenecks while maintaining hardware limits, the network is considered perfectly balanced if and only if $E(x) = m$.

Your task is to determine a valid tier assignment $x$ for all $n$ servers such that the network is perfectly balanced. If there are multiple valid ways, you must output the assignment that produces the lexicographically smallest sequence of operational tiers $x_1, x_2, \dots, x_n$. If it is impossible to satisfy the requirement, report that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a sync channel exists between server $u$ and server $v$.

## Output
If there is no valid tier assignment, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $x_1, x_2, \dots, x_n$, representing the lexicographically smallest valid sequence of operational tiers.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
By defining the configuration matrix $H$ iteratively from the channel list, it constructs the graph Laplacian. The quadratic form $x^T H x$ simplifies to the sum of squared differences $(x_u - x_v)^2$ over all edges. Since $x_i \in \{1, 2\}$, this sum equals $m$ if and only if $x_u \neq x_v$ for every channel. This forces models to algebraically recognize the Laplacian quadratic form and deduce the 2-coloring requirement, completely stripping away the bipartite graph affordances.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $x^T H x = m$ with $x_i \in \{1, 2\}$ is mathematically identical to requiring every edge to connect nodes with different values (and forbidding self-loops), which is exactly the bipartite coloring condition established by the original $3^m$ determinant product.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains identical to 2-coloring (checking bipartiteness and assigning colors to minimize lexicographically), keeping it in P and solvable via BFS in $O(n+m)$ time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the matrix construction if they fail to understand the iterative updates for duplicate edges, though the instructions ("for each of the m channels... apply exactly these four updates") are explicit and standard.
</RISK>
