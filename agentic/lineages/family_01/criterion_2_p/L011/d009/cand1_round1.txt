<METHOD_NAME>Product Set Span Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces a discrete inequality or union constraint with the span (max - min) of the Cartesian product set under scalar multiplication, separating the identical-choice cases (which yield different spans from each other) from the different-choice cases, thereby perfectly preserving the logic gate/coloring requirement while appearing as a continuous math problem.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Continuous Band Allocation

Time limit: 1 s
Memory limit: 256 MB

A research facility operates a network of $n$ wideband transmitters. To maintain operational stability, every transmitter $i$ ($1 \le i \le n$) must be assigned a fixed continuous operational band $I_i$. This band must be chosen from the set of two closed real intervals: $\{[0, 1], [1, 2]\}$.

The facility's layout dictates $m$ spacing requirements. Each requirement specifies two transmitters $u$ and $v$. To prevent resonant interference, the cross-modulation spectrum of these two transmitters must span exactly 2 units. The cross-modulation spectrum for transmitters $u$ and $v$ is defined as the set of all possible products of frequencies from their respective bands:
$$ S_{u,v} = \{x \cdot y \mid x \in I_u, y \in I_v\} $$
A configuration is valid only if, for all $m$ specified pairs, the difference between the maximum and minimum values in $S_{u,v}$ is precisely 2.

Your objective is to determine if a viable sequence of operational bands $(I_1, I_2, \dots, I_n)$ exists. If multiple valid sequences are possible, you must output the sequence that yields the lexicographically smallest sequence of right endpoints. 

For an interval $[a, b]$, the right endpoint is $b$. Thus, you will output a sequence of $n$ integers, each being either $1$ or $2$. (A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index where they differ, $A$ has a smaller value than $B$. This prioritization applies globally across the entire sequence of $n$ transmitters.)

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 200,000$, $0 \le m \le 200,000$), representing the number of transmitters and the number of requirements, respectively.

Each of the next $m$ lines provides two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that the requirement regarding the span of the cross-modulation spectrum $S_{u,v}$ must hold for transmitters $u$ and $v$.

## Output
If it is impossible to find a viable assignment of operational bands, output `NO` on a single line.
If a viable assignment exists, output `YES` on the first line. On the second line, output $n$ space-separated integers representing the sequence of right endpoints of $I_1, I_2, \dots, I_n$. This sequence must be the lexicographically smallest valid sequence of right endpoints.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The previous versions allowed models to trivially map the "union length exactly 2" condition to a bipartite graph coloring requirement. To defeat this, I replaced the union length constraint with the span (difference between maximum and minimum) of the set of all pairwise products of elements from the two intervals. Since $[0,1] \times [0,1]$ has a span of 1, $[1,2] \times [1,2]$ has a span of 3, and $[0,1] \times [1,2]$ has a span of 2, requiring a span of exactly 2 mathematically forces the intervals to be different. This perfectly preserves the 2-coloring reduction while completely hiding the bipartite graph pattern behind continuous set operations.
</RATIONALE>
<PRESERVED_ANSWER>
The product set span condition is satisfied if and only if one interval is [0, 1] and the other is [1, 2], which is mathematically identical to the original requirement that their union has length 2, meaning all valid assignments and the lexicographical tie-breaking remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still identically reduces to finding the lexicographically smallest valid 2-coloring of a graph (or determining if it is bipartite), which is solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models or readers might misinterpret $x \cdot y$ as a dot product if they forget that $x$ and $y$ are scalars from real intervals, though the phrasing "products of frequencies" and the 1D interval definitions make the scalar multiplication unambiguously clear.
</RISK>
