<STATEMENT>
# Server Synchronization States

Time limit: 1 s
Memory limit: 256 MB

You are configuring a network of $n$ server nodes. Each node $i$ must be assigned an operational tier $x_i \in \{1, 2\}$.

The nodes are connected by a set of $m$ bidirectional sync channels. For a channel connecting node $u$ and node $v$, the channel's load is defined as $x_u + x_v$.

To prevent data bottlenecks while maintaining hardware limits, the network is considered perfectly balanced if and only if, for every node $i$ in the network, the sum of the loads of all channels connected to node $i$ is exactly $3 d_i$, where $d_i$ is the total number of channels connected to node $i$. (If a node has no connected channels, its sum of loads is 0, which perfectly matches $3 \cdot 0$, so it is automatically considered balanced).

Your task is to determine a valid tier assignment for all $n$ nodes such that the network is perfectly balanced. If there are multiple valid ways, you must output the assignment that produces the lexicographically smallest sequence of operational tiers $x_1, x_2, \dots, x_n$. If it is impossible to satisfy the requirement, report that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a sync channel exists between node $u$ and node $v$.

## Output
If there is no valid tier assignment, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $x_1, x_2, \dots, x_n$, representing the lexicographically smallest valid sequence of operational tiers.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I changed the global product of determinants to a local sum of channel loads for each node. This forces the model to reason about local conditional extrema: since the target sum is $3 d_i$, and the load is $x_u + x_v$, the available values depend on $x_i$. If $x_i=1$, the load can only be 2 or 3, so an average of 3 strictly requires all neighbors to be 2. This prevents the heuristic "average is 3, so we can mix 2 and 4" because 4 is locally impossible for a node with tier 1.
</RATIONALE>
<PRESERVED_ANSWER>
The local condition $\sum (x_i + x_j) = 3 d_i$ requires every term to be exactly 3 (since if $x_i=1$, the maximum possible term is 3; if $x_i=2$, the minimum possible term is 3), which implies $x_j = 3 - x_i \neq x_i$ for all edges, perfectly preserving the exact equivalence to valid 2-colorings.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in $O(n+m)$ time using BFS.
</PRESERVED_CLASS>
<RISK>
The phrase "number of channels connected to node $i$" could be slightly ambiguous if there are self-loops and the reader assumes standard graph degree (where a self-loop adds 2 to degree) instead of simply counting the incident channel entities, but either interpretation correctly renders self-loops invalid, preserving correctness.
</RISK>
