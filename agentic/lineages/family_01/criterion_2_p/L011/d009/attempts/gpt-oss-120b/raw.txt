**Solution Explanation**

For a vertex `i` we have to choose a state `s_i ∈ {1,2}`.
For an edge `{u,v}` the thermal footprint is  

```
f(u,v) = 2^{s_u} + 2^{s_v} - 1
```

`2^{1}=2 , 2^{2}=4`, therefore the only possible values are  

* `s_u = s_v = 1` → `f = 3`  
* `s_u = 1 , s_v = 2` (or opposite) → `f = 5`  
* `s_u = s_v = 2` → `f = 7`

The total product must be `5^m`.  
Consequently **every edge must have value `5`**, i.e. its ends must have
different states, one `1` and the other `2`.

So the required configuration is exactly a **proper 2‑colouring** of the
graph with colours `{1,2}`.
If the graph is not bipartite, the answer is impossible.



--------------------------------------------------------------------

#### 1.   Bipartite check and component handling
We run a BFS/DFS over all vertices.

* `col[v] = 0` or `1` – the parity colour inside the component.
* While traversing we also collect the list `verts` of vertices belonging to
  the current component.

If we ever see an edge joining two vertices with the same `col`,
the graph is not bipartite → output `NO`.

--------------------------------------------------------------------

#### 2.   Lexicographically smallest assignment
Inside one component we have two possible assignments:

```
A : col = 0 → state 1 , col = 1 → state 2
B : col = 0 → state 2 , col = 1 → state 1   (swap)
```

Only the vertices of this component are affected, all other components are
independent.  
To obtain the globally lexicographically smallest sequence we may decide
the component independently: we simply choose the smaller of the two
sequences **restricted to the vertices of this component** (ordered by
their indices).

Implementation:

```
verts = sorted list of vertices of the component
seqA = [ 1 if col[v]==0 else 2 for v in verts ]
seqB = [ 2 if col[v]==0 else 1 for v in verts ]
if seqA <= seqB (lexicographically):
        use A
else:   use B
```

The chosen states are written into the final answer array `ans`.

--------------------------------------------------------------------

#### 3.   Special case `m = 0`
No edges → any states are allowed.
The lexicographically smallest sequence is all `1`s.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `YES` and the lexicographically smallest
valid configuration iff such a configuration exists.

---

##### Lemma 1  
For any edge `{u,v}` the product condition `∏ f(u,v) = 5^m` holds
iff `s_u ≠ s_v` (one endpoint state `1`, the other `2`).

**Proof.**  
The only possible edge values are `3,5,7`.  
If an edge value is `3` or `7` the product contains a factor different from
`5`, therefore the whole product cannot be `5^m`.  
Thus every edge must contribute factor `5`, which happens exactly when the
states differ (`2+4-1 = 5`). ∎



##### Lemma 2  
A configuration satisfying the requirement exists **iff** the graph is
bipartite.

**Proof.**  
By Lemma&nbsp;1 each edge must join vertices of different states, i.e. the
states give a proper 2‑colouring of the graph.  
Conversely, any proper 2‑colouring with colours `{1,2}` makes every edge
value `5`, hence the product is `5^m`. ∎



##### Lemma 3  
For a fixed connected component, among the two possible assignments
(`A` and `B`) the lexicographically smaller one (restricted to the
component’s vertices) yields the smallest possible values of those
positions in any global valid sequence.

**Proof.**  
The component’s vertices appear at certain indices in the global sequence,
all other indices belong to other components and are independent of the
choice inside this component.  
Changing the component from `A` to `B` only changes the values at its own
indices, leaving the rest unchanged.  
Therefore, to minimise the whole sequence, we must minimise the subsequence
formed by these indices, i.e. pick the smaller of `A` and `B`. ∎



##### Lemma 4  
Choosing, for every component, the smaller of its two assignments (as the
algorithm does) yields the lexicographically smallest global valid
sequence.

**Proof.**  
Consider the global index order `1 … n`.  
Let `i` be the first index where the algorithm’s output could differ from
any other valid sequence. Vertex `i` belongs to some component `C`.  
All earlier indices belong to components already fixed identically by the
algorithm (otherwise they would be earlier differences).  
By Lemma&nbsp;3 the algorithm’s choice for `C` gives the smallest possible
values at all indices of `C`, in particular at `i`. Hence any other valid
sequence must have the same value at `i`. Contradiction unless the other
sequence is identical. ∎



##### Lemma 5  
If the graph is bipartite, the algorithm outputs a valid configuration.

**Proof.**  
BFS colours the graph with `col ∈ {0,1}` without conflict, so the graph is
bipartite.  
For each component we assign states `1`/`2` according to either `A` or `B`,
both of which respect the parity colour, i.e. endpoints of every edge have
different states. By Lemma&nbsp;1 the product condition holds. ∎



##### Theorem  
The algorithm prints  

* `NO` iff no valid configuration exists,  
* otherwise `YES` and the lexicographically smallest valid sequence.

**Proof.**  

*If the algorithm prints `NO`.*  
That happens only when a conflict is detected, i.e. the graph is not
bipartite. By Lemma&nbsp;2 no configuration exists.

*If a configuration exists.*  
Then the graph is bipartite. The algorithm never reports a conflict,
produces a sequence (Lemma&nbsp;5) and, by Lemma&nbsp;4, this sequence is
the lexicographically smallest among all valid ones.

Thus the statement holds. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis
*BFS/DFS* visits each vertex and edge once: `O(n + m)` time.  
All additional work (sorting vertices inside a component) costs
`O(size_of_component log size)`; summed over components it is `O(n log n)`,
but we can avoid sorting by collecting vertices in the order they are
encountered, which is already increasing because we iterate vertices from
`1` to `n` and start a new BFS only when the vertex is still unvisited.
Thus total time `O(n + m)`.  

Memory: adjacency list `O(n + m)`, colour array, answer array – all
`O(n + m)` ≤ 4·10⁵, well inside limits.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    if m == 0:
        # all 1s is optimal
        print("YES")
        print(" ".join(["1"] * n))
        return

    col = [-1] * (n + 1)          # -1 = unvisited, 0/1 = parity colour
    ans = [0] * (n + 1)           # final states, 1-indexed
    from collections import deque

    for start in range(1, n + 1):
        if col[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        col[start] = 0
        verts = []
        ok = True
        while q:
            v = q.popleft()
            verts.append(v)
            for to in adj[v]:
                if col[to] == -1:
                    col[to] = col[v] ^ 1
                    q.append(to)
                elif col[to] == col[v]:
                    print("NO")
                    return
        # decide which assignment is lexicographically smaller
        verts.sort()   # ensure increasing index order
        seqA = [1 if col[v] == 0 else 2 for v in verts]
        seqB = [2 if col[v] == 0 else 1 for v in verts]
        if seqA <= seqB:
            for v, val in zip(verts, seqA):
                ans[v] = val
        else:
            for v, val in zip(verts, seqB):
                ans[v] = val

    print("YES")
    print(" ".join(str(ans[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```

conforms to the required input‑output format.
