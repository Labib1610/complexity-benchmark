**Solution Explanation**

For every reactor we have to choose one of the two mixtures  

* mixture 1 : Alpha = **1**, Beta = 2  
* mixture 2 : Alpha = **2**, Beta = 1  

For a requirement `(u , v)` the total amount of Alpha in the two reactors must be `3`.
Because each reactor contributes either `1` or `2` litres of Alpha, the only way to obtain
`3` is

```
Alpha(u) + Alpha(v) = 3   ⇔   Alpha(u) ≠ Alpha(v)
```

So every requirement forces the two reactors to receive **different** mixtures.
The whole set of requirements is therefore a graph whose edges demand *different*
values on their ends – exactly the definition of a **bipartite** graph.

--------------------------------------------------------------------

#### 1.   When does a solution exist ?

A solution exists **iff** the graph is bipartite.
During a BFS/DFS we colour vertices with `0` / `1`.  
If we ever meet an edge whose ends already have the same colour, the graph is not
bipartite → answer `NO`.

--------------------------------------------------------------------

#### 2.   Lexicographically smallest valid sequence

In a bipartite connected component there are only two possible assignments:

```
colour 0 → Alpha = 1 , colour 1 → Alpha = 2
or
colour 0 → Alpha = 2 , colour 1 → Alpha = 1
```

All vertices of the component change their value together when we swap the two
possibilities.

Consider the whole vertex order `1 … n`.  
Let `i` be the first vertex (smallest index) whose value is not yet fixed.
`i` belongs to some component `C`.  
We are free to choose which colour of `C` becomes `1`.  
Choosing the colour that contains `i` makes `Alpha(i) = 1`, the smallest possible
value, and therefore yields the lexicographically smallest overall sequence.
After fixing component `C` we never touch it again, so the greedy choice is optimal.

Consequences  

* For each component we only have to know which colour contains the **minimum**
  vertex index of this component.
* That colour is assigned Alpha = 1, the other colour Alpha = 2.

Isolated vertices are components of size 1, they receive `1`.

--------------------------------------------------------------------

#### 3.   Algorithm
```
read n, m
build adjacency list
colour[1…n] = -1   // -1 = unvisited, 0/1 = bipartite colour
answer[1…n]

for v = 1 … n
    if colour[v] == -1
        // start new component
        bfs queue ← v, colour[v] = 0
        component_vertices = []
        while queue not empty
            x = pop
            component_vertices.append(x)
            for each neighbour y of x
                if colour[y] == -1
                    colour[y] = colour[x] ^ 1
                    push y
                else if colour[y] == colour[x]
                    print "NO" and exit   // not bipartite
        // component finished
        min_vertex = min(component_vertices)
        // colour of min_vertex will become Alpha = 1
        if colour[min_vertex] == 0
            map0 = 1 ; map1 = 2
        else
            map0 = 2 ; map1 = 1
        for each x in component_vertices
            answer[x] = map0 if colour[x]==0 else map1

print "YES"
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise prints `YES` and the lexicographically smallest valid sequence.

---

##### Lemma 1  
If the algorithm prints `NO`, the graph is not bipartite, therefore no assignment
satisfying all requirements exists.

**Proof.** `NO` is printed only when during BFS an edge `(a,b)` with
`colour[a] == colour[b]` is discovered. This is exactly a violation of the
definition of bipartiteness. Any assignment must give different Alpha values to
`a` and `b`, impossible with equal colours. ∎



##### Lemma 2  
If the graph is not bipartite, the algorithm prints `NO`.

**Proof.** A non‑bipartite graph contains a connected component that is not
bipartite. BFS on that component inevitably meets an edge whose ends already have
the same colour (standard property of BFS 2‑colouring). The algorithm detects it
and prints `NO`. ∎



##### Lemma 3  
For a bipartite connected component `C` the algorithm assigns Alpha = 1 to exactly
the vertices whose colour equals `colour[min(C)]`, and Alpha = 2 to the others.

**Proof.** After BFS finishes, `colour` is a proper 2‑colouring of `C`.  
`min(C)` is the smallest index vertex of `C`. The algorithm checks its colour.
If it is `0` we set `map0 = 1, map1 = 2`; otherwise `map0 = 2, map1 = 1`.  
Thus every vertex `x` receives `1` iff `colour[x] == colour[min(C)]`. ∎



##### Lemma 4  
The assignment produced by the algorithm satisfies all requirements.

**Proof.** By Lemma 3, within each component vertices of the same colour receive the
same Alpha value, vertices of opposite colour receive opposite values (`1` vs `2`).
Every edge connects vertices of opposite colour (property of BFS colouring), hence
their Alpha values differ and sum to `3`. All edges belong to some component, so
all requirements hold. ∎



##### Lemma 5  
Among all valid assignments, the algorithm’s assignment is lexicographically
minimum.

**Proof.** Process vertices in increasing order.
Let `i` be the first index where any valid assignment can differ from the algorithm’s
assignment.

*If `i` lies in a component already processed earlier*, its value is already fixed
identically by the algorithm and any other valid assignment must have the same
value (otherwise it would differ earlier). Contradiction, so this case cannot happen.

Thus `i` is the smallest index of its component `C`.  
The algorithm, by Lemma 3, gives Alpha = 1 to `i`. Any other valid assignment must
choose one of the two possible colour‑to‑value mappings for `C`. The only way to give
Alpha = 1 to `i` is to pick the same mapping as the algorithm; otherwise `i` would get
value `2` which is larger. Therefore any lexicographically smaller sequence does not
exist. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no feasible assignment exists;  
* otherwise `YES` and the lexicographically smallest feasible sequence of Alpha
  volumes.

**Proof.**  
*If the algorithm prints `NO`* – by Lemma 1 no assignment exists.  
*If a feasible assignment exists* – the graph is bipartite, so by Lemma 2 the
algorithm does not print `NO`. It finishes, and by Lemma 4 the produced sequence
satisfies all requirements. Lemma 5 shows it is the lexicographically smallest
among all such sequences. ∎

#### 5.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all vertices*: each vertex and edge is processed once → `O(n + m)` time.  
*Additional work* (finding minima, filling answer) is linear in component size,
overall `O(n)`.

Total  

* **Time** `O(n + m)` ≤ `4·10⁵` operations, well inside 1 s.  
* **Memory** `O(n + m)` for adjacency list, colour array, answer array
  (≈ 2 · 10⁵ · 8 bytes ≈ 1.6 MB).

#### 6.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 unvisited, 0/1 bipartite colour
    ans = [0] * (n + 1)

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # new component
        q = deque([start])
        colour[start] = 0
        comp = []
        while q:
            x = q.popleft()
            comp.append(x)
            cx = colour[x]
            for y in adj[x]:
                if colour[y] == -1:
                    colour[y] = cx ^ 1
                    q.append(y)
                elif colour[y] == cx:
                    sys.stdout.write("NO")
                    return
        # decide mapping
        min_v = min(comp)
        if colour[min_v] == 0:
            map0, map1 = 1, 2
        else:
            map0, map1 = 2, 1
        for v in comp:
            ans[v] = map0 if colour[v] == 0 else map1

    out = ["YES\n", " ".join(str(ans[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
