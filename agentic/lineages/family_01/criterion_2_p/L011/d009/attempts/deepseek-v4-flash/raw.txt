We can model each reactor as a binary variable:  
- 1 means Alpha volume = 1  
- 2 means Alpha volume = 2  

For a requirement between reactors u and v, the sum of Alpha volumes must be 3.  
That means if u is 1, v must be 2, and vice versa.  
So each edge forces the two endpoints to have opposite values.

This becomes a **bipartite graph coloring** problem.  
If the graph is not bipartite, it’s impossible → output `NO`.  
If it is bipartite, we can assign values, and to get the lexicographically smallest sequence, we try to assign 1 to as many early nodes as possible.

We can do this with BFS/DFS, assigning colors greedily:  
- For each unvisited node, try assigning it 1, then propagate constraints.  
- If conflict occurs, try assigning it 2 instead.  
- If both fail, output `NO`.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n  # 0 -> Alpha=1, 1 -> Alpha=2

def bfs(start):
    # try assigning start as 0
    q = deque([start])
    color[start] = 0
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        # try with 0
        old = color[:]
        if bfs(i):
            continue
        # revert and try with 1
        color[:] = old
        color[i] = 1
        q = deque([i])
        ok = True
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    ok = False
                    break
            if not ok:
                break
        if not ok:
            print("NO")
            sys.exit()

print("YES")
print(' '.join(str(c + 1) for c in color))
```
