We need to assign each unit a state of either 1 or 2 such that for every edge \((u,v)\), the value \(2^{s_u} + 2^{s_v} - 1\) is either 5 or 7, and the product over all edges equals \(5^m\).  

That means every edge must have thermal footprint exactly 5.  

Let’s check when \(2^{s_u} + 2^{s_v} - 1 = 5\):  
- If both are 1: \(2+2-1=3\) → not 5  
- If one is 1 and the other is 2: \(2+4-1=5\) → yes  
- If both are 2: \(4+4-1=7\) → not 5  

So every edge must connect one unit with state 1 and one with state 2.  
That means the graph must be bipartite, and the two parts correspond to states 1 and 2.  

We need the lexicographically smallest assignment.  
We can do BFS/DFS coloring, trying to assign state 1 to the smallest-index node first, and propagate. If a conflict occurs, it’s impossible.  

Here’s the implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

state = [-1] * n

for i in range(n):
    if state[i] == -1:
        state[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if state[v] == -1:
                    state[v] = 3 - state[u]
                    q.append(v)
                elif state[v] == state[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(state[i]) for i in range(n)))
```
