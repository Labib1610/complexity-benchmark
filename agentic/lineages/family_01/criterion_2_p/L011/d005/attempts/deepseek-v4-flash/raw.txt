We can model each projector as a node in a graph, and each threshold as an edge.  
The stability formula simplifies:  

For two projectors with cycles \( p_u, p_v \in \{1,2\} \):  
\[
6(p_u+p_v) - (p_u+p_v)^2
\]  
If both are 1: \(6(2) - 4 = 8\)  
If one is 1 and the other 2: \(6(3) - 9 = 9\)  
If both are 2: \(6(4) - 16 = 8\)  

So the sum over all edges must be \(9m\).  
That means every edge must have one projector with cycle 1 and the other with cycle 2.  
Thus the graph must be bipartite, and we need the lexicographically smallest bipartition labeling (1 or 2) with 1 preferred at the earliest index.

We can solve with BFS/DFS coloring, trying to assign 1 first when possible.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 0  # try 0 first (meaning cycle 1)
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                possible = False
                q.clear()
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    # color 0 -> cycle 1, color 1 -> cycle 2
    # But we need lexicographically smallest: try flipping components if it gives smaller sequence
    # We already started with 0 at first uncolored node, which is optimal for lexicographic order
    print("YES")
    print(' '.join(str(1 if c == 0 else 2) for c in color))
```
