 We need to assign each node a value of 1 or 2 such that for every edge (u, v), the number of distinct paths from (0,0) to (x_u, x_v) is exactly 3.  

The number of paths from (0,0) to (a,b) moving only right or up is given by the binomial coefficient C(a+b, a).  
We need C(x_u + x_v, x_u) = 3.  

The only way to get 3 is if the binomial coefficient is 3, which happens for (a,b) = (1,2) or (2,1).  
That means for each edge, the pair (x_u, x_v) must be (1,2) or (2,1).  

So the graph must be bipartite with the two parts being nodes with value 1 and nodes with value 2.  
If the graph is not bipartite, it's impossible.  

We also need the lexicographically smallest assignment.  
We can do BFS/DFS coloring, starting with node 1 as 1, and assign alternating values.  
If a conflict occurs, output NO.  

Here’s the implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    adj[u-1].append(v-1)
    adj[v-1].append(u-1)

color = [-1] * n
color[0] = 1
q = deque([0])
possible = True

while q and possible:
    u = q.popleft()
    for v in adj[u]:
        if color[v] == -1:
            color[v] = 3 - color[u]
            q.append(v)
        elif color[v] == color[u]:
            possible = False
            break

if not possible:
    print("NO")
else:
    # Check for disconnected components
    for i in range(n):
        if color[i] == -1:
            color[i] = 1
            q = deque([i])
            while q and possible:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = 3 - color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        possible = False
                        break
            if not possible:
                break

    if not possible:
        print("NO")
    else:
        print("YES")
        print(" ".join(str(color[i]) for i in range(n)))
```
