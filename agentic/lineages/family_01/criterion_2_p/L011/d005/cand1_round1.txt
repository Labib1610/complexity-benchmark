<METHOD_DESCRIPTION>
This method replaces the explicit binary domain and algebraic edge constraint with a continuous-time interaction function evaluated via a Laplace transform. The transform evaluates to a symmetric Diophantine equation ($p_u^4 + p_v^4 = 17$) whose only positive integer solutions are $(1, 2)$ and $(2, 1)$. This forces models to perform symbolic calculus and integer number theory just to uncover the underlying bipartite graph structure, preventing surface-level pattern matching to 2-coloring.
</METHOD_DESCRIPTION>

<STATEMENT>
# Harmonic Interference Resolution

Time limit: 1 s
Memory limit: 256 MB

A research facility operates a network of acoustic projectors. To maintain operational stability, every projector in the network must be assigned a positive integer pulse cycle $p$ (measured in microseconds).

The facility's layout contains multiple interference thresholds, each connecting a specific pair of projectors. A cycle assignment is only viable if it resolves the interference at every threshold. The interference generated by a threshold connecting projector $u$ and projector $v$ is calculated by defining the time-domain interaction function:

$f(t) = p_u^4 \cos(t) + p_v^4 \sin(t)$

where $p_u$ and $p_v$ are their assigned pulse cycles. The interference value is defined as the Laplace transform of this function evaluated at $s = 1$, denoted as $\mathcal{L}\{f(t)\}(1)$. 

For the assignment to be viable, this interference value must evaluate to exactly $8.5$ for every single threshold in the network.

Your objective is to determine if a viable cycle assignment exists for the entire network. When multiple viable assignments exist, the system enforces a deterministic selection. It compares the valid sequences of $n$ pulse cycles (ordered by projector index from 1 to $n$). The system selects the sequence that features the strictly smaller pulse cycle at the very first projector index where the sequences diverge.

## Input
The facility's power grid can support up to 200,000 acoustic projectors, and its monitoring system can track up to 200,000 interference thresholds.

The first line of the input provides two integers $n$ and $m$, representing the actual number of projectors and the actual number of thresholds. The number of projectors $n$ is at least 1, and the number of thresholds $m$ is at least 0. Neither will exceed their respective maximum system capacities of 200,000.

Each of the subsequent $m$ lines provides two integers $u$ and $v$, indicating that an interference threshold connects the projector indexed $u$ and the projector indexed $v$. Projector indices are valid integers between 1 and $n$, inclusive.

## Output
If it is impossible to find a viable cycle assignment, output `NO` on a single line.
If a viable assignment exists, output `YES` on the first line. On the second line, output $n$ space-separated integers representing the pulse cycle assigned to each projector from 1 to $n$. This sequence must be the one that satisfies the tie-breaking rule described above.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
To defeat models that immediately recognize the $\{1, 2\}$ domain and the $p_u \neq p_v$ local constraint, the explicit domain restriction was removed and replaced with a global positive integer constraint. The local edge constraint was replaced with a Laplace transform evaluation that mathematically simplifies to $0.5(p_u^4 + p_v^4) = 8.5$, or $p_u^4 + p_v^4 = 17$. The only positive integer solutions to this Diophantine equation are $(1, 2)$ and $(2, 1)$, which perfectly restores the $\{1, 2\}$ domain and the $p_u \neq p_v$ constraint. This forces models to perform symbolic integration and solve a non-linear integer equation before they can even discover that the problem is a bipartite graph coloring task.
</RATIONALE>
<PRESERVED_ANSWER>
The Diophantine equation $p_u^4 + p_v^4 = 17$ over positive integers has exactly the solutions $\{1, 2\}$ and $\{2, 1\}$, making the valid assignments and the lexicographical tie-breaking mathematically identical to the original seed.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
