<STATEMENT>
# Server Synchronization States

Time limit: 1 s   Memory limit: 256 MB

You are configuring a network of $n$ server nodes. Each node $i$ must be assigned a continuous signal function $S_i(t)$. 

There are exactly two valid signal functions available for assignment:
- Signal A: $S(t) = t - 1$
- Signal B: $S(t) = t - 2$

Let $x_i$ be the operational state of node $i$, defined as the root of its assigned signal (the value where $S_i(x_i) = 0$). Thus, $x_i$ is securely restricted to either 1 (if Signal A is assigned) or 2 (if Signal B is assigned).

The nodes are connected by a set of $m$ bidirectional sync channels. To prevent constructive interference during synchronization, every channel imposes a strict cross-correlation limit on its endpoints. Specifically, if a channel connects node $u$ and node $v$, their assigned signals must satisfy the following integral condition over the interval $[1, 2]$:

$$ \int_{1}^{2} S_u(t) S_v(t) \, dt \le 0 $$

Your task is to determine a valid signal assignment for all $n$ nodes. If there are multiple valid ways, you must output the assignment that produces the lexicographically smallest sequence of operational states $x_1, x_2, \dots, x_n$. If it is impossible to satisfy all channel requirements simultaneously, report that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$. The number of nodes $n$ satisfies $1 \le n \le 2\cdot 10^5$. The number of channels $m$ satisfies $0 \le m \le 2\cdot 10^5$.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u \le n$ and $1 \le v \le n$), indicating that a sync channel exists between node $u$ and node $v$.

## Output
If there is no valid signal assignment, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $x_1, x_2, \dots, x_n$, representing the lexicographically smallest valid sequence of operational states.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The previous attempt was rejected for replacing the pairwise edge constraint with a global/neighborhood sum. This version returns to a strict pairwise constraint evaluated per edge, entirely equivalent to the seed. However, to prevent models from immediately recognizing the 2-coloring structure, the mutual exclusion is enforced analytically: the integral of the product of identical signals over [1, 2] is strictly positive (1/3), while the integral of the product of differing signals is strictly negative (-1/6). Thus, the condition $\le 0$ mathematically requires adjacent nodes to have different signals.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $\int_1^2 S_u(t) S_v(t) dt \le 0$ is true if and only if $S_u \neq S_v$, which perfectly mirrors the original requirement that connected nodes must have different operational states; thus all valid assignments and the lexicographically smallest one remain identical.
</PRESERVED_ANSWER>

The underlying problem is still exactly 2-coloring (bipartiteness testing) on the given graph, which is solvable in $O(n+m)$ time using BFS/DFS.
