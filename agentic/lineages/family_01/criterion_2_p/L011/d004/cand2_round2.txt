# Server Synchronization States

Time limit: 1 s   Memory limit: 256 MB

You are configuring a network of $n$ server nodes. Each node $i$ must be assigned an operational state $x_i$, which must be a positive integer ($x_i \ge 1$).

The nodes are connected by a set of $m$ bidirectional sync channels. For any positive integer $x$, let $D(x)$ denote the set of its positive integer divisors. To prevent data corruption during synchronization, every channel imposes a strict requirement on its endpoints: if a channel connects node $u$ and node $v$, the union of their divisor sets, $D(x_u) \cup D(x_v)$, must contain exactly two distinct elements whose product is 2. Furthermore, the symmetric difference of these two sets, $D(x_u) \triangle D(x_v)$, must contain exactly one element.

Your task is to determine a valid state assignment for all $n$ nodes. If there are multiple valid ways to assign the states, you must output the assignment that is lexicographically smallest when written as the sequence $x_1, x_2, \dots, x_n$. If it is impossible to satisfy all channel requirements simultaneously, you must report that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a channel exists between node $u$ and node $v$.

## Output
If there is no valid state assignment, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $x_1, x_2, \dots, x_n$, representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

The seed's algebraic equation was replaced with a logically equivalent set-theoretic condition on the divisors of the states. To satisfy the condition, the union of the divisor sets must be exactly {1, 2}, which forces both states to be chosen from {1, 2}. This completely removes the algebraic signature that models were using to pattern-match the problem to 2-coloring, forcing them to perform multi-step deductive reasoning to discover the bipartite nature of the constraints.
