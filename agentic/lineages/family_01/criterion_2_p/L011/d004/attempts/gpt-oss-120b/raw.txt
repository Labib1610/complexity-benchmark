**Solution Explanation**

For every node we have to choose one of the two functions  

* `I` – identity, `I(1)=1 , I(2)=2`  
* `S` – swap,   `S(1)=2 , S(2)=1`

For an edge `{u,v}` the condition is  

```
f_u ( f_v (1) ) = 2
```

Checking the four possibilities

| f_u | f_v | f_u(f_v(1)) |
|-----|-----|------------|
| I   | I   | 1 |
| I   | S   | 2 |
| S   | I   | 2 |
| S   | S   | 1 |

The condition holds **iff the two functions are different**.  
Therefore the whole problem is exactly a *2‑colouring* (bipartite
checking) of the given undirected graph:

* colour `1`  → function `I` (operational state `x = 1`)
* colour `2`  → function `S` (operational state `x = 2`)

If the graph is not bipartite there is no assignment.

--------------------------------------------------------------------

#### Lexicographically smallest assignment  

Different connected components are independent – we may flip the two
colours inside any component.
The lexicographically smallest sequence `x1 … xn` is obtained by the
following rule:

*For each connected component, give colour `1` to the smallest‑indexed
node belonging to that component.*

Why?  
All nodes with index `< minComponent` are already fixed, therefore the
first still‑free position in the whole sequence is exactly this minimum
index. Making it `1` (the smallest possible value) is optimal, and it
does not influence any earlier position. Repeating the rule for every
component yields the global optimum.

--------------------------------------------------------------------

#### Algorithm
```
read n,m
build adjacency list
answer[1…n] = 0
visited[1…n] = false
for v = 1 … n
    if not visited[v]:
        # BFS of one component
        queue = [v]; visited[v]=true; colour[v]=0   # temporary 0/1
        component_nodes = [v]
        while queue not empty:
            u = pop queue
            for w in adj[u]:
                if not visited[w]:
                    visited[w]=true
                    colour[w]=1-colour[u]
                    queue.append(w)
                    component_nodes.append(w)
                else:
                    if colour[w]==colour[u]:   # not bipartite
                        print "NO" and exit
        # decide orientation
        min_node = min(component_nodes)
        if colour[min_node]==0:
            # 0 → 1, 1 → 2
            for x in component_nodes:
                answer[x] = 1 if colour[x]==0 else 2
        else:
            # flip
            for x in component_nodes:
                answer[x] = 2 if colour[x]==0 else 1
print "YES"
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` iff no assignment exists,
otherwise prints `YES` and the lexicographically smallest valid
sequence.

---

##### Lemma 1  
For any edge `{u,v}` the requirement `f_u(f_v(1)) = 2` holds
iff `f_u` and `f_v` are different functions.

*Proof.* Direct inspection of the four possibilities (table above). ∎



##### Lemma 2  
A function assignment satisfying all edges exists **iff** the graph is
bipartite.

*Proof.*  
*If* the graph is bipartite, colour the two parts with `I` and `S`. By
Lemma&nbsp;1 every edge connects different colours, therefore the
condition holds.

*Only if* an assignment exists, define a vertex colour as `0` for `I`,
`1` for `S`. By Lemma&nbsp;1 every edge connects vertices of different
colours, i.e. the graph is bipartite. ∎



##### Lemma 3  
During BFS the algorithm assigns temporary colours `0/1` that are a
proper 2‑colouring of the processed component.

*Proof.* BFS starts with colour `0`. Whenever an unvisited neighbour `w`
of a vertex `u` is discovered, it receives colour `1‑colour[u]`. Hence
every explored edge connects opposite temporary colours. If later an
already visited neighbour has the same colour, the algorithm detects a
conflict and aborts. Therefore, if the algorithm continues, the
temporary colours are a proper 2‑colouring. ∎



##### Lemma 4  
For a processed component the algorithm chooses the orientation that
gives the smallest possible value to the smallest index inside the
component.

*Proof.* Let `c` be that smallest index and let its temporary colour be
`t` (`0` or `1`).  
If we keep the mapping `0→1, 1→2`, then `x_c = 1` when `t=0` and `2`
when `t=1`.  
If we flip the mapping, the values are exchanged. The algorithm picks
the mapping that makes `x_c = 1`. No other mapping can give a smaller
value at position `c`. ∎



##### Lemma 5  
The sequence produced by the algorithm is lexicographically minimal
among all valid assignments.

*Proof.* Consider the components ordered by their minimal vertex
index. By Lemma&nbsp;4 the algorithm fixes the value at the first index
of the first component to `1`. Any valid assignment must assign either
`1` or `2` there; `1` is the smallest possible, so the algorithm is
optimal up to this position.  
Having fixed all vertices of the first component, the next free position
is the minimal index of the second component, and the same argument
applies. By induction the whole sequence is lexicographically minimal. ∎



##### Lemma 6  
If the algorithm prints `NO` then no valid assignment exists.

*Proof.* The algorithm prints `NO` only when it discovers an edge whose
endpoints already have the same temporary colour. By Lemma&nbsp;3 this
means the graph is not bipartite, and by Lemma&nbsp;2 no assignment can
satisfy all edges. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff the required assignment does not exist;  
* otherwise `YES` and the lexicographically smallest sequence
  `x1 … xn` that satisfies all edges.

*Proof.*  
If the algorithm prints `NO`, Lemma&nbsp;6 gives impossibility.  
If it finishes without conflict, Lemma&nbsp;3 gives a proper
2‑colouring, thus by Lemma&nbsp;2 a valid assignment exists.
The final conversion to `1/2` respects the orientation chosen per
component, therefore the produced sequence is valid.
By Lemma&nbsp;5 it is lexicographically minimal. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once,
`O(n + m)` time, `O(n)` extra memory for queues and colour arrays.  

Total: **Time `O(n + m)`**, **Memory `O(n + m)`**, well within limits.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    visited = [False] * (n + 1)
    temp_col = [0] * (n + 1)          # 0 / 1 temporary colours
    answer = [0] * (n + 1)

    for start in range(1, n + 1):
        if visited[start]:
            continue
        # BFS this component
        q = deque([start])
        visited[start] = True
        temp_col[start] = 0
        comp = [start]
        while q:
            u = q.popleft()
            cu = temp_col[u]
            for w in adj[u]:
                if not visited[w]:
                    visited[w] = True
                    temp_col[w] = 1 - cu
                    q.append(w)
                    comp.append(w)
                elif temp_col[w] == cu:
                    print("NO")
                    return
        # decide orientation
        min_node = min(comp)
        if temp_col[min_node] == 0:
            for v in comp:
                answer[v] = 1 if temp_col[v] == 0 else 2
        else:
            for v in comp:
                answer[v] = 2 if temp_col[v] == 0 else 1

    print("YES")
    print(' '.join(str(answer[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
