# Server Synchronization States

Time limit: 1 s   Memory limit: 256 MB

You are configuring a network of $n$ server nodes. Each node $i$ must be assigned an operational state $x_i$, which must be a positive integer ($x_i \ge 1$).

The nodes are connected by a set of $m$ bidirectional sync channels. To prevent data corruption during synchronization, every channel imposes a strict balance requirement on its endpoints. Specifically, if a channel connects node $u$ and node $v$, you must construct the channel's resonance matrix:
$$ \begin{pmatrix} 2x_u & 3 \\ 3 & x_v \end{pmatrix} $$
The strict balance requirement dictates that the determinant of this matrix must be exactly equal to $3(x_u + x_v) - 14$.

Your task is to determine a valid state assignment for all $n$ nodes. If there are multiple valid ways to assign the states, you must output the assignment that minimizes the structural cost, defined as $\sum_{i=1}^n x_i \cdot 3^{n-i}$. If it is impossible to satisfy all channel requirements simultaneously, you must report that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$. The number of nodes $n$ is at least 1 and bounded by a network maximum of $2\cdot 10^5$. The number of channels $m$ is at least 0 and at most $2\cdot 10^5$.
Each of the following $m$ lines contains two integers $u$ and $v$ (valid node IDs ranging from 1 to $n$), indicating that a channel exists between node $u$ and node $v$.

## Output
If there is no valid state assignment, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $x_1, x_2, \dots, x_n$, representing the valid assignment that minimizes the structural cost.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
