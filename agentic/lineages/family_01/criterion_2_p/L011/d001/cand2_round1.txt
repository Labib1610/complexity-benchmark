# Diagnostic Calibration

Time limit: 1 s   Memory limit: 256 MB

You are designing a power distribution network with $n$ nodes. Each node $i$ requires a voltage regulator. You have two models of regulators available: one with an internal resistance of 1 ohm, and another with an internal resistance of 2 ohms.

The network contains $m$ critical links. Each link pairs two nodes $u$ and $v$. During the calibration of any link, the regulators at $u$ and $v$ are temporarily connected in parallel. For the diagnostic system to calibrate correctly, the equivalent parallel resistance of this pair must be exactly $2/3$ ohms for every link. (Recall that the equivalent parallel resistance of two resistors $R_u$ and $R_v$ is $\frac{R_u R_v}{R_u + R_v}$).

Your objective is to assign a regulator (either 1 ohm or 2 ohms) to each of the $n$ nodes such that all $m$ links satisfy the calibration requirement. 

If multiple valid assignments exist, you must provide the lexicographically smallest sequence of resistance values. If no such assignment is possible, report that it is impossible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a critical link between node $u$ and node $v$.

## Output
If there is no valid assignment satisfying all links, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers (each either 1 or 2), representing the lexicographically smallest valid sequence of resistance values $R_1, R_2, \dots, R_n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was completely reframed from an abstract system of linear equations into a physical circuit diagnostic scenario. The direct linear constraint exactly summing to 3 was replaced with a parallel resistance requirement of 2/3 ohms. This forces the model to evaluate the physical formula over the domain {1, 2} to deduce that the two nodes must take opposite values, preventing surface-level pattern matching on standard graph coloring templates.
</RATIONALE>
<PRESERVED_ANSWER>
The domain of values remains exactly {1, 2}, and the parallel resistance of 2/3 ohms is only mathematically possible if one resistor is 1 ohm and the other is 2 ohms, strictly enforcing the exact same inequality constraint as the seed problem.
</PRESERVED_ANSWER>

The underlying problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in linear time using Breadth-First Search.
</PRESERVED_CLASS>
