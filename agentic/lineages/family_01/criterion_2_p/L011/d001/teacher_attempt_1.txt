# Frequency Allocation

Time limit: 1 s   Memory limit: 256 MB

You are configuring a communication network. The network consists of $n$ broadcast nodes. The hardware requires at least a single node to function, and its memory architecture allocates exactly 8 bytes per node from a dedicated pool of 1,600,000 bytes, establishing the maximum possible node count. 

Each node in the network must be assigned a frequency band, which is identified as either band 1 or band 2.

The system also records $m$ interference links. The number of links can be zero, and is capped at the same maximum limit as the nodes. Each link connects two specific nodes. To avoid signal cancellation, the two nodes connected by an interference link must together utilize the full spectrum of available bands (meaning both band 1 and band 2 must be present across the pair of nodes).

Your objective is to find a valid band assignment for all $n$ nodes that satisfies all $m$ interference links simultaneously. Because multiple valid assignments may exist, you must output the lexicographically smallest sequence of band assignments. If no such assignment is possible, you must report that it is impossible.

## Input
The first line contains two integers $n$ and $m$, representing the number of nodes and the number of interference links. The values of $n$ and $m$ conform to the architectural limits described above.
Each of the following $m$ lines contains two integers $u$ and $v$ representing an interference link between node $u$ and node $v$. These identifiers correspond to valid nodes, which are sequentially numbered starting from 1 up to $n$.

## Output
If there is no valid band assignment satisfying all links, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers (each either 1 or 2), representing the lexicographically smallest valid assignment of bands to nodes $1, 2, \dots, n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

The numerical bounds were restated as derived physical limits (e.g., 1,600,000 bytes total / 8 bytes per node). This forces the model to deduce the variable domains and recognize the constraint as equivalent to a bipartite 2-coloring requirement, rather than pattern-matching on the explicit sum-to-3 formulation.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that each linked pair uses both band 1 and band 2 is logically identical to the original constraint $x_u + x_v = 3$ for $x \in \{1, 2\}$, ensuring the set of valid assignments and the lexicographically smallest solution remain exactly unchanged.
</PRESERVED_ANSWER>

The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of a graph, which can be solved in linear time using Breadth-First Search (BFS), keeping it in P.
</PRESERVED_CLASS>
