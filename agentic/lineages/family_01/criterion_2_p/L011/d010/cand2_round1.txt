<STATEMENT>
# Power Grid Synchronization

Time limit: 1 s
Memory limit: 256 MB

You are deploying a cluster of $n$ processing units. Each unit $i$ must be configured with a power state $s_i$. Due to hardware constraints, the power state must be a positive integer strictly less than 3.

A cluster's scale is limited by its initialization protocol. Each processing unit requires exactly 5 microseconds to boot. The total boot time for all units in any valid cluster must be strictly greater than 0 and cannot exceed 1,000,000 microseconds (1 second). This imposes a natural limit on the number of units $n$. Similarly, each data link draws a calibration current for exactly 5 microseconds. The total calibration time across all links can be zero but will never exceed 1,000,000 microseconds, bounding the number of links $m$.

The cluster contains $m$ bidirectional data links between units. For each data link connecting unit $u$ and unit $v$, the link's impedance ratio is calculated as $\frac{s_u}{s_v} + \frac{s_v}{s_u}$. 

The total impedance ratio of the cluster is the sum of the impedance ratios of all $m$ links. (If the cluster has no links, the total impedance ratio is considered to be 0). To prevent overheating while maintaining performance, the cluster achieves optimal equilibrium if and only if its total impedance ratio is exactly $2.5 \times m$.

Your task is to determine a valid power state configuration for all $n$ units such that the cluster reaches optimal equilibrium. If there are multiple valid configurations, you must output the one that produces the lexicographically smallest sequence of power states $s_1, s_2, \dots, s_n$. If it is impossible to satisfy the requirement, report that no such configuration exists.

## Input
The first line contains two integers $n$ and $m$, representing the number of processing units and the number of data links, respectively. The bounds on $n$ and $m$ are guaranteed to respect the initialization limits described above.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a data link exists between unit $u$ and unit $v$.

## Output
If there is no valid configuration, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $s_1, s_2, \dots, s_n$, representing the lexicographically smallest valid sequence of power states.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Replaced the integer arithmetic product condition with a rational function extremum condition ($x/y + y/x$). Removed explicit numeric bounds via S07, replacing them with physical initialization time limits that require the model to independently deduce the limits for $n$, $m$, and $s_i$. This forces the model to mathematically prove that the maximum of the rational function implies inequality between endpoints, blocking simple pattern matching on the arithmetic.
</RATIONALE>
<PRESERVED_ANSWER>
Since state values are restricted to $\{1, 2\}$, the expression $\frac{s_u}{s_v} + \frac{s_v}{s_u}$ evaluates to $2$ if $s_u = s_v$ and $2.5$ if $s_u \neq s_v$; because the maximum value is $2.5$, a sum of $m$ edges exactly equaling $2.5m$ is only possible if every edge connects differing states, perfectly preserving the original solution space.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains identical: finding the lexicographically smallest 2-coloring of a graph, which is solvable in linear time using a standard breadth-first search.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the physical time limits as part of the simulation to be coded rather than simple derived bounds on $n$ and $m$, though the text explicitly states "bounding the number of links".
</RISK>

<METHOD_DESCRIPTION>Replaces the direct edge-validity arithmetic with a rational function $f(x,y) = x/y + y/x$. Over the domain $\{1, 2\}$, this function has a strict maximum of 2.5 when $x \neq y$. By requiring the sum over $m$ edges to be exactly $2.5m$, it forces every edge to evaluate to 2.5, which rigorously requires $s_u \neq s_v$.
