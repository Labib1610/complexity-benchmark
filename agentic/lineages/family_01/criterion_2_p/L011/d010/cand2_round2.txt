<METHOD_NAME>Bitwise Orthogonality Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the arithmetic product condition with a bitwise operation condition: `(u | v) * (u & v) == 0`. Since the allowed states are 1 (binary 01) and 2 (binary 10), their bitwise AND is 0 if and only if they are different. Because the footprint is strictly non-negative, a sum of 0 forces every edge to have different states. This completely masks the bipartite/2-coloring requirement behind bitwise logic, defeating models that rely on algebraic or parity-based clues.</METHOD_DESCRIPTION>

<STATEMENT>
# Power Grid Synchronization

Time limit: 1 s
Memory limit: 256 MB

You are deploying a cluster of $n$ processing units. Each unit $i$ must be configured with a power state $s_i \in \{1, 2\}$.

The cluster contains $m$ bidirectional data links between units. When a link connects unit $u$ and unit $v$, the link's thermal footprint is calculated as the product of the bitwise OR and the bitwise AND of their power states:
$(s_u \mid s_v) \times (s_u \mathbin{\&} s_v)$
where $|$ denotes the bitwise OR operator and $\&$ denotes the bitwise AND operator.

The total thermal footprint of the cluster is the sum of the thermal footprints of all $m$ links. (If the cluster has no links, the total thermal footprint is considered to be 0). To prevent overheating while maintaining performance, the cluster achieves optimal equilibrium if and only if its total thermal footprint is exactly 0.

Your task is to determine a valid power state configuration for all $n$ units such that the cluster reaches optimal equilibrium. If there are multiple valid configurations, you must output the one that produces the lexicographically smallest sequence of power states $s_1, s_2, \dots, s_n$. If it is impossible to satisfy the requirement, report that no such configuration exists.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a data link exists between unit $u$ and unit $v$.

## Output
If there is no valid configuration, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $s_1, s_2, \dots, s_n$, representing the lexicographically smallest valid sequence of power states.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was completely stripped of its arithmetic product affordance and replaced with a bitwise operation sum. Because `(1 & 2) == 0` and `(x | y) >= 1`, the sum can only be 0 if every connected pair of units has different states. This forces models to logically deduce the 2-coloring requirement from the bitwise truth table rather than recognizing the arithmetic pattern.
</RATIONALE>
<PRESERVED_ANSWER>
The condition `(s_u | s_v) * (s_u & s_v) == 0` for `s_i \in {1, 2}` is mathematically identical to requiring `s_u != s_v` for every edge, which is exactly the same 2-coloring constraint as the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring (bipartite coloring) of a graph, which is solvable in linear time O(n+m) using BFS/DFS.
</PRESERVED_CLASS>
