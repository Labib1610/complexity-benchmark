<STATEMENT>
# Ledger Reconciliation

Time limit: 1 s   Memory limit: 256 MB

You are auditing a financial network consisting of $n$ corporate accounts.
Each account $i$ must be assigned an audit category $x_i$. The regulatory framework only permits category 1 or category 2.

The network contains $m$ bilateral transaction records. Each record ties together exactly two accounts.
To comply with cross-verification rules, every transaction record imposes a strict constraint on its two accounts: if a record ties account $u$ and account $v$, the arithmetic mean of their audit categories must evaluate to exactly 1.5.

Your task is to determine a valid category assignment for all $n$ accounts.
If there are multiple valid assignments, you must output the assignment that is lexicographically smallest when written as the sequence $x_1, x_2, \dots, x_n$. If it is impossible to satisfy all cross-verification rules simultaneously, you must report that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$. The number of accounts $n$ is at least 1 and at most $2\cdot 10^5$. The number of transaction records $m$ is at least 0 and at most $2\cdot 10^5$.
Each of the following $m$ lines contains two integers $u$ and $v$ (valid account IDs ranging from 1 to $n$), indicating that a transaction record ties account $u$ and account $v$.

## Output
If there is no valid assignment, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $x_1, x_2, \dots, x_n$ (each being 1 or 2), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the domain from facility staffing and communication links to financial auditing and transaction records. Replaced the explicit sum constraint ($x_u + x_v = 3$) with an equivalent arithmetic mean constraint (mean is exactly 1.5) to force the model to independently deduce the underlying inequality ($x_u \neq x_v$) rather than pattern-matching the sum equation to a known 2-coloring template.
</RATIONALE>
<PRESERVED_ANSWER>
The allowed values are strictly 1 and 2, and the mean of two such values is 1.5 if and only if their sum is 3, preserving all valid assignments and the lexicographical tie-breaker exactly as in the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of an undirected graph, which is solvable in linear time using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "arithmetic mean" as implying continuous values, but the text explicitly restricts $x_i$ to "category 1 or category 2", negating this risk.
</RISK>
