# Microservice Execution Rings

Time limit: 1 s
Memory limit: 256 MB

You are migrating a backend system to a microservice architecture. The service registry allocates sequentially assigned integer IDs starting at 1. The registry's memory is capped, allowing a maximum of $200,000$ microservices to be registered.

To ensure high availability, each microservice must be assigned to one of two isolated execution rings, identified as Ring 1 and Ring 2. 

The policy database contains a list of interference constraints. The database might be empty, or it could contain up to a maximum limit of $200,000$ constraints. Each constraint specifies two microservice IDs that share a non-thread-safe dependency. Consequently, the microservices specified in a constraint will fail if they are assigned to the identical execution ring.

Your task is to assign every microservice to an execution ring such that no interference constraints are violated. If there are multiple valid ways to assign the rings, you must choose the one that is lexicographically first. Specifically, when comparing two different valid assignments by reading the ring IDs in order of the microservice IDs, the preferred assignment will place a microservice in Ring 1 at the earliest ID where the two assignments differ.

## Input
The first line contains two integers representing the total count of microservices and the total count of interference constraints, respectively. (These counts respect the registry and database capacities described above).
Each of the subsequent lines describes a single interference constraint by listing the two integer IDs of the conflicting microservices.

## Output
If no valid ring assignment exists for the given constraints, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print a space-separated sequence of integers (each either 1 or 2) representing the optimal ring assignment for each microservice, in increasing order of their IDs.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
