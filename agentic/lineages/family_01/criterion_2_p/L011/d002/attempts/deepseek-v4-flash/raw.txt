We can model this as a graph coloring problem:  
Each node must be 1 or 2, and for an edge `(u, v)`, we need `x_u^2 + x_v^2 = 5`.  
Since `1^2 + 2^2 = 5` and `2^2 + 1^2 = 5`, the only valid assignment is that connected nodes must have different values (one is 1, the other is 2).  

So the problem reduces to checking if the graph is bipartite, and if so, output the lexicographically smallest coloring (with 1 preferred over 2).  

We can do a BFS/DFS, assigning 1 to the first node, then alternating.  
To get lexicographically smallest, we process nodes in order and assign the smallest possible value that keeps consistency.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 1
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 3 - color[u]  # 1 -> 2, 2 -> 1
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
