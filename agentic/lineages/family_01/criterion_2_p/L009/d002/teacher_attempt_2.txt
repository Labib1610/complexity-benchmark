# Problem B — Flux Channels

Time limit: 1 s   Memory limit: 256 MB

An experimental fusion reactor contains $n$ magnetic coils. Each coil must be calibrated to exactly one of two polarity states: state 1 or state 2.

The reactor's design includes $m$ delicate flux channels, each connecting a specific pair of coils. To maintain a stable magnetic field and prevent the channel from saturating, the two coils connected by any flux channel must be calibrated to different polarity states. Exactly one coil in the pair must be in state 1, and the other must be in state 2.

You need to determine if there is a valid calibration for all $n$ coils that keeps every flux channel stable, or report that no such configuration is possible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a pair of coils connected by a flux channel.

## Output
If no valid calibration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $c_1, \dots, c_n$ (each $c_i \in \{1, 2\}$), where $c_i$ is the polarity state assigned to coil $i$. If there are multiple valid calibrations, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
