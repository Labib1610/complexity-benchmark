# Problem B — Factory Tuning

Time limit: 1 s   Memory limit: 256 MB

The factory requires each of its $n$ machines to be set to a power mode of either 1 or 2. There are $m$ interference links between specific pairs of machines. A legacy controller accepts a link only when the modes $x$ and $y$ of the two connected machines satisfy the equation $3xy = 2(x + y)$. You must assign a power mode to every machine such that all $m$ links are accepted by the controller.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a linked pair of machines.

## Output
If no valid assignment of modes exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit condition that $x \oplus y = 3$ over $\{1,2\}$ immediately triggers models to recognize bipartite graph coloring because it explicitly forces $x \neq y$. I replaced this with the algebraic constraint $3xy = 2(x+y)$, which evaluates to true strictly for $(1,2)$ and $(2,1)$ but requires algebraic reasoning to deduce the $x \neq y$ requirement, forcing the model to analyze the constraint rather than matching a known pattern. The artificial search space framing was removed to make it read naturally.
</RATIONALE>
<PRESERVED_ANSWER>
For $x, y \in \{1, 2\}$, the equation $3xy = 2(x+y)$ holds if and only if $x \neq y$ (since $3(2)=6$ and $2(1+2)=6$, while $3(1)\neq 2(2)$ and $3(4)\neq 2(4)$), making it identical to the original XOR constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartite testing) on a graph, which is solvable in $O(n+m)$ time using BFS/DFS.
</PRESERVED_CLASS>
