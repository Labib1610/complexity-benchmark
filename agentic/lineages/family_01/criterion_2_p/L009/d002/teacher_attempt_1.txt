# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

A manufacturing plant operates two daily schedules: schedule 1 and schedule 2. The factory employs $n$ workers, numbered 1 through $n$. To ensure operations run smoothly, management needs to place every worker into exactly one of these schedules. The factory employs at least one worker, but due to safety regulations, the total workforce never exceeds two hundred thousand.

There are $m$ specialized tools in the plant. The number of tools can be zero, up to a maximum of two hundred thousand. Each tool is shared by exactly two specific workers. To prevent delays, two workers sharing a tool are forbidden from working the same schedule. 

You must determine a valid schedule assignment for all workers that satisfies all tool sharing constraints, or report that no such schedule is possible.

## Input
The first line contains two integers $n$ and $m$, representing the number of workers and the number of specialized tools, respectively. The valid ranges for these quantities are defined by the factory's safety regulations and tool capacity described above.
Each of the next $m$ lines contains two integers $u$ and $v$, representing a pair of workers who share a tool.

## Output
If no valid schedule assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $s_1, \dots, s_n$ (each $s_i \in \{1, 2\}$), where $s_i$ is the schedule assigned to worker $i$. If there are multiple valid assignments, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
