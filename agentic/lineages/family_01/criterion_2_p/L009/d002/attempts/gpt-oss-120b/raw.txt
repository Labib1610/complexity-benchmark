**Solution Explanation**

For every machine we are given the two staff members that are responsible for it.
During routine 1 at least one of them must work, during routine 2 at least one of
them must work.
Because a machine has only two responsible persons, the only way to satisfy
both requirements is

* one of the two persons works in routine 1,
* the other works in routine 2.

Hence every machine (edge) must connect two staff members that are assigned to
different routines.  
The whole problem is therefore exactly the problem of **2‑colouring a graph**
(bipartite checking).  
If the graph is not bipartite the answer is `NO`.  
If it is bipartite we have to output the lexicographically smallest
colouring (1 < 2).

--------------------------------------------------------------------

#### 1.   Graph model
* vertices – staff members `1 … n`
* undirected edges – machines `(u , v)`

--------------------------------------------------------------------

#### 2.   Bipartite check & component handling
We run a BFS/DFS over every not yet visited vertex.

During the search we store for each vertex a temporary colour `par`
(`0` or `1`) – the parity inside the current component.

If we ever meet an already coloured neighbour with the same parity,
the component is **not bipartite** → answer `NO`.

While traversing a component we also collect all its vertices in a list
`comp`.  
After the BFS finishes we know the two sides of the component:
`par = 0` and `par = 1`.

--------------------------------------------------------------------

#### 3.   Lexicographically smallest global colouring
Components are independent, we may flip the whole component
(`0 → 1 , 1 → 2` or the opposite) without breaking any edge condition.

To obtain the smallest possible whole array we act greedily:

* let `vmin` be the smallest vertex index inside the component.
* if `par[vmin] == 0` we keep the current orientation  
  (`par = 0` → routine 1, `par = 1` → routine 2);
* otherwise we flip the orientation.

Why is this optimal?
The first position where the final answer can differ from any other feasible
answer is exactly the smallest index of the first component that is not yet
fixed. By forcing that vertex to be `1` we minimise the answer at the earliest
possible place, and later components cannot affect earlier positions.
Thus the greedy rule yields the lexicographically smallest overall assignment.

--------------------------------------------------------------------

#### 4.   Algorithm
```
read n, m
build adjacency list
colour = [ -1 ] * (n+1)          # -1 = unvisited, else 0/1 inside its component
answer = [ 0 ] * (n+1)           # final routine numbers 1/2

for v = 1 … n:
    if colour[v] == -1:
        BFS starting from v
        store visited vertices of this component in list comp
        during BFS detect non‑bipartite → print NO and exit
        vmin = min(comp)
        if colour[vmin] == 0:   # keep orientation
            for x in comp:
                answer[x] = 1 if colour[x] == 0 else 2
        else:                    # flip orientation
            for x in comp:
                answer[x] = 1 if colour[x] == 1 else 2

print YES
print answer[1] … answer[n] separated by spaces
```

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints `NO` iff no feasible assignment exists,
otherwise prints `YES` and the lexicographically smallest feasible assignment.

---

##### Lemma 1  
If the algorithm prints `NO`, the input graph is not bipartite.

**Proof.** `NO` is printed only when during BFS an edge `(u,v)` with
`colour[u] == colour[v]` is found. This is exactly the definition of a
non‑bipartite graph. ∎



##### Lemma 2  
If the input graph is not bipartite, the algorithm prints `NO`.

**Proof.** In a non‑bipartite graph every 2‑colouring attempt fails on at least
one edge. Our BFS assigns colours arbitrarily (0/1) and explores the whole
connected component. The first edge that violates bipartiteness will be
encountered, triggering the `NO` output. ∎



##### Lemma 3  
Assume the graph is bipartite. For each connected component the algorithm
outputs a colouring that satisfies all its edges.

**Proof.** Inside a component BFS guarantees that every edge connects vertices
with opposite temporary colours (`0` vs `1`). Afterwards we possibly flip the
mapping `0→1,1→2` or `0→2,1→1`. In both cases the two endpoints receive different
routines, therefore every edge has one endpoint in routine 1 and the other in
routine 2, satisfying the requirement. ∎



##### Lemma 4  
For a bipartite graph the algorithm’s final array `answer` is lexicographically
minimum among all feasible assignments.

**Proof.** Consider the components ordered by the smallest vertex they contain:
`C1, C2, …`.  
The algorithm decides the orientation of `Ci` solely based on its smallest
vertex `vi = min(Ci)`, forcing `answer[vi] = 1`.  

Take any other feasible assignment `B`.  
If for the first component where `B` differs from our assignment we have
`B[vi] = 2`, then `answer` is lexicographically smaller because at the earliest
different position it has `1 < 2`.  
If `B[vi] = 1`, then the orientation of `Ci` in `B` must be the same as ours,
otherwise `vi` would receive `2`. Hence `B` coincides with our assignment on
`Ci`. By induction over components the whole array of `answer` is not larger
than any feasible `B`. ∎



##### Lemma 5  
If the graph is bipartite, the algorithm outputs a feasible assignment.

**Proof.** By Lemma&nbsp;3 each component is coloured correctly, therefore all
edges of the whole graph satisfy the condition. ∎



##### Theorem  
The algorithm prints `NO` iff no feasible routine assignment exists;
otherwise it prints `YES` followed by the lexicographically smallest feasible
assignment.

**Proof.**  
*If* the algorithm prints `NO`, by Lemma&nbsp;1 the graph is not bipartite,
hence no feasible assignment exists (edges would need different colours).  

*If* a feasible assignment exists, the graph must be bipartite, otherwise
Lemma&nbsp;2 would have caused `NO`. The algorithm therefore proceeds to the
colouring phase, and by Lemma&nbsp;5 produces a feasible assignment.
Lemma&nbsp;4 shows this assignment is lexicographically minimal. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis
*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all vertices*: each vertex and edge is processed once → `O(n + m)`  
*Overall*: `O(n + m)` time, `O(n + m)` memory, well within limits (`n,m ≤ 2·10⁵`).

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    parity = [-1] * (n + 1)          # temporary 0/1 inside component
    answer = [0] * (n + 1)           # final 1/2

    for start in range(1, n + 1):
        if parity[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        parity[start] = 0
        comp = [start]
        ok = True
        while q:
            u = q.popleft()
            pu = parity[u]
            for v in adj[u]:
                if parity[v] == -1:
                    parity[v] = pu ^ 1
                    q.append(v)
                    comp.append(v)
                elif parity[v] == pu:
                    # not bipartite
                    print("NO")
                    return
        # decide orientation for lexicographically smallest result
        vmin = min(comp)
        if parity[vmin] == 0:
            for x in comp:
                answer[x] = 1 if parity[x] == 0 else 2
        else:
            for x in comp:
                answer[x] = 1 if parity[x] == 1 else 2

    # all components processed successfully
    out = ["YES", " ".join(str(answer[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
