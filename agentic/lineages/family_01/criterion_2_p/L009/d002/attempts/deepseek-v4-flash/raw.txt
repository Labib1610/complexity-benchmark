 We can model this as a graph problem.  
Each staff member is a node, and each machine is an edge between two staff members.  
The condition says: for every edge (u, v), one of them must be in routine 1 and the other in routine 2.  
That means the graph must be bipartite.  

We can solve it with BFS/DFS coloring.  
If the graph is not bipartite, output `NO`.  
Otherwise, output the coloring with `1` and `2`, choosing the lexicographically smallest assignment (which means we start coloring node 1 with `1`).

Here’s the implementation:

```python
from collections import deque

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
