We can treat each machine as a node in a graph, and each link as an edge.  
The condition:

\[
3xy = 2(x + y)
\]

with \(x, y \in \{1, 2\}\):

- If \(x = 1, y = 1\): \(3 = 4\) → false  
- If \(x = 1, y = 2\): \(6 = 6\) → true  
- If \(x = 2, y = 1\): \(6 = 6\) → true  
- If \(x = 2, y = 2\): \(12 = 8\) → false  

So the only valid pairs are (1,2) and (2,1).  
That means the graph must be bipartite, with the two parts being mode 1 and mode 2.

We need the lexicographically smallest assignment, so we try to assign mode 1 as early as possible, using BFS/DFS with coloring.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n  # -1 uncolored, 0 = mode 1, 1 = mode 2

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 0
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
print(' '.join(str(c + 1) for c in color))
```
