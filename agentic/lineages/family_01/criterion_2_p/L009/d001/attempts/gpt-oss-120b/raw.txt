**Solution Explanation**

For every tool we are given the two staff members that can operate it.
During a shift the tool works if at least one of its two members works in
that shift.
The tool has to work in **both** shifts, therefore for every edge  
`(u , v)` we need

* at least one endpoint in shift 1
* at least one endpoint in shift 2

Both conditions are satisfied **iff** the two endpoints belong to different
shifts.  
Consequently we have to colour the vertices of the given graph with two
colours `1` and `2` such that adjacent vertices have different colours.
That is exactly the definition of a *bipartite* graph.

So the problem is

* check whether the graph is bipartite,
* output a 2‑colouring,
* among all possible colourings output the lexicographically smallest one.

--------------------------------------------------------------------

#### 1.   Bipartite test and component collection  

We run a BFS/DFS over every not yet visited vertex.

During the search we store  

* `col[v] ∈ {0,1}` – temporary colour,
* the list `comp` of vertices of the current connected component,
* the smallest vertex index `mn` inside this component.

If we ever meet an edge `(v,w)` with `col[v] == col[w]` the graph is not
bipartite → answer `NO`.

The total work is `O(n+m)`.

--------------------------------------------------------------------

#### 2.   Lexicographically smallest colouring  

Inside one connected component the two possible colourings are

```
colour 0 → shift 1 , colour 1 → shift 2
or
colour 0 → shift 2 , colour 1 → shift 1   (swap)
```

All vertices of the component share the same orientation.
The first position where the whole answer can differ between the two
orientations is the **smallest index vertex of this component** (`mn`).
To obtain the smallest possible whole sequence we simply force this vertex
to obtain shift 1.

*If `col[mn] == 0`* we keep the orientation as is.  
*If `col[mn] == 1`* we flip the orientation (swap the two shifts).

The flip can be expressed by `final_shift[v] = (col[v] xor flip) + 1`,
where `flip` is `0` or `1` for the component.

Processing components independently in any order works, because the
decision for a component never influences any vertex with a smaller index
(the smallest index of the component is already fixed to `1`).

--------------------------------------------------------------------

#### 3.   Algorithm
```
read n, m
build adjacency list
col = [-1] * (n+1)          # -1 = unvisited, else 0/1
answer = [0] * (n+1)

for v = 1 .. n:
    if col[v] == -1:
        BFS starting from v, set col[v]=0
        collect vertices of this component in list comp
        remember mn = minimal vertex in comp
        if a conflict is found -> print "NO" and exit

        # decide orientation
        flip = 1 if col[mn] == 1 else 0
        for u in comp:
            answer[u] = (col[u] ^ flip) + 1

print "YES"
print answer[1] … answer[n] separated by spaces
```

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `NO` iff no feasible assignment exists,
otherwise prints the lexicographically smallest feasible assignment.

---

##### Lemma 1  
If the algorithm prints `NO` then the input graph is not bipartite.

**Proof.** `NO` is printed only when during BFS an edge `(x,y)` with
`col[x] == col[y]` is discovered. All previously visited vertices keep the
colour assigned at the moment they were first reached, therefore the
partial colouring is proper on all examined edges.
The discovered edge violates the bipartite condition, hence the whole
graph cannot be bipartite. ∎



##### Lemma 2  
If the input graph is not bipartite the algorithm prints `NO`.

**Proof.** A non‑bipartite graph contains an odd cycle.
During the BFS of the component containing that cycle, vertices are coloured
alternately along the walk. Because the cycle length is odd, the first
vertex of the cycle receives the same colour as the last one, i.e. an edge
of the cycle is examined with equal colours and the algorithm prints `NO`. ∎



##### Lemma 3  
Assume the graph is bipartite. For every connected component the algorithm
outputs a shift assignment that satisfies all edges of the component.

**Proof.** Inside a component the BFS produces a proper 2‑colouring
`col`. For any edge `(u,v)` we have `col[u] != col[v]`.  
If `flip = 0` the final shift is `col+1`; the two endpoints receive different
shifts `1` and `2`.  
If `flip = 1` the final shift is `(col xor 1)+1`, i.e. the colours are swapped,
still different. Hence every edge has one endpoint in each shift. ∎



##### Lemma 4  
For a bipartite graph the assignment produced by the algorithm is
lexicographically minimal among all feasible assignments.

**Proof.** Consider one component `C` and let `mn` be its smallest vertex.
The two feasible assignments for `C` differ exactly by swapping the two
shifts, therefore `mn` receives either shift 1 or shift 2.
All vertices with index `< mn` belong to other components and are already
fixed (by the algorithm) to the smallest possible values (induction on the
order of increasing indices).

The algorithm chooses the orientation that gives `mn` shift 1.
Any other feasible global assignment must give `mn` either shift 1 (same as
algorithm) or shift 2 (larger).  
If it gives shift 2, the whole sequence is lexicographically larger at
position `mn`.  
If it gives shift 1, the orientation of `C` coincides with the algorithm’s
choice, thus the values on all vertices of `C` are identical.
Proceeding to the next component repeats the argument.
Consequently no feasible assignment is lexicographically smaller. ∎



##### Lemma 5  
If the graph is bipartite the algorithm outputs a feasible assignment.

**Proof.** By Lemma&nbsp;3 each component is coloured correctly, therefore
every edge of the whole graph has its endpoints in different shifts.
Thus all tools are active in both shifts. ∎



##### Theorem  
The algorithm prints `NO` iff no valid shift arrangement exists;
otherwise it prints `YES` followed by the lexicographically smallest
valid arrangement.

**Proof.**  
*If* the algorithm prints `NO`, by Lemma&nbsp;1 the graph is not bipartite,
hence no valid arrangement exists (a valid arrangement would be a proper
2‑colouring).  

*If* a valid arrangement exists, the graph is bipartite.
The algorithm will not encounter a conflict, therefore it reaches the
output phase. By Lemma&nbsp;5 the produced assignment is feasible, and by
Lemma&nbsp;4 it is the lexicographically smallest one. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all vertices*: each vertex and edge is processed once → `O(n+m)`  
*Additional work* (building answer) is linear in the size of components,
still `O(n+m)`.

Total time `O(n + m)` ≤ `4·10⁵`, well inside the 1 s limit.  
Memory consumption: adjacency list (`2m` integers) + a few arrays of size
`n` → `O(n + m)` ≤ about 3 MB.

#### 6.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    col = [-1] * (n + 1)          # 0 / 1 temporary colours
    ans = [0] * (n + 1)

    for start in range(1, n + 1):
        if col[start] != -1:
            continue
        # BFS for this component
        q = deque([start])
        col[start] = 0
        comp = [start]
        mn = start
        while q:
            v = q.popleft()
            if v < mn:
                mn = v
            for to in adj[v]:
                if col[to] == -1:
                    col[to] = col[v] ^ 1
                    q.append(to)
                    comp.append(to)
                elif col[to] == col[v]:
                    sys.stdout.write("NO")
                    return
        # decide orientation: make vertex mn have shift 1
        flip = 1 if col[mn] == 1 else 0
        for v in comp:
            ans[v] = (col[v] ^ flip) + 1

    out = ["YES", " ".join(str(ans[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
