We can model this as a bipartite graph problem: each staff member is a node, and each equipment pair is an edge. We need to 2-color the graph such that adjacent nodes have different colors (shifts 1 and 2). If the graph is not bipartite, output `NO`.  

To get the lexicographically smallest assignment, we should try to assign shift `1` to as many early-indexed nodes as possible. This can be done by running BFS/DFS and, when we start a new component, always start with color `1` for the smallest-index node in that component.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
