To solve this problem, we need to assign each staff member to one of two shifts such that every tool (edge) has at least one staff member in each shift. This means for every edge (u, v), u and v cannot both be in the same shift. Thus, the problem reduces to checking if the graph is bipartite. If it is, we can output the lexicographically smallest bipartition; otherwise, output "NO".

### Approach
1. **Bipartite Check**: The graph must be bipartite. If it's not, output "NO".
2. **Lexicographically Smallest Bipartition**: To get the lexicographically smallest assignment, we should assign shift 1 to as many early nodes as possible. This can be achieved by performing a BFS or DFS, starting from the smallest unvisited node each time, and assigning it shift 1, then its neighbors shift 2, and so on. This ensures that the first occurrence of each node in the BFS/DFS order gets the smallest possible shift.

### Solution Code
```python
import sys
from collections import deque

def solve():
    n, m = map(int, sys.stdin.readline().split())
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v = map(int, sys.stdin.readline().split())
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * (n + 1)
    possible = True
    
    for i in range(1, n+1):
        if color[i] == 0:
            q = deque()
            q.append(i)
            color[i] = 1
            while q and possible:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == 0:
                        color[v] = 3 - color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        possible = False
                        break
                if not possible:
                    break
        if not possible:
            break
    
    if not possible:
        print("NO")
    else:
        print("YES")
        print(' '.join(map(str, color[1:])))

solve()
```

### Explanation
1. **Reading Input**: The input is read from standard input, where the first line contains the number of staff members (n) and tools (m). The subsequent m lines describe the edges between staff members.
2. **Graph Construction**: An adjacency list is constructed to represent the graph.
3. **Bipartite Check**: Using BFS, we check if the graph is bipartite. Each node is assigned a color (1 or 2) such that adjacent nodes have different colors. If at any point adjacent nodes have the same color, the graph is not bipartite, and we print "NO".
4. **Lexicographically Smallest Assignment**: The BFS starts from the smallest unvisited node each time, assigning it color 1. This ensures that the first occurrence of each node in the BFS order gets the smallest possible color, leading to the lexicographically smallest solution.
5. **Output**: If the graph is bipartite, the solution is printed as "YES" followed by the color assignments for each staff member. If not, "NO" is printed.

This approach efficiently checks for bipartiteness and ensures the solution is lexicographically smallest by leveraging BFS starting from the smallest nodes first.
