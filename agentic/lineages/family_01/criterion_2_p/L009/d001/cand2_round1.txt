# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

The same factory now runs only two shifts, requiring each of the $n$ workers to be assigned a shift parameter $s_i \in \{1, 2\}$. There are $2^n$ possible shift configurations to consider. 

You are given $m$ operational constraints. Each constraint is defined by a pair of workers $(u, v)$, and requires that their assigned shift parameters satisfy the equation:
$$s_u^2 + s_v^2 = 5$$

Search the configuration space to determine if there exists a valid assignment of shift parameters for all $n$ workers. If multiple valid assignments exist, you must find the one that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of workers that share an operational constraint.

## Output
If no valid assignment exists in the configuration space, print a single line NO.
Otherwise print YES, followed by a second line with $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The suggested strategy of adding a global condition would change the correct output for edgeless graphs, violating the hard constraint to preserve identical answers. Instead, the affordance of "pairwise inequality constraints" was removed by replacing the concept of "conflicts" and "sharing a shift" with a non-linear algebraic equation ($s_u^2 + s_v^2 = 5$) over the domain $\{1, 2\}$. This forces models to algebraically deduce the bipartite structure rather than relying on surface-level keyword matching to trigger graph-coloring templates.
</RATIONALE>
<PRESERVED_ANSWER>
Since the domain of $s_i$ is strictly $\{1, 2\}$, the equation $s_u^2 + s_v^2 = 5$ is satisfied if and only if one variable is 1 and the other is 2, making it mathematically identical to the original $s_u \neq s_v$ constraint for all possible inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains equivalent to 2-coloring a graph with $n$ vertices and $m$ edges, which is solvable in $O(n+m)$ time using BFS or DFS, keeping it in P.
</PRESERVED_CLASS>
