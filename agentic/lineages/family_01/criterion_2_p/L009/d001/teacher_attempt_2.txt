# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

A factory needs to divide its $n$ employees into two distinct workgroups, designated as group 1 and group 2.

The factory has $m$ specialized workstations. Each workstation requires exactly two specific employees to operate it. Due to scheduling conflicts, these two employees cannot be placed in the same workgroup. Therefore, for every workstation, its two assigned employees must be placed in opposite groups.

You need to find a valid group assignment for all $n$ employees that respects these workstation restrictions. If no such configuration exists, you must detect this.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of employees who operate a shared workstation.

## Output
If it is impossible to satisfy all restrictions, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, \dots, s_n$, where $s_i \in \{1, 2\}$ represents the group assigned to employee $i$. If more than one valid configuration exists, you must output the configuration that minimizes the value of the expression $\sum_{i=1}^n s_i \cdot 2^{n-i}$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The phrase "lexicographically smallest" was replaced with the mathematical objective function $\sum_{i=1}^n s_i \cdot 2^{n-i}$. Because $2^{n-i}$ strictly dominates the sum of all subsequent maximum possible terms, minimizing this expression is mathematically identical to finding the lexicographically smallest sequence. This removes the text pattern that models rely on to shortcut the tie-break logic, forcing them to reason about the objective function to deduce the greedy component-assignment strategy.
</RATIONALE>
<PRESERVED_ANSWER>
The maximum possible value of the remaining terms after index $k$ is strictly less than the difference made by changing $s_k$ from 1 to 2, ensuring the minimum sum corresponds exactly to the lexicographically smallest sequence.
</PRESERVED_ANSWER>
