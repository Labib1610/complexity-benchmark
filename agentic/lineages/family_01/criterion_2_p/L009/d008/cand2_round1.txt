# Problem B — Module Updates

Time limit: 1 s
Memory limit: 256 MB

You are configuring $n$ processing modules. Each module must be assigned exactly one update package, chosen from either package 1 or package 2.
- Package 1 installs libraries A and B.
- Package 2 installs libraries B and C.

The system contains $m$ dependency links. Each link connects exactly two specific modules.
For a link to function correctly, the union of the libraries installed on its two connected modules must contain exactly 3 distinct libraries.

You must assign a package to each of the $n$ modules so that all $m$ links function correctly. If no such assignment is possible, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of the two modules connected by a single dependency link.

## Output
If no valid package assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $c_1, \dots, c_n$ (each $c_i \in \{1, 2\}$), where $c_i$ is the package assigned to module $i$. 
If there are multiple valid assignments, output the one that is preferred according to the following rule: compare assignments module by module starting from module 1; at the first module where they differ, the assignment with the smaller package number is preferred.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The scenario was entirely rewritten using a "Set Union Cardinality Masking" method. By framing the constraint as a requirement that the union of two feature sets ({A, B} and {B, C}) must have exactly 3 distinct elements, the problem perfectly encodes a pairwise inequality constraint without using any arithmetic (like "sum to 3") or graph coloring terminology. This forces the model to logically deduce the mutual exclusion and map it to bipartite component traversal, rather than relying on surface-level keyword triggers. The tie-breaker was also rephrased to avoid the word "lexicographically".
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that the union of {A, B} (package 1) and {B, C} (package 2) contains exactly 3 distinct libraries is only satisfied if one module has package 1 and the other has package 2, which is mathematically identical to the original requirement that their channels sum to 3; the tie-breaker is also the precise definition of lexicographical order.
</PRESERVED_ANSWER>

The problem remains equivalent to finding the lexicographically smallest 2-coloring of an undirected graph (or determining if it is bipartite), which is solvable in $O(n+m)$ time using Breadth-First Search or Depth-First Search.
</PRESERVED_CLASS>
