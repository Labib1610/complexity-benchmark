<STATEMENT>
# Problem B — Network Channels

Time limit: 1 s
Memory limit: 256 MB

You are configuring a network of $n$ communication nodes. Each node $i$ must be assigned a channel $c_i$ belonging to the set $\{1, 2\}$.

The network contains $m$ interference links. Each link connects exactly two specific nodes. 
To maintain a balanced signal across the network, we define the resonance score of a link connecting node $u$ and node $v$ as $R(u, v) = c_u^{c_v} + c_v^{c_u}$. 
The configuration is considered stable if and only if the resonance score of every interference link in the network is exactly 3.

You must assign a channel to each of the $n$ nodes so that this stability requirement is met for all links. If no such assignment is possible, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the two nodes connected by a single interference link.

## Output
If no valid channel assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $c_1, \dots, c_n$ (each $c_i \in \{1, 2\}$), where $c_i$ is the channel assigned to node $i$. If there are multiple valid assignments, output the one that is lexicographically smallest. An assignment sequence $A$ is lexicographically smaller than $B$ if, at the first index $i$ where they differ, $A_i < B_i$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit linear sum condition ($c_u + c_v = 3$) with an equivalent non-linear exponential equation ($c_u^{c_v} + c_v^{c_u} = 3$). This forces the model to evaluate the mathematical relationship to discover the implicit $c_u \neq c_v$ constraint, breaking simple pattern matching to bipartite graph coloring while avoiding any forbidden complexity-class vocabulary.
</RATIONALE>
<PRESERVED_ANSWER>
Since the domain is restricted to {1, 2}, the equation $c_u^{c_v} + c_v^{c_u} = 3$ is only satisfied when one channel is 1 and the other is 2, which is exactly equivalent to the seed's validity condition.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
