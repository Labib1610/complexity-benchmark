<METHOD_NAME>Polynomial Root Masking</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the direct "sum to 3" or "not equal" constraint with a mathematically equivalent condition on the roots of a quadratic polynomial. Models relying on surface pattern matching for graph coloring will fail to map this algebraic property to bipartite checking, while models that algebraically evaluate the condition over the finite domain {1, 2} will derive the true constraint (c_u != c_v) and succeed.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem B — Transmitter Frequencies

Time limit: 1 s
Memory limit: 256 MB

You are configuring a network of $n$ signal transmitters. Each transmitter $i$ must be assigned a frequency band $c_i$ of either 1 or 2.

The network contains $m$ interference links. Each link connects exactly two specific transmitters. 
To avoid signal cancellation, the combined signal of any two linked transmitters $u$ and $v$ must be strictly non-degenerate. Specifically, the quadratic polynomial $P(x) = c_u x^2 + (c_u + c_v)x + c_v$ must have two distinct real roots.

You must assign a frequency band to each of the $n$ transmitters so that this requirement is met for all links. If no such assignment is possible, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the two transmitters connected by a single interference link.

## Output
If no valid band assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $c_1, \dots, c_n$ (each $c_i \in \{1, 2\}$), where $c_i$ is the band assigned to transmitter $i$. If there are multiple valid assignments, output the one that is lexicographically smallest. An assignment sequence $A$ is lexicographically smaller than $B$ if, at the first index $i$ where they differ, $A_i < B_i$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit sum-to-3 requirement was replaced with a condition requiring a quadratic polynomial to have distinct real roots. This forces the model to either algebraically deduce the discriminant condition or evaluate the polynomial for the four possible $(c_u, c_v)$ combinations to uncover the underlying bipartite structure, breaking simple keyword-based pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The discriminant of $P(x) = c_u x^2 + (c_u + c_v)x + c_v$ is $(c_u + c_v)^2 - 4 c_u c_v = (c_u - c_v)^2$, which is strictly positive (yielding distinct real roots) if and only if $c_u \neq c_v$; since the domain is $\{1, 2\}$, this is perfectly equivalent to the original requirement that they sum to 3.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying mathematical task remains identifying whether the graph is bipartite and finding the lexicographically smallest valid 2-coloring, keeping the problem squarely in P.
</PRESERVED_CLASS>
