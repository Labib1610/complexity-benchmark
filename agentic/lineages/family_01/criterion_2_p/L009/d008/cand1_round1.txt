<METHOD_DESCRIPTION>Replaces a simple discrete constraint (sum to 3) with a geometric invariant (non-collinearity of three points parameterized by the variables). Models that rely on text similarity to known graph problems fail to match the geometric phrasing to bipartite coloring, forcing them to analytically evaluate the conditions for all domain pairs to discover the $c_u \neq c_v$ constraint.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Spatial Resonance Avoidance

Time limit: 1 s
Memory limit: 256 MB

You are configuring a network of $n$ communication nodes. Each node $i$ must be assigned a scaling factor $c_i$ chosen from the set $\{1, 2\}$.

The system's maximum node capacity is exactly the number of 5-byte data frames that can fit into a 1-megabyte (defined as $10^6$ bytes) buffer. The network consists of $n$ nodes ($1 \le n \le \text{maximum capacity}$) and $m$ interference links ($0 \le m \le \text{maximum capacity}$).

Each interference link connects exactly two specific nodes. To prevent signal resonance across a link connecting node $u$ and node $v$, the assignment must guarantee that the three points in the 2D Cartesian plane given by $P_1 = (c_u, c_v)$, $P_2 = (c_v, c_u)$, and $P_3 = (1, 1)$ form the vertices of a non-degenerate triangle (i.e., a triangle with strictly positive area, meaning the three points are not collinear).

You must assign a scaling factor to each of the $n$ nodes so that this geometric requirement is met for all interference links. If no such assignment is possible, you must report it.

## Input
The first line contains two integers $n$ and $m$.
Each of the next $m$ lines contains two integers $u$ and $v$ — the two nodes connected by a single interference link.

## Output
If no valid scaling factor assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $c_1, \dots, c_n$ (each $c_i \in \{1, 2\}$), where $c_i$ is the scaling factor assigned to node $i$. If there are multiple valid assignments, output the one that is lexicographically smallest. An assignment sequence $A$ is lexicographically smaller than $B$ if, at the first index $i$ where they differ, $A_i < B_i$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit "sum to 3" constraint with a geometric non-collinearity condition parameterized by the node assignments. This forces the model to step out of pure graph-theory pattern matching and analytically evaluate the condition over the allowed domain $\{1, 2\}$ to discover that it strictly enforces $c_u \neq c_v$. I also applied strategy S07, hiding the numerical bounds behind a simple buffer capacity calculation.
</RATIONALE>
<PRESERVED_ANSWER>
Over the domain {1, 2}, the points (c_u, c_v), (c_v, c_u), and (1, 1) are distinct and non-collinear if and only if c_u != c_v, which is mathematically identical to the original requirement that c_u + c_v = 3, ensuring all valid assignments remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains fundamentally equivalent to finding a valid 2-coloring (checking bipartiteness) on an undirected graph, which is solvable in O(n + m) time using BFS or DFS, keeping it firmly in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the geometric condition as requiring a floating-point representation or complex computational geometry algorithms, rather than realizing it simplifies to a strict inequality check on a binary domain.
</RISK>
