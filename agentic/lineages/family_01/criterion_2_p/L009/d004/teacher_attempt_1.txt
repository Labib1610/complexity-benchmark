# Problem B — Flux Channels

Time limit: 1 s
Memory limit: 256 MB

An experimental fusion reactor relies on an array of $n$ magnetic coils. Every coil $i$ requires a specific frequency multiplier $c_i$ to operate. Due to strict hardware limitations, the only allowable multiplier values are 1 and 2.

The reactor architecture includes $m$ delicate flux channels, each establishing a direct link between a pair of coils. To prevent saturation and maintain magnetic stability, the product of the multipliers assigned to any two linked coils must be exactly 2.

Your task is to verify if there is a complete assignment of multipliers for all $n$ coils that prevents every flux channel from saturating. If no such state can be achieved, you must report it.

## Input
The first line specifies two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the subsequent $m$ lines provides two integers $u$ and $v$ ($1 \le u, v \le n$), identifying a pair of coils linked by a flux channel.

## Output
If a stable state cannot be achieved, print `NO` on a single line.
If a stable state is possible, print `YES` on the first line. On the second line, provide $n$ integers $c_1, \dots, c_n$, where $c_i$ is the multiplier for coil $i$. If there are several valid assignments, select the one that minimizes $c_1$. If ties persist, minimize $c_2$, and continue resolving ties in this left-to-right manner up to $c_n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
