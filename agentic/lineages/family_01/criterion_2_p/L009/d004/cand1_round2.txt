# Problem B — Factory Tuning

Time limit: 1 s   Memory limit: 256 MB

The factory operates $n$ machines, each of which must be tuned to a power mode of either 1 or 2. The facility's layout introduces $m$ interference links between specific pairs of machines. 

To prevent feedback loops, a legacy safety controller monitors each link. For any linked pair of machines with assigned power modes $x$ and $y$, the controller evaluates the complex number $(x + y i)^2$, where $i$ is the imaginary unit. The controller accepts the link if and only if the imaginary part of this evaluated number is exactly 4.

Your task is to assign a power mode to every machine such that all $m$ links are safely accepted by the controller.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a linked pair of machines.

## Output
If no valid assignment of modes exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Replaced the matrix inversion constraint with evaluating the imaginary part of $(x+yi)^2$. This mathematically simplifies to $2xy = 4 \implies xy=2$, which over the domain $\{1, 2\}$ is exactly the condition $x \neq y$. This forces models to genuinely evaluate the new local condition and recognize the underlying 2-coloring structure, defeating pattern matchers that look for matrix determinants or explicit inequality constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the imaginary part of $(x+yi)^2$ equals 4 simplifies to $2xy = 4$, which for $x, y \in \{1, 2\}$ is true if and only if $x \neq y$, exactly matching the seed's matrix invertibility condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "imaginary part exactly equal to 4" as requiring the entire complex number to be pure imaginary (i.e., real part is 0), but the standard mathematical definition isolates the imaginary coefficient, making this risk minimal.
</RISK>
