<METHOD_NAME>Non-linear Diophantine Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the linear sum condition (x+y=3) with a highly non-linear symmetric equation (x^y + y^x = 3) over the domain {1, 2}. Models relying on semantic pattern matching will fail to recognize the bipartite graph coloring structure, while models that reason about the finite domain will deduce x != y and solve it with BFS/DFS.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Resonance Tuning

Time limit: 1 s
Memory limit: 256 MB

You are tuning a system of $n$ oscillators. Each oscillator $i$ must be assigned a phase state $p_i$ of either 1 or 2.

The system contains $m$ interference monitors. Each monitor observes exactly two specific oscillators. To achieve perfect destructive interference, the phase states of the two observed oscillators, $u$ and $v$, must satisfy the resonance equation:
$$p_u^{p_v} + p_v^{p_u} = 3$$

You must assign a phase state to each of the $n$ oscillators such that all $m$ monitors detect perfect balance. If no such configuration is possible, you must report it.

## Input
The first line contains two integers $n$ and $m$. The number of oscillators $n$ is at least one and bounded by a maximum capacity of two hundred thousand. The number of monitors $m$ ranges from zero up to two hundred thousand.
Each of the next $m$ lines contains two integers $u$ and $v$ — the two oscillators that a single monitor observes.

## Output
If no valid phase state assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $p_1, \dots, p_n$ (each $p_i \in \{1, 2\}$), where $p_i$ is the phase state assigned to oscillator $i$. If there are multiple valid assignments, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I changed the arithmetic condition from a linear sum ($p_u + p_v = 3$) to a non-linear exponential equation ($p_u^{p_v} + p_v^{p_u} = 3$). Over the restricted domain $\{1, 2\}$, this is mathematically equivalent to demanding that $p_u \neq p_v$. This forces the model to evaluate the equation over the finite domain to discover the inequality, preventing it from pattern-matching the problem straight to bipartite graph coloring based on the "sum to 3" keyword. I also removed direct numeric bounds, replacing them with text limits.
</RATIONALE>
<PRESERVED_ANSWER>
The domain of $p_i$ is strictly $\{1, 2\}$, and for any pair in this domain, $x^y + y^x = 3$ is only satisfied when $x=1, y=2$ or $x=2, y=1$; this matches the exact same truth table as $x+y=3$, meaning every valid assignment remains identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is still equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in $O(n+m)$ time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
Models might struggle to parse the text-based bounds for $n$ and $m$, though the wording is explicit and leaves no room for ambiguous interpretation.
</RISK>
