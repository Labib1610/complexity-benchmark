# Problem B — Flux Channels

Time limit: 1 s   Memory limit: 256 MB

An experimental fusion reactor contains $n$ magnetic coils. Each coil $i$ must be tuned to an operating frequency multiplier $c_i$, which must be chosen from the set $\{1, 2\}$.

The reactor's design includes $m$ delicate flux channels, each connecting a specific pair of coils. To maintain a stable magnetic field and prevent the channel from saturating, the product of the frequency multipliers of the two coils connected by any flux channel must be exactly 2.

You need to determine if there is a valid tuning for all $n$ coils that keeps every flux channel stable, or report that no such configuration is possible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a pair of coils connected by a flux channel.

## Output
If no valid tuning exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $c_1, \dots, c_n$, where $c_i$ is the frequency multiplier assigned to coil $i$. If multiple stable tunings exist, they are compared by examining the coils in numerical order from $1$ to $n$. At the first coil index where two tunings assign different multipliers, the tuning that assigns 1 is strictly preferred over the tuning that assigns 2. You must output the most preferred tuning.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the channel stability condition from a sum of 3 to a product of 2, and explicitly spelled out the tie-break comparison without using the word "minimize". This forces the model to independently deduce that the product condition over the domain {1, 2} requires differing assignments, blocking the direct `3 - cu` arithmetic trick and the surface-level recognition of lexicographical component orientation.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $c_u \times c_v = 2$ for $c_i \in \{1, 2\}$ is mathematically identical to $c_u + c_v = 3$, meaning the set of valid tunings and their preference order for any input is exactly the same as in the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains fundamentally equivalent to finding a valid 2-coloring of a graph and choosing the lexicographically smallest valid assignment, which is solvable in linear time using a standard traversal algorithm.
</PRESERVED_CLASS>
