# Problem B — Flux Channels

Time limit: 1 s   Memory limit: 256 MB

An experimental fusion reactor contains a set of magnetic coils. Each coil must be tuned to a specific phase state, represented by the integer 1 or 2.

The reactor's design includes delicate flux channels, each connecting a specific pair of coils. To maintain a stable magnetic field and prevent the channel from saturating, the coil at one end of a flux channel must be tuned to a different phase state than the coil at the other end.

The reactor's main chassis requires at least a single coil to operate, and has physical space to mount a maximum of $200,000$ coils. The cooling infrastructure can support any number of flux channels from zero up to a strict limit of $200,000$.

You need to determine if there is a valid tuning for all installed coils that keeps every flux channel stable, or report that no such configuration is possible.

## Input
The first line contains two integers $n$ and $m$, the number of installed coils and the number of flux channels, respectively. The values of $n$ and $m$ respect the physical limits of the chassis and cooling infrastructure described above.
Each of the next $m$ lines contains two integers $u$ and $v$, representing the indices of the coils at the two ends of a flux channel. Coils are indexed with integers from $1$ to $n$, inclusive.

## Output
If no valid tuning exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, output $n$ integers $c_1, \dots, c_n$, where $c_i$ is the phase state assigned to coil $i$. If multiple valid tuning sequences exist, output the one that is lexicographically smallest (i.e., choose the sequence that minimizes $c_1$; if ties remain, minimize $c_2$, and so on).

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
