**Solution Explanation**

For a node we choose a capacity `c_i ∈ {1,2}`.  
For an edge `(u,v)` we look at a grid `c_u × c_v`.  
The number of different sub‑rectangles of an `a × b` grid equals  

\[
\frac{a(a+1)}2 \cdot \frac{b(b+1)}2 .
\]

For `a,b ∈ {1,2}` the values are  

| a | b | rectangles |
|---|---|------------|
|1|1|1|
|1|2|3|
|2|1|3|
|2|2|9|

The required value is **3**, therefore each edge must connect a node with
capacity 1 to a node with capacity 2.
So the whole graph has to be *bipartite* and the two parts must be coloured
`1` and `2`.

--------------------------------------------------------------------

#### Lexicographically smallest colouring
In a bipartite component we may swap the two colours.
To obtain the smallest possible whole sequence we simply force the
**smallest indexed vertex of every component to be colour 1**.
All other vertices are then forced to the opposite colour.
Processing vertices in increasing order and starting a BFS/DFS whenever we meet
an uncoloured vertex guarantees exactly this rule, because the first vertex
of the component we encounter is its smallest index.

If during the BFS we ever need to give a neighbour the same colour as the
current vertex, the graph is not bipartite → answer `NO`.

--------------------------------------------------------------------

#### Algorithm
```
read n,m
build adjacency list
col[1..n] = 0          # 0 = uncoloured, 1 or 2 otherwise
for v = 1 .. n:
    if col[v] == 0:
        col[v] = 1                     # smallest vertex of its component → 1
        queue = [v]
        while queue not empty:
            u = pop queue
            for w in adj[u]:
                if col[w] == 0:
                    col[w] = 3 - col[u]   # opposite colour
                    push w
                elif col[w] == col[u]:
                    print "NO" and exit
print "YES"
print col[1] … col[n]
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a lexicographically smallest
valid assignment iff such an assignment exists.

---

##### Lemma 1  
If the algorithm finishes without conflict, the produced assignment satisfies
the stability condition for every edge.

**Proof.**  
During BFS each edge `(u,v)` is examined exactly once from each endpoint.
When `v` is first discovered we set `col[v] = 3 - col[u]`, i.e. the two
endpoints receive different colours (1 and 2).  
Thus every edge connects capacities `1` and `2`, which is exactly the
required pair (1,2) or (2,1). ∎



##### Lemma 2  
If the algorithm reports a conflict, no valid assignment exists.

**Proof.**  
A conflict appears when an edge `(u,v)` has already assigned colours
`col[u] = col[v]`. Any proper 2‑colouring of a graph must give opposite
colours to the ends of every edge, otherwise the edge would connect equal
capacities and the number of sub‑rectangles would be 1 or 9, not 3.
Hence a graph containing such an edge cannot be coloured according to the
requirement, i.e. no solution exists. ∎



##### Lemma 3  
Assume the graph is bipartite. The algorithm outputs a colouring that is
lexicographically smallest among all valid colourings.

**Proof.**  
Consider a connected component `C`. Let `x` be the smallest index vertex in
`C`. The algorithm starts the BFS from `x` (when the outer loop reaches it)
and forces `col[x]=1`. Any valid colouring must assign opposite colours to
the two bipartition sides; swapping the two sides would change `x` to colour 2,
which makes the whole sequence larger at position `x`. Therefore any
lexicographically minimal colouring must have `col[x]=1`.  
All other vertices of `C` are forced uniquely by the bipartition, so the
algorithm’s colours on `C` coincide with every lexicographically minimal
colouring. Repeating the argument for every component (processed in increasing
order) yields the globally smallest sequence. ∎



##### Lemma 4  
If the graph is bipartite, the algorithm never reports a conflict.

**Proof.**  
A bipartite graph admits a 2‑colouring with opposite colours on each edge.
The BFS exactly reproduces such a colouring (starting from any vertex) because
it always assigns the opposite colour to neighbours. Hence no edge ever has
both ends with the same colour, so no conflict occurs. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no assignment of capacities `{1,2}` satisfies the stability
  condition for all edges;  

* otherwise `YES` followed by the lexicographically smallest valid assignment.

**Proof.**  

- If the algorithm prints `NO`, by Lemma&nbsp;2 no solution exists.
- If it prints `YES`, it finished without conflict, therefore by Lemma&nbsp;1
  the assignment is valid.  
  By Lemma&nbsp;4 this can happen only when the graph is bipartite.
  By Lemma&nbsp;3 the produced assignment is the lexicographically smallest
  among all valid ones.  

Conversely, if a valid assignment exists, the graph must be bipartite,
so the algorithm (by Lemma&nbsp;4) finishes without conflict and prints a
valid assignment, which by Lemma&nbsp;3 is the smallest possible. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`O(n + m)` time: each vertex and edge is processed once.  
`O(n + m)` memory for the adjacency lists and the colour array.

--------------------------------------------------------------------

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    col = [0] * (n + 1)          # 0 = uncoloured, 1 or 2 otherwise

    for start in range(1, n + 1):
        if col[start]:
            continue
        col[start] = 1            # smallest vertex of this component → 1
        q = deque([start])
        while q:
            u = q.popleft()
            cu = col[u]
            for w in adj[u]:
                if col[w] == 0:
                    col[w] = 3 - cu
                    q.append(w)
                elif col[w] == cu:
                    sys.stdout.write("NO")
                    return

    out = ["YES"]
    out.append(' '.join(str(col[i]) for i in range(1, n + 1)))
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```

to the required input‑output format.
