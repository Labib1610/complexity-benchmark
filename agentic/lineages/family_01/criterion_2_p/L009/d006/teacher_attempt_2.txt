# Differential Lighting

Time limit: 1 s   Memory limit: 256 MB

You are setting up a lighting network with $n$ fixtures, indexed from 1 to $n$. Each fixture must be connected to exactly one of two power grids: Grid 1 or Grid 2.

The network is equipped with $m$ voltage comparators. Each comparator is attached to two specific fixtures (it is possible for a comparator to be attached to the same fixture twice). A comparator operates successfully only if it detects a potential difference, which requires its two attached fixtures to be connected to different grids.

Determine if there is a complete grid assignment for all $n$ fixtures such that every comparator operates successfully.

To resolve ambiguities when multiple valid assignments exist, the network's controller applies a sequential stabilization protocol. Starting with the full set of all valid assignments, it filters them step by step for each fixture $i$ from 1 to $n$:
- During step $i$, if the remaining pool of valid assignments contains at least one assignment where fixture $i$ is connected to Grid 1, the controller permanently discards any assignment from the pool where fixture $i$ is connected to Grid 2. If the pool only contains assignments where fixture $i$ is connected to Grid 2, no discards are made at this step.

Output the single assignment that survives this protocol.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing the indices of the fixtures attached to a voltage comparator.

## Output
If no valid grid assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $c_1, \dots, c_n$, where $c_i$ is the grid (1 or 2) assigned to fixture $i$ in the final surviving assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit instruction to "minimize $c_i$ sequentially" with an equivalent description of a sequential filtering process over the set of all valid assignments. This removes the direct trigger for the "lexicographically smallest = first vertex gets color 1" shortcut, forcing the model to deduce that the solution space factorizes by connected components in order to solve it efficiently.
</RATIONALE>
<PRESERVED_ANSWER>
The sequential filtering process that prefers Grid 1 at step $i$ exactly matches the lexicographical minimization of the sequence of circuit choices specified in the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem remains 2-coloring (bipartiteness testing), which is in P, and the tie-breaking rule still uniquely selects the same component-wise coloring in linear time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the filtering process as requiring a literal simulation of all valid assignments, leading to timeouts if they attempt a backtracking search instead of recognizing the underlying graph structure.
</RISK>
