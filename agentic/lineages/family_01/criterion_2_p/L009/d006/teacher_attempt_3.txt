# Phase Synchronization

Time limit: 1 s   Memory limit: 256 MB

You are configuring a phase synchronization network consisting of $n$ oscillators, numbered 1 through $n$. The facility infrastructure can host anywhere from a single oscillator up to two hundred thousand units.

The network includes $m$ interference links. The total number of links can range from zero up to two hundred thousand. Each link couples a specific pair of oscillators. Due to reflection artifacts, a link might couple an oscillator to itself.

Each oscillator must be configured to operate at a specific phase state, represented by an integer $c_i \in \{1, 2\}$.
For the network to remain stable, the states across every interference link must balance. Specifically, if a link couples oscillator $u$ and oscillator $v$, their assigned phase states must strictly satisfy the equation $c_u + c_v = 3$.

Your task is to determine whether there is a valid phase state assignment for all $n$ oscillators that satisfies all $m$ interference links simultaneously.

## Input
The first line contains two integers $n$ and $m$. The guarantees on their minimum and maximum values are provided by the facility constraints described above.
Each of the next $m$ lines contains two integers $u$ and $v$ (between 1 and $n$, inclusive), representing the indices of the oscillators coupled by an interference link.

## Output
If no valid phase state assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $c_1, \dots, c_n$, where $c_i$ is the phase state (1 or 2) assigned to oscillator $i$. If there are multiple valid assignments, choose the assignment that minimizes $c_1$. If there is still a tie, minimize $c_2$ among the remaining valid assignments, and continue this process sequentially up to $c_n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit mention of assigning fixtures to two different circuits was removed, as it strongly triggered bipartite-graph and 2-coloring recognition in models. Instead, the constraint is presented algebraically as $c_u + c_v = 3$ for $c_i \in \{1, 2\}$. This forces the model to deduce that the algebraic relation implies a bipartite structure, rather than relying on surface-level pattern matching on "different circuits". Numeric bounds are also expressed through the scenario text as physical capacities to comply with S07.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement $c_u + c_v = 3$ for bounded values $c_i \in \{1, 2\}$ is mathematically identical to requiring that exactly one variable is 1 and the other is 2, perfectly preserving the original circuit assignment logic and tie-breaker.
</PRESERVED_ANSWER>

The core problem remains exactly 2-coloring / bipartiteness testing, which is solved in linear time $O(n+m)$ using BFS or DFS, keeping it firmly in P.
</PRESERVED_CLASS>
