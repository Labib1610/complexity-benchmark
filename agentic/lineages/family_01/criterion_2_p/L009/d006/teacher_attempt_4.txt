# Bivalent Equation System

Time limit: 1 s   Memory limit: 256 MB

You are analyzing a system of $n$ discrete variables, $v_1, v_2, \dots, v_n$. Due to hardware constraints, each variable must be assigned a value of exactly 1 or 2.

The system is restricted by $m$ sum conditions. Each condition specifies two variable indices $x$ and $y$ (due to automated generation, a condition might specify the same index twice). For the system to be stable, every condition must satisfy the equation:
$v_x + v_y = 3$

Your task is to determine whether there is an assignment of values for all $n$ variables that satisfies all $m$ equations simultaneously.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $x$ and $y$ ($1 \le x, y \le n$), representing the indices of the variables in a sum condition.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $v_1, \dots, v_n$, where $v_i$ is the value (1 or 2) assigned to variable $i$. If there are multiple valid assignments, choose the assignment that minimizes $v_1$. If there is still a tie, minimize $v_2$ among the remaining valid assignments, and continue this process sequentially up to $v_n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
