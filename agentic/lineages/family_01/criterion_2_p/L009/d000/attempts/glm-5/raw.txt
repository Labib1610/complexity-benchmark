Looking at this problem, I need to assign each worker to shift 1 or 2 such that no conflicting pair shares the same shift. This is exactly a 2-coloring problem on a graph where workers are nodes and conflict pairs are edges.

For the lexicographically smallest assignment, I should greedily assign the smallest valid value (1 if possible, else 2) to each unvisited node in order from 1 to n.

When I assign a value to a node, I propagate constraints to its neighbors. If a neighbor already has a conflicting assignment, it's impossible. If a neighbor is unassigned, I tentatively assign it the opposite value and continue propagating. If this leads to a contradiction, I need to backtrack and try the other value for the original node.

The key insight: when I try value 1 for node `u`, I do a full BFS/DFS propagation. If it fails, I try value 2. If both fail, output NO.

To handle backtracking efficiently, I track which nodes were assigned during the current propagation attempt, so I can undo them if needed.

```python
import sys
from collections import deque

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * (n + 1)
    
    for start in range(1, n + 1):
        if color[start] != 0:
            continue
        
        success = False
        for init_c in (1, 2):
            color[start] = init_c
            assigned = [start]
            queue = deque([start])
            ok = True
            
            while queue and ok:
                u = queue.popleft()
                for v in adj[u]:
                    if color[v] == 0:
                        color[v] = 3 - color[u]
                        assigned.append(v)
                        queue.append(v)
                    elif color[v] == color[u]:
                        ok = False
                        break
            
            if ok:
                success = True
                break
            else:
                for node in assigned:
                    color[node] = 0
        
        if not success:
            print("NO")
            return
    
    print("YES")
    print(' '.join(str(color[i]) for i in range(1, n + 1)))

solve()
```
