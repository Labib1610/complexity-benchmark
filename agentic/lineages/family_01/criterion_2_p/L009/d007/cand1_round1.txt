<STATEMENT>
# Problem B — Harmonic Stability

Time limit: 1 s
Memory limit: 256 MB

You are configuring $n$ resonance crystals in a laboratory. Each crystal $i$ must be tuned to a frequency multiplier $p_i$ of either 1 or 2.

For each crystal $i$, assigning it a frequency multiplier $p_i$ determines its characteristic polynomial value:
$C_i = p_i^3 - 3p_i^2 + 4p_i - 3$

This value is used to construct the crystal's $3 \times 3$ resonance matrix $M_i$:
$$ M_i = \begin{pmatrix} i & C_i & 0 \\ -C_i & i & 0 \\ 0 & 0 & 1 \end{pmatrix} $$

The setup contains $m$ harmonic bridges. Each bridge connects exactly two specific crystals. 
When a bridge connects crystal $u$ and crystal $v$, their matrices interact to form the bridge's compound matrix $K = M_u \times M_v$.
(Note: Matrix multiplication is the standard row-by-column product. The order of multiplication, $M_u \times M_v$ versus $M_v \times M_u$, does not affect the sum of the main diagonal elements).

To maintain structural stability, the trace of $K$ (the sum of the three elements on its main diagonal) must be strictly greater than $2 \cdot u \cdot v$.

You must assign a frequency multiplier to each of the $n$ crystals so that the compound matrix for every single bridge in the setup satisfies this stability condition. If no such assignment is possible, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the two crystals connected by a single harmonic bridge.

## Output
If no valid tuning assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $p_1, \dots, p_n$ (each $p_i \in \{1, 2\}$), where $p_i$ is the frequency multiplier assigned to crystal $i$. If there are multiple valid assignments, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit array inversion condition with a 3x3 matrix multiplication whose trace depends on a cubic polynomial of the assigned values. This mathematically reduces to exactly the same bipartite constraint ($p_u \neq p_v$), but statically appears as a non-linear algebraic system parameterized by node indices. To succeed, the model must now algebraically simplify the trace expression or write a script to evaluate the condition, rather than simply pattern-matching the known array inversion logic.
</RATIONALE>
<PRESERVED_ANSWER>
The trace of the compound matrix simplifies to $2uv - 2C_uC_v + 1$, which is strictly greater than $2uv$ if and only if $C_u \neq C_v$, meaning $p_u \neq p_v$, exactly preserving the valid assignments for every edge.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring of the graph, which is solvable in linear time using BFS or DFS, keeping it in P.
</PRESERVED_CLASS>
