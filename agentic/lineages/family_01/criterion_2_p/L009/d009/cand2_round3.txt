<METHOD_NAME>Game-Theoretic Local Masking</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the direct inequality condition (`c_u != c_v`) with the evaluation of a combinatorial game (Wythoff's game) played on piles of size `c_u` and `c_v`. Since the domain is strictly `{1, 2}`, a second-player win precisely isolates the pairs `(1, 2)` and `(2, 1)`. This forces the model to correctly evaluate the game theory constraint to discover the inequality, and then recognize the resulting global structure as bipartite coloring, defeating models that rely on simple algebraic pattern matching.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Network Channels

Time limit: 1 s
Memory limit: 256 MB

You are configuring a network of $n$ communication nodes. Each node $i$ must be assigned a channel $c_i$ belonging to the set $\{1, 2\}$.

The network contains $m$ conflict pairs. Each pair designates two specific nodes that interfere with each other. 
To evaluate if a channel assignment prevents interference, we define a stability testing game for each conflict pair $(u, v)$. The game starts with two energy pools containing $c_u$ and $c_v$ quanta respectively. Two automated agents take turns drawing energy. In a single turn, an agent must make exactly one of the following moves:
- Choose exactly one pool and draw $k$ quanta from it, where $1 \le k \le \text{current size of that pool}$.
- Draw $k$ quanta from both pools simultaneously, where $1 \le k \le \text{minimum of the current sizes of the two pools}$.

The agent who draws the last quantum of energy (thereby leaving both pools with 0 quanta) wins the game. 
The network configuration is considered stable if and only if, for every conflict pair in the network, the starting state $(c_u, c_v)$ guarantees a win for the second agent to move, assuming both agents play optimally.

You must assign a channel to each of the $n$ nodes so that this stability requirement is met for all conflict pairs. If no such assignment is possible, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the two nodes that form a conflict pair.

## Output
If no valid channel assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $c_1, \dots, c_n$ (each $c_i \in \{1, 2\}$), where $c_i$ is the channel assigned to node $i$. If there are multiple valid assignments, output the one that is lexicographically smallest. An assignment sequence $A$ is lexicographically smaller than $B$ if, at the first index $i$ where they differ, $A_i < B_i$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Removed the explicit algebraic resonance equation and replaced it with a combinatorial game played on the assigned channels. Evaluated over the domain {1, 2}, a second-player win perfectly isolates the valid assignments (1, 2) and (2, 1). This forces the model to mathematically evaluate the local game rules to discover the inequality constraint, and then correctly recognize the global bipartite structure without explicit hints.
</RATIONALE>
<PRESERVED_ANSWER>
For every possible pair of values from {1, 2}, the game is a second-player win if and only if the values are different, making the validity condition logically identical to the seed's for every possible input pair, including self-loops.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Bipartite 2-Coloring with a lexicographical tie-break, which can be solved in O(n + m) time using BFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the rules of the game or fail to understand normal-play convention, though the text explicitly defines the valid moves mathematically and states the exact winning condition.
</RISK>
