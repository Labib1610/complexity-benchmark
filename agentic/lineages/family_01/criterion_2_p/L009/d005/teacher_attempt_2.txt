# Problem B — Device Calibration

Time limit: 1 s   Memory limit: 256 MB

You are calibrating a system of $n$ devices, labeled $1$ through $n$. Due to hardware limitations, each device must be configured to a power state of either $1$ or $2$. 

The system has $m$ operational requirements. Each requirement specifies two devices (which may be the same device) and mandates that the product of their assigned power states must be exactly $2$. 

Your task is to determine whether there is a valid configuration of power states for all $n$ devices that satisfies all $m$ requirements simultaneously.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a requirement between device $u$ and device $v$.

## Output
If no valid configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $x_1, \dots, x_n$ representing the chosen power states. If there are multiple valid configurations, consider the sequence of states $x_1, x_2, \dots, x_n$ as the digits of a single base-10 number (with $x_1$ being the most significant digit and $x_n$ the least). You must output the configuration that makes this resulting number as small as possible.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

I changed the sum constraint ($x_u + x_v = 3$) to a product constraint ($x_u \cdot x_v = 2$) over the same domain $\{1, 2\}$, which breaks simple pattern-matching for linear equations while keeping the underlying logic identical. I also replaced the explicit sequential tie-breaking rule with a requirement to minimize the $n$-digit integer formed by the sequence, forcing the model to independently deduce that this requires a greedy lexicographical assignment.
</RATIONALE>
<PRESERVED_ANSWER>
The domain $\{1, 2\}$ and the constraint $x_u \cdot x_v = 2$ exactly enforce that one variable is 1 and the other is 2, which is logically identical to $x_u + x_v = 3$; the base-10 number minimization is mathematically identical to lexicographical minimization, ensuring all answers remain completely unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid assignment of two states under strict mutual exclusion and selecting the lexicographically first valid assignment, which is solvable in linear time using a standard traversal.
</PRESERVED_CLASS>
<RISK>
Some models might misinterpret the base-10 number tie-breaker as requiring arbitrary-precision arithmetic to directly compare answers, though they should realize the digits can just be compared sequentially.
</RISK>
