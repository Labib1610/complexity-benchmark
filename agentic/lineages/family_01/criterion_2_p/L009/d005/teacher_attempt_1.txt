# Problem B — Gear Ratio Configuration

Time limit: 1 s   Memory limit: 256 MB

You are designing a mechanical transmission system consisting of $n$ components, numbered $1$ to $n$. Due to manufacturing specifications, each component must be assigned a gear ratio factor, denoted $x_i$, which must be an integer chosen from the restricted set $\{1, 2\}$. 

You are provided with a list of $m$ meshing constraints. Each constraint specifies two components (which may be the same component repeated). For the system to operate smoothly, every constraint requires that the product of the ratio factors of the two specified components must be exactly 2. 

Your task is to determine whether there is an assignment of ratio factors $x_1, x_2, \dots, x_n$ to all $n$ components that satisfies all $m$ constraints simultaneously.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing the indices of the components in a meshing constraint.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $x_1, \dots, x_n$. If there are multiple valid assignments, choose the assignment that minimizes $x_1$. If there is still a tie, minimize $x_2$ among the remaining valid assignments, and continue this process sequentially up to $x_n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

Removed the explicit "sum must be exactly 3" condition which triggered models to instantly write `target = 3 - x` and pattern-match to bipartite coloring. Replaced it with a domain-specific scenario where the product of factors from the set {1, 2} must be exactly 2, forcing models to deduce the complementary relationship from the multiplication constraint rather than relying on the algebraic sum affordance.
</RATIONALE>
<PRESERVED_ANSWER>
The variables are still restricted to {1, 2}, and the product of two such variables is 2 if and only if one is 1 and the other is 2 (just as their sum is 3 if and only if one is 1 and the other is 2), so the set of valid assignments and the lexicographical tie-breaking remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a 2-coloring (testing for bipartiteness) on the graph defined by the constraints, which is solvable in O(n+m) time using BFS/DFS.
