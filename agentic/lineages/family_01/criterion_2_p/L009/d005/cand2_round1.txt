<STATEMENT>
# Problem B — Harmonic Stability

Time limit: 1 s
Memory limit: 256 MB

You are configuring $n$ resonance crystals in a laboratory. Each crystal must be assigned a frequency tier, which must be a positive integer strictly less than 3.

The setup contains $m$ harmonic bridges. Each bridge connects exactly two specific crystals. To maintain structural stability, each bridge requires a strict imbalance between the two crystals it connects. Specifically, for any bridge connecting crystal $u$ and crystal $v$, the arithmetic mean of their frequency tiers must be strictly greater than their geometric mean.

You must assign a frequency tier to each of the $n$ crystals so that all $m$ bridges are perfectly stable. If no such configuration is possible, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the two crystals connected by a single harmonic bridge.

## Output
If no valid tier assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $p_1, \dots, p_n$ (each $p_i \in \{1, 2\}$), where $p_i$ is the frequency tier assigned to crystal $i$. If there are multiple valid assignments, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit algebraic equation `p_u^2 + p_v^2 = 5` was removed. It was replaced with the condition that the arithmetic mean of the two tiers must be strictly greater than their geometric mean. Because the AM-GM inequality states that the arithmetic mean is strictly greater than the geometric mean if and only if the two values are distinct, this forces the model to either apply the theorem or explicitly evaluate the means for the domain `{1, 2}` to deduce the opposite-value constraint.
</RATIONALE>
<PRESERVED_ANSWER>
The allowed domain "positive integer strictly less than 3" restricts the values to {1, 2}, and the AM > GM condition is satisfied if and only if the two values are distinct, exactly matching the original `p_u^2 + p_v^2 = 5` constraint on the same domain.
</PRESERVED_ANSWER>
