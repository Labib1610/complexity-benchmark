<STATEMENT>
# Problem B — Factory Tuning

Time limit: 1 s
Memory limit: 256 MB

The factory requires each of its $n$ machines to be set to a power mode. The valid power modes are the positive integers $k$ that satisfy the inequality $k^2 + 2 \le 3k$.

There are $m$ interference links between specific pairs of machines. A legacy controller accepts a link between a machine with mode $x$ and a machine with mode $y$ if and only if the line segment in the Cartesian plane connecting the points $(x, 0)$ and $(0, y)$ intersects the boundary of the circle centered at the origin with a radius of $1.3$.

You must assign a valid power mode to every machine such that all $m$ links are accepted by the controller.

## Input
The first line contains two integers $n$ and $m$. The factory's infrastructure limits the number of machines $n$ and the number of links $m$ to at most the number of bytes in $200$ kilobytes (using the standard SI definition where $1\text{ kB} = 1000\text{ bytes}$). It is guaranteed that $1 \le n$ and $0 \le m$.
Each of the next $m$ lines contains two integers $u$ and $v$ — a linked pair of machines.

## Output
If no valid assignment of modes exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each a valid mode), representing the lexicographically smallest valid assignment. (An assignment $s$ is lexicographically smaller than $t$ if at the first index $i$ where they differ, $s_i < t_i$.)

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was rewritten to obfuscate both the available state space (modes 1 and 2) and the bipartite constraint (opposite modes). The state space is now defined by a quadratic inequality that strictly limits valid modes to {1, 2}. The link acceptance condition is replaced with a geometric intersection test. For modes in {1, 2}, this geometric test evaluates to True if and only if the modes are different, effectively functioning as an XOR gate. This forces the model to mathematically evaluate the continuous geometry to discover the discrete 2-coloring structure, breaking superficial pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The inequality $k^2 + 2 \le 3k$ restricts valid positive integers exactly to 1 and 2, and the geometric condition correctly accepts only pairs $(1, 2)$ and $(2, 1)$, preserving the exact same opposite-mode constraints and lexicographically smallest resolution as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest valid 2-coloring of a graph, which is solvable in $O(n+m)$ time using Breadth-First Search, keeping it in P.
</PRESERVED_CLASS>
<RISK>
A reader might question whether "intersects the boundary" includes cases where the segment is entirely inside the circle, but standard mathematical definitions (and the explicit use of the word "boundary") make it unambiguous that the segment must contain a point exactly at distance 1.3 from the origin.
</RISK>
