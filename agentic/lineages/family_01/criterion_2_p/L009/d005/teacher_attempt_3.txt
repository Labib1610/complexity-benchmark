<STATEMENT>
# Problem B — Container Stowage

Time limit: 1 s   Memory limit: 256 MB

A cargo ship is transporting $n$ shipping containers. The ship must carry at least one container, and its deck space imposes a strict physical limit of two hundred thousand containers. 

Each container must be stowed in one of two locations: Hold 1 or Hold 2. 

There are $m$ magnetic interference warnings. Each warning lists two containers (due to sensor glitches, a warning might list the same container twice). To avoid navigation failures, any two containers involved in a single warning must be stowed in different holds. 

The number of warnings, $m$, can be as low as zero, and is guaranteed to never exceed the ship's physical limit.

Your task is to determine whether there is an assignment of holds to all $n$ containers that satisfies all $m$ warnings.

## Input
The first line of the input contains the two integers $n$ and $m$.
Each of the next $m$ lines contains two integers $u$ and $v$, representing the indices of the containers in a warning. These indices correspond to valid containers, starting from 1 up to the actual number of containers on the ship.

## Output
If no valid assignment of holds exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers representing the hold assigned to each container (either 1 or 2). If there are multiple valid assignments, choose the assignment that minimizes the hold number for container 1. If there is still a tie, minimize the hold number for container 2 among the remaining valid assignments, and continue this process sequentially up to container $n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit algebraic system of variables summing to 3 with a domain-specific scenario about assigning containers to one of two holds. This removes the direct mathematical cue (`x_u + x_v = 3` with values `{1, 2}`) that trivially triggers bipartite coloring heuristics, forcing the model to infer the conflict structure from the scenario text. I also applied Strategy S07 by expressing the numeric bounds for $n$ and $m$ indirectly through the ship's physical limits.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to place two containers in different holds (Hold 1 or Hold 2) is logically identical to assigning them values from {1, 2} that sum to 3, preserving all constraint satisfaction, self-loop failures, and sequential tie-breaking outcomes exactly.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to 2-coloring (bipartiteness testing) on a graph where containers are nodes and warnings are edges, keeping it firmly in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "the ship's physical limit" for $m$ as being bounded by $n$ rather than 200,000, though the phrasing explicitly links it to the previously stated "strict physical limit of two hundred thousand".
</RISK>
