**Solution Explanation**

For every crystal `i`

* `d_i` – its degree (number of incident bridges)
* `S_i` – sum of squares of the multipliers of its neighbours  

The required equation  

```
S_i + 3·d_i·p_i = 7·d_i                (1)
```

holds for `p_i ∈ {1,2}`.

--------------------------------------------------------------------

#### 1.   Reformulating the condition  

`p_i = 1`  →  `7‑3·1 = 4`  

`p_i = 2`  →  `7‑3·2 = 1`

From (1)

```
S_i = d_i·4   if p_i = 1
S_i = d_i·1   if p_i = 2
```

`p_j` can only be `1` or `2`, therefore `p_j²` is `1` or `4`.

*If `p_i = 2`*  
`S_i = d_i` → every neighbour contributes `1` → **all neighbours must have p = 1**.

*If `p_i = 1`*  
`S_i = 4·d_i` → every neighbour contributes `4` → **all neighbours must have p = 2**.

Hence **every edge must connect a crystal with multiplier 1 to a crystal with multiplier 2**.
The graph must be bipartite and the two colour classes are exactly the sets
`{p = 1}` and `{p = 2}`.  
If the graph is bipartite, any proper 2‑colouring satisfies the equation,
because each vertex sees only the opposite colour.

--------------------------------------------------------------------

#### 2.   Existence test  

Run a BFS/DFS over every connected component, colour vertices `0/1`.
If we ever find an edge whose ends already have the same colour → the graph
is **not bipartite** → answer `NO`.

--------------------------------------------------------------------

#### 3.   Lexicographically smallest assignment  

For a component we may swap the meaning of the two colours:

```
colour 0 → p = 1 , colour 1 → p = 2          (A)
colour 0 → p = 2 , colour 1 → p = 1          (B)
```

The whole answer is the concatenation of the components in the natural vertex
order, therefore the first vertex (smallest index) where the two possibilities
differ decides which one is lexicographically smaller.
Consequently, for each component we look at its smallest‑index vertex `v`.
If `v` has colour `0` we keep mapping (A), otherwise we use (B) – this makes
`p_v = 1` and is optimal for the whole sequence.

--------------------------------------------------------------------

#### 4.   Algorithm
```
read n, m
build adjacency list
colour[1..n] = -1
answer[1..n] = 0
for each vertex v = 1 .. n
    if colour[v] == -1
        start BFS from v, colour[v] = 0
        store all vertices of this component in list comp
        while queue not empty
            pop x
            for each neighbour y of x
                if colour[y] == -1
                    colour[y] = colour[x] ^ 1
                    push y
                else if colour[y] == colour[x]
                    print "NO" and exit
        # component finished, decide mapping
        min_v = minimum vertex in comp
        if colour[min_v] == 0
            # mapping (A)
            for u in comp: answer[u] = 1 if colour[u]==0 else 2
        else
            # mapping (B)
            for u in comp: answer[u] = 2 if colour[u]==0 else 1
print "YES"
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints `YES` and a lexicographically smallest
valid assignment iff such an assignment exists.

---

##### Lemma 1  
If the algorithm finishes the BFS without conflict, the graph is bipartite
and the colour array is a proper 2‑colouring.

**Proof.** BFS assigns opposite colours to the two ends of every traversed
edge. A conflict would be detected when an edge connects two already coloured
vertices with the same colour. Absence of conflict means no such edge exists,
hence the colouring is proper. ∎



##### Lemma 2  
For any component, the two possible mappings described in the algorithm both
produce a valid multiplier assignment for that component.

**Proof.** By Lemma&nbsp;1 the component is properly coloured, i.e. every edge joins
different colours. In mapping (A) colour 0 receives `p=1`, colour 1 receives
`p=2`. Therefore each edge connects a `1`‑crystal with a `2`‑crystal.
The argument of Section&nbsp;1 shows that this exactly satisfies the required
equation for every vertex. Mapping (B) swaps the two values, still keeping
the property that adjacent vertices have different multipliers, so it is also
valid. ∎



##### Lemma 3  
For a component the algorithm chooses the lexicographically smaller of the two
valid assignments.

**Proof.** Let `v` be the smallest‑index vertex of the component.
The two assignments differ first at `v` (all earlier vertices belong to other
components). In mapping (A) `p_v = 1` iff `colour[v]=0`; in mapping (B) `p_v = 1`
iff `colour[v]=1`. The algorithm selects the mapping that makes `p_v = 1`,
hence the resulting component sequence is lexicographically minimal. ∎



##### Lemma 4  
If the algorithm outputs `YES` and the array `answer`, the whole array satisfies
the resonance equation for every vertex.

**Proof.** Each component is handled independently.
By Lemma&nbsp;2 the assignment chosen for the component is valid for all its
vertices. Since components are vertex‑disjoint, the property holds for every
vertex of the graph. ∎



##### Lemma 5  
If a valid assignment exists, the algorithm never prints `NO`.

**Proof.** Any valid assignment must, by the reasoning of Section&nbsp;1,
assign opposite multipliers to the ends of every edge, i.e. it is a proper
2‑colouring of the graph. Therefore the graph is bipartite. BFS on a bipartite
graph never encounters a conflict, so the algorithm does not abort with `NO`. ∎



##### Lemma 6  
If the algorithm prints `NO`, no valid assignment exists.

**Proof.** `NO` is printed only when BFS discovers an edge whose ends already
have the same colour, i.e. the graph contains an odd cycle and is not bipartite.
As shown in Section&nbsp;1 any valid assignment would induce a proper 2‑colouring,
which is impossible for a non‑bipartite graph. Hence no assignment exists. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff the required tuning is impossible;  
* otherwise `YES` and the lexicographically smallest feasible multiplier
  sequence.

**Proof.**  
*If the algorithm prints `NO`* – by Lemma&nbsp;6 no solution exists.  

*If the algorithm prints `YES`* – by Lemma&nbsp;5 a solution exists,
  Lemma&nbsp;4 guarantees the printed sequence is feasible,
  and Lemma&nbsp;3 guarantees that for each component the locally minimal
  choice is taken. Since components are ordered by their smallest vertex,
  the concatenation is globally lexicographically minimal. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Building adjacency list*: `O(n + m)`  
*BFS over all vertices*: each vertex and edge processed once → `O(n + m)`  
*Memory*: adjacency list `O(n + m)`, colour & answer arrays `O(n)`.

Both limits satisfy the constraints (`n, m ≤ 2·10⁵`).

#### 7.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # 0 / 1
    ans = [0] * (n + 1)

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        while q:
            x = q.popleft()
            cx = colour[x]
            for y in adj[x]:
                if colour[y] == -1:
                    colour[y] = cx ^ 1
                    q.append(y)
                    comp.append(y)
                elif colour[y] == cx:
                    print("NO")
                    return
        # decide mapping for lexicographically smallest
        min_v = min(comp)
        if colour[min_v] == 0:
            # colour 0 -> p=1
            for v in comp:
                ans[v] = 1 if colour[v] == 0 else 2
        else:
            # swap
            for v in comp:
                ans[v] = 2 if colour[v] == 0 else 1

    # output
    out = ["YES", " ".join(str(ans[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

to the required input‑output format.
