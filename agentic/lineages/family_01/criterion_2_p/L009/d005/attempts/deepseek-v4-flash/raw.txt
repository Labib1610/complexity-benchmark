We can model this as a graph problem: each fixture is a node, and each sensor is an edge that requires its two endpoints to be in different circuits. This is exactly checking if the graph is bipartite. If it is, we also need the lexicographically smallest assignment.

To get the lexicographically smallest assignment, we can run a BFS/DFS that prefers assigning circuit `1` to nodes, and when we encounter an unvisited node, we assign `1` and propagate.  
If a conflict occurs, the graph is not bipartite → output `NO`.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 0
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
