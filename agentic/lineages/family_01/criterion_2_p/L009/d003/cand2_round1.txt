# Problem B — Factory Tuning

Time limit: 1 s   Memory limit: 256 MB

A manufacturing facility is upgrading its infrastructure. The facility floor is mapped out as a grid containing precisely 400 rows and 500 columns of designated installation bays. The facility operates a network of $n$ machines, where $n$ is at least 1 and can be at most the total number of installation bays on the floor.

Each machine in the network must be calibrated to a specific operational tier. The available hardware only supports tier 1 and tier 2. 

The machines are interconnected by $m$ diagnostic connections. The diagnostic routing system supports up to one connection per installation bay, meaning the number of connections $m$ starts from 0 and its maximum possible value is also equal to the total number of bays in the grid.

An automated safety module evaluates every diagnostic connection. For a connection between two machines operating at tiers $x$ and $y$, the safety module will only approve the connection if the definite integral $\int_{0}^{1} z^{x+y} \, dz$ evaluates to exactly $0.25$. 

Your task is to calibrate every machine to a valid operational tier such that the safety module approves all $m$ diagnostic connections simultaneously.

## Input
The first line provides the two integers $n$ and $m$, bound by the facility's physical limits described above.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ — representing a diagnostic connection between machine $u$ and machine $v$.

## Output
If it is impossible to calibrate the machines to satisfy all connections, output a single line containing `NO`.
If a valid calibration is possible, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$) representing the assigned tiers. If there are multiple valid ways to assign the tiers, you must output the sequence that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
