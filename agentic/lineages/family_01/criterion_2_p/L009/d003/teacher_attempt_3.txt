# Problem B — Resonance Tuning

Time limit: 1 s   Memory limit: 256 MB

An acoustic levitation array consists of $n$ resonators. Each resonator must be configured to operate in one of two discrete states, represented by the integer values 1 and 2.

The array includes $m$ acoustic bridges. Each bridge connects a specific pair of resonators. To prevent structural damage from constructive interference, every bridge must be stabilized. A bridge connecting two resonators is considered stable if and only if the sum of their assigned state values is exactly 3.

You need to determine if there is a valid state assignment for all $n$ resonators that stabilizes every acoustic bridge in the array, or report that no such configuration is possible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a pair of resonators connected by an acoustic bridge.

## Output
If no valid state assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $s_1, \dots, s_n$ (each $s_i \in \{1, 2\}$), where $s_i$ is the state value assigned to resonator $i$. If there are multiple valid assignments, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
