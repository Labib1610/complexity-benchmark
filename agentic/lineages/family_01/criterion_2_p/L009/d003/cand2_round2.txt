<STATEMENT>
# Problem B — Signal Synchronization

Time limit: 1 s   Memory limit: 256 MB

A communications facility requires each of its $n$ transmitters to be configured with a signal delay of either 1 or 2. 

The facility has $m$ interference links between specific pairs of transmitters. When a transmitter is configured with a delay of $x$, it broadcasts continuously during the open time interval $(x, x+1)$. A diagnostic controller monitors the network and will only accept an interference link if the broadcast intervals of the two connected transmitters are completely disjoint (their intersection is empty).

You must assign a delay to every transmitter such that all $m$ interference links are accepted by the controller.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of transmitters connected by an interference link.

## Output
If no valid assignment of delays exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the algebraic equation `3xy = 2(x+y)` with a temporal constraint where signal intervals `(x, x+1)` must not overlap. This forces the model to deduce that the only way to avoid overlap with choices $x \in \{1,2\}$ is to assign strictly different delays to connected nodes, preventing simple algebraic pattern-matching while keeping the underlying structure intact.
</RATIONALE>
<PRESERVED_ANSWER>
Since the available delays are only 1 and 2, the open intervals (1, 2) and (2, 3) are disjoint, whereas identical assignments produce perfectly overlapping intervals; thus the condition remains exactly $x \neq y$, preserving all valid assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring (and choosing the lexicographically smallest component orientations), which is solvable in linear time using BFS/DFS, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the open interval notation `(x, x+1)` as a closed interval and worry about boundary overlap, though the explicit definition "open time interval" mathematically prevents this.
</RISK>
