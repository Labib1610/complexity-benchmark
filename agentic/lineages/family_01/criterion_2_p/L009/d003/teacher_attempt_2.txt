# Problem B — Telemetry Tiers

Time limit: 1 s   Memory limit: 256 MB

An experimental fusion reactor monitors a set of telemetry streams. To avoid data saturation, every stream must be assigned to one of two processing tiers: tier 1 or tier 2. 

The reactor's diagnostic log identifies interference events. Each event specifies two streams that will cause a system fault if they operate in the same tier. Thus, the two streams mentioned in any interference event must be assigned to different tiers.

The reactor's data bus has exactly two hundred thousand processing slots, meaning the number of active telemetry streams $n$ can be anywhere from 1 up to this slot limit. The log buffer can hold up to an identical number of interference events, meaning $m$ can range from an empty log (0) up to the slot limit. Streams are identified by integer IDs from 1 to $n$.

You need to determine if there is a valid tier assignment for all $n$ streams that resolves all interference events, or report that no such configuration is possible.

## Input
The first line contains the hardware footprint: the integer count of telemetry streams $n$ and the integer count of interference events $m$.
Each of the subsequent $m$ lines contains two integers $u$ and $v$, representing the IDs of two streams involved in an interference event.

## Output
If no valid tier assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $c_1, \dots, c_n$ (each $c_i \in \{1, 2\}$), where $c_i$ is the tier assigned to stream $i$. If there are multiple valid assignments, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
