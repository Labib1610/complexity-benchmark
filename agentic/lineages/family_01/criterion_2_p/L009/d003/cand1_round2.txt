# Problem B — Factory Tuning

Time limit: 1 s   Memory limit: 256 MB

The factory requires each of its $n$ machines to be set to a power mode of either 1 or 2. There are $m$ interference links between specific pairs of machines. A legacy controller accepts a link only when the $2 \times 2$ matrix $\begin{pmatrix} x & 1 \\ 1 & y \end{pmatrix}$, where $x$ and $y$ are the modes of the two connected machines, is invertible and its inverse matrix consists entirely of integers. You must assign a power mode to every machine such that all $m$ links are accepted by the controller.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a linked pair of machines.

## Output
If no valid assignment of modes exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The previous LLMs solved the problem by instantly recognizing that the equation $3xy = 2(x+y)$ over $\{1,2\}$ is only satisfied when $x \neq y$, reducing it directly to bipartite coloring. To prevent this immediate pattern matching while strictly preserving the problem's mathematical reality and avoiding any extra graph mechanics, I replaced the equation with a linear algebra condition: the local matrix formed by the two modes must have an integer inverse. This evaluates to exactly the same truth table but forces the models to reason about matrix determinants and inverses rather than simple polynomial evaluation, disrupting their graph-theory templates.
</RATIONALE>
<PRESERVED_ANSWER>
The matrix is invertible with an integer inverse if and only if its determinant $xy-1$ is $\pm 1$, which for $x,y \in \{1,2\}$ only occurs when one mode is 1 and the other is 2, perfectly preserving the original $x \neq y$ constraint for every link.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in $O(n+m)$ time using Breadth-First Search, keeping it in P.
</PRESERVED_CLASS>
<RISK>
The most likely risk is that models might incorrectly assume the matrix condition implies a global matrix property rather than a local one, but the text explicitly states "A legacy controller accepts a link only when the 2x2 matrix... is invertible", localizing it unambiguously to the edge.
</RISK>
