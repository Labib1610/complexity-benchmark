<METHOD_NAME>Polynomial Constraint Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit relational constraint (u != v) with a Diophantine-style polynomial equation over a restricted domain (Eu^3 + Ev^3 = 9 for E in {1, 2}). This forces models to algebraically deduce that the values must be distinct before they can recognize the underlying bipartite graph structure.</METHOD_DESCRIPTION>

<STATEMENT>
# Quantum Resonance Calibration

Time limit: 1 s   Memory limit: 256 MB

A quantum computing facility is calibrating $n$ optical resonators. Each resonator $i$ must be tuned to an energy state $E_i$, which must be strictly assigned a value of either `1` or `2`.

The facility has identified $m$ interference constraints between specific pairs of resonators. To prevent harmonic destabilization, any two resonators $u$ and $v$ that share an interference constraint must have their energy states configured such that the sum of the cubes of their states is exactly 9 (i.e., $E_u^3 + E_v^3 = 9$).

If there is no way to tune all $n$ resonators to satisfy this requirement for every constraint, the calibration must be aborted. When multiple valid configurations exist, the safety protocol mandates selecting the sequence of energy states (ordered from resonator 1 to $n$) that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of resonators and the number of interference constraints.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — a pair of resonators that share an interference constraint.

## Output
If no valid configuration can be found, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $E_1 \dots E_n$ (each either `1` or `2`), denoting the energy states for resonators 1 through $n$. This sequence must be the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit instruction that one tier must be strictly greater than the other has been replaced with the polynomial constraint $E_u^3 + E_v^3 = 9$. Because the domain is restricted to $\{1, 2\}$, the only valid pairs are $(1, 2)$ and $(2, 1)$, making this mathematically identical to requiring distinct values. Models must now algebraically verify this equivalence before they can recognize the problem as checking bipartiteness.
</RATIONALE>
<PRESERVED_ANSWER>
Since $1^3 + 2^3 = 9$ and $2^3 + 1^3 = 9$ (while $1^3 + 1^3 = 2$ and $2^3 + 2^3 = 16$), the equation stringently enforces that connected resonators have different states, perfectly mirroring the original "strictly greater" logic and producing the exact same lexicographically optimal sequences.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) on an undirected graph, solvable in $O(n+m)$ using BFS or DFS.
</PRESERVED_CLASS>
