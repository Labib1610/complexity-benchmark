<METHOD_DESCRIPTION>Replaces the explicit "strictly greater than" or "not equal" 2-coloring constraint with a requirement that a specific 2x2 matrix constructed from the two assigned values has a determinant of zero. Since the allowed values are constrained to the roots of t^2 - 3t + 2 = 0 (which are 1 and 2), the determinant condition t_u * t_v - 2 = 0 strictly enforces that one value is 1 and the other is 2. # Tiered Settlement Obligations

Time limit: 1 s   Memory limit: 256 MB

A financial clearinghouse is migrating $n$ institutional accounts to a new regulatory framework. The clearinghouse's mainframe allocates memory for a maximum of two hundred thousand institutional accounts, and requires at least one account to initialize. The transaction log can record up to two hundred thousand reciprocal obligations, though it is possible for the log to be completely empty.

Under this framework, each account $i$ must be assigned a compliance tier $t_i$. To ensure compatibility with legacy systems, $t_i$ must be a positive integer that satisfies the characteristic equation $t_i^2 - 3t_i + 2 = 0$.

The clearinghouse has identified $m$ reciprocal obligations between specific pairs of accounts. To satisfy risk-margin requirements, any two accounts $u$ and $v$ involved in a reciprocal obligation must form a stable margin pair. A pair is considered stable if and only if the matrix 
$$ \begin{pmatrix} t_u & 1 \\ 2 & t_v \end{pmatrix} $$
is singular (meaning its determinant is exactly zero).

If there is no way to assign tiers to all $n$ accounts such that every reciprocal obligation forms a stable margin pair, the migration must be halted. When multiple valid tier assignments are possible, the compliance protocol mandates selecting the sequence of tier designations (ordered from account 1 to $n$) that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$, representing the number of accounts and the number of reciprocal obligations, respectively.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — a pair of accounts that share a reciprocal obligation.

## Output
If no valid tier assignment can be found, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $t_1 \dots t_n$ denoting the compliance tier sequence for accounts 1 through $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit bounds were removed and replaced with physical system limits (Strategy S07), forcing the model to extract the $200,000$ bound from the text. The core 2-coloring constraint was completely obfuscated using a novel algebraic method: restricting values to the roots of $t^2 - 3t + 2 = 0$ (yielding exactly 1 and 2) and requiring a matrix determinant to be zero ($t_u t_v - 2 = 0$). This forces the model to mathematically deduce that the interacting variables must be strictly unequal, bypassing superficial graph-coloring pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The characteristic equation restricts valid tiers strictly to 1 and 2, and the matrix singularity condition strictly requires $t_u t_v = 2$, which is mathematically only possible if one tier is 1 and the other is 2, perfectly preserving the original inequality requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of an undirected graph, which is solvable in $O(n+m)$ time using Breadth-First Search.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the characteristic equation as allowing non-integer roots if they ignore the "positive integer" constraint, but the wording explicitly restricts valid $t_i$ to positive integers.
</RISK>
