Permutation Group Obfuscation
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces a combinatorial parity condition with a condition based on the composition of two transpositions in the symmetric group S3. Because transpositions are their own inverses, applying the same tier twice maps the target element back to itself (invalid), whereas applying two different tiers maps it elsewhere (valid). This forces models to trace the state machine of the transformations rather than relying on surface-level parity or odd/even keywords to guess bipartiteness.
</METHOD_DESCRIPTION>

yes
</METHOD_NOVEL>
<STATEMENT>
# Tiered Settlement Obligations

Time limit: 1 s   Memory limit: 256 MB

A financial clearinghouse is migrating $n$ institutional accounts to a new regulatory framework. Under this framework, each account must be assigned a compliance tier, strictly designated as either `1` or `2`.

Each tier defines a specific bijective transformation over three virtual ledgers ($A$, $B$, and $C$) used during audits:
- Tier `1` applies the transformation $f_1$, where $f_1(A)=B$, $f_1(B)=A$, and $f_1(C)=C$.
- Tier `2` applies the transformation $f_2$, where $f_2(A)=A$, $f_2(B)=C$, and $f_2(C)=B$.

The clearinghouse has identified $m$ reciprocal obligations between specific pairs of accounts. To satisfy risk-margin requirements, any two accounts $u$ and $v$ involved in a reciprocal obligation (assigned tiers $t_u$ and $t_v$) must form a valid joint supervisory committee. 

The rule for a valid committee is that applying their tier transformations in sequence to Ledger $C$ must not map the audit trace back to Ledger $C$. That is, the assignment must satisfy $f_{t_v}(f_{t_u}(C)) \neq C$. (Due to the symmetric properties of these specific transformations, $f_{t_v}(f_{t_u}(C)) \neq C$ is true if and only if $f_{t_u}(f_{t_v}(C)) \neq C$, so the order in which the accounts are evaluated does not matter).

If there is no way to assign tiers to all $n$ accounts such that every reciprocal obligation satisfies this transformation rule, the migration must be halted. When multiple valid tier assignments are possible, the compliance protocol mandates selecting the sequence of tier designations (ordered from account 1 to $n$) that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of accounts and the number of reciprocal obligations.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — a pair of accounts that share a reciprocal obligation.

## Output
If no valid tier assignment can be found, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (each either `1` or `2`), denoting the compliance tier for accounts 1 through $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the combinatorial parity rule with a condition based on the composition of two transpositions in the symmetric group S3. Models can no longer rely on keywords like "odd" or "combinations" to shortcut to bipartiteness; they must now genuinely evaluate the state machine of the transformations to deduce that the condition requires $t_u \neq t_v$.
</RATIONALE>
<PRESERVED_ANSWER>
The transformation condition $f_{t_v}(f_{t_u}(C)) \neq C$ evaluates to false when $t_u = t_v$ (because $f_1 \circ f_1$ and $f_2 \circ f_2$ both map $C$ to $C$) and evaluates to true when $t_u \neq t_v$, which exactly matches the $t_u \neq t_v$ validity condition of the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains logically equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in $O(n+m)$ time using Breadth-First Search, keeping it firmly in P.
</PRESERVED_CLASS>
