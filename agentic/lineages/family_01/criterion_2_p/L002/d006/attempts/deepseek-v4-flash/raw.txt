We can model this as a graph problem. The committee rule with tiers 1 and 2:  

- The sequence consists of exactly `t_u` primary audits and `t_v` secondary audits.  
- No two adjacent audits of same type, and the number of distinct arrangements must be exactly 1.  
That forces the two tiers to be different — otherwise with equal numbers or both same, we'd get more than 1 arrangement or invalid pattern.  

So for each edge `(u, v)`, exactly one must be tier 1 and the other tier 2, meaning the graph must be bipartite.  

If the graph is not bipartite → `NO`.  
If it is bipartite, to get lexicographically smallest assignment, we try to assign tier 1 to smallest index node possible, and propagate using BFS/DFS coloring.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    adj[u-1].append(v-1)
    adj[v-1].append(u-1)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1  # start with tier 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]  # 1 -> 2, 2 -> 1
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
