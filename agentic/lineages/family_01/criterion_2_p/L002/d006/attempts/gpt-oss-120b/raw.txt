**Solution Explanation**

For an edge `{u , v}` we have to put `t_u` letters `A` (primary audits) and
`t_v` letters `B` (secondary audits) in a line, no two equal letters may be
adjacent.
The number of such lines is

* `0` if `|t_u‑t_v| > 1`   (impossible)
* `2` if `t_u = t_v`       (both `ABAB…` and `BABA…`)
* `1` if `|t_u‑t_v| = 1`   (the majority letter must be at both ends)

The required number is exactly `1`, therefore for every edge we must have  

```
|t_u – t_v| = 1      ⇔      {t_u , t_v} = {1 , 2}
```

So adjacent vertices must receive **different** tiers.
The whole problem is reduced to:

*Is the given graph bipartite?*  
If yes, output the lexicographically smallest 2‑colouring with colours
`1` and `2`.

--------------------------------------------------------------------

#### 1.   Bipartite check and component handling  

We run a BFS/DFS over every not yet visited vertex.

* `col[v] = 0` or `1` – provisional colour.
* While traversing an edge `(v , to)` we require `col[to] = 1‑col[v]`.
  If a neighbour already has the same colour → the graph is **not**
  bipartite → answer `NO`.

All vertices reached in one BFS belong to the same connected component.
For each component we store its vertices in a list `comp`.

--------------------------------------------------------------------

#### 2.   Lexicographically smallest colouring  

Inside a component there are exactly two possible colourings
(the two are each other’s complement).
Let  

```
m = smallest vertex index inside the component
c = col[m]          (0 or 1)
```

If `c = 0` we keep the colours as they are,
otherwise we flip all colours of this component.
After the possible flip the vertex `m` gets colour `0`,
which we finally output as tier `1`
(`tier = colour + 1`).

Why is this optimal?
The first position where two global colourings can differ is the smallest
index of a component that is not fixed yet.
Choosing colour `1` for that position is strictly better than colour `2`,
and the decision for a component never influences earlier indices
(because components are disjoint).  
Thus the rule “make the smallest index of the component colour 1”
produces the lexicographically smallest overall assignment.

--------------------------------------------------------------------

#### 3.   Algorithm
```
read n, m
build adjacency list
col[1…n] = -1
answer[1…n] = 0

for v = 1 … n:
    if col[v] == -1:
        start BFS from v, set col[v] = 0
        comp = []                     # vertices of this component
        while queue not empty:
            x = pop
            comp.append(x)
            for y in adj[x]:
                if col[y] == -1:
                    col[y] = 1 - col[x]
                    push y
                elif col[y] == col[x]:
                    print "NO" and exit
        m = min(comp)
        flip = col[m]                  # 0 → no flip, 1 → flip
        for x in comp:
            final_colour = col[x] ^ flip
            answer[x] = final_colour + 1   # 0→1 , 1→2

print "YES"
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise prints the lexicographically smallest valid assignment.

---

##### Lemma 1  
For an edge `{u,v}` the number of admissible audit sequences equals `1`
iff `{t_u , t_v} = {1,2}`.

**Proof.**  
The sequence must contain `t_u` letters `A` and `t_v` letters `B`,
no equal neighbours.
A necessary and sufficient condition for existence is `|t_u‑t_v| ≤ 1`.
If `|t_u‑t_v| = 0` (both `1`) there are two alternating sequences,
otherwise (`|t_u‑t_v| = 1`) the majority letter must be at both ends,
hence the sequence is unique. ∎



##### Lemma 2  
A tier assignment satisfies the statement of the problem
iff it is a proper 2‑colouring of the graph (adjacent vertices receive
different tiers).

**Proof.**  
By Lemma&nbsp;1 an edge is satisfied exactly when its endpoints have tiers
`1` and `2` in some order, i.e. different tiers.
Thus all edges are satisfied ⇔ every edge connects vertices of different
tiers ⇔ the assignment is a proper 2‑colouring. ∎



##### Lemma 3  
If the algorithm prints `NO` then the graph is not bipartite,
hence no valid assignment exists.

**Proof.**  
`NO` is printed only when during BFS an edge `(x,y)` with `col[x]=col[y]`
is found. This is precisely a violation of bipartiteness.
If a graph is not bipartite it has no proper 2‑colouring,
and by Lemma&nbsp;2 no valid tier assignment exists. ∎



##### Lemma 4  
If the algorithm finishes without conflict, the produced array `answer`
is a proper 2‑colouring.

**Proof.**  
During BFS each newly visited vertex receives the opposite colour of the
vertex it is reached from, therefore for every traversed edge the two
endpoints have opposite provisional colours.
The possible final flip is applied uniformly to the whole component,
so opposite colours stay opposite.
Thus every edge connects vertices with different final colours,
i.e. a proper 2‑colouring. ∎



##### Lemma 5  
For each connected component the algorithm chooses the orientation that
gives the smallest possible tier at the smallest index of that component.

**Proof.**  
Let `m` be the smallest index in the component and `c = col[m]`.
If `c = 0` we keep the colours, so `answer[m] = 1`.
If `c = 1` we flip, turning colour `1` into `0`, again `answer[m] = 1`.
No other orientation can give tier `1` at position `m`. ∎



##### Lemma 6  
The whole array `answer` is the lexicographically smallest proper
2‑colouring of the graph.

**Proof.**  
Consider the vertices in increasing order.
The first vertex where two proper colourings can differ belongs to some
component `C`. All vertices with smaller indices lie in components already
processed, and by Lemma&nbsp;5 each of those components already has tier `1`
at its smallest index, which is the minimum possible value.
Hence the first differing position is the smallest index `m` of component
`C`. By Lemma&nbsp;5 our algorithm assigns tier `1` to `m`, while any other
proper colouring must assign tier `2` there (otherwise it would coincide
with our choice on all earlier vertices). Therefore our colouring is
lexicographically smaller than any other proper colouring. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no tier assignment satisfying the problem exists;
* otherwise `YES` and the lexicographically smallest satisfying assignment.

**Proof.**  

*If the algorithm prints `NO`*: by Lemma&nbsp;3 the graph is not bipartite,
hence by Lemma&nbsp;2 no satisfying assignment exists.

*If the algorithm prints `YES`*: it terminated without conflict,
so by Lemma&nbsp;4 the produced `answer` is a proper 2‑colouring,
hence by Lemma&nbsp;2 a satisfying assignment.
By Lemma&nbsp;6 this assignment is lexicographically smallest among all
satisfying assignments.

Thus the output is correct in all cases. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all vertices*: each vertex and edge is processed once →  
`O(n + m)` time, `O(n)` additional memory for colour array and queue.  

Overall  

```
Time   :  O(n + m)   ≤ 4·10⁵ operations
Memory :  O(n + m)   ≤ 4·10⁵ integers
```

Both fit easily into the limits.

#### 6.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    n = next(it)
    m = next(it)

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = next(it); v = next(it)
        adj[u].append(v)
        adj[v].append(u)

    col = [-1] * (n + 1)          # provisional colours 0 / 1
    ans = [0] * (n + 1)           # final tiers 1 / 2

    for start in range(1, n + 1):
        if col[start] != -1:
            continue
        # BFS for this component
        q = deque([start])
        col[start] = 0
        comp = []
        while q:
            v = q.popleft()
            comp.append(v)
            cv = col[v]
            for to in adj[v]:
                if col[to] == -1:
                    col[to] = 1 - cv
                    q.append(to)
                elif col[to] == cv:
                    sys.stdout.write("NO")
                    return
        # decide orientation: smallest index gets tier 1
        m_idx = min(comp)
        flip = col[m_idx]          # 0 -> no flip, 1 -> flip
        for v in comp:
            final_colour = col[v] ^ flip
            ans[v] = final_colour + 1   # 0->1, 1->2

    out = ["YES", " ".join(str(ans[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
