# Tiered Settlement Obligations

Time limit: 1 s   Memory limit: 256 MB

A financial clearinghouse is migrating $n$ institutional accounts to a new regulatory framework. Under this framework, each account $i$ must be assigned a compliance tier $t_i$, strictly designated as either `1` or `2`.

The clearinghouse has identified $m$ reciprocal obligations between specific pairs of accounts. To satisfy risk-margin requirements, any two accounts $u$ and $v$ involved in a reciprocal obligation must be assigned tiers $t_u$ and $t_v$ such that they can form a valid joint supervisory committee. 

The validity of the committee is determined by a compliance metric $C(x, y) = P(x, y) + Q(x, y)$. The state functions $P$ and $Q$ are evaluated for all integers $x$ and $y$ as follows:
- Base constraints: If $x < 0$ or $y < 0$, then $P(x, y) = 0$ and $Q(x, y) = 0$.
- For all $x \ge 0$ and $y \ge 0$:
  - $P(x, y) = 1$ if $x = 1$ and $y = 0$, otherwise $P(x, y) = Q(x-1, y)$.
  - $Q(x, y) = 1$ if $x = 0$ and $y = 1$, otherwise $Q(x, y) = P(x, y-1)$.

To ensure definitive accountability, the metric evaluated at the accounts' tiers, $C(t_u, t_v)$, must equal exactly 1. (Note that this metric evaluates symmetrically with respect to $u$ and $v$).

If there is no way to assign tiers to all $n$ accounts such that every reciprocal obligation satisfies this committee rule, the migration must be halted. When multiple valid tier assignments are possible, the compliance protocol mandates selecting the sequence of tier designations (ordered from account 1 to $n$) that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of accounts and the number of reciprocal obligations.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — a pair of accounts that share a reciprocal obligation.

## Output
If no valid tier assignment can be found, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $t_1 \dots t_n$ (each either `1` or `2`), denoting the compliance tier for accounts 1 through $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I removed the direct description of arranging primary and secondary audits such that no two of the same type are adjacent. In its place, I introduced an abstract mutual recurrence $C(x, y)$ that mathematically computes the exact same sequence count without any combinatorial phrasing. Models can no longer rely on NLP pattern-matching to identify this as a bipartiteness check; they must now explicitly evaluate the recurrence for the possible inputs (1 and 2) to deduce that $C(t_u, t_v) = 1 \iff t_u \neq t_v$.
</RATIONALE>
<PRESERVED_ANSWER>
The recurrence exactly mimics the number of valid alternating sequences: evaluating it for the domain {1, 2} yields C(1,1)=2, C(1,2)=1, C(2,1)=1, and C(2,2)=2, meaning the constraint C(t_u, t_v) = 1 is satisfied if and only if t_u != t_v, perfectly preserving the original edge validity condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains fundamentally about finding a valid 2-coloring of an undirected graph and choosing the lexicographically smallest valid assignment, which is solvable in O(n + m) time using Breadth-First Search (BFS) and belongs to P.
</PRESERVED_CLASS>
