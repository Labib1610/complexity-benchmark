We can model this as a bipartite graph problem: each nurse is a node, and each forbidden pair is an edge. We need to 2-color the graph (assign shifts 1 and 2) such that no edge connects two nodes of the same color. If the graph is not bipartite, output `NO`. Otherwise, we need the lexicographically smallest assignment.

To get the lexicographically smallest assignment, we process nodes in order from 1 to n, and when we encounter an uncolored node, we start a BFS/DFS from it, assigning it color 1 (shift 1) and alternating colors. This ensures that earlier nodes get the smallest possible shift.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    for start in range(n):
        if color[start] == -1:
            color[start] = 1
            q = deque([start])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = 1 - color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        print("NO")
                        return
    
    print("YES")
    print(' '.join(str(c + 1) for c in color))

if __name__ == "__main__":
    solve()
```
