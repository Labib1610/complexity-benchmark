We can model this as a bipartite graph problem: each nurse is a node, and each forbidden pair is an edge. We need to 2-color the graph (assign shifts 1 and 2) such that no edge connects two nodes of the same color. If the graph is not bipartite, output `NO`. Otherwise, we need the lexicographically smallest assignment.

To get the lexicographically smallest assignment, we should try to assign shift 1 to as many early-indexed nurses as possible, but we must respect the bipartite constraints. A standard BFS/DFS coloring can be adapted: when we encounter an uncolored node, we try to color it with 1 if possible, but if that leads to a conflict, we must use 2.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start):
    q = deque([start])
    color[start] = 1
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 3 - color[u]  # alternate
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        if not bfs(i):
            print("NO")
            sys.exit()

# Now we have a valid coloring, but we want lexicographically smallest.
# We can try to flip colors in each connected component if it makes earlier nodes smaller.
# Since BFS above already starts with 1, we just need to check if flipping a component
# gives a lexicographically smaller result.

visited = [False] * n
for i in range(n):
    if not visited[i]:
        # collect component
        comp = []
        q = deque([i])
        visited[i] = True
        while q:
            u = q.popleft()
            comp.append(u)
            for v in adj[u]:
                if not visited[v]:
                    visited[v] = True
                    q.append(v)
        # Try flipping this component
        # Compare current vs flipped
        current = [color[u] for u in comp]
        flipped = [3 - color[u] for u in comp]
        # We want lexicographically smallest overall assignment.
        # Since comp is in increasing order of index (because we iterate i from 0..n-1),
        # we can decide per component.
        # If flipping makes the first differing index smaller, flip.
        for a, b in zip(current, flipped):
            if a < b:
                break
            elif b < a:
                for u in comp:
                    color[u] = 3 - color[u]
                break

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
