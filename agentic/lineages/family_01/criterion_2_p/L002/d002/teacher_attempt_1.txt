<STATEMENT>
# Problem B — Catalyst Assignment

Time limit: 1 s   Memory limit: 256 MB

A manufacturing process treats $n$ raw materials, numbered 1 to $n$. Each material $i$ must be assigned a catalyst index $s_i$, which can only be chosen as 1 or 2.

The process involves $m$ known interactions between specific pairs of materials. For any interacting pair of materials $u$ and $v$, the system will only remain stable if their catalyst indices sum to exactly 3 (that is, $s_u + s_v = 3$).

Determine if it is possible to assign a catalyst index to every material such that all interacting pairs satisfy this stability equation.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that material $u$ and material $v$ interact with each other.

## Output
If there is no assignment of catalyst indices that satisfies all stability conditions, print a single line containing NO.
Otherwise, print YES. On the second line, print $n$ integers $s_1 \dots s_n$ (each being 1 or 2), representing the lexicographically smallest valid sequence of catalyst indices.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the explicit "same solvent" conflict phrasing with an algebraic condition requiring that the assigned values for interacting pairs sum to exactly 3. Since the available values are 1 and 2, this is mathematically equivalent to requiring them to be different, but it removes the semantic triggers for graph bipartition and forces the model to deduce the inequality structurally.
</RATIONALE>
<PRESERVED_ANSWER>
The constraint $s_u + s_v = 3$ with $s_i \in \{1, 2\}$ is satisfied if and only if $s_u \neq s_v$, making the valid assignments exactly identical to those in the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains structurally equivalent to 2-coloring (or bipartiteness testing), solvable in $O(n+m)$ time using BFS or DFS.
</PRESERVED_CLASS>
