# Problem B — Sensor Frequency Allocation

Time limit: 1 s   Memory limit: 256 MB

A smart factory has $n$ wireless sensors. To operate correctly, every sensor must be assigned exactly one frequency band, chosen from the available options: band 1 and band 2.

The physical layout of the factory means certain sensors are placed too close to one another. Specifically, there are $m$ known pairs of sensors that will experience signal interference if they are configured to use the identical frequency band. To guarantee uninterrupted data transmission, you must ensure that for each of these $m$ pairs, the two sensors are given distinct band assignments.

Your task is to determine whether it is possible to assign a frequency band to every sensor without causing any interference. If several valid assignments exist, you must find the one that produces the lexicographically smallest sequence of assignments $s_1, s_2, \dots, s_n$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$, indicating a pair of sensors that will interfere if they share a band.

## Output
If it is impossible to configure the sensors without interference, output a single line containing NO.
Otherwise, output YES on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$) representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Removed the explicit equation $s_u + s_v = 3$ which allowed models to pattern-match the condition to parity/bipartite coloring without analyzing the scenario. Replaced it with the logical equivalent: pairs must have distinct assignments chosen from the set {1, 2}. Models must now logically deduce that this forces alternating states across the interference pairs.
</RATIONALE>
<PRESERVED_ANSWER>
Requiring two variables from the set {1, 2} to be distinct is mathematically identical to requiring that their sum is exactly 3, so all valid assignments remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring of a graph (or testing bipartiteness) and selecting the lexicographically smallest coloring, which is solvable in linear time using BFS/DFS.
</PRESERVED_CLASS>
