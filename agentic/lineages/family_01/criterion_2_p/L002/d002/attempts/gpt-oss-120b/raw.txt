**Solution Explanation**

For every pair `(u , v)` the two sensors must use different frequencies.
Thus the graph formed by the `m` pairs has to be *bipartite*.
If it is bipartite, each connected component has exactly two possible
2‑colourings – they differ only by swapping the two colours.

The required output is the lexicographically smallest sequence  
` s1 s2 … sn ` (each `1` or `2`).  
Lexicographic order compares the positions from left to right, therefore
the first position where two possible answers differ decides which one is
smaller.

--------------------------------------------------------------------

#### Observation  

Components are independent – there are no edges between different
components.  
Consequently the choice of orientation (which colour is called “1”) can be
made **independently for each component**.

Inside one component let `c(v) ∈ {0,1}` be the colour obtained by a normal
bipartite BFS (starting colour `0`).  
If we keep this orientation, the final frequencies are

```
freq(v) = 1  if c(v)=0
freq(v) = 2  if c(v)=1
```

If we flip the orientation, all colours are inverted:

```
freq(v) = 1  if c(v)=1
freq(v) = 2  if c(v)=0
```

The first vertex of the component (the smallest index inside it) is the
first place where the two possible answers can differ.
To obtain the lexicographically smallest whole sequence we simply make
this vertex receive frequency `1`.  
That is: **choose the orientation so that the smallest‑index vertex of the
component gets colour `0`** (i.e. frequency 1).  
If its BFS colour already is `0` we keep the orientation,
otherwise we flip it.

--------------------------------------------------------------------

#### Algorithm
```
read n, m
build adjacency list

color[1…n] = -1          # -1 = unvisited, otherwise 0/1
answer[1…n] = 0

for v = 1 … n:
    if color[v] == -1:
        # start a new component
        bfs from v, assigning colours 0/1
        if a conflict (edge with equal colours) appears → print NO
        collect all vertices of this component in list comp
        minv = minimum vertex in comp
        flip = (color[minv] == 1)          # need to invert?
        for each x in comp:
            final = (color[x] ^ flip)      # 0 → 1, 1 → 2
            answer[x] = 1 if final == 0 else 2

print YES
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints “NO” iff no valid configuration exists,
and otherwise prints the lexicographically smallest valid configuration.

---

##### Lemma 1  
During BFS each visited vertex receives a colour `0` or `1` such that
every processed edge connects vertices of opposite colours.
If a conflict is detected, the graph is not bipartite.

**Proof.**  
BFS starts with colour `0`. Whenever we traverse an edge `u‑v`,
if `v` is uncoloured we set `color[v]=color[u]⊕1`, guaranteeing opposite
colours. If `v` is already coloured and `color[v]==color[u]`,
the edge connects equal colours, which is impossible in a bipartite
graph. ∎



##### Lemma 2  
If BFS finishes a component without conflict, the component is bipartite
and the obtained colours are a valid 2‑colouring (up to swapping the two
colours).

**Proof.**  
By Lemma&nbsp;1 all edges of the component connect opposite colours, therefore
the component is bipartite. Any other 2‑colouring of the same component can
only differ by swapping the two colour classes, because the colour of a
vertex is forced by the parity of the path length from the start vertex. ∎



##### Lemma 3  
For a bipartite component, the algorithm chooses the orientation that gives
frequency 1 to the smallest‑index vertex of the component.

**Proof.**  
Let `minv` be that vertex. After BFS its colour is `c = color[minv] ∈ {0,1}`.
If `c = 0` the algorithm sets `flip = False` and keeps the orientation,
so `minv` receives frequency 1.  
If `c = 1` the algorithm sets `flip = True`; all colours are inverted,
hence `minv` now has colour `0` and receives frequency 1. ∎



##### Lemma 4  
The sequence produced by the algorithm is lexicographically minimal among
all valid configurations.

**Proof.**  
Consider the vertices in increasing order.
Whenever the first vertex of a component appears, all earlier vertices
belong to already processed components and their frequencies are already
fixed to the smallest possible values (by induction on the order).
By Lemma&nbsp;3 the current component is oriented so that its smallest vertex
gets frequency 1, which is the smallest value any valid configuration can
assign to that position. Therefore no other valid overall assignment can be
lexicographically smaller. ∎



##### Lemma 5  
If the algorithm outputs “NO”, no valid configuration exists.

**Proof.**  
“NO” is printed only when BFS finds an edge whose endpoints have equal
colours, i.e. an odd cycle. Any assignment of two frequencies would give the
same frequency to both ends of that edge, violating the requirement.
Hence the graph is not bipartite and no configuration exists. ∎



##### Lemma 6  
If the algorithm outputs “YES”, the printed assignment satisfies all
constraints.

**Proof.**  
All components were processed without conflict, therefore each is bipartite
(Lemma&nbsp;2). The final frequencies are obtained from the BFS colours by
possibly flipping the whole component, which still keeps opposite colours on
every edge. Thus every interfering pair receives different frequencies. ∎



##### Theorem  
The algorithm is correct.

**Proof.**  
- If it prints “NO”, by Lemma&nbsp;5 no solution exists.
- If it prints “YES”, by Lemma&nbsp;6 the assignment is valid, and by
  Lemma&nbsp;4 it is the lexicographically smallest among all valid
  assignments.

Thus the algorithm fulfills the specification. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

Each vertex and each edge is processed once in BFS.

```
Time   :  O(n + m)   ≤ 4·10⁵ operations
Memory :  O(n + m)   adjacency list + arrays
```

Both limits satisfy the problem constraints.

--------------------------------------------------------------------

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * (n + 1)          # 0 / 1 during BFS
    answer = [0] * (n + 1)          # final frequencies 1 / 2

    for start in range(1, n + 1):
        if color[start] != -1:
            continue
        # BFS of a new component
        q = deque([start])
        color[start] = 0
        comp = [start]
        while q:
            u = q.popleft()
            cu = color[u]
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = cu ^ 1
                    q.append(v)
                    comp.append(v)
                elif color[v] == cu:
                    # not bipartite
                    sys.stdout.write("NO")
                    return
        # decide orientation: smallest index gets frequency 1
        minv = min(comp)
        flip = (color[minv] == 1)   # need to invert colours?
        for v in comp:
            final = color[v] ^ flip   # 0 -> freq 1, 1 -> freq 2
            answer[v] = 1 if final == 0 else 2

    out = ["YES"]
    out.append(' '.join(str(answer[i]) for i in range(1, n + 1)))
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
