# Problem B — Component Configuration

Time limit: 1 s   Memory limit: 256 MB

A production system handles a batch of distinct components, numbered consecutively starting from 1. Each component must be configured with exactly one of two operational states: State 1 or State 2.

Testing has revealed specific pairs of components that will trigger an error if they are both set to the same state. You must assign a state to each component such that no such pair shares the same state.

If there is no way to safely configure all components, report impossibility.

The facility has $200,000$ testing bays, meaning the batch size $n$ can be anywhere from a single component up to full capacity. The defect tracking system's database allocates exactly enough rows to store $200,000$ error records, so the number of pairs $m$ ranges from zero up to this database limit.

## Input
The first line contains $n$ and $m$ (the number of components and error pairs, respectively, constrained by the physical capacities described above).
Each of the next $m$ lines contains two integers $u$ and $v$ (valid component identifiers between $1$ and $n$, with $u \ne v$), representing a pair that cannot share a state.

## Output
If no safe configuration exists, print a single line containing NO.
Otherwise, print YES, followed by a second line containing $n$ integers $s_1 \dots s_n$ (each being 1 or 2), representing the lexicographically smallest valid state assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
