# Problem B — Lunar Habitat Modules

Time limit: 1 s   Memory limit: 256 MB

A lunar base consists of $n$ habitat modules, numbered 1 to $n$. Each module must be connected to exactly one of two life-support networks: Network 1 or Network 2.

There are $m$ thermal imbalances identified by the engineers. Each imbalance involves two specific modules. If these two modules draw power from the same network, the network overloads. Therefore, the two modules involved in an imbalance must be connected to different networks.

Determine if it is possible to connect all $n$ modules safely. If it is impossible, report a failure. If it is possible, provide the valid connection plan. If there are multiple valid plans, you must output the one that is lexicographically smallest when the network assignments of modules 1 to $n$ are written as a sequence.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$) — the two modules involved in a thermal imbalance.

## Output
If no safe connection plan exists, print a single line containing NO.
Otherwise, print YES, followed by a second line containing $n$ integers $s_1 \dots s_n$ (each being 1 or 2), representing the lexicographically smallest valid sequence of network assignments.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
