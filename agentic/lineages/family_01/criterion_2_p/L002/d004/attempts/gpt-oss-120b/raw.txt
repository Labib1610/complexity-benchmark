**Solution Explanation**

For every edge `{u , v}` the tiers `t_u , t_v ∈ {1,2}` have to satisfy  

```
x² – (t_u + t_v)·x + 2 = 0          (1)
```

The quadratic has integer roots **iff** its discriminant is a perfect square
and the sum of the roots (`t_u+t_v`) is integer.
The product of the roots equals `2`, therefore the only possible integer
pairs of roots are `(1,2)` and `(-1,-2)`. Their sums are `3` and `-3`.
Since `t_u , t_v` are positive, only the sum `3` can occur, i.e.

```
t_u + t_v = 3                                    (2)
```

Thus every edge must connect a vertex with tier `1` and a vertex with tier `2`.
The whole graph has to be **bipartite** and the two colour classes are exactly
the two tiers.

--------------------------------------------------------------------

#### Lexicographically smallest assignment  

If a component is bipartite there are two possible assignments:
* colour `0` → tier `1`, colour `1` → tier `2`
* colour `0` → tier `2`, colour `1` → tier `1`

To obtain the lexicographically smallest global sequence we process the
vertices in increasing order `1 … n`.  
When we meet the first still uncoloured vertex `v` we start a BFS/DFS from it,
fix its colour to `0` and consequently its tier to `1`.  
All other vertices of this component receive tiers according to this orientation.
Because `v` is the smallest index of the component, any other orientation would
give tier `2` to `v` and would be lexicographically larger.  
Repeating this for every component yields the overall smallest possible sequence.

--------------------------------------------------------------------

#### Algorithm
```
read n, m
build adjacency list
colour[1…n] = -1   // -1 = unvisited, 0/1 = bipartite colour
answer[1…n]

for v = 1 … n
    if colour[v] == -1
        start BFS from v
        set colour[v] = 0
        store all vertices of this component in list comp
        while queue not empty
            pop x
            for each neighbour y of x
                if colour[y] == -1
                    colour[y] = colour[x] ^ 1
                    push y
                else if colour[y] == colour[x]
                    print "NO" and exit   // not bipartite
        // orientation: colour 0 → tier 1, colour 1 → tier 2
        for each u in comp
            answer[u] = 1 if colour[u] == 0 else 2

print "YES"
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise prints `YES` and the lexicographically smallest valid assignment.

---

##### Lemma 1  
For an edge `{u,v}` a tier assignment satisfies condition (1) **iff**
`{t_u , t_v} = {1,2}`.

**Proof.**  
From the discussion above the quadratic has integer roots only when
`t_u + t_v = 3`. With `t_u , t_v ∈ {1,2}` the only way to obtain sum `3` is
`{1,2}`. ∎



##### Lemma 2  
A tier assignment satisfying all edges exists **iff** the graph is bipartite.

**Proof.**  
*If* the graph is bipartite, colour the two parts `0` and `1`. Assign tier `1`
to colour `0` and tier `2` to colour `1`. By Lemma&nbsp;1 every edge connects
different colours, therefore its endpoints have tiers `{1,2}` and the condition
holds.

*Only‑if*: suppose a tier assignment exists. By Lemma&nbsp;1 each edge connects
different tiers, i.e. different values `1` and `2`. Define colour of a vertex as
`0` if its tier is `1`, `1` otherwise. Adjacent vertices have different colours,
hence the graph is bipartite. ∎



##### Lemma 3  
When the algorithm processes a component, fixing the starting vertex `v`
to tier `1` yields the lexicographically smallest tier sequence among all
valid assignments for this component.

**Proof.**  
All valid assignments for the component are exactly the two orientations of its
bipartition (Lemma&nbsp;2). In one orientation `v` receives tier `1`, in the
other tier `2`. Since `v` is the smallest index of the component, any sequence
with tier `2` at position `v` is lexicographically larger than the one with tier
`1`. Thus the orientation chosen by the algorithm is optimal for this component. ∎



##### Lemma 4  
If the algorithm finishes without printing `NO`, the produced sequence is a
valid assignment.

**Proof.**  
During BFS the algorithm checks every edge `{x,y}`. If both ends already have a
colour, equality of colours would mean the edge connects vertices of the same
tier, contradicting Lemma&nbsp;1, so the algorithm would have printed `NO`.  
Hence all edges connect vertices of opposite colours, and after the final
orientation step each edge connects tiers `{1,2}`. By Lemma&nbsp;1 the condition
holds for every edge. ∎



##### Lemma 5  
If a valid assignment exists, the algorithm never prints `NO`.

**Proof.**  
Assume a valid assignment exists. By Lemma&nbsp;2 the graph is bipartite, i.e.
there exists a 2‑colouring with no edge inside a colour class. The BFS performed
by the algorithm discovers exactly such a colouring (starting from any vertex,
colours propagate uniquely). Therefore it never encounters an edge whose ends
already have the same colour, so it never prints `NO`. ∎



##### Lemma 6  
If a valid assignment exists, the sequence output by the algorithm is the
lexicographically smallest among all valid assignments.

**Proof.**  
Consider the vertices in order `1 … n`. Let `v` be the first vertex where the
algorithm’s output differs from any other valid assignment `A`.  
`v` belongs to some component `C`. By construction the algorithm started the BFS
of `C` at the smallest vertex of `C`, which is exactly `v`. By Lemma&nbsp;3 the
algorithm chose the orientation giving tier `1` to `v`. Any other valid
assignment must give tier `2` to `v` (the opposite orientation), therefore its
sequence is lexicographically larger. ∎



##### Theorem  
The program prints  

* `NO` iff no tier assignment satisfying all obligations exists;  
* otherwise `YES` and the lexicographically smallest valid assignment.

**Proof.**  
*If* the program prints `NO`, it happened because an edge with equal colours was
found, i.e. the graph is not bipartite, so by Lemma&nbsp;2 no assignment exists.  

*If* the program prints `YES`, by Lemma&nbsp;4 the produced sequence is valid,
and by Lemma&nbsp;6 it is the lexicographically smallest one.  

Conversely, if a valid assignment exists, Lemma&nbsp;5 guarantees the program
does not print `NO`, thus it prints `YES` and the sequence described above. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once → `O(n + m)` time.  

Total time `O(n + m)`, total memory `O(n + m)`, well within the limits
(`n, m ≤ 2·10⁵`).

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 unvisited, 0/1 bipartite colour
    ans = [0] * (n + 1)

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component, fixing start colour = 0 (so tier 1)
        q = deque([start])
        colour[start] = 0
        comp = [start]
        while q:
            v = q.popleft()
            cv = colour[v]
            for to in adj[v]:
                if colour[to] == -1:
                    colour[to] = cv ^ 1
                    q.append(to)
                    comp.append(to)
                elif colour[to] == cv:
                    print("NO")
                    return
        # assign tiers: colour 0 -> 1, colour 1 -> 2
        for v in comp:
            ans[v] = 1 if colour[v] == 0 else 2

    print("YES")
    print(' '.join(str(ans[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
