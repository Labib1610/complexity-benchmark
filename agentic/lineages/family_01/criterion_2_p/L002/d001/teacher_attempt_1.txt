# Problem B — Shift Scheduling

Time limit: 1 s
Memory limit: 256 MB

A hospital must schedule its nurses into one of two working blocks, labeled 1 and 2. Every nurse must receive exactly one block. Certain pairs of nurses rely on the same specialized medical device. To ensure the device is never double-booked, the sum of the block labels assigned to any pair of nurses sharing a device must be exactly 3.

Determine a valid block assignment for all nurses, or report if it is impossible.

## Input
The hospital has a maximum capacity of $200,000$ staff members. The first line provides two integers, $n$ and $m$. The value $n$ is the number of nurses currently employed (there is always at least one, up to the maximum capacity). The value $m$ is the number of device-sharing pairs (which may be zero, and is guaranteed never to exceed the hospital's maximum capacity).

Each of the following $m$ lines contains two integers $u$ and $v$ — a pair of nurses who share a device. Nurses are identified by integers from $1$ to $n$.

## Output
If no valid block assignment can be made, print a single line NO.
Otherwise, print YES, followed by a second line containing $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Changed the conflict phrasing from "cannot work during the same shift" to the arithmetic requirement that "the sum of the block labels... must be exactly 3", removing the surface-level phrasing that triggers bipartite graph pattern matching. Applied strategy S07 by expressing the numeric bounds $n$ and $m$ indirectly via a physical maximum capacity of $200,000$, forcing the reader to derive the exact inequalities.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that the block labels (which are restricted to 1 and 2) must sum to 3 for each shared pair is mathematically identical to requiring that they be assigned different shifts, meaning the valid assignments remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding a valid 2-coloring of an undirected graph and selecting the lexicographically smallest valid coloring per component, which is solvable in linear time using BFS/DFS.
</PRESERVED_CLASS>
