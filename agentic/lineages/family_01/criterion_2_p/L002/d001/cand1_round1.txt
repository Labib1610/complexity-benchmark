# Problem B — Thread Priorities

Time limit: 1 s   Memory limit: 256 MB

A processor has $n$ execution threads. Each thread must be assigned a priority level, which must be chosen as either 1 or 2.

There are $m$ pairs of threads that share a locked resource. To avoid race conditions, the hardware requires that for each such pair, the bitwise XOR of their assigned priority levels must evaluate to exactly 3.

Determine if there is a valid priority assignment for all threads. If so, find the sequence of priority levels that satisfies all requirements, and if there are multiple valid sequences, output the one that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of threads that share a resource.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit "cannot share a shift" wording immediately triggers bipartite/2-coloring pattern matching. By replacing it with a bitwise XOR condition on the domain {1, 2}, models must explicitly evaluate the logic ($1 \oplus 2 = 3$, whereas $1 \oplus 1 = 0$ and $2 \oplus 2 = 0$) to realize it enforces strict inequality. Models that pattern-match to generic XOR-SAT or 2-SAT templates will likely fail the lexicographical tie-break or exceed the time limit, while models that reason about the bipartite structure will easily satisfy the greedy component-wise assignment.
</RATIONALE>
<PRESERVED_ANSWER>
Because the only allowed values are 1 and 2, their bitwise XOR is 3 if and only if they are different, making the constraint mathematically identical to the original incompatibility condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring / bipartiteness testing on an undirected graph, which is in P and solvable in O(n+m) time.
</PRESERVED_CLASS>
