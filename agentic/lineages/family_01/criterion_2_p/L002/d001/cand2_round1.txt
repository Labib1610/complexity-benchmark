<STATEMENT>
# Problem B — Frequency Alignment

Time limit: 1 s   Memory limit: 256 MB

A communications array consists of $n$ transmitter modules, numbered 1 to $n$. To prevent harmonic resonance, each module must be tuned to one of two frequency bands, designated as band 1 and band 2.

The diagnostic system has identified $m$ two-module interactions that exhibit harmonic interference. To eliminate this interference, the frequencies $s_u$ and $s_v$ assigned to any such interacting pair of modules $u$ and $v$ must satisfy the equation $s_u + s_v = 3$.

Determine a valid frequency band assignment for all modules. If the interference cannot be resolved under these conditions, the array must be shut down.

## Input
The first line contains two integers $n$ and $m$. The array's power grid limits the total number of transmitter modules $n$ to $200,000$, with a minimum of one module required for operation. The diagnostic log capacity restricts the number of interference records $m$ to at most $200,000$, and it is possible for no records to be present.

Each of the next $m$ lines contains two integers $u$ and $v$ — the identifiers of two modules that exhibit harmonic interference.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise print `YES`, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The conflict condition was changed from a behavioral description ("cannot work during the same shift") to a strict algebraic constraint ($s_u + s_v = 3$) over the domain {1, 2}. Standard mathematical inequality bounds for $n$ and $m$ were replaced with physical system limits described in prose. This forces the model to algebraically deduce that the constraint is equivalent to an inequality ($s_u \neq s_v$), and to extract the data bounds from the text rather than relying on standard notation parsing.
</RATIONALE>
<PRESERVED_ANSWER>
The constraint $s_u + s_v = 3$ for $s_i \in \{1, 2\}$ is mathematically identical to $s_u \neq s_v$, so all valid assignments and the lexicographical tie-breaking remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring (or detecting an odd cycle) in an undirected graph, which is solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might incorrectly interpret "the array's power grid limits..." as an additional capacity constraint on the sum of frequencies, but the wording explicitly says "limits the total number of transmitter modules $n$", which directly mitigates this risk.
</RISK>
