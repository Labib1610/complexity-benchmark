We can model this as a graph problem: each sensor is a node, and each interfering pair is an edge.  
The condition “sum of their band labels is exactly 3” means the two nodes must have different labels (1 and 2).  
So the graph must be bipartite.  

We need the lexicographically smallest assignment, so we try to assign 1 whenever possible, using BFS/DFS with coloring.  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

# color 0 -> band 1, color 1 -> band 2
print("YES")
print(' '.join(str(c + 1) for c in color))
```
