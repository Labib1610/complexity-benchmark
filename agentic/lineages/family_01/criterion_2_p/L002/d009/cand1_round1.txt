<STATEMENT>
# Decentralized Phase Locking

Time limit: 1 s
Memory limit: 256 MB

A distributed system consists of $n$ processes that need to be synchronized. Each process $i$ must be assigned a phase $p_i$, which must be strictly designated as either `1` or `2`.

The system has $m$ synchronization constraints between specific pairs of processes. For any two processes $u$ and $v$ that share a constraint, their assigned phases must satisfy the following condition to avoid data collisions:
The number of integer pairs $(j, k)$ such that $1 \le j \le p_u$, $1 \le k \le p_v$, and $j \neq k$ must be exactly $1$.

If there is no way to assign phases to all $n$ processes such that every constraint is satisfied, the system cannot be synchronized. 

When multiple valid phase assignments are possible, the scheduler mandates selecting the assignment that minimizes the total system energy $E$, defined as:
$E = p_1 \cdot 3^{n - 1} + p_2 \cdot 3^{n - 2} + \dots + p_n \cdot 3^0$
where $p_i$ is the phase of process $i$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$) — the number of processes and the number of synchronization constraints.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — a pair of processes that share a synchronization constraint.

## Output
If no valid phase assignment can be found, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $p_1 \dots p_n$ (each either `1` or `2`), denoting the phases for processes 1 through $n$. This sequence must be the one that minimizes the system energy $E$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit product constraint `p_u * p_v = 2` was replaced with a combinatorial counting condition that evaluates to exactly 1 if and only if $p_u \neq p_v$. Additionally, the lexicographical tie-breaking rule was reformulated as minimizing a base-3 exponential sum (the "energy" $E$). This forces models to genuinely reason about the mathematical equivalence: pattern-matching models will either perceive the energy minimization as an NP-hard weighted optimization (like Weighted 2-SAT) and fail, or they will naively compute the massive sum $3^{200000}$ for each component and Time Limit Exceed. Only models that recognize the base-3 sum as a strict lexicographical order will correctly apply the $O(N+M)$ greedy component choice.
</RATIONALE>
<PRESERVED_ANSWER>
The combinatorial pair-counting condition is mathematically satisfied if and only if one phase is 1 and the other is 2, perfectly preserving the bipartite edge constraints; furthermore, minimizing the base-3 polynomial $E$ is mathematically identical to finding the lexicographically smallest sequence of phases.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-Coloring (Bipartiteness Testing) on an undirected graph, which is solvable in $O(N+M)$ time using BFS/DFS.
</PRESERVED_CLASS>
