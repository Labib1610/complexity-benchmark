 We can model this as a bipartite graph problem.  
Each process is a node, and each constraint is an edge.  
The condition “cannot both be phase 1, nor both be phase 2” means the two endpoints must have different phases — i.e., the graph must be bipartite.  

If the graph is not bipartite, output `NO`.  
If it is bipartite, we assign phases 1 and 2 to the two color classes.  
To get the lexicographically smallest assignment, we should try to assign phase 1 to as many early-indexed nodes as possible.  
We can do this by running BFS/DFS and, when we encounter an uncolored node, always start with color 1.  

Here’s the implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start):
    q = deque([start])
    color[start] = 0
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = color[u] ^ 1
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        if not bfs(i):
            print("NO")
            sys.exit()

print("YES")
print(' '.join('1' if c == 0 else '2' for c in color))
```
