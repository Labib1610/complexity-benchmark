Because 1+1=2 and 2+2=4 are not multiples of 3, this mathematically enforces that the states must be different (1 and 2). <STATEMENT>
# Frequency Interleaving

Time limit: 1 s
Memory limit: 256 MB

A distributed system consists of $n$ processes that need to be synchronized. The hardware is partitioned into exactly $200$ sectors, each capable of hosting up to $1,000$ processes. The total number of processes $n$ is guaranteed to be at least one, and will never exceed the combined maximum capacity of all sectors.

Each process $i$ must be assigned a frequency multiplier $p_i$, which must be either `1` or `2`.

The system's constraint database allocates storage in blocks. There are $200$ blocks available, each capable of storing exactly $1,000$ constraint entries. The total number of constraints $m$ can be zero, and will not exceed the total capacity of all available blocks. Each of these $m$ constraints specifies a pair of processes that interact.

To prevent harmonic resonance cascades, any two processes $u$ and $v$ that share a constraint must be assigned multipliers such that the sum of their multipliers is a multiple of 3.

If there is no way to assign multipliers to all $n$ processes such that every constraint is satisfied, the system cannot be synchronized. When multiple valid multiplier assignments are possible, the scheduler mandates selecting the sequence of multipliers (ordered from process 1 to $n$) that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ — the actual number of processes and the number of constraints.
Each of the next $m$ lines contains two integers $u$ and $v$ — the identifiers of a pair of processes that share a constraint. Process identifiers are positive integers starting from $1$ up to $n$.

## Output
If no valid multiplier assignment can be found, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $p_1 \dots p_n$ (each either `1` or `2`), denoting the multipliers for processes $1$ through $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit condition that two processes "cannot both be assigned phase 1, nor can they both be assigned phase 2" was replaced with the algebraic rule that their sum must be a multiple of 3. The numeric bounds were also hidden behind physical sector capacities (200 sectors * 1000 processes = 200,000) using Strategy S07. This forces the model to deduce the bounds manually and mathematically prove that the multiple-of-3 invariant on the domain {1, 2} strictly requires complementary assignments, rather than relying on surface-level conflict descriptions to identify the bipartite coloring structure.
</RATIONALE>
<PRESERVED_ANSWER>
Because the only possible values for the multipliers are 1 and 2, the possible sums for a constrained pair are 2 (1+1), 3 (1+2 or 2+1), and 4 (2+2); since only 3 is a multiple of 3, constrained pairs must always receive different multipliers, which is logically identical to the original problem's collision rule.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring / bipartiteness checking, as the core constraint still dictates that adjacent nodes in the interaction graph must be assigned different states from a set of size 2, keeping it solvable in O(n + m) time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
A model might incorrectly interpret "multiple of 3" as allowing negative sums or 0, but since the domain is strictly {1, 2}, those values are mathematically impossible to reach, making the statement completely unambiguous.
</RISK>
