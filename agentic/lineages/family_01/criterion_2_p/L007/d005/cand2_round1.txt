<STATEMENT>
# Problem B — Network Configurations

Time limit: 1 s
Memory limit: 256 MB

A communication grid consists of $n$ radio towers and $m$ critical links. The grid's diagnostic system allocates exactly 5 microseconds of maintenance time per tower per second, supporting a maximum grid size derived from a full 1-second maintenance cycle. Thus, $n$ can be anywhere from $1$ up to this maximum capacity. The monitoring database can track one critical link per maximum possible tower, meaning $m$ is bounded between $0$ and this same maximum.

You must assign each tower $i$ a protocol flag $f_i \in \{1, 2\}$.

Each tower $i$ features a directional transmitter. At time step $t=0$, all transmitters are calibrated to face true north (an angle of 0 radians). During operation, time advances in synchronized steps $t \ge 1$. The assigned flag determines the continuous rotation schedule of the transmitter:
- If $f_i = 1$, the transmitter rotates clockwise by $\frac{2\pi}{3}$ radians at each time step.
- If $f_i = 2$, the transmitter rotates counter-clockwise by $\frac{2\pi}{3}$ radians at each time step.

Let $\theta_i(t)$ be the accumulated rotation angle of tower $i$'s transmitter at time step $t$, measured in radians (with clockwise rotations considered positive and counter-clockwise rotations considered negative).

To prevent interference, any two towers $u$ and $v$ connected by a critical link must maintain a perfect phase alignment. The phase alignment index of a link at time $t$ is defined as $\cos(\theta_u(t) + \theta_v(t))$. A critical link is considered conflict-free if and only if its phase alignment index is exactly $1$ at every time step $t \ge 1$.

Determine if a valid assignment of protocol flags exists for all towers such that all critical links are conflict-free. If no such assignment is possible, report impossibility.

## Input
The first line contains two integers $n$ and $m$, representing the number of towers and critical links respectively.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of towers connected by a critical link.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise print `YES`, then a second line with $n$ integers $f_1 \dots f_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit state machine transitions (Sync/Ping/Ack) with a continuous trigonometric phase alignment condition. The explicit bounds on $n$ and $m$ were removed and are now indirectly specified via a 1-second maintenance cycle divided by a 5-microsecond-per-tower allocation. This forces the model to mathematically deduce that $\cos(\theta_u(t) + \theta_v(t)) = 1$ strictly implies $f_u \neq f_v$, rather than just pattern-matching a standard bipartite XOR constraint from overlapping temporal states.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $\cos(\pm \frac{2\pi}{3} t \pm \frac{2\pi}{3} t) = 1$ is satisfied for all $t \ge 1$ if and only if the rotation signs are opposite, perfectly preserving the $f_u \neq f_v$ edge constraint and leaving all valid assignments identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still reduces exactly to 2-coloring (bipartiteness testing) on an undirected graph, which is solvable in $O(n+m)$ time using standard BFS or DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "accumulated rotation angle" and apply a modulo $2\pi$ operation before calculating the sum, though mathematically $\cos((a \bmod 2\pi) + (b \bmod 2\pi))$ is identical to $\cos(a+b)$, so this shouldn't alter the logical deduction.
</RISK>
<METHOD_NAME>
Trigonometric Phase Obfuscation
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces discrete XOR state incompatibilities with a continuous trigonometric identity ($\cos(x+y)=1$) that evaluates to true if and only if the underlying variables are distinct. This defeats models that rely on keyword or state-transition pattern matching to identify graph bipartiteness, forcing them to perform algebraic deduction first.
</METHOD_DESCRIPTION>
