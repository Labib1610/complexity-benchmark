# Problem B — Resonant Foundations

Time limit: 1 s
Memory limit: 256 MB

The structural integrity of a new skyscraper depends on $n$ primary load-bearing pillars, numbered 1 to $n$. The engineering firm must select a concrete composite grade for each pillar. The approved composite grades are exactly 1 and 2.

To mitigate wind-induced vibrations, the design includes $m$ acoustic dampeners. Each dampener spans between a specific pair of pillars. 

For each pillar $u$, we define its *vicinity mass* $V_u$ by examining all dampeners attached to it, and summing the composite grades of the pillars at the other ends of those dampeners. The vibration control system achieves perfect acoustic balance if and only if for every pillar $u$, the following equation holds true:

$V_u + d_u \cdot c_u = 3 \cdot d_u$

where $d_u$ is the total number of dampeners attached to pillar $u$, and $c_u$ is the composite grade chosen for pillar $u$. 

Your task is to determine if there is a safe composite selection for all $n$ pillars such that perfect acoustic balance is achieved. If multiple safe selections exist, the procurement system requires the one that is lexicographically smallest when represented as a sequence of $n$ composite grades.

## Input
The first line contains two integers $n$ and $m$. The number of pillars $n$ requires at least one foundational slot, up to the site's maximum capacity of 200,000 slots. The number of dampeners $m$ is constrained by the warehouse inventory, which starts at zero and caps at 200,000 units.
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of the two pillars spanned by a dampener.

## Output
If no safe selection exists, print a single line `NO`.
Otherwise print `YES`, then a second line with $n$ integers $c_1 \dots c_n$ (each being 1 or 2), representing the lexicographically smallest safe selection.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the global edge-sum condition and the quadratic resonance formula with a local, vertex-centric equation ($V_u + d_u \cdot c_u = 3 \cdot d_u$). This forces models to algebraically deduce that since grades are restricted to {1, 2}, the equation can only be satisfied if every neighbor of a pillar has the opposite grade, completely removing the overt bipartite graph coloring affordances. I also stated the bounds indirectly using the physical constraints of the site and inventory.
</RATIONALE>
<PRESERVED_ANSWER>
Because $c \in \{1, 2\}$, if $c_u = 1$, the terms $c_v + c_u \le 3$, so summing to $3 d_u$ strictly requires every $c_v = 2$; conversely if $c_u = 2$, the terms $c_v + c_u \ge 3$, requiring every $c_v = 1$, making the new equation exactly logically equivalent to the original requirement that $c_u \neq c_v$ for all edges.
</PRESERVED_ANSWER>

The problem remains exactly equivalent to finding the lexicographically smallest valid 2-coloring of a graph, which is in P and solvable via BFS in $O(n+m)$ time.
</PRESERVED_CLASS>
