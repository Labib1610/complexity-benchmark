We need to assign each relay a key of either 1 or 2 such that for every edge (u, v), the XOR of their keys is 3.  

Since keys are only 1 or 2, XOR = 3 means the two keys must be different (1 XOR 2 = 3). So this is a **bipartite coloring** problem:  
- Color each node with 1 or 2.  
- Adjacent nodes must have different colors.  

If the graph is not bipartite, output `NO`.  
Otherwise, we need the lexicographically smallest assignment.  

To get lexicographically smallest, we process nodes in order 1..n. For each uncolored node, we try to color it with 1 first, then run BFS/DFS to color its component. If a conflict occurs, we try with 2. If both fail, it's impossible.  

Here’s the implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start, first_color):
    q = deque([start])
    color[start] = first_color
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        # try color 1
        temp = color[:]
        if bfs(i, 0):
            continue
        # rollback and try color 2
        color[:] = temp
        if not bfs(i, 1):
            print("NO")
            sys.exit()

print("YES")
print(' '.join(str(c + 1) for c in color))
```
