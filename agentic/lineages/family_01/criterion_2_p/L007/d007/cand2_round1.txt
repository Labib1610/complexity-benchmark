<METHOD_NAME>Algebraic Parity Inversion</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the direct "opposite protocol" constraint with a requirement that the sum of two 2x2 matrices (mapped to the binary states) is invertible. Models must mathematically evaluate the matrix sums to discover this equates to a simple inequality constraint, and then conceptually map that to bipartite graph coloring.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Matrix Stability Configurations

Time limit: 1 s
Memory limit: 256 MB

A computational grid consists of $n$ processing nodes. You must assign each node $i$ a configuration state $f_i \in \{1, 2\}$. 

Each state corresponds to a specific $2 \times 2$ transformation matrix:
- Configuration $1$ assigns the matrix $M_1 = \begin{pmatrix} 1 & 1 \\ 1 & 1 \end{pmatrix}$.
- Configuration $2$ assigns the matrix $M_2 = \begin{pmatrix} 1 & -1 \\ -1 & 1 \end{pmatrix}$.

There are $m$ synchronization links between specific pairs of nodes. 
For a link between node $u$ and node $v$ to successfully synchronize, the element-wise sum of their assigned matrices, $S = M_{f_u} + M_{f_v}$, must be an invertible matrix (i.e., its determinant must be non-zero).

Determine if a valid assignment of configuration states exists for all nodes such that all synchronization links are successful. If no such assignment is possible, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of nodes connected by a synchronization link.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $f_1 \dots f_n$ (each in $\{1,2\}$). 
If multiple valid assignments exist, you must resolve ties by choosing the assignment that assigns the smallest possible configuration state to node 1. If ties remain, among those, choose the one that assigns the smallest possible configuration state to node 2, and continue this sequential preference for smaller configuration states up to node $n$ (this is equivalent to the lexicographically smallest valid assignment).

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The direct constraint requiring mismatched protocols was entirely replaced with a linear algebra condition involving 2x2 matrices. To solve the problem optimally, the model must evaluate the determinant for the three possible matrix sums ($M_1+M_1$, $M_2+M_2$, and $M_1+M_2$) to deduce that only the combination of different states yields a non-zero determinant. This forces an extra step of mathematical reasoning before the structural graph problem (bipartite coloring) can even be recognized.
</RATIONALE>
<PRESERVED_ANSWER>
Because det(M1+M1)=0, det(M2+M2)=0, and det(M1+M2)=4, the invertibility requirement is strictly satisfied if and only if linked nodes are assigned different states, perfectly matching the original problem's mismatched protocol requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core structural task remains verifying if a graph can be validly 2-colored and finding the lexicographically first coloring, keeping it firmly in P (solvable in O(n+m) via BFS/DFS).
</PRESERVED_CLASS>
