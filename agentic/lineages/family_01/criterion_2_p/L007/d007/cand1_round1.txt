<STATEMENT>
# Problem B — Network Configurations

Time limit: 1 s
Memory limit: 256 MB

A communication grid consists of $n$ radio towers. 

Each tower $i$ must be assigned a signal amplifier type, denoted by $f_i \in \{1, 2\}$. The available amplifier types apply different algebraic transformations to an incoming signal $x$:
- Type 1: Squares the signal. Its transformation is $A(x) = x^2$.
- Type 2: Cubes the signal. Its transformation is $A(x) = x^3$.

There are $m$ critical links between specific pairs of towers. 

To establish a successful bidirectional handshake across a critical link between tower $u$ and tower $v$, their combined signal processing must raise the signal to exactly the sixth power. Specifically, if a signal $x$ is passed through the amplifier of tower $v$ and then the resulting signal is passed through the amplifier of tower $u$, the final output $A_u(A_v(x))$ must be identical to $x^6$ for all $x$. (Because these specific transformations commute, the direction of the signal flow across the link does not matter).

Determine if a valid assignment of amplifier types exists for all towers such that all critical links successfully establish their handshakes. If no such assignment is possible, report impossibility.

## Input
The first line contains two integers $n$ and $m$. The geographic registry's indexing system strictly limits the total number of towers $n$ to at most two hundred thousand, and the number of critical links $m$ is capped at exactly the same maximum capacity (with at least one tower and zero or more links).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of towers connected by a critical link.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $f_1 \dots f_n$ (each in $\{1,2\}$). 
If multiple valid assignments exist, you must resolve ties by choosing the assignment that assigns the smallest possible amplifier type to tower 1. If ties remain, among those, choose the one that assigns the smallest possible amplifier type to tower 2, and continue this sequential preference for smaller types up to tower $n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit "primary matches backup" constraint inherently revealed that neighboring towers must choose opposite states, directly exposing the 2-coloring structure. I replaced this with an algebraic composition constraint where two signal transformations ($x^2$ and $x^3$) must compose to $x^6$. Additionally, I applied S07 by replacing the numeric input bounds with a textual description of the registry's capacity limits. This forces models to algebraically deduce the mutual exclusion and carefully parse the text for boundary conditions.
</RATIONALE>
<PRESERVED_ANSWER>
Because the composition of $x^2$ and $x^3$ yields $x^6$ only when exactly one of each operation is applied, the new condition strictly enforces $f_u \neq f_v$ across all links, perfectly mirroring the original binary constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains fundamentally equivalent to finding a valid 2-coloring of an undirected graph (and choosing the lexicographically smallest component orientations), maintaining its linear time complexity.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the composition $A_u(A_v(x)) = x^6$ as allowing combinations of types other than 1 or 2, though the text explicitly restricts $f_i \in \{1, 2\}$.
</RISK>
<METHOD_NAME>
Algebraic Composition Constraint
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the direct "opposite protocol" constraint with a requirement that the composition of two algebraic signal transformations yields x^6. Since the available transformations are squaring (type 1) and cubing (type 2), the product of their exponents must be 6, which forces exactly one of each type per link. This mathematically preserves the exact bipartite structure while completely hiding it from superficial pattern matching.
</METHOD_DESCRIPTION>
