<STATEMENT>
# Problem B — Sensor Network Calibration

Time limit: 1 s
Memory limit: 256 MB

You are calibrating a network of $n$ sensors. Each sensor $i$ must be configured with a power state $b_i \in \{1, 2\}$.

There are $m$ interference links between specific pairs of sensors. For the network to be stable, the power states must satisfy a specific multiplicative balance. 

For every sensor $i$, let $d_i$ be the number of interference links connected to it. The product of the power states of the sensors at the other ends of these $d_i$ links must evaluate to exactly $2^{d_i (2 - b_i)}$. 
(If a sensor has no interference links, i.e., $d_i = 0$, the product over zero links is considered to be 1. Since $2^0 = 1$, the condition is trivially met for isolated sensors).

Determine if a valid assignment of power states exists for all sensors such that this stability condition is simultaneously satisfied for all $n$ sensors. If no such assignment is possible, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of sensors connected by an interference link.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $b_1 \dots b_n$ (each in $\{1,2\}$). 
If multiple valid assignments exist, you must output the assignment that minimizes the sum $\sum_{i=1}^n b_i \cdot 3^{n-i}$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the local edge condition (inverses of affine transformations) with a global neighborhood condition: the product of neighbors' states must equal $2^{d_i(2-b_i)}$. Because $b_k \in \{1, 2\}$, this mathematically forces all neighbors to be 2 if $b_i=1$ (since the max possible product of $d_i$ elements is $2^{d_i}$), and forces all neighbors to be 1 if $b_i=2$ (since the min possible product is 1). This perfectly preserves the 2-coloring requirement but requires models to perform algebraic deduction on sets of variables rather than evaluating a 2x2 local truth table. The tie-breaker was rewritten from a base-3 integer string rule to its exact polynomial equivalent to prevent keyword-based recognition of lexicographical BFS.
</RATIONALE>
<PRESERVED_ANSWER>
The product condition is mathematically satisfied if and only if every adjacent pair has opposite states, perfectly enforcing the bipartite graph requirement, and the tie-breaker polynomial sum exactly equals the numerical value of the original base-3 integer sequence.
</PRESERVED_ANSWER>

The problem remains standard 2-coloring on an undirected graph, solvable in O(N+M) using BFS or DFS.
</PRESERVED_CLASS>
