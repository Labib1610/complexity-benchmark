# Problem B — Access Protocol

Time limit: 1 s   Memory limit: 256 MB

The factory planning process involves configuring the access protocols for the workforce. The physical facility guarantees a headcount of at least one, up to a maximum capacity of $200,000$ employees. The HR department maintains a registry of restricted employee pairs. The database storage limit allows for up to $200,000$ such records, or it may contain none at all.

Your task is to assign each employee exactly one of two access badges, designated as type 1 and type 2. To comply with HR regulations, any two employees listed together in the registry must receive distinct badge types. If no such valid configuration is possible, the system must report this. Otherwise, the configuration will be sent to the payroll department for final processing.

## Input
The first line contains two integers $n$ and $m$ — the actual headcount and the number of registry records. The limits on these values are defined by the physical facility and database limits described above.

Each of the next $m$ lines contains two integers $u$ and $v$ — a restricted pair.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1, 2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

Changed the scenario from assigning shifts to assigning access badges to remove the "two-shift conflict" phrasing that triggered direct pattern-matching to bipartite coloring templates. Rephrased the bounds as physical facility capacities and database limits instead of mathematical inequalities, forcing the reader to extract the constraints contextually.
</RATIONALE>
<PRESERVED_ANSWER>
The task remains to partition a graph into two independent sets (labeled 1 and 2) and return the lexicographically smallest valid assignment, which is exactly the same logical requirement as the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding a valid 2-coloring of a graph, which is solvable in O(n+m) time using BFS or DFS, leaving it in P.
</PRESERVED_CLASS>
<RISK>
The phrase "distinct badge types" is slightly less explicit than "no conflicting pair shares a shift", but it unambiguously means the two employees cannot have the same badge type.
</RISK>
