**Solution Explanation**

For every tower we have to choose a value `1` or `2`.
For a critical link `{u , v}` the condition  

```
value[u] + value[v] = 3
```

must hold, i.e. the two endpoints must receive *different* values.
So the whole graph has to be **bipartite**.  
If it is bipartite we have two colour classes in each connected component.
Inside a component we may exchange the meaning of the two colours
(`0 → 1 , 1 → 2` or `0 → 2 , 1 → 1`).  
To obtain the lexicographically smallest assignment we simply make the
smallest‑indexed vertex of the component receive value `1`
(the flip that achieves this is always possible).

--------------------------------------------------------------------

#### Algorithm
```
read n , m
build adjacency list

colour[1…n] = -1          # -1 = not visited, 0/1 = bipartite colour
answer[1…n] = 0

for v = 1 … n
    if colour[v] == -1
        # start a new component
        queue ← [v]
        colour[v] = 0
        component_vertices = [v]

        while queue not empty
            x = pop queue
            for each neighbour y of x
                if colour[y] == -1
                    colour[y] = colour[x] ^ 1
                    push y to queue
                    component_vertices.append(y)
                else if colour[y] == colour[x]
                    print "NO" and exit   # not bipartite

        # component is bipartite, decide orientation
        min_vertex = min(component_vertices)
        if colour[min_vertex] == 0
            # colour 0 → value 1, colour 1 → value 2
            for u in component_vertices
                answer[u] = 1 if colour[u] == 0 else 2
        else
            # flip
            for u in component_vertices
                answer[u] = 2 if colour[u] == 0 else 1

print "YES"
print answer[1] … answer[n] separated by spaces
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `"NO"` iff no valid assignment exists,
otherwise prints `"YES"` and the lexicographically smallest valid assignment.

---

##### Lemma 1  
During the BFS of a component, if the algorithm detects an edge
`(x , y)` with `colour[x] == colour[y]`, then the graph is not bipartite.

**Proof.**  
All already visited vertices have a colour fixed by the BFS rule
(`neighbour gets opposite colour`).  
If an edge connects two vertices with the same colour, any 2‑colouring would
assign the same colour to both ends, contradicting the requirement that
adjacent vertices have different colours. ∎



##### Lemma 2  
If the algorithm finishes the BFS of a component without conflict,
the component is bipartite and the array `colour` gives a proper 2‑colouring.

**Proof.**  
The BFS starts with an arbitrary vertex coloured `0`.  
Whenever a vertex `x` is processed, every uncoloured neighbour `y` receives
`colour[y] = colour[x] xor 1`, i.e. the opposite colour.
Thus every explored edge connects vertices of different colours.
Because every vertex of the component is eventually reached,
all edges satisfy the property, i.e. the component is bipartite. ∎



##### Lemma 3  
For a bipartite component the algorithm assigns values `1`/`2` that satisfy
all critical links inside the component.

**Proof.**  
Two cases.

*If `colour[min] == 0`* we set `value = 1` for colour `0` and `2` for colour `1`.  
*If `colour[min] == 1`* we flip the mapping, i.e. colour `0 → 2`, colour `1 → 1`.  

In both cases vertices of different colours receive different values,
hence for every edge the sum is `1+2 = 3`. ∎



##### Lemma 4  
The assignment produced by the algorithm is lexicographically minimal among
all valid assignments.

**Proof.**  
Consider any component `C`. Let `p` be the smallest index vertex of `C`.
All valid assignments must give `p` either `1` or `2`.  
Our algorithm chooses the orientation that gives `p` value `1`
(because we flip exactly when `colour[p] == 1`).  
Thus for component `C` no other valid assignment can have a smaller value
at position `p`.  
Components are independent, and vertices are processed in increasing order,
so the whole concatenated sequence is lexicographically minimal. ∎



##### Lemma 5  
If the algorithm prints `"NO"` then no valid assignment exists.

**Proof.**  
The algorithm prints `"NO"` only when Lemma&nbsp;1 detects a same‑colour edge,
i.e. the graph contains a non‑bipartite component.
In any assignment values must differ on every edge, which is exactly a
2‑colouring of the graph. A non‑bipartite graph admits no 2‑colouring,
hence no valid assignment exists. ∎



##### Lemma 6  
If the algorithm prints `"YES"` then the printed assignment is valid.

**Proof.**  
Printing `"YES"` means every component passed Lemma&nbsp;2, therefore the
whole graph is bipartite. By Lemma&nbsp;3 the values assigned inside each
component satisfy all its edges, consequently all edges of the whole graph
satisfy the required sum `3`. ∎



##### Theorem  
The algorithm outputs

* `"NO"` iff the instance has no feasible configuration,
* otherwise `"YES"` followed by the lexicographically smallest feasible
  configuration.

**Proof.**  
*If the algorithm outputs `"NO"`* – by Lemma&nbsp;5 no feasible configuration
exists.

*If the algorithm outputs `"YES"`* – by Lemma&nbsp;6 the printed configuration
is feasible, and by Lemma&nbsp;4 it is lexicographically minimal among all
feasible ones.

Conversely, if a feasible configuration exists, the graph must be bipartite,
so Lemma&nbsp;1 never triggers and the algorithm reaches `"YES"`. ∎

#### Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once → `O(n + m)` time.  
*Additional work* (finding minima, filling answer) is linear in component size,
overall `O(n)`.

Total time `O(n + m)` ≤ `4·10⁵`, well inside the 1 s limit.  
Memory consumption `O(n + m)` ≤ `~4·10⁵` integers → < 10 MB.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 = unvisited, 0/1 = bipartite colour
    ans = [0] * (n + 1)

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp = [start]

        while q:
            x = q.popleft()
            cx = colour[x]
            for y in adj[x]:
                if colour[y] == -1:
                    colour[y] = cx ^ 1
                    q.append(y)
                    comp.append(y)
                elif colour[y] == cx:
                    sys.stdout.write("NO")
                    return

        # decide orientation: smallest index gets value 1
        min_v = min(comp)
        if colour[min_v] == 0:
            for v in comp:
                ans[v] = 1 if colour[v] == 0 else 2
        else:
            for v in comp:
                ans[v] = 2 if colour[v] == 0 else 1

    out = ["YES", " ".join(str(ans[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
