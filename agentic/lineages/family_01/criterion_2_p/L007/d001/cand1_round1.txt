# Problem B — Network Configurations

Time limit: 1 s
Memory limit: 256 MB

A communication grid consists of $n$ radio towers. You need to assign each tower a configuration value, which must be either 1 or 2. 

There are $m$ critical links between specific pairs of towers. To prevent signal degradation, the two towers in any critical link must have configuration values that sum to exactly 3. 

Determine if a valid assignment exists for all towers. If no such assignment is possible, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of towers connected by a critical link.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $f_1 \dots f_n$ (each in $\{1,2\}$), the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The suggested removal of forcing both frequencies to be used would have changed the expected output for edgeless graphs (like n=1, m=0), directly violating the IDENTICAL ANSWERS constraint. Instead, I removed the "different colors" affordance by requiring that the values of connected towers sum to exactly 3. Since the only available values are 1 and 2, this mathematically forces them to be distinct, requiring models to deduce the bipartite coloring structure themselves without relying on pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
Because the configuration values are strictly restricted to 1 and 2, their sum is 3 if and only if they are distinct, making the constraints and lexicographical tie-breaking mathematically identical to the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to testing bipartiteness (2-coloring) on an undirected graph, which is solvable in O(n+m) time using BFS.
</PRESERVED_CLASS>
