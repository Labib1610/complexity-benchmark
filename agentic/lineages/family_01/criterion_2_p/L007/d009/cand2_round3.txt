# Problem B — Polynomial Shift Assignments

Time limit: 1 s
Memory limit: 256 MB

You are configuring a system of $n$ computational nodes. Each node $i$ must be assigned a configuration parameter $b_i \in \{1, 2\}$. 
Choosing parameter 1 assigns the node the characteristic polynomial $P_i(x) = x - 1$.
Choosing parameter 2 assigns the node the characteristic polynomial $P_i(x) = x + 1$.

There are $m$ data pipelines between specific pairs of nodes. For a data pipeline to function securely between node $u$ and node $v$, their assigned characteristic polynomials must satisfy the following condition over the interval $[-1, 1]$: 
$$ \int_{-1}^{1} P_u(x) P_v(x) \, dx < 0 $$

Determine if a valid assignment of configuration parameters exists for all nodes such that this integral condition is strictly negative for all data pipelines. If no such assignment is possible, report impossibility.

## Input
The first line contains two integers $n$ and $m$. The values of $n$ and $m$ are at least $1$ and $0$ respectively, and neither will exceed the total number of minutes in exactly $138$ days, $21$ hours, and $20$ minutes.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of nodes connected by a data pipeline. Repeated pipelines between the same pair of nodes may occur and must each satisfy the condition (a node may also have a pipeline connecting to itself).

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $b_1 \dots b_n$ (each in $\{1,2\}$). 
If multiple valid assignments exist, you must output the lexicographically smallest valid assignment (i.e., resolve ties by preferring parameter 1 over parameter 2 for node 1, then for node 2, and so on).

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the seed's matrix sum invertibility condition with a definite integral over the product of two assigned polynomials. Evaluating this integral reveals it is strictly negative if and only if the two polynomials are different (i.e., one is $x-1$ and the other is $x+1$), which elegantly preserves the exact bipartite coloring reduction of the seed without using any matrices or terminology that trivially pattern-matches to graph concepts. I also used Strategy S07 to express the $2 \cdot 10^5$ bounds indirectly as a duration in minutes, forcing the model to explicitly derive the limits.
</RATIONALE>
<PRESERVED_ANSWER>
The definite integral of the product of the polynomials evaluates to $8/3$ when the parameters are the same and $-4/3$ when they are different, so the pairwise condition is satisfied if and only if connected nodes receive different parameters, exactly mirroring the invertibility of the matrix sums in the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains exactly 2-coloring (bipartiteness testing) on an undirected graph, which is in P and solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the time conversion for the bounds if they assume different definitions of a day (e.g., sidereal days), though standard competitive programming conventions make this highly unlikely.
</RISK>
