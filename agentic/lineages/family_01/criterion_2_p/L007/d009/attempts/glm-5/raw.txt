We need to determine if we can assign each sensor a basis in {1,2} such that for every edge (u,v), f_{b_v}(f_{b_u}(x)) = x for all x in {0,1,2,3,4}.

Let's compute the composition of transformations:
- f1(x) = (2x+1) mod 5
- f2(x) = (3x+2) mod 5

We need f_{b_v} ∘ f_{b_u} = identity.

Let's check all 4 combinations:
- f1∘f1: f1(f1(x)) = f1(2x+1) = 2(2x+1)+1 = 4x+3 mod 5. Not identity.
- f1∘f2: f1(f2(x)) = f1(3x+2) = 2(3x+2)+1 = 6x+5 = x mod 5. Identity! ✓
- f2∘f1: f2(f1(x)) = f2(2x+1) = 3(2x+1)+2 = 6x+5 = x mod 5. Identity! ✓
- f2∘f2: f2(f2(x)) = f2(3x+2) = 3(3x+2)+2 = 9x+8 = 4x+3 mod 5. Not identity.

So the condition is: for every edge (u,v), b_u ≠ b_v. This is a standard 2-coloring (bipartite) problem.

We need to check if the graph is bipartite. If yes, output the lexicographically smallest assignment (minimize b_1, b_2, ..., b_n as base-3 number with b_1 most significant). Since we want to minimize, we prefer 1 over 2.

To get the lexicographically smallest assignment, we process components and assign the smallest possible value to the smallest-indexed unvisited node, then BFS/DFS to assign alternating values.

Let me verify with example 1: 4 nodes, edges 1-2, 2-3, 3-4, 1-4. This is a cycle of length 4 (bipartite). Assign 1 to node 1, then 2 to node 2, 1 to node 3, 2 to node 4. Output: 1 2 1 2. Matches.

Example 2: triangle, not bipartite. Output NO. Matches.

```python
import sys
from collections import deque

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(input_data[idx]) - 1; idx += 1
        v = int(input_data[idx]) - 1; idx += 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n  # 0 = unassigned, 1 or 2
    
    for start in range(n):
        if color[start] == 0:
            color[start] = 1
            queue = deque([start])
            while queue:
                u = queue.popleft()
                for v in adj[u]:
                    if color[v] == 0:
                        color[v] = 3 - color[u]
                        queue.append(v)
                    elif color[v] == color[u]:
                        print("NO")
                        return
    
    print("YES")
    print(' '.join(str(c) for c in color))

solve()
```
