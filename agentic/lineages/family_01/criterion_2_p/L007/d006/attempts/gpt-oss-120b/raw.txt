**Solution Explanation**

For a pillar we have two possible vectors  

* grade 1 : **a** = (1, 2, 3)  
* grade 2 : **b** = (3, 1, 2)

For an edge `{u,v}` the required value is  

```
‖ v_u × v_v ‖²
```

```
a × a = 0                     → 0
b × b = 0                     → 0
a × b = (1,7,‑5)              → 1²+7²+5² = 75
b × a = –(a × b)              → 75
```

Hence an edge contributes  

* `0` if both ends have the same grade,
* `75` if the grades differ.

The total required sum is `75·m`.  
Therefore **every edge must contribute 75**, i.e. its ends must have different
grades.  
The problem is exactly:  

> Is the given graph bipartite?  
> If yes, output the lexicographically smallest 2‑coloring (colors 1 and 2).

--------------------------------------------------------------------

#### 1.   Bipartite test and component handling  

We run BFS/DFS on each connected component.

*During BFS* we assign a temporary side `0/1` to every visited vertex.
If we ever meet an edge whose two ends already have the same side,
the graph is not bipartite → answer `NO`.

While exploring a component we store all its vertices in a list `comp`.
After the BFS finishes we know the bipartition of this component.

--------------------------------------------------------------------

#### 2.   Lexicographically smallest coloring  

For a component we may flip the meaning of the two sides:

```
side 0 → grade 1 , side 1 → grade 2
or
side 0 → grade 2 , side 1 → grade 1
```

Lexicographic order compares vertices `1 … n`.  
The first vertex of the component that appears in this order is the smallest
index `min_idx = min(comp)`.  
If we give this vertex grade 1, the whole sequence becomes as small as
possible, because later vertices cannot affect earlier positions.

So:

```
s = side[min_idx]          # 0 or 1
if s == 0:   mapping = {0:1, 1:2}
else:        mapping = {0:2, 1:1}
```

All vertices of the component receive their final grades according to this
mapping. Isolated vertices are a component of size 1, they obtain grade 1.

Processing vertices in increasing order guarantees that each component is
oriented independently, and the whole resulting sequence is the lexicographically
smallest among all proper 2‑colorings.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `YES` and the lexicographically smallest
valid assignment iff such an assignment exists.

---

##### Lemma 1  
For any edge `{u,v}` the value `‖v_u × v_v‖²` equals `0` if `c_u = c_v`
and `75` otherwise.

*Proof.* Direct computation of the three possible cross products shown above. ∎



##### Lemma 2  
A coloring satisfies the required total sum `75·m` **iff** every edge connects
vertices of different grades, i.e. the coloring is a proper 2‑coloring of the
graph.

*Proof.* By Lemma&nbsp;1 each edge contributes either `0` or `75`.  
The sum equals `75·m` exactly when all `m` edges contribute `75`, i.e. when
their ends have different grades. ∎



##### Lemma 3  
If the algorithm reports `NO`, the graph is not bipartite.

*Proof.* The algorithm reports `NO` only when during BFS an edge is found whose
endpoints already have the same temporary side. This is precisely a violation
of bipartiteness. ∎



##### Lemma 4  
If the graph is bipartite, the algorithm produces a proper 2‑coloring.

*Proof.* For each component BFS assigns sides `0/1` without conflict,
because the graph is bipartite. Afterwards we map the two sides to grades
`1` and `2` (possibly swapping). Adjacent vertices belong to opposite sides,
hence receive opposite grades. ∎



##### Lemma 5  
For a bipartite graph, the coloring output by the algorithm is the
lexicographically smallest among all proper 2‑colorings.

*Proof.* Consider one connected component `C`.  
Let `p = min(C)` be its smallest vertex index.
All vertices with index `< p` belong to earlier components and are already
fixed. To minimise the whole sequence we must give `p` the smallest possible
grade, i.e. `1`. The algorithm chooses exactly the mapping that assigns grade 1
to the side containing `p`. Any other proper coloring either gives `p` grade 2
or coincides on `p` and differs later, thus is not lexicographically smaller.
Since components are independent, applying this rule to every component yields the
global lexicographically minimum sequence. ∎



##### Lemma 6  
If a proper 2‑coloring exists, the algorithm never reports `NO`.

*Proof.* Existence of a proper 2‑coloring implies the graph is bipartite.
BFS on a bipartite graph never encounters a same‑side edge, so the algorithm
does not reject. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no safe selection exists;  
* otherwise `YES` followed by the lexicographically smallest safe selection.

*Proof.*  
- If the algorithm prints `NO`, by Lemma&nbsp;3 the graph is not bipartite,
  thus by Lemma&nbsp;2 no safe selection exists.
- If a safe selection exists, the graph is bipartite, so by Lemma&nbsp;6 the
  algorithm does not reject. By Lemma&nbsp;4 it outputs a proper 2‑coloring,
  which by Lemma&nbsp;2 satisfies the required sum. Lemma&nbsp;5 shows this
  coloring is the lexicographically smallest possible. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

`BFS` visits each vertex once and scans each edge twice.

```
Time   :  O(n + m)   ≤ 4·10⁵ operations
Memory :  O(n + m)   adjacency lists + arrays
```

Both fit easily into the limits.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    side = [-1] * (n + 1)          # temporary bipartition side 0/1
    color = [0] * (n + 1)          # final grades 1/2
    q = deque()

    for start in range(1, n + 1):
        if side[start] != -1:
            continue
        # start new component
        comp = []
        side[start] = 0
        q.append(start)
        bip = True
        while q:
            v = q.popleft()
            comp.append(v)
            for to in adj[v]:
                if side[to] == -1:
                    side[to] = side[v] ^ 1
                    q.append(to)
                elif side[to] == side[v]:
                    # not bipartite
                    print("NO")
                    return
        # choose orientation to make smallest index vertex colour 1
        min_idx = min(comp)
        s = side[min_idx]          # side (0 or 1) of that vertex
        # mapping: side == s -> 1, else -> 2
        for v in comp:
            color[v] = 1 if side[v] == s else 2

    # all components processed, graph bipartite
    print("YES")
    print(' '.join(str(color[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
