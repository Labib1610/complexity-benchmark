# Problem B — Heterodyne Array Configuration

Time limit: 1 s   Memory limit: 256 MB

A radio telescope array contains $n$ local oscillators, numbered 1 to $n$. The facility requires at least one oscillator, and can support up to a maximum hardware limit of two hundred thousand. Each oscillator must be tuned to a phase mode, which must be set to either 1 or 2.

The array's signal processing relies on $m$ heterodyne correlators. A system might have zero correlators, while a fully built array can have up to two hundred thousand. Each correlator receives the phase mode signals from two specific oscillators. For the correlator to correctly downconvert the astronomical signal, the phase mode of one of its connected oscillators must be exactly double the phase mode of the other.

You must determine if there is a valid tuning configuration for all $n$ oscillators that satisfies all correlator requirements. If a valid configuration exists, you must output it. In cases where multiple configurations satisfy all requirements, you must output the configuration that forms the lexicographically smallest sequence of phase modes.

## Input
The first line contains two integers $n$ and $m$.
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of two oscillators connected to a correlator.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, followed by a second line containing $n$ integers $s_1 \dots s_n$ (each being 1 or 2), representing the lexicographically smallest valid sequence of phase modes.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

Removed the explicit "product must be 2" constraint, which mathematically triggered bipartite coloring templates in models. Replaced it with the requirement that one phase mode must be exactly double the other, forcing the model to deduce that within the domain {1, 2}, this still strictly enforces inequality between adjacent nodes. Also applied strategy S07, removing the bare inequalities for $n$ and $m$ from the Input section and instead embedding their exact limits into the facility's hardware constraints in the description.
</RATIONALE>
<PRESERVED_ANSWER>
The domain of variables remains {1, 2}, and the condition that one value is double the other is only satisfied by the pair {1, 2}, which is mathematically identical to their product being 2; thus all valid assignments and the lexicographical tie-breaker remain identical.
</PRESERVED_ANSWER>
