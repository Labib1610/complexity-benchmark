<STATEMENT>
# Problem B — Network Configurations

Time limit: 1 s
Memory limit: 256 MB

A communication grid consists of $n$ radio towers. You need to assign each tower $i$ a configuration value $f_i$, which must be chosen from the set $\{1, 2\}$. 

The configuration value determines the tower's transmission interval: a tower with value $f_i$ transmits a sync pulse every $f_i$ microseconds (i.e., at times $t = f_i, 2f_i, 3f_i, \dots$). 

There are $m$ critical links between specific pairs of towers. To prevent signal degradation, the configuration values of the two towers connected by any critical link must satisfy the *handshake stability predicate*. For a link between tower $u$ and tower $v$ to be stable, the total combined number of sync pulses transmitted by both towers within the strictly positive time window $0 < t \le 2$ microseconds must be exactly 3.

Determine if a valid assignment exists for all towers. If no such assignment is possible, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of towers connected by a critical link.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise print `YES`, then a second line with $n$ integers $f_1 \dots f_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the directly evaluable algebraic equation with an indirectly presented stability predicate based on sync pulse counts within a specific time window. This forces the model to trace the physical mechanics of the transmission intervals to deduce that connected towers must have different configuration values, removing the affordance of pattern-matching a simple formula.
</RATIONALE>
<PRESERVED_ANSWER>
The new sync pulse condition evaluates to exactly 3 pulses if and only if one tower operates at interval 1 (yielding 2 pulses) and the other at interval 2 (yielding 1 pulse), exactly preserving the requirement that connected towers must have different values.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core constraint remains that every critical link requires its endpoints to have strictly different values from a set of size two, which is identical to testing graph bipartiteness (2-coloring) in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the time window boundaries, although the phrase "strictly positive time window $0 < t \le 2$" is mathematically standard and explicitly includes $t=2$ while excluding $t=0$.
</RISK>
