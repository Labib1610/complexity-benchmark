**Solution Explanation**

For every critical link the two towers must have opposite signals.
If a tower has configuration  

* `1` – pattern **high, low**  
* `2` – pattern **low, high**

then the two towers of a link must be different.
So the whole graph has to be *bipartite*.
If it is not bipartite there is no assignment.

If the graph is bipartite, each connected component has exactly two possible
assignments – the two colour classes can be mapped to `{1,2}` in two ways.
We have to output the *lexicographically smallest* assignment.
Lexicographic order is decided by the first position where two assignments differ,
therefore we should make the smallest‑index vertex of every component receive `1`
(if possible).  
Because the two colourings are just a swap, we can always do that:
choose the orientation that maps the colour of the smallest vertex to `1`.

Thus the algorithm is:

```
for every vertex not visited:
        BFS/DFS, colour vertices 0/1
        if we ever see an edge joining equal colours → not bipartite → NO
        store the list of vertices of this component
        let v = smallest vertex in the component
        if colour[v] == 0:   colour 0 → 1 , colour 1 → 2
        else:                colour 1 → 1 , colour 0 → 2
        write the chosen numbers into the answer array
```

The whole work is `O(n+m)` time and `O(n+m)` memory.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints **NO** iff no valid assignment exists,
otherwise prints **YES** and the lexicographically smallest valid assignment.

---

##### Lemma 1  
If the algorithm reports “NO”, the graph is not bipartite, therefore no
assignment satisfies all links.

**Proof.**  
During BFS we colour each visited vertex `0` or `1`.  
When an edge `(u,v)` is examined, if `colour[u] == colour[v]` we output “NO”.
In any 2‑colouring of a graph adjacent vertices must have different colours,
so such an edge makes a bipartite colouring impossible.
∎



##### Lemma 2  
If the graph is bipartite, the algorithm produces a configuration that satisfies
all links.

**Proof.**  
For each component the BFS produces a proper 2‑colouring, i.e. every edge joins
different colours.  
After the BFS we map the two colour classes to the numbers `{1,2}` (maybe swapped).
Thus every edge connects vertices with different numbers, exactly the required
condition. ∎



##### Lemma 3  
For a bipartite component, among the two possible mappings of colours to
`{1,2}` the algorithm chooses the one that makes the smallest‑index vertex of the
component equal to `1`.

**Proof.**  
Let `v` be the smallest vertex of the component and `c = colour[v]` (0 or 1).  
If `c = 0` we map colour 0 → 1, colour 1 → 2, otherwise we swap.
Hence `v` receives `1` in both cases. ∎



##### Lemma 4  
The assignment produced by the algorithm is lexicographically minimal among all
valid assignments.

**Proof.**  
Consider the vertices in increasing order.
Take the first vertex `p` where the algorithm’s assignment `A` could differ from
another valid assignment `B`.  
`p` belongs to some component `C`.  
All vertices with index `< p` are in components whose smallest vertex is `< p`,
so by Lemma&nbsp;3 both `A` and `B` already give them the value `1` (the minimal
possible).  
Inside component `C` the smallest vertex is exactly `p`.  
Lemma&nbsp;3 forces any valid assignment to give `p` the value `1`; otherwise the
two colour classes would be swapped and `p` would become `2`, contradicting
validity (since the other colour class would then contain the smallest vertex
with value `2`).  
Therefore `A[p] = 1 ≤ B[p]`.  
If `B[p] = 1` the two assignments coincide on `p` and we continue; otherwise
`A[p] < B[p]`.  
Thus no other valid assignment is lexicographically smaller than `A`. ∎



##### Theorem  
The algorithm outputs  

* “NO” iff no configuration satisfying all links exists;  
* otherwise “YES” and the lexicographically smallest such configuration.

**Proof.**  
If the algorithm prints “NO”, by Lemma&nbsp;1 the graph is not bipartite, hence
no configuration exists.  
If it prints “YES”, the graph is bipartite; Lemma&nbsp;2 guarantees the printed
configuration is valid, and Lemma&nbsp;4 shows it is the lexicographically smallest
one. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*BFS/DFS* visits each vertex once and each edge once: `O(n + m)` time.  
All stored structures (adjacency list, colour array, answer array) need
`O(n + m)` memory.  
Both limits satisfy the problem constraints.

--------------------------------------------------------------------

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 = unvisited, 0/1 = colour
    answer = [0] * (n + 1)           # final configuration (1 or 2)

    from collections import deque

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        while q:
            u = q.popleft()
            cu = colour[u]
            for v in adj[u]:
                if colour[v] == -1:
                    colour[v] = cu ^ 1
                    q.append(v)
                    comp.append(v)
                elif colour[v] == cu:
                    print("NO")
                    return
        # decide orientation: smallest vertex gets 1
        min_v = min(comp)
        if colour[min_v] == 0:
            # colour 0 -> 1, colour 1 -> 2
            for v in comp:
                answer[v] = 1 if colour[v] == 0 else 2
        else:
            # swap
            for v in comp:
                answer[v] = 1 if colour[v] == 1 else 2

    # all good
    print("YES")
    print(' '.join(str(answer[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
