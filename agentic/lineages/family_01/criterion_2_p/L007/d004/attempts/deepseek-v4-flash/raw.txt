We can model this as a graph coloring problem.  
Each tower has a flag 1 or 2, and the state cycles are opposite in order.  
If we look at the states over time, two towers with the same flag will be in the same state at the same time, which would cause conflicts if they are connected.  
Two towers with different flags will be in different states at any time, so they never conflict.  

Thus, the problem reduces to:  
- If the graph is bipartite, assign flag 1 to one partition and flag 2 to the other.  
- If not bipartite, output NO.  

We also need the lexicographically smallest assignment, so we try to assign flag 1 as much as possible (BFS/DFS with priority to 1).  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    # color 0 -> flag 1, color 1 -> flag 2
    print("YES")
    print(" ".join(str(c + 1) for c in color))
```
