We need to check if the graph is bipartite, because the condition “absolute difference between squares is exactly 3” means:

- If one node has amplitude 1 (square = 1), the neighbor must have amplitude 2 (square = 4), difference = 3.
- If one node has amplitude 2 (square = 4), the neighbor must have amplitude 1 (square = 1), difference = 3.

So the graph must be 2-colorable (bipartite).  
We also need the lexicographically smallest assignment, so we assign 1 to the smallest index possible in each component, then BFS/DFS to color.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
