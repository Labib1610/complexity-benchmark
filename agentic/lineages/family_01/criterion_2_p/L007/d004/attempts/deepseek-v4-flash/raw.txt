We can simplify the resonance formula first.  

For grades 1 and 2:

- If both are 1:  
  \( R = 3(1+1) - 2(1)(1) = 6 - 2 = 4 \)
- If one is 1 and the other is 2:  
  \( R = 3(1+2) - 2(1)(2) = 9 - 4 = 5 \)
- If both are 2:  
  \( R = 3(2+2) - 2(2)(2) = 12 - 8 = 4 \)

So the sum is \(5m\) only if every dampener connects pillars with different grades.  
That means the graph must be bipartite, with pillars colored 1 and 2.

We need the lexicographically smallest bipartition coloring (with 1 and 2).  
We can do BFS/DFS, assigning 1 to the first uncolored node, then alternate.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
