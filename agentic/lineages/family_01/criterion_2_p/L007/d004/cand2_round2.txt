# Problem B — Resonant Foundations

Time limit: 1 s
Memory limit: 256 MB

The structural integrity of a new skyscraper depends on $n$ primary load-bearing pillars, numbered 1 to $n$. The engineering firm must select a stiffness coefficient $c_i$ for each pillar $i$. The approved stiffness coefficients are exactly 1 and 2.

To mitigate wind-induced vibrations, the design includes $m$ acoustic dampeners. Each dampener spans between a specific pair of pillars. A dampener's ability to properly distribute stress depends on the stiffness of the two pillars it connects. Specifically, a dampener connecting pillar $u$ and pillar $v$ will safely distribute stress if and only if the product of their stiffness coefficients is exactly 2 ($c_u \times c_v = 2$). If the product is 1 or 4, the dampener shatters under heavy winds.

Your task is to determine if there is a valid stiffness selection for all $n$ pillars such that no dampener shatters. If multiple valid selections exist, the procurement system requires the one that is lexicographically smallest when represented as a sequence of $n$ integers $c_1, c_2, \dots, c_n$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the indices of the two pillars spanned by a dampener.

## Output
If no valid selection exists, print a single line `NO`.
Otherwise print `YES`, then a second line with $n$ integers $c_1 \dots c_n$ (each being 1 or 2), representing the lexicographically smallest valid sequence of stiffness coefficients.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
