# Problem B — Power-Draw Configurations

Time limit: 1 s   Memory limit: 256 MB

A logistics site coordinates $n$ automated delivery vehicles, identified by integers from $1$ to $n$. The site's control software requires at least one active vehicle and imposes a strict maximum fleet capacity of $200,000$.

Each vehicle must be configured with a power-draw setting, which is restricted to exactly $1$ or $2$.

The site contains $m$ shared charging bays. Due to spatial constraints, the total number of bays can be anywhere from zero up to exactly $200,000$. Each bay is dedicated to a specific pair of vehicles.

To prevent electrical faults, the settings of any two vehicles sharing a bay must be complementary. Specifically, the power-draw setting of one vehicle in the pair must be exactly double the power-draw setting of the other.

You must determine if a valid configuration of power-draw settings exists for all $n$ vehicles such that the conditions at all $m$ bays are met. If a valid configuration exists, output it. If there are multiple valid configurations, you must output the one that produces the lexicographically smallest sequence of settings across the vehicles $1$ to $n$.

## Input
The first line provides two integers $n$ and $m$, constrained by the software and spatial limits described above.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ — the numeric identifiers of two vehicles that utilize the same charging bay.

## Output
If no valid configuration is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers (each either $1$ or $2$) representing the lexicographically smallest valid sequence of power-draw settings.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

Removed the explicit mathematical formula `max = 2 * min` and replaced it with a verbal description ("one vehicle ... exactly double ... the other"), which requires the model to deduce that the only valid pair from `{1, 2}` is `(1, 2)`. Additionally, numeric bounds were moved from bare inequalities in the Input section to physical and software limits in the description text, testing whether the model can extract and apply them.
</RATIONALE>
<PRESERVED_ANSWER>
The allowed states are still strictly 1 and 2, and the requirement that one state is double the other forces every connected pair to have distinct states, preserving the exact same valid assignments and lexicographical tie-breaking as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to 2-coloring (bipartiteness checking) on an undirected graph, which is solvable in O(n+m) time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
The bounds being described in text ("at least one", "maximum fleet capacity of 200,000", "zero up to exactly 200,000") could theoretically be overlooked by a sub-par parser, though they are stated unambiguously.
</RISK>
