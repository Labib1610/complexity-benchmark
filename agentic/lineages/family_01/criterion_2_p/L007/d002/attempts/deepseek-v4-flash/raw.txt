We can model this as a graph problem. Each oscillator is a node, and each correlator is an edge. The condition that the product of the two multipliers is exactly 2 means one must be 1 and the other must be 2. So the graph must be bipartite, with the two parts being the nodes assigned 1 and 2.

We need to find a bipartition, and among all valid bipartitions, output the lexicographically smallest assignment of 1s and 2s.

Here’s the approach:

- Build adjacency list from input.
- Use BFS/DFS to color the graph with two colors (1 and 2).
- If any conflict (same color on both ends of an edge), output `NO`.
- For lexicographically smallest, we want as many 1s as possible at the beginning.  
  We can do this by trying to assign 1 to the smallest uncolored node first, then BFS from it, and if a component can be flipped, we choose the orientation that gives more 1s earlier.

A simple way:  
For each connected component, do BFS from the smallest index node.  
Try both colorings (starting with 1 or starting with 2), and pick the one that is lexicographically smaller for that component.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
res = [1] * n

for start in range(n):
    if color[start] != -1:
        continue
    # BFS to get component
    comp = []
    q = deque([start])
    color[start] = 0
    comp.append(start)
    ok = True
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = color[u] ^ 1
                comp.append(v)
                q.append(v)
            elif color[v] == color[u]:
                ok = False
    if not ok:
        print("NO")
        sys.exit()
    # Try both colorings for this component
    # coloring A: start node = 1
    # coloring B: start node = 2
    # We'll build both and pick lexicographically smaller
    # Since color array currently has 0/1 for this comp, we can map
    # 0 -> 1, 1 -> 2 for A
    # 0 -> 2, 1 -> 1 for B
    comp_sorted = sorted(comp)
    seqA = [0] * n
    seqB = [0] * n
    for u in comp:
        seqA[u] = 1 if color[u] == 0 else 2
        seqB[u] = 2 if color[u] == 0 else 1
    # Compare lexicographically on the component indices
    # We only need to compare on comp_sorted
    chooseA = False
    for u in comp_sorted:
        if seqA[u] < seqB[u]:
            chooseA = True
            break
        elif seqA[u] > seqB[u]:
            break
    for u in comp:
        res[u] = seqA[u] if chooseA else seqB[u]

print("YES")
print(" ".join(map(str, res)))
```
