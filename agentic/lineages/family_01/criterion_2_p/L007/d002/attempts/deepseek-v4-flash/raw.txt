We have to choose values \( f_i \in \{1, 2\} \) for each tower such that for every edge \( (u,v) \),  
\[
f_u^{f_v} + f_v^{f_u} = 3
\]

Let's check all 4 possibilities for \( (f_u, f_v) \):

- \( (1,1) \): \( 1^1 + 1^1 = 1+1=2 \) → invalid
- \( (1,2) \): \( 1^2 + 2^1 = 1+2=3 \) → valid
- \( (2,1) \): \( 2^1 + 1^2 = 2+1=3 \) → valid
- \( (2,2) \): \( 2^2 + 2^2 = 4+4=8 \) → invalid

So valid edges must connect a `1` with a `2`. Thus the graph must be bipartite, with all towers being either in part 1 (value `1`) or part 2 (value `2`).  

If the graph is not bipartite → output `NO`.

Otherwise: we want lexicographically smallest assignment.  
We can BFS/DFS color from each unvisited node starting with color 1 (value 1), but we can't always start with 1 — we must check for correctness global bipartition and lexicographic minimality.  
A standard trick: try starting each component with color `1`, then if a conflict occurs during BFS, we switch that component's starting color to `2` if neededwing color.  
But simpler: we BFS+color each component with color 1 for the source; if conflict occurs, output NO. Then we check if flipping some components reduces lexicographic value. Actually, because we always start from smallest index, we can assign greedily smallest possible: … but that could disturb later.  

We can do BFS assigning color `1` at start if possible without contradiction in that component. If we always start at smallest unvisited node with value `1`, the assignment will be lexicographically smallest because we never force a `2` unless needed — but might be impossible though graph is bipartite? Actually, starting with `1` is always safe if graph is bipartite because both colors are symmetric (values 1,2). So we can just BFS from smallest index setting it to 1era? Wait: if it's disconnected, we can always set each component's starting node to 1 to get lexicographically smallest.  

Hence solution: Check bipartiteness via 2-coloring; if not bipartite → NO. Else assign colors as 1/2 via BFS starting with 1 for the smallest unassigned node each time accompanied with standard coloring.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]  # 1 -> 2, 2 -> 1
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(map(str, color)))
```
