**Solution Explanation**

For every tower we have to choose a value `f_i ∈ {1,2}`.
For a critical link `{u,v}` the stability condition is  

```
f_u ^ f_v + f_v ^ f_u = 3
```

(`^` is exponentiation).

--------------------------------------------------------------------

#### 1.   Allowed pairs

```
(1,1) : 1^1 + 1^1 = 2   (invalid)
(1,2) : 1^2 + 2^1 = 1 + 2 = 3   (valid)
(2,1) : symmetric, also valid
(2,2) : 2^2 + 2^2 = 8   (invalid)
```

So on every critical link the two endpoints must have **different**
values, i.e. the whole graph has to be *bipartite* and the two colour
classes correspond to the values `1` and `2`.

--------------------------------------------------------------------

#### 2.   Existence test

We run a BFS/DFS over every connected component, colour vertices with
`0` / `1`.  
If we ever meet an edge whose ends already have the same colour,
the component is not bipartite → answer `NO`.

--------------------------------------------------------------------

#### 3.   Lexicographically smallest assignment

For a bipartite component there are exactly two possible assignments:

* colour `0` → value `1`, colour `1` → value `2`
* colour `0` → value `2`, colour `1` → value `1`

The whole output sequence is compared lexicographically.
Consider the smallest index `v` that belongs to the component.
All vertices with index `< v` are already fixed, therefore the decision
for this component is decided solely by `v` :

*If we give `v` the value `1` the whole sequence becomes smaller,
and this is always possible by choosing the appropriate orientation.*

Hence the optimal rule is:

```
for each component:
        let v = smallest vertex index in the component
        if colour[v] == 0:   colour 0 → 1, colour 1 → 2
        else:                colour 1 → 1, colour 0 → 2
```

Isolated vertices are handled the same way (they become `1`).

--------------------------------------------------------------------

#### 4.   Algorithm
```
read n,m
build adjacency list
answer = array of size n (0‑based)

visited = [False]*n
colour  = [0]*n          # 0 / 1 inside a component

for each vertex i = 0 … n-1:
        if not visited[i]:
                bfs from i
                collect all vertices of this component in list comp
                during bfs check bipartiteness
                if conflict → print NO and exit
                min_v = min(comp)
                if colour[min_v] == 0:
                        map0 = 1 ; map1 = 2
                else:
                        map0 = 2 ; map1 = 1
                for v in comp:
                        answer[v] = map0 if colour[v]==0 else map1

print YES
print answer (1‑based indices)
```

`n, m ≤ 2·10⁵`, BFS/DFS is `O(n+m)` time and `O(n+m)` memory,
well inside the limits.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise prints `YES` and the lexicographically smallest valid
assignment.

---

##### Lemma 1  
For any edge `{u,v}` the stability condition holds **iff**
`f_u ≠ f_v`.

*Proof.* Direct computation of the four possible pairs shown in section 1.
∎



##### Lemma 2  
A configuration satisfying all conditions exists **iff** the graph is
bipartite.

*Proof.*  
*If* the graph is bipartite, colour its two parts with `0` and `1`.  
Assign value `1` to one part and `2` to the other – by Lemma 1 every edge
joins different values, condition holds.

*Only‑if*: suppose a configuration exists. By Lemma 1 every edge connects
different values, therefore vertices with value `1` and with value `2`
form a bipartition of the graph. ∎



##### Lemma 3  
For a bipartite connected component `C` let `v_min` be its smallest
index. There exists a valid assignment for `C` with `f_{v_min}=1`.

*Proof.* Take any bipartition (colours `0/1`). If `v_min` already has colour
`0`, map colour `0 → 1`. Otherwise map colour `1 → 1`. Both mappings are
valid because they only swap the two values globally inside the component.
∎



##### Lemma 4  
The algorithm outputs a valid assignment whenever the graph is bipartite.

*Proof.*  
During BFS each component is coloured properly, otherwise the algorithm
stops with `NO`. By Lemma 3 the algorithm chooses a mapping that gives the
smallest vertex of the component value `1`; all other vertices receive the
opposite value. By Lemma 1 every edge connects different values, therefore
all conditions are satisfied. ∎



##### Lemma 5  
Among all valid assignments the one produced by the algorithm is
lexicographically smallest.

*Proof.*  
Consider the vertices in increasing order.
Let `C` be the component containing the first vertex `i` whose value can
still differ between two valid assignments.
All earlier vertices belong to components already fixed by the algorithm,
hence they have the same values in every optimal assignment.

`i` is the smallest index of `C`. By Lemma 3 there exists a valid
assignment with `f_i = 1`. The algorithm chooses exactly this orientation,
so its value at position `i` is `1`, the minimum possible.
Therefore no other valid assignment can be lexicographically smaller.
∎



##### Lemma 6  
If the algorithm prints `NO` then no valid assignment exists.

*Proof.* The algorithm prints `NO` only when it discovers an edge whose
endpoints have the same BFS colour, i.e. an odd cycle. Hence the graph is
not bipartite. By Lemma 2 a valid assignment would imply bipartiteness,
contradiction. ∎



##### Theorem  
The program prints  

* `NO` iff the required configuration does not exist;  

* otherwise `YES` followed by the lexicographically smallest valid
  configuration.

*Proof.*  
- If the program prints `NO`, by Lemma 6 no configuration exists.  
- If the program prints `YES`, the graph is bipartite, and by Lemma 4 the
  printed assignment is valid. By Lemma 5 it is the lexicographically
  smallest among all valid assignments. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis

*Time* : each vertex and each edge is processed once → `O(n + m)`  
*Memory*: adjacency list + a few arrays of size `n` → `O(n + m)`

Both satisfy the limits.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    visited = [False] * n
    colour = [0] * n          # 0 / 1 inside a component
    ans = [0] * n

    for start in range(n):
        if visited[start]:
            continue
        # BFS this component
        q = deque([start])
        visited[start] = True
        colour[start] = 0
        comp = [start]
        ok = True
        while q:
            v = q.popleft()
            for to in adj[v]:
                if not visited[to]:
                    visited[to] = True
                    colour[to] = colour[v] ^ 1
                    q.append(to)
                    comp.append(to)
                elif colour[to] == colour[v]:
                    # not bipartite
                    print("NO")
                    return
        # choose orientation: smallest index gets value 1
        min_v = min(comp)
        if colour[min_v] == 0:
            map0, map1 = 1, 2
        else:
            map0, map1 = 2, 1
        for v in comp:
            ans[v] = map0 if colour[v] == 0 else map1

    # all components processed
    print("YES")
    print(' '.join(map(str, ans)))

if __name__ == "__main__":
    solve()
```

conforms to the required input‑output format.
