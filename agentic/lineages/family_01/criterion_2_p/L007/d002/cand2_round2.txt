# Problem B — Network Configurations

Time limit: 1 s
Memory limit: 256 MB

A communication grid is composed of $n$ radio towers. Each tower must be assigned an operational setting of either 1 or 2.

The network includes $m$ critical links, each connecting a specific pair of towers. To avoid signal interference across these connections, the settings of the two linked towers must yield a quotient of exactly 2 when the larger setting is divided by the smaller setting.

Determine if there is a valid way to configure all towers in the grid. If no such configuration is possible, report this impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of towers connected by a critical link.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $f_1 \dots f_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The affordance "sum to exactly 3" was a direct trigger for models to recognize that the two values must be different, immediately reducing the problem to testing for bipartiteness. This was replaced with a mathematically equivalent but less structurally obvious condition: requiring the larger setting divided by the smaller setting to equal exactly 2. Models must now deduce that with only values 1 and 2 available, this quotient condition enforces that linked towers cannot share the same value.
</RATIONALE>
<PRESERVED_ANSWER>
The allowed values are exactly 1 and 2; the only pair of these values that yields a quotient of 2 is {1, 2}, which is logically identical to requiring their sum to be 3.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring for an undirected graph (bipartiteness testing), which is solvable in O(n+m) time using BFS or DFS.
</PRESERVED_CLASS>
