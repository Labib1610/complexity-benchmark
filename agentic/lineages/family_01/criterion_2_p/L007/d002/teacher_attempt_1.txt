<STATEMENT>
# Problem B — Calibration Sequence

Time limit: 1 s
Memory limit: 256 MB

A precision manufacturing machine consists of $n$ adjustable actuators, numbered 1 to $n$. The facility design requires at least one actuator and can structurally support up to $2 \cdot 10^5$. The machine's stability is maintained by $m$ mechanical linkages, which can be entirely absent or number up to $2 \cdot 10^5$. Each linkage connects two specific actuators.

Each actuator must be calibrated to a voltage level of either 1 or 2. To maintain equilibrium, any linkage connecting two actuators requires the average of their assigned voltage levels to be exactly 1.5.

You must determine if there is a valid configuration for all $n$ actuators that satisfies all equilibrium conditions. If a valid configuration exists, you must output it. In cases where multiple configurations satisfy all conditions, you must output the configuration that forms the lexicographically smallest sequence of voltage levels.

## Input
The first line contains two integers $n$ and $m$, representing the number of actuators and linkages respectively (the limits on these values are defined by the facility capacities described above).
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of two actuators connected by a linkage.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, followed by a second line containing $n$ integers $s_1 \dots s_n$ (each being 1 or 2), representing the lexicographically smallest valid calibration sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I moved the numeric bounds into the scenario description as physical facility limits rather than placing them as bare inequalities in the input section. I also replaced the explicit sum-to-3 constraint with a requirement that the average voltage must be exactly 1.5, which obscures the complementary sum that previously triggered bipartite coloring algorithms, forcing models to deduce the mutually exclusive assignment requirement mathematically.
</RATIONALE>
<PRESERVED_ANSWER>
The average of two values from {1, 2} is 1.5 if and only if one value is 1 and the other is 2, which is mathematically identical to their sum being 3, ensuring all valid configurations remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring of a graph (or determining none exists) and selecting the lexicographically smallest one, which is solvable in O(n+m) time using Breadth-First or Depth-First Search.
</PRESERVED_CLASS>
<RISK>
Models might overthink the word "average" and attempt floating-point arithmetic instead of realizing it strictly enforces a discrete condition, but "exactly 1.5" mathematically restricts it unambiguously.
</RISK>
