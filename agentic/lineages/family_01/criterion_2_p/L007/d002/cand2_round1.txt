# Problem B — Network Configurations

Time limit: 1 s
Memory limit: 256 MB

A communication grid consists of $n$ radio towers. The central registry's memory allocation permits indexing up to 200,000 such towers (requiring at least one to be operational). The maintenance budget can support up to 200,000 critical links between specific pairs of towers, though an entirely unlinked deployment is also permitted.

You need to assign each tower a configuration value, which must be either 1 or 2. 

To prevent signal degradation, the configuration values across any critical link must satisfy a specific ratio: the quotient obtained by dividing the maximum of the two configuration values by the minimum of the two must be exactly 2.

Determine if a valid assignment exists for all towers. If no such assignment is possible, report impossibility.

## Input
The first line contains two integers $n$ and $m$, representing the number of towers and the number of critical links, respectively. The bounds for these values are governed by the operational limits described above.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of towers connected by a critical link.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $f_1 \dots f_n$ (each in $\{1,2\}$), the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The direct "sum to exactly 3" constraint was replaced with a requirement that dividing the maximum configuration value by the minimum yields exactly 2. This forces models to deduce that the values must be strictly different (since 2/2=1 and 1/1=1), breaking the superficial pattern-matching to standard bipartiteness templates while preserving the exact same mathematical restriction. The numeric bounds were also shifted into the scenario description as physical limits to satisfy the S07 strategy.
</RATIONALE>
<PRESERVED_ANSWER>
For values restricted to {1, 2}, the only pair that yields a quotient of 2 when dividing the maximum by the minimum is the pair {1, 2}, which is exactly the same set of valid pairs as those that sum to 3.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying constraint still strictly requires adjacent nodes in the link graph to have different values from a set of size 2, keeping the problem identical to 2-coloring (testing bipartiteness) and solvable in linear time using BFS/DFS.
</PRESERVED_CLASS>
