**Solution Explanation**

For every sensor we have to choose a basis `1` or `2`.

```
C1 = [[1,1],[1,1]]
C2 = [[1,-1],[-1,1]]
```

For an interference link `{u,v}` the sum `Cu + Cv` must be invertible.

```
C1 + C1 = [[2,2],[2,2]]          det = 0   (singular)
C2 + C2 = [[2,-2],[-2,2]]        det = 0   (singular)
C1 + C2 = [[2,0],[0,2]]          det = 4   (non‑singular)
```

So a link is **good** *iff* the two endpoints use **different** bases.
The whole problem is therefore exactly the classic *2‑colouring* (graph
bipartition) problem:

* assign colour `1` or `2` to every vertex,
* adjacent vertices must have different colours.

If the graph is not bipartite the answer is `NO`.
Otherwise many colourings exist – each connected component can be flipped
(`1 ↔ 2`).  
We have to output the **lexicographically smallest** valid assignment,
i.e. the smallest possible value for sensor 1, then for sensor 2, …

--------------------------------------------------------------------

#### Lemma 1  
Consider one connected component. Let `v` be the smallest numbered vertex
inside this component.  
Among the two possible colourings of the component, the lexicographically
smaller one is the one that gives `v` colour `1`.

*Proof.*  
All vertices with index `< v` belong to other components, already fixed.
Inside the component the two colourings are identical except that all
colours are swapped.  
Therefore the first position where they differ is exactly `v`.  
Choosing colour `1` for `v` makes the whole array smaller. ∎



#### Consequence  
Processing vertices in increasing order, whenever we meet an unvisited
vertex `i` we start a BFS/DFS from it, fix its colour to `1` and propagate
alternating colours. This automatically yields the lexicographically
smallest global assignment.

--------------------------------------------------------------------

#### Algorithm
```
read n,m
build adjacency list
colour[1..n] = 0   (0 = unvisited, 1 = basis 1, 2 = basis 2)

for i = 1 .. n
    if colour[i] == 0
        colour[i] = 1                     # smallest vertex of this component gets 1
        queue = [i]
        while queue not empty
            v = pop
            for each neighbour w of v
                if colour[w] == 0
                    colour[w] = 3 - colour[v]   # opposite colour
                    push w
                elif colour[w] == colour[v]      # same colour on an edge -> not bipartite
                    print "NO" and exit

print "YES"
print colour[1] … colour[n] separated by spaces
```

`3 - colour` works because colours are only `1` and `2`.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise prints the lexicographically smallest valid assignment.

---

##### Lemma 2  
If the algorithm prints `NO`, the graph is not bipartite, therefore no
valid assignment exists.

*Proof.*  
`NO` is printed only when during BFS an edge `{v,w}` with
`colour[v] == colour[w]` is found. All colours were assigned by the rule
“neighbour gets opposite colour”, so the existence of such an edge creates
an odd cycle, i.e. the graph is not bipartite. As shown at the beginning,
a valid assignment requires a proper 2‑colouring, which is impossible. ∎



##### Lemma 3  
If the algorithm finishes without printing `NO`, the produced array
`colour[1..n]` is a valid assignment.

*Proof.*  
The algorithm assigns colours only by the rule “neighbour gets opposite
colour”. Therefore for every processed edge `{v,w}` we have
`colour[v] != colour[w]`. Because every vertex is eventually visited,
this holds for **all** edges, i.e. the assignment satisfies the required
condition. ∎



##### Lemma 4  
Assume the graph is bipartite. For each connected component the algorithm
outputs the lexicographically smallest colouring of that component.

*Proof.*  
When the first (smallest indexed) vertex `i` of a component is met,
the algorithm fixes `colour[i]=1`. By Lemma&nbsp;1 this is exactly the
choice that yields the smallest possible colour for the whole component.
All other vertices are forced uniquely by the alternating rule, so the
component’s colouring is the lexicographically smallest one. ∎



##### Lemma 5  
Assume the graph is bipartite. The whole array printed by the algorithm
is the lexicographically smallest valid assignment.

*Proof.*  
Components are processed in increasing order of their smallest vertex.
By Lemma&nbsp;4 each component is coloured minimally **given** the colours
already fixed for earlier vertices (which belong to earlier components).
Thus after processing component after component, no later decision can
change any earlier entry, and each entry is as small as possible.
Consequently the final concatenated array is the global lexicographically
minimum. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no assignment satisfying all interference links exists;  
* otherwise `YES` followed by the lexicographically smallest valid
  assignment.

*Proof.*  
*If* the algorithm prints `NO`, by Lemma&nbsp;2 no assignment exists.  
*If* it finishes, by Lemma&nbsp;3 the assignment is valid, and by
Lemma&nbsp;5 it is the lexicographically smallest one.  
Conversely, if a valid assignment exists, the graph is bipartite, so the
algorithm never encounters a same‑colour edge and therefore does not print
`NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once,
`O(n + m)` time.  

Total time `O(n + m)` ≤ `4·10⁵`, well inside the 1 s limit.  
Memory consumption `O(n + m)` ≤ `~4·10⁵` integers, far below 256 MB.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [0] * (n + 1)          # 0 = unvisited, 1 or 2 = basis

    for i in range(1, n + 1):
        if colour[i]:
            continue
        colour[i] = 1               # smallest vertex of this component gets 1
        q = deque([i])
        while q:
            v = q.popleft()
            cv = colour[v]
            for w in adj[v]:
                if colour[w] == 0:
                    colour[w] = 3 - cv   # opposite colour
                    q.append(w)
                elif colour[w] == cv:
                    sys.stdout.write("NO")
                    return

    out = ["YES\n"]
    out.append(' '.join(str(colour[i]) for i in range(1, n + 1)))
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```
