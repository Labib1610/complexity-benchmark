**Solution Explanation**

For every office `v` ( `1 … n` ) and for every classification `i`
( `1 … k` ) we create a *copy* `v_i`.
Only the copies of the same classification may exchange dossiers,
therefore the copies are completely independent – they form `k`
disjoint layers of the original graph.

All classifications use the same transfer protocols.
For a protocol `e : u → v` with daily quota `cap`
the total number of dossiers of **all** classifications that use this
protocol must not exceed `cap`.
We enforce this by a *capacity node* :

```
u_i  ──►  e_in  ──►  e_out  ──►  v_i
        (∞)      (cap)      (∞)
```

`e_in → e_out` has capacity `cap`, all other edges have infinite
capacity.  
Thus the sum of the flows of all layers through `e` is limited by `cap`.

The whole construction is a single‑commodity flow problem:

* a super source `S` is connected to every source copy `s_i_i`
  with capacity `d_i` (the required number of dossiers of classification `i`);
* every sink copy `t_i_i` is connected to a super sink `T`
  with capacity `d_i`.

If a flow of value ` Σ d_i ` can be sent from `S` to `T`,
all demands are satisfied and the flow on the edges
`u_i → e_in` tells how many dossiers of classification `i`
use protocol `e`.

The network is a directed graph with at most  

```
k·n          copy nodes
2·m          capacity nodes (e_in , e_out)
2            S , T
```

edges – easily small enough for Dinic’s algorithm
(`O(E·√V)` in practice, far below the limits).

The construction is *integral*: all capacities are integers,
Dinic returns an integral maximum flow,
hence the obtained per‑classification numbers are integers as required.



--------------------------------------------------------------------

#### Algorithm
```
read n , m , k
read classifications (s[i], t[i], d[i])      i = 0 … k-1
read protocols (u[j], v[j], cap[j])          j = 0 … m-1

node id:
    copy(v,i) = i·n + (v-1)                (0‑based)
    base = k·n
    e_in (j)  = base + 2·j
    e_out(j)  = base + 2·j + 1
    S = base + 2·m
    T = S + 1

build Dinic graph
    for each i:
        add_edge(S , copy(s[i],i) , d[i])
        add_edge(copy(t[i],i) , T , d[i])

    for each protocol j (u→v, cap):
        add_edge(e_in(j) , e_out(j) , cap)                // capacity node
        for each i = 0 … k-1:
            add_edge( copy(u-1,i) , e_in(j) , INF )
            add_edge( e_out(j) , copy(v-1,i) , INF )
            remember the forward edge id of (copy(u-1,i) → e_in(j))
            → this edge will later give the answer for (i , j)

run Dinic max flow from S to T
if flow value != Σ d[i] :   print "NO" and stop

print "YES"
for i = 0 … k-1:
    for j = 0 … m-1:
        edge = remembered forward edge (copy(s_i) → e_in(j))
        used = edge.original_cap - edge.cap   // flow sent through it
        output used
```

`INF` can be any number larger than the total demand,
e.g. `10**18`.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints **YES** and a correct routing
iff such a routing exists.

---

##### Lemma 1  
For every protocol `e` the total flow that passes through the node
`e_in → e_out` equals the sum of flows of all classifications that use
this protocol, and is bounded by `cap(e)`.

**Proof.**  
All edges entering `e_in` come from copies `u_i` and have infinite
capacity, all edges leaving `e_out` go to copies `v_i` and also have
infinite capacity.
The only edge with finite capacity on the way from `u_i` to `v_i`
is `e_in → e_out` with capacity `cap(e)`.  
Therefore the amount of flow that can travel from any `u_i` to any
`v_i` via this construction is limited by `cap(e)`, and the flow that
actually uses the protocol is exactly the flow through that edge. ∎



##### Lemma 2  
If the constructed network admits a flow of value `Σ d_i`,
then for each classification `i` the net flow out of its source copy
` s_i_i ` equals `d_i` and the net flow into its sink copy ` t_i_i `
equals `d_i`, while all other copies satisfy flow conservation.

**Proof.**  
The only edges incident to `s_i_i` are `S → s_i_i` (capacity `d_i`) and
edges to protocol nodes. Because the edge from `S` has capacity `d_i`,
the total flow that can leave `s_i_i` is at most `d_i`.  
If the total flow value equals `Σ d_i`, every edge `S → s_i_i`
must be saturated, otherwise the total flow would be smaller.
Thus exactly `d_i` units leave `s_i_i`.  
Analogously, exactly `d_i` units must enter `t_i_i` to be able to leave
through `t_i_i → T`.  
All other copy nodes have only incoming and outgoing edges of the
form `copy → e_in` and `e_out → copy`; they have no external source or
sink, therefore flow conservation holds for them. ∎



##### Lemma 3  
From a feasible flow of value `Σ d_i` we can construct a routing that
satisfies all problem constraints, and the number of dossiers of
classification `i` using protocol `j` equals the flow on edge
`copy(s_i) → e_in(j)`.

**Proof.**  
Consider classification `i`.  
Because of Lemma&nbsp;2 the flow that enters `s_i_i` equals `d_i` and
leaves `t_i_i` equals `d_i`.  
Inside layer `i` the flow respects the original graph edges:
whenever one unit of flow goes from `copy(u,i)` to `e_in(j)` and then
through `e_in(j) → e_out(j)` to `copy(v,i)`, we interpret it as sending
one dossier of classification `i` through protocol `j : u→v`.  
All flow conservation statements of Lemma&nbsp;2 translate exactly to
the required balance conditions of the statement of the problem.
By Lemma&nbsp;1 the sum over all classifications of the used amount on
protocol `j` does not exceed its quota `cap(j)`.  
Thus the obtained routing is feasible and the amount on protocol `j`
for classification `i` is precisely the flow on the edge
`copy(u,i) → e_in(j)`. ∎



##### Lemma 4  
If a feasible routing exists, the constructed network admits a flow of
value `Σ d_i`.

**Proof.**  
Take the given routing. For every dossier of classification `i`
that uses protocol `j : u→v` send one unit of flow
`S → s_i_i → copy(u,i) → e_in(j) → e_out(j) → copy(v,i) → t_i_i → T`.
All capacities are respected:
* edges `S → s_i_i` and `t_i_i → T` carry exactly `d_i`;
* each protocol node `e_in → e_out` carries the total number of dossiers
  that use this protocol, which by feasibility is ≤ `cap(j)`;
* all other edges have infinite capacity.
Thus we built a feasible flow of total value `Σ d_i`. ∎



##### Lemma 5  
The algorithm outputs “YES” and a matrix of numbers **iff**
a feasible routing exists.

**Proof.**  
*If* the algorithm outputs “YES”, it has found a flow of value `Σ d_i`.
By Lemma&nbsp;3 the extracted numbers give a feasible routing.

*Only‑if*: if a feasible routing exists, Lemma&nbsp;4 guarantees a flow
of value `Σ d_i` in the network, therefore Dinic’s algorithm will find
such a flow and the program will output “YES”. ∎



##### Theorem  
The program prints “YES” followed by a correct per‑classification
distribution of dossiers over protocols exactly when such a distribution
exists; otherwise it prints “NO”.

**Proof.** Directly from Lemma&nbsp;5. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

```
V = k·n + 2·m + 2          ≤  (k·n) + 2·m + 2
E = k·m·2   (two edges per (i,protocol))  + 2·m (capacity edges) + 2·k (source/sink)
    ≤ 2·k·m + 2·m + 2·k
```

Dinic runs in `O(E·√V)` in practice; with the given limits
(`n,m ≤ 500`, `k ≤ 10` in typical tests) this is far below the
5‑second limit.

Memory consumption is `O(E)` for the adjacency lists – well under
256 MiB.

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

INF = 10 ** 18

class Dinic:
    def __init__(self, n):
        self.n = n
        self.adj = [[] for _ in range(n)]

    def add_edge(self, u, v, cap):
        fwd = [v, cap, None]          # to, cap, rev
        rev = [u, 0, fwd]
        fwd[2] = rev
        self.adj[u].append(fwd)
        self.adj[v].append(rev)
        return fwd                     # return forward edge for later inspection

    def bfs_level(self, s, t):
        level = [-1] * self.n
        q = [s]
        level[s] = 0
        for u in q:
            for v, cap, _ in self.adj[u]:
                if cap and level[v] == -1:
                    level[v] = level[u] + 1
                    q.append(v)
        self.level = level
        return level[t] != -1

    def dfs(self, u, t, f):
        if u == t:
            return f
        for i in range(self.it[u], len(self.adj[u])):
            self.it[u] = i
            v, cap, rev = self.adj[u][i]
            if cap and self.level[v] == self.level[u] + 1:
                ret = self.dfs(v, t, min(f, cap))
                if ret:
                    self.adj[u][i][1] -= ret
                    rev[1] += ret
                    return ret
        return 0

    def max_flow(self, s, t):
        flow = 0
        while self.bfs_level(s, t):
            self.it = [0] * self.n
            while True:
                pushed = self.dfs(s, t, INF)
                if not pushed:
                    break
                flow += pushed
        return flow


def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))

    s = []
    t = []
    d = []
    for _ in range(k):
        s.append(int(next(it)) - 1)
        t.append(int(next(it)) - 1)
        d.append(int(next(it)))

    u = []
    v = []
    cap = []
    for _ in range(m):
        u.append(int(next(it)) - 1)
        v.append(int(next(it)) - 1)
        cap.append(int(next(it)))

    # node ids
    def copy_id(vv, ii):
        return ii * n + vv

    base = k * n
    e_in = [base + 2 * j for j in range(m)]
    e_out = [base + 2 * j + 1 for j in range(m)]
    S = base + 2 * m
    T = S + 1
    N = T + 1

    dinic = Dinic(N)

    # source / sink edges
    total_need = 0
    for i in range(k):
        dinic.add_edge(S, copy_id(s[i], i), d[i])
        dinic.add_edge(copy_id(t[i], i), T, d[i])
        total_need += d[i]

    # remember edges for answer
    edge_ref = [[None] * m for _ in range(k)]

    for j in range(m):
        # capacity node
        dinic.add_edge(e_in[j], e_out[j], cap[j])
        for i in range(k):
            # copy(u,i) -> e_in
            fwd = dinic.add_edge(copy_id(u[j], i), e_in[j], INF)
            edge_ref[i][j] = fwd
            # e_out -> copy(v,i)
            dinic.add_edge(e_out[j], copy_id(v[j], i), INF)

    flow = dinic.max_flow(S, T)
    if flow != total_need:
        print("NO")
        return

    print("YES")
    out_lines = []
    for i in range(k):
        line = []
        for j in range(m):
            fwd = edge_ref[i][j]
            used = fwd[1] ^ INF  # not correct, need original cap - residual
            # we stored original cap as INF, so flow = INF - residual
            used = INF - fwd[1]
            line.append(str(used))
        out_lines.append(' '.join(line))
    sys.stdout.write('\n'.join(out_lines))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
