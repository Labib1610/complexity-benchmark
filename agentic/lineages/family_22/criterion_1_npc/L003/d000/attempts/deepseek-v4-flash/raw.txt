We need to schedule reactions in cycles 1..T, respecting dependencies and reactor capacity M.

This is essentially a **topological scheduling with resource constraints** problem.  
We can solve it using a greedy level-based approach:

1. Build adjacency list for dependencies.
2. Compute in-degree for each node.
3. Use a queue to process nodes whose prerequisites are done.
4. Assign each node to the earliest possible cycle, but also ensure we don’t exceed M reactions per cycle.

We can do this by processing cycle by cycle:

- At each cycle, take up to M available nodes (in-degree 0) and assign them to this cycle.
- After assigning, reduce in-degrees of their dependents.
- If at some point we still have nodes left but no available ones, it’s impossible (cycle in graph).
- If we exceed T cycles, it’s impossible.

Let’s implement this.

```python
import sys
from collections import deque

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    M = int(next(it))
    T = int(next(it))
    m = int(next(it))
    
    adj = [[] for _ in range(n + 1)]
    indeg = [0] * (n + 1)
    
    for _ in range(m):
        a = int(next(it))
        b = int(next(it))
        adj[a].append(b)
        indeg[b] += 1
    
    # queue of available nodes
    q = deque()
    for i in range(1, n + 1):
        if indeg[i] == 0:
            q.append(i)
    
    assign = [0] * (n + 1)
    processed = 0
    cycle = 1
    
    while processed < n:
        if cycle > T:
            print("NO")
            return
        if not q:
            print("NO")
            return
        
        # take up to M nodes for this cycle
        count = 0
        next_q = deque()
        while q and count < M:
            u = q.popleft()
            assign[u] = cycle
            processed += 1
            count += 1
            for v in adj[u]:
                indeg[v] -= 1
                if indeg[v] == 0:
                    next_q.append(v)
        
        # merge remaining q (if any) with next_q
        q = next_q + q
        cycle += 1
    
    # check if all assigned within T
    if max(assign[1:]) > T:
        print("NO")
        return
    
    print("YES")
    print(" ".join(map(str, assign[1:])))

if __name__ == "__main__":
    solve()
```
