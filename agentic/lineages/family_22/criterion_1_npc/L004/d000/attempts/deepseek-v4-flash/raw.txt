We need to assign each relic to a room (1 to T) such that:

- Each room has at most M relics.
- If there is a rule `a b`, then room(a) < room(b).

This is essentially a topological ordering problem with capacity constraints.

We can model it as follows:

- Build a DAG from the rules.
- We need to assign each node a room number such that all edges go from lower room to higher room.
- Each room can hold at most M nodes.

A greedy approach works:

1. Compute in-degrees.
2. Use a min-heap (or priority queue) to always assign the smallest possible room to nodes that are ready (in-degree 0).
3. We process rooms from 1 to T. In each room, we can place up to M nodes that are currently ready.
4. If at any point we run out of rooms before placing all nodes, output NO.

We need to be careful: if a node is ready, we can place it in the current room. But if we place it in a later room, that's also fine, but we want to use the earliest possible to avoid running out of rooms.

So algorithm:

- Initialize in-degree array.
- Build adjacency list.
- Push all nodes with in-degree 0 into a min-heap.
- For room from 1 to T:
  - For up to M times:
    - If heap is empty, break.
    - Pop smallest node, assign it to current room.
    - Decrease in-degree of its neighbors; if any becomes 0, push to heap.
  - If heap is empty and all nodes assigned, we can stop early (but we still need to output room numbers for all).
- After processing all rooms, if any node unassigned, output NO.

But careful: We must assign all nodes. If we finish all nodes before using all rooms, that's fine.

Let's implement.

Edge cases:
- If there is a cycle, topological sort impossible → NO.
- If T * M < n → impossible.

Let's code.```python
import sys
import heapq

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    M = int(next(it))
    T = int(next(it))
    m = int(next(it))
    
    adj = [[] for _ in range(n + 1)]
    indeg = [0] * (n + 1)
    
    for _ in range(m):
        a = int(next(it))
        b = int(next(it))
        adj[a].append(b)
        indeg[b] += 1
    
    # If total capacity is less than number of relics, impossible
    if T * M < n:
        print("NO")
        return
    
    heap = []
    for i in range(1, n + 1):
        if indeg[i] == 0:
            heapq.heappush(heap, i)
    
    room_assignment = [0] * (n + 1)
    assigned_count = 0
    
    for room in range(1, T + 1):
        placed = 0
        # Place up to M relics in this room
        while placed < M and heap:
            node = heapq.heappop(heap)
            room_assignment[node] = room
            assigned_count += 1
            placed += 1
            
            for nxt in adj[node]:
                indeg[nxt] -= 1
                if indeg[nxt] == 0:
                    heapq.heappush(heap, nxt)
        
        if assigned_count == n:
            # All assigned, we can stop early
            break
    
    if assigned_count < n:
        print("NO")
        return
    
    # Check if all room numbers are within 1..T
    # They are by construction
    print("YES")
    print(" ".join(str(room_assignment[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
