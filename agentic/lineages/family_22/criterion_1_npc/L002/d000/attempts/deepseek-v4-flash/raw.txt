We need to assign each dish to a stage from 1 to T, respecting:

1. Each stage has at most M dishes.
2. If there is an edge a → b, then stage(a) < stage(b).

This is essentially a scheduling problem on a DAG (if there’s a cycle, it’s impossible).  
We can solve it using a topological sort with capacity constraints.

**Approach:**
- Build adjacency list and indegree array.
- If there’s a cycle → output `NO`.
- Use a min-heap (or queue) to assign stages level by level, but we must respect capacity M per stage.
- We can assign dishes to the earliest possible stage, filling up to M per stage.

We can do a BFS-like topological sort:
- Start with nodes with indegree 0.
- Assign them to current stage, but if current stage already has M dishes, move to next stage.
- After assigning a node, reduce indegree of its neighbors; if a neighbor’s indegree becomes 0, add it to the queue for the next available stage.

We must ensure we don’t assign a node to a stage ≤ its prerequisite’s stage. Since we process in topological order, assigning to the earliest possible stage works.

**Implementation details:**
- Use a queue of nodes ready to be placed.
- Keep track of current stage and count in that stage.
- If queue is empty but not all nodes processed → cycle → NO.

Let’s write the code.

```python
import sys
from collections import deque

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    M = int(next(it))
    T = int(next(it))
    m = int(next(it))
    
    adj = [[] for _ in range(n)]
    indeg = [0] * n
    
    for _ in range(m):
        a = int(next(it)) - 1
        b = int(next(it)) - 1
        adj[a].append(b)
        indeg[b] += 1
    
    q = deque()
    for i in range(n):
        if indeg[i] == 0:
            q.append(i)
    
    stage = [0] * n
    current_stage = 1
    count_in_stage = 0
    processed = 0
    
    while q:
        # If current stage is full, move to next
        if count_in_stage == M:
            current_stage += 1
            count_in_stage = 0
            if current_stage > T:
                print("NO")
                return
        
        u = q.popleft()
        stage[u] = current_stage
        count_in_stage += 1
        processed += 1
        
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    
    if processed != n:
        print("NO")
        return
    
    # Check if any stage exceeds T
    if max(stage) > T:
        print("NO")
        return
    
    print("YES")
    print(" ".join(str(x) for x in stage))

if __name__ == "__main__":
    solve()
```
