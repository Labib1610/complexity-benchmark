<STATEMENT>
# Problem B — Synthesizing the Target Substructure

Time limit: 2 s   Memory limit: 256 MB

## Description

A newly discovered macromolecule consists of **n** functional groups (numbered 1 to n). The molecule is held together by **m** chemical bonds. The structure is fully contiguous, and due to the specific valency of its components, the removal of any single bond would inevitably split the molecule into two completely separate pieces.

Among the functional groups, exactly **t** have been tagged with a rare isotope. Your goal is to isolate a single, intact fragment of the molecule that contains all **t** of these tagged groups. 

Isolating a fragment involves applying a chemical stabilizer to the bonds you wish to keep intact, while allowing all unstabilized bonds to naturally dissolve. Applying stabilizer to the bond between group **u** and group **v** requires **w** units of stabilizer. Dissolving a bond requires zero stabilizer. 

Determine the minimum total amount of stabilizer needed to preserve a single fragment that includes every tagged group.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers: the identifiers of the tagged functional groups.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): indicating a bond between functional group u and functional group v that requires w units of stabilizer to preserve. The bonds follow the structural properties described above.

## Output

Print a single integer: the minimum total amount of stabilizer required to maintain a single fragment containing all tagged groups.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the tagged groups 1 and 4 can only be kept in the same fragment if groups 2 and 3 are also included. Thus, all three bonds must be stabilized, requiring 5 + 1 + 2 = 8 units of stabilizer. In Example 2, there is only one tagged group, so a fragment consisting of just that single group is sufficient, requiring 0 bonds to be stabilized.

<RATIONALE>
The problem was completely reframed from a hospital fiber-optic network to a macromolecule with chemical bonds. The tree property is no longer explicitly handed to the model as "exactly one possible route"; instead, it is described physically ("removal of any single bond would inevitably split the molecule"), forcing the model to deduce the unique-path and acyclic properties from the structural constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The objective remains to find the minimum-weight connected subgraph containing a specific set of vertices, meaning the sum of edge weights for the minimal spanning subtree of the required nodes is identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying graph is still a tree and the problem still asks for the minimal subtree covering a subset of nodes, which can be solved in O(n) time using post-order traversal to count required nodes per subtree.
</PRESERVED_CLASS>
<RISK>
Models might overthink the phrase "allowing all unstabilized bonds to naturally dissolve" and wonder if the dissolved components incur a penalty, but the text explicitly states "Dissolving a bond requires zero stabilizer," making the cost function unambiguous.
</RISK>
