<STATEMENT>
# Document Routing Consolidation

Time limit: 2 s   Memory limit: 256 MB

## Description

A corporate headquarters consists of $n$ departments. Exactly $t$ of these departments are designated as **Auditing Offices**.

The headquarters has a legacy network of $m$ undirected pneumatic tube lines, each connecting a pair of departments. The available lines form a single connected network spanning all $n$ departments. The system was built with no redundancies, meaning there are exactly $m = n - 1$ lines in total.

Each line requires a specific maintenance budget to remain operational. You must select a subset of these lines to keep active. The retained lines must ensure that all $t$ Auditing Offices belong to the same connected communication zone (i.e., any Auditing Office can route documents to any other Auditing Office using only the retained lines, possibly passing through other intermediate departments). Lines that are not selected are decommissioned and provide no connectivity.

Your objective is to determine the minimum total maintenance budget required for the selected subset of lines.

## Input

The first line of the document contains three integers: $n$, $m$, and $t$.
- $n$ is the total number of departments. The headquarters contains at least 1 department and at most 200000.
- $m$ is the number of available lines, which is exactly $n - 1$.
- $t$ is the number of Auditing Offices, which is at least 1 and at most $n$.

The second line contains $t$ distinct integers: the identifiers of the Auditing Offices (from 1 to $n$).

Each of the next $m$ lines details an available undirected line with three integers: $u$, $v$, and $w$.
- $u$ and $v$ are distinct department identifiers (from 1 to $n$) connected by the line.
- $w$ is the maintenance budget required to keep this line active. This cost is a positive integer not exceeding 1000000.

The available lines are guaranteed to connect all $n$ departments into a single connected network with exactly $n - 1$ lines.

## Output

Print a single integer: the minimum total maintenance budget required to ensure all Auditing Offices are in the same connected zone using only the selected lines.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the Auditing Offices 1 and 4 must be in the same connected zone. Retaining the lines between 1-2, 2-3, and 3-4 achieves this for a total cost of 5 + 1 + 2 = 8. In Example 2, there is only one Auditing Office. An isolated department forms a valid connected zone for the required offices, requiring zero retained lines, so the minimum cost is 0.
