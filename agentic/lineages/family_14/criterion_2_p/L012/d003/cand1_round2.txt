<STATEMENT>
# Document Routing Consolidation

Time limit: 2 s   Memory limit: 256 MB

## Description

A corporate headquarters consists of $n$ departments. Exactly $t$ of these departments are designated as **Auditing Offices**.

The headquarters has a legacy network of $m$ undirected pneumatic tube lines, each connecting a pair of departments. The layout of these available lines integrates all $n$ departments into a single fully connected infrastructure, meaning a carrier can travel between any two departments using some sequence of lines. The total number of available lines is strictly $m = n - 1$.

Each line requires a specific maintenance budget to remain operational. You must select a subset of these lines to keep active. The selected lines must form a functional routing system where all $t$ Auditing Offices are mutually reachable (meaning any Auditing Office can route documents to any other Auditing Office, possibly passing through other departments). Lines that are not selected are decommissioned and provide no connectivity.

Your objective is to determine the minimum total maintenance budget required to select a valid subset of lines.

## Input

The first line of the document contains three integers: $n$, $m$, and $t$.
- $n$ is the total number of departments. The headquarters contains at least 1 department and at most 200000.
- $m$ is the number of available lines, which is exactly $n - 1$.
- $t$ is the number of Auditing Offices, which is at least 1 and at most $n$.

The second line contains $t$ distinct integers: the identifiers of the Auditing Offices (from 1 to $n$).

Each of the next $m$ lines details an available undirected line with three integers: $u$, $v$, and $w$.
- $u$ and $v$ are distinct department identifiers (from 1 to $n$) connected by the line.
- $w$ is the maintenance budget required to keep this line active. This cost is a positive integer not exceeding 1000000.

The available lines strictly follow the structural properties described above.

## Output

Print a single integer: the minimum total maintenance budget required to interconnect all Auditing Offices using only the selected lines.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, interconnecting Auditing Offices 1 and 4 requires keeping the lines that pass through departments 2 and 3 active, so all three lines (5 + 1 + 2 = 8) must be selected. In Example 2, there is only one Auditing Office. With a single required department, an empty set of lines is valid, so the minimum cost is 0.

Instead, I presented the exact same mathematical constraints by stating the network is a "single fully connected infrastructure" with exactly $m = n - 1$ lines, forcing the model to logically deduce the acyclic tree structure rather than relying on surface-level keyword matching.
</RATIONALE>

Finding the minimum cost to connect a subset of vertices in a connected graph with n-1 edges is equivalent to the Steiner tree problem on a tree, which remains solvable in O(n) time.
