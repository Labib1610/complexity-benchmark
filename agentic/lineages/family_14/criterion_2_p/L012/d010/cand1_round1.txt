<STATEMENT>
# Null Space Target Minimization

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given an integer $n$. You will construct an $n \times n$ symmetric matrix $L$, which is initially filled entirely with zeros.

You are provided with $m$ available matrix update operations. Each operation is specified by a pair of indices $(u, v)$ and an associated cost $w$. 
If you choose to apply an operation, you modify the matrix $L$ by performing the following four additions:
- Add $1$ to $L_{u,u}$
- Add $1$ to $L_{v,v}$
- Subtract $1$ from $L_{u,v}$
- Subtract $1$ from $L_{v,u}$

The cost of applying this operation is $w$. You may apply each operation at most once.

You are also given a target set of $t$ primary indices. Your objective is to select a subset of the $m$ operations to apply such that in the resulting matrix $L$, any $n$-dimensional column vector $x$ that satisfies the equation $L x = 0$ (where $0$ is the zero vector) strictly satisfies $x_a = x_b$ for all indices $a$ and $b$ in the primary set.

You are guaranteed that if you were to apply all $m$ available operations, the resulting matrix $L$ would have the property that $L x = 0$ implies all $n$ components of $x$ are identical. Furthermore, you are given exactly $m = n - 1$ operations.

Determine the minimum total cost of a subset of operations that achieves your objective. (If $t=1$, the condition $x_a = x_b$ for all primary indices is trivially satisfied for any matrix $L$, requiring 0 cost).

## Input

The first line contains three integers: $n$, $m$, and $t$.
- $n$ is the matrix dimension. It is at least 1 and at most 200,000.
- $m$ is the number of available operations, which is exactly $n - 1$.
- $t$ is the number of primary indices, which is at least 1 and at most $n$.

The second line contains $t$ distinct integers: the primary indices (from 1 to $n$).

Each of the next $m$ lines details an available operation with three integers: $u$, $v$, and $w$.
- $u$ and $v$ are the distinct indices (from 1 to $n$) modified by the operation.
- $w$ is the cost to apply this operation. This cost is a positive integer not exceeding 1,000,000.

The input guarantees that the full collection of $m$ operations satisfies the null space property described above.

## Output

Print a single integer: the minimum total cost to apply a subset of operations that guarantees $x_a = x_b$ for all primary indices $a$ and $b$ whenever $L x = 0$.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the primary indices are 1 and 4. We want to apply a subset of operations such that any vector $x$ satisfying $L x = 0$ must have $x_1 = x_4$. To achieve this, we must apply all three operations. The resulting matrix $L$ will enforce $x_1 = x_2 = x_3 = x_4$, which satisfies $x_1 = x_4$. If we omitted the third operation (cost 2), the matrix would not enforce $x_3 = x_4$, meaning $x_1$ and $x_4$ could differ in the null space. The minimum cost is therefore 5 + 1 + 2 = 8. 

In Example 2, there is only one primary index. Since the condition $x_a = x_b$ for all primary indices only requires $x_3 = x_3$, it is already satisfied regardless of $L$. No operations need to be applied, resulting in a minimum cost of 0.
</STATEMENT>
<RATIONALE>
The problem was reframed from physical hardware locks to constructing a Laplacian matrix via symmetric updates. This completely hides the tree connectivity structure behind the algebraic properties of the matrix's null space, forcing models to genuinely understand that $Lx = 0$ implies constant values on connected components rather than relying on standard graph-based pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The matrix $L$ is exactly the graph Laplacian, and its null space consists of vectors constant on connected components; thus the condition $Lx = 0 \implies x_a = x_b$ requires the primary indices to be in the same connected component, which in the guaranteed tree structure is uniquely achieved by the minimal connecting subtree.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains finding the minimal subtree connecting a set of vertices in a given tree, which is solvable in $O(n)$ time using a standard post-order tree traversal.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the $0$ in $Lx = 0$ as a scalar instead of the zero vector, though standard mathematical context and the explicit clarification make this highly unlikely.
</RISK>
