 We can model the operations as edges of a graph, where each operation \((u, v)\) with cost \(w\) corresponds to an edge between nodes \(u\) and \(v\).  
Applying an operation is like adding that edge to a graph.  

The null space condition means:  
If we contract all required indices into one super-node, the graph must be connected.  
Because if the graph is connected, the only null-space vectors are constant on each connected component, and since all required indices are in the same component, they must be equal.

So the problem reduces to:  
We have a graph with \(n\) nodes and \(n-1\) edges (a tree if all used). We must select a subset of edges with minimum total cost such that all required nodes are in the same connected component.

This is exactly the **minimum Steiner tree** problem on a tree, but since the original graph is a tree (because \(m = n-1\) and using all edges makes it connected), the minimum Steiner tree is just the minimal subtree connecting all required nodes.

We can solve it by:
1. Root the tree arbitrarily.
2. Mark required nodes.
3. Do a DFS from the root.  
   For each node, if its subtree contains any required node, then the edge from its parent to it must be included.  
   Sum the costs of all such edges.

This works because in a tree, the minimal connected subgraph containing a set of nodes is unique — it’s the union of paths between them.

Let’s implement it.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    required = set(map(int, input().split()))
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    if t == 1:
        print(0)
        return
    
    visited = [False] * (n+1)
    total_cost = 0
    
    def dfs(u, parent_edge_cost):
        nonlocal total_cost
        visited[u] = True
        has_required = u in required
        for v, w in adj[u]:
            if not visited[v]:
                child_has = dfs(v, w)
                if child_has:
                    total_cost += w
                has_required = has_required or child_has
        return has_required
    
    # Start DFS from any required node
    start = next(iter(required))
    dfs(start, 0)
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
