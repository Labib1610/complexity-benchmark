<METHOD_NAME>Algebraic Implication Framing</METHOD_NAME>
<METHOD_DESCRIPTION>Shifts the problem from physical locks and registers to abstract variables and linear identities. Instead of finding a subtree to connect nodes, the model must find a minimum-cost subset of equations that algebraically implies the equality of a target subset of variables. This masks the graph structure behind a system of equations, preventing graph-based pattern matching.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Subspace Variable Alignment

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of $n$ continuous variables, $x_1, x_2, \dots, x_n$. An adversary attempts to assign an arbitrary real value to each variable.

You can restrict the adversary by enforcing structural identities. You have a menu of $m$ available identities. Each identity enforces the condition $x_u = x_v$ for two specific variables $u$ and $v$, and requires a specific activation cost. When an identity is activated, the adversary's assignment must strictly satisfy $x_u = x_v$.

The adversary's objective is to successfully assign values to all $n$ variables such that all activated identities are satisfied, yet at least two variables in a designated set of $t$ **Target Variables** end up with strictly different values.

The menu of $m$ available identities is fully comprehensive: if you were to activate all of them, the only valid assignments would be those where all $n$ variables collapse to a single identical value. Furthermore, the number of available identities is exactly $m = n - 1$.

Your objective is to determine the minimum total activation cost of a subset of identities that makes the adversary's goal strictly impossible. (If $t=1$, the adversary's goal is inherently impossible, requiring 0 cost).

## Input

The first line contains three integers: $n$, $m$, and $t$, satisfying $1 \le n \le 200000$, $m = n - 1$, and $1 \le t \le n$.
- $n$ is the total number of variables.
- $m$ is the number of available identities.
- $t$ is the number of Target Variables.

The second line contains $t$ distinct integers: the indices of the Target Variables (from 1 to $n$).

Each of the next $m$ lines details an available identity with three integers: $u$, $v$, and $w$, satisfying $1 \le u, v \le n$, $u \neq v$, and $1 \le w \le 1000000$.
- $u$ and $v$ are the indices of the variables equated by the identity ($x_u = x_v$).
- $w$ is the cost to activate this identity.

The input guarantees that the full collection of $m$ identities is comprehensive as described above.

## Output

Print a single integer: the minimum total activation cost to select a subset of identities that guarantees all Target Variables must share the same value.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the Target Variables are 1 and 4. The adversary wants to assign values such that $x_1 \neq x_4$. To prevent this, the activated identities must algebraically imply $x_1 = x_4$. Activating the full set of three identities implies $x_1 = x_2 = x_3 = x_4$, which forces $x_1 = x_4$. No strictly smaller subset of these identities implies $x_1 = x_4$. The minimum cost is therefore 5 + 1 + 2 = 8. 

In Example 2, there is only one Target Variable. Since the adversary needs at least two Target Variables to have different values, their goal is already impossible. No identities need to be activated, resulting in a minimum cost of 0.
</STATEMENT>
<RATIONALE>
The problem was reframed from physical locks on registers to algebraic identities over continuous variables. This forces the model to reason about algebraic implication rather than graph connectivity, defeating models that rely on "tree" or "path" keyword associations while preserving the exact same underlying mathematical structure.
</RATIONALE>
<PRESERVED_ANSWER>
The structural identities form the same spanning tree over the variables as the hardware locks did over the registers, meaning the exact same subset of identities/edges is required to satisfy the condition for any given input.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the unique minimal subtree connecting a set of target nodes in a given tree, which is solvable in polynomial time O(n).
</PRESERVED_CLASS>
