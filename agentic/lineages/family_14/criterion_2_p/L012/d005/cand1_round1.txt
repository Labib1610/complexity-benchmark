<STATEMENT>
# Polynomial Root Confinement

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of $n$ real variables $x_1, x_2, \dots, x_n$. You are given a set of $t$ **Target Variables** from this system.

You have a dictionary of $m$ available polynomial terms. The $k$-th available term is defined by two variable indices $u$ and $v$, and takes the form $P_k(x) = (x_u - x_v)^2$. Each term has an associated inclusion cost $w$.

You must select a subset of these terms to construct a sum function $F(x) = \sum_{k \in S} P_k(x)$, where $S$ is your selected subset. 

Your objective is to ensure that the Target Variables are "confined". A selected subset $S$ is valid if and only if, for every possible point $x \in \mathbb{R}^n$ that is a global minimum of $F(x)$ (i.e., where $F(x) = 0$), all $t$ Target Variables evaluate to exactly the same value. (If $t=1$, this condition is trivially satisfied for any $x$, as a single variable always equals itself).

To ensure the system is minimally complete, the dictionary contains exactly $m = n - 1$ terms. These terms are structured such that if you were to include all $m$ of them in $F(x)$, the only points $x \in \mathbb{R}^n$ that achieve $F(x) = 0$ are those where all $n$ variables are equal. There are no redundant terms that could form alternative combinations to achieve this full confinement.

Determine the minimum total inclusion cost required to select a valid subset of terms that confines the Target Variables.

## Input

The first line contains three integers: $n$, $m$, and $t$.
- $n$ is the total number of variables. The system contains at least 1 variable and at most 200000.
- $m$ is the number of available polynomial terms, which is exactly $n - 1$.
- $t$ is the number of Target Variables, which is at least 1 and at most $n$.

The second line contains $t$ distinct integers: the indices of the Target Variables (from 1 to $n$).

Each of the next $m$ lines details an available polynomial term with three integers: $u$, $v$, and $w$.
- $u$ and $v$ are the distinct variable indices (from 1 to $n$) that define the term $P_k(x) = (x_u - x_v)^2$.
- $w$ is the inclusion cost for this term. This cost is a positive integer not exceeding 1000000.

These $m$ lines form the exact polynomial structure described above, guaranteeing that including all terms forces all variables to be equal without any redundant terms.

## Output

Print a single integer: the minimum total inclusion cost required to confine the Target Variables using only the selected terms.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the Target Variables 1 and 4 are confined only if we select the terms involving variables 1 and 2, 2 and 3, and 3 and 4. This ensures that when $(x_1 - x_2)^2 + (x_2 - x_3)^2 + (x_3 - x_4)^2 = 0$, it is mathematically required that $x_1 = x_4$. All three terms (5 + 1 + 2 = 8) must be included.
In Example 2, there is only one Target Variable (variable 3). A single variable is always equal to itself, so the confinement condition is satisfied even if no terms are selected. The minimum cost is 0.
