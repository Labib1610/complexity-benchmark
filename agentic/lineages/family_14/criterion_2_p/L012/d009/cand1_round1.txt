<STATEMENT>
# Laplacian Nullspace Restriction

Time limit: 2 s   Memory limit: 256 MB

## Description

You are tasked with constructing an $n \times n$ symmetric positive semi-definite matrix $M$. Initially, $M$ is the $n \times n$ zero matrix. A specific subset of $t$ indices from $1$ to $n$ are designated as the **Target Indices**.

You are provided with a collection of $m$ candidate matrix updates. Each candidate update is defined by two distinct indices $u$ and $v$. Including this update modifies the matrix $M$ by adding $1$ to the diagonal entries $M_{u,u}$ and $M_{v,v}$, and subtracting $1$ from the off-diagonal entries $M_{u,v}$ and $M_{v,u}$. Including a candidate update in your construction incurs a specific scalar cost.

If you were to include the complete collection of $m$ available updates, the resulting matrix $M$ would have a nullspace of exactly dimension 1 (spanned entirely by the all-ones vector). Furthermore, this collection contains exactly $m = n - 1$ updates.

You must select a subset of these candidate updates to form your matrix $M$. Your selection must satisfy the following condition: for every vector $\mathbf{x}$ in the nullspace of $M$, it must be true that $\mathbf{x}_a = \mathbf{x}_b$ for any pair of Target Indices $a$ and $b$. (When $t=1$, this condition imposes no restrictions).

Your objective is to determine the minimum total cost required to select a valid subset of candidate updates meeting this condition.

## Input

The first line contains three integers: $n$, $m$, and $t$.
- $n$ is the dimension of the matrix $M$. There is at least 1 dimension and at most 200,000.
- $m$ is the number of available candidate updates, which is exactly $n - 1$.
- $t$ is the number of Target Indices, which is at least 1 and at most $n$.

The second line contains $t$ distinct integers: the Target Indices (from 1 to $n$).

Each of the next $m$ lines details an available candidate update with three integers: $u$, $v$, and $w$.
- $u$ and $v$ are the distinct indices (from 1 to $n$) defining the matrix update.
- $w$ is the cost to include this update. This cost is a positive integer not exceeding 1,000,000.

These $m$ lines form the exact structure described above, guaranteeing the full collection yields a nullspace of dimension 1.

## Output

Print a single integer: the minimum total cost required to ensure the nullspace condition is met for all Target Indices.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the Target Indices are 1 and 4. To ensure that any vector $\mathbf{x}$ in the nullspace of $M$ satisfies $\mathbf{x}_1 = \mathbf{x}_4$, we must include all three candidate updates. If any update were omitted, the nullspace dimension would increase, introducing a vector where $\mathbf{x}_1 \neq \mathbf{x}_4$. The minimum total cost is therefore 5 + 1 + 2 = 8.

In Example 2, there is only one Target Index. Since there are no pairs to constrain, the zero matrix (with no updates included) trivially satisfies the condition, resulting in a minimum cost of 0.

<RATIONALE>
The problem was completely reframed from vector space spanning to constructing a graph Laplacian matrix and constraining its nullspace. The condition that target entries must be equal in all nullspace vectors is mathematically identical to requiring those indices to be in the same connected component. Models must now bridge the gap between linear algebra (nullspace dimension, rank-1 symmetric updates) and graph theory (trees, connectivity) to realize they can still optimize this using a linear-time Steiner tree on a tree algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The matrix updates construct a graph Laplacian where the nullspace vectors are constant on connected components; guaranteeing equality across target indices requires connecting them, and since the $n-1$ available updates yield a 1D nullspace, they form a spanning tree, making the minimum cost subset exactly the unique connecting subtree.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the task of finding the unique subtree connecting a set of target vertices in a given tree, which is solvable in $O(n)$ time using a simple Depth-First Search.
</PRESERVED_CLASS>
