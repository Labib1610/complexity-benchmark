We are given a tree with \( n \) nodes and \( n-1 \) weighted edges.  
We need to select a subset of edges such that all primary registers are in the same connected component.  
This is equivalent to finding the minimum total weight of edges to keep all primary nodes connected.

This is the **Steiner tree** problem on a tree, which can be solved by:

- If \( t \le 1 \), answer is 0.
- Otherwise, we can root the tree and do a DP to find the minimal cost to connect all primary nodes.

A simpler approach:  
Since it’s a tree, the minimal subgraph connecting a set of nodes is the union of all edges on paths between those nodes.  
We can compute this by marking all edges that lie on any path between two primary nodes.

We can do this efficiently:

1. Root the tree at any node.
2. For each node, compute how many primary nodes are in its subtree.
3. An edge (parent–child) is needed if and only if the child’s subtree contains at least one primary node **and** the rest of the tree (outside the subtree) also contains at least one primary node.  
   If both sides have at least one primary, then this edge is on a path between two primaries, so it must be included.

Sum the weights of all such edges.

Let’s implement this.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    primaries = list(map(int, input().split()))
    primary_set = set(primaries)
    
    adj = [[] for _ in range(n)]
    edges = []
    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append((v, w))
        adj[v].append((u, w))
        edges.append((u, v, w))
    
    if t <= 1:
        print(0)
        return
    
    parent = [-1] * n
    parent_weight = [0] * n
    order = [0]
    stack = [0]
    parent[0] = -2  # root marker
    
    # Build parent and order via iterative DFS
    while stack:
        u = stack.pop()
        order.append(u)
        for v, w in adj[u]:
            if v == parent[u]:
                continue
            parent[v] = u
            parent_weight[v] = w
            stack.append(v)
    
    # Count primary nodes in each subtree
    sub_count = [0] * n
    for p in primaries:
        sub_count[p] = 1
    
    # Process in reverse order (post-order)
    total_cost = 0
    for u in reversed(order):
        if u == 0:
            continue
        p = parent[u]
        # If subtree has at least one primary and outside has at least one primary
        if sub_count[u] > 0 and (t - sub_count[u]) > 0:
            total_cost += parent_weight[u]
        sub_count[p] += sub_count[u]
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
