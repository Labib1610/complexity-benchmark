<STATEMENT>
# Equivalence Derivation Optimization

Time limit: 2 s   Memory limit: 256 MB

## Description

A formal verification system contains $n$ boolean variables. Exactly $t$ of these variables are designated as **Target Variables**.

The system has a legacy knowledge base of $m$ bidirectional logical equivalences, each linking a pair of variables. The infrastructure of available equivalences spans the entire system such that every variable's value can be derived from any other. To minimize redundancy, the knowledge base was built with exactly $m = n - 1$ equivalences, ensuring there are no alternative derivation sequences between any pair of variables. This guarantees a single valid derivation route between any two variables.

Each equivalence requires a specific computational overhead to remain active in the solver. You must select a subset of these equivalences to keep active. In the knowledge base containing only your selected equivalences, all $t$ Target Variables must be mutually derivable (meaning the value of any Target Variable can be derived from any other Target Variable, possibly relying on other intermediate variables). Equivalences that are not selected are discarded and provide no derivation capabilities.

Your objective is to determine the minimum total computational overhead required to select a valid subset of equivalences that mutually connects all Target Variables.

## Input

The first line contains three integers: $n$, $m$, and $t$.
- $n$ is the total number of variables ($1 \le n \le 200000$).
- $m$ is the number of available equivalences, which is exactly $m = n - 1$.
- $t$ is the number of Target Variables ($1 \le t \le n$).

The second line contains $t$ distinct integers: the identifiers of the Target Variables (from $1$ to $n$).

Each of the next $m$ lines details an available bidirectional equivalence with three integers: $u$, $v$, and $w$.
- $u$ and $v$ are distinct variable identifiers ($1 \le u, v \le n$, $u \neq v$) linked by the equivalence.
- $w$ is the computational overhead required to keep this equivalence active ($1 \le w \le 1000000$).

These $m$ lines form the exact layout described above, guaranteeing a single derivation route between any two variables.

## Output

Print a single integer: the minimum total computational overhead required to make all Target Variables mutually derivable using only the selected equivalences.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, Target Variables 1 and 4 can only be derived from each other by passing through variables 2 and 3, so all three equivalences (5 + 1 + 2 = 8) must be selected. In Example 2, there is only one Target Variable. With one required variable, an empty set of equivalences is valid, so the minimum overhead is 0.
