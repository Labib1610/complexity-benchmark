<STATEMENT>
# Secure Enclave Federation

Time limit: 2 s   Memory limit: 256 MB

## Description

You are configuring a secure communication federation among $n$ isolated enclaves, numbered $1$ to $n$. A subset of $t$ enclaves are designated as **Root Authorities**.

You are provided with a blueprint of $m$ potential cryptographic bridges. Each bridge can be activated to link a specific pair of enclaves $u$ and $v$. Activating a bridge incurs a specific scalar cost. The complete blueprint of $m$ available bridges connects all $n$ enclaves into a single unified federation. Furthermore, the blueprint contains exactly $m = n - 1$ bridges.

The architecture enforces a strict non-redundancy constraint: any subset of $k$ activated bridges that form a fully linked segment will always span exactly $k+1$ enclaves. Therefore, the full blueprint of available bridges forms a single connected network over all $n$ enclaves without any closed loops.

You must select a subset of these bridges to activate. Your selection must satisfy the following condition: through the activated bridges (possibly by chaining through intermediate enclaves), all $t$ Root Authorities must mutually authenticate; that is, all Root Authorities must lie in a single connected component of the activated bridges. (When $t=1$, this condition imposes no additional restrictions on the selected subset).

Your objective is to determine the minimum total cost required to select a valid subset of bridges meeting this condition.

## Input

The first line contains three integers: $n$, $m$, and $t$.
- $n$ is the total number of enclaves. There is at least 1 enclave and at most 200000.
- $m$ is the number of available bridges, which is exactly $n - 1$.
- $t$ is the number of Root Authorities, which is at least 1 and at most $n$.

The second line contains $t$ distinct integers: the indices of the Root Authorities (from 1 to $n$).

Each of the next $m$ lines details an available bridge with three integers: $u$, $v$, and $w$.
- $u$ and $v$ are distinct enclave indices (from 1 to $n$) linked by the bridge.
- $w$ is the cost to activate this bridge. This cost is a positive integer not exceeding 1000000.

These $m$ lines form the exact structure described above, guaranteeing the full collection connects all $n$ enclaves.

## Output

Print a single integer: the minimum total cost required to ensure all Root Authorities are in the same connected component.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the Root Authorities 1 and 4 can only be connected by activating all three bridges (costs 5 + 1 + 2 = 8). In Example 2, there is only one Root Authority. With only one Root Authority, no bridge is required, so the minimum cost is 0.
