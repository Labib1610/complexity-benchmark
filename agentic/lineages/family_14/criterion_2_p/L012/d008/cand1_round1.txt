<METHOD_NAME>Matroid Sparsity Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit "generates the symmetric group" (spanning tree) guarantee with its equivalent matroid independence condition (every subset of k vertices has at most k-1 edges). This mathematically preserves the tree structure and complexity class (P) while stripping away the recognizable group/graph theory vocabulary that triggers the standard tree DFS shortcut. Models that fail to logically deduce the tree structure from this sparsity condition will assume the network contains cycles and likely fallback to an NP-hard Steiner Tree approximation, yielding incorrect costs or timing out.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Cryptographic Key Sharding

Time limit: 2 s   Memory limit: 256 MB

## Description

You are configuring a secure communication network for $n$ distinct server enclaves, indexed $1$ to $n$. A specific subset of $t$ enclaves are designated as **Root Authorities**.

You are provided with a collection of $m$ potential cryptographic bridges. Each bridge allows enclave $u$ and enclave $v$ to mutually authenticate and share keys. Activating a bridge incurs a specific computational cost $w$. 

You must select a subset of these bridges to activate. Your selection must satisfy the following condition: through the network of activated bridges, all $t$ Root Authorities must be able to mutually authenticate with each other, possibly by chaining through intermediate enclaves. (When $t=1$, this condition imposes no additional restrictions on the selected subset).

The available bridges satisfy a strict redundancy constraint: for any group of $k$ enclaves (where $k \ge 1$), the number of available bridges that operate exclusively between members of this group never exceeds $k - 1$. Furthermore, the total number of provided bridges is exactly $m = n - 1$.

Your objective is to determine the minimum total cost required to activate a valid subset of bridges meeting the authentication condition.

## Input

The first line contains three integers: $n$, $m$, and $t$.
- $n$ is the total number of enclaves. There is at least 1 enclave and at most 200000.
- $m$ is the number of available bridges, which is exactly $n - 1$.
- $t$ is the number of Root Authorities, which is at least 1 and at most $n$.

The second line contains $t$ distinct integers: the indices of the Root Authorities (from 1 to $n$).

Each of the next $m$ lines details an available bridge with three integers: $u$, $v$, and $w$.
- $u$ and $v$ are distinct enclave indices (from 1 to $n$) connected by the bridge.
- $w$ is the cost to activate this bridge. This cost is a positive integer not exceeding 1000000.

These $m$ lines form the exact structure described above, adhering to the redundancy constraint.

## Output

Print a single integer: the minimum total cost required to ensure all Root Authorities can mutually authenticate under the activated subset of bridges.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the Root Authorities 1 and 4 can only authenticate by activating all three bridges (costs 5 + 1 + 2 = 8). 
In Example 2, there is only one Root Authority. Since a single enclave trivially authenticates with itself, no bridges need to be activated, resulting in a minimum cost of 0.
</STATEMENT>
<RATIONALE>
I replaced the explicit group-theoretic guarantee ("generates $S_n$") with an equivalent matroid sparsity condition ("any subset of $k$ enclaves has at most $k-1$ bridges"). This removes the obvious "spanning tree" affordance that allowed models to instantly use a tree DFS. Models must now either mathematically deduce that this condition combined with $m=n-1$ implies a tree, or they will assume the network contains cycles and incorrectly apply a general Steiner Tree approximation algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The required subset of bridges to connect the target enclaves in a tree is unique, so the minimum cost remains exactly the sum of weights of the unique connecting paths.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The condition that any $k$ elements have at most $k-1$ edges mathematically restricts the input domain to forests; with $m=n-1$, it is always a spanning tree, keeping the problem in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "operate exclusively between members" but the phrase is standard for induced subgraphs and unambiguous in context.
</RISK>
