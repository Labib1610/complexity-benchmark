**Solution Explanation**

For every candidate vector we are given two different indices `u , v` and a cost `w`.
The vector is  

```
d = e_u – e_v
```

If we take several vectors, their linear span consists of all vectors that can be
written as a sum of the taken vectors with real coefficients.
In a tree this span has a very simple meaning.

--------------------------------------------------------------------

#### 1.   Geometry → Graph

All `m = n‑1` vectors are linearly independent and span the whole
`(n‑1)`‑dimensional subspace `{ x | Σ x_i = 0 }`.  
Therefore the `m` vectors form a **tree** on the vertices `1 … n` :

* vertex `i`  – the basis vector `e_i`
* edge `u – v` – the vector `e_u – e_v`

*Proof sketch* – the `n` vectors `e_i` are linearly independent,
the `n‑1` difference vectors are independent and their span has dimension `n‑1`,
hence they connect the `n` vertices without cycles – a tree.

--------------------------------------------------------------------

#### 2.   When is `e_a – e_b` obtainable?

Take any set `S` of edges of the tree.
Let the forest obtained from the tree by deleting all edges not in `S`
have connected components `C₁ , C₂ , …`.

*Claim*  
`e_a – e_b` belongs to the span of `S` **iff** `a` and `b` lie in the same component.

*Reason* – In a tree the unique path from `a` to `b` consists of edges
`(x₁,x₂) , (x₂,x₃) , … , (x_{k-1},x_k)`.
The sum of the corresponding vectors is exactly `e_a – e_b`.
If any edge of that path is missing, the sum cannot be formed,
otherwise it can. ∎



Consequences  

* All target vertices must become **connected** after we choose edges.
* In a tree there is only one minimal set of edges that connects a given
  set of vertices – the **Steiner tree**, i.e. the union of all pairwise
  paths between the targets.
  Every edge of that subtree is unavoidable, every other edge is useless.

Thus the answer is simply the total cost of the edges that belong to the
minimal subtree containing all target vertices.

--------------------------------------------------------------------

#### 3.   Which edges belong to that subtree?

Root the tree arbitrarily (vertex `1`).  
For each vertex `v` let  

```
cnt[v] = number of target vertices in the subtree of v (including v)
```

Let `total = t` be the number of target vertices.
Consider a tree edge `parent – child` (child is deeper in the rooted tree).

*The edge is needed* **iff**  

```
0 < cnt[child] < total
```

because then there is at least one target below the edge and at least one
target outside, so the edge lies on a path between two targets.

Therefore we only have to compute `cnt[v]` for all vertices and sum the
costs of edges satisfying the condition above.

--------------------------------------------------------------------

#### 4.   Algorithm
```
read n, m, t
read list TARGET (size t)
build adjacency list of the tree, each entry: (neighbor, weight)

if t == 1:
        print 0 and exit

# 1. iterative DFS to obtain parent, edge weight to parent, order
stack = [(1, 0, -1)]          # (node, weight_from_parent, parent)
order = []                    # visitation order
parent = [0]*(n+1)
pw = [0]*(n+1)                # weight of edge (parent -> node)
while stack:
        v, w, p = stack.pop()
        parent[v] = p
        pw[v] = w
        order.append(v)
        for to, wt in adj[v]:
                if to == p: continue
                stack.append((to, wt, v))

# 2. post‑order processing to compute cnt
cnt = [0]*(n+1)
for v in TARGET:
        cnt[v] = 1

answer = 0
for v in reversed(order):            # children before parent
        p = parent[v]
        if p != 0:                    # not the root
                if 0 < cnt[v] < t:    # edge (p,v) is needed
                        answer += pw[v]
                cnt[p] += cnt[v]

print answer
```

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm outputs the minimum possible total cost.

---

##### Lemma 1  
For any set of selected edges `S`, the vectors `e_a – e_b` (with `a,b`
targets) are in the span of `S` **iff** all target vertices belong to the
same connected component of the forest `(V, S)`.

*Proof* – given in Section&nbsp;2. ∎



##### Lemma 2  
Let `T*` be the set of edges whose removal separates the target set into
both non‑empty parts, i.e. edges `parent–child` with `0 < cnt[child] < t`.
Then `T*` is exactly the minimal subtree containing all target vertices.

*Proof*  
*Containment*:  
If `0 < cnt[child] < t`, there is a target in the child’s subtree and a
target outside, therefore the unique path between those two targets must
use the edge `parent–child`. Hence the edge belongs to the union of all
paths between targets, i.e. to the minimal subtree.

*Maximality*:  
Take any edge `e` of the minimal subtree. Removing `e` splits the tree
into two components, each containing at least one target (otherwise the
subtree would be disconnected). The deeper endpoint of `e` is a child
with `0 < cnt[child] < t`, therefore `e` satisfies the condition and is
included in `T*`. ∎



##### Lemma 3  
Any feasible selection of edges must contain all edges of `T*`.

*Proof*  
Assume a feasible set `S` misses an edge `e ∈ T*`. By Lemma&nbsp;2,
removing `e` separates the target vertices into two non‑empty groups.
Consequently those two groups lie in different components of `(V,S)`,
contradicting Lemma&nbsp;1. ∎



##### Lemma 4  
The set `T*` itself is feasible.

*Proof*  
By construction every pair of targets is connected inside `T*`
(the minimal subtree is connected and contains all targets), therefore
Lemma&nbsp;1 holds. ∎



##### Lemma 5  
The algorithm computes `∑_{e∈T*} w(e)`.

*Proof*  
During the post‑order loop the algorithm examines each non‑root edge
exactly once, with `cnt[child]` already known.
The condition `0 < cnt[child] < t` is precisely the definition of
membership in `T*` (Lemma&nbsp;2), and the edge weight `pw[child]` is added
iff the condition holds. Hence the accumulated sum equals the total
weight of `T*`. ∎



##### Theorem  
The algorithm outputs the minimum possible total cost of a subset of
candidate vectors satisfying the requirement.

*Proof*  

*Optimality*:  
Any feasible subset must contain all edges of `T*` (Lemma&nbsp;3), therefore
its total cost is at least `∑_{e∈T*} w(e)`.

*Achievability*:  
Choosing exactly the edges of `T*` is feasible (Lemma&nbsp;4) and its cost
equals that lower bound. By Lemma&nbsp;5 the algorithm outputs this cost.
Thus no cheaper feasible subset exists. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Building the adjacency list*: `O(n)`  
*DFS traversal* : `O(n)`  
*Post‑order counting* : `O(n)`  

Memory consumption: adjacency list `O(n)`, several integer arrays `O(n)`.  

Both time (`≤ 2·10⁵` operations) and memory fit easily into the limits.

#### 7.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    n = int(next(it))
    m = int(next(it))          # = n-1, not used separately
    t = int(next(it))

    targets = [int(next(it)) for _ in range(t)]
    if t == 1:
        # no required differences
        print(0)
        return

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it)); w = int(next(it))
        adj[u].append((v, w))
        adj[v].append((u, w))

    # iterative DFS to get parent, weight to parent and order
    parent = [0] * (n + 1)
    pw = [0] * (n + 1)          # weight of edge (parent -> node)
    order = []
    stack = [(1, 0, 0)]         # node, weight from parent, parent
    while stack:
        v, w, p = stack.pop()
        parent[v] = p
        pw[v] = w
        order.append(v)
        for to, wt in adj[v]:
            if to == p:
                continue
            stack.append((to, wt, v))

    cnt = [0] * (n + 1)
    for v in targets:
        cnt[v] = 1

    total = t
    ans = 0
    for v in reversed(order):
        p = parent[v]
        if p != 0:
            if 0 < cnt[v] < total:
                ans += pw[v]
            cnt[p] += cnt[v]

    print(ans)


if __name__ == "__main__":
    solve()
```

to the required input‑output format.
