<STATEMENT>
# High-Security Pneumatic Upgrades

Time limit: 2 s   Memory limit: 256 MB

## Description

A sprawling bureaucracy consists of $n$ departments. Physical documents are routed between departments via a network of bidirectional pneumatic tubes. There are exactly $m$ tube lines, where $m = n - 1$. The tube network is fully integrated: a document can be routed between any two departments using some sequence of tubes. Because there are no redundant tubes, disabling any single tube line would permanently separate some departments from others.

Exactly $t$ departments are designated as Auditing Offices. To comply with new regulations, the bureaucracy must upgrade a subset of its tube lines to high-security status. The goal is to ensure that a secure route, consisting entirely of high-security tube lines, exists between any two Auditing Offices. The documents may pass through non-auditing departments along the route, provided the tubes they travel through are all upgraded.

Each tube line requires a specific amount of funding to upgrade. Your task is to determine the minimum total funding required to upgrade a valid subset of tube lines such that all Auditing Offices are interconnected by high-security tubes.

## Input

The first line of the manifest contains three integers: $n$, $m$, and $t$.
- $n$ is the total number of departments. The network contains at least 1 department and is bounded by a maximum capacity of 200000.
- $m$ is the number of pneumatic tube lines, which is exactly $n - 1$.
- $t$ is the number of Auditing Offices, which is at least 1 and at most $n$.

The second line contains $t$ distinct integers: the identifiers of the Auditing Offices.

Each of the next $m$ lines details a pneumatic tube line with three integers: $u$, $v$, and $w$.
- $u$ and $v$ are distinct department identifiers (from 1 to $n$) connected by the tube line.
- $w$ is the funding required to upgrade this tube line. This cost is a positive integer bounded by a maximum of 1000000.

The tube network guarantees connectivity as described above.

## Output

Print a single integer: the minimum total funding required to ensure all Auditing Offices can route classified documents to each other exclusively through upgraded tubes.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, Auditing Offices 1 and 4 can only exchange classified documents by routing them through departments 2 and 3, so all three tube lines (5 + 1 + 2 = 8) must be upgraded. In Example 2, there is only one Auditing Office, so no tube lines need to be upgraded.

<RATIONALE>
The problem was completely reframed from an orbital comm-link network into a bureaucracy with a pneumatic tube document routing system. The explicit statement that "between any two outposts there would be exactly one possible route" was removed and replaced with a mechanical description of the network's properties (fully connected, but disabling any tube disconnects parts of the network). This forces the model to deduce the unique-path property of the tree rather than simply reading it from the text.
</RATIONALE>
<PRESERVED_ANSWER>
The structural requirements for the network (a connected component containing all $t$ designated nodes) and the costs of the edges remain mathematically identical, so the optimal minimum-weight spanning subtree remains the exact same set of edges.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks for the minimum weight subgraph connecting a subset of vertices in a tree, which is exactly the Steiner tree problem on trees, solvable in $O(n)$ time.
</PRESERVED_CLASS>
<RISK>
None. The requirement that "a secure route, consisting entirely of high-security tube lines, exists between any two Auditing Offices" perfectly specifies the connectivity constraint without any ambiguity.
</RISK>
