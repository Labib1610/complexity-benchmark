<STATEMENT>
# Mycelium Resource Routing

Time limit: 2 s   Memory limit: 256 MB

## Description

A fungal organism consists of **n** vesicles. To maintain structural integrity with minimal resources, the organism forms **m** hyphal threads, which is the absolute minimum number of threads required to keep all its vesicles connected in a single biological network.

Each vesicle requires exactly one microgram of a specialized fluorescent dye to be individually visible under the microscope, and the laboratory allocates a maximum of 200 milligrams of this dye for a single organism. 

Among all vesicles, **t** of them have developed fruiting bodies. In order for the organism to reproduce successfully, all vesicles with fruiting bodies must be able to exchange nutrients with one another. Nutrients can flow freely through any thread that has been metabolically activated. Activating the thread between vesicle **u** and vesicle **v** requires a specific metabolic cost **w**, measured in picojoules. The maximum energetic capacity (and thus the highest possible activation cost) of any single thread is exactly one microjoule.

Determine the minimum total metabolic cost required to activate a subset of threads such that every vesicle with a fruiting body can exchange nutrients with every other vesicle with a fruiting body (possibly passing through other intermediate, non-fruiting vesicles).

## Input

The first line contains three integers **n**, **m**, and **t**. The bounds are dictated by the physical constraints: the number of vesicles **n** is at least 1 and at most the limit imposed by the dye supply; **m** is the exact number of threads needed to minimally connect all **n** vesicles; and **t** ranges from 1 up to **n**.

The second line contains **t** distinct integers ranging from 1 to **n**: the identifiers of the vesicles that have developed fruiting bodies.

Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v). These represent a thread linking vesicle **u** and vesicle **v** with an activation cost of **w** picojoules. The cost **w** is at least 1 and does not exceed the one-microjoule energetic limit. The threads form the minimal connected network described above.

## Output

Print a single integer: the minimum total metabolic cost to link all vesicles with fruiting bodies.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the vesicles with fruiting bodies (1 and 4) can only exchange nutrients via vesicles 2 and 3, so all three threads (costs 5, 1, and 2) must be activated, totaling 8.
In Example 2, there is only one vesicle with a fruiting body, so no threads need to be activated.

<RATIONALE>
Removed the explicit mention of a "unique non-repeating sequence" and replaced it with a description of a minimally connected network, requiring the model to deduce that the structure is a tree. Additionally, numeric constraints on `n` and `w` were obfuscated into physical units (micrograms vs milligrams, picojoules vs microjoules) forcing the model to derive the bounds via SI prefix conversions.
</RATIONALE>
<PRESERVED_ANSWER>
The structural requirement is still to find the minimum weight subgraph connecting a subset of vertices, which in a tree is exactly the uniquely defined minimal subtree.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying graph is still guaranteed to be a tree, meaning the Steiner tree problem simplifies to polynomial-time subtree pruning.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the unit conversions (e.g. confusing micro and milli) leading to incorrect array allocations, though standard SI prefixes should be unambiguous to a competent reader.
