# Logic Constraint Enforcement

Time limit: 2 s   Memory limit: 256 MB

## Description

A digital circuit contains $n$ logic registers, each holding a single boolean state. 

You are provided a predefined list of $m$ available equivalence gates. Each gate, if activated, continuously enforces the constraint that register $u$ and register $v$ must hold the exact same boolean state. Activating a gate incurs a configuration cost of $w$ microjoules.

The circuit's architecture guarantees that if all $m$ available gates were activated, all $n$ registers would be forced to share the same state. To prevent redundancy, the total count of available gates $m$ is strictly fixed at exactly one less than $n$.

A specific subset of $t$ registers are designated as output registers. 

You must select a subset of the available gates to activate such that, simply by adhering to the activated constraints, all $t$ output registers are logically forced to hold the same boolean state (meaning no valid assignment of states to the $n$ registers could ever result in two output registers having different states). Registers that are not designated as output registers may hold any state, as long as all activated gates are satisfied.

Your objective is to determine the minimum possible total configuration cost required to activate a valid set of gates that satisfies this output requirement. (If there is only one output register, no constraints between multiple registers are needed, and zero gates need to be activated).

## Input

The first line provides three integers: the total number of registers $n$, the total number of available gates $m$, and the headcount of output registers $t$. The board's maximum physical capacity dictates that $n$ can be up to two hundred thousand, with at least one register always present. The total count of available gates $m$ is always exactly one less than $n$. The headcount of output registers $t$ can be anywhere from a single register up to the entire set of $n$ registers.

The second line contains $t$ distinct integers representing the identifiers of the output registers (valid IDs from 1 to $n$).

Following this, there are $m$ lines, each detailing a single available equivalence gate with three integers: $u$, $v$, and $w$. This indicates a gate between distinct registers $u$ and $v$. The configuration cost $w$ draws at least one microjoule, up to a maximum thermal limit of one million microjoules per gate.

## Output

Print a single integer: the minimum possible total configuration cost required to activate a set of gates such that all output registers are logically forced to hold the same boolean state.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the output registers are 1 and 4. To logically force register 1 and register 4 to hold the same state, we must activate the gates between 1 and 2 (cost 5), 2 and 3 (cost 1), and 3 and 4 (cost 2). If these are activated, register 1 must equal 2, 2 must equal 3, and 3 must equal 4, thereby forcing 1 to equal 4. The total cost is 5 + 1 + 2 = 8. This is the minimum possible total cost.

In Example 2, there is only one output register (register 3). Since no constraints between multiple output registers are needed, zero gates need to be activated. The minimum possible total cost is 0.

This removes all graph-theoretic and spatial terminology, forcing the model to deduce that logical entailment of equality among variables is mathematically equivalent to finding a connected subgraph, which on a tree structure is exactly the minimal subtree.
