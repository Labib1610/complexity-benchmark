<STATEMENT>
# Intercellular Nutrient Allocation

Time limit: 2 s   Memory limit: 256 MB

## Description

A fungal organism consists of **n** microscopic vesicles. These vesicles are joined by **m** biological threads. The organism is fully contiguous, meaning it is possible to navigate between any two vesicles via some sequence of threads. Because there are exactly **m** = **n** - 1 threads, there is exactly one unique simple path between any two vesicles.

Among all vesicles, **t** of them contain reproductive spores. In order for the organism to reproduce successfully, all spore-containing vesicles must be connected to one another. Nutrients can pass freely through any thread that has been metabolically activated. Activating the thread joining vesicle **u** and vesicle **v** requires a specific metabolic cost **w**.

Choose a set of threads to activate with the minimum total metabolic cost such that for every pair of spore-containing vesicles, there is a path between them consisting entirely of activated threads. This path may freely pass through intermediate non-spore vesicles.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ **n** ≤ 200000, **m** = **n** - 1, 1 ≤ **t** ≤ **n**). 

The second line contains **t** distinct integers: the identifiers of the vesicles containing reproductive spores.

Each of the following **m** lines contains three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000), representing a thread joining vesicle **u** and vesicle **v** with a metabolic cost of **w**. It is guaranteed that the given threads connect all **n** vesicles into a single contiguous structure.

## Output

Print a single integer: the minimum total metabolic cost to connect all spore-containing vesicles.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the spore-containing vesicles 1 and 4 can only be connected via vesicles 2 and 3, so all three threads (costs 5, 1, and 2) must be activated, resulting in a total cost of 8.
In Example 2, there is only one spore-containing vesicle, so no threads need to be activated to connect all of them, resulting in a total cost of 0.
