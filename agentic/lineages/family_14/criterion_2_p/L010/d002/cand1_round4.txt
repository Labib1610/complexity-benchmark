<STATEMENT>
# Intercellular Nutrient Allocation

Time limit: 2 s   Memory limit: 256 MB

## Description

A biological entity comprises **n** microscopic chambers connected by **m** filamentous tubes. The entity's architecture is entirely contiguous, ensuring that any chamber can be reached from any other chamber through a series of tubes.

A specific subset of **t** chambers are designated as reproductive nodes, as they contain vital spores. For the entity to achieve reproductive success, these specific chambers must all be integrated into a functional nutrient-sharing network. Nutrients can only pass through tubes that have been chemically energized. Energizing the tube connecting chamber **u** and chamber **v** incurs a precise chemical expenditure **w**.

Your task is to calculate the smallest possible total chemical expenditure needed to energize a collection of tubes such that nutrients can flow between all pairs of reproductive nodes. The flow of nutrients may route through non-reproductive chambers if those connecting tubes are energized.

## Input

The first line provides three integers **n**, **m**, and **t**. The total number of chambers **n** is between 1 and 200000. The number of reproductive nodes **t** satisfies 1 ≤ **t** ≤ **n**. The number of filamentous tubes **m** is exactly **n** − 1.

The second line contains **t** distinct integers: the identifiers of the chambers that contain spores.

Each of the subsequent **m** lines provides three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), describing a tube between chamber **u** and chamber **v**. The chemical expenditure **w** is between 1 and 1000000. The tubes connect all chambers into the single contiguous architecture mentioned above.

## Output

Output a single integer representing the minimum total chemical expenditure required to ensure all reproductive nodes are connected by energized tubes.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the reproductive nodes 1 and 4 can only exchange nutrients via chambers 2 and 3, so all three tubes (expenditures 5, 1, and 2) must be energized, totaling 8.
In Example 2, there is only one reproductive node, so no tubes need to be energized.
