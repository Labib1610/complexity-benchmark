<STATEMENT>
# Intercellular Nutrient Allocation

Time limit: 2 s   Memory limit: 256 MB

## Description

A fungal organism consists of **n** microscopic vesicles, which share **m** biological threads. Nutrients can be passed from vesicle to vesicle across these threads, and currently, the threads are arranged such that a nutrient could theoretically travel from any vesicle to any other.

Among these, **t** specific vesicles contain reproductive spores. For successful reproduction, a nutrient exchange system must be established that allows every spore-containing vesicle to send nutrients to every other spore-containing vesicle (possibly routing through intermediate, non-spore vesicles).

A thread only allows nutrient exchange if it is metabolically activated. Activating the thread between vesicle **u** and vesicle **v** requires a metabolic cost **w**. Find the minimum total metabolic cost to activate a collection of threads that successfully connects all spore-containing vesicles.

## Input

The first line contains three integers **n**, **m**, and **t**. The physical limits of the petri dish restrict the organism to at most 200000 vesicles, so **n** is between 1 and 200000. The number of spore-bearing vesicles **t** is at least 1 and at most **n**. The number of threads **m** is exactly the minimum quantity necessary to ensure that it is possible for a nutrient to travel from any vesicle to any other.

The second line contains **t** distinct integers: the identifiers of the vesicles containing reproductive spores.

Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), representing a thread between vesicle **u** and vesicle **v** with metabolic cost **w**. The metabolic cost **w** is at least 1 and is bounded by a strict biological cap of 1000000.

## Output

Print a single integer: the minimum total metabolic cost to link all spore-containing vesicles.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the spore-containing vesicles 1 and 4 can only exchange nutrients via vesicles 2 and 3, so all three threads (costs 5, 1, and 2) must be activated, totaling 8.
In Example 2, there is only one spore-containing vesicle, so no threads need to be activated.
</STATEMENT>
<RATIONALE>
Removed the explicit `m = n - 1` equation and the phrase "fully contiguous structure", which allowed models to immediately pattern-match the problem to a tree. Instead, the bound is presented conceptually: `m` is described as the minimum number of threads necessary to ensure all vesicles can reach each other. This forces the model to actively deduce that $m = n - 1$ and that the graph is therefore a tree, before applying the linear-time subtree pruning algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The structural constraints and costs remain exactly the same, so the minimal cost to connect the required subset of vesicles is unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying graph is still guaranteed to be a tree, so finding the minimal connecting network is equivalent to finding the unique spanning subtree for the marked nodes, which remains solvable in O(n) time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "minimum quantity necessary to ensure it is possible to travel" as implying the graph might have cycles but we are only given a spanning tree, or they might fail to deduce $m = n - 1$ entirely. However, graph theoretically, this uniquely defines $m = n - 1$, so an unambiguous logical path exists.
</RISK>
