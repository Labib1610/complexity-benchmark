<STATEMENT>
# Intercellular Nutrient Allocation

Time limit: 2 s   Memory limit: 256 MB

## Description

A fungal organism consists of **n** microscopic vesicles. These vesicles are linked by **m** undirected biological threads. The organism is fully contiguous, meaning it is possible to navigate between any two vesicles via some sequence of threads.

Among all vesicles, **t** of them contain reproductive spores. You must choose a single set of threads to metabolically activate. Each chosen thread contributes its specific metabolic cost **w** exactly once to the total.

Determine the minimum total metabolic cost to choose a set of threads such that all spore-containing vesicles lie in the same connected component of the chosen set. This means any spore-containing vesicle can reach any other spore-containing vesicle using only the chosen threads, possibly passing through other intermediate non-spore vesicles.

## Input

The first line contains three integers **n**, **m**, and **t**. The physical limits of the petri dish restrict the organism to at most 200000 vesicles, so **n** is between 1 and 200000. The number of spore-bearing vesicles **t** is at least 1 and at most **n**. The structural integrity dictates that the number of threads **m** is strictly less than **n**.

The second line contains **t** distinct integers: the identifiers of the vesicles containing reproductive spores.

Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), representing an undirected thread linking vesicle **u** and vesicle **v**. The metabolic cost **w** is at least 1 and is bounded by a strict biological cap of 1000000. The threads form the fully contiguous structure described above.

## Output

Print a single integer: the minimum total metabolic cost of the chosen set of threads.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the spore-containing vesicles 1 and 4 can only be connected via vesicles 2 and 3, so all three threads (costs 5, 1, and 2) must be chosen, totaling 8.
In Example 2, there is only one spore-containing vesicle, so no threads need to be chosen, resulting in a minimum cost of 0.

<RATIONALE>
Changed the explicit "m = n - 1" to "m is strictly less than n". Along with the contiguity constraint, this still uniquely forces the graph to be a tree, but removes the explicit string that models use to shortcut to tree algorithms, forcing them to deduce the tree structure mathematically. Additionally, tightened the objective to a purely static subset-selection to eliminate flow/process task drift.
</RATIONALE>
<PRESERVED_ANSWER>
The problem is mathematically identical because a connected graph with m < n edges must have exactly m = n - 1 edges and be a tree, and the objective remains finding the minimum weight connected subgraph spanning the required vertices.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying graph is still a tree and the problem still asks for the minimal subtree connecting a set of terminals, which is computable in linear time.
</PRESERVED_CLASS>
<RISK>
Models might fail to deduce m = n - 1 and incorrectly assume the graph can be disconnected, although the statement explicitly mandates that the organism is "fully contiguous".
</RISK>
