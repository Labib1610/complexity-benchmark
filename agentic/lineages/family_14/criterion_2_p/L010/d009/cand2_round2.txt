<METHOD_DESCRIPTION>
Translates the linear span condition of vectors into the equivalent null space condition of a Laplacian matrix. It masks the underlying tree topology behind spectral properties (a single zero eigenvalue), preventing models from pattern-matching the problem to a tree DFS while remaining mathematically identical.
</METHOD_DESCRIPTION>

yes

<STATEMENT>
# Null Space Alignment

Time limit: 2 s   Memory limit: 256 MB

## Description

You are working with an $n \times n$ symmetric matrix $M$, which is initially the zero matrix. The rows and columns are indexed from $1$ to $n$.

You are given a pool of $m$ available matrix modification operations. Each available operation is specified by two indices $u$ and $v$ and an associated cost $w$. Applying this operation adds $1$ to $M_{u,v}$ and $M_{v,u}$, and subtracts $1$ from $M_{u,u}$ and $M_{v,v}$. The cost to include this operation in your selected set is $w$. 

You are mathematically guaranteed that if you were to apply all $m$ available operations, the resulting matrix would have exactly one eigenvalue equal to zero. The total number of available operations $m$ is exactly $n - 1$.

A specific subset of $t$ indices are designated as target indices. 

You must select a subset of the available operations to apply. Your selected operations yield a final matrix $M^*$. Your selection must satisfy the following condition: for every vector $x \in \mathbb{R}^n$ in the null space of $M^*$ (i.e., any vector $x$ such that $M^* x = 0$), it must be true that $x_{c_a} = x_{c_b}$ for every pair of target indices $c_a$ and $c_b$. 

Your objective is to determine the minimum possible total cost of a subset of operations that satisfies this requirement. (If there is only one target index, the requirement is vacuously satisfied by selecting no operations, and the cost is zero).

## Input

The first line provides three integers: $n$, $m$, and $t$. The matrix dimension $n$ satisfies $1 \le n \le 200000$. The number of available operations $m$ is always exactly $n - 1$. The number of target indices $t$ satisfies $1 \le t \le n$.

The second line contains $t$ distinct integers representing the target indices.

Following this, there are $m$ lines, each detailing a single available operation with three integers: $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$). This represents the operation on indices $u$ and $v$ with cost $w$. The cost $w$ to include any single operation satisfies $1 \le w \le 1000000$.

## Output

Print a single integer: the minimum possible total cost required to select a valid subset of operations.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the target indices are 1 and 4. We must ensure that for any vector $x$ where $M^* x = 0$, we have $x_1 = x_4$. By selecting the operations on (1, 2) with cost 5, (2, 3) with cost 1, and (3, 4) with cost 2, the resulting matrix $M^*$ has a null space consisting only of vectors where $x_1 = x_2 = x_3 = x_4$. Thus, $x_1 = x_4$ is satisfied. The total cost is 5 + 1 + 2 = 8. No cheaper subset of operations forces this condition for all vectors in the null space.

In Example 2, there is only one target index (index 3). Since there are no pairs of distinct target indices, the condition is vacuously satisfied by an empty set of operations. The final matrix $M^*$ is the zero matrix, and the minimum possible total cost is 0.

In Example 3, all three indices are targets. Selecting the operations (1, 2) with cost 4 and (2, 3) with cost 5 ensures that any vector in the null space satisfies $x_1 = x_2 = x_3$. The total cost is 4 + 5 = 9.
</STATEMENT>
<RATIONALE>
I transformed the problem from finding a subset of vectors whose span contains specific differences into finding a subset of matrix operations such that the resulting matrix's null space enforces equality between target indices. This forces the model to recognize that the matrix operations construct a negative graph Laplacian, that the null space condition is equivalent to connected components, and that the single zero eigenvalue with $m=n-1$ operations implies a tree structure, completely defeating simple keyword-based tree DFS pattern matching while preserving the exact numeric bounds.
</RATIONALE>
<PRESERVED_ANSWER>
The matrix $M^*$ is the negative Laplacian of the graph formed by the selected operations; vectors in its null space are constant on connected components, so forcing $x_{c_a} = x_{c_b}$ for all targets is mathematically identical to requiring all targets to be connected by the chosen edges, leaving the optimal subset and its cost unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the minimum weight Steiner tree on a tree, which is solvable by rooting the tree and summing weights of edges on paths between targets in $O(n)$ time, keeping it firmly in the polynomial time class P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "subset of operations" as allowing multiple applications of the same operation, though the word "subset" strictly implies each available operation is either included once or excluded entirely.
</RISK>
