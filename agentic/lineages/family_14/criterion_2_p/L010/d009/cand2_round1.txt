<METHOD_NAME>System of Equations Shift</METHOD_NAME>
<METHOD_DESCRIPTION>Translates a graph connectivity problem into an equivalent algebraic problem of enforcing variable equality through a system of equations. By framing edges as pairwise equality constraints, and target connectivity as enforcing uniform values across a subset of variables across all possible solutions, it obscures the underlying tree structure. Models relying on graph pattern matching (e.g., detecting "spanning" or "tree") will fail to recognize the equivalence, while models that reason mathematically will understand that enforcing equality requires a chain of equations, which forms a tree.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Homogeneity Enforcement

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of continuous variables $x_1, x_2, \dots, x_n$ over the real numbers. 

You are provided with a catalog of allowable coupling equations. Each coupling equation is defined by a pair of variable indices $u$ and $v$, and when enforced, imposes the strict condition that $x_u = x_v$. Enforcing a particular coupling equation requires an energy input of $w$. 

The catalog has a special structural property: if all available coupling equations were simultaneously enforced, the system's solution space would be restricted entirely to states where $x_1 = x_2 = \dots = x_n$. The total number of coupling equations in the catalog is precisely one less than the number of variables $n$.

A subset of $t$ variables are marked as the observation target. 

You must choose a subset of the coupling equations to enforce. Your chosen subset must guarantee that any valid solution to the enforced equations has the property that all variables in the observation target share the exact same value. 

Your goal is to calculate the minimum possible total energy input required to enforce such a subset. (If the observation target contains only one variable, the requirement is vacuously satisfied by enforcing zero equations, for a total energy input of zero).

## Input

The first line provides three integers: $n$, $m$, and $t$. The number of variables $n$ ranges from one up to the number of seconds in 55 hours, 33 minutes, and 20 seconds. The number of available coupling equations $m$ is always exactly one less than $n$. The size of the observation target $t$ ranges from one up to $n$.

The second line contains $t$ distinct integers representing the indices of the observation target variables.

Following this, there are $m$ lines, each detailing a single allowable coupling equation with three integers: $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$). This indicates that the equation $x_u = x_v$ requires an energy input of $w$. The energy input $w$ is at least one and does not exceed the square of one thousand.

## Output

Print a single integer: the minimum possible total energy input required to select a valid subset of coupling equations.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the observation target variables are 1 and 4. We must ensure that any solution to our enforced equations satisfies $x_1 = x_4$. By enforcing the equations $x_1 = x_2$ (energy 5), $x_2 = x_3$ (energy 1), and $x_3 = x_4$ (energy 2), we guarantee that $x_1 = x_4$. The total energy input is 5 + 1 + 2 = 8. Because the allowable equations are non-redundant, no cheaper subset enforces this equality.

In Example 2, there is only one observation target variable (variable 3). Since there are no pairs of distinct target variables, the condition is vacuously satisfied by the empty set of equations. The minimum possible total energy input is 0.
</STATEMENT>
<RATIONALE>
The problem was reframed from selecting vectors that span a set of differences to selecting pairwise equality equations that force a subset of variables to be equal. The explicit guarantee of spanning all basis vectors was replaced with the mathematically equivalent condition that enforcing all equations restricts the solution space to uniform values. Numeric bounds were stated indirectly (e.g., $n \le 200000$ as the number of seconds in 55h 33m 20s). This forces the model to recognize that enforcing equality across all solutions requires the selected equations to form a connected component containing the target variables, without relying on graph or vector-space buzzwords.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that any valid solution must have equal values for the target variables holds if and only if the enforced equations form a connected component containing all targets; since the full set of $n-1$ equations connects all variables, it forms a tree, making the minimum cost subset identical to the minimal subtree connecting the targets.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains finding the minimum Steiner tree on a graph that is guaranteed to be a tree, which is solvable in $O(n)$ time and remains in P.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret "any valid solution to the enforced equations" as allowing the trivial solution (all zeros) to satisfy the condition without enforcing any equations, but the phrase "any valid solution... has the property" logically means the property must hold across the entire solution space, which robustly requires the variables to be algebraically linked.
</RISK>
