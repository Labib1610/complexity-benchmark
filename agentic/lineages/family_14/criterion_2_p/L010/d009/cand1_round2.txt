<STATEMENT>
# Ideal Generator Pricing

Time limit: 2 s   Memory limit: 256 MB

## Description

You are working with linear combinations of $n$ abstract variables, indexed from $1$ to $n$. Let $x_i$ denote the $i$-th variable.

You are given a pool of $m$ available difference generators. Each available generator is specified by two indices $u$ and $v$ and an associated price $w$, representing the expression $x_u - x_v$. The price to include this generator in your chosen working set is $w$. 

You are mathematically guaranteed that if you were to include all $m$ available generators, their linear span would contain all expressions of the form $x_i - x_j$ for any $1 \le i, j \le n$. The total number of available generators $m$ is exactly $n - 1$. This implies a specific structural condition: the given pairs $(u, v)$ form a connected network with no alternative routes, meaning there is exactly one minimal sequence of generators that can be linearly combined to form the difference between any two variables.

A specific subset of $t$ indices are designated as target variables. 

You must select a subset of the available generators to form a working set. Your working set must satisfy the following condition: for every pair of target variables $c_a$ and $c_b$, the difference expression $x_{c_a} - x_{c_b}$ must be in the linear span of your working set. 

Your objective is to determine the minimum possible total price of a working set that satisfies this requirement. 

If there is only one target variable, the requirement is vacuously satisfied by an empty working set, and the minimum price is zero.

## Input

The first line provides three integers: $n$, $m$, and $t$. The number of variables can be up to two hundred thousand ($1 \le n \le 200000$). The number of available generators $m$ is always exactly $n - 1$. The number of target variables $t$ can range from one up to all variables ($1 \le t \le n$).

The second line contains $t$ distinct integers representing the indices of the target variables.

Following this, there are $m$ lines, each detailing a single available generator with three integers: $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$). This represents the generator $x_u - x_v$ with price $w$. The price $w$ to include any single generator is at least one and does not exceed one million units ($1 \le w \le 1000000$).

## Output

Print a single integer: the minimum possible total price required to select a valid working set of generators.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the target variables are 1 and 4. We must ensure $x_1 - x_4$ is in the linear span of our selected working set. By selecting the generators $x_1 - x_2$ (price 5), $x_2 - x_3$ (price 1), and $x_3 - x_4$ (price 2), we can form the linear combination $x_1 - x_4 = (x_1 - x_2) + (x_2 - x_3) + (x_3 - x_4)$. The total price is 5 + 1 + 2 = 8. Because the available generators are linearly independent, no cheaper subset spans this difference.

In Example 2, there is only one target variable (variable 3). Since there are no pairs of distinct target variables, the condition is vacuously satisfied by the empty set. The minimum possible total price is 0.
