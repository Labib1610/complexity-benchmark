Looking at this problem:

- We have a tree with $n$ nodes and $n-1$ edges (generators).
- We need to select a subset of edges such that all target nodes are in the same connected component.
- This is the minimum Steiner tree problem on a tree: find the minimum cost subtree connecting all target nodes.

The key insight is that an edge must be included if and only if both sides of the edge (when the edge is removed) contain at least one target node. This is because:
- If only one side has targets, the edge isn't needed to connect targets to each other.
- If both sides have targets, the edge is essential to connect the targets on opposite sides.

So the algorithm is:
1. Root the tree at any node.
2. For each node, compute whether its subtree contains any target.
3. For each edge (parent to child), include it if the child's subtree has targets AND there are targets outside the child's subtree.

Let me verify with the examples:
- Example 1: Tree 1-2-3-4, targets {1,4}. Edge 1-2: subtree of 2 has target 4, outside has target 1 → include (5). Edge 2-3: subtree of 3 has target 4, outside has target 1 → include (1). Edge 3-4: subtree of 4 has target 4, outside has target 1 → include (2). Total = 8. ✓
- Example 2: Only 1 target, no edges needed. Total = 0. ✓
- Example 3: Tree 1-2-3, targets {1,2,3}. All edges needed. Total = 4+5 = 9. ✓

```python
import sys
from collections import deque

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    t = int(input_data[idx]); idx += 1
    
    targets = set()
    for i in range(t):
        targets.add(int(input_data[idx])); idx += 1
    
    adj = [[] for _ in range(n + 1)]
    edges = []
    for i in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        w = int(input_data[idx]); idx += 1
        adj[u].append((v, w, i))
        adj[v].append((u, w, i))
        edges.append((u, v, w))
    
    if t <= 1:
        print(0)
        return
    
    parent = [0] * (n + 1)
    parent_edge = [-1] * (n + 1)
    order = []
    visited = [False] * (n + 1)
    
    root = 1
    visited[root] = True
    parent[root] = 0
    queue = deque([root])
    while queue:
        u = queue.popleft()
        order.append(u)
        for v, w, eid in adj[u]:
            if not visited[v]:
                visited[v] = True
                parent[v] = u
                parent_edge[v] = eid
                queue.append(v)
    
    has_target = [False] * (n + 1)
    for node in targets:
        has_target[node] = True
    
    for u in reversed(order):
        p = parent[u]
        if p != 0 and has_target[u]:
            has_target[p] = True
    
    total = 0
    for u in range(2, n + 1):
        if has_target[u]:
            eid = parent_edge[u]
            total += edges[eid][2]
    
    print(total)

solve()
```
