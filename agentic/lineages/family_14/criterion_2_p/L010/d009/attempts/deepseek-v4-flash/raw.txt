We can model the generators as edges of a tree (since \( m = n-1 \) and the graph is connected).  
The condition that all differences between target variables are in the span means that the selected edges must connect all target vertices into one connected component in the tree.

Thus, the problem reduces to:  
Given a tree with weighted edges, find the minimum total weight of edges needed to connect all target nodes.

This is the **Steiner tree** problem on a tree, which can be solved by taking the minimal subtree that spans all target nodes and summing its edge weights.

We can do this by:
1. Root the tree at any target node.
2. Mark all target nodes.
3. Perform DFS to determine which edges are needed (edges that lead to at least one target node in their subtree).
4. Sum the weights of those edges.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    targets = set(map(int, input().split()))
    
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    if t <= 1:
        print(0)
        return
    
    # Root at any target
    root = next(iter(targets))
    
    parent = [0] * (n + 1)
    parent_edge_weight = [0] * (n + 1)
    visited = [False] * (n + 1)
    
    # DFS to build parent info
    stack = [root]
    visited[root] = True
    order = []
    while stack:
        u = stack.pop()
        order.append(u)
        for v, w in adj[u]:
            if not visited[v]:
                visited[v] = True
                parent[v] = u
                parent_edge_weight[v] = w
                stack.append(v)
    
    # Determine which edges are needed
    needed = [False] * (n + 1)
    for node in targets:
        needed[node] = True
    
    total = 0
    # Process in reverse order (post-order)
    for u in reversed(order):
        if u == root:
            continue
        if needed[u]:
            total += parent_edge_weight[u]
            needed[parent[u]] = True
    
    print(total)

if __name__ == "__main__":
    solve()
```
