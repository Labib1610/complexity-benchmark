<STATEMENT>
# Component Fusion

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system consisting of $n$ distinct physical components. The system contains $m$ bidirectional fusion links, each connecting a pair of components. The arrangement of these links guarantees that the entire system is fully cohesive (all components are interlinked). The number of links $m$ is exactly $n - 1$.

A specific subset of $t$ components are classified as "critical cores".

You have the ability to activate a fusion process along any chosen link. When you activate the link originally connecting component $u$ and component $v$, those two components permanently merge into a single unified component. Any other links that were previously connected to $u$ or $v$ will automatically reconnect to this new merged component. 

Each of the $m$ links has a fixed, inherent energy cost $w$ to activate. This cost remains constant regardless of when the link is activated or how many components have already been merged into its endpoints.

Your objective is to select and activate a subset of the links such that all $t$ critical cores are merged together into one single component. You may activate any number of links to achieve this. Links that are not activated remain in their current state and cost zero energy.

Determine the minimum total energy expenditure required to ensure all $t$ critical cores end up merged into the same component.

## Input

The first line provides three integers: $n$, $m$, and $t$. The system supports a maximum of two hundred thousand components ($1 \le n \le 200000$). The number of links $m$ is always $n - 1$. The number of critical cores $t$ can range from a single component up to the entire system ($1 \le t \le n$).

The second line contains $t$ distinct integers representing the IDs of the critical cores.

Following this, there are $m$ lines, each detailing a single fusion link with three integers: $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$). The energy cost $w$ for activating any single link is at least one and does not exceed one million units ($1 \le w \le 1000000$). 

## Output

Print a single integer: the minimum total energy expenditure required.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the critical cores are components 1 and 4. To merge them, you can activate the link between 1 and 2 (cost 5), merging them into a combined component {1, 2}. Then activate the link between 3 and 4 (cost 2), merging them into {3, 4}. Finally, activate the link originally between 2 and 3 (cost 1), which now connects {1, 2} and {3, 4}. This merges all four original components into a single component. The total energy expenditure is 5 + 2 + 1 = 8. This is the minimum possible cost.

In Example 2, there is only one critical core (component 3). It is already trivially merged with itself, requiring no links to be activated. The total energy expenditure is 0.
