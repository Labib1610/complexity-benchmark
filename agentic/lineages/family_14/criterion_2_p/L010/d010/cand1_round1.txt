<METHOD_NAME>Invariant Subspace Linear Dependency</METHOD_NAME>
<METHOD_DESCRIPTION>Translates the requirement of graph connectivity (spanning differences) into a linear algebraic condition on the invariant subspace of a set of averaging operators. The condition $\sum x_{c_i} = t \cdot x_{c_1}$ must hold for all invariant states, which mathematically forces all targets to belong to the same connected component. This defeats models by forcing them to deduce the component-equality requirement from a sum identity, breaking their immediate heuristic mapping from $m=n-1$ to a tree-pruning algorithm.</METHOD_DESCRIPTION>

<STATEMENT>
# Subspace Invariant Pricing

Time limit: 2 s   Memory limit: 256 MB

## Description

You are working in an $n$-dimensional real vector space. Vectors are represented as $x = (x_1, x_2, \dots, x_n)$.

You are given a pool of $m$ available linear operators. Each operator is specified by two indices $u$ and $v$ and an associated price $w$. 
The operator $M_{u,v}$ acts on a vector $x$ by replacing both its $u$-th and $v$-th coordinates with their simple average, $\frac{x_u + x_v}{2}$, while leaving all other coordinates unchanged. 
The price to include this operator in your working set is $w$. 

You are mathematically guaranteed that if you were to include all $m$ available operators in your working set, the only vectors that would remain unchanged by all of them are those where all $n$ coordinates are identical. The total number of available operators $m$ is exactly $n - 1$.

A subset of $t$ distinct indices are designated as target coordinates, $c_1, c_2, \dots, c_t$. 

You must select a subset of the available operators to form a working set. 
A vector $x$ is called an *invariant state* of your working set if $M_{u,v} x = x$ for every operator $M_{u,v}$ that you have included in the working set. 

Your working set must satisfy the following condition: for every invariant state $x$ of your working set, the sum of the values at the target coordinates must exactly equal $t$ times the value at the first target coordinate. Mathematically, this requires:
$$ \sum_{i=1}^t x_{c_i} = t \cdot x_{c_1} $$
This equation must hold true for *all* invariant states $x$ of your selected working set. 

Your objective is to determine the minimum possible total price of a working set that satisfies this requirement. 

If there is only one target coordinate ($t=1$), the requirement simplifies to $x_{c_1} = x_{c_1}$, which is always satisfied by an empty working set, resulting in a minimum price of zero.

## Input

The first line provides three integers: $n$, $m$, and $t$. The dimension $n$ can be up to two hundred thousand ($1 \le n \le 200000$). The number of available operators $m$ is always exactly $n - 1$. The number of target coordinates $t$ can range from one up to $n$ ($1 \le t \le n$).

The second line contains $t$ distinct integers representing the indices of the target coordinates. The first integer on this line is $c_1$.

Following this, there are $m$ lines, each detailing a single available operator with three integers: $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$). This represents the operator $M_{u,v}$ with price $w$. The price $w$ to include any single operator is at least one and does not exceed one million units ($1 \le w \le 1000000$).

## Output

Print a single integer: the minimum possible total price required to select a valid working set of operators.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the target coordinates are 1 and 4. The required condition is that for any invariant state $x$, $x_1 + x_4 = 2 \cdot x_1$, which mathematically simplifies to $x_1 = x_4$. We must select a working set of operators such that any vector unchanged by these operators has $x_1 = x_4$. By selecting the operators for (1, 2) at price 5, (2, 3) at price 1, and (3, 4) at price 2, any invariant state must satisfy $x_1 = x_2$, $x_2 = x_3$, and $x_3 = x_4$, which guarantees $x_1 = x_4$. The total price is 5 + 1 + 2 = 8. No cheaper subset forces this condition.

In Example 2, there is only one target coordinate (index 3). The condition is vacuously satisfied by the empty set, as $x_3 = 1 \cdot x_3$ holds for any vector. The minimum possible total price is 0.

<RATIONALE>
Framed the requirement of graph connectivity as a linear algebraic condition on the invariant subspace of a set of averaging operators. The condition $\sum x_{c_i} = t \cdot x_{c_1}$ must hold for all invariant states, which mathematically forces all target coordinates to belong to the same interdependent component. This forces the model to deduce the component-equality requirement from a sum identity, breaking their immediate heuristic mapping from $m=n-1$ to a tree algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
An invariant state requires $x_u = x_v$ for all selected operators, meaning coordinates are constant on the connected components of the selected pairs; the condition $\sum_{i=1}^t x_{c_i} = t \cdot x_{c_1}$ holds for all such arbitrary assignments if and only if all targets are in the same component, which is mathematically identical to the original spanning requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains finding the minimum cost subset of edges to connect a set of target vertices in a graph that is structurally guaranteed to be a tree, which is solvable in $O(n)$ time.
</PRESERVED_CLASS>
<RISK>
Models might struggle to mathematically prove that the sum condition strictly requires all targets to be in the same component (rather than satisfying some specific linear dependency), though the deduction is completely rigorous and unambiguous.
</RISK>
