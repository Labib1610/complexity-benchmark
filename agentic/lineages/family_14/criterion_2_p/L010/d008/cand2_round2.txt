<STATEMENT>
# Variable Equality Enforcement

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a mathematical model consisting of $n$ unknown variables, denoted $x_1, x_2, \dots, x_n$. You are provided with a set of $m$ optional equality constraints. Each constraint, if activated, enforces that variable $x_u$ and variable $x_v$ are strictly equal ($x_u = x_v$), and requires paying a specific activation cost of $w$.

The model's structure guarantees that if you were to activate all $m$ available constraints, it would logically imply that all $n$ variables are equal to each other. Furthermore, the total number of provided constraints $m$ is exactly $n - 1$.

A specific subset of $t$ variables are designated as target variables. 

You must select a subset of the constraints to activate such that it is logically implied by the selected constraints that all $t$ target variables are equal to each other. 

Your objective is to determine the minimum possible total activation cost required to achieve this. (If there is only one target variable, it trivially equals itself, requiring zero constraints and thus a cost of zero).

## Input

The first line provides three integers: $n$, $m$, and $t$. The model contains up to two hundred thousand variables ($1 \le n \le 200000$). The number of available constraints $m$ is always exactly $n - 1$. The number of target variables $t$ can range from one up to all variables ($1 \le t \le n$).

The second line contains $t$ distinct integers representing the indices of the target variables.

Following this, there are $m$ lines, each detailing a single equality constraint with three integers: $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$). The activation cost $w$ for any single constraint is at least one and does not exceed one million ($1 \le w \le 1000000$).

## Output

Print a single integer: the minimum possible total activation cost required to select a set of constraints such that all target variables are logically forced to be equal.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the target variables are $x_1$ and $x_4$. To ensure $x_1 = x_4$, the constraints between 1 and 2 (cost 5), 2 and 3 (cost 1), and 3 and 4 (cost 2) must be activated. This logically implies $x_1 = x_2 = x_3 = x_4$. The total cost is 5 + 1 + 2 = 8. This is the minimum possible total cost.

In Example 2, there is only one target variable ($x_3$). Since no equality between multiple target variables needs to be enforced, zero constraints need to be activated. The minimum possible total cost is 0.
</STATEMENT>
<RATIONALE>
The problem was reframed from a network synchronization scenario into a system of algebraic equality constraints. This removes all graph-related vocabulary (registers, protocols) while preserving the exact mathematical structure (variables as vertices, constraints as edges, logical implication as connectivity), forcing the model to recognize the underlying tree structure without standard graph cues. I also restored the exact literal numeric bounds to comply with the I/O contract.
</RATIONALE>
<PRESERVED_ANSWER>
The logical implication of equality among variables maps exactly to paths in a graph, so finding the minimum cost to equate a subset of variables is identical to finding the minimum weight subtree connecting those vertices.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The global condition that $m = n - 1$ constraints equate all $n$ variables guarantees the constraint graph is a tree, making the required minimal subset unique and computable in linear time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "logically implied" as allowing complex algebraic derivations, but since the constraints are purely simple equalities ($x_u = x_v$), equivalence classes are the only possible deduction.
</RISK>
