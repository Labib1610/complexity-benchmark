<STATEMENT>
# Industrial Component Routing

Time limit: 2 s   Memory limit: 256 MB

## Description

An industrial facility operates **n** workstations, linked by a network of **m** bidirectional conveyor belts. The facility's transport network is fully integrated, meaning components can be routed between any two workstations. To minimize infrastructure costs, the network contains absolutely no redundant belts; removing any single belt would split the facility into isolated sections.

A specific inspection protocol involves **t** designated quality control stations. During this protocol, components must be able to flow freely among all **t** of these stations. Conveyor belts must be powered on to allow this flow, and each belt between workstation **u** and workstation **v** requires a specific energy overhead **w** to activate.

Your task is to calculate the minimum total energy overhead required to activate a set of conveyor belts such that every quality control station can route components to every other quality control station. Components may pass through non-designated workstations along the way.

## Input

The first line contains three integers **n**, **m**, and **t**. The number of workstations **n** is between 1 and 200,000. The number of quality control stations **t** is between 1 and **n**. The number of belts **m** is exactly **n** − 1, adhering to the non-redundant layout described above.

The second line contains **t** distinct integers representing the identifiers of the quality control stations.

Each of the following **m** lines contains three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), indicating a conveyor belt connecting workstation **u** and workstation **v** with an activation energy overhead of **w** (1 ≤ **w** ≤ 1,000,000). The layout guarantees full integration.

## Output

Output a single integer representing the minimum total energy overhead required to link the **t** quality control stations.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, quality control stations 1 and 4 can only exchange components by routing through workstations 2 and 3. Thus, all three conveyor belts (overheads 5, 1, and 2) must be activated, resulting in a total overhead of 8.
In Example 2, with only one quality control station, no conveyor belts need to be activated.
