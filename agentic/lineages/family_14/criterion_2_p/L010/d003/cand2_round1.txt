<STATEMENT>
# Factory Floor Integration

Time limit: 2 s   Memory limit: 256 MB

## Description

A manufacturing complex contains **n** assembly nodes. These nodes are linked by **m** bidirectional transit tracks. The complex's internal logistics guarantee that materials can be transported between any pair of assembly nodes through some sequence of tracks.

A specific number of these nodes, denoted as **t**, are designated as audit centers. A new compliance directive requires that all audit centers must be capable of transferring materials to one another. Tracks are normally dormant. Activating the track between node **u** and node **v** demands a specific activation energy **w**. Materials can only pass through activated tracks.

Calculate the lowest possible total activation energy needed to turn on a collection of tracks such that every audit center can reach every other audit center (potentially routing materials through other intermediate assembly nodes).

## Input

The first line provides three integers **n**, **m**, and **t**. The node count **n** is at least 1. The facility was constructed using a blueprint that accommodates up to two hundred thousand nodes, which serves as the strict upper limit for **n**. The track count **m** is exactly the minimum necessary to keep all **n** nodes fully interconnected. The count of audit centers **t** requires at least a single center, and is bounded by the total node count.

The second line contains **t** distinct integers: the specific IDs of the audit centers.

Each of the subsequent **m** lines specifies three integers **u**, **v**, and **w**. Nodes **u** and **v** are distinct valid node IDs (indexed from 1 to **n**), indicating a track connects them. The activation energy **w** is bounded below by 1, and cannot exceed the local circuit breaker limit of one million units. The track layout guarantees full reachability across all nodes as detailed earlier.

## Output

Output a single integer representing the minimum total activation energy to ensure all audit centers are interconnected.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, audit centers 1 and 4 can only transfer materials via nodes 2 and 3, so all three transit tracks (energies 5, 1, and 2) must be activated, totaling 8.
In Example 2, there is only one audit center, so no transit tracks need to be activated.
