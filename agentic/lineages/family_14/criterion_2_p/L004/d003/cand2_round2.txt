# Quarantine Network

Time limit: 2 s
Memory limit: 256 MB

## Description

A communication network consists of **n** workstations (numbered 1 to **n**) and **m** bidirectional data links. The network allows data to be routed between any two workstations. 

A security scan has identified exactly **t** workstations that must be quarantined together. To do this, you must activate a subset of the data links to form a continuous subnetwork that contains all **t** identified workstations. The active subnetwork must allow data to travel between any two identified workstations (either directly or through intermediate workstations). You may include unidentified workstations in this active subnetwork if they are needed to bridge the connections.

Activating a data link requires a certain amount of power. Your task is to select a subset of links that connects all **t** identified workstations while minimizing the total power required.

## Input

The first line contains three integers **n**, **m**, and **t**. The total number of workstations **n** is bounded by 1 ≤ **n** ≤ 200000. The number of data links **m** is exactly **m** = **n** − 1. The number of identified workstations **t** is restricted by 1 ≤ **t** ≤ **n**.
The second line contains **t** distinct integers: the identifiers of the identified workstations.
Each of the next **m** lines contains three integers **u**, **v**, and **w**. These specify a bidirectional data link between distinct workstations **u** and **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**). The power **w** required to activate this link is bounded by 1 ≤ **w** ≤ 1000000.

## Output

Print a single integer: the minimum total power required to form a continuous network connecting all identified workstations.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```
