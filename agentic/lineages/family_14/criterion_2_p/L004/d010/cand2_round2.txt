<STATEMENT>
# Subspace Spanning Cost

Time limit: 2 s
Memory limit: 256 MB

## Description

You are working in a vector space over the real numbers with $n$ standard basis vectors, denoted $e_1, e_2, \dots, e_n$.

You are provided with a list of $m$ potential vectors to purchase. Each potential vector is specified by a pair of distinct indices $u$ and $v$, and is defined exactly as $e_u - e_v$. Purchasing this vector requires a cost of $w$.

The given list of potential vectors satisfies a strict structural guarantee: there are exactly $m = n - 1$ vectors available in total, and the linear span of all $m$ available vectors has a dimension of exactly $n - 1$.

Your goal is to purchase a subset of these vectors such that a specific group of $t$ priority indices satisfy the following condition: for any two priority indices $a$ and $b$, the vector $e_a - e_b$ must lie within the linear span of the subset of vectors you have purchased.

What is the minimum total cost required to purchase a valid subset of vectors?

## Input

The first line contains three integers **n**, **m**, and **t**. The number of basis vectors is **n** (1 ≤ **n** ≤ 200000). The number of potential vectors **m** is always exactly **n** − 1. The number of priority indices is **t** (1 ≤ **t** ≤ **n**).
The second line contains **t** distinct integers: the priority indices.
Each of the next **m** lines contains three integers **u**, **v**, and **w**. These represent a potential vector $e_u - e_v$ (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), which costs **w** to purchase (1 ≤ **w** ≤ 1000000). Note that since $e_u - e_v = -(e_v - e_u)$, the order of $u$ and $v$ does not change the spanned subspace, and each option can be treated symmetrically.

## Output

Print a single integer: the minimum total cost required.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```
</STATEMENT>
<RATIONALE>
The problem has been reframed using the algebraic properties of a graph's incidence matrix. The vectors $e_u - e_v$ correspond to edges. The guarantee that $n-1$ vectors span a subspace of dimension $n-1$ mathematically encodes that the graph is connected and acyclic. The requirement that $e_a - e_b$ lies in the span of the selected subset is equivalent to the existence of a path between $a$ and $b$. This removes all graph-theoretic terminology while remaining perfectly mathematically rigorous, forcing models to deduce the tree structure from linear algebra to apply the correct $O(n)$ algorithm instead of attempting an $O(n^3)$ Gaussian elimination.
</RATIONALE>
<PRESERVED_ANSWER>
The linear span of a set of vectors of the form $e_u - e_v$ contains $e_a - e_b$ if and only if $a$ and $b$ are in the same connected component of the corresponding graph, making the required minimal subset structurally identical to the Steiner tree on the same graph.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying mathematical object remains exactly a tree (implied by rank $n-1$ for $n-1$ vectors), meaning the $O(n)$ DFS approach is still fully applicable and optimal.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the vector space as being over a finite field instead of the real numbers, but this is mitigated by explicitly stating "vector space over the real numbers".
</RISK>
