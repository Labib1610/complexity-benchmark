<STATEMENT>
# Subspace Projection Alignment

Time limit: 2 s
Memory limit: 256 MB

## Description

You are working with an $n$-dimensional vector space over the real numbers. The standard basis vectors are denoted as $\mathbf{e}_1, \mathbf{e}_2, \dots, \mathbf{e}_n$.

You have a collection of $m$ candidate difference vectors. Each candidate vector is formed by taking two distinct basis vectors $\mathbf{e}_u$ and $\mathbf{e}_v$ and subtracting them to form $\mathbf{v} = \mathbf{e}_u - \mathbf{e}_v$. Each candidate vector has an associated inclusion penalty $w$.

The collection contains exactly $m = n - 1$ candidate vectors. You are guaranteed that if you were to select all $m$ of them, their linear span would have exactly dimension $n - 1$.

You are also given a target list of $t$ specific coordinate indices.

Your objective is to select a subset of the candidate vectors such that for any two indices $a$ and $b$ in the target list, the difference vector $\mathbf{e}_a - \mathbf{e}_b$ lies within the linear span of your selected subset. (If $t \le 1$, this condition is vacuously satisfied by the empty set).

What is the minimum total inclusion penalty of a valid subset of candidate vectors?

## Input

The first line contains three integers **n**, **m**, and **t**. The dimension of the space is **n** (1 ≤ **n** ≤ 200000). The number of candidate vectors **m** is always exactly **n** − 1. The number of target indices is **t** (1 ≤ **t** ≤ **n**).
The second line contains **t** distinct integers: the target coordinate indices.
Each of the next **m** lines contains three integers **u**, **v**, and **w**. These represent a candidate vector $\mathbf{e}_u - \mathbf{e}_v$ (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), which has an inclusion penalty of **w** (1 ≤ **w** ≤ 1000000).

## Output

Print a single integer: the minimum total inclusion penalty required.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```

```

**Output**
```
0
```

### Example 3

**Input**
```

2 3 5
```

**Output**
```
9
```

<RATIONALE>
The problem was reframed from a network connectivity task to an algebraically isomorphic task involving the linear span of basis difference vectors. Models that rely on keyword matching will attempt generic vector space algorithms (like Gaussian elimination) which will fail the time limit, forcing them to genuinely deduce that the vectors form the incidence matrix of a tree.
</RATIONALE>
<PRESERVED_ANSWER>
The linear span of a subset of difference vectors contains e_a - e_b if and only if a and b are connected in the graph formed by those vectors; thus, the minimum penalty subset is exactly the minimal Steiner tree.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the computation of the Steiner tree on a given tree, which is solvable in O(n) time.
</PRESERVED_CLASS>
