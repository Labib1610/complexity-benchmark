<STATEMENT>
# Reference Frame Alignment

Time limit: 2 s
Memory limit: 256 MB

## Description

You are configuring a navigation system that operates across a set of distinct spatial reference frames, numbered 1 to **n**.

To translate coordinates between frames, you can activate bidirectional mapping modules. The manufacturer provides a specific catalog of available modules. This catalog is minimally comprehensive: there are exactly **m** = **n** − 1 modules available, and if all were activated, there would be exactly one valid sequence of mappings bridging any two distinct reference frames.

You are given a list of **t** critical reference frames. You must activate a subset of the available mapping modules such that every critical frame is mutually translatable with every other critical frame. (Two frames are mutually translatable if there is a sequence of activated modules connecting them; this sequence may pass through non-critical frames as intermediate steps. If there is only one critical frame, this condition is trivially satisfied with no activated modules.)

Each mapping module has an activation cost **w**. What is the minimum total cost of the modules you must activate to ensure all critical reference frames are mutually translatable?

## Input

The first line contains three integers: the system's frame capacity **n**, the catalog size **m**, and the critical target count **t**. The system requires at least one frame and supports a physical maximum of 200,000 frames. The catalog size **m** is always exactly **n** − 1. The critical target count **t** ranges from a single frame up to the total number of instantiated frames **n**.

The second line contains **t** distinct integers: the identifiers of the critical reference frames.

Each of the next **m** lines contains three integers **u**, **v**, and **w**. These describe an available module providing a bidirectional mapping between frame **u** and frame **v** (which are always distinct valid frame identifiers). The activation cost **w** requires a minimum of 1 energy credit and has a hardware cap of 1,000,000 energy credits.

## Output

Print a single integer: the minimum total activation cost required.

**Output**

8

<RATIONALE>
The framing was shifted from symmetric groups and permutation orbits to a static spatial infrastructure network (reference frames and mapping modules). This removes the group theory vocabulary that allowed models to easily map the problem to a transposition graph, while strictly preserving the static connectivity objective to prevent task drift. The numeric bounds were woven into hardware limitations according to the S07 strategy.
</RATIONALE>
<PRESERVED_ANSWER>
The problem still asks for the minimum-cost subset of edges to connect a specific set of terminal vertices within a graph that is guaranteed to be a single connected component with exactly n-1 edges, maintaining the exact identical mathematical structure.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying graph is still explicitly guaranteed to have exactly n-1 edges and a unique path between any two nodes, meaning it is still a tree; finding the minimum subgraph connecting terminals on a tree remains solvable in O(n) time.
</PRESERVED_CLASS>
