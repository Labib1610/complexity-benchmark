<STATEMENT>
# Zero-Sum Material Routing

Time limit: 2 s
Memory limit: 256 MB

## Description

You manage a logistics network of $n$ storage facilities. 

You are provided with a pool of $m$ optional bidirectional pipelines. Each pipeline connects facility $u$ and facility $v$ and has an associated one-time construction cost $w$. Once built, a pipeline has infinite capacity, allowing you to move any arbitrary amount of material between $u$ and $v$ in either direction.

You have a specific list of $t$ critical facilities. 

Your objective is to select a subset of pipelines to build such that the network can handle any localized supply-demand imbalances among the critical facilities. Specifically, the built network must satisfy the following requirement:
For *any* arbitrary initial distribution of material across the $t$ critical facilities—provided the total net amount of material across these $t$ facilities is exactly zero—it must be possible to route material through the built pipelines (which strictly conserves the total amount of material in the network) such that every facility in the entire network ends up with exactly zero material. (Assume all non-critical facilities always start with zero material).

The pool of available pipelines is minimal and complete: there are exactly $m = n - 1$ pipelines available, and if you were to build all of them, you would be able to resolve any zero-sum distribution across the entire network of $n$ facilities.

What is the minimum total construction cost of the pipelines you must build to satisfy this routing requirement?

## Input

The first line contains three integers **n**, **m**, and **t**. The number of facilities is **n** (1 ≤ **n** ≤ 200000). The number of available pipelines **m** is always exactly **n** − 1. The number of critical facilities is **t** (1 ≤ **t** ≤ **n**).
The second line contains **t** distinct integers: the identifiers of the critical facilities.
Each of the next **m** lines contains three integers **u**, **v**, and **w**. These denote an optional pipeline between facility **u** and facility **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), which costs **w** to build (1 ≤ **w** ≤ 1000000).

## Output

Print a single integer: the minimum total construction cost required.

<RATIONALE>
The problem was completely reframed from group theory (transpositions, subgroups, orbits) to logistics and network flow. The requirement that elements belong to the same orbit was mapped to the requirement that any zero-sum material distribution among critical nodes can be routed to zero. This forces the model to realize that infinite-capacity zero-sum routing is strictly equivalent to the critical nodes being in the same connected component, thereby requiring a Steiner tree on the given tree.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that any zero-sum distribution among the target set can be routed to zero is mathematically equivalent to all target elements being in the same connected component, which means the minimum cost subset of edges is still exactly the unique Steiner tree connecting the target elements.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Because the $m=n-1$ edges can route any distribution across all $n$ nodes, they form a connected tree; finding the minimal connecting subgraph for $t$ nodes in a tree remains solvable in $O(n)$ time via a single post-order traversal.
</PRESERVED_CLASS>
<RISK>
A reader might incorrectly assume that the cost $w$ is paid per unit of material moved rather than as a one-time fixed cost, though the phrases "one-time construction cost" and "minimum total construction cost" strongly mitigate this.
</RISK>
