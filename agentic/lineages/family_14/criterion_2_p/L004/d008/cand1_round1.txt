<METHOD_NAME>Algebraic Equality Constraint Framing</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the group-theoretic transposition and orbit concepts with a system of variables and pairwise equality constraints. Forcing a subset of variables to be equal via pairwise constraints is structurally identical to finding a connected component in a graph, but avoids all graph/group terminology.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<STATEMENT>
# Ledger Reconciliation

Time limit: 2 s
Memory limit: 256 MB

## Description

A financial auditing system tracks a set of unknown ledger balances, represented as variables $x_1, x_2, \dots, x_n$.

You are provided with a pool of $m$ optional reconciliation rules. Each rule, if enforced, guarantees that $x_u = x_v$ for two specific balances $u$ and $v$, and has an associated enforcement cost $w$.

The pool of available rules is comprehensive yet non-redundant: there are exactly $m = n - 1$ rules available, and enforcing all of them would logically force all $n$ balances to take on the exact same value.

Your objective is to select a subset of these rules to enforce. You must ensure that under the chosen subset of rules, a specific list of $t$ critical balances are logically forced to be equal to one another. The relationships between the remaining non-critical balances do not matter, as long as the critical ones are guaranteed to share the same value.

What is the minimum total cost of the rules you must enforce to satisfy this condition?

## Input

The first line contains three integers **n**, **m**, and **t**. The number of balances is **n** (the system requires at least one and supports up to two hundred thousand). The number of available rules **m** is always exactly **n** minus one. The number of critical balances is **t** (ranging from one up to **n**).
The second line contains **t** distinct integers: the identifiers of the critical balances.
Each of the next **m** lines contains three integers **u**, **v**, and **w**. These denote an optional rule forcing balance **u** to equal balance **v** (valid identifiers between 1 and **n**, with **u** $\neq$ **v**), which requires **w** computational credits to enforce (ranging from one to one million).

## Output

Print a single integer: the minimum total cost required to force the critical balances to be equal.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```

```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3

2 3 5
```

**Output**
```
9
```
</STATEMENT>
<RATIONALE>
I replaced the group-theoretic framing (symmetric group, transpositions, orbits) with an algebraic system of variables and pairwise equality constraints. Models can no longer rely on standard subgroup orbit templates, and must deduce that enforcing pairwise equalities among $n$ variables with $n-1$ non-redundant rules is isomorphic to finding a minimal spanning subtree. Numeric bounds were also embedded into the scenario text (S07) to prevent simple parsing.
</RATIONALE>
<PRESERVED_ANSWER>
Forcing a subset of variables to be equal via chosen pairwise equality rules is logically identical to selecting edges to form a connected component containing the corresponding vertices; the required minimal subset and its cost remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains finding the minimum weight subtree that connects a given subset of terminal nodes in a tree, which is solvable in polynomial time O(n).
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "logically forced to be equal" as allowing broader algebraic combinations rather than just transitive equality, though the restriction to only pairwise equality rules prevents any other mathematical interpretation.
</RISK>
