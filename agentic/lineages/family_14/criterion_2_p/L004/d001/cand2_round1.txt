<STATEMENT>
# Sector Integration Energy

Time limit: 2 s
Memory limit: 256 MB

## Description

The deep-space array's calibration sequence requires establishing a unified communication grid. The array consists of multiple sensor nodes joined by bidirectional data links. To conserve materials during construction, the array was built with the absolute minimum number of links necessary to ensure that a message can be routed between any two nodes.

During a solar event, a diagnostic sweep flags a specific subset of nodes that have lost calibration.

To restore them, the main computer must activate a subset of the existing data links. The activated links must form a single connected network that includes every flagged node (unflagged nodes may also be included if they are needed to bridge connections). Activating a link consumes a set amount of power. The computer must find the subset of links that connects all flagged nodes while consuming the lowest possible total power.

Your task is to write the routine that calculates this lowest total power.

## Input

The first line provides three integers **n**, **m**, and **t**. The array's physical housing limits the total number of nodes **n** to a maximum of two hundred thousand, with a minimum of one. The diagnostic sweep flags **t** nodes, which can range from a single node up to the entire array. The number of links **m** is determined by the minimal-connectivity construction: it is exactly the smallest number of links needed to bridge all **n** nodes into a single network.

The second line contains **t** distinct integers representing the identifiers of the flagged nodes. Nodes are numbered starting from 1 up to **n**.

The following **m** lines describe the data links. Each line provides three integers **u**, **v**, and **w**, meaning a link exists between node **u** and node **v** (where **u** and **v** are distinct nodes from 1 to **n**). The activation power **w** is at least one, and restricted by a hardware safety limit to a maximum of one million.

## Output

Output a single integer representing the minimum total power required to establish a continuous grid connecting all flagged nodes.

<RATIONALE>
Removed the explicit statements that there are `n-1` relays and exactly one valid sequence between any two modules. Instead, the problem dictates that `m` is the minimum number of links needed to connect `n` nodes, which indirectly enforces `m = n - 1` and implies the network is a tree. All numeric bounds are now presented as physical constraints rather than bare inequalities, forcing models to deduce the graph's acyclic nature from the minimal-connectivity requirement.
</RATIONALE>
<PRESERVED_ANSWER>
The objective is still to find the minimum-weight connected subgraph containing a specific set of nodes, and since the underlying network is still a tree, the exact same unique set of edges must be selected.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a Steiner tree on a tree, which is solvable in O(n) time by pruning subtrees that contain no required nodes.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "smallest number of links needed to bridge all n nodes" as a dynamic property of the subset rather than a fixed property of the input graph, though "determined by the minimal-connectivity construction" clarifies it applies to the entire array.
</RISK>
