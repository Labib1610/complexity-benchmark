# Phase 3: Synchronization Energy

Time limit: 2 s
Memory limit: 256 MB

## Description

The facility's emergency response protocol consists of four automated phases:

1. **Phase 1 (Detection)**: The system initializes **n** hardware modules (numbered 1 to n) and a fixed infrastructure of **m** bidirectional power relays. The infrastructure connects all modules such that there are exactly **n − 1** relays, and between any two modules there is exactly one valid sequence of relays connecting them.
2. **Phase 2 (Flagging)**: A diagnostic scan identifies exactly **t** modules that require immediate synchronization.
3. **Phase 3 (Synchronization - Your Task)**: The central system must power on a specific set of essential relays. A relay is essential if and only if removing it from the Phase 1 infrastructure would leave at least one pair of flagged modules without any valid sequence of relays connecting them. Relays that are not essential remain powered off. Each relay requires a specific energy expenditure to power on. The system must calculate the total energy required to power on all essential relays.
4. **Phase 4 (Purge)**: The synchronized modules execute a distributed memory purge.

Your program is responsible for Phase 3. Given the infrastructure layout and the list of flagged modules from Phase 2, calculate the total energy expenditure required to complete Phase 3.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers: the identifiers of the flagged modules.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): a relay connecting module u to module v requiring w units of energy to power on. The relays form the infrastructure described in Phase 1.

## Output

Print a single integer: the total energy required to power on all essential relays.

<RATIONALE>
I changed the objective framing from "find a connected network linking all flagged modules" to "determine which individual relays are essential, where a relay is essential if its removal disconnects any pair of flagged modules." This forces the model to recognize that an edge's removal in a tree disconnects a pair of flagged nodes if and only if both resulting components contain at least one flagged node, which is mathematically identical to finding the minimal subtree (Steiner tree). Models that pattern-match without structural reasoning will likely attempt to simulate the removals or check pairs naively, resulting in a Time Limit Exceeded error.
</RATIONALE>
<PRESERVED_ANSWER>
In a tree, the set of edges whose removal disconnects at least one pair of flagged nodes is exactly the set of edges comprising the minimal connected subgraph spanning those nodes, so the sum of their required energies is identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains solvable in O(n) time using a single depth-first search to count flagged nodes in each subtree, keeping the complexity class exactly the same.
</PRESERVED_CLASS>
