# Synchronization Energy

Time limit: 2 s
Memory limit: 256 MB

## Description

In an industrial plant, a number of processing units are linked by bidirectional transfer pipes. The piping architecture guarantees that fluid can travel between any two units in the plant. At the same time, the design is perfectly lean: the removal of even a single pipe would fracture the plant into two disconnected zones.

A sensor array has flagged a specific group of units that must be synchronized. To achieve this, you must open a subset of the transfer pipes to form a single continuous fluid network that connects all flagged units together. This continuous network is permitted to route through unflagged units if necessary.

Opening a pipe requires a certain amount of mechanical energy. You must select a subset of pipes that successfully links all flagged units such that the total energy expended is minimized.

The plant's master controller is built with a hard capacity limit of two hundred thousand processing units. The synchronization protocol requires at least one unit to be flagged, and could theoretically flag every installed unit. Energy to open a pipe is measured in micro-joules; it always takes at least one micro-joule, while pressure regulators cap the maximum energy for any single pipe at exactly one million micro-joules. 

## Input

The first line contains three integers **n**, **m**, and **t**, representing the number of units, the number of pipes, and the number of flagged units, respectively. The total number of pipes, **m**, is precisely one less than the number of units, an inevitable consequence of the lean architecture.

The second line contains **t** distinct integers: the identifiers of the flagged units. Units are identified by sequential integers starting from 1 up to **n**.

Each of the next **m** lines contains three integers **u**, **v**, and **w**, indicating a bidirectional pipe between distinct units **u** and **v** that requires **w** micro-joules to open. 

## Output

Print a single integer: the minimum total energy required to connect all flagged units.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```


**Output**
```

```
