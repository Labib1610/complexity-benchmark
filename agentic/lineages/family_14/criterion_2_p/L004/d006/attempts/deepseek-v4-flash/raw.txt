We can model the mechanisms as edges of a tree (since there are exactly n−1 edges and they form a minimal basis for full rigidity).  
The condition that critical indices must be equal means that in the chosen subset of edges, all critical nodes must be in the same connected component.  

So the problem reduces to:  
Given a tree with weighted edges, find the minimum total weight of edges to remove so that all critical nodes remain connected.  
Equivalently, we can think of keeping a connected subgraph that contains all critical nodes, and we want to minimize the cost of edges we *keep* (since we pay for activated mechanisms).  

Actually, we pay for edges we activate. To keep critical nodes connected, we must activate enough edges to connect them. The minimal cost is the weight of the minimal subtree that connects all critical nodes.  

We can solve this by:
1. Mark critical nodes.
2. Do a DFS from any critical node, and for each edge, if the subtree below contains at least one critical node, we must keep that edge (add its cost).  
3. The sum of costs of such edges is the answer.

If t = 1, the answer is 0 because no edges are needed.

Let’s implement this efficiently for n up to 200,000.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    critical = set(map(int, input().split()))
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    if t == 1:
        print(0)
        return
    
    visited = [False] * (n+1)
    total_cost = 0
    
    def dfs(u):
        nonlocal total_cost
        visited[u] = True
        has_critical = u in critical
        for v, w in adj[u]:
            if not visited[v]:
                child_has = dfs(v)
                if child_has:
                    total_cost += w
                has_critical = has_critical or child_has
        return has_critical
    
    # start from any critical node
    start = next(iter(critical))
    dfs(start)
    print(total_cost)

if __name__ == "__main__":
    solve()
```
