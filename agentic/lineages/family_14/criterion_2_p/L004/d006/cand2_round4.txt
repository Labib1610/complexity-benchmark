# Quantum Entanglement Routing

Time limit: 2 s
Memory limit: 256 MB

## Description

You are calibrating a quantum computing array consisting of **n** qubits, numbered 1 to **n**. Each qubit can collapse into one of two spin states: Up or Down.

You have access to a set of **m** optional entanglement links. Each link binds two qubits **u** and **v** such that they are perfectly correlated (if one is Up, the other must be Up; if one is Down, the other must be Down). Activating a link consumes **w** units of cryogenic coolant.

The set of available links is structurally rigid: there are exactly **m** = **n** − 1 optional links, and if all were activated, the entire array's state space would collapse from 2^**n** possibilities down to exactly two valid global configurations (either all **n** qubits are Up, or all **n** qubits are Down).

Your objective is to activate a subset of these links such that a specific list of **t** target qubits are unconditionally correlated. That is, in any valid global state that respects your activated links, the **t** target qubits must all share the exact same spin state. You do not care about the spin states of the non-target qubits, provided the activated links are not violated.

What is the minimum total cost of coolant you must consume to ensure this property for the **t** target qubits?

## Input

The first line contains three integers **n**, **m**, and **t**. The number of qubits **n** is bounded by the hardware limit of 200,000 (and requires at least 1). The number of available links **m** is exactly one less than the number of qubits. The number of target qubits **t** can be as small as 1 and as large as the entire array size **n**.
The second line contains **t** distinct integers: the identifiers of the target qubits.
Each of the next **m** lines contains three integers **u**, **v**, and **w**. These denote an optional entanglement link between qubit **u** and qubit **v** (valid indices from 1 to **n**, **u** ≠ **v**), which costs **w** to activate. The coolant cost **w** requires a minimum of 1 unit and is physically limited to a maximum of 1,000,000 units per link.

## Output

Print a single integer: the minimum total coolant cost required.

<RATIONALE>
Restored the exact structural guarantee of the seed (that the m=n-1 constraints reduce the system to exactly 2 states) but reframed it using quantum entanglement and state-space collapse. This preserves the mathematical guarantee of a tree topology without using graph keywords, defeating models that rely on recognizing "tree" or "connected" in the problem text while avoiding the G3 error from the previous draft. Numeric bounds were rewritten as physical hardware limits to fulfill S07.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that the target qubits must share the same spin state in any valid configuration mathematically forces them to be in the same connected component of activated links, identical to the seed's synchronization requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying graph is still guaranteed to be a tree by the m=n-1 and two-state collapse conditions, so the problem remains solvable in O(n) time by finding the minimal subtree spanning the target nodes.
</PRESERVED_CLASS>
<RISK>
Models might interpret "unconditionally correlated" as a statistical property rather than a strict state-space constraint, though the definition provided ("in any valid global state... must all share the exact same spin state") is unambiguous.
</RISK>
