<STATEMENT>
# Problem B — Translation Consistency

Time limit: 2 s   Memory limit: 256 MB

## Description

An international publisher operates across **n** distinct languages (numbered 1 through **n**). 

The publisher can retain professionals from a pool of **m** bilingual translators. Each translator provides bidirectional conversion between a specific pair of languages for a fixed retainer fee. 
The network of available translators might not connect all **n** languages, and some subgroups of languages might have redundant translation routes (cycles). However, the given pool satisfies a strict property: within the entire pool, for any two distinct priority languages, there exists exactly one valid sequence of translators connecting them.

A forthcoming publication must be prepared in **t** priority languages. Select a subset of translators with **minimum total retainer fee** such that all **t** priority languages are connected (i.e., a text can be converted from any priority language to any other, possibly routing through non-priority languages).

Calculate this minimum total retainer fee. The fee for each retained translator is paid exactly once, independent of the number of conversion routes they support.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers: the identifiers of the priority languages.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): indicating a translator who bridges language **u** and language **v** for a fee of **w**. 

## Output

Print a single integer: the minimum total retainer fee required to retain a valid subset of translators that connects all priority languages.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the priority languages 1 and 4 can only be bridged through languages 2 and 3, so all three translators (fees 5+1+2 = 8) must be retained. In Example 2, there is only one priority language, so no translators need to be retained.

<RATIONALE>
The previous draft was rejected for dropping the explicit "minimum total cost" optimization objective. This rewrite restores the exact optimization contract ("Select a subset... with minimum total retainer fee") while executing the strategy. By stating that the overall graph might contain cycles and disconnected components, models are prevented from blindly assuming the entire input is a single tree and using a global rooted traversal. They must now genuinely reason that the unique-path guarantee between priority languages means the required subgraph is a unique tree, or they will fall back to an exponential general Steiner Tree algorithm and TLE.
</RATIONALE>
<PRESERVED_ANSWER>
The hidden test cases are trees, so the optimal cost to connect the priority languages remains exactly the sum of the edge weights in the unique Steiner subtree, unchanged from the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Because there is exactly one valid sequence between any pair of priority languages, the required subgraph is unique and can be found by simply taking the union of these sequences (e.g., via BFS), keeping the problem in polynomial time (P).
</PRESERVED_CLASS>
<RISK>
Models might find the mention of "might not connect all n languages" confusing when m = n - 1, but this is mathematically consistent (a graph with n-1 edges can be disconnected if it has cycles), so a careful reader will understand it.
</RISK>
