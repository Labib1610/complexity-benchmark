**Solution Explanation**

For a tree there is exactly one simple path between any two vertices.
For a set `C` of *critical* vertices the cheapest set of edges that makes
all vertices of `C` connected is simply the **union of all those unique
paths**.  
The obtained subgraph is a tree again; every edge of it lies on a path
between two critical vertices, and every edge that is *not* on such a path
can be removed without disconnecting any two critical vertices.

So we only have to know which edges belong to that union.

--------------------------------------------------------------------

#### 1.   Observation  

Root the tree arbitrarily (vertex 1).  
For a vertex `v` let  

```
sub(v) = number of critical vertices in the subtree of v (including v)
```

Consider the edge from `v` to its parent `p`.

```
sub(v) = 0                     → the whole subtree contains no critical vertex
sub(v) = t                     → all critical vertices are inside the subtree
0 < sub(v) < t                 → some critical vertices are inside,
                                 some are outside
```

Only the third case is useful – the edge is necessary to connect the two
parts.  
Therefore the answer is the sum of the weights of all edges whose child
subtree contains a *proper* non‑empty subset of the critical vertices.

--------------------------------------------------------------------

#### 2.   Algorithm
```
read input
mark every critical vertex
build adjacency list (undirected, weighted)

# ---------- build a rooted tree ----------
parent[1] = 0
stack = [1]
order = []                     # visiting order (preorder)
while stack not empty:
        v = stack.pop()
        order.append(v)
        for (to, w) in adj[v]:
                if to != parent[v]:
                        parent[to] = v
                        weight_to_parent[to] = w
                        stack.append(to)

# ---------- bottom‑up counting ----------
answer = 0
for v in reversed(order):                     # children processed before parent
        cnt = 1 if v is critical else 0
        for (to, w) in adj[v]:
                if parent[to] == v:          # to is a child
                        child_cnt = sub[to]
                        if 0 < child_cnt < t:
                                answer += w
                        cnt += child_cnt
        sub[v] = cnt

print answer
```

`sub[v]` – array of subtree counts – is filled while iterating
bottom‑up, therefore every child already knows its `sub` value.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs the minimum possible total activation
cost.

---

##### Lemma 1  
For any edge `e = (v, parent[v])` the algorithm adds `weight(e)` to the
answer **iff** removing `e` separates the set of critical vertices into two
non‑empty parts.

**Proof.**  
During the bottom‑up phase `sub[v]` equals the number of critical vertices
in the subtree of `v`.  
The condition `0 < sub[v] < t` holds exactly when the subtree contains at
least one but not all critical vertices, i.e. the other side of `e`
contains the remaining critical vertices. ∎



##### Lemma 2  
The set of edges selected by the algorithm connects all critical vertices.

**Proof.**  
Take any two critical vertices `a` and `b`.  
On the unique tree path `P(a,b)` consider any edge `e`.  
Removing `e` splits the tree into two components, each containing exactly
one of `{a,b}`. Hence each component contains at least one critical vertex,
so by Lemma&nbsp;1 `e` is selected.  
Thus every edge of `P(a,b)` belongs to the selected set, consequently the
selected edges contain the whole path `P(a,b)`. Since this holds for every
pair of critical vertices, all of them are mutually connected. ∎



##### Lemma 3  
Every edge selected by the algorithm is necessary in any feasible solution.

**Proof.**  
By Lemma&nbsp;1 an selected edge `e` separates the critical vertices into two
non‑empty groups `A` and `B`. Any solution that connects all critical vertices
must contain a path between a vertex of `A` and a vertex of `B`.  
All such paths must use `e` (the tree has exactly one path between the two
groups). Hence `e` appears in every feasible solution. ∎



##### Lemma 4  
The total weight computed by the algorithm equals the weight of the minimal
subtree that spans all critical vertices.

**Proof.**  
Let `S` be the set of edges selected by the algorithm.

*From Lemma&nbsp;2* `S` is a feasible solution, therefore the minimal possible
weight `OPT` satisfies `OPT ≤ weight(S)`.

*From Lemma&nbsp;3* every edge of `S` is mandatory, therefore any feasible
solution must contain all edges of `S`. Hence `weight(S) ≤ OPT`.

Consequently `weight(S) = OPT`. ∎



##### Theorem  
The algorithm outputs the minimum total activation cost required to connect
all critical workstations.

**Proof.** Directly from Lemma&nbsp;4. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency list* – `O(n)` memory, `O(n)` time.  
*Rooting the tree* – one DFS, `O(n)` time, `O(n)` stack.  
*Bottom‑up counting* – each edge inspected once, `O(n)` time.  

Overall  

```
Time   :  O(n)        ( ≤ 2·10⁵ operations, easily inside limits )
Memory :  O(n)
```

All arithmetic fits into 64‑bit signed integer (`≤ (n‑1)·10⁶ ≤ 2·10¹¹`).

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    n = next(it)
    m = next(it)   # equals n-1, not used
    t = next(it)

    is_crit = [False] * (n + 1)
    for _ in range(t):
        v = next(it)
        is_crit[v] = True

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = next(it); v = next(it); w = next(it)
        adj[u].append((v, w))
        adj[v].append((u, w))

    if t <= 1:
        print(0)
        return

    parent = [0] * (n + 1)
    wpar = [0] * (n + 1)          # weight to parent
    order = []
    stack = [1]
    parent[1] = -1                # mark root as visited

    while stack:
        v = stack.pop()
        order.append(v)
        for to, w in adj[v]:
            if parent[to] == 0:
                parent[to] = v
                wpar[to] = w
                stack.append(to)

    sub = [0] * (n + 1)
    total = 0
    for v in reversed(order):
        cnt = 1 if is_crit[v] else 0
        for to, w in adj[v]:
            if parent[to] == v:          # to is a child of v
                child_cnt = sub[to]
                if 0 < child_cnt < t:
                    total += w
                cnt += child_cnt
        sub[v] = cnt

    print(total)

if __name__ == "__main__":
    solve()
```
