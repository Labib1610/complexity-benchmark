# Problem B — Secure Workstation Uplink

Time limit: 2 s   Memory limit: 256 MB

## Description

A secure research facility houses **n** workstations, uniquely identified by integers starting from 1 up to **n**. The facility's floor space and power capacity limit the maximum number of workstations to exactly two hundred thousand. A specific count of these workstations, denoted as **t**, handle classified materials and are considered **critical**. The security protocol requires that at least one workstation is critical, and depending on the active project, up to all **n** workstations might be critical.

These critical workstations must all be able to exchange data with each other. This is achieved by activating a subset of the pre-installed data links. Each data link connects a specific pair of workstations and requires a certain activation cost in dollars. The cost to activate any single link is at least one dollar and is capped by a strict one million dollar per-link budget limit.

The pre-installed links guarantee that the entire facility is physically interconnected. To minimize physical vulnerabilities, the total number of installed links, **m**, is exactly one fewer than the total number of workstations.

Your objective is to determine the minimum total activation cost required to ensure that all critical workstations can communicate, whether directly or by routing through other intermediate workstations.

## Input

The first line provides three integers: **n**, **m**, and **t**.
The second line lists **t** distinct integers representing the identifiers of the critical workstations.
The subsequent **m** lines detail the pre-installed data links. Each line contains three integers **u**, **v**, and **w**: indicating a link between workstation **u** and workstation **v** (where **u** and **v** are different) with an activation cost of **w**. The network structure and costs adhere to the facility's design limits described above.

## Output

Output a single integer representing the lowest possible total cost to activate a set of links that allows all critical workstations to communicate.
