# Problem B — Translation Consistency

Time limit: 2 s   Memory limit: 256 MB

## Description

A publisher is preparing a major international release involving **n** distinct languages (numbered 1 to **n**). 

To facilitate communication, the publisher can hire from a pool of **m** bilingual translators. Each translator works in both directions between a specific pair of languages and charges a fixed retainer fee. The complete pool of translators is minimally comprehensive: they collectively enable a manuscript to be translated between any two languages in the company's registry (possibly through intermediates), but because there are exactly **m** = **n** − 1 translators in total, declining to hire any single translator from the full pool would sever the ability to translate between some pair of languages.

The upcoming book must be finalized in **t** specific target languages. To ensure editorial consistency, the publisher must hire a subset of translators such that a manuscript can be passed from any of the **t** target languages to any other of the **t** target languages, relying only on the hired translators. 

Determine the minimum total retainer fee the publisher must pay to hire a valid subset of translators. Each hired translator's fee is paid exactly once, regardless of how many times they are used.

## Input

The first line contains three integers **n**, **m**, and **t**. The total number of languages **n** is an integer from 1 up to the publisher's registry capacity of 200,000. The number of translators in the pool, **m**, is exactly **n** − 1. The number of target languages **t** is an integer from 1 up to **n**.

The second line contains **t** distinct integers representing the ids of the target languages.

Each of the next **m** lines contains three integers **u**, **v**, and **w**. These represent a translator who bridges language **u** and language **v** (where **u** and **v** are distinct integers from 1 to **n**) for a retainer fee **w**. The fee **w** is an integer from 1 up to the corporate maximum of 1,000,000. The full pool of translators forms the minimally comprehensive structure described above.

## Output

Print a single integer: the minimum total retainer fee to ensure all target languages can inter-translate.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the target languages 1 and 4 can only be bridged through languages 2 and 3, so all three translators (fees 5+1+2 = 8) must be hired. In Example 2, there is only one target language, so no translators need to be hired.
