# Problem B — Translation Consistency

Time limit: 2 s
Memory limit: 256 MB

## Description

A publisher is preparing a major international release. There are **n** distinct languages involved in their global operations, identified by integers starting from 1 up to **n**. 

To facilitate communication, the publisher can hire from a pool of **m** bilingual translators. Each translator works in both directions between exactly two specific languages and charges a fixed retainer fee. The pool of available translators is strictly minimally comprehensive: the entire set of **n** languages can inter-communicate using the full pool, but the dismissal of even a single translator would permanently sever the connection between at least some pair of languages. 

The upcoming book must be finalized in **t** specific target languages. To ensure editorial consistency, the publisher must hire a subset of translators such that a manuscript can be passed from any of the **t** target languages to any other of the **t** target languages, relying only on the hired translators (this may require passing through intermediate languages). 

Determine the minimum total retainer fee the publisher must pay to hire a valid subset of translators. Each hired translator's fee is paid exactly once, regardless of how many translation sequences they participate in.

## Input

The first line contains three integers **n**, **m**, and **t**. The publisher's global operations involve a minimum of 1 and a maximum capacity of 200000 distinct languages (**n**). The release targets **t** languages, where **t** is at least 1 and at most **n**. Because the translator pool is minimally comprehensive across all languages, the headcount of translators **m** is always exactly **n** minus 1.

The second line contains **t** distinct integers: the ids of the target languages. Each id is between 1 and **n**.

Each of the next **m** lines contains three integers **u**, **v**, and **w**. These indicate a translator who bridges distinct languages **u** and **v** (both between 1 and **n**) for a retainer fee **w**. The fee **w** is at least 1 and capped at a maximum of 1000000. 

## Output

Print a single integer: the minimum total retainer fee to ensure all target languages can inter-translate.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the target languages 1 and 4 can only be bridged through languages 2 and 3, so all three translators (fees 5+1+2 = 8) must be hired. In Example 2, there is only one target language, so no translators need to be hired.

<RATIONALE>
The explicit mention of "exactly one possible sequence" and "n - 1 options" in the description has been removed, as this wording was a direct trigger for models to immediately classify the graph as a tree and apply tree-specific pruning. Instead, the problem now describes the graph as "minimally comprehensive" (connected, but removing any edge disconnects it), requiring the model to deduce the tree properties and unique paths from this functional definition. Bounds are described as scenario capacities following S07, carefully preserving all numeric limits.
</RATIONALE>
<PRESERVED_ANSWER>
The structural requirement to connect the target languages using a subset of translators is mathematically identical to finding the minimum weight subgraph connecting the target nodes, which remains unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains finding a Steiner tree on a graph that is functionally defined as a tree, which can be solved in O(n) time and remains in P.
</PRESERVED_CLASS>
<RISK>
The phrase "minimally comprehensive" is well-defined by the subsequent clause, but models might misinterpret it as a general connected graph rather than a strict tree if they fail to parse the condition about removing a single translator.
</RISK>
