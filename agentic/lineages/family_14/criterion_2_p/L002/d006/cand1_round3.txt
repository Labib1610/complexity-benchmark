<METHOD_DESCRIPTION>The problem is framed as selecting a subset of edges that can be oriented to form directed paths from a single root to all targets. Since the input graph is connected with n-1 edges, this is equivalent to finding the unique minimal subgraph connecting the targets. By focusing on directed paths and orientations, models that look for undirected connectivity or structure pruning may fail to recognize the equivalence.</METHOD_DESCRIPTION>

<STATEMENT>
# Optimal Network Orientation

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a communication network with $n$ nodes and $m$ bidirectional links. The network is fully connected, and it is guaranteed that $m = n - 1$.

Each link connects two nodes $u$ and $v$ and has an activation cost $w$.

You are given a set of $t$ distinct target nodes. You must select a subset of the $m$ links to activate. Activating a link incurs its cost, regardless of how it is used. You may activate links connected to non-target nodes if they help satisfy the requirement.

A selected subset of activated links is considered valid if there exists at least one way to assign a single direction to each activated link such that there is some node $r$ (which can be any node in the network) from which there is a directed path to every one of the $t$ target nodes using only the activated links in their assigned directions.

Find the minimum total activation cost of a valid subset of links. The total cost is the sum of the activation costs $w$ of the links in your selected subset.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$). The network of $m$ links is connected.
The second line contains $t$ distinct integers: the target nodes.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a bidirectional link between nodes $u$ and $v$ with an activation cost of $w$.

## Output

Print a single integer: the minimum total activation cost of a subset of links that satisfies the orientation requirement for the target nodes.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

<RATIONALE>
I completely reframed the problem from a group theory setting (transpositions generating permutations) to a network activation problem with a directed orientation requirement. Instead of asking for the target elements to be in the same orbit, the problem now requires selecting a subset of links that can be oriented such that all targets are reachable from a single node. This forces the model to deduce that in a connected graph with $n-1$ edges, such an orientation is only possible if the selected edges form a connected component containing all targets, which is exactly the original requirement.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that there exists an orientation making all targets reachable from some node is satisfied if and only if the selected edges connect all targets. Since the costs and graph structure are identical to the seed, the minimum cost to connect the targets remains exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding the minimum weight subgraph connecting a subset of vertices in a connected graph with $n-1$ edges, which is solvable in polynomial time $O(n)$ by pruning leaves that do not lead to targets.
</PRESERVED_CLASS>
<RISK>
The phrase "there is some node $r$ ... from which there is a directed path to every one of the $t$ target nodes" could be misinterpreted if readers assume $r$ must be one of the targets, though the text explicitly says "(which can be any node in the network)".
</RISK>
