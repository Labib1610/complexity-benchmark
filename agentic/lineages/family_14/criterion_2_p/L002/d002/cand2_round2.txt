# Orbital Station Power Grid

Time limit: 2 s   Memory limit: 256 MB

## Description

An orbital station consists of **n** modules (numbered 1 to **n**). These modules are interconnected by structural corridors. The architecture of the station guarantees that the entire facility is fully contiguous. To eliminate structural redundancies, the design ensures that removing any single corridor would split the station into two disconnected sections. Consequently, there is exactly one sequence of corridors connecting any two modules without backtracking.

During a low-power emergency, the station commander must power down non-essential areas. However, **t** specific modules act as critical life-support nodes. The commander must keep a subset of corridors fully pressurized so that all **t** critical life-support nodes remain interlinked. This means every critical node must be able to reach every other critical node (either directly or through intermediate modules) exclusively by traversing pressurized corridors. Unpressurized corridors cannot be traversed.

Each corridor requires a certain amount of power to remain pressurized. Determine the minimum total power required to maintain pressurization in a set of corridors that successfully connects all **t** critical life-support nodes. 

The station's physical capacity establishes a maximum structural limit of exactly 200000 modules. A hardware power regulator caps the maximum power consumption of any single corridor at exactly 1000000 units.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ **t** ≤ **n**, 1 ≤ **n** ≤ maximum structural limit, **m** = **n** − 1).
The second line contains **t** distinct integers: the identifiers of the critical life-support nodes.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ maximum power regulator limit), representing a corridor linking module **u** and module **v** that requires **w** units of power to pressurize. The listed corridors satisfy the connectivity and non-redundancy properties described above.

## Output

Print a single integer: the minimum total power required to keep all critical life-support nodes connected.

<RATIONALE>
I substituted the bare numeric bounds in the input inequalities with named limits ("maximum structural limit", "maximum power regulator limit") and defined their exact values in the prose description. This forces the model to read and link the narrative constraints to the formal input format. I also replaced the direct mention of "the absolute minimum number of corridors necessary" with a precise mechanical description of the network's non-redundancy (removing any corridor splits the station), which mathematically guarantees a tree structure without using standard graph terminology.
</RATIONALE>
<PRESERVED_ANSWER>
The requested output remains the minimum total power of a connected subgraph spanning the critical nodes, which is mathematically identical to the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The input graph is still explicitly guaranteed to be a tree (connected, m = n - 1, no redundant corridors), so finding the minimal spanning subgraph for the given nodes remains solvable in linear time using a subtree traversal (P class).
</PRESERVED_CLASS>
