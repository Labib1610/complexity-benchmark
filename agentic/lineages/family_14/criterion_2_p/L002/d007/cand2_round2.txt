<METHOD_NAME>Reachability Set Equivalence Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Converts a static graph connectivity problem into a dynamic element-routing problem using array swappers, hiding the structural 'connected component' requirement behind a set-equality condition ($R(A) = R(B)$). This prevents the LLM from immediately triggering tree-traversal algorithms based on surface phrasing.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Array Swapper Optimization

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system that manipulates an array of $n$ items, which are initially located at positions $1$ through $n$.

There is a proposed set of $m$ bidirectional swappers. Each proposed swapper is defined by a pair of positions $u$ and $v$, and has an installation cost $w$. Once installed, a swapper allows you to exchange the items currently at positions $u$ and $v$ an unlimited number of times. You are guaranteed that $m = n - 1$, and that if all $m$ proposed swappers were installed, it would be possible to route an item from any position to any other position in the array. 

For any position $x$, let $R(x)$ be the set of all positions $y$ such that an item can be moved from position $x$ to position $y$ through a sequence of swaps using only the installed swappers (note that $x \in R(x)$ is always true). 

You are given a list of $t$ target positions. You must select a subset of the proposed swappers to install such that the reachable sets for all target positions are perfectly identical. That is, for every pair of target positions $A$ and $B$, you must ensure that $R(A) = R(B)$. You may install swappers involving non-target positions to help satisfy this requirement.

Find the minimum total installation cost of a selected subset of swappers that satisfies this requirement. The total cost is the sum of the installation costs $w$ of the swappers you choose to install.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$). The proposed swappers strictly satisfy the full-mobility guarantee described above.
The second line contains $t$ distinct integers: the target positions.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a proposed swapper for positions $u$ and $v$ that requires a cost of $w$ to install.

## Output

Print a single integer: the minimum total cost of a subset of swappers whose installation guarantees $R(A) = R(B)$ for all target positions $A$ and $B$.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1

```

**Output**
```
8
```


**Output**
```

```

### Example 3

```

```
</STATEMENT>
<RATIONALE>
Replaced the algebraic subspace and linear constraints framing with an array swapper and permutation reachability setting. To prevent the model from immediately mapping the pairwise relations to a graph connectivity algorithm, the requirement to connect the target nodes is disguised as an equivalence of their reachable sets ($R(A) = R(B)$). This forces the model to deduce that equal reachable sets in a system with $m = n - 1$ full-mobility swappers is equivalent to finding the minimum Steiner tree.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $R(A) = R(B)$ is satisfied if and only if all target positions are in the same connected component of the chosen swappers, which is identical to the seed problem's requirement of satisfying an algebraic equality constraint across all targets, yielding exactly the same minimum cost.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the minimum weight subtree that spans a specified set of vertices in a given acyclic network, which is solvable in polynomial time (O(n)) using standard traversal.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret $R(A) = R(B)$ as requiring the reachable sets to be the entire array (i.e. all $n$ positions), but the wording strictly says the sets must be identical to each other, not necessarily maximal, minimizing this risk.
</RISK>
