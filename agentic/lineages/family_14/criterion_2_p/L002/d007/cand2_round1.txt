<METHOD_NAME>Polynomial Roots Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces all mentions of equality ($y_u = y_v$) with the mathematically equivalent condition that a sum of squared linear terms (e.g., $(x - y_u)^2 + (x - y_v)^2$) has a real root. This completely removes graph and equality terminology, forcing the model to algebraically deduce the equality condition before it can recognize the underlying tree structure.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Real Roots Optimization

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a vector space $V = \mathbb{R}^n$. The coordinates of any vector $y \in V$ are denoted as $y_1, y_2, \dots, y_n$.

There is a proposed set of $m$ algebraic constraints. Each proposed constraint is defined by a pair of coordinate indices $u$ and $v$. Activating this constraint restricts the vector space to those vectors $y$ for which the quadratic polynomial $P(x) = (x - y_u)^2 + (x - y_v)^2$ has a real root. Each constraint has an associated activation cost $w$. 
You are guaranteed that $m = n - 1$, and that the intersection of all $m$ proposed constraints forms exactly the 1-dimensional subspace of $V$ where the polynomial $R(x) = \sum_{i=1}^n (x - y_i)^2$ has a real root.

You are given a set of $t$ focal coordinate indices. You must select a subset of the proposed constraints to activate. Your selected subset defines a subspace $W \subseteq V$ consisting of all vectors $y$ that satisfy every constraint in your subset. You require that for every vector $y \in W$, the polynomial $Q(x) = \sum_{k \in T} (x - y_k)^2$ has a real root (where $T$ is the set of your focal coordinate indices). You may activate constraints involving non-focal coordinates if they help satisfy this algebraic requirement.

Find the minimum total activation cost of a selected subset of constraints that satisfies this requirement. The total cost is the sum of the activation costs $w$ of the constraints you choose to activate.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$). The proposed constraints strictly satisfy the intersection guarantee described above.
The second line contains $t$ distinct integers: the focal coordinate indices.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a proposed constraint defined by indices $u$ and $v$ that requires a cost of $w$ to activate.

## Output

Print a single integer: the minimum total cost of a subset of constraints whose defined subspace forces the focal polynomial $Q(x)$ to have a real root.

<RATIONALE>
Replaced the direct equality constraint ($y_u = y_v$) with the mathematically equivalent condition that the sum of squares $(x - y_u)^2 + (x - y_v)^2$ has a real root. This completely removes all mentions of equality, forcing the model to algebraically deduce that a sum of squares only has a real root if all its squared terms evaluate to zero simultaneously, which implies equality of all involved coordinates. It breaks pattern matching on standard graph connectivity.
</RATIONALE>
<PRESERVED_ANSWER>
A sum of squares $\sum (x - c_i)^2$ has a real root if and only if all $c_i$ are identical; thus the new algebraic condition enforces exactly the same equality constraints as the seed, keeping all optimal selections and costs identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains finding the minimum weight subtree connecting a set of target vertices in a tree, which is solvable in polynomial time $O(n)$ via tree traversal.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret $x$ as a vector rather than a scalar variable, though "quadratic polynomial $P(x)$" strongly implies a scalar polynomial in standard mathematical notation.
</RISK>
