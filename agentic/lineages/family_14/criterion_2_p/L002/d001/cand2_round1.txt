# Patent Portfolio

Time limit: 2 s   Memory limit: 256 MB

## Description

A technology standard involves **n** concepts (numbered 1..n). There are **m** existing patents, each covering the integration of two specific concepts. Acquiring a patent costs a known legal fee.

The standard is minimally cohesive: it is possible to link any two concepts through a sequence of patents, but removing even a single patent would break the standard into isolated conceptual islands.

Your company is developing a product that relies on **t** core concepts. You must acquire a subset of the patents such that all **t** core concepts belong to the same connected group. This means it must be possible to link any two core concepts using strictly the acquired patents. It is acceptable if these linkages incorporate non-core concepts, provided every patent used in the sequence is acquired. Patents you do not acquire cannot be used.

Determine the minimum total legal fee required to acquire a valid subset of patents.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers: the identifiers of the core concepts.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), representing a patent integrating concept u and concept v that costs w in legal fees.

## Output

Print a single integer: the minimum total legal fee required to connect all core concepts.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2


**Output**
```

```

### Example 3

**Input**
```
3 2 3

2 3 5
```

**Output**
```
9
```
