# Orbital Station Power Grid

Time limit: 2 s   Memory limit: 256 MB

## Description

An orbital infrastructure consists of a set of isolated habitat modules that have been linked by structural corridors. The architecture was designed with the absolute minimum number of corridors necessary to ensure that all modules in the facility are interconnected. 

During a low-power emergency, the station commander must power down non-essential areas. Specific modules contain critical life-support systems. The commander must keep a subset of corridors fully pressurized so that all critical modules can reach each other (directly or through intermediate modules) exclusively using pressurized corridors.

Each corridor requires a certain amount of power to remain pressurized. Unpressurized corridors cannot be traversed. Determine the minimum total power required to maintain pressurization in a set of corridors that connects all critical modules.

The station's registry is built to support a maximum capacity of 200,000 modules. Because there is at least one critical module, the station has at least one module. The emergency protocols track up to the total number of modules as critical. Module identifiers are positive integers up to the total number of modules. No corridor links a module to itself. A single corridor's power requirement is at least 1 unit and never exceeds 1,000,000 units.

## Input

The first line contains three integers **n** (the total number of modules), **m** (the number of corridors), and **t** (the number of critical modules).
The second line contains **t** distinct integers representing the identifiers of the critical modules.
Each of the next **m** lines contains three integers **u**, **v**, and **w**, indicating that a corridor links module **u** and module **v** and requires **w** units of power to pressurize.

## Output

Print a single integer: the minimum total power required to keep all critical modules connected.
