We are given a set of \( n-1 \) transpositions that generate the full symmetric group \( S_n \). This means the graph formed by these transpositions (with vertices \(1..n\) and edges as the transpositions) is a tree.

We need to select a subset of edges (transpositions) such that all target vertices are in the same connected component in the selected subgraph. The cost is the sum of weights of selected edges. We want the minimum cost.

This is exactly the **minimum Steiner tree** problem on a tree graph, where the terminals are the target elements. Since the graph is a tree, the minimum Steiner tree is simply the minimal subtree that connects all terminals. Its cost is the sum of edge weights in that minimal subtree.

**Approach:**
1. Build the tree from the given edges.
2. Mark the target nodes.
3. Find the minimal subtree that connects all target nodes. This can be done by:
   - Root the tree at any target node.
   - Perform DFS to determine which edges are needed: an edge is needed if the subtree below it contains at least one target node.
4. Sum the weights of all needed edges.

This works because in a tree, the minimal connected subgraph containing a set of nodes is unique — it's the union of all paths between those nodes.

Let's implement this efficiently for \( n \) up to 200,000.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    targets = set(map(int, input().split()))
    
    adj = [[] for _ in range(n+1)]
    edges = []
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
        edges.append((u, v, w))
    
    # Root the tree at any target node
    root = next(iter(targets))
    
    parent = [0]*(n+1)
    parent_w = [0]*(n+1)
    visited = [False]*(n+1)
    stack = [root]
    visited[root] = True
    order = []
    while stack:
        u = stack.pop()
        order.append(u)
        for v, w in adj[u]:
            if not visited[v]:
                visited[v] = True
                parent[v] = u
                parent_w[v] = w
                stack.append(v)
    
    # Now compute for each node if its subtree contains a target
    has_target = [False]*(n+1)
    for node in targets:
        has_target[node] = True
    
    total_cost = 0
    # Process nodes in reverse order (post-order)
    for u in reversed(order):
        if u != root:
            if has_target[u]:
                total_cost += parent_w[u]
                # propagate up
                p = parent[u]
                has_target[p] = True
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
