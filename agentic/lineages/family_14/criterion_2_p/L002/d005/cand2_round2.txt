<METHOD_NAME>Matrix Null Space Isomorphism</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the vector space span and difference vectors with the null space of a sum of graph Laplacian matrices. The condition that target vertices are in the same connected component is mathematically isomorphic to the condition that any vector in the null space of the summed Laplacian has equal coordinates at the target indices.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Null Space Constraint Selection

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of **n** variables, represented as a column vector $x \in \mathbb{R}^n$.

You are given a pool of **m** available constraint matrices. Each constraint matrix is defined by a pair of indices **u** and **v**. The matrix associated with **u** and **v** is an **n** $\times$ **n** symmetric matrix where the entries at $(u,u)$ and $(v,v)$ are $1$, the entries at $(u,v)$ and $(v,u)$ are $-1$, and all other entries are $0$. Including this matrix in your system incurs a computational cost of **w**.

You are guaranteed that **m** = **n** − 1. Furthermore, if you sum all **m** available matrices to form a single matrix $L$, the equation $L x = 0$ implies that all coordinates of $x$ are equal (i.e., $x_1 = x_2 = \dots = x_n$).

You are given a set of **t** critical indices. You must select a subset of the constraint matrices to minimize the total cost. Let $S$ be the sum of your selected matrices (if no matrices are selected, $S$ is the zero matrix). Your selection must satisfy the following requirement: for any vector $x \in \mathbb{R}^n$ satisfying $S x = 0$, it must be guaranteed that $x_a = x_b$ for all pairs of critical indices **a** and **b**. You may include constraint matrices that do not directly involve the critical indices if they help satisfy this requirement.

Find the minimum total cost of a selected subset of constraint matrices that satisfies this requirement. The total cost is the sum of the costs **w** of the matrices you choose to include.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ **t** ≤ **n**, 1 ≤ **n** ≤ 200000, **m** = **n** − 1). The **m** matrices strictly satisfy the global null space guarantee described above.
The second line contains **t** distinct integers: the critical indices.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000), representing a constraint matrix defined by indices **u** and **v** that requires a cost of **w** to include.

## Output

Print a single integer: the minimum total cost of a subset of matrices whose sum $S$ ensures that $S x = 0$ forces $x_a = x_b$ for all critical indices **a** and **b**.

<RATIONALE>
The problem was completely rewritten to use the Matrix Null Space Isomorphism. Instead of asking for vectors in a linear span (which models easily map to paths in a tree), the problem asks for a subset of matrices (which are actually edge Laplacians) such that their sum $S$ forces $x_a = x_b$ for all $x$ in the null space of $S$. This is mathematically identical to the seed's spanning condition, but forces the model to independently deduce that $S x = 0$ corresponds to constant values on connected components of a graph, and that the global null space guarantee implies the matrices form a spanning tree.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that $v_a - v_b$ is in the span of the selected difference vectors is mathematically equivalent to the condition that any vector in the orthogonal complement of that span has $x_a = x_b$; since the null space of the summed Laplacian matrices is exactly that orthogonal complement, a subset satisfies the new condition if and only if it satisfied the seed condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding the minimum cost subset of edges that connects all critical vertices in a tree, which has a unique solution path between any two vertices, so it remains solvable in O(n) time using tree traversal.
</PRESERVED_CLASS>
<RISK>
Models might fail to recognize that the symmetric constraint matrix is a graph Laplacian, leading them to misinterpret the problem as a general linear algebra optimization and attempt $O(n^3)$ matrix operations instead of $O(n)$ tree algorithms.
</RISK>
