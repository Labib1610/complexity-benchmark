<STATEMENT>
# Linear Difference Span

Time limit: 2 s   Memory limit: 256 MB

## Description

You are working with a vector space containing $n$ formal basis variables $x_1, x_2, \dots, x_n$. 

You are provided with a pool of $m$ available difference generators. Each generator is specified by two indices $u$ and $v$ and an activation cost $w$. Activating this generator adds the formal binomial difference $x_u - x_v$ to your active generator set.

To ensure the system is well-defined, the full pool of $m$ generators is minimally sufficient to span all possible differences between the variables. Specifically, if you were to activate all $m$ generators, the linear span of the resulting active set would contain the difference $x_a - x_b$ for every possible pair of variables $x_a$ and $x_b$. Furthermore, because $m = n - 1$, there is exactly one valid linear combination of the full pool's generators that yields any specific difference $x_a - x_b$. The available generators are strictly non-redundant: removing any single generator from the full pool would strictly shrink the linear span, leaving some differences impossible to form.

You are given a target set of $t$ critical variables. You must select a subset of the available generators to activate. Your goal is to ensure that for every pair of critical variables $x_i$ and $x_j$, their difference $x_i - x_j$ is contained within the linear span of your active generator set. You may activate generators involving non-critical variables if they are necessary to form the required linear combinations.

Find the minimum total activation cost of a selected subset of generators that achieves this goal. The total cost is the sum of the activation costs $w$ of the generators you choose to activate.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$). 
The second line contains $t$ distinct integers: the indices of the critical variables.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing an available difference generator $x_u - x_v$, which requires a cost of $w$ to activate.

The provided set of $m$ available generators strictly satisfies the minimal sufficiency guarantee described above.

## Output

Print a single integer: the minimum total cost of a subset of generators such that the difference between any pair of critical variables can be expressed as a linear combination of the activated generators.

## Examples

**Output**

```
8
```

</STATEMENT>
<RATIONALE>
I replaced the mechanical synchronization framing with a formal linear algebra setting, requiring the difference of critical variables to be in the linear span of the chosen binomial differences. This forces the model to realize that a linear combination of differences corresponds exactly to a path in a graph, and since the generators form a minimally sufficient set ($m=n-1$), the only way to span the required differences is to select the edges of the unique paths connecting the critical variables.
</RATIONALE>
<PRESERVED_ANSWER>
The formal differences $x_u - x_v$ span $x_i - x_j$ if and only if there is a sequence of generators forming a path between $i$ and $j$; thus the minimum cost to span all critical pairs is exactly the minimum Steiner tree on the same graph, keeping all answers identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains finding the minimum weight subtree connecting a set of critical nodes in a given tree, which is solvable in linear time using a standard tree traversal, keeping it in P.
</PRESERVED_CLASS>
<RISK>
The phrase "formal binomial difference $x_u - x_v$" might be seen as slightly contradictory because the input format provides $u, v, w$ without specifying order, but since the span is linear, $x_u - x_v$ and $x_v - x_u$ generate the same subspace, making it unambiguous.
</RISK>
