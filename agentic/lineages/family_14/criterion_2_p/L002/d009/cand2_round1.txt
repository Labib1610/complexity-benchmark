# Null Space Projection Requirements

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing an $n$-dimensional vector space over the real numbers, defined by the standard basis vectors $e_1, e_2, \dots, e_n$.

There is a pool of $m$ available constraint vectors. Each constraint vector is of the form $c = e_u - e_v$ and has an associated selection penalty $w$. 
Selecting a subset of constraint vectors $C$ defines a null space $N(C) = \{ x \in \mathbb{R}^n \mid c \cdot x = 0 \text{ for all } c \in C \}$. 

To ensure the system's architecture is well-defined, you are guaranteed that the full pool of $m$ available constraint vectors is minimally sufficient to reduce the null space to exactly the one-dimensional line spanned by the all-ones vector $\mathbf{1} = (1, 1, \dots, 1)^T$. Consequently, removing any single constraint vector from the full pool would strictly increase the dimension of the null space.

You are given a target subset of $t$ critical dimensions. Your goal is to select a subset of constraint vectors $C$ such that for every vector $x \in N(C)$, the coordinates of $x$ at all $t$ critical dimensions are strictly equal to each other. You may include constraint vectors involving non-critical dimensions if they are necessary to satisfy this algebraic requirement.

Find the minimum total selection penalty of a selected subset $C$ that achieves this goal. The total penalty is the sum of the penalties $w$ of the constraint vectors you choose to select.

## Input

The first line contains three integers $n$, $m$, and $t$. 
The dimension $n$ is a positive integer that does not exceed the number of 4-byte elements that fit into an 800-kilobyte buffer (where 1 kilobyte = 1000 bytes). 
The number of available constraint vectors $m$ is exactly the dimension of the orthogonal complement of the one-dimensional consensus line, meaning $m = n - 1$. 
The number of critical dimensions $t$ can range from a single dimension up to the full dimensionality of the space.

The second line contains $t$ distinct integers: the indices of the critical dimensions. Each index is a valid identifier for one of the $n$ orthogonal axes.

Each of the next $m$ lines contains three integers $u$, $v$, and $w$, representing an available constraint vector $e_u - e_v$, which requires a penalty of $w$ to select. The indices $u$ and $v$ refer to distinct orthogonal axes in the space. The penalty $w$ is a positive integer bounded by the number of cubic centimeters in one cubic meter.

The provided set of $m$ available constraint vectors strictly satisfies the minimal sufficiency guarantee described above.

## Output

Print a single integer: the minimum total selection penalty of a subset of constraint vectors whose resulting null space forces the coordinates at all critical dimensions to be identical.

<RATIONALE>
The problem was completely reframed from mechanical shaft synchronization (graph connectivity) to linear algebra null spaces. To solve this efficiently, the model must deduce that a set of $n-1$ difference vectors that reduces the null space to the span of $\mathbf{1}$ is mathematically isomorphic to a spanning tree, and that forcing equality among $t$ coordinates requires selecting the minimal subtree connecting those variables. Models relying on surface pattern matching will fail to recognize the hidden tree structure and will likely attempt to use matrix operations or general Steiner tree algorithms, resulting in Time Limit Exceeded or Memory Limit Exceeded. Numeric bounds were also stated indirectly using physical and computational constants to prevent simple regex-based bound extraction.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $c \cdot x = 0$ for $c = e_u - e_v$ is algebraically identical to $x_u = x_v$, making the required subset of constraints exactly the minimal subtree connecting the critical dimensions, preserving all topological relationships and minimum costs.
</PRESERVED_ANSWER>
