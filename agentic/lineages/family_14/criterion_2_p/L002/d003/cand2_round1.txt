# Emergency Pressurization

Time limit: 2 s   Memory limit: 256 MB

## Description

An orbital station is built from a collection of modules linked by transit tubes. The structural layout ensures that personnel can travel from any given module to any other module through the tube system. 

Due to a catastrophic energy loss, the station is running on auxiliary batteries. Certain modules house critical emergency override consoles. The commander must isolate a functional sub-network of tubes to remain powered. This energized sub-network must guarantee that a crew member can travel between any two modules containing an override console without ever leaving the powered tubes. Modules without consoles may be included in this energized sub-network to act merely as junctions. Tubes not selected for the sub-network will be completely powered down and sealed, rendering them impassable.

Determine the absolute minimum total kilowatts required to power a sub-network that successfully interconnects all override consoles.

## Input

The first line provides three space-separated integers: the total number of modules **n**, the total number of tubes **m**, and the count of override consoles **t**. 
The station's master database limits the architecture to a maximum of 200,000 modules, while requiring at least one module to function. 
To minimize structural weakness, the total number of tubes **m** is always built to be exactly one less than the module count. 
The emergency protocol coordinates between a minimum of one override console and a theoretical maximum where every module houses a console.

The second line lists **t** distinct module indices where the consoles are located.

The following **m** lines detail the tubes. Each line gives three integers **u**, **v**, and **w**, indicating a tube between module **u** and module **v** needing **w** kilowatts of power. Modules are addressed by integers starting from 1 up to the total number of modules. A tube always links two distinct modules. Each tube's continuous power draw is rated between a 1-kilowatt idle state and a 1,000,000-kilowatt maximum load.

## Output

Print a single integer: the minimum total kilowatts required to keep all override consoles interconnected.
