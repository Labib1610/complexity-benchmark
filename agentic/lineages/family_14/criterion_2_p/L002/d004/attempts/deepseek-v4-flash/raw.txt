We are given a graph with \( n \) nodes and \( m = n-1 \) edges, which means it’s a tree.  
The vectors \( v_u - v_v \) correspond to edges.  
We need to select a subset of edges such that for any two target nodes \( a, b \), the difference \( v_a - v_b \) is in the span of selected edges.

In a tree, the span of a set of edges corresponds to the set of all differences between nodes in the same connected component (after removing unselected edges).  
So the condition means: all target nodes must be in the same connected component after selecting edges.

Thus the problem reduces to:  
Given a tree with edge costs, find the minimum cost to connect all target nodes (possibly using other nodes as Steiner points).  
This is the **Steiner tree problem on a tree**, which can be solved by taking the minimal subtree that connects all target nodes.

**Approach:**
1. Mark target nodes.
2. Do a DFS from any target node to find the minimal subtree that connects all targets.
3. Sum the costs of edges in that minimal subtree.

We can do this by:
- Root the tree at any target node.
- For each node, compute if its subtree contains any target node.
- If a child subtree contains a target, then the edge to that child must be included.

Implementation:

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    targets = set(map(int, input().split()))
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    # pick a root as any target
    root = next(iter(targets))
    
    parent = [0]*(n+1)
    parent_cost = [0]*(n+1)
    order = []
    stack = [root]
    parent[root] = -1
    while stack:
        u = stack.pop()
        order.append(u)
        for v, w in adj[u]:
            if v == parent[u]:
                continue
            parent[v] = u
            parent_cost[v] = w
            stack.append(v)
    
    has_target = [False]*(n+1)
    for x in targets:
        has_target[x] = True
    
    total_cost = 0
    # process in reverse order (post-order)
    for u in reversed(order):
        if u == root:
            continue
        if has_target[u]:
            total_cost += parent_cost[u]
            # propagate up
            p = parent[u]
            while p != -1 and not has_target[p]:
                has_target[p] = True
                p = parent[p]
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
