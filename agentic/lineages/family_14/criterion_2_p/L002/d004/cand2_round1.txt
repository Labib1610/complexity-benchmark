<STATEMENT>
# Emergency Pressurization

Time limit: 2 s   Memory limit: 256 MB

## Description

An orbital station is composed of **n** modules. The modules are joined by **m** structural corridors, each requiring a specific continuous power draw to remain pressurized. The architecture of the station ensures that it forms a single contiguous facility with exactly one sequence of corridors connecting any pair of modules without retracing steps.

A reactor failure has forced the station to operate on emergency power. There are **t** critical modules that house essential life-support systems. The commander must establish a safe subnetwork.

To define the safe subnetwork, the commander considers every possible pair of critical modules. For each pair, there is exactly one valid sequence of corridors connecting them without retracing steps. The safe subnetwork is defined as the union of all such sequences for all pairs of critical modules. Corridors that belong to at least one such sequence must be pressurized. All other corridors are depressurized and impassable. 

If there is only one critical module, no sequences are formed, and zero corridors are pressurized.

Your task is to calculate the total power draw required to pressurize all corridors in this safe subnetwork.

## Input

The first line contains three integers, **n**, **m**, and **t**. The station directory supports up to 200,000 modules (the minimum is 1). The number of corridors **m** is exactly one less than the number of modules. The count of critical modules **t** ranges from a single module up to the entire station.
The second line contains **t** distinct integers representing the identifiers of the critical modules.
Each of the following **m** lines provides three integers **u**, **v**, and **w**. These indicate a corridor between module **u** and module **v** that requires **w** units of power to pressurize. A corridor's power requirement is at least 1 and never exceeds 1,000,000 units, and it strictly connects two distinct modules.

## Output

Print a single integer: the exact total power draw for the pressurized corridors.

<RATIONALE>
I changed the objective from finding the minimum cost to keep the modules interconnected to finding the union of the unique paths between all pairs of critical modules. This forces the model to recognize that this procedural definition is mathematically equivalent to finding the minimal spanning subtree. Models that fail to see this equivalence will likely implement the literal $O(t^2 n)$ path-finding procedure, which will result in a Time Limit Exceeded error.
</RATIONALE>
<PRESERVED_ANSWER>
In a graph with exactly one path between any two nodes, the minimal connected subgraph containing a set of vertices is exactly the union of the simple paths between all pairs of those vertices, meaning the exact same set of corridors is selected.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains finding the total weight of the minimal subtree containing a specific subset of vertices, which can be solved in $O(n)$ time.
</PRESERVED_CLASS>
<RISK>
A reader might wonder if "sequence of corridors" implies an ordered list and whether traversing it in opposite directions counts as different sequences, but since the operation is a set union of the physical corridors themselves, this distinction does not affect the final set of pressurized corridors.
</RISK>
