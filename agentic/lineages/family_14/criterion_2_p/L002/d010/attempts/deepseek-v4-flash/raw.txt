We have a graph with \( n \) nodes and \( m = n-1 \) edges, so it’s a tree.  
Each edge represents an equation \( x_u - x_v = 0 \), meaning the two nodes must be equal.  
We need to connect all critical nodes into one connected component (so they all have the same value).  

This becomes: given a tree with weighted edges, find the minimum total weight of edges to connect all given critical nodes.  
That’s exactly the **Steiner tree** problem on a tree, which can be solved by:

- Remove all non-critical leaves iteratively (they are useless).
- The remaining tree has all critical nodes as leaves or internal nodes.
- The minimal cost is the sum of all edges in the minimal subtree that connects all critical nodes.

We can do this by:
1. Mark critical nodes.
2. Do a DFS/BFS to compute for each node whether its subtree contains any critical node.
3. Keep only edges where both sides contain at least one critical node.
4. Sum the weights of those edges.

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    critical = set(map(int, input().split()))
    
    adj = [[] for _ in range(n)]
    edges = []
    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append((v, w))
        adj[v].append((u, w))
        edges.append((u, v, w))
    
    # DFS to mark which nodes have critical in their subtree
    parent = [-1] * n
    order = []
    stack = [0]
    parent[0] = 0
    while stack:
        u = stack.pop()
        order.append(u)
        for v, w in adj[u]:
            if v == parent[u]:
                continue
            parent[v] = u
            stack.append(v)
    
    has_critical = [False] * n
    for c in critical:
        has_critical[c] = True
    
    for u in reversed(order):
        for v, w in adj[u]:
            if v == parent[u]:
                continue
            if has_critical[v]:
                has_critical[u] = True
    
    # Sum edges where both sides have critical
    total = 0
    for u, v, w in edges:
        if has_critical[u] and has_critical[v]:
            total += w
    
    print(total)

if __name__ == "__main__":
    solve()
```
