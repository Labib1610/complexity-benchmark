Solution Space Projection Dimension
</METHOD_NAME>
<METHOD_DESCRIPTION>
Frame the connectivity requirement as restricting the dimension of the solution space projected onto the target coordinates. Instead of asking to "connect" variables or make them "equal", we require that the projection of the null space onto the critical variables has dimension exactly 1. Models must algebraically deduce that this dimension equals the number of connected components intersecting the critical set, forcing them to reason about the structure rather than pattern-matching "equations equal to a single value" to "tree connectivity".
</METHOD_DESCRIPTION>

yes

<STATEMENT>
# Sparse Linear Subsystem Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a homogeneous linear system over $n$ real variables $x_1, x_2, \ldots, x_n$.

You are provided with a pool of $m$ candidate equations. Each candidate equation is specified by two indices $u$ and $v$ and an activation cost $w$. Activating this candidate imposes the constraint $x_u - x_v = 0$ on your system.

You are given a target set of $t$ critical variables. You must select a subset of the candidate equations to activate. Let $V \subseteq \mathbb{R}^n$ be the solution space of the resulting active subsystem (the set of all valid assignments to $x_1, \ldots, x_n$ that satisfy all activated equations). Let $\pi(V) \subseteq \mathbb{R}^t$ be the projection of $V$ onto the coordinates of the $t$ critical variables. That is, $\pi(V)$ is the set of all vectors in $\mathbb{R}^t$ that can be formed by taking a vector in $V$ and extracting only the values of the critical variables.

Your objective is to ensure that the vector space dimension of $\pi(V)$ is exactly 1. You may activate equations involving non-critical variables if they are necessary to achieve this dimension.

To ensure the system is well-posed, you are guaranteed that the full pool of $m$ candidate equations is strictly linearly independent. This structural property guarantees that if you were to activate all $m$ equations, the dimension of the full solution space $V$ would be exactly 1.

Find the minimum total activation cost of a selected subset of equations that achieves this objective. The total cost is the sum of the activation costs $w$ of the equations you choose to activate.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$). 
The second line contains $t$ distinct integers: the indices of the critical variables.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a candidate equation $x_u - x_v = 0$ which requires a cost of $w$ to activate.

The provided set of $m$ candidate equations strictly satisfies the linear independence guarantee described above.

## Output

Print a single integer: the minimum total activation cost of a subset of equations such that the dimension of $\pi(V)$ is exactly 1.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

<RATIONALE>
The previous affordance was the explicit objective to "ensure the condition $x_i = x_j$ is algebraically entailed", which directly pattern-matches to "find paths connecting these nodes in a graph". I replaced this with the requirement that the projection of the solution space onto the critical coordinates has a vector space dimension of exactly 1. This mathematically forces all critical variables to equal each other (as the all-1 vector always spans a 1D subspace), but requires models to algebraically deduce this equivalence rather than relying on surface-level keywords.
</RATIONALE>
<PRESERVED_ANSWER>
The dimension of the projected solution space $\pi(V)$ is exactly 1 if and only if all critical variables are forced to take the identical value in every valid assignment, which is exactly the original requirement that $x_i = x_j$ for all critical $i, j$; thus, the required subset of equations and its minimum cost are identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying mathematical problem remains finding the minimum-weight subtree connecting a subset of vertices in a given tree, which is solvable in linear time using a standard tree traversal, keeping the problem in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "projection of $V$ onto the coordinates" if they are unfamiliar with the formal definition, though the text explicitly clarifies it as "extracting only the values of the critical variables", making ambiguity highly unlikely.
</RISK>
