We are given a tree (since m = n-1 and it’s minimally sufficient), and we need to connect all critical nodes so they are in the same connected component. This is the classic **Steiner tree** problem on a tree, where terminals are the critical nodes.  

On a tree, the minimal Steiner tree connecting a set of terminals is simply the union of all edges on the paths between them. The minimum cost is the sum of edge weights in the minimal subtree that connects all terminals.

We can solve it by:
1. Mark critical nodes.
2. Do a DFS/BFS from any critical node, and compute the total weight of edges that are on paths connecting critical nodes.  
   - A standard method: do a DFS, and for each node, count how many critical nodes are in its subtree. If that count is > 0 and < total critical count, then the edge to its parent is needed.

Let's implement it.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    critical = set(map(int, input().split()))
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    total_critical = t
    visited = [False] * (n+1)
    ans = 0
    
    def dfs(u, parent):
        nonlocal ans
        visited[u] = True
        cnt = 1 if u in critical else 0
        for v, w in adj[u]:
            if v == parent:
                continue
            if not visited[v]:
                sub = dfs(v, u)
                if sub > 0 and sub < total_critical:
                    ans += w
                cnt += sub
        return cnt
    
    # start from any critical node
    start = next(iter(critical))
    dfs(start, -1)
    
    print(ans)

if __name__ == "__main__":
    solve()
```
