# Null Space Target Component Synchronization

Time limit: 2 s   Memory limit: 256 MB

## Description

You are constructing a linear transformation $L: \mathbb{R}^n \to \mathbb{R}^k$ (where $k$ is the number of rows you choose). You start with an empty transformation matrix. You can expand $L$ by appending row vectors from a predefined candidate pool of size $m$. Appending the $j$-th candidate row (which has a $1$ at component $u_j$, a $-1$ at component $v_j$, and $0$ elsewhere) increases your operational cost by $w_j$.

You are given a target set of $t$ critical dimensions. Your objective is to ensure that the kernel of $L$ (the subspace of all vectors $x \in \mathbb{R}^n$ where $Lx = \mathbf{0}$) is strictly homogeneous across these critical dimensions. Specifically, for any vector $x \in \ker(L)$, the value of the $i$-th component of $x$ must exactly equal the value of the $j$-th component of $x$, for all $i,j$ in the target set. You may append candidate rows involving non-target dimensions if they are algebraically necessary to enforce this condition.

The candidate pool represents an arbitrary set of constraints and is not guaranteed to be fully coupled. Do not assume that appending the entire pool reduces the kernel to a one-dimensional subspace. You are only guaranteed that at least one valid subset of rows exists to satisfy the requirement.

Find the minimum total operational cost required to construct such a transformation $L$.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$).
The second line contains $t$ distinct integers: the target dimensions.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a candidate row vector with $1$ at component $u$ and $-1$ at component $v$, which requires an operational cost of $w$ to append.

## Output

Print a single integer: the minimum total cost of a subset of row vectors whose resulting transformation kernel forces all target components to be equal.

## Examples

### Example 1

**Input**
```

2 3 1

```

**Output**
```
8
```

**Output**
```

```


**Output**
```

```

<RATIONALE>
Removed the explicit guarantee that the full matrix has a 1D null space, which models used to deduce the underlying tree structure of the constraints. Added a statement explicitly warning that the candidate pool is arbitrary and might not fully couple the space. This forces models to derive the connectivity requirement algebraically rather than relying on a promised graph property.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic requirement that $x_i = x_j$ for all targets in the null space still inherently requires the corresponding edges to form a connected component containing all targets; since the actual test data remains unchanged ($m=n-1$ trees), the minimum cost subset is identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains finding the minimum subtree connecting the target vertices in a tree, which is solvable in linear time.
</PRESERVED_CLASS>
<RISK>
Models might interpret the warning about the candidate pool not being fully coupled as a possibility that the graph is disconnected in a way that makes the task impossible, but the text explicitly guarantees that at least one valid subset exists.
</RISK>
