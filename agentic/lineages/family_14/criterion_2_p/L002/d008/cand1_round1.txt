# Null Space Target Component Synchronization

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing an unknown vector $x \in \mathbb{R}^n$. The $i$-th component of $x$ is denoted as $x_i$.

There is a pool of $m$ available linear conditions. Each condition is represented by a row vector with exactly one $1$, exactly one $-1$, and $0$ everywhere else. Specifically, a condition defined by indices $u$ and $v$ corresponds to a row vector with $1$ at position $u$ and $-1$ at position $v$. Activating this condition incurs a cost of $w$. 

The pool of conditions is provided as-is. Do not assume the available conditions are linearly independent. The full $m \times n$ matrix formed by activating all available conditions may contain redundant dependencies, and its null space dimension is not guaranteed to be exactly 1. 

You are given a set of $t$ target indices. Your objective is to select a subset of the available conditions to form a constraint matrix $B$. This matrix must be chosen such that for every vector $x$ in the null space of $B$ (i.e., all $x$ satisfying $Bx = \mathbf{0}$), the components $x_i$ for all target indices $i$ are identical. You may include conditions involving non-target indices if they are algebraically necessary to restrict the null space in this way.

Determine the minimum total cost of a selected subset of conditions that achieves this requirement. The total cost is the sum of the costs $w$ of the conditions you choose to include. It is guaranteed that at least one valid subset exists.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$).
The second line contains $t$ distinct integers: the target indices.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing an available condition with $1$ at position $u$ and $-1$ at position $v$, which requires a cost of $w$ to activate.

## Output

Print a single integer: the minimum total cost of a subset of conditions whose resulting matrix null space forces all target components to be equal.

## Examples

### Example 1

**Input**
```

```

**Output**
```
8
```

**Output**
```

```

### Example 3


**Output**
```
9
```
