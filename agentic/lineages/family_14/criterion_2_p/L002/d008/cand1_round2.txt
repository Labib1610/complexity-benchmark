<STATEMENT>
# Shaft Synchronization Mechanism

Time limit: 2 s   Memory limit: 256 MB

## Description

You are assembling a mechanical system with $n$ rotating shafts. The angular velocity of the $i$-th shaft is $x_i$.

There is a pool of $m$ available transmission belts. Each available belt is specified by two indices $u$ and $v$ and an installation cost $w$. Installing this belt rigidly connects shaft $u$ and shaft $v$, enforcing the algebraic condition $x_u = x_v$.

To ensure the system's architecture is well-defined, you are guaranteed that the full pool of $m$ available belts is minimally sufficient to synchronize the entire assembly. Specifically, if you were to install all $m$ belts, all $n$ shafts would be forced to rotate at the exact same angular velocity. However, the available belts are strictly non-redundant: removing any single belt from the full pool of $m$ would allow some shafts to rotate at different velocities. 

You are given a target set of $t$ critical shafts. You must select a subset of the available belts to install. Your goal is to ensure that in the resulting mechanism, the angular velocities $x_i$ for all $t$ critical shafts are forced to be identical to each other. You may install belts involving non-critical shafts if they are necessary to satisfy this synchronization requirement.

Find the minimum total installation cost of a selected subset of belts that achieves this goal. The total cost is the sum of the installation costs $w$ of the belts you choose to install.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$). 
The second line contains $t$ distinct integers: the indices of the critical shafts.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing an available belt connecting shaft $u$ and shaft $v$, which requires a cost of $w$ to install.

The provided set of $m$ available belts strictly satisfies the minimal sufficiency guarantee described above.

## Output

Print a single integer: the minimum total cost of a subset of belts whose resulting configuration forces all critical shafts to rotate at the same angular velocity.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1

```

**Output**
```
8
```

### Example 2

**Output**
```

```

### Example 3

**Input**
```

1 2 3

```

**Output**
```

```

<RATIONALE>
The problem was reframed from a null space matrix task to a mechanical shaft synchronization task. The structural guarantee of a tree was preserved by specifying that the full set of constraints is connected ("forces all to rotate at the exact same velocity") and minimal ("removing any single belt allows different velocities"), forcing solvers to deduce the tree structure rather than relying on explicit linear algebra keywords like "null space dimension 1".
</RATIONALE>
<PRESERVED_ANSWER>
The required constraints still form a tree and the objective is still to find the minimum cost subtree connecting all target vertices, so the optimal cost is identical for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the minimum Steiner tree problem on a graph that is guaranteed to be a tree, which is solvable in $O(n)$ time.
</PRESERVED_CLASS>
