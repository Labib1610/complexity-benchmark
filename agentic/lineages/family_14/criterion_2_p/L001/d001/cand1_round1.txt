# Problem B — Activating the Primary Network

Time limit: 2 s   Memory limit: 256 MB

## Description

A large facility consists of **n** locations (numbered 1 to n). You are provided with a list of **m** potential bidirectional data links that can be activated between specific pairs of locations. Each link has a known activation cost. The available links are minimally sufficient to network the entire facility: they can connect all locations, but removing any single link from the given list would leave some locations isolated from others.

A specific group of **t** locations are designated as **primary**. Your objective is to choose a subset of the potential links to activate such that every primary location can communicate with every other primary location (data can be routed through any activated intermediate locations). Determine the absolute minimum total activation cost required to accomplish this.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers: the ids of the primary locations.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): a potential link between location u and location v with an activation cost of w.

## Output

Print a single integer: the minimum total activation cost to fully connect all primary locations.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the primary locations 1 and 4 can only communicate if the links between (1,2), (2,3), and (3,4) are all activated. The total cost is 5 + 1 + 2 = 8.
In Example 2, there is only one primary location, so no links need to be activated.
In Example 3, primary locations 1, 2, and 3 must all be connected. Activating link (1,2) with cost 4 and link (2,3) with cost 5 achieves this for a total cost of 9.

The explicit phrase "between any two sites there is exactly one possible cabling route" was removed, as it acts as a massive hint that the graph is a tree and any subset connection is simply the union of these unique paths. The problem is now framed as a general network design task (finding a Steiner Tree), forcing the model to independently deduce from the "minimally sufficient" description and the `m = n - 1` constraint that the network is a tree, and thus solvable in linear time rather than requiring a complex NP-hard approximation.
</RATIONALE>
