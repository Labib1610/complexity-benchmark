# Problem B — Cabling the Required Sites (Constrained Layout)

Time limit: 2 s   Memory limit: 256 MB

## Description

A campus has **n** sites (numbered 1 to **n**). Certain pairs of sites can be joined by a cabling option at a given cost. Among the sites, **t** are **required** and must all end up connected to each other through the cabling you install (directly or through intermediate relay sites).

In this campus, the available cabling options are structurally minimal: it is possible to route a connection between any two sites using the available options, but the removal of any single option from the available pool would leave some sites unreachable from others.

Install a set of cabling options of minimum total cost so that all required sites are connected. Report that minimum total cost.

## Input

The first line contains three integers **n**, **m**, and **t**.
- **n** is the total number of sites. The campus has at least 1 site and a maximum capacity of 200000 sites.
- **m** is the number of available cabling options. Due to the minimal infrastructure, **m** is exactly **n** − 1.
- **t** is the number of required sites. There is at least 1 required site, up to a maximum of **n**.

The second line contains **t** distinct integers: the identifiers of the required sites.

Each of the next **m** lines contains three integers **u**, **v**, and **w**, describing a cabling option between site **u** and site **v** at cost **w**.
- **u** and **v** are distinct site identifiers ranging from 1 to **n**.
- **w** is the cost of the option, which is at least 1 and capped by a maximum single-link budget of 1000000.

The options follow the minimal structure described above.

## Output

Print a single integer: the minimum total cost to connect all required sites.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

This is the same minimum-cabling problem as Problem A. The only difference is the structural constraint on the available cabling options. In Example 1 the required sites 1 and 4 are joined only through 2 and 3, so all three options (5+1+2 = 8) are needed. In Example 2 there is one required site, so no cabling is needed.
</STATEMENT>
<RATIONALE>
Removed the explicit phrases "exactly one possible cabling route" which serve as a strong keyword trigger for tree-based algorithms. Replaced it with the structural property that the network is connected but the removal of any single edge disconnects it, forcing the model to deduce the tree structure mathematically rather than via pattern matching. The numeric bounds are integrated into descriptive prose as physical capacities and budgets, satisfying the strategy while keeping the exact numbers explicitly visible for validation.
</RATIONALE>
<PRESERVED_ANSWER>
The structural definition (connected + every edge is a bridge) is exactly equivalent to a tree, so the unique path between any two required sites remains identical, preserving all optimal cabling costs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks for the minimum weight connected subgraph spanning a subset of vertices on a tree (Steiner tree on a tree), which remains solvable in linear time (O(n)) by trimming leaves or doing a subtree sum, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might fail to parse the constraints from the bulleted list since they are embedded in prose rather than bare inequalities, but the numeric values are explicitly present and unambiguous.
</RISK>
