<STATEMENT>
# Problem B — Equivalence System Calibration

Time limit: 2 s   Memory limit: 256 MB

## Description

You are configuring a system of $n$ variables, indexed 1 to $n$.
You must assign a binary status $x_i \in \{0, 1\}$ to each variable $i$ (for $1 \le i \le n$). 
A specific set of $t$ mandatory variables must be assigned a status of 1; that is, $x_i = 1$ for every mandatory variable $i$.

You are given $m$ pairwise constraints. Each constraint $j$ binds variable $u_j$ and variable $v_j$, and has an associated calibration cost $w_j$.
These $m$ constraints are guaranteed to form a minimal, complete equivalence system. This means that if you were to write an algebraic equation $Z_{u_j} = Z_{v_j}$ for each constraint $j$, the resulting system of $m$ equations would be strictly non-redundant and would uniquely force all $n$ variables $Z_1, \dots, Z_n$ to be equal.

The *structural index* of a status assignment $x$ is defined mathematically as the number of variables assigned 1, minus the number of constraints where both bound variables are assigned 1:
$$ I(x) = \sum_{i=1}^n x_i - \sum_{j=1}^m x_{u_j} x_{v_j} $$
An assignment is considered **valid** if and only if its structural index evaluates to exactly $I(x) = 1$.

The *operational cost* of an assignment is the sum of the calibration costs for the constraints where both bound variables are assigned 1:
$$ C(x) = \sum_{j=1}^m w_j x_{u_j} x_{v_j} $$

Your task is to determine the absolute minimum operational cost $C(x)$ among all valid assignments.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$).
The second line contains $t$ distinct integers: the indices of the mandatory variables.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a constraint binding variable $u$ and variable $v$ with a calibration cost of $w$.
These $m$ constraints are guaranteed to form the minimal equivalence system described above.

## Output

Print a single integer: the minimum operational cost $C(x)$ of a valid assignment.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the mandatory variables are 1 and 4, so $x_1 = 1$ and $x_4 = 1$. 
If we only assign 1 to these two ($x = [1, 0, 0, 1]$), the structural index is:
$I(x) = (1 + 0 + 0 + 1) - (0 + 0 + 0) = 2$.
Since $I(x) \neq 1$, this assignment is invalid.
If we assign 1 to all four variables ($x = [1, 1, 1, 1]$), the structural index is:
$I(x) = (1 + 1 + 1 + 1) - (1 \cdot 1 + 1 \cdot 1 + 1 \cdot 1) = 4 - 3 = 1$.
This assignment is valid. The operational cost is $C(x) = 5(1) + 1(1) + 2(1) = 8$.

In Example 2, there is only one mandatory variable (3). By setting $x_3 = 1$ and all other $x_i = 0$, we get:
$I(x) = 1 - 0 = 1$.
This assignment is valid, and the operational cost is $C(x) = 0$.

In Example 3, mandatory variables 1, 2, and 3 must all be assigned 1 ($x = [1, 1, 1]$).
$I(x) = (1 + 1 + 1) - (1 \cdot 1 + 1 \cdot 1) = 3 - 2 = 1$.
The operational cost is $C(x) = 4(1) + 5(1) = 9$.
</STATEMENT>
<RATIONALE>
The explicit description of a tree ("exactly one non-repeating sequence of links connecting them") was replaced with an equivalent algebraic property ("system of equations Z_u = Z_v that is non-redundant and forces all variables to be equal"). This removes the standard competitive programming boilerplate that allowed models to immediately recognize the problem as finding a Steiner tree on a tree, forcing them to deduce the connectedness and acyclicity from first principles.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical formulation of the constraints, the operational cost, and the valid assignment condition remain identical, meaning the exact same subtree of selected variables minimizes the cost.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure is still a tree and the goal is still to find the minimum weight subtree spanning a set of mandatory nodes, keeping the problem in P (solvable in O(n) via DFS).
</PRESERVED_CLASS>
<RISK>
A model might misinterpret the hypothetical variables $Z_i$ used to explain the equivalence system as being related to the actual variables $x_i$, though the text explicitly separates them.
</RISK>
