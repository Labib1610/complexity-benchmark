We are given a tree (since m = n - 1) and a set of primary nodes.  
We need the minimum cost to connect all primary nodes.  
This is equivalent to finding the **Steiner tree** for the primary nodes in a tree, which is simply the union of all paths between primary nodes.  

The minimal cost is the sum of all edges that lie on the minimal subtree connecting all primary nodes.  

A standard way:  
- Root the tree at any primary node.  
- Do a DFS, and for each edge, if the subtree below it contains at least one primary node, then that edge must be included.  

Implementation:  

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    primaries = set(map(int, input().split()))
    
    adj = [[] for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
        edges.append((u, v, w))
    
    # Root at any primary node
    root = next(iter(primaries))
    
    parent = [0] * (n + 1)
    parent_cost = [0] * (n + 1)
    order = []
    stack = [root]
    parent[root] = -1
    while stack:
        u = stack.pop()
        order.append(u)
        for v, w in adj[u]:
            if v == parent[u]:
                continue
            parent[v] = u
            parent_cost[v] = w
            stack.append(v)
    
    # Count primaries in subtree
    has_primary = [False] * (n + 1)
    for p in primaries:
        has_primary[p] = True
    
    total_cost = 0
    # Process in reverse order (post-order)
    for u in reversed(order):
        if u == root:
            continue
        if has_primary[u]:
            total_cost += parent_cost[u]
        # propagate up
        if has_primary[u]:
            has_primary[parent[u]] = True
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
