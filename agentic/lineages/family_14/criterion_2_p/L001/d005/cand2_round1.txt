<STATEMENT>
# Problem B — State Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of **n** components, numbered 1 to $n$. Each component $i$ must be assigned a binary state: $V_i \in \{0, 1\}$. 

The system includes **m** coupling terms. Each coupling term connects two distinct components, $u$ and $v$, and carries a non-negative penalty $w$. 

For each component $i$, we define its *co-activation degree* $d_i$ as the number of coupling terms connecting $i$ to some other component $j$ where $V_j = 1$.

A specific subset of **t** components are designated as **primary**. Your assignment of states must strictly satisfy the following conditions:
1. Every primary component $c$ must be active: $V_c = 1$.
2. The sum of the co-activation degrees of all *active* components must exactly equal twice the total number of active components minus two. Mathematically:
   $$ \sum_{i=1}^n (V_i \times d_i) = 2 \left( \sum_{i=1}^n V_i \right) - 2 $$

When a coupling term connects two active components ($V_u = 1$ and $V_v = 1$), it is considered *realized*, and you incur its penalty $w$. Coupling terms that are not realized incur no penalty.

Your task is to determine the absolute minimum total penalty required to yield a valid assignment of states.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers: the indices of the primary components.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000) representing a coupling term between component **u** and component **v** with a penalty of **w**.

## Output

Print a single integer: the minimum total penalty required for a valid assignment.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the primary components are 1 and 4, so $V_1 = 1$ and $V_4 = 1$. If we only activate these two ($\sum V_i = 2$), neither is coupled to another active component, so $d_1 = 0$ and $d_4 = 0$. The sum $\sum (V_i \times d_i)$ would be 0, which violates $0 = 2(2) - 2$. To satisfy the equation, we must also set $V_2 = 1$ and $V_3 = 1$. This yields $\sum V_i = 4$. The co-activation degrees are $d_1 = 1$, $d_2 = 2$, $d_3 = 2$, and $d_4 = 1$. The sum is $1 + 2 + 2 + 1 = 6$. The right side of the equation is $2(4) - 2 = 6$, so the assignment is valid. The coupling terms (1,2), (2,3), and (3,4) are realized. The total penalty is 5 + 1 + 2 = 8.

In Example 2, there is only one primary component ($V_3 = 1$). By setting all other components to 0, we have $\sum V_i = 1$ and $d_3 = 0$. The sum $\sum (V_i \times d_i)$ is 0. The equation $0 = 2(1) - 2$ is satisfied. The minimum total penalty is 0.

In Example 3, primary components 1, 2, and 3 must all be active, so $\sum V_i = 3$. The co-activation degrees are $d_1 = 1$, $d_2 = 2$, and $d_3 = 1$. The sum is $1 + 2 + 1 = 4$. The right side is $2(3) - 2 = 4$, satisfying the equation. The coupling terms (1,2) and (2,3) are realized. The total penalty is 4 + 5 = 9.
</STATEMENT>
<RATIONALE>
I removed the explicit statement that the relations form "exactly one simple sequence" (which trivially identifies the graph as a tree). I then replaced the global edge-count constraint with a local co-activation degree sum constraint ($\sum V_i d_i = 2 \sum V_i - 2$). This mathematically enforces that the induced active subgraph is a single connected tree, but obscures this structural fact behind an algebraic formula, forcing models to independently discover the tree equivalence rather than relying on surface-level pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic degree constraint evaluates to exactly twice the number of realized couplings, making it mathematically equivalent to the original constraint $|E_{active}| = |V_{active}| - 1$; since the input graph is a tree, the only valid assignments remain the connected subtrees spanning all primary components, yielding identical minimum costs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Because the valid assignments are exactly the connected subtrees spanning the primary components on the input tree, the problem is still solvable in O(n) time using a standard tree traversal to find the minimal spanning subtree.
</PRESERVED_CLASS>
<RISK>
The definition of co-activation degree $d_i$ could be misinterpreted if a reader fails to realize it counts coupling terms based on the state of the *other* component $j$, but the phrase "where $V_j = 1$" combined with the detailed worked examples makes this unambiguous.
</RISK>
