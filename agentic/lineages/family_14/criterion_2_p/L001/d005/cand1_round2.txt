<STATEMENT>
# Problem B — Core Factions

Time limit: 2 s   Memory limit: 256 MB

## Description

You are evaluating a network of **n** facilities (numbered 1 to n) and **m** bidirectional communication links. The network is fully connected, and $m = n - 1$. This structure guarantees there is exactly one simple path of links between any two facilities.

A specific group of **t** facilities are designated as **primary**. 

The network must support a system-wide synchronization protocol. During synchronization, every primary facility must be able to send a direct message to every other primary facility. Each message travels along the unique simple path between the two primary facilities.

You must select a subset of links to be *active*. A selected subset is considered valid if it can successfully route all synchronization messages. A message can only be successfully routed if every link on its unique simple path is selected to be active.

Each link has a specific maintenance cost **w**. When a link is selected to be active, you must pay this cost. Links that are not active cost nothing. You only pay a link's maintenance cost once, regardless of how many messages travel through it.

If there is fewer than two primary facilities, no messages are sent, so zero links need to be active and the cost is 0.

Find the absolute minimum total maintenance cost required to select a valid subset of active links.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers: the ids of the primary facilities.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000) representing a bidirectional link between facility u and facility v with a maintenance cost of w.

## Output

Print a single integer: the minimum total maintenance cost required for a valid subset of active links.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the primary facilities are 1 and 4. The single synchronization message between facility 1 and facility 4 travels through links (1,2), (2,3), and (3,4). To successfully route this message, all three links must be selected to be active. The minimum total cost is 5 + 1 + 2 = 8.

In Example 2, there is only one primary facility (3). Since there are no pairs of primary facilities, no messages are sent. A valid subset can contain zero active links. The minimum total cost is 0.

In Example 3, the primary facilities are 1, 2, and 3. The synchronization messages are:
- Between 1 and 2: travels through link (1,2).
- Between 2 and 3: travels through link (2,3).
- Between 1 and 3: travels through links (1,2) and (2,3).
To route all these messages, links (1,2) and (2,3) must both be selected to be active. The minimum total cost is 4 + 5 = 9.
