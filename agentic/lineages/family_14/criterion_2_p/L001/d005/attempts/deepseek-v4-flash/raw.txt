We are given a tree (since \( m = n-1 \) and there’s exactly one path between any two nodes).  
The condition is:

\[
X^T A X = 2 X^T X - 2
\]

Let \( k = X^T X \) = number of activated modules.  
\( X^T A X = 2 \times (\text{number of edges with both endpoints activated}) \).

So the condition becomes:

\[
2E = 2k - 2 \quad \Rightarrow \quad E = k - 1
\]

Where \( E \) is the number of activated edges.  
Thus, the activated modules must form a connected subgraph (a tree) with exactly \( k \) nodes and \( k-1 \) edges.  
Since the original graph is a tree, any connected subset of nodes induces a connected subgraph that is also a tree.

So the problem reduces to:  
We must choose a connected set of nodes containing all primary modules, minimizing the sum of edge weights inside that set.

This is the **Steiner tree** problem on a tree, which can be solved by:

- Start with the minimal subtree connecting all primary nodes.
- This is unique: take the union of all paths between primary nodes.
- The cost is the sum of edge weights in that minimal subtree.

We can find it by:
1. Mark all primary nodes.
2. Do a DFS/BFS from any primary node, count how many primary nodes are in each subtree.
3. An edge is included if both sides contain at least one primary node.

Let’s implement that.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    primary = set(map(int, input().split()))
    
    adj = [[] for _ in range(n+1)]
    edges = []
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
        edges.append((u, v, w))
    
    # DFS to count primary nodes in subtree
    parent = [0]*(n+1)
    pweight = [0]*(n+1)
    order = []
    stack = [1]
    parent[1] = -1
    while stack:
        u = stack.pop()
        order.append(u)
        for v, w in adj[u]:
            if v != parent[u]:
                parent[v] = u
                pweight[v] = w
                stack.append(v)
    
    cnt = [0]*(n+1)
    for u in primary:
        cnt[u] = 1
    
    total_cost = 0
    for u in reversed(order):
        if u == 1:
            continue
        if cnt[u] > 0:
            total_cost += pweight[u]
        cnt[parent[u]] += cnt[u]
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
