<METHOD_NAME>Endpoint Assignment Invariant</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the algebraic formula for local stability (which trivially reduced to 2V - 2E = 2) with a combinatorial assignment condition. The model must now deduce that assigning each edge to one endpoint such that one vertex receives 0 and all others receive 1 logically requires E = V - 1, which on a tree implies the activated vertices form a single connected component.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Core Factions

Time limit: 2 s   Memory limit: 256 MB

## Description

You are configuring a system of $n$ modules (indexed 1 to $n$) and $m$ bidirectional channels. The channels are structured such that between any two modules, there is exactly one non-repeating sequence of channels linking them.

You must choose a subset of modules to activate. A specific set of $t$ primary modules is mandatory and must be included in your activated subset.

Each channel has a specific positive maintenance penalty $w$. A channel is considered *energized* if and only if both of its endpoint modules are activated. For every energized channel, its maintenance penalty is added to the total cost of the configuration. Channels that are not energized incur no cost.

To ensure system coherence, your chosen subset of activated modules is considered valid if and only if there exists at least one way to assign every energized channel to exactly one of its two endpoint modules such that:
- Exactly one activated module is assigned zero energized channels.
- Every other activated module is assigned exactly one energized channel.

You must determine the absolute minimum total cost required to yield a valid configuration of activated modules.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$).
The second line contains $t$ distinct integers: the indices of the primary modules.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a channel connecting module $u$ and module $v$ with a maintenance penalty of $w$.
These $m$ channels are guaranteed to form the structure described above (exactly one non-repeating sequence of channels linking any two modules).

## Output

Print a single integer: the minimum total cost required for a valid configuration.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the primary modules are 1 and 4, so they must be activated. If we only activate these two, there are no energized channels. We have 2 activated modules, but 0 energized channels to assign. It is impossible to have exactly one module assigned zero channels and the other assigned one channel, so this configuration is invalid. If we activate modules 1, 2, 3, and 4, the energized channels are (1,2), (2,3), and (3,4). We can assign channel (1,2) to module 2, channel (2,3) to module 3, and channel (3,4) to module 4. Module 1 is assigned zero channels, while modules 2, 3, and 4 are each assigned exactly one channel. This satisfies the condition, making the configuration valid. The total cost is 5 + 1 + 2 = 8.

In Example 2, there is only one primary module (3). By activating only module 3, there are no energized channels. Module 3 is assigned zero channels, and since there are no other activated modules, the condition is perfectly satisfied. The minimum total penalty is 0.

In Example 3, primary modules 1, 2, and 3 must all be activated. The energized channels are (1,2) and (2,3). We can assign (1,2) to module 1 and (2,3) to module 3. Module 2 is assigned zero channels, while modules 1 and 3 are each assigned exactly one. The configuration is valid, yielding a total cost of 4 + 5 = 9.
</STATEMENT>
<RATIONALE>
Removed the "local stability" formula (2 - c(u)) which trivially summed to 2V - 2E, allowing models to easily pattern-match the condition 2V - 2E = 2. Replaced it with a combinatorial assignment invariant that mathematically forces E = V - 1. Models must now independently deduce that this mapping implies connectivity on the given graph structure.
</RATIONALE>
<PRESERVED_ANSWER>
The assignment condition requires E = V - 1 energized channels for V activated modules; on a tree, this is true if and only if the activated modules form a single connected component, which is exactly the same validity constraint as the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks for the minimum-weight connected subgraph spanning a set of mandatory vertices on a tree (the Steiner tree), which remains solvable in O(n) time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "assign every energized channel to exactly one of its two endpoint modules" as modifying the graph's edges rather than being a purely logical condition, though the phrase "there exists at least one way to assign" heavily implies it is a property to be satisfied.
</RISK>
