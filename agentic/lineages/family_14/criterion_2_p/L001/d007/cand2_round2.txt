<METHOD_NAME>
Topological Sequence Disguise
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the algebraic sum of local stabilities with an equivalent structural property: the existence of an elimination ordering where every vertex except the last has exactly one forward edge. This defeats solvers that pattern-match the algebraic sum to Euler's formula (2|V| - 2|E| = 2) to deduce the subset must be a connected tree, forcing them to instead reason about the graph-theoretic implications of the sequence condition.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<STATEMENT>
# Problem B — Core Factions

Time limit: 2 s   Memory limit: 256 MB

## Description

You are configuring a system of $n$ modules (indexed 1 to $n$) and $m$ bidirectional channels. The channels are structured such that between any two modules, there is exactly one non-repeating sequence of channels linking them.

You must choose a subset of modules to activate. A specific set of $t$ primary modules is mandatory and must be included in your activated subset.

Each channel has a specific positive maintenance penalty $w$. A channel is considered *energized* if and only if both of its endpoint modules are activated. For every energized channel, its maintenance penalty is added to the total cost of the configuration. Channels that are not energized incur no cost.

Your chosen subset of activated modules is considered valid if and only if its modules can be ordered into a sequence $v_1, v_2, \dots, v_k$ (where $k$ is the total number of activated modules) such that for every index $i$ from $1$ to $k-1$, the module $v_i$ is directly connected (via an energized channel) to exactly one module that appears later in the sequence (i.e., among $v_{i+1}, \dots, v_k$).

You must determine the absolute minimum total cost required to yield a valid configuration of activated modules.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$).
The second line contains $t$ distinct integers: the indices of the primary modules.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a channel connecting module $u$ and module $v$ with a maintenance penalty of $w$.
These $m$ channels are guaranteed to form the structure described above (exactly one non-repeating sequence of channels linking any two modules).

## Output

Print a single integer: the minimum total cost required for a valid configuration.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the primary modules are 1 and 4, so they must be activated. If we only activate these two, there are no energized channels. For the sequence $v_1=1, v_2=4$, module 1 is connected to zero modules later in the sequence, which violates the requirement of exactly one. Thus, this configuration is invalid. 
If we activate modules 1, 2, 3, and 4, the energized channels are (1,2), (2,3), and (3,4). We can order them as $1, 4, 2, 3$. Module 1 connects only to 2 (which is later). Module 4 connects only to 3 (which is later). Module 2 connects to 1 (earlier) and 3 (later), so it connects to exactly one module later in the sequence. This proves the configuration is valid. The cost is 5 + 1 + 2 = 8.

In Example 2, there is only one primary module (3). By activating only module 3, $k=1$. The sequence is just $3$. The condition for indices $1$ to $k-1$ requires nothing, so it is trivially valid. No channels are energized, so the minimum total penalty is 0.

In Example 3, primary modules 1, 2, and 3 must all be activated. The energized channels are (1,2) and (2,3). We can use the sequence $1, 3, 2$. Module 1 connects to 2 (later). Module 3 connects to 2 (later). The condition is satisfied. The energized channels yield a total cost of 4 + 5 = 9.
</STATEMENT>
<RATIONALE>
The surviving model relied on pattern-matching the algebraic sum of local stabilities (which evaluates to $2|V| - 2|E|$) to Euler's formula, immediately deducing that the valid configuration must be a single connected tree. To defeat this, the algebraic condition was replaced with an equivalent structural property: the existence of an elimination ordering where every vertex except the last has exactly one forward edge. This preserves the exact same mathematical constraint (an induced subtree) but forces the model to reason about the graph-theoretic implications of the sequence rather than relying on a hardcoded algebraic shortcut.
</RATIONALE>
<PRESERVED_ANSWER>
The sequence condition is satisfied if and only if the induced subgraph of activated modules is a single connected tree, which is exactly the same requirement as the original local stability sum, meaning the optimal subsets and their costs remain completely unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding the minimum total weight of edges to connect a given set of mandatory vertices in a tree, which is the exact same O(n) Steiner tree problem on a tree as the original.
</PRESERVED_CLASS>
<RISK>
A reader might mistakenly assume they are required to output or construct the sequence, but the wording clearly states the sequence is just a condition for validity ("considered valid if and only if its modules can be ordered into a sequence"), and the Output section strictly asks for the minimum total cost.
</RISK>
