<METHOD_NAME>Deactivated Degree Identity</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the tree connectivity condition (V - E = 1 for the active subgraph) with a mathematically equivalent but highly obscured identity on the inactive subgraph: the sum of full-graph degrees of all inactive vertices equals the number of inactive vertices plus the number of edges between two inactive vertices. Because this involves full-graph degrees and inactive edges, it masks the active-subgraph focus and requires non-trivial algebraic graph theory to simplify back to V - E = 1.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Network Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

You are evaluating a communication grid consisting of $n$ modules and $m$ bidirectional links. The grid is connected.

You must assign an operational state $x_i \in \{0, 1\}$ to each module $i$ ($1 \le i \le n$). A module is activated if $x_i = 1$, and deactivated if $x_i = 0$.
A specific subset of $t$ critical modules must be activated (that is, $x_i = 1$ for these modules).

For any module, let its *connection count* be the total number of links connected to it in the full grid. 
An assignment is considered **valid** if the sum of the connection counts of all deactivated modules is exactly equal to the total number of deactivated modules plus the number of links where both endpoints are deactivated.

Each link $j$ has a positive maintenance penalty $w_j$. The *activation cost* of an assignment is the sum of the maintenance penalties for all links where both endpoint modules are activated.

Your task is to determine the absolute minimum activation cost among all valid assignments.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$).
The second line contains $t$ distinct integers: the IDs of the critical modules.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a bidirectional link between module $u$ and module $v$ with a maintenance penalty of $w$.
It is guaranteed that the links form a connected grid.

## Output

Print a single integer: the minimum activation cost of a valid assignment.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the critical modules are 1 and 4. The connection counts in the grid are: module 1 has 1, module 2 has 2, module 3 has 2, module 4 has 1.
If we only activate modules 1 and 4 ($x = [1, 0, 0, 1]$):
- The deactivated modules are 2 and 3.
- The sum of their connection counts is $2 + 2 = 4$.
- The total number of deactivated modules is 2.
- The links with both endpoints deactivated is exactly 1 (the link between 2 and 3).
The sum of connection counts (4) does not equal the number of deactivated modules plus deactivated links ($2 + 1 = 3$). This assignment is invalid.

If we activate all four modules ($x = [1, 1, 1, 1]$):
- The deactivated modules: none.
- The sum of their connection counts is 0.
- The number of deactivated modules is 0, and links with both endpoints deactivated is 0.
Since $0 = 0 + 0$, this assignment is valid. 
The activation cost is the sum of penalties for links where both endpoints are activated: $5 + 1 + 2 = 8$.

In Example 2, the only critical module is 3. By activating only module 3 ($x = [0, 0, 1, 0, 0]$):
- The deactivated modules are 1, 2, 4, 5. 
- Their connection counts are 1, 2, 2, 1. The sum is $1 + 2 + 2 + 1 = 6$.
- The total number of deactivated modules is 4.
- The links with both endpoints deactivated are (1, 2) and (4, 5), which is 2 links.
Since $6 = 4 + 2$, this assignment is valid. 
The activation cost is 0, because no link has both endpoints activated.

In Example 3, critical modules 1, 2, and 3 must all be activated ($x = [1, 1, 1]$).
- There are no deactivated modules, so the sum of connection counts is 0.
- The number of deactivated modules is 0, and links with both endpoints deactivated is 0.
Since $0 = 0 + 0$, this assignment is valid. 
The activation cost is $4 + 5 = 9$.
</STATEMENT>
<RATIONALE>
The problem's core constraint $V_{act} - E_{act} = 1$ (which implies the active subset forms a connected subtree) was rewritten into a mathematically equivalent identity over the inactive complement. By forcing the condition to be evaluated as $\sum_{i \in I} D_i = |I| + E_{uniform\_0}$, models can no longer pattern-match the active subtree requirement directly. They must now perform a non-trivial algebraic graph theory reduction using the global $m = n - 1$ invariant to recover the true structural meaning, otherwise Tree DP or search approaches will appear to require tracking large state sums and fail.
</RATIONALE>
