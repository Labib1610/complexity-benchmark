# Problem B — Activating the Primary Network

Time limit: 2 s   Memory limit: 256 MB

## Description

You are tasked with establishing a communication sub-network across **n** sites (numbered 1 to n). You are given a list of **m** possible bidirectional links that could be established between these sites. Each link has a specific activation cost. The provided list of links is comprehensive enough that, if all were activated, any site could send a message to any other site.

Among the sites, **t** are designated as **critical** facilities. You must choose a subset of the **m** links to activate such that all **critical** facilities can exchange messages with one another. A message can pass through any number of activated links, and may transit through non-critical sites.

Find the minimum possible sum of activation costs needed to ensure that all critical facilities are interconnected.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line lists **t** distinct integers: the identifiers of the critical facilities.
The following **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000). This indicates a possible link between site u and site v with an activation cost of w.

## Output

Output a single integer representing the minimum total cost to activate a valid sub-network for the critical facilities.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the critical facilities 1 and 4 can only communicate if the links between (1,2), (2,3), and (3,4) are all activated. The total cost is 5 + 1 + 2 = 8.
In Example 2, there is only one critical facility, so no links need to be activated. The minimum total cost is 0.
In Example 3, critical facilities 1, 2, and 3 must all be connected. Activating the link (1,2) with cost 4 and the link (2,3) with cost 5 achieves this for a total cost of 9.
