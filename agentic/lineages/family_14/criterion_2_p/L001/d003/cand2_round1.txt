# Problem B — Activating the Primary Network

Time limit: 2 s   Memory limit: 256 MB

## Description

You are tasked with establishing a dedicated communication network across **n** sites using a pool of **m** available bidirectional fiber links. Each link has a specific installation cost.

A subset of **t** sites are designated as **core** sites. Your objective is to select a subset of the available fiber links to install such that every core site can transmit data to every other core site. Data can be routed through any installed links, including those passing through non-core sites.

Calculate the absolute minimum total installation cost required to ensure all core sites are mutually interconnected.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers: the identifiers of the core sites.
Each of the subsequent **m** lines provides three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating an available fiber link between site u and site v with an installation cost of w.

## Output

Output a single integer representing the minimum total cost to connect all core sites.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the core sites 1 and 4 can only communicate if the links between (1,2), (2,3), and (3,4) are all installed. The total cost is 5 + 1 + 2 = 8.
In Example 2, there is only one core site, so no links need to be installed. The minimum total cost is 0.
In Example 3, core sites 1, 2, and 3 must all be interconnected. Installing the link (1,2) with cost 4 and the link (2,3) with cost 5 achieves this for a total cost of 9.
