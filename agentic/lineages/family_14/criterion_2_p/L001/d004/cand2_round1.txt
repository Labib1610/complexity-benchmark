# Problem B — Axiomatic Equivalences

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a formal logical system containing **n** distinct propositions (numbered 1 to n). You are provided with a set of **m** bidirectional logical equivalences. Each equivalence establishes that proposition **u** and proposition **v** are logically equivalent, and requires a cognitive load of **w** to comprehend.

These **m** equivalences are comprehensive and minimally independent: if you accept all of them, you can construct proofs showing that all **n** propositions are mutually equivalent, and this property is lost if even a single equivalence is removed.

You are focusing on a specific subset of **t** core propositions. Your objective is to select a subset of the provided equivalences to accept as axioms, such that you can formally prove that all **t** core propositions are equivalent to each other. You may use non-core propositions as intermediate steps in your proofs.

Determine the absolute minimum total cognitive load of the equivalences you must accept to guarantee the core propositions are mutually equivalent.

## Input

The first line contains three integers **n**, **m**, and **t**. The bounds are derived from the system: the number of propositions **n** is up to 200,000 (1 ≤ n ≤ 200000), the number of core propositions **t** satisfies 1 ≤ t ≤ n, and **m** is exactly the theoretical minimum number of equivalences required for the system to be comprehensive as described.
The second line contains **t** distinct integers: the indices of the core propositions.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000) representing an equivalence between proposition u and proposition v with a cognitive load of w.

## Output

Print a single integer: the minimum total cognitive load required to prove all core propositions are equivalent.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, core propositions 1 and 4 can only be proven equivalent if the equivalences (1,2), (2,3), and (3,4) are all accepted. The total cognitive load is 5 + 1 + 2 = 8.
In Example 2, there is only one core proposition, so no equivalences need to be accepted. The minimum total load is 0.
In Example 3, core propositions 1, 2, and 3 must all be proven equivalent. Accepting the equivalence (1,2) with load 4 and the equivalence (2,3) with load 5 achieves this for a total load of 9.

<RATIONALE>
The problem was shifted from a spatial network of treaties to a formal logic system of propositions and equivalences. This removes structural keywords ("network", "simple sequence", "paths") that typically trigger tree-specific algorithms, while maintaining the exact same mathematical constraints. The implicit bound `m = n - 1` is preserved via the phrase "minimally independent", forcing models to either deduce the tree structure from algebraic properties or incorrectly apply greedy DSU/Kruskal algorithms which will fail by including irrelevant low-cost equivalences.
</RATIONALE>
<PRESERVED_ANSWER>
The logical equivalence relation is mathematically identical to reachable connected components in a graph, so finding the minimal subset of equivalences to link the core propositions requires finding the exact same minimal subtree as before.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The input still describes a tree structure (a minimally connected graph of equivalences), meaning the minimal subset can still be found in O(n) time using tree traversal, keeping it in P.
</PRESERVED_CLASS>
<RISK>
A reader might misinterpret "subset of the provided equivalences to accept as axioms" as allowing the creation of new equivalences, though "provided equivalences" explicitly restricts choices to the input set.
</RISK>
