**Solution Explanation**

For a set `S` of activated modules  

* each activated module creates `2` units,
* each edge whose both ends are in `S` consumes `1` unit from **each** end.

Total net stability  

```
sum_{v in S} 2  –  sum_{e inside S} 2 = 2·|S| – 2·E(S)
```

The assignment is valid iff this value equals `2` :

```
2·|S| – 2·E(S) = 2   →   |S| – E(S) = 1   →   E(S) = |S| – 1
```

`E(S) = |S|-1` means that the induced subgraph on `S` has exactly one edge
less than vertices – i.e. it is a **tree**.
The original graph is a tree, therefore any induced subgraph is a forest.
Consequently a valid assignment must activate a **connected subtree**
containing all critical modules.

The activation cost of a subtree is the sum of weights of its internal edges.
Among all connected subtrees containing the required vertices we need the one
with minimum total weight.

---

### 1.   Minimal subtree containing given vertices in a tree  

In a tree the unique minimal connected subgraph that contains a set of
vertices is the union of all simple paths between every pair of required
vertices.  
Equivalently, an edge belongs to this subtree **iff** there is at least one
required vertex on each side of the edge.

Therefore the answer is simply the sum of weights of all edges that separate
the required vertices into two non‑empty groups.

---

### 2.   Computing the needed edges  

Root the tree at any vertex (e.g. `1`).  
During a DFS compute for every node `v`

```
cnt[v] = number of required vertices in the subtree of v
```

For an edge `parent – child` with weight `w`

```
if 0 < cnt[child] < t :   // required vertices on both sides
        answer += w
```

`cnt[child] = 0` → no required vertex below, edge not needed.  
`cnt[child] = t` → all required vertices are below, edge not needed
(because the other side has none).

Complexities: `O(n)` time, `O(n)` memory.

---

### 3.   Correctness Proof  

We prove that the algorithm outputs the minimum possible activation cost.

#### Lemma 1  
A set of activated vertices `S` is valid **iff** the induced subgraph on `S`
is a tree.

*Proof.*  
From the derivation above, validity ⇔ `E(S)=|S|-1`.  
In any graph `E = |S|-1` holds exactly for trees (connected and acyclic). ∎



#### Lemma 2  
For a tree, the unique minimal connected subgraph containing a given set
`R` of vertices is the set of edges whose removal separates `R` into two
non‑empty parts.

*Proof.*  
Take any edge `e`. Removing it splits the tree into two components `A,B`.
If both `A` and `B` contain a vertex of `R`, any connected subgraph that
contains all of `R` must contain `e`; otherwise `R` would be disconnected.
If only one side contains `R`, `e` can be omitted.  
Thus the described set of edges is necessary and sufficient, and obviously
connected; any extra edge would be unnecessary. ∎



#### Lemma 3  
The algorithm sums exactly the weights of the edges described in Lemma 2.

*Proof.*  
Rooting the tree, for edge `parent–child` the component below the child is
exactly the subtree of `child`.  
`cnt[child]` counts required vertices inside it.
`0 < cnt[child] < t` ⇔ both sides of the edge contain required vertices.
Hence the algorithm adds the weight precisely for those edges. ∎



#### Lemma 4  
The subtree formed by the edges selected by the algorithm is a valid
activation set (its induced subgraph is a tree) and contains all critical
modules.

*Proof.*  
By Lemma 3 the selected edges connect all required vertices, therefore the
subgraph is connected and contains `R`.  
Being a subgraph of a tree, it is acyclic, thus a tree. By Lemma 1 the
corresponding activation set is valid. ∎



#### Lemma 5  
No other valid activation set has smaller total edge weight.

*Proof.*  
Any valid activation set must be a connected subtree containing `R`
(Lemma 1). By Lemma 2 every such subtree must contain **all** edges whose
removal separates `R`. The algorithm includes exactly those edges, therefore
any other subtree contains at least the same edges and possibly more,
hence its total weight is not smaller. ∎



#### Theorem  
The algorithm outputs the minimum possible activation cost among all valid
assignments.

*Proof.*  
From Lemma 4 the algorithm’s edge set corresponds to a valid assignment,
so the output is an achievable cost.  
From Lemma 5 no valid assignment can have lower cost.  
Thus the output is the optimum. ∎



---

### 4.   Complexity Analysis  

*Time* : one DFS traverses all `n` vertices and `n‑1` edges → `O(n)`  
*Memory*: adjacency list, `cnt` array, recursion/stack → `O(n)`

Both satisfy the limits (`n ≤ 200 000`).

---

### 5.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); t = int(next(it))
    required = [0] * (n + 1)
    for _ in range(t):
        required[int(next(it))] = 1

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it)); w = int(next(it))
        adj[u].append((v, w))
        adj[v].append((u, w))

    cnt = [0] * (n + 1)
    ans = 0

    def dfs(u, p):
        nonlocal ans
        c = required[u]
        for v, w in adj[u]:
            if v == p:
                continue
            sub = dfs(v, u)
            if 0 < sub < t:
                ans += w
            c += sub
        cnt[u] = c
        return c

    dfs(1, 0)
    print(ans)

if __name__ == "__main__":
    main()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
