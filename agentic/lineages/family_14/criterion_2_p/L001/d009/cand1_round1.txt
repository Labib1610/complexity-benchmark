<STATEMENT>
# Problem B — Network Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

You are evaluating a communication grid consisting of $n$ modules and $m$ bidirectional links. The grid is connected.

You must assign an operational state $x_i \in \{0, 1\}$ to each module $i$ ($1 \le i \le n$). A module is activated if $x_i = 1$, and deactivated if $x_i = 0$.
A specific subset of $t$ critical modules must be activated (that is, $x_i = 1$ for these modules).

When a module is activated, it generates exactly 2 units of operational stability. However, for every link that connects two activated modules, 1 unit of stability is consumed from each of those two connected modules. Links where at least one endpoint is deactivated consume no stability. 
The *total net stability* of an assignment is the sum of the remaining (unconsumed) stability units across all activated modules.
An assignment is considered **valid** if its total net stability evaluates to exactly 2.

Each link $j$ has a positive maintenance penalty $w_j$. The *activation cost* of an assignment is the sum of the maintenance penalties for all links where both endpoint modules are activated.

Your task is to determine the absolute minimum activation cost among all valid assignments.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$).
The second line contains $t$ distinct integers: the IDs of the critical modules.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a bidirectional link between module $u$ and module $v$ with a maintenance penalty of $w$.
It is guaranteed that the links form a connected grid.

## Output

Print a single integer: the minimum activation cost of a valid assignment.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Output**


### Example 3

**Input**
```

```

**Output**
```

```

## Note

In Example 1, the critical modules are 1 and 4. 
If we only activate these two modules ($x = [1, 0, 0, 1]$):
- Module 1 generates 2 stability units and consumes 0 (no activated neighbors).
- Module 4 generates 2 stability units and consumes 0.
The total net stability is $2 + 2 = 4$. This assignment is invalid.
If we activate all four modules ($x = [1, 1, 1, 1]$):
- Module 1 generates 2 units, and consumes 1 (shared with module 2). Net: 1.
- Module 2 generates 2 units, and consumes 2 (shared with 1 and 3). Net: 0.
- Module 3 generates 2 units, and consumes 2 (shared with 2 and 4). Net: 0.
- Module 4 generates 2 units, and consumes 1 (shared with 3). Net: 1.
The total net stability is $1 + 0 + 0 + 1 = 2$.
This assignment is valid. The activation cost is $5 + 1 + 2 = 8$.

In Example 2, the only critical module is 3. By activating only module 3 ($x = [0, 0, 1, 0, 0]$):
- Module 3 generates 2 stability units and consumes 0.
The total net stability is $2$.
This assignment is valid, and the activation cost is 0.

In Example 3, critical modules 1, 2, and 3 must all be activated ($x = [1, 1, 1]$).
- Module 1 generates 2 units, consumes 1. Net: 1.
- Module 2 generates 2 units, consumes 2. Net: 0.
- Module 3 generates 2 units, consumes 1. Net: 1.
The total net stability is $1 + 0 + 1 = 2$.
This assignment is valid, and the activation cost is $4 + 5 = 9$.

I also reframed the network balance equation as a physical resource constraint (stability units generated and consumed). This forces models to independently deduce both the tree topology from the input bounds and the mathematical equivalence of the stability constraint to the Euler characteristic.
