<METHOD_NAME>
Linear Algebraic Isomorphism
</METHOD_NAME>
<METHOD_DESCRIPTION>
Translates a graph connectivity problem into an equivalent problem of finding the minimum-cost subset of basis vectors (from a given set of $e_u - e_v$) that spans a required set of difference vectors. This completely removes graph terminology, tricking models into attempting matrix rank or Gaussian elimination algorithms which will TLE or MLE on $N=200,000$.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<STATEMENT>
# Subspace Span Minimization

Time limit: 2 s   Memory limit: 256 MB

## Description

You are working in an $N$-dimensional vector space over the real numbers, with standard basis vectors $e_1, e_2, \dots, e_N$. You are given a target set of $T$ distinct indices, called the *priority dimensions*. Your objective is to select a subset of available vectors such that for any two priority dimensions $a$ and $b$, the difference vector $e_a - e_b$ lies within the linear span of your selected subset. (If $T \le 1$, this condition is vacuously satisfied without selecting any vectors, so the cost is 0.)

You are provided with a catalog of $M$ available vectors. Each vector in the catalog is defined by a pair of indices $(u, v)$ and, when selected, adds the vector $e_u - e_v$ to your chosen subset. Selecting this vector incurs a scalar cost of $w$. 

Your goal is to choose a subset of these $M$ available vectors such that the condition $e_a - e_b \in \text{Span}(\text{Selected})$ is logically guaranteed for all priority dimensions $a, b$. 

You must find the minimum possible total cost (the sum of the costs of the chosen vectors) to achieve this.

## Input

The first line provides three integers $N$, $M$, and $T$. The spatial dimension $N$ is bounded by $1 \le N \le 200000$. The number of available vectors $M$ is exactly $N - 1$. The number of priority dimensions $T$ satisfies $1 \le T \le N$.

The second line provides $T$ distinct integers representing the priority dimensions.

The subsequent $M$ lines each contain three integers $u$, $v$, and $w$. These values describe an available vector $e_u - e_v$ (where $1 \le u, v \le N$ and $u \neq v$) that incurs a cost of $w$ ($1 \le w \le 1000000$). It is algebraically guaranteed that if all $M$ available vectors are selected, their linear span contains $e_x - e_y$ for all $1 \le x, y \le N$.

## Output

Print a single integer indicating the minimum total cost required to ensure that $e_a - e_b$ is in the linear span for all pairs of priority dimensions $a, b$.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the priority dimensions are 1 and 4. We require $e_1 - e_4$ to be in the linear span of the chosen vectors. The only way to form this vector is by selecting all three available vectors: $v_1 = e_1 - e_2$, $v_2 = e_2 - e_3$, and $v_3 = e_3 - e_4$. The linear combination $v_1 + v_2 + v_3 = e_1 - e_4$. Thus, all three vectors (costing 5 + 1 + 2 = 8) must be chosen. 

In Example 2, there is only one priority dimension, so no difference vectors need to be spanned. The minimum cost is 0.
</STATEMENT>
<RATIONALE>
The problem was completely translated from an equality constraint / graph connectivity domain into a linear algebra domain. Because the incidence matrix of a tree forms a basis for the zero-sum subspace, spanning a difference vector is mathematically isomorphic to finding a path in a tree. Models relying on surface pattern matching will likely attempt to use matrix operations, Gaussian elimination, or generic basis-finding algorithms, which will TLE or MLE given $N=200,000$.
</RATIONALE>
<PRESERVED_ANSWER>
The subset of vectors $e_u - e_v$ required to span $e_a - e_b$ uniquely corresponds to the edges on the path between node $a$ and node $b$ in a tree, so the minimal cost subset is exactly the minimal Steiner tree on the same input graph.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the problem of finding the minimal subtree connecting a set of target nodes in a given tree, which can be solved in $O(N)$ time using tree traversals.
</PRESERVED_CLASS>
