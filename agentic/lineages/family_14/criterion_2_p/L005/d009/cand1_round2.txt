<STATEMENT>
# Quadratic Bound Minimization

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a quadratic inequality over vectors $x \in \mathbb{R}^n$. The vector components are indexed from $1$ to $n$. You are given a target set of $t$ indices, called the *focus indices*. 

You are provided with a catalog of $m$ available transition pairs. Each pair is defined by two indices $(u, v)$ and has an associated activation cost $w$. 

Your goal is to select a subset $S$ of these $m$ available pairs such that there exists a strictly positive real constant $C > 0$ for which the following inequality holds for all vectors $x \in \mathbb{R}^n$:

$$ \max_{a, b \in T} (x_a - x_b)^2 \le C \sum_{(u,v) \in S} (x_u - x_v)^2 $$

where $T$ is the set of focus indices. (If $t \le 1$, the left-hand side evaluates to $0$, so the inequality holds for any subset $S$ and any $C > 0$ without activating any pairs, incurring a cost of $0$.)

You must find the minimum possible total cost (the sum of the activation costs of the chosen pairs in $S$) to satisfy this requirement.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **n** ≤ 200000, **m** = **n** - 1, 1 ≤ **t** ≤ **n**).

The second line provides **t** distinct integers representing the focus indices.

The subsequent **m** lines each contain three integers **u**, **v**, and **w**. These values describe an available transition pair between indices **u** and **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**) with an activation cost of **w** (1 ≤ **w** ≤ 1000000). 

It is guaranteed that the available pairs are structured such that between any two distinct indices in $\{1, \dots, n\}$, there is exactly one sequence of available pairs that connects them without repeating any pairs.

## Output

Print a single integer indicating the minimum total cost required to select a subset $S$ that satisfies the inequality for the focus indices.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the focus indices are 1 and 4. The only way to ensure the inequality holds for all $x \in \mathbb{R}^n$ is if the selected subset $S$ links 1 and 4. This requires selecting the pairs (1, 2), (2, 3), and (3, 4). Thus, all three pairs (costing 5 + 1 + 2 = 8) must be chosen. 

In Example 2, there is only one focus index. The maximum difference on the left-hand side is over a single element, which is 0. The inequality holds for any $x$ without selecting any pairs, so the minimum cost is 0.
