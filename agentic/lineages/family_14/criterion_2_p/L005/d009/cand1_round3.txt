<STATEMENT>
# Site Cabling Minimization

Time limit: 2 s   Memory limit: 256 MB

## Description

You are managing a network of **n** sites, labeled $1$ to **n**. You are given a target set of **t** sites, called the *required sites*. Your objective is to ensure that all required sites are connected to each other in a single continuous communication network. (If **t** $\le 1$, the minimum cost is $0$ because a single required site is already connected to itself without deploying any cables.)

You are provided with a catalog of **m** available cabling options. Each option is defined by a pair of sites (**u**, **v**) and, when deployed, establishes a direct communication link between site **u** and site **v**. Deploying this cable incurs a cost of **w**. 

Because there are exactly **m** = **n** - 1 options and they are guaranteed to connect all **n** sites, there is exactly one unique route between any two sites if all available cables are deployed.

Your goal is to choose a subset of these **m** available cabling options such that, using only the deployed cables, there is a valid path between any two required sites (possibly routed via non-required relay sites). 

You must find the minimum possible total cost (the sum of the costs of the deployed cables) to achieve this.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **n** ≤ 200000, **m** = **n** - 1, 1 ≤ **t** ≤ **n**).

The second line provides **t** distinct integers representing the required sites.

The subsequent **m** lines each contain three integers **u**, **v**, and **w**. These values describe an available cabling option establishing a link between site **u** and site **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**) that incurs a cost of **w** (1 ≤ **w** ≤ 1000000). It is guaranteed that if all **m** available cables are deployed, all **n** sites will be connected.

## Output

Print a single integer indicating the minimum total cost required to ensure that all required sites are connected.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the required sites are 1 and 4. We must ensure they are connected. Because of the unique routes, the only way to establish a path between site 1 and site 4 is by deploying the cables between (1, 2), (2, 3), and (3, 4). Thus, all three cables (costing 5 + 1 + 2 = 8) must be chosen. 

In Example 2, there is only one required site. Since a site is already connected to itself, no cables need to be deployed, resulting in a minimum cost of 0.
