# Isotope Substructure Isolation

Time limit: 2 s   Memory limit: 256 MB

## Description

A complex macromolecule consists of **n** atoms, indexed from 1 to **n**. Among these, a specific list of **t** atoms are identified as target isotopes.

The molecule is held together by **m** chemical bonds. Each bond directly connects a pair of atoms and has a specific binding energy. The structure of the molecule is such that **m** = **n** - 1, and all **n** atoms are connected by these bonds. Consequently, between any two atoms, there is exactly one simple path (a sequence of bonds without repetition).

In a controlled dissociation process, you will choose a subset of these bonds to preserve, allowing the rest to dissolve. The chosen subset of bonds must ensure that all **t** target isotopes lie within the same connected component (meaning any target isotope can reach any other target isotope by traversing exclusively the preserved bonds). Each bond may be either preserved or dissolved; the order in which they are chosen is irrelevant.

Your task is to determine the minimum possible sum of binding energies of the preserved bonds required to achieve this.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ **n** ≤ 200000, **m** = **n** - 1, 1 ≤ **t** ≤ **n**).

The second line contains **t** distinct integers: the indices of the target isotopes.

The following **m** lines each contain three integers **u**, **v**, and **w**. These specify a bond between atom **u** and atom **v** (1 ≤ **u**, **v** ≤ **n** and **u** ≠ **v**) having a binding energy of **w** (1 ≤ **w** ≤ 1000000).

## Output

Print a single integer representing the minimum total binding energy of the preserved bonds.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the target isotopes 1 and 4 are linked only via atoms 2 and 3. Therefore, all three bonds (energies 5 + 1 + 2 = 8) must be preserved. In Example 2, there is only one target isotope, so no bonds need to be preserved.
