<METHOD_DESCRIPTION>
Replaces the explicit topological guarantee ("exactly one unique sequence of conduits", i.e., a tree) with its algebraic equivalent: "the oriented incidence matrix has linearly independent columns". This mathematically guarantees the graph is a forest, and with m = n - 1, a tree, preserving the P complexity class. Models relying on text pattern matching will likely fail to connect this algebraic property to tree-based algorithms (like leaf pruning) and may attempt inefficient general graph algorithms or get confused by the linear algebra framing.
</METHOD_DESCRIPTION>

<STATEMENT>
# Algebraic Dependency Subsystem

Time limit: 2 s   Memory limit: 256 MB

## Description

A computational framework consists of **n** variables, indexed starting from 1. A specific subset of **t** variables are designated as "primary" variables that must be jointly evaluated.

The framework includes a set of **m** potential pairwise dependencies. Each dependency links two distinct variables and requires a specific number of floating-point operations (FLOPs) to evaluate. 

Your task is to select a subset of these dependencies such that all primary variables are algebraically unified. We say a set of variables is unified by a subset of dependencies if, in the subgraph formed by these chosen dependencies, all primary variables belong to the same connected component (i.e., any primary variable can reach any other primary variable through a sequence of chosen dependencies). You must find the minimum total FLOPs required for the selected dependencies.

The dependencies satisfy a strict mathematical property: if you arbitrarily assign a direction to each potential dependency and construct the **n** × **m** oriented incidence matrix (where each column corresponds to a dependency, having exactly one +1 and one -1 in the rows corresponding to the linked variables, and all other entries are 0), the columns of this matrix are linearly independent over the real numbers. 

The framework's scale is defined by the following specifications:
- The system memory allocates space for variables up to a strict capacity limit of exactly two hundred thousand. There is always at least one variable.
- The number of potential dependencies **m** is exactly one less than the number of variables.
- The number of primary variables **t** is at least one, and could include all **n** variables.
- The evaluation cost for any single dependency is a positive integer that will not exceed exactly one million FLOPs.

## Input

The first line contains three integers **n**, **m**, and **t**.

The second line contains **t** distinct integers representing the indices of the primary variables.

The following **m** lines each contain three integers **u**, **v**, and **w**. These specify a potential dependency between variable **u** and variable **v** (**u** ≠ **v**) requiring **w** FLOPs.

## Output

Print a single integer representing the minimum total FLOPs required to unify all primary variables.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the primary variables 1 and 4 are unified only by including 2 and 3, so all three dependencies (5+1+2 = 8) must be selected. In Example 2, there is one primary variable, so no dependencies are needed.

<RATIONALE>
I removed the explicit mention of a "unique sequence of conduits" (which directly implies a tree) and replaced it with the condition that the oriented incidence matrix has linearly independent columns. This forces the model to mathematically deduce that the graph is a forest (and thus a tree, since m = n - 1) rather than relying on surface-level topological keywords.
</RATIONALE>
<PRESERVED_ANSWER>
The graph topology, the required nodes, and the edge weights are exactly identical to the seed, so the minimum cost to connect the primary variables remains exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
An oriented incidence matrix with linearly independent columns mathematically defines a forest; with m = n - 1, the input is guaranteed to be a tree, keeping the minimum connected subgraph problem solvable in O(N) time.
</PRESERVED_CLASS>
<RISK>
Models might not immediately recognize the definition of an oriented incidence matrix, though it is standard mathematical terminology and explicitly defined in the text to prevent true ambiguity.
</RISK>
