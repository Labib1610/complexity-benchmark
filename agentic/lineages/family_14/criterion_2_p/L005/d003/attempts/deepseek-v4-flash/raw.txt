 We can solve this by finding the minimal subtree that connects all priority nodes.  
Since the graph is a tree, the minimal connected subgraph containing all priority nodes is the union of all paths between them.  
We can compute this by:

1. Marking all priority nodes.
2. Doing a DFS/BFS from any priority node to find the farthest priority node (diameter-like approach), but here we need the total cost of the minimal subtree.
3. A simpler method:  
   - Root the tree at any node.  
   - For each edge, if removing it separates the tree into two parts and both parts contain at least one priority node, then that edge must be included.  
   - Sum the weights of all such edges.

We can do this with a DFS that returns the number of priority nodes in the subtree.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    priorities = set(map(int, input().split()))
    
    adj = [[] for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
        edges.append((u, v, w))
    
    # If only one priority node, no edges needed
    if t == 1:
        print(0)
        return
    
    visited = [False] * (n + 1)
    
    def dfs(u):
        visited[u] = True
        count = 1 if u in priorities else 0
        total_cost = 0
        for v, w in adj[u]:
            if not visited[v]:
                sub_count, sub_cost = dfs(v)
                if sub_count > 0 and (t - sub_count) > 0:
                    total_cost += w + sub_cost
                else:
                    total_cost += sub_cost
                count += sub_count
        return count, total_cost
    
    # Start DFS from any node (1)
    _, result = dfs(1)
    print(result)

if __name__ == "__main__":
    solve()
```
