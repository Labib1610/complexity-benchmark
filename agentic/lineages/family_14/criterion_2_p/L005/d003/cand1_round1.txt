<STATEMENT>
# Priority Grid Integration

Time limit: 2 s
Memory limit: 256 MB

## Description

A regional grid comprises **n** substations, numbered starting from 1. Certain pairs of substations can be connected by activating a transmission line, which requires a specific amount of resources. A subset of **t** substations are designated as **priority**. Your task is to determine the minimum total resources required to activate a set of transmission lines such that every priority substation is integrated into a single communicating network, possibly routing through non-priority substations.

The proposed transmission lines are designed with zero redundancy: if all proposals were built, every substation would be connected to the grid, but omitting even one proposed line would divide the network into disconnected segments.

## Input

The first line provides three integers **n**, **m**, and **t**. The total number of substations **n** is a positive integer limited by the grid's maximum capacity of two hundred thousand. The number of priority substations **t** ranges from a single substation up to the total number of substations **n**. The value **m** represents the number of proposed transmission lines; because of the zero-redundancy design, this is always exactly one less than the number of substations.

The second line contains **t** distinct integers representing the identifiers of the priority substations.

Each of the subsequent **m** lines contains three integers **u**, **v**, and **w**. These indicate a proposed transmission line between distinct substations **u** and **v**. The resource requirement **w** is a positive integer that will not exceed the hardware limit of one million.

## Output

Print a single integer representing the minimum total resources required to ensure all priority substations are linked.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In the first example, the priority substations 1 and 4 can only be joined by routing through 2 and 3, so all three transmission lines (5 + 1 + 2 = 8) must be activated. In the second example, there is only one priority substation, so no transmission lines need to be activated.

<RATIONALE>
Replaced the explicit statement that there are exactly n-1 candidate conduits providing full connectivity with a physical description of a zero-redundancy design where omitting any line disconnects the grid. Replaced bare numeric inequalities with scenario-based capacities and limits (Strategy S07). This forces the model to deduce the acyclic tree structure from the connectivity properties rather than pattern-matching the n-1 edge count directly.
</RATIONALE>
<PRESERVED_ANSWER>
The underlying graph is still exactly the same tree connecting the same priority vertices, so the minimal connected subgraph has the same unique set of edges and identical total cost.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The graph structure remains a tree, meaning the problem of finding the minimal connected subgraph spanning a subset of vertices is solvable in linear time using graph traversals.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the "omitting even one proposed line would divide the network" as a dynamic network-reliability problem rather than a static description of the graph's topology, though the framing as a "design" mitigates this.
</RISK>
