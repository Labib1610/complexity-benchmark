<STATEMENT>
# Target Variable Synchronization

Time limit: 2 s   Memory limit: 256 MB

## Description

A mathematical model consists of **n** variables (numbered 1..n). Certain pairs of variables can be constrained to maintain the exact same value, which incurs a specific enforcement cost. A subset of **t** variables are marked as **target**. Your objective is to select a set of constraints to enforce so that every target variable is guaranteed to be equal to every other target variable, possibly relying on the transitive property through intermediate variables.

The given candidate constraints provide a fully integrated system: if all candidate constraints were enforced, it would be possible to prove that any two variables in the model are equal, and there are exactly **n − 1** candidate constraints in total.

Determine the minimum total cost of the constraints you must enforce to ensure all target variables are equal to each other.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line provides **t** distinct integers: the identifiers of the target variables.
The following **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), representing a candidate constraint between variable u and variable v with an enforcement cost of w. The candidate constraints follow the integrated system described above.

## Output

Print a single integer representing the minimum total enforcement cost required to make all target variables equal.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, target variables 1 and 4 can only be proven equal by chaining through variables 2 and 3, so all three constraints (5+1+2 = 8) must be enforced. In Example 2, there is only one target variable, so no constraints are required, and the minimum cost is 0.

<RATIONALE>
Changed the scenario from a physical network of stations and conduits to an algebraic system of variables and equality constraints. This forces the model to recognize the graph structure underlying the transitive relations rather than relying on standard "network connectivity" triggers. Removed the word "trivially" from the note to comply with H3 constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that n-1 relations can equate all n variables means the constraints form a connected acyclic structure, so there is exactly one minimal subset of constraints equating any subset of variables, keeping the required sum identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is mathematically identical to finding the minimal subtree connecting a set of marked vertices in a given tree, which is solvable in linear time using standard graph traversal.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "relying on the transitive property" as allowing them to generate new cost-free links between variables, but the instruction to "select a set of constraints to enforce" explicitly limits them to the given inputs.
</RISK>
