<METHOD_NAME>Logical Connectivity Translation</METHOD_NAME>
<METHOD_DESCRIPTION>The problem is translated from vector space spanning (which models immediately map to graph incidence matrices and connected components) into a logical constraint satisfaction problem over a discrete function. The requirement to "connect" target vertices is disguised as requiring that no valid function can assign different values to the target identifiers. This forces the model to deduce that logical implication of equality is equivalent to path connectivity in the constraint graph.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Function Constraint Minimization

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a discrete function $F$ that maps $n$ distinct identifiers (labeled $1$ to $n$) to integer values. 
You are given a specific subset of $t$ identifiers called the *target identifiers*. You must guarantee that $F(a) = F(b)$ for every pair of target identifiers $a$ and $b$.

To enforce this, you can purchase constraints from a catalog of $m$ available options. 
Each available option is a bidirectional constraint specifying $F(u) = F(v)$ for a specific pair of identifiers $u$ and $v$. Purchasing this constraint incurs a cost of $w$. 

A function $F$ is considered "valid" if it satisfies all the constraints you have chosen to purchase. Your objective is to purchase a subset of constraints such that *every* valid function $F$ assigns the exact same value to all $t$ target identifiers. (If $t \le 1$, this condition is trivially satisfied for any subset of purchased constraints, including the empty set).

The catalog of $m$ available constraints has the following structural guarantees:
- If you were to purchase all $m$ options, the constraints would link all $n$ identifiers together, meaning the only valid functions would be those where $F(x)$ is identical for all $1 \le x \le n$.
- $m = n - 1$.
- Because of these two properties, the available constraints form a structure where there is exactly one sequence of available constraints linking any two identifiers.

You must find the minimum possible total cost (the sum of the costs of your purchased constraints) to achieve your objective.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **n** ≤ 200000, **m** = **n** - 1, 1 ≤ **t** ≤ **n**).

The second line provides **t** distinct integers representing the target identifiers.

The subsequent **m** lines each contain three integers **u**, **v**, and **w**. These values describe an available constraint $F(u) = F(v)$ (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**) that incurs a cost of **w** (1 ≤ **w** ≤ 1000000). The full list of constraints forms the structural guarantees described above.

## Output

Print a single integer indicating the minimum total cost of a purchased subset of constraints that guarantees $F(a) = F(b)$ for all target identifiers $a$ and $b$.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the target identifiers are 1 and 4. We must ensure $F(1) = F(4)$ for any valid function $F$. The only sequence of constraints linking 1 and 4 uses $F(1) = F(2)$, $F(2) = F(3)$, and $F(3) = F(4)$. If we purchase all three, any valid function must satisfy $F(1) = F(2) = F(3) = F(4)$, guaranteeing $F(1) = F(4)$. Thus, all three constraints (costing 5 + 1 + 2 = 8) must be purchased. If we omitted $F(2) = F(3)$, a function $F$ could have $F(1)=F(2)=10$ and $F(3)=F(4)=20$, which would be valid but would result in $F(1) \neq F(4)$.

In Example 2, there is only one target identifier, so no constraints need to be purchased to guarantee all target identifiers have the same value. The minimum cost is 0.
</STATEMENT>
<RATIONALE>
The problem was translated from vector space linear spanning to logical constraint satisfaction on a discrete function. This removes all linear algebra terminology that models previously mapped directly to graph incidence matrices. The models must now deduce that logically forcing equality across all valid assignments is mathematically identical to selecting a connected subtree of constraints, forcing them to reason about the underlying structure rather than relying on keyword association.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that all target identifiers evaluate to the same value in every valid function is satisfied if and only if the target identifiers are in the same connected component of purchased constraints, which is exactly the same mathematical requirement (and thus yields the same minimum cost) as the original vector subspace spanning problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The structural guarantees explicitly define a tree (connected, n-1 edges, unique paths), meaning the objective is still to find the minimum weight subtree connecting a set of target vertices (which is unique and solvable in O(n) time).
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "every valid function" as requiring a universally quantified algebraic proof rather than recognizing it as a definition of connected components, though the Note for Example 1 explicitly demonstrates that a broken sequence allows a counterexample function.
</RISK>
