We are given a graph with \( n \) nodes and \( m = n-1 \) edges, each edge \((u, v)\) with weight \( w \) representing the vector \( e_u - e_v \).  
The focus indices are a set \( S \). We need the span of chosen edges to contain \( e_a - e_b \) for all \( a, b \in S \).

Since the edges form a tree (because \( m = n-1 \) and the span condition guarantees connectivity), the vector \( e_a - e_b \) is in the span of the tree edges if and only if the chosen edges connect all focus nodes into one connected component in the tree.

Thus the problem reduces to:  
Given a tree with \( n \) nodes, select a minimum-cost set of edges such that all focus nodes are in the same connected component.

This is the **Steiner tree** problem on a tree, which can be solved by considering the minimal subtree that connects all focus nodes.  
The minimal cost is the sum of all edges in the minimal subtree connecting the focus nodes.

We can find this by:
1. Mark focus nodes.
2. Remove all leaves that are not focus nodes iteratively.
3. Sum the weights of the remaining edges.

Since \( n \) can be up to 200,000, we do this in \( O(n) \).

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m, t = map(int, input().split())
focus = set(map(int, input().split()))

adj = [[] for _ in range(n + 1)]
deg = [0] * (n + 1)
edge_weight = {}

for _ in range(m):
    u, v, w = map(int, input().split())
    adj[u].append((v, w))
    adj[v].append((u, w))
    deg[u] += 1
    deg[v] += 1
    edge_weight[(u, v)] = w
    edge_weight[(v, u)] = w

# If only one focus node, cost is 0
if t == 1:
    print(0)
    sys.exit()

# Remove non-focus leaves
q = deque()
in_tree = [True] * (n + 1)
for i in range(1, n + 1):
    if deg[i] == 1 and i not in focus:
        q.append(i)

while q:
    u = q.popleft()
    in_tree[u] = False
    for v, w in adj[u]:
        if in_tree[v]:
            deg[v] -= 1
            if deg[v] == 1 and v not in focus:
                q.append(v)

# Sum weights of edges where both endpoints are in_tree
total = 0
for (u, v), w in edge_weight.items():
    if u < v and in_tree[u] and in_tree[v]:
        total += w

print(total)
```
