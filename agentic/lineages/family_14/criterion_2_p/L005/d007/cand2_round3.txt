<METHOD_NAME>Algebraic Isomorphism Mapping</METHOD_NAME>
<METHOD_DESCRIPTION>Translates the graph connectivity problem into an equivalent system of linear equations where connected components correspond to uniquely determined relative differences, preventing models from relying on graph-specific heuristics or tree-traversal templates.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<STATEMENT>
# Algebraic System Extraction

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of **n** unknown scalar variables, $x_1, x_2, \dots, x_n$. While their absolute values are unobservable, you can evaluate the exact numerical difference between certain pairs of these variables by selecting specific relational constraints. 

A subset of **t** variables are designated as target variables. Your objective is to select a subset of constraints such that the numerical difference between every possible pair of target variables is logically deduced and uniquely determined by your selection. 

You have a pool of **m** candidate constraints available. Each constraint evaluates the difference between a specific pair of variables $x_u$ and $x_v$, and incurs a selection cost of **w**. 

You are guaranteed that the full pool of **m** constraints is sufficient to uniquely determine the relative differences between all **n** variables. 

Find the absolute minimum total selection cost of a subset of constraints that fulfills the requirement for the target variables.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **n** ≤ 200000, **m** = **n** - 1, 1 ≤ **t** ≤ **n**).

The second line provides **t** distinct integers representing the indices of the target variables.

The subsequent **m** lines each contain three integers **u**, **v**, and **w**. These values describe a candidate constraint that evaluates the difference between variable **u** and variable **v** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**) with a selection cost of **w** (1 ≤ **w** ≤ 1000000). It is guaranteed that if all **m** candidate constraints were selected, the relative differences between all **n** variables would be fully determined.

## Output

Print a single integer indicating the minimum total selection cost required to ensure the relative differences between all pairs of target variables are uniquely determined.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the difference between target variables 1 and 4 can only be deduced by algebraically combining the constraints for (1,2), (2,3), and (3,4). Thus, all three constraints (costing 5+1+2 = 8) must be selected. 

In Example 2, there is only one target variable, so no relative differences need to be determined, requiring a selection cost of 0.
</STATEMENT>
<RATIONALE>
The problem is mathematically isomorphic to finding the minimal Steiner tree on a tree, but it is now framed entirely in terms of linear algebra and systems of equations. By removing all graph terminology and framing the connectivity requirement as "algebraically deduced differences", models that rely on recognizing graph keywords to trigger tree-traversal templates will be forced to reason from first principles to discover the underlying tree structure.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the difference between two variables is uniquely determined is mathematically identical to the condition that the two variables are in the same connected component of the selected constraints; thus, the minimum cost subset is the exact same minimal spanning subtree.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The input still defines a tree ($m = n - 1$ and full determinability implies connectivity), so the unique minimal subtree can still be found in $O(n)$ time using the same algorithms.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "logically deduced and uniquely determined" if they lack the mathematical background to map linear combinations of pairwise differences to graph connectivity, though this is a standard concept in linear algebra.
</RISK>
