Framed the task as finding a minimum-cost connected subgraph for a subset of vertices (the Steiner Tree problem), completely removing explicit mentions of "unique simple paths". Models relying on surface pattern matching will likely attempt a general Steiner Tree algorithm (which is exponential time) and fail due to Time Limit Exceeded. Models that genuinely reason about algorithmic structure will deduce that because m = n - 1 and the graph is connected, the input is a tree, meaning the minimal connected subgraph is unique and computable in linear time.
</METHOD_DESCRIPTION>

<STATEMENT>
# Secure Comm-Link Blueprint

Time limit: 2 s   Memory limit: 256 MB

## Description

A planetary settlement has $n$ outposts. You are given a list of $t$ priority outposts that must be able to communicate with each other.

You have a manifest of $m$ potential bidirectional communication links that can be constructed. Each link connects a specific pair of outposts $u$ and $v$, and requires a construction budget of $w$. 
The manifest guarantees that if all $m$ links were built, every outpost would be able to communicate with every other outpost.

Your task is to select a subset of these $m$ links to build such that all $t$ priority outposts are interconnected (i.e., information can flow between any two priority outposts, possibly passing through other non-priority outposts along the built links). You must find the minimum possible total budget required to achieve this.

## Input

The first line contains three integers $n$, $m$, and $t$. The settlement can have up to two hundred thousand outposts, but will always have at least one. The number of available links $m$ is exactly one less than the number of outposts. The priority list contains at least one outpost, and could include the entire settlement.

The second line contains $t$ distinct integers, the identifiers of the priority outposts. Outposts are identified by integers from $1$ to $n$.

The following $m$ lines each contain three integers $u$, $v$, and $w$, describing a potential link between outpost $u$ and outpost $v$ ($u \neq v$) with a construction budget of $w$. The budget $w$ for any single link is at least one credit and is capped at one million credits. 

## Output

Print a single integer: the minimum total budget of a subset of links that ensures all priority outposts are interconnected.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the priority outposts are 1 and 4. To connect them, we must build the links (1, 2), (2, 3), and (3, 4). The total budget is 5 + 1 + 2 = 8.

In Example 2, there is only one priority outpost, so it is already interconnected with itself. No links need to be built, resulting in a budget of 0.
</STATEMENT>
<RATIONALE>
I removed the explicit instruction to retain the unique simple path between every pair of essential sites. Instead, I framed the problem as finding the minimum cost to interconnect a subset of sites. This forces the model to independently deduce that because $m = n - 1$ and the graph is connected, the input is a tree, and the minimal connected subgraph is exactly the union of the unique paths.
</RATIONALE>
<PRESERVED_ANSWER>
In a connected graph with $n$ vertices and $n-1$ edges, the unique minimal connected subgraph containing a specific subset of vertices is exactly the union of the simple paths between them, ensuring the minimum cost is identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The input graph is still a tree, meaning the minimal connecting subgraph can still be found in $O(n)$ time using standard tree traversal and subtree counting.
</PRESERVED_CLASS>
<RISK>
Models might interpret "interconnected" as requiring a direct link between every pair of priority outposts, but the parenthetical "(i.e., information can flow between any two priority outposts, possibly passing through other non-priority outposts along the built links)" resolves this ambiguity.
</RISK>
