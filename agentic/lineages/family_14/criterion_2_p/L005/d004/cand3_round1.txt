<STATEMENT>
# Algebraic Entailment

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of **n** unknown variables, indexed from 1 to **n**. 

You are provided with a list of **m** potential algebraic constraints. Each constraint specifies that two particular variables are strictly equal, and comes with a computational cost **w** to include in your axiom set. 

The proposed constraints are structured such that if you were to include all of them, the equality of any two variables in the entire system could be logically deduced through exactly one non-redundant chain of transitive substitutions.

You are given a list of **t** target variables. Your task is to select a subset of the potential constraints to include in your axiom set such that it logically guarantees all **t** target variables are equal to each other. 

Determine the minimum total computational cost required to form such an axiom set.

## Input

The first line contains three integers **n**, **m**, and **t**. The total number of variables **n** is at least 1 and at most 200000. The number of potential constraints **m** is exactly **n** - 1. The number of target variables **t** is at least 1 and at most **n**.

The second line contains **t** distinct integers: the indices of the target variables.

The following **m** lines each contain three integers **u**, **v**, and **w**. These specify a potential constraint establishing the equality of variable **u** and variable **v** (with **u** and **v** being distinct integers from 1 to **n**) having a computational cost of **w** (an integer from 1 to 1000000).

## Output

Print a single integer representing the minimum total computational cost of a subset of constraints that logically entails the mutual equality of all target variables.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, to logically guarantee that variable 1 and variable 4 are equal, the deduction must bridge through variables 2 and 3. Therefore, all three equality constraints (costing 5, 1, and 2) must be included in the axiom set, resulting in a total cost of 8. 

In Example 2, there is only one target variable, so its equality to itself is trivially true. No constraints need to be included, making the cost 0.
</STATEMENT>
<RATIONALE>
The problem was completely reframed from a physical infrastructure network into an abstract algebraic logic system. By replacing "substations", "communication lines", and "relaying" with "variables", "equality constraints", and "transitive substitutions", models can no longer rely on standard network-graph pattern matching. They must now genuinely deduce that logical entailment of equality across a subset of variables requires selecting a subset of constraints that forms a connected component, which on a tree structure is exactly the minimal spanning subtree.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical condition for a set of equality constraints to entail the mutual equality of a target set is that those variables must belong to the same connected component in the constraint graph; since the available constraints form a tree, the minimal valid subset is exactly the minimal subtree spanning the targets, making the minimum cost identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains finding the minimal Steiner tree on a graph that is already a tree, which is solvable in O(n) time via leaf-pruning or post-order traversal, keeping it in P.
</PRESERVED_CLASS>
