# Facility Thermal Stabilization

Time limit: 2 s   Memory limit: 256 MB

## Description

A deep-sea research facility consists of **n** modules, indexed from 1 to **n**. You are provided with a list of **t** modules that contain delicate biological samples. There are also **m** structural joints, each connecting a pair of modules. Activating a joint allows climate control to be shared between the two modules it connects, but requires a specific thermal stabilization cost.

The structural joints are arranged such that there is exactly one unique sequence of joints connecting any two modules in the facility.

Your task is to determine the minimum total thermal stabilization cost required to activate a subset of joints such that all modules containing biological samples are connected to each other, either directly or via a chain of activated joints passing through other modules.

## Input

The first line contains three integers **n**, **m**, and **t**. The total number of modules **n** is between 1 and 200000, inclusive. The number of structural joints **m** is exactly **n** - 1. The number of modules containing biological samples **t** is between 1 and **n**, inclusive.

The second line contains **t** distinct integers: the indices of the modules containing biological samples.

The following **m** lines each contain three integers **u**, **v**, and **w**. These specify a structural joint between module **u** and module **v** (where **u** and **v** are distinct integers from 1 to **n**) having a thermal stabilization cost of **w** (where **w** is an integer from 1 to 1000000).

## Output

Print a single integer representing the minimum total thermal stabilization cost required to connect all modules containing biological samples.

```

8

```

**Output**
```

```

## Note

In Example 1, the modules containing biological samples 1 and 4 are joined only through modules 2 and 3, so all three structural joints (costs 5, 1, and 2, which sum to 8) must be activated. In Example 2, there is only one module containing a biological sample, so no structural joints need to be activated.
