# Mandatory Hub Integration

Time limit: 2 s   Memory limit: 256 MB

## Description

A logistics plan involves **n** distribution hubs, labeled with integers from 1 to **n**. Within this network, a specific group of **t** hubs are designated as mandatory hubs. 

There are exactly **m** potential transit links proposed for the network. Each transit link joins a pair of distinct hubs and requires a specified activation budget. The proposed links connect all **n** hubs, and the topology guarantees that between any two hubs there is exactly one unique sequence of transit links.

Your objective is to choose a subset of these transit links to activate such that all mandatory hubs are connected to each other (either directly or by passing through other hubs, which may include non-mandatory ones). Find the minimum total activation budget required to establish this connectivity among all mandatory hubs.

## Input

The first line contains three integers **n**, **m**, and **t**. The total number of hubs **n** is at least 1 and at most 200000. The number of potential transit links **m** is exactly **n** - 1. The number of mandatory hubs **t** is at least 1 and at most **n**.

The second line contains **t** distinct integers: the labels of the mandatory hubs.

The following **m** lines each contain three integers **u**, **v**, and **w**. These specify a potential transit link between hub **u** and hub **v** (where **u** and **v** are distinct integers from 1 to **n**) having an activation budget of **w** (an integer from 1 to 1000000).

## Output

Print a single integer representing the minimum total activation budget required to link all mandatory hubs.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1 the mandatory hubs 1 and 4 are joined only through hubs 2 and 3, so all three transit links (5+1+2 = 8) are needed. In Example 2 there is one mandatory hub, so no transit links are needed.
