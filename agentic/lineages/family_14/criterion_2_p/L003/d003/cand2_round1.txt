<STATEMENT>
# Fluid Routing Optimization

Time limit: 2 s   Memory limit: 256 MB

## Description

You are configuring the pipeline layout for a chemical processing plant. The plant contains **n** vats, identified by integers from 1 to **n**. You have a schematic detailing **m** potential bidirectional pipe segments. Installing a pipe segment between two vats incurs a specific material cost.

A specific set of **t** vats are designated as priority reaction chambers. Your goal is to select a subset of the proposed pipe segments to install so that fluid can flow between any two priority reaction chambers. Fluid can route through any installed pipes, passing through non-priority vats as needed.

Find the minimum total material cost of the installed pipes required to ensure all priority reaction chambers are mutually linked.

## Input

The first line contains three integers **n**, **m**, and **t**. The plant's main facility can house up to two hundred thousand vats **n**, with a minimum operational requirement of one vat. The blueprint always specifies a pipe segment count **m** that is exactly one fewer than the total vat count. The priority subset count **t** includes anywhere from a single vat up to the entire facility.

The second line contains **t** distinct integers, each between 1 and **n** inclusive: the identifiers of the priority reaction chambers.

Each of the next **m** lines contains three integers **u**, **v**, and **w**. These represent a potential bidirectional pipe segment between vat **u** and vat **v** (where **u** and **v** are distinct integers ranging from 1 to **n** inclusive). The installation cost **w** for any individual pipe segment ranges from a base rate of one up to a maximum of one million credits.

The schematic guarantees that installing all **m** pipe segments would merge all **n** vats into a single contiguous fluid system.

## Output

Print a single integer representing the minimum total cost to install a subset of pipes such that all priority reaction chambers can share fluid with each other.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the priority reaction chambers 1 and 4 can only share fluid if it routes through vats 2 and 3. Thus, all three available pipe segments (costs 5, 1, and 2) must be installed, resulting in a total cost of 8.
In Example 2, there is only a single priority reaction chamber, meaning no pipe segments are required and the total cost is 0.
