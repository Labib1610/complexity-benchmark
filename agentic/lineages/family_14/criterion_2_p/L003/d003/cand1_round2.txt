<STATEMENT>
# Subnet Activation Protocol

Time limit: 2 s   Memory limit: 256 MB

## Description

You are provisioning a communication network for a computing cluster. The cluster consists of **n** processing nodes, numbered 1 through **n**. You are given a blueprint of **m** available bidirectional communication links. Enabling a link between its two endpoints incurs a known activation fee.

A specific group of **t** nodes are flagged as priority targets. Your task is to select a subset of the available links to enable so that all priority targets can exchange data with one another. Data can be routed through any enabled links, and may pass through non-priority nodes if necessary.

The blueprint structurally guarantees that all **n** nodes are connected by exactly **n** − 1 links. Because of this exact configuration, there is exactly one valid sequence of links between any two nodes in the cluster, and no alternative routes or parallel links exist.

Find the minimum total activation fee required to enable a subset of links that mutually connects all priority targets.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ **n** ≤ 200000, **m** = **n** − 1, 1 ≤ **t** ≤ **n**).

The second line contains **t** distinct integers from 1 to **n**: the identifiers of the priority targets.

The next **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000). These represent an available bidirectional link between node **u** and node **v** with an activation fee of **w**.

The provided links strictly follow the structural guarantee described above: exactly one sequence of links connects any two nodes, ensuring no alternative routes or parallel links exist.

## Output

Output a single integer representing the minimum total fee to enable a subset of links such that all priority targets are mutually connected.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the priority targets 1 and 4 can only exchange data if it is routed through nodes 2 and 3. Therefore, all three available links (fees 5, 1, and 2) must be enabled, resulting in a total fee of 8.
In Example 2, there is only one priority target, so no links need to be enabled and the total fee is 0.
