# Problem B — Fluid Integration Fabric

Time limit: 2 s   Memory limit: 256 MB

## Description

You are designing the fluid transport system for a chemical plant. The plant contains **n** mixing vats, each assigned a unique integer identifier from 1 to **n**. You are given a schematic showing **m** possible bidirectional pipe segments. Installing a pipe segment between its two endpoint vats requires a certain installation cost.

Among the vats, a specific subset of **t** vats are designated as priority reaction chambers. Your goal is to select a subset of the available pipe segments to install so that fluid can flow between any two priority chambers. Fluid can be routed through any installed pipe segments, passing through non-priority vats along the way.

Determine the minimum possible total installation cost of the installed pipe segments that guarantees all priority chambers are mutually linked.

## Input

The first line contains three integers **n**, **m**, and **t**. The factory's physical floor space limits the total vat count **n** to a maximum capacity of 200000, and there is always at least 1 vat. The schematic provides exactly **m** = **n** − 1 potential pipe segments. The headcount of priority chambers **t** is at least 1 and at most **n**.

The second line contains **t** distinct integers, each between 1 and **n** inclusive: the identifiers of the priority chambers.

Each of the next **m** lines contains three integers **u**, **v**, and **w**. These represent a potential bidirectional pipe segment between vat **u** and vat **v** (where **u** and **v** are distinct integers ranging from 1 to **n** inclusive). The budget restricts the installation cost **w** of any single segment to a minimum of 1 and a maximum of 1000000.

The schematic guarantees that installing all **m** pipe segments would merge all **n** vats into a single fully contiguous fluid system. Because of the exact number of segments, there would be exactly one sequence of segments between any two vats, and no two segments connect the same pair of vats.

## Output

Print a single integer representing the minimum total cost to install a subset of pipe segments such that all priority chambers can share fluid with each other.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the priority chambers 1 and 4 can only share fluid if it passes through vats 2 and 3. Therefore, all three available pipe segments (costs 5, 1, and 2) must be installed, resulting in a total cost of 8.
In Example 2, there is only one priority chamber, so no pipe segments need to be installed and the total cost is 0.
