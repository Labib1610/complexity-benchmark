# Problem B — Module Integration Fabric

Time limit: 2 s   Memory limit: 256 MB

## Description

You are tasked with designing a routing sub-network for a distributed system. The system contains a positive number of processing modules, numbered sequentially starting from 1. The physical chassis has enough slots to support up to two hundred thousand such modules. You are given a list of potential bidirectional data conduits that could be deployed. Deploying a conduit between a specific pair of modules incurs an installation cost, measured as a positive integer not exceeding one million.

To prevent feedback loops and minimize manufacturing overhead, the supplier provides a very specific number of potential conduits: exactly one fewer than the number of modules. They guarantee that if you were to deploy every provided conduit, it would be possible for any module to communicate with any other module.

There is a non-empty subset of these modules designated as critical processors. Your goal is to select a subset of the potential conduits to deploy so that all critical processors can transmit data to one another. Data can be relayed through non-critical modules if necessary.

Determine the minimum total installation cost required to achieve full connectivity among all critical processors.

## Input

The first line contains three integers: the total number of modules, the number of potential conduits, and the number of critical processors.
The second line contains the distinct ID numbers of the critical processors.
Each of the remaining lines (one for each potential conduit) describes a conduit using three integers: the ID of the first module it connects, the ID of the second module, and its installation cost. The two module IDs for any conduit are always distinct.

## Output

Print a single integer representing the minimum total cost to deploy conduits such that all critical processors can communicate with each other.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the critical processors 1 and 4 can only communicate if the data passes through modules 2 and 3. Therefore, all three available conduits (costs 5, 1, and 2) must be deployed, giving a total cost of 8.
In Example 2, there is only one critical processor, so no conduits need to be deployed and the total cost is 0.
