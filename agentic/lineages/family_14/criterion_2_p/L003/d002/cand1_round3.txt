# Problem B — Sub-Network Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

You are configuring the communication backbone for a distributed computing environment. The environment consists of **n** processing nodes, identified by integers from 1 to **n**. You are provided with a catalog of **m** allowable bidirectional data links. Activating a link between a specific pair of nodes requires a certain configuration expense.

Within this environment, **t** specific nodes are designated as priority endpoints. Your objective is to choose a subset of the allowable data links to activate, ensuring that every priority endpoint can exchange information with every other priority endpoint. Information can be routed through non-priority nodes as needed.

Calculate the minimum total configuration expense required to establish full mutual communication among all priority endpoints.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers representing the identifiers of the priority endpoints.
Each of the following **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000). This indicates an allowable bidirectional data link between node **u** and node **v** with a configuration expense of **w**. It is guaranteed that if all **m** allowable links were activated, there would be exactly one valid sequence of links connecting any two nodes in the environment.

## Output

Output a single integer representing the minimum total configuration expense needed to activate a subset of links such that all priority endpoints are able to communicate with one another.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the priority endpoints 1 and 4 can only communicate if the information is routed through nodes 2 and 3. Therefore, all three allowable links (expenses 5, 1, and 2) must be activated, giving a total expense of 8.
In Example 2, there is only one priority endpoint, so no links need to be activated and the total expense is 0.
