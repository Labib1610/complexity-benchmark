We can solve this by noting that the graph is a tree (since m = n − 1 and it’s connected).  
We need the minimal cost to connect all critical nodes.  

This is equivalent to finding the **Steiner tree** for the critical nodes in a tree, which can be solved by:

1. Removing all non-critical leaf nodes iteratively (pruning).
2. Summing the weights of the remaining edges.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m, t = map(int, input().split())
critical = set(map(int, input().split()))

adj = [[] for _ in range(n + 1)]
degree = [0] * (n + 1)

for _ in range(m):
    u, v, w = map(int, input().split())
    adj[u].append((v, w))
    adj[v].append((u, w))
    degree[u] += 1
    degree[v] += 1

# If only one critical node, cost is 0
if t == 1:
    print(0)
    sys.exit()

# Prune non-critical leaves
q = deque()
in_tree = [True] * (n + 1)

for i in range(1, n + 1):
    if degree[i] == 1 and i not in critical:
        q.append(i)

while q:
    u = q.popleft()
    in_tree[u] = False
    for v, w in adj[u]:
        if in_tree[v]:
            degree[v] -= 1
            if degree[v] == 1 and v not in critical:
                q.append(v)

# Sum weights of edges where both endpoints are still in the tree
total_cost = 0
for u in range(1, n + 1):
    if in_tree[u]:
        for v, w in adj[u]:
            if u < v and in_tree[v]:
                total_cost += w

print(total_cost)
```
