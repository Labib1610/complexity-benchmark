<METHOD_DESCRIPTION>The problem's objective (finding a connected Steiner tree) is reformulated as satisfying a global constraint on all possible binary labelings of the vertices. Specifically, any labeling that assigns different values to elements of T must have at least one selected edge with endpoints of different values. This is mathematically identical to requiring T to be in a single connected component (the cut condition), but forces models to bridge the gap between binary label assignments and graph connectivity, bypassing their standard tree DP templates.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Binary State Separation

Time limit: 2 s
Memory limit: 256 MB

## Description

You are analyzing a system of $n$ elements, indexed 1 to $n$. Within this system, there is a critical subset $T$ containing $t$ elements.

You are given a catalog of $m$ available bidirectional links. Each link associates element $u$ and element $v$, and requires a stabilization cost $w$.

Your goal is to select a subset of links $C$ that satisfies the following strict structural property:
For every possible assignment of binary states (0 or 1) to all $n$ elements, if there exist any two critical elements $i, j \in T$ that are assigned different states, then your chosen subset $C$ must contain at least one link where its two endpoints $u$ and $v$ are assigned different states.

You are provided with a guarantee about the global structure of the full catalog of $m$ links: $m = n - 1$, the $m$ available links collectively connect all $n$ elements, and there is exactly one unique path (sequence of links) between any two elements in the system. 

Determine the minimum possible total stabilization cost (the sum of the costs of the selected links) required to choose a single valid subset $C$ that satisfies the binary state property for the critical subset $T$.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **t** ≤ **n**, 1 ≤ **n** ≤ 200000, **m** = **n** − 1). The elements are indexed from 1 to **n**.
The second line lists **t** distinct integers representing the indices of the critical subset $T$.
Following this are **m** lines, each containing three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000). These values indicate an available link between element **u** and element **v** with a stabilization cost of **w**.

## Output

Output a single integer representing the minimum possible total cost to choose a subset of links that satisfies the required binary state property for $T$.

<RATIONALE>
The explicit tree guarantee requested by the gate is strictly preserved and stated clearly. To defeat the models, the objective of "connecting the critical subset" has been replaced with its algebraic cut-condition equivalent: any binary labeling that separates elements of $T$ must be crossed by at least one selected link. This forces the model to mathematically deduce that the binary state requirement is identical to graph connectivity, breaking the pattern-matching of standard Steiner tree descriptions.
</RATIONALE>
<PRESERVED_ANSWER>
A subset of links satisfies the binary state property for all possible assignments if and only if it connects all elements in $T$ into a single component; since the base graph is a tree, the minimal valid subset is exactly the unique minimal subtree spanning $T$, preserving the minimum cost exactly.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains finding the Steiner tree on a given tree, which is solvable in $O(n)$ time using a post-order traversal (tree DP), keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "For every possible assignment" as requiring a different subset $C$ for each assignment, though the prompt explicitly asks to "choose a single valid subset $C$ that satisfies the property", which resolves this ambiguity.
</RISK>
