<STATEMENT>
# Problem B — Subgroup Orbit Acquisition

Time limit: 2 s
Memory limit: 256 MB

## Description

You are analyzing the action of permutations on the set of integers $\{1, 2, \dots, n\}$.

You are provided with a catalog of $m$ optional permutations. Each available permutation is a transposition $(u, v)$ that swaps elements $u$ and $v$ while leaving all other elements fixed, and it comes with a specific acquisition cost.

Your objective focuses on a designated target set of $t$ elements. You must acquire a subset of the available transpositions such that, in the subgroup generated by your acquired transpositions, the entire target set is contained within a single orbit. You may acquire transpositions involving non-target elements if they are useful for chaining the algebraic relations to merge orbits.

Determine the minimum total cost required to acquire a valid subset of transpositions that satisfies this condition for the target set.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **t** ≤ **n**, 1 ≤ **n** ≤ 200000, **m** = **n** − 1).
The second line lists **t** distinct integers representing the elements in the target set.
Following this are **m** lines, each containing three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000). These values indicate an available transposition $(u, v)$ that can be acquired at a cost of **w**. It is guaranteed that if you were to acquire all **m** transpositions, the generated subgroup would act transitively on the entire set $\{1, \dots, n\}$. Furthermore, the underlying undirected graph formed by treating each transposition $(u, v)$ as an edge between $u$ and $v$ is connected and has exactly one simple path between any two elements.

## Output

Output a single integer representing the minimum possible total cost to acquire a subset of transpositions that places all target elements in the same orbit.

<RATIONALE>
Replaced the system of equations with a group-theoretic framing involving permutations and transpositions. This forces the solver to recognize that elements belonging to a single orbit under a set of transpositions is mathematically equivalent to the elements being in the same connected component in a graph, without relying on recognizable keywords like "equations" or "variables".
</RATIONALE>
<PRESERVED_ANSWER>
The cost to connect the target elements into a single orbit is identical to the cost of forcing equations to be equal, as both correspond to finding the minimum weight subtree spanning the target vertices.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a Steiner tree on a graph that is already a tree, which is solvable in O(n) time by pruning leaves that do not lead to target vertices.
</PRESERVED_CLASS>
<RISK>
The phrase "single orbit" might be misunderstood by models lacking abstract algebra knowledge, though the mapping to connected components is mathematically standard.
</RISK>
