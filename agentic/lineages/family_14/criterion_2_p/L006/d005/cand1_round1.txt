<METHOD_DESCRIPTION>Translates a graph connectivity problem (Steiner tree on a tree) into an equivalent algebraic problem of selecting linear equality constraints. This strips all graph-theoretic keywords (path, connected, tree, span, basis) and forces the model to mathematically deduce that transitivity of equality over n-1 constraints forming a full rank system is isomorphic to connectivity in a tree. Models relying on graph keywords will fail to map this to the required subtree DP.</METHOD_DESCRIPTION>

# Problem B — Equation Acquisition

Time limit: 2 s
Memory limit: 256 MB

## Description

You are working with a system of $n$ unknown real variables, $x_1, x_2, \dots, x_n$.

You are provided with a catalog of $m$ optional equations. Each available equation is of the form $x_u = x_v$ and has a specific acquisition cost.

Your objective focuses on a designated priority set of $t$ indices. You must acquire a subset of the available equations such that, for any valid assignment of real numbers to the variables that satisfies all of your acquired equations, it is mathematically guaranteed that $x_i = x_j$ for every pair of indices $i$ and $j$ in the priority set. You may acquire equations involving non-priority indices if they are useful for chaining logical deductions.

Determine the minimum total cost required to acquire a valid subset of equations that satisfies this condition for the priority set.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **t** ≤ **n**, 1 ≤ **n** ≤ 200000, **m** = **n** − 1).
The second line lists **t** distinct integers representing the indices in the priority set.
Following this are **m** lines, each containing three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000). These values indicate an available equation $x_u = x_v$ that can be acquired at a cost of **w**. It is guaranteed that if you were to acquire all **m** equations, the only satisfying assignments would be those where all **n** variables are equal.

## Output

Output a single integer representing the minimum possible total cost to acquire a subset of equations that guarantees $x_i = x_j$ for all priority indices $i$ and $j$.

## Examples

**Input**

**Output**

8

<RATIONALE>
I replaced the vector space and basis terminology with a system of algebraic equality constraints. This removes all graph and vector span keywords, forcing the model to mathematically deduce that the transitivity of $m=n-1$ equality constraints is structurally identical to a tree, and that implying equality for a subset of variables is equivalent to finding a Steiner tree.
</RATIONALE>
<PRESERVED_ANSWER>
An equation $x_u = x_v$ algebraically enforces the exact same constraint as acquiring the vector $e_u - e_v$ in the null space, meaning the minimum cost subset to guarantee equality for priority variables is identical to the minimum subset spanning their differences.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains finding the minimum weight connected subgraph containing a specific subset of vertices in a tree, which is solvable in $O(n)$ via subtree dynamic programming.
</PRESERVED_CLASS>
<RISK>
A model could mistakenly believe it needs to simulate or search over real-number assignments rather than recognizing the logical implication of transitivity, though the wording is mathematically standard for equivalence classes.
</RISK>
