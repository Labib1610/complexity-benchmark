<STATEMENT>
# Problem B — Basis Vector Acquisition

Time limit: 2 s
Memory limit: 256 MB

## Description

You are working within a vector space of dimension **n**. Let $e_1, e_2, \dots, e_n$ denote the standard basis vectors of this space. 

You are provided with a catalog of **m** available vectors. Each vector in the catalog is of the form $e_u - e_v$ for some indices $u$ and $v$, and acquiring it incurs a specific monetary cost.

The full catalog of **m** vectors forms a minimal basis for the subspace of all vectors whose coordinates sum to zero. This means that if you were to acquire all **m** vectors, you could express any zero-sum vector as a linear combination of your acquired set, and omitting even one vector from the catalog would strictly reduce the dimension of the space you can span.

You are given a designated target group of **t** priority indices. Your objective is to select and fund a subset of vectors from the catalog such that for any two priority indices $a$ and $b$, the target vector $e_a - e_b$ can be expressed as a linear combination of your acquired subset. You may include vectors in your subset that do not directly involve priority indices if they are necessary to form the required linear combinations.

Determine the minimum total cost needed to acquire a valid subset of vectors that satisfies this condition for all priority indices.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **t** ≤ **n**, 1 ≤ **n** ≤ 200000, **m** = **n** − 1).
The second line lists **t** distinct integers representing the priority indices.
Following this are **m** lines, each containing three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000). These values indicate that the vector $e_u - e_v$ is available in the catalog and can be acquired at a cost of **w**. It is guaranteed that the given **m** vectors provide the minimal basis described above.

## Output

Output a single integer representing the minimum possible total cost to acquire a subset of vectors that can span $e_a - e_b$ for all pairs of priority indices $a, b$.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```
*Explanation:* Priority indices are 1 and 4. We must be able to form $e_1 - e_4$. The catalog contains $v_1 = e_1 - e_2$ (cost 5), $v_2 = e_2 - e_3$ (cost 1), and $v_3 = e_3 - e_4$ (cost 2). To express $e_1 - e_4$, we require $v_1 + v_2 + v_3 = (e_1 - e_2) + (e_2 - e_3) + (e_3 - e_4) = e_1 - e_4$. All three vectors must be acquired. The minimum cost is 5 + 1 + 2 = 8.

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```
*Explanation:* The priority group contains only index 3. The condition that $e_a - e_b$ can be formed for any priority pair is vacuously true (for $a=3, b=3$, $e_3 - e_3 = 0$, which is trivially spanned by the empty set). No vectors need to be acquired, so the minimum cost is 0.

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```
*Explanation:* Priority indices are 1, 2, 3. The catalog contains $v_1 = e_1 - e_2$ (cost 4) and $v_2 = e_2 - e_3$ (cost 5). Acquiring both allows forming $e_1 - e_2$ ($v_1$), $e_2 - e_3$ ($v_2$), and $e_1 - e_3$ ($v_1 + v_2$). Total cost is 4 + 5 = 9.
</STATEMENT>
<RATIONALE>
I removed the "sensor offsets" and "minimal basis of comparisons" framing entirely, replacing it with a formally isomorphic linear algebra problem. The model can no longer rely on graph-theory keywords to trigger its tree-pruning templates. Because $N=200,000$, any literal algebraic approach (like Gaussian elimination) will time out, forcing the model to genuinely deduce the graph-theoretic equivalence to achieve the necessary $O(N)$ solution.
</RATIONALE>
<PRESERVED_ANSWER>
The linear independence of the zero-sum basis means any target vector $e_a - e_b$ has exactly one valid linear combination, which maps perfectly to the unique path between $a$ and $b$ in the underlying tree, ensuring the required subset (and thus the minimum cost) is mathematically identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying mathematical task is still finding the minimum weight Steiner tree on a given tree, which remains solvable in $O(N)$ time (Polynomial class).
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "linear combination" as allowing fractional coefficients, though the totally unimodular nature of the basis guarantees the unique coefficients are strictly $\{-1, 0, 1\}$, making this mathematically harmless.
</RISK>
