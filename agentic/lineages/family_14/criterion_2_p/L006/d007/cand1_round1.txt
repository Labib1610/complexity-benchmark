# Sensor Network Synchronization

Time limit: 2 s
Memory limit: 256 MB

## Description

You are analyzing a deployment of $n$ distributed sensor nodes. The network is deployed across a facility that can accommodate up to a $400 \times 500$ grid of sensors, setting the absolute maximum for $n$.

A specific subset of $t$ nodes are designated as primary anchors. There is always at least one primary anchor, and in the maximum case, all $n$ nodes could be designated as anchors.

You are provided with a catalog of $m$ potential wireless links. Each link can bridge exactly two distinct nodes $u$ and $v$, and activating it requires a continuous power allocation of $w$ milliwatts. The power allocation $w$ is at least 1 and is physically capped at the square of $1000$.

Your objective is to select a subset of these potential links to activate, forming an active network $C$. The active network must meet a strict synchronization requirement:
Suppose you were to assign every node in the entire network to either a "red" state or a "blue" state. If your assignment results in the set of primary anchors containing at least one red node and at least one blue node, then your active network $C$ must contain at least one link that bridges a red node directly to a blue node. This requirement must hold true for *every* possible assignment of states that splits the anchors.

Due to hardware constraints, the number of potential links $m$ provided in the catalog is exactly one less than the total number of nodes $n$. It is guaranteed that the provided potential links are sufficient to form at least one valid active network $C$. Note that some nodes might not need to be synchronized with the anchors at all, and the catalog might not connect all nodes into a single unified structure.

Determine the minimum total power allocation required to form a valid active network $C$.

## Input

The first line provides three integers **n**, **m**, and **t**.
The second line lists **t** distinct integers representing the primary anchors.
Following this are **m** lines, each containing three integers **u**, **v**, and **w**, indicating a potential link between node **u** and node **v** that requires **w** milliwatts to activate.

## Output

Output a single integer representing the minimum possible total power allocation to activate a valid network $C$.

## Examples

**Output**


**Output**
```
9
```

<RATIONALE>
I removed the explicit guarantee that all vertices form a connected structure, replacing it with a weaker promise that a valid network is merely possible, which suggests a forest rather than a tree. I also translated the subset-cut condition into a "red/blue state" assignment scenario, and indirected the numeric bounds using S07. This forces the model to deduce that the required structure is a unique subtree within a specific forest component, rather than blindly applying a global tree traversal rooted at an arbitrary node.
</RATIONALE>
<PRESERVED_ANSWER>
The red/blue state condition is logically identical to the subset cut condition (requiring all anchors to be connected in the chosen subgraph), and since the input graph format and weights are unchanged, the minimum cost subgraph remains the exact same Steiner tree.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Because $m = n - 1$ and a valid solution exists, the anchors are still guaranteed to be connected by a unique path in a forest, allowing the same $O(n)$ tree-pruning algorithm to find the optimal solution, keeping the problem in P.
</PRESERVED_CLASS>
<RISK>
The red/blue state assignment might be misread as a bipartite graph coloring requirement rather than an arbitrary cut condition, though the phrase "every possible assignment" should clarify its true meaning.
</RISK>
