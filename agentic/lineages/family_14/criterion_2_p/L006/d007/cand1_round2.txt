<METHOD_NAME>Algebraic Constraint Synchronization</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces graph connectivity with the algebraic equivalent of enforcing equality constraints among continuous variables. The tree property is framed as a system of equations that leaves exactly one degree of freedom, forcing models to translate constraint satisfaction back into tree topology to apply the optimal O(n) algorithm.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem B — Equivalence System Activation

Time limit: 2 s
Memory limit: 256 MB

## Description

You are tasked with enforcing a set of constraints on an array of $n$ continuous variables $X = [x_1, x_2, \dots, x_n]$. You have a critical subset $T$ containing $t$ indices that require synchronization.

You are given a catalog of $m$ available bidirectional synchronizers. Each synchronizer can enforce the equality constraint $x_u = x_v$ and requires an activation energy $w$.

Your goal is to select a subset of synchronizers $C$ such that for any two indices $i, j \in T$, the equation $x_i = x_j$ is mathematically guaranteed by the synchronizers in $C$ (using the standard transitive, symmetric, and reflexive properties of equality). 

Equivalently, the collection $C$ must satisfy the following structural property: For every possible partition of the $n$ indices into two disjoint non-empty sets $A$ and $B$, if both $A$ and $B$ contain at least one index from $T$, then there must exist at least one synchronizer in $C$ that bridges the partition (i.e., enforces $x_u = x_v$ where $u \in A$ and $v \in B$).

You may activate synchronizers that do not involve any indices from $T$ if they are needed to propagate the equality constraints between critical variables.

You are given that $m = n - 1$. Furthermore, it is mathematically guaranteed that if you were to activate all $m$ available synchronizers, the property would hold for *all* non-empty proper subsets $A$ (meaning the full set of $m$ synchronizers logically forces $x_1 = x_2 = \dots = x_n$, leaving exactly one degree of freedom for the entire array).

Determine the minimum total activation energy required to choose a valid collection $C$ that synchronizes the critical subset $T$.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **t** ≤ **n**, 1 ≤ **n** ≤ 200000, **m** = **n** − 1). The variables are indexed from 1 to **n**.
The second line lists **t** distinct integers representing the indices of the critical subset $T$.
Following this are **m** lines, each containing three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000). These values indicate an available synchronizer that enforces $x_u = x_v$ and can be activated at an energy cost of **w**.

## Output

Output a single integer representing the minimum possible total energy to activate a collection of synchronizers that satisfies the required property for $T$.


**Output**
```
8
```

</STATEMENT>
<RATIONALE>
The problem is reframed from selecting edges in a graph to selecting equality constraints in an algebraic system. The input tree guarantee is preserved but disguised as a system of $n-1$ equations that leaves exactly one degree of freedom. This forces the model to deduce that the constraints form a tree topology before it can apply the standard $O(n)$ rooting and subtree extraction algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The logical implication of equality among variables is mathematically identical to nodes being in the same connected component, so the identical set of synchronizers (edges) minimizes the sum of weights.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains finding the minimum weight Steiner tree on a graph that is guaranteed to be a tree, which is solvable in linear time ($O(n)$) and therefore remains in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "continuous variables" as requiring a numerical solver or linear programming, but the explicit equivalent structural property clarifies that it is a discrete selection problem.
</RISK>
