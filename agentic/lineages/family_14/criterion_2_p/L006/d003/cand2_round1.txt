# Problem B — Relative Calibration

Time limit: 2 s
Memory limit: 256 MB

## Description

A facility contains **n** sensors, labeled from 1 to **n**. Because their absolute baseline readings are unobservable, their calibration must rely entirely on pairwise comparisons. You are given a roster of **m** potential testing operations. A single operation evaluates a specific pair of sensors and yields the precise numerical offset between them. 

The provided roster of potential testing operations is minimally comprehensive. If you were to fund all of them, you could determine the offset between any two sensors in the facility. However, the roster contains no redundancies; failing to perform even one operation from the full roster would leave at least one pair of sensors without a chain of comparisons linking them.

Your objective focuses on a designated priority group of **t** sensors. You need to choose a subset of the testing operations so that the relative offset between every pair of these **t** priority sensors can be determined. You are allowed to include tests involving non-priority sensors if they help bridge the calculations between the priority ones.

Each testing operation carries a specific monetary cost. Determine the minimum total cost required to fund a valid subset of operations that fully integrates the priority sensors.

## Input

The first line provides three integers **n**, **m**, and **t**. The total number of sensors **n** is at least one and is bounded by the facility's maximum hardware capacity of two hundred thousand. The priority group size **t** ranges from a single sensor up to the total number of installed sensors **n**. The number of potential testing operations **m** equals the exact theoretical minimum number of operations required to fully link all **n** sensors into a single unified system.

The second line lists **t** distinct integers representing the labels of the priority sensors.

Following this are **m** lines, each containing three integers **u**, **v**, and **w**. These values indicate a potential testing operation that evaluates sensor **u** and sensor **v** (both being valid sensor labels, with **u** ≠ **v**). The cost **w** is at least one, and cannot exceed the maximum departmental authorization limit for a single test, which is one million. It is guaranteed that the given **m** operations can relate all **n** sensors according to the minimally comprehensive structure described.

## Output

Output a single integer representing the minimum possible total cost to execute the necessary operations to deduce the offsets among all priority sensors.
