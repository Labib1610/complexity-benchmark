# Problem B — Relative Calibration

Time limit: 2 s
Memory limit: 256 MB

## Description

An array of sensors (numbered 1 to **n**) is being calibrated. You cannot measure the absolute reading of any sensor. Instead, there are **m** available pairwise calibration procedures. Each procedure compares two specific sensors, determining the exact numerical difference between their readings. 

The available procedures form a minimal complete set: they provide exactly one unique sequence of intermediate comparisons to mathematically deduce the relative difference between any two sensors in the entire array.

The project requires establishing the relative differences among a specific group of **t** target sensors. You must select a subset of the available procedures to perform such that the relative difference between every pair of these **t** target sensors can be deduced (possibly using other non-target sensors as intermediaries in the calculations). 

Each procedure has a known financial cost to execute. You must find a valid selection of procedures that minimizes the total execution cost, and report this minimum total cost.

## Input

The first line contains three integers **n**, **m**, and **t**. The array size **n** is at least 1 and accommodates up to a design maximum of 200,000 sensors. To ensure minimal redundancy, the number of procedures **m** is exactly one less than the total number of sensors. The number of target sensors **t** can be anywhere from a single sensor up to all **n** sensors.

The second line contains **t** distinct integers: the identifiers of the target sensors.

Each of the next **m** lines contains three integers **u**, **v**, and **w**. The values **u** and **v** specify distinct sensor identifiers between 1 and **n** that the procedure compares. The financial cost **w** to execute this procedure is at least 1 and capped at a maximum of 1,000,000. It is guaranteed that the full set of **m** procedures can relate all **n** sensors.

## Output

Print a single integer: the minimum total execution cost of the procedures required to deduce the relative differences among all target sensors.

## Examples

**Input**
```

```

**Output**
```
8
```

```

### Example 3

```

**Output**
```
9
```
