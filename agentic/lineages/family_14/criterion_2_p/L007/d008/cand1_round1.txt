<STATEMENT>
# Subspace Basis Selection

Time limit: 2 s   Memory limit: 256 MB

## Description

You are working with a vector space constructed from $n$ orthogonal basis vectors $\mathbf{e}_1, \mathbf{e}_2, \ldots, \mathbf{e}_n$.

You are provided with a generator pool of $m = n - 1$ distinct transition vectors. Each transition vector is defined by a pair of indices $u$ and $v$ ($u \neq v$), representing the vector $\mathbf{e}_u - \mathbf{e}_v$, and has a specific activation cost $w$.

It is guaranteed that the full pool of available transition vectors spans the entire $(n-1)$-dimensional subspace defined by the equation $\sum_{i=1}^n x_i = 0$.

A researcher has specified a target subset of $t$ indices, denoted as $T$. Your objective is to select a subset of the available transition vectors such that their linear span contains the vector $\mathbf{e}_a - \mathbf{e}_b$ for every pair of distinct indices $a, b \in T$. Note that the linear span of your selected vectors may also contain transition vectors involving indices outside of $T$, which is permissible and often necessary to establish the required vectors.

Determine the minimum total activation cost of a subset of transition vectors that must be selected to satisfy the researcher's requirement. Any transition vector not strictly needed to span the required target vectors can be omitted.

## Input

The first line provides three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$).
The second line provides $t$ distinct integers, representing the indices in the target subset $T$.
The next $m$ lines each contain three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), indicating an available transition vector $\mathbf{e}_u - \mathbf{e}_v$ with an activation cost of $w$.

## Output

Output a single integer: the minimum total activation cost of the selected subset of transition vectors.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```

```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3

2 3 5
```

**Output**
```
9
```

<RATIONALE>
I replaced the group-theoretic framing (generating transpositions in the symmetric group) with an isomorphic linear algebra framing (spanning difference vectors in an $n$-dimensional space). This forces the model to recognize that the linear independence of $n-1$ difference vectors corresponds exactly to an acyclic graph structure, and that spanning a target difference requires selecting the unique path in the underlying tree.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that a subset of basis difference vectors spans a target difference vector $\mathbf{e}_a - \mathbf{e}_b$ is mathematically equivalent to the condition that $a$ and $b$ are in the same connected component of the graph formed by the selected vectors, so the exact same minimal subset of edges (and thus the same total cost) is required.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains a graphical matroid on a tree where we must connect a subset of terminal vertices, preserving the $O(n)$ tree-pruning complexity.
</PRESERVED_CLASS>
<RISK>
Models might assume they need to perform actual Gaussian elimination and fail due to Time Limit Exceeded, but the statement itself is mathematically unambiguous and solvable in $O(n)$ time.
</RISK>

Vector Space Isomorphism
</METHOD_NAME>
<METHOD_DESCRIPTION>
I mapped the group generation requirement to an isomorphic linear algebra requirement (spanning difference vectors). Models relying on surface pattern matching will likely attempt generalized linear algebra algorithms (like matrix rank checks or Gaussian elimination), which will severely exceed the 2-second time limit for n=200000. Models that genuinely reason about algorithmic structure will recognize that the transition vectors form the incidence matrix of a tree, and that spanning a target difference requires connecting those nodes in the tree, thus reducing back to the correct O(n) subtree pruning algorithm.
</METHOD_DESCRIPTION>
