We can model the reference points as vertices of a graph, and each available integral as an undirected edge with a cost.  
Since the catalog is guaranteed to connect all points, the graph is a tree (because \( m = n-1 \) and it’s connected).  

To deduce integrals between all pairs in the target set \( T \), we need to ensure that in the selected subgraph, all target vertices are in the same connected component.  
That means we need to find the minimum-cost subgraph (subset of edges) that connects all vertices in \( T \).  

This is exactly the **Steiner tree** problem on a tree, which can be solved efficiently:  
- For a tree, the minimal Steiner tree connecting a set of terminals is the union of all edges on the paths between terminals.  
- The cost is the sum of weights of all edges in the minimal subtree spanning \( T \).  

We can find this by:  
1. Mark all target vertices.  
2. Do a DFS from any target vertex, and keep only edges that lead to at least one target vertex in their subtree.  
3. Sum the weights of those kept edges.  

Here’s the implementation:  

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    targets = set(map(int, input().split()))
    
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    if t == 1:
        print(0)
        return
    
    # DFS to find minimal subtree connecting targets
    visited = [False] * (n + 1)
    total_cost = 0
    
    def dfs(u, parent):
        nonlocal total_cost
        visited[u] = True
        has_target = u in targets
        for v, w in adj[u]:
            if v == parent:
                continue
            if not visited[v]:
                child_has_target = dfs(v, u)
                if child_has_target:
                    total_cost += w
                has_target = has_target or child_has_target
        return has_target
    
    # Start from any target
    start = next(iter(targets))
    dfs(start, -1)
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
