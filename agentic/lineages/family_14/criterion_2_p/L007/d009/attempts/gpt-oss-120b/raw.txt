**Solution Explanation**

For every evaluation we are given an unordered pair of reference points  
`(u , v)` and its cost `w`.  
All `m = n‑1` evaluations are enough to deduce any integral, therefore the
graph formed by the `n` points and the `m` edges is a **tree** (connected,
`n‑1` edges).

For a set `T` of target points we have to choose a subset of edges whose
known integrals allow us to deduce the integral between **any two** points of
`T`.  
In a tree an integral between two points is the sum of the integrals on the
unique path that connects them, therefore we can deduce it iff all edges of
that path are known.

Consequently the chosen edges must contain a connected sub‑graph that spans
all vertices of `T`.  
The cheapest such sub‑graph in a tree is unique: it is the **minimal subtree
that contains all vertices of `T`** (the union of all pairwise paths).  
An edge of the original tree belongs to this minimal subtree **iff**
removing the edge separates the tree into two components each containing at
least one vertex of `T`.

So the answer is simply the sum of the costs of all edges whose removal
leaves at least one target vertex on each side.

--------------------------------------------------------------------

#### Algorithm
```
read input
build adjacency list of the tree
mark the target vertices

root the tree at vertex 1
perform an iterative DFS
    store for every vertex:
        parent[vertex]
        weight_to_parent[vertex]
        order of visitation (for later bottom‑up processing)

process vertices in reverse DFS order (post‑order)
    subtree_target[vertex] = 1 if vertex is a target else 0
    add subtree_target[child] for all children
    if vertex is not the root:
         cnt = subtree_target[vertex]          # number of targets in its component
         if 0 < cnt < |T|:
                answer += weight_to_parent[vertex]

output answer
```

`subtree_target[vertex]` is the number of target vertices inside the
component that would remain if the edge to its parent were cut.
The condition `0 < cnt < |T|` exactly means that both sides of the edge contain
a target vertex.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs the minimum possible total cost.

---

##### Lemma 1  
For any edge `e = (p, c)` (parent `p`, child `c`) let `cnt` be the number of
target vertices in the subtree of `c`.  
Edge `e` belongs to the minimal subtree spanning `T` **iff** `0 < cnt < |T|`.

**Proof.**  
Removing `e` splits the tree into two components:
* component `C` = subtree of `c` (contains exactly `cnt` target vertices),
* component `P` = the rest (contains `|T|‑cnt` target vertices).

*If* both components contain a target vertex (`cnt>0` and `|T|-cnt>0`),
any connected subgraph that contains all targets must contain a path from a
target in `C` to a target in `P`, therefore must contain `e`.

*If* one component contains no target vertex, all targets lie in the other
component, so a connected subgraph spanning `T` can stay completely inside that
component and does not need `e`.

∎



##### Lemma 2  
The set of edges selected by the algorithm (those with `0 < cnt < |T|`)
forms a connected subgraph that contains all vertices of `T`.

**Proof.**  
Take any two target vertices `a, b`.  
On the unique tree path between them, each edge separates the tree into two
parts, each containing at least one of `{a,b}`; therefore each edge of the
path satisfies the condition of Lemma&nbsp;1 and is selected.
Thus the whole path is present, so `a` and `b` are connected inside the
selected edges. Since this holds for every pair, the selected edges connect
all targets. ∎



##### Lemma 3  
Any connected subgraph of the original tree that contains all vertices of `T`
must contain every edge selected by the algorithm.

**Proof.**  
Consider a selected edge `e`. By Lemma&nbsp;1 both sides of `e` contain a target
vertex. Any connected subgraph containing all targets must contain a path
between those two vertices, and the only possible path in a tree uses `e`.
Hence `e` is mandatory. ∎



##### Theorem  
The algorithm outputs the minimum possible total compute cost needed to be
able to deduce all integrals between pairs of target points.

**Proof.**  

*Existence*: By Lemma&nbsp;2 the edges chosen by the algorithm indeed allow us
to deduce every required integral, so the total cost `Ans` is feasible.

*Optimality*: Let `S` be any feasible set of edges (i.e. a connected subgraph
spanning `T`). By Lemma&nbsp;3 every edge selected by the algorithm belongs to
`S`. Therefore `cost(S) ≥ cost(algorithm) = Ans`. No feasible solution can be
cheaper, so `Ans` is optimal. ∎

#### Complexity Analysis  

*Building the adjacency list*: `O(n)`  
*DFS traversal*: `O(n)`  
*Post‑order processing*: `O(n)`  

Memory consumption: adjacency list (`2·(n‑1)` entries) + a few `O(n)` arrays,
all `O(n)`.

Both limits satisfy `n ≤ 200 000`.

--------------------------------------------------------------------

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    n = int(next(it))
    m = int(next(it))          # equals n-1, not needed separately
    t = int(next(it))

    targets = [0] * (n + 1)
    for _ in range(t):
        idx = int(next(it))
        targets[idx] = 1

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        w = int(next(it))
        adj[u].append((v, w))
        adj[v].append((u, w))

    # iterative DFS to avoid recursion limit
    parent = [0] * (n + 1)
    w_to_parent = [0] * (n + 1)
    order = []

    stack = [1]
    parent[1] = -1          # root marker
    while stack:
        u = stack.pop()
        order.append(u)
        for v, w in adj[u]:
            if v == parent[u]:
                continue
            parent[v] = u
            w_to_parent[v] = w
            stack.append(v)

    subtree_cnt = [0] * (n + 1)
    total = 0
    for u in reversed(order):
        cnt = targets[u]
        for v, _ in adj[u]:
            if parent[v] == u:          # v is a child of u
                cnt += subtree_cnt[v]
        subtree_cnt[u] = cnt
        if parent[u] != -1:             # not the root
            if 0 < cnt < t:
                total += w_to_parent[u]

    print(total)


if __name__ == "__main__":
    solve()
```

to the required input‑output format.
