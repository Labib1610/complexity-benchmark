**Solution Explanation**

For every pair of racks there is exactly one path in the whole network,
therefore the network is a **tree**.
The customer rents `t` special racks.
We have to switch on a set of edges whose total cost is minimal,
but the set must connect all special racks.
Edges may be used as relays even if their ends are not rented.

--------------------------------------------------------------------

#### 1.   Observation  

In a tree the cheapest way to connect a given set of vertices is the
**union of all paths between them**.
The obtained sub‑tree is called the *Steiner tree* of the special vertices,
and on a tree it is unique.

An edge belongs to that sub‑tree **iff**
after removing the edge the two resulting components each contain at
least one special rack.
Consequently the answer is the sum of the costs of all such edges.

--------------------------------------------------------------------

#### 2.   Reducing the condition to subtree sizes  

Root the tree at any vertex (conveniently vertex `1`).

For a node `v` let  

```
cnt[v] = number of special racks in the subtree of v (including v)
```

Consider the edge between a node `v (≠ root)` and its parent `p`.
Removing this edge separates the subtree of `v` from the rest of the tree.
The edge is needed **iff**

```
0 < cnt[v] < t
```

because then both sides contain at least one special rack.

So we only have to know `cnt[v]` for every node.

--------------------------------------------------------------------

#### 3.   Computing the subtree counts  

*   Build adjacency lists (`O(n)`).
*   Perform an iterative DFS (stack) from the root.
    While traversing store for every node  

    * `parent[node]` – its parent,
    * `pw[node]`      – weight of the edge to its parent,
    * `order`        – the visiting order (pre‑order).

*   Initialise `cnt[v] = 1` for every special rack, otherwise `0`.
*   Process the nodes **in reverse order** (children before parent):
    ```
    for node in reversed(order):
        if node == root: continue
        c = cnt[node]
        if 0 < c < t: answer += pw[node]
        cnt[parent[node]] += c          # propagate to the parent
    ```

The reverse of a pre‑order list guarantees that every child is handled
before its parent, therefore the propagation works correctly.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm outputs the minimum possible total activation
cost.

---

##### Lemma 1  
For any edge `e = (parent, child)` the algorithm adds its weight to the
answer **iff** the two components obtained by deleting `e` each contain at
least one special rack.

**Proof.**  
During the reverse traversal `cnt[child]` equals the number of special
racks in the child’s component (the subtree).  
`0 < cnt[child] < t` holds exactly when the child component has a special
rack (`cnt>0`) and the rest of the tree also has a special rack
(`t-cnt>0`). The algorithm adds `pw[child]` precisely under this condition. ∎



##### Lemma 2  
The set of edges selected by the algorithm connects all special racks.

**Proof.**  
Take any two special racks `a` and `b`.  
On the unique tree path between them, every edge separates the tree into
two parts, each containing one of the two vertices, therefore each part
contains a special rack. By Lemma&nbsp;1 every edge on that path is selected.
Thus the whole path is present, and consequently `a` and `b` are connected.
Since this holds for every pair, all special racks are mutually reachable. ∎



##### Lemma 3  
Every edge selected by the algorithm is necessary in any feasible solution.

**Proof.**  
Consider a selected edge `e`. By Lemma&nbsp;1 both sides of `e` contain a
special rack. Any solution that connects all special racks must contain a
path between those two racks, and any such path must cross the cut defined
by `e`. The only edges crossing that cut are `e` itself (the tree has a
single edge between the two components). Hence `e` must be activated. ∎



##### Lemma 4  
The total weight output by the algorithm equals the weight of the unique
minimum Steiner tree of the special vertices.

**Proof.**  
The Steiner tree on a tree is exactly the set of edges whose removal would
separate the special vertices, i.e. the edges satisfying the condition of
Lemma&nbsp;1. By Lemma&nbsp;2 the algorithm’s edge set connects all specials,
and by Lemma&nbsp;3 no proper subset can do so. Therefore the algorithm’s set
coincides with the Steiner tree, and their total weights are equal. ∎



##### Theorem  
The algorithm returns the minimum possible total activation cost needed to
connect all rented racks.

**Proof.**  
By Lemma&nbsp;4 the algorithm’s cost equals the weight of the Steiner tree,
which is the optimal solution for connecting a given set of vertices in a
tree. Hence no cheaper set of edges exists, and the algorithm is optimal. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Building adjacency lists* : `O(n)` time, `O(n)` memory.  
*DFS traversal*          : `O(n)` time, `O(n)` memory for stacks and arrays.  
*Reverse processing*    : `O(n)` time.  

Overall  

```
Time   : O(n)      ( ≤ 2·10⁵ operations, easily fits 2 s )
Memory : O(n)      ( ≤ 256 MiB )
```

#### 6.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    it = iter(data)

    n = next(it)          # number of racks
    m = next(it)          # = n-1
    t = next(it)          # number of rented racks

    specials = [next(it) for _ in range(t)]

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = next(it)
        v = next(it)
        w = next(it)
        adj[u].append((v, w))
        adj[v].append((u, w))

    root = 1
    parent = [0] * (n + 1)   # parent[node]
    pw = [0] * (n + 1)        # weight to parent
    order = []                # preorder

    stack = [root]
    parent[root] = -1        # mark root
    while stack:
        node = stack.pop()
        order.append(node)
        for nb, w in adj[node]:
            if nb != parent[node]:
                parent[nb] = node
                pw[nb] = w
                stack.append(nb)

    cnt = [0] * (n + 1)
    for s in specials:
        cnt[s] = 1

    ans = 0
    for node in reversed(order):
        if node == root:
            continue
        c = cnt[node]
        if 0 < c < t:
            ans += pw[node]
        cnt[parent[node]] += c

    sys.stdout.write(str(ans))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input‑output format.
