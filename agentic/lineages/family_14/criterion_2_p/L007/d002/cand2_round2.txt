<STATEMENT>
# Datacenter Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

A datacenter is equipped with $n$ server racks, which are assigned identifiers from 1 up to $n$. The facility's internal infrastructure provides $m$ possible fiber conduit connections between pairs of racks. Turning on any given conduit incurs a specific activation cost.

A corporate client has rented a target group of $t$ racks. Your objective is to select a subset of the available conduits to power on, such that data can flow between all $t$ of the client's rented racks. When establishing this communication, the data may pass through racks that the client did not rent; these unrented racks simply act as free intermediate switches, requiring no extra fee beyond the cost of the powered-on conduits that attach to them.

Calculate the minimum total activation cost needed to link all of the client's rented racks into a single communicating group.

## Input

The first line contains three integers $n$, $m$, and $t$. The facility is built to house up to a maximum capacity of 200000 racks, meaning $1 \le n \le 200000$. The number of conduits $m$ is exactly $n - 1$, designed to ensure a loop-free layout. The client's rental agreement covers at least one rack and up to all available racks, so $1 \le t \le n$.
The second line contains $t$ distinct integers representing the identifiers of the rented racks.
Each of the following $m$ lines contains three integers $u$, $v$, and $w$. This indicates a fiber conduit is installed between rack $u$ and rack $v$ ($1 \le u, v \le n$, $u \ne v$). The activation cost $w$ for this conduit is at least 1 and is bounded by the hardware maximum of 1000000 ($1 \le w \le 1000000$). It is guaranteed that powering on all $m$ conduits would successfully connect all $n$ racks.

## Output

Print a single integer representing the minimum total activation cost to connect all rented racks.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```

```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```
