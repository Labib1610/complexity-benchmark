# Datacenter Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

A computing facility houses **n** server racks, indexed from 1 to **n**. The building is pre-wired with exactly **n − 1** bidirectional fiber-optic links. The network's physical layout is strictly loop-free: there is no sequence of distinct links that forms a closed circuit. Powering on each link incurs a specific activation expense.

A customer has rented a specific group of **t** racks. Your objective is to power on a selection of the fiber-optic links so that every rented rack can exchange data with every other rented rack. Data can be routed through racks that the customer has not rented.

The total activation expense for your network is calculated by summing two components:
1. The individual activation expenses of all powered-on fiber-optic links.
2. A relay activation fee for every unrented rack that is included in the active communication routes.

Currently, the relay activation fee is fixed at 0 per unrented rack. Calculate the minimum total activation expense necessary to tie all the rented racks together, ensuring you incorporate both the link expenses and the relay activation fees into your final calculation.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line provides **t** distinct integers, which are the indices of the rented racks.
The next **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000). This indicates a pre-wired fiber-optic link between rack **u** and rack **v** that costs **w** to power on. You are guaranteed that the provided infrastructure contains a valid subset of links that connects all rented racks.

## Output

Output a single integer: the minimum total activation expense to power on the required links and racks.

<RATIONALE>
Removed the explicit "unique communication route between any given pair" guarantee, which is a common trigger for models to immediately apply tree DP or DFS pruning. Replaced it with the mathematical equivalent: the network has $n-1$ links and is "strictly loop-free". Added a redundant guarantee in the input section that the rented racks can be connected, which acts as a distractor implying the graph might be a disconnected forest, forcing the model to either mathematically deduce that the entire graph is a single tree or attempt a general Steiner Tree algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The problem still asks for the minimum cost to connect a subset of racks using the exact same costs and graph structure, so the required subset of links and total cost remain identical for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The combination of $n$ vertices, $n-1$ edges, and a strictly loop-free topology mathematically guarantees that the graph is a single tree, meaning the problem remains solvable in polynomial time $O(n)$ by pruning the tree.
</PRESERVED_CLASS>
<RISK>
Models might interpret "strictly loop-free" as meaning a directed graph, though the addition of "bidirectional" explicitly prevents this; otherwise, none.
</RISK>
