<STATEMENT>
# Datacenter Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

A computing facility contains **n** server racks, numbered 1 through **n**. The facility is equipped with exactly **n − 1** fiber-optic links. Bringing each link online requires a certain activation expense.

A client has leased a subset of **t** racks. You must select and power on a subset of the available links such that all **t** leased racks can communicate with one another. Communication paths may pass through unleased racks. You are guaranteed that the provided links are sufficient to establish this connectivity among the leased racks.

The total activation expense for the network consists of two parts:
1. The sum of the activation expenses for all powered-on links.
2. A relay activation fee applied to each unleased rack that forms part of the active communication paths.

At present, the relay activation fee is set to exactly 0 per unleased rack. Your task is to determine the minimum total activation expense required to interconnect all leased racks, taking into account both the link expenses and the relay fees.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers, representing the identifiers of the leased racks.
The following **m** lines each provide three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), meaning there is a fiber-optic link between rack **u** and rack **v** with an activation expense of **w**.

## Output

Output a single integer representing the minimum total activation expense needed to power on the necessary links and racks.

<RATIONALE>
The explicit guarantee that the links form a tree with exactly one unique communication route between any given pair of racks has been removed. The problem now simply states there are n-1 links that can connect the leased racks, forcing models to independently deduce that this graph is a forest and that the minimal connecting subgraph is unique, rather than relying on surface-level keyword matching to trigger a tree traversal.
</RATIONALE>
<PRESERVED_ANSWER>
The answers are unchanged because the input structure and the underlying graph topology are exactly the same; the minimum cost to connect the required subset of nodes in a forest remains the unique minimal spanning subtree.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The complexity class remains in P because finding the minimal connecting subgraph for a subset of nodes in a graph with m = n - 1 (a forest) can always be done in linear time.
</PRESERVED_CLASS>
