<METHOD_NAME>Algebraic Equivalence Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Re-framed the graph connectivity problem as a system of algebraic equivalence constraints. Vertices become variables, edges become bidirectional equality constraints, and the goal of connecting a subset of nodes becomes forcing a subset of variables to be equal. This prevents models from relying on graph-theoretic pattern matching (like "Steiner tree on a tree") while perfectly preserving the mathematical structure and O(n) tree DP/pruning solution.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Datacenter Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of **n** variables, indexed from 1 to **n**. You are provided with **m** available bidirectional equivalence constraints. Each constraint specifies that two variables must take the same value, and enforcing it requires a certain amount of computational effort.

The set of available constraints contains no circular dependencies; there is at most one valid sequence of constraints linking any given pair of variables.

You need a chosen set of **t** target variables to be strictly equal to one another. Your objective is to enforce a selection of the available constraints so that all **t** target variables are mathematically forced to be equal. You may enforce constraints involving variables outside the target set to chain the equivalences together.

You are guaranteed that the provided set of **m** constraints is sufficient to prove the equivalence of all **t** target variables. Calculate the minimum total effort necessary to enforce a valid selection of constraints.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line provides **t** distinct integers, which are the indices of the target variables.
The next **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000). This indicates an available constraint between variable **u** and variable **v** that requires **w** effort to enforce.

## Output

Output a single integer: the minimum total effort to enforce a valid subset of constraints.

<RATIONALE>
The problem was completely re-framed from network routing to enforcing algebraic equality constraints between variables. The underlying structure remains exactly the same (finding the minimum cost subtree connecting a set of target nodes in a forest), but the graph-theoretic terminology has been removed. This forces solvers to map the logical requirement of "mathematically forced to be equal" to graph components, preventing them from blindly applying standard tree-pruning templates without understanding the mapping.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical task remains identical: selecting a minimum-weight set of edges (constraints) such that a specific subset of vertices (target variables) is in the same connected component.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The input is still structurally a forest (or tree) with positive edge weights, meaning the minimal connecting subgraph is unique and can be found in O(n) time using the same tree traversal or leaf-pruning logic.
</PRESERVED_CLASS>
