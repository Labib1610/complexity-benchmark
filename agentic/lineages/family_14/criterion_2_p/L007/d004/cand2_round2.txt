# Variable Unification

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of **n** abstract variables, indexed from 1 to **n**. You are provided with exactly **n − 1** potential unification constraints. The structure of these constraints guarantees that, when all are enforced, there is exactly one unique sequence of constraints linking any given pair of variables. Enforcing each constraint incurs a specific computational effort.

A particular query focuses on a specific group of **t** target variables. Your objective is to enforce a selection of the unification constraints so that every target variable is transitively forced to be identical to every other target variable. Unification chains can pass through variables that are not in the target group.

The total effort for your selection is calculated by summing two components:
1. The individual computational efforts of all enforced constraints.
2. A bridging penalty for every non-target variable that is included in the active unification chains.

Currently, the bridging penalty is fixed at 0 per non-target variable. Calculate the minimum total effort necessary to unify all the target variables together, ensuring you incorporate both the constraint efforts and the bridging penalties into your final calculation.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line provides **t** distinct integers, which are the indices of the target variables.
The next **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000). This indicates a potential unification constraint between variable **u** and variable **v** that costs **w** to enforce. The given set of **m** constraints guarantees that exactly one valid sequence of constraints exists between any two variables when fully enforced.

## Output

Output a single integer: the minimum total effort to enforce the required constraints and variables.
