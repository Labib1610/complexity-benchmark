<METHOD_DESCRIPTION>Replaced the path-finding/integral-deduction framing with a state-toggling cellular automaton (genetic mutagens). Toggling two endpoints of an edge allows toggling exactly any two nodes in a connected component via path cancellation, making the requirement mathematically equivalent to finding a minimal connected subgraph (Steiner tree) while completely hiding graph vocabulary.</METHOD_DESCRIPTION>

<STATEMENT>
# Mutagenesis Parity

Time limit: 2 s   Memory limit: 256 MB

## Description

You are studying a genome with $n$ specific gene loci. All $n$ loci are initially in their wild-type state.

You are provided with a catalog of $m$ possible mutagens. Mutagen $i$ affects locus $u$ and locus $v$, and costs $w$ dollars to synthesize. 

When a synthesized mutagen is applied, it simultaneously toggles the state of both locus $u$ and locus $v$ (from wild-type to mutated, or from mutated back to wild-type). You can apply the synthesized mutagens in any sequence, and you may apply each synthesized mutagen any number of times.

A researcher has specified a target subset of $t$ loci, denoted by the index set $T$. Your objective is to synthesize a subset of the available mutagens such that, for *every* pair of distinct loci $a, b \in T$, there exists a sequence of mutagen applications that leaves exactly loci $a$ and $b$ in the mutated state, with all other $n-2$ loci in the genome restored to their wild-type state. You must be able to achieve this specific two-locus mutation for any chosen pair of distinct loci $a, b \in T$ independently (starting from the all wild-type state each time).

It is guaranteed that if you synthesize the full catalog of $m$ mutagens, you can achieve this state for any pair of distinct loci in the entire genome.

Determine the minimum total synthesis cost required to prepare a subset of mutagens that satisfies the researcher's requirement. Any mutagen not strictly needed to achieve the required states can be omitted.

## Input

The first line provides three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$).
The second line provides $t$ distinct integers, representing the indices in the target subset $T$.
The next $m$ lines each contain three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), indicating an available mutagen that affects loci $u$ and $v$ with a synthesis cost of $w$ dollars.

## Output

Output a single integer: the minimum total synthesis cost of the selected subset of mutagens.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```
</STATEMENT>
<RATIONALE>
Replaced the "deducing integrals" path-finding frame with a cellular automaton / mutagenesis scenario. The operation of toggling two states simultaneously means that leaving exactly two nodes mutated is only possible if they are in the same connected component (by applying all edges on the path between them). This forces models to deduce the isomorphism to graph connectivity and Steiner trees, defeating those that rely on the familiar "A to B plus B to C" transitive pattern.
</RATIONALE>
<PRESERVED_ANSWER>
The condition to independently toggle any pair in T requires the selected mutagens to form a connected component containing T; since m=n-1, the minimal such component is exactly the minimum weight subtree connecting T, identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still reduces to finding the minimum weight subtree containing a subset of vertices on a given tree, which is solvable in O(n) time.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the $t=1$ case if they don't realize "every pair of distinct loci" is vacuously true for a set of size 1, but Example 2 outputting 0 explicitly clarifies this edge case.
</RISK>
