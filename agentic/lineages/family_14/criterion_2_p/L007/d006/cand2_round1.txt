<METHOD_DESCRIPTION>
Translates a graph connectivity problem into a group generation problem. The edges of a tree are represented as a minimal set of transpositions generating the symmetric group. Connecting a target set of vertices is exactly equivalent to selecting a subset of transpositions whose generated subgroup contains all pairwise transpositions of the target elements. This hides all graph-related keywords (tree, path, connected) while maintaining a rigorous 1:1 mathematical isomorphism.
</METHOD_DESCRIPTION>

<STATEMENT>
# Transposition Subgroup Generation

Time limit: 2 s   Memory limit: 256 MB

## Description

You are investigating the symmetric group $S_n$, which consists of all permutations of $n$ distinct elements. The elements are identified by integers from $1$ to $n$.

You are provided with a generator pool of $m = n - 1$ distinct transpositions. Each transposition swaps exactly two elements $u$ and $v$ (leaving all other elements unchanged) and has a specific inclusion cost $w$.

It is guaranteed that the full pool of $m$ transpositions generates the entire symmetric group $S_n$. Because $m = n - 1$, this generating set is minimal; removing any transposition from the full pool would result in a subgroup strictly smaller than $S_n$.

A researcher has specified a target subset of $t$ elements, denoted as $T$. Your objective is to select a subset of the available transpositions such that the subgroup generated by your selected transpositions contains the transposition $(a, b)$ for every pair of distinct elements $a, b \in T$. Note that the generated subgroup may also permute elements outside of $T$, which is permissible and often necessary to establish the required permutations.

Determine the minimum total inclusion cost of a subset of transpositions that must be selected to satisfy the researcher's requirement. Any transposition not strictly needed to generate the required target transpositions can be omitted.

## Input

The first line provides three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$).
The second line provides $t$ distinct integers, representing the elements in the target subset $T$.
The next $m$ lines each contain three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), indicating an available transposition that swaps elements $u$ and $v$, with an inclusion cost of $w$.

## Output

Output a single integer: the minimum total inclusion cost of the selected subset of transpositions.

**Input**


**Output**

```
8
```

<RATIONALE>
Replaced the logical equivalence scenario with a group-theoretic one. The problem now asks to find a minimum-cost subset of transpositions that generates a subgroup containing all pairwise transpositions of a target set. This forces the model to realize that a minimal generating set of transpositions forms a tree, and generating specific transpositions requires connecting the target elements in this tree.
</RATIONALE>
<PRESERVED_ANSWER>
A subset of transpositions on $n$ elements generates the transposition $(a, b)$ if and only if $a$ and $b$ are in the same connected component of the transposition graph; since the available transpositions form a tree, the minimal subset satisfying this for all targets is exactly the unique minimal connecting subtree, identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure remains finding the minimum weight subtree connecting a subset of vertices in a tree, which is solvable in $O(n)$ time using a post-order traversal to prune unneeded branches.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "subgroup generated by your selected transpositions contains the transposition $(a, b)$" as needing to explicitly compute permutations, but the mathematical terminology is standard and unambiguous.
</RISK>
