<METHOD_NAME>Global Cut-Set Reformulation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the objective of "connecting nodes" with the mathematically equivalent requirement of "intersecting every cut that separates the target nodes". On a tree, this uniquely identifies the exact same set of required edges, but it frames the problem as a global constraint satisfaction over all partitions, steering models towards complex cut-set or network design algorithms instead of a simple tree traversal.</METHOD_DESCRIPTION>

<STATEMENT>
# Bipartition Verification

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a cluster of data nodes, identified by unique sequential integers starting from 1. The cluster is designed to scale up to a maximum physical capacity of 200,000 data nodes. You are provided with a set of potential synchronization links. Each link can synchronize two distinct nodes, and requires a specific verification time to activate. This verification time is a positive number of microseconds, limited by a hardware timeout of 1,000,000 microseconds.

A client has specified a target list of priority nodes. The priority headcount is guaranteed to be at least one, and could potentially include every node in the cluster. Your objective is to select a subset of the potential links to activate.

To ensure consistency, the selected subset must satisfy the following condition:
Consider every possible way to divide all of the cluster's nodes into two disjoint sets, $A$ and $B$, such that every node belongs to exactly one of the sets. If both set $A$ and set $B$ contain at least one priority node, then your selected subset MUST contain at least one activated link that connects a node in $A$ to a node in $B$.

The provided set of potential links forms a minimally sufficient backbone for the cluster. If you were to activate all of them, every such division of the cluster would be crossed by at least one link. Furthermore, the total count of potential links is exactly one less than the cluster's node count. This means that if you were to drop even a single link from the full provided set, there would exist at least one division of the cluster with zero crossing links.

Determine the minimum total verification time of a valid subset of links. Any link not needed to satisfy the condition can be left inactive.

## Input

The first line provides three integers: the total number of data nodes, the number of potential links, and the headcount of priority nodes.
The second line provides the distinct identifiers of the priority nodes.
The subsequent lines each correspond to a potential link, providing three integers: the two nodes it connects, and its verification time in microseconds.

## Output

Output a single integer: the minimum total verification time of a subset of activated links that successfully satisfies the condition.

<RATIONALE>
The problem objective was transformed from "connecting the targets" to "intersecting every cut that separates the targets". This forces the model to deduce that on a minimal connecting graph (a tree), the edges that cross cuts separating the targets are exactly the edges on the unique paths between them, requiring a shift from global partition reasoning back to simple tree traversal. Numeric bounds were also moved into the text as physical system limits.
</RATIONALE>
<PRESERVED_ANSWER>
Because every edge in a tree defines a unique fundamental cut, a subset of edges intersects all cuts separating the priority nodes if and only if it connects all priority nodes; therefore, the required subset and its minimum cost remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure is still finding the minimal subtree spanning a set of vertices in a tree, which is solved in O(n) time via post-order traversal or BFS/DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the condition as requiring a link between *every* node in A and B (a complete bipartite connection), though "at least one activated link that connects a node in A to a node in B" is strictly phrased to mean a single crossing edge.
</RISK>
