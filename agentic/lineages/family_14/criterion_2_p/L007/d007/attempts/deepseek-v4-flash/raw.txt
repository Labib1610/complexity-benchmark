We can model the transpositions as edges of a graph on vertices \(1 \dots n\), with edge weights equal to inclusion costs.  
The condition that the selected transpositions generate all transpositions among the target set \(T\) means that in the selected subgraph, all vertices of \(T\) must be in the same connected component.  

Why?  
- A set of transpositions generates the full symmetric group on a set of vertices if and only if those vertices are connected in the graph formed by the transpositions.  
- For any two target vertices \(a, b \in T\), we need \((a,b)\) to be in the generated subgroup. This is possible if and only if \(a\) and \(b\) are in the same connected component of the selected graph.  

Thus, the problem reduces to:  
Find the minimum total edge weight such that all vertices in \(T\) are connected.  

This is exactly the **Minimum Steiner Tree** problem on a graph with \(n\) vertices, but here the graph is a tree (since \(m = n-1\) and it's connected).  
For a tree, the minimum Steiner tree connecting a set of terminals is simply the union of all edges on the paths between terminals.  

So the solution is:  
1. Build the tree from the given edges.  
2. Mark the target vertices.  
3. Find the minimal subtree that connects all target vertices.  
4. Sum the weights of edges in that subtree.  

We can do this efficiently using DFS:  
- Root the tree arbitrarily.  
- For each node, compute if its subtree contains any target vertex.  
- An edge is needed if both sides contain at least one target vertex.  

Implementation:  

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    targets = set(map(int, input().split()))
    
    adj = [[] for _ in range(n+1)]
    edges = []
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
        edges.append((u, v, w))
    
    # DFS to find needed edges
    visited = [False] * (n+1)
    needed = [False] * (n+1)  # whether node is in the minimal subtree
    
    def dfs(u):
        visited[u] = True
        has_target = u in targets
        for v, w in adj[u]:
            if not visited[v]:
                child_has = dfs(v)
                if child_has:
                    needed[v] = True
                has_target = has_target or child_has
        return has_target
    
    # Start from any target
    start = next(iter(targets))
    dfs(start)
    
    total_cost = 0
    for u, v, w in edges:
        if needed[u] or needed[v]:
            total_cost += w
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
