Looking at this problem, I need to find the minimum cost subset of transpositions such that the generated subgroup contains all transpositions (a,b) for pairs a,b in T.

**Key Insight:** The transpositions form a tree (since m = n-1 and they generate S_n, meaning the graph is connected). For a set of transpositions forming a tree, the subgroup they generate is S_n restricted to the connected components. To get all transpositions (a,b) for a,b in T, all elements of T must be in the same connected component.

So the problem reduces to: find the minimum cost subset of edges (from a tree) such that all elements of T are in the same connected component.

**Approach:** 
- If |T| ≤ 1, answer is 0.
- Otherwise, I need to connect all T-elements. The minimum cost is the MST cost connecting all T-elements, but since we have a tree, I can use a Steiner tree approach.

For a tree, the minimum Steiner tree connecting a set of terminals can be found by:
1. Root the tree at any T-element
2. For each T-element, find path to root
3. Take union of all paths

But this might not be optimal. The optimal approach for Steiner tree on a tree: the minimum Steiner tree is the minimal subtree connecting all terminals. This can be found by:
- Mark all T-elements as terminals
- The answer is the sum of edges in the minimal subtree connecting all terminals

**Algorithm:**
1. Build the tree
2. Find the minimal subtree connecting all T-elements using a greedy approach: process edges, keep only edges that lie on paths between T-elements

A clean way: Use union-find with edges sorted by weight. For each edge, if it connects two components where at least one component has terminals, and after merging the combined component doesn't yet contain all terminals, we need this edge. Actually, this is Kruskal-like but for Steiner tree.

Actually, the correct approach for minimum Steiner tree on a tree:
- The minimal subtree connecting all terminals is unique (it's the union of all paths between pairs of terminals)
- We can find it by: for each node, check if its subtree contains any terminal. An edge is needed if both sides of the edge contain at least one terminal.

Let me implement this with DFS:

```python
import sys
from collections import defaultdict
import heapq

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    t = int(input_data[idx]); idx += 1
    
    T = set()
    for i in range(t):
        T.add(int(input_data[idx])); idx += 1
    
    if t <= 1:
        print(0)
        return
    
    adj = defaultdict(list)
    edges = []
    for i in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        w = int(input_data[idx]); idx += 1
        adj[u].append((v, w))
        adj[v].append((u, w))
        edges.append((u, v, w))
    
    # DFS to count terminals in each subtree
    # Root at first terminal
    root = next(iter(T))
    parent = {}
    parent_edge_weight = {}
    visited = set()
    stack = [(root, 0, False)]  # node, parent, processed
    order = []
    
    # Iterative DFS
    stack2 = [root]
    visited.add(root)
    parent[root] = 0
    
    while stack2:
        node = stack2.pop()
        order.append(node)
        for nb, w in adj[node]:
            if nb not in visited:
                visited.add(nb)
                parent[nb] = node
                parent_edge_weight[nb] = w
                stack2.append(nb)
    
    # Count terminals in subtree
    subtree_terminals = [0] * (n + 1)
    for node in T:
        subtree_terminals[node] = 1
    
    # Process in reverse order (leaves first)
    for node in reversed(order):
        p = parent[node]
        if p != 0:
            subtree_terminals[p] += subtree_terminals[node]
    
    # An edge (parent[node], node) is needed if subtree_terminals[node] > 0 
    # and (t - subtree_terminals[node]) > 0
    total = 0
    for node in order:
        if node == root:
            continue
        st = subtree_terminals[node]
        if st > 0 and (t - st) > 0:
            total += parent_edge_weight[node]
    
    print(total)

solve()
```
