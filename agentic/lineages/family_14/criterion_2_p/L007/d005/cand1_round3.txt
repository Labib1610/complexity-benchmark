<STATEMENT>
# Datacenter Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

A computing facility houses $n$ server racks, indexed from 1 to $n$. The facility is equipped with $m$ pre-wired bidirectional fiber-optic links. The infrastructure is fully interconnected, meaning that every single rack in the facility can reach any other rack through a sequence of connections. Because there are exactly $m = n - 1$ links providing this full reachability, there is exactly one unique, non-repeating communication route between any given pair of racks.

A customer has rented a specific group of $t$ racks. Each fiber-optic link has a specific activation expense to power on. The facility management will power on a link if and only if it lies on the unique communication route between at least one pair of distinct rented racks. Any link that does not serve as part of the route between any two rented racks will remain powered off. 

Each required link is powered on exactly once, and its activation expense is counted exactly once in the total, regardless of how many different pairs of rented racks use it for their communication route. If the customer has rented fewer than two racks, no pairs exist and no links will be powered on.

Your objective is to determine the total activation expense of all links that will be powered on.

## Input

The first line provides three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$).
The second line provides $t$ distinct integers, representing the indices of the rented racks.
The next $m$ lines each contain three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), indicating a pre-wired bidirectional link between rack $u$ and rack $v$ with an activation expense of $w$.

## Output

Output a single integer: the total activation expense of the links that will be powered on.

<RATIONALE>
I replaced the optimization framing ("minimum expense to connect rented racks") with a direct structural definition ("sum of expenses of links on the route between any pair of rented racks"). This forces the model to mathematically deduce that the union of pairwise paths in a tree is exactly the minimal spanning subtree, rather than relying on surface-level keyword matching to trigger a Steiner tree algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
In a tree, the union of all unique paths between pairs of nodes in a given subset forms exactly the minimal connected subgraph (Steiner tree) spanning that subset, so the exact same set of links is powered on and their total expense is identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying combinatorial object and required edges remain identical, so the problem is still solvable in linear time using a single depth-first search, keeping it in P.
</PRESERVED_CLASS>
<RISK>
The phrase "pair of distinct rented racks" might be misunderstood if a model considers ordered pairs vs unordered pairs, but since the route is undirected and identical in both directions, the set of links remains exactly the same either way.
</RISK>
