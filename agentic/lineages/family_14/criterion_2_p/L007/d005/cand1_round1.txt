<STATEMENT>
# Subspace Projection Alignment

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a homogeneous linear system over $\mathbb{R}^n$. The coordinates of the vectors are indexed from 1 to $n$.

You are provided with a pool of $m$ potential restriction equations. Each restriction is of the form $x_u - x_v = 0$ and carries an associated implementation penalty $w$. 

The full pool of $m$ restrictions is known to be linearly independent. Applying all of them reduces the solution space to exactly the 1-dimensional subspace spanned by the vector $(1, 1, \dots, 1)^T$. 

A client has specified a target index set $T$ containing $t$ distinct indices. Your objective is to select a subset of the restrictions to implement such that, for every vector $x$ in the resulting solution space, the condition $x_a = x_b$ holds for all $a, b \in T$. 

You must determine the minimum total implementation penalty of a subset of restrictions that successfully enforces this condition. Restrictions that are not selected impose no penalty and do not constrain the space.

## Input

The first line provides three integers $n$, $m$, and $t$. The dimension $n$ can reach up to two hundred thousand. The number of restrictions $m$ is exactly $n - 1$, guaranteeing linear independence. The target set size $t$ ranges from 1 up to the full dimension $n$.
The second line provides $t$ distinct integers, representing the indices in the target set $T$.
The next $m$ lines each contain three integers $u$, $v$, and $w$. Each line indicates a potential restriction $x_u - x_v = 0$ with an implementation penalty of $w$. The indices $u$ and $v$ are distinct and valid dimensions. The penalty $w$ is a positive integer bounded by one million.

## Output

Output a single integer: the minimum total implementation penalty of a subset of restrictions that ensures $x_a = x_b$ for all $a, b \in T$ in the resulting solution space.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```
