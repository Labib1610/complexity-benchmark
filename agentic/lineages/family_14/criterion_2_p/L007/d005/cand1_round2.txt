<STATEMENT>
# Equivalence Relation Enforcement

Time limit: 2 s   Memory limit: 256 MB

## Description

A formal system consists of $n$ variables, indexed from 1 to $n$. The system defines $m = n - 1$ potential bidirectional equivalence constraints. Applying a constraint between variable $u$ and variable $v$ mathematically forces $x_u = x_v$. The structure of these potential constraints is minimally complete: despite having only $n - 1$ constraints available, applying all of them forces all $n$ variables to be equal. Because it is minimal, there is exactly one unique logical deduction sequence between any given pair of variables.

You are given a specific target set of $t$ variables. Each equivalence constraint has a specific enforcement cost. Your objective is to determine the minimum total enforcement cost of a subset of constraints that must be applied so that every variable in the target set is mathematically forced to equal every other variable in the target set. Variables outside the target set may also be forced into this equivalence class if they are part of the intermediate deductions. Any constraint that is not required to maintain this mutual equality among the $t$ target variables can be left unapplied.

## Input

The first line provides three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$).
The second line provides $t$ distinct integers, representing the indices of the target variables.
The next $m$ lines each contain three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), indicating a potential bidirectional equivalence constraint between variable $u$ and variable $v$ with an enforcement cost of $w$.

## Output

Output a single integer: the minimum total enforcement cost of the constraints that must be applied to ensure all target variables are forced to be equal to each other.

## Examples

**Input**

**Output**

```
8
```

**Output**
```

```

<RATIONALE>
The problem was reframed from a datacenter network to a formal system of equivalence constraints. The exact tree property ("minimally complete" with "exactly one unique logical deduction sequence") is preserved, forcing the model to recognize the underlying graph structure from logical relations rather than standard networking keywords. All numeric bounds have been restored precisely to satisfy the strict I/O contract.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical task is identical: finding the minimum weight subset of edges (constraints) that connect a specific subset of nodes (target variables) in a given tree, yielding the exact same sum of weights for every input.
</PRESERVED_ANSWER>
