# Datacenter Activation

Time limit: 2 s   Memory limit: 256 MB

## Description

A datacenter contains **n** server racks, numbered 1 to **n**. You are evaluating a set of **m** available fiber conduits that can be activated. Each conduit connects two racks and has a specific activation cost.

A client has leased a specific subset of **t** racks. You must design a routing configuration by choosing a subset of the available conduits to activate. The chosen configuration must provide a communication path between every pair of leased racks. Data can be routed through unleased racks, which will act as pass-through switches if they are part of the activated configuration. You are free to select any combination of available conduits that satisfies the client's connectivity requirement. It is guaranteed that at least one valid configuration exists.

Determine the minimum total activation cost necessary to link all of the client's leased racks.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers representing the identifiers of the leased racks.
Each of the following **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating an available fiber conduit between rack **u** and rack **v** with an activation cost of **w**.

## Output

Print a single integer representing the minimum total activation cost to connect all leased racks.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Output**
```

```

### Example 3

```

2 3 5
```

**Output**
```

```
