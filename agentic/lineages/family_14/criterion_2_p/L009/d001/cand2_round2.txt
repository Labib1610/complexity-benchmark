# Freight Hub Upgrades

Time limit: 2 s   Memory limit: 256 MB

## Description

A regional railway network is composed of **n** stations and **m** direct track segments. The layout of the tracks guarantees that it is possible to travel between any two stations in the system.

The transport authority has identified **t** of these stations as freight hubs. To accommodate heavy cargo trains, a subset of the track segments must be reinforced. This reinforced subset must allow every freight hub to route trains to every other freight hub using exclusively the reinforced track segments. Reinforcing each track segment incurs a specific upgrade cost.

Determine the minimum total cost needed to reinforce the required track segments.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line contains **t** distinct integers representing the identifiers of the freight hubs.
Each of the following **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating a direct track segment between station **u** and station **v** with an upgrade cost of **w**.

## Output

Print a single integer: the minimum total cost to reinforce track segments such that all freight hubs are mutually connected via the reinforced tracks.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```

```

**Output**
```

```

### Example 3

**Input**
```

1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

The explicit statement that there is "exactly one sequence of direct track segments connecting any pair of stations" has been removed, as this directly handed the tree property to the models. Solvers must now deduce that the graph is a tree by combining the connectivity guarantee in the description with the `m = n - 1` constraint in the input bounds.
</RATIONALE>
<PRESERVED_ANSWER>
The graph remains a tree and the objective is still to find the minimum cost to connect a designated subset of vertices, meaning the unique minimal subtree spanning the hubs is identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains finding a Steiner tree on a graph that is intrinsically a tree, which is solvable in O(n) time via post-order traversal and subtree hub counting.
</PRESERVED_CLASS>
