 We can model the constraints as edges of a graph, where each edge has a cost.  
Since the whole graph is connected (because all variables can be proven equal using all constraints), we need to connect all critical variables with minimum cost.  

This is exactly the **Steiner tree** problem on a graph, but here the graph is a tree (since E = N − 1).  
For a tree, the minimum Steiner tree connecting a set of terminals is simply the minimal subtree that spans all terminals.  
The cost is the sum of edge weights in that minimal subtree.

We can find it by:
1. Marking all critical nodes.
2. Doing a DFS from any critical node, and keeping only edges that lead to at least one critical node in their subtree.
3. Summing the weights of those kept edges.

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    N, E, F = map(int, input().split())
    critical = set(map(int, input().split()))
    
    adj = [[] for _ in range(N+1)]
    for _ in range(E):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    visited = [False] * (N+1)
    
    def dfs(u, parent):
        visited[u] = True
        has_critical = u in critical
        total_cost = 0
        for v, w in adj[u]:
            if v == parent:
                continue
            if not visited[v]:
                sub_cost, sub_has = dfs(v, u)
                if sub_has:
                    total_cost += w + sub_cost
                    has_critical = True
        return total_cost, has_critical
    
    # Start from any critical node
    start = next(iter(critical))
    cost, _ = dfs(start, -1)
    print(cost)

if __name__ == "__main__":
    solve()
```
