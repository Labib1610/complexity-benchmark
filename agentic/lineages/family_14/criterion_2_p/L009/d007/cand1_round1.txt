<STATEMENT>
# Facility Ventilation Integration

Time limit: 2 s   Memory limit: 256 MB

## Description

An underground facility consists of **N** pressure chambers, labeled 1 through **N**.

The facility contains **E** potential ventilation shafts. Each shaft links a specific pair of chambers, **u** and **v**, requiring a known excavation effort of **w**. The geological survey confirms that if all **E** shafts were bored, the facility would be fully integrated (meaning air could circulate between any two chambers).

A specific subset of **F** chambers are designated as *vital*.

You must select a subset of the potential shafts to bore. Your selection must satisfy the **indivisibility condition**, which is evaluated as follows:
1. Consider any arbitrary assignment of the **N** chambers into two disjoint groups, Group A and Group B, such that every chamber is placed in exactly one of the two groups.
2. If Group A contains at least one vital chamber and Group B contains at least one vital chamber, this assignment is classified as a *vital split*.
3. Your selection of shafts is valid if and only if **every** possible vital split is crossed by at least one bored shaft from your selection. (A shaft crosses a split if one of its endpoints is in Group A and the other is in Group B.)

Determine the minimum total excavation effort required to form a valid selection of shafts. (If **F** = 1, there are no vital splits, so an empty selection is valid and requires 0 effort.)

## Input

The first line contains three integers **N**, **E**, and **F** (1 ≤ F ≤ N, 1 ≤ N ≤ 200000, E = N − 1).
The second line contains **F** distinct integers: the labels of the vital chambers.
Each of the following **E** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ N, u ≠ v, 1 ≤ w ≤ 1000000), representing a potential shaft between chamber **u** and chamber **v** with an excavation effort of **w**.

## Output

Print a single integer: the minimum total excavation effort required for a valid selection of shafts.

<METHOD_NAME>Dual Cut-Set Framing</METHOD_NAME>
<METHOD_DESCRIPTION>Replaced the path-based connectivity requirement with its dual cut-set formulation. Instead of asking to connect all vital nodes, the problem requires that every partition separating vital nodes is crossed by at least one selected edge. This mathematically equivalent condition avoids connectivity keywords and forces the model to deduce that crossing all vital cuts in a tree is synonymous with forming a minimal spanning subtree of the vital nodes.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<RATIONALE>
The problem was reframed from a path-based connectivity task to its dual cut-set formulation. By defining the goal as crossing all "vital splits" (partitions separating vital chambers), surface pattern matching for Steiner tree or MST algorithms is disrupted. To succeed, the model must now genuinely reason that in a tree structure, crossing all such cuts is mathematically identical to selecting the minimal subtree spanning the vital chambers.
</RATIONALE>
<PRESERVED_ANSWER>
By Menger's theorem and basic cut-set properties, a subset of edges in a tree crosses every partition separating vital nodes if and only if it connects all vital nodes, so the minimal valid subset and its cost remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the minimal subtree connecting a set of terminals in a tree, which is solvable in O(N) time via depth-first search or leaf pruning.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "every possible vital split" as requiring a global check that is computationally intractable, missing the deduction that the tree structure limits the fundamental cuts to exactly the edges of the tree.
</RISK>
