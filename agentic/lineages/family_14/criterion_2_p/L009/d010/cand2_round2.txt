<METHOD_NAME>Permutation Group Isomorphism</METHOD_NAME>
<METHOD_DESCRIPTION>Transforms the problem of finding a Steiner tree on a vector-span incidence matrix into finding a minimum-cost subset of transpositions that places a subset of elements into the same orbit. This exploits the isomorphism between connected components of a graph and the orbits of a permutation group generated by transpositions.</METHOD_DESCRIPTION>

<STATEMENT>
# Transposition Generator Optimization

Time limit: 2 s   Memory limit: 256 MB

## Description

You are working with a set of **N** distinct elements, labeled 1 through **N**.

You are given a catalog of **E** available transpositions. Each transposition swaps exactly two elements **u** and **v**, leaving all other elements fixed. Purchasing this transposition to add to your generating set incurs a cost of **w**.

It is guaranteed that the permutation group generated by the entire catalog of **E** transpositions acts transitively on the set of **N** elements. (That is, if you purchase all available transpositions, any element can be mapped to any other element by some sequence of swaps.)

A specific subset of **F** elements are designated as *critical*. Your task is to select a subset of the available transpositions to purchase such that, in the permutation group generated by your purchased subset, all **F** critical elements belong to the same orbit. That is, for any two critical elements $x$ and $y$, there must exist some permutation in the generated group that maps $x$ to $y$.

Determine the minimum total cost required to purchase a valid subset of transpositions. (If **F** = 1, the empty set of transpositions is sufficient, as the single critical element is trivially in its own orbit, so the minimum total cost is 0.)

## Input

The first line contains three integers **N**, **E**, and **F** (1 ≤ F ≤ N, 1 ≤ N ≤ 200000, E = N − 1).
The second line contains **F** distinct integers: the labels of the critical elements.
Each of the following **E** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ N, u ≠ v, 1 ≤ w ≤ 1000000), representing an available transposition that swaps elements **u** and **v**, and has a purchase cost of **w**.

## Output

Print a single integer: the minimum total cost required to purchase a subset of transpositions such that all critical elements are in the same orbit of the generated permutation group.

## Examples

**Output**

```

**Output**

```

<RATIONALE>
The seed problem posed a Steiner tree problem disguised as finding a linear span of vectors with +1 and -1 coordinates. The surviving models recognized that these vectors form the incidence matrix of a graph, and that $E = N-1$ implies a tree. To defeat this, the rewrite uses an exact mathematical isomorphism: the orbits of a permutation group generated by transpositions correspond directly to the connected components of a graph whose edges are those transpositions. A transitive group generated by $N-1$ transpositions is mathematically equivalent to a spanning tree. Models relying on surface patterns will fail to map this group-theoretic framing back to a simple tree traversal, while models that genuinely reason about algebraic structure will deduce the underlying tree properties.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that critical elements belong to the same orbit under the generated permutation group is mathematically identical to requiring that the selected edges form a connected component containing all critical vertices, so the optimal cost is unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Steiner tree problem on a tree, which is solvable in $O(N)$ time by rooting the structure and pruning subtrees that contain no critical elements.
</PRESERVED_CLASS>
