<STATEMENT>
# Subspace Span Optimization

Time limit: 2 s   Memory limit: 256 MB

## Description

You are working in an **N**-dimensional vector space over the real numbers. The space has a standard basis consisting of **N** independent basis vectors, denoted as $\mathbf{b}_1, \mathbf{b}_2, \dots, \mathbf{b}_N$.

You are given a catalog of **E** available difference vectors. Each difference vector is defined by a pair of indices **u** and **v**, and takes the form $\mathbf{d} = \mathbf{b}_u - \mathbf{b}_v$. Purchasing this vector for your set incurs a cost of **w**. (Note that purchasing $\mathbf{b}_u - \mathbf{b}_v$ is equivalent to purchasing $\mathbf{b}_v - \mathbf{b}_u$, as their linear span is identical; the order of the indices does not matter).

The catalog of available vectors is guaranteed to form a basis for the subspace of all vectors whose coordinates sum to zero.

A specific subset of **F** basis vectors are designated as *target* vectors. Your task is to select a subset of the available difference vectors to purchase such that the linear span of your purchased subset contains the vector $\mathbf{b}_x - \mathbf{b}_y$ for every pair of target vectors $\mathbf{b}_x$ and $\mathbf{b}_y$.

Determine the minimum total cost required to purchase a valid subset of difference vectors. (If **F** = 1, no vectors need to be purchased, so the minimum total cost is 0.)

The vector space is maintained by a simulator with a minimum dimension of 1 and a maximum dimension capacity of 200,000. The target set contains a minimum of 1 target vector and a maximum equal to the full dimension of the space. The catalog's size **E** is strictly equal to the dimension of the aforementioned zero-sum subspace. Each index **u** and **v** corresponds to a valid basis dimension, and no difference vector is formed by subtracting a basis vector from itself. The purchase cost **w** of any difference vector is a strictly positive integer, capped at a maximum of 1,000,000.

## Input

The first line contains three integers **N**, **E**, and **F**.
The second line contains **F** distinct integers: the indices of the target basis vectors.
Each of the following **E** lines contains three integers **u**, **v**, and **w**, representing an available difference vector $\mathbf{b}_u - \mathbf{b}_v$ with a purchase cost of **w**.

## Output

Print a single integer: the minimum total cost required to purchase a subset of difference vectors whose span satisfies the condition for all target vectors.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

```

```

**Output**
```
0
```

### Example 3

```

```

**Output**
```

```

<RATIONALE>
Removed the explicit `E = N - 1` bound and the explicit guarantee that all pairs are spanned. Instead, stated that the catalog forms a basis for the zero-sum subspace. This forces the model to algebraically deduce that the dimension is $N-1$, meaning $E=N-1$, and therefore the underlying structure is a tree, rather than relying on explicit graph-theoretic hints in the bounds.
</RATIONALE>
<PRESERVED_ANSWER>
The required span condition and the available vectors remain identical; a subset spanning the targets in the zero-sum subspace basis corresponds exactly to the minimal connecting subtree, keeping all costs the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the unique minimal subtree connecting a set of target vertices in a given tree, which is solvable in $O(N)$ time.
</PRESERVED_CLASS>
<RISK>
Models might struggle to parse the indirect bounds (e.g., "dimension of the aforementioned zero-sum subspace") into exact integer bounds for E, though any competent reader with linear algebra knowledge can deduce E = N - 1.
</RISK>
