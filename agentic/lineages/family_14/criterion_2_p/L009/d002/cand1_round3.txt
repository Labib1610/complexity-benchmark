# Freight Hub Upgrades

Time limit: 2 s   Memory limit: 256 MB

## Description

A regional transit system contains **N** stations and **E** track segments. The track segments are arranged so that the entire system is fully connected.

The transport authority has selected **F** stations to serve as priority freight hubs. They need to reinforce a subset of the track segments to handle heavy industrial trains. The chosen subset of reinforced segments must form a single connected network that includes all **F** priority hubs. Intermediate stations that are not priority hubs may be included in this reinforced network to help connect the hubs. Each track segment has a specific reinforcement cost.

Calculate the minimum total cost to reinforce a valid subset of track segments.

## Input

The first line contains three integers **N**, **E**, and **F**. 
- **N** is the total number of stations (there is at least a single station, up to a regional maximum of 200,000).
- **E** is the number of track segments (designed to be exactly one fewer than **N**).
- **F** is the number of priority hubs (at least one, up to all **N** stations).

The second line contains **F** distinct integers: the identifiers of the priority hubs.

Each of the following **E** lines contains three integers **u**, **v**, and **w**, describing a track segment between distinct stations **u** and **v** (using 1-based indexing up to **N**). The reinforcement cost **w** is at least 1 and bounded by a maximum municipal allowance of 1,000,000.

## Output

Print a single integer: the minimum total cost of reinforced track segments such that all priority hubs are in the same connected network of reinforced tracks.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1

```

**Output**
```
8
```

```

```

**Output**
```
9
```
