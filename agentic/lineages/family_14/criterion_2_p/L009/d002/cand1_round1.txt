# Freight Hub Upgrades

Time limit: 2 s   Memory limit: 256 MB

## Description

A regional railway network is composed of **N** stations and **E** track segments. The infrastructure was designed so that every station can be reached from any other station, but without any redundant loops, meaning there is exactly one sequence of segments between any two stations.

The transport authority has selected **F** stations to serve as priority freight hubs. They need to reinforce a subset of the track segments to handle heavy industrial trains. The chosen subset of segments must ensure cargo can travel between any pair of priority hubs using exclusively reinforced segments. Each track segment has a specific reinforcement cost.

Determine the minimum total cost to reinforce a valid subset of track segments.

## Input

The first line provides three integers **N**, **E**, and **F**. The network registry supports a minimum of one and a maximum capacity of two hundred thousand stations (**N**). The number of designated hubs (**F**) requires at least one station and can include up to every station in the registry. The segment count (**E**) perfectly matches the minimum structural requirement to connect all **N** stations without forming any closed loops.

The second line contains **F** distinct integers representing the identifiers of the priority hubs.

Each of the following **E** lines contains three integers **u**, **v**, and **w**. The endpoints **u** and **v** are distinct stations indexed from 1 to **N**. The reinforcement expense **w** costs at least one monetary unit and cannot exceed the municipal cap of one million.

## Output

Print a single integer: the minimum total cost to reinforce track segments such that all priority hubs are connected to each other via reinforced tracks.
