<STATEMENT>
# Output Variable Unification

Time limit: 2 s   Memory limit: 256 MB

## Description

A formal verification system contains **N** independent variables, indexed 1 through **N**.

There are **E** equality axioms available to be added to the system's knowledge base. Each axiom establishes that variable **u** is equal to variable **v** ($X_u = X_v$), and requires a one-time memory allocation of **w** bytes to store.

The full set of available axioms provides complete algebraic collapse: if all **E** axioms were stored in the knowledge base, a proof could be constructed showing that all **N** variables are equal to each other. The axiom set contains no circular dependencies or redundancies.

A specific subset of **F** variables are designated as *output* variables. You must choose a single subset of the available axioms to permanently store in the knowledge base so that the system can mathematically prove that all output variables share the same value. (Proofs may use transitivity through non-output variables, provided the corresponding axioms are stored).

Determine the minimum total memory allocation required to guarantee all output variables are equal. (If **F** = 1, no axioms need to be stored, so the minimum total allocation is 0.)

## Input

The first line contains three integers **N**, **E**, and **F**. The compiler allocates up to two hundred thousand variable slots for **N**. The count of output variables **F** is at least one, and bounded above by the total variable count. Because the axioms form a minimal complete foundation for equality, their total count **E** is exactly the variable count minus one.
The second line contains **F** distinct integers: the indices of the output variables.
Each of the following **E** lines contains three integers **u**, **v**, and **w**. These denote an available axiom stating that variable **u** equals variable **v** (which are always distinct positive integers bounded by the total number of variables) requiring **w** bytes of memory. The memory footprint for any single axiom is a positive integer that never exceeds one million bytes.

## Output

Print a single integer: the minimum total memory allocation required to ensure all output variables can be proven equal.
