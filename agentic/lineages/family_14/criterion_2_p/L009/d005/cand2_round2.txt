# Market Consolidation

Time limit: 2 s   Memory limit: 256 MB

## Description

An industry consists of **N** independent corporations, labeled 1 through **N**.

There are **E** potential bilateral merger agreements available. Each agreement allows corporation **u** and corporation **v** to merge, forming a single joint entity. The legal restructuring cost to execute this specific merger is **w**.

When mergers are executed, the involved corporations (and any entities they have already merged with) consolidate into a larger conglomerate. This consolidation is transitive: if corporation A merges with B, and B merges with C, then A, B, and C all belong to the exact same conglomerate.

The full set of available mergers is structurally minimal: if every available agreement were executed, the entire industry would consolidate into a single monopoly, but removing even one agreement from the full set would permanently leave at least two separate entities.

A subset of **F** corporations are identified as *flagship brands*. You must select a subset of the available merger agreements to execute such that all **F** flagship brands are ultimately consolidated into the exact same conglomerate. (Non-flagship corporations may also be absorbed into this conglomerate as a byproduct of the selected mergers).

Determine the minimum total legal cost required to execute such a subset of mergers.

## Input

The first line contains three integers **N**, **E**, and **F** (1 ≤ F ≤ N, 1 ≤ N ≤ 200000, E = N − 1).
The second line contains **F** distinct integers: the labels of the flagship brands.
Each of the following **E** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ N, u ≠ v, 1 ≤ w ≤ 1000000), representing an available merger agreement between corporation **u** and corporation **v** with an execution cost of **w**.

## Output

Print a single integer: the minimum total cost required to execute a valid subset of mergers such that all flagship brands are consolidated into the same conglomerate.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```

```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

<RATIONALE>
The problem was completely rewritten to use a corporate merger domain. By describing the connectivity requirement as "transitive consolidation into a conglomerate," the text perfectly mimics the standard pedagogical framing of Disjoint Set Union (DSU) and Kruskal's algorithm. Models that pattern-match this semantic domain will likely attempt a greedy edge-sorting approach, which incorrectly adds cheap irrelevant edges and fails for Steiner trees. To succeed, models must look past the DSU terminology and recognize the underlying tree structure and path-dependency.
</RATIONALE>
<PRESERVED_ANSWER>
The input graph is a tree (E=N-1 and structurally minimal), so there is a unique minimal subset of edges that connects any given subset of nodes; the minimum cost to consolidate the flagship brands is exactly the sum of weights of this unique spanning subtree, identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the Steiner tree on a given tree, which is solvable in linear or O(N log N) time by pruning non-required leaves or using LCA, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "minimum total cost" as allowing the creation of multiple separate conglomerates as long as the flagships are in one, but this is explicitly intended and mathematically equivalent to the Steiner tree objective (ignoring disconnected components costs nothing).
</RISK>
