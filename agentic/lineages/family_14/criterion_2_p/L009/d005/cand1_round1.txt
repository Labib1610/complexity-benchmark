<METHOD_DESCRIPTION>Transforms a graph connectivity problem into a permutation group reachability problem. Edges become array transpositions, and path-finding becomes the ability to move an item between positions using a sequence of swaps. <STATEMENT>
# Transposition Subset

Time limit: 2 s   Memory limit: 256 MB

## Description

You have an array of **N** distinct items, initially located at positions 1 through **N**.

There is a pool of **E** optional swap operations available. Operation $i$ allows you to swap the items currently at position **u** and position **v**. You can permanently unlock this operation by paying a one-time fee of **w**. Once unlocked, the operation can be executed an unlimited number of times, in any order, alongside any other unlocked operations.

The full pool of operations is minimally comprehensive: if all **E** operations are unlocked, it is possible to rearrange the array into any arbitrary permutation. Furthermore, if you were to permanently remove any single operation from the full pool, there would be some permutations that become impossible to reach.

A subset of **F** positions are designated as critical. You must unlock a single subset of the available operations such that, for every pair of critical positions $a$ and $b$, there exists a sequence of unlocked operations that moves an item from position $a$ to position $b$. (If **F** = 1, this requirement is trivially satisfied without unlocking any operations). 

Determine the minimum total fee required to unlock a valid subset of operations.

## Input

The first line contains three integers **N**, **E**, and **F** (1 ≤ F ≤ N, 1 ≤ N ≤ 200000, E = N − 1).
The second line contains **F** distinct integers: the labels of the critical positions.
Each of the following **E** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ N, u ≠ v, 1 ≤ w ≤ 1000000), representing an available operation that swaps position **u** and position **v** with an unlock fee of **w**.

## Output

Print a single integer: the minimum total fee required to unlock a subset of operations that satisfies the condition for all critical positions.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```
</STATEMENT>
<RATIONALE>
I completely reframed the problem using permutation group theory instead of a sensor network. By presenting the edges as transposition operations that swap items at specific positions, the condition of "finding a subtree that connects critical nodes" is transformed into "unlocking a subset of swaps that allows moving an item between any two critical positions". This forces models to bridge the conceptual gap between sequence permutations and graph connectivity before they can apply the tree-pruning shortcut.
</RATIONALE>
<PRESERVED_ANSWER>
Reachability between positions via a sequence of swaps is mathematically identical to connectivity in the graph defined by those swaps, meaning the exact same minimal spanning subtree of critical nodes is required.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Steiner tree problem on a tree (which is polynomial and solvable in O(N)), as the input structure and minimal-connectivity requirements are isomorphic to the original graph.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "rearrange the array into any arbitrary permutation" as requiring the unlocked subset itself to generate the full symmetric group, but the prompt explicitly restricts this requirement to the *full pool* of operations, making the actual task unambiguous.
</RISK>
