# Transit Network Upgrade

Time limit: 2 s   Memory limit: 256 MB

## Description

A research facility consists of **N** workstations and **E** bidirectional transit tubes. Each transit tube connects exactly two workstations. The tubes provide a fully connected network, meaning any workstation can be reached from any other workstation through some sequence of tubes.

A subset of **F** workstations are designated as high-priority terminals. The administration wants to upgrade a subset of the transit tubes to form a dedicated high-speed subnetwork. This upgraded subnetwork must be contiguous and must include all **F** high-priority terminals, ensuring that data can flow between any two high-priority terminals using only the upgraded tubes. It is permissible for the upgraded subnetwork to route through workstations that are not high-priority.

Each transit tube has a known upgrade cost. Your task is to determine the minimum possible total cost to upgrade a valid subset of tubes that interconnects all high-priority terminals.

## Input

The first line contains three integers **N**, **E**, and **F** (1 ≤ F ≤ N, 1 ≤ N ≤ 200000). To ensure a minimally connected topology, the number of transit tubes **E** is always exactly one less than the number of workstations.
The second line contains **F** distinct integers: the identifiers of the high-priority terminals.
Each of the following **E** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ N, u ≠ v, 1 ≤ w ≤ 1000000), representing a transit tube between workstation **u** and workstation **v** with an upgrade cost of **w**.

## Output

Print a single integer: the minimum total cost to upgrade a subset of tubes such that all high-priority terminals are connected exclusively via upgraded tubes.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```
