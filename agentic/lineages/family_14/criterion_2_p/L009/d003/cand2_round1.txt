# Water Distribution Network

Time limit: 2 s   Memory limit: 256 MB

## Description

A regional water system consists of **N** pumping stations and **E** bidirectional pipelines. Every station can exchange water with any other station through a sequence of pipelines. The system has exactly enough pipelines so that the removal of any single pipeline would leave some stations unable to reach each other.

A drought has occurred, and a specific group of **F** stations designated as primary reservoirs must remain operational. You must select a subset of pipelines to keep open, shutting down all others. The chosen open pipelines must connect all primary reservoirs together, meaning water can flow between any two primary reservoirs exclusively through the open pipelines. (Non-primary stations may act as junctions along these open pipelines).

Keeping a pipeline open incurs a daily operational cost. Find the minimum total daily cost to keep a valid subset of pipelines open.

## Input

The first line contains three integers **N**, **E**, and **F**.
- The number of stations **N** is constrained by a minimum of 1 and a regional licensing maximum of 200,000.
- The number of pipelines **E** is exactly the quantity dictated by the critical connectivity property described above.
- The number of primary reservoirs **F** is bounded by a minimum of 1 and a maximum of **N**.

The second line contains **F** distinct integers: the identifiers of the primary reservoirs. Stations are identified by numbers from 1 to **N**.

Each of the following **E** lines contains three integers **u**, **v**, and **w**. These indicate a pipeline between distinct stations **u** and **v** with a daily operational cost **w** (a positive integer capped at a municipal limit of 1,000,000).

## Output

Print a single integer: the minimum total daily cost required such that all primary reservoirs are linked exclusively via the open pipelines.

## Examples

### Example 1

**Input**
```

```

**Output**

```
8
```

```

```

<RATIONALE>
The explicit bounds `E = N - 1` and the terminology "continuous tapestry" were removed to prevent models from trivially triggering tree-specific algorithms via surface pattern matching. Instead, the tree structure and the exact value of `E` are established through a physical property of the network (it is fully connected, but every edge is a bridge). Models must now genuinely reason about this connectivity constraint to deduce that the graph is a tree and apply the O(N) Steiner tree on a tree algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The task still requires finding the minimum weight subgraph that connects a given subset of vertices in what is mathematically identical to the original tree, so the optimal cost is exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a Steiner tree on a tree, which is solvable in polynomial time (O(N)) because the unique path property of trees makes the minimal connecting subtree unique.
</PRESERVED_CLASS>
