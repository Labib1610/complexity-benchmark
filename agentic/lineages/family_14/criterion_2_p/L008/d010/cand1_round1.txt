<METHOD_DESCRIPTION>Replaces the static graph property "connected" with a dynamic "cascade process" that computes the convex hull of an initially chosen set, shifting the model's focus from finding a minimal subtree to optimizing the initial state of a diffusion process.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Resonance Containment

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a system of $R$ distinct resonant zones. These zones interact through $S$ bidirectional harmonic corridors. The corridors are established such that all zones are interconnected, and there is exactly one sequence of corridors between any pair of zones without repeating a zone. This sequence is called the *resonance path* between the two zones.

You need to trigger a resonance cascade. You do this by selecting an initial set of zones to manually activate. 

Once the initial zones are activated, the system undergoes an automatic *cascade process*:
If any two activated zones have a zone on their resonance path that is not yet activated, that intermediate zone will automatically become activated. This automatic activation continues until no new zones can be activated. The system then reaches its *final active state*.

A recent protocol requires that a specific set of $P$ mandated zones must be present in the final active state. 

Activating zones incurs a penalty based on the corridors. Each harmonic corridor has a characteristic penalty $w$. If both zones associated with a corridor end up activated in the final active state, the corridor becomes "saturated" and adds its penalty $w$ to the total system cost. If one or neither of the associated zones is in the final active state, the corridor remains dormant and contributes 0 to the total cost.

You may choose any initial set of zones to manually activate. Your objective is to determine the minimum possible total penalty of the saturated corridors in the final active state, such that all $P$ mandated zones are in the final active state.

## Input

The first line contains three integers $R$, $S$, and $P$. 
The total number of zones $R$ satisfies $1 \le R \le 200000$. 
The number of harmonic corridors $S$ is exactly equal to $R - 1$. 
The number of mandated zones $P$ satisfies $1 \le P \le R$.

The second line contains $P$ distinct integers representing the identifiers of the mandated zones.

Each of the following $S$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le R$, $u \neq v$). This indicates a harmonic corridor between zone $u$ and zone $v$ with a characteristic penalty of $w$ ($1 \le w \le 1000000$). 

## Output

Output a single integer representing the minimum possible total penalty of the saturated corridors under the given conditions.

</STATEMENT>
<RATIONALE>
The static property "connected" (previously "synchronous") has been replaced with a dynamic "cascade process" that effectively computes the convex hull of the initially activated set. This forces the model to realize that the minimal valid final state is exactly the closure of the mandated nodes, rather than simply matching the problem to a standard subtree-pruning template. Models that attempt to simulate the cascade or optimize the initial set will fail or time out.
</RATIONALE>
<PRESERVED_ANSWER>
The cascade process ensures the final active state contains all paths between its elements, which in this structure means it forms a connected subgraph; since all corridor penalties are positive, the minimum cost connected subgraph containing the mandated zones remains exactly the minimal spanning subtree.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires finding the total weight of the minimal subtree containing a set of required vertices, which remains solvable in O(N) time by leaf pruning or bottom-up tree traversal.
</PRESERVED_CLASS>
