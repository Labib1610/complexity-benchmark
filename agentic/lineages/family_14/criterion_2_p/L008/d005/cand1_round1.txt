<METHOD_NAME>Algebraic Subspace Isomorphism</METHOD_NAME>
<METHOD_DESCRIPTION>Transforms a graph connectivity problem into an equivalent linear algebra problem by mapping edges to basis vectors $e_u - e_v$ and connected components to the linear span containing $e_i - e_j$. This removes all "tree" and "routing" terminology, forcing models to either perform a complex conceptual translation or fall into an $O(P^2)$ path-finding trap that exceeds the time limit.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Phase 2: Basis Subspace Span

Time limit: 2 s   Memory limit: 256 MB

## Description

You are studying a vector space over $\mathbb{R}$ with a standard basis $e_1, e_2, \dots, e_R$.
You are provided with a pool of $S$ available vectors. Each available vector is of the form $e_u - e_v$. 
Including a specific vector $e_u - e_v$ in your chosen subset incurs an inclusion cost of $w$.

During evaluation, a set of $P$ target indices is identified. 
You must choose a subset of the available vectors such that, for every pair of indices $i$ and $j$ (not necessarily distinct) in the target set, the vector $e_i - e_j$ is contained within the linear span of your chosen subset. 

Find the minimum possible total inclusion cost of the chosen subset. The total inclusion cost is the sum of the costs of the distinct vectors you have chosen.

## Input

The first line contains three integers $R$, $S$, and $P$. The dimension $R$ is constrained by a maximum of $200,000$. The number of available vectors $S$ is always exactly $R - 1$. The number of target indices $P$ satisfies $1 \le P \le R$.
The second line contains $P$ distinct integers: the target indices.
Each of the next $S$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le R$, $u \neq v$). This represents an available vector $e_u - e_v$ (note that its linear span is identical to that of $e_v - e_u$) with an inclusion cost of $w$ ($1 \le w \le 1,000,000$). 
The pool of $S$ vectors provided in the input is guaranteed to be a basis for the subspace of all vectors in $\mathbb{R}^R$ whose coordinates sum to zero. Thus, if all $S$ vectors were chosen, their linear span would contain $e_i - e_j$ for all $1 \le i, j \le R$.

## Output

Print a single integer: the minimum total inclusion cost of the chosen subset of vectors.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**

**Output**
```

```

### Example 3

**Input**
```

```

**Output**
```
9
```
</STATEMENT>
<RATIONALE>
I completely reframed the problem from network routing ("signals converging at a node") into linear algebra ("vectors in a linear span"). 
By changing the edges to basis vectors of the form $e_u - e_v$ and the connectivity requirement to "the span contains $e_i - e_j$", the underlying mathematical structure (a tree) is perfectly preserved (as the given vectors form a basis for the zero-sum subspace). 
However, this framing removes the intuitive "tree leaves" or "routing paths" concepts. This forces models to either perform a difficult conceptual translation back to tree-pruning, or fall into writing a naive $O(P^2)$ linear-combination path-finding algorithm that will fail the time limit.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that $e_i - e_j$ is in the linear span of a subset of $\{e_u - e_v\}$ is mathematically equivalent to $i$ and $j$ being in the same connected component of the corresponding graph, so the optimal subset and its cost remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is still equivalent to finding the minimal subtree connecting a set of target nodes in a given tree, which can be solved in $O(N)$ time by counting targets per subtree, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the vector form as implying they must track signs or directionality, but the explicit note that the linear span is identical to $e_v - e_u$ clarifies that it behaves as an unoriented pair.
</RISK>
