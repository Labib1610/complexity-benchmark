# Phase 2: High-Priority Routing

Time limit: 2 s   Memory limit: 256 MB

## Description

A cybersecurity firm is upgrading a facility's hardware. This project is divided into three distinct phases:

**Phase 1: Facility Survey.** Engineers map out the available bidirectional conduit segments between $n$ equipment rooms (numbered 1 to $n$). While industrial networks often contain redundant loops, the engineers simply verify that the mapped segments form a fully connected network, ensuring every room can reach any other room. 

**Phase 2: Cable Planning.** You are responsible for this phase. The client has designated $t$ specific rooms as high-priority. These high-priority rooms must all be able to exchange data with one another, either directly or by passing data through a sequence of intermediate rooms. You are given the cost of installing fiber optic cable in each mapped conduit segment. You must choose a subset of the available segments to cable such that the high-priority rooms are all interconnected. Calculate the minimum possible total installation cost to achieve this connectivity.

**Phase 3: Procurement.** The finance department takes your calculated minimum cost, adds a 20% markup for price fluctuations, and approves the final budget.

Your task is to write a program that executes Phase 2. Given the network topology from Phase 1 and the list of high-priority rooms, output the exact minimum cost before any Phase 3 markups are applied.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$, $m = n - 1$).
The second line contains $t$ distinct integers: the identifiers of the high-priority rooms.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$): a conduit segment joining room $u$ and room $v$ at an installation cost of $w$. 
The segments provided in the input are guaranteed to satisfy the connectivity verified in Phase 1.

## Output

Print a single integer: the minimum total cost calculated in Phase 2.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

<RATIONALE>
I removed the explicit statement that there is "exactly one continuous route" between rooms, which handed the models the tree property directly. Instead, I framed the topology as a general network that only guarantees connectivity, forcing models to deduce from the input bound $m = n - 1$ that the network is actually a tree in order to avoid attempting an intractable general Steiner connectivity algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The objective is still to find the minimum cost to connect the high-priority rooms, and since the input graph is always a tree, the optimal solution remains the unique minimal spanning subtree.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains solvable in $O(n)$ time because the implicit guarantee of $m = n - 1$ connected edges ensures the graph is a tree, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might interpret the mention of "redundant loops" as a guarantee that cycles exist, conflicting with $m = n - 1$, but careful reading shows it only states loops "often" exist in such networks, not necessarily in this specific input.
</RISK>
