We are given a tree (since m = n - 1 and it’s connected), and we need to connect all high-priority nodes with minimum total edge cost.  

The minimal subgraph connecting a set of nodes in a tree is the **Steiner tree** for those nodes, which in a tree is simply the union of all paths between them. The cost is the sum of weights of edges in that union.

A standard way:  
- Mark all high-priority nodes.  
- Do a DFS/BFS from any high-priority node, and compute the total weight of edges that are on paths between high-priority nodes.  
- Equivalently, remove all leaves that are not high-priority iteratively; the remaining edges are exactly those needed.

We can do this efficiently with a queue-based leaf pruning:

1. Build adjacency list with edge weights.
2. Track degree of each node.
3. Initialize queue with all leaves (degree 1) that are **not** high-priority.
4. While queue not empty:
   - Pop node, mark as removed.
   - For each neighbor not removed, decrement its degree.
   - If that neighbor becomes a leaf and is not high-priority, push it.
5. After pruning, sum weights of edges where both endpoints are not removed.

This runs in O(n).

```python
import sys
from collections import deque

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    high = set(map(int, input().split()))
    
    adj = [[] for _ in range(n + 1)]
    deg = [0] * (n + 1)
    edges = []
    
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
        deg[u] += 1
        deg[v] += 1
        edges.append((u, v, w))
    
    removed = [False] * (n + 1)
    q = deque()
    
    for i in range(1, n + 1):
        if deg[i] == 1 and i not in high:
            q.append(i)
    
    while q:
        u = q.popleft()
        if removed[u]:
            continue
        removed[u] = True
        for v, w in adj[u]:
            if not removed[v]:
                deg[v] -= 1
                if deg[v] == 1 and v not in high:
                    q.append(v)
    
    total = 0
    for u, v, w in edges:
        if not removed[u] and not removed[v]:
            total += w
    
    print(total)

if __name__ == "__main__":
    solve()
```
