# Architectural Core Cluster

Time limit: 2 s   Memory limit: 256 MB

## Description

An industrial facility contains $R$ logic modules, interconnected by $S$ bidirectional data linkages. 
A recent directive requires you to assign an operational state—either *Unified* or *Standard*—to each of the $R$ modules.

This state assignment must satisfy the following rules:
1. All $P$ of the mandated priority modules must be assigned the *Unified* state. (Other modules may also be assigned the *Unified* state).
2. The *Unified* modules must form a contiguous block. Specifically, for any two modules assigned the *Unified* state, it must be possible to transmit data between them using exclusively linkages that connect two *Unified* modules.

The facility's network architecture guarantees that information between any two modules flows through exactly one unique sequence of linkages. 

Whenever two modules that share a physical linkage are both assigned the *Unified* state, that linkage becomes active and incurs its synchronization overhead. Linkages where at least one endpoint is assigned the *Standard* state remain dormant and incur no overhead.

Your objective is to determine the minimum possible total synchronization overhead of the active linkages required to establish a valid state assignment.

## Input

The first line contains three integers $R$, $S$, and $P$. 
The total number of modules $R$ satisfies $1 \le R \le 200,000$. 
The number of linkages $S$ is exactly equal to $R - 1$. 
The number of priority modules $P$ satisfies $1 \le P \le R$.

The second line contains $P$ distinct integers: the identifiers of the priority modules.

Each of the following $S$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le R$, $u \neq v$). This indicates a bidirectional linkage between module $u$ and module $v$ with a synchronization overhead of $w$ ($1 \le w \le 1,000,000$). 

## Output

Output a single integer representing the minimum total synchronization overhead incurred by a valid state assignment.

## Examples

```

**Output**

```

**Output**
```
9
```

<METHOD_NAME>
State Assignment Framing
</METHOD_NAME>
<METHOD_DESCRIPTION>
Reframes the problem from explicitly finding a minimum-cost contiguous integration network to assigning binary states (Unified/Standard) to nodes, where edges between Unified nodes become active and incur cost. By removing the explicit sentence that equates this to finding a minimum-cost network, it forces the model to independently deduce that minimizing the cost of this contiguous state assignment on a graph with unique paths is equivalent to finding the minimal spanning subtree of the priority nodes.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<RATIONALE>
I removed the explicit statement that equated the objective to identifying a minimum-cost contiguous integration network encompassing the mandates. By framing the problem purely as a node state assignment with adjacency penalties, models that rely on recognizing explicit network-routing or Steiner-tree phrasing will fail, as they must now independently deduce the equivalence.
</RATIONALE>
<PRESERVED_ANSWER>
The cost of a state assignment where $P$ specific nodes are Unified and connected is exactly the sum of edges in the induced subgraph of Unified nodes, which on a tree is exactly the subtree spanning those $P$ nodes, yielding the exact same minimum cost.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying graph remains a tree where we need to find the minimum cost to connect a subset of nodes, meaning the O(N) tree pruning or tree DP algorithms still apply perfectly.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "contiguous block" if they fail to read the clarifying sentence that explicitly defines it as being connected via linkages between Unified modules, though the definition is rigorous.
</RISK>
