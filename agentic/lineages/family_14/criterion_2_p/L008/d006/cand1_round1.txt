# Phase 2: Schema Synchronization

Time limit: 2 s   Memory limit: 256 MB

## Description

You are optimizing a relational database containing a number of tables. There are symmetric foreign-key relationships between certain pairs of tables. 

A business requirement specifies a set of core tables that must be present in your deployment. You must select a subset of tables (a "schema") that satisfies two conditions:
1. The schema must include all of the required core tables (it may also include any number of other tables).
2. The schema must be *fully joined*. A schema is considered fully joined if it is impossible to partition its tables into two non-empty subsets $A$ and $B$ such that no relationship exists between any table in $A$ and any table in $B$.

When you deploy your schema, every relationship whose both endpoint tables are included in the schema becomes active. Relationships involving one or zero tables in the schema remain inactive. 

Each relationship has a specific synchronization latency. The total latency of your deployed schema is the sum of the synchronization latencies of all active relationships. Find the minimum possible total latency to deploy a valid schema.

The full database of tables is known to be fully joined. Furthermore, the total number of relationships in the database is exactly the theoretical minimum necessary to ensure this property holds for the given number of tables.

## Input

The first line contains three integers $R$, $S$, and $P$. 
The total number of tables $R$ is constrained by system memory to be at least one and at most two hundred thousand. 
The integer $S$ represents the number of relationships; as described, it is always exactly the mathematical minimum required to keep $R$ tables fully joined. 
The number of core tables $P$ is at least one and cannot exceed the total number of tables.

The second line contains $P$ distinct integers: the identifiers of the core tables.

Each of the next $S$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le R$, $u \neq v$). This represents a symmetric relationship between table $u$ and table $v$ with a synchronization latency $w$. The latency $w$ is at least one and capped at one million.

## Output

Print a single integer: the minimum total synchronization latency of a valid schema.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Output**
```

```

### Example 3

**Input**
```

```

**Output**
```
9
```
