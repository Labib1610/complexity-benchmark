# Phase 2: High-Priority Routing

Time limit: 2 s   Memory limit: 256 MB

## Description

A cybersecurity firm is retrofitting a secure data center's communication infrastructure. This project is divided into three distinct phases:

**Phase 1: Facility Survey.** Engineers map out $S$ available bidirectional fiber-optic corridors between $R$ security vaults (numbered 1 to $R$). The engineers verify that these mapped corridors provide exactly one valid routing sequence between any two vaults in the facility, ensuring complete reachability without any cyclic redundancies.

**Phase 2: Cable Planning.** You are responsible for this phase. The client has designated $P$ specific vaults as critical. These critical vaults must all be able to exchange data with one another, either directly or by passing data through a sequence of intermediate vaults. You are given the cost of activating the fiber-optic cable in each mapped corridor. You must choose a subset of the available corridors to activate such that the critical vaults are all seamlessly linked. Calculate the minimum possible total activation cost to achieve this requirement.

**Phase 3: Procurement.** The finance department takes your calculated minimum cost, adds a 20% markup for price fluctuations, and approves the final budget.

Your task is to write a program that executes Phase 2. Given the survey data from Phase 1 and the list of critical vaults, output the exact minimum cost before any Phase 3 markups are applied.

## Input

The first line contains three integers $R$, $S$, and $P$. The facility's architectural limit allows a maximum of 200000 security vaults (meaning $1 \le R \le 200000$). There is always at least 1 critical vault, and $P$ cannot exceed $R$ ($1 \le P \le R$). Because there is exactly one routing sequence between any two vaults, the number of corridors $S$ is always exactly $R - 1$.
The second line contains $P$ distinct integers: the identifiers of the critical vaults.
Each of the next $S$ lines contains three integers $u$, $v$, and $w$. This indicates a corridor between vault $u$ and vault $v$ (where $1 \le u, v \le R$, $u \neq v$) with an activation cost of $w$. The activation cost $w$ is constrained by a minimum of 1 and a maximum budget of 1000000 per corridor ($1 \le w \le 1000000$).
The corridors provided in the input are guaranteed to satisfy the strict non-redundant connectivity described in Phase 1.

## Output

Print a single integer: the minimum total activation cost calculated in Phase 2.
