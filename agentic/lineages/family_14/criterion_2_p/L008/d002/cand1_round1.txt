# Phase 2: High-Priority Routing

Time limit: 2 s   Memory limit: 256 MB

## Description

A cybersecurity firm is upgrading a facility's hardware. This project is divided into three distinct phases:

**Phase 1: Facility Survey.** Engineers map out $S$ available bidirectional conduit segments between $R$ equipment rooms (numbered 1 to $R$). The engineers verify that these mapped segments provide a valid communication path between any two rooms in the facility. 

**Phase 2: Cable Planning.** You are responsible for this phase. The client has designated $P$ specific rooms as high-priority. These high-priority rooms must all be able to exchange data with one another, either directly or by passing data through a sequence of intermediate rooms. You are given the cost of installing fiber optic cable in each mapped conduit segment. You must choose a subset of the available segments to cable such that the high-priority rooms are all interconnected. Calculate the minimum possible total installation cost to achieve this requirement.

**Phase 3: Procurement.** The finance department takes your calculated minimum cost, adds a 20% markup for price fluctuations, and approves the final budget.

Your task is to write a program that executes Phase 2. Given the survey data from Phase 1 and the list of high-priority rooms, output the exact minimum cost before any Phase 3 markups are applied.

## Input

The first line contains three integers $R$, $S$, and $P$ ($1 \le P \le R \le 200000$). The number of segments $S$ is always exactly $R - 1$.
The second line contains $P$ distinct integers: the identifiers of the high-priority rooms.
Each of the next $S$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le R$, $u \neq v$, $1 \le w \le 1000000$): a conduit segment joining room $u$ and room $v$ at an installation cost of $w$. 
The segments provided in the input are guaranteed to satisfy the communication paths verified in Phase 1.

## Output

Print a single integer: the minimum total cost calculated in Phase 2.
