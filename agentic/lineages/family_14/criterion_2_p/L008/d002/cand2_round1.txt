# Phase 2: High-Priority Routing

Time limit: 2 s   Memory limit: 256 MB

## Description

A cybersecurity firm is upgrading a facility's hardware. This project is divided into three distinct phases:

**Phase 1: Facility Survey.** Engineers map out the available bidirectional conduit segments between equipment rooms. The facility contains anywhere from one to two hundred thousand equipment rooms (numbered starting from 1). The engineers verify that the mapped segments form a fully connected network, ensuring every room can reach any other room. To minimize initial construction costs, the original builders installed exactly one fewer conduit segment than the total number of rooms.

**Phase 2: Cable Planning.** You are responsible for this phase. The client has designated a certain number of rooms as high-priority, ranging anywhere from a single room up to the entire facility. These high-priority rooms must all be able to exchange data with one another, either directly or by passing data through a sequence of intermediate rooms. You are given the cost of installing fiber optic cable in each mapped conduit segment. The installation cost for any single segment is a positive integer that never exceeds one million. You must choose a subset of the available segments to cable such that the high-priority rooms are all interconnected. Calculate the minimum possible total installation cost to achieve this connectivity.

**Phase 3: Procurement.** The finance department takes your calculated minimum cost, adds a 20% markup for price fluctuations, and approves the final budget.

Your task is to write a program that executes Phase 2. Given the network topology from Phase 1 and the list of high-priority rooms, output the exact minimum cost before any Phase 3 markups are applied.

## Input

The first line contains three integers: the number of rooms, the number of mapped segments, and the number of high-priority rooms.
The second line contains distinct integers: the identifiers of the high-priority rooms.
Each of the remaining lines (one for each mapped segment) describes a mapped conduit segment using three integers: the two distinct rooms it connects, and the installation cost for that segment.
The segments provided in the input are guaranteed to satisfy the connectivity verified in Phase 1.

## Output

Print a single integer: the minimum total cost calculated in Phase 2.
