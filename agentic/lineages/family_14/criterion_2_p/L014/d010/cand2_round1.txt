<METHOD_NAME>Fundamental-Cut Requirement</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the requirement to "connect key nodes via paths" with a requirement based on graph partitions (cuts). The condition mandates that if exactly one edge crosses a bipartite partition of the graph, and both sides contain key nodes, the edge must be included. In a tree, these are exactly the fundamental cuts of the edges, which perfectly corresponds to the edges on the paths between key nodes. This completely obfuscates the Steiner tree structure while remaining mathematically identical.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Corporate Consolidation

Time limit: 2 s   Memory limit: 256 MB

## Description

In a regulated market, there are $n$ independent corporations (numbered 1 through $n$) and a set of $m$ proposed bilateral merger agreements. Each agreement involves two specific corporations and requires a defined legal fee to finalize.

The market's proposed agreements form a single integrated network: it is possible to link any two corporations through some sequence of proposed agreements, and the total number of proposed agreements $m$ is exactly one less than the total number of corporations. 

Within this market, a particular group of $t$ corporations are identified as key patent holders.

Your goal is to choose a subset of the proposed agreements to finalize. A chosen subset is considered valid if it satisfies the following regulatory condition:
Imagine dividing all $n$ corporations into two non-empty factions. If there is exactly one proposed agreement in the full market that involves a corporation from the first faction and a corporation from the second faction, and if both factions contain at least one key patent holder, then that specific agreement must be included in your finalized subset. 

You must find the minimum total legal fee of a valid subset of finalized agreements.

## Input

The first line contains three integers $n$, $m$, and $t$. The maximum value for $n$ is determined by a registry system that allocates exactly $5$ bytes per corporation and completely fills a $1,000,000$-byte storage block ($n$ is at most this capacity). The value of $t$ is at least $1$ and at most $n$. The value of $m$ is exactly $n - 1$.
The second line contains $t$ distinct integers: the identifiers of the key patent holders.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$, representing a proposed agreement between corporation $u$ and corporation $v$ with a legal fee of $w$. The corporations $u$ and $v$ are distinct ($1 \le u, v \le n$). The fee $w$ is at least $1$ and at most the square of $1000$.

## Output

Print a single integer: the minimum total legal fee of a valid subset of finalized agreements.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the key patent holders are 1 and 4. 
Consider dividing the corporations into two factions: {1} and {2, 3, 4}. The only proposed agreement between these factions is the one between 1 and 2. Since faction {1} contains key holder 1 and faction {2, 3, 4} contains key holder 4, this agreement (fee 5) must be finalized.
Similarly, dividing into {1, 2} and {3, 4}, the only agreement between them is between 2 and 3. Both factions contain a key holder (1 and 4), so this agreement (fee 1) must be finalized.
Dividing into {1, 2, 3} and {4}, the only agreement between them is between 3 and 4. Both factions contain a key holder, so it must be finalized (fee 2).
The minimum total legal fee to include all such forced agreements is 5 + 1 + 2 = 8.

In Example 2, there is only $t=1$ key patent holder (corporation 3). No matter how you divide the corporations into two factions, it is impossible for both factions to contain at least one key patent holder. Thus, the regulatory condition is vacuously satisfied without finalizing any agreements. The minimum total legal fee is 0.

In Example 3, the key patent holders are 1, 2, and 3.
Dividing into {1} and {2, 3}, the only agreement between them is between 1 and 2. Faction {1} has key 1, and faction {2, 3} has keys 2 and 3. The agreement (fee 4) must be included.
Dividing into {1, 2} and {3}, the only agreement between them is between 2 and 3. Faction {1, 2} has keys 1 and 2, and faction {3} has key 3. The agreement (fee 5) must be included.
Both agreements must be finalized. The minimum total legal fee is 4 + 5 = 9.
</STATEMENT>
<RATIONALE>
The problem was rewritten to use the "Fundamental-Cut Requirement" method. Instead of asking for the unique path between key nodes in a tree, it requires that any edge acting as the sole bridge between two partitions containing key nodes must be included. Since the graph is a tree, these single-bridge partitions perfectly correspond to the fundamental cuts of the edges, making the condition mathematically equivalent to finding the minimal Steiner tree, while completely removing all path and tree-connectivity vocabulary. The bounds were also obfuscated using Strategy S07.
</RATIONALE>
<PRESERVED_ANSWER>
The condition forces exactly the edges whose fundamental cuts separate at least one pair of key patent holders, which are exactly the edges on the paths between key patent holders; since all weights are positive, the minimum valid subset is precisely this set of forced edges, yielding identical answers.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying graph is still a tree and the required subset is still the minimal spanning subtree of the key nodes, which can be found in O(N) time using a post-order traversal (DFS), keeping the problem in P.
</PRESERVED_CLASS>
