**Solution Explanation**

For the given data the graph is a **tree**  

* `m = n‑1`  
* for every set of `k` vertices there are at most `k‑1` edges inside it  

These two facts together mean that the graph is connected and has no cycles,
i.e. it is a tree.

For a tree the cheapest way to make all `t` special vertices belong to the
same component is unique:

*take the union of all simple paths between the special vertices*.
The obtained sub‑tree is called the **Steiner tree** of the special vertices
in a tree, and it is the only connected sub‑graph that contains them all.
Its total cost is simply the sum of the weights of the edges that belong to it.

--------------------------------------------------------------------

#### When is an edge necessary ?

Root the tree at any vertex (conveniently vertex `1`).

For an edge `parent – child`

```
cnt[child] = number of special vertices inside the subtree of child
```

The edge is part of the Steiner tree **iff**

```
cnt[child] > 0   and   cnt[child] < t
```

because then there is at least one special vertex on each side of the edge,
so the edge lies on a path connecting two specials.

Therefore the answer is

```
sum of w(e) over all edges e with 0 < cnt[side] < t
```

--------------------------------------------------------------------

#### Algorithm
```
read input
mark special vertices
build adjacency list

# 1. iterative DFS to obtain parent, edge weight to parent and a postorder list
stack = [(root, 0, 0)]          # (node, parent, weight_to_parent)
while stack:
        node, par, w = stack.pop()
        parent[node] = par
        pw[node] = w
        order.append(node)     # preorder, later processed in reverse
        for (nbr, wt) in adj[node]:
                if nbr != par:
                        stack.append((nbr, node, wt))

# 2. compute cnt[ ] bottom‑up
for node in reversed(order):
        cnt[node] = 1 if special[node] else 0
        for (nbr, _) in adj[node]:
                if nbr != parent[node]:
                        cnt[node] += cnt[nbr]

# 3. accumulate answer
ans = 0
for v = 2 … n:                     # all vertices except the root
        if 0 < cnt[v] < t:
                ans += pw[v]

print(ans)
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs the minimum possible total fee.

---

##### Lemma 1  
For any edge `e = (parent, child)` let `S` be the set of special vertices
inside the subtree of `child`.  
`e` belongs to the unique minimal connecting sub‑tree of all specials  
iff `S` is non‑empty and `S ≠ all specials`.

**Proof.**  
*If* `S` is empty, removing `e` does not separate any special vertex, so
`e` is never needed.  
*If* `S` contains all specials, the whole tree is already on one side,
again `e` is unnecessary.  
Otherwise there is at least one special vertex on each side of `e`; any
connected sub‑graph containing all specials must contain a path between those
two vertices, and that path must use `e` (the tree has a unique path). ∎



##### Lemma 2  
The algorithm marks exactly the edges described in Lemma&nbsp;1.

**Proof.**  
During the bottom‑up pass `cnt[child]` equals `|S|` from Lemma&nbsp;1.
The condition `0 < cnt[child] < t` is precisely the condition of Lemma&nbsp;1,
hence the algorithm adds the weight of exactly those edges. ∎



##### Lemma 3  
The sum produced by the algorithm equals the total weight of the Steiner tree
of the special vertices.

**Proof.**  
By Lemma&nbsp;2 the algorithm sums the weights of all and only the edges that
must belong to any connected sub‑graph containing all specials.
The Steiner tree in a tree is exactly the set of those mandatory edges,
so the summed weight equals its weight. ∎



##### Theorem  
The algorithm outputs the minimum possible total legal fee required to make
all `t` patent‑holding corporations belong to the same conglomerate.

**Proof.**  
Any feasible set of agreements must connect all special vertices, therefore
its edge set must contain the Steiner tree (otherwise some specials stay
disconnected). Consequently its total weight is at least the weight of the
Steiner tree.  
By Lemma&nbsp;3 the algorithm outputs exactly that weight, which is therefore
optimal. ∎

#### Complexity Analysis  

*Building adjacency list* : `O(n)`  
*DFS (both passes)*        : `O(n)`  
*Memory*                   : adjacency list `2·(n‑1)` edges, plus several
arrays of size `n` → `O(n)`.

Both limits satisfy the constraints (`n ≤ 200 000`).

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    n = next(it)
    m = next(it)          # equals n-1, not used separately
    t = next(it)

    specials = [0] * (n + 1)
    for _ in range(t):
        v = next(it)
        specials[v] = 1

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = next(it); v = next(it); w = next(it)
        adj[u].append((v, w))
        adj[v].append((u, w))

    root = 1
    parent = [0] * (n + 1)
    pw = [0] * (n + 1)          # weight to parent
    order = []                  # preorder list

    stack = [(root, 0, 0)]
    while stack:
        node, par, w = stack.pop()
        parent[node] = par
        pw[node] = w
        order.append(node)
        for nb, wt in adj[node]:
            if nb != par:
                stack.append((nb, node, wt))

    cnt = [0] * (n + 1)
    for node in reversed(order):
        c = specials[node]
        for nb, _ in adj[node]:
            if nb != parent[node]:
                c += cnt[nb]
        cnt[node] = c

    total = 0
    for v in range(2, n + 1):          # all except root
        if 0 < cnt[v] < t:
            total += pw[v]

    print(total)

if __name__ == "__main__":
    solve()
```
