# Hardware Synchronization

Time limit: 2 s   Memory limit: 256 MB

## Description

You are optimizing a data synchronization protocol for a hardware processor. The processor contains $n$ registers, numbered 1 to $n$. A specific subset of $t$ registers are designated as output registers. The hardware provides $m$ bidirectional sync channels between certain pairs of registers, each with a specific latency when activated.

Your objective is to select a subset of these sync channels to remain active. A selected subset is considered valid if it satisfies the following synchronization requirement:
For every possible partition of the $t$ designated output registers into two non-empty sets $G_1$ and $G_2$ (such that their union is the set of all designated registers and their intersection is empty), there must exist a sequence of registers $R_1, R_2, \dots, R_k$ (where each $R_i$ can be any of the $n$ available registers) satisfying:
1. $R_1$ belongs to $G_1$.
2. $R_k$ belongs to $G_2$.
3. For every $1 \le i < k$, the sync channel between $R_i$ and $R_{i+1}$ is included in your active subset.

You must find a valid subset of active channels that minimizes the sum of their latencies.

The hardware architecture conforms to two structural rules that guarantee a valid subset always exists:
First, the total number of available sync channels $m$ is strictly one less than the number of registers $n$.
Second, for any arbitrary partition of all $n$ registers into two non-empty sets, there is always at least one sync channel in the hardware design that links a register in the first set to a register in the second set.

## Input

The first line contains three integers $n$, $m$, and $t$. The total number of registers $n$ is at least 1 and bounded by the hardware maximum of 200,000. The number of channels $m$ is exactly one less than $n$. The count of designated output registers $t$ ranges from 1 to $n$.
The second line contains $t$ distinct integers: the identifiers of the designated output registers.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$. This indicates a sync channel between register $u$ and register $v$ ($u \neq v$, both between 1 and $n$) with a latency of $w$. The latency is a positive integer up to a clock cycle maximum of 1,000,000.

## Output

Print a single integer: the minimum total latency of a valid active subset of channels.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the designated output registers are 1 and 4. The only possible partition of these registers into two non-empty sets is $G_1 = \{1\}$ and $G_2 = \{4\}$. A valid active subset includes the channels between 1 and 2, 2 and 3, and 3 and 4. This allows the sequence 1, 2, 3, 4, satisfying the requirement with a total latency of 5 + 1 + 2 = 8.

In Example 2, there is only one designated output register. It is impossible to partition a single element into two non-empty sets, so the requirement is vacuously satisfied with an empty subset of channels. The minimum latency is 0.

In Example 3, the designated output registers are 1, 2, and 3. All channels must be active to satisfy the requirement for all possible partitions (for instance, partitioning into $G_1 = \{1\}$ and $G_2 = \{2, 3\}$ requires a sequence from 1 to either 2 or 3). The minimum total latency to achieve this is 4 + 5 = 9.
