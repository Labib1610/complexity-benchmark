<STATEMENT>
# Corporate Consolidation

Time limit: 2 s   Memory limit: 256 MB

## Description

In a regulated market, there are $n$ independent corporations (numbered 1 through $n$) and a set of $m$ proposed bilateral merger agreements. Each agreement involves two specific corporations and requires a defined legal fee to finalize.

Within this market, a particular group of $t$ corporations are identified as key patent holders. 

The antitrust regulatory board has certified that the market is fully integrated, meaning any two distinct corporations can be linked by at least one valid sequence of proposed agreements (a sequence where consecutive agreements share a corporation). The market may contain redundant agreements, meaning there could be multiple distinct sequences of agreements linking the same pair of corporations.

We classify a proposed agreement as *critical* if there exists a pair of distinct key patent holders such that *every* valid sequence of proposed agreements linking this pair must include this specific agreement.

Your goal is to choose a subset of the proposed agreements to finalize. A chosen subset is considered valid if and only if it includes every *critical* agreement. 

You must find the minimum total legal fee of a valid subset of finalized agreements.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$).
The second line contains $t$ distinct integers: the identifiers of the key patent holders.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a proposed agreement between corporation $u$ and corporation $v$ with a legal fee of $w$.

## Output

Print a single integer: the minimum total legal fee of a valid subset of finalized agreements.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the key patent holders are 1 and 4. 
Every valid sequence of proposed agreements linking key patent holder 1 and key patent holder 4 must include the agreement between 1 and 2. Therefore, it is critical.
Similarly, the agreement between 2 and 3, and the agreement between 3 and 4 are also included in every valid sequence between 1 and 4, making them critical as well.
To form a valid subset, all three must be included. The minimum total legal fee is 5 + 1 + 2 = 8. 

In Example 2, there is only one key patent holder (corporation 3). 
Since it is impossible to form a pair of distinct key patent holders, no agreements can meet the condition to be critical. 
The condition is vacuously satisfied by choosing an empty subset, resulting in a minimum total legal fee of 0.

In Example 3, the key patent holders are 1, 2, and 3.
Every valid sequence linking key patent holder 1 and key patent holder 3 must include the agreement between 1 and 2, so it is critical.
Similarly, every valid sequence linking 1 and 3 must include the agreement between 2 and 3, so it is also critical.
Both agreements are critical and must be included in any valid subset. The minimum total legal fee is 4 + 5 = 9.
</STATEMENT>
<RATIONALE>
I removed the guarantee that the input graph is a tree and explicitly stated that redundant agreements (cycles) may exist. I also reframed the "separates key holders" condition to its mathematical equivalent: "must be included in every sequence linking a pair of key holders". This forces models to abandon simple subtree-count tree traversals and instead attempt significantly more complex general bridge-finding and block-cut tree algorithms, which rely on deeper algorithmic reasoning and are heavily prone to implementation failure or TLE if done naively.
</RATIONALE>
<PRESERVED_ANSWER>
For any connected graph, an edge is included in every path between X and Y if and only if it is a bridge whose removal separates X and Y, meaning exactly the same set of edges is deemed critical and the minimum cost remains identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Finding all bridges and determining which ones separate specific nodes in a general connected graph can be solved in O(N + M) time using Tarjan's algorithm and a block-cut tree, keeping the problem firmly in P.
</PRESERVED_CLASS>
<RISK>
Models might be confused whether a 'sequence' allows repeating agreements (a walk) or must be a simple path; however, since an agreement is in every walk if and only if it is in every simple path, there is no mathematical ambiguity.
</RISK>
