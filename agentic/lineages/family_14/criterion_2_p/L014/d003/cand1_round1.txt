<STATEMENT>
# Connecting the Critical Facilities

Time limit: 2 s   Memory limit: 256 MB

## Description

A large industrial complex consists of $n$ facilities, numbered 1 to $n$. A specific subset of $t$ facilities are designated as critical operations centers. There are $m$ potential bidirectional communication links that can be constructed between certain pairs of facilities, each requiring a specific construction cost.

Your objective is to select a subset of these links to build so that all $t$ critical facilities can communicate with one another, either directly or by routing through other intermediate facilities. You must achieve this requirement at the minimum possible total construction cost.

The blueprint for the complex guarantees that if every proposed link were built, a signal originating from any facility would have exactly one route to reach any other facility without backtracking.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le n$, $1 \le n \le 200000$).
The second line contains $t$ distinct integers: the identifiers of the critical facilities.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a potential link between facility $u$ and facility $v$ with a construction cost of $w$. 

## Output

Print a single integer: the minimum total cost to ensure all critical facilities are interconnected.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the critical facilities 1 and 4 are integrated by building the links that join 1 to 2, 2 to 3, and 3 to 4, for a total cost of 5 + 1 + 2 = 8. In Example 2, there is only one critical facility, so no links need to be constructed.
</STATEMENT>
<RATIONALE>
I removed the explicit statement that $m$ is exactly $n - 1$ and the phrase "single unified network", which models used as a surface-level shortcut to immediately identify the graph as a tree. Instead, I established the tree topology by specifying that there is exactly one route between any two facilities without backtracking. This forces models to genuinely deduce the structural properties (connected and acyclic) from the routing description rather than pattern-matching the explicit edge count.
</RATIONALE>
<PRESERVED_ANSWER>
The problem still asks for the minimum cost to connect the identical subset of critical facilities using the identical available links, so the optimal cost remains exactly the same for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The guarantee of exactly one route between any pair of facilities without backtracking mathematically defines a tree, ensuring the input graph is always a tree, so the problem remains solvable in polynomial time (O(n)).
</PRESERVED_CLASS>
<RISK>
Models might fail to deduce that $m = n - 1$ from the text and assume $m$ could be large, leading them to attempt general-graph algorithms that TLE, but this is the intended failure mode for models that lack genuine reasoning.
</RISK>
