<METHOD_NAME>
Cut-Based Essentiality
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the path-union condition ("unique sequence of agreements linking") with an equivalent edge-cut condition ("rejecting the agreement divides the market into exactly two isolated groups, each containing a key holder"). This shifts the framing from a Steiner tree path-union problem to a graph-cut problem, forcing models to independently deduce that on a tree, the cut condition identifies exactly the edges of the minimal spanning subtree.
</METHOD_DESCRIPTION>

yes

<STATEMENT>
# Corporate Consolidation

Time limit: 2 s   Memory limit: 256 MB

## Description

In a regulated market, there are $n$ independent corporations (numbered 1 through $n$) and a set of $m$ proposed bilateral merger agreements. Each agreement involves two distinct corporations and requires a defined legal fee to finalize. 

The corporate registry can track a maximum of two hundred thousand corporations. The number of proposed agreements, $m$, is always exactly one less than the number of corporations. The proposals ensure that all corporations are part of a single interconnected market; no corporation or group of corporations is completely isolated from the rest.

Within this market, a particular group of $t$ corporations are identified as key patent holders. There is always at least one key patent holder, and at most, every corporation is one. The legal fee for any agreement is a strictly positive integer no greater than one million.

To maintain market equilibrium, the antitrust regulatory board evaluates the structural impact of each proposed agreement. If a single proposed agreement were to be rejected while all other $m - 1$ proposed agreements were approved, the corporations would be partitioned into exactly two isolated groups, with no remaining agreements linking any corporation in the first group to any corporation in the second group. An agreement is classified as *essential* if both of these resulting groups contain at least one key patent holder.

Your goal is to choose a subset of the proposed agreements to finalize. A chosen subset is considered valid if and only if it includes every essential agreement. You must find the minimum total legal fee of a valid subset of finalized agreements.

## Input

The first line contains three integers $n$, $m$, and $t$.
The second line contains $t$ distinct integers: the identifiers of the key patent holders.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$, representing a proposed agreement between corporation $u$ and corporation $v$ with a legal fee of $w$.

## Output

Print a single integer: the minimum total legal fee of a valid subset of finalized agreements.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

### Example 2

**Input**
```
5 4 1
3
1 2 4
2 3 6
3 4 2
4 5 9
```

**Output**
```
0
```

### Example 3

**Input**
```
3 2 3
1 2 3
1 2 4
2 3 5
```

**Output**
```
9
```

## Note

In Example 1, the key patent holders are 1 and 4. 
If the agreement between 1 and 2 is rejected, the corporations are partitioned into groups {1} and {2, 3, 4}. Both groups contain a key patent holder, so this agreement is essential.
If the agreement between 2 and 3 is rejected, the groups are {1, 2} and {3, 4}. Both contain a key patent holder, so it is essential.
If the agreement between 3 and 4 is rejected, the groups are {1, 2, 3} and {4}. Both contain a key patent holder, so it is essential.
A valid subset must include all three of these agreements. The minimum total legal fee is 5 + 1 + 2 = 8. 

In Example 2, there is only one key patent holder (corporation 3). 
If any single agreement is rejected, one of the resulting groups will contain corporation 3, and the other group will contain zero key patent holders. 
Therefore, no agreements are classified as essential. The condition is satisfied by choosing an empty subset of agreements, resulting in a minimum total legal fee of 0.

In Example 3, the key patent holders are 1, 2, and 3. 
Rejecting the agreement between 1 and 2 partitions the corporations into groups {1} and {2, 3}. Both groups contain at least one key patent holder, so this agreement is essential.
Rejecting the agreement between 2 and 3 partitions the corporations into groups {1, 2} and {3}. Both groups contain at least one key patent holder, so this agreement is essential.
A valid subset must include both essential agreements. The minimum total legal fee is 4 + 5 = 9.
</STATEMENT>
<RATIONALE>
Changed the condition from a path-union framing ("unique sequence linking pairs") to an edge-cut framing ("rejecting an agreement partitions the market into two isolated groups, both containing a key holder"). This forces the model to realize that evaluating cuts in a tree is equivalent to finding the unique paths between key terminals, preventing reliance on surface-level path-finding pattern matching. Numeric bounds were also integrated into the text using strategy S07.
</RATIONALE>
<PRESERVED_ANSWER>
Removing an edge in a tree separates the key patent holders if and only if that edge lies on the unique path between some pair of them, making the set of 'essential' agreements exactly the same minimal valid subset from the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The topology is still a tree (connected, N-1 edges), and the essential edges can still be found in O(N) time via a single post-order traversal counting key patent holders in subtrees, keeping it in P.
</PRESERVED_CLASS>
<RISK>
A reader might misunderstand 'isolated groups' as implying more than two components, but the text explicitly specifies 'exactly two isolated groups', eliminating this ambiguity.
</RISK>
