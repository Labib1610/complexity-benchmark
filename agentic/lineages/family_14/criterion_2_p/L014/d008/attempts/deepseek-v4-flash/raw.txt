We are given a tree (since \( m = n-1 \) and the graph is connected).  
We need to find all edges that, when removed, split the tree into two components each containing at least one key patent holder.  
These are the *critical* edges.  
Then we must include all critical edges in our chosen subset, and we may optionally include other edges to minimize cost — but since we must include all critical edges, the minimum cost is simply the sum of their weights.

So the task reduces to:  
- Root the tree at any node.  
- For each edge, compute the number of key nodes in the subtree below it.  
- If that count is between 1 and \( t-1 \), the edge is critical.  
- Sum weights of all such edges.

We can do this with a DFS.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    keys = set(map(int, input().split()))
    
    adj = [[] for _ in range(n)]
    edges = []
    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append((v, w))
        adj[v].append((u, w))
        edges.append((u, v, w))
    
    parent = [-1] * n
    parent_edge_weight = [0] * n
    order = [0]
    for u in order:
        for v, w in adj[u]:
            if v == parent[u]:
                continue
            parent[v] = u
            parent_edge_weight[v] = w
            order.append(v)
    
    subtree_key_count = [0] * n
    for u in reversed(order):
        if u in keys:
            subtree_key_count[u] += 1
        if parent[u] != -1:
            subtree_key_count[parent[u]] += subtree_key_count[u]
    
    total_cost = 0
    for u in range(1, n):
        cnt = subtree_key_count[u]
        if 0 < cnt < t:
            total_cost += parent_edge_weight[u]
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
