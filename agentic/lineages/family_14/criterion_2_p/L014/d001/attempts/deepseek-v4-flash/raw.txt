 We can solve this by building a **minimum Steiner tree** for the required sites.  
Since the graph is a tree (m = n − 1), the optimal solution is the minimal subtree that connects all required nodes.  

The approach:  
- Root the tree at any required node.  
- Perform DFS, and for each node, decide whether to keep the edge to its parent based on whether the subtree contains any required node.  
- Sum the weights of all kept edges.  

Here’s the implementation:  

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    required = set(map(int, input().split()))
    
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    visited = [False] * (n + 1)
    total_cost = 0
    
    def dfs(u, parent_edge_cost):
        nonlocal total_cost
        visited[u] = True
        has_required = u in required
        for v, w in adj[u]:
            if not visited[v]:
                child_has_required = dfs(v, w)
                if child_has_required:
                    total_cost += w
                has_required = has_required or child_has_required
        return has_required
    
    # Start from any required node
    start = next(iter(required))
    dfs(start, 0)
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
