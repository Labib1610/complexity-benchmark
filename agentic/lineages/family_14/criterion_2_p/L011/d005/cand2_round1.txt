# Domain Synchronization

Time limit: 2 s   Memory limit: 256 MB

## Description

You are configuring a system with a domain of **n** variables, labeled 1 through **n**. You are provided a list of **m** synchronization protocols. Each protocol binds a specific pair of variables and has an associated overhead cost.

The system's full set of **n** variables is **indecomposable** with respect to the **m** protocols. A set of variables is considered indecomposable if it is impossible to partition it into two non-empty disjoint subsets (whose union is the set itself) such that no protocol binds a variable in the first subset to a variable in the second subset.

A subset of **t** variables are designated as **critical variables**. Your objective is to define a **working domain** (a subset of the **n** variables) that minimizes the total overhead cost while satisfying these conditions:
1. The working domain must include all **t** critical variables.
2. Any protocol that binds two variables which are BOTH included in the working domain is automatically active. The total overhead cost of the working domain is the sum of the costs of all its active protocols.
3. The working domain itself must be indecomposable with respect to its active protocols.

Determine the minimum total overhead cost required to establish a valid working domain.

## Input

The first line provides three integers **n**, **m**, and **t**. The system's architecture supports a variable count **n** up to a hard memory limit of 200,000. The number of protocols **m** is exactly one less than the variable count **n**, which is the precise threshold required to guarantee the full domain is indecomposable. The count of critical variables **t** can be any valid quantity from a solitary variable up to the full capacity of **n** variables.
The second line provides **t** distinct integers representing the labels of the critical variables.
Each of the subsequent **m** lines provides three integers **u**, **v**, and **w**, indicating a protocol binding variable **u** and variable **v** with an overhead cost of **w**. The identifiers **u** and **v** are always distinct and refer to valid variables within the system's current size. The overhead cost **w** requires at least 1 compute cycle and is capped by a thermal safety limit of 1,000,000 cycles.

## Output

Output a single integer representing the minimum total overhead cost of the active protocols in a valid working domain.

<RATIONALE>
I completely removed all graph-theoretic and networking terminology (paths, connections, endpoints, networks). Instead, I reframed the connectivity requirement as a set-theoretic property called "indecomposability" (the inability to partition the set without breaking a binding). This forces the model to logically deduce that "indecomposable" means "connected graph", and that a connected graph with exactly `n-1` edges is a tree, preventing solutions that rely on surface-level keyword matching to trigger tree algorithms.
</RATIONALE>
<PRESERVED_ANSWER>
The definition of an "indecomposable" set perfectly mirrors the definition of a connected graph component, meaning the minimal valid working domain is mathematically identical to the minimal connected subgraph containing all required nodes, preserving all costs and outputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the Steiner tree problem on a graph that is guaranteed to be a tree, which has a unique minimal connecting subgraph that can be found in O(n) time, keeping it firmly in P.
</PRESERVED_CLASS>
<RISK>
Models might struggle with the formal definition of "partition it into two non-empty disjoint subsets (whose union is the set itself)", though this is standard mathematical terminology for a set partition and leaves no true ambiguity.
</RISK>
