 We have a tree (since m = n-1), and we need to find the minimum cost connected subgraph that contains all critical nodes.  
This is essentially the **Steiner tree** problem on a tree, which can be solved by:

1. Compress the tree to only the critical nodes and their necessary connecting paths.
2. The minimal cost is the sum of edge weights in the minimal subtree that connects all critical nodes.

We can do this by:
- Marking critical nodes.
- Doing a DFS to find the minimal subtree that contains all critical nodes.
- Summing the weights of edges in that subtree.

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    critical = set(map(int, input().split()))
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    # DFS to find minimal subtree containing all critical nodes
    visited = [False] * (n+1)
    
    def dfs(u, parent):
        visited[u] = True
        need = u in critical
        total_cost = 0
        for v, w in adj[u]:
            if v == parent:
                continue
            if not visited[v]:
                child_need, child_cost = dfs(v, u)
                if child_need:
                    need = True
                    total_cost += child_cost + w
        return need, total_cost
    
    # Start from any critical node
    start = next(iter(critical))
    _, cost = dfs(start, -1)
    print(cost)

if __name__ == "__main__":
    solve()
```
