<STATEMENT>
# Problem B — Minimal Constraint System Reduction

Time limit: 2 s   Memory limit: 256 MB

## Description

You are given a system of **n** variables, numbered 1 to **n**, and **m** equality constraints. Each constraint specifies that two distinct variables are identically equal and has a known verification cost.

The initial system of variables is fully *coupled*. A set of variables is considered *coupled* if, for any two variables in the set, it is possible to logically deduce that they are equal using a sequence of the given constraints, where every constraint used in the deduction only involves variables that both belong to the set. (A set consisting of a single variable is inherently coupled).

You may perform a sequence of variable eliminations to simplify the system. In a single step, you permanently discard exactly one variable, which also removes any constraints that involve it. Your elimination sequence must satisfy two conditions:
1. You may never discard any of the **t** *target variables*, as their values are required for the final evaluation.
2. After every individual elimination step, the set of remaining variables must still be *coupled*. If discarding a variable would cause the remaining variables to no longer be coupled (i.e., you could no longer deduce equality between some pair of remaining variables), that variable cannot be discarded at that time.

You can stop the elimination process at any point, including making no eliminations at all. Your objective is to determine the minimum possible total verification cost of the constraints that remain in the system when you finish.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line provides **t** distinct integers representing the labels of the target variables.
Each of the subsequent **m** lines provides three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating a constraint stating **u** = **v** with a verification cost of **w**.

## Output

Output a single integer representing the minimum possible total verification cost of the remaining constraints after a valid sequence of eliminations.

<RATIONALE>
I shifted the semantic domain from physical structure removal to algebraic variable elimination, directly addressing the expert's feedback to use neutral engineering terms while avoiding contrived sci-fi themes. This forces the model to realize that a system of n variables and n-1 constraints that allows full deduction of equality is structurally a tree, and that discarding variables while maintaining deducibility is equivalent to leaf pruning.
</RATIONALE>
<PRESERVED_ANSWER>
The allowed eliminations exactly correspond to removing non-target leaf nodes from a tree, so the minimal remaining constraints form the unique Steiner tree connecting the target variables, identical to the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the minimum connected subgraph containing a set of terminal nodes in a tree, which is solvable in O(n) time and is in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "logically deduce that they are equal" as allowing the use of constraints that were already removed, but the text explicitly states "where every constraint used in the deduction only involves variables that both belong to the set", minimizing this risk.
</RISK>
