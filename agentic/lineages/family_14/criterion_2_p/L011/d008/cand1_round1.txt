# Problem B — Phase-Locked Systems

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a theoretical network of **n** quantum oscillators, numbered 1 to **n**. The network contains **m** bidirectional resonance links. Each link connects two distinct oscillators and has a known stability cost.

A subset of oscillators $S$ is considered *phase-locked* if every valid solution to the following constraint system is a uniform solution (meaning all oscillators in $S$ share the exact same state):
- Each oscillator in $S$ is assigned a binary state (either 0 or 1).
- For every active resonance link (a link connecting two oscillators both currently in $S$), the two connected oscillators must be assigned the identical binary state.

(A subset consisting of a single oscillator trivially satisfies this, as any assignment to it is uniform). The initial set of all **n** oscillators is guaranteed to be fully phase-locked.

You may perform a sequence of oscillator isolations to reduce the network. In a single step, you permanently isolate exactly one oscillator from $S$, which safely destroys any resonance links attached to it. However, your isolation sequence must satisfy two strict regulations:
1. You may never isolate any of the **t** *reference oscillators*, as they are required for the final measurement.
2. After every individual isolation step, the remaining subset of oscillators $S$ must still be *phase-locked*. If isolating an oscillator would cause the remaining subset to lose this property (i.e., it would become possible to find a valid non-uniform binary assignment where every remaining active link still connects two oscillators of the identical state), that oscillator cannot be isolated at that time.

You can stop the isolation process at any point, including making no isolations at all. Your objective is to determine the minimum possible total stability cost of the resonance links that remain active when you finish.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line provides **t** distinct integers representing the labels of the reference oscillators.
Each of the subsequent **m** lines provides three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating a resonance link between oscillator **u** and oscillator **v** with a stability cost of **w**.

## Output

Output a single integer representing the minimum possible total stability cost of the remaining resonance links after a valid sequence of isolations.

<RATIONALE>
The previous framing used the word "cohesive" and defined it as being unable to "partition into two unlinked groups", which models immediately mapped to graph connectedness. Combined with `m = n - 1`, this instantly revealed the tree structure and the minimal-subtree solution. To break this affordance, I completely replaced the set-theoretic definition of connectivity with a Boolean Constraint Satisfaction (2-SAT flavor) definition. Now, models must logically deduce that a constraint system where every edge forces equality only has uniform solutions if and only if the underlying graph is connected. This extra layer of abstraction prevents the immediate pattern-matching to tree algorithms.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the constraint system only permits uniform solutions is mathematically identical to the condition that the graph induced by $S$ is connected, so the set of valid isolations remains exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Because the underlying structure and constraints are identical, the solution remains finding the minimal spanning subtree of the required terminals on the given tree, preserving the O(n) complexity class.
</PRESERVED_CLASS>

The definition of the constraint system is highly explicit, but there is a slight risk that models misinterpret "valid non-uniform binary assignment" if they fail to link it back to the two bullet points, though the parenthetical clarification heavily mitigates this.
</RISK>
