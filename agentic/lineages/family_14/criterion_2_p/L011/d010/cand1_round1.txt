# Problem B — Minimal Sorting Network Reduction

Time limit: 2 s   Memory limit: 256 MB

## Description

You are configuring a sorting mechanism for an array of **n** slots, numbered 1 to **n**. You are provided with a set of **m** bidirectional swap mechanisms. Each swap mechanism allows you to exchange the contents of slot **u** and slot **v**, and requires a daily maintenance budget of **w**.

A subset of slots **S** is considered *fully mixable* if, assuming each slot in **S** contains a distinct item, it is possible to rearrange these items into any arbitrary permutation of those same items, using exclusively the swap mechanisms that connect two slots that are both in **S**. (A subset containing exactly one slot is inherently fully mixable). You are given that initially, the full set of **n** slots is fully mixable.

You wish to reduce the overall maintenance budget by permanently sealing some slots. In a single step, you may permanently seal exactly one slot. Sealing a slot safely disables and permanently removes any swap mechanisms attached to it. 

However, your sealing sequence must abide by two strict regulations:
1. You may never seal any of the **t** *critical slots*, as they must remain active.
2. After every individual sealing step, the subset of remaining unsealed slots must still be *fully mixable*. If sealing a slot would restrict the remaining slots such that some permutations of their items can no longer be reached, that slot cannot be sealed at that moment.

You may halt the sealing process at any time, including not sealing any slots at all. Your objective is to determine the minimum possible total maintenance budget of the swap mechanisms that remain active when you conclude the process.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line provides **t** distinct integers representing the indices of the critical slots.
Each of the subsequent **m** lines provides three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating a swap mechanism between slot **u** and slot **v** with a maintenance budget of **w**.

## Output

Output a single integer representing the minimum possible total maintenance budget of the remaining swap mechanisms after a valid sequence of sealing steps.

## Examples

**Input**

```
2 3 1
3 4 2
```

**Output**
```
8
```

```

```

**Output**
```
9
```

<RATIONALE>
The surviving models successfully mapped the "equality conditions" and "monolithic variables" to a connected graph, and from `m = n-1` deduced it was a tree, solving it via leaf pruning (Steiner tree). To break this shortcut, the problem is recast into the domain of sorting networks and permutations. The connectivity condition is replaced by the mathematically equivalent property of generating the symmetric group via transpositions ("fully mixable"). This forces the model to genuinely reason about how swap mechanisms enable arbitrary permutations, rather than relying on surface-level graph terminology.
</RATIONALE>
<PRESERVED_ANSWER>
A set of transpositions generates the symmetric group on a subset of elements if and only if the corresponding graph of transpositions is connected; thus "fully mixable" is strictly equivalent to "monolithic" (connected), preserving the exact same valid elimination sequences and minimum costs.
</PRESERVED_ANSWER>

The underlying structure remains finding the minimal connected subgraph spanning a set of required vertices in a tree, which is solvable in O(n) time by repeatedly pruning non-mandated leaves.
</PRESERVED_CLASS>
