 We need to find the minimum possible total mass of remaining struts after removing non-anchor joints while keeping the remaining set cohesive at all times.

Key observations:

- The framework is a tree (since m = n - 1).
- Removing a joint from a tree splits it into multiple components unless the joint is a leaf.
- To keep the remaining set cohesive, we can only remove leaves (degree 1) that are not anchors.
- This is equivalent to repeatedly removing non-anchor leaves until only anchors remain (or until no more non-anchor leaves exist).
- The remaining structure will be the minimal subtree that connects all anchor joints.
- The total mass of remaining struts is the sum of weights of edges in that minimal subtree.

So the solution is:

1. Build the tree.
2. Mark anchor nodes.
3. Perform a leaf-pruning process:  
   - Use a queue of leaves that are not anchors.
   - Remove them one by one, decrementing degree of neighbors.
   - If a neighbor becomes a leaf and is not an anchor, add it to the queue.
4. After pruning, the remaining edges are those that connect the remaining nodes (which form the minimal subtree spanning all anchors).
5. Sum the weights of those remaining edges.

Let's implement this efficiently.

```python
import sys
from collections import deque

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    anchors = set(map(int, input().split()))
    
    adj = [[] for _ in range(n)]
    degree = [0] * n
    edges = []
    
    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append((v, w))
        adj[v].append((u, w))
        degree[u] += 1
        degree[v] += 1
        edges.append((u, v, w))
    
    # Leaf pruning
    q = deque()
    removed = [False] * n
    for i in range(n):
        if degree[i] == 1 and i not in anchors:
            q.append(i)
    
    while q:
        u = q.popleft()
        if removed[u]:
            continue
        removed[u] = True
        for v, w in adj[u]:
            if not removed[v]:
                degree[v] -= 1
                if degree[v] == 1 and v not in anchors:
                    q.append(v)
    
    # Sum weights of edges where both endpoints are not removed
    total = 0
    for u, v, w in edges:
        if not removed[u] and not removed[v]:
            total += w
    
    print(total)

if __name__ == "__main__":
    solve()
```
