# Problem B — Campus Network Infrastructure

Time limit: 2 s   Memory limit: 256 MB

## Description

A university campus contains a number of facilities, each assigned a unique integer identifier starting from 1 up to the total number of facilities. A survey has identified a specific set of potential two-way communication links that can be installed between certain pairs of facilities. Each potential link requires a specific financial investment. The layout of these potential links ensures that a message can be routed between any two facilities on campus. Furthermore, this layout is completely free of redundant loops; between any pair of facilities, there is exactly one sequence of potential links.

A specific group of these facilities are designated as core facilities. Your task is to select a subset of the surveyed links to install so that all core facilities can communicate with each other. They can communicate directly, or their data can be relayed through other intermediate facilities (which do not need to be core facilities themselves).

Find the minimum total investment required to install a valid network that allows all core facilities to communicate.

## Input

The first line provides three integers: the total number of facilities, the number of potential links, and the number of core facilities. The campus maintains at least one facility, up to a maximum physical capacity of 200,000 facilities. The total number of potential links provided is exactly one less than the number of facilities. The core facility count is at least one, and can be up to the total number of facilities present.
The second line lists the distinct integer identifiers of the core facilities.
Each subsequent line describes a potential link using three integers: the two distinct facilities it connects, and the investment required. A facility cannot link to itself. The investment is a strictly positive integer subject to a single-link funding cap of 1,000,000.

## Output

Output a single integer representing the minimum total investment needed to ensure all core facilities are connected.

## Examples

```

**Output**

8

```
