# Problem B — Campus Network Infrastructure

Time limit: 2 s   Memory limit: 256 MB

## Description

A university campus is expanding its digital infrastructure. The campus has **n** buildings, identified by integers from 1 to **n**. The university's master plan caps the maximum number of buildings at two hundred thousand, and there is always at least one building. 

The IT department has identified **m** possible bidirectional fiber-optic connections that can be laid between specific pairs of buildings. To avoid redundant wiring, the proposed connections are designed such that if all of them were installed, there would be exactly one physical path of cables between any two buildings on campus. Consequently, the total number of proposed connections **m** is exactly one less than the number of buildings. Each connection requires a specific installation cost. The cost for any single connection is at least one, and budget rules cap the cost of any single connection at one million.

Certain buildings house critical servers; these **t** buildings are designated as core facilities. There is at least one core facility, and depending on the campus configuration, up to all **n** buildings could be core facilities. 

Your task is to choose a subset of the proposed connections to install so that all core facilities can transmit data to one another. Data can be relayed through intermediate buildings, which do not need to be core facilities themselves. 

Find the minimum total installation cost required to ensure all core facilities are interconnected.

## Input

The first line of input provides three integers **n**, **m**, and **t**, representing the number of buildings, proposed connections, and core facilities, respectively.
The second line lists the **t** distinct integer identifiers of the core facilities.
Each of the subsequent **m** lines contains three integers **u**, **v**, and **w**, representing a proposed connection between building **u** and building **v** (which are always distinct) with an installation cost of **w**.

## Output

Output a single integer representing the minimum total installation cost needed to ensure all core facilities are connected.

## Examples

### Example 1

**Input**
```

3 4 2
```

**Output**

8
```

```
