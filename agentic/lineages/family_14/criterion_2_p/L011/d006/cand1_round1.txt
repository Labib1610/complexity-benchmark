<METHOD_NAME>Binary State Connectivity Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the subset-partition definition of connectivity with a functionally equivalent logic definition based on universal binary state assignments. To satisfy the new condition, any non-uniform binary coloring of the subset must have an edge with differing endpoint colors. This forces the model to deduce that the condition simply means the induced subgraph is connected, entirely removing graph terminology and subset partitions.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Quantum State Entanglement

Time limit: 2 s   Memory limit: 256 MB

## Description

You are analyzing a quantum computing system consisting of $n$ modules, numbered 1 to $n$. You are provided with a list of $m$ potential entanglement channels between these modules. Each channel connects two distinct modules and has a positive maintenance cost.

The $m$ channels are configured such that the entire system of $n$ modules is fully *entangled*. A subset of modules $K$ is defined as *entangled* if, for every possible assignment of binary states (0 or 1) to the modules in $K$, at least one of the following two conditions holds:
1. All modules in $K$ are assigned the identical state.
2. There exists at least one channel from the $m$ provided channels that connects a module $u \in K$ and a module $v \in K$ such that $u$ and $v$ are assigned different states.

(A subset consisting of a single module inherently satisfies the first condition for any state assignment, and is thus entangled).

A specific set of $t$ modules are designated as **target modules**. Your objective is to select a subset of modules, called the **active subset**, satisfying the following conditions:
1. The active subset must include all $t$ target modules.
2. The active subset itself must be *entangled*.

When you select the active subset, you activate exactly those channels that have BOTH of their connected modules within the active subset. Channels that have one or zero modules in the active subset are not activated.

The total cost of your selection is the sum of the maintenance costs of all activated channels. Determine the minimum total cost required to form a valid active subset.

## Input

The first line provides three integers $n$, $m$, and $t$. The facility's physical capacity restricts the number of modules $n$ to at most two hundred thousand. The number of target modules $t$ is at least one and cannot exceed the total number of modules. To prevent interference, the number of channels $m$ is exactly the minimum possible number required to ensure a system of $n$ modules is fully entangled. 

The second line provides $t$ distinct integers representing the labels of the target modules.

Each of the subsequent $m$ lines provides three integers $u$, $v$, and $w$. These indicate a channel between module $u$ and module $v$ (where $u$ and $v$ are distinct valid module labels). The maintenance cost $w$ is a positive integer not exceeding one million.

## Output

Output a single integer representing the minimum total cost of the activated channels.

<RATIONALE>
The explicit subset-partition definition of connectivity was replaced with a logically equivalent definition using universal binary state assignments, masking the graph structure. The explicit `m = n - 1` bound was replaced with an indirect constraint stating that $m$ is the minimum number required for the system to be entangled. This forces the model to deduce that "entangled" means "connected", and therefore the minimum edges for $n$ vertices is $n-1$, making the graph a tree.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that any binary state assignment must either be uniform or have a cross-state channel is mathematically equivalent to the subset being connected, so the set of valid active subsets and their costs remains exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure is still finding the minimal spanning tree for a set of target vertices in a tree graph, which remains solvable in O(n) time.
</PRESERVED_CLASS>
<RISK>
Models might struggle to evaluate the indirect bound for $m$ if they fail to equate the binary state condition to graph connectivity, but the mathematical definition is unambiguous and exact.
</RISK>
