<METHOD_DESCRIPTION>
Frames the graph connectivity requirement as a dimension constraint on the intersection of two vector subspaces. This translates "vertices in the same connected component" into "basis vectors satisfying a linear dependency", successfully hiding the tree structure and Steiner tree shortcut behind linear algebra concepts. Models relying on pattern-matching will likely attempt $O(N^3)$ matrix operations and TLE, while models that genuinely reason through the mathematics will recover the $O(N)$ tree algorithm.
</METHOD_DESCRIPTION>

<STATEMENT>
# Subspace Intersection Optimization

Time limit: 2 s   Memory limit: 256 MB

## Description

You are working in an **n**-dimensional real vector space equipped with a standard basis $e_1, e_2, \dots, e_n$.

You are given a pool of **m** candidate vectors. Each candidate vector is defined by a pair of distinct indices $u$ and $v$, and takes the exact form $e_u - e_v$. Including a candidate vector in your selection incurs a specific computational overhead $w$. The full pool of candidate vectors is comprehensive enough that, if you were to select all **m** of them, their linear span would have a dimension of exactly $n - 1$.

Within this space, a subset of **t** basis vectors are designated as target dimensions. Let $V_T$ be the subspace spanned exclusively by these **t** target basis vectors (i.e., $V_T = \text{span}(\{e_z \mid z \text{ is a target index}\})$).

Your objective is to choose a subset of the candidate vectors such that, if $S$ is the linear span of your chosen subset, the dimension of the intersection subspace $S \cap V_T$ is exactly $t - 1$. 

Determine the minimum total overhead required to select a valid subset of candidate vectors that satisfies this dimension requirement.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ n, 1 ≤ n ≤ 200000, m = n − 1).
The second line provides **t** distinct integers representing the indices of the target dimensions.
Each of the subsequent **m** lines provides three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that a candidate vector $e_u - e_v$ can be selected with an overhead of **w**.

## Output

Output a single integer representing the minimum total overhead needed to ensure the dimension of $S \cap V_T$ is exactly $t - 1$.

## Examples

### Example 1

**Input**
```
4 3 2
1 4
1 2 5
2 3 1
3 4 2
```

**Output**
```
8
```

**Output**
```

```

```
2 3 5
```

**Output**
```
9
```

<RATIONALE>
I changed the problem from enforcing equality constraints between variables to selecting difference vectors to satisfy a subspace intersection dimension constraint. This forces the model to mathematically prove that $\dim(S \cap V_T) = t - 1$ is equivalent to all target basis vectors belonging to a single connected component of the selected vectors, preventing superficial pattern-matching to tree or graph algorithms.
</RATIONALE>
<PRESERVED_ANSWER>
The dimension of the intersection subspace $S \cap V_T$ is exactly $t - k$, where $k$ is the number of connected components intersecting $T$, so requiring it to be $t - 1$ mathematically mandates selecting a subset of vectors that forms a connected tree spanning all targets, making the optimal cost identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Since the underlying combinatorial requirement remains finding the minimum weight subtree connecting a set of target vertices in a tree, the optimal solution is still found in $O(n)$ time using exactly the same graph traversal.
</PRESERVED_CLASS>
<RISK>
Models might struggle with the continuous real vector space framing if they suspect floating-point precision issues, though the problem is purely combinatorial and exact over any field.
</RISK>
