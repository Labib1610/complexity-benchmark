# Problem B — Equivalence Relation Generation

Time limit: 2 s   Memory limit: 256 MB

## Description

You are working with a base set $X$ consisting of $n$ distinct elements, identified by integers from 1 to $n$. You are provided with a pool of $m$ generating pairs. Each pair $\{u, v\}$ links two elements of $X$ and has an associated scalar cost $w$. 

This pool of pairs is known to generate a single equivalence class containing all $n$ elements. Because it contains no redundant pairs, the total number of pairs $m$ is exactly one less than $n$.

A specific subset $Y \subseteq X$ containing $t$ elements is designated as the core set. Your objective is to select a subset of the generating pairs to construct a new relation, $\sim$. The relation $\sim$ is defined as the equivalence relation generated by your selected pairs (that is, the reflexive, symmetric, and transitive closure of the chosen pairs). 

Your selection must ensure that all $t$ elements of the core set $Y$ fall into the exact same equivalence class under $\sim$. Each generating pair you select adds its scalar cost $w$ to your total expense. Find the absolute minimum total expense required to select a valid subset of pairs that satisfies this condition for the core set.

## Input

The first line provides three integers $n$, $m$, and $t$ ($1 \le t \le n \le 200000$, $m = n - 1$).
The second line provides $t$ distinct integers, representing the identifiers of the elements in the core set $Y$.
Each of the subsequent $m$ lines provides three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), specifying a generating pair between element $u$ and element $v$ with a scalar cost of $w$.

## Output

Output a single integer representing the minimum total cost of the selected generating pairs.

<RATIONALE>
I changed the problem framing from a constraint satisfaction network to generating an equivalence relation using a subset of pairs. This forces the model to mathematically deduce that the "minimal generating set" of $n-1$ pairs forms a tree, and that connecting the core set requires isolating the unique spanning subtree. The "equivalence relation" terminology strongly baits surface-level pattern matchers into using Disjoint Set Union (DSU) and Kruskal's algorithm, which fails here because Kruskal's will greedily include cheap edges that do not contribute to connecting the core set.
</RATIONALE>
<PRESERVED_ANSWER>
The minimum cost to place the core elements in the same equivalence class using a subset of the given $n-1$ pairs is mathematically identical to finding the minimum weight subtree spanning those elements, so all outputs remain exactly the same.
</PRESERVED_ANSWER>

The underlying structure remains finding a minimal spanning subtree on a given tree, which is solvable in O(n) time using DFS or BFS to prune unneeded leaves.
</PRESERVED_CLASS>
