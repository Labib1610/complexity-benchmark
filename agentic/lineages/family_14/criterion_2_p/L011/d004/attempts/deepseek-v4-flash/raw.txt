We can solve this by noting that the graph is a tree, and we need the minimal connected subgraph that contains all required sites.  

That’s equivalent to finding the **Steiner tree** on a tree, which is simply the union of all paths between required sites. The minimal cost is the sum of edges in the minimal subtree that connects all required nodes.

We can do this efficiently:

1. Mark required nodes.
2. Do a DFS from any required node to compute distances and track which edges are needed.
3. The needed edges are those that lie on paths between required nodes.

A standard method:
- Root the tree at any required node.
- For each node, compute how many required nodes are in its subtree.
- An edge (parent–child) is needed if the child’s subtree contains at least one required node **and** the rest of the tree also contains at least one required node (i.e., not all required nodes are in that subtree).

We can compute this with a single DFS.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    required = set(map(int, input().split()))
    
    adj = [[] for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
        edges.append((u, v, w))
    
    # Root at any required node
    root = next(iter(required))
    
    parent = [0] * (n + 1)
    parent_w = [0] * (n + 1)
    order = []
    stack = [root]
    parent[root] = -1
    while stack:
        u = stack.pop()
        order.append(u)
        for v, w in adj[u]:
            if v == parent[u]:
                continue
            parent[v] = u
            parent_w[v] = w
            stack.append(v)
    
    # Count required nodes in subtree
    cnt = [0] * (n + 1)
    for u in required:
        cnt[u] = 1
    
    total_cost = 0
    # Process in reverse order (post-order)
    for u in reversed(order):
        if u == root:
            continue
        p = parent[u]
        cnt[p] += cnt[u]
        # Edge (p, u) is needed if subtree has at least 1 required
        # and not all required are in that subtree
        if cnt[u] > 0 and cnt[u] < t:
            total_cost += parent_w[u]
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
