<STATEMENT>
# Problem A — Binomial Ideal Generators

Time limit: 5 s   Memory limit: 256 MB

## Description

You are studying a polynomial ring over the real numbers with **n** variables, $x_1, x_2, \dots, x_n$. You are presented with a catalog of **m** available binomials, each of the form $x_u - x_v$. Each binomial has an associated acquisition cost **w**.

You may select a subset of these binomials to form a generating set $G$. Let $I = \langle G \rangle$ be the ideal generated by your selected subset $G$. Recall that $I$ consists of all finite sums $\sum p_i g_i$ where $p_i$ are any polynomials in the ring and $g_i \in G$.

You are given a specific set of **t** target variables. Your objective is to ensure that for any pair of target variables $x_a$ and $x_b$, their difference $x_a - x_b$ is an element of the ideal $I$. You may include binomials in $G$ that contain non-target variables if it helps achieve the objective at a lower total acquisition cost.

Determine the minimum total cost of a generating set $G$ that satisfies this condition.

The problem parameters are bounded as follows:
- The number of target variables **t** is a positive integer at most the total number of distinct digits in the decimal numeral system.
- The total number of variables **n** is a positive integer at most the square of the maximum possible value for **t**.
- The number of available binomials **m** is a non-negative integer at most the number of unique two-element subsets of the **n** variables.
- The cost **w** of any binomial is a positive integer at most one million.
- The indices **u** and **v** for any binomial are distinct and between 1 and **n** inclusive.

## Input

The first line contains three integers **n**, **m**, and **t**.
The second line provides **t** distinct integers representing the indices of the target variables.
The subsequent **m** lines each contain three integers **u**, **v**, and **w**, describing an available binomial $x_u - x_v$ and its acquisition cost **w**. (Note: $x_u - x_v$ generates the same ideal as $x_v - x_u$, so the order of **u** and **v** does not matter).
It is guaranteed that purchasing all available binomials would successfully satisfy the condition.

## Output

Print a single integer: the minimum total cost to purchase a generating set $G$ that satisfies the objective.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, purchasing the binomials $x_1 - x_4$, $x_2 - x_4$, and $x_3 - x_4$ costs $1+1+1 = 3$. This choice allows us to express the differences between any pair of the target variables $\{x_1, x_2, x_3\}$. For instance, $x_1 - x_2 = 1 \cdot (x_1 - x_4) - 1 \cdot (x_2 - x_4)$, which demonstrates that it is an element of the ideal. This is more economical than purchasing binomials that only involve the target variables directly (which would cost 4).

In Example 3, there is only a single target variable, so no differences need to be formed. The minimum cost is 0.

</PRESERVED_ANSWER>
