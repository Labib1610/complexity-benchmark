<STATEMENT>
# Problem A — Subspace Spanning Vectors

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing a linear algebraic structure involving **n** formal basis vectors, denoted $x_1, x_2, \dots, x_n$. Among these, exactly **t** basis vectors are designated as the *objective targets*.

You are provided with a catalog of **m** available *elementary difference vectors*. Each available difference vector is of the form $x_u - x_v$, and has a procurement cost of **w**. 

When you procure a subset of these vectors, they span a linear subspace over the real numbers. Your task is to select a subset of the available difference vectors to procure, such that for every pair of objective targets $x_a$ and $x_b$, the vector $x_a - x_b$ lies within the linear subspace spanned by your procured subset. 

You may procure difference vectors involving basis vectors that are not objective targets; these can serve as intermediate basis elements to span the required vectors at a lower total cost.

Determine the minimum total cost required to procure a subset of elementary difference vectors that satisfies this subspace condition.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ t ≤ 10). The integer **t** is the number of objective targets.
The second line provides **t** distinct integers representing the identifiers of these objective targets.
The subsequent **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), describing an available elementary difference vector $x_u - x_v$ for a procurement cost of **w**.
It is guaranteed that procuring all available difference vectors would successfully satisfy the condition for all objective targets.

## Output

Print a single integer: the minimum total cost to procure a subset of elementary difference vectors that satisfies the subspace condition.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, procuring $x_1 - x_4$, $x_2 - x_4$, and $x_3 - x_4$ (costing 1+1+1 = 3) allows us to span $x_1 - x_2 = (x_1 - x_4) - (x_2 - x_4)$, $x_2 - x_3 = (x_2 - x_4) - (x_3 - x_4)$, and $x_1 - x_3 = (x_1 - x_4) - (x_3 - x_4)$. This uses the non-target basis vector $x_4$ as an intermediate and is more economical than procuring the direct differences among the targets (which would cost 4). 
In Example 3, there is only a single objective target. Since there are no pairs of distinct targets, the subspace condition is trivially satisfied with an empty subset, costing 0.
</STATEMENT>
<RATIONALE>
The problem was reframed from graph connectivity (synchronization modules enforcing equality) to linear algebra (elementary difference vectors spanning a subspace). The underlying mathematical structure remains identical because the linear span of a set of edge vectors contains a difference between two basis vectors if and only if those two basis vectors belong to the same connected component in the corresponding graph. This disguise prevents models from triggering on standard graph terminology or Steiner Tree heuristics, forcing them to genuinely analyze the algebraic condition to reconstruct the optimal connected subgraph.
</RATIONALE>
<PRESERVED_ANSWER>
The linear span of elementary difference vectors $x_u - x_v$ contains $x_a - x_b$ if and only if $a$ and $b$ are connected by the procured vectors, meaning the minimum cost to satisfy the subspace condition is identical to the minimum cost to connect the targets.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to the Steiner Tree problem on a weighted graph, preserving its NP-complete complexity class.
</PRESERVED_CLASS>
<RISK>
A model might incorrectly assume that fractional or non-integer coefficients in the linear span could allow satisfying the condition without full connectivity, though standard algebraic graph theory proves this is impossible (the incidence matrix is totally unimodular and components strictly partition the space).
</RISK>
