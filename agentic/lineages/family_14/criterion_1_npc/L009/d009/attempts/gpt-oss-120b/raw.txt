**Solution Explanation**

For a vector `b_u + b_v` we can think of an (undirected) edge `u – v` with
cost `w`.  
The row space generated by a set of such vectors is exactly the
*cut‑space* of the graph formed by the chosen edges.
For two vertices `x , y`

```
b_x + b_y  is in the cut‑space   ⇔   there exists a path between x and y
```

Therefore the requirement  

```
for every pair of priority coordinates x , y   :   b_x + b_y ∈ V
```

is equivalent to

```
all priority vertices must lie in one connected component
```

i.e. we have to choose a set of edges of minimum total cost that connects
all given terminals.  
That is the **Steiner Tree** problem in an undirected graph with
`n ≤ 100` vertices and at most `t ≤ 10` terminals.
The classic DP over subsets solves it in `O(3^t·n + 2^t·m)` which is easily
fast enough.

--------------------------------------------------------------------

#### 1.   DP definition  

`term[i]` – the i‑th priority vertex, `i = 0 … t‑1`  

`mask` – bitmask of terminals already connected (`0 … 2^t‑1`)  

`dp[mask][v]` – minimal cost of a subgraph that

* connects exactly the terminals whose bits are set in `mask`,
* and **contains vertex `v`** (the subgraph may have other vertices).

The answer will be `min_v dp[fullMask][v]` where `fullMask = (1<<t)-1`.

--------------------------------------------------------------------

#### 2.   Initialisation  

For each terminal `i`

```
dp[1<<i][term[i]] = 0
dp[1<<i][v] = INF   for v ≠ term[i]
```

All other `dp` entries are `INF`.

--------------------------------------------------------------------

#### 3.   Subset combination  

For a fixed `mask` we can split it into two non‑empty disjoint parts
`sub` and `mask ^ sub`.  
If both parts already have a Steiner tree ending in the same vertex `v`,
their union also ends in `v` and costs the sum.

```
dp[mask][v] = min over sub ⊂ mask, sub≠0, sub≠mask
              ( dp[sub][v] + dp[mask ^ sub][v] )
```

We only need to consider `sub` that are proper non‑empty subsets.
Iterating `sub = (mask-1) & mask` downwards enumerates all of them.

--------------------------------------------------------------------

#### 4.   Propagation through edges (Dijkstra)  

After the combination step `dp[mask][*]` may still be improved by
adding ordinary edges: moving the “root” from `u` to a neighbour `v`
costs the edge weight.

For each `mask` we run Dijkstra on the original graph with initial
distances `dp[mask][*]`. The result replaces `dp[mask][*]`.

Complexity of one Dijkstra: `O(m log n)`.  
We run it for every `mask` (`2^t` masks) → `O(2^t·m log n)` which is fine
(`t ≤ 10`).

--------------------------------------------------------------------

#### 5.   Whole algorithm  

```
read input
build adjacency list
fullMask = (1<<t) - 1
dp = [ [INF]*n for _ in range(1<<t) ]

initialise single‑terminal masks

for mask from 1 to fullMask:
        # combine smaller subsets
        sub = (mask-1) & mask
        while sub:
                other = mask ^ sub
                for v in 0..n-1:
                        dp[mask][v] = min(dp[mask][v],
                                          dp[sub][v] + dp[other][v])
                sub = (sub-1) & mask

        # Dijkstra to spread through edges
        run Dijkstra with start distances dp[mask][*]
        (standard heap, relax neighbours)

answer = min(dp[fullMask][v] for v in 0..n-1)
print(answer)
```

All indices are converted to `0‑based`.

--------------------------------------------------------------------

#### 6.   Correctness Proof  

We prove that the algorithm outputs the minimum possible total cost.

---

##### Lemma 1  
For any mask and vertex `v`, after the Dijkstra step finishes,
`dp[mask][v]` equals the minimum cost of a subgraph that

* connects exactly the terminals of `mask`,
* contains vertex `v`,
* and is a **tree** (acyclic).

**Proof.**  
The Dijkstra step starts from the values obtained by the combination
rule, which already represent some (possibly disconnected) union of
trees whose root is `v`. Adding edges via Dijkstra corresponds to
extending the tree by a cheapest path from the current root to another
vertex, which never creates a cycle because we always keep a single root
`v`. Dijkstra computes the cheapest way to reach every vertex from any
already reachable configuration, therefore the resulting value is the
minimum cost of a tree with the required properties. ∎



##### Lemma 2  
For any mask and vertex `v`, after the combination step (before Dijkstra)
`dp[mask][v]` equals the minimum cost of a **forest** (disjoint union of
trees) that

* connects exactly the terminals of `mask`,
* each tree of the forest contains `v`.

**Proof.**  
Induction over the number of bits in `mask`.

*Base*: `|mask| = 1`. Initialization gives cost `0` when `v` is the
terminal itself, `INF` otherwise – exactly the cheapest forest (a single
tree consisting of that terminal).

*Induction*: assume statement true for all proper non‑empty subsets.
Take any optimal forest for `mask` with root `v`. The forest can be split
into two sub‑forests whose terminal sets are `sub` and `mask^sub`
(`sub` is the set of terminals in the component of `v` after removing
one edge incident to `v`). Their costs are `dp[sub][v]` and
`dp[mask^sub][v]` by induction hypothesis, therefore the total cost is at
least the minimum over all such splits, which is exactly what the
combination rule computes. Conversely, taking the best split and joining
the two optimal forests yields a feasible forest of that cost. ∎



##### Lemma 3  
After both combination and Dijkstra for a mask are finished,
`dp[mask][v]` equals the minimum cost of a **Steiner tree** that connects
all terminals of `mask` and contains `v`.

**Proof.**  
From Lemma&nbsp;2 we have the cheapest forest with root `v`. Adding edges
via Dijkstra can only connect different components of that forest,
never increasing the number of components without paying the edge weight.
The cheapest way to turn the forest into a single connected tree is
exactly the shortest‑path relaxation performed by Dijkstra, therefore the
resulting value is the optimum Steiner tree cost with root `v`. ∎



##### Lemma 4  
For the full mask `F = (1<<t)-1`, `min_v dp[F][v]` equals the minimum
cost of any subgraph that connects all priority vertices.

**Proof.**  
Any connected subgraph containing all terminals has at least one vertex
`v`. Its cost is at least the optimum Steiner tree cost with root `v`,
i.e. `dp[F][v]`. Taking the minimum over `v` gives a lower bound.
Conversely, the optimal Steiner tree for the mask attains that minimum,
so the bound is tight. ∎



##### Theorem  
The algorithm outputs the minimum possible total cost of a subset of
given vectors such that every pair of priority coordinates `x, y`
satisfies `b_x + b_y ∈ V`.

**Proof.**  
By the equivalence between vector span and graph connectivity,
the problem is exactly the minimum cost to connect all priority vertices.
By Lemma&nbsp;4 the algorithm returns the optimum cost of such a
connection, therefore it is optimal for the original problem. ∎



--------------------------------------------------------------------

#### 7.   Complexity Analysis  

*Number of masks*: `2^t ≤ 1024`  

*Combination step*: for each mask we iterate all proper sub‑masks  
`∑_{mask} 2^{|mask|} = 3^t` and for each sub‑mask we scan all `n ≤ 100`
vertices.  
`O(3^t · n) ≤ 3^10·100 ≈ 590 k`.

*Dijkstra*: `2^t` times, each `O(m log n)`.  
`m ≤ n·(n-1)/2 ≤ 4950`.  
`2^10·4950·log 100` ≈ `5·10^6` operations.

Both time and memory (`dp` size `2^t·n ≤ 1024·100 = 102 400` integers) fit
comfortably into the limits.

#### 8.   Reference Implementation  (Python 3)

```python
import sys
import heapq

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))
    terminals = [int(next(it)) - 1 for _ in range(t)]

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        adj[u].append((v, w))
        adj[v].append((u, w))

    INF = 10**18
    full = (1 << t) - 1
    dp = [[INF] * n for _ in range(1 << t)]

    # initialise single terminal masks
    for i, v in enumerate(terminals):
        dp[1 << i][v] = 0

    # iterate masks
    for mask in range(1, full + 1):
        # combine submasks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            # only need to combine when both parts are non‑empty
            if other:
                dpm = dp[mask]
                dps = dp[sub]
                dpo = dp[other]
                for v in range(n):
                    val = dps[v] + dpo[v]
                    if val < dpm[v]:
                        dpm[v] = val
            sub = (sub - 1) & mask

        # Dijkstra to propagate through edges
        dist = dp[mask][:]
        heap = [(dist[v], v) for v in range(n) if dist[v] < INF]
        heapq.heapify(heap)
        while heap:
            d, u = heapq.heappop(heap)
            if d != dist[u]:
                continue
            for v, w in adj[u]:
                nd = d + w
                if nd < dist[v]:
                    dist[v] = nd
                    heapq.heappush(heap, (nd, v))
        dp[mask] = dist

    ans = min(dp[full])
    print(ans)

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input‑output format.
