# Problem A — Linking the Priority Facilities

Time limit: 5 s   Memory limit: 256 MB

## Description

A regional development initiative spans **n** distinct districts, numbered 1 through **n**. Among these, exactly **t** districts carry a special regulatory certificate designating them as priority facilities.

You are tasked with deploying a unified data grid across the region. Available to you is a catalogue of potential optical links, where each link can bridge two different districts for a specific cost.

Your goal is to select a subset of these optical links that guarantees full data exchange between all priority facilities. Any two priority facilities can communicate if there is a path of selected optical links connecting them, which may pass through any number of other districts. Districts lacking the priority designation are completely optional: they can be used to route the grid if doing so reduces the overall expense, or they can be ignored entirely.

Calculate the minimum total expense required to procure a set of optical links that fully integrates all priority facilities.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ t ≤ 10). The integer **t** is the number of certified priority facilities.
The second line provides **t** distinct integers representing the identifiers of these priority facilities.
The subsequent **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), describing an optical link that bridges district **u** and district **v** for a cost of **w**.
It is guaranteed that the available links can successfully integrate all priority facilities.

## Output

Print a single integer: the minimum total expense to integrate all priority facilities.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, routing the grid through the optional district 4 (costing 1+1+1 = 3) is more economical than bridging the three priority facilities directly (which would cost 4). In Example 3, there is only a single priority facility, meaning no optical links are required.
