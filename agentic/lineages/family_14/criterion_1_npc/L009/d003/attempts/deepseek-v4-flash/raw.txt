 We can solve this by treating it as a **Steiner tree** problem, but since the number of priority facilities is small (≤ 10), we can use **bitmask DP** over the terminals.

Here’s the approach:

1. Run **Floyd–Warshall** to get shortest paths between all pairs of nodes.
2. Let `terminals` be the list of priority facility nodes.
3. Use DP:
   - `dp[mask][v]` = minimum cost to connect the set of terminals in `mask`, ending at node `v`.
   - Initialize for each terminal `i`: `dp[1 << i][terminals[i]] = 0`.
4. Transition:
   - Combine two disjoint masks: `dp[mask1 | mask2][v] = min(dp[mask1][v] + dp[mask2][v])`.
   - Move along shortest paths: `dp[mask][u] = min(dp[mask][v] + dist[v][u])`.
5. Answer is `min(dp[(1 << t) - 1][v])` for any `v`.

Here’s the implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    terminals = list(map(int, input().split()))
    terminals = [x - 1 for x in terminals]  # 0-based

    INF = 10**18
    dist = [[INF] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0

    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        if w < dist[u][v]:
            dist[u][v] = w
            dist[v][u] = w

    # Floyd-Warshall
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]

    # DP over subsets
    full_mask = (1 << t) - 1
    dp = [[INF] * n for _ in range(1 << t)]

    for i in range(t):
        dp[1 << i][terminals[i]] = 0

    for mask in range(1 << t):
        # Combine subsets
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if other > sub:  # avoid double work
                for v in range(n):
                    dp[mask][v] = min(dp[mask][v], dp[sub][v] + dp[other][v])
            sub = (sub - 1) & mask

        # Relax via shortest paths
        for u in range(n):
            if dp[mask][u] < INF:
                for v in range(n):
                    if dist[u][v] < INF:
                        nd = dp[mask][u] + dist[u][v]
                        if nd < dp[mask][v]:
                            dp[mask][v] = nd

    ans = min(dp[full_mask])
    print(ans)

if __name__ == "__main__":
    solve()
```
