# Problem A — Linking the Essential Hubs

Time limit: 5 s   Memory limit: 256 MB

## Description

A regional development project encompasses **n** distinct districts (numbered 1 to **n**). Within this region, certain districts have been designated as essential hubs. Each essential hub has been issued a Tier-1 regulatory certificate. The project plan specifies exactly **t** such certificates.

Your objective is to establish a unified data grid. You are provided with a catalogue of potential optical links, each capable of joining two different districts at a given cost.

You must choose a collection of these optical links so that every essential hub can exchange data with all other essential hubs. Data exchange between any two essential hubs is possible if they are joined by a sequence of chosen optical links. This sequence can traverse any number of intermediate districts. The districts without a Tier-1 certificate are strictly optional; you may route the grid through them if it achieves a lower total cost, or you may bypass them entirely.

Determine the minimum total cost of a collection of optical links that successfully interconnects all essential hubs.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ t ≤ 10). The integer **t** represents the number of essential hubs holding a Tier-1 regulatory certificate.
The second line contains **t** distinct integers: the ids of the essential hubs.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): an optical link joining district **u** and district **v** at cost **w**.
The provided optical links are sufficient to interconnect all essential hubs.

## Output

Print a single integer: the minimum total cost to interconnect all essential hubs.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, routing the grid through the optional district 4 (costs 1+1+1 = 3) is cheaper than joining the three essential hubs directly (which would cost 4). In Example 3 there is only one essential hub, so no optical links are needed.
