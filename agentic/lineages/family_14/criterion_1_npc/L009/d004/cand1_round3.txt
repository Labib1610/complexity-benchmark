# Problem A — Enforcing Target Equivalence

Time limit: 5 s   Memory limit: 256 MB

## Description

An algebraic system contains **n** distinct variables, indexed 1 through **n**. Among these, exactly **t** variables are designated as target variables.

You are provided with a catalogue of potential bidirectional equivalence constraints. Each constraint can bind two different variables together for a specific enforcement cost.

Your objective is to enforce a subset of these constraints such that all target variables are transitively bound to each other. Any two target variables are considered bound if there is a sequence of enforced constraints connecting them, which may pass through any number of other variables. Variables lacking the target designation are optional: they can be used to chain constraints if doing so reduces the overall expense, or they can be ignored entirely.

Calculate the minimum total expense required to enforce a set of constraints that fully binds all target variables together.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ t ≤ 10). The integer **t** is the number of target variables.
The second line provides **t** distinct integers representing the identifiers of these target variables.
The subsequent **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), describing a constraint that binds variable **u** and variable **v** for a cost of **w**.
It is guaranteed that the available constraints can successfully bind all target variables.

## Output

Print a single integer: the minimum total enforcement expense to bind all target variables together.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, chaining the constraints through the optional variable 4 (costing 1+1+1 = 3) is more economical than binding the three target variables directly (which would cost 4). In Example 3, there is only a single target variable, so no constraints need to be enforced.
