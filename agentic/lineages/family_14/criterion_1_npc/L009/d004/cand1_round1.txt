<METHOD_NAME>Boolean Satisfiability Cut Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Translates the graph connectivity requirement of a Steiner Tree into an equivalent logical condition on boolean assignments. Instead of asking for a connected subgraph containing all terminals, it asks for a subset of equality constraints (edges) that makes it impossible to assign boolean values to all variables such that the constraints are satisfied but the terminal variables take divergent values. This is mathematically identical to requiring the terminals to be in the same connected component (as any valid 2-partition corresponds to a cut separating the terminals), but completely hides all graph and networking terminology.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<STATEMENT>
# Problem A — Resolving the Observable States

Time limit: 5 s   Memory limit: 256 MB

## Description

A system consists of **n** discrete variables, numbered 1 through **n**. Each variable can take a state of either 0 or 1. Among these variables, exactly **t** are designated as *observables*.

You can impose constraints on the system. There is a catalogue of **m** potential *bonds* available. A bond between variable **u** and variable **v** costs **w** to activate, and enforces the strict condition that variable **u** and variable **v** must hold the identical state.

You need to activate a subset of these bonds such that the system is *macroscopically resolved*. A subset of bonds achieves this if it strictly prevents the observables from diverging. Specifically, the subset is macroscopically resolved if it is **impossible** to find any global assignment of 0s and 1s to the **n** variables that simultaneously satisfies both of the following conditions:
1. Every activated bond is respected (i.e., for every activated bond between **u** and **v**, variables **u** and **v** share the same state).
2. The observables are not uniform (i.e., at least one observable is assigned 0, and at least one observable is assigned 1).

Variables that are not observables do not have strict uniformity requirements on their own; they simply follow the states dictated by the bonds you activate. You may activate bonds involving any variables if it helps satisfy the resolution requirement for a lower total cost, or you can ignore them entirely.

Calculate the minimum total cost to activate a subset of bonds that makes the system macroscopically resolved.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ t ≤ 10). The integer **t** is the number of observables.
The second line provides **t** distinct integers representing the identifiers of the observables.
The subsequent **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), describing a potential bond between variable **u** and variable **v** with an activation cost of **w**.
It is guaranteed that it is possible to make the system macroscopically resolved using the available bonds.

## Output

Print a single integer: the minimum total cost to make the system macroscopically resolved.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, activating bonds (1,4), (2,4), and (3,4) costs 1+1+1 = 3. Suppose we try to assign states to variables 1, 2, 3, 4 to violate the resolution. If we respect the bonds, variable 1 must match 4, variable 2 must match 4, and variable 3 must match 4. Thus, variables 1, 2, 3, and 4 must all share the exact same state. The observables (1, 2, and 3) will therefore all have the same state. It is impossible to assign them divergent states (e.g., some 0 and some 1). This subset of bonds is valid. Activating bonds between the observables directly without using variable 4 would cost 4.

In Example 3, there is only 1 observable. Condition 2 requires at least one observable to be 0 and at least one to be 1. This is impossible with only a single observable, meaning the empty subset of bonds (cost 0) is already macroscopically resolved.
</STATEMENT>
<RATIONALE>
I reformulated the Steiner Tree connectivity requirement into a logically equivalent cut condition on boolean assignments. By framing the problem as finding a minimum-cost set of equality constraints that makes a divergent boolean assignment impossible, models are forced to independently discover that this logical condition is mathematically identical to connecting all terminal nodes in a graph, completely bypassing their pattern-matching for Steiner Tree DP.
</RATIONALE>
<PRESERVED_ANSWER>
The impossibility of finding a boolean assignment that respects the bonds while diverging the observables is logically identical to requiring all observables to be in the same connected component formed by the activated bonds, preserving the exact Steiner Tree objective and costs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Steiner Tree problem on a graph, which is NP-complete, with the variables acting as vertices, bonds as edges, and observables as terminals.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret "global assignment" as requiring the bonds to dictate the states of all variables, but the phrase "Variables that are not observables do not have strict uniformity requirements on their own" clarifies that isolated variables simply act independently.
</RISK>
