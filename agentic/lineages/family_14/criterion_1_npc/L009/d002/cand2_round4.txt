# Problem A — Territorial Transit Grid

Time limit: 5 s   Memory limit: 256 MB

## Description

A territorial infrastructure initiative spans **n** districts (indexed 1..n). Your objective is to deploy a transit grid. Within this territory, **t** particular districts are identified as primary centers. 

You are provided with a catalog of potential links. Each link connects two distinct districts for a given expense. You must choose a collection of these links so that all primary centers have mutual access. Two centers have mutual access if they are joined by a chain of chosen links, which can traverse any amount of intermediate districts. 

The ordinary districts are strictly optional; you can route the grid through them if it lowers the overall expense, or bypass them entirely. Determine the minimum overall expense of a collection of links that guarantees all primary centers are mutually accessible.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2). Due to administrative limits, the quantity **t** is at least 1, and at most the number of years in a decade.
The second line contains **t** distinct integers: the identifiers of the primary centers.
Each of the following **m** lines provides three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): a potential link connecting district **u** and district **v** for an expense of **w**.
The provided links are guaranteed to be sufficient to connect all primary centers.

## Output

Output a single integer: the minimum overall expense to ensure all primary centers are connected.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, routing the transit grid through the optional district 4 (expenses 1+1+1 = 3) is cheaper than linking the three primary centers directly (which would incur an expense of 4). In Example 3, there is only one primary center, so zero links are required.
</STATEMENT>
<RATIONALE>
Changed the explicit bound `t <= 10` to an indirect bound ("number of years in a decade") to prevent models from easily pattern-matching the small parameter that enables exponential dynamic programming. The other bounds are kept as strictly formatted inequalities to ensure exact machine-readability of the I/O contract. The scenario terminology was shifted from "zones/communication" to "districts/transit".
</RATIONALE>
<PRESERVED_ANSWER>
The problem still asks for the minimum total weight of a subgraph connecting a specific subset of vertices, preserving all graph structure and costs, so the output for any input remains identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the Steiner Tree problem on graphs, meaning it fundamentally requires the same computational complexity (NP-complete) and intended DP approach.
</PRESERVED_CLASS>
<RISK>
The phrase "number of years in a decade" could be considered slightly narrative, though it unambiguously means exactly 10 and is a standard fact.
