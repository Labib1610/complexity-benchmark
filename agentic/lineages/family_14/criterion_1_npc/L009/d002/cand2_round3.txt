<STATEMENT>
# Problem A — Integrating the Priority Centers

Time limit: 5 s   Memory limit: 256 MB

## Description

A regional initiative oversees **n** designated areas, identified by integers from 1 to n. Within this region, a specific subset of **t** areas are classified as priority centers.

Your objective is to deploy a unified transmission grid. You are provided with a catalogue of potential links, where each link can bridge two distinct areas for a given installation expense.

You must activate a collection of these links so that every priority center is integrated into a single communicating framework. Two priority centers can exchange information if they are joined by a chain of activated links. This chain is permitted to transit through any sequence of other areas. The standard, non-priority areas are strictly optional; you are free to utilize them as transit points if it yields a cheaper overall deployment, or bypass them entirely.

Determine the lowest possible total expense required to activate a valid collection of links that fully integrates all priority centers.

## Input

The first line specifies three integers **n**, **m**, and **t**. The region's zoning laws allow for **n** designated areas, numbering from 1 up to a maximum of 100. The number of potential links **m** can range from 0 up to the theoretical limit of n·(n−1)/2. The priority centers are governed by a special council that requires exactly one representative per priority center; the council's charter mandates a minimum of 1 member and a maximum of 10 members, strictly defining the limits for **t**.

The second line contains **t** distinct integers: the identifiers of the priority centers.

Each of the following **m** lines provides three integers **u**, **v**, and **w**. These represent a potential link bridging area **u** and area **v** (where u and v are distinct integers between 1 and n), requiring an installation expense **w** (scaled between 1 and 1000000 credits).

You are guaranteed that the catalogue of links is sufficient to integrate all priority centers.

## Output

Print a single integer: the lowest possible total expense to integrate all priority centers.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, routing the transmission through the optional area 4 (incurring expenses of 1+1+1 = 3) is more economical than bridging the three priority centers directly (which would total 4). In Example 3, there is only one priority center, so no links need to be activated.
