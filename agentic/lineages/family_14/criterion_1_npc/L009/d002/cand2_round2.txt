# Problem A — Linking the Priority Sites

Time limit: 5 s   Memory limit: 256 MB

## Description

A regional infrastructure initiative involves **n** locations (numbered 1 to **n**). Within this region, **t** specific locations are designated as priority sites that require continuous coordination. 

You must build a unified transmission grid. You are provided with a catalog of surveyed connections, each capable of linking two distinct locations in exchange for a certain amount of resources. 

Your objective is to activate a subset of these surveyed connections so that all priority sites are fully linked. Two priority sites are considered linked if there is a path of activated connections between them. This path may traverse any number of intermediate locations. The non-priority locations are strictly optional; you can route your grid through them if it decreases the overall resources used, or you can bypass them entirely.

Determine the minimum total resources required to activate a set of connections that ensures every priority site is linked into the same grid.

## Input

The first line contains three integers **n**, **m**, and **t**. The total number of locations **n** is between 1 and 100. The number of priority sites **t** is at least 1, and cannot exceed the region's limit of 10 emergency response channels. The number of surveyed connections **m** ranges from 0 up to a theoretical maximum of n·(n−1)/2.

The second line contains **t** distinct integers: the ids of the priority sites.

Each of the next **m** lines contains three integers **u**, **v**, and **w**. These specify a connection joining location **u** and location **v** (where **u** and **v** are distinct integers between 1 and **n**). The resources required for this connection, **w**, will be at least 1 and will not exceed the budget cap of 1000000.

The provided connections are guaranteed to be sufficient to link all priority sites.

## Output

Print a single integer: the minimum total resources to link all priority sites.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, routing the transmission grid through the optional location 4 (resources 1+1+1 = 3) is cheaper than linking the three priority sites directly (which would require 4). In Example 3 there is only one priority site, so no connections are needed.
