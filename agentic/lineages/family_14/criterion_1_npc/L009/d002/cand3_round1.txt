# Problem A — Unified Portfolio

Time limit: 5 s
Memory limit: 256 MB

## Description
A private equity firm is restructuring a market consisting of **n** independent corporations (numbered 1 to n). Among these, a specific set of **t** corporations are deemed "core assets."

The firm's goal is to ensure all core assets belong to a single unified conglomerate. To achieve this, the firm can sponsor bilateral integration agreements. You are provided with a list of proposed agreements, each of which binds two distinct corporations together for a specific legal and administrative cost. 

When two corporations sign an agreement, they become part of the same conglomerate. This relationship is transitive: if corporation A is integrated with B, and B is integrated with C, then A, B, and C all belong to the same conglomerate. The firm can also sponsor agreements involving non-core corporations if using them as intermediaries results in a cheaper overall restructuring.

Determine the minimum total cost of a set of agreements that must be sponsored so that all core assets are integrated into the same conglomerate.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the identifiers of the core assets.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), representing a proposed integration agreement between corporation **u** and corporation **v** at a cost of **w**.
The provided proposals are always sufficient to unify all core assets.

## Output

Print a single integer: the minimum total cost of the agreements required to unify all core assets.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, unifying the core assets (1, 2, and 3) through the non-core corporation 4 requires three agreements (1-4, 2-4, and 3-4) for a total cost of 3. This is cheaper than unifying them directly without corporation 4 (which would cost 4). In Example 3, there is only one core asset, so it is already unified with itself and no agreements need to be sponsored.
