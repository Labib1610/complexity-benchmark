# Problem A — Upgrading the Campus Infrastructure

Time limit: 5 s
Memory limit: 256 MB

## Description

A university is executing a three-phase infrastructure overhaul: surveying, planning, and installation.

In the surveying phase, the grounds were divided into **n** distinct zones (identified by integers 1 to n). The engineers identified **m** potential segments where fiber-optic lines could be buried, each carrying a specific financial cost to deploy between two zones. 

You are responsible for the planning phase. The university administration has designated **t** specific zones as "critical hubs." Your objective is to authorize a subset of the potential fiber-optic lines such that data can successfully traverse between any two critical hubs. To achieve this, data can jump across multiple authorized lines, passing through any number of non-critical zones, which act as passive repeaters. Non-critical zones do not need to be integrated into this data-sharing unless they serve as useful stepping stones.

Calculate the lowest possible total financial cost to authorize a valid subset of lines that integrates all critical hubs. 

During the final installation phase, the physical lines will be laid based on the budget you determine.

## Input

The first line provides three integers: **n**, **m**, and **t**. The total number of zones **n** is between 1 and 100. The number of potential segments **m** is between 0 and n·(n−1)/2. The number of critical hubs **t** is between 1 and 10.
The second line lists **t** distinct integers representing the identifiers of the critical hubs.
The subsequent **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that a fiber-optic segment can be deployed between zone **u** and zone **v** for a cost of **w**.
It is guaranteed that the provided segments are sufficient to integrate all critical hubs.

## Output

Output a single integer representing the absolute minimum total cost required to ensure all critical hubs can communicate.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, utilizing the non-critical zone 4 as a passive repeater (costing 1+1+1 = 3) is a more economical choice than linking the three critical hubs directly (which would total 4). In Example 3, there is only one critical hub, meaning no lines need to be authorized.
