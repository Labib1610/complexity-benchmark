# Problem A — Grid Planning

Time limit: 5 s   Memory limit: 256 MB

## Description

A communications grid is being planned across $n$ distinct locations (numbered 1 to $n$). Some locations are deemed critical and must be able to communicate with each other. You are given a list of $t$ critical locations. The other locations are optional and can be used to relay the signal if it is cost-effective.

There are $m$ possible bidirectional links that can be built, each with a specific cost. Your objective is to select a subset of these links such that all critical locations are mutually connected (either directly or via other locations), minimizing the sum of the costs of the selected links.

## Input

The first line of input provides three integers: $n$, $m$, and $t$. 
The infrastructure can support up to a maximum capacity of 100 locations, so $n$ is between 1 and 100. 
The number of links $m$ ranges from a minimum of 0 up to a fully connected grid of $n(n-1)/2$. 
The critical locations require specialized transceivers; the inventory has exactly 10 in stock, meaning $t$ is at least 1 and at most 10.

The second line lists the $t$ distinct identifiers of the critical locations.

Then, $m$ lines follow, each describing a possible link with three integers $u$, $v$, and $w$. 
The identifiers $u$ and $v$ represent distinct locations (between 1 and $n$, with $u \neq v$). 
The cost $w$ of building the link is at least 1 and capped by a maximum grant of 1000000.

It is guaranteed that the available links are sufficient to connect all critical locations.

## Output

Print a single integer: the minimum total cost to connect all critical locations.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, utilizing the optional relay location 4 (costing 1+1+1 = 3) is cheaper than linking the three critical locations directly (which would cost 4). In Example 3, there is only one critical location, so no links are needed.
