<STATEMENT>
# Problem A — Orbit Procurement

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing the symmetric group $S_n$ acting on the domain $X = \{1, 2, \ldots, n\}$.

You are provided with a catalog of available transpositions. Each catalog entry offers a specific transposition $\tau = (u, v)$ that you may procure for a given weight $w$.

You are also given a specific subset $T \subseteq X$ consisting of $t$ target elements.

Your objective is to procure a subset of the available transpositions, denoted as $E$, such that the subgroup $G = \langle E \rangle$ generated by $E$ satisfies the following condition:
All elements of $T$ must belong to the exact same orbit under the natural action of $G$ on $X$.

In other words, for any two target elements $a, b \in T$, there must exist at least one permutation $\pi$ in the generated subgroup $G$ such that $\pi(a) = b$.

Calculate the minimum total weight of transpositions you must procure to satisfy this condition.

## Input

The first line contains three integers **n**, **m**, and **t**.
The integer **t** is the number of target elements. Its maximum possible value is exactly the fourth triangular number.
The integer **n** is the size of the domain $X$, which is at most the square of the maximum possible value of **t**.
The integer **m** is the number of available transpositions, which will not exceed the total number of distinct pairs of elements in the domain.
The second line provides **t** distinct integers from $1$ to **n**, representing the elements of the target set $T$.
The subsequent **m** lines each contain three integers **u**, **v**, and **w** ($u \neq v$), describing a catalog entry that provides the transposition $(u, v)$ for a procurement weight of **w**. The weight **w** is a positive integer not exceeding the cube of the maximum possible value of **n**.
It is guaranteed that procuring all available transpositions would be sufficient to satisfy the condition for the target set.

## Output

Print a single integer: the minimum total weight of transpositions to satisfy the condition for the target set.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, procuring the transpositions $(1, 4)$, $(2, 4)$, and $(3, 4)$ incurs a total weight of 1+1+1 = 3. The subgroup generated by these three transpositions contains permutations that can map any element in $\{1, 2, 3, 4\}$ to any other element. For instance, the sequence of transpositions $(1, 4)$ followed by $(2, 4)$ yields a permutation that maps 1 to 2. Thus, the target elements 1, 2, and 3 all belong to the same orbit. This is more economical than selecting a subset of transpositions that do not involve element 4 (which would cost at least 4).

In Example 3, there is only a single target element. The condition that all target elements must belong to the same orbit is vacuously satisfied by the trivial subgroup generated by an empty set of transpositions, resulting in a cost of 0.
