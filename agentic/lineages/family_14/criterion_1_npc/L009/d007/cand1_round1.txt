<STATEMENT>
# Problem A — Data Partition Procurement

Time limit: 5 s   Memory limit: 256 MB

## Description

You are configuring a classification system for $n$ distinct data points. Within this dataset, a specific set of $t$ points are designated as objective targets.

You are tasked with procuring a subset of equivalence rules from a provided catalog. Each catalog entry allows you to enforce a rule that point $u$ and point $v$ must be assigned to the exact same group, for a specified procurement expense.

A classification of the $n$ points is considered *valid* if it satisfies all the equivalence rules you have procured. For any chosen subset of rules, let $K$ be the maximum possible number of groups that a valid classification can partition the $n$ points into (where each point belongs to exactly one group).

Your goal is to select a subset of equivalence rules such that, if a new, overriding requirement were introduced forcing all $t$ objective targets to be assigned to the exact same group, the maximum possible number of groups $K$ in a valid classification would remain completely unchanged.

Calculate the minimum total expense required to procure a subset of rules that satisfies this condition.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ t ≤ 10). The integer **t** is the number of objective targets.
The second line provides **t** distinct integers representing the indices of these objective targets.
The subsequent **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), describing a catalog entry that provides an equivalence rule between point **u** and point **v** for a procurement expense of **w**.
It is guaranteed that the available options are sufficient to satisfy the condition for all objective targets.

## Output

Print a single integer: the minimum total expense to satisfy the condition.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, procuring the rules for (1, 4), (2, 4), and (3, 4) incurs a total expense of 1+1+1 = 3. These rules enforce that points 1, 2, 3, and 4 must all be in the same group. Thus, any valid classification can partition the points into at most $K = 1$ group. If the overriding requirement that targets 1, 2, and 3 must share a group is added, the maximum number of groups remains $K = 1$. This is more economical than selecting a subset of rules that do not involve point 4 (which would cost at least 4).

In Example 3, there is only a single objective target. The hypothetical requirement that all objective targets must share the same group is vacuously satisfied by any classification. Therefore, $K$ remains unchanged even if no rules are procured, resulting in a cost of 0.

<RATIONALE>
The problem was completely reframed from a linear algebra condition (which models easily recognized as requiring a connected subgraph) to a combinatorial invariant on partitions. The requirement that the targets are connected is now disguised as the condition that the maximum number of blocks in a valid partition (which equals the number of connected components) remains unchanged when an additional rule forcing the targets together is introduced. This forces the model to mathematically deduce that $K$ remains unchanged if and only if the targets are already in the same connected component, breaking the pattern matching to the Dreyfus-Wagner Steiner Tree algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The maximum number of groups in a valid partition is exactly the number of connected components formed by the procured rules; this number remains unchanged upon forcing the targets together if and only if the targets are already in the same connected component, making it mathematically identical to the original Steiner Tree requirement.
</PRESERVED_ANSWER>

The problem still requires finding a minimum-cost subset of edges to connect a specific set of target vertices, which is exactly the NP-complete Steiner Tree problem.
</PRESERVED_CLASS>

</RISK>
