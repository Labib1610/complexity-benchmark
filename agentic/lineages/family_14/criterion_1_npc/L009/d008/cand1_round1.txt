# Problem A — Subspace Basis Procurement

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing the $n$-dimensional vector space $\mathbb{F}_2^n$ over the finite field of two elements. Let $b_1, b_2, \ldots, b_n$ denote the standard basis vectors of this space. Within this representation, a specific set of $t$ indices are designated as priority coordinates.

You are tasked with procuring a subset of vectors from a provided catalog. Each catalog entry allows you to add a specific vector of the form $b_u + b_v$ (where addition is performed modulo 2) to your chosen subset for a specified procurement expense. 

Your goal is to select a subset of the available vectors to act as a generating set for a subspace $V$. You must ensure that for every pair of distinct priority coordinates $x$ and $y$, the vector $b_x + b_y$ is an element of the generated subspace $V$.

Calculate the minimum total expense required to procure a subset of vectors that satisfies this condition.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ t ≤ 10). The integer **t** is the number of priority coordinates.
The second line provides **t** distinct integers representing the indices of these priority coordinates.
The subsequent **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), describing a catalog entry that provides the vector $b_u + b_v$ for a procurement expense of **w**.
It is guaranteed that the available options are sufficient to satisfy the condition for all priority coordinates.

## Output

Print a single integer: the minimum total expense to satisfy the condition for all priority coordinates.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, procuring the vectors $b_1 + b_4$, $b_2 + b_4$, and $b_3 + b_4$ incurs a total expense of 1+1+1 = 3. The subspace generated by these three vectors contains $b_1 + b_2$ (since $(b_1 + b_4) + (b_2 + b_4) = b_1 + b_2$ modulo 2), as well as $b_2 + b_3$, and $b_1 + b_3$. Consequently, for any pair of the distinct priority coordinates 1, 2, and 3, their corresponding sum is in the subspace. This is more economical than selecting a subset of vectors that do not involve coordinate 4 (which would cost at least 4).

In Example 3, there is only a single priority coordinate. The condition that for every pair of distinct priority coordinates $x$ and $y$, the vector $b_x + b_y$ is in the subspace is vacuously satisfied by an empty subset of vectors, resulting in a cost of 0.

I replaced the group-theoretic subgroup orbit formulation with an isomorphic linear algebra problem over $\mathbb{F}_2^n$. The model must now independently prove that spanning $b_x + b_y$ using vectors $b_u + b_v$ is mathematically identical to finding a connected subgraph containing the target vertices, forcing true structural reasoning instead of relying on NLP pattern matching for graph or permutation keywords.
</RATIONALE>
<PRESERVED_ANSWER>
The vector $b_x + b_y$ is in the linear span of a subset of vectors $b_u + b_v$ over $\mathbb{F}_2$ if and only if $x$ and $y$ belong to the same connected component in the graph formed by the edges $(u, v)$, making the required subset identical in cost to the original orbit condition.
</PRESERVED_ANSWER>

The underlying problem remains exactly the Steiner Tree problem on an undirected graph, which is NP-complete.
