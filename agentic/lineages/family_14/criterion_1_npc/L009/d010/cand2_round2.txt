<METHOD_DESCRIPTION>
Replaces the GF(2) subspace spanning condition with logical deduction over metric space axioms. The target property (ensuring points are connected in a graph) is mathematically isomorphic to ensuring that the triangle inequality forces the distance between those points to be zero. This completely hides the discrete graph structure behind continuous metric-space terminology.
</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Pseudometric Zero-Forcing

Time limit: 5 s   Memory limit: 256 MB

## Description

Consider a pseudometric $d$ on a space of points $S = \{1, 2, \dots, n\}$. By definition, a pseudometric assigns a real number to every pair of points and satisfies the following properties for all points $x, y, z \in S$:
1. $d(x, y) \ge 0$
2. $d(x, x) = 0$
3. $d(x, y) = d(y, x)$
4. $d(x, z) \le d(x, y) + d(y, z)$

A specific subset of $t$ points in $S$ are designated as priority points.

You do not know the exact distances between points, but you have a list of $m$ available constraints you can enforce. Each available option allows you to permanently enforce the condition $d(u, v) = 0$ for a specific pair of points $u$ and $v$. Enforcing this condition incurs a cost of $w$.

You must select a subset of these available options. Your goal is to choose a subset such that, for *any* valid pseudometric $d$ that satisfies all your selected conditions, it is mathematically guaranteed that $d(x, y) = 0$ for every pair of priority points $x$ and $y$.

Calculate the minimum total cost required to select a subset of options that guarantees this property.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2, 1 ≤ t ≤ 10). The integer **t** is the number of priority points.
The second line provides **t** distinct integers representing the identities of these priority points.
The subsequent **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), describing an available option that enforces the condition $d(u, v) = 0$ for a cost of **w**.
It is guaranteed that the available options are sufficient to guarantee $d(x, y) = 0$ for all pairs of priority points $x$ and $y$ if all options were selected.

## Output

Print a single integer: the minimum total cost to satisfy the condition for all priority points.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the constraints $d(1, 4) = 0$, $d(2, 4) = 0$, and $d(3, 4) = 0$ incurs a total cost of 1+1+1 = 3. By the properties of a pseudometric, $d(1, 2) \le d(1, 4) + d(4, 2) = 0 + 0 = 0$, which forces $d(1, 2) = 0$. Similarly, $d(2, 3) = 0$ and $d(1, 3) = 0$ are guaranteed. Consequently, the condition $d(x, y) = 0$ is guaranteed for all pairs among the priority points 1, 2, and 3. This is more economical than selecting a subset of constraints that do not involve point 4 (which would cost at least 4).

In Example 3, there is only a single priority point. The condition that for every pair of priority points $x$ and $y$, $d(x, y) = 0$ is guaranteed, is vacuously satisfied by an empty subset of constraints, resulting in a cost of 0.
</STATEMENT>
<RATIONALE>
The problem has been reframed from GF(2) vector spanning to logical deduction over metric space axioms. Generating a zero-distance between two points strictly requires a chain of zero-distance links (by the triangle inequality), which perfectly preserves the underlying graph-connectivity requirement while completely stripping away graph and linear algebra terminology. This forces the model to independently realize that "guaranteeing distance 0" is isomorphic to "finding a connected component containing the priority points."
</RATIONALE>
<PRESERVED_ANSWER>
The condition that $d(x, y)=0$ is logically forced if and only if $x$ and $y$ are in the same connected component of the chosen zero-distance pairs, making the valid subsets and their costs identical to the seed's graph-spanning formulation.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum-Weight Steiner Tree problem on a graph, which is NP-complete, and can be solved with the exact same Dreyfus-Wagner subset DP algorithm.
</PRESERVED_CLASS>
