<METHOD_DESCRIPTION>Removes the standard `(1 <= t <= 10)` mathematical inequality blocks that LLMs use as surface-level triggers for subset dynamic programming. Instead, bounds are embedded directly into the descriptive prose using scenario capacities (e.g., "hardware guarantees... will not exceed 10"). This forces the model to actually read the text to determine the state space size, defeating pattern matchers that scan for `t <= 10` to decide on exponential time algorithms.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Entanglement Synchronization

Time limit: 5 s   Memory limit: 256 MB

## Description

You are configuring a network of quantum nodes. The nodes are indexed from 1 to **n**. Initially, no nodes are entangled with each other.

You are provided with a list of **m** potential entanglement links. Activating a link between node $u$ and node $v$ costs $w$ microjoules. Entanglement is transitive: if a path of activated links connects two nodes, they are placed into the same entangled state.

Among the nodes, **t** are designated as critical nodes. Your objective is to select a subset of the potential links to activate such that all **t** critical nodes belong to a single connected component of activated links (i.e., they share the exact same entangled state).

You may activate links involving non-critical nodes; these can serve as intermediate connectors between critical nodes if doing so results in a lower total energy cost.

Determine the minimum total microjoules required to ensure that all **t** critical nodes are in the same entangled state. (If there is exactly one critical node, no links need to be activated and the minimum cost is 0).

## Input

The first line contains three integers **n**, **m**, and **t**. The hardware guarantees that the number of critical nodes **t** is at least 1 and will not exceed 10. The total number of nodes **n** is at least **t** and at most 100. The number of potential links **m** is non-negative and will not exceed the number of unique pairs of nodes.
The second line contains **t** distinct integers $c_1, c_2, \dots, c_t$: the indices of the critical nodes.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u ≤ n, 1 ≤ v ≤ n, u ≠ v), indicating that a link can be activated between node **u** and node **v** at a cost of **w** microjoules. The activation cost **w** is a positive integer up to 1,000,000.
It is guaranteed that the available links are sufficient to entangle all critical nodes into the same state.

## Output

Print a single integer: the minimum total microjoules to activate a set of links that satisfies the requirement.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the critical nodes are 1, 2, and 3. You can activate links between (1,4), (2,4), and (3,4) for a total cost of 1+1+1 = 3 microjoules. Because node 1 is entangled with 4, and 2 is entangled with 4, they are in the same state. Similarly, 3 is entangled with 4, so all three critical nodes belong to a single connected component. Alternatively, activating links strictly between critical nodes like (1,2) and (2,3) directly would cost 2+2 = 4 microjoules. The minimum cost is 3. 

In Example 3, there is only one critical node, so no links need to be activated and the minimum cost is 0.

The ambiguous physics terminology from the previous rejected attempt has been replaced with rigorous graph connectivity language.
