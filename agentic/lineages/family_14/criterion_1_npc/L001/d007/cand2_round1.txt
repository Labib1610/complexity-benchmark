# Problem A — Broadcast Initialization

Time limit: 5 s   Memory limit: 256 MB

## Description

You are designing a communication network across **n** relay stations, numbered 1 through **n**. Initially, no stations are connected.

You have a list of **m** potential bidirectional transmission links. Establishing a link between station $u$ and station $v$ requires a one-time hardware cost of $w$. 
Once a link is established, it can carry signals in either direction. Signals can be relayed through multiple connected stations.

There is a specific group of **t** listener stations that must receive a critical broadcast. 
Your objective is to:
1. Select exactly one station to act as the primary broadcast source (this can be any of the **n** stations, including one of the listener stations).
2. Establish a set of transmission links such that a signal emitted from the primary broadcast source can successfully reach all **t** listener stations.

You may establish links involving non-listener stations if they help form a cheaper relay routing. A single established link can route the signal to multiple destinations simultaneously without incurring any additional cost. The total cost of your network is simply the sum of the one-time hardware costs of the links you choose to establish.

Determine the minimum total hardware cost required to establish a valid broadcast network. (If $t=1$, the listener station can be chosen as the broadcast source, requiring no links and costing 0).

## Input

The first line contains three integers **n**, **m**, and **t**, representing the total number of relay stations, the number of potential links, and the number of listener stations. The value of **t** is at least 1 and will never exceed the number of distinct digits in the decimal numeral system. The value of **n** is between 1 and one hundred, and **m** is between 0 and the maximum possible number of distinct pairs of stations.
The second line contains **t** distinct integers $c_1, c_2, \dots, c_t$: the indices of the listener stations.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v), indicating that a link can be established between station u and station v for a hardware cost of w (where w is a positive integer up to one million).
It is guaranteed that it is possible to connect all listener stations.

## Output

Print a single integer: the minimum total hardware cost to establish a set of links that satisfies the requirement.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the listener stations are 1, 2, and 3. You can choose station 4 as the primary broadcast source and establish links (1,4), (2,4), and (3,4) for a total hardware cost of 1+1+1 = 3. The signal from station 4 directly reaches listeners 1, 2, and 3. Alternatively, if you chose station 1 as the source and established links (1,2) and (2,3), the signal would reach station 2 directly and station 3 via relay, but this would cost 2+2 = 4. The minimum possible cost is 3. 

In Example 3, there is only one listener station ($t=1$). You can select station 1 as the primary broadcast source. Since the source is already the listener, no links need to be established, resulting in a minimum cost of 0.

<METHOD_DESCRIPTION>
Reframes the Steiner Tree problem as selecting a single "broadcast source" and routing to all targets. This baits models into using a Shortest Path Tree or Facility Location heuristic (summing shortest paths from a source), which fails because it double-counts shared edges. It also applies S07 to obfuscate the small terminal bound (t <= 10) by expressing it as "the number of distinct digits in the decimal numeral system", disabling prompt-based DP triggers.
</METHOD_DESCRIPTION>

yes
</METHOD_NOVEL>
<RATIONALE>
The problem is reframed from "Equality Entailment" to establishing a "Broadcast Network" from a single source to multiple listeners. This shifts the apparent objective from subset equivalence (which strongly hints at Steiner Tree) to a 1-to-many routing task, baiting greedy shortest-path heuristics. Furthermore, the critical bound `t <= 10` is stated indirectly to prevent models from using regex/pattern matching to automatically allocate exponential DP states.
</RATIONALE>
<PRESERVED_ANSWER>
Finding the minimum cost to connect a chosen source to a set of targets in an undirected graph, where edge costs are paid once regardless of how many paths share them, is mathematically identical to finding the minimum cost connected subgraph containing those targets (since the optimal source will simply be any node within that subgraph).
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the undirected Steiner Tree problem, which is NP-complete, as the requirement is still to find a minimum-weight connected subgraph that spans a specific subset of terminal nodes.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the problem as requiring directed edges (an arborescence), but the phrase "potential bidirectional transmission links" and "can carry signals in either direction" explicitly clarifies the undirected nature.
</RISK>
