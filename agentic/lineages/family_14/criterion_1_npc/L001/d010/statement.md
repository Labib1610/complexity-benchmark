# Problem A — Subgroup Orbit Constraints

Time limit: 5 s   Memory limit: 256 MB

## Description

You are investigating the action of a permutation group on a set of $n$ elements, labeled $1$ through $n$. Your objective is to ensure a specific property holds for a distinguished subset of $t$ target elements, identified by their labels $c_1, c_2, \dots, c_t$.

To achieve this, you can construct a subgroup by acquiring a set of generators. You are provided with a list of $m$ available transpositions. Each transposition exchanges two elements, $u$ and $v$, and has an acquisition cost of $w$. 
When you acquire a transposition, it becomes a generator for your subgroup. The subgroup generated by your chosen set of transpositions partitions the $n$ elements into orbits. Two elements are in the same orbit if and only if there is a sequence of acquired transpositions that moves one element to the other.

You must select a subset of the available transpositions to acquire such that, under the action of the resulting subgroup, all $t$ target elements belong to the exact same orbit. 
You may freely acquire transpositions involving any elements (not just the target ones) if doing so yields a lower total acquisition cost. 

Determine the minimum total acquisition cost required to ensure all $t$ target elements are in the same orbit. If $t=1$, choosing no transpositions yields cost 0.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2), representing the total number of elements, the number of available transpositions, and the number of target elements.
The second line contains **t** distinct integers $c_1, c_2, \dots, c_t$: the labels of the target elements.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that the transposition exchanging $u$ and $v$ can be acquired for a cost of w.
It is guaranteed that acquiring all available transpositions is sufficient to place all target elements in the same orbit.

## Output

Print a single integer: the minimum total acquisition cost.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the target elements are $1, 2$, and $3$. You can acquire the transpositions exchanging $(1, 4)$, $(2, 4)$, and $(3, 4)$ for a total cost of 1+1+1 = 3. 
In the resulting subgroup, elements $1, 2, 3$, and $4$ all belong to the same orbit, fulfilling the condition for the targets. 
Alternatively, you could acquire the transpositions exchanging $(1, 2)$ and $(2, 3)$ for a total cost of 2+2 = 4 to place elements $1, 2$, and $3$ in the same orbit. The minimum cost is 3.

In Example 3, there is only one target element ($t=1$), so no transpositions are needed. The minimum cost is 0.
