<STATEMENT>
# Problem A — Zero-Knowledge Ledger Consensus

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing a decentralized ledger with $n$ distinct accounts. Your objective is to publicly prove that a critical subset of $t$ target accounts all hold the exact same balance.

To accomplish this, you can publish zero-knowledge equivalence proofs. You have access to a repository of $m$ valid proofs. Each proof cryptographically verifies that account $u$ and account $v$ have identical balances, and requires a transaction fee of $w$ to be published on the blockchain. 
Because equality is mathematically transitive, if you publish a proof linking account A to account B, and another linking account B to account C, it is irrevocably established that account A and account C hold the same balance.

You must select a subset of the available proofs to publish such that the $t$ target accounts are all proven to hold the identical underlying value. You are explicitly permitted to publish proofs involving non-target accounts, using them as intermediate logical steps, if doing so yields a lower total transaction fee. 

Determine the minimum total transaction fee required to guarantee all $t$ target accounts are proven equal. (If $t=1$, no proofs are needed, so the minimum fee is 0).

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2), representing the total number of accounts, the number of available proofs, and the number of target accounts.
The second line contains **t** distinct integers $c_1, c_2, \dots, c_t$ (each between 1 and n): the indices of the target accounts.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that a proof establishing equality between account u and account v can be published for a fee of w.
It is guaranteed that the available proofs are sufficient to prove all target accounts are equal.

## Output

Print a single integer: the minimum total transaction fee.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the target accounts are 1, 2, and 3. You can publish the proofs linking 1 and 4, 2 and 4, and 3 and 4 for a total fee of 1+1+1 = 3. Since account 1 equals 4, account 2 equals 4, and account 3 equals 4, it follows logically that 1, 2, and 3 all hold the identical balance. All target accounts are proven equal. 
Alternatively, you could publish the proofs linking 1 and 2, and 2 and 3 for a total fee of 2+2 = 4 to achieve the same result. The minimum fee is 3.

In Example 3, there is only one target account ($t=1$), so no proofs are needed. The minimum fee is 0.
