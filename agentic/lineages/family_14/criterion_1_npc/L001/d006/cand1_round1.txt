<METHOD_NAME>Logical Entailment Isomorphism</METHOD_NAME>
<METHOD_DESCRIPTION>Transforms the connectivity requirement of a Steiner Tree into a logical entailment problem over systems of equations. By framing edges as equality axioms ($V_u = V_v$) and the Steiner tree requirement as the logical entailment of a target equality chain ($V_{c_1} = \dots = V_{c_t}$), it removes all spatial, geometric, and graph-theoretic cues. Models relying on keyword association (like "merge", "stepping stones", "groups") to trigger their Steiner Tree templates will fail to recognize the underlying graph structure, likely attempting SAT-solving or algebraic substitution approaches.</METHOD_DESCRIPTION>

<STATEMENT>
# Axiomatic Entailment

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing a formal verification system comprising **n** unconstrained real-valued variables, indexed 1 through **n**.

You are provided with a repository of **m** available equality axioms. Activating a specific axiom asserts that variable $u$ and variable $v$ are strictly equal ($V_u = V_v$). Selecting this axiom to be active in your proof system incurs a one-time memory cost of $w$ units. 

You are given a query containing a subset of **t** target variables: $c_1, c_2, \dots, c_t$. 
Your objective is to select a subset of the available axioms to activate such that the universal equality of all **t** target variables ($V_{c_1} = V_{c_2} = \dots = V_{c_t}$) is unconditionally entailed by the selected subset. A condition is unconditionally entailed if it holds true for every possible assignment of real numbers to the variables that satisfies all active axioms.

You may activate axioms involving non-target variables; these auxiliary equivalences can form a chain of logical deductions to entail the final requirement at a lower total memory cost. 

Determine the minimum total memory cost required to ensure that the equality of all **t** target variables is entailed. (If $t=1$, the condition is trivially entailed without activating any axioms, and the minimum cost is 0).

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2), representing the total number of variables, the number of available axioms, and the number of target variables.
The second line contains **t** distinct integers $c_1, c_2, \dots, c_t$: the indices of the target variables. The order of these indices does not matter.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that an axiom asserting $V_u = V_v$ can be activated at a cost of w.
It is guaranteed that the available axioms are sufficient to entail the equality of all target variables.

## Output

Print a single integer: the minimum total memory cost to activate a valid subset of axioms.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the target variables are 1, 2, and 3. You can activate the axioms $V_1 = V_4$, $V_2 = V_4$, and $V_3 = V_4$ for a total cost of 1+1+1 = 3 memory units. Because $V_1$ equals $V_4$, and $V_2$ equals $V_4$, it is logically entailed that $V_1 = V_2$. Similarly, $V_3$ equals $V_4$, so the universal equality $V_1 = V_2 = V_3$ is unconditionally entailed. Alternatively, activating the axioms $V_1 = V_2$ and $V_2 = V_3$ directly would cost 2+2 = 4 units. The minimum cost is 3. 

In Example 3, there is only one target variable ($t=1$), so no axioms need to be activated and the minimum cost is 0.

<RATIONALE>
I changed the framing from merging elements into groups to selecting equality axioms to logically entail a universal equality among target variables. This forces the model to deduce that logical entailment of equality is mathematically isomorphic to finding a connected component in a graph, thus requiring it to derive the Steiner Tree reduction from first principles rather than relying on surface patterns like "merge" or "stepping stones".
</RATIONALE>
<PRESERVED_ANSWER>
Every valid subset of axioms corresponds to a set of edges, and the target equality is entailed if and only if the target variables reside in the same equivalence class (connected component), meaning the minimum cost to entail the equality is exactly the minimum cost Steiner Tree.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the exact same Minimum Steiner Tree problem in an undirected graph, which is NP-complete, with identical parameters and structurally identical constraints.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret "unconstrained variables" as boolean variables and attempt to solve it using 2-SAT or propositional logic, but the explicit mention of "assignment of real numbers" prevents any domain-size loopholes.
</RISK>
