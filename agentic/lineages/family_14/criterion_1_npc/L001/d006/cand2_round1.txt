<METHOD_DESCRIPTION>
Reframes the graph connectivity problem as a system of algebraic equality constraints. Vertices become independent variables, edges become optional equality constraints, and the target component becomes a required logical implication. This shifts the semantic domain away from graphs and networks toward constraint satisfaction and logic, which may prevent the model from recognizing the Steiner Tree structure and instead prompt it to attempt SAT/SMT or integer linear programming approaches.
</METHOD_DESCRIPTION>

yes

<STATEMENT>
# Problem A — Constraint Implication

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing a mathematical model consisting of **n** independent integer variables, $x_1, x_2, \dots, x_n$. Initially, these variables are completely unconstrained and can take any arbitrary values.

You are provided with a catalog of **m** optional equality constraints. Each constraint specifies that two particular variables, $x_u$ and $x_v$, must be strictly equal. Enforcing this specific constraint incurs a computational penalty of $w$.

You are also given a target list containing **t** specific variable indices: $c_1, c_2, \dots, c_t$. 
Your objective is to select a subset of the optional constraints to enforce such that their combined application logically guarantees that all **t** target variables must evaluate to the exact same value (i.e., $x_{c_1} = x_{c_2} = \dots = x_{c_t}$ for all possible assignments satisfying the chosen constraints). 

You are permitted to enforce constraints that involve variables outside the target list. Because equality is transitive, these auxiliary variables can act as logical bridges to deduce the equality of the target variables, which may result in a lower total penalty.

Determine the minimum total penalty required to enforce a valid subset of constraints. (If $t=1$, the condition is trivially satisfied with no constraints, and the minimum penalty is 0).

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2), representing the total number of variables, the number of available constraints, and the number of target variables.
The second line contains **t** distinct integers $c_1, c_2, \dots, c_t$: the indices of the target variables. The order of these indices does not matter.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that the constraint $x_u = x_v$ can be enforced for a penalty of $w$.
It is guaranteed that the available constraints are sufficient to logically guarantee the equality of all target variables.

## Output

Print a single integer: the minimum total penalty to enforce a subset of constraints that satisfies the requirement.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the target variables are $x_1$, $x_2$, and $x_3$. You can enforce the constraints $x_1 = x_4$, $x_2 = x_4$, and $x_3 = x_4$ for a total penalty of 1+1+1 = 3. Because $x_1 = x_4$ and $x_2 = x_4$, it mathematically follows that $x_1 = x_2$. Similarly, $x_3 = x_4$ implies $x_1 = x_2 = x_3$. Enforcing the constraints $x_1 = x_2$ and $x_2 = x_3$ directly would incur a penalty of 2+2 = 4. The minimum penalty is 3.

In Example 3, there is only one target variable ($t=1$), so no constraints need to be enforced and the minimum penalty is 0.
</STATEMENT>
<RATIONALE>
The problem was reframed from unifying groups to enforcing equality constraints among variables. This shifts the conceptual domain from sets/graphs to algebra and logic, forcing the model to independently deduce that transitive equality implication is isomorphic to graph connectivity, bypassing superficial pattern matching on "merging groups".
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical condition for a set of equality equations to guarantee that a subset of variables are equal is exactly that those variables are connected in the graph where equations are edges; thus, the minimum cost to achieve this is identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the Steiner Tree problem on an undirected graph, which is NP-complete, simply presented using the isomorphism between connected components and equivalence classes.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "logically guarantees" as allowing complex algebraic manipulations, but since the variables are uniformly independent and the only available constraints are direct equalities, only transitive equality applies, making the risk of ambiguity very low.
</RISK>
