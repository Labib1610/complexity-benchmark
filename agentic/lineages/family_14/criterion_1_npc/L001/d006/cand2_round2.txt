<STATEMENT>
# Problem A — Variable Alignment

Time limit: 5 s   Memory limit: 256 MB

## Description

You are configuring a system of **n** variables, denoted $x_1, x_2, \dots, x_n$. Initially, these variables can hold arbitrary independent values.

You are provided with a list of **m** available equality constraints. An equality constraint between variable $x_u$ and variable $x_v$ forces their values to be equal ($x_u = x_v$). Enforcing this specific constraint incurs a one-time penalty of $w$ units.

You are given a query containing a subset of **t** target variables: $x_{c_1}, x_{c_2}, \dots, x_{c_t}$. 
Your objective is to select a subset of the available equality constraints to enforce such that, as a logical consequence of the selected constraints, all **t** target variables must be equal to one another.

You may select constraints involving non-target variables; these can be included in the chosen subset if they result in a lower total penalty.

Determine the minimum total penalty required to ensure that all **t** target variables hold the same value. (When $t=1$, the requirement is already satisfied, and the minimum penalty is 0).

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2), representing the total number of variables, the number of available equality constraints, and the number of target variables.
The second line contains **t** distinct integers $c_1, c_2, \dots, c_t$: the indices of the target variables. The order of these indices does not matter.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that an equality constraint can be enforced between variable $x_u$ and variable $x_v$ at a penalty of w.
It is guaranteed that the available constraints are sufficient to force all target variables to be equal.

## Output

Print a single integer: the minimum total penalty to enforce a set of constraints that satisfies the requirement.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the target variables are $x_1, x_2$, and $x_3$. You can enforce constraints between (1,4), (2,4), and (3,4) for a total penalty of 1+1+1 = 3 units. Because $x_1 = x_4$ and $x_2 = x_4$, it follows that $x_1 = x_2$. Similarly, $x_3 = x_4$, so all three target variables must be equal. Alternatively, enforcing constraints for (1,2) and (2,3) directly would incur a penalty of 2+2 = 4 units. The minimum penalty is 3. 

In Example 3, there is only one target variable ($t=1$), so no constraints are needed and the minimum penalty is 0.

Replaces graph connectivity with a system of variables and equality constraints. The transitive property of equality naturally models path connectivity, obscuring the Steiner Tree graph structure while preserving the exact mathematical properties.

<RATIONALE>
The problem was reframed from a graph-connectivity grouping task into an abstract algebraic constraint-satisfaction problem. The transitive nature of equality constraints perfectly mirrors path connectivity, forcing models to infer that finding the minimum-penalty constraint subset is isomorphic to finding a minimum-weight tree connecting the target vertices.
</RATIONALE>
<PRESERVED_ANSWER>
The transitive closure of equality constraints behaves identically to connected components in a graph, so the minimum penalty to equate target variables is mathematically identical to the minimum weight to connect target vertices.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Steiner Tree problem on an undirected graph, preserving its NP-completeness and the need for bitmask dynamic programming over the target subset.
</PRESERVED_CLASS>
