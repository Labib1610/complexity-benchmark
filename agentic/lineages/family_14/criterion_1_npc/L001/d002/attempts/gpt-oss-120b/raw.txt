**Solution Explanation**

For every bank we know which other banks can be linked to it and the cost of each link.
We have to choose some links so that all *core* banks become equal, i.e. they belong
to the same connected component after the chosen links are installed.
The cheapest possible total cost is required.

The problem is exactly the **Steiner tree** problem on an undirected weighted graph:

* vertices – memory banks (`n ≤ 100`);
* edges – possible links with their costs;
* terminals – the `t ( ≤ 10 )` core banks.

The Steiner tree problem asks for a minimum‑cost subgraph that connects all terminals.
For small `t` the classical DP of Dreyfus‑Wagner solves it in  
`O( 3^t · n + 2^t · (m log n) )`, easily fast for the given limits.



--------------------------------------------------------------------

#### 1.   DP definition  

```
dp[mask][v] = minimum cost of a connected subgraph
              that contains all terminals whose bits are set in mask
              and whose (any) vertex v belongs to this subgraph.
```

`mask` runs over all `2^t` subsets, `v` over the `n` vertices.

Initially  

```
for each terminal i (0‑based):
        dp[1<<i][terminal_i] = 0
all other entries = INF
```

--------------------------------------------------------------------

#### 2.   Merging two already solved subsets  

For a fixed `mask` we try to split it into two non‑empty complementary parts
`sub` and `mask ^ sub`.  
If both parts already have a Steiner tree that ends in the same vertex `v`,
their union is also a feasible tree for the whole `mask`.

```
dp[mask][v] = min( dp[sub][v] + dp[mask^sub][v] )    over all proper sub ⊂ mask
```

The loop over all `sub` of a mask costs `O(3^t)` over the whole DP,
which is tiny (`t ≤ 10` → `3^t = 59049`).

--------------------------------------------------------------------

#### 3.   Propagation through the graph (Dijkstra)

After the merging step `dp[mask][v]` is known **only** for trees that already
contain vertex `v`.  
We may enlarge such a tree by adding ordinary edges – exactly the shortest‑path
relaxation.

For each `mask` we run Dijkstra starting from **all** vertices with the current
`dp[mask][v]` as initial distances.  
The result are the true minima `dp[mask][*]` for this mask.

`n ≤ 100`, `m ≤ n·(n-1)/2`, therefore  
`2^t` Dijkstra runs (`≤ 1024`) are easily inside the limits.

--------------------------------------------------------------------

#### 4.   Answer  

The whole set of terminals corresponds to `full = (1<<t) - 1`.  
The tree may end in any vertex, therefore

```
answer = min_v dp[full][v]
```

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm outputs the minimum possible total cost.

---

##### Lemma 1  
For every mask and vertex `v` after the *merge* step  
`dp[mask][v]` equals the minimum cost of a Steiner tree for `mask`
**that is forced to contain vertex `v`** and whose interior does not use any
edge outside the already processed masks.

**Proof.** Induction over the number of bits in `mask`.

*Base* – `|mask| = 1`.  
`dp[mask][v]` is `0` if `v` is the terminal itself, `INF` otherwise.
That is exactly the minimum cost of a tree that must contain `v` and also the
single terminal – only possible when `v` equals the terminal.

*Induction step.* Assume the statement true for all proper subsets of `mask`.  
Take any tree `T` for `mask` that contains `v`.  
Delete `v` (keeping it) and split `T` into two edge‑disjoint parts,
each containing a non‑empty subset of terminals, say `sub` and `mask\sub`,
both still containing `v`.  
Their costs are at least `dp[sub][v]` and `dp[mask\sub][v]` by the induction
hypothesis. Hence `cost(T) ≥ dp[sub][v] + dp[mask\sub][v]`.
Taking the minimum over all splits yields a lower bound for `dp[mask][v]`.

Conversely, for any split `sub` the concatenation of optimal trees
realizing `dp[sub][v]` and `dp[mask\sub][v]` (both contain `v`) forms a feasible
tree for `mask` with total cost exactly their sum.
Therefore the minimum over splits is achievable, i.e. equals the optimum.
∎



##### Lemma 2  
After the Dijkstra run for a given `mask`,
`dp[mask][v]` equals the minimum cost of **any** Steiner tree for `mask`
that contains `v` (no other restriction).

**Proof.** Dijkstra starts with distances exactly `dp[mask][*]` from Lemma&nbsp;1.
Running Dijkstra on a graph with non‑negative edge weights computes for every
vertex the shortest distance from the set of sources.
Appending a shortest path from the source set to a vertex `v` to the corresponding
tree yields a feasible Steiner tree for `mask` ending in `v` and with cost
`dist(v)`. No cheaper tree can exist, otherwise its restriction to the source set
would give a shorter source‑to‑`v` path, contradicting Dijkstra optimality.
∎



##### Lemma 3  
For every mask, after the algorithm finishes processing it,
`dp[mask][v]` is the true optimum described in Lemma&nbsp;2.

**Proof.** By induction over masks in increasing order of their integer value.
The induction hypothesis guarantees that all proper sub‑masks already satisfy
Lemma&nbsp;2, which is exactly the premise of Lemma&nbsp;1.
Hence after the merge step Lemma&nbsp;1 holds, and after the following Dijkstra
step Lemma&nbsp;2 holds. ∎



##### Lemma 4  
`answer = min_v dp[full][v]` equals the minimum possible total cost of links
that make all core banks equal.

**Proof.** Any feasible set of links induces a connected subgraph containing all
terminals. Pick any vertex `v` inside this subgraph; the subgraph is a Steiner
tree for `full` that contains `v`, therefore its cost is at least
`dp[full][v]`. Consequently the optimum cost is at least `answer`.

Conversely, Lemma&nbsp;3 guarantees existence of a Steiner tree of cost
`dp[full][v]` for each `v`. Taking the cheapest `v` gives a feasible set of
links with total cost `answer`. ∎



##### Theorem  
The algorithm outputs the minimum total hardware cost required to guarantee that
all core memory banks hold the same value.

**Proof.** Directly from Lemma&nbsp;4. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

```
states      : 2^t ≤ 1024
vertices    : n ≤ 100
edges       : m ≤ 4950
```

* Merging step – for each mask all its proper sub‑masks are enumerated:  
  `O(3^t · n)  ≤ 5·10^4 · 100  = 5·10^6`.

* Dijkstra – performed for every mask:  
  `O( 2^t · (m log n) ) ≤ 1024 · 5000 · log 100  < 6·10^6`.

Both together are far below the 5 s limit and use `O(2^t·n)` memory
(~100 KB).

#### 7.   Reference Implementation  (Python 3)

```python
import sys
import heapq

INF = 10**18

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))
    terminals = [int(next(it)) - 1 for _ in range(t)]

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        adj[u].append((v, w))
        adj[v].append((u, w))

    full = (1 << t) - 1
    dp = [[INF] * n for _ in range(1 << t)]

    # initialise single terminals
    for i, v in enumerate(terminals):
        dp[1 << i][v] = 0

    # process all masks
    for mask in range(1, full + 1):
        # merge two proper sub‑masks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if other:
                dp_sub = dp[sub]
                dp_other = dp[other]
                dp_mask = dp[mask]
                for v in range(n):
                    val = dp_sub[v] + dp_other[v]
                    if val < dp_mask[v]:
                        dp_mask[v] = val
            sub = (sub - 1) & mask

        # Dijkstra to propagate through the graph
        dist = dp[mask]
        heap = [(dist[v], v) for v in range(n) if dist[v] < INF]
        heapq.heapify(heap)
        while heap:
            d, u = heapq.heappop(heap)
            if d != dist[u]:
                continue
            for v, w in adj[u]:
                nd = d + w
                if nd < dist[v]:
                    dist[v] = nd
                    heapq.heappush(heap, (nd, v))

    ans = min(dp[full])
    print(ans)


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms to
the required I/O format.
