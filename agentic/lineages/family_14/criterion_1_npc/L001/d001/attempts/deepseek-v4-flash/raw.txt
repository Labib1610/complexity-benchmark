We can solve this by treating it as a **minimum Steiner tree** problem, but since the number of critical registers is at most 10, we can use a **bitmask DP** approach.

Here’s the plan:

1. Run **Floyd–Warshall** to get the shortest path distances between all pairs of nodes.
2. Use **DP over subsets** of critical registers:
   - `dp[mask][v]` = minimum cost to connect the critical registers in `mask` and end at node `v`.
   - Initialize for each critical node `i`: `dp[1 << i][i] = 0`.
   - Combine subsets: for each mask, try merging two submasks.
   - Relax using shortest paths: `dp[mask][v] = min(dp[mask][v], dp[mask][u] + dist[u][v])`.
3. The answer is `min(dp[(1 << t) - 1][v])` over all `v`.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    critical = list(map(int, input().split()))
    critical = [x - 1 for x in critical]  # 0-based

    INF = 10**18
    dist = [[INF] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0

    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        if w < dist[u][v]:
            dist[u][v] = w
            dist[v][u] = w

    # Floyd-Warshall
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]

    full_mask = (1 << t) - 1
    dp = [[INF] * n for _ in range(1 << t)]

    for i in range(t):
        dp[1 << i][critical[i]] = 0

    for mask in range(1 << t):
        # Merge submasks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if other < sub:  # avoid duplicate work
                for v in range(n):
                    best = INF
                    for u in range(n):
                        if dp[sub][u] + dist[u][v] < best:
                            best = dp[sub][u] + dist[u][v]
                    if best + dp[other][v] < dp[mask][v]:
                        dp[mask][v] = best + dp[other][v]
            sub = (sub - 1) & mask

        # Relax via shortest paths
        for u in range(n):
            if dp[mask][u] < INF:
                for v in range(n):
                    if dp[mask][u] + dist[u][v] < dp[mask][v]:
                        dp[mask][v] = dp[mask][u] + dist[u][v]

    ans = min(dp[full_mask])
    print(ans)

if __name__ == "__main__":
    solve()
```
