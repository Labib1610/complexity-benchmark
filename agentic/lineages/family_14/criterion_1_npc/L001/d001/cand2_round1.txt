# Problem A — Quantum Grid Synchronization

Time limit: 5 s   Memory limit: 256 MB

## Description

A quantum communication grid consists of **n** stations. Certain pairs of stations can be linked by a fiber segment for a specific installation cost. Among these stations, exactly **t** are designated as **anchor stations**. To synchronize the grid, all anchor stations must end up communicating with each other through the fiber segments you establish (either directly or routed through intermediate stations). The remaining stations are optional relays: you may route connections through them if it minimizes the total cost, or leave them completely disconnected.

Determine a set of fiber segments to establish such that all anchor stations are fully connected, while minimizing the total installation cost. Report this minimum total cost.

## Input

The first line contains three integers **n**, **m**, and **t**.
The number of anchor stations **t** is at least 1. Each anchor station requires a unique quantum frequency channel; the hardware multiplexer provides exactly 10 such channels, strictly limiting the maximum number of anchor stations.
The total number of stations **n** is at least 1. The grid's addressing protocol restricts identifiers to a maximum capacity of 100 stations.
The number of available fiber segments **m** is non-negative and will not exceed the total number of unordered pairs of distinct stations in the grid.

The second line contains **t** distinct integers: the identifiers of the anchor stations.

Each of the next **m** lines contains three integers **u**, **v**, and **w**, representing a fiber segment that can link station **u** and station **v** (where **u** and **v** are distinct station identifiers between 1 and **n**). The installation cost **w** is at least 1, and no segment's cost exceeds the single-segment grant limit of 1,000,000.

It is guaranteed that the available fiber segments are sufficient to connect all anchor stations.

## Output

Print a single integer: the minimum total installation cost required to connect all anchor stations.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, routing the connections through the optional relay station 4 (which costs 1+1+1 = 3) is cheaper than linking the three anchor stations directly (which would cost 4). In Example 3, there is only a single anchor station, so no fiber segments need to be established.
