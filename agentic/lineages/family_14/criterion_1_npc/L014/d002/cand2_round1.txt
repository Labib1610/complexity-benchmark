<STATEMENT>
# Problem A — Decentralized Ledger Synchronization

Time limit: 5 s   Memory limit: 256 MB

## Description

A global financial consortium oversees an ecosystem of distinct data vaults. By regulatory statute, the consortium's license restricts them to operating a maximum of one hundred such vaults, and mandates at least one vault in the ecosystem. Each vault is assigned a unique identification number starting from 1. 

Within this network, certain vaults are designated as master vaults. The consortium's governance structure dictates that at least one vault, and up to a maximum of ten vaults (corresponding to the ten seats on the executive board), must be designated as master vaults. The remaining vaults, if any, serve as standard relay vaults. 

To ensure consistency, the master vaults must be fully synchronized. This means every master vault must be able to exchange updates with every other master vault. This exchange can happen directly, or it can be routed through a sequence of standard relay vaults. Any vault will automatically forward data across any active connections it has.

There is a list of proposed two-way data bridges that can be activated. Each proposed bridge links two distinct vaults and requires a known integration cost to establish. The cost is always a positive integer of credits, capped at a maximum of one million credits per bridge. The consortium has evaluated every feasible pair of vaults, so the number of proposed bridges ranges from none at all up to a bridge between every possible pair of vaults.

Your task is to select which of the proposed data bridges to activate so that all master vaults are fully synchronized. You may activate bridges that connect to standard relay vaults if it helps reduce the total expense. Determine the minimum possible total integration cost required to achieve this synchronization.

## Input

The first line provides three integers: the total number of vaults, the number of proposed data bridges, and the number of master vaults.
The second line lists the identification numbers of the master vaults.
Following this, each of the remaining lines describes a proposed data bridge using three integers: the two distinct vaults it connects, and the integration cost for that bridge.
It is guaranteed that there is at least one valid way to synchronize all master vaults using the provided list of bridges.

## Output

Output a single integer representing the lowest total integration cost needed to ensure all master vaults can communicate with one another.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, activating the data bridges that route through the standard relay vault 4 (costing 1+1+1 = 3) is more economical than directly linking the three master vaults (which would cost 2+2 = 4). In Example 3, there is only one master vault, meaning no data bridges need to be activated.
