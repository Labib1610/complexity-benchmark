# Problem A — Atmospheric Terraforming

Time limit: 5 s   Memory limit: 256 MB

## Description

A newly discovered planet has **n** distinct atmospheric sectors (numbered 1 to n). To stabilize the climate, you can construct directional wind generators based on available blueprints. Each blueprint specifies a source sector **u**, a target sector **v**, and a construction cost **w**. When constructed, the generator actively pushes air from **u** to **v**. Because atmospheric mass must be conserved, the operation of this generator inherently induces a passive return current from **v** to **u**. Both the active push and the passive return current can be used for drone navigation.

A specific group of **t** sectors are designated as **habitable** zones. Your goal is to select a set of blueprints to construct such that a drone can travel between any pair of habitable zones. Drones may chain together any sequence of active pushes and passive return currents, and their flight paths may pass through sectors that are not habitable zones.

Find the minimum total construction cost required to achieve this goal.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line lists **t** distinct integers representing the ids of the habitable zones.
The following **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000). These represent a blueprint for a generator that can actively push air from sector **u** to sector **v** for a construction cost of **w**.
It is guaranteed that the available blueprints can fulfill the requirement.

## Output

Output a single integer representing the minimum total construction cost required to achieve the goal.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, constructing the generators involving sector 4 (total cost 1+1+1 = 3) allows drones to navigate between any ordered pair among 1, 2, and 3. This is cheaper than constructing generators to navigate between the three habitable zones directly (which would cost 4). In Example 3 there is only one habitable zone, so no generators need to be constructed.
