<STATEMENT>
# Problem A — Subspace Spanning

Time limit: 5 s   Memory limit: 256 MB

## Description

Consider an **n**-dimensional real vector space with the standard basis vectors $e_1, e_2, \dots, e_n$. 

You are given a target set of **t** designated dimensions. Your objective is to ensure that the difference between any two basis vectors from this target set is contained within the linear span of a chosen set of vectors.

You have a list of **m** available vectors to choose from. Each available vector is defined by two indices **u** and **v**, representing the vector $e_u - e_v$. Selecting this vector to be part of your chosen set incurs a cost of **w**. (Note that the linear span of a set of vectors is the set of all their finite linear combinations using real coefficients. Because $e_u - e_v = -(e_v - e_u)$, the order of **u** and **v** in the definition does not change the resulting span).

You may select any subset of the available vectors. The total cost of a subset is the sum of the costs of the vectors it contains. Find the minimum total cost of a selected subset such that for every pair of indices $a$ and $b$ in the target set, the vector $e_a - e_b$ is in the linear span of your selected subset.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line lists **t** distinct integers representing the indices of the target dimensions.
The following **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000). These represent an available vector $e_u - e_v$ that can be selected for a cost of **w**.
It is guaranteed that it is possible to satisfy the condition using the available vectors.

## Output

Output a single integer representing the minimum total cost to select a subset of vectors whose linear span satisfies the requirement.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the target set of dimensions is {1, 2, 3}. Selecting the three vectors involving dimension 4 ($e_1 - e_4$, $e_2 - e_4$, and $e_3 - e_4$) costs 1 + 1 + 1 = 3. 
The vector $e_1 - e_2$ can be formed by the linear combination $(e_1 - e_4) - (e_2 - e_4)$. 
The vector $e_2 - e_3$ can be formed by $(e_2 - e_4) - (e_3 - e_4)$. 
The vector $e_1 - e_3$ can be formed by $(e_1 - e_4) - (e_3 - e_4)$. 
Thus, all required differences between target dimensions are in the linear span of the selected subset. This is cheaper than selecting vectors that directly combine the target dimensions (which would cost 2 + 2 = 4).

In Example 3, there is only one target dimension. For any pair $a, b$ in {1}, $e_1 - e_1$ is the zero vector, which is always in the linear span of the empty set, costing 0.

I completely replaced the corporate-merger (disjoint-set) framing with a rigorous linear algebra isomorphism. The problem of selecting edges to connect a subset of vertices is mathematically identical to selecting incidence vectors $e_u - e_v$ such that their linear span contains $e_a - e_b$ for all target pairs $a, b$. This forces the model to either independently prove this equivalence to undirected graph connectivity or attempt to solve an NP-complete subset-spanning problem in the vector space domain, bypassing pattern matching entirely.
</RATIONALE>
<PRESERVED_ANSWER>
The linear span of a subset of vectors of the form $e_u - e_v$ contains $e_a - e_b$ if and only if $a$ and $b$ are in the same connected component of the graph formed by the corresponding edges (a fundamental property of incidence matrices), meaning the selected subsets and their costs are identical.
</PRESERVED_ANSWER>
