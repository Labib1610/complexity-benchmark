# Problem A — Translating for the Delegated Languages

Time limit: 5 s   Memory limit: 256 MB

## Description

A summit features **n** languages (numbered 1 to n). To facilitate communication, you can acquire translation modules. Each available module is offered for a specific fee and covers a specific pair of languages. Acquiring a module for a pair synchronizes their grammatical structures.

A subset of **t** languages are considered **delegated**. Your objective is to ensure that a document originating in any delegated language can be successfully converted into any other delegated language. To achieve this, documents can undergo multiple consecutive conversions through any chain of synchronized languages. The languages functioning as intermediaries in these consecutive conversions do not need to be delegated themselves.

Determine the minimum total fee needed to acquire a set of modules that satisfies this requirement.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the ids of the delegated languages.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000) representing a translation module covering languages u and v available for fee w.
The available modules are sufficient to satisfy the requirement.

## Output

Print a single integer: the minimum total fee to acquire a valid set of modules.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, acquiring the modules involving language 4 (total fee 1+1+1 = 3) synchronizes a network connecting 1, 2, and 3. This is cheaper than acquiring modules to synchronize the three delegated languages directly (which would cost 4). In Example 3 there is only one delegated language, so no modules need to be acquired.
