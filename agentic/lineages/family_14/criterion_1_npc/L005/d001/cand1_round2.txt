<STATEMENT>
# Problem A — Translating for the Delegated Languages

Time limit: 5 s   Memory limit: 256 MB

## Description

A summit features **n** languages (numbered 1..n). You are offered a catalog of translation services. Each entry in the catalog specifies two languages and a hiring fee. Paying this fee allows you to convert documents from the first language to the second, and simultaneously from the second language to the first. 

Among the languages, **t** are **delegated**. Your objective is to pay for a subset of the catalog entries such that a document starting in any delegated language can be successfully converted into every other delegated language. You may convert documents through any sequence of languages, including those that are not delegated, if you have paid for the necessary entries.

Find the minimum total fee required to purchase a valid subset of catalog entries.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the ids of the delegated languages.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): a catalog entry for languages u and v at fee w.
The available entries are enough to satisfy the requirement.

## Output

Print a single integer: the minimum total fee to satisfy the requirement.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, purchasing the entries that involve language 4 (fees 1+1+1 = 3) is cheaper than purchasing entries exclusively among the three delegated languages (which would cost 4). In Example 3 there is only one delegated language, so no entries need to be purchased.
</STATEMENT>
<RATIONALE>
The problem was reworded to remove the "bridged by a bilingual translator" phrasing that models used to easily recognize and construct an undirected graph. Instead, the problem describes catalog entries that allow document conversion in both directions, forcing the model to infer the undirected graph structure from the symmetric conversion property rather than relying on standard "edge" or "bridge" keywords. Note that the prompt's specific suggestion to explicitly make the model directed was not strictly applied, because doing so would change the answer to Example 1 (and violate Hard Constraint 1).
</RATIONALE>
<PRESERVED_ANSWER>
The answers are identical because the possible connections and their costs are exactly the same, and the requirement of mutual reachability among delegated languages is mathematically equivalent to connecting them in a Steiner Tree.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the Undirected Steiner Tree problem (NP-complete), as the underlying graph and the subset of terminal nodes to connect are unchanged.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "convert documents from the first language to the second, and simultaneously from the second language to the first" as requiring two separate directed edges with separate costs, though "paying this fee allows..." should make it clear the single fee covers both directions.
</RISK>
