<STATEMENT>
# Problem A — Translating for the Delegated Languages

Time limit: 5 s   Memory limit: 256 MB

## Description

A summit features **n** languages (numbered 1 to **n**). You can purchase translation modules. Each module is listed as a pair of languages and a fee.

Among the languages, **t** are **delegated**. You must purchase a set of modules. A set of purchased modules is valid if there is no way to divide all **n** languages into two disjoint groups, $X$ and $Y$, such that:
- Every language is either in $X$ or in $Y$.
- $X$ contains at least one delegated language.
- $Y$ contains at least one delegated language.
- No purchased module consists of one language from $X$ and one language from $Y$.

Find the minimum total fee required to purchase a valid set of modules.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the ids of the delegated languages.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000) representing a translation module between languages **u** and **v** available for fee **w**.
The available modules are enough to satisfy the requirement.

## Output

Print a single integer: the minimum total fee to purchase a valid set of modules.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, purchasing the modules {1-4, 2-4, 3-4} (total fee 1+1+1 = 3) forms a valid set. For instance, if we try to divide the languages into $X=\{1, 4\}$ and $Y=\{2, 3\}$, both contain delegated languages, but the purchased modules 2-4 and 3-4 each consist of one language from $X$ and one from $Y$. Any other division where both $X$ and $Y$ contain at least one delegated language will also have at least one purchased module crossing between the groups. This is cheaper than purchasing modules between the three delegated languages directly (e.g., {1-2, 2-3} would cost 4). In Example 3 there is only one delegated language, so it is impossible for both $X$ and $Y$ to contain a delegated language. Thus, purchasing no modules is valid.
