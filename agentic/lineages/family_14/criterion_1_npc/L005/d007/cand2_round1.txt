<METHOD_NAME>Continuous Lie Group Action Framing</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the static linear subspace spanned by difference vectors with the dynamic action of a continuous Lie group (the orthogonal group) generated by local 2D rotations (Givens rotations). The goal of containing a difference vector is replaced by the goal of finding a composite rotation that maps one basis state exactly to another. This forces the model to deduce that the invariant subspaces of the generated group correspond exactly to the connected components of the underlying graph, hiding the graph connectivity requirement behind continuous geometric transformations.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Subspace Rotation Synthesis

Time limit: 5 s   Memory limit: 256 MB

## Description

You are controlling a system with **n** orthonormal basis states, denoted $s_1, s_2, \ldots, s_n$.

You are given a set of **t** specific states, referred to as the *target states*. Your objective is to acquire the ability to transform any target state into any other target state.

To do this, you can select from a provided list of **m** available *mixing operators*. Each available operator is defined by a pair of states **u** and **v** and has an associated cost of **w**. 

When you purchase the operator for **u** and **v**, you gain the ability to apply arbitrary 2D rotations in the plane spanned by $s_u$ and $s_v$. Specifically, for any chosen angle $\theta$, you can apply a linear transformation $M_{u,v}(\theta)$ which acts on the basis states as follows:
- $s_u \mapsto \cos(\theta)s_u + \sin(\theta)s_v$
- $s_v \mapsto -\sin(\theta)s_u + \cos(\theta)s_v$
- $s_k \mapsto s_k$ for all $k \notin \{u, v\}$

You may choose any subset of the available mixing operators to purchase, paying the sum of their costs. 

Once purchased, you may apply any finite sequence of your available operators, in any order, choosing a specific angle $\theta$ for each application. Let $\mathcal{T}$ be the set of all composite linear transformations that can be formed in this way. (The empty sequence corresponds to the identity transformation).

You must ensure that for every pair of target states $i$ and $j$, there exists at least one composite transformation $R \in \mathcal{T}$ such that $R(s_i) = s_j$ exactly (with a coefficient of +1).

Determine the minimum total cost of a subset of mixing operators that satisfies this requirement.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line lists **t** distinct integers representing the indices of the target states.
The following **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000). These represent an available mixing operator for states $s_u$ and $s_v$ that can be purchased for a cost of **w**. (Note that the operator is symmetric with respect to the plane it rotates, so an operator for $u, v$ provides the exact same capabilities as one for $v, u$).
It is guaranteed that it is possible to satisfy the requirement using the available operators.

## Output

Output a single integer representing the minimum total cost of a subset of mixing operators that allows the required transformations between all target states.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1

3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```

1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the target states are 1, 2, and 3. We require the ability to construct transformations that map $s_1 \to s_2$, $s_2 \to s_3$, $s_1 \to s_3$, etc. By purchasing the three operators for (1,4), (2,4), and (3,4) at a total cost of 1+1+1 = 3, we can form the required transformations. For instance, to transform $s_1$ to $s_2$, we can first apply $M_{1,4}(\pi/2)$ which maps $s_1 \mapsto s_4$, followed by $M_{2,4}(-\pi/2)$ which maps $s_4 \mapsto s_2$. The composite transformation maps $s_1$ exactly to $s_2$. This is cheaper than purchasing the operators for (1,2) and (2,3) directly (which would cost 2+2=4). 

In Example 3, there is only one target state. The requirement is vacuously satisfied by the empty sequence of operators (the identity transformation), so 0 operators need to be purchased.
</STATEMENT>
<RATIONALE>
The problem was completely reframed from finding a static linear subspace that contains difference vectors to synthesizing a continuous Lie group action (Givens rotations) that can map one basis state exactly to another. This forces the model to deduce that the invariant subspaces of the generated orthogonal group correspond exactly to the connected components of the underlying graph. It removes the textual affordances of "difference vector" and "linear span" that models relied on to recognize the Steiner Tree structure.
</RATIONALE>
<PRESERVED_ANSWER>
The orthogonal group generated by a set of 2D rotations decomposes into invariant subspaces that perfectly match the connected components of the chosen operators; thus, mapping $s_i$ to $s_j$ is possible if and only if they belong to the same connected component, making the minimum cost identical to the original Steiner Tree formulation.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Steiner Tree problem on an undirected graph, which is NP-complete, because satisfying the rotation requirement is mathematically equivalent to connecting the target states in the graph induced by the purchased operators.
</PRESERVED_CLASS>
