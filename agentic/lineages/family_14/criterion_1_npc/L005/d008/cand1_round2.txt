<METHOD_DESCRIPTION>Replaces boolean toggles / graph connectivity with the generation of an algebraic difference ideal over variables, masking the Steiner tree structure without using forbidden terms like polynomial.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Algebraic Generator Selection

Time limit: 5 s   Memory limit: 256 MB

## Description

You are working with a formal algebraic system defined over $n$ variables, $x_1, x_2, \dots, x_n$.

You can purchase "difference generators" to build a structural closure. Each available generator is an elementary binomial of the form $(x_u - x_v)$ for two distinct variables $x_u$ and $x_v$. 

Given a purchased subset of generators $S = \{g_1, g_2, \dots, g_k\}$, its algebraic closure is defined as the set of all expressions that can be written in the form:
$E_1 \cdot g_1 + E_2 \cdot g_2 + \dots + E_k \cdot g_k$
where each $E_r$ can be any valid algebraic expression formed by addition, subtraction, and multiplication of real constants and the variables $x_1, \dots, x_n$.

A specific subset of **t** variables are designated as *target variables*. Your task is to purchase a subset of the available generators such that the following condition is satisfied: 
For *every* pair of distinct target variables $x_i$ and $x_j$, the exact expression $(x_i - x_j)$ must belong to the algebraic closure of your purchased subset. 

You are given a list of **m** available generators, each with a one-time purchase cost **w**. Determine the minimum total cost of a subset of generators that satisfies this requirement.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line lists **t** distinct integers representing the indices of the target variables (1-indexed).
The following **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1,000,000). These represent an available generator $(x_u - x_v)$ that can be purchased for a cost of **w**. (Note that the order of $u$ and $v$ does not matter, as $(x_u - x_v)$ and $(x_v - x_u)$ generate the same closure by multiplying by $-1$).
It is guaranteed that it is possible to satisfy the requirement using the available generators.

## Output

Output a single integer representing the minimum total cost of a subset of generators that allows reaching the required closure for all pairs of target variables.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the target variables are $x_1, x_2,$ and $x_3$. We must ensure that $(x_1 - x_2)$, $(x_2 - x_3)$, and $(x_1 - x_3)$ are all in the closure.

By purchasing the three generators $(x_1 - x_4), (x_2 - x_4),$ and $(x_3 - x_4)$ for a total cost of 1+1+1 = 3, we can satisfy the requirement. For instance, to form $(x_1 - x_2)$, we can use the expression $1 \cdot (x_1 - x_4) + (-1) \cdot (x_2 - x_4)$. This is cheaper than purchasing $(x_1 - x_2)$ and $(x_2 - x_3)$ directly, which would cost 2+2=4.

In Example 3, there is only one target variable. Because there are no pairs of distinct target variables, the requirement is vacuously satisfied. No generators need to be purchased, resulting in a cost of 0.
</STATEMENT>
<RATIONALE>
I transformed the problem from boolean flag toggling into building an algebraic closure (an ideal) over variables. This forces the model to mathematically deduce that generating the exact binomial $(x_i - x_j)$ from a set of differences is equivalent to finding a connected component in a graph, thus hiding the Steiner Tree structure behind algebraic formalism while strictly avoiding banned terminology like "polynomial".
</RATIONALE>
<PRESERVED_ANSWER>
The target binomial $(x_i - x_j)$ belongs to the algebraic closure of a set of differences if and only if variables $x_i$ and $x_j$ are in the same connected component, making it mathematically identical to the original connectivity requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Steiner Tree problem in a graph, which maintains its NP-complete complexity.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the algebraic closure as allowing division or other operations not explicitly stated, though the text strictly limits it to addition, subtraction, and multiplication.
</RISK>
