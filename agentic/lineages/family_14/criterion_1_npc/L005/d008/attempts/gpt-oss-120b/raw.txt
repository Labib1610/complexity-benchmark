**Solution Explanation**

For every purchased procedure (edge) `e = (u , v)` we can apply it any number of
times.
Applying it once adds `1` to the parity of `u` and `v`.
All possible parity vectors that can be created are exactly the **GF(2)**
linear span of the edge incidence vectors  

```
e → vector with 1 at u and v, 0 elsewhere
```

--------------------------------------------------------------------

#### 1.   What is required?

For every two different regulated ledgers `i , j` we must be able to obtain
the parity vector  

```
p(i,j) : 1 at i and j, 0 elsewhere
```

All such vectors together generate **all even‑weight vectors on the set of
regulated vertices** (any even number of 1’s can be written as a sum of pair
vectors).  
Therefore the purchased edges have to span a subspace of dimension  

```
|R| – 1          (|R| = number of regulated vertices)
```

restricted to the rows belonging to regulated vertices.

--------------------------------------------------------------------

#### 2.   Graph interpretation

For an undirected graph the incidence matrix over GF(2) has rank  

```
rank = n – (#connected components)
```

because in each component the sum of all its rows is the zero vector and
there are no other linear dependencies.

Consequences for a set of purchased edges `E` :

* let `C(E)` be the number of connected components that contain at least one
  regulated vertex,
* the rows of regulated vertices have rank `|R| – C(E)`.

We need rank `|R| – 1`, therefore  

```
C(E) = 1
```

i.e. **all regulated vertices must lie in one connected component** of the
chosen edges.  
No other condition is necessary.

So the problem is exactly:

> Choose a minimum‑cost set of edges that connects all regulated vertices.

That is the **Steiner Tree** problem with at most `t ≤ 10` terminals,
`n ≤ 100`.  
We solve it with the classic DP over subsets (Dreyfus‑Wagner algorithm).

--------------------------------------------------------------------

#### 3.   DP formulation

Number the regulated vertices `r[0] … r[t‑1]`.

```
dp[mask][v] = minimum cost of a tree
              that connects the terminals whose bits are 1 in mask
              and whose (any) root is vertex v
```

`mask` runs over `0 … (1<<t)-1`, `v` over `1 … n`.

*Initialization*  

```
for each i:
    dp[1<<i][r[i]] = 0
    dp[1<<i][v≠r[i]] = INF
```

*Combination*  

For a non‑single mask we try to split it into two non‑empty disjoint parts
that share the same root `v`.

```
dp[mask][v] = min over sub ⊂ mask, sub≠0, sub≠mask
              ( dp[sub][v] + dp[mask ^ sub][v] )
```

*Propagation through edges*  

After the combination step the tree may be extended by adding one more edge.
That is a shortest‑path relaxation:

```
run Dijkstra (or SPFA) on the graph with initial distances = dp[mask][*]
edges are undirected with weight w
```

The result of the Dijkstra becomes the new `dp[mask][*]`.

We process masks in increasing order of their size, because every sub‑mask
has already been computed.

*Answer*  

```
full = (1<<t) - 1
answer = min_v dp[full][v]
```

If `t ≤ 1` the requirement is vacuous, answer = 0.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm returns the minimum possible total cost.

---

##### Lemma 1  
For any set of purchased edges `E`, the regulated vertices are connected in
`E` **iff** the parity vectors `p(i,j)` (for all regulated `i≠j`) belong to the
GF(2) span of the incidence vectors of `E`.

**Proof.**  
If the regulated vertices are in one component, the rank of the incidence
matrix restricted to those rows is `|R|-1` (as shown above), which equals the
dimension of the space generated by all `p(i,j)`. Hence every `p(i,j)` is in
the span.

Conversely, if the regulated vertices lie in at least two components, the
rank is at most `|R|-2`, so the span cannot contain all `p(i,j)`. ∎



##### Lemma 2  
For any mask `M` and vertex `v`, after the Dijkstra step
`dp[M][v]` equals the minimum cost of a **connected** subgraph that

* contains all terminals of `M`,
* is contained in the whole graph,
* and has `v` as a (not necessarily unique) vertex of the subgraph.

**Proof.**  
Induction over the order the masks are processed.

*Base* (`|M| = 1`): the only connected subgraph connecting a single terminal
and containing `v` is possible only when `v` is that terminal, cost `0`.  
All other `v` are impossible → `INF`. Holds.

*Induction step*: assume the statement true for all proper sub‑masks of `M`.

1. **Combination**: splitting `M` into `A` and `B` with the same root `v`
   yields a connected subgraph formed by the union of optimal subgraphs for
   `A` and `B`. Their union is connected because both contain `v`. Its cost
   is `dp[A][v] + dp[B][v]`. Taking the minimum over all splits gives the
   cheapest connected subgraph whose *root* is exactly `v` and whose
   *edges* are the union of two smaller optimal subgraphs (still connected).

2. **Dijkstra relaxation**: starting from those candidates, we allow adding
   arbitrary paths from any vertex `u` to a neighbour `v` with edge weight
   `w`. This exactly corresponds to extending the subgraph by one edge,
   preserving connectivity. Dijkstra computes the cheapest way to reach each
   vertex, i.e. the cheapest connected subgraph that contains the required
   terminals and ends at that vertex.

Thus after both steps `dp[M][v]` is the optimum described. ∎



##### Lemma 3  
For the full mask `F` (all regulated terminals) and any vertex `v`,
`dp[F][v]` equals the minimum cost of a subgraph that connects all regulated
vertices (i.e. a Steiner tree) and contains `v`.

**Proof.** Directly from Lemma&nbsp;2 with `M = F`. ∎



##### Lemma 4  
`answer = min_v dp[F][v]` equals the minimum possible total purchase cost that
satisfies the problem statement.

**Proof.**  
*Soundness*: any set of purchased edges that connects all regulated vertices
forms a feasible solution (Lemma&nbsp;1). Its cost is at least the cost of a
minimum Steiner tree, which by Lemma&nbsp;3 is `answer`. Hence `answer` is a
lower bound.

*Optimality*: let `T` be a minimum‑cost Steiner tree connecting the regulated
vertices. Choose any vertex `v` of `T`. By Lemma&nbsp;3 the DP value
`dp[F][v]` is at most the cost of `T`. Therefore `answer ≤ cost(T)`. Combined
with the lower bound we have equality, and the DP yields an optimal purchase
set. ∎



##### Theorem  
The algorithm outputs the minimum total cost of procedures that allow reaching
the required parity states for every pair of regulated ledgers.

**Proof.**  
If `t ≤ 1` the algorithm outputs `0`, which is trivially optimal.  
Otherwise, by Lemma&nbsp;4 the value computed (`answer`) is exactly the
minimum cost of a set of edges connecting all regulated vertices, which by
Lemma&nbsp;1 is equivalent to satisfying the parity requirement. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

* `S = 2^t ≤ 1024`
* For each mask we run Dijkstra on a graph with `n ≤ 100` vertices and
  `m ≤ 4950` edges: `O(m log n)`.
* Combination step iterates over all proper sub‑masks: `O(3^t)` overall,
  but with `t ≤ 10` this is at most `59049`.

Total time  

```
O( S * m log n + 3^t * n )   ≤   about 1·10^6 operations
```

well inside the 5 s limit.

Memory  

```
dp: S * n  ≤ 1024 * 100 = 102400  integers
graph adjacency list: O(m)
```

far below 256 MB.

#### 6.   Reference Implementation  (Python 3)

```python
import sys
import heapq

INF = 10**18

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))
    regs = [int(next(it)) - 1 for _ in range(t)]

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        adj[u].append((v, w))
        adj[v].append((u, w))

    if t <= 1:
        print(0)
        return

    T = t
    full = (1 << T) - 1
    dp = [[INF] * n for _ in range(1 << T)]

    # initialization
    for i, r in enumerate(regs):
        dp[1 << i][r] = 0

    # process masks in increasing order of bits
    for mask in range(1, full + 1):
        # skip singletons (already initialized)
        if mask & (mask - 1):
            # combine submasks
            sub = (mask - 1) & mask
            while sub:
                other = mask ^ sub
                if other:
                    for v in range(n):
                        val = dp[sub][v] + dp[other][v]
                        if val < dp[mask][v]:
                            dp[mask][v] = val
                sub = (sub - 1) & mask

        # Dijkstra to propagate through edges
        dist = dp[mask][:]
        pq = [(dist[v], v) for v in range(n) if dist[v] < INF]
        heapq.heapify(pq)
        visited = [False] * n
        while pq:
            d, u = heapq.heappop(pq)
            if visited[u]:
                continue
            visited[u] = True
            for v, w in adj[u]:
                nd = d + w
                if nd < dist[v]:
                    dist[v] = nd
                    heapq.heappush(pq, (nd, v))
        dp[mask] = dist

    ans = min(dp[full])
    print(ans)


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
