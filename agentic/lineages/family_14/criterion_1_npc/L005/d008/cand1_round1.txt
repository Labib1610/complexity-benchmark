<STATEMENT>
# Problem A — Polynomial Ideal Generators

Time limit: 5 s   Memory limit: 256 MB

## Description

You are working in the polynomial ring $\mathbb{R}[x_1, x_2, \dots, x_n]$ over the real numbers, which contains **n** variables.

You can purchase binomial generators to construct a polynomial ideal. Each available generator is tied to exactly two distinct variables, $x_u$ and $x_v$, and takes the form of the binomial $x_u - x_v$. 

Once a set of generators is purchased, they are permanently unlocked. The purchased generators collectively generate an ideal $I$. By definition, this ideal $I$ consists of all polynomials that can be expressed as a finite sum $\sum p_k g_k$, where each $g_k$ is one of your purchased generators and each $p_k$ is any polynomial in $\mathbb{R}[x_1, x_2, \dots, x_n]$.

A specific subset of **t** variables are designated as *target* variables. Your task is to purchase a subset of available generators such that the following condition is satisfied: 
For *every* pair of distinct target variables $x_i$ and $x_j$, the binomial $x_i - x_j$ must be an element of the ideal $I$.

You are given a list of **m** available generators, each with a one-time purchase cost **w**. Determine the minimum total cost of a subset of generators that satisfies this requirement.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line lists **t** distinct integers representing the indices of the target variables (1-indexed).
The following **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1,000,000). These represent an available generator $x_u - x_v$ that can be purchased for a cost of **w**. (Note that the order of $u$ and $v$ does not matter, as the ideal generated by $x_u - x_v$ is identical to the ideal generated by $x_v - x_u$).
It is guaranteed that it is possible to satisfy the requirement using the available generators.

## Output

Output a single integer representing the minimum total cost of a subset of generators that ensures $x_i - x_j \in I$ for all pairs of target variables $x_i, x_j$.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the target variables are $x_1, x_2$, and $x_3$. We must ensure the ideal $I$ contains the binomials:
- $x_1 - x_2$
- $x_2 - x_3$
- $x_1 - x_3$

By purchasing the three generators $x_1 - x_4$, $x_2 - x_4$, and $x_3 - x_4$ for a total cost of 1+1+1 = 3, we can satisfy the requirement. For instance, the binomial $x_1 - x_2$ belongs to the resulting ideal because it can be expressed as the algebraic combination $1 \cdot (x_1 - x_4) - 1 \cdot (x_2 - x_4)$. This is cheaper than purchasing the generators $x_1 - x_2$ and $x_2 - x_3$ directly, which would cost 2+2=4.

In Example 3, there is only one target variable. Because there are no pairs of distinct target variables, the requirement is vacuously satisfied. No generators need to be purchased, resulting in a cost of 0.
</STATEMENT>
<RATIONALE>
I completely removed the boolean toggling and sequence-of-executions mechanics, which models easily mapped to graph paths and spanning trees. Instead, the problem is framed in commutative algebra: selecting binomial generators $x_u - x_v$ to form an ideal that contains all target differences $x_i - x_j$. This forces the model to mathematically deduce that ideal membership for these degree-1 binomials requires the selected pairs to form a connected component on the variables, rather than relying on surface pattern matching of "toggling".
</RATIONALE>
<PRESERVED_ANSWER>
The binomial $x_i - x_j$ belongs to the ideal generated by a subset of $\{x_u - x_v\}$ if and only if $i$ and $j$ are in the same connected component of the graph formed by the subset, meaning the minimum cost to satisfy this for all target pairs is exactly the minimum Steiner tree cost.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is mathematically isomorphic to the Minimum Steiner Tree problem on graphs, preserving its NP-complete status.
</PRESERVED_CLASS>
<RISK>
Models with weak algebraic reasoning might fail to deduce the equivalence to graph connectivity, interpreting it instead as a general Grobner basis problem which is computationally intractable within the time limit.
</RISK>
