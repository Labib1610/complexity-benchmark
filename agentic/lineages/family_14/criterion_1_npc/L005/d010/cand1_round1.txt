<STATEMENT>
# Problem A — Commutative Algebra Optimization

Time limit: 5 s   Memory limit: 256 MB

## Description

You are working in the polynomial ring over the real numbers with $n$ variables, denoted as $R = \mathbb{R}[x_1, x_2, \dots, x_n]$.

You are given a target set $C$ containing $t$ specific variable indices. 

You have the option to purchase from a list of $m$ available binomials. Each binomial is of the exact form $x_u - x_v$ (where $u$ and $v$ are distinct variable indices), and purchasing it has a one-time cost of $w$. 

Your task is to select a subset of these available binomials to generate a polynomial ideal $I$. The algebraic requirement is that for every pair of indices $c_i, c_j \in C$, the binomial $x_{c_i} - x_{c_j}$ must be an element of the ideal $I$. 

Find the minimum total cost of a subset of binomials that satisfies this requirement. It is guaranteed that purchasing all available binomials would satisfy the condition.

## Input

The first line provides three integers $n$, $m$, and $t$. 
- $t$ is the number of target variable indices. This value ranges from 1 up to the total number of single-digit non-negative integers.
- $n$ is the number of variables in the polynomial ring. It is at least 1, and its upper limit is exactly the square of the upper limit of $t$.
- $m$ is the number of available binomials. It is non-negative and bounded above by the total number of unique unordered pairs of distinct variables.

The second line lists $t$ distinct integers representing the indices in $C$ (1-indexed).

The following $m$ lines each contain three integers $u$, $v$, and $w$. These represent an available binomial $x_u - x_v$ (or equivalently $x_v - x_u$, as either generates the same principal ideal on its own) that can be purchased for a cost of $w$. The indices $u$ and $v$ are distinct and valid variable indices (between 1 and $n$). The cost $w$ is a positive integer no greater than the number of cubic centimeters in one cubic meter.

## Output

Output a single integer representing the minimum total cost of a subset of binomials that satisfies the condition.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the target indices are 1, 2, and 3. By purchasing the binomials $x_1 - x_4$, $x_2 - x_4$, and $x_3 - x_4$ for a total cost of 1+1+1=3, the ideal $I$ they generate contains the required differences. For instance, $(x_1 - x_4) - (x_2 - x_4) = x_1 - x_2$, so $x_1 - x_2 \in I$. The other required binomials $x_2 - x_3$ and $x_1 - x_3$ are similarly in $I$. If we had only purchased $x_1 - x_2$, the ideal would not contain the binomials necessary for index 3, violating the requirement. 

In Example 2, purchasing $x_1 - x_2$ and $x_2 - x_3$ for a cost of 1+1=2 generates an ideal $I$ that includes $x_1 - x_2$, $x_2 - x_3$, and their sum $x_1 - x_3$. This satisfies all conditions for the target set $\{1, 2, 3\}$. The variable $x_4$ does not need to be involved, which is valid since 4 is not a target index.

In Example 3, there is only one target index. The only pair of indices from the target set is $(1, 1)$, requiring the ideal $I$ to contain $x_1 - x_1$, which is the zero polynomial. Since the zero polynomial is an element of every ideal (including the zero ideal generated by the empty set), the requirement is satisfied without purchasing any binomials, resulting in a cost of 0.

<RATIONALE>
The problem was completely reframed from a graph-theoretic "autonomous subset" condition into a commutative algebra problem about generating polynomial ideals. The models relied on the "all or none in a subset" phrasing to detect a partition/connectivity requirement. By shifting strictly to polynomial rings and ideal generation, this textual affordance is removed. To solve it, models must now mathematically deduce (via the Nullstellensatz or degree-1 homogeneous properties) that generating $x_a - x_b$ from a set of $x_u - x_v$ binomials is exactly equivalent to path connectivity, forcing genuine structural reasoning. The numeric bounds were also obscured using physical and mathematical constants per Strategy S07.
</RATIONALE>
<PRESERVED_ANSWER>
Because the generators are degree-1 homogeneous polynomials, $x_a - x_b \in I$ if and only if $x_a - x_b$ is a linear combination of the generators with constant coefficients, which mathematically occurs if and only if there is a path between $a$ and $b$ in the graph formed by the purchased binomials; thus, the minimum cost subset is completely identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is mathematically isomorphic to the Minimum Weight Steiner Tree problem on an undirected graph, preserving its NP-complete complexity class.
</PRESERVED_CLASS>
