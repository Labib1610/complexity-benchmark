<METHOD_NAME>Binary Classification Cut-Cover</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the "autonomous subset" (connected components / partitions) framing with a universal condition over all possible binary classifications (cuts). The requirement that any classification splitting the key features must violate a rule is logically equivalent to requiring that no empty cut separates the key features, meaning they must be in the same connected component. This completely removes graph terminology and forces the model to map classification labels to graph cuts.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Binary Classification Robustness

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing a dataset with $n$ features. 

You can extract "correlation rules". Each rule involves exactly two distinct features, $u$ and $v$. 

A *binary classification* assigns a label of either 'Positive' or 'Negative' to each of the $n$ features. A correlation rule involving feature $u$ and feature $v$ is considered *violated* by a classification if feature $u$ and feature $v$ receive different labels.

A specific subset of $t$ features are designated as *key* features. Your task is to extract a subset of available correlation rules such that the following condition is satisfied:
Any binary classification that assigns 'Positive' to some key features and 'Negative' to other key features MUST violate at least one extracted correlation rule. 
(It must be logically impossible to construct a binary classification that splits the key features into different labels without violating at least one extracted rule).

You are given a list of $m$ available correlation rules, each with a one-time extraction cost $w$. Determine the minimum total cost of a subset of rules that satisfies this requirement.

## Input

The first line provides three integers $n$, $m$, and $t$ (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line lists $t$ distinct integers representing the indices of the key features (1-indexed).
The following $m$ lines each contain three integers $u$, $v$, and $w$ (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1,000,000). These represent an available correlation rule involving features $u$ and $v$ that can be extracted for a cost of $w$.
It is guaranteed that it is possible to satisfy the requirement using the available rules.

## Output

Output a single integer representing the minimum total cost of a subset of rules that satisfies the condition.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the key features are 1, 2, and 3. By extracting the rules (1, 4), (2, 4), and (3, 4) for a total cost of 1+1+1=3, any binary classification that splits features 1, 2, and 3 into different labels must violate at least one of these rules. For instance, if feature 1 is 'Positive' and feature 2 is 'Negative', then feature 4 must be assigned a label. If feature 4 is 'Positive', the rule involving features 2 and 4 has one 'Negative' and one 'Positive' feature, so it is violated. If feature 4 is 'Negative', the rule involving features 1 and 4 is violated. Thus, any split of the key features violates at least one extracted rule. If we had only extracted the rule involving 1 and 2, a classification could assign 'Positive' to features 1 and 2, and 'Negative' to features 3 and 4. This splits the key features (feature 3 differs from 1 and 2) but violates no extracted rules, which fails the requirement.

In Example 2, by extracting rules involving (1, 2) and (2, 3) for a cost of 1+1=2, any classification splitting features 1, 2, and 3 will violate at least one of them. Feature 4 can be assigned any label without consequence since it is not a key feature.

In Example 3, there is only one key feature. It is logically impossible to assign 'Positive' to some key features and 'Negative' to other key features. Thus, the condition is vacuously satisfied for any binary classification without extracting any rules, resulting in a cost of 0.
</STATEMENT>
<RATIONALE>
I replaced the "autonomous subset" (connected components / partitions) framing with a universal condition over all possible binary classifications (cuts). The requirement that any classification splitting the key features must violate a rule is logically equivalent to requiring that no empty cut separates the key features, meaning they must be in the same connected component. This forces the model to deduce the equivalence between universal cut properties and graph connectivity, defeating models that rely on surface pattern matching for Steiner Tree.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that every binary classification separating the key features violates at least one extracted rule is mathematically identical to requiring that the extracted rules form a connected subgraph containing all key features, meaning the minimum cost solution remains the exact Minimum Steiner Tree of the original graph.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks for the minimum cost subset of edges required to connect a given set of terminal nodes, which is exactly the Minimum Steiner Tree problem, preserving its NP-complete complexity.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "binary classification" as implying a machine learning or 2-SAT problem where they must find a valid classification, but the phrasing "Any binary classification... MUST violate" and "logically impossible to construct" explicitly clarifies the universally quantified constraint.
</RISK>
