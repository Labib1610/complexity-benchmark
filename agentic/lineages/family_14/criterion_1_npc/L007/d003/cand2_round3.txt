# Problem A — Synchronization Subnet

Time limit: 5 s   Memory limit: 256 MB

## Description

A distributed system contains **n** processing units, identified by integers from 1 to n. The system architecture dictates a maximum of 100 processing units and requires at least 1 to be operational.

Within this system, a designated group of **t** core units must be able to synchronize their states. To prevent excessive synchronization overhead, the architectural limit for the number of core units is exactly 10, with a minimum of 1.

You are provided with **m** potential bidirectional data channels. The number of potential channels can range from 0 up to n·(n−1)/2. Each channel connects a specific pair of processing units and requires a certain configuration cost. The configuration cost for any single channel is bounded between 1 and 1000000.

Your task is to select a subset of these bidirectional channels to establish a unified synchronization subnet. In this subnet, every core unit must be able to exchange data with every other core unit, either directly or through intermediate units. You may include non-core processing units in your selected subset if they help reduce the total configuration cost.

Find the minimum total configuration cost required to form a valid synchronization subnet for all core units.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the identifiers of the core units.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): a potential bidirectional data channel between unit u and unit v with a configuration cost of w.
The provided channels are guaranteed to be sufficient to form a synchronization subnet for all core units.

## Output

Print a single integer: the minimum total configuration cost to synchronize all core units.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, routing the synchronization through unit 4 (costs 1+1+1 = 3) is more cost-effective than linking the three core units directly (which would cost 4). In Example 3, there is only one core unit, so no channels need to be configured.
