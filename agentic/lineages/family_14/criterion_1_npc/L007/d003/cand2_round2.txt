# Problem A — Campus Network Integration

Time limit: 5 s   Memory limit: 256 MB

## Description

The campus IT department manages a collection of local networks. The administration has mandated that a specific subset of these, known as the core operational networks, must be fully synchronized so they can freely exchange data with one another.

To achieve this, you can purchase bidirectional gateway links between specific pairs of networks. A list of potential gateway links is provided, each with an associated installation cost.

Your objective is to select a subset of these gateway links to install such that every core operational network can route data to every other core operational network, either directly or by forwarding data through a sequence of intermediate networks. You are permitted to install gateway links involving non-core networks if routing data through them results in a lower total installation cost.

Determine the minimum total cost of the gateway links needed to mutually integrate all core operational networks.

## Input

The first line provides three integers: the total count of networks **n**, the number of proposed gateway links **m**, and the size of the core group **t**. The campus infrastructure dictates a network capacity **n** from 1 up to a maximum of 100. The core group size **t** is restricted to between 1 and 10 networks to limit synchronization overhead. The number of proposed links **m** can be 0 or any quantity up to **n**·(**n**−1)/2.

The second line lists **t** distinct integers, identifying the core operational networks.

Each of the subsequent **m** lines contains three integers **u**, **v**, and **w**. These describe a potential bidirectional gateway link between network **u** and network **v**. The networks **u** and **v** are guaranteed to be distinct identifiers (**u** ≠ **v**) ranging from 1 to **n**. The installation cost **w** for any link is bounded by a minimum of 1 and a maximum budget of 1000000.

The provided proposals are always sufficient to successfully integrate the core networks.

## Output

Print a single integer: the minimum total cost to mutually integrate all core operational networks.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, utilizing network 4 as an intermediary (total cost 1+1+1 = 3) is more cost-effective than linking the three core networks directly (which would cost 4 to connect them). In Example 3, there is only 1 core network, so no gateway links need to be purchased.
