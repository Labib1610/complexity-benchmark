<STATEMENT>
# Ideal Generators

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing the polynomial ring $R = \mathbb{R}[x_1, x_2, \dots, x_n]$ over the real numbers, which consists of polynomials in $n$ variables indexed $1$ to $n$.

You need to construct an ideal by selecting a set of generators. There are $m$ available binomials you can choose from. The $i$-th available binomial is of the form $x_u - x_v$. Selecting this binomial to be included in your generating set incurs a weight penalty of $w$.

When a subset of these binomials is selected, they generate an ideal $I$ in the ring $R$. 

You are given a target set of $t$ variable indices. Your goal is to select a subset of the available binomials such that, for every pair of indices $a$ and $b$ from the target set, the polynomial $x_a - x_b$ is an element of the generated ideal $I$.

Determine the minimum total weight penalty required to select a generating set that achieves this guarantee.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the indices of the target variables.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): an available binomial $x_u - x_v$, and its weight penalty **w**.
The provided set of available binomials is sufficient to guarantee the target differences belong to the ideal.

## Output

Print a single integer: the minimum total weight penalty required to guarantee that all differences between the target variables are in the ideal.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the binomials involving variable 4 (i.e., $x_1 - x_4$, $x_2 - x_4$, and $x_3 - x_4$ at a penalty of 1 + 1 + 1 = 3) generates an ideal $I$. In this ideal, the difference $x_1 - x_2$ can be expressed as $(x_1 - x_4) - (x_2 - x_4)$, which proves it belongs to $I$. Similarly, all other differences between the target variables (1, 2, and 3) belong to $I$. This incurs a lower penalty than selecting binomials directly among the target variables.

In Example 3, there is only one target variable. The difference between a variable and itself is $x_1 - x_1 = 0$, which is the zero polynomial. The zero polynomial is always a member of every ideal, so no binomials need to be selected. The minimum penalty is therefore 0.
