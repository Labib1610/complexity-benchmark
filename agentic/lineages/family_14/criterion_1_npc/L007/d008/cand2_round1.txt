<STATEMENT>
# Subspace Synchronization

Time limit: 5 s   Memory limit: 256 MB

## Description

You are developing a state-space simplification pass for a quantum simulation. The system manages **n** basis states, indexed from 1 to **n**. Let $e_i$ denote the $i$-th standard basis vector in $\mathbb{R}^n$.

You can enforce coupling between certain pairs of states. There are **m** available coupling operators. The $i$-th operator couples state **u** and state **v** (**u** ≠ **v**), and activating it adds the difference vector $(e_u - e_v)$ to a generating set $S$. This set $S$ spans a linear subspace $V$ in $\mathbb{R}^n$. Activating this operator consumes **w** energy units.

You are given a priority subset containing **t** distinct states. Your task is to select a subset of the available operators to activate, such that in the resulting subspace $V$ spanned by the activated operators, the difference vector $(e_a - e_b)$ belongs to $V$ for every pair of states **a** and **b** in the priority subset. 

Determine the minimum total energy units required to activate a valid subset of operators.

The system architecture imposes the following physical limits:
- The number of priority states **t** is at least one and at most the total number of base-10 digits.
- The total number of states **n** is at least one and at most the square of the maximum possible number of priority states.
- The number of available operators **m** is non-negative and at most the number of strictly unique unordered pairs of the **n** states.
- The energy cost **w** for any operator is a positive integer not exceeding the cube of the maximum possible number of states.

## Input

The first line contains three integers **n**, **m**, and **t**.
The second line contains **t** distinct integers representing the indices of the priority states.
Each of the next **m** lines contains three integers **u**, **v**, and **w**: an available coupling operator between state **u** and state **v**, and its energy cost **w**.
(The values strictly adhere to the limits described above. The provided set of available operators is guaranteed to be sufficient to ensure the priority states satisfy the subspace condition.)

## Output

Print a single integer: the minimum total energy units required to guarantee that for every pair of priority states **a** and **b**, the vector $(e_a - e_b)$ belongs to the generated subspace $V$.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, activating the operators involving state 4 (between 1 and 4, 2 and 4, and 3 and 4 at an energy cost of 1 + 1 + 1 = 3) adds $(e_1 - e_4)$, $(e_2 - e_4)$, and $(e_3 - e_4)$ to the generating set $S$. In the resulting subspace $V$, the difference vector between any pair of the priority states (1, 2, and 3) can be constructed via linear combination. For instance, $(e_1 - e_2) = (e_1 - e_4) - (e_2 - e_4)$, which demonstrates it belongs to $V$. This incurs a lower energy cost than activating operators directly among the priority states.

In Example 3, there is only one priority state. For any single state **a**, the difference vector $(e_a - e_a)$ is the zero vector, which is trivially present in any linear subspace, so an empty generating set $S$ is sufficient. The minimum cost is therefore 0.

<RATIONALE>
The problem has been reframed using linear algebra. The condition that nodes are in the same connected component (voting identically) has been replaced by the mathematically isomorphic condition that the difference of their standard basis vectors lies in the linear span of the difference vectors of the selected edges. This forces models to bridge the gap between continuous vector spaces and combinatorial graph connectivity, breaking heuristics that trigger on "identical" or "connected components". Bounds are also expressed indirectly via physical limits (e.g., "cube of the maximum possible number of states" = 100^3 = 1,000,000).
</RATIONALE>
<PRESERVED_ANSWER>
The difference vector $(e_a - e_b)$ is in the span of a set of difference vectors $\{e_u - e_v\}$ if and only if $a$ and $b$ are in the same connected component of the graph formed by the selected edges, making the optimal subset identical to the Steiner Tree solution.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
