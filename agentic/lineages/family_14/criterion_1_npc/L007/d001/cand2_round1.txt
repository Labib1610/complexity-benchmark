# Problem A — Data Pipeline Architecture

Time limit: 5 s   Memory limit: 256 MB

## Description

A sprawling research campus contains several facilities. Certain pairs of these facilities can be linked with a bidirectional data pipeline for a known installation cost. A specific group of these facilities are designated as primary operation centres. 

Your objective is to select a subset of pipelines to install so that every primary operation centre can exchange data with every other primary operation centre. Data can flow directly between them or be routed through any number of other facilities. Facilities that are not primary operation centres can act as intermediate routing junctions if including them leads to a more cost-effective overall network. You must find the minimum possible total installation cost to achieve this.

## Input

The first line contains three integers **n**, **m**, and **t**. 
The number of facilities **n** is between 1 and the campus grid capacity of exactly 100 lots, inclusive.
The number of primary operation centres **t** is between 1 and the central authority's maximum allocation of exactly 10 operation centres, inclusive.
The number of possible pipelines **m** is between 0 and the maximum possible number of distinct pairs of facilities, inclusive.

The second line contains **t** distinct integers: the identifiers of the primary operation centres (each between 1 and **n**).

Each of the following **m** lines contains three integers **u**, **v**, and **w**. This indicates a potential pipeline between facility **u** and facility **v** (both between 1 and **n**, with **u** ≠ **v**) with an installation cost of **w**. The cost **w** is between 1 and the maximum per-pipeline grant of exactly 1,000,000, inclusive.

It is guaranteed that the given pipelines are sufficient to connect all primary operation centres.

## Output

Print a single integer representing the minimum total cost to ensure all primary operation centres can exchange data.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, routing the data through facility 4 (which costs 1+1+1 = 3) is cheaper than linking the three primary operation centres directly (which would cost 4). In Example 3, there is only one primary operation centre, so no pipelines need to be installed.
