# Problem A — Secure Outpost Communications

Time limit: 5 s   Memory limit: 256 MB

## Description

A territory consists of up to 100 outposts (numbered 1 to **n**). A survey has identified **m** potential secure communication links between specific pairs of outposts, each requiring a certain budget to establish. A highly restricted protocol designates a select group of exactly **t** of these outposts (where the protocol strictly limits this to at most 10) as command centers.

Your objective is to deploy a communication network that guarantees all command centers are interconnected (meaning a message can travel between any two command centers, possibly passing through other outposts). You are permitted to route these paths through any of the other available outposts if doing so results in a more economical overall deployment. Outposts that are not command centers do not need to be integrated into the network unless they serve as useful conduits.

Calculate the minimum total budget required to establish an interconnected communication network containing all command centers.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the identifiers of the command centers.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): a potential secure link between outpost u and outpost v requiring budget w.
The potential secure links are sufficient to interconnect all command centers.

## Output

Print a single integer: the minimum total budget necessary to interconnect all command centers.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, routing the network through outpost 4 (budget 1+1+1 = 3) is more economical than linking the three command centers directly (which would require a budget of 4). In Example 3, there is only one command center, so no links need to be established.
