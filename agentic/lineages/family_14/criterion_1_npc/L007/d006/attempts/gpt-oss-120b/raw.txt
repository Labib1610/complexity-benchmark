**Solution Explanation**

For every constraint `x_u = x_v` we may pay its weight `w` and add the
undirected edge `u – v` to the system.
After adding a set of edges the variables that belong to the same
connected component must be equal, all other components stay independent.
Therefore the projection on the target axes has dimension `1`
iff all target vertices belong to one connected component,
i.e. the chosen edges connect all target vertices.

So the problem is exactly:

*Given an undirected weighted graph ( `n ≤ 100` ),
a set `T` of at most `10` terminal vertices,
find the cheapest sub‑graph that connects all terminals
(ordinary Steiner tree).*

--------------------------------------------------------------------

#### 1.   Steiner DP over subsets  

`k = |T| ≤ 10`.  
For every subset `mask ⊆ {0 … k‑1}` and every vertex `v`
```
dp[mask][v] = minimum total weight of a tree
              that connects all terminals of 'mask'
              and whose (arbitrary) root is vertex v
```
The answer will be `min_v dp[ALL][v]`.

*Initialization*  
For each terminal `i` (vertex `ti`)  
`dp[1<<i][ti] = 0`, all other entries are `∞`.

*Combine two smaller subsets*  
For a fixed `mask` we try to split it into two non‑empty disjoint parts
`sub` and `mask ^ sub` (both contain the same root `v`):
```
dp[mask][v] = min( dp[sub][v] + dp[mask^sub][v] )
```
The loop over all proper non‑empty `sub` of `mask` is `O(3^k)` overall.

*Relax along graph edges*  
After the combination step `dp[mask][*]` is a set of distances
that are correct **only at the vertices where the tree ends**.
To allow the tree to end at any vertex we run Dijkstra
with these distances as the initial source:
```
priority queue initially contains (dp[mask][v], v) for all v
while queue not empty:
        (d, u) = pop
        if d != dp[mask][u]: continue
        for each edge u‑w with weight c:
                if dp[mask][w] > d + c:
                        dp[mask][w] = d + c
                        push(dp[mask][w], w)
```
After Dijkstra `dp[mask][v]` is the cheapest cost of a tree that
connects the terminals of `mask` and ends at `v` (the tree may use any
other vertices as Steiner points).

We perform the combine‑then‑relax steps for all masks in increasing order
of their size.  
Complexities  

* number of masks: `2^k ≤ 1024`
* combine step: `O(3^k * n)   (≈ 59049 * 100)` – tiny
* Dijkstra for each mask: `O(m log n)` → at most `1024 * 5000 * log 100`
  well below the limits.

--------------------------------------------------------------------

#### 2.   Correctness Proof  

We prove that the algorithm returns the minimum possible total penalty.

---

##### Lemma 1  
For any mask and vertex `v`, after the Dijkstra step
`dp[mask][v]` equals the minimum weight of a tree that

* connects all terminals of `mask`,
* contains vertex `v`,
* and whose total weight is the sum of its edges.

**Proof.**  
Before Dijkstra, `dp[mask][v]` is the minimum weight of a tree that
connects the terminals of `mask` **and ends exactly at `v`** (by induction
on mask size, see Lemma&nbsp;2).  
Running Dijkstra on the graph with these values as source distances
computes for every vertex `x` the cheapest way to reach `x` from any
source `v` by adding a path of edges. Adding that path to the tree ending
at `v` yields a tree that still connects all terminals of `mask` and now
contains `x`. The cost is exactly `dp[mask][v] + pathWeight`.  
Dijkstra finds the minimum over all such possibilities, therefore the
resulting `dp[mask][x]` is the optimum described in the lemma. ∎



##### Lemma 2  
After processing a mask (combine + Dijkstra) the invariant holds:

> For every vertex `v`, `dp[mask][v]` is the minimum possible weight of a
> tree that connects exactly the terminals of `mask` and contains `v`.

**Proof by induction on |mask|.**

*Base* `|mask| = 1`.  
The only tree connecting a single terminal `ti` and containing a vertex
`v` is possible iff `v = ti`; its weight is `0`. The initialization sets
`dp[1<<i][ti]=0` and `∞` otherwise, satisfying the statement.
Dijkstra does not improve any value because there is no cheaper way to
reach another vertex without adding edges, which would increase the weight,
so the invariant stays true.

*Induction step.*  
Assume the invariant true for all proper subsets of `mask`.  
First we combine two disjoint non‑empty subsets `sub` and `mask\sub` that
share the same root `v`. By the induction hypothesis,
`dp[sub][v]` and `dp[mask\sub][v]` are optimal for their subsets.
Their union is a tree connecting all terminals of `mask` and still
contains `v`; its weight is the sum. Taking the minimum over all splits
gives the cheapest tree that **ends at `v**` (i.e. whose root is `v`).
Thus after the combine step the invariant holds for trees ending at `v`.

Then Dijkstra (Lemma&nbsp;1) expands the root to any vertex, preserving
optimality. Hence after the whole processing the invariant holds for the
full mask. ∎



##### Lemma 3  
For the full mask `ALL` (all terminals) the value  
`ans = min_v dp[ALL][v]` equals the minimum total weight of any
sub‑graph that connects all terminals.

**Proof.**  
Any connected sub‑graph that connects all terminals contains at least one
vertex `v`. Its weight is at least the optimum tree weight for mask `ALL`
ending at `v`, i.e. `dp[ALL][v]`. Therefore the weight of any feasible
solution is ≥ `ans`.  

Conversely, pick `v*` attaining the minimum.
`dp[ALL][v*]` corresponds (Lemma&nbsp;2) to a tree that connects all
terminals, whose weight is exactly `ans`. A tree is a valid sub‑graph,
so `ans` is achievable. ∎



##### Theorem  
The algorithm outputs the minimum possible total penalty required to make
the projection on the target axes one‑dimensional.

**Proof.**  
Making the projection one‑dimensional is equivalent to forcing all target
variables to be equal, i.e. to connecting all target vertices in the
equality graph.  
The algorithm computes `ans` as described in Lemma&nbsp;3, which is the
minimum total weight of a sub‑graph that connects all target vertices.
Thus `ans` is exactly the minimum total penalty. ∎



--------------------------------------------------------------------

#### 3.   Complexity Analysis  

```
k = number of targets ( ≤ 10 )
N = n ( ≤ 100 )
M = m ( ≤ 4950 )
```

* DP table size: `2^k * N   ≤ 1024 * 100 = 102 400`
* Combine step: `O(3^k * N)   ≤ 59 049 * 100 ≈ 6·10^6`
* Dijkstra for each mask: `O( M log N )` per mask  
  total `2^k * M log N  ≤ 1024 * 5000 * 7 ≈ 3.6·10^7`
* Memory: the DP table (`≈ 1e5` integers) plus graph.

All well inside the limits (5 s, 256 MB).

#### 4.   Reference Implementation  (Python 3)

```python
import sys
import heapq

INF = 10**18

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))
    targets = [int(next(it)) - 1 for _ in range(t)]

    # graph
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        adj[u].append((v, w))
        adj[v].append((u, w))

    if t == 1:
        print(0)
        return

    K = t
    ALL = (1 << K) - 1
    dp = [[INF] * n for _ in range(1 << K)]

    # init singletons
    for i, v in enumerate(targets):
        dp[1 << i][v] = 0

    # process masks in increasing order of bits
    for mask in range(1, ALL + 1):
        # combine submasks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            # only need to consider each unordered pair once
            if other:
                for v in range(n):
                    val = dp[sub][v] + dp[other][v]
                    if val < dp[mask][v]:
                        dp[mask][v] = val
            sub = (sub - 1) & mask

        # Dijkstra to propagate through graph
        pq = []
        for v in range(n):
            if dp[mask][v] < INF:
                heapq.heappush(pq, (dp[mask][v], v))
        while pq:
            d, u = heapq.heappop(pq)
            if d != dp[mask][u]:
                continue
            for w, wcost in adj[u]:
                nd = d + wcost
                if nd < dp[mask][w]:
                    dp[mask][w] = nd
                    heapq.heappush(pq, (nd, w))

    ans = min(dp[ALL])
    print(ans)


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
