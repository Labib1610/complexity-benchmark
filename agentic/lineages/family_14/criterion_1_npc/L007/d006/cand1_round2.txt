<STATEMENT>
# Algebraic Variety Intersection

Time limit: 5 s   Memory limit: 256 MB

## Description

Consider a mathematical space defined by **n** scalar variables, $x_1, x_2, \dots, x_n$. We are interested in a specific geometric property involving **t** critical target variables.

You are provided with a dictionary of **m** algebraic constraints. The $i$-th available constraint restricts the space to the hyperplane defined by $x_u = x_v$, and has an associated algebraic complexity of $w$.

You must select a subset of these constraints. The intersection of the hyperplanes corresponding to your selected subset defines an algebraic variety. Your goal is to ensure that, for every point $(x_1, \dots, x_n)$ in this variety, the **t** critical target variables are strictly identical to each other.

To ensure unambiguous interpretation of this geometric condition: in the graph where the **n** variables are vertices and the selected constraints $x_u = x_v$ are undirected edges, a selected subset of constraints is valid if and only if all **t** critical variables are in the same connected component. Variables that are not among the critical targets may be used as intermediate equivalences in this component. The provided dictionary of constraints is guaranteed to be sufficient to connect all critical variables.

The total algebraic complexity of a selected subset is the linear sum of the $w$ values of the selected constraints. (Note: While some geometric models aggregate complexity via the sum of squares, $\sum w^2$, in this system the total complexity is strictly the linear sum of the provided $w$ values, $\sum w$. Do not square the input values). Determine the minimum total algebraic complexity required to form a valid variety.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the indices of the critical target variables.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): an available constraint $x_u = x_v$ with an algebraic complexity of $w$.

## Output

Print a single integer: the minimum total algebraic complexity to ensure all critical target variables are equal.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the constraints involving variable 4 (between 1 and 4, 2 and 4, and 3 and 4 at a complexity of 1+1+1 = 3) ensures that critical variables 1, 2, and 3 are strictly identical on the resulting variety. This incurs a lower complexity than selecting the constraints directly between the critical variables. In Example 3, there is only one critical variable, so no constraints need to be selected and the minimum complexity is 0.
