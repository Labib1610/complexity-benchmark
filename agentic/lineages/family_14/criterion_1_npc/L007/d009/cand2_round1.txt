# Symmetric Function Classes

Time limit: 5 s   Memory limit: 256 MB

## Description

Let $x = (x_1, x_2, \dots, x_n)$ be a vector in $\mathbb{R}^n$. 
For any two distinct positions $u$ and $v$ ($1 \le u, v \le n$), let the transformation $\tau_{u,v}$ be defined such that $\tau_{u,v}(x)$ exchanges the components at positions $u$ and $v$, leaving all other components unchanged. 
A function $f: \mathbb{R}^n \to \mathbb{R}$ is said to be *symmetric* under $\tau_{u,v}$ if $f(x) = f(\tau_{u,v}(x))$ for all possible vectors $x \in \mathbb{R}^n$.

You are provided with a pool of $m$ available transformations. The $i$-th transformation is $\tau_{u_i, v_i}$ and can be acquired for a cost of $w_i$. 
When you acquire a subset of transformations, you define a function class $\mathcal{C}$. This class consists of all functions $f$ that are symmetric under *every* transformation in your acquired subset.

There is a specified set $T$ containing $t$ critical positions. 
Your task is to acquire a subset of transformations such that the resulting function class $\mathcal{C}$ satisfies a strict requirement: every function $f \in \mathcal{C}$ must logically also be symmetric under $\tau_{a,b}$ for all pairs of distinct positions $a, b \in T$.

Calculate the minimum total total cost required to acquire a subset of transformations that guarantees this requirement is met.

## Input

The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le 10$, $1 \le n \le 100$, $0 \le m \le n(n-1)/2$).
The second line contains $t$ distinct integers: the critical positions in $T$.
Each of the following $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing an available transformation $\tau_{u,v}$ and its acquisition cost $w$.
It is guaranteed that acquiring all available transformations is sufficient to meet the requirement.

## Output

Output a single integer representing the minimum total cost to satisfy the requirement.

<RATIONALE>
The explanatory Note after the examples explicitly told models that intermediate non-target variables could be used as transit hubs to satisfy the symmetry condition, which instantly gave away the minimum-cost Steiner Tree structure. I completely removed this Note and formalized the problem text into abstract algebra (transformations and symmetry classes) to force models to mathematically deduce that transitive symmetry implies graph connectivity on their own.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that every function symmetric under the acquired transformations is also symmetric under transpositions of targets holds if and only if all targets are in the same connected component of acquired transformations, meaning the minimum cost remains identical for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem requires finding the minimum-cost subset of edges (transformations) that connects a specific subset of vertices (critical positions), which is exactly the NP-complete Steiner Tree problem.
</PRESERVED_CLASS>
<RISK>
Models might struggle to deduce that function symmetry is an equivalence relation that perfectly maps to graph connectivity, but the mathematical definition is rigorous and unambiguous.
</RISK>
