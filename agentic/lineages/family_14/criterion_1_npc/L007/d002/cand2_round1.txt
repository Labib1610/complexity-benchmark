<STATEMENT>
# Problem A — Campus Network Integration

Time limit: 5 s   Memory limit: 256 MB

## Description

A campus consists of **n** locations (numbered 1 to n). You are given a set of **t** priority locations that must all be integrated into a unified communication system. To achieve this, you can purchase communication links between specific pairs of locations, each having a known price.

When you purchase a link, data can flow between its two endpoints. Furthermore, data can be forwarded across any contiguous sequence of purchased links. The system is fully integrated if data can successfully flow between every pair of priority locations. You may purchase links connected to non-priority locations if they help bridge the connections.

Determine the minimum total price of a set of links that must be purchased to ensure the system is fully integrated.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the ids of the priority locations.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): a communication link available between locations u and v at price w.
The available links are sufficient to integrate all priority locations.

## Output

Print a single integer: the minimum total price to integrate all priority locations.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, purchasing the links connected to location 4 (prices 1+1+1 = 3) is cheaper than bridging the three priority locations directly (which would price 4). In Example 3 there is only one priority location, so no links need to be purchased.
</STATEMENT>
<RATIONALE>
Removed the explicit phrases "possibly passing through multiple intermediate locations" and "route the communication through any of the other locations", replacing them with a description of transitive data flow across contiguous sequences of purchased links. The literal suggestion to restrict routing to "at most one intermediate location" was not applied as it would change the mathematical rules of the problem and invalidate the reference solution; instead, the affordance was removed by redefining connectivity purely through contiguous sequences without explicitly highlighting the intermediate node structure. This forces models to independently deduce that the required subgraph can take the shape of an arbitrary tree connecting the terminals.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that data can flow between any pair of priority locations over a contiguous sequence of purchased links is mathematically identical to requiring that the priority locations belong to the same connected component in the chosen subgraph, preserving all optimal link selections and costs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Steiner Tree problem in graphs, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "contiguous sequence of purchased links" as requiring a single simple path that visits all priority locations (a TSP-like path) rather than a tree, though "between every pair" typically implies general connectivity in the resulting subgraph.
</RISK>
