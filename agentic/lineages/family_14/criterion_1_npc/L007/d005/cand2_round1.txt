<METHOD_NAME>Homogeneous Linear System Reframing</METHOD_NAME>
<METHOD_DESCRIPTION>Transforms the Steiner tree problem into selecting a subset of homogeneous linear equations ($\theta_u - \theta_v = 0$) such that the resulting solution space restricts a specific subset of variables to be equal. This mathematically preserves the exact same connectivity requirement but completely removes graph terminology, transitivity explanations, and hints about using intermediate variables, forcing the model to algebraically deduce that the equations form a Steiner tree.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Parameter Condition Minimization

Time limit: 5 s
Memory limit: 256 MB

## Description

You are analyzing a mathematical model with **n** unknown real parameters, $\theta_1, \theta_2, \ldots, \theta_n$. 
There is a requirement set of **t** critical parameters.

You have a pool of **m** candidate linear conditions. The $i$-th candidate condition is the equation $\theta_u - \theta_v = 0$ and has an implementation cost of $w$.

Your task is to select a subset of the candidate conditions to form a constraint system. The selected system must guarantee that all **t** critical parameters evaluate to the exact same value in every valid solution to the system. You may select any combination of the available conditions.

Determine the minimum total implementation cost of a selected subset of candidate conditions that satisfies this requirement.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the indices of the critical parameters.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): a candidate condition $\theta_u - \theta_v = 0$ with implementation cost $w$.
The available conditions are sufficient to ensure all critical parameters are equal.

## Output

Print a single integer: the minimum total implementation cost of the selected subset.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the conditions $\theta_1 - \theta_4 = 0$, $\theta_2 - \theta_4 = 0$, and $\theta_3 - \theta_4 = 0$ costs 1 + 1 + 1 = 3. Any solution satisfying this system of three equations necessitates $\theta_1 = \theta_2 = \theta_3$, fulfilling the requirement. In Example 3, there is only one critical parameter, so an empty system (cost 0) trivially satisfies the requirement.
</STATEMENT>
<RATIONALE>
Removed explicit references to "transitivity" and the suggestion that constraints involving variables outside the target subset can be used as cheaper connectors. Replaced the graph-like variable equality propagation with a strictly algebraic formulation where homogeneous linear equations restrict a solution space. This forces the model to deduce on its own that the logical implication of equality among the critical parameters corresponds precisely to spanning a connected component over those indices.
</RATIONALE>
<PRESERVED_ANSWER>
The solution space of a set of equations of the form $\theta_u - \theta_v = 0$ forces $\theta_x = \theta_y$ for all critical parameters if and only if those parameters belong to the same connected component in the graph formed by the selected equations, making the minimum cost identical to the original minimum Steiner tree formulation.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Steiner Tree problem on a graph, which is NP-complete, with identical vertices, edges, weights, and terminals.
</PRESERVED_CLASS>
