<STATEMENT>
# Problem A — Orthogonal Subspace Enforcement

Time limit: 5 s   Memory limit: 256 MB

## Description

You are working in an **n**-dimensional real vector space $\mathbb{R}^n$. Let $e_k$ denote the $k$-th standard basis vector, which has a 1 in the $k$-th coordinate and 0 everywhere else.

You are given a specific set of **t** target coordinate indices.

You are also provided with a pool of **m** available test vectors. The $i$-th available test vector is defined as $e_u - e_v$ for some indices $u$ and $v$, and it requires a cost of $w$ to include in your active set. 

You may select any subset of these available test vectors to form your active set. The total cost of your active set is the sum of the inclusion costs of the vectors you selected.

Your objective is to ensure that for every possible vector $y \in \mathbb{R}^n$ that is orthogonal to all test vectors in your active set (i.e., the standard dot product is zero), all **t** target coordinates of $y$ are guaranteed to be equal to one another. 

Determine the minimum total cost of an active set that satisfies this condition.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the target coordinate indices.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): representing an available test vector $e_u - e_v$ and its inclusion cost $w$.
The available test vectors in the pool are always sufficient to achieve the objective.

## Output

Print a single integer: the minimum total cost to include a set of test vectors such that any vector orthogonal to the active set has identical values at all target coordinate indices.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, an optimal active set consists of the test vectors $e_1 - e_4$, $e_2 - e_4$, and $e_3 - e_4$, incurring a total cost of 1+1+1 = 3. The orthogonal complement of this active set restricts any orthogonal vector $y$ to have $y_1 = y_2 = y_3 = y_4$. This satisfies the requirement that the target coordinates (1, 2, and 3) must be equal.

In Example 3, there is only a single target coordinate. The equality condition across the target subset is trivially satisfied for any arbitrary vector $y \in \mathbb{R}^3$, so the optimal active set is empty, costing 0.
</STATEMENT>
<RATIONALE>
I transformed the problem from a graph connectivity/equality constraint framing into a linear algebra problem about vector space orthogonality. By representing edges as difference vectors $e_u - e_v$ and connectedness as properties of the orthogonal complement, the mathematical structure of Steiner Tree is perfectly preserved while stripping all graph-theoretic and transitivity keywords. This forces models to first mathematically prove the equivalence between subspace orthogonality and connected components before they can even realize a graph algorithm is needed.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that any vector orthogonal to the active set has identical target coordinates is mathematically identical to requiring that the selected difference vectors span all pairwise differences between target coordinates, which is exactly equivalent to connecting the target variables in a graph.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the Minimum Steiner Tree problem on an undirected graph, as selecting a minimum-cost subset of difference vectors to span the required target differences is isomorphic to finding a minimum-cost tree connecting the target terminals.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "orthogonal to all test vectors in your active set" as requiring $y$ to be orthogonal to the entire pool of available vectors, though "in your active set" is explicitly stated.
</RISK>
