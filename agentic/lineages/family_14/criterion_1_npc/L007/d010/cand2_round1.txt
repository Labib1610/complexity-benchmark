<STATEMENT>
# Generative Grammar Synchronization

Time limit: 5 s   Memory limit: 256 MB

## Description

You are studying a formal generative system defined over an alphabet of **n** distinct symbols, represented by integers from 1 to **n**.

The system can be customized by activating a subset of bidirectional expansion rules. There are **m** such rules available. The $i$-th available rule applies to symbols **u** and **v**, and requires a cost of **w** to activate.
If activated, this rule introduces two productions into the grammar:
- Any single occurrence of symbol **u** in a string can be replaced by the two-character string **uv**.
- Any single occurrence of symbol **v** in a string can be replaced by the two-character string **vu**.

These productions can be applied an arbitrary number of times, in any order, to any string.

For any starting symbol $x$, we define its *derivable vocabulary*, denoted $V(x)$, as the set of all distinct symbols that appear in at least one string that can be derived from the single-character string "$x$" using any sequence of the currently activated rules. (Note that $x$ is always in $V(x)$ because it trivially appears in the initial string).

You are given a priority set of **t** target symbols. Your objective is to activate a subset of the available rules such that the following strict condition holds:
For every pair of distinct target symbols $a$ and $b$ in your priority set, their derivable vocabularies must be exactly identical. That is, $V(a) = V(b)$.

Determine the minimum total cost required to activate a subset of rules that achieves this guarantee.

The number of target symbols **t** will never exceed the number of pins in a standard ten-pin bowling setup.
The total number of symbols **n** is at most the square of the maximum possible number of target symbols.
The number of available rules **m** is at most the number of possible unordered pairs of distinct symbols.
The cost **w** of any rule is a positive integer not exceeding one million.

## Input

The first line contains three integers **n**, **m**, and **t**.
The second line contains **t** distinct integers: the target symbols.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**): an available rule between symbol **u** and symbol **v**, and its activation cost **w**.
The provided set of available rules is always sufficient to satisfy the required condition.

## Output

Print a single integer: the minimum total cost required to activate a subset of rules that satisfies the condition.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 3, there is only one target symbol, so there are no distinct pairs to constrain. Choosing no rules satisfies the condition vacuously with a total cost of 0.

<RATIONALE>
The seed problem heavily telegraphed graph connectivity through the algebraic concept of transposition invariance, which models correctly mapped to connected components of an equivalence relation. To defeat this, I reframed the problem in the domain of formal language theory and string rewriting systems. The requirement that priority vertices share a connected component is now expressed as requiring that their "derivable vocabularies" (the set of all symbols that can eventually be generated from a starting symbol) are perfectly identical. This forces the model to deduce that mutual derivability is exactly reachability in an undirected graph, completely stripping away the standard Steiner Tree vocabulary. I also applied S07 (Indirect Bounds) to hide the explicit `t <= 10` hint that models use to trigger subset-based dynamic programming.
</RATIONALE>
<PRESERVED_ANSWER>
Activating the rule for `u` and `v` allows generating `v` from `u` and vice versa, which is mathematically identical to adding an undirected edge between `u` and `v`; a symbol's derivable vocabulary is therefore exactly its connected component, meaning $V(a) = V(b)$ holds if and only if $a$ and $b$ are in the same connected component, preserving the Steiner Tree objective and all costs exactly.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the Minimum Steiner Tree problem on an undirected graph, which is NP-complete, and the I/O format and bounds are entirely unchanged.
</PRESERVED_CLASS>
<RISK>
Models could misinterpret "any occurrence of symbol u in a string can be replaced by the two-character string uv" as order-dependent or strictly linear, but the definition of derivable vocabulary explicitly looks at the set of all symbols across *any* valid derivation sequence, which safely nullifies string-order ambiguities.
</RISK>

Generative Grammar Reachability Closure + Indirect Bounds
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the equivalence relation / graph connectivity requirement with a condition on the generated vocabulary (terminal alphabet) of a formal string rewriting system. Instead of asking for a connected subgraph, it asks for rules of the form u -> uv to be selected such that the set of all derivable characters is identical for all priority starting characters. This perfectly mirrors connected components while appearing as a formal language theory problem, preventing models from matching it to Steiner Tree templates. Combined with S07 to hide the small subset bound.
</METHOD_DESCRIPTION>
