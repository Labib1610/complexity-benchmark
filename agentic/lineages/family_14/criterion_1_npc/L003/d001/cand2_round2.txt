<STATEMENT>
# Unifying the Target Propositions

Time limit: 5 s   Memory limit: 256 MB

## Description

A mathematical theory consists of **n** propositions (numbered 1..n). Certain pairs of propositions can be proven equivalent by authoring a bidirectional lemma, which requires a specific number of pages to write. Within this theory, a specific subset of **t** target propositions must all be shown to be mutually equivalent.

Because equivalence is transitive, you do not need to prove every pair of target propositions equivalent directly. You may author lemmas connecting any available propositions, using non-target propositions as intermediate steps if doing so reduces the total length of the proofs.

Find the minimum total number of pages required to author a set of lemmas such that all **t** target propositions are equivalent to one another.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the ids of the target propositions.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): a bidirectional lemma proving propositions u and v are equivalent, requiring w pages to write.
The available lemmas are sufficient to ensure all target propositions can be made mutually equivalent.

## Output

Print a single integer: the minimum total number of pages required to make all target propositions mutually equivalent.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, establishing equivalence through proposition 4 (which takes 1+1+1 = 3 pages) is shorter than connecting the three target propositions directly (which would take 4 pages). In Example 3, there is only one target proposition, so no lemmas are needed and the minimum total is 0 pages.
