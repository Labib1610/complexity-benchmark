<STATEMENT>
# Problem A — Establishing the Protocols

Time limit: 5 s   Memory limit: 256 MB

## Description

You oversee **n** communication outposts, numbered 1 to n. Initially, each outpost operates in complete isolation. There are **m** available bidirectional synchronization protocols. Each protocol binds two specific outposts together, merging their operational domains, and requires a specific amount of power to establish.

When outposts are bound, they form a unified group. This grouping is transitive: if outpost A is bound to B, and B is bound to C, then A and C operate in the same unified group. 

A given subset of **t** outposts are classified as critical. Your mandate is to establish a selection of protocols so that all critical outposts belong to the exact same unified group. You are permitted to bind non-critical outposts into this group if it yields a more power-efficient overall configuration.

Determine the minimum total power of the established protocols required to guarantee every critical outpost shares the same unified group.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the identifiers of the critical outposts.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): an available synchronization protocol between outposts u and v that requires w power to establish.
The available protocols are sufficient to allow all critical outposts to share a unified group.

## Output

Print a single integer: the minimum total power of the established protocols required to allow all critical outposts to share the same unified group.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, establishing protocols involving outpost 4 (power 1+1+1 = 3) is more efficient than using protocols that only involve the critical outposts (which would require 4 power). In Example 3 there is only one critical outpost, so no protocols need to be established.

The suggested removal (requiring a single simple path) would change the problem to a Hamiltonian Path/TSP variant, violating the hard constraint to preserve all answers (e.g., Example 1 would change from 3 to 4). Instead, to remove the graph-routing affordance, I replaced all networking terminology ('route', 'path', 'connect') with an equivalence-relation framing ('unified group', 'bind'). This forces the model to deduce on its own that minimizing the cost to place a subset of elements into the same transitive equivalence class is structurally identical to the minimum Steiner tree problem.
