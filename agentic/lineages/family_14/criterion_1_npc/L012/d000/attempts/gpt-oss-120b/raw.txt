**Solution Explanation**

For every language we have a vertex.
Every translator `u – v` with fee `w` is an undirected edge of weight `w`.

For a set `S` of *primary* languages we have to hire translators so that
all languages of `S` become mutually reachable.
We may also hire translators for other languages – they may be used as
intermediate nodes.
The problem is exactly the **Steiner Tree** problem in an undirected weighted
graph with

* `n ≤ 100` vertices
* at most `t ≤ 10` terminals (the primary languages)

The Steiner Tree problem is NP‑hard in general, but with at most ten terminals
the classic **Dreyfus‑Wagner** dynamic programming solves it fast enough.

--------------------------------------------------------------------

#### 1.   Shortest paths between every pair of vertices  

Only the existence of a path matters, not which edges are used.
Therefore we first compute the cheapest distance between every two vertices.

```
dist[i][j] = length of a cheapest path i … j
```

`n ≤ 100`, so Floyd‑Warshall (`O(n³) = 10⁶`) is trivial.

--------------------------------------------------------------------

#### 2.   DP definition  

```
dp[mask][v] = minimal total fee of a set of translators
              that connects all terminals whose bits are 1 in mask,
              and the whole set is contained in one connected component
              whose (any) root is the language v
```

`mask` – bitmask of size `t` (`0 … 2ᵗ-1`),  
`v`   – vertex (`0 … n‑1`).

The answer finally is  

```
min_v dp[ALL][v]          (ALL = (1<<t)-1)
```

--------------------------------------------------------------------

#### 3.   Initialisation  

For a mask that contains exactly one terminal `p`

```
dp[1<<i][p] = 0          (cost 0, we already have that language)
dp[1<<i][v] = ∞   (v ≠ p)
```

After the next step (see 4.) these values become the true
shortest distances from the terminal to every vertex.

--------------------------------------------------------------------

#### 4.   DP transition  

*Combination of two already built sub‑trees*  

For a mask with at least two bits we split it into two non‑empty disjoint
sub‑masks `a` and `b` (`a ∪ b = mask`).  
If both parts already end in the same vertex `v`,
the whole tree also ends in `v`.

```
dp[mask][v] = min over a⊂mask ( dp[a][v] + dp[mask\a][v] )
```

All proper sub‑masks are enumerated – this is `O(3^t·n)` which is tiny
(`t ≤ 10`).

*Propagation through the graph*  

After the combination step the tree can be *extended* by ordinary
shortest paths: from a vertex `u` where the tree already ends we may walk
to any other vertex `v` paying `dist[u][v]`.

```
new[v] = min_u ( dp[mask][u] + dist[u][v] )
```

`new[·]` becomes the new `dp[mask][·]`.

The propagation costs `O(n²)` per mask, i.e. `O(2^t·n²)` ( ≤ 10⁷ operations).

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm returns the minimum possible total retainer fee.

---

##### Lemma 1  
After processing a mask `M` (combination + propagation)  
`dp[M][v]` equals the minimum cost of a Steiner tree that

* connects exactly the terminals of `M`,
* is contained in a single connected component,
* and whose component contains vertex `v`.

**Proof.** Induction over the number of bits in `M`.

*Base* – `|M| = 1`.  
The only terminal is `p`.  
Before propagation `dp[M][p]=0`, all other entries are ∞.
Propagation replaces them by `dist[p][v]`, the cheapest possible
way to obtain a tree that contains `p` and ends in `v`.  
Thus the statement holds.

*Induction step* – assume the statement true for all proper non‑empty
sub‑masks of `M`.  

Take any optimal Steiner tree `T` for mask `M` that contains `v`.
Remove `v` from `T`; the remaining edges split into several
connected components, each of them containing at least one terminal.
Choose the set of terminals of one component as sub‑mask `A`,
the rest as `B = M \ A`.  
Both components still end in `v` (otherwise `v` would be missing from the
corresponding part).  
By induction hypothesis their optimal costs are `dp[A][v]` and `dp[B][v]`.  
Therefore  

```
cost(T) ≥ dp[A][v] + dp[B][v] .
```

Taking the minimum over all possible splits yields  

```
cost(T) ≥ min_A ( dp[A][v] + dp[M\A][v] ) .
```

The algorithm sets `dp[M][v]` to at most this value, therefore after the
combination step `dp[M][v]` is **not larger** than any feasible tree that
already ends in `v`.

Now we may also extend a tree that already ends in some vertex `u`
by a cheapest path `u … v`.  
The cheapest possible extension costs exactly `dist[u][v]`,
hence after the propagation step `dp[M][v]` becomes the minimum over all
ways to end the tree in any `u` and then walk to `v`.  
Consequently `dp[M][v]` is **not larger** than any feasible Steiner tree
for mask `M` that contains `v`.

Conversely, every value created by the algorithm corresponds to a concrete
construction:

* combine two already feasible trees (induction hypothesis) that both end in
  the same vertex `v`,
* optionally walk from that vertex to another vertex using a cheapest path.

Both operations keep the tree feasible for mask `M`.  
Thus `dp[M][v]` cannot be smaller than the optimum. ∎



##### Lemma 2  
After all masks have been processed,
`ans = min_v dp[ALL][v]` equals the minimum possible total fee that connects
all primary languages.

**Proof.** By Lemma&nbsp;1, for `M = ALL` each `dp[ALL][v]` is the cheapest cost
of a feasible Steiner tree whose component contains `v`.  
Taking the minimum over all vertices discards the unnecessary condition
“contains `v`”, leaving exactly the cheapest feasible Steiner tree. ∎



##### Theorem  
The algorithm outputs the minimum total retainer fee needed so that every
primary language can be translated into every other one.

**Proof.** Directly from Lemma&nbsp;2. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

* Floyd‑Warshall : `O(n³)   ≤ 10⁶`
* DP over masks :

| operation                               | count                              | cost per operation |
|----------------------------------------|------------------------------------|--------------------|
| combine sub‑masks (∑ₘ 2^{|M|})          | `O(3^t)` ( ≤ 6·10⁴ )               | `O(n)`             |
| propagation (all‑pairs distances)      | `2^t` masks ( ≤ 1024 )             | `O(n²)`            |

Total DP   `O(3^t·n + 2^t·n²) ≤ 6·10⁶ + 10⁷  ≈ 1.6·10⁷` operations.

Memory consumption  

* `dist` : `n·n`  ≤ 10⁴ integers  
* `dp`   : `2^t·n` ≤ 1024·100 = 1.0·10⁵ integers  

Both far below the limits.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys

INF = 10 ** 15

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))

    terminals = [int(next(it)) - 1 for _ in range(t)]

    # ---------- all‑pairs shortest paths ----------
    dist = [[INF] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0

    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        if w < dist[u][v]:
            dist[u][v] = dist[v][u] = w

    # Floyd‑Warshall
    for k in range(n):
        dk = dist[k]
        for i in range(n):
            dik = dist[i][k]
            if dik == INF:
                continue
            row_i = dist[i]
            nd = dik
            for j in range(n):
                val = nd + dk[j]
                if val < row_i[j]:
                    row_i[j] = val

    # ---------- DP ----------
    size = 1 << t
    dp = [[INF] * n for _ in range(size)]

    # single terminal masks
    for i, term in enumerate(terminals):
        dp[1 << i][term] = 0

    # process all masks
    for mask in range(1, size):
        # combine two proper sub‑masks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            # both sub and other are non‑empty and smaller than mask
            dp_sub = dp[sub]
            dp_other = dp[other]
            dp_mask = dp[mask]
            for v in range(n):
                cand = dp_sub[v] + dp_other[v]
                if cand < dp_mask[v]:
                    dp_mask[v] = cand
            sub = (sub - 1) & mask

        # propagate through the graph (use pre‑computed shortest paths)
        cur = dp[mask]
        new = [INF] * n
        for u in range(n):
            du = cur[u]
            if du == INF:
                continue
            row = dist[u]
            nd = du
            for v in range(n):
                val = nd + row[v]
                if val < new[v]:
                    new[v] = val
        dp[mask] = new

    full = size - 1
    answer = min(dp[full])
    print(answer)


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input / output format.
