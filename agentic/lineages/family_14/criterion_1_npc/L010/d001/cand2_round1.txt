# Problem A — Cabling the Required Sites

Time limit: 5 s   Memory limit: 256 MB

## Description

A campus has **n** sites (numbered 1 to **n**). You are provided with a list of potential cabling options, each capable of joining a specific pair of sites for a known cost. Among all the sites, exactly **t** are designated as **required**.

Select cabling options to install so that all required sites are mutually reachable; no connectivity condition is imposed on sites that are not required. Determine the minimum total cost of a valid set of cabling options.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the ids of the required sites.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000): a cabling option joining site **u** and site **v** at cost **w**.
The cabling options are sufficient to ensure all required sites can be mutually reachable.

## Output

Print a single integer: the minimum total cost to make all required sites mutually reachable.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, using site 4 to interlink the required sites (cost 1+1+1 = 3) is cheaper than joining the three required sites without it (which would cost 4). In Example 3, there is only one required site, so no cabling is needed.
