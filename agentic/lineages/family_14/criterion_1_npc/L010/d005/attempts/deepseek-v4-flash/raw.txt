We can model this as a graph problem. The key observation is that we need to connect all target variables into a single connected component using the cheapest possible edges, but we can also use non-target variables as intermediate "hubs" to reduce cost.

This is essentially a **minimum Steiner tree** problem, but with a small number of targets (t ≤ 10), we can solve it using **bitmask DP over subsets of targets**.

Here’s the plan:

1. Compute all-pairs shortest paths between all nodes (Floyd–Warshall or Dijkstra from each node).
2. Use DP over subsets of target nodes:
   - `dp[mask][v]` = minimum cost to connect the targets in `mask` and have the tree rooted at node `v`.
   - Initialize `dp[1 << i][target[i]] = 0`.
   - Combine subsets: `dp[mask][v] = min(dp[mask][v], dp[sub][v] + dp[mask ^ sub][v])`.
   - Relax via shortest paths: `dp[mask][v] = min(dp[mask][v], dp[mask][u] + dist[u][v])`.
3. Answer is `min(dp[(1<<t)-1][v])` for any `v`.

Let's implement this efficiently.

```python
import sys
import heapq

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    targets = list(map(int, input().split()))
    targets = [x-1 for x in targets]  # 0-index

    INF = 10**18
    dist = [[INF]*n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append((v, w))
        adj[v].append((u, w))

    # Dijkstra from each node to get all-pairs shortest paths
    for src in range(n):
        d = [INF]*n
        d[src] = 0
        pq = [(0, src)]
        while pq:
            du, u = heapq.heappop(pq)
            if du > d[u]:
                continue
            for v, w in adj[u]:
                nd = du + w
                if nd < d[v]:
                    d[v] = nd
                    heapq.heappush(pq, (nd, v))
        dist[src] = d

    # DP over subsets
    full_mask = (1 << t) - 1
    dp = [[INF]*n for _ in range(1 << t)]

    for i in range(t):
        dp[1 << i][targets[i]] = 0

    for mask in range(1 << t):
        # Combine subsets
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if sub < other:  # avoid double work
                for v in range(n):
                    dp[mask][v] = min(dp[mask][v], dp[sub][v] + dp[other][v])
            sub = (sub - 1) & mask

        # Relax via shortest paths
        for v in range(n):
            if dp[mask][v] < INF:
                for u in range(n):
                    if dist[v][u] < INF:
                        nd = dp[mask][v] + dist[v][u]
                        if nd < dp[mask][u]:
                            dp[mask][u] = nd

    ans = min(dp[full_mask])
    print(ans)

if __name__ == "__main__":
    solve()
```
