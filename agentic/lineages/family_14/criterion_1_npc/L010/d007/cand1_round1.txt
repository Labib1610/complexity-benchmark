<STATEMENT>
# Problem A — Transitive Subgroup Generation

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing permutations of a set of **n** elements, numbered 1 to **n**. 

You are provided with **m** potential transpositions that you can use to form a generating set $S$. The $i$-th potential transposition swaps element **u** and element **v** (leaving all other elements fixed) and can be added to $S$ for a one-time cost of **w**. 

Let $H = \langle S \rangle$ be the subgroup generated by your chosen set of transpositions. 

You are given a list of **t** distinct target elements. Your objective is to select a subset of the potential transpositions such that the subgroup $H$ acts transitively on this set of target elements. Specifically, for every pair of target elements $a$ and $b$, there must exist some permutation $\pi \in H$ such that $\pi(a) = b$. 

You may select transpositions involving any of the **n** elements to serve as intermediate operations to achieve this.

Determine the absolute minimum total cost required to select such a set of transpositions.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers representing the target elements.
The next **m** lines each provide three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that the transposition swapping **u** and **v** is available to be selected for a cost of **w**.
It is guaranteed that selecting all available transpositions would allow the resulting subgroup to act transitively on the target elements.

## Output

Output a single integer representing the minimum total cost required.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the transpositions (1, 4), (2, 4), and (3, 4) costs 1 + 1 + 1 = 3. The subgroup $H$ generated by these three transpositions includes permutations that can map any element in {1, 2, 3} to any other element in {1, 2, 3}. For instance, applying (1, 4) then (2, 4) then (1, 4) yields the transposition (1, 2), which maps 1 to 2. Thus, $H$ acts transitively on the target elements 1, 2, and 3. This costs less than selecting (1, 2) and (2, 3) directly (which would cost 2 + 2 = 4).

In Example 3, with only one target element, the condition that there exists $\pi \in H$ such that $\pi(a) = b$ for all pairs in the target set is trivially satisfied (the only pair is 1 and 1, and the identity permutation maps 1 to 1). Thus, no transpositions need to be selected, and the minimum cost is 0.
</STATEMENT>
<RATIONALE>
The problem was translated from equivalence relations (which models easily map to graph connectivity) into the domain of permutation groups. Finding a minimum-cost set of transpositions that generates a subgroup acting transitively on a target subset is mathematically identical to finding a minimum-weight Steiner tree for those targets. This forces the models to reason through the abstract algebra to realize it is a shortest-path/connectivity problem, bypassing their pattern-matching on graph structures.
</RATIONALE>
<PRESERVED_ANSWER>
The orbits of a permutation group generated by transpositions correspond exactly to the connected components of the graph where those transpositions are edges, so the minimum cost to place the targets in a single orbit is identical to the minimum Steiner tree on those vertices.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Steiner Tree problem on a weighted undirected graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "acts transitively on this set" if they assume the subgroup must ONLY permute the target elements and fix the rest, but the text explicitly clarifies this by defining it as "for every pair ... there must exist some permutation $\pi \in H$ such that $\pi(a) = b$", removing ambiguity.
</RISK>
