# Problem A — Transposition Subgroup Synthesis

Time limit: 5 s   Memory limit: 256 MB

## Description

Consider a set of **n** distinct points, indexed from 1 to **n**.

You are given a collection of **m** available transpositions. A transposition swaps the positions of two specific points. Each available transposition between point **u** and point **v** has an associated assignment cost of **w**.

You must select a subset of these available transpositions. The selected transpositions generate a permutation group. Two points are considered orbit-equivalent if there exists a permutation in this generated group that maps one point to the other.

You are given a priority list of **t** distinct points. Your objective is to select a subset of transpositions such that all **t** priority points belong to the same orbit (i.e., they are all mutually orbit-equivalent). You may include transpositions involving any of the **n** points to achieve this.

Determine the absolute minimum total assignment cost required to select such a subset of transpositions.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers representing the indices of the priority points.
The next **m** lines each provide three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that the transposition swapping point **u** and point **v** is available for a cost of **w**.
It is guaranteed that selecting all available transpositions would make all priority points mutually orbit-equivalent.

## Output

Output a single integer representing the minimum total assignment cost required.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the transpositions between point 4 and points 1, 2, and 3 costs 1 + 1 + 1 = 3. In the permutation group generated by these three transpositions, points 1, 2, and 3 all belong to the same orbit. This costs less than selecting the transpositions directly among 1, 2, and 3 (which would cost 2 + 2 = 4).

In Example 3, with only one priority point, the condition is already met without selecting any transpositions, so the minimum cost is 0.
