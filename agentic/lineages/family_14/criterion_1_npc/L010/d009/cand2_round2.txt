<STATEMENT>
# Problem A — Pressure Equalization

Time limit: 5 s   Memory limit: 256 MB

## Description

An industrial facility contains **n** isolated fluid chambers, numbered 1 to **n**. Each chamber initially holds a fluid at an unspecified, potentially unique pressure.

You have access to **m** distinct pipe blueprints. Each blueprint specifies an equalization pipe that can be installed between a specific pair of chambers, **u** and **v**, for an installation cost of **w**. If a pipe is installed, fluid flows freely between the two chambers until their pressures are exactly equalized. Because equalization is a transitive physical process, if any group of chambers is linked together by installed pipes, all chambers in that group will equalize to the exact same pressure.

There are **t** critical chambers in the facility. Your objective is to select a subset of pipe blueprints to install such that, regardless of the initial fluid pressures, all **t** critical chambers are guaranteed to equalize to the exact same pressure as each other. 

Determine the absolute minimum total installation cost required to select such a subset of pipe blueprints.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers representing the identifiers of the critical chambers.
The next **m** lines each provide three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that an equalization pipe between chamber **u** and chamber **v** can be installed for a cost of **w**.
It is guaranteed that installing all available pipes would force all critical chambers to equalize to the same pressure.

## Output

Output a single integer representing the minimum total installation cost required.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, installing the equalization pipes between chamber 4 and chambers 1, 2, and 3 costs 1 + 1 + 1 = 3. With these three pipes installed, chambers 1, 2, and 3 must all equalize to the same pressure (because they all equalize with chamber 4). This costs less than a non-relay-only installation among the required chambers (which would cost 2 + 2 = 4).

In Example 3, with only one critical chamber, no pipe is needed to ensure it has the same pressure as itself, so the minimum cost is 0.
</STATEMENT>
<RATIONALE>
The graph structure and connectivity requirements were replaced with a physical property synchronization scenario (pressure equalization across chambers). By removing explicit permission to use non-critical intermediate elements and avoiding graph terminology, models must deduce that transitive equalization corresponds to finding a minimum-cost Steiner tree connecting the required terminals.
</RATIONALE>
<PRESERVED_ANSWER>
The physical equalization is transitive and symmetric, which is mathematically identical to edges forming connected components; thus, finding the minimum cost to equalize a subset of chambers is exactly the Steiner tree problem on the given graph, preserving all answers.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the classic Minimum Steiner Tree problem in graphs, which is NP-complete, as the input size and cost structure are perfectly preserved.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "guaranteed to equalize" as requiring a specific pressure value rather than just being equal to each other, though "equalize to the exact same pressure as each other" clarifies this.
</RISK>
