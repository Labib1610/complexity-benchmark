<STATEMENT>
# Problem A — Logical Consistency Enforcement

Time limit: 5 s   Memory limit: 256 MB

## Description

An automated reasoning engine manages a set of **n** Boolean variables, numbered 1 to **n**. Each variable can independently be assigned a state of True or False.

You have access to **m** potential equivalence constraints. Each constraint can be activated between a specific pair of variables, **u** and **v**, for a processing cost of **w**. Activating a constraint restricts the engine so that it only considers variable assignments where **u** and **v** evaluate to the exact same truth value. 

There is a designated set of **t** primary variables. Your objective is to activate a subset of constraints such that, in every possible assignment of truth values that satisfies all activated constraints, the **t** primary variables are guaranteed to all evaluate to the same truth value (either all True or all False). 

Determine the absolute minimum total processing cost required to activate such a subset of constraints.

## Input

The first line contains three integers **n**, **m**, and **t**. The system architecture enforces strict limits on these parameters: **t** is at least 1 and at most the number of distinct digits in the standard base-10 number system; **n** is at least 1 and at most the number of years in a century; and **m** is between 0 and the maximum number of unique unordered pairs that can be formed from the **n** variables.
The second line contains **t** distinct integers representing the identifiers of the primary variables.
The next **m** lines each provide three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, and **w** is at least 1 and at most one million), indicating that an equivalence constraint between variable **u** and variable **v** can be activated for a processing cost of **w**.
It is guaranteed that activating all available constraints would successfully force all primary variables to evaluate to the same truth value.

## Output

Output a single integer representing the minimum total processing cost required.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, activating the equivalence constraints between variable 4 and variables 1, 2, and 3 costs 1 + 1 + 1 = 3. In any assignment satisfying these three constraints, variables 1, 2, and 3 must all share the same truth value as variable 4, and therefore match each other. This costs less than activating constraints directly among the primary variables (which would cost 2 + 2 = 4).

In Example 3, with only one primary variable, no constraints need to be activated to ensure it has the same truth value as itself, so the minimum cost is 0.
</STATEMENT>
<METHOD_NAME>Logical Equivalence Isomorphism</METHOD_NAME>
<METHOD_DESCRIPTION>I translated the graph connectivity requirement into a logical equivalence requirement over Boolean variables. Instead of asking to connect vertices, the problem asks to select a minimum cost set of biconditional constraints such that all primary variables are forced to the same truth value in any satisfying assignment. This perfectly preserves the Steiner Tree structure while completely removing all graph terminology, preventing models from pattern-matching the problem to Dreyfus-Wagner while still providing a rigorous, unambiguous definition. I also replaced explicit numeric bounds with physical constants (digits in base-10, years in a century) to break shallow regex/parsing heuristics.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<RATIONALE>
The problem was completely reframed from a physical network (chambers and pipes) to a logical constraint satisfaction problem (Boolean variables and equivalence constraints). This forces the model to deduce that ensuring a set of variables always share the same truth value is isomorphic to finding a spanning component in a graph, breaking reliance on graph-specific pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that variables must share the same truth value in all valid assignments is mathematically identical to requiring that those variables belong to the same connected component of activated constraints, preserving the minimum cost subset exactly.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Weight Steiner Tree problem on an undirected graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the problem as a variant of 2-SAT or a general Boolean Satisfiability optimization problem and fail to recognize that the constraints inherently form an undirected graph, though this is the intended difficulty.
</RISK>
