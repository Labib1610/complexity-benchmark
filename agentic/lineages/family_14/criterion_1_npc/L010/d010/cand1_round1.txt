<STATEMENT>
# Problem A — Basis Selection

Time limit: 5 s   Memory limit: 256 MB

## Description

Let $V$ be an $n$-dimensional vector space over the real numbers, with a standard basis $e_1, e_2, \dots, e_n$. 
You are given a catalog of $m$ available difference vectors. Each vector in the catalog is of the form $e_u - e_v$, and adding it to your chosen set $T$ incurs a specific cost $w$.

You are also given a target set $S$ consisting of $t$ specific basis vector indices.
Your objective is to select a subset $T$ of the catalog vectors such that the subspace spanned by $T$ contains the vector $e_i - e_j$ for every pair of indices $i$ and $j$ in $S$.

Determine the minimum total cost of a subset $T$ that satisfies this requirement.

## Input

The first line contains three integers $n$, $m$, and $t$ (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains $t$ distinct integers representing the target indices in $S$.
The next $m$ lines each provide three integers $u$, $v$, and $w$ (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that the vector $e_u - e_v$ is available in the catalog for a cost of $w$.
It is guaranteed that selecting all $m$ catalog vectors would satisfy the condition for the target set $S$.

## Output

Output a single integer representing the minimum total cost required.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the vectors $e_1 - e_4$, $e_2 - e_4$, and $e_3 - e_4$ costs 1 + 1 + 1 = 3. 
The subspace spanned by these three vectors contains $e_1 - e_2$ because $(e_1 - e_4) - (e_2 - e_4) = e_1 - e_2$. 
Similarly, it contains $e_2 - e_3$ and $e_1 - e_3$. Thus, for any $i, j \in \{1, 2, 3\}$, the required difference vector is in the span. This is the minimum cost to satisfy the requirement.

In Example 3, with only one target index ($S = \{1\}$), the only pair is $i=1, j=1$. The required vector is $e_1 - e_1 = 0$, which is trivially in the span of the empty set. Thus, no vectors need to be purchased, and the minimum cost is 0.
</STATEMENT>
<RATIONALE>
Replaced the explicit graph connectivity and fluid chamber scenario with a mathematically equivalent linear algebra framing over a vector space. To satisfy the basis span condition, models must deduce that the difference vectors correspond to rows of a graph's incidence matrix, making the problem equivalent to finding a minimum-cost connecting subgraph (Steiner Tree), thereby thwarting superficial pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
A set of difference vectors $e_u - e_v$ spans $e_i - e_j$ if and only if $i$ and $j$ are in the same connected component of the corresponding graph, making the minimum cost identical for every input.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
