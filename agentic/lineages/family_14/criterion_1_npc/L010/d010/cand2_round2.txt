<METHOD_NAME>Linear Algebra Isomorphism</METHOD_NAME>
<METHOD_DESCRIPTION>Transforms the graph connectivity problem into an equivalent linear algebra problem involving the span of difference vectors. This hides the graph structure and the standard Steiner Tree DP cues behind vector space terminology, forcing models to recognize the graphic matroid equivalence to apply the correct algorithm.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Subspace Spanning

Time limit: 5 s   Memory limit: 256 MB

## Description

You are working in an **n**-dimensional vector space over the real numbers, with a standard basis denoted by $e_1, e_2, \dots, e_n$.

You have a catalog of **m** available difference vectors. Each available vector is of the form $d = e_u - e_v$ for a specific pair of basis indices **u** and **v**, and has an associated procurement cost **w**. You may procure any subset of these vectors to form a generating set $S$.

You are given a target set of **t** specific basis indices. Your objective is to procure a subset of the available difference vectors such that, for every pair of indices $i$ and $j$ from the target set, the difference vector $e_i - e_j$ lies within the linear span of your procured generating set $S$.

Determine the absolute minimum total procurement cost required to form such a generating set $S$.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers representing the target basis indices.
The next **m** lines each provide three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that the difference vector $e_u - e_v$ can be added to your generating set for a procurement cost of **w**.
It is guaranteed that procuring all available vectors would successfully span all required difference vectors between the target indices.

## Output

Output a single integer representing the minimum total procurement cost required.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, procuring the difference vectors $e_1 - e_4$, $e_2 - e_4$, and $e_3 - e_4$ costs 1 + 1 + 1 = 3. The linear span of these three vectors includes $e_1 - e_2$ (since $(e_1 - e_4) - (e_2 - e_4) = e_1 - e_2$), as well as $e_2 - e_3$ and $e_1 - e_3$. Thus, all difference vectors between the target indices (1, 2, and 3) are in the span. This is cheaper than procuring vectors exclusively among the target indices (such as $e_1 - e_2$ and $e_2 - e_3$, which would cost 2 + 2 = 4).

In Example 3, with only one target index, any pair of indices from the target set must be the same index $i$. The required difference vector is $e_i - e_i = 0$, which is vacuously in the linear span of the empty set. Thus, no vectors need to be procured, and the minimum cost is 0.
</STATEMENT>
<RATIONALE>
The problem is mathematically isomorphic to Steiner Tree on a graph, but framed entirely in terms of linear algebra (vector spaces, basis indices, difference vectors, and linear span). The difference vector $e_u - e_v$ corresponds to an undirected edge between $u$ and $v$, and a set of vectors spans $e_i - e_j$ if and only if there is a path between $i$ and $j$ in the corresponding graph. This completely masks the graph-theoretic nature of the problem, forcing models to independently recognize the graphic matroid property to realize that the Dreyfus-Wagner DP algorithm applies.
</RATIONALE>
<PRESERVED_ANSWER>
The linear independence and spanning properties of difference vectors are exactly equivalent to the acyclicity and connectivity of edges in a graph, meaning the minimum cost subset of vectors to span the target differences is identical to the minimum cost Steiner tree connecting the target vertices.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Weight Steiner Tree problem on a graph, merely translated into its precise linear algebraic equivalent via the incidence matrix, preserving its NP-complete status.
</PRESERVED_CLASS>
