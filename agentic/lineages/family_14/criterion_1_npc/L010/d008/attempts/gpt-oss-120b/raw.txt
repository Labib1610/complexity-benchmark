**Solution Explanation**

For every mandate we pay we force the two incident canvases to have the same colour.
If we pay a set of mandates, the canvases are partitioned into connected components of the
chosen edges – canvases inside one component must obtain the same colour,
different components may obtain different colours.

Therefore the requirement  

*“all `t` centerpiece canvases must obtain the same colour”*  

is equivalent to  

*“the `t` special vertices must become connected by the paid edges”*.

So we have to choose a set of edges of minimum total weight that connects all
special vertices.  
That is exactly the **Steiner Tree** problem in an undirected weighted graph,
with at most `t ≤ 10` terminals and `n ≤ 100` vertices.

The classic exact algorithm for small `t` is the
*Dreyfus‑Wagner* dynamic programming:

```
dp[mask][v] = minimum cost of a tree
              that connects all terminals whose bits are 1 in mask
              and whose (arbitrary) root is vertex v
```

`mask` runs over all subsets of the `t` terminals (`0 … 2^t‑1`),
`v` over all vertices (`1 … n`).

--------------------------------------------------------------------
### 1.   All‑pairs shortest paths

Inside a tree we may travel from one vertex to another along the unique
path, paying the sum of edge weights on that path.
Consequently, after we have built a tree that already connects a set of
terminals and ends in vertex `u`, we can move the root to any other vertex
`v` by adding the cheapest path `u → v`.  
Hence we need the shortest distances between every pair of vertices.

`n ≤ 100`, so Floyd‑Warshall (`O(n³)`) is fast enough.

--------------------------------------------------------------------
### 2.   DP initialisation

For each terminal `i` (its original vertex number `term[i]`)

```
dp[ 1<<i ][ term[i] ] = 0          # no edge needed, tree of size 0
dp[ 1<<i ][ other vertices ] = INF
```

--------------------------------------------------------------------
### 3.   DP transition – merging two sub‑trees

For a non‑empty mask `M` we try to split it into two non‑empty disjoint
sub‑masks `A` and `B` (`A ∪ B = M`).  
If we already know optimal trees for `A` and for `B` that both end in the
same vertex `v`, we can unite them (they share the root `v`) and obtain a
tree for `M` ending in `v` with cost `dp[A][v] + dp[B][v]`.

```
for every proper non‑empty submask A of M:
        B = M ^ A
        for every vertex v:
                dp[M][v] = min( dp[M][v], dp[A][v] + dp[B][v] )
```

The number of masks is `2^t` ( ≤ 1024 ), the inner loop over vertices is `n`
( ≤ 100 ), the total work of this merging step is `O(3^t * n)` – easily fast.

--------------------------------------------------------------------
### 4.   DP transition – moving the root using shortest paths

After the merging step `dp[M][v]` is the cheapest cost of a tree that
connects the terminals of `M` **and** ends in `v`.  
We may now relocate the root to any vertex `w` by adding the cheapest
`v → w` path:

```
dp[M][w] = min over v ( dp[M][v] + dist[v][w] )
```

This is a simple `O(n²)` relaxation for each mask.

--------------------------------------------------------------------
### 5.   Result

The whole set of terminals is `FULL = (1<<t) - 1`.  
The answer is the cheapest tree for this mask, irrespective of the root:

```
answer = min_v dp[FULL][v]
```

If `t = 1` the DP never adds any edge, the answer is `0` as required.

--------------------------------------------------------------------
### 6.   Correctness Proof  

We prove that the algorithm returns the minimum possible total fee.

---

#### Lemma 1  
For any mask `M` and vertex `v`, after the algorithm finishes processing
`M`, `dp[M][v]` equals the minimum cost of a **connected** subgraph
containing exactly the terminals of `M` and having `v` in its component.

*Proof.* By induction over the size of `M`.

*Base* `|M| = 1`.  
`dp[1<<i][v]` is `0` if `v` is the terminal itself, otherwise `INF`.  
The only connected subgraph that contains the single terminal and `v`
is possible iff `v` is that terminal, with cost `0`. So the statement holds.

*Induction step.* Assume the statement true for all proper non‑empty subsets
of `M`.  
Consider any optimal connected subgraph `S` for mask `M` that contains `v`.
Pick any edge of `S` whose removal separates the terminals of `M` into two
non‑empty groups `A` and `B`. Let the two resulting components contain `v`
(both, because we keep `v` in the component after removal).  
Both components are connected subgraphs for masks `A` and `B` respectively,
both contain `v`. By induction their optimal costs are `dp[A][v]` and
`dp[B][v]`. Adding the removed edge gives cost `dp[A][v] + dp[B][v]`,
therefore `dp[M][v] ≤` optimal cost.

Conversely, the algorithm can construct a subgraph of exactly that cost:
first take optimal subgraphs for `A` and `B` ending in `v` (cost
`dp[A][v] + dp[B][v]`), then add the edge that connects the two components.
Thus `dp[M][v]` is not larger than the optimum. ∎



#### Lemma 2  
After the *root‑moving* relaxation for mask `M`,
`dp[M][w] = min_v ( optimal cost for mask M with root v + dist[v][w] )`,
i.e. the minimum cost of a connected subgraph for mask `M` that contains `w`.

*Proof.* Adding the cheapest path from `v` to `w` (cost `dist[v][w]`) to an
optimal subgraph for `M` rooted at `v` yields a connected subgraph for `M`
that also contains `w`. The relaxation takes the minimum over all `v`,
so `dp[M][w]` cannot be larger than the optimum.  
If a connected subgraph for `M` contains `w`, pick any vertex `v` of that
subgraph that is also a terminal of `M` (or any vertex). Removing the
unique `v‑w` path leaves a connected subgraph for `M` rooted at `v` with
cost at most `optimal - dist[v][w]`. Hence the optimum is at least the
minimum computed by the relaxation. ∎



#### Lemma 3  
After processing all masks, for every mask `M` and vertex `v`,
`dp[M][v]` equals the minimum possible total fee of a set of mandates that
guarantees all terminals of `M` are forced to have the same colour **and**
that set contains `v` in the same colour class.

*Proof.* By Lemma&nbsp;1 the DP after merging gives the optimum among trees
that end in `v`. Lemma&nbsp;2 extends this optimum to any connected subgraph,
which is exactly the set of paid edges we may choose (extra edges can only
increase cost). Therefore the value matches the definition. ∎



#### Lemma 4  
`min_v dp[FULL][v]` equals the minimum total fee that forces all `t`
centerpiece canvases to share a colour.

*Proof.* Any feasible set of paid mandates must make the `t` special vertices
belong to a single connected component; pick any vertex `v` of that component.
The cost of the set is at least `dp[FULL][v]` by Lemma&nbsp;3, therefore at
least the minimum over `v`.  
Conversely, for the vertex `v*` attaining the minimum, the subgraph
corresponding to `dp[FULL][v*]` is a feasible set of mandates, so the minimum
is achievable. ∎



#### Theorem  
The algorithm outputs the minimum possible total legal fee required to
enforce that all centerpiece canvases receive the same colour.

*Proof.* Directly from Lemma&nbsp;4. ∎



--------------------------------------------------------------------
### 7.   Complexity Analysis

* Floyd‑Warshall: `O(n³) ≤ 10⁶`
* DP merging: `O(3^t · n) ≤ 3^10·100 ≈ 590 000`
* DP root‑moving: `O(2^t · n²) ≤ 1024·10⁴ = 10⁷`
* Memory: `dp` array `2^t × n ≤ 1024·100 = 102 400` integers.

All well inside the limits.

--------------------------------------------------------------------
### 8.   Reference Implementation  (Python 3)

```python
import sys
import math

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))
    terminals = [int(next(it)) - 1 for _ in range(t)]

    INF = 10**18
    # distance matrix
    dist = [[INF] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        if w < dist[u][v]:
            dist[u][v] = dist[v][u] = w

    # Floyd‑Warshall
    for k in range(n):
        dk = dist[k]
        for i in range(n):
            di = dist[i]
            ik = di[k]
            if ik == INF:
                continue
            for j in range(n):
                nd = ik + dk[j]
                if nd < di[j]:
                    di[j] = nd

    full = 1 << t
    dp = [[INF] * n for _ in range(full)]
    for i, v in enumerate(terminals):
        dp[1 << i][v] = 0

    # iterate masks
    for mask in range(1, full):
        # merging submasks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            # only need each unordered pair once; enforce sub < other to cut work
            if sub < other:
                dp_sub = dp[sub]
                dp_other = dp[other]
                dp_mask = dp[mask]
                for v in range(n):
                    val = dp_sub[v] + dp_other[v]
                    if val < dp_mask[v]:
                        dp_mask[v] = val
            sub = (sub - 1) & mask

        # shortest‑path relaxation: dp[mask][w] = min_v dp[mask][v] + dist[v][w]
        dp_mask = dp[mask]
        # we can compute new array then assign
        new = dp_mask[:]  # copy current values
        for v in range(n):
            dv = dp_mask[v]
            if dv == INF:
                continue
            drow = dist[v]
            for w in range(n):
                nd = dv + drow[w]
                if nd < new[w]:
                    new[w] = nd
        dp[mask] = new

    ans = min(dp[full - 1])
    print(ans)

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
