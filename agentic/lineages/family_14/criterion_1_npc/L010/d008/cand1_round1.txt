# Problem A — Chromatic Compliance Mandates

Time limit: 5 s   Memory limit: 256 MB

## Description

An art exhibition features a collection of unpainted canvases, indexed from 1 to **n**.

You are provided with a list of available color-match mandates. A mandate legally binds canvas **u** and canvas **v**, requiring them to be painted the exact same color. Enacting the mandate between canvas **u** and canvas **v** requires an administrative fee of **w**. Canvases that are not bound by an enacted mandate (either directly or indirectly) may be painted the same color or different colors; there are no restrictions on the painting other than strictly obeying all enacted mandates.

You are given a specific list of centerpiece canvases. Your objective is to enact a subset of the available mandates such that, in *every* legally compliant painting of the exhibition (assuming an ample palette of available colors), all centerpiece canvases are absolutely forced to be painted the exact same color.

Determine the absolute minimum total administrative fee required to enact such a subset of mandates.

## Input

The first line contains three integers **n**, **m**, and **t**, representing the total number of canvases, the number of available mandates, and the number of centerpiece canvases, respectively. (The total number of canvases **n** is at least 1 and does not exceed the gallery's maximum capacity of one hundred. The number of available mandates **m** is non-negative and bounded by the total number of unique pairs of canvases. The number of centerpiece canvases **t** is at least 1 and is strictly limited to the ten display pedestals available.)
The second line contains **t** distinct integers representing the indices of the centerpiece canvases.
The next **m** lines each provide three integers **u**, **v**, and **w**, indicating that a mandate between canvas **u** and canvas **v** can be enacted for a fee of **w**. (The indices **u** and **v** are distinct and valid between 1 and **n**; the fee **w** is strictly positive and capped at one million).
It is guaranteed that enacting all available mandates would successfully force all centerpiece canvases to share the same color.

## Output

Output a single integer representing the minimum total administrative fee required.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, enacting the mandates between canvas 4 and canvases 1, 2, and 3 requires a fee of 1 + 1 + 1 = 3. In any legally compliant painting respecting these three mandates, canvas 1 must match canvas 4, canvas 2 must match 4, and canvas 3 must match 4. Consequently, canvases 1, 2, and 3 are forced to all be the exact same color. This costs less than enacting the mandates directly among 1, 2, and 3 (which would cost 2 + 2 = 4).

In Example 3, with only a single centerpiece canvas, it trivially matches its own color without needing to enact any mandates, so the minimum fee is 0.

<RATIONALE>
I reframed the problem from permutation groups to chromatic constraint entailment. By using terms like "painting" and "colors", models are heavily baited to apply Graph Coloring logic (which focuses on conflict avoidance). However, enforcing equality across a subset of variables in all satisfying assignments mathematically requires forming a connected subgraph, forcing the model to recognize the Steiner Tree structure despite the misdirecting domain. I also integrated S07 to hide the bare inequalities behind the gallery's physical capacities.
</RATIONALE>
<PRESERVED_ANSWER>
The only way to logically force a set of independent variables to hold identical values in every valid assignment of equality constraints is if those variables belong to the same connected component of constraints; thus, the minimum fee to achieve this is exactly the minimum Steiner Tree cost.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Steiner Tree problem on graphs (NPC), as the canvases act as vertices, mandates as edges with weights, and centerpiece canvases as terminals that must be connected.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "legally compliant painting" as implying adjacent canvases without mandates must be different colors (standard graph coloring), but the description explicitly states "there are no restrictions on the painting other than strictly obeying all enacted mandates", which clearly removes this ambiguity.
</RISK>
