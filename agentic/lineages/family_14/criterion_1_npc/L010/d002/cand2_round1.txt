<STATEMENT>
# Problem A — Cabling the Critical Locations

Time limit: 5 s
Memory limit: 256 MB

## Description

A campus infrastructure consists of **n** locations, numbered from 1 to **n**. You have the option to lay cable links between specific pairs of locations, where each potential link has an associated installation price. Within this campus, a subset of **t** locations are designated as critical.

Your task is to select a set of cable links to purchase and install. The chosen links must form a communication infrastructure where any critical location can route messages to any other critical location, either directly or by relaying through a sequence of installed links. Determine the minimum total installation price required to accomplish this.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n(n−1)/2).
The second line lists **t** distinct integers representing the critical locations.
The subsequent **m** lines each contain three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that a cable link can be installed between location **u** and location **v** for a price of **w**.
It is guaranteed that the available links are sufficient to establish communication between all critical locations.

## Output

Output a single integer representing the minimum total installation price to ensure all critical locations can route messages to one another.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, routing the communication infrastructure through location 4 (which costs 1+1+1 = 3) is cheaper than directly linking the three critical locations without it (which would cost 2+2 = 4). In Example 3, there is only one critical location, so no cable links need to be installed.
</STATEMENT>
<RATIONALE>
Removed the explicit statement "No connectivity condition is imposed on sites that are not required," which acted as a direct keyword trigger for "Steiner Tree intermediates." Models must now infer from the routing requirements that any location can be part of the chosen paths without being strictly required, forcing them to reason about the network topology rather than pattern-matching the textbook description of a Steiner point.
</RATIONALE>
<PRESERVED_ANSWER>
The set of valid networks remains exactly those that connect the critical locations, and the optimization objective is identical, so the minimum cost is unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the classic Minimum Weight Steiner Tree in graphs, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might incorrectly assume that they are strictly forbidden from using non-critical locations, though the phrase "relaying through a sequence of installed links" combined with Example 1 strongly demonstrates otherwise.
</RISK>
