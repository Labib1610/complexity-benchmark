# Problem A — Equivalence Entailment

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing a theoretical system of **n** abstract elements, identified by integers from 1 to **n**.

You are provided with a list of **m** potential bidirectional equivalences. Each potential equivalence indicates that element **u** is interchangeable with element **v**, and can be formally proven by expending a one-time cost of **w** energy units.

Equivalence is transitive: if you prove that element **A** is interchangeable with element **B**, and that element **B** is interchangeable with element **C**, then it is logically deduced that element **A** is interchangeable with element **C** at no additional cost. 

You are given a priority list of **t** target elements. Your objective is to select a subset of the potential equivalences to prove such that, through direct proof and logical deduction, every target element is established as interchangeable with every other target element. You may prove equivalences involving any of the **n** elements to serve as intermediate deductive steps.

Determine the absolute minimum total energy cost required to prove such a subset of equivalences.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers representing the identities of the target elements.
The next **m** lines each provide three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that a potential equivalence between element **u** and element **v** can be proven for a cost of **w** energy units.
It is guaranteed that some subset of equivalences allows all target elements to be established as mutually interchangeable.

## Output

Output a single integer representing the minimum total energy cost required.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, proving the equivalences between element 4 and elements 1, 2, and 3 costs 1 + 1 + 1 = 3 energy units. This logically entails that elements 1, 2, and 3 are all mutually interchangeable (for instance, element 1 is interchangeable with 4, and 4 with 2, deducing that 1 is interchangeable with 2). This strategy costs less than proving the direct equivalences between 1, 2, and 3 (which would cost 2 + 2 = 4 energy units).

In Example 3, with only one target element, it is trivially interchangeable with itself, requiring no proofs, so the minimum cost is 0.
</STATEMENT>
<RATIONALE>
The problem was reframed from a network routing / value-passing scenario to a logical equivalence deduction scenario. This removes the "unlimited number of times" and "pass values" phrasing that models used to pattern-match the problem to a Steiner Tree or shortest-path network routing. To solve it, models must now genuinely recognize that finding the minimum cost to form an equivalence class spanning a subset of elements is mathematically identical to finding a minimum Steiner Tree.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical structure is identical: selecting a subset of bidirectional equivalences to make a subset of elements mutually interchangeable is equivalent to selecting a subset of edges to connect a subset of vertices in a graph.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the exact same Minimum Steiner Tree problem on an undirected weighted graph, which is NP-complete, solvable in the same time complexity via the Dreyfus-Wagner algorithm.
</PRESERVED_CLASS>
