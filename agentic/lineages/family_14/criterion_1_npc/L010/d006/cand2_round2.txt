<STATEMENT>
# Problem A — Quotient Space Identification

Time limit: 5 s   Memory limit: 256 MB

## Description

A discrete space contains **n** points, numbered 1 to **n**. Initially, each point is distinct.

You are provided with **m** possible gluing operations. Each operation can be performed by paying a one-time cost of **w** energy units. Once an operation between point **u** and point **v** is performed, it identifies point **u** and point **v** as the exact same point in a quotient space. This identification is transitive: if **x** is identified with **y**, and **y** is identified with **z**, then **x** is identified with **z**.

You are given a list of **t** required points. Your objective is to perform a subset of operations such that all **t** required points are merged into a single point in the quotient space. You may use any of the **n** points as intermediates to achieve this.

Determine the minimum total energy cost required to perform such a set of operations.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers representing the identities of the required points.
The next **m** lines each provide three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that an operation between point **u** and point **v** can be performed for a cost of **w** energy units.
It is guaranteed that some subset of operations allows all required points to be merged.

## Output

Output a single integer representing the minimum total energy cost required.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, performing operations that identify point 4 with points 1, 2, and 3 costs 1 + 1 + 1 = 3. This allows points 1, 2, and 3 to all be merged into a single point, costing less than the cheapest way using only direct operations among required points 1, 2, and 3 (which costs 4).

In Example 3, with one required point, it already exists as a single point in the quotient space without any operations, so the minimum cost is 0.

The problem statement was reframed using topological quotient space terminology instead of graph-theoretic or network-connectivity terms. The word "trivially" was removed as requested by the gate feedback to avoid any complexity-class vocabulary. The note was updated to accurately reflect the cost of direct operations without implying specific edges were omitted.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical structure remains identical: points are vertices, gluing operations are edges with costs, and transitivity corresponds to connected components, exactly preserving the minimum cost to connect the required vertices.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is still the classic Steiner Tree problem on a weighted graph, preserving its NP-completeness and solvable via the exact same algorithms.
</PRESERVED_CLASS>
