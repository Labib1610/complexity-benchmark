<METHOD_DESCRIPTION>
Transforms the graph connectivity problem into a topological quotient space problem. Instead of variables and values (which easily maps to connected components or shortest paths), it uses topological points and identification maps (gluing). The goal is to find the minimum cost set of identifications such that a specific subset of points maps to the same equivalence class in the quotient space. This avoids all graph, network, and data-flow terminology, preventing the model from recognizing the Steiner Tree structure through surface pattern matching while maintaining perfect mathematical equivalence.
</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Topological Quotient Space

Time limit: 5 s   Memory limit: 256 MB

## Description

A topological space initially consists of **n** distinct, independent points, numbered 1 to **n**.

You can alter the space by applying gluing operations. You are provided with **m** possible gluing operations. Each operation specifies two points, **u** and **v**, and a cost of **w** energy units. If you choose to apply this operation, you pay the energy cost, and the space is modified by topologically identifying point **u** and point **v** (merging them into a single point). 

Topological identification forms an equivalence relation. Therefore, if point **u** is identified with point **v**, and point **v** is identified with point **x**, then **u**, **v**, and **x** all become the exact same point in the resulting quotient space. An applied gluing operation permanently merges the points.

You are given a list of **t** target points. Your objective is to select and apply a subset of the available gluing operations such that, in the final quotient space, all **t** target points have been merged into one single identical point. You may use any of the **n** points as intermediate identifications to achieve this.

Determine the absolute minimum total energy cost required to apply such a subset of gluing operations.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers representing the initial identities of the target points.
The next **m** lines each provide three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that a gluing operation between point **u** and point **v** can be applied for a cost of **w** energy units.
It is guaranteed that some subset of operations allows all target points to be merged into a single point.

## Output

Output a single integer representing the minimum total energy cost required.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, applying the gluing operations that identify point 4 with points 1, 2, and 3 costs 1 + 1 + 1 = 3. This merges points 1, 2, and 3 into the same point in the quotient space (along with point 4). This costs less than applying operations directly between 1, 2, and 3 (which would cost 2 + 2 = 4).

In Example 3, with only one target point, it trivially exists as a single point in the quotient space without any operations, so the minimum cost is 0.
</STATEMENT>
<RATIONALE>
The problem was completely reframed using the mathematics of topological quotient spaces. By replacing "variables passing values" with "topological identification of points", the problem strips away the network and data-flow metaphors that trigger LLMs to recognize graph connectivity and shortest-path reductions. Models must now genuinely reason that forming an equivalence class among a subset of elements via pairwise symmetric relations is isomorphic to the Steiner Tree problem. (Note: The specific S12 suggestion of banning non-target relays was ignored because it would change the optimal answer for any hidden test case where those relays are required, violating the identical answers constraint).
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical definition of topological identification is an equivalence relation matching exactly the connected components of a graph; finding the minimum cost to place a subset of elements in the same equivalence class is identical to finding the minimum cost Steiner Tree.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Steiner Tree problem on an undirected graph, which is NP-complete, with identical bounds and state space.
</PRESERVED_CLASS>
<RISK>
Models unfamiliar with rigorous topological terminology might hallucinate spatial or geometric distances between the points, though the text strictly defines the mechanics of the gluing operations to prevent this.
</RISK>
