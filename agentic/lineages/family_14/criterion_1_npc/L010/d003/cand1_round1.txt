# Problem A — Fiber Integration for Critical Hubs

Time limit: 5 s   Memory limit: 256 MB

## Description

An enterprise is upgrading its physical network across **n** operational hubs, numbered 1 through **n**. Vendors have proposed **m** direct fiber connections, each linking two specific hubs for a stated price.

The enterprise's primary requirement is to establish full connectivity among a designated group of **t** critical hubs. Full connectivity means a signal can travel between any two critical hubs. To achieve this, signals can pass through any number of active fiber connections. Hubs that are not in the critical group can be used as relay points to bridge connections.

Calculate the lowest possible total price to activate a collection of fiber connections that successfully integrates all **t** critical hubs into a single communicating unit.

## Input

The first line contains three integers **n**, **m**, and **t**. The total number of hubs **n** is between 1 and 100. The number of available connections **m** is between 0 and **n**(**n**−1)/2. The size of the critical group **t** is at least 1 and at most 10.
The second line contains **t** distinct integers identifying the critical hubs.
The next **m** lines each provide three integers **u**, **v**, and **w**. This indicates that a direct fiber connection can be activated between hub **u** and hub **v** (where **u** and **v** are distinct hubs between 1 and **n**) for a price of **w** (between 1 and 1,000,000).
It is guaranteed that it is possible to integrate all critical hubs using the provided proposals.

## Output

Output a single integer representing the minimum total price to ensure all critical hubs are integrated.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, using hub 4 as a relay point (which costs 1+1+1 = 3) is more cost-effective than linking the three critical hubs directly (which would cost 4). In Example 3, there is only one critical hub, so no connections need to be activated.
