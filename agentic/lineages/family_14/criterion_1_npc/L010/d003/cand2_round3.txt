# Problem A — Interconnecting the Critical Facilities

Time limit: 5 s   Memory limit: 256 MB

## Description

A regional grid contains **n** stations, indexed from 1 to **n**. You are provided with a list of feasible communication links that can be constructed between specific pairs of stations. Each link has an associated construction cost. The operational guidelines mandate that a designated group of **t** stations—known as critical facilities—must be fully interconnected to share operational data.

Data can be routed through any combination of constructed links. This implies that stations outside the critical group can be utilized as intermediary relays to bridge the critical facilities. Your task is to calculate the absolute minimum total construction cost needed to fulfill this interconnection mandate.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers identifying the critical facilities.
The next **m** lines each provide three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that a communication link can be constructed between station **u** and station **v** for a cost of **w**.
It is guaranteed that it is possible to satisfy the mandate using the provided options.

## Output

Output a single integer representing the minimum total cost to ensure all critical facilities can share operational data.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, using station 4 as an intermediary relay (which costs 1+1+1 = 3) is more cost-effective than linking the three critical facilities directly (which would cost 4). In Example 3, there is only one critical facility, so no links need to be constructed.
