<STATEMENT>
# Problem A — Cabling the Priority Locations

Time limit: 5 s   Memory limit: 256 MB

## Description

A campus infrastructure project involves $n$ sites, numbered 1 through $n$. The project is funded by a grant that supports a maximum of one hundred site installations, capping $n$ at exactly one hundred. 

You have a catalog of $m$ potential bidirectional cabling segments that can be laid between specific pairs of sites. The catalog size $m$ ranges from zero up to the theoretical maximum where every distinct pair of sites has exactly one potential segment. Each segment has a known installation expense $w$, which is a positive integer. The project charter limits the expense of any single segment to exactly one million.

The project mandate requires that a specific subset of $t$ sites, designated as priority locations, must be integrated into a single unified communication framework. These locations correspond to the university's executive directors. The university charter strictly limits the board of directors to ten members, and each member oversees exactly one priority location. Thus, the count of priority locations $t$ is at most ten (though there is always at least one).

To establish this framework, you must select a collection of cabling segments to install such that a continuous physical path exists between any two priority locations. The paths may route through any sequence of installed segments, meaning standard (non-priority) sites can freely act as intermediate junctions to link the priority locations. Determine the absolute minimum total installation expense required to satisfy the mandate.

## Input

The first line provides three integers $n$, $m$, and $t$. All bounds on these values are derived from the project limitations described above.
The second line contains $t$ distinct integers identifying the priority locations.
The next $m$ lines each provide three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$), showing that a cabling segment can be laid between site $u$ and site $v$ for an expense of $w$.
It is guaranteed that it is possible to satisfy the mandate using the provided options.

## Output

Output a single integer representing the minimum total expense to ensure all priority locations are integrated into the unified communication framework.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, using site 4 as an intermediate junction (which costs 1+1+1 = 3) is more cost-effective than linking the three priority locations directly (which would cost 4). In Example 3, there is only one priority location, so no segments need to be installed.
