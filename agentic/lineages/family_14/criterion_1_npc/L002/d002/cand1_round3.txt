<STATEMENT>
# Problem A — Digital Archive Restoration

Time limit: 5 s
Memory limit: 256 MB

## Description
A digital archivist is restoring a collection of historical documents saved in various obsolete file formats. There are $n$ different file formats in total, identified by integers from $1$ to $n$.

A software vendor sells $m$ bidirectional conversion adapters. Each adapter allows converting files back and forth between a specific pair of formats, and requires a one-time purchase price. 

The archivist has identified $t$ specific formats as essential to the restoration project. The goal is to purchase a set of adapters such that a file in any essential format can be converted to any other essential format. Conversions can be chained through multiple adapters. Furthermore, the archivist is allowed to purchase adapters involving non-essential formats, as long as using them as intermediate steps reduces the total purchase price.

Calculate the minimum total purchase price required to ensure that all $t$ essential formats can be converted into one another.

## Input
The first line contains three integers $n$, $m$, and $t$.
The value of $t$ is at least one and at most the number of years in a decade.
The value of $n$ is at least one and at most the square of the maximum possible value of $t$.
The value of $m$ is at least zero and at most the number of ways to choose two distinct items from a set of $n$ items.
The second line contains $t$ distinct integers: the IDs of the essential formats.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$, representing an available adapter between format $u$ and format $v$ ($1 \le u \le n$, $1 \le v \le n$, $u \neq v$) that has a purchase price of $w$. The value of $w$ is at least one and at most one million.
It is guaranteed that purchasing all available adapters would successfully allow conversions among all essential formats.

## Output
Print a single integer: the minimum total purchase price to ensure all essential formats can be converted into one another.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note
In Example 1, chaining conversions through the non-essential format 4 (which costs 1+1+1 = 3) is cheaper than purchasing the adapters that directly convert between the three essential formats (which would cost 4). 
In Example 3, there is only one essential format, so no adapters need to be purchased.

<RATIONALE>
The problem was rewritten to use indirect bounds (Strategy S07). Instead of providing raw numerical limits, the bounds for $t$, $n$, and $m$ are described using logical and physical constants (e.g., "the number of years in a decade" for 10). This forces the model to read and parse the text to extract the constraints, discouraging reliance on purely structural pattern matching based on small integer bounds like $t \le 10$, which previously tipped off the Steiner Tree DP approach. Banned vocabulary like "trivially" was removed.
</RATIONALE>
