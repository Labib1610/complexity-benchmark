<STATEMENT>
# Problem A — Monetary Stabilization

Time limit: 5 s
Memory limit: 256 MB

## Description
A global economic union is attempting to stabilize its markets. There are $n$ distinct currencies in circulation, numbered 1 to $n$.

Financial regulators can establish bilateral pegs between specific pairs of currencies. When a bilateral peg is established between two currencies, their exchange rate is permanently locked. Furthermore, this locking is transitive: if currency A is locked to currency B, and currency B is locked to currency C, then currency A is effectively locked to currency C. 

The union's analysts have identified $m$ potential bilateral pegs that could be established. However, maintaining each peg requires a specific amount of foreign reserves.

There are $t$ currencies designated as "anchor currencies". The union's mandate is to ensure that every anchor currency is locked to every other anchor currency, creating a single unified bloc among them. The regulators may establish pegs involving non-anchor currencies if using them as intermediaries reduces the total reserve requirement.

Write a program to determine the minimum total foreign reserves required to establish a set of bilateral pegs such that all $t$ anchor currencies are locked to one another.

## Input
The first line contains three integers $n$, $m$, and $t$ ($1 \le t \le 10$, $1 \le n \le 100$, $0 \le m \le n(n-1)/2$).
The second line contains $t$ distinct integers: the IDs of the anchor currencies.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$), representing a potential bilateral peg between currency $u$ and currency $v$ that requires $w$ units of foreign reserves.
It is guaranteed that it is possible to lock all anchor currencies together by establishing all available pegs.

## Output
Print a single integer: the minimum total foreign reserves required to ensure all anchor currencies are locked to each other.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note
In Example 1, locking the anchor currencies by pegging them all to the non-anchor currency 4 (requiring 1+1+1 = 3 units of reserves) is cheaper than establishing pegs directly among the three anchor currencies (which would require a minimum of 4 units). 
In Example 3, there is only one anchor currency, so it is trivially locked to itself without requiring any pegs to be established.
