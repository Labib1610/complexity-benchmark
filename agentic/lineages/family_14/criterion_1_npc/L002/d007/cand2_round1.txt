<STATEMENT>
# Problem A — Commutator Kernel

Time limit: 5 s
Memory limit: 256 MB

## Description
Let $\mathcal{H}$ be the vector space of $n \times n$ real diagonal matrices. Let $E_{i,j}$ denote the $n \times n$ matrix with a $1$ at row $i$ and column $j$, and $0$s elsewhere.

You are provided with a pool of $m$ candidate linear maps. Each candidate is defined by a pair of indices $(u, v)$ and represents the commutator map $\mathcal{L}_{u,v} : \mathcal{H} \to \mathbb{R}^{n \times n}$ given by:
$$ \mathcal{L}_{u,v}(D) = D E_{u,v} - E_{u,v} D $$
Activating a specific candidate map incurs a one-time cost $w$.

A specific subset of $t$ indices have been designated as essential indices.

Suppose you activate a subset of the candidate maps. Let $\mathcal{K} \subseteq \mathcal{H}$ be the intersection of the kernels (null spaces) of all activated maps. Your objective is to choose the subset of candidates such that for every diagonal matrix $D \in \mathcal{K}$, and for every pair of essential indices $a$ and $b$, the following condition holds:
$$ \mathrm{Tr}(D E_{a,a}) = \mathrm{Tr}(D E_{b,b}) $$
where $\mathrm{Tr}$ denotes the trace of a matrix.

Write a program to calculate the minimum total cost necessary to ensure this kernel condition is met.

## Input
The first line contains three integers $n$, $m$, and $t$.
The dimension $n$ satisfies $1 \le n \le 100$. The number of candidate maps $m$ satisfies $0 \le m \le n(n-1)/2$. The number of essential indices $t$ satisfies $1 \le t \le 10$.

The second line contains $t$ distinct integers: the essential indices.

Each of the next $m$ lines contains three integers $u$, $v$, and $w$, representing a candidate map $\mathcal{L}_{u,v}$ that requires a cost of $w$. The integers $u$ and $v$ identify the indices involved ($1 \le u \le n$, $1 \le v \le n$, $u \neq v$). The cost $w$ satisfies $1 \le w \le 1000000$.

It is guaranteed that the available candidate maps are sufficient to ensure the condition can be met.

## Output
Print a single integer: the minimum total cost to ensure the target kernel condition is met.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

Replaced the "covector span" framing with a "commutator kernel" framing over diagonal matrices, and removed the explanatory note that explicitly demonstrated transitivity. The new framing forces the model to symbolically evaluate the commutator $D E_{u,v} - E_{u,v} D = 0$ to discover it enforces $D_{u,u} = D_{v,v}$, and then independently recognize that guaranteeing this equality across all essential indices is equivalent to finding a minimum-cost connecting subgraph (Steiner Tree).
</RATIONALE>
<PRESERVED_ANSWER>
The condition $D \in \mathcal{K} \implies D_{a,a} = D_{b,b}$ is mathematically identical to the previous span condition, enforcing that activated pairs transitively connect all essential indices, so the minimum cost subset is exactly the same for all inputs.
</PRESERVED_ANSWER>
