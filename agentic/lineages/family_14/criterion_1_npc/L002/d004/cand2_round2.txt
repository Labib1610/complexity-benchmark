<METHOD_NAME>Algebraic Vector Space Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Transforms the graph connectivity requirement into a linear algebra requirement by representing edges as difference vectors of standard basis vectors. The condition that a set of edges connects a set of vertices is mathematically equivalent to the condition that the corresponding difference vectors span the difference vectors of the target vertices. This removes all graph-theoretic language and forces the model to recognize the equivalence between vector spanning and graph connectivity.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Subspace Spanning

Time limit: 5 s
Memory limit: 256 MB

## Description
Consider an $n$-dimensional vector space with a standard basis $e_1, e_2, \dots, e_n$.
You are offered $m$ difference vectors, each of the form $e_u - e_v$ for some basis vectors $e_u$ and $e_v$. Acquiring a specific difference vector incurs a one-time cost. 

A specific subset of $t$ indices have been designated as target indices. Your objective is to select a set of difference vectors to acquire such that for any two target indices $a$ and $b$, the vector $e_a - e_b$ lies within the linear span of the acquired set. You are permitted to acquire difference vectors that involve non-target indices; if utilizing them as intermediate basis components reduces the overall cost, it is a valid strategy.

Write a program to calculate the minimum total cost necessary to ensure all required vectors $e_a - e_b$ are in the span of the acquired set.

## Input
The first line contains three integers $n$, $m$, and $t$.
The number of dimensions $n$ satisfies $1 \le n \le 100$. The number of available vectors $m$ satisfies $0 \le m \le n(n-1)/2$. The number of target indices $t$ satisfies $1 \le t \le 10$.

The second line contains $t$ distinct integers: the target indices.

Each of the next $m$ lines contains three integers $u$, $v$, and $w$, representing an available difference vector $e_u - e_v$ that requires a cost of $w$. The integers $u$ and $v$ identify the two distinct dimensions involved ($1 \le u \le n$, $1 \le v \le n$, $u \neq v$). The cost $w$ satisfies $1 \le w \le 1000000$.

It is guaranteed that the available vectors are sufficient to ensure the target condition can be met.

## Output
Print a single integer: the minimum total cost to ensure the target condition is met.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note
In Example 1, acquiring the vectors $e_1 - e_4$, $e_2 - e_4$, and $e_3 - e_4$ (which requires a cost of 1+1+1 = 3) allows $e_1 - e_2$, $e_2 - e_3$, and $e_1 - e_3$ to be formed via linear combinations. This is more cost-effective than acquiring vectors that only involve the three target indices directly (which would require a cost of 4). 
In Example 3, with only one target index, there are no target pairs that require acquiring any vector, so the minimum cost is 0.
</STATEMENT>
<RATIONALE>
The problem was completely reframed from graph connectivity (database synchronization) to a linear algebra context (vector subspace spanning). The target condition of connecting all primary ledgers is directly equivalent to requiring the difference vectors of all target indices to be in the linear span of the chosen basis differences. This forces models to bridge the gap between linear algebra and graph theory, preventing them from blindly applying standard graph algorithms without deeper reasoning.
</RATIONALE>
<PRESERVED_ANSWER>
The linear span of a set of difference vectors $e_u - e_v$ contains $e_a - e_b$ if and only if indices $a$ and $b$ are in the same connected component of the graph formed by edges $(u, v)$, meaning the mathematical optimization is completely identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the exact same Steiner Tree optimization problem on an undirected graph, maintaining its NP-complete complexity.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the underlying field of the vector space, but since difference vectors form a totally unimodular matrix, the span over the reals is equivalent to the span over any field, leaving no actual ambiguity in the target condition.
</RISK>
