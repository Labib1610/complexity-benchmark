<METHOD_NAME>Dual Null Space Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Transforms the linear span condition into its orthogonal complement (null space) equivalent. Instead of requiring target difference vectors to be in the span of the selected vectors, it requires that any vector orthogonal to the selected vectors has equal coordinates at the target dimensions. This forces the model to deduce the equivalence to graph connectivity from first principles of linear algebra, breaking surface-level associations with paths and spanning trees.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<STATEMENT>
# Problem A — Null Space Constraints

Time limit: 5 s
Memory limit: 256 MB

## Description
Consider an $n$-dimensional Euclidean space $\mathbb{R}^n$ with the standard basis $e_1, e_2, \dots, e_n$.
You are provided with $m$ potential constraint vectors. Each constraint vector has the form $e_u - e_v$ for some distinct basis vectors $e_u$ and $e_v$, and requires a specific one-time cost to activate.

When you activate a subset of these constraint vectors, they define a null space $V$. This null space $V$ is the subspace consisting of all vectors $x \in \mathbb{R}^n$ that are orthogonal to every activated constraint vector (i.e., the dot product $x \cdot v = 0$ for all activated vectors $v$).

A specific subset of $t$ dimensions has been designated as target dimensions. Your objective is to activate a subset of constraint vectors with the minimum total cost such that the resulting null space $V$ satisfies the following property: for every vector $x \in V$, its coordinates at all target dimensions are equal (i.e., $x_a = x_b$ for any target dimensions $a$ and $b$). 

Write a program to calculate the minimum total cost necessary to ensure this property holds for the target dimensions.

## Input
The first line contains three integers $n$, $m$, and $t$.
The number of dimensions $n$ satisfies $1 \le n \le 100$. The number of available constraint vectors $m$ satisfies $0 \le m \le n(n-1)/2$. The number of target dimensions $t$ satisfies $1 \le t \le 10$.

The second line contains $t$ distinct integers: the target dimensions.

Each of the next $m$ lines contains three integers $u$, $v$, and $w$, representing an available constraint vector $e_u - e_v$ that requires a cost of $w$. The integers $u$ and $v$ identify the two distinct dimensions involved ($1 \le u \le n$, $1 \le v \le n$, $u \neq v$). The cost $w$ satisfies $1 \le w \le 1000000$.

It is guaranteed that activating all available constraint vectors is sufficient to ensure the target property can be met.

## Output
Print a single integer: the minimum total cost to ensure the target condition is met.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note
In Example 1, activating the constraint vectors $e_1 - e_4$, $e_2 - e_4$, and $e_3 - e_4$ requires a total cost of $1+1+1 = 3$. For any vector $x \in \mathbb{R}^4$ orthogonal to these three activated vectors, it must be true that $x \cdot (e_1 - e_4) = 0$, $x \cdot (e_2 - e_4) = 0$, and $x \cdot (e_3 - e_4) = 0$. This implies $x_1 = x_4$, $x_2 = x_4$, and $x_3 = x_4$. Consequently, $x_1 = x_2 = x_3$, fulfilling the requirement for the target dimensions 1, 2, and 3. Activating constraint vectors that only involve the target dimensions directly would incur a higher cost of 4.

In Example 3, with only one target dimension, the condition that all target dimensions share the same coordinate is vacuously true for any vector $x$. Thus, no constraint vectors need to be activated and the minimum cost is 0.
</STATEMENT>
<RATIONALE>
The explicit affordance telling the models they could use non-target dimensions as intermediates was removed. Furthermore, the problem was dualized from requiring vectors to be in the linear span of the acquired set, to requiring that the orthogonal complement (null space) of the acquired set forces equality across all target coordinates. This requires the model to independently deduce that $x \cdot (e_u - e_v) = 0 \iff x_u = x_v$, and that forcing equality across a subset of variables via pairwise equalizations is equivalent to connecting them in a graph.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that every vector orthogonal to the selected set satisfies $x_a = x_b$ is mathematically identical to the original condition that $e_a - e_b$ lies in the linear span of the selected set, ensuring all valid subsets of vectors and their costs remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the Minimum Steiner Tree problem on a graph, as the logical requirement is still to find a minimum-cost set of edges that connects all target vertices into a single component.
</PRESERVED_CLASS>
