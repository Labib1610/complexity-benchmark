**Solution Explanation**

For a subset `Y ⊆ {1,…,n}` let  

*`Y` splits `T`* ⇔ `Y∩T` is non‑empty and not equal to `T`.

`Y` also splits a pair `{u,v}` ⇔ exactly one of `u , v` belongs to `Y`.

--------------------------------------------------------------------

#### 1.   What does the requirement really mean ?

Take any `Y` that splits `T` and look at the part of `Y` that lies inside `T`

```
X = Y ∩ T          (  ∅ ⊂ X ⊂ T )
```

`Y` may contain arbitrary elements outside `T`.  
If a selected pair `{a,b}` has one endpoint in `X` and the other endpoint **outside**
`T`, `Y` could simply also contain that outside endpoint – then the pair would **not**
be split.  
Therefore a pair that is guaranteed to be split for **every** possible `Y`
must have its two endpoints **both inside `T`**, one in `X` and the other in `T\X`.

Consequences  

* only pairs whose both ends belong to `T` can be useful,
* for every non‑empty proper subset `X ⊂ T` we need at least one selected pair
  with one end in `X` and the other in `T\X`.

--------------------------------------------------------------------

#### 2.   Graph interpretation

Consider the graph `G` whose vertices are the elements of `T` and whose edges are
the given pairs whose both ends lie in `T` (with their costs).

The condition from the previous paragraph is exactly the definition of a
*connected* graph: a graph is connected iff for every cut `(X , T\X)` (`∅≠X≠T`)
there is an edge crossing the cut.

Hence we have to choose a set of edges that makes `T` connected
and whose total cost is minimum – **the Minimum Spanning Tree (MST) problem**
on at most `10` vertices.

If `|T| = 1` there is no non‑trivial split, the answer is `0`.

--------------------------------------------------------------------

#### 3.   Algorithm
```
if t == 1: answer = 0
else:
    collect all edges (u,v,w) with u∈T and v∈T
    run Kruskal's algorithm (or Prim) on these edges
    answer = total weight of the MST
```
`n ≤ 100`, `t ≤ 10`, `m ≤ 4950`; Kruskal with sorting (`O(m log m)`) is trivial.

The statement guarantees that the edges are sufficient, i.e. the MST exists.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm outputs the minimum possible total cost.

---

##### Lemma 1  
Any feasible set `S` of activated pairs must contain only pairs whose both
endpoints are in `T`.

**Proof.**  
Assume `S` contains a pair `{a,b}` with `a∈T`, `b∉T`.  
Take `Y = {a}` (plus any subset of elements outside `T` that does **not** contain `b`).
`Y` splits `T` because it contains `a` but not the other elements of `T`.  
`Y` does **not** split `{a,b}` because it contains `a` and not `b`.  
Thus the condition is violated. ∎



##### Lemma 2  
A set `S` of pairs (all inside `T`) satisfies the problem condition
iff the graph formed by `S` on vertex set `T` is connected.

**Proof.**  

*If part.*  
Assume the graph is connected. For any non‑empty proper `X⊂T` there exists an
edge `{u,v}` of the graph with `u∈X`, `v∈T\X` (definition of connectivity).
For any `Y` with `Y∩T = X`, that edge is split because exactly one of its ends
lies in `Y`. Hence the condition holds.

*Only‑if part.*  
Suppose the graph is **not** connected; let `C` be a connected component,
`∅≠C≠T`. Choose `Y = C`. Then `Y` splits `T` (contains some but not all of `T`),
but every edge of `S` has both ends either inside `C` or both outside `C`,
so none is split – contradiction. ∎



##### Lemma 3  
Among all feasible sets, the one with minimum total cost is a minimum spanning
tree of the graph consisting of all admissible edges (edges inside `T`).

**Proof.**  
By Lemma&nbsp;2 any feasible set must make `T` connected, therefore it contains a
spanning connected subgraph. Removing edges while keeping connectivity never
increases the cost, so there exists an optimal feasible set that is a spanning
tree. Conversely, any spanning tree is feasible (Lemma&nbsp;2). Hence the
optimal feasible set is exactly a minimum‑cost spanning tree. ∎



##### Lemma 4  
Kruskal’s algorithm returns a minimum spanning tree of the admissible edges.

**Proof.**  
Standard property of Kruskal’s algorithm. ∎



##### Theorem  
The algorithm outputs the minimum possible total activation cost.

**Proof.**  

*If `t = 1`* the answer `0` is correct because no split of `T` exists.

*If `t ≥ 2`* the algorithm builds the set of admissible edges, runs Kruskal and
outputs the weight of the obtained tree.
By Lemma&nbsp;4 this weight equals the cost of a minimum spanning tree.
By Lemma&nbsp;3 any feasible solution has cost at least that of a minimum
spanning tree, and a minimum spanning tree itself is feasible.
Therefore the algorithm’s output is both achievable and optimal. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Filtering edges*: `O(m)`  
*Sorting for Kruskal*: `O(m log m)` ( `m ≤ 4950` )  
*Union‑Find operations*: `O(m α(t))` (inverse Ackermann, negligible)

Memory consumption: `O(m)` for the edge list, `O(t)` for DSU – well within limits.

#### 6.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))
    T = set(int(next(it)) for _ in range(t))
    edges = []
    for _ in range(m):
        u = int(next(it)); v = int(next(it)); w = int(next(it))
        if u in T and v in T:
            edges.append((w, u, v))
    if t <= 1:
        print(0)
        return

    # Kruskal
    edges.sort()
    parent = {x: x for x in T}
    rank = {x: 0 for x in T}

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    def union(a, b):
        ra, rb = find(a), find(b)
        if ra == rb:
            return False
        if rank[ra] < rank[rb]:
            parent[ra] = rb
        elif rank[ra] > rank[rb]:
            parent[rb] = ra
        else:
            parent[rb] = ra
            rank[ra] += 1
        return True

    total = 0
    edges_used = 0
    for w, u, v in edges:
        if union(u, v):
            total += w
            edges_used += 1
            if edges_used == t - 1:
                break

    print(total)

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
