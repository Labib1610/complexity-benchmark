<STATEMENT>
# Problem A — Quantum State Orbit

Time limit: 5 s
Memory limit: 256 MB

## Description
A quantum state mixer operates on a register of $n$ qubits, indexed from $1$ to $n$. A specific subset of $t$ qubits are designated as *target qubits*, representing a logical entangled state.

You are provided with a catalog of $m$ available *exchange gates*. Each exchange gate is a mathematical transposition: when applied, it swaps the states of two specific qubits, $u$ and $v$, leaving all other qubits unchanged. Activating an exchange gate for use in the mixer incurs a one-time calibration cost $w$.

Once activated, the selected gates can be applied in any sequence and any number of times. Mathematically, the chosen gates form a generating set $S$ for a permutation group $G = \langle S \rangle$ acting on the $n$ qubits. This group action partitions the qubits into disjoint orbits. Two qubits $x$ and $y$ belong to the same orbit if and only if there exists at least one permutation $g \in G$ such that $g(x) = y$.

Your objective is to activate a subset of gates such that all $t$ target qubits are contained within a single orbit of $G$.

Write a program to calculate the minimum total calibration cost required to ensure this condition is met.

## Input
The first line contains three integers $n$, $m$, and $t$.
The number of qubits $n$ is a positive integer limited by the motherboard capacity of exactly one hundred slots.
The number of available exchange gates $m$ is a non-negative integer bounded by the theoretical maximum of one gate for every distinct pair of qubits.
The number of target qubits $t$ is a positive integer that cannot exceed the ten dedicated cryptographic coprocessors available in the hardware.

The second line contains $t$ distinct integers: the indices of the target qubits.

Each of the next $m$ lines contains three integers $u$, $v$, and $w$. This represents an available exchange gate that swaps qubits $u$ and $v$ (where $u$ and $v$ are distinct positive integers up to $n$). The calibration cost $w$ is a positive integer capped by a strict budget limit of one million micro-credits.

It is guaranteed that the available exchange gates are sufficient to ensure all target qubits can be placed in the same orbit.

## Output
Print a single integer: the minimum total calibration cost to ensure the target condition is met.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note
In Example 1, the target qubits are 1, 2, and 3.
If we activate the exchange gates for (1, 4), (2, 4), and (3, 4), these three transpositions form our generating set $S$.
The group $G = \langle S \rangle$ acts on the 4 qubits. Applying the sequence of gates (1, 4) then (2, 4) then (1, 4) produces the permutation that swaps 1 and 2, while leaving 3 and 4 unchanged. Through such compositions, any qubit in the system can be mapped to any other qubit.
Therefore, the entire set of 4 qubits forms a single orbit under $G$. Since the target qubits (1, 2, and 3) are all within this single orbit, the condition is met.
The total cost is 1 + 1 + 1 = 3. Activating gates strictly among the target qubits (e.g., (1, 2) and (2, 3)) would cost 2 + 2 = 4, which is suboptimal.

In Example 3, with only 1 target qubit, the single target trivially belongs to its own orbit even if no exchange gates are activated (the generating set is empty, $G$ is the trivial group, and every qubit is in a singleton orbit). Thus, a cost of 0 is sufficient.
