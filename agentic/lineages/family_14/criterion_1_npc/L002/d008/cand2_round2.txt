<METHOD_NAME>
Permutation Group Orbit Disguise
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the geometric orthogonal complement of incidence vectors with the equivalent algebraic condition of orbits under a permutation group generated by transpositions. Two elements are in the same orbit if and only if they are in the same connected component of the graph where the transpositions are edges. This preserves the minimum-cost Steiner tree structure exactly, while forcing models to reason about group actions rather than graph connectivity or spatial vectors.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<STATEMENT>
# Problem A — Orbital Synchronization

Time limit: 5 s
Memory limit: 256 MB

## Description
Consider a set of $n$ distinct elements labeled $1$ through $n$. A specific subset of $t$ elements are designated as primary elements.

You are provided with a pool of $m$ available transpositions. Each transposition is specified by a pair of distinct elements $(u, v)$, representing the operation that swaps $u$ and $v$ while leaving all other elements fixed. Activating a specific transposition from the pool incurs a one-time cost $w$.

Your objective is to activate a subset of the available transpositions to form a generating set $S$. Let $G$ be the permutation group generated by $S$. The group $G$ acts naturally on the set of $n$ elements. You must ensure that all $t$ primary elements belong to the exact same orbit under the action of $G$. Recall that the orbit of an element $a$ under $G$ is the set $\{g(a) \mid g \in G\}$.

Write a program to calculate the minimum total cost necessary to ensure this condition is met.

## Input
The first line contains three integers $n$, $m$, and $t$.
The number of elements $n$ satisfies $1 \le n \le 100$. The number of available transpositions $m$ satisfies $0 \le m \le n(n-1)/2$. The number of primary elements $t$ satisfies $1 \le t \le 10$.

The second line contains $t$ distinct integers: the labels of the primary elements.

Each of the next $m$ lines contains three integers $u$, $v$, and $w$, representing a transposition that swaps elements $u$ and $v$, which requires an activation cost of $w$. The integers $u$ and $v$ identify the two distinct elements involved ($1 \le u \le n$, $1 \le v \le n$, $u \neq v$). The cost $w$ satisfies $1 \le w \le 1000000$.

It is guaranteed that the available transpositions are sufficient to ensure the condition can be met.

## Output
Print a single integer: the minimum total cost to ensure the target condition is met.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note
In Example 1, the primary elements are 1, 2, and 3.
If we activate the transpositions $(1, 4)$, $(2, 4)$, and $(3, 4)$, the set $S$ contains three transpositions.
The group $G$ generated by $S$ contains permutations that can map any of the elements 1, 2, 3, and 4 to any other.
Thus, all four elements are in the same orbit, meaning the primary elements 1, 2, and 3 belong to the same orbit.
The cost of this selection is $1+1+1=3$. This is more cost-effective than activating the transpositions defined solely on the primary elements, which would cost at least 4.

In Example 3, with only one primary element, there are no pairs of distinct primary elements to synchronize. The condition that all primary elements belong to the same orbit is vacuously satisfied even if $S$ is empty (where the orbit of 1 is just $\{1\}$). Thus, no transpositions need to be activated, resulting in a minimum cost of 0.
</STATEMENT>
<RATIONALE>
The problem is reframed from orthogonal complements of incidence vectors to the orbits of a permutation group generated by transpositions. Models that rely on recognizing vector orthogonality as a graph connectivity problem will fail, while models that can reason through the algebraic definition (that elements are in the same orbit exactly when they are connected by a sequence of the chosen transpositions) will recover the underlying Steiner tree structure.
</RATIONALE>
<PRESERVED_ANSWER>
Two elements are in the same orbit of a group generated by transpositions if and only if they are in the same connected component of the graph formed by those transpositions, making the objective mathematically identical to the seed's connectivity requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Steiner Tree problem in disguise, preserving its NP-complete status and allowing the same exact subset-DP algorithm to solve it.
</PRESERVED_CLASS>

Some readers might overcomplicate the group action aspect, but the definition of an orbit is standard and unambiguous, clearly mapping to the connected components of the underlying elements.
