# Problem A — Synchronization Backbone

Time limit: 5 s
Memory limit: 256 MB

## Description
A regional energy provider is upgrading its grid management system. The grid consists of $n$ power substations (numbered starting from 1). The number of substations is constrained by the legacy address space, which supports anywhere from a minimum of 1 up to a maximum of 100 substations.

Field engineers have identified $m$ viable underground conduits where fiber-optic links can be installed. Depending on the terrain, the number of conduits $m$ could be as few as 0, or as many as $n(n-1)/2$ if a conduit exists between every possible pair of substations.

Among the substations, a specific count of $t$ have been designated as synchronization hubs. The number of hubs corresponds to the number of regional directors. Because there is always at least 1 director and the executive boardroom only accommodates up to 10 directors, $t$ is restricted to this range.

Your task is to design a unified communication backbone that ensures all $t$ synchronization hubs can exchange data with one another. This means they must all be part of the same interconnected network. Messages can be routed through any sequence of installed fiber links, and you may utilize any of the non-hub substations as passive relays if it reduces the overall expense. 

For any conduit between distinct substations $u$ and $v$ (where both are between 1 and $n$, and $u \neq v$), the engineers have assessed an exact installation expense $w$. The minimum base price for any installation is 1, and the finance committee has capped the maximum budget per conduit at 1000000. 

You must calculate the minimum possible total expense required to achieve this connectivity among the synchronization hubs.

## Input
The first line contains three integers $n$, $m$, and $t$.
The second line contains $t$ distinct integers: the IDs of the synchronization hubs.
Each of the next $m$ lines contains three integers $u$, $v$, and $w$, representing a viable conduit between substation $u$ and substation $v$ with an installation expense of $w$.
It is guaranteed that the surveyed conduits are sufficient to connect all synchronization hubs.

## Output
Print a single integer: the minimum total expense to ensure all synchronization hubs are connected.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note
In Example 1, routing the connection through the passive relay substation 4 (which costs 1+1+1 = 3) is cheaper than linking the three synchronization hubs directly to each other (which would cost 4). 
In Example 3, there is only one synchronization hub, so no conduits need to be installed.
