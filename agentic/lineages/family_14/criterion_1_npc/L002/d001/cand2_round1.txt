<STATEMENT>
# Problem A — Grid Management Upgrade

Time limit: 5 s
Memory limit: 256 MB

## Description
A regional energy provider is modernizing its communication infrastructure. The territory contains several power substations. A subset of these substations serve as central dispatch hubs. To synchronize operations, all the central dispatch hubs must be linked together into a single continuous network.

Field engineers have surveyed the territory and identified specific corridors where fiber-optic cables can be installed between pairs of substations. They have also determined the exact installation expense for each viable corridor.

Your task is to select a set of corridors to install such that every central dispatch hub can exchange messages with every other central dispatch hub. A message can travel through any sequence of installed fiber corridors. You are allowed to route connections through substations that are not central dispatch hubs; these simply act as passive relays if it reduces the overall expense.

Determine the minimum possible total installation expense required to achieve full connectivity among all central dispatch hubs.

## Input
The first line contains three integers $n$, $m$, and $t$.
- $n$ is the total number of substations. Substation IDs are assigned sequentially starting from 1. The legacy telemetry system has a strict hardware limit: it can handle a maximum of 100 unique substation addresses. There is always at least one substation.
- $m$ is the number of surveyed corridors.
- $t$ is the number of central dispatch hubs. Each central dispatch hub requires a dedicated physical console at headquarters. The headquarters room has space for exactly 10 consoles, which serves as the upper limit. Since the system must be operational, at least one console is always in use.

The second line contains $t$ distinct integers: the IDs of the central dispatch hubs.
Each of the following $m$ lines contains three integers $u$, $v$, and $w$, describing a surveyed corridor between substation $u$ and substation $v$ with an installation expense of $w$.
- The IDs $u$ and $v$ are distinct substations.
- There is at most one surveyed corridor between any specific pair of substations, meaning the count of corridors $m$ ranges from none up to the theoretical maximum for $n$ substations.
- The installation expense $w$ is measured in whole dollars. It is always at least 1, and restricted by a maximum single-corridor budget cap of 1,000,000.

It is guaranteed that the surveyed corridors provide a way to connect all central dispatch hubs.

## Output
Print a single integer: the minimum total expense to ensure all central dispatch hubs are connected.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note
In Example 1, routing the fiber through the passive relay substation 4 (which costs 1+1+1 = 3) is cheaper than linking the three central dispatch hubs directly to each other (which would cost 4). 
In Example 3, there is only one central dispatch hub, so no fiber links need to be installed.

<RATIONALE>
Removed explicit inequality constraints (e.g. `1 <= t <= 10`) and instead integrated the numeric bounds into the scenario's physical and hardware limitations (e.g. a limit of 10 consoles). This prevents models from simply pattern-matching the small $t$ bound to trigger a $O(3^t)$ DP, forcing them to read and reason about the text to deduce that the terminal set is small enough to permit exponential-time subset merging.
</RATIONALE>

</PRESERVED_ANSWER>
