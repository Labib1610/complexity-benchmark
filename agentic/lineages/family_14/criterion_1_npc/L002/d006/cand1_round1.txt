<METHOD_NAME>Commutative Ideal Membership Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Transforms a Steiner Tree graph connectivity problem into a problem of ideal membership in a commutative ring. Edges become binomial generators of the form x_u - x_v, and graph connectivity is recast as requiring the differences between critical variables to be within the generated ideal. This forces models to reason about abstract algebraic structures and prevents surface-level pattern-matching to graph algorithms, as the linear equations are hidden behind ideal generation.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<STATEMENT>
# Problem A — Ideal Subsets

Time limit: 5 s
Memory limit: 256 MB

## Description
Consider the commutative ring $R = \mathbb{R}[x_1, x_2, \dots, x_n]$ over the real numbers.
You are given a menu of $m$ potential generators. Each generator is a binomial of the form $x_u - x_v$, and adding it to your generating set incurs a one-time cost $w$.

You are also given a set of $t$ critical variables.
Your task is to select a subset of the available generators to form a generating set for an ideal $I \subseteq R$. The ideal $I$ must satisfy a specific membership condition: for every pair of critical variables $x_a$ and $x_b$, the binomial $x_a - x_b$ must be an element of $I$.

Determine the minimum total cost of generators you need to select such that this ideal membership condition is satisfied.

## Input
The first line contains three integers $n$, $m$, and $t$.
The number of variables $n$ is a positive integer bounded by the number of years in a century.
The number of available generators $m$ is a non-negative integer bounded by the maximum possible number of unique pairs of these variables.
The number of critical variables $t$ is a positive integer bounded by the number of years in a decade.

The second line contains $t$ distinct integers representing the indices of the critical variables.

Each of the following $m$ lines contains three integers $u$, $v$, and $w$. This indicates that a generator $x_u - x_v$ is available for a cost of $w$.
The indices $u$ and $v$ identify the two distinct variables involved ($1 \le u \le n$, $1 \le v \le n$, $u \neq v$).
The cost $w$ is a positive integer bounded by the number of millimeters in a kilometer.

It is guaranteed that selecting all available generators would satisfy the ideal membership condition.

## Output
Print a single integer: the minimum total cost to satisfy the condition.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note
In Example 1, selecting the generators $x_1 - x_4$, $x_2 - x_4$, and $x_3 - x_4$ incurs a cost of $1+1+1=3$. The ideal they generate, $I = \langle x_1 - x_4, x_2 - x_4, x_3 - x_4 \rangle$, contains $x_1 - x_2$ because $x_1 - x_2 = (x_1 - x_4) - (x_2 - x_4)$. Similarly, $x_2 - x_3$ and $x_1 - x_3$ are also elements of $I$. Thus, for every pair formed from the critical variables $x_1, x_2$, and $x_3$, their binomial difference is an element of $I$. This is more cost-effective than selecting generators defined solely on the critical variables, which would cost at least 4.

In Example 3, with only one critical variable ($x_1$), there are no pairs of distinct critical variables. The membership condition is vacuously satisfied by the zero ideal (selecting no generators), resulting in a minimum cost of 0.
</STATEMENT>
<RATIONALE>
I completely changed the framing from functional kernels (which trivially translates to unconstrained systems of linear equations and thus graph connectivity) to ideal membership in a commutative ring. By requiring $x_a - x_b$ to be in the ideal generated by a subset of binomials, the mathematical condition remains exactly equivalent to graph connectivity, but it uses terminology from commutative algebra. This forces models to reason through the algebraic definition of an ideal rather than immediately parsing the input as undirected graph edges. I also applied Strategy S07 to state all numeric bounds indirectly.
</RATIONALE>
<PRESERVED_ANSWER>
Because the generators $x_u - x_v$ and targets $x_a - x_b$ are homogeneous of degree 1, $x_a - x_b \in I$ if and only if it is in the real linear span of the generators, which exactly corresponds to $a$ and $b$ being in the same connected component of the chosen subset.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Steiner Tree problem on a graph, and the bounds permit the standard fixed-parameter tractable dynamic programming solution.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret 'ideal' and attempt to use full polynomial combinations (e.g., Gröbner bases) rather than realizing the degree-1 homogeneity restricts it to simple linear combinations and graph connectivity.
</RISK>
