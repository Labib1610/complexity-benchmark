<STATEMENT>
# Problem A — Clearing House Synchronization

Time limit: 5 s
Memory limit: 256 MB

## Description

You are designing a centralized clearing system for **n** financial accounts, numbered 1 to **n**. The system allows you to establish bilateral settlement channels between specific pairs of accounts. There are **m** possible channels you can establish. Establishing a channel between account **u** and account **v** incurs a one-time setup cost of **w**. Channels are symmetric and can process transfers in either direction.

A new regulatory policy requires that a designated group of **t** *target accounts* must be fully integrated into a synchronized clearing cluster. You may include any number of other non-target accounts to act as intermediaries if it helps reduce the overall setup cost.

Specifically, you must select a subset of accounts **S** and a specific set of channels **C** between accounts in **S** to establish. Your selection is valid if and only if it satisfies all of the following regulatory rules:
1. **Target Inclusion:** **S** must contain all **t** target accounts.
2. **Universal Liquidity:** The channels in **C** must completely integrate **S**. Formally, for any hypothetical scenario where each account in **S** is assigned an arbitrary initial surplus or deficit (provided the net sum across all accounts in **S** is exactly zero), it must be mathematically possible to resolve all accounts to a zero balance by routing funds exclusively through the established channels in **C**.
3. **Minimal Overhead:** To prevent redundant settlement cycles, the number of established channels in **C** must be exactly one less than the total number of accounts in **S** (i.e., $|C| = |S| - 1$).
4. **Intermediary Justification:** Every non-target account included in **S** must act as a true intermediary. Therefore, any non-target account in **S** must be directly involved in at least two established channels within **C**.

Your task is to find a valid selection of **S** and **C** that satisfies all regulatory rules while keeping the total setup cost of the established channels in **C** to the absolute minimum.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **t** ≤ 10, 1 ≤ **n** ≤ 100, 0 ≤ **m** ≤ **n**·(**n**−1)/2).  
The second line lists **t** distinct integers representing the identifiers of the target accounts.  
Following this, there are **m** lines. Each line provides three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000), indicating that a settlement channel can be established between account **u** and account **v** for a setup cost of **w**.  
It is guaranteed that the available channels provide at least one valid way to satisfy the policy for all target accounts.

## Output

Output a single integer representing the minimum possible total setup cost required to satisfy the regulatory policy.

## Note

In Example 1, establishing the channels between account 4 and accounts 1, 2, and 3 requires a total setup cost of 1 + 1 + 1 = 3. We select **S** = {1, 2, 3, 4} and **C** containing those three channels. This satisfies all regulatory rules:
1. **Target Inclusion:** **S** contains all 3 target accounts (1, 2, and 3).
2. **Universal Liquidity:** The channels completely integrate **S**. Any zero-sum distribution of surpluses and deficits among the four accounts can be resolved by routing funds through account 4.
3. **Minimal Overhead:** The number of channels in **C** is 3, which is exactly $|S| - 1$ (4 - 1).
4. **Intermediary Justification:** The only non-target account in **S** is 4, which is involved in 3 channels, satisfying the requirement of being involved in at least 2.

Utilizing account 4 is more cost-effective than establishing channels exclusively among the target accounts, which would incur a cost of at least 4.

In Example 3, only one account is designated as a target. We select **S** = {1} and **C** as an empty set of channels. 
1. **Target Inclusion:** **S** contains the 1 target account.
2. **Universal Liquidity:** **S** is completely integrated because any zero-sum assignment on a single account must be exactly zero, which is already naturally resolved.
3. **Minimal Overhead:** The number of channels is 0, which is exactly $|S| - 1$ (1 - 1).
4. **Intermediary Justification:** There are no non-target accounts in **S**, so this rule is vacuously satisfied.

Thus, zero channels need to be established, resulting in a cost of 0.

<RATIONALE>
I completely replaced the textbook definition of a connected graph (partitioning into two disjoint sets bridged by a constraint) with a mathematically equivalent network-flow condition: the ability to resolve any arbitrary zero-sum distribution of balances. This forces models to reason from first principles about what kind of structure permits universal zero-sum routing, breaking their Steiner Tree pattern-matching and likely causing them to misclassify the problem as a flow or matching task. I also directly restored the exact numeric bounds and input contract format to satisfy strict checking.
</RATIONALE>
<PRESERVED_ANSWER>
The "Universal Liquidity" condition is mathematically equivalent to the graph $(S, C)$ being connected; combined with $|C| = |S| - 1$, this still perfectly defines a tree spanning the target accounts, keeping the optimal subset and cost identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Steiner Tree problem on an undirected graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models or readers might initially misinterpret "routing funds" as requiring a directed graph, but the explicit statement that "Channels are symmetric and can process transfers in either direction" completely resolves this ambiguity.
</RISK>
