# Problem A — Subspace Synchronization

Time limit: 5 s
Memory limit: 256 MB

## Description

You are analyzing a system of **n** state variables. You can enforce symmetric bidirectional couplings between specific pairs of variables. There are **m** possible couplings available. Enforcing a coupling between variable **u** and variable **v** incurs a one-time energy cost of **w**.

A new operational directive requires that a designated group of **t** *essential* variables must be fully synchronized. You may include other non-essential variables to act as intermediaries if it reduces the total cost.

To comply with system architecture limits, the parameters are strictly bounded. The number of essential variables **t** is at least 1 and at most the sum of the first four positive integers. The total number of variables **n** is at least 1 and at most the square of this upper bound on **t**. The number of available couplings **m** is at least 0 and can be up to the maximum number of unique pairs among **n** variables. The cost **w** for any single coupling is at least 1 and will not exceed the cube of the maximum possible value of **n**.

You must select a subset of variables **S** and a specific set of couplings **C** between variables in **S**. To determine if your selection is valid, construct an incidence matrix **M** with $|S|$ rows (one for each variable in **S**) and $|C|$ columns (one for each coupling in **C**). For each coupling connecting variable **x** and variable **y**, assign it an arbitrary orientation (e.g., **x** $\to$ **y**) and place a $1$ in the row for **x**, a $-1$ in the row for **y**, and $0$ in all other rows of that column.

Your selection is valid if and only if it satisfies all of the following algebraic conditions:
1. **Essential Inclusion:** The subset **S** must contain all **t** essential variables.
2. **Subspace Unification:** The rank of the matrix **M** over the real numbers must be exactly $|S| - 1$.
3. **Dimensional Minimality:** The number of columns in **M** must be exactly one less than the number of rows (i.e., $|C| = |S| - 1$).
4. **Intermediary Non-Triviality:** For every row in **M** that corresponds to a non-essential variable, the $L_0$ norm of that row (the number of non-zero entries) must be at least 2.

Your task is to find a valid selection of **S** and **C** that satisfies all conditions while keeping the total energy cost of the enforced couplings in **C** to the absolute minimum.

## Input

The first line provides three integers **n**, **m**, and **t**.  
The second line lists **t** distinct integers representing the identifiers of the essential variables (from 1 to **n**).  
Following this, there are **m** lines. Each line provides three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**), indicating that a coupling can be enforced between variable **u** and variable **v** for a cost of **w**.  
It is guaranteed that the available couplings provide at least one valid way to satisfy the conditions for all essential variables.

## Output

Output a single integer representing the minimum possible total energy cost required to satisfy the operational directive.

```

```

## Note

In Example 1, enforcing the couplings between variable 4 and variables 1, 2, and 3 requires a total cost of 1 + 1 + 1 = 3. We select **S** = {1, 2, 3, 4} and **C** containing those three couplings. This satisfies all conditions:
1. **Essential Inclusion:** **S** contains all 3 essential variables (1, 2, and 3).
2. **Subspace Unification:** Constructing the 4 × 3 incidence matrix **M** (assuming orientations from 4 to the others) yields a matrix with rank 3. This is exactly $|S| - 1$ (4 - 1).
3. **Dimensional Minimality:** The number of columns in **M** is 3, which is exactly $|S| - 1$.
4. **Intermediary Non-Triviality:** The only non-essential variable in **S** is 4. Its corresponding row in **M** has three non-zero entries (the three $1$s or $-1$s), satisfying the requirement of having an $L_0$ norm of at least 2.

Utilizing variable 4 is more cost-effective than enforcing couplings exclusively among the essential variables, which would incur a cost of at least 4.

In Example 3, only one variable is designated as essential. We select **S** = {1} and **C** as an empty set of couplings. 
The incidence matrix **M** has 1 row and 0 columns.
1. **Essential Inclusion:** **S** contains the 1 essential variable.
2. **Subspace Unification:** The rank of a 1 × 0 matrix is 0, which is exactly $|S| - 1$ (1 - 1).
3. **Dimensional Minimality:** The number of columns is 0, exactly $|S| - 1$.
4. **Intermediary Non-Triviality:** There are no non-essential variables in **S**, so this is vacuously satisfied.

Thus, zero couplings need to be enforced, resulting in a cost of 0.
