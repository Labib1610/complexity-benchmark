<STATEMENT>
# Problem A — Vector Subspace Generator Selection

Time limit: 5 s
Memory limit: 256 MB

## Description

You are analyzing the real vector space $V$ spanned by $n$ basis vectors, denoted $v_1, v_2, \dots, v_n$.

You are given a target set $T$ containing $t$ distinct indices, representing a set of target basis vectors $\{v_i \mid i \in T\}$. 
Additionally, there is a pool of $m$ candidate difference vectors. Each candidate is of the form $v_u - v_v$ and incurs a computational cost $w$ if selected.

Your objective is to select a subset $C$ from the pool of candidates to span a specific type of subspace.

For any chosen subset $C$, we define its *active basis set* $S$ as the union of the target set $T$ and the set of all indices $i$ such that the basis vector $v_i$ appears with a non-zero coefficient in at least one vector in $C$.
Let $W = \text{span}(C)$ be the vector subspace generated by $C$.

Your selection $C$ is considered valid if and only if it satisfies all of the following algebraic conditions:
1. **Primary Equivalence:** The subspace $W$ must equate all active basis vectors. That is, for any two indices $a, b \in S$, the difference $v_a - v_b$ must belong to $W$.
2. **Generator Count:** The number of vectors in $C$ must be exactly $|S| - 1$.
3. **Subspace Partitioning:** For every index $k \in S \setminus T$, let $C_k$ be the subset of vectors in $C$ that have a coefficient of $0$ for the basis vector $v_k$. Let $W_k = \text{span}(C_k)$ be the subspace generated by $C_k$.
The subspace $W_k$ naturally partitions the active basis vectors in $S \setminus \{k\}$ into $p$ equivalence classes, where two basis vectors $v_a$ and $v_b$ belong to the same class if and only if their difference $v_a - v_b$ belongs to $W_k$. We require that $p \ge 2$, and that *every* such equivalence class contains at least one target basis vector $v_t$ (where $t \in T$).

Your task is to find a valid selection $C$ that minimizes the total sum of the costs of the selected vectors.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **t** ≤ 10, 1 ≤ **n** ≤ 100, 0 ≤ **m** ≤ **n**·(**n**−1)/2).  
The second line lists **t** distinct integers representing the indices in the target set $T$.  
Following this, there are **m** lines. Each line provides three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000), indicating that a candidate difference vector $v_u - v_v$ is available for a cost of **w**. (Note: the vector $v_u - v_v$ generates the same one-dimensional subspace as $v_v - v_u$, so the order of the indices does not matter).  
It is guaranteed that the available vectors provide at least one valid way to satisfy the conditions.

## Output

Output a single integer representing the minimum possible total cost of a valid selection $C$.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3

```

**Output**
```
2
```

### Example 3

**Input**
```

1
1 2 5

```

**Output**
```
0
```

## Note

In Example 1, we can select $C = \{v_1 - v_4, v_2 - v_4, v_3 - v_4\}$, which incurs a total cost of 1 + 1 + 1 = 3. 
- The target set is $T = \{1, 2, 3\}$.
- The vectors in $C$ involve basis vectors $v_1, v_2, v_3$, and $v_4$. Thus, the active basis set is $S = \{1, 2, 3, 4\}$.
- **Primary Equivalence:** The subspace $W = \text{span}(v_1 - v_4, v_2 - v_4, v_3 - v_4)$ contains the difference between any two basis vectors in $S$ (e.g., $v_1 - v_2 = (v_1 - v_4) - (v_2 - v_4) \in W$).
- **Generator Count:** The number of vectors in $C$ is 3, which equals $|S| - 1$ (4 - 1).
- **Subspace Partitioning:** The only index in $S$ not in $T$ is 4. The subset $C_4$ of vectors in $C$ that have a coefficient of 0 for $v_4$ is empty. The subspace $W_4 = \text{span}(\emptyset)$ is exactly the zero subspace $\{0\}$. Two basis vectors have their difference in the zero subspace if and only if they are the same vector. Thus, the equivalence classes modulo $W_4$ on the set $S \setminus \{4\}$ are exactly the singleton sets $\{v_1\}$, $\{v_2\}$, and $\{v_3\}$. There are 3 such classes (which is $\ge 2$), and each class contains a target basis vector (since 1, 2, and 3 are all in $T$).
This selection is valid and optimal. Selecting vectors only among the target indices would incur a cost of at least 4.

In Example 3, the target set $T = \{1\}$ has only one index. We can select $C = \emptyset$.
- The active basis set is $S = \{1\} \cup \emptyset = \{1\}$.
- **Primary Equivalence:** The subspace $W = \text{span}(\emptyset)$ is the zero subspace. The only pair of indices from $S$ is $(1, 1)$, and $v_1 - v_1 = 0 \in W$.
- **Generator Count:** The number of vectors in $C$ is 0, which equals $|S| - 1$ (1 - 1).
- **Subspace Partitioning:** There are no indices in $S \setminus T$, so this requirement is vacuously satisfied.
Thus, zero vectors need to be selected, resulting in a cost of 0.
</STATEMENT>
<RATIONALE>
The problem was completely reframed into a linear algebra context using vector spaces, subspaces, and basis vector equivalences. This entirely removes the graph-theoretic vocabulary (nodes, edges, trees, connected components) that models were using to pattern-match the problem to Steiner Tree and trigger subset dynamic programming. To succeed, a model must now mathematically prove that the subspace equivalence classes correspond exactly to the connected components of a spanning forest, forcing genuine structural reasoning.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical conditions on the vector subspaces (dimension, span, and equivalence classes of the basis vectors modulo the subspace) are perfectly isomorphic to the connectivity, tree, and leaf-pruning properties of a Steiner Tree, ensuring all valid selections and their costs remain exactly the same.
</PRESERVED_ANSWER>

The problem remains exactly the Minimum Steiner Tree problem, which is NP-complete, framed merely through the incidence matrices of the selected edges.
</PRESERVED_CLASS>
