# Problem A — Database Record Unification

Time limit: 5 s
Memory limit: 256 MB

## Description

You are integrating a legacy database containing $n$ distinct records, indexed $1$ to $n$.

You are given a target set $T$ consisting of $t$ distinct records. Additionally, you have a repository of $m$ available equivalence rules. Each rule asserts that a specific record $u$ and a specific record $v$ represent the same entity, and incurs a processing cost $w$ if activated.

Your objective is to select a subset $C$ of these equivalence rules.

For any chosen subset $C$, we define its *active domain* $S$ as the union of the target set $T$ and the set of all records that are involved in at least one rule in $C$.

Your selection $C$ is valid if and only if it satisfies all of the following conditions:
1. **Unified Scope:** Any record in $S$ can be shown to be equivalent to any other record in $S$ through a chain of rules in $C$.
2. **Minimal Assertions:** The number of rules in $C$ must be exactly $|S| - 1$.
3. **Indispensability:** For every record $k \in S$ that is not in $T$, let $C_k$ be the subset of rules in $C$ that do *not* involve $k$. The rules in $C_k$ partition the set $S \setminus \{k\}$ into isolated equivalence classes. There must be at least two such equivalence classes, and *every* such equivalence class must contain at least one record from the target set $T$.

Your task is to find a valid selection $C$ that minimizes the total sum of the costs of the activated rules.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **t** ≤ 10, 1 ≤ **n** ≤ 100, 0 ≤ **m** ≤ **n**·(**n**−1)/2).  
The second line lists **t** distinct integers representing the indices in the target set $T$.  
Following this, there are **m** lines. Each line provides three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000), indicating that an equivalence rule between record **u** and record **v** is available for a cost of **w**.  
It is guaranteed that the available rules provide at least one valid way to satisfy the conditions.

## Output

Output a single integer representing the minimum possible total cost of a valid selection $C$.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, we can select $C$ consisting of the rules linking (1, 4), (2, 4), and (3, 4), which incurs a total cost of 1 + 1 + 1 = 3. 
- The target set is $T = \{1, 2, 3\}$.
- The rules in $C$ involve records 1, 2, 3, and 4. Thus, the active domain is $S = \{1, 2, 3, 4\}$.
- **Unified Scope:** The rules link any record in $S$ to any other record in $S$.
- **Minimal Assertions:** The number of rules in $C$ is 3, which equals $|S| - 1$ (4 - 1).
- **Indispensability:** The only record in $S$ not in $T$ is 4. The subset $C_4$ of rules in $C$ that do not involve 4 is empty. An empty set of rules leaves every record isolated. Thus, the equivalence classes on $S \setminus \{4\} = \{1, 2, 3\}$ are exactly the individual records $\{1\}$, $\{2\}$, and $\{3\}$. There are 3 such classes (which is at least 2), and each class contains a record of $T$ (since 1, 2, and 3 are all in $T$).
This selection is valid and optimal. Activating rules only among the target records would cost 4.

In Example 3, the target set $T = \{1\}$ has only one record. We can select $C$ as an empty set of rules.
- The active domain is $S = \{1\} \cup \emptyset = \{1\}$.
- **Unified Scope:** A single record is considered linked to itself without any rules.
- **Minimal Assertions:** The number of rules in $C$ is 0, which equals $|S| - 1$ (1 - 1).
- **Indispensability:** There are no records in $S$ outside of $T$, so this requirement is vacuously satisfied.
Thus, zero rules need to be selected, resulting in a cost of 0.
