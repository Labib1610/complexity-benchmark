# Problem A — Database Record Linkage

Time limit: 5 s
Memory limit: 256 MB

## Description

You are working on a data deduplication system for a large database containing $n$ records, indexed 1 to $n$.

Through manual auditing, you have identified a target set of $t$ specific records that definitely belong to the same real-world entity. However, the system's automated rule engine needs to be explicitly configured to link them.

You have a pool of $m$ candidate "equivalence rules". Each rule, if activated, asserts that record $u$ and record $v$ refer to the same entity. Activating a rule incurs a computational overhead cost of $w$.

Equivalence is transitive: if the active rules link record $A$ to $B$, and $B$ to $C$, the system deduces that $A$ and $C$ are the same entity. The system can use any of the $n$ records as intermediate stepping stones to form these deductive chains.

Your objective is to select a subset of candidate rules to activate such that all $t$ records in the target set are deduced to be the same entity. You must find a valid selection that minimizes the total cost of the activated rules.

## Input

The first line provides three integers $n$, $m$, and $t$ (1 ≤ $t$ ≤ 10, 1 ≤ $n$ ≤ 100, 0 ≤ $m$ ≤ $n(n-1)/2$).  
The second line lists $t$ distinct integers representing the indices of the target records.  
Following this, there are $m$ lines. Each line provides three integers $u$, $v$, and $w$ (1 ≤ $u, v$ ≤ $n$, $u \neq v$, 1 ≤ $w$ ≤ 1000000), indicating that a candidate rule linking record $u$ and record $v$ is available for a cost of $w$.  
It is guaranteed that the available rules are sufficient to link all target records.

## Output

Output a single integer representing the minimum possible total cost to activate a valid set of rules.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the target records are 1, 2, and 3. We can activate the rules linking (1, 4), (2, 4), and (3, 4) for a total cost of 1 + 1 + 1 = 3. Record 4 acts as an intermediate link, successfully proving that 1, 2, and 3 are the same entity. Activating rules directly between the target records would cost at least 4.

In Example 3, the target set contains only record 1. Since a single record is trivially equivalent to itself, no rules need to be activated. The minimum cost is 0.

<RATIONALE>
The problem was completely reframed into a database record linkage scenario. By removing all group-theoretic and mathematical constraints and replacing them with a natural "transitive equivalence" requirement, models can no longer rely on recognizing the algebraic conditions of a Steiner Tree. They must now genuinely deduce that finding the minimum cost to logically equate a subset of items via pairwise rules is structurally identical to the Steiner Tree problem.
</RATIONALE>
<PRESERVED_ANSWER>
Because all candidate rule costs are strictly positive, any optimal selection that places the target records in the same equivalence class will naturally form a minimal connected component (a tree whose leaves are target records), which perfectly matches the minimum cost of the seed's algebraic constraints.
</PRESERVED_ANSWER>
