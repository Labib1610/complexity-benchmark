<METHOD_NAME>Topological Closure Framing</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces graph-theoretic concepts (connectivity, trees, leaves) with equivalent topological concepts using closed subsets under a relation. Connected components are redefined as minimal non-empty closed subsets, and the "no non-terminal leaves" condition is redefined via the partitioning of these closed subsets when an element is removed. This completely hides the Steiner Tree structure while maintaining exact mathematical equivalence.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Configuration Subset Selection

Time limit: 5 s
Memory limit: 256 MB

## Description

You are analyzing a system of $n$ elements, indexed $1$ to $n$.

You are provided with a target set $T$ containing $t$ distinct indices. Additionally, there is a pool of $m$ available candidates. Each candidate links two specific elements $u$ and $v$ (denoted as $(u, v)$), and incurs a computational cost $w$ if selected.

Your objective is to select a subset $C$ from the pool of candidates to form a valid configuration.

For any chosen subset $C$, we define a subset of indices $U \subseteq \{1, \dots, n\}$ to be **$C$-closed** if for every candidate $(u, v)$ present in $C$, it is true that either both $u$ and $v$ are in $U$, or neither is in $U$.

Your selection $C$ is considered valid if and only if it satisfies all of the following structural conditions:
1. **Target Cohesion:** There does not exist any $C$-closed subset that contains at least one, but not all, of the target indices in $T$. (Consequently, there is a unique minimal $C$-closed subset that contains all of $T$. Let this minimal subset be denoted as $S$).
2. **Minimal Generation:** The total number of candidates in $C$ must be exactly $|S| - 1$.
3. **Criticality of Non-Targets:** For every index $k \in S$ that is not in $T$, let $C_{\neg k}$ be the set of all candidates in $C$ except those that include $k$ as one of their two elements. A subset of $S \setminus \{k\}$ is called $C_{\neg k}$-closed if it satisfies the closure condition with respect to $C_{\neg k}$. We define a *minimal* non-empty $C_{\neg k}$-closed subset of $S \setminus \{k\}$ as one that does not properly contain any other non-empty $C_{\neg k}$-closed subset. The set $S \setminus \{k\}$ must contain at least two such minimal non-empty $C_{\neg k}$-closed subsets, and *every* such minimal non-empty $C_{\neg k}$-closed subset of $S \setminus \{k\}$ must contain at least one target index from $T$.

Your task is to find a valid selection $C$ that minimizes the total sum of the costs of the selected candidates.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **t** ≤ 10, 1 ≤ **n** ≤ 100, 0 ≤ **m** ≤ **n**·(**n**−1)/2).  
The second line lists **t** distinct integers representing the indices in the target set $T$.  
Following this, there are **m** lines. Each line provides three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000), indicating that a candidate $(u, v)$ is available for a cost of **w**.  
It is guaranteed that the available candidates provide at least one valid way to satisfy the conditions.

## Output

Output a single integer representing the minimum possible total cost of a valid selection $C$.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, we can select $C$ consisting of the candidates $(1, 4)$, $(2, 4)$, and $(3, 4)$, which incurs a total cost of 1 + 1 + 1 = 3. 
- The target set is $T = \{1, 2, 3\}$.
- Any $C$-closed subset containing exactly one or two of the targets would have to separate them, but they are all linked through 4. For instance, a $C$-closed subset containing 1 must contain 4 (due to $(1, 4)$), and containing 4 means it must contain 2 and 3. Thus, no $C$-closed subset contains some but not all targets. The minimal $C$-closed subset containing $T$ is $S = \{1, 2, 3, 4\}$.
- **Minimal Generation:** The number of candidates in $C$ is 3, which equals $|S| - 1$ (4 - 1).
- **Criticality of Non-Targets:** The only element in $S$ not in $T$ is 4. The subset $C_{\neg 4}$ of candidates in $C$ that do not include 4 is empty. A subset of $S \setminus \{4\} = \{1, 2, 3\}$ is $C_{\neg 4}$-closed if it satisfies the closure condition. Since $C_{\neg 4}$ is empty, *every* subset of $\{1, 2, 3\}$ is $C_{\neg 4}$-closed. The minimal non-empty $C_{\neg 4}$-closed subsets are exactly the singleton sets $\{1\}$, $\{2\}$, and $\{3\}$. There are 3 such minimal subsets (which is at least 2), and each contains an element of $T$ (since 1, 2, and 3 are all in $T$).
This selection is valid and optimal. Selecting candidates only among the target indices would incur a cost of at least 4.

In Example 3, the target set $T = \{1\}$ has only one index. We can select $C$ as an empty set of candidates.
- Since $T$ has only one element, it is impossible for a subset to contain "some, but not all" elements of $T$. Thus, Target Cohesion is vacuously satisfied.
- The minimal $C$-closed subset containing $T$ is $S = \{1\}$.
- **Minimal Generation:** The number of candidates in $C$ is 0, which equals $|S| - 1$ (1 - 1).
- **Criticality of Non-Targets:** There are no elements in $S$ outside of $T$, so this requirement is vacuously satisfied.
Thus, zero candidates need to be selected, resulting in a cost of 0.

<RATIONALE>
The problem was rewritten to replace all group-theoretic and graph-theoretic vocabulary with topological closure properties. Connected components are now defined as minimal non-empty closed subsets, and the structural requirements of a Steiner Tree (connectivity, exact edge count, no non-terminal leaves) are enforced through these abstract closure rules. This forces the model to deduce the equivalence between the closure properties and tree connectivity, breaking surface-level pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The conditions for a valid selection are mathematically isomorphic to the original ones (a minimal $C$-closed subset exactly corresponds to a connected component), ensuring that the exact same subsets of candidates are considered valid and the minimum cost remains identical for every input.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Steiner Tree problem on a graph, preserving its NP-complete complexity class.
</PRESERVED_CLASS>
<RISK>
A reader might momentarily wonder if the closure condition for $C_{\neg k}$ on subsets of $S \setminus \{k\}$ requires evaluating elements outside that domain; however, the definition explicitly states "either both $u$ and $v$ are in $U$, or neither is in $U$", which naturally and rigorously handles elements outside the subset without ambiguity.
</RISK>
