 We can model this as a graph problem.  
The candidates are edges with costs.  
We need to pick a set of edges forming a tree on some vertex set \( S \) that includes all target vertices \( T \), and satisfies the orbit condition.

Key observations:

- The active domain \( S \) must be connected via the chosen edges (transitive action).
- The number of edges is \( |S|-1 \), so the chosen edges form a tree on \( S \).
- The orbit condition: For every non-target vertex \( k \in S \setminus T \), removing \( k \) from the tree must split it into at least two components, each containing at least one target vertex.  
  This means every non-target vertex must be a **cut vertex** whose removal separates the targets into different components.  
  In tree terms: every non-target vertex must lie on a path between two distinct target vertices, and its removal must separate at least two targets.

Thus, the problem reduces to:  
Find a minimum-cost tree (using available edges) that contains all target vertices, and where every non-target vertex in the tree is a **Steiner point** that lies on a path between two targets (i.e., it is not a leaf and not in a "dead-end" branch without a target).

Equivalently:  
The tree must be a **minimal Steiner tree** connecting the target set \( T \), with the additional condition that all non-target vertices in the tree are internal (degree ≥ 2) and lie on paths between targets.  
This is exactly a **minimum Steiner tree** problem on a graph with up to \( n=100 \) vertices and \( t \le 10 \) terminals.

Since \( t \le 10 \), we can solve the Steiner tree problem using the standard **DP over subsets** approach:

1. Compute all-pairs shortest paths (Floyd–Warshall) using the given edge costs.
2. Let \( dp[mask][v] \) = minimum cost to connect the terminals in `mask` and end at vertex `v`.
3. Initialize: for each terminal \( i \), \( dp[1<<i][i] = 0 \).
4. Transition:
   - Merge two subsets: \( dp[mask1 | mask2][v] = \min(dp[mask1][v] + dp[mask2][v]) \).
   - Extend to neighbor: \( dp[mask][u] = \min(dp[mask][v] + dist[v][u]) \).
5. The answer is \( \min_v dp[full\_mask][v] \).

This gives the minimum cost Steiner tree.  
The orbit condition is automatically satisfied because in a minimum Steiner tree, all non-terminal vertices are internal (otherwise we could remove a leaf non-terminal and reduce cost).  
Also, the tree connects all targets, so every non-target vertex lies on a path between two targets.

Edge cases:
- If \( t = 1 \), the answer is 0 (empty tree).
- If \( t > 1 \), we run the DP.

Let’s implement it.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    targets = list(map(int, input().split()))
    targets = [x-1 for x in targets]  # 0-index

    INF = 10**18
    dist = [[INF]*n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0

    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        if w < dist[u][v]:
            dist[u][v] = w
            dist[v][u] = w

    # Floyd-Warshall
    for k in range(n):
        for i in range(n):
            if dist[i][k] == INF:
                continue
            for j in range(n):
                if dist[k][j] == INF:
                    continue
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]

    if t == 1:
        print(0)
        return

    full_mask = (1 << t) - 1
    dp = [[INF]*n for _ in range(1 << t)]
    for i, term in enumerate(targets):
        dp[1 << i][term] = 0

    for mask in range(1 << t):
        # merge subsets
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if other < sub:  # avoid duplicate work
                for v in range(n):
                    if dp[sub][v] + dp[other][v] < dp[mask][v]:
                        dp[mask][v] = dp[sub][v] + dp[other][v]
            sub = (sub - 1) & mask

        # relax via shortest paths
        for v in range(n):
            if dp[mask][v] == INF:
                continue
            for u in range(n):
                if dist[v][u] < INF:
                    nd = dp[mask][v] + dist[v][u]
                    if nd < dp[mask][u]:
                        dp[mask][u] = nd

    ans = min(dp[full_mask])
    print(ans)

if __name__ == "__main__":
    solve()
```
