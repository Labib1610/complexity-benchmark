# Problem A — Permutation Subgroup Selection

Time limit: 5 s
Memory limit: 256 MB

## Description

You are analyzing permutation groups acting on a set of $n$ elements, indexed $1$ to $n$.

You are provided with a target set $T$ containing $t$ distinct indices. Additionally, there is a pool of $m$ available candidate transpositions. Each candidate transposition swaps two specific elements $u$ and $v$ (denoted as $(u, v)$), and incurs a computational cost $w$ if selected.

Your objective is to select a subset $C$ from the pool of candidates to form a valid generating set.

For any chosen subset $C$, we define its *active domain* $S$ as the union of the target set $T$ and the set of all elements that are moved by at least one transposition in $C$.

Your selection $C$ is considered valid if and only if it satisfies all of the following algebraic conditions:
1. **Transitive Action:** The subgroup generated by the transpositions in $C$ must act transitively on the active domain $S$.
2. **Generator Count:** The number of transpositions in $C$ must be exactly $|S| - 1$.
3. **Orbit Requirement:** For every element $k \in S$ that is not in $T$, let $C_k$ be the subset of transpositions in $C$ that do *not* move $k$. The subgroup generated by $C_k$ naturally partitions the set $S \setminus \{k\}$ into a number of disjoint orbits. There must be at least two such orbits, and *every* such orbit must contain at least one element from the target set $T$.

Your task is to find a valid selection $C$ that minimizes the total sum of the costs of the selected transpositions.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **t** ≤ 10, 1 ≤ **n** ≤ 100, 0 ≤ **m** ≤ **n**·(**n**−1)/2).  
The second line lists **t** distinct integers representing the indices in the target set $T$.  
Following this, there are **m** lines. Each line provides three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000), indicating that a candidate transposition $(u, v)$ is available for a cost of **w**.  
It is guaranteed that the available transpositions provide at least one valid way to satisfy the conditions.

## Output

Output a single integer representing the minimum possible total cost of a valid selection $C$.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, we can select $C$ consisting of the transpositions $(1, 4)$, $(2, 4)$, and $(3, 4)$, which incurs a total cost of 1 + 1 + 1 = 3. 
- The target set is $T = \{1, 2, 3\}$.
- The transpositions in $C$ move the elements 1, 2, 3, and 4. Thus, the active domain is $S = \{1, 2, 3, 4\}$.
- **Transitive Action:** The subgroup generated by these 3 transpositions can map any element in $S$ to any other element in $S$, so it acts transitively on $S$.
- **Generator Count:** The number of transpositions in $C$ is 3, which equals $|S| - 1$ (4 - 1).
- **Orbit Requirement:** The only element in $S$ not in $T$ is 4. The subset $C_4$ of transpositions in $C$ that do not move 4 is empty. The subgroup generated by an empty set is the trivial group, which leaves every element fixed. Thus, its orbits on $S \setminus \{4\} = \{1, 2, 3\}$ are exactly the singleton sets $\{1\}$, $\{2\}$, and $\{3\}$. There are 3 such orbits (which is at least 2), and each orbit contains an element of $T$ (since 1, 2, and 3 are all in $T$).
This selection is valid and optimal. Selecting transpositions only among the target indices would incur a cost of at least 4.

In Example 3, the target set $T = \{1\}$ has only one index. We can select $C$ as an empty set of transpositions.
- The active domain is $S = \{1\} \cup \emptyset = \{1\}$.
- **Transitive Action:** The trivial subgroup generated by the empty set acts transitively on the 1-element set $S$.
- **Generator Count:** The number of transpositions in $C$ is 0, which equals $|S| - 1$ (1 - 1).
- **Orbit Requirement:** There are no elements in $S$ outside of $T$, so this requirement is vacuously satisfied.
Thus, zero transpositions need to be selected, resulting in a cost of 0.
