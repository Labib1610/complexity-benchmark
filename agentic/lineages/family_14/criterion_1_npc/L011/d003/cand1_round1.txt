# Problem A — Pneumatic Infrastructure

Time limit: 5 s   Memory limit: 256 MB

## Description

An industrial complex consists of **n** facilities (numbered 1 to **n**). You are provided with a catalog of potential bidirectional pneumatic links that could be installed between certain pairs of facilities. Every potential link has an associated installation cost.

An upcoming safety review has designated a list of **t** specific facilities as *audit-critical*. To pass the review, all audit-critical facilities must be fully integrated into a shared communication network. A physical canister must be capable of traveling from any audit-critical facility to any other. It may not freely use arbitrary noncritical facilities as internal vertices for its route; a canister's journey must be made exclusively through a contiguous sequence of the pneumatic links you choose to install.

You can choose to install any subset of the available links. Calculate the lowest possible total installation cost needed to successfully integrate all audit-critical facilities.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the identifiers of the audit-critical facilities.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), representing a potential pneumatic link between facility **u** and facility **v** with an installation cost of **w**.
It is guaranteed that the provided catalog of potential links is sufficient to integrate all audit-critical facilities.

## Output

Print a single integer: the lowest total installation cost.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, installing the links that join facility 4 to facilities 1, 2, and 3 incurs a total cost of 1 + 1 + 1 = 3. This successfully integrates the audit-critical facilities (1, 2, and 3) and is more economical than linking them exclusively using direct connections between each other, which would cost at least 4. In Example 3, there is only one audit-critical facility, so no links need to be installed.
</STATEMENT>
<RATIONALE>
The phrase "possibly passing through other intermediate buildings" acts as a strong semantic trigger for the Steiner Tree problem, as it explicitly highlights the core difference between MST and Steiner Tree. I replaced this with a negative constraint ("may not freely use arbitrary noncritical facilities as internal vertices"), followed by a clarification that paths must consist of paid edges. This removes the classic Steiner Tree wording while logically enforcing the exact same requirement, forcing models to deduce the structure from the exact mechanics.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that paths must consist of chosen links is tautologically identical to the original graph requirement, meaning any valid connected subgraph spanning the critical vertices remains valid and incurs the same cost.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks for the minimum cost subset of edges to connect a specified subset of vertices in a weighted graph, which is exactly the NP-complete Steiner Tree problem.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret "may not freely use arbitrary noncritical facilities" as a strict prohibition on using noncritical facilities entirely, though the Example 1 Note explicitly clarifies that using facility 4 (a noncritical facility) is allowed and optimal.
</RISK>
