We can model this as a **Steiner tree** problem, but since the number of required terminals is small (≤ 10), we can solve it using **bitmask DP over subsets of terminals** combined with shortest paths.

Here’s the approach:

1. **Precompute shortest paths** between all pairs of nodes using Floyd–Warshall (n ≤ 100).
2. Use **DP over subsets**:
   - Let `dp[mask][v]` = minimum cost to connect the terminals in `mask` and end at node `v`.
   - Initialize for each terminal `i`: `dp[1 << i][terminal[i]] = 0`.
3. For each mask:
   - Combine two submasks: `dp[mask][v] = min(dp[mask][v], dp[sub][v] + dp[mask ^ sub][v])`.
   - Then relax via shortest paths: for each `v`, for each `u`, `dp[mask][u] = min(dp[mask][u], dp[mask][v] + dist[v][u])`.
4. Answer is `min(dp[(1 << t) - 1][v])` over all `v`.

This works because t ≤ 10, so 2^t ≤ 1024, and n ≤ 100, so the DP is feasible.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))
    terminals = [int(next(it)) - 1 for _ in range(t)]
    
    INF = 10**15
    dist = [[INF] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0
    
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        if w < dist[u][v]:
            dist[u][v] = w
            dist[v][u] = w
    
    # Floyd-Warshall
    for k in range(n):
        for i in range(n):
            if dist[i][k] == INF:
                continue
            for j in range(n):
                if dist[k][j] == INF:
                    continue
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]
    
    # DP over subsets
    full_mask = 1 << t
    dp = [[INF] * n for _ in range(full_mask)]
    
    for i, term in enumerate(terminals):
        dp[1 << i][term] = 0
    
    for mask in range(1, full_mask):
        # Combine submasks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if sub < other:  # avoid double work
                for v in range(n):
                    if dp[sub][v] + dp[other][v] < dp[mask][v]:
                        dp[mask][v] = dp[sub][v] + dp[other][v]
            sub = (sub - 1) & mask
        
        # Relax via shortest paths
        for v in range(n):
            if dp[mask][v] == INF:
                continue
            for u in range(n):
                if dist[v][u] == INF:
                    continue
                if dp[mask][v] + dist[v][u] < dp[mask][u]:
                    dp[mask][u] = dp[mask][v] + dist[v][u]
    
    ans = min(dp[full_mask - 1])
    print(ans)

if __name__ == "__main__":
    solve()
```
