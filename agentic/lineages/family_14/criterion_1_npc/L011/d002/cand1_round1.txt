<STATEMENT>
# Problem A — Facility Fiber Integration

Time limit: 5 s   Memory limit: 256 MB

## Description

A sprawling campus contains **n** separate administrative and operational buildings, identified by numbers 1 through **n**. To upgrade the infrastructure, you have been given a catalog of possible bidirectional optical fiber connections that can be laid between specific pairs of buildings. Each potential connection has a quoted installation cost.

Within the campus, there is a designated emergency roster consisting of **t** critical coordination buildings. Due to strict regulatory constraints, this emergency roster is highly exclusive and will never exceed ten buildings. 

Your task is to design a communication backbone such that every building on the emergency roster can route data to any other building on the roster. Data can be routed between any two buildings provided there is a continuous path of installed fiber connections between them. You are free to install any subset of the cataloged connections, including routing through non-roster buildings if it is cost-effective.

Determine the lowest possible total installation cost to achieve full interconnectivity for the emergency roster.

## Input

The first line consists of three integers: **n** (1 ≤ n ≤ 100), **m** (0 ≤ m ≤ n·(n−1)/2), and **t** (at least 1). The value **n** denotes the total number of buildings, **m** is the number of available fiber connections in the catalog, and **t** is the size of the emergency roster (which is guaranteed to respect the regulatory maximum described above).

The second line contains **t** distinct integers, listing the identifiers of the buildings on the emergency roster.

The following **m** lines detail the catalog. Each line contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), meaning a fiber connection can be laid between building **u** and building **v** at a cost of **w**.

It is guaranteed that a valid network connecting all roster buildings can always be formed using the cataloged connections.

## Output

Print a single integer representing the absolute minimum total cost to lay the required fiber connections.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the fiber connections linking building 4 to buildings 1, 2, and 3 incurs a total cost of 1 + 1 + 1 = 3. This successfully allows the emergency roster buildings (1, 2, and 3) to communicate and is more economical than linking them exclusively using direct connections between each other, which would require a cost of at least 4. In Example 3, there is only one building on the roster, so no fiber connections need to be installed.
