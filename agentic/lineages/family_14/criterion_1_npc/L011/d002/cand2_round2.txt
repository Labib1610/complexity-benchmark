# Problem A — Site Connectivity

Time limit: 5 s   Memory limit: 256 MB

## Description

A site is composed of **n** distinct structures. You are provided with a catalog of potential bidirectional data conduits that could be installed between specific pairs of these structures. Each conduit has an associated installation cost.

A critical alert group identifies **t** of these structures that require guaranteed mutual contact. Your objective is to provision a network such that any structure in the critical alert group can route data to any other structure in the group. Data routing can traverse any sequence of installed conduits, meaning structures outside the alert group can be freely utilized as intermediate relays.

You may install any subset of the potential conduits. Determine the lowest possible total installation cost that successfully connects the entire critical alert group.

## Input

The first line contains three integers **n**, **m**, and **t**. The site capacity **n** is between 1 and 100. The number of cataloged conduits **m** is between 0 and **n**·(**n**−1)/2. The critical alert group headcount **t** is between 1 and 10.
The second line contains **t** distinct integers: the identifiers of the structures in the critical alert group.
Each of the next **m** lines contains three integers **u**, **v**, and **w**. These denote a potential conduit between structure **u** and structure **v** (where **u** and **v** are distinct structure identifiers between 1 and **n**) with an installation cost **w** between 1 and 1000000.
It is guaranteed that the cataloged conduits are sufficient to allow all structures in the critical alert group to communicate.

## Output

Print a single integer: the minimum total cost to install the conduits.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, installing the conduits connecting structure 4 to structures 1, 2, and 3 incurs a total cost of 1 + 1 + 1 = 3. This successfully allows the critical alert group (structures 1, 2, and 3) to communicate and is more economical than linking them exclusively using direct connections between each other, which would require a cost of at least 4. In Example 3, there is only one structure in the critical alert group, so no conduits need to be installed.
