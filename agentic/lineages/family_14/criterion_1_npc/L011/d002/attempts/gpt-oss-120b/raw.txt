**Solution Explanation**

For every building we know all possible tubes (undirected edges) and their
construction costs.
Among the buildings `T = { t1 … tt }` (`t ≤ 10`) we have to guarantee that
any two of them can reach each other using the built tubes.
The cheapest possible total cost is the weight of a *minimum Steiner tree*
for the terminal set `T`.

`n ≤ 100`, `t ≤ 10` – the classic DP over subsets of terminals is easily fast
enough.

--------------------------------------------------------------------

#### 1.   Graph

```
adj[u] = list of (v , w)   # undirected, 0‑based vertices
```

--------------------------------------------------------------------

#### 2.   DP definition  

```
dp[mask][v] = minimum cost of a tree
              * that contains vertex v
              * that connects exactly the terminals whose bits are 1 in mask
```

`mask` runs from `0 … (1<<t)-1`, `v` from `0 … n-1`.

*initialisation*  

For every terminal `ti` (index `i` in the terminal list)

```
dp[1<<i][ ti ] = 0          # a tree consisting only of this vertex
all other entries = INF
```

--------------------------------------------------------------------

#### 3.   Bringing a set together – merging two sub‑sets  

Assume we already know optimal trees for two **disjoint** subsets
`sub` and `other = mask ^ sub`.  
Both trees may end at the same vertex `v`.  
Connecting them at `v` yields a tree for the union `mask`.

```
dp[mask][v] = min( dp[mask][v] , dp[sub][v] + dp[other][v] )
```

All proper non‑empty sub‑masks are examined, therefore after this loop
`dp[mask][v]` equals the cheapest tree that *ends* in `v`
but possibly still contains “holes” (edges not yet taken into account).

--------------------------------------------------------------------

#### 4.   Spreading the tree through the graph – Dijkstra  

From the values just obtained we start a multi‑source Dijkstra:
every vertex `v` is a source with distance `dp[mask][v]`.
Running Dijkstra relaxes edges and produces the true cheapest
tree for the whole subset `mask`.

After Dijkstra finishes, the array `dp[mask]` already holds the optimal
costs for this subset.

Complexities per mask  

* merging : `O( number_of_submasks * n )`
* Dijkstra : `O( (n+m) log n )`

`2^t ≤ 1024`, `n ≤ 100`, `m ≤ 4950` – easily below the limits.

--------------------------------------------------------------------

#### 5.   Result  

`full = (1<<t) - 1`  
answer = `min_v dp[full][v]`

If `t = 1` the initialisation already gives `0`.

--------------------------------------------------------------------

#### 6.   Correctness Proof  

We prove that the algorithm outputs the minimum possible total cost.

---

##### Lemma 1  
For any mask and vertex `v` after the **merging step**  
`dp[mask][v]` equals the minimum cost of a forest consisting of two
disjoint Steiner trees that

* connect exactly the terminals of two non‑empty, disjoint sub‑masks
  whose union is `mask`,
* both contain `v` as a (common) vertex.

**Proof.**  
The merging loop enumerates every proper non‑empty sub‑mask `sub`.
For each `sub` the complementary set `other = mask ^ sub` is also non‑empty.
`dp[sub][v]` (induction hypothesis) is the cheapest tree for `sub` that ends
in `v`; the same holds for `dp[other][v]`.
Joining the two trees at `v` yields a forest of total cost
`dp[sub][v] + dp[other][v]`.  
Taking the minimum over all possibilities gives exactly the cheapest such
forest. ∎



##### Lemma 2  
After the **Dijkstra step** for a fixed `mask`,
`dp[mask][v]` equals the minimum cost of a (connected) Steiner tree that

* connects all terminals whose bits are 1 in `mask`,
* contains vertex `v`.

**Proof.**  
Before Dijkstra, by Lemma&nbsp;1 each `dp[mask][v]` is the cheapest
forest that already contains `v`.  
Running multi‑source Dijkstra with these values as initial distances
adds arbitrary paths (any edges may be taken) to every vertex.
The relaxation rule exactly corresponds to extending the current tree
by one edge `v–u` with cost `w`.  
Because edge weights are non‑negative, Dijkstra computes the shortest
possible distance from the set of sources to every vertex, i.e. the cheapest
way to *connect* the already built forest to `v`.  
Consequently the final value is the cheapest connected tree for the whole
terminal set `mask` that ends at `v`. ∎



##### Lemma 3  
For every mask and vertex `v` the algorithm maintains the invariant of
Lemma&nbsp;2 after processing that mask.

**Proof.**  
Induction over increasing `mask` (by integer value, which respects subset
inclusion).

*Base*: masks with a single bit. The only non‑INF entry is
`dp[1<<i][ti] = 0`.  
Running Dijkstra yields the shortest paths from terminal `ti` to every
vertex – exactly the cheapest tree that connects only this terminal
(and ends at each vertex). Lemma&nbsp;2 holds.

*Induction step*: Assume the invariant true for all proper sub‑masks.
During processing of `mask` we first apply the merging step.
By Lemma&nbsp;1 the resulting values are the cheapest forests whose
components are optimal for the sub‑masks (induction hypothesis).
Running Dijkstra transforms each of those forests into the cheapest
connected tree for `mask` (Lemma&nbsp;2). ∎



##### Lemma 4  
`ans = min_v dp[full][v]` is the minimum possible total cost to interconnect
all audit‑critical buildings.

**Proof.**  
By Lemma&nbsp;3, after the last mask (`full`) is processed,
`dp[full][v]` is the optimum cost of a Steiner tree connecting *all*
terminals and ending at `v`.  
Taking the minimum over all possible ending vertices yields the overall
minimum Steiner tree cost. ∎



##### Theorem  
The algorithm outputs the minimum total construction cost that guarantees
all audit‑critical buildings are mutually reachable.

**Proof.**  
Directly from Lemma&nbsp;4. ∎



--------------------------------------------------------------------

#### 7.   Complexity Analysis  

```
states          : 2^t   ≤ 1024
vertices per state : n ≤ 100
edges           : m ≤ 4950
```

* Merging over sub‑masks:   `O( 3^t * n )`  
  (`∑_{mask} 2^{popcount(mask)} = 3^t`)

* Dijkstra for each mask:  `O( 2^t * (n+m) log n )`

Overall  
`time  ≤  O( 3^t * n + 2^t * (n+m) log n )  ≤  a few·10^7` operations – well
inside the 5 s limit.  

Memory: `dp` array `2^t × n` → at most `1024 × 100 = 102 400` integers,
negligible.

--------------------------------------------------------------------

#### 8.   Reference Implementation  (Python 3)

```python
import sys
import heapq

INF = 10 ** 18

def solve() -> None:
    data = list(map(int, sys.stdin.read().strip().split()))
    if not data:
        return
    it = iter(data)
    n = next(it)
    m = next(it)
    t = next(it)

    terminals = [next(it) - 1 for _ in range(t)]   # 0‑based
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = next(it) - 1
        v = next(it) - 1
        w = next(it)
        adj[u].append((v, w))
        adj[v].append((u, w))

    full = (1 << t) - 1
    dp = [[INF] * n for _ in range(1 << t)]

    # initialisation: single terminal sets
    for i, v in enumerate(terminals):
        dp[1 << i][v] = 0

    # process all masks
    for mask in range(1, full + 1):
        # merging sub‑masks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if other:   # both non‑empty
                dsub = dp[sub]
                dother = dp[other]
                dcur = dp[mask]
                for v in range(n):
                    val = dsub[v] + dother[v]
                    if val < dcur[v]:
                        dcur[v] = val
            sub = (sub - 1) & mask

        # Dijkstra to spread through the graph
        dist = dp[mask]
        pq = [(dist[v], v) for v in range(n) if dist[v] < INF]
        heapq.heapify(pq)
        while pq:
            d, u = heapq.heappop(pq)
            if d != dist[u]:
                continue
            for to, w in adj[u]:
                nd = d + w
                if nd < dist[to]:
                    dist[to] = nd
                    heapq.heappush(pq, (nd, to))

    answer = min(dp[full])
    print(answer)


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input / output format.
