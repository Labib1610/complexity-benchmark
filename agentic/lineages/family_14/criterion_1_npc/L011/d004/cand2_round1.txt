# Problem A — Logical Foundations

Time limit: 5 s
Memory limit: 256 MB

## Description

A formal system contains **n** distinct propositions, identified by integers from 1 to **n**. Researchers can establish a direct logical biconditional (an "if and only if" result) between certain pairs of propositions. Establishing the direct biconditional between proposition **u** and proposition **v** requires publishing a formal proof consisting of **w** lines of deduction.

An upcoming doctrinal review mandates that a specific subset of **t** propositions—designated as *core axioms*—must be shown to be logically equivalent to one another. 

By the laws of logic, equivalence is transitive. If proposition A is equivalent to B, and B is equivalent to C, then A is equivalent to C. Therefore, any two propositions are considered logically equivalent as long as there is a chain of established direct biconditionals linking them.

When selecting which proofs to publish, you are not restricted to only establishing biconditionals between the core axioms. Any of the remaining auxiliary propositions may be utilized as intermediate logical steps; proving that a core axiom is equivalent to an auxiliary proposition, which is in turn equivalent to another core axiom, is entirely valid and may be advantageous if it reduces the overall length of the proofs.

Your task is to choose a subset of the available direct biconditionals to establish such that all **t** core axioms are logically equivalent to one another, while keeping the sum of the lines of deduction for the chosen biconditionals to the absolute minimum.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **t** ≤ 10, 1 ≤ **n** ≤ 100, 0 ≤ **m** ≤ **n**·(**n**−1)/2).  
The second line lists **t** distinct integers representing the identifiers of the core axioms.  
Following this, there are **m** lines. Each line provides three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000), indicating that a direct biconditional between proposition **u** and proposition **v** can be established using a proof of **w** lines.  
It is guaranteed that the available proofs provide at least one valid way to demonstrate the equivalence of all core axioms.

## Output

Output a single integer representing the minimum possible total lines of deduction required to satisfy the mandate.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, establishing the direct biconditionals that link proposition 4 to propositions 1, 2, and 3 requires a total of 1 + 1 + 1 = 3 lines of deduction. This successfully demonstrates that the core axioms (1, 2, and 3) are all mutually equivalent, because they are all equivalent to proposition 4. Utilizing proposition 4 as an intermediate step is more efficient than forcing direct proofs solely between the core axioms, which would require at least 4 lines of deduction. 

In Example 3, only one proposition is flagged as a core axiom. Since a single proposition is trivially equivalent to itself, zero proofs need to be established, resulting in 0 lines of deduction.

<RATIONALE>
The problem was completely reframed from a spatial routing scenario to a formal logic scenario. Instead of connecting sectors with pipes, the objective is now to prove propositions equivalent using transitive biconditionals. This removes all graph-theoretic and network-routing vocabulary ("junctions", "grid", "paths"), forcing the model to recognize that establishing transitive equivalence classes with minimum weight is isomorphic to finding a Steiner Tree.
</RATIONALE>
<PRESERVED_ANSWER>
The cost of each proof is only paid once when it is established, and the goal is to form a single equivalence class (connected component) containing the target propositions, which is mathematically identical to the original minimum-cost subgraph requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the Steiner Tree problem on graphs, which is NP-complete, requiring the same Dreyfus-Wagner or bitmask dynamic programming approach.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret "chain of established direct biconditionals" as requiring a single linear path rather than a tree, though the example note clarifies that linking multiple axioms to a central proposition successfully establishes mutual equivalence.
</RISK>
