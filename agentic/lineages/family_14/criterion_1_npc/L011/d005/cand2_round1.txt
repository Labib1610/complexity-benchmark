<STATEMENT>
# Problem A — Subspace Dimensionality Reduction

Time limit: 5 s
Memory limit: 256 MB

## Description

You are working with an **n**-dimensional vector space, where the coordinates of any vector are indexed from 1 to **n**.

You are provided with a set of **m** possible hyperplane restrictions that can be applied to this space. Each restriction is defined by a pair of coordinate indices **u** and **v**. If you choose to apply a restriction, it forces the vector space to be confined to the subspace where the **u**-th coordinate is exactly equal to the **v**-th coordinate (i.e., $x_u = x_v$). Applying a restriction incurs a specific energy cost **w**.

You may select any subset of the **m** available restrictions to apply simultaneously. The total energy cost of your selection is simply the sum of the **w** values for the restrictions you have chosen.

A theoretical framework requires that the final confined subspace must satisfy a strict symmetry condition across a specific set of **t** *critical* coordinate indices. Specifically, for every vector that exists in the final subspace, its coordinate values at all **t** critical indices must be identical to each other.

You are not required to only restrict the critical coordinates directly. You may apply restrictions involving any of the **n** coordinates, as long as the logical consequence of the entire set of chosen restrictions ensures that the critical coordinates are forced to be equal.

Your task is to determine the minimum possible total energy cost to choose a subset of restrictions that satisfies this requirement.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **t** ≤ 10, 1 ≤ **n** ≤ 100, 0 ≤ **m** ≤ **n**·(**n**−1)/2).  
The second line lists **t** distinct integers representing the indices of the critical coordinates.  
Following this, there are **m** lines. Each line provides three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000), indicating that a restriction forcing $x_u = x_v$ is available for an energy cost of **w**.  
It is guaranteed that the available restrictions provide at least one valid way to satisfy the requirement for the critical coordinates.

## Output

Output a single integer representing the minimum possible total energy cost required to satisfy the framework's requirement.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, choosing the three restrictions that force $x_1 = x_4$, $x_2 = x_4$, and $x_3 = x_4$ incurs a total energy cost of 1 + 1 + 1 = 3. In the resulting subspace, any vector must satisfy $x_1 = x_4$, $x_2 = x_4$, and $x_3 = x_4$, which logically guarantees that $x_1 = x_2 = x_3$. This satisfies the requirement for the critical coordinates (1, 2, and 3). Utilizing coordinate 4 as an intermediate constraint is more energy-efficient than applying restrictions solely among the critical coordinates, which would cost at least 4.

In Example 3, only one coordinate is designated as critical. Since every vector trivially satisfies $x_1 = x_1$ without any restrictions, zero restrictions are applied, resulting in a minimum energy cost of 0.

<RATIONALE>
I transformed the graph connectivity problem into an equivalent linear algebra problem about vector space projections. By framing edges as hyperplane restrictions ($x_u = x_v$) and connected components as logically implied coordinate equalities, models relying on graph-theoretic pattern matching (like 'unification' or 'transitive') will fail to recognize the underlying Steiner Tree structure. Models capable of genuine mathematical reasoning will deduce that linear dependence among such equations is isomorphic to graph connectivity.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that a set of equations $x_u = x_v$ logically implies $x_a = x_b$ holds if and only if $a$ and $b$ are in the same connected component of the graph formed by the chosen equations, making the valid subsets and their costs identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Steiner Tree problem on an undirected graph, which is NP-complete, simply expressed through the incidence matrix's null space rather than graph terminology.
</PRESERVED_CLASS>
<RISK>
Models might wonder which field the vector space is defined over, but since the linear implications of difference equations $x_u - x_v = 0$ are identical across all fields, this does not create any ambiguity in the required subset.
</RISK>
