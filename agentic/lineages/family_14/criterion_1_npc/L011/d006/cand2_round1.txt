<STATEMENT>
# Problem A — Arbitrage Replication

Time limit: 5 s
Memory limit: 256 MB

## Description

You are an analyst at a quantitative hedge fund. The market consists of **n** distinct assets, identified by integers from 1 to **n**. The price of asset **i** at any given time is denoted as $P_i$.

The fund can purchase access to **m** different "relative return" data feeds. Accessing a feed between asset **u** and asset **v** incurs a one-time licensing fee of **w**. Once licensed, a feed allows your trading algorithms to continuously monitor and trade the price difference between these two assets. 

Specifically, having access to the feed for (**u**, **v**) allows you to construct a portfolio whose payout is exactly $P_u - P_v$ (or $P_v - P_u$, by shorting). By taking linear combinations of the payouts from the licensed feeds, you can replicate the price difference of other asset pairs. For example, if you hold $q_1$ units of a $(u_1, v_1)$ spread and $q_2$ units of a $(u_2, v_2)$ spread, the combined payout is $q_1(P_{u_1} - P_{v_1}) + q_2(P_{u_2} - P_{v_2})$, where the position sizes $q_1$ and $q_2$ can be any real numbers.

A new risk-management directive requires the fund to perfectly hedge a core group of **t** *benchmark* assets. To achieve this, the algorithms must be able to replicate the exact price difference $P_x - P_y$ for every possible pair of benchmark assets **x** and **y**. This replication identity must hold true algebraically for all theoretically possible asset prices $P_1, \dots, P_n$.

You may license any combination of the **m** available feeds. Your task is to select a subset of feeds to license such that the algorithms can replicate the price difference between any two benchmark assets, while keeping the total licensing fee to the absolute minimum.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **t** ≤ 10, 1 ≤ **n** ≤ 100, 0 ≤ **m** ≤ **n**·(**n**−1)/2).  
The second line lists **t** distinct integers representing the identifiers of the benchmark assets.  
Following this, there are **m** lines. Each line provides three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000), indicating that a data feed can be licensed between asset **u** and asset **v** for a fee of **w**.  
It is guaranteed that the available feeds provide at least one valid way to satisfy the risk-management directive.

## Output

Output a single integer representing the minimum possible total licensing fee required to satisfy the directive.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```

```

### Example 3

**Input**

```
1
1 2 5

```

**Output**
```
0
```

## Note

In Example 1, licensing the feeds for (1, 4), (2, 4), and (3, 4) costs 1 + 1 + 1 = 3. With these feeds, we can replicate the price difference between any pair of the benchmark assets {1, 2, 3}. For instance, to replicate the difference $P_1 - P_2$, the algorithm can hold 1 unit of the (1, 4) spread and -1 unit of the (2, 4) spread. The payout will be $1 \cdot (P_1 - P_4) - 1 \cdot (P_2 - P_4) = P_1 - P_2$. This works for any prices $P_1, P_2, P_4$. Similarly, $P_2 - P_3$ and $P_1 - P_3$ can be replicated. Licensing feeds (1, 2) and (2, 3) directly would cost 2 + 2 = 4, which is also valid but more expensive.

In Example 3, only asset 1 is designated as a benchmark asset. The requirement is to replicate $P_x - P_y$ for all pairs in the benchmark set. The only pair is $x=1, y=1$, so we must replicate $P_1 - P_1 = 0$. A payout of 0 is trivially replicated by holding an empty portfolio (0 units of any feed). Thus, zero feeds need to be licensed, resulting in a cost of 0.
</STATEMENT>
<RATIONALE>
The problem was completely reframed from a network connectivity scenario to an algebraic vector-spanning scenario disguised as financial portfolio replication. To solve this, a model must independently deduce that algebraically spanning the difference vectors $e_x - e_y$ using a subset of basis differences $e_u - e_v$ is mathematically isomorphic to finding a connected subgraph containing the target vertices. This forces genuine structural reasoning and defeats models that rely on surface-level graph terminology to retrieve their Steiner Tree templates.
</RATIONALE>
<PRESERVED_ANSWER>
The algebraic condition of replicating the price differences $P_x - P_y$ for all target assets is satisfied if and only if all target assets belong to the same connected component in the graph of licensed feeds, meaning the minimum cost subset is exactly the Minimum Steiner Tree, preserving all answers.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains mathematically identical to finding a Minimum Steiner Tree on an undirected graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Some models might misinterpret "linear combinations" as allowing fractional licensing of the feeds themselves, though the phrase "select a subset of feeds to license" and the one-time fee description strongly counteract this.
</RISK>
