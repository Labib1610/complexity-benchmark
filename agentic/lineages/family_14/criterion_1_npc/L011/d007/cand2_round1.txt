<METHOD_NAME>Algebraic Vector Span Isomorphism</METHOD_NAME>
<METHOD_DESCRIPTION>Transforms the graph connectivity requirement into an equivalent linear algebra requirement: spanning the difference vectors of target dimensions using a subset of allowed basis difference vectors. This hides the graph structure entirely while preserving the exact mathematical solution space via the properties of graphic matroids and totally unimodular matrices. The models will struggle to recognize the Steiner Tree problem without graph-theoretic or set-partitioning cues.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Subspace Spanning

Time limit: 5 s
Memory limit: 256 MB

## Description

You are working in an **n**-dimensional real vector space. The standard basis vectors for this space are denoted as **e**₁, **e**₂, ..., **e**ₙ. 

You are given a catalog of **m** available generator vectors that you can purchase. Each generator vector is of the form **e**_**u** - **e**_**v** (for some distinct indices **u** and **v**) and has an associated purchase cost **w**. Because you are forming a linear span, purchasing **e**_**u** - **e**_**v** inherently allows you to form **e**_**v** - **e**_**u** simply by multiplying by -1.

A specific set of **t** indices are designated as *target dimensions*. 

Your objective is to purchase a subset of the available generator vectors such that, for every possible pair of target dimensions **x** and **y**, the difference vector **e**_**x** - **e**_**y** is contained within the linear span of your purchased subset. 

You may purchase any generator vector from the catalog, including those that involve dimensions other than the target dimensions, if doing so helps to minimize the total cost. 

Find the minimum total purchase cost required to obtain a valid subset of generator vectors.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ **t** ≤ 10, 1 ≤ **n** ≤ 100, 0 ≤ **m** ≤ **n**·(**n**−1)/2).  
The second line lists **t** distinct integers representing the indices of the target dimensions.  
Following this, there are **m** lines. Each line provides three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000), indicating that the generator vector **e**_**u** - **e**_**v** is available for a cost of **w**.  
It is guaranteed that the available generator vectors provide at least one valid way to span the required difference vectors.

## Output

Output a single integer representing the minimum possible total cost required to satisfy the condition.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the target dimensions are 1, 2, and 3. By purchasing the generator vectors **e**₁ - **e**₄, **e**₂ - **e**₄, and **e**₃ - **e**₄, we incur a total cost of 1 + 1 + 1 = 3. 
The linear span of this selected subset contains the required difference vectors for all pairs of target dimensions. For instance, the difference vector for target dimensions 1 and 2 is **e**₁ - **e**₂. This vector can be formed by the linear combination (**e**₁ - **e**₄) - (**e**₂ - **e**₄). Similarly, **e**₂ - **e**₃ and **e**₁ - **e**₃ are also in the span. Utilizing the generator vectors involving dimension 4 is more cost-effective than purchasing vectors exclusively among the target dimensions, which would incur a cost of at least 4.

In Example 3, there is only one target dimension (**t** = 1). Because there are no distinct pairs of target dimensions, the condition that every pair **x** and **y** must have **e**_**x** - **e**_**y** in the span is vacuously satisfied (for **x**=1 and **y**=1, the difference is **e**₁ - **e**₁ = **0**, which is always in the span of the empty set). Thus, zero vectors need to be purchased, resulting in a cost of 0.
</STATEMENT>
<RATIONALE>
I completely removed the graph and set-partitioning framing, replacing it with an equivalent algebraic formulation over a real vector space. The required connectivity is now expressed as requiring the difference vectors of target dimensions to be within the linear span of the selected basis difference vectors. This forces models to independently discover the isomorphism between graphic matroid closure and graph connectivity to apply the Steiner Tree algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The linear span of a set of difference vectors $e_u - e_v$ contains $e_x - e_y$ if and only if $x$ and $y$ are in the same connected component of the graph formed by treating the vectors as edges; thus, the valid subsets and their costs perfectly match the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains mathematically isomorphic to the Minimum Weight Steiner Tree problem on a graph, preserving its NP-complete complexity class.
</PRESERVED_CLASS>
<RISK>
Models might mistakenly assume that fractional coefficients in the linear combination could yield a cheaper span than integer coefficients, although the total unimodularity of the incidence matrix guarantees this is never the case.
</RISK>
