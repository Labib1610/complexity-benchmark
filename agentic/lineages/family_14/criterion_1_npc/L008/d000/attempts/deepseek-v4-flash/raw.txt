We can solve this by treating it as a **Steiner tree** problem, but since the number of primary turbines is small (≤ 10), we can use a **bitmask DP over the terminals** combined with shortest paths.

Here’s the approach:

1. Run **Floyd–Warshall** to get all-pairs shortest paths.
2. Let `terminals` be the list of primary turbine nodes.
3. Use DP:  
   `dp[mask][v]` = minimum cost to connect the terminals in `mask` and end at node `v`.
4. Initialize `dp[1 << i][terminals[i]] = 0` for each terminal.
5. Transition:
   - Merge two disjoint masks: `dp[mask1 | mask2][v] = min(dp[mask1][v] + dp[mask2][v])`
   - Extend to another node: `dp[mask][u] = min(dp[mask][v] + dist[v][u])`
6. Answer is `min(dp[(1<<t)-1][v])` for any `v`.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    terminals = list(map(int, input().split()))
    terminals = [x-1 for x in terminals]
    
    INF = 10**18
    dist = [[INF]*n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0
    
    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        if w < dist[u][v]:
            dist[u][v] = w
            dist[v][u] = w
    
    # Floyd-Warshall
    for k in range(n):
        dk = dist[k]
        for i in range(n):
            dik = dist[i][k]
            if dik == INF:
                continue
            di = dist[i]
            for j in range(n):
                nd = dik + dk[j]
                if nd < di[j]:
                    di[j] = nd
    
    # DP over subsets
    full_mask = (1 << t) - 1
    dp = [[INF]*n for _ in range(1 << t)]
    
    for i in range(t):
        dp[1 << i][terminals[i]] = 0
    
    for mask in range(1 << t):
        # Merge subsets
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if other > sub:  # avoid double work
                for v in range(n):
                    if dp[sub][v] + dp[other][v] < dp[mask][v]:
                        dp[mask][v] = dp[sub][v] + dp[other][v]
            sub = (sub - 1) & mask
        
        # Relax via shortest paths
        for v in range(n):
            if dp[mask][v] < INF:
                dv = dp[mask][v]
                for u in range(n):
                    if dist[v][u] < INF:
                        nd = dv + dist[v][u]
                        if nd < dp[mask][u]:
                            dp[mask][u] = nd
    
    ans = min(dp[full_mask])
    print(ans)

if __name__ == "__main__":
    solve()
```
