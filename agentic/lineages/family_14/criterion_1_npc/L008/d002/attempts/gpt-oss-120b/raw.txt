**Solution Explanation**

For every platform we know the cost of a possible cable to another platform.
All platforms are vertices of an undirected weighted graph.

` t ( ≤ 10 )` vertices are *terminals* – they contain primary turbines.
We have to build some cables so that after all built cables are taken,
all terminals belong to the same connected component.
Other (non‑terminal) vertices may be used as intermediate points.
The required minimum total cost is exactly the weight of a **minimum Steiner
tree** for the given terminals.



--------------------------------------------------------------------

#### 1.   Steiner DP on subsets  

`n ≤ 100 ,   t ≤ 10` – the number of terminals is tiny, therefore a classic
dynamic programming over subsets works.

```
dp[mask][v] = minimum cost of a tree
              that connects all terminals whose bits are set in mask
              and whose *root* (any vertex of the tree) is v
```

`mask` runs over all `0 … (1<<t)-1`, `v` over all vertices `0 … n-1`.

*Initialization*  

For every terminal `i` (0‑based) placed at vertex `term[i]`

```
dp[1<<i][ term[i] ] = 0          # a tree consisting of a single vertex
```

All other entries are `+∞`.

*Combining two already built sub‑trees*  

If a tree for `mask` is split into two disjoint non‑empty parts `s` and
`mask ^ s`, both having the same root `v`, the two trees can be merged
without any extra edge:

```
dp[mask][v] = min( dp[s][v] + dp[mask^s][v] )
```

The loop over all proper sub‑masks of `mask` gives the well known
`O(3^t · n)` complexity.  
To avoid doing the same split twice we only consider sub‑masks `s`
with `s < mask^s`.

*Shortest paths inside the current mask*  

After the combination step `dp[mask][*]` contains the best cost of a tree
that ends at each vertex, but the tree may be improved by adding ordinary
graph edges (i.e. by moving the root through the graph).  
Therefore we run a multi‑source Dijkstra:

```
all vertices v with dp[mask][v] < INF are inserted into a heap
standard Dijkstra relaxes edges:
    dp[mask][to] = min( dp[mask][to] , dp[mask][v] + w(v,to) )
```

After Dijkstra finishes, `dp[mask][v]` equals the cheapest
Steiner tree for `mask` whose root is `v`.

Processing masks in increasing order of their integer value guarantees
that when a mask is used as a sub‑mask, its Dijkstra step has already been
performed.

*Result*  

The answer is the cheapest tree for the full set of terminals,
independent of the root:

```
answer = min_v dp[fullMask][v]
```

--------------------------------------------------------------------

#### 2.   Correctness Proof  

We prove that the algorithm outputs the minimum possible total cost.

---

##### Lemma 1  
For every mask and vertex `v`, after the Dijkstra step of that mask
`dp[mask][v]` equals the minimum cost of a Steiner tree that connects all
terminals of `mask` and whose root is `v`.

**Proof.**  
Induction over the order in which masks are processed.

*Base* – `mask` is a power of two, i.e. a single terminal `ti`.  
Before Dijkstra we have `dp[mask][ti]=0` and `∞` elsewhere.
Running Dijkstra on this source set computes exactly the shortest path
distance from `ti` to every vertex, which is the cheapest tree (a single
path) connecting the only terminal and ending at `v`.  

*Induction step* – assume the statement true for all proper sub‑masks of
`mask`.  
Before Dijkstra the algorithm performed the combination step:

```
dp'[mask][v] = min_{s proper non‑empty} ( dp[s][v] + dp[mask^s][v] )
```

By the induction hypothesis each term `dp[s][v]` (resp. `dp[mask^s][v]`)
is the optimum cost of a tree for `s` (resp. `mask^s`) rooted at `v`.
Their sum is the cost of the union of the two trees, which is a feasible
tree for `mask` rooted at `v`.  
Taking the minimum over all splits yields the cheapest such tree **that
does not use any edge leaving the root**.

Now Dijkstra is started with exactly these values as initial distances.
Standard Dijkstra computes for every vertex `v` the cheapest way to reach
`v` from any source, i.e. the cheapest tree for `mask` whose root may be
any vertex and then extended by a shortest path to `v`.  
Consequently after Dijkstra `dp[mask][v]` is the optimum cost of a Steiner
tree for `mask` rooted at `v`. ∎



##### Lemma 2  
For every mask, after its Dijkstra step `dp[mask][v]` is **no larger** than
the cost of any set of cables that connects exactly the terminals of
`mask` and whose connected component contains `v`.

**Proof.**  
Take any feasible set of cables `C`. Its connected component containing
`v` is a tree (or can be reduced to a tree without increasing cost) that
connects all terminals of `mask`. Root this tree at `v`.  
By Lemma&nbsp;1 the DP value after Dijkstra is the minimum possible cost
among all such trees, therefore it cannot exceed the cost of `C`. ∎



##### Lemma 3  
For the full mask `F = (1<<t)-1` the value  

```
best = min_v dp[F][v]
```

equals the minimum possible total cost of cables that make all terminals
mutually reachable.

**Proof.**  
*Upper bound*: By Lemma&nbsp;1 each `dp[F][v]` is the cost of a concrete
Steiner tree, hence `best` is achievable.

*Lower bound*: Let `C*` be an optimal set of cables achieving the global
minimum `OPT`. Its connected component containing all terminals is a tree
`T*`. Choose any vertex `r` of `T*` as root. By Lemma&nbsp;2,
`dp[F][r] ≤ cost(T*) = OPT`. Consequently `best ≤ OPT`. ∎



##### Theorem  
The algorithm prints the minimum total material cost required to make all
primary turbine platforms belong to the same energy grid.

**Proof.**  
The algorithm outputs `best = min_v dp[F][v]`. By Lemma&nbsp;3 this value
equals the optimum `OPT`. ∎



--------------------------------------------------------------------

#### 3.   Complexity Analysis  

```
Number of masks          : 2^t   ≤ 1024
Combination step per mask: O( (number of proper sub‑masks) · n )
                           ≤ O( 2^{|mask|-1} · n )
Total over all masks    : O( 3^t · n )   ≤ 5.9·10^4 · 100  ≈ 6·10^6
Dijkstra per mask       : O( m log n )
All masks               : O( 2^t · m log n ) ≤ 1024·5000·7 ≈ 3.6·10^7
Memory                  : O( 2^t · n )  ≤ 1.0·10^5  integers
```

Both time (well below the 5 s limit) and memory fit easily.

#### 4.   Reference Implementation  (Python 3)

```python
import sys
import heapq

INF = 10 ** 18

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))

    terminals = [int(next(it)) - 1 for _ in range(t)]

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        adj[u].append((v, w))
        adj[v].append((u, w))

    full_mask = (1 << t) - 1
    dp = [[INF] * n for _ in range(1 << t)]

    # initialise single‑terminal masks
    for i, v in enumerate(terminals):
        dp[1 << i][v] = 0

    # process masks in increasing order
    for mask in range(1, full_mask + 1):
        # combine two already computed sub‑masks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if other and sub < other:          # each unordered pair once
                dps = dp[sub]
                dpo = dp[other]
                dpm = dp[mask]
                for v in range(n):
                    val = dps[v] + dpo[v]
                    if val < dpm[v]:
                        dpm[v] = val
            sub = (sub - 1) & mask

        # multi‑source Dijkstra for this mask
        heap = [(dp[mask][v], v) for v in range(n) if dp[mask][v] < INF]
        heapq.heapify(heap)
        while heap:
            d, v = heapq.heappop(heap)
            if d != dp[mask][v]:
                continue
            for to, w in adj[v]:
                nd = d + w
                if nd < dp[mask][to]:
                    dp[mask][to] = nd
                    heapq.heappush(heap, (nd, to))

    answer = min(dp[full_mask])
    print(answer)


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input / output format.
