<STATEMENT>
# Problem A — Grid Integration

Time limit: 5 s   Memory limit: 256 MB

## Description

An offshore wind farm features **n** platforms (numbered 1 to **n**). A surveying team has evaluated **m** potential submarine cable routes. Each route can link a specific pair of platforms for a given material cost.

Among the platforms, **t** of them are equipped with primary turbines. Your objective is to unify all primary turbines into a single energy-sharing network by installing a subset of the surveyed cables. Two primary turbines can share energy if there is a continuous path of installed cables between them. These paths can pass freely through any platforms in the wind farm, meaning platforms without primary turbines can serve as intermediate routing junctions. You do not need to connect non-primary platforms unless they are useful for bridging the primary ones.

Determine the minimum total material cost required to install a valid subset of cables. The surveyed routes are guaranteed to be sufficient to unify all primary turbines.

## Input

The first line contains three integers **n**, **m**, and **t**. The physical capacity of the wind farm allows for a total platform count **n** of at least 1 and at most 100. The number of surveyed routes **m** is at least 0 and at most **n**·(**n**−1)/2. The hardware constraints limit the number of primary turbines **t** to be at least 1 and at most 10.
The second line contains **t** distinct integers: the IDs of the primary turbine platforms, each between 1 and **n**.
Each of the next **m** lines contains three integers **u**, **v**, and **w**. These represent a potential submarine cable between platform **u** and platform **v** (**u** ≠ **v**, both between 1 and **n**) with a material cost **w**. Budget and material limits mean the cost **w** is at least 1 and at most 1000000.

## Output

Print a single integer: the minimum total material cost of the installed cables.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, purchasing the cables joining platform 4 to platforms 1, 2, and 3 (total cost 1+1+1 = 3) unifies the three primary turbines into a single network. This is cheaper than installing cables strictly between the primary turbine platforms themselves (which would cost 4). In Example 3, there is only one primary turbine, so no cabling is needed.

<RATIONALE>
I reworded the connectivity requirement to describe unifying nodes into a "single energy-sharing network" rather than explicitly stating "every primary turbine platform can exchange energy with every other". This avoids the standard Steiner Tree phrasing that triggers pattern matching. I also integrated the numeric bounds directly into the input section as physical and hardware constraints, applying the strategy while ensuring no exact limits were dropped.
</RATIONALE>
