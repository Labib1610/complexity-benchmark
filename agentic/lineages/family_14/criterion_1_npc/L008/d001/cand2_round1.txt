<STATEMENT>
# Problem A — Grid Integration

Time limit: 5 s   Memory limit: 256 MB

## Description

An offshore wind facility consists of **n** marine installations (numbered 1 to **n**). Exactly **t** of these installations are active generators, and the rest are passive hubs.

You have the option to commission bidirectional transmission links between certain pairs of installations. Commissioning a link between installation **u** and **v** requires an investment of **w** resources.

Your objective is to select a subset of links to commission such that all **t** active generators are unified. The active generators are unified if, using only the commissioned links, energy can be transferred between any pair of them. Once commissioned, a link can carry energy in either direction. Passive hubs do not generate energy, but they will freely transfer energy between any commissioned links attached to them. You may utilize as many passive hubs as necessary to minimize your total investment.

Determine the minimum total resource investment (the sum of the investments for all commissioned links) required to unify all active generators.

## Input

The first line provides three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line provides **t** distinct integers: the identifiers of the installations that are active generators.
Each of the next **m** lines provides three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), indicating that a transmission link can be commissioned between installations **u** and **v** for an investment of **w** resources.
It is guaranteed that the available link options are sufficient to unify all active generators.

## Output

Output a single integer representing the minimum total resource investment required to unify all active generators.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, utilizing the passive hub at installation 4 to transfer energy (investment of 1+1+1 = 3) is more economical than commissioning links directly between the three active generators (which would require an investment of 4). In Example 3, there is only one active generator, so no links need to be commissioned.
