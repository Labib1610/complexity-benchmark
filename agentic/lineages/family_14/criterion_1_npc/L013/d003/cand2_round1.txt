<STATEMENT>
# Problem A — Data Topic Exchange

Time limit: 5 s   Memory limit: 256 MB

## Description

An industrial facility fields **n** routing nodes. Within this network, there are **t** distinct data topics. Each topic is exclusively mastered by a single, unique routing node. 

To achieve full system consensus, the facility must satisfy a complete set of pairwise subscription demands: every master node must establish a two-way subscription with every other master node. 

Subscriptions are processed by establishing a continuous communication fabric. The facility features **m** potential bidirectional data links between pairs of nodes. Activating any single link imposes a strict, continuous energy draw. A subscription demand between two master nodes is satisfied if data can route between them through any sequence of active links. Because the data is multiplexed, multiple subscriptions can share the same active links simultaneously without requiring any additional energy.

Your task is to determine the minimum total continuous energy draw necessary to activate a set of links such that all pairwise subscription demands among the master nodes are simultaneously satisfied.

The facility operates under strict hardware limits:
* The number of data topics **t** requires a dedicated consensus register per topic. There is at least one register, and a maximum of exactly ten such registers available.
* The total number of routing nodes **n** is at least one, and can be at most the square of the maximum number of consensus registers. The nodes are assigned integer identifiers from one up to **n**.
* The number of potential links **m** can be as low as zero and as high as the total number of unique pairs that can be formed from the **n** nodes.
* Each potential link connects two distinct nodes, and its energy draw **w** is at least one unit and cannot exceed exactly one million units.

## Input

The first line contains three integers **n**, **m**, and **t**.
The second line contains **t** distinct integers: the identifiers of the routing nodes that master the data topics.
Each of the next **m** lines contains three integers **u**, **v**, and **w**, representing a potential bidirectional data link between node **u** and node **v** that requires **w** units of energy to activate.
It is guaranteed that there exists at least one combination of links that allows all pairwise subscription demands to be satisfied.

## Output

Print a single integer: the minimum total energy draw required to ensure all pairwise subscription demands are satisfied.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the optimal configuration activates the links between nodes (1, 4), (2, 4), and (3, 4) for a total energy draw of 1 + 1 + 1 = 3. This allows the master nodes 1, 2, and 3 to satisfy all pairwise subscription demands by routing through node 4. In Example 3, there is only one master node, so zero pairwise demands exist, requiring a total energy draw of 0.
