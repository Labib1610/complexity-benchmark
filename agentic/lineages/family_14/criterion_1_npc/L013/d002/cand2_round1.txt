# Problem A — Network Provisioning

Time limit: 5 s   Memory limit: 256 MB

## Description

A distributed computing system contains **n** processing nodes (numbered 1 through **n**). A physical constraint of the facility's chassis caps the total number of nodes at exactly 100. There is always at least one node.

A designated group of **t** core controllers must be fully interconnected to exchange telemetry data. The master control board features exactly 10 priority sockets, meaning the number of core controllers is at least 1 and at most 10.

You can provision bidirectional communication channels between certain pairs of nodes. The number of available channels **m** ranges from 0 up to the maximum possible number of distinct pairs of nodes.

Each available channel requires a specific amount of power to maintain. The power supply units ensure that any channel's power requirement **w** is at least 1, and no channel requires more than 1,000,000 units of power.

Data exchange operates across the provisioned channels: telemetry can be transmitted directly between two nodes if a channel is provisioned between them. Telemetry transmission is transitive: if data can be transmitted between node A and node B, and between node B and node C, then it can be transmitted between node A and node C.

Your objective is to select a subset of the available channels to provision such that telemetry can be successfully exchanged among all core controllers. Find the minimum total power required to provision such a set of channels.

## Input

The first line contains three integers **n**, **m**, and **t**. (Their bounds are determined by the physical limits described above: the chassis capacity for **n**, the available pairs for **m**, and the priority sockets for **t**).
The second line contains **t** distinct integers: the identifiers of the core controllers.
Each of the next **m** lines contains three integers **u**, **v**, and **w**, representing an available bidirectional channel between node **u** and node **v** that requires **w** units of power to maintain. (The power **w** respects the minimum and maximum ratings detailed above. **u** and **v** are distinct valid node identifiers).
It is guaranteed that there exists at least one set of channels that allows all core controllers to exchange telemetry data.

## Output

Print a single integer: the minimum total power required to provision channels such that all core controllers can exchange telemetry data with each other.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, the optimal subset of channels to provision requires a total power of 3. In Example 3, there is only one core controller, so no channels need to be provisioned (0 power).
