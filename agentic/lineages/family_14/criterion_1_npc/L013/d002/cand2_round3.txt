<STATEMENT>
# Problem A — Security Grid

Time limit: 5 s   Memory limit: 256 MB

## Description

An underground facility has **n** junction points (numbered 1 through **n**). A designated subset of **t** critical junctions must be fully interconnected to form a unified security grid.

You are provided with a list of potential bidirectional fiber-optic cables that can be activated between certain pairs of junction points. Activating each cable incurs a specific energy cost.

The security grid relies on transitive connectivity: if a path of activated cables exists between any two critical junctions, they are considered linked. 

Your task is to determine the minimum total energy cost required to activate a set of cables such that all **t** critical junctions are linked into a single communicating network.

## Input

The first line contains three integers **n**, **m**, and **t**. The facility size limits the number of junctions to at most 100 (1 ≤ n ≤ 100). Hardware priority slots restrict the number of critical junctions to at most 10 (1 ≤ t ≤ 10). The number of potential cables **m** is bounded by the maximum possible connections (0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the identifiers of the critical junctions.
Each of the next **m** lines contains three integers **u**, **v**, and **w**. These represent a potential bidirectional cable between distinct junctions **u** and **v** (1 ≤ u, v ≤ n, u ≠ v) requiring an energy cost of **w** (1 ≤ w ≤ 1000000).
It is guaranteed that the available cables are sufficient to link all critical junctions.

## Output

Print a single integer: the minimum total energy cost required to activate cables such that all critical junctions are linked together.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, activating cables (1,4), (2,4), and (3,4) costs 1+1+1 = 3 energy, which successfully links the critical junctions 1, 2, and 3. In Example 3, there is only one critical junction, so no cables need to be activated (0 energy).
