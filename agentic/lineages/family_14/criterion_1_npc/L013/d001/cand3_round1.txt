<STATEMENT>
# Problem A — Coalition Building

Time limit: 5 s   Memory limit: 256 MB

## Description

A parliamentary system consists of **n** political factions (numbered 1 through **n**). A specific subset of **t** key factions must be brought together into a unified voting bloc to pass a crucial resolution.

You can negotiate formal alliances between certain pairs of factions. Each potential alliance requires a specific amount of political capital to secure.

Factions belong to the same coalition if an alliance is negotiated directly between them. Furthermore, coalition membership is transitive: if faction A and faction B belong to the same coalition, and faction B and faction C belong to the same coalition, then faction A and faction C belong to the same coalition.

Your goal is to select a set of alliances to negotiate such that all key factions belong to the same coalition. You may negotiate alliances involving non-key factions if using them as intermediaries reduces the overall political capital required.

Find the minimum total political capital required to negotiate a valid set of alliances.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ t ≤ 10, 1 ≤ n ≤ 100, 0 ≤ m ≤ n·(n−1)/2).
The second line contains **t** distinct integers: the identifiers of the key factions.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v ≤ n, u ≠ v, 1 ≤ w ≤ 1000000), representing a potential alliance between faction **u** and faction **v** that requires **w** units of political capital to secure.
It is guaranteed that there exists at least one set of alliances that brings all key factions into the same coalition.

## Output

Print a single integer: the minimum total political capital required to negotiate alliances such that all key factions belong to the same coalition.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, securing alliances through the non-key faction 4 (requiring 1+1+1 = 3 capital) is more efficient than allying the three key factions directly (which would require 2+2 = 4 capital). In Example 3, there is only one key faction, so it already constitutes its own coalition and no alliances need to be negotiated (0 capital).

<RATIONALE>
Changed the domain from data synchronization (a classical spatial/network framing) to political coalitions (abstract relations). This removes the standard networking cues ("modules", "links", "data flow") that models rely on to quickly map the problem to graph connectivity and the Steiner Tree problem, forcing them to reconstruct the graph theoretic structure from the abstract rules of transitive grouping.
</RATIONALE>
<PRESERVED_ANSWER>
The structural requirement of finding a minimum-weight set of relations to transitively group a specific subset of entities remains exactly the same, ensuring all optimal costs are identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying mathematical model is still exactly the Steiner Tree problem on graphs, preserving its NP-complete complexity.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "belong to the same coalition" as requiring a complete clique of pairwise alliances, though the explicit definition of transitivity strongly mitigates this.
</RISK>
