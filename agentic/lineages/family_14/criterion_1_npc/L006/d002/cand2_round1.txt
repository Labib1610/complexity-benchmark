<STATEMENT>
# Problem A — Corporate Liquidity

Time limit: 5 s   Memory limit: 256 MB

## Description

A global financial market operates with **n** distinct currencies, indexed 1 through **n**. The market offers **m** potential bidirectional exchange agreements. Activating an agreement between currency **u** and currency **v** requires the corporation to secure **w** regulatory approvals. Each regulatory approval incurs a fixed processing cost of exactly 1 unit. Consequently, the effective expense to activate a given agreement is equal to its required number of approvals.

A multinational corporation maintains strategic reserves in a specific subset of **t** primary currencies. The corporation's goal is to guarantee pure liquidity exclusively across this primary subset. 

Pure liquidity is defined as the unbroken ability to route funds from any primary currency to any other primary currency. This routing may occur directly via a single activated agreement, or indirectly via a sequence of activated agreements. The corporation may route funds through non-primary currencies, provided every agreement in the routing sequence has been fully activated.

Calculate the minimum total processing cost the corporation must incur to activate a valid configuration of agreements that guarantees pure liquidity for all primary currencies.

## Input

The first line contains three integers **n**, **m**, and **t** (1 ≤ **t** ≤ 10, 1 ≤ **n** ≤ 100, 0 ≤ **m** ≤ **n**·(**n**−1)/2).
The second line contains **t** distinct integers: the ids of the primary currencies.
Each of the next **m** lines contains three integers **u**, **v**, and **w** (1 ≤ **u**, **v** ≤ **n**, **u** ≠ **v**, 1 ≤ **w** ≤ 1000000): indicating an available exchange agreement between currency **u** and currency **v** that requires **w** regulatory approvals.
The available exchange agreements are sufficient to achieve pure liquidity.

## Output

Print a single integer: the minimum total processing cost to guarantee pure liquidity among all primary currencies.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, activating agreements through the non-primary currency 4 requires 1+1+1 = 3 approvals (a processing cost of 3). This is cheaper than activating agreements between the three primary currencies directly (which would require 4 approvals, costing 4). In Example 3, there is only one primary currency, so no agreements need to be activated (cost of 0).

<RATIONALE>
The suggestion to change the cost to $w^2$ was rejected because it would change the correct output for inputs where $w > 1$, violating the Hard Constraint to preserve identical answers for the unmodified reference solution. Instead, the "direct additive" affordance was disrupted by redefining $w$ as a quantity of regulatory approvals rather than a direct monetary fee, with each approval costing 1 unit. This forces models to deduce that the effective edge weight is $w \times 1 = w$, breaking superficial pattern matching while maintaining mathematical equivalence.
</RATIONALE>
<PRESERVED_ANSWER>
The total cost of an agreement is defined as $w$ approvals multiplied by 1 cost unit per approval, which mathematically equals exactly $w$, ensuring all outputs remain identical to the seed.
</PRESERVED_ANSWER>
