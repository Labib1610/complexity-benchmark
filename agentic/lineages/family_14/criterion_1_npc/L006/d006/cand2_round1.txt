# Problem A — Permutation Group Orbits

Time limit: 5 s   Memory limit: 256 MB

## Description

A mathematical puzzle involves a set of $n$ distinct elements, labeled 1 through $n$. You are given a set of $m$ available transposition operations. Each transposition operation allows you to swap the elements at two specific labels $u$ and $v$.

Each transposition operation has an associated selection cost $w$. You are required to select a subset of these operations. Let $E$ be your selected subset. 

The selected transpositions in $E$ mathematically generate a permutation group $G = \langle E \rangle$. The group $G$ consists of all permutations that can be formed by composing any sequence of transpositions chosen exclusively from $E$ (transpositions from $E$ can be used any number of times in the sequence, in any order).

Under the natural action of the group $G$, the $n$ labels are partitioned into disjoint equivalence classes called orbits. Two labels $a$ and $b$ belong to the same orbit if and only if there exists at least one permutation $P \in G$ such that $P(a) = b$.

You are given a target subset of $t$ critical labels. Your objective is to select a subset of transpositions $E$ such that all $t$ critical labels belong to the exact same orbit under the action of the generated group $G$. 

You may select transpositions involving non-critical labels if they help to merge the orbits containing the critical labels.

Determine the minimum total selection cost of a subset $E$ that satisfies this requirement.

## Input

The first line provides three integers $n$, $m$, and $t$ (1 ≤ $t$ ≤ 10, 1 ≤ $n$ ≤ 100, 0 ≤ $m$ ≤ $n$·($n$−1)/2).
The second line lists $t$ distinct integers representing the critical labels.
Each of the subsequent $m$ lines specifies an available transposition operation using three integers $u$, $v$, and $w$ (1 ≤ $u$, $v$ ≤ $n$, $u$ ≠ $v$, 1 ≤ $w$ ≤ 1000000). This indicates a transposition swapping labels $u$ and $v$ with a selection cost of $w$.
It is guaranteed that selecting all $m$ available operations would place all critical labels in the same orbit.

## Output

Print a single integer: the minimum total selection cost required to ensure all critical labels share the same orbit.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the transpositions involving the non-critical label 4 (costs 1, 1, and 1; total cost = 3) is more cost-effective than selecting the transpositions directly among the three critical labels (which would require a total cost of 4). The group generated by the three selected transpositions is the symmetric group $S_4$, which acts transitively on all four labels, meaning they all belong to a single orbit.

In Example 3, there is only a single critical label. It is trivially in its own orbit, so no transpositions need to be selected, resulting in a total cost of 0.

<RATIONALE>
The problem was completely reframed from linear algebra to abstract algebra (permutation groups). Instead of asking for vectors to be in a linear span, it asks for a subset of transpositions that generates a permutation group whose orbit contains all critical elements. This forces the model to realize the mathematical equivalence between the orbits of a group generated by transpositions and the connected components of a graph whose edges are those transpositions.
</RATIONALE>
<PRESERVED_ANSWER>
The orbits of a permutation group generated by a set of transpositions correspond exactly to the connected components of the graph formed by treating those transpositions as edges; thus, finding the minimum cost to place terminal nodes in the same orbit is mathematically identical to finding a minimum-weight Steiner Tree.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains the Steiner Tree problem on graphs, which is NP-complete, as the translation to permutation group orbits is a perfect mathematical isomorphism that preserves the exact same combinatorial structure.
</PRESERVED_CLASS>
