# Problem A — Orbit Configuration

Time limit: 5 s   Memory limit: 256 MB

## Description

A combinatorial design team is configuring a system of $n$ discrete state variables, indexed 1 through $n$. The team is focused on a specific subset of $t$ core variables.

Their objective is to ensure that all core variables belong to the same orbit under a generated permutation group.

To achieve this, the team can activate a selection from $m$ available primitive operators. Each available operator acts on the state variables by swapping the values of a specific pair of variables $u$ and $v$ (a transposition). 

In the context of permutation groups, if we consider the subgroup of the symmetric group $S_n$ generated by the selected transpositions, two variables belong to the same orbit if and only if one can be mapped to the other by some sequence of the selected operators. The team's requirement is that the entire subset of $t$ core variables must be contained within a single orbit of the generated group.

The team is permitted to activate operators involving non-core variables, provided their inclusion helps merge the orbits containing the core variables. Each available operator is either selected for activation or not selected. If selected, its activation cost is paid exactly once. (Once activated, the operators conceptually generate the subgroup by being composable any number of times).

Each primitive operator has a fixed activation cost, $w$. The total cost is the sum of the activation costs of the distinct operators the team chooses to activate.

Determine the minimum total activation cost required to select a set of operators such that all $t$ core variables are in the same orbit of the subgroup they generate.

## Input

The first line provides three integers $n$, $m$, and $t$ (1 ≤ $t$ ≤ 10, 1 ≤ $n$ ≤ 100, 0 ≤ $m$ ≤ $n$·($n$−1)/2).
The second line lists $t$ distinct integers representing the indices of the core variables.
Each of the subsequent $m$ lines specifies an available primitive operator using three integers $u$, $v$, and $w$ (1 ≤ $u$, $v$ ≤ $n$, $u$ ≠ $v$, 1 ≤ $w$ ≤ 1000000). This indicates an operator swapping variables $u$ and $v$ with a one-time activation cost of $w$.
It is guaranteed that the set of all $m$ available operators is sufficient to place all core variables into a single orbit.

## Output

Print a single integer: the minimum total activation cost required to ensure all core variables belong to the same orbit under the generated subgroup.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, activating the operators that involve the non-core variable 4 (which require costs of 1, 1, and 1; total cost = 3) is more efficient than activating the operators directly involving only the three core variables (which would result in a total cost of 4). The transpositions (1 4) and (2 4) generate a subgroup where 1, 2, and 4 are in the same orbit, and including (3 4) places 3 in that orbit as well. Thus, variable 4 acts as an effective intermediary. 
In Example 3, there is only a single core variable. The requirement is already satisfied, so no operators need to be activated, resulting in a total cost of 0.
