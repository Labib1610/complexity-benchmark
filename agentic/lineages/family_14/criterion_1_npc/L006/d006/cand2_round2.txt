<METHOD_NAME>Permutation Orbit Framing</METHOD_NAME>
<METHOD_DESCRIPTION>Transforms the graph connectivity problem into an abstract algebra problem where selecting edges corresponds to selecting transpositions, and connected components correspond to orbits under the generated subgroup. This obscures the standard graph-theoretic Steiner Tree structure while maintaining exact mathematical equivalence.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Orbit Generation

Time limit: 5 s   Memory limit: 256 MB

## Description

A computational algebra system is manipulating a set of $n$ distinct labels, denoted $1, 2, \dots, n$. The system tracks a specific subset of $t$ critical labels.

The system's objective is to construct a permutation group $H$ such that all $t$ critical labels belong to the exact same orbit under the natural action of $H$. Recall that the orbit of a label $x$ under a group $H$ is the set of all labels $y$ such that there exists a permutation $h \in H$ mapping $x$ to $y$.

To construct $H$, the system can select from $m$ available basic transpositions. Each available transposition swaps exactly two labels $u$ and $v$ (leaving all other labels fixed). When a subset of these transpositions is selected, $H$ is defined as the subgroup generated by the selected transpositions.

The system is permitted to select transpositions that swap non-critical labels, as long as the resulting generated subgroup $H$ places all critical labels into a single orbit.

Each available transposition has a fixed selection cost, $w$. The total cost is the sum of the selection costs of the distinct transpositions chosen.

Determine the minimum total selection cost required to choose a set of transpositions such that all critical labels are in the same orbit under the generated subgroup $H$.

## Input

The first line provides three integers $n$, $m$, and $t$ (1 ≤ $t$ ≤ 10, 1 ≤ $n$ ≤ 100, 0 ≤ $m$ ≤ $n \cdot (n - 1) / 2$).
The second line lists $t$ distinct integers representing the critical labels.
Each of the subsequent $m$ lines specifies an available transposition using three integers $u$, $v$, and $w$ (1 ≤ $u$, $v$ ≤ $n$, $u \neq v$, 1 ≤ $w$ ≤ 1000000). This indicates a transposition swapping labels $u$ and $v$ with a selection cost of $w$.
It is guaranteed that the set of all $m$ available transpositions is sufficient to place all critical labels into a single orbit.

## Output

Print a single integer: the minimum total selection cost required to ensure all critical labels belong to the same orbit under the subgroup generated by the selected transpositions.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the transpositions that involve the non-critical label 4 (costs of 1, 1, and 1; total cost = 3) is more efficient than selecting the transpositions directly swapping only the three critical labels (total cost = 4). The transpositions (1, 4) and (2, 4) can generate the transposition (1, 2) by composition. Thus, label 4 acts as an effective algebraic pivot to merge the orbits. 
In Example 3, there is only a single critical label. The requirement that all critical labels belong to the same orbit is already satisfied without selecting any transpositions, resulting in a total cost of 0.
</STATEMENT>
<RATIONALE>
The problem was rewritten to use the language of permutation groups and orbits rather than linear algebra or graph theory. This forces models to realize that elements being in the same orbit under a generated set of transpositions is isomorphic to vertices being in the same connected component of a graph, thus hiding the "Steiner Tree" nature of the problem behind algebraic definitions.
</RATIONALE>
<PRESERVED_ANSWER>
Two elements are in the same orbit under a group generated by transpositions if and only if there is a path between them in the graph where the transpositions are edges; thus, finding the minimum cost to place terminal elements in the same orbit is exactly the minimum Steiner tree problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the minimum-cost connected subgraph containing a set of critical nodes (Steiner Tree), maintaining its NP-completeness.
</PRESERVED_CLASS>
<RISK>
Models might struggle with the definition of generated subgroups or orbits, but the definitions provided are standard and mathematically unambiguous.
</RISK>
