<METHOD_NAME>Polynomial Ideal Isomorphism</METHOD_NAME>
<METHOD_DESCRIPTION>Transforms the linear algebra / vector span framing into a commutative algebra framing using ideals generated by binomials in a polynomial ring. The degree-1 homogeneity ensures mathematical equivalence to graph connectivity, but forces the model to bridge the gap between polynomial ideals and combinatorial graphs without relying on standard incidence-matrix terminology.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Binomial Ideals

Time limit: 5 s   Memory limit: 256 MB

## Description

A computer algebra system operates over the polynomial ring $R = \mathbb{R}[x_1, x_2, \dots, x_n]$. 
The system is tasked with constructing an ideal $I \subseteq R$ that satisfies a specific algebraic condition regarding a designated subset of $t$ critical variables.

The requirement is that for every pair of critical variables $x_a$ and $x_b$, their difference $x_a - x_b$ must be an element of the ideal $I$.

To construct $I$, the system selects from $m$ available binomial generators. Each available generator is of the form $x_u - x_v$ for a specific pair of variables $x_u$ and $x_v$. 
Adding a generator $x_u - x_v$ to the generating set of $I$ incurs a fixed computational cost $w$. The total cost is the sum of the costs of all distinct generators chosen. 
The ideal $I$ is then formally defined as the ideal generated by the selected subset of binomials.

The system is permitted to select generators involving non-critical variables, provided the resulting ideal successfully contains the required binomials $x_a - x_b$ for all critical $a, b$.

Determine the minimum total cost of a subset of available generators such that the ideal they generate contains $x_a - x_b$ for all pairs of critical variables $a$ and $b$.

## Input

The first line provides three integers $n$, $m$, and $t$ (1 ≤ $t$ ≤ 10, 1 ≤ $n$ ≤ 100, 0 ≤ $m$ ≤ $n$·($n$−1)/2).
The second line lists $t$ distinct integers representing the indices of the critical variables.
Each of the subsequent $m$ lines specifies an available generator using three integers $u$, $v$, and $w$ (1 ≤ $u$, $v$ ≤ $n$, $u$ ≠ $v$, 1 ≤ $w$ ≤ 1000000). This indicates that the binomial $x_u - x_v$ is available to be added to the generating set for a cost of $w$.
It is guaranteed that selecting all $m$ available generators would yield an ideal containing all target differences among the critical variables.

## Output

Print a single integer: the minimum total cost required to select a generating set such that $x_a - x_b \in I$ for all critical variables $a$ and $b$.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the generators $x_1 - x_4$, $x_2 - x_4$, and $x_3 - x_4$ incurs a total cost of $1 + 1 + 1 = 3$. 
The ideal generated by these three binomials contains the required differences $x_1 - x_2$, $x_2 - x_3$, and $x_1 - x_3$. For instance, $x_1 - x_2$ is in this ideal. 
This is more efficient than selecting generators directly involving only the three critical variables, which would result in a total cost of at least 4. Variable $x_4$ acts as an effective algebraic pivot. 
In Example 3, there is only a single critical variable, so there are no pairs $a, b$ whose difference needs to be contained in the ideal. No generators need to be selected, resulting in a total cost of 0.
</STATEMENT>
<RATIONALE>
The problem was rewritten to use the language of commutative algebra and polynomial ideals rather than linear algebra and vector span. Because the generators and targets are all homogeneous polynomials of degree 1, ideal membership is mathematically identical to linear span, which in turn is isomorphic to graph connectivity. This forces models to reason through the algebraic definition to discover the underlying Steiner Tree structure, preventing pattern-matching on incidence vectors.
</RATIONALE>
<PRESERVED_ANSWER>
Because degree-1 binomials can only generate other degree-1 binomials via constant multipliers, $x_a - x_b \in I$ if and only if $a$ and $b$ are in the same connected component of the graph formed by the chosen generators, meaning the exact same subsets are valid and optimal.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Steiner Tree problem on a graph, keeping it in NP-Complete and preserving the $O(3^t n + 2^t (n+m) \log n)$ Dreyfus-Wagner intended solution.
</PRESERVED_CLASS>
<RISK>
Models might attempt to actually compute Groebner bases or use symbolic algebra packages if they fail to recognize the combinatorial reduction, leading to Time Limit Exceeded, but the statement itself is mathematically unambiguous.
</RISK>
