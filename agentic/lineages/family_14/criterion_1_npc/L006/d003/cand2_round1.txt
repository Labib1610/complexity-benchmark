<STATEMENT>
# Problem A — Corporate Liquidity

Time limit: 5 s   Memory limit: 256 MB

## Description

A financial system tracks a set of assets. Within this system, certain bilateral swap agreements are available. Activating an agreement permits transactions to flow in either direction between two specified assets, but incurs a specific compliance overhead.

A consortium manages a core portfolio of target assets. Their objective is to establish a unified clearing network exclusively for this core portfolio. A network is considered unified if a sequence of activated swap agreements can route transactions from any target asset to any other target asset.

When constructing this network, the consortium does not have to restrict themselves to agreements between target assets. They may incorporate any other assets into their routing paths as transitional steps.

The total compliance burden of a proposed configuration is evaluated as the $L_1$ norm (the sum of absolute values) of the vector formed by the compliance overheads of all activated agreements. Determine the minimum total compliance burden required to guarantee that all target assets are mutually routable.

## Input

The first line contains three integers **n**, **m**, and **t**.
- The total number of assets **n** is at least 1 and is strictly bounded by the maximum capacity of the legacy trading mainframe, which supports exactly 100 distinct assets.
- The number of available swap agreements **m** is at least 0 and cannot exceed the total number of unique pairs among the **n** assets.
- The number of target assets **t** is at least 1 and bounded by the number of digital signature slots on the consortium's multi-sig wallet, which is exactly 10.

The second line contains **t** distinct integers: the identifiers of the target assets.

Each of the next **m** lines contains three integers **u**, **v**, and **w**, describing an available swap agreement between asset **u** and asset **v** (where **u** and **v** are distinct, and between 1 and **n**). The compliance overhead **w** is at least 1 and is capped by the maximum insurance policy limit of exactly 1000000.

It is always possible to form a unified clearing network using the given agreements.

## Output

Print a single integer: the minimum total compliance burden to achieve a unified clearing network among all target assets.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, establishing swap agreements through the auxiliary asset 4 (overheads 1, 1, 1; $L_1$ norm = 3) is more efficient than establishing agreements between the three target assets directly (which would have an $L_1$ norm of 4). In Example 3 there is only one target asset, so no swap agreements need to be activated (vector is empty, $L_1$ norm = 0).
