**Solution Explanation**

For the given undirected weighted graph we have to choose a set of edges whose total
weight is minimum and which makes all `t` *terminal* vertices belong to the same
connected component.
That is exactly the **Steiner Tree** problem for a small number of terminals
(`t ≤ 10`).  
The classic exact algorithm of Dreyfus‑Wagner solves it in  

```
O( 3^t · n + 2^t · m log n )
```

which is easily fast enough for `n ≤ 100 , m ≤ 4950`.

--------------------------------------------------------------------

#### 1.   Notation  

* `n` – number of vertices (1 … n)  
* `m` – number of edges, each edge `u‑v` has weight `w` (positive)  
* `term[0 … t‑1]` – the terminal vertices (the “primary currencies”)  
* `FULL = (1<<t)‑1` – bitmask with all terminals set  

`dp[mask][v]` – minimal total weight of a sub‑graph that

* connects **exactly** the terminals whose bits are set in `mask`
* and whose **rightmost** vertex (the “root”) is `v`

The answer will be `min_v dp[FULL][v]`.

--------------------------------------------------------------------

#### 2.   Initialisation  

For every terminal `i`

```
dp[ 1<<i ][ term[i] ] = 0
```

All other entries are `INF`.

--------------------------------------------------------------------

#### 3.   Merging two already built sub‑trees  

For a mask containing at least two terminals we can split it into two non‑empty
disjoint sub‑masks `sub` and `mask ^ sub`.  
If both sub‑trees end in the **same** vertex `v`, they can be united without
paying any extra edge:

```
dp[mask][v] = min( dp[mask][v] , dp[sub][v] + dp[mask^sub][v] )
```

We try **all** proper sub‑masks (`sub = (mask-1) & mask` loop).

--------------------------------------------------------------------

#### 4.   Spreading the root through the graph  

After the merging step `dp[mask][v]` is known only for the vertices that are
already roots of the two parts.  
To allow the root to move to a neighbour we run a multi‑source Dijkstra
with the current `dp[mask][*]` as initial distances:

```
while priority queue not empty:
        (dist, u) = pop
        if dist != dp[mask][u]: continue
        for (v, w) in adj[u]:
                if dp[mask][u] + w < dp[mask][v]:
                        dp[mask][v] = dp[mask][u] + w
                        push (dp[mask][v], v)
```

After Dijkstra finishes, `dp[mask][v]` equals the cheapest way to connect the
terminals of `mask` and end the tree at `v`.

--------------------------------------------------------------------

#### 5.   Whole DP order  

Masks are processed in increasing order of their integer value.
For a mask

```
if mask is power of two:   # already initialised, only Dijkstra needed
        run Dijkstra
else:
        for every proper submask:
                relax dp[mask][v] by merging (section 3)
        run Dijkstra (section 4)
```

Because every sub‑mask is smaller, its `dp` table is already final when it is
used.

--------------------------------------------------------------------

#### 6.   Result  

`answer = min( dp[FULL][v] for v in 0 … n-1 )`

If `t == 1` the initialisation already gives `0`.

--------------------------------------------------------------------

#### 7.   Correctness Proof  

We prove that the algorithm outputs the minimum possible total weight.

---

##### Lemma 1  
For any mask and vertex `v`, after the Dijkstra step finishes,
`dp[mask][v]` equals the minimum weight of a **connected** sub‑graph that

* contains all terminals of `mask`
* and whose **rightmost** vertex is `v`.

**Proof.**  
Induction over the Dijkstra process.

*Initially* the queue contains exactly those vertices `v` for which a tree
ending at `v` is already known (coming from the merging step). Their distances
are correct by definition.

*Relaxation step*: when we pop `(dist, u)` we already know that `dist` is the
minimum possible (standard Dijkstra invariant). Adding edge `u‑v` of weight `w`
creates a tree ending at `v` with total weight `dist + w`. If this is better
than the current value for `v` we update it. No other tree ending at `v` can be
cheaper, because any such tree must contain a cheapest path from its root to
`v`, and Dijkstra explores paths in non‑decreasing order of their total weight.
∎



##### Lemma 2  
After processing a mask `M` (including its merging and Dijkstra steps),
for every vertex `v` the value `dp[M][v]` is the minimum possible weight of a
tree that connects **exactly** the terminals of `M` and ends at `v`.

**Proof.**  
Induction over the number of bits in `M`.

*Base*: `|M| = 1`. The only tree connecting a single terminal `t` and ending at
`v` has weight `0` if `v = t` and is impossible otherwise. The algorithm sets
exactly these values, and Dijkstra then correctly propagates them to all other
vertices (the cheapest way is the shortest path from `t` to `v`). Hence the
statement holds.

*Induction step*: assume the statement true for all proper sub‑masks of `M`.  
Consider any optimal tree `T` for mask `M` ending at vertex `v`. Remove the
edges of `T` that are incident to `v`; the remaining forest consists of two
disjoint sub‑trees whose terminal sets form a partition `A , B` of `M`
(`A ∪ B = M , A ∩ B = ∅`). Both sub‑trees also end at `v`. By the induction
hypothesis their costs are at least `dp[A][v]` and `dp[B][v]`. Therefore

```
cost(T) ≥ dp[A][v] + dp[B][v] .
```

The algorithm examines **all** such partitions during the merging loop and
stores the minimum of the right‑hand side into `dp[M][v]`. Consequently
`dp[M][v]` is not larger than the optimum.

Conversely, any value produced by the merging step corresponds to joining two
optimal sub‑trees (by induction hypothesis) at the same vertex `v`; the union
is a feasible tree for `M` ending at `v`. Afterwards Dijkstra only adds shortest
paths, which cannot increase the optimum for a fixed ending vertex. Hence the
final `dp[M][v]` cannot be smaller than the true optimum.

Thus `dp[M][v]` equals the optimum. ∎



##### Lemma 3  
For the full mask `FULL`, `min_v dp[FULL][v]` equals the minimum total weight of
any set of edges that makes all terminals mutually connected.

**Proof.**  
Any connected sub‑graph that contains all terminals has at least one vertex
`v`. Removing all edges that are not on a spanning tree of that sub‑graph yields a
tree with the same vertex set and not larger total weight, still ending at `v`.
By Lemma&nbsp;2 the cheapest such tree ending at `v` costs `dp[FULL][v]`. Taking the
minimum over all possible `v` gives the cheapest connected sub‑graph at all. ∎



##### Theorem  
The algorithm outputs the minimum possible total regulatory burden required to
connect all primary currencies.

**Proof.**  
By Lemma&nbsp;2 the DP table is correct after the algorithm finishes.
Lemma&nbsp;3 shows that the answer derived from the table is exactly the optimum.
Therefore the printed number is the required minimum. ∎



--------------------------------------------------------------------

#### 8.   Complexity Analysis  

*Number of masks*: `2^t ≤ 1024`.

*Merging step*: for each mask we iterate over all its proper sub‑masks.
The total number of `(mask, submask)` pairs is `3^t`.  
For each pair we scan all `n ≤ 100` vertices → `O(3^t · n)`.

*Dijkstra*: performed once per mask.
Each run is `O( (n + m) log n )`.  
Overall `O( 2^t · (n+m) log n )`.

With the given limits (`t ≤ 10, n ≤ 100, m ≤ 4950`) the program runs far
below the 5‑second limit and uses `O(2^t · n) ≤ 1024·100 ≈ 10⁵` memory.

--------------------------------------------------------------------

#### 9.   Reference Implementation  (Python 3)

```python
import sys
import heapq

INF = 10**18

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))
    terminals = [int(next(it)) - 1 for _ in range(t)]

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        adj[u].append((v, w))
        adj[v].append((u, w))

    if t == 1:
        print(0)
        return

    FULL = (1 << t) - 1
    dp = [[INF] * n for _ in range(FULL + 1)]

    # initialise singletons
    for i, node in enumerate(terminals):
        dp[1 << i][node] = 0

    # helper: run multi-source Dijkstra for a given mask
    def dijkstra(mask: int):
        pq = []
        for v in range(n):
            if dp[mask][v] < INF:
                heapq.heappush(pq, (dp[mask][v], v))
        while pq:
            d, u = heapq.heappop(pq)
            if d != dp[mask][u]:
                continue
            for v, w in adj[u]:
                nd = d + w
                if nd < dp[mask][v]:
                    dp[mask][v] = nd
                    heapq.heappush(pq, (nd, v))

    # DP over masks
    for mask in range(1, FULL + 1):
        # skip singletons for merging, but still need Dijkstra
        if mask & (mask - 1):          # more than one bit set
            sub = (mask - 1) & mask
            while sub:
                other = mask ^ sub
                # to avoid doing both (sub, other) and (other, sub) we could enforce sub < other,
                # but the min operation is cheap; we just process all.
                for v in range(n):
                    val = dp[sub][v] + dp[other][v]
                    if val < dp[mask][v]:
                        dp[mask][v] = val
                sub = (sub - 1) & mask
        # after merging, spread through the graph
        dijkstra(mask)

    ans = min(dp[FULL])
    print(ans)


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
