<STATEMENT>
# Ideal Generator Selection

Time limit: 5 s   Memory limit: 256 MB

## Description

Consider the polynomial ring $R = \mathbb{R}[x_1, x_2, \dots, x_n]$ over the real numbers. The ring has $n$ variables, indexed 1 through $n$. You are given a set of $t$ target indices, $T$.

There is a pool of $m$ available generator polynomials. Each available generator is a binomial of the form $x_u - x_v$ for some pair of distinct variables. Incorporating a specific generator into your chosen subset incurs a one-time cost of $w$.

You must select a subset of the available generators. Let $I \subseteq R$ be the ideal generated by your selected subset. Recall that the ideal $I$ generated by a subset of polynomials $S$ consists of all finite sums $\sum h_i g_i$, where $g_i \in S$ and $h_i \in R$.

Your objective is to ensure that for every pair of indices $a, b \in T$, the polynomial $x_a - x_b$ is an element of the ideal $I$.

You may select generators involving variables whose indices are not in $T$, provided their inclusion helps establish the required polynomials in the ideal. The total cost is the sum of the costs of the distinct generators you choose to include.

Determine the minimum total cost required to select a subset of generators such that the resulting ideal satisfies the condition.

## Input

The first line provides three integers $n$, $m$, and $t$ (1 ≤ $t$ ≤ 10, 1 ≤ $n$ ≤ 100, 0 ≤ $m$ ≤ $n(n-1)/2$).
The second line lists $t$ distinct integers representing the indices in the target set $T$.
Each of the subsequent $m$ lines specifies an available generator using three integers $u$, $v$, and $w$ (1 ≤ $u, v$ ≤ $n$, $u \ne v$, 1 ≤ $w$ ≤ 1000000). This indicates that the polynomial $x_u - x_v$ is available to be selected for a cost of $w$. (Because $x_v - x_u = -(x_u - x_v)$, selecting either generates the same ideal, so the order of $u$ and $v$ is immaterial).
It is guaranteed that the set of all $m$ available generators is sufficient to ensure $x_a - x_b \in I$ for all $a, b \in T$.

## Output

Print a single integer: the minimum total cost of a selected subset of generators that satisfies the condition.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the generators $x_1 - x_4$, $x_2 - x_4$, and $x_3 - x_4$ incurs costs of 1, 1, and 1, for a total cost of 3. In the resulting ideal, we can express $x_1 - x_2$ as $(x_1 - x_4) - (x_2 - x_4)$. Because ideals are closed under addition and subtraction, $x_1 - x_2$ is in the ideal. Similarly, $x_2 - x_3$ and $x_1 - x_3$ can be formed. Thus, $x_a - x_b \in I$ for all $a, b \in \{1, 2, 3\}$. This is more cost-effective than selecting generators directly between the target indices (which would result in a total cost of 4).

In Example 3, there is only a single target index. The requirement that $x_a - x_b \in I$ for every pair $a, b \in T$ is inherently satisfied, because the only pair is $a=1, b=1$, and $x_1 - x_1 = 0$, which is trivially in any ideal. Therefore, no generators need to be selected, resulting in a total cost of 0.

<RATIONALE>
The problem was completely reframed using abstract algebra, specifically polynomial rings and ideal generation. To solve it, a model must independently construct the proof that a degree-1 binomial $x_a - x_b$ belongs to the ideal generated by a set of binomials $\{x_u - x_v\}$ if and only if $a$ and $b$ are in the same connected component of the corresponding graph. This completely masks the Steiner Tree structure and breaks pattern-matching on graph terminology.
</RATIONALE>
<PRESERVED_ANSWER>
The answers are preserved because $x_a - x_b$ is in the ideal generated by a subset of $\{x_u - x_v\}$ if and only if there is a path between $a$ and $b$ in the graph formed by the selected subset, making the condition mathematically equivalent to finding a connected subgraph containing all target vertices.
</PRESERVED_ANSWER>

The complexity class is unchanged because the underlying optimization task is still EXACTLY the minimum-weight Steiner Tree problem on an undirected graph, which is NP-complete.
